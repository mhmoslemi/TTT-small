**1. Mathematical Reformulation**

For a discretised step‑function `h∈[0,1]^n` with `∑h = n/2` (`n` = number of sample points, the default is 120) the overlap integrals are the entries of the linear correlation

```
c_k(h) = Σ_{i=0}^{n‑1} h[i]·(1‑h[i+k])   ,   k = –(n‑1)…(n‑1)
```

(the sum is taken only over indices that stay inside the array).  
With `S = Σ h_i = n/2` we have

```
c_k(h) = S – Σ_i h_i·h_{i+k}.
```

Thus minimising `max_k c_k` is equivalent to **maximising the smallest auto‑correlation term**
`Σ_i h_i·h_{i+k}` over all shifts.  
The objective is a *max* of smooth (actually quadratic) functions, which is non‑convex but has a simple sub‑gradient.

**2. Smoothed Max via Log‑Sum‑Exp**

Instead of the non‑smooth maximum we minimise the smooth surrogate

```
F_α(h) = (1/α)·log Σ_k exp(α·c_k(h)) ,   α>0 .
```

`F_α` converges to `max_k c_k` as `α→∞`, yet for moderate `α` it is differentiable and its gradient is a weighted average of the gradients of the individual `c_k`:

```
∇F_α(h) = Σ_k w_k·∇c_k(h) ,
w_k = exp(α·c_k) / Σ_j exp(α·c_j) .
```

Because `∇c_k(h)= 1 – h_{i+k} – h_{i‑k}` (out‑of‑range terms are omitted) the gradient can be written in a fully vectorised form.

**3. Exact Gradient Evaluation (O(n²) but tiny)**

* `h[i‑k]`  → subtract `w_k·h` from the last `n‑|k|` components.

The constant term `+1` appears in every component because the weights sum to 1:
