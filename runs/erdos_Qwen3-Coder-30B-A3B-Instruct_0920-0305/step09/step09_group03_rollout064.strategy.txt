**Goal** – Find a step‑function `h` on `[0,2]` (discretised into `n` points) that minimises  

\[
C_5(h)=\max_{k}\int_0^2 h(x)\bigl(1-h(x+k)\bigr)\,dx .
\]

In the discrete world (sampling step `dx = 2/n`) this is  

\[
C_5(h)=dx\; \max_{\ell\in\{-n+1,\dots,n-1\}} 
\;f_\ell(h),\qquad
f_\ell(h)=\sum_{i=0}^{n-1} h_i\,\bigl(1-h_{i+\ell}\bigr),
\]

where out‑of‑range indices are taken as zero.  
The constraints are  

* `0 ≤ h_i ≤ 1` for all `i`,
* `∑_i h_i = n/2`  (because `dx·∑h_i = 1`).

The current record (≈ 0.38092) was obtained by a very heuristic random‑search + COBYLA scheme.  
The new approach replaces the heuristic search by a **smooth, gradient‑based optimisation** that directly targets the *maximum* of the `f_ℓ`’s, followed by a fast **local annealing** phase to escape possible shallow minima.

--------------------------------------------------------------------
### 1.  Smooth approximation of the max‑operator  

Rewrite the objective as

\[
\max_\ell f_\ell(h)=\frac{1}{\alpha}\log\!\Bigl(\sum_{\ell}
   \exp\bigl(\alpha\,f_\ell(h)\bigr)\Bigr)
\;\;\stackrel{\alpha\to\infty}{\longrightarrow}\;\;
\max_\ell f_\ell(h).
\]

For a moderate temperature `α` the function is differentiable; we can compute its gradient analytically and use it in a projected gradient step.  
We will **increase `α` progressively** (continuation method) – start with `α=1` and multiply by `1.5` every few hundred iterations until a cap `α_max≈200` is reached.  This yields a smooth descent initially and a more exact max‑minimisation later.

--------------------------------------------------------------------
### 2.  Gradient of the soft‑max objective  

Define

* `b = 1 – h` (element‑wise),
* `f = correlate(h, b, mode='full')`  – the vector of `f_ℓ`,
* `w_ℓ = exp(α f_ℓ) / Σ_j exp(α f_j)`  – soft‑max weights (they sum to 1).

For a fixed `ℓ`

\[
\frac{\partial f_\ell}{\partial h_i}
   = 1 - \bigl(h_{i+\ell}+h_{i-\ell}\bigr),
\qquad\text{(out‑of‑range indices give zero)} .
\]

Therefore the gradient of the soft‑max objective is

\[
\nabla_h\;=\; \sum_{\ell} w_\ell\,
            \bigl[\,1 \;-\;(h_{\cdot+\ell}+h_{\cdot-\ell})\bigr] 
        \;=\;
          \mathbf{1}
          \;-\;
          \bigl( W\ast h \;+\; W^{\!R}\!\ast h \bigr) ,
\]

where `W` is the weight vector `w` (indexed by shift `ℓ`), `W^{R}` its reversal,
and `∗` denotes *linear* convolution (zero‑padded).  
Only the central `n` entries of each convolution are needed.

**Implementation details**

* Convolutions are performed via a **real FFT** on length `L = next_pow2(2n‑1 + n‑1)`.  
  This gives `O(L log L)` per iteration – negligible for `n ≤ 256`.  
* The constant vector `1` has length `n`; we subtract the two convolution results element‑wise to obtain the gradient.

--------------------------------------------------------------------
### 3.  Projection onto the feasible set  

After a gradient step the vector may leave the box `[0,1]^n` and the linear constraint `∑h = n/2`.  
We use the **capped‑simplex projection** (Duchi‑Shalev‑Shwartz 2008) :

1. Clip the vector to `[0,1]`.
2. Find a scalar `λ` such that `∑_i clip(x_i+λ,0,1) = n/2`.  
   This is a 1‑dimensional monotone root‑finding problem; a binary search on `λ` converges in ≤ 50 iterations.  
3. Return the clipped, shifted vector.

The projection is cheap (linear time) and keeps us exactly on the feasible manifold.

### 4.  Optimisation loop  

**Parameters (tuned offline, but kept simple):**

| Symbol | Meaning | Typical value |
|--------|---------|----------------|
| `n` | discretisation points | 224 (a power‑of‑two‑plus‑a‑few, `dx≈0.0089`) |
| `α_start` | initial soft‑max temperature | 1.0 |
| `α_factor` | temperature increase factor | 1.5 |

| `η_decay` | multiply step size when `α` is increased | 0.7 |
| `iters_per_α` | number of gradient steps between two temperature upgrades | 150 |
| `max_iters` | hard cap on total iterations | 5000 (well below the 600 s budget) |
| `restart_budget` | time fraction devoted to fresh restarts | ≈ 0.7 of total time |

**Algorithm (single “restart”):**

```
h ← feasible random start (uniform [0,1] then capped‑simplex projection)
α ← α_start, η ← η_start
for it = 1 … max_iters
    compute f = correlate(h, 1‑h)               # O(n log n) via FFT
    compute soft‑max weights w (stable exp)     # subtract max for numerical safety
    compute convolutions c1 = conv(w, h), c2 = conv(w[::-1], h)   # via FFT
    grad = 1 – (c1_center + c2_center)          # vector of length n
    h ← h + η * grad                            # ascent on the soft‑max (negative gradient descent)
    h ← project_onto_capped_simplex(h)          # enforce constraints
    if it % iters_per_α == 0:
        α ← min(α·α_factor, α_max)
        η ← η·η_decay
    keep the best h seen (lowest exact C5 evaluated by raw correlation)
end
```

**Why this works:**  
* The smooth max turns the original non‑smooth “max‑over‑shifts” into a differentiable objective that still directs the iterate toward the *worst* shift.  
* The continuation (`α` growth) lets the algorithm first move in a well‑behaved landscape (small `α`) and later focus sharply on the actual max.  
* Projection guarantees we never violate the hard constraints, which removes the need for penalty terms.

### 5.  Multi‑restart strategy  

The whole optimisation (Section 4) is **restarted** many times with different seeds:

The number of restarts is limited only by the remaining wall‑clock time (≈ 70 % of the budget). After each restart the best‑so‑far vector and its exact `C5` are stored.

### 6.  Post‑gradient local annealing  

When the gradient phase ends we possess a high‑quality candidate `h*`.  
To possibly shave off the remaining few 10⁻⁴ in `C5` we run a **simulated‑annealing fine‑tuner** that respects the constraints by construction:

* Pick two indices `i≠j`.  
  *If `h_i` is not at a bound, propose `h_i' = h_i + δ` and `h_j' = h_j – δ`.*
* `δ` is drawn uniformly from `[-Δ,Δ]` with `Δ` shrinking over time (e.g. start `Δ=0.05`).  
* Project the pair onto the box `[0,1]` (clipping after the symmetric transfer already keeps the sum exact, no extra projection needed).  
* Compute the exact `C5` of the perturbed vector (full correlation via FFT).  
* Accept the move if it improves `C5`; otherwise accept with Metropolis probability  
  `exp(-(C5_new‑C5_old)/T)`, where the temperature `T` decays exponentially.

The annealer runs for the remaining ≈ 30 % of the time budget, performing a few thousand proposals (each proposal is O(n log n) and cheap).

### 7.  Evaluation routine  

All `C5` evaluations inside the optimiser use the **FFT‑based correlation**:

```
g = ifft( fft(h_rev, L) * fft(1‑h, L) ).real
C5 = dx * max(g)
```

`dx = 2/n`.  
Only the *final* returned `C5` needs to be a Python `float`; everything else stays as NumPy arrays.
