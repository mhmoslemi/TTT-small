### 1.  Problem formulation (continuous version)

For a discrete step‑function `h = (h₀,…,h_{n‑1})` on `[0,2]` we use the same discretisation as the evaluator:

```
c_k(h) = Σ_{i=0}^{n‑1‑|k|} h_{i+|k|}·(1‑h_i)      ,   k = -(n‑1)…(n‑1)
C₅(h)   = dx·max_k c_k(h)    with  dx = 2/n
```

The feasible set is the box `[0,1]^n` intersected with the linear equality  

```
Σ_i h_i = n/2   (because ∫₀² h = 1)
```

The objective `max_k c_k` is non‑smooth and non‑convex.  We replace the hard maximum by a smooth **log‑sum‑exp** upper bound:

```
F_ε(h) = (1/ε)·log( Σ_k exp( ε·c_k(h) ) )    (ε > 0)
```

`F_ε` → `max_k c_k` as `ε → ∞`.  Minimising `F_ε` is a differentiable surrogate that can be handled by gradient‑based optimisation.

### 2.  Analytic gradient of the surrogate

For a fixed shift `s ≥ 0` the term

```
c_s = Σ_{i=0}^{n‑1‑s} h_{i+s}·(1‑h_i)
```

has the partial derivative

```
∂c_s/∂h_j =  (1‑h_{j‑s})·1_{j≥s}   –   h_{j+s}·1_{j≤n‑1‑s}
```

For a negative shift `‑s (s>0)` the expression is symmetric:

```
c_{‑s} = Σ_{i=0}^{n‑1‑s} h_i·(1‑h_{i+s})
∂c_{‑s}/∂h_j =  (1‑h_{j+s})·1_{j≤n‑1‑s}   –   h_{j‑s}·1_{j≥s}
```

The derivative of `F_ε` follows from the chain rule because it is a weighted sum of the `c_k`’s:

```
w_k = exp( ε·c_k ) / Σ_j exp( ε·c_j )          (softmax weights)
∇F_ε(h) = Σ_k w_k · ∇c_k(h)
```

Thus the gradient is a **linear combination of shifted copies** of the vectors `(1‑h)` and `h`.  Implementation can be done in O(n²) time with simple NumPy slices, or in O(n log n) by using FFTs for the `c_k` values and then looping over the `n` shifts to accumulate the weighted contributions.

### 3.  Projection onto the feasibility set

After any gradient step we must enforce:

```
0 ≤ h_i ≤ 1      for all i
Σ_i h_i = n/2
```

The projection reduces to finding a scalar λ such that

```
ĥ_i = clip( h_i + λ , 0 , 1 )
```

satisfies the sum constraint.  Because the mapping λ ↦ Σ_i ĥ_i is monotone, a short binary search (≈30 iterations, double‑precision tolerance 1e‑10) yields λ efficiently.  This routine works for any `n` and is already present in the reference code.
