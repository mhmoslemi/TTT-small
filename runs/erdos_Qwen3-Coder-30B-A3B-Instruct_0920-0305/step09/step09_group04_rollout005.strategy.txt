**1.  Problem restatement in discrete form**  

Let `n` be the number of sample points (choose `n = 120` – the same size as the provided seed, which gives a fine enough discretisation while keeping the problem tractable).

h = (h0 , h1 , … , h_{n‑1}) ∈ [0,1]^n ,    Σ_i h_i = n/2 .

For an integer shift `k ∈ { -(n‑1), … , n‑1 }` the discrete overlap used by the evaluator is  

```
c_k(h) = Σ_{i=0}^{n‑1‑|k|}  h_{i+|k|} · (1 – h_i) .

The quantity to be minimised is  

```

**2.  Smooth‑max surrogate**  

The `max` is non‑differentiable, which prevents the use of gradient methods.  
Introduce a smooth approximation based on the log‑sum‑exp:

```
f_ε(h) = (1/ε) · log( Σ_k exp( ε·c_k(h) ) ) .
```

For any ε>0, `f_ε(h) ≥ max_k c_k(h)` and as ε→∞ the surrogate converges to the true maximum.  
The gradient of `f_ε` is a weighted average of the gradients of the individual overlaps:

```
w_k = exp( ε·c_k(h) ) / Σ_j exp( ε·c_j(h) )      (soft‑max weights)

∇f_ε(h) = Σ_k w_k · ∇c_k(h) .
```

Thus we only need the gradient of a single overlap `c_k`.

**3.  Gradient of a single overlap**  

For a non‑negative shift `s ≥ 0`

```
c_s(h) = Σ_{i=0}^{n‑1‑s} h_{i+s}·(1 – h_i) .
```

For a component `h_j`

```
∂c_s/∂h_j =  {  (1 – h_{j‑s})    if j ≥ s                (h_j appears as the shifted factor)
               –h_{j+s}        if j ≤ n‑1‑s           (h_j appears as the unshifted factor)
               0               otherwise } .
```

For a negative shift `–s (s>0)` the roles are interchanged and the same formula follows by symmetry.  
Collecting all shifts, the gradient can be written compactly using shifted copies of `h` and `1‑h`:

```
For each s = 0 … n‑1:
    a_s = [0,…,0, (1‑h)_0,…,(1‑h)_{n‑1‑s}]          (length‑n vector)
    b_s = [h_s,…,h_{n‑1}, 0,…,0]                    (length‑n vector)
    contribution for +s :   w_{+s} · (a_s – b_s)

For each s = 1 … n‑1:
    a'_s = [(1‑h)_s,…,(1‑h)_{n‑1}, 0,…,0]          (shift left)
    b'_s = [0,…,0, h_0,…,h_{n‑1‑s}]                (shift right)
    contribution for –s :   w_{‑s} · (a'_s – b'_s)
```

Summing all contributions yields `∇f_ε(h)` in O(n²) time (n≈120 ⇒ negligible).
