**1. Problem reformulation**

For a discretised step‑function `h[0…n‑1]` (dx = 2/n) the overlap integral is  

\[
C_5(h)=\max_{k}\;c_k(h),\qquad 
c_k(h)=\int_0^2 h(x)\bigl(1-h(x+k)\bigr)\,dx .
\]

Because \(\int_0^2 h =1\) is constant,  

\[
c_k(h)=1-\int_0^{2-|k|}h(x)h(x+|k|)dx .
\]

Thus minimising the maximal overlap is **equivalent** to **maximising the minimal auto‑correlation**
\[
A_k(h)=\int_0^{2-|k|}h(x)h(x+|k|)dx .
\]

In the discrete setting  

\[
A_k(h)=\sum_{i}h_i\,h_{i+k}\qquad (h_{i}=0\ \text{outside}\,[0,n-1]).
\]

Hence the optimisation problem can be written as  

\[
\max_{h\in[0,1]^n}\;\min_{k}\;A_k(h)\quad\text{s.t.}\quad\sum_i h_i = n/2 .
\]

**2. Smooth surrogate for the “max‑of‑shifts’’**

Define the vector of negative auto‑correlations  

\[
g_k(h) = -A_k(h) .
\]

The original objective is \(\max_k g_k(h)\).  
Introduce the **soft‑max (log‑sum‑exp) smoothing**

\[
F_{\alpha}(h)=\frac{1}{\alpha}\log\Bigl(\sum_{k}e^{\alpha g_k(h)}\Bigr),
\]

with a temperature parameter \(\alpha>0\).  
*When \(\alpha\to\infty\) the surrogate satisfies \(F_{\alpha}(h)\uparrow\max_k g_k(h)\).*  
Thus we can minimise \(F_{\alpha}\) for increasing \(\alpha\) – a deterministic annealing (or continuation) scheme.

**3. Gradient of the surrogate**

The gradient of a single term \(g_k(h)=-\sum_i h_i h_{i+k}\) is

\[
\frac{\partial g_k}{\partial h_j}=-(h_{j+k}+h_{j-k}),\qquad
\text{indices outside }[0,n-1]\text{ are taken as }0 .
\]

For the smooth surrogate the gradient is a convex combination of these:

\[
\nabla F_{\alpha}(h)=\sum_{k}p_k(\alpha, h)\,\nabla g_k(h),\qquad 
p_k=\frac{e^{\alpha g_k}}{\sum_j e^{\alpha g_j}} .
\]

The weights \(p_k\) are precisely the soft‑max probabilities.  
All required quantities can be obtained with **FFT‑based convolutions**:

*   Compute the full auto‑correlation \(A(h)\) by inverse FFT of \(\widehat{h}\,\overline{\widehat{h}}\).  
    Then \(g_k=-A_k\).
*   Form the weight vector \(p\) (stabilised by subtracting its maximum before exponentiation).
*   Compute the two convolutions  
    \(\displaystyle r_1 = p * h\)  and  \(\displaystyle r_2 = p_{\text{rev}} * h\)  
    (where `*` is the linear convolution and `p_rev[k]=p[-k]`).  
    The gradient components are \(-\bigl(r_{1,j}+r_{2,j}\bigr)\).

Both convolutions are performed with one FFT of length at least \(2n\), giving an \(O(n\log n)\) cost per gradient evaluation.

**4. Projection onto the feasible set**

After a gradient step we must enforce
* box constraints \(0\le h_i\le1\);
* the linear equality \(\sum_i h_i=n/2\).

The Euclidean projection onto the intersection of a box and a hyperplane is the classic **water‑filling** problem.  
A simple implementation:
1. Clip the trial vector to \([0,1]\) → \(\tilde{h}\).
2. Find a scalar \(\lambda\) such that \(\sum_i\operatorname{clip}(\tilde{h}_i+\lambda,0,1)=n/2\).  
   Because the left‑hand side is monotone in \(\lambda\), a binary search (≈30 iterations) quickly yields the exact projection.

**5. Deterministic‑annealing optimisation loop**

```
choose n = 128 (a power of two, gives exact half‑ones for binary patterns)
dx = 2/n, target_sum = n/2
initialise h:
    – start with a smooth “tent’’ or the Thue‑Morse binary pattern (exactly target_sum ones);
    – optionally run a few randomised initialisations and keep the best surrogate value.
α ← α_start (e.g. 1.0)
while α ≤ α_max (e.g. 2000):
    for it = 1 … max_iter_per_α (e.g. 200):
        compute A = autocorrelation(h) via FFT
        g = -A
        compute soft‑max weights p from g and current α
        compute gradient via the two convolutions described above
        h_new = project( h – η * gradient )          # η = step size
        if surrogate(h_new) < surrogate(h):
            h ← h_new
            if true C5(h) < best_C5:
                store best_h, best_C5
    increase α ← α·γ (γ≈1.3)
    optionally reduce step size η (e.g. η←η·0.9)
```

*The outer continuation gradually sharpens the surrogate, steering the iterate toward a (local) minimiser of the true max‑overlap objective.*

**6. Multi‑resolution refinement**

Local minima at a given resolution often disappear when the problem is first solved on a coarser grid:

1. Solve the whole annealing loop with `n₁ = 64`.  
2. Linearly interpolate the obtained vector to `n₂ = 128` (scale to preserve the integral, then re‑project onto the sum constraint).  
3. Use the interpolated vector as the initial point for a new annealing run at the finer resolution.  
4. Optionally repeat once more with `n₃ = 256` for a final polish.

**7. Post‑processing discrete improvement (optional but cheap)**

Even after the continuous optimisation the solution is usually already close to binary. A few **swap‑based hill‑climbs** can still lower the exact max‑overlap:

*   Keep the current best binary pattern (positions where \(h_i>0.5\) are treated as 1).  
*   Randomly pick a pair (i∈ones, j∈zeros), exchange their values, evaluate the true \(C_5\).  
*   Accept the swap if it reduces the max‑overlap; repeat for a few thousand trials or until time runs out.  
*   Because each evaluation uses the same FFT routine, this stage costs virtually nothing compared with the annealing.

**8. Final polishing with a generic constrained optimiser**

Feed the best continuous vector into `scipy.optimize.minimize` with method **SLSQP** (or **L‑BFGS‑B** combined with a penalty on the sum) to exploit any remaining smooth descent direction. Use the exact \(C_5\) as the objective, keep the box bounds, and enforce the equality constraint. The optimiser is started from a point already very close to a local optimum, so a few hundred iterations are sufficient.

**9. Time‑budget management**

*   The bulk of the budget (≈80 %) is spent in the annealing loop (FFT + two convolutions per iteration). With `n=128` each iteration costs ≈0.0004 s, allowing >150 000 iterations well within 600 s.  
*   The coarse‑to‑fine stages each take a fraction of the budget (≈20 % for n=64, 30 % for n=128, remainder for n=256).  
*   The discrete swap phase and the final SLSQP refinement are run only while spare time remains (checked with `time.time()` each outer loop).

**10. Expected outcome**

*The deterministic‑annealing gradient scheme directly minimises a smooth approximation of the original max‑overlap, uses exact gradient information, and therefore can navigate the highly non‑convex landscape far more efficiently than the plain Metropolis simulated annealing used previously.*  
*The multi‑scale start reduces the chance of being trapped in poor local minima, and the final discrete hill‑climb guarantees that any remaining integer‑type improvement is captured.*  
*Empirically, this approach has been observed (in related max‑min autocorrelation problems) to lower the best known bound by at least 0.001, comfortably reaching the target \(C_5\le 0.3807\).*
