### 1.  Problem recap  

* Variables: a step‑function sampled on a uniform grid of `n` points  
  `h = (h₀,…,h_{n‑1}) , 0 ≤ h_i ≤ 1`.  

* Equality constraint:  `Σ_i h_i · dx = 1`   (with `dx = 2/n`).  
  Equivalently `Σ_i h_i = n/2`.

* Objective (to be **minimised**):  

\[
C_5(h)=\max_{k\in\{-n+1,\dots,n-1\}} 
\;c_k(h),\qquad 
c_k(h)=\sum_{i} h_i\bigl(1-h_{i+k}\bigr) ,
\]

where out‑of‑range indices are ignored when the sum is formed
(the same definition used by `np.correlate(...,mode='full')`).

The goal is to find a feasible `h` with the smallest possible `C_5`
(​the current best ≈ 0.380975).

### 2.  Why the previous approach is limited  

* **Simulated annealing** explores the space almost blindly and
  spends many iterations on proposals that are immediately rejected.
* **SLSQP** works on a *non‑convex*, non‑smooth objective (`max` of
  quadratic terms) and can easily get stuck in a local basin.
* Neither method exploits the **structure** of the objective:
  the worst shift `k` is known after each evaluation and the gradient
  of the corresponding term can be written analytically.

--------------------------------------------------------------------

### 3.  Core idea – smooth‑max surrogate + projected sub‑gradient descent  

Replace the non‑smooth `max` by the **log‑sum‑exp** (soft‑max) which
converges to the true max when a temperature parameter `μ` → 0:

\[
S_μ(h)=\mu\;\log\Bigl(\sum_{k} \exp\!\bigl(c_k(h)/\mu\bigr)\Bigr)
\qquad\text{and}\qquad
\lim_{μ\downarrow0} S_μ(h)=\max_k c_k(h).
\]

* `S_μ` is **differentiable**; its gradient is a convex combination of
  the gradients of the individual `c_k` :

\[
\frac{\partial S_μ}{\partial h_i}= \sum_{k} w_k(h)\;
\frac{\partial c_k}{\partial h_i},
\qquad 
w_k(h)=\frac{\exp\!\bigl(c_k(h)/μ\bigr)}
           {\sum_j \exp\!\bigl(c_j(h)/μ\bigr)} .
\]

* The weights `w_k` automatically give a **sub‑gradient** of the true
  `max` when `μ` is tiny – we can therefore use them in a sub‑gradient
  method while still having a smooth direction for larger `μ`.

--------------------------------------------------------------------

### 4.  Analytic gradient of a single shift  

For a fixed integer shift `k ≥ 0` the term

\[
c_k(h)=\sum_{i=0}^{n-k-1} h_i\bigl(1-h_{i+k}\bigr)
\]

has the following partial derivatives (the case `k<0` is symmetric
after swapping the roles of the two sequences):

```
∂c_k/∂h_i =  1 - h_{i+k}            if 0 ≤ i ≤ n-k-1
∂c_k/∂h_i = -h_{i-k}               if k ≤ i ≤ n-1
∂c_k/∂h_i =  0                     otherwise
```

In vector form this can be built with two slice operations:

```
grad[:n-k]   += 1 - h[k:]
grad[k:]     -= h[:n-k]
```

For negative `k` we just use `k = -k` and swap the two slices.

--------------------------------------------------------------------

### 5.  Projection onto the feasible set  

After any (unconstrained) step we must enforce

* box constraints `0 ≤ h_i ≤ 1`
* the **sum constraint** `Σ_i h_i = n/2`.

Both can be satisfied in **O(n)** by the classical “water‑filling”
(or “box‑simplex”) projection:

1. Shift all components by a scalar `λ`: `z_i = h_i + λ`.
2. Clip: `z_i ← min(max(z_i,0),1)`.
3. Choose `λ` so that `Σ_i z_i = n/2`.  
   The required `λ` is found by a short binary search because the
   function `f(λ)=Σ_i clip(h_i+λ,0,1)` is monotone.

The same routine (`project_to_sum_box` in the reference code) will be
re‑used, but it will be called *after every gradient step* rather than
only at the end of a random proposal.
