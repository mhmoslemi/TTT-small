**1.  Problem Reformulation**

For a discretisation with `n` points (`dx = 2/n`) let  

```
h  –  vector of length n,   0 ≤ h[i] ≤ 1
w  –  target sum = Σ h[i] = n/2            (because ∫₀² h = 1)
```

For an integer shift `k` (‑(n‑1) ≤ k ≤ n‑1) define  

```
f_k(h) = Σ_i h[i]·(1 – h[i+k])            (zero‑padding outside the interval)
```

The quantity to be minimised is  

```

```

Because `Σ h[i] = w` is constant,
```
f_k(h) = w – Σ_i h[i]·h[i+k] .
```
Thus minimising `C5` is equivalent to maximising the *minimum* overlap  
`Σ_i h[i]·h[i+k]`.  The objective is non‑convex (bilinear terms) but it is
smooth except at the point where the maximal shift changes.

`Φ_β` is differentiable and satisfies

When `β` is increased the envelope converges to the true max.  Optimising
