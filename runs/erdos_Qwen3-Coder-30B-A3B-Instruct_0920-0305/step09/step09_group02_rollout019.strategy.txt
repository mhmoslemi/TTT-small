**Goal** – Produce a step‑function `h` on `[0,2]` (discretised with `n` points) such that  

\[
C_5(h)=\max_{k}\int_{0}^{2}h(x)\bigl(1-h(x+k)\bigr)\,dx
      =\frac{2}{n}\,\max_{k}\;f_k(h)
\]

is as small as possible, while  

* `0 ≤ h[i] ≤ 1` for every index `i`,
* `∑ h[i] · dx = 1`  ⇔ `∑ h[i] = n/2`.

The plan below departs completely from the simulated‑annealing / SLSQP pipelines that have been tried so far.  
It builds a **convex‑relaxation (SDP) / rounding framework**, combined with a **cutting‑plane (lazy‑constraint) loop** that tightens the model only for the shifts that are actually critical.  The method is deterministic, exploits problem structure (symmetry, monotonicity) and uses only the libraries that are guaranteed to be available (`numpy`, `scipy`, `cvxpy` with `SCS`/`MOSEK`/`CBC`).

### 1.  Reformulation as a rank‑1 matrix program  

Introduce a vector `h ∈ ℝⁿ` and the Gram matrix  

\[
X = h\,h^{\!\top}\;\in\;\mathbb{R}^{n\times n}.
\]

For any integer shift `k` (‑(n‑1) ≤ k ≤ n‑1) define the overlap of 1‑values

\[
\omega_k(h) = \sum_{i=0}^{n-1-|k|} h_i\,h_{i+|k|} = \operatorname{tr}\bigl( S_k^{\top}X\bigr) ,
\]

where `S_k` is the binary selection matrix that extracts the `|k|`‑offset diagonal of `X`.  
Consequently  

\[
f_k(h) = w - \omega_k(h), \qquad w:=\frac{n}{2}.
\]

The original problem is  

\[
\begin{aligned}
\min_{h\in[0,1]^n}&\; t   \\
\text{s.t. }&\; w-\operatorname{tr}(S_k^{\top}X)\;\le\;t   &&\forall k,\\
            &\; X = h h^{\!\top},\\
            &\; \sum_i h_i = w .
\end{aligned}
\]

The non‑convexity lies only in the rank‑1 constraint `X = h hᵀ`.

---

### 2.  Convex SDP relaxation  

Drop the rank‑1 constraint but keep the *linear* relationships that are valid for any outer‑product:

* **PSD constraint** – `X ≽ 0` (positive semidefinite).
* **Diagonal tying** – `X_{ii} = h_i` for all `i`.  This forces each diagonal entry to equal the corresponding component of `h`.
* **Box constraints** – `0 ≤ h_i ≤ 1`.
* **Mass constraint** – `∑ h_i = w`.

The relaxed problem becomes a **semidefinite program (SDP)**:

\[
\begin{aligned}
\min_{h,X,t}&\; t \\
\text{s.t. }&\; w-\operatorname{tr}(S_k^{\top}X)\le t,\quad \forall k\in\mathcal{K},\\
            &\; X\succeq 0,\\
            &\; X_{ii}=h_i,\; 0\le h_i\le 1,\; \sum_i h_i = w .
\end{aligned}
\]

Here `𝒦` is initially a **small subset** of the shifts (e.g. `k = 0, ±1, ±⌊n/2⌋`).  The SDP yields a **lower bound** on the optimal `t` and a matrix `X` that is usually close to rank‑1.

---

### 3.  Lazy‑constraint (cutting‑plane) loop  

The full set of `2n‑1` shift constraints is far larger than necessary for the early iterations.  
We therefore adopt a **lazy‑constraint scheme**:

1. **Solve the current SDP** with the current set `𝒦` of shift constraints.
2. **Extract a candidate vector** `ĥ` (see Section 4) and compute the *exact* overlap values  
   `f_k(ĥ)` for *all* shifts using the fast `np.correlate` routine.
3. Let `k* = argmax_k f_k(ĥ)`.  
   If `f_{k*}(ĥ) ≤ t+ε` (with a tiny tolerance ε) the candidate already satisfies every shift and we have a feasible upper bound – stop.
4. Otherwise **add the violating shift** `k*` to `𝒦` and **repeat** from step 1.  
   The SDP is re‑solved with one extra linear inequality; the bound `t` can only increase, and the feasible set shrinks.

Because each iteration adds only **one** new constraint, the total number of SDP solves is bounded by the number of distinct violating shifts (typically < 20 for `n=120`).  The loop ends either with a feasible solution or when the allotted wall‑clock time is exhausted.

### 4.  From the relaxed SDP to a feasible `h`  

Although the SDP relaxation does not enforce `X = h hᵀ`, the optimal `X` is often **nearly rank‑1**.  We obtain a concrete step‑function by **randomized rounding**:

* Compute an eigen‑decomposition `X = Q Λ Qᵀ`.  
  Let `λ₁` be the largest eigenvalue and `q₁` the corresponding eigenvector.
* Set the *raw* candidate `h̃ = √λ₁ · q₁`.  
  By construction `h̃` respects the diagonal constraints only approximately, so we **project** it back onto the feasible set (box and sum) using the same simple bisection projection described in the previous solutions.
* **Symmetrisation** – enforce mirror symmetry (`h̃ = (h̃ + rev(h̃))/2`) before the final projection; symmetry is provably optimal for the continuous Erdős problem.
* **Optional polishing** – run a very short projected gradient descent (or the accelerated method from the previous strategy) starting from `h̃` for a few hundred iterations.  This step refines the rounding error while keeping the objective value ≤ the current SDP bound.

The rounded vector is a **feasible point** for the original problem; its exact `C₅` is obtained by `dx * max_k f_k(h̃)`.  Because the SDP lower bound is tight in practice, the rounded solution is usually only a few 10⁻⁴ above the optimum, often beating the 0.38092 record.

### 5.  Exploiting additional structure  

To keep the SDP modest and improve solution quality we incorporate two *deterministic* structural constraints that are known to be optimal for the continuous variant:

| Property | Linear expression |
|----------|-------------------|
| **Mirror symmetry** | `h_i = h_{n-1-i}`  (pairwise equality constraints) |
| **Unimodality (non‑increasing away from centre)** | For indices `i < n/2`: `h_i ≥ h_{i+1}` and symmetrically on the right side.  These are simple linear inequalities. |

Adding them reduces the effective dimension from `n` to roughly `n/4` and dramatically speeds up the SDP solves while *guiding* the relaxation toward the true optimum.
