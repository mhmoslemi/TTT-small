The problem is to minimize the maximum overlap integral C₅ over step functions h: [0, 2] → [0, 1] with integral 1. The overlap integral is defined as C₅ = max_k ∫ h(x)(1 - h(x+k)) dx, representing the maximum overlap over all shifts k. The solution involves a "materially different algorithm" than previous naive local search.

Our approach utilizes three distinct stages in sequence:

1. **Genetic Algorithm (GA) for Binary Discrete Search On a Combinatorial Space:**
   - Each chromosome in the population is a binary vector of length n, with exactly n/2 ones (to ensure integral constraint when scaled).
   - Fitness of an individual is defined as the negative of the maximum overlap computed from its FFT-based correlation.
   - Selection uses tournament selection.
   - Crossover is uniform crossover followed by repair to maintain exact sum constraint.
   - Mutation swaps a random 0 and 1 to preserve binary nature and sum.
   - Elitism keeps the best individual each generation.
   - Evolution runs for a fixed number of generations (based on remaining time budget) or a fixed number to limit computation.

2. **Simulated Annealing (SA) for Locally Refining Binary Solution:**
   - Start from the best binary individual found by GA.
   - Perform simulated annealing with a geometric cooling schedule.
   - Moves consist of swapping pairs of bits (1 to 0, 0 to 1) while maintaining the sum.
   - Acceptance is based on Metropolis criterion: accepts if lower C5, else with probability exp(-ΔC5/T).
   - Efficiently evaluate ΔC5 using ifft-based incremental change formula, avoiding full correlation recompute each time.

3. **Smoothed Proximal Gradient Descent (PGD) and Continuous Refinement:**
   - Initialize from the best solution obtained by SA.
   - Formulate the bilinear objective term as a smooth surrogate using log-sum-exp (LSE) to approximate the max, ensuring differentiability.
   - Use projected gradient descent with step sizing and Nesterov momentum.
   - Project onto the constraint set (box constraints [0,1], integral = 1) after each gradient step.
   - Anneal smoothing parameter α (from large to small) during descent to approach exact objective.
   - Converge or stop upon budget exhaustion.

The algorithm maintains differentiable proxies for non-smooth functions and switches between discrete and continuous domains to find a highly optimized solution with lower C₅ bound than previous attempts. It avoids iterative local searches common in earlier code, instead leveraging global exploration strategies (GA) followed by local stochastic refinement (SA) and fine-tuning (PGD).

TARGET_SUM = None

def compute_corr_fft(h):
    """Compute correlation using FFT"""
    h_rev = h[::-1]
    b = 1 - h
    L = 2 * len(h) - 1
    corr = np.fft.ifft(np.fft.fft(h_rev, L) * np.fft.fft(b, L)).real
    return corr

    """Convert correlation result to C5 value"""
    return dx * np.max(corr)

def evaluate_c5(h):

    corr = compute_corr_fft(h)
    return c5_from_corr(corr, n_points)

def project_to_sum_box(x, target_sum):
    """Project vector x onto box constraints [0,1] with sum = target_sum"""
    # Binary search for lambda: find lambda such that sum(clamp(x+lambda, 0, 1)) = target_sum
    def f(lam):
        projected = np.clip(x + lam, 0, 1)
        return np.sum(projected) - target_sum

    a, b = -1.0, 1.0
    while f(a) * f(b) > 0:
        a -= 0.1
        b += 0.1

    tol = 1e-10
    for _ in range(50):
        m = (a + b) / 2
        fm = f(m)
        if abs(fm) < tol:
            break
        if fm * f(a) < 0:
            b = m
        else:
            a = m
    
    result = np.clip(x + (a + b)/2, 0, 1)
    return result
