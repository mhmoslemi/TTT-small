### 1.  Re‑formulation of the problem  

For a discretisation with `n` evenly spaced points (`dx = 2/n`) let  

```
h = (h0,…,h_{n‑1}) ,   0 ≤ h_i ≤ 1 ,   Σ_i h_i = n/2                (1)
```

Define for every integer shift `k∈{-(n‑1),…,(n‑1)}`  

```
C_k(h) = Σ_{i : 0≤i,i+k<n} h_i·(1‑h_{i+k})
       = Σ_i h_i  –  Σ_{i:0≤i,i+k<n} h_i·h_{i+k}                (2)
```

The quantity to be minimised is  

```
C5(h) = max_k C_k(h) = 1 – min_k  Σ_{i} h_i·h_{i+k}·dx .          (3)
```

Thus **maximising the minimal overlap**  

```
τ = min_k  Σ_i h_i·h_{i+k}                                         (4)
```  

is equivalent to minimising `C5 = 1 – τ·dx`.  The overlap terms are **bilinear** in the variables `h_i`.
