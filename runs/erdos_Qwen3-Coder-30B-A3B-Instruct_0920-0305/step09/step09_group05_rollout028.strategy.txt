### 1.  Core mathematical reformulation  

For a discretised step‑function  

```
h = (h0 , … , h_{n‑1})   ,  n = 120
0 ≤ h_i ≤ 1 ,    Σ_i h_i = n/2               (integral = 1)
```

let  

```
b_i = 1 – h_i .
```

The overlap integral for a shift `k∈{-(n‑1),…,n‑1}` is the linear correlation  

```
c_k(h) = Σ_{i=0}^{n‑1} h_i · b_{i+k}          (terms outside 0…n‑1 are omitted)
```

and the quantity we must minimise is  

```
C5(h) = max_k c_k(h) · dx ,     dx = 2/n .
```

Writing `c_k = S – Σ_i h_i h_{i+k}` with `S = Σ_i h_i = n/2` shows that minimising the
maximum overlap is equivalent to **maximising the smallest auto‑correlation**
`Σ_i h_i h_{i+k}` over all shifts.  The map  
`h ↦ c_k(h)` is a smooth quadratic function; the only non‑smoothness of the whole
problem comes from the outer `max`.

We therefore attack a *smooth surrogate* of the outer max and combine it with a
**global combinatorial search** on the binary (0/1) hyper‑cube, followed by a
**continuous refinement** that exploits the exact gradient of the surrogate.
This pipeline is fundamentally different from the earlier SLSQP‑only routine.

### 2.  Smooth max via the log‑sum‑exp (LSE) envelope  

For any `α>0`

```
F_α(h) = (1/α) · log Σ_k exp(α·c_k(h))
```

satisfies `max_k c_k ≤ F_α ≤ max_k c_k + (log(2n‑1))/α`.  
As `α→∞` the envelope converges to the true max, but for moderate `α` the
objective is **differentiable** and its gradient can be written in closed form.

Define the **weight vector**

```
w_k = exp(α·c_k) / Σ_j exp(α·c_j)   ,   Σ_k w_k = 1 .
```

The gradient of each `c_k` with respect to a component `h_i` is

```
∂c_k / ∂h_i = 1 – h_{i+k} – h_{i‑k}   (out‑of‑range indices give zero contribution)
```

Hence

```
∇F_α(h) = Σ_k w_k · (1 – h_{·+k} – h_{·‑k}) .
```

The constant term “1” appears in every component because the weights sum to one,
so the gradient can be assembled as  

```
g = 1·ones(n)
for each shift k with weight w_k:
        if k ≥ 0:
                g[0:n‑k]   -= w_k·h[k:]
                g[k:n]     -= w_k·h[:n‑k]
        else:
                s = –k
                g[s:n]     -= w_k·h[:n‑s]
                g[0:n‑s]   -= w_k·h[s:]
```

The loop runs over the `2n‑1` shifts; for `n=120` this is ≈ 14 000 elementary
operations – negligible compared with the FFT used to compute `c_k`.

### 3.  Exact projection onto the feasible set  

After any gradient step we must enforce  

```
0 ≤ h_i ≤ 1   and   Σ_i h_i = n/2 .
```

The feasible set is the intersection of a hyper‑plane with the unit cube.
The projection can be performed *exactly* by a one‑dimensional binary search on a
scalar λ:

```
y(λ)_i = clamp( x_i + λ , 0 , 1 )
choose λ such that Σ_i y(λ)_i = n/2 .
```

`Σ_i clamp(x_i+λ,0,1)` is monotone in λ, so a 30‑iteration bisection yields
machine‑precision satisfaction of the equality while never violating the box.
This operation is cheap (O(n)) and guarantees that every iterate stays feasible.

### 4.  Global discrete optimisation – a Genetic‑Annealing hybrid  

The most influential part of the search is the **global exploration of the
binary sub‑space** `{0,1}^n` with exactly `n/2` ones.  Binary vectors give the
largest possible product `h_i·h_{i+k}` for any shift, and the optimum of the
continuous problem is always at least as good as the binary optimum.  Therefore,
a strong binary seed can dramatically lower the final bound.

**Population‑based Genetic Algorithm (GA)**  
* **Encoding** – each individual is a bit‑string of length `n` with exactly
  `n/2` ones (enforced by construction).  
* **Fitness** – `‑max_k c_k(h)·dx` (the negative overlap; higher fitness = lower
  overlap).  The correlation vector `c` is obtained with a single FFT per
  individual.  
* **Selection** – tournament (size 3) to keep pressure while maintaining diversity.  
* **Crossover** – *balanced uniform crossover*: concatenate the two parents,
  then randomly select `n/2` positions to stay 1, fixing the cardinality.  
* **Mutation** – swap a randomly chosen 1 with a randomly chosen 0 (guarantees
  sum preservation). Mutation probability ≈ 0.2 per offspring.  
* **Elitism** – the best individual of the current generation is copied unchanged
  to the next generation.  
* **Population size** – 60 individuals.  
* **Generations** – run until a fixed fraction of the time budget (≈ 20 % of the
  total) has elapsed; for a 600 s budget this gives roughly 300 generations,
  which is easily affordable because each generation evaluates ≤ 60 FFTs
  (≈ 0.01 s per FFT).

The GA creates a **diverse pool of good binary patterns** and quickly drives the
population toward low overlap values.  The best binary individual found by the GA
is taken as the starting point for the next stage.

**Simulated Annealing (SA) polishing**  
The GA seed is further refined by a classical SA on the binary space:

* **Move** – swap a 1 with a 0 (preserving the sum).  
* **Energy** – the exact overlap `max_k c_k·dx`.  
* **Temperature schedule** – geometric cooling `T←γ·T` with `γ≈0.995`, starting
  from `T0` equal to a few percent of the initial energy spread.  
* **Acceptance** – always accept downhill moves; uphill moves are accepted with
  probability `exp(‑Δ/T)`.  
* **Stopping** – continue until the allotted SA budget (≈ 10 % of total time) is
  exhausted or no improvement occurs for several thousand iterations.

The result of SA is a **high‑quality binary vector** that is very close to the
continuous optimum.

### 5.  Continuous refinement – projected gradient descent on `F_α`  

The binary seed is turned into a **fractional vector** by adding a tiny
uniform perturbation (e.g. ±0.01) and projecting onto the feasible set.  
From this point we optimise the smooth surrogate `F_α`.

**Algorithmic skeleton**

```
h ← binary‑seed  (+ tiny noise) → feasible by projection
α ← α0 (≈ 2) ,   η ← η0 (≈ 0.25) ,   momentum m ← 0
repeat until time expires:
        c  ← correlation vector of h   (FFT,  O(n log n))
        w  ← softmax(α·c)               (stable log‑sum‑exp)
        g  ← gradient Σ_k w_k·∇c_k   (slice loop, O(n²))
        m  ← β·m + (1‑β)·g            (β≈0.9, Nesterov‑type momentum)
        h̃ ← h – η·m
        h  ← project( h̃ )             (box+sum projection)
        η  ← η·δ   (δ≈0.9995)           (slow decay)
        every L iterations:
                α ← min(α·ρ , α_max)   (ρ≈1.02, α_max≈30)
                evaluate true C5 = max(c)·dx; keep best overall
```

*The smoothing parameter `α` starts small so the landscape is gentle, allowing
the iterates to move across basins; it is increased gradually so that, at the
end, the algorithm is effectively minimising the true max.*  

All operations are vectorised; a single iteration costs roughly a few
micro‑seconds on a modern CPU, allowing **thousands of iterations per second**.
The projection step guarantees feasibility at every iteration, so the exact
bound can be evaluated after any number of steps.

### 6.  Final polishing – sub‑gradient on the true max  

When `α` reaches its maximum, the surrogate coincides with the true objective up
to a negligible additive term.  At this stage we switch to a **pure sub‑gradient
method** on the actual max:

* Identify the active set of shifts `K = {k | c_k = max c}`.  
* Assign uniform weight `w_k = 1/|K|` for `k∈K` and zero otherwise.  
* Compute the gradient `g = Σ_{k∈K} ∇c_k / |K|` using the same slicing routine.  
* Take a tiny projected step `h ← project( h – η_small·g )` (`η_small≈0.02`).  
* Perform a few dozen such steps (or until no improvement).

Because only the worst shifts influence the gradient, this stage removes the
last possible “plateaus’’ caused by the LSE smoothing and usually yields the
final best value.

### 7.  Optional MILP feasibility check (if time permits)

If the current best bound is `t`, we may attempt to *prove* a lower bound `t‑ε`
by solving a small mixed‑integer linear programme that enforces  

```
c_k(h) ≤ t‑ε   for all k
0 ≤ h_i ≤ 1 , Σ h_i = n/2 .
```

Bilinear products `h_i·h_{i+k}` are linearised with McCormick envelopes using
auxiliary binaries `z_{i,k}`:

```
z_{i,k} ≤ h_i ,   z_{i,k} ≤ h_{i+k}
z_{i,k} ≥ h_i + h_{i+k} – 1 .
```

Only the shifts that are close to the current worst value need to be kept in
the model, drastically reducing the number of auxiliary variables (≈ a few
hundred instead of 14 000).  A fast open‑source MILP solver (CBC, GLPK, or the
free GLOP/ECOS) can attempt this feasibility check within the remaining time.
If it succeeds, we replace the bound by `t‑ε`; otherwise we keep the current
solution.

### 9.  Expected failure modes & mitigations  

| Failure mode | Symptom | Counter‑measure |
|--------------|---------|-----------------|
| GA converges to a narrow region (loss of diversity) | Population fitness plateaus early | Increase mutation rate, use “crowding’’ replacement to keep diverse niches |
| SA gets trapped in a flat region | No improvement for many swaps | Occasionally perform a *large* move (swap two disjoint pairs) or raise temperature briefly (re‑annealing) |
| Gradient descent overshoots when `α` is large | `max c_k` suddenly rises | Implement back‑tracking: if after a step the exact max increases by > 10 %, halve `η` and retry |
| Projection fails to find λ (no sign change) | Binary search ends with `f(a)·f(b)>0` | Expand the interval `[a,b]` exponentially until opposite signs appear; the monotonicity guarantees eventual success |
| Numerical overflow in `exp(α·c)` for very large `α` | `inf` values appear | Use the stable LSE trick (`exp(α·c – max)`) and store weights in double precision |
| MILP becomes too large | Solver runs out of memory | Restrict the model to the *active* shifts only (those within a small margin of the current worst value) |
