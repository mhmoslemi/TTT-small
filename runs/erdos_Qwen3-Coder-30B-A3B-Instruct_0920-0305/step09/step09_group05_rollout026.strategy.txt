### 1. Mathematics & Objective Reformulation

For a discrete vector `h∈[0,1]^n` let  

```
b = 1 – h
c(k) = Σ_i h[i]·b[i+k]                     (k = –(n‑1)…(n‑1))
```

(`c(k)` is exactly the `np.correlate(h,b,mode='full')` entry).  
Define

```
S = Σ_i h[i] = n/2   (fixed)
c(k) = S – Σ_i h[i]·h[i+k]                (quadratic term)
```

Hence minimising `max_k c(k)` is equivalent to **maximising the smallest auto‑correlation** `Σ_i h[i]h[i+k]` over all shifts.  The quantity is a *max of quadratic functions* – non‑convex, but it admits a smooth upper bound

```
Fα(h) = (1/α)·log Σ_k exp(α·c(k))        (α>0)
```

`Fα → max_k c(k)` as `α → ∞`.  `Fα` is differentiable and its gradient is a weighted sum of the individual gradients

```
∇c(k)_i = 1 – h[i+k] – h[i–k]            (out‑of‑range terms are omitted)
∇Fα(h) = Σ_k w_k·∇c(k) ,   w_k = exp(α·c(k))/ Σ_j exp(α·c(j))
```

The constant part `+1` appears in every component because Σ_k w_k = 1.

The gradient can be evaluated in **O(n²)** operations by looping over the `2n‑1` shifts and using sliced vector updates (see the “Gradient implementation” box below).  With `n=120` this is only a few × 10⁴ elementary operations – negligible compared with an FFT‑based correlation.

### 3. Stage A – Genetic Algorithm on the Binary Hyper‑cube

1. **Encoding** – Each individual is a binary array of length `n` with exactly `n/2` ones.  The constraint is enforced by **repair**: after any genetic operator the array is edited by swapping random bits until the count of ones equals `n/2`.

2. **Population** – `pop_size = 60`.  Initialise:
   * Insert the supplied `initial_h_values` (rounded to 0/1 and repaired) as the first individual.
   * Fill the remainder with random permutations of `n/2` ones.

3. **Fitness** – `fit(ind) = – C5(ind)`.  `C5` is obtained by a single FFT correlation (`O(n log n)`).  Because the population is modest, the whole fitness evaluation per generation costs < 0.01 s.

4. **Selection** – *tournament selection* (size = 3) to pick parents.

5. **Crossover** – **Balanced uniform crossover**:
   * For each position, copy the bit from parent A with probability 0.5, otherwise from parent B.
   * After the naive crossover count the ones; if it differs from `n/2`, perform a minimal number of **swap‑repairs** (exchange a 1 with a 0) to restore the exact count.

6. **Mutation** – With probability `p_mut = 0.1` perform a **pair‑swap** (choose a random 1‑position and a random 0‑position and exchange them).  The mutation respects the sum automatically.

7. **Elitism** – Preserve the current best individual unchanged into the next generation.

8. **Termination** – Run for a fixed number of generations `G = floor( (budget_A) / (pop_size·cost_per_fitness) )`.  With `budget_A ≈ 130 s` and `cost_per_fitness ≈ 0.0008 s`, `G ≈ 2600`.  Early stop if no improvement for 300 generations.

9. **Result** – Keep the best binary individual `h_bin_best` and its `C5` value.

#### 5.2. Exact Projection onto `[0,1] ∩ { Σh = n/2 }`
The projection solves  

```
min ‖x – y‖²   s.t.   0 ≤ x ≤ 1 , Σ x = target
```

Solution: find a scalar `λ` such that `x_i = clamp(y_i + λ, 0, 1)` satisfies the sum.  
Because the function `φ(λ)= Σ clamp(y_i+λ,0,1) – target` is monotone, a **binary search** on `λ` converges in ≤ 30 iterations to machine precision (`1e‑12`).  This method respects the box at all times, is O(n log tol) and works for any `n`.

#### 5.3. Smoothed Objective and Gradient
* **Smoothing parameter** – start with `α₀ = 2.0`.  After every `L = 200` gradient steps increase `α ← min(α·ρ, α_max)` with `ρ = 1.02` and `α_max = 30.0`.  This anneals the surrogate from a very smooth landscape to a close approximation of the true max.
* **Gradient** – for a given `α` we compute:
  1. Correlation vector `c = compute_corr_fft(h)`.  (FFT of length `2n‑1`.)
  2. Weights `w_k = exp(α·c_k – max(α·c)) / Σ_j exp(α·c_j)`.  The subtraction of the max guarantees numerical stability.
  3. Initialise `g = np.ones(n)`.  For each shift `k` (index `idx = k + n‑1`) with weight `w`:
     * If `k ≥ 0`:
       * `g[:n‑k]  -= w * h[k:]`  
       * `g[k:]    -= w * h[:n‑k]`
     * If `k < 0` (let `s = –k`):
       * `g[s:]    -= w * h[:n‑s]`  
       * `g[:n‑s]  -= w * h[s:]`
  This implements `∇Fα = Σ_k w_k·(1 – h[i+k] – h[i‑k])` exactly.
* **Step direction** – Because we minimise `Fα`, the descent direction is `–g`.

* **Projection** – Apply the exact projection of §5.2 to `h̃`, obtaining `h_new`.
* **Acceptance** – Because the projection guarantees feasibility, we accept `h_new` unconditionally.
* **Best‑ever tracking** – After each iteration compute the *exact* max overlap
