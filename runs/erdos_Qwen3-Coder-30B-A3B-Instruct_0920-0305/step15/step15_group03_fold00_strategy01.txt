**1.  Core observation – rewrite the objective**

For a discretisation with `n` samples (`dx = 2/n`) let  

```
h = (h0,…,h_{n‑1}) ,          0 ≤ hi ≤ 1 ,    Σ hi = n/2 .
```

Define  

```
Fk(h) = dx· Σ_{i=0}^{n‑1‑k} hi·(1 – h_{i+k})      (k = 0,…,n‑1)
```

so that  

```
C5(h) = max_k Fk(h) .
```

Because Σ hi·dx = 1,  

```
Fk(h) = 1 – dx· Σ_{i} hi·h_{i+k} .
```

Thus minimising the maximum overlap is equivalent to maximising the *minimum* autocorrelation, but we stay with the max‑form because it yields a simple sub‑gradient.
