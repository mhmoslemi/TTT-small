**Goal**  
Find a step function `h` on `[0,2]` (discretised into `n` uniform samples) satisfying  

* `0 ≤ h[i] ≤ 1` for all `i`  
* `∑ h[i] * dx = 1`  (i.e. `∑ h[i] = n/2`)  

that minimises  

```
C5 = max_k ∫ h(x)·(1‑h(x+k)) dx
```

In the discrete world  

```
C5 = dx · max_{lag∈[-(n‑1), … , (n‑1)]}  corr_h_1mh[lag]
```

where `corr_h_1mh = np.correlate(h, 1‑h, mode='full')`.  
Smaller `C5` gives a tighter upper bound on the Erdős constant.

### 1. Core mathematical tools

1. **Fast evaluation** – `C5` is computed by a single FFT‑based correlation:
   * Pad both sequences to length `L = 2·n‑1`.
   * `corr = ifft( fft(h, L) * fft(1‑h, L) ).real`
   * `C5 = dx * max(corr)`.  
   This costs `O(L log L)` and is fast enough for thousands of evaluations per second.

2. **Projection onto the feasible set** – after any unconstrained update we must enforce both box constraints and the exact sum constraint.  
   Use the standard “water‑filling” / λ‑binary‑search projection:
   * Find λ such that `∑ clip(x + λ, 0, 1) = target_sum`.  
   * A simple bisection (≈ 50 iterations) converges to machine precision.

3. **Gradient of the active term** – let `k*` be a lag where the maximum of `corr_h_1mh` is attained (the “worst shift”).  
   For a given signed lag `k` the unscaled objective term is  

   ```
   f_k(h) = Σ_{i} h_i·(1‑h_{i+k})
   ```

   (indices out of the range [0,n‑1] are omitted).  
   Its gradient w.r.t. each component `h_j` is  

   ```
   g_j(k) =  (j in mass‑range ? 1 : 0)
            – (j in mass‑range ? h_{j+k} : 0)
            – (j‑k in range   ? h_{j‑k}   : 0)
   ```

   where “mass‑range” is `0 ≤ j ≤ n‑1‑|k|` for a positive lag and `|k| ≤ j ≤ n‑1` for a negative lag.  
   This can be assembled with two vectorised slice operations.

   The gradient points **upwards** (increasing `f_k`). Since we minimise `C5 = dx·max_k f_k`, we move **opposite** to the gradient of the worst shift:
   `h ← h – α·g(k*)`.
