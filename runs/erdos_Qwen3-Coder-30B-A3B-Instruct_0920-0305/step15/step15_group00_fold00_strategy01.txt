### 1. Problem Re‑formulation and Efficient Core Routines

* **Overlap vector** – for a given `h` (length `n`) define  

  ```
  total = np.cumsum(h)                     # cumulative sum
  sum_slice[k] = total[n‑1‑k]               # ∑_{i=0}^{n‑k‑1} h[i]
  corr = np.correlate(h, h, mode='full')[n‑1:]   # Σ h[i]·h[i+k] (zero‑padded)
  overlap[k] = sum_slice[k] - corr[k]      # before multiplying by dx
  C5(h) = dx * max(overlap)
  ```

  This is `O(n)` for the cumulative part and `O(n log n)` for the correlation (via FFT) – negligible for `n≤200`.

* **Sub‑gradient of the active shift** – let `k* = argmax overlap`.  
  For each index `i`

  ```
  g_i = 1_{i ≤ n‑1‑k*}
        - 1_{i ≤ n‑1‑k*}·h[i+k*]
        - 1_{i ≥ k*}·h[i‑k*] .
  ```

  This follows directly from differentiating  

  `overlap(k) = Σ_{i≤n‑k‑1} h[i] – Σ_{i≤n‑k‑1} h[i]·h[i+k]`.

  The gradient is obtained in `O(n)` by vectorised masking.

* **Projection onto the box‑simplex** – after a gradient step we must enforce  

  `0 ≤ h ≤ 1` and `∑h = n/2`.  
  The Euclidean projection solves  

  ```
  min ‖x‑v‖²   s.t.   ∑x = s,   0 ≤ x ≤ 1    (s = n/2)
  ```

  The solution is `x_i = clip(v_i – λ, 0, 1)` where the scalar `λ` is chosen so that the sum constraint holds.  
  Because the sum of clipped values is a monotone decreasing function of `λ`, a simple binary search (≈ 50 iterations) finds `λ` to machine precision. This operation is `O(n log ε)` and dominates neither the sub‑gradient loops nor the final polish.

* **Smooth max surrogate** – for polishing we replace the hard max by

  ```
  Φβ(h) = (1/β)·log( Σ_k exp( β·overlap[k] ) )
  ```

  When `β→∞`, `Φβ → max overlap`.  
  Its gradient is a weighted sum of the per‑shift gradients:

  ```
  w_k = exp(β·overlap[k]) / Σ_j exp(β·overlap[j])
  ∇Φβ = Σ_k w_k · g(k)                     (g(k) = sub‑gradient of shift k)
  ```

  This gradient is also `O(n²)` if computed naïvely, but because `g(k)` is essentially the same mask‑based expression as above we can obtain all `g(k)` in a single pass of `O(n²)` (still cheap for `n≤200`).
