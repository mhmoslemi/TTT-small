**Goal** – Produce a step‑function `h` on `[0,2]` (sampled on a uniform grid) with  
`∫_0^2 h = 1` and `0≤h≤1` that minimises  

\[
C_5=\max_{k\ge 0}\int_0^{2-k} h(x)\bigl(1-h(x+k)\bigr)\,dx .
\]

The discrete version (grid of `N` points, spacing `dx=2/N`) is  

\[
C_5(dx)=dx\;\max_{s\in\{0,\dots ,N-1\}}\; \sum_{i=0}^{N-1-s} h_i\bigl(1-h_{i+s}\bigr).
\]

Because `∑_i h_i = N/2` (the integral constraint) we can rewrite the inner term

\[
\sum_{i=0}^{N-1-s}h_i\bigl(1-h_{i+s}\bigr)
   =\underbrace{\sum_{i=0}^{N-1-s}h_i}_{A_s}
    -\underbrace{\sum_{i=0}^{N-1-s}h_i h_{i+s}}_{B_s}.
\]

`A_s` is a linear function of `h` while `B_s` is a *quadratic* term.  
The optimisation problem is therefore a **max‑min quadratic problem**.

The previous solution relied on generic continuous optimisation (DE, L‑BFGS‑B).  
Below is a *different* methodology that exploits the problem structure and
uses a **mixed‑integer linear programme (MILP)** to obtain an *exact* binary

All steps are designed to run well inside the 600 s budget.

### 1.  Reformulate as a max‑min binary problem

*Observation* – The optimal `h` is known (from the literature on the Erdős
minimum‑overlap problem) to be essentially binary: `h_i∈{0,1}` with exactly
`N/2` ones.  With binary variables the quadratic products become *new binary*
variables, allowing a linear description.

Introduce variables  

* `h_i ∈ {0,1}` – the step‑function values (size `N`).  
* `w_{i,s} ∈ {0,1}` for each shift `s∈{1,…,N‑1}` and each index `i`
  with `i+s<N`.  The intended meaning is  

  \[
  w_{i,s}=h_i\cdot h_{i+s}.
  \]

* `t  ∈ ℝ` – a lower bound on every autocorrelation sum `B_s`.

**Linearisation of the product**  
For every admissible pair `(i,s)` enforce the classic McCormick constraints

```
w_{i,s} ≤ h_i
w_{i,s} ≤ h_{i+s}
w_{i,s} ≥ h_i + h_{i+s} – 1
```

When `h_i` and `h_{i+s}` are binary these constraints force `w_{i,s}=h_i·h_{i+s}`.

**Link with the objective**  
For a given shift `s`

\[
B_s =\sum_{i=0}^{N-1-s} w_{i,s}.
\]

We wish to **maximise** the smallest `B_s`.  Introduce the epigraph variable `t`
and add, for each shift,

```
∑_{i=0}^{N-1-s} w_{i,s}  ≥  t .
```

Because the integral constraint fixes `∑ h_i = N/2`, the maximal overlap is

\[
C_5 = 1 - \frac{2}{N}\,t .
\]

Thus *maximising* `t` is exactly *minimising* `C_5`.

**Remaining linear constraints**

```
∑_{i=0}^{N-1} h_i = N/2            (integral constraint)
0 ≤ h_i ≤ 1     (box, already implied by binary type)
```

All constraints are linear; the problem is a pure MILP.

### 3.  Post‑processing – continuous polishing

The binary solution is often very close to the true optimum, but a final
continuous tweak can squeeze a few hundredths of a percent improvement.

1. **Interpret the binary `h` as a starting point for a smooth optimiser**.  
   Convert the binary vector into a real vector `ĥ` and keep the box constraint
   `0≤ĥ≤1` and the equality `∑ ĥ = N/2`.

2. **Smooth max surrogate** – Define

   \[
   F_{\beta}(ĥ)=\frac{1}{\beta}\log\!\Bigl(\sum_{s=0}^{N-1}
           \exp\!\bigl(\beta\,C_s(ĥ)\bigr)\Bigr),
   \]

   where `C_s(ĥ)=∑_{i=0}^{N-1-s} ĥ_i\bigl(1-ĥ_{i+s}\bigr)`.  
   For a large value of `β` (e.g. 20) `Fβ` is a differentiable approximation of
   `max_s C_s`.  Its gradient is a weighted sum of the individual gradients
   `∇C_s`, where the weight for shift `s` is proportional to `exp(β C_s)`.

3. **Projected gradient ascent on `t = 1 - (2/N)·Fβ`** –  
   * Compute `∇Fβ` analytically (each `∇C_s` is cheap: `∇C_s[i]=1` for
     `i< N‑s`, minus the partner values `ĥ_{i+s}` and `ĥ_{i‑s}`).  
   * Take a step `ĥ ← ĥ – α ∇Fβ` with an adaptive step size `α` (start
     `α≈0.05`, halve when the objective does not improve).  
   * **Projection** – after each step, enforce the box and the equality
     constraint by a *water‑filling* projection:
       - Clip to `[0,1]`.  
       - If the sum deviates from `N/2`, distribute the discrepancy uniformly
         over the interior (non‑bound) coordinates; repeat until the residual
         is < 1e‑12.

4. **Random perturbations** – Every few hundred iterations add a tiny uniform
   noise (`±0.02`) to all entries, re‑project, and keep the perturbation only if
   `C_5` improves.  This helps escape shallow plateaus.

5. **Termination** – Stop when the remaining wall‑clock time is < 5 s or when
   `C_5` has not improved for a predefined number of iterations (e.g. 2000).

The polishing stage is *extremely cheap* (each iteration needs a single FFT‑based
correlation – `O(N log N)`) and typically yields a reduction of `C_5` by a few
·10⁻⁴, enough to push the bound below the target 0.3807.
