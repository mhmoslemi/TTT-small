## 2. Phase A – Binary Simulated Annealing (≈30 % of time)

### 2.1. Representation
`h` is a **binary** array (`0` or `1`) with exactly `target_sum` ones.  Working in the binary space simplifies the feasibility check (the sum constraint is automatically preserved by any swap of a `1` with a `0`).

### 2.2. Move set
A single move = **swap** a randomly chosen `i` where `h[i]=1` with a randomly chosen `j` where `h[j]=0`.  
This keeps the Hamming weight unchanged and explores the combinatorial space efficiently.

### 2.3. Acceptance rule
* Compute `C5_new = evaluate(h_swapped)`.  
* Let `Δ = C5_new – C5_current`.

The temperature schedule is exponential:

```

T = T0 * (0.995 ** iteration)
```

The schedule is fast enough to let the algorithm escape local plateaux early on and freeze later.

### 2.4. Restarts & Diversity

`C5(h) = max_k f_k(h)` with  


## 4. Phase C – Targeted Local Fractional Moves (≈15 % of time)

Having a high‑quality continuous vector, we now perform *structured* local refinements that are cheaper than a full gradient step but can still reduce the maximal correlation.

Three move families are used repeatedly (randomly selected each iteration):

1. **Block‑redistribution** – pick a small block of consecutive indices (`len ∈ {2,3,4}`), compute the total mass `M = Σ block`.  Solve the tiny 1‑D convex problem  
   ```
   min  max_k  f_k( h with block variables )
   subject to   Σ block = M ,  0 ≤ block_i ≤ 1
   ```  
   (the problem is 1‑dimensional, so a simple line‑search on the block values suffices).  Replace the block entries with the optimal distribution.

2. **Smooth‑averaging** – choose an index `i` and replace its value by the average of its neighbours (`(h[i‑1]+h[i+1])/2`), then project.  This reduces abrupt jumps that often cause large local peaks in `C5`.

3. **Fractional swap** – pick a `1`‑type index `i` (value close to 1) and a `0`‑type index `j` (value close to 0) and shift a small δ (`δ ∈ {0.02,0.05}`) from `i` to `j`:  
   ```
   h_i ← clamp(h_i – δ, 0, 1)
   h_j ← clamp(h_j + δ, 0, 1)
   ```
   Followed by projection to enforce the exact sum.

Each trial is evaluated using the cheap FFT routine; the move is kept only if it reduces `C5`.  Run this loop until the rest of the budget is spent.

*Variables*


*Objective* – maximise `t` subject to `t ≤ Σ_i y_{i,i+k}` for each shift `k`.
