**Goal** – Find a step‑function h on [0,2] (discretised with n samples) that minimises  

\[
C_5(h)=\max_{0\le k\le n-1}\; \int_0^2 h(x)\bigl(1-h(x+k)\bigr)\,dx
      =\frac{2}{n}\,\max_{k}\;O_k(h),
\]

where  

\[
O_k(h)=\sum_{i=0}^{n-k-1}h_i-\sum_{i=0}^{n-k-1}h_i\,h_{i+k}
\qquad (h_i=h(x_i),\;x_i=i\frac{2}{n}).
\]

The constraints are  

* \(0\le h_i\le 1\) for all i,  
* \(\displaystyle\sum_{i=0}^{n-1}h_i=\frac n2\)   (because \(\int_0^2h=1\)).  

The current record C₅ ≈ 0.380975 was obtained with a generic SLSQP + DE pipeline.  
The new plan replaces the generic global optimiser by a **deterministic projected sub‑gradient / smoothed‑max descent**, followed by a **binary‑rounding + local swap** phase.  This approach directly attacks the min–max structure, exploits cheap O(n) gradient formulas and stays well within the 600 s budget.

### 1.   Discretisation and basic utilities  

1. **Choose n** – start with the supplied 120‑point grid (dx = 2/n).  
   A secondary pass with a larger grid (e.g. n = 150) is attempted only if time allows.  

2. **Correlation and prefix sums** – for any vector h  

   * `cum = np.cumsum(h)` (size n)  
   * `sum_slice[k] = cum[n‑1‑k]` gives \(\sum_{i=0}^{n-k-1}h_i\).  
   * `corr = np.correlate(h,h,mode='full')[n-1:]` gives the product term
     \(\sum_{i=0}^{n-k-1}h_i\,h_{i+k}\).  

   Hence  

   \[
   O_k(h)=\text{sum\_slice}[k]-\text{corr}[k],\qquad k=0,\dots,n-1 .
   \]

   Both `O` and `C5 = (2/n)*O.max()` are computed in **O(n)** time.

3. **Projection onto the feasible set** – after any tentative update v,
   we must enforce  

   \[
   0\le x_i\le 1,\qquad\sum_i x_i = \tfrac n2 .
   \]

   The projection is the solution of  

   \[
   x_i = \operatorname{clip}\bigl(v_i-\lambda,0,1\bigr),\qquad
   \sum_i x_i = \frac n2 .
   \]

   The scalar λ is found by a **bisection** (≈ 50 iterations) on the monotone
   function \(S(\lambda)=\sum_i\operatorname{clip}(v_i-\lambda,0,1)\).
   Initial bracketing uses \(\lambda_{\text{low}}=-2\), \(\lambda_{\text{high}}=+2\); the
   interval is widened automatically if the target sum is not bracketed.

   This yields a fast, fully vectorised O(n log ε) projection.

### 2.   Phase I – Projected sub‑gradient descent on the true max  

*Idea* – minimise \(\max_k O_k\) by repeatedly moving **away from the worst‑shift**
and projecting back onto the feasible set.

**Gradient of the active shift**  
Let \(k^\* = \arg\max_k O_k\).  
For each index i the sub‑gradient of \(O_{k^\*}\) is

\[
g_i=
\underbrace{\mathbf 1_{\,i\le n-1-k^\*}}_{\text{from the linear sum}}
\;-\;
\mathbf 1_{\,i\le n-1-k^\*}\,h_{i+k^\*}
\;-\;
\mathbf 1_{\,i\ge k^\*}\,h_{i-k^\*}.
\]

All three terms are obtained by simple Boolean masks; the whole vector g
is assembled in O(n) without Python loops.

**Update rule**  

\[
v^{(t+1)} = h^{(t)} - \alpha_t\,g^{(t)},
\qquad
h^{(t+1)} = \Pi_{\mathcal F}\bigl(v^{(t+1)}\bigr),
\]

where \(\Pi_{\mathcal F}\) denotes the projection of §1.3 and the stepsize follows
the classic diminishing schedule  

\[
\alpha_t = \frac{\alpha_0}{\sqrt{t+1}},\qquad
\alpha_0\in[0.1,0.5] .
\]

**Random perturbations** – every L iterations (e.g. L = 200) we add a tiny
uniform jitter \( \epsilon\sim\mathcal U[-\eta,\eta]\) (η≈10⁻³) before projection.
This helps the method escape flat plateaus.

**Multiple restarts** – the sub‑gradient loop is run from several
initial points:

* the supplied `initial_h_values` (projected once to satisfy the sum);
* a handful (≈ 4) of random feasible vectors (generated by sampling U(0,1) and projecting).

Each run executes up to T₁ iterations (≈ 3000) or stops early if the remaining
time drops below a safety margin (5 s).  The best (lowest) C₅ encountered is stored.

### 3.   Phase II – Smoothed‑max refinement (log‑sum‑exp)  

The sub‑gradient phase quickly reduces the worst‑shift; to obtain a finer
solution we replace the non‑smooth max by a **smooth approximation**

\[
f_{\beta}(h)=\frac{1}{\beta}\log\Bigl(\sum_{k=0}^{n-1}\exp\bigl(\beta\,O_k(h)\bigr)\Bigr),
\]

with \(\beta>0\).  As \(\beta\!\to\!\infty\), \(f_{\beta}\to\max_k O_k\).

**Gradient of the smoothed objective**  

\[
\nabla f_{\beta}(h)=\sum_{k=0}^{n-1} w_k(\beta)\,\nabla O_k(h),
\qquad
w_k(\beta)=\frac{\exp(\beta O_k)}{\sum_j\exp(\beta O_j)} .
\]

Each \(\nabla O_k\) has the same closed‑form as in §2 (replace the indicator for
the active shift by its generic expression).  Computing all \(\nabla O_k\) and
forming the weighted sum costs O(n²) in a naïve loop; however for n ≤ 150 this
is negligible, and a fully vectorised implementation (outer products of the
Boolean masks) keeps the wall‑time well under a second per iteration.

**Algorithm**  

* Initialise β = 1.0; α₀ = 0.2.  
* For a schedule β ← β·γ (γ≈2) run a few (≈ 200) projected gradient steps
  with stepsizes \(\alpha_t = \alpha_0 / \sqrt{t+1}\).  
* After each β‑stage, re‑evaluate the exact max‑overlap C₅; keep the best vector.
* Stop when β reaches a large value (β ≈ 40) or when the time budget is exhausted.

The smoothed phase benefits from the **compressed memory of the sub‑gradient
phase**, i.e. we start each β‑stage from the best point of the previous stage.

### 4.   Phase III – Binary rounding & combinatorial local optimisation  

Empirically the optimum for C₅ is attained by a **binary** step function
(0/1 values).  After Phase II we therefore produce a discrete candidate:

1. **Thresholding** – sort the entries of the current continuous solution,
   set the largest n/2 entries to 1 and the rest to 0; denote the resulting
   binary vector by b.

2. **Evaluation** – compute its exact C₅ (no smoothing).

3. **Greedy swap improvement** – while improvements are possible and time permits:

   * Randomly pick a pair (i ∈ support, j ∉ support).
   * Swap the bits (i.e., set b_i←0, b_j←1) and recompute C₅.
   * Accept the swap if C₅ decreases; otherwise revert.

   We keep a quick‑update of the overlap counts: swapping only modifies
   products involving indices i and j, so the full Oₖ array can be updated in
   O(n) per trial.  After ~10 000 successful swaps (or when no improving
   swap is found after a few hundred attempts) we stop.

4. **Simulated‑annealing fallback** – if the purely greedy search stalls,
   we occasionally accept a worsening swap with probability \(\exp(-\Delta/T)\),
   where Δ is the increase in C₅ and T is a temperature that decays geometrically.
   This allows exploration of a larger neighbourhood without exploding the
   runtime.

The binary phase frequently pushes the bound below the continuous optimum,
because the integral constraints force many entries to be close to 0 or 1.

### 5.   Phase IV – Optional small‑scale MILP verification  

If, after Phase III, the remaining time exceeds 30 s, we launch a **compact MILP**
with the same n (or a reduced n = 100 for speed) to certify that no better binary
solution exists in that discretisation.  The MILP formulation is:

* binary variables \(x_i\) (0/1), \(\sum_i x_i = n/2\);
* for each shift k, auxiliary binaries \(y_{i,k}\) representing \(x_i x_{i+k}\)
  with the McCormick constraints  

  \[
  y_{i,k}\le x_i,\; y_{i,k}\le x_{i+k},\;
  y_{i,k}\ge x_i+x_{i+k}-1 .
  \]

* continuous variable T ≥ 0 and constraints  

  \[
  \frac{2}{n}\Bigl(\sum_{i=0}^{n-k-1}x_i - \sum_{i=0}^{n-k-1}y_{i,k}\Bigr) \le T,
  \qquad\forall k .
  \]

* Objective minimise T.

The model contains ≤ n²/2 binary variables (≈ 7 500 for n = 120) and is
readily solved by the default “GLPK_MI” or “CBC” solvers within a few seconds.
If a better integer solution is found, it supersedes the current best.
