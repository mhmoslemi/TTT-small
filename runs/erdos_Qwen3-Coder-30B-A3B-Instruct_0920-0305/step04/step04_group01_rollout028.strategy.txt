**Overview**

The new method treats the Erdős overlap problem as a *convex feasibility* problem via a *rank‑1 lifting* into a semidefinite program (SDP).  By binary‑searching on the target value \(M\) (a candidate upper bound for \(C_{5}\)), we ask the SDP whether a step function \(h\) exists whose maximal overlap does not exceed \(M\).  The SDP is a linear programme in the lifted matrix variable, so each feasibility test is fast, provides a certificate, and can be solved with standard conic solvers.  After the binary search finishes we extract an explicit step function by *randomized rounding* of the SDP solution and optionally polish it with a light local optimiser.

The approach is mathematically distinct from the prior DE + SLSQP pipeline: it linearises the quadratic constraints, uses convex optimisation with rigorous bounds, and only afterwards applies a stochastic rounding step.

### 1. Discretisation

* Choose a modest but expressive grid size, e.g. **\(n = 100\)** (Δx = 2/100 = 0.02).  
* The discretised unknown is the vector \(\mathbf{h}\in[0,1]^{n}\) with the linear equality  

\[
\sum_{i=0}^{n-1} h_{i}= \frac{n}{2}.
\]

### 2. Lifting to a Matrix Variable

Define the rank‑1 Gram matrix  

\[
X = \mathbf{h}\,\mathbf{h}^{\!\top}\in\mathbb{R}^{n\times n},\qquad X\succeq0,\qquad \operatorname{rank}(X)=1.
\]

For any shift \(\ell\) (integer, \(-n+1\le \ell\le n-1\)) let \(S_{\ell}\) be the *shift matrix* with entries  

\[
(S_{\ell})_{ij}= \begin{cases}
1 &\text{if } j=i-\ell\text{ and both indices are in }[0,n-1],\\[4pt]
0 &\text{otherwise.}
\end{cases}
\]

Then the discrete autocorrelation at lag \(\ell\) is  

\[
A_{\ell}= \sum_{i} h_{i}h_{i-\ell}= \operatorname{tr}(S_{\ell}X).
\]

Because  

\[
C_{5}=\Delta x\;\Bigl(\frac{n}{2}-\min_{\ell}A_{\ell}\Bigr),
\]

the condition \(C_{5}\le M\) is **equivalent** to requiring every lag to satisfy  

\[
A_{\ell}\;\ge\;\frac{n}{2}-\frac{M}{\Delta x}\;\; \text{for all }\ell .
\tag{1}
\]

Thus the original non‑linear max‑over‑shifts becomes a **set of linear inequalities** in the lifted matrix.

---

### 3. SDP Formulation (Feasibility Test)

For a fixed candidate bound \(M\) define a constant  

\[
b(M)=\frac{n}{2}-\frac{M}{\Delta x}.
\]

We then ask: does there exist \((\mathbf{h},X)\) satisfying  

* **Box constraints** \(0\le h_{i}\le1\) for all \(i\).  
* **Sum constraint** \(\sum_i h_i = \tfrac{n}{2}\).  
* **Diagonal coupling** \(X_{ii}=h_i\) (linear, forces diagonal of \(X\) to equal the entries of \(\mathbf{h}\)).  
* **Positive semidefiniteness** \(X\succeq0\).  
* **Correlation lower bounds** \(\operatorname{tr}(S_{\ell}X)\ge b(M)\) for every \(\ell=0,\dots,n-1\) (symmetry makes negative lags redundant).  

All constraints are linear except the PSD cone, so this is a **convex feasibility SDP**.  The rank‑1 requirement is *dropped*; the SDP gives a *relaxation*.  If the relaxed problem is feasible, the original (non‑convex) problem may still be feasible, but we can extract a concrete \(h\) by rounding.

### 5. Randomized Rounding of the SDP Solution

When the binary search finishes, we have a feasible pair \((\mathbf{h}^{\star},X^{\star})\) with \(X^{\star}\succeq0\).  Usually \(X^{\star}\) will not be rank‑1.  To obtain an explicit step function:

1. Compute the eigen‑decomposition \(X^{\star}=V\Lambda V^{\!\top}\).  
2. For each of **\(R\) random trials (e.g. 200)**:  
   a. Sample a Gaussian vector \(\mathbf{g}\sim\mathcal N(0,I)\).  
   b. Form the candidate \(\tilde{\mathbf{h}} = V\Lambda^{1/2}\mathbf{g}\).  
   c. **Project** \(\tilde{\mathbf{h}}\) onto the feasible set:
      * Clip to \([0,1]\).  
      * Apply the *shift‑and‑clip* algorithm (see §8) to enforce \(\sum \tilde h_i = n/2\) exactly while preserving the box bounds.  
   d. Evaluate the true overlap bound \(C_{5}(\tilde{\mathbf{h}})\) with the fast FFT‑based correlation (see §7).  
   e. Keep the best trial (smallest \(C_{5}\)).

Because the SDP guarantees \(\operatorname{tr}(S_{\ell}X^{\star})\ge b(M)\), many random draws will inherit a large autocorrelation and therefore a low overlap; the best rounded vector is a valid constructive bound.

### 6. Fast Evaluation of \(C_{5}\) (FFT Correlation)

To evaluate a candidate \(\mathbf{h}\):

1. Form \( \mathbf{b}=1-\mathbf{h}\).  
2. Reverse \(\mathbf{h}\) → \(\mathbf{h}_{\text{rev}}\).  
3. Compute the convolution \(\mathbf{c}= \mathbf{h}_{\text{rev}} * \mathbf{b}\) using a real FFT of length \(L=2n-1\):  

   * FFT of \(\mathbf{h}_{\text{rev}}\) and \(\mathbf{b}\) (real‑FFT).  
   * Multiply pointwise, inverse real FFT to obtain \(\mathbf{c}\).  

4. The maximal overlap is \(\max(\mathbf{c})\).  
5. Return \(C_{5}= \Delta x \cdot \max(\mathbf{c})\).

The FFT approach is \(O(n\log n)\) and negligible even for millions of evaluations.

### 7. Projection onto the Box‑Sum Hyperplane

Given any vector \(\mathbf{y}\) (after clipping to \([0,1]\)), we need the nearest point \(\mathbf{h}\) that additionally satisfies \(\sum h_i = n/2\).  The exact projection is:

* Find a scalar \(\lambda\) such that  

  \[
  \sum_{i=0}^{n-1}\!\operatorname{clip}(y_i+\lambda,0,1)=\frac{n}{2}.
  \]

* The left‑hand side is a monotone function of \(\lambda\); locate its root by a binary search on \(\lambda\in[-1,1]\) (≈50 iterations).  
* Return \(\mathbf{h}= \operatorname{clip}(\mathbf{y}+\lambda,0,1)\).

This method respects both the box constraints and the equality exactly, is O(n), and can be called thousands of times without trouble.

### 8. Optional Local Polishing

The rounded vector \(\mathbf{h}_{\text{round}}\) may still be improvable.  Perform a short **projected subgradient descent**:

1. Compute the worst lag \(\ell^{\*}\) (index of the maximal correlation entry).  
2. Form the subgradient \(g_i = h_{i-\ell^{\*}} + h_{i+\ell^{\*}}\) (zero where the shifted index falls outside).  
3. Take a small step \(\mathbf{h} \gets \mathbf{h} - \eta\, \mathbf{g}\) with a diminishing step size \(\eta\) (e.g. \(\eta=10^{-2}\) then halve every 100 iterations).  
4. After each step, re‑project with the algorithm of §7.  
5. Stop after a few thousand iterations or when the improvement stalls.

Because the subgradient directly targets the lag that determines the max overlap, this polishing usually nudges the bound down a few 1e‑4, often enough to beat the previous record.
