### 1. Mathematical Reformulation  

For any shift `k`

```
∫ h(x)(1‑h(x+k)) dx = ∫ h(x) dx – ∫ h(x)h(x+k) dx = 1 – I(k)
```

where  

```
I(k) = ∫ h(x)h(x+k) dx   (autocorrelation of h)
```

Hence  

```
C5 = 1 – min_k I(k) .
```

The problem is equivalent to **maximising the smallest autocorrelation value** over all shifts. This insight suggests that shapes with a high, fairly uniform overlap with themselves for any shift will be optimal.

Because the domain and the integral are symmetric, the optimal `h` can be assumed *even* around the centre `x=1`. Enforcing symmetry halves the number of independent variables and dramatically simplifies the search.

### 2. Low‑dimensional Parametric Family  

We model `h` as a symmetric, piecewise‑linear function defined by a small set of parameters:

* `c`  – width of each outer ramp (0 ≤ c ≤ 1).  
* `a`  – plateau height, forced by the area constraint  

```
area = a·(2‑c) = 1   ⇒   a = 1 / (2‑c) .
```

The shape is  

```
for x ∈ [0,c]            : h(x) = a·x / c
for x ∈ [c, 2‑c]         : h(x) = a
for x ∈ [2‑c, 2]         : h(x) = a·(2‑x) / c
```

Only one free parameter (`c`) remains. This family includes:

* `c = 0` → constant height `a = 0.5` (the flat function).

### 5. Projection onto the Feasible Set  

When we move from the parametric family to a **full‑dimensional optimisation** (e.g. to fine‑tune the discrete values), we must enforce:

* `0 ≤ h[i] ≤ 1`
* `∑h[i] = n/2` (i.e. `∫h = 1`)

**Projection algorithm (water‑filling)**  

1. Clip the vector to `[0,1]`.  
2. Compute current sum `s`.  
3. If `s = target` stop.  
4. Let `Δ = target – s`.  
5. Identify the set `F` of free indices (those not at a bound).  
6. Distribute `Δ` uniformly over `F` (`h[F] += Δ / |F|`).  
7. Clip again and repeat until `|Δ|` is below a tiny tolerance (≤ 1e‑12).  

This projection is cheap (linear in `n`) and guarantees feasibility after each stochastic move.
