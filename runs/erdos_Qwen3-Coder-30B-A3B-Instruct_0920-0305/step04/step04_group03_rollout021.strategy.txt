def project_feasible(v, target):
    v = np.clip(v, 0, 1)
    s = v.sum()
    if np.isclose(s, target):
        return v
    # Determine indices that can be increased (v<1) or decreased (v>0).
    if s < target:
        # need to increase mass
        # compute amount to add equally to all free entries
        free = (v < 1 - 1e-12)
        while True:
            num = free.sum()
            if num == 0:
                break
            delta = (target - s) / num
            # add delta to free entries, but cap at 1
            add = np.minimum(delta, 1 - v[free])
            v[free] += add
            s = v.sum()
            # Update free set
            free = (v < 1 - 1e-12)
            if np.abs(target - s) < 1e-9:
                break
    else:
        # need to decrease mass
        free = (v > 1e-12)
        while True:
            num = free.sum()
            if num == 0:
                break
            delta = (s - target) / num
            sub = np.minimum(delta, v[free])
            v[free] -= sub
            s = v.sum()
            free = (v > 1e-12)
            if np.abs(target - s) < 1e-9:
                break
    return v

def project_feasible(v, target):
    # First clip to [0,1]
    v = np.clip(v, 0.0, 1.0)
    # Compute current sum
    s = v.sum()
    if np.isclose(s, target):
        return v
    # Determine direction
    if s < target:
        # need to add mass
        # Determine free indices where v < 1
        free = v < 1
        # While sum < target:
        while s < target - 1e-12:
            num_free = free.sum()
            if num_free == 0:
                break
            # allocate equally
            delta = (target - s) / num_free
            # Update
            add = np.minimum(delta, 1 - v[free])
            v[free] += add
            s = v.sum()
            free = v < 1 - 1e-12
    else:
        # need to reduce
        free = v > 0
        while s > target + 1e-12:
            num_free = free.sum()
            if num_free == 0:
                break
            delta = (s - target) / num_free
            sub = np.minimum(delta, v[free])
            v[free] -= sub
            s = v.sum()
            free = v > 1e-12
    # final small correction adjust small residual by scaling all within bounds
    # If still not close due to rounding, adjust uniformly
    if not np.isclose(v.sum(), target):
        diff = target - v.sum()
        # distribute diff equally among non-saturated entries
        free = (v > 0) & (v < 1)
        if free.any():
            v[free] += diff / free.sum()
            v = np.clip(v, 0, 1)
    return v

**1. Goal & Constraints**  
- Find a step function `h : [0,2] → [0,1]` (discretized on `n` points) with  
  \[
  \int_0^2 h(x)\,dx = 1 \qquad\Longleftrightarrow\qquad \sum_{i=0}^{n-1}h_i\,dx = 1,
  \]  
  where `dx = 2/n`.  
- Minimise the *overlap* constant  
  \[
  C_5(h)=\max_{k}\int_0^2 h(x)\bigl(1-h(x+k)\bigr)\,dx
        =\max_{s\in\{-n+1,\dots ,n-1\}} r_s\,dx,
  \]  
  where the discrete correlation vector is  
  \[
  r_s=\sum_{i=0}^{n-1} h_i\bigl(1-h_{i+s}\bigr),\qquad h_j=0\;\text{if}\;j\notin[0,n-1].
  \]  

**2. Choice of discretisation**  
- Use a moderate‑size grid `n = 200` (or `n = 256` to keep `n` a power of two).  
- With this grid `dx = 2/n` and the integral constraint becomes `∑h_i = n/2`.  
- `n≈200` gives a smooth enough approximation of the continuous problem while keeping every iteration cheap (O(n²) operations are still < 0.1 ms).

**3. Analytic gradient of the *smooth* max objective**  

The objective is a pointwise maximum, which is non‑differentiable.  
Replace the max by a *soft‑max* (log‑sum‑exp) with temperature `τ>0`:

\[
\Phi_\tau(h)=\tau\log\Bigl(\sum_{s} e^{r_s/τ}\Bigr).
\]

- Produce the weight vector  
  \[
  w_s=\frac{e^{r_s/τ}}{\sum_{t}e^{r_t/τ}},\qquad \sum_s w_s=1.
  \]

The derivative of `r_s` w.r.t. a component `h_l` (using zero padding) is

\[
\frac{\partial r_s}{\partial h_l}= (1-h_{l+s}) - h_{l-s}.
\]

Summing with the soft‑max weights gives the gradient of the smooth objective:

\[
\frac{\partial\Phi_\tau}{\partial h_l}
 =\sum_{s} w_s\bigl[ (1-h_{l+s})-h_{l-s}\bigr]
 =1-\sum_{s}w_s\bigl(h_{l+s}+h_{l-s}\bigr).
\]

Define the weight vector `w` of length `2n‑1` (index `s = j-(n‑1)`).
