### Phase 1 – Exact binary optimisation via mixed‑integer linear programming (MILP)

1. **Discretisation**  
   * Use the same grid size as the benchmark: `n = len(initial_h_values) = 42`.  
   * Let `dx = 2/n`.  The integral constraint becomes `∑_{i=0}^{n‑1} x_i = n/2 = 21`.

2. **Decision variables**  
   * `x_i ∈ {0,1}` – the binary step values (1 ↔ “on”, 0 ↔ “off”).  
   * For each non‑zero shift `d ∈ {-(n‑1),…, -1, 1,…, n‑1}` and for each index `i` such that `i+d` lies in the grid, introduce a binary auxiliary variable  
     `y_{i,d}` intended to represent the product `x_i·x_{i+d}`.

3. **Linearisation of the product** (McCormick “AND” constraints)  
   For every `y_{i,d}` add three linear constraints:
   ```
   y_{i,d} ≤ x_i
   y_{i,d} ≤ x_{i+d}
   y_{i,d} ≥ x_i + x_{i+d} – 1
   ```
   With binary `x` these constraints force `y_{i,d}=x_i·x_{i+d}`.

4. **Overlap count for a shift**  
   For a fixed shift `d ≠ 0`,

   N_d = \sum_i x_i \;-\; \sum_i y_{i,d}

### Phase 2 – Fractional refinement by smooth‑max projected gradient descent

The binary optimum provides a tight **integer** bound.  By allowing `h_i` to take values in `[0,1]` we can often lower the maximal overlap by a few thousandths.  This phase treats the problem as a smooth optimisation on the simplex.

1. **Objective (smoothed)**  
   The true objective is a maximum over shifts:
   \[
   C_{5}(h) = \max_{d\neq0} \;C_d(h),\qquad
   C_d(h)=\sum_i h_i - \sum_i h_i h_{i+d}.
   \]
   Replace the non‑smooth max with the **log‑sum‑exp** surrogate (soft‑max):
   \[
   \Phi_{\tau}(h) = \tau\log\!\Bigl(\sum_{d\neq0}
        \exp\!\bigl(C_d(h)/\tau\bigr)\Bigr),
   \]
   where the temperature `τ>0` controls smoothness.  As `τ→0`, `Φ_τ → max_d C_d`.

2. **Gradient of a single shift**  
   For a fixed shift `d`,
   \[
   \frac{\partial C_d}{\partial h_j}
        = 1 \;-\; \bigl(h_{j+d}\mathbf{1}_{j+d<n}
                     + h_{j-d}\mathbf{1}_{j-d\ge0}\bigr).
   \]
   The gradient of the surrogate is a convex combination of these:
   \[
   \nabla\Phi_{\tau}(h)=\sum_{d\neq0} w_d \,\nabla C_d(h),\qquad
   w_d = \frac{\exp(C_d/τ)}{\sum_{d'}\exp(C_{d'}/τ)} .
   \]

3. **Projection onto the feasible set**  
   After a gradient step `h ← h – α∇Φ_τ(h)`:
   * **Box projection** – clip each component to `[0,1]`.  
   * **Linear equality** – enforce `∑ h_i = n/2`.  This is a projection onto a simplex intersected with a box; a simple scaling works because all entries are non‑negative:
     \[
     h \leftarrow \frac{h}{\sum_i h_i}\;·\;\frac{n}{2}.
     \]
     If clipping creates zero entries, repeat clipping+scaling once more; with `n=42` this converges instantly.

4. **Step‑size selection (back‑tracking)**  
   * Initialise `α = 1.0`.  
   * Compute `Φ_τ(h_new)`.  
   * If `Φ_τ` does not decrease, set `α ← α/2` and retry (max 6 halvings).  
   * Accept the first successful `α`.

5. **Continuation (temperature schedule)**  
   * Start with a relatively large temperature, e.g. `τ₀ = 0.5`.  
   * Perform a fixed inner loop (≈ 200 projected gradient steps) at this temperature.  
   * Reduce the temperature geometrically, `τ ← τ/2`, and repeat the inner loop.  
   * Continue until `τ` reaches a tiny value (e.g. `τ = 1e‑4`).  At that stage the surrogate is essentially the original max, and the iterate `h` is a high‑quality approximation of a minimiser of `C₅`.

6. **Randomised restarts**  
   * To avoid local minima, after completing a full continuation schedule, perturb the current best vector:
     `h_pert = h + ε·Normal(0,σ²)` with `σ ≈ 0.02`.  
   * Clip, re‑project onto the simplex, and launch a new continuation from this perturbed start.  
   * Limit the number of restarts (e.g. 10–15) so that the total wall‑clock time remains well under the allotted budget.

7. **Final polishing (optional)**

   * Initialise from the current best `h`; this step removes any residual smoothing bias and yields a final `C₅` value that is as low as possible.
