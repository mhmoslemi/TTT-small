\[
C_5(h)=dx\;\max_{s\in\{-N+1,\dots ,N-1\}}\; \sum_{i}h_i\bigl(1-h_{i+s}\bigr) .

Because the sum of the entries is fixed
\[

\sum_i h_i\bigl(1-h_{i+s}\bigr)

**3.  Analytic gradient of the smooth surrogate**

\[

\[
\frac{\partial c_s}{\partial h_j}=h_{j+s}+h_{j-s},

with the convention that out‑of‑range indices contribute zero.

\[
w_s=\frac{\exp\!\bigl(-\beta\,c_s(h)\bigr)}{\sum_{t}\exp\!\bigl(-\beta\,c_t(h)\bigr)} .

Then the gradient of \(F_{\beta}\) is  

\[
\nabla F_{\beta}(h)
   =\sum_{s} w_s \, \bigl(-\frac{\partial c_s}{\partial h}\bigr)

Because the weight vector is *symmetric* (\(w_{-s}=w_{s}\)), the two shift‑summations are identical and we obtain a compact convolution form

where \(w\) is the weight vector (length \(2N-1\)), `*` denotes the linear convolution and the centre slice (`N‑1 … N‑1+N‑1`) selects the \(N\) components that correspond to the gradient entries.

**4.  Projection onto the feasible set**

After a gradient step we must enforce  

* box constraints \(0\le h_i\le 1\),  
* the linear equality \(\sum_i h_i = N/2\).

The projection can be performed in two stages:

1. **Clip** each component to the interval \([0,1]\).  
2. **Adjust the sum** while staying inside the box.  
   This is the classic *bounded‑simplex projection* (water‑filling).  
   Algorithm (converges in ≤ 3 passes):  

   * Compute the current sum `s`.  
   * If `s = target` we are done.  
   * Let `free = { i : 0 < h_i < 1 }`.  
   * Distribute the deficit/excess uniformly over `free`:  
     `h_i ← h_i + (target‑s)/|free|` for all `i∈free`.  
   * Clip again to \([0,1]\) and repeat until the sum matches the target (the clipping step reduces the set of free variables, guaranteeing termination).

This projection is exact, cheap, and preserves feasibility at every iteration.
