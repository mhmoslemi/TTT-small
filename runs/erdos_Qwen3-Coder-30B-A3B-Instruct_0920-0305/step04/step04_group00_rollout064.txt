### Strategy for Improving the C₅ Bound in the Erdős Minimum Overlap Problem

#### Overview
The problem aims to minimize the maximum overlap integral:
$$C_5 = \max_k \int h(x)(1 - h(x+k)) dx$$
over step functions $ h: [0, 2] \to [0, 1] $ subject to:
1. $ 0 \le h(x) \le 1 $
2. $ \int_0^2 h(x) dx = 1 $

This is reframed numerically as minimizing $ C_5 = \max_k f_k(h) $ where $ f_k(h) = \sum_i h_i (1 - h_{i+k}) \Delta x $ for discrete $ h $, and $ k $ varies over all valid shift indices.

We adopt a globally optimized, parametric shape approach using a carefully chosen ansatz. Given the dimensionality concerns and non-convexity, we aim for a compromise moving beyond previous stochastic approaches.

#### Algorithm and Methodology

**Step 1: Construct a Symmetric Decreasing Parametric Shape for h**

We propose constructing a piecewise linear function from a small number of parameters ($ p=4 $ to $ 6 $) that describes $ h(x) $. This shape is:

1. **Symmetric**: $ h(x) = h(2 - x) $
2. **Monotonic decreasing** toward the center: $ h(x) $ increases on $ [0,1] $ to peak, decreases on $ [1,2] $
3. **Parametrization Using 4-6 parameters**:
   - Peak height $ h_{\text{max}} $
   - Central plateau width $ w_{\text{plateau}} $
   - Slope of linear segments $ m $
   - Optional: asymmetry or overshoot control

From these parameters, we evaluate a vector of shape points via interpolation at regularly spaced sample positions (e.g., 200 points over [0,2]).

**Step 2: Discretization and Numerical Consistency**

We discretize the domain [0, 2] into $ n = 200 $ points. Define:
$$
h_{i} = h(x_i),\quad x_i = \frac{2i}{n},\quad i = 0, \dots, n-1.
$$

We validate the integral:
$$
\sum_{i=0}^{n-1} h_i \Delta x = 1 \quad \text{where } \Delta x = \frac{2}{n}
$$
If integrals = 1 exactly, proceed; otherwise scale with a global factor to enforce the constraint.

We ensure all $ h_i \in [0,1] $ via soft clipping after soft interpolation.

**Step 3: Objective Evaluation Utilizing Correlation**

The overlap integral:
$$
C_5 = \max_k f_k(h) = \max_k \sum_{i} h_i (1 - h_{i+k}) \Delta x
$$
This can be computed efficiently via `np.correlate` with mode='full', but use subset only where needed (limited shifts) as full shifts are expensive. Candidate shifts are limited.

To accelerate, we weight possible $ k $ values based on influence, often only the first ~20 shifts, suffice to capture essential behavior.

- Samples 32 candidates per generation across 6 parameters
- Performs crossover and mutation
- Is invariant to local conditions and objective smoothness

- $ w_{\text{plateau}} \in [0.05, 0.5] $

import numpy as np
from scipy.optimize import differential_evolution, minimize
from scipy.signal import correlate
import time

def interpolate_shape(params, n_points=200):
    """
    Construct a symmetric, monotonic decreasing shape h(x) from 4 parameters:
    - h_max: peak height (in [0.2, 0.9])
    - w_plateau: width of central plateau (in [0.05, 0.5])
    - slope: slope of arms (in [5, 25])
    - asymmetry: optional, adjust inner/outer slopes (-0.5 to 0.5)
    """
    h_max, w_plateau, slope, asymmetry = params
    
    x = np.linspace(0, 1, n_points//2 + 1)
    h = np.zeros(n_points)
    
    # For symmetric shape centered at x=1
    # Left part: increasing from 0 to h_max
    # Right part: decreasing from h_max to 0
    
    # Midpoint splits into [0, 1] according to plateau
    left_end = 0.5 - w_plateau/2
    right_end = 0.5 + w_plateau/2
    
    # Left slope
    m = slope + asymmetry
    for i in range(len(x)):
        xi = x[i]
        if xi <= left_end:
            # Linear increasing part
            h[i] = h_max * (xi / left_end)
        elif xi <= right_end:
            # Plateau
            h[i] = h_max
        else:
            # Linear decreasing part
            ratio = (xi - right_end) / (1 - right_end)
            h[i] = h_max * (1 - ratio)

    # Mirror to get full h(x) on [0, 2]
    h_full = np.zeros(n_points)
    for i in range(n_points//2):
        h_full[i] = h[i]
        h_full[n_points - 1 - i] = h[i]
    
    return h_full

def evaluate_c5_function(h):
    """Evaluate C5 constant for a step function h."""
    n = len(h)
    dx = 2.0 / n
    corr = correlate(h, 1 - h, mode="full")
    max_corr = np.max(corr)
    return max_corr * dx

def param_to_h(params):
    h_full = interpolate_shape(params)
    dx = 2.0 / len(h_full)
    integral = np.sum(h_full) * dx
    h_normalized = h_full * (1.0 / integral)
    h_clipped = np.clip(h_normalized, 0, 1)
    h_final = h_clipped
    integral_final = np.sum(h_final) * dx
    h_scaled = h_final * (1.0 / integral_final)
    h_scaled = np.clip(h_scaled, 0, 1)
    return h_scaled

def objective_func(params):
    h = param_to_h(params)
    return evaluate_c5_function(h)

def run(seed=42, budget_s=600, **kwargs):
    np.random.seed(seed)
    start_time = time.time()
    n_points = 200
    dx = 2.0 / n_points
    
    bounds = [
        (0.2, 0.9),    # h_max
        (0.05, 0.5),   # w_plateau
        (5, 25),       # slope
        (-0.5, 0.5)    # asymmetry
    ]

    # Run global optimization using Differential Evolution
    try:
        result_de = differential_evolution(
            objective_func,
            bounds,
            maxiter=100,
            popsize=32,
            seed=seed,
            strategy='best1bin',
            tol=1e-6,
            copybest=0
        )
        best_params = result_de.x
    except Exception as e:
        best_params = [0.5, 0.2, 10, 0.0]

    # Refine using local optimization
    try:
        result_l_bfgs = minimize(
            objective_func,
            best_params,
            method='L-BFGS-B',
            bounds=bounds,
            options={'maxiter': 300, 'ftol': 1e-12, 'gtol': 1e-12}
        )
        if result_l_bfgs.success:
            best_params = result_l_bfgs.x
    except Exception as e:
        pass

    # Construct final h
    h_final = param_to_h(best_params)
    c5_final = evaluate_c5_function(h_final)
    
    return (h_final.tolist(), c5_final, n_points)
