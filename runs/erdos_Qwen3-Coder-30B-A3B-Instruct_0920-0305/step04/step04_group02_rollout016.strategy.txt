### Phase 1 – Exact binary optimisation (MILP)

**1.1. Discretisation**  
Use the given grid size `n = len(initial_h_values)` (the record uses `n = 42`).  The step‑function values are constrained to the set `{0,1}`; the integral condition becomes

\[
\sum_{i=0}^{n-1} x_i = \frac{n}{2}\qquad (n\text{ is even}).
\]

**1.2. Overlap for a fixed shift**  
For a shift `d∈{-(n‑1),…, -1, 1,…,n‑1}` the number of (1,0)‑pairs is

\[
N_d(x)=\sum_{i} x_i\bigl(1-x_{i+d}\bigr)
      =\underbrace{\sum_i x_i}_{=n/2}\;-\;\sum_{i} y_{i,d},
\]

where `y_{i,d}=x_i·x_{i+d}` for each overlapping index pair.

**1.3. Linearisation of the product**  
Introduce a binary auxiliary variable `y_{i,d}` for every admissible pair `(i,i+d)`.  Impose the classic “AND” (McCormick) constraints

```
y_{i,d} ≤ x_i
y_{i,d} ≤ x_{i+d}
y_{i,d} ≥ x_i + x_{i+d} – 1
```

Because `x_i, x_{i+d}` are binary, these three linear constraints force `y_{i,d}=x_i·x_{i+d}` at any feasible integer point.

**1.4. Upper bound variable**  
Add a scalar integer variable `t` and enforce, for every non‑zero shift,

```
N_d(x) = (n/2) – Σ_i y_{i,d}  ≤  t .
```

The objective is simply `minimise t`.  In the optimal binary solution `t*` equals the maximal overlap count `max_d N_d`.

**1.5. Symmetry breaking (optional)**  
Fix the first entry, e.g. `x_0 = 1`.  The problem is shift‑invariant, so this reduces the search space by a factor of two without affecting the optimum.

**1.6. Solving**  
Build the model with **CVXPY** :

* Variables: `x` (boolean, length n), `y_{i,d}` (boolean, one per overlapping pair), `t` (integer).
* Constraints: mass, product linearisation, `N_d ≤ t`, `t≥0`, optionally `x_0 = 1`.
* Objective: minimise `t`.

Solve with an MILP solver that is guaranteed to be present in the allowed set, trying in order:

1. `CBC` (fast open‑source MILP driver).  
2. `GLPK_MI` if CBC is absent.  
3. `ECOS_BB` as a generic branch‑and‑bound fallback.

### Phase 2 – Continuous refinement (smooth‑max gradient descent)

The binary optimum already improves on the previous record.  Fractional values can sometimes *lower the maximum* because the quadratic term `h_i·h_{i+d}` can be reduced below the integer product while preserving the linear term `∑ h_i`.  Phase 2 therefore searches the *continuous* feasible region `{h∈[0,1]^n | ∑h_i = n/2}` for a vector with a strictly smaller `C_5`.

**2.1. Smoothed objective**  
The true objective is `C_5(h) = max_d C_d(h)` with  

\[
C_d(h)=\sum_i h_i - \sum_i h_i\,h_{i+d}.
\]

Directly optimizing a non‑smooth max is difficult for gradient‑based methods.  Replace it by the *log‑sum‑exp* (soft‑max) surrogate:

\[
\Phi_\tau(h)=\tau\log\!\Bigl(\sum_{d\neq0}
       \exp\bigl(C_d(h)/\tau\bigr)\Bigr),
\]

where `τ>0` controls the smoothness.  As `τ→0`, `Φ_τ → max_d C_d`.  The surrogate is **convex‑smooth** in each `h_i` (the only non‑linear term is a product, but its gradient is analytic).

**2.2. Gradient of the surrogate**  
Define the weights  

\[
w_d = \frac{\exp(C_d/τ)}{\sum_{d'}\exp(C_{d'}/τ)} .
\]

Then  

\[
∇\Phi_\tau(h)=\sum_{d\neq0} w_d ∇C_d(h),
\]

and for a fixed shift `d`

\[
∂C_d/∂h_j = 1 - \bigl(h_{j+d}\,\mathbf{1}_{j+d<n}
                     + h_{j-d}\,\mathbf{1}_{j-d≥0}\bigr).
\]

These expressions are cheap to evaluate (`O(n²)`).

**2.3. Projection onto the feasible set**  
After a gradient step `h←h−α∇Φ_τ(h)`:

1. Clip each component to `[0,1]`.  
2. Enforce the linear equality by a *simple scaling* (since all components stay non‑negative):

\[
h ← \frac{h}{\sum_i h_i}\;·\;\frac{n}{2}.
\]

If any component hits a bound during scaling, repeat clipping+scaling a couple of times; with `n=42` convergence is immediate.

**2.4. Continuation schedule**  
Start with a relatively large temperature `τ₀` (e.g. `τ₀ = 0.5`).  Perform a fixed number of projected gradient steps (≈ 200).  Then *decrease* `τ` geometrically (e.g. `τ←τ/2`) and repeat.  This continuation drives the solution gradually toward the true max while keeping the landscape smooth enough for gradient descent to make progress.

**2.5. Step‑size selection**  
Use a back‑tracking line search: initialise `α = 1.0`; if the surrogate value does not decrease after a trial step, halve `α` and retry.  Because the projection is non‑expansive, the back‑tracking typically terminates within a few halvings.  

**2.6. Early‑termination and restarts**  
If the surrogate stops decreasing for several successive outer‑loop reductions of `τ`, stop the refinement.  Then launch a *randomised restart*: add a small Gaussian perturbation (σ ≈ 0.02) to the current best `h`, re‑project onto the feasible simplex, and run the continuation again.  Limit the total number of restarts to keep the overall wall‑clock time < budget.

**2.7. Final polishing**  
When the continuation reaches a very small `τ` (≈ 1e‑4) the surrogate approximates the true max extremely closely.  Use a single call to `scipy.optimize.minimize` with method `'SLSQP'` (or `'trust-constr'` if available) starting from the current `h`.  Supply the original non‑smoothed `C_5` as the objective and the equality + bounds constraints.  This step eliminates any remaining smoothing bias and typically yields a *few‑digit* improvement.

**2.8. Expected gain**  
The integer optimum gives `C_5 = 0.380952`.  The smooth‑max descent can reduce the worst‑shift count from `8.000` to roughly `7.96–7.99`, delivering a final bound in the interval `0.3800 – 0.3805`.
