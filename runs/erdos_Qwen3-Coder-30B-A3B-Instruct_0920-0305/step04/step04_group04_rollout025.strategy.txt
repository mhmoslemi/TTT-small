\[
C_5=\max_k\int_0^{2-k}h(x)\bigl(1-h(x+k)\bigr)\,dx

```python

so for a binary vector `h∈{0,1}ⁿ`

corr[l] = Σ_i h[i] - Σ_i h[i]·h[i+l]          (overlapping indices only)

The term `Σ_i h[i]·h[i+l]` is the **self‑intersection count** of the set
`{i | h[i]=1}` at shift `l`.  
Consequently

A_l = number of 1‑entries in the overlapping part
S_l = number of coincident 1‑pairs at lag l
```

Minimising `C5` is therefore equivalent to **minimising the worst‑case loss

### 2. MILP formulation

All variables are defined on the integer grid `i = 0 … n‑1`.

| Symbol | Meaning | Type | Bounds |
|--------|----------|------|--------|
| `h_i` | step value at point *i* (0 or 1) | binary (`0 ≤ h_i ≤ 1`) |
| `p_{i,l}` | logical AND `h_i ∧ h_{i+l}` (product for lag `l>0`) | binary |
| `M` | worst‑case overlap count (integer) | integer, `M ≥ 0` |

**Logical AND (McCormick) constraints** – for every lag `l = 1 … n‑1`
and every `i = 0 … n‑l‑1` :

```
p_{i,l} ≤ h_i
p_{i,l} ≤ h_{i+l}
p_{i,l} ≥ h_i + h_{i+l} - 1
```

These three linear inequalities force `p_{i,l}=1` iff both `h_i` and `h_{i+l}`
are 1, otherwise `p_{i,l}=0`.

**Intersection counts for a given lag**  

```
S_l = Σ_{i=0}^{n-l-1} p_{i,l}
A_l^+ = Σ_{i=0}^{n-l-1} h_i                # overlap from the left side
A_l^- = Σ_{i=l}^{n-1}   h_i = (total_ones) - Σ_{i=0}^{l-1} h_i
```

(The two overlapping windows are symmetric, therefore the same `S_l` appears
in both directions.)

**Worst‑case overlap constraints** – for every non‑zero lag `l` we require

```
A_l^+ - S_l ≤ M
A_l^- - S_l ≤ M
```

Because `A_l - S_l` is exactly the raw (unscaled) overlap count for that lag,
constraining it by `M` guarantees `max_l (A_l - S_l) ≤ M`.

**Integral constraint**

```
Σ_i h_i = n/2          # exactly 21 ones for n=42
```

**Objective**

```
minimise M
```

All constraints are linear, the only integer (binary) variables are the `h`
and `p` variables, therefore the model is a pure MILP.
