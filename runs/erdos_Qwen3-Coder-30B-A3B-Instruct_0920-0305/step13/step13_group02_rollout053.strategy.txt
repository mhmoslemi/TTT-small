### 1. Core utilities (to be written once)

1. **Evaluation** – `evaluate_c5(h)`  
   * Use `np.correlate(h, 1-h, mode='full')` (C implementation, O(N²) with N≈120, negligible).

2. **Projection onto the feasible set** – `project(h_raw, target_sum)`  
   * First clip `h_raw` to `[0,1]`.  
   * If `∑clip ≠ target_sum`, perform a *water‑filling* projection:  
        – Sort the clipped values.  
        – Find a Lagrange multiplier `λ` so that `∑ clip(x_i + λ) = target_sum`.  
        – This can be done in O(N log N) by scanning the sorted list.  
   * The result satisfies both the box constraints and the exact sum.

3. **Correlation sub‑gradient** – `subgradient(h, worst_shifts)`  
   * For a particular shift `k≥0` the (non‑zero‑padded) term is  
        `c_k = Σ_{i=0}^{N-1‑k}  h[i]·(1‑h[i+k])`.

        ```
        ∂c_k/∂h[i] =  (1‑h[i+k])          if i ≤ N-1‑k
        ```

### 4. Binary exploitation (swap‑based local search)

**Swap‑based simulated annealing**

1. **State** – a binary vector `h`.  
2. **Neighbour move** – pick a random `i` with `h[i]=1` and a random `j` with `h[j]=0`; swap them (preserves the sum).  
3. **Evaluation** – `C5_new = evaluate_c5(h_swap)`.  
4. **Acceptance rule** – classic Metropolis:  
   * If `C5_new ≤ C5_current` accept.  
   * Else accept with probability `exp( -(C5_new‑C5_current)/T )`.  
5. **Temperature schedule** – start `T₀ = 1e‑2` (order of the expected improvement), multiply by `α_T = 0.995` each iteration, floor at `1e‑6`.  
6. **Greedy acceleration** – after every 1000 accepted moves, recompute the *worst shift* `k*`. For that `k*` construct the set of mismatching positions  

   ```
   M = { i | h[i]=1  and  i+k* < N and h[i+k*]=0 }
   ```

   and try *targeted swaps*: pick `i∈M` and a random `j` with `h[j]=0` that is **not** in `M`. Evaluate the swap; if it reduces `C5` accept immediately (deterministic improvement).  

7. **Tabu list** – keep the last 200 visited swaps; refuse a swap that would simply undo a recent move, which discourages cycles.

Run this binary annealing until the overall remaining time budget falls below ~5 % of the total. Keep the best binary vector `h_best_bin` encountered.
