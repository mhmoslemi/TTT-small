**1. Problem reformulation**

The objective is  

\[
C_5(h)=\max_{k}\;c_k(h),\qquad
c_k(h)=\int_{0}^{2}h(x)\bigl(1-h(x+k)\bigr)\,dx .
\]

Discretise the interval with `n` points (`n` will be fixed to 120 – a comfortable size for fast FFT‑based evaluation).  
Let  

* `h∈[0,1]^n` be the vector of values,  
* `dx = 2/n`, and  
* `S = n/2` (the required sum of the entries because ∫h=1).

Then  

\[
c_k(h)=dx\;\sum_{i=0}^{n-1}h_i\bigl(1-h_{i+k}\bigr),\qquad   
k\in\{-n+1,\dots ,n-1\},
\]

with out‑of‑range indices interpreted as zero.  
The optimisation problem is

\[
\min_{h\in[0,1]^n,\; \sum h_i=S}\; \max_k c_k(h).
\]

**2. Sub‑gradient description**

For a fixed shift `k≥0` the correlation can be written as a linear function of `h` and a bilinear term:

\[
c_k(h)=dx\Bigl(\sum_{i} h_i -\sum_{i} h_i h_{i+k}\Bigr).
\]

Only the bilinear term depends on the interaction of two components.  
When `k` is the *worst* shift (i.e. the one attaining the current maximum), the objective locally behaves like the linear functional  

\[
g^{(k)}_i=\partial_{h_i}c_k=
\begin{cases}
dx\;(1-h_{i+k}), & i+k<n,\\[4pt]
dx, & i+k\ge n .
\end{cases}
\]

If the worst shift is negative we obtain the symmetric expression using `h_{i-k}`.  
If several shifts tie for the maximum we can take an arbitrary convex combination of the corresponding gradients – this is a valid sub‑gradient of the max‑operator.

Hence a *sub‑gradient* of `C_5` at any `h` can be computed in **O(n)** time by:

1. compute the whole correlation vector with one FFT;  
2. locate the index (or indices) `k*` of the maximal entry;  
3. build the gradient using the formula above for those `k*`.

**3. Projection onto the feasible polytope**

The feasible set is the intersection of a hyper‑cube `[0,1]^n` with an affine hyper‑plane `∑h_i=S`.  
The Euclidean projection onto this set can be performed by the classic *water‑filling* (or “projection onto a simplex with upper bounds”) algorithm:

* Clip the vector to `[0,1]`.  
* If the sum is already `S`, we are done.  
* Otherwise sort the clipped values, find the Lagrange multiplier `λ` such that `∑clip(x_i+λ,0,1)=S`, and apply it.  

This operation is `O(n log n)` but with `n=120` it is negligible.
