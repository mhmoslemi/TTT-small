### 1.  Core mathematical reformulation  

*Discretisation* – Use `n = n_points = 120` grid points on `[0,2]`.  
`dx = 2.0 / n`.  The step‑function is a binary vector  

\[
h \in \{0,1\}^{n},\qquad \sum_{i=0}^{n-1} h_i = n/2 = 60 .
\]

For a lag \(\ell\in\{-n+1,\dots ,n-1\}\) the evaluator computes  

\[
I_\ell(h)=\sum_{i=0}^{n-1} h_i\bigl(1-h_{i+\ell}\bigr) ,
\]
zero‑padding the index `i+ℓ` outside `[0,n-1]`.  
The objective is  

\[
J(h)=\max_{\ell} I_\ell(h),\qquad 
C_{5}=dx\;J(h).
\]

Because  

\[
I_\ell(h)=\underbrace{\sum_i h_i}_{=60}
          -\underbrace{\sum_{i=0}^{n-\ell-1}h_i h_{i+\ell}}_{\displaystyle S_\ell},
\]

minimising `J` is equivalent to **maximising** the *minimum* auto‑correlation  

\[
\delta \;=\; \min_{\ell} S_\ell .
\]

If we can obtain a large \(\delta\) we obtain a small bound  

\[
C_{5}=1-\delta\;dx .
\]

### 2.  Semidefinite programming (SDP) relaxation  

Introduce the symmetric matrix  

\[
X = h\,h^{\!\top}\in\mathbb{R}^{n\times n}.
\]

If \(h\) were binary, then  

* \(X\succeq0\) and \(\operatorname{rank}(X)=1\);  
* the diagonal entries satisfy \(X_{ii}=h_i\in\{0,1\}\);  
* for any lag \(\ell\),

\[
S_\ell = \sum_{i=0}^{n-\ell-1} X_{i,i+\ell}
       = \operatorname{tr}(T_\ell X),
\]

where \(T_\ell\) is the Toeplitz matrix that has ones on the \(\ell\)‑th
super‑diagonal (and zero elsewhere).  Thus each auto‑correlation is a **linear**
function of \(X\).

Relax the rank‑1 and integrality constraints and keep only the convex
constraints:

* **PSD**: \(X\succeq0\).  
* **Diagonal equals the marginal**: \(X_{ii}=v_i\) with a new vector
  \(v\in[0,1]^n\).  
* **Mass constraint**: \(\sum_i v_i = n/2\).  
* **Lag constraints**: for every lag \(\ell\) in a chosen set \(\mathcal L\),

\[
\operatorname{tr}(T_\ell X)\;\ge\;\delta .
\]

* **Box on diagonals**: \(0\le v_i\le 1\).

The SDP becomes  

\[
\begin{aligned}
\max_{X,v,\delta}\;&\delta\\[2mm]
\text{s.t. }& X\succeq0,\\
            & X_{ii}=v_i,\quad i=0,\dots ,n-1,\\
            & 0\le v_i\le1,\\
            & \sum_i v_i = n/2,\\
            & \operatorname{tr}(T_\ell X)\ge\delta,\qquad\forall\ell\in\mathcal L .
\end{aligned}
\]

The objective \(\delta\) is exactly the smallest overlap we are trying to
push up.  The bound that follows is  

\[
C_{5}\le 1-\delta\;dx .
\]

### 5.  From the relaxed solution to a binary step function  

The matrix `X*` is PSD and its diagonal `v_i = X*_{ii}` can be interpreted
as **marginal probabilities** that point `i` belongs to the set.  To obtain
a feasible binary vector we employ **spectral/randomised rounding**:

1. **Cholesky / eigen‑decomposition** – Compute a factor `L`
   (`X* = L Lᵀ`).  (`L` is `n×r` with `r` the rank of `X*`; in practice
   `r` is modest because the SDP pushes the solution toward rank 1.)  
2. **Gaussian sampling** – Draw a vector `g ~ N(0, X*)` by `g = L·z`,
   where `z ~ N(0, I_r)`.  
3. **Thresholding** – Sort the entries of `g`.  Choose a threshold `τ`
   so that exactly `n/2` of the components are ≥ `τ`; set those positions
   to `1`, the rest to `0`.  This yields a binary vector `ĥ` that respects
   the weight constraint by construction.  
4. **Multiple trials** – Repeat the sampling 30–50 times and keep the
   vector with the smallest `C5` (evaluated with a single FFT‑correlation).

If the diagonal entries are already very close to `0` or `1`,
the deterministic rounding `ĥ_i = 1` for the largest `v_i` also works
and is much cheaper; we keep it as a fallback.

### 6.  Polishing the rounded solution (purely combinatorial)

The rounded vector is very good, but the SDP relaxation may leave a small
integrality gap.  A **fast greedy local search** finishes the job:

* Pre‑compute the full correlation `I = correlate(ĥ, 1‑ĥ, mode='full')`.  
* While the current maximum `max(I)` exceeds the target `M_target`
  (`M_target = floor(0.3807/dx) = 22`) and time permits:
  * Identify the lag `ℓ* = argmax(I)`.  
  * Collect the “bad” indices  
    `B = { i | i+ℓ* < n, ĥ[i]=1, ĥ[i+ℓ*]=0 }`.  
  * Pick a random `i∈B`.  
  * Choose a zero position `j` such that the swap does **not**
    create a new bad pair for the same lag, i.e.  
    `j+ℓ* ≥ n` **or** `ĥ[j+ℓ*]=1`.  
  * Swap `ĥ[i] ↔ ĥ[j]` (keeps the total number of ones).  
  * Update `I` with a cheap FFT (cost `O(n log n)`).  
  * Keep the best vector seen.

Because each successful swap removes at least one contribution to the
worst lag, the algorithm is monotone and typically drives `max(I)` from

budget).  If the greedy phase stalls, a short **simulated‑annealing**
