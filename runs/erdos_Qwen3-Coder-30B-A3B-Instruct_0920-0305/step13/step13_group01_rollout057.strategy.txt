**Goal**  
Find a step‑function `h : [0,2] → [0,1]` (represented by `n` uniformly spaced samples) that minimises  

\[
C_5(h)=\max_{k\in\{-n+1,\dots ,n-1\}}\int_0^2 h(x)\bigl(1-h(x+k\,dx)\bigr)\,dx
     =dx\;\max_{k}{\rm Corr}_k(h,1-h),
\]

subject to  

* box constraints `0 ≤ h[i] ≤ 1`,  
* “area’’ constraint `∑_i h[i] = n/2`  (because the step length is `dx = 2/n`).

The current best bound (obtained by a differential‑evolution / simulated‑annealing pipeline) is `C_5≈0.380975`.  
The strategy below is **substantially different**: it formulates a *smooth* surrogate of the max‑operator, uses an explicit analytic gradient, and solves a sequence of *continuation* problems with a constrained optimiser (SLSQP / trust‑region). The idea is to obtain a high‑quality local optimum, then polish it with a cheap discrete local‑search.

### 2. Smooth max‑approximation (log‑sum‑exp)

For any scalar `α>0` define  

\[
\Phi_\alpha(h)=\frac{dx}{\alpha}\,\log\Bigl(\sum_{k} \exp\bigl(\alpha\, S_k(h)\bigr)\Bigr),\qquad
S_k(h)=\sum_{i}h_i\bigl(1-h_{i+k}\bigr),
\]

where the sum over `k` runs over all integer shifts (`k = -(n‑1)…(n‑1)`).  
*When α→∞,  Φₐ → C₅.*  

**Gradient** – For the weight vector  

\[
w_k = \frac{\exp(\alpha S_k)}{\sum_j \exp(\alpha S_j)}\;,
\]

the derivative of each `S_k` w.r.t. `h` is  

\[
\nabla_h S_k[i] = 1 \;-\; h_{i+k} \;-\; h_{i-k},
\]

where out‑of‑range indices contribute 0. Hence  

\[
\nabla_h \Phi_\alpha = dx\;\sum_{k} w_k \,\bigl( {\bf 1} - \operatorname{shift}_{+k}(h) - \operatorname{shift}_{-k}(h) \bigr).
\]

The shifts can be realised with simple slices; because only a handful of weights are appreciable for large α, the cost is O(n·|active k|).

For each level we minimise `Φ_α(h)` subject to the box and sum constraints, **initialising the optimiser with the solution from the previous level**. The sequence forces the algorithm to first move into the basin of a good basin (low‑α) and then to refine the exact max (high‑α).

### 4. Constrained optimisation at a fixed α  

For a fixed `α` we solve  

\[
\min_{h\in[0,1]^n,\;\sum h = target}\; \Phi_\alpha(h).
\]

Two solvers in SciPy can handle the required constraints:

* **SLSQP** – accepts bound constraints and an *equality* constraint (`∑h‑target = 0`).  
* **trust‑constr** – works with bounds, linear equality constraints and can make use of the supplied gradient.

Both accept a callable gradient; we supply the analytic `∇Φ_α` derived above.  
Key practical points:

* **Bounds**: `0 ≤ h ≤ 1` are given directly to the optimiser.  
* **Equality**: `fun = lambda h: np.sum(h) - target`, `jac = lambda h: np.ones_like(h)`.  
* **Stopping criteria**: tolerance on the objective (`1e‑9`) and on the gradient norm.  
* **Maximum iterations per level**: about `200` – enough for convergence given the modest dimension.

Because the optimiser works with the smooth surrogate, the variables never leave the feasible box, and the equality constraint is enforced to machine precision. No separate projection step is needed inside the optimiser (the optimiser itself respects the constraints).

### 6. Optional fine‑grained polishing (discrete local search)

After the continuation finishes, we have a high‑quality continuous vector `h*`.  
We now perform a **cheap greedy local search** that respects the constraints exactly:

1. **Swap move** – pick two indices `i≠j`, exchange their values, then re‑project onto the sum‑box (the swap already preserves the sum, so projection only clips to `[0,1]`).  
2. **Small‑mass transfer** – pick `i,j`, transfer a tiny amount `δ` from `h[i]` to `h[j]` (keeping both inside `[0,1]`).  
3. Accept the move **iff** the exact `C₅` (computed by `np.correlate`) does not increase; otherwise reject.  

Perform a fixed budget of `≈3000` such attempts (or stop early if no improvement for a few hundred steps). Because each evaluation uses the exact correlation on a 240‑point vector, it is cheap (`≈5·10⁴` multiplications) and can be done thousands of times within the remaining time.
