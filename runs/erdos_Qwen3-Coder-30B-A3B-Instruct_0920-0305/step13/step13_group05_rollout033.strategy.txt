\[
\min_{h\in[0,1]^N,\;\sum h_i=N/2}
\;F(h)\;,\qquad 
F(h)=\max_{k\in\{-N+1,\dots,N-1\}}
\;C_k(h)
\]

with  

\[
C_k(h)=\sum_{i}\;h_i\bigl(1-h_{i+k}\bigr)  \qquad
(\text{out‑of‑range indices are ignored}).
\]

The equality \(\sum h_i=N/2\) (so that \(\int_0^2h=1\)) and the box constraints are the only feasibility requirements.  
The constant we finally report is  

\[
C_5 = \frac{2}{N}\;\max_k C_k(h) .

### 1. Exact sub‑gradient of a single shift

For a fixed integer shift \(k\) (positive, negative or zero) the correlation term is  

\[
C_k(h)=\sum_{i=0}^{N-1-k} h_i\,(1-h_{i+k})\quad (k\ge 0),
\]
\[
C_{-k}(h)=\sum_{i=k}^{N-1} h_i\,(1-h_{i-k})\quad (k>0).
\]

The gradient \(\nabla C_k\in\mathbb R^N\) is sparse and has a closed form:

*If \(k\ge 0\)*  

```
∂C_k/∂h_i = (1 - h_{i+k})          for i = 0,…,N-1‑k
∂C_k/∂h_i = -h_{i‑k}               for i = k,…,N‑1
∂C_k/∂h_i = 0                      otherwise
```

*If \(k<0\) (let t = –k > 0)*  

```
∂C_{‑t}/∂h_i = (1 - h_{i‑t})        for i = t,…,N‑1
∂C_{‑t}/∂h_i = -h_{i+t}            for i = 0,…,N‑1‑t
```

All other components are zero.  These formulas are cheap to evaluate with NumPy slices.

### 2. Smooth approximation of the max

Instead of the non‑differentiable \(\max_k C_k\) we use the **log‑sum‑exp** (soft‑max)

\[
\Phi_\gamma(h)=\frac{1}{\gamma}\log\Bigl(\sum_{k}e^{\gamma C_k(h)}\Bigr) .
\]

When \(\gamma\to\infty\) this converges to \(\max_k C_k\).  The gradient is

\[
\nabla\Phi_\gamma(h)=\sum_k \omega_k(h)\,\nabla C_k(h) ,
\qquad 
\omega_k(h)=\frac{e^{\gamma C_k(h)}}{\sum_j e^{\gamma C_j(h)}} .
\]

Thus we obtain a **smooth weighted sum of the exact shift gradients**.  The weights are a probability distribution that automatically focuses on the worst shifts as \(\gamma\) grows.

### 3. Projection onto the feasible set

After each gradient step we must return to  

\[
\mathcal{X}= \{h\in\mathbb R^N\mid 0\le h_i\le1,\;\sum_i h_i = N/2\}.
\]

The projection can be performed with a *water‑filling* (a.k.a. capped‑simplex) routine:

1. Shift the vector by a scalar \(\lambda\): \(z_i = \operatorname{clip}(x_i+\lambda,0,1)\).  
2. Choose \(\lambda\) such that \(\sum_i z_i = N/2\).  
   The function \(g(\lambda)=\sum_i \operatorname{clip}(x_i+\lambda,0,1)\) is monotone, so a short binary search (≈30 iterations) finds \(\lambda\) to machine precision.

The routine runs in \(\mathcal O(N)\) and is reused at every iteration.

### 4. Primal–dual saddle‑point scheme

The original objective can be written as a minimisation of a pointwise maximum, i.e.

\[
\min_{h\in\mathcal X}\;\max_{k} C_k(h)
      = \min_{h\in\mathcal X}\;\max_{w\in\Delta}\;\sum_k w_k C_k(h),
\]
where \(\Delta\) is the simplex of length \(2N-1\).

We solve this **min‑max** problem by alternating updates:

| Variable | Update rule | Interpretation |
|----------|-------------|----------------|
| **h** (primal) | \(h^{t+1}= \Pi_{\mathcal X}\bigl( h^t - \alpha_t \,\nabla_h\!\bigl(\!\sum_k w^t_k C_k(h^t)\!\bigr)\bigr)\) | Projected (sub‑)gradient descent on the weighted sum of shifts. |
| **w** (dual) | \(w^{t+1}_k \propto w^t_k\; \exp\bigl(\beta_t\, C_k(h^{t+1})\bigr)\)  (followed by normalisation) | Exponential‑weights ascent on the simplex – increases the probability of the most offending shifts. |

*Why this works* – The pair of updates is a standard mirror‑prox / extragradient scheme for convex–concave saddle points.  In our setting the primal sub‑problem is non‑convex, but the scheme still provides a powerful guided descent because the dual distribution concentrates on the currently largest correlations.

**Parameter schedules**

*Stepsizes*:  
\[
\alpha_t = \frac{\alpha_0}{\sqrt{t+1}},\qquad
\beta_t  = \frac{\beta_0}{\sqrt{t+1}}.
\]

Typical values (found empirically on the 120‑point problem) are  
\(\alpha_0 = 0.5\) and \(\beta_0 = 0.3\).

*Soft‑max temperature*: we start with a modest \(\gamma_0=0.5\) and multiply by \(1.03\) every 200 iterations, capping at \(\gamma_{\max}=30\).  When \(\gamma\) is small the gradient is smooth (good for early exploration); when it becomes large the algorithm behaves like the pure max‑subgradient method (fine‑tuning).

**Algorithm skeleton**

### 7. Failure modes & mitigations

1. **Stagnation** – If the dual distribution collapses onto a single shift too early, the algorithm may stop improving other shifts.  
   *Mitigation*: cap the maximal weight (`w_k ≤ 0.5`) and/or add a small entropy regulariser to the dual update (multiply by `exp(β_t*C_k)`, then blend with uniform distribution).

2. **Projection overflow** – The binary‑search for the water‑level may occasionally diverge if the input vector is far outside \([0,1]\).  
   *Mitigation*: clip the vector to a slightly larger interval (e.g. `[-0.1, 1.1]`) before the binary search; the clipping guarantees the root exists.

3. **Too large \(\gamma\) too early** – The soft‑max becomes a hard max before the primal variable has moved enough, leading to noisy sub‑gradients.  
   *Mitigation*: enforce a minimum number of iterations (e.g. 500) before any increase of \(\gamma\).

4. **Excessive binary‑swap time** – The final local swaps could consume the remaining budget.  
   *Mitigation*: bound the number of swap attempts by the remaining time; stop early if no improvement for several hundred attempts.
