### 1.  Reformulation with a smooth approximation of the max

For a fixed vector h, let  

 cₖ(h) = ∑ᵢ hᵢ (1 − hᵢ₊ₖ)  (k = –(n‑1)…+(n‑1))

Replace it by the **log‑sum‑exp** (soft‑max) :

 f_β(h) =  (1/β) log ∑ₖ exp(β cₖ(h))  (β > 0).

When β→∞, f_β → maxₖ cₖ, while for moderate β the function is smooth and has a simple gradient.

### 2.  Analytic gradient of the smoothed objective

Define the weight of shift k:

 wₖ = exp(β cₖ) / ∑ⱼ exp(β cⱼ)  (∑ₖ wₖ = 1).

The derivative of a single term cₖ w.r.t. hᵢ is

```
∂cₖ/∂hᵢ = 1 − (hᵢ₊ₖ  +  hᵢ₋ₖ)      (out‑of‑range entries are treated as 0)
```

Hence the gradient of the soft‑max is a weighted sum:

```
∂f_β/∂hᵢ = Σₖ wₖ·∂cₖ/∂hᵢ
        = 1 − Σₖ wₖ·(hᵢ₊ₖ + hᵢ₋ₖ)

```

Thus the whole gradient vector can be obtained in **O(n log n)** by a single convolution of the current h with the weight vector w (which lives on the same index set as the full correlation).

### 3.  Projection onto the feasible set

After a gradient step we must enforce both box constraints [0,1] and the exact sum ∑ hᵢ = n/2.

The projection is a **water‑filling (box‑constrained simplex) operation**:

1.  Shift the vector by a scalar λ :  xᵢ = hᵢ − λ.  
2.  Clip:  yᵢ = min(1, max(0, xᵢ)).  
3.  Choose λ such that ∑ yᵢ = target = n/2.  

Because the mapping λ ↦ ∑ yᵢ is monotone, λ can be found by a short bisection (≈30 iterations) on the interval [‑1, 1].  This projection is cheap and guarantees feasibility after every update.
