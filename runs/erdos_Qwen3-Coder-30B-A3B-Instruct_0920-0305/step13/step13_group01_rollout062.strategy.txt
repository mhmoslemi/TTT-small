### 1.  Problem Recap
We must construct a step‑function `h` on `[0,2]` (discretised to `n` equally spaced points) such that  

\[
h_i\in[0,1],\qquad \sum_{i=0}^{n-1} h_i = \frac{n}{2},
\]

and the **Erdős overlap constant**

\[
C_5(h)=\max_{k}\; \int_{0}^{2} h(x)\bigl(1-h(x+k)\bigr)\,dx
\]

is as small as possible.  After discretisation, with `dx = 2/n`,

\[
C_5(h)=dx\;\max_{k\in\{-n+1,\dots,n-1\}} 
\underbrace{\sum_{i}\;h_i\bigl(1-h_{i+k}\bigr)}_{\displaystyle S_k(h)} .
\]

The task therefore is a **min–max** problem with a simple box‑plus‑sum constraint.

---

### 2.  Mathematical Reformulation
Write  

\[
S_k(h)=\sum_i h_i - \sum_i h_i\,h_{i+k}
      =\frac{n}{2} - \sum_i h_i\,h_{i+k}.
\]

Because `∑h_i = n/2` is constant, minimising the maximum of `S_k` is equivalent to **maximising the minimum autocorrelation**

\[
\min_k\; \sum_i h_i\,h_{i+k}.
\]

The term `∑ h_i h_{i+k}` is bilinear; the overall objective is the maximum of a family of affine functions in `h` (each `S_k` is affine plus a concave quadratic piece).  The exact objective is non‑convex, but the *max* of a set of affine functions is a **convex, piecewise‑linear** function of `h`.  Hence a *subgradient* can be obtained analytically.

---

### 3.  Core Optimisation Idea – Projected Sub‑gradient Descent
For a given `h` let  

```
Craw = compute_corr_fft(h)                 # length 2n‑1, values of S_k (without dx)
Cmax = max(Craw)
Kmax = { k | S_k(h) = Cmax }               # the set of active shifts
```

The sub‑gradient of `max_k S_k` is any convex combination of the gradients of the active shifts.  
For a single shift `k` the gradient w.r.t. `h_j` is  

\[
\frac{\partial S_k}{\partial h_j}= 1
            -\mathbf{1}_{j+k<n}\,h_{j+k}
            -\mathbf{1}_{j-k\ge0}\,h_{j-k}.
\]

Hence a convenient sub‑gradient (the average over all active shifts) is

```
g = |Kmax| * 1_vector
    - Σ_{k∈Kmax} (h shifted left by k) 
    - Σ_{k∈Kmax} (h shifted right by k)
```

All operations are `O(|Kmax|·n)`; in practice `|Kmax|` is 1–3.

**Update rule (ordinary sub‑gradient):**

```
h ← Proj_{[0,1],∑=n/2} ( h – η_t * g )
```

with a diminishing step‑size  

\[
\eta_t = \frac{\eta_0}{\sqrt{t+1}}.
\]

### 4.  Constraint Projection – “Capped Simplex”
We must enforce simultaneously  

* box: `0 ≤ h_i ≤ 1`,
* equality: `∑h_i = target = n/2`.

The Euclidean projection onto this set is obtained by solving for a scalar λ such that  

\[
\sum_i \operatorname{clip}(x_i-λ,0,1)=\text{target}.
\]

Because the left‑hand side is monotone decreasing in λ, a **binary search** on λ converges in ~60 iterations to machine precision.  
The procedure:

```
lo = min(x) - 1          # certainly below the solution
hi = max(x)              # certainly above the solution
repeat 60 times:
    λ = (lo+hi)/2
    proj = clip(x-λ,0,1)
    if sum(proj) > target: lo = λ
    else:                   hi = λ
return clip(x-(lo+hi)/2,0,1)
```

The projection is exact up to the binary‑search tolerance and guarantees the sum constraint.

### 5.  Fast Correlation Computation
The vector `S_k(h)` for all shifts is needed each iteration.  
Use FFT‑based convolution:

1. `a = h`, `b = 1‑h`.
2. Zero‑pad both to the next power of two `L ≥ 2n‑1`.
3. `corr = ifft( fft(a,L) * fft(b,L) ).real[:2*n‑1]`.

This yields the same numbers as `np.correlate` but in `O(L log L)` (≈ 5 k operations for `n≈240`).

### 8.  Smooth‑Phase – Homotopy from Log‑Sum‑Exp

\[

Gradient of the smooth objective is

\[
\nabla \tilde C = \sum_{k} w_k\,\nabla S_k,\qquad
w_k = \frac{e^{\beta S_k}}{\sum_j e^{\beta S_j}}.

The same convolution‑based code used in the original solution computes `∇S_k`.
