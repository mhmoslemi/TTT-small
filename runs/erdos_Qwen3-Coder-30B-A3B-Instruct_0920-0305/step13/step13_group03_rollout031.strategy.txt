- Use "hill climbing" with random restarts, and at each step compute max overlap and see which shift causes worst overlap; then propose a swap that directly reduces that shift (choose a 1 from region overlapped with zeros for that shift and swap with a 0 from region overlapped with ones). This can be a "move" that guaranteed reduces I at that shift by at least 1.

- Implementation: For current worst shift ℓ_w (max I), compute positions where h[i] = 1 and (1 - h[i+ℓ_w]) = 1 i.e., h[i]=1, h[i+ℓ_w]=0 (these are mismatched "bad" contributions). Let's denote set B = {i : 0 <= i < n-ℓ_w, h[i]=1, h[i+ℓ_w]=0}. Similarly, to preserve sum, we need to switch a 0 from elsewhere to become 1. Pick a position j such that h[j]=0 and either (1) j is not in B and maybe not causing new mismatches for ℓ_w or causing minimal. We swap h[i]=1, h[j]=0. After swap, the mismatched pair at i is corrected because h[i] becomes 0, reducing I_ℓ_w by 1 (since originally i contributed 1 to I_ℓ_w). However, switching at j might introduce new mismatches at other shifts (including ℓ_w). To avoid making I_ℓ_w increase again, we should choose j such that if we set h[j]=1, the pair with j+ℓ_w not produce mismatched (i.e., either j+ℓ_w out of bounds or h[j+ℓ_w]=1). So we need to find j such that either j+ℓ_w >= n (outside overlapping region) or h[j+ℓ_w]=1. Similarly also ensure that j-ℓ_w not cause mismatch because h[j-ℓ_w]=1? Actually we need to consider mismatches contributed by j as first index: if h[j] becomes 1 then term h[j] * (1 - h[j+ℓ_w]) will be positive if h[j+ℓ_w]=0 and j+ℓ_w < n. So we want h[j+ℓ_w] = 1 (i.e., cooperating). That's a candidate. Similarly we also need to consider mismatches for negative lag ℓ (i.e., if j as second index). But it's complex.

Simplify: Instead of designing specific j, we can try random j choices until if swap reduces the max I (maybe reduces at ℓ_w). Accept if improvement.

Thus local search can be:

While time left:
    compute I = correlation array.
    ℓ_max = argmax(I)
    compute mismatch indices B from ℓ_max: positions i where h[i]=1 and (i+ℓ_max) in range and h[i+ℓ_max]=0.
    For each i in random sample of B (maybe up to 5):
        pick a random zero position j.
        evaluate swap effect (recompute I after swap). If new max I < current max (improvement), accept.
        else maybe accept with some probability.

Thus each iteration focuses on worst shift.
