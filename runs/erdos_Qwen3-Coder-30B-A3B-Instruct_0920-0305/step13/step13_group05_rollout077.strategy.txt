### 1. Analytic ingredients

1. **Correlation vector (full mode).**  
   Use FFT‑based convolution:  
   ```
   b = 1 - h
   corr = ifft( fft(h[::-1], L) * fft(b, L) ).real   # L = 2*N-1
   ```
   `corr[t]` corresponds to shift `s = t-(N-1)`.

2. **Exact gradient of a single shift.**  
   For a shift `s` (positive, negative, or zero) the derivative of  
   \(C_s(h)=\sum_{i}h_i\bigl(1-h_{i+s}\bigr)\) is  

   \[
   \frac{\partial C_s}{\partial h_j}= 
   \begin{cases}
       1-h_{j+s}      &\text{if }0\le j,\;j+s<N,\\[4pt]
      -h_{j-s}       &\text{if }0\le j-s,\;j<N,\\[4pt]
       0              &\text{otherwise.}
   \end{cases}
   \]

   In vector form (Python‑style, `g = np.zeros(N)`):

   *if s ≥ 0*  

   ```
   g[:N-s] += 1 - h[s:]          # forward part
   g[s:]   += -h[:N-s]           # backward part
   ```

   *if s < 0* (let t = -s)  

   ```
   g[t:]   += 1 - h[:N-t]        # forward part (now to the left)
   g[:N-t] += -h[t:]            # backward part
   ```

   The gradient of the *max* is any convex combination of the gradients of the active shifts (those attaining the maximal correlation).  

3. **Smooth max via log‑sum‑exp.**  
   Define a temperature parameter \(\gamma>0\)

   \[
   F_\gamma(h)=\frac{dx}{\gamma}\log\Bigl(\sum_{s}e^{\gamma C_s(h)}\Bigr).
   \]

   \[
   \nabla F_\gamma(h)=dx\;\sum_{s} w_s\,\nabla C_s(h),\qquad
   w_s=\frac{e^{\gamma C_s(h)}}{\sum_{t}e^{\gamma C_t(h)}} .
   \]

   The weights are cheap to obtain once the correlation vector is known.

4. **Projection onto the capped simplex.**  
   We need the Euclidean projection of a vector `v` onto  

   \[
   \mathcal{S}=\{x\in[0,1]^N:\; \mathbf{1}^\top x = N/2\}.

   This is a standard “water‑filling” problem:
   * find a scalar \(\lambda\) such that \(\sum_i \operatorname{clip}(v_i-\lambda,0,1)=N/2\);

   (≈30 iterations) or by sorting `v` (O(N log N)).  The binary‑search version
