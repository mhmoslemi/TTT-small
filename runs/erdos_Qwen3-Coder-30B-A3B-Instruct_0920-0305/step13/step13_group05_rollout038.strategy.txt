**1.  Problem reformulation**

For a discretised step‑function  
\(h\in[0,1]^{N}\) with \(N=n_{\text{points}}\) (default 120) we have  

\[
C_5(h)=dx\;\max_{k\in\{-N+1,\dots ,N-1\}}
\;c_k(h),\qquad 
c_k(h)=\sum_{i=0}^{N-1}h_i\bigl(1-h_{i+k}\bigr),
\]

where out‑of‑range indices are ignored (zero‑padding) and \(dx=2/N\).

Because \(\sum_i h_i = N/2\) the problem is equivalent to  

\[
\min_{h\in[0,1]^N,\;\sum h_i=N/2}
\;F(h):= \max_k c_k(h).
\]

The function \(c_k(h)\) is *linear* in each component of \(h\) except for the product term
\(h_i\,h_{i+k}\).  Its gradient (for a fixed shift \(k\)) can be written **exactly**:

*for a non‑negative shift* \(k\ge0\)

\[
\frac{\partial c_k}{\partial h_j}= 
\begin{cases}
1-h_{j+k}, & 0\le j\le N-1-k,\\[4pt]
-\,h_{j-k},& k\le j\le N-1,\\[4pt]
0, &\text{otherwise}.
\end{cases}
\]

*for a negative shift* \(k<0\) (write \(t=-k>0\))

\[
\frac{\partial c_{-t}}{\partial h_j}= 
\begin{cases}
1-h_{j-t}, & t\le j\le N-1,\\[4pt]
-\,h_{j+t}, & 0\le j\le N-1-t,\\[4pt]
0, &\text{otherwise}.
\end{cases}
\]

Thus the gradient of a *single* shift is obtainable in \(O(N)\) time with simple vector
operations.

**2.  Smoothing the max‑operator**

Direct optimisation of the non‑smooth function \(\max_k c_k\) is difficult for gradient‑based methods.  
Introduce a temperature parameter \(\gamma>0\) and replace the max by a **log‑sum‑exp** (soft‑max) surrogate:

\[
\Phi_\gamma(h)=\frac{dx}{\gamma}\,
\log\Bigl(\sum_{k} \exp\bigl(\gamma\,c_k(h)\bigr)\Bigr).
\]

When \(\gamma\to\infty\) we recover \(dx\max_k c_k\).  For moderate \(\gamma\) the surrogate is smooth,
convex in the neighbourhood of each active shift, and its gradient is a convex combination of the
individual shift gradients:

\[
\nabla\Phi_\gamma(h)=dx\sum_{k} w_k(h)\,\nabla c_k(h),\qquad
w_k(h)=\frac{\exp(\gamma c_k(h))}{\displaystyle\sum_{j}\exp(\gamma c_j(h))}.
\]

The weights are cheap to compute once the vector of all \(c_k\) is available.

**3.  Efficient evaluation of all \(c_k\)**  

Use the FFT‑based correlation already proven fast:

```
b = 1 - h
corr = ifft( fft(h[::-1], L) * fft(b, L) ).real    # L = 2*N-1
```

`corr` contains \(c_k\) for all shifts (index‑shift conversion: shift = index-(N-1)).
The cost is \(O(N\log N)\) per iteration (≈ 1 ms for N=120).

**4.  Projection onto the feasible set**  

After a gradient step we must enforce

* box constraints: \(0\le h_i\le1\);
* sum constraint: \(\sum_i h_i = N/2\).

The projection onto the *capped simplex* can be performed by a simple water‑filling / binary‑search on a Lagrange multiplier \(\lambda\):

\[
\hat h_i = \operatorname{clip}(h_i+\lambda,\;0,\;1),\qquad
\sum_i \hat h_i = N/2.
\]

A fast implementation (≈ 30 µs for N=120) iterates the bisection for 30–40 steps,
which is negligible compared with the FFT.

**5.  Optimisation loop (core algorithm)**  


**6.  Multi‑restart strategy**

The landscape is non‑convex; a single run from the provided `initial_h_values` may miss a better basin.

* Keep the best of all restarts together with the best of the main run.

**7.  Final polishing (optional binary polishing)**  

After the smooth‑max optimisation we usually obtain a *near‑binary* vector with many components very close to 0 or 1.
