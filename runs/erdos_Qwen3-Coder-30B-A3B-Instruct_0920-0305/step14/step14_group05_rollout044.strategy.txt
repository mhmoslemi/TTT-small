### 1.  Reformulation of the objective

For a discretisation with **n** points (dx = 2 / n) let  

\[
h\in[0,1]^n ,\qquad \sum_{i=0}^{n-1}h_i=\frac{n}{2}.
\]

Define the *raw* overlap for shift `s*∈{-(n‑1),…,n‑1}*

\[
C_s(h)=\sum_{i=0}^{n-1}h_i\bigl(1-h_{i+s}\bigr)
       =\underbrace{\sum_i h_i}_{=\;n/2}
        \;-\; \underbrace{\sum_i h_i\,h_{i+s}}_{=:Q_s(h)} .
\]

Hence  

\[
C_5(h)=\frac{2}{n}\max_{s}C_s(h)=1-\frac{2}{n}\,\min_{s}Q_s(h).
\]

The problem is therefore **maximise the minimum auto‑correlation**  

\[
\max_{h}\;\min_{s} Q_s(h)
\quad\text{s.t.}\quad
0\le h_i\le1,\;
\sum_i h_i=n/2 .
\]

The term \(Q_s(h)=\sum_i h_i h_{i+s}\) is bilinear, so each constraint
\(\;Q_s(h)\ge\tau\) is non‑convex.  We shall *convexify* it by a
majorisation‑minimisation (MM) step that replaces every bilinear term by a
linear upper bound obtained from a first‑order Taylor expansion at the current iterate.

### 2.  Linear surrogate for a single shift

At iteration k let the current vector be \(h^{(k)}\).
For a fixed shift *s* the function  

\[
C_s(h)=\sum_i h_i-\sum_i h_i h_{i+s}
\]

has gradient  

\[
\bigl[\nabla C_s(h^{(k)})\bigr]_i
    = 1 - h^{(k)}_{i+s} - h^{(k)}_{i-s},
\]
with the convention that out‑of‑range indices contribute 0.
A first‑order (affine) majorising model is  

\[
\widetilde C_s(h)= C_s\!\bigl(h^{(k)}\bigr)
                +\sum_i\bigl(1-h^{(k)}_{i+s}-h^{(k)}_{i-s}\bigr)
                       \bigl(h_i-h^{(k)}_i\bigr).
\]

After rearrangement  

\[
\widetilde C_s(h)= \underbrace{b_s}_{\text{constant}}
                 +\sum_{i=0}^{n-1} a_{s,i}\,h_i,
\qquad
a_{s,i}=1-h^{(k)}_{i+s}-h^{(k)}_{i-s},
\qquad
b_s = C_s\!\bigl(h^{(k)}\bigr)-\sum_i a_{s,i}\,h^{(k)}_i .
\]

Thus each surrogate \(\widetilde C_s\) is an **affine function** of the
variables \(h_i\).

### 3.  Outer MM loop – solving a linear programme

For a set of shifts \(\mathcal S\) (see Section 5) we minimise the
maximum surrogate value:

\[
\begin{aligned}
\min_{h,t}\;& t\\[2mm]
\text{s.t. } & 0\le h_i\le 1, \qquad i=0,\dots,n-1,\\
            & \sum_{i=0}^{n-1} h_i = \tfrac{n}{2},\\
            & t \;\ge\; b_s+\sum_{i=0}^{n-1} a_{s,i}\,h_i ,
               \qquad\forall s\in\mathcal S .
\end{aligned}
\]

The variables are the vector \(h\) and the scalar \(t\).  The problem
is a **linear programme (LP)**.  It can be solved with any fast LP
solver available in `cvxpy` (e.g. ECOS, OSQP, SCS) or with SciPy’s
`linprog`.  Because the surrogate is a *global over‑estimate* of each
\(C_s\), the optimal LP solution never increases the true objective:
\(t_{\text{new}}\le \max_s C_s\bigl(h^{(k)}\bigr)\).

After solving we obtain the next iterate \(h^{(k+1)}\) and the
corresponding true maximum overlap \(C_{\max}^{(k+1)}\).

### 4.  Selecting the active shift set \(\mathcal S\)

focusing on the most critical constraints:

1. Compute the exact overlaps \(c_s = C_s\!\bigl(h^{(k)}\bigr)\) (FFT‑based

2. Let \(c_{\max}= \max_s c_s\).

3. Optionally add the two neighbouring shifts \((s_{\max}\pm1)\) to avoid

### 5.  Trust‑region stabilisation (optional but crucial)

The linear surrogate is only reliable within a neighbourhood of the

\[
|h_i - h^{(k)}_i| \le \delta_k\qquad\forall i,

with \(\delta_0\) e.g. 0.2 and a geometric decay \(\delta_{k+1}=0.9\,

### 7.  Final polishing – projected sub‑gradient descent

1. Evaluate the worst shift(s) of the current best vector.
2. Compute the exact sub‑gradient

3. Take a diminishing step

| **Search breadth** | Single deterministic trajectory (momentum, modest random tweaks). | **Multi‑start** + coarse‑to‑fine grid escalation + optional random perturbations, guaranteeing exploration of distinct basins. |
| **Mathematical foundation** | Heuristic descent. | **Majorisation–Minimisation** (a proven descent method for DC problems), guaranteeing monotone decrease of the true objective. |
| **Scalability** | Fixed n=120 (or modest variations). | Systematic *grid‑refinement* up to n≈240 while keeping each LP tiny; the LP size grows only linearly with n. |
| **Guarantees** | No theoretical guarantee of descent; may stall. | Each LP provides a *guaranteed non‑increase* of the exact objective (by construction of the majorising surrogates). |

Because the LP step computes the *best* feasible move respecting the
current affine approximation, it typically produces larger objective
improvements per iteration than a simple gradient step.  The multi‑start
scheme ensures that we are not trapped in the basin discovered by the
previous deterministic method, and the final sub‑gradient polishing
adds the fine‑grained adjustment that the coarse LP cannot capture.

### 10.  End‑to‑end workflow (no code, just logical flow)

1. **Initialisation** (stage 1): generate `M₁` random feasible vectors, keep the best after a few MM iterations.
2. **Stage 2 (medium grid)**: up‑sample the best coarse vector, project, run the MM loop with a tighter trust‑region and a larger active‑shift set. Keep the best.
3. **Stage 3 (fine grid)**: up‑sample again to `n₃≈240`, run the MM loop with a very small trust‑region, add occasional random perturbations if progress stalls.
4. **Polishing**: run projected sub‑gradient descent for a few thousand steps.
5. **Return** the vector `h_best`, its evaluated constant `C₅ = (2/n₃)·max_s C_s(h_best)`,
   and `n₃` as the number of points.

All steps respect the supplied `budget_s` by monitoring elapsed time and
cutting short any inner loop that would exceed its allotted fraction.
