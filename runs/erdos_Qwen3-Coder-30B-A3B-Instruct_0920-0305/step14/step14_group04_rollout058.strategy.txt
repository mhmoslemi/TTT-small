### 1. Convex‑relaxation via McCormick envelopes  

1.1 **Variables**  
* Primary variables h[i] ∈ [0,1] (i = 0…n‑1).  
* Auxiliary variables y[i,s] intended to represent h[i]·h[i+s] for every shift s ∈ {-(n‑1)…(n‑1)}.  
* Scalar t ≥ 0 (the upper bound on the correlation Cₛ).

1.2 **Linear constraints** (McCormick relaxation, valid for 0 ≤ h ≤ 1)  

For each i,s:

```
y[i,s] ≥ 0
y[i,s] ≥ h[i] + h[i+s] – 1
y[i,s] ≤ h[i]
y[i,s] ≤ h[i+s]
```

If i+s is outside the index range, treat the missing h as 0 and drop the corresponding y‑variables.

1.3 **Overlap constraints**  

The raw (un‑scaled) correlation for shift s is  

 C_raw(s) = Σᵢ h[i] – Σᵢ y[i,s].

Because Σᵢ h[i] = n/2 is constant, the max‑correlation constraint becomes  

 Σᵢ y[i,s] ≥ (n/2) – t/dx  for every shift s.

Thus the linear programme is  

```
minimise   t
subject to Σ h[i] = n/2
           0 ≤ h[i] ≤ 1
           McCormick constraints for all y[i,s]
           Σ y[i,s] ≥ (n/2) – t/dx   for all s
```

1.4 **Size control** – The full formulation contains O(n²) auxiliary variables.  
Choose a moderate grid (e.g. n = 100) so that the LP has ≈10⁴ variables, well within the capability of open‑source LP solvers (CBC, GLPK, or the ECOS/PDLP back‑end of CVXPY).

### 2. Global stochastic optimisation (Differential Evolution)

2.1 **Population encoding** – Each individual is a length‑n vector p.  
After mutation/crossover, a *repair* step enforces the constraints:

* Clip every component to [0,1].
* Apply a fast “water‑filling’’ projection to make the sum exactly n/2.  
  (Binary‑search for λ such that Σ clip(p+λ,0,1) = n/2.)

2.2 **Symmetry reduction** – After repair, replace p by (p + p[::-1])⁄2 (enforce mirror symmetry around x = 1) and re‑project. This halves the effective dimensionality and respects the natural symmetry of the problem.

2.3 **Fitness evaluation** – For each individual compute  

 C₅(p) = dx·maxₛ FFT‑correlation(p, 1‑p).  

FFT‑based correlation is O(n log n) and dominates time; with n ≈ 120 it is negligible.

2.4 **Algorithm flow**  

```
Initialize a population (size ≈ 30):
    • one member = h⁰ from the LP,
    • a few members = the triangular shape (h[x]=min(x,2‑x)),
    • the rest = random feasible vectors (uniform or binary, repaired).

While time remains (≈ 60 % of the budget):

    • Repair each trial to satisfy box+sum+symmetry.
```

### 3. Local refinement of elite individuals (Projected Adam)

3.1 **Smooth max surrogate** – Replace maxₛ Cₛ by a log‑sum‑exp barrier  

 F(h) = (dx/α)·log( Σₛ exp(α·Cₛ) ),  

with a temperature α that is increased gradually (α ← 1.0 → 300).  

The gradient of F is  

 ∇F = Σₛ pₛ·∇Cₛ, pₛ = softmax(α·Cₛ).

Because ∇Cₛ[i] = 1 − h[i+s] − (1 − h[i‑s]) = –(h[i+s] + h[i‑s]) (for interior indices), the gradient is a weighted sum of neighbour‑sums.

3.2 **Adam update** – Maintain first‑ and second‑moment estimates (m, v).  
At each iteration:

```
g = –∇F   (direction that lowers C₅)
m ← β₁·m + (1‑β₁)·g
v ← β₂·v + (1‑β₂)·g²
m̂ = m/(1‑β₁ⁿ) ,  v̂ = v/(1‑β₂ⁿ)
h_new = h – η·m̂/(√v̂ + ε)
```

3.3 **Projection** – After each Adam step, project h_new onto the intersection of the box and the sum‑hyperplane using the same water‑filling routine as in DE.  
Enforce symmetry again (average with its reverse) before projection.

3.4 **Schedule** – Run the Adam refinement for a few thousand iterations on the elite individual after each DE generation or when the elite has not improved for a while.  
Decrease learning‑rate η over time (ηᵏ = η₀/√k) and increase α exponentially (α←α·1.05) so the surrogate becomes tighter.
