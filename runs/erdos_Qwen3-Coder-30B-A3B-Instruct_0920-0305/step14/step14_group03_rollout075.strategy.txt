### 1. Exact analytic ingredients

1. **Correlation vector**  
   For a given h (length n) let `L = 2*n‑1`.  
   `corr = ifft( fft(h[::-1], L) * fft(h, L) ).real`  (FFT‑based linear convolution).  
   `corr[r] = Σ₀^{n‑1‑|s|} h[i] h[i+s]` for shift `s = r‑(n‑1)`.

2. **Overlap values**  
   `O = dx * ( target_sum – corr )`  (length L).  
   The current bound is `C = max(O)`.

3. **Exact gradient of O_s**  
   For a shift `s` (non‑zero)  
   ∂O_s/∂h[i] = ‑dx·( h[i+s] + h[i‑s] ) whenever the shifted index is inside [0,n‑1]; for the zero shift, the factor 2 appears: ∂O₀/∂h[i] = ‑2·dx·h[i].

4. **Smooth max (soft‑max) surrogate**  
   Choose a temperature α>0 and define weights  

    `w[r] = exp( α·( O[r] – max(O) ) ) / Σ exp( … )`.  

   The surrogate objective is `F = Σ w[r]·O[r]`.

### 2. Projection onto the feasible set

We need the Euclidean projection of a vector x onto  

 { h ∈ ℝⁿ | 0≤h[i]≤1 ∧ Σ h[i] = target_sum }.

Because the feasible set is a **capped simplex**, a simple binary‑search on a Lagrange multiplier λ works:

```
f(λ) = Σ clamp( x[i] + λ , 0 , 1 ) – target_sum
```

f is monotone in λ; find λ such that f(λ)=0 (tolerance 1e‑12).  
The projected vector is `h = clamp( x + λ , 0 , 1 )`.  
This routine is cheap (≈30 iterations of bisection) and works for any n.
