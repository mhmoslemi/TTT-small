        constraints_expr = []  # list of cvxpy constraints
        # current best t bound estimate
        t_val = evaluate_c5(h_current)  # actual value
        # Set up variables once
        h_var = cvxpy.Variable(n_points)
        t_var = cvxpy.Variable()
        basic_constraints = [h_var >= 0, h_var <= 1, cvxpy.sum(h_var) == target]
        # Loop
        for it in range(30):
            # compute correlation and find worst shift(s)
            I_full = compute_corr(h_current)  # returns array length L
            idx_max = int(np.argmax(I_full))
            I_max = I_full[idx_max]
            shift = idx_max - (n_points - 1)
            # generate linearized constraint for this shift
            grad = compute_gradient_for_shift(h_current, shift)  # returns vector length N
            const = I_max - grad @ h_current
            # add constraint: t_var >= const + grad @ h_var
            constraints_expr.append(t_var >= const + grad @ h_var)
            # solve LP
            prob = cvxpy.Problem(cvxpy.Minimize(t_var),
                                 basic_constraints + constraints_expr)
            prob.solve(solver='ECOS', warm_start=True, verbose=False)
            if h_var.value is None:
                # infeasible or solver failed: break
                break
            h_new = np.clip(np.array(h_var.value).astype(np.float64), 0, 1)
            # re-project to exact sum
            h_new = project_to_sum_box(h_new, target)
            new_c5 = evaluate_c5(h_new)
            # convergence check
            if new_c5 >= t_val - 1e-7:
                # no significant improvement
                break
            h_current = h_new
            t_val = new_c5
        return h_current, t_val

    # Now iterate over starters:
    for init_h in starters:
        # time check
        if time.time() - start > budget_s * 0.9: break
        # run cutting plane

        # update best
        if c5_refined < best_c5:
            best_c5 = c5_refined
            best_h = h_refined.copy()

    if best_h is None:
        best_h = np.zeros(n_points)
        best_c5 = evaluate_c5(best_h)
    
    return best_h.tolist(), float(best_c5), n_points

**Goal** – produce a step function `h` on `[0,2]` (discretised with *n* points, *n* ≤ 1000) such that  

```
C5(h) = max_k ∫_0^2 h(x)·(1‑h(x+k)) dx
```

is as small as possible (the smaller the tighter upper bound on the Erdős constant).  
The integral is evaluated by the full linear correlation of the vectors  
`h` and `b = 1‑h` multiplied by `dx = 2/n`.

The new method departs completely from the evolutionary‑gradient hybrid used before.  
It combines **(i) a cutting‑plane / successive linearisation scheme solved with a LP
solver (CVXPY)** and **(ii) a cheap sub‑gradient refinement**.  
Because the LP is tiny (≈ *n* variables, a handful of linear constraints) it can be
solved many times within the 600 s budget, allowing many independent restarts and
rapid convergence to a better feasible point.

--------------------------------------------------------------------
### 1.   Mathematical reformulation

For a fixed shift `j` (integer offset, `j = –(n‑1)…(n‑1)`) define  

```
I_j(h) = Σ_i h_i·(1‑h_{i+j})     (zero outside the interval)
```

`C5(h) = dx·max_j I_j(h)`.  
Writing `b = 1‑h` gives `I_j(h) = Σ_i h_i·b_{i+j}` – a bilinear form.

The minimisation problem can be written as

```
 minimise   t
 subject to Σ_i h_i = n/2,        0 ≤ h_i ≤ 1               (box + sum)
            I_j(h) ≤ t   for all j                (non‑convex)
```

The constraints `I_j(h) ≤ t` are non‑convex because of the product `h_i·h_{i+j}`.
We replace each of them **only at the current iterate** by its first‑order
Taylor expansion (a supporting hyperplane).  
For a given shift `s` the gradient of `I_s` with respect to `h` is

```
∂I_s/∂h_i =  (1‑h_{i+s})   if 0 ≤ i+s < n
           –h_{i‑s}       if 0 ≤ i‑s < n
           0               otherwise
```

If `h⁰` is the current point and `I_s⁰ = I_s(h⁰)`, the linearised constraint is

```
t ≥ I_s⁰ + Σ_i ∂I_s/∂h_i (h_i – h⁰_i)
   = (I_s⁰ – ∇I_s·h⁰) + ∇I_s·h          (*)
```

The right‑hand side is an **affine function of h**, therefore the constraint is linear.
At iteration `k` we keep all linearised constraints generated at earlier iterates,
solve the resulting LP, obtain a new `h`, recompute the worst shift(s) and add their
linearisation.  This is the classical cutting‑plane method for a min‑max problem.

### 2.   Core algorithm (one restart)

```
INPUT : n (even, e.g. 180), initial vector h⁰ (already satisfies
        0 ≤ h ≤ 1 and Σh = n/2)

repeat up to MAX_ITER (≈30) or until no improvement
    1) Compute the full correlation I = corr(h, 1‑h)  (FFT, O(n log n)).
    2) Find the worst shift(s) j* where I attains its maximum.
    3) For each j*:
           – compute the gradient g = ∇I_{j*}(h) using the formula above;
           – compute constant c = I_{j*} – g·h;
           – add the linear constraint   t ≥ c + g·h   to the LP.
    4) Solve the LP:

           minimise   t
           subject to 0 ≤ h ≤ 1 , Σh = n/2 ,                     (box + sum)
                      (all accumulated linear constraints)       (linear)

       Variables are the vector h (size n) and scalar t.
       Use CVXPY with the ECOS (or SCS) solver; the problem is tiny, so each
       solve takes only a few milliseconds.

    5) Retrieve the optimal h_new, project it once more onto the box+sum
       (tiny numerical drift) and evaluate the true C5 value.
    6) If C5(h_new) is smaller than the best value seen so far,
       update the best‑ever solution; otherwise terminate the loop
       (the linearisation has become too loose).

OUTPUT of the restart : refined h and its true C5.
```

*Why this works* – each added hyperplane cuts away a part of the feasible region that
cannot contain the optimal solution of the original non‑convex problem.  The LP
optimises over the convex outer approximation; as more cuts are introduced the
approximation tightens and the LP solution converges toward a local minimiser of the
true max‑objective.

### 3.   Auxiliary utilities (used everywhere)

* **Correlation (`full_corr`)** – compute `I` via FFT:
  ```
  L = 2·n‑1
  h_rev = h[::-1]
  b = 1‑h
  I = real( ifft( fft(h_rev, L) * fft(b, L) ) )
  ```
  The result is the un‑scaled sum; the final bound is `dx·max(I)`.

* **Gradient for a shift (`grad_shift`)** – vectorised implementation:

  ```
  if s ≥ 0:
      g[:n‑s]   += 1 - h[s:]
      g[s:]     -= h[:n‑s]
  else:
      s = -s
      g[s:]     += 1 - h[:n‑s]      # term (1‑h_{i‑s})
      g[:n‑s]   -= h[s:]           # term –h_{i+s}
  ```

* **Projection onto the box and exact sum (`project_sum_box`)** – binary‑search
  for λ such that `clip(x+λ,0,1)` has sum `n/2`.  The search interval `[-1,1]`
  always contains a solution because the total range of `x` is within `[0,1]`.

* **Sub‑gradient local refinement** – after the cutting‑plane phase we run a very
  cheap sub‑gradient descent on the true max‑objective:

  ```
  for it = 1 … K (≈2000):
       compute worst shift s = argmax I
       g = grad_shift(h, s)
       step = α / sqrt(it)   (α≈0.5)
       h ← h – step·g
       h ← project_sum_box(clip(h,0,1), n/2)
       keep the best h seen
  ```

  This typically squeezes a few additional 1e‑4 off the bound.
