### 1.  High‑level idea  
Treat the discretised step‑function **h** as a vector  
\(h\in\mathbb R^{n},\;0\le h_i\le 1,\;\sum_i h_i = n/2\) (so that the integral constraint is satisfied).  
For a shift \(s\in\{-n+1,\dots ,n-1\}\) define the overlap  

\[
Q_s(h)=\sum_{i=0}^{n-1}h_i\,h_{i+s}\qquad\bigl(h_{j}=0\text{ if }j\notin[0,n-1]\bigr)
\]

and the quantity to be minimised  

\[
C_5(h)=\frac{2}{n}\max_{s}\Bigl(\underbrace{\sum_i h_i}_{=n/2}-Q_s(h)\Bigr)
      =1-\frac{2}{n}\min_{s} Q_s(h).
\]

Thus **maximising the minimum autocorrelation** \(\min_{s}Q_s\) is equivalent to **minimising** \(C_5\).

The products \(h_i h_j\) are the only non‑convex elements.  
Introduce the rank‑one matrix  

\[
X = h\,h^{\!\top}\in\mathbb R^{n\times n},\qquad X\succeq 0,\;\operatorname{rank}(X)=1 .
\]

Each overlap can be written linearly in terms of X :

\[
Q_s(h)=\sum_{i=0}^{n-1} X_{i,i+s}.
\]

If we **relax** the rank‑one constraint we obtain a **semidefinite programme (SDP)** that gives a *global upper bound* on the optimum and, after a suitable rounding step, a concrete feasible vector h.

The whole pipeline is:

1. **Select a grid size** \(n\) (coarse → fine).  
2. **Build and solve the SDP** for the maximal achievable \(\mu:=\min_{s}Q_s\).  
3. **Extract a low‑rank factor** of the SDP solution and **randomly round** it to a feasible vector h.  
4. **Project** the rounded vector onto the box‑sum set \(\{0\le h\le1,\;\sum h=n/2\}\).  
5. **Evaluate** the true objective \(C_5(h)\); keep the best sample.

### 3.  SDP formulation  

#### Variables  

* \(h\in\mathbb R^{n}\) – the step values (continuous).  
* \(X\in\mathbb R^{n\times n}\) – symmetric matrix intended to be \(h h^{\!\top}\).  
* \(\mu\in\mathbb R\) – a lower bound on every autocorrelation term.

#### Constraints  

1. **Box and sum constraints on h**  

   \[
   0\le h_i\le 1,\qquad\sum_{i=0}^{n-1}h_i = \frac{n}{2}.
   \]

2. **PSD constraint**  

   \[
   X\succeq 0 .
   \]

3. **Linking h and X (McCormick linearisation of the rank‑one relation)**  

   For every pair \((i,j)\) we impose the standard convex envelope of the product on the box:

   \[
   \begin{aligned}
   X_{ij} &\le h_i,\\
   X_{ij} &\le h_j,\\
   X_{ij} &\ge 0,\\
   X_{ij} &\ge h_i+h_j-1 .
   \end{aligned}
   \]

   Because \(0\le h_i,h_j\le1\), these four linear inequalities are *exact* when the rank‑one condition holds and are a tight convex relaxation otherwise.

4. **Minimum‑overlap constraints** (one per shift)  

   For every shift \(s\in\{-n+1,\dots,n-1\}\) define the index set  

   \[
   \mathcal I_s=\{(i,i+s)\mid 0\le i,i+s<n\}.
   \]

   Impose  

   \[
   \sum_{(i,i+s)\in\mathcal I_s} X_{i,i+s}\;\ge\;\mu .
   \]

#### Objective  

\[
\max\ \mu .
\]

Because \(\mu\) is a lower bound on all overlaps, the SDP maximises the *minimal* autocorrelation. The corresponding bound on the Erdős constant is  

\[
C_5^{\text{SDP}} = 1 - \frac{2}{n}\mu^{\star},
\]

where \(\mu^{\star}\) is the optimal SDP value.

#### Solver choice  

* Use **CVXPY** with a first‑order conic solver that handles PSD cones efficiently (e.g. **SCS** or **ECOS**).  
* Set a modest accuracy tolerance (e.g. `eps=1e-4`) – the SDP is only a relaxation, so extremely high precision is unnecessary.  
* For the coarse grid (\(n=80\)) the problem has 80 variables, ~6400 linear constraints, and a single PSD cone of size 80 – it finishes in well under a second.  
* For the finer grids (\(n=160,240\)) the same formulation scales quadratically, still solvable in a few seconds on a single CPU using SCS.

### 4.  Extracting a feasible vector from the SDP solution  

The SDP returns a feasible pair \((h^{\text{SDP}},X^{\text{SDP}})\) satisfying all linear constraints, but \(X^{\text{SDP}}\) may have rank > 1.  

1. **Eigen‑decomposition** of \(X^{\text{SDP}}\):  

   \[
   X^{\text{SDP}} = V\Lambda V^{\!\top},\qquad\Lambda=\operatorname{diag}(\lambda_1,\dots,\lambda_r),\; \lambda_k\ge0.
   \]

   Keep the eigenvectors associated with the **top r** eigenvalues (e.g. r≈10, enough to capture most of the mass).

2. **Randomised rounding**  

   *For each trial* (we will perform 200–500 trials per grid):
   * Sample a standard Gaussian vector \(g\in\mathbb R^{r}\).

     \hat h_i = \bigl(V_{i,:}\sqrt{\Lambda}\,g\bigr) .

### 5.  Local polishing – exact worst‑shift sub‑gradient descent  

The best rounded candidate \(h^{\text{rnd}}\) is a high‑quality feasible point but usually still leaves a small gap to the SDP bound. A short, deterministic refinement eliminates this gap:

1. **Compute the correlation vector** \(c = \text{corr}(h,1-h)\) (no scaling).  
2. Determine the *worst* shift set  

   \[
   \mathcal S = \{s\mid c_s \ge \max_{t}c_t - \varepsilon\},
   \qquad\varepsilon =10^{-12}.
   \]

   In practice \(|\mathcal S|=1\) most of the time.

3. **Exact sub‑gradient for a shift** \(s\):  

   For each index \(i\),

   \[
   g_i(s) = 1 - h_{i+s} - h_{i-s},
   \]

   where out‑of‑range neighbours are taken as zero.  
   The sub‑gradient of the max is the *average* of \(g(s)\) over all \(s\in\mathcal S\).

4. **Step‑size schedule** – use a diminishing step  

   \[
   \eta_k = \eta_0 / \sqrt{k+1},\qquad\eta_0=0.5 .
   \]

5. **Update and projection**  

   \[
   h^{\text{new}} = \operatorname{proj}_{[0,1],\sum=n/2}\!\bigl( h - \eta_k g \bigr).
   \]

   The same projection routine as in the rounding stage is used.

6. **Stopping criteria** – run at most 2000 iterations or stop earlier when the improvement in \(C_5\) falls below \(10^{-7}\).

Because the descent uses the true worst‑shift gradient, each accepted step strictly decreases the objective (or leaves it unchanged after projection). Empirically a few hundred iterations are sufficient to push the value within a few \(10^{-5}\) of the SDP bound.
