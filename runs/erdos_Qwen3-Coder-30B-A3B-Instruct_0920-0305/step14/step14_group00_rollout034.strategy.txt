- Choose a modest number of sample points `n` (e.g. 200–250).

**2. Objective formulation**  
For a shift `k` corresponding to an integer lag `s = k/dx` (range `‑(n‑1)…(n‑1)`), the discrete overlap is  

```
C_s(h) = Σ_{i∈I_s} h_i (1 – h_{i+s})
```

where `I_s = { i | 0 ≤ i < n‑|s| }`.  
The target value is  

```
C5(h) = max_s C_s(h)
```

`C5` is a *max* of a collection of functions, each of which is linear in `h` minus a bilinear term `h_i·h_{i+s}`.

**3. Sub‑gradient of the max‑objective**  
For a given lag `s` the gradient is easy to write analytically:

- if `s ≥ 0` (right shift): for all `i = 0 … n‑s‑1`  

```
∂C_s/∂h_i     = 1 – h_{i+s}
∂C_s/∂h_{i+s} = –h_i
```

- if `s < 0` (left shift): let `t = –s` and repeat the same pattern with the roles of the two indices swapped.  

For `s = 0` this reduces to `∂C_0/∂h_i = 1 – 2·h_i`.

The *sub‑gradient* of `C5` is any convex combination of the gradients of those shifts attaining the current maximum. In practice we take the simple average of the gradients of all maximal lags (ties are rare but harmless).

**4. Projection onto the feasible set**


This is a Euclidean projection onto a *capped simplex*.
