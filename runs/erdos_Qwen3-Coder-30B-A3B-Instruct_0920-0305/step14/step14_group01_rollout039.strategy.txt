**Goal** – Produce a step‑function `h` (discretised on `n_points` samples) that satisfies  

*  `0 ≤ h[i] ≤ 1` for all i,  
*  `∑ h[i] · dx = 1`   (`dx = 2/n_points`),  

and minimises  

\[
C_{5}(h)= \max_{k}\;\int_{0}^{2} h(x)\bigl(1-h(x+k)\bigr)\,dx .
\]

The evaluation used by the grader is the full linear correlation  
`corr = h ⋆ (1‑h)` (zero padding) and `C5 = dx·max(corr)`.

The previous submission relied on a differential‑evolution / simulated‑annealing loop.
Below is a **different** optimisation pipeline that combines a smooth surrogate for the
max‑operator, analytic gradients, a low‑dimensional symmetric‑unimodal parametrisation,
and a continuation on the smoothing parameter.  All components are fast enough for
`n_points ≤ 300` and fit easily into the 600 s budget.

--------------------------------------------------------------------
### 1. Theoretical simplifications

1. **Symmetry** – The functional `C5` is invariant under the reflection
   `x ↦ 2 – x`.  For any admissible `h` the symmetrised function  

   \[
   \bar h(x)=\frac{h(x)+h(2-x)}{2}
   \]

   has the same integral, the same box constraints and **does not increase**
   any overlap value (by Jensen).  Hence we may restrict the search to **even**
   functions: `h[i] = h[n‑1−i]`.  We therefore optimise only the first half of
   the array and mirror it automatically.

2. **Unimodality (heuristic)** – Numerical experiments on the known best
   constructions show a single hill: values increase up to the centre
   (`x=1`) and then decrease.  Enforcing monotone increase on `[0,1]` (and the
   mirror decreasing on `[1,2]`) drastically reduces the search space while
   not harming the optimum.  We enforce it with a *soft* penalty rather than a
   hard constraint, allowing the optimiser to escape if a non‑unimodal shape is
   actually better.

--------------------------------------------------------------------
### 2. Parametrisation

*Choose a modest resolution* – `n = 240` (`dx = 2/240 = 0.00833…`).  
Only the first `m = n/2 = 120` entries are independent because of symmetry.
Let `u[0…m‑1]` be the independent variables; the full vector is  

```
h = concatenate([u, u[::-1]])   # mirrored
```

**Box + sum constraint** – After each optimisation step we project `u` onto
the feasible set `{0 ≤ u ≤ 1,  sum(u)=n/2}` using a standard water‑filling
binary‑search (the same routine used in the reference solution).

**Monotonicity penalty** – For the increasing half we add

```
pen_inc = λ * sum( max(0, u[i‑1] – u[i])² )   for i = 1…m‑1
```

and the same expression on the mirrored side (automatically satisfied).  
`λ` is set to a large value (e.g. `1e3`) so that any violation is heavily
discouraged.

--------------------------------------------------------------------
### 3. Smooth surrogate of the max‑operator

The max is non‑differentiable.  Replace it by the log‑sum‑exp (LSE) with a
temperature `ε > 0`:

\[
S_{ε}(h) = ε \log\Bigl(\sum_{j} \exp\bigl(I_j(h)/ε\bigr)\Bigr),
\qquad
I_j(h)=dx·\text{corr}_j .
\]

* As `ε → 0` we have `S_ε → max_j I_j`.  
* For moderate `ε` the function is smooth and its gradient is a weighted sum
  of the gradients of each shift.

--------------------------------------------------------------------
### 4. Analytic gradient of `S_ε`

Let  

* `b = 1 – h`,
* `L = 2·n – 1`,
* `corr = ifft( fft(h_rev, L) * fft(b, L) ).real`   (full linear correlation).

Define the weights

```
w = exp(corr / ε)
w /= w.sum()                     # shape (L,)
```

The gradient of the original overlap for a single shift `j` is

```
∂I_j/∂h_i = b[i + j]  (if i+j in range)  –  h[i – j] (if i‑j in range)
```

Summing with the weights yields a **convolution**:

```
g = conv(w, b)   –   conv(w_rev, h)   (both full convolutions)
grad_i = g[i + (n‑1)]            # extract the central n entries
```

All convolutions are computed with FFT for `O(n log n)` cost.  
The final gradient of the smooth objective (including penalties) is

```
∇S_ε = dx * grad + ∇pen_inc + 2·μ·(sum(u) – n/2)·1
```

where `μ` is the penalty coefficient for the equality constraint (if we prefer a
penalty formulation; otherwise we keep the exact projection after each step).

### 5. Optimisation loop (continuation)

We solve a sequence of smoother problems, each feeding its solution to the next
tighter one.

```
ε‑schedule = [0.5, 0.3, 0.15, 0.08, 0.04, 0.02, 0.01]
```

For each `ε`:

1. **Initial point** – the result from the previous `ε` (or a seed for the first

3. **Projection step** – After each L‑BFGS iteration we project the current `u`

4. **Record a best‑so‑far** – Compute the *real* `C5` with the original max

### 6. Final refinement (exact max)

After the last ε (≈ 0.01) we perform a short **projected sub‑gradient** descent
directly on the true objective `C5`:

```
repeat until time runs out:
    compute corr, locate the worst shift j* (argmax)
    grad_i = (1 - h[i + j*])   (if i+j* in range)
           – h[i - j*]         (if i‑j* in range)
    h ← project( h – α_t * grad )       # α_t = α0 / sqrt(t+1)
```

Because only the worst shift is used, the step is cheap (`O(n)`).  A few
thousand iterations typically shave the final `C5` down a few 1e‑4.
