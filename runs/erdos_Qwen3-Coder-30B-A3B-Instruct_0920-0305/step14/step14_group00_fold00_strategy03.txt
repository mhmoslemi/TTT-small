### 1.  Core idea – projected (sub)gradient descent on the true objective

`C₅(h)` is the **maximum** over `2n‑1` linear‑plus‑quadratic functions

```
f_s(h) = Σ_{i∈I_s} h_i – Σ_{i∈I_s} h_i·h_{i+s}
```

where `I_s = {0,…,n‑1‑s}` for a shift `s≥0` and analogously for `s<0`.  
`C₅ = max_s f_s(h)·dx`.  This is a *non‑convex* but **Lipschitz** function; a
sub‑gradient of `C₅` is obtained by taking the gradient of any shift `s*`
that attains the maximum (or a convex combination when several are tied).

Because the constraints are simple box constraints together with one linear
equality (`∑h = n/2`), the natural optimisation scheme is:

1. **Compute the worst shift(s).**  
   `corr = np.correlate(h, 1‑h, 'full')` → obtain the index/shift(s) `s*` where
   `corr` is maximal.
2. **Form a (sub)gradient.**  
   For a single shift `s` the derivative w.r.t. each component is  

   ```
   if s ≥ 0:
       for i = 0 … n‑1‑s:
           ∂f_s/∂h_i     += 1 – h_{i+s}
           ∂f_s/∂h_{i+s} -= h_i
   else:   # s = –t, t>0
       for i = 0 … n‑1‑t:
           ∂f_s/∂h_{i}     -= h_{i+t}
           ∂f_s/∂h_{i+t}   += 1 – h_i
   ```

   When several shifts share the maximal value we average the gradients.
3. **Take a step.**  
   `h' = h – α·g` with a diminishing stepsize `α = α₀ / √(iter+1)`.
4. **Project back onto the feasible set** (box & sum).  

   The projection is the Euclidean projection onto the *capped simplex*:

   ```
   find λ such that   x_i = clip(v_i – λ, 0, 1)   satisfies   Σ x_i = n/2
   ```

   This one‑dimensional root can be found by bisection (≈60 iterations give
   double‑precision accuracy).  The result automatically respects all constraints.
5. **Update the best‑so‑far solution** if the newly evaluated `C₅` is smaller.
6. **Iterate** until the allocated time expires.
