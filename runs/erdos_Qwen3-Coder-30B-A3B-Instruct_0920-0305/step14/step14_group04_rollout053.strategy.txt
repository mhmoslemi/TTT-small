### 1. Mathematical Re‑formulation

1. **Overlap interpretation**  
   \[
   c_k = \underbrace{\sum_i h_i}_{=n/2} - \underbrace{\sum_i h_i h_{i+k}}_{=:o_k}\,dx .
   \]  
   Since the first term is constant, minimizing `max c_k` is equivalent to **maximising the minimum overlap**  

   \[
   o_k=\sum_i h_i h_{i+k}\,dx .
   \]

2. **Bilinear constraints**  
   For each shift `k` we would like  
   \[
   o_k \ge \tau \quad\Longleftrightarrow\quad
   \sum_i h_i h_{i+k} \ge \tau .
   \]  
   The product `h_i h_j` is bilinear on `[0,1]²`.  
   Using the **McCormick envelope** we can replace each product by an auxiliary variable `y_{ij}` with linear constraints  

   ```
   0 ≤ y_{ij} ≤ h_i
   0 ≤ y_{ij} ≤ h_j
   y_{ij} ≥ h_i + h_j – 1 .
   ```

   Adding a scalar `t` that bounds the objective,
   ```
   t ≥ Σ_i h_i – Σ_i y_{i,i+k}      for every shift k .
   ```
   The feasible set is a convex relaxation of the original problem.  

3. **Relaxation as a Linear Program**  
   The variables are:
   * `h_i` (continuous, 0‥1, sum = n/2),
   * `y_{i,i+k}` for each shift `k` and each index `i` (with the McCormick bounds),
   * a scalar `t` (the relaxed upper bound on `dx·max c_k`).  

   The objective is simply **minimise `t`**.

   The relaxation provides a *lower bound* on the true optimum, but the `h` obtained is *feasible* for the relaxed problem and can be used as a high‑quality starting point for a non‑convex refinement.
