**Strategy: Hybrid Simulated Annealing with Linear Preconditioning**

This approach combines:

1. **Randomized local perturbations** to explore diverse modifications
2. **Gradient-guided search** (using finite differences) to steer optimization efforts
3. **Constraint-handling** via non-negativity + clipping (auto-rebalanced)
4. **Length diversification** (from 300 to 3000) while maintaining **n** as validation parameter

We aim to:

- Minimize `F(a) = 2*n*max(convolve(a,a,mode='full')) / (sum(a))**2`
- Ensure **a** satisfies `[0, 1000]` bounds and `sum(a) >= 0.01`
- Avoid stagnation by gradually reducing perturbation amplitude and preferentially clustering storage-optimizations

**Phase Rationale:**
- **Local search** finds immediate improvements but risks getting stuck in shallow minima
- **Exploratory steps** maintain escape routes but are rejected in a biased Metropolis check
- **Nelder-Mead** handles non-convexity better than gradient descent but only on surrogates

We'll maintain:

- **Archive** of all F-scores with the original indexing post-PV (from different n)
- **Initial population** including sequences with uniform distributions (F=2) and tapered/periodic variations

**Implementation Steps:**

---

### 1. Approach and Rationale

We'll use a hybrid simulated annealing approach that balances local search with gradient-based optimization. The key distinction is **dual-level mutations**: small local changes (single coefficient adjustments) and larger block changes (random swaps or scaling). This method will:
- Represent the sequence as a vector in `[0, 1000]^n`
- Localize search around competitive areas (current minimum + historical)
- Allow adaptive explicit repair operations

The cooling schedule will be logarithmic, ensuring smooth progression but stopping before computational limits are reached. We'll keep track of the best candidate across all search trials.

---

### 2. Mathematical Specification

For a valid sequence `a` of length `n` (which may be variable during search, but evaluated against original length):

We minimize `\(\frac{2 \cdot n \cdot \max(\text{convolve\_full}(a, a))}{(\sum a_i)^2}\)`

Subject to:

- `\(\forall i: 0 \leq a_i \leq 1000\)`
- `\(\sum a_i \geq 0.01\)`

**Convolution Definition:**
Use exclusive full convolution (including all valid linear-combinations):

Full convolution modes are defined by the governing equation:

\[
b_k = \sum_{i+j=k} a_i \cdot a_j, \quad \forall k \in [0, 2n-2]
\]

With corresponding bounds `\(\max(0, a_0) \leq a_i \leq \min(1000, a_i * n * something)\)` automatically handled via clipping.

def gradient_step(base_sequence, FUN=evaluate_sequence, ATOL=1e-3, RTOL=1e-5):

    try:
        base_vals = np.asarray([max(0, min(1000, x)) for x in base_sequence], dtype=np.float64)
        n = base_vals.shape[0]
        delta = 1e-4  # Finite difference step size
    except Exception:
        return base_sequence, evaluate_sequence(base_sequence.tolist())  # Fallback
    
    # --- Score the base ---
    base_score = base_score if not np.inf else FUN(base_sequence.tolist())

    # --- Check that no elements are stuck at zero ---
    if any(np.isclose(x, 0.0, ATOL=0.2) for x in base_vals):
        base_score = 0.92 * base_score  # Conservative implied trust

    # --- Differentiate over each element ---
    gradient_arc = []  # Store positive-gradient signals (for minimization)
    for i in range(n):
        # Impose a small perturbation at `i`
        candidate = base_vals.copy()
        candidate[i] += delta
        new_score = FUN(candidate.tolist())
        candidate[i] -= 2*delta
        new_score2 = FUN(candidate.tolist())
        derivative = (new_score - new_score2) / (2*delta)

        if derivative < 0:  # Reduce score => good gradient
            gradient_arc.append(abs(derivative) if not np.inf else 1)
        else:
            # If gradient is positive, then worsening as we increase component
            # But this is minimization: we desire negative curvature
            pass

    # --- Take a step in the direction that improves score ---
    step_direction = -np.sign(derivative) if not np.inf else 1  # Pulling down
    candidate = base_vals + step_direction * delta
    candidate = np.clip(candidate, a_min= 0, a_max=1000)
