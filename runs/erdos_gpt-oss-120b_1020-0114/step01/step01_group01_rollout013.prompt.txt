$$C_5 = \max_k \int h(x)(1 - h(x+k)) dx$$

### 1. Approach and Rationale

The core challenge is to minimize the maximum overlap integral \(C_5 = \max_k \int_0^2 h(x)(1-h(x+k))dx\) for a step function \(h: [0,2] \to [0,1]\) with integral \( \int_0^2 h(x)dx = 1 \). The previous implementation used SLSQP with local restarts on fixed grids, which could get trapped in local minima. This new approach adopts a multi-start convex optimization strategy with exponential grid resolution doubling, leveraging descent methods and analytical gradients to improve global exploration.

The rationale is that:
- The optimal solution often exhibits periodic behavior, and finer grids better capture its structure.
- The integral constraint \( \sum h_i = n_{\text{points}}/2 \) needs a projection/normalization mechanism to maintain feasibility.
- By using exponential grid size progression (doubling each time) and fewer function evaluations, we reduce computational load while improving solution quality.
- The method explicitly computes numerical gradients for faster convergence compared to finite differences.

### 2. Mathematical Specification

#### 2.1 Variables
- \(h = (h_1, h_2, \ldots, h_{n}\): step function values on grid \([0, 2]\) with \(n\) points.
- \(t\): variable representing the maximum overlap value.
- \(dx = 2.0/n\): grid spacing.

#### 2.2 Objective
Minimize:
\[
\min t
\s.t. \max_k \left( \sum_{i=0}^{n-1} h_i \cdot (1 - h_{\text{mod}(i+k,n)}) \cdot dx \right) \leq t
\]
where \(k\) ranges over \([-n+1, n-1]\) and indices are circular modulo \(n\).

#### 2.3 Constraints
- Box constraints: \(0 \leq h_i \leq 1\) for all \(i\)

1. Start at base grid size \(n_0\)

\[
