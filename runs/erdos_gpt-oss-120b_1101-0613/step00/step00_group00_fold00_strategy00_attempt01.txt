1. Approach and rationale
   The current parent construction is already a good local optimum of a finite-grid discretization of the Erdős one-dimensional minimum-overlap problem.  The main obstruction to improving the bound is that the objective is a finite maximum over roughly `2n-1` quadratic functions of `h`, subject to a single global equality and box constraints.  A plain CVXPY fit of the full product expression is not convex, and an unconstrained local optimizer without a global sum constraint would drift away from the required integral.

   The proposed program follows one coherent primary approach: use a smooth minimax surrogate, specifically a log-sum-exp approximation to the maximum lag value, minimize it with equality and box constraints using a local constrained nonlinear optimizer (`scipy.optimize.minimize`, preferably SLSQP), and compare every candidate only by the authoritative evaluator `max(np.correlate(h, 1-h, mode="full")) * dx`.  This replaces the nonsmooth finite maximum by a smooth family that becomes increasingly sharp over a schedule, while preserving the original objective through independent exact evaluation.  The objective is nonconvex, and the method cannot guarantee global optimality; it is intended to move a supplied high-quality parent point, or a diverse set of starting points in its basin, slightly below the present bound.

   The main improvements are made on resolutions tied to the supplied parent, especially the representative length around `45`, and a modest transfer to larger grids up to a controlled maximum.  Larger grids can help smoothing and interpolation, but returning very long arrays is discouraged; therefore candidates that seem stable are transferred back to smaller grids, and ties are decided in favor of smaller `n`.  If no parent is available, deterministic binary periodic/wave-like constructions are repaired to exact constraints and refined by the same local optimizer.

   Correctness facts:
   - The evaluator is linear finite-support correlation of `h` and `1-h`, not circular autocorrelation.
   - The maximum must be taken over all `2n-1` output lags.
   - `sum(h)` must equal `n/2`; boundary and single-point residual effects are preserved exactly because every candidate is scored using the evaluator itself.
   - The surrogate is only used for directions; improvement is accepted only when the exact evaluator improves.
   - The resulting vector must satisfy `0 <= h_i <= 1` and the sum constraint as floating point, using explicit repair and excluded invalid proposals.

   Hypotheses being explored:
   - A parent dominated by a few active lags can benefit from optimizing a smooth surrogate over a schedule of smoothing parameters.
   - Transferring a parent to a slightly finer grid releases the discrete equality and boundary stiffness and allows small improvements after reconstraining the exact problem.
   - Binary periodic starting structures and low-frequency perturbations are useful because the arithmetic mean of overlap constraints strongly penalizes too much mass self-overlap.

   This plan explicitly does not claim that any found vector is globally optimal on the continuous problem.  It returns a feasible candidate whose exact evaluator value is the returned upper bound.

2. Mathematical specification

   Let `n = n_points`.  The grid constant is
   `dx = 2.0 / n`.
   Let `m = n / 2`, so
   `sum_i h[i]` must equal `m`.

   For a given output index `k`, where `k = 0, ... , 2n-2`, the evaluator's unnormalized correlation entry is exactly the scalar quadratic function
   `G_k(h) = sum` over all integer subscripts inside both length-`n` arrays of
   `h_i * (1 - h_j)`,
   and the coefficient `dx` is multiplied outside.

   With the lag
   `d = k - (n - 1)`, the same entry can be written as
   `G_d(h) = sum` over the valid left indices `i` satisfying `0 <= i <= n-1` and `0 <= i+d <= n-1` of
   `h_i * (1-h_{i+d})`.
   Hence the scaled candidate value is
   `C_k(h) = dx * G_k(h)`,
   and the true minimum-overlap value assumed by the objective is
   `C5(h) = max_k C_k(h)`.

   The constraints are:
   - `0 <= h_i <= 1` for all `i`;
   - `sum_i h_i = m = n/2`;
   - finite real values.

   Derivative.  The derivative of the evaluator's unnormalized term is derived by differentiating `h_i(1-h_j)`, with `j=i+d`.  For one fixed lag `d`, a valid pair contributes an increment of `1 - h_j` to coordinate `i` and `-h_i` to coordinate `j`.  Those contributions are weighted by the scaling `dx`.  For the pair case with nonzero `d`, coordinate `i` is in the left range `[s,e]`, where
   `s = max(0, -d)` and `e = min(n-1, n-1-d)`.  For `d = 0`, both the positive and negative contributions apply to the same coordinate, yielding the correct local derivative `dx * (1 - 2 h_i)` when shifted to scaled objective.

   Because `C5` is a pointwise maximum, a generalized minimizer direction uses a convex combination of gradients of active or near-active lags.  A nonsmooth subgradient method is unstable.  Therefore use the log-sum-exp surrogate.

   Define a positive smoothing value
   `tau(h)` or a fixed per-solve parameter `tau > 0`.
   With `beta = 1/tau`, define
   `Phi_tau(h) = (1/beta) sum_{k=0}^{2n-2} exp(beta C_k(h))`.
   More numerically, compute `Cmax = max_k C_k`, form centered exponent claims `beta*(C_k-Cmax)`, then stabilize the log-sum.
   The gradient of the full log sum is
   `∇Phi_tau(h) = sum_k W_k * ∇C_k(h)`,
   where
   `W_k = exp(beta*C_k) / sum imply beta*C`,
   after exponent cancellation.  If numerical underflow is avoided by subtracting `Cmax`, use
   `W_k = exp(beta*(C_k-Cmax)) / sum that expression`.  The gradient normalizes automatically; adding a positive beta to a padded denom doesn't change the direction unless it is simply rescaled.

   As `tau -> 0`, `Phi_tau -> max_k C_k`.  A schedule beginning with moderate `tau` and ending with small `tau` decreases bias toward multiple lower lags.  If weights below a numerical threshold are dropped, define the objective and gradient from the same retained set whenever possible.  In implementation this is safe if the thresholds correspond only to numerical underflow size.

   Feasibility.  Optimize directly over `h` under SLSQP constraints exactly as they appear in the final discrete problem, rather than using a crude `clip` and rescaling.

   For starting vectors and post-solver repair, use a capped simplex projection: solve uniquely for `lambda` such that
   `sum_i clip(h_i - lambda, 0, 1) = m`.
   Because `s(lambda) = sum_i clip(x_i - lambda, 0, 1)` is continuous nonincreasing, bisection with bounds
   `low = min_i x_i - 1`,
   `high = max_i x_i`,
   is sufficient.  The interval contains the desired result if `0 < m < n`.  After the final projection, chirp check the summation and add/subtract an extremely small residual by proportional transfer over variables with room.  This maintains `[0,1]`.  Since floating point can still accumulate last bit feedback, the final code can also set a final balance coordinate if it has room; target strict tolerance must not exceed an acceptable floating evaluation tolerance, extremely small residual is notued precise because the score is generated by `np.correlate` values, but the program should try to make residual on the order of machine epsilon times `n`.
