**Goal** – Produce a step‑function `h` on `[0,2]` (discretised) with values in `[0,1]`, total mass `∫h=1`, that minimizes  

\[
C_5(h)=\max_{k}\; \int_0^2 h(x)\bigl(1-h(x+k)\bigr)\,dx .
\]

The strategy is a *convex‑smoothing + accelerated gradient* pipeline that evaluates all shifts simultaneously by FFT, avoids stochastic heuristics, and finishes with a fast combinatorial polishing. It is fundamentally different from the simulated‑annealing / LP approach used earlier.

--------------------------------------------------------------------
### 1. Discretisation and notation
* Choose a power‑of‑two grid size `N = 256` (any even `N` works, 256 gives `dx = 2/N ≈ 0.0078`).  
* Let `h ∈ ℝ^N` be the vector of sample values (ordered from `x=0` to `x=2‑dx`).  
* Box constraints: `0 ≤ h_i ≤ 1`.  
* Mass constraint: `∑_{i=0}^{N‑1} h_i = N/2` (exactly half the entries sum to `1`).

All later formulas use this discretisation; multiplying by `dx` converts sums to integrals.

--------------------------------------------------------------------
### 2. Linear functionals and smooth max
For a shift `k` (non‑negative integer, `0 ≤ k ≤ N‑1`) define the linear functional  

\[
f_k(h) = \sum_{i=0}^{N-1} h_i\;\bigl(1-h_{i+k}\bigr),
\qquad
h_{i+k}=0\; \text{if } i+k\ge N .
\]

(If `i+k` exceeds the array length the term is zero – this implements the “zero‑padding” used by the original correlation.)

`C_5(h) = max_k f_k(h)`.  
Each `f_k` is affine in `h` (the product term is linear in `h_i` because `h_{i+k}` is a *different* variable), therefore the pointwise maximum of the `f_k` is a **convex** function of `h`.  

To obtain a differentiable surrogate we use the *log‑sum‑exp* smoothing  

\[
F_\tau(h) = \tau \,\log\Bigl(\sum_{k=0}^{N-1} \exp\bigl(f_k(h)/\tau\bigr)\Bigr),
\]

with smoothing parameter `τ>0`. As `τ → 0` we have `F_τ(h) → max_k f_k(h) = C_5(h)`. For any `τ`, `F_τ` is convex and **smooth**, with gradient  

\[
\nabla F_\tau (h) = \sum_{k=0}^{N-1} p_k(\tau,h)\;
\bigl[(1-h_{i+k}) - h_{i-k}\bigr]_{i},
\qquad
p_k = \frac{\exp(f_k/\tau)}{\sum_j \exp(f_j/\tau)} .
\]

Thus the gradient is a weighted sum of simple shift‑difference vectors; the weights `p_k` form a probability distribution over shifts.

--------------------------------------------------------------------
### 3. Fast evaluation of all `f_k` by FFT
Define the zero‑padded vectors  

```
h_pad   = [h, 0,…,0]      length = 2N
g_pad   = [1‑h, 0,…,0]    length = 2N
```

The linear convolution `c = h_pad * g_pad` (computed with a real FFT of length `2N`) yields  

```
c[k] = Σ_i h_i * (1‑h_{i+k})   for k = 0,…,N‑1 .
```

Hence  

```
f = c[:N]                # vector of all f_k
```

Complexity: `O(N log N)` per evaluation, negligible for `N=256`.

--------------------------------------------------------------------
### 4. Gradient via weighted convolution
Let `p` be the vector of weights `p_k`. Write  

```
w1 = convolution(p, 1‑h)   (zero‑padded, length 2N, keep first N entries)
w2 = convolution(p_rev, h)   (p_rev[k] = p[N‑k] )
∇F = w1[:N]  –  w2[:N]
```

Both convolutions use the same FFT length `2N`. This yields the exact gradient of `F_τ` in `O(N log N)`.

--------------------------------------------------------------------
### 5. Projection onto the feasible set (box + sum)
We need `Π_Ω(v)` where  

```
Ω = { h ∈ ℝ^N : 0 ≤ h_i ≤ 1 , Σ h_i = N/2 } .
```

**Projection algorithm (water‑filling with bounds)**  

1. Clip `v` to `[0,1]` → `z`.  
2. Compute residual `r = N/2 - Σ z`.  
3. Let `I = { i : 0 < z_i < 1 }` (interior indices).  
4. If `|I|>0`, distribute `r` uniformly over `I`: `z_i ← z_i + r/|I|`.  
5. After the update, some interior values may have hit `0` or `1`.  
6. Repeat steps 2‑5 until `|r|` is below `1e‑12` (at most a few iterations because each repeat reduces the interior set).  

The algorithm runs in `O(N)` and always returns the Euclidean projection onto `Ω`.

--------------------------------------------------------------------
### 6. Accelerated projected gradient descent (Nesterov)
We minimise `F_τ` over `Ω`. The algorithm proceeds in *outer* stages where `τ` is reduced, and *inner* iterations of Nesterov steps.

**Parameters (tuned empirically)**
* `τ_start = 0.05` (≈ 5 % of typical `C_5` values).  
* `τ_factor = 0.5` (geometric decay).  
* `outer_cycles = 6` → final `τ ≈ 0.00078`.  
* In each outer stage perform `inner_iters = 150` Nesterov updates (or stop early if change < `1e‑9`).  
* Step‑size `α` chosen by simple back‑tracking line search on `F_τ` (starting from `α = 1.0`). Because `F_τ` is smooth with Lipschitz constant roughly `L ≈ (max f_k)/τ`, the line search converges quickly.

**Nesterov update (for iteration t)**
1. `y = h_t + β_t (h_t - h_{t‑1})`   with `β_t = (t‑1)/(t+2)`.  
2. Compute `∇F_τ(y)` using the FFT pipeline (Sections 3‑4).  
3. Gradient step: `z = y - α∇F_τ(y)`.  
4. Project: `h_{t+1} = Π_Ω(z)`.  

At the end of an outer stage we set `h_0 ← h_T` (the last iterate) and halve `τ`. The continuation scheme preserves progress while gradually sharpening the approximation to the true max.

**Why this works** – `F_τ` is convex; Nesterov’s method gives an `O(1/t²)` convergence rate for smooth convex problems, far faster than plain subgradient or SLSQP on the nondifferentiable original objective.

--------------------------------------------------------------------
### 7. Rounding to a binary (or near‑binary) feasible vector
When the outer loop finishes, `h` is already close to an extreme point of `Ω`. To obtain a *step* function that can be evaluated exactly by the original `c5_of_h`:

1. **Thresholding** – Sort indices by `h_i`. Set the `N/2` largest entries to `1`, the rest to `0`.  
2. **Feasibility check** – This binary vector automatically satisfies the sum constraint.  
3. **Optional fractional correction** – If the smoothing left many entries near `0.5`, we may keep up to four fractional entries to fine‑tune the sum (the original problem permits non‑binary values). This is done by solving a tiny linear program: keep the binary pattern, treat selected borderline indices as continuous variables with box constraints, enforce the sum exactly, and minimise the true `C_5`. The LP has at most 8 variables and can be solved instantly with `cvxpy`/`ECOS`.

--------------------------------------------------------------------
### 8. Local combinatorial polishing (swap hill‑climbing)
The rounded binary mask may still be improvable. We apply a fast **swap search** that repeatedly attempts to exchange a `1`‑position `i` with a `0`‑position `j`:

* Compute the full linear correlation `c = h * (1‑h)` (again via FFT) and the current maximal value `C = max(c)`.  
* For a candidate swap `(i,j)`, the correlation change can be updated in `O(N)` by recomputing only the rows/columns affected (or simply recompute the whole correlation – cheap for `N=256`).  
* Accept the swap if it reduces `C`.  
* Iterate until a full sweep over a random sample of `S = 5000` swaps yields no improvement, or until the allocated time slice (`≈ 80 s`) expires.

Because the objective is the *maximum* of a set of linear forms, any improvement must reduce the worst‑case shift; this greedy search quickly converges to a local optimum that is usually global for binary masks of this size.

--------------------------------------------------------------------
### 9. Multi‑resolution refinement (optional)
If time permits after polishing:

1. **Upsample** the binary mask to `N_high = 512` by linear interpolation (or by repeating each sample twice).  
2. Renormalise to satisfy the mass constraint (`∑ h = N_high/2`).  
3. Run a short **SLSQP** (or a few more Nesterov steps with `τ = 1e‑4`) on the high‑resolution vector.  
4. Project back to the feasible set after each iteration.

The extra resolution allows fine repositioning of the block edges, typically shaving a few `10⁻⁴` off the final `C_5`.

If the budget ends mid‑stage, the algorithm immediately returns the best `h` produced so far (the current iterate of the outer loop, already feasible after projection).

### 12. Complete algorithm (pseudo‑code)

```
def run(seed=42, budget_s=600):
    set_random_seed(seed)
    start = time.time()
    N = 256                     # base resolution
    h = random_binary(N, N/2)   # half ones, half zeros
    h = project_onto_Ω(h)       # ensure feasibility

    τ = 0.05
    for outer in range(6):
        α = 1.0                 # initial step size
        h_prev = h.copy()
        for t in range(150):
            y = h + ((t-1)/(t+2)) * (h - h_prev)   # Nesterov extrapolation
            f = correlation_fft(y)                 # O(N log N)
            p = np.exp(f/τ - np.max(f/τ))          # stable softmax
            p /= p.sum()
            grad = weighted_gradient_fft(y, p)    # Sections 3‑4
            # back‑tracking line search
            while True:
                z = y - α * grad
                z_proj = project_onto_Ω(z)
                if Fτ(z_proj, τ) <= Fτ(y, τ) - 0.5*α*np.dot(grad, grad):
                    break
                α *= 0.5
            h_new = z_proj
            h_prev, h = h, h_new
            if time.time() - start > budget_s - 30: break
        τ *= 0.5
        if time.time() - start > budget_s - 30: break

    # ---- rounding & tiny LP ----
    h_bin = binary_from_top(h, N//2)                # step 7.1
    # optional fractional correction via 8‑var LP
    h_refined = fractional_correction(h_bin)

    # ---- swap hill‑climbing ----
    best_h = h_refined
    best_c5 = c5_of_h(best_h)
    while time.time() - start < budget_s - 80:
        i, j = random_one_zero_pair(best_h)
        cand = swap(best_h, i, j)
        cand_c5 = c5_of_h(cand)
        if cand_c5 < best_c5 - 1e‑7:
            best_h, best_c5 = cand, cand_c5

    # ---- optional up‑sampling & SLSQP ----
    if time.time() - start < budget_s - 5:
        h_up = upsample(best_h, 512)
        h_up = project_onto_Ω(h_up)
        res = scipy.optimize.minimize(
                fun=lambda x: c5_of_h(x),
                x0=h_up,
                method='SLSQP',
                bounds=[(0,1)]*512,
                constraints={'type':'eq','fun':lambda x: np.sum(x)-256},
                options={'maxiter':100,'ftol':1e-9})
        final_h = res.x
        final_c5 = c5_of_h(final_h)
        if final_c5 < best_c5:
            best_h, best_c5 = final_h, final_c5
        n_points = len(final_h)
    else:
        n_points = N

    return (best_h, best_c5, n_points)
```

All sub‑routines (`correlation_fft`, `weighted_gradient_fft`, `project_onto_Ω`, `binary_from_top`, `fractional_correction`, `swap`, `upsample`) are straightforward implementations using `numpy` and `scipy.fft`. No file or network I/O is required, and the total wall‑clock time respects the `budget_s` limit.
