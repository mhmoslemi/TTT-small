**Overview**  
The core of the Erdős C₅ problem is a max‑min quadratic objective:  
\(C_5(h)=\displaystyle\max_{k}\int_0^2 h(x)\bigl(1-h(x+k)\bigr)\,dx\)  
with \(\int_0^2h=1,\;0\le h\le1\).  The integrand is linear in \(h\) once the quadratic term \(\int h(x)h(x+k)\) is isolated:
\(C_5=2/n-\frac{2}{n}\min_{k\neq0}\sum_i h_i\,h_{i+k}\).
Thus we must **maximise the minimum autocorrelation** of the sampled vector \(h\).

Instead of working directly in the high‑dimensional space of all samples (as previous SLSQP/gradient/LP approaches do), we **reduce the design space to a low‑dimensional parametric family of piecewise‑constant (step) functions**.  The parameters are block lengths and heights.  With only a handful of blocks we can explore the global landscape exhaustively, obtain a high‑quality shape, and then lift it to a fine discretisation for a final local polish.  The method consists of three stages:

1. **Parametric block model and analytic evaluation**  
2. **Global black‑box optimisation of the block parameters**  
3. **Fine discretisation + local refinement**

Each stage is equipped with fast feasibility handling and strict time‑budget monitoring.

### 1. Parametric block model

* **Structure** – Choose an integer \(K\ge4\) (e.g. \(K=6\)).  The interval \([0,2]\) is split into \(K\) contiguous blocks.  Block \(b\) has length \(\ell_b>0\) and constant height \(h_b\in[0,1]\).  The vectors of lengths \(\boldsymbol\ell\) and heights \(\mathbf{h}\) uniquely define a step function:
  \[
  h(x)=h_b\quad\text{for }x\in\Bigl[\sum_{j< b}\ell_j,\;\sum_{j\le b}\ell_j\Bigr).
  \]

* **Constraints** – Two equalities must hold:
  * **Length sum**: \(\sum_{b=1}^K\ell_b=2\).  
  * **Integral**: \(\sum_{b=1}^K h_b\,\ell_b=1\).  

  Both are enforced by a **simple re‑parameterisation**:
  * Let raw variables \(u_b\in\mathbb{R}\).  Define \(\ell_b = 2\,\frac{e^{u_b}}{\sum_{j=1}^K e^{u_j}}\).  This guarantees positivity and the length sum automatically.
  * Let raw variables \(v_b\in\mathbb{R}\).  Define provisional heights \(\tilde h_b = \frac{1}{1+e^{-v_b}}\in(0,1)\).  The integral constraint is imposed by solving for a scaling factor \(\alpha>0\):
    \[
    \alpha = \frac{1}{\sum_{b=1}^K \tilde h_b\ell_b},\qquad h_b = \min\bigl(1,\;\alpha \tilde h_b\bigr).
    \]
    After scaling, if any height hits the upper bound 1 the remaining sum deficit is redistributed by re‑scaling the still‑free heights (a few Newton iterations converge quickly).  The resulting \(\mathbf{h}\) satisfies the integral exactly while respecting the box bound.

* **Analytic autocorrelation** – For a given shift \(s\ge0\) the product \(\int h(x)h(x+s)\) decomposes into a sum over block pairs:
  \[
  \Phi(s)=\sum_{a=1}^K\sum_{b=1}^K h_a h_b \, \bigl|\;I_a\cap(I_b-s)\;\bigr|,
  \]
  where \(I_a\) is the interval of block \(a\) and \(|\cdot|\) denotes interval length (zero if disjoint).  Because each block is an interval, \(|I_a\cap(I_b-s)|\) is a simple piecewise‑linear function of \(s\) computed by:
  \[
  \max\bigl(0,\,\min(r_a,r_b-s)-\max(l_a,l_b-s)\bigr),
  \]
  with \(l_a,r_a\) the left/right endpoints of block \(a\).  For a fixed parameter set we can evaluate \(\Phi(s)\) for all discrete shifts \(s_k = k\Delta\) (where \(\Delta = 2/n_{\text{eval}}\)) by a **double loop over blocks** (cost \(O(K^2)\) per shift) or, more efficiently, by pre‑computing the break‑points where the overlapping pattern changes (at most \(2K\) per pair).  The total cost of evaluating the full max‑overlap over all shifts is therefore \(O(K^3)\), negligible for \(K\le8\).

* **Objective** – With \(\Delta=2/n_{\text{eval}}\) the discrete overlap for shift \(k\) is
  \[
  I_k = \Delta\Bigl(1-\Phi(s_k)\Bigr).
  \]
  The block‑level “C₅” value is \(C_{\text{blk}} = \max_k I_k\).  This is the quantity fed to the global optimiser.

---

### 2. Global optimisation of block parameters

* **Search space** – The raw vectors \(\mathbf{u}\in\mathbb{R}^K\) (lengths) and \(\mathbf{v}\in\mathbb{R}^K\) (heights) provide a smooth, unconstrained domain for any optimiser.  The transformation guarantees feasibility, so the optimiser never sees an infeasible point.

* **Algorithm choice** – Use a **population‑based black‑box optimiser** that excels in non‑convex, non‑smooth landscapes: **CMA‑ES** (Covariance Matrix Adaptation Evolution Strategy) or **Differential Evolution (DE)** from SciPy.  Both require only the objective function value, no gradients, and automatically handle scaling.  CMA‑ES is preferred for its self‑adaptive step‑size, but DE is acceptable if solvers are limited.

* **Population size & stopping** – Set population size to \(10\!\times\!K\) (e.g. 60 for \(K=6\)).  Use the global time budget \(T_{\text{budget}}\) split as follows:
  * **Stage A (global search)**: up to 30 % of the total time.  
  * Stop early if a candidate achieves \(C_{\text{blk}}<0.3807\) (the target bound).

* **Evaluation speed tricks** –  
  * Pre‑compute block endpoint cumulative sums each time a candidate is decoded.  
  * Use a modest shift resolution, e.g. \(n_{\text{eval}}=200\) (Δ≈0.01).  This over‑approximates the true max‑overlap; any candidate passing the bound at this resolution is re‑checked later on a finer grid.  
  * Vectorise the double‑loop over blocks with NumPy broadcasting to keep per‑candidate runtime well below a millisecond.

* **Diversity encouragement** – If the population’s best fitness stagnates for >5 seconds, inject a few **random re‑starts** (draw fresh \(\mathbf{u,v}\) from a normal distribution) to escape plateaus.

* **Result extraction** – Keep the best raw parameters \((\mathbf{u}^{*},\mathbf{v}^{*})\) and the corresponding block description \(\{(\ell_b,h_b)\}_{b=1}^K\).  Verify the true continuous‑grid C₅ by evaluating on a finer shift grid (e.g. \(n_{\text{eval}}=800\)).  If the finer evaluation yields a value still ≤ 0.3807, the search can be terminated early.

### 3. Fine discretisation and local polishing

* **Discretise** – Choose a target sample count \(n_{\text{fine}}\) (e.g. 400).  Build the vector \(h^{(0)}\in[0,1]^{n_{\text{fine}}}\) by assigning to each sample the height of the block that covers its coordinate.  By construction the integral is exactly 1 (since block areas sum to 1) and values respect the bounds.

* **Projection routine** – For any subsequent modification of \(h\) we enforce feasibility with an **efficient projection onto the simplex with box bounds**:
  1. Clip to \([0,1]\).  
  2. Compute the sum excess/deficit \(\delta = \frac{n_{\text{fine}}}{2} - \sum h\).  
  3. Add a constant \(\lambda\) to all entries, then re‑clip; adjust \(\lambda\) by a short bisection (≤20 iterations) so the final sum equals \(n_{\text{fine}}/2\).  This operation is \(O(n_{\text{fine}})\).

* **Local gradient‑descent on the worst shift** –  
  * Compute the full correlation \(c = \text{correlate}(h,1-h,\text{full})\) and locate the worst shift index \(k^\star\).  
  * The exact derivative of the worst‑shift integral w.r.t. element \(h_i\) is
    \[
    \frac{\partial I_{k^\star}}{\partial h_i}= \Delta\Bigl[(1-h_{i+k^\star})-h_{i-k^\star}\Bigr],
    \]
    with out‑of‑range indices treated as zero.  
  * Perform a **projected gradient step**: \(h\gets\Pi_{\mathcal{F}}\bigl(h - \alpha \nabla I_{k^\star}\bigr)\), where \(\Pi_{\mathcal{F}}\) is the projection above and \(\alpha\) is selected by a simple back‑tracking line search (initial \(\alpha=1\), halve until the true max‑overlap decreases).  
  * Re‑compute the worst shift after each successful step.  Iterate until improvement stalls or the allocated time for this stage (≈ 30 % of the budget) is exhausted.

* **Memetic refinement** – After the targeted gradient phase, run a short **hill‑climbing/coordinate‑swap** loop:
  * Randomly pick a pair of indices \((i,j)\) with \(h_i>0\) and \(h_j<1\).  
  * Transfer a tiny amount \(\delta = \min\{h_i, 1-h_j, 0.01\}\) from \(i\) to \(j\).  
  * Project, evaluate \(C_5\), and keep the change only if it improves the bound.  
  * Perform up to a few thousand such swaps or until the time limit is reached.

* **Optional “binary push”** – If the final vector still contains many fractional entries, add a small penalty \(\mu\sum_i h_i(1-h_i)\) to the objective and run a few more projected gradient steps with \(\mu\) gradually increased (e.g. \(\mu=10^{-4},10^{-3},10^{-2}\)).  This nudges the solution toward a 0/1 pattern without violating constraints.

* **Final validation** – Compute the exact \(C_5\) using the full correlation on the fine grid (no down‑sampling).  If the result is below the target 0.3807, store this vector as the best.  If not, retain the best vector found during earlier stages (the block‑level candidate already supplies a valid bound).

### Time‑budget management

| Phase | Approx. Share of Budget | Activity |
|------|------------------------|----------|
| 0. Setup & seed | ≤ 5 s | Initialise random seed, allocate arrays, pre‑compute constants. |
| 1. Global block optimisation (CMA‑ES / DE) | 0.30 × budget | Run population evolution, monitor best C₅, stop early if target reached. |
| 2. Fine discretisation & projection utilities | ≤ 5 s | Build \(h^{(0)}\), implement projection. |
| 3. Targeted projected gradient on worst shift | 0.30 × budget | Iterate until improvement stalls. |
| 4. Memetic swap hill‑climb + optional binary push | 0.30 × budget | Random swaps, penalty‑augmented gradient steps. |
| 5. Final evaluation & return | ≤ 5 s | Compute exact C₅, package output. |

At each phase the loop checks `time.time() - start` against the remaining budget and exits gracefully, guaranteeing a return before the timeout.

### Expected advantages over prior methods

* **Dimensionality reduction** – Optimising only a handful of block parameters (≈12 variables) avoids the curse of dimensionality faced by SLSQP on 300‑dimensional vectors.  Global optimisation becomes thorough, not reliant on local gradients.
* **Exact feasibility by construction** – Length‑softmax and height‑scaling guarantee that every sampled candidate automatically satisfies the integral and box constraints, eliminating costly projection inside the global optimiser.
* **Analytic autocorrelation** – Computing the objective in \(O(K^3)\) rather than \(O(n^2)\) per evaluation makes millions of candidate evaluations feasible, enabling a robust global search.
* **Hybrid refinement** – After obtaining a high‑quality block shape, a focused projected‑gradient on the worst shift drives the discrete representation toward the true min‑max optimum, a step absent from earlier hill‑climbs.
* **Flexibility** – The block count \(K\) can be raised if the global search uncovers a promising pattern that needs finer structure; the same pipeline scales without major code changes.
* **Deterministic back‑stop** – Even if the global search fails to beat the record, the subsequent gradient and swap phases will at least match (or improve) the SLSQP baseline because they start from a high‑quality seed.

### Failure‑mode mitigations

* **Stagnation in CMA‑ES** – Remedy by random restarts and by temporarily increasing the step‑size (`sigma`) if the evolution path indicates low variability.  
* **Projection drift** – The height‑scaling step may produce a few heights exactly at 1, breaking area balance; the iterative redistribution loop restores feasibility quickly; monitor the number of iterations and fallback to a simple water‑filling projection if needed.  
* **Numerical error in autocorrelation** – Use double precision and guard against negative overlap lengths (clamp to 0).  Re‑evaluate the best candidate on a finer shift grid as a safeguard.  
* **Time overrun** – All loops are wrapped with a `if time.time() - start > budget_s - safety_margin: break` guard; the safety margin (≈0.5 s) ensures a return before the kernel kills the process.
