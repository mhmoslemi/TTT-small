**Goal** – Find a discretised step‑function h on [0,2] (length n) with  
0 ≤ h[i] ≤ 1,  ∑ h[i] = n/2, that minimizes  

\[
C_5(h)=\max_k\int_0^2h(x)(1-h(x+k))dx

Because \(\int_0^2 h =1\),  

\[
C_5(h)=1-\min_k\;dx\;\sum_{i}h_i\,h_{i+k}
\]

so we want to **maximise the smallest auto‑correlation** of h.  
The optimisation is non‑convex (quadratic) and high‑dimensional; the plan below attacks it with a *global, gradient‑free* stage (CMA‑ES) followed by *local, gradient‑based polishing* that uses a smooth‑max surrogate. ### 1. Discretisation & fast objective evaluation
* Choose a modest size for the global stage: **n₁ = 150** (dx₁ = 2/n₁≈0.0133).  
* For the final refinement use **n₂ = 300** (dx₂ = 2/300≈0.006667).  
* Convolution is computed with the FFT for O(n log n) cost:  

  ```python
  H = np.fft.rfft(h, n=2*n-1)           # zero‑padded to length 2n‑1
  G = np.fft.rfft(1-h, n=2*n-1)
  conv = np.fft.irfft(H*G)[:2*n-1]     # linear correlation
  C5  = dx * np.max(conv)             
  ```

* **Early‑stop pruning** – while calculating the inverse FFT we can monitor the running maximum of `conv`; as soon as it exceeds the current best bound we abort the evaluation and discard the candidate (this saves time when many candidates are poor).

### 2. Constraint handling – projection onto the feasible set
A candidate vector **u** (real numbers) is turned into a feasible **h** by:

     \[

   - The operation is **exact** (the resulting h satisfies the equality and box constraints).

All optimisation stages use this projection after each mutation/replacement step.

### 3. Global search with **CMA‑ES** (Covariance Matrix Adaptation Evolution Strategy)

#### 3.1 Parameterisation

### 4. Local refinement – smooth‑max gradient descent (different from the earlier soft‑max on the original max‑overlap)
Now we directly minimise  

\[
F_\beta(h)=\frac{1}{\beta}\log\Bigl(\sum_{k=-n+1}^{n-1}
        \exp\bigl(\beta\,dx_2\,\operatorname{conv}_k(h)\bigr)\Bigr)
\]

with the *same* projection onto the feasible set after each step.

#### 4.1 Gradient formula (exact, vectorised)
For each shift k,
\[
\frac{\partial\,\operatorname{conv}_k}{\partial h_i}
    = (1-h_{i+k})\mathbf{1}_{0\le i+k<n}
      -h_{i-k}\mathbf{1}_{0\le i-k<n}.
\]
Compute all shifted versions of `h` with `np.pad` and obtain a (2n‑1) × n Jacobian *implicitly*:
```python
right = np.pad(1-h, (kmax,0))[:n]   # for all k>0 simultaneously via broadcasting
left  = np.pad(h, (0,kmax))[:n]
grad_per_k = right - left
```
The soft‑max weights are
\[
w_k=\frac{\exp(\beta dx_2\,\operatorname{conv}_k)}{\sum_t \exp(\beta dx_2\,\operatorname{conv}_t)} .
\]
The full gradient is  
\[
\nabla F_\beta = dx_2 \sum_k w_k \,\nabla\operatorname{conv}_k .
\]

All operations are vectorised; the cost per gradient evaluation is O(n log n) (FFT for `conv`) plus O(n²) for the Jacobian only if implemented naïvely.  We avoid the O(n²) term by exploiting the shift structure: the Jacobian for all k is a **Toeplitz** stack; we can compute the weighted sum efficiently by convolving `h` with the weight vector `w`:
\[
(\nabla F_\beta)_i
   = dx_2\Bigl( \sum_{k\ge0} w_k\,(1-h_{i+k}) - \sum_{k<0} w_k\,h_{i+k} \Bigr).
\]
These two sums are just *correlations* of `w` with `1-h` and `h`, calculable with two FFTs.
