\sum_{i=0}^{n-1}h_i=\frac{n}{2}, \qquad

### 1. Binary reformulation

Introduce a ±1 vector
\[
x_i = 2h_i-1\;\in\{-1,+1\},\qquad i=0,\dots ,n-1 .
\]
Then
\[
h_i=\frac{x_i+1}{2},\qquad
h_i h_{i+k}= \frac{1+x_i+x_{i+k}+x_i x_{i+k}}{4}.
\]

Insert into the correlation term:
\[
\sum_i h_i h_{i+k}
 =\frac{n}{4}+\frac12\sum_i x_i+\frac12\sum_i x_{i+k}
 +\frac14\sum_i x_i x_{i+k}.
\]
Because the total sum of the `x`‑entries must be zero (the `h`‑sum is `n/2`):
\[
\sum_i x_i =0 .
\]
Thus the shift‑dependent overlap simplifies to
\[
C(k)=\tfrac{n}{2}-\!\sum_i h_i h_{i+k}
      =\frac{n}{4}-\frac14\sum_i x_i x_{i+k}.
\]

Consequently,
\[
\boxed{C_5(h)=\frac{n}{4}-\frac14\;\min_{k}\;\sum_i x_i x_{i+k}} .
\]
Minimising `C_5` is equivalent to **maximising the minimum aperiodic autocorrelation**
\[
A_{\min}(x)=\min_{k}\sum_i x_i x_{i+k}.
\]

\[
\begin{aligned}
&\max_{x\in\{-1,1\}^n}\ \min_{k}\ \sum_i x_i x_{i+k}\\
&\text{s.t. }\sum_i x_i =0 .
\end{aligned}
\]

### 2. SDP relaxation

Define the matrix \(X = xx^{\!\top}\).  For any shift `k` let `S_k` be the \(n\times n\) **shift matrix**:
\[
(S_k)_{i,j}= \begin{cases}
1 & \text{if } j=i+k\ (\text{mod }n) \text{ and }0\le i,i+k<n,\\
0 & \text{otherwise.}
\end{cases}
\]
Then
\[
\sum_i x_i x_{i+k}= \operatorname{tr}(S_k X).
\]

Relax the binary constraints by allowing a **correlation matrix** \(X\) with
\[
X\succeq 0,\qquad X_{ii}=1,\qquad \operatorname{rank}(X)=1\ \text{(dropped)} .
\]
The zero‑sum condition becomes \(\mathbf{1}^{\!\top}x=0\), which in matrix form is
\[
\mathbf{1}^{\!\top}x=0\ \Longleftrightarrow\ \operatorname{tr}(\mathbf{1}\mathbf{1}^{\!\top} X)=0 .
\]
Since \(X\succeq0\) and all diagonal entries are 1, the only feasible way to have zero trace with the all‑ones matrix is to enforce
\[
\mathbf{1}^{\!\top}X\mathbf{1}=0 .
\]
This linear constraint forces the vector of row‑sums of `X` to be orthogonal to the all‑ones vector, which is a valid relaxation of \(\sum_i x_i=0\).

Introduce a scalar `t` representing the **worst‑case overlap**:
\[
t\ge C(k)=\frac{n}{4}-\frac14\operatorname{tr}(S_k X)\quad\forall k .
\]

All constraints are linear in `X` and `t`; the PSD cone makes the set convex.  The SDP reads

```
minimise    t
subject to  X ⪰ 0
            X_ii = 1            (∀ i)
            1ᵀ X 1 = 0          (zero‑sum relaxation)
            t ≥ n/4 - 0.25·tr(S_k X)   (∀ k ∈ K)
```

`K` is the set of shifts that can be the maximiser.  Empirically the worst shift lies near `k≈n/2`; we include all `k` with `|k| ≤ ⌊0.9 n⌋` (≈180 constraints for `n=200`).  The number of constraints is linear in `n`, while the PSD matrix is size `n×n`.  For `n≈200` this SDP is well within the capability of first‑order solvers (SCS, CVXOPT, or MOSEK if available) and solves in a few seconds.

**Symmetry reduction** – the optimal `h` can be taken centrally symmetric (`h(x)=h(2−x)`), which forces `x_i = x_{n-1-i}`.  We therefore keep only the first `⌈n/2⌉` variables and construct `X` as a block matrix, cutting the PSD dimension roughly in half (≈100).  This speeds the SDP dramatically.

### 4. Randomised Goemans‑Williamson rounding

From the optimal PSD matrix `X*` we generate a large pool of candidate binary vectors:

1. Perform a **Cholesky‑like factorisation** `X* = V Vᵀ` (e.g. via eigen‑decomposition; keep all eigenvectors, discarding tiny negative eigenvalues).  
2. For each sample:
   - Draw a standard Gaussian vector `g ∈ ℝ^m`.  
   - Compute `y = Vᵀ g`.  
   - Set `x_i = sign(y_i)` (breaking ties arbitrarily).  
   - Enforce the **zero‑sum** condition: compute current sum `s = Σ x_i`.  
     If `s≠0`, flip the `|s|/2` entries of smallest absolute `|y_i|` from `+1` to `‑1` (or vice‑versa) until the sum becomes zero.  
   - Map back to `h_i = (x_i+1)/2`.  
   - Because we used the symmetry reduction, reconstruct the full length‑`n` vector by mirroring the half‑vector.  

3. **Evaluate** the discrete `C_5` (`max correlation * dx`). Keep the best among, say, **200** samples (the pool size is limited by time).  

The rounding is provably within a constant factor of the SDP optimum for max‑cut‑type problems; empirically it yields binary vectors whose `C_5` is only a few percent above `t*·dx`.

### 5. Local binary refinement

The rounded vector is a high‑quality starting point but may still be improvable.  We run a **deterministic swap‑based hill‑climber**:

*Maintain*: the current binary vector `h`, its correlation array `c = correlate(h, 1‑h, mode='full')`, and the current best value `cmax`.

For a fixed budget (≈30 % of total time) repeat:
1. Randomly pick an index `i₁` with `h[i₁]=1` and an index `i₀` with `h[i₀]=0`.  
2. **Swap** them, yielding `h'`.  
3. **Update** the correlation efficiently: the swap alters only the rows/columns of the convolution that involve `i₁` and `i₀`.  Rather than recomputing the full convolution, we subtract the contributions of the old bits and add the contributions of the new bits using simple slice operations (`c += Δ`), which is `O(n)` per swap (n≈200).  
4. Compute `cmax' = max(c)`.  
5. If `cmax' < cmax` (i.e. new `C_5` smaller), **accept** the swap (`h←h'`, `c←c'`, `cmax←cmax'`). Otherwise **reject**.

Because each accepted move strictly improves the objective, the process converges to a local optimum of the discrete problem.  Empirically a few thousand successful swaps reduce the bound by an additional 0.001–0.003.

Optionally, after the hill‑climb we perform a **pairwise exchange of blocks** (swap two contiguous blocks of equal length) to escape shallow basins; we attempt these only if no improvement was seen for a full pass of single swaps.
