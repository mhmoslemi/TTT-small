These constraints are linear, so the whole model stays a **linear program (LP)**.

### 3. LP master problem (for a fixed set of shifts S)

Decision variables:
* \(w_i\) – independent h‑values (i = 0…d‑1), later mirrored.
* \(p_{i,k}\) for every \(k\in S\) and admissible i.
* Scalar \(M\) – the current upper bound on the overlap.

Constraints  

1. **Box:** \(0 ≤ w_i ≤ 1\).  
2. **Sum:** \(\displaystyle\sum_{i=0}^{d-1} w_i = n/4 + 0.5\).  
3. **McCormick:** as listed above for each \((i,k)\).  
4. **Overlap for each active shift:**  

   \[
   \bigl(\tfrac n2\bigr)-\sum_{i} p_{i,k} \;\le\; M, \qquad
   \forall k\in S .
   \]

   The left‑hand side is exactly the discrete overlap \(\int h(1-h^{(k)})\) after
   using the linearized products.

5. **Binary‑penalty (optional, linear):**  
   Introduce the term \(-\lambda\sum_i p_{i,0}\) into the objective.
   Since \(\sum_i w_i\) is constant, this term is equivalent to
   maximizing the sum of squares, which pushes each \(w_i\) toward 0 or 1.

**Objective**  

\[
\min\;  M \;-\;\lambda\sum_{i} p_{i,0},
\qquad \lambda>0\text{ (start small, increase later).}
\]

The LP provides a **lower bound** on the true \(C_5\) because the
McCormick envelope can overestimate the product; the bound is tightened
as more shifts are added.

---

### 4. Double‑oracle (cutting‑plane) loop

```
S ← {0}                     # start with the trivial shift
λ ← 0.1                     # modest binary push
bestC5 ← +∞
while time remaining > safety_margin:
    solve LP defined in §3
    recover full h by mirroring w_i
    evaluate exact C5(h) using np.correlate (full O(n²) is cheap for n=200)
    if C5(h) < bestC5:
         bestC5 ← C5(h); best_h ← h
    # termination test
    if C5(h) ≤ M + ε:     # LP bound matches true overlap within tolerance
         break
    # otherwise add the worst shift as a new cut
    k_max ← argmax_k C5_k(h)   # shift with maximal overlap
    S ← S ∪ {k_max}
    # gradually increase binary pressure to force integrality
    λ ← min(5.0, λ*1.5)
```

* **Complexity:** each iteration adds at most `n` new variables and four
  constraints per variable; with `|S|` kept modest (≤ 20) the LP stays well
  below 10 k variables and solves in < 0.1 s using `cvxpy` with the `ECOS`
  (or `GLOP`) solver.
* **Stopping criteria:**  
  – `ε = 1e‑6` ensures the LP bound is tight;  
  – a hard iteration cap (e.g., 50) protects the budget;  
  – if `|S|` exceeds 30 the loop terminates early and hands the current
    `best_h` to the polishing stage.

The loop is deterministic and yields a feasible \(h\) whose exact overlap
is at most a few 1e‑4 above the LP bound.

---

### 5. Polishing stage – projected subgradient descent

The LP solution is already near‑binary; a few gradient steps improve the true
max‑overlap.

* **Subgradient:** for the current worst shift \(k^\*\) (the one attaining
  \(C_5\)), the subgradient of \(C_5\) w.r.t. each full‑grid entry \(h_i\) is  

  \[
  g_i = (1-h_{i+k^\*})\mathbf{1}_{i+k^\*<n}
       -h_{i-k^\*}\mathbf{1}_{i-k^\*>0}.
  \]

* **Projected step:**  

  \[
  h \leftarrow \Pi_{\mathcal{F}}\bigl(h - \alpha g\bigr),
  \]

  where \(\Pi_{\mathcal{F}}\) projects onto the feasible set:
  1. Clip to \([0,1]\);  
  2. Enforce the sum \(\sum h_i=n/2\) by the standard *water‑filling* routine:
     repeatedly subtract the excess/deficit uniformly from all interior
     entries until the equality holds (finite‑termination because the set is a
     simplex intersected with a box).  
  3. Re‑symmetrise: \(h \leftarrow (h+h_{\rm rev})/2\).

* **Schedule:** start with step size \(\alpha=0.02\), decay geometrically
  (\(\alpha←0.9\,\alpha\)) and stop after either 200 iterations or when
  the improvement in \(C_5\) falls below \(1e‑6\).

This stage refines the bound to the true max‑overlap optimum for the
continuous problem, typically shaving a few \(10^{-4}\).

---

### 6. Final stochastic hill‑climb (optional)

If time remains (≈ 10 % of the budget):

1. Pick `p = min(6, n//20)` indices uniformly.
2. Add independent perturbations \(\delta\sim\mathcal{U}(-\epsilon,\epsilon)\) with
   \(\epsilon=0.003\); clip and re‑project as in §5.
3. Accept the move only if the exact \(C_5\) improves.
4. Every 40 accepted moves re‑symmetrise.

Because each move is cheap (single convolution), thousands of trials fit well
within the remaining seconds and often yield a final improvement of order
\(10^{-5}\).

### 8. Expected advantages over previous methods

* **Deterministic convergence:** the double‑oracle guarantees that when the
  LP bound matches the exact overlap, the solution is provably optimal for the
  current linear relaxation; this eliminates the stochastic variability of DE/CMA‑ES.
* **Low dimensionality via symmetry:** halving the variables and cuts dramatically
  reduces the LP size, allowing many iterations within the budget.
* **Explicit certificates:** each added shift yields an explicit linear
  constraint; the final set `S` can be inspected to understand which
  translations dominate the overlap.
* **Binary encouragement without full integer programming:** the linear penalty
  on \(\sum p_{i,0}\) steers the solution toward 0/1 values, avoiding the
  expensive MILP on the full grid used in earlier strategies.
* **Scalable to finer grids:** after a successful run on `n=200`, the same
  `h` can be interpolated to `n=300` (or any higher resolution) and
  re‑polished, exploiting the already‑good macroscopic shape.
