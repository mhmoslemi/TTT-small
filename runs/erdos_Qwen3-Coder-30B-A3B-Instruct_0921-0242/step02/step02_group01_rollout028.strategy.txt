**Goal**: Produce a step function h on [0,2] (discretized) with ∫h=1 and 0≤h≤1 that minimizes  
\(C_5=\max_k\int h(x)(1-h(x+k))dx\). We must return (h_values, c5_bound, n_points) within ~600 s, preferring ≤1 k points.

**Key observations**
1. The objective is the maximum correlation of h with its complement over all integer shifts (in the discretization).  
2. The constraint ∑h = n/2 (since total length 2, dx=2/n) is linear; the box constraints are simple.
3. The problem is a non‑convex quadratic program: maximize a convex piecewise‑linear function (the max of many linear forms in the quadratic term h·(1‑h shifted)). Global optimum is unknown, but good local minima can be found via tailored heuristics.

**Algorithmic plan**
We will combine three complementary methods:

1. **Deterministic convex‑relaxation + rounding**  
   - Relax h to continuous variables with the same constraints and replace the max‑over‑shifts by an auxiliary variable t with constraints  
     \(t \ge \sum_i h_i(1-h_{i+k})dx\) for each shift k.  
   - This yields a convex problem (linear constraints, quadratic terms with a negative sign? Actually each term is bilinear h_i * (1‑h_{i+k}) = h_i - h_i h_{i+k}; the quadratic part –h_i h_{i+k} is concave, making the constraint convex because we require t ≥ linear - concave, which is not convex. So we cannot solve directly with CVX.  
   - Instead we linearize the concave product using McCormick envelopes with auxiliary variables w_{i,k}=h_i h_{i+k}. This gives a mixed‑integer linear relaxation (MILP) after binary approximation of h. Too heavy for time.

   Therefore we will **not** rely on pure convex solvers; they are ineffective here.

2. **Gradient‑based local search on the worst shift** (similar to previous code but improved)
   - For a given h we compute all shift correlation values C(k)=dx·∑_i h_i (1‑h_{i+k}). Identify the worst shift k\* = argmax C(k).  
   - The objective is locally the value C(k\*). Its subgradient w.r.t. h is:  
     ∂C/∂h_i = dx·[(1‑h_{i+k\*}) - h_{i‑k\*}] (mod n).  
   - Perform a projected gradient descent on the worst shift, with a diminishing step size α_t = α0 / sqrt(t). After each step project onto the feasible polytope (box + sum constraint) using a fast water‑filling algorithm (clip then adjust mean).  
   - Run this inner refinement for a fixed number of iterations (e.g., 200) starting from several seeds.

3. **Population‑based global search (Differential Evolution + occasional swaps)**
   - Maintain a modest population (e.g., 40 vectors).  
   - Use **Differential Evolution (DE)** with the classic “rand/1/bin” strategy: for each target vector x_i, pick three distinct vectors a,b,c, create donor v = a + F·(b‑c) (F≈0.6). Clip v to [0,1], then enforce sum constraint by scaling and water‑fill. Perform binomial crossover with CR≈0.9 to generate trial u. Evaluate C5(u); if better replace x_i.  
   - DE is cheap (O(pop·n·shifts)) because we can compute all C(k) via FFT (O(n log n)) per evaluation. With n≈500 the cost is small; we can afford ~5000 evaluations within budget.
   - Periodically (every 200 generations) inject a **local refinement**: run the gradient‑based worst‑shift descent on the current best individual, then replace it if improved.

4. **Fine‑grained stochastic “pair‑swap” polishing** (as in original code) but with adaptive delta.
   - After DE stops, take the best h and perform a simulated‑annealing style hill‑climb: repeatedly pick i,j and transfer a small amount δ from h_i to h_j while respecting bounds. Accept if C5 improves; otherwise accept with probability exp(-(Δ)/T) where temperature T decays geometrically. This helps escape shallow local plateaus.

**Implementation details**

- **Discretization size**: Start with n=400 (dx=0.005). This gives sufficient resolution while keeping FFT cheap. After obtaining a promising pattern, we will **refine** by interpolating to n=800 and performing a short local gradient descent to ensure the bound does not degrade with finer sampling.
- **FFT correlation**: Use `np.fft.rfft` for speed. Compute convolution of h and (1‑h) via element‑wise product of FFTs of length L = next power of two ≥ 2n. The correlation for shift k is the real part at index (k) after appropriate roll; we’ll extract the first n values (positive shifts) and ignore shift 0 (which equals ∫h(1‑h) ≤ 0.25).
- **Projection onto sum constraint**: Implement a function `proj_sum_box(x, target_sum)`:
  1. Clip x to [0,1].
  2. Compute excess = target_sum - sum(x).  
  3. If |excess| < tol, return.
  4. Add `excess / n` to all entries, clip again, repeat at most 2 times (standard water‑filling converges quickly because after first clip max/min are hit only a few times).  
  This is O(n) and deterministic.
- **Gradient descent parameters**: α0 = 0.1·dx, decay exponent 0.5. Stop when improvement <1e‑7 or after 200 iterations. After each inner loop compute full C5; if it drops, keep the new h as the refined best.
- **DE hyper‑parameters**:  
  *Population size* P = min(40, 2·n/10) ⇒ with n=400, P=40.  
  *F* = 0.6, *CR* = 0.9.  
  *Generations* = floor(budget / (eval_time·P)). Empirically eval_time≈0.001 s, so we can run ~4000 generations comfortably.
- **Time management**:  
  - Record start time.  
  - Loop DE until elapsed < 0.75·budget.  
  - Then run gradient refinement on the best for up to 0.15·budget.  
  - Finally run stochastic swap polishing for remaining time (<0.1·budget).  
  If budget is short (<30 s) we scale down P and iteration counts proportionally.

**Why this should improve over previous attempt**
- DE explores the search space more globally than PSO used before; its differential mutation exploits vector differences, often finding better basins for quadratic‑type objectives.
- The worst‑shift gradient descent is more mathematically grounded than the ad‑hoc backtracking line search; using a deterministic step schedule avoids wasted evaluations.
- Combining both provides a “memetic” algorithm: DE discovers promising structures, gradient refines them to the local optimum for the identified worst shift, and the final swap phase fine‑tunes the distribution of mass.
- The additional refinement at higher resolution (n=800) safeguards against discretization artefacts that may artificially lower C5 at coarser grids.

**Potential failure modes & mitigations**
- *Stagnation*: If DE population converges early, we re‑seed a fraction (10%) with random vectors respecting constraints.
- *Projection bias*: Repeated clipping can bias sum; the water‑filling routine ensures exact sum.
- *Numerical noise in FFT*: Use `np.real_if_close` and round negligible imaginary parts.
- *Time overflow*: All loops check elapsed time each iteration; break early if needed.
