### 1.  Reformulation of the objective

For a discretisation with `n` points (`dx = 2/n`) the overlap integral is  

\[
C_5(h)=\max_{k} \; \underbrace{dx\sum_{i=0}^{n-1}h_i\bigl(1-h_{i-k\bmod n}\bigr)}_{c_k}.
\]

Because \(\sum_i h_i=n/2\) is fixed,  

\[
c_k =dx\Bigl(\frac n2-\sum_{i}h_i\,h_{i-k}\Bigr)
      =dx\Bigl(\tfrac n2-\operatorname{autocorr}_k\Bigr),
\]

where \(\operatorname{autocorr}_k=\sum_i h_i h_{i-k}\).  
Thus **minimising** the maximal overlap is equivalent to **maximising the minimal periodic autocorrelation** of the sequence \(h\).

If we restrict \(h_i\in\{0,1\}\) (binary pattern) the problem becomes the classic construction of a binary sequence of length \(n\) with weight \(n/2\) that maximises \(\min_k\operatorname{autocorr}_k\).  After a good binary pattern is found we can soften the discontinuities (fractional ramps) to obtain a genuine step function and improve the bound further.

The plan therefore has three distinct stages:

1. **Binary optimisation by large‑scale simulated annealing** – fast, purely combinatorial, exploits FFT for exact autocorrelation.
2. **Boundary smoothing and projected gradient refinement** – converts the binary pattern into a continuous step function, adds a few fractional points, and performs a nonsmooth min‑max descent.
3. **Progressive up‑sampling** – double the resolution, interpolate the refined function and finish with a few gradient steps.

All stages are explicitly time‑controlled; the total wall‑clock is kept below the supplied budget.

### 2.  Core numerical primitives

* **FFT‑based autocorrelation**  
  For a real vector `h` of length `n` let  

  ```python
  H = np.fft.rfft(h, n)                     # rfft returns the half‑spectrum
  autocorr = np.fft.irfft(H * np.conj(H), n)  # real inverse FFT
  ```

  `autocorr` is exactly \(\sum_i h_i h_{i-k}\) for all integer shifts `k`.  
  The overlap vector is `c = dx * (n/2 - autocorr)`.  
  The current bound is `c.max()`.

* **Projection onto the feasible affine‑box**  
  After any continuous update we must enforce  

  \[
  0\le h_i\le 1,\qquad \sum_i h_i = n/2 .
  \]

  This is the “water‑filling” projection: clamp to \([0,1]\), compute the excess/surplus `d = n/2 - \sum h`, then shift all entries by a common amount `λ` (found by a short bisection) and finally renormalise if the shift pushed any component out of bounds.  The algorithm is \(\mathcal O(n)\) and numerically stable.

* **Gradient of the worst shift**  
  Let `k* = argmax_k c_k`.  The objective is  

  \[
  f(h)=c_{k*}=dx\Bigl(\frac n2-\sum_i h_i h_{i-k*}\Bigr).
  \]

  Its sub‑gradient is  

  \[
  \frac{\partial f}{\partial h_j}= -dx\bigl(h_{j-k*}+h_{j+k*}\bigr).
  \]

  Moving **against** this gradient (i.e. `h ← h + η·dx·(h_{j‑k*}+h_{j+k*})`) increases the autocorrelation at the worst shift and therefore reduces `f`.  The gradient is computed with two cyclic rolls – O(n) per iteration.

* **Smooth approximation of the max** (optional)  
  For the continuous refinement we may replace \(\max_k c_k\) by the log‑sum‑exp surrogate  

  \[
  f_{\gamma}(h)=\frac{1}{\gamma}\log\Bigl(\sum_k e^{\gamma c_k}\Bigr),
  \]

  whose gradient is a softmax‑weighted combination of the individual gradients.  With `γ≈10` the surrogate is tight while being smooth, enabling standard projected‑gradient steps with Nesterov momentum.

### 3.  Stage‑1 – Binary simulated annealing

**Parameters**  
* Choose a power‑of‑two `n` (e.g. 256) → FFT is optimal.  
* Temperature schedule: start `T0 = 5·dx` (roughly the size of an elementary correlation change) and decay multiplicatively `T←α·T` with `α≈0.9997` per 1 000 swaps.  

**Loop (time‑controlled)**  

1. Maintain the current binary pattern `h∈{0,1}ⁿ` and its autocorrelation `ac`.  
2. Pick uniformly at random an index `i` with `h_i=1` and `j` with `h_j=0`.  
3. Propose the swap `h' = h` with `h'_i=0, h'_j=1`.  
4. Update `ac` **exactly** by the formula  

   ```
   delta = -h_shift_i + h_shift_j          # vectors of length n
   # plus the constant self‑terms (+2 at shift 0, -1 at (i‑j) and (j‑i))
   ac' = ac + delta + self_terms
   ```

   (All operations are vectorised, O(n)).  
5. Compute the new bound `c'.max()`.  
6. Accept the swap if `c' ≤ c` or with probability `exp(-(c'‑c)/T)`.  
7. Update the best‑ever pattern whenever a lower bound is observed.  

Because the autocorrelation is recomputed via the cheap O(n) delta, a **single swap costs ≈ 0.3 µs** on a modern CPU, allowing > 10⁶ proposals within the 0.5 × budget window.  The stochastic acceptance prevents premature trapping and yields high‑quality binary patterns with `min_k autocorr_k` close to the theoretical optimum for the chosen `n`.

### 4.  Stage‑2 – Boundary smoothing & projected gradient

The binary optimum usually features many abrupt 0/1 jumps.  Introducing a *fractional ramp* of width `w` (1–3 sample points) at each transition reduces the worst correlation because the product `h_i·h_{i‑k}` is lowered when two ones are slightly mis‑aligned.

**Construction of a smoothed start**  

1. Scan the binary pattern; for each boundary `0→1` (or `1→0`) replace the step by a linear ramp:
   - For a `0→1` boundary at index `b`, set  

     \[
     h_{b+r}= \frac{r+1}{w+1},\qquad r=0,\dots,w,
     \]

     leaving the rest of the block unchanged.
2. The total sum changes by at most `w/2` per boundary; finally call `project_to_feasible` to restore the exact integral constraint.

**Projected gradient refinement**  

Now \(h\) is a genuine real‑valued step function.  We run a **sub‑gradient descent on the true max** (or on the smooth surrogate) :

```
while time remains:
    compute k* = argmax_k c_k
    g = -dx * (np.roll(h, k*) + np.roll(h, -k*))    # sub‑gradient
    η = backtracking_line_search(g)                # start η≈0.5, halve until improvement
    h ← h - η * g
    h ← project_to_feasible(h)
    update best if c.max() decreased
```

A plain backtracking line search converges in ≤ 30 inner evaluations because the objective is piecewise linear.  Typically 2 000–5 000 gradient steps suffice to push the bound down by 0.001–0.003 relative to the binary result.

Optionally, after every 100 steps we perform a **pairwise fractional swap** (move a tiny δ from a larger entry to a smaller one) to escape plateaus; acceptance is greedy.
