**Goal recap (in math)**  
For a discretised step‑function `h∈[0,1]^n` with `∑h = n/2` we have  

```
C5(h) = max_k ∫0^2 h(x)(1‑h(x+k))dx
      = 1 – (2/n)·min_s   γ_s ,   γ_s = Σ_i h[i]·h[i+s] .
```

Thus the task is **to maximise the smallest autocorrelation value**  
`γ_min = min_s γ_s`.  The bound is `C5 = 1 – (2/n)·γ_min`.  Any feasible `h`
must keep the total mass `∑h = n/2` and respect the box `0≤h[i]≤1`.

The proposed method departs from the earlier PSO / smooth‑max gradient
scheme.  It is a **stochastic, incremental local‑search** (simulated‑annealing‑style)
that works directly with the autocorrelation structure, using *exact O(n)*
updates for each proposal.  The search consists of three phases:

---

### 1.  Problem‑specific data structures

* **Length `n`** – Choose a modest size (e.g. `n = 250` or `300`).  This gives a
  grid spacing `dx = 2/n` and keeps per‑iteration work cheap.
* **State vectors**  
  - `h` – current feasible step function (float, not necessarily binary).  
  - `γ` – autocorrelation `γ = correlate(h, h, mode='full')` (length `2n‑1`).  
  - `C = 1 – (2/n)·γ` – the vector of overlap values; its maximum is `C5`.
* **Derived sets**  
  - `S_w = { s : C[s] ≥ C5 – ε }` – the *worst shifts* (ε a tiny tolerance,
    e.g. `1e‑5`).  All subsequent moves are guided by this set.

Both `h` and `γ` are kept consistent: after any accepted move we update
`γ` **incrementally** (see §3) and only recompute it from scratch
periodically to correct accumulated rounding error.

---

### 2.  Move generation – transferring a mass chunk

A move transfers a small amount `Δ∈(0,Δ_max]` from index `i` (source) to
index `j` (target) while preserving the total sum automatically.
The move respects the box constraints by choosing  

```
Δ ≤ min( h[i] , 1‑h[j] )
```

and by picking `i` only when `h[i] > η` and `j` only when `h[j] < 1‑η`
(`η` a tiny safety margin, e.g. `1e‑8`).  Two families of moves are used:

| Move type | Description | Typical Δ |
|-----------|-------------|-----------|
| **Binary swap** | `Δ = 1`, `h[i]=1→0`, `h[j]=0→1` (only when both are exactly 0/1). | 1 |
| **Fractional transfer** | `Δ` drawn uniformly from `[0, Δ_max]` (initially `Δ_max≈0.2`, later halved). | ≤ 0.2 |

The binary swap allows the algorithm to explore the combinatorial
search space of half‑filled 0/1 patterns (the classic “minimum‐autocorrelation”
problem).  Fractional transfers let the continuous optimiser fine‑tune a
promising binary skeleton.

---

### 3.  Exact O(n) update of the autocorrelation

For a transfer `Δ` from `i` to `j` the change in each autocorrelation entry
`γ_s` (shift `s` corresponds to index `s+n‑1`) is linear except for the
self‑term `s = 0`.  Let `ĥ` be the temporary vector **after** zeroing the
source (`ĥ[i]=0`, other components unchanged).  The contribution of a single
coordinate `p` to `γ` is the sum of `h[p]·h[p+s]` over all admissible `s`.
Therefore the exact update is:

```
for s = -(n‑1)…(n‑1):
    idx = s + n - 1
    # removal of Δ from i
    if 0 ≤ i+s < n:   Δγ[idx] -= Δ * ĥ[i+s]
    if 0 ≤ i‑s < n and s!=0: Δγ[idx] -= Δ * ĥ[i‑s]

    # addition of Δ to j
    if 0 ≤ j+s < n:   Δγ[idx] += Δ * ĥ[j+s]
    if 0 ≤ j‑s < n and s!=0: Δγ[idx] += Δ * ĥ[j‑s]

# self‑term (s = 0) – exact quadratic correction
Δγ[n‑1] += -2*h[i]*Δ + Δ*Δ + 2*h[j]*Δ + Δ*Δ
```

All accesses are simple index checks, so the whole loop runs in **O(n)**
time (≈ 300 operations).  After computing `Δγ` we obtain the tentative new
minimum autocorrelation:

```
γ_new = γ + Δγ
γ_min_new = min(γ_new)
C5_new = 1 - (2/n) * γ_min_new
```

Because `C5` depends only on `γ_min`, a single scan of `γ_new` suffices to
evaluate the proposal.

### 4.  Acceptance rule – simulated annealing

*Current* value: `C5_cur`.  
*Proposal* value: `C5_new`.

```
if C5_new < C5_cur:
    accept
else:
    accept with probability  exp( -(C5_new - C5_cur) / T )
```

The temperature `T` follows an exponential schedule  

```
T = T0 * α^iteration ,   0 < α < 1 .
```

`T0` is set to a fraction (≈0.3) of the initial spread
`C5_max – C5_min` of the randomly initialised state; `α` is chosen so that
the temperature decays to ≈10⁻⁴ after the allotted number of iterations
(e.g. `α = 0.9995` for ~200 000 steps).

The schedule is **adaptive**: every 5000 accepted moves the acceptance
ratio is measured; if it falls below 0.25 the temperature is increased by
20 % (to avoid premature freezing), otherwise it follows the base decay.

### 5.  Guided move selection (exploiting the worst shifts)

Simply picking random `i, j` is wasteful when the worst autocorrelation
entries are dominated by a few indices.  After each `γ` update we recompute
the set `S_w` of worst shifts (those whose `C` is within `ε = 1e‑5` of
`C5`).  For every index `p` we define a **score**

```
score[p] = Σ_{s∈S_w} ( h[p+s] + h[p‑s] )    (only terms inside the domain)
```

Intuitively, a large `score[p]` means that `p` contributes heavily to the
currently maximal overlap.  The move generator then:

1. **Select source** `i` among the top‑10 % highest scores with `h[i] > η`.
2. **Select target** `j` among the bottom‑10 % lowest scores with
   `h[j] < 1‑η`.
3. Pick `Δ` as described in §2 (large early, shrinking later).

This bias dramatically speeds convergence because each accepted move
directly attacks the dominant autocorrelation peaks.

### 7.  Projection onto the feasible set for continuous steps

All updates preserve the total sum by construction (Δ is transferred).
Only the box constraints may be violated by the line‑search in phase E.
We employ the **water‑filling projection**:

Given a tentative vector `y`, find `λ` such that  

```
x_i = clip( y_i – λ , 0 , 1 )      and   Σ x_i = n/2 .
```

`S(λ) = Σ_i clip(y_i – λ,0,1)` is monotone decreasing, so `λ` is obtained
by a fast bisection (≈ 40 iterations give double precision).  This routine
(`project_box_sum`) is used after each subgradient step.
