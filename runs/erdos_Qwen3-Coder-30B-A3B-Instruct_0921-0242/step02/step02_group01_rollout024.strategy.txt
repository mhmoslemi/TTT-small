**Goal** – Produce a step function h on [0, 2] (sampled uniformly) with  
∑ h dx = 1, 0 ≤ h ≤ 1 that minimises  

 C₅ = maxₖ ∫₀² h(x)·[1 − h(x + k)] dx.

The current best upper bound is ≈ 0.382.  The plan below uses a *smooth‑max surrogate* together with a quasi‑Newton optimiser (L‑BFGS‑B) and a homotopy on the smoothing parameter, followed by a deterministic worst‑shift refinement.  This differs fundamentally from PSO/DE/LP approaches and works directly with gradient information from **all** shifts at once.

### 1.  Discretisation & linear algebra

1. Choose a modest grid size  
   `n = 350`  (dx = 2/n ≈ 0.0057).  This keeps FFTs cheap while still giving a tight bound; later a finer upscale can be attempted if time permits.
2. Store the vector `h ∈ ℝⁿ`.  The integral constraints become  

   *Box*: 0 ≤ hᵢ ≤ 1.  
   *Sum*: ∑ᵢ hᵢ = n/2 ( because ∫h dx = 1 ⇒ ∑h·dx = 1).  

3. For any integer shift `k` (0 ≤ k < n) define the discrete overlap  

   ```
   C(k, h) = dx * ( Σ_i h_i  –  Σ_i h_i * h_{i+k} )
           = 1   –   dx * Σ_i h_i * h_{i+k}
   ```
   (indices outside 0…n‑1 are treated as zero – the “full’’ correlation used by `np.correlate`).

4. All convolutions Σ_i h_i h_{i+k} are obtained in **O(n log n)** by a single FFT:  

   ```
   H = fft(h, 2*n)                       # zero‑padded to length 2n
   corr = ifft( H * conj(H) ).real       # linear auto‑correlation, length 2n-1
   overlap[k] = dx * corr[k]   (0 ≤ k < n)
   ```

   The vector `C_vec = 1 - overlap` holds the values of the objective for every shift.

---

### 2.  Smooth approximation of the max‑operator

The true objective is `max(C_vec)`.  Replace it by the *p‑norm* (or log‑sum‑exp) which is smooth and differentiable:

```
S_p(h) = ( Σ_k C(k,h)^p )^(1/p)        ,   p  large (e.g. 20 … 200)
```

When `p → ∞`, `S_p` → `max C`.  For moderate `p` the landscape is much smoother, allowing gradient‑based optimisation.  A *continuation* (homotopy) strategy will start with a small `p` and increase it gradually, using the solution of the previous stage as the starting point for the next.

---

### 3.  Exact gradient of the smooth surrogate

For a fixed `p` the gradient of `S_p` w.r.t. `h_i` can be written analytically using the chain rule:

```
∂C(k)/∂h_i = dx * [ (1 - h_{i+k})  -  h_{i-k} ]        (indices out of bounds → 0)

Let w_k = C(k)^(p-1) .
∂S_p/∂h_i = (1 / S_p^(p-1)) * Σ_k w_k * ∂C(k)/∂h_i
```

All `∂C(k)/∂h_i` for a given `i` are obtained by two shifted copies of `h`:
* forward shift `h_{i+k}` (vector `h` rolled by `+k`),
* backward shift `h_{i-k}` (rolled by `‑k`).

Thus the full gradient is computed in **O(n log n + n p)**; with `p` ≤ 200 the cost is dominated by the FFT, negligible for `n≈350`.

---

### 4.  Handling the linear equality ∑h = n/2

Two simple alternatives:

* **Penalty method** – add `λ * ( Σh – n/2 )²` to the objective with a large λ (e.g. 10⁴).  The gradient contribution is `2λ * ( Σh – n/2 )` added uniformly to every component.
* **Affine reduction** – keep the last component dependent:  

  ```
  h_n = n/2 - Σ_{i=1}^{n-1} h_i
  ```

  Optimise only the first `n‑1` free variables; after each gradient evaluation recompute `h_n` and clip it to [0,1] (if it violates a bound the step is rejected).

The penalty approach is simpler to implement with `scipy.optimize.minimize` and works well because the optimizer quickly restores feasibility.

### 6.  Deterministic worst‑shift refinement (memetic step)

The smooth surrogate may leave a slight imbalance: a few shifts could be slightly larger than the rest.  Perform a **projected sub‑gradient ascent** on the *minimum* overlap (equivalently descent on `C₅`) focusing only on the *worst* shift:

1. Identify `k* = argmax_k C(k, h)`.
2. Gradient for that shift:  

   `g_i = dx * [ (1 - h_{i+k*}) - h_{i‑k*} ]`.
3. Take a step `h ← h - α·g` with a back‑tracking line search (α starts at `0.1·dx` and is halved until `C₅` decreases).
4. Project back onto `[0,1]` and enforce the sum (water‑filling: add/subtract the excess uniformly, clip, repeat once).
5. Iterate ≤ 100 times or until no improvement.  

Because the direction is exact for the active constraint, this phase typically reduces `C₅` by a few 10⁻⁴.

### 7.  Final stochastic polishing (optional)

* Accept if it improves, otherwise accept with probability `exp(-(Δ)/T)` where temperature `T` decays geometrically.  
* After each accepted move, re‑project the sum constraint (the transfer already preserves it).
