### 1. Discretisation and evaluation primitive
* Choose a modest but sufficiently fine grid:  
 **n = 400** (dx = 2/n = 0.005).  
* Correlation is computed by FFT for speed:
  1. Pad both vectors to length `2*n` (zero‑padding gives linear, not cyclic, convolution).  
  2. `c = ifft( fft(h,2*n) * conj( fft(1‑h,2*n) ) ).real[:2*n‑1]`.  
  3. `C5 = dx * max(c)`.  
  This routine (`eval_c5`) costs < 1 ms per call.

### 2. Symmetric piecewise‑constant representation

We enforce the (known from rearrangement) mirror symmetry `h(x)=h(2‑x)`.  
Only the left half **[0,1]** is stored; the right half is its mirror.

**Segments.**  
Pick an integer **M ≥ 5** (e.g. M = 7). The half‑interval is divided into M contiguous blocks, each having:
* a *width* `w_i > 0` (∑ w_i = 1),  
* a *height* `a_i ∈ [0,1]`.

The full function is built as:

```
h_half(x) = a_i   for x in the i‑th block (according to cumulative widths)
h_full   = [h_half , reverse(h_half)]
```

Thus the parameter vector has **2M** real numbers:
* raw widths `p_i` → actual widths via soft‑max: `w_i = exp(p_i)/∑exp(p)`.  
* raw heights `q_i` → actual heights via logistic: `a_i = 1/(1+exp(-q_i))`.

Both transformations guarantee the constraints automatically (positivity, sum‑to‑1 for widths, bound [0,1] for heights). The symmetry and exact integral are enforced later by a cheap projection.

**Integral constraint.**  
After constructing the discrete vector `h` (length n) we apply the same *water‑filling* projection used in the reference code:
1. Clip to [0,1].  
2. Compute current sum `S = Σ h`.  
3. If `S ≠ n/2`, distribute the deficit/excess uniformly among interior points that are not at a bound until the sum matches exactly.  
The projection is O(n) and preserves feasibility.

### 3. Black‑box optimisation with CMA‑ES

CMA‑ES (Covariance Matrix Adaptation Evolution Strategy) is a derivative‑free optimiser that excels on low‑to‑moderate‑dimensional continuous problems with non‑convex objectives.

**Setup**
* Dimension `D = 2*M` (e.g. D = 14).  
* Initial mean: choose a sensible starting shape – a block of height 1 covering the centre:
  * `p_i` set so that the middle three widths equal 0.3, the others share the remainder.  
  * `q_i` set to large positive for the middle heights (≈ 5, giving heights ≈ 0.993) and large negative for the outer heights (≈ ‑5, giving ≈ 0.007).  
* Initial step size σ = 0.3 (covers the whole feasible region after transformations).  
* Population size λ = 4 + ⌊3·log(D)⌋ (standard default).  

**Evaluation loop**
For each individual:
1. Transform `p, q` into widths `w` and heights `a`.  
2. Build the discrete symmetric vector `h` (length n) by filling the `n/2` points of the left half according to the segment widths (use cumulative sums to map indices to segments).  
3. Mirror to obtain full `h`.  
4. Project to the feasible polytope (clip + sum‑fix).  
5. Compute `C5 = eval_c5(h)`.  

The fitness is the value `C5` (lower is better).

* Keep the μ = λ/2 best individuals, compute the new mean and covariance as in standard CMA‑ES.  
* No constraint handling beyond the projection; the algorithm works on transformed, unconstrained parameters.

**Restarts**
