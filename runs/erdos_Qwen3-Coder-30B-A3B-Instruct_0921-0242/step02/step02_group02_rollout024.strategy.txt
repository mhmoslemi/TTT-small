### 1. Reformulation in terms of the autocorrelation matrix  

For a vector `h∈ℝⁿ` let  

```
X = h hᵀ   (rank‑1, PSD)
aₖ = ∑ᵢ h[i]·h[i‑k] = trace( Pₖ X ),   k=0,…,n‑1
```

where `Pₖ` is the cyclic‑shift permutation matrix (`(Pₖ)_{ij}=1` iff `j=i‑k (mod n)`).  
The overlap integral can be written  

```
cₖ = dx·( n/2 – aₖ ) .
```

Thus **minimising the maximal overlap is equivalent to maximising the minimal autocorrelation** `aₖ`.  

If the rank‑1 constraint on `X` is dropped, the feasible set becomes convex:
`X⪰0`, `X_{ii}=hᵢ∈[0,1]`, `∑ᵢ hᵢ = n/2`.  
The linear constraints `aₖ = trace(Pₖ X)` are then also linear in `X`.  
Consequently the following SDP gives a *relaxed* upper bound on the attainable `t = minₖ aₖ`:

```
max   t
s.t.  X ⪰ 0
      0 ≤ X_{ii} ≤ 1            (i=0,…,n‑1)
      ∑_i X_{ii} = n/2
      trace(Pₖ X) ≥ t    for all k
```

Because all constraints are linear in `X` and `t`, the problem is a standard SDP.

### 2. Solving the SDP (global stage)

1. **Choose a modest resolution** – `n = 180` (dx≈0.011).  This size yields a 180×180 PSD variable (≈32 k variables) and is comfortably solvable by first‑order SDP solvers (`SCS`, `ECOS`) within ~30 s.  

2. **Build the shift‑matrices** – For each `k∈{0,…,n‑1}` create a sparse matrix `Pₖ` that implements a cyclic roll; only the diagonal of `Pₖ` is needed, i.e. the vector `pₖ[i] = 1` at position `(i,(i‑k) mod n)`.  In CVXPY the linear expression `trace(Pₖ @ X)` is assembled by summing the appropriate off‑diagonal entries of `X`.

3. **Formulate the optimisation** – Declare variables `X = cp.Variable((n,n), PSD=True)` and `t = cp.Variable()`.  Add the box constraints on the diagonal, the sum‑constraint, and the `n` autocorrelation constraints `trace(Pₖ @ X) >= t`.  Use `objective = cp.Maximize(t)`.

4. **Solve** – Call `cp.Problem(...).solve(solver='SCS', max_iters=25000, eps=1e‑5)`.  The solver returns `X*` and `t*`. ### 3. Extracting a feasible step function from the SDP solution  

The matrix `X*` is not rank‑1, so it does not directly define a vector `h`.  We obtain a concrete `h` by **spectral factorisation**:

1. **Eigen‑decomposition** – Compute `λ₁≥…≥λₙ` and eigenvectors `v₁,…,vₙ` of `X*`.  The leading eigenpair `(λ₁,v₁)` captures most of the energy because the SDP pushes the autocorrelations up uniformly.

2. **Form a candidate** – Set `ĥ = √λ₁·v₁`.  This vector satisfies `ĥ ĥᵀ ≈ X*` in the sense of the dominant component.

3. **Project onto the feasible polytope** –

     minimise ‖h – ĥ‖₂  s.t. 0≤h≤1 , ∑h = n/2 .

    P = [build_cyclic_shift_matrix(k, n) for k in range(n)]

    h0 = project_to_feasible(lead)          # water‑filling

    # 4. Evaluate and keep best of a few random draws
    best_h, best_c5 = h0, evaluate_c5(h0)
    for _ in range(15):
        g = np.random.randn(n) @ np.linalg.cholesky(X_opt)
        h = project_to_feasible(np.clip(g,0,1))
        c5 = evaluate_c5(h)
        if c5 < best_c5:
            best_h, best_c5 = h, c5

    # 5. Sub‑gradient refinement (time‑controlled)
    while time.time() - start < 0.5*budget_s:
        best_h, best_c5 = subgradient_refine(best_h, dx, budget_s - (time.time()-start))

    # 6. Upsample if time remains
    if time.time() - start < 0.85*budget_s:

        best_h, best_c5 = subgradient_refine(h_up, 2.0/n2,
                                             budget_s - (time.time()-start))
