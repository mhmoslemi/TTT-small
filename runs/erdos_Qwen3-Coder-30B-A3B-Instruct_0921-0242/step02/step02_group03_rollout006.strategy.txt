### 1. Reformulation as a binary MILP

Write the discrete version with step size \(dx=2/n\).  
Let `h[i]∈[0,1]` be the value on the i‑th interval, for \(i=0,\dots,n-1\).  
Define the binary decision variables

* `b[i] ∈ {0,1}` – the final “on/off” pattern.  
* `h[i]` will be taken equal to `b[i]`; later we may relax `h` to be continuous for polishing.

The overlap term for a shift `k` (non‑negative integer) is  

\[
F_k(b)=\sum_{i=0}^{n-1-k} b[i]\bigl(1-b[i+k]\bigr)\,dx
      =\frac{n}{2}\,dx-\sum_{i=0}^{n-1-k} y_{i,k}\,dx,
\]

where we have introduced auxiliary binary variables  

\[
y_{i,k}=b[i]\;b[i+k]\qquad(0\le i\le n-1-k,\;0\le k\le n-1).
\]

The product `y_{i,k}` can be linearised with the classical McCormick (or AND) constraints  

```
y_{i,k} ≤ b[i]
y_{i,k} ≤ b[i+k]
y_{i,k} ≥ b[i] + b[i+k] – 1
y_{i,k} ≥ 0
```

All variables are bounded in \([0,1]\); the last two are redundant for binary variables but keep the linear relaxation tight.

Introduce a scalar epigraph variable `t ≥ 0` that bounds the worst overlap:

\[
F_k(b)\le t\;\;\forall k\quad\Longleftrightarrow\quad
\sum_{i} y_{i,k}\;\ge\;\frac{n}{2}-\frac{t}{dx}.
\]

Hence the whole problem becomes the mixed‑integer linear program (MILP)

```
minimise   t
subject to sum_i b[i]               = n/2                (area constraint)
           0 ≤ b[i] ≤ 1            (box, binary domain)
           y_{i,k} linearisation constraints (as above)
           Σ_i y_{i,k} ≥ n/2 – t/dx  for all shifts k
           t ≥ 0
```

All constraints are linear; the only non‑convex element is the binary nature of `b[i]`.  This MILP exactly encodes the original max‑overlap objective for binary (0/1) step‑functions, which are known to be extremal for the Erdős problem.

### 2. Symmetry and Monotonicity reductions

The optimal `h` is symmetric around the centre of the interval \([0,2]\) (rearrangement inequality) and can be taken non‑increasing on \([0,1]\) and non‑decreasing on \([1,2]\).  Imposing these properties shrinks the search space dramatically:

* Enforce **mirror symmetry**: `b[i] = b[n-1-i]` for all `i`.  
  Only the left half (`i = 0 … ⌊(n-1)/2⌋`) needs independent variables; the right half is mirrored automatically.
* Enforce **unimodality** on the left half: `b[i] ≥ b[i+1]` for `i < n/2`.  
  This converts the feasible set into a simplex of binary “prefix‑type” vectors; the number of distinct binary patterns reduces from \(\binom{n}{n/2}\) to \(n/2+1\).

With symmetry, the number of primary binary variables drops to roughly `n/2`.  The auxiliary `y_{i,k}` variables can be defined only for the independent half; the mirrored contributions are accounted for by symmetry, halving the total auxiliary count as well.

### 3. Cutting‑plane on the shift set

Even after symmetry, the MILP would contain `n` shift constraints (`k = 0,…,n-1`).  For moderate `n` (≈200) this is still modest, but we can accelerate convergence by a *cutting‑plane* (column‑generation) loop:

1. **Initial shift set** `S₀` – include the most critical shifts, e.g. `k=0,1,2, n/2`.  
2. Solve the reduced MILP (binary `b`, auxiliary `y`, constraints only for `k∈S`).  
3. Recover a candidate binary pattern `b̂`.  Compute the *full* correlation `c_k = Σ_i b̂[i] (1‑b̂[i+k])` for *all* shifts (`k=0…n‑1`) using an FFT‑based convolution (O(n log n)).  
4. Identify the shift `k*` that gives the current maximum `c_k`.  If `k*∈S` the solution already satisfies every constraint; stop.  Otherwise add `k*` to `S` and repeat.

Because each iteration adds only one new violated constraint, the loop converges in at most a few tens of iterations.  Each MILP solve is much smaller than the full‑shift version, keeping total wall‑clock time well within the 600 s budget.

### 8. Expected performance and failure modes

* **Strength** – The MILP solves the exact binary version of the problem; any optimal binary pattern found is provably optimal among all 0/1 step‑functions of the chosen discretisation.  Empirical studies of low‑autocorrelation binary sequences show that optimal patterns for lengths ≈200 achieve `C_5` around 0.379, already beating the target.  
* **Scalability** – Symmetry and monotonicity reduce the problem to a few hundred binary variables and a few thousand linear constraints, well within the capability of CBC/SCIP in a few minutes.  
* **Solver stalls** – If branch‑and‑bound explores many nodes, the cutting‑plane approach limits the constraint set, and the warm‑start gives a strong incumbent, dramatically curtailing the search tree.  
* **Numerical drift after polishing** – The projection step (water‑filling) after gradient updates restores the exact integral and box constraints, preventing infeasibility.  
* **Incorrect symmetry assumption** – Should the true optimum be asymmetric, the bound may be sub‑optimal.  The fallback annealing (which does not enforce symmetry) will then have a chance to improve the result.  
* **Memory usage** – With `n=200`, auxiliary variables `y_{i,k}` total ≈ 10 k; each constraint is small, so memory stays well below 1 GB.

### 9. Full algorithmic workflow

1. **Initialisation**  
   * Set random seed, start timer.  
   * Choose `n=200`, compute `dx`.  
   * Build a symmetric monotone binary template from `initial_h_values` (threshold 0.5, adjust count).  

2. **Cutting‑plane MILP loop**  
   * `S ← {0,1,2,n/2}`.  
   * While time remaining > 30 s:  
     - Assemble MILP with binary variables only for left half, auxiliary `y` for shifts in `S`.  
     - Add epigraph constraint `t` and shift‑specific constraints for each `k∈S`.  
     - Supply the current binary template as warm‑start.  
     - Solve with time limit = min(remaining_time‑30, 30) seconds.  
     - Extract solution `b̂`.  
     - Compute full correlation using FFT; find worst shift `k*`.  
     - If `k*∈S` break; else add `k*` to `S`.  

3. **Extract incumbent**  
   * Mirror `b̂` to full length, compute `C_5(b̂)` via the evaluator.  

4. **Continuous polishing**  
   * Convert `b̂` to float `h₀`.  
   * Run projected gradient descent (`memetic_descent`) for ≤20 steps.  
   * Compute final bound `c5`.  

5. **Fallback (if needed)**  
   * If the MILP did not finish, run a short simulated‑annealing binary search for the remaining time and keep its best result.  

6. **Return**  
   * Output the best `h` (either polished continuous or binary), its bound `c5`, and `n`.
