**1. Insight – a low‑dimensional family that contains (or almost contains) the optimum**  
For any admissible step function the worst overlap is attained when the mass of the function is as concentrated as possible while keeping the shape “balanced”.  By the rearrangement inequality the minimiser of  
\[
C_5(h)=\max_k\int_0^2 h(x)\bigl(1-h(x+k)\bigr)\,dx
\]
can be taken to be symmetric, non‑increasing on \([0,1]\) and non‑decreasing on \([1,2]\).  Consequently the optimal profile is expected to consist of a few linear pieces (zero, a ramp, a flat top, a symmetric ramp, zero).  All admissible functions of this type are fully described by **two continuous parameters**:

* `t` – the length of each ramp (the left and right ramps have the same length);
* `H` – the height of the flat top (the ramps rise/fall linearly to this height).

The zero‑regions on both sides have equal length `a`.  The three geometric constraints are

```
2a + 2t + L = 2               (total length)
H·(t + L) = 1                 (area = 1)
L = 1/H – t   (from the area equation)
a = (2 – 2t – L)/2            (from the length equation)
```

Feasibility requires `t ≥ 0`, `H ∈ [0.5,1]` (otherwise `a` becomes negative) and `L ≥ 0`.  For `H = 1` we obtain the familiar “block with linear fronts” (`L = 1‑t`, `a = (1‑t)/2`).  Allowing `H < 1` yields a wider, lower hump – a degree of freedom that is essential for beating the previous bound.

Thus the optimisation problem reduces to  

\[
\min_{(t,H)\in\mathcal D}  \; \Phi(t,H)
\qquad\text{with}\qquad
\Phi(t,H)=\max_{k\in[0,2]} \int_0^2 h_{t,H}(x)\bigl(1-h_{t,H}(x+k)\bigr)dx,
\]
where `h_{t,H}` is the piecewise‑linear trapezoid defined by the parameters and `\mathcal D` is the feasible region above.

Because the objective is a *max* of a smooth function of `k`, `\Phi(t,H)` is a piecewise‑smooth scalar function of two variables – cheap to evaluate with a fast FFT‑based correlation, and cheap to search globally.

**2. Fast evaluation of \(\Phi(t,H)\)**  

*Discretisation.*  Choose a modest resolution, e.g. `n = 800` points (so `dx = 2/n = 0.0025`).  The grid points are the mid‑points of the sub‑intervals: `x_i = (i+0.5)*dx, i=0..n‑1`.

*Constructing `h` for a given `(t,H)`.*
1. Compute `L = 1.0/H - t` and `a = (2 - 2*t - L)/2`.  If any of `L, a` are negative, the pair is infeasible – discard it.
2. Initialise a zero array `h` of length `n`.
3. Fill the left ramp: for all `x` in `[a, a+t)` set `h = H*(x-a)/t`.  (If `t=0` the ramp is empty.)
4. Fill the flat top: for `x` in `[a+t, a+t+L)` set `h = H`.
5. Fill the right ramp: for `x` in `[a+t+L, a+2*t+L)` set `h = H*(a+2*t+L-x)/t`.
   The remaining points stay zero.

*Enforcing the exact integral constraint.*  
The continuous construction guarantees an area of exactly `1`, but after sampling the sum `S = Σ h_i` might deviate from `n/2` by a few `dx`.  Perform a single “water‑filling” projection:
```
diff = n/2 - S
if diff > 0:
    raise the smallest entries (still <1) uniformly until diff≈0
else:
    lower the largest entries (still >0) uniformly
clip to [0,1] afterwards.
```
The projection changes the function only by O(dx) and never harms feasibility.

*Correlation by FFT.*  
For the projected `h` compute the full linear correlation with its complement using zero‑padding:
```
N = 2*n                # length for linear convolution
Hc = fft(h, N)
Gc = fft(1-h, N)
corr = real(ifft(Hc * conj(Gc)))[:2*n-1]   # length 2n‑1, index 0 --> shift -(n‑1)
C5 = max(corr) * dx
```
All operations are O(N log N) and take less than 2 ms for `n = 800`.  Thus an evaluation of `Φ(t,H)` costs virtually nothing.
