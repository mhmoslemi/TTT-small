**1. Mathematical reformulation**

For a discretisation with `n` samples (`dx = 2/n`) the overlap constant is  

\[
C_5(h)=\max_{s=-(n-1)}^{n-1}\Bigl(1-\frac{2}{n}\,\gamma_s\Bigr),\qquad 
\gamma_s=\sum_{i=0}^{n-1-s}h_i\,h_{i+s},
\]

so minimising `C₅` ⇔ maximising the smallest a‑periodic autocorrelation  

\[
\gamma_{\min}= \min_s\gamma_s .
\]

The constraints are  

* \(0\le h_i\le 1\)   (box)  
* \(\sum_i h_i = n/2\) (integral mass).

The plan uses a **two‑phase scheme**: (i) obtain a high‑quality *binary* pattern by solving a **mixed‑integer linear program (MILP)** on a modest grid, (ii) lift that pattern to the desired resolution and improve it with a **smooth‑max projected gradient descent** that respects the box‑plus‑sum constraints.

All steps are deterministic except for the optional random‑restart at the very end; no heuristic‑only methods (PSO, SA, memetic) are employed, making the approach fundamentally different from the previous submissions.

### 2. Phase I – Binary optimisation by MILP

**2.1 Choice of size**  
Pick a small even `n₁` (e.g. 120 – 132).  
The total number of 1‑entries must be `n₁/2`.  With this size the MILP contains fewer than 8 000 binary variables, well inside the capability of open‑source solvers (CBC, GLPK) called through **CVXPY**.

**2.2 Variables**

| Symbol | Meaning | Domain |
|--------|---------|--------|
| `b_i`  | binary indicator of sample `i` (1 = occupied) | `{0,1}` |
| `a_{i,s}` | product `b_i·b_{i+s}` (the contribution of the pair `(i,i+s)`) | `{0,1}` |
| `γ_s` | autocorrelation for shift `s≥0` | integer ≥0 |
| `L`   | lower bound on all `γ_s` (the quantity we maximise) | scalar (continuous) |

Only non‑negative shifts are needed because \(\gamma_{-s}=\gamma_s\) for aperiodic correlation.

**2.3 Constraints**

1. **Mass** \(\sum_i b_i = n₁/2\).

2. **Product linearisation** (McCormick for binaries) for every admissible pair \((i,s)\) with `i+s < n₁`:
   ```
   a_{i,s} ≤ b_i
   a_{i,s} ≤ b_{i+s}
   a_{i,s} ≥ b_i + b_{i+s} - 1
   ```
   This forces `a_{i,s}=b_i·b_{i+s}`.

3. **Autocorrelation definition** for each shift `s`:
   ```
   γ_s = Σ_{i=0}^{n₁-1-s} a_{i,s}
   ```

4. **Uniform lower bound**:
   ```
   γ_s ≥ L    for all s = 0 … n₁-1 .
   ```
   (For `s=0`, `γ_0 = Σ_i b_i = n₁/2` so `L ≤ n₁/2` automatically.)

**2.4 Objective**

```
maximise   L
```

Thus the MILP maximises the smallest autocorrelation value among all shifts.

### 4. Phase III – Smooth‑max projected gradient descent

The non‑smooth `max` is replaced by a **log‑sum‑exp (soft‑max) surrogate**:

\[
F_{β}(h)=\frac{1}{β}\log\Bigl(\sum_{s} e^{β\,C_s(h)}\Bigr),\qquad
C_s(h)=1-\frac{2}{n₂}\,\gamma_s,
\]
where \(\gamma_s=\) aperiodic autocorrelation of `h`.  As `β→∞`, `F_β → max_s C_s = C₅(h)`.

**4.1 Gradient of the surrogate**

Let the weight vector be  

\[
w_s = \frac{e^{β C_s}}{\sum_t e^{β C_t}} .
\]

Differentiating gives  

\[
\nabla F_{β}(h)= -\frac{2}{n₂}\Bigl(\, w * h \;+\; (w\;\text{reversed}) * h \Bigr),
\]
where `*` denotes linear convolution (zero‑padded, aperiodic).  
Both convolutions are computed efficiently by FFT:
```
W = fft(w)
H = fft(h)
conv = ifft(W * H).real          # w*h
conv_rev = ifft(np.conj(W) * H).real   # w_rev*h
grad = -(2/n₂) * (conv + conv_rev)
```

**4.2 Projection onto the feasible set**  

Given a tentative vector `y = h - α·grad`, the projection onto  

\[
T=\{\,h\mid 0\le h_i\le 1,\; \sum_i h_i = n₂/2\,\}
\]

is performed by a **water‑filling (λ‑shifting) algorithm**:

1. Clip `y` to `[0,1]` → `ŷ`.  
2. If `∑ ŷ = n₂/2` we are done.  
3. Otherwise find a scalar `λ` such that  

   \[
   \sum_i \operatorname{clip}(y_i-λ,\,0,\,1)= n₂/2 .
   \]

   The monotone function `S(λ)` is evaluated in O(n); a bisection (≈ 40 iterations) yields `λ` to double‑precision.

**4.3 Line search and schedule**

* Initialise temperature `β = 2.0`.  
* Use a back‑tracking Armijo line search: start with `α = 1.0`; halve `α` until `F_β(projected(y)) ≤ F_β(h)`.  
* After a fixed number of inner iterations (e.g. 150) increase `β ← min(β·1.5, 200)`.  This anneals the soft‑max towards the true max.  
* Apply **Nesterov acceleration** (momentum term `(k‑1)/(k+2)`) to the projected points; the acceleration is reset whenever the line search rejects a trial.

**4.4 Score‑guided perturbations (optional escape)**  

Every `T_swap` (≈ 200) iterations, compute a *score* for each index:

\[
\text{score}_i = \sum_{s\in\mathcal{W}}(h_{i+s}+h_{i-s}),
\]
where `𝓦` is the set of shifts whose `C_s` lies within `ε=1e‑5` of the current maximum.  
Pick a source index with *large* score and a target with *small* score, move a tiny amount `δ = min(0.01, h_i, 1‑h_j)`.  Project afterwards.  This cheap move can break plateaus without altering the gradient machinery.

**4.5 Stopping criterion**

Continue until the wall‑clock reaches `0.85·budget_s` or until the improvement in `C₅ = max_s C_s` over the last 500 iterations falls below `1e‑7`.  The best feasible `h` seen so far is stored as `h_best`.

--------------------------------------------------------------------
### 5. Phase IV – Final polishing (tiny budget)

If time remains (`> 0.1·budget_s`), perform a short **projected sub‑gradient** phase on the *original* non‑smoothed objective:

* Identify the set `𝓦` of worst shifts (those attaining `C₅`).  
* The sub‑gradient is  

  \[
  g = -\frac{2}{n₂}\,\frac{1}{|\mathcal{W}|}\sum_{s\in\mathcal{W}} \bigl( \text{shift}_{+s}(h) + \text{shift}_{-s}(h) \bigr).
  \]

* Take a step `h ← project_T(h - η g)` with a simple diminishing step size `η = η₀ / √k`.  
* Run at most 200 iterations; keep the best vector.

### 8. Failure‑mode handling

| Potential issue | Mitigation |
|-----------------|------------|
| MILP does not finish within its time budget | Use a generous MIP gap (`rel_gap=5e‑3`) and a hard solver timeout; retain the incumbent solution. |
| Too many binary variables for the solver | Reduce `n₁` (e.g. 100) or drop far‑shift constraints (keep only shifts ≤ ⌊n₁/2⌋) – the worst shift is usually among the first half. |
| Upsampled vector too “blocky” for gradient descent | Apply a brief Gaussian blur (σ=1) before the first gradient iteration; the projection step restores feasibility. |
| Gradient descent stalls (no improvement) | Increase temperature `β` more slowly, reset Nesterov momentum, or invoke a score‑guided swap batch. |
| Projection bisection fails to converge (numerical) | Clamp λ‑search interval to \([-1,1]\) and perform a fixed number (40) of iterations; the resulting sum error is \< 1e‑9, acceptable for the evaluator. |
| Overall runtime exceeds budget | The algorithm checks wall‑clock after each outer loop; if the remaining time is < 0.1·budget it jumps directly to the final polishing stage and returns the best solution so far. |

            if α < 1e-8: break
        h = h_trial

        # schedule

        # occasional swap

        iteration += 1
