The goal is to produce a step‑function `h` on `[0,2]` (discretised to ≤ 1000 points) with  
`0 ≤ h[i] ≤ 1`, `∑h[i]=n/2` and a minimal value of  

```
C5 = max_k  dx·∑_i h[i]·(1−h[i−k])
```

where `dx = 2/n`.  
All previous attempts optimise the full‑dimensional vector `h` directly (PSO, simulated‑annealing, local gradient descent).  
The new strategy **reduces the dimension first** by representing `h` as a linear combination of a small set of smooth basis functions, then performs a **global derivative‑free search** on the low‑dimensional coefficient space, followed by a **fast convex‐approximation refinement** and a final up‑sampling polish.  The approach is fundamentally different: it never manipulates the raw `n`‑dimensional vector in the global stage, it exploits analytic properties of Fourier series, and it uses a deterministic linearisation (sequential linear programming) for local improvement instead of PSO‑style heuristics.

### 1. Analytic reformulation

For a periodic function `h` on `[0,2]` the circular autocorrelation is

```
A(k) = ∫_0^2 h(x)·h(x+k) dx .
```

Because `∫_0^2 h = 1`, the overlap integral is  

```
C5 = 1 – min_k A(k) .
```

Hence **maximising the minimal autocorrelation** is equivalent to minimising `C5`.

If `h` has a Fourier series  

```
h(x) = a0 + Σ_{m=1}^M [ am·cos(mπx) + bm·sin(mπx) ] ,
```

with period 2, then by the Wiener‑Khinchin theorem

```
A(k) = 2·Σ_{m=0}^M (am² + bm²)·cos(mπk) .
```

The coefficients `am,bm` appear only **quadratically** in `A(k)`; the constant term `a0` is forced to ½ to satisfy the integral constraint (`a0 = ½` because all sine/cosine terms have zero mean).  Consequently the design problem reduces to selecting a modest number `M` of coefficients `c = (a1,b1,…,aM,bM)` such that the resulting autocorrelation is as flat as possible while the pointwise bounds `0≤h≤1` hold.

### 4. Local refinement – **Sequential Linear Programming (SLP)**

The DE output already respects the bounds and integral, but the max‑overlap is still a **non‑convex** max‑function of a quadratic form.  We now perform a deterministic local descent that **linearises the worst‑shift constraint** at each iteration.

#### 4.1 Problem reformulation

Introduce a scalar `t` representing the current lower bound on the autocorrelation:

```
t ≤ A(k)    for all k = 0,…,n0‑1 .
```

Since `C5 = 1 – min_k A(k) = 1 – t`, *maximising* `t` is equivalent to *minimising* `C5`.  For a current shape `h`, the autocorrelation at shift `k` is

```
A(k) = hᵀ P_k h          (P_k is the permutation matrix that shifts by k)
```

Its gradient w.r.t. `h` is `∇_h A(k) = (P_k + P_kᵀ) h = 2·roll(h,k)`.  Let `k*` be the shift attaining the current minimum `t = A(k*)`.

#### 4.2 Linearised subproblem

At iteration `ℓ` we have a feasible `h⁽ℓ⁾`.  Linearise each autocorrelation constraint around `h⁽ℓ⁾`:

```
A(k) ≈ A⁽ℓ⁾(k) + ∇A(k)·(h – h⁽ℓ⁾)  ≥  t .
```

Only the *active* constraints (those with value close to the current minimum) need to be retained; we keep the worst 5‑10 shifts to keep the LP size modest.

The subproblem is a **linear program**:

```
max   t
s.t.   A⁽ℓ⁾(k) + ∇A(k)·(h – h⁽ℓ⁾)  ≥  t   for selected k
       0 ≤ h ≤ 1
       ∑ h = n0/2 .
```

All variables (`h_i` and `t`) appear linearly, and the constraints are cheap because each gradient is just a rotated copy of `h⁽ℓ⁾`.  The LP can be solved with `scipy.optimize.linprog` (interior‑point) in a few milliseconds.

#### 4.3 Update rule

* Solve the LP → obtain `(h̃, t̃)`.  
* Compute the exact autocorrelation of `h̃` (FFT) and the true `C5`.  
* If the new `C5` improves, accept `h⁽ℓ+1⁾ = h̃`; otherwise perform a **damped step**: `h⁽ℓ+1⁾ = (1‑α)·h⁽ℓ⁾ + α·h̃` with `α ∈ (0,1]` found by backtracking line search to guarantee descent.

Iterate until either (i) improvement < 1e‑6, (ii) a maximum of 300‑400 LP solves, or (iii) the allocated time for the refinement phase expires (≈ 30 % of the total budget).  Because each LP is tiny (≤ n0 ≈ 250 variables, ≤ 15 constraints), the whole refinement finishes in < 5 seconds even for the 5 candidates.

**Why SLP is new** – previous approaches used gradient descent on the original max‑overlap; here we replace the nondifferentiable objective by a **convex linear approximation** at each step, guaranteeing a *global* improvement of the linearised model and often escaping plateaus that stall pure sub‑gradient methods.
