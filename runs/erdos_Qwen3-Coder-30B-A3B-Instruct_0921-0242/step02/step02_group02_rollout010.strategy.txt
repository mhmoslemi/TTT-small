### Overview
We treat the Erdős C₅ problem as a **min‑max quadratic program** on the circle of length 2.  
For a discretisation of length n (dx = 2/n) the objective is  

\[
F(h)=\max_{k\in\{0,\dots,n-1\}} \; c_k,\qquad 
c_k =dx\sum_{i=0}^{n-1} h_i\bigl(1-h_{i-k}\bigr)
    =dx\Bigl(\tfrac n2-\sum_{i}h_i h_{i-k}\Bigr).
\]

Thus minimizing the maximal overlap is equivalent to **maximising the minimal periodic autocorrelation** of the vector h.  

The proposed pipeline separates the problem into three distinct layers:

1. **Spectral lower‑bound guided binary search** – we solve a *relaxed* linear‑matrix inequality (LMI) that yields a lower bound on the best possible maximal overlap for a given n. The dual variables give a *target autocorrelation shape*.
2. **Deterministic construction of a binary pattern** – using the target autocorrelation we formulate a *binary integer program* (BIP) that attempts to match the desired autocorrelation values as closely as possible. This BIP is solved with a modern MIP solver (CBC via cvxpy) together with a *cut‑generation* loop that enforces the max‑overlap constraint.
3. **Continuous refinement by projected quasi‑Newton** – the binary solution is softened into a real‑valued step function, then a few iterations of a **projected limited‑memory BFGS** (L‑BFGS‑B) are performed on the exact max‑overlap objective using a smooth log‑sum‑exp surrogate. The final solution is projected back onto the feasible polytope (box [0,1] and sum = n/2).

Each layer is time‑controlled; the total wall‑clock stays below the allotted budget while exploring a much richer search space than pure PSO or simulated‑annealing.

### 1. Spectral LMI Relaxation (guidance)

#### 1.1 Formulation
Define the circulant matrix \(C_k\) with entries \((C_k)_{ij}=1\) if \(j=i-k\ (\mathrm{mod}\ n)\) and 0 otherwise.  
Then  

\[
c_k = dx\Bigl(\tfrac n2 - h^\top C_k h\Bigr).
\]

Let \(\gamma\) be a scalar upper bound on all \(c_k\). The constraints \(c_k\le\gamma\) are equivalent to

\[
h^\top C_k h \ge \tfrac n2 - \tfrac{\gamma}{dx}\quad\forall k .
\]

Collect the matrices \(C_k\) into a block‑diagonal matrix and apply the standard **Shor relaxation**:

\[
\begin{aligned}
\text{minimise } & \gamma\\
\text{s.t. } &
\operatorname{Tr}(C_k X) \ge \tfrac n2 - \tfrac{\gamma}{dx} \quad\forall k,\\
& X = hh^\top,\; X\succeq hh^\top,\\
& 0\le h_i\le 1,\;\sum_i h_i = n/2 .
\end{aligned}
\]

Relax the rank‑1 constraint to \(X\succeq 0\). This yields a **semidefinite program (SDP)** that can be solved quickly for modest n (≈200). The optimal dual vector \(\lambda_k\) indicates which shifts are most critical; the corresponding primal matrix \(X^\star\) supplies a *target covariance* of h.

#### 1.2 Extraction of a target autocorrelation profile
From the optimal \(X^\star\) we compute its eigen‑decomposition and take the leading eigenvector \(v\) (non‑negative after clipping). The autocorrelation implied by \(v\) is

\[
\tilde a_k = v^\top C_k v .
\]

We normalise \(\tilde a_k\) to respect the weight constraint and treat \(\tilde a_k\) as a **desired autocorrelation** for the subsequent binary construction.

### 2. Binary Integer Program with Cut Generation

#### 2.1 Decision variables
- Binary vector \(b\in\{0,1\}^n\) (the 0/1 pattern; weight = n/2).
- Continuous auxiliary variable \(\gamma\) (upper bound on the overlap).

#### 2.2 Core constraints
For each shift \(k\):

\[
dx\bigl(\tfrac n2 - \sum_i b_i b_{i-k}\bigr) \le \gamma .
\]

These are **quadratic** but become linear after introducing auxiliary variables:

\[
s_k = \sum_i b_i b_{i-k},\qquad
dx\bigl(\tfrac n2 - s_k\bigr) \le \gamma .
\]

The products \(b_i b_{i-k}\) are linearised with standard McCormick envelopes because the variables are binary:

\[
z_{ik} \le b_i,\; z_{ik} \le b_{i-k},\; 
z_{ik} \ge b_i+b_{i-k}-1,\; z_{ik}\ge 0,
\]
and \(s_k = \sum_i z_{ik}\).

The weight constraint \(\sum_i b_i = n/2\) is added directly.

#### 2.3 Cut‑generation loop
Initially we include only a **subset** of the shift constraints (e.g., the k’s with largest dual values from the SDP). After solving the MIP, we evaluate the resulting binary pattern’s full correlation. If any shift violates the current \(\gamma\) by more than a tolerance, we add its corresponding linearised constraint and re‑solve. This lazy‑constraint approach keeps the MIP size modest while guaranteeing convergence to a pattern whose maximal overlap equals the final \(\gamma\).

#### 2.4 Solver settings
- Use cvxpy with the CBC solver (fast for binary problems up to n≈500).  
- Time‑limit per MIP solve: 15 s; overall binary phase limited to 0.4 × budget.  
- Warm‑start by feeding the previous solution when new cuts are added.

The outcome is a **high‑quality binary pattern** whose maximal overlap is close to the SDP lower bound, typically within a few × 10⁻³.

### 3. Continuous Refinement via Projected Quasi‑Newton

#### 3.1 From binary to continuous
Convert the binary vector \(b\) to a real vector \(h^{(0)}\) by applying a **smooth ramp** of width w (2–4 points) at each transition 0→1 or 1→0. This reduces the product \(h_i h_{i-k}\) when two blocks are misaligned, providing an immediate drop in the max‑overlap.

After ramp insertion, enforce feasibility:

\[
h = \operatorname{Proj}_{\mathcal{F}}(h^{(0)}) ,
\]
where \(\mathcal{F}=\{0\le h\le 1,\;\sum h = n/2\}\). The projection is performed by the same water‑filling algorithm used earlier (O(n)).

#### 3.2 Smooth surrogate objective
Directly minimizing \(\max_k c_k\) is non‑differentiable. Replace it by a **log‑sum‑exp (LSE)** approximation:

\[
\phi_\beta(h)=\frac{1}{\beta}\log\Bigl(\sum_{k=0}^{n-1} e^{\beta\,c_k(h)}\Bigr),
\]
with \(\beta\) gradually increased (e.g., start at 5, double every 200 iterations up to 80). The gradient of \(\phi_\beta\) is a softmax‑weighted combination of the individual gradients:

\[
\frac{\partial \phi_\beta}{\partial h_i}= \sum_k w_k \,\frac{\partial c_k}{\partial h_i},
\qquad
w_k = \frac{e^{\beta c_k}}{\sum_j e^{\beta c_j}} .
\]

For each shift,
\[
\frac{\partial c_k}{\partial h_i}=dx\bigl( -h_{i-k} + (1-h_{i+k})\bigr)
      =dx\bigl( h_{i+k} - h_{i-k}\bigr).
\]

All gradients are computed with two cyclic rolls, O(n) per iteration.

#### 3.3 L‑BFGS‑B with projection
We employ **L‑BFGS‑B** (limited‑memory BFGS with box constraints) on \(\phi_\beta\) while handling the linear equality \(\sum h = n/2\) via a simple **affine projection** after each step:

1. Propose an L‑BFGS‑B step \(h_{\text{tmp}}\) respecting 0≤h≤1.  
2. Project onto the hyperplane \(\sum h = n/2\) by adding the constant \(\lambda\) that enforces the sum (solve \(\lambda = (n/2 - \sum h_{\text{tmp}})/n\)). Clip again to [0,1] and repeat a few times (at most 2) to guarantee feasibility.

The line search uses the **Armijo condition** on \(\phi_\beta\). Because the surrogate is smooth, the quasi‑Newton updates converge rapidly; we limit the refinement phase to 2000 iterations or the remaining time budget, whichever occurs first.

#### 3.4 Final polishing
When the time remaining drops below ~5 s, switch to the **exact max‑overlap** objective:

- Identify the current worst shift \(k^\star\).  
- Perform a **projected sub‑gradient step** with step size \(\eta = \frac{c_{k^\star}}{\|\nabla c_{k^\star}\|^2}\) (optimal for a single linear piece).  
- Project back onto \(\mathcal{F}\).  
- Repeat for a few hundred micro‑steps (tiny \(\eta\)) to eliminate any residual slack introduced by the surrogate.

The final value of \(F(h)\) is then computed with the exact correlation (FFT) and returned.

| Phase | n (samples) | Approx. time | Goal |
|------|--------------|--------------|------|
| SDP relaxation | 200 | ≤ 30 s | Obtain lower bound & target autocorrelation |
| Binary MIP (lazy cuts) | 200‑300 (adjustable) | ≤ 0.35 · budget | Produce near‑optimal 0/1 pattern |
| Ramp smoothing & projection | same n | negligible | Initialise continuous phase |
| L‑BFGS‑B (LSE) | same n | ≤ 0.2 · budget | Reduce max‑overlap significantly |
| Upsampling (optional) | 2·n (if time) | ≤ 0.05 · budget | Remove discretisation error |
| Final exact sub‑gradient polish | final n | remainder | Reach best possible bound |

If the binary phase finishes early, we increase n (e.g., 300 → 400) and repeat the construction, because higher resolution often yields a lower maximal overlap after refinement.

### 5. Anticipated Failure Modes & Mitigations

1. **SDP infeasibility / numerical issues** – use a modest regularisation (add ε·I to the PSD constraint) and fallback to a simple uniform target autocorrelation (all shifts equal) if the solver fails.
2. **MIP does not converge within time** – limit the number of added cuts per iteration; if still slow, switch to a **heuristic greedy rounding** of the SDP solution (threshold at 0.5) and use that as the binary start.
3. **L‑BFGS‑B stagnates** – restart with a higher β (sharper surrogate) or inject a random perturbation of magnitude 0.01 to escape flat regions.
4. **Projection loops** – ensure the water‑filling projection uses a deterministic bisection with tolerance 1e‑12; it converges in ≤ 30 iterations for n ≤ 800.
5. **Memory overflow for large n** – keep n ≤ 800; all matrices are circulant, so we never store full C_k; only use FFT‑based convolutions.

### 6. Expected Outcome
