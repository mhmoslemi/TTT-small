--------------------------------------------------------------------
### 1.  Mathematics of the objective

For a shift `s` (integer number of samples, `‑(n‑1)…(n‑1)`) define  

```
γ_s = ∑_{i=0}^{n‑1} h[i]·h[i+s]          (zero outside the interval)
```

`γ_s` is the *autocorrelation* of `h`.  Using `dx = 2/n` and `∑h = n/2`

```
C_s = ∫ h·(1‑h(·+s·dx)) = 1 – (2/n)·γ_s .
```

Thus  

```
C5 = max_s C_s = 1 – (2/n)· min_s γ_s .
```

Minimising `C5` ⇔ maximising the smallest autocorrelation value.

--------------------------------------------------------------------
### 2.  Smooth approximation of the max

`max_s C_s` is non‑differentiable.  Replace it by a *log‑sum‑exp* (soft‑max)
with temperature `β>0`:

```
F_β(h) = (1/β)·log( Σ_s exp( β·C_s ) )
```

As `β → ∞`, `F_β → max_s C_s`.  For moderate `β` the function is smooth and
its gradient is a convex combination of the gradients of the active shifts.

Let  

```
w_s = exp( β·C_s ) / Σ_t exp( β·C_t )   (weights, Σ w = 1)
```

The gradient of `C_s` w.r.t. `h[i]` (zero‑padding at the borders) is

```
∂C_s/∂h[i] = – (2/n)·( h[i+s] + h[i‑s] ) .
```

Therefore the gradient of `F_β` is

```
∇F_β = –(2/n)· Σ_s w_s·(shift_{+s}(h) + shift_{‑s}(h)) .
```

All shifts are linear operations; the whole sum can be written as two
convolutions:

* let `w` be the vector of weights (length `2n‑1`),
* `conv1 = convolve(w, h, mode='full')`,
* `conv2 = convolve(w[::-1], h, mode='full')`,
* the needed slice is `conv1[n‑1:n‑1+n]` and `conv2[n‑1:n‑1+n]`.

Hence  

```
grad = –(2/n)·( conv1_slice + conv2_slice ) .
```

All quantities are computed with NumPy, no explicit Python loops.

--------------------------------------------------------------------
### 3.  Projection onto the feasible set

We must keep the iterate inside  

```
0 ≤ h[i] ≤ 1 ,   Σ_i h[i] = n/2 .
```

The Euclidean projection onto the intersection of a box and an affine hyper‑plane
has a closed form: there exists a scalar λ such that  

```
x_i = clip( y_i – λ , 0 , 1 ) ,   Σ_i x_i = n/2 .
```

The sum `S(λ) = Σ_i clip( y_i – λ , 0 , 1 )` is monotone decreasing in λ,
so λ can be found by a simple bisection (≈ 40 iterations give double precision).
The routine `project_box_sum(y, total)` implements this ( `total = n/2`).

--------------------------------------------------------------------
### 4.  Optimisation driver

**Parameters**
```
n            = 250            (≈ 0.008·dx, a good trade‑off speed / accuracy)
total_mass   = n/2
β_start      = 2.0
β_max        = 200.0
β_factor     = 1.6   (multiply after a fixed number of iterations)
max_iter_β   = 2000  (iterations per β value, adaptive to remaining time)
step_init    = 1.0   (initial step length for back‑tracking line search)
```

**Main loop**
```
h ← feasible start (see §5)
best_h ← h , best_val ← C5(h)

while time remains and β ≤ β_max:
    for it = 1 … max_iter_β:
        compute autocorrelation γ = correlate(h, h, 'full')
        C = 1 – (2/n)·γ
        w = softmax(β·C)    # stable: subtract max(C) before exp
        grad = –(2/n)·(conv(w, h) + conv(w[::-1], h))[slice]

        # back‑tracking line search
        α ← step_init
        repeat:
            h_new ← project_box_sum( h – α·grad , total_mass )
            if C5(h_new) ≤ C5(h):  break
            α ← α·0.5
        until α is tiny

        h ← h_new
        if C5(h) < best_val:
            best_val ← C5(h);  best_h ← h.copy()

        # optional step‑size adaptation (increase if improvement, else decrease)
        if C5(h_new) < C5(h):   step_init ← min(step_init·1.1, 2.0)
        else:                    step_init ← step_init·0.9
    β ← min(β·β_factor , β_max)
```

The loop checks the wall‑clock after every ~100 iterations and stops before the
global budget (`budget_s`).  The final `best_h` is the best encountered point.

--------------------------------------------------------------------
### 5.  Starting points

* **Primary start** – the supplied `initial_h_values`.  
  If its length differs from `n`, linearly interpolate to `n` points, then
  rescale to satisfy the integral (`h *= (total_mass / np.sum(h))`) and finally
  project with `project_box_sum`.

* **Random restarts** – after a long stagnation (e.g. 500 iterations without
  improvement) generate a fresh feasible vector:
  ```
  h_rand = np.random.rand(n)
  h_rand = project_box_sum( h_rand , total_mass )
  ```
  Restart the inner optimisation from `h_rand`.  This guards against being
  trapped in a poor local minimum.

* **Hybrid perturbation** – before each restart (or occasionally) add a tiny
  uniform noise (`±0.02`) to the current best, re‑project, and resume.  This
  explores the neighbourhood of a good solution without losing feasibility.

--------------------------------------------------------------------
### 6.  Evaluation routine (used only for acceptance)

```
def evaluate_c5(h):
    dx = 2.0 / len(h)
    corr = np.correlate(h, 1.0 - h, mode='full')
    return np.max(corr) * dx
```

All candidate vectors are always projected, so the constraint `∑h = n/2`
holds exactly; the evaluator therefore returns a reliable `C5` value.

--------------------------------------------------------------------
### 7.  Time‑management

* The whole `run` function records `t0 = time.time()`.
* The main optimisation loop runs while `time.time() - t0 < 0.94·budget_s`.
* Inside the loop, after each block of ~100 iterations we recompute the elapsed
  time to avoid overrunning.
* The final return occurs immediately once the budget is exhausted; the best
  solution seen so far (`best_h`, `best_val`) is returned.

### 8.  Expected performance

* Each iteration costs two `np.convolve` (≈ O(n²) = 6·10⁴ ops) and one
  `np.correlate` for the objective – well under 1 ms on a single core.
* With `β` increasing geometrically we perform ~10 β‑stages, each with a few
  hundred iterations → a few thousand iterations total → < 30 s on a typical
  CPU.
* Random restarts and the smoothing schedule help escape local minima; experience
  with similar “max‑autocorrelation” problems shows that the soft‑max approach
  reliably finds lower peak values than pure PSO for the same discretisation.

The algorithm therefore has a realistic chance of beating the current record
(0.382149) and reaching the target bound `C5 ≤ 0.3807`.
