\[
C_5(h)=\max_{k}\int_0^2 h(x)\bigl(1-h(x+k)\bigr)\,dx

is as small as possible, respecting  

* \(0\le h_i\le1\) for every sample `i`;
* \(\sum_i h_i = n/2\) (i.e. integral equals 1).

The evaluation uses a full linear correlation of `h` with `1‑h` multiplied by `dx`.

To improve we combine three ideas:

1. **Exact convex formulation for a *fixed* shift set** – the objective is the maximum of a finite set of linear functionals, which is a convex piece‑wise‑linear problem. By introducing an auxiliary variable `t` we obtain a linear program (LP):  

   \[
   \min\; t\quad\text{s.t.}\quad
   \sum_i h_i\bigl(1-h_{i+s}\bigr)\,dx \le t\quad\forall s\in S,
   \quad 0\le h_i\le 1,\quad \sum_i h_i = n/2 .
   \]

   Here `S` is a discrete set of integer shifts representing the correlation lags we care about (all possible `s = -n+1,…,n-1`). The LP size is `O(n|S|)`. For modest `n` (≈300–500) the problem is tractable with any open‑source LP solver (ECOS via CVXPY). Solving this LP directly yields the global optimum for the *chosen* set `S`. 2. **Warm‑start via a reduced shift set and iterative refinement** – solving the full LP with all `2n‑1` shifts can be expensive. Instead:

   * Evaluate the full correlation, locate the shift `s_max` that violates the bound the most (i.e., gives the current `C5`).
   * If `s_max` is already in `S`, stop (optimal for full set). Otherwise add `s_max` to `S` and re‑solve.
   * Repeat until no new violating shift appears or time runs out.

   This is a classic cutting‑plane / column‑generation approach that converges quickly because each LP solution reduces the maximal correlation.
