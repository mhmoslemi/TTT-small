**Overview**  
We will solve the Erdős minimum‑overlap problem by (1) *parameterising* the step function with a very small number of constant pieces, (2) *evaluating* the exact max‑overlap analytically for any such parametrisation, and (3) *optimising* the parameters with a *global, derivative‑free* optimiser (Differential Evolution) followed by a local refinement.  The whole pipeline respects the constraints, works with any discretisation size n ≤ 1000, and needs only elementary NumPy/ SciPy primitives.

The approach is fundamentally different from the earlier sub‑gradient / log‑sum‑exp schemes: it does not use gradients of the max‑overlap, it does not linearise the bilinear terms, and it reduces the search space to a handful of geometric variables instead of the full 𝑛‑dimensional vector.

### 1. Low‑dimensional piecewise‑constant model

We represent a candidate function h on \([0,2]\) as a *monotone* step function with **M** pieces (M≈5–7 is enough).

\[
h(x)=a_j\quad\text{for }x\in[s_j,s_{j+1}),\qquad j=0,\dots,M .
\]

**Why monotone?**  
For a fixed multiset of values \(\{a_j\}\) the worst shift aligns large values of h with large values of 1‑h. By the rearrangement inequality the maximal overlap is attained when the values are ordered oppositely, i.e. when h is non‑increasing. Empirically the best known constructions are of this shape, so the restriction does not lose optimality but shrinks the search drastically.

**Constraints in the parametrisation**

1. **Box constraints**: \(0\le a_j\le1\).  
2. **Monotonicity**: enforce by construction (see transformation below).  
3. **Integral**:  
   \[
   \int_0^2 h(x)\,dx
   =\sum_{j=0}^{M} a_j\,(s_{j+1}-s_j)=1 .
   \]
   This is a *single linear equality* in the variables.

All other constraints are automatically satisfied.

**Variable transformation (to embed constraints in an unconstrained box)**  

- Let \(u_j\ge0\) for \(j=0,\dots,M\) be *segment lengths*; set \(s_{j+1}=s_j+u_j\). Impose \(\sum_{j=0}^{M} u_j = 2\). Enforce by fixing \(u_M = 2-\sum_{j=0}^{M-1} u_j\) and restricting the first M variables to \([0,2]\).  
- Let \(v_j\ge0\) be *height drops*: define \(a_0\) free in \([0,1]\) and for \(j\ge1\) set \(a_j = a_{j-1} - v_{j-1}\). Enforce \(a_M\ge0\) by fixing \(v_{M-1}=a_{M-1}\) (or by adding a penalty).  
- The free optimisation variables are therefore  
  \[
  x = (u_0,\dots,u_{M-1},a_0,\,v_0,\dots,v_{M-2}) .
  \]
  Their bounds are simple boxes (all ∈[0,2] for lengths, ∈[0,1] for heights and drops). The remaining dependent variables are recovered by cumulative sums.

With this transformation the integral constraint becomes a linear equality in the dependent variables:
\[
\sum_{j=0}^{M} a_j\,u_j = 1 .
\]
We enforce it exactly by solving for the last *height* \(a_M\) after the other heights are known, or we add a large quadratic penalty \(\lambda\,|\,\sum a_j u_j-1\,|^2\) to the objective (λ≈10⁶) – the DE algorithm tolerates soft penalties.

---

### 2. Exact evaluation of the max‑overlap \(C_5\) for a piecewise‑constant h

For any shift \(k\in[0,2]\) the overlap integral is
\[
F(k)=\int_0^2 h(x)\,\bigl(1-h(x+k)\bigr)\,dx
      =\sum_{j=0}^{M}\sum_{\ell=0}^{M} a_j\bigl(1-a_\ell\bigr)\;
        \mathrm{len}\bigl(I_j\cap (I_\ell-k)\bigr),
\]
where \(I_j=[s_j,s_{j+1})\) and \(\mathrm{len}(\cdot)\) denotes Lebesgue measure, zero if the intervals do not intersect.

For a *fixed* pair \((j,\ell)\) the intersection length is a *piecewise‑linear* function of k:
\[
L_{j\ell}(k)=\max\bigl(0,\; \min(s_{j+1},\,s_{\ell+1}-k)-
                         \max(s_{j},\,s_{\ell}-k)\bigr).
\]
The breakpoints of \(L_{j\ell}\) are exactly the two values
\[
k^{(1)}_{j\ell}=s_{\ell}-s_{j+1},\qquad
k^{(2)}_{j\ell}=s_{\ell+1}-s_{j}.
\]
Thus **the whole function \(F(k)\) is piecewise linear**, its slope can change only at a breakpoint belonging to the set
\[
\mathcal K = \bigl\{\,k^{(1)}_{j\ell},\,k^{(2)}_{j\ell}\mid 0\le j,\ell\le M\,\bigr\}
\cap[0,2].
\]

**Computation of \(C_5\)**  

1. Build the list \(\mathcal K\) (size ≤ 2(M+1)²).  
2. Sort \(\mathcal K\) and add the interval ends 0 and 2.  
3. For each \(k\) in the sorted list evaluate  
   \[
   F(k)=\sum_{j,\ell} a_j\,(1-a_\ell)\,L_{j\ell}(k)
   \]
   by a double loop over the at most (M+1)² pairs – cheap because M≤7.  
4. Return \(C_5=\max_{k\in\mathcal K}F(k)\).

This evaluation is **exact** (no discretisation error) and runs in O(M³) which is negligible.

### 3. Global optimisation with Differential Evolution (DE)

DE is a robust, population‑based, derivative‑free optimiser that works with simple box constraints.  Our transformed variables live naturally in a hyper‑rectangle, so DE can be applied directly.

**Algorithmic steps**

1. **Parameter choices**  
   - Population size = 15 × (dimensions).  
   - Mutation factor F = 0.8, crossover CR = 0.9 (standard defaults).  
   - Stop when the elapsed wall‑time reaches a preset budget (see §5).  

2. **Fitness function**  
   Given a candidate vector x:
   - Recover lengths \(u_j\) and heights \(a_j\) (including the dependent last length and height).  
   - If any derived quantity violates a hard bound (negative height, length ≤0, or height > 1) assign a huge penalty (e.g. 1e6).  
   - Compute the integral residual \(r = \sum a_j u_j - 1\).  
   - If \(|r|>10^{-8}\) add a penalty term \(\lambda r^2\) with \(\lambda=10^6\).  
   - Evaluate the exact max‑overlap \(C_5\) using the analytic routine of §2.  
   - Return the penalised objective:  
     \[
     \Phi(x)=C_5 + \lambda\,r^2 + \text{large penalty for bounds}.
     \]
   Because DE minimises the fitness, lower \(C_5\) wins.

3. **Population initialisation**  
   - Sample each free variable uniformly within its box.  
   - For lengths, a Dirichlet sample can be used to bias toward roughly equal segment sizes; for heights, an exponential‑like sample ensures diversity between 0 and 1.

4. **Evolution loop**  
   - Standard DE operations (mutation, crossover, selection).  
   - After each generation compute the best fitness; keep the corresponding “best‑ever” candidate (not just the current generation) for later refinement.

5. **Termination**  
   - Stop when the overall wall‑clock time reaches the allocated budget for this phase (e.g. 200 s).  
   - Keep the best candidate found.

---

### 4. Local refinement (deterministic search)

The DE result is a good global approximation but may be slightly sub‑optimal because the objective is piecewise linear in k, causing flat regions.  A small deterministic refinement can push the solution further:

1. **Formulate a constrained nonlinear problem** with variables \(u_j, a_j\) (still respecting monotonicity via the same transformation).  
2. **Objective**: the exact \(C_5\) (non‑smooth).  Replace it by a *smooth surrogate*—the *log‑sum‑exp* of the overlap values at all breakpoints:
   \[
   \Psi_\beta = \frac{1}{\beta}\log\Bigl(\sum_{k\in\mathcal K}
                \exp\bigl(\beta\,F(k)\bigr)\Bigr)
   \]
   for a large \(\beta\) (e.g. β = 50).  This is smooth and shares the same minimiser as the max when β→∞.  
3. Use **SLSQP** (`scipy.optimize.minimize`) with explicit equality constraint \(\sum a_j u_j = 1\) and box bounds on the free variables.  
4. Initialise the optimiser at the DE best‑ever point, run for a few hundred iterations (time‑limited).  
5. After the smooth phase, switch to **subgradient descent on the true max‑overlap**: identify the current worst shift(s) \(k^*\), compute the gradient of \(F(k^*)\) w.r.t. the free variables (derived analytically from the interval‑intersection formulas), and take a diminishing stepsize \(\alpha_t = \alpha_0 / \sqrt{t}\) while re‑projecting onto the feasible box.  Perform at most a few hundred steps.

The final refined candidate will have a **guaranteed feasible** h (by construction) and, after evaluation, a *real* C₅ value (not an approximation).

### 5. Time budgeting and multi‑resolution schedule

The total wall‑clock budget is `budget_s` (≤ 600 s).  We split it as follows:

| Phase | Purpose | Approx. time |
|-------|---------|--------------|
| **A** (Coarse model) | DE on M=4 pieces, n≈128 | 0.30 · budget |
| **B** (Finer model)  | DE on M=6 pieces, n≈256 | 0.40 · budget |
| **C** (Local refinement) | SLSQP + subgradient on the best candidate from B | remaining time (≈ 0.30 · budget) |

If the budget is unusually small (< 30 s), we skip phase B and go directly from A to C with M=5.  The code will monitor `time.time()` after each major loop and break early if the remaining time falls below a safety margin (0.5 s) to guarantee a return.

### 6. Construction of the final discrete step vector

The optimiser yields a *continuous* piecewise‑constant description \((s_j,a_j)\).  To produce the required output `h_values`:

1. Choose a final discretisation size `n_points` (≤ 800, default 256).  
2. Set `dx = 2.0 / n_points`.  
3. For each index `i` (0 ≤ i < n_points) compute the coordinate `x = (i+0.5)*dx`.  
4. Find the segment `j` with `s_j ≤ x < s_{j+1}` and set `h[i]=a_j`.  
5. Due to floating‑point rounding the discrete sum may deviate from the exact integral; perform a *simple projection*: compute `delta = (np.sum(h)*dx - 1)`, then adjust all interior values uniformly within the box using the capped‑simplex projection algorithm (binary search on a Lagrange multiplier).  This step restores the exact integral constraint while preserving the shape.

Finally compute the official bound:
```python
corr = np.convolve(h, 1-h, mode='full') * dx
c5_bound = np.max(corr)
```
and return `(h.tolist(), float(c5_bound), n_points)`.

### 7. Expected performance and failure modes

- **Complexity**: DE evaluations dominate time.  For M=6 the analytic C₅ routine costs ≤ (7²)·(2·7²) ≈ 500 elementary operations, negligible compared with population handling.  With a population of ~120 and ~200 generations, each phase requires < 0.2 s on a single core.  Hence the whole schedule comfortably fits the 600 s budget even with safety margins.
- **Local minima**: DE’s stochastic nature mitigates being stuck; the subsequent deterministic refinement removes residual flat‑region artefacts.
- **Constraint violations**: The transformation guarantees all box constraints; any small numerical drift is corrected by the final projection.
- **Non‑monotone optimal shapes**: If the true optimum is not monotone, the obtained bound is still a valid *upper bound* (maybe slightly weaker).  Should the bound not improve beyond the record, we can relax the monotonicity (allow a small “bump”) by adding an extra free height variable and a soft penalty for non‑monotonicity, and re‑run the DE phase—this is a simple fallback without altering the core pipeline.
