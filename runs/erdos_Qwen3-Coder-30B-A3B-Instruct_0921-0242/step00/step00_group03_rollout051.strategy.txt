**Overview**

We must produce a step function `h` on [0,2] (sampled uniformly) satisfying  
- 0 ≤ h[i] ≤ 1  
- sum(h) = n/2 (so integral = 1)  

and minimise  
`C5 = max_k ∫ h(x) (1‑h(x+k)) dx`  
which discretely is the maximum entry of the full convolution of `h` with `1‑h`.

The problem is a constrained non‑convex optimisation over a moderate‑size vector (≈70–200). We can treat it as a continuous optimisation with simple bound and linear equality constraints and use a gradient‑based stochastic optimizer (e.g., Adam) together with projection onto the feasible set after each step. Because the objective is the maximum over many linear functionals of the vector, we can smooth it using a soft‑max (log‑sum‑exp) to obtain a differentiable surrogate, then gradually anneal the smoothing parameter.

**Key components**

1. **Feasible projection**  
   - Clip each component to [0,1].  
   - After clipping, adjust the vector to satisfy the sum constraint via a simple algorithm:  
     *Compute deficit = target_sum – current_sum.*  
     *If deficit > 0, add uniformly to components not at 1 (capped by 1). If deficit < 0, subtract uniformly from components not at 0.*  
     *Iterate until deficit ≈ 0 (few iterations because adjustments are small).  
   This yields a projection onto the intersection of the hypercube and the affine hyperplane.

2. **Objective smoothing**  
   - Let `c[k] = dx * sum_i h[i] * (1‑h[i+k])` for all integer shifts `k = -(n-1)…(n-1)`.  
   - The true objective = max_k c[k].  
   - Use `softmax_β(c) = (1/β) * log( sum_k exp(β * c[k]) )`. As β→∞, softmax_β → max.  
   - Start with a modest β (e.g., 5) and increase multiplicatively every few hundred iterations (up to ≈200) to focus the optimizer on the worst shift.

3. **Gradient computation**  
   - The convolution can be computed via FFT for speed, but for n ≤ 200 direct O(n²) is fine.  
   - Derivative of `c[k]` w.r.t. h[i] is `dx * ( (1‑h[i+k]) - h[i‑k] )` (taking care of index bounds, treating out‑of‑range as zero because h is defined only on [0,2]; using periodic wrap is incorrect – we use zero padding).  
   - For the soft‑max surrogate, gradient = Σ_k softmax_weight_k * ∂c[k]/∂h, where `softmax_weight_k = exp(β*c[k]) / Σ_j exp(β*c[j])`.

4. **Optimization loop**  
   - Initialise `h` from `initial_h_values` (provided, n≈70).  
   - Optionally randomise a fraction of entries (e.g., 5%) to escape local minima.  
   - Use Adam with learning rate ≈0.05 (tuned quickly).  
   - Every iteration: compute c, soft‑max loss, gradient, apply Adam step, then project onto feasible set.  
   - Every `proj_interval` (e.g., 10 iterations) enforce exact sum by the projection routine.  
   - Every `β_update_interval` increase β (multiply by 1.5) until a cap (≈200).  

5. **Multiple restarts & sizes**

**Potential pitfalls & mitigations**

- **Projection divergence**: The simple uniform redistribution may overshoot; guard with a maximum number of redistribution passes (e.g., 10) and fall back to solving a small linear program with `cvxpy` if needed (still cheap because n is tiny).  
- **Gradient accuracy**: Use double precision (`float64`). Verify gradient by finite differences on a tiny test to ensure sign correctness.  
- **Local minima**: After a run converges, perform a short perturbation (add small Gaussian noise with std ≈ 0.02, re‑project) and resume optimisation for a few hundred iterations; keep improvement if any.  
- **Boundary shifts**: Convolution with zero padding automatically handles the domain; ensure indexing matches `np.correlate` behaviour (full mode length = 2*n-1, shift index `k = -(n-1)…(n-1)`).

```python
def project_feasible(h, target_sum):
    h = np.clip(h, 0.0, 1.0)
    # iterative redistribution
    for _ in range(10):
        deficit = target_sum - h.sum()
        if abs(deficit) < 1e-12:
            break
        # indices that can move in needed direction
        if deficit > 0:
            idx = np.where(h < 1.0)[0]
            if len(idx) == 0: break
            delta = np.minimum(deficit/len(idx), 1.0 - h[idx])
            h[idx] += delta
        else:
            idx = np.where(h > 0.0)[0]
            if len(idx) == 0: break
            delta = np.minimum(-deficit/len(idx), h[idx])
            h[idx] -= delta
    return h
```
