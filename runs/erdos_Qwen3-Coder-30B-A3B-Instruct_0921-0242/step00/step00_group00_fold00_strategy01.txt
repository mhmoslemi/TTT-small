**Mathematical reformulation**

For a discretisation with `n` points (`dx = 2/n`) let  

```
h = (h0,…,h_{n‑1}) ,   0 ≤ hi ≤ 1 ,   Σ hi = n/2 .
```

Define the linear (zero‑padded) auto‑correlation  

```
O_k(h) = Σ_{i=0}^{n‑1‑k} hi * h_{i+k}       for k = 0,…,n‑1 .
```

The overlap integral in the statement is  

```
C5(h) = max_k  dx·Σ_i hi·(1–h_{i+k})  = 1 – min_k O_k(h) .
```

Thus **minimising** `C5` ⇔ **maximising** the worst (minimum) auto‑correlation `min_k O_k`.  The problem is a non‑convex max‑min quadratic program.

**Key idea – smooth max via log‑sum‑exp**

Instead of dealing with the non‑smooth `min_k O_k`, introduce a smooth surrogate

```
Fβ(h) =  1 – (1/β)·log Σ_{k=0}^{n‑1}  exp( β·O_k(h) ) .
```

For any `β>0` we have `Fβ(h) ≤ 1 – min_k O_k(h) = C5(h)`.  
When `β → ∞`, `Fβ(h) → C5(h)`.  Hence minimising `Fβ` provides a valid upper bound, and a sequence of increasing `β` (continuation) drives the solution toward the true objective.

**Gradient of the surrogate**

`O_k` is quadratic with a simple linear gradient:

```
∂O_k / ∂h_i =   h_{i+k}   if i + k < n          (forward term)
             + h_{i‑k}   if i - k ≥ 0           (backward term)
```

Define the soft‑max weights  

```
w_k =  exp(β·O_k) / Σ_j exp(β·O_j)   ( Σ w_k = 1 )
```

Then  

```
∇Fβ(h) = – Σ_{k=0}^{n‑1} w_k·∇O_k(h)
       = – g  ,   where
g_i = Σ_k w_k·[ h_{i+k}·1_{i+k<n} + h_{i‑k}·1_{i‑k≥0} ] .
```

All `O_k` and the weighted sum for the gradient can be computed in
`O(n log n)` using FFT‑based linear convolutions (zero padding).  

**Projection onto the feasible set**

We must keep `h` in the “capped simplex”

```
0 ≤ hi ≤ 1 ,   Σ hi = n/2 .
```

The Euclidean projection onto this set can be performed by a single
scalar‐bisection on a Lagrange multiplier λ:

```

```

Find λ such that Σ p_i(λ) = n/2 (the function Σ p_i(λ) is monotone in λ).
A few dozen bisection steps give machine precision and cost `O(n)`.
