### 1. Smooth surrogate for the minimum

For a temperature‑like parameter `α>0` define the *soft‑minimum*  

```
S_α(h) = - (1/α)·log( Σ_{k≥1} exp( -α·r_k(h) ) ).
```

Properties:  
* `S_α(h) ≤ min_{k≥1} r_k(h)` for any `α`.  
* `S_α(h) → min_{k≥1} r_k(h)` as `α → ∞`.  

We will **maximise** `S_α`.  Its gradient is analytically tractable:

```
w_k   = exp(-α·r_k) / Σ_j exp(-α·r_j)          (soft‑weights, Σ w_k = 1)
∂r_k/∂h_i = h_{i+k}   (if i+k < n)  +  h_{i‑k}   (if i‑k ≥ 0)
∇S_α = Σ_{k≥1} w_k · ∂r_k/∂h .
```

Thus each component of the gradient is a weighted sum of two shifted copies of `h`.  
All shifts can be performed efficiently with FFT‑based circular convolutions

### 2. Efficient evaluation of autocorrelations and gradients

*Zero‑padded FFT*  
1. Pad `h` with `n` zeros → length `2n`.  
2. Compute `H = FFT(padded_h)`.  
3. Autocorrelation (linear) is `r = real(IFFT( H·conj(H) ))`.  
4. Take `r[1:n]` as the needed `r_k` (`k=1,…,n‑1`).  

Because the same `FFT` is used for every gradient step, the cost per iteration
is `O(n log n)`.

The weighted sum `∑_k w_k·∂r_k/∂h` can be obtained by noticing

```
∇S_α = (w * h)  +  (reverse(w) * h)
```

where `*` denotes linear convolution and `reverse(w)` is the weight vector read
backwards.  Both convolutions are again performed by FFT in `O(n log n)`.
The resulting gradient respects the boundary conditions (indices outside
`[0,n‑1]` contribute zero).

### 3. Projection onto the feasible set (box + simplex)

Feasibility requires

```

∑ h_i = n/2 .
```

We use the *bounded simplex projection*:

1. Clip each component to `[0,1]` → `ĥ`.
