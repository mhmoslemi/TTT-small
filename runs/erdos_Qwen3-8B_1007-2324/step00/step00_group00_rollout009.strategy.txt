- Multi-level optimization that starts from a coarse grid derived from the initial 45-sample solution and gradually refines to 45 samples
- A penalty formulation that explicitly incorporates the circular structure of the expected optimal solution

The key innovation is the use of derivative-free optimization on the simplex of feasible solutions, combined with an adaptive grid size that automatically refines around promising solutions. We precompute information about the expected shift structure based on the initial solution's Fourier spectrum to guide the optimization.

2. Mathematical Specification:

Variables:
- h: A probability vector in ℝⁿ with n=45
- dx = 2/45
- cumulative sum constraint: ∑_{i=1}^{n} h_i = n/2

Objectives:
- Minimize: max_k [ (1/dx) * ∫_{0}^{2} h(x)(1-h(x+k)) dx ]

Constraints:
- 0 ≤ h_i ≤ 1 for all i
- ∑_{i=1}^{n} h_i = n/2
- Solution lives in the feasible set (determined by projection)

We use the barrier method to incorporate constraints:
- For box constraints: -log(1-|h_i|²) as barrier penalty
- For sum constraint: -log(∑|h_i - mean|²) penalty

The optimization proceeds in stages:
1. Initialization: Start from initial_h_values
2. Projection: Project onto the simplex regularized by total variation
3. Local search: Use gradient information to refine the solution

        len_o = len(h)
        correlation = np.zeros(2 * len_o - 1)
        for lag in range(-(len_o-1), (len_o-1)+1):
            correlation[lag + len_o - 1] = np.dot(h, np.roll(np.copy(1-h), lag))
        c5_val = np.max(correlation) * dx
        return c5_val

    def objective(h_flat):
        if len(h_flat) != n_points:
            return np.inf
        h = np.copy(h_flat)
        return compute_objective(h)

    # Gradient approximation for constrained optimization
    def grad_objective(h_flat):
        h = np.copy(h)
        len_o = len(h)
        # Partial derivatives not available, use finite difference
        if len_o > 1:
            dh = np.ones_like(h) * 0.01
            gradients = np.zeros_like(h)
            for i in range(len_o):
                h_plus = np.copy(h)
                h_plus[i] += dh[i]
                obj_plus = objective(h_plus)
                obj_minus = objective(h - dh[i]*np.sign(h[i]-0.5))
                # Avoid floating point issues

                    gradients[i] = (obj_plus - obj_minus) / (2 * dh[i])
                except:
