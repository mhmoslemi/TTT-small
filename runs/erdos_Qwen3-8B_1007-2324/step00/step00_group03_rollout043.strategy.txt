## 1. Approach and Rationale

The core challenge is to minimize the maximum overlap integral \(C_5 = \max_k \int h(x)(1-h(x+k)) \, dx\) for a step function \(h: [0,2] \to [0,1]\) with integral 1. The non-convex nature of this optimization and the high dimensionality at high resolutions (e.g., 280 points) suggest the need for adaptive optimization with strong heuristic components. The analytical gradient is computationally prohibitive due to the boundary-aware overlap computation, so finite-difference approximation is required. 

The proposed strategy involves:
- **Progressive Resolution**: Starting from the parent solution at 70 points and intelligently upgrading to higher resolutions (140 or 280 points) while preserving the integral condition.
- **Projected Gradient Descent with Finite-Differences**: Use finite-difference approximations for gradient components, supplemented by projected updates to stay within bounds.
- **Dynamic Learning Rate**: Adjust step sizes based on the previous iterations' best values to avoid escaping local minima.
- **Domain Awareness**: The overlap function must account for boundary effects, so the gradient will appropriately handle invalid indices.
- **Adaptive Search**: Heuristically explore shifts from -n+1 to n-1, but only the maximizing shift is used for gradient descent direction.

The primary bottleneck is the high computational cost when handling all relevant shifts explicitly, which drove the need for focused updates and resolution scaling.

## 2. Mathematical Specification

### Representation
- Input: Discrete step function as an \(n\)-point array \(h \in [0, 1]^n\) with \(\sum h = n/2\) (so \(\int h(x) \, dx = 1\) with \(dx = 2/n\))
- Variable: The step function values at each grid point.

### Objective Function
- The overlap contribution for shift \(k\) (integer index) is:
  \[\text{overlap}(h, k) = \sum_{\text{valid } i} h[i] \cdot (1 - h[i + k])\]
  This is a function of \(h\) defined only over valid indices: \(i\) is valid if both \(i\) and \(i+k\) are in \([0, n-1]\) (clamped by zero-padding/tolerance).

### Constraints
- Box constraints: \(0 \leq h[i] \leq 1\) for all \(i\)
- Integral constraint: \(\sum_i h[i] = n/2\)

### Helper Functions
- **Overlap Calculation**:
  \[
  \text{overlap}(h, k, n) = \sum_{i=\max(0, -k)}^{\min(n-1, n-1-k)} h[i] \cdot (1 - h[i+k])
  \]
  Where \(k\) is the shift index (integer).
- **Finite-Difference Gradient** (approximation for shift \(k_0\) at \(h\)):
  \[
  \nabla_j \text{overlap}(h, k_0) \approx \frac{\text{overlap}(h^{(j)}_+, k_0) - \text{overlap}(h^{(j)}_-, k_0)}{2\epsilon}
  \]
  with \(\epsilon = 1 \times 10^{-8}\).

### Optimization Steps
- The full objective is \(\max_k \text{overlap}(h, k) \cdot dx\), but we only use \(\text{overlap}\) for gradient calculation.
- All optimization is done with finite-difference gradients and explicit adaptive state management.

## 3. Implementation Procedure

### Variables
- \(n\): Number of points (70, 140, or 280)
- \(dx = 2.0 / n\)
- \(vals\) (output): The candidate \(h\) vector
- \(costs\) (output): The current minimum overlap value scaled by \(dx\)

### Parent Solution Handling
- If `initial_h_values` exists, use its upscaled version (via replication) as initial.
- Check feasibility and integral constraint before use.

### Gradient Components Calculation
- For each iteration:
  1. **Estimate Peak Overlap Shift** (\(k_0\)):
     - Compute \(\text{overlap}(h, k)\) for all \(k \in [-n+1, n-1]\) via the valid-index sum.
     - Choose \(k_0\) as the shift maximizing \(\text{overlap}\).
  2. **Finite-Difference Gradient** (\(\nabla\)) of \(\text{overlap}(\cdot, k_0)\):
     - For each \(j\), perturb \(h[j]\) to \((h[j] + \epsilon)\) and \((h[j] - \epsilon)\), recompute overlap at \(k_0\), then back out.
     - Handle boundaries by clamping during overlap calculation.

### Gradient Projection
- Update: \(h^\text{new} = h^\text{old} - \eta \cdot \nabla \cdot dx\), control \(\eta\) via previous improvement.
- Project to [0, 1] by clipping.
- Restore integral constraint by scaling if \(\sum h^\text{new} \neq n/2\).

### Initialization
- Start with `initial_h_values` replicated to target `n` (if available) and proceed to gradient descent.

### Projection & Normalization
- **Box Constraints**: Clip values to [0, 1].
- **Integral Constraint**: Scale by \(1 / (\text{current sum})\) to set \(\sum h = n/2\).

### Output
- After the allowed time, return the best-known \(h\) and its cost computed via: \(dx \times \max_k \text{overlap}(h, k)\).
