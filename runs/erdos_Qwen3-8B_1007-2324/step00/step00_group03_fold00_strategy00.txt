  ```python  
          if abs(new_sum - n_samples/2) > 0.01:  
              x = np.clip(x, 0, 1)  
              # Manual projection if constraint violated  
              a = np.linalg.norm(x)  
              b = len(x)/2 * dx  # Target constraint  
              if a < b:  
                  scale = (b / a)  
                  x *= scale  
              else:  
                  # Add noise/x-over to reach constraint  
                  x += (b - a) / len(x) * np.random.randn(len(x))  
          x_best = min(x_best, f(x))  # Track best cost  
          # Apply stop condition if stuck  
          if iter % 10 == 0 and all(d[i] < 1e-4 for i in range(len(d))):  
              break  
      return x_best, x  
  ```
