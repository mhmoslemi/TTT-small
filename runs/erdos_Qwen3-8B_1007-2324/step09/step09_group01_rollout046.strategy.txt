1. Approach and rationale
The central idea is to optimize the "two-interval symmetric stepfunction" representation using a more sophisticated optimization algorithm than the previous SLSQP. We replace SLSQP with a Bayesian optimization approach using Tree of Parzen Estimators (TPE) from OptimizeBayes, which is better suited for non-convex problems with few function evaluations. This method explores the space of functions defined by their breakpoints and heights within fixed-duration intervals, rather than just step functions. The key improvements are:
   - Broader exploration: Consider functions with 2-6 fixed-duration intervals (widths) instead of just two
   - Adaptive interval scheduling: Start with coarser intervals and refine as the optimization progresses
   - No gradient required: TPE handles exploration vs exploitation balance properly
   - Feasibility repair: Automatically scales the function to meet the integral constraint without destroying structure
   - Bayesian optimization: More efficiently uses function evaluations compared to SLSQP
   
This addresses the bottleneck of local optimization by using a global optimizer that intelligently balances exploration and exploitation.

2. Mathematical specification
We define piecewise constant functions with fixed-duration intervals at integer start positions. The function is defined by:
   - Number of intervals (n_segments, between 2 and 6)
   - Start positions (start_i) for each interval (non-decreasing integers between 0 and n_points-1)
   - End positions (end_i) for each interval (end_i = start_i + n_half, ensuring the function is symmetric over the interval)
   - Heights (heights_i) between 0 and 1 for each interval

The function is built by interpolating constant height onto the grid points between start_i and end_i. The integral constraint is maintained through a repair mechanism. The objective is evaluated by computing the maximum correlation between the function and its time-shifted complement.
