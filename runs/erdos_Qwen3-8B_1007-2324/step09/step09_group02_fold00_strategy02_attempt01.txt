     - Constraint: bounds [0,1] and equality integral (handled via SLSQP).
   - **Smoothness**: C5 is continuous but not differentiable everywhere; however, the max operation changes when multiple lags bind, but the gradient at those points requires subgradient handling, here approximated numerically.

3. Implementation procedure
   - **Input**: n, dx (fixed as 2.8), target integral 1. Initial point defined by 'initial_h_values' if available.
   - **Step 1: Validate and initialize**
     - If 'initial_h_values' available, h_full = np.concatenate([initial_h_values, initial_h_values[::-1]]) for feasibility check (assert 0 <= min(initial_h_values) <= max <=1 and |sum(h_full) - 140| < 1e-4).
     - Else seed with random half-h vector: h = np.random.random(nhalfo) * 0.5 + 0.25, then adjust symmetry.
   - **Step 2: Define objective and gradient functions**
     - Objective function:
       ```python
       def obj_func(h):
           h_full = np.concatenate([h, h[::-1]])
           corr = np.correlate(h_full, 1 - h_full, mode='full')
           return np.max(corr) * dx
       ```
     - Gradient approximation (central difference):
       ```python
       def grad_func(h):
           n_half = len(h)
           grad = np.zeros(n_half)
           for i in range(n_half):
               # Compute f at +delta
               h_plus = h.copy()
               h_plus[i] += delta
               hp_full_plus = np.concatenate([h_plus, h_plus[::-1]])
               corr_plus = np.correlate(hp_full_plus, 1 - hp_full_plus, mode='full')
               f_plus = np.max(corr_plus) * dx
               # Compute f at -delta
               h_minus = h.copy()
               h_minus[i] -= delta
               hp_full_minus = np.concatenate([h_minus, h_minus[::-1]])
               corr_minus = np.correlate(hp_full_minus, 1 - hp_full_minus, mode='full')
               f_minus = np.max(corr_minus) * dx
               # Central difference
               grad[i] = (f_plus - f_minus) / (2 * delta)
           return grad
       ```
       Use delta=1e-5 for numerical stability.
     - Constraint function:
       ```python
       def constraint_func(x):
           return sum(np.concatenate([x, x[::-1]])) - 140.0
       ```
   - **Step 3: Global search with multiple local optima**
     - Generate M diverse populations (default M=5):
       - For each population index m=0 to 4:
         - Perturb initial_h by random noise: magnitude σ = initial_h / (10*m) (to explore differently).
         - If m == 0 (first), start from initial_h, else from Gaussian noise: h_rand = initial_h.copy() + np.random.normal(0, 0.02, nhalfo)  [0,1] clipping.
         - Augment to full vector and compute obj value.
     - Use SciPy's minimize with:
       ```python
       from scipy.optimize import minimize, SLSQP
       bounds = [(0.0, 1.0) for _ in range(nhalfo)]
       cons = {'type': 'eq', 'fun': constraint_func}
       result = minimize(obj_func, h, method='SLSQP', bounds=bounds, constraints=cons, jac=grad_func, options={'maxiter': 100, 'ftol': 1e-4})
       ```
       Note: obj_func includes the approximate gradient (grad_func). Initial maxiter chosen for balance; if obj decreases slowly, reduce n.
   - **Step 4: Evaluate and select best**
     - Keep track of best_C5 across all populations.
     - Record h value and C5.
   - **Step 5: Hyperparameter adaptation**
     - After 40% time or 2 generations, if no improvement: increase population diversity by adding uniform noise to best candidate.
     - If constraint is violated (detected separately), scale to satisfy, then re-optimize.
     - Track progress: stop if time exceeds budget or obj stops improving by factor 1.001.
   - **Step 6: Return best found**
     - Full h_full = np.concatenate([best_h, best_h[::-1]])
     - Verify: C5_computed = max(np.correlate(h_full, 1-h_full, mode='full')) * dx, then assert 0 <= min(full_h) <= max <=1 and |sum(full_h) - 140| < 1e-4.
     - Also, allow fallback if functions return NaN/inf by reverting to previous best.
