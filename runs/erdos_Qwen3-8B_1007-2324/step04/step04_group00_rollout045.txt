def generate_h_vectorized(M, params, n_points, dx):

    h = np.zeros_like(x)
    if M == 2:

        b2 = 2.0 - b1
        # pulse1: start=0, width=b1
        # pulse2: start=b1, width=b2
        for (start, width) in [(0.0, b1), (b1, b2)]:
            # compute the pulse values
            in_range = (x >= start) & (x <= start + width)
            x_in = x[in_range]
            # compute values for in_range
            # split into left and right of peak
            peak_pos = start + width / 2
            left = (x_in <= peak_pos)
            right = ~left
            val = np.zeros_like(x)
            val[in_range] = np.where(left, 2 * (x_in - start) / width, 2 * (start + width - x_in) / width)
            h += val
    elif M ==3:

        b3 = 2.0 - b1 -b2

            right = ~left
            val = np.zeros_like(x)
            val[in_range] = np.where(left, 2 * (x_in - start) / width, 2 * (start + width - x_in) / width)
            h += val
    h = np.clip(h, 0, 1)
    return h

This approach is more efficient using vectorized operations.

Once the h_values are generated, compute the correlation.

The correlation is calculated as np.correlate(h, 1-h, mode='full') * dx. But since the h is generated as a step function, the correlation is computed over all shifts.

But the code in the previous example uses np.correlate with mode='full', which returns the cross-correlation of h and (1-h) over all possible shifts.

The 'full' mode returns the cross-correlation at all shifts, which for h of length n and 1-h of length n is of length 2n - 1. The maximum value of this is the maximum overlap integral.

Thus, the code for computing the correlation:

def compute_correlation(h_values, n_points, dx):
    # Compute (1 - h) as a new array
    one_minus_h = 1.0 - h_values
    corr = np.correlate(h_values, one_minus_h, mode='full')
    # The max value is the maximum correlation
    max_corr = np.max(corr) * dx
    return max_corr
