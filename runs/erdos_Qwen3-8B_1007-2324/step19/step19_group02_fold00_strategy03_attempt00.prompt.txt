1) A multi-resolution optimization strategy that solves the problem on a sequence of increasing resolutions, from coarse to fine, upgrading the solution stage-by-stage to gradually improve accuracy.

2) A flexible solution representation that supports two formats: (a) standard step function with n_points samples, and (b) sparse compact representation suitable for coarser resolutions and local optimization.

3) A hybrid optimization system combining global Search (GlS) with (a) fireworks algorithm (WA) for global exploration at coarse resolutions, (b) reached for local refinement at finer experiments, and (c) SLSQP for terminal polishing.

This three-phase strategy systematically explores the solution space while gradually improving the candidate's accuracy, avoiding local optima and handling constraints more effectively than current approaches.

1) Variables:
- n_points (number of samples, even) determines the solution's resolution
- h_values (vector of length L = n_points//2) represents the half-constraint (integral constraint is defined for the full step function)

2) Objective function:

C5(h) = max_lag(correlation(h, 1-h) · dx)

Where:
- correlation is computed using mode='full' on the concatenated vector [h, h[::-1]]
- dx = 2.0/n_points
- max_lag is taken over all integer lags

3) Constraints:
- Box constraints: 0 ≤ h[i] ≤ 1 for all i
- Linear equality: sum(h)[0:L] = n_points/4 (so full integral is 1)

4) Solution representations:
- Standard representation: vector of length n_points
- Sparse representation: vector of positions and values for a binary-like solution
