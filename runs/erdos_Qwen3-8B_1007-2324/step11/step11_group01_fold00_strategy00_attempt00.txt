1. Approach and rationale
The current method uses a local search (simulated annealing) starting from a parent solution. While effective for refinement, it may not escape local optima. We change to a population-based global optimizer, CMA-ES (Covariance Matrix Adaptation Evolution Strategy), which is well-suited for high-dimensional black-box optimization problems with expensive function evaluations. CMA-ES maintains a population mean and covariance matrix to explore the search space efficiently under given constraints. We use the available parent solution as an initial guess and repair candidates to maintain the integral constraint and feasible space.

2. Mathematical specification
- Representation: Discrete vector of length `n_points` representing values of h(x) at grid points.
- Objective: Minimize C5 = max_k ∫ h(x)(1-h(x+k)) dx (over integer shifts k)
- Constraints: 0 ≤ h[i] ≤ 1 ∀ i, sum(h_i * dx) = 0.5 where dx = 2.0/n_points
- Repair function: Sort dimensions by distance from grid center, assign values in descending order.
- Repair computation: Scale vector to meet integral target, clip to [0,1].
- Optimization: CMA-ES minimizes the repair-transformed objective function, using numerical convolution to compute the correlation.
