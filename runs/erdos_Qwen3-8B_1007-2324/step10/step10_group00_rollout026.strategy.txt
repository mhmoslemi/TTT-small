$$C_5=\max_k\inth(x)(1-h(x+k))dx$$

subject to:
1. $0 \leq h(x) \leq 1$ for all x
2. $\int_0^2 h(x)  dx = 1$

The function is defined on the interval [0,2] and represented with n_points samples (dx = 2.0 / n_points). The objective is evaluated via discrete convolution, scaled by dx.

## 1. Approach and Rationale

- Maintain a population of candidate solutions.
- Use tournament selection for parent selection.
- Apply one-point crossover to generate new offspring.
- Use Gaussian mutation for exploration.
- Repair any infeasible candidates (those not satisfying integral=1 or domain constraints) by clipping and rescaling.
- Allow injecting random exploratory pushes to escape local optima.

This GA strategy aims to find a candidate that significantly outperforms the parent's 0.381277 bound by leveraging population diversity and effective mutation.

## 2. Mathematical Specification

### Variables
- **n_points**: Number of discrete samples (280).
- **dx = 2.0 / n_points**: The width of each sample interval.
- **desired_sum = n_points / 2**: Ensures ∫h(x)dx = dx * desired_sum = 1.
- **h**: A NumPy array of length n_points. Any candidate h must satisfy:
    - 0 ≤ h[i] ≤ 1 for all i
    - ∑h[i] = desired_sum

### Objective Function
For a candidate vector `h`, compute:
- **full representation**: `h_full = np.concatenate([h, h[::-1]])`
- **correlation**: `corr = np.correlate(h_full, 1 - h_full, mode='full')`
- **objective value**: `C_5 = np.max(corr) * dx`

The goal is to minimize C_5. Lower C_5 values provide tighter upper bounds.

### Constraints
- **Integral constraint**: dx * ∑h[i] = 1 ⇒ ∑h[i] = desired_sum
- **Domain constraint**: Each h[i] ∈ [0, 1]
