### 1. Approach and rationale
The current approach uses SLSQP optimization on a dense grid representation, which is computationally expensive due to the O(n²) correlation operation. The proposed approach reformats the grid representation as a sparse set of disjoint, contiguous intervals (blocks) where the function takes value 1. The total number of grid points in these intervals must sum to n/2 (grid integral 1). The optimization becomes more efficient:
- Each candidate solution is defined as a set of disjoint intervals (contiguous grid points)
- The objective function computes the maximum correlation using these intervals
- The grid representation is maintained only for evaluation
This reduces the effective number of parameters and leverages the structure of step functions.

The key improvements:
1. Fewer parameters (typically 2-4 intervals) instead of n parameters
2. Cheaper objective function evaluation through the contiguous interval representation
3. Better control over the solution structure to avoid arbitrary oscillations

However, the primary challenge is ensuring the intervals remain disjoint and the total cover exactly n/2 points, while the secondary challenge is translating this representation to a grid with minimal distortion.

### 2. Mathematical specification
Variables:
- n - grid size (140 or 280 points)
- m - number of intervals (typically 2-4)
- s_i, e_i for i=1,...,m - start and end indices (grid points) of intervals

Objective:
Minimize max_k [integral h(x)(1-h(x+k))dx] = max_k [dx * (sum_{x} h(x)(1-h(x+k))] scaled by dx=2/n

Constraints:
1. 0 ≤ s_i ≤ e_i ≤ n-1
2. Intervals disjoint: s_{i+1} ≥ e_i + 1 (ensuring gaps)
3. Total coverage: sum_{i=1}^m (e_i - s_i + 1) = n/2

Representation:
- Intervals define which grid points are covered (h[i]=1)
- The function is extended linearly between grid points as needed

Optimization framework:
- SLSQP with bounds and nonlinear constraints
- Initial points derived from parent solution

Comparison to the original:
- The original function called np.correlate O(n²) times, making its cost O(n⁴) due to the grid size
- The new objective computes the same from sparse intervals, reducing computation by O(n²)
