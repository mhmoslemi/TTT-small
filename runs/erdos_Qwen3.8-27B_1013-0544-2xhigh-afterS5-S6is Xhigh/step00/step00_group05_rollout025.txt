Let me think about the gradient. For a given h, let k* be the argmax lag. Then:
∂f_{k*}/∂h[i] = dx * (1 - h[i+k*]) - dx * h[i-k*] (with appropriate bounds, considering both i and i as part of the pair)

Actually, f_k = dx * sum_{i=0}^{n-1-k} h[i]*(1-h[i+k]) for k > 0.
∂f_k/∂h[i] = dx * (1-h[i+k]) for i < n-k, and also from the term where i appears as i+k, i.e., from h[i-k]*(1-h[i]) when i-k ≥ 0: ∂/∂h[i] of h[i-k]*(1-h[i]) = -dx*h[i-k].

So ∂f_k/∂h[i] = dx*(1-h[i+k]) - dx*h[i-k] (with terms that are 0 when indices are out of range).

For the negative lag: f_{-k} = dx * sum_{i=0}^{n-1-k} h[i+k]*(1-h[i])
∂f_{-k}/∂h[i] = -dx*h[i+k] + dx*(1-h[i-k]) (with bounds)

Note that f_{-k} and f_k are related but not equal in general (unless h is symmetric).

Actually, looking at np.correlate more carefully:
np.correlate(h, 1-h, mode="full") computes:
result[m] = sum_i h[i] * (1-h)[i - m + n - 1] (with bounds)

Let me just define it cleanly. Let a = h, v = 1-h, both length n.
result = np.correlate(a, v, mode="full") has length 2n-1.
result[n-1] = sum_i a[i]*v[i] (zero lag)
result[n-1+k] = sum_i a[i+k]*v[i] for k=1,...,n-1 (this is "a shifted right by k correlated with v")
result[n-1-k] = sum_i a[i]*v[i+k] for k=1,...,n-1

So:
result[n-1+k] = sum_{i=0}^{n-1-k} h[i+k]*(1-h[i])
result[n-1-k] = sum_{i=0}^{n-1-k} h[i]*(1-h[i+k])

The C₅ = max(result) * dx.

For the gradient of result[n-1+k] with respect to h[j]:
= sum_{i: i+k=j} (1-h[i]) + sum_{i: i=j} h[i+k]*(-1)
= (1-h[j-k]) [if j≥k] - h[j+k] [if j+k < n]

For result[n-1-k] with respect to h[j]:
= sum_{i: i=j} (1-h[i+k]) + sum_{i: i+k=j} h[i]*(-1)
= (1-h[j+k]) [if j+k<n] - h[j-k] [if j≥k]

So the gradient of result[n-1±k] w.r.t. h[j] is:
For +k: (1-h[j-k]) - h[j+k] (with 0 for out-of-bounds)
For -k: (1-h[j+k]) - h[j-k] (with 0 for out-of-bounds)

The subgradient of max is the average of gradients of all active constraints (those achieving the max).

For projected gradient descent:
1. Compute all result values
2. Find the max (and which lags achieve it)
3. Compute gradient as average of active gradients
4. Take a step in the negative gradient direction
5. Project onto feasible set: 0 ≤ h[i] ≤ 1, sum(h) = n/2

The projection onto {h: 0≤h[i]≤1, sum(h)=n/2} can be done via bisection on a Lagrange multiplier (water-filling).

Actually, for this type of problem (minimizing max of linear-ish functions over a polytope), a good approach is:

1. **Iterative proportional fitting / multiplicative weights**: Not directly applicable here.

2. **Alternating minimization**: Fix all but one coordinate, optimize that coordinate.

3. **Cutting plane / bisection on C₅ value**: Binary search on C₅, check feasibility via LP.

The LP approach: For a given C₅ = c, check if there exists h with:
- 0 ≤ h[i] ≤ 1
- sum(h) = n/2
- For all k: dx * sum_{valid} h[i](1-h[i+k]) ≤ c

The constraints are bilinear (h[i]*h[i+k]), so it's not a standard LP. But if we fix h to be binary, it becomes: for each k, the number of 1→0 transitions ≤ c * n / 2.

Actually, for non-binary h, the constraint h[i](1-h[i+k]) ≤ c*dx is not linear. We could linearize it: h[i](1-h[i+k]) ≤ c*dx is equivalent to... well it's a product, so not linear.

However, we can use the fact that for h[i] ∈ [0,1]:
h[i](1-h[i+k]) = h[i] - h[i]*h[i+k]

And h[i]*h[i+k] ≥ h[i] + h[i+k] - 1 (since (h[i]-h[i+k])² ≥ 0 ... no that gives h[i]² + h[i+k]² ≥ 2h[i]h[i+k])

Actually, a lower bound: h[i]*h[i+k] ≥ max(0, h[i] + h[i+k] - 1) (this is a valid relaxation since h[i]h[i+k] ≥ h[i]+h[i+k]-1 for h[i],h[i+k] ∈ [0,1]).

So h[i](1-h[i+k]) = h[i] - h[i]h[i+k] ≤ h[i] - max(0, h[i]+h[i+k]-1)

If h[i]+h[i+k] ≤ 1: h[i](1-h[i+k]) ≤ h[i]
If h[i]+h[i+k] > 1: h[i](1-h[i+k]) ≤ h[i] - (h[i]+h[i+k]-1) = 1 - h[i+k]

```python
import numpy as np
import time

def evaluate_c5(h, n_points):
    dx = 2.0 / n_points
    return float(np.max(np.correlate(h, 1.0 - h, mode="full") * dx))

def compute_gradient(h, n_points):
    """Compute subgradient of C5 at h."""
    n = n_points
    dx = 2.0 / n
    v = 1.0 - h
    corr = np.correlate(h, v, mode="full")
    max_val = np.max(corr)
    
    # Active set: lags within epsilon of max
    eps = max(1e-8, max_val * 1e-8)
    active = np.where(corr >= max_val - eps)[0]
    
    grad = np.zeros(n)
    for lag_idx in active:
        k = lag_idx - (n - 1)
        g = np.zeros(n)
        if k == 0:
            g[:] = 1.0 - 2.0 * h
        elif k > 0:
            # corr[n-1+k] = sum_{i=0}^{n-1-k} h[i+k]*(1-h[i])
            # d/dh[j]: (1-h[j-k]) for j in [k, n-1] minus h[j+k] for j in [0, n-1-k]
            g[k:] += (1.0 - h[:n-k])
            g[:n-k] -= h[k:]
        else:
            ka = -k
            # corr[n-1-ka] = sum_{i=0}^{n-1-ka} h[i]*(1-h[i+ka])
            # d/dh[j]: (1-h[j+ka]) for j in [0, n-1-ka] minus h[j-ka] for j in [ka, n-1]
            g[:n-ka] += (1.0 - h[ka:])
            g[ka:] -= h[:n-ka]
        grad += g
    
    grad /= len(active)
    return max_val * dx, grad

def project_feasible(h, n_points):
    """Project h onto {0<=h<=1, sum(h)=n/2} using bisection."""
    target = n_points / 2.0
    lo, hi = -2.0, 2.0
    for _ in range(60):
        mid = (lo + hi) / 2.0
        h_proj = np.clip(h - mid, 0.0, 1.0)
        s = np.sum(h_proj)
        if s > target:
            lo = mid
        else:
            hi = mid
    h_proj = np.clip(h - (lo + hi) / 2.0, 0.0, 1.0)
    # Adjust sum exactly
    diff = target - np.sum(h_proj)
    if abs(diff) > 1e-12:
        interior = (h_proj > 1e-10) & (h_proj < 1.0 - 1e-10)
        ni = np.sum(interior)
        if ni > 0:
            h_proj[interior] += diff / ni
            h_proj = np.clip(h_proj, 0.0, 1.0)
    return h_proj

def gradient_descent(h, n_points, max_iters=5000, lr_init=0.5):
    h = h.copy()
    best_h = h.copy()
    best_c5 = evaluate_c5(h, n_points)
    lr = lr_init
    
    for it in range(max_iters):
        c5, grad = compute_gradient(h, n_points)
        if c5 < best_c5:
            best_c5 = c5
            best_h = h.copy()
        
        h_new = h - lr * grad
        h_new = project_feasible(h_new, n_points)
        
        c5_new = evaluate_c5(h_new, n_points)
        if c5_new < c5 - 1e-12:
            h = h_new
        else:
            lr *= 0.7
            if lr < 1e-8:
                break
    
    return best_h, best_c5

def binary_local_search(h, n_points, max_rounds=200):
    """Greedy local search on binary sequences."""
    h = (h >= 0.5).astype(np.float64)
    best_c5 = evaluate_c5(h, n_points)
    n = n_points
    
    for round in range(max_rounds):
        improved = False
        ones = np.where(h == 1.0)[0]
        zeros = np.where(h == 0.0)[0]
        
        if len(ones) == 0 or len(zeros) == 0:
            break
        
        best_delta = 1e-10
        best_pair = None
        
        # Try all pairs (i in ones, j in zeros)
        # For efficiency, try random subset if too many
        n_ones = len(ones)
        n_zeros = len(zeros)
        
        if n_ones * n_zeros <= 50000:
            for i in ones:
                for j in zeros:
                    h[i] = 0.0
                    h[j] = 1.0
                    c5 = evaluate_c5(h, n_points)
                    delta = c5 - best_c5
                    if delta < best_delta:
                        best_delta = delta
                        best_pair = (i, j)
                    h[i] = 1.0
                    h[j] = 0.0
        else:
            # Random sampling
            n_trials = 50000
            for _ in range(n_trials):
                i = ones[np.random.randint(n_ones)]
                j = zeros[np.random.randint(n_zeros)]
                h[i] = 0.0
                h[j] = 1.0
                c5 = evaluate_c5(h, n_points)
                delta = c5 - best_c5
                if delta < best_delta:
                    best_delta = delta
                    best_pair = (i, j)
                h[i] = 1.0
                h[j] = 0.0
        
        if best_pair is not None:
            i, j = best_pair
            h[i] = 0.0
            h[j] = 1.0
            best_c5 = best_c5 + best_delta
            improved = True
        
        if not improved:
```

```python
        ones = np.where(h == 1.0)[0]
        zeros = np.where(h == 0.0)[0]
        if len(ones) == 0 or len(zeros) == 0:
            break
        i = ones[np.random.randint(len(ones))]
        j = zeros[np.random.randint(len(zeros))]
        h[i], h[j] = 0.0, 1.0
        nc = eval_c5(h, n)
        d = nc - cc
        if d < 0 or np.random.random() < np.exp(-d / max(T, 1e-12)):
            cc = nc
            if nc < bc:
                bc, bh = nc, h.copy()
        else:
            h[i], h[j] = 1.0, 0.0
    return bh, bc

def run(seed=42, budget_s=1100, **kwargs):
    np.random.seed(seed)
    t0 = time.time()
    bh, bc, bn = None, float('inf'), 0

    try:
        h_init = np.array(initial_h_values, dtype=np.float64)
        n_init = len(h_init)
    except Exception:
        h_init = None
        n_init = 0

    # Phase 1: Optimize initial construction
    if h_init is not None and n_init % 2 == 0:
        h1, c1 = bin_ls(h_init, n_init, rounds=300)
        if c1 < bc:
            bc, bh, bn = c1, h1.copy(), n_init
        h2, c2 = grad_descent(h1, n_init, iters=5000)
        if c2 < bc:
            bc, bh, bn = c2, h2.copy(), n_init
        h3, c3 = bin_ls(h2, n_init, rounds=300)
        if c3 < bc:
            bc, bh, bn = c3, h3.copy(), n_init
        if time.time() - t0 < budget_s * 0.4:
            h4, c4 = sa(h3, n_init, iters=60000)
            if c4 < bc:
                bc, bh, bn = c4, h4.copy(), n_init

    # Phase 2: Try various n with random/structured starts
    time_limit = budget_s * 0.85
    n_list = [40, 44, 48, 52, 56, 60, 64, 68, 70, 72, 76, 80, 84, 88, 92, 96, 100, 110, 120, 140, 160]
    n_list = [x for x in n_list if x != n_init]

    for n in n_list:
        if time.time() - t0 > time_limit:
            break
        n_restarts = 4 if n <= 72 else 2
        for r in range(n_restarts):
            if time.time() - t0 > time_limit:
                break
            if r == 0:
                # Structured: every other position
                h = np.zeros(n)
                h[::2] = 1.0
            elif r == 1:
                # Block structure
                h = np.zeros(n)
                h[:n // 2] = 1.0
            else:
                h = np.zeros(n)
                h[np.random.choice(n, n // 2, replace=False)] = 1.0

            h, c = bin_ls(h, n, rounds=100)
            if c < bc:
                bc, bh, bn = c, h.copy(), n
            h2, c2 = grad_descent(h, n, iters=2000)
            if c2 < bc:
                bc, bh, bn = c2, h2.copy(), n
            if time.time() - t0 < time_limit * 0.6:
                h3, c3 = sa(h2, n, iters=20000)
                if c3 < bc:
                    bc, bh, bn = c3, h3.copy(), n

    # Phase 3: Polish best solution
    if bh is not None and time.time() - t0 < budget_s * 0.92:
        bh2, c = bin_ls(bh, bn, rounds=500)
        if c < bc:
            bc, bh = c, bh2
        bh2, c = grad_descent(bh, bn, iters=5000)
        if c < bc:
            bc, bh = c, bh2
        bh2, c = bin_ls(bh, bn, rounds=500)
        if c < bc:
            bc, bh = c, bh2
        if time.time() - t0 < budget_s * 0.97:
            bh2, c = sa(bh, bn, iters=30000)
            if c < bc:
                bc, bh = c, bh2
            bh2, c = bin_ls(bh, bn, rounds=200)
            if c < bc:
                bc, bh = c, bh2

    if bh is None:
        n = 70
        bh = np.zeros(n)
        bh[:n // 2] = 1.0
        bc = eval_c5(bh, n)
        bn = n

    return bh, bc, bn
```
