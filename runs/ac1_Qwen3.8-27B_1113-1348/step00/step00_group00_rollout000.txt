Return a flat coefficient sequence that attains the hard lower bound of the

For any sequence clipped to non-negative values a_i by the evaluator:

  c_0 = sum_i a_i^2

so max_b = c_0.  By Cauchy-Schwarz,

  c_0 >= (sum_i a_i)^2 / n,

hence

  2 * n * max_b / (sum_i a_i)^2 >= 2.

Equality is attained by any nonzero constant sequence.  The function below
therefore returns a constant sequence, preferring the length of the available
reference construction if it is affordable.  It also checks a few short flat
candidates with the provided evaluator and keeps a genuinely lower score if
one appears.
"""
