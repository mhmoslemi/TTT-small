correlate[k] = sum_{i: 0≤i<n, 0≤i+k<n} h[i+k] * v[i]

For v = 1-h:
correlate[k] = sum_{valid i} h[i+k] * (1 - h[i])

d(corr[k])/d(h[m]) = 
  (1-h[i]) for terms where m = i+k (i.e., i = m-k must be valid)
  + h[i+k] * (-1) for terms where m = i (i.e., i = m must be valid)

So:
d(corr[k])/d(h[m]) = (1-h[m-k]) * valid(m-k) - h[m+k] * valid(m)

where valid(x) means 0 ≤ x < n AND the pair (x, x+k) is in the sum.

More precisely:
- The term (1-h[m-k]) contributes if m-k is a valid index in the sum, i.e., 0 ≤ m-k < n AND 0 ≤ (m-k)+k < n, i.e., 0 ≤ m-k < n AND 0 ≤ m < n. Since m is in [0,n-1], the second condition is automatic. So we need 0 ≤ m-k < n.
- The term -h[m+k] contributes if m is a valid index in the sum, i.e., 0 ≤ m < n AND 0 ≤ m+k < n. Since m is in [0,n-1], we need 0 ≤ m+k < n.

So:
d(corr[k])/d(h[m]) = (1-h[m-k]) * [0 ≤ m-k < n] - h[m+k] * [0 ≤ m+k < n]

This is clean. Let me verify with a small example.

n=3, h = [a, b, c], k=1:
corr[1] = h[0+1]*(1-h[0]) + h[1+1]*(1-h[1]) = b*(1-a) + c*(1-b)

d(corr[1])/d(a) = -b (from the -h[a+k] term, m=0, m+k=1, valid) + (1-h[a-1]) where a-1=-1, not valid. So d/d(a) = -b. ✓
d(corr[1])/d(b) = (1-h[0]) + (1-h[1]) - h[2] - h[0+1]... 

Wait let me recompute. m=1 (b):
(1-h[m-k]) = 1-h[0] = 1-a, valid since m-k=0.
-h[m+k] = -h[2] = -c, valid since m+k=2.
d/d(b) = (1-a) - c.

Check: corr[1] = b(1-a) + c(1-b). d/d(b) = (1-a) - c. ✓

m=2 (c):
(1-h[m-k]) = 1-h[1] = 1-b, valid since m-k=1.
-h[m+k] = -h[3], not valid since 3 ≥ n.
d/d(c) = (1-b).

Check: d/d(c) of b(1-a) + c(1-b) = (1-b). ✓

Now, for the optimization, I'll use a projected subgradient method:
1. Compute all correlate values
2. Find the top few lags (within epsilon of max)
3. Compute gradient as average of gradients for those lags
4. Take step: h = h - lr * grad
5. Project to {0 ≤ h ≤ 1, sum(h) = n/2}

The projection to the constraint set {0 ≤ h ≤ 1, sum(h) = n/2} is:
- This is the intersection of a hypercube and a hyperplane
- The projection can be found by: find λ such that sum(clamp(h - λ, 0, 1)) = n/2

This is a 1D root-finding problem (bisection on λ).

smooth_max ≈ (1/τ) * log(sum(exp(τ * corr[i]))) for small τ

This gives a smooth objective that we can minimize with L-BFGS-B. But it might be less accurate.

Let me also think about the binary projection. If the optimal solution is binary (0/1), then we only need to choose which n/2 positions are 1. This reduces the problem to a combinatorial search. But the optimal solution might not be exactly binary.

Actually, for this type of problem (minimize max of quadratic functions over a polytope), the optimal solution is often at a vertex (i.e., binary). Let me check: at a vertex, h[i] ∈ {0,1} for all i, and exactly n/2 are 1. The objective at a vertex is:
C5_binary = max_k |{i: h[i]=1, h[i+k]=0}| * dx (for k≠0)
            = 0 * dx (for k=0, since h(1-h)=0)

Wait, at k=0: h[i]*(1-h[i]) = 0 for all i. So the k=0 term is always 0 for binary h.

For k≠0: the term counts the number of "1→0" transitions at distance k.

So for binary h, C5 = max_{k≠0} count_1to0(k) * dx where count_1to0(k) = |{i: h[i]=1, h[i+k]=0}|.

Note that count_1to0(k) + count_0to1(k) + count_1to1(k) + count_0to0(k) = n - |k| (for |k| < n, linear shift)
And count_1to0(k) + count_1to1(k) = number of 1s in position i where i+k is valid.

This is a combinatorial optimization problem. For n=47, we can't brute force it (C(47,23) is enormous). But we can use local search (swap two bits).

Phase 1: Start from initial_h_values, optimize with SLSQP → get a good continuous solution
Phase 2: Round to binary (n/2 ones, n/2 zeros) using rounding + local swap search
Phase 3: Random binary restarts with local swap search
Phase 4: Refine the best binary solution back to continuous with SLSQP

    h = np.array(h, dtype=float)

    result = np.zeros(n)
    result[sorted_idx[:n//2]] = 1.0

def project_feasible(h, target_sum):
