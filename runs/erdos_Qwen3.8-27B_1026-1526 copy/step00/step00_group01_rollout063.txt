def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    c = np.correlate(h, 1.0 - h, mode="full") * dx
    return np.max(c), c

def gradient_c(h, c):
    """Compute matrix G where G[m, k] = d c[k] / d h[m]"""
    n = len(h)
    G = np.zeros((n, 2*n-1))
    for k in range(2*n-1):
        shift = k - (n-1)
        for m in range(n):
            g = 0.0
            if 0 <= m - shift < n:
                g += 1.0 - h[m - shift]
            if 0 <= m + shift < n:
                g -= h[m + shift]
            G[m, k] = g
    return G

def project(h, target_sum):

        s = np.sum(proj)
        if s > target_sum:
            lo = mid
        else:
            hi = mid
    return np.clip(h - (lo+hi)/2, 0, 1)

  - Second part: h shifted left by s (with zeros on the right) = [h[s], h[s+1], ..., h[n-1], 0...0]

  - First part: (1-h) shifted right by s' = (1-h) shifted left by |s|... 

Hmm, let me just define it clearly.

Let a = 1-h (length n), b = h (length n).

For shift s (negative or positive):
Part A: A[m] = a[m-s] = 1-h[m-s] if 0 ≤ m-s < n, else 0
Part B: B[m] = b[m+s] = h[m+s] if 0 ≤ m+s < n, else 0
G[:, k] = A - B (times dx)

A is a "left shift" of a by s positions (if s > 0) or "right shift" by |s| positions (if s < 0), with zero-padding.
B is a "right shift" of b by s positions (if s > 0) or "left shift" by |s| positions (if s < 0), with zero-padding.

In numpy:
For s > 0:

  B = np.concatenate([b[s:], np.zeros(s)])  # b shifted left by s (padded with zeros at end)

For s = 0:

  B = b

So I can vectorize the gradient computation:

```python
def grad_c(h):
    n = len(h)
    dx = 2.0 / n
    a = 1.0 - h
    b = h
    G = np.zeros((n, 2*n-1))
    for k in range(2*n-1):
        s = k - (n-1)
        if s >= 0:
            A = np.concatenate([np.zeros(s), a[:n-s]]) if s > 0 else a.copy()
            B = np.concatenate([b[s:], np.zeros(s)]) if s > 0 else b.copy()
        else:
            sp = -s
            A = np.concatenate([a[sp:], np.zeros(sp)])
            B = np.concatenate([np.zeros(sp), b[:n-sp]])
        G[:, k] = (A - B) * dx
    return G
```

This is O(n²) but with vectorized operations inside, so it's much faster than the double Python loop.

Actually, I can make it even faster by avoiding the loop over k:

```python
def grad_c(h):
    n = len(h)
    dx = 2.0 / n
    a = 1.0 - h
    G = np.zeros((2*n-1, n))  # transposed for easier multiplication with p
    for k in range(2*n-1):
        s = k - (n-1)
        if s == 0:
            A = a
            B = h
        elif s > 0:
            A = np.zeros(n); A[s:] = a[:n-s]
            B = np.zeros(n); B[:n-s] = h[s:]
        else:
            sp = -s
            A = np.zeros(n); A[:n-sp] = a[sp:]
            B = np.zeros(n); B[sp:] = h[:n-sp]
        G[k, :] = (A - B) * dx
    return G
```

Then grad = G @ p (where p is the softmax weights, shape (2n-1,)).

This makes the gradient computation a single matrix-vector product after the setup.
