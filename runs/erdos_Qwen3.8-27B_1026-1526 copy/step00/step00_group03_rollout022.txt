Actually, let me think about this differently. The most effective approach for this type of problem is probably:

1. **Subgradient method**: Since the objective is the max of smooth (bilinear) functions, we can use a subgradient method. At each iteration, find the shift k* that achieves the max, compute the subgradient, and take a step in the negative subgradient direction.

The subgradient of C(k*) w.r.t. h[i] is:
∂C(k*)/∂h[i] = dx * [(1 - h[i-k*]) + (-(1-h[i+k*]))]  (with boundary handling)
= dx * [1 - h[i-k*] - 1 + h[i+k*]]
= dx * [h[i+k*] - h[i-k*]]

Wait, let me be more careful. C(k) = dx * ∑_i h[i] * (1-h[i+k]) (for the valid range).

∂C(k)/∂h[j] = dx * [data that depends on j's role]

If j is the "first" index (h[j] * (1-h[j+k])): contribution is (1-h[j+k])
If j is the "second" index (h[j-k] * (1-h[j])): contribution is -h[j-k]

So ∂C(k)/∂h[j] = dx * [(1-h[j+k]) - h[j-k]] (with boundary conditions: if j+k is out of range, the first term is 0; if j-k is out of range, the second term is 0).

More precisely, for the full correlation:
C(k) = dx * ∑_i h[i+k] * (1-h[i]) where the sum is over valid i (both i and i+k in [0, n-1]).

For a specific index j:
- j appears as i+k when i = j-k (valid if 0 ≤ j-k ≤ n-1 and 0 ≤ j ≤ n-1): contribution is (1-h[j-k])
- j appears as i when i = j (valid if 0 ≤ j ≤ n-1 and 0 ≤ j+k ≤ n-1): contribution is -h[j+k]

So ∂C(k)/∂h[j] = dx * [(1-h[j-k]) * 1_{0≤j-k≤n-1} - h[j+k] * 1_{0≤j+k≤n-1}]

For the subgradient of the max: SG = ∂C(k*)/∂h where k* is the argmax.

Then we take a step: h_new = h - α * SG, and project back to the feasible set [0,1]^n ∩ {sum = n/2}.

This is a standard subgradient method. The step size α can be chosen by backtracking or a diminishing sequence.

This might be more effective than Nelder-Mead because it uses the structure of the problem (the subgradient points in the direction of the worst shift).

def compute_subgrad(h, s):
    n = len(h)
    dx = 2.0 / n
    sg = np.zeros(n)
    # Term 1: (1-h[j-s]) for j where 0 <= j-s < n
    if s >= 0:
        # j-s >= 0 => j >= s; j-s < n => j < n+s (always true since j < n)
        # So for j = s, s+1, ..., n-1: term1 = 1 - h[j-s]
        sg[s:] += (1.0 - h[:n-s])
    else:
        # j-s >= 0 => j >= s (always true since s < 0 and j >= 0)
        # j-s < n => j < n+s
        # So for j = 0, 1, ..., n+s-1: term1 = 1 - h[j-s] = 1 - h[j+|s|]
        m = abs(s)
        sg[:n-m] += (1.0 - h[m:])
    
    # Term 2: -h[j+s] for j where 0 <= j+s < n
    if s >= 0:
        # j+s < n => j < n-s
        # So for j = 0, 1, ..., n-s-1: term2 = -h[j+s]
        sg[:n-s] += (-h[s:])

        m = abs(s)
        sg[m:] += (-h[:n-m])
    
    return dx * sg

    return float(np.max(corr) * dx)

def repair(h, target_sum):
    n = len(h)
    h = np.array(h, dtype=float).copy()
    h = np.clip(h, 0.0, 1.0)

    if s < 1e-15:
        return np.full(n, target_sum / n)

            break
        if diff > 0:
            mask = h < 1.0
        else:
            mask = h > 0.0
        cnt = np.count_nonzero(mask)
        if cnt == 0:
            break
        h[mask] += diff / cnt
    return h

def compute_subgrad(h, s):
    n = len(h)
    dx = 2.0 / n
    sg = np.zeros(n)

            sg[m:] += (-h[:n-m])
