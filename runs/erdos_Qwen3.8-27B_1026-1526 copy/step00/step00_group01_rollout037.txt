For a sequence with Σ s[i] = 0 (equal number of ±1) and autocorrelation R_s(k) = Σ s[i]s[i+k]:
= (1/4)(0 - R_s(k) + n - |k|) = (n - |k| - R_s(k))/4

To minimize the max of this over k, we want to minimize max_k (n - |k| - R_s(k)).
Since n - |k| is fixed, we want to maximize min_k R_s(k) (make the autocorrelation as "flat" as possible, or at least make the minimum as high as possible).

Wait, that's not quite right. We want to minimize max_k (n - |k| - R_s(k)), which means we want R_s(k) to be as large as possible for the k that maximizes (n-|k| - R_s(k)).

For k=0: n - 0 - R_s(0) = n - n = 0 (since R_s(0) = n for a ±1 sequence with n elements... wait, R_s(0) = Σ s[i]² = n).
So at k=0, the value is 0. Good.

For k≠0: we want R_s(k) to be as close to n-|k| as possible. But for a ±1 sequence, R_s(k) can range from -(n-|k|) to (n-|k|).

The ideal would be R_s(k) = n-|k| for all k≠0, which would give 0 for all k. But this is only possible for trivial sequences.

The next best is to make R_s(k) as close to n-|k| as possible for all k. This is related to the "conjugate" of the sequence having low peak sidelobe.

This is a well-studied problem in signal processing. Known optimal sequences for short lengths include Barker sequences, Zadoff-Chu sequences, etc.

For our problem (n=47, which is prime), we can use a Legendre sequence!

A Legendre sequence of odd prime length p is:
s[i] = (i/p) for i = 1, ..., p-1, and s[0] = 1 (or -1)

where (i/p) is the Legendre symbol (1 if i is a quadratic residue mod p, -1 otherwise).

For p=47: the quadratic residues mod 47 are:
1²=1, 2²=4, 3²=9, 4²=16, 5²=25, 6²=36, 7²=49=2, 8²=64=17, 9²=81=34, 10²=100=6, 11²=121=27, 12²=144=3, 13²=169=28, 14²=196=8, 15²=225=40, 16²=256=21, 17²=289=7, 18²
