The correlation is computed as np.correlate(h, 1-h, mode="full"). Let me verify what this gives.

For h = [h0, h1, ..., h_{n-1}], 1-h = [1-h0, 1-h1, ..., 1-h_{n-1}]

np.correlate(a, v, "full")[k] = sum_j a[k-j] * v[j] for valid k, j

So np.correlate(h, 1-h, "full") has length 2n-1, indexed from 0 to 2n-2.

For k = n-1 (the center), this is sum_j h[j] * (1-h[j]) = sum h[j] - sum h[j]² 

For k = n-1+m (positive lag m), this is sum_j h[j+m] * (1-h[j]) (approximately, with boundary effects)

OK so my earlier analysis was correct. The center value (k = n-1) is sum(h) - sum(h²) = n/2 - sum(h²).

For a binary h with n/2 ones, this is n/2 - n/2 = 0. For a continuous h, it's n/2 - sum(h²) which is > 0 (since h² < h for h ∈ (0,1)).

So for binary solutions, the center correlation is 0, and the important values are the non-center ones.

This confirms that binary (or near-binary) solutions are preferred, as they minimize the center correlation.

    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)

def smooth_obj(h, beta):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    scaled = beta * corr
    # Handle numerical issues
    max_scaled = np.max(scaled)
    if max_scaled > 500:
        return dx * np.max(corr)
    return (dx / beta) * (max_scaled + np.log(np.sum(np.exp(scaled - max_scaled))))

def eq_constraint(h, target):
    return h.sum() - target

def project_to_feasible(h, target):
    """Project h onto the feasible set {x: 0<=x[i]<=1, sum(x)=target}"""
    h = np.clip(h, 0.0, 1.0)
    deficit = target - h.sum()
    if abs(deficit) > 1e-12:
        # Distribute deficit among elements that can absorb it
        if deficit > 0:
            # Need to increase sum: add to elements < 1
            room = 1.0 - h
            room[h >= 1.0 - 1e-10] = 0.0
            total_room = room.sum()
            if total_room > 1e-10:
                h += deficit * room / total_room
            else:
                h += deficit / len(h)
        else:
            # Need to decrease sum: subtract from elements > 0
            space = h.copy()
            space[h <= 1e-10] = 0.0
            total_space = space.sum()
            if total_space > 1e-10:
                h += deficit * space / total_space
            else:
                h += deficit / len(h)
    h = np.clip(h, 0.0, 1.0)

    n = len(h)

def project_feasible(h, target):
