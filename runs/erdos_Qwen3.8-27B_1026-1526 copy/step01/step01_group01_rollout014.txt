```python
def subgradient_step(h, n, alpha):
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    max_val = np.max(corr)
    # Active set: lags where corr is within tolerance of max
    tolerance = 1e-6
    active = np.where(corr >= max_val - tolerance)[0]
    
    # Compute gradient for each active lag
    # c[m] = sum_i h[i] * (1 - h[i - (m - n + 1)])
    g = np.zeros(n)
    for m in active:
        l = m - (n - 1)  # effective lag
        # dc/du[j] = 1 - h[j+l] - h[j-l] (with boundary handling)
        for j in range(n):
            grad = 1.0
            if 0 <= j + l < n:
                grad -= h[j + l]
            if 0 <= j - l < n:
                grad -= h[j - l]
            g[j] += grad
    g /= len(active)
    g *= dx
    
    # Step
    h_new = h - alpha * g
    # Project
    h_new = project_feasible(h_new, n)
    return h_new
```

For general lag l:

- h[j] appears in the "second factor" h[i-l] when i-l=j, i.e., i=j+l: valid if i=j+l is in the valid range

  Second factor: i=j+l valid if l ≤ j+l ≤ n-1, i.e., j ≤ n-1-l. Contribution: -h[j+l]
  ∂c/∂h[j] = (1-h[j-l])*I(j≥l) - h[j+l]*I(j≤n-1-l)

For l < 0 (let l' = -l > 0): valid i range is [0, n-1-l'] = [0, n-1+l] (so i+l' ≤ n-1 i.e. i ≤ n-1-l')
  First factor: i=j valid if 0 ≤ j ≤ n-1-l', i.e., j ≤ n-1-l'. Contribution: (1-h[j+l'])
  Second factor: i-l=j, i=j+l=j-l' valid if 0 ≤ j-l' ≤ n-1-l', i.e., l' ≤ j ≤ n-1. Contribution: -h[j-l']
  ∂c/∂h[j] = (1-h[j+l'])*I(j≤n-1-l') - h[j-l']*I(j≥l')

Let me re-express for l ≥ 0, al = l:

  - If j > n-1-al: ∂c/∂h[j] = 1 - h[j-al]

  - If j < al: ∂c/∂h[j] = 1 - h[j+al]

So the pattern is:
- Middle region (al ≤ j ≤ n-1-al): 1 - h[j-al] - h[j+al]
- Left edge (j < al): depends on sign of l
  - l ≥ 0: -h[j+al] = -h[j+al]
  - l < 0: 1 - h[j+al]
- Right edge (j > n-1-al): depends on sign of l
  - l ≥ 0: 1 - h[j-al]
  - l < 0: -h[j-al]

This is NOT the same for l ≥ 0 and l < 0 at the edges! My earlier simplification was wrong.

Let me just compute it directly for a given lag:

```python
def compute_grad(h, l, n):
    """Gradient of correlation at lag l w.r.t. h"""
    g = np.zeros(n)
    if l >= 0:
        # c = sum_{i=l}^{n-1} h[i]*(1-h[i-l])
        # dc/du[j] = (1-h[j-l])*I(j>=l) - h[j+l]*I(j+l<=n-1)
        for j in range(n):
            val = 0.0
            if j >= l:
                val += (1.0 - h[j-l])
            if j + l < n:
                val -= h[j+l]
            g[j] = val
    else:
        ll = -l
        # c = sum_{i=0}^{n-1-ll} h[i]*(1-h[i+ll])
        # dc/du[j] = (1-h[j+ll])*I(j+ll<=n-1) - h[j-ll]*I(j-ll>=0)
        for j in range(n):
            val = 0.0
            if j + ll < n:
                val += (1.0 - h[j+ll])
            if j - ll >= 0:
                val -= h[j-ll]
            g[j] = val
    return g
```

This is O(n) per lag, which is fine. But for the subgradient of the max over all lags, I need to sum/average over the active set, which could be many lags. Total: O(n * |active_set|).

For n=190 and active_set of size ~10, that's 1900 operations per step. Very fast.

Now, for the Nesterov accelerated subgradient method:
- The subgradient is g = (dx/|S|) * Σ_{k∈S} grad_k
- Step: y = h - alpha * g
- Project to feasible set
- Nesterov momentum

The step size alpha needs to be adapted. For subgradient methods, alpha_k = c / sqrt(k) is standard, but I'll use a backtracking/adaptive scheme:
- Start with alpha = 0.1
- If the objective worsens by more than a threshold, halve alpha
- If it improves consistently, slowly increase alpha

Let me now write the complete solution. I'll aim for a clean implementation that:
1. Starts from the parent
2. Does a quick SLSQP polish
3. Runs Nesterov subgradient for the bulk of the time
4. Periodically does SLSQP refinement
5. Tries higher resolution
6. Returns the best found

Let me also add a "flatness" penalty: in addition to minimizing the max, I'll add a small penalty for variance of the correlation. This helps "spread" the optimization across lags.

Actually, for the subgradient method, I'll use a "soft" active set: instead of just the max lag, I'll use all lags with corr > 0.9 * max_corr. This gives a smoother subgradient.

```python
import numpy as np
from scipy.optimize import minimize
import time


def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)


def project_feasible(h, n):
    h = np.asarray(h, dtype=float).copy()
    h = np.clip(h, 0.0, 1.0)
    for _ in range(300):
        diff = n / 2.0 - np.sum(h)
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            mask = h < 1.0 - 1e-13
        else:
            mask = h > 1e-13
        if not np.any(mask):
            break
        h[mask] += diff / np.sum(mask)
        np.clip(h, 0.0, 1.0, out=h)
    diff = n / 2.0 - np.sum(h)
    if abs(diff) > 1e-14:
        if diff > 0:
            idx = int(np.argmax(1.0 - h))
            h[idx] = min(h[idx] + diff, 1.0)
        else:
            idx = int(np.argmax(h))
            h[idx] = max(h[idx] + diff, 0.0)
    return h


def smooth_max(x, beta):
    m = np.max(x)
    shifted = np.clip(beta * (x - m), -500.0, 500.0)
    return m + np.log(np.sum(np.exp(shifted))) / beta


def sum_eq(x, n):
    return np.sum(x) - n / 2.0


def slsqp_optimize(h0, n, max_iter=200, beta=80.0):
    h0 = project_feasible(h0.copy(), n)
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': sum_eq, 'args': (n,)}]

    def obj_func(x):
        hx = np.clip(x, 0.0, 1.0)
        corr = np.correlate(hx, 1.0 - hx, mode="full")
        return smooth_max(corr, beta) * (2.0 / n)

    try:
        res = minimize(obj_func, h0, method='SLSQP', bounds=bounds,
                       constraints=cons,
                       options={'maxiter': max_iter, 'ftol': 1e-13, 'iprint': 0})
        h_res = project_feasible(res.x, n)
        return h_res, compute_c5(h_res)
    except Exception:
        return None, None


def grad_lag(h, l, n):
    g = np.zeros(n)
    if l >= 0:
        for j in range(n):
            val = 0.0
            if j >= l:
                val += (1.0 - h[j - l])
            if j + l < n:
                val -= h[j + l]
            g[j] = val
    else:
        ll = -l
        for j in range(n):
            val = 0.0
            if j + ll < n:
                val += (1.0 - h[j + ll])
            if j - ll >= 0:
                val -= h[j - ll]
            g[j] = val
    return g


def subgradient_h(h, n, top_frac=0.15):
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    max_val = np.max(corr)
    active = np.where(corr >= max_val - top_frac * max_val)[0]
    if len(active) == 0:
        active = np.array([int(np.argmax(corr))])
    g = np.zeros(n)
    for m in active:
        l = m - (n - 1)
        g += grad_lag(h, l, n)
    g /= len(active)
    g *= dx
    return g * 2.0


def nesterov_subgrad(h, n, max_iter=2000, top_frac=0.15):
    h = project_feasible(h.copy(), n)
    best_h = h.copy()
    best_c5 = compute_c5(h)
    alpha = 0.3
    t = 1.0
    h_prev = h.copy()
    h_curr = h.copy()
    momentum = 0.0

    for it in range(max_iter):
        y = h_curr + momentum * (h_curr - h_prev)
        y = np.clip(y, 0.0, 1.0)
        g = subgradient_h(y, n, top_frac)
        alpha /= np.sqrt(1.0 + 0.5 * t / 100.0)
        new_t = 0.5 * (1.0 + np.sqrt(1.0 + 4.0 * t * t))
        momentum = (t - 1.0) / new_t
        t = new_t

        h_new = y - alpha * g
        h_new = project_feasible(h_new, n)
        c5_new = compute_c5(h_new)

        if c5_new < best_c5:
            best_h = h_new.copy()
            best_c5 = c5_new

        h_prev = h_curr
        h_curr = h_new

        if it % 200 == 199:
            alpha = min(alpha * 1.2, 0.5)

    return best_h, best_c5


def active_set_slsqp(h, n, top_k=5, max_iter=50, beta=100.0):
    h = project_feasible(h.copy(), n)
    dx = 2.0 / n
    best = compute_c5(h)
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': sum_eq, 'args': (n,)}]

    for it in range(max_iter):
        corr = np.correlate(h, 1.0 - h, mode="full")
        top_idx = np.argsort(corr)[-top_k:][::-1]
        target = corr[top_idx[0]]

        def obj_as(x):
            hx = np.clip(x, 0.0, 1.0)
            cc = np.correlate(hx, 1.0 - hx, mode="full")
            return smooth_max(cc, beta) * dx + 5.0 * np.sum(np.maximum(cc[top_idx] - target, 0.0)**2) * dx

        try:
            res = minimize(obj_as, h, method='SLSQP', bounds=bounds,
                           constraints=cons,
                           options={'maxiter': 20, 'ftol': 1e-11, 'iprint': 0})
            h_new = project_feasible(res.x, n)
            c5_new = compute_c5(h_new)
            if c5_new < best:
                h = h_new
                best = c5_new
        except Exception:
            break

    return h, best


def interpolate_h(h_old, n_old, n_new):
    x_old = np.linspace(0.0, 2.0, n_old)
    x_new = np.linspace(0.0, 2.0, n_new)
    h_interp = np.interp(x_new, x_old, h_old)
    return h_interp


def binarize_push(h, n, strength=0.05):
    h_b = np.where(h > 0.5, 1.0, 0.0)
    h_b = project_feasible(h_b, n)
    return h + strength * (h_b - h)


def make_perturbed(h, n, sigma, rng):
    h_p = h + rng.normal(0.0, sigma, n)
    return project_feasible(h_p, n)


def run(seed=42, budget_s=1300, **kwargs):
    np.random.seed(seed)
    rng = np.random.RandomState(seed)
    t0 = time.time()

    best_h = None
    best_c5 = 1e9

    if 'initial_h_values' in globals() and initial_h_values is not None:
        h_init = np.array(initial_h_values, dtype=float).copy()
        n = len(h_init)
        h_init = project_feasible(h_init, n)
        best_h = h_init
        best_c5 = compute_c5(h_init)
    else:
        n = 190
        best_h = np.ones(n) * 0.5
        best_c5 = compute_c5(best_h)

    def check_time(remaining=30):
        return (time.time() - t0) < budget_s - remaining

    # Phase 1: Quick SLSQP polish
    if check_time(200):
        h_opt, c5_opt = slsqp_optimize(best_h, n, 300, 80.0)
        if h_opt is not None and c5_opt < best_c5:
            best_h, best_c5 = h_opt, c5_opt

    # Phase 2: Nesterov subgradient descent (main engine)
    if check_time(200):
        h_sg, c5_sg = nesterov_subgrad(best_h, n, max_iter=3000, top_frac=0.12)
        if c5_sg < best_c5:
            best_h, best_c5 = h_sg, c5_sg

    # Phase 3: Interleaved SLSQP + subgradient refinement
    if check_time(200):
        h_work = best_h.copy()
        for round_idx in range(8):
            if not check_time(200):
                break
            h_opt, c5_opt = slsqp_optimize(h_work, n, 150, 120.0)
            if h_opt is not None and c5_opt < best_c5:
                best_h, best_c5 = h_opt, c5_opt
                h_work = h_opt
            h_sg, c5_sg = nesterov_subgrad(h_work, n, max_iter=500, top_frac=0.10)
            if c5_sg < best_c5:
                best_h, best_c5 = h_sg, c5_sg
            h_work = best_h

    # Phase 4: Active set SLSQP
    if check_time(200):
        h_as, c5_as = active_set_slsqp(best_h, n, top_k=8, max_iter=30, beta=150.0)
        if c5_as < best_c5:
            best_h, best_c5 = h_as, c5_as

    # Phase 5: Binarization push + re-optimize
    if check_time(200):
        h_bin = binarize_push(best_h, n, 0.15)
        h_bin = project_feasible(h_bin, n)
        h_opt, c5_opt = slsqp_optimize(h_bin, n, 300, 100.0)
        if h_opt is not None and c5_opt < best_c5:
            best_h, best_c5 = h_opt, c5_opt
        h_sg, c5_sg = nesterov_subgrad(best_h, n, max_iter=1000, top_frac=0.10)
        if c5_sg < best_c5:
            best_h, best_c5 = h_sg, c5_sg

    # Phase 6: Try higher resolution
    for n_try in [200, 230, 260]:
        if not check_time(150):
            break
        h_interp = interpolate_h(best_h, len(best_h), n_try)
        h_interp = project_feasible(h_interp, n_try)
        h_opt, c5_opt = slsqp_optimize(h_interp, n_try, 250, 60.0)
        if h_opt is not None:
            h_sg, c5_sg = nesterov_subgrad(h_opt, n_try, max_iter=800, top_frac=0.12)
            if c5_sg < c5_opt:
                h_opt, c5_opt = h_sg, c5_sg
        if h_opt is not None and c5_opt < best_c5:
            best_h, best_c5 = h_opt, c5_opt

    # Phase 7: Multi-restart with perturbation
    if check_time(150):
        for trial in range(5):
            if not check_time(150):
                break
            sigma = 0.08 + 0.04 * trial
            h_pert = make_perturbed(best_h, len(best_h), sigma, rng)
            h_opt, c5_opt = slsqp_optimize(h_pert, len(best_h), 200, 100.0)
            if h_opt is not None:
                h_sg, c5_sg = nesterov_subgrad(h_opt, len(best_h), max_iter=400, top_frac=0.10)
                if c5_sg < c5_opt:
                    h_opt, c5_opt = h_sg, c5_sg
            if h_opt is not None and c5_opt < best_c5:
                best_h, best_c5 = h_opt, c5_opt

    # Phase 8: Final high-beta polish
    if check_time(50):
        h_opt, c5_opt = slsqp_optimize(best_h, len(best_h), 400, 300.0)
        if h_opt is not None and c5_opt < best_c5:
            best_h, best_c5 = h_opt, c5_opt

    if check_time(30):
        h_opt, c5_opt = slsqp_optimize(best_h, len(best_h), 300, 500.0)
        if h_opt is not None and c5_opt < best_c5:
            best_h, best_c5 = h_opt, c5_opt

    # Final: one more subgradient pass with very small steps
    if check_time(20):
        h_sg, c5_sg = nesterov_subgrad(best_h, len(best_h), max_iter=500, top_frac=0.05)
        if c5_sg < best_c5:
            best_h, best_c5 = h_sg, c5_sg

    best_h = project_feasible(best_h, len(best_h))
    best_c5 = compute_c5(best_h)

    return (best_h, best_c5, len(best_h))
```
