Approach and Rationale
---
The current program uses local optimization around a parent solution, which may lead to local optima. This strategy replaces local optimization with a global Particle Swarm Optimization (PSO) method to overcome this limitation. PSO explores a larger solution space by simulating the social behavior of particles. This approach will likely find a better solution because:
1. PSO better explores the complex, non-convex search space than local methods
2. PSO is more robust to initial conditions and can escape local minima
3. Multi-resolution solutions are considered by running PSO on multiple grid sizes

The main bottleneck addressed is local convergence. PSO provides diversity through multiple particles, each with memory of their best position and collective knowledge of the global best. The search is balanced by adjusting inertia weights and cognitive/social parameters.

Key mathematical components:
- PSO is a population-based optimization algorithm with:
  x_i: particle positions (function samples)
  v_i: particle velocities
  pbest_i: individual best known position
  gbest: global best position
- Objective function: combine correlation calculations with penalty terms
- Initialization: use parent solution if available, supplement with generated structures
- Update rule:
  v_new = w*v + c1*(pbest - x) + c2*(gbest - x)
- Feasibility ensured by projection operator

Mathematical Specification
---
**Problem Representation**:
- h: [0,2] → [0,1] approximated by n samples
- Integral constraint: Σh_i * (2/n) = 1 (equivalently Σh_i = n/2)
- Objective: min maxₖ (∫h(x)(1-h(x+k))dx) * (2/n)

**Variables and Functions**:
- Grid size n: one of [40,50,60,70,80,90,100] (even and odd grid sizes)
- Particles: 5 particles per grid size
- Inertia weight w: varies linearly from 0.9 to 0.4 over generations
- Cognitive/social coefficient c: {1.5, 2.0} randomly selected
- τ parameter for penalty = 0.1
- Smooth_max applied to entire correlation vector
- Functions from environment:
  np.correlate (mode="full")
  smooth_max (penalty function)
  project_feasible (projection to feasible set)

**Objective Function**:
f(x) = (τ-smooth_max(correlation) + β*|sum(x)-n/2|) * (2/n)
where β=10, τ=0.1, penalty parameter

**Constraints**:
1. 0 ≤ h_i ≤ 1 (strictly enforced)
2. ∑h_i = n/2 (enforced by projection)
3. Lag range [-n+1, n-1] considered
