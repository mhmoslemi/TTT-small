           = base_m + t*(1-h[j+s_m])*[valid1] + h[j-s_m]*[valid2] - t*h[j-s_m]*[valid2]
           = (base_m + h[j-s_m]*[valid2]) + t*((1-h[j+s_m])*[valid1] - h[j-s_m]*[valid2])

So corr[m] = A_m + t * B_m where:
A_m = base_m + h[j-s_m]*[j-s_m valid]
B_m = (1-h[j+s_m])*[j+s_m valid] - h[j-s_m]*[j-s_m valid]

And we want to minimize max_m (A_m + B_m * t) for t ∈ [0,1].

This is a lower envelope of lines problem! The optimal t is where the maximum of these lines is minimized.

To solve this:
1. Compute A_m and B_m for all m
2. Find t* that minimizes max_m (A_m + B_m * t)

The function max_m (A_m + B_m * t) is convex in t (max of linear functions). We can find the minimum by:
- Checking all pairwise intersections of the lines
- Checking t=0 and t=1
- Taking the best

For 2n-1 lines, there are O(n²) intersections to check. For n=59, that's about 13000 checks per coordinate. With n=59 coordinates per sweep, that's about 770,000 checks per sweep. Each check is O(1) to O(n) (to evaluate the max at that point). So one sweep is O(n³) ≈ 200,000 operations. Very fast!

Actually, we can be smarter. Since the function is convex, we can use ternary search or just check the "critical points" (intersections of adjacent lines when sorted by slope).

Even simpler: since we have at most 117 lines (2n-1), we can just:
1. Compute the slope B_m for each m
2. Sort by slope
3. The upper envelope changes at most 116 times
4. Check the value at each breakpoint

Or even simpler: just do a fine grid search over t ∈ [0,1] with, say, 1000 points, and pick the best. For n=59, evaluating the max at 1000 points for 59 coordinates is 1000 * 117 * 59 ≈ 7 million operations per sweep. A bit much, but still fast enough.

Actually, the cleanest approach: for each coordinate j, compute A_m and B_m for all m, then find the optimal t by checking:
- t = 0
- t = 1
- All intersection points t = (A_m2 - A_m1) / (B_m1 - B_m2) where B_m1 ≠ B_m2, that fall in [0,1]
- At each candidate t, compute max_m (A_m + B_m * t)
- Pick the t with minimum max

- After changing h[j], adjust another coordinate to maintain the sum
- Or use a "paired" coordinate descent: change h[j] and h[k] simultaneously

Actually, the simplest approach: after the coordinate descent sweep, project back to the feasible set. The projection (shifting all values by a constant and clipping) is what project_feasible does. Since the changes are small (each coordinate only changes by a small amount), the projection should be a small correction.

```python
def coordinate_descent_step(h, n, j):
    """Optimize coordinate j of h, returning the optimal value."""
    s_offset = -(n-1)  # For m=0, shift = -(n-1)
    
    # Compute A_m and B_m for all m
    A = np.zeros(2*n-1)
    B = np.zeros(2*n-1)
    
    # Base correlations (with h[j] = 0 for now)
    h_temp = h.copy()
    h_temp[j] = 0.0
    base = np.correlate(h_temp, 1.0-h_temp, mode="full")
    
    for m in range(2*n-1):
        s = m - (n-1)
        # Term 1: t * (1-h[j+s]) if 0 <= j+s < n
        valid1 = (j + s >= 0) and (j + s < n)
        # Term 2: h[j-s] * (1-t) if 0 <= j-s < n
        valid2 = (j - s >= 0) and (j - s < n)
        
        A[m] = base[m]
        if valid1:
            B[m] += (1.0 - h[j+s])
        if valid2:
            B[m] += -h[j-s]
            A[m] += h[j-s]  # The constant part of h[j-s]*(1-t) = h[j-s] - h[j-s]*t
    
    # Find t that minimizes max_m (A[m] + B[m]*t) for t in [0,1]
    # Check t=0, t=1, and intersections
    best_t = 0.0
    best_val = np.max(A)  # value at t=0
    
    val_at_1 = np.max(A + B)
    if val_at_1 < best_val:
        best_val = val_at_1
        best_t = 1.0
    
    # Check intersections
    for m1 in range(2*n-1):
        for m2 in range(m1+1, 2*n-1):
            if abs(B[m1] - B[m2]) < 1e-15:
                continue
            t_int = (A[m2] - A[m1]) / (B[m1] - B[m2])
            if 0.0 < t_int < 1.0:
                val = np.max(A + B * t_int)
                if val < best_val:
                    best_val = val
                    best_t = t_int
    
    return best_t
```

def evaluate_c5(h):
    n = len(h)
    dx = 2.0 / n
    g = 1.0 - h
    corr = np.correlate(h, g, mode="full")
    return float(np.max(corr) * dx)

def project_feasible(h, n):
    target = n / 2.0
    lo = -3.0
    hi = 3.0
    for _ in range(60):
        mid = 0.5 * (lo + hi)
        proj = np.clip(h + mid, 0.0, 1.0)
        s = np.sum(proj)
        if s > target:
            hi = mid
        else:
            lo = mid
    result = np.clip(h + 0.5 * (lo + hi), 0.0, 1.0)
    diff = target - np.sum(result)
    if abs(diff) > 1e-12:
        sorted_idx = np.argsort(np.abs(result - 0.5))
        for idx in sorted_idx:
            if diff > 0:
                add = min(diff, 1.0 - result[idx])
                result[idx] += add
                diff -= add
            else:
                sub = min(-diff, result[idx])
                result[idx] -= sub
                diff += sub
            if abs(diff) < 1e-12:
                break
    return result

def smooth_max(values, tau):
    v = values / tau
    vmax = np.max(v)
    return tau * (vmax + np.log(np.sum(np.exp(v - vmax))))

def compute_subgradient(h, n, tau):

    c = corr / tau
    c -= np.max(c)
    w = np.exp(c)
    w /= np.sum(w)
    grad = np.zeros(n)

        if wm < 1e-12:

                grad[:n-s] += wm * (1.0 - h[s:n])

        else:
            s2 = -s
            if s2 < n:
                grad[s2:n] += wm * (1.0 - h[:n-s2])
                grad[:n-s2] += -wm * h[s2:n]
    return grad * dx

def coord_optimize(h, n, j):
    """Find optimal value for coordinate j, minimizing max correlation."""
    # Compute base correlation with h[j] = 0
    h0 = h.copy()
    h0[j] = 0.0
    base = np.correlate(h0, 1.0 - h0, mode="full")
    
    # For each lag m, corr[m] = base[m] + t * delta[m]
    # where delta[m] is the change in corr[m] per unit increase in h[j]
    delta = np.zeros(2 * n - 1)
    for m in range(2 * n - 1):
        s = m - (n - 1)
        d = 0.0
        # When i = j: contribution is t * (1 - h[j+s])
        if 0 <= j + s < n:
            d += (1.0 - h[j + s])
        # When i + s = j: contribution is h[j-s] * (1-t), change is -h[j-s] * t
        if 0 <= j - s < n:
            d += -h[j - s]
        delta[m] = d
    
    # Minimize max_m (base[m] + delta[m] * t) for t in [0,1]
    # Use grid search + refinement
    t_grid = np.linspace(0, 1, 200)
    vals = np.max(base[None, :] + delta[None, :] * t_grid[:, None], axis=1)
    t_best = t_grid[np.argmin(vals)]
    
    # Refine with ternary search
    lo, hi = max(0, t_grid[max(0, np.argmin(vals)-1)]), min(1, t_grid[min(len(t_grid)-1, np.argmin(vals)+1)])
    for _ in range(50):
        m1 = lo + (hi - lo) / 3
        m2 = hi - (hi - lo) / 3
        v1 = np.max(base + delta * m1)
        v2 = np.max(base + delta * m2)
        if v1 <= v2:
            hi = m2
        else:
            lo = m1
    t_best = 0.5 * (lo + hi)
    
    return t_best
