**Goal**  
Find a step‑function \(h:[0,2]\to[0,1]\) with \(\int_0^2 h=1\) that minimizes  

\[
C_5=\max_{k}\int_0^2 h(x)\bigl(1-h(x+k)\bigr)\,dx,
\]

where the shift is taken modulo 2 (i.e. on the circle).  In the discrete test harness the integral is approximated by a *circular* correlation of a length‑\(n\) vector \(h\) (the code uses `np.correlate` with “full”, but the intended problem is the periodic case; the strategy therefore works with circular convolution explicitly).

The optimisation can be written as a **max‑min quadratic program**:

\[
\begin{aligned}
\text{maximize}\;\;&t\\
\text{s.t.}\;&\; \sum_{i=0}^{n-1} h_i = n/2,\\
&\;0\le h_i\le 1\quad\forall i,\\
&\; \sum_{i=0}^{n-1} h_i\,h_{(i+k)\!\!\!\!\pmod n}\;\ge\;t\qquad\forall k\in\{0,\dots,n-1\}.
\end{aligned}
\]

Indeed, for any shift \(k\)

\[
\int h(x)(1-h(x+k))dx = 1-\int h(x)h(x+k)dx 
                       = 1- \frac{2}{n}\sum_i h_i h_{i+k},
\]

so the worst shift is the one with the **smallest** autocorrelation term.  Maximising the lower bound \(t\) on every autocorrelation term directly minimises \(C_5 = 1-\frac{2}{n}t\).

Because the constraints are quadratic (and not convex), we attack the problem in three complementary layers:

--------------------------------------------------------------------
### 1. Convex‑relaxation layer (SDP)

1. **Lift** the vector to a matrix \(X = hh^{\!\top}\).  
   With this lift the autocorrelation constraints become linear:
   \[
   \operatorname{trace}(M_k X) \ge t,
   \qquad M_k \;=\;(e_i e_{i+k}^{\!\top}+e_{i+k}e_i^{\!\top})_{i}
   \]
   (the symmetric shift matrix that inserts a 1 at positions \((i,i+k)\) and \((i+k,i)\)).  

2. **Add** the linear constraints that encode the box and sum conditions:
   \[
   X_{ii}=h_i,\qquad 0\le h_i\le1,\qquad
   \sum_i h_i = n/2.
   \]

3. **Relax** the rank‑1 condition \(\operatorname{rank}(X)=1\) and keep only
   \(X\succeq0\).  The resulting semidefinite program (SDP) is:
   \[
   \max_{X\succeq0,\,h,\;t}\; t
   \quad\text{s.t.}\;
   \begin{cases}
   \operatorname{trace}(M_k X) \ge t &\forall k,\\
   X_{ii}=h_i,\\
   0\le h_i\le1,\\
   \sum_i h_i = n/2 .
   \end{cases}
   \]

4. **Solve** the SDP with CVXPY using a fast first‑order solver (SCS or
   ECOS).  Choose a modest discretisation, e.g. \(n=80\).  Memory consumption
   is \(O(n^2)\) ≈ 6 k entries, well within the budget.

5. **Outcome:** a PSD matrix \(X^\star\) and a vector \(h^\star\) (the
   diagonal of \(X^\star\)).  The objective value \(t_{\text{SDP}}\) is a
   **global upper bound** on the achievable minimal autocorrelation,
   thus a lower bound on the best possible \(C_5\).

### 2. Random‑hyperplane rounding + deterministic polishing

The SDP solution is not necessarily rank‑1, so we need a concrete
step‑function.  We use a standard “Goemans‑Williamson” style rounding:

1. **Cholesky** (or eigen‑decompose) \(X^\star = V V^{\!\top}\) with

2. **Sample** a Gaussian vector \(g\sim\mathcal N(0,I_r)\) and set
   \[
   \tilde h_i =

   \end{cases}

   problem (the sum constraint is already satisfied, the box constraint is
