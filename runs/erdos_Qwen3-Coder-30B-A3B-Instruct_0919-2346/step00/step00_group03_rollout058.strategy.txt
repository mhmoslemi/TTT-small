**1. Mathematical Reformulation**

Let the discretisation size be `n` (so `dx = 2/n`).  
Write the step‑function values as a vector  

```
h = (h_0 , … , h_{n‑1}) , 0 ≤ h_i ≤ 1 , ∑_i h_i = n/2 .
```

For an integer shift `ℓ` (‑(n‑1) ≤ ℓ ≤ n‑1) the overlap term computed by the reference code is  

```
s_ℓ(h) = ∑_{i=0}^{n‑|ℓ|‑1} h_i · (1 – h_{i+ℓ}) .
```

`C₅(h) = dx· max_ℓ s_ℓ(h)` is the quantity to be minimised.

Because `∑_i h_i` is constant,  

```
s_ℓ(h) = (∑_{i∈I_ℓ} h_i) –  ∑_{i∈I_ℓ} h_i·h_{i+ℓ},
```

where `I_ℓ = {0,…,n‑|ℓ|‑1}`.  
Thus minimising `max_ℓ s_ℓ` is equivalent to **maximising the minimum self‑correlation**

```
c_ℓ(h) = ∑_{i∈I_ℓ} h_i·h_{i+ℓ} .
```

The objective becomes  

```
min  t
s.t.  s_ℓ(h) ≤ t    ∀ ℓ,
      0 ≤ h_i ≤ 1   ∀ i,
```

The constraints `s_ℓ(h) ≤ t` are quadratic (they contain the bilinear terms `h_i·h_{i+ℓ}`).

### 2.B Global Continuous Optimisation (Differential Evolution)

The binary MILP can only explore the discrete corner of the feasible set. The true optimum is known to use fractional values, so we now optimise directly over the continuous hyper‑cube.

#### 2.B.1 Decision Variables and Feasibility Projection
* Vector `h ∈ [0,1]^n`.  
* After each evolutionary operation we **project onto the affine simplex** `∑ h_i = n/2` by simple affine scaling:
  1. Compute the mean violation `δ = (∑ h_i – n/2)/n`.  
  2. Replace `h ← h – δ·1`.  
  3. Clip any component that left the interval `[0,1]` back to the nearest bound, and repeat step 1 a few times (the “Dykstra” projection) until the sum constraint is satisfied to machine precision.

#### 2.B.2 Objective Evaluation (fast correlation)
* Compute the full correlation by FFT in `O(n log n)`:
  * `F = fft(h)`, `G = fft(1-h)`.  
  * `corr = ifft(F * conj(G)).real`.  
* `s_max = max(corr)`.  
* The scalar objective is `C₅(h) = dx·s_max`.

The FFT approach is about 10× faster than the naïve `np.correlate` for `n≈200` and easily fits into the 600 s budget.

#### 2.B.3 Differential Evolution (DE) Engine
* **Population size** `popsize = 30`.  
* **Mutation factor** `F = 0.8`, **crossover rate** `CR = 0.9`.  
* **Generation loop** (stop when time runs out):
  1. For each individual `x` pick three distinct donors `a,b,c`.  
  2. Form a mutant `v = a + F·(b‑c)`.  
  3. Apply crossover to obtain trial `u`: `u_i = v_i` with probability `CR`, otherwise `u_i = x_i`.  
  4. Project `u` onto the feasible set (sum = n/2, box constraints).  
  5. Evaluate `C₅(u)`. If `C₅(u) ≤ C₅(x)` replace `x` with `u`.  
  6. Keep a global `best` individual.

* **Seeding**: initialise the population with the binary pattern returned by the MILP (or with the provided `initial_h_values`) plus Gaussian‑perturbed copies to diversify the search.

* **Adaptive restart**: every `G_restart` generations (e.g. 150) replace the worst half of the population by fresh random feasible vectors while preserving the best `k` individuals. This combats premature convergence.

* **Termination criteria**: time‑budget (`budget_s`), or stagnation (no improvement in the best value for 30 s).

#### 2.B.4 Targeted Local Refinement (post‑DE)

After DE stops we apply a deterministic *mismatch‑swap* local optimiser that directly reduces the worst shift:

1. Compute the shift `ℓ*` attaining `s_max`.  
2. Identify the index set  

```
M₁ = { i ∈ I_{ℓ*} | h_i ≈ 1  and  h_{i+ℓ*} ≈ 0 }
M₀ = { i ∈ I_{ℓ*} | h_i ≈ 0  and  h_{i+ℓ*} ≈ 1 } .
```

3. While both sets are non‑empty and `s_max` is still above the desired threshold:
   * Pick `i ∈ M₁`, `j ∈ M₀`.  
   * Exchange the two values (`h_i ↔ h_j`).  
   * Renormalise the vector (the exchange preserves the sum, only bounds may be violated; if a bound is exceeded, clamp it and compensate by a tiny opposite adjustment).  
   * Re‑evaluate `s_max`.  
   * Update `M₁, M₀` accordingly.

Each successful swap reduces the contribution of the dominant shift by at least `Δ = |h_i – h_j|·(1–h_{i+ℓ*}) + |h_j – h_i|·(1–h_{j+ℓ*})`, guaranteeing monotonic improvement.

If the swap set empties before the target is reached, we perform a *small random perturbation* (pick two indices, move a tiny amount ε from one to the other) and resume the swap loop. This mirrors a “hill‑climbing with occasional shake‑up”.

### 6. Why This Strategy Is Distinct

* **Exact MILP component** – Unlike plain hill‑climbing or simulated annealing, we formulate a *global* mixed‑integer linear model that, for a modest discretisation, can prove optimality or certify infeasibility of a given bound. This provides a mathematically rigorous lower‑bound on the achievable `t` and yields a high‑quality seed.  
* **Continuous global optimisation (DE)** – Instead of random swaps only, DE explores the *continuous* feasible polytope, allowing fractional values that are known to improve `C₅`. The FFT‑based evaluation makes the approach scalable to `n≈200`.  
* **Deterministic mismatch‑swap refinement** – After the stochastic stage we apply a *combinatorial* improvement that directly targets the worst shift, guaranteeing monotone reduction of the objective. This deterministic step is rarely used in prior attempts.  
* **Hybrid exploitation of tiny exhaustive search** – By enumerating all binary necklaces for `n ≤ 22` we obtain provably optimal tiny patterns that inform the construction of larger candidates, a technique not present in simple meta‑heuristics.

Together these three layers (exact, stochastic, deterministic) constitute a materially new, mathematically grounded pipeline that is far more likely to push the bound below the current record within the allotted 600 seconds.
