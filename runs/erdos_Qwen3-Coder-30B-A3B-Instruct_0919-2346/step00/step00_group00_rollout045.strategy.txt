### 1. Continuous formulation and smooth max approximation  

For a fixed shift `ℓ` (integer lag in the discrete setting) define  

```
O_ℓ(h) = dx * Σ_i h[i]·(1 – h[i+ℓ])          (out‑of‑range indices are ignored)
```

`C5(h) = max_ℓ O_ℓ(h)`.  The max is non‑smooth, which makes gradient‑based methods difficult.  Replace the max by a **log‑sum‑exp** (LSE) surrogate that converges to the max as a temperature parameter `α → ∞`:

```
F_α(h) = (dx/α) * log( Σ_ℓ exp( α·O_ℓ(h) ) ) .      (1)
```

For moderate `α` the function is smooth, has a well‑defined gradient, and is an upper bound on the true `C5`.  By slowly increasing `α` (deterministic annealing) we can drive `F_α` towards `C5`.

### 2. Gradient of the surrogate  

The derivative of (1) with respect to a component `h[i]` is obtained by the chain rule.  
First compute the *weights* (soft‑max over the shifts)

```
w_ℓ = exp( α·O_ℓ(h) ) / Σ_j exp( α·O_j(h) ) .       (2)
```

Then the partial derivative is

```
∂F_α/∂h[i] = Σ_ℓ w_ℓ * ( (1 – h[i+ℓ]) – h[i‑ℓ] ) .  (3)
```

The terms `h[i+ℓ]` or `h[i‑ℓ]` are omitted when the index lies outside `[0,n‑1]`.  
Equation (3) can be evaluated **vector‑wise** using two convolutions:

* `c1 = conv1d( w , 1‑h )`   gives the first part `Σ_ℓ w_ℓ·(1‑h[i+ℓ])`.
* `c2 = conv1d( w_rev , h )` where `w_rev[ℓ] = w[−ℓ]` gives the second part `Σ_ℓ w_ℓ·h[i‑ℓ]`.

The gradient is then `grad = c1 – c2`.  All convolutions are performed with `mode='full'` and subsequently sliced to length `n`; the FFT‑based convolution in NumPy (`np.fft.ifft(np.fft.fft… )`) makes each gradient evaluation O(n log n).

### 3. Projection onto the feasible set  

After a gradient step `h ← h – η·grad` we must enforce the box constraints `0≤h≤1` **and** the equality constraint `∑ h = n/2`.  This is a classic *projection onto a capped simplex*:

1. **Clamp** each component to `[0,1]`.  
2. If the sum after clamping equals `n/2` we are done.  
3. Otherwise solve for a scalar `λ` such that the **water‑filling** projection  

   ```
   ĥ[i] = min( 1 , max( 0 , h[i] – λ ) )
   ```

   satisfies `∑ ĥ[i] = n/2`.  
   `λ` can be found by sorting the elements of `h` once (O(n log n)) and scanning the piecewise‑linear function of the sum; this is cheap compared with the convolution work.

The projection is exact (up to floating‑point tolerance) and guarantees that every iterate stays feasible.
