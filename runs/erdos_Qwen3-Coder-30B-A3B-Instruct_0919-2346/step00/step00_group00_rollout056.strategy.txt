```
C5(h) = dx * max_{ℓ∈[−(n‑1)…(n‑1)]}  corr[ℓ] ,
```

### 1.  Parametric representation of admissible step‑functions  

Instead of searching over `2^n` binary strings directly, we restrict the search to functions that are *unions of a small number M of contiguous intervals*.  
Any admissible mask can be written as

```
A = ⋃_{i=0}^{M‑1} [ s_i ,  s_i + ℓ_i ]          (1)
```

where  

* `ℓ_i ≥ 0` is the length of interval i,  
* `g_i ≥ 0` is the gap that follows interval i,  
* the total length of all intervals is 1 and the total length of all gaps is 1, i.e.

```
∑ ℓ_i = 1,      ∑ g_i = 1 .                     (2)
```

If we enumerate intervals and gaps alternately, the start points are obtained by a cumulative sum:

```
s_0 = 0
s_i = ∑_{j< i} (ℓ_j + g_j)    for i≥1 .        (3)
```

The representation automatically enforces non‑overlap and the required total measure.

--------------------------------------------------------------------
### 2.  Unconstrained optimisation variables  

We embed the positivity and sum constraints of (2) **without** explicit bounds by a soft‑max transformation:

* Draw a real vector `x ∈ ℝ^{2M}` (the optimisation variables).  
* Split it: `x = (a_0,…,a_{M‑1}, b_0,…,b_{M‑1})`.  
* Exponentiate and normalise:

```
ℓ_i = exp(a_i) / Σ_{j=0}^{M‑1} exp(a_j)          (4)
g_i = exp(b_i) / Σ_{j=0}^{M‑1} exp(b_j)          (5)
```

Because the exponentials are always positive, (4)–(5) guarantee `ℓ_i,g_i ≥ 0` and the normalisation guarantees the two equalities in (2) exactly.  No extra constraints are needed in the optimiser.

### 3.  From interval parameters to a discrete mask  

For a chosen discretisation size `n` (even, e.g. `n = 200`), step size `dx = 2.0/n`:

1. Compute the cumulative start points `s_i` using (3).  
2. Initialise a zero array `h = np.zeros(n)`.  
3. For each interval `i` set the mask entries whose centre lies inside the interval to 1:
   ```
   left  = int( np.floor( s_i          / dx ) )
   right = int( np.floor( (s_i+ℓ_i)    / dx ) )
   h[left:right] = 1
   ```
   (If `right==left` the interval is smaller than one sample and contributes nothing – this is acceptable because the optimisation works in the continuous domain.)

4. **Exact mass correction** – after discretisation the integer sum `S = Σ h` may differ from the required `n/2`.  Perform a minimal correction:
   * If `S > n/2`, randomly pick `S‑n/2` indices where `h==1` and set them to 0.

   This step preserves the interval structure up to a tiny perturbation and guarantees feasibility.

The resulting `h` is a binary step‑function that respects all problem constraints.

2. Repeat for a fixed budget (e.g. 10 000 successful swaps or until the remaining time < 5 s):
   * Randomly choose `i` with `h[i]=1` and `j` with `h[j]=0`.  
   * Compute the new correlation after swapping `i ↔ j` using the O(n) update (loop over all `k ≠ i,j`).  
   * If `max(new_corr) < max(corr)`, perform the swap and replace `corr`.  
   * Otherwise discard the trial.  

Because each trial touches only `O(n)` entries, the refinement phase finishes quickly even for `n=200`.

### 9.  Failure‑mode mitigation  

* **Discretisation error** – If the binary mask deviates strongly from the continuous intervals (e.g., due to a very small `dx`), the mass‑correction step may flip many points.  Mitigation: choose `n` sufficiently large (≥ 200) so that one interval length typically covers many samples; also limit the interval count `M` so each interval is at least a few samples wide.  
* **Stagnation of DE** – If the population converges prematurely, restart DE with a new random seed (multi‑start).  The total budget allows several short runs; keep the best result across all runs.  
* **Too few intervals** – The true optimum might need more than `M` pieces.  If after the first DE run the bound is not better than the record, increase `M` (e.g. from 6 to 9) and repeat; the variable dimension grows only linearly, keeping DE affordable.  
* **Local refinement cost** – For `n` up to 200 the O(n) update is negligible; if `n` is enlarged, cap the number of swap attempts to stay within the remaining time.
