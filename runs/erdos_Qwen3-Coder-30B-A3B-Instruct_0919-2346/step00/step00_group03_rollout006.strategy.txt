**Goal** – Find a step‑function `h` on `[0,2]` (discretised with `n` points) with  
`∑h·dx = 1` and `0≤h_i≤1` that minimises  

```
C5 = maxℓ ∑i h_i·(1‑h_{i+ℓ})·dx                (ℓ runs over all integer shifts)
```

The problem is a *min‑max* non‑convex quadratic program.  The new approach departs from the usual random‑swap / simulated‑annealing heuristics and works directly on the continuous relaxation, using a sub‑gradient descent on the worst‑shift, an exact projection onto the feasible box‑simplex, a smooth surrogate for the max, and a deterministic final rounding plus exchange refinement.  The whole pipeline is fast enough for `n≈200–256` while giving a systematic way to improve the bound.

---

### 1. Discretisation & Pre‑computations
1. **Choose `n`** – a power of two (e.g. 256) so that FFT‑based convolutions are O(`n log n`).  
   `dx = 2.0 / n` and the integral constraint becomes `∑ h_i = n/2`.
2. **Index convention** – store `h` as a NumPy 1‑D float array `h[0 … n‑1]`.  
   For a shift `ℓ≥0` the overlap term is  
   `g_ℓ(h) = ∑_{i=0}^{n‑ℓ‑1} h_i·(1‑h_{i+ℓ})`.  
   For `ℓ<0` use symmetry (`g_{‑ℓ}=g_ℓ`).

---

### 2. Continuous Formulation
Define the *worst‑shift* objective  

```
F(h) = max_{ℓ∈[‑(n‑1),…,n‑1]} g_ℓ(h)               (integer ℓ)
```

`C5 = F(h)·dx`.  Because `F` is the pointwise maximum of a finite family of smooth functions, it is convex‑concave but non‑smooth.  We minimise `F` by *sub‑gradient descent* on the active shift.

---

### 3. Sub‑gradient of the active shift
For a given shift `ℓ≥0`, write  

```
g_ℓ(h) = Σ_{i=0}^{n‑ℓ‑1} h_i          – Σ_{i=0}^{n‑ℓ‑1} h_i·h_{i+ℓ}
```

Derivative w.r.t. each component:

*If 0 ≤ i < n‑ℓ*  ∂g_ℓ/∂h_i =  1 – h_{i+ℓ}  
*If ℓ ≤ i < n*  ∂g_ℓ/∂h_i = –h_{i‑ℓ}  
*Otherwise*    ∂g_ℓ/∂h_i = 0  

Thus a sub‑gradient `∇_ℓ g` can be built in O(`n`) by two vector shifts:
```
grad = zeros(n)
grad[0:n‑ℓ]   += 1.0 – h[ℓ:n]
grad[ℓ:n]     -= h[0:n‑ℓ]
```
For the global objective `F`, take the gradient of the *active* shift `ℓ* = argmax g_ℓ`.

---

### 4. Projection onto the feasible set
After a gradient step `h ← h – α·grad` we must enforce  

* box constraints: 0 ≤ h_i ≤ 1  
* linear equality: ∑ h_i = n/2  

The projection onto the capped simplex can be performed by the well‑known O(`n log n`) “water‑filling” algorithm:

1. clip `h` to `[0,1]` → `ĥ`.
2. compute the excess `δ = Σ ĥ – n/2`.
3. If `|δ|` is negligible we are done.  
   Otherwise find a scalar `λ` such that `Σ min(max(ĥ_i – λ, 0), 1) = n/2`.  
   This is done by sorting `ĥ` and scanning the breakpoints; the resulting
   `h = min(max(ĥ – λ, 0), 1)` satisfies both constraints exactly.

The projection is deterministic and cheap compared with the convolution step.

---

### 5. Smoothing the max (optional but stabilises early iterations)
Early in the optimisation the active shift may change abruptly, causing zig‑zag.  
Replace `F` by a smooth upper bound  

```
F_μ(h) = (1/μ)·log( Σ_ℓ exp( μ·g_ℓ(h) ) )
```

For a large `μ` the expression approximates the max; start with a moderate `μ≈5`
and increase it geometrically (e.g. multiply by 1.2 every 500 iterations) until
`μ≈40`.  The gradient of `F_μ` is a convex combination of the individual
gradients `∇_ℓ g` with weights proportional to `exp( μ·g_ℓ )`.  This yields a
well‑behaved direction while still steering the solution toward the worst‑shift.

### 6. Main optimisation loop
```
initialise h (e.g. uniform random numbers, then project to feasibility)
best_h ← h , best_F ← F(h)

for k = 1 … K (K≈10⁴ or until time limit):

        (extract the appropriate slice for ℓ ∈ [‑(n‑1),…,n‑1])
    choose active shift ℓ* = argmax g_ℓ
    compute sub‑gradient ∇ = grad_of_g_ℓ*(h)                (section 3)
```

### 7. Deterministic rounding to a binary step function
The continuous optimum typically contains many entries close to 0 or 1.  
To obtain a genuine step‑function:

1. **Greedy rounding** – sort the components of `best_h`; set the largest `n/2`
   entries to 1 and the rest to 0.  The sum constraint is automatically satisfied.
2. **Local exchange refinement** – while the current binary vector `b` has a
   worst shift `ℓ_max` with `g_ℓ_max(b) > target`:
   * collect indices `i` with `b_i=1, b_{i+ℓ_max}=0` (a *mismatch*)
   * collect indices `j` with `b_j=0, b_{j+ℓ_max}=1` (a *complementary* mismatch)
   * swapping any `(i,j)` reduces `g_ℓ_max` by exactly one.  
   Perform swaps greedily until no further improvement for the current worst
   shift, then recompute the new worst shift.  This loop terminates quickly
   because each swap strictly lowers the objective and the objective is integer‑valued.

The result is a binary vector `h_bin` with the same `n` and a rigorously evaluated `C5 = maxℓ g_ℓ(h_bin)·dx`.

* **Why it works** – The sub‑gradient descent directly reduces the *worst* overlap, not a surrogate “energy” that may ignore the max.
