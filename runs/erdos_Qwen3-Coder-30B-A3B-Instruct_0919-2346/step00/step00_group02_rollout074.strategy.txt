### 1. Discretisation and basic utilities  

*Pick a modest grid size* – default \(N=140\) (so \(dx=2/N\)).  
All operations are performed on the length‑\(N\) vector `h`.  

*Correlation*:  

\[
\Gamma_k(h)=dx\;\Bigl[h\;\star\;h\Bigr]_{k+N-1},
\]

where `★` denotes discrete correlation (the same as `np.correlate`).  
A single evaluation costs \(O(N\log N)\) with FFT or \(O(N^2)\) with direct loops – both cheap for \(N\le 200\).

*Gradient of a correlation*: for a fixed shift \(k\),

\[
\frac{\partial\Gamma_k}{\partial h_i}=dx\,
\bigl(h_{i+k}+h_{i-k}\bigr)
\quad\text{(indices out of range are ignored)} .
\]

Thus the gradient vector is the sum of two shifted copies of `h`.

*Feasibility*: the box constraints \(0\le h_i\le1\) and the linear equality \(\sum_i h_i=N/2\) are kept **exactly** by projecting any candidate onto the intersection of the box and the hyper‑plane. In the LP this is done by imposing `0 ≤ h_i+Δ_i ≤ 1` and `∑Δ_i = 0`.

### 2. Formulating the LP sub‑problem  

Let the current iterate be `h`.  
Define the set of *critical shifts*  

\[
\mathcal{K}=\bigl\{k\;|\;\Gamma_k(h)\text{ is among the }K\text{ smallest values}\bigr\},
\]

with a modest `K` (e.g. 5–10).  
These are the shifts that currently dominate the max‑overlap.

We introduce a step vector `Δ∈\mathbb{R}^N` and a scalar `τ` that will serve as a lower bound on the *new* minimal correlation.  

Linearising each correlation around `h`:

\[
\Gamma_k(h+Δ)\;\approx\;
\Gamma_k(h)+\nabla\Gamma_k(h)^{\!\top}Δ .
\]

The LP reads

```
max   τ
s.t.  Γ_k(h) + (∇Γ_k(h))ᵀ Δ  ≥  τ      for all k ∈ 𝒦
      0 ≤ h_i + Δ_i ≤ 1                for i=0,…,N‑1
      Σ_i Δ_i = 0
```

All constraints are linear; the objective is linear in `τ`.  
The LP is always feasible because `Δ=0, τ= min_k Γ_k(h)` satisfies it.  
Solving it yields a direction `Δ` that *simultaneously* improves the worst‑case correlations (if possible) while respecting all bounds.

### 3. Step‑size control (line search)

The linear model is only an approximation, so we perform a back‑tracking line search:

1. Set λ←1.  
2. Evaluate the true objective `C_5(h+λΔ)`.  
3. If it is lower than the current `C_5(h)`, accept the step with that λ.  
4. Otherwise halve λ (λ←λ/2) and repeat a fixed number of times (e.g. up to 6 halvings).  
If no λ yields improvement, the iteration is considered a **stall**.

Because the LP guarantees `τ` ≤ the true new minimal correlation for `Δ=0`, the line search never makes the worst‑case correlation worse than before when λ is small enough.

### 8. Expected numerical behaviour & safeguards  

*Why the LP works*: The correlation \(\Gamma_k\) is a quadratic form; its gradient is exact, so the linear model is accurate for small steps. By maximising a lower bound `τ` on all selected shifts simultaneously, the LP steers the iterate away from the current worst shift(s) without sacrificing any of the others.

*Potential failure modes*  

- **Degenerate LP** – if many shifts tie for worst, the constraints may be linearly dependent, but the solver still returns a feasible direction (often the zero direction). The line‑search then detects no improvement and the algorithm stalls, which is handled by the stall counter.  
- **Box violation** – the LP respects the box via `0 ≤ h_i+Δ_i ≤ 1`. Numerical rounding may push a component infinitesimally outside; after acceptance we project back onto `[0,1]` (clipping) and re‑adjust the sum by distributing the tiny residual to a non‑saturated entry.  
- **Poor initial step size** – the line‑search prevents overshooting; if λ=1 never works, the algorithm automatically reduces λ.  
- **Too few critical shifts** – if `K` is too small, the algorithm may improve one shift while silently worsening another outside `𝒦`. Mitigation: after each accepted step recompute the full set of correlations and update `𝒦`; also increase `K` gradually as the algorithm approaches convergence.

*Numerical precision*: All computations are double‑precision. Correlations are multiplied by `dx`; the smallest non‑zero correlation is on the order of `dx≈0.014` for `N=140`, well above machine epsilon. Hence the LP coefficients are well‑scaled.
