### 1.  Reformulate the problem as a (mixed‑)integer linear program  

For a discretisation with `N` points (`dx = 2/N`) define  

```
y[i,s]   ≈   h[i]·h[i+s]      (only for i,s with 0≤i, i+s<N)
α        =   max_s  C_s       where  C_s = dx·( Σ_i h[i] – Σ_i y[i,s] )
```

The constraints are  

* **Box & total‑mass**  
  `0 ≤ h[i] ≤ 1`  for all `i`  
  `Σ_i h[i] = N/2`  (exactly the required integral)

* **McCormick envelope for the product** (exact when `h[i]∈{0,1}`)  

```
y[i,s] ≤ h[i]                (1)
y[i,s] ≤ h[i+s]              (2)
y[i,s] ≥ h[i] + h[i+s] – 1   (3)
y[i,s] ≥ 0                   (4)
```

* **Maximum‑overlap definition** (one inequality per shift)  

```
α ≥ dx·( N/2 – Σ_i y[i,s] )    for every shift s = –(N‑1)…(N‑1)
```

* **Optional structural constraints** (to shrink the search space and exploit symmetry that is believed to be optimal)  

```
h[i] = h[N‑1‑i]                       (mirror symmetry)
h[i] ≥ h[i+1]   for i < N/2          (non‑increasing from the ends to the centre)
```

The **objective** is `minimise α`.  All constraints are linear; the only non‑convexity is the product, which is linearised by the McCormick envelope.  When the binary restriction `h[i]∈{0,1}` is imposed the envelope becomes exact, turning the model into a **mixed‑integer linear program (MILP)**.  Dropping the integrality gives a **pure linear program (LP)** that provides a tight relaxation.
