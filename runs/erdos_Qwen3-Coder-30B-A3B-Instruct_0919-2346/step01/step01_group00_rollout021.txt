### **Strategy for Improving C₅ Upper Bound**

#### **1. Problem Understanding**

We aim to find a step function h: [0, 2] → [0, 1] that minimizes the following overlap integral:

$$
C_5 = \max_k \int_0^2 h(x)(1 - h(x + k)) dx
$$

- This is constrained by:
  - $ 0 \leq h(x) \leq 1 $ for all $ x $
  - $ \int_0^2 h(x) dx = 1 $

We are discretized into `n_points` samples with `dx = 2.0 / n_points` and the sum of values must be exactly `n_points / 2`.

The function to optimize is the maximum value of a convolution-like integral over shifts.

---

#### **2. Key Insight: Convolution Interpretation**

Let’s define the convolution:
$$
c_k = \int_0^2 h(x)(1 - h(x + k)) dx
$$
This represents a cross-correlation of h with (1 - h), where we introduce a shift `k`.

Using the discretization, this can be computed as:
```python
c = np.correlate(h, 1 - h, mode="full") * dx
```
Thus, the objective is:
$$
C_5 = \max_k c_k
$$

So we want to minimize the maximum of a vector of values obtained from these correlations.
