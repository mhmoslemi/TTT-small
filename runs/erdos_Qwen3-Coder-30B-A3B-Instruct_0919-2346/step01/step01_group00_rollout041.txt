The goal is to find a step function `h: [0, 2] → [0, 1]` that minimizes the overlap integral:
$$
C_5 = \max_k \int h(x)(1 - h(x+k)) dx
$$
subject to:
- $ h(x) \in [0, 1] $ for all $ x $
- $ \int_0^2 h(x) dx = 1 $

#### 1. Mathematical Foundation of C₅

The integral represents the maximum overlap (in the sense of convolution) between the function and its shifted complement:
$$
\int h(x)(1 - h(x + k)) dx = \sum_i h_i (1 - h_{i+k})
$$
for each shift $k$, with a vectorized correlate. The problem is convex in nature due to the linear dependency on $h_i$, but the objective function is non-linear due to the max over shifts.

from scipy.optimize import minimize
import random

def c5_of(h):
    """Compute C5 = max_k integral h(x)(1-h(x+k)) dx."""
    dx = 2.0 / len(h)
    c = np.correlate(h, 1 - h, mode="full")
    c *= dx
    return np.max(c)

def evaluate_and_renormalize(h):
    """Ensure that sum(h) == 70 and values are in [0,1]."""
    h = np.clip(h, 0, 1)
    scale = 70.0 / np.sum(h)
    h = h * scale
    return h
