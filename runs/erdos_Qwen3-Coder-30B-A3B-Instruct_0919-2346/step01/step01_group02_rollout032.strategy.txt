**Mathematical reformulation**

For a discretisation with `N` points (`dx = 2/N`) we have  

```
C5(h) = max_s   C_s   ,   C_s = dx * Σ_i  h[i]·(1 – h[i+s]) .
```

Because `Σ_i h[i] = N/2` is constant,
```
C_s = 1 – dx * Σ_i h[i]·h[i+s] .
```
Hence minimising `max_s C_s` is equivalent to **maximising the minimal autocorrelation**
```
A_s = Σ_i h[i]·h[i+s]                      (no scaling)
```
subject to the box constraints `0 ≤ h[i] ≤ 1` and the linear equality
`Σ_i h[i] = N/2`.  The objective is a max‑min of linear (actually bilinear) forms,
so the problem is non‑convex but admits a useful sub‑gradient.

**Sub‑gradient of the worst shift**

Let `s*` be the shift attaining the current maximum `C_s`.  Write

```
C_{s*} = Σ_i h[i] – Σ_i h[i]·h[i+s*] .
```

Derivative w.r.t. `h[k]` (ignoring the outer `dx` factor) is

```
∂C_{s*}/∂h[k] = 1 – ( h[k+s*]   if k+s* in [0,N) )
                – ( h[k–s*]   if k–s* in [0,N) ) .
```

If an index falls outside the overlap region the corresponding term is absent.
Multiplying by `dx` gives the gradient of the *scaled* objective `C5`.

The gradient is very cheap to compute:
for `m = |s*|`  

```
g = dx * 1                # base vector
g[:N-m] -= dx * h[m:]    # subtract h[i+m]  where it exists
g[m:]   -= dx * h[:N-m]  # subtract h[i–m]  where it exists
```
For `m = 0` the two subtractions refer to the same vector, yielding
`g = dx·(1 – 2·h)` as required.

**Projection onto the feasible set**

After a gradient step we must enforce  

```
0 ≤ h[i] ≤ 1      and      Σ_i h[i] = N/2 .
```

The Euclidean projection onto the intersection of a box and a hyper‑plane
has a closed‑form “water‑filling’’ algorithm:

* Find a scalar λ such that  

  `w_i = clip( v_i + λ , 0 , 1 )`  

  satisfies `Σ_i w_i = N/2`.  
  The function `F(λ)=Σ_i clip(v_i+λ,0,1)` is monotone increasing, with  
  `F(λ→-∞)=0` and `F(λ→+∞)=N`.  A simple binary search on λ (≈ 50 iterations)
  yields λ to machine precision; the resulting `w` is the required projection.

```
def c5_of(h):
    dx = 2.0/len(h)
    return np.max(np.correlate(h, 1-h, mode='full')) * dx

def worst_shift(h):
    corr = np.correlate(h, 1-h, mode='full')
    idx = np.argmax(corr)
    return idx - (len(h)-1)               # signed shift

def subgradient(h, s):
    N = len(h); dx = 2.0/N
    m = abs(s)
    g = np.full(N, dx)                     # 1*dx everywhere
    if m < N:
        g[:N-m] -= dx * h[m:]              # term with h[i+m]
        g[m:]   -= dx * h[:N-m]            # term with h[i‑m]
    return g                               # gradient of C5

def project(v, target):
    # binary‑search for λ such that Σ clip(v+λ,0,1) = target
    lo = -np.max(v)                # all clipped to 0
    hi =  1.0 - np.min(v)          # all clipped to 1
    for _ in range(50):
        lam = (lo+hi)/2.0
        w = np.clip(v+lam, 0.0, 1.0)
        if w.sum() < target:
            lo = lam
        else:
            hi = lam
    w = np.clip(v+(lo+hi)/2.0, 0.0, 1.0)
    # tiny correction for rounding errors
    diff = target - w.sum()
    if abs(diff) > 1e-12:
        free = (w>0) & (w<1)
        if free.any():
            w[free] += diff / free.sum()
            w = np.clip(w,0,1)
    return w
```
