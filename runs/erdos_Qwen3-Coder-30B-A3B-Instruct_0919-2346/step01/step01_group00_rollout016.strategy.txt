**1. Reformulate the objective**

For a discretised step‑function `h ∈ ℝⁿ` (samples on `[0,2]`, `dx = 2/n`) the overlap for a shift `k` (index offset `τ`) is  

\[
C_τ(h)=\int_0^{2}h(x)\bigl(1-h(x+τdx)\bigr)\,dx
      =\underbrace{\sum_{i=0}^{n-1}h_i\,dx}_{=1}
        -dx\!\sum_{i=0}^{n-1}h_i\,h_{i+τ}\;,
\]

where out‑of‑range indices are interpreted as zero.  
Hence  

\[
C_τ(h)=1-dx\,S_τ(h),
\qquad
S_τ(h)=\sum_i h_i h_{i+τ}
\]

is the (zero‑padded) autocorrelation of `h`.  
The Erdős constant for `n=5` is  

\[
C_5(h)=\max_{τ}C_τ(h)=1-\min_{τ}S_τ(h)\; .
\]

Thus **minimising** `C_5` is equivalent to **maximising** the minimal autocorrelation  
\(\min_{τ}S_τ(h)\).

The constraints are linear:

* box: `0 ≤ h_i ≤ 1`,
* mass: `∑_i h_i = n/2`   (because `dx·∑h_i = 1`).

The feasible set is a convex polytope; the objective, however, is a non‑convex max‑of‑linear‑quadratics.

**2. Smooth the max to obtain a usable gradient**

Define the vector of overlaps  

\[
c = C(h) \in ℝ^{2n-1},\qquad c_τ = 1-dx\,S_τ(h).
\]

Introduce a temperature‑like smoothing parameter `α>0` and the soft‑max (log‑sum‑exp) surrogate  

\[
f_α(h)=\frac{1}{α}\log\Bigl(\sum_{τ}e^{α c_τ}\Bigr).
\]

* As `α → ∞`, `f_α(h) → max_τ c_τ = C_5(h)`.  
* For moderate `α` the function is smooth and its gradient is a weighted average of the gradients of each `c_τ`.

Let  

\[

**3. Compute the gradient analytically**

From the definition of `c_τ`

\[
c_τ = 1-dx\!\sum_i h_i h_{i+τ},
\]

and using zero padding, the derivative w.r.t. `h_i` is  

\[
\frac{∂c_τ}{∂h_i}= -dx\bigl(h_{i+τ}+h_{i-τ}\bigr).
\]

Hence for the smoothed objective

\[
(∇ f_α)_i = -dx\!\sum_{τ} w_τ\bigl(h_{i+τ}+h_{i-τ}\bigr).
\]

Because `∑_τ w_τ = 1` one can rewrite the gradient compactly as  

\[
g = -dx\bigl( (w * h) + (w^{\mathrm{rev}} * h) \bigr),
\]

where `*` denotes the discrete convolution and `w^{rev}` is `w` reversed (so that the second term corresponds to the `i‑τ` shift).

**Key properties**

* The gradient automatically satisfies `∑_i g_i = 0`. Therefore a pure gradient step leaves the total mass unchanged up to round‑off, and we only have to enforce the box constraints explicitly.
* Convolutions can be performed efficiently with FFTs (`O(n log n)`) or with NumPy’s `np.convolve` (still cheap for `n≈150`).

**4. Projection onto the feasible set (box + mass)**  

After a gradient step `h' = h - η g` we must enforce `0 ≤ h' ≤ 1` **and** `∑ h' = n/2`.  
The projection is the solution of  

\[
\min_{x}\; \|x-h'\|_2^2 \quad
\text{s.t. } 0\le x_i\le 1,\;
\sum_i x_i = n/2 .
\]

This is a classic bounded‑sum projection (water‑filling). It can be solved by a simple scalar root‑find:

* Define a Lagrange multiplier `λ`. The optimal point has the form  

  \[
  x_i = \operatorname{clip}(h'_i-λ,0,1).
  \]

* The function `φ(λ) = Σ_i clip(h'_i-λ,0,1) - n/2` is monotone decreasing in `λ`.  
* Perform a bisection on an interval that certainly contains the root (e.g. `[min(h')-1, max(h')+1]`).  
* Stop when `|φ(λ)|` is below a tiny tolerance (`1e‑12`).  

The result satisfies both constraints exactly and is inexpensive (`O(n log n)` for the bisection, each iteration `O(n)`).
