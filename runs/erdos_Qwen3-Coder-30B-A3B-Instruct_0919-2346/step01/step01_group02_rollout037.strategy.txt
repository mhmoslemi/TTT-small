**Overview** – Treat the Erdős overlap problem as a *flatten‑the‑autocorrelation* problem and attack it in three qualitatively different stages:

1. **Exact binary optimisation (MILP)** – obtain the best possible 0/1 indicator function on the 140‑point grid.
2. **Low‑dimensional interval model** – parametric search over a handful of constant‑height intervals (symmetrised three‑interval family) using an *analytic* expression for the overlap, which gives a global view of the landscape that the binary solution cannot see.
3. **Fine‑grained continuous polishing** – a short projected sub‑gradient / hill‑climb phase that starts from the best interval‑based vector and removes the discretisation artefacts.

Every stage respects the constraints `0 ≤ h[i] ≤ 1` and `∑ h = N/2` (with `N = 140`).  The total wall‑clock time is budget‑aware; the most expensive stage (the MILP) is given a time cap, the cheap analytic search runs virtually instantly, and the final polishing is limited to a few hundred iterations.

### 1. Binary MILP (global optimum among indicator functions)

*Variables*  
- `b_i ∈ {0,1}` for each grid point `i = 0,…,N‑1`.  
- Auxiliary binary variables `y_{i,s} ∈ {0,1}` for the product `b_i ∧ b_{i+s}` (zero‑padding outside the interval).  
- A continuous variable `t` that bounds the worst overlap.

*Constraints*  
- **Mass**: `∑_i b_i = N/2` (exactly half the points are 1).  
- **Product linearisation** (for each shift `s` and each feasible `i`):  
  `y_{i,s} ≤ b_i`, `y_{i,s} ≤ b_{i+s}`, `y_{i,s} ≥ b_i + b_{i+s} – 1`.  
- **Worst‑overlap bound** (for each shift `s`):  
  `t ≥ Σ_i b_i – Σ_i y_{i,s}`.  
  The RHS equals the discrete version of `∫ h (1‑h(·+k))`.  

*Objective* – minimise `t`.  

*Implementation notes*  
- Because `c_s` is symmetric under reversal of the shift index, it is sufficient to enforce the bound for `s = 0,…,N‑1` (the negative shifts give the same expression after zero‑padding).  
- The model size is roughly `N*(N) ≈ 20 000` binary variables (`y`); modern open‑source MILP solvers (CBC, GLPK, SCIP) handle this comfortably within a few hundred seconds.  
- The MILP is built with **cvxpy** using the `CBC` solver and a per‑instance time limit (e.g. `solver_kwargs={'maxTime': 250}`).

*Outcome*  
The MILP returns an optimal binary vector `b*`.  Its overlap `C5(b*)` is a valid upper bound (usually ≈ 0.382, not yet the target).  `b*` is an excellent *starting pattern* for the subsequent stages because it concentrates the mass in a configuration that already maximises the minimal self‑overlap among all binary patterns.

### 2. Analytic low‑dimensional interval search (global perspective)

**Rationale** – The 140‑dimensional search space is huge; however the *shape* of an optimal `h` is believed to consist of a small number of constant blocks (the known record uses a two‑peak shape).  By restricting ourselves to a *symmetric three‑interval* family we obtain a 2‑parameter problem that can be explored exhaustively.

**Parametrisation (symmetric three‑interval family)**  

```
a ∈ (0, 0.5]                # length of each outer interval
u ∈ [0,1]                  # height of the outer intervals
v ∈ [0,1]                  # height of the middle interval
```

The intervals are  
- `[0, a]` and `[2‑a, 2]` (height `u`),  
- `[a, 2‑a]` (height `v`).  

The integral constraint is linear:

```
2·a·u + (2‑2·a)·v = 1   ⇒   v = (1 – 2·a·u) / (2‑2·a).
```

Thus the admissible region is a simple rectangle in the `(a, u)` plane bounded by `0 ≤ v ≤ 1`.

**Exact correlation for a given `(a,u)`**  

For any integer shift `s ∈ {-(N‑1),…,N‑1}` the overlap of two intervals after the shift is a *piecewise linear* function of `a`.  Because there are only three intervals we can pre‑compute for each shift `s` the matrix of overlap lengths:

```
O_{ij}(s) = length( interval_i ∩ (interval_j + s·dx) ),   i,j ∈ {outer, middle}.
```

These are pure geometric numbers (0 ≤ O ≤ min(length_i, length_j)).  The total product contribution for shift `s` is

```
P(s) = u²·O_{outer,outer}(s) + 2·u·v·O_{outer,middle}(s) + v²·O_{middle,middle}(s).
```

The discrete correlation value is

```
C_s(a,u) = 1 – dx·P(s)      (dx = 2/N).
```

Therefore the objective for a pair `(a,u)` is simply

```
C5(a,u) = max_s C_s(a,u) = 1 – dx·min_s P(s).
```

All quantities are computed in O(1) per shift, i.e. O(N) for the whole max, which is trivial.

**Global optimisation in (a,u) space**  

1. **Coarse grid** – Scan `a` from 0.10 to 0.45 in steps of `0.005`.  
2. For each `a`, compute the admissible interval for `u` (`0 ≤ u ≤ 1` and `0 ≤ v ≤ 1`).  
3. On that interval run a **1‑D golden‑section search** (or Brent’s method) to minimise `C5(a,u)`.   Each evaluation of `C5` involves a single pass over the pre‑computed `O_{ij}(s)` tables, so the entire grid + refinement takes < 0.1 s.  
4. Keep the pair `(a*,u*)` with the smallest `C5`.  

If needed, the symmetry restriction can be lifted (allow different heights for the two outer blocks, or a fourth interior block).  In that case the search becomes a 3‑ or 4‑dimensional bounded optimisation, which can be handled by **differential evolution** (`scipy.optimize.differential_evolution`) with a modest population (size ≈ 20) – still cheap because each fitness evaluation costs O(N).

**Upsampling to the full grid**  

From the optimal `(a*,u*,v*)` we build a length‑`N` vector `h_int`:

```
for i = 0,…,N‑1:
    x = (i + 0.5)·dx
    if x < a* or x ≥ 2‑a*: h_int[i] = u*
    else:                     h_int[i] = v*
```

Because of rounding, the discrete sum may deviate from `N/2` by at most one unit of `dx`.  We **project** `h_int` onto the feasible set using the water‑filling algorithm (see below).  The projection preserves the shape while enforcing the exact integral.

**Result of stage 2** – an *almost continuous* candidate whose analytic C5 is typically already ≤ 0.3800 (often beating the binary MILP).  The discretised version, after projection, yields a concrete `h` that can be fed to the evaluation routine.

### 3. Final continuous polishing (projected sub‑gradient)

Having a high‑quality vector `h₀` from stage 2, we perform a brief deterministic refinement that directly minimises the original non‑smooth objective.

**Sub‑gradient for the worst shift**  

1. Compute the full correlation `c = np.correlate(h, 1‑h, mode='full')` and locate the worst shift `s*` (the index of the maximal entry).  
2. The gradient of `C5` at that shift is  

```
g = dx·( 1  –  shift_left(h, s*)  –  shift_right(h, s*) )
```

   where the shift operations treat out‑of‑range entries as zero; the formula works for any signed `s*`.  

3. Update `h ← h – η·g` with a step size `η` that decays linearly from `η₀ = 0.4` to `η_min = 0.02` over the allotted polishing time (≈ 0.15 · budget).  

4. **Projection** – after each update project onto the box‑plus‑sum set using the same water‑filling routine as in the MILP stage.  

5. Accept the new point only if `C5` has decreased; otherwise keep the old point (no stochastic uphill moves are needed because we start already close to a basin).  

A few hundred iterations (≈ 200–500) are sufficient: the worst shift changes only a handful of times, and the objective quickly stabilises.  The final `C5` is computed with the original `c5_of` routine and returned as the bound.

### 4. Projection onto box & sum (water‑filling)

Given a vector `v` (possibly out of bounds) and target sum `S = N/2`:

1. Find λ such that `Σ_i clip(v_i + λ, 0, 1) = S`.  
   `F(λ) = Σ_i clip(v_i + λ, 0, 1)` is monotone increasing; start with  
   `λ_low = -max(v)` (all clipped to 0) and `λ_high = 1‑min(v)` (all clipped to 1).  
2. Binary‑search λ for 50 iterations (or until |F(λ)‑S| < 1e‑12).  
3. Set `w = clip(v + λ, 0, 1)`.  
4. Because of finite precision `Σ w` may differ from `S` by ≤ 1e‑12; if needed, distribute the tiny residual uniformly over the *free* entries (`0<w<1`).  

The routine is O(N) and is used after every MILP scaling, after the interval up‑sampling, and after each sub‑gradient step.

### 6. Expected performance & failure handling

*Why this beats the previous annealing‑only approach*  
- **Global optimality at the binary level**: the MILP guarantees the best possible 0/1 pattern; the previous code could only stumble upon a good binary configuration by chance.  
- **Analytic global view**: the three‑interval model explores the continuous neighbourhood of the binary optimum without any stochastic noise, discovering shapes that the local annealer never reaches.  
- **Very cheap objective evaluations**: the interval model evaluates `C5` in O(N) per candidate, allowing a dense grid and reliable line‑search, unlike the O(N²) correlation used at every annealing step.  
- **Focused polishing**: only a few hundred sub‑gradient updates are required because the candidate is already near an optimal basin; this is far more efficient than thousands of random moves.

*Potential failure modes & mitigations*  
- **MILP does not finish**: the time limit (≈ 250 s) guarantees termination; if CBC reports “time limit”, the best feasible incumbent is still valid and will be used.  
- **Optimal interval lies outside the symmetric family**: if the obtained `C5` after stage 2 is still > 0.3807, we fall back to a **four‑interval unsymmetric model** (four continuous parameters) and run differential‑evolution on it – still cheap because each fitness evaluation is O(N).  
- **Projection drift**: the water‑filling step guarantees exact sum; any numerical drift is corrected by the final redistribution pass.  
- **Discrete‑grid artefacts**: after up‑sampling we perform a short sub‑gradient polishing that removes any uplift caused by the grid alignment.
