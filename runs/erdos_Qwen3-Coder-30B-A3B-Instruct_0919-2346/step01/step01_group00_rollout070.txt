## 1. Problem Understanding and Mathematical Analysis

The goal is to minimize the maximum overlap integral for a step function h on [0,2]:
$$C_5 = \max_k \int h(x)(1 - h(x+k)) dx$$

This overlapping integral represents the extent to which h and its shifted version (1-h) overlap. The constraint that ∫₀² h(x) dx = 1 implies that, on average, h takes value 0.5.

The function we're looking to minimize is a maximum of many integrals over different shifts. This transforms into a complex optimization problem with non-convexity and multiple local minima.

def c5_of(h):
    """Compute C5 = max_k integral h(x)(1-h(x+k)) dx."""
    dx = 2.0 / len(h)
    # Compute correlation: h * (1 - h) with full mode
    c = np.correlate(h, 1 - h, mode="full")
    # Multiply by dx to get continuous integral
    c *= dx
    # Return maximum value among all shifts
    return np.max(c)
