Because both players have simple constraints (H is a box + equality; λ is a simplex), we can use projected gradient updates for both sides.

Specifically:

- At iteration t:
   - Compute gradient w.r.t h of L = Σ_s λ_s f_s(h). Since f_s is linear minus quadratic, gradient formula known.
   - Update h using a step in negative gradient (as H wants to minimize).
   - Project onto feasible set (box + equality).
   - Compute gradient w.r.t λ of L: ∂L/∂λ_s = f_s(h). Since λ belongs to simplex, we can ascend by picking shift with largest f_s (or follow gradient ascent on simplex via exponentiated gradient).
   - Update λ using exponentiated gradient (or simple "always put weight 1 on argmax").
