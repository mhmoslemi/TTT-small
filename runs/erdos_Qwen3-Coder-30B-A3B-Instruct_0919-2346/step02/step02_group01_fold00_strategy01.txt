### 5. Solving strategy – binary search on `t`  

Directly minimising `t` with a MILP solver works, but the objective surface is very flat and solvers waste time on weak bounding.

1. Initialise `t_low = 0` (infeasible) and `t_high = 1` (trivially feasible).

   - Set `t_mid = (t_low + t_high) / 2`.  
   - Add the constraints `dx * … ≤ t_mid` for all shifts (they are the same each iteration, only the RHS changes).  
   - Call a MILP solver (CBC, GLPK or SCIP via **cvxpy**) with a **hard time limit** (e.g. 30 s) and `warm_start=True` so the previous basis is reused.  
   - If the model is **feasible**, store the solution (`h*`) and set `t_high = t_mid`.  
   - If **infeasible**, set `t_low = t_mid`.  
3. After the loop, `t_high` is the smallest feasible upper bound found within the prescribed tolerance.  

Because each feasibility test only fixes the RHS, the linear part of the model (matrix structure) is built **once**; subsequent tests only re‑solve the linear system, which is extremely fast for the modest size (`N ≈ 180` → ≈ 16 000 binary `y` variables, ≈ 360 constraints).
