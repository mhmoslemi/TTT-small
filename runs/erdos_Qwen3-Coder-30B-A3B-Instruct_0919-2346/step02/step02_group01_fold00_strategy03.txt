**Overview**

The current best construction is obtained by manipulating the value of *h* at every discretisation point (≈140 variables).  
A fundamentally different route is to *parameterise* the step function by a small number of intervals (the natural shape of optimal solutions for the Erdős‑overlap problem) and to optimise those interval parameters directly.  
This reduces the dimensionality from O(N) to O(M) (M = number of “1‑intervals”), makes the evaluation of the objective exact (no discretisation error), and permits the use of powerful global‑optimisation tools (Differential Evolution, local refinement).  

The algorithm consists of three layers:

1. **Low‑dimensional parametric model** – a binary step function defined by alternating “1‑intervals” and “0‑gaps”.  
2. **Exact evaluation of the overlap functional** – analytic computation of the maximal overlap for any shift using interval geometry (no FFT, no sampling error).  
3. **Two‑phase optimisation** – (i) a global stochastic search on the low‑dimensional simplex, (ii) a fast local optimiser that fine‑tunes the best candidate.

Because the model space is tiny, we can afford many generations and restarts within the 600 s budget, and we can safely increase the number of intervals (M = 5, 7, 9…) if the current model does not reach the target bound.

### 1. Parametric representation of *h*

*Domain:* [0, 2] with total “mass” ∫ h = 1 (i.e. total length of the 1‑regions is 1).  
We assume *binary* values (h ∈ {0, 1}) – this yields O₀ = 0 automatically, and the known optimal solutions for C₅ are unions of a few intervals.

**Variables**

- **Lengths of the 1‑intervals**: ℓ₁,…,ℓ_M (ℓ_i > 0, ∑ℓ_i = 1).  
- **Lengths of the 0‑gaps**:   g₁,…,g_M (g_i > 0, ∑g_i = 1).  

The pattern on [0, 2] is therefore  

```
[0,ℓ₁)      – 1
[ℓ₁,ℓ₁+g₁) – 0
[ℓ₁+g₁,ℓ₁+g₁+ℓ₂) – 1
...
```

Only the *relative* ordering matters; we fix the first gap to start at 0 (no loss of generality because the overall shift of the whole pattern does affect the overlap only through the boundary, but we can let the optimiser discover the optimal offset by allowing a free “global offset” δ∈[0,2] as an extra variable if needed).

**Enforcement of the simplex constraints**

We map an unconstrained vector **u**∈ℝ^{2M} to (ℓ,g) by softmax:

```
ℓ_i = exp(u_i) / Σ_{j=1}^{M} exp(u_j)          (i = 1..M)
g_i = exp(u_{M+i}) / Σ_{j=1}^{M} exp(u_{M+j}) (i = 1..M)
```

Thus every candidate automatically satisfies positivity and the two sum‑to‑1 constraints, removing the need for a projection step inside the optimiser.

If we later wish to allow *fractional heights* (0 < h < 1 on some intervals) we simply add a height variable h_i∈[0,1] for each “1‑interval”. The mapping then becomes

```
h_i = sigmoid(v_i)      (v_i∈ℝ)
```

but we start with the binary model.

### 2. Exact computation of  C₅  for a given (ℓ,g)

For a binary set A (union of the M intervals) the functional

\[
C_5(A)=\max_{k\in\mathbb R}\int_{0}^{2} \mathbf 1_A(x)\bigl(1-\mathbf 1_A(x+k)\bigr)\,dx
\]

can be rewritten as

\[
C_5(A)=\max_{k}\bigl\{\,\text{length}(A\cap[0,2])\;-\;|A\cap (A-k)|\,\bigr\}
      = 1- \min_{k} |A\cap (A-k)|
\]

Hence we need the *minimum* overlap of A with its translate.  
Because A consists of intervals, the overlap for a fixed shift k is simply the sum of the pairwise intersections of the translated intervals:

\[
T(k)=|A\cap (A-k)|=\sum_{i=1}^{M}\sum_{j=1}^{M}
      \operatorname{len}\bigl([a_i,b_i)\cap [a_j+k,b_j+k)\bigr),
\]

where \(a_i,b_i\) are the start/end of interval i.  
The intersection length of two intervals is a piece‑wise linear function of k with at most three regimes (no overlap, partial overlap, full containment). Consequently **T(k) is a piecewise linear function** whose breakpoints occur exactly when an endpoint of one interval aligns with an endpoint of another interval.

**Algorithm to evaluate max C₅**

1. Build the list of interval endpoints \(\{a_i,b_i\}\).  
2. Generate the set of *critical shifts*  

   \[
   K_{\text{crit}}=
   \{\,b_j-a_i,\;a_j-b_i \mid i,j=1..M\}\cap[-2,2].
   \]

   At each such k the expression for an intersection changes its linear formula.  
3. Sort the critical values, add the interval ends –2 and 2, and take the mid‑point of every consecutive pair:  

   \[
   k_{\text{test}} = \frac{k_{r}+k_{r+1}}{2}.
   \]

   Because T(k) is linear on each sub‑interval, the minimum of T(k) (and therefore the maximum of C₅) is attained at a critical point; evaluating the mid‑points is sufficient to locate the global minimum reliably.  
4. For each test shift compute T(k) by a double loop over intervals (O(M²) operations).  
5. Compute  

   \[
   C_5 = 1 - \min_{k\in K_{\text{test}}} T(k).
   \]

All operations are fast (for M ≤ 9 the double loop is < 100 operations). The result is *exact* with respect to the chosen interval model (no discretisation).

### 3. Optimisation strategy

#### 3.1 Global search – Differential Evolution (DE)

- **Design variables**: the unconstrained vector **u**∈ℝ^{2M} (soft‑max parameters) + optionally a global offset δ∈[0,2] (treated as a simple bounded variable).  
- **Population size**: 15 × dim (standard DE rule). For M = 5 → dim = 11 → pop≈165.  
- **Mutation / crossover**: classic “DE/rand/1/bin” with scaling factor F ≈ 0.8, crossover CR ≈ 0.9.  
- **Bounds**: all components of **u** are unrestricted; δ is bounded. DE works on the unconstrained space; the soft‑max ensures feasibility.  
- **Fitness**: the analytic C₅ value (to be minimised).  

Run DE until either the time budget for the global phase is exhausted (≈ 300 s) or the improvement over the last few generations drops below a tiny threshold. Because each fitness evaluation is O(M³) ≈ few hundred elementary ops, we can afford > 50 000 evaluations comfortably.

#### 3.2 Local refinement – gradient‑free local optimiser

Take the best individual returned by DE and polish it with a deterministic local optimiser that does not rely on derivatives:

- **Method**: `scipy.optimize.minimize` with `method='Nelder‑Mead'` or `method='Powell'`.  
- **Starting point**: the DE best **u** (and δ).  
- **Stopping criteria**: tolerance on the objective of 1e‑7 or a maximum of 5 000 local steps.  
- The same analytic C₅ evaluator is used, guaranteeing that the local stage sees the exact objective surface.

Optionally, after the first round with binary heights we can *lift* the model to allow fractional heights: add M extra variables h_i∈[0,1] (again via sigmoid) and repeat the DE + local stage. This gives the algorithm the ability to escape any binary‑only barrier if the optimum truly needs intermediate values.

#### 3.3 Adaptive increase of the number of intervals

If after the refinement the obtained bound exceeds the target 0.3807, increase M (e.g. 5 → 7 → 9) and repeat the whole optimisation. The dimension grows linearly, but still stays ≤ 20, which DE can handle easily within the remaining time. Because the algorithm is *anytime*, we can opportunistically stop at the best bound obtained so far when the wall‑clock limit is reached.
