**Goal** – Produce a step‑function `h` on `[0,2]` (discretised with `N` points, `N≈140`) satisfying  

* `0 ≤ h[i] ≤ 1`  
* `∑ h[i]·dx = 1`  (i.e. `∑ h[i] = N/2`)  

that minimises  

```
C5 = max_k ∫ h(x)·(1‑h(x+k)) dx
     = 1 – min_k ∫ h(x)·h(x+k) dx .
```

Thus the problem is equivalent to **maximising the minimum autocorrelation**  
`g(k)=∫ h(x)h(x+k)dx`.  The optimal `h` should make `g(k)` as flat as possible.

The previous solution relied on random pair‑wise adjustments and a generic genetic algorithm.  
The new plan replaces that with a **deterministic‑annealing gradient ascent** on a smooth approximation of the “minimum” together with a **targeted binary swap hill‑climber** and a **low‑dimensional evolutionary search** for diversification.

### 1. Mathematics – smooth “min” and its gradient

For a discrete vector `h∈[0,1]^N` let  

```
g_k(h) = Σ_i h[i]·h[i+k]         (full correlation, zero‑padding)
```

and `dx = 2/N`.  The objective to maximise is `m(h)=min_k g_k(h)`.  
Introduce a smooth surrogate (soft‑minimum) with temperature τ>0:

```
m_τ(h) = – (1/τ)·log( Σ_k exp( –τ·g_k(h) ) ) .
```

As τ→∞, `m_τ → min_k g_k`.  The gradient of `m_τ` is

```
∂m_τ/∂h[i] = Σ_k w_k·( h[i+k] + h[i‑k] ) ,   (indices outside [0,N‑1] give 0)
```

where  

```
w_k = exp( –τ·g_k ) / Σ_l exp( –τ·g_l )    (soft‑min weights, Σ w_k = 1)
```

All quantities are inexpensive to compute with a single convolution per iteration.

### 2. Core optimisation loop – deterministic‑annealing gradient ascent (DAGA)

1. **Parameters**  
   * `N = 140` (or any even number ≤ 1000).  
   * `dx = 2/N`, target sum `S = N/2`.  
   * Temperature schedule τ = [0.5, 1, 5, 10, 30, 100].  
   * Initial step size `α₀ = 0.1`.  
   * Max inner iterations per τ: `Iτ = 2000` (or less if time runs out).  
   * Convergence tolerance `ε = 1e‑6` on `m_τ` improvement.

2. **Initial vector** – start from the constant 0.5 function (already feasible).  
   Optionally blend with the supplied `initial_h_values` to diversify.

3. **Iteration for a fixed τ**  

   a. Compute the full correlation `g = corr(h,h)` (use `np.convolve` or FFT for speed).  
   b. Stabilise the exponential by shifting: let `ĝ = g – min(g)`.  
   c. Compute the soft‑min weights `w_k = exp( –τ·ĝ_k )`; normalise.  
   d. Compute the gradient  
      `grad = 2·( conv(w, h) + conv(w_rev, h) )`, where `w_rev` is `w` reversed; the convolution is performed with “full” mode and the central part is taken.  
   e. **Projected gradient step**  
      - `h_new = h + α·grad`.  
      - Clip to `[0,1]`.  
      - **Enforce the sum constraint exactly** by a *bounded‑simplex projection*:  
        * clip to `[0,1]`;  
        * compute deficit `δ = S – Σ h_new`;  
        * distribute `δ` uniformly over the *free* (non‑bound) entries, iterating until `|δ|` is negligible.  This guarantees `Σ h_new = S`.  
   f. Evaluate `m_τ(h_new)`. If the increase is < ε, reduce the step (`α ← 0.9·α`) and continue; otherwise keep the new point.  
   g. Stop when either the maximum inner iterations are exhausted or the improvement falls below `ε`.

4. **Annealing** – after finishing the inner loop for a τ, increase τ to the next value, keep the current `h` as the start, and optionally reset `α` to `α₀`.  The gradual increase forces the algorithm first to improve a smooth average of all overlaps, then to concentrate on the worst shift.

5. **Result of DAGA** – a continuous vector `h_cont` with a low `C5 = 1 – dx·min(g_k(h_cont))`.  Because the projection always respects the box and sum constraints, `h_cont` is a feasible solution.

### 3. From continuous to binary – targeted swap hill‑climber

Binary vectors are often optimal for such max‑min autocorrelation problems.  
We therefore **round** `h_cont` to a binary pattern while preserving the sum:

1. Sort the indices by decreasing `h_cont[i]`.  
2. Set the top `S = N/2` entries to 1, the rest to 0 → `h_bin`.  

Now improve `h_bin` with a **targeted swap heuristic** that directly attacks the current worst shift.

**Swap heuristic (single‑swap hill‑climber)**  

*Maintain*: current binary `h`, its correlation `g`, and the current `C5`.

Loop (until time expires or patience runs out):

1. Identify the shift `k*` giving the **minimum autocorrelation** `g_min = min_k g_k`.  
2. Gather two index sets limited to the overlapping region of shift `k*`  

   * `A = { i | 0≤i,i+k*<N, h[i]=1 and h[i+k*]=0 }` – “bad 1s”.  
   * `B = { j | 0≤j,j+k*<N, h[j]=0 and h[j+k*]=1 }` – “bad 0s”.  

3. If both sets are non‑empty, sample up to 30 random elements from each (to keep O(1) work).  
   For every sampled pair `(i,j)` evaluate the effect of swapping `h[i]↔h[j]` (full `C5` recomputed by a single correlation).  
   Keep the swap achieving the **largest decrease** in `C5`.  

4. If an improving swap exists, perform it and reset a “patience” counter.  
   Otherwise perform a **probabilistic escape move**: a random swap of a 1 and a 0 accepted with probability `p = exp( –ΔC5 / T )` where `T` is a slowly cooling temperature (e.g. start `T=0.02` and multiply by 0.99 each iteration).

5. Update `g` after each accepted swap (re‑compute once per iteration; the cost is negligible for the chosen `N`).  

6. Keep the best binary vector ever seen in this run.

Multiple **restarts** (e.g. 15–20) are performed: each restart begins from a fresh random binary vector (or from the rounded `h_cont`) and runs the hill‑climber for a bounded number of iterations (≈ 2000) or until the time budget for this stage is exhausted.

The result of this stage is a high‑quality binary pattern `h_best_bin`.

### 4. Low‑dimensional evolutionary search (optional diversification)

If time remains after stages 1–3, run a **global optimiser on a compact parametrisation**, which can discover structures the gradient‑ascent misses.

1. **Parametrisation** – split the interval into `B = 10` equally sized blocks (length `L = N/B`).  
   Each block `b` carries a constant height `u_b ∈ [0,1]`.  
   The block heights must satisfy the average constraint `Σ u_b = B/2` (equivalently `Σ u_b·L = N/2`).  

2. **Projection onto the bounded simplex** – after any mutation, the vector `u` is projected onto the feasible set `{ u∈[0,1]^B | Σ u = B/2 }` using the same bounded‑simplex routine described in §2‑e.

3. **Objective** – given `u`, expand it to an `N`‑long vector `h_block` by repeating each `u_b` over its block, then compute `C5(h_block)`.  

4. **Optimizer** – call `scipy.optimize.differential_evolution` with:
   * Bounds `(0,1)` for each `u_b`.  
   * Population size `popsize = 12` (≈ 120 candidates).  
   * Maximum generations `maxiter = 150`.  
   * `polish=False` (the later stages already polish).  

   The DE routine will invoke the projection before evaluating the objective, thereby respecting the constraints.

5. **Seeding** – initialise the DE population with:
   * The block‑averaged version of `h_best_bin` (average each `L`‑segment).  
   * Several random feasible `u` vectors.

The best block‑based candidate is either retained directly (if its `C5` improves the global best) or used as a fresh seed for another short binary‑swap hill‑climber (re‑round the block heights to a binary pattern and run the swap heuristic for a few hundred iterations).

| Stage | Approx. share of budget | What it does |

### 6. Numerical choices & safeguards

* **Convolution** – use FFT (`np.fft.fft`) for `g_k` and for the gradient convolutions; O(N log N) cost keeps the inner loop cheap.  
* **Exponential stability** – before computing `w_k = exp(-τ·g_k)`, shift `g_k` by its minimum value (or subtract `max(g_k)` for the soft‑max case) to avoid under/overflow.  
* **Projection onto bounded simplex** – an iterative water‑filling algorithm (clipping, distributing the remaining deficit uniformly over free variables) converges in at most `B` + `N` steps and guarantees `Σ h = S` exactly.  
* **Precision** – all floating‑point work is performed in double precision; the final `C5` is computed with the same `dx` factor as the evaluator expects.  
* **Random seed** – `np.random.seed(seed)` and `random.seed(seed)` are called at the start; all stochastic components derive from these generators for reproducibility.

### 7. Expected failure modes & mitigations

| Failure mode | Symptom | Mitigation |
|--------------|---------|------------|
| **Stagnation in DAGA** (gradient points to a flat region) | `m_τ` stops improving early, τ still low. | Reduce step size adaptively; if improvement stalls for > 100 iterations, restart from a perturbed copy of current `h`. |
| **Overflow in soft‑min weights** (very large τ) | `exp(-τ·ĝ)` becomes all zeros → NaNs. | Apply the shift trick (`ĝ = g – min(g)`) and compute weights via `np.exp(-τ·ĝ)`; also cap τ to 200 to stay safe. |
| **Projection failure** (all variables hit bounds, sum not reached) | The water‑filling loop cannot distribute the remaining deficit. | In that rare case, perform a simple scaling of the whole vector (as in the original `project_feasible`) and re‑clip; this restores feasibility. |
| **Binary hill‑climber gets trapped** | No improving swap for many iterations. | Introduce a temperature‑controlled random swap (simulated‑annealing step) that occasionally accepts a worsening move, allowing escape. |
| **DE population collapses** (many individuals become identical) | Search loses diversity, no improvement. | Inject a few random fresh individuals every 20 generations. |
| **Running out of time** | Last stage never starts. | The timing guard automatically skips later stages, guaranteeing a valid return. |
