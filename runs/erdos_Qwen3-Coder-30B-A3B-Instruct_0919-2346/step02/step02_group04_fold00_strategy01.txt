**Goal** – Produce a step‑function `h` on `[0,2]` (discretised to `N` points) with  
`0 ≤ h[i] ≤ 1`, `∑ h[i]·dx = 1` (`dx = 2/N`) that minimises  

```
C5(h) = max_k  ∫_0^2  h(x)·(1‑h(x+k)) dx
      = max_k  O_k(h) .
```

The current best construction (`C5 ≈ 0.38125`) was obtained by a mixture of differential
evolution, simulated annealing and tiny two‑coordinate moves.  
Below is a **completely different optimisation framework** that exploits analytic
structure of the objective and works directly on the *max* (or a smooth
approximation of it) with a principled projected‑gradient scheme and a
low‑dimensional parametric search running in parallel.

--------------------------------------------------------------------
### 1. Reformulation

For a discrete vector `h` of length `N`

```
O_k(h) = ∑_{i=0}^{N‑1} h[i]·(1‑h[i+k])·dx
      = 1 – ∑_{i} h[i]·h[i+k]·dx               (the term ∑h = 1 is constant)
```

Hence

```
C5(h) = max_k  (1 – Q_k(h))   with   Q_k(h) = ∑_i h[i]·h[i+k]·dx .
```

The *worst* shift `k* = argmax_k O_k` is the one with the **smallest** autocorrelation
`Q_k`.  Reducing `C5` therefore amounts to **increasing the smallest autocorrelation**.

--------------------------------------------------------------------
### 2. Smooth‑max surrogate

Directly minimising `max_k O_k` produces a non‑smooth, non‑convex landscape.
Instead we minimise a differentiable surrogate

```
F_β(h) = (1/β)·log(  Σ_k  exp( β·O_k(h) ) )          (β > 0)
```

* For `β → 0`  `F_β` is the arithmetic mean of the `O_k`.
* For `β → ∞`  `F_β → max_k O_k = C5`.

The gradient is a **soft‑max weighted sum** of the gradients of the individual
shifts:

```
∂O_k/∂h[i] = (1 – h[i+k]) – h[i‑k]          (indices out of range give zero)
w_k      = exp(β·O_k) / Σ_l exp(β·O_l)

∇F_β(h)[i] = Σ_k w_k·∂O_k/∂h[i] .
```

All needed quantities (`O_k`, the weights `w_k`, and the gradient) are obtained
with a single `np.correlate` call and a few linear‑time loops (O(N²) ≤ 20 000
operations for `N = 140`).

--------------------------------------------------------------------
### 3. Projection onto the feasible set

The feasible region is the **box + affine** constraint

```
0 ≤ h ≤ 1 ,          Σ_i h[i]·dx = 1   ⇔   Σ_i h[i] = N/2 .
```

After a gradient step `y = h – α·∇F_β(h)` we project `y` onto this set:

1. **Box clipping** – `y ← clip(y,0,1)`.
2. **Simplex‑with‑bounds projection** – find the unique λ such that

```
ĥ[i] = clip( y[i] – λ , 0 , 1 )   satisfies   Σ_i ĥ[i] = N/2 .
```

Because the clipping function is monotone, λ can be found by a fast
bisection (≈ 30 iterations) guaranteeing the exact affine constraint while
preserving the box limits.

--------------------------------------------------------------------
### 4. Optimisation algorithm (single‑run)

```
Input: N (default 140), time budget B, β‑schedule, step‑size schedule.
Output: best h, best C5.

1. Initialise h₀:
   • Use the best known construction (the one supplied in `initial_h_values`);
   • Additionally start from several random feasible vectors:
        – Sample u_i ~ Exp(1) (i=0..N‑1), set h = u / Σu * (N/2);
        – Clip to [0,1] (if needed) and re‑project to satisfy Σh = N/2.

2. For each start vector run the following loop until the allocated time is
   exhausted (or until convergence):

   a. Compute O_k = correlation of h with (1‑h)   (full mode) → vector of length 2N‑1.
   b. Evaluate the surrogate F_β and its gradient ∇F_β using the formulas above.
   c. Choose step size α = α₀·(1 – t/B)   (linear decay) or use a simple back‑track
      line‑search that respects the projection.
   d. Perform the projected gradient step described in §3.
   e. If the new vector yields a smaller genuine `C5 = max(O_k)`, store it as the
      current best.
   f. **Annealing of β** – after a fixed number of iterations increase β
      (e.g. multiply by 1.2) up to a final value β_max ≈ 30.  This gradually
      turns the smooth surrogate into the true max while keeping the early
      iterations well‑behaved.
   g. **Escaping plateaus** – every 500 iterations perform a cheap random
      two‑coordinate exchange (identical to `propose_move` of the original code)
      and continue gradient descent from the perturbed point if it improves the
      best value.

3. When the time limit B is approached, stop all runs and return the globally
   best `h` that was observed together with `C5 = max_k O_k(h)` and the used `N`.
```

Because each gradient evaluation costs only a few thousand floating‑point
operations, millions of iterations comfortably fit inside the 600 s budget, even
with several restarts.

--------------------------------------------------------------------
### 5. Parallel low‑dimensional *parametric* search (second, independent
   track)

To diversify the search we also run a **structured family** of step functions:

*Choose a small integer `p` (e.g. `p = 5` or `6`).*  
Define consecutive intervals with widths `w₁,…,w_p > 0`, Σ w_i = 2,
and heights `h₁,…,h_p ∈ [0,1]`.  The integral condition becomes

```
Σ_i h_i·w_i = 1 .
```

**Parameterisation**

```
– Let s_i = log w_i   (unconstrained);   w_i = 2·softmax(s)_i .
– Let r_i = log( h_i / (1‑h_i) )   (logit);   h_i = sigmoid(r_i) .
```

Now the only remaining constraint is the integral one, which we enforce by a
penalty term

```
P(h) = λ·max( 0 , 1 – Σ_i h_i·w_i )² .
```

**Optimization**

Apply a **CMA‑ES** (Covariance Matrix Adaptation Evolution Strategy) on the
`2p` real parameters `(s,r)`.  CMA‑ES is derivative‑free, works well on low‑
dimensional continuous spaces, and naturally balances exploration vs. exploitation.
The fitness for a candidate is the true `C5` (computed analytically for a
piecewise‑constant function – which is O(p²) – then discretised to the required
`N` points only for the final reporting).

We run CMA‑ES with a modest population (λ = 20) for a fixed budget of
≈ 30 % of the total time, restarting with different random seeds.  The best
candidate from this track is compared with the best result of the gradient‑
descent track and the superior one is returned.
