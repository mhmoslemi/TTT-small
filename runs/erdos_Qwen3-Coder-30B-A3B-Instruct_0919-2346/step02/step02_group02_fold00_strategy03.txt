**Goal**  
Find a step‑function `h` on `[0,2]` (discretised to `N` points, `dx = 2/N`) satisfying  

* `0 ≤ h[i] ≤ 1`  
* `∑ h[i] = N/2`  

that minimises    

```
C5(h) = max_{shift s∈{-(N-1)…(N-1)}}  dx * Σ_{i} h[i]·(1−h[i+s])
```

The best known value is ≈ 0.381 .  The strategy below departs substantially from the previous simulated‑annealing / GA code by **targeting the worst shift directly**, using **projected sub‑gradient steps**, and finishing with a **global differential‑evolution (DE) refinement**.  All operations are cheap (O(N²) per evaluation) and fit easily into the 600 s budget.

### 1.  Core mathematical ingredients  

| Ingredient | Why it matters |
|-----------|----------------|
| **Worst‑shift identification** – compute the full correlation once, locate the shift `s*` attaining the maximal value `Cmax`. | The objective is the *maximum* over shifts, so any improvement must attack the current worst shift. |
| **Exact gradient for a single shift** – for a fixed shift `s ≥ 0` the contribution is `C_s = Σ_{i=0}^{N-1-s} h[i]·(1−h[i+s])`. Its derivative w.r.t. the vector is  
```
∂C_s/∂h[i] = 1 − h[i+s]          for i in 0..N-1-s
∂C_s/∂h[i+s] = −h[i]            for i in 0..N-1-s
```
(and symmetric for `s < 0`). | The gradient tells precisely *how* to move mass from a “high‑value / low‑overlap” index to the partner that aligns better under `s*`. |
| **Projection onto the capped simplex** – after a gradient step we must enforce `0≤h≤1` **and** `∑h = N/2`.  The feasible set is the intersection of the ordinary simplex with an upper‑bound box.  A linear‑time algorithm exists: repeatedly (a) clip to `[0,1]`; (b) compute the residual `δ = (desired_sum − current_sum) / n_free`; (c) add `δ` to every *free* coordinate (those not on a bound); repeat until `|δ|` is negligible. | Guarantees that every trial stays feasible without costly sorting, keeping the inner loop fast. |
| **Sub‑gradient descent with diminishing step** – use step size `α_t = α0 / sqrt(t+1)`. | Provides a simple, theoretically sound descent on a non‑convex max‑of‑quadratics problem; in practice it drives the worst shift down quickly. |
| **Multiple worst‑shift aggregation** – optionally combine the gradients of the `K` largest shifts (`K = 2…3`) by averaging them. | Prevents over‑fitting to a single shift when several shifts are close to the maximum. |
| **Differential Evolution (DE)** – a population‑based global optimiser that works well on bounded continuous problems.  DE chromosomes are raw vectors in `[0,1]`; before evaluating the objective we **project** them onto the capped simplex. | Supplies a global search that can escape the basin of attraction of the local sub‑gradient method and explores different “shapes’’ of `h`. |
| **Low‑dimensional Fourier parametrisation (optional final polish)** – represent `h` as a truncated Fourier series `h = ½ + Σ_{m=1}^{M} (a_m cos(2π m·x) + b_m sin(2π m·x))`, clip & project, then run a tiny DE on the coefficients (`M≈5`). | Gives a smooth analytic family that often lies near the optimum; optimisation in the low‑dimensional coefficient space is cheap and can improve the final value. |

All of the above are **deterministic** except the stochastic DE and occasional random perturbations for escaping plateaus.

### 2.  Algorithm outline (high‑level flow)

```
run(seed, budget_s):
    set random seeds
    N  ← 200                # enough resolution, still cheap
    dx ← 2.0 / N
    target_sum ← N/2

    # ---------- 2.1  Build several initial seeds ----------
    seeds = [
        uniform   (0.5 everywhere),
        two‑edge  (linear ramp up‑down, renormalised),
        random   (sample Dirichlet then clip),
        best_from_initial_h_values (interpolated to N),
        sine‑bias (0.5 + 0.3*cos(pi*x), clipped)
    ]

    best_h   ← None
    best_c5  ← +∞
    start    ← now()

    # ---------- 2.2  Local worst‑shift optimisation for each seed ----------
    for h0 in seeds:
        h = project_to_capped_simplex(h0)         # guarantee feasibility
        c5 = C5(h)
        if c5 < best_c5:   save best

        t  ← 0
        α0 ← 0.02                                 # initial step size
        while time_left() > 0.6*budget_s:        # leave 40 % for DE
            s*  ← index_of_max_shift(h)           # O(N log N) via np.correlate
            g   ← gradient_of_shift(h, s*)        # O(N)
            α   ← α0 / sqrt(t+1)                  # diminishing step
            h_new ← project_to_capped_simplex( h - α * g )
            c5_new ← C5(h_new)
            if c5_new ≤ c5 or random()<exp(-(c5_new-c5)/α):
                h, c5 = h_new, c5_new          # accept (simulated‑annealing style)
                if c5_new < best_c5:
                    best_h, best_c5 = h_new, c5_new
            t += 1

    # ---------- 2.3  Global DE refinement ----------
    #  Use the current best_h as one member of the initial population.
    bounds = [(0.0,1.0)] * N
    def de_objective(x):
        h = project_to_capped_simplex(x)
        return C5(h)

    de_result = differential_evolution(
                    func=de_objective,
                    bounds=bounds,
                    maxiter = 200,                # ~ 200*popsize ≈ 4000 evaluations
                    popsize = 12,
                    polish  = False,
                    init = 'latinhypercube',
                    updating = 'deferred',
                    seed = seed,
                    workers = 1,
                    callback = lambda x, conv: update_best(x) )
    # callback projects x, evaluates C5, updates global best_h / best_c5

    # ---------- 2.4  Optional Fourier polish ----------
    if time_left() > 5 s:
        optimise Fourier coefficients (M≈5) with a tiny DE
        reconstruct h, project, evaluate, keep if improvement

    # ---------- 2.5  Return ----------
    best_h = best_h * (target_sum / np.sum(best_h))   # final renormalisation (should be already)
    return (best_h, best_c5, N)
```

**Key sub‑routines**

*`project_to_capped_simplex(v)`* – implements the “clip‑then‑redistribute’’ algorithm:
```
v = np.clip(v,0,1)
def redistribute(v):
    excess = target_sum - v.sum()
    free = (v>0) & (v<1)
    while abs(excess) > 1e-12 and free.any():
        delta = excess / free.sum()
        v[free] += delta
        # re‑clip any that left bounds
        v = np.clip(v,0,1)
        free = (v>0) & (v<1)
    return v
```
The routine runs at most a few passes because `delta` shrinks quickly.

*`C5(h)`* – exactly the provided definition:
```
c = np.correlate(h, 1-h, mode='full')
return (c * dx).max()
```

*`gradient_of_shift(h, s)`* – for integer shift `s` (positive or negative):
```
g = np.zeros_like(h)
if s >= 0:
    i = slice(0, N-s)
    j = slice(s, N)
    g[i] += 1 - h[j]          # ∂/∂h[i]
    g[j] += -h[i]             # ∂/∂h[j]
else:
    s = -s
    i = slice(s, N)
    j = slice(0, N-s)
    g[i] += 1 - h[j]
    g[j] += -h[i]
return g
```
All operations are vectorised, O(N).

*`index_of_max_shift(h)`* – compute full correlation `c = np.correlate(h,1-h,'full')`; pick the index of the maximal entry; convert to shift `s = idx - (N-1)`.

*`update_best(x)`* – inside the DE callback, project `x`, compute `c5`, and replace the global best if improved.

### 3.  Why this should beat the previous record

1. **Targeted descent** – By always moving mass **along the direction that directly reduces the *current* worst shift**, we avoid wandering in flat regions that plagued random pair swaps.  The gradient is exact for that shift, so each accepted step provably lowers (or keeps) the worst‑shift value unless the projection undoes it.

2. **Projection guarantees feasibility** – The capped‑simplex projection maintains the strict `∑h=½·2` and box constraints without shrinking the feasible region, unlike the ad‑hoc normalisation in the old code.

3. **Diminishing step with occasional Metropolis acceptance** – Provides a simulated‑annealing flavour that prevents early stagnation while still converging quickly.

4. **Multiple seeds and DE** – The local optimiser may get stuck in a narrow basin; DE explores the global landscape with a *different* search principle (population evolution) and uses the already–good local optimum as a seed.  DE’s population size and iteration count are chosen to fit comfortably in the remaining time budget, giving a strong chance of finding a better configuration.

5. **Low‑dimensional Fourier polish** – If time permits, the final Fourier optimisation can capture smooth, globally‑coherent variations that are hard for point‑wise moves to discover, giving a last push below the 0.381 threshold.

All components are **pure NumPy / SciPy**, no external solvers, fitting the allowed libraries and the 1‑CPU limit.  The most expensive operation (full correlation) is performed ≤ ~ 10⁴ times, each costing O(N²) ≈ 4·10⁴ FLOPs for `N=200`, well below the 600 s budget.

### 6.  Robustness & failure‑mode mitigations

* **Projection loops** – The redistribution loop terminates after at most three passes because each pass strictly reduces the number of violated bounds.  A safeguard `max_pass = 10` is added.
* **Stagnation** – If after a large number of iterations (`t > 5000`) the worst‑shift value does not improve, the algorithm randomly perturbs a small fraction (≈ 2 %) of coordinates by `±0.05` (clipped), then resumes descent.  This “restart‑kick’’ prevents permanent dead‑ends.
* **DE premature convergence** – The DE callback forces acceptance of any offspring that improves the global best, overriding the default `strategy='best1bin'` acceptance rule for that individual.  This accelerates exploitation of promising regions.
* **Numerical stability** – All computations are carried out in double precision; the correlation is multiplied by `dx` only at the very end to avoid cumulative rounding errors.
