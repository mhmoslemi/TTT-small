We must produce a step‑function `h` on `[0,2]` (represented by `N` equally spaced samples) satisfying  

* `0 ≤ h[i] ≤ 1` for all `i`

`C5 = max_k ∫ h(x)(1‑h(x+k))dx`  

is as small as possible.  The discrete evaluation used in the grader is  

`c = np.correlate(h, 1‑h, mode='full')*dx` , `C5 = np.max(c)`.

### 1. Reformulation

For any integer shift `d` (lag `d = k/dx`)  

```
O(d) = dx·∑_i h[i]·(1‑h[i+d])      (out‑of‑range indices => h = 0)
     = 1 – dx·∑_i h[i]·h[i+d]                (because ∑h[i]·dx = 1)
```

Thus minimising `max O(d)` ⇔ maximising the *minimum* autocorrelation  
`A(d)=dx·∑_i h[i]·h[i+d]`.  The term `A(d)` is bilinear, so the problem is a non‑convex quadratic **maximin**.

### 2. High‑level optimisation scheme

We will combine three complementary optimisation layers:

1. **Deterministic annealing (smooth‑max gradient descent)** – works on the continuous domain `[0,1]` and drives the whole vector toward a configuration with a low max‑overlap.  
2. **Binary refinement by simulated‑annealing (swap‑search)** – projects the continuous solution to a 0/1 vector (exactly `N/2` ones) and then improves it with a classic SA on swaps, keeping the integral constraint exact.  
3. **Targeted local pairwise adjustments** – a final short hill‑climbing phase that nudges the best solution found by the two previous layers.

All three phases respect the `∑ h = N/2` constraint and are timed so that the whole `run` finishes well inside the allocated budget.

### 3. Phase 1 – Deterministic annealing (smooth‑max)

**3.1. Smooth approximation of the max**  
Replace `max_d O(d)` by the log‑sum‑exp surrogate  

```
F_λ(h) = (1/λ)·log( Σ_d exp( λ·O(d) ) )
```

For small λ the landscape is smooth; as λ → ∞, `F_λ → max O`.  We will start with λ≈0.5 and increase it gradually (geometric schedule, factor ≈ 1.3) up to λ≈8–10.

**3.2. Gradient of the surrogate**  
For a fixed lag `d`

```
∂O(d)/∂h[i] = –dx·( h[i+d] + h[i‑d] )          (indices out of range give 0)
```

Hence

```
∂F_λ/∂h[i] = Σ_d w_d·∂O(d)/∂h[i]
with  w_d = exp(λ·O(d)) / Σ_j exp(λ·O(j))      (softmax weights)
```

The gradient is a weighted sum of neighbour values; it can be computed in O(N²) with simple loops (N=140 → 20 k operations, negligible).

**3.3. Gradient‑step with projection**  

* Step size `η` – start at 0.02 and decay like `η_t = η0/(1+t)` (t = iteration).  
* Update: `h_new = h – η·grad`.  
* **Projection onto the feasible set** (box + sum constraint):  
  - Clip `h_new` to `[0,1]`.  
  - Apply a *water‑filling* projection onto the hyperplane `∑h = N/2` while respecting the box:  
        1. Compute excess = ∑h – N/2.  
        2. Identify the set `U` of indices not on a bound (0 < h < 1).  
        3. Distribute `–excess/|U|` uniformly to all `U`.  
        4. Re‑clip, recompute excess, repeat (normally converges in ≤ 3 passes).  

The projection is exact (up to floating‑point tolerance) and keeps the integral constraint satisfied throughout the annealing.

### 4. Phase 2 – Binary refinement by simulated annealing

The annealed `h` is usually fractional; a pure 0/1 configuration may give a smaller `max O` because the product term becomes exact (binary maximises `h[i]·h[i+d]`).  We therefore:

**4.1. Projection to binary** – Sort the entries of the current `h`; set the largest `N/2` to 1, the remainder to 0.  This guarantees the integral constraint.

**4.2. Simulated‑annealing on swaps**  

*State:* a binary vector `b` with exactly `N/2` ones.  
*Neighbour move:* pick a random index `i` with `b[i]=1` and a random `j` with `b[j]=0`; swap them (so the sum stays correct).  

*Energy:* `E(b) = max_d O_b(d)` (computed with the same correlation routine).  

*Acceptance:*  
  - If `E_new < E_cur` accept.

*Temperature schedule:* start `T₀ = 0.02`, multiply by `0.995` each step; stop when `T < 1e‑5` or when the allotted time slice (~30 % of the budget) expires.
