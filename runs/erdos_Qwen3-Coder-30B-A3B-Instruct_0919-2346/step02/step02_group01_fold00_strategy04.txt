def block_h_from_params(params, N):
    n = len(params)//2
    u = params[:n]
    v = params[n:]
    a = np.exp(u)
    a /= a.sum()
    b = np.exp(v)
    b /= b.sum()
    # Build block lengths and fill grid
    # We need to create N points; we can compute start indices.
    # Approach: allocate integer counts for each block based on fractional lengths.
    # For block with ones: target count = a_i * N/2 (since half of total points should be ones).
    # But total points per block (both ones and zeros) = (a_i + b_i) * N/2? Actually each block length in terms of total measurement: a_i for ones, b_i for zeros; total measure of both combined is 2 (half each). In terms of points (since dx = 2/N), the number of points per unit measure is N/2 per unit length. So the number of points for block i (ones) = a_i * N/2; for zero block = b_i * N/2.

    # Let's compute integer counts for each block by rounding.
    point_per_unit = N/2.0
    ones_counts = np.floor(a * point_per_unit + 1e-12).astype(int)
    zeros_counts = np.floor(b * point_per_unit + 1e-12).astype(int)
    # Track fractions for allocation of remainder
    ones_frac = a * point_per_unit - ones_counts
    zeros_frac = b * point_per_unit - zeros_counts
    # Compute remaining points needed for ones and zeros:
    ones_rem = int(round(N/2 - ones_counts.sum()))
    zeros_rem = int(round(N/2 - zeros_counts.sum()))
    # allocate remainder points to those with largest fractions
    if ones_rem > 0:
        idx = np.argsort(-ones_frac)[:ones_rem]
        ones_counts[idx] += 1
    elif ones_rem < 0:
        idx = np.argsort(ones_frac)[: -ones_rem]
        ones_counts[idx] -= 1
    if zeros_rem > 0:
        idx = np.argsort(-zeros_frac)[:zeros_rem]
        zeros_counts[idx] += 1
    elif zeros_rem < 0:
        idx = np.argsort(zeros_frac)[: -zeros_rem]
        zeros_counts[idx] -= 1

    # Build h array using interleaved blocks: 1's block then 0's block.
    h = np.empty(N, dtype=float)
    pos = 0
    for i in range(n):
        cnt_one = ones_counts[i]
        if cnt_one > 0:
            h[pos:pos+cnt_one] = 1.0
            pos += cnt_one
        cnt_zero = zeros_counts[i]
        if cnt_zero > 0:
            h[pos:pos+cnt_zero] = 0.0
            pos += cnt_zero
    # In case due to rounding pos < N, fill the rest with 0 (should be zeros)
    if pos < N:
        h[pos:] = 0.0
    return h

Implementation of compute_c5_fft:

def compute_c5(h):
    N = h.shape[0]
    dx = 2.0 / N
    # Use FFT length >= 2*N-1
    size = 1 << ((2*N - 1).bit_length())
    # reverse (1 - h) for correlation
    rev = (1.0 - h)[::-1]
    H = np.fft.rfft(h, n=size)
    G = np.fft.rfft(rev, n=size)
    conv = np.fft.irfft(H * G, n=size)[:2*N-1]
    c5 = np.max(conv) * dx
    return float(c5)

def build_binary_h(N, a, b):
    # a,b arrays of length n each summing to 1.
    point_per_unit = N / 2.0
    # compute ideal integer counts
    ones_counts_float = a * point_per_unit
    zeros_counts_float = b * point_per_unit
    ones_counts = np.floor(ones_counts_float).astype(int)
    zeros_counts = np.floor(zeros_counts_float).astype(int)
    # compute fractional parts
    ones_frac = ones_counts_float - ones_counts
    zeros_frac = zeros_counts_float - zeros_counts
    # allocate remaining counts
    ones_rem = int(round(N/2 - ones_counts.sum()))
    zeros_rem = int(round(N/2 - zeros_counts.sum()))
    # assign ones rem
    if ones_rem > 0:
        idx = np.argsort(-ones_frac)[:ones_rem]
        ones_counts[idx] += 1
    elif ones_rem < 0:
        idx = np.argsort(ones_frac)[: -ones_rem]
        ones_counts[idx] -= 1
    # assign zeros rem
    if zeros_rem > 0:
        idx = np.argsort(-zeros_frac)[:zeros_rem]
        zeros_counts[idx] += 1
    elif zeros_rem < 0:
        idx = np.argsort(zeros_frac)[: -zeros_rem]
        zeros_counts[idx] -= 1
    # build h
    h = np.empty(N, dtype=float)
    pos = 0
    for i in range(len(a)):
        cnt_one = ones_counts[i]
        if cnt_one > 0:
            h[pos:pos+cnt_one] = 1.0
            pos += cnt_one
        cnt_zero = zeros_counts[i]
        if cnt_zero > 0:
            h[pos:pos+cnt_zero] = 0.0
            pos += cnt_zero
    # if pos < N fill remainder zero
    if pos < N:
        h[pos:] = 0.0
    return h

**Goal** – Produce a step‑function `h` on `[0,2]` (discretised to `N` points, `∑h·dx = 1`) whose overlap value  

```
C5(h) = max_k ∫_0^2 h(x)·(1‑h(x+k)) dx
```

is as small as possible (target ≈ 0.3807).  The previous code treated every point as an independent variable; we will instead optimise a *low‑dimensional block representation* of the function and then refine the resulting binary sequence with a fast swap‑based hill‑climber.  The whole pipeline is fully deterministic, respects the time budget and uses only the allowed libraries.

--------------------------------------------------------------------
### 1.  Discretisation choice  

*Pick a moderate resolution that is fast to evaluate but still fine enough to capture the optimum.*  
`N = 200` gives `dx = 2/200 = 0.01`.  The constraint `∑h = N/2` means exactly `100` entries must be `1` and `100` entries must be `0`.

--------------------------------------------------------------------
### 2.  Block parametrisation  

We assume `h` consists of alternating blocks of value `1` and `0`:

```
1‑block 0‑block 1‑block 0‑block … (n ones‑blocks, n zero‑blocks)
```

The optimisation variables are the **relative lengths** of the blocks:

* `a = (a1,…,an)` – lengths of the 1‑blocks,  Σ a_i = 1  
* `b = (b1,…,bn)` – lengths of the 0‑blocks, Σ b_i = 1  

The total interval length is `2 = Σ a_i + Σ b_i`.  The dimension of the search space is `2·n‑2` (the two sum‑constraints are built‑in).

**Why this is different:** the original programme optimised all `N` point values; we now optimise only the *positions* of the jumps, i.e. a handful of continuous parameters.

--------------------------------------------------------------------
### 3.  Enforcing the simplex constraints  

We map an unconstrained vector `u∈ℝ^{2n}` to feasible block lengths by a soft‑max:

```
a_i = exp(u_i) / Σ_{j=1..n} exp(u_j)
b_i = exp(u_{n+i}) / Σ_{j=1..n} exp(u_{n+j})
```

Thus any `u` yields positive `a,b` that automatically satisfy the required sums.

--------------------------------------------------------------------
### 4.  From block lengths to a binary sample vector  

Given `a` and `b` and the target resolution `N`:

* The expected number of “1” samples contributed by block *i* is `a_i·N/2`.
* Take the floor of each expectation, keep the fractional remainders,
* Distribute the remaining whole samples to the blocks with the largest remainders
  (standard “largest‑remainder” rounding).  The same is done for the 0‑blocks.
* Interleave the integer‑count blocks (1‑block, 0‑block, …) to fill an array
  `h_bin ∈ {0,1}^N` that contains **exactly** `N/2` ones.

This guarantees the feasibility constraints (`0≤h≤1` and correct integral) without any post‑hoc scaling.

--------------------------------------------------------------------
### 5.  Fast evaluation of `C5`  

`C5` can be computed from the discrete correlation

```
c = correlate( h , 1‑h , mode='full' )
C5 = max(c) * dx
```

Evaluating `correlate` via FFT is far faster (O(N log N)) and easily vectorised:

1. Form `g = (1‑h)[::-1]` (reversed complement).
2. Choose a power‑of‑two length `L ≥ 2·N‑1`.
3. Compute `Fh = rfft(h, L)`, `Fg = rfft(g, L)`.
4. `conv = irfft(Fh * Fg, L)[:2·N‑1]`.
5. `C5 = max(conv) * dx`.

All evaluations in the algorithm use this routine.

--------------------------------------------------------------------
### 6.  Global search – Differential Evolution (DE)  

* **Variables:** the `2·n` real parameters `u`.  
* **Bounds:** `u_i ∈ [‑8, 8]` – wide enough to let any block dominate if needed.  
* **Population size:** `popsize = 15`.  
* **Iterations:** `maxiter = 120` (≈ 1800 objective calls).  
* **Objective function:** for a candidate `u`, build `a,b`, construct `h_bin`,

DE explores the low‑dimensional block space globally and quickly discovers promising
alternating patterns that are difficult to reach by point‑wise random moves.

### 7.  Local refinement – Swap‑based hill climbing  

The best binary vector returned by DE becomes the starting point for a
large‑scale **simulated‑annealing / hill‑climbing** on the *binary* space:

* **Move:** pick uniformly a position `i` where `h[i]=1` and a position `j` where `h[j]=0`,
