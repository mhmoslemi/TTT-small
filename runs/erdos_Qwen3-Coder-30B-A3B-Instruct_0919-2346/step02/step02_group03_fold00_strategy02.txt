### 1. Reformulation as a max‑min quadratic problem  

For an integer lag `d` (corresponding to shift `k = d·dx`)

```
O(d) = dx·∑_i h[i]·(1‑h[i+d])      (out‑of‑range h = 0)
     = 1 – dx·∑_i h[i]·h[i+d]        (since ∑ h[i]·dx = 1)
```

Hence  

`C₅ = max_d O(d) = 1 – dx·min_d  Σ_i h[i]·h[i+d]`

The bilinear term `h[i]·h[i+d]` is the only source of non‑convexity.

If we restrict `h` to be binary (`h[i]∈{0,1}`) the integral constraint forces exactly `N/2` ones.  Binary solutions are admissible and often give tighter overlaps, so we will search **exclusively** in the binary space and later optionally smooth them.

---

### 2. MILP model with product linearisation  

Introduce binary variables  

```
b_i ∈ {0,1}      for i = 0,…,N‑1           (the step function)
```

enforcing  

```
∑_i b_i = N/2                          (integral constraint)
```

For each lag `d` we need the overlap term  

```
S_d = ∑_{i=0}^{N‑1‑d} b_i·b_{i+d}
```

Linearise each product with an auxiliary binary variable `w_{i,d}`:

```
w_{i,d} ≤ b_i
w_{i,d} ≤ b_{i+d}
w_{i,d} ≥ b_i + b_{i+d} – 1
w_{i,d} ∈ {0,1}
```

Then  

```
S_d = ∑_{i=0}^{N‑1‑d} w_{i,d}
O(d) = 1 – dx·S_d
```

Introduce a continuous variable `t` that upper‑bounds all overlaps:

```
t ≥ O(d)   ⇔   S_d ≥ N/2 – t/dx     for every d
```

The MILP becomes

```
minimise   t
subject to  ∑ b_i = N/2
            S_d ≥ N/2 – t/dx          ∀ d ∈ ActiveLags
            product‐linearisation constraints for each (i,d)
            0 ≤ b_i ≤ 1,  b_i integer
            0 ≤ w_{i,d} ≤ 1, w_{i,d} integer
            0 ≤ t ≤ 1
```

All constraints are linear; the only non‑convexity is captured by the binary product variables.

### 3. Constraint‑generation (cutting‑plane) loop  

Adding product variables for **every** lag `d = 0,…,N‑1` yields ~10 000 binary `w` variables – still manageable, but solving the full model can be slow.  Instead we start with a *small* active set of lags (e.g. `{0, ⌊N/2⌋}`) and iteratively add the most‑violating lag.

**Loop**

1. **Build the MILP** with the current set `K` of active lags.  
2. **Solve** (time‑bounded, e.g. 8 s per solve) using any open‑source MILP solver (CBC, GLPK_MI, SCIP, or the CP‑SAT solver from OR‑Tools).  
   - Provide the binary warm‑start obtained from the supplied `initial_h_values` (top half = 1).  
3. **Extract** the binary vector `b*` and the objective value `t*`.  
4. **Full evaluation** – compute `C₅(b*)` with the grader’s `np.correlate`.  
5. If `C₅(b*) ≤ t* + ε` (ε≈1e‑6) stop: `b*` satisfies all lags, and `t*` is the exact max‑overlap for this binary pattern.  
6. Otherwise identify the lag `d_max` where `O(d_max) = C₅(b*)`.  
7. Add `d_max` to `K` and repeat.

Because each iteration only inserts the lag that is currently the worst, the number of added constraints stays tiny (often ≤ 10).  The MILP size therefore remains modest, and the solver can quickly re‑optimise using the previous basis.

**Symmetry reductions (optional but highly effective)**  

* **Mirror symmetry** – enforce `b_i = b_{N‑1‑i}`; reduces variables by ~½.  
* **Phase fixing** – set `b_0 = 1` (the pattern can be rotated without loss).  
These cuts shrink the search space without excluding an optimal solution (any optimal pattern can be rotated to satisfy them).

### 4. Parallel heuristic: Simulated‑Annealing on swaps  

While the MILP loop runs, a lightweight simulated‑annealing (SA) process explores the binary space independently:

* **State** – binary vector `b` with exactly `N/2` ones.  
* **Neighbour move** – pick a random `i` with `b_i=1` and a random `j` with `b_j=0`; swap them.  
* **Energy** – `E(b) = C₅(b)`.  
* **Acceptance** – Metropolis rule with temperature schedule `T ← T₀·α^step` (e.g. `T₀=0.02, α=0.995`).  
* **Budget** – run for a fixed fraction of the total time (≈ 30 %).  

Whenever SA discovers a vector with a lower `C₅` than the current MILP incumbent, we feed this vector to the MILP as a warm start for the next iteration.  This cross‑pollination accelerates convergence because the MILP can start from a good feasible point.

### 5. Continuous polishing – deterministic annealing (smooth‑max)

After the MILP‑SA phase finishes we possess a high‑quality binary vector `b̂`.  To squeeze the last few hundredths we relax it to a continuous vector `h` and perform a *smooth‑max gradient descent*:

1. Initialise `h ← b̂` (cast 0/1 to float).  
2. For a smoothing parameter `λ` (start at 0.5, multiply by 1.3 each outer iteration, up to ≈ 8) compute  
   * `O(d) = dx·∑ h[i]·(1‑h[i+d])` for all lags `d`.  
   * Softmax weights `w_d = exp(λ·O(d)) / Σ exp(λ·O)`.  
   * Gradient `∂F/∂h[i] = –dx·Σ_d w_d·(h[i+d] + h[i‑d])`.  
3. Update `h ← h – η·grad` with a diminishing step size `η`.  
4. **Project** onto the feasible set (`0≤h≤1` and `∑h = N/2`) using a water‑filling projection:  
   * Clip to `[0,1]`.  
   * Compute excess `e = ∑h – N/2`.  
   * Distribute `–e/|U|` uniformly over the unfixed indices `U = {i | 0<h_i<1}`; repeat until `|e|` is negligible.  
5. Keep the best `h` (lowest `C₅`) seen across all λ values.

Because the smoothing turns the non‑differentiable `max` into a smooth convex combination, the descent can move the fractional values away from the binary extremes only where it helps to reduce the worst lag, often lowering `C₅` by 1–3 · 10⁻⁴.

### 6. Final fine‑grained hill‑climbing (optional)

Run a short (≈ 5 % of total budget) deterministic hill‑climb that **targets the current worst lag**:

* Compute the lag `d* = argmax O(d)`.  
* For every index `i` in the overlapping region of `d*`, evaluate the local contribution `c_i = h[i]·(1‑h[i+d*])`.  
* Pick the index with the largest `c_i` (high value where the shifted partner is low) and the index `j` with the smallest `c_j` (low value where partner is high).  
* Transfer a small amount `δ` (start at 0.05, shrink when no improvement) from `i` to `j`, re‑project, and accept only if `C₅` improves.  

Because this move directly attacks the dominant term, a few iterations can shave off the final few ten‑thousandths.
