h = (h0,…,hN‑1) ,      0 ≤ hi ≤ 1 ,      Σi hi = N/2                (1)
Oi(k) = dx· Σi hi·(1‑h_{i+k})                               (2)
```

where the index `i+k` is ignored when it falls outside `{0,…,N‑1}` (zero‑padding).  
Using Σi hi = N/2 we rewrite (2) as  

```
Oi(k) = 1 – (2/N)· Σi hi·h_{i+k}                           (3)
```

Define a slack variable λ ≥ max_k Oi(k).  The optimisation problem is

```
 minimise   λ
 subject to  (3) ⇒ Σi hi·h_{i+k} ≥ (1‑λ)·(N/2)   for every shift k   (4)
             (1) .
```

Thus we must **increase the smallest autocorrelation** Σi hi·h_{i+k} while keeping the box and affine constraints.

--------------------------------------------------------------------
### 2.  Linearisation of the bilinear terms (McCormick envelope)

Introduce a new variable   

```
wij(k)  ≈  hi·h_{i+k}      (i = 0,…,N‑1‑k) .
```

For variables bounded in `[0,1]` the convex hull of the product is described by the four McCormick inequalities  

```
wij(k) ≥ 0,
wij(k) ≥ hi + h_{i+k} – 1,
wij(k) ≤ hi,
wij(k) ≤ h_{i+k}.                                            (5)
```

If (5) holds then `wij(k)` is a **relaxation** of the exact product; it can be larger than the true product, never smaller.  
Replacing the products in (4) by `wij(k)` gives a **linear program (LP)** whose feasible set contains the original feasible set.  Consequently the optimum λ\*_LP of the LP is a **lower bound** on the true optimum λ\*.

--------------------------------------------------------------------
### 3.  Cutting‑plane (constraint‑generation) scheme  

Adding all shifts (`2N‑1 ≈ 280` for `N=140`) at once would create > 20 000 `wij` variables – still tractable, but many of those constraints are never active at the optimum.  
Instead we start with a *tiny* subset `K ⊂ {‑N+1,…,N‑1}` (e.g. `K = {0,1,‑1,2,‑2}`) and **iteratively enlarge** it:

```
repeat
    1.  Solve the LP (λ, h, {wij(k) | k∈K})   – minimise λ.
    2.  Obtain the optimal fractional vector ĥ.
    3.  Evaluate the *exact* overlaps
            Ô(k) = dx· Σi ĥi·(1‑ĥ_{i+k})      for all k (full correlation).
    4.  Let k* = argmax_k Ô(k) and  Ô* = Ô(k*).
    5.  If  Ô* ≤ λ̂ + ε    stop   (the LP solution already certifies optimality
                                   within tolerance ε).
       Otherwise add the violating shift k* to K    (K ← K ∪ {k*})
       and go to step 1.
```

Because every new constraint forces the LP to raise the lower bound λ, the sequence `λ̂` is monotone increasing and converges to the true optimum after a modest number of iterations (typically < 50).

*Complexity*: each LP contains `|K|·(N‑|k|)` variables `wij(k)` and `N` variables `hi`.  For `|K| ≤ 30` the problem has at most ≈ 4 000 variables – easily solved with the LP solver bundled in **CVXPY** (`ECOS` or `OSQP`).  The correlation in step 3 costs O(N²) (≈ 2·10⁴ FLOPs for N=140) and is negligible.

--------------------------------------------------------------------
### 4.  From the fractional LP solution to a feasible step‑function  

The LP optimum gives a **fractional** profile `ĥ`.  To obtain a valid `h ∈ [0,1]` with the exact integral we perform a deterministic rounding:

1.  Sort the indices by the value `ĥi` (descending).  
2.  Set the first `N/2` entries to `1` and the remaining ones to `0`.  
3.  If some `ĥi` is exactly `0.5` (or any tie) break ties arbitrarily.  

The resulting binary vector `h⁰` satisfies the integral constraint *exactly* and respects the box constraints.  Because the LP relaxation is a **lower bound**, the binary rounding can only increase the objective, i.e. the true `C5(h⁰)` is an **upper bound** on λ\*_LP.

Optionally we can improve the rounding quality by **randomised rounding**: for each i draw a Bernoulli variable with probability `ĥi` and then project the resulting vector onto the hyperplane Σ hi = N/2 (by moving mass from the smallest to the largest entries).  We keep the best of a few independent trials.
