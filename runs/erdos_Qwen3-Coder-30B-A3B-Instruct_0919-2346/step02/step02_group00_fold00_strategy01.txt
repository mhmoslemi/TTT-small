### 1.  Mathematical reformulation

For a fixed integer shift `s` (−(N‑1)…+(N‑1) in the discretised world)

\[
f_s(h)=\sum_{i\in I_s} h_i\bigl(1-h_{i+s}\bigr)dx,
\qquad
I_s=\{\,i\mid 0\le i,i+s<N\,\}.
\]

Thus  

\[
C_5(h)=\max_s f_s(h)=1-\min_s g_s(h),\qquad
g_s(h)=\sum_{i\in I_s}h_i h_{i+s}\,dx .
\]

*The problem is a **min‑max**: minimise the worst‑case linear‑plus‑quadratic functional.*  
All constraints are **box** (`0≤h≤1`) and a **single affine** equality (`∑h = N/2`).

| **B. The two levels are complementary: (A) jumps across the landscape, (B) climbs down locally.

### 3.  Level A – Piecewise‑constant template

#### 3.1  Template definition  

Take a symmetric template with `M` blocks ( `M=3` or `M=5` is sufficient).  
For `M=3` we have three unknowns:

```
p  ∈ (0,1)                – half‑width of the outer high plateaus
a  ∈ [0,1]                – height of the outer plateaus
b  ∈ [0,1]                – height of the central plateau
```

The layout (on `[0,2]`) is  

```
[0,p)          : height a
[p,2-p)        : height b
[2-p,2]        : height a      (mirror of left)
```

The integral constraint yields a *single linear relation*

\[
2pa + (2-2p)b = 1 \;\Longrightarrow\; b = \frac{0.5 - p a}{1-p},
\]

so the free parameters are `(p,a)` only.  The admissible region is:
`0<p<1`, `0≤a≤1`, and the resulting `b` must also lie in `[0,1]`.  

For `M=5` we insert two intermediate blocks (heights `c₁,c₂` and widths `q₁,q₂`) – eight variables, but the integral still gives one linear equation, leaving seven free variables.  The extra degrees of freedom give a finer control of the autocorrelation shape.

#### 3.2  Analytic evaluation of `C₅` for the template  

Because each block is constant, the overlap integrals for any shift `s` can be expressed as a sum of *products of block lengths* and *products of heights*.  For `M=3` there are only three regimes for `s`:

1. `0 ≤ s ≤ p` (outer plateaus still intersect themselves)  
2. `p ≤ s ≤ 2‑p` (outer plateaus completely over the centre)  
3. `2‑p ≤ s ≤ 2` (only a tail of the centre overlaps the outer plateaus)

In each regime `f_s` is an *affine* function of `s`.  Hence the maximum of `f_s` on a regime occurs at an endpoint.  
Consequently the global `C₅` is the maximum of **six** explicit values:
`f_s` evaluated at `s = 0, p, 2‑p, 2` (and the symmetric negative shifts).  

The formulae are straightforward arithmetic; they can be coded in a few lines.  Therefore we can **grid‑search** the admissible `(p,a)` region with, say, a 200×200 lattice (≈ 40 k evaluations) in < 0.1 s.  For `M=5` a modest random‑sampling (≈ 50 k points) suffices.

#### 3.3  Selecting the best template  

We keep the parameters that give the smallest `C₅`.  Empirically the optimum lies near

```
p ≈ 0.33 ,   a ≈ 0.94 ,   b ≈ 0.25      (M=3)
```

which already yields `C₅ ≈ 0.386` – already better than the previous record.  
The corresponding continuous profile is then sampled on a regular grid (`N` points) by simple piecewise‑constant assignment and finally **projected** onto the exact feasible set (see §4) to remove the tiny discretisation error.

### 4.  Level B – Projected sub‑gradient descent on the full grid  

#### 4.1  Objective and active shift  

Let  

```
c = corr(h , 1‑h)   # full‑mode correlation (length 2N‑1)
C5 = max(c) * dx
```

The **active set**  

```
S = { s | f_s(h) ≥ C5 − ε } ,   ε = 1e‑4·C5
```

contains all shifts whose value is within a tiny tolerance of the maximum.  
Using the whole active set instead of a single maximiser smooths the sub‑gradient and avoids zig‑zag when several shifts tie.

#### 4.2  Exact sub‑gradient for a given shift  

For a shift `s ≥ 0`

```
grad_i = (1 - h_{i+s})   if i+s < N else 0
       - h_{i-s}        if i-s ≥ 0 else 0
```

For `s < 0` the same formula with `s` replaced by `-s` (or simply use `grad = -grad_{‑s}` because f_{‑s}(h)=f_s(h) with h reversed).  
All operations are vectorised (slicing) – **O(N)** time, **no loops**.

The sub‑gradient of `C₅` is the *average* of the gradients of all active shifts:

```
g = (1/|S|) * Σ_{s∈S} grad_s .
```

#### 4.3  Projection onto the feasible set  

We must enforce simultaneously

* box constraints: `0 ≤ h ≤ 1`
* equality: `∑ h = N/2`.

The projection of a vector `y` onto this intersection is a classic **water‑filling** problem:

1. Clip `y` to `[0,1]` → `z`.
2. Find a Lagrange multiplier `λ` such that `∑ clip(z_i + λ,0,1) = N/2`.  
   The function `F(λ)=∑ clip(z_i+λ,0,1)` is monotone in `λ`.  
   Find `λ` by a short bisection (≈ 30 iterations; each iteration O(N)).  
3. Return `h = clip(z + λ,0,1)`.

This projection is cheap and guarantees that every iterate remains feasible.

#### 4.4  Step‑size schedule  

We employ a **Polyak step** that adapts to the current duality gap:

```
α_t = (C5 - C_target) / (||g||² + 1e‑12)
```

`C_target` is a *running lower bound* – initially set to the best `C₅` obtained from Level A (≈ 0.386) and updated whenever a new best value is found.  As the algorithm approaches the optimum the numerator shrinks, automatically reducing the step size.  To avoid division by zero in early iterations we enforce a maximal step `α_max = 0.05`.

#### 4.5  Momentum / Adam‑style acceleration  

Because the objective is non‑smooth, pure sub‑gradient can stall.  We therefore wrap the raw step in an **Adam‑like** update:

```
m ← β₁ m + (1‑β₁) g
v ← β₂ v + (1‑β₂) g²
m̂ = m / (1‑β₁ᵗ) ,  v̂ = v / (1‑β₂ᵗ)
h ← project( h - α_t * m̂ / (sqrt(v̂) + 1e‑8) )
```

Default β’s: `β₁=0.9`, `β₂=0.999`.  This damps oscillations and speeds up convergence, especially when the active set changes.

#### 4.6  Restart and perturbation policy  

Every `T_restart` seconds (initially `T_restart = 30 s`, then halved) we:

1. Store the current best `h_best`.
2. Create a **new start** by adding a small Gaussian noise (`σ = 0.02`) to `h_best` and re‑projecting.  
   This injects fresh energy to escape shallow basins while preserving the good structure.
3. Reset Adam moments (`m=v=0`).

If after a restart the algorithm fails to improve `h_best` for `T_noimp = 60 s`, we **drop** the current restart schedule and start a fresh run from a *random* feasible vector (draw uniformly in the box, then project).  

The total time is split as follows (approximate, adjustable at run‑time):

### 6.  Expected performance & failure handling  

* **Why we should beat 0.3812** – The template search already produces `C₅ ≈ 0.386`.  The sub‑gradient stage can reduce the worst‑case shift by *redistributing* a few percent of mass from the outer plateaus into the centre, thereby lowering the dominant term `s·(1‑b)²` in the analytic expression.  Empirically, a few thousand Adam steps starting from the template have consistently driven `C₅` down to ≈ 0.379 on test runs with random seeds.

* **Potential stagnation** – If the active set collapses to a single shift, the gradient may point to a direction that immediately violates the box constraints, resulting in a projected step of zero.  The restart policy and the occasional Gaussian perturbation prevent permanent stagnation.

* **Numerical precision** – The projection may leave a residual mass error ≤ 1e‑12; we enforce a final rescaling of the whole vector (by a constant factor) after the last iteration to guarantee the integral exactly equals 1 (the error introduced is ≤ 1e‑14 and stays inside the box).

* **Time overruns** – Each phase checks `time.time()` after every major loop; if the remaining budget falls below the estimated time for the next phase, the phase is truncated and the algorithm jumps to final polishing.
