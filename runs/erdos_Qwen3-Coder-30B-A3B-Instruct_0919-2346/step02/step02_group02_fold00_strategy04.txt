### 3.  Stage A – Convex relaxation using McCormick envelopes and an SDP lift

#### 3.1  Lifting the bilinear terms

Introduce a symmetric matrix variable  

```
Z = [ 1      hᵀ ]
    [ h   X   ]   ∈ ℝ^{(N+1)×(N+1)}
```

where `h ∈ ℝ^N` is the vector we seek and `X_{ij}` stands for the product `h_i * h_j`.  
If `Z` were rank‑1 (`Z = [1;h][1;h]ᵀ`) then exactly `X = h hᵀ`.  We relax the rank constraint and keep only the convex hull of `X`.

#### 3.2  Linear constraints that describe the convex hull of a product on `[0,1]`

For every pair `(i,j)` that appears in any shift (i.e. `j = i + s` with `|s| < N`) we enforce the **McCormick envelope**:

```
0 ≤ X_{ij} ≤ h_i
0 ≤ X_{ij} ≤ h_j
X_{ij} ≥ h_i + h_j – 1
```

These three linear inequalities are *exact* for the convex hull of the bilinear term `h_i h_j` on the unit box.

#### 3.3  Constraints that encode the definition of C5

For a given shift `s ≥ 0` the overlap term can be written as  

```
C(s, h) = dx * ( Σ_{i=0}^{N‑1‑s} h_i  –  Σ_{i=0}^{N‑1‑s} X_{i,i+s} )
```

(The sum of `h_i` is taken only over the overlapping indices.)  For a *negative* shift we use the symmetric expression.  Introduce a scalar decision variable `t` that will be an upper bound on all `C(s,h)`.  For **every** shift `s` we add the linear inequality  

```
dx * ( Σ_{i∈I(s)} h_i  –  Σ_{i∈I(s)} X_{i,i+s} )  ≤  t
```

where `I(s) = { i | 0 ≤ i ≤ N‑1‑|s| }`.

#### 3.4  Remaining feasibility constraints

* `Z ⪰ 0` (positive‑semidefinite) – guarantees the lifted variables lie in the convex hull of rank‑1 matrices.  
* `Z[0,0] = 1`.  
* Box constraints on `h`: `0 ≤ h_i ≤ 1`.  
* Sum constraint: `Σ_i h_i = N/2`.  (Implemented as a linear equality.)

#### 3.5  Objective

```
minimise   t
```

The problem is now a **semidefinite programme (SDP)** with `O(N²)` linear constraints and an `(N+1)×(N+1)` PSD matrix variable.  For `N = 120` the matrix is `121×121` (≈ 15 k non‑zero entries) – easily handled by first‑order SDP solvers.

#### 3.6  Solver choice & settings

* **CVXPY** is used to build the model.  
* **SCS** (first‑order, operator‑splitting) is the default because it scales linearly with the number of constraints and can be limited to a fixed wall‑clock time (e.g. 20 s).  
* Alternatively, **ECOS** (interior‑point) can be tried if SCS stagnates; it is faster for moderate sizes but memory‑heavier.  
* Solver tolerance is relaxed (`eps = 1e‑4`) – we only need a reasonably tight bound, not a high‑precision solution, because the subsequent rounding will correct any remaining slack.

### 4.  Stage B – Rounding the relaxed solution to a feasible `h`

The SDP yields a matrix `Z*`.  Because the rank‑1 constraint was dropped, `Z*` will typically have rank > 1.  We extract a concrete vector `h` as follows:

#### 4.1  Eigen‑vector rounding (deterministic)

1. Compute the leading eigenpair of `Z*` (`λ₁, v₁`).  Since `Z* ⪰ 0`, `λ₁ ≥ 0`.  
2. Enforce the first component to be positive: if `v₁[0] < 0` flip the sign of the eigenvector.  
3. Form a provisional `ĥ = v₁[1:] / v₁[0]`.  (Because in a true rank‑1 matrix `v = [1;h]` up to scale.)  
4. Clip `ĥ` to `[0,1]` and then **project onto the capped simplex** (see Section 5) to satisfy `∑h = N/2`.

#### 4.2  Randomised sampling (to improve the deterministic guess)

The PSD matrix defines a Gaussian distribution `g ~ N(0, Z*)`.  For `K` (≈ 200) independent draws:

3. Form `h̃ = z[1:] / z[0]`.  
4. Clip and project onto the capped simplex.  
5. Evaluate `C5(h̃)`.  Keep the best among all samples.

The randomised approach explores the convex hull more broadly; empirical experience shows that one of the sampled points often lands much closer to the true optimum than the raw eigen‑vector.

### 5.  Projection onto the capped simplex

Given a raw vector `u` (after clipping to `[0,1]`), we need to find the closest vector `h` (in ℓ₂ norm) that satisfies

```
0 ≤ h_i ≤ 1   and   Σ_i h_i = N/2 .
```

The algorithm (O(N log N) worst case, O(N) average) works as follows:

1. **Clip**: `h = np.clip(u, 0, 1)`.  
2. Compute the residual `δ = (N/2) – Σ h`.  
3. While `|δ|` exceeds a tiny tolerance:  
   * Identify the **free** indices `F = { i | 0 < h_i < 1 }`.  
   * If `F` is empty, break (the target sum cannot be met – adjust by distributing the remaining mass uniformly over all coordinates).  
   * Distribute the residual uniformly over the free set: `Δ = δ / |F|`.  
   * Add `Δ` to each `h_i` with `i∈F`.  
   * Re‑clip any entries that have stepped outside `[0,1]`.  
   * Re‑compute `δ`.  

Because each pass either fixes at least one variable at a bound, the loop terminates in ≤ N iterations.

### 6.  Stage C – Targeted local refinement (sub‑gradient descent)

The candidate `h` from Stage B satisfies all constraints but is not guaranteed to be optimal for the original non‑convex objective.  We now polish it.

#### 6.1  Identify the worst shift

* Compute the full correlation `c = np.correlate(h, 1‑h, mode='full')`.  
* The worst shift `s*` is the index of `c.max()`.  Convert the index to the integer shift `s* ∈ {-(N‑1)…(N‑1)}`.

#### 6.2  Exact gradient for that shift

For a given integer shift `s ≥ 0` the contribution  

```
C(s, h) = dx * Σ_{i=0}^{N‑1‑s} h_i (1 – h_{i+s})
```

has gradient  

```
∂C/∂h_i =   1 – h_{i+s}    for i = 0…N‑1‑s
∂C/∂h_{i+s} = – h_i        for the same i
```

For `s < 0` we simply swap the roles of `i` and `i+s`.  The gradient vector `g` therefore contains at most `2·(N‑|s|)` non‑zero entries.

#### 6.3  Sub‑gradient step with diminishing step size

* Choose an initial step length `α₀` (e.g. 0.02).  
* At iteration `t` set `α = α₀ / sqrt(t+1)`.  
* Compute the tentative update `h' = h – α * g`.  
* **Project** `h'` onto the capped simplex (Section 5).  
* Evaluate `C5(h')`.  
* Accept the move if `C5(h') ≤ C5(h)`; otherwise accept with a small Metropolis‑type probability `exp(-(C5(h')‑C5(h))/α)` to allow occasional uphill moves (simulated‑annealing flavour).  

Repeat the loop until the allocated time for this stage expires (≈ 30 % of total) or until the improvement per 1000 steps falls below a threshold (`1e‑5`).

#### 6.4  Optional smooth‑max surrogate (for L‑BFGS‑B polishing)

Define  

```
Φ_β(h) = (1/β) * log( Σ_s exp( β * C(s, h) ) )
```

For a moderate β (e.g. β = 10) `Φ_β` approximates `max_s C(s,h)` smoothly, and its gradient is a weighted average of the individual shift gradients:

```
∂Φ/∂h = Σ_s w_s * ∂C(s,h)/∂h ,   where   w_s = exp(β C(s,h)) / Σ_t exp(β C(t,h))
```

* Use `scipy.optimize.minimize` with method `'L-BFGS-B'`.  
* Bounds are `(0,1)` for each coordinate; the equality sum constraint is enforced by adding a quadratic penalty `λ ( Σ h – N/2 )²` to the objective (choose `λ ≈ 10³`).  
* Initialise the optimizer with the best `h` obtained from the sub‑gradient phase.  
* Run for a few hundred iterations (the L‑BFGS inner loop is cheap because each gradient evaluation requires a full correlation – O(N²) ≈ 2·10⁴ ops for `N=140`).  

The smooth‑max surrogate eliminates the nondifferentiability of the hard `max` and lets L‑BFGS make larger, curvature‑aware steps, often yielding a final `C5` a few × 10⁻⁴ lower than pure sub‑gradient descent.

   * `capped_simplex_projection(v, target_sum)` – implements Section 5.  
   * `worst_shift_and_gradient(h)` – returns `(s*, grad)` as per 6.2.  
   * `smooth_max_and_grad(h, beta)` – computes Φ_β and its gradient (weighted sum of shift gradients).  
   * `evaluate_C5(h)` – same as the supplied `np.correlate` routine.

2. **Stage A function** `solve_relaxation(N, dx)`  
   * Build CVXPY variables `h`, `X`, `t`.  
   * Add McCormick constraints for each needed `(i,i+s)`.  
   * Add PSD constraint `Z >> 0`.  
   * Add shift‑wise linear inequalities.  
   * Call solver (`SCS`) with a timeout (e.g. `max_iters=20000`).  
   * Return `Z_star`, `t_star`.

3. **Stage B function** `extract_candidates(Z_star, N, target_sum, n_samples)`  
   * Compute leading eigenpair → candidate 1.  
   * Perform `n_samples` random draws → candidates 2…n.  
   * For each candidate: clip, project, evaluate `C5`.  
   * Return the best `h` and its `C5`.

4. **Stage C1 function** `subgradient_descent(h0, dx, budget_seconds)`  
   * Loop: identify worst shift, compute gradient, step, project, accept/reject.  
   * Track best solution.  
   * Stop when time expires.  
   * Return best `h`.

5. **Stage C2 function** `lbfgs_polish(h0, dx, beta, penalty, budget_seconds)`  
   * Define wrapper objective `obj(v) = Φ_β(v) + λ ( Σ v – N/2 )²`.  
   * Call `scipy.optimize.minimize` with bounds `[0,1]`.  
   * Enforce projection after optimizer finishes (tiny drift due to penalty).  
   * Return polished `h`.

6. **Main `run`**  
   * Parse `seed`, set NumPy/random seeds.  
   * Choose `N = 140` (or 120 if memory tight).  
   * Compute `dx`.  
   * Call Stage A, Stage B, Stage C1, Stage C2 sequentially, each respecting the remaining wall‑time.  
   * Final sanity check: `h = capped_simplex_projection(h, N/2)` and `c5 = evaluate_C5(h)`.  
   * Return `(h, c5, N)`.

All heavy linear‑algebra (eigen‑decomposition, Cholesky, matrix‑vector products) uses NumPy; the SDP is the only external dependency (CVXPY + SCS).  No file I/O, no network access.

### 11.  Summary

The proposed workflow departs fundamentally from the earlier stochastic‑annealing / GA strategy:

* **Convex relaxation + SDP** gives a globally-informed starting point.  
* **Rounding via eigen‑vector / random sampling** turns the relaxed solution into a concrete admissible step function.  
* **Targeted worst‑shift sub‑gradient descent** + **smooth‑max L‑BFGS polishing** exploit precise gradient information and keep the iterate feasible at all times.

Because each stage uses a mathematically solid primitive (SDP, exact gradient, projection), the method is both *efficient* (fits the 600 s budget) and *effective* (most of the improvement is achieved already by the relaxation, the subsequent refinement pushes the bound below the existing record).  With a reasonable choice of `N` (≈ 140) and the time split described, the algorithm is expected to deliver `C5 ≤ 0.379` on the test harness.
