**Overview**  
Treat the problem as a *max‑min quadratic* program and attack it with a *convex SDP relaxation* that captures all shift constraints at once.  After solving the SDP we extract a high‑quality candidate (fractional or binary) by spectral/ probabilistic rounding, then polish it with a very cheap local search (swap‑SA or smooth‑max gradient descent).  This pipeline is fundamentally different from the previous hill‑climbing or MILP‑cutting‑plane approaches: it works in the lifted matrix space, uses a global convex bound, and only afterwards resorts to combinatorial refinement.

### 1. Mathematical reformulation

For a discrete grid of `N` points (`dx = 2/N`) define a vector `h∈[0,1]^N` with  
`∑_i h_i dx = 1`  ⇔ `∑_i h_i = N/2`.

For an integer lag `d (0≤d<N)` let  

```
A_d[i,j] = 0.5   if |i‑j| = d and both indices are inside [0,N‑1]
          = 0   otherwise
```

(the factor 0.5 makes `trace(A_d X)` equal the sum `∑_i h_i h_{i+d}` once we set `X = h hᵀ`).

Define the lifted matrix variable `X = h hᵀ`.  Then

```
O(d) = dx·∑_i h_i(1‑h_{i+d}) = 1 – dx·∑_i h_i h_{i+d}
     = 1 – dx·trace(A_d X)
```

Hence  

```
C5 = max_d O(d) = 1 – dx·min_d trace(A_d X) .
```

Introduce a scalar `τ` to represent the *minimum* autocorrelation:

```
τ ≤ trace(A_d X)    for every d .
```

Minimising `C5` ⇔ **maximising** `τ`.  The optimisation problem is  

```
max τ
s.t.    trace(A_d X) ≥ τ          ∀ d
        0 ≤ h_i ≤ 1               (will be enforced via X)
        ∑_i h_i = N/2
        X ⪰ 0                     (positive semidefinite)
        diag(X) ≤ 1               (since h_i ≤ 1 ⇒ X_ii = h_i² ≤ 1)
        trace(X) ≤ N/2            (∑ h_i² ≤ ∑ h_i = N/2)
```

The rank‑1 constraint `X = h hᵀ` is **dropped**, yielding a *convex semidefinite program* (SDP).  Solving the SDP supplies a global upper bound on `τ` and a matrix `X` from which a feasible `h` can be derived.

### 2. SDP construction (CVXPY)

*Variables*  
- `X ∈ ℝ^{N×N}` symmetric, PSD.  
- `τ ∈ ℝ` (scalar).

*Constraints*  

1. **Shift constraints** – for every lag `d` (or for the first `⌈N/2⌉` lags, exploiting symmetry) add  
   `cp.trace(A_d @ X) >= τ`.

2. **Box on diagonal** – `cp.diag(X) <= 1`.

3. **Mass constraint** – `cp.trace(X) <= N/2`.  (Because `trace(X)=∑ h_i²` and `∑ h_i = N/2`.)

4. **Positive‑semidefiniteness** – `X >> 0` (PSD).

5. **Optional symmetry fixing** – enforce `X` to be symmetric; CVXPY does it automatically.

*Objective* – maximise `τ`.  In CVXPY we write `cp.Maximize(τ)`.

*Solver* – use a first‑order SDP solver that works inside the time budget, e.g. **SCS** (or **ECOS** if memory is tight).  Set a modest accuracy (`eps = 1e‑5`) and a maximum solve time of a few dozen seconds; the problem size (`N≈140`) yields a matrix of ≈ 20 k variables, easily handled by SCS.
