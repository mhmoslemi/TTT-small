The goal is to construct a step function  h  on \([0,2]\) (discretised to \(N\) points, default \(N=140\)) with  

\[

that minimises  

\[

\]

Because \(O_k=1-\)autocorrelation, *minimising* the worst overlap is equivalent to *maximising* the smallest autocorrelation:

\[
\min C_5 \;\Longleftrightarrow\;

\]

The integral is a bilinear form in the vector \(h\).  
The strategy below treats the bilinear terms **exactly** by binary linearisation, turning the problem into a **mixed‑integer linear program (MILP)**. ### 1. Binary formulation (indicator step function)

We restrict ourselves first to **binary step functions**:
\[
h_i\in\{0,1\},\qquad \sum_i h_i = N/2 .
\]
In the continuous problem any admissible \(h\) can be approximated arbitrarily well by a binary one (the optimizer of a max‑min autocorrelation problem is known to lie at an extreme point of the feasible polytope).  Therefore a high‑quality binary construction already yields an excellent upper bound for the original problem; allowing fractional values afterwards can only improve it.

For a given shift \(k\in\{0,1,\dots ,N-1\}\) (negative shifts are symmetric) the discrete autocorrelation is

\[
Q_k(h)=\sum_{i=0}^{N-1-k} h_i\,h_{i+k}\;dx .
\]

The overlap for that shift is

\[
O_k(h)=1-Q_k(h)=1-dx\!\sum_{i=0}^{N-1-k}h_i\,h_{i+k}.
\]

Introduce auxiliary binary variables  

\[
w_{i,k}\;\;=\;h_i\,h_{i+k},\qquad
0\le i\le N-1-k,\; 1\le k\le N-1 .
\]

Because all variables are binary we can enforce the product exactly with the classic McCormick linearisation (which becomes exact for binary variables):

\[
\begin{aligned}
w_{i,k} &\le h_i,\\
w_{i,k} &\le h_{i+k},\\
w_{i,k} &\ge h_i+h_{i+k}-1,\\
w_{i,k} &\ge 0 .
\end{aligned}
\]

All constraints are linear.  The shift‑wise overlap constraints become

\[
O_k = 1-dx\sum_{i} w_{i,k}\;\le\;t,
\qquad k=0,\dots ,N-1 .
\]

(For \(k=0\) the constraint is automatically satisfied because \(w_{i,0}=h_i\) and \(\sum_i h_i = N/2\) gives \(O_0=0\).)

**Symmetry‑breaking** – translation of the set does not change the objective, so we fix the first point to be “inside” the set:

\[
h_0 = 1 .
\]

This reduces the search space and eliminates redundant symmetric solutions.

**Variable count**  
* Binary variables*: \(h_i\) ( \(N\) ) + \(w_{i,k}\) ( \(\frac{N(N-1)}{2}\) ) ≈ 9 800 for \(N=140\).  
* Continuous variable*: the bound \(t\).  

All constraints are linear; the model fits comfortably into the memory limits of CBC/GLPK/SCIP.

### 3. Continuous refinement (optional but powerful)

The binary solution \(h^{(0)}\) is feasible for the original continuous problem, but may not be optimal because we have forced values to be exactly 0 or 1.  We therefore perform a short **local‑search phase** that allows each entry to become fractional while preserving the constraints:

1. **Projection routine** – given a vector \(y\in\mathbb{R}^N\), compute the Euclidean projection onto the box‑plus‑mass set:
   * Clip to \([0,1]\).  
   * Adjust by a scalar \(\lambda\) so that \(\sum_i \max(0,\min(1,y_i-\lambda)) = N/2\).  
   This is a standard “simplex with bounds” projection that can be solved by a fast bisection on \(\lambda\) (≈ 30 iterations).  

2. **Gradient of the true objective** – for a continuous vector \(h\) the gradient of a single overlap term is
   \[
   \frac{\partial O_k}{\partial h_i}= (1-h_{i+k}) - h_{i-k},
   \]
   (indices out of range give 0).  The gradient of the **max** can be taken as the gradient of the *worst* shift, i.e. the shift \(k^\star\) attaining the current \(C_5\).  This yields a sub‑gradient.

3. **Projected sub‑gradient step**  
   \[
   h^{(new)} = \Pi_{\mathcal{F}}\bigl( h^{(old)} - \alpha\,\nabla O_{k^\star}\bigr) ,
   \]
   where \(\Pi_{\mathcal{F}}\) is the projection defined above, and \(\alpha\) is a diminishing step size (e.g. \(\alpha=\alpha_0/(1+t)\) with \(\alpha_0=0.1\)).  

4. **Acceptance rule** – if the new vector yields a *strictly smaller* true \(C_5\) (computed with np.correlate), accept it; otherwise keep the old one.  Perform at most a few thousand iterations or stop when improvement falls below \(10^{-7}\).

Because the starting point already respects the mass constraint, the projection is cheap (O(N log N)).  Empirically a few hundred sub‑gradient steps improve the binary bound by 0.0005–0.001, enough to push the final bound below the target 0.3807.
