Actually, G[i] depends on all h values (through the (1-h[...]) and h[...] terms). So after changing h[i] and h[j], all rows of G are affected. Recomputing G is O(n * m) = O(n * 2n) = O(n²) per change. With 2415 changes per sweep, that's O(n² * n²) = O(n⁴) = O(70⁴) ≈ 24M per sweep. That's too slow.

Alternative: don't maintain G incrementally. Instead, for each pair, compute gd on the fly. But that's also O(n) per pair (computing G[i] and G[j]).

Actually, G[i] is a vector of length m = 2n-1 = 139. Computing it requires O(m) operations. For 2415 pairs, that's 2415 * 2 * 139 ≈ 670K operations per sweep. That's fast.

But the issue is: after I update h[i] and h[j], the G values for all other pairs are stale. If I use stale G values, the sweep might not be monotone (i.e., it might increase the objective for some pairs).

import time

def _corr(h):
    return np.correlate(h, 1.0 - h, mode='full')

def _c5(h, dx):
    return float(np.max(_corr(h)) * dx)

def _repair(h, n):
    h = np.clip(h, 0.0, 1.0).copy()
    target = n / 2.0
    s = h.sum()
    if s < 1e-12:
        return np.full(n, 0.5)
    h *= (target / s)
    h = np.clip(h, 0.0, 1.0)
    diff = target - h.sum()
    if abs(diff) > 1e-12:
        order = np.argsort(1.0 - h) if diff > 0 else np.argsort(h)
        for idx in order:
            if diff > 0:
                add = min(diff, 1.0 - h[idx])
                h[idx] += add
                diff -= add
            else:
                sub = min(-diff, h[idx])
                h[idx] -= sub
                diff += sub
            if abs(diff) < 1e-12:
                break
    return h

def _g_row(h, i, n):
    """Compute row i of the gradient matrix."""
    m = 2 * n - 1
    t = np.arange(m) - (n - 1)
    row = np.zeros(m)
    idx1 = i + t
    m1 = (idx1 >= 0) & (idx1 < n)
    row[m1] += (1.0 - h[idx1[m1]])
    idx2 = i - t
    m2 = (idx2 >= 0) & (idx2 < n)
    row[m2] -= h[idx2[m2]]
    return row

def _optimal_d(a, b, lo, hi):
    """Minimize max(a + b*d) for d in [lo, hi] via bisection on subgradient."""
    if hi - lo < 1e-14:
        return (lo + hi) * 0.5
    for _ in range(40):
        mid = (lo + hi) * 0.5
        vals = a + b * mid
        k = int(np.argmax(vals))
        if b[k] > 1e-13:
            hi = mid
        elif b[k] < -1e-13:
            lo = mid
        else:
            break
    return (lo + hi) * 0.5

                h[j] = hj - d_opt
                corr = corr + d_opt * gd
                improved = True
    return h, improved
