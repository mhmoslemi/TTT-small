Let me also think about the subgradient approach:
- Compute corr = correlate(h, 1-h)
- Find all p where corr[p] is within epsilon of max(corr)
- The "gradient direction" to reduce the max is to decrease these specific correlation values
- For corr[p] = sum_i h[i]*(1-h[i+k_p]), to decrease it:
  - Decrease h[i] for i where h[i+k_p] is large (reduces h[i]*(1-h[i+k_p])... wait that increases it if h[i+k_p] is small)
  
  Actually: d(corr[p])/d(h[j]) = (1-h[j+k_p]) - h[j-k_p]
  
  If h[j+k_p] is close to 1, then (1-h[j+k_p]) is small, and -h[j-k_p] is negative (if h[j-k_p] > 0). So the gradient is negative, meaning increasing h[j] would decrease corr[p].
  
  If h[j-k_p] is close to 1, then -h[j-k_p] is very negative, so the gradient is negative.
  
  To decrease corr[p], we should move h[j] in the direction -grad[j] (negative gradient direction).

  But we also need to keep the constraint sum(h) = n/2. So we project onto the constraint.

Let me implement a projected subgradient method:
1. Compute smooth max value and its gradient
2. Take step: h_new = h - lr * grad
3. Project onto {0 <= h <= 1, sum(h) = n/2}
4. Repeat

The projection onto {sum(h) = n/2, 0 <= h <= 1} is a water-filling problem.

For the projection:
- We want to find h' that minimizes ||h' - h||^2 subject to sum(h') = n/2 and 0 <= h' <= 1
- This is a quadratic program with box constraints and one equality constraint
- The solution is: h'[i] = clip(h[i] - lambda, 0, 1) for some lambda
- We find lambda by bisection so that sum(h') = n/2

This is clean and efficient. Let me code this up.

```python
def _project(h, n):
    target = n / 2.0
    # Find lambda such that sum(clip(h - lambda, 0, 1)) = target
    lo, hi = h.min() - 2.0, h.max() + 2.0
    for _ in range(100):
        mid = (lo + hi) / 2
        h_proj = np.clip(h - mid, 0, 1)
        s = h_proj.sum()
        if s > target:
            lo = mid
        else:
            hi = mid
    h_proj = np.clip(h - (lo+hi)/2, 0, 1)
    # Fine adjustment
    diff = target - h_proj.sum()
    if abs(diff) > 1e-10:
        if diff > 0:
            order = np.argsort(1.0 - h_proj)
        else:
            order = np.argsort(h_proj)
        for idx in order:
            if diff > 0:
                add = min(diff, 1.0 - h_proj[idx])
                h_proj[idx] += add
                diff -= add
            else:
                sub = min(-diff, h_proj[idx])
                h_proj[idx] -= sub
                diff += sub
            if abs(diff) < 1e-10:
                break
    return h_proj
```

```python
def _grad_corr(h, alpha):
    n = len(h)
    corr = np.correlate(h, 1.0 - h, mode='full')
    m = np.max(corr)
    clipped = np.clip(alpha * (corr - m), -500, 500)
    ew = np.exp(clipped)
    w = ew / ew.sum()
    val = m + np.log(ew.sum()) / alpha
    
    # grad[j] = sum_p w[p] * [(1-h[j+k_p]) * 1(0<=j+k_p<n) - h[j-k_p] * 1(0<=j-k_p<n)]
    grad = np.zeros(n)
    for p in range(2*n - 1):
        k = p - (n - 1)
        wp = w[p]
        if wp < 1e-10:
            continue
        # Part 1: (1-h[j+k]) for j where 0 <= j+k < n
        lo = max(0, -k)
        hi = min(n, n - k)
        if lo < hi:
            grad[lo:hi] += wp * (1.0 - h[lo+k:hi+k])

        lo = max(0, k)
        hi = min(n, n + k)
        if lo < hi:
            grad[lo:hi] -= wp * h[lo-k:hi-k]
    return val, grad
```

```python
def _linearize_solve(h0, dx, n):
    # Linearize corr_k around h0, solve LP: min max_k (a_k + b_k · h)
    corr0 = _corr(h0)
    # a_k = corr_k(h0) - ∇corr_k(h0)·h0 ... no
    # corr_k(h) ≈ corr_k(h0) + ∇corr_k(h0)·(h - h0)
    # = (corr_k(h0) - ∇corr_k(h0)·h0) + ∇corr_k(h0)·h
    # So a_k = corr_k(h0) - ∇corr_k(h0)·h0, b_k = ∇corr_k(h0)
    
    # But computing ∇corr_k for each k is O(n) per k, O(n^2) total. Fine for n=70.
    
    # Actually, this is equivalent to:
    # corr_k(h) = sum_i h[i]*(1-h[i+k]) 
    # Linearized: sum_i h0[i]*(1-h0[i+k]) + sum_i [(1-h0[i+k])*(h[i]-h0[i]) + h0[i]*(0-(h[i+k]-h0[i+k]))]
    # = corr_k(h0) + sum_i (1-h0[i+k])*h[i] - sum_i h0[i]*h[i+k]
    #   - sum_i (1-h0[i+k])*h0[i] + sum_i h0[i]*h0[i+k]
    # = corr_k(h0) - corr_k(h0) + ... 
    # = sum_i (1-h0[i+k])*h[i] - sum_i h0[i]*h[i+k]
    
    # So the linearized corr_k(h) = sum_i (1-h0[i+k])*h[i] - sum_i h0[i]*h[i+k]
    # = sum_i [(1-h0[i+k]) - h0[i-k]] * h[i]  (reindexing the second sum)
    
    # This is a dot product: g_k · h where g_k[i] = (1-h0[i+k]) - h0[i-k]
    
    # LP: min t
    #     s.t. g_k · h <= t for all k
    #          0 <= h <= 1
    #          sum(h) = n/2
    
    # This has 70 + 1 = 71 variables and 139 + 140 + 1 = 280 constraints.
    # Very fast for any LP solver.
```

Wait, but this linearization gives a lower bound on the true corr_k (since corr_k is not convex, the linearization can go either way). Let me check:

corr_k(h) = sum_i h[i]*(1-h[i+k])
At h0: = sum_i h0[i]*(1-h0[i+k])
Linear approximation: sum_i h0[i]*(1-h0[i+k]) + sum_i [(1-h0[i+k])*(h[i]-h0[i]) + h0[i]*(0 - (h[i+k]-h0[i+k]))]
= sum_i h0[i]*(1-h0[i+k]) + sum_i (1-h0[i+k])*h[i] - sum_i (1-h0[i+k])*h0[i] - sum_i h0[i]*h[i+k] + sum_i h0[i]*h0[i+k]
= sum_i (1-h0[i+k])*h[i] - sum_i h0[i]*h[i+k]

So corr_k_lin(h) = sum_i [(1-h0[i+k]) - h0[i-k]] * h[i] (after reindexing)

And the true corr_k(h) - corr_k_lin(h) = sum_i h[i]*(1-h[i+k]) - sum_i [(1-h0[i+k]) - h0[i-k]]*h[i]
= sum_i [h[i] - h[i]*h[i+k] - (1-h0[i+k])*h[i] + h0[i-k]*h[i]]
= sum_i [h[i]*h0[i+k] - h[i]*h[i+k] + h0[i-k]*h[i]]
= sum_i h[i] * [h0[i+k] - h[i+k] + h0[i-k]]

This is not zero in general. So the linearization is not an upper or lower bound.

However, as an iterative method, it can still work: at the solution of the LP, the linearized correlations are all <= t. The true correlations might be higher, but if h hasn't moved far from h0, they should be close.

Let me implement this "iterative linearization" approach:

1. Start with h0
2. Compute g_k[i] = (1-h0[i+k]) - h0[i-k] for each k
3. Solve LP: min t s.t. g_k·h <= t, 0<=h<=1, sum(h)=n/2
4. Set h = solution
5. Check actual C5. If linearized C5 ≈ actual C5, we're close to optimal.
6. Repeat with new h0

For step 3, I can use scipy.optimize.linprog or cvxpy.

Using scipy.optimize.linprog:
- Variables: [h_0, ..., h_69, t] (71 variables)
- Objective: minimize t (c = [0,...,0,1])
- Inequality: g_k · h - t <= 0 for each k (139 constraints)
- Bounds: 0 <= h_i <= 1, t >= 0
- Equality: sum(h) = n/2

```python
from scipy.optimize import linprog

def _linear_step(h0, dx, n, max_iter=50):
    target = n / 2.0
    best_h = h0.copy()
    best_c5 = _c5(h0, dx)
    
    for iter in range(max_iter):
        # Compute linearization coefficients
        corr0 = _corr(h0)
        # g_k[i] = (1-h0[i+k]) - h0[i-k] for valid indices
        # Build constraint matrix A for LP: A @ [h; t] <= b
        # g_k · h - t <= 0
        
        n_vars = n + 1  # h_0..h_{n-1}, t
        A_rows = []
        b_row = []
        for p in range(2*n-1):
            k = p - (n-1)
            g = np.zeros(n)
            for i in range(n):
                ci = 0.0
                if 0 <= i+k < n:
                    ci += (1.0 - h0[i+k])
                if 0 <= i-k < n:
                    ci -= h0[i-k]
                g[i] = ci
            # g · h - t <= 0
            row = np.zeros(n_vars)
            row[:n] = g
            row[n] = -1.0
            A_rows.append(row)
            b_row.append(0.0)
        A = np.array(A_rows)
        b = np.array(b_row)
        
        # Objective: minimize t
        c = np.zeros(n_vars)
        c[n] = 1.0
        
        # Bounds
        bounds = [(0.0, 1.0)] * n + [(0.0, None)]
        
        # Equality: sum(h) = target
        A_eq = np.zeros((1, n_vars))
        A_eq[0, :n] = 1.0
        b_eq = np.array([target])
        
        res = linprog(c, A_ub=A, b_ub=b, A_eq=A_eq, b_eq=b_eq, bounds=bounds, method='highs')
        
        if res.status != 0:
            break
        
        h_new = res.x[:n]
        t_new = res.x[n]
        
        # Check actual C5
        c5_new = _c5(h_new, dx)
        
        if c5_new < best_c5 - 1e-12:
            best_c5 = c5_new
            best_h = h_new.copy()
            h0 = h_new.copy()
        else:
            # Try a step: h = h0 + alpha * (h_new - h0)
            found = False
            for alpha in [0.5, 0.25, 0.1]:
                h_try = h0 + alpha * (h_new - h0)
                h_try = _project(h_try, n)
                c5_try = _c5(h_try, dx)
                if c5_try < best_c5 - 1e-12:
                    best_c5 = c5_try
                    best_h = h_try.copy()
                    h0 = h_try.copy()
                    found = True
                    break
            if not found:
                break
    
    return best_h, best_c5
```

```python
import numpy as np
from scipy.optimize import linprog
import time


def _corr(h):
    return np.correlate(h, 1.0 - h, mode='full')


def _c5(h, dx):
    return np.max(_corr(h)) * dx


def _smooth_max(val, alpha):
    m = np.max(val)
    s = np.clip(alpha * (val - m), -500, 500)
    return m + np.log(np.sum(np.exp(s))) / alpha


def _grad_smooth(h, alpha):
    n = len(h)
    corr = _corr(h)
    m = np.max(corr)
    clipped = np.clip(alpha * (corr - m), -500, 500)
    ew = np.exp(clipped)
    w = ew / ew.sum()
    val = m + np.log(ew.sum()) / alpha
    grad = np.zeros(n)
    for p in range(2 * n - 1):
        k = p - (n - 1)
        wp = w[p]
        if wp < 1e-10:
            continue
        lo1 = max(0, -k)
        hi1 = min(n, n - k)
        if lo1 < hi1:
            grad[lo1:hi1] += wp * (1.0 - h[lo1 + k:hi1 + k])
        lo2 = max(0, k)
        hi2 = min(n, n + k)
        if lo2 < hi2:
            grad[lo2:hi2] -= wp * h[lo2 - k:hi2 - k]
    return val, grad


def _project(h, n):
    target = n / 2.0
    lo_b = h.min() - 2.0
    hi_b = h.max() + 2.0
    for _ in range(60):
        mid = (lo_b + hi_b) / 2.0
        s = np.clip(h - mid, 0.0, 1.0).sum()
        if s > target:
            lo_b = mid
        else:
            hi_b = mid
    lam = (lo_b + hi_b) / 2.0
    hp = np.clip(h - lam, 0.0, 1.0)
    diff = target - hp.sum()
    if abs(diff) > 1e-10:
        if diff > 0:
            order = np.argsort(1.0 - hp)
        else:
            order = np.argsort(hp)
        for idx in order:
            if diff > 0:
                a = min(diff, 1.0 - hp[idx])
                hp[idx] += a
                diff -= a
            else:
                a = min(-diff, hp[idx])
                hp[idx] -= a
                diff += a
            if abs(diff) < 1e-10:
                break
    return hp


def _linear_step(h0, dx, n, max_iter, t_end):
    target = n / 2.0
    best_h = h0.copy()
    best_c5 = _c5(h0, dx)
    n_vars = n + 1
    for _it in range(max_iter):
        if time.time() > t_end:
            break
        h0n = h0.copy()
        A_rows = []
        for p in range(2 * n - 1):
            k = p - (n - 1)
            g = np.zeros(n)
            for i in range(n):
                ci = 0.0
                if 0 <= i + k < n:
                    ci += (1.0 - h0n[i + k])
                if 0 <= i - k < n:
                    ci -= h0n[i - k]
                g[i] = ci
            row = np.zeros(n_vars)
            row[:n] = g
            row[n] = -1.0
            A_rows.append(row)
        A = np.array(A_rows)
        b = np.zeros(2 * n - 1)
        c = np.zeros(n_vars)
        c[n] = 1.0
        bounds = [(0.0, 1.0)] * n + [(0.0, None)]
        A_eq = np.zeros((1, n_vars))
        A_eq[0, :n] = 1.0
        b_eq = np.array([target])
        try:
            res = linprog(c, A_ub=A, b_ub=b, A_eq=A_eq, b_eq=b_eq,
                          bounds=bounds, method='highs',
                          options={'maxiter': 5000})
        except Exception:
            break
        if res.status != 0:
            break
        h_new = _project(res.x[:n], n)
        c5_new = _c5(h_new, dx)
        if c5_new < best_c5 - 1e-13:
            best_c5 = c5_new
            best_h = h_new.copy()
            h0 = h_new.copy()
        else:
            moved = False
            for frac in [0.5, 0.3, 0.1]:
                h_try = _project(h0 + frac * (h_new - h0), n)
                c5_try = _c5(h_try, dx)
                if c5_try < best_c5 - 1e-13:
                    best_c5 = c5_try
                    best_h = h_try.copy()
                    h0 = h_try.copy()
                    moved = True
                    break
            if not moved:
                break
    return best_h, best_c5


def _coord_sweep(h, dx, n, max_sweeps, deltas, t_end):
    best = _c5(h, dx)
    for _sw in range(max_sweeps):
        if time.time() > t_end:
            break
        improved = False
        for i in range(n):
            for j in range(n):
                if i == j:
                    continue
                hi, hj = h[i], h[j]
                for d in deltas:
                    ni = hi + d
                    nj = hj - d
                    if ni < -1e-9 or ni > 1.0 + 1e-9:
                        continue
                    if nj < -1e-9 or nj > 1.0 + 1e-9:
                        continue
                    h[i] = ni
                    h[j] = nj
                    c = _c5(h, dx)
                    if c < best - 1e-13:
                        best = c
                        improved = True
                    else:
                        h[i] = hi
                        h[j] = hj
        if not improved:
            break
    return h, best


def _subgrad_phase(h, dx, n, alpha, lr0, max_iter, t_end):
    best_h = h.copy()
    best_c5 = _c5(h, dx)
    lr = lr0
    for _it in range(max_iter):
        if time.time() > t_end:
            break
        val, grad = _grad_smooth(h, alpha)
        h = h - lr * grad
        h = _project(h, n)
        c5 = _c5(h, dx)
        if c5 < best_c5 - 1e-12:
            best_c5 = c5
            best_h = h.copy()
        lr *= 0.997
    return best_h, best_c5


def run(seed=42, budget_s=1100, **kwargs):
    t_start = time.time()
    rng = np.random.RandomState(seed)
    n = len(initial_h_values)
    dx = 2.0 / n
    h = _project(np.array(initial_h_values, dtype=float).copy(), n)
    best_h = h.copy()
    best_c5 = _c5(h, dx)

    # Phase 1: LP-based linear iteration
    t1 = t_start + budget_s * 0.25
    h1, c1 = _linear_step(h, dx, n, 300, t1)
    if c1 < best_c5:
        best_c5 = c1
        best_h = h1

    # Phase 2: Coordinate descent (coarse)
    t2 = t_start + budget_s * 0.55
    deltas2 = [0.005, 0.01, 0.02, 0.05, 0.1, -0.005, -0.01, -0.02, -0.05, -0.1]
    h2 = best_h.copy()
    h2, c2 = _coord_sweep(h2, dx, n, 400, deltas2, t2)
    if c2 < best_c5:
        best_c5 = c2
        best_h = h2

    # Phase 3: Subgradient refinement
    t3 = t_start + budget_s * 0.70
    for alpha in [100, 300, 800]:
        if time.time() > t3:
            break
        h3, c3 = _subgrad_phase(best_h, dx, n, alpha, 0.04, 200, t3)
        if c3 < best_c5:
            best_c5 = c3
            best_h = h3

    # Phase 4: More LP iterations
    t4 = t_start + budget_s * 0.85
    h4, c4 = _linear_step(best_h, dx, n, 200, t4)
    if c4 < best_c5:
        best_c5 = c4
        best_h = h4

    # Phase 5: Fine coordinate descent
    t5 = t_start + budget_s * 0.97
    deltas5 = [0.001, 0.002, 0.005, 0.01, -0.001, -0.002, -0.005, -0.01]
    h5 = best_h.copy()
    h5, c5f = _coord_sweep(h5, dx, n, 300, deltas5, t5)
    if c5f < best_c5:
        best_c5 = c5f
        best_h = h5

    # Multi-restart with perturbation (if time remains)
    if time.time() < t_start + budget_s - 5:
        for sigma in [0.05, 0.1, 0.2]:
            if time.time() > t_start + budget_s - 5:
                break
            hp = _project(best_h + sigma * rng.randn(n), n)
            hc, cc = _coord_sweep(hp, dx, n, 100, deltas5, t_start + budget_s - 5)
            if cc < best_c5:
                best_c5 = cc
                best_h = hc

    best_h = _project(best_h, n)
    best_c5 = _c5(best_h, dx)
    return (best_h, best_c5, n)
```
