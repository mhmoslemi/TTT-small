This is a 1D convex optimization: minimize max_m (c[m] + delta * sens[m]).

The subgradient w.r.t. delta is sens[m*] where m* = argmax. So:
- If sens[m*] > 0, moving delta up increases the max → optimal is to the left
- If sens[m*] < 0, moving delta down increases the max → optimal is to the right
- If sens[m*] = 0, we're at a flat region

Binary search on the subgradient sign:

But wait, I also need to maintain the sum constraint. If I change h[i] by delta, I need to change some other h[j] by -delta. This makes the problem 2D instead of 1D.

Simpler approach: Don't enforce the sum constraint during coordinate descent. Just optimize each coordinate independently (minimizing max corr subject to 0 ≤ h[i] ≤ 1), then project back to the sum constraint after each sweep.

The projection: find h' = h - alpha * 1 such that sum(h') = n/2, i.e., alpha = (sum(h) - n/2) / n. Then clip to [0,1] and iterate if needed.

Actually, a better projection: 
1. Compute alpha = (sum(h) - n/2) / n
2. h' = h - alpha
3. Clip to [0,1]
4. The sum is now off. Adjust: distribute the remaining difference among coordinates that weren't clipped.
5. Repeat if necessary (one or two iterations suffice).

This is similar to the repair function but more principled.

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    c = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(c) * dx)

def repair(h, n):
    h = np.clip(h.astype(float).copy(), 0.0, 1.0)
    target = n * 0.5
    for _ in range(10):
        diff = target - h.sum()
        if abs(diff) < 1e-12:
            break
        if diff > 0:
            mask = h < 1.0
        else:
            mask = h > 0.0
        if not mask.any():
            break
        step = diff / mask.sum()
        h[mask] = np.clip(h[mask] + step, 0.0, 1.0)
    # Final fix
    diff = target - h.sum()
    if abs(diff) > 1e-14:
        if diff > 0:
            idx = np.argmin(h)
        else:
            idx = np.argmax(h)
        h[idx] = np.clip(h[idx] + diff, 0.0, 1.0)
    return h

def coord_descent(h, n, max_sweeps=100, tol=1e-10):
    """Exact 1D coordinate descent with binary search on subgradient."""
    h = h.copy()
    c = np.correlate(h, 1.0 - h, mode='full')
    best_val = np.max(c)
    
    for sweep in range(max_sweeps):
        improved = False
        for i in range(n):
            # Sensitivity: how does c[m] change when h[i] changes by 1?
            # c[m] = sum_i h[i]*(1-h[i+m-(n-1)])
            # dc[m]/dh[i] = (1-h[i+m-(n-1)]) - h[i-m+(n-1)]  (when valid)
            # But this is annoying with the full correlation indexing.
            # Simpler: just compute c for h[i]+eps and h[i]-eps to get sensitivity.
            # Or: directly compute c + delta*sens for trial delta.
            
            # Actually, simplest: just evaluate c for a few trial values and 
            # use the structure.
            
            old = h[i]
            # Try golden section search for optimal h[i]
            # f(x) = max(c + (x-old)*sens) where sens = dc/dh[i]
            
            # Compute sensitivity by finite difference (accurate enough)
            eps = 1e-7
            h[i] = old + eps
            c_plus = np.correlate(h, 1.0 - h, mode='full')
            h[i] = old - eps
            c_minus = np.correlate(h, 1.0 - h, mode='full')
            h[i] = old
            sens = (c_plus - c_minus) / (2 * eps)
            
            # Now minimize max(c + delta * sens) for delta in [-old, 1-old]
            lo = -old
            hi = 1.0 - old
            for _ in range(40):
                mid = 0.5 * (lo + hi)
                c_trial = c + mid * sens
                m_star = np.argmax(c_trial)
                if sens[m_star] > 1e-12:
                    hi = mid
                elif sens[m_star] < -1e-12:
                    lo = mid
                else:
                    break
            
            opt_delta = 0.5 * (lo + hi)
            new_val = old + opt_delta
            
            if abs(new_val - old) < 1e-12:
                continue
            
            h[i] = new_val
            c = np.correlate(h, 1.0 - h, mode='full')
            val = np.max(c)
            
            if val < best_val - tol:
                best_val = val
                improved = True
            else:
                h[i] = old
                c = np.correlate(h, 1.0 - h, mode='full')
        
        # Project to sum constraint
        h = repair(h, n)
        c = np.correlate(h, 1.0 - h, mode='full')
        val = np.max(c)
        if val < best_val:
            best_val = val
        
        if not improved:
            break
    
    return h, best_val * (2.0/n)

Valid: 0 ≤ i0 - m + (n-1) ≤ n-1

→ 0 ≤ m - i0 ≤ n-1
→ i0 ≤ m ≤ i0 + n - 1

Contribution to c[m]: h[i0 - m + (n-1)] * (-delta) = -delta * h[i0 - m + (n-1)]

dc[m]/dh[i0] = [1 - h[i0 + m - (n-1)]] * I[(n-1-i0) ≤ m ≤ (n-1+i0)]

where I[condition] is the indicator.

This means for each i0, only O(n) correlation bins are affected. I can compute the sensitivity in O(n) time.
