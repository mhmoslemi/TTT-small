Actually, the most natural parametrization for a step function is: h consists of a union of intervals. The "best" h might be something like h = 1 on a carefully chosen set of measure 1 in [0,2].

For a 0-1 valued function (extreme points of the feasible set), h is the indicator of a set A with measure 1. Then:
O(k) = |A ∩ (A+k)^c| = |A| - |A ∩ (A+k)| = 1 - |A ∩ (A+k)|

So minimizing max_k O(k) is equivalent to maximizing min_k |A ∩ (A+k)|, i.e., making the autocorrelation as uniform as possible.

This is related to the problem of finding sets with minimal maximum autocorrelation, which is a well-studied problem in combinatorics (related to difference sets, etc.).

For a continuous version on [0,2], the best set A of measure 1 would be something like a "Fat Cantor" or carefully interspersed intervals.

Let me think about what structure the optimal solution might have. If A is "equidistributed" in [0,2], then |A ∩ (A+k)| ≈ 1 - |k|/2 for |k| ≤ 2... no, that's for a single interval.

Actually for a single interval A = [0,1], |A ∩ (A+k)| = max(0, 1-|k|) for |k| ≤ 2.
Then O(k) = 1 - max(0, 1-|k|). Max over k: at k=0, O(0) = 0 (since |A∩A|=1). At k→2, O→1. So max O(k) = 1 (at k=±2). That's terrible.

For a better construction, we want A to have low autocorrelation at all shifts. This is the "Golay sequence" / "Barker sequence" problem in continuous form.

One idea: if A is the union of many small intervals evenly spaced, the autocorrelation will be more uniform. For example, if A consists of m intervals each of length 1/m, evenly spaced in [0,2]:
A = ∪_{j=0}^{m-1} [j*2/m, j*2/m + 1/m]

Then |A| = m * 1/m = 1 ✓
|A ∩ (A+k)|: this depends on k. For k = 2l/m (integer multiple of spacing), the intervals align and |A∩(A+k)| = 1 (if k < 2) or 0. For other k, it's more complex.
