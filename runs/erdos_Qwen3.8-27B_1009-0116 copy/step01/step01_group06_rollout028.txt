The smoothed objective (or the hard max) as a function of h[j] is piecewise linear convex. The minimum of max_k (A_k * x + B_k) over x ∈ [0,1] can be found by:
- Evaluating at x=0, x=1, and at the intersection points of pairs of lines.
- Or more simply, for the smoothed version, doing a few Newton/bisection steps.

Actually, for the hard max, the optimal x is where two (or more) constraints are tight. We can find it by:
1. Computing all A_k and B_k
2. The function f(x) = max_k (A_k * x + B_k) is convex piecewise linear
3. Minimum is where the subgradient contains 0, or at a boundary

For the smoothed version:
f'(x) = sum_k w_k(x) * A_k where w_k(x) = exp(s*(A_k*x+B_k)) / sum_m exp(s*(A_m*x+B_m))
f''(x) = s * (sum_k w_k * A_k² - (sum_k w_k * A_k)²) > 0 (variance)

So we can do Newton's method: x_new = x - f'(x)/f''(x), project to [0,1].

This is very efficient! Each coordinate update is O(n) (to compute A_k, B_k) plus a few Newton steps.
