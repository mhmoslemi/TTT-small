  = (stuff) + h[i]*((1-h[i+k]) - h[i-k]) [combining valid terms]
  
  This is LINEAR in h[i]! So C₅ as a function of h[i] is the max of linear functions, which is a piecewise-linear convex function. Its minimum can be found by:
  1. Identifying all the "breakpoints" (where two lines cross)
  2. Evaluating at breakpoints and at 0 and 1
  
  But this is complex to implement. A simpler approach: just evaluate C₅ at, say, 20 equally-spaced values of h[i] ∈ [0,1], plus the current value. Pick the best.

Let me code this up. For n=70-100, each C₅ evaluation is O(n²) (due to correlate), and we do 20 evaluations per coordinate, n coordinates, so 20*n² per pass. For n=100: 200,000 ops per pass. Very fast.
