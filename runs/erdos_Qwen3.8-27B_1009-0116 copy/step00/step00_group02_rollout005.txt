Let me also add a simple coordinate descent as a post-processing step. For each coordinate j, we can find the optimal value of h[j] (given all other h[i] fixed) by noting that the objective is piecewise linear in h[j]. The maximum of a set of linear functions is convex, so for each j, we can find the optimal h[j] by checking the breakpoints.

Actually, the objective as a function of h[j] alone is:
f(h[j]) = max_k [a_k * h[j] + b_k]

where a_k and b_k depend on the other h values. This is a convex piecewise linear function of h[j]. The minimum of a convex piecewise linear function on [0,1] occurs at a breakpoint or at the boundary. We can find all breakpoints and evaluate f at each.

This coordinate descent is exact (finds the optimal value for each coordinate) and converges to a coordinate-wise optimum. Let me add this as a polishing step.

For coordinate j:
f(h[j]) = max_k [Σ_{i≠j} h[i](1-h[i+k]) + contribution_from_j] * dx

The contribution from j to the k-th correlate:
- h[j] appears in the sum as h[j]*(1-h[j+k]) if j+k is valid → coefficient of h[j] is (1-h[j+k])
- h[j] appears as -h[j-k]*h[j] if j-k is valid → coefficient is -h[j-k]

So: c_k(h[j]) = base_k + h[j] * [(1-h[j+k])_ind - h[j-k]_ind] * dx

where base_k = c_k with h[j] replaced by 0.

So f(h[j]) = max_k [base_k + h[j] * coef_k] * dx

This is indeed piecewise linear in h[j]. The breakpoints occur where two lines cross:
base_m + h[j]*coef_m = base_k + h[j]*coef_k
h[j] = (base_k - base_m) / (coef_m - coef_k) for coef_m ≠ coef_k

We can find all breakpoints in [0,1], sort them, and evaluate f at each plus 0 and 1.

For n=45, there are 2n-1 = 89 "k" values. The number of breakpoints is O(n²) in the worst case = O(8000). But many will be outside [0,1]. In practice, it should be manageable.

    n_corr = 2 * n - 1
    dx = 2.0 / n
    
    for sweep in range(max_sweeps):
        improved = False
        for j in range(n):
            h[j] = 0  # temporarily
            base = np.correlate(h, 1.0 - h, mode="full") * dx
            
            # Coefficients for h[j]
            coefs = np.zeros(n_corr)
            for m in range(n_corr):
                k = m - (n - 1)
                coef = 0.0
                if 0 <= j - k < n:
                    coef += (1.0 - h[j - k])
                if 0 <= j + k < n:
                    coef -= h[j + k]
                coefs[m] = coef * dx
            
            # Find all breakpoints in [0,1]
            candidates = [0.0, 1.0]
            for m1 in range(n_corr):
                for m2 in range(m1 + 1, n_corr):
                    dc = coefs[m1] - coefs[m2]
                    if abs(dc) > 1e-15:
                        bp = (base[m2] - base[m1]) / dc
                        if 0.0 <= bp <= 1.0:
                            candidates.append(bp)
            
            # Evaluate at all candidates

            best_x = 0.0
            for x in candidates:
                val = np.max(base + x * coefs)
                if val < best_val:
                    best_val = val
                    best_x = x
            
            if abs(best_x - h[j]) > 1e-10:
                improved = True
            h[j] = best_x
        
        if not improved:
            break
    
    return h

    best_h = _project_feasible(best_h, n)
    best_c5 = _compute_c5(best_h, n)
    return (best_h, best_c5, n)
