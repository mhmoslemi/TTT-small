Approach and rationale
The central idea is to use a three-cluster periodic pattern to minimize maximum overlap, leveraging gradients computed only for the top K shifts to reduce dimensionality. Unlike previous strategies that relied on penalized objectives, we enforce integral constraints exactly via projection, addressing local optima by tracking critical shifts. The key bottleneck is balancing integral constraints while reducing overlap without underfitting; three-cluster initialization overcomes this by explicitly optimizing logarithmic and exponentiated correlations penalized by max-shift overlap.

Mathematical specification
Variables:
h: n-dimensional step function (discrete on grid points over [0,2]) with integral 0.5 (n/2 samples normalized by dx).
Constraints: 0 <= h[i] <= 1 for all i, ∑h = n/2.
Objective: Min C5 = max k ∫h(x)(1-h(x+k))dx, approximated by maximum correlation in full mode divided by dx.

Implementation procedure
1. Initialization: Convert initial_h_values to cluster centers if provided, else randomize 3 centers with height α=100. Each cluster assignment: h[i] = σ for points near clusters, 0 elsewhere.
2. Objective (F): Compute correlation for full mode, take max, weight with Poisson-disk separation and soft-max thresholding.
3. Gradient approximation: Finite differencing only for top 500 shifts.
4. Repair: Project to integral/norm=1 by redistributing surplus.
5. Optimization: L-BFGS-B with callback eagerly switching to active-set refinement upon dC/dt < ε.
6. Validation: Run 30 restarts with cluster migration.

Search choices and useful variations
- Three-cluster (≥2) based on Poisson-disk positioning with density inversion if overlap stagnates.
- Use initial_centers from around [8, 16, 24] (normalized by grid length).
- Abort if validation fails and retry with continuous parameterization.

Computational budget and robustness
500's for the core optimization, 1100s with warm starts. Abort if repair cycles >5. Fallback cluster seeds: [40, 70, length-40] etc.

Validation and return contract
Post-optimization: Re-calculate C5. Return (h_cluster, C5, n_points). Check 0<=h[i]<=1 and integral≈0.5 within 1e-3.
