The gradient of _smooth_max(c, alpha) with respect to x is:
d/dx = (1/alpha) * sum_k exp(alpha*(c_k - c_max)) * (dc_k/dx) / sum_k exp(alpha*(c_k - c_max))

This gives us a weighted average of the gradients of the top correlations, weighted by their "activations." This is much more informative than just the top-K.

Let me implement this!

```python
def _smooth_max_grad(x, alpha):
    c = _corr(x)
    m = float(np.max(c))
    s = alpha * (c - m)
    s = np.clip(s, -500.0, 500.0)
    w = np.exp(s)
    w /= (w.sum() + 1e-30)
    # Gradient of smooth max = weighted sum of gradients of c_k
    g = np.zeros(n)
    for k in range(len(c)):
        if w[k] < 1e-10:
            continue
        # gradient of c_k with respect to x
        # c_k = sum_i x[i] * (1 - x[i+k-(n-1)]) for valid i
        m_offset = k - (n - 1)
        for i in range(n):
            j = i + m_offset
            if 0 <= j < n:
                g[i] += w[k] * (1.0 - x[j])
                g[j] -= w[k] * x[i]
    return g / alpha
```

Wait, this is expensive because it's O(n * 2n) = O(n²) for each iteration. For n=70, that's 9800 operations per gradient evaluation. With SLSQP doing ~100 iterations, that's ~1M operations. Should be fine.

But actually, computing this gradient in Python with nested loops will be slow. Let me vectorize it.

For a given lag offset m = k - (n-1):
- g[i] gets contribution w[k] * (1 - x[i+m]) from the first term (for valid i where i+m is in [0,n-1])
- g[i+m] gets contribution -w[k] * x[i] from the second term

So for each k, I need to add a shifted version of (1-x) to g and subtract a shifted version of x.

Let me vectorize:
```python
def _smooth_max_grad(x, alpha, n):
    c = _corr(x)
    m = float(np.max(c))
    s = np.clip(alpha * (c - m), -500.0, 500.0)
    w = np.exp(s)
    w /= (w.sum() + 1e-30)
    g = np.zeros(n)
    for k in range(len(c)):
        wk = w[k]
        if wk < 1e-10:
            continue
        off = k - (n - 1)
        if off >= 0:
            # x[i] pairs with x[i+off], valid i: 0 to n-1-off
            valid = n - off
            g[:valid] += wk * (1.0 - x[off:])
            g[off:] -= wk * x[:valid]
        else:
            # x[i] pairs with x[i+off] = x[i-|off|], valid: |off| to n-1
            ao = -off  # |off|
            valid = n - ao
            g[ao:] += wk * (1.0 - x[:valid])
            g[:valid] -= wk * x[ao:]
    return g / alpha
```

This is O(n * 2n) = O(n²) per call. For n=70, that's ~5000 multiply-adds per k, times 139 k's = ~700k operations. In Python with numpy, the vectorized operations should handle this in a few ms.

import time

def _corr(h):
    return np.correlate(h, 1.0 - h, mode='full')

def _c5(h, dx):
    return float(np.max(_corr(h)) * dx)

def _repair(h, n):
    h = np.clip(h, 0.0, 1.0).copy()
    target = n / 2.0
    s = h.sum()
    if s < 1e-12:
        return np.full(n, 0.5)
    if abs(s - target) > 1e-10:
        h *= target / s
        h = np.clip(h, 0.0, 1.0)
        diff = target - h.sum()
        if abs(diff) > 1e-12:
            order = np.argsort(1.0 - h) if diff > 0 else np.argsort(h)
            for idx in order:
                if diff > 0:
                    a = min(diff, 1.0 - h[idx])
                    h[idx] += a
                    diff -= a
                else:
                    a = min(-diff, h[idx])
                    h[idx] -= a
                    diff += a
                if abs(diff) < 1e-12:
                    break
    return h

def _smooth_max(x, alpha, n):
    c = _corr(x)
    m = float(np.max(c))
    s = np.clip(alpha * (c - m), -500.0, 500.0)
    return m + np.log(np.sum(np.exp(s))) / alpha

    c = _corr(x)
    m = float(np.max(c))
    s = np.clip(alpha * (c - m), -500.0, 500.0)
    w = np.exp(s)
    w /= (w.sum() + 1e-30)
    g = np.zeros(n)

        wk = w[k]
        if wk < 1e-10:
            continue

            valid = n - ao

    best_c5 = _c5(best_h, dx)
