c_k = np.correlate(h, 1-h, 'full')[k] where k = 0, 1, ..., 2n-2

The lag L = k - (n-1), so L ranges from -(n-1) to (n-1).

c_k = sum_i h[i+L] * (1-h[i]) where the sum is over valid i.

For L > 0: i ranges from 0 to n-1-L (so that i+L < n)
For L = 0: i ranges from 0 to n-1
For L < 0: let L2 = -L > 0, i ranges from L2 to n-1 (so that i+L = i-L2 >= 0)

∂c_k/∂h[m]:
The term h[m] appears in c_k in two ways:
1. As h[i+L] where i+L = m, so i = m-L. Valid if 0 ≤ m-L < n.
   Contribution: 1 - h[m-L]
2. As h[i] where i = m. Valid if i+L = m+L is in [0, n-1].
   Contribution: -h[m+L]

So ∂c_k/∂h[m] = (1-h[m-L]) * [0≤m-L<n] - h[m+L] * [0≤m+L<n]

For L > 0:
- m-L ≥ 0 means m ≥ L
- m+L < n means m < n-L
- ∂c/∂h[m] = (1-h[m-L]) for m ∈ [L, n-1], minus h[m+L] for m ∈ [0, n-L-1]

For L < 0 (L2 = -L):
- m-L = m+L2 < n means m < n-L2
- m+L = m-L2 ≥ 0 means m ≥ L2
- ∂c/∂h[m] = (1-h[m+L2]) for m ∈ [0, n-L2-1], minus h[m-L2] for m ∈ [L2, n-1]

For L = 0:

import numpy as np
from scipy.optimize import minimize
import time

def _repair(h, n):
    h = np.clip(h, 0.0, 1.0).copy()
    target = n / 2.0
    s = h.sum()
    if s < 1e-15:
        return np.full(n, 0.5)
    if abs(s - target) > 1e-9:
        h *= target / s
        h = np.clip(h, 0.0, 1.0)
        diff = target - h.sum()
        if abs(diff) > 1e-12:
            idx = np.argsort(1.0 - h) if diff > 0 else np.argsort(h)
            for i in idx:
                if diff > 0:
                    a = min(diff, 1.0 - h[i]); h[i] += a; diff -= a
                else:
                    a = min(-diff, h[i]); h[i] -= a; diff += a
                if abs(diff) < 1e-12:
                    break
    return h

def _eval(h):
    return float(np.max(np.correlate(h, 1.0 - h, mode='full')) * 2.0 / len(h))

def _grad_lag(h, L):
    n = len(h)
    g = np.zeros(n)
    if L == 0:
        return 1.0 - 2.0 * h
    if L > 0:
        g[L:] += (1.0 - h[:n - L])
        g[:n - L] -= h[L:]
    else:
        L2 = -L
        g[:n - L2] += (1.0 - h[L2:])
        g[L2:] -= h[:n - L2]
    return g

def _subgrad(h, k_act):
    c = np.correlate(h, 1.0 - h, mode='full')
    n = len(h)
    top = np.argsort(c)[-k_act:]
    g = np.zeros(n)
    for idx in top:
        g += _grad_lag(h, idx - (n - 1))
    return g / k_act, c

def _sf(h, a):
    c = np.correlate(h, 1.0 - h, mode='full')
    m = c.max()
    s = np.clip(a * (c - m), -500, 500)
    return m + np.log(np.sum(np.exp(s))) / a

def _sj(h, a):
    n = len(h)
    c = np.correlate(h, 1.0 - h, mode='full')
    m = c.max()
    s = np.clip(a * (c - m), -500, 500)

    g = np.zeros(n)
    for k in range(2 * n - 1):
        if w[k] < 1e-14:
            continue
        g += w[k] * _grad_lag(h, k - (n - 1))
    return g

def _slsqp(h, n, alpha, maxiter):

        res = minimize(_sf, h, jac=_sj, args=(alpha,), method='SLSQP',
                       bounds=[(0.0, 1.0)] * n,

                                     'jac': lambda x: np.ones(n)}],
                       options={'maxiter': maxiter, 'ftol': 1e-18})
        return _repair(res.x, n)
    except Exception:
        return _repair(h, n)
