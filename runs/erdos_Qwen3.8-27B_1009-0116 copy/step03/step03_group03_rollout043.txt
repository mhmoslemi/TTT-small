```python
                t_hi = min(t_hi, (mid - beta[m]) / alpha[m])
        if t_lo <= t_hi and t_lo <= 1.0 and t_hi >= 0.0:
            hi = mid
        else:
            lo = mid

    # Find t
    t_lo = 0.0
    t_hi = 1.0
    for m in range(M):
        if alpha[m] > 1e-12:
            t_lo = max(t_lo, (τ - beta[m]) / alpha[m])
        elif alpha[m] < -1e-12:
            t_hi = min(t_hi, (τ - beta[m]) / alpha[m])
    t = (min(max(t_lo, 0), 1) + min(max(t_hi, 0), 1)) / 2
    t = min(max(t, 0), 1)
    return t, τ
```

Wait, but this doesn't account for the sum constraint. After changing h[i], the sum changes. We need to either:
(a) Ignore the sum constraint in the 1D optimization, then repair
(b) Account for it by also adjusting one other coordinate

Option (a) is simpler and should work well in practice.

But actually, there's an issue: when we compute c = _corr(h), this gives the CURRENT correlations. The linear approximation c[m] ≈ α[m]*t + β[m] is exact (since c[m] is linear in h[i]). So this is not an approximation - it's exact!

The only issue is the sum constraint. Let me just optimize h[i] freely (ignoring sum), then repair.

Actually wait - I realize the sum constraint is important. If I change h[i] from 0.5 to 1.0, the sum increases by 0.5, and I need to decrease some other h[j] by 0.5. The repair function handles this by distributing the deficit/surplus.

Let me just do: optimize h[i] → repair → check if improved.

This coordinate descent should converge to a local optimum where no single coordinate change (followed by repair) improves the objective. Combined with the gradient-based local search, this should find a very good local optimum.

Let me now write the full algorithm:

def _corr(h):
    return np.correlate(h, 1.0 - h, mode='full')

def _c5(h, dx):
    return np.max(_corr(h)) * dx

def _repair(h, n):
    h = np.clip(h, 0.0, 1.0).copy()
    target = n / 2.0
    s = h.sum()
    if s < 1e-12:
        return np.full(n, 0.5)
    h *= target / s
    h = np.clip(h, 0.0, 1.0)
    diff = target - h.sum()
    if abs(diff) > 1e-12:
        if diff > 0:
            order = np.argsort(1.0 - h)
        else:
            order = np.argsort(h)
        for idx in order:
            if diff > 0:
                add = min(diff, 1.0 - h[idx])
            else:
                add = max(diff, h[idx] - 1.0)
            h[idx] += add
            diff -= add
            if abs(diff) < 1e-12:
                break
    return h
