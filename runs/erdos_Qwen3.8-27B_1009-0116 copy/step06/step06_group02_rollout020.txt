Subgradient at t: the set of all convex combinations of {coeff[k] : k ∈ argmax}.
So subgradient = [min_{k∈argmax} coeff[k], max_{k∈argmax} coeff[k]]

If 0 is in this interval, t is optimal.
If min subgradient > 0, f is increasing at t, go left.
If max subgradient < 0, f is decreasing at t, go right.

```python
def _min_max_linear(const, coeff):
    lo, hi = 0.0, 1.0
    for _ in range(60):
        mid = 0.5 * (lo + hi)
        vals = const + mid * coeff
        mx = vals.max()
        active = (vals >= mx - 1e-15)
        if active.sum() == 0:
            active = (vals == mx)
        min_sub = coeff[active].min()
        max_sub = coeff[active].max()
        if min_sub > 1e-12:
            hi = mid
        elif max_sub < -1e-12:
            lo = mid
        else:
            break
    return 0.5 * (lo + hi)
```
