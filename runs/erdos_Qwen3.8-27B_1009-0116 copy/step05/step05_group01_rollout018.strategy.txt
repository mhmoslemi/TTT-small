        def simulated_annealing(h0, n_points, max_iter=5000, initial_temp=1.0, cooling_rate=0.995, step_size=0.1):
            h_current = repair(h0, n_points).copy()
            current_energy = compute_objective(h_current, n_points)
            best_h = h_current.copy()
            best_energy = current_energy

            T = initial_temp
            for i in range(max_iter):
                h_neighbor = h_current.copy()
                # Choose a random index
                idx = np.random.randint(n_points)
                # Perturb h_neighbor[idx]
                change = np.random.uniform(-step_size, step_size)
                h_neighbor[idx] += change
                # Repair the neighbor
                h_neighbor = repair(h_neighbor, n_points)
                energy_neighbor = compute_objective(h_neighbor, n_points)

                delta_e = energy_neighbor - current_energy

                # If we found a better solution, accept
                if delta_e < 0 or np.random.random() < np.exp(-delta_e / T):
                    h_current = h_neighbor.copy()
                    current_energy = energy_neighbor
                    if current_energy < best_energy:
                        best_h = h_current.copy()
                        best_energy = current_energy

                T *= cooling_rate

            return best_h, best_energy

We propose a multi-resolution optimization algorithm based on simulated annealing at successively finer resolutions. Unlike the SLSQP and gradient projection methods used previously, simulated annealing explores the solution space more thoroughly by accepting suboptimal moves early in the optimization process. This approach is particularly suitable for non-convex problems where local optima are prevalent. The key bottleneck in the current implementation is the repair mechanism that maintains feasibility (0≤h[i]≤1) while exactly satisfying the integral constraint (sum(h)=∫dx= n/2). Our repair function uses a combination of value normalization and targeted redistribution, which we believe will help sidestep some of the local convergence issues observed in previous work.

def repair(h, n, max_iter=100):
    target = n/2.0  # Required sum for integral
    h_clipped = np.clip(h, 0.0, 1.0)  # Enforce box constraints
    s = sum(h_clipped.value)
    
    if abs(s - target) < 1e-9: return h_clipped
    
    # Initialize iteration counter
    iter_count = 0
    improvement = 1e9
    
    while improvement > 1e-7 and iter_count < max_iter:
        iter_count += 1
        
        if s < target - 1e-9:  # Need to increase sum
            order = np.argsort(1.0 - h_clipped)  # Find indices with most room for increase
            diff = target - s  # Amount needed
            idx = order[0]  # First index in line for increase
            add = min(diff, 1.0 - h_clipped[idx])
            h_clipped[idx] += add
            s += add
            improvement = abs(target - s)
        elif s > target + 1e-9:  # Need to decrease sum
            order = np.argsort(h_clipped)  # Find indices with least stored mass
            diff = s - target
            idx = order[-1]  # Last in order (lowest value)
            reduce = min(diff, h_clipped[idx])
            h_clipped[idx] -= reduce
            s -= reduce
            improvement = abs(target - s)
    
    return h_clipped.value
