For the objective f(h) = max_k O_k, the subgradient at h (when O_{k*} is the unique max) is:
∂f/∂h[i] = ∂O_{k*}/∂h[i] = sum over all terms involving h[i]

Wait, let me be more careful:
O_k = sum_{i: 0≤i≤n-1-k} h[i](1-h[i+k])

∂O_k/∂h[i] = (1-h[i+k]) [from the first factor] + sum_{j: j+k=i} h[j]*(-1) [from the second factor]
= (1-h[i+k]) - h[i-k] (if i-k ≥ 0 and i-k ≤ n-1-k)

So the subgradient of the objective (when k* is active) is:
g[i] = (1-h[i+k*]) - h[i-k*] (with boundary terms)

A descent direction would be -g, but we need to maintain the constraint sum(h) = n/2. So we project:
d = -g + mean(g) * ones (to make sum(d) = 0)
Then take a step: h_new = project(h + step * d, n)

This is a subgradient method! It's simple and might work well.

def subgradient_step(h, n, step_size, deadline):
    dx = 2.0 / n
    best_h = h.copy()
    best_c = compute_c5(best_h, n)
    
    for it in range(10000):
        if time.time() > deadline:
            break
        prof = compute_profile(best_h, n)
        k_active = np.argmax(prof)
        # Convert to actual shift
        shift = k_active - (n - 1)
        
        if shift == 0:
            # At shift 0, O_0 = sum h[i](1-h[i]) which is always ≥ 0
            # and for {0,1} valued h, it's 0
            # For continuous h, it's 1 - sum(h[i]^2)
            # Gradient: 1 - 2*h[i]
            g = 1 - 2 * best_h
        else:
            s = shift
            g = np.zeros(n)
            if s > 0:
                # O_s = sum_{i=0}^{n-1-s} h[i](1-h[i+s])
                # d/dh[i] = (1-h[i+s]) for i < n-s
                # d/dh[i] -= h[i-s] for i >= s and i-s < n-s, i.e., i < n
                g[:n-s] += (1 - best_h[s:n])
                g[s:] -= best_h[:n-s]
            else:
                s = -s
                g[:n-s] += (1 - best_h[s:n])
                g[s:] -= best_h[:n-s]
        
        # Project gradient to maintain sum constraint
        g = g - np.mean(g)
        
        # Adaptive step size
        step = step_size / (1 + it * 0.01)
        h_new = project(best_h - step * g, n)
        c_new = compute_c5(h_new, n)
        
        if c_new < best_c:
            best_c = c_new
            best_h = h_new
        # else: keep best_h
    return best_h, best_c

    """Compute subgradient of max_k O_k at current h"""
    prof = compute_profile(h, n)

    s = abs(shift)

            g[s2:] -= 0.1 * h[:n-s2]

Let me think about what structures might be good:
- The function should have "anti-correlation" at the shifts that are worst
- If the worst shift is k*, we want h(x) and h(x+k*) to be as similar as possible (both high or both low)
- This suggests a periodic-like structure with period related to k*

For the continuous problem on [0,2], if the worst shift is around 1 (which is often the case), then we want h(x) ≈ h(x+1) for x ∈ [0,1]. This means h should be roughly symmetric: h(x) ≈ h(x+1).

But h needs to have integral 1 over [0,2], so average value 0.5. If h(x) = h(x+1), then h is periodic with period 1, and its integral over [0,2] is 2 × integral over [0,1] = 1, so integral over [0,1] = 0.5.

A periodic function with period 1 and integral 0.5 over [0,1]... that's just any function on [0,1] with integral 0.5, extended periodically.

But this won't help because the overlap at shift k=1 would be:
∫₀¹ h(x)(1-h(x))dx = ∫₀¹ h(x)dx - ∫₀¹ h(x)²dx = 0.5 - ∫₀¹ h(x)²dx

To minimize this, we want to maximize ∫₀¹ h(x)²dx, which means h should be as extreme as possible (0 or 1). If h is {0,1} on [0,1] with integral 0.5, then ∫h² = 0.5, and the overlap at k=1 is 0.5 - 0.5 = 0.

But then the overlap at other shifts might be large. For example, at k=0.5:
∫₀² h(x)(1-h(x+0.5))dx

If h is a step function equal to 1 on [0, 0.5] and 0 on [0.5, 1) (repeated periodically), then at shift 0.5, h(x) and h(x+0.5) are always complementary, so the overlap is maximal.

So the tradeoff is: try to make h "correlated" at the worst shift, but this makes it "anti-correlated" at other shifts.

This is a fundamental tension that makes the problem hard.

    best_c = compute_c5(best_h, n)
    for alpha in [1000, 10000, 100000, 1000000]:
        if time.time() > deadline - 20:
            break
        h_new = slsqp_opt(best_h, n, alpha, maxiter=3000)
        c_new = compute_c5(h_new, n)
        if c_new < best_c - 1e-11:
            best_c = c_new
            best_h = h_new
    if time.time() < deadline - 25:
        best_h, best_c = gradient_descent(best_h, n, deadline - 25)
    if time.time() < deadline - 15:
        best_h, best_c = targeted_local(best_h, n, deadline - 15)
    if time.time() < deadline - 10:
        best_h, best_c = near_local(best_h, n, deadline - 10, radius=30)
    if time.time() < deadline - 5:
        h_new = slsqp_opt(best_h, n, 5000000, maxiter=5000)
        c_new = compute_c5(h_new, n)
        if c_new < best_c:
            best_h = h_new
            best_c = c_new
    return best_h, best_c

def run(seed=42, budget_s=1100, **kwargs):
    t0 = time.time()
    deadline = t0 + budget_s - 5
    rng = np.random.RandomState(seed)
    try:
        h_parent = np.array(initial_h_values, dtype=float).copy()
        n_parent = len(h_parent)
    except Exception:
        h_parent = None
        n_parent = 250
    best_h = None
    best_c = float('inf')
    if h_parent is not None:
        alloc = min(380, (deadline - t0) * 0.38)
        best_h, best_c = optimize_full(h_parent, n_parent, t0 + alloc, rng)
    x_p = np.linspace(0, 2, n_parent)
    for n_try in [100, 150, 350, 500]:
        if n_try == n_parent or time.time() > deadline - 55:
            continue
        alloc = min(110, (deadline - time.time()) * 0.22)
        if alloc < 25:
            break
        if h_parent is not None:
            h_int = np.interp(np.linspace(0, 2, n_try), x_p, h_parent)
        else:
            h_int = np.full(n_try, 0.5)
        h_int = project(h_int, n_try)
        h_opt, c_opt = optimize_full(h_int, n_try, time.time() + alloc, rng)
        if c_opt < best_c:
            best_c = c_opt
            best_h = h_opt
            x_p = np.linspace(0, 2, n_try)
            n_parent = n_try
    if best_h is not None and time.time() < deadline - 35:
        n = len(best_h)
        remaining = deadline - time.time() - 18
        n_restart = max(2, int(remaining / 65))
        scales = [0.003, 0.008, 0.015, 0.03, 0.05, 0.08]
        for r in range(n_restart):
            if time.time() > deadline - 18:
                break
            s = scales[r % len(scales)]
            hp = project(best_h + rng.normal(0, s, n), n)
            alloc = min(55, (deadline - time.time() - 18) * 0.3)
            if alloc < 15:
                break
            h_opt, c_opt = optimize_full(hp, n, time.time() + alloc, rng)
            if c_opt < best_c:
                best_c = c_opt
                best_h = h_opt
    if best_h is not None and time.time() < deadline - 4:
        n = len(best_h)
        best_h, best_c = gradient_descent(best_h, n, deadline - 4)
        if time.time() < deadline - 2:
            best_h, best_c = targeted_local(best_h, n, deadline - 1)
        best_h = project(best_h, n)
        best_c = compute_c5(best_h, n)
    if best_h is None:
        best_h = project(np.full(100, 0.5), 100)
        best_c = compute_c5(best_h, 100)
    return best_h, best_c, len(best_h)
