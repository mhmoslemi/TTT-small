def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h.copy(), 0.0, 1.0)
    for _ in range(500):
        diff = target - h.sum()
        if abs(diff) < 1e-13:
            break
        if diff > 0:
            room = 1.0 - h
            tot = room.sum()
            if tot < 1e-15:
                break
            h += (diff / tot) * room
        else:
            tot = h.sum()
            if tot < 1e-15:
                break
            h += (diff / tot) * h
    return np.clip(h, 0.0, 1.0)

    return x.sum() - n / 2.0

    return np.ones(len(x))

More precisely, for arrays a and b of length n:
np.correlate(a, b, 'full')[k] = Σ_{i} a[i] · b[i + k - n + 1]  (with b indexed as 0..n-1, out of range = 0)

So for our case:
np.correlate(h, 1-h, 'full')[k] = Σ_i h[i] · (1-h)[i + k - n + 1]

For k = n-1 (the center): = Σ_i h[i] · (1-h)[i] = Σ_i h[i](1-h[i]) — this is the "zero lag" term.

For k = n-1+1 = n: = Σ_i h[i] · (1-h)[i+1] — this is the +1 lag term.

And so on.

The integral ∫₀² h(x)(1-h(x+t)) dx for a step function with n points is approximated by:
dx · Σ_i h[i] · (1-h[i + round(t/dx)])

So the numpy correlate result at index (n-1 + round(t/dx)) gives us dx⁻¹ times the integral for shift t.

Therefore, C₅ = max_k correlate[k] * dx is correct.

    if best_h is None:
        best_h = project_feasible(np.full(n0, 0.5), n0)
        best_n = n0
        best_c = compute_c5(best_h, best_n)
    
    best_h = project_feasible(best_h, best_n)
    best_c = compute_c5(best_h, best_n)
    return best_h, best_c, best_n
