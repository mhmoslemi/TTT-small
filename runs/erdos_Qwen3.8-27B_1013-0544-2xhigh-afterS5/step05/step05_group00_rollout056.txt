        delta[s] = sum over unique affected j values of (h_new[j]*(1-h_new[j+s]) - h_old[j]*(1-h_old[j+s]))
        
        The affected j values are from the set {i, i-s, j, j-s} (only valid ones).
        
        In the worst case, there are 4 affected j values. In the overlap case (s=0, s=i-j, s=j-i), there are fewer.
        
        So for each (i, j, s), computing delta[s] is O(1) (just 4 lookups). For all s (2n-1 values), it's O(n) per pair.
        
        But we want to find the (i,j) that minimizes max_s (corr[s] + delta[s]). For a given (i,j), computing all delta[s] for s=-n+1,...,n-1 is O(n). Then max is O(n). Total per pair: O(n).
        
        For all pairs: O(n² * n) = O(n³). Same complexity as before, but without the precomputation.
