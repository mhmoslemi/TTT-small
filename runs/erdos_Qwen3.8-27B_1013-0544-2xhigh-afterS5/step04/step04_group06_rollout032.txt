Let me also think about whether there's a smarter way to compute the gradient.

The correlation c(j) for lag j-(n-1) = k is:
- For k ≥ 0: c = sum_{i=0}^{n-1-k} h[i] * (1-h[i+k])
- For k < 0: c = sum_{i=|k|}^{n-1} h[i] * (1-h[i-|k|]) = sum_{i=0}^{n-1-|k|} h[i+|k|] * (1-h[i])

The gradient w.r.t. h[m] for lag k ≥ 0:
- If m < n-k: term includes h[m]*(1-h[m+k]), contributes (1-h[m+k])
- If m ≥ k: term includes h[m-k]*(1-h[m]), contributes -h[m-k]
- Otherwise: 0

So for a given lag k ≥ 0, the gradient contribution to h is:
g[m] += w * (1-h[m+k]) for m = 0..n-1-k
g[m] -= w * h[m-k] for m = k..n-1

This is what the code already does. The key optimization is that for the p-norm, many weights will be small (since the p-norm emphasizes the max), so the `if abs(weight[j]) < 1e-14: continue` check is important.

For large p (like p=256), only the top few correlation values will have non-negligible weights. So the gradient computation becomes much faster!

Let me refine the approach:
- For small p (p=4, 8): all lags contribute, gradient is O(n^2)
- For large p (p=256, 512): only top ~5-10 lags contribute, gradient is O(n * 10)

This is great! The high-p optimization is actually fast.

Let me also think about an alternative: instead of p-norm, use the **exponential** (log-sum-exp) approach but with a better-structured gradient.

Actually, the previous code already uses log-sum-exp. Let me think about why it might not be converging well.

The log-sum-exp approach:

The issue is that for large beta, the gradient becomes concentrated on the max element, which is essentially the subgradient. So for large beta, log-sum-exp ≈ subgradient, and the optimization becomes slow.

The p-norm approach has a similar issue for large p. The advantage of p-norm is that for moderate p (16-64), it gives a smoother approximation than log-sum-exp at the same "sharpness".

Let me think about another approach: **Alternating Direction Method of Multipliers (ADMM)**

We can write the problem as:
min_h max_k c_k(h)
subject to: 0 ≤ h ≤ 1, sum(h) = n/2

Introduce variable t:
min_{h,t} t
subject to: c_k(h) ≤ t for all k, 0 ≤ h ≤ 1, sum(h) = n/2

ADMM would alternate between:
1. Update h: min_{h} t + (ρ/2) * sum_k max(0, c_k(h) - t + u_k)^2 subject to 0≤h≤1, sum(h)=n/2
2. Update t: min_t t + (ρ/2) * sum_k max(0, c_k(h) - t + u_k)^2
3. Update multipliers

The h-update is a QP (since c_k are quadratic in h). This could be solved with CVXPY or a custom QP solver.

    dx = 2.0 / len(h)
    return float(np.max(np.correlate(h, 1.0 - h, mode="full"))) * dx

def project_sum(h, target):
    h = np.clip(h, 0.0, 1.0)
    lo, hi = -2.0, 2.0
    for _ in range(80):
        mid = (lo + hi) * 0.5
        if np.clip(h - mid, 0.0, 1.0).sum() > target:
            lo = mid
        else:
            hi = mid
    return np.clip(h - (lo + hi) * 0.5, 0.0, 1.0)

def corr_and_grad(h, p):
    """Compute p-norm of correlation vector and its gradient"""
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full") * dx
    abs_corr = np.abs(corr)
    # p-norm
    if p == np.inf:
        val = np.max(corr)
    else:
        val = np.sum(abs_corr**p)**(1.0/p)
    if val < 1e-30:
        return val, np.zeros(n)
    # weights for gradient
    if p == np.inf:
        # subgradient: weight on the max element
        w = np.zeros(len(corr))
        idx_max = np.argmax(corr)
        w[idx_max] = 1.0
    else:
        w = abs_corr**(p-1) * np.sign(corr) / (val**(p-1))
    # Compute gradient
    g = np.zeros(n)
    nc = len(corr)
    n1 = n - 1
    for j in range(nc):
        if abs(w[j]) < 1e-12:
            continue
        lag = j - n1
        if lag == 0:
            g += w[j] * (1.0 - 2.0 * h)
        elif lag > 0:
            g[lag:] += w[j] * (1.0 - h[:-lag])
            g[:n-lag] -= w[j] * h[lag:]
        else:
            m2 = -lag
            g[:n-m2] += w[j] * (1.0 - h[m2:])
            g[m2:] -= w[j] * h[:n-m2]
    return val, g

def subgrad_polish(h, target, n_active, max_iter, t0, budget):
    n = len(h)
    best = h.copy()
    best_c5 = compute_c5(best)
    no_improve = 0
    for it in range(max_iter):
        if budget - (time.time() - t0) < 5:
            break
        corr = np.correlate(best, 1.0 - best, mode="full")
        top_idx = np.argsort(corr)[::-1][:n_active]
        g = np.zeros(n)
        for idx in top_idx:
            lag = int(idx) - (n - 1)
            if lag == 0:
                g += (1.0 - 2.0 * best)
            elif lag > 0:
                g[lag:] += (1.0 - best[:-lag])
                g[:n-lag] -= best[lag:]
            else:
                m2 = -lag
                g[:n-m2] += (1.0 - best[m2:])
                g[m2:] -= best[:n-m2]
        gn = np.linalg.norm(g)
        if gn < 1e-14:
            break
        g /= gn
        improved = False
        for step in [0.04, 0.02, 0.01, 0.005, 0.002, 0.001, 0.0004]:
            ht = project_sum(best - step * g, target)
            c5t = compute_c5(ht)
            if c5t < best_c5 - 1e-16:
                best = ht
                best_c5 = c5t
                improved = True
                break
        if not improved:
            no_improve += 1
            if no_improve > 150 and it % 100 == 99:
                alpha = 0.01 + 0.02 * np.random.random()
                ht = project_sum(best + np.random.randn(n) * alpha, target)
                c5t = compute_c5(ht)
                if c5t < best_c5:
                    best = ht
                    best_c5 = c5t
                    no_improve = 0
            if no_improve > 2000:
                break
        else:
            no_improve = 0
    return best, best_c5
