I think the key to a good solution is to find a sequence where the "1→0" counts are as uniform as possible across all shifts.

This is related to the concept of a "difference set" or "perfect difference set" in combinatorics. A (v, k, λ) difference set is a k-element subset S of a group of order v such that every nonzero element is represented exactly λ times as a difference of two elements of S.

If we could find a perfect difference set, the R(k) values would be perfectly uniform. But perfect difference sets only exist for certain parameters and don't always exist.

For our problem, we're looking for a subset S of {0, 1, ..., n-1} of size n/2 such that the number of pairs (s, s+k) with s ∈ S, s+k ∉ S is as uniform as possible in k.

This is equivalent to: the autocorrelation of the indicator function of S is as flat as possible.

This is exactly the "Golay sequence" or "complementary set" problem!

A Golay complementary pair (A, B) is a pair of binary sequences such that their aperiodic autocorrelations sum to zero for all nonzero shifts. If we could find such a pair, we could potentially get a very flat R(k).

But I don't think a single sequence can have perfectly flat autocorrelation (that would be a "perfect sequence," which only exists in very limited cases).

    return b

def eval_c5(h, dx):
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr)) * dx
