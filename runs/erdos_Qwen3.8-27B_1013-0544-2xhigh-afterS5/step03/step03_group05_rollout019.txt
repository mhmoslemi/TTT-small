For a single variable h[i], given all other variables fixed, the objective max_k g_k(h) as a function of h[i] is:
- For each lag k, g_k depends on h[i] linearly (it appears in at most 2 terms: as h[i] and as 1-h[i] in the pair)
- So g_k(h[i]) = a_k * h[i] + b_k (linear in h[i])
- The max of linear functions is convex in h[i]
- The minimum of a convex function over [0,1] (with the sum constraint) is at the point where the subgradient contains 0, or at a boundary

This means we can do exact coordinate descent! For each i:
1. Compute g_k for all k as a function of h[i] (it's a set of lines)
2. Find the h[i] in [0,1] that minimizes max_k (a_k * h[i] + b_k), subject to the sum constraint
3. Update h[i]

The sum constraint complicates things a bit, but if we're just adjusting one variable, the constraint becomes: h[i] must be in [max(0, target - sum(others)), min(1, target - sum(others))].

Actually, for the sum constraint: if we change h[i] by delta, all other variables stay the same, so the sum changes by delta. To maintain the sum, we'd need to adjust another variable. This makes pure coordinate descent not directly applicable.

Alternative: use a "swap" move. Pick i and j, and transfer some amount from h[i] to h[j] (or vice versa). This preserves the sum constraint automatically.

For a swap move (h[i] += delta, h[j] -= delta):
- The effect on g_k can be computed
- We find the delta that minimizes max_k g_k

This is a 1D optimization (over delta), and since each g_k is linear in delta, the max is a convex piecewise linear function of delta. The minimum is at a breakpoint or at a boundary.

import numpy as np
from scipy.optimize import minimize, Bounds
from functools import partial
import time


def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)


def smooth_max_val(x, beta):
    m = x.max()
    x_shift = np.clip(beta * (x - m), -500, 500)
    return m + np.log(np.sum(np.exp(x_shift)) / len(x)) / beta


def project_h(h, target_sum):
    h = np.clip(h, 0.0, 1.0)
    for _ in range(200):
        diff = target_sum - h.sum()
        if abs(diff) < 1e-14:
            break
        free = (h > 1e-10) & (h < 1.0 - 1e-10)
        if free.sum() == 0:
            free = np.ones(len(h), dtype=bool)
        h[free] += diff / free.sum()
        h = np.clip(h, 0.0, 1.0)
    return h


def resample_to(h_old, n_new):
    n_old = len(h_old)
    if n_old == n_new:
        return h_old.copy()
    x_old = np.linspace(0, 2, n_old)
    x_new = np.linspace(0, 2, n_new)
    return np.interp(x_new, x_old, h_old)


def grad_lag(h, lag, n, dx):
    g = np.zeros(n)
    if lag == 0:
        g[:] = (1.0 - 2.0 * h) * dx
    elif lag > 0:
        g[lag:] += (1.0 - h[:n - lag]) * dx
        g[:n - lag] += (-h[lag:]) * dx
    else:
        l = -lag
        g[:n - l] += (1.0 - h[l:]) * dx
        g[l:] += (-h[:n - l]) * dx
    return g


def obj_smooth_pen(h, n, dx, beta, penalty):
    corr = np.correlate(h, 1.0 - h, mode="full")
    return smooth_max_val(corr, beta) * dx + penalty * (h.sum() - n / 2.0) ** 2


def subgrad_phase(h, n, target, dx, max_iters, deadline, min_remain, best):
    cur = h.copy()
    cur_c5 = compute_c5(cur)
    vel = np.zeros(n)
    mu = 0.85
    for it in range(max_iters):
        if time.time() > deadline - min_remain:
            break
        corr_val = np.correlate(cur, 1.0 - cur, mode="full") * dx
        top_k = min(4, n // 60 + 2)
        top_idx = np.argsort(corr_val)[::-1][:top_k]
        vals = corr_val[top_idx]
        temp = 200.0 + 300.0 * it / max(1, max_iters)
        w = np.exp((vals - vals[0]) * temp)
        w /= w.sum()
        grad = np.zeros(n)
        center = n - 1
        for ti, wi in zip(top_idx, w):
            lag = int(ti) - center
            grad += wi * grad_lag(cur, lag, n, dx)
        gn = np.linalg.norm(grad)
        if gn < 1e-15:
            break
        grad /= gn
        step = 0.05 / (1.0 + 0.002 * it)
        new_vel = mu * vel - step * grad
        h_t = project_h(cur + new_vel, target)
        vel = new_vel
        c5_t = compute_c5(h_t)
        if c5_t < cur_c5 - 1e-16:
            cur = h_t
