```python
                new_vals = a_vals * x_try + b_vals
                # Also need to check if any inactive lag becomes the new max
                # Conservative: take max of (new active values) and (old max of inactive)
                inactive_max = 0  # conservative bound
                if not active_mask.all():
                    inactive_max = corr[~active_mask].max() if (~active_mask).any() else 0
                
                # For k=0 (quadratic), the actual value is:
                # x*(1-x) + (corr[0] - old*(1-old))
                # Let's handle this
                k0_idx = n - 1  # index of lag 0 in corr array
                if k0_idx in active_indices:
                    idx0 = np.where(active_indices == k0_idx)[0][0]
                    # Actual k=0 value: sum h[j]*(1-h[j]) = (sum h[j]) - sum h[j]²
                    # = n/2 - sum h[j]² (approximately, given our constraint)
                    # Change: x*(1-x) - old*(1-old)
                    actual_k0 = corr[k0_idx] + x_try*(1-x_try) - old_val*(1-old_val)
                    new_vals[idx0] = actual_k0
                
                new_max = max(new_vals.max() if len(new_vals) > 0 else 0, inactive_max)
                
                if new_max < best_obj - 1e-12:
                    best_obj = new_max
                    best_x = x_try
            
            if best_x != old_val:
                best_h[i] = best_x
                best_in_sweep = False
        
        # Check improvement
        new_c5 = compute_c5(best_h)
        if new_c5 < best_c5:
            best_c5 = new_c5
        else:
            # Rollback if no improvement (or keep, since coordinate descent should improve)
            pass
        
        if best_in_sweep:
            break
    
    return best_h, best_c5, n
```

Hmm, this is getting complex. The issue is that the k=0 lag has a quadratic term, making the 1D subproblem a minimax of linear and quadratic functions, which is still solvable but more complex.

Let me simplify: just use a fine grid for the 1D subproblem, and evaluate the TRUE objective (full correlation) at a few candidate points.

Actually, a cleaner approach: for each coordinate i, try a few values of h[i] (from a grid), compute the full C₅ for each, and pick the best. This is O(n * grid_size * n²) per sweep = O(n³ * grid_size). For n=200, grid_size=20, that's 200 * 20 * 40000 = 160M operations per sweep. Too slow.

Better: use the linearity property. For each coordinate i, the change in corr[k] is linear in h[i] (except for k=0). So I can compute the new corr vector in O(n) time per candidate x value (just update the affected lags).

Let me think about this more carefully. When I change h[i] from old to x:
- For lag k > 0 (k_idx = n-1+k):
  - If i <= n-1-k: corr[k_idx] += (x - old) * (1 - h[i+k])
  - If i >= k: corr[k_idx] += (old - x) * h[i-k]
- For lag k < 0, m = -k (k_idx = n-1-k = n-1+m):
  - If i >= m: corr[k_idx] += (x - old) * (1 - h[i-m])
  - If i+m <= n-1: corr[k_idx] += (old - x) * h[i+m]
- For k = 0: corr[n-1] += x*(1-x) - old*(1-old)

So I can update the full corr vector in O(n) time (only O(n) lags are affected). Then finding the max is O(n). Total per coordinate update: O(n). Per sweep: O(n²).

But I need to be more careful about the delta computation. Let me verify:

For lag k > 0, corr[n-1+k] = sum_{j=0}^{n-1-k} h[j] * (1 - h[j+k])

d/dh[i] of this:
- First factor: h[j] where j = i, valid when 0 ≤ i ≤ n-1-k. Contribution: (1 - h[i+k])
- Second factor: (1-h[j+k]) where j+k = i, i.e., j = i-k. Valid when 0 ≤ i-k ≤ n-1-k, i.e., k ≤ i ≤ n-1. Contribution: -h[i-k]

So delta[n-1+k] = [i ≤ n-1-k] * (1-h[i+k]) + [k ≤ i ≤ n-1] * (-h[i-k])

For lag k < 0, let m = -k > 0. corr[n-1-m] = sum_{j=m}^{n-1} h[j] * (1-h[j-m])
= sum_{j=0}^{n-1-m} h[j+m] * (1-h[j])

d/dh[i]:
- First factor: h[j+m] where j+m = i, i.e., j = i-m. Valid when 0 ≤ i-m ≤ n-1-m, i.e., m ≤ i ≤ n-1. Contribution: (1-h[i-m])
- Second factor: (1-h[j]) where j = i. Valid when 0 ≤ i ≤ n-1-m, i.e., i ≤ n-1-m. Contribution: -h[i+m]

So delta[n-1-m] = [m ≤ i ≤ n-1] * (1-h[i-m]) + [i ≤ n-1-m] * (-h[i+m])

For k = 0: corr[n-1] = sum_j h[j](1-h[j])
d/dh[i] = 1 - 2h[i]
Second derivative: -2

This all checks out. The computation of delta is O(n) per coordinate (since for each k, we do O(1) work). So per sweep it's O(n²), which is very fast.

Let me also think about whether we should use a wider grid or a smarter search. Since the 1D problem is to minimize a convex function (max of affine functions, plus a concave quadratic for k=0... wait, that's not convex in general).

Actually, the max of affine functions IS convex. But the k=0 term is concave (it's -d²). So the overall objective in the 1D subproblem is:
max(affine_1(x), affine_2(x), ..., concave_quad(x))

This is NOT necessarily convex! The max of convex functions is convex, but the max of convex and concave functions is not necessarily convex.

However, in practice, the k=0 term is usually not the binding constraint (since for a good solution, the k=0 overlap is much smaller than the max). So the 1D subproblem is approximately convex, and a grid search should work well.

The range of x is [0,1], and the change in corr is at most O(1) per unit change in x. import numpy as np

import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)

def smooth_max(x, beta):
    m = np.max(x)
    x_shift = np.clip(beta * (x - m), -500, 500)
    return m + np.log(np.sum(np.exp(x_shift)) / len(x)) / beta

def project_to_box_sum(h, target_sum):
    h = np.array(h, dtype=float)
    for _ in range(1000):
        h = np.clip(h, 0.0, 1.0)
        diff = target_sum - h.sum()
        if abs(diff) < 1e-14:
            break
        free = (h > 1e-12) & (h < 1.0 - 1e-12)
        nf = free.sum()
        if nf == 0:
            h = np.clip(h, 0.0, 1.0)
            if abs(h.sum() - target_sum) < 0.5:
                break
            raise ValueError("Cannot project")
        h[free] += diff / nf
    return np.clip(h, 0.0, 1.0)

def interp_h(h, n_new):
    if len(h) == n_new:
        return h.copy()
    x_old = np.linspace(0, 2, len(h))
    x_new = np.linspace(0, 2, n_new)
    return np.interp(x_new, x_old, h)
