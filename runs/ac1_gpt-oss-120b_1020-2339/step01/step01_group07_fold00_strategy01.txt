<h1>Constraint-Aware Block-Structured Optimization Strategy</h1>

<h2>Approach and Rationale</h2>
<p>This strategy adopts a constraint-aware optimization method based on block-structured optimization with projected gradients. Unlike the previous white-box processing, we combine several novel components:</p>
<ul>
  <li><strong>Time-Aware Optimization</strong>: Balances between exploration and exploitation by automatically adjusting perturbation intensity based on elapsed time and remaining budget</li>
  <li><strong>Gradient Projection</strong>: Uses projected gradient descent with constrained backtracking line search to ensure feasibility and progression toward the minimum</li>
  <li><strong>Block-Specific Normalization</strong>: Applies different scaling strategies to different blocks of the sequence to maintain the $L_1$ constraint budget</li>
  <li><strong>Adaptive Active Set</strong>: Dynamically selects the most promising blocks for perturbation based on their contribution to the autocorrelation bound</li>
</ul>

<p>Our primary bottleneck is managing the trade-off between the dimensionality of the optimization space and computational cost of evaluations. We address this by maintaining a portfolio of candidate perturbations rather than garbage-collecting them after computation. This approach ensures diversity in the search landscape while avoiding premature convergence.</p>

<h2>Mathematical Specification</h2>
<p>Given a sequence $a = (a_0, a_1, \ldots, a_{n-1})$ with $\sum_{i=0}^{n-1}a_i \ge 0.01$, we wish to minimize:</p>
\[
\text{AC1Bound}(a) = \frac{2n}{(\sum a_i)^2} \max_{k=0}^{2n-2} \left| \sum_{i=0}^{n-1} a_i a_{k-i} \right|
\]
<p>subject to:</p>
\[
{\rm Convergence:} \; \nabla \text{AC1Bound}(a) \cdot d \leq -\epsilon \quad \text{for some descent direction } d
\]
\[
{\rm Primal constraints:} \; 0 \leq a_i \leq 1000 \quad \forall i
\]
\[
{\rm Global constraint:} \; \sum a_i \ge 0.01
\]

<p>The optimization occurs in a space decomposed into $M$ contiguous blocks, each represented by $(x^{(m)}, \alpha^{(m)})$.</p>

<h3>Algorithm structure</h3>
1. Decompose sequence $a$ into $M$ contiguous blocks
2. Parameterize optimization problem in terms of block parameters $\theta$
3. Compute projected Newton step using sparse structure
4. Line-search for minimum $f$ in descent direction $d$
5. Update block parameters using $\theta_{\text{new}} = \theta_{\text{current}} + \alpha \cdot d$

<h2>Implementation Procedure</h2>

<h3>Step 3: AC1-bound calculation</h3>
<p>Compute autocorrelation bound using optimized convolution method:</p>
```python
def calculate_ac1(seq):
    n_seq = len(seq)
    # First pass: normalize by sum under constraints
    total = sum(seq)
    if total < 0.01:
        return float('inf')
    # Compute labeled central moments for autocorrelation
    conv_result = np.convolve(seq, seq, mode='full')
    max_val = np.max(conv_result)
    return 2 * n_seq * max_val / total**2
```

<h3>Step 4: Gradient projection</h3>
<p>Approximate the gradient using sparse difference methods:</p>
```python

    obj0 = calculate_ac1(seq)
    grad = np.zeros_like(seq)

        # Compute difference by modifying single elements
        seq_dif = seq.copy()
        seq_dif[idx] *= (0.9 if seq[idx] > 0 else 1.1)
        obj1 = calculate_ac1(seq_dif)
        grad[idx] = (obj1 - obj0) / 0.1
```

<h3>Step 5: Projected gradient update</h3>
<p>Update parameters with projected gradient and backtrack:</p>
```python
def update_parameters(params, learning_rate=0.1):
    seq = from_parameters(params)  # Conversion between optimization variables and raw sequence
    grad = estimate_gradient(seq)
    
    # Project onto feasible set
    grad_project = np.clip(grad * learning_rate, -0.2, 0.2)
    cand = seq + grad_project
    cand = np.clip(cand, 0, 1000)
    cand_sum = sum(cand)
    if cand_sum < 0.01:

        cand = cand * 0.01 / (cand_sum / sum(seq))

    alpha = 0.8
    k = 0
    while obj_new >= obj_old + armijo_factor * alpha and k < 20:
        grad *= 0.5
        k += 1

```
