The max function f(h) = max_k corr_k(h) is convex in h (since each corr_k is... wait, is corr_k convex in h?).

corr_k(h) = sum_i h[i]*(1-h[i+k]) = sum_i h[i] - sum_i h[i]*h[i+k]

The Hessian of h[i]*h[i+k] with respect to (h[i], h[i+k]) is [[0, 1], [1, 0]] which has eigenvalues 1 and -1. So h[i]*h[i+k] is neither convex nor concave. Therefore corr_k is not convex in h.

This means the max of corr_k is not necessarily convex, and subgradient methods might not converge to the global optimum. But they can still be useful as a heuristic.

The log-sum-exp approximation IS convex in h (since it's a composition of a convex increasing function with... wait, no. log-sum-exp of the corr_k values, where each corr_k is non-convex. So the log-sum-exp is also non-convex.

So the entire problem is non-convex, and all methods are heuristics. The key is to use multiple approaches and keep the best.

                best_c5 = c5_new
                best_h = h_new.copy()
                h_perturb = h_new.copy()
                break

    # Phase 6: Try smaller n values
    for n_try in [62, 64, 66, 68, 70, 72, 74, 76, 78, 80]:
        if remaining() < 50:
            break
        if n_try % 2 != 0:
            continue
        m_try = n_try // 2
        x_orig = np.linspace(0, 2, len(best_h))
        x_new = np.linspace(0, 2, n_try)
        h_interp = np.interp(x_new, x_orig, best_h)
        h_interp = project_feasible(h_interp, n_try / 2.0)
        q_try = h_interp[:m_try].copy()
        for beta in [3000, 10000, 20000]:
            if remaining() < 35:
                break
            q_new = run_q_lbfgs(q_try, n_try, beta, maxiter=1500)
            h_new = build_h_from_q(q_new, n_try)
            h_new = project_feasible(h_new, n_try / 2.0)
            c5_new = exact_score(h_new)[0]
            if c5_new < best_c5 - 1e-12:
                best_c5 = c5_new
                best_h = h_new.copy()
                q_try = q_new.copy()

    # Phase 7: Continued random restarts on best solution
    n_best = len(best_h)
    m_best = n_best // 2
    target_best = n_best / 2.0
    for i in range(30):
        if remaining() < 15:
            break
        q_cur = best_h[:m_best].copy() if n_best % 2 == 0 else best_h[:m_best].copy()
        noise = 0.01 + 0.005 * rng.rand()
        q_perturb = q_cur + rng.randn(m_best) * noise
        q_perturb = np.clip(q_perturb, 0.0, 1.0)
        q_new = run_q_lbfgs(q_perturb, n_best, 20000, maxiter=2000)
        h_new = build_h_from_q(q_new, n_best)
        h_new = project_feasible(h_new, target_best)
        c5_new = exact_score(h_new)[0]
        if c5_new < best_c5 - 1e-15:
            best_c5 = c5_new
            best_h = h_new.copy()

    # Phase 8: Final high-beta polish
    if remaining() > 20 and n_best % 2 == 0:
        q_final = best_h[:m_best].copy()
        for beta in [20000, 50000]:
            if remaining() < 15:
                break
            q_new = run_q_lbfgs(q_final, n_best, beta, maxiter=3000)
            h_new = build_h_from_q(q_new, n_best)
            h_new = project_feasible(h_new, target_best)
            c5_new = exact_score(h_new)[0]
            if c5_new < best_c5 - 1e-15:
                best_c5 = c5_new
                best_h = h_new.copy()
                q_final = q_new.copy()

    if remaining() > 20:
        h_new = run_full_lbfgs(best_h, n_best, 20000, 1000.0, maxiter=3000)
        c5_new = exact_score(h_new)[0]
        if c5_new < best_c5 - 1e-15:
            best_c5 = c5_new
            best_h = h_new.copy()

    # Final validation
    best_h = np.clip(best_h, 0.0, 1.0)
    n_out = len(best_h)
    best_h = project_feasible(best_h, n_out / 2.0)
    final_score, _ = exact_score(best_h)
    if final_score < best_c5:
        best_c5 = final_score

    return best_h, best_c5, n_out
