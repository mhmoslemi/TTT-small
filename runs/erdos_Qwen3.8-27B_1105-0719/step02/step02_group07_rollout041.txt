    """Local search on binary vectors via swap moves."""

    zeros = list(np.where(h == 0)[0])

            break

            zeros.append(best_b)

- Constraints: (2n-1) linear inequalities for the corr bounds + 1 equality for sum + 2n inequalities for bounds
- Total: O(n) constraints

This is a clean approach! Each iteration solves an LP, and the solution gives a lower bound on the true optimum (since we're minimizing a linear under-approximation of the max). The sequence of solutions should converge to a local optimum.

The advantage of this approach:
1. Each iteration is a fast LP solve (O(n³) at most, but practically very fast for n=126)
2. It naturally handles the non-convexity by iteratively adding linear constraints (the "outer approximation" method)
3. It's exact at each step (no approximation like log-sum-exp)

The disadvantage:
1. It might converge slowly (many iterations needed)
2. It's a local method (converges to a local optimum)
3. The LP might be infeasible if the linearization is too far from the true function

To address (3), I can use a "trust region" approach: limit how far h can move from h_curr. Add constraint ||h - h_curr||_∞ ≤ Δ for some trust radius Δ.
