Let me implement this. This will be much faster than smooth max because each iteration is O(n_k) for computing slopes and O(n_k^2) for finding the optimum (or O(n_k log n_k) with a linear-time convex hull trick).

Actually, for the 1D minimax of lines, there's a linear-time algorithm:
- The optimum is where the "upper envelope" is minimized
- We can use a binary search on t: for a given t, check if there exists q_s ∈ [0,1] such that all lines are ≤ t at q_s
- For line k: intercept_k + q_s * slope_k ≤ t ⟺ q_s ≤ (t - intercept_k)/slope_k (if slope_k > 0) or q_s ≥ (t - intercept_k)/slope_k (if slope_k < 0)
- So the feasible set for q_s is an interval [lo, hi]
- If [lo, hi] ∩ [0,1] is non-empty, t is feasible

This gives a binary search in O(n_k) per evaluation, O(n_k * log(precision)) total. Very fast!

OK so my algorithm will be:

```
        Update q_s
    Project to sum constraint (if needed) - but for symmetric, sum is automatically n/2
```

```python
    m = n // 2
    q = np.empty(m)

            h[interior] += diff / interior.sum()

def compute_cd_slopes(h, n_full, d_k, s, a, b):
    """Compute slope S_k for correlation k with respect to q[s].
    a = s (index in h), b = n_full-1-s (mirror index in h)
    d_k = shift for correlation k
    Returns the slope such that corr_k = C_k + q[s] * S_k
    """
    i_lo = max(0, -d_k)
    i_hi = min(n_full - 1, n_full - 1 - d_k)
    if i_lo > i_hi:
        return 0.0
    
    # slope contribution from h[a] (= q[s]):
    # +1 if a in [i_lo, i_hi] (first factor)
    # -h[a+d_k] if a in [i_lo, i_hi] (bilinear: h[a]*h[a+d_k])
    # -h[a-d_k] if a-d_k in [i_lo, i_hi] (bilinear: h[a-d_k]*h[a])
    slope_a = 0.0
    if i_lo <= a <= i_hi:
        slope_a += 1.0
        slope_a -= h[a + d_k]
    if i_lo <= a - d_k <= i_hi:
        slope_a -= h[a - d_k]
    
    # slope contribution from h[b] (= 1-q[s]):
    # The coefficient of (1-q[s]) is similar but with sign flipped for q[s]
    # h[b] = 1 - q[s], so d corr_k / d q[s] from h[b] terms = -d corr_k / d h[b]
    slope_b = 0.0
    if i_lo <= b <= i_hi:
        slope_b += 1.0
        slope_b -= h[b + d_k]
    if i_lo <= b - d_k <= i_hi:
        slope_b -= h[b - d_k]
    
    # Total slope wrt q[s]: slope_a (from h[a]=q[s]) + (-1)*slope_b (from h[b]=1-q[s])
    return slope_a - slope_b
```

- h[a] changes by (new_val - old_val) = delta
- h[b] changes by -(new_val - old_val) = -delta

The change in corr_k:
Δcorr_k = delta * (contribution of h[a] to corr_k at new values) + (-delta) * (contribution of h[b] to corr_k at new values)

But the "contribution" depends on the current values of neighboring h's, which are fixed. So:
Δcorr_k = delta * slope_a_k - delta * slope_b_k = delta * S_k

where S_k is exactly the slope we computed! So the update is:
corrs[k] += delta * S_k

This is O(active_k) per coordinate update. Total per round: O(m * active_k) = O(63 * 60) = 3780. Very fast!

Hmm wait, there's a problem with my incremental update. When I update q[s], the slopes for other coordinates change (because h changes). So the slopes I computed for coordinate s are only valid for that step. For the next coordinate s', I need to recompute slopes. That's fine - I'm computing slopes fresh for each coordinate.

But the issue is: when I update corrs[active_k] += delta * slopes, this is only correct if the slopes haven't changed. But they have changed (h changed). So the incremental update is slightly off.

For a small delta, this is a first-order approximation and should be fine. The periodic recompute every 5 rounds will correct any drift.

Actually, let me think more carefully. The slope S_k for coordinate s is:
S_k = contribution of h[a] at current h values - contribution of h[b] at current h values

When I change h[a] by delta and h[b] by -delta, the slope for coordinate s' (different from s) changes because h[a] and h[b] appear in the bilinear terms. But the change in corr_k is:
Δcorr_k = sum of changes = delta * S_k(s) for the coordinate s we just updated

This is exact for the first-order change. Higher-order terms (delta^2) are negligible for small delta.

So the incremental update corrs[active_k] += delta * slopes is a first-order approximation. For the CD to work correctly, I need the slopes to be recomputed after each update (which I do - I compute slopes fresh for each coordinate). import numpy as np
```python
from scipy.optimize import minimize
import time

def eval_score(h):
    n = len(h)
    dx = 2.0 / n
    return float(np.max(np.correlate(h, 1.0 - h, mode='full')) * dx)

def corr_raw(h):
    return np.correlate(h, 1.0 - h, mode='full')

def build_sym_h(q):
    m = len(q)
    h = np.empty(2 * m)
    h[:m] = q
    h[m:] = 1.0 - q[::-1]
    return h

def sym_from_h(h):
    n = len(h)
    m = n // 2
    q = np.empty(m)
    for i in range(m):
        q[i] = 0.5 * (h[i] + (1.0 - h[n - 1 - i]))
    return np.clip(q, 0.0, 1.0)

def project_feasible(x, target_sum):
    n = len(x)
    lo, hi = -1.5, 1.5
    for _ in range(60):
        mid = (lo + hi) / 2.0
        s = np.clip(x + mid, 0.0, 1.0).sum()
        if s > target_sum:
            hi = mid
        else:
            lo = mid
    h = np.clip(x + (lo + hi) / 2.0, 0.0, 1.0)
    diff = target_sum - h.sum()
    if abs(diff) > 1e-14:
        interior = (h > 1e-12) & (h < 1.0 - 1e-12)
        if interior.sum() > 0:
            h[interior] += diff / interior.sum()
    return np.clip(h, 0.0, 1.0)

def cd_sym(q, n_full, max_rounds=200, margin_frac=0.012, max_active=55,
           recompute_every=4, seed=0, bisection_depth=28):
    """Fast coordinate descent for symmetric parameterization with exact 1D subproblem."""
    m = n_full // 2
    dx = 2.0 / n_full
    rng = np.random.RandomState(seed)
    q = np.clip(q.copy(), 0.0, 1.0)
    h = build_sym_h(q)
    corrs = corr_raw(h) * dx
    best_score = float(corrs.max())

    n_corr = 2 * n_full - 1
    d_vals = np.arange(n_corr) - (n_full - 1)
    i_lo_all = np.maximum(0, -d_vals).astype(int)
    i_hi_all = np.minimum(n_full - 1, n_full - 1 - d_vals).astype(int)

    active_k = np.arange(n_corr)
    prev_score = best_score

    for rnd in range(max_rounds):
        if rnd % recompute_every == 0:
            max_c = float(corrs.max())
            threshold = max_c - max(margin_frac * max_c, 4e-7)
            active = np.where(corrs >= threshold)[0]
            if len(active) > max_active:
                top_idx = np.argsort(corrs[active])[::-1][:max_active]
                active = active[np.sort(top_idx)]
            active_k = active

        a_vals = d_vals[active_k].astype(int)
        ilo_a = i_lo_all[active_k]
        ihi_a = i_hi_all[active_k]
        n_act = len(active_k)
        if n_act == 0:
            active_k = np.arange(n_corr)
            a_vals = d_vals
            ilo_a = i_lo_all
            ihi_a = i_hi_all
            n_act = n_corr

        order = rng.permutation(m)

        for s in order:
            a = s
            b = n_full - 1 - s
            if a == b:
                continue
            qs = q[s]

            # Slope from h[a] = q[s]
            in_first_a = (a >= ilo_a) & (a <= ihi_a)
            a_plus_d = a + a_vals
            a_minus_d = a - a_vals
            valid_ap = in_first_a & (a_plus_d >= 0) & (a_plus_d < n_full)
            valid_am = (a_minus_d >= ilo_a) & (a_minus_d <= ihi_a) & (a_minus_d >= 0) & (a_minus_d < n_full)
            h_ap = np.zeros(n_act)
            h_am = np.zeros(n_act)
            if valid_ap.any():
                h_ap[valid_ap] = h[a_plus_d[valid_ap]]
            if valid_am.any():
                h_am[valid_am] = h[a_minus_d[valid_am]]
            slope_a = in_first_a.astype(float) - h_ap - h_am

            # Slope from h[b] = 1-q[s]
            in_first_b = (b >= ilo_a) & (b <= ihi_a)
            b_plus_d = b + a_vals
            b_minus_d = b - a_vals
            valid_bp = in_first_b & (b_plus_d >= 0) & (b_plus_d < n_full)
            valid_bm = (b_minus_d >= ilo_a) & (b_minus_d <= ihi_a) & (b_minus_d >= 0) & (b_minus_d < n_full)
            h_bp = np.zeros(n_act)
            h_bm = np.zeros(n_act)
            if valid_bp.any():
                h_bp[valid_bp] = h[b_plus_d[valid_bp]]
            if valid_bm.any():
                h_bm[valid_bm] = h[b_minus_d[valid_bm]]
            slope_b = in_first_b.astype(float) - h_bp - h_bm

            slopes = slope_a - slope_b
            if np.all(np.abs(slopes) < 1e-12):
                continue

            intercepts = corrs[active_k] - qs * slopes

            # Binary search on optimal t = min_{q_s in [0,1]} max_k (intercepts[k] + q_s*slopes[k])
            vals0 = intercepts
            vals1 = intercepts + slopes
            lo_t = float(min(vals0.min(), vals1.min())) - 0.01
            hi_t = float(max(vals0.max(), vals1.max())) + 0.01

            for _ in range(bisection_depth):
                mid_t = 0.5 * (lo_t + hi_t)
                pos = slopes > 1e-13
                neg = slopes < -1e-13
                q_hi = 1.0
                q_lo = 0.0
                feasible = True
                if pos.any():
                    ph = (mid_t - intercepts[pos]) / slopes[pos]
                    q_hi = min(q_hi, float(ph.min()))
                if neg.any():
                    nl = (mid_t - intercepts[neg]) / slopes[neg]
                    q_lo = max(q_lo, float(nl.max()))
                if not pos.any() and not neg.any():
                    if intercepts.max() > mid_t:
                        feasible = False
                if feasible and q_lo > q_hi:
                    feasible = False
                if feasible:
                    hi_t = mid_t
                else:
                    lo_t = mid_t

            t_star = hi_t
            pos = slopes > 1e-13
            neg = slopes < -1e-13
            q_lo_f = 0.0
            q_hi_f = 1.0
            if pos.any():
                q_hi_f = min(q_hi_f, float(((t_star - intercepts[pos]) / slopes[pos]).min()))
            if neg.any():
                q_lo_f = max(q_lo_f, float(((t_star - intercepts[neg]) / slopes[neg]).max()))
            q_opt = float(np.clip(0.5 * (q_lo_f + q_hi_f), 0.0, 1.0))

            delta = q_opt - qs
            if abs(delta) > 1e-14:
                q[s] = q_opt
                h[a] = q_opt
                h[b] = 1.0 - q_opt
                corrs[active_k] += delta * slopes

        if (rnd + 1) % recompute_every == 0:
            h = build_sym_h(q)
            corrs = corr_raw(h) * dx
            sc = float(corrs.max())
            if sc < best_score:
                best_score = sc
            if sc > prev_score * 1.005 and rnd > 10:
                break
            prev_score = sc

    h = build_sym_h(q)
    corrs = corr_raw(h) * dx
    sc = float(corrs.max())
    if sc < best_score:
        best_score = sc
    return q, best_score, h

def smooth_max_sym(q, n_full, beta, maxiter=100):
    """L-BFGS-B optimization of smooth max in symmetric parameterization."""
    m = n_full // 2
    dx = 2.0 / n_full
    n_corr = 2 * n_full - 1

    def obj_grad(x):
        q_x = np.clip(x, 0, 1)
        h = build_sym_h(q_x)
        corrs = corr_raw(h) * dx
        max_c = corrs.max()
        shifted = corrs - max_c
        w = np.exp(beta * shifted)
        ws = w.sum()
        if ws < 1e-30:
            w = np.ones(n_corr) / n_corr
        else:
            w /= ws
        val = max_c + np.log(ws) / beta
        grad_q = np.zeros(m)
        for k in range(n_corr):
            if w[k] < 1e-14:
                continue
            d_k = k - (n_full - 1)
            i_lo = max(0, -d_k)
            i_hi = min(n_full - 1, n_full - 1 - d_k)
            if i_lo > i_hi:
                continue
            idx = np.arange(i_lo, i_hi + 1)
            dh_first = (1.0 - h[idx + d_k])
            dh_second = -h[idx]
            # Map to q gradient
            for r in range(m):
                g = 0.0
                # h[r] = q[r], contributes dh_first[r] if r in idx
                if i_lo <= r <= i_hi:
                    g += dh_first[r - i_lo]
                if i_lo + d_k <= r <= i_hi + d_k and 0 <= r < n_full:
                    g += dh_second[r - i_lo - d_k]
                # h[n-1-r] = 1-q[r], contributes -dh at n-1-r
                r2 = n_full - 1 - r
                if i_lo <= r2 <= i_hi:
                    g -= dh_first[r2 - i_lo]
                if i_lo + d_k <= r2 <= i_hi + d_k and 0 <= r2 < n_full:
                    g -= dh_second[r2 - i_lo - d_k]
                grad_q[r] += w[k] * dx * g
        return val, grad_q

    bounds = [(0.0, 1.0)] * m
    try:
        res = minimize(obj_grad, q, jac=True, method='L-BFGS-B',
                      bounds=bounds, options={'maxiter': maxiter, 'ftol': 1e-14, 'gtol': 1e-8})
        q_new = np.clip(res.x, 0, 1)
    except Exception:
        q_new = q.copy()
    h_new = build_sym_h(q_new)
    return q_new, eval_score(h_new), h_new

def transfer_to_n(h_old, n_new):
    n_old = len(h_old)
    x_old = (np.arange(n_old) + 0.5) * 2.0 / n_old
    x_new = (np.arange(n_new) + 0.5) * 2.0 / n_new
    h_new = np.interp(x_new, x_old, h_old)
    return project_feasible(h_new, n_new / 2.0)

def binary_push(q, n_full, thresh=0.3):
    """Push q values toward 0 or 1 if they exceed threshold distance from center."""
    m = len(q)
    q_new = q.copy()
    for i in range(m):
        if q[i] > 0.5 + thresh:
            q_new[i] = 1.0
        elif q[i] < 0.5 - thresh:
            q_new[i] = 0.0
    h_new = build_sym_h(q_new)
    return q_new, h_new, eval_score(h_new)

def smooth_max_full(h, n_full, beta, maxiter=100):
    """L-BFGS-B on full h with sum constraint handled by penalty."""
    dx = 2.0 / n_full
    n_corr = 2 * n_full - 1

    def obj_grad(x):
        h_x = np.clip(x, 0, 1)
        corrs = corr_raw(h_x) * dx
        max_c = corrs.max()
        shifted = corrs - max_c
        w = np.exp(beta * shifted)
        ws = w.sum()
        if ws < 1e-30:
            w = np.ones(n_corr) / n_corr
        else:
            w /= ws
        val = max_c + np.log(ws) / beta
        # Penalty for sum constraint
        sum_val = h_x.sum()
        penalty = 50.0 * (sum_val - n_full / 2.0) ** 2
        val += penalty
        grad = np.zeros(n_full)
        for k in range(n_corr):
            if w[k] < 1e-14:
                continue
            d_k = k - (n_full - 1)
            i_lo = max(0, -d_k)
            i_hi = min(n_full - 1, n_full - 1 - d_k)
            if i_lo > i_hi:
                continue
            idx = np.arange(i_lo, i_hi + 1)
            grad[idx] += w[k] * dx * (1.0 - h_x[idx + d_k])
            grad[idx + d_k] += w[k] * dx * (-h_x[idx])
        grad += 100.0 * (sum_val - n_full / 2.0)
        return val, grad

    bounds = [(0.0, 1.0)] * n_full
    try:
        res = minimize(obj_grad, h, jac=True, method='L-BFGS-B',
                      bounds=bounds, options={'maxiter': maxiter, 'ftol': 1e-14, 'gtol': 1e-8})
        h_new = project_feasible(np.clip(res.x, 0, 1), n_full / 2.0)
    except Exception:
        h_new = project_feasible(h.copy(), n_full / 2.0)
    return h_new, eval_score(h_new)

            # Smooth max with high beta
            if rem() > 20:
                q_m, c5_m, h_m = smooth_max_sym(q_fin, n_fin, 1500, maxiter=100)
                if c5_m < best_c5:
                    best_c5 = c5_m
                    best_h = h_m.copy()

                # One more CD
                if rem() > 10:
                    q_f2, c5_f2, h_f2 = cd_sym(sym_from_h(best_h), n_fin, max_rounds=100,
                                              margin_frac=0.005, max_active=80,
                                              seed=seed + 40000)
                    if c5_f2 < best_c5:
                        best_c5 = c5_f2
                        best_h = h_f2.copy()

    # Validate and return
    if best_h is None:
        m_fb = 63
        x_fb = np.linspace(0, 1, m_fb)
        q_fb = (0.5 + 0.3 * np.sin(2 * np.pi * x_fb)).clip(0, 1)
        best_h = build_sym_h(q_fb)

    best_h = np.asarray(best_h, dtype=float).reshape(-1)
    n_out = len(best_h)
    best_h = project_feasible(best_h, n_out / 2.0)
    best_h = np.clip(best_h, 0.0, 1.0)
    best_c5 = eval_score(best_h)

    return best_h, best_c5, n_out
```
