A better approach: **Iterative active-set method**
1. Start with some h
2. Compute all corr_k
3. Find the active set A = {k : corr_k > max_corr - ε}
4. Solve: minimize (1/|A|) * sum_{k in A} corr_k(h) subject to constraints
   (or minimize max over A, which is the same if they're all close)
5. Update h
6. Repeat

This focuses the optimization on the binding constraints and should converge faster.

- Bounds: 0 ≤ h_i ≤ 1, t ≥ 0
