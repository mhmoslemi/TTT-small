1. Approach and rationale

The current parent is close to the record but the prior program appears to be strongly attracted to the same local basin: a reduced symmetric representation followed by smoothed max/log-sum-exp descent, active-set epigraph refinement, and further epigraph restarts from the same parent. Those methods are excellent for tightening a local minimum, but a gap of only about `1.4e-4` to the target record can be blocked by a non-smooth local maximum over correlation lags. To obtain a materially different chance at improvement, the proposed algorithm does not make a single deterministic local refinement the main engine. It treats the exact discrete objective as a strict acceptance oracle and drives it from several structurally different feasible basins.

The primary search is built around the exact feasible half-representation

h = [q, 1 - reverse(q)]

for even n, and the analogous odd construction with a fixed center value 1/2. Every real or binary vector q in [0,1]^m yields a feasible h automatically: 0 <= h_i <= 1 and sum(h) = n/2. This gives a low-dimensional, exactly feasible manifold and enables cheap binary mutation: flipping an entry of q also flips the complementary mirrored entry of h, so the total sum remains n/2. This feasibility property is used to run an exact-objective stochastic binary search, not a surrogate search.

The new plan combines four complementary mechanisms:

A. Exact binary q-space simulated annealing. Binary q-vectors correspond to step functions with exact integral and with equal totals enforced by the mirror-complement construction. Binary local/m жилищ spaces expose structurally different combinatorial basins from the continuous parent. The exact evaluator is used to accept or reject each move with Metropolis cooling.

B. Exact one-coordinate continuous descent and exact block recombination. Starting from all promising binary and fractional elites, each q coordinate is exactly minimized or contracted using the true objective. The fractional space is also explored by exact neutral and guided moves, line searches, elite convex combinations, and basin re-entry acceptance. This refines binary combinatorial candidates without relying on a gradient.

C. Elite pool and recombination search. The algorithm maintains a small pool of feasible binary/fractional q candidates. Candidate construction is not restricted to restarting the global optimizer from the original parent; it recombines and perturbs low-score elites accepted by the exact objective.

D. Local exact active-lag epigraph refinement from many diverse elites. This is a conventional descent mechanism, but it is only a final deepening mechanism from candidates produced by the binary and exact coordinate engines. Each epigraph subproblem is judged by re-evaluating all lag correlations exactly, so a solver-converged value is never trusted.

The central idea is thus: exploit the automatically feasible low-dimensional representation to perform exact combinatorial and coordinate search across multiple basins; only afterwards use nonlinear active-constraint solvers to polish promising elites. This differs materially from a parent-polishing algorithm because structure-changing binary/large-motion search precedes refinement, and candidate acceptance is always exact.

Limitations and non-claims:

- The mirror-complement q representation is a constrained feasible ansatz. It can miss an asymmetric optimum. It is retained because it provides exact feasibility, half the dimensions, and enables binary moves preserving the discrete mean. A full non-symmetric parent is still evaluated as a candidate, and final candidates are also returned in full feasible format. No global optimality over the unrestricted original problem is claimed.

- Simulated annealing and coordinate descent are local probabilistic/local methods. They are expected to improve basin selection, but there is no certifiable guarantee that the target `0.3808` will be reached.

- The active epigraph subproblems are nonconvex in the original bilinear terms. They are SQP/epigraph-style local models. Their results are accepted only after exact re-evaluation.

corr_full = np.correlate(h, c, mode="full"),
score(h) = max(corr_full) * dx.

`score` returns a scalar and also the exact full correlation vector when needed. The necessary outputs are `n_points`, `h_values`, and the exact reported `c5_bound = score(h_values)`. All variables and reported bounds use the same finite discrete objective. The zero lag and all positive and negative lags must be included. Do not replace the objective by an autocorrelation identity unless exactly derived for every lag boundary; the formula above is authoritative.

Feasibility rules:

- `0.0 <= h[i] <= 1.0`.
- `sum(h) * dx = 1.0` numerically, i.e. `sum(h) = n/2` within tolerance.
- Floating-point waterfilling or final single-coordinate repair is required for arbitrary full-space candidates.
- Every returned q-built candidate is first made numerically sum-correct using only a tiny adjustment amount, then scored.

2.2 Exact mirror-complement representation

For even n = 2m, define

q = q[0..m-1] ∈ [0,1]^m,
h[0:m] = q,
h[m:2m] = 1 - reverse(q).

For odd n = 2m + 1, define

q = q[0..m-1] ∈ [0,1]^m,
h[0:m] = q,
h[m] = 0.5,
h[m + 1:2m + 1] = 1 - reverse(q).

In both cases, clipping q ensures entries are in [0,1]. Algebraically,

sum(h) = sum(q) + sum(1 - q) = m

for even n, hence sum(h)=n/2. With a floating-point final repair step, the same is enforced numerically for odd/even candidates.

The representation maps q to n-dimensional full space but reduces unconstrained continuous variables from n to m. A real optimum in this subspace is a valid upper bound for original Erdős overlap as long as final feasibility and scoring are exact. Asymmetric minima outside this manifold cannot be guaranteed found.

2.3 Feasible joint repair

For arbitrary full vectors z that may violate the bounds or exact mean, use a bisection waterfill repair. Let target = n/2.

Solve for lambda such that

p(lambda) = sum(clip(z - lambda, 0, 1)) = target

by bisection over an interval large enough to include z. For 70 to 90 iterations:

- choose lambda_mid = (lambda_low + lambda_high) / 2,
- compute y = clip(z - lambda_mid, 0, 1),
- if sum(y) > target, search with a larger shift, so lambda_low = lambda_mid,
- otherwise lambda_high = lambda_mid.

Set y = clip(z - (lambda_low + lambda_high)/2, 0, 1).

Let delta = target - sum(y). If |delta| is below `1e-12`, use y directly. Otherwise repair exactly:

- If delta > 0, repeatedly find an index with `y[i] < 1.0`; add `min(delta, 1.0 - y[i])` to `y[i]` and reduce delta.
- If delta < 0, repeatedly find an index with `y[i] > 0.0`; add delta (negative value) and clamp according to tolerance; repeat until delta is below `1e-12`.
- If no index with delta > 0 exists, fail for that target and recover from the parent or a q-built candidate.

This waterfilling plus residual incremental repair is a valid joint feasibility mechanism and avoids the invalid operation of clipping followed by independent proportional rescaling.

For a candidate built from q, sum tolerance should already be tiny. Apply a final repair but choose a coordinate changed by the smallest feasible amount if needed.

2.4 Exact coordinate objective

For q-space exact evaluation:

`q_to_h(q, n)` builds h according to the exact rule. Then

`score_q(q, n)` evaluates exact `score(h)`, and returns `(score_val, corr_vec)`.

The exact coordinate objective for scalar coordinate j at base q_base is

`g_j(x) = score_q(q_base with q_base[j] replaced by x, n)`.

Only x enters bounds: `0 <= x <= 1`. Other q entries are fixed.

This exact scalar function is non-differentiable because it is a maximum over lag correlations. A practical maximization replacement cannot be accepted as an improvement unless exact objective evaluation confirms it.

2.5 Correlation orientation calibration and manual gradients

The evaluator is numpy's linear full correlation. For analytic gradient calculations, define a manual correlation convention for testing:

For lag index k in `[0, 2n-2]` and d = k - (n-1):

- if d >= 0:

  `raw_overlap(d) = sum_{i=0}^{n-d-1} h[i+d] * (1 - h[i])`.

- if d < 0, `s = -d`:

  `raw_overlap(-s) = sum_{i=0}^{n-s-1} h[i] * (1 - h[i+s])`.

A helper computes the 2n-1 vector for at least one random high-dimensional feasible vector and one random unfeasible vector. Compare it to `np.correlate(h, 1-h, mode="full")`. If the match is within tolerance, use this orientation. If the reversed vector matches the numpy evaluator, store an index permutation mapping from manual lag k to evaluator lag `n-1-k`. If neither convention reliably matches, do not use analytic gradients in the epigraph phase; that phase can continue using a finite-difference fallback only if relaxed direction calculations would not risk wasted time. Exact non-gradient methods remain available.

For a fixed lag d, the unscaled full derivative of `raw_overlap(d)` with respect to the full h vector is:

If d >= 0:
  D[d] += 1 - h[i] at positions `h[i+d]`; vectorized equivalent:
  D[d: n] += 1 - h[0 : n - d]
  D[0 : n - d] -= h[d : n]

If d < 0 and s = -d:
  D[0 : n - s] += 1 - h[s : n]
  D[s : n] -= h[0 : n - s]

Multiply by dx if the derivative is needed in scaled units.

For the q-to-even-h map, let F be the unscaled full derivative for a scalar objective. q derivative:

G_q[j] = F[j] - F[n - 1 - j]

because q_j contributes positively to h_j and negatively to h_{n-1-j}. For odd n, center derivative is zero and the same first m entries minus mirror entries apply.

The q epigraph variables are `(t, q_0,...,q_{m-1})`. The scaled correlation loss for q is `corr_q(k)*dx` where corr_q is evaluated through the builder. Scale active constraint derivatives by dx as well.

2.6 Active-lag epigraph model

At a q start point, define scaled correlations `r_k(q)`. Choose an active set A, usually high correlation lags plus previously violated lags. Solve a local problem

minimize t
subject to 0 <= q_i <= 1,
           r_k(q) <= t for k in A.

This is an epigraph relaxation because constraints outside A are hidden. After solve, exact all-lag evaluation tests for hidden violations. If some are hidden above the solved t, add them and repeat. This process can improve a local minimum because hidden constraints become explicit and new descent directions may be added.

The formulation contains nonlinear quadratic constraints. `SLSQP` or `trust-constr` can be used as local solvers. Their converged models are not global. Only exact evaluations define a feasible lower value.

3. Implementation procedure

The program must define top-level helpers only. No filesystem, no network, no hard-coded parent table. It uses the supplied `initial_h_values` array when available.

3.1 Time and candidate bookkeeping

Define running timer functions:

- `start_time = time.time()` at entry.
- `remaining_time() = budget_s - (time.time() - start_time)`.
- `hard_deadline = start_time + budget_s - final_reserve_s`, with `final_reserve_s = 60.0`. This allows final feasibility and score correction.
- Before each solver call or stochastic run, verify enough elapsed projection remains. Any heavy loop should check the deadline after a bounded group of accepted/rejected evaluations.

Maintain a best candidate state containing:

- `best_h`: full feasible vector currently accepted by exact objective.
- `best_c5`: exact objective value for `best_h`.
- `best_n`: length of `best_h`.
- A pool of candidate q-vectors and associated scores for mirror space, up to 16 entries. Pool key is `score_q`; duplicate/trivially close q-vectors need not be retained unless scores differ by meaningful tolerance.
- Tolerance `correct_tol = 1e-12` for evaluation tolerance and output feasibility tolerance.
- If `best_c5` decreases by at least `max(1e-13, best_c5*1e-12)`, replace the global best. If scores are within `2e-12` and a candidate has smaller n, consider the smaller candidate preferable for final output.

Candidate update procedure `accept_full_candidate(h, exact_score_value)`:

1. coalesce exact if not computed
2. repair full feasibility via waterfill plus residual repair.
3. re-score repaired h exactly.
4. if repaired score is less than reported candidate score by overrun, optionally update the resolved candidate score and report final exact value later. For selection, use repaired score.
5. compare to pool best and global best.

This guarantees the global best is always validated. For q-produced candidates, also save q variants for faster re-entry.
