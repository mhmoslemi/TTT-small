1. Approach and rationale

1.1 Central idea

The evaluator treats any returned feasible vector as an exact discrete construction:

C5(h,n) = max_{r=0,...,2n-2} raw_r(h) * (2/n),

where

raw_r(h) = sum_{i in I_r} h_{i+r-(n-1)} * (1 - h_i),

and the index set I_r contains precisely the indices for which both h_i and h_{i+r-(n-1)} lie inside [0,n-1]. The proposal keeps this exact evaluator as the only criterion. The new search is organized around two mechanisms that are different from the parent’s smooth-max local polishing:

1. A mixed-integer linear orientation program for even dimensions. For a binary candidate, each raw_r is an integer count of ordered pairs (i,j) such that x_j=1 and x_i=0 at offset j-i. All orientation constraints and the max constraint are linear after exact item logic is encoded. An MIP can therefore minimize the largest orientation count exactly on a chosen even grid. This produces extremely strong binary skeletons with a different local structure than the continuous soft-max parent.

2. An active, exact-offset linearized lowering descent. Starting from a parent, MILP seed, or rotated interpolation, solve a linear program that finds a bounded search direction whose exact first-order offsets are as close as possible to a slightly reduced target. Repeated exact line search and feasibility projection then accept only true reductions measured by the authoritative correlate formula. This is driven by individually indexed offset gradients, not by an averaged soft maximum.

The overall program verifies all constructions using the exact evaluator. Surrogates and relaxations can search, but no reported value is based on one. The result remains feasible because every stored output is re-projected and re-evaluated before return.

1.2 Why this might improve the supplied parent

The supplied construction lies in a flat local basin: many offsets are almost tied and only a small exact shrinkage is required (from about 0.380934 toward 0.38085). A smooth log-sum objective averages a broad offset population, even at high beta, and can poison useful local directions. The proposed MILP eliminates exact maximum-offset count in a binary space and creates structurally new balanced starting states. These can enter different continuous basins once passed through high-beta smoothing and post-processing.

The active linearized operation directly handles which exact grid offsets must improve. If h has a true feasible descent into slightly lower maximum count, linearized offsets point to it; exact line search pays the curvature cost immediately and rejects false constructions. A tiny local dip below the parent does not require proof of a global solution. It only requires one accepted vector with lower exact score.

1.3 Facts versus hypotheses

Facts:

* The objective is linear correlation h vs. 1-h over the full array and both positive and negative offsets, not autocorrelation or circular correlation.
* The exact offset family contains 2n-1 terms.
* Boundary terms are kept because each offset sums only overlapping indices.
* The MILP is linear after explicit auxiliary variables are introduced; it is valid only after minimizing with binary x and reading the corresponding binary sequence. A fractional MILP solution is not a valid exact proof unless rounded or continuously repaired and subsequently evaluated.
* The exact directional derivative of every offset is given by simple closed-form terms on the same overlapping pairs.

Hypotheses:

* A binary skeleton generated by the minimal orientation MIP gives a better family of continuous starting points than random or perturbed continuous states.
* An OFFSET-adaptive linearized method can accept a lower exact score in the narrow basin around the parent, possibly on propagation distance beyond the current alphabet/dimension.
* The parent remains an essential fallback. Because the underlying squared vector equation is nonconvex, no claimed proof exists for any global low solution. A winner only has to be one exact feasible vector with smaller bound.

Important limitations:

* MIP minimization is theoretically expensive and may be solved only approximately or not to proof_BOUNDS under a short timeout. The best feasible objective is kept.
* Exact nonlinear correction cannot be guaranteed if all target estimates are too small or directions are curvature-rejected.
* Solver failures, numerical limits and tiny time overrun bypass every MIP limitations; any fallback valid output remains feasible and bounded above by reported exact value.
* Output lower than target might fail to materialize. The strongest fallback is the best previously validated exact score, normally the parent.
