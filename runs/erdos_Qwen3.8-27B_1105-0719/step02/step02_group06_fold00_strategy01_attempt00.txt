1. Approach and rationale

The improvement method will abandon the previous “smoothed max plus symmetric SLSQP epigraph” formulation as the primary engine and replace it with a stochastic exact one-dimensional line-search descent in the original nonnegative vector variables. The main variable is the supplied vector h itself; no symmetry compression is required, and every accepted move must preserve feasibility and exactly improve the authoritative evaluator.

The method is built around a precise algebraic observation: if finitely many coordinates are changed by a common scalar parameter t in a fixed sum-preserving affine direction, then for every correlation lag the unknown C5 objective term is exactly a polynomial of degree at most 2 in t. Therefore, when a feasible direction is proposed, the minimal value along that entire direction can be found (or reliably approximated) without numerical finite differences of the max objective and without an outer smooth surrogate. The method repeatedly proposes feasible directions, optimizes the exact max-over-lags curve along them, and uses an annealed acceptance rule to escape local minima. It uses the global objective directly, so every final returned value is checked against the evaluator rather than inferred from a model.

A short discrete simulated-annealing module is used first only as a seeding heuristic. It is not used to certify feasibility. It produces card-constrained binary vectors; these are converted to feasible continuous seeds. This is deliberately different from the previous algorithm because it is a discrete branched-seeding mechanism for escaping symmetric smooth minima. A final optional conservative epigraph polish may be run for completeness, but its exploit will not be trusted; candidate acceptance still uses the actual evaluator and projectable feasibility corrections, as required.

Important facts and hypotheses that await empirical validation:
