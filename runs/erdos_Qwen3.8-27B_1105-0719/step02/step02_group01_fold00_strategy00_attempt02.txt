## 1. Approach and rationale

### 1.1 Core idea
Use a continuous pairwise-transfer line search that optimizes a *one-dimensional slice* of the exact discrete objective while preserving the sum constraint exactly at every evaluated point. This is different from the previous log-sum-exponential/SLSQP smoothing and differential/gradients path. The important structural fact is that, when only two coordinates are changed as \(h_i\gets h_i+t\), \(h_j\gets h_j-t\), each correlation-lag curve is either linear or quadratic with a positive quadratic coefficient. Therefore the exact C₅ value along that pairwise direction is the maximum of affine and convex quadratic functions and is convex in the line-search parameter. A one-dimensional golden-section search gives the globally optimal improvement along that transfer direction using only exact grid quantities.

This local line minimization spans the full tangent space of the equality constraint \( \sum h = n/2 \) through pairwise transfer directions. Since every feasible direction preserving the sum is a linear combination of vectors \(e_i-e_j\), the method explores a genuinely different class of candidate moves: exact line optima on small pairwise subspaces, instead of penalized global descent curves such as log-sum-exp continua. Expected benefit: jumps to nearby valleys that smooth/damped multiteam gradient methods miss; lower overshoots because there is no penalty relaxation inside a line step.

### 1.2 Known structure and why it is useful
For a correlation lag \(m\), with center \(c=n-1\), define the finite, non-normalized correlation term
\[
C_m(h)=\sum_{p \text{ such that } 0\le p,\; p+m-c < n} h_p\bigl(1-h_{p+m-c}\bigr).
\]
When only pair \((i,j)\) is updated with \(t\), the only quadratic terms involve the two terms in which the updated pair appears. In \(C_m\), either both coordinates appear as the source-target pair in the same lag, or neither appears in that quadratic pair. No other topological dependencies occur. The exact translated objective along the line is computable as:
\[
C_m(h(t)) = C_m(h(0)) + \alpha_m(i,j)t + \beta_{ij}(m)t^2,
\]
where only two lags have \(\beta=1\) and all others have \(\beta=0\). Since the functions have nonnegative quadratic coefficient and linear functions are convex, the maximum over lags is convex. Therefore exact golden section on that curve is safe and quicker than multi-dimensional smoothing and repeated finite problems under correlations.

### 1.3 Search layer
The deterministic exact line search is a high-quality local minimizer. To reduce risk of being trapped by a nearby basin, add two layers:

* **Pair-selection from stable evaluated shifts:** prefer changes between coordinates having opposing effect on current max shifts. This exact coordinate-direction selection avoids arbitrary changes on near-flat periods.
* **A population/basin hop layer:** keep top finite local results from multiple transformations of the parent. The population uses limited evaluations and small perturbations/allocation tag; after each population it uses exact local minimization, parental memory and best-value exact check before storing the best value. This runs a globally-oriented stochastic layer rather than only true unline from one currently optimal global problem with locally low C₅.

This produces a different possible cope from the earlier program: the dominated algorithm will be dominated at coarse early overkill via exact line-over flex radicale calculate before alternative moves, rather than randomized-p第二届(old motions).
