Let me define offset = k - (n-1). Then c[k] = sum_i h[i] * (1-h[i+offset]) for valid i and i+offset.

When h[i] goes from 1 to 0:
- The term h[i]*(1-h[i+offset]) was (1-h[i+offset]), now 0.
  - Valid when 0 ≤ i+offset < n, i.e., -i ≤ offset ≤ n-1-i
  - In array indices: k = offset + (n-1), so k ranges from (n-1-i) to (n-1+n-1-i) = (2n-2-i)
  - Delta at these k: -= (1-h[i+offset]) = -(1-h[i+offset])

- The term h[i-offset]*(1-h[i]) was h[i-offset]*1 = h[i-offset], now h[i-offset]*0 = 0.
  - Valid when 0 ≤ i-offset < n, i.e., i-n+1 ≤ offset ≤ i
  - In array indices: k = offset + (n-1), so k ranges from (i-n+1+n-1) to (i+n-1) = i to i+n-1
  - Wait: offset ranges from i-n+1 to i, so k = offset+(n-1) ranges from i to i+n-1
  - Delta at these k: -= h[i-offset]

When h[j] goes from 0 to 1:
- The term h[j]*(1-h[j+offset]) was 0, now (1-h[j+offset]).
  - Valid when 0 ≤ j+offset < n, i.e., -j ≤ offset ≤ n-1-j
  - Delta: += (1-h[j+offset])

- The term h[j-offset]*(1-h[j]) was h[j-offset]*1 = h[j-offset], now h[j-offset]*0 = 0.
  - Valid when 0 ≤ j-offset < n, i.e., j-n+1 ≤ offset ≤ j
  - Delta: -= h[j-offset]

Now let me rewrite in terms of the ms array where ms[m] = offset for m = 0, 1, ..., 2n-2:
ms[m] = m - (n-1) for m = 0, ..., 2n-2
So ms = [-(n-1), -(n-2), ..., -1, 0, 1, ..., n-2, n-1]

For h[i] going 1→0:
- First part: offset in [-i, n-1-i], i.e., ms in [-i, n-1-i]
  - delta[ms in range] -= (1 - h[i + ms[valid]])
  
- Second part: offset in [i-n+1, i], i.e., ms in [i-n+1, i]
  - delta[ms in range] -= h[i - ms[valid]]

For h[j] going 0→1:
- First part: offset in [-j, n-1-j]
  - delta += (1 - h[j + ms[valid]])
  
- Second part: offset in [j-n+1, j]
  - delta -= h[j - ms[valid]]
