1. Approach and rationale

1.1 Central idea

The task is an upper-bound construction problem: find a finite sample vector
h satisfying 0 <= h[i] <= 1 and sum(h[i]) = n/2 for which the evaluator

C5(h) = max(np.correlate(h, 1-h, mode='full')) * (2/n)

is as small as possible. The supplied parent has already been optimized by
smooth-max local solvers, so a straightforward rerun of the same soft objective
is unlikely to yield a new construction below the current parent. The proposed
method keeps the exact evaluator as the only acceptance criterion, but searches
with a different local geometry: at each point, it linearizes all, or a carefully
selected subset of, the exact normalized lag constraints and solves a linear
programming subproblem for a direction that reduces the linearized maximum over
those constraints. It then tests that direction on the original nonlinear
objective with a conservative exact line search. The method is followed by
target-slice retries, dimension-preserving transformations, complementary
extreme starts, and a compact group of standard smooth-max fallbacks.

The key difference from the previous smooth-max or epigraph solvers is the
choice of local descent rule. Instead of minimizing a global log-sum-exp surrogate
or a nonlinear epigraph with SLSQP, this algorithm solves a linear model for
a direction that changes all selected exact lag constraints. The LP model retains
the actual gradients of exact lag correlations and respects feasibility constraints
through step bounds and an exact line search. Candidate improvements are accepted
only where the original, unsmoothed evaluator decreases. The code therefore does
not substitute a surrogate score for the requested bound.

1.2 Why this could help

For a measured maximum near a local stagnation point, the nonlinear improvement
problem is dominated by a few lag constraints whose gradients are nearly in
conflict. A smooth maximum averages these constraints. A target epigraph can
constrain them but still solves a nonlinear program whose direction depends on
the entire selected feasible set. In contrast, the active-linear-direction
mechanism exactly implements the first-order nonsmooth directional test: solve
for a feasible sum-preserving direction that most reduces the predicted maximum,
then check whether the actual nonlinear product terms allow the corresponding
path. Since exact corr_h_lag(h) = np-correlation terms are bilinear, the linearized
direction is often useful near the current point, and the exact line filter
prevents rejection or false acceptance. Multiple combinations of active
subset size, trust magnitude, target offset, and starting dimensions produce
several local-addressing directions. This can escape a flat soft-minimum basin
if the true local geometry is not perfectly approximated by a smoothed scalar.

The method is heuristic. Because the original objective is bilinear and the
problem is nonconvex, the LP and the line search are local and provide no global
optimality certificate. Constructive improvements may require candidates built
outside the main objective basin. That is why this plan integrates distinct
valid starting families and an explicit fallback; candidates are judged only by
the exact evaluator, and the valid best-known construction is always retained.

1.3 Scope of claims

Facts:
- The relation between exact correlation, dx, sum-target, and feasible boxes is
  exactly preserved.
- The returned vector is validated against the exact constraints and evaluated
  by the exact evaluator formula.
- The main bounded optimization subproblem is a constrained linear LP defined by
  gradients of exact constraints, not a hand-tuned scalar score.

Hypotheses:
- The target gap from approximately 0.380934 to less than 0.3808 is within the
  reach of repeated locally different first-order searches, exact restarts,
  and complementary starts.
- Lower sample counts might yield competitive exact bounds; the procedure tests
  and retains them only if the exact score justifies it.
- Candidate diversity across shifted and anti-complement bases can reach local
  basins unavailable to finishing the supplied continuous parent.

There is no guarantee that any single phase improves the parent. The best valid
construction found, or the valid fallback supplied by the environment, will be
returned before the time limit.

2. Mathematical specification

2.1 Exact representation and scoring at runtime

For a vector h of length n:

dx = 2.0 / n
target_sum = n / 2.0
f(h) = np.correlate(h, 1.0 - h, mode='full')
C_exact(h) = dx * max(f(h))

The vector has 2n-1 lag entries. Indexing must remain linear and finite. The
computation must never replace the above by circular correlation, only one
side positive lags, autocorrelation, absolute-value reductions, or an autocorr
relationship without precisely matching the evaluator.

For every candidate dimension, dx and target_sum are recomputed from its length.
Comparisons among candidates use their individually recomputed C_exact values,
not raw correlation values from different n.

2.2 Lag indexing and derivatives

Let normalized objective values be:

F_k(h) = dx * [np.correlate(h, 1-h, mode='full')][k],
k = 0, 1, ..., 2n-2

For lag k, define lag offset

d = k - (n - 1).

Following numpy correlate, the corresponding raw term is

raw_k(h) = sum over valid q of h[q + d] * (1 - h[q]),

where q is constrained so that both q and q+d lie between 0 and n-1. Equivalently,
for q from max(0, -d) to min(n-1, n-1-d):

p = q + d

Enumerate valid q in this finite overlap. For d=0, the derivative is

grad_raw_k[i] = 1 - 2*h[i], for all i

because each term is h[i]*(1-h[i]). For d != 0, for every valid overlap pair
(q,p):

grad_raw_k[p] += 1 - h[q]
grad_raw_k[q] += -h[p]

The normalized gradient used in the LP is obviously

grad_F_k = dx * grad_raw_k.

This indexing convention and derivative formula must be used both in the LP and
in the optional fallback smooth solvers. A small check is sufficient to catch
console mistakes. The returned bound is direct by recomputing C_exact via
np.correlate, independent of gradient code; nevertheless smaller step proposals
can rely on consistent formulas.

2.3 Feasibility and joint projection

Every candidate must satisfy both the box constraints and the same-length sum
exactly within numerical tolerance. Use a scalar monotone shift projection.

Given arbitrary z length n and target_sum = n/2, define for scalar s

g(s) = sum(clip(z - s, 0, 1)).

g(s) is continuous and nonincreasing in s. Bracket by s_min = min(z)-n and
s_max = max(z)+n to ensure g(s_min) >= target_sum and g(s_max) <= target_sum.
Bisect about 80 to 120 times, or until absolute residual < 1e-13. Set

h = clip(z - s*, 0, 1).

If residual remains above about 1e-12 due to floating error and there are open
indices a with 1e-12 < h[a] < 1 - 1e-12, distribute the excess error uniformly
over those entries, then clip again. If no open entries are available, as happens
for valid integer or edge-constrained states, the state is feasible when residual
is below 1e-10 absolute. Any random artificial failure that violates the target
by more than 1e-10 must not be accepted. Never implement feasibility by clipping
and then rescaling independently: that procedure can reactivate both bounds and
doesn’t ensure both constraints. The monotone shift is executable and safe.

For dimensions with n/2 noninteger, this is algebraically fine in floating
arithmetic: sum is merely n/2. There is no requirement that h entries are binary.

2.4 Direction LP model

Let h be the current feasible vector with normalized correlation array F(h).
Let

F_max = max_k F_k(h)

and fix a desired normalized target level T below or equal to the incumbent.
A direction d length n with zero sum changes the current point along the ray

h + alpha*d, alpha >= 0.

For first-order valid pairs,

F_k(h + d) approximately = F_k(h) + grad_F_k(h)^T d.

Require the linearized constraint

F_k(h) + grad_F_k(h)^T d <= T + y

for selected k. Rearranging,

grad_F_k(h)^T d - y <= T - F_k(h).

For nonselected latss this linear known constraint is omitted or assigned to a soft
condition.

Decision variables:

d[i], i=0,...,n-1
auxiliary absolute variables u[i], u[i] >= 0
scalar y

LP objective:

minimize y + lambda/n * sum_i u_i

Use lambda about 1e-3. The u terms regularize the direction and reduce noise
from unaligned models. Without them, the LP can produce very lopshift directions
that are equivalent in the limited active model but numerically unstable.

Constraints:

Equality:
sum_i d[i] = 0,
so alpha*d preserves sum.

Absolute regularization:
d[i] - u[i] <= 0
-d[i] - u[i] <= 0

This yields u_i >= |d_i|. These constraints are optional when using exact special
prox locals that don’t need zero-sum; use them in the common coder.
