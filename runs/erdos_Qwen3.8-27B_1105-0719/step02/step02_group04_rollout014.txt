    phi = M + tau * np.log(Z)
    p = exp_s / Z

    target = n / 2.0
    sdev = h.sum() - target
    phi += 0.5 * 1e4 * sdev * sdev
    
    grad_h = np.zeros(n)

        if lo2 <= hi2:

    grad_h += 1e4 * sdev  # gradient of sum penalty
    
    return phi, grad_h

    return h

We have c_j = sum_{n in S_j} h[n+k_j] * (1-h[n]) where k_j = j - (n-1) and S_j is the valid range.

d(c_j)/d(h[m]) = sum_{n in S_j} [δ_{m, n+k_j} * (1-h[n]) + h[n+k_j] * (-δ_{m,n})]

For the first term: δ_{m, n+k_j} = 1 when n = m - k_j. For this to be in S_j, we need m-k_j ∈ S_j.
The valid range S_j for n is: max(0, -k_j) ≤ n ≤ min(n-1, n-1-k_j).
So m-k_j valid means: max(0, -k_j) ≤ m-k_j ≤ min(n-1, n-1-k_j)
=> max(k_j, k_j) ≤ m ≤ min(n-1+k_j, n-1)
For k_j ≥ 0: k_j ≤ m ≤ n-1
For k_j < 0: 0 ≤ m ≤ n-1+k_j = n-1-|k_j|

When valid, the contribution is (1-h[m-k_j]).

For the second term: δ_{m,n} = 1 when n = m. For m ∈ S_j:
max(0, -k_j) ≤ m ≤ min(n-1, n-1-k_j)
For k_j ≥ 0: 0 ≤ m ≤ n-1-k_j
For k_j < 0: -k_j ≤ m ≤ n-1, i.e., |k_j| ≤ m ≤ n-1

When valid, the contribution is -h[m+k_j].

So:
d(c_j)/d(h[m]) = (1-h[m-k_j]) * I(m ∈ valid_range_1) - h[m+k_j] * I(m ∈ valid_range_2)
