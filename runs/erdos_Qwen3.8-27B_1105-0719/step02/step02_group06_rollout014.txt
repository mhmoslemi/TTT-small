Let me think about what's different from the previous approach:

Let me design the algorithm:

1. **LP Trust Region**: Given current q, compute active lags, form a linear program where we minimize τ subject to linearized constraints for active lags, with q bounds and a trust region constraint.

2. **Coordinate sweep**: For each coordinate (or selected subset), sweep the value while keeping others fixed, find the exact minimum of the max correlation. This is a 1D problem that can be solved by checking the breakpoints where the max changes.

3. **Resolution exploration**: Try various n values (smaller and larger), optimize at each, and keep the best.

Let me think about the LP formulation more carefully:

For the symmetric parameterization h = [q, 1-q[::-1]] with n=2m:
- The correlation at lag k is: c_k = Σ h[i] * (1-h[i+k]) * dx
  (with appropriate bounds)
- The gradient w.r.t. q[r] involves: dx * (grad_h[r] - grad_h[n-1-r])

For the LP trust region:
- Variables: d (step direction), m values) and τ (scalar)
- Objective: minimize τ
- Constraints: for each active lag k: c_k + grad_k · d ≤ τ
- Bounds: 0 ≤ q[r] + d[r] ≤ 1
- Trust region: ||d||_∞ ≤ Δ (or ||d||_2 ≤ Δ)

Using infinity norm trust region: |d[r]| ≤ Δ for all r
This gives box constraints: -Δ ≤ d[r] ≤ Δ

So the LP is:
minimize τ
subject to:
  grad_k[r] * d[r] - τ ≤ -c_k for each active k
  q[r] - 1 ≤ d[r] (i.e., q[r] + d[r] ≤ 1)
  -q[r] ≤ d[r] (i.e., q[r] + d[r] ≥ 0)
  |d[r]| ≤ Δ
  τ ≥ 0 (optional, since correlations are always ≥ 0)

Wait, let me be more careful. The correlation at lag k is:
c_k = Σ_i h[i] * (1 - h[i+k]) * dx

The gradient w.r.t. h[i] is:
∂c_k/∂h[i] = (1 - h[i+k]) * dx if i is in the "first" position
           + (-h[i-k]) * dx if i is in the "second" position

For the symmetric parameterization, if h[i] = q[i] for i < m, and h[i] = 1 - q[n-1-i] for i ≥ m:
∂c_k/∂q[r] = ∂c_k/∂h[r] - ∂c_k/∂h[n-1-r]

So grad_q[k, r] = dx * (grad_h[k, r] - grad_h[k, n-1-r])

The LP becomes:
minimize τ
subject to:
  Σ_r grad_q[k, r] * d[r] - τ ≤ -c_k  for each active k
  0 ≤ q[r] + d[r] ≤ 1  for all r
  |d[r]| ≤ Δ  for all r (trust region)

This is a standard LP that scipy.optimize.linprog can solve.

Now, for the coordinate sweep:
Given the current h, for coordinate r (in the q parameterization or full h), I want to find the value that minimizes max_k c_k.

The function c_k(x) as a function of a single variable x (with all other variables fixed) is piecewise linear (or quadratic if both h[i] and h[i+k] depend on x). Actually, since c_k = Σ h[i](1-h[i+k]), if only one variable changes, each c_k is at most quadratic in that variable.

Wait, for the full h: if I change h[j], then c_k depends on h[j] through:
- h[j]*(1-h[j+k]) if j+k is in range
- h[j-k]*(1-h[j]) if j-k is in range

So c_k is quadratic in h[j] (at most one quadratic term per c_k).

The max of quadratics is a convex piecewise-quadratic function, which is minimized where the derivative changes sign. I can use scipy.optimize.minimize_scalar on the interval [0,1] for each coordinate.

Actually, for the symmetric parameterization, changing q[r] affects h[r] and h[n-1-r], so the effect is more complex but still the function is smooth (piecewise quadratic).

import numpy as np
from scipy.optimize import minimize, linprog, minimize_scalar
import time

def eval_score(h):
    n = len(h)
    dx = 2.0 / n
    return float(np.max(np.correlate(h, 1.0 - h, mode='full')) * dx)

def corr_raw(h):
    return np.correlate(h, 1.0 - h, mode='full')

def build_sym_h(q):
    m = len(q)
    h = np.empty(2 * m)
    h[:m] = q
    h[m:] = 1.0 - q[::-1]
    return h

def sym_from_h(h):
    n = len(h)
    m = n // 2
    q = np.empty(m)
    for i in range(m):
        q[i] = 0.5 * (h[i] + (1.0 - h[n - 1 - i]))
    return np.clip(q, 0.0, 1.0)

def project_feasible(x, target_sum):
    n = len(x)
    lo, hi = -1.5, 1.5
    for _ in range(80):
        mid = (lo + hi) / 2.0
        s = np.clip(x + mid, 0.0, 1.0).sum()
        if s > target_sum:
            hi = mid
        else:
            lo = mid
    h = np.clip(x + (lo + hi) / 2.0, 0.0, 1.0)
    diff = target_sum - h.sum()
    if abs(diff) > 1e-12:
        interior = (h > 1e-10) & (h < 1.0 - 1e-10)
        if interior.sum() > 0:
            h[interior] += diff / interior.sum()
    return np.clip(h, 0.0, 1.0)

def corr_at_k(h, k):
    n = len(h)
    d = k - (n - 1)
    i_lo = max(0, -d)
    i_hi = min(n - 1, n - 1 - d)
    if i_lo > i_hi:
        return 0.0
    return float(np.sum(h[i_lo:i_hi + 1] * (1.0 - h[i_lo + d:i_hi + 1 + d])))

def corr_grad_h(h, k):
    """Gradient of correlation at lag k w.r.t. h."""
    n = len(h)
    d = k - (n - 1)
    grad = np.zeros(n)
    i_lo = max(0, -d)
    i_hi = min(n - 1, n - 1 - d)
    if i_lo > i_hi:
        return grad
    idx = np.arange(i_lo, i_hi + 1)
    grad[idx] += (1.0 - h[idx + d])
    grad[idx + d] += (-h[idx])
    return grad

def corr_grad_q(q, k):
    """Gradient of correlation at lag k w.r.t. q (symmetric parameterization)."""
    m = len(q)
    n = 2 * m
    h = build_sym_h(q)
    g = corr_grad_h(h, k)
    return g[:m] - g[n-1::-1]

def select_active(corrs, margin_frac=0.03, margin_abs=2e-6, neighbor_pad=4, max_k=70):
    n = len(corrs)
    max_val = corrs.max()
    threshold = max_val - max(margin_abs, margin_frac * max_val)
    active = set(np.where(corrs >= threshold)[0].tolist())
    padded = set()
    for k in active:
        for d in range(-neighbor_pad, neighbor_pad + 1):
            if 0 <= k + d < n:
                padded.add(k + d)
    active_list = sorted(padded)
    if len(active_list) > max_k:
        scored = sorted([(corrs[k], k) for k in active_list], reverse=True)
        active_list = sorted([k for _, k in scored[:max_k]])
    return active_list

def lp_trust_region(q, active_k, delta, n_full):
    """Solve LP trust region for symmetric parameterization.
    Minimize tau subject to linearized constraints.
    Returns (d, tau) where d is the step in q-space.
    """
    m = len(q)
    dx = 2.0 / n_full
    
    # Compute current correlations and gradients for active lags
    corrs_vals = []
    grads = []
    for k in active_k:
        c = corr_at_k(build_sym_h(q), k) * dx
        g = corr_grad_q(q, k) * dx
        corrs_vals.append(c)
        grads.append(g)
    
    corrs_vals = np.array(corrs_vals)
    grads = np.array(grads)  # shape (len(active_k), m)
    
    # Variables: [d_0, ..., d_{m-1}, tau]
    # Objective: minimize tau
    c_obj = np.zeros(m + 1)
    c_obj[m] = 1.0
    
    # Constraints: grads[k, r] * d[r] - tau <= -corr_vals[k] for each active k
    A_ub = np.zeros((len(active_k), m + 1))
    b_ub = np.zeros(len(active_k))
    for i, k in enumerate(active_k):
        A_ub[i, :m] = grads[i]
        A_ub[i, m] = -1.0
        b_ub[i] = -corrs_vals[i]
    
    # Box constraints on d: 0 <= q[r] + d[r] <= 1 => -q[r] <= d[r] <= 1-q[r]
    # Trust region: |d[r]| <= delta
    # Combined: max(-q[r], -delta) <= d[r] <= min(1-q[r], delta)
    bounds = []
    for r in range(m):
        lo = max(-q[r], -delta)
        hi = min(1.0 - q[r], delta)
        bounds.append((lo, hi))
    bounds.append((None, None))  # tau unbounded (but will be >= 0 naturally)
    
    try:
        res = linprog(c_obj, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')
        if res.success:
            d = res.x[:m]
            tau = res.x[m]
            return d, tau
    except Exception:
        pass
    return np.zeros(m), float('inf')

def smooth_max_obj_grad(q, n_full, beta):
    """Smooth max objective and gradient in q-space."""
    m = len(q)
    h = build_sym_h(q)
    dx = 2.0 / n_full
    corrs = corr_raw(h) * dx
    max_c = corrs.max()
    shifted = corrs - max_c
    w = np.exp(np.clip(beta * shifted, -100, 100))
    w_sum = w.sum()
    if w_sum < 1e-30:
        w = np.ones(len(corrs)) / len(corrs)
    else:
        w /= w_sum
    val = max_c + np.log(w_sum) / beta
    
    grad_q = np.zeros(m)
    for k in range(2 * n_full - 1):
        if w[k] < 1e-12:
            continue
        g = corr_grad_q(q, k) * dx
        grad_q += w[k] * g
    return val, grad_q

def coord_sweep_sym(q, n_full, max_rounds=3, time_limit=None):
    """Coordinate descent with exact 1D optimization for symmetric parameterization."""
    m = len(q)
    q_cur = q.copy()
    best_c5 = eval_score(build_sym_h(q_cur))
    
    for rnd in range(max_rounds):
        if time_limit is not None and time.time() > time_limit:
            break
        improved = False
        for r in range(m):
            if time_limit is not None and time.time() > time_limit:
                break
            
            def obj_1d(val):
                q_test = q_cur.copy()
                q_test[r] = val
                h_test = build_sym_h(q_test)
                return eval_score(h_test)
            
            # Use bounded scalar minimization
            res = minimize_scalar(obj_1d, bounds=(0.0, 1.0), method='bounded',
                                  options={'xatol': 1e-10, 'maxiter': 30})
            if res.success and res.fun < best_c5 - 1e-13:
                q_cur[r] = res.x
                best_c5 = res.fun
                improved = True
    
    return q_cur, best_c5

def transfer_to_n(h_old, n_new):
    n_old = len(h_old)
    x_old = (np.arange(n_old) + 0.5) * 2.0 / n_old
    x_new = (np.arange(n_new) + 0.5) * 2.0 / n_new
    h_new = np.interp(x_new, x_old, h_old)

def epig_sym_con_fun(x, k, n_full):
    q = x[:n_full // 2]
    t = x[n_full // 2]
    h = build_sym_h(q)
    dx = 2.0 / n_full
    return t - corr_at_k(h, k) * dx

def epig_sym_con_jac(x, k, n_full):
    m = n_full // 2
    q = x[:m]
    dx = 2.0 / n_full
    g = corr_grad_q(q, k) * dx
    j = np.zeros(m + 1)
    j[:m] = -g
    j[m] = 1.0
    return j

def epig_sym_obj(x):
    return x[len(x) - 1]

def epig_sym_obj_grad(x):
    n = len(x)
    g = np.zeros(n)
    g[n - 1] = 1.0
    return g

def solve_epigraph_sym(q_center, n_full, active_k, maxiter, ftol, time_limit=None):

    try:

import numpy as np
from scipy.optimize import minimize, linprog
import time

def eval_score(h):
    n = len(h)
    dx = 2.0 / n
    return float(np.max(np.correlate(h, 1.0 - h, mode='full')) * dx)

def corr_raw(h):
    return np.correlate(h, 1.0 - h, mode='full')

def build_sym_h(q):
    m = len(q)
    h = np.empty(2 * m)
    h[:m] = q
    h[m:] = 1.0 - q[::-1]
    return h

def sym_from_h(h):
    n = len(h)
    m = n // 2
    q = np.empty(m)
    for i in range(m):
        q[i] = 0.5 * (h[i] + (1.0 - h[n - 1 - i]))
    return np.clip(q, 0.0, 1.0)

def project_feasible(x, target_sum):
    n = len(x)
    lo, hi = -1.5, 1.5
    for _ in range(80):
        mid = (lo + hi) / 2.0
        s = np.clip(x + mid, 0.0, 1.0).sum()
        if s > target_sum:
            hi = mid
        else:
            lo = mid
    h = np.clip(x + (lo + hi) / 2.0, 0.0, 1.0)
    diff = target_sum - h.sum()
    if abs(diff) > 1e-12:
        interior = (h > 1e-10) & (h < 1.0 - 1e-10)
        if interior.sum() > 0:
            h[interior] += diff / interior.sum()
    return np.clip(h, 0.0, 1.0)

def corr_at_k(h, k):
    n = len(h)
    d = k - (n - 1)
    i_lo = max(0, -d)
    i_hi = min(n - 1, n - 1 - d)
    if i_lo > i_hi:
        return 0.0
    return float(np.sum(h[i_lo:i_hi + 1] * (1.0 - h[i_lo + d:i_hi + 1 + d])))

def corr_grad_h(h, k):
    n = len(h)
    d = k - (n - 1)
    grad = np.zeros(n)
    i_lo = max(0, -d)
    i_hi = min(n - 1, n - 1 - d)
    if i_lo > i_hi:
        return grad
    idx = np.arange(i_lo, i_hi + 1)
    grad[idx] += (1.0 - h[idx + d])
    grad[idx + d] += (-h[idx])
    return grad

def corr_grad_q(q, k):
    m = len(q)
    n = 2 * m
    h = build_sym_h(q)
    g = corr_grad_h(h, k)
    return g[:m] - g[n - 1::-1]

def select_active(corrs, margin_frac=0.03, margin_abs=2e-6, neighbor_pad=4, max_k=70):
    n = len(corrs)
    max_val = corrs.max()
    threshold = max_val - max(margin_abs, margin_frac * max_val)
    active = set(np.where(corrs >= threshold)[0].tolist())
    padded = set()
    for k in active:
        for d in range(-neighbor_pad, neighbor_pad + 1):
            if 0 <= k + d < n:
                padded.add(k + d)
    active_list = sorted(padded)
    if len(active_list) > max_k:
        scored = sorted([(corrs[k], k) for k in active_list], reverse=True)
        active_list = sorted([k for _, k in scored[:max_k]])
    return active_list

def solve_lp_trust(q, active_k, delta, n_full):
    m = len(q)
    dx = 2.0 / n_full
    h_cur = build_sym_h(q)
    n_acts = len(active_k)
    if n_acts == 0:
        return np.zeros(m), 0.0
    c_vals = np.zeros(n_acts)
    g_mat = np.zeros((n_acts, m))
    for i, k in enumerate(active_k):
        c_vals[i] = corr_at_k(h_cur, k) * dx
        g_mat[i] = corr_grad_q(q, k) * dx
    c_obj = np.zeros(m + 1)
    c_obj[m] = 1.0
    A_ub = np.zeros((n_acts, m + 1))
    b_ub = np.zeros(n_acts)
    for i in range(n_acts):
        A_ub[i, :m] = g_mat[i]
        A_ub[i, m] = -1.0
        b_ub[i] = -c_vals[i]
    bounds = []
    for r in range(m):
        lo = max(-q[r], -delta)
        hi = min(1.0 - q[r], delta)
        bounds.append((lo, hi))
    bounds.append((-0.5, None))
    try:
        res = linprog(c_obj, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')
        if res.success:
            return res.x[:m], res.x[m]
    except Exception:
        pass
    return np.zeros(m), float('inf')

        h_parent = np.clip(h_parent, 0.0, 1.0)
        best_h = h_parent.copy()
        best_c5 = eval_score(best_h)
    else:
        m_p = 63
        x = np.linspace(0, 1, m_p)
        q_p = (0.5 + 0.3 * np.sin(2 * np.pi * x)).clip(0, 1)
        best_h = build_sym_h(q_p)
        best_c5 = eval_score(best_h)

    n_cur = len(best_h)

    # Phase 1: LP trust region - main refinement
    if n_cur % 2 == 0 and rem() > 150:
        q_cur = sym_from_h(best_h)
        tl = time.time() + min(300, rem() * 0.35)
        q_cur, c5_lp = lp_refine(q_cur, n_cur, 300, 0.3, 0.0005, tl, 0.02, 3, 55)
        if c5_lp < best_c5:
            best_c5 = c5_lp
            best_h = build_sym_h(q_cur).copy()

    # Phase 2: Smooth max optimization
    if n_cur % 2 == 0 and rem() > 150:
        q_cur = sym_from_h(best_h)
        tl = time.time() + min(150, rem() * 0.25)
        q_s, c5_s, h_s = smooth_opt(q_cur, n_cur, [100, 250, 500, 1000, 2000], 200, tl)
        if c5_s < best_c5:
            best_c5 = c5_s
            best_h = h_s.copy()

    # Phase 3: LP trust region again with tighter params
    if n_cur % 2 == 0 and rem() > 100:
        q_cur = sym_from_h(best_h)
        tl = time.time() + min(200, rem() * 0.25)
        q_cur, c5_lp = lp_refine(q_cur, n_cur, 300, 0.15, 0.0003, tl, 0.015, 2, 40)
        if c5_lp < best_c5:
            best_c5 = c5_lp
            best_h = build_sym_h(q_cur).copy()

    # Phase 4: Coordinate sweep
    if n_cur % 2 == 0 and rem() > 80:
        q_cur = sym_from_h(best_h)
        tl = time.time() + min(60, rem() * 0.4)
        q_cur, c5_c = coord_sweep(q_cur, n_cur, max_rounds=3, time_limit=tl)
        if c5_c < best_c5:
            best_c5 = c5_c
            best_h = build_sym_h(q_cur).copy()

    # Phase 5: Another LP pass
    if n_cur % 2 == 0 and rem() > 80:
        q_cur = sym_from_h(best_h)
        tl = time.time() + min(100, rem() * 0.3)
        q_cur, c5_lp = lp_refine(q_cur, n_cur, 200, 0.1, 0.0002, tl, 0.01, 2, 35)
        if c5_lp < best_c5:
            best_c5 = c5_lp
            best_h = build_sym_h(q_cur).copy()

    # Phase 6: Multi-resolution exploration
    n_base = len(best_h)
    n_candidates = set()
    for delta in [-8, -6, -4, -2, 2, 4, 6, 10, 14]:
        nc = n_base + delta
        if 50 <= nc <= 220 and nc % 2 == 0:
            n_candidates.add(nc)
    n_candidates = sorted(n_candidates)

    for n_try in n_candidates:
        if rem() < 50:
            break
        h_try = transfer_to_n(best_h, n_try)
        n_try = len(h_try)
        if n_try % 2 != 0:
            continue
        q_try = sym_from_h(h_try)
        c5_try = eval_score(h_try)
        if c5_try < best_c5:
            best_c5 = c5_try
            best_h = h_try.copy()
        if rem() > 40:
            tl = time.time() + min(40, rem() * 0.5)
            q_try2, c5_try2, _ = lp_refine(q_try, n_try, 100, 0.2, 0.001, tl, 0.02, 3, 45)
            if c5_try2 < best_c5:
                best_c5 = c5_try2
                best_h = build_sym_h(q_try2).copy()
        if rem() > 30:
            if best_h is not None and len(best_h) == n_try:
                q_try = sym_from_h(best_h)
            tl = time.time() + min(30, rem() * 0.5)
            q_un, c5_u, _ = smooth_opt(q_try, n_try, [200, 500], 150, tl)
            if c5_u < best_c5:
                best_c5 = c5_u
                best_h = build_sym_h(q_un).copy()

    # Phase 7: Back to best resolution, final LP + coord
    if n_cur % 2 == 0 and rem() > 40:
        if len(best_h) != n_cur:
            best_h = transfer_to_n(best_h, n_cur)
            n_cur = len(best_h)
            q_cur = sym_from_h(best_h)
            if q_cur is None or len(q_cur) == 0:
                q_cur = sym_from_h(best_h)
        else:
            q_cur = sym_from_h(best_h)
        tl = time.time() + min(40, rem() * 0.5)
        q_cur, c5_f = lp_refine(q_cur, n_cur, 150, 0.1, 0.0002, tl, 0.01, 2, 35)
        if c5_f < best_c5:
            best_c5 = c5_f
            best_h = build_sym_h(q_cur).copy()

    if n_cur % 2 == 0 and rem() > 20:
        q_cur = sym_from_h(best_h)
        tl = time.time() + min(20, rem() * 0.5)
        q_cur, c5_c = coord_sweep(q_cur, n_cur, max_rounds=2, time_limit=tl)
        if c5_c < best_c5:
            best_c5 = c5_c
            best_h = build_sym_h(q_cur).copy()

    # Phase 8: Final ultra-tight LP
    if rem() > 15 and best_h is not None and len(best_h) % 2 == 0:
        q_cur = sym_from_h(best_h)
        tl = time.time() + min(12, rem() * 0.6)
        q_cur, c5_f = lp_refine(q_cur, len(best_h), 100, 0.05, 0.0001, tl, 0.005, 1, 25)
        if c5_f < best_c5:
            best_c5 = c5_f
            best_h = build_sym_h(q_cur).copy()

    # Validate and return
    if best_h is None:
        m_fb = 63
        x_fb = np.linspace(0, 1, m_fb)
        q_fb = (0.5 + 0.3 * np.sin(2 * np.pi * x_fb)).clip(0, 1)
        best_h = build_sym_h(q_fb)

    best_h = np.asarray(best_h, dtype=float).reshape(-1)
    n_out = len(best_h)
    best_h = project_feasible(best_h, n_out / 2.0)
    best_c5 = eval_score(best_h)
    return best_h, best_c5, n_out
