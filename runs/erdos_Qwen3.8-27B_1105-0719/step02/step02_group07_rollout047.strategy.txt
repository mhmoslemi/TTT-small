1. Approach and rationale

### 1.1 Central idea

The proposed algorithm contributes three substantive departures from the current parent optimizer:

1. **A constructor-based symmetric search space.**  
   Instead of searching over all `h` with an integral constraint enforced by penalties/projections, the algorithm searches a reduced mirror variable `q ∈ [0,1]^m`, `m = floor(n/2)`, and reconstructs a vector that is guaranteed to satisfy `0 <= h_i <= 1` and `sum(h) = n/2` algebraically for both even and odd `n`. This changes the problem from constrained continuous optimization to unconstrained box optimization in half the dimension. The construction is not claimed to be globally sufficient, but it provides a family of exactly feasible candidates and is used next to a retained parent fallback.

2. **A combinatorial basin-hopping stage.**  
   The previous approach is dominated by smooth objective descent and semicontinuous epigraph SLSQP. The new stage treats the mirror variable partly as binary and systematically tries **single-bit mirror flips** and **random 2-bit mirror flip moves**. These moves produce very different local correlation patterns while retaining exact feasibility automatically. The objective is always evaluated by the original exact evaluator; the discrete stage is a generator of starting points for continuous repair, not an accepted bound by itself.

3. **Exact low-dimensional maximax line search.**  
   After discrete progress, the optimizer proposes low-dimensional path directions and optimizes the **raw exact objective along each path** using bracketing and golden-section refinement rather than optimizing only a smoothed aggregate. The tried path families include active-correlation gradient-opposing pairs, random pairs, gradient-sign paths, block-window paths, and coarse coordinate moves. This addresses the nail that smoothed smooth-max descent may drift in a non-representative basins near active lags, while exact path search directly flat-taxes relatively many minimax components along a feasible one-dimensional face.

This remains a heuristic research for positive practical upper bound, not a proof of global optimality. Every final report condition is a strict exact-objective improvement.

### 1.2 Bottleneck addressed

The previous method spent much budget in the same continuous region and had long epigraph smooth stages. The new method increases global search volume by:

- generating several isolated feasible basins from thresholded and jittered versions of the parent in the mirror family;
- exploring pattern neighbors through binary flip perturbations;
- then selecting only paths that improve the **raw maximum correlation** by testing multiple identified directions with exact objective line minimization.

If no stage improves the exact parent score, the parent vector is returned whenever available and feasible. Thus there is a safe validation contract.
