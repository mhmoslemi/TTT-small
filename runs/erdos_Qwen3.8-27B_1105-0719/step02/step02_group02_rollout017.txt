- j+off_k = i, i.e., j = i-off_k: contribution is h[i-off_k] * (1-h[i]) if i-off_k in [0,n-1]

So result[k] = R_k(x) where:
R_k(x) = (sum of all terms NOT involving i) + x*(1-h[i+off_k])*I_valid(i+off_k) + h[i-off_k]*(1-x)*I_valid(i-off_k)

Let me define:
- C_k = sum of all terms NOT involving index i in result[k]
- A_k = (1-h[i+off_k]) if i+off_k in [0,n-1], else 0
- B_k = h[i-off_k] if i-off_k in [0,n-1], else 0

Then R_k(x) = C_k + A_k*x + B_k*(1-x) = (C_k + B_k) + (A_k - B_k)*x

So p_k = C_k + B_k, q_k = A_k - B_k.

Now, C_k = result[k] - A_k*h[i] - B_k*(1-h[i])

The computation of A_k and B_k for all k given a fixed i:
- A_k is nonzero when 0 <= i+off_k < n, i.e., when off_k in [-i, n-1-i], i.e., k in [n-1-i, n-1-i+n-1] = [n-1-i, 2n-2-i]

And B_k is nonzero for k in [i, n-1+i] (at most n values)

For the rest, A_k = B_k = 0, so p_k = result[k], q_k = 0.

For the minimax: the lines with q_k = 0 are constant, so they form a "floor" that the varying lines must stay above (or the max is at least that floor).

Let me also think about the bit-flipping approach. If h is binary (or near-binary), a "move" is to swap a 1 and a 0. The change in correlations can be computed incrementally.

For a swap of i (1→0) and j (0→1):
- result[k] changes by:
  - Removing h[i]=1: for each k where i contributes, result[k] decreases
  - Adding h[j]=1: for each k where j contributes, result[k] increases

The contribution of h[i]=1 to result[k]:
- If i+off_k in [0,n-1]: contributes 1*(1-h[i+off_k]) = 1-h[i+off_k]
- If i-off_k in [0,n-1]: contributes h[i-off_k]*(1-1) = 0

So removing h[i]=1 from result[k] changes it by: -(1-h[i+off_k]) if i+off_k valid (the "first factor" term)

Wait, I need to be more careful. result[k] = sum_j h[j]*(1-h[j+off_k]).

If h[i] goes from 1 to 0:
- The term j=i in the sum goes from 1*(1-h[i+off_k]) = 1-h[i+off_k] to 0*(1-h[i+off_k]) = 0
- So result[k] decreases by (1-h[i+off_k]) if i+off_k is valid

If h[j] goes from 0 to 1:
- The term j=j in the sum goes from 0*(1-h[j+off_k]) = 0 to 1*(1-h[j+off_k]) = 1-h[j+off_k]
- So result[k] increases by (1-h[j+off_k]) if j+off_k is valid

But wait, there's also the effect on other terms! If h[i] appears as the "second factor" in some other term:
- Term j' where j'+off_k = i, i.e., j' = i-off_k: this term is h[i-off_k]*(1-h[i])
  - When h[i] goes from 1 to 0: this term goes from h[i-off_k]*0 = 0 to h[i-off_k]*1 = h[i-off_k]
  - So result[k] increases by h[i-off_k] if i-off_k is valid

Similarly for h[j]:
- Term j'' where j''+off_k = j: h[j-off_k]*(1-h[j])
  - When h[j] goes from 0 to 1: goes from h[j-off_k]*1 to h[j-off_k]*0
  - So result[k] decreases by h[j-off_k] if j-off_k is valid

So the total change in result[k] from the swap (i: 1→0, j: 0→1):
Δresult[k] = -(1-h[i+off_k])*I(i+off_k valid) + h[i-off_k]*I(i-off_k valid)

import numpy as np
from scipy.optimize import minimize
from scipy.special import logsumexp
import time


def project_feasible(x, target_sum):
    n = len(x)
    lo, hi = -1.0, 1.0
    for _ in range(80):
        mid = (lo + hi) / 2.0
        h = np.clip(x - mid, 0.0, 1.0)
        if h.sum() > target_sum:
            lo = mid
        else:
            hi = mid
    h = np.clip(x - (lo + hi) * 0.5, 0.0, 1.0)
    diff = target_sum - h.sum()
    if abs(diff) > 1e-12:
        mask = (h > 1e-12) & (h < 1.0 - 1e-12)
        if mask.sum() > 0:
            h[mask] += diff / mask.sum()
    h = np.clip(h, 0.0, 1.0)
    return h


def compute_c5(h, dx):
    corrs = np.correlate(h, 1.0 - h, mode='full')
    return float(corrs.max() * dx)


def full_corrs(h):
    return np.correlate(h, 1.0 - h, mode='full')


def smooth_max_obj(h, dx, beta):
    corrs = full_corrs(h)
    return float(logsumexp(beta * corrs) / beta * dx)


def smooth_max_grad(h, dx, beta):
    n = len(h)
    corrs = full_corrs(h)
    shifted = corrs - corrs.max()
    w = np.exp(beta * shifted)
    w_sum = w.sum()
    if w_sum < 1e-30:
        w = np.ones_like(corrs) / len(corrs)
    else:
        w /= w_sum
    grad = np.zeros(n)
    for k in range(2 * n - 1):
        if w[k] < 1e-14:
            continue
        off = k - (n - 1)
        i_lo = max(0, -off)
        i_hi = min(n - 1, n - 1 - off)
        if i_lo > i_hi:
            continue
        idx = np.arange(i_lo, i_hi + 1)
        grad[idx + off] += w[k] * (1.0 - h[idx])
        grad[idx] += w[k] * (-h[idx + off])
    return grad * dx


def slsqp_smooth(h0, dx, target_sum, beta, maxiter):
    n = len(h0)
    bounds = [(0.0, 1.0)] * n

    def obj(x):
        return smooth_max_obj(x, dx, beta)

    def obj_grad(x):
        return smooth_max_grad(x, dx, beta)

    def con_fun(x):
        return x.sum() - target_sum

    def con_jac(x):
        return np.ones(n)

    cons = [{'type': 'eq', 'fun': con_fun, 'jac': con_jac}]
    try:
        res = minimize(obj, h0, jac=obj_grad, method='SLSQP',
                       bounds=bounds, constraints=cons,
                       options={'maxiter': maxiter, 'ftol': 1e-14})
        h_out = project_feasible(res.x, target_sum)
    except Exception:
        h_out = project_feasible(h0, target_sum)
    return h_out, compute_c5(h_out, dx)


def slsqp_penalty(h0, dx, target_sum, target_c, penalty_w, maxiter):
    n = len(h0)
    target_raw = target_c / dx
    bounds = [(0.0, 1.0)] * n

    def obj(x):
        corrs = full_corrs(x)
        violations = np.maximum(0, corrs - target_raw)
        return float(penalty_w * np.sum(violations ** 2) + 0.001 * corrs.max())

    def obj_grad(x):
        corrs = full_corrs(x)
        grad = np.zeros(n)
        for k in range(2 * n - 1):
            coeff = 0.0
            if corrs[k] > target_raw:
                coeff += 2.0 * penalty_w * (corrs[k] - target_raw)
            coeff += 0.001
            off = k - (n - 1)
            i_lo = max(0, -off)
            i_hi = min(n - 1, n - 1 - off)
            if i_lo > i_hi:
                continue
            idx = np.arange(i_lo, i_hi + 1)
            grad[idx + off] += coeff * (1.0 - x[idx])
            grad[idx] += coeff * (-x[idx + off])
        return grad * dx

    def con_fun(x):
        return x.sum() - target_sum

    def con_jac(x):
        return np.ones(n)

    cons = [{'type': 'eq', 'fun': con_fun, 'jac': con_jac}]
    try:
        res = minimize(obj, h0, jac=obj_grad, method='SLSQP',
                       bounds=bounds, constraints=cons,
                       options={'maxiter': maxiter, 'ftol': 1e-12})
        h_out = project_feasible(res.x, target_sum)
    except Exception:
        h_out = project_feasible(h0, target_sum)
    return h_out, compute_c5(h_out, dx)


def coord_desc_step(h, i):
    """Find optimal h[i] given all other coordinates fixed (ignoring sum constraint)."""
    n = len(h)
    corrs = full_corrs(h)
    x0 = h[i]

    p = corrs.copy()
    q = np.zeros(2 * n - 1)

    for k in range(2 * n - 1):
        off = k - (n - 1)
        a_k = 0.0
        b_k = 0.0
        if 0 <= i + off < n:
            a_k = 1.0 - h[i + off]
        if 0 <= i - off < n:
            b_k = h[i - off]
        if a_k == 0.0 and b_k == 0.0:
            continue
        p[k] = corrs[k] - a_k * x0 - b_k * (1.0 - x0) + b_k
        q[k] = a_k - b_k

    # Find x in [0,1] minimizing max_k (p[k] + q[k]*x)
    candidates = [0.0, 1.0]
    # Add pairwise intersections
    m = 2 * n - 1
    for a_idx in range(m):
        if q[a_idx] == 0.0:
            continue
        for b_idx in range(a_idx + 1, m):
            if q[b_idx] == 0.0:
                continue
            denom = q[a_idx] - q[b_idx]
            if abs(denom) < 1e-15:
                continue
            x_int = (p[b_idx] - p[a_idx]) / denom
            if -1e-10 <= x_int <= 1.0 + 1e-10:
                candidates.append(max(0.0, min(1.0, x_int)))

    best_x = x0
    best_val = float('inf')
    for xc in candidates:
        vals = p + q * xc
        v = vals.max()
        if v < best_val:
            best_val = v
            best_x = xc

    return best_x


def coord_desc_sweep(h, target_sum, n_sweeps=15):
    n = len(h)
    h = h.copy()
    best_c5 = compute_c5(h, 2.0 / n)
    dx = 2.0 / n

    for sweep in range(n_sweeps):
        improved = False
        order = np.arange(n)
        for i in order:
            new_val = coord_desc_step(h, i)
            if abs(new_val - h[i]) > 1e-10:
                h[i] = new_val
                improved = True
        h = project_feasible(h, target_sum)
        c5 = compute_c5(h, dx)
        if c5 < best_c5:
            best_c5 = c5
        if not improved:
            break

    return h, best_c5


def bit_flip_search(h, target_sum, max_rounds=200, rng=None):
    """Local search by swapping 1s and 0s."""
    n = len(h)
    dx = 2.0 / n
    h = h.copy()
    best_c5 = compute_c5(h, dx)

    # Make near-binary: threshold at 0.5
    h_bin = np.where(h >= 0.5, 1.0, 0.0).astype(float)
    # Fix sum
    s = h_bin.sum()
    if s > target_sum:
        # Need to flip some 1s to 0s
        excess = int(s - target_sum)
        ones = np.where(h_bin == 1.0)[0]
        rng2 = np.random.RandomState(0)
        flip_idx = rng2.choice(ones, size=min(excess, len(ones)), replace=False)
        h_bin[flip_idx] = 0.0
    elif s < target_sum:
        deficit = int(target_sum - s)
        zeros = np.where(h_bin == 0.0)[0]
        rng2 = np.random.RandomState(0)
        flip_idx = rng2.choice(zeros, size=min(deficit, len(zeros)), replace=False)
        h_bin[flip_idx] = 1.0

    h = h_bin
    best_c5 = compute_c5(h, dx)
    best_h = h.copy()

    for rnd in range(max_rounds):
        ones = np.where(h > 0.5)[0]
        zeros = np.where(h < 0.5)[0]
        if len(ones) == 0 or len(zeros) == 0:
            break

        best_improve = 0.0
        best_pair = None
        corrs = full_corrs(h)
        current_max = corrs.max()

        # Sample a subset of swaps if too many
        if len(ones) * len(zeros) > 20000:
            sample_o = rng.choice(ones, size=200, replace=False) if rng is not None else ones[:200]
            sample_z = rng.choice(zeros, size=200, replace=False) if rng is not None else zeros[:200]
        else:
            sample_o = ones
            sample_z = zeros

        for i in sample_o:
            for j in sample_z:
                # Compute delta for all correlations
                # h[i]: 1->0, h[j]: 0->1
                new_corrs = corrs.copy()
                for k in range(2 * n - 1):
                    off = k - (n - 1)
                    delta = 0.0
                    # i going from 1 to 0:
                    # As first factor: -(1 - h[i+off]) if valid
                    if 0 <= i + off < n:
                        delta -= (1.0 - h[i + off]) if i + off != j else (1.0 - 1.0)
                    # As second factor: +h[i-off] if valid (since (1-h[i]) goes from 0 to 1)
                    if 0 <= i - off < n:
                        delta += h[i - off] if i - off != j else 0.0
                    # j going from 0 to 1:
                    # As first factor: +(1 - h[j+off]) if valid
                    if 0 <= j + off < n:
                        delta += (1.0 - h[j + off]) if j + off != i else 0.0
                    # As second factor: -h[j-off] if valid (since (1-h[j]) goes from 1 to 0)
                    if 0 <= j - off < n:
                        delta -= h[j - off] if j - off != i else -1.0

                    new_corrs[k] = corrs[k] + delta

                new_max = new_corrs.max()
                if current_max - new_max > best_improve:
                    best_improve = current_max - new_max
                    best_pair = (i, j)

        if best_pair is not None and best_improve > 1e-14:
            i, j = best_pair
            h[i] = 0.0
            h[j] = 1.0
            new_c5 = compute_c5(h, dx)
            if new_c5 < best_c5:
                best_c5 = new_c5
                best_h = h.copy()
        elif best_pair is None:
            break

    return best_h, best_c5


def subgrad_momentum(h0, dx, target_sum, max_iter=20000):
    n = len(h0)
    h = h0.copy()
    v = np.zeros(n)
    best_h = h.copy()
    best_c5 = compute_c5(h, dx)
    alpha = 0.1
    gamma = 0.8
    no_improve = 0
    top_m = max(5, n // 8)

    for it in range(max_iter):
        corrs = full_corrs(h)
        c5_val = float(corrs.max() * dx)

        if c5_val < best_c5 - 1e-14:
            best_c5 = c5_val
            best_h = h.copy()
            no_improve = 0
        else:
            no_improve += 1

        if no_improve > 5000:
            break

        # Use top-m weighted gradient
        top_idx = np.argsort(corrs)[-top_m:]
        weights = np.zeros(len(top_idx))
        w_max = corrs.max()
        for ii, k in enumerate(top_idx):
            weights[ii] = np.exp(10.0 * (corrs[k] - w_max))
        weights /= weights.sum()

        grad = np.zeros(n)
        for ii, k in enumerate(top_idx):
            if weights[ii] < 1e-14:
                continue
            off = k - (n - 1)
            i_lo = max(0, -off)
            i_hi = min(n - 1, n - 1 - off)
            if i_lo > i_hi:
                continue
            idx = np.arange(i_lo, i_hi + 1)
            grad[idx + off] += weights[ii] * (1.0 - h[idx])
            grad[idx] += weights[ii] * (-h[idx + off])
        grad *= dx

        v = gamma * v - alpha * grad
        h_new = project_feasible(h + v, target_sum)
        new_c5 = compute_c5(h_new, dx)

        if new_c5 < c5_val - 1e-15:
            h = h_new
            alpha = min(alpha * 1.002, 0.3)
        else:
            alpha *= 0.92
            v *= 0.2

        if alpha < 1e-13:
            break

    return best_h, best_c5

            best_h = h_opt
            target_c = best_c5 * 0.998

    # Phase 3: Coordinate descent
    if remaining() > 60:
        h_cd, c5_cd = coord_desc_sweep(best_h, target_sum, n_sweeps=20)
        if c5_cd < best_c5:
            best_c5 = c5_cd
            best_h = h_cd

    # Phase 4: Bit-flip local search
    if remaining() > 60:
        h_bf, c5_bf = bit_flip_search(best_h, target_sum, max_rounds=100, rng=rng)
        if c5_bf < best_c5:
            best_c5 = c5_bf
            best_h = h_bf
            # Refine with SLSQP after bit flip
            h_opt, c5_val = slsqp_smooth(best_h, dx, target_sum, 500, 500)
            if c5_val < best_c5:
                best_c5 = c5_val
                best_h = h_opt
            # More coordinate descent
            h_cd2, c5_cd2 = coord_desc_sweep(best_h, target_sum, n_sweeps=15)
            if c5_cd2 < best_c5:
                best_c5 = c5_cd2
                best_h = h_cd2

    # Phase 5: Subgradient momentum
    if remaining() > 80:
        h_sg, c5_sg = subgrad_momentum(best_h, dx, target_sum, max_iter=15000)
        if c5_sg < best_c5:
            best_c5 = c5_sg
            best_h = h_sg

    # Phase 6: Alternate between methods
    methods = ['slsqp', 'coord', 'bitflip', 'penalty', 'subgrad']
    for phase in range(8):
        if remaining() < 30:
            break
        method = methods[phase % len(methods)]
        if method == 'slsqp':
            beta = 500 + 500 * phase
            h_opt, c5_val = slsqp_smooth(best_h, dx, target_sum, beta, 600)
            if c5_val < best_c5:
                best_c5 = c5_val
                best_h = h_opt
        elif method == 'coord':
            h_cd, c5_cd = coord_desc_sweep(best_h, target_sum, n_sweeps=15)
            if c5_cd < best_c5:
                best_c5 = c5_cd
                best_h = h_cd
        elif method == 'bitflip':
            h_bf, c5_bf = bit_flip_search(best_h, target_sum, max_rounds=80, rng=rng)
            if c5_bf < best_c5:
                best_c5 = c5_bf
                best_h = h_bf
        elif method == 'penalty':
            tc = best_c5 * (1.0 - 0.002 * (1 + phase))
            h_opt, c5_val = slsqp_penalty(best_h, dx, target_sum, tc, 50 * (1 + phase), 400)
            if c5_val < best_c5:
                best_c5 = c5_val
                best_h = h_opt
        elif method == 'subgrad':
            h_sg, c5_sg = subgrad_momentum(best_h, dx, target_sum, max_iter=8000)
            if c5_sg < best_c5:
                best_c5 = c5_sg
                best_h = h_sg

    # Phase 7: Try different n values
    n_list = sorted(set([n - 4, n - 3, n - 2, n - 1, n + 1, n + 2, n + 3, n + 4,
                          n - 8, n + 8, n - 12, n + 12]))
    n_list = [x for x in n_list if x >= 30]

    for n_try in n_list:
        if remaining() < 50:
            break
        dx_try = 2.0 / n_try
        ts_try = n_try / 2.0
        x_old = np.arange(len(best_h)) * (2.0 / len(best_h))
        x_new = np.arange(n_try) * dx_try
        h_interp = np.interp(x_new, x_old, best_h)
        h_interp = project_feasible(h_interp, ts_try)

        h_opt, c5_val = slsqp_smooth(h_interp, dx_try, ts_try, 200, 400)
        if c5_val < best_c5:
            best_c5 = c5_val
            best_h = h_opt
            # Refine
            if remaining() > 40:
                h_cd, c5_cd = coord_desc_sweep(best_h, len(best_h) / 2.0, n_sweeps=10)
                if c5_cd < best_c5:
                    best_c5 = c5_cd
                    best_h = h_cd
            if remaining() > 30:
                h_opt2, c5_val2 = slsqp_smooth(best_h, 2.0 / len(best_h),
                                               len(best_h) / 2.0, 800, 500)
                if c5_val2 < best_c5:
                    best_c5 = c5_val2
                    best_h = h_opt2

    # Phase 8: Perturbation restarts
    for trial in range(15):
        if remaining() < 20:
            break
        mag = 0.01 + 0.03 * (trial / 15.0)
        h_pert = best_h + rng.normal(0, mag, len(best_h))
        h_pert = project_feasible(h_pert, len(best_h) / 2.0)
        h_opt, c5_val = slsqp_smooth(h_pert, 2.0 / len(best_h), len(best_h) / 2.0, 400, 300)
        if c5_val < best_c5:
            best_c5 = c5_val
            best_h = h_opt
            if remaining() > 30:
                h_cd, c5_cd = coord_desc_sweep(best_h, len(best_h) / 2.0, n_sweeps=10)
                if c5_cd < best_c5:
                    best_c5 = c5_cd
                    best_h = h_cd

    # Phase 9: Final intensive polish
    n_b = len(best_h)
    dx_b = 2.0 / n_b
    ts_b = n_b / 2.0

    if remaining() > 30:
        for beta in [2000, 5000, 10000]:
            if remaining() < 15:
                break
            h_final, c5_final = slsqp_smooth(best_h, dx_b, ts_b, beta, 800)
            if c5_final < best_c5:
                best_c5 = c5_final
                best_h = h_final

    if remaining() > 25:
        h_cd, c5_cd = coord_desc_sweep(best_h, ts_b, n_sweeps=25)
        if c5_cd < best_c5:
            best_c5 = c5_cd
            best_h = h_cd

    if remaining() > 20:
        h_bf, c5_bf = bit_flip_search(best_h, ts_b, max_rounds=50, rng=rng)
        if c5_bf < best_c5:
            best_c5 = c5_bf
            best_h = h_bf
            h_opt, c5_val = slsqp_smooth(best_h, 2.0 / len(best_h),
                                         len(best_h) / 2.0, 3000, 600)
            if c5_val < best_c5:
                best_c5 = c5_val
                best_h = h_opt

    if remaining() > 15:
        h_final, c5_final = slsqp_smooth(best_h, 2.0 / len(best_h),
                                         len(best_h) / 2.0, 15000, 600)
        if c5_final < best_c5:
            best_c5 = c5_final
            best_h = h_final

    # Final coordinate descent squeeze
    if remaining() > 10:
        h_cd, c5_cd = coord_desc_sweep(best_h, len(best_h) / 2.0, n_sweeps=20)
        if c5_cd < best_c5:
            best_c5 = c5_cd
            best_h = h_cd

    # Verify and return
    best_h = project_feasible(best_h, len(best_h) / 2.0)
    final_c5 = compute_c5(best_h, 2.0 / len(best_h))
    if final_c5 < best_c5:
        best_c5 = final_c5

    return best_h, best_c5, len(best_h)
