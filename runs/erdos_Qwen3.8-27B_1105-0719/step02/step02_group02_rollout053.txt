This is the max of affine functions of h[j], so it's convex in h[j] (for fixed other coordinates). We can minimize it by finding the point where the subgradient contains 0, or by ternary search on [0, 1].

Actually, it's the max of affine functions, so it's piecewise linear. The minimum occurs at a "kink" point where two or more affine functions cross, or at a boundary (0 or 1).

Finding the exact minimum of a max of affine functions in 1D can be done by:
1. Compute all the "lines" f_k(t) = a_k + b_k * t
2. Find the lower envelope... wait, we want to minimize the max, so we want the "lowest point on the upper envelope"

This is a 1D convex optimization problem. We can solve it by:
- Bisection on the derivative (subgradient)
- Or by finding all intersection points and evaluating

For 2n-1 ≈ 251 lines, finding all intersections is O(n^2) = O(n^2*251^2) which is too much.

Bisection is better: O(log(range/eps)) * O(n) per iteration = O(n * log(1/eps)). For eps=1e-12, that's about 40 evaluations * 251 lines = 10,000 operations per coordinate. For n=126 coordinates, that's 1.26M operations per full sweep. Very fast!

OK, coordinate descent is tricky because of the quadratic term at s=0. Let me abandon this and stick with the SLSQP approach.

Let me focus on making the epigraph SLSQP work well. Key considerations:

1. **Target selection**: Start with target = current_best - small_delta, where small_delta is about 0.0002 initially.

2. **Regularization**: Use a small rho (like 0.01) to prevent the solution from drifting too far from the anchor. Actually, let me try rho=0 first and see if the solver converges to something useful.

3. **Initial slack**: s0 should be slightly above the actual violation to ensure the point is feasible for the constraints.

4. **SLSQP options**: Use a tight ftol and sufficient maxiter.

Let me also think about an alternative: instead of the epigraph, use a **penalty method**. Minimize:
max_k corr_k + mu * max(0, max_k corr_k - target_raw)^2

This is like a Lagrangian relaxation. But it's still non-smooth.

Or: minimize the sum of violated constraints:
sum_k max(0, corr_k - target_raw)^2 + rho * ||h - anchor||^2

This is smooth (C^1) and can be optimized with gradient methods. But it's a weak formulation.

I think the SLSQP epigraph is the right approach. Let me just implement it carefully.

One concern: with 251 inequality constraints, SLSQP might be slow. Each iteration involves solving a QP subproblem with 251 constraints. For a dense QP with 127 variables and 251 constraints, this should take maybe 1-10ms per iteration. With 100-300 iterations, that's 0.1-3 seconds per SLSQP call. Very reasonable.

import numpy as np
from scipy.optimize import minimize
from scipy.special import logsumexp
import time

def compute_corrs(h):
    return np.correlate(h, 1.0 - h, mode='full')

def c5_of_h(h):
    n = len(h)
    return float(compute_corrs(h).max() * 2.0 / n)

def project_feasible(x, target_sum):
    n = len(x)
    lo = float(np.min(x)) - 1.0
    hi = float(np.max(x)) + 1.0
    for _ in range(100):
        mid = (lo + hi) / 2.0
        s = np.clip(x - mid, 0.0, 1.0).sum()
        if s > target_sum:
            lo = mid
        else:
            hi = mid
    h = np.clip(x - (lo + hi) * 0.5, 0.0, 1.0)
    diff = target_sum - h.sum()
    if abs(diff) > 1e-12:
        mask = (h > 1e-10) & (h < 1.0 - 1e-10)
        if mask.sum() > 0:
            h[mask] += diff / mask.sum()
            h = np.clip(h, 0.0, 1.0)
    return h

def grad_all_corrs(h):
    n = len(h)
    ncorr = 2 * n - 1
    grads = np.zeros((ncorr, n))
    grads[n-1, :] = 1.0 - 2.0 * h
    for s in range(1, n):
        k = n - 1 + s
        j1 = np.arange(n - s)
        grads[k, j1] += (-h[j1 + s])
        j2 = np.arange(s, n)
        grads[k, j2] += (1.0 - h[j2 - s])
    for d in range(1, n):
        k = n - 1 - d
        j1 = np.arange(n - d)
        grads[k, j1] += (1.0 - h[j1 + d])
        j2 = np.arange(d, n)
        grads[k, j2] += (-h[j2 - d])
    return grads

def lse_solve(h0, beta, maxiter, ftol=1e-14):
    n = len(h0)
    dx = 2.0 / n
    target_sum = n / 2.0
    
    def obj_func(x):
        corrs = compute_corrs(x) * dx
        return logsumexp(beta * corrs) / beta
    
    def obj_jac(x):
        corrs = compute_corrs(x) * dx
        shifted = corrs - corrs.max()
        w = np.exp(beta * shifted)
        w /= w.sum()
        all_g = grad_all_corrs(x)
        return dx * (w @ all_g)
    
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': lambda x: x.sum() - target_sum,
             'jac': lambda x: np.ones(n)}]
    
    try:
        res = minimize(obj_func, h0, jac=obj_jac, method='SLSQP',
                      bounds=bounds, constraints=cons,
                      options={'maxiter': maxiter, 'ftol': ftol})
        h_out = project_feasible(res.x, target_sum)
    except Exception:
        h_out = project_feasible(h0, target_sum)
    return h_out, c5_of_h(h_out)

    target_raw = target_norm * n / 2.0

    s_init = max(0.0, current_raw - target_raw) + 0.001

    def ep_obj(x):
        h = x[:n]
        s = x[n]
        val = s
        if rho > 0:
            val += rho * np.sum((h - h_anchor)**2) / n
        return val
    
    def ep_obj_jac(x):
        h = x[:n]
        jac = np.zeros(n + 1)
        jac[n] = 1.0
        if rho > 0:
            jac[:n] += 2.0 * rho * (h - h_anchor) / n

        return x[:n].sum() - target_sum

        jac[:n] = 1.0
        return jac
