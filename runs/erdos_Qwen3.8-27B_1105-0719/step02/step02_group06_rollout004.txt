def project_to_box_sum(x, target_sum):
    n = len(x)
    x = np.clip(np.nan_to_num(x, nan=0.5, posinf=1.0, neginf=0.0), 0.0, 1.0).copy()

        if s > target_sum:

    x = np.clip(x + (lo + hi) / 2.0, 0.0, 1.0)
    diff = target_sum - x.sum()

Change from this term: (h[a]+δ)(1-h[b]+δ) - h[a](1-h[b]) = δ(1-h[b]) + h[a]δ + δ²

Are there other terms involving a or b?
- b in first position: i=b. But i_hi = min(N-1, N-1-d). If b ≤ N-1-d, then b is in range. The term is h[b]*(1-h[b+d]). Change: (h[b]-δ)*(1-h[b+d]) - h[b]*(1-h[b+d]) = -δ(1-h[b+d])
- a in second position: i+d=a → i=a-d. If a-d ≥ i_lo and a-d ≤ i_hi, the term is h[a-d]*(1-h[a]). Change: h[a-d]*(1-(h[a]+δ)) - h[a-d]*(1-h[a]) = -h[a-d]*δ
- b in second position: i+d=b → i=b-d=a. This is the same term as "i=a" which we already handled!

So for d=b-a>0:
- The "i=a" term gives: δ(1-h[b]) + h[a]δ + δ² (quadratic, coeff +1)
- "i=b" term (if b in range): -δ(1-h[b+d])
- "i=a-d" term (if a-d in range): -h[a-d]δ

Total: δ[(1-h[b]) + h[a] - (1-h[b+d])*I(b in range) - h[a-d]*I(a-d in range)] + δ²

So the quadratic coefficient is +1 (from the product term). The linear coefficient depends on other terms.

For d=a-b>0 (so a=b+d):
The term where i=b: h[b]*(1-h[b+d]) = h[b]*(1-h[a]) → becomes (h[b]-δ)*(1-(h[a]+δ)) = (h[b]-δ)*(1-h[a]-δ)
Change: (h[b]-δ)(1-h[a]-δ) - h[b](1-h[a]) = -δ(1-h[a]) - h[b]δ + δ² = -δ(1-h[a]+h[b]) + δ²

So quadratic coeff is +1 here too.

For d=0:
Every term h[i](1-h[i]) that involves a or b gives a -δ² term.
- i=a: change = δ(1-2h[a]) - δ²
- i=b: change = δ(2h[b]-1) - δ²
Total: δ(2h[b]-2h[a]) - 2δ². Quadratic coeff is -2 (concave!).

So the only problematic case is d=0, where we get a concave quadratic. For all other shifts, we get either linear or convex quadratic (coeff +1).

For d≠0, the max of (linear or convex quadratic) functions is convex. So for d≠0, the 1D problem is convex.

For d=0, we have a concave quadratic mixed with convex/linear ones. The max of these is still... well, it's the max of a set of functions where one is concave and others are convex. The max is not guaranteed to be convex.
