The key difference between the smooth minimax approach and the active-set approach:
- Active set: only penalizes constraints above threshold t, can be noisy when active set changes
- Log-sum-exp: smoothly weights ALL constraints, giving a more stable gradient that naturally rebalances all near-max constraints

The log-sum-exp approach:
- Phi_tau(h) = M + tau * log(sum(exp((C_j - M)/tau)))
- As tau → 0, this approaches max(C_j)
- Gradient: sum_j p_j * grad(C_j) where p_j = exp((C_j - M)/tau) / sum(exp(...))

This should give a more balanced descent direction that simultaneously reduces all near-max constraints.

Let me also think about the gradient computation:
- C_j = sum_i h[i] * (1 - h[i-d]) * dx where d = j - (n-1)
- For d >= 0: i ranges from d to n-1
- For d < 0: i ranges from 0 to n-1+d

The gradient of C_j with respect to h[i]:
- ∂C_j/∂h[i] = (1 - h[i-d]) for the first term
- ∂C_j/∂h[i-d] = -h[i] for the second term

In the anti-symmetric representation:
- h[0:m] = q[0:m]
- h[m:2m] = 1 - q[2m-1-i+1] = 1 - q[m-1-(i-m)] for i in [m, 2m)
  So h[i] = 1 - q[2m-1-i] for i >= m

Actually let me be more careful. If n = 2m:
- h[i] = q[i] for i = 0, ..., m-1
- h[i] = 1 - q[m-1-(i-m)] = 1 - q[2m-1-i] for i = m, ..., 2m-1

So the mapping is: h[i] pairs with h[2m-1-i], and h[i] + h[2m-1-i] = 1.

For the gradient w.r.t. q[k]:
- q[k] affects h[k] directly (for k < m)
- q[k] affects h[2m-1-k] as (1 - q[k])

So ∂h[k]/∂q[k] = 1 and ∂h[2m-1-k]/∂q[k] = -1

Therefore: ∂C_j/∂q[k] = ∂C_j/∂h[k] * 1 + ∂C_j/∂h[2m-1-k] * (-1)
= ∂C_j/∂h[k] - ∂C_j/∂h[2m-1-k]

This is the key transformation for the gradient.

def corr_grad_h(h, d, n):
    """Gradient of correlation output at lag d with respect to h."""
    g = np.zeros(n)
    if d >= 0:
        # C = sum_{i=d}^{n-1} h[i] * (1 - h[i-d])
        valid = np.arange(d, n)
        g[valid] += (1.0 - h[valid - d])
        g[valid - d] -= h[valid]
    else:
        # d < 0, let d2 = -d
        # C = sum_{i=0}^{n-1+d2} h[i] * (1 - h[i+d2])
        d2 = -d
        valid = np.arange(0, n - d2)
        g[valid] += (1.0 - h[valid + d2])
        g[valid + d2] -= h[valid]
    return g

    m = n // 2

    scores = np.clip(scores, -50, 50)

    if Z < 1e-300:

        p = np.ones(2*n-1) / (2*n-1)

def project_to_target(x, target_sum):
    """Project x to [0,1]^n with sum = target_sum using bisection."""
    lo, hi = -2.0, 2.0
    for _ in range(60):

            hi = mid

        if mask.any():
            h[mask] += diff / mask.sum()
        else:
            # Spread uniformly
            h += diff / len(h)
    return np.clip(h, 0.0, 1.0)

def eval_c5(h):
    n = len(h)
    return float(np.max(np.correlate(h, 1.0 - h, mode='full')) * (2.0 / n))


def build_anti(q, n):
    m = n // 2
    h = np.empty(n)
    h[:m] = q
    h[m:] = 1.0 - q[::-1]
    return h


def q_of_anti(h, n):
    m = n // 2
    return 0.5 * (h[:m] + 1.0 - h[n-1:m-1:-1])


def corr_grad_h(h, d, n):
    g = np.zeros(n)
    if d >= 0:
        g[d:n] += (1.0 - h[0:n-d])
        g[0:n-d] -= h[d:n]
    else:
        d2 = -d
        g[0:n-d2] += (1.0 - h[d2:n])
        g[d2:n] -= h[0:n-d2]
    return g


def smooth_phi_grad(q, tau, n):
    m = n // 2
    h = build_anti(q, n)
    dx = 2.0 / n
    C = np.correlate(h, 1.0 - h, mode='full') * dx
    M = C.max()
    scores = (C - M) / tau
    scores = np.clip(scores, -60, 60)
    exp_scores = np.exp(scores)
    Z = exp_scores.sum()
    if Z < 1e-300:
        p = np.ones(2 * n - 1) / (2 * n - 1)
    else:
        p = exp_scores / Z
    phi = M + tau * np.log(Z)
    g_h = np.zeros(n)
    for j in range(2 * n - 1):
        if p[j] < 1e-14:
            continue
        d = j - (n - 1)
        g_h += p[j] * dx * corr_grad_h(h, d, n)
    g_q = g_h[:m] - g_h[n-1:m-1:-1]
    return phi, g_q

    lo, hi = -2.0, 2.0

            hi = mid

    best_c5 = eval_c5(best_h)

    return best_h, best_c5, len(best_h)
