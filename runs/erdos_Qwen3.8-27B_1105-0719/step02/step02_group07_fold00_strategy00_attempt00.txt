## 1. Approach and rationale

The supplied parent construction is already close to the desired bound, so the remaining gain must come from improving the local treatment of the maximum of many lag correlations rather than from reformulating the whole problem from scratch. The main limitation of a simple “smooth objective” strategy is that a finite smoothing parameter leaves several active or nearly active lags privileged; conversely, an unsmoothed maximum is nonconvex and nonsmooth. The central idea is therefore to combine three complementary local mechanisms in a compact symmetric search space, with exact evaluation and a multiscale repair step:

1. **Double-smoothing descent to a near-maximizing point.** Use the far stronger log-sum-exp surrogate on the array of all lag correlations. Optimize its gradient, not only the exact maximum, using L-BFGS or similar bounded coordinate variables. This avoids the step-size sensitivity of epigraphic NLP solvers and is much cheaper than exact `max`-value derivative-free work, while still building movement in the direction of reducing the currently largest lags.

2. **Direct exact active-set epigraph solve.** Whenever a smooth-optimization descent has a point with reduced correlations, refine it by solving a nonconvex epigraph problem
   \[
   \min_{t,q} t \quad \text{s.t. } r_j(q)=t-c_j(h(q))\ge 0,
   \]
   with a sparse or enlargeable active set of lags. Unlike smoothing alone, this directly optimizes the actual objective `max c_j` by allowing the largest lags to move together.

3. **Discrete bootstrap plus continuous refinement.** Use the fact that if the parent correlations cluster near one integer lag count per lag, small integer sequences often encode a useful cage around the active lags. A symmetric binary simulated-annealing search across q bits can reveal lower plateau regions, especially for resolutions near 120–220. Each useful binary result is then softly relaxed (starting continuous variables near 0/1) and passed to the same continuous solvers. This is not regarded as a binary lower-bound proof but as a reliable construction mechanism.

4. **Coarse-to-fine resolution with guaranteed feasibility.** Change resolution only when a projected/interpolded candidate is explicitly accepted by the task evaluator, always keeping a feasible parent vector. This allows a lower lag count of objective to gain expressive room for fractional step functions used by the smooth solvers, while permitting falling back to the initial construction if refinement worsens the qualified value.

The overall method remains a local nonconvex search. It is not claimed to be globally optimal and should not be reported as a global optimum. However, it uses meaningful structure: exact score, derivative information, a mathematically well-enforced sum constraint under symmetric complement mapping, direct epigraph for corrective local search, and binary seeding that can escape local smoothing plateaus. Any conclusion uses acceptance by the original evaluator.

### 2.1 Exact task objective in matrix terms

For a selected even resolution `n`, let `h[k]`, `k=0..n-1`, be sampled values on `[0,2]`, represented by cell widths
\[
dx=2/n.
\]
Feasibility is exactly
\[
0\le h_i\le 1, \quad \sum_{i=0}^{n-1}h_i = n/2.
\]
The authoritative task metric is
\[
F(h)=\max_{\ell=0}^{2n-2} C_\ell(h)dx,
\]
where
\[
C_\ell(h)=\operatorname{correlate}(h, 1-h, mode='full')[\ell]=\sum_{i\in I_{s(\ell)}} h_i(1-h_{i+s(\ell)}).
\]
The lag shift associated with the `full` output is
\[
s(\ell)=\ell-(n-1),
\]
and the valid overlap indices are
\[
I_{s}=\{i: \max(0,-s)\le i\le \min(n-1,n-1-d_s)\}.
\]
or, equivalently in code, one can use the output of a standard full `np.correlate`. Not every lag has the same overlap width, and no transformation to autocorrelation or circular correlation is allowed or used.

Because `np.correlate(h,1-h,'full')` is linear in the two arrays, each value is bilinear in `h`:

\[
C_s(h)=\sum_{i\in I_s} h_i -\sum_{i\in I_s} h_i h_{i+s}.
\]

The block gradient from one lag is essential. For a lag written as a matrix operator `A_s` producing the paired terms `h_i*h_{i+s}`, the gradient of `C_s` w.r.t. `h` is:

\[
\frac{\partial C_s}{\partial h_j}=J_j - \sum_{\substack{i\in I_s,\ i+s=j}} h_i - \sum_{\substack{i\in I_s,\ i=j}} h_{i+s}.
\]

Practically for a single lag `d`:

- If `j` is a first location: the term `h_j(1-h_{j+d})` symifies in `h_j` gives `1-h_{j+d}`.
- If `j` is the second location of a cross-product term from lower index `i=j-d`: locally different coordinates often have the net derivative from `-h_i h_j` with respect to `h_j` equals `-h_i`.

Together with the leading linear term `h_j` this is correctly collected by adding, for each valid pair `(i,d)`:
\[
\partial_j C_s \leftarrow \partial_j C_s + dx (1-h_{i+d}),
\]
\[
\partial_{i+d} C_s \leftarrow \partial_{i+d} C_s + dx (-h_i).
\]

For a given lag matrix `A`, a linear gradient term with weights `w_s` is:
\[
\nabla\left(dx\sum_{l,d}w_d CJane)\right)=\sum_d w_d \nabla C_d,
\]
where the two-addition pair expansion above is exactly the standard derivative.

### 2.2 Symmetric coordinate map and why the sum constraint is exact

Define `q\in[0,1]^m`, with `m=n/2`. Build `h` symmetrically:

\[
h_i=q_i,\quad 0\le i<m;
\]
\[
h_{n-1-j}=1-q_j,\quad 0\le j<m.
\]
Equivalently:
```
h[0:m] = q
h[m:n] = 1 - q[::-1]
```

Then:

\[
\sum_i h_i=\sum_{j=0}^{m-1}q_j+
\sum_{j=0}^{m-1}(1-q_j)=m=n/2
\]

automatically. Thus the symmetric search space contains only bound constraints. This maps the symmetric candidate manually back through `make_sym_h`; the norm closure of variables `q` bounds are direct.

A `q` vector can be recovered from a complete feasible `h` by averaging the two possible symmetric definitions:
\[
q_j=\frac{h_j+1-h_{n-1-j}}{2},
\]
after which it can feasibly be clipped to `[0,1]`. Since the mapping has exact m-sum for any feasible `q`, the sum of the returned symmetric function remains feasible except for subsequent rounding.
