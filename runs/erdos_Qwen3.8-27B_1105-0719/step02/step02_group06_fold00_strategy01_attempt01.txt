<strategy>
1. Approach and rationale

1.1 Central idea

Build all candidates as anti-palindromic step functions of the form

- `h[0:m] = q[0:m]`
- `h[n-1-r] = 1 - q[r]` for r = 0,...,m-1, where `m = n/2`

and then optimize `q` in this reduced space. This ensures exactly the continuous constraint `∫ h = 1` in the mathematical functional sense, because each of the `m` symmetric pairs contributes unit weight:

`h[r] + h[n-1-r] = q[r] + (1 - q[r]) = 1`.

After a candidate is generated, it is still verified and repaired with an exact bounded-sum projection; anti-palindromicity is therefore a search-heuristic, not a claimed global reduction. Exact evaluation through the authoritative correlation formula decides every acceptance; when no improved non-parent candidate is found, the supplied parent remains a valid fallback.

1.2 Why this can improve previous work

The previous high-dimensional smoothed-max and compact epigraph/SLSQP scheme suffered from three bottlenecks:

1. It optimized a smoothed or surrogate proxy and reconstructed the hard maximum only afterward, losing the exact active constraints.
2. It treated feasibility by post hoc symmetrization/projection, so many intermediate iterates were not structurally on the feasible manifold.
3. It had little global exploration: most seeds came from parent-based local descent.

The proposed search replaces those parts with a combination of:

- automatic symmetric feasibility and therefore no equality constraint or persistent global-sum repair inside the inner local solver;
- a row-generating active-set epigraph local solver specialized to the first-halfangent variable `q`, using only the full, exact finite-support correlation;
- multiple independent seed generators: parent transfer, deterministic harmonic/pulse seeds, continuous multistart, and binary anti-palindromic simulated annealing;
- a disciplined multi-resolution neighborhood sweep, because the discrete evaluator can be sensitive to alignment and resolution.

This remains a heuristic. It does not claim global optimality. Bounds are reported only from explicitly validated nonnegative bounded floating vectors whose exact objective is recomputed.

2. Mathematical specification

2.1 Exact discrete objective

For vector `h` of length `n`, with `dx = 2/n`, the objective used throughout is exactly

`C(h) = max_tau dx * sum_i h[i] * (1 - h[i + tau - (n - 1)])`

over all full linear-correlation lag indices `tau = 0,...,2n-2`, excluding invalid terms for which the shifted index lies outside `0,...,n-1`. Equivalently, the lag index corresponds to shift

`delta = tau - (n - 1)`.

A weak discrete integration convention is:

For lag `tau`, all integer `i` satisfying

- `low = max(0, -delta)`
- `high = min(n - 1, n - 1 - delta)`

are valid. The raw correlation value for this lag is

`A_tau = sum_{i=low}^{high} h[i] * (1 - h[i + delta])`.

Then `c_tau = dx * A_tau` and `C(h) = max_tau c_tau`. This uses linear, finite-support correlation and includes both positive and negative shift directions automatically through the full lag range. It is not circular autocorrelation.

2.2 Symmetric parametrization

Let an even resolution be `n = 2*m` and `h` be constructed from `q` of length `m`:

`h[0], ..., h[m-1] = q[0], ..., q[m-1]`

and

`h[n-1-r] = 1 - q[r]`, r = 0,...,m-1.

Thus `h` consists of `m` exact pairs that algebraically sum to `m = n/2`, so the mathematical integral constraint is

`sum(h) * dx = m * 2/n = 1`.

The floating implementation may accumulate tiny numerical error; the final candidate receives the exact feasibility repair below.

Define

`q_from_h(h) = 0.5 * (h[i] + (1 - h[n-1-i]))` for i = 0,...,m-1, followed by clipping to `[0,1]`. This reduces an arbitrary vector into the symmetric manifold. For any repaired final candidate, symmetrization is used as a seed; acceptance is always by exact objective.

2.3 Anti-differentiation

Constraints are generated from exact active lag correlations. Let `g_raw(k)` be the derivative of the unscaled raw correlation `A_tau` with respect to full vector `h`, without `dx`. With `delta = tau - (n - 1)`, initialize all entries of `g_raw` to zero. For

`i = max(0, -delta), ..., min(n-1, n-1-delta)`

set `j = i + delta` and add

`g_raw[i] += 1 - h[j]`
