But wait, what if i+d = j or j+d = i? Then there's a cross term.

If i+d = j (i.e., d = j-i): the term h[i]*(1-h[j]) is present in r_d.
After change: (h[i]+δ)*(1-(h[j]-δ)) = (h[i]+δ)*(1-h[j]+δ) = h[i]*(1-h[j]) + δ*(1-h[j]) + h[i]*δ + δ²

So the change is δ*(1-h[j]+h[i]) + δ². There IS a quadratic term!

Similarly, if j+d = i (i.e., d = i-j < 0): the term h[j]*(1-h[i]) is present.
After change: (h[j]-δ)*(1-(h[i]+δ)) = h[j]*(1-h[i]) - δ*(1-h[i]) - h[j]*δ + δ²
Change: -δ*(1-h[i]+h[j]) + δ²

So the quadratic term appears only when d = j-i or d = i-j (the lag exactly connecting i and j).

For all other lags, the change is purely linear.

```python
def pair_minimize(h, i, j, r_affected, a_affected, c_affected, n):
    """Find optimal δ for transferring from j to i."""
    hi = min(1.0 - h[i], h[j])
    lo = max(-h[i], h[j] - 1.0)
    if hi - lo < 1e-12:
        return 0.0
    
    def f(delta):
        return float(np.max(r_affected + a_affected * delta + c_affected * delta * delta))
    
    # Golden section search
    gr = (np.sqrt(5.0) - 1.0) / 2.0
    a, b = lo, hi
    c = b - gr * (b - a)
    d = a + gr * (b - a)
    fc = f(c)
    fd = f(d)
    for _ in range(40):
        if fc < fd:
            b = d
            d = c
            fd = fc
            c = b - gr * (b - a)
            fc = f(c)
        else:
            a = c
            c = d
            fc = fd
            d = a + gr * (b - a)
            fd = f(d)
    delta = (a + b) / 2.0
    return delta
```

```python
    """Get lags (d values) affected by changing h[i] and h[j]."""
    # A lag d is affected if i or j participates in r_d
    # i participates in r_d if: max(0,-d) <= i <= min(N-1, N-1-d) OR max(0,-d) <= i-d <= min(N-1, N-1-d)

        j_is_first = (i_lo <= j <= i_hi)
        j_is_second = (i_lo <= j-d <= i_hi)
        if i_is_first or i_is_second or j_is_first or j_is_second:
```
