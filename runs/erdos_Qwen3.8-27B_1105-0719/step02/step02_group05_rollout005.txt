d(corr[k])/dh[j] = (1 - h[j+d]) * I(j+d valid) + (-h[j-d]) * I(j-d valid)
                 = (1 - h[j+d]) * I(0 ≤ j+d < n) - h[j-d] * I(0 ≤ j-d < n)

For d ≥ 0:
  d(corr[k])/dh[j] = (1 - h[j+d]) * I(j+d < n) - h[j-d] * I(j ≥ d)
  = (1 - h[j+d]) * I(j < n-d) - h[j-d] * I(j ≥ d)

For d < 0, let e = -d > 0:
  d(corr[k])/dh[j] = (1 - h[j-e]) * I(j ≥ e) - h[j+e] * I(j+e < n)
  = (1 - h[j-e]) * I(j ≥ e) - h[j+e] * I(j < n-e)

Now, d(corr[k])/dq[i] = d(corr[k])/dh[i] + sum_{j=m}^{2m-1} d(corr[k])/dh[j] * dh[j]/dq[i]

For j ≥ m: h[j] = 1 - q[2m-1-j], so dh[j]/dq[i] = -δ(2m-1-j, i) = -δ(j, 2m-1-i)

So: d(corr[k])/dq[i] = G[i] - G[2m-1-i] where G[j] = d(corr[k])/dh[j]
