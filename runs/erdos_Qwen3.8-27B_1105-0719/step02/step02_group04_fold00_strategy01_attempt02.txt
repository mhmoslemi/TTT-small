1. Approach and rationale

1.1 Central idea

The provided evaluator is the discrete, nonsmooth maximin quantity

C5(h) = max_j A_j(h),

where

A_j(h) = dx * sum_{valid i} h[i] * (1 - h[i - d(j)]),

dx = 2 / n_points,

or equivalently the exact scaled correlation returned by

dx * np.correlate(h, 1 - h, mode="full").

The current parent construction is close to the target: its reported value is about 0.380938 and the desired target is 0.3808. The bottleneck is therefore not finding a gross global structure, but resolving a small, smoothed barrier created by a cluster of comparable overlap lags. Scalar penalties or smoothed maxima often struggle near such clusters because the next activity may lie just outside the penalized top set, and the local gradient direction may be dominated by inactive or barely inactive terms.

The selected primary method is a dynamic active-set epigraph method. Instead of squeezing the nonsmooth maximum into one scalar objective, solve a sequence of smooth local epigraph problems of the form

minimize t
subject to t >= A_j(h(q)) for selected active lags j,
plus the feasible bounds on the decision variables.

At every outer iteration, the active lag set is reselected from the exact evaluator. After each inner subproblem, every proposed candidate is re-evaluated with the original discrete correlation objective. Only candidates whose exact C5 is smaller than the currently accepted best are committed as improvements. This preserves the exact task metric even though the inner subproblem is an approximation.

This is materially different from the previous program, which primarily used nonsmooth-penalty reduced models in L-BFGS-B and only indirectly enforced the max constraints. Here the surrogate explicitly contains the epigraph variable t and exact inequalities for currently relevant overlap lags. The gradients are analytical derivatives of the exact overlap expressions. The active set is updated from the full discrete evaluator, and the nonconvexity is handled by exact line search and exact acceptance, not by claiming that the surrogate approximates a convex problem.

1.2 Why the active epigraph can improve the parent

At a local maximin optimum, many lags share the same active value, or at least lie within a small band. Any useful improvement must reduce almost all of these simultaneously. A scalar soft-max objective tries to minimize approximate p-values of the cluster. An epigraph subproblem imposes the exact smooth constraints

t - A_j(h(q)) >= 0

for the actual cluster. When the exact A_j are reduced faster than t, the local active-set solution produces meaningful descent directions. When the active constraints are satisfied in the subproblem but the inactive set becomes the new max, the exact evaluator rejects the candidate and the algorithm can enlarge the active set or shrink the step.

This local method is not a proof of global optimality. It is a carefully constrained local method whose acceptance is hard-coded against the official objective. Random multi-starts, perturbations, and resolution changes provide the only escape mechanism from local minima.

1.3 Automatic feasibility through a paired anti-symmetric representation

Many optimized step-type representatives are close to the anti-symmetric structure

h[i] + h[n-1-i] = 1,

possibly with a central 1/2 when n is odd. The anti-symmetric representation

h[0:m] = q,
h[n-m:n] = 1 - reverse(q),

and, for odd n, h[m] = 1/2, makes the discrete integral constraint automatic because paired coordinates contribute exactly 1. In that representation, the only feasibility concerns are

0 <= q[i] <= 1.

This representation is robust and avoids scalar bucket sums plus clipping inconsistencies. Most of the method is implemented on q in dimension m = floor(n/2). The solver is allowed to test general unstructured vectors in one optional phase, but a general candidate is repaired with a mass-preserving box projection before exact acceptance, and only exact repaired objective values contribute to the reported result.

1.4 Limitations and non-assumptions

- The epigraph subproblem is nonconvex because each A_j contains bilinear terms q[i] q[i - c] after the paired builder is substituted.
- SLSQP is used only for the inner augmented smooth subproblem. The final merit is always the exact discrete overlap maximum.
- If the nonlinear inner solve fails, or if all line-searched steps violate the exact objective more than the current point, the current best construction is retained.
- The method is expected to refine a supplied good parent, especially when it is close to active-set stationary. The global structure of the lattice-space Erdos overlap problem remains hard and no global optimality of the output is claimed.
- Restricting to the paired representation may discard asymmetric better vectors; an optional general epigraph phase is included to probe this, with exact feasibility repair and exact acceptance.

2. Mathematical specification

2.1 Discrete objects and exact evaluator

Let h have length n. Define dx = 2 / n and define the correlation output length as 2n - 1. For each output index j = 0, 1, ..., 2n-2 define

d = j - (n - 1).

The exact unscaled correlation used by the evaluator is

R_j(h) = sum over i such that both h[i] and h[i - d] are inside [0, n-1]
         h[i] * (1 - h[i - d]).

Explicitly,

if d >= 0:
    R_j(h) = sum_{i=d}^{n-1} h[i] * (1 - h[i - d])
if d < 0:
    R_j(h) = sum_{i=0}^{n+d-1} h[i] * (1 - h[i - d])

because d is negative in the second case.

The exact scaled overlap vector is

C_j(h) = (2 / n) * R_j(h).

The exact task objective is

F(h) = max_j C_j(h).

The final return must report max over all 2n - 1 lags, not only positive lags and not a circular or periodic analogue.

The returned vector must satisfy

0 <= h[i] <= 1 for all i,
sum_i h[i] = n / 2.

Equivalently for the height integral, dx * sum_i h[i] = 1.

2.2 Paired anti-symmetric representation

Define, for a vector q of length m = floor(n/2),

for i = 0, ..., m-1:

h[i] = q[i]
h[n-1-i] = 1 - q[i].

If n is odd, index m exists in the center and is set to 1/2. The pair construction gives exactly

h[i] + h[n-1-i] = 1,

so the central-of-pairs sum is exactly m for even n or m + 1/2 for odd n, which corresponds to n/2.

Because each q[i] is bounded in [0, 1], h is automatically bounded in [0, 1]. The scalar constraint is guaranteed by construction. To avoid floating-point drift in the project of an arbitrary h into q, define the symmetrizing projection

q[i] = 0.5 * (h[i] + 1 - h[n-1-i])

and clip q to [0, 1]. This is not an exact projection onto all general h, only onto the anti-symmetric feasible set. Creating h from projected q removes the mass projection problem for the main search.

For general h repair, a top-level waterfill function is required. Its definition is in section 5.

2.3 Exact gradients of the overlap functions

Define G_j(h) as the length-n gradient of C_j(h) with respect to h. Since C_j is already scaled, include the dx = 2/n scale factor or take R_j's gradient and multiply by dx after each gradient accumulation.

Let d = j - (n - 1). Then:

If d >= 0:
  G_j[d:n]   += dx * (1 - h[d:n])
  G_j[0:n-d] -= dx * h[d:n]

If d < 0:
  let e = -d.
  G_j[0:n-e] += dx * (1 - h[e:n])
  G_j[e:n]   -= dx * h[0:n-e]

These formulas match the orientation of np.correlate(h, 1-h, mode="full"): for central lag d=0, the gradient entry for h[i] is dx * (1 - 2 h[i]) from both derivatives in the formula. This can be determinant-checked with a direct finite-difference test in the code. The objective evaluator remains independent; if a gradient implementation were short-circuited, exact evaluation would still deliver a valid objective value when the same h array is returned with exact formalized structure.

2.4 Gradient under q builder

For even n, paired coordinates are

z_plus[i] = q[i],
z_minus[i] = n - 1 - i, with value 1 - q[i].

A positive increase of q[i] raises h[i] and lowers h[n-1-i]. For any full-length gradient g, the induced q-gradient is

g_q[i] = g[i] - g[n - 1 - i].

For odd n, the center index m = n // 2 is independent of q and is ignored in g_q. The returned q vector must have length m = n // 2. The q-gradient constructor must produce exactly length n // 2 (for odd n) or length n/2 (for even n). If m = 0 or small edge units, skip length-zero operations.

2.5 Epigraph subproblem in q-space

Given the current feasible q with builder h and current scalar value c, select an active output-index array A from the exact overlap array C(h). Let B = len(A). The decision vector is

z = [q[0], ..., q[m-1], t],

with t scalar. The inner solve approximates the local maximin problem

minimize t
subject to t - C_{A[r]}(h(q)) >= 0 for r = 0, ..., B-1,
bounds 0 <= q[i] <= 1,
bounds 0.0 <= t <= max(1.0, c + 1.0).

No equality is required in q-space because the paired builder automatically satisfies the integral constraint.

The linear objective is f(z) = t. Its analytical gradient is the length m + 1 array consisting of m zeros and then 1.

The inequality function, in SciPy SLSQP convention, should be

F_r(z) = t - C_{A[r]}(h(q)),

so that the feasible requirement is F_r >= 0.

If I_r denotes the full length-n gradient computed by section 2.3 converted to q-gradient by section 2.4, then the constraint rows are

(J_F)_{r, [0:m]} = -I_r,
(J_F)_{r, m} = -1.

No contribution from builder anti-pairing is ignored: the q gradient above already includes both h and its paired coordinate. This exact Jacobian lets SLSQP solve the smooth local active epigraph model robustly.

If no Jacobian is supplied, SLSQP finite-differences everything. Supply the Jacobian. In practice, the objective Jacobian is dense and the constraint Jacobian has dimensions B x (m + 1), which is manageable for n around 126 and active set size below 200.

2.6 Optional full epigraph phase

For a general unstructured solve, use decision

z = [h[0], ..., h[n-1], t],

with equality

E(z) = sum_i h[i] - n/2 = 0,

and bounds

0 <= h[i] <= 1,
0 <= t <= max(1, c + 1).

Objective f(z) = t, with gradient zeros except final 1. Inequality rows for previously active or top blocks are the same

F_r(z) = t - C_{A[r]}(h),

with Jacobian rows having -G_j for h components and -1 for t. Equality Jacobian is the length n vector of ones followed by 0.

Because SLSQP can introduce inexact equality satisfaction, every full-vector proposition must be passed through the mass-preserving feasibility repair described in section 5 before its exact objective is accepted. A full-vector proposal is never returned unprocessed. The exact maximum after repair is the value used.

1. Approach and rationale

1.1 Central result and why this is a different method

The evaluator is the nonsmooth discrete maximin value

C5(h) = max_j (2/n) * sum_{valid i} h[i] * (1 - h[i - d_j]),

where j runs over the 2n-1 output indices of `np.correlate(h, 1-h, mode="full")` and d_j = j - (n-1). The supplied parent is near the target, so the remaining barrier is not finding an entirely new global shape but resolving a local maximin cluster. Many top lags are nearly tied, and reducing just one lag raises another by only 10^-4 or less.

The previous program primarily used smooth or reduced penalty models and L-BFGS-B on scalar surrogate functions. The present plan is materially different: it solves a sequence of epigraph nonlinear programming subproblems of the form

minimize t subject to t >= A_j(h) for an actively selected set of overlap lags j.

The active lag set is refreshed from the exact discrete correlation array after every outer iteration. All accepted output vectors are judged only by the exact evaluator, not by the surrogate. The subproblem is solved with analytical gradients, avoiding blind finite-difference or penalty methods. This direct epigraph active-set method is targeted at small, maximin-aware moves: it tries to select lag patterns where the parent has active inequality tangencies and reduce these simultaneous terms together.

The only nonconvexity concerns are contained inside the local epigraph subproblem. Acceptance is strict: a candidate must decrease the exact `max Correlation` objective. If an epigraph move improves the moment shape but causes some unmodelled lag to become the new maximum, the exact evaluator rejects or withholds it. Then the active set can grow, step sizes can shrink, or random restarts can escape a local plateau.

1.2 Why it can improve the provided parent

The current parent may already be close to a local KKT point for one activeable cluster. The target gap is about only 1.4e-4. The easiest useful step is to reweight and relocate the correlations that are already at the max. An epigraph subproblem directly models these inequalities. A smooth-penalization method can become insensitive because many lower lags distort its penalty direction; an exact epigraph local solve instead incorporates them dynamically. A final line search with the exact global maximum ensures nonmonotone surrogate attempts can still lead to a measurable descent.

Another important different axis is using a variable resolution search with strictly computed short sequences and alternating symmetric and unstructured representations. The paired representation automatically satisfies the integral constraint, making lower-dimensional feasible moves robust. The optional full-coordinate epigraph phase can inspect asymmetric local possibilities that symmetric pattern charts miss. Shorter resolutions are tried because they may avoid a restrictive discretized local optimum and have lower evaluation cost, while all candidates are evaluated by the official exact metric.

1.3 Correctness stance

The method is local and nonconvex. It does not claim a global minimum. Nevertheless, all final results are guaranteed numerically feasible by construction or by the prescribed mass-preserving repair, and the deployed C5 is always computing with the actual discrete correlation formula. If all improved moves fail, the sanitized parent or the deterministic fallback vector is returned. Growing active rejection after infeasible moves is handled through exact acceptance, not by approximating the full evaluator.
