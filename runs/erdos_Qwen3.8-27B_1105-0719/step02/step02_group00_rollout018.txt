- Suppose constraints d_1, ..., d_r are active (P_{d_j} = t).
- We want to find h that satisfies:
  P_{d_j}(h) = t for all j
  sum(h) = n/2
  (optimality: gradient condition)

The Newton system:
Let F(h, t, μ) = [P_{d_1}(h) - t, ..., P_{d_r}(h) - t, sum(h) - n/2, ∇_h (∑ μ_j P_{d_j}(h)) - ν*1]

This is a system of r + 1 + n equations in n + r + 1 + 1 = n + r + 2 unknowns. As I noted, it's underdetermined by 1.

The resolution: we fix t (or one of the μ_j) and solve the rest. Or we can use the fact that ∑ μ_j = 1 (from the KKT condition on t).

With ∑ μ_j = 1 as an additional constraint:
- r equations: P_{d_j}(h) = t
- 1 equation: sum(h) = n/2
- n equations: (∑ μ_j ∇P_{d_j})(h) = -ν * 1 (all components equal)
- 1 equation: ∑ μ_j = 1

Total: r + 1 + n + 1 = n + r + 2 equations
Unknowns: n (h) + 1 (t) + r (μ) + 1 (ν) = n + r + 2 ✓

So the system is square! We can solve it with Newton's method.

But this is a nonlinear system (P_d is quadratic in h), so Newton is the right approach.

The Jacobian of this system w.r.t. (h, t, μ, ν):
- ∂(P_{d_j} - t)/∂h = ∇P_{d_j}^T (row vector)
- ∂(P_{d_j} - t)/∂t = -1
- ∂(P_{d_j} - t)/∂μ = 0
- ∂(P_{d_j} - t)/∂ν = 0

- ∂(sum(h) - n/2)/∂h = 1^T
- ∂(sum(h) - n/2)/∂t = 0
- ∂(sum(h) - n/2)/∂μ = 0
- ∂(sum(h) - n/2)/∂ν = 0

- ∂(∑ μ_j ∇P_{d_j} + ν*1)/∂h = ∑ μ_j H_{d_j} (sum of Hessians, where H_{d_j} is the Hessian of P_{d_j})
- ∂(∑ μ_j ∇P_{d_j} + ν*1)/∂t = 0
- ∂(∑ μ_j ∇P_{d_j} + ν*1)/∂μ_j = ∇P_{d_j} (column vector for each j)
- ∂(∑ μ_j ∇P_{d_j} + ν*1)/∂ν = 1 (column vector)

- ∂(∑ μ_j - 1)/∂μ = 1^T (row vector of length r)
- Others = 0

The Hessians H_{d_j}: since P_d is bilinear (quadratic but with no h[i]^2 terms for d ≠ 0), the Hessian is sparse and simple.

For d > 0: P_d = dx * ∑_{i=0}^{n-1-d} h[i+d] * (1-h[i])
∂²P_d/∂h[i+d]∂h[i'] = -dx * δ_{i,i'} (for the cross term)
So H_d has:
H_d[i+d, i] = -dx for i = 0..n-1-d
H_d[i, i+d] = -dx for i = 0..n-1-d

For d = 0: P_0 = dx * ∑ h[i](1-h[i])
H_0[i,i] = -2*dx

For d < 0 (e = -d): similar to d > 0 case.

So the Hessian is very sparse (only 2*(n-|d|) non-zero entries).

This means the Newton system can be solved efficiently!

def active_set_newton(h, active_indices, n_iterations=50):
    """Newton's method for the active-set KKT system."""
    n = len(h)
    dx = 2.0 / n
    r = len(active_indices)
    target = n / 2.0
    
    # Initial guess for μ and ν
    mu = np.ones(r) / r
    nu = 0.0
    
    for it in range(n_iterations):
        # Compute current profile values and gradients
        profile = compute_profile(h)
        t = np.max(profile)
        
        # Residuals
        # F1: P_{d_j}(h) - t = 0 for j = 1..r
        F1 = profile[active_indices] - t  # shape (r,)
        
        # F2: sum(h) - n/2 = 0
        F2 = np.sum(h) - target  # scalar
        
        # F3: sum_j mu_j * gradP_{d_j} + nu * 1 = 0 (n equations)
        G = build_gradient_matrix(h)
        grad_comb = (G[active_indices, :].T @ mu)  # shape (n,)
        F3 = grad_comb + nu * np.ones(n)  # shape (n,)
        
        # F4: sum(mu) - 1 = 0
        F4 = np.sum(mu) - 1.0  # scalar
        
        # Check convergence
        F_all = np.concatenate([F1, [F2], F3, [F4]])
        if np.max(np.abs(F_all)) < 1e-12:
            break
        
        # Build Jacobian
        # The Jacobian is (r+1+n+1) x (n+r+1+1)
        # Variables ordered as: h (n), mu (r), t (1), nu (1)
        
        # J11: dF1/dh = G[active_indices, :]  shape (r, n)
        # J12: dF1/dmu = 0  shape (r, r)
        # J13: dF1/dt = -1 (for each equation)  shape (r, 1)
        # J14: dF1/dnu = 0  shape (r, 1)
        
        # J21: dF2/dh = ones(n)  shape (1, n)
        # J22: dF2/dmu = 0
        # J23: dF2/dt = 0
        # J24: dF2/dnu = 0
        
        # J31: dF3/dh = sum_j mu_j * H_{d_j}  shape (n, n)
        # J32: dF3/dmu = G[active_indices, :].T  shape (n, r)
        # J33: dF3/dt = 0
        # J34: dF3/dnu = ones(n)  shape (n, 1)
        
        # J41: dF4/dh = 0
        # J42: dF4/dmu = ones(r)  shape (1, r)
        # J43: dF4/dt = 0
        # J44: dF4/dnu = 0
        
        # Build the (n+r+2) x (n+r+2) Jacobian
        # Total rows: r + 1 + n + 1 = n + r + 2
        # Total cols: n + r + 1 + 1 = n + r + 2
        
        size = n + r + 2
        J = np.zeros((size, size))
        
        # J[0:r, 0:n] = G[active_indices, :]
        J[0:r, 0:n] = G[active_indices, :]
        # J[0:r, n+r:n+r+1] = -1 (dF1/dt)
        J[0:r, n+r] = -1.0
        
        # J[r, 0:n] = ones (dF2/dh)
        J[r, 0:n] = 1.0
        
        # J[r+1:r+1+n, 0:n] = sum_j mu_j * H_{d_j}
        H_comb = np.zeros((n, n))
        for idx, d_idx in enumerate(active_indices):
            H_d = build_hessian_row(d_idx, h, n, dx)
            H_comb += mu[idx] * H_d
        J[r+1:r+1+n, 0:n] = H_comb
        
        # J[r+1:r+1+n, n:n+r] = G[active_indices, :].T (dF3/dmu)
        J[r+1:r+1+n, n:n+r] = G[active_indices, :].T
        
        # J[r+1:r+1+n, n+r+1] = 1 (dF3/dnu)
        J[r+1:r+1+n, n+r+1] = 1.0
        
        # J[r+1+n, n:n+r] = 1 (dF4/dmu)
        J[r+1+n, n:n+r] = 1.0
        
        # Solve J * delta = -F_all
        F_vec = np.concatenate([F1, [F2], F3, [F4]])
        
        try:
            delta = np.linalg.solve(J, -F_vec)
        except np.linalg.LinAlgError:
            delta = np.linalg.lstsq(J, -F_vec, rcond=None)[0]
        
        # Extract updates
        dh = delta[0:n]
        dmu = delta[n:n+r]
        dt = delta[n+r]
        dnu = delta[n+r+1]
        
        # Damping: ensure step doesn't make things worse
        step = 1.0
        for _ in range(20):

                break
            step *= 0.5
        
        # Renormalize mu
        if mu.sum() > 1e-15:
            mu /= mu.sum()
    
    return h, exact_score(h)

def repair_feasible(vec):
    n = len(vec)
    h = np.clip(np.asarray(vec, dtype=np.float64), 0.0, 1.0)
    target = n / 2.0
    diff = target - h.sum()
    if abs(diff) < 1e-14:
        return h
    if diff > 0:
        # Need to add mass: add to positions with most room
        capacity = 1.0 - h
        order = np.argsort(-capacity)
        remaining = diff
        for i in range(n):
            idx = order[i]
            add = min(remaining, capacity[idx] + 1e-15)
            if add > 0:
                h[idx] += add
            remaining -= add
            if remaining <= 1e-12:
                break
    else:
        # Need to remove mass: remove from positions with most mass
        order = np.argsort(h)
        remaining = -diff
        for i in range(n):
            idx = order[i]
            rem = min(remaining, h[idx] + 1e-15)
            if rem > 0:

            remaining -= rem

                break
    # Final fix

        else:

    return G

    h_new = np.interp(xt, full_xs, full_h)

def smoothed_gradient_descent(h, mu_start=30, mu_end=200, max_iters=500, 
                               tol=1e-13, time_fn=None, time_budget=300):
    """L-BFGS style smoothed minimax optimization."""
    n = len(h)
    dx = 2.0 / n
    h = h.copy()
    best_c = exact_score(h)
    best_h = h.copy()
    
    for it in range(max_iters):
        if time_fn is not None and time_fn() > time_budget:
            break
        
        profile = compute_profile(h)
        t = np.max(profile)
        
        # Compute softmax weights
        shifted = mu_start * (profile - t)
        weights = np.exp(shifted)
        weights /= weights.sum()
        
        # Compute weighted gradient

        grad = G.T @ weights
        grad -= np.mean(grad)  # Remove mean for sum constraint
        
        gnorm = np.linalg.norm(grad)
        if gnorm < 1e-14:
            break
        
        grad /= gnorm  # Normalize
