1.1 Central idea

The task is the exact discrete minimax problem

    C5(h) = max_m P_m(h),
    P_m(h) = dx * [np.correlate(h, 1-h, mode="full")][m],
    dx = 2 / n,

over vectors `h` satisfying `0 <= h[i] <= 1` and `sum(h) = n/2`.

The proposed program does not rely primarily on perturbing the parent with Gaussian noise, a large smoothed epigraph, or one nonlinear sensitivity routine. Instead it uses a deterministic exact preconcave local algorithm built on the local subgradient geometry of the minimax objective.

For the current feasible point, we build a convex directional linear subproblem. Let `P_m` denote exact eager profile rows and let `∇P_m` be analytic derivatives of these rows. Among all scaled feasible directions, including sum-zero and box-transition necessary directions, it finds the direction that most uniformly decreases the currently active and near-active rows:

    maximize alpha
    subject to    ∇P_m dot d + alpha <= 0     for active rows m
                  sum_i d_i = 0
                  1 <= sum_i d_i_positive/d_i_negative <= 1 in a directional norm

This solves the best possible first-order descent direction in the current tangent/active cone. The nonconvex original objective is never accepted with the surrogate value. Every LP-generated proposal is repaired, and only if its exact evaluator is strictly smaller than the current local candidate is the move accepted. Therefore the method accepts monotonically exact progress but uses a genuine convex inner problem rather than random-ish weighted central gradients.
