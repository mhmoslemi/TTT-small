1. Approach and rationale

The supplied evaluator is the nonconvex, finite min--max problem

C5(h) = max over all correlation lags of
       dx * np.correlate(h, 1-h, mode="full"),

with dx = 2/n_points, 0 <= h[i] <= 1 and sum(h) = n_points/2. It is a discrete quadratic problem: each correlation lag is a sum of bilinear terms h_i(1-h_j). No property of the problem justifies a convex global solution claim, and no surrogate value is considered an improvement unless it is accepted by the exact evaluator.

The parent algorithm pursued by the supplied program appears mainly to polish the parent function with closely related smoothing/epigraph processes. That creates risk of a large basin around the parent. This plan deliberately changes the search engine and the exploration directions:

1. The feasible search is first restricted to a representation that automatically satisfies both box and mean constraints for every candidate, so the optimizer never wastes effort on constraint repair.
2. It uses a global stochastic search that treats the full exact objective as a black box, not a smoothed approximation or an active subset taken from the parent only: differential-evolution search in the reduced feasible coordinate vector q. This directly samples both active and inactive lag regimes with exact acceptance.
3. It uses a coarse-to-fine multiresolution chain. Small grids search structurally cheap, binary-like or nearly binary structures using global exact fitness. The best structures are interpolated to finer grids, where deterministic gradient line searches, high-p/log-sum-exp smooth-max descent, coordinate descent, and an active-set epigraph local refiner accept only exact improvements.
4. It fixes trial reduction variables on an "anti-symmetric" feasible manifold h + reversed(h) = 1. This manifold is not claimed to contain every optimum for odd or non-symmetric local optima; it is a deliberately chosen much smaller, exactly constraint-free offset containing many step-function witnesses. All accepted outputs are therefore automatically feasible without disturbing the proposed values through clipping plus independent rescaling.
5. Optional very-small mixed-integer models can expose excellent 0/1 binary substrates when a test backend with a mixed-integer solver is available. If the optional backend is unavailable, slow, or returns errors, that module is silently skipped without affecting the algorithm.

The intended improvement mechanism is not a different sequence of renormalized MIT smooth extrema like before. The combination is substantially different: exact-fitness differential evolution on a feasible q-space, then deterministic exploration via a gradient-art predicted exact path followed by iterative relaxation smooth-max projected descent, coordinatewise exact search, epigraph all as exact-filtered refinements. Final output is chosen among alternative resolutions by recomputing the exact global overlap value every time.

Use startpoints beyond only gradient descent: interpolate the parent to many lengths; explicit discrete structures, binary rounding, binary stochastic mutation, adversarially preserved q transformations, and custom high-performance representation to produce alternative bin matrices.
