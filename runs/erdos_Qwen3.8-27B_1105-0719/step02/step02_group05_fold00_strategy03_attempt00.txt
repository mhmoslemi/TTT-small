1.1 Central idea: binary-guided exact-relaxation search

- First generate and locally move integer/binary structural witnesses on the exact feasible mirror manifold. Binary binary valuations make the search combinatorial rather than gradient dominated and can escape continuous fractional basins that only move local values.
- Then take the best integer/relaxed structural witnesses and relax them along one-dimensional mirror-coordinate line searches, using the exact finite-grid overlap objective for every candidate value. Relaxation accepts only strict exact score improvements.
- Periodically combine exact binary local search, coordinate relaxation, and simple global structural directions (e.g., complements, references, random block resets) on multiple resolutions.
- No surrogate value is trusted as a candidate improvement. All accepted elements are immediately re-scored using the authoritative evaluator definition.

The primary bottleneck addressed is not just reducing the current surrogate value at one grid length, but allowing the search to move through disconnected binary structural basins and then relax back into fractional space along a different direction than the smooth-max surrogate would choose. This can be expected to help when small local coordinate relaxations around the parent basin are blocked by parity-like combinatorial barriers.

1.2 What is mathematically certain versus heuristic
Certain facts used:
- The evaluator objective is exact on the discretized problem: for vector h length n, dx=2.0/n, score=max(np.correlate(h,1-h,mode="full"))*dx.
- The anti-symmetric mirror construction described below automatically satisfies the discrete sum constraint for any even n.
- Candidate acceptance only after exact re-evaluation.
Heuristic hypotheses:
- Binary or near-binary structures often reveal good finite-window correlation structures; binary annealing can reach these regions where surrogate greedy stays trapped.
- One-dimensional exact-objective coordinate relaxation after integer structure discovery can recover fractional improvements without requiring a specific convex coordinate solver.
- Cross-resolution transfer can expose better constants at other finite grid lengths. These are plausible discovery steps, not proof of optimality.

1.3 Scope and non-claim
No global optimality is claimed. The algorithm is a stochastic/local exact-discovery method. It stops because of time, budget, stagnation, or if the target bound is reached, and returns the smallest previously valid exact score found. If no better construction is found, the supplied valid parent or a simple feasible fallback is returned.

1. Approach and rationale and core improvement idea

1.1 Central idea: binary-guided exact-relaxation discovery
The supplied parent has been obtained by a smooth-max/epigraph/active-set style local refinement process. Repeating similar continuous surrogate polishing from this parent tends to stay in the same local basin, especially around the same fractional intersection barriers. This plan attacks the discovery problem from a different side:

1. Search explicitly in a binary/integer structural space embedded in the same exactly-feasible mirror representation used for full h. Binary mirror vectors automatically satisfy the total-sum constraint. Integer score differences and simple flip/block perturbations explore nearby combinatorial basins that smooth gradient/L-BFGS/log-sum-exp trajectories rarely visit.
2. Take the best integer/semi-integer structural witnesses found and relax them coordinate-by-coordinate in fractional mirror q-space. Each coordinate relaxation uses the exact finite-grid overlap objective, and accepts a coordinate move only after the full np.correlate-based evaluator confirms a strict exact improvement. This is not a surrogate value relaxation in the usual smoothing sense: the direction values are only line-search candidates, and every accepting/progressive state is re-scored with the authoritative objective.
3. Periodically combine these two mechanisms with simple structural directions (global complements, top-reference interpolation, random valid block changes) and with multi-resolution transfer among several even grid sizes. Smaller valid exact scores are preferred only for ties; otherwise the smallest numerical bound wins.
4. Keep a valid fallback at all times: the parent or a parent-derived mirror vector if present, otherwise a simple all-0.5 feasible mirror vector.

This is materially different from prior strategies because the search engine is not primarily a smooth-max surrogate polished with gradients alone. It uses integer/binary exact feasible moves to escape the baseline local basin and then an exact-objective coordinate relaxation coupled to a structural pipeline. The strategy cannot claim optimality; only the final re-evaluation score is certified for the particular returned vector.

1.2 What works and what is not guaranteed
Certain facts:
- The objective is `score(h) = max(np.correlate(h, 1-h, mode="full")) * (2.0/n)`. It is evaluated on a finite length-n grid. Both zero and nonzero lags are included.
- The mirror construction for even n gives a feasible vector with `sum(h) = n/2` automatically, even when q entries are clipped to [0,1] and even when q is binary.
- Exact acceptance after recomputing the objective with the evaluation bundle avoids objective computation errors and surrogate acceptance errors.

Hypotheses/heuristics:
- The parent may already be near the best solution accessible with smooth descent alone, while binary or semi-binary structural moves may discover different correlation-active-lag structures.
- Exact coordinate relaxation after integer structures can recover fractional improvements by disarticulating different adjacent lags in a monotone way.
