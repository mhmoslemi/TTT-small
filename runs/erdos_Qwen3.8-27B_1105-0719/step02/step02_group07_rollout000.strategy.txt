1. Approach and rationale

1.1 Central idea

The supplied parent is a high-quality but locally optimized construction. Its previous search spends most of its time in one symmetric smooth/epigraph basin. The proposed program keeps that parent as a valid fallback, but materially changes the search in two ways.

First, it explores the exact discrete minimax objective in a richer set of feasible symmetric step functions using multiscale evolutionary search. The evolutionary variables are not penalized continuum variables. The proposed construction uses a symmetric parameterization of the returned array that automatically satisfies both box bounds and the integral constraint for every `q` value in `[0,1]`. Evolutionary search therefore samples many structurally different feasible basins, using the original objective for every acceptance decision.

Second, it exploits the difference among admissible resolutions. The evaluator defines the exact metric for whatever vector length is returned. A coarser or different number of samples can represent a valid piecewise constant function and can therefore give a tighter functional bound or a different shaping basin. The proposed schedule explicitly evaluates resolutions below, near, and above the parent resolution. It saves the entire candidate vector and length whenever the exact evaluator gives a smaller score.

The final local refinement combines exact value line searches, low-dimensional smoothed LSE stages, deterministic sheet sampling, and optional derivative-free scalar moves. These stages are secondary to the global evolutionary global basin search, but they allow high-quality coarse structures to be sharpened in the exact evaluator.

This is not a global proof and not a proof that the symmetric construction contains the global optimum. It is a heuristic upper-bound construction. The only claim implemented is that the returned array satisfies the required constraints and the returned number is the exact evaluator score of that returned array. The symmetric construction is chosen because the provided parent already uses that topology; keeping and symmetrizing the parent lets one inherit it safely when present, while still allowing broader global search relationships.

1.2 Why this may improve over the previous program

The previous code mainly minimizes a smoothed maximum with LSE, then attempts SLSQP epigraph in the same symmetric space from parentitar space. Such methods can sit at a local maximum of several correlations and cannot easily escape unless the smoothing schedule or the starting shape changes the active lag set. In this task, improving by about one part in `10^3` or `10^4` often requires changing quasi periodic structures; exact gradient descent in the same basin can plateau as nonlinear terms at original steps aligns gradients among constraints remain locally dispersed.

By contrast, the proposed multiscale control-DE search performs exact evaluations of the actual evaluator metric in a reduced but diverse generation archive. Each scored candidate already satisfies the linear constraint by construction without any surrogate.
