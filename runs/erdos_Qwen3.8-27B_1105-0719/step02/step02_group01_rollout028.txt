The functions a_k * x + b_k are lines. The maximum of lines is a convex piecewise linear function. We want to find the minimum of this convex function on [l, u].

The minimum occurs either at:

- Or at a boundary (l or u)

To find it: sort the lines by slope. The maximum is the upper envelope. The minimum of the upper envelope on [l, u] is at the point where the envelope is "flattest" - i.e., where two adjacent lines in the sorted-by-slope order have crossing point in [l, u].

def c5_of_h(h, dx):

def grad_smooth_max(h, dx, beta):
    n = len(h)
    corrs = np.correlate(h, 1.0 - h, mode='full')
    scaled = corrs * dx
    m = scaled.max()
    exps = np.exp(beta * (scaled - m))
    s = exps.sum()
    w = exps / s
    grad = np.zeros(n)
    for k in range(2 * n - 1):
        wk = w[k]
        if wk < 1e-13:
            continue
        d = k - (n - 1)
        # term1: (1-h[j-d]) for j where 0<=j-d<n
        js1 = max(0, d)
        je1 = min(n, n + d)
        if je1 > js1:
            grad[js1:je1] += wk * (1.0 - h[js1-d:je1-d])

        je2 = min(n, n - d)
        if je2 > js2:

    grad *= dx
    return grad

    scaled = corrs * dx
    m = scaled.max()
    return m + np.log(np.exp(beta * (scaled - m)).sum()) / beta
