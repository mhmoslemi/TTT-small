1. Approach and rationale

1.1 Central idea

The proposed method is a hybrid greedy-continuous search that combines two mechanisms that are not normally combined in this task:

- A feasibility-preserving discrete exploratory phase on moderate grids, where the step function is represented on a very small set of levels, e.g. values in {0, 0.25, 0.5, 0.75, 1}. This phase uses simulated annealing with joint feasibility-preserving moves: every proposal changes two entries by one level in opposite directions. Hence the discrete total mass is exactly unchanged, with no bisection or projection required. The discrete phase deliberately searches outside the basin of the parent array and gives purely constructive candidate seed vectors.

- A dedicated non-smooth minimax polish stage based on an active-set linear program plus exact objective line search. At the current h vector, the maximum of all overlap correlations is a nonsmooth maximum of many finite-support bilinear functions. The method linearizes only the currently largest correlations in a trust-region LP, solves the resulting LP for a descent direction, respects the equality mass constraint exactly inside the LP, and then performs a backtrack line search using the exact evaluator. This is fundamentally different from smoothing the max with a log-sum-exp proxy and asking an SLSQP stack to solve a smooth surrogate. The LP has direct information about the active upper-envelope constraints, and every candidate candidate is accepted only after the exact C5 evaluation.

The parent construction supplied through `initial_h_values`, if present, is always validated and kept as a fallback. It can be used as one starting point for the polish phase and as one source for discrete seeds. The method is not restricted to starting from it.

1.2 Why this could improve the supplied parent

The previous workflow mostly polished the parent by smooth-max maturing, which has two main failure modes:

- The analytic soft-max objective can be very ill-conditioned at the requested tiny improvement scale. The parent needs something on the order of a few 1e-4 or less relative to itself.
- The optimizer may make tiny, mostly inactive motion and stop due numerical tolerances, not because the original max is locally unavoidable in an exact sense.

The active-set LP polynomial instead:

- explicitly targets the largest correlations that define the current max;
- preserves the linear mass constraint inside the subproblem;
