def pair_delta(h, n, i, j):
    """Compute the change in all correlations when h[i] += 1, h[j] -= 1."""
    # For shift s, the change is:
    # delta_i(s) - delta_j(s) where delta_p(s) = (1-h[p+s])_valid - h[p-s]_valid
    result = np.zeros(2*n-1)

        dj = 0.0
        if 0 <= i + s < n:
            di += (1.0 - h[i + s])
        if 0 <= i - s < n:
            di -= h[i - s]
        if 0 <= j + s < n:
            dj += (1.0 - h[j + s])
        if 0 <= j - s < n:
            dj -= h[j - s]
        result[s + n - 1] = di - dj
    return result

Option 1: Vectorize the pair evaluation.
For a given source i and step d, the change in correlations for all possible sinks j is:
Δcorr_j = -D[i] + D[j] (for the move h[i]-=d, h[j]+=d... wait, let me be careful about signs)

If h[i] decreases by d and h[j] increases by d:
Δcorr = -d*D[i] + d*D[j] = d*(D[j] - D[i])

where D[p] is the column vector (over all shifts) giving the change in corr when h[p] increases by 1.

So for a fixed source i, the best sink j is the one that minimizes max(corr + d*(D[j] - D[i])).

This can potentially be vectorized: for all j simultaneously, compute the matrix of (corr + d*(D[j] - D[i])) and find which j gives the smallest max.

But the "max over shifts" for each j is a row-wise max of a matrix, which is straightforward in numpy.

Let me think about the memory: D is n × (2n-1) = 126 × 251 ≈ 31,600 elements. That's tiny.

For a fixed i:
- D[i] is a vector of length 2n-1
- For all j: D[j] - D[i] is a matrix of shape (n, 2n-1)
- new_corr = corr + d*(D[j] - D[i]) for each j, giving a matrix of shape (n, 2n-1)
- new_max_for_j = new_corr.max(axis=1) gives a vector of length n
- The best j is argmin(new_max_for_j) subject to validity (h[j] < M-1 for the move)

This is O(n^2) per source i, and O(n^3) total. With n=126, that's about 2 million operations, which numpy can do in a few milliseconds!
