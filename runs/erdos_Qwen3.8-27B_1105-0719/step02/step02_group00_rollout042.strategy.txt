1. APPROACH AND RATIONALE

1.1 Central idea
The previous program is dominated by local refinement of the supplied continuous parent vector: perturbations of the parent, epigraph SLSQP solves, dimension interpolation, and momentum-like descent. That is a legitimate local search, but the parent’s basin restricts candidate values to a nearest pattern of which samples are high, medium, and low. The current gap from 0.380917 down to the target region around 0.3808/0.38085 is small but likely requires a materially different representation of candidate step functions.

The planned approach is a pattern-first method:

- Convert continuous candidate profiles to binary threshold patterns that encode which samples belong to the mass-heavy branch `h≈1` and which belong to the mass-light branch `h≈0`.
- Explicitly search that combinatorial pattern space using balanced exchange moves and simulated annealing on an exact or near-exact energy derived from the actual linear-correlation overlap profile. This is structurally different from Gaussian perturbation of a continuous point; it discovers different high/low patterns, different run arrangements, and different boundary effects.
- For each promising binary pattern, run a constrained continuous optimization inside the combinatorial interval class defined by that pattern. In this class, samples marked 1 are allowed to occupy values `>= q`, samples marked 0 are allowed to occupy values `<= 1-q`, with `q` in a range such as `0.25...0.35`. The exact bilinear min-max overlap objective is minimized with an epigraph formulation and analytic constraint gradients.
- Finally, take every accepted candidate, interpolate it between relevant resolutions with mass-preserving edge/bin interpolation, and polish it with an exact active-set/steepest-descent line search.

The key hypothesis is not that the binary problem alone attains the target; in fact, for many feasible dimensions its objective will be a multiple of `2/n`, so it may be above or below the target only by discrete coarseness. The purpose is to use binary structure as a combinatorial guide and then relax each pattern into continuous values. This gives a representation in between fully binary step functions and dense local SLSQP starting from the continuous parent. It addresses the local-basin bottleneck by changing the search domain to threshold patterns and combinatorial intervals rather than only continuous local perturbations.

1.2 Why some claims are heuristic and not guaranteed
The objective
`max_m P_m(h)`
is nonconvex because of terms such as `h_i h_j`. Constraint repair and clipping are corrective, but they do not turn the problem into a convex optimization problem. No claimed universal optimum can be derived from the proposed local SLSQP or pattern relaxation. Improvement of the supplied parent is a numerical possibility, not a proof. Binary simulated annealing uses surrogate energies to escape plateaus and exact scalings to accept candidates; it has no global guarantee.

1.3 Role of different resolutions
The evaluator works for all sample sizes through `dx=2/n` and the same linear-correlation metric. A valid candidate at `n=48`, `n=70`, or `n=130` can be compared directly against the bound if it satisfies the same sample-average constraint. Mass-preserving resolution changes are therefore meaningful choices rather than nuisance changes when moving between coarse pattern spaces and finer continuous repetitions. When the current parent is invalid or unavailable, generate valid candidates algorithmically; never hard-code a numeric parent array.

1.4 Primary algorithmic pipeline
The operational core is:

1. Validate and store the parent as a fallback.
2. Generate continuous candidates by dimension interpolation and active descent; do light initial improvement to gather additional seeds.
3. Convert each seed to binary pattern candidates.
4. Explore pattern space with balanced pattern moves.
5. For pattern candidates, form interval-class relaxed vectors and run bounded epigraph minimization with smooth gradients.
6. Convert accepted relaxed vectors to free-box continuous points and run epigraph plus active-set descent.
7. Prefer best exact score; when scores tie within a small numerical tolerance, prefer smaller `n`.

The balance between pattern search and continuous refinement is a budget-time parameter rather than an essential mathematical difference.

2.1 Representation and exact objective
Let

- `n = len(h)`, integer sample count.
- `dx = 2/n`.
- `h_i = h[i]`, `i = 0,...,n-1`.
- `w_i = 1-h_i`.

`C(n,h) = max_{m=0,...,2n-2} P_eval_m(h)`,

`P_eval(h) = np.correlate(h, 1-h, mode='full') * dx`.
