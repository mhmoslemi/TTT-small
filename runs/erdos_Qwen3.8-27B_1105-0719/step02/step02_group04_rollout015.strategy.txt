1. Approach and rationale

1.1 Central idea

Construct a finite family of exact feasible step vectors and minimize the exact grader objective

  C5(h) = max_j np.correlate(h, 1 - h, mode="full")[j] * (2/n_points).

The search algorithm should be a sequential linear programing (SLP) method built on the active overlap constraints. At each iteration, it computes the exact overlap vector, linearizes the largest overlap constraints using correct gradients of the evaluator, solves one small linear program for a feasible descent direction, moves only along that direction, and accepts a step only after re-evaluating the original objective on the full, exactly feasible point.

This is materially different from smoothing the maximum (for example log-sum-exp), from a simple nonsmooth interior-point-like penalty, and from general unconstrained L-BFGS. The method uses:

- the exact active-set structure of the current maximum;
- a convex linearized epigraph subproblem;
- a trust-box/line-search filter that never accepts based on a model value;
- an exact-sum, exact-bound feasible representation for the main search;
- optional full-dimensional SLP to leave a symmetric subspace;
- multi-length interpolation to exploit the fact that smaller sample counts are cheaper but different discretizations can have different realized maxima.

The supplied parent is near the target by about 1.4e-4. Therefore the bottleneck is precision in the active “equalizer” of several nearly tied lags. A smoothing surrogate can lower its smooth objective while increasing the discrete maximum of a nonactive near-tie. An SLP subproblem directly asks the optimizer to lower a common linearized upper bound simultaneously over many active lags, then tests the exact maximum. This more faithfully addresses the nonsmooth max structure.

1.2 Feasible representation

The main iterative solver should use an anti-complementary builder. For n = 2m, a vector q ∈ [0,1]^m defines

  h[0:m]       = q,
  h[m:2*m]     = 1 - reverse(q).

For odd n = 2m+1, define

  h[0:m]       = q,
  h[m]         = 0.5,
  h[m+1:n]     = 1 - reverse(q).

Every returned q-builder vector satisfies 0 <= h_i <= 1 and sum(h) = n/2 by construction, up to only roundoff. This avoids clipping-then-rescaling infeasibility.

From a generic supplied full h, one may project into this subspace by

  q[i] = 0.5 * (h[i] + 1 - h[n-1-i])

for paired indices. However, this projection is not guaranteed to improve C5, so it is only a candidate generator and a starting point. The parent full vector itself should also be validated and retained as a fallback if it is feasible.

1.3 Limitations

This is a local/nonconvex method. It does not claim global optimality and does not rely on convexity of the exact problem. The linearized subproblem is only a local model, and nonlinear steps can violate the model. Therefore every accepted candidate must use the original evaluator. If all steps fail, the algorithm still returns a feasible fallback, preferably the best of:

- the supplied parent, after feasibility repair if necessary;
- the symmetric projection of the supplied parent, if feasible and scored;
- a deterministic fallback builder;
- any accepted SLP candidate.

1.4 Why it could improve the parent

The parent is likely a local point where several overlap constraints are almost tied. Correct gradients of the full bilinear objective are essential: the previous algorithm omitted the derivative of the shifted complement factor, which discards important balancing information. Adding that derivative lets the linearized subproblem move the two endpoint variables of each product in opposite directions, which is often needed to lower a max without raising neighboring constraints.

The SLP subproblem can also adjust several crashes simultaneously: minimize a new upper bound subject to linearized inequalities for all overlap values near the maximum, with trust-box constraints and the feasible representation.
