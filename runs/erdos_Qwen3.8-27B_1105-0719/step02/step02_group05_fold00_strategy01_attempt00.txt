1. Approach and rationale

The supplied evaluator uses the exact discrete overlap score

C5(h) = max_{k=0}^{2n-2} dx * corr_k,
corr_k = np.correlate(h, 1.0 - h, mode="full")[k],
dx = 2.0 / n,

with constraints h_i in [0,1] and sum_i h_i = n/2. This is a finite-support linear-lag correlation problem. It is not circular correlation, not a pure autocorrelation minus a boundary-free term, and it is not convex in h because each lag term contains products h_i * h_j. Therefore all candidate acceptance must be based on the exact evaluator value, not on a smooth surrogate or relaxation.

The previous kind of algorithm typically stayed near one parent basin because it repeatedly minimized smooth surrogate objectives or solved active epigraphs from the same local model. The central new idea here is to build the search around a mirror-feasible parametrization of h and to use a trust-region nonsmooth minimax method whose subproblem is an exact linear approximation of the active lag constraints, followed by exact line-search validation in the original objective. This removes the most important limitation of pure smoothing: smoothing can distort the location of the true maximum. The surrogate is only a local vertex-searching device; every accepted step must improve the exact C5.

To avoid just polishing one basin, the exact local minimax method is embedded in a population/mutational search on a smaller feasible manifold. The population contains full feasible vectors and their mirror q-snapshots. Mutations are cheap because the mirror representation conserves the integral constraint by construction, then a full projection repair is used whenever needed. Small, exact subproblems are solved sequentially, while exact scoring is used for selection. A separate resolution-transfer stage tries smaller and slightly larger grids because smaller n is preferred when the exact score is equal or better. Optional truncated binary MILP/repaired-integer excursions are specified only as time-available surrogates, not as a proof of feasibility.

Why this can improve the parent: it is almost certainly very close to a local optimum. The trust-region linear model is specialized to reduce the maximum of the current active lags directly, and the population/simulated annealing/differential-evolution-like mutation system explores nearby and recombining basins. The exact line search catches overlap-generating errors from linearization. This combination is materially different from only descended through log-sum-exp barriers or global epigraphs.

Notability: the method does not prove a global minimum at any resolution. Results are feasible upper bounds only.

2. Mathematical specification

Let n be the chosen number of samples, dx = 2.0 / n, and Ntarget = n / 2. For any vector h in R^n:

feasible iff all 0 <= h_i <= 1 and sum_i h_i = Ntarget.

Define exact correlation vector and score:

coeff = dx * np.correlate(h, 1.0 - h, mode="full")
C5(h) = max(coeff)

The lag index k maps to an integer shift d = k - (n - 1). For d >= 0 the unscaled value is

r_d = sum_{i=0}^{n-d-1} h[i+d] * (1 - h[i])

and for d < 0, a = -d:

r_{-a} = sum_{i=0}^{n-a-1} h[i] * (1 - h[i+a])

Each correlation object returned by the evaluator is dx*r_d.

Mirror parametrization. For any n, let m = n // 2. Let q in [0,1]^m. For even n:

h(q) = concatenate( q[0:m], 1 - q[m-1:0:-1] )

For odd n:

h(q) = concatenate( q[0:m], [0.5], 1 - q[m-1:0:-1] )

For any q bounds, h(q) is bounded and has exact sum dx * sum h = 1 because the first half contributes S and the complementary tail contributes m - S plus center .5 if odd. This is used as the main local variable.

Symmetrization of any feasible h. If a supplied parent is not already of mirror form, define

p = 1 - h
r = p[::-1]
h_sym = 0.5 * (h + r)

Then h_sym is in [0,1], and sum h_sym = 0.5 * (sum h + sum p) = n/2, so h_sym is feasible. It is processed under exact score and kept if useful.

Feasibility-repair projection: q-based candidates remain feasible up to floating error. Candidate full vectors obtained from interpolation or mutation may need joint feasibility repair. Use a water-filling repair:
