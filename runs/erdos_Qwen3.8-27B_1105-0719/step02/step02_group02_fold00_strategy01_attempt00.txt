1. Approach and rationale

1.1 Central idea

The supplied parent construction and the prior program rely mainly on smooth surrogate objectives such as a softmax over the correlation constraints, plus projection and subgradient momentum. This is stable but weak for squeezing the last few ten-thousandths of the bound because the true objective is the nonsmooth maximum of many whole-lag correlations. A smoothing parameter gives a gradient field, not necessarily the true local model of the active maximum. Conversely, replacing the whole problem by one sequential optimizer can stall when only a few near-active lag constraints are insufficiently weighted.

The proposed algorithm introduces a materially different local-search skeleton:

- Work directly on the original finite-lag objective
  `C5(h)=max_s corr_s(h)*dx`, without converting the max into a permanent smooth objective.
- Maintain `h` exactly feasible for `0<=h_i<=1` and `sum(h)=n/2`.
- Use an exchange-form active-set nonlinear program: periodically solve the smooth transformed problem
  `minimize raw_t subject to corr_active(h) <= raw_t`, `sum(h)=n/2`, bounds, and then rebuild the active set from the exact full evaluator. The inequality constraints are truly `t - corr_s(h) >= 0` for the selected constraints; inactive constraints are ignored during a local solve, but every candidate is re-scored using the complete exact objective before acceptance.
- Add, as a separate descent mechanism, exact global one-dimensional minimization along specially computed feasible directions:
  * active-constraint mutual least-norm descent directions obtained from the true gradient of the correlation constraints,
  * coordinate-pair directions,
  * low-frequency structure directions, and
  * randomized feedforward steps.
- Evaluate every step with the original evaluator. Never report a surrogate value, a relaxed value, or an intermediate solver value unless it is rechecked by the exact `np.correlate(..., mode="full")` formula.

1.2 Why this could improve the supplied parent

The parent near `0.380934` needs a decrease of approximately `0.00013` (dimensionless) to reach the target `0.3808`. At `n=126`, the required raw-correlation decrease is roughly
`delta_raw ~= 0.000134 * (n/2) ~= 0.0084`
raw overlap units. This is a very small, highly active-set-constrained movement. A smoothed maximum-descent method may not point in the exact direction needed because its weights can blunt equal regions of the active set. The active-set direct nonlinear program and exact line minimizers use the exact raw correlation and exact gradients to reduce all currently limiting lags, which is more favorable to small, tightly constrained improvements. Extra direct and line directions help avoid being stuck in a stationary point of a single smooth surrogate.

1.3 Limitations and assumptions

- The original optimization is nonconvex because the constraints `corr_s(h)` contain bilinear terms. The SLSQP/trust-region executable as a direct nonlinear program is not guaranteed to find a global optimum. It is a local solver.
- Exact line minimization along chosen directions is a strong local neighborhood search but also not a global proof. It merely uses the true one-dimensional restriction of the exact objective; if the Voronoi-like valley of the min-max problem is very narrow compared to the sampled direction field, it can miss it. The randomized directions and restarts are hypothesized heuristics intended to reduce this risk, not proven guarantees.
- Every final reported value is computed by the specified exact evaluator or an equivalent one. Thus, if it survives verification, the resulting upper bound is mathematically valid for the discrete evaluation model even though the search is local/heuristic.
- The algorithm can return the parent fallback or a guaranteed constructed fallback. Hence it will not increase the verifier’s result merely because it seeks a better dimension, but it does not guarantee that the `.3808` target will be reached.

2. Mathematical specification

2.1 Discrete representation and exact objective

For a vector length `n`:

- `dx = 2.0 / n`.
- Feasibility is `0 <= h_i <= 1` and `sum_{i=0}^{n-1} h_i = n/2`, which is exact translation of `dx*sum(h_i)=1`.
- Define `1h_vector = 1.0 - h`.
- The evaluator value is:
  `raw(h) = max(np.correlate(h, 1h_vector, mode="full"))`
  with output length `2*n - 1`.
  The dimensionless scored value is:
  `C5(h) = raw(h) * dx`.

This is linear finite-support correlation, not circular. Both positive and negative lag directions are included by the `mode="full"` evaluator.

2.2 Correlation indexing and gradients

Let `offset = k - (n - 1)` for an evaluator output index `k = 0,...,2n-2`. The lag `offset` corresponds to indexed pairs `(i, i+offset)`. A coordinate `i` is included exactly when `0 <= i <= n-1` and `0 <= i+offset <= n-1`.

The raw objective for a given output index `k` is:
`c_offset(h) = sum_i h_i * (1 - h_{i+offset})`.

For `offset == 0`: derivative `grad_i = 1 - 2*h_i` for every `i`.

For `offset > 0` (`m=offset`): valid indices `i = 0,..., n-m-1`. For every such index:
- derivative wrt `h_i` is `1 - h_{i+m}`;
- derivative wrt `h_{i+m}` is `-h_i`.

For `offset < 0` (`m=-offset`): valid indices `i = m,...,n-1`. For every such index:
- derivative wrt `h_i` is `1 - h_{i-m}`;
- derivative wrt `h_{i-m}` is `-h_i`.

An implementation should implement a helper
`raw_grad_offset(h, offset, n)`
that builds a length `n` vector from those exact formulas. The formulas include all boundary truncations and handle `offset=0` by combining both derivative contributions into the single term `1 - 2*h_i`.

A robust development check is to compare the gradient with finite differences on several vectors using the exact overlap sum, not a circular formula.

2.3 Active-set epigraph nonlinear program

Let `raw_t(h)` be the raw correlation array from the evaluator. Introduce one scalar raw-t variable `T`. The continuous epigraph transform of the minimization of the discrete max is locally:

`minimize T`
subject to
`c_s(h) <= T` for selected active constraints `s`,
`sum_i h_i = n/2`,
`0 <= h_i <= 1`.

For scipy nonlinear solvers that use inequalities `g(x)>=0`, store the inequality in the flipped form:
`T - c_s(h) >= 0`.

The decision vector used by the solver can be:
`x = [T, h_0, h_1, ..., h_{n-1}]`.

Solver constraints:

- Equality: `sum(h)-n/2=0`.
- Inequality for each active index `s`: `T-c_s(h)>=0`.
- Bounds: `T` between a nonnegative lower bound (for example `0`) and a generous upper raw value such as `n+1`; `h_i` between `0` and `1`.

Objective gradient for `minimize T`: derivative is 1 in the first variable and 0 for all `h_i`.

Inequality gradient row for `T - c_s(h)`: plus 1 for `T`, and `-grad_s(h)` for the h coordinates. Use the exact `raw_grad_offset` formula for `grad_s`.

The chosen active set can be a subset of correlations, reunited outward with the full synchronous verification/repair procedure in order to remain scalable. If the active set consists of a few approximately equal indices, each appears as a row in the gradient matrix. Inactive constraints are still fully evaluated after every solve. To avoid only allowing all correlations of a dimension or many constraints, cap the active matrices for the solver at e.g. 64–96 rows and choose the most limiting constraints first.

3. The clipped sum approaches continuously. Find `delta` by binary search in the interval `[-1, 1]`; the value is valid if the sum can be equalized within bounds.
4. This preserves `0 <= h_i <= 1`.
5. The current parent needs roughly a `1.3e-4` normalized reduction. At `n=126`, that is a raw correlation reduction of only about `0.008`.
