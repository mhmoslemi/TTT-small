Actually, one more thought: I should also try a **proximal minimax** approach. The idea:

```python
def proximal_minimax(h, max_iters=500, time_limit=30):
    n = len(h)
    M = 2 * n - 1
    w = np.ones(M) / M  # Uniform initial weights
    t = 1.0  # Learning rate
    best_c = score_exact(h)
    
    for it in range(max_iters):
        P = profile(h)
        G = grad_profile(h)
        
        # Update weights (exponentiated gradient)
        w = np.exp(P / t)
        w /= w.sum()
        
        # Weighted gradient
        g = w @ G  # Shape (n,)
        g -= g.mean()  # Preserve sum constraint
        
        # Step
        h_new = h - t * g
        h_new = repair(h_new)
        
        c_new = score_exact(h_new)
        if c_new < best_c - 1e-13:
            h = h_new
            best_c = c_new
        
        # Reduce learning rate
        t *= 0.99
    
    return h, best_c
```

This is a simple but effective approach. The exponentiated gradient on the weights automatically focuses on the active constraints.
