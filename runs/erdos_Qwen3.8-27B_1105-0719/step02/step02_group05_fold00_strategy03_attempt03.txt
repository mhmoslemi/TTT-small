1. Approach and rationale

1.1 Central idea

The supplied construction is already a fairly good local solution on the given 126-point grid, but it was produced without any global, low-dimensional reparameterization of the principal function shape. The proposed method changes the search geometry first: all main trial solutions are generated from smooth, fixed-magnitude coefficient vectors over a half-interval. The full solution is then obtained by

    h(i) = q(i),   for the first half,
    h(i) = 1 - q(m-1-i), for the reversed second half,

for even n=2m. This representation is feasible automatically for every coefficient vector: every value remains in [0,1], and the discrete integral is exactly n/2 because the coordinate changes cancel in mirror pairs. There is no needing to project after an update.

The core novelty is to optimize a very small number of continuous coefficients in a constraint-free, positivity-preserving representation. The coefficients define q(i), a mirrored step function is constructed at full resolution, and every candidate is judged by the original exact evaluator, not by the surrogate. This is different from starting at the parent and performing only high-dimensional smoothing/epigraph descents. It gives global structure movement over diverse basins, including variations in phase, scale, symmetry, and peak placement that are very expensive to find by local high-dimensional perturbation alone.

The search is then refined:

1. Low-dimensional global coefficient search using an L-infinity-like surrogate.
2. Exact acceptance and lifting of promising coefficient vectors to the grid.
3. Exact one-dimensional coordinate polishing in q-space, preserving the same automatic feasible representation.
4. Optional random tangent-line or block moves in q-space to escape coordinate-daent九天不能了了
5. Multi-resolution transfer and polishes of the global best functions to other grid sizes.
6. Exact re-evaluation and return of the strictly best candidate.

The return is always exactly judged using np.correlate(h,1-h,mode="full") * dx and all coordinate constraints.

1.2 Why it can improve the supplied parent

The previous parent is a discrete function, but the continuous solution of the Erdős-type minimum overlap problem is determined by macroscopic overlap and support-plane behaviour of a low-frequency curve, as well as boundary discontinuities. The low-dimensional trial representation can change the entire frequency content, support distribution, and mirror half-structure of the parent at once. This tends to generate candidates whose high-dimensional smoothing and epigraph refinements are often blocked by their multiple mostly inactive correlations. Coordinate polishing then adjusts the further high-frequency patterns necessary to reduce max lags without breaking the exact mean constraint.

The main bottleneck addressed is not numerical precision but local basin dependency. The final algorithm still does not become a global proof, and it should not be described as optimizing the original nonsmooth objective globally. It is a global/multistart surrogate exploration procedure with exact acceptance; every claimed improvement is explicitly exact independently.

2. Mathematical specification

2.1 Exact discrete objective

For a vector h of length n and dx = 2.0 / n,

    c(k) = np.correlate(h, 1.0-h, mode="full")[k],

has length 2n-1 and indexed

    d = k - (n-1), d=-(n-1),...,(n-1).

The exact score used for acceptance is

    C(h) = max_k c(k) * dx.

All accepted candidates and the final reported bound use this exact operation. For clarity, raw correlations as returned by np.correlate have no dx factor. A smooth surrogate is built on the raw correlations and optimizes the same maximization direction in the scaled model; the final evaluator uses scaling manually.

2.2 Constraint-free mirrored representation

For output length n choose the search coordinate length

    m = n // 2

for even n; if the parent value is an odd length and an output vector is needed, replace the odd reference with the next even length using the transfer procedure below. Only even n is used as a low-dimensional candidate output length.

Given q in [0,1]^m, construct h of length 2m:

    h[:m] = q
    h[m:] = 1 - q[::-1]

For even n this gives:

    sum(h) = sum_j q_j + sum_j (1-q_j) = m = n/2.

Thus exact elementary average and box constraints hold. It is feasible before and after any coefficient changes. For a final expected odd vector, use

    h = q + [0.5] + (1-q)[::-1]

when appropriate, but final searched candidate lengths are kept even for simplicity.

2.3 Logisticriered smooth coefficients q

For each asymptotic dimension K, let x_i = i / (m-1), after ensuring m>1 (m>=2). Build basis matrix B ∈ R^{m × K}. The first column illustrates the checker columns according to r and a number of dimensions, chosen by formulas requested below. The coefficient vector θ ∈ R^K is unconstrained and unbounded; a normalization theorem makes it suitable for L-BFGS–B-like numeric solvers.

Define

    z(θ)_i = scale * (B @ θ)_i
    z_safe(i) = clip(z_i, -35, 35)
    q(θ)_i = σ(z_safe(i)) = 1 / (1 + exp(-z_safe(i)))

Every q is strictly between 0 and 1; it cannot leave the feasible container, no clipping is required after evaluation. When θ causes saturation, evaluation remains stable due to ±35 clamp, though tiny derivative points; exact candidates and later q-based polishing can reach jumps and near binary local adjustments.
