The main remaining obstacle is not programming speed or feasibility enforcement, but the very flat nonconvex minimax landscape: small changes in a few sample points can degrade one lag constraint while helping another, so exact active-set descent can stall. I propose a different robust local-to-global polishing pipeline based on three coupled mechanisms:

- feasible random/symmetric arrivals: every proposed vector is passed through a strict feasibility map that enforces both `0 <= h_i <= 1` and `sum(h_i) = n/2` simultaneously, so every intermediate iterate is an exact valid candidate.
- feasible-line directional descent: instead of solving SLSQP epigraph problems that may stall on local nondifferentiability, generate descent directions from smoothed active-constraint gradients and active-constraint linearized LP trust-region directions, then test all proposals against the exact evaluator and only store statistically/theoretically valid improvements.
- multi-resolution transfer: repeatedly interpolate valid candidates into several smaller and larger resolutions, locally polish them at that resolution, and return only the dimension where the exact recorded objective is best. Because smaller dimensions are faster and can reveal different step structures, this broadens the valley in a way that single-dimension SLSQP does not.

This approach addresses the bottleneck directly: it allows repeated nonmonotone feasible jumps and stochastic perturbations while never allowing an infeasible candidate to contaminate the run and never improving on a smoothed surrogate without exact validation. It does not claim global optimality; every claimed objective value is quantified by the official evaluator. If the parent itself is `<= 0.38080`, keep parent as returned.
