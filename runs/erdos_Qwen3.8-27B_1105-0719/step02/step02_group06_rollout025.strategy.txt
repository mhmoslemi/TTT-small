<strategy>
1. Approach and rationale

1.1 Core idea

Commercial previous constructions primarily optimize an antiparallel/symmetric half vector and use either a smoothed maximum objective or a nonlinear epigraph program. Those methods are effective but can stall in a local basin and do not exploit the full non-antiparallel feasible set. The proposed strategy is different on three axes:

1. Direct full-vector minimax tangent program.
   At a feasible full vector h, build a first-order linearized model of every correlation lag r_lag(h) = sum_i h[i] * (1 - h[i+shift]). Solve a linear program that minimizes a scalar epigraph variable t subject to all (or a safely large active/all set) linearized lag constraints, box constraints, trust-region bounds, and the exact mass equation sum h = n/2. Step lengths and acceptance are always performed by the original exact evaluator.

2. Exact one-dimensional mass-preserving transfer line searches.
   Preserve sum exactly by selecting two indices a,b and transferring mass: h[a] += delta, h[b] -= delta. This keeps sum(h) unchanged exactly without any projection artifact. Since the exact objective along such a nonconvex one-dimensional slice can improve through curvature even when the first-order tangent model has a zero or poor direction, repeatedly search over delta using robust grid + local refinement evaluations. These moves find kink crossings and second-order improvements that a gradient/LP direction may miss.

3. Full-vector global diversification followed by polishing at multiple resolutions.
   Instead of restricting every new seed to antiparallel structure, start from diverse feasible full vectors: balanced binary patterns, smoothed binary/numerical patterns, Fourier/piecewise constructions, and transferred solutions from other resolutions. Binary patterns are first refined by discrete swap hill-climbing, then converted to continuous and refined by the tangent-LP and line-search routine. The best exact C5 value is always recomputed from the returned vector. Lower C5 wins; if scores are essentially tied, the smaller n is preferred.

1.2 Why this may improve the parent

The objective is nonconvex and nonsmooth due to max over bilinear lag correlations. A smoothed scalar optimization averages many constraints and can fail to identify a simultaneous feasible perturbation that lowers several near-max lags. A tangent epigraph LP explicitly models the simultaneous constraints with sharp inequality constraints and gives a coordinated direction. At the same time, linearization is not exact because the lag functions are bilinear; exact transfers, exact line searches, and exact recomputation compensate. Enabling jumping out of the antiparallel half-vector manifold may find a different local basin absent from the parent.

1.3 Limitations and proof status

The tangent LP is a local trust-region subproblem. It is not a convex relaxation of the original problem because lag terms h[i](1-h[j]) are bilinear. The strategy does not claim global optimality. The only claims are:
- For fixed resolution, minimizing raw correlate max is exactly equivalent to minimizing C5 because C5 = (2/n) * raw max.
- Every returned vector is validated by the authoritative evaluator.
- Mass-preserving steps have an exact sum guarantee as long as endpoints sum exactly, but the subproblem is locally heuristic due to nonconvexity.
- All candidate selection is by exact recomputation.

2. Mathematical specification

2.1 Exact objective and indexing

Let n = len(h), dx = 2.0 / n. Let raw_corr = np.correlate(h, 1.0 - h, mode="full"), length L = 2n - 1. The authoritative scaled objective is

    C5(h) = dx * max(raw_corr).

A correlation lag output is indexed ell in {0, ..., 2n - 2}. Let shift d = ell - (n - 1). For every valid first-array index i satisfying

    0 <= i < n,
    0 <= i + d < n,

the contribution to raw_corr[ell] is

    h[i] * (1 - h[i + d]).

Equivalently, if i_lo = max(0, -d) and i_hi = min(n - 1, n - 1 - d), and i_lo <= i_hi,

    raw_corr[ell] = sum_{i=i_lo}^{i_hi} h[i] * (1 - h[i + d]).

This formula follows from np.correlate(h, second, mode="full") output orientation: term h[i] * v[j] appears at output ell = (j - i) + (n - 1). The exact helper in the implementation may simply use np.correlate for final scoring to avoid mismatch; the derivative routine must match this definition.

For fixed n, minimizing

    R(h) = max_ell raw_corr[ell]

is equivalent to minimizing C5(h). Across resolutions, compare C5(h) owing to differing dx.

2.2 Feasible set constraints

Return h_values as a 1D float64 vector of length n satisfying:

    0 <= h[i] <= 1  for all i,
    sum(h) == n * 0.5  within a tolerance like 1e-10.

For odd n, the target sum is non-integer n/2; continuous values make it feasible. Binary samples may require a small continuous correction. Do not enforce an integer target count independently; always project to the real target n/2.

2.3 Tangent LP formulation

At a current feasible point x (this can be a full h vector length n or a symmetric half vector q length m), let V be the variable vector whose length is dim(x). For full vector optimization, V=x=h. For symmetric antiparallel optimization, V=q and h is constructed from q. Let the raw correlation at lag ell be R_ell(x). The first-order model is

    m_ell(z) = R_ell(x0) + grad_ell(x0)^T (z - x0).

Decision vector is [z, t], where z has length dim(x0) and t is a scalar for maximum raw correlation. For each selected lag ell:

    grad_ell^T z - t <= grad_ell^T x0 - R_ell(x0).

Check test at z=x0: becomes x? x term -t <= x_term - R => -t <= -R => t >= R, feasible for current maximum under equality. This sign is essential. Do not flip constants.

The LP is:

    minimize t
    subject to:
       for each selected ell: grad_ell^T z - t <= grad_ell^T x0 - R_ell(x0)
       for symmetric q branch: 0 <= z_i <= 1, no equality needed because anti-complement ensures sum(h)=m
       for full h branch: 0 <= z_i <= 1, and a scalar equality sum(z_i)=sum(x0_i)=n/2
       0 <= t <= upper_raw_max
       z_i within x0_i +/- rho and within [0,1].

The scalar mass equality in full branch ensures any direction d=z-x0 has sum exactly zero (up to LP numerical tolerance), and a convex so x0 + alpha*(z-x0) preserves sum algebraically. The objective uses raw scale, not scaled C5; dx is constant per resolution.

The subproblem uses scipy.optimize.linprog, supported for linear inequalities, equality constraints, objective vector, variable bounds, and method HIGHS if available with default as fallback. It is a legitimate subproblem formulation. It is only a local surrogate, not a global convex relaxation.

2.4 Gradients of correlation lags

For the exact raw corr function, gradient against full entries, at lag ell shift d:

For i in [i_lo, i_hi], let j = i+d. The term is h[i]*(1-h[j]). Its partial derivatives with respect to full h are:

    gradient[i] += 1 - h[j]
    gradient[j] -= h[i]

Use a scatter-add method because i and j may be identical at d=0. For d=0, resulting derivative is 1 - 2h[i], which is correctly obtained by adding both contributions to the same index.

For the half vector transformation, construct h from q:

    n = 2m.
    h[0:m] = q.
    h[m:n] = 1 - q[::-1].

Every q_r influences h_r and h_{n-1-r}:

    gain(h_r) =  q_r
    gain(h_{n-1-r}) = 1 - q_r

Derivative through the chain rule:

    grad_q[r] = grad_h[r] - grad_h[n - 1 - r].

This is the only transformation required for the half-vector tangent matrix. Since the construction enforces sum by anti-complement action applied, no separate sum equality is needed.

2.5 Exact one-dimensional transfer line

For any pair of full-vector indices a != b, define a direction transfer_delta:

    h_a(delta) = x0[a] + delta
    h_b(delta) = x0[b] - delta
    h_i(delta)=x0[i] otherwise.

This preserves sum exactly for all delta. Bounds:

    lower = max(-x0[a], x0[b] - 1)
    upper = min(1 - x0[a], -x0[b])

If upper < lower do nothing. Search delta in [lower, upper]. The one-dimensional objective delta -> max_lag R_lag(h(delta)) may be nonconvex; exact global minimization along it is not claimed. Use a robust sufficient local/global line search: evaluate a dense grid of candidate deltas; sample near the best grid point; refine a neighboring level using bounded golden-section or trisection. Always refine the initial candidate near feasible end. Exact global arising one evaluation; a predictor with local search cannot assume convex.

2.6 Symmetric direct coordinate transfer (symmetric branch)

A coordinate r in q changes h around both index r and mirror. The feasible q_r interval:

    delta_min = max(-q[r], -1? no q lower is 0 and upper 1) -> lower = -q[r], upper = 1 - q[r].

For full vector we use pair-transfer to h_a + delta, h_b - delta. The symmetric conversion maps this pair transfer in q_r to mass swap ignoring nonconvexity. No boundary projection.

2.7 Joint box-and-sum feasible projection

All general constructions must pass through a single joint projection project_to_box_sum(x, target=n/2), which guarantees [0,1] and sum.

Algorithm:

1. Convert x to float. Replace nonfinite values by 0.5.
2. Clip to [0,1]. If abs(sum(x)-target) <= 1e-12 return clipped copy.
3. Find uniform shift c using monotone function f(c)=sum(clip(x+c,0,1)). Set low = -n - 1 and high = n + 1. Do 90 bisection evaluations on value mid = (low+high)/2. If f(mid) > target, set high=mid, else low=mid. Let c=(low+high)/2. Let v=clip(x+c,0,1).
4. Let residual r = target - sum(v). If abs(r)<=1e-13 return v.
5. If r>0, raise values toward 1 in ascending current-value order, adding min(r,1-v[i]) until residual or capacity exhausted.
6. If r<0, lower values toward 0 in descending current-value order, subtracting min(-r,v[i]) until residual or capacity exhausted.
7. If |r|>1e-11 after receipt (rare), repeat projection from the current v a small constant number, min 3 outer times. If still not exact due pathological constraints need fallback symmetric construction; but for target in [0,n] and not pathological this succeeds.

This mechanism accepts any vector, partial clip order, smooth? for reconstruction. Do not simply normalize after clipping, because that can break bounds; do this exact joint process.
