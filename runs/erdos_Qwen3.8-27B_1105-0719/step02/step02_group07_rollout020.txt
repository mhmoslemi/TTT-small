def golden_section_1d(f, a, b, n_iter=50):
    """Minimize unimodal f on [a, b] using golden section."""
    gr = (np.sqrt(5.0) - 1.0) / 2.0
    x1 = b - gr * (b - a)
    x2 = a + gr * (b - a)
    c1 = f(x1)
    c2 = f(x2)
    for _ in range(n_iter):
        if c1 < c2:
            b = x2
            x2 = x1
            c2 = c1
            x1 = b - gr * (b - a)
            c1 = f(x1)
        else:
            a = x1
            x1 = x2
            c1 = c2
            x2 = a + gr * (b - a)
            c2 = f(x2)

```python
def subgradient_step(h, n, top_k=5, alpha=None):
    """One subgradient step: compute subgradient, take step, project."""
    corrs = corr_values(h)
    # Get top-k active lags
    idx = np.argsort(corrs)[::-1][:top_k]
    # Weights proportional to how "active" each is
    weights = corrs[idx] - corrs.min()
    weights = np.maximum(weights, 1e-10)
    weights /= weights.sum()
    
    # Compute subgradient (weighted average of gradients of active corrs)
    dx = 2.0 / n
    G = np.zeros(n)
    for w, idx_val in zip(weights, idx):
        d = idx_val - (n - 1)
        if d >= 0:
            # j appears as h[i+d] (first factor) when i = j-d >= 0, i.e., j >= d
            # Contributes (1-h[j-d])
            G[d:] += w * (1.0 - h[:n-d])
            # j appears as h[i] (second factor, with -sign) when i = j, and j+d < n
            # Contributes -h[j+d]
            G[:n-d] += w * (-h[d:])
        else:
            ad = abs(d)
            # j appears as h[i+d] when i = j-d = j+ad >= 0 (always) and j+ad < n
            # Contributes (1-h[j+ad])
            G[:n-ad] += w * (1.0 - h[ad:])
            # j appears as h[i] when i = j, and j+d = j-ad >= 0, i.e., j >= ad
            # Contributes -h[j-ad]
            G[ad:] += w * (-h[:n-ad])
    
    G *= dx
    
    if alpha is None:
        # Adaptive step size
        c_cur = exact_score(h)
        alpha = 1.0 / (np.linalg.norm(G) + 1e-10)
    
    h_new = h - alpha * G
    h_new = project_feasible(h_new, n / 2.0)
    return h_new, exact_score(h_new)
```

np.correlate(a, v, mode='full') at index k (0-indexed in output):
The "lag" is d = k - (n-1).
result[k] = sum over i of a[i+d] * v[i] where 0 ≤ i < n and 0 ≤ i+d < n.

With a = h, v = 1-h:
result[k] = sum_{i: 0≤i<n, 0≤i+d<n} h[i+d] * (1-h[i])

Partial derivative with respect to h[j]:
- h[j] appears as h[i+d] when i+d = j, i.e., i = j-d. Valid when 0 ≤ j-d < n.
  Contribution: (1-h[j-d]) * 1 = (1-h[j-d])
- h[j] appears in (1-h[i]) when i = j. Valid when 0 ≤ j < n (always) and 0 ≤ j+d < n.
  Contribution: h[j+d] * (-1) = -h[j+d]

So: ∂result[k]/∂h[j] = (1-h[j-d])*[0≤j-d<n] - h[j+d]*[0≤j+d<n]

For d ≥ 0:
- (1-h[j-d]): valid when j ≥ d. So for j = d, d+1, ..., n-1: G[j] += (1-h[j-d])
- -h[j+d]: valid when j+d < n, i.e., j < n-d. So for j = 0, 1, ..., n-d-1: G[j] += -h[j+d]

For d < 0 (let ad = |d|):
- (1-h[j-d]) = (1-h[j+ad]): valid when j+ad < n, i.e., j < n-ad. For j = 0, ..., n-ad-1: G[j] += (1-h[j+ad])
- -h[j+d] = -h[j-ad]: valid when j-ad ≥ 0, i.e., j ≥ ad. For j = ad, ad+1, ..., n-1: G[j] += -h[j-ad]
