1. Approach and rationale

1.1 Central idea

The primary proposed approach is a genuinely different local/global search architecture from the supplied parent program. Instead of reducing the search to the antiparallel half-vector construction and relying chiefly on exponential smoothing, a nonlinear epigraph solve over the maximum constraints, or fixed smooth L-BFGS passes, this plan uses three complementary exact-feature mechanisms:

1. Sequential linearized trust-region LP descent on the exact full-length vector. At any feasible point, build a local first-order model of every correlation constraint. Solve a small linear program that minimizes a scalar maximization surrogate over a trust-region box. Candidate acceptance is always performed using the exact `np.correlate` objective. This produces coordinated full-dimension moves that are sharper than one shared smoothed objective and cheaper than repeatedly solving nonlinear epigraph programs.

2. Exact sum-preserving pairwise minimization себя on the true objective. Choose two samples `(i,j)` and transfer mass as `h[i] -> h[i]+δ`, `h[j] -> h[j]-δ`. This preserves the sum constraint exactly. Along that line, every correlation term is either affine or a convex quadratic in `δ`, and the maximum of the resulting functions is convex. This 1D minimization directly improves a non-convex multilinear objective without changing the mass constraint and without projection artifacts.

3. Global basin exploration at low to medium effective resolutions through projected differential evolution. DE does not claim global optimality for the continuous high-resolution problem. It is used as a generator for different basins. Its raw vectors are projected to the feasible box and sum exactly. Low-resolution feasible improvements are valid returned constructions because the given task explicitly permits sample count choice and prefers smaller sequences. Moderate-resolution DE results are also interpolated back up to the parent-scale range and accepted as seeds.

This plan attacks the observed bottleneck more directly than the parent program:
- The supplied parent program is near a local optimum of its chosen symmetric subproblem. A materially different basin/representation search is needed.
- Pairwise 1D convex descent gives very accurate movement along the constrained polytope edges that preserve sum exactly, not by post-projecting.
- The trust-region linear program gives simultaneous descent over many adjacent lags at once.
- Inexact smoothing can settle too early; every accepted solution here is verified by the exact evaluator.

This is only a local/global heuristic search. It must never claim a global optimum. All claims below are either mathematically justified identities or explicitly stated heuristics.

1.2 Mathematical and algorithmic justification

Let `N` be the number of samples. Let `dx = 2/N`. Let the feasible vector be `h ∈ [0,1]^N` with `Σ_i h_i = N/2`. The evaluator objective is

`C5(h) = dx * max_{ell} corr_ell(h)`,

where

`corr = np.correlate(h, 1-h, mode="full")`

is length `2N-1` and `ell` is the output index. Define raw correlation

`r_ell(h) = corr_ell(h)`.

Then `C5 = dx * max_ell r_ell`, and `dx` is constant for fixed `N`. Therefore, within one fixed resolution, minimizing raw maximum is mathematically equivalent to minimizing the displayed objective. Resolutions must still be compared by the final raw times `dx` objective, not by raw alone.

For an output index `ell`, let the discrete shift be

`d = ell - (N - 1)`.

The valid indices of the first array are

`i_lo = max(0, -d)` and `i_hi = min(N-1, N-1-d)`,

provided `i_lo <= i_hi`. For every valid index `i`, the corresponding overlapping pair is `(i, i+d)`. The raw correlation at `ell` is

`r_ell(h) = Σ_{i=i_lo}^{i_hi} h[i] * (1 - h[i+d])`.

This formula includes both positive and negative shifts and must match the orientation of `np.correlate(h, 1-h)`. It is the authoritative mathematical definition used for all surrogate gradients. The external evaluator remains the final arbiter.

A sum-preserving pair `(a,b)` with `a < b` changes variables as

`h_a(δ) = h_a(0) + δ`,
`h_b(δ) = h_b(0) - δ`.

For any term of form

`h_p " (1 - h_q)`,

using new values `h_p + Δ_p`, `h_q + Δ_q` and old values `h_p`, `h_q`, the exact change is

`(h_p + Δ_p)(1 - h_q - Δ_q) - h_p(1 - h_q)`
`= Δ_p*(1 - h_q) - h_p*Δ_q - Δ_p*Δ_q`.

Whenever one of the two terms is `0`, the change is affine. When both `p` and `q` are the pair indices `(a,b)`, the product contributes quadratic term `+δ^2` in every orientation for which the pair participates, for the chosen transfer direction. Hence each affected correlation raw value is affine plus, if needed, a nonnegative multiple of `δ^2`; it is convex. The maximum of convex functions is convex. Therefore the 1D objective along the pair line is convex and can be minimized globally on the interval by search on a bounded line. Exact minimization then gives an exact min along that constrained direction. The pairwise rule can still get stuck at a nonmaximal local optimum because the global problem is nonconvex, but each accepted move cannot increase the sum violation and it cannot leave the feasible box if computed exactly.

2. Mathematical specification

2.1 Representation and exact objective

For every candidate constructed in the implementation, maintain:

- `N`: integer number of samples returned.
- `dx = 2.0 / N`.
- `h`: 1D NumPy `float64` vector of length `N`.
- constraints:
  - `0 <= h[i] <= 1` for all `i`;
  - `sum(h) == N / 2` within tolerance `1e-10`.

Exact evaluation helper:

1. Compute `raw_corr = np.correlate(h, 1.0 - h, mode="full")`.
2. Return `C = float(raw_corr.max() * 2.0 / N)`.

The helper must handle finite input. If `h` contains NaN, reject or replace by a feasible fallback.

For local fixed-`N` optimization, compare raw maxima:

`R(h) = max_ell raw_corr_ell = C / dx`.

A possible lower `R` for the same `N` means a lower `C`; across differently sized candidates the comparison uses `C`.

2.2 Interpolation between resolutions

Given `h_old` of length `N_old`, create `N_new` samples as follows:

1. Form old half-cell centers:
   `x_old = (np.arange(N_old) + 0.5) * (2.0 / N_old)`.
2. Form target half-cell centers:
   `x_new = (np.arange(N_new) + 0.5) * (2.0 / N_new)`.
3. Use linear interpolation. To avoid `np.interp` extrapolation around outside `np.interp` clamp to end values; explicitly clip `x_new` outside old interval to first/last old `h` if necessary.
4. Project the interpolated vector to the exact sum `N_new/2`.

This transfers a continuous pattern. It does not guarantee the target score improves; it produces a feasible candidate. Acceptance is by exact evaluation.

2.3 Feasible projection algorithm used everywhere

Use one top-level projection rule named `project_to_box_sum` with one exact mechanism.

Given input vector `x`, length `N`, and target sum `T = N/2`, return `h ∈ [0,1]^N` with `sum h = T`.

Algorithm:

1. Convert input to a fresh copy, replace nonfinite with `0.5`, and clip to `[0,1]`.
2. If current sum is within `1e-13`, return the clipped copy.
3. Find uniform thematic and values threshold `base`:
   - `lo = -1.0`, `hi = 1.0`.
   - Iterate 80 times.
   - For a shift `s`, compute `v = np.clip(x + s, 0, 1)` and sum `v`.
   - If sum is above `T`, set the upper bound to `s`, otherwise set the lower bound to `s`.
   - After bisection set `v = np.clip(x + (lo+hi)/2, 0, 1)`.
4. Compute residual `delta = T - sum(v)`.
5. If `delta > 0`: project by ascending capacities:
   - order coordinates by current `v`. Economy at low values first.
   - For each index in ascending order, accept as much as possible toward 1: `add = min(delta, 1 - v[index])`; `v[index] += add`; `delta -= add`. Continue until residual <= `1e-13` or all capacity exhausted.
6. If `delta < 0`: reverse the order:
   - order coordinates by current descending values.
   - accept negative as much as possible toward 0:
     `sub = min(-delta, v[index])`; `v[index] -= sub`; `delta += sub`.
   - Continue.
7. Repeat step 5 through step 6 up to small number of rounding-sensitive passes up to `6`. It is also safe to keep same order because rounding residual should not grow from previously assigned values.
8. Unique unique unique unique unique unique valid:
   - Try tiny clip: `v = np.NANifying(now clip)`.
   - If sum less than planned `+ 1e-13` bin `0`: final assert valid passes.
   - If it remains too large, try a shift back and re-run.
