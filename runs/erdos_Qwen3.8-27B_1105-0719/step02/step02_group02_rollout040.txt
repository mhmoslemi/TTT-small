Let me now think about the **cutting-plane LP** approach more carefully.

At each iteration:
1. Compute corrs at current h.
2. Find the most violated constraint (the lag with max correlation).
3. Add its linearization to the active set.
4. Solve the LP: min t s.t. (active linearized constraints), 0≤h≤1, sum(h)=n/2.
5. Update h to the LP solution.
6. Repeat until convergence.

The LP in standard form for scipy.optimize.linprog:
minimize c · x
subject to A_ub · x ≤ b_ub
         A_eq · x = b_eq
         bounds

where x = [h_0, h_1, ..., h_{n-1}, t]

Objective: c = [0, ..., 0, 1] (minimize t)

Constraints:
- For each active lag k: (grad_k · h) ≤ t, i.e., grad_k · h - t ≤ 0
  In (A_ub, b_ub) form: row = [grad_k, -1], b = 0
- 0 ≤ h_i ≤ 1: handled by bounds
- sum(h) = n/2: A_eq = [1, ..., 1, 0], b_eq = [n/2]

Wait, the linearization is:
C_k(h) ≈ C_k(h*) + grad_k(h*) · (h - h*)

So the constraint C_k(h) ≤ t becomes:
C_k(h*) + grad_k · (h - h*) ≤ t
grad_k · h ≤ t - C_k(h*) + grad_k · h*
grad_k · h - t ≤ -C_k(h*) + grad_k · h*

```python
        max_idx = np.argmax(corrs)

        if max_idx not in [a[0] for a in active]:

            c_val = corrs[max_idx]
            active.append((max_idx, g, c_val))

            active = active[-n_active_max:]

            row[:n] = g

            b_ub.append(-c_val + g @ h)

        b_eq = np.array([target_sum])
```

```python
def weighted_sa(h_init, dx, n_iter=500000, rng=None):

    h[order[:n//2]] = 1.0
    
    corrs = compute_corrs(h)
    cur_c5 = corrs.max()
    best_c5 = cur_c5
    best_h = h.copy()
    
    # Temperature schedule with restarts
    base_t0 = best_c5 * 0.2
    base_tf = best_c5 * 0.001
    segments = 10
    seg_len = n_iter // segments
    cooling = (base_tf / base_t0) ** (1.0 / seg_len)
    
    for seg in range(segments):
        temp = base_t0 * (base_tf / base_t0) ** (seg / segments)
        for it in range(seg_len):
            # Weighted selection: positions in active lags get higher weight
            active_mask = corrs > 0.8 * corrs.max()
            # Positions involved in active lags
            weight = np.ones(n)
            for k in np.where(active_mask)[0]:
                offset = k - (n-1)
                i_lo = max(0, -offset)
                i_hi = min(n-1, n-1-offset)
                idx = np.arange(i_lo, i_hi+1)
                weight[idx] += 1
                weight[idx+offset] += 1
            
            ones = np.where(h == 1)[0]
            zeros = np.where(h == 0)[0]
            
            # Weighted random selection
            w_ones = weight[ones]
            w_zeros = weight[zeros]
            w_ones /= w_ones.sum()
            w_zeros /= w_zeros.sum()
            
            i = ones[rng.choice(len(ones), p=w_ones)]
            j = zeros[rng.choice(len(zeros), p=w_zeros)]
            
            h[i] = 0.0
            h[j] = 1.0
            new_corrs = compute_corrs(h)
            new_c5 = new_corrs.max()
            
            delta = new_c5 - cur_c5
            if delta < 0 or rng.rand() < np.exp(-delta / temp):
                cur_c5 = new_c5
                corrs = new_corrs
                if new_c5 < best_c5:
                    best_c5 = new_c5
                    best_h = h.copy()
            else:
                h[i] = 1.0
                h[j] = 0.0
            
            temp *= cooling
    
    return best_h, best_c5 * dx
```

For the greedy, at each step we add position p to S (set h[p]=1). The change in corrs[k] from this is:
- For each k, offset = k - (n-1)
- If p - offset is a valid index in [0, n-1] AND p is the "h[n+offset]" position:
  i.e., if there exists n such that n+offset = p, i.e., n = p-offset, and n is in [i_lo, i_hi]:
  corrs[k] increases by (1 - h[p-offset]) = 1 - h[p-offset] (since h[p-offset] is 0 or 1 currently)
  
- If p is the "n" position (i.e., p is in [i_lo, i_hi]):
  corrs[k] decreases by h[p+offset] (which is 0 or 1)

So the net change in corrs[k] is:
delta_k = (1 - h[p-offset]) * I(p-offset ∈ valid range) - h[p+offset] * I(p ∈ valid range)

where "valid range" for the first term means p-offset ∈ [i_lo(k), i_hi(k)] and for the second term means p ∈ [i_lo(k), i_hi(k)].

For corrs[k] with offset = k - (n-1):
corrs[k] = sum_{n=i_lo}^{i_hi} h[n+offset] * (1-h[n])
where i_lo = max(0, -offset), i_hi = min(n-1, n-1-offset)

The valid range for n is [i_lo, i_hi].
For the "h[n+offset]" term: n ranges over [i_lo, i_hi], so n+offset ranges over [i_lo+offset, i_hi+offset].
For the "(1-h[n])" term: n ranges over [i_lo, i_hi].

If we change h[p] from 0 to 1:

  Change: +(1-h[p-offset]) = 1 (since h[p-offset] is 0 or 1, and we're adding to a position where h[p] was 0)
  Actually, the change is: old term was 0*(1-h[p-offset]) = 0, new term is 1*(1-h[p-offset]) = 1-h[p-offset].

```python
import numpy as np
from scipy.optimize import minimize
from scipy.special import logsumexp
import time

def compute_corrs(h):
    return np.correlate(h, 1.0 - h, mode='full')

def c5_of_h(h, dx):
    return float(compute_corrs(h).max() * dx)

def project_feasible(x, target_sum):
    n = len(x)
    lo, hi = -1.0, 1.0
    for _ in range(60):
        mid = (lo + hi) / 2.0
        h = np.clip(x - mid, 0.0, 1.0)
        if h.sum() > target_sum:
            lo = mid
        else:
            hi = mid
    h = np.clip(x - (lo + hi) * 0.5, 0.0, 1.0)
    diff = target_sum - h.sum()
    if abs(diff) > 1e-14:
        mask = (h > 1e-12) & (h < 1.0 - 1e-12)
        if mask.sum() > 0:
            h[mask] += diff / mask.sum()
            h = np.clip(h, 0.0, 1.0)
    return h

def grad_corr_k(h, k, n):
    offset = k - (n - 1)
    grad = np.zeros(n)
    if offset == 0:
        grad[:] = 1.0 - 2.0 * h
        return grad
    i_lo = max(0, -offset)
    i_hi = min(n - 1, n - 1 - offset)
    if i_lo > i_hi:
        return grad
    idx = np.arange(i_lo, i_hi + 1)
    grad[idx + offset] += (1.0 - h[idx])
    grad[idx] += (-h[idx + offset])
    return grad

def smooth_max_obj(h, dx, beta):
    corrs = compute_corrs(h)
    return float(logsumexp(beta * corrs) / beta * dx)

def smooth_max_grad(h, dx, beta):
    n = len(h)
    corrs = compute_corrs(h)
    shift = corrs - corrs.max()
    w = np.exp(beta * shift)
    w_sum = w.sum()
    if w_sum < 1e-300:
        w = np.ones(2 * n - 1) / (2 * n - 1)
    else:
        w /= w_sum
    grad = np.zeros(n)
    for k in range(2 * n - 1):
        if w[k] > 1e-14:
            grad += w[k] * grad_corr_k(h, k, n)
    return grad * dx

def slsqp_smooth(h0, dx, target_sum, beta, maxiter=500):
    n = len(h0)
    bounds = [(0.0, 1.0)] * n
    
    def obj(x):
        return smooth_max_obj(x, dx, beta)
    
    def grad(x):
        return smooth_max_grad(x, dx, beta)
    
    cons = [{'type': 'eq', 'fun': lambda x: x.sum() - target_sum,
             'jac': lambda x: np.ones(n)}]
    
    try:
        res = minimize(obj, h0, jac=grad, method='SLSQP',
                       bounds=bounds, constraints=cons,
                       options={'maxiter': maxiter, 'ftol': 1e-16})
        h_out = project_feasible(res.x, target_sum)
    except Exception:
        h_out = project_feasible(h0, target_sum)
    return h_out, c5_of_h(h_out, dx)

def sa_binary(h_init, dx, target_sum, n_iter, rng, use_weighted=True):
    n = len(h_init)
    target = int(target_sum)
    
    # Initialize
    h = np.zeros(n)
    order = np.argsort(-h_init)
    h[order[:target]] = 1.0
    
    corrs = compute_corrs(h)
    cur_val = corrs.max()
    best_val = cur_val
    best_h = h.copy()
    
    t0 = best_val * 0.15
    tf = best_val * 0.0005
    cooling = (tf / max(t0, 1e-15)) ** (1.0 / max(n_iter, 1))
    temp = t0
    
    no_improve = 0
    for it in range(n_iter):
        ones = np.where(h == 1)[0]
        zeros = np.where(h == 0)[0]
        if len(ones) == 0 or len(zeros) == 0:
            break
        
        if use_weighted:
            # Weight positions by their involvement in active lags
            active_thresh = 0.85 * corrs.max()
            active_lags = np.where(corrs >= active_thresh)[0]
            if len(active_lags) > 0 and len(active_lags) < 50:
                weight = np.ones(n)
                for k in active_lags:
                    offset = k - (n - 1)
                    i_lo = max(0, -offset)
                    i_hi = min(n - 1, n - 1 - offset)
                    if i_lo <= i_hi:
                        weight[i_lo:i_hi+1] += 1
                        j_lo = max(0, i_lo + offset)
                        j_hi = min(n - 1, i_hi + offset)
                        if j_lo <= j_hi:
                            weight[j_lo:j_hi+1] += 1
            else:
                weight = np.ones(n)
        else:
            weight = np.ones(n)
        
        w_ones = weight[ones].astype(float)
        w_zeros = weight[zeros].astype(float)
        if w_ones.sum() > 0:
            w_ones /= w_ones.sum()
        else:
            w_ones = np.ones(len(ones)) / len(ones)
        if w_zeros.sum() > 0:
            w_zeros /= w_zeros.sum()
        else:
            w_zeros = np.ones(len(zeros)) / len(zeros)
        
        i = ones[rng.choice(len(ones), p=w_ones)]
        j = zeros[rng.choice(len(zeros), p=w_zeros)]
        
        h[i] = 0.0
        h[j] = 1.0
        new_corrs = compute_corrs(h)
        new_val = new_corrs.max()
        
        delta = new_val - cur_val
        if delta < 0 or (temp > 1e-15 and rng.rand() < np.exp(-delta / temp)):
            cur_val = new_val
            corrs = new_corrs
            if new_val < best_val:
                best_val = new_val
                best_h = h.copy()
                no_improve = 0
            else:
                no_improve += 1
        else:
            h[i] = 1.0
            h[j] = 0.0
            no_improve += 1
        
        temp *= cooling
    
    return best_h, best_val * dx

def greedy_construct(n, rng):
    h = np.zeros(n)
    corrs = np.zeros(2 * n - 1)
    
    for step in range(n // 2):
        best_p = -1
        best_max = float('inf')
        for p in range(n):
            # Compute new max if we set h[p] = 1
            new_max = 0.0
            for k in range(2 * n - 1):
                offset = k - (n - 1)
                i_lo = max(0, -offset)
                i_hi = min(n - 1, n - 1 - offset)
                if i_lo > i_hi:
                    delta = 0
                else:
                    delta = 0
                    # p in h[n+offset] position
                    if i_lo <= p - offset <= i_hi and 0 <= p - offset <= n - 1:
                        delta += (1.0 - h[p - offset])
                    # p in n position
                    if i_lo <= p <= i_hi and 0 <= p + offset <= n - 1:
                        delta -= h[p + offset]
                new_val = corrs[k] + delta
                if new_val > new_max:
                    new_max = new_val
            if new_max < best_max:
                best_max = new_max
                best_p = p
        
        h[best_p] = 1.0
        # Update corrs
        for k in range(2 * n - 1):
            offset = k - (n - 1)
            i_lo = max(0, -offset)
            i_hi = min(n - 1, n - 1 - offset)
            if i_lo > i_hi:
                continue
            delta = 0
            if i_lo <= best_p - offset <= i_hi and 0 <= best_p - offset <= n - 1:
                delta += (1.0 - h[best_p - offset])
            if i_lo <= best_p <= i_hi and 0 <= best_p + offset <= n - 1:
                delta -= h[best_p + offset]
            corrs[k] += delta
    
    return h
```

Actually wait, I realize there might be a bug. When I check "p in h[n+offset] position", I need p = n+offset for some valid n. The valid n range is [i_lo, i_hi]. So p-offset must be in [i_lo, i_hi]. But I also need p itself to be a valid index (0 ≤ p ≤ n-1), which it is by construction.

Similarly, "p in n position" means p ∈ [i_lo, i_hi]. And I need p+offset to be a valid index (0 ≤ p+offset ≤ n-1).
