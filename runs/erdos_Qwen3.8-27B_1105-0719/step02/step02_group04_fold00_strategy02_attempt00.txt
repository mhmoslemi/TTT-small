1. Approach and rationale

1.1 Central idea and why it is materially different

The task is to reduce the exact discrete overlap bound from the supplied parent value near 0.380938 to below 0.3808. The authoritative score is the exact finite-support cross-correlation maximum
`C(h) = max_j corr(h, 1-h)[j] * (2/n_points)`,
where `corr` is linear discrete correlation, not circular correlation, and all `2n-1` lags, in both directions, are included.

The previous methods described in the context are best understood as smooth or least-squares proxies whose output is then judged exactly. They do not directly represent the hard epigraph constraints that are causing the plateau: near the optimum many correlation values are almost tied, and a small move in `h` must simultaneously control one or more of these tied upper constraints. A smooth objective such as log-sum-exp collapses this truss into a weighted penalty and often fails to lower the exact max; a least-squares equalizer makes selected correlations equal but does not directly minimize their maximum.

The proposed primary algorithm is different: at each current nonconvex feasible point, build a local exact epigraph nonlinear program

`minimize t`  
`subject to selected exact correlations C_j(h) <= t`,  
`sum(h) = n/2`,  
`0 <= h_i <= 1`,

and solve it with a nonlinear constrained optimizer that accepts the actual per-lag gradient structure (`SciPy SLSQP`). The selected correlations are those currently detected as top bottlenecks by the exact evaluator. After solving, we return a feasible vector from an exact feasibility projection and accept or discard it only by the exact task score. Candidate vectors are not accepted because the surrogate subproblem succeeded, but only because the exact `np.correlate` evaluation improved the recorded best feasible value.

This addresses the local bottleneck in a dedicated way:

- It solves for `t` directly rather than trying to approximate a max.
- It gives exact selected correlation constraints their own Lagrangian roles, instead of globally averaging them.
- The set of active correlations is recomputed from the exact correlation vector after accepted moves, so hidden bottlenecks that rise can later enter.
- It uses exact gradients to respect the finite-support correlation orientation and boundary overlap truncation.

1.2 Nonconvex status and justification

For a nonzero lag, the correlation contains products `h_i * (1 - h_{i-d})`. The individual products are indefinite on `[0,1]`, so the epigraph problem is genuinely nonconvex. We do not claim global optimality or an equivalent convex relaxation. The nonlinear program is a local active-set minimax correction. Its value is experimental: if a new local point yields a smaller exact `C(h)`, it is a mathematically valid construction for the discrete problem, but it is not certified globally optimal. Feasibility is ensured independently of the nonconvex optimizer by a sum-preserving projection and the anti-symmetric builder when used.

1.3 Main algorithm family and accepted variation

The primary family is active-set exact epigraph SLSQP, repeated with gradually larger active sets. There are three related implemented modes that share the same mathematical formulation but differ in representation and state space:

- Full mode: directly optimizes full `h` with exact sum equality and selected correlation inequalities. It uses the representation with maximum expressive power. Full mode is the primary default because the supplied parent may not be symmetric.
- Anti mode: optimizes the first half of an anti-complementary builder with automatic fixed sum and bounds. This makes the integral constraint exact and reduces variables by about a factor of 2. It is useful to expose structure and to polish without needing sum repair, but not an unconditional loss assumption.
- Random/perturbed mode: dynamically re-enters the same SLSQP formulation from slight random or generated starts around accepted feasible solutions. This prevents immediate stagnation at the parent point; it is still centered on the same epigraph constraints rather than a globally different objective.

The material difference relative to earlier proposed ideas is the use of actual epigraph inequality constraints and constrained local nonlinear-programming candidates, with exact reselection from the true fully evaluated correlation vector.

2. Mathematical specification

2.1 Exact objective and indexing used uniformly

Let `n` be the number of samples returned. Let `dx = 2/n`. Let `g = 1 - h` elementwise. The task evaluator is

`C_score(h) = max_{s = 0,...,2n-2} (np.correlate(h, g, mode='full')[s] * dx)`.

For nonsmooth optimization, define for output/lag index `s` the signed lag parameter

`d = s - (n - 1)`.

The unscaled correlation value matching NumPy full cross-correlation is

`corr_raw[s] = sum_{i=lo(s)}^{hi(s)} h_i * (1 - h_{i-d})`.

where the sums over valid indices use inclusive `lo, hi` with

`lo(s) = max(0, d)`  
`hi(s) = min(n - 1, n - 1 + d)`.

If `lo > hi`, the contribution is zero. The scaled exact value for that correlation index is

`C_s(h) = dx * corr_raw[s]`.

This includes all truncated boundary overlaps for `d != 0` and both lag directions because `s` ranges over the full `2n-1` correlation output array.

2.2 Gradient identity

For selected output index `s`, let `g_raw(s)` denote the gradient of the unscaled correlation `corr_raw[s]` with respect to the full vector `h`. Valid contribution pairs are `(i, i - d)`. Starting from a zero vector of length `n`:

1. For `lo to hi`, add `1 - h[lo - d : hi - d + 1]` to gradient entries `h[lo : hi + 1]`.
2. For the same product terms, add `-h[lo : hi + 1]` to gradient entries `h[lo - d : hi - d + 1]`.

The gradient of the scaled objective constraint value is `dx * g_raw(s)`. Thus the gradient of the epigraph constraint

`F_s(h, t) = t - C_s(h)`

is

- full `h` coordinate entries: `-dx * g_raw(s)`
- `t` coordinate derivative: `+1`.

This indexing convention is consistent with taking the derivative of the finite exact NumPy correlation at interior and boundary overlap indices. A numerical finite-difference validation should be checked on one or two random feasible vectors as a non-blocking defensive measure. If a mismatch is detected due to an accidental implementation orientation error, one should switch to using the exact `np.correlate` array and a one lag-coordinate swap or recompute the gradient rows only after correcting the implementation, not silently use inaccurate gradients. In the specification above, the formula itself is already matched to NumPy's full correlation convention; verification should pass.

2.3 Anti-complementary representation

When using anti mode, because `n` should be chosen even, put `m = n // 2`. Let `q` be variables length `m`, with `0 <= q_i <= 1`. Define the builder

`h[0:m] = q[0:m]`  
`h[m:n] = 1 - reverse(q)`, i.e. `h[m+j] = 1 - q[m - 1 - j]`.

For every pair `(q_k, 1 - q_{m-1-k})`, the pair sum is exactly 1, so the full sum over `h` is exactly `m = n/2`, before floating accumulation error. The integral condition is therefore intrinsic and no sum constraint or repair is needed for exactly represented anti vectors. If arbitrary floating drift or projection is applied outside the builder, re-evaluate exact sum against target using tolerance about `1e-9`.

Given full feasible `h` of even length, derive the nearest anti first half by

`q_i = 0.5 * (h_i + 1 - h_{n-1-i})`, then clamp `q_i` independently to `[0,1]`. This gives a feasible anti vector and preserves length `m`; the full reconstructed vector by the builder automatically has exact target sum. It does not guarantee that the anti score equals the full score, so exact scoring is required after any conversion.

The anti-mode gradient chain is: For a constraint row `g_full` in full `h` coordinates, the derivative with respect to `q_i` is

`dq_i = g_full[i] - g_full[n - 1 - i]`.

The `t` coordinate derivative remains `+1`. Variables have bounds `[0,1]`.

If `n` is odd, it is strongly simpler and unavoidable to avoid anti mode for that `n` because exact `sum(h)=n/2` is fractional; use full mode or convert an odd vector to an even target `n - 1` or `n + 1`. Candidate lengths should be even wherever an anti builder is used.

2.4 Feasibility-preserving projection for arbitrary vectors

The constraints are simultaneous box constraints `0 <= v_i <= 1` and the hyperplane `sum(v) = n/2`. Sequential clipping and adding cannot in general preserve both. Use a scalar one-dimensional projection that finds `lambda` so that

`v(lambda) = clip(x - lambda, 0, 1)`

has the desired sum. Because `sum(clip(x - lambda, 0, 1))` is monotone non-increasing in `lambda`, use bisection to solve for sum equal to target. Since target `n/2` lies strictly inside possible sums, an anchor interval broader than the data range suffices; `lambda` can be allocated in `[-1, 1]` expanded by any finite nondominant initial result. After the root `lambda` is located to about `1e-16` relative accuracy, after endpoint clipping the sum error can be taken up by variables whose current coordinate satisfies `1e-13 < v_i < 1 - 1e-13`: distribute `target - sum(v)` equally over them to reduce residual sum error to machine epsilon. If there are no interior variables for numerical corner cases, return `x` unchanged without tiny violation vector if it is already feasible; otherwise create a known anti feasible `0.5` fallback and defer projection.

For full mode acceptability, post-projection exact sum tolerance should be within `1e-8` or absolute sum error `<= 1e-8*n` and max bound violation `<= 1e-12`. For final output, enforce 0 and 1 exactly by clamping and equal interior redistribution.

2.5 Correlation objective for scoring

Every candidate scoring function used for acceptance must be

`c5 = float(np.max(np.correlate(np.asarray(h, float), 1.0 - np.asarray(h, float), mode='full')) * (2.0 / len(h)))`.

It should not use the internal optimized `corr_raw` values selected by the NLP for acceptance. The NLP values can be used only to choose footwork.

1. Approach and rationale

1.1 Target, bottleneck, and central method

The scored quantity is the exact discrete overlap value

`C5(h) = max_j corr(h, 1 - h)[j] * (2/n_points)`,

where `corr` is NumPy linear/final-support cross-correlation (`mode="full"`); all `2n_points - 1` lags and both lag directions must be included. The supplied construction is around `0.380938`, and the goal is at or below `0.3808`. This is a very small numerical gain, so the bottleneck is not broad global search, but a local plateau: several correlation lags are almost tied at the current maximum, and any useful movement must treat the tied upper-bound constraints simultaneously.

The proposed primary method is an exact epigraph active-set local nonlinear program. At a current feasible vector `h`, compute the exact correlation vector. Choose the currently high bound constraints and solve

`minimize t`  
`subject to C_j(h) <= t for selected j`  
`sum_i h_i = n/2`  
`0 <= h_i <= 1`.

The program is directly scored only when a feasible candidate produced by the local program has a smaller exact `C5` from the original evaluator. If the exact metric improves, the candidate is accepted; otherwise it is rejected, regardless of how well the surrogate subproblem performed.

1.2 Why this is a better match for the bad plateau

- It keeps the true upper envelope of selected correlations as explicit constraints rather than replacing the maximum by a smooth penalty, log-sum-exp smoothing, or a pure least-squares equalizer.
- The active correlation set is selected from the exact correlation vector and refreshed after each accepted move, so hidden constraints that rise just above earlier chosen constraints can later enter.
- The `t` variable directly minimizes the modeled upper envelope.
- The selected inequalities are exactly the needed `t - C_j(h) >= 0` constraints, with analytic dot-Hessian gradients, avoiding finite-difference noise.
- Feasibility is enforced independently by a joint sum-and-box projection or an anti-symmetric builder. Acceptance is based only on the original metric, so nonconvex solvers cannot intentionally weaken the published bound.

1.3 Scope and nonconvex safety

Products `h_i * (1 - h_{i-d})` make the feasible correlation constraints and objective values nonconvex. The local epigraph QP is not a relaxation proving global optimality. It is a local numerical correction directed by exact selected inequalities. The only certification that matters is exact evaluation: the returned vector is feasible and has a lower exact objective than the fallback. Different active sets, lengths, representations (full and anti builder), and pseudo-random perturbations improve the chance of crossing the local plateau without impeding the exact acceptance rule.

1.4 Main algorithm family and variation

All work is housed in one unified flow but implemented alternately through three representations:

1. Full mode: optimize full `h` with the stated sum equality and list of selected top correlation values. It can discover improvements that are not symmetric under complementary reflection.
2. Anti-builder mode: define the second half as the complement of the reversed first half; the sum constraint becomes intrinsic with variables/upper bounds, giving approx half as many variables and momentum for refined local small moves. This is a strong continuation method but not assumed to be space-preserving by itself; every anti output is re-scored exactly.
3. Perturb/restart mode: small, constrained, targeted changes around accepted states, fed into the same active-constraint NLP. This breaks local KKT stagnation while retaining the exact epigraph model.
