1.2 Why it can improve the given point

The smooth log-sum-exp descent used previously is only a surrogate optimizer and is constrained by its basin. Adding exact coordinate descent can locally center the max of the exact lags more directly. Active-set epigroup SLSQP makes the constraints explicit, and locally linearized subproblems act as conservative trust-region steps. Binary / low-discrepancy search can reach “fractal/combinatorial” boundary configurations that continuous descent starting from the current parent may not find. Multi-resolution transport can reduce artifacts from a particular grid.

1.3 Main approach coherence

Use symmetric half-space as the primary representation because its sum constraint is always exactally satisfied. Treat the half-space tuples as construction parameters. Any output is converted back to a full h vector and scored by the original objective. The final returned construction must be reconstructed and rescored before submission.

For non-symmetric phase, feasibility is maintained by a dedicated exact-sum projection. Binary/deconstructive phases are always valid because the symmetric binary construction preserves the sum and bounds.

1.4 Failure safeguards

If optimization is time-expensive or unstable, the optimizer must have already published an intermediate score. It must never lose the valid candidate that scored lower than previously found. The original parent becomes the emergency fallback.

2. Mathematical specification

2.1 Exact task objective

For a full h vector of length n:

```
dx = 2.0 / n
C_exact = max(np.correlate(h, 1.0 - h, mode="full")) * dx
```

This is the sole optimization acceptance metric.

2.2 Symmetric half-variable construction

For even n=2m, define q in [0,1]^m. Build:

```
h[0:m] = q
h[m:] = 1 - q[::-1]
```

Then:

```
sum(h) = sum(q) + sum(1 - q) = n/2
```

All entries are still in [0,1] because q_i ∈ [0,1].

For odd n, drop the last parent sample before med range half representation. When moving to a different resolution, force the transferred vector to even length. The fallback may avoid odd lengths entirely.

2.3 Transport from full vector to symmetric half-vector

For a valid h of even n=2m, define:

```
q_proj[i] = 0.5 * (h[i] + (1 - h[n-1-i]))
q_proj = clip(q_proj, 0.0, 1.0)
```

Then h_sym = construct(q_proj).
