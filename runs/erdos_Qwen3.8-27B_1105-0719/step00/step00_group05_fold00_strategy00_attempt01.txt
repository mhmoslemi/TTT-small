1. Approach and rationale

1.1 Central idea
The authoritative quantity is the finite-support discrete maximum of the bilinear cross-correlations

    A_m(h) = (2/n_points) * sum_{valid pairs} h[i] * (1 - h[j]),

for all 2*n_points-1 lag indices provided by `np.correlate(h, 1-h, mode="full") * dx`.  
The feasible set is convex:

    0 <= h[i] <= 1,    sum_i h[i] = n_points / 2,

but the objective is a maximum of bilinear functions of `h`, hence globally nonconvex. A direct CVXPY model of the exact objective is not available because of the products h[i]*h[j]. This plan therefore uses an improvement/perturbation search that (i) uses a smooth approximation of the maximum to obtain continuous descent directions, (ii) evaluates and accepts only the original discrete objective, (iii) keeps or returns a repaired convex projection whenever a box+sum-constraint violation appears, and (iv) explores nearby resolutions, because small resolution changes often expose better discrete discretizations without requiring a global proof.

1.2 Why this can improve the supplied parent
The supplied construction at 42 samples is already good, so the relevant bottleneck is fine local adjustment and escape from a local plateau. The method improves a parent by:

- running deterministic projected optimization from the parent at its native resolution;
- randomly but reproducibly perturbing the parent and running the same projected method;
- using ``smooth maximum`` gradients that gradually emphasize the largest correlation lags;
- after a smooth candidate is found, using an exact active-constraint direction line search to polish according to the original max objective;
- optionally transferring the construction to a higher or adjacent resolution, optimizing there, and down-transferring for exact evaluation; lower resolution is preferred only when scores are tied or nearly tied.

1.3 Justified facts versus heuristic hypotheses
The following are facts for the discrete problem:

- `max_m A_m(h) * dx >= 0`; the returned bound is always exact after re-evaluation.
- The feasible set is convex, so one common orthogonal projection onto `box intersect hyperplane` restores feasibility completely.
- The gradients of the discrete objective vector are easily derived from the bilinear formula, so no numerical gradient approximation is needed.
- Candidate acceptance uses the evaluator's exact finite correspondence with `np.correlate(h, 1-h, mode="full") * dx`; no lower-bound surrogate or circular convolution is claimed to be exact for the objective.
