- We want to minimize max_k c_k(x)

The result has length 2*n - 1.

Let me just think of it as: for each lag offset, we compute the sum of products.

When we change h[i] = x and h[j] = S-x:
- Terms involving h[i]: contribute x * (1 - h[m]) for some m, or h[m] * (1-x) for terms where h[i] is in the second factor
- Similarly for h[j] with S-x
- Terms involving both h[i] and h[j]: contribute x*(1-(S-x)) or (S-x)*(1-x) = quadratic

So for each lag, the correlation is at most quadratic in x. Good.

The minimax problem: minimize max_k q_k(x) over x in [low, high], where q_k(x) is quadratic.

This is a 1D problem that can be solved by:
1. Bisection on threshold t: is there x in [low, high] such that q_k(x) <= t for all k?
2. For each k, q_k(x) <= t defines an interval (possibly empty, possibly all of [low,high])
3. The intersection of all these intervals (clipped to [low,high]) gives the feasible set
4. If non-empty, x is feasible at threshold t

Let me implement this:

For a quadratic q(x) = a*x² + b*x + c:
- q(x) <= t means a*x² + b*x + (c-t) <= 0
- If a > 0: between the two roots (or empty if discriminant < 0)
- If a < 0: outside the two roots (or all if discriminant < 0)

    n = len(h)

def _fix_sum(h, n):

def _stochastic_pass(h, rng, temperature, time_start, budget_s, safety_margin=10, n_iter=None):

        i = rng.integers(n)
        j = rng.integers(n)

        low = max(0.0, S - 1.0)
        high = min(1.0, S)

        x = rng.uniform(low, high)

        h_new[i] = x
        h_new[j] = S - x
        
        new_score = _evaluate_c5(h_new)
        
        # Metropolis acceptance
        if new_score < current_score:
            current_h = h_new
            current_score = new_score
            if new_score < best_score - 1e-13:
                best_h = h_new.copy()
                best_score = new_score
        else:
            delta = new_score - current_score
            if delta < 1e-10:

            else:
                accept = rng.random() < np.exp(-delta / max(temperature, 1e-10))
            if accept:
                current_h = h_new
                current_score = new_score
    
    return best_h, best_score

def _feasible_interval(a, b, c, t, low, high):
    """Find x in [low, high] such that a*x^2 + b*x + c <= t for all k (elementwise)."""
    c_adj = c - t
    n_lags = len(a)
    
    feasible_low = low
    feasible_high = high
    
    # Handle quadratic terms
    # For a > 0: roots give [r1, r2] where q <= t
    # For a < 0: roots give (-inf, r1] ∪ [r2, inf) where q <= t
    # For a ≈ 0: linear
    
    # Vectorized:
    # disc = b^2 - 4*a*(c-t)
    # For a > 0: feasible is [max(low, r1), min(high, r2)]
    # For a < 0: feasible is [max(low, r2), min(high, r1)] (note r1 < r2)
    
    # Actually this is tricky because the "outside" case for a < 0 gives two intervals.
    # The intersection of "outside" intervals with [low, high] could be [low, r1] ∪ [r2, high]
    # But we need the intersection over ALL lags, so we need the intersection of all these.
    
    # This is harder to vectorize. Let me keep the loop but make it efficient.
    
    for k in range(n_lags):
        ak = a[k]
        bk = b[k]
        ck = c_adj[k]
        
        if abs(ak) < 1e-15:
            if abs(bk) < 1e-15:
                if ck > 0:
                    return None  # infeasible
                continue
            root = -ck / bk
            if bk > 0:
                feasible_high = min(feasible_high, root)
            else:
                feasible_low = max(feasible_low, root)
        else:
            disc = bk*bk - 4.0*ak*ck
            if disc < 0:
                if ak > 0:
                    return None  # always positive
                continue  # always negative
            sqrt_disc = np.sqrt(disc)
            r1 = (-bk - sqrt_disc) / (2.0*ak)
            r2 = (-bk + sqrt_disc) / (2.0*ak)
            if r1 > r2:
                r1, r2 = r2, r1
            if ak > 0:
                feasible_low = max(feasible_low, r1)
                feasible_high = min(feasible_high, r2)
            else:
                # Outside: [low, r1] or [r2, high]
                # The intersection with other constraints is complex.
                # For the "outside" case, the feasible set is [low, r1] ∪ [r2, high]
                # Intersecting with [feasible_low, feasible_high]:
                # Result: [max(feasible_low, low), min(feasible_high, r1)] ∪ [max(feasible_low, r2), min(feasible_high, high)]
                # This makes the interval tracking more complex.
                # For simplicity, let's handle it by checking both sub-intervals.
                # But for bisection, we just need to know if ANY point is feasible.
                # So: feasible if [feasible_low, min(feasible_high, r1)] is non-empty
                #      OR [max(feasible_low, r2), feasible_high] is non-empty
                lo1 = feasible_low
                hi1 = min(feasible_high, r1)
                lo2 = max(feasible_low, r2)
                hi2 = feasible_high
                if lo1 > hi1 and lo2 > hi2:
                    return None  # infeasible
                # For the actual feasible region, we'd need to track multiple intervals.
                # But for bisection, we just need feasibility. Let's be conservative:
                # Take the wider of the two sub-intervals.
                if (hi1 - lo1) > (hi2 - lo2):
                    feasible_low = lo1

The correlation is: c[k] = sum_i h[i+k-(n-1)] * (1-h[i]) for valid i.

When we change h[i] = x and h[j] = S-x:

- Terms where i appears in the second factor: h[m] * (1-x) for some m

- Terms where both i and j appear: x*(1-(S-x)) or (S-x)*(1-x)

For terms where neither is involved, the coefficient is constant (a=0, b=0).

def _check_feasible_vectorized(a, b, c_adj, low, high):
    """Check if there exists x in [low, high] with a_k*x^2 + b_k*x + c_adj_k <= 0 for all k."""
    n_lags = len(a)
    
    feasible_lo = np.full(n_lags, low)
    feasible_hi = np.full(n_lags, high)
    
    # Quadratic terms (a > 0)
    quad_mask = a > 1e-14
    if np.any(quad_mask):
        disc = b[quad_mask]**2 - 4.0 * a[quad_mask] * c_adj[quad_mask]
        valid = disc >= 0
        if not np.all(valid):
            return False, 0, 0
        sqrt_disc = np.sqrt(disc[valid])
        idx = np.where(quad_mask & valid)[0]
        r1 = (-b[idx] - sqrt_disc) / (2.0 * a[idx])
        r2 = (-b[idx] + sqrt_disc) / (2.0 * a[idx])
        lo_roots = np.minimum(r1, r2)
        hi_roots = np.maximum(r1, r2)
        feasible_lo[idx] = lo_roots
        feasible_hi[idx] = hi_roots
    
    # Linear terms (a ≈ 0, b ≠ 0)
    lin_mask = (a <= 1e-14) & (np.abs(b) > 1e-14)
    if np.any(lin_mask):
        roots = -c_adj[lin_mask] / b[lin_mask]
        idx = np.where(lin_mask)[0]
        # b*x + c <= 0: if b > 0, x <= root; if b < 0, x >= root
        pos_b = b[idx] > 0
        feasible_hi[idx[pos_b]] = roots[pos_b]
        feasible_lo[idx[~pos_b]] = roots[~pos_b]
    
    # Check intersection
    final_lo = np.max(feasible_lo)
    final_hi = np.min(feasible_hi)
    
    if final_lo <= final_hi:
        return True, final_lo, final_hi
    return False, 0, 0

def _eval_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr)) * dx

def _fix_sum(h, n):
    target = n / 2.0
    h = h.copy()
    h = np.clip(h, 0.0, 1.0)
    for _ in range(3):
        diff = target - np.sum(h)
        if abs(diff) < 1e-12:
            break
        if diff > 0:
            mask = h < 1.0 - 1e-10
        else:
            mask = h > 1e-10
        cnt = np.sum(mask)
        if cnt == 0:
            break
        h[mask] += diff / cnt
        h = np.clip(h, 0.0, 1.0)
    return h

    low = max(0.0, S - 1.0)
    high = min(1.0, S)
    if high - low < 1e-13:
        return None, float('inf')

    n_lags = 2 * n - 1
    dx = 2.0 / n

    x1 = low
    x3 = high
    x2 = (low + high) / 2.0
    if abs(x2 - x1) < 1e-12:
        x2 = low + (high - low) * 0.3
    if abs(x3 - x2) < 1e-12:
        x2 = low + (high - low) * 0.7

    c2 = np.empty(n_lags)
    c3 = np.empty(n_lags)

        np.correlate(h_tmp, 1.0 - h_tmp, mode='full', out=cv)

    d2 = (x2 - x1) * (x2 - x3)
    d3 = (x3 - x1) * (x3 - x2)

Actually, I realize I should double-check my understanding of `np.correlate(h, 1-h, mode='full')`.

For arrays a (length n) and v (length m), `np.correlate(a, v, mode='full')` returns an array of length n+m-1.
The output at index k is: sum_i a[i] * v[i + k - (m-1)] for valid i.

In our case, a = h, v = 1-h, both of length n. So the output has length 2n-1.
output[k] = sum_i h[i] * (1-h)[i + k - (n-1)] for valid i.

For k=0: h[i] * (1-h)[i-(n-1)] → only i=n-1 is valid: h[n-1] * (1-h)[0]
For k=n-1: h[i] * (1-h)[i] → sum_i h[i] * (1-h[i]) (the "zero lag" overlap)
For k=2n-2: h[i] * (1-h)[i+n-1] → only i=0: h[0] * (1-h)[n-1]

So the correlation at "lag 0" (zero offset) is at position n-1 in the output, and equals sum_i h[i](1-h[i]).

The maximum over all lags includes the zero-lag term and all offset terms.

        sd = np.sqrt(np.maximum(disc, 0.0))
        r1 = (-b[qm] - sd) / (2.0 * a[qm])
        r2 = (-b[qm] + sd) / (2.0 * a[qm])
        qi = np.where(qm)[0]
        fl[qi] = np.minimum(r1, r2)
        fh[qi] = np.maximum(r1, r2)
    lm = (a <= 1e-14) & (np.abs(b) > 1e-14)
    if np.any(lm):
        rt = -ca[lm] / b[lm]
        li = np.where(lm)[0]
        pos = b[li] > 0
        fh[li[pos]] = rt[pos]
        fl[li[~pos]] = rt[~pos]

    x_opt = float(np.clip((np.max(fl) + np.min(fh)) * 0.5, lo, hi))
    hn = h.copy()
    hn[i] = x_opt
    hn[j] = S - x_opt
    return hn


def run(seed=42, budget_s=1100, **kwargs):
    t0 = time.time()
    rng = np.random.default_rng(seed)

    try:
        h = np.asarray(initial_h_values, dtype=np.float64).flatten().copy()
    except (NameError, TypeError, ValueError):
        h = np.full(47, 0.5)

    if len(h) == 0 or not np.all(np.isfinite(h)):
        h = np.full(47, 0.5)

    n = len(h)
    h = _fix_sum(h)
    best_h = h.copy()
    best_c5 = _eval_c5(h)

    # Try simple transforms
    for t in [1.0 - h, h[::-1].copy()]:
        t = _fix_sum(t)
        s = _eval_c5(t)
        if s < best_c5:
            best_h = t.copy()
            best_c5 = s
    h = best_h.copy()

    pairs = [(i, j) for i in range(n) for j in range(i + 1, n)]
    np_ = len(pairs)

    # Main optimization loop with stochastic restarts
    stall = 0
    pert_scale = 0.05
    for p in range(1000):
        if time.time() - t0 > budget_s - 30:
            break
        order = rng.permutation(np_)
        improved = False
        for idx in order:
            if time.time() - t0 > budget_s - 30:
                break
            i, j = pairs[idx]
            hn = _pair_opt(h, i, j)
            if hn is not None:
                s = _eval_c5(hn)
                if s < best_c5 - 1e-13:
                    h = hn
                    best_h = hn.copy()
                    best_c5 = s
                    improved = True
        if improved:
            stall = 0
        else:
            stall += 1
            if stall >= 2:
                # Perturb to escape local optimum
                h = h + rng.normal(0, pert_scale, n)
                h = _fix_sum(h)
                # Re-optimize from perturbed state
                stall = 0
                pert_scale *= 0.7
                if pert_scale < 0.001:
                    pert_scale = 0.001

    # Final deterministic refinement passes
    for p in range(10):
        if time.time() - t0 > budget_s - 5:
            break
        for i in range(n):
            for j in range(i + 1, n):
                if time.time() - t0 > budget_s - 5:
                    break
                hn = _pair_opt(best_h, i, j)
                if hn is not None:
                    s = _eval_c5(hn)
                    if s < best_c5 - 1e-14:
                        best_h = hn
                        best_c5 = s

    best_h = _fix_sum(best_h)
    final_c5 = _eval_c5(best_h)
    return best_h, final_c5, n
