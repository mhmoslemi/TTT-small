1. Approach and rationale

1.1 Central idea

The discrete problem is too small for generic global optimization to be hopeless, but too nonconvex for a naive convex solver to prove anything. The main idea is to separate the search into two layers:

1. A *global exact linear-search over a validated binary/half-binary model*, using a mixed-integer linear program (MILP). For vectors whose entries are restricted to 0 and 1, except possibly one fixed 0.5 coordinate when the desired length is odd, the bilinear term

   `x_i (1 - x_j)`

   can be represented exactly with continuous auxiliary variables and linear inequalities. The objective `max_lag dx * sum_{i-j fixed} h_i(1-h_j)` is therefore the maximum of exact linear row sums. Solving this linear-integer epigraph model gives exact candidates in that restricted class, independent of any parent-derived coordinate direction. If such a candidate has a smaller exact discrete score than the parent, it immediately reduces the discrete bound under the task evaluator.

2. A *feasibility-preserving stochastic/smoothing continuation stage*, used only if the MILP stage does not already achieve the target. It uses exact parent/pool transformations, simulated flipping over binary/half-binary selected sets, logarithmic-sum-exponential smoothing with gradient-based local optimization, and an exact rank-two/direct coordinate descent loop. Every candidate is accepted or rejected only after evaluating the authoritative evaluator

   `C(h) = dx * max(np.correlate(h, 1-h, mode="full")).`

This is materially different from the earlier proposals: the primary driver is not local rank-one transfers, smooth surrogate coasts, or explicit active-lag LP linearization. Instead, the primary driver is an exact product-linearization MILP over the extreme point structure of the box and sum constraint, with only auxiliary stochastic/continuous polishing.

1.2 Why this can improve the supplied parent

The supplied parent is most likely a strong continuous local optimum under the known discrete score and known task-specific constructions. To move slightly below a value like `0.38085`, one often needs a coordinated change of many coordinates. The MILP model globally optimizes a broad class that includes the most natural endpoint structure for a total budget of 1 or a total budget of 1/2 plus binary values. It does not get stuck along a single transfer direction, and it can be run independently at several resolutions shorter or slightly longer than the parent length. If any of these MILP-rounded/half-binary solutions has a smaller exact evaluator score, the returned bound improves.

Even if the true discrete optimum uses many fractional values, MILP solutions often identify excellent near-optimal basins. They can reseed a stochastic and continuous polishing stage more diverse than starting only from the parent and random perturbations of the parent.

1.3 Justified facts, hypotheses, and limitations

Justified facts used by the design:

1. For binary `x ∈ {0,1}`, the identity

   `x_i(1-x_j) = x_i - x_i x_j`

   is linearized exactly by an auxiliary variable `w_ij` satisfying

   `0 ≤ w_ij ≤ x_i`,
   `w_ij ≤ 1 - x_j`,
   `w_ij ≥ x_i - x_j`.

   At binary endpoints, `w_ij` is forced to the actual product value.

2. For an odd length, `sum h_i = n/2` is half-integer. The fixed one-0.5 endpoint class with binary remaining entries is always feasible and exactly enforceable.

3. The exact evaluator is cheap: small vectors of length up to about 50 give correlations of length about 100 and product counts of a few thousand. Exact acceptance checks can be called many times.

Hypotheses and heuristics:

1. The MILP may not reach a better global optimum if the true better solution requires values other than 0, 0.5, and 1. In that case, the binary/half-binary class may not capture the parent's fractional gain. The continuation stage is a heuristic defense against this.

2. Solver status is not a proof of the global continuous optimum. The MILP is exact only over its restricted integer model; the continuous polish only gives local improvements; final truth resides in the authoritative evaluator.

3. Fixed half-coordinate location is a heuristic restriction for odd lengths. If the best half-binary solution has the half at another position, many fixed assignments must be tried at that length if time permits.

4. Simulated annealing and smoothing are stochastic. They do not provide certificates. They only provide candidate solutions judged by the exact objective.

Therefore the program must never report the internal MILP objective as a continuous-optimum or global proof. The returned `c5_bound` is always the exact evaluator score of the returned feasible vector.

2. Mathematical specification

2.1 Exact discrete objective and convention

For any feasible candidate vector `h` of length `n`, define

- `dx = 2.0 / n`,
- `g = 1 - h`,
- output length `L = 2*n - 1`.

The task-authoritative scalar objective is

`C_exact = dx * max_{s=0,...,L-1} corr_s`,

where

`corr = np.correlate(h, g, mode="full")`.

Feasibility required for return:

- `0 <= h[i] <= 1` for all `i`,
- `sum(h) ≈ n/2` within numerical tolerance, preferably exactly for binary and half-binary values.

The row mapping needed for MILP is derived from the discrete correlation convention. For indices `i, j ∈ {0,...,n-1}` set

`lag_index(i,j) = i - j + n - 1`.

This term `h_i * (1 - h_j)` contributes to output position `lag_index(i,j)`. Thus the discrete objective can be written as

`C_exact = dx * max_s R_s(h)`,

with

`R_s(h) = sum_{i,j : i-j+n-1 = s} h_i (1-h_j)`.

All boundary truncations are automatically included because only pairs inside the finite grid appear. Do not replace this by circular correlation or by a symmetric autocorrelation version.

2.2 Binary exact MILP over all-vector-at-endpoints

For an even length `n`:

Decision variables:

- `x ∈ {0,1}^n`, where `h_i = x_i`.
- For every ordered pair `(i,j)`, auxiliary `w_ij ∈ [0,1]`.

Exact product constraints:

For every pair `(i,j)`:

1. `w_ij <= x_i`.
2. `w_ij <= 1 - x_j`.
3. `w_ij >= x_i - x_j`.
4. `w_ij >= 0`.

For any integer solution, constraints 4 and constraints 1, 2, 3 force exactness:

- If `x_i = 1, x_j = 0`: constraints imply `w_ij >= 1` and `w_ij <= 1`, so `w_ij=1`.
- If `x_i = 0`: upper bound from `w_ij <= x_i` forces `w_ij=0`.
- If `x_j = 1`: upper bound from `w_ij <= 1-x_j` forces `w_ij=0`.

Thus `w_ij = x_i(1-x_j)`.

For each row `s` define

`W_s = sum_{i,j : i-j+n-1=s} w_ij`.

Epigraph variable `T ≥ 0`. MILP objective:

`minimize T`

subject to

`W_s <= T`, for every `s = 0,...,2n-2`.

The corresponding exact upper model bound is `dx*T`. At an integer feasible solution, `dx*T` equals the exact evaluator objective score. The final returned score will be recomputed with the evaluator regardless, because the MILP could be stopped early and can have numerical tolerance.

Sum constraint for even length:

`sum_i x_i = n/2`.

Because `n` is even, `n/2` is an integer. Use an exact integer right-hand side to avoid solver target violation.

2.3 Half-binary exact MILP with one or more fixed fractional coordinates

- choose some coordinates in a fixed set `F`,
- each fixed coordinate `p ∈ F` has a fixed value `a_p ∈ {0, 0.5, 1}`. In the default strict odd extension use exactly one fixed coordinate with value `0.5`, but the algebra below supports any values,
- remaining coordinates are boolean, indexed by `v_m`, with `h_i ∈ {x_m}` for `i ∉ F`,
- `sum_m x_m = n/2 - sum_{p∈F} a_p`.

The target must be an integer and lie in `[0, m]`, where `m = n - |F|`. If not, skip that fixed assignment.

For arbitrary fixed positions, each ordered pair `(i,j)` is decomposed into a contribution exact in the final final binary values. Let `s = lag_index(i,j)`.

Case 1: Both endpoints are variable booleans:

`i ∉ F, j ∉ F`.

Create a corresponding auxiliary `w_ij` and use all four linear product constraints as above. Add `+ w_ij` to row `s`.

Case 2: Both are fixed values:

`i ∈ F, j ∈ F`.

The contribution is the constant

`a_i * (1 - a_j)`.

Add that constant to row `s`.

Case 3: First is fixed value `a_i`, second is variable `x_v`:

Contribution

`a_i * (1 - x_v) = a_i - a_i x_v`.

Add constant `a_i` to row `s`, and add linear coefficient `-a_i` on variable `x_v` in row `s` in the under-METS epigraph form.

Case 4: First is variable `x_v`, second is fixed value `a_j`:

Contribution

`x_v * (1 - a_j) = (1 - a_j) x_v`.

with only binary-binput coefficients being 1 for each included arbitrary `w_ab`.

Add

`row_s_linear <= T`

and optionally `T ≥ 0`. The constants can be precomputed as a dense or sparse vector. The numerical algebra does not include `dx` inside the solver to avoid repeated floating scale and prevent essential shrink objective ambiguity. On recovery, the upper model bound is `dx*T`.

If this MILP is fully solved for a chosen fixed position, it returns an exact optimum over that odd half-binary restricted class. If not fully solved and it has a fractional integer solution with solution arrays, a conservative rounding rule described in rank by the solver variable values preserves feasibility and may yield good candidate vectors for exact evaluation. If no recovered value can be made feasible, skip it.

This is not a global convex relaxation of the full continuous problem. It is an exact restricted exact model whose objective and feasible set correspond exactly to the discrete evaluator over binary and assigned fractional entries.
