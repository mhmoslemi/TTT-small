1.1 Central objective and reputable problem model

1.1.1 The final trusted objective will always be exactly the task evaluator
`dx * max(np.correlate(h, 1-h, mode="full"))`, where `h` is a real one-dimensional
vector of length `n`, `dx = 2.0 / n`, `0 <= h_i <= 1`, and `sum_i h_i = n / 2` up to
the small tolerance permitted at return. All changes to `h` inside optimization live
inside these discrete constraints; comparison is always by the finished exact
evaluator vector after a repair routine, not by a surrogate value. The optimization
is nonconvex, so this construction is a heuristic search that provides a valid
upper bound if a feasible candidate is returned. It does not claim global
optimality, local optimality, or that every returned score can be returned with the
same numerical tolerance on every implementation environment.

1.1.2 The parent construction is a standard discretized feasible point whose score is
around 0.38085. The desired improvement is only about 0.00005. This is very small.
The local bottleneck is therefore not large, exploratory shape changes; the real
difficulty is to move simultaneously in the coordinates that jointly participate in
the currently active correlation maxima, while retaining exact finite-support overlap
semantics. The proposed framework searches for a better bound primarily through a
multi-resolution LogSumExp epigraph smoother, exact discrete-constraint repair, and
a number of starting points. The smoother is used only to generate candidate
trajectories. Every inherited candidate is accepted globally if and only if the
actual objective score is smaller than the current best score. This avoids replacing
the max objective with an incorrect one-sided or circular autocorrelation
approximation. It likewise avoids applying clipping followed by linear rescaling as
an invalid shortcut for both bounds and an exact integral.

1.2 Why a multi-resolution feasible smoothing gradual construction can improve
supplied parent

1.2.1 The parent function has 45 independent grid coordinates. At that resolution,
many variable combinations can be blocked by local active constraints and the
dependent equality condition. A smoother surrogate that gives decreasing but nonzero
weight to every lag can find rearrangements that reduce an overactive constraint
profile across several lags, which a one-dimensional fixed pair-line search may miss.
It does this without repeatedly constructing and validating huge-column active-set
linearizations: coordinates are moved continuously. The underlying constraint
`sum h = n/2` remains a hard linear equality in the smooth optimizer.

1.2.2 The parent is a single discrete representation of a step function. The exact
problem has input constraints and orientation, and the objective is more sensitive to
the sense of shifted sample assignments. Finer resolutions are allowable (well under

overlap below the parent. A parent-to-child resolution transfer changes the score
nontrivially, but the exact returned evaluator tells us immediately if a particular
child solution helps. The significant accuracy advantage is not that a transfer
automatically improves the score; it is that we get a better-conditioned feasible
seed at a different quantization for the smooth maximin step.

1.2.3 The complete search is deliberately diversified across multiple target

global best interpolation, deterministic or multiple seed, pair-escape randomized
