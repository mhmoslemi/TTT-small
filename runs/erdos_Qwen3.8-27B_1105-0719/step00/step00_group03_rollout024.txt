If h is a periodic function with period p (within [0,2]), then for shifts that are multiples of p, the correlation is zero (if the pattern is binary). For other shifts, it depends on the fractional part.

For a "grid" pattern: h(x) = 1 if floor(x/d) is even, 0 otherwise, where d is the "period half-length". Then:
- For shift k = m*d (multiple of period), correlation = 0
- For shift k = m*d + d/2 (half-period), correlation = maximum (all 1s align with 0s)

To equalize the correlation across all shifts, we might want a more complex pattern.

Actually, the optimal continuous solution to this type of problem is related to the "minimum overlap" problem studied by Erdős. The answer for C₅ (5-fold covering) is known to be around 0.38. Let me not try to derive it analytically and just focus on the numerical optimization.

def exact_score(h):
    n = len(h)
    dx = 2.0 / n
    scores = np.correlate(h, 1.0 - h, mode="full") * dx
    return float(scores.max()), scores

def project_balanced(y, target):
    n = len(y)
    lo, hi = float(y.min()) - 2.0, float(y.max()) + 2.0
    for _ in range(80):
        mid = (lo + hi) * 0.5
        s = np.clip(y + mid, 0.0, 1.0).sum()
        if s > target:
            hi = mid
        else:
            lo = mid
    x = np.clip(y + (lo + hi) * 0.5, 0.0, 1.0)
    res = target - x.sum()
    if abs(res) > 1e-10:
        idx = np.where((x > 1e-10) & (x < 1.0 - 1e-10))[0]
        if len(idx) > 0:
            x[idx] += res / len(idx)
            x = np.clip(x, 0.0, 1.0)
    return x

def weighted_gradient(h, weights, dx):
    n = len(h)
    g = 1.0 - h
    grad = np.zeros(n)
    for r in range(2 * n - 1):
        w = weights[r]
        if abs(w) < 1e-14:
            continue
        k = r - (n - 1)
        i_lo = max(0, -k)
        i_hi = min(n, n - k)
        for i in range(i_lo, i_hi):
            j = i + k
            grad[i] += dx * w * g[j]
            grad[j] += dx * w * (-h[i])
    return grad

def random_transfer(h, target, rng):

    h_new = np.zeros(n_new)
    for i in range(n_new):
        x_lo = i * dx_new
        x_hi = (i + 1) * dx_new
        j_lo = max(0, int(np.floor(x_lo / dx_old)))
        j_hi = min(n_old, int(np.ceil(x_hi / dx_old)))
        for j in range(j_lo, j_hi):
            ox_lo = j * dx_old
            ox_hi = (j + 1) * dx_old
            overlap = min(x_hi, ox_hi) - max(x_lo, ox_lo)
            if overlap > 0:
                h_new[i] += h[j] * overlap / dx_new
    h_new = np.clip(h_new, 0.0, 1.0)
