Let me think about the local active-set descent more carefully. Given the current best h with score C:
- Compute all lag values (profile)
- Identify the top A lags (active set)
- Compute the gradient of the active lag values
- Find a direction that decreases all active lag values simultaneously

Actually, a simpler approach: use the subgradient of the max function. The subgradient of max(f_1, ..., f_M) at h is the convex hull of {grad(f_m) : m in active set}. To decrease the max, we want a direction d such that grad(f_m) · d < 0 for all active m. This is equivalent to: find d in the negative of the convex hull of active gradients, projected to the feasible directions.

Simplest: average the gradients of active lags, negate it, project to sum=0, check box constraints.

def exact_score(h):
    n = len(h)
    dx = 2.0 / n
    return float(np.max(np.correlate(h, 1 - h, mode="full")) * dx)

def repair_feasible(vec):
    n = len(vec)
    x = np.clip(np.nan_to_num(vec, nan=0.5, posinf=1.0, neginf=0.0), 0.0, 1.0)
    target = n / 2.0
    diff = target - x.sum()
    if abs(diff) < 1e-13:
        return x
    if diff > 0:
        mask = x < 1.0
        cap = (1.0 - x[mask]).sum()
        if cap > 1e-15:
            scale = min(1.0, diff / cap)
            x[mask] += (1.0 - x[mask]) * scale
    else:
        mask = x > 0.0
        avail = x[mask].sum()
        if avail > 1e-15:
            scale = min(1.0, -diff / avail)
            x[mask] -= x[mask] * scale
    diff2 = target - x.sum()
    if abs(diff2) > 1e-14:
        if diff2 > 0:
            idx = np.argmin(x)
        else:
            idx = np.argmax(x)
        x[idx] = np.clip(x[idx] + diff2, 0.0, 1.0)
    return x

    n = len(h)

        return h.copy()

    h_ext = np.concatenate([[h[0]], h, [h[-1]]])
    return np.interp(x_dst, x_ext, h_ext)
