1. Approach and rationale

1.1 Central idea  
The problem is to find a feasible discrete vector \(h\in[0,1]^n\) with \(\sum_i h_i=n/2\) minimizing the worst signed-lag overlap
\[
C_5(h)= dx\,\max_{l\in\{-(n-1),\dots,n-1\}} \operatorname{corr}_l(h,1-h),\qquad dx=2/n,
\]
with `np.correlate(h, 1-h, mode="full")` as the authoritative discrete formulation. This is a small-dimensional but nonconvex quadratic max problem.

The plan combines two complementary stages:

1. Continuous local refinement of any supplied parent solution  
   Use a smooth surrogate for the maximum, log-sum-exp of the raw correlation values, and attempt local descent while preserving the linear total-mass and box constraints exactly. This is the most natural way to reduce a nearly optimal continuous parent like \(n=95\) by a very small amount such as \(0.38085\to0.38080\).

2. Binary search paths  
   Even though the problem allows fractional h, the integral constraint becomes trivial and exact for exact halves \(n=2s\), \(h_i\in\{0,1\}\), \(\sum h_i=s\). Binary sequences have the useful property that the count of bad pairs for each lag is integer, allowing exact incremental updates. A binary solution at a slightly larger even \(n\) can produce a final reported bound well under the current continuous record if it has low maximal bad-pair count. The smoother initial values constructed from the parent plus periodic/lawlike patterns then undergo simulated annealing with fast incremental updates.

This hybrid addresses the bottleneck that direct global optimization is unstable because the original objective is max of many quadratic forms and changes active lags. It does not require proving global optimality. Every candidate is scored by the original evaluator, and the best valid candidate is retained.

Important limitation: the method is heuristic. It does not attempt to certify a global optimum unless a fallback MILP is tried if time and solvers are available; even then, failure to certify must be treated as a feasible candidate only if its original score is accepted.

2. Mathematical specification

2.1 Discrete notation and exact objective  
Let \(n\) be the number of points and
\[
dx = 2/n,\qquad h=(h_0,\dots,h_{n-1}),\qquad \sum_{i=0}^{n-1}h_i = S = n/2.
\]
Define raw correlation
\[
R_l = \sum_{i,j: i-j=l} h_i(1-h_j), \qquad l=-(n-1),\dots,n-1.
\]
The returned evaluator objective equals
\[
\text{C5}(h)=dx\max_l R_l.
\]
The vector \(R\) is exactly `np.correlate(h, 1-h, mode="full")`; at output index `t = l + n - 1` the pair is `h_i(1-h_j)` with `i-j = l`.

This normalization preserves both negative and positive lag directions and finite-boundary truncation. Do not replace it by
\(1-\max\sum h_i h_{i+l}\)
without finite-support corrections, because the evaluator uses direct `h*(1-h(other))` over valid index intersections only.

2.2 Objective vector representation  
For efficiency, maintain a one-lag vector `counts` of length \(2n-1\), where `counts[t]` corresponds to lag \(l=t-(n-1)\). For `h\in[0,1]`,
\[
counts[t]=R_{t-(n-1)}.
\]
The raw objective is
\[
M(h)=\max_t counts[t],
\]
and
\[
C5(h)=dx\,M(h).
\]
Optimization may minimize either raw-count \(M\) or objective; use raw counts for all internal comparisons because \(dx\) is fixed per \(n\).

2.3 Joint feasibility projection for continuous vectors  
The exact constraint set is
\[
\mathcal C=\{x\in\mathbb R^n: 0\le x_i\le 1,\ \sum_i x_i=n/2\}.
\]
Clipping alone changes the sum. Project/scale alone can leave the box. The implementation must therefore use a Euclidean projection onto this box intersected with the hyperplane.

Projection algorithm `project_box(y, target=n/2)` operating on `y` as a NumPy array:

1. If `target<0` set `target=0`; if `target>n` set `target=n`.
2. Binary-search a scalar \(\lambda\) on function
\[
\phi(\lambda)=\sum_i \operatorname{clip}(y_i-\lambda,0,1).
\]
\(\phi\) is continuous, decreasing from \(n\) to \(0\). Search \(\lambda\) in \([\min(y)-1, \max(y)+1]\) using about 80 bisection iterations.
3. Set
\[
x_i=\operatorname{clip}(y_i-\lambda,0,1).
\]
4. Fix floating residual \(r=target-\sum_i x_i\):
   - If \(r>0\), add \(r\) by cycling through indices with slack \(1-x_i>0\), assigning to each min\(r,\text{remaining slack}\), until zero.
   - If \(r<0\), subtract \(r\) through indices with positive value \(x_i>0\), removing min\(|\text{remaining }r|,x_i\).
5. Return \(x\).

Accept if `abs(sum(x)-target) <= 1e-10*n` and `all(x>=-1e-12)` and `all(x<=1+1e-12)`; if not, perform a bounded repair by +/- clipping to `[0,1]` followed again by small slack adjustments and defer invalid candidates.

For discrete targets where exact integer sum is required, output integer vectors and maintain mass via counts. Final binary vector has exactly `S` ones by construction.

\[

\[
