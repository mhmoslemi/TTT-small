1. Approach and rationale

Central idea. Use exact two-coordinate exchange moves. For a fixed feasible vector `h`, choose two indices `i` and `j`, and consider the one-dimensional feasible segment obtained by increasing coordinate `i` by `t` and decreasing coordinate `j` by `t`, so that the total mass is preserved and both coordinates remain in `[0,1]`. On this segment the full nonlinear objective, including every lag not selected as active, is a convex function of `t` and can be minimized by a bounded one-dimensional descent on the true `np.correlate` objective. This gives a coordinate-exchange method that does not require smoothing the maximum, do not has to build an LP/QP relaxation, and never uses an accepted-but-infeasible surrogate. After each one-dimensional minimization, the pair is accepted by the original evaluator objective only.

Why this addresses the bottleneck. The objective is `max_m f_m(h)` where each `f_m` is a bilinear overlap count for a different lag. A full nonconvex global optimization is impossible within the budget, and smoothing or LP linearization can miss the non-selected active constraints that become limiting after a move. For the two-coordinate exchange segment, every overlap term is either linear in `t` or a convex quadratic in `t` with the same nonnegative quadratic coefficient, so their maximum remains convex. Consequently a golden-section search on the exact objective finds the true minimum along that entire feasible exchange direction, not just along an active linear model. Candidate coordinates are selected from the stored exact profile by directional first-order slopes of active lags, but candidate acceptance is determined by the actual full-line search using the same evaluator formula.

Coherent primary workflow. Keep the best vector globally as a valid, finite, feasible candidate. Run repeated pair-descent passes on the supplied length. Each pass uses active-gradient information only to order candidate pairs. Exact pair minimization proposes a concrete move; acceptance tests evaluate the exact objective and preserve feasibility. If pair descent stagnates, use: candidate reinitializations around the current best, bounded exchange perturbations, and transfer to other resolutions. Shorter valid vectors are investigated separately, and if their exact objective is lower, they become the returned bound. If no improvement is found, the supplied parent remains the valid fallback.

Limitations and claims. The method is a local pairwise coordinate descent plus randomized travel and multi-resolution search. It does not prove global optimality. The pair moves are exact in the chosen two-coordinate line but may miss optima requiring simultaneous changes of many variables. The exact profile gradient formulas are used only for selecting likely exchange directions. If the analytic gradient profile alignment fails, the pair minimization still uses the exact evaluator objective through random or broad candidate selection. The final returned `C5` is recomputed from the formal evaluator on the returned vector. No global optimum or guaranteed improvement is claimed.
