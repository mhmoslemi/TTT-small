1. Approach and rationale

The supplied and returned construction is a finite-dimensional nonconvex constrained minimax problem. The objective contains terms of the form h_i(1-h_j), so directly treating it with a convex solver is not valid. The proposed method therefore remains a heuristic, candidate-acceptance search, but uses objective functions and moves that are strongly informed by the exact evaluator.

The central algorithm is:

- Keep the starting `initial_h_values` construction, when present, and treat it as a validated local starting point rather than a hard-coded output.
- Maintain every proposed vector strictly in [0,1] with sum exactly n/2 using a bounded-hyperplane projection. At the return stage, replace the vector by a dyadic rational vector whose target sum is enforced by integer arithmetic, so that feasibility is controlled jointly rather than by clipping-after-rescaling.
- Use a smoothed max approximation, specifically a log-sum-exp surrogate of the exact overlap correlations, as a smooth majorant of the exact peak. Drive this surrogate with analytic first derivatives and SLSQP constrained to the bounded hyperplane. SLSQP supports smooth objective gradients, interval bounds, and linear equality constraints.
- Track the original unsimplified peak value, rather than the smoothed value, using exactly `np.correlate(h, 1-h, "full") * (2/n)`.
- Apply local random restarts, symmetry variations, and rescalings among nearby discretizations.
- Add an active-set first-order descent/quadratic-or linear feasibility-corrector phase. This phase is not solving the original nonconvex problem globally; it proposes balance-preserving first-order descent directions for lags whose exact peak values are near the active maximum, then accepts only those first-order exact score improvements. This helps improve fine tie-breaking among correlations after smooth maximization.
- Use bounded, deadline-aware phase transfers among resolutions, while retaining the best validated candidate at all times.

Why this can improve the supplied parent:

- The supplied parent already has score near the current record, so the path is a refinement of a highly qualified local basin, not a blind global search.
- A smoothed-max trace can move several near-maximize lags simultaneously and handles nondifferentiability of the exact max.
- The active-descent phase can rectify the known mismatch between a smoothed surrogate and the exact maximum, by explicitly concentrating on the lags that form the exact maximum after one or more continuous descents.
- Transferring nearby sample counts and rescaling can shift the discrete boundary terms and relieve limited-resolution codeword-format or donor constraints.

Limitations:

- No global optimality certificate is claimed.
- Success depends on finding enough local improvement around the supplied basin. The exact-constraint final projection could degrade a marginally below-threshold real-valued solution; this is mitigated by using a large dyadic denominator, 2^16, and by applying projection and occasional dyadic-aware local polish before documenting the final answer.
- The first-order active phase will terminate normally at local stationary points. If it finds no positive descent direction, the search uses other starts; it does not certify no improvement exists.

1. Approach and rationale

The task is to improve an upper bound for a small finite-dimensional nonconvex minimax problem. For a sample vector h of length n,

```
score(h) = max np.correlate(h, 1-h, mode="full") * (2/n)
```

with constraints `0 <= h_i <= 1` and `sum(h)=n/2`. The available `initial_h_values`, if present, is a high-quality n=45 parent. A fresh global search from scratch is unlikely to beat a tightly tuned parent, so the primary strategy is rigorous local and semilocal refinement. However, "local" alone is insufficient because a finite n discretization and a nonzero numerical margin need tie-breaking among several active correlations. The plan therefore combines four techniques while always verifying candidates on the supplied exact objective:

1. Feasibility-preserving distance projection onto `[0,1]^n` with exact sum `n/2`. Do not recover the constraint sum after clipping; use a genuine projection onto the bounded hyperplane before objective evaluation.
2. Smooth-max optimization. Replace the exact peak with a log-sum-exp surrogate of the exact finite-support overlaps and minimize it using SLSQP. This surrogate can move multiple near-maximal lag values simultaneously. Derivatives are analytic.
3. Random, symmetric, interpolation-based, and dimension-transfer starting points around the supplied parent. Acceptance is always by exact maximum of the rough or smooth result, not by the smoothed surrogate.
4. Active-lag refinement. Once several correlations are nearly tied at the maximum, compute first-order directions that balance nonmaximal rows and propose decreases of the currently maximal rows, following line searches checked against the true objective. Parallelize across a variety of top-lag sets, balance step sizes, and random lags.

This is a heuristic plan and does not make global optimality claims. It addresses the local_solution bottleneck caused by non-convex bilinear terms and exact max nondifferentiability by using feasible gradient smoothing and active first-order corrections. The implementation maintains a permanent last authoritative parent fallback and stores multiple screening solutions.
