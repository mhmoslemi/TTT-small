1. Approach and rationale

1.1 Central idea

The exact scoring function is small and cheap to evaluate at the dimensions
recommended for this task (tens to under a few hundred samples).  Instead of
claiming that a smooth or locally linearized surrogate is the true problem,
construct feasible candidate directions in the full discrete sequence and then
perform an exact scalar line search in that direction.

For any direction d that has zero discrete sum, the point

    h(α) = h + α d

has the required discrete mass exactly, provided that α is chosen at or inside
the interval for which every coordinate remains in [0, 1].  The full linear
correlation objective along that line is exactly a collection of quadratic
functions of α because linear correlation is bilinear:

    corr(h+αd, 1 - (h+αd))
      = corr(h, 1-h)
        + α corr(d, 1-h)
        - α corr(h, d)
        - α² corr(d, d),

with every correlation taken by the authoritative numpy call
`np.correlate(..., mode="full")`.  Multiplication by `dx = 2/n` turns this
vector into the vector whose maximum is the score.  Therefore, for each
constructed feasible direction d, one can evaluate the exact objective as an
implicitly known function of α without using an approximation.  Practical search
then consists of sampling many diverse feasible line directions, searching each
one by exact one-dimensional minimax evaluation, accepting only exact score
improvement, and maintaining a small population of several seeds and resolutions.

This is materially different from the earlier proposed families:
- It is not a generalized smoothed minimization of the objective.
- It is not a convex relaxation of the bilinear product.
- It does not restrict descent to single-pair coordinate transfers, because each
  proposed line direction may move many coordinates simultaneously while retaining
  the equality and box constraints exactly/acceptably after repair.
- It does not rely on a finite-support autocorrelation identity; it calls the
  authoritative correlation vector exactly as the evaluator does.

The method is fundamentally a family of exact one-dimensional minimax line
searches on non-axis well-organized feasible direction fields.  This is intended
to move along coordinated directions that can reduce several active correlation
lags at once, while avoiding the risks and complexity of global convex/global
nonconvex solvers.

1.2 Why this can improve beyond the supplied continuation

The supplied parent is assumed to be a locally good construction at its current
resolution.  Pairwise coordinate-transfer moves are often constrained by the
boundary terms of many active lags; a two-coordinate direction cannot always
escape such a box unless one wait controller.  If the current vector is locally
optimal under individual pair transfers, placing several carefully selected
transfers around the sequence coordinates and taking one scalar step may form
in an active envelope whose feasible reduction strictly exceeds what any one
point coordinate direction can do.  One then has an exact one-dimensional way of
testing those simultaneous changes.

Including several resolutions is also an independent reason for improvement:
the exact evaluator uses different grid spacing for each `n` in the general
`np.correlate(h, 1-h, mode='full')` task.  Transmitting and adapting a parent to
a nearby or coarser grid requires a precise projection operation; use the final
evaluator directly for every changed resolution.  Any better precision score at
a permitted smaller length is valid for the provided digital shell discretization.

1.3 Honest limits

- This is a search/line-polishing method.
- It provides feasible upper bounds for the specified evaluation model, not global
  optimality and not a stage-free continuity certificate.
- In the moment that the highest worst lag changes as a function of step length,
  the objective can have many local minima along the line.  The line search will
  provide a strong numerical minimization using nested grid sampling plus
  analytic candidates and local golden-section refinement.  This is robust but
  not claimed exact globally along an arbitrary long line.
- Equality preservation of sum and box constraints is strictly maintained with
  exact joint repair and validation before acceptance.
