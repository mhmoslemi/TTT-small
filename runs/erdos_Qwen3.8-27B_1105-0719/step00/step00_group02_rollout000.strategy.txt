1. Approach and rationale

1.1 Central algorithm

The proposed algorithm is exact-direction constrained descent. It repeatedly does the following:

1. Start from a feasible vector h in the discrete polytope K_n.
2. Construct a balanced velocity vector u with sum(u)=0.
3. Move from h along the ray h(t)=h+t u over the largest interval [t_min,t_max] that remains inside 0≤h(t)≤1.
4. Along this one-dimensional ray, the exact task objective is the maximum of 2n-1 univariate quadratic polynomials.
5. Find a near-global minimizer of this one-dimensional max-quadratic problem by evaluating all feasible interval endpoints, single-quadratic stationary points, and pairwise equality points of the lag polynomials.
6. Reconstruct h(t), perform a tiny exact feasibility repair only for floating-point drift, and evaluate the returned vector with the authoritative task objective. Accept and advance only if the exact task score improves, unless a controlled diversification phase intentionally accepts a non-best starting anchor; the global best vector is still never overwritten unless its exact score is strictly better.

This is different from previous plans in a substantive way:
- It does not smooth the max and then optimize the smoothed score.
- It does not use Frank–Wolfe vertices of the whole polytope as proposal points.
- It does not restrict updates to ordinary two-coordinate transfers as the main search engine; ordinary pair moves are one member of a much larger ray family, but the search also uses multi-coordinate, low-frequency, active-lag-derived, random balanced directions, and differences between elite feasible vectors.
- Every proposed direction is followed by an exact scalar solve of the original nonconvex objective restricted to that ray; only the original evaluator decides acceptance.

1.2 Why this addresses the problem

At a near-optimal vector, many discrete lags are nearly tied at the maximum. Improving one lag often raises another, so small smooth gradient steps, or single-coordinate pair moves, make tiny progress or stall. A scalar ray update changes many coordinates simultaneously while preserving feasibility exactly. Because the original objective along a balanced ray is available analytically as a maximum of quadratic polynomials, the best point on the ray can be found from the original task objective rather than from another surrogate. The direction generator then supplies diverse rays, including global quadratic structures and active-lag micro-structures.

The method cannot prove global optimality: the feasible set is convex, but the objective is nonconvex because each lag contains products h_i(1-h_j). There is no permitted convex QCQP or CVXPY formulation that exactly captures the original problem. The proposed mechanism only produces feasible vectors and verifies improvements with the exact discrete evaluator.

1.3 Facts and hypotheses

Justified facts:
- The scalar interpolation h+t u preserves sum(h) if sum(u)=0.
- Box feasibility for h+t u is a closed interval in t, computed exactly from current h and u.
- The full linear correlation and its complement product are bilinear, so coefficients along h+t u are exactly a quadratic in t for every lag.
- The exact returned bound is always computed after construction by np.correlate(h,1-h,mode="full")*(2/n), not from coefficient approximations.

Working hypotheses:
- A mixed direction pool can reduce the maximum of several active lags at once better than pair-only coordinate descent.
- Low-frequency sine, cosine, translation, and elite-difference rays can leave local basins of a parent vector.
- Pairwise stationary/equality candidates are sufficient for an effective, though numerical, global solve along each scalar ray.
- Controlled uphill/anchor restarts are needed if downloading to the global best stagnates at the parent score.

2. Mathematical specification

2.1 Exact discrete task

For a vector h of length n, define
- dx = 2.0 / n,
- mass = n / 2,
- one_minus_h = 1_h_minus h, where notation means vector 1 minus h.

The authoritative function to minimize is

    C(h) = dx * max_k corr(h, 1-h, full)[k].

Here k ranges over all 2n-1 full linear correlation values. Positive and negative lags and all boundary overlaps are included. Autocorrelation or circular convolution is not a valid replacement. Feasibility is:

    0 <= h_i <= 1 for all i,
    sum(h_i) = mass.

The mass is a float for odd n, for example n=47 gives mass=23.5. Do not force integer-only vectors.

2.2 Feasible directions

A direction u is suitable when sum(u)=0. Given current feasible h and u, the line is

    h(t) = h + t u.

The sum is preserved:

    sum(h(t)) = sum(h) + t sum(u) = mass.

The box constraints produce an admissible interval [t_low, t_high] as follows. For each coordinate:
- If |u_i| <= tiny_eps, no bound is contributed; only skip if h_i is nonfeasible.
- If u_i > 0, t must satisfy
      -h_i/u_i <= t <= (1-h_i)/u_i.
- If u_i < 0, t must satisfy
      (1-h_i)/u_i <= t <= -h_i/u_i.

Let t_low be the maximum of all implied lower bounds and t_high the minimum of all implied upper bounds. Because t=0 is feasible, any finite solution has t_low <= 0 <= t_high, though machine arithmetic may change this by tiny amounts. Clamp the interval to contain 0 and discard it if width is at most a numerical threshold.

No clipping after line evaluation is needed for mathematical correctness; in implementation, only a tiny repair is performed for floating-point residuals.

2.3 Exact quadratic lag polynomials along a line

Let g = 1-h. Define the raw full correlation arrays

    q0 = corr(h, g, full)
    q1 = corr(u, g, full) - corr(h, u, full)
    q2 = -corr(u, u, full).

Then, for any t before feasibility projection,

    corr(h+t u, 1-(h+t u), full) = q0 + t q1 + t^2 q2.

The ray score in raw units is

    F_raw(t) = max_a (q0[a] + q1[a] t + q2[a] t^2).

The actual objective on the ray is dx * F_raw(t). Since dx is a positive constant, minimizing F_raw over t is equivalent to minimizing C for that line. Final acceptance still uses the direct correlation formula on the reconstructed vector.

2.4 One-dimensional max-quadratic solve

For a fixed direction u and feasible interval [t_low,t_high], define L=2n-1 scalar functions

    f_a(t) = q0_a + q1_a t + q2_a t^2.

For the continuous piecewise function F_raw(t)=max_a f_a(t), a global minimizer over a compact interval can occur only at:
- an interval endpoint;
- a stationary point of one active smooth region, which is a single-quadratic derivative-zero point f'_a(t)=0;
- a nonsmooth point where at least two active functions are equal, which is a solution of f_a(t)=f_b(t).

Algorithmically candidate points:

1. Include t_low, t_high, and 0.
2. Include all t in the interval satisfying
       2 q2_a t + q1_a = 0
   when |q2_a| is not too small. Points from a negative q2_a are maxima of that quadratic but do no harm to include; the relevant global minimizer will still be among enumerated candidates or a better scalar fallback will cover numerical issues.
3. For every a<b, solve

       (q0_a-q0_b) + (q1_a-q1_b) t + (q2_a-q2_b) t^2 = 0.

   If the quadratic term is negligible, solve the linear equation if the linear term is nonzero. If the difference is almost identically zero, no isolated intersection needs adding. Include real roots inside the feasible interval with a small numerical residual.

The effective candidate set can be deduplicated using a grid fractional size proportional to (t_high-t_low)/(some multiple of interval length), then any duplicate root is dropped unless another root remains. To guard against numerical instability, also evaluate points with a small offset around each root:
    t - eps_ro, t, t + eps_ro,
where eps_ro is about 1e-10 times max(1, |t|, interval_width). This catches loss of exact equality from floating-point rounding.

For each candidate batch, raw scores are evaluated vectorized. If the number of candidate points is huge, process in chunks to avoid memory pressure, retaining the best t and all candidates within a small tolerance of the best when diversity is desired. Choose the best t by raw maximum polynomial score. Because root enumeration is in floating-point arithmetic, the final vector h(t_best) is always re-evaluated exactly using np.correlate, and exact score is compared to the exact score of the current state and global best.

If the quadratic factor count/validation is unreliable due to numerical conditioned coefficients, fall back to sampling:
- begin by 64-256 dense points over interval;
- include all single-quadratic stationary points;
- locate the best local bracket and refine it with a golden-section/shrink search; repeated random offsets may be used when non-convex local minima are known to exist. This fallback is used only when the algebraic enumeration fails or case time is too small.

2.5 Exact feasibility repair without invalid clipping/rescaling

Given approximate vector x and target mass:

1. Convert to a contiguous float64 vector.
2. If a minimum is less than a small tolerance, clip only tiny violations.
3. If max is greater than 1+small tolerance, lower by tiny overshoot.
4. Let residual r = mass - sum(x). If |r| is already below a machine sum tolerance, stop.
5. If r > 0, distribute only to slack capacities cap_i = max(0, 1-x_i). If total slack is positive, x := x + r * cap_i / sum(cap_i). If the resulting residual remains, iterate up to four times. If impossible, retain last feasible or previous valid parent.
6. If r < 0, distribute negative correction proportional to state affordance a_i = max(0, x_i). If impossible, reject candidate.
7. For numeric preservation, ensure final residual satisfies |mass-sum(x)| <= max(1e-10, 1e-12 * max(1,n)). Enlarge rejection if larger. The repair is never argued to equal after simple rescale because the field slack routing, positivity and upper bound may simultaneously cap lengths. Running to capacities does preserve constraints due the flow method. The interventions alter the score, so exact evaluation is used after repair.

The Euclidean projection auxiliary, used for random starts, is:

    x(λ) = clip(y - λ,0,1)
    Σx_i(λ) mass

Monotone binary search over λ gives a point close to K_n; afterwards apply the exact residual capacity repair. This gives exact joint feasibility.
