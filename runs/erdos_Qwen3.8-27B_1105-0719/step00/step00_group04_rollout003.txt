Actually, a simpler approach: for each pair (i,j), the feasible range of δ is:
- h[i] + δ ≥ 0 → δ ≥ -h[i]
- h[i] + δ ≤ 1 → δ ≤ 1 - h[i]
- h[j] - δ ≥ 0 → δ ≤ h[j]
- h[j] - δ ≤ 1 → δ ≥ h[j] - 1

So δ ∈ [max(-h[i], h[j]-1), min(1-h[i], h[j])]

Within this range, max_k F_k is convex in δ. We can find the minimum by:
- Evaluating at the endpoints and at all kink points
- A kink point occurs where F_k(δ) = F_l(δ) for some k, l
- F_k(δ) = A_k * δ + B_k (linear in δ)
- So F_k(δ) = F_l(δ) → (A_k - A_l) * δ = B_l - B_k → δ = (B_l - B_k) / (A_k - A_l)

This is exact but might be slow to enumerate all pairs of kinks. For a simpler approach, just evaluate at a grid of δ values.
