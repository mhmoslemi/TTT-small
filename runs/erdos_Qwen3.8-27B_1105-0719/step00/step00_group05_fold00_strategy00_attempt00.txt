1. Approach and rationale

The objective is finite, exact, and evaluated as
C_N(h)=max(np.correlate(h,1-h,mode=full)*dx), dx=2/N,
where N=n_points is also the number of returned samples. The continuous problem has the exact discrete constraints 0<=h_i<=1 and sum(h)=N/2. The goal is to search for a feasible vector whose C_N value is no larger than 0.3808 while keeping N within the stated “less than 2k” practical preference. The supplied parent has moderate size, so the algorithm should first improve that parent and then try a small set of neighboring resolutions rather than committing immediately to a huge grid.

The central method is a coherent local/global hybrid:

1. Preserve the true evaluator as the only acceptance criterion.
2. Optimize several smooth surrogates, most importantly a log-sum-exp smoothing of the exact correlation vector. The surrogate has exact gradient formulas on the same finite-shift representation as the evaluator and is minimized subject to the exact sum and bounds using SLSQP.
3. Use constrained direct min-max SLSQP solves with variables (h,z), obeying c_r(h)-z<=0 for all lags or active lags. These solves are nonconvex and therefore have no global optimality implication, but they can polish a parent to very small decreases.
4. Multistart around a best-known and locally improved vectors by tangent-space perturbations, dimension transfers, exact acceptance, and exact min-max restarts.
5. Use a small set of dimensions around the parent dimension so that runtime stays manageable while gaining a small amount of resolution.

The main bottleneck addressed is that the exact C_N maximum is nonsmooth and has many active lags near the optimum. A log-sum-exp surrogate makes a descent direction available, while the exact min-max formulation uses many local equality of highest correlations. Because this problem is bilinear, all final acceptances are computed by the authoritative evaluator only.

This is not a global proof of optimality. It is a rigorous local/global search pipeline with all proposed candidates checked against the exact objective and exact feasibility. A fallback to the valid parent or to an algorithmic cosine fallback is always available.

2. Mathematical specification

Let N be the runtime dimension and dx=2/N. A candidate is h in R^N satisfying sum_i h_i=N/2 and 0<=h_i<=1 for every i. Let target_values(h) be the exact evaluator array
E(h)=np.correlate(h,1-h,mode=full)*dx,
and exact_score(h)=max(E(h)). All acceptance uses exact_score.

Finite shift definition. A direct convention must be established and then calibrated against the evaluator. For shifts s=-(N-1),...,(N-1), define unscaled raw correlations Q_s:
If s>=0,
Q_s=sum_{i=0}^{N-s-1} h_i*(1-h_{i+s}).
If s<0,
Q_s=sum_{i=0}^{N-|s|-1} h_{i+|s|}*(1-h_i).
The direct array is indexed by r=s+N-1 (from row 0 for s=-(N-1) to row 2N-2 for s=N-1). Scale by dx. The exact evaluator itself is np.correlate(h,1-h,mode="full")*dx. For each dimension, compute a direct vector from a deterministic test array, compute np.correlate, and compare with np.allclose. If direct values allclose, use identity permutation. Else if reverse of direct values allclose, use row order reverse once fixed for all invariant correlations and gradients for that dimension. Otherwise, choose direct and enable numerical-gradient fallback for exact polynomial constraints; all smooth values must still be evaluated with exact_score before acceptance. This calibration makes constraints, gradients, and exact scoring mutually consistent at the first feasible attempt if possible.

Projection. The joint feasible set is a box [0,1]^N intersected with the hyperplane sum=A=N/2. Projection to a check basis is obtained by minimizing sum_i (x_i-y_i)^2 subject to L2 constraints. Because the region is a capped simplex, projection has the closed form
x(lambda)=clip(y-lambda,0,1),
where lambda is selected monotonically to produce sum(x)=A. Bisection over [-2,2] for about 70 iterations gives a high-quality projection. Afterward, let r=A-sum(x). For |r|>1e-12, add or subtract from vectors having slack and potentially slip: if residual is positive, add to an index with x_i<1; if it is negative, subtract from an index with x_i>1. Loop at most 30 times over bounded slack while |r|>tol. For finite dimensions and tol below machine precision residue, this produces strictness within 1e-13 and saves short equality error.

Smooth objective. For a smoothing temperature t>0, work with the calibrated exact correlation vector C(h) scaled with dx from the evaluator. Let raw score components be nonnegative for feasible h. Stable evaluation: M=max_r C_r, e_r=exp((C_r-M)/t), S=sum e_r, F_t=M+t*log(S). The exact gradient is
grad F_t(h)=sum_r w_r grad C_r(h),

Analytic gradient of each direct shift. For a scaled row C_s=dx*Q_s, write raw row derivatives before scaling. For s>0:
DQ_s/Dh_j =
  + (1-h_{j+s}) if 0<=j<N-s,
  - h_{j-s} if s<=j<N,
  otherwise 0.
Equivalent vectorized row fill:
row[0:N-s] += 1-h[0:N-s]
row[s:N]   -= h[0:N-s]

For s<0, with u=-s:
row[0:N-u] += 1-h[0:N-u]
row[u:N]   -= h[0:N-u]

For s=0, the two slices coincide and yield row[j]=(1-2h_j). Scaling by dx yields grad C_s. min z
