```python
        g[i_lo:i_hi] += wp * (1.0 - h[i_lo+p:i_hi+p])
        i_lo2 = max(0, p)
        i_hi2 = min(n, n + p)
        g[i_lo2:i_hi2] -= wp * h[i_lo2-p:i_hi2-p]
    return g * dx
```

This is O(n) per lag, O(n²) total, but with NumPy vectorized inner loops. Should be fast.

For n=47, there are 93 lags, each doing O(47) work → about 4400 vector operations total. Very fast.

```python
        R[p + n - 1] = dx * np.sum(h[i_lo:i_hi] * (1.0 - h[i_lo+p:i_hi+p]))
    return R
```
