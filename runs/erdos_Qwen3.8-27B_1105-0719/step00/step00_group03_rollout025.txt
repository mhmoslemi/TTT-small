For the active lag k*, I want to reduce S_{k*}. The most direct approach:
- If k* > 0: S_{k*} = dx * sum_{i=0}^{n-1-k*} h[i+k*] * (1-h[i])
  To reduce this, I want to either decrease h[i+k*] or increase h[i] (for the terms that matter most).

Wait, I need to be more careful. Let me define k* as the lag that maximizes S.

For k* > 0: The pairs are (i, i+k*) for i = 0 to n-1-k*.
S_{k*} = dx * sum_i h[i+k*] * (1-h[i])

To reduce S_{k*}, for a specific pair (i, i+k*):
- If h[i+k*] is high and h[i] is low, transferring from i+k* to i would help
  (decrease h[i+k*], increase h[i], which decreases h[i+k*]*(1-h[i]))
  
  Actually: new term = (h[i+k*]-δ)*(1-(h[i]+δ)) = (h[i+k*]-δ)*(1-h[i]-δ)
  = h[i+k*](1-h[i]) - δ(1-h[i]) - h[i+k*]δ + δ²
  Change = -δ(1-h[i]) - h[i+k*]δ + δ²
  = -δ(1-h[i] + h[i+k*]) + δ²
  = -δ(1 + h[i+k*] - h[i]) + δ²
  
  This is negative (reduces S) when δ < 1 + h[i+k*] - h[i], which is always true for small δ since 1+h[i+k*]-h[i] > 0.
  
  So yes, transferring from i+k* to i (for k*>0) always reduces S_{k*} for small δ!

- Similarly, for k* < 0 (k* = -d): S = dx * sum_i h[i] * (1-h[i+d])
  Transferring from i to i+d reduces S.

So the optimal direction for reducing the active lag is:
- k* > 0: transfer from higher index to lower index (within pairs k* apart)
- k* < 0: transfer from lower index to higher index (within pairs |k*| apart)

    n_old = len(h)

def gradient_step_move(h, scores, rng, num_trials=2):
    """Gradient-based move."""
    n = len(h)
    dx = 2.0 / n
    
    # Soft weights
    max_s = scores.max()
    beta = rng.uniform(5, 30)
    weights = np.exp(beta * (scores - max_s))
    total_w = weights.sum()
    if total_w < 1e-10:
        return None
    weights /= total_w
    
    # Compute gradient
    grad = np.zeros(n)
    for rng_idx in range(2 * n - 1):
        k = rng_idx - (n - 1)
        w = weights[rng_idx]
        if w < 1e-10:
            continue
        if k == 0:
            grad += w * dx * (1.0 - 2.0 * h)
        elif k > 0:
            # ∂S_k/∂h[i] = dx * [(1-h[i-k]) for i>=k] + dx * [-h[i+k] for i<n-k]
            grad[k:] += w * dx * (1.0 - h[:-k])
            grad[:n-k] += w * dx * (-h[k:])
        else:
            d = -k
            grad[:n-d] += w * dx * (1.0 - h[d:])
            grad[d:] += w * dx * (-h[:-d])
    
    max_g = np.max(np.abs(grad))
    if max_g < 1e-12:
        return None
    
    # Line search
    best_h = None
    best_c = float('inf')
    steps = [0.1, 0.5, 1.0, 2.0]
    for s in steps:
        step = s / max_g
        h_try = project_balanced(h - step * grad)
        scores_try, c_try = exact_scores(h_try)
        if c_try < best_c:
            best_c = c_try
            best_h = h_try
    
    return best_h

def random_perturb(h, rng, scale=0.05):
