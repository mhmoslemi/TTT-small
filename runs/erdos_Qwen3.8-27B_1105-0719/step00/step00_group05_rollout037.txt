correlate(a, v) computes: c_k = sum_n a_{n+k} * conj(v_n)

In "full" mode, k ranges from -(Nv-1) to Na-1.

For a = h (length n), v = 1-h (length n):

The output array is indexed from 0 to 2n-2, where:
output[0] corresponds to k = -(n-1)
output[n-1] corresponds to k = 0
output[2n-2] corresponds to k = n-1

So output[m] = c_{m-(n-1)}

For k ≥ 0 (m ≥ n-1):
c_k = sum_{n=0}^{n-1-k} h_{n+k} * (1-h_n)

For k < 0 (m < n-1), let k' = -k > 0:
c_{-k'} = sum_n h_{n-k'} * (1-h_n)
Valid n: n-k' ≥ 0 and n < n, so n = k', k'+1, ..., n-1
c_{-k'} = sum_{n=k'}^{n-1} h_{n-k'} * (1-h_n)
Let i = n - k':
= sum_{i=0}^{n-1-k'} h_i * (1-h_{i+k'})

So:
- For m ≥ n-1 (k = m - n + 1 ≥ 0): corr[m] = sum_{i=0}^{n-1-k} h_{i+k} * (1-h_i)
- For m < n-1 (k = m - n + 1 < 0, k' = n-1-m > 0): corr[m] = sum_{i=0}^{n-1-k'} h_i * (1-h_{i+k'})

Now for the gradient of corr[m] with respect to h_j:

Case 1: m ≥ n-1, k = m-n+1 ≥ 0
corr[m] = sum_{i=0}^{n-1-k} h_{i+k} * (1-h_i)

h_j appears in two ways:
(a) As h_{i+k} where i = j-k. Valid when 0 ≤ j-k ≤ n-1-k, i.e., k ≤ j ≤ n-1.
    Contribution: (1-h_{j-k})
(b) As h_i where i = j. Valid when 0 ≤ j ≤ n-1-k.
    Contribution: -h_{j+k}

So d(corr[m])/dh_j = (1-h_{j-k})*1[k≤j≤n-1] + (-h_{j+k})*1[0≤j≤n-1-k]

Case 2: m < n-1, k' = n-1-m > 0

h_j appears in:
(a) As h_i where i = j. Valid when 0 ≤ j ≤ n-1-k'.

(b) As h_{i+k'} where i = j-k'. Valid when 0 ≤ j-k' ≤ n-1-k', i.e., k' ≤ j ≤ n-1.
    Contribution: -h_{j-k'}

So d(corr[m])/dh_j = (1-h_{j+k'})*1[0≤j≤n-1-k'] + (-h_{j-k'})*1[k'≤j≤n-1]

```python
def _smo_grad(x):
    n = len(x)
    dx = 2.0 / n
    corr = np.correlate(x, 1.0 - x, mode="full")
    cmax = np.max(corr)
    ev = np.exp((corr - cmax) / _tau_g)
    w = ev / np.sum(ev)
    
    grad = np.zeros(n)
    for m in range(2 * n - 1):
        wm = w[m] * dx
        if wm < 1e-14:
            continue
        k = m - (n - 1)
        if k >= 0:
            # Case 1
            if k < n:
                # (a) j in [k, n-1]: contribution (1 - x[j-k])
                ja = np.arange(k, n)
                grad[ja] += wm * (1.0 - x[ja - k])
                # (b) j in [0, n-1-k]: contribution -x[j+k]
                jb = np.arange(0, n - k)
                grad[jb] += wm * (-x[jb + k])
        else:
            kk = -k  # = n-1-m
            # Case 2
            if kk < n:
                # (a) j in [0, n-1-kk]: contribution (1 - x[j+kk])
                ja = np.arange(0, n - kk)
                grad[ja] += wm * (1.0 - x[ja + kk])
                # (b) j in [kk, n-1]: contribution -x[j-kk]
                jb = np.arange(kk, n)
                grad[jb] += wm * (-x[jb - kk])
    return grad
```
