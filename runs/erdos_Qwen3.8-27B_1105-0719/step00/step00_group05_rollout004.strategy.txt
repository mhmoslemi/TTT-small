1. Approach and rationale

1.1 Central idea

The task is a finite-dimensional nonconvex minimax problem on
F_n = {h in R^n: 0 <= h_i <= 1, sum_i h_i = n/2},
with the authoritative objective
C_exact(h) = max_l np.correlate(h, 1 - h, mode="full")[l] * (2 / n).
No global optimality is claimed. The goal is to find a valid candidate whose exact measured C_exact is at or below the target 0.3808, while always keeping the returned vector feasible under both bound and sum constraints.

The proposed method is materially different from a generic clipping/projection or hand-crafted subgradient program. Its core mechanism is a smooth, explicitly feasible transformation from an unconstrained vector y in R^n to a vector h(y) in the feasible interior (0,1)^n with exact sum n/2. The map is
   h_i(y) = sigmoid(y_i + lambda(y)),
where sigmoid(t)=1/(1+exp(-t)) and lambda(y) is chosen uniquely by a one-dimensional monotone scalar equation
   sum_i sigmoid(y_i + lambda(y)) = n/2.
This removes the equality sum constraint and the [0,1] box constraint from the optimizer itself. The smooth surrogate objective
   F_beta(h) = (1/beta) log sum_r exp(beta v_r(h))
over all directional overlap values v_r is then minimized in the unconstrained coordinate y using a quasi-Newton BFGS routine with an analytically derived transformed gradient. Every returned/proposed candidate is measured with the original discrete evaluator and at least one decreasing exact metric is stored whenever it is seen. The core is therefore:
   analytic feasible parameterization + analytic smoothed-overlap gradient + unconstrained BFGS local search + exact pairwise coordinate-transfer polish + parent-preserving fallback.

1.2 Why it addresses the supplied parent problem

The supplied parent construction has C_exact about 0.38085, and the requested upper bound 0.3808 is only about 5e-5 lower. Such tiny improvements are typically found by entering nearby smooth basins and moving along low-curvature active-constraint directions rather than by large random global reboots. The logistic-body map places the parent interior (apart from clipping boundary values) inside a smooth feasible manifold, so a local quasi-Newton optimizer can exploit curvature/gradient structure without spending effort on bound and equality repair. At the same time, the numerical final vector may be a valid interior point and always contains values bounded by [0,1]. Boundary-extreme optima are approached by large finite y values; exact tiny numerical clip/feasibility correction can then be applied without destroying the objective improvement. Exact replicate evaluations are used for acceptance and reporting. No global optimality statement is made or implied.

1.3 Justified facts versus heuristics

Justified facts:
- The directional set represents every entry of the finite-support full correlation up to permutation.
- Logistic common-shift transformation maps all strict interior feasible points and transforms equality-constrained optimization into unconstrained optimization.
- Chain-rule gradient formula for the common-shift transformation is exact for the smoothed objective, so a smooth local search has correct search directions.
- Exact evaluator, parent storage, final projection, and constraint tolerance catches local-point or numerical pathologies.

Heuristics:
- log-sum-exp smoothing, beta choices, BFGS iterations, candidate pools, random perturbations, pairwise coordinate exchange moves are heuristics intended to improve the exact objective, not guaranteed optimality searches.
- Random restarts and pair moves can avoid some local basins, but no guarantee any candidate achieves the exact target.
- Resize/select dimensions are heuristic heuristics for smaller samples may assist optimization/evaluate evaluation.

1.4 Materially different difference from prior proposals

Prior attempts impose feasibility after arbitrary coordinate moves and hand-set projected smooth descent. Our approach instead transforms the feasible set itself to an unconstrained logistic manifold with exact initial sum and box constraints. It uses BFGS on transformed smooth objective to work directly in coordinate-space space and never takes unfeasibly recorded exact row as benefit. Exact evaluation and pair transfer as a separate polish; fallback to feasible hand-search remains for robustness. This centers the task on an explicit manifold parameterization and quasi-Newton search rather than only repeated post-projection or pure random search.
