1. Approach and rationale

1.1 Central idea

The problem is a discretized, nonsmooth, nonconvex minimax problem:

C(h) = max over full lags of [np.correlate(h, 1-h, mode="full") * dx],
dx = 2 / n,
with 0 <= h_i <= 1 and sum(h) = n/2.

The proposed primary engine is a sequence of strongly constrained linear programs that optimize one side of the current bilinear correlation pattern while holding the other side fixed. For a current feasible h, define the linearized two-sided correlation functional:

Phi_k(a, b) = dx * sum_i a_i * b_{i + lag_k},

where the lag slice is chosen exactly to match the finite-support boundaries of np.correlate. The actual problem has b = 1-h, but Phi is bilinear in (a,b). The method repeatedly solves convex LPs:

- primal expression: minimize over new a = h' the maximum Phi_k(h', b_current), where b_current = 1 - h_current;
- dual expression: minimize over new b' the maximum Phi_k(h_current, b'), then return h' = 1 - b'.

Both LP subproblems are supported directly by linear-programming solvers because, once one argument is fixed, every lag term is linear in the variable. The resulting vectors are not trusted because of interior value or tolerance alone; each is normalized to exact feasibility, blended with the current feasible vector by an exact line scan, and only accepted if the original evaluator improves. This differs substantially from smoothing-only or pair-coordinate-only plans: it asks a global full-dimensional LP to choose many coordinated changes as a candidate descent sheet, then verifies the actual discrete objective exactly.

1.2 Why this may improve the parent

The supplied parent is already on the near-optimal boundary of the current grid. The bottleneck is finding a very small exact reduction. Local one-coordinate moves are fragile because decreasing one near-critical lag can increase another boundary lag. Full-dimensional LP moves can change strongly correlated coordinates together while respecting sum and box constraints. Additionally, lowering the upper bound may require a resolution-transfer move: parent values on a different sampling grid can produce a different overlap vector and fall into a better basin.

The primary heuristics are:

- Fixed-complement primal LP descent/plugins increase the probability of moving away from the current complement at the most dangerous lags.
- Fixed-current complement dual LP descent/plugins directly generate candidate complements that reduce correlation with the current h.
- Exact full-lag accepted by the task metric can still produce large one-step changes like binary-like or low-overlap structures, even if the exact objective may worsen.
- Multi-dimension transfers to other lengths create diverse feasible starting points.
- A bottom-local exact-polish pass on selected pair coordinates gives robust final improvement on the pushed LP or transfer candidate.

Limitations:

- The exact objective is not convex. The LP subproblems are convex only because one complement is fixed.
- Nothing here guarantees local or global optimality, monotone objective decline, or global solution by the fixed-point conditions.
- All accepted improvements are exactly the supplied official evaluator from validated feasible vectors, so LP variable tolerances and solved abstract objectives never count alone.
- Multiple sampling sizes must be compared by their actual discrete C5 bound; no monotonic comparison is assumed. If one grid adheres to another bound / finer / has lower values, objective can either improve or get worse. Each dimension result lives together and has an exact score. For same consistent or tie variants, shorter saved `n` is selected if the score does not materially change.
