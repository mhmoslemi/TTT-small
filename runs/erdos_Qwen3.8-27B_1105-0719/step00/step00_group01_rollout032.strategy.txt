1. Approach and rationale

1.1 Central idea

The supplied parent is already extremely close to the desired bound, so the difficulty is not finding a crude construction; it is escaping a very small local basin around the parent and making a sequence of simultaneous, feasibility-preserving fractional changes that lowers several worst lag correlations at once. The proposed program attacks this with a staged “basin escape followed by fractional multi-lag repair” program:

- It keeps a validated parent fallback at all times and uses the exact task evaluator internally for every accepted entry.
- It creates diversified starting vectors in several admissible resolutions using exact resampling and the symmetries of the objective.
- It escapes poor continuous basins using a constrained binary/threshold basin-hopping stage. The binary stage is not the final construction; it is a cheap, high-structure search over one major near-binary family that is often successful in this problem and cheap to evaluate exactly.
- From good binary and parent-derived basins, it repeatedly performs exact, feasibility-preserving line searches in coordinate, block, and active-gradient directions. These searches use the true evaluator on the whole line; they minimize the original nonsmooth maximum along each chosen feasible affine segment rather than minimizing a soft maximum only.
- It finally uses a true epigraph nonlinear program only as a polishing/validation solver (with bounded time and explicit feasibility checks), not as the primary global method. This holds the actual all-lag inequalities and the exact integral equality.

This is materially different from the earlier plans: the primary search is not a single smooth-max projected-gradient path, not a single line-search-only engine, and not a single epigraph SLSQP attempt. The main engine is a constrained discrete-continuous search over basins, with exact line-path minimization and active-gradient/tangent descent as the fractional-moving core, followed by an exact epigraph polish.

1.2 Why it can improve the parent

The parent is likely near a local optimum of the finite-dimensional nonsmooth objective. Small decreases require a coordinated simultaneous reduction of multiple active lags. A direct binary pattern can reveal a different distribution of one and zero blocks, avoiding a local optimum of the parent. For odd resolutions, exact binary feasibility is impossible, but near-binary feasible constructions are produced by mixing a thresholded parent/binary basin with the parent or another feasible extract and preserving the target mass. Continuous line and block moves then use the exact evaluator to turn nearby structure into sub-Dx improvements (the last fractions of a basis mass), which a pure binary search cannot obtain.

The bottleneck is the combination of:

- exact partial-support correlations at all positive and negative lags;
- a nonsmooth maximum over many quadratic functions;
- integer-like degeneracy of binary nearby patterns when the mass is exactly half;
- a very small required improvement beyond the current parent.

The proposed method addresses the first by always scoring with the true full correlation/equal-lag expression. It addresses the second and third by using exact active-gradient/coordinate line search rather than a single smoothed objective, and by using discrete basin search to avoid overreliance on a local maximum. It addresses the fourth by allowing many small exact line improvements locally while always preserving the best globally valid candidate.
