1. Approach and rationale

Central idea. Treat the parent construction as a near-optimal discrete feasible point and perform direct local minimization of the finite-support overlap functional under the exact box and mean constraints. Because each lag contribution is a bilinear finite sum, we minimize a smooth log-sum-exp surrogate for the maximum at the fixed lag set, apply several smoothing temperatures, and accept or store only candidates after re-scoring with the authoritative evaluator. Use many deliberately perturbed starts around the parent and nearby resolutions. This attacks the 0.38085-to-0.38080 gap by refining and perturbing an already near-optimal sequence, while preserving the exact objective definition exactly.

Why this can help. The current parent starts from very close to the desired upper bound; a local method is attractive because all lag terms at the accepted optimum lie close together and smooth temperature can reduce the worst lag without damaging others. The exact feasible set is nonconvex because of h_i h_j products, so the algorithm does not seek a CVXPY global proof; it seeks several local stationary candidates and uses the exact evaluator for acceptance and storage.

Core representative strategy:
- Start from the expected parent array at n=45 when available.
- Run a trust-region constrained nonlinear program using analytic gradients of a log-sum-exp smoothing of the exact lag max, with exact bounds 0<=h_i<=1 and equality of the discrete sum to n/2.
- Use temperature schedules so the optimization gradually becomes more maximin-like.
- After each trust-constr attempt, protect feasibility through box-sum projection whenever needed and rescore using the exact correlation evaluator.
- Run additional starts from smoothed parent starts, binary-ish medianized starts, perturbed starts, and from transferred parent constructions at nearby resolutions.
