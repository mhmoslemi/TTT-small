1. Approach and rationale
1.1 Central idea
The proposed program is a parent-preserving, exact-metric local search whose decisive component is a linearized min–max subproblem for a subset of the correlation lags. At each parent or accepted iterate, the raw cross-correlation values and their first-order lag gradients are computed. A small trust-region-feasible linear program then proposes a direction that lowers the maximum of the linearized selected lags while preserving the sum constraint exactly at the first-order level and respecting the [0,1] bounds. Every proposed step is re-scored with the authoritative discrete evaluator and accepted only when its exact maximum strictly decreases. Exact pairwise mass transfers are then used to polish residual plateau conflicts, because pair transfers preserve the mass constraint independently of floating projection and often resolve small conflicts missed by smooth linearized steps. The approach is materially different from a log-sum-exp smoothing plus simulated-annealing plan: it replaces a surrogate-gradient search with a constrained linearized active-lag descent, while retaining the original objective as the only acceptance and reporting criterion.

This design targets the observed bottleneck. The supplied parent is already very close to the current record, so broad global search alone is inefficient. Improvement of order 10^-5 likely requires changing several entries simultaneously in a way that lowers multiple active lags at once. A generic gradient step on a soft max can be too diffuse, while independent coordinate moves cannot reduce multiple correlated active lags together. The LP subproblem chooses, within a trust ball, the best simultaneous first-order change for a selected bundle of active constraints. Because the original problem is bilinear and nonconvex, the linearized step is only a proposal; the exact evaluator happens after interpolating feasible step sizes and after exact feasibility projection. This prevents false progress from the nonconvexity of the model.

1.2 Why it could improve the parent
A local point may have isolated decrease-bonus pairs whose individual pair moves do not improve the max, yet a joint linearized direction that lowers all of the current top lags does. The LP step directly optimizes a finite active set, using first-order sensitivity rather than random neighbors. If it fails, exact pair transfers can capture any strict local improvement whose area is baixo-fine monotone with respect to the selected amount; this gives a full-constraint, exact-metric local descent layer. Constructing and testing certain nearest dimensions can move the problem to a nearby discrete grid that transfers the parent into a geometry with slightly better exact max. The program conservatively keeps the parent as a verified fallback, so it cannot lose against the supplied construction.

1.3 Honest limitations
The min–max function is nonconvex: each lag contains terms h_i(1-h_j)=-h_i h_j+h_i. The LP model is a first-order linearization with trust-region constraints, not a valid relaxation and not a convex optimizer of the original problem. It is not claimed globally optimal. If current gradients admit no good linearized direction or the omitted quadratic terms are too large, the proposed direction can fail exact scoring.
