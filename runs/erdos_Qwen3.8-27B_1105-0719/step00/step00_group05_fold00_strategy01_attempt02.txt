1.1 Central idea

The authoritative discrete problem is nonconvex because the evaluator objective is the maximum, over all finite-support correlation lags, of sums of bilinear terms h_i(1-h_j). The main strategy here is therefore not a smooth-max projection or a purely stochastic pair-transfer search. It is instead a trust-region Sequential Linear Programming method, abbreviated SLP, which each iteration does the following:

1. At the current feasible vector x, compute all exact directional lag-values, including the zero lag and both lag directions.
2. Build the exact first-order Lagrange linearization of every directional objective value with respect to all coordinates.
3. Solve a small linear program that minimizes the linearized maximum lag objective subject to the true box constraints, the true mean-sum constraint, and a small trust interval around the current point.
4. Take a conservative line step in the LP direction and evaluate every proposed point with the actual finite-support correlation objective.
5. Accept a candidate only after verifying feasibility and an actual improvement, with limited non-improving acceptance allowed only to escape premature trapping.

This is materially different because it optimizes a simultaneous linear model of the finite-support evaluator, including boundary terms and zero lag, in one constrained linear minimax calculation. It does not replace the objective by a smooth maximum and does not temporarily solve a heuristically weighted sum.
