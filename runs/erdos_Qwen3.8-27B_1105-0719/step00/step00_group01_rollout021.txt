So the total change in corr_k is:
Δ = t * [(1-h[i+k]) - h[i-k] - (1-h[j+k]) + h[j-k]]

where we define h[i+k]=0 if i+k is out of range, and h[i-k]=0 if i-k is out of range (similarly for j).

This is indeed linear in t. So f(t) = max_k {dx * (corr_k(0) + t * coeff_k)} is the max of linear functions, hence convex.

Great, so for each pair move, the objective is convex in t, and we can find the minimum efficiently.

For a convex piecewise-linear function, the minimum is where the subgradient contains 0, i.e., where the function stops decreasing and starts increasing. We can find this with:
1. Evaluate f at t_lo and t_hi
2. If f(t_lo) is decreasing (f'(t_lo) < 0) and f(t_hi) is decreasing (f'(t_hi) < 0), minimum at t_hi
3. If f(t_lo) is increasing and f(t_hi) is increasing, minimum at t_lo
4. Otherwise, the minimum is somewhere in between, at a breakpoint

For practical purposes, I'll use a combination of:
- Check endpoints
- Check t=0
- Use ternary/golden search for the interior minimum (works well for convex functions)

Actually, for piecewise linear convex functions, we can do better. The subgradient at any point is the set of slopes of the active linear pieces. The minimum is where 0 is in the subgradient. We can binary search on the slope:
- At a point t, the slope is the coefficient of the maximizing k
- If slope < 0, move right; if slope > 0, move left
- If slope = 0 (or changes sign), we're at the minimum

But this requires knowing which k is maximizing, which requires evaluating the max. Let me just use a practical approach:

1. Evaluate f at t=0, t_lo, t_hi, and a few interior points
2. If the best is interior, do a few bisections/ternary search steps
