```python
                g += (1.0 - h[jp])
            if 0 <= jm < n:
                g -= h[jm]
            row[j] = g
        G[k, :] = dx * row
    return G
```

Hmm, the O(M*n) = O(n²) loop is fine for n=70 (4900 iterations), but it'll be called many times in the NLP. Let me vectorize the inner part.

For a given lag:
- Row[j] = (1-h[j+lag]) * 1[0≤j+lag<n] - h[j-lag] * 1[0≤j-lag<n]

For lag >= 0:
- Term 1: j+lag < n ⟺ j < n-lag. So for j=0,...,n-lag-1: (1-h[j+lag])
  This is (1 - h[lag:n]) placed at positions [0:n-lag]
- Term 2: j-lag >= 0 ⟺ j >= lag. So for j=lag,...,n-1: -h[j-lag]
  This is -h[0:n-lag] placed at positions [lag:n]

For lag < 0 (let L = -lag > 0):
- Term 1: j+lag < n always (since j < n and lag < 0), and j+lag >= 0 ⟺ j >= L
  So for j=L,...,n-1: (1-h[j-L]) = (1-h[j+lag])
  This is (1 - h[0:n-L]) placed at positions [L:n]
- Term 2: j-lag >= 0 always (since j >= 0 and -lag > 0), and j-lag < n ⟺ j < n+lag = n-L
  So for j=0,...,n-L-1: -h[j+L] = -h[j-lag]
  This is -h[L:n] placed at positions [0:n-L]

3. Solve the NLP with only those K inequality constraints
4. Re-evaluate and update the active set
5. Repeat

    target = n / 2.0
