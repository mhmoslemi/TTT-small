**Pair coordinate descent:**

- This is a 1D problem: minimize the maximum of M quadratics over an interval.

This is exactly what the strategy described! And it's exact (the quadratics are exact, not approximations).

To solve "minimize max of quadratics over an interval":
1. Sample the interval densely to get a rough idea
2. Find the upper envelope of the quadratics
3. The minimum of the upper envelope occurs at either:
   - A vertex of one of the quadratics (where derivative = 0)
   - An intersection of two quadratics (where they're both on the envelope)
   - An endpoint of the interval

So the algorithm is:
1. Evaluate all quadratics at a set of candidate points (endpoints, vertices, intersections)
2. The answer is the candidate point with the lowest max value.

    """Try to improve h by changing h[i] and h[j] while preserving their sum."""
    n = len(h)
    S = h[i] + h[j]
    lo = max(0.0, S - 1.0)
    hi = min(1.0, S)
    if hi - lo < 1e-10:
        return h, False

    # P_k(x) = A_k x^2 + B_k x + C_k where x = h[i], h[j] = S - x
    dx = 2.0 / n
    w = 2 * n - 1  # number of lags
    
    # For each lag, compute the correlation term involving positions i and j
    # P_k = dx * sum_t h[t] * (1 - h[t-k]) (with appropriate bounds)
    # When we change h[i] from old to x and h[j] from old to S-x:
    # The change in P_k is:
    #   dx * [x*(1-h[i-k]) - h[i]*(1-h[i-k])]  (if t=i is in range for lag k)
    #   + dx * [h[j-k]*(1-x) - h[j-k]*(1-h[j])]  (if t=j-k is in range, i.e., the "1-h[i]" term)
    #   + ... similar for j
    #
    # Actually, it's easier to just compute the full profile at 3 points and fit quadratics.
    
    h_orig = h.copy()
    current_x = h[i]
    
    # Evaluate at 3 points
    pts = [lo, hi, (lo + hi) / 2.0]
    # If current_x is in [lo, hi] and different from the above, use it
    # Actually, let's use lo, hi, and mid
    
    profiles = []
    for x_val in pts:
        h[i] = x_val
        h[j] = S - x_val
        prof = np.correlate(h, 1.0 - h, mode='full') * dx
        profiles.append(prof)
    
    h[i] = current_x
    h[j] = S - current_x  # restore
    
    # Fit quadratics: P_k(x) = a_k x^2 + b_k x + c_k
    # [x^2, x, 1] * [a, b, c]^T = P_k
    A_mat = np.array([[p*p, p, 1.0] for p in pts])  # 3x3
    # P is w x 3 (each column is a profile)
    P_mat = np.stack(profiles, axis=1)  # w x 3
    # Solve A_mat.T * [a,b,c] = P_k for each k
    # Actually: for each k, P_mat[k,0:3] = A_mat @ [a_k, b_k, c_k]
    # So [a_k, b_k, c_k] = A_mat^{-1} @ P_mat[k, 0:3]
    A_inv = np.linalg.inv(A_mat)  # 3x3

    a_coeff = coeffs[0]  # w
    b_coeff = coeffs[1]  # w
    c_coeff = coeffs[2]  # w

    candidates = [lo, (lo+hi)/2.0, hi]

            xv = -b_coeff[k] / (2.0 * a_coeff[k])
            if lo < xv < hi:
                candidates.append(xv)
    
    # Current value
    candidates.append(current_x)
    
    # Intersections of active quadratics (near the max)
    # First, evaluate at current point to find active set
    P_current = np.array([a_coeff[k]*current_x**2 + b_coeff[k]*current_x + c_coeff[k] for k in range(w)])
    max_val = np.max(P_current)

                # da*x^2 + db*x + dc = 0

                    for sign in [1, -1]:

                if lo < xi < hi:
                    candidates.append(xi)

    best_x = current_x
    best_obj = exact_objective(h)
    
    for x_val in candidates:

        h[j] = S - x_val

    h[j] = S - best_x
    improved = best_x != current_x
    return h, improved

    n = len(h)
    dx = 2.0 / n
    S = h[i] + h[j]
    lo = max(0.0, S - 1.0)
    hi = min(1.0, S)
    if hi - lo < 1e-10:
        return h, False
    
    current_x = h[i]
    w = 2 * n - 1
    
    # For each lag k (indexed 0 to w-1, corresponding to actual lag k-(n-1)):
    # P_k(x) = a_k * x^2 + b_k * x + c_k
    # For most k: a_k = 0 (linear)
    # For k = n-1+(i-j) and k = n-1+(j-i): a_k may be nonzero
    
    # Compute coefficients by evaluation at 3 points (safe and simple)
    pts = np.array([lo, (lo+hi)/2.0, hi])
    profiles = []
    for xv in pts:
        h[i] = xv
        h[j] = S - xv
        prof = np.correlate(h, 1.0 - h, mode='full') * dx
        profiles.append(prof.copy())
    h[i] = current_x
    h[j] = S - current_x
    
    # Fit: for each lag k, P_k = a*x^2 + b*x + c
    # Using 3 points: [x^2, x, 1] @ [a,b,c]^T = P_k

    b_c = coeffs[1]  # = coeffs[1]
    c_c = coeffs[2]
