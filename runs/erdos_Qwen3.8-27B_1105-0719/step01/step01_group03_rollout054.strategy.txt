1. Approach and rationale
-------------------------

### 1.1 Central algorithmic idea

The proposed search does **not** use SLSQP/Frank-Wolfe/log-sum-exp as the main engine. Its primary engine is a **targeted violation Newton/least-squares descent** procedure:

- Treat a numerical bound `t` as a hypothesis to be attained.
- At a feasible candidate `h`, define the target violation
  \[
    V_t(h)=\sum_m \left(\max(0, C_m(h)-t)\right)^2,
  \]
  where `C_m(h)` are the exact profile entries.
- If `V_t(h)=0`, then the exact evaluator score is `≤ t`.
- Otherwise, construct a linearized least-squares model of the **active positive residuals** `C_m(h)-t` and move only in directions that reduce this smooth violation measure.
- Each proposed move is repaired jointly to satisfy `0 ≤ h_i ≤ 1` and `sum h_i = n/2`, and is accepted only after exact profile recomputation. No smooth surrogate value ever determines acceptance except `V_t`, but the globally retained bound is always an exact `C_5` value.

This is materially different from:

- Direct minimization of a smooth surrogate such as log-sum-exp, which optimizes a smoothed approximation to `max_m C_m`.
- Generic epigraph `minimize t` inner solvers, which merely solve a nonconvex nonlinear program with constraints `t ≥ C_m(h)`.
- Simple SLSQP/perturbation revisits around the parent.
- Frank-Wolfe/vertex motion, which uses linear indicators rather than an active least-squares correction system.

The practical goal is to make a narrow target-improvaller from the supplied parent while also producing structurally different feasible seeds using quantized binary patterns and fast pairwise exchange local search. This combination targets the 0.0002 gap between the previous `0.381010` construction and the target `0.3808`, while every output remains evaluated using the exact objective.

### 1.2 Why this can help

The current local optimum is very close to the target. SLSQP solution paths may stop quickly once the smoothed direction becomes locally unhelpful, especially if only one or two starting points are used. Targeted violation descent makes progress by explicitly solving the linearized system of residual constraints. At each iteration it asks: *how can I make the hardest explicit overlaps fall below the target, while retaining the exact mass?* This can find small feasible trade-offs among many constraints more deliberately than a general epigraph inner solve.

The search starts from many feasible candidates:

- The supplied parent.
- Symmetrized and cyclically shifted parents.
- Several quantized/rank-threshold feasible step functions derived from the parent.
- Locally improved balanced binary exchange points. These are not claimed to be globally binary-optimal; they simply produce structurally different starting points for continuous NTV polishing.
- Deterministic sinusoidal/block children if the parent is unavailable.
- NTV-polished candidates transferred to other resolutions.

The primary improvement path for the supplied parent is therefore:
```
parents / quantized variants / local exchange starts
       -> exact candidate pool
       -> targeted violation Newton least-squares polishing
       -> optional resolution transfer and light exact polish
       -> exact best accepted candidate returned
```

Limitations and heuristics:

- The problem is bilinear and nonconvex. Neither exact solver nor NTV produces a proof of global optimality.
- The least-squares model is local. If the trust-region step overshoots, exact evaluation repair determines whether the proposed point is retained.
- The target descent loop aims below previous exact minima. It cannot always reach a specified target because a local minimum of the violation may still have positive violating residual.
- The final bound is therefore only: `there exists at least one feasible vector with exact score equal to the reported bound`. It is not a proof that no better vector exists.

### 2.1 Exact discrete representation

For a candidate vector `h=[h_0,...,h_{n-1}]`, define:

\[
dx=\frac{2}{n},\qquad T=\frac{n}{2}.
\]

Feasibility is exactly:

\[
0\le h_i\le 1\quad\forall i,
\]
\[
\sum_{i=0}^{n-1}h_i = T.
\]

The authoritative overlap profile is:

\[
p(h)=dx\,\texttt{np.correlate}(h,1-h,\texttt{mode='full'}).
\]

Its length is:

\[
M=2n-1.
\]

The exact objective:

\[
C_5(h)=\max_{m=0}^{2n-2} p_m(h).
\]

No circular correlation must be used. No autocorrelation substitution may be used without matching this exact finite-boundary formula. All candidate acceptance uses exactly `np.max(np.correlate(h,1-h,mode="full")*dx)`.

### 2.2 Exact profile they indexing and row formula

Let output index `m ∈ {0,...,2n-2}`. Define a signed finite lag

\[
s = m-(n-1).
\]

All rows below must be ordered consistently with `s=m-(n-1)` and the `np.correlate` convention. The used row formulas are:

- For `s = 0` (`m = n-1`)
  \[
  p_{n-1}=dx\sum_{i=0}^{n-1}h_i(1-h_i).
  \]

- For `s=d>0` (`m=n-1+d`), the overlap convention is
  \[
  p_{n-1+d}=dx\sum_{i=0}^{n-d-1} h_{i+d}(1-h_i).
  \]
  This is the pair type `1` at the later position and `0` at the earlier position.

- For `s=-d<0` (`m=n-1-d`), the overlap convention is
  \[
  p_{n-1-d}=dx\sum_{i=0}^{n-d-1} h_i(1-h_{i+d}).
  \]
  This is the pair type `1` at the earlier position and `0` at the later position.

The objective takes the maximum over all `m`, including both signed direction families and the centering lag. Direction swapping at the implementation level only changes which row gets which gradient/score; to avoid mistakes, include the one-time validation described in Section 6.3.

### 2.3 Analytic gradient used by NTV

Define `G` as the Jacobian rows of the exact profile rows. Every row is scaled by `dx`. The row positive-shift gradient, for `d=1,...,n-1`, in m-index `m=n-1+d`:

\[
\frac{\partial p_m}{\partial h_j}=
\begin{cases}
dx(1-h_j), & j\in[d,n-1],\quad \text{with the paired earlier index }j-d,\\
? 
\end{cases}
\]

More concretely, implement with vector segment additions:

- For `s = 0`:
\[
G_{n-1,j}=dx(1-2h_j),\quad j=0,...,n-1.
\]

- For positive `s=d>0`, row `m=n-1+d`:
  \[
  p_m=dx\sum_{i=0}^{n-d-1}h_{i+d}(1-h_i).
  \]
  derivative:
  \[
  G_m[d:n] += dx(1-h[0:n-d])
  \]
  \[
  G_m[0:n-d] += -dx\;h[d:n]
  \]

- For negative `s=-d<0`, row `m=n-1-d`:
  \[
  p_m=dx\sum_{i=0}^{n-d-1}h_i(1-h_{i+d})
  \]
  derivative:
  \[
  G_m[0:n-d] += dx(1-h[d:n])
  \]
  \[
  G_m[d:n] += -dx\;h[0:n-d]
  \]

These formula slices are required for active residual least-squares step without recomputing gradients by finite differences. If G matrix has NaNs due zero-size slice logic, reinitialize independent coefficients and use `np.add.at` form or paired loop formulation. A root gradient sanity check is required for acceptance of NTV if row offset is wrong.

### 2.4 Target-violation model and least-squares direction

Fix a target bound `t`, with `t < C_5(h_current)`. Define:

\[
u_m(h)=p_m(h)-t
\]

and violation only on hard active positive residuals:

\[
V_t(h)=\sum_{m:u_m>0}\wpalpha^2(\max(u_m,\spill{t}))u_m^2,
\]

\[
