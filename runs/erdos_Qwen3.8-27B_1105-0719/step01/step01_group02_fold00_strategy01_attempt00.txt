1.1 Central idea

The evaluator’s exact objective is

    C(h) = max(np.correlate(h, 1-h, mode="full") * dx),   dx = 2 / n,

over feasible vectors h in R^n satisfying 0 <= h[i] <= 1 and sum(h) = n/2. The supplied parent is already near the current record, so the bottleneck is not broadly restarting a low-dimensional surrogate, but rather making very small, exact-objective-respecting descent moves in the highly active parts of the profile. Many locally optimized profiles are blocked because:

- premultiplying the whole max by a log-sum-exp surrogate usually creates slow, nearly flat moves;
- penalized equality vs. feasibility projection can repeatedly undo nonmax profile reductions;
- many algorithms hop between boundary shapes, while the tiny remaining margin is controlled by a handful of active lags and a few coordinates;
- discrete coarser/fine discretizations can have separate local minima, and useful continuations between them need feasibility-preserving maps.

The proposed primary algorithm is therefore a feasible-space nonsmooth exact-line minimization method:

1. Keep the candidate exactly feasible throughout.
2. At feasible h, compute the exact profile and the exact current C value.
3. Use a smooth LSE gradient only to generate a candidate descent direction through currently active lags, not as the final objective.
4. Test a line of projected and unprojected candidates with the true objective, and accept only if the true score decreases, or if a small temporary uphill move opens a later local descent basin.
5. 6. Use thresholded binary snapshots and a small binary random restart pool to leave continuous local traps that imply finite Setembro-gradient changes cannot cross the objective.
7. Repeat across several neighboring sequence lengths, with dimension transfer and exact re-scoring. Always carry the best infeasible-proof fallback. If time is too low, do a final validation and return the best validated h.

This plan is materially different from previous strategies because it makes true exact one-dimensional line search and pairwise mass transfer the principal local operator not a secondary heuristic.
