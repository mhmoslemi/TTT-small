Key observations:
1. The problem is to minimize the maximum overlap integral over all shifts k
2. The previous program uses SLSQP with epigraph formulation, local gradient descent, and multi-start perturbations
3. The strategy suggests using log-sum-exp smooth surrogate for the max, which is a good idea

Let me think about what could improve things:

1. **Log-sum-exp smoothing**: Instead of directly optimizing the max (which is non-smooth), use a smooth approximation: `LSE(profile, temperature) ≈ max(profile)` as temperature → 0. This gives a smooth objective that can be optimized more effectively.

2. **Better gradient computation**: The gradient of the LSE is the softmax-weighted sum of individual lag gradients, which naturally balances all lags.

3. **CVXPY approach**: The problem can be formulated more cleanly. Actually, the overlap integral `p_k = dx * sum_i h[i] * (1-h[i+k])` is non-convex in h (it's bilinear), so CVXPY won't directly work.

4. **Alternative approach**: 
   - Use the fact that `p_k = dx * sum h[i](1-h[i+k])` 
   - This is equivalent to `dx * (sum h[i] - sum h[i]*h[i+k])` over the valid range
   - So minimizing max_k p_k is equivalent to maximizing min_k sum h[i]*h[i+k] (the autocorrelation)
   - The autocorrelation approach might be more amenable to certain optimizations

5. **Better local search**: 
   - Coordinate descent on individual h values
   - Subspace optimization (optimize subsets of coordinates)
   - Simulated annealing or other stochastic methods

**Approach**: 
1. Start from the parent construction
2. Use log-sum-exp smoothed objective with adaptive temperature
3. Use SLSQP with the smooth objective (much better conditioned than the epigraph)
4. Use coordinate descent as a polishing step
5. Use diverse restarts with different structures

The key insight is that the log-sum-exp `f_t(h) = (1/t) * log(sum_k exp(t * p_k))` is:
- Smooth (differentiable) for t > 0
- Converges to max_k p_k as t → ∞
- Its gradient is `(sum_k p'_k * exp(t*p_k)) / (sum_k exp(t*p_k))` which is a convex combination of lag gradients

This means we can use SLSQP directly on this smooth objective without the epigraph variable, and the gradients naturally handle the active set.

Let me also think about the structure of optimal solutions. For the Erdős problem, the optimal h tends to be:
- Mostly 1 in some regions, mostly 0 in others
- With smooth transitions
- The transitions are what determine the overlap

For n=140, dx = 2/140 ≈ 0.0143, so the total integral is 1.

import numpy as np
import time
from scipy.optimize import minimize

def exact_score(h):
    dx = 2.0 / len(h)
    return float(np.max(np.correlate(h, 1.0 - h, mode="full") * dx))

def get_profile(h):
    dx = 2.0 / len(h)
    return np.correlate(h, 1.0 - h, mode="full") * dx

def repair_feasible(h, target=None):
    h = np.array(h, dtype=np.float64).copy()
    h = np.nan_to_num(h, nan=0.5, posinf=1.0, neginf=0.0)
    h = np.clip(h, 0.0, 1.0)
    n = len(h)
    if target is None:
        target = n / 2.0
    diff = target - h.sum()
    if abs(diff) < 1e-14:
        return h
    if diff > 0:
        room = 1.0 - h
        order = np.argsort(-room)
        remaining = diff
        for idx in order:
            if remaining <= 1e-15:
                break
            add = min(remaining, room[idx])
            h[idx] += add
            remaining -= add
    else:
        order = np.argsort(-h)
        remaining = -diff
        for idx in order:
            if remaining <= 1e-15:
                break
            rem = min(remaining, h[idx])
            h[idx] -= rem
            remaining -= rem
    return h

def lse_objective(h, t):
    """Log-sum-exp smooth approximation of max(profile)."""
    prof = get_profile(h)
    # Shift for numerical stability
    max_p = np.max(prof)
    if t <= 0:
        return max_p
    # LSE = max_p + (1/t) * log(sum(exp(t*(p - max_p))))
    shifted = t * (prof - max_p)
    # Clip for numerical stability
    shifted = np.clip(shifted, -50, 0)
    return max_p + np.log(np.sum(np.exp(shifted))) / t

def lse_gradient(h, t):
    """Gradient of LSE w.r.t. h."""
    prof = get_profile(h)
    n = len(h)
    dx = 2.0 / n
    max_p = np.max(prof)
    shifted = t * (prof - max_p)
    shifted = np.clip(shifted, -50, 0)
    weights = np.exp(shifted)
    weights /= np.sum(weights)
    
    # Gradient of p_k w.r.t. h
    # p_k = dx * sum_i h[i] * (1-h[i+k]) for valid i
    # dp_k/dh[j] = dx * sum over valid pairs (i,j) where j=i or j=i+k
    # For lag delta (correlate index k = n-1+delta):
    #   if delta >= 0: p = dx * sum_{i=delta}^{n-1} h[i]*(1-h[i-delta])
    #     dp/dh[j] = dx * (1-h[j-delta]) for j in [delta, n-1] (from first factor)
    #               + dx * (-h[j+delta]) for j in [0, n-1-delta] (from second factor)
    #   if delta < 0, d = -delta: p = dx * sum_{i=0}^{n-1-d} h[i]*(1-h[i+d])
    #     dp/dh[j] = dx * (1-h[j+d]) for j in [0, n-1-d] (from first factor)
    #               + dx * (-h[j-d]) for j in [d, n-1] (from second factor)
    
    M = 2 * n - 1
    grad = np.zeros(n)
    
    for k in range(M):
        delta = k - (n - 1)
        w = weights[k]
        if w < 1e-10:
            continue
        if delta >= 0:
            if delta < n:
                # First factor: h[i] where i goes from delta to n-1
                # dh[j] appears as h[j] in first factor when j >= delta
                # and as h[j] in (1-h[j-delta]) when j-delta >= 0, i.e., j >= delta... wait
                # p = dx * sum_{i=delta}^{n-1} h[i]*(1-h[i-delta])
                # dp/dh[j] = dx * (1-h[j-delta]) [j appears as h[i] with i=j, valid if j>=delta and j<n]
                #           + dx * sum_{i: i-delta=j} (-h[i]) [j appears in (1-h[i-delta]), so i = j+delta, valid if 0<=i-delta<=n-1-delta, i.e., 0<=j<=n-1-delta]
                #           = -dx * h[j+delta] (valid if j+delta < n, i.e., j < n-delta)
                if delta == 0:
                    # p = dx * sum h[i]*(1-h[i])
                    grad += w * dx * (1 - 2*h)
                else:
                    # j in [delta, n-1]: contributes dx*(1-h[j-delta])
                    grad[delta:n] += w * dx * (1 - h[0:n-delta])
                    # j in [0, n-1-delta]: contributes -dx*h[j+delta]
                    grad[0:n-delta] += w * dx * (-h[delta:n])
        else:
            d = -delta
            if d < n:
                # p = dx * sum_{i=0}^{n-1-d} h[i]*(1-h[i+d])
                # dp/dh[j] = dx*(1-h[j+d]) for j in [0, n-1-d]
                #           + -dx*h[j-d] for j in [d, n-1]
                if d == 0:
                    grad += w * dx * (1 - 2*h)
                else:
                    grad[0:n-d] += w * dx * (1 - h[d:n])
                    grad[d:n] += w * dx * (-h[0:n-d])
    
    return grad

def solve_lse(h_start, t, maxiter=100):
    """Solve using LSE smooth objective with SLSQP."""
    n = len(h_start)
    
    def obj(x):
        return lse_objective(x, t)
    
    def jac(x):
        return lse_gradient(x, t)
    
    def cons_eq(x):
        return x.sum() - n / 2.0
    
    def cons_jac_eq(x):
        return np.ones(n)
    
    bounds = [(0.0, 1.0)] * n
    
    try:
        result = minimize(
            obj, h_start, jac=jac,
            method='SLSQP',
            bounds=bounds,
            constraints=[{'type': 'eq', 'fun': cons_eq, 'jac': cons_jac_eq}],
            options={'maxiter': maxiter, 'ftol': 1e-12}
        )
        if result.x is not None and np.all(np.isfinite(result.x)):
            return repair_feasible(result.x)
    except Exception:
        pass
    return None

def coordinate_descent(h, max_iters=200, time_limit=20):
    """Coordinate descent: for each coordinate, find optimal value given others fixed."""
    n = len(h)
    h = h.copy()
    best_score = exact_score(h)
    best_h = h.copy()
    t0 = time.perf_counter()
    
    for it in range(max_iters):
        if time.perf_counter() - t0 > time_limit:
            break
        
        improved = False
        # Random order of coordinates
        order = np.random.permutation(n)
        
        for j in order:
            if time.perf_counter() - t0 > time_limit:
                break
            
            # Fix all coordinates except j, find best h[j]
            # The objective is piecewise linear in h[j] (since p_k is linear in h[j] for fixed others)
            # Actually p_k = dx * sum h[i](1-h[i+k]), which is linear in h[j] for each k
            # So the max of linear functions is convex in h[j]
            # The optimal h[j] is at a vertex: 0, 1, or where two p_k's are equal
            
            # For efficiency, just try a few values
            old_val = h[j]
            h[j] = 0.0
            s0 = exact_score(h)
            
            h[j] = 1.0
            s1 = exact_score(h)
            
            if s0 < best_score - 1e-12:
                best_score = s0
                best_h = h.copy()
                improved = True
                h[j] = 0.0
                continue
            
            if s1 < best_score - 1e-12:
                best_score = s1
                best_h = h.copy()
                improved = True
                h[j] = 1.0
                continue
            
            # Try intermediate values (the optimal is where active constraints cross)
            # Try the old value and a few nearby
            h[j] = old_val
            # Try to find where the max profile changes
            prof_at_old = get_profile(h)
            max_k = np.argmax(prof_at_old)
            
            # Binary search for optimal h[j] in [0, 1]
            lo, hi = 0.0, 1.0
            for _ in range(8):
                mid = (lo + hi) / 2
                h[j] = mid
                s_mid = exact_score(h)
                h[j] = mid + 0.1
                if mid + 0.1 <= 1.0:
                    s_right = exact_score(h)
                else:
                    s_right = s_mid
                h[j] = mid - 0.1
                if mid - 0.1 >= 0.0:
                    s_left = exact_score(h)
                else:
                    s_left = s_mid
                
                if s_right > s_left:
                    hi = mid
                else:
                    lo = mid
                h[j] = old_val
            
            h[j] = (lo + hi) / 2
            s_new = exact_score(h)
            if s_new < best_score - 1e-12:
                best_score = s_new
                best_h = h.copy()
                improved = True
            else:
                h[j] = old_val
        
        if not improved:
            break
    
    return best_h, best_score

def symmetrize(h):
    h_sym = 0.5 * (h + h[::-1].copy())
    return repair_feasible(h_sym)

def interpolate_to_dim(vec, new_len):
    n = len(vec)
    x_src = (np.arange(n) + 0.5) * 2.0 / n
    x_tgt = (np.arange(new_len) + 0.5) * 2.0 / new_len
    x_ext = np.concatenate([[0.0], x_src, [2.0]])
    f_ext = np.concatenate([[vec[0]], vec, [vec[-1]]])
    h_new = np.interp(x_tgt, x_ext, f_ext)
    h_new = np.clip(h_new, 0.0, 1.0)
    return repair_feasible(h_new)

def get_lag_gradients(h):
    """Compute gradient rows for each lag."""
    n = len(h)
    dx = 2.0 / n
    M = 2 * n - 1
    G = np.zeros((M, n))
    for k in range(M):
        delta = k - (n - 1)
        if delta >= 0:
            if delta < n:
                if delta == 0:
                    G[k, :] = dx * (1.0 - 2.0 * h)
                else:
                    G[k, delta:n] += dx * (1.0 - h[0:n - delta])
                    G[k, 0:n - delta] -= dx * h[delta:n]
        else:
            d = -delta
            if d < n:
                if d == 0:
                    G[k, :] = dx * (1.0 - 2.0 * h)
                else:
                    G[k, 0:n - d] += dx * (1.0 - h[d:n])
                    G[k, d:n] -= dx * h[0:n - d]
    return G

def softmax_descent(h, max_iters=100, time_limit=30):
    """Descent using softmax-weighted gradient of the profile."""
    n = len(h)
    h = h.copy()
    best_h = h.copy()
    best_score = exact_score(h)
    t0 = time.perf_counter()
    
    for it in range(max_iters):
        if time.perf_counter() - t0 > time_limit:
            break
        
        prof = get_profile(h)
        score = float(np.max(prof))
        if score < best_score - 1e-12:
            best_score = score
            best_h = h.copy()
        
        # Softmax weights with adaptive temperature
        # Higher temperature = more uniform, lower = more peaked
        temp = max(0.01, 0.1 - 0.001 * it)
        shifted = (prof - np.max(prof)) / temp
        weights = np.exp(np.clip(shifted, -50, 0))
        weights /= weights.sum()
        
        G = get_lag_gradients(h)
        direction = weights @ G  # weighted sum of gradient rows
        direction -= direction.mean()  # maintain sum constraint
        
        norm = np.linalg.norm(direction)
        if norm < 1e-14:
            break
        direction /= norm
        
        improved = False
        for alpha in [0.05, 0.025, 0.01, 0.005, 0.002, 0.001, 0.0005]:
            h_trial = repair_feasible(h - alpha * direction)
            s_trial = exact_score(h_trial)
            if s_trial < best_score - 1e-11:
                h = h_trial
                best_h = h.copy()
                best_score = s_trial
                improved = True
                break
        
        if not improved:
            # Try smaller steps or break
            break
    
    return best_h, best_score

def subspace_optimize(h, time_limit=15):

    n = len(h)
    h = h.copy()
    best_h = h.copy()
    best_score = exact_score(h)

            if time.perf_counter() - t0 > time_limit:
                break
            
            start = b * block_size
            end = start + block_size
            old_vals = h[start:end].copy()

                if time.perf_counter() - t0 > time_limit:

                delta = np.random.randn(block_size) * 0.05

                    improved = True

        if not improved:

Actually, for coordinate descent, I can be smarter. The objective `max_k p_k` where each `p_k` is linear in `h[j]` (for fixed other coordinates) is a convex piecewise-linear function of `h[j]`. So the minimum is at a breakpoint or at the boundary {0, 1}.

The breakpoints occur where two profile values are equal. For a given coordinate j, the profile values as a function of `h[j] = x` are:
- For lag delta >= 0, j in range: `p_{delta}(x) = a_delta + b_delta * x`
- The breakpoints are where `a_delta + b_delta * x = a_delta' + b_delta' * x` for different pairs of lags.

But computing all breakpoints is expensive. A simpler approach: just try x = 0, x = 1, and the old value, plus maybe the value that equalizes the top two active lags.

**Key insight**: The Lagrangian of the problem (ignoring bound constraints for a moment) is:
L = t + λ(sum(h) - n/2)
subject to t >= p_k(h) for all k

At the optimum, the active lags (where t = p_k) determine the KKT conditions. The gradient condition for non-bound variables is:
λ = sum_k μ_k * (dp_k/dh_j) for each free j

This is exactly what the softmax/LSE approach approximates.

1. Use a warm-start temperature schedule (start high, decrease)
2. After each LSE solve, do a few rounds of softmax descent
3. Use adaptive step size in the descent

def repair_feasible(h, target=None):

def get_lag_gradients(h):
