def exact_objective(h):
    n = len(h)
    dx = 2.0 / n
    profile = np.correlate(h, 1.0 - h, mode='full') * dx
    return float(np.max(profile))

def project_box_sum(h, target=None):
    n = len(h)
    if target is None:
        target = n / 2.0
    h = np.array(h, dtype=np.float64)
    h = np.nan_to_num(h, nan=0.0, posinf=1.0, neginf=0.0)
    h = np.clip(h, 0.0, 1.0)
    for _ in range(200):
        s = float(np.sum(h))
        diff = s - target
        if abs(diff) < 1e-15:
            break
        if diff > 0:
            mask = h > 1e-10
            cnt = int(np.sum(mask))
            if cnt == 0:
                break
            step = min(diff / cnt, np.min(h[mask]))
            h[mask] -= step
        else:
            mask = h < 1.0 - 1e-10
            cnt = int(np.sum(mask))
            if cnt == 0:
                break
            step = min(-diff / cnt, 1.0 - np.max(h[mask]))
            h[mask] += step
    diff = float(np.sum(h)) - target
    if abs(diff) > 1e-12:
        mask = (h > 0) if diff > 0 else (h < 1.0)
        if np.any(mask):
            h[mask] -= diff / np.sum(mask)
            h = np.clip(h, 0.0, 1.0)
    return h

def smooth_obj_grad(x, tau):
    n = len(x)
    dx = 2.0 / n
    r = np.correlate(x, 1.0 - x, mode='full')
    # f = (dx/tau) * log(sum(exp(r/tau)))
    r_scaled = r / tau
    r_scaled = np.clip(r_scaled, -700, 700)  # prevent overflow
    max_r = np.max(r_scaled)
    exp_r = np.exp(r_scaled - max_r)
    log_sum = max_r + np.log(np.sum(exp_r))
    value = (dx / tau) * log_sum
    
    # Weights
    weights = exp_r / np.sum(exp_r)
    
    # Gradient
    grad = np.zeros(n)
    for t in range(2 * n - 1):
        w = weights[t]
        if w < 1e-15:
            continue
        k = t - (n - 1)
        if k == 0:
            grad += w * (1.0 - 2.0 * x)
        elif k > 0:
            grad[k:n] += w * (1.0 - x[0:n-k])
            grad[0:n-k] -= w * x[k:n]
        else:
            m = -k
            grad[0:n-m] += w * (1.0 - x[m:n])
            grad[m:n] -= w * x[0:n-m]
    grad *= (dx / tau)
    
    return value, grad

    if 0 ≤ i ≤ n-1 and 0 ≤ i+k ≤ n-1 and the valid range for lag k includes n=i:
      old contribution: h[i+k]*(1-h[i]) = h[i+k]*1
      new contribution: h[i+k]*0 = 0
      delta: -h[i+k]
  
  Change due to j (0→1):
  - j as the "first" index (h[n+k]=h[j], so n=j-k):
    if valid: delta: +(1-h[j-k]) = +h[j-k]... wait, (1-h[j-k]) where h[j-k] is unchanged.
      Actually: old contribution: h[j]*(1-h[j-k]) = 0*(1-h[j-k]) = 0
      new contribution: 1*(1-h[j-k]) = 1-h[j-k]
      delta: +(1-h[j-k])
  - j as the "second" index (h[n]=h[j], so n=j):
    if valid: old contribution: h[j+k]*(1-h[j]) = h[j+k]*1
      new contribution: h[j+k]*(1-1) = 0
      delta: -h[j+k]

So total delta_raw[t] = sum of these four contributions (each may be 0 if the position is not in the valid range for that lag).

For a given swap (i,j) and lag k = t-(n-1):
delta = [contribution of i as first] + [contribution of i as second] + [contribution of j as first] + [contribution of j as second]

The valid range for lag k is n from max(0,-k) to min(n-1, n-1-k).

So:
- i is in valid range as "first" (n+k=i) if: max(0,-k) ≤ i-k ≤ min(n-1, n-1-k)
- i is in valid range as "second" (n=i) if: max(0,-k) ≤ i ≤ min(n-1, n-1-k)

For k > 0: valid n is [0, n-1-k]
- i as first (n=i-k): 0 ≤ i-k ≤ n-1-k, i.e., k ≤ i ≤ n-1
- i as second (n=i): 0 ≤ i ≤ n-1-k, i.e., 0 ≤ i ≤ n-1-k

For k < 0 (let m=-k): valid n is [m, n-1]
- i as first (n=i-k=i+m): m ≤ i+m ≤ n-1, i.e., 0 ≤ i ≤ n-1-m
- i as second (n=i): m ≤ i ≤ n-1

For k = 0: valid n is [0, n-1]
- i as first: 0 ≤ i ≤ n-1 (always true)
- i as second: 0 ≤ i ≤ n-1 (always true)
- But for k=0: h[n+k] = h[n] = h[i], so both contributions are from the same term h[i]*(1-h[i])
  delta for i (1→0): old = 1*0 = 0, new = 0*1 = 0, so delta = 0. Makes sense since binary h[i]*(1-h[i]) = 0 always.

Actually, I think the cleaner approach for the binary search is:

1. Start with a binary h
2. Compute raw = np.correlate(h, 1-h, mode='full')
3. Find the current max value M = max(raw)
4. For each pair (i in ones, j in zeros):
   - Compute delta_raw for all t (vectorized, O(n) per pair)
   - new_raw = raw + delta_raw
   - new_max = max(new_raw)
   - If new_max < M, this is an improving swap
5. Apply the best improving swap (or all improving swaps if they don't conflict)
6. Repeat until no improvement

- For each lag k from -(n-1) to n-1 (skip k=0 since binary):
  - Determine if i and j are in the valid range (as first or second index)
  - Compute the delta contribution
