1. Approach and rationale

1.1 Central idea

The parent construction is a feasible discrete representation of a step function on \([0,2]\). A generic smooth min-max/SLSQP method can improve it locally, but it often becomes trapped in flat or kinked regions of the exact overlap objective: the maximum profile is piecewise structured, and many nearby solutions differ mainly by moving box-boundary mass through several lag windows.

This plan proposes a materially different local engine: exact two-coordinate constrained line search using an exact quadratic parametrization of every profile entry.

For a feasible vector \(h\), choose two coordinates \(i,j\). Preserving the total integral exactly is automatic by moving only on the line
\[
h_i(y)=y,\qquad h_j(y)=S-y,\qquad S=h_i+h_j,
\]
where
\[
L=\max(0,S-1),\qquad U=\min(1,S),\qquad y\in [L,U].
\]
For this line, the full correlation profile
\[
P(y)=\operatorname{correlate}(h(y),1-h(y),\text{full})\cdot \frac{2}{n}
\]
has each entry as an exact quadratic polynomial in \(y\). Therefore every line step can be searched analytically: fit all \(2n-1\) quadratic polynomials from three exact profiles, then search the pointwise maximum of those quadratics using vertices and pairwise intersection roots. Candidate line positions are accepted only after recomputation with the authoritative exact objective. This replaces smooth max objectives and generic nonlinear programming by direct, exact, sum-preserving quadratic line steps.

The second complementary engine is binary search on an exactly half-support family. Binary simulated annealing and greedy exact swaps propose structural changes that continuous line steps may find too local. These binary points can then be transferred/constrained into the continuous search again. This gives a different move family: continuous quadratic moves and discrete topology moves.

This plan is not claimed to be globally optimal. All returned constants are verified with the evaluator.

1.2 What bottleneck is addressed

The bottleneck is local minimality at plateau/kinked exact profile maxima. Exact two-coordinate quadratic moves remain feasible automatically, do not rely on post-hoc rescaling, and can move mass while counseling many active lag constraints simultaneously. Binary moves can escape basin topologies by changing the set of occupied half-pixels.

1.3 Important limitations and assumptions

- Justified facts:
  1. For a fixed pair \((i,j)\), with only those coordinates varying linearly, every bilinear term \(h_p(1-h_q)\) produces polynomial degree at most \(2\) in \(y\). Hence each exact profile entry is exact quadratic in \(y\).
  2. Three distinct sample points determine the exact quadratic for each profile entry.
  3. Pair-line moves preserve the sum constraint algebraically.
- Hypotheses/heuristics:
  1. Quadratic line minimization of the profile maximum will improve the parent.
  2. Binary annealing finds useful discrete basins for nested transfer.
  3. A multi-size local search improves a better bound than parent-only search.
- Solver non-globality: all acceptance is exact, but failure to improve globally is possible. The fallback archive must always return a valid feasible solution.
