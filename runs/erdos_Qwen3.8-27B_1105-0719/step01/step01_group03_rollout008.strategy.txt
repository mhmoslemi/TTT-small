1. Approach and rationale

1.1 Main object of interest
The supplied evaluator is the only true objective: for a vector h of length n, with step size dx = 2 / n, it scores h by the maximum, over all full linear-correlation lags, of the sampled overlap profile between h and 1-h. The returned scalar must be the max value of that profile. Circular correlation, autocorrelation identities, or unnormalized sums are not acceptable unless explicitly reduced to the same finite-boundary formula.

1.2 Why a new method is needed
The previous approach centered on constrained nonlinear epigraph optimization and local gradient/surrogate motion. That framework is reasonable, but in the present nonconvex bilinear landscape it can become trapped very close to the supplied parent basin. The gap between 0.38101 and the target 0.3808 is small but not purely numerical: it may require moving several coordinates simultaneously along a feasible ridge that a single SLSQP path misses.

The proposed primary method is materially different: a trust-region sequential linear-programming surrogate inside the feasible polytope, followed by an exact evaluation line search. At each SCA cycle the exact nonlinear overlap profile is linearized around the current feasible point. Those tangents are used as a linear epigraph model of the minimax problem in variables h and tau, with exact boundary box and area constraints and a ball-like trust region. The linear program produces a direction and endpoint that reduce the linearized worst-case overlap according to the surrogate. Because the true objective is nonconvex and the tangent model is not globally valid, each endpoint is not accepted automatically. Instead, the method performs a fully exact line search from the current feasible point to the LP endpoint, using necessarily the actual finite-support evaluator. This separates proposal generation from acceptance: proposal generation is convex and fast; candidate acceptance is exact and conservative.

This differs from:
- base SLSQP, because proposals are obtained globally from a linear objective over many linearized lag constraints, not by treating the nonlinear max constraints as generic SLSQP rows;
- Frank-Wolfe/smooth-logsumexp methods, because the proposal chooses a vertex-like direction inside a tangent epigraph LP rather than moving toward a simplex vertex optimizing a smooth subgradient;
- scalar descent/subgradient descent, because the proposed point simultaneously addresses every lag tangent, not only the highest lag;
- simulated annealing or genetic searches as the primary engine, because those do not exploit the analytic finite-difference gradients of all lag profile rows;
- patching or thresholded RS cases, because the dominant solver-based engine is variable recreation enforced with strongly subsolvable validity.

Mathematically, the proposed SCA loop is a local deterministic nonlinear-program heuristic for a global minimization of a nonsmooth constrained objective. It can produce feasible points with meaningful lower exact C5. The surrogate LP is not a relaxation that certifies C5. The method is not a certificate of global optimality. All numerical claims come only from the exact evaluator applied to the returned vector.
