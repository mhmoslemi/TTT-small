The KKT conditions at optimum:
- There exist multipliers λ_i ≥ 0 with sum(λ_i) = 1
- ∑ λ_i ∇f_i(x*) + μ·1 + ν = 0 (where ν handles the box constraints)
- λ_i * f_i(x*) = 0 (complementary slackness)

minimize t

If the optimal t < 0, we have a descent direction. If t = 0, we're at the optimum (all active constraints are balanced).

Wait, let me be more careful. np.correlate(h, 1-h, mode='full') gives:
result[m] = sum_i h[i] * (1-h)[m-i]

For correlate(a, b, 'full'), result[k] = sum_i a[i] * b[k-i]
where the valid range ensures both indices are in [0, n-1].

So result[m] = sum_i h[i] * (1-h[m-i]) for valid i, m-i.

The lag is m - (n-1). For lag = 0 (m = n-1):
result[n-1] = sum_i h[i] * (1-h[i])

For lag = k > 0 (m = n-1+k):
result[n-1+k] = sum_i h[i] * (1-h[i-k]) where i ranges so that 0 ≤ i < n and 0 ≤ i-k < n
i.e., i ranges from k to n-1.

So profile for lag k > 0: sum_{i=k}^{n-1} h[i] * (1-h[i-k])

The gradient with respect to h[j]:
- If j appears as h[i] (i.e., j = i, so i = j, and j ≥ k): contributes (1 - h[j-k])
- If j appears as h[i-k] (i.e., i-k = j, so i = j+k, and j+k < n): contributes -h[j+k]

So grad[j] = (1-h[j-k]) * [j ≥ k] - h[j+k] * [j+k < n], all times dx.

Now for the LP approach:
- Variables: d (descent direction), with sum(d) = 0
- For box constraints: if h[j] ≈ 0, d[j] ≥ 0 (can only increase); if h[j] ≈ 1, d[j] ≤ 0 (can only decrease)
- Objective: minimize max over active lags of G_active @ d
  - Introduce variable t: minimize t
  - Subject to G_active @ d ≤ t for each active lag
  - sum(d) = 0
  - Box sign constraints on d

To handle the unboundedness of t, we can normalize d (e.g., ||d||_∞ ≤ 1) or add a constraint like sum(d²) ≤ 1, but the latter makes it non-linear. Instead, let's use ||d||_∞ ≤ 1 as a bound.

Actually, for a proper LP:
Variables: d_0, ..., d_{n-1}, t
Minimize: t
Subject to:
- G_row_i · d ≤ t for each active lag i
- sum(d) = 0
- For each j: if h[j] ≈ 0: d[j] ≥ 0; if h[j] ≈ 1: d[j] ≤ 0; else: -1 ≤ d[j] ≤ 1
- t is free (or t ≥ -1 as a lower bound to keep it bounded)

Wait, if all constraints G_row_i · d ≤ t and we want to minimize t, the LP is bounded below only if there's a feasible direction where all G_row_i · d < 0 simultaneously. Otherwise t ≥ 0.

Actually the LP is:
min t
s.t. G_i · d ≤ t, i ∈ active
     sum(d) = 0
     box constraints on d

This is always bounded below (t can be at most 0 by choosing d=0, but we want to minimize). If there exists a feasible d with all G_i · d < 0, then t < 0 is achievable and we have a descent direction. If the minimum t = 0, we're at optimality (for the active set).

Let me code this up properly.

For the box constraints in the LP:
- If h[j] > eps (not at lower bound): d[j] can be negative, bound by -1
- If h[j] < 1-eps (not at upper bound): d[j] can be positive, bound by +1
- If h[j] ≈ 0: d[j] ≥ 0 (can only go up), bound d[j] ≤ 1
- If h[j] ≈ 1: d[j] ≤ 0 (can only go down), bound d[j] ≥ -1

So bounds on d[j]:
- Lower bound: 0 if h[j] ≤ eps, else -1
- Upper bound: 0 if h[j] ≥ 1-eps, else +1

And t is free, so bounds are (-inf, +inf) or we can set t lower bound to -1.

import numpy as np
from scipy.optimize import linprog, minimize
import time

def exact_objective(h):
    n = len(h)
    if n == 0:
        return float('inf'), np.array([])
    dx = 2.0 / n
    profile = np.correlate(h, 1.0 - h, mode='full') * dx
    return float(np.max(profile)), profile

def project_box_sum(h, target=None):
    n = len(h)
    if target is None:
        target = 0.5 * n
    h = np.array(h, dtype=np.float64).copy()
    h = np.nan_to_num(h, nan=0.0, posinf=1.0, neginf=0.0)
    h = np.clip(h, 0.0, 1.0)
    for _ in range(200):
        diff = target - np.sum(h)
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            mask = h < 1.0
            count = np.sum(mask)
            if count == 0:
                break
            step = diff / count
            h[mask] = np.minimum(h[mask] + step, 1.0)
        else:
            mask = h > 0.0
            count = np.sum(mask)
            if count == 0:
                break
            step = diff / count
            h[mask] = np.maximum(h[mask] + step, 0.0)
    return h

def lag_gradient(h, lag, dx):
    """Compute gradient of profile at given lag."""
    n = len(h)
    grad = np.zeros(n)
    if 0 <= lag < n:
        s = n - lag
        grad[:s] -= h[lag:]
        grad[lag:] += 1.0 - h[:s]
    elif -n < lag < 0:
        a = -lag
        s = n - a
        grad[:s] += 1.0 - h[a:]
        grad[a:] -= h[:s]
    return grad * dx

def active_set_lp_direction(h, active_lags, dx, eps=1e-6):
    """
    Solve LP to find descent direction.
    Returns (direction, t_value) or (None, None) if no descent.
    """
    n = len(h)
    A_rows = []
    for lag in active_lags:
        g = lag_gradient(h, lag, dx)
        A_rows.append(g)
    G = np.array(A_rows)  # shape (m, n)
    
    # Variables: d[0..n-1], t
    # Minimize t
    # Constraints: G[d] - t <= 0  =>  G[:, :n] @ d + [-1]*t <= 0
    # A_ub: [G, -1] @ [d, t] <= 0
    A_ub = np.hstack([G, -np.ones((len(active_lags), 1))])
    b_ub = np.zeros(len(active_lags))
    
    # Equality: sum(d) = 0
    A_eq = np.zeros((1, n + 1))
    A_eq[0, :n] = 1.0
    b_eq = np.array([0.0])
    
    # Bounds:
    # d[j] bounds based on h[j]
    bounds = []
    for j in range(n):
        lo = 0.0 if h[j] <= eps else -1.0
        hi = 0.0 if h[j] >= 1.0 - eps else 1.0
        if lo == hi:
            bounds.append((lo, hi))
        else:
            bounds.append((lo, hi))
    # t is free
    bounds.append((-1.0, 1.0))
    
    c = np.zeros(n + 1)
    c[-1] = 1.0  # minimize t
    
    try:
        res = linprog(c, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq, 
                      bounds=bounds, method='highs')
        if res.success:
            t_val = res.x[-1]
            d = res.x[:n]
            # Remove mean to ensure sum(d) = 0 exactly
            d -= np.mean(d)
            if t_val < -1e-10:
                return d, t_val
            else:
                return None, t_val
        else:
            return None, None
    except Exception:
        return None, None

def exact_line_search(h, d, c_current, dx, max_alpha=1.0):
    """
    Find alpha that minimizes F(h + alpha*d) with feasibility.
    d should have sum(d) ≈ 0.
    Returns (best_h, best_c).
    """
    n = len(h)
    # Determine safe alpha range
    alpha_max = max_alpha
    for j in range(n):
        if d[j] < -1e-12 and h[j] > 1e-12:
            alpha_max = min(alpha_max, h[j] / abs(d[j]))
        elif d[j] > 1e-12 and h[j] < 1.0 - 1e-12:
            alpha_max = min(alpha_max, (1.0 - h[j]) / d[j])
    
    if alpha_max <= 0:
        return h.copy(), c_current
    
    alpha_max = min(alpha_max, 2.0)  # cap
    
    target = 0.5 * n
    best_c = c_current
    best_h = h.copy()
    
    # Try a set of alpha values
    alphas = [alpha_max * f for f in [1.0, 0.8, 0.6, 0.4, 0.3, 0.2, 0.1, 0.05, 0.01]]
    # Also add some uniform trying
    alphas = list(set([max(0.001, a) for a in alphas if a > 0]))
    alphas.sort(reverse=True)
    
    for alpha in alphas:
        if alpha <= 0:
            continue
        h_try = h + alpha * d
        h_try = project_box_sum(h_try, target)
        c_try, _ = exact_objective(h_try)
        if c_try < best_c - 1e-13:
            best_c = c_try
            best_h = h_try.copy()
    
    return best_h, best_c

def active_set_method(h, deadline, max_iter=200, active_tol=0.02, active_max=30):
    """
    Main active set optimization for convex min-max problem.
    """
    n = len(h)
    dx = 2.0 / n
    target = 0.5 * n
    target_sum = n / 2.0
    
    best_h = project_box_sum(h, target_sum)
    best_c, best_profile = exact_objective(best_h)
    
    for it in range(max_iter):
        if time.time() > deadline:
            break
        
        c_current, profile = exact_objective(best_h)
        
        # Find active lags
        c_max = np.max(profile)
        active_indices = np.where(profile >= c_max - active_tol)[0]
        
        # Limit active set size
        if len(active_indices) > active_max:
            # Take top active_max by profile value
            sorted_idx = active_indices[np.argsort(-profile[active_indices])]
            active_indices = sorted_idx[:active_max]
        
        active_lags = [(idx - (n - 1)) for idx in active_indices]
        
        # Solve LP
        d, t_val = active_set_lp_direction(best_h, active_lags, dx)
        
        if d is None:
            # No descent direction - try with slightly different active set
            # or use subgradient
            if t_val is not None and t_val >= -1e-10:
                # Possibly at optimum (or active set is too restrictive)
                # Try with wider active set
                active_indices2 = np.where(profile >= c_max - 2 * active_tol)[0]
                if len(active_indices2) > active_max:
                    sorted_idx2 = active_indices2[np.argsort(-profile[active_indices2])]
                    active_indices2 = sorted_idx2[:active_max]
                active_lags2 = [(idx - (n - 1)) for idx in active_indices2]
                d, t_val = active_set_lp_direction(best_h, active_lags2, dx)
                if d is None:
                    # Try subgradient of the single max
                    max_idx = int(np.argmax(profile))
                    max_lag = max_idx - (n - 1)
                    g = lag_gradient(best_h, max_lag, dx)
                    d = -g
                    d -= np.mean(d)
                    # Apply box sign constraints
                    for j in range(n):
                        if best_h[j] <= 1e-6:
                            d[j] = max(0, d[j])
                        elif best_h[j] >= 1 - 1e-6:
                            d[j] = min(0, d[j])
                    if np.max(np.abs(d)) < 1e-12:
                        break
                    d = d / np.max(np.abs(d))
                    # Line search
                    best_h, best_c = exact_line_search(best_h, d, c_current, dx)
                    if best_c >= c_current - 1e-14:
                        # Shrink active tol and try again
                        active_tol *= 0.5
                        if active_tol < 1e-6:
                            break
                    continue
            else:
                break
        
        # Line search
        best_h, best_c = exact_line_search(best_h, d, c_current, dx)
        
        if best_c >= c_current - 1e-14:
            # No improvement, try smaller step
            d_small = d * 0.1
            best_h2, best_c2 = exact_line_search(best_h, d_small, c_current, dx)
            if best_c2 < best_c:
                best_h = best_h2
                best_c = best_c2
            else:
                # Stuck - perturb active set tolerance
                active_tol = max(active_tol * 0.7, 1e-6)
                if active_tol < 1e-7:
                    break
    
    best_c, _ = exact_objective(best_h)
    return best_h, best_c

def subgradient_method(h, deadline, max_iter=500, step_decay=0.98):
    """
    Subgradient method for the convex min-max problem.
    Uses Langevin-style step with averaging.
    """
    n = len(h)
    dx = 2.0 / n
    target = 0.5 * n
    
    best_h = project_box_sum(h, target)
    best_c, _ = exact_objective(best_h)
    
    # Running average for convergence
    h_avg = best_h.copy()
    step_size = 0.05
    
    for it in range(max_iter):
        if time.time() > deadline:
            break
        
        c_current, profile = exact_objective(h_avg)
        c_max = np.max(profile)
        
        # Find all near-active lags and average their gradients
        near_active = np.where(profile >= c_max - 0.01)[0]
        if len(near_active) == 0:
            near_active = [int(np.argmax(profile))]
        
        # Weight by how close to max
        weights = np.zeros(len(near_active))
        for i, idx in enumerate(near_active):
            weights[i] = max(0, 1.0 - (c_max - profile[idx]) / 0.01)
        if np.sum(weights) < 1e-10:
            weights[:] = 1.0
        weights /= np.sum(weights)
        
        # Compute subgradient
        g = np.zeros(n)
        for i, idx in enumerate(near_active):
            lag = idx - (n - 1)
            g += weights[i] * lag_gradient(h_avg, lag, dx)
        
        # Project gradient onto feasible directions (sum=0, box)
        d = -g
        d -= np.mean(d)
        for j in range(n):
            if h_avg[j] <= 1e-6:
                d[j] = max(0, d[j])
            elif h_avg[j] >= 1 - 1e-6:
                d[j] = min(0, d[j])
        
        gnorm = np.linalg.norm(d)
        if gnorm < 1e-10:
            break
        
        # Try multiple step sizes
        for alpha in [step_size / gnorm, step_size / (2 * gnorm), step_size / (4 * gnorm)]:
            h_try = h_avg + alpha * d
            h_try = project_box_sum(h_try, target)
            c_try, _ = exact_objective(h_try)
            if c_try < best_c:
                best_c = c_try
                best_h = h_try.copy()
            h_avg = h_try
            break
        
        # Update running average
        # (already done in h_avg update)
        
        step_size *= step_decay
    
    # Final iteration with best_h
    best_c, _ = exact_objective(best_h)
    return best_h, best_c

def random_pair_move(h, rng, n_moves=100, max_delta=0.15):
    """
    Simulated annealing style: random pair moves that preserve sum.
    """
    n = len(h)
    target = 0.5 * n
    c_current, _ = exact_objective(h)
    current_h = h.copy()
    T = 0.002
    
    for _ in range(n_moves):
        if rng.random() < 0.1:
            T *= 0.95
        
        # Pick two indices
        i = rng.randint(n)
        j = rng.randint(n)
        if i == j:
            continue
        
        # Choose direction and magnitude
        delta = rng.uniform(-max_delta, max_delta)
        
        # Respect bounds
        new_i = current_h[i] + delta
        new_j = current_h[j] - delta
        if new_i < 0 or new_i > 1 or new_j < 0 or new_j > 1:
            continue
        
        current_h[i] = new_i
        current_h[j] = new_j
        
        c_new, _ = exact_objective(current_h)
        delta_c = c_new - c_current
        
        if delta_c < 0 or rng.random() < np.exp(-delta_c / max(T, 1e-10)):
            c_current = c_new
        else:
            current_h[i] = current_h[i] - delta
            current_h[j] = current_h[j] + delta
    
    c_final, _ = exact_objective(current_h)
    return current_h, c_final

def make_starts(n, rng, n_starts=6):
    """Generate diverse starting points."""
    starts = []
    target = 0.5 * n
    
    # 1. Alternating
    h = np.zeros(n)
    h[::2] = 1.0
    starts.append(project_box_sum(h, target))
    
    # 2. Block
    h = np.zeros(n)
    h[:n//2] = 1.0
    starts.append(project_box_sum(h, target))
    
    # 3. Random
    h = (rng.random(n) > 0.5).astype(float)
    starts.append(project_box_sum(h, target))
    
    # 4. Sinusoidal
    x = np.arange(n)
    h = 0.5 + 0.5 * np.sin(2 * np.pi * 2 * x / n)
    starts.append(project_box_sum(h, target))
    
    # 5. Two-block
    h = np.zeros(n)
    q = n // 4
    h[:q] = 1.0
    h[n//2:n//2+q] = 1.0
    starts.append(project_box_sum(h, target))
    
    # 6. Gaussian-ish
    h = 0.5 * np.ones(n)
    h += rng.randn(n) * 0.2
    starts.append(project_box_sum(h, target))
    
    return starts

def downsample(h, new_n):
    n = len(h)
    if new_n == n:
        return h.copy()
    x_old = (np.arange(n) + 0.5) / n
    x_new = (np.arange(new_n) + 0.5) / new_n
    vals = np.interp(x_new, x_old, h)
    return project_box_sum(vals, 0.5 * new_n)

def exact_objective(h):

def project_box_sum(h, target=None):
    n = len(h)

                break

            h[mask] = np.minimum(h[mask] + step, 1.0)
        else:
            mask = h > 0.0

def lag_gradient(h, lag, dx):
    n = len(h)
    grad = np.zeros(n)
    if 0 <= lag < n:
        s = n - lag
        grad[:s] -= h[lag:]
        grad[lag:] += 1.0 - h[:s]
    elif -n < lag < 0:
        a = -lag
        s = n - a
        grad[:s] += 1.0 - h[a:]
        grad[a:] -= h[:s]
    return grad * dx


def lp_descent_direction(h, active_lags, dx, eps_bound=1e-8):
    n = len(h)
    rows = []
    for lag in active_lags:
        g = lag_gradient(h, lag, dx)
        rows.append(g)
    if not rows:
        return None, 0.0
    G = np.array(rows)
    m = G.shape[0]
    A_ub = np.hstack([G, -np.ones((m, 1))])
    b_ub = np.zeros(m)
    A_eq = np.zeros((1, n + 1))
    A_eq[0, :n] = 1.0
    b_eq = np.zeros(1)
    bounds = []
    for j in range(n):
        if h[j] <= eps_bound:
            bounds.append((0.0, 1.0))
        elif h[j] >= 1.0 - eps_bound:
            bounds.append((-1.0, 0.0))
        else:
            bounds.append((-1.0, 1.0))
    bounds.append((-1.0, 0.0))
    c_vec = np.zeros(n + 1)
    c_vec[-1] = 1.0
    try:
        res = linprog(c_vec, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq,
                      bounds=bounds, method='highs',
                      options={'maxiter': 5000})
        if res.success:
            t_val = res.x[-1]
            d = res.x[:n].copy()
            d -= np.mean(d)
            if t_val < -1e-9:
                return d, t_val
            return None, t_val
        return None, -1.0

def pair_anneal(h, rng, n_proposals=2000, T_init=0.003, max_delta=0.12):

            T *= 0.92
        i = rng.randint(n)
        j = rng.randint(n)
        if i == j:
            continue
        delta = rng.uniform(-max_delta, max_delta)
        ni = cur_h[i] + delta
        nj = cur_h[j] - delta
        if ni < 0 or ni > 1 or nj < 0 or nj > 1:

        cur_h[j] = nj

                best_c = c_new
                best_h = cur_h.copy()
        else:
            cur_h[i] = ni - delta
            cur_h[j] = nj + delta
    return best_h, best_c

        h_ds = downsample(best_h, n_try)
        c_ds, _ = exact_objective(h_ds)
        if c_ds < best_c + 0.03:
            h_opt, c_opt = active_set_optimize(h_ds, min(deadline - 15, time.time() + 30),
                                               active_tol_init=0.02, active_max=30)
            if c_opt < best_c:
                best_c = c_opt
                best_h = h_opt
    if time.time() < deadline - 15:
        h_opt, c_opt = gradient_descent_refine(best_h, min(deadline - 10, t0 + 1090), lr=0.01)
        if c_opt < best_c:
            best_c = c_opt
            best_h = h_opt
    if time.time() < deadline - 8:
        h_opt, c_opt = active_set_optimize(best_h, deadline - 5,
                                           active_tol_init=0.005, active_max=15)
        if c_opt < best_c:
            best_c = c_opt
            best_h = h_opt
    best_h = project_box_sum(best_h, 0.5 * len(best_h))
    final_c, _ = exact_objective(best_h)
    return (best_h, final_c, len(best_h))
