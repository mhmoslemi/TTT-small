Actually, for the projection, the standard approach is:
1. Clip to [0,1].

The correct projection onto {x ∈ [0,1]^n : sum(x) = target} is:
- If sum(h) = target: done.
- If sum(h) > target: we need to reduce. The projection is h_proj[i] = max(0, min(1, h[i] - λ)) for some λ ≥ 0 chosen so that sum(h_proj) = target.
- If sum(h) < target: h_proj[i] = max(0, min(1, h[i] + λ)) for some λ ≥ 0.

This is the "Duchon" or "water-filling" projection. I can find λ by binary search.

```python
def project_box_sum(h, target):
    n = len(h)
    h = np.array(h, dtype=np.float64).copy()
    h = np.clip(h, 0.0, 1.0)
    current_sum = np.sum(h)
    if abs(current_sum - target) < 1e-14:
        return h
    
    if current_sum > target:
        # Need to reduce: h[i] - lambda, clipped to [0, 1]
        # Find lambda > 0 such that sum(max(0, min(1, h[i]-lambda))) = target
        lo, hi = 0.0, 1.0
        for _ in range(100):
            mid = (lo + hi) / 2
            proj = np.clip(h - mid, 0.0, 1.0)
            if np.sum(proj) > target:
                lo = mid
            else:
                hi = mid
        h = np.clip(h - (lo + hi) / 2, 0.0, 1.0)
    else:
        # Need to increase: h[i] + lambda, clipped to [0, 1]
        lo, hi = 0.0, 1.0
        for _ in range(100):
            mid = (lo + hi) / 2
            proj = np.clip(h + mid, 0.0, 1.0)
            if np.sum(proj) < target:
                lo = mid
            else:
                hi = mid
        h = np.clip(h + (lo + hi) / 2, 0.0, 1.0)
    
    # Final correction
    diff = target - np.sum(h)
    if abs(diff) > 1e-15:
        # Distribute the remaining diff
        if diff > 0:
            mask = h < 1.0
            h[mask] += diff / np.sum(mask)
        else:
            mask = h > 0.0
            h[mask] += diff / np.sum(mask)
        h = np.clip(h, 0.0, 1.0)
    
    return h
```
