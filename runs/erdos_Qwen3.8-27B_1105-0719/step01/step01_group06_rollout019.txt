The Erdős minimum overlap problem asks us to find a step function h: [0,2] → [0,1] that minimizes:
C₅ = max_k ∫ h(x)(1-h(x+k)) dx

Subject to:
- h(x) ∈ [0,1] for all x
- ∫₀² h(x) dx = 1 (i.e., sum(h) * dx = 1, so sum(h) = n/2)

The previous solution achieved C₅ = 0.381096, and the target is 0.3808.

The strategy suggests using a "line exchanger" method with:
1. Exact one-dimensional affine exchange lines (quadratic fitting along feasible directions)
2. Feasible exchange directions and block movements
3. Binary-derived starters for diversity

Let me design a cleaner, more effective algorithm:

1. **Exact quadratic line search**: For a direction d with sum(d)=0, the profile along h + t*d is exactly quadratic in t. I can find the optimal t by fitting the quadratic exactly and finding its minimum within the feasible interval.

2. **Smart direction generation**: 
   - Pairwise exchanges between "high overlap contribution" coordinates
   - Gradient-based directions (from the Lagrangian)
   - Block moves
   - Binary-derived perturbations

3. **Active set focus**: Only track the top K lags that are near the maximum, since those are the binding constraints.

The key insight is that the problem is non-convex (max of bilinear functions), so local methods can get stuck. The previous method used SLSQP with epigraph formulation, which is a standard approach but can be slow to converge on the last bits.

My approach:
1. Start from the parent (initial_h_values, n=140)
2. Use exact quadratic line search along carefully chosen directions
3. Generate directions from:

Let me think about the quadratic line search more carefully:

Given h and direction d (sum(d)=0), the profile at lag k is:
P_k(t) = dx * sum_{pairs} (h_i + t*d_i)(1 - h_j - t*d_j)

For positive delta: pairs are (i, i+delta) for i=0..n-delta-1
P_k(t) = dx * sum_i (h_i + t*d_i)(1 - h_{i+delta} - t*d_{i+delta})
       = dx * sum_i [h_i(1-h_{i+delta}) + t*d_i*(1-h_{i+delta}) - t*h_{i+delta}*d_i - t^2*d_i*d_{i+delta}]
       = dx * [sum_i h_i(1-h_{i+delta}) + t*(sum_i d_i*(1-h_{i+delta}) - sum_i h_{i+delta}*d_i) - t^2*sum_i d_i*d_{i+delta}]

Wait, let me be more careful. For lag with delta > 0:
P_k = dx * sum_{i=0}^{n-delta-1} h[i+delta] * (1 - h[i])

So (h + t*d)[i+delta] * (1 - (h+t*d)[i])
= (h[i+delta] + t*d[i+delta]) * (1 - h[i] - t*d[i])
= h[i+delta]*(1-h[i]) + t*d[i+delta]*(1-h[i]) - t*h[i+delta]*d[i] - t^2*d[i+delta]*d[i]

So: c_k = dx * sum_i h[i+delta]*(1-h[i])
    b_k = dx * sum_i [d[i+delta]*(1-h[i]) - h[i+delta]*d[i]]
    a_k = dx * sum_i d[i+delta]*d[i]  (note: this is the coefficient of -t^2, so actual is -a_k)

Wait: the expression is c + t*b - t^2*a where a = dx * sum_i d[i+delta]*d[i].

Actually let me re-derive:
(h[i+delta] + t*d[i+delta]) * (1 - h[i] - t*d[i])
= h[i+delta] - h[i+delta]*h[i] + t*d[i+delta] - t*d[i+delta]*h[i] - t*h[i+delta]*d[i] + t^2*d[i+delta]*d[i]

So: constant = h[i+delta]*(1-h[i])
    linear coeff = d[i+delta]*(1-h[i]) - h[i+delta]*d[i]
    quadratic coeff = d[i+delta]*d[i]

For delta = 0:
h[i]*(1-h[i]) → (h[i]+t*d[i])*(1-h[i]-t*d[i])
= h[i] - h[i]^2 + t*d[i] - t*d[i]*h[i] - t*h[i]*d[i] + t^2*d[i]^2
= h[i]*(1-h[i]) + t*d[i]*(1-2*h[i]) + t^2*d[i]^2

Wait: d[i]*(1-h[i]) - h[i]*d[i] = d[i]*(1-2*h[i])
And quadratic: -d[i]*d[i] ... no wait.

(h+t*d)*(1-h-t*d) = h*(1-h) + t*d*(1-h) - t*h*d - t^2*d^2
= h*(1-h) + t*d*(1-2h) - t^2*d^2

So quadratic coeff is -d[i]^2.

For delta < 0 (sepa = -delta):
h[i] * (1 - h[i+sepa])
→ (h[i]+t*d[i])*(1-h[i+sepa]-t*d[i+sepa])
= h[i]*(1-h[i+sepa]) + t*d[i]*(1-h[i+sepa]) - t*h[i]*d[i+sepa] - t^2*d[i]*d[i+sepa]

So the pattern is consistent. For each lag, P_k(t) = c_k + b_k*t + a_k*t^2 where:
- a_k is the sum of products of d components at the relevant pairs (with appropriate sign)
- b_k is the cross term
- c_k is the current value

The key point: I don't need to compute all 2n-1 lags explicitly for the line search. I just need to find the t that minimizes max_k P_k(t) over the feasible interval.

A practical approach:
1. Compute the current profile P_k for all k
2. Identify the "critical" lags (those near the max, say top 20-50)
3. For a direction d, compute a_k, b_k, c_k for only the critical lags
4. Find the t that minimizes the max of these quadratics over the feasible interval
5. Evaluate the full profile at the new point to verify

For finding the optimal t given a set of quadratics, I can:
- Evaluate the max at a grid of t values
- Refine with ternary search or golden section on the max of quadratics
- Or use the fact that the max of convex/concave quadratics can be minimized by checking critical points

Actually, since each quadratic can be convex or concave (depending on sign of a_k), the max is not necessarily convex. But in practice, most a_k will be small and the functions will be nearly linear.

Let me simplify: I'll use a practical approach where I:
1. Compute the quadratic coefficients for the top K lags
2. Do a fine grid search for t (say 200 points) over the feasible interval
3. Evaluate the full profile at the best few t values
4. Accept if improvement

For direction generation, the key ideas:
- **Gradient direction**: For each active lag k, compute the gradient w.r.t. h. The "descent direction" is negative weighted sum of gradients of active lags. But we need sum(d)=0, so subtract the mean.
- **Pairwise**: Find pairs (i,j) where increasing h[i] and decreasing h[j] would reduce the active lag profiles.
- **Block**: Transfer a block of mass from one region to another.
- **Binary**: Generate random binary vectors (sum = n/2), interpolate toward current solution.

Let me now write the code. I'll aim for a clean, efficient implementation.

Key design decisions:
- Use n=140 (same as parent) for the main optimization
- Quadratic line search with ~100-200 grid points
- Top K=30 active lags for direction computation
- Multiple restarts with binary seeds
- Time budget management

Let me also think about what's different from the previous approach:
- Previous: SLSQP with epigraph (full nonlinear solver)
- Mine: Pure line search with exact quadratic evaluation (much faster per step, can do many more iterations)

The advantage of line search: each step is O(n*K) for computing coefficients + O(grid*K) for finding best t + O(n) for evaluation. No matrix factorization, no constraint handling overhead. Can do thousands of steps in the time budget.

import numpy as np
import time

def exact_score(h):
    dx = 2.0 / len(h)
    return float(np.max(np.correlate(h, 1.0 - h, mode="full") * dx))

def get_profile(h):
    dx = 2.0 / len(h)
    return np.correlate(h, 1.0 - h, mode="full") * dx

def repair_feasible(h, target=None):
    h = np.array(h, dtype=np.float64).copy()
    h = np.nan_to_num(h, nan=0.5, posinf=1.0, neginf=0.0)
    h = np.clip(h, 0.0, 1.0)
    n = len(h)
    if target is None:
        target = n / 2.0
    diff = target - h.sum()
    if abs(diff) < 1e-14:
        return h
    if diff > 0:
        room = 1.0 - h
        order = np.argsort(-room)
        remaining = diff
        for idx in order:
            if remaining <= 1e-15:
                break
            add = min(remaining, room[idx])
            h[idx] += add
            remaining -= add
    else:
        order = np.argsort(-h)
        remaining = -diff
        for idx in order:
            if remaining <= 1e-15:
                break
            rem = min(remaining, h[idx])
            h[idx] -= rem
            remaining -= rem
    return h

def compute_quadratic_coeffs(h, d, profile_current, k_indices):
    """Compute a_k, b_k, c_k for lags in k_indices along direction d."""
    n = len(h)
    dx = 2.0 / n
    M = 2 * n - 1
    a = np.zeros(len(k_indices))
    b = np.zeros(len(k_indices))
    c = profile_current[k_indices].copy()
    
    for i, k in enumerate(k_indices):
        delta = k - (n - 1)
        if delta > 0:
            # P_k = dx * sum_{i=0}^{n-delta-1} h[i+delta]*(1-h[i])
            h_a = h[delta:n]
            h_b = h[0:n-delta]
            d_a = d[delta:n]
            d_b = d[0:n-delta]
            a[i] = dx * np.dot(d_a, d_b)
            b[i] = dx * (np.dot(d_a, 1.0 - h_b) - np.dot(h_a, d_b))
        elif delta < 0:
            sepa = -delta
            # P_k = dx * sum_{i=0}^{n-sepa-1} h[i]*(1-h[i+sepa])
            h_a = h[0:n-sepa]
            h_b = h[sepa:n]
            d_a = d[0:n-sepa]
            d_b = d[sepa:n]
            a[i] = dx * np.dot(d_a, d_b)
            b[i] = dx * (np.dot(d_a, 1.0 - h_b) - np.dot(h_a, d_b))
        else:
            # P_k = dx * sum h[i]*(1-h[i])
            a[i] = -dx * np.dot(d, d)
            b[i] = dx * np.dot(d, 1.0 - 2.0 * h)
    
    return a, b, c

def feasible_interval(h, d):
    """Find tau range where h + tau*d stays in [0,1]."""
    n = len(h)
    tau_min = -np.inf
    tau_max = np.inf
    
    pos = d > 1e-14
    neg = d < -1e-14
    
    if np.any(pos):
        tau_min = max(tau_min, np.max(-h[pos] / d[pos]))
        tau_max = min(tau_max, np.max((1.0 - h[pos]) / d[pos]))
    
    if np.any(neg):
        tau_min = max(tau_min, np.max((1.0 - h[neg]) / d[neg]))
        tau_max = min(tau_max, np.max(-h[neg] / d[neg]))
    
    # Clamp to reasonable range
    tau_min = max(tau_min, -5.0)
    tau_max = min(tau_max, 5.0)
    
    if tau_min >= tau_max:
        return 0.0, 0.0
    return tau_min, tau_max

def line_search(h, d, profile, K, grid_size=100):
    """Find best t along direction d using exact quadratic for top K lags."""
    n = len(h)
    tau_min, tau_max = feasible_interval(h, d)
    if tau_min >= tau_max:
        return 0.0, profile
    
    # Identify top K lags
    M = len(profile)
    k_order = np.argsort(profile)[::-1][:K]
    
    # Compute quadratic coefficients
    a, b, c = compute_quadratic_coeffs(h, d, profile, k_order)
    
    # Grid search for best t
    ts = np.linspace(tau_min, tau_max, grid_size)
    # Evaluate max of quadratics at each t
    # values[i,j] = a[j]*t[i]^2 + b[j]*t[i] + c[j]
    vals = c[None, :] + b[None, :] * ts[:, None] + a[None, :] * (ts[:, None] ** 2)
    max_vals = vals.max(axis=1)
    
    # Find best t
    best_idx = np.argmin(max_vals)
    best_t = ts[best_idx]
    
    # Refine with finer grid around best
    if 0 < best_idx < grid_size - 1:
        t_lo, t_hi = ts[max(0, best_idx-2):grid_size-min(1, grid_size-best_idx-1)+1]
        if len(t_lo) > 3:
            ts_fine = np.linspace(t_lo[0], t_lo[-1], 50)
            vals_fine = c[None, :] + b[None, :] * ts_fine[:, None] + a[None, :] * (ts_fine[:, None] ** 2)
            max_fine = vals_fine.max(axis=1)
            best_idx_fine = np.argmin(max_fine)
            best_t = ts_fine[best_idx_fine]
    
    # Evaluate full profile at best_t
    h_new = h + best_t * d
    h_new = np.clip(h_new, 0.0, 1.0)
    profile_new = get_profile(h_new)
    
    return best_t, profile_new

def gradient_direction(h, profile, K):
    """Compute descent direction as negative weighted gradient of top K lags."""
    n = len(h)
    dx = 2.0 / n
    d = np.zeros(n)
    
    k_order = np.argsort(profile)[::-1][:K]
    weights = profile[k_order] - profile.max() * 0.8  # weight by proximity to max
    weights = np.maximum(weights, 0.1)
    weights = weights / weights.sum()
    
    for i, k in enumerate(k_order):
        delta = k - (n - 1)
        if delta > 0:
            # dP/dh[j] for j in [0, n-delta)
            # G[k, j] = -dx * h[j+delta] for the (1-h[j]) part
            # G[k, j+delta] = dx * (1-h[j]) for the h[j+delta] part
            d[delta:n] += weights[i] * dx * (1.0 - h[0:n-delta])  # positive part (h[j+delta])
            d[0:n-delta] += weights[i] * (-dx) * h[delta:n]  # negative part (from 1-h[j])
        elif delta < 0:
            sepa = -delta
            d[0:n-sepa] += weights[i] * dx * (1.0 - h[sepa:n])
            d[sepa:n] += weights[i] * (-dx) * h[0:n-sepa]
        else:
            d += weights[i] * dx * (1.0 - 2.0 * h)
    
    # Make zero-sum
    d -= d.mean()
    
    # We want to DECREASE the profile, so negate
    d = -d
    
    return d

def pair_exchange_direction(h, profile, K, rng):
    """Generate a pairwise exchange direction."""
    n = len(h)
    # Find coordinates that "want to increase" vs "decrease" based on gradient
    grad = gradient_direction(h, profile, K)
    
    # Pick a positive and negative component
    pos_candidates = np.where(grad > 0.01 * np.max(np.abs(grad)))[0]
    neg_candidates = np.where(grad < -0.01 * np.max(np.abs(grad)))[0]
    
    if len(pos_candidates) == 0 or len(neg_candidates) == 0:
        return None
    
    for _ in range(20):
        i = pos_candidates[rng.randint(len(pos_candidates))]
        j = neg_candidates[rng.randint(len(neg_candidates))]
        if i == j:
            continue
        
        d = np.zeros(n)
        mass = min(h[j], 1.0 - h[i]) * (0.3 + 0.5 * rng.random())
        d[i] += mass
        d[j] -= mass
        
        # Add some noise
        noise_scale = mass * 0.3
        d[rng.randint(n, 3)] += noise_scale * rng.randn(3)
        d -= d.mean()
        
        return d
    
    return None

def block_exchange_direction(h, rng, n):
    """Generate a block exchange direction."""
    d = np.zeros(n)
    block_size = rng.randint(3, max(4, n // 8))
    
    # Source block
    src_start = rng.randint(0, n - block_size)
    # Dest block (different location)
    max_dest = n - block_size
    if max_dest <= src_start:
        return None
    dest_start = rng.randint(0, max_dest)
    while dest_start < src_start + block_size and dest_start + block_size > src_start:
        dest_start = rng.randint(0, max_dest)
        if dest_start >= src_start + block_size - 1:
            break
    
    # Transfer mass from src to dest
    src_mass = h[src_start:src_start+block_size].sum()
    dest_mass = h[dest_start:dest_start+block_size].sum()
    
    # Create smooth block shape
    shape = np.sin(np.pi * np.arange(block_size + 1) / (block_size + 1))[1:-1]
    shape /= shape.sum()
    
    amount = min(src_mass, 1.0 * block_size - dest_mass) * (0.2 + 0.6 * rng.random())
    amount = max(0.01, min(amount, 0.5 * block_size))
    
    if dest_start < src_start:
        # Overlap check
        if dest_start + block_size > src_start:
            return None
    
    d[src_start:src_start+block_size] -= amount * shape
    d[dest_start:dest_start+block_size] += amount * shape
    d -= d.mean()
    
    norm = np.linalg.norm(d)
    if norm < 1e-10:
        return None
    return d

def binary_start(n, rng):
    """Generate a random binary vector with sum = n/2."""
    if n % 2 != 0:
        n = n + 1  # make even
    idx = rng.permutation(n)
    h = np.zeros(n)
    h[idx[:n//2]] = 1.0
    return h

def smooth_binary(h_bin, n_cont, iterations=5, alpha=0.3):
    """Smooth a binary vector toward continuous."""
    h = h_bin.astype(np.float64).copy()
    for _ in range(iterations):
        h_smooth = alpha * h + (1 - alpha) * np.roll(h, 1)
        h_smooth[1:-1] = alpha * h_smooth[1:-1] + (1-alpha) * 0.5*(h[1:-1] + np.roll(h[1:-1],1))
        # Simpler: just do a box blur
        kernel = np.ones(3) / 3.0
        h_pad = np.pad(h, 1, mode='edge')
        h = np.convolve(h_pad, kernel, mode='valid')[:n_cont]
        h = np.clip(h, 0, 1)
    return repair_feasible(h)
