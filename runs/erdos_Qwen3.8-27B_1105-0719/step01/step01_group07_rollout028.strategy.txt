2. Mathematical specification

2.1 Discrete representation and exact count
Let n be an even positive integer and h be an array indexed by i=0,...,n-1. Let

    dx = 2.0 / n
    total weight = n/2.

The exact task profile can be computed with np.correlate(h, 1.0-h, mode="full")*dx, producing 2n-1 values. We define the equivalent lag family on supports [-n+1, n-1]:

    C_s(h) = dx * sum_{i=a(s)}^{b(s)} h_i * (1 - h_{i+s}),

where

    a(s) = max(0, -s)
    b(s) = min(n-1, n-1-s)

and it is implicit that only valid second indices are summed. For each lag s, C_s corresponds to a member of the full evaluator correlation array (possibly with reversed ordering). The objective is

    J(h) = max_{s=-(n-1)}^{n-1} C_s(h).

This representation includes lag 0 and boundary partial overlaps correctly; it does not replace the evaluator by circular autocorrelation or by omitting boundary lengths.

2.2 Lag objective as a bilinear epigraph target
The optimization surface can be written explicitly as

    C_s(h) = dx * sum over overlap interval { h_i - h_i * h_{i+s} }.

Each C_s is linear plus negative bilinear cross-products. This is non-convex. Therefore a direct epigraph problem in variables (h,t) is

    minimize t
    subject to sum_i h_i = n/2
    0 <= h_i <= 1
    C_s(h) <= t - eps           for every s.

The small eps, suitable values [1e-7,1e-6], allows numerical solvers to avoid equality noise. It does not alter feasibility in the optimization result: exact acceptance is checked after epigraph calls with the authoritative evaluator and with exact constraint adaptation.

2.3 Gradients and Jacobians
For helper collisions, design per-Lag gradient matrix for compare. The partial derivative of a single C_s is

    ∂C_s / ∂h_p = dx * A_p - dx * B_p.

Here A is from h_p as first factor:

    A_p = 1 - h_{p+s}
    provided max(0,-s) <= p <= min(n-1,n-1-s).

Here B is from second factor:

    B_p = h_{p-s}
    provided max(0,-s) <= p - s <= min(n-1,n-1-s).

In vectorized profile generation:

    G_s[:, i_1...i_2] += dx * (1 - h_{p am+1 to b})
    G_s[:, i_1+s] -= dx * h_{i_1...i_2}

The full lag gradient for a weighted profile f(h), with weights w_j >= 0, is

    grad f(h) = sum_j w_j * grad C_{s_j}(h).
