Actually wait. Let me reconsider. The function f_d(h) = dx * sum h_i(1-h_{i+d}) is:
- Linear in h_i for the "1" part
- Quadratic (negative) in the "h_i h_{i+d}" part

So f_d is a quadratic form that is neither convex nor concave in general. The Hessian of f_d has negative diagonal entries (from the -h_i² terms when d=0) and off-diagonal entries (from the -h_i h_{i+d} terms).

For d=0: f_0(h) = dx*(n/2 - sum h_i²), Hessian = -2*dx*I (negative definite)
For d≠0: the Hessian has 0 on diagonal (no h_i² terms) and -dx/2 on the (i, i+d) and (i+d, i) positions.

So for d≠0, f_d is actually bilinear (no quadratic terms in individual variables), meaning its Hessian is zero on the diagonal. The function is "flat" in each individual coordinate direction but has cross terms.

This means the weighted sum Q_w will have:
- Diagonal entries: only from the d=0 term, which is -2*dx*w_0
- Off-diagonal entries: from the d≠0 terms

If w_0 is small (which it will be since the d=0 lag is typically not the max for a good solution), then Q_w is approximately zero on the diagonal. The QP then becomes essentially a bilinear (saddle-point) optimization, which is hard.

    if diff > 0:

        capacity = 1.0 - h

        remaining = diff

            idx = order[i]
            add = min(remaining, capacity[idx])
            if add > 0:
                h[idx] += add
            remaining -= add
            if remaining <= 1e-13:

    else:

    """Gradient of log-sum-exp smooth approximation."""
    profile = compute_profile(h)
    max_p = np.max(profile)
    w = np.exp((profile - max_p) / tau)
    w /= w.sum()
    G = profile_gradient(h)

    """Barzilai-Borwein step size."""
    s = h_curr - h_prev
    y = grad_curr - grad_prev

    sy = s @ y
    yy = y @ y

        return 0.01
    if sy > 1e-16:
        return ss / sy  # BB1
    elif yy > 1e-16:
        return sy / yy  # BB2
    else:
        return 0.01
