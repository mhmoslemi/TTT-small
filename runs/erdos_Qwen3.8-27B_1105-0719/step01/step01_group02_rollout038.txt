def targeted_binary_swap(b, active_k=10, max_rounds=1000, time_limit=None, start_time=None):
    n = len(b)
    cur = b.copy()
    cur_c = exact_objective(cur)
    dx = 2.0 / n
    
    for round_idx in range(max_rounds):
        if time_limit is not None and time.time() - start_time > time_limit:
            break
        
        profile = np.correlate(cur, 1.0 - cur, mode='full') * dx
        # Find active lags
        sorted_idx = np.argsort(-profile)[:active_k]
        
        best_delta = 0.0
        best_i, best_j = -1, -1
        
        # For each active lag, find contributing positions and try swaps
        candidates = set()
        for p in sorted_idx:
            k = p - (n - 1)  # lag
            if k == 0:
                continue
            if k > 0:
                # c[p] = sum_{n=0}^{n-1-k} cur[n+k]*(1-cur[n])
                # Contributing pairs: cur[n+k]=1, cur[n]=0
                for m in range(n - k):
                    if cur[m+k] == 1 and cur[m] == 0:
                        # Try: set cur[m]=1 (swap with some 0) or cur[m+k]=0 (swap with some 1)
                        candidates.add((m, m+k))  # means: swap cur[m] (0→1) with cur[m+k] (1→0)

                        # After swap: cur[m]=1, cur[m+k]=0
            else:
                r = -k
                # c[p] = sum_{n=r}^{n-1} cur[n-r]*(1-cur[n])
                for m in range(r, n):
                    if cur[m-r] == 1 and cur[m] == 0:
                        candidates.add((m, m-r))  # cur[m]=0→1, cur[m-r]=1→0
        
        # Evaluate candidate swaps
        for (a, b_pos) in candidates:
            if cur[a] == 0.0 and cur[b_pos] == 1.0:
                cur[a] = 1.0
                cur[b_pos] = 0.0

                cur[a] = 0.0

            cur[best_j] = 0.0
            cur_c -= best_delta
        else:
            # Try random swaps as perturbation
            break

            zeros.remove(j)
            zeros.append(i)
        else:
            cur[i] = 1.0
            cur[j] = 0.0

Let me also add one more idea from the strategy: **LP-based active set direction**. This is the most promising improvement over the previous program. Let me implement a simplified version:

At each step:
1. Compute profile P and identify active set A = {k : P[k] ≥ max(P) - ε}
2. Build the LP:
   - Variables: δ ∈ R^n (the direction), t (scalar)
   - Objective: minimize t
   - Constraints:
     - For each k in A: grad_P[k] · δ ≤ t (try to reduce active profiles)
     - sum(δ) = 0 (mass constraint)
     - For each i: -h[i] ≤ δ[i] ≤ 1-h[i] (box, ensuring h+δ ∈ [0,1])
     - sum(|δ|) ≤ r (L1 trust region, or we can use ||δ||_∞ ≤ r)
3. Solve the LP
4. Take a damped step: h_new = h + α * δ, where α is chosen to maintain feasibility
5. Project to [0,1] with sum constraint

The LP has n+1 variables and |A| + 1 + 2n + 1 constraints. For n=140 and |A|=10, that's 141 variables and about 300 constraints. This is a small LP that scipy's linprog can solve in milliseconds.
