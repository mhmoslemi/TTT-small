1. Approach and rationale

Central idea. Improve the supplied construction by restarting the search from the parent only inside a much better-conditioned, exactly feasible complement-palindromic representation, and then polish the result with exact minimax nonlinear programming rather than a fixed smoothing surrogate. The original task is a discrete approximation of a bilinear max-over-lags optimization problem. The previous method relies heavily on smoothing parameter beta and full-dimensional variables with a separate sum constraint. This creates two weaknesses: first, the smoothing objective can bias the solution away from the exact maximum constraint; second, in the original full-variable problem, the sum constraint and feasible repair interfere with local convergence. The proposed method addresses both weaknesses.

The principal change is to restrict the search to functions satisfying an exact complement-palindromic relation. For a full point grid of length n, choose variables q and build h as follows: for every pair (i, n-1-i), the two endpoint values sum exactly to 1; if n is odd, the middle sample is exactly 1/2. This automatically enforces both the box constraints and the integral sum with no equality constraint or repair projection. This representation is a restriction of the full feasible set, but it is a natural restriction for this problem because the objective contains h(x)*(1-h(x+k)), and replacing h by the reflected complement 1-h(2-x) preserves the integral and maps feasibility to itself. It is therefore plausible that an optimal or near-optimal construction can be found in this symmetric subspace. This is a justified hypothesis, not a theorem. To avoid losing a true optimum outside this subspace, keep the original full-dimensional representation as a fallback and also run full-dimensional exact max-constraint solvers from the best construction found in the symmetric subspace.

The main numerical engine is an exact active-set epigraph solver. Rather than optimizing log-sum-exp with finite beta indefinitely, solve the exact formulation “minimize t subject to t >= C_k(h) for selected lags k, with t and h bounded,” then evaluate the full original objective exactly. If the selected constraint set is smaller than all lags, collect any hidden violations and repeat until the relevant active constraints are represented or until time/solver limits are reached. After every solver result, accept only if the exact evaluator objective improves and feasibility remains within tolerance.

A secondary search mechanism uses smooth p-norm/log-sum-exp optimization for globalization, random feasible restarts, low-dimensional bounded basis functions, and dimension transfer. These are not relied upon to define correctness: the exact evaluator always rules acceptance.

Limitations and claims. The method is local and nonconvex. It may fail to find a global minimum. Improvement over the previous method is expected because of exact epigraph optimization and the exact feasible complement-palindromic subspace, not because of any proved optimality or convex relaxation. The complement-palindromic restriction could exclude an asymmetric optimum; therefore the algorithm must continue to search in the full representation and retain the original parent as a safe fallback.

2. Mathematical specification

Let h be an array of length n. The task evaluator uses

C5(h) = max_k [ dx * sum over valid positions of the correlation term ]

where dx = 2/n. Operationally, the final and accepted objective is always computed exactly as

score_h(h) = max(np.correlate(h, 1.0 - h, mode="full")) * (2.0 / len(h)).

All candidate solutions must satisfy:
- 0 <= h_i <= 1 exactly within numerical tolerance.
- sum(h) = n/2 exactly within numerical tolerance, preferably to absolute error below 1e-10 after final validation.

Complement-palindromic representation.

For an even full length n = 2m, introduce m free variables q_0, ..., q_{m-1}. Define

h_i = q_i, for 0 <= i < m,

h_{n-1-i} = 1 - q_i, for 0 <= i < m.

a pair is complete:

h = [q_0, q_1, ..., q_{m-1}, 1 - q_{m-1}, ..., 1 - q_1, 1 - q_0].

If every q_i is bounded in [0, 1], then automatically 0 <= h_i <= 1 and

sum(h) = sum(q) + m - sum(q) = m = n/2.

This is exact as a mathematical identity. Floating point summation may leave only roundoff error, and a final robust feasibility projection should be applied only if needed.

For odd full length n = 2m + 1, introduce m free variables q_0, ..., q_{m-1}, and fix the middle value h_m = 1/2. Define for 0 <= i < m:

h_i = q_i,
h_{n-1-i} = 1 - q_i,
h_m = 1/2.

The sum is

sum(q) + 1/2 + (m - sum(q)) = m + 1/2 = n/2.

Again, no equality constraint is needed during optimization on q.

Correlation orientation and gradient.

The constrained solver should be aligned with the exact evaluator. To prevent an off-by-one or convention mismatch in hand-derived gradients, require a runtime consistency check using a small random valid vector: for a selected lag index computed from np.correlate, compare the hand-formula value with an exact one-point reevaluation extracted from the full correlation array. The parent program’s offset convention was, for lag index r:

d = r - (n - 1)
valid i: i ranges from max(0, -d) to min(n - 1, n - 1 - d)
j = i + d

and the overlap value proportional to the orientation used in exact correlation is computed with a helper consistent with the previous code path. For safe tolerance, it is acceptable to construct the gradient from the exact same correlation convention used for selected lags. Given q variables h[q_i] = q_i and h[n-1-i] = 1 - q_i, the q-gradient is obtained from the full-h gradient G by

G_q[i] = G[i] - G[n-1-i]

for even n. For odd n, with absent central variable,

G_q[i] = G[i] - G[n],  ...? Concretely if h = [q_0..q_{m-1}, 1/2, ...], then variable q_i affects full index i and full index n-1-i, so use the positions

q_i -> full position i and full position n-1-i.

Therefore simply use G_q[i] = G[i] - G[n-1-i] after attention to the reordered segment. If implementer uses slices, ensure the reversed segment is aligned to q order. A safer implementation is to accumulate over full positions:

initialize G_q zeros length m
for i from 0 to m - 1:
    G_q[i] = G[i]
    G_q[i] = G_q[i] - G[n - 1 - i]

ignore if n odd and i reaches middle before m.

Exact epigraph model.

At a current point h, define F_r(h) = the r-th correlation contribution including dx. The exact completed problem is

minimize t
subject to t - F_r(h) >= 0 for all r,
0 <= h_i <= 1,
sum(h) = n/2.

The epigraph problem is nonconvex due products h_i h_j. No solver is claimed to solve it exactly or globally. The method uses local constrained optimization of this problem and evaluates the exact objective after each step.

In the symmetric q-space, the model reduces to

minimize t
subject to t - F_r(q) >= 0 for selected r,
0 <= q_i <= 1.

There is no explicit sum constraint. Full-dimensional variants additionally include

sum(h) - n/2 = 0

as an equality constraint handled by the constrained solver and repaired by projection afterward.

Active lag selection.

Use a dynamic subset of active or near-active constraints. For each candidate point q:
1. Compute all F_r(q) exactly using np.correlate and policy.
2. Select initially only the largest constraints because only those influence lowering the maximum. A default subset size for symmetric n=126 is
   L = min(90, 2n - 1)
   subject to at least the current minimizer and perhaps +10 neighbors in lag index to avoid missing symmetrical neighbors.
3. Solve the restricted epigraph problem.
4. Recompute all F_r(q). Compute hidden violations: any index with
   F_r(q) - t_solved > epsilon_active,
   with epsilon_active about 1e-6 or 1e-7.
5. Add all hidden violating indices, possibly also indices with large negative reduced slack, and resolve. Repeat 2 to 4 times. The aim is to recover hidden active constraints. The SLSQP model only needs a subset active constraining true optimum moving toward exact.

Smoothing surrogate for restarts.

Use a smooth maximum

V_beta(q) = (1/beta) log sum exp(beta F_r(q))

for beta values gradually increasing. V_beta is smooth but not convex. It is only a warmer. Use beta sequence such as [100, 250, 500, 800, 1200]. Gradient:

weights w_r = exp(beta*(F_r(q) - max F))
w += normalized w
Grad(vjection)= sum_r w_r Grad(F_r).

For full variables, the same formula plus handling of box constraints and equality is accepted as local smoother. Acceptance uses exact evaluator Vbar(h) = max F_r, not the smooth objective value.

Feasibility and projection.

For full representation, modify projection robustly by binary search on h(x-s) clipped to [0,1] so the sum root is target n/2. After projection, re-evaluate feasibility. If residual sum error > 1e-10 and if there are interior entries with slack, distribute residual to slack proportionally; if there are none, rely on the clipped projection error and reject candidate if it skews significantly. For symmetric q candidates, building h from q and selecting? Sum is nearly exact; apply builder->full projection only if needed, then evaluate exact score on projected full h and only accept projected if it remains better and feasible.
