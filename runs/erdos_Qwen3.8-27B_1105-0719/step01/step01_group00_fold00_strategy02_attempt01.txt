1. Approach and rationale

Central idea and why it can help.

The supplied parent is already very close to the target. The remaining gap is tiny, so a conventional log-sum-exp/SLSQP search is likely to stall: the exact evaluator is a finite, bilinear, finite-support maximization over all 2n-1 lag indices. Smooth maximum objectives bias the result, and full-dimensional SLSQP calls can lose precision because they must feed both the 0/1 box and the equality constraint through one generic constrained solver.

The proposed approach changes the search object rather than merely relabeling the objective. First, it treats the nearby optimum as an almost-binary balanced sequence problem. On an even-length grid, if h is binary and sum(h)=n/2, the exact objective is exactly raw_max*dx, where raw_max is an integer. This integer structure explains many local minima near the record. The method therefore performs a combinatorial/annealing search over the strictly feasible discrete set, with exact scoring at every move, instead of only continuous gradient steps. This can move into a different discrete basin whose exact value is feasible and possibly below the parent.

Second, if a discrete or already good continuous candidate remains above target, the method refines it with an active top-correlation p-norm objective rather than log-sum-exp maximization or a fixed smoothing temperature. This objective directly compresses the top few correlation vectors and uses exact finite-difference/linear-algebra gradients checked against the same correlation convention as the evaluator. The exact evaluator is always used for candidate acceptance, so the p-norm can be viewed as a computational guide only.

Third, the method transfers candidates among a small set of resolution lengths satisfying feasibility. The importance of finite discrete target resolution is exploited: for the target value 0.3808, the required raw maximum is floor(0.3808 * n / 2). An even-length binary candidate at n=128 succeeds if raw max is <= 24, for example, because 24*2/128 = 0.375. Parent transformations to nearby lengths are legitimate because the evaluator uses the returned n, dx=2/n, and exact over all feasible segmentation lengths.

Important distinctions from prior plans.

The first part is not a compressed smooth max, smooth epigraph, quadratic majorizer, or symmetric-rection subspace continuation. It is a feasible discrete sequence basin with exact average mass and exact one-point swaps. The second optimization phase is not an asymptotic smoothing maximization but an active top-short finite-p norm that targets the peak vector cluster and relies on exact acceptance after each iteration. Dimension transfer is not blindly performed; candidates must exactly satisfy the chosen n's constraints and be evaluated with the real evaluator.

Limitations and honest claims.

The discrete search is a global heuristic over an astronomically large balanced binary set. The local p-norm refinement is nonconvex. No global optimality or target guarantee is claimed. The suggested improvement is plausible because many near-record states sit in plateaus created by continuous smoothing (values near 0, near 1, fractional spent at differing transitions), and because integer/balanced sequences and exact active compression can enter thermodynamics near plateaus yet leave funnel. The result will always be accepted only by the exact evaluator. The returned vector will meet equality and box constraints by explicit repair and an independent accept/reject check.
