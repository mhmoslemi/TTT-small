1. Approach and rationale

1.1 Central idea

We construct a materially different nonlinear nonconvex optimizer whose search variable is not the epigraph scalar used in many previous attempts, and whose inner optimization is not initially an epigraph-constrained SLSQP problem on the original clipped sample vector. The new primary method is:

1. Represent feasible step functions by an unconstrained vector z through a monotone logit projection

   h_i = σ(z_i + c(z)),    σ(x)=1/(1+exp(-x)),

   where the scalar c(z) is chosen by one monotone root solve so that

   Σ_i h_i = n/2 exactly.

   This construction enforces 0 < h_i < 1 and exact integral normalization inside every continuous optimization iteration, without clipping or repeated post-hoc water-filling. It also provides an analytic chain-rule gradient.

2. Minimize a smooth soft-max of all full-lag correlations

   J_beta(h) = (1/beta) log Σ_l exp(beta C_l(h)),

   where C_l(h) = dx np.correlate(h, 1-h, "full")_l and dx=2/n. J_beta is differentiable and eta-approaches the true objective max_l C_l(h) as beta grows. The gradient of J_beta w.r.t. h is obtained analytically from exact finite-lag correlation gradient chemistry. The gradient w.r.t. the unconstrained logit coordinate is then obtained exactly from the projected gradient chain rule.

3. Use multiple resolution levels. The supplied parent has n=140 in the stated context, but the grid is not to be hard-coded. For a dynamically observed parent dimension p, the search considers p, and when the budget is large enough probe larger dimensions such as approximately 2p and 3p while respecting a dimension cap. Larger resolution can break cells into small variations that are unavailable on the fixed grid. After high-resolution candidates are found, use an exact area-preserving transfer back to other dimensions, then polish locally and keep the best.

4. Acceptance is always with the authoritative evaluator

   exact_score(h)=dx * max_k np.correlate(h, 1-h, "full")[k].

   Soft objective values, epigraph variables, linearizations, and logit intermediate values are never used as the reported bound.

5. After the smooth logit-stage, reconstruct with several deterministically searched and exactly evaluated global/local regularizers:

   - exact soft-max beta annealing in logit space,
   - exact active descent on the final feasible coefficient with line search,
   - dimension transfers from good high-resolution solutions down to coarser dimensions,
   - symmetrization as an exact-change probe,
   - optional small randomized escapes when time remains.

1.2 Why this is different from the parent method

The previous program repeats SLSQP in the original h variables, using either the full nonlinear epigraph or an active subset of epigraph inequalities, followed by deterministic active descent. That method has three practical bottlenecks:

- Whenever a variable touches 0 or 1, epigraph constraints and repair mix clipping and integral compensation, making the local feasibility neighborhood awkward.
- Many lag constraints are nearly tied. Hard epigraph inequality sets give poor model gradients and cause SLSQP to make tiny tangential oscillations.
- The parent is already close to a local optimum on its given dimension. Keeping n=140 constant shape-space gives little opportunity to discover features that cannot be represented in the original cells.

The new primary method changes all three points:

- The logit projection is an inner model of the feasible polytope that uses smooth coordinates and exact one-dimensional normalization shift.
- The objective is a direct differentiable soft-max of the actual np-correlation values. It does not claim to solve a convex relaxation; it is only a smooth surrogate for local/stochastic nonconvex descent.
- The resolution is a search variable with exact transfer operations. Returns from larger grids may have lower exact score on the parent grid, and larger grids may contain better feature space not visible on the parent.

This remains a nonconvex local/global heuristic search. No global optimality claim is made.

1.3 Special features tailored to this subproblem

We retain a useful mathematical identity for interpretation and syntax checking, but the code remains organized so every returned candidate is scored with np.correlate.

For any h, let total = Σ_i h_i, dx=2/n, and for integer lag m=0,...,n-1 define prefix/suffix

P_m = Σ_{i=0}^{m-1} h_i,
S_m = Σ_{i=n-m}^{n-1} h_i,
P_0=0, S_0=0,

and centered autocorlation terms

A_m = Σ_{i=0}^{n-m-1} h_i h_{i+m}.

Then the maximum full cross-correlation with the complement is the exact maximum over positive and negative shifts

max_{lag shifts} (dx Σ_i h_i(1-h_{shifted_i}))
= dx( total - min_{m>=0} [ A_m + min(P_m,S_m) ] ).

In particular if feasible total=n/2,

exact score = 1 - dx * min_m (A_m + min(P_m,S_m)).

The program does not substitute artificial identities wherever the evaluator could be affected. It may use this identity for optional sanity checks, but the primary objective, values, and acceptance use the supplied matrix evaluator.

2. Mathematical specification

2.1 Discrete model and authoritative constraint

Let n=len(h) be any positive integer. Let

dx = 2.0/n.

Constraints are

0 <= h_i <= 1 for every i,
Σ_i h_i = n/2.

The target sum may be a non-integer when n is odd; all operations must support this. The evaluator is

C(h) = max_k corr_k * dx,
corr_k = Σ_i h_i * (1-h_{later_i})

where corr is pygame output of np.correlate(h, 1.0-h, mode="full"). The output index k corresponds to integer lag

δ = k - (n-1).

For a lag δ:

- If δ>0, the positive-lag correlation uses i=0,...,n-1-δ:

  C_δ = dx Σ_{i=0}^{n-1-δ} h_i (1 - h_{i+δ}).

- If δ<0, put m=-δ; the negative-lag correlation uses i=m,...,n-1:

  C_δ = dx Σ_{i=m}^{n-1} h_i (1 - h_{i-m}).

- For δ=0:

  C_0 = dx Σ_i h_i(1-h_i).

The vector C is ordered as δ=-(n-1),...,0,...,n-1 in np-correlate full output.

2.2 Original objective and smooth surrogate

For beta>0 define C_l=dx*corr_l and

J_beta(h) = (1/beta) log Σ_{l=0}^{2n-2} exp(beta C_l).

This satisfies

max_l C_l <= J_beta(h) <= max_l C_l + (1/beta) log(2n-1).

Therefore beta-annealing gives meaningful smooth descent to a true upper-bound objective.

Soft-max weights at h are

w_l = N normalizing Σ_l exp(beta C_l).

Then

∂J_beta/∂h_j = Σ_l w_l ∂C_l/∂h_j,

with the same w_l used in the gradient. The gradient is exactly the weighted sum of the true correlation gradients. Soft values are only a computational surrogate; the final score of every proposed h is exact_score(h)=max_l C_l.

2.3 Analytical h-gradient of any weighted correlation profile

Let w_l be any array of length L=2n-1, usually normalized to sum one. Define weighted objective

K_h(w) = Σ_{l=0}^{L-1} w_l C_l.

Its gradient entries are computed externally by O(n^2) but can be done safely with vector slices over lag indices.

For the k-th profile entry,

δ = k - (n-1),
w_k = profile weight.

The contribution of lag δ to derivative:

- As first product factor: h_j appears whenever the first index range contains j. Equivalent bounded interval in δ:

  -j <= δ <= n-1-j.

- As first complement index q_j=1-h_j, appears whenever the second index equals j. Equivalent

  j-(n-1) <= δ <= j.

Define

A_j = Σ_{k : n-1-j <= k <= 2n-2-j} w_k,
B_j = Σ_{k=0}^{L-1} w_k h_{j - (k-(n-1))},

where h index outside [0,n-1] is treated as zero.

Then

G_rad(w)_j = dx [ (1-h_j) A_j - B_j ].

A practical vectorized computation:

- Compute A from cumulative prefix sums over weights. If W is a cumulative array W[0]=0, W[t]=Σ_{r=0}^{t-1} w_r, then for j=0,...,n-1

  A_j = W[2n-1-j] - W[n-1-j].

- Compute B by looping over nonzero lag weights w_k with lag δ. Split by sign:

  If δ>=0, then contribution affects indices j=δ,...,n-1 with h_{j-δ}:

    B[δ:n] += w_k * h[:n-δ].

  If δ<0 and m=-δ, then contribution affects j=0,...,n-1-m with h_{j+m}:

    B[:n-m] += w_k * h[m:n].

  If C profile values are not configured so this matches np.correlate, use the finite-difference and direct-gradient sanity test in Section 6.

This formula includes boundary restrictions and the finite support of the non-periodic correlation. It is not circular convolution.

2.4 Logit projection and its derivative

Given unconstrained vector z∈R^n, define h(z) by finding c(z) such that

Φ(c)=Σ_i σ(z_i+c) = n/2.

Φ is strictly increasing in c when not zero. It changes bracket bounds as necessary. Define

σ_i = σ(z_i+c), and σ'_i = σ_i(1-σ_i), T=Σ_i σ'_i.

The root solution c(z) gives all h_i strictly inside (0,1) for finite z. The derivative by implicit differentiation is

∂c/∂z_k = -σ'_k / T.

For h_i=σ(z_i+c),

∂h_i/∂z_k = σ'_i [e_i_k - σ'_k / T].

If G_h is a row/column vector of h-space gradient ∂J/∂h, then the chain-rule logit gradient is

G_z_j = G_h_j - σ'_j (Σ_i σ'_i G_h_i) / T.

This is the exact first-order derivative of J_beta(z+c(z)). For finite-difference derivative verification, optionally the program can perturb one coordinate of z. If T is too small due to numerical extreme saturation, use fallback: evaluate repaired project helper/projection and zero gradient or abort that z-stage; it should not happen in normal interior numerics after clipping.
