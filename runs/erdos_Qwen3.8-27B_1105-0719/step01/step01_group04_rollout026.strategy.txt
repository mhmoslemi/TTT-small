1. Approach and rationale

23. Central idea
The supplied parent is already close to the current record. The previous algorithm treats the original epigraph form with many direct overlap inequalities and uses a single hard active-set step plus generic SLSQP. The main bottleneck is that, after a few iterations, the optimizer is essentially parked at the best point accessible from the parent in the given discretization; random perturbations and active-set weights do not reliably escape.

This plan changes the local optimization primitive:
- Replace the full `2n-1` overlap-max docked formulation with an exact equivalent `min` over shifted autocorrelation plus the smaller of the two boundary-prefix sums.
- Optimize a smoothed version of this `min` with exact analytic gradients. The smooth objective is a log-sum-min of only `n` nonnegative lag values, rather than `2n-1` max-overlap values. Smoothness improves the quality of descent directions and permits an annealed optimizer that progressively sharpens toward the true minimax.
- Every candidate is accepted only after evaluation with the authoritative evaluator `max(np.correlate(h, 1-h, mode="full")) * dx`.
- Combine this with dimension-transfer restarts, symmetrization/transformed probes, a small discrete binary global-restart probe, and exact active descent at the end.

Why this may improve the parent:
- The exact identity adds structural information. It reorganizes the task around the worst lag of `autocorrelation + boundary-min` terms. This often makes the active constraints less redundant than the raw pairwise overlap profile.
- Smooth log-sum-min gives gradients from several near-worst lags simultaneously; the active-set midpoint descent uses the exact objective, while the smooth SLSQP stage provides transitions between nonsmooth regions.
- Annealing betas avoids optimizing a purely average objective or a fully nondifferentiable min; high beta makes the surrogate track the minimum for SLSQP without single-constraint gradient collapse.
- Dimension transfers from a good high-dimensional parent can expose smooth directions absent on a coarser fixed grid; a final coarsening step can return smaller grids when they still validate.

This is a local/global-regularized improvement strategy, not a global optimality proof. It uses nonconvex local optimization with exact acceptance.

31. Discrete representation and authoritative objective

Let n = n_points be an even positive integer. Define dx = 2.0/n. The step function represented by h[i], i = 0..n-1 is assumed constant on the finite grid used by the evaluator. The constraints are

    0 <= h[i] <= 1 for all i,
    sum(h) = n/2.

The authoritative evaluation is

    R(h) = max(full_correlation(h, 1 - h)) * dx,

where `full_correlation` is the implementer's call to `np.correlate(h, 1-h, mode="full")`. This is the scalar returned by `exact_score(h)` throughout the algorithm.

32. Exact identity used for optimization

For clarity, do not regard it as replacing the evaluator. It is an exact equivalent for feasible sequences and is used for values, gradients, and descriptors.

Define for each grid-based integer lag m = 0,1,...,n-1:

    P_m = sum_{i=0}^{m-1} h[i],       P_0 = 0,
    S_m = sum_{i=n-m}^{n-1} h[i],     S_0 = 0,
    A_m = sum_{i=0}^{n-m-1} h[i]    * h[i+m],

with `A_0 = sum_i h[i]^2`. Define the boundary term

    B_m = min(P_m, S_m).

Let `L_m = dx * (A_m + B_m)`. Let `total = sum(h)` be the actual sum of the supplied vector. Then for any h not only feasible,

    R_exact_formula(h) = dx * (total - min_{m=0}^{n-1} (A_m + B_m)).

Equivalently, if h is feasible with total = n/2, then dx * total = 1 and

    R(h) = 1 - min_{m=0}^{n-1} L_m.

Derivation, useful for verifying indexing:
For absolute shift m > 0, the positive-lag overlap is

    g_pos(m) = dx * sum_{i=0}^{n-1-m} h[i] * (1 - h[i+m])
             = dx * (sum_{i=0}^{n-1-m} h[i] - A_m).

Since `sum_{i=0}^{n-1-m} h[i] = total - S_m`,

    g_pos(m) = dx * (total - S_m - A_m).

The negative-lag overlap with the same absolute lag is

    g_neg(m) = dx * sum_{i=m}^{n-1} h[i] * (1 - h[i-m])
             = dx * (total - P_m - A_m).

Taking the maximum over the two signs gives

    max(g_pos(m), g_neg(m))
    = dx * [total - A_m - min(P_m, S_m)].

For m = 0, the only correlation is `dx*(total - A_0)`, and the formula with `B_0 = 0` is identical. The global maximum across all lags is therefore `dx * (total - min_m(A_m + B_m))`. Use the direct correlation evaluator as acceptance protection in case indexing is wrong.
