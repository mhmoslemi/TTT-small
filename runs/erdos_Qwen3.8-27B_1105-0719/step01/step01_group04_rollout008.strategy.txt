Objective and current bottleneck

Let h be the discrete vector supplied by the previous parent construction. The authoritative score used throughout this plan is exactly

    R(h) = max_{full shift r} dx * sum_i h[i] * (1 - h[i + offset_r]),

    C5 = max(np.correlate(h, 1.0 - h, mode="full")) * dx.

The previous strategy treats the problem by minimizing a nonlinear epigraph formulation using SLSQP: nonoverlap-overlap maxima are added as raw nonlinear constraints to a semi-defimited variable t. A small weighted-gradient active descent is then used for polishing. The failure mode that this new plan attacks is that SLSQP can become trapped in nonsmooth active-constraint regions: it either moves along a single active lag, becomes poorly scaled, or repeatedly searches the same tangent directions after the active set changes. Generic Gaussian perturbations are then a weak escape mechanism.

Central replacement: trust-region linearization / model-based nonlinear programming

The new core algorithm is a trust-region stochastic-step method for a nonconvex minimax objective. At every iteration we:
  1. form exact values of all full-lag objective terms and exact exact derivatives of those same terms at the current point;
  2. solve a convex model problem for a proposed new h: it minimizes a linearization of the best achievable maximum, plus quadratic movement regularization, with exact box and integral constraints;
  3. evaluates the full model proposed step backtracking α∈{1, 0.75, 0.5, ...}; the non-linear terms are only accepted after they truly lower the original score, never after surrogate success alone;
  4. if no descent is possible, shrink/strength the step acceptance radius or constraint set and skip; or switch to the active-slope method used independently at the end; if a descent occurs, continue.

This differs substantially from the earlier approach in that it treats the future non-oriented number against model sensitivities using an explicit model fitting, giving a generic active obstacle at the nonlinear scale. It also uses a strong verification capable of solving global full lag linear programs embellished with regression, step width backsliding.
