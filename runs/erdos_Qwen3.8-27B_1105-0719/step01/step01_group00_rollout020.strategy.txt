1. Approach and rationale

1.1 Central idea

The supplied program is essentially a smoothed-maximization pipeline: it optimizes a log-sum-exp approximation of the maximum lag value, projects or repairs the integral constraint, and then does a few sub-gradient-style polish steps. That is useful globally, but it is not the strongest way to move away from a near-optimal point. At a good point the only thing that matters is the very small set of correlations that are already at the maximum, or very close to it. A better local engine should ask the true nonconvex inequality system directly:

    minimize the scalar epigraph variable t,
    subject to t >= dx * R_r(h) for the presently relevant lags r,
    with 0 <= h_i <= 1 and the exact integral constraint.

Here R_r is the raw finite-support correlation at evaluator lag r. The method proposed below keeps candidates accepted only by the exact evaluator, but it drives every serious local improvement through an exact epigraph subproblem using selected constraints. This is materially different from the supplied parent program, and it avoids the systematic bias of optimizing a fixed log-sum-exp surrogate. The surrogate is still used only as a warm-start/search generators mechanism, never as the basis for acceptance.

The main improvement candidates are then searched in three coordinated ways:

1. Symmetric pair parametrization. For many lengths, especially even lengths, optimizing the reduced variables q_i with h_{n-1-i}=1-q_i makes the integral constraint automatic and removes an equality constraint from local solvers. This gives a faster, better-conditioned exact optimization model. The symmetric subspace is not claimed to contain the global optimum. Therefore it is only a productive engine, not the final authority.

2. Full-variable exact epigraph polish. The best points produced in the symmetric subspace are reconverted to full vectors and polished with full-variable epigraph subproblems that still use the true correlation inequalities and the exact sum constraint. This protects against the symmetric restriction excluding a better asymmetric solution.

3. Multiresolution continuation. parent points are transferred to several nearby resolutions, especially a smaller resolution that is preferred and a somewhat higher resolution that gives more fractional flexibility. Because each discrete score is computed exactly on the actual returned vector, lower scores at other resolutions can be accepted, while smaller vectors are preferred if scores are effectively tied. When increasing resolution, the mathematically smaller resolution outcome is retained as a fallback if no meaningful score improvement is obtained.

1.2 What bottleneck this targets

The supplied result is within about 4e-5 of the target. Large global smooth searches are unlikely to move it once the active correlation average is very tight. An exact active-constraint method focuses directly on the binding constraints, reducing the surrogate error that would otherwise shift the search away from the true minimax neighborhood. The exact epigraph solver also permits hidden-violation re-expansion, which closes a gap left by methods that only follow a smooth aggregate of all correlations.

1.3 Clearly separated facts and hypotheses

Facts:

- The returned exact score is always max over all 2n-1 lags of dx times the raw np.correlate value. Hand-coded derivatives are only used to represent constraints and gradients; final acceptance always recomputes the exact result.
- The finite-support correlation has different overlap lengths at the boundaries, so the objective is not a simple 1 - autocorrelation identity and must retain the same boundary-lag structure as the evaluator.
- The full discrete problem is bilinear and nonconvex, so local solvers provide local minima only, not certified global lower bounds on the true continuous constant unless separately verified.

Hypotheses:

- There is likely a local move, possibly after changing n slightly or leaving the symmetric subspace, that improves below parent. This plan is designed to find such a move; it does not prove that one exists.
- Complement-palindromic feasible points are often good representatives because the problem is invariant under the reflected-complement transformation. This is a working hypothesis, not a theorem. The method nonetheless includes full-variable relaxation to address asymmetricTimeQuadr

Limitations:

- The epigraph subproblem is nonconvex because each exact correlation is bilinear. It is treated as a local nonlinear-program subproblem, not as an NP-hard global relaxation.
- Sufficient active lags may require too many constraints for a large n if not consolidated, so the implementation must adaptively cap active constraints based on the actual remaining time.
- A fine resolution can find a lower discrete score while returning no mathematically smaller-point advantage. Therefore the output rule must primarily optimize score and only prefer smaller lengths when scores are essentially equal.

2.1 Variables and exact evaluator

Let h be a one-dimensional real vector of length n. Define

    dx = 2.0 / n

The discrete feasible set is

    0 <= h_i <= 1,
    sum_i h_i = n / 2.

The authoritative objective is

    score(h) = max(np.correlate(h, 1.0 - h, mode="full")) * dx.

Let the raw evaluator correlation array be

    A_eval(r),      r = 0, 1, ..., 2n-2.

The implementation will use a hand-computed internal array

    A_internal(r)

with the convention

    A_internal(s) =
        sum over b of h[b] * (1 - h[b + (s - (n - 1))]),

where the valid b indices are

    b_lo = max(0, s - (n - 1))
    b_hi = min(n - 1, 2n - 2 - s)

if b_lo <= b_hi; otherwise the sum is zero.

Equivalent offset form: for internal index s, let

    d = s - (n - 1)

and sum over b satisfying 0 <= b < n and 0 <= b + d < n. Each valid pair contributes

    h[b] * (1 - h[b + d]).

Derivative convention for that internal raw value: for every valid base b, j = b + d,

    partial A_internal(s) / partial h[b] += 1 - h[j]
    partial A_internal(s) / partial h[j] -= h[b]

If d = 0 and b = j, the two contributions combine to

    partial A_internal(s) / partial h[b] = 1 - 2 h[b].

Scale constraints use

    C_internal(s) = dx * A_internal(s).
