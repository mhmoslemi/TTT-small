output[n-1+k] = sum_i h[i] * (1-h[i+k]) for i such that 0 ≤ i < n and 0 ≤ i+k < n.

So for shift k (which can be negative, zero, or positive):
R(k) = sum_{i: 0≤i<n, 0≤i+k<n} h[i] * (1-h[i+k])

And C₅ = dx * max_k R(k).

Now, when we change h[p] -= τ and h[q] += τ:
The terms in R(k) that change are those where i = p or i+k = p (i.e., i = p-k) or i = q or i+k = q (i.e., i = q-k).

For a given k:
- Term at i=p: h[p]*(1-h[p+k]) → (h[p]-τ)*(1-h[p+k]), change = -τ*(1-h[p+k]) [if 0≤p+k<n]
- Term at i=p-k: h[p-k]*(1-h[p]) → h[p-k]*(1-(h[p]-τ)), change = +τ*h[p-k] [if 0≤p-k<n]
- Term at i=q: h[q]*(1-h[q+k]) → (h[q]+τ)*(1-h[q+k]), change = +τ*(1-h[q+k]) [if 0≤q+k<n]
- Term at i=q-k: h[q-k]*(1-h[q]) → h[q-k]*(1-(h[q]+τ)), change = -τ*h[q-k] [if 0≤q-k<n]

So ΔR(k) = τ * [h[p-k] - (1-h[p+k]) + (1-h[q+k]) - h[q-k]]
(with the convention that out-of-range terms are 0)

This is LINEAR in τ! (Not quadratic, because p ≠ q and we're looking at distinct positions.)

Wait, but what if p+k = q? Then the term h[p]*(1-h[q]) becomes (h[p]-τ)*(1-(h[q]+τ)) = h[p]*(1-h[q]) - τ*(1-h[q]) - τ*h[p] + τ². So there's a τ² term!

Similarly if q+k = p.

So for most k, ΔR(k) is linear in τ. For k = q-p and k = p-q, there's an additional τ² term.

Specifically:
- For k = q-p (assuming q > p): the term at i=p is h[p]*(1-h[q]), which becomes (h[p]-τ)*(1-(h[q]+τ)).
  Additional change: -τ² (the cross term)
- For k = p-q (negative): similarly.

So R(k + τ) is at most quadratic in τ, and the max over k is at most the max of convex quadratics, which is convex.

For the line search, since f(τ) is convex on [0, cap], we can use:
1. Evaluate f(0) = current max
2. Evaluate f(cap) and f(cap/2)
3. Use ternary search or golden section to find the minimum

But since most of the time f is piecewise linear (with at most 2 quadratic pieces), we can be even faster.

```python
    best_c5 = compute_c5(h)
    
    for round in range(max_rounds):

        one_minus_h = 1.0 - h

        current_max = np.max(corr) * dx

            for q in range(p+1, n):

                cap = min(h[p], 1.0 - h[q])
                if cap < 1e-10:
                    continue

                cap2 = min(h[q], 1.0 - h[p])

                best_val = current_max

                for direction in [(p, q, cap), (q, p, cap2)]:
                    src, dst, c = direction

                        if c5_new < best_val - 1e-12:

                    improved = True

            break
        # Recompute
    return h, compute_c5(h)
```

```python
def simulated_annealing(h0, n, t_start, t_end, n_iter, rng):
    h = h0.copy()
    c5 = compute_c5(h)
    best_h = h.copy()
    best_c5 = c5
    
    for i in range(n_iter):
        # Temperature (exponential cooling)
        t = t_start * (t_end / t_start) ** (i / n_iter)
        
        # Choose a random move: transfer from p to q
        p, q = rng.choice(n, 2, replace=False)
        cap = min(h[p], 1.0 - h[q])
        if cap < 1e-10:
            continue
        tau = rng.uniform() * cap
        # Or: tau = cap (full transfer, i.e., swap)
        
        h[p] -= tau
        h[q] += tau
        c5_new = compute_c5(h)
        delta = c5_new - c5
        
        if delta < 0 or rng.uniform() < np.exp(-delta / t):
            c5 = c5_new
            if c5 < best_c5:
                best_c5 = c5
                best_h = h.copy()
        else:
            h[p] += tau
            h[q] -= tau
    
    return best_h, best_c5
```

```python
import numpy as np
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)

def project_feasible(y, n):
    """Project y to [0,1]^n with sum = n/2."""
    target = n / 2.0
    h = np.clip(y, 0.0, 1.0)
    # Bisection to get exact sum
    lo, hi = -2.0, 2.0
    for _ in range(60):
        mid = (lo + hi) / 2.0
        s = np.sum(np.clip(y - mid, 0.0, 1.0))
        if s > target:
            lo = mid
        else:
            hi = mid
    h = np.clip(y - (lo + hi) / 2.0, 0.0, 1.0)
    # Fix residual
    residual = target - np.sum(h)
    if abs(residual) > 1e-10:
        # Distribute among interior points
        interior = np.where((h > 1e-8) & (h < 1.0 - 1e-8))[0]
        if len(interior) > 0:
            adj = residual / len(interior)
            h[interior] = np.clip(h[interior] + adj, 0.0, 1.0)
    return h

def greedy_pair_search(h, n, max_rounds=20, rng=None):
    """Greedy local search: try all pairs, accept if improves."""
    c5 = compute_c5(h)
    for _ in range(max_rounds):
        improved = False
        improved = _greedy_sweep(h, n, c5)
        if not improved[0]:
            break
        c5 = improved[1]
    return h, compute_c5(h)

def _greedy_sweep(h, n, c5_current):
    """One sweep over all pairs. Returns (improved, new_c5)."""
    any_improved = False
    for p in range(n):
        for q in range(p + 1, n):
            # Try swap
            h[p], h[q] = h[q], h[p]
            c5_new = compute_c5(h)
            if c5_new < c5_current - 1e-12:
                c5_current = c5_new
                any_improved = True
            else:
                h[p], h[q] = h[q], h[p]
    return (any_improved, c5_current)
```
