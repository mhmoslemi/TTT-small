Note that corr_neg[k] = sum_{n=0}^{n_pts-1-k} h[n]*(1-h[n+k]) = A(k).
And corr_pos[k] = B(k).

So C₅ = max(max_k corr_pos[k], max_k corr_neg[k]) * dx.

When h[i] changes from 1 to 0:
- corr_pos[k]: the term at position n=i is h[i+k]*(1-1) = 0 → h[i+k]*(1-0) = h[i+k]. Change: +h[i+k]. (Valid if i+k < n_pts)
  Also, position n where n+k=i, i.e., n=i-k: h[i]*(1-h[i-k]) = 1*(1-h[i-k]) → 0. Change: -(1-h[i-k]). (Valid if i-k ≥ 0)
  
- corr_neg[k]: the term at position n=i is h[i-k]*(1-1) = 0 → h[i-k]*(1-0) = h[i-k]. Change: +h[i-k]. (Valid if i-k ≥ 0)
  Also, position n where n-k=i, i.e., n=i+k: h[i]*(1-h[i+k]) = 1*(1-h[i+k]) → 0. Change: -(1-h[i+k]). (Valid if i+k < n_pts)

When h[j] changes from 0 to 1:
- corr_pos[k]: position n=j: h[j+k]*(1-0) = h[j+k] → h[j+k]*0 = 0. Change: -h[j+k]. (Valid if j+k < n_pts)
  Position n where n+k=j, n=j-k: h[j]*(1-h[j-k]) = 0 → 1*(1-h[j-k]). Change: +(1-h[j-k]). (Valid if j-k ≥ 0)

- corr_neg[k]: position n=j: h[j-k]*(1-0) = h[j-k] → h[j-k]*0 = 0. Change: -h[j-k]. (Valid if j-k ≥ 0)
  Position n where n-k=j, n=j+k: h[j]*(1-h[j+k]) = 0 → 1*(1-h[j+k]). Change: +(1-h[j+k]). (Valid if j+k < n_pts)

So for a swap (i: 1→0, j: 0→1), the change in corr_pos at lag k is:
Δcorr_pos[k] = (h[i+k] - (1-h[i-k])) * [i+k < n and i-k ≥ 0] (from i's contribution, with care for boundaries)
              + (-(h[j+k]) + (1-h[j-k])) * [j+k < n and j-k ≥ 0] (from j's contribution)

- Change from h[i]: 1→0:

So Δcorr_neg[k] from i: +h[i-k] (if i-k ≥ 0) - (1-h[i+k]) (if i+k < n)
And Δcorr_neg[k] from j: -h[j-k] (if j-k ≥ 0) + (1-h[j+k]) (if j+k < n)

Total: Δcorr_neg[k] = (h[i-k] - h[j-k]) - (1-h[i+k] - (1-h[j+k]))

def fast_swap_delta(h, i, j, n):
    delta = np.zeros(2*n-1)
    # Positive lags
    k_range = np.arange(1, n)
    # i+k valid where i+k < n, i.e., k < n-i
    mask_ik = (i + k_range < n)
    # i-k valid where i-k >= 0, i.e., k <= i
    mask_ik2 = (i - k_range >= 0)
    mask_jk = (j + k_range < n)
    mask_jk2 = (j - k_range >= 0)
    
    d_pos = np.zeros(n-1)
    d_pos[mask_ik] += h[i + k_range[mask_ik]]
    d_pos[mask_ik2] -= (1.0 - h[i - k_range[mask_ik2]])
    d_pos[mask_jk] -= h[j + k_range[mask_jk]]
    d_pos[mask_jk2] += (1.0 - h[j - k_range[mask_jk2]])
    delta[n:] = d_pos  # indices n to 2n-2
    
    # Negative lags
    d_neg = np.zeros(n-1)
    d_neg[mask_ik2] += h[i - k_range[mask_ik2]]
    d_neg[mask_ik] -= (1.0 - h[i + k_range[mask_ik]])
    d_neg[mask_jk2] -= h[j - k_range[mask_jk2]]
    d_neg[mask_jk] += (1.0 - h[j + k_range[mask_jk]])
    delta[:n-1] = d_neg  # indices 0 to n-2
    
    return delta

- If delta[p] ≥ 0, then new_max ≥ prof[p] + delta[p] ≥ cur_max, so this swap doesn't help

Wait, that's not quite right. Even if delta[p] ≥ 0, another position q might have prof[q] + delta[q] < cur_max, but that doesn't help since new_max = max over all positions.

The key insight: new_max < cur_max requires BOTH:
1. At the position(s) where prof = cur_max, delta < 0 (so those positions decrease below cur_max)
2. No other position increases to or above cur_max

Condition 1 is a quick filter. Let me use it:
- Find positions where prof == cur_max (or within epsilon)
- For a swap to potentially improve, we need delta < 0 at ALL those positions (or at least, the max of prof+delta must be < cur_max)

Actually, the simplest fast filter: if any position with prof[p] = cur_max has delta[p] ≥ 0, then new_max ≥ cur_max (since prof[p] + delta[p] ≥ cur_max). So we can skip these swaps.

But this only helps if there are few positions at the max. In practice, there might be many.

Let me just go with the O(n) delta computation and np.max. It should be fast enough with numpy.

Let me also consider: for the hill climbing, I'm doing n²/4 = 4900 (for n=140) evaluations per pass, each O(n) = O(140). Total: 686K operations per pass. With numpy vectorization, each operation is a vector op on arrays of length ~140. So maybe 5-10 microseconds per swap evaluation. Total per pass: ~50ms. 1000 passes: 50s. That's a bit much.

I can speed up by:
1. Only considering a random subset of swaps per pass (not all n²/4)
2. Using "first improvement" instead of "best improvement" (stop at first improving swap)
3. Reducing the number of passes

Let me use "first improvement" with a random order of swaps. This is O(n²) expected per pass (since we stop early), and each evaluation is O(n). So O(n³) worst case but typically much faster.

Actually, for "first improvement" with random order:
- Expected number of evaluations before finding an improvement depends on the fraction of improving swaps.
- Near a local optimum, this fraction is small, so we might evaluate all n²/4 swaps.
- Far from a local optimum, we find improvements quickly.

So the total cost of a full hill climb (from random to local optimum) is O(n³) in the worst case, but typically much less.

For n=140: worst case is 4900 * 140 = 686K operations ≈ 10-50ms with numpy. A full climb might take 100-1000 passes ≈ 1-5s. That's manageable.

import numpy as np
from scipy.optimize import minimize
import time

def exact_objective(h):
    n = len(h)
    if n == 0:
        return float('inf')
    dx = 2.0 / n
    profile = np.correlate(h, 1.0 - h, mode='full') * dx
    return float(np.max(profile))

def project_box_sum(h, target=None):
    n = len(h)
    h = np.array(h, dtype=np.float64)
    h = np.nan_to_num(h, nan=0.0, posinf=1.0, neginf=0.0)
    if target is None:
        target = n / 2.0
    h = np.clip(h, 0.0, 1.0)
    for _ in range(500):
        s = np.sum(h)
        diff = s - target
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            mask = h > 0
            cnt = int(np.sum(mask))
            if cnt == 0:
                break
            step = min(diff / cnt, np.min(h[mask]))
            h[mask] -= step
        else:
            mask = h < 1.0
            cnt = int(np.sum(mask))
            if cnt == 0:
                break
            step = min(-diff / cnt, 1.0 - np.max(h[mask]))
            h[mask] += step
    return h

def fast_swap_delta(h, i, j, n):
    delta = np.zeros(2 * n - 1)
    k_range = np.arange(1, n)
    mask_ik = (i + k_range < n)
    mask_ik2 = (i - k_range >= 0)
    mask_jk = (j + k_range < n)
    mask_jk2 = (j - k_range >= 0)
    d_pos = np.zeros(n - 1)
    d_pos[mask_ik] += h[i + k_range[mask_ik]]
    d_pos[mask_ik2] -= (1.0 - h[i - k_range[mask_ik2]])
    d_pos[mask_jk] -= h[j + k_range[mask_jk]]
    d_pos[mask_jk2] += (1.0 - h[j - k_range[mask_jk2]])
    delta[n:] = d_pos
    d_neg = np.zeros(n - 1)
    d_neg[mask_ik2] += h[i - k_range[mask_ik2]]
    d_neg[mask_ik] -= (1.0 - h[i + k_range[mask_ik]])
    d_neg[mask_jk2] -= h[j - k_range[mask_jk2]]
    d_neg[mask_jk] += (1.0 - h[j + k_range[mask_jk]])
    delta[:n - 1] = d_neg
    return delta

def binary_hill_climb_first(b, max_passes=2000, rng_seed=0):
    n = len(b)
    cur = b.copy().astype(np.float64)
    prof = np.correlate(cur, 1.0 - cur, mode='full')
    cur_max = np.max(prof)
    rg = np.random.RandomState(rng_seed)
    for _ in range(max_passes):
        ones = np.where(cur == 1.0)[0]
        zeros = np.where(cur == 0.0)[0]
        found = False
        order = rg.permutation(len(ones) * len(zeros))
        for idx in order:
            ii = int(idx) // len(zeros)
            jj = int(idx) % len(zeros)
            i = ones[ii]
            j = zeros[jj]
            delta = fast_swap_delta(cur, i, j, n)
            new_max = np.max(prof + delta)
            if new_max < cur_max - 1e-12:
                prof = prof + delta
                cur[i] = 0.0
                cur[j] = 1.0
                cur_max = new_max
                found = True
                break
        if not found:
            break
    return cur, cur_max * (2.0 / n)

def binary_hill_climb_best(b, max_passes=200, rng_seed=0):
    n = len(b)
    cur = b.copy().astype(np.float64)
    prof = np.correlate(cur, 1.0 - cur, mode='full')
    cur_max = np.max(prof)
    rg = np.random.RandomState(rng_seed)
    for _ in range(max_passes):
        ones = np.where(cur == 1.0)[0]
        zeros = np.where(cur == 0.0)[0]
        best_imp = 0.0
        best_i, best_j = -1, -1
        best_delta_arr = None
        for i in ones:
            for j in zeros:
                delta = fast_swap_delta(cur, i, j, n)
                new_max = np.max(prof + delta)
                imp = cur_max - new_max
                if imp > best_imp:
                    best_imp = imp
                    best_i, best_j = i, j
                    best_delta_arr = delta
        if best_i < 0:
            break
        prof = prof + best_delta_arr
        cur[best_i] = 0.0
        cur[best_j] = 1.0
        cur_max = np.max(prof)
    return cur, cur_max * (2.0 / n)

def binary_sa(b, n_iter=5000, T_mult=0.02, rng_seed=0):
    n = len(b)
    cur = b.copy().astype(np.float64)
    prof = np.correlate(cur, 1.0 - cur, mode='full')
    cur_max = np.max(prof)
    cur_c = cur_max * (2.0 / n)
    best = cur.copy()
    best_c = cur_c
    rg = np.random.RandomState(rng_seed)
    T0 = T_mult * cur_max
    T1 = 0.001 * T0
    for t in range(n_iter):
        frac = t / float(n_iter)
        T = T0 * (T1 / T0) ** frac
        ones = np.where(cur == 1.0)[0]
        zeros = np.where(cur == 0.0)[0]
        i = ones[rg.randint(len(ones))]
        j = zeros[rg.randint(len(zeros))]
        delta = fast_swap_delta(cur, i, j, n)
        new_prof = prof + delta
        new_max = np.max(new_prof)
        new_c = new_max * (2.0 / n)
        if new_c < cur_c or (T > 1e-10 and rg.random() < np.exp(-(new_c - cur_c) / (T * (2.0 / n)))):
            prof = new_prof
            cur[i] = 0.0
            cur[j] = 1.0
            cur_max = new_max
            cur_c = new_c
            if cur_c < best_c:
                best_c = cur_c
                best = cur.copy()
    return best, best_c

def random_balanced_binary(n, rng):
    b = np.zeros(n)
    idx = rng.choice(n, n // 2, replace=False)
    b[idx] = 1.0
    return b

def transfer_to_size(parent, target_n):
    n = len(parent)
    if n == target_n:
        return parent.copy()
    x_old = (np.arange(n) + 0.5) / n
    x_new = (np.arange(target_n) + 0.5) / target_n
    new_h = np.interp(x_new, x_old, parent)
    return project_box_sum(new_h)

def binary_threshold(h):
    n = len(h)
    if n % 2 != 0:
        return None
    target = n // 2
    idx = np.argsort(-h)
    b = np.zeros(n)
    b[idx[:target]] = 1.0
    return b

def kick_binary(b, n_kicks, rng):
    cur = b.copy()
    for _ in range(n_kicks):
        ones = np.where(cur == 1.0)[0]
        zeros = np.where(cur == 0.0)[0]
        i = ones[rng.randint(len(ones))]
        j = zeros[rng.randint(len(zeros))]
        cur[i] = 0.0
        cur[j] = 1.0
    return cur

def continuous_refine(h_bin, n_iterations=2000, rng_seed=0):
    n = len(h_bin)
    cur = h_bin.astype(np.float64).copy()
    cur_c = exact_objective(cur)
    rg = np.random.RandomState(rng_seed)
    dx = 2.0 / n
    for t in range(n_iterations):
        frac = t / float(n_iterations)
        scale = 0.1 * (1.0 - frac) + 0.01
        i, j = rg.choice(n, 2, replace=False)
        amt = scale * (0.3 + 0.7 * rg.random())
        if amt > cur[j] * 0.9:
            amt = cur[j] * 0.85
        if amt > (1.0 - cur[i]) * 0.9:
            amt = max(0.01, (1.0 - cur[i]) * 0.85)
        if amt < 0.003:
            continue
        cur[i] += amt
        cur[j] -= amt
        c = exact_objective(cur)
        if c < cur_c - 1e-12:
            cur_c = c
        else:
            temp = 0.005 * (1.0 - frac) + 0.0005
            if rg.random() < np.exp(-(c - cur_c) / temp):
                cur_c = c
            else:
                cur[i] -= amt
                cur[j] += amt
    return cur, cur_c

def slsqp_smooth(h0, tau, maxiter=100):
    n = len(h0)
    dx = 2.0 / n

    def obj_grad(x):
        r = np.correlate(x, 1.0 - x, mode='full')
        r_max = np.max(r)
        shifted = np.clip((r - r_max) / tau, -400.0, 400.0)
        exp_s = np.exp(shifted)
        log_sum = np.log(np.sum(exp_s))
        value = dx * (r_max + tau * log_sum)
        weights = exp_s / np.sum(exp_s)
        grad = np.zeros(n)
        for i in range(2 * n - 1):
            k = i - (n - 1)
            w = weights[i]
            if w < 1e-14:
                continue
            if k == 0:
                grad += w * (1.0 - 2.0 * x)
            elif k > 0:
                grad[k:n] += w * (1.0 - x[0:n-k])
                grad[0:n-k] -= w * x[k:n]
            else:
                a = -k
                grad[0:n-a] += w * (1.0 - x[a:n])
                grad[a:n] -= w * x[0:n-a]
        grad *= dx
        return value, grad

    def eq_fun(x):
        return np.sum(x) - n / 2.0

    def eq_jac(x):
        return np.ones(n)

    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': eq_fun, 'jac': eq_jac}]
    try:
        res = minimize(obj_grad, h0, method='SLSQP', jac=True, bounds=bounds,
                       constraints=cons, options={'maxiter': maxiter, 'ftol': 1e-12})
        return project_box_sum(res.x)
    except Exception:
        return None
