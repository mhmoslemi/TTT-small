1. Approach and rationale

1.1 Central idea

The computation should be treated as a finite-dimensional nonconvex minimax problem and solved in two layers:

1. A global or semi-global layer creates many genuinely different feasible step functions using low-dimensional generators, random feasible mutations, exact-sum pairwise moves, symmetrized variants, and dimension transfers. This layer is responsible for finding a different basin.
2. A local layer uses a first-order trusted-region linear-programming subproblem. At the current vector, the exact bilinear correlation values are linearized for the currently maxing or near-maxing lags, and the resulting problem “minimize a scalar t subject to linearized correlation upper bounds, box bounds, exact mass, and a trust box” is an ordinary linear program. The LP is convex and gives a principled active-set descent move. The candidate is accepted or rejected only by re-evaluating the original exact objective.

This is substantively different from a single smooth log-sum-exp, fixed-beta SLSQP, or a pure epigraph nonlinear solver. The new method uses the evaluator with no approximation for acceptance, but uses linearizations only as temporary search directions. Its main potential advantage is avoiding the basin and beta-bias problems of blended survivals. It is not exact over a local set due the nonconvex bilinear exact products. It returns locally and heuristically improved constructions, with the supplied parent as a guaranteed fallback if the supplied parent is feasible.

1.2 Why this could improve the supplied construction

The parent vector n=126 obtained by previous methods reaches around 0.380938. The current target bound is 0.38085, so a relative absolute-only improvement of about 1.4e-5 is required. The trusted direction LP directly recognizes active correlations and gives a linear search direction that strictly decreases many of them close to the current tangent and not a non-convergent smoothed average. 1.3 Limitations and claims

- The nonconvexity means there is no claimed global optimum.
- A linearized LP model may decrease the tangent approximation but increase exact values due truncation or bias hidden, so trust widths and exact reevaluation are mandatory.
