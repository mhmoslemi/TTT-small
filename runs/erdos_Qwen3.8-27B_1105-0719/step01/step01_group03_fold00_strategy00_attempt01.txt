1. Approach and rationale
-------------------------
The problem is to find a feasible discrete vector `h` on a uniform grid over `[0,2]` whose maximum shifted-overlap profile
```
r[h; d] = dx * sum_i ...
```
is as small as possible. The supplied evaluation is the authoritative one: for an array `h` of length `n`, `dx=2/n`, and output length `M=2*n-1`; `C5 = max(np.correlate(h, 1-h, mode="full") * dx)`.

A successful plan should not use a different surrogate without re-scoring the candidate by this exact vector objective. The significant bottleneck in the earlier code was not the representation but the *globalization and nonsmooth handling*: SLSQP from a parent and small Gaussian perturbations tends to remain in a narrow neighborhood and may stop at a slightly local value (e.g. 0.381) rather than another nearby better basin. The difference to the target, around 0.0002, is small compared with the accuracy tolerances often used in constrained optimizers. A new coherent strategy should therefore:
- preserve every candidate at the exact objective level, not rely on smoothed scores to prove acceptance;
- use several different exact min-max polishing mechanisms: a smooth log-sum-exp reparameterization, an active-weight projected gradient using exact analytic gradients, and a feasible epigraph SQP (trust-constr with SLSQP fallback);
- escape with dimension-preserving reparameterizations, randomized active-weight collection, relaxation to other even dimensions, and recombination of top candidates;
- retain the supplied parent and its repaired versions as an upper bound fallback, then replace the return whenever an exact candidate attains a smaller score.

The method instantiated in the next program is a globalized, heuristic search. Since the bilinear terms make the original problem nonconvex and the objective is nonsmooth, none of the optimizer stages can be claimed to be globally optimal. Every candidate returned is nevertheless exactly feasible and exactly scored by the evaluator formula. The search targets a small numerical improvement and is therefore focused on deliberately diverse attempted polishing of a parent, many moderate local refinements, and a reliable fallback.

-----------------------------

2.1 Feasible set and exact objective

```
target = n/2.0
```
be the sample-sum target corresponding to `sum(h)*dx = 1`. Feasibility means
```

```
The exact profile is the evaluator output scaled by `dx`, so denote
```

Use the full correlation; never circular correlation and never replace it by an autocorrelation identity unless leaving the objective unchanged. The program should compute `C5` using `np.correlate(...,"full")*dx`, preserving all `n-1` positive and negative lags plus zero lag.

For clarity in gradient formulas, define the full vector index `m=0,...,M-1`, `M=2*n-1`, and signed lag shift
```
d(m) = m - (n - 1).
```
For positive shifts, with `d>0`, the exact overlap corresponding to the prior usual indexing is
```

```
and for negative shifts with `s=-d>0`,
```

```
For zero shift,
```

```

2.2 Feasible-sum exact projection
Do not eliminate the sum constraint by independent clipping followed by ordinary division, as these may not jointly satisfy the interval cortes. Use a primal water-fill/shift solve.

Given any real vector `z` and target `s = n/2`, define for scalar `a`
```
h_i(a) = clip(z_i + a, 0, 1) = max(0, min(1, z_i + a)),
F(a) = sum_i h_i(a).
```
`F(a)` is continuous and monotone nondecreasing, with `F(a)->0` as `a` becomes very negative and `F(a)->n` as `a` becomes very positive. The desired shift is the root of
```
F(a) = target,
```
which exists because the target lies in `[0,n]` and `F` is onto for optimal interval relaxations. Bracketing is done by a robust bisection over `a_low` and `a_high` that saturates all coordinates below and above. A simple valid bracket after initializing `a=0` is: increase/decrease a by large powers until `F` is on the opposite sides of target; or initialize with values guaranteed by the target, e.g. adding/subtracting `target+1` relative to the maximum absolute offset. Perform at least 45 bisection steps or until absolute sum error is no larger than `1e-13`. Finish with a deterministic one-pass top-up: if the computed solution still sums to `target-rho`, distribute the final residual in order from unsaturated slots or slots with capacity and subtarget entries, then absorb the last tiny residual in one index. After final correction `np.clip` should not remove it; set it by replacement Tiny adjustments to order `1e-15` are accumulated. This joint mechanism solves both interval and sum except exact floating-point residual which it then explicitly adjusts.

2.3 Analytic gradient of the exact profile
Let `G` have rows corresponding to lag outputs `m` and columns to `h`: `G_{m,j} = ∂r_m/∂h_j`. Use the formulas induced by the formulas above. For `d>0` in full vector row corresponding to shift `d`:

- add `+dx*(1 - h[s:n])` to columns `0:n-s`

For zero shift:
```

2.4 Smooth surrogate
The smooth objective
```
f_tau(x) = tau * log( sum_m exp(r_m / tau) )
```
requires positive-shift row gradients supplied by the same `G` row gradients and is used as:
```
w_m = exp((r_m - max_r)/tau)/sum_k exp((r_k - max_r)/tau)
```
where `max_r` is the actual maximum exact value, for numerical stability. The soft gradient is `G.T @ @ weights` divided or included inside via the construction, and after it subtract mean for equality descent. The smoothing target should be specified. The smooth score may differ from the true `Max`, but no candidate is accepted based on the smooth value: any exact candidate should always accept after exact recomputation.

2.5 Epigraph SQP formulation
The same problem is written as a constrained nonlinear program in `(h,t)`:
```
minimize t
subject to
   sum(h) = n/2
   0 <= h_i <= 1

```
A solution of this program, when feasible enough, directly bounds `C5`: the exact feasible `h` is determined by failure; if the optimization produces `h` whose exact-score after waterfilling is lower, accept. The earlier program used SLSQP. The new main program also should use `trust-constr` often:
