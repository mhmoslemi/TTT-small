```python
def compute_swap_delta(h, i, j, n):
    """
    h: binary array of length n
    i: position with h[i]=1 (will become 0)
    j: position with h[j]=0 (will become 1)
    Returns delta array of length 2n-1
    """
    delta = np.zeros(2 * n - 1)
    for m in range(2 * n - 1):
        ell = m - (n - 1)
        d = 0.0
        
        # i as first index: valid if 0 <= i+ell <= n-1
        if i + ell >= 0 and i + ell < n:
            # h'[i+ell]
            if i + ell == j:
                d += 1.0
            elif i + ell == i:
                d += 0.0  # ell==0, no contribution
            else:
                d += h[i + ell]
        
        # i as second index: valid if 0 <= i-ell <= n-1
        if i - ell >= 0 and i - ell < n:
            # -(1 - h[i-ell]), using pre-swap h
            if i - ell == i:
                pass  # ell==0
            else:
                d -= (1.0 - h[i - ell])
        
        # j as first index: valid if 0 <= j+ell <= n-1
        if j + ell >= 0 and j + ell < n:
            # -h[j+ell], using pre-swap h
            if j + ell == j:
                pass  # ell==0
            else:
                d -= h[j + ell]
        
        # j as second index: valid if 0 <= j-ell <= n-1
        if j - ell >= 0 and j - ell < n:
            # +(1 - h'[j-ell])
            if j - ell == i:
                d += 1.0  # h'[i] = 0, so 1-0 = 1
            elif j - ell == j:
                d += 0.0  # ell==0
            else:
                d += (1.0 - h[j - ell])
        
        delta[m] = d
    
    return delta
```

This is O(n) per swap evaluation (looping over 2n-1 lags with O(1) work each).

Now, for the full profile update: P_new = P + delta. And C_new = max(P_new) * dx.

For the local search:
1. Compute initial profile P
2. For each (i,j) swap where h[i]=1, h[j]=0:
   a. Compute delta
   b. C_candidate = max(P + delta) * dx
   c. Track the best swap
3. If best swap improves C, apply it
4. Repeat until no improvement

This is O(n³) per full pass (n² swaps × O(n) per swap). For n=48, that's about 100k operations per pass. Very fast.

We can do thousands of passes in the time budget, allowing thorough local optimization.

Let me also think about the CVXPY approach (ALEM). The idea is:
1. From a continuous h, compute the profile and identify the "active" lags (those near the maximum)
2. Solve a trust-region QCQP: minimize t subject to linearized profile constraints at active lags, box constraints, sum constraint, and trust region
3. The solution gives a direction to move
4. Check the exact objective at the new point

This is more complex to implement but potentially more powerful for the continuous case.

def swap_delta_fast(h, i, j, n):
    """Vectorized computation of swap delta."""
    m_all = np.arange(2 * n - 1)
    ell = m_all - (n - 1)
    delta = np.zeros(2 * n - 1)
    
    # i as first index: ell in range [-i, n-1-i]
    ip = i + ell
    mask_ip = (ip >= 0) & (ip < n)
    if np.any(mask_ip):
        contrib = np.zeros(2*n-1)
        vals = np.where(ip == j, 1.0, np.where(ip == i, 0.0, 0.0))
        # For ip != i and ip != j: contrib = h[ip]
        valid = mask_ip & (ip != i) & (ip != j)
        contrib[valid] = h[ip[valid]]
        contrib[mask_ip & (ip == j)] = 1.0
        delta += contrib
    
    # i as second index: ell in range [i-(n-1), i]
    im = i - ell
    mask_im = (im >= 0) & (im < n) & (im != i)
    if np.any(mask_im):

    # j as first index: ell in range [-j, n-1-j]
    jp = j + ell
    mask_jp = (jp >= 0) & (jp < n) & (jp != j)
    if np.any(mask_jp):

    jm = j - ell
    mask_jm = (jm >= 0) & (jm < n)
    if np.any(mask_jm):
        contrib = np.zeros(2*n-1)
        contrib[mask_jm & (jm == i)] = 1.0
        valid = mask_jm & (jm != i) & (jm != j)
        contrib[valid] = (1.0 - h[jm[valid]])
        delta += contrib
