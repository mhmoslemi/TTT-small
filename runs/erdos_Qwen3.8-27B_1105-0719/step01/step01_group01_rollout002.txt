```python
def smooth_max_obj(h, beta):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    m = np.max(corr)
    shifted = beta * (corr - m)
    # Clip for numerical stability
    shifted = np.clip(shifted, -50, 50)
    val = m + np.log(np.sum(np.exp(shifted))) / beta
    return val * dx

def slsqp_polish(h0, betas, max_iter=200):
    n = len(h0)
    best_h = h0.copy()
    best_c5 = compute_c5(h0)
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': lambda x: np.sum(x) - n/2.0, 
             'jac': lambda x: np.ones(n)}]
    for beta in betas:
        try:
            res = minimize(
                smooth_max_obj, best_h, args=(beta,),
                jac=smooth_max_grad,
                method='SLSQP',
                bounds=bounds,
                constraints=cons,
                options={'maxiter': max_iter, 'ftol': 1e-15}
            )
            if res.x is not None and res.success or (res.x is not None and np.all(res.x >= -1e-6) and np.all(res.x <= 1+1e-6)):
                x = np.clip(res.x, 0.0, 1.0)
                x = project_feasible(x, n)
                c5_new = compute_c5(x)
                if c5_new < best_c5:
                    best_c5 = c5_new
                    best_h = x
        except Exception:
            pass
    return best_h, best_c5

    return h
```

Now, one concern: the SLSQP with the smooth max surrogate might not be the best use of time. The local search with pairwise moves is very effective for this type of problem because:
1. The feasible set is a polytope (intersection of hypercube and a hyperplane)
2. The objective is the max of linear functions (each correlation is linear in h)
3. Therefore the objective is convex in h!

Wait, is it convex? The objective is max_k c_k(h) where each c_k(h) is... let's see.

c_k(h) = sum_m h[m]*(1-h[m+k])

This is NOT linear in h! It's bilinear (product of h[m] and h[m+k]). So the objective is NOT convex.

Hmm, that changes things. The product h[m]*(1-h[m+k]) = h[m] - h[m]*h[m+k] is not linear.

So we can't use convex optimization tools directly. The smooth max of these non-convex functions is also non-convex.

This means SLSQP is finding local minima of a non-convex function, which is what the previous code was doing too.

Given this, the local search approach (pairwise moves) is actually quite natural because it directly searches the non-convex landscape.

Let me think about what would make the local search more effective:

1. **Adaptive step size**: Instead of random deltas, try to find the best delta for a given (i,j) pair by trying more values or using a golden section search.

2. **Greedy coordinate descent**: Instead of random pairs, cycle through all pairs and for each, find the best delta. This is more systematic.

3. **Block moves**: Move a contiguous block of h values together. E.g., add δ to h[i:i+L] and subtract δ from h[j:j+L] (keeping the sum constant). This can capture more structure.

4. **Restart strategy**: If stuck for many iterations, perturb the solution significantly.

Let me refine the algorithm:

```python
def greedy_pairwise_descent(h, n, max_sweeps=50, n_delta_tries=9):
    """Cycle through all pairs and find best transfer for each."""
    best_h = h.copy()
    best_c5 = compute_c5(best_h)
    
    for sweep in range(max_sweeps):
        improved = False
        for i in range(n):
            for j in range(i+1, n):
                max_d = min(1.0 - best_h[i], best_h[j])
                min_d = -min(best_h[i], 1.0 - best_h[j])
                if max_d <= 1e-10 and min_d >= -1e-10:
                    continue
                # Try several delta values
                deltas = np.linspace(min_d, max_d, n_delta_tries)
                best_delta = 0.0
                best_local = best_c5
                for d in deltas:
                    if abs(d) < 1e-12:
                        continue
                    h_new = best_h.copy()
                    h_new[i] += d
                    h_new[j] -= d
                    c5_new = compute_c5(h_new)
                    if c5_new < best_local - 1e-14:
                        best_local = c5_new
                        best_delta = d
                if best_delta != 0.0:
                    best_h[i] += best_delta
                    best_h[j] -= best_delta
                    best_c5 = best_local
                    improved = True
        if not improved:
            break
    return best_h, best_c5
```
