```python
    pattern_p[s] = b[p+s] + b[p-s] (out-of-bounds treated as 0)

            if 0 <= p-s < n:

            patterns[p, idx] = v
    return patterns
```

```python
def find_best_swap(C, patterns, ones, zeros):
    """Find the swap (i in ones, j in zeros) that most reduces max(C)."""
    best_delta = 0.0
    best_i_idx, best_j_idx = -1, -1
    cur_max = np.max(C)
    
    for ii in range(len(ones)):
        i = ones[ii]
        # Shape: (len(zeros), 2n-1)
        new_profiles = C[None, :] + patterns[i][None, :] - patterns[zeros]
        new_maxes = np.max(new_profiles, axis=1)
        deltas = new_maxes - cur_max
        min_idx = np.argmin(deltas)
        if deltas[min_idx] < best_delta:
            best_delta = deltas[min_idx]
            best_i_idx = ii
            best_j_idx = min_idx
    
    if best_i_idx < 0:
        return -1, -1, 0.0
    return ones[best_i_idx], zeros[best_j_idx], best_delta
```

This is similar to the binary swap delta but without the full flip. The net effect depends on the local structure.

This suggests that a "soft" version of the binary solution might be slightly better. But the improvement is O(ε) and we'd need to optimize ε carefully.
