1. Approach and rationale

Central idea. Improve the parent construction by solving a succession of small exact active-constraint trust-region subproblems built from quadratic majorizers of the exact correlation terms, rather than using a smooth log-sum-exp objective, a fixed smoothed maximum, or a global symmetric/palindromic reparameterization. The true discrete objective is

C5(h) = max_r (dx) * [np.correlate(h, 1 - h, mode="full")][r],

over all 2*n - 1 lag indices r. Each raw correlation term is a sum of bilinear products h_i * h_j, so the full problem is nonconvex. The new method keeps all variables h_i in the original full-dimensional feasible set and enforces sum(h) = n/2 as an equality constraint in the subproblems. It then linearizes/quadratically majorizes only the currently active/near-active correlation constraints and solves a convex epigraph subproblem locally. Candidate points are always accepted only after exact reevaluation with the original metric.

Why this could solve the current bottleneck. The parent result is close to the target by roughly 1e-4 to 5e-5. The previous smooth-max/SISQP-style search mostly works on a surrogate that can bias where it looks for improvement and depends on a beta schedule. By contrast, exact active-constraint epigraph solving directly asks: “move h inside a modest trust region so that the currently binding maximum correlation values are reduced, while keeping the exact integral and box constraints.” Because the true problem is minimax, inactive correlations do not matter unless they become hidden violations after a move. The method uses active constraints first, exact reevaluation, and adaptive expansion of the active set.

New main change. The primary algorithm is a trust-region sequential quadratic majorization scheme:
- Choose the currently largest correlations.
- For each chosen lag r, define a quadratic upper model for the exact correlation function around the current point.
- Minimize an epigraph variable t subject to t >= model_r(h) for those chosen lags, h in a trust box, and sum(h) = n/2.
- Add a small quadratic regularization term to the objective and keep hard trust-region box bounds.
- Project, evaluate the exact objective, accept only if exact maximum improves.
- If exact evaluation reveals that constraints not included in the model block the improvement, expand the active set and resolve.

This formula remains faithful to the official evaluator: the same lag indexing convention used by numpy.correlate is used to generate active constraints and gradients; the final scoring uses exact np.correlate(h, 1-h, mode="full")*dx.

Limitations.
- This is a heuristic nonconvex local method. No global optimality or convex global guarantee is claimed.
- The quadratic model majorizes every correlation term locally; it is intentionally conservative. A point improving the surrogate need not improve the true maximum, so exact reevaluation is mandatory.
- Good starting points matter. The plan therefore includes deterministic parent transformations, safe symmetric warm starts, and limited stochastic starts.
- Time must be explicit: every solver call has finite maxiter and launcher time checks. The best valid candidate is retained throughout.

2. Mathematical specification

2.1 Variables and exact objective

Let h be an array of length n. define dx = 2.0 / n. A valid discrete point satisfies:
- 0 <= h_i <= 1 for all i.
- sum_i h_i = n / 2.

The objective used for acceptance is exactly

score(h) = max(np.correlate(h, 1.0 - h, mode="full")) * dx.

This length-2*n-1 correlation has lag offsets d = r - (n - 1) for r = 0, 1, ..., 2*n - 1.

Orientation convention. For match numpy.correlate, raw correlation at index r is evaluated as the sum over valid base indices b of

h_{b + d} * (1 - h_b),

where d = r - (n - 1), and the valid base indices are

b_min = max(0, -d)
b_max = min(n - 1, n - 1 - d)

inclusive if b_min <= b_max. This is the convention from the previous successful orientation check and should be used to build all model derivatives.

For fixed h0 and a chosen lag d, exact raw correlation is

R_d(h) = sum_{b = b_min}^{b_max} h_{b+d}(1 - h_b).

The exact constraint for that lag in the epigraph model is

t >= dx * R_d(h).

The true maximum over all lags is exact even if only part of R_d is modeled in the subproblem.

2.2 Quadratic majorizer for active correlation constraints

Let h0 be the current center and delta = h - h0. For one lag offset d, let

f_d(h) = sum h_j(1-h_b) where j = b + d.

At h0, define exact raw value R0 = R_d(h0) and exact gradient G_d for h such that

G_d[j] += 1.0 - h0[b]
G_d[b] -= h0[j]

for each valid pair (b, j=b+d). The true function is

R_d(h0 + delta) = R0 + G_d^T delta + sum_pairs ( -delta_j * delta_b ).

Use the inequality

- delta_j * delta_b <= 0.5 * delta_j^2 + 0.5 * delta_b^2.

Therefore

R_d(h) <= R_model_d(h)

with

R_model_d(h) = R0 + G_d^T(h - h0)
               + 0.5 * sum_q diag_r[q] * (h_q - h0_q)^2.

Here diag_r[q] counts how many of the two positions in every valid pair that involves variable q. If both roles of a term are the same variable, count both roles. Equivalently, when j and b are the same index, add 2 to diag_r[q]; when different, add 1 to each of the two entries.

Constraint used in the trust subproblem:

t >= dx * R_model_d(h).

This subproblem is convex because the model functions are positive semidefinite diagonal quadratics and constraints t - dx*R_model >= 0 define epigraph regions above convex functions, with linear bounds and linear sum.

Do not claim this is a global upper optimum; it is only a local convex majorant. Loss of accuracy over large displacements is controlled by trust-region bounds and by final exact rejection.

2.3 Trust-region subproblem

For current center h_c, score S_c, trust radius rho, proximal weight alpha_h, active set A, target sum s = n/2, decision vector

z = [h_0, ..., h_{n-1}; t]

( length n + 1).

Subproblem:
Minimize

J(z) = t + alpha_h * sum_i (h_i - h_c_i)^2

subject to:

1. sum(h) = n/2.
2. lower_i <= h_i <= upper_i, i=0,...,n-1, with

lower_i = max(0, h_c_i - rho)
upper_i = min(1, h_c_i + rho).

3. t >= dx * R_model_r(h) for r in A.
4. bounded linear lower/upper convenient solver limits:

0 <= t <= S_c + 1.0.

Initial feasible point is

h = h_c, t = S_c + eps_t,

which exactly satisfies the model when delta=0; t must be just high enough for numeric SLSQP feasibility. The active model is constructed around h_c.

Objective gradients used by SLSQP:
- gradient with respect to h_i: 2*alpha_h*(h_i - h_c_i).
- gradient with respect to t: 1.

This is different from previous logsumexp smoothing: no beta schedule and no max approximation inside the optimization; the surrogate max is replaced by exact active inequalities plus relax. Constraint gradients are derived in sections above.
