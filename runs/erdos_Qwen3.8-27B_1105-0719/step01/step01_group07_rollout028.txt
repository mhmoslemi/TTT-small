But this is O(n^2) per local search step (trying all pairs), and n=48 gives 24*24=576 pairs. Each evaluation is ~5 microseconds. So one local search step is ~3 ms. If we need 100 steps to converge, that's ~300 ms per local search. In 600 seconds, we can do about 2000 ILS iterations. That's reasonable.

But actually, the greedy local search (trying all pairs and taking the best) is more expensive per iteration but fewer iterations. Let me use "first improvement" instead: try pairs in random order and take the first one that improves. This is faster per iteration and still effective.

Let me now write the final, clean version. I'll structure it as:

1. Helper functions (objective, projection, etc.)
2. Binary SA with full profile recomputation
3. ILS (greedy + perturbation)
4. Continuous LSE refinement
5. Main run function

Let me also add a key trick: **shift invariance**. If I cyclically shift the binary pattern, the objective might change (because of boundary effects in the non-cyclic correlation). So I should also try shifted versions.

Actually, the problem is defined on [0,2] with h: [0,2] → [0,1]. The correlation is over the finite support [0,2], so shifting does change the objective (boundary effects). But I can try all cyclic shifts and pick the best. For n=48, that's 48 shifts, each requiring one evaluation. Cheap.

Wait, but cyclic shifts of the array don't correspond to a valid "shift" of the function h on [0,2]. The function h is defined on [0,2] and we compute h(x+k) which is only defined for x+k in [0,2]. A cyclic shift of the discrete array would wrap around, which doesn't correspond to the original problem.

So I should NOT use cyclic shifts. The array represents h evaluated at specific points in [0,2], and shifting it would be meaningless.

    h = np.array(h, dtype=np.float64).copy()
    n = len(h)
    target = n / 2.0
    h[~np.isfinite(h)] = 0.0

        diff = target - s
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            mask = h < 1.0 - 1e-15
            cnt = np.sum(mask)
            if cnt == 0:
                break
            h[mask] = np.minimum(1.0, h[mask] + diff / cnt)
        else:
            mask = h > 1e-15
            cnt = np.sum(mask)
            if cnt == 0:

        if it % 500 == 0 and time.time() > deadline - 5:
            break

        i_pos = rng.randint(n)
        j_pos = rng.randint(n)
        if curr[i_pos] == curr[j_pos]:
            continue

        if curr[i_pos] == 0:
            i_pos, j_pos = j_pos, i_pos
        
        curr[i_pos] = 0.0
        curr[j_pos] = 1.0

        delta = new_c - curr_c

            curr_c = new_c
            if new_c < best_c:
                best_c = new_c
                best = curr.copy()
        else:
            curr[i_pos] = 1.0
            curr[j_pos] = 0.0
        
        T = max(T * cool_rate, T_min)

def lse_objective_grad(h, tau):
    n = len(h)
    dx = 2.0 / n
    profile = np.correlate(h, 1.0 - h, mode='full') * dx
    m = float(np.max(profile))
    shifted = np.minimum((profile - m) / tau, 0.0)
    exp_vals = np.exp(shifted)
    sum_exp = float(np.sum(exp_vals))
    weights = exp_vals / sum_exp
    obj = m + tau * np.log(sum_exp)
    
    grad = np.zeros(n)
    for j in range(2 * n - 1):
        w = weights[j]
        if w < 1e-12:
            continue
        s = j - (n - 1)
        if s >= 0:
            k1 = np.arange(s, n)
            grad[k1] += w * dx * (1.0 - h[k1 - s])
            k2 = np.arange(0, n - s)
            grad[k2] -= w * dx * h[k2 + s]
        else:
            a = -s
            k1 = np.arange(0, n - a)
            grad[k1] += w * dx * (1.0 - h[k1 + a])
            k2 = np.arange(a, n)
            grad[k2] -= w * dx * h[k2 - a]
    return obj, grad
