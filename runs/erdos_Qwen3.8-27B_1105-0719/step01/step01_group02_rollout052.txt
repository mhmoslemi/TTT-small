  - j is now being counted in c[k] when h[j]=1 (n+k=j, n=j-k) and h[j-k]=0. For k where 0≤j-k<n and h[j-k]=0, c[k] += 1.
  - j was "blocking": for c[k] where n=j, if h[j+k]=1 and h[j]=0, it was counted. After flip h[j]=1, so it's no longer counted. For k where 0≤j+k<n and h[j+k]=1, c[k] -= 1.

So the total change for swap (i: 1→0, j: 0→1):
Δc[k] = -[k: 0≤i-k<n, h[i-k]=0] + [k: 0≤i+k<n, h[i+k]=1] + [k: 0≤j-k<n, h[j-k]=0] - [k: 0≤j+k<n, h[j+k]=1]

This is a sum of indicator functions. For each k, Δc[k] ∈ {-2, -1, 0, 1, 2}.

Now, to find the best swap, I need to minimize max(c[k] + Δc[k]) over all k.

Here's an efficient approach:
- Precompute M = max(c) and the set of indices where c[k] = M (call it S_max).
- For a candidate swap, the new max is max(max of c[k]+Δc[k] for affected k, max of c[k] for unaffected k).
- max of c[k] for unaffected k = M if S_max has an element not affected, else the second maximum.
- For affected k, compute c[k] + Δc[k].

The number of affected k values is at most 4n (from the 4 contributions above), but in practice around 2n.

For n=140: ~280 affected k values per swap. With n²/4 = 4900 swaps per round: 4900 * 280 ≈ 1.4M operations. Very fast!

    Returns the new profile values at affected indices and the new max."""

    # From i (1->0):
    #   - c[k] for k where 0 <= i-k < n and b[i-k] == 0: c[k] -= 1 (i no longer counted)
    #   + c[k] for k where 0 <= i+k < n and b[i+k] == 1: c[k] += 1 (i now "blocks" -> no, i now "unblocks")

    #     i.e., k in [i-(n-1), i] ∩ [-(n-1), n-1] = [max(i-n+1, -(n-1)), min(i, n-1)]

    #     so now if b[i+k]=1, c[k] += 1. For k where 0<=i+k<n, i.e., k in [0, n-1-i].

    #   - j was counted in c[k] when n=j (so n+k=j+k) and b[j+k]=1 and b[j]=0:
    #     b[j] was 0, so if b[j+k]=1, c[k] was counting this. After flip b[j]=1, not counting. c[k] -= 1.
    
    # Let me just compute the delta for each affected k.
    # Affected k values:
    affected = set()
    delta = {}
    
    # i: 1->0
    # Loss: k where 0<=i-k<n and b[i-k]==0
    for k in range(max(i-n+1, -(n-1)), min(i, n-1)+1):

            affected.add(k)

            affected.add(k)
            delta[k] = delta.get(k, 0) + 1

    # Gain: k where 0<=j-k<n and b[j-k]==0

        if 0 <= n_idx < n and b[n_idx] == 0:
            affected.add(k)
            delta[k] = delta.get(k, 0) + 1

    for k in range(0, n-j):
        if b[j+k] == 1:
            affected.add(k)
            delta[k] = delta.get(k, 0) - 1

def exact_score(h):

def project_box(h, target):
    n = len(h)
    h = np.clip(np.nan_to_num(h, nan=0.0, posinf=1.0, neginf=0.0), 0.0, 1.0)
    for _ in range(200):
        diff = target - float(np.sum(h))
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            mask = h < 1.0
            if not np.any(mask):
                break

            step = min(diff / np.sum(mask), avail.min())
            h[mask] += step
        else:
            mask = h > 0.0
            if not np.any(mask):
                break
            avail = h[mask]
            step = min(-diff / np.sum(mask), avail.min())
            h[mask] -= step
    return h

    idx = np.argsort(-h, kind='stable')
    b = np.zeros(n)

    h_new = np.interp(x_dst, x_src, h_src)
