1. Approach and rationale

The task is to produce a feasible vector h in [0,1]^n with sum n/2 that minimizes the exact evaluator

    C(h) = max_t dx * np.correlate(h, 1-h, mode="full")[t],  dx = 2/n.

This is a max-of-quadratics, nonsmooth, nonconvex optimization problem. The supplied parent is already close to the desired bound, so broad global search alone is unlikely to produce the needed improvement. The practical bottleneck is refining a good vector while preserving feasibility exactly and reducing the currently binding shifted overlaps without accidentally raising another lag.

The proposed primary method is materially different from smoothing repost reaches previous. Instead of minimizing a smoothed log-sum-exp surrogate or using only random transfers, we implement an epigraph constrained local explaineMinimize:

    minimize t
    subject to P_k(h) <= t for all lag indices k,
    0 <= h_i <= 1,
    sum_i h_i = n/2,

where all P_k(h) are the exact scaled correlation profiles, not samples of a continuous integral. The restriction P_k(h) <= t is exact; minimizing t locally is locally equivalent to minimizing max P_k(h) subject to feasibility. scipy optimize SLSQP solves smooth inequality and equality constraints directly, and the equality sum constraint and box bounds preserve the problem geometry. This formulation differs from previous methods because:

- it does not smooth or smooth away the unscaled nonlinear max; it preserves all lag constraints in the optimization model;
- it provides exact derivatives of every inequality with respect to every h_i and the auxiliary variable t;
- it relies on multiresolution aircraft and exact-exchange features only to escape local stagnation rather than as the main objective;
