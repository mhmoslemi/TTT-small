1. Approach and rationale

1.1 Objective and central idea

The problem is to minimize the nonsmooth, nonconvex, box-constrained mean-value problem

    minimize over h in [0,1]^n, sum_i h_i = n/2,
        C_n(h) = max_j P_j(h),
    where P_j(h) = dx * [np.correlate(h, 1-h, mode="full")]_j,
    dx = 2/n.

The previous parent construction is one feasible local point with reported objective about 0.381099 for length 48. The previous soft/temperature/SLSQP strategies either average the maximum through one smooth envelope or perform scalar directional moves that collapse many active profile lags into a single scalar subgradient. The new primary method, Active Linearized Envelope Trust Method (ALEM), instead treats the profile maxima as separate first-order cuts of the original exact objective and uses a convex trust-region subproblem only as a generator of proposed interior moves. It does not claim that solving the linearized subproblem optimizes the original problem. It proposes a local move and then checks that move and safe interpolations using the authoritative exact objective.

For a current feasible point h, every profile entry P_l has first-order linearization

    L_l(z; h) = P_l(h) + grad_l(h)^T (z - h).

ALEM solves a low/sub-medium-size, convex, trust-region problem in z and a scalar epigraph t:

    find z,t,
    minimize t
    subject to sum_i z_i = n/2,       0 <= z_i <= 1,
               sum_i (z_i - h_i)^2 <= R^2,
               L_j(z;h) <= t for selected lag outputs j.

Because the constraints are affine apart from the trust disk, this is a convex QCQP (quadratically constrained quadratic/linear problem). It can be solved by CVXPY when a compatible QP/conic solver is available. The proposed z and several damped versions are remapped by the exact oracle. A move is accepted only if the authoritative objective is strictly lower. This differs substantively from LSE/soft-max strategies: the method does not replace the maximum by a single weighted-sum objective permanently. It handles multiple active or near-max lags as separate affine constraints and it is checked with the exact evaluator at every acceptance decision.

It differs from the pair-sum coordinate method because ALEM proposes a coupled direction to many coordinates in a single trust-region primal cut, not only a one-dimensional polynomial line over a two-point displacement. It differs from full SLSQP on the original objective because it never asks the nonlinear sulver to model the exact, nonsmooth max of all bilinear profile values. It only asks for a linearized model whose solution may be wrong due to unmodeled quadratic terms; wrongness is rejected when the original profile is evaluated.

1.2 Why this can improve the current point

The narrow loss gap from 0.381099 to 0.38085 usually means the proposed move must lower several closely competing local maximum entries at once, leaving one or two high lags unchanged or only slightly worse at active local maxima. Soft-max or scalar-gradient methods collapse them into one averaged slope and then fail when the interpolation is no longer near the same active envelope. The active/epigraph linear cutting plane exactly exposes which particular discrete lag outputs are blocking a step, and the trust-region subproblem selects the convex nearest direction that lowers the envelope linearization. If the exact objective confirms that direction, this is a genuine witness of movement beyond a single Lagrange weighted gradient direction.

ALEM is also run over a resolution ladder and multiple seed families. The parent construction at n=48 may be discretely lucky in some lags. Moving up to n=64..128 from interpolated parent/constructed seeds is not an arbitrary cosmetic rescaling; the boundary overlap weights and dx scaling change. A lower original bound at a larger resolution is valid for the returned resolution. When smaller size is important for speed preference, ALEM also receives downward transfers and binarization/group moves as useful auxiliary strategies, but the smaller size is never chosen if it worsens the exact objective. Final selection is made solely by exact objective up to a fixed tie tolerance; near-tie prefer the smaller n. If smaller were significantly worse it is rejected.

1.3 What ALEM does not claim

- It is not a global optimization proof and cannot by itself claim global optimality.
- Solving the linearized QCQP does not guarantee improvement of the original objective because C_j is nonlinear because of products h_i h_l.
- The parent remains a valid fallback against any solver exception or timing violation.
- The returned bound is the exact objective of the final feasible vector, not the theoretical lower bound/optimal value from anything solved.
