1. Approach and rationale

Central objective idea

The previous program primarily solved an epigraph SLSQP problem with many nonlinear overlap inequalities. That formulation contains a large number of active inequalities and often becomes poorly conditioned once the profile of correlations is nearly equioscillatory: the optimizer either rotates along one partial active set, stalls because the active changes discontinuously, or spends budget repairing an infeasible local contraction rather than improving the true maximum.

This plan uses a materially different local optimizer and search architecture:

1. Instead of introducing a scalar upper-bound variable `t` and constraining all `2n-1` correlation values against `t`, optimize a smooth direct upper-envelope of the actual correlation profile:
   
   `J_beta(h) = (1/beta) log(sum_{r=0}^{2n-2} exp(beta * C_r(h)))`,
   
   where `C_r(h)` are the discrete correlation contributions already used by the authoritative evaluator. This keeps the search in the original `h`-space with the linear integral constraint only.

2. The smooth objective is annealed through a sequence of increasing beta values. Low beta makes the objective differentiable with multiple contributing lags, helping escape nonsmooth plateau directions. High beta makes the objective closely track the true maximum correlation, so final accepted moves improve the actual evaluator.

3. Full feasibility is restored by an explicit water-filling repair that enforces `0 <= h_i <= 1` and `sum(h) = n/2`, not by naive clipping and rescaling. Every candidate is judged by the authoritative evaluator after repair.

4. Search robustness is increased by a portfolio of original, symmetrized, reversed, transferred, and randomly perturbed seeds. Dimension transfer is performed by cumulative-mass resampling rather than direct pixel interpolation, preserving the integral constraint much more accurately before repair.

5. A final exact active-gradient descent pass is used to exploit the true unsmoothed profile without introducing an epigraph variable.

Why this may improve the parent

- The parent is already close to the record, so the gain must come from better handling of near-ties in the top correlation lags. A soft-max of the full 2n-1 lag profile is a natural way to move multiple near-ties simultaneously while still following the true island of worst lags as beta increases.
- Direct soft-max avoids the epigraph variable and the large feasibility-consistency requirements of an inequality-constrained SLSQP solve. It gives one smooth objective whose gradient is directly related to the gradient of the actual correlation values.
- Random-perturbation and dimension-transfer restarts search different discretizations of the underlying continuous step function, which can expose directions unavailable on a fixed grid.
- This is not a proof of global optimality. It is a nonconvex, local, restart-based strategy that only accepts true objective decreases in the discrete evaluator.

2. Mathematical specification

2.1 Representation

Let `n` be the number of grid samples. Define

- `dx = 2.0 / n`
- `h = (h[0], ..., h[n-1])`
- feasible set `F_n`:
  - `0 <= h[i] <= 1` for all `i`
  - `sum_{i=0}^{n-1} h[i] = n / 2.0`

Feasible points represent piecewise-constant samples on `[0, 2]` with grid cells of length `dx`, and the total integral is `dx * sum(h) = 1`.

2.2 Authoritative score

The final objective must be evaluated exactly as the task defines:

`C5(h) = max(np.correlate(h, 1.0 - h, mode="full")) * (2.0 / n)`

This must be used for every stored best value. All other formulas are optimization helpers only.

2.3 Full-lag profile and gradient

For optimization use the full lag profile `C_r(h)`, `r = 0, ..., 2n-2`, ordered exactly as the numpy full correlation output. Let `delta = r - (n - 1)`.

For the zero shift, both the local profile used for gradients and the evaluator correspond to:

`C_{n-1}(h) = dx * sum_{i=0}^{n-1} h[i] * (1 - h[i])`.

For `delta = m > 0`:

`C_{n-1+m}(h) = dx * sum_{i=0}^{n-1-m} h[i] * (1 - h[i + m])`

For `delta = -m < 0`:

`C_{n-1-m}(h) = dx * sum_{i=m}^{n-1} h[i] * (1 - h[i - m])`

These formulas match `np.correlate(h, 1-h, mode="full")` when the profile index is interpreted with offset `delta` from the center.

Gradient formulas, important for soft maximization:

At zero shift:

- `dC_{n-1} / dh[k] = dx * (1 - 2*h[k])`

For positive shift `m`:

For each `i = 0,...,n-1-m`:
- `dC_{n-1+m} / dh[i] += dx * (1 - h[i + m])`
- `dC_{n-1+m} / dh[i + m] += -dx * h[i]`

For negative shift `-m`:

For each `i = m,...,n-1`:
- `dC_{n-1-m} / dh[i] += dx * (1 - h[i - m])`
- `dC_{n-1-m} / dh[i - m] += -dx * h[i]`

The full profile can be generated and compared once, during development or optional startup validation, against `np.correlate(h, 1-h, "full") * dx` on random feasible vectors. In final execution, use the local profile for the analytic smoothing optimization and use `np.correlate` for the stored accepted score.

2.4 Smooth direct upper envelope

For a fixed current `h`, compute `C[]` and gradient rows `G[r, :]` for the 2n-1 lags. Define the smooth objective to be minimized:

`J_beta(h) = (1/beta) * log(sum_{r=0}^{2n-2} exp(beta * C_r(h)))`

Stable evaluation:

1. `M = max_r C_r(h)`
2. `a_r = beta * (C_r(h) - M)`
3. `w_r = exp(a_r) / sum_s exp(a_s)`
4. `J_beta(h) = M + log(sum_s exp(a_s)) / beta`

This is a smooth upper bound for the true maximum. As beta increases, the weights concentrate on the worst lags and `J_beta` approaches `max_r C_r`.

Gradient:

`grad J_beta(h) = sum_r w_r * grad C_r(h)`

Implementation detail: collect `w_r * G` either as matrix multiplication `w.T @ G` or, efficiently for the small-dimensional problem, accumulate weighted slices for each `m` using the sparse row formulas above.

2.5 Constraints for smooth minimization

Use the original variable dimension `n`. Minimize `J_beta(h)` subject only to:

- equality: `sum(h) - n/2 = 0`, gradient trustworthy as all ones.
- bounds: `0 <= h[i] <= 1`.

No epigraph variable and no row-by-row overlap inequalities are used inside the smooth pass.

If using SciPy `SLSQP`, use a top-level objective:

2.8 Dimension transfer

Define function `cumulative_transfer(vec, new_n)`. For piecewise-constant interpretation:

- Let `old_n = len(vec)`, `dx_old = 2.0 / old_n`.
- Construct old bin boundary coordinate grid `xb = dx_old * np.arange(old_n + 1)`.
- Compute cumulative integral function via step masses:
  - `cum_old = dx_old * concat([0], cumsum(vec))`
- New boundaries: `xn = (2.0 / new_n) * np.arange(new_n + 1)`.
- Interpolate cumulative integral: `cum_new = np.interp(xn, xb, cum_old)`.
- New masses: `mass = cum_new[1:] - cum_new[:-1]`.
- New density `h_new = mass / (2.0 / new_n)`.
- Clip and repair.

This preserves the continuous mass far better than center interpolation, and then repair corrects the exact `sum=n/2`. For upsampling, this linearly refines the piecewise cumulative function; for downsampling, it averages across blocks. Always compare scores using the authoritative discrete score after repair.

1. Approach and rationale

1.1 What is wrong with the current bottleneck

The supplied parent is already near the record, so the remaining improvement must come from resolving nearly tied worst-case correlation lags and escaping a fixed-datagrid local optimum. The previous program mainly performs SLSQP on an epigraph variable subject to allFull linear/nonlinear correlation inequalities. That formulation has two practical weaknesses:

- It is strongly affected by the active set changing abruptly. If several lags are almost tied, SLSQP can spend many iterations adjusting an epigraph constraint that is nearly nonsmooth.
- It constantly tries to satisfy a large number of inequalities directly. When a candidate becomes slightly infeasible, much of the budget goes into feasibility repair rather than decreasing the true maximum.

1.2 Central new method

Avoid the epigraph variable completely. Optimize the original vector `h` under only the two natural constraints: physical bounds and one integral equality constraint. Use a smooth direct upper envelope of the full correlation profile:

`J_beta(h) = (1/beta) * log(sum_{r=0}^{2n-2} exp(beta * C_r(h)))`

where `C_r(h)` is exactly the full correlation value at lag `r`, already scaled by `dx = 2/n`. Since `C5(h) = max_r C_r`, this smooth objective upper-bounds the true score and becomes precisely the true max as `beta` increases.

This is materially different from epigraph SLSQP. It optimizes a single differentiable scalar directly in `h`-space. Gradients automatically mix several near-worst lags at low beta, and then focus on the true worst lags at high beta. The exact disparate score remains the acceptance criterion.

1.3 Globalization architecture

A single smooth minimizer has limited escape ability. The plan combines it with the following nonlocal search devices.

- Portfolio initialization: all feasible transformations of the parent are kept.
  - parent itself
  - reversed parent
  - complement of parent `1-h`
  - symmetrized parent `(h + reverse(h))/2`
  - low-dimensional and high-dimensional cumulative-transfer variants of best and parent
  - random Gaussian perturbations preserving the mean before repair
  - if parent unavailable: Fourier-like safe starting functions, linear ramps, and the uniform feasible constant `0.5`.

- Sequential soft-max annealing. Each pass uses increasing `beta` values. One pass starts after another is repaired, and only candidates with strictly better exact scores become new simulation seeds.

- Cross-resolution search. The piecewise-constant step function is transferred through the cumulative-integral operator, not by producing pixel values in isolation. This transfers mass more faithfully before total-sum repair. Then optimization problems are solved in both smaller and larger meeting dimensions.

- Exact non-smooth final descent. After smooth passes, the true full-lag profile and its exact gradient-deorganic direction are tested directly. This手术室 removes long-term translation lagging behind the surrogate objective.

1.4 Why improvement is plausible but not guaranteed

The method is still a nonconvex local search. There is no global optimality claim. Rationale for potential improvement:

- When near optimality, the true optimum is governed by several lags being equal. The smooth approximation softly integrates their gradients.
- Low beta pass easier regions; high beta pass gives precise max-tracking. Annealing switches them properly.
- Higher or lower resolutions can reveal nearby lower-dimensional or smoother bounds unavailable to parent `n=140`.
- Random zero-mean Gaussian relational perturbations stem from constant directions unsuperior regime, occurring before adaptive repair projection.
