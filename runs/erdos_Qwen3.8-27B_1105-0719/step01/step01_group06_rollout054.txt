    **Approach: Smoothed max + projected gradient**

    The max function can be smoothed using the log-sum-exp:
    smooth_max(p) = (1/β) * log(sum_k exp(β * p_k))

    As β → ∞, this approaches the true max. For finite β, it's a smooth approximation.

    The gradient of smooth_max is:
    grad = (1/sum_j exp(β*p_j)) * Σ_j β*exp(β*p_j) * grad_p_j

    This gives a weighted average of the gradients of the individual p_k, with more weight on the larger p_k.

    Algorithm:
    1. Start from feasible h
    2. Compute profile p
    3. Compute β (adaptive: start large, decrease if stuck)
    4. Compute gradient of smooth_max
    5. Project gradient onto feasible set (subtract mean to maintain sum constraint, clip to [0,1])
    6. Take step, project back to feasible set
    7. Repeat
