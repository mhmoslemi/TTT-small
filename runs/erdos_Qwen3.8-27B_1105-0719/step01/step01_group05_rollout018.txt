         sum(h) = n/2
         0 ≤ h ≤ 1

This is a non-convex optimization (p_r is bilinear) but we can use a bisection approach:
- For a given t, check if there exists h such that p_r(h) ≤ t for all r, sum(h) = n/2, 0 ≤ h ≤ 1
- This feasibility problem is still non-convex

Alternatively, we can use the following iterative approach:
1. Start with a feasible h
2. Compute profile p = correlate(h, 1-h, full) * dx
3. Let M = max(p)
4. The "active" lags are those where p_r ≈ M
5. Try to reduce p_r for the active lags while keeping others below M
6. This is like a "water-filling" or "balancing" approach

For step 5, the gradient of p_r w.r.t. h is:
∂p_r/∂h[k] = (1 - h[k+r-(n-1)]) - h[k+(n-1)-r] (for valid indices)

So the gradient of max(p) w.r.t. h is a linear combination of ∇p_r for the active r's.

This is essentially what the smooth_obj_and_grad function in the previous code does (with the softmax smoothing). The issue is that SLSQP might not converge well.

   - For each pair (i,j), find best λ using vectorized grid search
   - Accept improving moves
   - Repeat until convergence or time budget

2. **Phase 2: Binary local search**
   - Threshold the continuous solution to binary
   - Do swap-based local search on the binary space
   - Accept if it improves

3. **Phase 3: Multi-resolution**
   - Try a few different resolutions (downsample or upsample)
   - Apply Phase 1 at each resolution
   - Keep the best

4. **Phase 4: Refinement**
   - Go back to the best resolution
   - Run more Phase 1 iterations
   - Try Phase 2 again

import numpy as np
import time

def exact_objective(h):
    n = len(h)
    if n == 0:
        return float('inf'), np.array([])
    dx = 2.0 / n
    profile = np.correlate(h, 1.0 - h, mode='full') * dx
    return float(np.max(profile)), profile

def project_box_sum(h, target=None):
    n = len(h)
    if target is None:
        target = 0.5 * n
    h = np.array(h, dtype=np.float64).copy()
    h = np.nan_to_num(h, nan=0.0, posinf=1.0, neginf=0.0)
    h = np.clip(h, 0.0, 1.0)
    for _ in range(200):
        diff = target - np.sum(h)
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            mask = h < 1.0
            cnt = np.sum(mask)
            if cnt == 0:
                break
            h[mask] = np.minimum(h[mask] + diff / cnt, 1.0)
        else:
            mask = h > 0.0
            cnt = np.sum(mask)
            if cnt == 0:
                break
            h[mask] = np.maximum(h[mask] + diff / cnt, 0.0)
    return h

def compute_lin_coeff(h, i, j, n):
    """Compute linear coefficient vector for pair (i,j).
    p_new[r] ≈ p_old[r] + λ * lin_coeff[r]"""
    g = 1.0 - h
    lin = np.zeros(2 * n - 1)
    
    # Contribution from h[i] += λ:
    # Term k=i in p[r] = sum_k h[k]*g[k+r-(n-1)]:
    #   λ * g[i+r-(n-1)] for r where 0 <= i+r-(n-1) < n
    lo1 = max(0, n - 1 - i)
    hi1 = min(2 * n - 2, n - 1 + (n - 1 - i))  # = min(2n-2, 2n-2-i+n-1-i) hmm
    # i + r - (n-1) ranges from 0 to n-1
    # So r ranges from (n-1)-i to (n-1)-i+(n-1) = 2n-2-i
    lo1 = max(0, (n - 1) - i)
    hi1 = min(2 * n - 2, (n - 1) + (n - 1 - i))
    for r in range(lo1, hi1 + 1):
        k = i + r - (n - 1)
        lin[r] += g[k]
    
    # Contribution from g[i] -= λ (i.e., the term h[k]*g[i] where k+r-(n-1)=i):
    # k = i - r + (n-1), valid when 0 <= k < n
    # -λ * h[k] = -λ * h[i - r + (n-1)]
    lo2 = max(0, (n - 1) - i)  # k = i-(r-(n-1)), need k>=0: r-(n-1) <= i, r <= n-1+i
    hi2 = min(2 * n - 2, (n - 1) + i + (n - 1))  # need k < n: i-(r-(n-1)) < n, r-(n-1) > i-n, r > i
    # Actually: k = i + (n-1) - r, valid when 0 <= i+(n-1)-r < n
    # r > i+(n-1)-n = i-1, and r < i+(n-1)
    # So r ranges from max(0, i) to min(2n-2, i+n-2)
    lo2 = max(0, i)
    hi2 = min(2 * n - 2, i + n - 2)
    for r in range(lo2, hi2 + 1):
        k = i + (n - 1) - r
        lin[r] -= h[k]
    
    # Now for j (with sign flipped since h[j] -= λ and g[j] += λ):
    # h[j] -= λ: term k=j gives -λ * g[j+r-(n-1)]
    lo3 = max(0, (n - 1) - j)
    hi3 = min(2 * n - 2, (n - 1) + (n - 1 - j))
    for r in range(lo3, hi3 + 1):
        k = j + r - (n - 1)
        lin[r] -= g[k]
    
    # g[j] += λ: term h[k]*g[j] where k = j+(n-1)-r
    lo4 = max(0, j)
    hi4 = min(2 * n - 2, j + n - 2)
    for r in range(lo4, hi4 + 1):
        k = j + (n - 1) - r
        lin[r] += h[k]
    
    return lin

def two_coord_descent_fast(h, max_sweeps=500, deadline=None, n_grid=30, verbose=False):
    n = len(h)
    dx = 2.0 / n
    h = h.copy()
    c5, profile = exact_objective(h)
    g = 1.0 - h
    
    for sweep in range(max_sweeps):
        if deadline is not None and time.time() > deadline:
            break
        improved = False
        for i in range(n):
            if deadline is not None and time.time() > deadline:
                break
            for j in range(n):
                if i == j:
                    continue
                L = max(-h[i], h[j] - 1.0)
                U = min(1.0 - h[i], h[j])
                if U - L < 1e-10:
                    continue
                
                # Compute linear coefficient
                lin = compute_lin_coeff(h, i, j, n)
                
                # Grid search for best λ
                lam_grid = np.linspace(L, U, n_grid)
                # new_profile[r] = profile[r] + lam * lin[r]
                # max over r for each lam
                # Shape: (n_grid, 2n-1)
                new_profiles = profile[None, :] + lam_grid[:, None] * lin[None, :]
                max_vals = np.max(new_profiles, axis=1) * dx
                
                best_idx = np.argmin(max_vals)
                best_c = max_vals[best_idx]
                
                if best_c < c5 - 1e-12:
                    best_lam = lam_grid[best_idx]
                    h[i] += best_lam
                    h[j] -= best_lam
                    # Update profile exactly
                    profile = np.correlate(h, 1.0 - h, mode='full') * dx
                    g = 1.0 - h
                    c5 = float(np.max(profile))
                    improved = True
        
        if not improved:
            break
        if verbose:
            print(f"Sweep {sweep}: c5 = {c5:.6f}")
    
    return h, c5

Wait, I realize there's an issue with my linear coefficient computation. The linear approximation p_new ≈ p_old + λ*lin is only an approximation (it ignores the quadratic terms). For the grid search, this means I might miss the true optimum if the quadratic terms are significant.

The quadratic terms only affect 2-3 specific profile entries (r = n-1, r = n-1+(j-i), r = n-1+(i-j)), so in most cases the linear approximation is very good. And since I'm doing a grid search (not just evaluating at one point), I should be fine.

However, there's a correctness issue: after I accept a move, I need to recompute the exact profile (which I do with np.correlate). So the approximation is only used for the search, and the actual value is always verified exactly. Good.
