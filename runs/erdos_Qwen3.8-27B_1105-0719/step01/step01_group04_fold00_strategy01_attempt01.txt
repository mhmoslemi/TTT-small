1. Approach and rationale

1.1 Central idea

The implemented prior program uses an epigraph formulation with a large number of direct overlap inequalities, plus ad hoc active-set descent and dimension transfers. That formulation is correct but suffers from two related bottlenecks:

- The optimizer must satisfy many near-redundant nonlinear overlap inequalities. Once many near-ties exist, SLSQP spends effort moving along constraint boundary noise rather than the direction that improves the worst overlap.
- The active-set descent stage uses a hand-made weighted sum of gradients of active lags. That direction is only a crude heuristic for the local max-min problem and often becomes ineffective near the current construction.

This plan changes the core local model. Instead of minimizing the raw maximum overlap as a large epigraph problem, use an exact equivalent reorganization of the objective in terms of a length-n profile shaped as:

    autocorrelation + boundary bias.

Then optimize a single smoothed scalar `softmin` of that profile with only the simple equality constraint `sum(h)=n/2` and box constraints. Exact feasibility is restored by a joint box/simplex water-filling projection after every solver step and every accept/return.

The algorithm also adds a materially different local improvement stage: a small trust-region linear program for a max-min Taylor objective over the active lags. At a current point, the linear program asks for a tangent-space direction that raises all lag-profile quantities whose values are close to the worst value. This is a proper first-order model of the local max-min structure, not an arbitrary weighted gradient. Exact acceptance is always by the authoritative evaluator.

The final pipeline is therefore:

1. Validate or recover the supplied parent.
2. Generate a small, diverse pool of feasible candidates through symmetry, dimension transfer, and structured random initializations.
3. For each candidate, run an annealed scalar smooth-minimize optimizer over the exact transformed profile. No epigraph constraints are used in this relaxation.
4. Use exact active-discent after each improved candidate using a trust-region linear programming direction over near-worst lags.
5. Periodically transfer between nearby dimensions and prefer smaller valid dimensions when they achieve essentially the same objective.
6. Return the best valid candidate confirmed by the authoritative `np.correlate` evaluator, with the parent or synthetic construction as a fallback.

This is a substantive change from the previous program:

- The epigraph constraints are removed.
- The objective is a smooth scalar over the transformed profile, not the raw 2n-1 overlap maximum with many constraints.
- Optimizers consume exact analytic gradients of the scalar surrogate and the original equality constraint, instead of many derivative equality/inequality components.
- Active improvement is a small trust-region LP direction solving the linearized near-max problem.
- The final candidate acceptance is exact and independent of all surrogates.

The proposal does not claim global optimality. It is a nonconvex local-search improvement strategy with randomized diversification and exact acceptance, designed to move the supplied parent from about 0.381025 toward the target upper bound 0.3808.

2. Mathematical specification

2.1 Discrete object and exact objective

Let `n = n_points` be an integer, even or odd. Let:

    dx = 2.0 / n
    target_sum = n / 2.0

A candidate vector is `h in R^n`. The executable constraints are:

    0 <= h[i] <= 1 for all i
    sum_i h[i] = target_sum

The authoritative objective is defined by exactly the harness formula. In names:

    corr = np.correlate(h, 1.0 - h, mode="full")
    raw_score(h) = max(corr) * dx

where `corr` has length `2n - 1`. Every candidate accepted in the optimizer must be tested by this solver, not by an internal surrogate.

2.2 Exact transformed profile

For integer lag `m = 0,1,...,n-1` define:

    total(h) = sum_{k=0}^{n-1} h[k]

    P_m = sum_{k=0}^{m-1} h[k]              (P_0 = 0)
    S_m = sum_{k=n-m}^{n-1} h[k]            (S_0 = 0)

    A_m = sum_{k=0}^{n-m-1} h[k] * h[k+m]   (for m=0, A_0 = sum_k h[k]^2)

Define the unscaled profile and scaled profile:

    F_m = A_m + min(P_m, S_m)
    Q_m = dx * F_m

The following derivation is exact for all `h`, not only feasible `h`:

For `m > 0`, the positive-sign correlation with shift m is:

    G_plus(m) = dx * sum_{k=0}^{n-m-1} h[k] * (1 - h[k+m])

Since:

    sum_{k=0}^{n-m-1} h[k] = total - S_m,

then:

    G_plus(m) = dx * (total - S_m - A_m)

The negative-sign correlation with shift m is:

    G_minus(m) = dx * sum_{k=m}^{n-1} h[k] * (1 - h[k-m])

We similarly have:

    sum_{k=m}^{n-1} h[k] = total - P_m

Hence:

    G_minus(m) = dx * (total - P_m - A_m)

The larger of the two signs for absolute lag m is:

    max(G_plus, G_minus)
      = dx * (total - A_m - min(P_m, S_m))

For `m=0`, both formulas collapse to the zero-lag term:

    G_full(0) = dx * (total - A_0)

Thus the raw objective is:

    raw_score(h) = dx * total - min_{m=0}^{n-1} Q_m

If `h` is strictly feasible and satisfies `total = n/2`, then:

    dx * total = (2/n) * (n/2) = 1

and:

    raw_score(h) = 1 - min_{m=0}^{n-1} Q_m

So minimizing the raw objective is equivalent to maximizing:

    min_m Q_m

This transformed-objective representation is exact, but it is used as an optimization model. The final value remains `raw_score(h)`.

2.3 Gradients of `Q_m`

For gradient-based smoothing, let `E_m` denote a smoothed boundary term:

    E_m(h) = smooth_min_b(dx * P_m, dx * S_m)

and:

    Q_m(h) = dx * A_m + E_m(h)

For `m=0` define `E_0 = 0`.

The autocorrelation contribution `dx * A_m` has derivative:

If `m == 0`:

    d(dx * A_0) / dh_j = dx * 2h_j

If `m > 0`:

    d(dx * A_m) / dh_j =
        dx * h[j+m]  if j < n-m
      + dx * h[j-m]  if j >= m

The pair boundary term is a smooth minimum of two scalar sums. Use the stable smooth minimum:

    smin_b(u, v, b) = -log(exp(-b*u) + exp(-b*v)) / b

In stable logs, if `u0 = min(u,v)` and `delta = abs(v-u)`, use:

    smin_b(u,v,b) = u0 - (1/b) * log(1 + exp(-b*delta))

Optionally omit the normalization by 2. It only adds a constant offset for a near-balanced pair; do not use a log(2) misalignment in gradients.

Derivative weights:

For `u <= v`:

    w_u = 1 / (1 + exp(-b*(v-u)))
    w_v = 1 - w_u

For `v < u`:

    w_v = 1 / (1 + exp(-b*(u-v)))
    w_u = 1 - w_v

Numerical rule: if `abs(u-v) * b > 40`, assign the smaller value weight `1.0` and the larger term weight `0.0`.

For a pair term where `u = dx * P_m` and `v = dx * S_m`, the chain derivatives are:

    d E_m / dh_j =
        dx * w_u  if j < m
      + dx * w_v  if j >= n-m

If the first-m prefix and last-m suffix sets overlap, include both terms. If `m=0`, edge derivative is zero. Final gradient of `Q_m`:

    grad12(Q_m) = grad_autocorr(Q_m) + grad_edge(X_m)

This matrix is dense but small: `n x n`. For `n <= 260`, memory is below 600MB, and most practical dimensions use 140 to 160, where overhead is small.

2.4 Smooth scalar objective
