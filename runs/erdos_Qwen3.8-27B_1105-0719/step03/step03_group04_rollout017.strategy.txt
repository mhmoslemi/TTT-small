1.1 Central idea

The supplied evaluator is a discrete nonlinear min-max problem. For length n and dx = 2.0 / n, the exact objective for a numeric vector h is

    C(h) = max_k [ dx * correlation_with_complement(h)[k] ]

where the correlation is linear and finite-support, not circular. The feasible set is the intersection of a box and an exact mass constraint:

    0 <= h[i] <= 1,     sum_i h[i] = n / 2.

The previous approaches, as understood from context, mainly relied on constructed linearized trust-region directions, smooth-to-hard logits/annealed surrogates, or generic epigraph formulations. This plan uses a materially different primary method: a feasible exact mass-transfer beam search. At each local step, the algorithm proposes a finite set of coordinate-pair mass shifts, a full-array mass-balance direction, and randomized low-dimensional flow directions. It evaluates these directions by the original objective on the full correlation profile and accepts only those shifts whose exact score actually decreases. There is no final surrogate value, no final smoothing temperature, and no reliance on a convex relaxation to certify the result. The returned bound is always the actual score of a computationally valid vector.

The main new mechanism is that the local search works directly on fundamental feasible perturbations that preserve total mass:

    increase one coordinate q by epsilon,
    decrease a different coordinate p by epsilon,
    keeping sum(h) unchanged.

The slope of this line with respect to the correlation profile can be computed from exact finite-support derivatives. A candidate line is chosen by predicting the minimum of a piecewise-linear approximation over a selected subset of high-overlap lags; then the line is tested by exact objective evaluation. Pair-paths are complemented by a population of elite feasible vectors, linear mixing, coarse/fine transfer, symmetry transforms, and final exact polishing. The global aspect is deliberately infeasible-space projection and exact profile mixing, not a smooth global objective.

1. Approach and rationale

1.1 Central object and nonconvex trouble

The returned vector represents a step function on [0,2] with finite length n. The task metric is

    C(h) = max_k [ np.correlate(h, 1 - h, mode="full") * (2 / n) ]_k,

with constraints

    0 <= h_i <= 1,   sum_i h_i = n / 2.

The profile at lag d is the finite-support overlap

    P_d(h) = dx * sum_i h_i * (1 - h_{i+d})

summed only over valid overlapping pairs. This is a bilinear, box-constrained, exact-mass, nonconvex min-max objective. The finite boundary terms are part of the objective and cannot be replaced by circular or averaged correlation formulas.

This plan proposes a pair-transfer exact-evaluation search. The key distinction from more conventional smooth-annealed, globally linearized, or pure epigraph local methods is that the primary descent engine operates on the primitive feasible zero-mass paths: take epsilon mass from one grid point and put the same epsilon mass into another grid point. These elementary mass transfers preserve the exact sum exactly to machine arithmetic and directly expose the critical side derivatives of the overlap profile. A small beam of such exact-transfer lines, plus full-array descent paths and elite mixing, each are re-accepted only after exact non-smooth evaluation of the original max-over-lags objective. No final surrogate score and no final continuous relaxation form the reported value.

1.2 What the method targets

A small reduction in a near-optimal solution often requires precise mass adjustment around nearly degenerate pairs of grids and active overlap lags. Pair paths are well suited because:

- They satisfy the mass constraint exactly by construction.
- The derivative action of moving one source index away from one sink index is explicit from the finite-pair formula.
- A pair line can reduce one overlapping active lag while a hidden lag remains low; exact line verification considers all lags.
- Beam candidates are constrained combinations of coordinates, which often reveal coordinated small movements omitted by an averaged gradient step evaluated on many hidden lags.
- Global mixing amongst feasible elite vectors remains in the exact feasible-manifold neighborhood, while exact acceptance keeps performance honest when mixing only produces worse vectors.

The method is not a proof of optimality and cannot, in advance, guarantee reaching a lower value than the supplied record. However, every returned bound is directly produced from the original evaluator formula on a feasibility-repaired candidate. This gives a trustworthy upper bound for the given step-function representation.

1.3 Limitations and assumptions

Justified facts:

- Pair direction swaps preserve total sum exactly.
- First-order exact profile derivatives can be computed by local-pair formulas.
- Adaptive top-lag subsetting and restoring feasibility never affect returned feasibility as long as the final candidate is repaired before actual evaluation.
- Coarsening and finer interpolation comparisons must be decided using actual objective evaluations, not approximate transfer scores.

Heuristic assumptions:

- Beam full-array and pairwise zero-sum directions contain useful descent directions near the current optimum if weighted/selected appropriately.
- Coarse-to-fine mixing and exchange between elites can escape shallow parent basins.
- 1D predictor plus exact golden sampling on candidate lines is sufficient to catch line minima on the original nonconvex objective.
- Random transfers are necessary primarily to break stagnation when active beam weights miss a needed coordinated change.

Possibly failure cases:

- The search may only improve slightly above target or not below the supplied value if the needed direction is neither a low-sample beam pair nor a global mixing perturbation within the budget. The framework must then return the best exact feasible candidate found.
