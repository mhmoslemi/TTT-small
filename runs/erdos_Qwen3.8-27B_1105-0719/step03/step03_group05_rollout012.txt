def repair_feasible(vec):
    n = len(vec)
    h = np.clip(np.asarray(vec, dtype=np.float64), 0.0, 1.0)
    target = n / 2.0
    diff = target - h.sum()
    if abs(diff) < 1e-14:
        return h
    if diff > 0:
        capacity = 1.0 - h
        order = np.argsort(-capacity)
        remaining = diff
        for i in range(n):
            idx = order[i]
            add = min(remaining, capacity[idx] + 1e-15)
            if add > 0:
                h[idx] += add
            remaining -= add
            if remaining <= 1e-12:
                break
    else:
        order = np.argsort(h)
        remaining = -diff
        for i in range(n):
            idx = order[i]
            rem = min(remaining, h[idx] + 1e-15)
            if rem > 0:
                h[idx] -= rem
            remaining -= rem
            if remaining <= 1e-12:
                break
    diff2 = target - h.sum()
    if abs(diff2) > 1e-14:
        if diff2 > 0:
            idx = int(np.argmax(1.0 - h))
        else:
            idx = int(np.argmin(h))
        h[idx] += diff2
        h = np.clip(h, 0.0, 1.0)
    return h

Let me think about the power-sum smoothing more carefully.

f_p(h) = (1/M) * sum_m P[m]^p

∂f_p/∂h[j] = (p/M) * sum_m P[m]^{p-1} * ∂P[m]/∂h[j]
= (p/M) * (G^T w)[j]

where w[m] = P[m]^{p-1}

This is a smooth approximation to the max. As p → ∞, it approaches the max.

The gradient can be computed in O(M*n) = O(n²) time, which is fine.

For Nesterov acceleration:
y_k = x_k + (t_k-1)/t_{k+1} * (x_k - x_{k-1})
x_{k+1} = y_k - alpha * grad(y_k)
t_{k+1} = (1 + sqrt(1 + 4*t_k²))/2

The step size alpha needs to be chosen carefully. For a Lipschitz gradient with constant L, alpha = 1/L. We can estimate L from the Hessian or use backtracking.

For this problem, the gradient is Lipschitz with constant related to the bilinear structure. A safe choice is alpha = 2/(M*dx) or something similar. Let me just use backtracking.

Actually, since the objective is bounded (0 ≤ P[m] ≤ 2dx * n = 4), and the gradient is bounded, we can use a fixed step size with a safety factor.

Let me estimate the Lipschitz constant. The Hessian of f_p involves P[m]^{p-1} * Hessian of P[m] + (p-1)*P[m]^{p-2} * (grad P[m])^T (grad P[m]). The Hessian of P[m] is a sparse matrix with O(n) nonzeros. So L is roughly O(n * p * max(P)^{p-1}).

For practical purposes, I'll use backtracking line search.

    target = n / 2.0
    diff = target - h.sum()
    if abs(diff) < 1e-14:

        order = np.argsort(-capacity)
        remaining = diff
        for i in range(n):

            add = min(remaining, capacity[idx] + 1e-15)
            if add > 0:
                h[idx] += add
            remaining -= add
            if remaining <= 1e-12:
                break
    else:
        order = np.argsort(h)
        remaining = -diff
        for i in range(n):
            idx = order[i]
            rem = min(remaining, h[idx] + 1e-15)
            if rem > 0:
                h[idx] -= rem
            remaining -= rem
            if remaining <= 1e-12:
                break

        if diff2 > 0:
            idx = int(np.argmax(1.0 - h))
        else:
            idx = int(np.argmin(h))
        h[idx] += diff2
        h = np.clip(h, 0.0, 1.0)
    return h

    """Build the gradient matrix G where G[m,j] = dP[m]/dh[j]."""
    M = 2 * n - 1
    G = np.zeros((M, n))
    for m in range(M):
        d = m - (n - 1)
        if d == 0:
            G[m, :] = dx * (1.0 - 2.0 * h)
        elif d > 0:
            G[m, d:] += dx * (1.0 - h[0:n-d])
            G[m, 0:n-d] += -dx * h[d:n]
        else:
            dp = -d
            G[m, 0:n-dp] += dx * (1.0 - h[dp:n])
            G[m, dp:n] += -dx * h[0:n-dp]
    return G

    n = len(h)
    dx = 2.0 / n
    M = 2 * n - 1

    w = np.power(np.maximum(P, 1e-30), p - 1)
    G = build_G(h, n, dx)
    grad = G.T @ w
    grad -= grad.mean()  # project out the sum-constraint direction
    return grad, P

    t = 1.0

            break

        t_new = (1.0 + np.sqrt(1.0 + 4.0 * t * t)) / 2.0
        beta = (t - 1.0) / t_new
        y = h + beta * (h - h_prev)
        y = np.clip(y, 0.0, 1.0)
        
        grad, P = smooth_gradient(y, p)
        gnorm = np.linalg.norm(grad)
        if gnorm < 1e-14:
            break
        grad_normed = grad / gnorm
        
        # Backtracking line search
        best_alpha = None
        for a in [alpha, alpha*0.5, alpha*0.25, alpha*0.1, alpha*0.05, alpha*0.01]:
            h_try = repair_feasible(y - a * gnorm * grad_normed)
            c_try = exact_score(h_try)
            if c_try < best_c - 1e-15:
                best_alpha = a
                h_new = h_try
                break
            elif c_try < exact_score(y) - 1e-15:

                h_new = h_try
                break

                    break
            else:
                alpha *= 0.5
                h_prev = h.copy()
                continue
        
        h_prev = h.copy()
        h = h_new
        t = t_new
        
        c = exact_score(h)
        if c < best_c:
            best_c = c
            best_h = h.copy()
    
    return best_h, best_c

For the coordinate descent, here's the idea:
- At each step, pick a random pair (i, j)
- Try changing h[i] by +δ and h[j] by -δ (and vice versa)
- Find the best δ that minimizes the max of the modified profile
- Use bisection or a direct computation

For the "direct computation" of the best δ:
The modified profile is P_new[m] = P[m] + δ * (G[m,i] - G[m,j])
We want to minimize max_m P_new[m] over δ ∈ [δ_min, δ_max]
where δ_min = max(-h[i], h[j]-1) and δ_max = min(1-h[i], h[j])

This is a 1D minimax of linear functions, which can be solved in O(M log M) time:
1. Compute all the "crossing" δ values where P_new[m1] = P_new[m2]
2. Evaluate max_m P_new[m] at each crossing and at the boundaries
3. Pick the best

But O(M²) crossings is expensive. Instead, use bisection on the 1D function f(δ) = max_m P[m] + δ * (G[m,i] - G[m,j]).

f(δ) is a convex piecewise-linear function, so bisection works.

Let me code this:

```python
def coord_pair_optimize(h, i, j, P, G):
    """Find best delta for swapping h[i] and h[j]."""
    n = len(h)
    dG = G[:, i] - G[:, j]  # change in profile per unit delta
    P0 = P.copy()
    
    # delta range: h[i] + delta in [0,1], h[j] - delta in [0,1]
    d_min = max(-h[i], h[j] - 1.0)
    d_max = min(1.0 - h[i], h[j])
    
    if d_max - d_min < 1e-15:
        return 0.0, P0
    
    def f(d):
        return np.max(P0 + d * dG)
    
    # Bisection for the minimum of a convex piecewise-linear function
    # Use ternary search instead (simpler)
    lo, hi = d_min, d_max
    for _ in range(40):
        m1 = lo + (hi - lo) / 3.0
        m2 = hi - (hi - lo) / 3.0
        if f(m1) < f(m2):
            hi = m2
        else:
            lo = m1
    delta = (lo + hi) / 2.0
    return delta, P0 + delta * dG
```
