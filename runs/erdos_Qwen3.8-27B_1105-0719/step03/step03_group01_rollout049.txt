Let me also add a simple "coordinate descent" style polish: for each coordinate i, try to optimize h[i] while keeping others fixed. This is a 1D problem (for each i) and can be solved very fast.

For fixed h[-i], the objective C₅(h) as a function of h[i] is:
C₅(h) = max_k [corr_k(h) * dx]

where corr_k(h) is linear in h[i] (since corr_k = sum h[j](1-h[j+k]) and h[i] appears in at most 2 terms for each k).

Wait, actually for a fixed k, corr_k(h) is bilinear in h in general, but if we're only varying h[i], then for each k, corr_k is at most quadratic in h[i] (since h[i] appears in at most 2 products: h[i]*(1-h[i+k]) and h[i-k]*(1-h[i])).

So for each k, corr_k as a function of h[i] is a quadratic (or linear) function. And C₅(h) = max_k dx * corr_k(h) is the max of quadratics, which is a convex function of h[i] (max of convex functions is convex, but max of nonconvex functions is...).

Wait, each corr_k as a function of h[i] is:
- If i is one of the indices in the sum for corr_k: corr_k = a*h[i] + b*h[i]^2 + c (quadratic)
- The coefficient of h[i]^2 is -1 (from the term -h[i]*h[i+k] or -h[i-k]*h[i])
- So corr_k is concave in h[i] (coefficient -1 < 0)
- max of concave functions is not necessarily convex or concave

So coordinate descent doesn't guarantee convergence. But it can still be useful as a heuristic.

For each i, we want to minimize max_k dx * corr_k(h) over h[i] in [0,1]. This is a 1D minimax problem. We can solve it by:
1. For each k where i appears, compute the quadratic corr_k(t) = a_k*t^2 + b_k*t + c_k for t = h[i]
2. Find the minimum of max_k dx * corr_k(t) over t in [0,1]

The max of quadratics is a piecewise quadratic function. Its minimum can be found by:
- Checking the critical points of each pair of quadratics (where they cross)
- Checking the endpoints t=0 and t=1
- Checking the vertex of each quadratic (if it's a minimum, i.e., a_k > 0)

But since a_k = -1 < 0 for all k, each individual corr_k(t) is a concave quadratic (opens downward). The max of concave quadratics is... complicated.

Actually, let me simplify. For a given i, the indices k where i appears are those where i is in the valid range for offset d_k. For offset d, i appears if:
- If d >= 0: i is in [0, n-d-1], and i+d < n
- If d < 0: i is in [-d, n-1], and i+d >= 0

For i to appear in corr_k (offset d = k-(n-1)):
- i + d must be in [0, n-1] and i must be in [0, n-1]
- So i in [-d, n-1-d] (clamped to [0, n-1])

The number of k where i appears is at most 2*min(i+1, n-1-i) + 1 ≈ 2*min(i, n-i) which is at most n.

So for each i, we need to check at most n quadratics. For n=126, that's 126 quadratics per coordinate, and 126 coordinates total. That's 126*126 = 15876 quadratic evaluations, which is fast.

    return float(corr.max() * dx)

    offset = k - (n - 1)
    grad = np.zeros(n)
    i_lo = max(0, -offset)
    i_hi = min(n - 1, n - 1 - offset)
    if i_lo > i_hi:
        return grad
    idx = np.arange(i_lo, i_hi + 1)
    j1 = idx + offset
    grad[j1] += (1.0 - h[idx])
    grad[idx] += (-h[idx + offset])
    return grad

        return x[0]

        g[0] = 1.0
        return g

def pair_polish(h, n, dx, target_sum, t0, budget, n_pairs=200):
    """Pair-wise line search polish."""
    best_h = h.copy()
    best_c5 = compute_c5(best_h, dx)
    rng = np.random.RandomState(123)
    
    for _ in range(n_pairs):
        if time.time() - t0 > budget:
            break
        
        i = rng.randint(n)
        j = rng.randint(n)
        if i == j:
            continue
        
        # Direction: e_i - e_j (preserves sum)
        # h_new = best_h + alpha * (e_i - e_j)
        # = best_h with h[i] += alpha, h[j] -= alpha
        # Bounds: 0 <= best_h[i] + alpha <= 1 and 0 <= best_h[j] - alpha <= 1
        # => -best_h[i] <= alpha <= 1 - best_h[i]
        # => best_h[j] - 1 <= alpha <= best_h[j]
        lo = max(-best_h[i], best_h[j] - 1.0)
        hi = min(1.0 - best_h[i], best_h[j])
        if hi - lo < 1e-10:
            continue
        
        def obj_1d(alpha):
            h_new = best_h.copy()
            h_new[i] += alpha
            h_new[j] -= alpha
            return compute_c5(h_new, dx)
        
        try:
            res = minimize_scalar(obj_1d, bounds=(lo, hi), method='bounded',
                                 options={'maxiter': 30})
            if res.fun < best_c5 - 1e-12:
                best_h[i] += res.x
                best_h[j] -= res.x
                best_c5 = res.fun
        except Exception:
            pass
    
    return best_h, best_c5
