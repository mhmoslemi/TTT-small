We can find it as follows:

2. The upper envelope at x=0 is determined by the max a_k
3. As x increases, lines with larger b_k become dominant
4. As x decreases, lines with smaller b_k become dominant

The minimum of the upper envelope is where the "left-dominant" and "right-dominant" lines meet.

Algorithm:
1. Find k_max = argmax_k a_k (the dominant line at x=0)
2. If b_{k_max} < 0: the function is decreasing at x=0, so we want to go right

   - Continue until we find a line with b > 0 that crosses
3. If b_{k_max} > 0: the function is increasing at x=0, so we want to go left
   - Similar in the other direction
4. If b_{k_max} = 0: x=0 is optimal (or we're at a flat spot)

This is essentially walking along the upper envelope, which takes O(n log n) with a convex hull trick, or O(n²) naively.

def compute_all_grads(h):
    n = len(h)
    offsets = np.arange(2*n-1) - (n-1)
    # grad[i, k] = (1-h[i-d_k])*[0<=i-d_k<n] - h[i+d_k]*[0<=i+d_k<n]
    # For each i, d_k ranges over offsets
    # i - d_k ranges over i - offsets for all k
    # i + d_k ranges over i + offsets for all k
    
    i_idx = np.arange(n)[:, None]  # shape (n, 1)
    d = offsets[None, :]  # shape (1, 2n-1)
    
    im = i_idx - d  # shape (n, 2n-1)
    ip = i_idx + d
    
    mask_m = (im >= 0) & (im < n)  # shape (n, 2n-1)
    mask_p = (ip >= 0) & (ip < n)
    
    # For valid entries: 1 - h[im] for mask_m, h[ip] for mask_p
    im_clip = np.clip(im, 0, n-1)
    ip_clip = np.clip(ip, 0, n-1)
