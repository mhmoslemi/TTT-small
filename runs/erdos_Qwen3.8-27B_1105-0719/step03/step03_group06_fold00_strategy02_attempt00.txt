1. Approach and rationale

The parent construction (often `initial_h_values`, reported n≈70, score around 0.380917) was evolved by local nonsmooth descent and epigraph SLSQP. The remaining gap to the desired 0.3808 is small, but a local dense-vector method is likely trapped by a plateau of nearly active correlation rows. Instead of adding another variant of signed-gradient descent, the proposed method changes the decision space for many dimensions.

Central idea: solve exactly, in the finite arithmetic of the evaluator, for binary step functions whose elements are only 0 or 1. For such a vector, all correlation terms are integer transition counts times dx. The nonconvex dependence on h is exactly linearized by introducing a binary transition indicator for every ordered pair of samples. One then asks a Mixed Integer Linear Program (MILP) whether a binary vector of selected length satisfies upper bounds on both lag orientations. The MILP either proves a candidate incumbent for the exact finite model, provides rounded propositions, or fails/times out. Every proposition is returned only after validated by the actual evaluator `max(np.correlate(h, 1-h, mode="full") * (2/n))`. Parent fallback is always retained.

Why this can improve the parent:
- The evaluator for binary h is exactly a weighted max over discrete transition counts. In that regime the objective is not a meaningless relaxation; it is an integer profile count. Therefore a feasible MILP solution is feasible for the original task, not a surrogate.
- Exact local ridge metrics can remove an entire lag violation with one coordinate, whereas a dense local continuous objective gets stuck when a single subgradient direction does not decrease the maximum. Integer transport exploration moves the feasible set itself at correlated or near-correlated scores and yields nonlocal jump candidates that can then be smoothed. This gives a new basin to polish.
- If a dimension that has fewer-than-or-equal target cutoff can be solved exactly for a restricted feasible model, it can push the empirical bound down from relaxing.
- Small supplies can return smaller faster arrays; bigger dimensions have a finer increment and less discrete loss.
- This is conceptually independent from varying LSE, SLSQP restarts, or dimension interpolation, though it can use the parent as incumbent and reuse simple feasibility repair to avoid return/evaluation failure.

Limitations, clearly separated from facts:
- A MILP/P/cpp branch may not solve even moderate n within the budget. The algorithm is constructive, and no optimality, guarantee of reaching target 0.3808, or "global nonconvex solver" is claimed.
- If a MILP solution does not have a valid solution it is not trusted for update unless exact profile validates it; rules have no implication of optimality outside evaluated range.
- The integer transition model explicitly upper-bounds both orientation values per lag because correlation implementation sign conventions/notation may differ. It is called exact in terms of accepted candidate acceptance checking; it only translates MILP variable sum limits into exact objective revaluation on a base control and never needs an untruth model return record.
