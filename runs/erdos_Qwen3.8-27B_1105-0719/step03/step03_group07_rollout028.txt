5. The feasible range of δ: we need 0 <= a+δ <= 1 and 0 <= b-δ <= 1, so δ ∈ [max(-a, b-1), min(1-a, b)]
6. Find the minimum of f(δ) on this interval using convex optimization (e.g., ternary search or subgradient method).

Step 5: δ_low = max(-a, b-1), δ_high = min(1-a, b)
Note: δ_low <= 0 <= δ_high always (since 0<=a,b<=1).

- The minimum is where 0 ∈ [min_i g_i, max_i g_i], i.e., min_i g_i <= 0 <= max_i g_i

def repair_feasible(vec):
    n = len(vec)
    h = np.clip(np.asarray(vec, dtype=np.float64), 0.0, 1.0)
    target = n / 2.0
    diff = target - h.sum()
    if abs(diff) < 1e-14:
        return h
    if diff > 0:
        capacity = 1.0 - h
        order = np.argsort(-capacity)
        remaining = diff
        for i in range(n):
            idx = order[i]
            add = min(remaining, capacity[idx])
            h[idx] += add
            remaining -= add
            if remaining <= 1e-12:
                break
    else:
        order = np.argsort(h)
        remaining = -diff
        for i in range(n):
            idx = order[i]
            rem = min(remaining, h[idx])
            h[idx] -= rem
            remaining -= rem
