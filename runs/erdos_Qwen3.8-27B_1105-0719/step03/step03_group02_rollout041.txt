Actually, the standard algorithm for finding the minimum of a max of linear functions in 1D:
- The subdifferential of f at eps is the convex hull of {s_k : k such that c_k + eps*s_k = f(eps)}
- f is minimized where 0 ∈ subdifferential, i.e., min{s_k : c_k + eps*s_k = f(eps)} ≤ 0 ≤ max{s_k : c_k + eps*s_k = f(eps)}

Practical algorithm:
1. Start at eps = 0 (or lo, or hi)
2. Find the set S = argmax_k (c_k + eps*s_k)
3. If min(s_k for k in S) ≤ 0 ≤ max(s_k for k in S), we're at the minimum
4. Otherwise:
   - If all s_k for k in S are > 0: f is decreasing, move eps down
   - If all s_k for k in S are < 0: f is increasing, move eps up
5. Move to the nearest breakpoint (where a non-active line catches up to the max)

This is essentially the simplex method for the 1D LP, and it terminates in at most n steps (each step removes one line from the "far" side).

def pair_slope(h, i, j):
    """Compute s[k] = d(c_k)/d(eps) for swap h[i]-eps, h[j]+eps."""
    n = len(h)
    s = np.zeros(2*n - 1)
    for k in range(2*n - 1):
        offset = k - (n-1)
        lo = max(0, -offset)
        hi = min(n-1, n-1-offset)
        if lo > hi:
            continue
        # coeff for position m:
        # (1-h[m-offset]) if lo <= m-offset <= hi (and 0 <= m-offset < n)
        # - h[m+offset] if lo <= m <= hi (and 0 <= m+offset < n)
        
        def coeff(m):
            val = 0.0
            m_off = m - offset
            if lo <= m_off <= hi and 0 <= m_off < n:
                val += (1.0 - h[m_off])
            m_plus = m + offset
            if lo <= m <= hi and 0 <= m_plus < n:
                val += -h[m_plus]
            return val
        
        s[k] = coeff(j) - coeff(i)
    return s
