1. Approach and rationale

1.1 Central idea

   Build a different local/global optimizer from the supplied parent by replacing repeated linearized active-set linear programs with:
   - continuation in a smooth soft-max surrogate of the exact finite-lag overlap objective;
   - randomized exponentially weighted supergradient descent with feasible Euclidean projection;
   - low-dimensional differential-evolution searches in smooth zero-sum modes around the parent;
   - exact stochastic two-coordinate moves judged by the original evaluator;
   - guarded multi-resolution transfers of the current best construction.

   The previous LP method relies on first-order linearizations over selected lag constraints. The new method uses smooth supergradient information, second-order-like escape through randomized soft-max weights, stochastic global subspace moves, and exact pairwise constrained moves that directly inspect the original discretized correlation vector. The smooth surrogate gives a richer direction set than a single hard active-set LP. The stochastic and low-dimensional searches attempt to leave the basin of the parent. Every update is accepted only if the exact evaluator value improves a retained valid candidate.

1.2 Why this could improve the parent

   The exact objective is a highly nonsmooth maximum of many bilinear functions. When current top correlations are nearly tied, first-order directions can be very closely aligned and cancel after the sum-zero constraint. Replacing the max with a soft-max gives a differentiable objective whose weighted gradient can lower slightly lower lag terms while protecting current maxima. Small random perturbations in the exponential weights can produce exchange directions that a deterministic linearization misses. Exact pairwise coordinate moves can exploit quadratic curvature from terms `h_i (1 - h_j)` and `h_j (1 - h_i)` that any first-order model does not see.

1.3 Scope and limitations

   The algorithm is heuristic. It does not prove optimality and does not guarantee reaching the target numeric bound. It is a finite-dimensional local-global stochastic refinement. The returned output will always be the best valid vector found; if the global method fails, a validated parent or algorithmic fallback is returned.

   All final candidates must be projected into the box-sum feasible set and re-evaluated with the original evaluator:
   `dx * max(np.correlate(h, 1.0 - h, mode='full'))`.

1.4 Primary budget balance

2.2 Exact lag and gradient convention

   Use natural offset convention. For full-correlation index `k = 0, 1, ..., 2n-2`, define:
