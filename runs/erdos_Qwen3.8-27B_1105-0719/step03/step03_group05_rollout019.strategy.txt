1. Approach and rationale

1.1 Central idea
The supplied parent construction is already a strong discretized local optimum, achieved here by generic smoothing, epigraph solvers, active-set descent and resolution changes. To get below the current bound, the search must avoid spending most of its budget repeatedly enforcing the mass constraint in the original coordinate system. This plan introduces a different primary feasible-search primitive: work in the complement symmetric (anti-reflective) subspace
    h(x) + h(2 - x) = 1,
or its grid analogue, where the integral constraint sum(h) = n/2 is automatically satisfied. In this subspace the full state is determined by only the left half of the step function, and every coordinate or reduced-direction move is automatically feasible. Optimization is then performed by exact evaluator-aware searches over low-dimensional feasible curves:
- one-variable complement moves,
- pair moves among reduced coordinates,
- exact line searches along weighted reduced gradient directions,
- randomized reduced-coordinate moves,
- reduced epigraph local solves,
- occasional full-vector complement-preserving pair jumps on the unrestricted family.

All candidate decisions are made from the authoritative objective
    max(np.correlate(h, 1 - h, mode='full') * dx),
not from milder surrogate values. The reduced smoothing function and epigraph constraints are only proposal generators; a candidate is kept only if its exact full objective improves or sufficiently advances the local face profile, and the maintained global best is always returned after final validation.

1.2 Why this can reduce the bound
The main bottleneck of the previous parent is a nonconvex local plateau in full coordinates. The mass constraint sum(h)=n/2 couples all coordinates and can make active-set line searches lose many directions except as gradient approximations. In the complement symmetric subspace:
- the feasible set is exactly the box [0,1]^m in reduced variables plus fixed mirror centering, avoiding costly repairs during the inner loop;
- every single reduced coordinate line changes two full samples in opposite directions while preserving mass identically, so accurate exact line searches are cheap and valid;
- reduced pair and vector line searches give many different nonconvex 1D slices through the same feasible high-dimensional set;
- dimensionality is halved, allowing more trials, more exact line samples, and fewer constraint tests inside a fixed budget.

This is a materially different operating geometry from the previous program's main LSE/SLSQP/anti-perturbation mixture. The previous program primarily worked in full coordinates, using anti-symmetrization as a temporary projection or perturbation. Here the complement symmetric family is the main optimization environment, and exact one-dimensional feasible slice optimization is the central mechanism. The unrestricted full-vector pair line searches are retained only as escape moves around the inherited parent between symmetric proposals.

1.3 Scope and limitations
This remains a nonconvex local and basin-trust search. The complement symmetric constraint is mathematically meaningful because it implies the required integral for any admissible h, but it is a deliberate heuristic restriction. Without proof it is not assumed that the global optimum lies there. Therefore the program must maintain the original repaired parent, possibly symmetrized / projected variants and several resolution candidates in a pool, and must never discard the best exact incumbent. No claim of a global optimum is made, and no relaxed subproblem is claimed to solve the original nonconvex problem. The method gives valid upper bounds by returning a feasible h and recomputing the evaluator objective.

1.4 Difference from unverified prior strategy plans
The earlier strategies mixed generic pair moves, smoothing descent, SLSQP and random choices without making a feasible-steering subspace the primary geometry. This plan makes anti-reflection:
    h_left variables, h_right = 1 - reverse(h_left)
the exact feasible parameterization. It introduces deterministic directionful line proposals over the reduced box and full-vector mass-preserving pair searches. The key methodological difference is that feasibility is met identically and the local search spends its budget on exact 1D slices inside a reduced no-repair feasible space.

2. Mathematical specification

2.1 Representation and exact evaluator
Let n be the final number of points. Work mostly with even n = 2m, with deterministic fallback to odd n = 2m + 1 using a fixed center coordinate. Define dx = 2.0 / n. For a feasible vector h in R^n, the evaluator-compatible profile is
    P_j(h) = dx * np.correlate(h, 1 - h, mode='full')_j,
with j = 0, ..., 2n-2.
    C_5(h) = max_j P_j(h).
This is the authoritative objective. All acceptance tests use this exact C_5 after constructing or repairing the candidate.

A mathematically equivalent internal profile convention for proposal generation is:
For row index q, define lag s = q - (n - 1).
- If s >= 0,
    F_s^+(h) = dx * sum_{i=0}^{n-1-s} h_i * (1 - h_{i+s}).
- If s = -r with r > 0,
    F_{-r}^-(h) = dx * sum_{i=0}^{n-1-r} h_{i+r} * (1 - h_i).
These rows contain the two overlap directions for every nonzero lag and the diagonal overlap at s=0. This internal profile may correspond to the evaluator profile up to a permutation relative to np.correlate; C_5 is unaffected because it is the maximum of the same set of overlaps. All final candidates are still scored by the original np.correlate formula. The derivative matrix below is defined for this internal row convention, not for any row of an unspecified outer profile. If the implementation observes a gradient mistake, exact line and pair procedures must remain active as they do not require derivatives.

2.2 Complement symmetry and feasible reduced variables
For even n=2m:
    y = (y_0,...,y_{m-1}), with 0 <= y_j <= 1,
    h_j = y_j for j=0,...,m-1,
    h_{n-1-j} = 1 - y_j for j=0,...,m-1.
For odd n=2m+1:
    h_j = y_j for j=0,...,m-1,
    h_m = 1/2,
    h_{n-1-j} = 1 - y_j for j=0,...,m-1.
A direct calculus argument gives exact mass satisfaction:
- even: sum_{j=0}^{m-1}[y_j + (1 - y_j)] = m = n/2.
- odd: sum_{j=0}^{m-1}1 + 1/2 = m + 1/2 = n/2.
Bound satisfaction follows because each full coordinate is either y_j or 1-y_j. This parameterization achieves 0 <= h <= 1 and sum = n/2 by identities in exact arithmetic. Finite floating rounding can leave a very small deviation; final validation uses an exact repair step that only modifies coordinate entries in bounds without depending on the reduced family. Search proposals inside reduced coordinates are allowed to use identities for feasibility and exact objective instead of repairing after every single proposal.

2.3 Projecting a feasible parent into the anti subspace
For a feasible h_old of length n_old:
- If target length n itself is handled directly, simply construct anti vector from h_old rebuilt at n; if n_old = n, use y_j = 0.5*(h_old_j + 1 - h_old_{n-1-j}) for j in reduced range.
- If n_old differs, first apply area-preserving interpolation to a candidate h_interp: for each old bin interval [a,b) = [j*2/n_old, (j+1)*2/n_old) and target interval [c,d) = [k*2/n_new, (k+1)*2/n_new), compute w_{j,k}=max(0,min(b,d)-max(a,c)), h_interp_k = sum_j w_{j,k} h_old_j / sum_j w_{j,k} if denominator > 0, otherwise 0.5.
- repair_feasible(h_interp) to enforce bounds and sum.
Then build anti y from the repaired h_interp using the reduced projection. Evaluate C_5 of fully built h_antзмы and accept only if it is finite and feasible. The parent exact h remains stored as fallback.

2.4 One-dimensional feasible lines in reduced coordinates
Let m reduced variables be y.

Single reduced coordinate move between levels y_j+t and mirror complement:
    y_j' = y_j + t.
The feasible interval for t is
    t_min = -y_j,    t_max = 1 - y_j.

Reduced pair move:
    y_i' = y_i + t,
    y_j' = y_j - t.
Feasibility:
    t >= -y_i,
    t <= 1 - y_i,
    t >= y_j - 1,
    t <= y_j.
Thus
    t_min = max(-y_i, y_j - 1),
    t_max = min(1 - y_i, y_j).
A valid line exists if t_min < t_max - 1e-14.

Full unrestricted mass-preserving pair move on h of possibly non-symmetric feasible h:
    h_i' = h_i + t,
    h_j' = h_j - t.
Feasibility:
    t >= -h_i,  t <= 1 - h_i,  t >= h_j - 1,  t <= h_j,
so the same interval formula with y replaced by h_i and h_j. The sum remains unchanged because total change is +t and -t. This preserves mass between floating operations and candidate numerical changes are only final-sanitized.

These lines can produce exact full objective score-compatible candidates while always preserving constraints to machine precision. The single reduced coordinate is not a simple pair mass transfer but an exact full move by +t on left coordinate and -t on mirrored coordinate, with the switched pair, while preserving the identity mass.

2.5 Derivatives for weighted gradient directions only
Derivative information should never replace exact values in acceptance. It guides proposal generation and the backward/backtracking loop in reduced LSE.

2.5.1 Full gradient matrix for row generator F_s
Let G[2n-1,n] be the derivative of internal overlap vector from section 2.1 ignoring dx. Set G zero. For diagonal lag s=0:
    for i=0,...,n-1: G[i,i] = dx * (1 - 2*h_i).
For positive lag s>0, suppose relevant shift row selection:
    row = q, corresponding s=q-(n-1) > 0.
For i=0,...,n-1-s:
    G[row, i]  += dx * (1 - h_{i+s})
    G[row, i+s] += dx * (-h_i)
For negative lag s=-r<0:
    row = q.
For i=0,...,n-1-r:
    G[row, i+r] += dx * (1 - h_i)
    G[row, i]   += dx * (-h_{i+r})
This is used both with row weights and local linearized constraints. Its accuracy may deviate due orientation from np.correlate, which is a helper constraint; exact evaluation remains authoritative.
