1. Approach and rationale

The objective is a finite-domain finite-correlation maximum:
\[
C_5(h)=\max_{0\le r<2n-1} \left(\operatorname{corr}(h,1-h)_{\text{full}}[r]\cdot \frac{2}{n}\right),
\]
subject to \(0\le h_i\le 1\) and \(\sum_i h_i=n/2\). The problem is nonconvex because the correlated quantities contain the bilinear terms \(h_i(1-h_j)\). The supplied local optimizer can become trapped in a local pattern of active lag constraints. The proposed improvement has two major changes relative to the parent program:

1. A global discrete exploration phase using balanced binary strings and a memetic/simulated-annealing search over swap neighborhoods. For binary vectors the objective is equal to an exact nonzero-lag overlap count multiplied by \(dx\). This phase explores basins that a continuous local method can miss.
2. A threshold-targeting projected-penalty phase. Instead of only maximizing a smoothed maximum directly, it tries to make all correlations below explicit targets slightly more ambitious than the current best. The target is relaxed into squared hinge losses and minimized with projected gradient steps; exact candidate acceptance is always made from the actual evaluator.

The method combines:
- exploration: many balanced binary members with local guided swaps;
- coarse-to-fine discretization testing over manageable grids;
- exact validation and comparison by the definition of the evaluator;
- local polishing using a linearized active-set LP trust-region and two SLSQP passes (direct and for variable \(h\) through a sigmoid variable).

The plan does not claim a global optimum. Every candidate is evaluated with the exact supplied metric; only a strictly lower exact score replaces the best solution.

2. Mathematical specification

2.1 Objective and correlation indexing

Let \(n\) be even, \(dx=2/n\), \(h\in \mathbb{R}^n\). Let \(g=1-h\). For full correlation used by the evaluator:
\[
c_r = \sum_i h_i g_j,
\]
with the pair indices determined by the full-correlation offset. Use the same offset convention:
\[
s = r-(n-1),
\]
where \(s\) is the integer lag offset. For \(s\ge 0\):
\[
c_r = \sum_{i=0}^{n-1-s} h_{i+s} (1-h_i).
\]
For \(s<0\):
\[
c_r = \sum_{i=-s}^{n-1} h_{i} (1-h_{i+s}),
\]
where \(i+s\) is the second factor index. The objective is
\[
C_5 = \max_r c_r dx.
\]

2.2 Constraint feasibility

Feasible set:
\[
h_i\in[0,1],\quad \sum_i h_i = n/2.
\]
For every returned vector the implementation must re-evaluate the objective and also check bounds and a feasibility tolerance. A binary bitstring of even length \(n\) with exactly \(n/2\) entries equal to 1 is exactly feasible in floating point. For continuous vectors use water-filling projection, where for scalar \(t\):
\[
h_i(t)=\min(1,\max(0, x_i-t)),
\]
and \(t\) is found by bisection so that \(\sum_i h_i(t)\approx n/2\). This projection projects minimally under a common shift to the box and sum. Floating-point equality checks should use tolerance around \(10^{-10}\), but construction of binary valid vectors and final correction maintains high exactness.

2.3 Exact gradient of a correlation coordinate

For a full-correlation coordinate \(r\) with offset \(s=r-(n-1)\), without code, the gradient vector \(\nabla_h c_r\) is assembled as follows.

For \(s\ge 0\), let \(i=0,1,\ldots,n-1-s\):
\[
\frac{\partial c_r}{\partial h_{i+s}} \mathrel{+}= 1-h_i,
\]
\[
\frac{\partial c_r}{\partial h_i} \mathrel{-}= h_{i+s}.
\]

For \(s<0\), let \(i=-s,-s+1,\ldots,n-1\):
\[
\frac{\partial c_r}{\partial h_i} \mathrel{+}= 1-h_{i+s},
\]
\[
\frac{\partial c_r}{\partial h_{i+s}} \mathrel{-}= h_i.
\]

This derivative convention matches the evaluator's ring-full correlation if the formula is applied to the same lag coordinate. In implementation, after adding all active coordinate gradients, compare an exact finite difference derivative with this formula for one small random lag and one small perturbation during a self-test. If derivative-mismatch detected, rely solely on gradient-free guided binary search and active-set finite differences.

2.4 Penalty threshold for descent

For a current feasible candidate \(h\), let
\[
q_j = c_j(h)dx.
\]
Choose target \(t<c_5(h)\). Define squared positive-part penalty:
\[
\Phi_t(h) = \sum_j [\max(0,q_j-t)]^2.
\]
Its gradient, usually zero except for correlations above the target, is
\[
\nabla\Phi_t(h) = 2dx \sum_{j:q_j>t} (q_j-t) \nabla c_j(h).
\]
The target-penalty descent can reduce the exact maximum below the current value and sometimes cross a lower plateau. Every proposal still uses actual \(c(h)\).

2.5 Active-set linearized trust-region LP

Once \(h\) is nearly locally optimal, use a first-order linearization of active lags. Let active set be the \(n_k\) largest correlations within a tolerance, or the largest \(30\) correlations, excluding only trivial zero lag. For each active lag \(r\), let \(v_r=\nabla c_r(h)\). A move \(\delta\) changes
\[
q_r(h+\delta) \approx q_r(h) + dx\, v_r^T\delta.
\]
Solve the linear program:
\[
\min_{\delta,\tau}\ \tau
\]
subject to
\[
q_r(h)+dx\,v_r^T\delta \le \tau \quad \forall r\in A,
\]
\[
\sum_i\delta_i=0,
\]
\[
-h_i\le \delta_i \le 1-h_i,
\]
\[
-\ell \le \delta_i \le \ell.
\]
The initial trust radius \(\ell\) is determined by time and number of variables. A line search accepts a move only if exact \(C_5\) decreases. If not, shrink \(\ell\) geometrically. If LP fails, leave candidate unchanged. This is not convex in original variables because products are replaced by first-order affine estimates, but exact post-polishing is tolerance-friendly.

2.6 Binary formulation

For a binary vector \(b\in\{0,1\}^n\) with exactly \(n/2\) ones, let
\[
m = \max_r \operatorname{corr}(b,1-b)_{\text{full}}[r].
\]
Then
\[
C_5 = mdx.
