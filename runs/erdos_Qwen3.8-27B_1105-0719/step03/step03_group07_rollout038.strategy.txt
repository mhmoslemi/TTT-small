1.1 Central idea

The supplied parent (`initial_h_values`, normally length `n = 70`) is retained as a valid fallback, but it will not be the only driver of the search. The proposed method is a two-tier nonconvex search:

Tier A: construct and improve diverse binary/substep combinatorial structures over a set of nearby sample counts. In discretized form with binary values, the task value is exactly `dx` times the largest integer number of overlap violations among all finite-support lags. This discrete representation exposes the bottleneck most clearly. A goal-directed binary annealing and local-exchange search builds an archive of half-balanced binary patterns whose exact task objective is often only one or two discrete units below a continuous local optimum. These patterns are accepted only when re-evaluated on the original evaluator, not when judged by surrogate counts.

Tier B: continuous fractional reconstruction and descent from binary structures. From the best patterns and from the parent we form multiple full vectors satisfying the exact sum constraint, either by threshold conversion, stage blends, or interpolation to nearby dimensions. Each vector is refined by a primary sequential linear programming (SLP) minimax method and exact two-variable preserving-sum corrections. The SLP is the key difference from the unused soft-max/SLSQP pipeline: at each iteration it linearizes every finite-support correlation value simultaneously and solves a bounded linear minimax subproblem that proposes one direction that should reduce all first-order tangent approximations at once. Exact acceptance on the original correlation objective is always required, so the linear model may underproduce true improvement but cannot turn an invalid or worsening model step into a returned candidate.

The overall pipeline is nonconvex and heuristic; it does not claim global optimality. The justified facts are: exact evaluation of every candidate; exact preservation of the sum and bound constraints; correctness of the linearized objective directions given the same indexing as `np.correlate`; and the possibility of marginal improvement by exposing discrete flat directions or alternative basins not visible from the previous parent.

A pair-preserving-sum exact line search can exploit boundary fractional split-downs that a coordinatewise repair search can miss.
