Let me think about what would actually work well here. The key insight is that the objective is the maximum of many correlation values, and we want to push them all down simultaneously.

Key ideas to implement:
1. **LSE-based gradient descent**: Instead of picking the single maximum row, use a softmax-weighted combination of gradients from all rows (weighted by exp(beta * p_m)). This creates a smooth surrogate that naturally balances pushing down multiple rows.

2. **Trust-region SLP**: At each point, linearize all rows and solve an LP to find the best direction that simultaneously reduces the linearized objective.

3. **Multiple starting dimensions**: Try different grid sizes to escape local optima.

4. **Binary/near-binary seeds**: The optimal solution for this type of problem tends to be near-binary (values close to 0 or 1), so exploring near-binary starting points makes sense.

Let me think about the LSE approach more carefully:

The LSE objective is:
s_beta(h) = (1/beta) * log(sum_m exp(beta * p_m(h)))

Its gradient is:
∇s_beta = (1/sum(exp(beta*p_m))) * sum_m exp(beta*p_m) * ∇p_m

This is a weighted average of the row gradients, where weights are softmax(beta * p_m).

As beta → ∞, this approaches the gradient of the max (subgradient at the argmax).
For moderate beta, it smoothly interpolates, pushing down multiple rows simultaneously.

For the trust-region SLP:
- At point h, compute all row gradients G (M × n matrix)
- Solve: min t s.t. G @ d + p <= t, sum(d) = 0, |d_j| <= R_j
- This is a linear program that finds the best first-order improvement

import numpy as np
from scipy.optimize import minimize, linprog

def repair_feasible(vec):
    n = len(vec)
    h = np.clip(np.asarray(vec, dtype=np.float64), 0.0, 1.0)
    target = n / 2.0
    diff = target - h.sum()
    if abs(diff) < 1e-14:
        return h
    if diff > 0:
        order = np.argsort(-(1.0 - h))
        remaining = diff
        for i in range(n):
            idx = order[i]
            cap = 1.0 - h[idx]
            if cap <= 1e-15:
                continue
            add = min(remaining, cap)
            h[idx] += add
            remaining -= add
            if remaining <= 1e-14:
                break
    else:
        order = np.argsort(h)
        remaining = -diff
        for i in range(n):
            idx = order[i]
            if h[idx] <= 1e-15:
                continue
            rem = min(remaining, h[idx])
            h[idx] -= rem
            remaining -= rem
            if remaining <= 1e-14:
                break
    diff2 = target - h.sum()
    if abs(diff2) > 1e-15:
        if diff2 > 0:
            idx = int(np.argmax(1.0 - h))
        else:
            idx = int(np.argmax(h))
        h[idx] = float(np.clip(h[idx] + diff2, 0.0, 1.0))
    return h

def exact_score(h):
    n = len(h)
    dx = 2.0 / n
    return float(np.max(np.correlate(h, 1 - h, mode="full") * dx))

def compute_profile(h):
    n = len(h)
    dx = 2.0 / n
    return np.correlate(h, 1 - h, mode="full") * dx

def grad_row(h, m, n):
    dx = 2.0 / n
    d = m - (n - 1)
    if d == 0:
        return dx * (1.0 - 2.0 * h)
    elif d > 0:
        g = np.zeros(n)
        g[d:] += dx * (1.0 - h[:-d])
        g[:-d] -= dx * h[d:]
        return g
    else:
        p = -d
        g = np.zeros(n)
        g[:-p] += dx * (1.0 - h[p:])
        g[p:] -= dx * h[:-p]
        return g

def lse_gradient(h, beta):
    """Compute gradient of LSE objective."""
    n = len(h)
    dx = 2.0 / n
    M = 2 * n - 1
    profile = np.correlate(h, 1 - h, mode="full") * dx
    c = profile.max()
    z = np.exp(beta * (profile - c))
    w = z / z.sum()
    # Gradient = sum_m w_m * grad_row(h, m)
    g = np.zeros(n)
    for m in range(M):
        g += w[m] * grad_row(h, m, n)
    return g, profile

def lse_descent(h, max_iters=500, beta_start=20.0, beta_end=200.0):
    """LSE-based descent with ascending beta schedule."""
    n = len(h)
    h = h.copy()
    best_c = exact_score(h)
    momentum_vec = np.zeros(n)
    momentum = 0.4
    
    for it in range(max_iters):
        # Linearly interpolate beta

        beta = beta_start * (beta_end / beta_start) ** t
        
        g, profile = lse_gradient(h, beta)
        # Center the gradient (remove mean to preserve sum constraint approximately)
        g -= g.mean()
        gnorm = np.linalg.norm(g)
        if gnorm < 1e-15:
            break
        
        momentum_vec = momentum * momentum_vec + g

        if mv_norm < 1e-15:
