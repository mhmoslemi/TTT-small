**Subgradient descent on the max:**
At each iteration:
1. Compute corrs = compute_corrs(h)
2. Find the max value and all active lags (those within tolerance of max)
3. Compute the average gradient over active lags: g = mean(grad_corr_k for active k)
4. Take a step: h_new = h - lr * g
5. Project: h_new = project_feasible(h_new, target_sum)
6. If the max decreased, accept; otherwise reduce lr.

This is a standard subgradient method for minimizing a max of differentiable functions. It converges slowly but can escape local minima that trap other methods.

    """LP polish using all lags as constraints."""
    n = len(h)
    h = h.copy()
    best_h = h.copy()
    best_c5 = c5_of_h(h, dx)
    step = init_step
    
    for it in range(max_iters):
        corrs = compute_corrs(h)
        c5_val = corrs.max() * dx
        if c5_val < best_c5:
            best_c5 = c5_val
            best_h = h.copy()
        
        # Build LP
        c_obj = np.zeros(n + 1)
        c_obj[n] = 1.0  # minimize t
        
        A_rows = []
        b_rows = []
        for k in range(2 * n - 1):
            g = grad_corr_k(h, k, n)
            row = np.zeros(n + 1)
            row[:n] = dx * g
            row[n] = -1.0
            A_rows.append(row)
            b_rows.append(-corrs[k] * dx)
        
        A_eq = np.zeros((1, n + 1))
        A_eq[0, :n] = 1.0
        b_eq = np.zeros(1)
        
        bounds = []
        for i in range(n):
            lo_i = max(-h[i], -step)
            hi_i = min(1.0 - h[i], step)
            bounds.append((lo_i, hi_i))
        bounds.append((0.0, None))
        
        res = linprog(c_obj, A_ub=np.array(A_rows), b_ub=np.array(b_rows),
                      A_eq=A_eq, b_eq=b_eq, bounds=bounds, method='highs')
        if res.status != 0:
            break
        
        delta = res.x[:n]
        if np.max(np.abs(delta)) < 1e-14:
            break
        
        h_new = project_feasible(h + delta, target)
        new_c5 = c5_of_h(h_new, dx)
        
        if new_c5 < c5_val - 1e-14:
            h = h_new
            step = min(step * 1.1, init_step)

Actually, I realize there might be an issue with the SLSQP approach. The logsumexp smoothing:
phi_beta(h) = (1/beta) * logsumexp(beta * corrs) * dx

This approximates max(corrs) * dx as beta → ∞. But for finite beta, it's a smooth over-approximation. The gradient is:
d(phi_beta)/dh = dx * sum_k exp(beta * corr_k) / sum_j exp(beta * corr_j) * d(corr_k)/dh
= dx * sum_k w_k * d(corr_k)/dh

where w_k = softmax(beta * corrs). This is a weighted average of the correlation gradients, weighted by how close each corr is to the max.

For large beta, only the active lags (those with corr ≈ max) contribute to the gradient. This is similar to the subgradient of the max, but smooth.

The issue with SLSQP is that it uses a quadratic model of the objective, which might not be accurate for the logsumexp function (which is "almost" a max for large beta, and the max is non-smooth). This can cause SLSQP to take very small steps or converge slowly.

A better approach might be to use the logsumexp only for the objective value (for smoothness) but use the exact subgradient for the gradient. Or to use a "hybrid" gradient that blends the smooth gradient with the exact subgradient.
