- h[i-d]*(1-h[i]) where i-d = j: h[j]*(1-t) = (s-t)*(1-t) = t² - (s+1)t + s → convex
- h[j-d]*(1-h[j]) where j-d = i: h[i]*(1-(s-t)) = t*(t+1-s) = t² + (1-s)t → convex

All the "self-interacting" terms (where the two changed coordinates appear in the same product) are convex quadratics. The "cross" terms (where one changed coordinate appears but not the other in the same product) are linear.

So P[k](t) is a sum of:
- Some linear terms
- At most 2 quadratic terms (from the cases where i±d = j or j±d = i)

The total is at most quadratic with non-negative coefficient of t² (it's either 0, 1, or 2 times dx). So it's convex in t.

And the objective max_k P[k](t) is the max of convex functions, which is convex. So we can still do 1D convex minimization!

For the 1D minimization of a max of convex quadratics/linear functions on an interval, I can use:
- Grid search + refinement (simple and robust).
- Or: subgradient method (find where 0 is in the subdifferential).

Grid search with 200 points + refinement should be more than sufficient for the precision we need.

OK let me now also handle the incremental profile update correctly.

When we change h[i] from old_i to new_i and h[j] from old_j to new_j:
For each affected lag k (d = k-(n-1)):
P_new[k] = P_old[k] + delta

where delta = (new contribution) - (old contribution).

The old contribution at lag k involving indices i and j:
- Term A: if 0 ≤ i+d < n: h_old[i+d] * (1-h_old[i])
- Term B: if 0 ≤ i-d < n: h_old[i] * (1-h_old[i-d])  [this is the term where i' = i-d, so h[i'+d] = h[i]]
- Term C: if 0 ≤ j+d < n: h_old[j+d] * (1-h_old[j])
- Term D: if 0 ≤ j-d < n: h_old[j] * (1-h_old[j-d])  [term where i' = j-d, h[i'+d] = h[j]]

The new contribution:
- Term A': if 0 ≤ i+d < n: h_new[i+d] * (1-h_new[i])
- Term B': if 0 ≤ i-d < n: h_new[i] * (1-h_new[i-d])
- Term C': if 0 ≤ j+d < n: h_new[j+d] * (1-h_new[j])
- Term D': if 0 ≤ j-d < n: h_new[j] * (1-h_new[j-d])

But h_new[i] = new_i, h_new[j] = new_j, and for other indices, h_new = h_old.

So:
- If i+d ≠ j: A' = h_old[i+d] * (1-new_i), delta_A = h_old[i+d] * (old_i - new_i) = -h_old[i+d] * delta_i
- If i+d = j: A' = new_j * (1-new_i), delta_A = new_j*(1-new_i) - old_j*(1-old_i) = (s-new_i)*(1-new_i) - (s-old_i)*(1-old_i)

Similarly for the others. This is getting complicated but manageable.

Wait, I need to be careful about the definition. Let me use the definition:
P[d] = sum_{i: 0≤i<n, 0≤i+d<n} h[i+d] * (1-h[i])

For d ≥ 0: i ranges from 0 to n-1-d. P[d] = sum_{i=0}^{n-1-d} h[i+d]*(1-h[i]) = dot(h[d:], (1-h)[:n-d])
For d < 0: let dp = -d > 0. i ranges from dp to n-1. P[d] = sum_{i=dp}^{n-1} h[i-dp]*(1-h[i]). Let j = i-dp, j ranges from 0 to n-1-dp. = sum_{j=0}^{n-1-dp} h[j]*(1-h[j+dp]) = dot(h[:n-dp], (1-h)[dp:])

OK so:
- P[d] for d ≥ 0: dot(h[d:], (1-h)[:n-d])
- P[-dp] for dp > 0: dot(h[:n-dp], (1-h)[dp:])

Note: P[d] + P[-d] is NOT simply related in general (unlike for the autocorrelation).

Let me verify with a simple example. n=3, h = [a, b, c].
P[0] = a(1-a) + b(1-b) + c(1-c)
P[1] = b(1-a) + c(1-b)  [d=1: i ranges 0 to 1, h[i+1]*(1-h[i])]
P[-1] = a(1-b) + b(1-c)  [d=-1: i ranges 1 to 2, h[i-1]*(1-h[i])]

Check: P[1] = b - ab + c - bc, P[-1] = a - ab + b - bc. Not equal in general. Good.
