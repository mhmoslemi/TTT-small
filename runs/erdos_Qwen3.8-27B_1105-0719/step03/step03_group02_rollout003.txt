But can we actually achieve near-uniform correlations? This is related to the theory of difference sets and balanced incomplete block designs.

A (v, k, λ) difference set in a group of order v is a k-element subset D such that every non-identity element is represented exactly λ times as a difference d1 - d2 with d1, d2 ∈ D.

If we can find a difference set, we get exactly uniform correlations!

For our problem, we need a subset of {0, 1, ..., n-1} of size n/2 such that every non-zero difference is represented approximately the same number of times. This is like a "near difference set" or "almost difference set."

The existence of such structures is well-studied. For n = q² - q + 1 (Singer difference sets), we get exact difference sets with k = q, λ = q-1. But k = n/2 = (q²-q+1)/2, so we need q = (q²-q+1)/2, which gives q² - 3q + 1 = 0, not generally integer.

For our case, we want k = n/2 in a group of size n. The parameters would be (n, n/2, λ) where λ(n-1) = k(k-1) = (n/2)(n/2-1) = n(n-2)/4. So λ = (n-2)/(4) * n/(n-1) ≈ n/4 for large n.

For this to be an exact difference set, we need λ to be an integer, so n ≡ 2 (mod 4). E.g., n = 6, 10, 14, 18, ...

For n=6: k=3, λ = 6*4/(4*5) = 24/20 = 6/5. Not integer. So no exact difference set.
