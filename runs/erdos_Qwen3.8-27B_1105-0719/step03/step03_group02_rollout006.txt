    h_new = h + alpha_opt * d
    h_new = project_feasible(h_new, target_sum)
    return h_new, c5_of_h(h_new, dx)

Wait, there's an issue. When I project h_new to be feasible, the result might not be exactly h + alpha_opt*d. The projection clips to [0,1] and adjusts the sum. For small alpha_opt, this should be very close. For larger alpha_opt (like in Frank-Wolfe where we might go all the way to a vertex), the projection could be significant.

For the Frank-Wolfe case, d = v - h where v is a 0-1 vector with n/2 ones. Then h + α*d = (1-α)*h + α*v, which is always in [0,1] for α ∈ [0,1] (convex combination of two points in [0,1]). And sum(h + α*d) = sum(h) + α*sum(d) = n/2 + α*(n/2 - n/2) = n/2. So it's already feasible! No projection needed.

Great, so for Frank-Wolfe, the line search is clean.

For other directions (like -gradient), we need to ensure sum(d) = 0 and the path stays in [0,1]. The projection handles this.

Another idea: **Gauss-Seidel style optimization**. Update one pair of coordinates at a time (like the pair transfer), but with exact line search. Try all pairs (i,j) and for each, find the optimal transfer amount. This is O(n²) per sweep but each subproblem is solved exactly.

But we can be smarter: for a pair (i,j), only the correlations that involve i or j change. That's O(n) correlations affected. So each pair update is O(n), and a full sweep is O(n³) still. For n=146, one sweep is about 146² * 146 ≈ 3 million. With overhead, probably 0.1-0.5 seconds per sweep. So 100-2000 sweeps in the time budget.

Actually, for a pair update (move ε from i to j):
- h[i] -= ε, h[j] += ε
- Correlations affected: those where i or j appears
- For correlation at lag τ: it involves h[k] and h[k+τ] for valid k
  - i appears if i is a valid index (always) → affects lag τ where i is the first or second index
  - j appears similarly

The correlations affected are:
- c_k where i = k_idx or i+τ (for the first factor)
- c_k where j = k_idx or j+τ (for the second factor)

This is O(n) correlations. For each, the change is linear in ε (since we're just changing two entries). So we can compute the new value of each affected correlation as a linear function of ε.

Then the max of all correlations is the max of:
- The unaffected correlations (constant)
- The affected correlations (linear in ε)

So f(ε) = max(constant_max, max of linear functions of ε)

This is a piecewise-linear convex function of ε! We can find its minimum exactly by:
1. Finding all breakpoints (where two linear functions cross)
2. Evaluating at breakpoints and endpoints
3. Taking the minimum

Or more simply, since it's piecewise linear and convex, we can use binary search on the derivative, or just evaluate at a few points.

Actually, for piecewise linear convex functions, the minimum is where the subgradient contains 0. We can find this by:
1. Computing the slope on the left of the feasible interval
2. If slope ≥ 0, minimum is at the left endpoint
3. If slope < 0 at the right endpoint, minimum is at the right endpoint
4. Otherwise, find where the slope crosses 0

The slope of f(ε) at a point is the slope of the active (maximum) linear function. As ε increases, different functions become active.

This is getting complex. Let me just use the simpler approach: for each pair (i,j), do a few evaluations of the true objective at different ε values (e.g., golden section with 20 iterations) and take the best. This is approximate but fast.

Or even simpler: for each pair, compute the optimal ε analytically from the linear approximation, then verify with the true objective.

import numpy as np
from scipy.optimize import minimize, linprog
from scipy.special import logsumexp
import time


def project_feasible(x, target_sum):
    n = len(x)
    lo, hi = -1.0, 1.0
    for _ in range(80):
        mid = (lo + hi) / 2
        h = np.clip(x - mid, 0.0, 1.0)
        if h.sum() > target_sum:
            lo = mid
        else:
            hi = mid
    h = np.clip(x - (lo + hi) * 0.5, 0.0, 1.0)
    diff = target_sum - h.sum()
    if abs(diff) > 1e-14:
        mask = (h > 1e-12) & (h < 1.0 - 1e-12)
        if mask.sum() > 0:
            h[mask] += diff / mask.sum()
    return np.clip(h, 0.0, 1.0)


def compute_corrs(h):
    return np.correlate(h, 1.0 - h, mode='full')


def c5_of_h(h, dx):
    return compute_corrs(h).max() * dx


def grad_corr_k(h, k, n):
    offset = k - (n - 1)
    grad = np.zeros(n)
    i_lo = max(0, -offset)
    i_hi = min(n - 1, n - 1 - offset)
    if i_lo > i_hi:
        return grad
    idx = np.arange(i_lo, i_hi + 1)
    grad[idx] += (1.0 - h[idx + offset])
    grad[idx + offset] += (-h[idx])
    return grad


def smooth_max_grad(h, dx, beta):
    n = len(h)
    corrs = compute_corrs(h)
    shifted = corrs - corrs.max()
    w = np.exp(beta * shifted)
    w_sum = w.sum()
    if w_sum < 1e-30:
        w = np.ones_like(corrs) / len(corrs)
    else:
        w /= w_sum
    grad = np.zeros(n)
    for k in range(2 * n - 1):
        if w[k] > 1e-12:
            grad += w[k] * grad_corr_k(h, k, n)
    return grad * dx


def exact_line_search(h, d, dx, target_sum, n_iter=70):
    n = len(h)
    pos_mask = d > 1e-15
    neg_mask = d < -1e-15
    alpha_lo = 0.0
    alpha_hi = 1.0
    if pos_mask.any():
        alpha_hi = min(alpha_hi, np.min((1.0 - h[pos_mask]) / d[pos_mask]) - 1e-12)
    if neg_mask.any():
        alpha_lo = max(alpha_lo, np.max(h[neg_mask] / (-d[neg_mask])) + 1e-12)
    if alpha_hi <= alpha_lo + 1e-14:
        return h.copy(), c5_of_h(h, dx)

    def f_obj(alpha):
        h_a = h + alpha * d
        return compute_corrs(h_a).max()

    gr = (np.sqrt(5.0) - 1.0) / 2.0
    a, b = alpha_lo, alpha_hi
    c_pt = b - gr * (b - a)
    d_pt = a + gr * (b - a)
    fc, fd = f_obj(c_pt), f_obj(d_pt)
    for _ in range(n_iter):
        if b - a < 1e-14:
            break
        if fc < fd:
            b = d_pt
            d_pt = c_pt
            fd = fc
            c_pt = b - gr * (b - a)
            fc = f_obj(c_pt)
        else:
            a = c_pt
            c_pt = d_pt
            fc = fd
            d_pt = a + gr * (b - a)
            fd = f_obj(d_pt)
    alpha_opt = (a + b) / 2.0
    h_new = h + alpha_opt * d
    h_new = project_feasible(h_new, target_sum)
    return h_new, c5_of_h(h_new, dx)


def fw_exact_step(h, dx, target_sum, beta, rand_vertex=False, rng=None):
    n = len(h)
    n_ones = int(target_sum)
    if rand_vertex and rng is not None:
        v = np.zeros(n)
        v[rng.choice(n, size=n_ones, replace=False)] = 1.0
    else:
        g = smooth_max_grad(h, dx, beta)
        idx_sorted = np.argsort(g)
        v = np.zeros(n)
        v[idx_sorted[:n_ones]] = 1.0
    d = v - h
    if np.max(np.abs(d)) < 1e-15:
        return h.copy(), c5_of_h(h, dx), 0.0
    h_new, c5_new = exact_line_search(h, d, dx, target_sum)
    alpha_used = np.dot(d, h_new - h) / np.dot(d, d) if np.dot(d, d) > 1e-30 else 0.0
    return h_new, c5_new, alpha_used


def anti_grad_exact(h, dx, target_sum, beta, n_iter=70):
    n = len(h)
    g = smooth_max_grad(h, dx, beta)
    d = -g
    d -= d.mean()
    pos_mask = d > 1e-15
    neg_mask = d < -1e-15
    scale = 1.0
    if pos_mask.any():
        scale = min(scale, np.min((1.0 - h[pos_mask]) / d[pos_mask]))
    if neg_mask.any():
        scale = min(scale, np.max((-h[neg_mask]) / d[neg_mask]))
    if scale < 1e-14:
        return h.copy(), c5_of_h(h, dx)
    d *= min(scale * 0.99, 1.0)
    d -= d.mean()
    h_new, c5_new = exact_line_search(h, d, dx, target_sum, n_iter)
    return h_new, c5_new


def lp_exact_step(h, dx, target_sum, n_active=40, lam=0.3):
    n = len(h)
    corrs = compute_corrs(h)
    top_idx = np.argsort(corrs)[-n_active:]
    c_obj = np.zeros(n + 1)
    c_obj[-1] = 1.0
    A_rows = []
    b_rows = []
    for k in top_idx:
        row = np.zeros(n + 1)
        row[:n] = dx * grad_corr_k(h, k, n)
        row[n] = -1.0
        A_rows.append(row)
        b_rows.append(-corrs[k] * dx - 1e-13)
    A_eq = np.zeros((1, n + 1))
    A_eq[0, :n] = 1.0
    b_eq = np.zeros(1)
    bounds = []
    for i in range(n):
        bounds.append((max(-h[i], -lam), min(1.0 - h[i], lam)))
    bounds.append((0.0, None))
    try:
        res = linprog(c_obj, A_ub=np.array(A_rows), b_ub=np.array(b_rows),
                      A_eq=A_eq, b_eq=b_eq, bounds=bounds, method='highs')
    except Exception:
        return h.copy(), c5_of_h(h, dx)
    if res.status != 0:
        return h.copy(), c5_of_h(h, dx)
    delta = res.x[:n]
    if np.max(np.abs(delta)) < 1e-14:
        return h.copy(), c5_of_h(h, dx)
    h_new, c5_new = exact_line_search(h, delta, dx, target_sum)
    return h_new, c5_new

def slsqp_quick(h0, dx, target_sum, beta, maxiter):
    n = len(h0)

    def obj(x):
        corrs = compute_corrs(x)
        return logsumexp(beta * corrs) / beta * dx

    def grad_obj(x):
        return smooth_max_grad(x, dx, beta)

    def c_fun(x):
        return x.sum() - target_sum

    def c_jac(x):
        return np.ones(n)

    cons = [{'type': 'eq', 'fun': c_fun, 'jac': c_jac}]
    bounds = [(0.0, 1.0)] * n
    try:
        res = minimize(obj, h0, jac=grad_obj, method='SLSQP',
                       bounds=bounds, constraints=cons,
                       options={'maxiter': maxiter, 'ftol': 1e-16})
        h_out = project_feasible(res.x, target_sum)
    except Exception:
        h_out = project_feasible(h0, target_sum)
    return h_out, c5_of_h(h_out, dx)

        if c5_lp < best_c5:
            best_c5 = c5_lp
            best_h = h_lp

    # Validation
    if best_h is None:
        best_h = h0
        best_c5 = c5_of_h(best_h, dx)
    else:
        n_final = len(best_h)
        best_h = project_feasible(best_h, n_final / 2.0)
        best_c5 = c5_of_h(best_h, 2.0 / n_final)

    return best_h, best_c5, len(best_h)
