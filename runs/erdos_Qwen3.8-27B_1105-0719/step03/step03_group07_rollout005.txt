The Erdős minimum overlap problem asks us to find a step function h: [0,2] → [0,1] that minimizes:
C₅ = max_k ∫ h(x)(1-h(x+k)) dx

The current record is C₅ ≤ 0.38085, and the previous program achieved 0.380917.

Key observations:
1. The problem is a nonconvex bilinear minimax problem
2. The previous approach used SLSQP with active constraints, soft-max projected descent, and coordinate descent
3. The parent has n=70 samples

Let me think about what could be different:

1. **Different optimization strategies**: 
   - The LP-based active leveling direction mentioned in the strategy could be useful
   - Pair-coordinate exact line search
   - Binary/gray-code inspired patterns
   - More aggressive dimension exploration
   - Different initial constructions

2. **Key insight**: The objective is C(h) = max_m dx * sum_i h[i]*(1-h[i+m]) for the relevant lags. This is bilinear in h, making it nonconvex. However, for fixed h, it's linear in the "1-h" part, and vice versa.

3. **What might work better**:
   - A more careful active set management with LP directions
   - Using the structure that at the optimum, multiple lags should be "active" (equal to the maximum)
   - A primal-dual approach where we try to equalize the active constraints
   - More aggressive exploration of different dimensions
   - Trying to find solutions where the profile is more "flat" (many lags at the same level)

Let me think about the LP approach more carefully. At a local optimum, we want to find a direction d such that:
- d · 1 = 0 (preserve sum constraint)
- For all active lags m: G_m · d < 0 (decrease all active overlaps)

This is a linear feasibility problem. We can formulate it as:
- Find d, t such that G_m · d + t ≤ -1 for all active m, ||d||_∞ ≤ 1, d · 1 = 0

Or more practically, minimize t subject to G_m · d ≤ t for all active m, ||d||_∞ ≤ 1, d · 1 = 0.

If t < 0, we have a descent direction.

Let me also think about the pair-coordinate approach. If we fix all coordinates except two (a, b), the objective becomes a function of one scalar λ where h[a] = t, h[b] = s - t (s = h[a] + h[b] fixed). Each P_m is a linear function of λ (since it's bilinear and we're only changing two coordinates). So the max of linear functions is convex in λ, and we can find its minimum efficiently.

Actually, let me be more careful. P_m = dx * sum_i h[i]*(1-h[i+m]). If we change h[a] and h[b], then P_m changes only for lags m where a or b appears in the sum. Specifically:
- If m = b - a (assuming b > a), then h[a]*(1-h[b]) appears in P_m
- If m = a - b, then h[b]*(1-h[a]) appears in P_m
- For other lags, only one of h[a], h[b] might appear

So P_m as a function of λ (where h[a]=λ, h[b]=s-λ) is:
- For lag m = b-a: contains term h[a]*(1-h[b]) = λ*(1-(s-λ)) = λ - sλ + λ²
- For lag m = -(b-a): contains term h[b]*(1-h[a]) = (s-λ)*(1-λ) = s - sλ - λ + λ²
- For other lags where only h[a] appears: linear in λ
- For other lags where only h[b] appears: linear in (s-λ)
- For lags where neither appears: constant

So the max is the max of a few quadratic/linear functions. The quadratic parts (from the direct pair interaction) make it potentially non-convex, but in practice with only one quadratic term per relevant lag, it should be manageable.

Key improvements over the previous code:
1. **LP-based active direction finding** - use scipy.optimize.linprog to find descent directions that decrease all active constraints simultaneously
2. **Exact pair-coordinate line search** - for pairs of coordinates, find the optimal redistribution
3. **Better dimension exploration** - try more dimensions with proper interpolation
4. **Iterative active set refinement** - after finding a good direction, re-evaluate which lags are active and repeat
5. **More efficient gradient computation** - avoid redundant computation

import numpy as np
from scipy.optimize import minimize, linprog
import time

def exact_score(h):
    n = len(h)
    dx = 2.0 / n
    return float(np.max(np.correlate(h, 1.0 - h, mode="full"))) * dx

def profile_h(h):
    n = len(h)
    dx = 2.0 / n
    return np.correlate(h, 1.0 - h, mode="full") * dx

def repair_feasible(vec):
    n = len(vec)
    h = np.clip(np.asarray(vec, dtype=np.float64), 0.0, 1.0)
    target = n / 2.0
    diff = target - h.sum()
    if abs(diff) < 1e-14:
        return h
    if diff > 0:
        capacity = 1.0 - h
        order = np.argsort(-capacity)
        remaining = diff
        for i in range(n):
            idx = order[i]
            add = min(remaining, capacity[idx])
            h[idx] += add
            remaining -= add
            if remaining <= 1e-12:
                break
    else:
        order = np.argsort(h)
        remaining = -diff
        for i in range(n):
            idx = order[i]
            rem = min(remaining, h[idx])
            h[idx] -= rem
            remaining -= rem
            if remaining <= 1e-12:
                break
    # Final correction
    diff2 = target - h.sum()
    if abs(diff2) > 1e-15:
        if diff2 > 0:
            idx = int(np.argmax(1.0 - h))
        else:
            idx = int(np.argmax(h))
        h[idx] += diff2
        h = np.clip(h, 0.0, 1.0)
    return h

def interpolate_to_n(h, new_n):
    n = len(h)
    if n == new_n:
        return h.copy()
    xs = (np.arange(n) + 0.5) * (2.0 / n)
    xt = (np.arange(new_n) + 0.5) * (2.0 / new_n)
    full_xs = np.concatenate([[-1.0], xs, [2.0 + 1.0]])
    # Use first and last values for boundary
    h_padded = np.concatenate([[h[0]], h, [h[-1]]])
    xs_padded = np.concatenate([[xs[0] - 2.0/n], xs, [xs[-1] + 2.0/new_n]])
    h_new = np.interp(xt, xs_padded, h_padded)
    return repair_feasible(np.clip(h_new, 0.0, 1.0))

def build_gradient_for_lag(h, d):
    """Gradient of P_d with respect to h, where d is the lag offset."""
    n = len(h)
    dx = 2.0 / n
    g = np.zeros(n)
    if d == 0:
        g[:] = dx * (1.0 - 2.0 * h)
    elif d > 0:
        for i in range(n - d):
            g[i] += dx * (1.0 - h[i + d])
            g[i + d] -= dx * h[i]
    else:
        dp = -d
        for j in range(n - dp):
            g[j + dp] += dx * (1.0 - h[j])
            g[j] -= dx * h[j + dp]
    return g

def active_lp_direction(h, prof, active_offsets):
    """
    Find a direction d that decreases all active overlaps.
    Formulate as LP: minimize t s.t. G_m · d <= t for all active m,
    |d_i| <= 1 for all i, sum(d) = 0.
    """
    n = len(h)
    k = len(active_offsets)
    if k == 0:
        return None
    
    # Build constraint matrix
    # Variables: d_0, ..., d_{n-1}, t  (total n+1 variables)
    # Constraints:
    #   For each active lag m: G_m · d - t <= 0  (k constraints)
    #   d_i <= 1 for all i (n constraints)
    #   -d_i <= 1 for all i (n constraints)
    #   sum(d_i) = 0 (equal constraint)
    
    A_ub = np.zeros((2 * n + k, n + 1))
    b_ub = np.zeros(2 * n + k)
    
    for idx, m in enumerate(active_offsets):
        d = m - (n - 1)
        G = build_gradient_for_lag(h, d)
        A_ub[idx, :n] = G
        A_ub[idx, n] = -1.0
        b_ub[idx] = 0.0
    
    for i in range(n):
        A_ub[n + i, i] = 1.0
        b_ub[n + i] = 1.0
        A_ub[2*n + i, i] = -1.0
        b_ub[2*n + i] = 1.0
    
    A_eq = np.zeros((1, n + 1))
    A_eq[0, :n] = 1.0
    b_eq = np.zeros(1)
    
    c_obj = np.zeros(n + 1)
    c_obj[n] = 1.0  # minimize t
    
    try:
        res = linprog(c_obj, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq,
                      bounds=[(None, None)] * n + [(None, None)],
                      method='highs')
        if res.status == 0 and res.fun < -1e-10:
            d = res.x[:n]
            return d
    except Exception:
        pass
    return None

def pair_line_search(h, a, b, n_samples=20):
    """
    For pair (a,b), find optimal t such that h[a]=t, h[b]=s-t
    minimizes the max profile. Uses sampling of the 1D function.
    """
    s = h[a] + h[b]
    lo = max(0.0, s - 1.0)
    hi = min(1.0, s)
    if hi - lo < 1e-12:
        return None
    
    best_t = h[a]
    best_c = exact_score(h)
    
    # Sample points
    ts = np.linspace(lo, hi, n_samples)
    h_work = h.copy()
    for t in ts:
        h_work[a] = t
        h_work[b] = s - t
        c = exact_score(h_work)
        if c < best_c - 1e-15:
            best_c = c
            best_t = t
    
    return best_t, best_c

def symmetrize(h):
    return (h + h[::-1].copy()) / 2.0

def slsqp_minimax(h0, maxiter=300, active_k=12, tol=1e-12):
    """SLSQP minimax optimization with active constraints."""
    n = len(h0)
    dx = 2.0 / n
    M = 2 * n - 1
    P = profile_h(h0)
    c0 = P.max()
    
    # Select active constraints (those close to max)
    thresh = c0 - max(0.002, 0.05 * (c0 - np.median(P)))
    active = np.where(P >= thresh)[0]
    if len(active) == 0:
        active = np.array([np.argmax(P)])
    if len(active) > active_k:
        top_idx = np.argsort(P[active])[-active_k:]
        active = active[top_idx]
    
    active_d = active - (n - 1)  # Convert to lag offsets
    
    def obj(x):
        return x[-1]
    
    def obj_jac(x):
        g = np.zeros(n + 1)
        g[-1] = 1.0
        return g
    
    def eq_fun(x):
        return x[:-1].sum() - n / 2.0
    
    def eq_jac(x):
        g = np.zeros(n + 1)
        g[:-1] = 1.0
        return g
    
    def ineq_fun(x):
        h = x[:-1]
        t = x[-1]
        prof = profile_h(h)
        return t - prof[active]
    
    def ineq_jac(x):
        h = x[:-1]
        G = np.zeros((len(active), n))
        for idx, d in enumerate(active_d):
            G[idx] = build_gradient_for_lag(h, d)
        J = np.zeros((len(active), n + 1))
        J[:, :-1] = -G
        J[:, -1] = 1.0
        return J
    
    x0 = np.concatenate([h0, [c0 + 1e-4]])
    bounds = [(0.0, 1.0)] * n + [(0.0, c0 + 1.0)]
    cons = [
        {'type': 'eq', 'fun': eq_fun, 'jac': eq_jac},
        {'type': 'ineq', 'fun': ineq_fun, 'jac': ineq_jac}
    ]
    
    try:
        res = minimize(obj, x0, method='SLSQP', jac=obj_jac,
                       bounds=bounds, constraints=cons,
                       options={'maxiter': maxiter, 'ftol': tol})
        if res.x is not None and np.all(np.isfinite(res.x)):
            h_new = repair_feasible(res.x[:-1])
            c_new = exact_score(h_new)
            if c_new <= c0 + 1e-10:
                return h_new
    except Exception:
        pass
    return None

def lp_descent_step(h, prof, active_k=10, step_scale=0.5):
    """
    Use LP to find a direction that decreases all active constraints.
    Then do exact line search along that direction.
    """
    n = len(h)
    c = prof.max()
    
    # Find active set
    thresh = c - max(0.001, 0.03 * (c - np.median(prof)))
    active = np.where(prof >= thresh)[0]
    if len(active) > active_k:
        active = active[np.argsort(prof[active])[-active_k:]]
    
    if len(active) == 0:
        active = np.array([np.argmax(prof)])
    
    d = active_lp_direction(h, prof, active)
    if d is None:
        # Fallback: negative average gradient of active constraints
        G = np.zeros((len(active), n))
        for idx, m in enumerate(active):
            lag = m - (n - 1)
            G[idx] = build_gradient_for_lag(h, lag)
        d = -G.mean(axis=0)
        d -= d.mean()  # Ensure zero sum
    
    # Line search
    d_norm = np.linalg.norm(d)
    if d_norm < 1e-12:
        return h, c
    
    d = d / d_norm
    best_h = h.copy()
    best_c = c
    
    for step in [step_scale, step_scale * 0.5, step_scale * 0.25, 
                 step_scale * 0.1, step_scale * 0.05]:
        h_try = repair_feasible(h + step * d)
        c_try = exact_score(h_try)
        if c_try < best_c - 1e-14:
            best_h = h_try
            best_c = c_try
    
    return best_h, best_c

def pair_descent(h, n_pairs_per_sweep=30, sweeps=5, t_start=None, budget_s=1100):
    """
    Coordinate pair descent: for selected pairs, find optimal redistribution.
    """
    n = len(h)
    h = h.copy()
    best_c = exact_score(h)
    rng = np.random.RandomState(12345)
    
    for sweep in range(sweeps):
        if t_start is not None and time.perf_counter() - t_start > budget_s - 15:
            break
        
        # Select pairs
        pairs = []
        for _ in range(n_pairs_per_sweep):
            a = rng.randint(n)
            b = rng.randint(n)
            if a != b:
                pairs.append((a, b))
        
        for (a, b) in pairs:
            if t_start is not None and time.perf_counter() - t_start > budget_s - 15:
                break
            result = pair_line_search(h, a, b, n_samples=15)
            if result is not None:
                best_t, c_try = result
                if c_try < best_c - 1e-14:
                    s = h[a] + h[b]
                    h[a] = best_t
                    h[b] = s - best_t
                    h = repair_feasible(h)
                    best_c = exact_score(h)
    
    return h, best_c

def softmax_descent(h, betas=None, max_iters=50, t_start=None, budget_s=1100):
    """Soft-max smooth approximation with projected gradient."""
    if betas is None:
        betas = [30, 60, 120, 250]
    
    n = len(h)
    h = h.copy()
    best_c = exact_score(h)
    vel = np.zeros(n)
    
    for beta in betas:
        alpha = 0.03
        for it in range(max_iters // len(betas)):
            if t_start is not None and time.perf_counter() - t_start > budget_s - 20:
                return h, best_c
            P = profile_h(h)
            c = P.max()
            if c < best_c - 1e-14:
                best_c = c
            
            # Soft-max weights
            exp_arg = beta * (P - c)
            weights = np.exp(exp_arg)
            S = weights.sum()
            if S < 1e-300:
                break
            weights /= S
            
            # Only use top weights
            active = np.where(weights > 0.02 / len(P))[0]
            if len(active) == 0:
                active = np.argsort(weights)[-5:]
            w_a = weights[active]
            w_a /= w_a.sum()
            
            # Build gradient
            G = np.zeros((len(active), n))
            for idx, m in enumerate(active):
                d = m - (n - 1)
                G[idx] = build_gradient_for_lag(h, d)
            
            grad = G.T @ w_a
            # Sum constraint
            grad += 2.0 * (h.sum() - n / 2.0) / n
            grad -= grad.mean()
            
            gnorm = np.linalg.norm(grad)
            if gnorm < 1e-14:
                break
            grad /= gnorm
            
            vel = 0.4 * vel + grad
            vnorm = np.linalg.norm(vel)
            if vnorm > 0:
                vel /= vnorm
            
            improved = False
            for a in [alpha, alpha * 0.5, alpha * 0.25, alpha * 0.1]:
                h_try = repair_feasible(h - a * vel)
                s = exact_score(h_try)
                if s < best_c - 1e-14:
                    h = h_try
                    best_c = s
                    improved = True
                    break
                elif s < exact_score(h):
                    h = h_try
            if improved:
                alpha = min(alpha * 1.1, 0.1)
            else:
                alpha *= 0.5
                if alpha < 1e-7:
                    break
    
    return h, best_c

import numpy as np
from scipy.optimize import minimize, linprog
import time

def exact_score(h):
    n = len(h)
    dx = 2.0 / n
    return float(np.max(np.correlate(h, 1.0 - h, mode="full"))) * dx

def profile_h(h):
    n = len(h)
    dx = 2.0 / n
    return np.correlate(h, 1.0 - h, mode="full") * dx

def repair_feasible(vec):
    n = len(vec)
    h = np.clip(np.asarray(vec, dtype=np.float64), 0.0, 1.0)
    target = n / 2.0
    diff = target - h.sum()
    if abs(diff) < 1e-14:
        return h
    if diff > 0:
        capacity = 1.0 - h
        order = np.argsort(-capacity)
        remaining = diff
        for i in range(n):
            idx = order[i]
            add = min(remaining, capacity[idx])
            h[idx] += add
            remaining -= add
            if remaining <= 1e-12:
                break
    else:
        order = np.argsort(h)
        remaining = -diff
        for i in range(n):
            idx = order[i]
            rem = min(remaining, h[idx])
            h[idx] -= rem
            remaining -= rem
            if remaining <= 1e-12:
                break
    diff2 = target - h.sum()
    if abs(diff2) > 1e-15:
        if diff2 > 0:
            idx = int(np.argmax(1.0 - h))
        else:
            idx = int(np.argmax(h))
        h[idx] += diff2
        h = np.clip(h, 0.0, 1.0)
    return h

def build_gradient_for_lag(h, d):
    n = len(h)
    dx = 2.0 / n
    g = np.zeros(n)
    if d == 0:
        g[:] = dx * (1.0 - 2.0 * h)
    elif d > 0:
        for i in range(n - d):
            g[i] += dx * (1.0 - h[i + d])
            g[i + d] -= dx * h[i]
    else:
        dp = -d
        for j in range(n - dp):
            g[j + dp] += dx * (1.0 - h[j])
            g[j] -= dx * h[j + dp]
    return g

def trust_region_step(h, prof, active_offsets, sigma=0.3):
    """
    Trust-region LP step: find direction d that decreases all active
    overlaps, bounded by trust region radius sigma.
    """
    n = len(h)
    k = len(active_offsets)
    if k == 0:
        return None
    
    # LP: minimize t
    # s.t. G_m · d ≤ t - P_m(h) for all active m (k constraints)
    #      -h_i ≤ d_i ≤ 1-h_i for all i (2n constraints)
    #      ||d||_2 ≤ sigma (approximate with ||d||_∞ ≤ sigma, or use ellipsoid)
    #      sum(d) = 0 (1 equality)
    
    # For simplicity, use infinity norm: |d_i| ≤ sigma
    # Variables: d_0,...,d_{n-1}, t (n+1 vars)
    
    A_ub = np.zeros((k + 2*n, n+1))
    b_ub = np.zeros(k + 2*n)
    
    for idx, m in enumerate(active_offsets):
        d_lag = m - (n-1)
        G = build_gradient_for_lag(h, d_lag)
        A_ub[idx, :n] = G
        A_ub[idx, n] = -1.0
        b_ub[idx] = -prof[m]
    
    for i in range(n):
        A_ub[k+i, i] = 1.0
        b_ub[k+i] = min(1.0 - h[i], sigma)
        A_ub[k+n+i, i] = -1.0
        b_ub[k+n+i] = min(h[i], sigma)
    
    A_eq = np.zeros((1, n+1))
    A_eq[0, :n] = 1.0
    b_eq = np.zeros(1)
    
    c_obj = np.zeros(n+1)
    c_obj[n] = 1.0
    
    try:
        res = linprog(c_obj, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq,
                      bounds=[(None, None)]*(n), method='highs')
        if res.status == 0:
            d = res.x[:n]
            # t is res.x[n], the predicted max overlap
            # If t < current max, we have improvement
            return d, res.x[n]
    except Exception:
        pass
    return None

def pair_line_search(h, a, b, n_samples=16):
    s = h[a] + h[b]
    lo = max(0.0, s - 1.0)
    hi = min(1.0, s)
    if hi - lo < 1e-12:
        return None
    best_t = h[a]
    best_c = exact_score(h)
    ts = np.linspace(lo, hi, n_samples)
    h_work = h.copy()
    for t in ts:
        h_work[a] = t
        h_work[b] = s - t
        c = exact_score(h_work)
        if c < best_c - 1e-15:
            best_c = c
            best_t = t
    return best_t, best_c
