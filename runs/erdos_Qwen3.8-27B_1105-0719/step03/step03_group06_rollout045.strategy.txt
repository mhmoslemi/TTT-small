The previous parent method relies mainly on local nonlinear epigraph solvers and active-row descent. Its bottleneck is that a single visit to a nonlinear solver sees only one nonlinear feasible region defined by the exact bilinear profile, and it can stall in a shallow local maximum of the objective. The proposed method changes the search in two coordinated ways:

1. **Continuous global population and convex-crossing search.**  
   Feasible step functions are stored in a pool. Convex combinations of two feasible vectors of the same length are automatically feasible with respect to `0 <= h <= 1` and the integral constraint, so population operations do not need a special projection. Offspring are produced by mixing, degree of preference, and targeted box-safe perturbations. This gives a different “global” search mechanism from one parent trained one direction only.

2. **Linearized-epigraph trust-region linear programming (LERP).**  
   At a current feasible vector `h`, we linearize all `2n-1` profile rows around `h`. The local surrogate is:

   For displacement `d`:
   `P_m(h) + grad(P_m)_m dot d <= tau` for every row `m`.

   We then minimize `tau` subject to:

   - box trust region `|d_i| <= delta`,

   This is a linear programming subproblem because the objective and surrogate constraints are linear. The true evaluator is then used for acceptance. This differs materially from nonlinear program, SLSQP, or one-active-row descent. It selects a simultaneous direction that conservatively reduces the linearized values of many profile rows.
