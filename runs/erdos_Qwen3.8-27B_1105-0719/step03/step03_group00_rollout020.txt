def power_gradient(h, q, corr):
    n = len(h)
    maxc = max(corr.max(), 1e-30)
    a = np.maximum(corr, 0.0) / maxc
    log_w = (q - 1) * np.log(np.maximum(a, 1e-30))
    log_w -= log_w.max()
    w = np.exp(log_w)
    w[corr < 0] = 0.0  # correlations should be >= 0 since h in [0,1]
    
    g = np.zeros(n)
    
    # d=0 term: w[n-1] * (1 - 2*h)
    g += w[n-1] * (1.0 - 2.0 * h)
    
    for d in range(1, n):
        wp = w[n-1+d]   # weight for c_d
        wm = w[n-1-d]   # weight for c_{-d}
        K = n - d
        # For j in [0, K-1] (i.e., j <= n-1-d):
        #   from c_d: -wp * h[j+d]
        #   from c_{-d}: +wm * (1-h[j+d])
        g[:K] += -wp * h[d:] + wm * (1.0 - h[d:])
        # For j in [d, n-1] (i.e., j >= d):
        #   from c_d: +wp * (1-h[j-d])
        #   from c_{-d}: -wm * h[j-d]
        g[d:] += wp * (1.0 - h[:K]) - wm * h[:K]
    
    g -= g.mean()
    return g

Now let me think about the pair-coordinate optimization more carefully.

For a pair (p, q) with p ≠ q, we want to find t that minimizes:
max_k corr_k(h') where h' = h with h[p] += t and h[q] -= t.

The valid range for t is:
- h[p] + t >= 0 → t >= -h[p]
- h[p] + t <= 1 → t <= 1 - h[p]
- h[q] - t >= 0 → t <= h[q]
- h[q] - t <= 1 → t >= h[q] - 1

So L = max(-h[p], h[q]-1) and U = min(1-h[p], h[q]).

The function to minimize is f(t) = max_k corr_k(h(t)) where h(t) is the modified vector.

This is a 1D non-convex optimization (max of quadratics). We can use:
1. Sample multiple points in [L, U]
2. Find the best sample
3. Refine around the best with golden section or similar

For efficiency, we can note that corr_k is linear in each h[i] for fixed other values. So when we change h[p] and h[q], each corr_k changes by:
Δcorr_k = t * (d(corr_k)/d(h[p]) - d(corr_k)/d(h[q]))

So corr_k(h(t)) = corr_k(h) + t * (g_k[p] - g_k[q]) where g_k[i] = d(corr_k)/d(h[i]).

This means for each k, corr_k as a function of t is linear! So max_k of linear functions is a piecewise linear (convex) function of t. We can minimize it by finding the point where the "knuckle" is.

Actually, this is great! The max of linear functions is convex, so we have a 1D convex optimization problem. We can solve it efficiently.

The subgradient of max_k (a_k * t + b_k) at t is:
- If unique maximizer: a_k
- If multiple maximizers: convex combination of their a_k values

So we want to find t where 0 is in the subgradient, i.e., where the max switches from a positive-slope line to a negative-slope line.

Algorithm:
1. Compute the lines: for each k, slope_k = (d(corr_k)/d(h[p]) - d(corr_k)/d(h[q])), intercept_k = corr_k(h)
2. We want to minimize max_k (slope_k * t + intercept_k) over t ∈ [L, U]
3. This is a 1D convex piecewise-linear minimization

We can solve this by:
- Binary search on the subgradient
- Or: the minimum is at a point where two lines cross, or at a boundary

Actually, the cleanest approach: the minimum of a convex piecewise-linear function on [L,U] is at:
- L or U (boundary), or
- A point where the function has a "kink" (two lines cross)

Number of kinks = number of pairs of lines that cross in [L,U], which can be O(n²) in the worst case. But we can do better:

The min of max of lines is at the point where the "lower envelope" of the upper envelope has its minimum. This is equivalent to finding the point t* where:
max_{k: slope_k > 0} (slope_k * t + intercept_k) = max_{k: slope_k < 0} (slope_k * t + intercept_k)

(At the optimum, the maximum is achieved by lines with both positive and negative slopes, or all slopes are zero.)

A practical approach: binary search on t. At each t, compute which k gives the max. If the max is achieved by a line with positive slope, increase t. If negative slope, decrease t. If zero slope (or mix), we're at the optimum.

1. Evaluate f(t) at L, U, and the midpoints of all pairs of lines that cross in [L,U].
