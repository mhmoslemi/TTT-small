1. Approach and rationale
========================

A materially different construction will combine three ideas that the previous program did not use as a coherent system:

1. Smooth-max entropy optimization with a homotopy schedule.  
   The exact objective is the maximum of a large overlap-profile vector. A pure steepest descent for the maximum stalls when many lags are nearly active. We will optimize a Log-Sum-Exp (LSE) surrogate of the profile maximum with inverse temperature β, starting with small β and increasing it. The LSE objective is smooth and has a well-defined tangent-gradient in the constrained hyperplane. This lets the optimizer push down many near-active lags simultaneously instead of only the current argmax. After each traced step, the final candidate is always judged by the original exact objective, so the surrogate never makes the accepted result worse.

2. Trust-region sequential linear programming (SLP-Taylor) for the exact objective.  
   After smooth phases, we perform a different local descent method: at the current feasible h, form a linear model of every profile entry using the exact first partial derivatives, then solve a small linear program for feasible h-increments that minimize the biggest modeled profile value inside a finite trust region. This solves for a simultaneous move over all lags rather than a single line search on subgradient rows. The proposed point is evaluated exactly and accepted only if the true objective improves. This gives a new local search engine, not merely a renamed active descent.

3. Exact epigraph SLSQP refinement from diverse starts and multi-resolution transfer.  
   The previous program’s candidate set was mostly parent-derived. Here we preserve the parent, interpolate it to several other dimensions, and also generate balanced deterministic and randomized starts. Candidates that are competitive in both smooth and linearized stages are refined with the epigraph SLSQP formulation, which directly imposes 0≤h_i≤1 and the exact Lagrange-style sum constraint. The loop and SLSQP both return only candidates that pass the original `np.correlate(h, 1-h, mode="full") * (2/n)` evaluator.

Major limitations and honest inference:
- The program is nonconvex because of products h_i(1-h_{i+r}); no claimed global optimality. All proposed steps are heuristically accepted using the exact original objective.
- The SLP-Taylor LP uses the exact gradient as a linear surrogate. Nonlinear movement may violate the linear model; exact acceptance and backtracking are the only correctness safeguards.

1. Approach and rationale
=========================

The supplied parent is a parent-derived active-descent/SLSQP pipeline. That converges quickly to a local value around 0.380917, but its local exploration is centered on the current parent and mostly follows subgradient lines limited to currently active lags. The exact objective is the maximum of a finite-support full cross-correlation with `1-h`, which is nonsmooth when many rows are equal or near equal. The proposed algorithm attacks this bottleneck with a materially different three-part search:

1. **Smooth-max entropy homotopy.** Repeatedly optimize the Log-Sum-Exp (LSE) surrogate of the overlap-profile maximum with increasing sharpness parameter. LSE gradients allocate effort to many near-maximal lags, allowing the solution to bend several competing constraints at once. The formal objective remains the exact evaluation at every proposed full `h`, so the LSE only guides proposed feasible moves.

2. **Trust-region sequential linear programming / Taylor descent.** After smooth phases, form exact first-order gradient rows for the current objective. Solve a small linear program that determines simultaneous coordinate displacements that minimize the maximum linearized profile value inside a velocity trust region and exactly respect the feasible constraints. This is unlike the previous line search on subgradients; it chooses a vector step through a scalar linearized maximum model. The proposed point is then re-evaluated exactly and only accepted if the true objective improves or provides a controlled escape move during the smooth schedule.

3. **Multi-resolution and diverse-start exact epigraph refinement.** Keep the supplied parent as a guaranteed incumbent, transfer it to several nearby dimensions using cell-average interpolation, and combine those candidates with deterministic balanced starting patterns and parent blends. Competitive candidates receive a final epigraph SLSQP refinement using a direct constrained nonlinear formulation. This multi-start refinement, initialized away from the central active-descent basin, is intended to expose alternative local optima that plain active descent may miss.

Important limitations and claims discipline:

- The problem is nonconvex after discretization because product terms `h_i(1-h_j)` occur. No procedure in the plan provides a proof of global optimization. Acceptance by the original evaluator is the only safeguard.
- LSE and first-order linearizations are surrogates used to generate trial steps. None is used to prove that the final value satisfies an inequality unless the final vector itself is evaluated by `max(np.correlate(h, 1-h, mode="full")) * 2/n`.
- Controlled increases of selected trial objective during smooth phases may be used to escape nonsmooth plateaus, but the final reported value is never updated without an exact improvement.
- The parent is stored as a fallback; if every external solver fails or the budget terminates during exploration, the final feasible incumbent is returned.

2. Mathematical specification
=============================

2.1 Feasible set, discrete profile, and objective
-------------------------------------------------

For a vector `h` of length `n` representing cell averages on `[0,2]`, let `dx=2/n`. The feasible set is

```
Q(n) = { h in R^n : 0 <= h_i <= 1        for all i,
                     sum_i h_i = n/2 }.
```

The scoring profile is exactly

```
p(h) = np.correlate(h, 1-h, mode="full") * dx.
```

It has `M=2n-1` entries. The exact score is

```
C5(h) = max(p(h)).
```

The full finite-support correlation and the two lag directions represented by the rows of the full profile must not be replaced by circular correlations, a minimum-autocorrelation reformulation, or continuous normalization. Boundary/overlap terms are inherent in this profile and the objective.

2.2 Exact gradient of a profile row
-----------------------------------

Let row index `m=0,...,M-1` and lag

```
s = m - (n-1)
```

which ranges from `-(n-1)` to `+ (n-1)`. The exact derivative of the corresponding profile entry uses the following top-level scalar-row construction, implemented as `grad_row(h, m)`:

```
if s == 0:
    grad = dx * (1 - 2*h).
else if s > 0:
    start with zeros.
    grad[s:]   += dx * (1 - h[:n-s])
    grad[:n-s] -= dx * h[s:]
else:
    d = -s.
    grad[:n-d] += dx * (1 - h[d:])
    grad[d:]   -= dx * h[:n-d]
```

All other values are zero. This is the derivative of the corresponding finite-support full correlation row. It is used for SLSQP gradients and linearized trust-region descent; it is not the score itself. If implemented coding helpers deviate, the central difference validation below should expose the inconsistency.

2.3 Joint repair by water-filling
----------------------------------

Never successively clip and rescale and claim both box and sum constraints. Use this feasible projection to the intersection of hyperplane `sum=n/2` and box `[0,1]^n`.

Input arbitrary y to function repair_feasible(y):

1. Clip y to `[0,1]` if it is far outside. Let `target=n/2`.
2. If `abs(sum(y)-target)<1e-12`, return a copy adjusted below. Otherwise perform binary search for lambda:
   - search left range `[min(y)-1, max(y)+1]`.
   - Define `phi(lambda)=sum(clip(y-lambda, 0,1))`.
   - `phi` is continuous nonincreasing and target lies in `[0,n]`, hence feasible root exists.
   - Iterate until bracket interval endpoints or function values are within `1e-12`; use 70-80 iterations.
3. Form `x=clip(y-clar, 0,1)` at bracket midpoint. It should satisfy bounds by construction.
4. Numerically correct the sum:
   - Let `delta = target - sum(x)`.
   - If delta positive, add `min(delta, 1-x_i)` to elements with upper capacity.
   - If negative, subtract `min(-delta, x_i)` from elements with positive valence.
   - Continue pass over the 1 through 3, leaving bounds and sorted total.
   - Verifies `sum(x)` changed `x` envelope while bounds. Cleanfinal >= slightly. Add residual correction.
