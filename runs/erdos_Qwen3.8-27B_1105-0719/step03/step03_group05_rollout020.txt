Let me analyze the problem and strategy carefully.

The key insight from the strategy is to work in the **complement symmetric (anti-reflective) subspace** where:
- h(x) + h(2-x) = 1
- This automatically satisfies the mass constraint ∫h = 1 (since the total integral is automatically n/2 * dx = 1)
- We only need to optimize the first half of the vector

This is a fundamentally different approach from the previous program which:
1. Worked in full coordinates
2. Used expensive repair_feasible after every step
3. Used LSE (log-sum-exp) descent, SLSQP, active-set methods

The new approach:
1. Parameterizes only the first half (m = n/2 variables)
2. Every move is automatically feasible (no repair needed)
3. Uses exact 1D line searches along reduced coordinates
4. Is much more efficient per evaluation

Let me design the algorithm:

1. **Anti-symmetric parameterization**: For n = 2m points:
   - y[0..m-1] are the free variables
   - h[0..m-1] = y
   - h[m..2m-1] = 1 - y[m-1..0] (reversed complement)

2. **Exact evaluation**: Given y, construct h, compute C5 = max(correlate(h, 1-h) * dx)

3. **Optimization in reduced space**:
   - Single coordinate moves: change y[j] by t, check bounds
   - Pair moves: change y[i] + t, y[j] - t
   - Gradient-based line search: compute reduced gradient, do exact line search
   - SLSQP in reduced space (no mass constraint needed, just bounds)
   - Resolution changes with anti-projection

4. **Key advantage**: No mass constraint to enforce, so SLSQP becomes much simpler (just box constraints + the max profile constraint)

Let me think about the gradient computation in the reduced space:

If h = [y, 1-reverse(y)], then for a function f(h), the gradient with respect to y[j] is:
df/dy[j] = df/dh[j] - df/dh[2m-1-j]

For the profile P_s = dx * sum h[i] * (1-h[i+s]), the derivative with respect to h[k] can be computed.

Actually, let me think more carefully. The overlap profile is:
P_s = dx * sum_i h[i] * (1 - h[(i+s) mod n])... 

Wait, no. The correlate operation:
np.correlate(h, 1-h, mode='full') computes for each lag the sum of products.

Let me be more careful. For arrays a and b of length n:
np.correlate(a, b, mode='full')[k] = sum_i a[i] * b[i + k - (n-1)]

So for a = h, b = 1-h:
profile[k] = sum_i h[i] * (1 - h[i + k - (n-1)])

The valid range of i is where both indices are in [0, n-1].

For the derivative of profile[k] with respect to h[j]:
profile[k] = sum_i h[i] - sum_i h[i] * h[i+k-(n-1)]

d/dh[j] of the first term: 1 if j is in range
d/dh[j] of the second term: -h[j+k-(n-1)] - h[j] * (delta_{i+k-(n-1),j}... )

This is getting complex. Let me just use the existing build_gradient_matrix function but adapted for the reduced space.

Actually, let me think about this differently. Since the key innovation is the anti-symmetric parameterization, let me focus on making that work well:

1. Start with the parent, project to anti-symmetric subspace
2. Use SLSQP in the reduced space (just box constraints [0,1]^m, plus the epigraph constraint)
3. Use coordinate descent with exact line search in reduced space
4. Try different resolutions

For SLSQP in reduced space:
- Variables: y[0..m-1], c (epigraph variable)
- Objective: minimize c
- Constraints: 
  - 0 <= y[j] <= 1 for all j (box)
  - c - P_s(h(y)) >= 0 for all s (M constraints)
  - c >= 0 (box)
- NO equality constraint needed!

This is much simpler than the previous program's SLSQP which had the equality constraint sum(h) = n/2.

Let me also think about coordinate descent:
- For each coordinate j, find the best value of y[j] (with all others fixed) that minimizes C5
- This is a 1D optimization problem: C5(t) = max_s P_s(h(y with y[j]=t))
- We can evaluate this at many points and find the minimum

And pair moves:
- For each pair (i,j), find the best shift t that minimizes C5
- y[i] += t, y[j] -= t
- This is also 1D

import numpy as np
from scipy.optimize import minimize
import time

def exact_score(h):
    n = len(h)
    dx = 2.0 / n
    return float(np.max(np.correlate(h, 1 - h, mode="full") * dx))

def compute_profile(h):
    n = len(h)
    dx = 2.0 / n
    return np.correlate(h, 1 - h, mode="full") * dx

def build_anti(y):
    """Build full h from anti-symmetric parameter y."""
    m = len(y)
    n = 2 * m
    h = np.empty(n)
    h[:m] = y
    h[m:] = 1.0 - y[::-1]
    return h

def anti_project(h):
    """Project h to anti-symmetric subspace, return y."""
    n = len(h)
    m = n // 2
    y = np.empty(m)
    for j in range(m):
        y[j] = 0.5 * (h[j] + 1.0 - h[n-1-j])
    y = np.clip(y, 0.0, 1.0)
    return y

def repair_feasible(vec):
    n = len(vec)
    h = np.clip(np.asarray(vec, dtype=np.float64), 0.0, 1.0)
    target = n / 2.0
    diff = target - h.sum()
    if abs(diff) < 1e-14:
        return h
    if diff > 0:
        capacity = 1.0 - h
        order = np.argsort(-capacity)
        remaining = diff
        for i in range(n):
            idx = order[i]
            add = min(remaining, capacity[idx] + 1e-15)
            if add > 0:
                h[idx] += add
            remaining -= add
            if remaining <= 1e-12:
                break
    else:
        order = np.argsort(h)
        remaining = -diff
        for i in range(n):
            idx = order[i]
            rem = min(remaining, h[idx] + 1e-15)
            if rem > 0:
                h[idx] -= rem
            remaining -= rem
            if remaining <= 1e-12:
                break
    diff2 = target - h.sum()
    if abs(diff2) > 1e-14:
        if diff2 > 0:
            idx = int(np.argmax(1.0 - h))
        else:
            idx = int(np.argmin(h))
        h[idx] += diff2
        h = np.clip(h, 0.0, 1.0)
    return h

def interpolate_to_n(h, new_n):
    n = len(h)
    if n == new_n:
        return h.copy()
    xs = np.linspace(0, 2, n + 1)
    xt = np.linspace(0, 2, new_n + 1)
    h_interp = np.zeros(new_n)
    for k in range(new_n):
        lo_k, hi_k = xt[k], xt[k+1]
        total_mass = 0.0
        total_width = 0.0
        for j in range(n):
            lo_j, hi_j = xs[j], xs[j+1]
            overlap = min(hi_k, hi_j) - max(lo_k, lo_j)
            if overlap > 0:
                total_mass += h[j] * overlap
                total_width += overlap
        h_interp[k] = total_mass / total_width if total_width > 1e-15 else 0.5
    h_interp = np.clip(h_interp, 0.0, 1.0)
    return repair_feasible(h_interp)

def score_from_y(y):
    """Compute C5 from anti-symmetric parameter y."""
    h = build_anti(y)
    return exact_score(h)

def profile_from_y(y):
    """Compute profile from anti-symmetric parameter y."""
    h = build_anti(y)
    return compute_profile(h)

def slsqp_reduced(y0, maxiter=300):
    """SLSQP in reduced anti-symmetric space. No mass constraint needed!"""
    m = len(y0)
    dx = 2.0 / (2 * m)
    M = 4 * m - 1  # 2n - 1 where n = 2m
    
    h0 = build_anti(y0)
    c0 = exact_score(h0)
    
    def build_h(y):
        h = np.empty(2 * m)
        h[:m] = y
        h[m:] = 1.0 - y[::-1]
        return h
    
    def profile(c_y):
        return compute_profile(build_h(c_y[:m]))
    
    def obj(x):
        return x[-1]
    
    def obj_jac(x):
        g = np.zeros(m + 1)
        g[-1] = 1.0
        return g
    
    def ineq_fun(x):
        y = np.clip(x[:m], 0, 1)
        t = x[-1]
        p = compute_profile(build_h(y))
        return t - p
    
    def ineq_jac(x):
        y = np.clip(x[:m], 0, 1)
        h = build_h(y)
        n = 2 * m
        # Build gradient of profile w.r.t. h
        G = np.zeros((M, n))
        for k in range(M):
            d = k - (n - 1)
            if d == 0:
                G[k, :] = dx * (1.0 - 2.0 * h)
            elif d > 0:
                G[k, :n-d] += dx * (1.0 - h[d:])
                G[k, d:] += -dx * h[:n-d]
            else:
                p = -d
                G[k, p:] += dx * (1.0 - h[:n-p])
                G[k, :p] += -dx * h[p:]
        # Map to reduced: grad_y[j] = G[:,j] - G[:,n-1-j]
        Gy = G[:, :m] - G[:, n-1:m-1:-1]
        J = np.zeros((M, m + 1))
        J[:, :m] = -Gy
        J[:, -1] = 1.0
        return J
    
    x0 = np.concatenate([y0, [c0 + 1e-4]])
    bounds = [(0.0, 1.0)] * m + [(0.0, c0 + 0.5)]
    cons = [{'type': 'ineq', 'fun': ineq_fun, 'jac': ineq_jac}]
    
    try:
        res = minimize(obj, x0, method='SLSQP', jac=obj_jac,
                       bounds=bounds, constraints=cons,
                       options={'maxiter': maxiter, 'ftol': 1e-12})
        if res.x is not None and np.isfinite(res.x).all():
            y_new = np.clip(res.x[:m], 0.0, 1.0)
            h_new = build_h(y_new)
            c_new = exact_score(h_new)
            if c_new <= c0 + 1e-9:
                return y_new, c_new
    except Exception:
        pass
    return None, None

def coord_descent_anti(y, max_iters=200, n_samples=50):
    """Coordinate descent with exact 1D line search in anti-symmetric space."""
    m = len(y)
    y = y.copy()
    best_c = score_from_y(y)
    
    for it in range(max_iters):
        improved = False
        for j in range(m):
            # 1D optimization: vary y[j] in [0, 1]
            best_t = y[j]
            best_s = score_from_y(y)
            # Sample the 1D function at many points
            ts = np.linspace(0, 1, n_samples)
            for t in ts:
                if abs(t - y[j]) < 1e-12:
                    continue
                y[j] = t
                s = score_from_y(y)
                if s < best_s - 1e-14:
                    best_s = s
                    best_t = t
            if best_t != y[j]:
                y[j] = best_t
                if best_s < best_c - 1e-14:
                    best_c = best_s
                    improved = True
        if not improved:
            break
    return y, best_c

def pair_descent_anti(y, max_iters=100, n_sample_pairs=20, n_samples=40):
    """Pair coordinate descent in anti-symmetric space."""
    m = len(y)
    y = y.copy()
    best_c = score_from_y(y)
    rng = np.random.RandomState(12345)
    
    for it in range(max_iters):
        improved = False
        for _ in range(n_sample_pairs):
            i = rng.randint(m)
            j = rng.randint(m)
            if i == j:
                continue
            # Pair move: y[i] += t, y[j] -= t
            # Feasible: t in [-y[i], 1-y[i]] and t in [y[j]-1, y[j]]
            t_min = max(-y[i], y[j] - 1)
            t_max = min(1 - y[i], y[j])
            if t_max - t_min < 1e-12:
                continue
            ts = np.linspace(t_min + 1e-10, t_max - 1e-10, n_samples)
            best_t = 0.0
            best_s = score_from_y(y)
            for t in ts:
                y[i] += t
                y[j] -= t
                s = score_from_y(y)
                if s < best_s:
                    best_s = s
                    best_t = t
                y[i] -= t
                y[j] += t
            if abs(best_t) > 1e-12:
                y[i] += best_t
                y[j] -= best_t
                if best_s < best_c - 1e-14:
                    best_c = best_s
                    improved = True
        if not improved:
            break
    return y, best_c

def active_set_anti(y, max_iters=200, n_active=10):
    """Active set method in anti-symmetric space using reduced gradient."""
    m = len(y)
    n = 2 * m
    dx = 2.0 / n
    M = 2 * n - 1
    y = y.copy()
    best_c = score_from_y(y)
    
    for it in range(max_iters):
        h = build_anti(y)
        profile = compute_profile(h)
        c = float(np.max(profile))
        
        # Build gradient matrix
        G = np.zeros((M, n))
        for k in range(M):
            d = k - (n - 1)
            if d == 0:
                G[k, :] = dx * (1.0 - 2.0 * h)
            elif d > 0:
                G[k, :n-d] += dx * (1.0 - h[d:])
                G[k, d:] += -dx * h[:n-d]
            else:
                p = -d
                G[k, p:] += dx * (1.0 - h[:n-p])
                G[k, :p] += -dx * h[p:]
        
        # Reduced gradient: Gy[j] = G[:,j] - G[:,n-1-j]
        Gy = G[:, :m] - G[:, n-1:m-1:-1]
        
        # Select active rows
        margin = max(0.003, 3.0 * (c - float(np.median(profile))))
        active = np.where(profile >= c - margin)[0]
        if len(active) == 0:
            active = np.array([int(np.argmax(profile))])
        if len(active) > n_active:
            top_idx = np.argsort(profile[active])[-n_active:]
            active = active[top_idx]
        
        # Weighted gradient in reduced space
        w = np.ones(len(active)) / len(active)
        grad_y = Gy[active, :].T @ w
        
        # Line search
        improved = False
        for alpha in [0.01, 0.005, 0.002, 0.001, 0.0005]:
            y_new = np.clip(y - alpha * grad_y, 0.0, 1.0)
            s = score_from_y(y_new)
            if s < best_c - 1e-14:
                y = y_new
                best_c = s
                improved = True
                break
        if not improved:
            break
    return y, best_c

def lse_anti(y, beta=80.0, max_iters=200):
    """Log-sum-exp descent in anti-symmetric space."""
    m = len(y)
    n = 2 * m
    dx = 2.0 / n
    M = 2 * n - 1
    y = y.copy()
    best_c = score_from_y(y)
    alpha = 0.003
    
    for it in range(max_iters):
        h = build_anti(y)
        profile = compute_profile(h)
        
        # Build gradient matrix
        G = np.zeros((M, n))
        for k in range(M):
            d = k - (n - 1)
            if d == 0:
                G[k, :] = dx * (1.0 - 2.0 * h)
            elif d > 0:
                G[k, :n-d] += dx * (1.0 - h[d:])
                G[k, d:] += -dx * h[:n-d]
            else:
                p = -d
                G[k, p:] += dx * (1.0 - h[:n-p])
                G[k, :p] += -dx * h[p:]
        
        Gy = G[:, :m] - G[:, n-1:m-1:-1]
        
        scaled = beta * profile
        max_s = np.max(scaled)
        weights = np.exp(scaled - max_s)
        wsum = weights.sum()
        if wsum < 1e-300:
            break
        weights /= wsum
        
        grad = Gy.T @ weights
        
        # Line search
        improved = False
        for a in [alpha, alpha*0.5, alpha*0.25, alpha*0.1]:
            y_new = np.clip(y - a * grad, 0.0, 1.0)
            s = score_from_y(y_new)
            if s < best_c - 1e-14:
                y = y_new
                best_c = s
                improved = True
                alpha = min(alpha * 1.1, 0.015)
                break
        if not improved:
            alpha *= 0.5
            if alpha < 1e-10:
                break
    return y, best_c

            active = active[top_idx]
        grad_y = Gy[active, :].T @ (np.ones(len(active)) / len(active))
        improved = False
        for alpha in [0.01, 0.005, 0.002, 0.001, 0.0005, 0.0002, 0.0001]:
            y_new = np.clip(y - alpha * grad_y, 0.0, 1.0)
            s = score_y(y_new)
            if s < best_c - 1e-14:
                y = y_new
                best_c = s
                improved = True
                break
        if not improved:
            break
    return y, best_c

def nelder_mead_anti(y0, maxiter=500):
    m = len(y0)
    y0 = np.array(y0, dtype=np.float64)
    vals = [score_y(y0)]
    simplex = [y0.copy()]
    eps = 0.02
    for j in range(min(m, 20)):
        v = y0.copy()
        step = eps if y0[j] < 0.9 else -eps
        v[j] = np.clip(y0[j] + step, 0.0, 1.0)
        simplex.append(v)
        vals.append(score_y(v))
    for _ in range(maxiter):
        order = np.argsort(vals)
        simplex = [simplex[i] for i in order]
        vals = [vals[i] for i in order]
        if len(simplex) < 2:
            break
        centroid = np.mean(simplex[:-1], axis=0)
        x_r = np.clip(centroid + (centroid - simplex[-1]), 0.0, 1.0)
        f_r = score_y(x_r)
        if f_r < vals[0]:
            x_e = np.clip(centroid + 2.0 * (centroid - simplex[-1]), 0.0, 1.0)
            f_e = score_y(x_e)
            if f_e < f_r:
                simplex[-1] = x_e
                vals[-1] = f_e
            else:
                simplex[-1] = x_r
                vals[-1] = f_r
        elif f_r < vals[-1]:
            simplex[-1] = x_r
            vals[-1] = f_r
        else:
            x_c = np.clip(centroid + 0.5 * (simplex[-1] - centroid), 0.0, 1.0)
            f_c = score_y(x_c)
            if f_c < vals[-1]:
                simplex[-1] = x_c
                vals[-1] = f_c
            else:
                for i in range(1, len(simplex)):
                    simplex[i] = np.clip(simplex[0] + 0.5 * (simplex[i] - simplex[0]), 0.0, 1.0)
                    vals[i] = score_y(simplex[i])
                if max(vals) - min(vals) < 1e-10:
                    break
    best_idx = int(np.argmin(vals))
    return simplex[best_idx], vals[best_idx]

def coord_descent_anti(y, max_iters=200, n_samples=40):
    m = len(y)
    y = y.copy()
    best_c = score_y(y)
    for it in range(max_iters):
        improved = False
        for j in range(m):
            old = y[j]
            best_t = old
            best_s = best_c
            ts = np.linspace(0, 1, n_samples)
            for t in ts:
                if abs(t - old) < 1e-8:
                    continue
                y[j] = t
                s = score_y(y)
                if s < best_s - 1e-14:
                    best_s = s
                    best_t = t
            y[j] = best_t
            if best_s < best_c - 1e-14:
                best_c = best_s
                improved = True
        if not improved:
            break
    return y, best_c

def pair_descent_anti(y, max_iters=60, n_pairs=20, n_samples=30, rng=None):
    m = len(y)
    y = y.copy()
    best_c = score_y(y)
    if rng is None:
        rng = np.random.RandomState(999)
    for it in range(max_iters):
        improved = False
        for _ in range(n_pairs):
            i = rng.randint(m)
            j = rng.randint(m)
            if i == j:
                continue
            t_min = max(-y[i], y[j] - 1.0)
            t_max = min(1.0 - y[i], y[j])
            if t_max - t_min < 1e-8:
                continue
            ts = np.linspace(t_min + 1e-9, t_max - 1e-9, n_samples)
            best_t = 0.0
            best_s = score_y(y)
            for t in ts:
                y[i] += t
                y[j] -= t
                s = score_y(y)
                if s < best_s:
                    best_s = s
                    best_t = t
                y[i] -= t
                y[j] += t
            if abs(best_t) > 1e-8:
                y[i] += best_t
                y[j] -= best_t
                if best_s < best_c - 1e-14:
                    best_c = best_s
                    improved = True
        if not improved:
            break
    return y, best_c

def slsqp_full_space(h0, maxiter=200):
    n = len(h0)
    dx = 2.0 / n
    M = 2 * n - 1
    c0 = exact_score(h0)

    def obj(x):
        return x[-1]

    def obj_jac(x):
        g = np.zeros(n + 1)
        g[-1] = 1.0
        return g

    def eq_fun(x):
        return x[:-1].sum() - n / 2.0

    def eq_jac(x):
        g = np.zeros(n + 1)
        g[:-1] = 1.0
        return g

    def ineq_fun(x):
        h = np.clip(x[:-1], 0, 1)
        t = x[-1]
        return t - compute_profile(h)

    def ineq_jac(x):
        h = np.clip(x[:-1], 0, 1)
        G = build_grad_matrix(h)
        J = np.zeros((M, n + 1))
        J[:, :-1] = -G
        J[:, -1] = 1.0
        return J

    x0 = np.concatenate([h0, [c0 + 1e-4]])
    bounds = [(0.0, 1.0)] * n + [(0.0, c0 + 0.5)]
    cons = [
        {'type': 'eq', 'fun': eq_fun, 'jac': eq_jac},
        {'type': 'ineq', 'fun': ineq_fun, 'jac': ineq_jac}
    ]
    try:
        res = minimize(obj, x0, method='SLSQP', jac=obj_jac,
                       bounds=bounds, constraints=cons,
                       options={'maxiter': maxiter, 'ftol': 1e-12})
        if res.x is not None and np.isfinite(res.x).all():
            h_new = repair_feasible(res.x[:-1])
            c_new = exact_score(h_new)
            if c_new <= c0 + 1e-9:
                return h_new, c_new
    except Exception:
        pass
    return None, None

def active_set_full(h, max_iters=200, n_active=10):
    n = len(h)
    h = h.copy()
    best_c = exact_score(h)
    for it in range(max_iters):
        profile = compute_profile(h)
        c = float(np.max(profile))
        G = build_grad_matrix(h)
        margin = max(0.003, 4.0 * (c - float(np.median(profile))))
        active = np.where(profile >= c - margin)[0]
        if len(active) == 0:
            active = np.array([int(np.argmax(profile))])
        if len(active) > n_active:
            top_idx = np.argsort(profile[active])[-n_active:]
            active = active[top_idx]
        grad = G[active, :].T @ (np.ones(len(active)) / len(active))
        grad -= grad.mean()
        gnorm = np.linalg.norm(grad)
        if gnorm < 1e-14:
            break
        improved = False
        for alpha in [0.008, 0.004, 0.002, 0.001, 0.0005]:
            h_try = repair_feasible(h - alpha * grad)
            s = exact_score(h_try)
            if s < best_c - 1e-14:
                h = h_try
                best_c = s
                improved = True
                break
        if not improved:
            break
    return h, best_c

def run(seed=42, budget_s=1100, **kwargs):
    t_start = time.perf_counter()
    rng = np.random.RandomState(seed)

    def time_left():
        return budget_s + t_start - time.perf_counter()

    parent = None
    try:
        parent = np.array(initial_h_values, dtype=np.float64)
    except NameError:
        pass
    except Exception:
        pass

    if parent is None or len(parent) < 4:
        parent = np.full(70, 0.5)

    parent = np.clip(parent, 0.0, 1.0)
    parent = repair_feasible(parent)
    best_h = parent.copy()
    best_c = exact_score(parent)

    # Ensure even length for anti-symmetric parameterization
    n_p = len(parent)
    if n_p % 2 != 0:
        parent = interpolate_to_n(parent, n_p - 1)
        n_p = len(parent)
        c = exact_score(parent)
        if c < best_c - 1e-13:
            best_h = parent.copy()
            best_c = c

    # Project to anti-symmetric subspace
    y0 = anti_project(parent)
    h_anti = build_anti(y0)
    c_anti = exact_score(h_anti)
    if c_anti < best_c - 1e-12:
        best_h = h_anti.copy()
        best_c = c_anti

    # Stage 1: Initial optimization in anti space
    if time_left() > 120:
        y_new, c_new = active_set_anti(y0, max_iters=150, n_active=10)
        if c_new < best_c - 1e-13:
            best_h = build_anti(y_new)
            best_c = c_new
            y0 = y_new

    if time_left() > 100:
        y_new, c_new = lse_anti(y0, beta=60, max_iters=150)
        if c_new < best_c - 1e-13:
            best_h = build_anti(y_new)
            best_c = c_new
            y0 = y_new

    if time_left() > 80:
        y_new, c_new = active_set_anti(y0, max_iters=120, n_active=15)
        if c_new < best_c - 1e-13:
            best_h = build_anti(y_new)
            best_c = c_new
            y0 = y_new

    # Stage 2: SLSQP in reduced space (no mass constraint!)
    if time_left() > 100:
        y_new, c_new = slsqp_reduced(y0, maxiter=400)
        if y_new is not None and c_new < best_c - 1e-12:
            best_h = build_anti(y_new)
            best_c = c_new
            y0 = y_new
            y_new2, c_new2 = active_set_anti(y_new, max_iters=100, n_active=10)
            if c_new2 < best_c - 1e-13:
                best_h = build_anti(y_new2)
                best_c = c_new2
                y0 = y_new2

    # Stage 3: Coordinate descent
    if time_left() > 60:
        y_new, c_new = coord_descent_anti(y0, max_iters=80, n_samples=50)
        if c_new < best_c - 1e-13:
            best_h = build_anti(y_new)
            best_c = c_new
            y0 = y_new

    # Stage 4: Pair descent
    if time_left() > 50:
        y_new, c_new = pair_descent_anti(y0, max_iters=50, n_pairs=25, n_samples=40, rng=rng)
        if c_new < best_c - 1e-13:
            best_h = build_anti(y_new)
            best_c = c_new
            y0 = y_new

    # Stage 5: Nelder-Mead in anti space
    if time_left() > 80:
        y_new, c_new = nelder_mead_anti(y0, maxiter=400)
        if c_new < best_c - 1e-13:
            best_h = build_anti(y_new)
            best_c = c_new
            y0 = y_new
            y_new2, c_new2 = active_set_anti(y_new, max_iters=80, n_active=10)
            if c_new2 < best_c - 1e-13:
                best_h = build_anti(y_new2)
                best_c = c_new2
                y0 = y_new2

    # Stage 6: Resolution exploration in anti space
    if time_left() > 80:
        n_cur = len(best_h)
        factors = [0.85, 0.9, 0.95, 1.05, 1.1, 1.15, 1.25, 1.35]
        tried = set()
        for f in factors:
            if time_left() < 35:
                break
            new_n = int(round(n_cur * f / 2)) * 2
            new_n = max(24, min(new_n, 160))
            if new_n in tried or new_n == n_cur:
                continue
            tried.add(new_n)
            h_interp = interpolate_to_n(best_h, new_n)
            y_interp = anti_project(h_interp)
            y_new, c_new = active_set_anti(y_interp, max_iters=80, n_active=10)
            if c_new < best_c - 1e-13:
                best_h = build_anti(y_new)
                best_c = c_new
                y0 = y_new
            y_new, c_new = lse_anti(y_interp, beta=80, max_iters=80)
            if c_new < best_c - 1e-13:
                best_h = build_anti(y_new)
                best_c = c_new
                y0 = y_new

    # Stage 7: Multi-start SLSQP in reduced space
    if time_left() > 80:
        m_cur = len(y0)
        starts = [y0.copy()]
        for eps in [0.008, 0.015, 0.03, 0.05]:
            z = rng.randn(m_cur)
            z -= z.mean()
            starts.append(np.clip(y0 + eps * z, 0.0, 1.0))
        # Structured perturbation
        z = rng.randn(m_cur)
        z = 0.5 * (z - z[::-1])
        starts.append(np.clip(y0 + 0.02 * z, 0.0, 1.0))
        for y_start in starts:
            if time_left() < 25:
                break
            y_new, c_new = slsqp_reduced(y_start, maxiter=250)
            if y_new is not None and c_new < best_c - 1e-12:
                best_h = build_anti(y_new)
                best_c = c_new
                y0 = y_new

    # Stage 8: Full-space optimization (escape from anti subspace)
    if time_left() > 60:
        h_full = best_h.copy()
        h_new, c_new = slsqp_full_space(h_full, maxiter=200)
        if h_new is not None and c_new < best_c - 1e-12:
            best_h = h_new
            best_c = c_new
            # Project back to anti for further optimization
            y_proj = anti_project(best_h)
            y_new, c_new = active_set_anti(y_proj, max_iters=80, n_active=10)
            if c_new < best_c - 1e-13:
                best_h = build_anti(y_new)
                best_c = c_new
                y0 = y_new
        # Full-space active set
        if time_left() > 30:
            h_ase, c_ase = active_set_full(best_h, max_iters=100, n_active=10)
            if c_ase < best_c - 1e-13:
                best_h = h_ase
                best_c = c_ase

    # Stage 9: Varying active set sizes
    for n_act in [6, 12, 20, 30]:
        if time_left() < 15:
            break
        y_new, c_new = active_set_anti(y0, max_iters=120, n_active=n_act)
        if c_new < best_c - 1e-13:
            best_h = build_anti(y_new)
            best_c = c_new
            y0 = y_new

    # Stage 10: LSE with various betas
    for beta in [40, 100, 200, 400]:
        if time_left() < 12:
            break
        y_new, c_new = lse_anti(y0, beta=beta, max_iters=100)
        if c_new < best_c - 1e-13:
            best_h = build_anti(y_new)
            best_c = c_new
            y0 = y_new

    # Stage 11: Final SLSQP polish
    if time_left() > 40:
        y_new, c_new = slsqp_reduced(y0, maxiter=500)
        if y_new is not None and c_new < best_c - 1e-14:
            best_h = build_anti(y_new)
            best_c = c_new
            y0 = y_new

    # Stage 12: Final polish
    if time_left() > 15:
        y_new, c_new = active_set_anti(y0, max_iters=200, n_active=8)
        if c_new < best_c - 1e-14:
            best_h = build_anti(y_new)
            best_c = c_new
        y_new, c_new = lse_anti(y0, beta=150, max_iters=100, alpha_init=0.002)
        if c_new < best_c - 1e-14:
            best_h = build_anti(y_new)
            best_c = c_new

    # Final validation
    best_h = repair_feasible(best_h)
    final_c = exact_score(best_h)

    try:
        eval_result = evaluate_erdos_solution(best_h)
        if isinstance(eval_result, (float, int)):
            final_c = float(eval_result)
        elif isinstance(eval_result, tuple) and len(eval_result) >= 2:
            final_c = float(eval_result[0])
    except Exception:
        pass

    return best_h, final_c, len(best_h)
