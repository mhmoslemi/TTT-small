Let me think about the exact line search more carefully.

For a single reduced coordinate y_j, the full vector h changes as:
- h_j = y_j + t
- h_{n-1-j} = 1 - y_j - t

The objective is C_5(h) = max_k P_k(h) where P_k(h) = dx * sum_i h_i * (1-h_{i+k}) (with appropriate bounds).

For a given t, I can compute C_5(h(t)) exactly. I want to minimize this over t in [-y_j, 1-y_j].

This is a piecewise function (since it's a max of bilinear functions), so it's non-concave in general. But I can do a golden-section or bracketing search, or sample the 1D function at many points and find the minimum.

Actually, let me think about this differently. The function C_5(h(t)) as a function of t is the maximum of many quadratic functions (each P_k is quadratic in the h's, and h depends linearly on t). So C_5(h(t)) is the max of quadratics, which is convex in t. Wait, is that right?

Each P_k(h) = dx * sum_i h_i * (1 - h_{i+k}). If h_i = a_i + b_i * t where a_i, b_i are constants (b_i is 0 for most i, +1 for one, -1 for its mirror), then P_k(h(t)) is a quadratic in t. The max of convex functions is convex. So C_5(h(t)) is convex in t!

Wait, let me verify. P_k(h(t)) = dx * sum_i (a_i + b_i t)(1 - a_{i+k} - b_{i+k} t)
= dx * sum_i [(a_i + b_i t) - (a_i + b_i t)(a_{i+k} + b_{i+k} t)]
= dx * sum_i [a_i + b_i t - a_i a_{i+k} - a_i b_{i+k} t - a_{i+k} b_i t - b_i b_{i+k} t²]

The coefficient of t² is -dx * sum_i b_i b_{i+k}, which can be positive or negative depending on the structure. So P_k is not necessarily convex or concave in t. Therefore C_5(h(t)) is not necessarily convex.

So I can't rely on convexity for the 1D search. I'll need to do a more careful search - maybe sample at multiple points or use a derivative-based approach.

Actually, let me reconsider. For a single coordinate move in reduced space:
- b_i = 1 if i = j (the coordinate being moved)
- b_i = -1 if i = n-1-j (the mirror)
- b_i = 0 otherwise

So b_i b_{i+k} is non-zero only when:
- i = j and i+k = n-1-j, i.e., k = n-1-2j
- i = n-1-j and i+k = j, i.e., k = 2j-(n-1)
- i = j and i+k = j, i.e., k = 0
- i = n-1-j and i+k = n-1-j, i.e., k = 0

For k = 0: b_i b_{i+k} = b_i² = 1 for i=j and i=n-1-j. So sum = 2, giving coefficient -2*dx.
For k = n-1-2j: only i=j contributes (if j+k = n-1-j, i.e., k = n-1-2j, which is valid if 0 <= j+k < n). b_j * b_{n-1-j} = 1 * (-1) = -1. So sum = -1, giving coefficient +dx.
For k = 2j-(n-1): similarly, coefficient +dx.
For other k: coefficient 0.

So P_k(h(t)) is:
- Quadratic (concave, coeff -2dx) for k=0
- Linear (coeff 0 for t²) for k = ±(n-1-2j)
- Linear for all other k

Since C_5 is the max of these, and only the k=0 term is concave quadratic while others are linear, the overall function is not convex. But it's a max of one concave quadratic and many linear functions, which is a "max of affine and one concave quadratic" - this is actually non-convex but has a specific structure.

For practical purposes, I'll do a dense 1D search: sample t at many points in the feasible interval, evaluate C_5 at each, and take the best. With n up to ~100, evaluating C_5 takes O(n²) time (due to correlate). If I sample ~50 points per coordinate, and have m = n/2 coordinates, that's 50 * n/2 * O(n²) = 25n³ operations per full pass. For n=70, that's about 25 * 70³ ≈ 8.6 million operations per pass, which is very fast.

def exact_score(h):
    n = len(h)
    dx = 2.0 / n
    return float(np.max(np.correlate(h, 1 - h, mode="full") * dx))

def compute_profile(h):
    n = len(h)
    dx = 2.0 / n
    return np.correlate(h, 1 - h, mode="full") * dx

def repair_feasible(vec):
    n = len(vec)
    h = np.clip(np.asarray(vec, dtype=np.float64), 0.0, 1.0)
    target = n / 2.0
    diff = target - h.sum()
    if abs(diff) < 1e-14:
        return h
    if diff > 0:
        capacity = 1.0 - h
        order = np.argsort(-capacity)
        remaining = diff
        for i in range(n):
            idx = order[i]
            add = min(remaining, capacity[idx] + 1e-15)
            if add > 0:
                h[idx] += add
            remaining -= add
            if remaining <= 1e-12:
                break
    else:
        order = np.argsort(h)
        remaining = -diff
        for i in range(n):
            idx = order[i]
            rem = min(remaining, h[idx] + 1e-15)
            if rem > 0:
                h[idx] -= rem
            remaining -= rem
            if remaining <= 1e-12:
                break
    diff2 = target - h.sum()
    if abs(diff2) > 1e-14:
        if diff2 > 0:
            idx = int(np.argmax(1.0 - h))
        else:
            idx = int(np.argmin(h))
        h[idx] += diff2
        h = np.clip(h, 0.0, 1.0)
    return h

def interpolate_to_n(h, new_n):
    n = len(h)
    if n == new_n:
        return h.copy()
    xs = np.linspace(0, 2, n + 1)
    xt = np.linspace(0, 2, new_n + 1)
    h_interp = np.zeros(new_n)
    for k in range(new_n):
        lo_k, hi_k = xt[k], xt[k+1]
        total_mass = 0.0
        total_width = 0.0
        for j in range(n):
            lo_j, hi_j = xs[j], xs[j+1]
            overlap = min(hi_k, hi_j) - max(lo_k, lo_j)
            if overlap > 0:
                total_mass += h[j] * overlap
                total_width += overlap
        h_interp[k] = total_mass / total_width if total_width > 1e-15 else 0.5
    return repair_feasible(np.clip(h_interp, 0.0, 1.0))

def build_full_from_reduced(y, n):
    """Build full h from reduced anti-symmetric variables y of length m = n//2."""
    m = n // 2
    h = np.zeros(n)
    for j in range(m):
        h[j] = y[j]
        h[n - 1 - j] = 1.0 - y[j]
    if n % 2 == 1:
        h[m] = 0.5
    return h

def project_to_reduced(h, n):
    """Project full h to reduced anti-symmetric variables."""
    m = n // 2
    y = np.zeros(m)
    for j in range(m):
        y[j] = 0.5 * (h[j] + 1.0 - h[n - 1 - j])
    y = np.clip(y, 0.0, 1.0)
    return y

def anti_score(y, n):
    """Evaluate C5 for reduced variables y."""
    h = build_full_from_reduced(y, n)
    return exact_score(h)

def line_search_single(y, j, n, n_samples=40):
    """Dense 1D line search for coordinate j of reduced variables."""
    t_vals = np.linspace(-y[j], 1.0 - y[j], n_samples)
    best_t = 0.0
    best_c = anti_score(y, n)
    for t in t_vals:
        y[j] = y[j] + t
        c = anti_score(y, n)
        if c < best_c - 1e-14:
            best_c = c
            best_t = t
    y[j] = y[j] + best_t
    return best_c

def line_search_pair(y, i, j, n, n_samples=30):
    """Dense 1D line search for pair move (i, j)."""
    t_min = max(-y[i], y[j] - 1.0)
    t_max = min(1.0 - y[i], y[j])
    if t_max - t_min < 1e-14:
        return anti_score(y, n)
    t_vals = np.linspace(t_min, t_max, n_samples)
    yi, yj = y[i], y[j]
    best_t = 0.0
    best_c = anti_score(y, n)
    for t in t_vals:
        y[i] = yi + t
        y[j] = yj - t
        c = anti_score(y, n)
        if c < best_c - 1e-14:
            best_c = c
            best_t = t
    y[i] = yi + best_t
    y[j] = yj - best_t
    return best_c

def coordinate_descent(y, n, max_sweeps=20, n_samples=30):
    """Coordinate descent on reduced variables."""
    m = len(y)
    y = y.copy()
    best_c = anti_score(y, n)
    for sweep in range(max_sweeps):
        improved = False
        for j in range(m):
            old_c = anti_score(y, n)
            new_c = line_search_single(y, j, n, n_samples)
            if new_c < best_c - 1e-13:
                best_c = new_c
                improved = True
        if not improved:
            break
    return y, best_c

def pair_sweep(y, n, max_sweeps=10, n_samples=25, rng=None):
    """Randomized pair moves on reduced variables."""
    m = len(y)
    y = y.copy()
    best_c = anti_score(y, n)
    for sweep in range(max_sweeps):
        improved = False
        for _ in range(m * 2):
            i = rng.randint(m)
            j = rng.randint(m)
            if i == j:
                continue
            old_c = anti_score(y, n)

def reduced_gradient(y, n):
    """Compute gradient of C5 approximation (using LSE-weighted profile) in reduced variables."""
    h = build_full_from_reduced(y, n)
    m = len(y)
    profile = compute_profile(h)
    beta = 80.0
    scaled = beta * profile
    max_s = np.max(scaled)
    weights = np.exp(scaled - max_s)
    wsum = weights.sum()
    if wsum < 1e-300:
        return np.zeros(m)
    weights /= wsum
    
    g_full = np.zeros(n)
    for q in range(2 * n - 1):
        w = weights[q]
        if w < 1e-15:
            continue
        s = q - (n - 1)
        if s == 0:
            g_full += w * (1.0 - 2.0 * h)
        elif s > 0:
            g_full[:n - s] += w * (1.0 - h[s:])
            g_full[s:] += -w * h[:n - s]
        else:
            r = -s
            g_full[r:] += w * (1.0 - h[:n - r])
            g_full[:n - r] += -w * h[r:]
    
    g_red = np.zeros(m)
    for j in range(m):
        g_red[j] = g_full[j] - g_full[n - 1 - j]
    return g_red

def compute_profile(h):
    n = len(h)
    dx = 2.0 / n
    return np.correlate(h, 1 - h, mode="full") * dx

def repair_feasible(vec):
    n = len(vec)
    h = np.clip(np.asarray(vec, dtype=np.float64), 0.0, 1.0)
    target = n / 2.0
    diff = target - h.sum()
    if abs(diff) < 1e-14:
        return h
    if diff > 0:
        capacity = 1.0 - h
        order = np.argsort(-capacity)
        remaining = diff
        for i in range(n):
            idx = order[i]
            add = min(remaining, capacity[idx] + 1e-15)
            if add > 0:
                h[idx] += add
            remaining -= add
            if remaining <= 1e-12:
                break
    else:
        order = np.argsort(h)
        remaining = -diff
        for i in range(n):
            idx = order[i]
            rem = min(remaining, h[idx] + 1e-15)
            if rem > 0:
                h[idx] -= rem
            remaining -= rem
            if remaining <= 1e-12:
                break
    diff2 = target - h.sum()
    if abs(diff2) > 1e-14:
        if diff2 > 0:
            idx = int(np.argmax(1.0 - h))
        else:
            idx = int(np.argmin(h))
        h[idx] += diff2
        h = np.clip(h, 0.0, 1.0)
    return h

def interpolate_to_n(h, new_n):
    n = len(h)
    if n == new_n:
        return h.copy()
    xs = np.linspace(0, 2, n + 1)
    xt = np.linspace(0, 2, new_n + 1)
    h_interp = np.zeros(new_n)
    for k in range(new_n):
        lo_k, hi_k = xt[k], xt[k+1]
        total_mass = 0.0
        total_width = 0.0
        for j in range(n):
            lo_j, hi_j = xs[j], xs[j+1]
            overlap = min(hi_k, hi_j) - max(lo_k, lo_j)
            if overlap > 0:
                total_mass += h[j] * overlap
                total_width += overlap
        h_interp[k] = total_mass / total_width if total_width > 1e-15 else 0.5
    return repair_feasible(np.clip(h_interp, 0.0, 1.0))

def build_full_from_reduced(y, n):
    m = n // 2
    h = np.zeros(n)
    h[:m] = y
    h[m:] = 1.0 - y[::-1]
    if n % 2 == 1:
        h[m] = 0.5
    return h

def project_to_reduced(h, n):
    m = n // 2
    y = 0.5 * (h[:m] + 1.0 - h[n-1:m-1:-1])
    return np.clip(y, 0.0, 1.0)

def anti_score(y, n):
    h = build_full_from_reduced(y, n)
    return exact_score(h)

def coord_descent(y, n, max_sweeps=50, n_samples=50):
    m = n // 2
    y = y.copy()
    h = build_full_from_reduced(y, n)
    best_c = exact_score(h)
    
    for sweep in range(max_sweeps):
        improved = False
        for j in range(m):
            mirror = n - 1 - j
            yj = y[j]
            t_vals = np.linspace(-yj, 1.0 - yj, n_samples)
            best_t = 0.0
            best_c_local = best_c
            
            for t in t_vals:
                if abs(t) < 1e-12:
                    continue
                h[j] = yj + t
                h[mirror] = 1.0 - yj - t
                c = exact_score(h)
                if c < best_c_local - 1e-14:
                    best_c_local = c
                    best_t = t
            
            h[j] = yj + best_t
            h[mirror] = 1.0 - yj - best_t
            y[j] = yj + best_t
            best_c = best_c_local
            if best_t != 0.0:
                improved = True
        
        if not improved:
            break
    
    return y, best_c

def pair_descent(y, n, max_sweeps=20, n_samples=35, rng=None):
    m = len(y)
    y = y.copy()
    best_c = anti_score(y, n)
    
    for sweep in range(max_sweeps):
        improved = False
        for _ in range(m):
            i = rng.randint(m)
            j = rng.randint(m)
            if i == j:
                continue
            mi = n - 1 - i
            mj = n - 1 - j
            yi, yj = y[i], y[j]
            t_min = max(-yi, yj - 1.0)
            t_max = min(1.0 - yi, yj)
            if t_max - t_min < 1e-12:
                continue
            t_vals = np.linspace(t_min, t_max, n_samples)
            h = build_full_from_reduced(y, n)
            best_t = 0.0
            best_c_local = best_c
            
            for t in t_vals:
                if abs(t) < 1e-12:
                    continue
                h[i] = yi + t
                h[j] = yj - t
                h[mi] = 1.0 - yi - t
                h[mj] = 1.0 - yj + t
                c = exact_score(h)
                if c < best_c_local - 1e-14:
                    best_c_local = c
                    best_t = t
            
            h[i] = yi + best_t
            h[j] = yj - best_t
            h[mi] = 1.0 - yi - best_t
            h[mj] = 1.0 - yj + best_t
            y[i] = yi + best_t
            y[j] = yj - best_t
            best_c = best_c_local
            if best_t != 0.0:
                improved = True
        
        if not improved:
            break
    
    return y, best_c

def reduced_grad(y, n, beta=80.0):
    h = build_full_from_reduced(y, n)
    m = len(y)
    profile = compute_profile(h)
    scaled = beta * profile
    max_s = np.max(scaled)
    weights = np.exp(scaled - max_s)
    wsum = weights.sum()
    if wsum < 1e-300:
        return np.zeros(m)
    weights /= wsum
    
    g_full = np.zeros(n)
    for q in range(2 * n - 1):
        w = weights[q]
        if w < 1e-15:
            continue
        s = q - (n - 1)
        if s == 0:
            g_full += w * (1.0 - 2.0 * h)
        elif s > 0:
            g_full[:n - s] += w * (1.0 - h[s:])
            g_full[s:] += -w * h[:n - s]
        else:
            r = -s
            g_full[r:] += w * (1.0 - h[:n - r])
            g_full[:n - r] += -w * h[r:]
    
    g_red = g_full[:m] - g_full[n-1:m-1:-1]
    return g_red

def grad_descent_red(y, n, max_iters=80, alpha_init=0.008, beta=80.0):
    m = len(y)
    y = y.copy()
    best_c = anti_score(y, n)
    alpha = alpha_init
    stuck = 0
    for it in range(max_iters):
        g = reduced_grad(y, n, beta)
        gnorm = np.linalg.norm(g)
        if gnorm < 1e-14:
            break
        g /= gnorm
        improved = False
        for a in [alpha, alpha*0.5, alpha*0.25, alpha*0.1]:
            y_try = np.clip(y - a * g, 0.0, 1.0)
            c_try = anti_score(y_try, n)
            if c_try < best_c - 1e-14:
                y = y_try.copy()
                best_c = c_try
                improved = True
                alpha = min(alpha * 1.05, 0.04)
                stuck = 0
                break
            elif c_try < anti_score(y, n) - 1e-14:
                y = y_try.copy()
                improved = True
                break
        if not improved:
            alpha *= 0.5
            stuck += 1
            if stuck > 25 or alpha < 1e-10:
                break
    y, c = coord_descent(y, n, max_sweeps=10, n_samples=30)
    return y, min(best_c, c)

def lse_full(h, beta=80.0, max_iters=60, alpha_init=0.004):
    n = len(h)
    dx = 2.0 / n
    h = h.copy()
    best_c = exact_score(h)
    alpha = alpha_init
    stuck = 0
    for it in range(max_iters):
        profile = compute_profile(h)
        scaled = beta * profile
        max_s = np.max(scaled)
        weights = np.exp(scaled - max_s)
        wsum = weights.sum()
        if wsum < 1e-300:
            break
        weights /= wsum
        
        g = np.zeros(n)
        for q in range(2 * n - 1):
            w = weights[q]
            if w < 1e-15:
                continue
            s = q - (n - 1)
            if s == 0:
                g += w * dx * (1.0 - 2.0 * h)
            elif s > 0:
                g[:n - s] += w * dx * (1.0 - h[s:])
                g[s:] += -w * dx * h[:n - s]
            else:
                r = -s
                g[r:] += w * dx * (1.0 - h[:n - r])
                g[:n - r] += -w * dx * h[r:]
        
        g -= g.mean()
        gnorm = np.linalg.norm(g)
        if gnorm < 1e-14:
            break
        g /= gnorm
        improved = False
        for a in [alpha, alpha*0.5, alpha*0.25, alpha*0.1]:
            h_try = repair_feasible(h - a * g)
            s_try = exact_score(h_try)
            if s_try < best_c - 1e-14:
                h = h_try
                best_c = s_try
                improved = True
                alpha = min(alpha * 1.05, 0.025)
                stuck = 0
                break
            elif s_try < exact_score(h) - 1e-14:
                h = h_try
                improved = True
                break
        if not improved:
            alpha *= 0.5
            stuck += 1
            if stuck > 25 or alpha < 1e-10:
                break
    return h, best_c

def full_pair_move(h, max_iters=30, n_samples=20, rng=None):
    n = len(h)
    h = h.copy()
    best_c = exact_score(h)
    for it in range(max_iters):
        improved = False
        for _ in range(n // 2):
            i = rng.randint(n)
            j = rng.randint(n)
            if i == j:
                continue
            t_min = max(-h[i], h[j] - 1.0)
            t_max = min(1.0 - h[i], h[j])
            if t_max - t_min < 1e-12:
                continue
            t_vals = np.linspace(t_min, t_max, n_samples)
            hi, hj = h[i], h[j]
            best_t = 0.0
            best_c_local = best_c
            for t in t_vals:
                if abs(t) < 1e-12:
                    continue
                h[i] = hi + t
                h[j] = hj - t
                c = exact_score(h)
                if c < best_c_local - 1e-14:
                    best_c_local = c
                    best_t = t
            h[i] = hi + best_t
            h[j] = hj - best_t
            best_c = best_c_local
            if best_t != 0.0:
                improved = True
        if not improved:
            break
    return h, best_c
