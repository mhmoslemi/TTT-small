1. Approach and rationale

1.1 Central idea

Improve the supplied near-optimal vector by replacing the previous small active-set linearization pipeline with a feasibility-preserving, exact-objective pattern/line search. The centroid of the method is that every candidate is always constructed as

`h_candidate = h_current + alpha * v`

with `sum(v)=0`, so the integral constraint is preserved exactly along the whole line. Along such a direction the authoritative evaluator is evaluated as the true nonsmooth function

`F_hv(alpha) = max_m np.correlate(h + alpha*v, 1 - (h + alpha*v), mode="full")[m] * dx`.

A one-dimensional search (coarse grid plus golden-section refinement) is therefore performed on the exact problem objective, not on a gradient surrogate, not on an LP relaxation, and not on a constraint-restricted smoothing assumption. Multiple families of directions `v` are tested:

- soft-log-sum-exp-or-soft-max gradient directions, which apply pressure to a whole band of near-maximum lags instead of an arbitrarily chosen 18-lag active set;
- targeted coordinate-transfer directions `e_i - e_j`;
- stochastic low-amplitude batch directions to leave plateaus;
- binary-expressible structured directions from fast bit-pattern search, subsequently refined in continuous variables.

All candidates are accepted only after the authoritative evaluator says that the exact score improved. The actual binding objective values are stored and returned.

1.2 Material difference from the previous program

The prior program relied heavily on linearized active-set subproblems and short gradient steps from a narrow basin. The proposed method differs in three substantive ways.

First, candidate movement occurs along exact complete-ray objective minimization. Even if the true profile has many coincident maxima, the line search monitors the complete `2n-1` profile and cannot silently ignore a hidden lag that would later become active.

Second, the globality mechanism is not a single deterministic collection of parent perturbations. The search nevertheless starts from the parent but simultaneously maintains a multidirectional exploration pool generated from:
- deterministic transformations of the parent;
- multi-resolution vectors;
- rounded/binary threshold patterns generated from the parent or random seeds;
- simulated annealing-style threshold-accepting perturbations;
- random feasible micro-jumps from the current best or from the pool.

Third, a very fast binary integer path is separated from the continuous refinements. Since binary h values (`0` or `1`) preserve `sum = n/2` when `n` is even, binary local movement can be compared almost instantaneously. Bit-pattern search can sample far-discrete regions; promising bit states are kept as continuous `0/1` vectors and refined by the exact feasibility-line search. This allows fractional refinements where discrete counts are attached very close to the target objective value.
