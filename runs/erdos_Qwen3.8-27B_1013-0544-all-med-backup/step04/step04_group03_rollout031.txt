    return float(np.max(corr) * dx)

def project_h(h, target_sum):

    for _ in range(200):
        diff = target_sum - h.sum()

            break
        free = (h > 1e-12) & (h < 1.0 - 1e-12)

So minimizing the overlap is equivalent to MAXIMIZING Σ_{k∈A} Σ_i h[i]*h[i+k], which is a quadratic form.

This is a quadratic program! I can solve it with SLSQP or even with a custom conjugate gradient method.

But this doesn't immediately help because SLSQP is what we're already using.

Let me think of yet another approach.

**Nuclear norm / spectral approach**: The quadratic form Σ_i h[i]*h[i+k] can be written as h^T T_k h where T_k is a shift matrix. The sum over active lags gives h^T (Σ T_k) h. Maximizing this is a trust-region / rank-1 problem.

If I relax h to be a vector and solve h^T M h subject to sum(h) = target and 0≤h≤1, the optimal solution without the box constraint would be along the top eigenvector of M. With the box constraint, it's more complex.

This gives me an idea: use the top eigenvector of the "autocorrelation matrix" as a starting point or as a direction for optimization.

Let me define: M = Σ_{k∈A} (S_k + S_k^T) where S_k is the shift matrix by k.
Then h^T M h = 2 * Σ_{k∈A, k≠0} Σ_i h[i]*h[i+k] + Σ_i h[i]² (for k=0)

The top eigenvector of M gives the direction that maximizes the autocorrelation, which is what we want.

Let me implement this:

```python
def top_eigenvector_init(n, active_lags):
    """Create a starting vector from the top eigenvector of the autocorrelation matrix."""
    # Build M = sum of shift matrices
    M = np.zeros((n, n))
    for k in active_lags:
        if k > 0 and k < n:
            # S_k has 1s on the k-th superdiagonal
            idx = np.arange(n - k)
            M[idx, idx + k] = 1
            M[idx + k, idx] = 1
    # Add diagonal for k=0
    np.fill_diagonal(M, 1)
    
    # Find top eigenvector
    eigvals, eigvecs = np.linalg.eigh(M)
    v = eigvecs[:, -1]
    # Make it positive and project
    v = np.abs(v)
    v = project_onto_simplex_box(v, n/2)
    return v
```
