Let me now think about the pair coordinate descent more carefully, since that's where the real improvement might come from.

For a pair (i, j), the optimal δ to minimize max_s(g_s + δ*d_s) can be found as follows:

f(δ) = max_s (g_s + δ * d_s)

This is a convex piecewise-linear function of δ. Its minimum is at:
- A point where the subgradient contains 0, i.e., where the maximum is achieved by at least two lines with different slopes, and 0 is between those slopes.
- Or at a boundary of the feasible interval for δ.

Algorithm to find min of f(δ) over [δ_min, δ_max]:
1. Evaluate f at δ_min, δ_max, and 0.
2. Find the "active" set: which s achieves the max at each point.
3. The minimum is at the intersection of the two lines that form the "kink" closest to where the subgradient crosses 0.

A simpler approach: since f is convex and piecewise linear, we can find the minimum by:
1. Finding all breakpoints (intersections of pairs of lines that are on the upper envelope)
2. Evaluating f at each breakpoint and at the boundaries
3. Taking the minimum

But finding all breakpoints is O(K²) where K is the number of lines (499). That's 250K per pair, which is too slow.

Better approach: use a binary search / bisection on the subgradient.
- f'(δ) (the slope) is a step function that jumps at breakpoints.
- We want to find where f' crosses 0.
- At a given δ, f'(δ) = d_{s*} where s* = argmax_s(g_s + δ*d_s).
- If d_{s*} > 0, we need to decrease δ. If d_{s*} < 0, increase δ.
- We can use this to do a bisection-like search.

But the issue is that f' can jump over 0 (from negative to positive without hitting 0). In that case, the minimum is at the breakpoint where the jump occurs.

A practical approach: evaluate f at several candidate δ values:
- δ = 0 (current)
- δ = δ_min, δ_max (boundaries)
- δ values where the current maximum line (at δ=0) intersects other lines
  - For the current argmax s0, find δ where g_{s0} + δ*d_{s0} = g_s + δ*d_s for other s
  - δ = (g_s - g_{s0}) / (d_{s0} - d_s) (when d_{s0} ≠ d_s)
- Check a few of these (the ones in the feasible range)

This is O(K) per pair, which is 499. With 31000 pairs, that's 15.6M per sweep. In Python, this might take a few seconds per sweep. That's acceptable if we do a few sweeps.

```python
def pair_step(h, n, i, j, g):
    """Find optimal δ for moving h[i] by +δ and h[j] by -δ."""
    # Compute d_s for all s
    # d_s = (1-h[i+s])*[valid] - h[i-s]*[valid] - (1-h[j+s])*[valid] + h[j-s]*[valid]
    # which is a_is - a_js where a_is = (1-h[i+s])*[valid] - h[i-s]*[valid]
    
    # Actually, let me compute the change in g_s when we move h[i] by +δ and h[j] by -δ:
    # Δg_s = δ * a_is - δ * a_js = δ * (a_is - a_js)
    # where a_is = (1-h[i+s])*[0≤i+s<n] - h[i-s]*[0≤i-s<n]
    
    d = np.zeros(2*n-1)
    for k in range(2*n-1):
        l = k - (n-1)
        # a_is contribution
        if 0 <= i+l < n:
            d[k] += (1 - h[i+l])
        if 0 <= i-l < n:
            d[k] -= h[i-l]
        # a_js contribution (with -δ)
        if 0 <= j+l < n:
            d[k] -= (1 - h[j+l])
        if 0 <= j-l < n:
            d[k] += h[j-l]
    
    # Now f(δ) = max(g + δ*d)
    # Feasible range for δ:
    delta_lo = max(-h[i], h[j] - 1)
    delta_hi = min(1 - h[i], h[j])
    
    if delta_lo >= delta_hi:
        return 0.0, g.max()
    
    # Find min of max(g + δ*d) over δ ∈ [delta_lo, delta_hi]
    # Use the fact that it's convex piecewise linear
    
    # Candidate points: delta_lo, delta_hi, 0, and intersections
    candidates = [delta_lo, delta_hi, 0.0]
    
    # Find the current argmax
    s0 = int(np.argmax(g))
    
    # Intersections of line s0 with others
    for s in range(2*n-1):
        if s == s0:
            continue
        if abs(d[s0] - d[s]) < 1e-15:
            continue
        delta = (g[s] - g[s0]) / (d[s0] - d[s])
        if delta_lo <= delta <= delta_hi:
            candidates.append(delta)
    
    # Evaluate f at candidates
    best_delta = 0.0
    best_val = g.max()
    for delta in candidates:
        val = np.max(g + delta * d)
        if val < best_val - 1e-14:
            best_val = val
            best_delta = delta
    
    # Also try a few points via bisection on subgradient
    # (in case the minimum is at a breakpoint not in our candidates)
    lo, hi = delta_lo, delta_hi
    for _ in range(30):
        mid = (lo + hi) / 2
        s_mid = int(np.argmax(g + mid * d))
        if d[s_mid] > 0:  # slope positive, need to go left
            hi = mid
        elif d[s_mid] < 0:  # slope negative, need to go right
            lo = mid
        else:
            break
    
    for delta in [lo, hi, (lo+hi)/2]:
        if delta_lo <= delta <= delta_hi:
            val = np.max(g + delta * d)
            if val < best_val - 1e-14:
                best_val = val
                best_delta = delta
    
    return best_delta, best_val
```

```python
            break
```

```python
        m = float(g.max())
        sh = alpha * (g - m)
        sh -= sh.max()
        w = np.exp(sh)
        w /= w.sum()
        grad = compute_grad(h, n, w)
        gn = float(np.dot(grad, grad))
        if gn < 1e-20:
            break
        # Try a few step sizes
        improved = False
        for s in [step, step*0.5, step*0.25, step*0.1, step*0.05]:
            h_new = project_feasible(h - s * grad, n)
            c_new = compute_c5(h_new, n)

                h = h_new
                if c_new < best_c:
                    best_c = c_new
                    best_h = h.copy()
                improved = True
                break
        if not improved:
            step *= 0.5
            alpha *= 1.5
            if step < 1e-8:
                break
        else:
            step = min(step * 1.1, 1.0)
            alpha *= 1.05
    return best_h, best_c

def pair_descent(h, n, deadline, max_sweeps=50):
    best_h = h.copy()
    best_c = compute_c5(h, n)
    g = compute_all_g(best_h, n)
    for sweep in range(max_sweeps):
        if time.time() > deadline:
            break
        improved = False
        rng = np.random.RandomState(sweep)
        order = rng.permutation(n)
        for i in order:
            if time.time() > deadline:
                break
            # Find best j and delta
            # Compute a_is for all s (contribution of h[i])
            # Then for each j, d_s = a_is - a_js
            # This is expensive, so let's limit to a subset of j's
            
            # Quick heuristic: try j's that are "far" from i in the gradient sense
            # Or just try a random subset
            for _ in range(20):  # try 20 random j's
                j = int(rng.randint(n))
                if j == i:
                    continue
                # Compute d
                d = np.zeros(2*n-1)
                for k in range(2*n-1):
                    l = k - (n-1)
                    if 0 <= i+l < n:
                        d[k] += (1 - best_h[i+l])
                    if 0 <= i-l < n:
                        d[k] -= best_h[i-l]
                    if 0 <= j+l < n:
                        d[k] -= (1 - best_h[j+l])
                    if 0 <= j-l < n:
                        d[k] += best_h[j-l]
                
                # Find optimal delta
                d_lo = max(-best_h[i], best_h[j]-1)
                d_hi = min(1-best_h[i], best_h[j])
                if d_lo >= d_hi - 1e-15:
                    continue
                
                # Evaluate at a few points
                candidates = [d_lo, d_hi, 0.0]
                s0 = int(np.argmax(g))
                denom = d[s0]
                if abs(denom) > 1e-15:
                    # Find where line s0 crosses others
                    for s in range(0, 2*n-1, 3):  # subsample for speed
                        if s == s0:
                            continue
                        dd = d[s0] - d[s]
                        if abs(dd) > 1e-15:
                            delta = (g[s] - g[s0]) / dd
                            if d_lo < delta < d_hi:
                                candidates.append(delta)
                
                best_d = 0.0
                best_v = float(g.max())
                for delta in candidates[:20]:
                    v = float(np.max(g + delta * d))
                    if v < best_v - 1e-12:
                        best_v = v
                        best_d = delta
                
                if best_d != 0 and best_v < best_c - 1e-12:
                    best_h[i] += best_d
                    best_h[j] -= best_d
                    best_h = project_feasible(best_h, n)
                    best_c = compute_c5(best_h, n)
                    g = compute_all_g(best_h, n)
                    improved = True
        
        if not improved:
            break
    return best_h, best_c
```

import numpy as np

def compute_c5(h, n):
    dx = 2.0 / n
    return float(np.max(np.correlate(h, 1 - h, mode='full')) * dx)

def compute_all_g(h, n):
    dx = 2.0 / n
    return np.correlate(h, 1 - h, mode='full') * dx

def project_feasible(h, n):
    target = n / 2.0
    lo, hi = -2.0, 2.0
    for _ in range(64):
        tau = (lo + hi) / 2.0
        if np.clip(h - tau, 0.0, 1.0).sum() > target:
            lo = tau
        else:
            hi = tau
    return np.clip(h - (lo + hi) / 2.0, 0.0, 1.0)

def compute_grad(h, n, w):
    grad = np.zeros(n)
    for k in range(2 * n - 1):
        wk = w[k]
        if abs(wk) < 1e-15:
            continue
        l = k - (n - 1)
        if l == 0:
            grad += wk * (1.0 - 2.0 * h)
        elif l > 0:
            grad[:n-l] += wk * (1.0 - h[l:])
            grad[l:] -= wk * h[:n-l]
        else:
            m = -l
            grad[m:] += wk * (1.0 - h[:n-m])
            grad[:n-m] -= wk * h[m:]
    return grad

def pair_opt(delta_candidates, g, d):
