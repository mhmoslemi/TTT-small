For a given set of active lags S, the objective is:
f_S(h) = max_{k in S} corr(k) * dx

This can be replaced with:

which is linear in h (since each corr(k) is linear in h), so we can use SLSQP effectively.

Wait, actually each corr(k) is bilinear in h (it's sum h[i] * (1-h[i+k])). So it's not linear. But it is differentiable.

Let me write the gradient of sum_{k in S} corr(k) * dx:
For lag k (where k = idx - (n-1)):
- corr(idx) = sum_i h[i] * (1-h[i+k]) for appropriate indices

The gradient with respect to h[j] for a specific lag k:
- If k > 0: d/dh[j] sum_i h[i](1-h[i+k]) = (1-h[j+k]) - h[j-k] for j where both terms exist
  More carefully: corr = sum_{i=0}^{n-1-k} h[i](1-h[i+k])
  d/dh[i] = (1-h[i+k]) for i = 0..n-1-k
  d/dh[i+k] = -h[i] for i = 0..n-1-k
  
So for lag k > 0:
  grad[i] += (1-h[i+k]) for i < n-k
  grad[i] -= h[i-k] for i >= k

This is the same as what the previous code does. Good.

1. Compute all correlations
2. Pick top-k indices
3. Compute gradient of sum of those k correlations
4. Do SLSQP step (or a few gradient steps)

            h_c = project_h(r.x, n_coarse / 2.0)
            c5 = compute_c5(h_c)
    except Exception:
        pass
    h_back = project_h(np.interp(x_full, x_coarse, h_c), n / 2.0)
    return h_back, compute_c5(h_back)

def run(seed=42, budget_s=1100, **kwargs):
    np.random.seed(seed)
    _start_box[0] = time.time()
    _budget_box[0] = budget_s

    if 'initial_h_values' in globals() and initial_h_values is not None:
        best_h = np.array(initial_h_values, dtype=float).copy()
    else:
        best_h = np.full(200, 0.5)
    best_c5 = compute_c5(best_h)

    # Phase 1: Top-k SLSQP with decreasing k (focus on active constraints)
    for kf in [0.1, 0.06, 0.04, 0.025, 0.015]:
        if _time_left() < 15:
            break
        h2, c2 = do_topk(best_h, 120, kf, _time_left)
        if c2 < best_c5:
            best_h, best_c5 = h2, c2

    # Phase 2: Smooth-max SLSQP (anneal beta)
    if _time_left() > 40:
        h2, c2 = do_sm(best_h, [80, 300, 1500, 6000, 15000], 3500, _time_left)
        if c2 < best_c5:
            best_h, best_c5 = h2, c2

    # Phase 3: Random restarts to escape local optima
    if _time_left() > 80:
        best_h, best_c5 = do_restart(best_h, 10, _time_left, 0.006)

    # Phase 4: Coarse global search via DE
    for nc in [50, 80]:
        if _time_left() < 50:
            break
        h2, c2 = do_coarse_global(best_h, nc, _time_left, seed + nc)
        if c2 < best_c5:
            best_h, best_c5 = h2, c2

    # Phase 5: Refinement after global exploration
    if _time_left() > 30:
        h2, c2 = do_topk(best_h, 200, 0.03, _time_left)
        if c2 < best_c5:
            best_h, best_c5 = h2, c2
    if _time_left() > 30:
        h2, c2 = do_sm(best_h, [5000, 20000, 50000], 5000, _time_left)
        if c2 < best_c5:
            best_h, best_c5 = h2, c2

    # Phase 6: Another round of restarts + refine
    if _time_left() > 60:
        best_h, best_c5 = do_restart(best_h, 6, _time_left, 0.004)
        if _time_left() > 20:
            h2, c2 = do_topk(best_h, 150, 0.02, _time_left)
            if c2 < best_c5:
                best_h, best_c5 = h2, c2

    # Phase 7: Subgradient descent (long)
    steps = [0.025, 0.012, 0.006, 0.003, 0.0015, 0.0008, 0.0004]
    best_h, best_c5 = do_subgrad(best_h, 50000, 8, steps, _time_left, 200, 0.003)

    # Phase 8: Final SLSQP polish
    if _time_left() > 25:
        h2, c2 = do_sm(best_h, [20000, 50000, 100000], 8000, _time_left)
        if c2 < best_c5:
            best_h, best_c5 = h2, c2
    if _time_left() > 12:
        h2, c2 = do_topk(best_h, 100, 0.01, _time_left)
        if c2 < best_c5:
            best_h, best_c5 = h2, c2

    # Phase 9: Final subgradient micro-polish
    if _time_left() > 5:
        steps_fine = [0.01, 0.005, 0.002, 0.001, 0.0005]
        best_h, best_c5 = do_subgrad(best_h, 10000, 5, steps_fine, _time_left, 500, 0.002)

    return best_h, best_c5, len(best_h)
