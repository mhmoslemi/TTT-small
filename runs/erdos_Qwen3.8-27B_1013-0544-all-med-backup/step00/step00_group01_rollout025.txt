g[j] = (1 - h[j+lag]) * I[0 <= j+lag < n] - h[j-lag] * I[0 <= j-lag < n]

This can be computed as:
g[j] = (1 - h[j+lag]) - h[j-lag]

- Then h[j+lag] = h_pad[j+lag+1] and h[j-lag] = h_pad[j-lag+1]

```python
def compute_gradient_for_lag(h, n, lag):
    """Compute gradient of corr(lag) w.r.t. h, vectorized."""
    # h[j+lag] with out-of-bounds = 0
    # h[j-lag] with out-of-bounds = 0
    right = np.zeros(n)
    left = np.zeros(n)
    
    if lag >= 0:
        # h[j+lag] is valid for j = 0, 1, ..., n-1-lag
        right[:n-lag] = h[lag:]
        # h[j-lag] is valid for j = lag, lag+1, ..., n-1
        left[lag:] = h[:n-lag]
    else:
        # lag < 0, let l = -lag
        l = -lag
        # h[j+lag] = h[j-l] is valid for j = l, l+1, ..., n-1
        right[l:] = h[:n-l]
        # h[j-lag] = h[j+l] is valid for j = 0, 1, ..., n-1-l
        left[:n-l] = h[l:]
    
    return (1.0 - right) - left
```

This is O(n) per lag, and we have O(n) lags, so O(n^2) total.
