  b) Change h[i+t] from 0 to 1 where h[i]=1 (reduces c[t] by 1)
- But these changes affect other lags too.

So the key question is: which single-bit flip (compensated by another flip to maintain the sum constraint) most reduces the maximum correlation?

Let me try this approach:
1. Compute all correlations
2. Find the top-K worst lags
3. For each worst lag t, compute the "gradient" with respect to each position
4. Find the pair of positions (i, j) such that flipping h[i] (1→0) and h[j] (0→1) most reduces the max correlation
5. Apply the best swap
6. Repeat

The gradient approach: if I flip h[i] from 1 to 0, the change in c[t] is:
- -(1 - h[i+t]) if i+t is valid (i in source at lag t)
- +h[i-t] if i-t is valid (i in target at lag t, the term h[i-t]*(1-h[i]) loses 1)

Wait, let me be more careful. c[t] = sum_{valid i} h[i] * (1-h[i+t]).

If h[p] changes from 1 to 0:
- If p is a source index (p+t valid): the term h[p]*(1-h[p+t]) changes from 1*(1-h[p+t]) to 0, change = -(1-h[p+t])
- If p is a target index (p-t valid, i.e., h[p-t]*(1-h[p]) is a term): changes from h[p-t]*1 to h[p-t]*0, change = -h[p-t]

Total change in c[t] when h[p]: 1→0:
Δc[t] = -(1-h[p+t]) * [p+t valid] - h[p-t] * [p-t valid]

Similarly, when h[q]: 0→1:
Δc[t] = +(1-h[q+t]) * [q+t valid] + h[q-t] * [q-t valid]

For a swap (h[p]: 1→0, h[q]: 0→1):
Δc[t] = -(1-h[p+t]) * [p+t valid] - h[p-t] * [p-t valid] + (1-h[q+t]) * [q+t valid] + h[q-t] * [q-t valid]

        # Thue-Morse
        inits.append(thue_morse_binary(n))
        # Random
        hr = np.zeros(n)
        hr[rng.choice(n, size=n//2, replace=False)] = 1.0
        inits.append(hr)
        
        best_h_n = inits[0].copy()
        best_c_n = compute_c5(best_h_n, n)
        
        for init_idx, h_start in enumerate(inits):
            if time.time() > phase_dl:
                break
            time_left = phase_dl - time.time()
            if time_left < 10:
                break
            
            # Phase A: lag-aware local search
            frac_search = 0.5
            frac_sa = 0.3
            frac_final = 0.2
            dl_a = time.time() + time_left * frac_search
            dl_b = time.time() + time_left * (frac_search + frac_sa)
            dl_c = time.time() + time_left
            
            h_cur = h_start.copy()
            c_cur = compute_c5(h_cur, n)
            
            # Local search
            h_cur, c_cur = lag_aware_search(h_cur, n, dl_a, K=12, max_stall=100, seed=seed + idx_n * 100 + init_idx)
            if c_cur < best_c_n:
                best_c_n = c_cur
                best_h_n = h_cur.copy()
            
            # Simulated annealing
            if time.time() < dl_b:
                h_sa, c_sa = sa_search(best_h_n, n, dl_b, t_start=0.2, t_end=0.0005, seed=seed + 500 + idx_n + init_idx)
                if c_sa < best_c_n:
                    best_c_n = c_sa
                    best_h_n = h_sa.copy()
            
            # Final local search after SA
            if time.time() < dl_c - 2:
                h_fin, c_fin = lag_aware_search(best_h_n, n, dl_c - 2, K=15, max_stall=80, seed=seed + 900 + idx_n + init_idx)
                if c_fin < best_c_n:
                    best_c_n = c_fin
                    best_h_n = h_fin.copy()
        
        if best_c_n < best_c_overall:
            best_c_overall = best_c_n
            best_h_overall = best_h_n.copy()
            best_n_overall = n
    
    # Final polish on the overall best with small perturbations
    if time.time() < dl - 2:
        h_fp, c_fp = lag_aware_search(best_h_overall, best_n_overall, dl - 2, K=20, max_stall=50, seed=seed + 5000)
        if c_fp < best_c_overall:
            best_c_overall = c_fp
            best_h_overall = h_fp.copy()
    
    # Verify
    best_c_overall = compute_c5(best_h_overall, best_n_overall)
    return best_h_overall, best_c_overall, best_n_overall
