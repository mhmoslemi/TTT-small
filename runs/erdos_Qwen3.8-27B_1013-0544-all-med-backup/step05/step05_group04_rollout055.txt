```python
        # Find optimal δ
        if D[k_star] <= 1e-12:
            # This shouldn't happen since grad[i_best] > 0 means D[k_star] > 0
            # (grad[i_best] is the contribution to D[k_star] from position i_best)
            break
        
        denom = D[k_star] - D
        valid = denom > 1e-12
        if np.any(valid):
            cross = np.where(valid, (c - c[k_star]) / denom, np.inf)
            optimal_d = min(delta_max, np.min(np.clip(cross, 0, None)))
        else:
            optimal_d = delta_max
        
        if optimal_d < 1e-12:
            break
        
        # Take the step
        h[i_best] -= optimal_d
        h[j_best] += optimal_d
    
    # Final projection
    h = project_feasible(h, n)
    best_c = compute_c5(h, n)
    return h, best_c
```

This is O(n) per step, and we might need many steps. Let me estimate: each step moves one pair to its optimal position. The number of distinct pairs is O(n²), and we might revisit pairs. In practice, it should converge in O(n²) steps or so.

For n=250, that's about 62,500 steps, each O(n) = 250 operations. Total: ~15M operations. Should be fast.

But there's a subtlety: the "greedy" approach (always taking the best single pair move) might not converge to the global optimum. It could get stuck in a local optimum where no single pair move helps, but a combination of two pair moves would.

To handle this, I can:
1. Use the greedy approach until no improvement
2. Then use a "random perturbation + greedy" (simulated annealing style)
3. Or use the full pair search (all pairs, not just the best)

The key improvement over the previous solution is the **optimal step size** in the pair descent. Instead of trying fixed deltas {0.01, 0.005, ...}, we compute the exact optimal δ for each pair. This should be more efficient and find slightly better solutions.

Let me also add a "multi-lag" variant: instead of only reducing the maximum lag, try to equalize the top few lags. This can be done by using a weighted combination:

and minimizing this.

import time

def compute_c5(h, n):
    dx = 2.0 / n
    return float(np.max(np.correlate(h, 1 - h, mode='full')) * dx)

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h.copy(), 0.0, 1.0)
    for _ in range(1000):
        diff = target - h.sum()
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            room = 1.0 - h
            tot = room.sum()
            if tot < 1e-15:
                break
            h += (diff / tot) * room
        else:
            tot = h.sum()
            if tot < 1e-15:
                break
            h += (diff / tot) * h
    return np.clip(h, 0.0, 1.0)

def obj_smooth(x, n, alpha):
    dx = 2.0 / n
    c = np.correlate(x, 1 - x, mode='full') * dx
    m = c.max()
    sh = alpha * (c - m)
    mx = sh.max()
    if mx > 500:
        return float(m + (mx + np.log(np.sum(np.exp(sh - mx)))) / alpha)
    return float(m + np.log(np.sum(np.exp(sh))) / alpha)

def _sum_c(x, n):
    return float(x.sum() - n / 2.0)

def _sum_j(x, n):
    return np.ones(n)

    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': _sum_c, 'jac': _sum_j, 'args': (n,)}]
    try:
        res = minimize(obj_smooth, h, args=(n, alpha), method='SLSQP',
                       bounds=bounds, constraints=cons,
                       options={'maxiter': maxiter, 'ftol': 1e-15})
        return project_feasible(res.x, n)
    except Exception:
        return h.copy()
