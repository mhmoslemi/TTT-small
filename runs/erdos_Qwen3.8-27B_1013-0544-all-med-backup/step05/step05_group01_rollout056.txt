**Bisection on t**: For a given t, check if there exists h with all c_k ≤ t. This is a quadratic programming problem (though non-convex due to the h(1-h) terms).

Actually, c_k = ∑ h[i] * (1-h[j]) * dx is a quadratic form in h. The constraint c_k ≤ t is a quadratic inequality. The feasible set is the intersection of a box, a hyperplane, and quadratic inequalities. This is non-convex in general.

But wait: c_k = ∑ h[i] - ∑ h[i]*h[j] * dx. The first term is linear, the second is a quadratic form. The quadratic form is -∑ h[i]*h[j] which is indefinite (it's a product, not a sum of squares). So the constraint is non-convex.

Let me try yet another approach: **coordinate descent with a smart step size**.

At each step:
1. Pick the lag k* that achieves the maximum
2. Compute the gradient of c_{k*} with respect to h
3. Take a step in the negative gradient direction (projected onto the feasible set)
4. Repeat

The gradient of c_{k*} with respect to h[i]:
c_{k*} = ∑_m h[m] * (1-h[m+k*-(n-1)]) * dx

∂c_{k*}/∂h[i] = dx * [(1-h[i+k*-(n-1)]) + ∑_m h[m] * (-1) * δ_{i, m+k*-(n-1)}]
= dx * [(1-h[i+k*-(n-1)]) - h[i-k*+(n-1)]] (with valid indices)

So the gradient is:
g[i] = dx * [(1-h[i+k*-(n-1)]) - h[i-k*+(n-1)]] (for valid indices, 0 otherwise)

This is O(n) to compute! And we can take a projected gradient step.

def subgradient_step(h, n, k_star, step_size):
    """Take a projected gradient step to reduce c[k_star]."""
    dx = 2.0 / n
    grad = np.zeros(n)
    
    # First factor: h[i] appears as first factor in c[k_star] when m=i
    # Contribution: dx * (1 - h[i + k_star - (n-1)]) if 0 <= i + k_star - (n-1) < n
    lo1 = max(0, n - 1 - k_star)
    hi1 = min(n, n + k_star - (n - 1))  # = k_star + 1
    for i in range(lo1, hi1):
        j = i + k_star - (n - 1)
        if 0 <= j < n:
            grad[i] += dx * (1 - h[j])
    
    # Second factor: h[i] appears as second factor when m + k_star - (n-1) = i
    # i.e., m = i - k_star + (n-1)
    # Contribution: -dx * h[m] = -dx * h[i - k_star + (n-1)]

    # => i in [k_star - (n-1), k_star - 1]

Actually, I'll just trust that the correlation is computed correctly and focus on the algorithm.

The key point is: for a given k*, the gradient of c[k*] with respect to h can be computed in O(n). Then I can do projected subgradient descent.

But the issue is: the max might switch from one lag to another after a step. So I need to:
1. Find k* = argmax c
2. Compute gradient of c[k*]
3. Take a step
4. Check if the max is still at k* or has switched
5. If switched, go back to step 2 with the new k*

This is essentially the "active set" approach for the max function.

Let me also add: **when multiple lags are tied at the max**, use the average gradient (which is the correct subgradient).

Here's my refined algorithm:

def subgradient_descent(h, n, deadline, max_iters=100000):
    """Project subgradient descent on the max correlation."""
    best_h = h.copy()
    best_c = compute_c5(h, n)
    h = h.copy()
    dx = 2.0 / n
    
    for it in range(max_iters):

            break

            best_c = c_max
            best_h = h.copy()

            # = sum_i h[i]*dx - sum_i h[i]*h[i-k+n-1]*dx

        # Actually, let me compute the gradient properly.
        # c[k] = dx * sum_{i valid} h[i] * (1 - h[i-k+n-1])
        # Let j = i-k+n-1 (the index of the second h)
        # c[k] = dx * sum_i h[i] * (1 - h[j(i)])
        # where j(i) = i - k + n - 1 (if valid)
        
        # d(h[i] * (1-h[j(i)]))/dh[i] = (1-h[j(i)]) - h[i]*δ(i,j(i))
        #                                   = (1-h[j(i)]) - h[i] if j(i)=i
        # The condition j(i) = i means i - k + n - 1 = i, i.e., k = n-1.
        
        # So for k = n-1: d/dh[i] = (1-h[i]) - h[i] = 1 - 2h[i] (times dx)
        # For k ≠ n-1: d/dh[i] = (1-h[j(i)]) + (if i = j(m) for some m in the sum, then -h[m])
        
        # Wait, I need to be more careful. The product h[i]*(1-h[j(i)]) has:
        # d/dh[i] = (1-h[j(i)]) + h[i]*d(1-h[j(i)])/dh[i]
        #         = (1-h[j(i)]) - h[i]*δ_{j(i),i}
        #         = (1-h[j(i)]) for k ≠ n-1
        #         = (1-h[i]) - h[i] = 1-2h[i] for k = n-1
        
        # But h[i] also appears as h[j(m)] for some m ≠ i!
        # h[i] = h[j(m)] when j(m) = i, i.e., m - k + n - 1 = i, i.e., m = i + k - n + 1
        # For this m to be valid: 0 ≤ m ≤ n-1
        # The contribution: -dx * h[m] = -dx * h[i+k-n+1]
        
        # So the full gradient:
        # grad[i] = dx * (1-h[j(i)]) - dx*h[i+k-n+1] (if i+k-n+1 is valid)
        #         for k ≠ n-1
        # where j(i) = i-k+n-1
        
        # For k = n-1:
        # grad[i] = dx * (1-h[i]) - dx*h[i] = dx*(1-2h[i])
        # (since j(i) = i and i+k-n+1 = i)
        
        # Let me combine: grad[i] = dx * (1-h[i-k+n-1]) - dx*h[i+k-n+1]
        # (with the convention that h[x] = 0 for x outside [0,n-1])
        
        # This is a neat formula! Let me verify for k = n-1:
        # grad[i] = dx * (1-h[i-(n-1)+n-1]) - dx*h[i+(n-1)-n+1]
        #         = dx * (1-h[i]) - dx*h[i]
        #         = dx*(1-2h[i]) ✓
        
        # Great! So the gradient of c[k] w.r.t. h[i] is:
        # dx * (1 - h[(i-k+n-1) mod ...]) - dx * h[(i+k-n+1) mod ...]
        # where out-of-range indices contribute 0.
        
        # Let me vectorize this:
        if len(active) == 0:
            break
        
        grad = np.zeros(n)
        for k in active:
            # First term: (1 - h[i-k+n-1]) for valid i-k+n-1
            offset1 = n - 1 - k  # i + offset1 = i - k + n - 1
            # Valid when 0 <= i + offset1 < n, i.e., -offset1 <= i < n - offset1
            i_lo1 = max(0, -offset1)
            i_hi1 = min(n, n - offset1)
            if i_hi1 > i_lo1:
                grad[i_lo1:i_hi1] += dx * (1 - h[i_lo1 + offset1 : i_hi1 + offset1])
            
            # Second term: -h[i+k-n+1] for valid i+k-n+1
            offset2 = k - n + 1  # i + offset2 = i + k - n + 1
            i_lo2 = max(0, -offset2)
            i_hi2 = min(n, n - offset2)
            if i_hi2 > i_lo2:
                grad[i_lo2:i_hi2] -= dx * h[i_lo2 + offset2 : i_hi2 + offset2]
        
        # Average over active lags
        grad /= len(active)
        
        # Adaptive step size
        # Start with a small step, increase if it works
        step = 0.01
        for _try in range(10):
            h_new = h - step * grad
            h_new = np.clip(h_new, 0, 1)
            h_new = project_feasible(h_new, n)
            c_new = compute_c5(h_new, n)
            if c_new < c_max:
                h = h_new
                break
            step *= 0.5
        else:
            # Couldn't improve, try smaller step
            break
    
    return best_h, best_c

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1 - h, mode='full')
    return float(np.max(c) * dx)

def compute_corr_vec(h, n):
    dx = 2.0 / n
    return np.correlate(h, 1 - h, mode='full') * dx

def project_feasible(h, n):
    target_sum = n / 2.0
    h = np.clip(h.copy(), 0.0, 1.0)
    for _ in range(3000):
        diff = target_sum - h.sum()
        if abs(diff) < 1e-16:
            break
        if diff > 0:
            room = 1.0 - h
            tot = room.sum()
            if tot < 1e-15:
                break
            h += (diff / tot) * room
        else:
            tot = h.sum()
            if tot < 1e-15:
                break
            h += (diff / tot) * h
    return np.clip(h, 0.0, 1.0)

def softmax_obj(x, n, alpha):
    dx = 2.0 / n
    c = np.correlate(x, 1 - x, mode='full') * dx
    m = c.max()
    shifted = alpha * (c - m)
    shifted = np.clip(shifted, -100, 0)
    return float(m + np.log(np.sum(np.exp(shifted))) / alpha)

def _sum_fun(x, n):
    return float(x.sum() - n / 2.0)

def _sum_jac(x, n):
    return np.ones(n)

def slsqp_opt(h, n, alpha, maxiter):
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': _sum_fun, 'jac': _sum_jac, 'args': (n,)}]
    try:
        res = minimize(softmax_obj, h, args=(n, alpha), method='SLSQP',
                       bounds=bounds, constraints=cons,
                       options={'maxiter': maxiter, 'ftol': 1e-20})
        return project_feasible(res.x, n)
    except Exception:
        return h.copy()

def subgrad_descent(h, n, deadline, max_iters=500000):
    best_h = h.copy()
    best_c = compute_c5(h, n)
    h = h.copy()
    dx = 2.0 / n
    eps = 1e-5
    
    for it in range(max_iters):
        if time.time() > deadline:
            break
        c = compute_corr_vec(h, n)
        c_max = c.max()
        if c_max < best_c - 1e-15:
            best_c = c_max
            best_h = h.copy()
        
        active = np.where(c >= c_max - eps)[0]
        if len(active) == 0:
            break
        
        grad = np.zeros(n)
        for k in active:
            offset1 = n - 1 - k
            i_lo1 = max(0, -offset1)
            i_hi1 = min(n, n - offset1)
            if i_hi1 > i_lo1:
                grad[i_lo1:i_hi1] += dx * (1 - h[i_lo1 + offset1:i_hi1 + offset1])
            offset2 = k - (n - 1)
            i_lo2 = max(0, -offset2)
            i_hi2 = min(n, n - offset2)
            if i_hi2 > i_lo2:
                grad[i_lo2:i_hi2] -= dx * h[i_lo2 + offset2:i_hi2 + offset2]
        grad /= len(active)
        
        # Backtracking line search
        step = 0.1
        improved = False
        for _t in range(8):
            h_new = project_feasible(h - step * grad, n)
            c_new = compute_c5(h_new, n)
            if c_new < c_max - 1e-16:
                h = h_new
                improved = True
                break
            step *= 0.5
        if not improved:
            # Try a different tolerance
            eps *= 0.5
            if eps < 1e-12:
                break
    
    return best_h, best_c
