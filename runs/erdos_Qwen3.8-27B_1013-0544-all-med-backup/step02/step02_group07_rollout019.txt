```python
def compute_grad(h, n):
    """Compute gradient of all c[m] w.r.t. all h[j]. Returns shape (2n-1, n)."""
    offset_array = np.arange(2*n-1) - (n-1)  # range from -(n-1) to (n-1)
    grad = np.zeros((2*n-1, n))
    for m in range(2*n-1):
        off = offset_array[m]
        for j in range(n):
            g = 0.0
            if 0 <= j - off < n:
                g += (1.0 - h[j - off])
            if 0 <= j + off < n:
                g -= h[j + off]
            grad[m, j] = g
    return grad
```

```python
import cvxpy as cp

def solve_slp_step(h0, n):
    c = np.correlate(h0, 1-h0, mode='full')
    grad = compute_grad(h0, n)
    const = c - grad @ h0  # c[m] - grad[m,:]·h0
    
    x = cp.Variable(n)
    t = cp.Variable()
    constraints = [
        grad @ x + const <= t,
        x >= 0,
        x <= 1,
        cp.sum(x) == n/2
    ]
    objective = cp.Minimize(t)
    prob = cp.Problem(objective, constraints)
    prob.solve(solver=cp.GLOP)  # or ECOS, or CBC
    return x.value
```

```python
    best_c5 = compute_c5(h0)
    for it in range(max_iters):
        c = np.correlate(best_h, 1-best_h, mode='full')
        grad = compute_grad(best_h, n)
        const = c - grad @ best_h
        
        x = cp.Variable(n)
        t = cp.Variable()
        constraints = [
            grad @ x + const <= t,
            x >= 0,
            x <= 1,
            cp.sum(x) == n/2
        ]
        prob = cp.Problem(cp.Minimize(t), constraints)
        prob.solve(solver=cp.GLOP)
        
        if x.value is None:
            break
        
        x_val = np.clip(x.value, 0, 1)
        # Project to satisfy sum
        x_val = project_h(x_val, n/2)
        
        # Line search
        alpha = 1.0
        while alpha > 0.01:
            h_try = (1-alpha)*best_h + alpha*x_val
            h_try = project_h(h_try, n/2)
            c5_try = compute_c5(h_try)
            if c5_try < best_c5:
                break
            alpha *= 0.5
        
        best_h = (1-alpha)*best_h + alpha*x_val
        best_h = project_h(best_h, n/2)
        best_c5 = compute_c5(best_h)
        
        if alpha < 0.02:
            # Stuck, try a smaller trust region or break
            break
    
    return best_h, best_c5
```

If h is a step function (0 or 1), then h(x)(1-h(x+k)) = h(x) - h(x)h(x+k). For h to be 0 or 1, h(x)h(x+k) = 1 only if both are 1.

For a step function with value 1 on a set of measure 1 (since ∫h = 1 over [0,2]), the overlap at lag k is:
∫ h(x)(1-h(x+k)) dx = measure{A} - measure{A ∩ (A+k)} = 1 - measure{A ∩ (A+k)}

where A is the set where h=1, with measure 1.

To minimize max_k (1 - measure{A ∩ (A+k)}), we want to maximize min_k measure{A ∩ (A+k)}.

This is related to the "maximum overlap" problem. For a set A of measure 1 in [0,2], we want the autocorrelation to be as large as possible at all lags.

The best we can do with a step function is probably related to the structure of A. If A = [0,1], then A ∩ (A+k) has measure max(0, 1-|k|) for k ∈ [-1,1] and 0 otherwise. So the overlap at k=1 is 1-0=1, giving C₅ ≥ 1. That's terrible.

If A is spread out, like A = [0, 0.5] ∪ [1, 1.5], then A ∩ (A+0.5) = [0.5,0.5] ∪ [1,1.5]... wait, let me think more carefully.

Actually, for a measurable set A ⊂ [0,2] with measure 1, the autocorrelation function is:
(f*f)(k) = ∫ 1_A(x) 1_A(x+k) dx

We want to maximize the minimum of this over k (for k in [-2,2] since the domain is [0,2]).

For A of measure 1 in [0,2]:
- At k=0: (f*f)(0) = ∫ 1_A(x) dx = 1 (always)
- At k=±2: (f*f)(k) = 0 (A and A+k are disjoint for |k|≥2... well, A ⊂ [0,2] and A+k ⊂ [k, 2+k], so for k=2, A+k ⊂ [2,4], and A⊂[0,2], intersection is at most {2} which has measure 0)

```python
def compute_grad(h, n):
```

```python
    # For each m (with offset off), grad[m,j] = (1-h[j-off])_valid - h[j+off]_valid
    # j-off valid means 0 <= j-off < n, i.e., off <= j < n+off

        valid1 = (offsets[m] >= 0) & (offsets[m] < n)  # always true since off in -(n-1)..(n-1)
        # Actually let me just do it with masks
```

    offsets = np.arange(2 * n - 1) - (n - 1)
    grad = np.zeros((2 * n - 1, n))
    j = np.arange(n)
    for m in range(2 * n - 1):

        valid_a = (j - off >= 0) & (j - off < n)
        valid_b = (j + off >= 0) & (j + off < n)
