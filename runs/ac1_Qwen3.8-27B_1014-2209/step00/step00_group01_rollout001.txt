- So `d(conv_k)/d(a_i) = a_{k-i} + a_{k-i} = 2*a_{k-i}` (when both j=i and j=k-i are in range and j ≠ k-j)
- If k-i = i (i.e., k=2i), then it's just `a_i` (the term is a_i^2 and appears once).

So the gradient is essentially `2 * a` reversed and shifted, with a correction at the center.

This means the gradient computation is O(n) per term, or O(n^2) for all terms. For n=6121, that's about 37 million operations, feasible in numpy.

But computing the full objective (max of 2n-1 conv values) also requires O(n^2) or O(n log n) via FFT.

Let me design a practical algorithm:

**Algorithm: Subgradient descent with FFT**

1. Normalize: `a = a / sum(a)` so sum = 1.
2. Compute `conv = ifft(|fft(a)|^2)` (circular) and extract the linear part. Actually, for linear convolution, pad with zeros.
3. Find the peak: `k* = argmax(conv)`.
4. Compute subgradient: `g_i = 2 * a[(k*-i) mod n]` (approximately, for circular conv) or more carefully for linear conv.
5. Update: `a = a - lr * g; a = max(a, 0); a = a / sum(a)`.
6. Repeat.

The issue with this is that it only tracks one constraint (the peak). Better to track multiple near-peak constraints.

**Better: Use all constraints simultaneously**

The objective `max_k conv_k` has subgradient = average of gradients of all active constraints. If we define "active" as being within epsilon of the max, we get a smoother subgradient.

Or use the log-sum-exp smoothing: `L(tau) = tau * log(sum_k exp(conv_k/tau))`. For large tau, this is smooth and the gradient is available. Then decrease tau.

But for n=6121, `2n-1 = 12241` exp values, each requiring an FFT... actually no, the conv is computed once via FFT, and then we take the log-sum-exp of its entries. The gradient of LSE with respect to conv_k is `exp(conv_k/tau) / sum_j exp(conv_j/tau)`. Then the gradient with respect to a_i is the sum over k of that weight times the gradient of conv_k w.r.t. a_i.

This is a weighted average of the "shifted" versions of a. It can be computed as: `grad_a_i = sum_k w_k * 2*a_{k-i}` (approximately). This is a weighted convolution of a with itself, weighted by w. Can be done via FFT in O(n log n).
