For each interval [a, b], we need to find all x_i that fall within [a, b]. This can be done by finding the indices i where a <= x_i <= b.

But since dx is fixed, we can compute the start and end indices as:

start_idx = int(a / dx)
end_idx = int(b / dx)

But since a and b are real numbers, this may not be precise. However, for the purpose of initial guess, this approximation is acceptable.

So, for each interval, we can compute the start and end indices and set those positions to 1.0.

But we need to ensure that the end_idx does not exceed n_points - 1.

def generate_structured_guess(m, n_points):
    dx = 2.0 / n_points
    l = 1.0 / m
    g = (2.0 - m*l) / (m - 1)
    h = np.zeros(n_points)
    current_pos = 0.0
    for _ in range(m):
        # Find the indices for the current interval [current_pos, current_pos + l]
        start_idx = int(current_pos / dx)
        end_idx = int((current_pos + l) / dx)
        # Ensure end_idx does not exceed n_points - 1
        end_idx = min(end_idx, n_points - 1)
        # Set h[start_idx:end_idx+1] to 1.0
        h[start_idx:end_idx+1] = 1.0
        # Move to the next interval
        current_pos += l + g
    # Scale to ensure the integral is 1.0
    current_sum = np.sum(h)
    scale = (n_points / 2) / current_sum
    h = h * scale
    return h
