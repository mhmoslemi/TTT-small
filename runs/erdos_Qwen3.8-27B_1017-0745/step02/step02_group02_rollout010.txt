Let me be careful about the LP formulation:
- Variables: d[0..n-1], t (total n+1 variables)
- Minimize: t
- Constraints:
  - For each active lag s: q_s + g_s^T d <= t  →  g_s^T d - t <= -q_s
  - sum(d) = 0
  - Bounds: max(-Delta, -h[i]) <= d[i] <= min(Delta, 1-h[i])
  - t is free

In scipy linprog:
- c = [0, ..., 0, 1] (n+1 elements, last is 1 for t)
- A_ub: for each active lag s, row is [g_s, -1], b_ub is -q_s
  Wait: q_s + g_s^T d <= t → g_s^T d - t <= -q_s
  So A_ub row = [g_s entries, -1], b_ub = -q_s
- A_eq: [1, 1, ..., 1, 0] (sum of d = 0)
- b_eq: 0
- bounds: for d[i]: (max(-Delta, -h[i]), min(Delta, 1-h[i]))
  for t: (None, None)

        p = np.array(initial_h_values, dtype=np.float64).ravel()
        if 1 <= p.size <= 999 and np.all(np.isfinite(p)) and np.all(p >= -1e-8) and np.all(p <= 1.0 + 1e-8):
            n, parent = int(p.size), p
    except Exception:
        pass
    if parent is None and 'n_points' in kwargs:
        try:
            v = int(kwargs['n_points'])
            if 1 <= v <= 999:
                n = v
        except Exception:
            pass
    fb = project_capped(parent, n) if parent is not None else None
    if fb is None:
        fb = np.full(n, 0.5)
    try:
        rng = np.random.default_rng(int(seed))
    except Exception:
        rng = np.random.default_rng(42)
    if n == 1:
        return fb, exact_score(fb, n), 1
    if n <= 64:
        n_iter, n_starts, n_restart = 80, 7, 3
    elif n <= 128:
        n_iter, n_starts, n_restart = 45, 4, 2
    elif n <= 256:
        n_iter, n_starts, n_restart = 25, 3, 1
    elif n <= 512:
        n_iter, n_starts, n_restart = 12, 2, 1
    else:
        n_iter, n_starts, n_restart = 6, 2, 0
    K, Delta0 = 12, 0.25
    fb_score = exact_score(fb, n)
    gb, gs = fb.copy(), fb_score
    starts = build_starts(fb, n, rng, n_starts)
    for st in starts:
        s = exact_score(st, n)
        if s < gs - 1e-12:
            gs, gb = s, st.copy()
        try:
            bh, bf = local_search(st, n, n_iter, Delta0, K)
            if bf < gs - 1e-12:
                gs, gb = bf, bh.copy()
        except Exception:
            continue
    if gs < fb_score - 1e-5:
        perts = [0.04, 0.10, 0.18] if n <= 256 else [0.08]
    else:
        perts = [0.12, 0.22, 0.08] if n <= 64 else ([0.10, 0.18] if n <= 256 else [0.08])
    for i in range(min(n_restart, len(perts))):
        try:
            pert = project_capped(gb + rng.normal(0, perts[i], n), n)
            if pert is None:
                continue
            bh, bf = local_search(pert, n, n_iter, Delta0, K)
            if bf < gs - 1e-12:
                gs, gb = bf, bh.copy()
        except Exception:
            continue
    final = project_capped(gb, n)
    if final is None or not is_feasible(final, n):
        final = fb
    sf = exact_score(final, n)
    if sf > fb_score:
        final, sf = fb, fb_score
    if not is_feasible(final, n):
        final = np.full(n, 0.5)
        sf = exact_score(final, n)
    return final, float(sf), int(n)
