Hmm, I see the issue. The lag values are quadratic in h, not linear. The linearization is:

q_d(x) = dx * Σ x[p+j]*(1-x[q+j])

At point x0:
q_d ≈ q_d(x0) + Σ_j [dx*(1-x0[q+j])*Δx[p+j] + (-dx*x0[p+j])*Δx[q+j]]

So the gradient of q_d with respect to x at x0 is:
For position p+j: dx*(1-x0[q+j])
For position q+j: -dx*x0[p+j]

But when p+j == q+j (which happens when p==q, i.e., d=0), the combined gradient is:
dx*(1-x0[p+j]) + (-dx*x0[p+j]) = dx*(1-2*x0[p+j])

So the linearization matrix G depends on the current point x0. This is what the previous code does.
