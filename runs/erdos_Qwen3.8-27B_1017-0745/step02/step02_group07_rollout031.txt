Let me be careful about the constraint structure for SLSQP:
- Decision variable: z = (h_0, ..., h_{n-1}, t), length n+1
- Objective: minimize t → gradient is [0,...,0,1]
- Inequality: t - Q_j(h) >= 0 for j=0,...,2n-2 → vector of length 2n-1
  - Jacobian row j: [-grad Q_j, 1]
- Equality: sum(h) - n/2 = 0
  - Jacobian: [1,...,1,0]
- Bounds: 0 <= h_i <= 1, 0 <= t <= 2

For the gradient of Q_j:
- dx = 2/n
- A_0 = sum h_i(1-h_i), grad_i = 1-2h_i, so grad Q_0 = dx*(1-2h)
- A_{r,+} = sum_{i=0}^{m-1} h_i(1-h_{i+r}), m=n-r
  - d/dh_i = 1-h_{i+r} for i < m (from h_i factor)
  - d/dh_{i+r} = -h_i for i < m (from (1-h_{i+r}) factor)
  - So entries [0:m) += (1-h[r:n]) and entries [r:n) += -h[0:m]
- A_{r,-} = sum_{i=0}^{m-1} h_{i+r}(1-h_i)
  - d/dh_{i+r} = 1-h_i for i < m
  - d/dh_i = -h_{i+r} for i < m
  - So entries [0:m) += -h[r:n] and entries [r:n) += (1-h[0:m])

Wait, let me re-check. For A_{r,-} = sum_{i=0}^{m-1} h_{i+r}(1-h_i):
- Derivative w.r.t. h_k:
  - If k appears as h_{i+r} (i.e., k = i+r, so i = k-r, valid when 0 <= k-r < m, i.e., r <= k < r+m = n): contributes 1-h_{k-r}
  - If k appears as h_i (i.e., k = i, valid when 0 <= k < m): contributes -h_{k+r}

- For k in [0, m): contributes -h[k+r] (from being h_i in the product)
- For k in [r, n): contributes 1-h[k-r] (from being h_{i+r} in the product)

These overlap for k in [r, m) when r < m, i.e., r < n-r, i.e., r < n/2.

So the gradient vector for A_{r,-}:
- entries [0:m) -= h[r:n]  (this is h[r], h[r+1], ..., h[n-1], length m = n-r)

            best_h = h0.copy()
        if n <= 128:
            t0 = s0 + 1e-8
            z0 = np.concatenate([h0, [t0]])
            try:
                res = minimize(slsqp_obj, z0, args=(n,), jac=slsqp_obj_jac,
                               method='SLSQP',
                               constraints=[
                                   {'type': 'ineq', 'fun': slsqp_ineq, 'jac': slsqp_ineq_jac},
                                   {'type': 'eq', 'fun': slsqp_eq, 'jac': slsqp_eq_jac}],
                               bounds=[(0.0, 1.0)] * n + [(0.0, 2.0)],
                               options={'ftol': 1e-10, 'maxiter': mx_it, 'disp': False})
                if hasattr(res, 'x') and res.x.size == n + 1 and np.all(np.isfinite(res.x)):
                    for a in [1.0, 0.75, 0.5, 0.25]:
                        cand = project_capped(h0 + a * (res.x[:n] - h0), n)
                        if cand is not None:
                            sc = exact_score(cand, n)
                            if sc < best_s - 1e-12:
                                best_s = sc
                                best_h = cand.copy()
            except Exception:
                pass
    if n <= 128:
        h_r, s_r = smooth_refine(best_h, n, nr_it)
        if s_r < best_s - 1e-12:
            best_s = s_r
            best_h = h_r
        for h0 in starts[:3]:
            h_r, s_r = smooth_refine(h0, n, nr_it)
            if s_r < best_s - 1e-12:
                best_s = s_r
                best_h = h_r
    else:
        for h0 in starts:
            h_r, s_r = smooth_refine(h0, n, nr_it)
            if s_r < best_s - 1e-12:
                best_s = s_r
                best_h = h_r
    final = project_capped(best_h, n)
    if final is None or not is_feasible(final, n):
        final = fb.copy()
    final_s = exact_score(final, n)
    if not np.isfinite(final_s):
        final = fb.copy()
        final_s = fb_s
    return final.astype(np.float64), float(final_s), int(n)
