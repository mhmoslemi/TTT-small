Let me verify the correlation formula:
`np.correlate(a, b, mode='full')` gives:
out[k] = sum_i a[i+k] * b[i] for valid i

So for `np.correlate(h, 1-h, mode='full')`:
out[k] = sum_i h[i+k] * (1-h[i]) for valid i

This means lag d = k - (n-1) in the standard sense where:
- d = 0: out[n-1] = sum_i h[i] * (1-h[i])
- d > 0: out[n-1+d] = sum_i h[i+d] * (1-h[i]) for i = 0..n-1-d
- d < 0: out[n-1+d] = sum_i h[i+d] * (1-h[i]) for i = -d..n-1

Let me verify: for d >= 0, p = d, r = 0, m = n - d
out[n-1+d][k] = sum_{s=0}^{m-1} h[d+s] * (1-h[s])

For d < 0, p = 0, r = -d, m = n + d = n - |d|
out[n-1+d] = sum_{s=0}^{m-1} h[s] * (1-h[-d+s])

Gradient of q_d = dx * sum_s h[p+s] * (1-h[r+s]):
- wrt h[p+s]: dx * (1 - h[r+s])
- wrt h[r+s]: -dx * h[p+s]

For d=0: p=0, r=0, so both contributions hit the same h[s]:
grad = dx * (1-h[s]) - dx * h[s] = dx * (1 - 2*h[s])

That's correct.

grad S_tau = sum_d w_d * grad_q_d

This is the softmax-weighted average of lag gradients.

    return True

def project_capped(z, n):
    if z.shape != (n,):
        return None

    if not np.all(np.isfinite(z)):
        return None

    lo = np.min(z) - 1.0
    hi = np.max(z) + 1.0
    for _ in range(80):
        mid = 0.5 * (lo + hi)
        if np.sum(np.clip(z - mid, 0.0, 1.0)) > s:
            lo = mid
        else:
            hi = mid
    h = np.clip(z - 0.5 * (lo + hi), 0.0, 1.0)
    r = s - np.sum(h)
    for _ in range(2):

                break
