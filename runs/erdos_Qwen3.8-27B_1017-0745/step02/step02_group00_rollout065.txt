Now, for the algorithm:

For each pair (i,j), r=j-i:
1. Compute L = max(-h[i], h[j]-1), U = min(1-h[i], h[j])
2. If U-L < epsilon, skip
3. For each lag d, compute:
   - a[d] = q[d] (current value)
   - b[d] = dx * [(1-h[i+d]) if valid - h[i]*v[i+d] - (1-h[j+d]) if valid - h[j]*v[j+d]]
   - c[d] = as computed above (nonzero only at d=0, ±r)
4. The objective is max_d (a[d] + b[d]*t + c[d]*t²)
5. Find min over t in [L,U]

For step 5, the key insight is that only 3 lags (d=0, r, -r) have c≠0. All others are linear.

Strategy for finding the minimum:
- Build the upper envelope of the linear parts (for the 2n-4 linear lags)
- On each segment of the envelope, the objective is max of (envelope line, q_0(t), q_r(t), q_{-r}(t))
- Find candidates: endpoints, stationary points of the 3 quadratics, crossings

def build_hull(a_arr, b_arr, L, U):
    """
    Build upper envelope of lines a_i + b_i*t.
    a_arr, b_arr: arrays of intercepts and slopes.
    Returns list of (a, b, t_start, t_end) for segments in [L, U].
    """
    n_lines = len(a_arr)
    if n_lines == 0:
        return []
    # Sort by slope, for same slope keep max intercept
    order = np.argsort(b_arr, kind='stable')
    # Group by slope, keep max intercept
    slopes = []
    intercepts = []

    while i < n_lines:
        s = b_arr[order[i]]
        max_a = a_arr[order[i]]
        j = i + 1
