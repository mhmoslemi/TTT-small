def project_capped(z, n):

    s = n / 2.0
    lo, hi = np.min(z) - 1.0, np.max(z) + 1.0
    for _ in range(80):

        if np.sum(np.clip(z - mid, 0.0, 1.0)) > s:
            lo = mid
        else:
            hi = mid
    h = np.clip(z - 0.5 * (lo + hi), 0.0, 1.0)
    r = s - np.sum(h)

        return float('inf')
    c = np.correlate(h, 1.0 - h, mode='full') * (2.0 / n)
    return float(np.max(c)) if np.all(np.isfinite(c)) else float('inf')

def smooth_grad(h, n, tau):
    dx = 2.0 / n
    r = np.correlate(h, 1.0 - h, mode='full') * dx
    rmax = np.max(r)

    w = exps / np.sum(exps)
    fval = rmax + tau * np.log(np.sum(exps))
    g = np.zeros(n)

        g[p:p+m] += dx * wd * (1.0 - h[q:q+m])
        g[q:q+m] -= dx * wd * h[p:p+m]
    return fval, g

Actually, one more thought: I should consider whether the log-sum-exp approach is the right one for this problem. The objective is max_d r_d, which is a piecewise-linear (actually piecewise-bilinear) function. The log-sum-exp smooths this into a differentiable function.

The key insight is that at the optimum, multiple lags might be active (have the same maximum value). The log-sum-exp naturally handles this by weighting all active lags. As τ → 0, the weight concentrates on the single maximum lag, which is the exact objective.

The continuation (decreasing τ) helps because:
1. At large τ, the objective is smooth and the gradient points in a direction that reduces all lags somewhat.
2. At small τ, the objective focuses on the maximum lag, and the gradient points in a direction that specifically reduces the maximum.
3. This gradual focusing helps avoid getting stuck in local minima of the piecewise-bilinear function.

This is a well-known technique in optimization (log-barrier, smooth max, etc.). I'm confident it will help.
