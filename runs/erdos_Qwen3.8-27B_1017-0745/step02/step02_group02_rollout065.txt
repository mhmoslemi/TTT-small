For lag s (from -(n-1) to n-1):
- p = max(s, 0), r = max(-s, 0), m = n - |s|
- q_s = dx * sum_{j=0}^{m-1} h[p+j] * (1 - h[r+j])

The derivative:
- d q_s / d h[p+j] = dx * (1 - h[r+j])
- d q_s / d h[r+j] = -dx * h[p+j]

When p+j == r+j (i.e., when s=0, so p=r=0), both terms apply:
- d q_0 / d h[j] = dx * (1 - h[j]) + (-dx * h[j]) = dx * (1 - 2*h[j])

This is correct.

For the correlation array: np.correlate(h, 1-h, mode='full') gives 2n-1 values.

Index k in the full correlation corresponds to lag s = k - (n-1).

The weight for each lag in log-sum-exp is w_k = exp((q_k - qmax) / tau) / sum(exp((q_k' - qmax)/tau))

Gradient = sum_k w_k * grad(q_k)

For the direct gradient computation:
- For each k from 0 to 2n-2:
