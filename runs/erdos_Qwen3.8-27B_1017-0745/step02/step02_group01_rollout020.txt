Let me analyze the problem and strategy carefully.

The problem is to find a step function h: [0, 2] → [0, 1] that minimizes the maximum overlap integral C₅ = max_k ∫ h(x)(1-h(x+k)) dx.

Key constraints:
- h(x) ∈ [0, 1]
- ∫₀² h(x) dx = 1
- Discretized as n_points samples with dx = 2/n_points
- sum(h) * dx = 1, so sum(h) = n_points / 2

The previous program achieved C₅ = 0.380992, and the target is 0.3808 (lower is better). Current record is C₅ ≤ 0.38085.

The strategy suggests using a sequential linear-programming trust-region search. At each iteration:
1. Compute exact correlation and gradients
2. Form LP: minimize t subject to q_d + g_d^T u <= t, sum(u) = 0, box+trust bounds
3. Solve with HiGHS
4. Try fractional steps, accept only exact improvements
5. Adjust trust radius based on model agreement

            best_h, best_score = refine_chain(starts[i], n, iters, 0.08, best_h, best_score)
        except Exception:
            pass
    try:
        best_h, best_score = refine_chain(best_h, n, max(5, iters // 2), 0.03, best_h, best_score)
    except Exception:
        pass
    final = project_capped(best_h, n)
    if final is None or not is_feasible(final, n):
        final = fallback
    fs = exact_score(final, n)
    fb_s = exact_score(fallback, n)
    if fs > fb_s + 1e-12:
        final, fs = fallback, fb_s
    return final, float(fs), int(n)
