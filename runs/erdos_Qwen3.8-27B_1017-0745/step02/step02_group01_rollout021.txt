- Minimize: t
- Subject to: q_d + g_d^T u <= t for all d (i.e., g_d^T u - t <= -q_d)

The matrix A has shape (2n-1, n+1):
- First n columns: gradient of q_d with respect to h[i]
- Last column: -1 (for the -t term)

The constraint is A @ [u; t] <= -q

dq_d/dh[i] for i in [r, r+m): -dx * h[p+s] where s = i-r

At d=0, p=r=0, m=n, so both contributions apply to the same indices.
