Let me double-check the gradient formula. For lag t:
q_t = sum_i h[i+t] * (1-h[i]) for valid i (0≤i<n and 0≤i+t<n)

∂q_t/∂h_j:
- Term from h[i+t] when i+t = j, i.e., i = j-t: contribution (1-h[i]) = (1-h[j-t]) if 0≤j-t<n
- Term from (1-h[i]) when i = j: contribution -h[i+t] = -h[j+t] if 0≤j+t<n

So ∂q_t/∂h_j = 1[0≤j-t<n](1-h[j-t]) - 1[0≤j+t<n] h[j+t]

In my code:
For t >= 0:
- g[t:] += pk*(1 - h[:nt]) where nt = n-t
  - g[j] gets (1-h[j-t]) for j in [t, n-1], and j-t in [0, n-t-1] ✓
- g[:nt] -= pk*h[t:]
  - g[j] gets -h[j+t] for j in [0, nt-1], and j+t in [t, n-1] ✓

For t < 0, u = -t:
- g[:nu] += pk*(1 - h[u:]) where nu = n-u
