The capped simplex projection: minimize 0.5*||h-v||^2 subject to 0<=h[i]<=1, sum(h)=S where S=n/2.

KKT: h[i] = clip(v[i] - lambda, 0, 1)

At lambda < min(v): all h[i] = 1, sum = n
At lambda > max(v): all h[i] = 0, sum = 0

So we need lambda such that sum(clip(v[i]-lambda, 0, 1)) = S.

As lambda increases, sum decreases. So:
- If lambda = min(v) - 1: all v[i] - lambda >= 1, so h[i] = 1, sum = n > S
- If lambda = max(v) + 1: all v[i] - lambda <= 0, so h[i] = 0, sum = 0 < S

So lo = min(v) - 1 gives sum > S, hi = max(v) + 1 gives sum < S.

We want sum = S. As lambda increases, sum decreases.
- If sum(h) > S at midpoint: need larger lambda, so lo = mid
- If sum(h) < S at midpoint: need smaller lambda, so hi = mid
