Mathematical specification\nLet N be the number of samples, h in R^N, Δx = 2/N, and m = N/2. The feasible set is 0 ≤ h_i ≤ 1 for every i and Σ_i h_i = m. The score to minimize is F(h) = Δx times the maximum of the 2N−1 full-correlation entries.\n\nFor k from −(N−1) through N−1, NumPy’s full linear correlation has entry c_k = Σ_j h_{j+k}(1−h_j), where the sum is only over indices satisfying 0 ≤ j < N and 0 ≤ j+k < N. Equivalently define, for s from −(N−1) through N−1, I_s = {i : 0 ≤ i < N and 0 ≤ i+s < N}, and q_s(h) = Σ_{i in I_s} h_i(1−h_{i+s}). Reindexing gives c_k = q_{−k}, so max_k c_k = max_s q_s. This identity preserves the truncated overlap at every boundary; do not use circular correlation or replace the objective by 1 minus an autocorrelation expression.\n\nFor each s and component r, the exact derivative is ∂q_s/∂h_r = Σ_{i in I_s} [1_{r=i}(1−h_{i+s}) − 1_{r=i+s}h_i]. In particular, at s=0 the derivative for component r is 1−2h_r. The optimization epigraph has decision vector (h,t), minimizes t, and imposes t−q_s(h) ≥ 0 for every s, Σ_i h_i−m = 0, 0 ≤ h_i ≤ 1, and 0 ≤ t ≤ N. Since Δx is a positive constant, minimizing raw t has the same minimizers as minimizing Δx t. Each q_s is bilinear or quadratic, so the nonlinear feasible set is not generally convex; use SLSQP only as a local constrained optimizer. Its returned t is not the reported score.\n\nFor joint feasibility restoration, project any finite vector z onto the capped simplex by solving Σ_i clip(z_i−θ,0,1) = m and setting h_i = clip(z_i−θ,0,1). This is the Euclidean projection from the KKT conditions for minimizing one-half times the squared distance to z subject to the box and sum constraints. The left side is monotone in θ, so bisection gives a deterministic solution. Correct only the final floating-point residual by distributing it among coordinates with available room; do not clip and then independently rescale, since that does not in general preserve both constraints.\n\n3.
