For lag k (from -(n-1) to n-1):
q_k(h) = dx * sum_{r in I_k} h[r] * (1 - h[r-k])

where I_k = {r: max(0,k) ≤ r ≤ min(n-1, n-1+k)}

The gradient w.r.t. h[j]:
- If j ∈ I_k: term h[j]*(1-h[j-k]) contributes (1-h[j-k]) * dx
- If j+k ∈ I_k: term h[j+k]*(1-h[j]) contributes -h[j+k] * dx

So g_k[j] = dx * [1_{j∈I_k} * (1-h[j-k]) - 1_{j+k∈I_k} * h[j+k]]

In numpy indexing with row = k + (n-1):

- For j in [lo, hi): g[j] += dx * (1 - h[j-k])

Now for the dual problem:
D(p) = p·q + min_{h+d ∈ P} [p·G·d + (L/2)||d||²]
     = p·q + min_{y ∈ P} [p·G·(y-h) + (L/2)||y-h||²]

The minimizer y* satisfies: y* = argmin_{y∈P} (L/2)||y - h + (G^T p)/L||² = Pi_P(h - G^T p / L)

So d* = Pi_P(h - G^T p / L) - h

And grad D(p) = q + G * d*

The dual is to maximize D(p) over the simplex. Since D is concave (min of affine functions in p is concave, and we're adding p·q which is linear, so D is concave), we can use projected gradient ascent.

Wait, let me re-derive. 

D(p) = p·q + min_{y∈P} [p·G·(y-h) + (L/2)||y-h||²]

The inner min is concave in p (it's the min of affine functions). Adding p·q (linear) keeps it concave. So D is concave in p. We want to maximize D over the simplex.

The gradient of the inner min w.r.t. p: by Danskin's theorem, at the minimizer y*, the gradient is G·(y*-h) = G·d*. So grad D(p) = q + G·d*.

For projected gradient ascent on the simplex:
p_{new} = Pi_Δ(p + grad_D / L_dual)

where L_dual is a Lipschitz constant for grad_D.

The gradient grad_D(p) = q + G·d*, where d* = Pi_P(h - G^T p / L) - h.

The Lipschitz constant: |d*(p1) - d*(p2)| ≤ |G^T(p1-p2)|/L (by non-expansiveness of projection)
So |grad_D(p1) - grad_D(p2)| ≤ ||G|| · |G^T(p1-p2)|/L ≤ ||G||² / L · |p1-p2|

Actually, more carefully: |G·(d*(p1)-d*(p2))| ≤ ||G||·|d*(p1)-d*(p2)| ≤ ||G||·|G^T(p1-p2)|/L ≤ ||G||_F·|G^T(p1-p2)|/L ≤ ||G||_F·||G||_F/|p1-p2|... 

Actually, |G^T(p1-p2)| ≤ ||G|| · |p1-p2| where ||G|| is the spectral norm. And ||G|| ≤ ||G||_F. So:
|grad_D(p1) - grad_D(p2)| ≤ ||G|| · ||G|| / L · |p1-p2| ≤ ||G||_F² / L · |p1-p2|

So L_dual = 1.05 * ||G||_F² / L = 1.05 * sum(G²) / L.

For the accelerated (Nesterov) version:
- Maintain x_k, y_k
- x_{k+1} = Pi_Δ(y_k + grad_D(y_k) / L_dual)
- y_{k+1} = x_{k+1} + ((θ_k - 1)/θ_{k+1}) * (x_{k+1} - x_k)
- θ_{k+1} = (1 + sqrt(1 + 4θ_k²)) / 2

With restart: if D(x_{k+1}) < D(x_k), reset y = x_{k+1}, θ = 1.

Now let me think about the line search in the outer loop.

Given d (the displacement from the dual solve), we form:
M(α) = max(q + α*G·d) + (L/2)*α²*||d||²

This is an upper bound on C(h + α*d) for α ∈ [0,1]. We want to find the largest α where M(α) < C(h), forming a trial h' = h + α*d, projecting, and checking exact score.

Actually, since we're doing exact scoring anyway, the model M(α) is just a guide for which α values to try. We try α = 1, 1/2, 1/4, ..., and accept the first one where the exact score improves.

def solve_majorant(h, q, G, n, max_inner):
    L = 4.0 / n
    Ldual = max(1e-12, 1.05 * np.sum(G * G) / L)
    m = 2 * n - 1
    qmax = float(np.max(q))
    thresh = max(1e-12, 1e-8 * max(1.0, abs(qmax)))
    active = q >= qmax - thresh
    if active.sum() == 0:
        active[np.argmax(q)] = True
    p = np.zeros(m)
    p[active] = 1.0 / active.sum()
    x = p.copy()
    y = p.copy()
    theta = 1.0
    best_d = np.zeros(n)
    prev_step = 0
    stall = 0
    for it in range(max_inner):
        # compute gradient at project_simplex(y)
        py = project_simplex(y)
        gmix = G.T @ py
        yy, ok = project_capped(h - gmix / L, n)
        if not ok:
            break
        d_y = yy - h
        u_y = q + G @ d_y
        grad_y = u_y
        # trial step
        x_trial = project_simplex(y + grad_y / Ldual)
        # evaluate D at x_trial
        gmix_t = G.T @ x_trial
        yt, ok_t = project_capped(h - gmix_t / L, n)
        if not ok_t:
            break
        d_t = yt - h
        u_t = q + G @ d_t
        D_t = float(x_trial @ u_t + 0.5 * L * d_t @ d_t)
        D_curr = float(py @ u_y + 0.5 * L * d_y @ d_y)
        
        step = np.max(np.abs(x_trial - x))
        
        if D_t < D_curr - 1e-12:
            # restart
            x = x_trial
            y = x_trial
            theta = 1.0
        else:
            theta_new = (1.0 + np.sqrt(1.0 + 4.0 * theta * theta)) / 2.0
            y = x_trial + ((theta - 1.0) / theta_new) * (x_trial - x)
            x = x_trial
            theta = theta_new
        
        # convergence check at x
        gmix_x = G.T @ x
        yx, ok_x = project_capped(h - gmix_x / L, n)
        if ok_x:
            d_x = yx - h
            u_x = q + G @ d_x
            gap = float(np.max(u_x) - x @ u_x)
            best_d = d_x
            gap_tol = max(1e-10, 1e-8 * max(1.0, abs(float(np.max(u_x)))))
            if gap < gap_tol:
                break
            if step < 1e-12:
                stall += 1
                if stall >= 3:
                    break
            else:
                stall = 0
    
    # final
    gmix = G.T @ x
    yy, ok = project_capped(h - gmix / L, n)
    if ok:
        best_d = yy - h
    return best_d

def optimize_start(h0, n, max_outer, max_inner):
    h, ok = project_capped(h0.copy(), n)
    if not ok:
        h = np.full(n, 0.5)
    s = exact_score(h, n)
    best_h = h.copy()
    best_s = s
    L = 4.0 / n
    for outer in range(max_outer):
        q = lag_scores(h, n)
        G = build_G(h, n)
        if not np.all(np.isfinite(G)):
            break
        d = solve_majorant(h, q, G, n, max_inner)
        if not np.all(np.isfinite(d)) or np.max(np.abs(d)) < 1e-12:
            break
        # line search
        v = G @ d
        norm2 = d @ d
        qmax = float(np.max(q))
        improved = False
        for alpha in [1.0 / (2**j) for j in range(20)]:
            M = float(np.max(q + alpha * v) + 0.5 * L * alpha * alpha * norm2)
            if M >= qmax - 1e-14:
                continue
            h_trial = h + alpha * d
            h_tr, ok_tr = project_capped(h_trial, n)
            if not ok_tr:
                continue
            s_tr = exact_score(h_tr, n)
            if s_tr < s - 1e-12:
                h = h_tr
                s = s_tr
                if s < best_s:
                    best_s = s
                    best_h = h.copy()
                improved = True
                break
        if not improved:
            break
    return best_h, best_s

        rng = np.random.default_rng(seed)
    except Exception:
        rng = np.random.default_rng(42)

def check_feasible(h, n):
    return (h.shape == (n,) and np.all(np.isfinite(h))
            and np.all(h >= -1e-12) and np.all(h <= 1.0 + 1e-12)
            and abs(h.sum() - n / 2.0) <= 1e-10)

def lag_scores(h, n):
    dx = 2.0 / n
    return np.correlate(h, 1.0 - h, mode='full') * dx

def exact_score(h, n):
    if not check_feasible(h, n):
        return float('inf')
    return float(np.max(lag_scores(h, n)))

def build_G(h, n):
    dx = 2.0 / n
    G = np.zeros((2 * n - 1, n))
    for k in range(-(n - 1), n):
        row = k + n - 1
        lo1 = max(0, k)
        hi1 = min(n, n + k)
        if hi1 > lo1:
            G[row, lo1:hi1] += dx * (1.0 - h[lo1 - k:hi1 - k])
        lo2 = max(0, -k)
        hi2 = min(n, n - k)
        if hi2 > lo2:
            G[row, lo2:hi2] -= dx * h[lo2 + k:hi2 + k]
    return G

def project_simplex(z):
    nz = len(z)
    if not np.all(np.isfinite(z)):
        return np.full(nz, 1.0 / nz)
    zs = np.sort(z)[::-1]
    cs = np.cumsum(zs)
    rho = np.arange(1, nz + 1, dtype=np.float64)
    cond = zs - (cs - 1.0) / rho > 0
    if not cond.any():
        return np.full(nz, 1.0 / nz)
    rs = int(np.max(np.where(cond)[0])) + 1
    theta = (cs[rs - 1] - 1.0) / float(rs)
    p = np.maximum(z - theta, 0.0)
    s = p.sum()
    if s > 1e-15:
        p /= s
    else:
        p[:] = 1.0 / nz
    return p

    return d, u, D
