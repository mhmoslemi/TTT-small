Let me think about the LP construction carefully:

For n variables v[0..n-1], P = n*(n+1)/2 product variables z[i,j] for i<=j, and 1 variable t.
Total variables: n + P + 1

Product index for (i,j) where i<=j: i*n - i*(i-1)//2 + (j-i)

McCormick envelopes for z[i,j] = v[i]*v[j] in box [l_i, u_i] x [l_j, u_j]:
- z >= l_i*v_j + l_j*v_i - l_i*l_j
- z >= u_i*v_j + u_j*v_i - u_i*u_j
- z <= u_i*v_j + l_j*v_i - u_i*l_j
- z <= l_i*v_j + u_j*v_i - l_i*u_j

For each lag k (from -(n-1) to n-1):
Q_k = sum_{i in I_k} v[i] - z[min(i,j), max(i,j)] where j = i-k
Constraint: Q_k <= t, i.e., sum v[i] - z[...] - t <= 0

Equality: sum(v) = S

Objective: minimize t

Let me think about the line minimax more carefully:

h(a) = x + a*d, a in [0,1]
Q_k(h(a)) = sum_{i in I_k} h[a][i] * (1 - h[a][j])
= sum (x_i + a*d_i) * (1 - x_j - a*d_j)
= sum [x_i(1-x_j) + a*d_i(1-x_j) - a*x_i*d_j - a^2*d_i*d_j]
= D_k + a*B_k + a^2*A_k

where:
A_k = -sum_{i in I_k} d_i * d_j
B_k = sum_{i in I_k} [d_i*(1-x_j) - x_i*d_j]
D_k = sum_{i in I_k} x_i * (1-x_j)

We want to minimize max_k (A_k * a^2 + B_k * a + D_k) for a in [0,1].

The minimum of the upper envelope occurs at:
- Endpoints a=0, a=1
- Stationary points of individual quadratics: a = -B_k/(2*A_k) (if A_k != 0 and in [0,1])
- Intersections of pairs: (A_k - A_l)*a^2 + (B_k - B_l)*a + (D_k - D_l) = 0
