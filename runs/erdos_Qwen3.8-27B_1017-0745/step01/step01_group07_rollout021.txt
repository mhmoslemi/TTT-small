Key points:
1. Use DC-MM: decompose each lag's quadratic function into convex - convex, tangent approximation
2. Solve convex subproblem with CVXPY (conic solvers: ECOS, CVXOPT)
3. Start from `initial_h_values` (n=80) if available
4. Use exact scoring via `np.correlate(h, 1-h, mode='full') * (2.0/n)`
5. Keep all helpers top-level, no closures/lambdas
6. Return (h_values, c5_bound, n_points)

The DC decomposition for lag d:
- q_d(y) = dx * sum_{i in I_d} y[i] * (1 - y[i+d])
- Using -uv = ((u-v)^2 - (u+v)^2)/4:
  - A_d(y) = dx * sum [y[i] + (y[i]-y[i+d])^2/4]  (convex)
  - B_d(y) = dx/4 * sum (y[i]+y[i+d])^2  (convex)
  - q_d(y) = A_d(y) - B_d(y)
- Tangent to B_d at anchor a:
  - T_d(y;a) = dx/2 * sum (a[i]+a[j])*(y[i]+y[j]) - dx/4 * sum (a[i]+a[j])^2
- Majorizer: M_d(y;a) = A_d(y) - T_d(y;a) (convex, M_d >= q_d, M_d(a) = q_d(a))

The convex subproblem:
minimize t + eta/2 * ||y - a||^2
subject to M_d(y;a) <= t for all d
           0 <= y[i] <= 1
           sum(y) = S
           |y[i] - a[i]| <= rho

            except Exception:
                continue
        return None

        return None

    h_const = np.full(n, 0.5)
    best_h, best_score = h_const.copy(), exact_score(h_const, n)
    if best_score is None:
        best_score = 0.5
    pf, ps_c = None, None
    if parent is not None:
        ps_c = exact_score(parent, n)
        pf = parent.copy()
        if ps_c is not None and ps_c < best_score:
            best_score, best_h = ps_c, parent.copy()
    starts = build_starts(n, S, parent, rng)
    for s in starts:
        sc = exact_score(s, n)
        if sc is not None and sc < best_score - 1e-12:
            best_score, best_h = sc, s.copy()
    if n <= 256:
        for s in starts:
            best_h, best_score = optimize_dc(s, n, dx, S, best_h, best_score)
        if n <= 128:
            p2 = proj_simplex(best_h + 0.03 * rng.standard_normal(n), S)
            if p2 is not None and is_feasible(p2, n):
                best_h, best_score = optimize_dc(p2, n, dx, S, best_h, best_score)
    if not is_feasible(best_h, n):
        best_h = proj_simplex(best_h, S)
        if best_h is None:
            best_h = h_const.copy()
    fs = exact_score(best_h, n)
    if fs is None:
        best_h, fs = (pf, ps_c) if pf is not None and ps_c is not None else (h_const, 0.5)
    return best_h, fs, n
