∂Q_d/∂h_j:
- If j = a_d + r for some r: contribution is dx * (1 - h[b_d+r])
- If j = b_d + r for some r: contribution is -dx * h[a_d+r]
- Both can apply to the same index (when a_d+r = b_d+r', i.e., when the indices overlap)

So for index j:
- First term: find all r such that j = a_d + r, i.e., r = j - a_d. If 0 ≤ r < m_d, add dx*(1-h[b_d+r])
- Second term: find all r such that j = b_d + r, i.e., r = j - b_d. If 0 ≤ r < m_d, subtract dx*h[a_d+r]

This is what the vectorized slice operations do:
```
grad[a:a+m] += wi * dx * (1.0 - h[b:b+m])  # first contribution
grad[b:b+m] -= wi * dx * h[a:a+m]           # second contribution
```

When a=b (d=0), both apply to the same indices, giving grad[j] += wi*dx*(1-h[j]) - wi*dx*h[j] = wi*dx*(1-2h[j]), which is correct.

When a≠b, the slices may partially overlap. For example, if d>0, a=d, b=0, so grad[d:d+m] gets the first contribution and grad[0:m] gets the second. The overlap is indices [d, m) if d < m. For those indices, both contributions apply, which is correct since h[j] appears in both h[a+r] and h[b+r'] terms.

def project_capped(z, n):
    z = np.clip(np.asarray(z, dtype=np.float64), -1e12, 1e12)
    if z.shape != (n,):
        return None
    s = n / 2.0
    lo = float(np.min(z)) - 1.0
    hi = float(np.max(z)) + 1.0
    for _ in range(80):
        mid = 0.5 * (lo + hi)
        if np.sum(np.clip(z - mid, 0.0, 1.0)) > s:
            lo = mid
        else:
            hi = mid
    h = np.clip(z - 0.5 * (lo + hi), 0.0, 1.0)
    r = s - np.sum(h)
    for i in range(n):

            break
        if r > 0:
            h[i] = min(h[i] + r, 1.0)
        else:
            h[i] = max(h[i] + r, 0.0)
        r = s - np.sum(h)
