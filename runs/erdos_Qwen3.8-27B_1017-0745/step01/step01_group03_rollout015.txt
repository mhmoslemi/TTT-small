c[k] = sum_n a[n+k] * conj(v[n])

where the sum is over all n for which both a[n+k] and v[n] exist.

For a=h (length n), v=1-h (length n):
c[k] = sum_i h[i+k] * (1-h[i])

The result has length 2n-1, indexed as result[n-1+k] for k from -(n-1) to n-1.

So Q_k = result[n-1+k] = sum_i h[i+k] * (1-h[i]) for valid i.

dQ_k/dh_r:
- r appears in h[i+k] when i+k=r, i.e., i=r-k. Valid if 0≤r-k<n and 0≤i<n (same thing). Contribution: (1-h[r-k]).
- r appears in (1-h[i]) when i=r. Valid if 0≤r<n (always true). Contribution: -h[r+k] if 0≤r+k<n.

So dQ_k/dh_r = (1-h[r-k]) * 1_{0≤r-k<n} - h[r+k] * 1_{0≤r+k<n}
