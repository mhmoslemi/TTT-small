At each feasible vector, compute the exact finite-support lag values and their analytic gradients, then solve one linear program that chooses a simultaneous change to all n coordinates and minimizes the maximum of the linearized lag values. Test the resulting direction at several feasible step lengths using the exact evaluator objective; accept only an exact improvement. Shrink or expand the trust region using the agreement between predicted and actual improvement. Keep the best exact-scored vector throughout.\n\nThis is materially different from smooth log-sum-exp projected-gradient search and pair-transfer annealing: the main update is an all-coordinate sparse LP, not a smooth-gradient step or a stochastic sequence of two-coordinate moves. It is also different from applying a nonlinear epigraph solver to the original bilinear problem: each solver call here is a genuine LP for a local first-order model. The exact lag formula, its gradient, the LP constraints, and the feasibility projection are mathematical facts. Trust-region acceptance and several algorithmically generated starts are heuristics that may improve on the supplied construction, but they do not guarantee an improvement, the target bound, or global optimality. Mathematical specification\nFor the runtime length n, let h be a real vector of shape (n,), dx=2/n, and S=n/2. The feasible set is 0<=h[i]<=1 and sum_i h[i]=S, so dx*sum_i h[i]=1. Minimize the exact finite-support objective\n\nC5(h) = dx * max(np.correlate(h, 1-h, mode='full')).\n\nFor explicit lag indexing, let d range over -(n-1),...,n-1 and let I_d contain indices i with 0<=i<n and 0<=i+d<n. Define\n\nq_d(h) = dx * sum over i in I_d of h[i]*(1-h[i+d]).\n\nThe q_d values are exactly the evaluator's 2n-1 scaled correlation values in reverse order. Reversing them does not change their maximum. Use only indices in I_d: these are linear finite-support lags, not circular lags, and nonzero lags do not generally cover the full mass of h.\n\nThe exact derivative is\n\nG_d[j] = partial q_d / partial h[j]\n       = dx * ( 1[j in I_d]*(1-h[j+d]) - 1[j-d in I_d]*h[j-d] ),\n\nwhere a term is omitted if its indicated index is outside the valid overlap. For d=0 both terms apply, giving dx*(1-2*h[j]). For a change delta, the exact expansion is\n\nq_d(h+delta) = q_d(h) + G_d dot delta - dx*sum over i in I_d of delta[i]*delta[i+d].\n\nThus q_d(h)+G_d dot delta is a local linear model, not a guaranteed upper or lower bound. If max_i |delta[i]|<=rho, the absolute remainder for any lag is at most dx*n*rho^2=2*rho^2. This motivates a trust region, while exact scoring and acceptance handle the remaining nonlinear error.\n\nAt each LP step introduce delta in R^n, u in R^n, and a scalar t. For a current feasible x and trust radius rho, solve\n\nminimize t + mu*sum_i u[i]\nsubject to q_d(x) + G_d dot delta <= t for every d,\n           delta[i] <= u[i], -delta[i] <= u[i], u[i]>=0,\n           sum_i delta[i]=0,\n           max(-rho,-x[i]) <= delta[i] <= min(rho,1-x[i]),\n           t unrestricted,\n\nwith default mu=0.002*dx. This is a linear program: the lag epigraph constraints, absolute-value constraints, equality, and bounds are all explicit. Its feasible set contains delta=0, u=0, t=max_d q_d(x). The LP solves only the local model; the exact nonconvex problem is judged by the original objective.\n\nFor a finite vector z, the Euclidean projection onto the box-and-mass set is x[i]=clip(z[i]-lambda,0,1), with lambda chosen so sum_i clip(z[i]-lambda,0,1)=S. This follows from the KKT conditions for projection onto one sum equality and box bounds. The mass is monotone in lambda, so bisection followed by a bounded residual correction jointly enforces bounds and mass. Clipping and then rescaling is not an acceptable substitute.\n\n3.
