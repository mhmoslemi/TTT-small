Let me also think about whether I should use a gradient-based method. The smooth log-sum-exp approach with L-BFGS-B could be very effective. Let me add that as an option.

For the gradient of the smooth objective:
g(h) = (1/alpha) * log(sum_k exp(alpha * c_k * dx))

where c_k is the k-th element of the correlation.

∂g/∂h[j] = sum_k w_k * dx * ∂c_k/∂h[j]

where w_k = exp(alpha * c_k * dx) / sum_m exp(alpha * c_m * dx)

And ∂c_k/∂h[j] = (1-h[j-lag_k]) * 1[valid] - h[j+lag_k] * 1[valid]

where lag_k = k - (n-1) for the k-th element of the full correlation.

Let me implement this:

```python
def smooth_c5_with_grad(h, dx, alpha=100.0):
    n = len(h)
    corr = np.correlate(h, 1.0 - h, mode="full") * dx
    m = np.max(corr)
    vals = alpha * (corr - m)
    exp_vals = np.exp(vals)
    w = exp_vals / exp_vals.sum()
    val = m + np.log(exp_vals.sum()) / alpha
    
    # Compute gradient
    grad = np.zeros(n)
    for k in range(2 * n - 1):
        lag = k - (n - 1)
        wk_dx = w[k] * dx
        # ∂c_k/∂h[j] for each j
        for j in range(n):
            term = 0.0
            # (1-h[j-lag]) if 0 <= j-lag < n
            if 0 <= j - lag < n:
                # j is in the valid range for the first factor
                # Need j in S(lag): max(0,lag) <= j < n (since j < n always)
                # and 0 <= j-lag < n
                term += (1.0 - h[j - lag])
            # -h[j+lag] if 0 <= j+lag < n
            if 0 <= j + lag < n:
                term += -h[j + lag]
            grad[j] += wk_dx * term
    
    return val, grad
```

This is O(n * 2n) = O(n^2) per gradient evaluation, which is fine for n=45-180.

But wait, I need to verify my gradient formula. Let me double-check.

c[lag] = sum_{i in S(lag)} h[i] * (1 - h[i-lag])

where S(lag) = {i : 0 ≤ i < n AND 0 ≤ i-lag < n}

∂c[lag]/∂h[j] = sum_{i in S(lag)} [δ(i,j)(1-h[i-lag]) + h[i)(-δ(i-lag,j))]

= (1-h[j-lag]) if j ∈ S(lag) AND 0 ≤ j-lag < n  [first term, i=j]
  + (-h[j+lag]) if j+lag ∈ S(lag) AND 0 ≤ j < n  [second term, i-lag=j, so i=j+lag]

For the first term: j ∈ S(lag) means 0 ≤ j < n and 0 ≤ j-lag < n. Since 0 ≤ j < n is always true (j is an index), we need 0 ≤ j-lag < n.

For the second term: j+lag ∈ S(lag) means 0 ≤ j+lag < n and 0 ≤ (j+lag)-lag < n, i.e., 0 ≤ j+lag < n and 0 ≤ j < n. Again, 0 ≤ j < n is always true, so we need 0 ≤ j+lag < n.

So:
∂c[lag]/∂h[j] = (1-h[j-lag]) * [0 ≤ j-lag < n] - h[j+lag] * [0 ≤ j+lag < n]

This looks right. Let me verify with a small example.

n=3, h = [h0, h1, h2]
lag = 1: S(1) = {i : 0≤i<3, 0≤i-1<3} = {i : 1≤i≤2} = {1, 2}
c[1] = h[1]*(1-h[0]) + h[2]*(1-h[1])

∂c[1]/∂h[0] = (1-h[0-1]) * [0≤-1<3] - h[0+1] * [0≤1<3] = 0 - h[1] = -h[1]
Let me verify: c[1] = h[1] - h[1]*h[0] + h[2] - h[2]*h[1]
∂/∂h[0] = -h[1] ✓

∂c[1]/∂h[1] = (1-h[1-1]) * [0≤0<3] - h[1+1] * [0≤2<3] = (1-h[0]) - h[2]
Verify: ∂/∂h[1] of (h[1] - h[1]h[0] + h[2] - h[2]h[1]) = 1 - h[0] - h[2] ✓

∂c[1]/∂h[2] = (1-h[2-1]) * [0≤1<3] - h[2+1] * [0≤3<3] = (1-h[1]) - 0 = 1-h[1]
Verify: ∂/∂h[2] of (h[1] - h[1]h[0] + h[2] - h[2]h[1]) = 1 - h[1] ✓

Great, the formula is correct.

```python
def smooth_c5_grad(h, dx, alpha=100.0):
    n = len(h)
    corr_full = np.correlate(h, 1.0 - h, mode="full") * dx
    m = np.max(corr_full)
    vals = alpha * (corr_full - m)
    exp_vals = np.exp(vals)
    w = exp_vals / exp_vals.sum()
    val = m + np.log(exp_vals.sum()) / alpha
    
    grad = np.zeros(n)
    for k in range(2 * n - 1):
        lag = k - (n - 1)
        wk = w[k] * dx
        # First term: (1-h[j-lag]) for valid j
        # Valid j: 0 <= j-lag < n, i.e., lag <= j < n+lag
        # Combined with 0 <= j < n: max(0,lag) <= j < min(n, n+lag)
        j_start = max(0, lag)
        j_end = min(n, n + lag)
        if j_start < j_end:
            grad[j_start:j_end] += wk * (1.0 - h[j_start - lag:j_end - lag])
        # Second term: -h[j+lag] for valid j
        # Valid j: 0 <= j+lag < n, i.e., -lag <= j < n-lag
        # Combined with 0 <= j < n: max(0,-lag) <= j < min(n, n-lag)
        j_start2 = max(0, -lag)
        j_end2 = min(n, n - lag)
        if j_start2 < j_end2:
            grad[j_start2:j_end2] += wk * (-h[j_start2 + lag:j_end2 + lag])
    
    return val, grad
```

This is O(n * 2n) but with vectorized inner loop, so it should be fast.

    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)

def project_sum(h, target):
    x = np.clip(h.astype(float), 0.0, 1.0)
    s = x.sum()
    if abs(s - target) < 1e-14:
        return x
    lo, hi = -1.5, 1.5
    for _ in range(80):
        mid = (lo + hi) * 0.5
        if np.clip(x + mid, 0.0, 1.0).sum() < target:
            lo = mid
        else:
            hi = mid
    return np.clip(x + (lo + hi) * 0.5, 0.0, 1.0)

    h = project_sum(hf, target)
    return compute_c5(h, dx)

    n = len(h)
