One key insight: the objective max_k corr_k is piecewise bilinear. At the optimum, typically only a few lags are "active" (achieve the max). I can use an active set approach:

1. Start with a solution

3. Optimize a smoothed objective that emphasizes the active lags
4. Re-identify the active set
5. Iterate

But this is essentially what SLSQP does with the max objective.

Another thought: I can use a penalty/level method. Introduce t and minimize t + μ * sum of violations, where violations are corr_k - t > 0. This makes it smoother.

Actually, let me try a different angle. The problem is equivalent to:

minimize t
s.t. h * (1 - h_shifted) ≤ t/dx (elementwise, summed) for all shifts
     0 ≤ h ≤ 1
     sum(h) = n/2

This is like a robust optimization. For a fixed t, the feasibility problem is:
Does there exist h with 0≤h≤1, sum(h)=n/2, and for all shifts k: sum_i h[i]*(1-h[i_shifted_k]) ≤ t/dx?

The constraints are non-convex (bilinear), so this isn't directly solvable as a convex problem.

Let me try yet another approach: use a smooth approximation of the max with a geometric mean or log-sum-exp:

f(h) = (dx/τ) * log(sum_k exp(τ * corr_k / dx))

As τ → ∞, this approaches the max. For finite τ, it's smooth and differentiable.

The gradient:
∇f(h) = (1/τ) * sum_k (exp(τ*corr_k/dx) * τ/dx * ∇corr_k) / sum_j exp(τ*corr_j/dx)
       = (1/dx) * sum_k (w_k * ∇corr_k)

where w_k = exp(τ*corr_k/dx) / sum_j exp(τ*corr_j/dx) (softmax weights)

This is a convex combination of the individual gradients, which is nice.

Let me implement this:


This loop over all 2n-1 lags might be slow. Let me optimize: instead of looping over all lags, I can vectorize the gradient computation.

For a specific lag L ≥ 0:
- Contribution to grad[lag:] is (1-h[:n-lag])
- Contribution to grad[:n-lag] is -h[lag:]

For a specific lag -L (L > 0):
- Contribution to grad[L:] is (1-h[:n-L])
- Contribution to grad[:n-L] is -h[L:]

So for all positive lags L = 0, 1, ..., n-1 with weights w[n-1+L]:
grad[L:] += w[n-1+L] * (1-h[:n-L])
grad[:n-L] -= w[n-1+L] * h[L:]

For all negative lags -L with L = 1, ..., n-1 with weights w[n-1-L]:
grad[L:] += w[n-1-L] * (1-h[:n-L])
grad[:n-L] -= w[n-1-L] * h[L:]

I can combine: for each L = 0, ..., n-1:
weight_pos = w[n-1+L] (for lag +L)
weight_neg = w[n-1-L] (for lag -L)
total_w = weight_pos + weight_neg

grad[L:] += total_w * (1-h[:n-L])
grad[:n-L] -= total_w * h[L:]

Wait, let me double-check. For lag +L:
- grad[L:] += w_pos * (1-h[:n-L])
- grad[:n-L] -= w_pos * h[L:]

For lag -L:

- grad[:n-L] -= w_neg * h[L:]

Combined:
- grad[L:] += (w_pos + w_neg) * (1-h[:n-L])
- grad[:n-L] -= (w_pos + w_neg) * h[L:]

```python
import numpy as np
from scipy.optimize import minimize
import time

def compute_corr(h):
    return np.correlate(h, 1.0 - h, mode="full")

def c5_value(h):
    dx = 2.0 / len(h)
    return float(np.max(compute_corr(h))) * dx

def c5_grad_exact(h, flat_eps=5e-4):
    n = len(h)
    dx = 2.0 / n
    corr = compute_corr(h)
    max_val = np.max(corr)
    near_max = np.where(corr >= max_val - flat_eps)[0]
    grad = np.zeros(n)
    for idx in near_max:
        lag = int(idx - (n - 1))
        if lag >= 0:
            grad[lag:] += (1.0 - h[:n - lag])
            grad[:n - lag] -= h[lag:]
        else:
            l = -lag
            grad[l:] += (1.0 - h[:n - l])
            grad[:n - l] -= h[l:]
    grad /= float(len(near_max))
    return dx * grad

def c5_smooth_value(h, tau):
    dx = 2.0 / len(h)
    corr = compute_corr(h)
    x = tau * corr
    xm = np.max(x)
    return dx * (xm + np.log(np.sum(np.exp(x - xm)))) / tau

def c5_smooth_grad(h, tau):
    n = len(h)
    dx = 2.0 / n
    corr = compute_corr(h)
    x = tau * corr
    xm = np.max(x)
    w = np.exp(x - xm)
    w /= np.sum(w)
    weights = np.zeros(n)
    for L in range(n):
        weights[L] = w[n - 1 + L] + w[n - 1 - L]
    grad = np.zeros(n)
    for L in range(n):
        wl = weights[L]
        if wl < 1e-14:
            continue
        grad[L:] += wl * (1.0 - h[:n - L])
        grad[:n - L] -= wl * h[L:]
    return dx * grad

def fix_feasibility(h, n):
    h = np.clip(h, 0.0, 1.0)
    target = n / 2.0
    for _ in range(3):
        diff = target - np.sum(h)
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            mask = h < 0.9999
        else:
            mask = h > 0.0001
        cnt = np.sum(mask)
        if cnt == 0:
            mask = np.ones(n, dtype=bool)
            cnt = n
        h[mask] = np.clip(h[mask] + diff / cnt, 0.0, 1.0)
    return h

    return [{'type': 'eq', 'fun': lambda x, n=n: np.sum(x) - n / 2.0,
             'jac': lambda x, n=n: np.ones(n)}]
```
