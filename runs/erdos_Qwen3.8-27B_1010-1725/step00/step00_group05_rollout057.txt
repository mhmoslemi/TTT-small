- Terms where i+d = p (i.e., i = p-d): was h[p-d]*(1-h[p]) = h[p-d]*0 = 0, now h[p-d]*1 = h[p-d]

If we change h[q]: 0→1
- Term i=q: was 0, now (1-h[q+d])
- Terms where i+d = q (i = q-d): was h[q-d]*1 = h[q-d], now h[q-d]*0 = 0

So the total change in corr[d]:
Δcorr[d] = -(1-h[p+d]) + h[p-d] + (1-h[q+d]) - h[q-d]
(where each term is included only if the index is valid)

For binary h:
- (1-h[p+d]) = 1 if h[p+d]=0, else 0
- h[p-d] = 1 if h[p-d]=1, else 0
- (1-h[q+d]) = 1 if h[q+d]=0, else 0
- h[q-d] = 1 if h[q-d]=1, else 0

So Δcorr[d] = -(1-h[p+d]) + h[p-d] + (1-h[q+d]) - h[q-d] ∈ {-2,-1,0,1,2}

This is computable in O(1) per lag, so O(n) per swap.

For all n²/4 swaps: O(n³) per full scan. For n=70: 70³/4 ≈ 86K operations. Very fast!

def evaluate_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)

def make_binary(h, n):
    b = (h >= 0.5).astype(float)
    cnt = int(np.sum(b))
    if cnt != n // 2:
        if cnt > n // 2:
            idx = np.where(b == 1)[0]
            np.random.shuffle(idx)
            b[idx[:cnt - n // 2]] = 0.0
        else:
            idx = np.where(b == 0)[0]
            np.random.shuffle(idx)
            b[idx[:n // 2 - cnt]] = 1.0
    return b
