This is a 1D optimization! And for each t, max_k f_k is the max of affine functions of t (since f_k is linear in each h separately, and here only h[i] and h[j] change, with h[i]+h[j] fixed, so f_k is affine in t).

The min of a max of affine functions over an interval is a convex optimization in 1D. I can find it with a ternary search or by finding the intersection points.

Actually, since f_k(t) = m_k * t + b_k (affine in t), the function g(t) = max_k f_k(t) is a piecewise-linear convex function. Its minimum is at a "kink" point, which is an intersection of two of the f_k lines.

So I can:
1. For each pair (i,j), compute m_k, b_k for all k
2. Find t* that minimizes max_k (m_k * t + b_k) over the feasible interval
3. Update h[i] = t*, h[j] = s - t*

This is exact for the given pair! And it's a 1D problem with O(n) lines to find the minimum of the max.

To find min_t max_k (m_k * t + b_k) over [t_lo, t_hi]:
- This is a convex piecewise linear function
- The minimum is at a point where two lines intersect, or at an endpoint
- I can find it by: for each pair of lines (k1, k2), compute their intersection t_ij, check if it's in range, and evaluate max at that point. Better approach: Since g(t) = max_k (m_k * t + b_k) is convex and piecewise linear, I can find its minimum by:
- Binary search on the subgradient
- The subgradient at t is {m_k : f_k(t) = g(t)} (the subdifferential)
- g is minimized when 0 ∈ ∂g(t), i.e., when there exist active lines with m_k < 0 and m_k > 0 (or m_k = 0)

Actually for piecewise linear convex, the minimum is where the slope changes from negative to positive. I can sort all m_k values and find the "break even" point.

import time

def fix_sum(h, n):
    """Project h onto {0<=h[i]<=1, sum(h)=n/2}."""
    target = n / 2.0
    h = np.clip(h.astype(np.float64).copy(), 0.0, 1.0)
    for _ in range(10000):
        d = target - h.sum()
        if abs(d) < 1e-13:
            break
        m = h < 1.0 if d > 0 else h > 0.0

            break
