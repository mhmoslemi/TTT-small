    h = np.clip(h, 0, 1)
    target = len(h) / 2
    diff = target - np.sum(h)
    if abs(diff) < 1e-10:
        return h
    # Water-filling
    if diff > 0:
        # Need to increase sum by diff
        # Increase entries that are < 1, starting with smallest
        order = np.argsort(h)
        for idx in order:
            add = min(1 - h[idx], diff)
            h[idx] += add

    else:

            diff += sub
            if diff >= -1e-10:

Wait, more carefully:
f_k = sum_i h[i]*(1-h[i+k]) 

The terms involving h[j]:
- h[j]*(1-h[j+k]) (when j is in valid range for the first factor)
- h[j-k]*(1-h[j]) (when j-k is in valid range)

So f_k as a function of h[j]:
= h[j]*(1-h[j+k]) + h[j-k]*(1-h[j]) + const
= h[j] - h[j]*h[j+k] + h[j-k] - h[j]*h[j-k] + const
= h[j]*(1 - h[j+k] - h[j-k]) + h[j-k] + const

This is LINEAR in h[j]! (Since h[j+k] and h[j-k] are fixed when we vary h[j].)

So for each lag k, f_k is linear in h[j]. The max of linear functions is convex in h[j]. To minimize the max, we find the point where the top two (constrained) lines cross, or at a boundary.

This means coordinate descent is well-defined! For each j:
1. Compute the "slope" a_k = 1 - h[j+k] - h[j-k] for each lag k
2. Compute the "intercept" b_k = f_k - h[j]*a_k (this is f_k with h[j] set to 0)
3. f_k(h[j]) = a_k * h[j] + b_k
4. min_{0≤x≤1} max_k (a_k*x + b_k)

This is a 1D convex minimization (min of max of linear functions). The optimal x is where the maximum changes hands, or at 0 or 1.

To find it: sort the lines by slope. The upper envelope changes at intersection points. The minimum of the upper envelope on [0,1] is at the leftmost intersection point (if it's in [0,1]) or at a boundary.

This can be done in O(n log n) per coordinate (sort by slope, find the envelope minimum). For n=80 lags and 80 coordinates, that's 80 * 80*log(80) ≈ 38K operations per full pass. Very fast!
