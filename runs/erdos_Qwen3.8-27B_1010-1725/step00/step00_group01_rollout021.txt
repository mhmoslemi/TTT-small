For the smooth max: F_ε(h) = ε * log(∑_k exp(overlap_k(h) / ε))
With ε small (like 0.01), this approximates the max well.

The gradient of F_ε is: ∇F_ε = ∑_k (exp(overlap_k/ε) / ∑_j exp(overlap_j/ε)) * ∇overlap_k

This is a convex combination of the individual gradients, weighted by the softmax of the overlaps. This is much smoother than the hard max!

```python
def _smooth_max_obj(h, eps=0.01):
    n = len(h)
    dx = 2.0 / n
    rr = np.correlate(h, 1.0 - h, mode='full') * dx
    # Shift to avoid overflow
    rr_shifted = rr - rr.max()
    weights = np.exp(rr_shifted / eps)
    weights /= weights.sum()
    F = (rr.max() + eps * np.log(weights.sum() + 1e-300))
    return F, weights

def _smooth_grad(h, eps=0.01):
    n = len(h)
    dx = 2.0 / n
    rr = np.correlate(h, 1.0 - h, mode='full') * dx
    rr_shifted = rr - rr.max()
    weights = np.exp(rr_shifted / eps)
    weights /= weights.sum()
    
    g = np.zeros(n)
    # For each shift with significant weight, compute gradient
    # Only do top few to save time
    top_k = np.argsort(-weights)[:5]
    for km in top_k:
        w = weights[km]
        if w < 1e-6:
            continue
        k = int(km) - n + 1
        if k >= 0:
            g[k:] += w * (1.0 - h[:n-k])
            g[:n-k] -= w * h[k:]
        else:
            g[:n+k] += w * (1.0 - h[-k:])
            g[-k:] -= w * h[:n+k]
    return g
```
