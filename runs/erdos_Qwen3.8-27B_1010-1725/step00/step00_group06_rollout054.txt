SLSQP should use this for efficiency. But I'm not providing the gradient, so SLSQP will use finite differences. This makes it O(n) evaluations per iteration, so O(n^2) per iteration for the gradient, plus O(n^3) for the QP solve.

To speed things up, I could provide the gradient analytically. Let me compute it:

The objective is: $f(h) = \tau \log \sum_s \exp(c_s/\tau) + c_{max}$ (after the shift trick)

where $c_s = dx \cdot \text{corr}[s] = dx \cdot \sum_i h_i \cdot (1-h_{i+s-(n-1)})$ (for valid indices)

The gradient: $\partial f / \partial h_j = \tau \cdot \frac{1}{\sum_s \exp(c_s/\tau)} \cdot \sum_s \exp(c_s/\tau) \cdot \frac{1}{\tau} \cdot \frac{\partial c_s}{\partial h_j}$
$= \sum_s p_s \cdot \frac{\partial c_s}{\partial h_j}$

where $p_s = \exp(c_s/\tau) / \sum_t \exp(c_t/\tau)$.

And $\partial c_s / \partial h_j$:
$c_s = dx \cdot \sum_i h_i (1 - h_{i+s-(n-1)})$

For a fixed j, h_j appears in c_s when:
- i = j: contributes dx * (1 - h_{j+s-(n-1)})
- i+s-(n-1) = j: i = j - s + (n-1): contributes dx * (-h_{j-s+(n-1)})

So: $\partial c_s / \partial h_j = dx \cdot [(1 - h_{j+s-(n-1)}) \cdot \mathbb{1}[\text{valid}] - h_{j-s+(n-1)} \cdot \mathbb{1}[\text{valid}]]$

This is O(1) per (s, j) pair, but we need to sum over s for each j, giving O(n) per j, O(n^2) total.

    # corr[s] = dx * sum_i x[i] * (1-x)[i + s - (n-1)]
    # = dx * sum_i x[i] * (1 - x[i + s - (n-1)])

        # j-s+n-1 <= n-1 means j <= s

        for j in range(j_lo_b, j_hi_b+1):

            grad[j] -= ps * dx * x[idx]

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1 - h, mode='full')
    return float(np.max(corr) * dx)

def softmax_obj(x, n, tau):
    dx = 2.0 / n
    corr = np.correlate(x, 1 - x, mode='full') * dx
    m = np.max(corr)
    ev = np.exp((corr - m) / tau)
    return m + tau * np.log(np.mean(ev))

def softmax_grad(x, n, tau):
    dx = 2.0 / n
    corr = np.correlate(x, 1 - x, mode='full') * dx
    m = np.max(corr)
    ev = np.exp((corr - m) / tau)
    p = ev / ev.sum()
    grad = np.zeros(n)
    Nm1 = n - 1
    for m_idx in range(2 * n - 1):
        ps = p[m_idx]
        if ps < 1e-16:
            continue
        L = m_idx - Nm1
        # first term: j in [max(0,L), min(n-1, L+n-1)], contribution (1-x[j-L])
        jlo = max(0, L)
        jhi = min(n - 1, L + n - 1)
        if jlo <= jhi:
            idx = np.arange(jlo, jhi + 1) - L
            grad[jlo:jhi + 1] += ps * dx * (1.0 - x[idx])
        # second term: j in [max(0,-L), min(n-1, n-1-L)], contribution -x[j+L]
        jlo2 = max(0, -L)
        jhi2 = min(n - 1, n - 1 - L)
        if jlo2 <= jhi2:
            idx2 = np.arange(jlo2, jhi2 + 1) + L
            grad[jlo2:jhi2 + 1] -= ps * dx * x[idx2]
    return grad
