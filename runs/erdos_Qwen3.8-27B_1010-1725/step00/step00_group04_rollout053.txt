The problem is to minimize max_k ∫ h(x)(1-h(x+k)) dx subject to ∫h = 1, 0≤h≤1.

If h is a 0-1 function (which is often optimal for such problems), then ∫h(x)(1-h(x+k)) dx = measure of {x: h(x)=1, h(x+k)=0}.

For a 0-1 function, this is the "asymmetric difference" in one direction. We want to minimize the maximum over all shifts.

This is related to the problem of finding a binary sequence that minimizes the maximum cross-correlation (or more precisely, the maximum one-sided difference).

For periodic sequences, this is related to Barker sequences and CAZAC sequences, but our problem is on a line segment [0,2] with a specific integral constraint.

Given the current best of 0.38085, let me think about what's achievable.

The trivial bound: if h is constant 1/2 everywhere, then ∫h(1-h) = ∫1/4 = 2/4 = 1/2 for all shifts. So C₅ ≤ 0.5.

A step function that's 1 on [0,1] and 0 on [1,2]: For shift k near 0, the overlap is small. For shift k near 1, the overlap could be large. Let's compute: h(x)=1 for x∈[0,1], 0 for x∈[1,2].
∫₀² h(x)(1-h(x+k)) dx.
For 0≤k≤1: h(x)=1 for x∈[0,1], h(x+k)=1 for x∈[-k,1-k]∩[0,2]=[0,1-k].

Integral = k.
For 1≤k≤2: h(x+k)=1 for x∈[-k,1-k] which is empty in [0,2] when k≥1.
So h(x)(1-h(x+k)) = h(x)*1 = 1 for x∈[0,1].
Integral = 1.

        j_lo2 = max(0, -lag)

import numpy as np
from scipy.optimize import minimize
import time

_global_temp = 0.01

def project_feasible(h):
    h = np.clip(h, 0.0, 1.0)
    target = len(h) / 2.0
    diff = np.sum(h) - target
    if abs(diff) < 1e-12:
        return h
    lo, hi = -1.0, 1.0
    for _ in range(100):
        mid = (lo + hi) * 0.5
        hm = np.clip(h + mid, 0.0, 1.0)
        if np.sum(hm) > target:
            hi = mid
        else:
            lo = mid
    return np.clip(h + (lo + hi) * 0.5, 0.0, 1.0)

def compute_c5(h):
    corr = np.correlate(h, 1.0 - h, mode='full')
    return np.max(corr) * (2.0 / len(h))

def c5_grad(h, temp):
    n = len(h)
    corr = np.correlate(h, 1.0 - h, mode='full')
    dx = 2.0 / n
    m = np.max(corr)
    if temp < 1e-10:
        k_star = np.argmax(corr)
        c5_val = m * dx
        lag = k_star - (n - 1)
        grad = np.zeros(n)
        jlo = max(0, lag)
        jhi = min(n, lag + n)
        if jlo < jhi:
            idx = np.arange(jlo, jhi)
            grad[idx] += (1.0 - h[idx - lag])
        jlo2 = max(0, -lag)
        jhi2 = min(n, n - lag)
        if jlo2 < jhi2:
            idx2 = np.arange(jlo2, jhi2)
            grad[idx2] -= h[idx2 + lag]
        grad *= dx
        return c5_val, grad
    exp_c = np.exp((corr - m) / temp)
    s = np.sum(exp_c)
    c5_val = (m + temp * np.log(s)) * dx
    weights = exp_c / s
    grad = np.zeros(n)
    for k in range(len(corr)):
        w = weights[k]
        if w < 1e-10:
            continue
        lag = k - (n - 1)
        jlo = max(0, lag)
        jhi = min(n, lag + n)
        if jlo < jhi:
            idx = np.arange(jlo, jhi)
            grad[idx] += w * (1.0 - h[idx - lag])
        jlo2 = max(0, -lag)
        jhi2 = min(n, n - lag)
        if jlo2 < jhi2:
            idx2 = np.arange(jlo2, jhi2)
            grad[idx2] -= w * h[idx2 + lag]
    grad *= dx
    return c5_val, grad

    return v

    _, g = c5_grad(h, _global_temp)

    h_init = project_feasible(h_init.copy())
    n = len(h_init)

                       bounds=bounds, options={'maxiter': max_iter, 'maxls': 50, 'ftol': 1e-15})
        h_new = project_feasible(res.x)
        return h_new, compute_c5(h_new)
    except Exception:
        return h_init, compute_c5(h_init)
