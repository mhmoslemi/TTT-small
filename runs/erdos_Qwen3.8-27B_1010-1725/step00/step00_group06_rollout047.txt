from scipy.optimize import minimize
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return np.max(corr) * dx

def corr_and_grad(h):
    n = len(h)
    dx = 2.0 / n
    omh = 1.0 - h
    corr = np.correlate(h, omh, mode='full')
    # Gradient: for each m in [0, 2n-2], L = m - (n-1)
    # grad[j] = sum over valid contributions
    # For lag L, corr element m = n-1+L:
    #   grad[j] += (1-h[j+L]) if 0<=j+L<n (j is the first factor)
    #   grad[j] += -h[j-L] if 0<=j-L<n (j is the second factor, i.e., i+L=j, i=j-L)
    grad = np.zeros(n)
    for m in range(2*n - 1):
        L = m - (n - 1)
        # valid i range: max(0, -L) <= i < min(n, n-L)
        i_start = max(0, -L)
        i_end = min(n, n - L)
        for i in range(i_start, i_end):
            # h[i] * (1 - h[i+L])
            grad[i] += (1.0 - h[i + L])
            if i + L != i:  # avoid double counting at L=0
                grad[i + L] += (-h[i])
            else:
                # L=0: h[i]*(1-h[i]), grad w.r.t. h[i] = 1-2*h[i]
                # We already added (1-h[i]) for the first factor
                # Second factor contributes -h[i]
                grad[i] += (-h[i])
    return corr * dx, grad * dx

We want to minimize the maximum. This is like minimizing the maximum "disagreement" at any lag.

For a periodic pattern with period p, the correlations would repeat. For example, if h alternates 1,0,1,0,... (period 2), then at lag 1, every pair is (1,0) or (0,1), giving high correlation. At lag 2, every pair agrees, giving 0. So max is at lag 1.

For a block pattern like 111...1000...0 (half 1s, half 0s), the correlation is highest at lag = n/2.

The optimal pattern is somewhere in between. This is related to the problem of optimal binary sequences for radar/communication.
