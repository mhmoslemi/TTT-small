For coordinate i, fixing all other h[j] (j≠i), each correlation value corr[k] is an affine function of h[i]:
corr[k] = a_k * h[i] + b_k (for the terms involving h[i])

Wait, actually corr[k] = sum_j h[j] * (1 - h[j+k_or_shift]) which is quadratic in h. If we fix all h[j] for j ≠ i, then corr[k] is:
- Linear in h[i] if i appears only once in the sum
- Quadratic in h[i] if i appears as both h[i] and (1-h[i±k])

For a given lag k, h[i] appears in:
- h[i] * (1-h[i-k]) as the "h" term (if i-k is valid)
- h[i+k] * (1-h[i]) as the "(1-h)" term (if i+k is valid)

So corr[k] = ... + h[i]*(1-h[i-k]) + h[i+k]*(1-h[i]) + ...
= ... + h[i] - h[i]*h[i-k] + h[i+k] - h[i+k]*h[i] + ...
= ... + (1 - h[i-k] - h[i+k]) * h[i] + h[i+k] + ...

So it IS linear in h[i]! Each corr[k] is linear in h[i] when all other coordinates are fixed.

This means the max of corr[k] as a function of h[i] is the max of linear functions, which is a convex piecewise-linear function. We can minimize it by finding the "lowest point" of this convex PL function.

This is great! We can do coordinate descent efficiently:

2. The minimum is where the "kink" occurs, or at a boundary
3. We can binary search or use the slopes to find the minimum

- Evaluating at h[i] = 0 and h[i] = 1 (and the constrained range)
- The minimum of a convex function on an interval is at a point where the slope changes sign
- We can find this by checking slopes at the endpoints

import numpy as np
from scipy.optimize import minimize, Bounds
import time

def compute_c5(h, dx):
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)

def soft_max_obj(h, dx, alpha):
    corr = np.correlate(h, 1.0 - h, mode="full") * dx
    m = np.max(corr)
    return float(m + np.log(np.sum(np.exp(alpha * (corr - m)))) / alpha)

def project_onto_set(h, n):
    target = n / 2.0
    h = np.clip(h, 0.0, 1.0)
    diff = target - np.sum(h)
    if abs(diff) > 1e-12:
        free = (h > 1e-8) & (h < 1.0 - 1e-8)
        nf = int(np.sum(free))
        if nf > 0:
            h[free] += diff / nf
        else:
            h += diff / n
    h = np.clip(h, 0.0, 1.0)
    diff = target - np.sum(h)
    if abs(diff) > 1e-12:
        h += diff / n
    return np.clip(h, 0.0, 1.0)

def make_binary(n, rng, target):
    h = (rng.random(n) > 0.5).astype(float)
    s = int(np.sum(h))
    if s > target:
        ones = np.where(h == 1)[0]
        fl = rng.choice(ones, s - target, replace=False)
        h[fl] = 0.0
    elif s < target:
        zeros = np.where(h == 0)[0]
        st = rng.choice(zeros, target - s, replace=False)
        h[st] = 1.0
    return h

def slsqp_solve(h_start, n, dx, target, bounds, alpha, maxiter, ftol):
    def obj(x):
        return soft_max_obj(x, dx, alpha)
    cons = [{'type': 'eq', 'fun': lambda x: np.sum(x) - target,
             'jac': lambda x: np.ones(n)}]
    try:
        res = minimize(obj, h_start, method='SLSQP', bounds=bounds,
                       constraints=cons, options={'maxiter': maxiter, 'ftol': ftol})
        h_c = project_onto_set(res.x, n)
        c5_c = compute_c5(h_c, dx)
        return h_c, c5_c
    except Exception:
        return None, float('inf')

    best_local = h_start.copy()
    best_local_c5 = compute_c5(h_start, dx)

        if h_c is not None and c5_c < best_local_c5:
            best_local_c5 = c5_c
            best_local = h_c.copy()
            h_start = h_c.copy()
    return best_local, best_local_c5
