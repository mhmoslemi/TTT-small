Also, I realize I should make the subgradient computation more vectorized. Instead of looping over all shifts, I can compute the weighted subgradient more efficiently.

Actually, the key insight is: the weighted subgradient is:
sg = sum_k w[k] * _subgrad_at(h, (n-1)-k)

For shift s with |s| = a:
sg[a:] += w[k] * (1-h[:n-a])
sg[:n-a] -= w[k] * h[a:]

This means for each |s| value a, the contribution to sg depends only on a and w[k]. Since multiple k values can give the same |s| (e.g., k = n-1-s and k = n-1+s both give |s| = s), I can group by |s|.

For a given |s| = a (a ≥ 0):
- k = n-1-a gives s = a, weight w[n-1-a]
- k = n-1+a gives s = -a, weight w[n-1+a] (if valid, i.e., n-1+a < 2n-1)

For a = 0: only k = n-1, weight w[n-1]
For a > 0: k1 = n-1-a, k2 = n-1+a (both valid if 0 ≤ k ≤ 2n-2)

Combined weight for shift magnitude a: w_a = w[n-1-a] + w[n-1+a]

Then:
sg[a:] += w_a * (1-h[:n-a])
sg[:n-a] -= w_a * h[a:]

For a=0: sg[:] += w_0 * (1-h) and sg[:] -= w_0 * h, net: sg[:] += w_0 * (1-2h)

This reduces the loop from 2n-1 to n iterations (a = 0 to n-1). Nice.

```python
def _weighted_subgrad(h, w, n):
    """Compute weighted subgradient. w[k] is weight for correlation index k."""
    sg = np.zeros(n)
    for a in range(n):
        # a is |shift|
        k1 = n - 1 - a
        k2 = n - 1 + a
        wa = 0.0
        if 0 <= k1 < 2*n-1:
            wa += w[k1]
        if 0 <= k2 < 2*n-1:
            wa += w[k2]
        if wa < 1e-15:
            continue
        if a == 0:
            sg += wa * (1.0 - 2.0 * h)
        else:
            sg[a:] += wa * (1.0 - h[:n-a])
            sg[:n-a] -= wa * h[a:]
    return sg
```
