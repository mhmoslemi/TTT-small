    """Compute the change in correlation vector when h[j] changes by delta (linear approx)."""

**Approach: Projected gradient descent with line search.**

1. Compute the subgradient of the max (i.e., the correlation that achieves the max, or a convex combination if there's a tie)
2. Take a step in the negative subgradient direction
3. Project onto the feasible set (0≤h≤1, sum=n/2)

The subgradient of max_k c[k] with respect to h[j] is:
- If c[k*] is the unique max: ∂c[k*]/∂h[j]
- If there's a tie: weighted average of ∂c[k]/∂h[j] for all k in the tie set

The projection onto {h: 0≤h≤1, sum(h)=n/2} can be done in O(n log n) time (water-filling algorithm).

This is a well-known algorithm and should be efficient. Let me implement it.

Actually, for the subgradient, I need ∂c[k]/∂h[j] for the active k values.

c[k] = sum_i h[i] * (1 - h[i+m]) where m = k-(n-1)

∂c[k]/∂h[j]:
- From the first factor (h[j]): (1 - h[j+m]) if j+m is valid
- From the second factor (1-h[j]): -h[j-m] if j-m is valid (where i = j-m)

So ∂c[k]/∂h[j] = (1 - h[j+m_k]) * [0≤j+m_k<n] - h[j-m_k] * [0≤j-m_k<n]

where m_k = k - (n-1).

For the active set A (k values where c[k] = max), the subgradient with respect to h[j] is:
∇_j = sum_{k∈A} w_k * [(1 - h[j+m_k]) * I(0≤j+m_k<n) - h[j-m_k] * I(0≤j-m_k<n)]

where w_k are weights summing to 1 (e.g., uniform over the active set, or softmax weights).

This can be computed in O(|A| * n) time for all j, or O(n * |A|) time.

For the projected gradient method:
1. Compute subgradient g (O(n * |A|))
2. Compute step size α (line search or backtracking)
3. h_new = h - α * g
4. Project h_new onto feasible set (O(n log n))
5. Check if objective improved

The projection step: given a vector y, find the closest point to the set {h: 0≤h≤1, sum(h)=S}.
This is: h = clip(y - λ, 0, 1) where λ is chosen so that sum(h) = S.
Finding λ is a 1D search (bisection), O(n log n) total.

def project_sum(h, S):

        s = x.sum()
        if s > S:

    """Compute subgradient of max_{k in active_lags} c[k] w.r.t. h."""
    n = len(h)
    g = np.zeros(n)
    for k in active_lags:
        m = k - (n - 1)
        # For each j: ∂c[k]/∂h[j] = (1-h[j+m])*I(0≤j+m<n) - h[j-m]*I(0≤j-m<n)
        # j+m valid: j in [max(0,-m), min(n-1, n-1-m)]
        # j-m valid: j in [max(0,m), min(n-1, n-1+m)]

    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    c5 = np.max(corr) * dx
    h = h.copy()
    
    for sweep in range(max_sweeps):
        improved = False
        for j in range(1, n):
            orig = h[j]
            h0_val = h[0]
            best_c = c5
            best_v = orig
            
            for v in np.linspace(0.0, 1.0, n_grid):
                if abs(v - orig) < 1e-8:
                    continue
                delta = v - orig
                new_h0 = h0_val - delta
                if new_h0 < -1e-10 or new_h0 > 1.0 + 1e-10:
                    continue
                
                # Incremental update
                # Change from h[j] += delta:
                m = np.arange(-(n-1), n)  # all lags
                # Part 1: (1-h[j+m]) for valid j+m
                valid1 = (j + m >= 0) & (j + m < n)
                # Part 2: -h[j-m] for valid j-m
                valid2 = (j - m >= 0) & (j - m < n)
                
                delta_corr = np.zeros(2*n-1)
                delta_corr[valid1] += delta * (1.0 - h[j + m[valid1]])
                delta_corr[valid2] -= delta * h[j - m[valid2]]
                
                # Change from h[0] -= delta:
                # h[0] changes by -delta
                valid1_0 = (0 + m >= 0) & (0 + m < n)  # m in [0, n-1]
                valid2_0 = (0 - m >= 0) & (0 - m < n)  # m in [-(n-1), 0]
                delta_corr[valid1_0] += (-delta) * (1.0 - h[0 + m[valid1_0]])
                delta_corr[valid2_0] -= (-delta) * h[0 - m[valid2_0]]
                
                new_corr = corr + delta_corr
                c_new = np.max(new_corr) * dx
                if c_new < best_c - 1e-14:
                    best_c = c_new
                    best_v = v
            
            if best_v != orig:
                h[j] = best_v
                h[0] = h0_val + (orig - best_v)
                h[0] = np.clip(h[0], 0.0, 1.0)
                # Recompute full corr (to correct for the quadratic term and clipping)
                corr = np.correlate(h, 1.0 - h, mode="full")
                c5 = np.max(corr) * dx
                improved = True
        
        if not improved:
            break
    
    return h, c5
