Wait, let me be more careful. C_k = sum_i h[i] * (1-h[i+k]) * dx where i ranges over valid indices.

The valid range depends on k. For np.correlate(h, 1-h, 'full'), the result at index m (0 to 2n-2) corresponds to:
result[m] = sum_i h[i] * (1-h)[i + m - (n-1)]

where both i and i+m-(n-1) are in [0, n-1].

Let m = n-1+k, so k = m-(n-1) ranges from -(n-1) to (n-1).
result[m] = sum_i h[i] * (1-h[i+k]) where i and i+k are both in [0, n-1].

dC_k / dh[j] = dx * sum over terms where j appears:
- If j is the "h[i]" factor: i=j, need j+k in [0,n-1], contribution: (1-h[j+k])
- If j is the "h[i+k]" factor: i+k=j, i=j-k, need j-k in [0,n-1], contribution: -h[j-k] (derivative of 1-h[i+k] w.r.t. h[j] is -1, times h[i])

So dC_k/dh[j] = dx * [(1-h[j+k]) * I(0≤j≤n-1 and 0≤j+k≤n-1) - h[j-k] * I(0≤j≤n-1 and 0≤j-k≤n-1)]

This is the gradient of C_k. For the max, we can use the subgradient: if k* is an argmax, use dC_{k*}/dh.

This gives us a subgradient descent method. But subgradient descent is slow and has oscillations. The soft-max approach is smoother and probably better in practice.

    n = len(h)
    dx = 2.0 / n
    return np.correlate(h, 1.0 - h, mode='full') * dx

def _c5(h):
    return float(np.max(_c5_arr(h)))

def _fix(h, n):
    h = np.clip(h, 0.0, 1.0)
    d = 0.5 * n - np.sum(h)
    if abs(d) > 1e-10:
        h += d / n
        h = np.clip(h, 0.0, 1.0)
    d2 = 0.5 * n - np.sum(h)
    if abs(d2) > 1e-10:
        idx = np.argmax(h) if d2 < 0 else np.argmin(h)
        h[idx] += d2
        h = np.clip(h, 0.0, 1.0)
    return h

def _softmax_obj(h, alpha, beta):
    n = len(h)
    C = _c5_arr(h)
    m = C.max()
    aC = np.clip(alpha * (C - m), -500, 500)
    return m + np.log(np.sum(np.exp(aC))) / alpha + beta * (np.sum(h) - 0.5 * n) ** 2

    res = minimize(_softmax_obj, h.astype(float), args=(alpha, beta),
                   method='L-BFGS-B', bounds=[(0.0, 1.0)] * n,
                   options={'maxiter': maxiter, 'ftol': 1e-15, 'gtol': 1e-7})
    return _fix(res.x, n)

        idx = np.where(h == 1)[0]
        h[rng.choice(idx, n_ones - target, replace=False)] = 0
    elif n_ones < target:
        idx = np.where(h == 0)[0]
        h[rng.choice(idx, target - n_ones, replace=False)] = 1
    return h

                best_h = h.copy()

                bc, bh = c2, h2
        # Gradient polish best at this n
        if el() < budget_s * 0.62:
            for a in [300, 1000]:
                if el() > budget_s * 0.64:
                    break
                h2 = _grad_opt(bh, n, a, 5.0, 400)
                c2 = _c5(h2)
                if c2 < bc:
                    bc, bh = c2, h2

    # Phase 3: Focused ILS on best solution's n
    nb = len(bh)
    if el() < budget_s * 0.82:
        for s in range(8):
            if el() > budget_s * 0.84:
                break
            if s == 0:
                h0 = _to_bin(bh, nb, rng)
            else:
                pert = rng.randn(nb) * rng.uniform(0.2, 0.5)
                h0 = _to_bin(bh + pert, nb, rng)
            h2, c2 = _ils(h0, nb, rng, n_outers=8, n_inner=15000, ts=0.15, te=0.0003)
            if c2 < bc:
                bc, bh = c2, h2
        # Gradient polish
        if el() < budget_s * 0.88:
            for a in [500, 1500, 3000]:
                if el() > budget_s * 0.90:
                    break
                h2 = _grad_opt(bh, nb, a, 10.0, 500)
                c2 = _c5(h2)
                if c2 < bc:
                    bc, bh = c2, h2

    # Phase 4: High-alpha polish
    if el() < budget_s * 0.95:
        for a in [2000, 5000, 10000]:
            if el() > budget_s * 0.97:
                break
            h2 = _grad_opt(bh, nb, a, 20.0, 600)
            c2 = _c5(h2)
            if c2 < bc:
                bc, bh = c2, h2

    # Phase 5: Quick restarts
    while el() < budget_s * 0.99:
        h_try = _fix(bh + rng.randn(nb) * 0.03, nb)
        h2 = _grad_opt(h_try, nb, 800, 10.0, 200)
        c2 = _c5(h2)
        if c2 < bc:
            bc, bh = c2, h2

    return (bh, bc, nb)
