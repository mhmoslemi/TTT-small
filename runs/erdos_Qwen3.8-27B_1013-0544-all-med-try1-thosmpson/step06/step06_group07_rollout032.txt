Let me implement idea 1 more concretely:

**Plateau-focusing:**
- At each iteration:
  1. Compute c_values
  2. Identify the top-k shifts (k=2,3,4,5)
  3. Find the direction that reduces ALL of these simultaneously (if possible)
  4. If no such direction exists (they're in conflict), find the direction that reduces the maximum among them
  5. Take a step in that direction
  6. Update the active set

The direction that reduces all active c_k simultaneously is found by solving:
minimize max_i (g_i · d)  subject to ||d|| = 1

where g_i are the gradients of the active c_k's.

This is equivalent to finding the direction d that minimizes the maximum of the linear functions g_i · d.

The solution is d = -w where w is the minimum-norm solution to sum_i w_i * w_i = 1 (weighted sum of gradients). Actually, it's more nuanced.

Let me think about it differently. If we have active gradients g_1, ..., g_k, we want a direction d such that g_i · d < 0 for all i (to decrease all active objectives). If no such d exists, we find the d that minimizes max_i g_i · d.

The minimum of max_i g_i · d over ||d||=1 is related to the "width" of the set {g_1, ..., g_k}.

Actually, for practical purposes, a simple approach works:
- d = -sum_i g_i / ||sum_i g_i|| (if the sum isn't zero)
- If the sum is zero, try pairwise combinations

import warnings

def _tl(d):
    return max(0.0, d - time.time())

def repair(h):
    x = np.array(h, dtype=float, copy=True)
    n = x.size
    if n == 0:
        return x
    t = 0.5 * n
    np.clip(x, 0.0, 1.0, out=x)
    for _ in range(60):
        d = t - x.sum()
        if abs(d) < 1e-14:
            break
        if d > 0:
            m = 1 - x > 1e-15
            if not m.any():
                break
            x[m] += d * (1 - x[m]) / (1 - x[m]).sum()
        else:
            m = x > 1e-15
            if not m.any():
                break
            x[m] += d * x[m] / x[m].sum()
        np.clip(x, 0.0, 1.0, out=x)

def eval_c(h):
    n = len(h)
    return np.correlate(h, 1.0 - h, mode="full") * (2.0 / n)

def eval_max(h):
    return float(np.max(eval_c(h)))

def _agr(x, g, k, sc):
    if sc == 0.0:
        return
    n = x.size
    s = int(k) - (n - 1)
    a = max(0, -s)
    b = min(n - 1, n - 1 - s)
    if a <= b:
        g[a:b+1] += sc * (1.0 - x[a+s:b+1+s])
    a = max(0, s)
    b = min(n - 1, n - 1 + s)
    if a <= b:
        g[a:b+1] -= sc * x[a-s:b+1-s]

def wgrad(x, w):
    n = x.size
    g = np.zeros(n)
    for k in np.nonzero(w > 1e-12)[0]:
        _agr(x, g, int(k), w[k])
    return g * (2.0 / n)

def agrad(x, act):
    n = x.size
    g = np.zeros(n)
    if len(act) == 0:
        return g
    for k in act:
        _agr(x, g, int(k), 1.0)

    C = c.max()
    z = (c - C) / tau - 1.0
    e = np.exp(z)
    s = e.sum()
    if not np.isfinite(s) or s <= 0:
        return C
    return C + tau * np.log(s)

def _sjac(x, tau):
    c = eval_c(x)
    C = c.max()
    z = (c - C) / tau - 1.0
    e = np.exp(z)
    s = e.sum()
    if not np.isfinite(s) or s <= 0:
        w = np.zeros_like(c)
        w[c.argmax()] = 1.0
    else:
        w = e / s
    return _sobj(x, tau), wgrad(x, w)
