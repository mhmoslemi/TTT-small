new_corr[lag] = old_corr[lag] + δ * (S(j, lag) - S(i, lag))

And we want to minimize max(new_corr) * dx over δ in the feasible range.

This is a 1D problem! And it's a min of a max of linear functions, which is convex.

The feasible range for δ:
- 0 ≤ h[i] + δ ≤ 1 → -h[i] ≤ δ ≤ 1 - h[i]
- 0 ≤ h[j] - δ ≤ 1 → h[j] - 1 ≤ δ ≤ h[j]
So: max(-h[i], h[j]-1) ≤ δ ≤ min(1-h[i], h[j])

To find the optimal δ, I can:
1. Compute d[lag] = S(j, lag) - S(i, lag) for all lags.
2. The objective is f(δ) = max_lag (corr[lag] + δ * d[lag]).
3. f is convex and piecewise linear.
4. The minimum is at a breakpoint: δ* = (corr[a] - corr[b]) / (d[b] - d[a]) for some pair (a,b).
5. Or at a boundary.

For efficiency, I'll just evaluate f at a fine grid of δ values (say 200 points) and pick the best. With n=280, this is very fast.

Actually, even better: I can find the exact optimum. The breakpoints are at:
δ_ab = (corr[a] - corr[b]) / (d[b] - d[a]) for all a ≠ b with d[a] ≠ d[b].

There are O(n²) such breakpoints, but I only need to check the ones that are within the feasible range. And I can do this more efficiently by noting that the upper envelope of lines can be found in O(n) time (using the fact that we're looking for the minimum of the upper envelope).

But for n=280, even O(n²) = 78400 evaluations is fast. Let me just do a grid search for simplicity.

def project_h(h, target_sum):
    h = np.clip(h, 0.0, 1.0).copy()
    for _ in range(100):
        diff = target_sum - h.sum()
        if abs(diff) < 1e-14:
            break
        free = (h > 1e-10) & (h < 1.0 - 1e-10)
        if free.sum() == 0:
            free = np.ones(len(h), dtype=bool)
        h[free] += diff / free.sum()
        h = np.clip(h, 0.0, 1.0)
    return h

def swap_delta(h, i, j, corr):
    """Find optimal delta for swapping h[i]->h[i]+delta, h[j]->h[j]-delta"""
    n = len(h)
    # Feasible range for delta
    d_lo = max(-h[i], h[j] - 1.0)
    d_hi = min(1.0 - h[i], h[j])
    if d_hi - d_lo < 1e-15:
        return 0.0, compute_c5(h)
    
    # Compute S(i, lag) and S(j, lag) for all lags
    # lag ranges from -(n-1) to (n-1)
    # corr has length 2n-1, index = lag + (n-1)
    lags = np.arange(-(n-1), n)
    
    # S(i, lag) = h[i-lag] + h[i+lag] (0 if out of bounds)
    def S(idx, lag_arr):
        # lag_arr is array of lags
        a = idx - lag_arr  # i - lag
        b = idx + lag_arr  # i + lag
        sa = np.where((a >= 0) & (a < n), h[a], 0.0)
        sb = np.where((b >= 0) & (b < n), h[b], 0.0)
        return sa + sb
    
    Si = S(i, lags)
    Sj = S(j, lags)
    d = Sj - Si  # change per unit delta
    
    # Objective: f(delta) = max(corr + delta * d)
    # Grid search
    n_grid = 200
    deltas = np.linspace(d_lo, d_hi, n_grid)
    vals = np.max(corr[None, :] + deltas[:, None] * d[None, :], axis=1)
    best_idx = np.argmin(vals)
    best_delta = deltas[best_idx]
    
    # Refine with finer grid around best

        hi = deltas[best_idx + 1]
        deltas2 = np.linspace(lo, hi, 100)
        vals2 = np.max(corr[None, :] + deltas2[:, None] * d[None, :], axis=1)
        best_idx2 = np.argmin(vals2)
        best_delta = deltas2[best_idx2]
    
    return best_delta, np.max(corr + best_delta * d)
