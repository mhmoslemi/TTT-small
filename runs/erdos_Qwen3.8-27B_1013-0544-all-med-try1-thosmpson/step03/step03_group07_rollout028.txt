The third term: -sum_i h_t[i-s]*h[i]

So the linearized corr_s is: sum_i h[i]*((1 - h_t[i-s]) - h_t[i-s]) + const

Wait that doesn't seem right either. Let me be more careful.

corr_s = sum_i h[i]*(1-h[i-s])

Linearize h[i-s] around h_t[i-s]: h[i-s] ≈ h_t[i-s] + (h[i-s] - h_t[i-s])
But that's circular. The standard linearization of a product fg at (f0, g0) is:
fg ≈ f0*g + f*g0 - f0*g0

So: h[i]*h[i-s] ≈ h_t[i]*h[i-s] + h[i]*h_t[i-s] - h_t[i]*h_t[i-s]

Therefore:

≈ sum_i h[i] - sum_i h_t[i]*h[i-s] - sum_i h_t[i-s]*h[i] + sum_i h_t[i]*h_t[i-s]

This is linear in h (the terms with h are linear). 

So: corr_s ≈ sum_i h[i]*(1) - sum_i h_t[i]*h[i-s] - sum_i h_t[i-s]*h[i] + c_s

where c_s = sum_i h_t[i]*h_t[i-s] is constant.

The coefficient of h[j] in this expression:
- From sum_i h[i]: 1
- From -sum_i h_t[i]*h[i-s]: -h_t[j+s] (when i-s = j, i = j+s)
- From -sum_i h_t[i-s]*h[i]: -h_t[j-s] (when i = j)

So: corr_s ≈ c_s + sum_j h[j]*(1 - h_t[j+s] - h_t[j-s])

(with appropriate boundary handling)

Now, the smoothmax of these linearized correlations is a convex function of h (it's the smoothmax of linear functions). So we can solve:

minimize smoothmax_s(c_s + sum_j h[j]*(1 - h_t[j+s] - h_t[j-s]))
subject to 0 ≤ h ≤ 1, sum(h) = n/2

This is a convex optimization problem! We can solve it with SLSQP or even CVXPY (if we use the exact max, it's a SOCP).

Actually, if we use the exact max (not smoothmax), it's:
minimize t
subject to c_s + sum_j h[j]*(1 - h_t[j+s] - h_t[j-s]) ≤ t for all s
           0 ≤ h ≤ 1, sum(h) = n/2

This is a linear program! (The constraints are linear in h and t.)

LP at each SCA iteration! This is much faster than a QP.

Let me formalize the SCA-LP algorithm:
1. Initialize h_0 (from initial_h_values)
2. For t = 1, 2, ...:
   a. For each lag s, compute:
      - c_s = sum_i h_{t-1}[i]*h_{t-1}[i-s] (constant)
      - a_s[j] = 1 - h_{t-1}[j+s] - h_{t-1}[j-s] (coefficient of h[j])
      (with boundary handling: h[j+s] = 0 if j+s >= n, h[j-s] = 0 if j-s < 0)
   b. Solve LP:
      minimize t
      subject to c_s + sum_j a_s[j]*h[j] ≤ t for all s
                 0 ≤ h[j] ≤ 1
                 sum(h[j]) = n/2
   c. Set h_t = solution
3. Return h_T

This is elegant and potentially very effective! Each iteration is an LP with 2n+1 variables (h[0..n-1] and t) and 2n+1+2 = O(n) constraints.

For n=400: 801 variables, ~1601 constraints. CBC or GLPK can solve this in milliseconds.

The convergence of SCA is typically linear (if the problem is concave-convex, which it is: we're minimizing a function that's been linearized, and the original problem is non-convex but has special structure).

import numpy as np
from scipy.optimize import linprog
from scipy.interpolate import interp1d
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)

def project_feasible(h, target_sum):
    h = np.clip(h.copy(), 0.0, 1.0)
    diff = target_sum - h.sum()
    if abs(diff) > 1e-12:
        h = h + diff / len(h)
        h = np.clip(h, 0.0, 1.0)
    return h

def sca_lp_iteration(h_prev, n):
    """One SCA iteration: linearize and solve LP."""
    dx = 2.0 / n
    np_lags = 2 * n - 1  # number of correlation lags
    
    # Build LP: minimize t
    # Variables: h[0..n-1], t  → total n+1 variables
    # x = [h_0, h_1, ..., h_{n-1}, t]
    
    # Objective: minimize t → c = [0, 0, ..., 0, 1]
    c_obj = np.zeros(n + 1)
    c_obj[-1] = 1.0
    
    # Constraints:
    # 1) For each lag s: c_s + sum_j a_s[j]*h[j] ≤ t
    #    → c_s + sum_j a_s[j]*h[j] - t ≤ 0
    # 2) sum(h[j]) = n/2 (equality)
    # 3) 0 ≤ h[j] ≤ 1 (bounds)
    
    # Compute a_s[j] and c_s for each lag
    s_range = np.arange(-(n-1), n)  # -(n-1) to (n-1)
    
    A_rows = []
    b_rows = []
    
    for idx, s in enumerate(s_range):
        # corr_s = sum_i h[i]*(1-h[i-s]) linearized
        # = sum_i h[i] - sum_i h[i]*h[i-s]
        # ≈ sum_i h[i] - sum_i (h_prev[i]*h[i-s] + h[i]*h_prev[i-s] - h_prev[i]*h_prev[i-s])
        # = sum_i h[i]*(1 - h_prev[i-s]) - sum_i h_prev[i]*h[i-s] + sum_i h_prev[i]*h_prev[i-s]
        
        # Let me recompute the coefficient of h[j]:
        # From sum_i h[i]: contributes 1 to h[j]
        # From -sum_i h_prev[i]*h[i-s]: h[j] appears when i-s=j, i=j+s
        #   contributes -h_prev[j+s] (valid when 0<=j+s<n)
        # From -sum_i h_prev[i-s]*h[i]: h[j] appears when i=j
        #   contributes -h_prev[j-s] (valid when 0<=j-s<n)
        # Constant: sum_i h_prev[i]*h_prev[i-s]
        
        a = np.ones(n)  # from sum_i h[i]
        c_const = 0.0
        
        if s >= 0:
            # h[i-s] valid when i >= s, i.e., i in [s, n-1]
            # -sum_{i=s}^{n-1} h_prev[i]*h[i-s]:
            #   h[j] appears when i-s=j, i=j+s, valid when j+s < n, i.e., j < n-s
            #   coefficient: -h_prev[j+s]
            for j in range(n - s):
                a[j] -= h_prev[j + s]
            # -sum_i h_prev[i-s]*h[i]:
            #   h[j] appears when i=j, valid when j-s >= 0, i.e., j >= s
            #   coefficient: -h_prev[j-s]
            for j in range(s, n):
                a[j] -= h_prev[j - s]
            # Constant: sum_{i=s}^{n-1} h_prev[i]*h_prev[i-s]
            c_const = np.dot(h_prev[s:], h_prev[:n-s])
        elif s < 0:

            # -sum_{i=0}^{n-1-t} h_prev[i]*h[i+t]:
            #   h[j] appears when i+t=j, i=j-t, valid when j-t >= 0, i.e., j >= t
            #   coefficient: -h_prev[j-t]
            for j in range(t, n):
                a[j] -= h_prev[j - t]
            # -sum_i h_prev[i+t]*h[i]:
            #   h[j] appears when i=j, valid when j+t < n, i.e., j < n-t
            #   coefficient: -h_prev[j+t]
            for j in range(n - t):
                a[j] -= h_prev[j + t]
            # Constant: sum_{i=0}^{n-1-t} h_prev[i]*h_prev[i+t]
            c_const = np.dot(h_prev[:n-t], h_prev[t:])
        else:
            # s = 0: corr_0 = sum_i h[i]*(1-h[i])
            # ≈ sum_i h[i] - sum_i (h_prev[i]*h[i] + h[i]*h_prev[i] - h_prev[i]^2)
            # = sum_i h[i]*(1 - 2*h_prev[i]) + sum_i h_prev[i]^2
            a = 1.0 - 2.0 * h_prev
            c_const = np.sum(h_prev**2)
        
        # Constraint: c_const + a @ h ≤ t
        # → c_const + a @ h - t ≤ 0
        row = np.zeros(n + 1)
        row[:n] = a
        row[-1] = -1.0
        A_rows.append(row)
        b_rows.append(-c_const)
    
    # Equality: sum(h) = n/2
    eq_row = np.zeros(n + 1)
    eq_row[:n] = 1.0
    A_rows.append(eq_row)
    b_rows.append(n / 2.0)
    
    A = np.array(A_rows)
    b = np.array(b_rows)
    
    # Inequality constraints: A_ineq @ x ≤ b_ineq (for the corr constraints)
    # Equality: A_eq @ x = b_eq
    n_ineq = 2 * n - 1
    A_ineq = A[:n_ineq]
    b_ineq = b[:n_ineq]
    A_eq = A[n_ineq:n_ineq+1]
    b_eq = b[n_ineq:n_ineq+1]
    
    # Bounds: 0 ≤ h[j] ≤ 1, t is free (or t ≥ 0)
    bounds = [(0, 1)] * n + [(0, None)]
    
    from scipy.optimize import linprog
    result = linprog(c_obj, A_ub=A_ineq, b_ub=b_ineq, A_eq=A_eq, b_eq=b_eq,
                     bounds=bounds, method='highs')
    
    if result.success:
        h_new = result.x[:n]
        t_val = result.x[-1] * dx
        return h_new, t_val
    else:
        return h_prev.copy(), compute_c5(h_prev)

def linearize_corr(h_t, s, n):
    """Return (a, c) where linearized corr_s ≈ c + a @ h."""
    a = np.zeros(n)
    if s >= 0:
        lo, hi = s, n - 1
    else:
        lo, hi = 0, n - 1 + s  # = n - 1 - |s|
    
    i_range = np.arange(lo, hi + 1)
    # h[i-s] for i in i_range
    idx_sub = i_range - s  # these are i-s, all in [0, n-1]

    a[i_range] += (1.0 - h_t[idx_sub])
    # a[i-s] -= h_t[i] for i in i_range
    a[idx_sub] -= h_t[i_range]
    
    return a, c

1. Linearize the non-convex part
2. Solve the resulting convex problem
3. Accept the new point if it doesn't increase the original objective (which it shouldn't, by the properties of the linearization)

Actually, by the properties of the first-order Taylor expansion, for a function f that is the difference of two convex functions, the linearization at x_t gives an upper bound on f in a neighborhood. So the SCA iteration should be non-increasing in the original objective (at least locally).

But in practice, for the max of bilinear functions, the linearization might not be a valid upper bound everywhere. So I should check: if compute_c5(h_new) > compute_c5(h_t), reject the step and try a smaller step.

        h = np.clip(h, 0.0, 1.0)
    return h

def sca_lp_iter(h_t, n):
    """One SCA iteration using LP."""
    a_rows = []
    c_vals = []
    
    for s in range(-(n-1), n):
        a = np.zeros(n)
        if s >= 0:
            lo, hi = s, n - 1
        else:
            lo, hi = 0, n - 1 + s
        i_range = np.arange(lo, hi + 1)
        idx_sub = i_range - s
        c_val = float(np.dot(h_t[i_range], h_t[idx_sub]))
        a[i_range] += (1.0 - h_t[idx_sub])
        a[idx_sub] -= h_t[i_range]
        a_rows.append(a)
        c_vals.append(c_val)
    
    a_arr = np.array(a_rows)  # shape (2n-1, n)
    c_arr = np.array(c_vals)  # shape (2n-1,)
    
    # LP: minimize t
    # s.t. c_s + a_s @ h ≤ t  for all s
    #      sum(h) = n/2
    #      0 ≤ h ≤ 1
    # Variables: [h_0, ..., h_{n-1}, t]
    
    c_obj = np.zeros(n + 1)
    c_obj[-1] = 1.0
    
    # Inequality: a_s @ h - t ≤ -c_s
    A_ub = np.hstack([a_arr, -np.ones((2*n-1, 1))])
    b_ub = -c_arr
    
    # Equality: sum(h) = n/2
    A_eq = np.zeros((1, n + 1))
    A_eq[0, :n] = 1.0
    b_eq = np.array([n / 2.0])
    
    bounds = [(0, 1)] * n + [(0, None)]
    
    res = linprog(c_obj, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq,
                  bounds=bounds, method='highs')
    
    if res.success:
        return res.x[:n], res.x[-1]
    return h_t.copy(), None

from scipy.interpolate import interp1d

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)

def project_feasible(h, target_sum):
    h = np.clip(h.copy(), 0.0, 1.0)
    diff = target_sum - h.sum()
    if abs(diff) > 1e-10:
        h = h + diff / len(h)
        h = np.clip(h, 0.0, 1.0)
        diff2 = target_sum - h.sum()
        if abs(diff2) > 1e-10:
            free = (h > 1e-8) & (h < 1.0 - 1e-8)
            if free.sum() > 0:
                h[free] += diff2 / free.sum()
                h = np.clip(h, 0.0, 1.0)
    return h

def sca_lp_solve(h_t, n):
    """One SCA iteration: build and solve the LP relaxation."""
    n_lags = 2 * n - 1
    a_arr = np.zeros((n_lags, n))
    
    for idx, s in enumerate(range(-(n-1), n)):
        if s >= 0:
            i_range = np.arange(s, n)
        else:
            i_range = np.arange(0, n + s)
        if len(i_range) == 0:
            continue
        idx_sub = i_range - s
        a_arr[idx, i_range] += (1.0 - h_t[idx_sub])
        a_arr[idx, idx_sub] -= h_t[i_range]
    
    # Compute constants c_s
    c_arr = np.zeros(n_lags)
    for idx, s in enumerate(range(-(n-1), n)):
        if s >= 0:
            i_range = np.arange(s, n)
        else:
            i_range = np.arange(0, n + s)
        if len(i_range) == 0:
            continue
        idx_sub = i_range - s
        c_arr[idx] = float(np.dot(h_t[i_range], h_t[idx_sub]))
    
    # LP: min t s.t. a_s @ h - t <= -c_s, sum(h) = n/2, 0<=h<=1
    c_obj = np.zeros(n + 1)
    c_obj[-1] = 1.0
    
    A_ub = np.zeros((n_lags, n + 1))
    A_ub[:, :n] = a_arr
    A_ub[:, -1] = -1.0
    b_ub = -c_arr
    
    A_eq = np.zeros((1, n + 1))
    A_eq[0, :n] = 1.0
    b_eq = np.array([n / 2.0])
    
    bounds = [(0, 1)] * n + [(0, None)]
    
    res = linprog(c_obj, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq,
                  bounds=bounds, method='highs')
    
    if res.success:
        return res.x[:n]
    return h_t.copy()

def run_sca(h_init, max_iters=200, time_limit=60.0):
    h = h_init.copy()
    n = len(h)
    best_h = h.copy()
    best_c = compute_c5(h)
    t0 = time.time()
    
    for it in range(max_iters):
        if time.time() - t0 > time_limit:
            break
        h_new = sca_lp_solve(h, n)
        h_new = project_feasible(h_new, n/2)
        c_new = compute_c5(h_new)
        
        if c_new < best_c:
            best_h = h_new.copy()
            best_c = c_new
        
        # Accept if improvement or same
        if c_new <= best_c + 1e-10:
            h = h_new
        else:
            # Backtrack
            accepted = False
            for alpha in [0.5, 0.25, 0.1, 0.05]:
                h_trial = project_feasible((1-alpha)*h + alpha*h_new, n/2)
                if compute_c5(h_trial) <= best_c + 1e-10:
                    h = h_trial
                    accepted = True
                    break
            if not accepted:
                # Stay at current point, re-linearize
                pass
        
        if it > 20 and abs(compute_c5(h) - best_c) < 1e-10:
            break
    
    return best_h, best_c

def smoothmax_val_grad(h, beta):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    m = np.max(corr)
    shifted = corr - m
    exps = np.exp(beta * shifted)
    sw = np.sum(exps)
    w = exps / sw
    val = (m + np.log(sw) / beta) * dx
    grad = np.zeros(n)
    for idx, s in enumerate(range(-(n-1), n)):
        wk = w[idx]
        if wk < 1e-14:
            continue
        if s >= 0:
            i_range = np.arange(s, n)
        else:
            i_range = np.arange(0, n + s)
        if len(i_range) == 0:
            continue
        idx_sub = i_range - s
        grad[i_range] += wk * (1.0 - h[idx_sub])
        grad[idx_sub] += wk * (-h[i_range])
    grad *= dx
    return val, grad

def slsqp_refine(h, maxiter=200, beta=500.0):
    n = len(h)
    _beta = beta
    
    def obj(x):
        v, _ = smoothmax_val_grad(x, _beta)
        return v
    
    def grad(x):
        _, g = smoothmax_val_grad(x, _beta)
        return g
    
    bounds = Bounds(np.zeros(n), np.ones(n))
    cons = [{'type': 'eq', 'fun': lambda x: x.sum() - n/2, 'jac': lambda x: np.ones(n)}]
    
    try:
        res = minimize(obj, h, jac=grad, method='SLSQP', bounds=bounds,
                      constraints=cons, options={'maxiter': maxiter, 'ftol': 1e-14})
        if res.success:
            return project_feasible(res.x, n/2)
    except:
        pass
    return project_feasible(h.copy(), n/2)

def binary_local_search(h_init, n, max_swaps=5000, time_limit=30.0):
    """Local search on binary sequences."""
    t0 = time.time()
    # Round to binary (threshold at 0.5, adjust to get exactly n/2 ones)
    sorted_idx = np.argsort(-h_init)
    h_bin = np.zeros(n)
    h_bin[sorted_idx[:n//2]] = 1.0
    
    best_bin = h_bin.copy()
    best_c = compute_c5(h_bin)
    
    for _ in range(max_swaps):
        if time.time() - t0 > time_limit:
            break

        ones = np.where(h_bin == 1.0)[0]
        zeros = np.where(h_bin == 0.0)[0]
        i = np.random.choice(ones)
        j = np.random.choice(zeros)
        h_bin[i], h_bin[j] = 0.0, 1.0
        c = compute_c5(h_bin)
        if c < best_c:
            best_c = c
            best_bin = h_bin.copy()
        else:
            h_bin[i], h_bin[j] = 1.0, 0.0  # undo
    
    return best_bin, best_c

def interp_to_n(h, n_new):

    x_old = (np.arange(n_old) + 0.5) * (2.0 / n_old)
    x_new = (np.arange(n_new) + 0.5) * (2.0 / n_new)

    return project_feasible(h_new, n_new / 2.0)

import numpy as np
from scipy.optimize import linprog, minimize, Bounds
from scipy.interpolate import interp1d
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)

def project_feasible(h, target_sum):
    h = np.clip(h.copy(), 0.0, 1.0)
    diff = target_sum - h.sum()
    if abs(diff) > 1e-10:
        h = h + diff / len(h)
        h = np.clip(h, 0.0, 1.0)
        d2 = target_sum - h.sum()
        if abs(d2) > 1e-10:
            free = (h > 1e-9) & (h < 1.0 - 1e-9)
            if free.sum() > 0:
                h[free] += d2 / free.sum()
                h = np.clip(h, 0.0, 1.0)
    return h

def sca_lp_solve(h_t, n):
    n_lags = 2 * n - 1
    a_arr = np.zeros((n_lags, n))
    c_arr = np.zeros(n_lags)
    for idx, s in enumerate(range(-(n-1), n)):
        if s >= 0:
            i_range = np.arange(s, n)
        else:
            i_range = np.arange(0, n + s)
        if len(i_range) == 0:
            continue
        idx_sub = i_range - s
        a_arr[idx, i_range] += (1.0 - h_t[idx_sub])
        a_arr[idx, idx_sub] -= h_t[i_range]
        c_arr[idx] = float(np.dot(h_t[i_range], h_t[idx_sub]))
    c_obj = np.zeros(n + 1)
    c_obj[-1] = 1.0
    A_ub = np.zeros((n_lags, n + 1))
    A_ub[:, :n] = a_arr
    A_ub[:, -1] = -1.0
    b_ub = -c_arr
    A_eq = np.zeros((1, n + 1))
    A_eq[0, :n] = 1.0
    b_eq = np.array([n / 2.0])
    bounds = [(0, 1)] * n + [(0, None)]
    res = linprog(c_obj, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq,
                  bounds=bounds, method='highs')
    if res.success:
        return res.x[:n]
    return h_t.copy()

def run_sca(h_init, max_iters, time_limit):
    h = h_init.copy()
    n = len(h)
    best_h = h.copy()
    best_c = compute_c5(h)
    t0 = time.time()
    stall = 0
    for it in range(max_iters):
        if time.time() - t0 > time_limit:
            break
        h_new = sca_lp_solve(h, n)
        h_new = project_feasible(h_new, n / 2.0)
        c_new = compute_c5(h_new)
        if c_new < best_c - 1e-12:
            best_h = h_new.copy()
            best_c = c_new
            stall = 0
        else:
            stall += 1
            if stall > 30:
                # Perturb and reset stall counter
                h = project_feasible(h + np.zeros(n), n / 2.0)
                break
        if c_new <= best_c + 1e-9:
            h = h_new
        else:
            accepted = False
            for alpha in [0.5, 0.25, 0.1]:
                ht = project_feasible((1 - alpha) * h + alpha * h_new, n / 2.0)
                ct = compute_c5(ht)
                if ct <= best_c + 1e-9:
                    h = ht
                    accepted = True
                    break
            if not accepted:
                h = h  # stay
    return best_h, best_c

def smoothmax_val_grad(h, beta):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    m = np.max(corr)
    shifted = corr - m
    exps = np.exp(beta * shifted)
    sw = np.sum(exps)
    w = exps / sw
    val = (m + np.log(sw) / beta) * dx
    grad = np.zeros(n)
    for idx, s in enumerate(range(-(n-1), n)):
        wk = w[idx]
        if wk < 1e-14:
            continue
        if s >= 0:
            i_range = np.arange(s, n)
        else:
            i_range = np.arange(0, n + s)
        if len(i_range) == 0:
            continue
        idx_sub = i_range - s
        grad[i_range] += wk * (1.0 - h[idx_sub])
        grad[idx_sub] += wk * (-h[i_range])
    grad *= dx
    return val, grad

def slsqp_refine(h, maxiter, beta):
    n = len(h)
    def _obj(x):
        v, _ = smoothmax_val_grad(x, beta)
        return v
    def _grad(x):
        _, g = smoothmax_val_grad(x, beta)
        return g
    def _con(x):
        return x.sum() - n / 2.0
    def _conjac(x):
        return np.ones(n)
    bounds = Bounds(np.zeros(n), np.ones(n))
    cons = [{'type': 'eq', 'fun': _con, 'jac': _conjac}]
    try:
        res = minimize(_obj, h, jac=_grad, method='SLSQP', bounds=bounds,
                       constraints=cons, options={'maxiter': maxiter, 'ftol': 1e-14})
        if res.success:
            return project_feasible(res.x, n / 2.0)
    except Exception:
        pass
    return project_feasible(h.copy(), n / 2.0)

def binary_local_search(h_init, n, max_swaps, time_limit):
    t0 = time.time()
    sorted_idx = np.argsort(-h_init)
    h_bin = np.zeros(n)
    h_bin[sorted_idx[:n // 2]] = 1.0
    best_bin = h_bin.copy()
    best_c = compute_c5(h_bin)
    ones = np.where(h_bin == 1.0)[0]
    zeros = np.where(h_bin == 0.0)[0]
    for _ in range(max_swaps):
        if time.time() - t0 > time_limit:
            break
        i = np.random.choice(ones)
        j = np.random.choice(zeros)
        h_bin[i], h_bin[j] = 0.0, 1.0
        c = compute_c5(h_bin)
        if c < best_c:
            best_c = c
            best_bin = h_bin.copy()
            ones = np.where(h_bin == 1.0)[0]
            zeros = np.where(h_bin == 0.0)[0]
        else:
            h_bin[i], h_bin[j] = 1.0, 0.0
    return best_bin, best_c

def interp_to_n(h, n_new):
    n_old = len(h)
    x_old = (np.arange(n_old) + 0.5) * (2.0 / n_old)
    x_new = (np.arange(n_new) + 0.5) * (2.0 / n_new)
    if n_old < 4:
        h_new = np.interp(x_new, x_old, h)
    else:
        f = interp1d(x_old, h, kind='cubic', fill_value='extrapolate', assume_sorted=True)
        h_new = f(x_new)
    h_new = np.clip(h_new, 0.0, 1.0)
    return project_feasible(h_new, n_new / 2.0)

def run(seed=42, budget_s=1100, **kwargs):
    np.random.seed(seed)
    t0 = time.time()
    def tl():
        return budget_s - (time.time() - t0)
    if 'initial_h_values' in globals() and initial_h_values is not None:
        h_best = np.array(initial_h_values, dtype=float).copy()
    else:
        h_best = np.full(400, 0.5)
    best_c5 = compute_c5(h_best)
    n = len(h_best)
    # Phase 1: SCA from initial
    if tl() > 80:
        h_s, c_s = run_sca(h_best, 500, min(150, tl() - 40))
        if c_s < best_c5:
            h_best, best_c5 = h_s, c_s
    # Phase 2: Binary local search + SCA from binary
    if tl() > 80:
        h_bin, c_bin = binary_local_search(h_best, n, 15000, 30)
        if c_bin < best_c5:
            h_best, best_c5 = h_bin, c_bin
        h_s2, c_s2 = run_sca(h_best, 400, min(100, tl() - 30))
        if c_s2 < best_c5:
            h_best, best_c5 = h_s2, c_s2
    # Phase 3: Multi-resolution SCA
    for n_try in [200, 300, 500, 600, 800]:
        if tl() < 120:
            break
        h_i = interp_to_n(h_best, n_try)
        h_s3, c_s3 = run_sca(h_i, 300, min(80, tl() - 40))
        if c_s3 < best_c5:
            h_best, best_c5 = h_s3, c_s3
            n = n_try
    # Phase 4: SLSQP polish
    for beta in [200, 500, 1000]:
        if tl() < 40:
            break
        h_p = slsqp_refine(h_best, 250, beta)
        c_p = compute_c5(h_p)
        if c_p < best_c5:
            h_best, best_c5 = h_p, c_p
    # Phase 5: SCA refinement on best
    if tl() > 60:
        h_s5, c_s5 = run_sca(h_best, 400, min(120, tl() - 30))
        if c_s5 < best_c5:
            h_best, best_c5 = h_s5, c_s5
    # Phase 6: Another binary diversification
    if tl() > 80:
        scale = 0.3
        pert = np.random.randn(len(h_best)) * scale
        h_pert = project_feasible(h_best + pert, len(h_best) / 2.0)
        h_bin2, c_bin2 = binary_local_search(h_pert, len(h_best), 10000, 20)
        if c_bin2 < best_c5:
            h_best, best_c5 = h_bin2, c_bin2
        h_s6, c_s6 = run_sca(h_best, 300, min(80, tl() - 30))
        if c_s6 < best_c5:
            h_best, best_c5 = h_s6, c_s6
    # Phase 7: Final SLSQP
    if tl() > 30:
        h_f = slsqp_refine(h_best, 300, 2000)
        c_f = compute_c5(h_f)
        if c_f < best_c5:
            h_best, best_c5 = h_f, c_f
    # Final feasibility
    h_best = project_feasible(h_best, len(h_best) / 2.0)
    best_c5 = compute_c5(h_best)
    return h_best, best_c5, len(h_best)
