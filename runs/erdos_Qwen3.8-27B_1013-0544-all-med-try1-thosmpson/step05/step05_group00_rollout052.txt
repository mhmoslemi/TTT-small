            if s < 1e-14:

            if s < 1e-14:

def slsqp_optimize(h, n, alpha, maxiter, deadline):
    dx = 2.0 / n
    def obj(x):
        g = np.correlate(x, 1 - x, mode='full') * dx
        m = g.max()
        sh = alpha * (g - m)
        sm = sh.max()
        return m + (sm + np.log(np.exp(sh - sm).sum())) / alpha
    res = minimize(obj, h, method='SLSQP',
                   bounds=[(0.0, 1.0)] * n,
                   constraints=[{'type': 'eq', 'fun': lambda x: x.sum() - n/2.0}],
                   options={'maxiter': maxiter, 'ftol': 1e-14})
    return project_feasible(res.x, n)

For pairwise CD, the key operation is:
- Given current h, pick a pair (i, j)
- Let s = h[i] + h[j] (this must be preserved)
- Let a = s/2, so h[i] = a + t, h[j] = a - t
- t ∈ [max(-a, a-1), min(a, 1-a)] = [-min(a, 1-a), min(a, 1-a)]
- Find t* that minimizes max_k c_k(t) where c_k(t) is the correlation at lag k

Since c_k(t) is linear in t, the max is convex PL, and we can find the minimum by:
1. Evaluating at the endpoints and a few interior points
2. Or using ternary search
