The issue is: with random swaps, we're making O(1) improvement per step on average, which is too slow. We need a more targeted approach.

**Better approach: Use the correlation structure to guide swaps.**

For the current max lag k*, the contributions to corr[n-1+k*] are:
corr[n-1+k*] = sum_{m=0}^{n-1-k*} h[m+k*](1-h[m])

Each term h[m+k*](1-h[m]) is either 0 or 1 (for binary h). The "active" terms are those where h[m+k*]=1 and h[m]=0.

To reduce corr[n-1+k*], we can:
1. Change h[m+k*] from 1 to 0 (for some active m): this reduces corr[n-1+k*] by 1
   - But it might increase other lags
2. Change h[m] from 0 to 1 (for some active m): this reduces corr[n-1+k*] by 1
   - But it might increase other lags

Both require a swap (to maintain the constraint sum(h) = n/2).

So the strategy is:
- For option 1: choose a "1" position p = m+k* (where h[p]=1 and h[p-k*]=0), and swap it with some "0" position q.
- For option 2: choose a "0" position q = m (where h[m]=0 and h[m+k*]=1), and swap it with some "1" position p.

In both cases, the "primary" position (p or q) directly reduces S_{k*} by 1. The "secondary" position should be chosen to minimize the increase in other lags.

**Choosing the secondary position:**
If we swap the primary position with secondary position s:
- The change to S_{k*} is -1 (from the primary) + (change from secondary)
- The change from secondary depends on s's position relative to k*

For the secondary position s (going 0→1 if primary is a 1-being-removed, or 1→0 if primary is a 0-being-added):
- If s+k* is a 1 and h[s]=0: S_{k*} increases by 1 (bad!)
- If s-k* is a 0 and h[s]=1: S_{k*} increases by 1 (bad!)

So we want the secondary position s such that:
- h[s+k*] = 0 (if s is going 0→1) OR h[s-k*] = 1 (if s is going 0→1)
- i.e., the secondary position doesn't add to S_{k*}

And ideally, it reduces some other S_{k'} that's close to the max.

This gives us a candidate generation strategy:
1. Identify "primary" positions that directly reduce S_{k*}
2. For each primary, find "good" secondary positions
3. Evaluate the full swap and pick the best

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h, n):
    dx = 2.0 / n
    return float(np.max(np.correlate(h, 1-h, mode='full')) * dx)

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h, 0.0, 1.0)
    for _ in range(300):
        diff = target - h.sum()
        if abs(diff) < 1e-13:
            break
        if diff > 0:
            m = h < 1.0
            c = m.sum()
            if c == 0:
                break
            h[m] = np.minimum(1.0, h[m] + diff / c)
        else:
            m = h > 0.0
            c = m.sum()
            if c == 0:
                break
            h[m] = np.maximum(0.0, h[m] + diff / c)
    return np.clip(h, 0.0, 1.0)

def to_binary(h, n):
    t = n // 2
    b = np.zeros(n)
    b[np.argsort(-h)[:t]] = 1.0
    return b

def swap_delta(h, a, b, n, d):
    delta = np.zeros(2 * n - 1)
    va = (a + d >= 0) & (a + d < n)
    delta[va] -= (1.0 - h[a + d[va]])
    va2 = (a - d >= 0) & (a - d < n)
    delta[va2] += h[a - d[va2]]
    vb = (b + d >= 0) & (b + d < n)
    delta[vb] += (1.0 - h[b + d[vb]])
    vb2 = (b - d >= 0) & (b - d < n)
    delta[vb2] -= h[b - d[vb2]]
    return delta

def slsqp_lp(h, n, p, maxiter, deadline):
    dx = 2.0 / n
    def obj(x):
        g = np.correlate(x, 1 - x, mode='full') * dx
        return np.sum(g**p) ** (1.0 / p)
    def cf(x):
        return x.sum() - n / 2.0
    try:
        r = minimize(obj, h, method='SLSQP', bounds=[(0, 1)] * n,
                     constraints=[{'type': 'eq', 'fun': cf}],
                     options={'maxiter': maxiter, 'ftol': 1e-14})
        return project_feasible(r.x, n)
    except Exception:
        return h

def slsqp_max(h, n, alpha, maxiter, deadline):
    dx = 2.0 / n
    def obj(x):
        g = np.correlate(x, 1 - x, mode='full') * dx
        m = g.max()
        sh = alpha * (g - m)
        sm = sh.max()
        return m + (sm + np.log(np.exp(sh - sm).sum())) / alpha
    def cf(x):
        return x.sum() - n / 2.0
    try:
        r = minimize(obj, h, method='SLSQP', bounds=[(0, 1)] * n,
                     constraints=[{'type': 'eq', 'fun': cf}],
                     options={'maxiter': maxiter, 'ftol': 1e-14})
        return project_feasible(r.x, n)
    except Exception:
        return h

        ones = np.where(h == 1)[0]

        if len(ones) == 0 or len(zeros) == 0:

        active_from = []
        active_to = []
        if k_star >= 0:

        mp_off = k_star

            da = swap_delta(h, a, b, n, d)

            if nm < best_delta:

                cur_max = corr.max()
                stall = 0
