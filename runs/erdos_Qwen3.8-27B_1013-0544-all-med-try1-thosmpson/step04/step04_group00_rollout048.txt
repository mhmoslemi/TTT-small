We need to vectorize this. For a given swap (i,j), we can compute the delta for all lags at once using numpy:

```python
def delta_for_swap(h, i, j, n):
    """Compute delta_g for all lags when swapping h[i]:0->1, h[j]:1->0"""
    lags = np.arange(-(n-1), n)  # 2n-1 lags
    # i as "0" position (removing): -1 where h[i+lag]=1
    i_plus = i + lags
    term1 = np.where((i_plus >= 0) & (i_plus < n), -h[i_plus].astype(int), 0)
    # j as "1" position (removing): -1 where h[j-lag]=0
    j_minus = j - lags
    term2 = np.where((j_minus >= 0) & (j_minus < n), -(1-h[j_minus]).astype(int), 0)
    # i as "1" position (adding): +1 where h[i-lag]=0
    i_minus = i - lags
    term3 = np.where((i_minus >= 0) & (i_minus < n), (1-h[i_minus]).astype(int), 0)
    # j as "0" position (adding): +1 where h[j+lag]=1
    j_plus = j + lags
    term4 = np.where((j_plus >= 0) & (j_plus < n), h[j_plus].astype(int), 0)
    
    delta = term1 + term2 + term3 + term4
    
    # Fix special cases where i+lag == j or j+lag == i
    # ℓ = j-i: i+lag = j
    idx = j - (n-1)  # index of lag (j-i) in the lags array
    if 0 <= idx < 2*n-1:
        delta[idx] = -2  # special case
        # Plus corrections from items 3 and 4
        c3 = 2*i - j
        if 0 <= c3 < n:
            delta[idx] += (1 - h[c3])  # h[i-lag] after = h[2i-j], but h[j] changed to 0
            # Wait, in the special case ℓ=j-i, i-lag = i-(j-i) = 2i-j
            # h[2i-j] is unchanged (unless 2i-j = i, i.e., i=j, impossible)
            # And h[2i-j] after = h[2i-j] before (unchanged)
        c4 = 2*j - i
        if 0 <= c4 < n:
            delta[idx] += h[c4]
    
    # ℓ = i-j: j+lag = i
    idx2 = i - (n-1)  # index of lag (i-j)
    if 0 <= idx2 < 2*n-1:
        delta[idx2] = 2  # base from items 3 and 4
        c1 = 2*i - j
        if 0 <= c1 < n:
            delta[idx2] -= h[c1]  # -[h[2i-j]=1 before]
        c2 = 2*j - i
        if 0 <= c2 < n:
            delta[idx2] -= (1 - h[c2])  # -[h[2j-i]=0 before]
    
    return delta
```

This is O(n) per swap but vectorized, so it's fast. For n=250, it's about 499 array operations per swap, which numpy handles in ~50μs. With 31000 swaps per sweep, that's ~1.5s per sweep. With 100 sweeps, that's 150s. Feasible!
