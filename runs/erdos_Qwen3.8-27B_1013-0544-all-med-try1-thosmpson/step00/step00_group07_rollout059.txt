∂f/∂h[i] = dx * (1/t) * (∑_k exp(t*c_k) * ∂c_k/∂h[i]) / (∑_k exp(t*c_k))

where p_k = exp(t*c_k - t*max_c) / ∑_j exp(t*c_j - t*max_c).

Now, ∂c_k/∂h[i]:
For the k-th element of the full correlate (0-indexed), let lag = k - (n-1).
c_k = ∑_j h[j] * (1-h[j-lag]) where both j and j-lag must be in [0, n-1].

The partial derivative ∂c_k/∂h[i]:
- If i is the "first" index (j = i): contributes (1 - h[i-lag]) if 0 ≤ i-lag < n
- If i is the "second" index (j-lag = i, so j = i+lag): contributes -h[i+lag] if 0 ≤ i+lag < n

So ∂c_k/∂h[i] = (1 - h[i-lag]) * [0 ≤ i-lag < n] - h[i+lag] * [0 ≤ i+lag < n]

This can be computed in O(n) for a single (k, i) pair, but we need it for all k and i.

Total computation: for each i (n values), for each k (2n-1 values), compute ∂c_k/∂h[i]. That's O(n²) ≈ 12800 operations. Very fast.

grad[i] = dx * ∑_k p_k * ((1 - h[i-lag_k]) * [valid] - h[i+lag_k] * [valid])

where lag_k = k - (n-1).

For the 1D problem: minimize max_k (c_k + d*α_k) over d = v - old ∈ [-old, 1-old].

This is the minimum of the upper envelope of lines. The minimum occurs where the maximum of the "rising" lines equals the maximum of the "falling" lines (at the crossing point), or at a boundary.

Algorithm:
1. Separate k into "rising" (α_k > 0), "falling" (α_k < 0), and "flat" (α_k = 0)
2. The flat lines give a constant lower bound: max_flat = max(c_k for α_k=0)
3. Among rising lines, the max at d=0 is max(c_k for α_k>0), and it increases with d
4. Among falling lines, the max at d=0 is max(c_k for α_k<0), and it decreases with d
5. The optimum d is where max_rising(d) = max_falling(d) (or at a boundary)

This can be solved in O(n log n) time. But for n=80, even O(n²) is fine.

Simple approach: 
- max_rising(d) = max_{k: α_k>0} (c_k + d*α_k)
- max_falling(d) = max_{k: α_k<0} (c_k + d*α_k)
- We want min_d max(max_rising(d), max_falling(d), max_flat)

Since max_rising is increasing in d and max_falling is decreasing in d, the optimum is where they cross (or at a boundary). Binary search on d!

This is efficient: O(n * log(1/eps)) per coordinate.

```python
def _eval_c5(c, dx):
    return float(np.max(c) * dx)

def _compute_correlate(h):

    """Compute how correlate changes when h[i] changes by 1 unit."""
    n = len(h)
    length = 2 * n - 1
    alpha = np.zeros(length)
    # For each lag k (0 to 2n-2), lag_value = k - (n-1)
    for k in range(length):

        # h[i-lag] contribution: (1 - h[i-lag]) if 0 <= i-lag < n
        if 0 <= i - lag < n:
            alpha[k] += (1.0 - h[i - lag])
        # h[i+lag] contribution: -h[i+lag] if 0 <= i+lag < n
        if 0 <= i + lag < n:
            alpha[k] -= h[i + lag]
```

```python
def _minimax_1d(c, alpha, d_lo, d_hi):
    """Find d in [d_lo, d_hi] that minimizes max_k (c[k] + d*alpha[k])."""
    n = len(c)
    # Compute all intersection points
    best_d = 0.0
    best_val = np.max(c)
    
    # Check boundaries
    vals_lo = np.max(c + d_lo * alpha)
    vals_hi = np.max(c + d_hi * alpha)
    if vals_lo < best_val:
        best_val = vals_lo
        best_d = d_lo
    if vals_hi < best_val:
        best_val = vals_hi
        best_d = d_hi
    
    # Check all intersection points
    for i in range(n):
        for j in range(i+1, n):
            if alpha[i] == alpha[j]:
                continue
            d = (c[j] - c[i]) / (alpha[i] - alpha[j])
            if d_lo <= d <= d_hi:
                val = np.max(c + d * alpha)
                if val < best_val:
                    best_val = val
                    best_d = d
    
    return best_d, best_val
```

```python
    Uses the fact that g(d) is convex and piecewise-linear."""
    n = len(c)
    
    # The subgradient of g at d is conv{alpha[k] : c[k] + d*alpha[k] = g(d)}
    # g is minimized where 0 is in the subgradient
    
    def g(d):
        return np.max(c + d * alpha)
    
    def subgrad_contains_zero(d):
        vals = c + d * alpha
        gval = np.max(vals)
        active = np.where(np.abs(vals - gval) < 1e-12)[0]
        return np.min(alpha[active]) <= 0 <= np.max(alpha[active])
    
    # Binary search
    lo, hi = d_lo, d_hi
    for _ in range(60):
        mid = (lo + hi) / 2
        vals = c + mid * alpha
        gval = np.max(vals)
        active = np.where(np.abs(vals - gval) < 1e-10)[0]
        min_alpha = np.min(alpha[active
        max_alpha = np.max(alpha[active])
        
        if min_alpha > 0:
            # All active have positive slope → g is increasing → move left
            hi = mid
        elif max_alpha < 0:
            # All active have negative slope → g is decreasing → move right
            lo = mid
        else:
            # 0 is in subgradient → we're at the minimum
            return mid, gval
    
    # Return best of lo, hi
    g_lo = np.max(c + lo * alpha)
    g_hi = np.max(c + hi * alpha)
    if g_lo <= g_hi:

    else:
        return hi, g_hi
```

Wait, there's a numerical issue: the tolerance for "active" might cause problems. Let me use a slightly different approach:

The subgradient of g at d is the set of all weighted averages of alpha[k] for k achieving the max. The slope of g from the right is max{alpha[k] : k active from the right}, and from the left is min{alpha[k] : k active from the left}.

Actually, for a piecewise-linear convex function, the subgradient at a non-kink point is a singleton (the slope of the active line). At a kink point, it's the interval between the slopes of the two adjacent lines.

The function is minimized where the slope changes from negative to positive, i.e., where 0 is in the subgradient.

A cleaner binary search:
- At d, compute g(d) and find all k that achieve g(d)
- If all such k have alpha[k] > 0: the function is strictly increasing at d, so optimum is to the left → hi = d
- If all such k have alpha[k] < 0: the function is strictly decreasing at d, so optimum is to the right → lo = d
- If there's a mix (some positive, some negative): d is at a kink and is the optimum

The only issue is numerical: what if no k exactly achieves the max (due to floating point)? In that case, I should use a tolerance.

Let me implement this carefully:

```python
def _minimax_1d(c, alpha, d_lo, d_hi, tol=1e-10):
    n = len(c)
    
    # Handle edge cases
    if d_lo >= d_hi - tol:
        return d_lo, np.max(c + d_lo * alpha)
    
    lo, hi = d_lo, d_hi
    
    for _ in range(80):
        mid = (lo + hi) * 0.5
        vals = c + mid * alpha
        gval = np.max(vals)
        
        # Find active set (within tolerance)
        active = np.abs(vals - gval) < tol
        if not np.any(active):
            # Shouldn't happen, but handle it
            active = np.abs(vals - gval) < 1e-8
        
        a_min = np.min(alpha[active])
        a_max = np.max(alpha[active])
        
        if a_min > 0:
            hi = mid  # g is increasing, go left
        elif a_max < 0:
            lo = mid  # g is decreasing, go right
        else:
            return mid, gval  # 0 in subgradient
    
    # Return the better of lo, hi
    g_lo = np.max(c + lo * alpha)
    g_hi = np.max(c + hi * alpha)
    if g_lo <= g_hi:
        return lo, g_lo
    return hi, g_hi
```
