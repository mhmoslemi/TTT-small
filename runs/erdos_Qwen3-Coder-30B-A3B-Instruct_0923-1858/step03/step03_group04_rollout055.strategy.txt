## 2. Mathematical specification

### Decision variables
- $h \in \mathbb{R}^{n_p}$: step function values at $n_p$ points
- $dx = \frac{2}{n_p}$: sample spacing

### Objective function
Minimize:
\[
C_5 = \max_k \left( \sum_{i=0}^{n_p-1} h[i](1 - h[(i+k) \mod n_p]) \times dx \right)
\]
where $k$ ranges over all possible integer offsets $[-n_p+1, n_p-1]$

### Constraints
1. $\forall i, 0 \leq h[i] \leq 1$
2. $\sum_{i=0}^{n_p-1} h[i] = \frac{n_p}{2}$

### PSO dynamics
Each particle $p$ maintains:
- Position $h_p$
- Velocity $v_p$
- Personal best $h_p^{best}$
- Global best $h_g^{best}$

Update rules:
\[
v_p[i] = w v_p[i] + c_1 \epsilon_1 (h_p^{best}[i] - h_p[i]) + c_2 \epsilon_2 (h_g^{best}[i] - h_p[i])
\]
\[
h_p[i] = \text{clip}(h_p[i] + v_p[i], 0, 1)
\]
where $\epsilon_1, \epsilon_2 \sim U(0,1)$

### Feasibility projection
After updates, enforce sum constraint:
\[
h_{feasible}[i] = \frac{\text{clip}(h[i], 0, 1)}{\sum \text{clip}(h, 0, 1)} \times \frac{n_p}{2}
\]
