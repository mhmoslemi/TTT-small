## 1. Approach and Rationale

The core idea is to adopt a generalized pattern search method initialized with the parent sequence (`height_sequence_1`) to explore the optimization landscape more effectively than the previous gradient-based approaches. Gradient-based methods, while powerful, can easily get trapped in local minima due to noisy gradient estimates from FFT approximations, especially at scales associated with the simplex projection. This problem becomes more pronounced as the dimensionality increases, leading to slower convergence and suboptimal solutions. By contrast, a pattern search leverages a set of increasingly divergent directions from a current point, allowing for careful exploration without relying on gradient calculations, which can be expensive in terms of computational time due to the FFT convolutions required for objective evaluation.

This strategy is based on the Nelder–Mead method generalized to multiple points, which is affine-invariant and requires minimal gradient information. The key rationale is that by using a fixed point set and updating it based on function evaluations, we can escape shallow local minima and find a better global minimum for the AC1 upper bound. The original parent sequence provides a strong starting heuristic, and we aim to improve upon it by iteratively expanding the search radius around the current best candidate.

Important limitations include:
- The method may still converge to a local minimum if the initial point is poor or the search region is too large.
- Some of the initial variation steps might result in worse evaluations, so we include a mechanism to abort if the objective does not improve significantly.
- The computational budget is tight (1100s), but the algorithm is designed to balance exploration and exploitation, completing iterations even under time pressure.

Asymptotic improvement is expected over the previous gradient-based approach by leveraging a structured hyper-rectangle search that avoids the high computational cost of gradient approximation. This is backed by the fact that direct gradient descent often stagnates near the simplex centroid, while pattern search explores borders more effectively.

def _project_simplex(v):
    # v is a 1D NumPy array of coefficients
    n = v.size
    # Project onto simplex w.r.t. the constraint sum(x)=1 and x[0] >= 0 to 1000
    # Extract valid range as per evaluator
    a_clipped = np.clip(v, 0.0, 1000.0)
    S = np.sum(a_clipped)
    if S < 0.01:
        a_clipped *= (0.01 / S) if S != 0 else 1.0  # Scale to have sum>0.01 if needed
    a_normalized = a_clipped / S
    # Apply simplex projection
    # Using the standard self-orthogonal basis, solve by three steps
    u = np.sort(a_normalized)[::-1]
    css = np.cumsum(u) - 1.0
    rho = np.where(u <= 1+css/np.arange(1, len(u)+1))[0]
    if rho.size == 0:
        theta = u[-1]  # approximate nave eta
    else:
        rho = rho[-1]
    theta = css[rho] / (rho+1)
    return np.maximum(u - theta, 0) / theta
