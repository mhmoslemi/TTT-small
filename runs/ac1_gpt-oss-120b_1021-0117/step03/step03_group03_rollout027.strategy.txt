### 1. Approach and Rationale  
We address the problem of minimizing the AC1 upper bound for a non-negative step-function sequence using an adaptive gradient-based optimization algorithm. The previous program used a momentum-assisted projected gradient descent with a top-k gradient sampling scheme. However, our approach enhances this by:  

- **Gradient Refinement**: Instead of sampling k gradient indices, we use a complex gradient calculation based on the entire convolution to ensure precise gradient information is captured.  
- **Adaptive Regularization**: We introduce a dynamic regularization term to stabilize convergence during optimization, reducing the risk of premature plateaus.  
- **Efficient Transitions**: We implement careful interpolation checks and directional updates to ensure smooth transitions in the optimization path.  

The core idea is to iteratively adjust the sequence using gradient information from the full convolution calculation, ensuring convergence to a local or global minimum of the AC1 upper bound.  

### 2. Mathematical Specification  
Given a sequence `a` of length `n`, the objective to minimize is:  

\[
\min_{a \in \mathbb{R}_+^n} \left( \frac{2n \cdot \|\mathbf{a} * \mathbf{a}\|_\infty}{(\sum_{i} a_i)^2} \right)
\]  

**Variables**:  
- **a**: Non-negative sequence of coefficients of length `n`.  
- **n**: Length of the sequence (fixed or derived from parent if available).  

**Gradient Calculation**:  
The gradient of the objective with respect to each coefficient \(a_i\) is derived from the convolution peaks. For each position `k` in the convolution result, the gradient contribution is:  

\[
g_i = \sum_{\substack{k \text{ s.t.} \\ b_k = \text{max}(\mathbf{b})}} a_{k-i} \cdot \mathbf{1}_{\{k-i \in [0, n)\}}
\]  

**Constraints**:  
- Non-negativity: \(a_i \ge 0 \ \forall i\).  
- Unit mass: \(\sum_i a_i = 1\) (achieved via normalization).  

**Active Set Management**:  
The active set of gradient indices is determined by the top `k` largest values in the convolution result.
