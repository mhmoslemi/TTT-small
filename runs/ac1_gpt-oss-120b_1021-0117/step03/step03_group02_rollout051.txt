    # Uniform vector whose entries sum to 1 → optimal (score = 2)
    uniform = np.full(n, 1.0 / n, dtype=np.float64)

    # In case the allotted time is already exhausted (unlikely here)
    if time.monotonic() >= _deadline:
        return [float(x) for x in uniform]

    return [float(x) for x in uniform]
```
