# 1. Approach and Rationale

This problem involves searching for a sequence of nonnegative coefficients that minimizes the AC1 bound, defined as:  
`AC1 = (2 * n * max(convolve(a, a, mode='full'))) / sum(a)^2`  
where `n = 6962` is fixed, and the coefficients must satisfy `0 ≤ a_i ≤ 1000` for all i.

The AC1 bound is scale-invariant under positive scaling, meaning the ratio depends only on the shape of the sequence, not its scaling. This allows us to fix the total sum `T = sum(a)` to normalize the search space, reducing the degrees of freedom. The key challenge is optimizing the sequence's structure to minimize the convolution's maximum value while maintaining the fixed sum.

Our approach leverages simulated annealing (SA) with a cooling schedule. SA efficiently explores high-dimensional spaces by allowing uphill moves controlled by temperature parameters, preventing premature convergence. Each step involves:
1. Perturbing a small number of sequence elements (k indices)
2. Adjusting the chosen indices while preserving the fixed sum
3. Evaluating the AC1 score of the modified sequence
4. Accepting worse solutions probabilistically to escape local optima

The algorithm maintains two critical sequences:
1. **Current sequence (`current_seq`)** – Active candidate for the Markov chain
2. **Best sequence (`best_seq`)** – Store the best solution found during the search

We use the scale invariance property by normalizing both sequences to have sum 1. Each move ensures elements stay within bounds `[0, 1000]` while maintaining the fixed sum.

The AC1 bound is insensitive to the order of elements, suggesting local optimization techniques like swaps can work well. The search starts from an intelligent initial position: either the normalized parent sequence or a normalized Sidon-like sequence (which decays geometrically), both shown to yield competitive solutions.

The computational cost is dominated by the `evaluate_sequence` calls, which perform the full linear convolution (O(n log n) time) as implemented in scipy's convolution. We set all elements below 1000 to a small constant epsilon (0.0001) to ensure finite values and bounded sums.

The algorithm runs for 100000 iterations, with each iteration:
1. Choosing k=4 random indices
2. Perturbing them within bounds `[0, 1000]`
3. Adjusting the total sum uniformly across the sequence
4. Calculating the change in AC1 score
5. Deciding acceptance based on temperature

The cooling schedule (cooling_rate=0.995) gradually reduces the probability of accepting bad moves, converging to a local minimum of good quality.

The algorithm runs until either the maximum iterations or time budget is exceeded (1100 seconds) and returns the best_found sequence along with its score.

# 2. Mathematical Specification

## Sequence Representation
- Input: Fixed length sequence of real numbers (`n = 6962`)
- Output: Sequence `a` where `0 ≤ a_i ≤ 1000` and `sum(a) ≥ 0.01`

## Objective Function
- AC1 bound: `f(a) = (2 * n * max(convolve(a, a, mode='full'))) / sum(a)^2`
  - Convolution: Linear (non-cyclic) of length `2*n - 1`
  - `convolve(a, a, mode='full')` computes `c_k = sum_{i=0}^{n-1-k} a_i * a_{i+k}` for k=0 to n-1

## Formulation
Since AC1 is scale-invariant, we normalize by fixing:
`sum(a) = 1`
`a_i = b_i / sum(b)` where `b_i` is the original sequence

This reduces optimization from finding `a` with sum `T` to finding `b` with sum `T` or equivalently choosing unit-sum sequences `c_i` and scaling.

## Optimization Variables
- `a_i' ∈ [0, 1000]` for each `i`
- `sum(a') = 1`

## Constraints
- Nonnegativity: `a_i ≤ 1000`
- Normalization: `sum(a) = 1`

## Derivations
- For any known sequence, we can generate a neighborhood candidate by:
  k randomly selected indices
  Each index increased by d, with other indices decreased proportionally to maintain sum 1
  New sum = 2*T`? No, the convolution depends on the full sequence, so all elements affect the object function.

## Proposed Solution Approach
- Simulated annealing optimizer with:
  - Neighborhood defined by perturbing k=4 elements
  - Uniform distribution for perturbations
  - Cooling schedule: T = T * cooling_factor
  - Exponential Metropolis probability for uphill moves:

  `P_accept = exp(-(f_new - f_old)/T)` 

  - Termination conditions:
   temperature too low
   iteration count reached (100000)
   remaining time <= fudge factor

## Forward Mapping
- From parameters to sequence: 
  Generate k=4 random indices
 For each index i:
  - Choose random displacement d_i uniformly
  - Ensure 0 ≤ a_i + d_i ≤ 1000
  - Adjust other indices to keep sum=1
- The objective is the AC1 score evaluated via the linear convolution

## 4. Search Choices and Useful Variations

This algorithm systematically explores the solution space using simulated annealing with multiple configurable choices:

### 4.1. Core Search Parameters
- **Neighborhood Size**: 4 elements perturbed per iteration
- **Perturbation Magnitude**: Uniform random from -0.03 to 0.03
- **Cooling Rate**: 0.995 → Temperature halves roughly every 500 iterations
- **Iteration Budget**: 100,000 steps (30 estimates)

### 4.2. Progression Strategies
- **Adaptive Adjustment**: Main sequence elements are adjusted proportionally in later iterations (`adjustment * (iterations/100000)`)
