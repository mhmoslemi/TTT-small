Approach and rationale
We aim to minimize the AC1 upper bound score defined by the evaluator. The score is scale-invariant, so we can fix the sum of the sequence to 1 and minimize the maximum value of the autocorrelation convolution, which is directly proportional to the score without rescaling. Our optimization method combines iterative updates with exponential cooling and momentum to efficiently explore the space of probability distributions on the simplex. This approach balances exploration and exploitation while maintaining computational feasibility.

Mathematical specification
Our algorithm optimizes the normalized sequence vector `a` (length `n`) constrained to the probability simplex (nonnegative components summing to 1). The score to minimize is `S(a) = 2 * n * max_{k} (convolve(a, a)[k]) / (sum(a))^2`. By fixing `sum(a) = 1`, `S(a) = 2 * n * max_{k} (convolve(a, a)[k])`.

The optimization iteration:
1. Start with an initial sample `a_cur` from the simplex
2. Compute convolution via FFT
3. Compute maximum convolution value `m`
4. Apply softmax weighting to active convolution points
5. Estimate gradient using weighted convolution
6. Update sequence with projected gradient step
7. Apply exponential random restarts with optional symmetry bias

def project_simplex(v):
    """Project onto the probability simplex"""
    v_np = np.asarray(v, dtype=np.float64)
    n = v_np.size
    u = np.sort(v_np)[::-1]
    css = np.cumsum(u) - 1.0 / np.arange(1, n + 1)
    rho = np.where(u - css > 0)[0]
    if rho.size == 0:
        theta = 0.0
    else:
        rho = rho[-1]
        theta = css[rho] / (rho + 1)
        w = u - theta
        w[w < 0] = 0.0
        return w / w.sum()
    return np.ones(n) / n
