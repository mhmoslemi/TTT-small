### Approach and Rationale
The core idea is to:
1. Use MCTS to explore promising states (coefficients)
2. Use a DQN to provide value estimates for transitions
3. Employ a fast objective evaluation using FFT to guide exploration

This differs from gradient-based methods by viewing the problem as a search in a massive state space, leveraging RL's ability to handle non-convex spaces and long-term dependencies. The method iteratively balances exploration vs exploitation, prioritizing sequences that lower the AC1 bound.

### Mathematical Specification
- **State Representation**: A coefficient sequence of fixed length (2535) represented as a normalized vector
- **Actions**: Linear transformations (scaling, permutation, noise injection)
- **Objective Function**: Minimize AC1 score given by 2*n*max(convolution) / (sum(a))^2
- **Transition Dynamics**:
  - Apply action to state to get new state
  - Compute action-value function (Q-value) based on successor state's AC1
- **Policy**:
  - Greedy + exploration (ε-greedy)
  - Value update: Q(s,a) ← Q(s,a) + α[r + γ max_a' Q(s',a') - Q(s,a)]

### Implementation Procedure
1. **Initialization**:
   - Start with parent vector (if available)
   - Normalize to unit simplex
   - Initialize DQN, replay buffer

2. **Experience Collection**:
   - From current state, select 5 children states via action set
   - Each action: 
     - Scale (0.1×-2.0) 
     - Permute (random segment)
     - Inject noise (Laplace/Gaussian)
     - Project to simplex

3. **DQN Update**:
   - Minimize loss: L = E[(Q(s,a) - y(s,a))^2] where y(s,a)=r + γ*max_a' Q(s',a')
   - Batch size: 64
   - Target network: update every 100 steps
   - Epsilon: 0.3→0.1 over 2000 steps

4. **Selection**:
   - UCB = Q(s,a) + sqrt(ln(N(s)) / N(a))
   - Select action with highest UCB

5. **Termination**:
   - Early exit if target bound achieved
   - Fallback to tabular search if DQN diverges

- **Action Types**: 7 basic transformations (7 discrete actions)
- **Value Network**: Multi-layer perceptron (3 layers, 128 hidden units)
- **Experience Replay**: 10K warmup, polyak averaging
- **Transition Frequency**: Each state explores 5 transitions

### Budget and Robustness
