We are going to design a bilevel optimization strategy that iteratively updates a reference vector and a steering vector, using linear programming (LP) to find the steering vector that minimizes the AC1 score under the current reference vector. The key difference from the parent program is that we explicitly formulate and solve an LP in each iteration to guide the update. We will use the exact evaluator to validate candidates and update our best candidate whenever an improvement is found.

### Approach and Rationale
The central idea is to use bilevel optimization: the upper level (steering) LP defines a vector that, under the constraint that its convolution with the current reference vector does not exceed a given threshold, maximizes the sum of the steering vector (which, when scaled down, indicates a direction of potential decrease in the AC1 score). The lower level updates the reference vector by combining it with the steering vector in a randomized scale. This approach leverages the LP's ability to provide structured updates that can escape local minima more effectively than gradient-based methods alone.

The algorithm starts with a parent vector (if available) and then iteratively solves an LP to generate a steering vector. The steering vector is then used to generate one or more candidates by a stochastic linear combination, which are evaluated using the exact evaluator. The best candidate (lowest AC1 score) is tracked throughout the iterations. The procedure stops when the time budget is exhausted or a sufficiently low score is achieved.

This approach is chosen because bilevel optimization with LP provides a direct way to enforce constraints and can lead to significant improvements in the AC1 score compared to gradient-based methods. However, the LP may be computationally expensive, so we limit the number of iterations and hope to converge in under 1100 seconds.

### Mathematical Specification
- **Representation**: 
  - Let `f` be the reference vector of length `n` (initially set to the parent vector if available, otherwise a random vector).
  - The steering vector `g` is the solution to an LP with variables `g_j >= 0` for `j=0,...,n-1`.

- **Objective** (Upper Level):
  - Minimize: `-sum(g_j)`   (or equivalently, maximize `sum(g_j)`)
  - Subject to: `convolve(f, g)[k] <= M` for every `k`, where `M = max(convolve(f, f))`, i.e., the maximum autocorrelation of the reference vector `f`.
  - `g_j >= 0` for all `j`.

- **Update Rule** (Lower Level):
  - Given `g` from the LP, we update the reference vector as:
    `f_new = t * f + (1 - t) * g`
    where `t` is a uniform random variable in `[0, 1]`.
  - To maintain nonnegativity and the units simplex (for the LP constraints to be consistent), we also project the updated vector to the nonnegative orthant and (if necessary) normalize it.

- **Constraints and Objective Direction**:
  - The constraint `convolve(f, g)[k] <= M` ensures that the convolution of the reference vector `f` and the steering vector `g` at lag `k` does not exceed the maximum autocorrelation of `f`. This constraint is linear in `g`.
  - The objective is to maximize `sum(g_j)` which, under the constraints, gives a vector `g` that is "aligned" with the current reference vector `f` and leads towards a decrease in the AC1 score.
