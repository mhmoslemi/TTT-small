### Approach and rationale

We use a projected gradient method with momentum to minimize the AC1 bound. The core idea is to approximate the gradient of the maximum autocorrelation using an FFT-based softmax weighting, then update the vector toward lower scores. This allows us to efficiently search the space of nonnegative sequences while maintaining computational tractability. The simplex projection ensures the sequence remains valid (nonnegative, bounded, and normalized). 

The method combines elements of the parent program with enhanced exploration through periodic symmetrization and random redistribution. We optimize performance by using FFT-based convolution and gradient computation, which reduces time complexity compared to dense methods. The algorithm balances exploration and exploitation by cooling the gradient sparsity over time and occasionally accepting worse candidates (simulated annealing).

### Mathematical specification

**Variables**: A sequence `a` of length `n` (fixed to 2535), representing a nonnegative step-like function.

**Objective**: Minimize 
  `score(a) = 2 * n * max_{k} (convolve(a, a, mode="full")[k] / (sum(a))**2`
with `sum(a) >= 0.01` and `a_i ∈ [0, 1000]`.

**Surrogate gradient**: Compute the gradient approximation based on the softened maximum autocorrelation:
  Let `C = convolve(a, a, mode="full")`
  Let `m = max(C)`
  Let `w = exp((C - m) / temp)`  (softmax-like weights)
  The gradient is `∇score(a) = 2 * ∇_{a} [max_k C[k]] / (sum(a))**2`

**Constraints**: Enforce by projecting gradients to the nonnegative simplex `∑a_i = S` (fixed to 1), `a_i ≥ 0`.

**Complexity**: O(T * n log n) per iteration, dominated by FFT operations.
