### Approach and rationale
The core idea is to minimize the AC1 upper bound by using a disciplined search algorithm that combines global exploration with local refinement. The optimization focuses on sequences that natural biological signals might exhibit—abrupt transitions, tapered ends, and structured patterns. This strategy explicitly balances exploration across three distinct search regions: 
1. Patches with controlled heights representing biological-like structures,
2. Mixed-length signal portions from parent sequence clustering,
3. Randomly generated valid candidates with simplex structure to avoid local minima.  
The key novelty is using simplex-induced scaling for temperature adaptation and incorporating soft-constrained optimization to handle non-differentiable points in the autocorrelation. This ensures we escape shallow convex regions while preserving mathematical consistency with the evaluator's objective function.

### Mathematical specification
Let \(\\mathbf{a} = (a_0, a_1, \\dots, a_{n-1})\) be the optimization variables with simplex constraint \(\\sum_j a_j = 1\) and \(a_j \\geq 0\). The exact objective is \(\\theta(\\mathbf{a}) = 2n \\cdot \\max_k c_{\\text{full}}(k)\), where \(c_{\\text{full}}\) is the full convolution of \(\\mathbf{a}\). While optimizing, we approximate the maxima using temperature-dependent softmax surrogates: 
\[
w_j = \frac{\\exp\\left((c_j - \\max_c) / \\tau\\right)}{\\sum_k \\exp\\left((c_k - \\max_c) / \\tau\\right)}
\]
The projected gradient then measures the rate of change:
\[
\\nabla \\theta \\approx \\sum_j w_j \\nabla c_j
\]
All operations must respect convolution definitions via linear FFTs with length \(L = 2^n\), and the simplex projection is enforced via the Euclidean projection algorithm.
