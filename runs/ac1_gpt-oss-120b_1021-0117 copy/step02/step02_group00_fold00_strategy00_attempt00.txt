2. Mathematical specification
   **Variables and representation:** 
   - \( f, g, \ldots \): coefficient sequences of length \( n \) starting from the parent or 256 (for sqrt).
   - Each sequence is simplex-normalized (sum=1) and nonnegative.
   - The score is computed via exact linear convolution: score(f) = 2n * max_k (f* f)[k] / (sum(f))².

   **Core LP problem:** Given current sequence \( f \) (sum=1), let M = max_k (f* f)[k]. 
   - Solve: maximize ∑j bj over bj ≥ 0 and ∑i f[i] b[k-i] ≤ M for each k.
   - Let g0 be the solution, and set g = (10 * g0) / sum g0 (for stability against extreme values).
   - New candidate = 0.9*f + 0.1*g.

   **LP sparse representation:** Since convolution is Toeplitz, express constraints as sparse 
   matrix to avoid storing dense matrices. This uses O(n²) storage but remains within memory limits for n ~ 2500.

   **Output construction:** Return the simplex-normalized best sequence upon termination.

3. Implementation procedure
   **Sequence:**
   - `propose_candidate()`: main function with timer and hybrid algorithm.
   - `_project_simplex()`: Project to L1 unit simplex.
   - `_conv_fft()`: Convolve with single FFT for score and gradient computation.
   - `_score()`: Compute score using `_conv_fft`.

   **Steps:**
   1. Read parent initialization or generate sqrt series.
   2. Normal:ize to simplex by row int norm(1).
   3. Track best time-score pair.
   4. Loop until time: 
      - Fraction of iterations (80%) do gradient descent (steepest decent).
      - 10% do LP move usage.
      - 10% occasional reshuffling.
   5. Use exact score acceptance (not gradient).
   6. Return best list.

   **Security checks:** clip to [0, 1000] done by `_score()`, and time-outs must not slip.

4. Search choices and useful variations
   **Default:** 
      - Initial length: 256 (sqrt) if no parent.
      - Max length: parent's length (2535).

   **Gradation strategy:**
      - Gradient steps: decrease alpha0 over runs.
      - LP steps: taken at probability 1/10, costing ~15-30s.

   **Variations:**
      - Allow different mixing ratios in arbitrary size.
      - Observe score trends: transitioning to more aggressive steps.

5. Compute budget and robustness
   **Estimate:** 
      - One LP solve: ~0.3*n² operations. For n=2535, ~1.6e9 operations worst-case, but sparse reduce to ~6e6 nonzeros.
      - Gradient: O(n log n) for FFT.
      - Budget for 10 LP: 10 * 30s = 300s leavens 800s for gradient.
   **Early Exit:** If best score < target break.

   **Fallback:** Maintain best valid candidate with score not exceeding 1.518.

6. Validation and return contract
   **Checks:** `_score()` always validates candidates.
   **Output:** Only return best sequence found as list.
   **Sanity:** 
      - Initial verification (via score) against parent.
      - No synthetic data allowed.

#------------------------------------------------------------#Euclidean projection onto the simplex{x>=0, sum(x)=1}#------------------------------------------------------------ 
def _project_simplex(v:np.ndarray)->np.ndarray:
    "" "Project v onto the probability simplex."
    n = v.size
    u = np.sort(v)[::-1]
    css = np.cumsum(u) - 1.0
    rho = np.where(u - css[:n] / np.arange(1, n+1) > 0)[0]
    if rho.size == 0:
        theta = 0.0
    else:
        rho = rho[-1]
        theta = css[rho] / (rho + 1)
    w = np.maximum(v - theta, 0.0)
    return w

#------------------------------------------------------------#Fast convolution via FFT (full linear convolution)#------------------------------------------------------------ 
def _conv_fft(a:np.ndarray)->np.ndarray:
    n = a.shape[0]
    L = 1 << ((2*n - 1)).bit_length()  # Round up to next power of 2
    fv = np.fft.rfft(a, n=L)
    conv = np.fft.irfft(fv * fv, n=L)[:2*n-1]
    return conv

    conv = _conv_fft(a)

    sum_a = np.sum(a)
    return float(2 * n * max_b / (sum_a ** 2))
