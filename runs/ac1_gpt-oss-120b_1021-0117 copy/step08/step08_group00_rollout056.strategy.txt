### Approach and Rationale

The central idea is to optimize a non-negative step-function sequence to minimize the AC1 upper bound using enhanced linear programming and structured perturbation techniques. Unlike previous programs relying on simulated annealing and projection onto the simplex (sum=1), this approach leverages exact linear programming (LP) to reformulate the autocorrelation constraint. The key innovation is linearizing the max-constraint found in `evaluate_sequence` using a dual technique, enabling efficient gradient-free optimization. 

Limitations: 
- The core algorithm requires sparse-to-dense matrix multiplications, which we implement via a block-sparse structure
- Must explicitly account for the 2×n-1 convolution points in the objective function
- Requires careful handling to avoid O(n²) allocation

### Mathematical Specification

We represent sequences as X ∈ ℝⁿ⁺ (n=2535) with constraints:
- Non-negativity: x_i ≥ 0 ∀i
- Magnitude: 0 ≤ x_i ≤ 1000
- Sum constraint: ∑x_i ≥ 0.01
- Binary autocorrelation: minimize max_{k} |(X * X)[k]| / (∑x_i)²

We approximate the max-constraint with:
```
minimize t
subject to |(X * X)[k]| ≤ t * (∑x_i)², ∀k ∈ [0, 2n-2]
```
via variables t (temporal scaling) and Y_k (autocorrelation factors).

### Implementation Procedure

**Parent Handling**:
1. If `height_sequence_1` present, reshape to nD array (keep δ=20% energy)
2. Else generate uniform random noise

**Core Algorithm**:
1. **Representation**: Block-sparse encoding using non-negative hierarchical matrices
2. **LP Initialization**: Reshape 2535 coefficients into blocks of size b
3. **Block-Spectral Optimization**:
   - Convolve blocks via discrete sine transform (DST)
   - Compute energy vectors W_j = DST(X_j * X_j)
   - Solve:
```
minimize max_j W_j.max()
subject to sum_j W_j ≥ 0.01(8)
```
4. **Update Rule**:
   For block b, update entry i via:
```
∆x_i = -λ * sign(gradients[i])
CAND_i = max(0, X_i + α * ∆x_i)
```
5. **Constraint Handling**:
   Prescient projection via iterative spectral normalization:
```
λ ← atan(λ * β)  [stabilize gradient step]
α ← 1.0 / (1.0 + λ²)  [damp step size]
```

**Termination**:
- Track best solution from all iterations
- Return sequence after exact evaluation
