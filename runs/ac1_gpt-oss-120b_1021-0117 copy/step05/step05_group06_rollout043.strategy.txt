## 1. Approach and rationale

The core idea is to evolve high-performance sequences using differential evolution while maintaining nonnegativity and coefficient limits. Unlike gradient-based methods, this approach is derivative-free and exploit rarestructural patterns. The polynomial drift random walk initialization samples energy-efficient architectures. The search uses tournament selection to favor candidates with lower AC1 scores. The block sparsity incorporates knowledge that successful sequences have concentrated structure, both temporally and spatially. The algorithm adapts its parameters based on local progress, scaling populations during slow convergence and introducing disruptive mutations during plateau phases. The stopping condition hybridizes evaluation count, time budget, and score improvement barriers.

## 2. Mathematical specification

*   **Variables**:
    *   `batch_size` = int: Number of candidates per generation
    *   `population_size = batch_size * num_blocks`
    *   `evaluator(sequence): float` = Authoritative AC1 upper bound function
    *   `n = len(sequence)` with `n>=1`

*   **Objective**: Minimize `f(x) = evaluate_sequence(x)[0]` over the domain `{x | x_i ∈ [0,1000]∀i, ∑x_i ≥ 0.01}`

*   **Algorithm**: Differential evolution with constraints and structured mutation.

*   **Feasibility Handling**: Candidates violating nonnegativity or coefficient limits are repaired via projected gradient optimization from a neighboring point.

*   **Constraints Enforcement**:
    1.  Nonnegativity: `x_i = max(0, x_i)` for all `i`
    2.  Upper Bound: `x_i = min(1000, x_i)` for all `i`
    3.  Sum: If ∑`x_i < 0.01`, penalize by returning `np.inf` immediately

*   **Special Cases**: When `n=0`, return `[1000.0]` (or `np.inf` if evaluator invalidates)
