## 1. Approach and Rationale
The central idea is to evolve a nonnegative sequence using a hybrid perturbation strategy that balances global exploration with fine-tuning. We start from the provided parent sequence and iteratively improve its AC1 score by applying two types of perturbations: global re-sampling which explores the search space broadly, and local refinement which exploits promising regions. This approach escapes local minima while ensuring each candidate remains valid and within bounds. The method mimics physical processes where sequences temporarily invert (repulsive phase) followed by natural evolution toward optimal configurations.

We address dimensionality ($n=6733$) by using purely sequential operations that require $O(n)$ time per candidate. The AC1 minimization targets sequences whose self-convolution maxima are reduced relative to their sum, leveraging differential evolution principles with exponential smoothing and adaptive block sizes.

Key innovations include:
- Block-mirroring for enhanced symmetry
- Adaptive perturbation magnitudes based on progress
- Dynamic block selection spanning multiple scales
- Soft restarts via repulsive moves

## 2. Mathematical Specification
Sequences $a \in \mathbb{R}^n$ represent coefficients with $0 \leq a_i \leq 1000$. The objective is to minimize:
$$ \text{AC1}(a) = \frac{2n \cdot \max_k |(a \star a)[k]|}{(\sum_{i} a_i)^2} $$

where $\star$ denotes full linear convolution (length $2n-1$).

Constraints:
- Nonnegativity: $a_i \geq 0$ for all $i$
- Upper bound: $a_i \leq 1000$ for all $i$

Representation:
- Initial: Provided $height\_sequence\_1$ of length 6733
- Candidates: Transformed parent sequences via block operations

We explicitly track:
- $positions$: (start, length) tuple for block operations
- $amplitudes$: Scaling factors in [-0.5, 2.0]
- $center_frequency$: Base frequency parameter for repulsive moves

            candidate[start:] = pert
            score = evaluate_func(candidate)
            tries -= 1
            break
            
        if score < best_score:
            best_score = score
            best_seq = candidate.copy()
            tries = 3
            # Warm restart on progressive improvement
            if best_score < 1.7 and n_iter % 50 == 0:
                print("Acclimating optimal frequencies...")
                restart_bandwidth = 0.5 + np.random.rand() * 0.5

        remaining_time = deadline - time.time()
        if remaining_time < 30:  # Fall back to cautious refinement
            if remaining_time < 10:
                break
            tries = 1
    
    return best_seq.tolist()

def interpolate_vectors(v1, v2, rng):
    """Create interpolation between two vectors"""
    t = 1.0 - np.exp(-np.random.rand() * 5)
    return v1 + t * (v2 - v1) / (1 - t + 1e-4)

def smooth(v, alpha=1.0):
    """Apply smoothing or slight perturbation"""
    if alpha >= 1.0:
        # Direct perturbation
        return v * np.exp(rng.normal(0.0, 0.15 * (alpha-1), len(v)))
    else:
        # Frequency smoothing
        v_freq = np.fft.rfft(v)
        v_freq = v_freq * (1 - np.exp(-np.linspace(0, np.log(5), len(v_freq)) * (1-alpha)))
        return np.fft.irfft(v_freq)
