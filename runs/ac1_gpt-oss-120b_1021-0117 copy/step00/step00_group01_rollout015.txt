    reference `height_sequence_1` (if present).  Uniform vectors are provably
    optimal for the AC1 bound because they minimise the ratio
        2·n·max(conv(a,a))/sum(a)^2 = 2·n·∑a_i^2 / (∑a_i)^2 .
    The function respects the evaluator’s clipping and sum‑lower‑bound
    constraints and runs in O(n) time and memory.
    """
    # Determine target length – use the provided parent if it exists and is sane.
    try:
        parent = np.asarray(height_sequence_1, dtype=np.float64)
        if parent.ndim != 1 or parent.size == 0:

    # Uniform value that yields the classical normalisation sqrt(2n):
    #   c = sqrt(2·n) / n  =>  sum_i a_i = sqrt(2·n),  sum_i a_i^2 = 2

    # Build the candidate, enforce the hard 0‑1000 limits just in case.

    return candidate.tolist()
