1. Approach and Rationale

The central idea is to minimize the AC1 upper bound, defined as 2*n*max(convolve(a))[0]/ (sum(a))², using gradient-based optimization. Unlike the previous uniform distribution and local search, this approach uses a projected gradient descent method to efficiently explore the search space. The search space is constrained to non-negative sequences of length `n` with sum at least 0.01, but to simplify the optimization, we restrict to sequences summing to exactly 1. 

The key improvement is a hybrid strategy that combines direct gradient computation via an efficient analytical method with projection onto the simplex (to maintain sum=1) and a dynamic step size adjustment to prevent numerical instability. This addresses the weakness of standard gradient descent's slow convergence in high-dimensional spaces. The method allows escaping local minima by incorporating stochastic perturbations.

2. Mathematical Specification

The objective is to minimize:
    J(a) = 2*n*max(convolve(a, a))[0] / (sum(a))²

Constraints:
    a_i ≥ 0 for all i (handled by projection if initialization is valid)
    sum(a) = 1 (enforced by projection)
    (1) also implies entries ≤ 1000 (post-hoc)

The gradient is computed as:
    Let c = convolve(a, a) (full mode convolution)
    Let k0 = argmax(c) (index where the maximum occurs)
    Then for each j:
        g[j] = 
            if j ≤ k0 and (k0 - j) is a valid index (0 ≤ k0 - j < n):
                2 * a[k0 - j]
            else:
                0

Updates are performed using a momentum-based gradient descent with adaptive step size (via cubic backtracking) and projection to the simplex sum=1 constraint.

3. Implementation Procedure

The algorithm proceeds as follows:

**a. Initialization**
- If `height_sequence_1` exists: Clip and normalize to sum=1

4. Search Choices and Variations

- **Initial Seed**: Draw uniformly from simplex unless parent sequence is provided, indicating known heritage.
- **Local-to-Global Balance**: Momentum-based updates (GAMMA=0.5) combined with periodic scattering (20th iteration chance)
- **Line Search Strategy**: Instead of backtracking we use fixed adaptive learning rate (alone) to reduce evaluator calls
- **Adaptive Step Size**: Transitions automatically between small steps (>0.001) and large jumps (>0.1) based on gradient magnitude
- **Randomization**: Progressive phase-shift varies through iterations (0.0 to 0.5 % of inputs) to introduce diversity
- **Constraint Handling**: Gradient descent with explicit sum enforcement and stochastic clipping

5. Compute Budget and Robustness

- **Primary Cost**: Two convolution operations per candidate evaluation (O(n^2 log n) → ~0.2 seconds per gradient update)
- **Secondary Cost**: Projection (O(n)) and numerical Jacobian → evaluation-intensive for large n (n=2535)
- **Maximum Iterations**: Adaptive (matches system constraints, but default 10000)
- **Fallback Strategy**: Uniform initialization plus re-normalization if numerical issues occur
- **Failure Tolerance**: Simple insertion/removal of repeated lbfgs updates
