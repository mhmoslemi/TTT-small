Approach and rationale
The central idea of this approach is to use bilevel optimization to iteratively update both a 'reference' vector and a 'steering' vector that helps minimize the AC1 upper bound. Unlike the parent program which relies purely on gradient-based updates, this method leverages linear programming (LP) to explicitly solve for directions that guarantee improvements in the AC1 bound. The constraints are based on the maximum autocorrelation (from evaluating the reference vector), while the object is to find a steering vector that is within the feasible region and has the highest possible sum under these constraints. Each iteration involves solving an LP to derive the steering vector, combining it with the reference vector via a randomized scale factor, and projecting the result onto the simplex. This method is expected to escape local minima more effectively than is gradient descent, which avoids the simplex projection since the updates naturally preserve positivity.
