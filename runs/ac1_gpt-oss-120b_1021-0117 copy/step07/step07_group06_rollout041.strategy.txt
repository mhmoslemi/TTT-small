1. Approach and Rationale
This strategy employs bilevel optimization to iteratively improve the step-function candidate by using an upper-level linear program (LP) to find a "steering vector" that reduces the autocorrelation coefficient upper bound (AC1). The AC1 is defined as 2*n*max(conv(a,a)) / (sum(a))^2 with nonnegative coefficients in [0,1000]. We use the upper-level LP to find a vector that minimizes the AC1 under a maximum autocorrelation constraint derived from the current vector. The lower-level update combines the current vector with the steering vector scaled stochastically, then reprojects onto the simplex (sum=1). This approach escapes local minima faster than gradient methods by leveraging global linear programming guidance, addressing the non-convex nature of the problem.

2. Mathematical Specification
- **Representation**: Current vector `f` ∈ ℝⁿ (simplex projection ensures sum=1). Steering vector `g` solution to:
  - minimize: -∑g_j (equivalent to maximizing the vector sum)
  - satisfy: (f * g)[k] ≤ M for all lags k, with M = max(conv(f,f))
  - and g_j ≥ 0
- **Updates**: Random combination: `f ← t*f + (1-t)*g` then Euclidean projection to simplex.
- **Constraints**: Full convolution (non-circular) with fixed lags, reliable per-entry calculation.
