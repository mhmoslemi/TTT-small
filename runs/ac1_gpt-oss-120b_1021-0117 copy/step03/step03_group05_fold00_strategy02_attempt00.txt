### Approach and rationale
We aim to minimize the AC1 upper bound by optimizing the sequence coefficients. The score is invariant to scaling, allowing us to optimize sequences with fixed sums (here, sum(a)=1) and then scale to [0,1000] beforehand. The optimizer uses Fast Fourier Transform (FFT) for efficient convolution evaluation, gradient projection onto a simplex to enforce non-negativity and sum constraints, and employs two main update rules: additive projection gradient descent and multiplicative exponential weighting. The search balances exploration with exploitiation to escape local optima and find a global minimum.

### Mathematical specification
**Representation:** sequences of length n (2535) with values in [0,1000], sum 1, and non-negative.  
**Objective:** minimize score = 2n * max(convolve(a,a)) / (sum(a))², where a is the sequence.  
**Constraints:** a_i ≥ 0, sum(a) ≥ 0.01 (handled by evaluator).  
**Formulation:** Use simplex (sum(a)=1) for optimization. The gradient is approximated using the top K convolution terms.  
**Solver:** Projected gradient with active set using FFT for convolution.

### Implementation procedure
1. **Initialization:** Use `height_sequence_1` if available, else start with a random simplex projection.
2. **Convolution:** FFT-based linear convolution for gradient approximation.
3. **Gradient:** Top K convolution terms determine gradient direction.
4. **Updates:** Additive (projected gradient) and multiplicative (exponential weighting) rules with restarts.
5. **Exploration:** Occasional random reshuffling to escape local optima.
6. **Validation:** Use evaluator for exact score checks.

def project_simplex(v):
    """Project a vector onto the simplex with sum=1 and non-negative elements."""
    n = len(v)
    s = np.cumsum(v)
    # If already on simplex, return
    total = np.sum(v)
    if abs(total - 1) < 1e-12:
        return v

    # Binary search for threshold t
    low, high = 0, max(v) if total > 0 else 0
    tol = 1e-12
    while high > low + tol:
        mid = (high + low) / 2
        # Compute sum of max(v_i - mid, 0)
        residual_sum = np.sum(np.maximum(v - mid, 0)) - 1
        if residual_sum > 0:
            high = mid
        else:
            low = mid
    # Apply projection
    while True:
        t = low
        new_v = np.maximum(v - t, 0)
        new_sum = np.sum(new_v)
        if new_sum <= 1 + 1e-10:
            return new_v
        else:
            t += 1e-3  # Small step

    V = np.fft.rfft(v_padded)
    conv = np.fft.irfft(V * V)
