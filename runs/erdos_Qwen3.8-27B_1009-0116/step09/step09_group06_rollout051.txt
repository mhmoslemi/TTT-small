2. Primal step: minimize φ(h) = Σ_k p_k * c_k(h) via projected gradient with Nesterov momentum
3. Dual step: p_k ← softmax(c_k(h)/α)
4. Iterate with decreasing α

This is essentially the classical approach for min-max problems. The advantage over log-sum-exp is that:
- The primal subproblem is exactly smooth (no approximation)
- The dual variable directly tells us which lags are "active"
- We can solve the primal exactly (or very accurately) for each dual update

Let me also add:
- Periodic random perturbations to escape local minima
- A final intensive local search phase

Let me also think about the dual update. In the primal-dual method:
- Primal: minimize over h (feasible set)
- Dual: maximize over p (simplex)

The Lagrangian is L(h, p) = Σ p_k c_k(h)
- Min over h gives the primal value
- Max over p (simplex) picks the worst c_k

For the dual update: p_k ∝ exp(c_k / α) (softmax)
As α → 0, this concentrates on the argmax.

The algorithm:
1. Initialize p uniformly
2. For each iteration:
   a. Solve (or approximately solve) min_h Σ p_k c_k(h) via PGD
   b. Update p ← softmax(c(h)/α)
3. Decrease α over iterations

def _wgrad(h, p, n):
    """Gradient of sum_k p[k]*c_k(h)*dx where c=correlate(h,1-h)"""
    dx = 2.0 / n
    g = np.zeros(n)
    for k in range(len(p)):
        wk = p[k] * dx
        if wk < 1e-14:

    return g
