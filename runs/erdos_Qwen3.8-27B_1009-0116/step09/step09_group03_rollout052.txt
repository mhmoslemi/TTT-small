- If i ≥ L: -Δ·h'[i-L]

But if i+L = j, then h'[i+L] = h'[j] = s-t (changed!), so the term is Δ·(1-(s-t))
If i-L = j, then h'[i-L] = h'[j] = s-t, so the term is -Δ·(s-t)

Similarly for j with -Δ:
- If j ≤ n-1-L: -Δ·(1-h'[j+L])
- If j ≥ L: +Δ·h'[j-L]

With special cases if j+L=i or j-L=i.

So the total change in c[k] for lag L:
Δc[L] = Δ · [(1-h[i+L]) - h[i-L]] - Δ · [(1-h[j+L]) - h[j-L]] + corrections for overlaps

where corrections account for:
- if i+L=j: use (1-(s-t)) instead of (1-h[j])
- if i-L=j: use (s-t) instead of h[j]  
- if j+L=i: use (1-t) instead of (1-h[i])
- if j-L=i: use t instead of h[i]

    return best_h, best_c

def run(seed=42, budget_s=1100, **kwargs):
    t0 = time.time()
    def _el(): return time.time() - t0
    rng = np.random.RandomState(seed)
    n = len(initial_h_values)
    h0 = _repair(np.array(initial_h_values, dtype=float).copy(), n)
    best_h = h0.copy(); best_c = _eval(h0)
    
    # Main optimization from initial
    d_main = t0 + budget_s * 0.55
    h1, c1 = _optimize(h0, n, seed, d_main)
    if c1 < best_c: best_c = c1; best_h = h1.copy()
    
    # Try perturbed restart
    if _el() < budget_s * 0.75:
        h2 = _repair(best_h + 0.02 * rng.randn(n), n)
        d2 = t0 + budget_s * 0.85
        h2, c2 = _optimize(h2, n, seed + 100, d2)
        if c2 < best_c: best_c = c2; best_h = h2.copy()
    
    # Another restart with different perturbation
    if _el() < budget_s * 0.92:
        h3 = _repair(best_h + 0.005 * rng.randn(n), n)
        d3 = t0 + budget_s * 0.97
        h3, c3 = _optimize(h3, n, seed + 200, d3)
        if c3 < best_c: best_c = c3; best_h = h3.copy()
    
    # Final fine coordinate descent
    if _el() < budget_s - 3:
        h_final, c_final = _coord_descent(best_h, 40000, rng, t0 + budget_s - 2)
        if c_final < best_c: best_c = c_final; best_h = h_final.copy()
    
    best_h = _repair(best_h, n)
    best_c = _eval(best_h)
    return (best_h, best_c, n)
