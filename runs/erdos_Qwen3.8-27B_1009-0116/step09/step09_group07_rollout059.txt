        lo_d = max(-h[i], h[j] - 1.0)

            h[j] -= d_opt

- At a given t, compute f(t) and the set of active k (those with g[k]+beta[k]*t = f(t)).

- If min active beta > 0, the function is increasing, so move left (decrease t).
- If max active beta < 0, the function is decreasing, so move right (increase t).
- If 0 is in the subdifferential, we've found the minimum.
