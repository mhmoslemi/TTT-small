  - (1-h[i+k])*δ if i+k < n (the j=i term)
  - -h[i-k]*δ if i-k >= 0 (the j=i-k term)

So the change in overlap(k) is: δ * [(1-h[i+k])*[i+k<n] - h[i-k]*[i-k>=0]]

This means we can precompute the "sensitivity" for each point i and each lag k:
sens[i, k] = (1-h[i+k])*[i+k<n] - h[i-k]*[i-k>=0]

But this is an n×(2n-1) matrix, which for n=560 is about 627,000 entries. That's fine.

But after each change, all sensibilities change. So we can't really precompute them efficiently.

However, for a single-point change δ at position i:
Δoverlap(k) = δ * sens[i,k]

And the new C₅ = max_k (overlap(k) + δ*sens[i,k]) for the affected k's.

But ALL k's are affected! Because sens[i,k] is non-zero for many k.

Specifically, for point i:
- Sensitivity to lag k: (1-h[i+k]) if i+k < n, else 0, minus h[i-k] if i-k >= 0, else 0.

So for point i, the non-zero sensitivities are:
- k in [0, n-1-i]: contributes (1-h[i+k])
- k in [-(i), -1]: contributes -h[i-k] = -h[i+|k|]... wait

Let me re-derive. For lag k (where k = m-(n-1) for correlate index m):
sens[i,k] = (1-h[i+k]) * [0<=i+k<=n-1] - h[i-k] * [0<=i-k<=n-1]

For k >= 0:
- [0<=i+k<=n-1]: i+k < n → k < n-i, and i+k >= 0 always (since i>=0, k>=0). So k in [0, n-1-i].
- [0<=i-k<=n-1]: i-k >= 0 → k <= i, and i-k < n always (since i<n, k>=0). So k in [0, min(k_max, i)].

So for k >= 0:
sens[i,k] = (1-h[i+k]) - h[i-k] if k <= min(n-1-i, i)
         = (1-h[i+k]) if n-1-i <= k <= i (only when i > (n-1)/2, i.e., i >= n/2)
         = -h[i-k] if i < k <= n-1-i (only when i < (n-1)/2, i.e., i < n/2)
         = 0 if k > max(n-1-i, i) = n-1-min(i, n-1-i)

Hmm, this is getting complicated. Let me just compute the full overlap array each time. For n=560, np.correlate takes about 0.1ms, so we can do ~10,000 evaluations per second. That's plenty for a 500-second local search (5 million evaluations).

```python
import numpy as np
import time

def _c5(h):
    n = len(h)
    return float(np.max(np.correlate(h, 1.0-h, mode='full'))) * 2.0/n

def _c5_arr(h):
    n = len(h)
    return np.correlate(h, 1.0-h, mode='full') * 2.0/n

def _proj(v, S):
    x = np.clip(v.copy(), 0.0, 1.0)
    for _ in range(100):
        d = S - x.sum()
        if abs(d) < 1e-13:
            break
        mask = (x < 1.0) if d > 0 else (x > 0.0)
        if not mask.any():
            break
        x[mask] += d / mask.sum()
        np.clip(x, 0.0, 1.0, out=x)
    return x

def _sa_search(h0, rng, deadline, n_restarts=1):
    """Simulated annealing style local search."""
    n = len(h0)
    S = n * 0.5
    best_h = h0.copy()
    best_c = _c5(h0)
    
    for restart in range(n_restarts):
        h = best_h.copy() if restart == 0 else _proj(best_h + 0.01*rng.randn(n), S)
        c = _c5(h)
        corr = _c5_arr(h)
        mx = c
        
        t0 = time.time()
        end = deadline / n_restarts if n_restarts > 1 else deadline
        T = 0.01  # initial temperature
        step = 0.05
        
        while time.time() < min(deadline, t0 + end):
            fr = (time.time() - t0) / end
            T = 0.01 * (1e-6)**fr
            step = 0.05 * (0.01)**fr
            
            i = rng.randint(n)
            j = rng.randint(n)
            if i == j:
                continue
            
            d = step * (1 if rng.random() < 0.5 else -1)
            if d > 0:
                d = min(d, 1.0-h[i], h[j])
            else:
                d = -min(-d, h[i], 1.0-h[j])
            
            if abs(d) < 1e-12:
                continue
            
            h[i] += d
            h[j] -= d
            cn = _c5(h)
            
            if cn < c:
                c = cn
                corr = _c5_arr(h)  # update
                if c < best_c:
                    best_c = c
                    best_h = h.copy()
            else:
                # Maybe accept (simulated annealing)
                if rng.random() < np.exp(-(cn - c) / max(T, 1e-15)):
                    c = cn
                else:
                    h[i] -= d
                    h[j] += d
    
    return best_h, best_c
```
