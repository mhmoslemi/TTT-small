Let me also think about the 0/1 local search more carefully.

For a 0/1 function with n/2 ones, a swap is: pick i where h[i]=1 and j where h[j]=0, set h[i]=0, h[j]=1.

The change in C₅ from this swap depends on how it affects all the lags. Computing the full correlation after each swap is O(n²) = 313K for n=560.

A faster approach: compute the correlation once, then for each position i, precompute its "shadow" on all lags. Then the change from swapping i and j can be computed in O(1) or O(log n).

Shadow of position i (h[i]=1) on lag p:
- Contributes (1-h[i+p]) to corr at lag p if 0≤i+p<n
- Contributes -h[i-p] to corr at lag p if 0≤i-p<n (from the h[i-p]*(1-h[i]) term)

Wait, I already derived this. The shadow is:
shadow_i[p] = (1-h[i+p])*I[0≤i+p<n] - h[i-p]*I[0≤i-p<n]

When we set h[i] from 1 to 0:
- Remove shadow_i from all lags
When we set h[j] from 0 to 1:
- Add shadow_j to all lags (but shadow_j depends on h, which changed at i!)

This is the problem: the shadow of j depends on h[i] (which just changed). Specifically:
- shadow_j[p] includes the term -h[j-p]*I[0≤j-p<n]. If j-p = i, then this term changes from -h[i] to -0 = 0. Similarly, (1-h[j+p]) changes if j+p = i.

So the interaction is only at 2 specific lags: p = i-j and p = j-i. At all other lags, the change is simply:
Δcorr[p] = -shadow_i[p] + shadow_j[p] (with h unchanged except at i and j)

And at the two special lags, there's an additional correction.

For a practical implementation, I can:
1. Precompute the shadow for each position: shadow[i] is a vector of length 2n-1
2. When swapping i and j: Δcorr = -shadow[i] + shadow[j] + correction_at_two_lags
3. Update corr += Δcorr
4. Check if max(corr) decreased
