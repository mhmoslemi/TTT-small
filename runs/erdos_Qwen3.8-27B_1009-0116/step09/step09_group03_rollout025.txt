  So: ∂c_k/∂h[j] = dx * [I(j ≤ n-1-L) - I(j ≤ n-1-L)*h[j+L] - I(L ≤ j ≤ n-1)*h[j-L]]
  
  Where the last term has j-L ≥ 0 and j-L ≤ n-1-L, i.e., j ≥ L and j ≤ n-1.

- If L < 0 (let M = -L > 0): c_k = dx * ∑_{i=0}^{n-1-M} h[i+M](1-h[i])
  = dx * [∑_{i=M}^{n-1} h[i] - ∑_{i=0}^{n-1-M} h[i+M]*h[i]]
  
  ∂/∂h[j]:
  First term: dx if j ≥ M, else 0
  Second term: -dx * [h[j-M] (if j ≥ M and j-M ≤ n-1-M) + h[j+M] (if j ≤ n-1-M and j+M < n)]
  
  So: ∂c_k/∂h[j] = dx * [I(j ≥ M) - I(j ≥ M)*h[j-M] - I(j ≤ n-1-M)*h[j+M]]

    dx = 2.0 / n

def _repair(h, n):
    h = np.clip(h, 0.0, 1.0).copy()
    target = n / 2.0
    s = h.sum()
    if s < 1e-12:
        return np.full(n, 0.5)
    for _ in range(200):
        h *= target / s
        h = np.clip(h, 0.0, 1.0)
        s = h.sum()
        if abs(s - target) < 1e-12:
            break
    diff = target - h.sum()
    if abs(diff) > 1e-12:
        order = np.argsort(1.0 - h) if diff > 0 else np.argsort(h)
        for idx in order:
            if diff > 0:
                a = min(diff, 1.0 - h[idx])
                h[idx] += a
                diff -= a
            else:
                a = min(-diff, h[idx])
                h[idx] -= a
                diff += a
            if abs(diff) < 1e-13:
                break
    return h
