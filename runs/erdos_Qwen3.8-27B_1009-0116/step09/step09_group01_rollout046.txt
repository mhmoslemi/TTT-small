Actually, for a binary swap, the change to the overlap vector is very structured. Let me compute it directly.

For binary h, define:
- P[k] = #{m: h[m]=1, m+k < n, h[m+k]=0} for k=1,...,n-1  (positive lag, source=1)
- Q[k] = #{m: h[m]=0, m+k < n, h[m+k]=1} for k=1,...,n-1  (positive lag, source=0)

The full C₅ = max(max(P), max(Q)) * dx (since C[n-1]=0 for binary)

When we swap i (1→0) and j (0→1):
Change in P[k]:
- i was a source: P[k] had contribution 1 if h[i+k]=0 and i+k<n. Now i is 0, so contribution removed. Δ = -1 for k where 1<=k<=n-1-i and h[i+k]=0.
- i was a target: P[k] had contribution from m=i-k (if h[i-k]=1). h[i] was 0 (after swap), so contribution added. Δ = +1 for k where 1<=k<=i and h[i-k]=1.
- j was NOT a source (was 0): now j is source. P[k] gains contribution if h[j+k]=0 and j+k<n. Δ = +1 for k where 1<=k<=n-1-j and h[j+k]=0.
- j WAS a target from m=j-k (if h[j-k]=1): h[j] was 0, so h[m]=1, h[m+k]=0 contributed. Now h[j]=1, so no contribution. Δ = -1 for k where 1<=k<=j and h[j-k]=1.

So ΔP[k] = -[h[i+k]=0, k<n-i] + [h[i-k]=1, k<=i] + [h[j+k]=0, k<n-j] - [h[j-k]=1, k<=j]

Similarly for Q[k]:
- i was NOT a source (for Q, source=0): now i is 0, so i is a source. Q[k] gains if h[i+k]=1. Δ = +1 for 1<=k<=n-1-i, h[i+k]=1.
- i WAS a target for Q: m=i-k with h[m]=0, h[i]=1 contributed. Now h[i]=0, no contribution. Δ = -1 for 1<=k<=i, h[i-k]=0.
- j WAS a source (was 0): Q[k] had contribution if h[j+k]=1. Now j is 1, not a source. Δ = -1 for 1<=k<=n-1-j, h[j+k]=1.
- j WAS NOT a target: m=j-k with h[m]=0, h[j]=0 contributed nothing. Now h[j]=1, so contributes. Δ = +1 for 1<=k<=j, h[j-k]=0.

So ΔQ[k] = +[h[i+k]=1, k<n-i] - [h[i-k]=0, k<=i] - [h[j+k]=1, k<n-j] + [h[j-k]=0, k<=j]

This is all O(n) to compute (vectorized), then we update P and Q, and check if the max changes.

```python
def _swap_update(b, i, j):
    """Compute the change in overlap vectors when swapping b[i]:1->0, b[j]:0->1."""
    n = len(b)
    k = np.arange(1, n)
    
    # For P (source=1, target=0):
    # -[h[i+k]=0, k<n-i] + [h[i-k]=1, k<=i] + [h[j+k]=0, k<n-j] - [h[j-k]=1, k<=j]
    dP = np.zeros(n)  # index 0 unused
    if i + 1 < n:
        dP[1:n-i] -= (b[i+1:n] == 0).astype(int)
    if i >= 1:
        dP[1:i+1] += (b[0:i][::-1] == 1).astype(int)
    # Wait, b[i-k] for k=1..i is b[i-1], b[i-2], ..., b[0]
    # So dP[k] += b[i-k] for k=1..i
    # In vector form: dP[1:i+1] += b[0:i][::-1]
    
    if j + 1 < n:
        dP[1:n-j] += (b[j+1:n] == 0).astype(int)
    if j >= 1:
        dP[1:j+1] -= (b[0:j][::-1] == 1).astype(int)
    
    # For Q (source=0, target=1):
    # +[h[i+k]=1, k<n-i] - [h[i-k]=0, k<=i] - [h[j+k]=1, k<n-j] + [h[j-k]=0, k<=j]
    dQ = np.zeros(n)
    if i + 1 < n:
        dQ[1:n-i] += (b[i+1:n] == 1).astype(int)
    if i >= 1:
        dQ[1:i+1] -= (b[0:i][::-1] == 0).astype(int)
    if j + 1 < n:
        dQ[1:n-j] -= (b[j+1:n] == 1).astype(int)
    if j >= 1:
        dQ[1:j+1] += (b[0:j][::-1] == 0).astype(int)
    
    return dP, dQ
```
