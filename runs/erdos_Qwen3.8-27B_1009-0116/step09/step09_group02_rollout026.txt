- **Spend 60% of the time on local search and polish**
- **Use better moves in the local search**

For the local search, the key moves are:
1. **Pair swap**: h[i] += d, h[j] -= d (preserves sum)
2. **Block shift**: h[i:i+k] += d, h[j:j+k] -= d
3. **Gradient step**: h -= d * grad (preserves sum if grad has zero mean)
4. **Corridor move**: h[i:i+k] += d * linspace(1, 0, k) / sum (smooth addition)

The most effective for the final polish is probably #1 (pair swap) with very small d.

                h[idx] += a
                diff -= a

def _slsqp_run(h, n, alpha, m, maxiter, t0, budget):
    def _obj(x):
        c = np.correlate(x, 1.0 - x, mode='full') * 2.0 / n
        mx = c.max()
        idx = np.argpartition(c, -m)[-m:]
        s = np.clip(alpha * (c[idx] - mx), -300, 300)
        s -= s.max()
        return mx + np.log(np.exp(s).sum()) / alpha

    def _grad(x):
        return _smooth_grad(x, n, alpha, m)

    def _cfun(x):
        return x.sum() - n / 2.0

    def _cjac(x):
        return np.ones(n)

    try:
        bnds = [(0.0, 1.0)] * n
        cons = [{'type': 'eq', 'fun': _cfun, 'jac': _cjac}]
        res = minimize(_obj, h, jac=_grad, method='SLSQP',
                       bounds=bnds, constraints=cons,
                       options={'maxiter': maxiter, 'ftol': 1e-19})
        if time.time() - t0 < budget:
            return _repair(res.x, n)
    except Exception:
        pass
    return h
