    if s < 1e-15:

    h *= target / s

    diff = target - h.sum()
    if abs(diff) > 1e-13:

        for idx in order:
            amt = min(abs(diff), max(abs(1.0 - h[idx]), abs(h[idx])))
            if diff > 0:
                h[idx] += min(amt, 1.0 - h[idx])
            else:

            diff *= (1.0 - 2.0 * min(amt, abs(diff)))  # approximate
            # Actually let me just recompute

            if abs(diff) < 1e-14:

Actually, I want to also try a different approach for the local search: instead of trying fixed deltas, try the **optimal** delta for each pair.

For a pair (i,j), the change in c5 when h[i]→h[i]+d, h[j]→h[j]-d is a rational function of d (the max of several affine functions). The minimum of the max of affine functions is a linear programming problem in d!

Specifically, for each lag p:
c_new[p] = c[p] + d * G_p(i,j)

where G_p(i,j) = [(1-h[i-l_p])_v - (1-h[j-l_p])_v - h[i+l_p]_v + h[j+l_p]_v]

We want to find d that minimizes max_p (c[p] + d * G_p(i,j)), subject to 0≤h[i]+d≤1, 0≤h[j]-d≤1, and sum constraint (automatically satisfied).

This is a 1-dimensional LP! The optimal d is at one of the breakpoints of the max function, i.e., where c[p] + d * G_p(i,j) = c[q] + d * G_q(i,j) for some p≠q.

For n=70, there are 139 lags, so there are O(139²) = O(19321) breakpoints, but most G_p values are the same (many lags have the same G_p(i,j) due to the structure). In practice, there are only O(n) distinct G_p values.

The optimal d is at one of:
- d = 0 (current)
- d = 1-h[i] (i hits upper bound)
- d = -h[i] (i hits lower bound)
- d = h[j] (j hits lower bound)
- d = -(1-h[j]) (j hits upper bound)
- d = (c[q]-c[p]) / (G_p - G_q) for each pair (p,q) where G_p ≠ G_q

This gives O(n) candidate d values. We can evaluate c5 at each and pick the best.

This is much more efficient than trying a fixed set of deltas! And it's exact (no approximation).
