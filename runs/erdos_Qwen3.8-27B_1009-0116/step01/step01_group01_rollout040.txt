= A_ℓ + h[i] * [(1-h[i+ℓ]) - h[i-ℓ]] (where missing terms are 0)

Let me define:
- α_ℓ = (1-h[i+ℓ]) if 0≤i+ℓ<n else 0
- β_ℓ = h[i-ℓ] if 0≤i-ℓ<n else 0
- A_ℓ = c_ℓ - h[i]*(α_ℓ - β_ℓ) [the part not involving h[i]]

Then c_ℓ(t) = A_ℓ + t*(α_ℓ - β_ℓ) for t = h[i].

And C₅(t) = max_ℓ (A_ℓ + t*(α_ℓ - β_ℓ)) is convex piecewise linear in t.

To minimize over t ∈ [0,1]: find where the subgradient contains 0.
Subgradient at t: {max of (α_ℓ-β_ℓ) over active ℓ at t}
More precisely, the subdifferential is the convex hull of {α_ℓ-β_ℓ : ℓ active at t}.

The minimum is where the sign changes: find t* such that min slope ≤ 0 ≤ max slope among active constraints.

Practically: sort the lines by their value at t=0, find lower envelope... actually for max of lines, we want where the max slope goes from negative to positive.

Simpler approach: just evaluate C₅(t) at O(n) candidate points (all breakpoints, which are intersections of pairs of lines, plus 0 and 1) and take the minimum. But O(n²) breakpoints for O(n) lines is O(n²) per coordinate, O(n³) total. For n=376, that's ~53M operations per full sweep. Might be too slow for many sweeps.

Alternative: use binary search on t. At each t, compute the slope (max of active α_ℓ-β_ℓ). If slope < 0, increase t. If slope > 0, decrease t. This is O(n log n) per coordinate (log n bisections, each O(n) to evaluate). Total: O(n² log n) per sweep. For n=376: ~376² * 9 ≈ 1.3M per sweep. Very fast!

But wait, I also need to handle the sum constraint. If I change h[i] from old to new, I need to adjust another coordinate. This complicates things.

import numpy as np
from scipy.optimize import minimize
import time


def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    c = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(c) * dx)


def project_box_hyper(h, target):
    lo, hi = -2.0, 2.0
    for _ in range(80):
        mid = (lo + hi) * 0.5
        s = np.clip(h - mid, 0.0, 1.0).sum()
        if s > target:
            lo = mid
        else:
            hi = mid
    h_p = np.clip(h - (lo + hi) * 0.5, 0.0, 1.0)
    d = target - h_p.sum()
    if abs(d) > 1e-14:
        idx = np.argmin(np.abs(h_p - 0.5))
        h_p[idx] = np.clip(h_p[idx] + d, 0.0, 1.0)
    return h_p


def subgrad_h(h, n):
    c = np.correlate(h, 1.0 - h, mode='full')
    idx = int(np.argmax(c))
    ell = idx - (n - 1)
    g = np.zeros(n)
    if ell >= 0:
        v = n - ell
        if v > 0:
            g[:v] += 1.0 - h[ell:ell + v]
            g[ell:ell + v] -= h[:v]
    else:
        e = -ell
        v = n - e
        if v > 0:
            g[e:e + v] += 1.0 - h[:v]
            g[:v] -= h[e:e + v]
    return g, float(c[idx] * 2.0 / n)


def subgrad_descent(h0, n, n_iter, alpha0=0.5, decay=0.6, target=None):
    if target is None:
        target = n * 0.5
    h = project_box_hyper(h0.copy(), target)
    best_h, best_c5 = h.copy(), compute_c5(h)
    for t in range(1, n_iter + 1):
        alpha = alpha0 / (t ** decay)
        g, cur = subgrad_h(h, n)
        if cur < best_c5 - 1e-15:
            best_c5, best_h = cur, h.copy()
        gn = np.linalg.norm(g)
        if gn < 1e-14:
            break
        h = project_box_hyper(h - alpha * g / gn, target)
    return best_h, best_c5


def coord_descent(h0, n, sweeps=200):
    h = project_box_hyper(h0.copy(), n * 0.5)
    best_c5 = compute_c5(h)
    target = n * 0.5
    for sw in range(sweps):
        improved = False
        for i in range(n):
            old = h[i]
            lo_t, hi_t = 0.0, 1.0
            for _ in range(18):
                mid = (lo_t + hi_t) * 0.5
                h2 = h.copy()
                h2[i] = mid
                h2 = project_box_hyper(h2, target)
                v = compute_c5(h2)
                g_mid, _ = subgrad_h(h2, n)
                slope = g_mid[i]
                if slope > 0.01:
                    hi_t = mid
                elif slope < -0.01:
                    lo_t = mid
                else:
                    lo_t = hi_t = mid
                    break
            cand_list = [lo_t, hi_t, old, 0.0, 1.0, 0.5]
            best_val, best_cand = best_c5, old
            for cand in cand_list:
                if cand < -1e-9 or cand > 1 + 1e-9:
                    continue
                h2 = h.copy()
                h2[i] = cand
                h2 = project_box_hyper(h2, target)
                v = compute_c5(h2)
                if v < best_val - 1e-13:
                    best_val, best_cand = v, cand
            if best_cand != old:
                h = h.copy()
                h[i] = best_cand
                h = project_box_hyper(h, target)
                best_c5 = min(best_c5, compute_c5(h))
                improved = True
        if not improved:
            break
    return project_box_hyper(h, target), best_c5


def slsqp_polish(h0, n, maxiter=500, t_param=500.0):
    dx = 2.0 / n
    target = n * 0.5

    def obj(x):
        c = np.correlate(x, 1.0 - x, mode='full')
        cmax = np.max(c)
        return (cmax + np.log(np.sum(np.exp((c - cmax) * t_param))) / t_param) * dx

    bnds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': lambda x: x.sum() - target,
             'jac': lambda x: np.ones(n)}]
    res = minimize(obj, h0.copy(), method='SLSQP', bounds=bnds,
                   constraints=cons, options={'maxiter': maxiter, 'ftol': 1e-14})
    h = project_box_hyper(res.x, target)
    return h, compute_c5(h)

    t0 = time.time()
