def project(h, target, tol=1e-14):
    h = h.copy()
    for _ in range(100):
        h = np.clip(h, 0.0, 1.0)
        diff = target - h.sum()
        if abs(diff) < tol:
            break
        m = (h > tol) & (h < 1.0 - tol)

            h[m] += diff / m.sum()
        else:

        if m.any():

Let me think about a more efficient approach. The key insight is:

For the smooth max objective f(h) = slexp_max(overlap(h), alpha), the gradient is:
∇f = (1/sum_k w_k) * Σ_k w_k * ∇overlap_k

where w_k = exp(alpha * (o_k - o_max)) are the softmax weights.

And ∇overlap_k with respect to h_i can be computed analytically:
overlap_k = Σ_i h[i] * (1-h[i+k]) * dx (with appropriate index bounds)

∂overlap_k/∂h_i = dx * [(1-h[i+k]) - h[i-k]] (where out-of-range terms are 0)

So the gradient is a weighted sum of these, which can be computed in O(n²) total (for 2n-1 shifts, each requiring O(n) work, but we can use FFT).

Actually, for the full correlation, the gradient of the correlation with respect to h is:

For arrays a (length n) and v (length n), `np.correlate(a, v, mode='full')` returns an array of length 2n-1, where:
result[k] = sum_{t} a[t+k] * conj(v[t]) for valid t

So result[n-1] = sum_t a[t+n-1-t'] * v[t']... hmm, this is a bit confusing.

Let me just test mentally: for n=3, a=[a0,a1,a2], v=[v0,v1,v2]:
result = [a0*v0, a1*v0+a0*v1, a2*v0+a1*v1+a0*v2, a2*v1+a1*v2, a2*v2]

So result[2] (center) = a2*v0 + a1*v1 + a0*v2 = sum_i a[i]*v[2-i]... no that's not right.

Actually, numpy's correlate is defined as:
c[k] = sum_n a[n+k] * conj(v[n])

For k from -(N_v-1) to N_a-1, giving N_a + N_v - 1 values.

With a=[a0,a1,a2] (N_a=3) and v=[v0,v1,v2] (N_v=3):
k=-2: a[0]*v[2] = a0*v2
k=-1: a[0]*v[1] + a[1]*v[2] = a0*v1 + a1*v2
k=0: a[0]*v[0] + a[1]*v[1] + a[2]*v[2] = a0*v0 + a1*v1 + a2*v2
k=1: a[1]*v[0] + a[2]*v[1] = a1*v0 + a2*v1
k=2: a[2]*v[0] = a2*v0

So result = [a0*v2, a0*v1+a1*v2, a0*v0+a1*v1+a2*v2, a1*v0+a2*v1, a2*v0]

With v = 1-h, this is:
k=0: sum_i h[i]*(1-h[i])
k=1: sum_i h[i+1]*(1-h[i])  ... which is shift of h by 1
k=-1: sum_i h[i]*(1-h[i-1]) ... 

So the overlap at "shift k" is result[n-1+k], which equals sum_{valid i} h[i+k]*(1-h[i]).

This represents ∫ h(x+k)(1-h(x)) dx, which by change of variables is ∫ h(x)(1-h(x-k)) dx.

The set of all shifts k from -(n-1) to (n-1) covers all relevant lags. The max over all these gives C₅ * (1/dx).

So the formula C₅ = max(np.correlate(h, 1-h, mode='full')) * (2/n) is correct.

def _proj(h, target):
    h = h.copy().astype(float)

        np.clip(h, 0.0, 1.0, out=h)

                    cn = _c5(hn)
                    if cn < best_c:
                        best_c = cn
                        best_h = hn.copy()
                        best_n = n
                        print(f"  n={n} s{si} a{a}: {cn:.7f}")
                    h0 = hn
                except Exception:
                    pass

            if time.time() - t0 < budget_s - 8:
                try:
                    res2 = minimize(_obj_slexp, h0, args=(target, 5000),
                                  method='L-BFGS-B', bounds=bounds,
                                  options={'maxiter': 300, 'ftol': 1e-15})
                    hn2 = _proj(res2.x, target)
                    cn2 = _c5(hn2)
                    if cn2 < best_c:
                        best_c = cn2
                        best_h = hn2.copy()
                        best_n = n
                        print(f"  n={n} s{si} LB: {cn2:.7f}")
                    h0 = hn2
                except Exception:
                    pass

            if time.time() - t0 < budget_s - 8:
                h0 = _pair_cd(h0, target, sweeps=50)
                cn = _c5(h0)
                if cn < best_c:
                    best_c = cn
                    best_h = h0.copy()
                    best_n = n
                    print(f"  n={n} s{si} CD: {cn:.7f}")

    if time.time() - t0 < budget_s - 5:
        best_h = _pair_cd(best_h, best_n / 2.0, sweeps=60)
        best_c = _c5(best_h)

    print(f"Final: n={best_n} C5={best_c:.7f}")
    return best_h, best_c, best_n
