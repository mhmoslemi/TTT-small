One important idea: at the optimum, we expect several lags to be "active" (achieving the max). We can use this to construct a system of equations. If lags k=0,1,...,K are active, we want:
sum_i h[i+k]*(1-h[i]) = T for k=0,...,K
where T is the common max value (times dx).

This gives K+1 equations in n unknowns (plus the sum constraint = n+1 equations total). For n=70 and K=5, we have 6 equations in 70 unknowns - very underdetermined. We can solve this with least-squares or add an objective.

    target = n / 2.0
    h = np.clip(np.asarray(h, dtype=float), 0.0, 1.0)
    s = np.sum(h)
    if s < 1e-15:
        return np.full(n, 0.5)
    h = h * (target / s)

    best_c5 = compute_c5(h_best, best_n)
    return (h_best, best_c5, best_n)
