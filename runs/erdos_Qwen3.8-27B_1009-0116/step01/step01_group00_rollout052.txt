def _repair(h, n):
    h = np.clip(h, 0.0, 1.0)
    target = n / 2.0
    s = h.sum()
    if s < 1e-15:
        return np.full(n, 0.5)
    h *= target / s
    h = np.clip(h, 0.0, 1.0)
    diff = target - h.sum()
    if abs(diff) > 1e-10:
        if diff > 0:
            order = np.argsort(1.0 - h)
        else:
            order = np.argsort(h)
        for idx in order:
            if diff > 0:
                add = min(diff, 1.0 - h[idx])
                h[idx] += add
                diff -= add
            else:
                sub = min(-diff, h[idx])
                h[idx] -= sub
                diff += sub
            if abs(diff) < 1e-10:
                break
    return h

    m = corr.max()
    shifted = alpha * (corr - m)
    shifted = np.clip(shifted, -500, 500)
    return m + np.log(np.sum(np.exp(shifted))) / alpha

C[m] for m = n-1+k (k ≥ 0): C[m] = Σ_{i=0}^{n-1-k} h[i+k] * (1-h[i])

∂C[m]/∂h[p]:
- p appears in h[i+k] when i+k=p, i.e., i=p-k. Valid if 0 ≤ p-k ≤ n-1-k, i.e., k ≤ p ≤ n-1.
  Contribution: (1-h[p-k])
- p appears in (1-h[i]) when i=p, i.e., p ≤ n-1-k, i.e., k ≤ n-1-p.
  Contribution: -h[p+k]

So for m = n-1+k:
G[p, n-1+k] = [k ≤ p] * (1-h[p-k]) + [k ≤ n-1-p] * (-h[p+k])

Similarly for m = n-1-k (k > 0): C[m] = Σ_{i=k}^{n-1} h[i] * (1-h[i-k])

∂C[m]/∂h[p]:
- p appears in h[i] when i=p, valid if k ≤ p ≤ n-1.
  Contribution: (1-h[p-k])
- p appears in (1-h[i-k]) when i-k=p, i=p+k, valid if p+k ≤ n-1.
  Contribution: -h[p+k]

So for m = n-1-k (k > 0):
G[p, n-1-k] = [p ≥ k] * (1-h[p-k]) + [p+k < n] * (-h[p+k])

Note that for k=0, both formulas give:
G[p, n-1] = (1-h[p]) + (-h[p]) = 1 - 2h[p]
And from the first formula with k=0: [0≤p]*(1-h[p]) + [0≤n-1-p]*(-h[p]) = (1-h[p]) - h[p] = 1-2h[p]. ✓

Let me implement this more efficiently using vectorization:

```python
def _compute_grad(h, n):
    G = np.zeros((n, 2*n-1))
    for p in range(n):
        # Positive lags: m = n-1+k, k=0..n-1
        for k in range(n - p):
            # [k <= p] is True, contribution (1-h[p-k])
            G[p, n-1+k] += 1.0 - h[p-k]
            # [k <= n-1-p] check
            if k <= n - 1 - p:
                G[p, n-1+k] -= h[p+k]
        
        # Negative lags: m = n-1-k, k=1..n-1
        for k in range(1, min(p, n-1) + 1):
            # [p >= k] is True, contribution (1-h[p-k])
            G[p, n-1-k] += 1.0 - h[p-k]
            # [p+k < n] check
            if p + k < n:
                G[p, n-1-k] -= h[p+k]
    return G
```
