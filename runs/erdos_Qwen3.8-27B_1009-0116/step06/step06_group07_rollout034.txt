            gh[:n-lag] -= wkd * h[lag:]          # -h[i+lag] for i <= n-1-lag

            gh[:n-pl] += wkd * (1.0 - h[pl:])   # (1-h[i+pl]) for i <= n-1-pl

c[k] = sum_j h[j+lag] * (1-h[j])

∂c[k]/∂h[i]:
- h[i] appears in h[j+lag] when j+lag = i, i.e., j = i-lag. Valid when 0≤j<n: 0≤i-lag<n.
  Contribution: (1-h[j]) = (1-h[i-lag])
- h[i] appears in (1-h[j]) when j = i. Valid when 0≤i<n (always true) AND 0≤j+lag = i+lag < n.
  Contribution: h[j+lag] = h[i+lag] → but with negative sign from derivative: -h[i+lag]

Wait, h[i] appears in (1-h[j]) as (1-h[j]) where j=i. The derivative of (1-h[i]) w.r.t. h[i] is -1. And it's multiplied by h[j+lag] = h[i+lag].
So contribution is: -h[i+lag] (valid when 0≤i+lag<n).

So: ∂c[k]/∂h[i] = (1-h[i-lag])·[0≤i-lag<n] - h[i+lag]·[0≤i+lag<n]

For lag > 0:
- (1-h[i-lag]) valid for i ≥ lag: indices lag, lag+1, ..., n-1

- -h[i+lag] valid for i+lag < n, i.e., i < n-lag: indices 0, 1, ..., n-1-lag
  → gh[0:n-lag] -= h[lag:n] which is h[lag:] ✓

For lag < 0, let pl = -lag > 0:

**One more idea: Use the fact that the problem is symmetric.**

If h is optimal, then 1-h is also feasible (since sum(1-h) = n - n/2 = n/2). And the overlap for 1-h is:
∫(1-h)(1-(1-h(k)))dx = ∫(1-h)h(k)dx = ∫h(k)(1-h)dx

This is the same as the original overlap with h and 1-h swapped! So C₅(h) = C₅(1-h).

This means if h is optimal, 1-h is also optimal. The solution has a symmetry.

Also, h and its reflection (h(2-x)) should give the same C₅.

These symmetries can be used to reduce the search space, but for a numerical optimizer, they mainly mean we have multiple equivalent optima.
