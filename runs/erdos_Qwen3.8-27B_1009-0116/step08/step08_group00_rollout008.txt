31. **Block coordinate descent**: Instead of updating all n variables at once, update a block of b adjacent variables. For a block [i, i+b-1], the objective restricted to this block is still a max of bilinear forms, but with only b free variables. We can use a small SLSQP or even a grid search for small b.

Actually, for a block of b variables, the bilinear terms involving these variables are:
- Within the block: h[i+j]*(1-h[i+j+L]) for various j, L
- Between block and outside: h[i+j]*(1-h[k]) where k is outside

The "between" terms are linear in the block variables (since the outside is fixed), while the "within" terms are bilinear.

For small b (say 3-5), we could use a simple coordinate descent within the block:
- For each variable in the block, given the others, the objective is a max of linear functions → convex → can solve with SLSQP or even analytically.

Wait, actually for a single variable h[i], given all others fixed:
f_k as a function of h[i] is:
- If i is involved in f_k: f_k = a*h[i] + b*h[i]^2 + c (quadratic)
  where a and b depend on the specific lag
- If i is not involved in f_k: f_k is constant

So max_k f_k as a function of h[i] is the max of a set of polynomials (some linear, one quadratic). This is a 1D optimization problem that can be solved exactly.

But the constraint sum(h) = n/2 couples all variables. In block coordinate descent, we'd fix the sum of the block: sum(h_block) = target_block. This makes it a bit more complex.

Let me simplify: for block coordinate descent, I'll use a small SLSQP on the block variables.

    h = np.clip(h, 0.0, 1.0).copy()
    target = n / 2.0
    s = h.sum()
    if s < 1e-12:
        return np.full(n, 0.5)
    for _ in range(200):
        h *= target / s
        h = np.clip(h, 0.0, 1.0)
        s = h.sum()
        if abs(s - target) < 1e-12:
            break
    diff = target - h.sum()
    if abs(diff) > 1e-12:
        order = np.argsort(1.0 - h) if diff > 0 else np.argsort(h)
        for idx in order:
            if diff > 0:
                a = min(diff, 1.0 - h[idx])
                h[idx] += a
                diff -= a
            else:

                diff += a
