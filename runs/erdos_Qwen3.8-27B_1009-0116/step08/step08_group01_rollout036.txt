Let me try approach 1: **gradient-informed local search**.

At each iteration:
- Compute the gradient g
- Find the pair (i,j) that maximizes the descent when we move h[i] up and h[j] down (or vice versa)
- The descent direction for the constraint-preserving move (i, +d, j, -d) is:
  d²/g_i - g_j (approximately, for small d)
- The steepest descent pair is argmax_{i≠j} (g_j - g_i) for the (i,j) direction

Wait, the move is h[i] += d, h[j] -= d (preserving the sum). The change in f is approximately d*(g_i - g_j). To decrease f, we want g_i > g_j (move mass from i to j) or g_i < g_j (move mass from j to i).

So the steepest descent 2-move is: increase the component with the smallest gradient and decrease the component with the largest gradient.

This is essentially the "most negative" and "most positive" gradient components.

But we also need to respect the [0,1] bounds. So:
- i* = argmin g (candidate to increase)
- j* = argmax g (candidate to decrease)
- d_max = min(1 - h[i*], h[j*])

Let me implement this:

```python
def _grad_local_search(h, n_iter, alpha, top_k):
    n = len(h)
    cur = _eval(h)
    for _ in range(n_iter):
        _, g = _lse_fg(h, alpha, top_k)
        # Find best 2-move
        i_star = np.argmin(g)
        j_star = np.argmax(g)
        if i_star == j_star:
            continue
        d_max = min(1.0 - h[i_star], h[j_star])
        # Binary search for best d
        d = d_max * 0.5
        h_trial = h.copy()
        h_trial[i_star] += d
        h_trial[j_star] -= d
        c_trial = _eval(h_trial)
        if c_trial < cur:
            h = h_trial
            cur = c_trial
        else:
            # Try smaller d
            d *= 0.5
            h[i_star] += d
            h[j_star] -= d
            c_trial = _eval(h_trial)
            if c_trial < cur:
                h = h_trial
                cur = c_trial
            else:
                h[i_star] -= d
                h[j_star] += d
    return h, cur
```

        _, g = _lse_fg(h, alpha, tpk)

        neg = np.argsort(g)[:n_cand]

        moved = False
        for i in neg:
            if h[i] >= 1 - 1e-10: continue
            for j in pos:
                if j == i or h[j] <= 1e-10: continue
                dm = min(1.0 - h[i], h[j])

                        break
                    h[i] -= d; h[j] += d

        if moved:

        else:
