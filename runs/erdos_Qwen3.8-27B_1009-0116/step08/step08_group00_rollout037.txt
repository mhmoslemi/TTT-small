Actually, I realize I should think more carefully about the local search. The key insight is:

At a local optimum, for the active lag L*, the gradient g = ∂c_{L*}/∂h should satisfy:
- g[i] = λ for all i where 0 < h[i] < 1 (interior points)
- g[i] ≤ λ for all i where h[i] = 0
- g[i] ≥ λ for all i where h[i] = 1

This is the KKT condition. If this is violated, we can improve by moving mass from a point where g > λ (and h > 0) to a point where g < λ (and h < 1).

So the local search should:
1. Compute g for the active lag
2. Find i where h[i] > 0 and g[i] is large
3. Find j where h[j] < 1 and g[j] is small
4. Transfer ε from i to j

But this is for a single active lag. With multiple active lags, it's more complex.

    best_c5 = _eval(best_h)
    return (best_h, best_c5, len(best_h))
