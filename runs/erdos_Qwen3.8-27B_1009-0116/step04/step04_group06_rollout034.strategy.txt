## Approach and Rationale

The current approach uses projected gradient descent and SLSQP, which are gradient-based and might get stuck in local minima. To address this, we propose a two-stage method:

1. **Multi-grid optimization**: We start with a coarse grid and then refine the solution to a finer grid. This allows us to get a good initial solution and then improve it by capturing finer details.

2. **Physics-informed evolutionary strategy**: We incorporate physical principles (like wave propagation and diffusion) to guide the search. This helps in exploring the solution space more effectively and escaping local optima.

The rationale is that the optimal step function might have a structure that can be captured at multiple scales. By starting from a coarse grid, we can avoid premature convergence and then refine the solution.

## Mathematical Specification

**Domain**: Functions \(h: [0, 2] \to [0, 1]\) with \(\int_0^2 h(x)  dx = 1\).

**Objective**: Minimize \(C_5 = \max_k \int_0^2 h(x) (1 - h(x+k))  dx\).

**Discretization**: \(n\) points, \(x_i = i \cdot \frac{2}{n}\) for \(i=0,\ldots,n-1\). The integral is approximated by the full correlation of \(h\) and \(1-h\).

**Constraints**: \(0 \leq h_i \leq 1\) and \(\sum h_i = \frac{n}{2}\).

**Multi-grid Strategy**:
- Start with a grid size \(n_0\), then \(n_1\), and so on, doubling the grid size in each step until a target grid size (e.g., 140). The parent solution from the previous run can be used as a starting point.

**Physics-Informed Mutation**:

1. **Wave Mutation**: Randomly select a point and introduce a "wave" that affects neighboring points. The wave amplitude is adjusted to maintain the integral constraint.

2. **Diffusion Mutation**: Perform a diffusion step (Gaussian smoothing) and then adjust the function to maintain the integral.

These mutations are applied with a certain probability and are followed by a repair step to enforce constraints.

    for each individual in the population:

- Keep track of the best solution found so far and its objective.

### 6. Termination

- Stop when the budget time is exceeded.

### 7. Multi-grid Transition

- After completing a grid size, the best solution is used as the starting point for the next finer grid.

def mutate_wave(individual):
    n = len(individual)
    i = int(random.uniform(0, n-1))
    # Create a wave that affects i and neighbors
    j = int(random.uniform(0, n-1))
    fact = random.uniform(0.8, 1.2)  # direction
    amt = random.uniform(-0.05, 0.05) * (2 if fact>1.0 else 1)
    new_i = individual[i] + amt * (2 if fact>1.0 else 1)
    new_j = individual[j] + amt * (2 if fact<1.0 else 1)  # opposite to i
    candidate = individual.copy()
    candidate[i] = new_i
    candidate[j] = new_j
    # Clip and adjust sum
    candidate = np.clip(candidate, 0, 1)
    # No need to repair because we'll call repair at the end.
    return candidate

def mutate_diffuse(individual):

    new_candidate = np.clip(new_candidate, 0, 1)
