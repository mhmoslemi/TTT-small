L = m + (1/alpha) * log(sum_k exp(alpha * (c_k - m)))

where m = max(c_k). The derivative:
dL/dh[j] = (1/alpha) * sum_k [alpha * w_k * dc_k/dh[j]] - (1/alpha) * sum_k [alpha * w_k * dm/dh[j]]

where w_k = exp(alpha*(c_k-m)) / sum_l exp(alpha*(c_l-m))

The dm/dh[j] term is nonzero only for the k that achieves the max, and it equals dc_k/dh[j] for that k. So:

dL/dh[j] = sum_k w_k * dc_k/dh[j] - sum_k w_k * (dc_k/dh[j] if c_k == m else 0)
         = sum_k w_k * dc_k/dh[j] - w_argmax * dc_argmax/dh[j]

But if alpha is large, w_argmax ≈ 1 and the other w_k ≈ 0, so this simplifies to just dc_argmax/dh[j]. For moderate alpha, we need the full expression.

         = dm/dh[j] + sum_k w_k * du_k/dh[j]

where w_k = exp(alpha*u_k) / sum_l exp(alpha*u_l).

Now du_k/dh[j] = dc_k/dh[j] - dm/dh[j].

So dL/dh[j] = dm/dh[j] + sum_k w_k * (dc_k/dh[j] - dm/dh[j])

             = dm/dh[j] + sum_k w_k * dc_k/dh[j] - dm/dh[j]
             = sum_k w_k * dc_k/dh[j]

    # Block search on best
    if tleft() > 55:
        t_end = time.time() + min(35, tleft() - 30)
        h2, c5_2 = block_search(best_h.copy(), best_n, rng, t_end)
        if c5_2 < best_c5:
            best_c5 = c5_2
            best_h = h2.copy()

    # Targeted search
    if tleft() > 50:
        t_end = time.time() + min(35, tleft() - 30)
        h3, c5_3 = targeted_search(best_h.copy(), best_n, rng, t_end)
        if c5_3 < best_c5:
            best_c5 = c5_3
            best_h = h3.copy()

    # Second SLSQP round
    if tleft() > 40:
        h = slsqp_opt(best_h.copy(), best_n, 5000000, maxiter=600)
        c5 = eval_c5(h)
        if c5 < best_c5:
            best_c5 = c5
            best_h = h.copy()

    # More targeted search
    if tleft() > 35:
        t_end = time.time() + min(20, tleft() - 15)
        h4, c5_4 = targeted_search(best_h.copy(), best_n, rng, t_end, max_iter=200000)
        if c5_4 < best_c5:
            best_c5 = c5_4
            best_h = h4.copy()

    # Fine patches
    if tleft() > 20:
        t_end = time.time() + min(10, tleft() - 10)
        h5, c5_5 = fine_patches(best_h.copy(), best_n, rng, t_end)
        if c5_5 < best_c5:
            best_c5 = c5_5
            best_h = h5.copy()

    # Final SLSQP
    if tleft() > 15:
        h = slsqp_opt(best_h.copy(), best_n, 10000000, maxiter=400)
        c5 = eval_c5(h)
        if c5 < best_c5:
            best_c5 = c5
            best_h = h.copy()

    # Ultra-fine
    if tleft() > 8:
        t_end = time.time() + min(5, tleft() - 3)
        h6, c5_6 = fine_patches(best_h.copy(), best_n, rng, t_end)
        if c5_6 < best_c5:
            best_c5 = c5_6
            best_h = h6.copy()

    best_h = repair(best_h, best_n)
    best_c5 = eval_c5(best_h)
    return (best_h, best_c5, best_n)
