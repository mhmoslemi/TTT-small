This is the "minimize the maximum of linear functions" problem, which can be solved in O(m) time where m is the number of functions (2n-1). For each linear function c_k + δ*Δ_k, the "peak" is where it crosses the others. The optimal δ is where the two largest (in magnitude) crossing points meet.

This is exactly the problem solved by the "halfspace intersection" or "linear programming in 1D" algorithms.

Algorithm:
1. Compute all Δ_k
2. For positive Δ_k: these correlations increase with δ. The constraint c_k + δ*Δ_k ≤ t gives δ ≤ (t - c_k)/Δ_k.
3. For negative Δ_k: c_k + δ*Δ_k ≤ t gives δ ≥ (t - c_k)/Δ_k.
4. The feasible δ range for a given t is [max_{Δ<0}(t-c_k)/Δ_k, min_{Δ>0}(t-c_k)/Δ_k]
5. Binary search on t to find the smallest t where the interval is non-empty.
