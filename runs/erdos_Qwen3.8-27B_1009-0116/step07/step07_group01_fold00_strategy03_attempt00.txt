- **Variables:** h = [h_1, h_2, ..., h_n] with n points. Each h_i ∈ [0,1], and ∑_{i=1}^n h_i = n/2 (to satisfy integral 1, as dx=2/n).
- **Objective:** Minimize C5(h) = (2/n) * max_k (∫_0^2 h(x)(1-h(x+k)) dx), but discretized as max_lag(np.correlate(h, 1-h, mode='full')) * (2/n).
- **Constraints:**
  1. h[i] ∈ [0,1] ∀i
  2. ∑h[i] = n/2 (exact for n=560, sum=280)

**Modeling:**
- The domain is [0,2] implicitly handled by the continuous objective measure, however in code grid is discretized with n points, and overlap integrated via convolution with finite-step dx.
- Interpolation between coarse and fine grids introduces a mapping that changes resolution. h_c (coarse) and h_f (fine) must satisfy their respective sum constraints after interpolation.
- C5 is evaluated using np.correlate with mode='full' for all lags, ensuring all overlaps are considered.

**Optimization Philosophy:**
- Coarse grids (e.g., n=64) simplify computation and enable population-based global optimizers to run faster.
- Fine grids (n=560) exploit full resolution for precise minimum.
- Repair mechanisms enforce constraints not only at initial and phase start but during interpolation and local refinement.
- Two SLSQP-based optimization stages apply: first on coarse grid, then on fine grid refined by interpolation.

**Variable Handling:**
- h represents function values at discrete points; no analytical form, assumed piecewise constant in blocks for behavior analysis, but elevated to continuous values during optimization.

**Algorithm Selection:**
- Coarse phase: SLSQP for constrained minimization, as it handles bounds and equality constraints.
- Fine phase: Gradient-based repair after interpolation; local search uses similar SLSQP due to budget constraints.
- Convex hull repair is used post-manoeuvre to enforce 0≤h[i]≤1 and sum constraint.

**Fit to Initial_h_values:**
- Provided initial_h_values have sum=280, so repair ensures valid state.
