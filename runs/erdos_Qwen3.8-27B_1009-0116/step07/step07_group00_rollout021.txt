def _repair(h, n):
    h = np.clip(h, 0.0, 1.0).copy()
    target = n / 2.0
    s = h.sum()
    if s < 1e-12:

        h *= target / s
        h = np.clip(h, 0.0, 1.0)

        if abs(diff) > 1e-12:

**Instead of the coordinate descent with loop over lags, let me use a different strategy:**

For the 1D line search, I don't need the exact gradient for each lag. I can just evaluate the full correlation at trial points.

Given h and pair (i,j):
- Trial d: set h[i]+=d, h[j]-=d, compute _eval(h) = max(c)*dx
- Golden section on d

Each evaluation of _eval is O(n²) (correlate). With 50 golden section iterations and n=560, that's 50 × 313K = 15.7M per pair. With 10,000 pairs, that's 157B. Way too slow.

OK so I do need the incremental update. Let me go back to the loop approach but optimize it.

Actually, the key realization: the change in c[k] when h[i]→h[i]+d and h[j]→h[j]-d is simply:
Δc[k] = d * (grad_i[k] - grad_j[k])

where grad_i = dc/dh[i] (vector over all k) and grad_j = dc/dh[j] (vector over all k).

I can precompute grad_i and grad_j using the analytical formula, which requires O(n) operations each (one loop over k with simple index lookups). Then for the golden section, I just need:

f(d) = np.max(c + d * (grad_i - grad_j))

This is O(n) per evaluation (one multiply and one max on arrays of length 2n-1).

Total per pair: O(n) [compute grads] + O(50 × n) [golden section] = O(51n) ≈ 29K
With 50,000 pairs: 1.45B. In numpy, the O(n) vector ops are very fast. The loop over k for computing grads is the bottleneck.

Let me compute grad_i more efficiently. For a fixed index m:

grad[m, k] for all k:
- k = 0 to n-2: s = n-1-k > 0
- k = n-1: s = 0
- k = n to 2n-2: s = n-1-k < 0

For s > 0 (k = n-1-s):
- Term 1: (1-h[m+s])*dx if m+s <= n-1, i.e., s <= n-1-m
- Term 2: -h[m-s]*dx if m-s >= 0 and m-s <= n-1-s (auto), i.e., s <= m

For s = 0 (k = n-1):
- c[k] = sum h[a]*(1-h[a]), dc/dh[m] = (1-h[m])*dx - h[m]*dx = (1-2h[m])*dx

For s < 0 (p = -s, k = n-1+p):
- c[k] = sum_{a=0}^{n-1-p} h[a+p]*(1-h[a])
- dc/dh[m]:
  - m = a+p for some a: a = m-p, valid if 0<=m-p<=n-1-p, i.e., p<=m<=n-1. Contribution: (1-h[m-p])*dx
  - m = a: valid if 0<=m<=n-1-p. Contribution: -h[m+p]*dx
