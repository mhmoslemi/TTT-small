- **Directional random walks** following descent directions based on projected gradients

- **Multi-stage refinement** using increasingly precise optimization

The core idea is to balance exploration and exploitation by:

- Initially taking large steps (fast exploration)

- Using specialized gradient information to target critical regions

3. Implementation Procedure

We build a multi-stage refinement process:

Stage 1: Pattern Initialization
- Start with base pattern candidates at multiple lags
- Search over key parameters (gain/direction) in coarse grid
- Extract promising directions

Stage 2: Progressive Optimization
- Scale step sizes from large to small across phases
- Use projected gradients to stay feasible
- Filter out dominated lags based on improvement history
- Focus computation on the most critical shifts

Stage 3: Local Refinement
- Apply targeted optimization within filtered shift space
- Use more precise gradient estimates
- Maintain feasibility through exterior point projection
