C_5 = \max_{k=-n+1}^{n-2} \left| \frac{1}{n} \sum_{i} \mathbf{h}[i] \cdot (1 - \mathbf{h}[i+k]) \right|
\]
For specific \( k \), the product is zero where the index goes out of bounds due to `mode="full"`.

**Constraints:**
- \( \mathbf{h}_i \in [0,1] \) for all \( i \)
- \( \sum \mathbf{h}_i = n/2 \)

**Algorithm Structure:**
1. **Initialization**: Repair the initial sample to enforce \( \sum \mathbf{h} = n/2 \).
2. **Population Evolution**: Maintain a population of candidate solutions. Apply the following operations repeatedly:
   - **Crossover**: Take two parents and produce \( \alpha \text{-binomial crossover} \).
   - **Mutation**: Stochastically perturb \( \delta \)-points.
   - **Repair**: Maintain feasibility post-crossover/mutation.
3. **Simulated Tempering**: Simulate temperature changes to balance exploration vs. exploitation.
4. **Local Repair**: Adjust the population to keep the sum close to \( n/2 \).

**Repair:** Clipping is rejected due to constraint loss. Instead, use:
- **For violation \( s < n/2 \)**: Add "gel" to minimize sum until target.
- **For \( s > n/2 \)**: Remove "inh"
</strategy>

### Implementation Procedure

#### Function to Repair the Sum
```python
def repair_sum(h, n, target=None):
    if target is None:
        target = n / 2
    
    s = sum(h)
    
    # Initialize swap indices
    low_indices = []
    high_indices = []
    
    # For underfilled (s < target)
    while s < target - 0.01:
        # Find candidate to increase
        low_vals = h == min(h)
        remaining = np.setdiff1d(range(n), low_indices + high_indices)
        cand = remaining[low_vals]
        if not cand:
            cand = remaining
        
        idx = choice(cand)
        if h[idx] < 1.0:
            available = 1.0 - h[idx]
            add_amount = min(available, target - s)
            h[idx] += add_amount
            s += add_amount
            
    # For overfilled (s > target + 0.01)
    while s > target + 0.01:
        # Find candidate to decrease
        remaining = np.setdiff1d(range(n), low_indices + high_indices)
        high_vals = h == max(h)
        cand = remaining[high_vals]
        if not cand:
            cand = remaining
        
        idx = choice(cand)
        if h[idx] > 0.0:
            no_remove = 100  # Max iterations to avoid infinite loops
            i_remove = 0
            while no_remove > 0:
                remove_amount = min(h[idx], target - s)
                h[idx] -= remove_amount
                s -= remove_amount
                if h[idx] <= 0.0:
                    cand = np.delete(cand, 0)
                    no_remove -= 1
                else:
                    break
            else:
                h[idx] = 0.0
    
    # Clip to bounds
    h = np.clip(h, 0.0, 1.0)
    return h, s
```

#### Crossover Operation
```python
def crossover(parent1, parent2):
    n = len(parent1)
    alpha = exp(-1.0 / (runs+1))  # Adaptive mixing parameter, autodecay with runs
    offset = choice(range(1, n-1))  # Random offset index
    a1_index = np.arange(n) + alpha * np.cos(radians(90*uniform(0,1)))
    a2_index = -1 + alpha * uniform(0.0, 1.0) * (n-1)
    offspring = parent1 * a1_index + parent2 * a2_index
    offspring = repair_sum(offspring, n)[0]
    return offspring
```

#### Mutation and Repair
```python
def mutate(h, points_to_perturb=3, effect_size=0.08, repair=True):
    h_len = len(h)
    indices = sorted(set(range(h_len)))
    h_ret = h.copy()
    
    for _ in range(points_to_perturb):
        i = choice(indices)
        # Determine direction and size
        direction = 1 if h[i] < 0.8 else -1
        size_change = effect_size * choice([0.1, 0.2, 0.3])
        h_ret[i] += direction * min(abs(h[i] - 0.5) * size_change, 1.0)
        h_ret[i] = np.clip(h_ret[i], 0.0, 1.0)
    
    # Optionally repair multiples of h[i]
    if repair:
        h_ret, tot = repair_sum(h_ret, len(h_ret), None)[0]
    
    return h_ret

def repair_parent(h, n):
    return repair_sum(h, n, target=n/2)[0]
```

#### Core Optimization Function
```python
def objective(h):
    # Precompute the integral for all lags at once using vectorized operations
    if len(h) == n:
        c = np.correlate(h, 1-h, mode="full")
        # Rescale by dx but leave other units sensible
        c = c * (2.0 / len(h))
        return float(max(c))
    return float('inf')
```
