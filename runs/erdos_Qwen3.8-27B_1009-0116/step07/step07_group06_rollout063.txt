Let me also think about a pairwise CD step that's faster than the previous one. The key insight is that for a (i,j) pair with shift d, the change in c_k is:
Δc_k = d * (g_k[i] - g_k[j]) + d² * I(k is a "self" lag for i,j)

where the "self" lags are those where both i and j contribute to the same c_k with the same sign pattern.

For a given pair (i,j), the lags where both appear are:
- Lag s = j-i: h[i] and h[j] both appear (h[i] in first factor, h[j] in second)
  Actually, for shift s, c_s involves h[p] and h[p+s]. 
  h[i] appears as h[p] when p=i, paired with h[i+s]
  h[j] appears as h[p] when p=j, paired with h[j+s]
  h[i] appears as h[p+s] when p=i-s, paired with h[i]
  h[j] appears as h[p+s] when p=j-s, paired with h[j]
  
  For both h[i] and h[j] to appear in c_s:
  - i = j-s (j = i+s) and some p: c_s has h[p]*(1-h[p+s])
    h[i] appears when p=i or p+s=i → p=i-s
    h[j] appears when p=j or p+s=j → p=j-s
    Both appear if there exist valid p₁, p₂ where p₁ ∈ {i, i-s} and p₂ ∈ {j, j-s}
    And the cross term h[i]*h[j] or h[i]*(1-h[j]) etc. appears.
    
    Specifically, the cross term d² appears when:
    - p = i and p+s = j: i+s = j, so s = j-i
    - p = j and p+s = i: j+s = i, so s = i-j
    
  So only 2 lags have the d² term: s = j-i and s = i-j.

This is what the previous code handles. Good.

So for pairwise CD:
1. Pick random (i,j)
2. Compute g[i] - g[j] where g is the gradient for the active set
3. Binary search for optimal d
4. Update h and c

        # s ranges from -(n-1) to (n-1), indexed as 0 to 2n-2
        # i+s is in [0,n-1] when -i ≤ s ≤ n-1-i
        # i-s is in [0,n-1] when i-(n-1) ≤ s ≤ i

            vals = c + d * dgrad

        h[j] -= d_opt

        if 0 <= k1 < 2*n-1: c[k1] += d_opt*d_opt
        if 0 <= k2 < 2*n-1: c[k2] += d_opt*d_opt

            if 0 <= k2 < 2*n-1: c[k2] -= d_opt*d_opt
            stale += 1
            if stale > 5000: break
    
    return best_h, best_c, c

import numpy as np

def _eval_c5(h):
    n = len(h)
    return float(np.max(np.correlate(h, 1.0 - h, mode='full')) * 2.0 / n)

def _all_corr(h):
    n = len(h)
    return np.correlate(h, 1.0 - h, mode='full') * (2.0 / n)

def _grad_top(h, idxs, wts):
    n = len(h)
    g = np.zeros(n)
    for idx, w in zip(idxs, wts):
        s = int(idx) - (n - 1)
        if s >= 0:
            if s < n:
                g[:n - s] += w * (1.0 - h[s:])
                g[s:] -= w * h[:n - s]
        else:
            t = -s
            if t < n:
                g[t:] += w * (1.0 - h[:n - t])
                g[:n - t] -= w * h[t:]
    return g

def _proj_sum(h, target):
    lo = float(h.min()) - 2.0
    hi = float(h.max()) + 2.0
    for _ in range(80):
        mid = 0.5 * (lo + hi)

        else:
            hi = mid

import numpy as np
import time

def _eval_c5(h):
    n = len(h)
    return float(np.max(np.correlate(h, 1.0 - h, mode='full')) * 2.0 / n)

def _all_corr(h):
    n = len(h)
    return np.correlate(h, 1.0 - h, mode='full') * (2.0 / n)

def _grad_top(h, idxs, wts):
    n = len(h)
    g = np.zeros(n)
    for idx, w in zip(idxs, wts):
        s = int(idx) - (n - 1)
        if s >= 0:
            if s < n:
                g[:n-s] += w * (1.0 - h[s:])
                g[s:] -= w * h[:n-s]
        else:
            t = -s
            if t < n:
                g[t:] += w * (1.0 - h[:n-t])
                g[:n-t] -= w * h[t:]
    return g

def _proj_sum(h, target):
    lo = float(h.min()) - 2.0
    hi = float(h.max()) + 2.0
    for _ in range(80):
        mid = 0.5 * (lo + hi)
        if np.clip(h - mid, 0.0, 1.0).sum() > target:
            lo = mid
        else:
            hi = mid
    return np.clip(h - 0.5 * (lo + hi), 0.0, 1.0)

        c = m.sum()
        if c == 0:

        h = np.clip(h, 0.0, 1.0)
    return h

    c5 = float(c.max())

    v = np.zeros(n)
