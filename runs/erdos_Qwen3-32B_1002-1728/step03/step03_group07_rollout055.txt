Therefore, in this approach, after the optimization completes, the solution is projected, and that is the one considered.

But then, during the optimization, the solution may not be valid, but the optimizer is trying to minimize the objective function (possibly on infeasible points). However, this is a problem.

Alternatively, during the optimization, always project the solution to meet the sum constraint. This requires that after every gradient step, the current solution is projected. This can be done by implementing the projection within the objective function and gradient computation.

But how to do that within scipy.optimize?

Well, one way is to wrap the h passed to the objective function and gradient with the projection. For example:

def objective(h_flat):

    h = h_flat.reshape(n_points)

    h_projected = project(h, target_sum)  # project to sum and bounds

    cross_corr = np.correlate(h_projected, 1 - h_projected, mode='full')

    return np.max(cross_corr) * dx

def gradient(h_flat):

    h = h_flat.reshape(n_points)

    h_projected = project(h, target_sum)

    cross_corr = np.correlate(h_projected, 1 - h_projected, mode='full')

    k_star_index = np.argmax(cross_corr)

    k_star = k_star_index - (n_points - 1)

    grad_flat = np.zeros_like(h_flat)

    for i in range(n_points):

        j = i - k_star

        if 0 <= j < n_points:

            grad_flat[i] = (1 - h_projected[j]) * dx

        else:

            grad_flat[i] = 0.0

    return grad_flat

But this way, the objective and gradient are computed based on the projected h. So during the optimization, the h is always feasible. This requires that the projection is done before computing the objective and gradient. However, the projection is a non-linear operation, and the gradient of the objective function is the gradient of the projected h's objective.

But the projected h may have been obtained by adjusting the original h, which makes the gradient computation somewhat complicated. However, during the optimization, this is a way to ensure feasibility.

This approach could work, but it requires that during the objective and gradient computation, the current h is projected before evaluation.

However, since the projection is not smooth, this may introduce some non-smoothness into the objective function and gradient, potentially causing issues for the optimizer. But given the time constraints, it's worth trying.

So, the code will:

For the objective function and gradient, first project the current h to the feasible set (sum and bounds), then compute the objective and gradient.

This ensures that the optimization is always done with feasible solutions.

- The project function must take h and return a feasible h.

The code will:

Initialize with some h (initial_h_values or perturbed), run L-BFGS-B with bounds, passing the objective and gradient functions that project the current h. Then, after the optimization, the solution is already projected and feasible.

The multi-start approach will run multiple such optimizations from different starting points, select the best one.

import numpy as np
import time
from scipy.optimize import minimize

def run(seed=42, budget_s=1100, **kwargs):
    start_time = time.time()
    h_init = np.array(initial_h_values)
    n_points = len(h_init)
    dx = 2.0 / n_points
    target_sum = n_points / 2.0  # sum(h) == n_points / 2

    # Projection function
    def project(h, target):
        # Clip to [0, 1]
        clipped = np.clip(h, 0, 1)
        current_sum = np.sum(clipped)
        if abs(current_sum - target) < 1e-8:
            return clipped.copy()
        # Need to adjust sum
        delta = target - current_sum
        if delta > 0:  # Need to increase
            idx = np.where(clipped < 1.0 - 1e-8)[0]
            if len(idx) == 0:
                return clipped.copy()
            available = np.sum(1.0 - clipped[idx])
            if available <= 0:
                return clipped.copy()
            add_per = delta / len(idx)
            clipped[idx] += add_per
        else:  # Need to decrease
            idx = np.where(clipped > 1e-8)[0]
            if len(idx) == 0:
                return clipped.copy()  # already zero
            available = np.sum(clipped[idx])
            delta_abs = -delta
            if available <= 0:
                return clipped.copy()
            sub_per = delta_abs / len(idx)
            clipped[idx] -= sub_per
        # After adjustment, clip again in case of numerical issues
        return np.clip(clipped, 0, 1)

    def objective(h_flat):
        h = h_flat.reshape(n_points)
        h_proj = project(h, target_sum)
        cross_corr = np.correlate(h_proj, 1 - h_proj, mode='full')
        return np.max(cross_corr) * dx

    def gradient(h_flat):
        h = h_flat.reshape(n_points)
        h_proj = project(h, target_sum)
        cross_corr = np.correlate(h_proj, 1 - h_proj, mode='full')
        k_star_index = np.argmax(cross_corr)
        k_star = k_star_index - (n_points - 1)
        grad = np.zeros_like(h_flat)
        for i in range(n_points):
            j = i - k_star
            if 0 <= j < n_points:
                grad[i] = (1.0 - h_proj[j]) * dx
            else:
                grad[i] = 0.0
        return grad

    best_h = None
    best_energy = float('inf')
    np.random.seed(seed)
    # Run multiple optimizations
    n_restarts = 5
    for restart in range(n_restarts):
        # Generate initial guess
        if restart == 0:
            current_h = h_init.copy().ravel()
        else:
            # Perturb initial_h_values
            perturb = np.random.uniform(-0.05, 0.05, size=n_points)
            current_h = (h_init + perturb).ravel()
            current_h = project(current_h, target_sum)
        # Define bounds for L-BFGS-B
        bounds = [(0.0, 1.0) for _ in range(n_points)]
        # Run optimization
        res = minimize(
            fun=objective,
            x0=current_h,
            method='L-BFGS-B',
            jac=gradient,
            bounds=bounds,
            options={'maxiter': 1000, 'ftol': 1e-6}
        )
        if res.success:
            h_opt = res.x.reshape(n_points)
            # Compute the current energy (objective)
            current_energy = objective(h_opt)
            # Re-project (in case optimization didn't maintain it properly)
            h_opt_proj = project(h_opt, target_sum)
            current_energy_proj = np.max(np.correlate(h_opt_proj, 1 - h_opt_proj, mode='full')) * dx
            if current_energy_proj < best_energy:
                best_energy = current_energy_proj
                best_h = h_opt_proj.copy()
        if time.time() - start_time > budget_s * 0.99:
            break
    # Final checks
    assert abs(np.sum(best_h) - target_sum) < 1e-6, "Integral constraint violated"
    assert np.all((best_h >= -1e-8) & (best_h <= 1.0 + 1e-8)), "Value bounds violated"
    return (best_h.tolist(), best_energy, n_points)
