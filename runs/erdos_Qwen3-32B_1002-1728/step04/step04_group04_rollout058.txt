The Expected Improvement (EI) is used in minimization. Let’s denote the current best value as y_min. For a new candidate x, the improvement over the current minimum is:

I(x) = max(0, y_min - y(x)) 

We want to maximize I(x), because higher improvement means we have a better solution.

So:

EI = E[I(x)] = ∫ max(0, y_min - y(x)) p(y(x)) dy(x)

If σ(x) = 0, EI = max(0, y_min - μ(x))
Otherwise:
s = σ(x)
z = (y_min - μ(x)) / s
EI = s * [ z * Φ(z) + φ(z) ] if s > 0
