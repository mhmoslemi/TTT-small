The gradient step computes the finite difference gradient for the current maximum overlap shift and updates accordingly. It then projects back into the feasible region.

Adjustments to parameters like pop_size, generations, grad_steps, and learning_rate may be needed for better performance, but this is the basic structure.

The code reduces the population size and generations to allocate time for the gradient steps. The gradient steps are set to 500 with a learning rate of 0.05. The 'project_to_feasible' function ensures that after each gradient step, the constraints are re-enforced.
