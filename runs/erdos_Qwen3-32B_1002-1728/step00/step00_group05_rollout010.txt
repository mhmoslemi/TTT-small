The water-filling algorithm for the sum constraint and box constraints works as follows:

When projecting, we set h as close as possible to the current value, subject to the constraints sum(h) = T and h ∈ [0,1]^n. The optimal solution can be found by sorting the values. 

For example, the unconstrained solution would be to set h_i = current h_i adjusted to get the correct sum. But when this is outside the box constraints, we fix the violations by bringing the values to their bounds and adjusting the rest.

A well-known algorithm for this is the " Lukic's algorithm" or similar for box-constrained optimization. The method involves sorting the variables in decreasing order and iteratively adjusting the target sum while maintaining the constraints.

        h_fine = np.clip(h_fine, 0.0, 1.0)

        current_corr = np.max(np.correlate(h_fine, 1 - h_fine, mode='full') * dx_fine)
        if current_corr < best_c5:
            best_c5 = current_corr
            best_h = h_fine.copy()
            best_n = n_fine

    return (best_h.tolist(), best_c5, best_n)
