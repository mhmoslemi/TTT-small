The optimized solution is upscaled back to the original resolution and then optimized further with SLSQP. This should allow escaping local minima present in the original solution.

The code has try blocks to handle any exceptions during optimization, but in practice, it's better to handle all possible issues. The parameters for differential evolution and SLSQP are chosen to be aggressive but within the time budget.

def downscale_h(h_fine, n_coarse):
    n_fine = len(h_fine)
    k = n_fine // n_coarse
    h_coarse = np.zeros(n_coarse)
    for i in range(n_coarse):
        start = i * k
        end = start + k
        h_coarse[i] = np.mean(h_fine[start:end])
    return h_coarse

    h_fine = np.zeros(n_coarse * k)

    return h_fine
