Now, how to compute the derivative of O_k with respect to the full h?

For a given O_k (max overlap), the derivative at each i_full is:

dO_k/dh_full[i_full] = sum over all terms in O_k's sum where dO_k/dh_full[i_full] is non-zero.

Thus, for each i, if i +k is valid (i.e., i +k < n_points), then the term h[i] * (1 - h[j]) is part of the sum. So for each such i:

Similarly, for each j in the sum, which is i +k, dO_k/dh[j] = -h[i] * dx.

Thus, to compute the derivative of O_k with respect to the full h, we need to iterate over all i where i +k < n_points:

   j = i +k

   if j < n_points:

       contribution at i: (1 - h[j]) * dx

       contribution at j: -h[i] * dx

def run(seed=42, budget_s=1100, **kwargs):

    h_full = np.clip(h_full, 0.0, 1.0)
