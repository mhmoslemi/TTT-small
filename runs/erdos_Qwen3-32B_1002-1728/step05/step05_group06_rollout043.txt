Moreover, the gradient computation is for the current max overlap term, but if during the step, the max overlap shifts to another term, then the gradient is no longer based on the right k.

Additionally, the code for the gradient descent loop is only run for a fixed number of steps (max_gradient_steps), but this could be optimized based on time.
