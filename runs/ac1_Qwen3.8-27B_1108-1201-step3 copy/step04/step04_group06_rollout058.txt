For large n, sum(sqrt(j)) ≈ (2/3)*n^{3/2}. So a_i ≈ sqrt(i+1) / ((2/3)*n^{3/2}) ≈ (3/2)*sqrt(i+1)/n^{3/2}.

The convolution at lag k (for k < n):
conv[k] = sum_{j=0}^{k} a_j * a_{k-j} ≈ (9/4)/n^3 * sum_{j=0}^{k} sqrt((j+1)(k-j+1))

For large k (k ~ n), this is approximately (9/4)/n^3 * integral_0^k sqrt((j+1)(k-j+1)) dj ≈ (9/4)/n^3 * (pi/4) * k^2 (using the fact that integral_0^M sqrt(x(M-x)) dx = pi*M^2/8).

At k ≈ n: conv[n] ≈ (9/4)/n^3 * (pi/4) * n^2 = 9*pi/(16*n) ≈ 1.767/n.

Compare with ramp: 2/(3n) ≈ 0.667/n.

So the sqrt ramp has a HIGHER peak than the linear ramp! That makes sense - it's more concentrated.

What about a "concave" shape? Like a_i = (n+1-i)/(n(n+1)/2) (decreasing ramp)?

By symmetry, this should give the same score as the increasing ramp.

What about a shape that's flat in the middle and drops at both ends? Like a "trapezoid"?

a_i = c for i in [m, n-1-m] (the middle part), and linearly drops to 0 at the ends.

This would have a convolution that's more "top-hat" shaped, which might have a lower peak than the ramp.

Actually, let me think about this differently. The convolution of a with itself is like a "blurring" of the shape. A rectangular function convolved with itself gives a triangle. A triangle convolved with itself gives a "cubic" shape (piecewise cubic). A Gaussian convolved with itself gives a wider Gaussian.

To minimize the peak of the convolution, we want the original function to be as "spread out" as possible (uniform) BUT also as "asymmetric" as possible (so the center of the convolution is reduced).

The ramp is a good compromise. But maybe we can do better with a shape that's:
- Asymmetric (to reduce the center peak)
- But also has some "width" (to avoid endpoint peaks)

What about a_i = sin^2(pi*(i+1)/(2*n))? This is 0 at i=0 and 1 at i=n-1 (approximately), with a smooth transition.

Or a_i = (i/(n-1))^2 for i=0,...,n-1? This is a quadratic ramp.

Let me just try several shapes and see which gives the best score, then optimize from the best one.

Key improvements over the previous solution:
1. Start from asymmetric shapes (ramp, power law, etc.) instead of uniform.
2. Use a better subgradient computation (focus on top-k peaks with proper weighting).

4. Add a "spectral shaping" step: in the frequency domain, try to flatten the power spectrum.

"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using asymmetric initializations
(linear ramp, power laws, trigonometric shapes) combined with exponentiated
gradient optimization using top-k peak subgradients, frequency-domain
flattening, active-set refinement, and local search polishing.
The key insight is that asymmetric non-negative sequences (like ramps)
achieve much lower convolution peaks than symmetric ones, giving a
fundamental advantage over uniform initialization.
"""

import numpy as np
import time


def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]


def compute_score(a):
    """Compute the objective: 2*n*max(conv(a,a))/(sum(a))^2"""
    n = len(a)
    s = a.sum()
    if s < 1e-15:
        return np.inf
    c = fast_convolve(a)
    return 2.0 * n * c.max() / (s * s)


def compute_subgradient(a, c, temperature, top_k):
    """Compute softmax-weighted subgradient of max(c)."""
    n = len(a)
    len_c = len(c)

    if top_k is not None and top_k < len_c and top_k > 0:
        indices = np.argpartition(c, -top_k)[-top_k:]
        peek = c[indices]
    else:
        indices = np.arange(len_c)
        peek = c.copy()

    scaled = peek / temperature
    scaled -= scaled.max()
    w = np.exp(scaled)
    ws = w.sum()
    if ws < 1e-300:
        w = np.zeros(len(indices))
        w[np.argmax(peek)] = 1.0
    else:
        w /= ws

    sg = np.zeros(n)
    for idx in range(len(indices)):
        if w[idx] < 1e-15:
            continue
        k = int(indices[idx])
        js = max(0, k - n + 1)
        je = min(n - 1, k)
        sg[js:je + 1] += 2.0 * w[idx] * a[k - je:k - js + 1][::-1]

    return sg


def eg_optimize(a0, time_limit, eta0=1.0, temp0=0.01,
                temp_decay=0.9995, eta_decay=0.9999,
                top_k_frac=0.3, verbose=False):
    """Exponentiated gradient / multiplicative weights on the simplex."""
    a = np.maximum(a0.astype(np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(len(a)) / len(a)
    else:
        a = a / s
    n = len(a)
    top_k = max(20, int(n * top_k_frac))

    c = fast_convolve(a)
    best_obj = c.max()
    best_a = a.copy()

    avg_a = a.copy().astype(np.float64)
    count = 0

    eta = eta0
    temp = temp0

    t0 = time.monotonic()
    no_improve = 0
    it = 0

    while time.monotonic() - t0 < time_limit:
        it += 1

        sg = compute_subgradient(a, c, temperature=temp, top_k=top_k)
        sg_max = sg.max()
        if sg_max < 1e-15:
            break

        log_update = -eta * sg / sg_max
        log_update -= log_update.max()
        a_new = a * np.exp(log_update)
        a_new = np.maximum(a_new, 1e-300)
        s_new = a_new.sum()
        if s_new < 1e-300:
            a_new = a.copy()
            s_new = 1.0
        a_new = a_new / s_new

        c_new = fast_convolve(a_new)
        obj_new = c_new.max()

        count += 1
        avg_a = (count * avg_a + a_new) / (count + 1)

        if obj_new < best_obj - 1e-14:
            best_obj = obj_new
            best_a = a_new.copy()
            no_improve = 0
            if verbose and it % 5000 == 0:
                print(f"    EG iter {it}: obj={best_obj:.10f}, eta={eta:.6f}, temp={temp:.6f}")
        else:
            no_improve += 1

        a = a_new
        c = c_new

        if it % 2000 == 0:
            c_avg = fast_convolve(avg_a)
            if c_avg.max() < best_obj - 1e-14:
                best_obj = c_avg.max()
                best_a = avg_a.copy()

        eta *= eta_decay
        temp *= temp_decay
        temp = max(temp, temp0 * 0.001)

        if no_improve > 5000:
            rng_local = np.random.default_rng(it * 31 + 7)
            a = best_a + rng_local.standard_normal(n) * 0.001
            a = np.maximum(a, 1e-10)
            ps = a.sum()
            a = a / ps
            c = fast_convolve(a)
            best_obj = c.max()
            no_improve = 0
            eta = max(eta0 * 0.05, 0.01)
            temp = max(temp0 * 0.01, 0.0001)
            avg_a = a.copy()
            count = 0

    return best_a.copy(), best_obj


def spectral_flatten(a, time_limit, n_iter=500):
    """Try to flatten the power spectrum to reduce correlation peak."""
    a = np.maximum(a.astype(np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        return a
    a = a / s
    n = len(a)

    t0 = time.monotonic()
    best_a = a.copy()
    best_obj = fast_convolve(a).max()

    for it in range(n_iter):
        if time.monotonic() - t0 > time_limit:
            break

        A = np.fft.rfft(a, 2 * n)
        P = np.abs(A) ** 2

        # Target: flat power spectrum (but keep DC)
        P_flat = np.ones_like(P)
        P_flat[0] = P[0]  # Keep DC

        # Interpolate between current and flat
        alpha = 0.01
        P_new = (1 - alpha) * P + alpha * P_flat

        # Take sqrt to get amplitude, keep phase
        A_new = np.sqrt(P_new[0] + 0j) + 1j * 0
        for k in range(1, len(P)):
            phase = np.angle(A[k])
            A_new[k] = np.sqrt(P_new[k]) * np.exp(1j * phase)

        a_new = np.fft.irfft(A_new, 2 * n)[:n]
        a_new = np.maximum(a_new, 0)
        s2 = a_new.sum()
        if s2 < 1e-10:
            continue
        a_new = a_new / s2

        obj = fast_convolve(a_new).max()
        if obj < best_obj - 1e-14:
            best_obj = obj
            best_a = a_new.copy()
            alpha = min(alpha * 1.1, 0.1)
        else:
            alpha = max(alpha * 0.9, 0.001)

    return best_a


def local_search(a0, time_limit, max_rounds=500):
    """Local search: multiplicative perturbations on random coordinates."""
    a = np.maximum(a0.astype(np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        return a, np.inf
    a = a / s
    n = len(a)

    c = fast_convolve(a)
    best_obj = c.max()
    best_a = a.copy()

    t0 = time.monotonic()
    rng = np.random.default_rng(42)
    it = 0
    no_improve = 0

    while time.monotonic() - t0 < time_limit and it < max_rounds:
        it += 1
        improved = False

        # Batch perturb: perturb multiple coordinates at once
        batch_size = max(1, n // 8)
        coords = rng.choice(n, size=batch_size, replace=False)

        for i in coords:
            old_val = best_a[i]
            if old_val < 1e-15:
                continue

            best_factor = 1.0
            best_local_obj = best_obj

            for factor in [0.5, 0.7, 0.85, 1.18, 1.43, 2.0,
                           0.6, 0.8, 1.25, 1.67]:
                trial = best_a.copy()
                trial[i] = old_val * factor
                if trial[i] < 0:
                    continue
                s2 = trial.sum()
                if s2 < 1e-15:
                    continue
                trial = trial / s2
                c2 = fast_convolve(trial)
                obj2 = c2.max()
                if obj2 < best_local_obj - 1e-13:
                    best_local_obj = obj2
                    best_factor = factor

            if best_factor != 1.0:
                best_a[i] = old_val * best_factor
                s2 = best_a.sum()
                best_a = best_a / s2
                best_obj = best_local_obj
                improved = True

        if improved:
            no_improve = 0
        else:
            no_improve += 1
            if no_improve > 50:
                break

    return best_a.copy(), best_obj


def active_set_optimize(a0, time_limit, verbose=False):
    """
    Active set method: identify lags where conv is near the max,
    then solve a subproblem to equalize them.
    """
    a = np.maximum(a0.astype(np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        return a, np.inf
    a = a / s
    n = len(a)

    c = fast_convolve(a)
    best_obj = c.max()
    best_a = a.copy()

    t0 = time.monotonic()
    it = 0

    while time.monotonic() - t0 < time_limit:
        it += 1
        c = fast_convolve(a)
        current_max = c.max()

        if current_max < best_obj - 1e-14:
            best_obj = current_max
            best_a = a.copy()

        # Identify active lags (within 1% of max)
        threshold = current_max * 0.99
        active = np.where(c >= threshold)[0]

        if len(active) < 2:
            active = np.where(c >= current_max * 0.95)[0]

        if len(active) < 2:
            break

        # For each active lag k, the "gradient direction" is 2*flip(a) shifted by k
        # We want to find a direction d such that:
        #   (a + t*d)(a + t*d) at active lags decreases
        #   sum(d) = 0 (maintain normalization)
        #   a + t*d >= 0

        # Simple approach: use the negative subgradient projected onto the tangent space
        sg = np.zeros(n)
        for k in active:
            js = max(0, k - n + 1)
            je = min(n - 1, k)
            weight = c[k] / current_max
            sg[js:je + 1] += weight * a[k - je:k - js + 1][::-1]

        # Project onto hyperplane sum(d) = 0
        mean_sg = sg.mean()
        d = sg - mean_sg

        # Multiplicative update
        step = 0.05
        for _ in range(10):  # inner loop to find good step
            a_new = a * np.exp(-step * d / (np.abs(d).max() + 1e-10))
            a_new = np.maximum(a_new, 1e-10)
            s2 = a_new.sum()
            if s2 < 1e-10:
                step *= 0.5
                continue
            a_new = a_new / s2
            c_new = fast_convolve(a_new)
            if c_new.max() < current_max:
                a = a_new
                break
            else:
                step *= 0.5

        if step < 1e-10:
            break

    return best_a.copy(), best_obj


def generate_initializations(n, seed=42):
    """Generate diverse initializations."""
    rng = np.random.default_rng(seed)
    x = np.arange(n, dtype=np.float64)
    inits = []

    # Linear ramp (increasing)
    r = x + 1
    inits.append(r / r.sum())

    # Linear ramp (decreasing)
    r = n - x
    inits.append(r / r.sum())

    # Quadratic ramp
    r = (x + 1) ** 2
    inits.append(r / r.sum())

    # Square root ramp
    r = np.sqrt(x + 1)
    inits.append(r / r.sum())

    # Cubic ramp
    r = (x + 1) ** 3
    inits.append(r / r.sum())

    # Sine shape
    s = np.sin(np.pi * (x + 0.5) / (2 * n))
    s = np.maximum(s, 0.01)
    inits.append(s / s.sum())

    # Cosine ramp
    c = 1 - np.cos(np.pi * x / (n - 1 + 1e-10)) / 2 + 0.01
    inits.append(c / c.sum())

    # Exponential ramp (slow)
    e = np.exp(0.5 * x / n)
    inits.append(e / e.sum())

    # Exponential ramp (fast)
    e = np.exp(2.0 * x / n)
    inits.append(e / e.sum())

    # Edge-concentrated (U-shape)
    u = np.minimum(x, n - 1 - x)
    u = 1.0 / (u + 1.0)
    inits.append(u / u.sum())

    # Uniform
    inits.append(np.ones(n) / n)

    # Random Dirichlet (smooth-ish)
    for alpha in [0.5, 1.0, 2.0, 5.0]:
        r = rng.dirichlet(np.ones(n) * alpha)
        inits.append(r)

    # Smooth random (low-pass filtered)
    for _ in range(3):
        r = np.abs(rng.standard_normal(n))
        # Low-pass filter
        A = np.fft.rfft(r)
        A[int(len(A) * 0.3):] = 0
        r = np.fft.irfft(A, n)
        r = np.maximum(r, 0.01)
        inits.append(r / r.sum())

    return inits


def multi_scale_optimize(a0, time_limit, n_target, seed=42):
    """Optimize at a smaller scale, then upsample and continue."""
    n_orig = len(a0)
    if n_target >= n_orig:
        return eg_optimize(a0, time_limit, eta0=1.0, temp0=0.01,
                            temp_decay=0.9995, eta_decay=0.9999, verbose=False)

    # Downsample
    x_old = np.linspace(0, 1, n_orig)
    x_new = np.linspace(0, 1, n_target)
    a_small = np.interp(x_new, x_old, np.maximum(a0, 0))
    a_small = a_small / a_small.sum()

    # Optimize at small scale
    a_opt_small, _ = eg_optimize(a_small, time_limit * 0.4,
                                  eta0=1.0, temp0=0.01,
                                  temp_decay=0.999, eta_decay=0.9999,
                                  verbose=False)

    # Upsample back
    a_up = np.interp(x_old, x_new, a_opt_small)
    a_up = np.maximum(a_up, 0)
    a_up = a_up / a_up.sum()

    # Continue optimization at full scale
    a_opt_full, _ = eg_optimize(a_up, time_limit * 0.6,
                                 eta0=0.5, temp0=0.005,
                                 temp_decay=0.9997, eta_decay=0.99995,
                                 verbose=False)
    return a_opt_full
