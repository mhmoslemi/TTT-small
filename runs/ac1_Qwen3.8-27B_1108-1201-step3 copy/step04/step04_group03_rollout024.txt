Now I understand the problem better. The key insight is:
- We want the sequence to be asymmetric (front-loaded or back-loaded) so that the "cross" terms in the convolution are small.
- The peak of the convolution will be near one end (where the sequence values are largest), and we want to minimize that peak while keeping the sum fixed.
- This is a trade-off: making the sequence more asymmetric reduces the central peak but increases the peak at one end.

For large n, the optimal sequence is likely to be a "smoothly decreasing" function, like an exponential decay or a power law, possibly with some shaping to equalize the peaks.

Now let me think about the optimization approach:

**Key insight for the gradient**: The gradient of `max_k conv_k(a)` w.r.t. `a[i]` is:
- If the max is at `k*`: gradient is `2*a[k*-i]` (or `a[i]` if `k* = 2i`)
- More generally, if multiple peaks are tied, the gradient is the sum of their contributions.

For the "soft" version using log-sum-exp:
`LSE(a) = (1/beta) * log(sum_k exp(beta * conv_k(a)))`
`dLSE/da[i] = sum_k (exp(beta*conv_k) / sum_j exp(beta*conv_j)) * dconv_k/da[i]`
`= sum_k w_k * 2*a[k-i]` (approximately, with `w_k = exp(beta*conv_k) / sum exp(beta*conv)`)

This is a weighted average of the "mirror" of the sequence at different lags.

**My algorithm plan**:

1. **Initialization**: Start from a geometric or exponential decay, or from the parent.

2. **Main optimization loop**:
   - Compute `conv = convolve(a, a)`
   - Compute the "soft max" gradient using log-sum-exp with annealed beta
   - Update: `a[i] = a[i] * exp(-lr * grad[i])` (multiplicative update, preserves positivity)
   - Or: `a = project_simplex(a - lr * grad)` (additive with projection)
   - Anneal beta over time (start small, increase to emphasize the max)

3. **Coordinate descent refinement**:
   - For each coordinate, do a 1D search to minimize the objective
   - Since the objective as a function of one coordinate (with others fixed, and sum normalized) is unimodal, use ternary search

4. **Final polish**: Very small steps, focusing on the top few peaks.

- The previous approach used FW-LP (expensive LP solves), multiplicative weights with top-k peaks, and peak-chasing subgradient.
- My approach will use:

  - Multiplicative updates (naturally positive)

"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
1. LSE (log-sum-exp) gradient with multiplicative updates and beta annealing
2. Coordinate descent with incremental convolution updates
3. Hybrid hard-max subgradient polish
Key innovation: log-sum-exp gives a smooth surrogate where ALL peaks contribute
to the gradient (weighted by their exponential), leading to more balanced
descent than hard-max. Combined with coordinate descent for exact local optima.
"""

import numpy as np
import time


def fast_convolve(a):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]


def project_simplex(v):
    n = len(v)
    if n == 1:
        return np.array([max(v[0], 0.0)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)


def conv_gradient_peaks(a, peaks, weights):
    """Compute sum of weighted peak gradients.
    
    grad[i] = sum_p w_p * 2*a[p-i] (for valid p-i in [0,n-1])
    """
    n = len(a)
    grad = np.zeros(n)
    for idx, p in enumerate(peaks):
        p = int(p)
        w = weights[idx]
        if w < 1e-15:
            continue
        # a[p-i] is valid when 0 <= p-i < n, i.e., max(0,p-n+1) <= i <= min(n-1,p)
        i_lo = max(0, p - n + 1)
        i_hi = min(n - 1, p)
        if i_lo <= i_hi:
            grad[i_lo:i_hi+1] += 2.0 * w * a[p - i_hi : p - i_lo - 1 : -1]
    return grad


def lse_objective(conv, beta):
    """Compute log-sum-exp(beta * conv) / beta as smooth max approximation."""
    shifted = beta * conv
    shifted -= shifted.max()
    return (shifted.max() + np.log(np.sum(np.exp(shifted)))) / beta

    """Gradient of LSE(beta * conv(a,a)) w.r.t. a.
    
    = sum_k softmax_k * d(conv_k)/d(a)
    where softmax_k = exp(beta*conv_k) / sum exp(beta*conv_j)
    """
    n = len(a)
    m = len(conv)
    
    shifted = beta * conv
    shifted -= shifted.max()
    w = np.exp(shifted)
    w /= w.sum()
    
    # grad[i] = 2 * sum_k w[k] * a[k-i] for valid k-i
    # This is a cross-correlation: grad = 2 * corr(w, a)
    # corr[i] = sum_k w[k] * a[k-i]

    grad = np.zeros(n)
    for i in range(n):

        k_hi = min(m, i + n)
        if k_lo < k_hi:
            # a[k-i] for k in [k_lo, k_hi)
            # k-i ranges from k_lo-i to k_hi-1-i = 0 to k_hi-1-i
            grad[i] = 2.0 * np.dot(w[k_lo:k_hi], a[:k_hi-k_lo])

                # The correct increment at k=2i is x^2 (from a[i]*a[i])
                # We added 2*x*a[i], so we need to subtract 2*x*a[i] and add x^2
                # Net: subtract (2*x*a[i] - x^2) = x*(2*a[i] - x) at k=2i
                if 2 * i < len(conv_base):

                max_conv = conv_x.max()

                    c = d

                    fd = objective(d)

            a[i] = best_x
            s = a.sum()

Looking at this problem, I need to minimize `2*n*max(conv(a,a))/(sum(a))^2` which is scale-invariant. The key insight I'll exploit differently from the previous approach:

1. **Log-sum-exp smoothing**: Instead of hard-max subgradient (which only sees the single peak), I'll use a smooth LSE surrogate where ALL peaks contribute to the gradient, weighted exponentially. This gives much smoother descent.

2. **Coordinate descent with exact 1D search**: When changing one coordinate, the convolution changes in a simple structured way (adding a scaled copy of `a` plus a quadratic correction at one point). I can do golden-section search in O(n) per evaluation.

3. **Different initialization**: Exponential/power-law decays that are inherently asymmetric (the previous approach started from mostly symmetric inits).

4. **Beta annealing**: Start with smooth (small beta) to get out of bad regions, then increase beta to sharpen toward the true max.

"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
1. LSE (log-sum-exp) gradient with multiplicative updates and beta annealing
2. Coordinate descent with O(n) incremental convolution updates per evaluation
3. Hard-max subgradient with rank-weighted peaks for final polish
4. Structured asymmetric initialization (exponential/power-law decays)
Key innovation: LSE gives ALL peaks gradient contribution proportional to exp(beta*peak),
enabling smooth convergence. Coordinate descent with exact 1D golden-section search
achieves local optimality. Combined adversarial peaks strategy fights the max from

def fast_convolve(a):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]


def project_simplex(v):
    n = len(v)
    if n == 1:
        return np.array([max(v[0], 0.0)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)


def lse_grad(conv, a, beta):
    n = len(a)
    m = len(conv)
    shifted = beta * conv
    shifted -= shifted.max()
    w = np.exp(shifted)
    w /= w.sum()
    grad = np.zeros(n)
    for i in range(n):
        k_lo = max(0, i)
        k_hi = min(m, i + n)
        if k_lo < k_hi:
            grad[i] = 2.0 * np.dot(w[k_lo:k_hi], a[:k_hi - k_lo])
    return grad


def peak_grad(f, peaks, weights):
    n = len(f)
    grad = np.zeros(n)
    for idx in range(len(peaks)):
        p = int(peaks[idx])
        w = weights[idx]
        if w < 1e-15:
            continue
        i_lo = max(0, p - n + 1)
        i_hi = min(n - 1, p)
        if i_lo <= i_hi:
            grad[i_lo:i_hi + 1] += 2.0 * w * f[p - i_hi:p - i_lo - 1:-1]
    return grad

def generate_inits(n, parent, rng):
    """Generate diverse asymmetric initializations."""
    inits = []
    x = np.arange(n, dtype=np.float64)
    # Exponential decays (various rates)
    for rate in [0.01, 0.02, 0.03, 0.05, 0.08, 0.1]:
        e = np.exp(-rate * x)
        inits.append(e / e.sum())
        er = np.exp(-rate * (n - 1 - x))
        inits.append(er / er.sum())
    # Power-law decays
    for p in [1.0, 1.5, 2.0, 3.0]:
        pw = (x + 1.0) ** (-p)
        inits.append(pw / pw.sum())
        pwr = (n - x) ** (-p)
        inits.append(pwr / pwr.sum())
    # Cosine window (symmetric baseline)
    c = 0.5 * (1.0 + np.cos(np.pi * (x - (n - 1) / 2.0) / ((n - 1) / 2.0)))
    inits.append(c / c.sum())
    # Mixed exponential
    mx = np.exp(-0.03 * x) * (1.0 + 0.3 * np.cos(2 * np.pi * x / n))
    mx = np.maximum(mx, 0.01)
    inits.append(mx / mx.sum())
    # Random from Dirichlet
    inits.append(rng.dirichlet(np.ones(n) * 0.3))
    inits.append(rng.dirichlet(np.ones(n) * 2.0))
    # Parent interpolation
    if parent is not None:
        px = np.interp(x, np.linspace(0, 1, len(parent)), parent)
        px = np.maximum(px, 0)
        if px.sum() > 1e-10:
            inits.append(px / px.sum())
        # Blend parent with exponential
        blend = 0.5 * parent + 0.5 * np.exp(-0.03 * x)
        blend = np.maximum(blend, 0)
        if blend.sum() > 1e-10:
            inits.append(blend / blend.sum())
    return inits
