Let me think about approach 4 more carefully:

The KKT conditions for min max_k c[k] s.t. sum(a)=1, a>=0 are:
- There exist multipliers w_k >= 0 (for each constraint c[k] <= t) and lambda (for sum(a)=1) and mu_i >= 0 (for a_i >= 0) such that:
  - 2 * sum_k w_k * (T_k a)_i - lambda + mu_i = 0 for each i
  - w_k * (c[k] - t) = 0 for each k (complementary slackness)
  - mu_i * a_i = 0 for each i (complementary slackness)
  - sum_k w_k = 1 (normalization of the max constraint)
  - sum_i a_i = 1
  - a_i >= 0, c[k] <= t

For the "interior" case (a_i > 0 for all i), we need:
  2 * sum_k w_k * (T_k a)_i = lambda for all i

This means the vector sum_k w_k * (T_k a) is constant. Let's call this vector v. Then v = (lambda/2) * 1.

Now, (T_k a)_i = a[k-i] (with appropriate indexing, i.e., a is zero-padded and we take the valid range).

So: sum_k w_k * a[k-i] = constant for all i.

This is saying that the "weighted average" of the shifted copies of a is constant. If w is concentrated on a few lags, this gives us a linear equation in a.

For example, if only lag n-1 (the center) is active, then:
a[n-1-i] = constant for all i, which means a is constant (uniform). This gives the uniform solution.

If lags n-1 and n-2 (and n) are active, we get:
w_{n-1} * a[n-1-i] + w_{n-2} * a[n-2-i] + w_n * a[n-i] = constant

This is a linear recurrence! The solution is a linear combination of exponentials (or polynomial times exponentials for repeated roots).

This is a very useful structural insight! At the optimum, the sequence a should satisfy a linear recurrence determined by the active lags.

**Algorithm based on this insight:**
1. Choose a set of active lags S = {k_1, ..., k_m} (centered around n-1)
2. Solve the linear recurrence to find a
3. Check if the resulting c has its max at exactly the lags in S
4. If yes, we have a candidate optimal solution
5. If no, adjust S and repeat

This is similar to the "Welch bound" construction in frame theory, where you solve for frames that achieve the Welch bound.

Let me formalize this:

Suppose the active lags are n-1-d, n-1-d+1, ..., n-1+d (a window of size 2d+1 around the center).

The KKT condition gives: sum_{j=-d}^{d} w_{n-1+j} * a[n-1+j-i] = lambda/2 for all i.

Let b_i = a[i]. Then: sum_{j=-d}^{d} w_j * b_{n-1+j-i} = lambda/2 for all i.

Let m = n-1-i. Then: sum_{j=-d}^{d} w_j * b_{m+j} = lambda/2 for all m.

This is a sliding window sum! The weighted sum of any window of size (2d+1) of b is constant.

If all w_j are equal (say w_j = 1/(2d+1)), this is just a moving average, and the solution is b being constant (or periodic with period dividing any difference of active lags).

If w is concentrated, e.g., w_{n-1} = 1, then b is constant.

For non-trivial solutions, we need w to be non-uniform. For example, if S = {n-2, n-1, n} with weights (1/4, 1/2, 1/4), then:
(1/4)*b[m-1] + (1/2)*b[m] + (1/4)*b[m+1] = constant

This is a second-order linear recurrence: b[m+1] - 2*b[m] + b[m-1] = 0 (after rearranging), whose solution is b[m] = A + B*m (linear).

"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
1. Template-based initialization exploiting KKT structure
2. Improved LP-based Frank-Wolfe with adaptive constraints
3. Simulated annealing for escaping local minima
4. Subgradient polishing and local search

import numpy as np
from scipy.optimize import linprog
import time


def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]


def project_simplex(v):
    """Euclidean projection onto the probability simplex."""
    n = len(v)
    if n == 1:
        return np.array([max(v[0], 0.0)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)


def build_conv_matrix(f):
    """Build B matrix where (B*g)[k] = (f*g)[k]."""
    n = len(f)
    B = np.zeros((2 * n - 1, n))
    for j in range(n):
        B[j:j + n, j] = f
    return B


def solve_linearized_lp(f, conv_f, B=None, top_k=None):
    """Solve linearized LP: min t s.t. t >= conv_f[k] + 2*(B*g)[k], g >= -f, sum(g)=0."""
    n = len(f)
    if B is None:
        B = build_conv_matrix(f)
    
    if top_k is not None and top_k < len(conv_f):
        peaks = np.argpartition(conv_f, -top_k)[-top_k:]
        A_sub = B[peaks, :]
        b_sub = conv_f[peaks]
    else:
        A_sub = B
        b_sub = conv_f
    
    m = len(b_sub)
    # Variables: [t, g_0, ..., g_{n-1}]
    c = np.zeros(n + 1)
    c[0] = 1.0
    
    A_ub = np.zeros((m, n + 1))
    A_ub[:, 0] = -1.0
    A_ub[:, 1:] = 2.0 * A_sub
    b_ub = -b_sub
    
    A_eq = np.zeros((1, n + 1))
    A_eq[0, 1:] = 1.0
    b_eq = np.zeros(1)
    
    bounds = [(None, None)] + [(-f[i], None) for i in range(n)]
    
    res = linprog(c, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq,
                  bounds=bounds, method='highs')
    if res.success:
        return res.x[1:]
    return None


def solve_maxsum_lp(f, M):
    """Solve: max sum(g) s.t. (f*g)[k] <= M for all k, g >= 0."""
    n = len(f)
    c = -np.ones(n)
    A_ub = np.zeros((2 * n - 1, n))
    for j in range(n):
        A_ub[j:j + n, j] = f
    b_ub = np.full(2 * n - 1, M)
    bounds = [(0, None)] * n
    res = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')
    if res.success and res.x is not None and np.any(res.x > 0):
        return res.x
    return None


def line_search(f, target, current_obj, max_alpha=1.0):
    """Find best alpha for f_new = (1-alpha)*f + alpha*target."""
    best_alpha = 0.0
    best_obj = current_obj
    
    alphas = np.linspace(0.05, max_alpha, 10)
    for alpha in alphas:
        f_new = (1.0 - alpha) * f + alpha * target
        f_new = np.maximum(f_new, 0)
        s = f_new.sum()
        if s < 1e-15:
            continue
        f_new = f_new / s
        obj = fast_convolve(f_new).max()
        if obj < best_obj:
            best_obj = obj
            best_alpha = alpha
    
    if best_alpha > 0:
        lo = max(0.005, best_alpha * 0.5)
        hi = min(max_alpha, best_alpha * 1.5)
        for _ in range(10):
            mid = (lo + hi) / 2.0
            f_new = (1.0 - mid) * f + mid * target
            f_new = np.maximum(f_new, 0)
            s = f_new.sum()
            if s < 1e-15:
                break
            f_new = f_new / s
            obj = fast_convolve(f_new).max()
            if obj < best_obj:
                best_obj = obj
                best_alpha = mid
                lo = mid
            else:
                hi = mid
    
    return best_alpha, best_obj


def lp_fw_optimize(f0, time_limit, top_k=None, verbose=False):
    """LP-based Frank-Wolfe with adaptive constraints."""
    f = np.maximum(f0.astype(np.float64), 0.0)
    s = f.sum()
    if s < 1e-15:
        f = np.ones(len(f)) / len(f)
    else:
        f = f / s
    n = len(f)
    
    conv = fast_convolve(f)
    best_obj = conv.max()
    best_f = f.copy()
    
    t0 = time.monotonic()
    no_improve = 0
    it = 0
    rng = np.random.default_rng(999)
    
    while time.monotonic() - t0 < time_limit:
        it += 1
        conv = fast_convolve(f)
        current_obj = conv.max()
        
        g = solve_linearized_lp(f, conv, top_k=top_k)
        if g is None:
            no_improve += 5
            if no_improve > 50:
                f = project_simplex(best_f + rng.standard_normal(n) * 0.005)
                no_improve = 0
            continue
        
        target = f + g
        target = np.maximum(target, 0.0)
        ts = target.sum()
        if ts < 1e-15:
            no_improve += 1
            continue
        target = target / ts
        
        if np.max(np.abs(target - f)) < 1e-10:
            no_improve += 1
            if no_improve > 30:
                f = project_simplex(best_f + rng.standard_normal(n) * 0.003)
                no_improve = 0
            continue
        
        alpha, obj_val = line_search(f, target, current_obj)
        
        if alpha > 1e-8:
            f = (1.0 - alpha) * f + alpha * target
            f = np.maximum(f, 0.0)
            fs = f.sum()
            if fs > 1e-15:
                f = f / fs
            
            if obj_val < best_obj - 1e-14:
                best_obj = obj_val
                best_f = f.copy()
                no_improve = 0
                if verbose and it % 100 == 0:
                    print(f"    LPFW iter {it}: obj={best_obj:.10f}")
            else:
                no_improve += 1
        else:
            no_improve += 1
        
        if no_improve > 40:
            # Escalating perturbation
            scale = 0.002 + min(no_improve, 50) * 0.0003
            f = project_simplex(best_f + rng.standard_normal(n) * scale)
            no_improve = 0
    
    return best_f, best_obj

def subgrad_optimize(f0, time_limit, lr=0.002, mom=0.93, top_k=30, temp=0.0001):
    """Subgradient descent with multi-peak targeting."""
    f = np.maximum(f0.astype(np.float64), 0.0)
    s = f.sum()
    if s < 1e-15:
        f = np.ones(len(f)) / len(f)
    else:
        f = f / s
    n = len(f)
    
    v = np.zeros(n)
    conv = fast_convolve(f)
    best_obj = conv.max()
    best_f = f.copy()
    
    t0 = time.monotonic()
    no_improve = 0
    cur_lr = lr
    cur_temp = temp
    it = 0
    
    while time.monotonic() - t0 < time_limit:
        it += 1
        if top_k >= len(conv):
            peaks = np.arange(len(conv))
        else:
            peaks = np.argpartition(conv, -top_k)[-top_k:]
        
        pv = conv[peaks]
        scaled = pv / cur_temp
        scaled -= scaled.max()
        w = np.exp(scaled)
        ws = w.sum()
        if ws < 1e-15:
            w = np.zeros(len(peaks))
            w[np.argmax(pv)] = 1.0
        else:
            w /= ws
        
        sg = np.zeros(n)
        for i in range(len(peaks)):
            if w[i] < 1e-13:
                continue
            k = int(peaks[i])
            js = max(0, k - n + 1)
            je = min(n - 1, k)
            idx = np.arange(js, je + 1)
            sg[idx] += 2.0 * w[i] * f[k - idx]
        
        v = mom * v - cur_lr * sg
        f = project_simplex(f + v)
        conv = fast_convolve(f)
        co = conv.max()
        
        if co < best_obj - 1e-14:
            best_obj = co
            best_f = f.copy()
            no_improve = 0
        else:
            no_improve += 1
        
        cur_lr *= 0.9998
        cur_temp *= 1.003
        
        if no_improve > 200:
            rng = np.random.default_rng((it * 31 + 17) % 100000)
            f = project_simplex(best_f + rng.standard_normal(n) * 0.003)
            v = np.zeros(n)
            cur_lr = max(lr * 0.6, 0.0005)
            no_improve = 0
    
    return best_f, best_obj


def simulated_annealing(f0, time_limit, rng, T0=0.001, cooling=0.9995, min_T=1e-6):
    """Simulated annealing to escape local minima."""
    f = np.maximum(f0.astype(np.float64), 0.0)
    s = f.sum()
    if s < 1e-15:
        f = np.ones(len(f)) / len(f)
    else:
        f = f / s
    n = len(f)
    
    conv = fast_convolve(f)
    current_obj = conv.max()
    best_f = f.copy()
    best_obj = current_obj
    
    t0 = time.monotonic()
    T = T0
    it = 0
    step_size = 0.01
    
    while time.monotonic() - t0 < time_limit:
        it += 1
        # Propose perturbation
        noise = rng.standard_normal(n) * step_size
        f_new = project_simplex(f + noise)
        
        conv_new = fast_convolve(f_new)
        obj_new = conv_new.max()
        
        delta = obj_new - current_obj
        if delta < 0 or rng.random() < np.exp(-delta / T):
            f = f_new
            current_obj = obj_new
            if obj_new < best_obj - 1e-14:
                best_obj = obj_new
                best_f = f.copy()
        
        T = max(T * cooling, min_T)
        step_size = 0.01 * T / T0 + 0.001
    
    return best_f, best_obj

def template_init(n, parent=None, rng=None):
    """Generate template-based initializations using KKT structure."""
    if rng is None:
        rng = np.random.default_rng(0)
    
    inits = []
    
    # Uniform
    inits.append(np.ones(n) / n)
    
    # Gaussian with various widths
    x = np.arange(n, dtype=np.float64)
    for sigma in [0.15, 0.2, 0.3, 0.4, 0.5]:
        g = np.exp(-0.5 * ((x - 0.5*(n-1)) / (sigma*n))**2)
        inits.append(g / g.sum())
    
    # Cosine
    c = np.abs(np.cos(np.pi * x / n)) + 0.1
    inits.append(c / c.sum())
    
    # Linear ramp (from KKT with 3 active lags)
    ramp = np.arange(1, n+1, dtype=np.float64)
    inits.append(ramp / ramp.sum())
    inits.append(ramp[::-1].astype(np.float64) / ramp[::-1].astype(np.float64).sum())
    
    # Parabolic
    para = np.exp(-((x - 0.5*(n-1)) / (n*0.3))**4)
    inits.append(para / para.sum())
    
    # Bimodal
    b = np.exp(-0.5*((x - 0.25*n)/(n*0.15))**2) + np.exp(-0.5*((x - 0.75*n)/(n*0.15))**2)
    inits.append(b / b.sum())

Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using a multi-phase approach:
1. Template-based initialization exploiting KKT structure insights
2. LP-based Frank-Wolfe with adaptive constraint selection
3. Max-sum LP Frank-Wolfe for larger jumps

import numpy as np
from scipy.optimize import linprog
import time


def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]


def project_simplex(v):
    """Euclidean projection onto the probability simplex {x>=0, sum(x)=1}."""
    n = len(v)
    if n == 1:
        return np.array([max(v[0], 0.0)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)


def build_conv_matrix(f):
    """Build B matrix where (B@g)[k] = (f*g)[k]."""
    n = len(f)
    B = np.zeros((2 * n - 1, n))
    for j in range(n):
        B[j:j + n, j] = f
    return B


def solve_linearized_lp(f, conv_f, top_k=None):
    """Solve linearized LP: min t s.t. t >= conv_f[k] + 2*(B@g)[k], g >= -f, sum(g)=0."""
    n = len(f)
    B = build_conv_matrix(f)

    if top_k is not None and top_k < len(conv_f):
        peaks = np.argpartition(conv_f, -top_k)[-top_k:]
        A_sub = B[peaks, :]
        b_sub = conv_f[peaks]
    else:
        A_sub = B
        b_sub = conv_f

    m = len(b_sub)
    c = np.zeros(n + 1)
    c[0] = 1.0

    A_ub = np.zeros((m, n + 1))
    A_ub[:, 0] = -1.0
    A_ub[:, 1:] = 2.0 * A_sub
    b_ub = -b_sub

    A_eq = np.zeros((1, n + 1))
    A_eq[0, 1:] = 1.0
    b_eq = np.zeros(1)

    bounds = [(None, None)] + [(-f[i], None) for i in range(n)]

    res = linprog(c, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq,
                  bounds=bounds, method='highs')
    if res.success:
        return res.x[1:]
    return None


def solve_maxsum_lp(f, M):
    """Solve: max sum(g) s.t. (f*g)[k] <= M for all k, g >= 0."""
    n = len(f)
    c = -np.ones(n)
    A_ub = np.zeros((2 * n - 1, n))
    for j in range(n):
        A_ub[j:j + n, j] = f
    b_ub = np.full(2 * n - 1, M)
    bounds = [(0, None)] * n
    res = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')
    if res.success and res.x is not None and np.any(res.x > 0):
        return res.x
    return None

    for alpha in alphas:
        f_new = (1.0 - alpha) * f + alpha * target
        f_new = np.maximum(f_new, 0)
        s = f_new.sum()
        if s < 1e-15:
            continue
        f_new = f_new / s
        obj = fast_convolve(f_new).max()
        if obj < best_obj:
            best_obj = obj
            best_alpha = alpha

    if best_alpha > 0:
        lo = max(0.005, best_alpha * 0.5)
        hi = min(max_alpha, best_alpha * 1.5)
        for _ in range(12):
            mid = (lo + hi) / 2.0

            f_new = np.maximum(f_new, 0)
            s = f_new.sum()
            if s < 1e-15:

            f_new = f_new / s
            obj = fast_convolve(f_new).max()
            if obj < best_obj:
                best_obj = obj
                best_alpha = mid
                lo = mid
            else:
                hi = mid

    rng = np.random.default_rng(12345 + n)

    while time.monotonic() - t0 < time_limit:
        it += 1

        g = solve_maxsum_lp(f, M * m_exp)
        if g is None:
            m_exp *= 1.1
            if m_exp > 5.0:
                m_exp = 1.0
            continue

        g_sum = g.sum()
        if g_sum < 1e-15:
            break
        g = g / g_sum

        if np.max(np.abs(g - f)) < 1e-9:
            no_improve += 1
            if no_improve > 30:
                break
            m_exp = min(m_exp * 1.05, 3.0)
            continue

        best_alpha = 0.0
        best_val = M
        for alpha in [0.05, 0.1, 0.2, 0.3, 0.5, 0.7, 1.0]:
            ft = (1.0 - alpha) * f + alpha * g
            ft = np.maximum(ft, 0)
            st = ft.sum()
            if st < 1e-15:
                continue
            ft = ft / st
            val = fast_convolve(ft).max()
            if val < best_val:
                best_val = val
                best_alpha = alpha

        if best_alpha > 1e-10:
            # Fine-tune alpha
            lo = max(0.0, best_alpha - 0.08)
            hi = min(1.0, best_alpha + 0.08)
            for _ in range(8):
                mid = (lo + hi) / 2.0
                ft = (1.0 - mid) * f + mid * g
                ft = np.maximum(ft, 0)
                st = ft.sum()
                if st < 1e-15:
                    break
                ft = ft / st
                val = fast_convolve(ft).max()
                if val < best_val:
                    best_val = val
                    best_alpha = mid
                    lo = mid
                else:
                    hi = mid

            f = (1.0 - best_alpha) * f + best_alpha * g
            f = np.maximum(f, 0)
            f = f / f.sum()
            M = fast_convolve(f).max()
            m_exp = 1.0

            if M < best_obj - 1e-14:
                best_obj = M
                best_f = f.copy()
                no_improve = 0
                if verbose and it % 50 == 0:
                    print(f"    MaxFW iter {it}: obj={best_obj:.10f}")
            else:
                no_improve += 1
        else:
            no_improve += 1
            m_exp = min(m_exp * 1.08, 4.0)

        if no_improve > 40:
            f = project_simplex(best_f + rng.standard_normal(n) * 0.005)
            M = fast_convolve(f).max()
            m_exp = 1.0
            no_improve = 0

    return best_f, best_obj


def subgrad_optimize(f0, time_limit, lr=0.002, mom=0.94, top_k=30, temp=5e-5):
    """Subgradient descent with softmax-weighted multi-peak targeting."""
    f = np.maximum(f0.astype(np.float64), 0.0)
    s = f.sum()
    if s < 1e-15:
        f = np.ones(len(f)) / len(f)
    else:
        f = f / s
    n = len(f)

    v = np.zeros(n)
    conv = fast_convolve(f)
    best_obj = conv.max()
    best_f = f.copy()

    t0 = time.monotonic()
    no_improve = 0
    cur_lr = lr
    cur_temp = temp
    it = 0

    while time.monotonic() - t0 < time_limit:
        it += 1
        if top_k >= len(conv):
            peaks = np.arange(len(conv))
        else:
            peaks = np.argpartition(conv, -top_k)[-top_k:]

        pv = conv[peaks]
        scaled = pv / cur_temp
        scaled -= scaled.max()
        w = np.exp(scaled)
        ws = w.sum()
        if ws < 1e-15:
            w = np.zeros(len(peaks))
            w[np.argmax(pv)] = 1.0
        else:
            w /= ws

        sg = np.zeros(n)
        for i in range(len(peaks)):
            if w[i] < 1e-13:
                continue
            k = int(peaks[i])
            js = max(0, k - n + 1)
            je = min(n - 1, k)
            idx = np.arange(js, je + 1)
            sg[idx] += 2.0 * w[i] * f[k - idx]

        v = mom * v - cur_lr * sg
        f = project_simplex(f + v)
        conv = fast_convolve(f)
        co = conv.max()

        if co < best_obj - 1e-14:
            best_obj = co
            best_f = f.copy()
            no_improve = 0
        else:
            no_improve += 1

        cur_lr *= 0.9998
        cur_temp *= 1.003

        if no_improve > 250:
            rng = np.random.default_rng((it * 31 + 17) % 100000)
            f = project_simplex(best_f + rng.standard_normal(n) * 0.003)
            v = np.zeros(n)
            cur_lr = max(lr * 0.6, 0.0004)
            no_improve = 0

    return best_f, best_obj


def simulated_annealing(f0, time_limit, rng, T0=0.002, cooling=0.9998, min_T=3e-5):
    """Simulated annealing for escaping local minima."""
    f = np.maximum(f0.astype(np.float64), 0.0)
    s = f.sum()
    if s < 1e-15:
        f = np.ones(len(f)) / len(f)
    else:
        f = f / s
    n = len(f)

    conv = fast_convolve(f)
    current_obj = conv.max()
    best_f = f.copy()
    best_obj = current_obj

    t0 = time.monotonic()
    T = T0
    it = 0
    base_step = 0.012

    while time.monotonic() - t0 < time_limit:
        it += 1
        step_size = base_step * (T / T0) + 0.002
        noise = rng.standard_normal(n) * step_size
        f_new = project_simplex(f + noise)

        conv_new = fast_convolve(f_new)
        obj_new = conv_new.max()

        delta = obj_new - current_obj
        if delta < 0 or (T > min_T and rng.random() < np.exp(-delta / T)):
            f = f_new
            current_obj = obj_new
            if obj_new < best_obj - 1e-14:
                best_obj = obj_new
                best_f = f.copy()

        T = max(T * cooling, min_T)

    return best_f, best_obj


def local_search(f0, time_limit, rng):
    """Local search with adaptive perturbation and restarts."""
    f = np.maximum(f0.astype(np.float64), 0.0)
    s = f.sum()
    if s < 1e-15:
        f = np.ones(len(f)) / len(f)
    else:
        f = f / s
    n = len(f)

    conv = fast_convolve(f)
    best_obj = conv.max()
    best_f = f.copy()

    t0 = time.monotonic()
    scale = 0.006

    while time.monotonic() - t0 < time_limit:
        found = False
        for _ in range(300):
            if time.monotonic() - t0 > time_limit:
                break
            noise = rng.standard_normal(n) * scale
            f_pert = project_simplex(best_f + noise)
            obj = fast_convolve(f_pert).max()
            if obj < best_obj - 1e-14:
                best_obj = obj
                best_f = f_pert.copy()
                found = True
        if not found:
            scale *= 0.7
            if scale < 5e-5:
                # Moderate reset
                f_jump = project_simplex(best_f + rng.standard_normal(n) * 0.004)
                obj = fast_convolve(f_jump).max()
                if obj < best_obj:
                    best_obj = obj
                    best_f = f_jump.copy()
                scale = 0.003

    return best_f, best_obj


def generate_templates(n, parent, rng):
    """Generate diverse initializations using various structural templates."""
    inits = []
    x = np.arange(n, dtype=np.float64)

    # Uniform
    inits.append(np.ones(n) / n)

    # Gaussian with various widths
    for sigma in [0.12, 0.18, 0.25, 0.35, 0.5]:
        g = np.exp(-0.5 * ((x - 0.5 * (n - 1)) / (sigma * n)) ** 2)
        inits.append(g / g.sum())

    # Cosine variants
    c1 = np.abs(np.cos(np.pi * x / n)) + 0.05
    inits.append(c1 / c1.sum())
    c2 = np.cos(np.pi * x / n) ** 2 + 0.1
    inits.append(c2 / c2.sum())

    # Linear ramp (KKT with 3 active lags suggests linear solutions)
    ramp = np.arange(1, n + 1, dtype=np.float64)
    inits.append(ramp / ramp.sum())

    # Parabolic
    para = np.exp(-((x - 0.5 * (n - 1)) / (n * 0.25)) ** 4)
    inits.append(para / para.sum())

    # Bimodal
    b = (np.exp(-0.5 * ((x - 0.25 * n) / (n * 0.12)) ** 2) +
         np.exp(-0.5 * ((x - 0.75 * n) / (n * 0.12)) ** 2))
    inits.append(b / b.sum())

    # U-shape (edge concentration)
    u = 1.0 / (0.5 * np.abs(x - 0.5 * (n - 1)) / n + 0.05)
    inits.append(u / u.sum())

    # Beta-like
    beta_seq = (x + 1) ** 1.5 * (n - x) ** 1.5
    inits.append(beta_seq / beta_seq.sum())

    # Random Dirichlet
    for alpha in [0.3, 0.7, 1.5, 3.0]:
        inits.append(rng.dirichlet(np.ones(n) * alpha))

    # Interpolate from parent
    if parent is not None:
        px = np.interp(np.linspace(0, 1, n), np.linspace(0, 1, len(parent)), parent)
        px = np.maximum(px, 0)
        ps = px.sum()
        if ps > 1e-10:
            inits.append(px / ps)
        # Perturbed parent
        for scale in [0.01, 0.03, 0.05]:
            pp = px + rng.standard_normal(n) * scale
            pp = np.maximum(pp, 0)
            ps2 = pp.sum()
            if ps2 > 1e-10:
                inits.append(pp / ps2)

    return inits


def genetic_interpolation(candidates, rng, n_target):
    """Interpolate between two random candidates to create a new diverse solution."""
    if len(candidates) < 2:
        return None
    i = rng.integers(len(candidates))
    j = rng.integers(len(candidates))
    while j == i and len(candidates) > 1:
        j = rng.integers(len(candidates))

    a = np.interp(np.linspace(0, 1, n_target), np.linspace(0, 1, len(candidates[i])), candidates[i])
    b = np.interp(np.linspace(0, 1, n_target), np.linspace(0, 1, len(candidates[j])), candidates[j])

    alpha = rng.uniform(0.2, 0.8)
    result = alpha * a + (1 - alpha) * b
    result = np.maximum(result, 0)
    rs = result.sum()
    if rs > 1e-10:
        return result / rs
    return None


def propose_candidate(seed=42, budget_s=1800, **kwargs):
    """
    Main entry point. Multi-phase search combining LP-FW, max-sum FW,
    simulated annealing, subgradient, and local search with multi-length
    exploration and genetic-style diversity maintenance.
    """
    rng = np.random.default_rng(seed)
    deadline = time.monotonic() + max(1.0, float(budget_s) - 30.0)

    best_seq = None
    best_score = float('inf')
    hall_of_fame = []  # Store diverse good solutions

    def update_best(a, label):
        nonlocal best_seq, best_score
        a = np.maximum(a, 0.0)
        if len(a) == 0:
            return
        score = float(evaluate_sequence(a.tolist()))
        if np.isfinite(score) and score < best_score:
            best_score = score
            best_seq = a.copy()
            hall_of_fame.append(a.copy())
            if len(hall_of_fame) > 20:
                hall_of_fame.pop(0)
            print(f"  NEW BEST [{label}]: {score:.8f} (n={len(a)})")
        elif np.isfinite(score) and score < best_score + 0.005:
            hall_of_fame.append(a.copy())
            if len(hall_of_fame) > 20:
                hall_of_fame.pop(0)
        return score

    # Load parent
    parent = None
    try:
        p = np.asarray(height_sequence_1, dtype=np.float64)
        p = np.clip(p, 0.0, 1000.0)
        if p.ndim == 1 and p.size > 0 and np.isfinite(p).all() and p.sum() > 1e-10:
            parent = p / p.sum()
            print(f"Parent loaded: n={len(parent)}")
    except Exception:
        pass

    if parent is None:
        n_p = 384
        parent = np.ones(n_p) / n_p
    else:
        n_p = len(parent)

    # === Phase 1: Broad initialization ===
    print("=== Phase 1: Initialization ===")
    t_start = time.monotonic()

    update_best(parent, "parent")

    # Try templates at parent length
    templates = generate_templates(n_p, parent, rng)
    for i, tmpl in enumerate(templates[:8]):
        if time.monotonic() > deadline - 800:
            break
        update_best(tmpl, f"tmpl_{i}")

    # Try other lengths
    for n_try in [n_p - 48, n_p - 16, n_p + 16, n_p + 48, n_p + 80]:
        if n_try < 64 or time.monotonic() > deadline - 600:
            continue
        tmpl = generate_templates(n_try, parent, rng)[0]  # uniform
        update_best(tmpl, f"n{n_try}_uni")

    print(f"  Phase 1 best: {best_score:.8f} (n={len(best_seq)})")

    # === Phase 2: Primary LP-FW optimization ===
    print("=== Phase 2: LP-FW (primary) ===")
    n_best = len(best_seq)
    remaining = deadline - time.monotonic() - 500
    t_p2 = min(remaining * 0.45, 600)

    if t_p2 > 30:
        print(f"  LP-FW full (n={n_best}), budget={t_p2:.0f}s")
        a_opt, _ = lp_fw_optimize(best_seq, time_limit=t_p2, top_k=None, verbose=True)
        update_best(a_opt, "lpfw_full")

    # Quick reduced LP-FW from perturbed start
    rem = deadline - time.monotonic() - 350
    if rem > 20:
        t_p2b = min(rem * 0.4, 200)
        if t_p2b > 15:
            noise = rng.standard_normal(n_best) * 0.015
            f_pert = project_simplex(best_seq + noise)
            a_opt, _ = lp_fw_optimize(f_pert, time_limit=t_p2b, top_k=25)
            update_best(a_opt, "lpfw_pert")

    # LP-FW from a genetic interpolation
    rem = deadline - time.monotonic() - 250
    if rem > 20 and len(hall_of_fame) >= 2:
        t_p2c = min(rem * 0.3, 120)
        if t_p2c > 10:
            geno = genetic_interpolation(hall_of_fame, rng, n_best)
            if geno is not None:
                a_opt, _ = lp_fw_optimize(geno, time_limit=t_p2c, top_k=20)
                update_best(a_opt, "lpfw_gen")

    print(f"  Phase 2 best: {best_score:.8f}")

    # === Phase 3: Max-sum FW ===
    print("=== Phase 3: Max-sum FW ===")
    rem = deadline - time.monotonic() - 300
    t_p3 = min(rem * 0.4, 350)

    if t_p3 > 20:
        print(f"  Max-FW (n={n_best}), budget={t_p3:.0f}s")
        a_opt, _ = maxsum_fw(best_seq, time_limit=t_p3, verbose=True)
        update_best(a_opt, "maxfw")

        # Perturbed max-sum FW
        rem2 = deadline - time.monotonic() - 150
        if rem2 > 20:
            noise = rng.standard_normal(n_best) * 0.01
            f_pert = project_simplex(best_seq + noise)
            t_p3b = min(rem2 * 0.4, 150)
            if t_p3b > 15:
                a_opt, _ = maxsum_fw(f_pert, time_limit=t_p3b)
                update_best(a_opt, "maxfw_pert")

    print(f"  Phase 3 best: {best_score:.8f}")

    # === Phase 4: Simulated Annealing ===
    print("=== Phase 4: Simulated Annealing ===")
    rem = deadline - time.monotonic() - 200
    t_p4 = min(rem * 0.4, 200)

    if t_p4 > 15:
        print(f"  SA (n={n_best}), budget={t_p4:.0f}s")
        a_opt, _ = simulated_annealing(best_seq, time_limit=t_p4, rng=rng,
                                       T0=0.003, cooling=0.99985, min_T=2e-5)
        update_best(a_opt, "sa1")

        # Second SA with different parameters
        rem2 = deadline - time.monotonic() - 100
        if rem2 > 15:
            t_p4b = min(rem2 * 0.3, 100)
            if t_p4b > 10:
                a_opt, _ = simulated_annealing(best_seq, time_limit=t_p4b, rng=rng,
                                               T0=0.008, cooling=0.99995, min_T=5e-5)
                update_best(a_opt, "sa2")

    print(f"  Phase 4 best: {best_score:.8f}")

    # === Phase 5: Subgradient polishing ===
    print("=== Phase 5: Subgradient Polish ===")
    rem = deadline - time.monotonic() - 120
    t_p5 = min(rem * 0.4, 120)

    if t_p5 > 10:
        a_opt, _ = subgrad_optimize(best_seq, time_limit=t_p5,
                                    lr=0.0015, mom=0.95, top_k=n_best // 4, temp=3e-5)
        update_best(a_opt, "sg1")

        rem2 = deadline - time.monotonic() - 80
        if rem2 > 10:
            t_p5b = min(rem2 * 0.4, 60)
            if t_p5b > 8:
                a_opt, _ = subgrad_optimize(best_seq, time_limit=t_p5b,
                                            lr=0.0008, mom=0.96, top_k=n_best // 2, temp=1e-5)
                update_best(a_opt, "sg2_fine")

    print(f"  Phase 5 best: {best_score:.8f}")

    # === Phase 6: Local Search ===
    print("=== Phase 6: Local Search ===")
    rem = deadline - time.monotonic() - 80
    t_p6 = min(rem * 0.4, 80)

    if t_p6 > 8:
        a_opt, _ = local_search(best_seq, time_limit=t_p6, rng=rng)
        update_best(a_opt, "local")

    print(f"  Phase 6 best: {best_score:.8f}")

    # === Phase 7: Final optimization round ===
    print("=== Phase 7: Final Round ===")
    rem = deadline - time.monotonic() - 30

    if rem > 15 and best_seq is not None:
        n_best = len(best_seq)

        # Final LP-FW with reduced constraints
        if rem > 25:
            t_final = min(rem * 0.35, 40)
            a_opt, _ = lp_fw_optimize(best_seq, time_limit=t_final, top_k=15)
            update_best(a_opt, "final_lpfw")

        # Try one more SA + polish cycle
        rem2 = deadline - time.monotonic() - 20
        if rem2 > 20:
            t_sa = min(rem2 * 0.3, 30)
            if t_sa > 10:
                a_opt, _ = simulated_annealing(best_seq, time_limit=t_sa, rng=rng,
                                               T0=0.001, cooling=0.9999, min_T=1e-5)
                update_best(a_opt, "final_sa")
                rem3 = deadline - time.monotonic() - 10
                if rem3 > 8:
                    a_opt, _ = local_search(a_opt, time_limit=min(rem3 * 0.6, 15), rng=rng)
                    update_best(a_opt, "final_ls")

        # Try nearby lengths
        rem2 = deadline - time.monotonic() - 10
        for n_try in [n_best - 8, n_best + 8, n_best - 32]:
            if n_try < 32 or rem2 < 8:
                continue
            px = np.interp(np.linspace(0, 1, n_try), np.linspace(0, 1, n_best), best_seq)
            px = np.maximum(px, 0)
            ps = px.sum()
            if ps > 1e-10:
                px = px / ps
                a_opt, _ = lp_fw_optimize(px, time_limit=min(rem2 * 0.4, 15), top_k=12)
                update_best(a_opt, f"len{n_try}")
            rem2 = deadline - time.monotonic() - 5

    # Final verification
    if best_seq is not None:
        fs = float(evaluate_sequence(best_seq.tolist()))
        if np.isfinite(fs):
            best_score = fs
        print(f"\nFINAL SCORE: {best_score:.10f} (n={len(best_seq)})")
    else:
        best_seq = np.ones(384) / 384
        best_score = float(evaluate_sequence(best_seq.tolist()))
        print(f"\nFALLBACK SCORE: {best_score:.10f}")

    return [float(x) for x in best_seq]
