where $y \in \mathbb{R}^{2n-1}$ and $C \in \mathbb{R}^{(2n-1) \times n}$.

The dual has $2n-1$ variables and $n$ constraints. The constraint $C^T y \geq \mathbf{1}$ means for each $j$:
$$\sum_k C[k,j] y_k \geq 1$$
$$\sum_k a[k-j] y_k \geq 1 \quad \text{(for valid } k\text{)}$$

This is a set of $n$ convolution constraints: $(a^* * y)_j \geq 1$ where $a^*$ is the time-reversed $a$.

This is interesting! The dual is: minimize $M \sum y_k$ subject to $(a_{\text{rev}} * y) \geq \mathbf{1}$ element-wise and $y \geq 0$.

This is a "deconvolution" problem in some sense. And the constraint matrix is again Toeplitz, so we can use FFT-based methods.

For a **first-order method on the dual** (like proximal gradient):
- The objective is linear: $M \sum y_k$
- The constraint is $\min_j (a_{\text{rev}} * y)_j - 1 \geq 0$

We can use a **penalty method**: minimize $M \sum y_k + \rho \cdot \sum_j \max(0, 1 - (a_{\text{rev}} * y)_j)^2$

This can be solved with gradient descent where each gradient step requires one convolution (FFT-based, $O(n \log n)$).

This could be MUCH faster than solving the full LP!

This is a **sliding window sum** constraint! The sum of $y$ over any window of length $n$ starting at position $j$ must be at least $1/a[j]$.

This is a very structured problem! The constraints are:
$$\sum_{k=j}^{j+n-1} y_k \geq 1/a[j] \quad \forall j$$

And we want to minimize $\sum y_k$.

This is like a **covering problem** with interval constraints. It can be solved efficiently!

In fact, this is a **linear program with an interval matrix** (the constraint matrix is a consecutive-ones matrix), which is **totally unimodular**. So the LP has integer optimal solutions (if the RHS were integers), and more importantly, it can be solved in polynomial time using specialized algorithms.

Even better, since the constraint matrix is a "consecutive ones" matrix, the problem can be solved in $O(n \log n)$ using a greedy algorithm or a specialized simplex method!

Let me think about the greedy algorithm:
- We want to minimize $\sum y_k$ subject to $\sum_{k=j}^{j+n-1} y_k \geq b_j$ for all $j$, where $b_j = 1/a[j]$.
- This is the "minimum weight interval covering" problem.

Actually, this is a classic problem in operations research. The greedy algorithm for this (when the intervals have a specific structure) is:
1. Sort the constraints by their right endpoint.
2. For each constraint, if it's not satisfied, add mass to the rightmost available position.

But since all intervals have the same length $n$, the structure is even simpler.

Let me think about this differently. We have variables $y_0, y_1, ..., y_{2n-2}$ (total $2n-1$ variables) and constraints:
$$\sum_{k=j}^{j+n-1} y_k \geq b_j \quad \text{for } j = 0, 1, ..., n-1$$

The constraint for $j$ involves variables $y_j, y_{j+1}, ..., y_{j+n-1}$.

This is a **banded** constraint matrix. The efficient algorithm is:

**Greedy algorithm for interval covering:**
1. Process constraints from $j=0$ to $j=n-1$.
2. For constraint $j$, compute the current sum $S_j = \sum_{k=j}^{j+n-1} y_k$.
3. If $S_j < b_j$, we need to add $b_j - S_j$ more mass. Add it to position $j+n-1$ (the rightmost position in the window), because it will also help future constraints.
4. Set $y_{j+n-1} += b_j - S_j$.

- Adding mass to the rightmost position in the current window helps the most future windows.
- The constraints are "nested" in a specific way (each new constraint extends the right end by 1 and extends the left end by 1).

def solve_dual_greedy(a):
    """Solve the dual: min sum(y) s.t. a[j]*sum_{k=j}^{j+n-1} y_k >= 1, y >= 0."""
    n = len(a)
    b = 1.0 / np.maximum(a, 1e-30)  # b[j] = 1/a[j]
    y = np.zeros(2*n - 1)
    window_sum = 0.0
    for j in range(n):
        if j > 0:
            window_sum -= y[j-1]  # y[j-1] leaves the window
            # y[j+n-1] enters the window but is 0 (not yet set)
        if window_sum < b[j]:
            deficit = b[j] - window_sum
