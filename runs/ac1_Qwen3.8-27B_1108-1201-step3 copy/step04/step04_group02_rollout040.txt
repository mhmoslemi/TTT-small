- r_k = 1 if k = 2m else 0

So f(delta) = max( (p_{2m} + q_{2m}*delta + delta^2) / (S+delta)^2,  max_{k≠2m} (p_k + q_k*delta) / (S+delta)^2 )

For the k ≠ 2m terms, the numerator is linear in delta. For k = 2m, it's quadratic.

The function (p_k + q_k*delta) / (S+delta)^2 for k ≠ 2m has derivative:
q_k*(S+delta)^2 - (p_k + q_k*delta)*2*(S+delta) all divided by (S+delta)^4
= [q_k*(S+delta) - 2*(p_k + q_k*delta)] / (S+delta)^3
= [q_k*S + q_k*delta - 2*p_k - 2*q_k*delta] / (S+delta)^3
= [q_k*S - 2*p_k - q_k*delta] / (S+delta)^3

Setting to 0: q_k*S - 2*p_k - q_k*delta = 0 => delta = S - 2*p_k/q_k (if q_k ≠ 0)

At this delta, the value is: (p_k + q_k*(S - 2*p_k/q_k)) / (S + S - 2*p_k/q_k)^2
= (p_k + q_k*S - 2*p_k) / (2*S - 2*p_k/q_k)^2
= (q_k*S - p_k) / (2*(S - p_k/q_k))^2
= q_k*(q_k*S - p_k) / (4*(q_k*S - p_k)^2)
= q_k / (4*(q_k*S - p_k))

(assuming q_k > 0 and q_k*S > p_k)

So for each k with q_k > 0, the individual function (p_k + q_k*delta)/(S+delta)^2 achieves its minimum at delta_k = S - 2*p_k/q_k with value q_k/(4*(q_k*S - p_k)).

The overall f(delta) = max of all these (plus the quadratic one for k=2m). The minimum of the max occurs where the "envelope" is minimized.

This is a classical "minimax" 1D problem. The optimal delta* is where two (or more) of the individual functions are equal and at their "knee."

A practical approach: 
1. Find delta* by bisection on the derivative (which is the max of the individual derivatives)

"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
1. Smooth soft-max subgradient descent with adaptive temperature and momentum
2. Coordinate descent polishing (exploits per-coordinate 1D structure)
3. Multi-scale exploration with diverse initializations for n up to 2048
4. Careful time management to maximize improvement within 1800s budget
"""

import numpy as np
import time


def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]


def project_simplex(v):
    """Euclidean projection onto the probability simplex."""
    n = len(v)
    if n == 1:
        return np.array([max(v[0], 0.0)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)


def soft_max_gradient(f, conv, beta):
    """
    Compute gradient of soft_max(conv, beta) w.r.t. f.
    soft_max = (1/beta) * log(sum(exp(beta * conv_k)))
    gradient_m = sum_k w_k * 2 * f[k-m] (with f out of range = 0)
    where w_k = exp(beta * conv_k) / sum(exp(beta * conv_j))
    """
    n = len(f)
    # Compute softmax weights
    scaled = beta * conv
    scaled -= scaled.max()
    w = np.exp(scaled)
    wsum = w.sum()
    w /= wsum
    
    # For each m, gradient = sum_k w_k * 2 * f[k-m]
    # This is 2 * (w * f) circular-ish convolution, but not exactly
    # Actually: grad_m = 2 * sum_{k: 0<=k-m<n} w_k * f[k-m]
    #           = 2 * sum_{j: 0<=j<n} w_{m+j} * f[j]  (where w is defined for k in [0, 2n-2])
    
    # This is a correlation of w with f
    # grad_m = 2 * sum_j f[j] * w[m+j]
    # This is the cross-correlation of f and w, evaluated at lag m
    
    # Using FFT:
    # cross_corr[m] = sum_j f[j] * w[m+j] for m = 0, ..., n-1
    # w has length 2n-1, f has length n
    # We want: for each m in [0, n-1], sum over j in [0, n-1] of f[j] * w[m+j]
    # = sum over j of f[j] * w[m+j]
    # This is like a "sliding dot product"
    
    # Method 1: Direct (O(n^2)) - too slow for large n
    # Method 2: FFT-based
    
    # Note: sum_j f[j] * w[m+j] = <f, shift_{-m}(w[:n+m])> ... this is getting complex
    # Let me just do it with a few FFTs
    
    # Actually, the simplest FFT approach:
    # Let W = w (length 2n-1), F = f (length n)
    # We want c[m] = sum_j F[j] * W[m+j] for m=0,...,n-1
    # This is the "anti-convolution" or cross-correlation
    
    # Rearrange: c[m] = sum_j F[j] * W[m+j]
    # Let's define V[j] = W[j] (padded to length 2n-1)
    # c[m] = sum_j F[j] * V[m+j]
    #      = <F, V_shifted> where V_shifted[j] = V[m+j]
    
    # Using the property: if we define G[j] = F[n-1-j] (reversed F), then:
    # c[m] = sum_j G[n-1-j] * V[m+j]
    #      = (G * V)[n-1+m]  (convolution of G and V, evaluated at n-1+m)
    
    # So c = ifft(fft(G) * fft(V))[n-1 : n-1+n]
    
    G = f[::-1]
    fft_size = 1 << (2 * (2*n-1) - 2 - 1).bit_length()  # need length 3n-3 at least
    fft_size = 1 << (3 * n).bit_length()  # safe upper bound
    FG = np.fft.rfft(G, fft_size)
    VW = np.fft.rfft(w, fft_size)
    corr = np.fft.irfft(FG * VW, fft_size)
    # c[m] = corr[n-1+m] for m = 0, ..., n-1
    grad = 2.0 * corr[n-1:n-1+n]
    
    return grad


def soft_max_value(conv, beta):
    """Compute soft_max(conv, beta) = (1/beta) * log(sum(exp(beta*conv)))."""
    scaled = beta * conv
    scaled -= scaled.max()
    return (scaled.max() + np.log(np.exp(scaled).sum())) / beta


def smooth_descent(f0, time_limit, init_beta=10.0, end_beta=200.0, 
                   lr0=0.01, mom0=0.9, top_k=None):
    """
    Smooth subgradient descent using soft-max approximation.
    """
    n = len(f0)
    f = np.maximum(f0.astype(np.float64), 0.0)
    s = f.sum()
    if s < 1e-15:
        f = np.ones(n) / n
    else:
        f = f / s
    
    conv = fast_convolve(f)
    best_obj = conv.max()
    best_f = f.copy()
    
    v = np.zeros(n)
    t0 = time.monotonic()
    no_improve = 0
    it = 0
    beta = init_beta
    lr = lr0
    mom = mom0
    
    while time.monotonic() - t0 < time_limit - 1:
        it += 1
        if time.monotonic() - t0 > time_limit - 1:
            break
        
        # Compute gradient
        grad = soft_max_gradient(f, conv, beta)
        
        # Normalize gradient (optional)
        gnorm = np.linalg.norm(grad)
        if gnorm > 1e-15:
            grad = grad / gnorm
        
        # Momentum update
        v = mom * v - lr * grad
        f_new = project_simplex(f + v)
        
        # Evaluate
        conv_new = fast_convolve(f_new)
        obj_new = conv_new.max()
        
        if obj_new < best_obj - 1e-13:
            best_obj = obj_new
            best_f = f_new.copy()
            f = f_new
            conv = conv_new
            no_improve = 0
        else:
            no_improve += 1
            # Don't accept this step, try smaller lr
            v *= 0.5
        
        # Adaptive parameters
        beta *= 1.005  # slowly increase (make approximation sharper)
        lr *= 0.9995
        mom = min(0.99, mom0 + 0.001 * it)
        
        # Periodic perturbation
        if no_improve > 200:
            rng = np.random.default_rng(it * 31 + 7)
            f = project_simplex(best_f + rng.standard_normal(n) * 0.003 * (1 + it/1000))
            conv = fast_convolve(f)
            v = np.zeros(n)
            lr = lr0 * 0.5
            no_improve = 0
    
    return best_f, best_obj


def coord_descent(f0, time_limit, max_passes=10000):
    """
    Coordinate descent: for each coordinate m, find optimal value
    given all others fixed. Uses 1D minimization.
    """
    n = len(f0)
    f = np.maximum(f0.astype(np.float64), 0.0)
    s = f.sum()
    if s < 1e-15:
        f = np.ones(n) / n
    else:
        f = f / s
    
    conv = fast_convolve(f)
    best_obj = conv.max()
    best_f = f.copy()
    
    t0 = time.monotonic()
    pass_num = 0
    order = np.arange(n)
    
    while time.monotonic() - t0 < time_limit - 2 and pass_num < max_passes:
        pass_num += 1
        rng = np.random.default_rng(pass_num * 1000003 + 42)
        rng.shuffle(order)
        
        any_improved = False
        
        for m in order:
            if time.monotonic() - t0 > time_limit - 2:
                break
            
            am = f[m]
            S = f.sum()  # should be 1 if normalized
            
            # The 1D problem: minimize over delta >= -am:
            # max_k (conv_k + 2*delta*a_{k-m} + delta^2 * 1_{k=2m}) / (S+delta)^2
            
            # Precompute q_k = 2*a_{k-m}
            # q_k is nonzero for k in [m, m+n-1] (intersection with [0, 2n-2])
            
            # Try candidate deltas
            # The optimal delta is where the "envelope" of the individual curves is minimized
            # For each k with q_k > 0, the individual minimum is at:
            # delta_k = S - 2*conv_k / q_k (if q_k > 0)
            
            # Collect candidates
            k_lo = max(0, m)  # k - m >= 0
            k_hi = min(2*n-2, m+n-1)  # k - m <= n-1
            
            candidates = [0.0, -am]  # current and zero
            
            # Add some heuristic candidates based on the top peaks
            for k in [k_lo, k_hi, m, 2*m if 2*m <= 2*n-2 else 2*n-2]:
                if k_lo <= k <= k_hi:
                    qk = 2.0 * f[k - m]
                    if qk > 1e-15:
                        dk = S - 2.0 * conv[k] / qk
                        if -am < dk < am * 3 + 1:
                            candidates.append(dk)
            
            # Also try small perturbations
            candidates.extend([-am*0.1, -am*0.3, am*0.1, am*0.3, am*0.5])
            
            # Filter valid candidates
            valid_candidates = [c for c in candidates if c > -am - 1e-12]
            
            if not valid_candidates:
                continue
            
            # Evaluate each candidate
            best_delta = 0.0
            best_val = conv.max()
            
            for delta in valid_candidates:
                if abs(delta) < 1e-15:
                    continue
                new_am = am + delta
                if new_am < 0:
                    continue
                
                # Quick evaluation without full FFT
                # c'_k = c_k + 2*delta*f[k-m] + delta^2 * 1_{k=2m}
                new_max = 0.0
                # We only need the max, so let's compute efficiently
                # For k in [k_lo, k_hi]: c'_k = c_k + 2*delta*f[k-m]
                # For k outside: c'_k = c_k
                # Special: k = 2m has an extra delta^2 term
                
                # The max can only increase at positions in [k_lo, k_hi] (or decrease)
                # and the global max might be at a position outside [k_lo, k_hi]
                
                max_outside = 0.0
                if k_lo > 0:
                    max_outside = max(max_outside, conv[:k_lo].max())
                if k_hi < 2*n-2:
                    max_outside = max(max_outside, conv[k_hi+1:].max())
                
                # Inside [k_lo, k_hi]:
                idx = np.arange(k_lo, k_hi+1)
                new_vals = conv[k_lo:k_hi+1] + 2.0 * delta * f[idx - m]
                if 2*m >= k_lo and 2*m <= k_hi:
                    pos_in_slice = 2*m - k_lo
                    new_vals[pos_in_slice] += delta * delta
                max_inside = new_vals.max()
                
                new_max = max(max_outside, max_inside)
                new_obj = new_max / (S + delta)**2
                
                if new_obj < best_val / S**2 - 1e-14:
                    best_val = new_max
                    best_delta = delta
            
            if best_delta != 0.0:
                f[m] = max(0.0, am + best_delta)
                f = f / f.sum()  # renormalize
                conv = fast_convolve(f)
                obj = conv.max()
                if obj < best_obj - 1e-14:
                    best_obj = obj
                    best_f = f.copy()

            conv = fast_convolve(f)
            best_obj_check = conv.max()
            if best_obj_check < best_obj:
                best_obj = best_obj_check
                best_f = f.copy()
    
    return best_f, best_obj

def fast_convolve(a):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]


def project_simplex(v):
    n = len(v)
    if n == 1:
        return np.array([max(v[0], 0.0)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)


def compute_soft_max_grad(f, conv, beta):
    """Gradient of soft-max(conv, beta) w.r.t. f."""
    n = len(f)
    scaled = beta * conv
    scaled -= scaled.max()
    w = np.exp(scaled)
    w /= w.sum()
    
    # grad_m = 2 * sum_j f[j] * w[m+j] for m = 0,...,n-1
    # Use FFT correlation
    G = f[::-1]
    fft_size = 1 << (3 * n).bit_length()
    FG = np.fft.rfft(G, fft_size)
    FW = np.fft.rfft(w, fft_size)
    corr = np.fft.irfft(FG * FW, fft_size)
    grad = 2.0 * corr[n-1:n-1+n]
    return grad

"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
- Smooth soft-max subgradient descent with adaptive temperature and momentum
- Coordinate descent polishing (exploits 1D per-coordinate structure exactly)
- Multi-scale exploration across n = 384 to 2048
- Diverse structured initializations (parent interpolation, bumps, ramps)
- Careful time management with 4 phases

import numpy as np
import time


def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]


def project_simplex(v):
    """Euclidean projection onto the probability simplex {x>=0, sum(x)=1}."""
    n = len(v)
    if n == 1:
        return np.array([max(v[0], 0.0)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)


def compute_soft_max_grad(f, conv, beta):
    """
    Gradient of soft_max(conv, beta) = (1/beta)*log(sum(exp(beta*conv_k))) w.r.t. f.
    Uses FFT-based correlation for efficiency.
    grad_m = 2 * sum_j f[j] * w[m+j] where w_k = softmax(beta * conv)_k
    """
    n = len(f)
    scaled = beta * conv
    scaled -= scaled.max()
    w = np.exp(scaled)
    w /= w.sum()

    # grad_m = 2 * sum_{j=0}^{n-1} f[j] * w[m+j] for m=0,...,n-1
    # This is a cross-correlation: corr[m] = sum_j f[j]*w[m+j]
    # Use FFT: corr = ifft(fft(f[::-1]) * fft(w))[n-1 : n-1+n]
    G = f[::-1]
    fft_size = 1 << (3 * n).bit_length()
    FG = np.fft.rfft(G, fft_size)
    FW = np.fft.rfft(w, fft_size)
    corr = np.fft.irfft(FG * FW, fft_size)
    grad = 2.0 * corr[n - 1:n - 1 + n]
    return grad


def smooth_descent(f0, time_limit, init_beta=5.0, lr0=0.02, mom0=0.85):
    """
    Smooth subgradient descent using soft-max approximation of max(conv).
    Adaptive temperature (beta increases over time for sharper approximation).
    """
    n = len(f0)
    f = np.maximum(f0.astype(np.float64), 0.0)
    s = f.sum()
    if s < 1e-15:
        f = np.ones(n) / n
    else:
        f = f / s

    conv = fast_convolve(f)
    best_obj = conv.max()
    best_f = f.copy()

    v = np.zeros(n)
    t0 = time.monotonic()
    no_improve = 0
    it = 0
    beta = init_beta
    lr = lr0
    mom = mom0

    while time.monotonic() - t0 < time_limit - 1:
        it += 1
        if time.monotonic() - t0 > time_limit - 1:
            break

        grad = compute_soft_max_grad(f, conv, beta)
        gnorm = np.linalg.norm(grad)
        if gnorm > 1e-15:
            grad = grad / gnorm

        v = mom * v - lr * grad
        f_new = project_simplex(f + v)
        conv_new = fast_convolve(f_new)
        obj_new = conv_new.max()

        if obj_new < best_obj - 1e-13:
            best_obj = obj_new
            best_f = f_new.copy()
            f = f_new
            conv = conv_new
            no_improve = 0
        else:
            no_improve += 1
            v *= 0.5

        beta *= 1.003
        lr *= 0.9995
        mom = min(0.99, mom0 + 0.0005 * it)

        if no_improve > 400:
            rng = np.random.default_rng(it * 31 + 7)
            f = project_simplex(best_f + rng.standard_normal(n) * 0.005)
            conv = fast_convolve(f)
            v = np.zeros(n)
            lr = lr0 * 0.5
            beta = init_beta
            no_improve = 0

    return best_f, best_obj


def coord_descent(f0, time_limit):
    """
    Coordinate descent with exact 1D optimization per coordinate.
    For coordinate m, changing a_m by delta (then renormalizing) gives:
      new_conv_k = (conv_k + 2*delta*a_{k-m} + delta^2 * 1_{k=2m}) / (1+delta)^2
    We find the delta that minimizes max_k new_conv_k.
    """
    n = len(f0)
    f = np.maximum(f0.astype(np.float64), 0.0)
    s = f.sum()
    if s < 1e-15:
        f = np.ones(n) / n
    else:
        f = f / s

    conv = fast_convolve(f)
    best_obj = conv.max()
    best_f = f.copy()

    t0 = time.monotonic()
    pass_num = 0
    consecutive_no_improve = 0

    while time.monotonic() - t0 < time_limit - 2:
        pass_num += 1
        rng = np.random.default_rng(pass_num * 1000003 + 42)
        order = rng.permutation(n)

        any_improved = False

        for m in order:
            if time.monotonic() - t0 > time_limit - 2:
                break

            am = f[m]
            cur_max = conv.max()

            k_lo = max(0, m)
            k_hi = min(2 * n - 2, m + n - 1)

            # Collect candidate deltas
            candidates = [0.0]

            # Candidates from top peaks (where the constraint is most binding)
            if cur_max > 0:
                top_k_count = min(10, 2 * n - 1)
                top_idx = np.argpartition(conv, -top_k_count)[-top_k_count:]
                for k in top_idx:
                    if k_lo <= k <= k_hi:
                        qk = 2.0 * f[k - m]
                        if qk > 1e-12:
                            # Individual minimum of (conv_k + delta*qk)/(1+delta)^2
                            # d/delta: qk(1+delta) - 2(conv_k + delta*qk) = 0
                            # => qk - 2*conv_k - delta*qk = 0
                            # => delta = (qk - 2*conv_k) / qk = 1 - 2*conv_k/qk
                            dk = 1.0 - conv[k] / f[k - m]
                            if -am - 1e-6 < dk < am * 10 + 2.0:
                                candidates.append(dk)

            # Heuristic candidates
            if am > 1e-12:
                candidates.extend([-am * 0.05, -am * 0.2, -am * 0.5,
                                   am * 0.05, am * 0.2, am * 0.5, am])

            best_delta = 0.0
            best_new_obj = cur_max

            for delta in candidates:
                if abs(delta) < 1e-14:
                    continue
                if delta <= -1.0 + 1e-12:
                    continue
                new_am = am + delta
                if new_am < -1e-12:
                    continue

                # Compute new max without full FFT
                max_out = 0.0
                if k_lo > 0:
                    max_out = max(max_out, conv[:k_lo].max())
                if k_hi < 2 * n - 2:
                    max_out = max(max_out, conv[k_hi + 1:].max())

                idx = np.arange(k_lo, k_hi + 1)
                new_vals = conv[k_lo:k_hi + 1] + 2.0 * delta * f[idx - m]
                if 2 * m >= k_lo and 2 * m <= k_hi:
                    pos = 2 * m - k_lo
                    new_vals[pos] += delta * delta

                max_in = new_vals.max()
                new_max = max(max_out, max_in)
                new_obj = new_max / (1.0 + delta) ** 2

                if new_obj < best_new_obj - 1e-14:
                    best_new_obj = new_obj
                    best_delta = delta

            if best_delta != 0.0:
                f[m] = max(0.0, am + best_delta)
                f = f / f.sum()
                conv = fast_convolve(f)
                obj = conv.max()
                if obj < best_obj - 1e-14:
                    best_obj = obj
                    best_f = f.copy()
                any_improved = True

        if any_improved:
            consecutive_no_improve = 0
        else:
            consecutive_no_improve += 1
            if consecutive_no_improve > 50:
                break

    return best_f, best_obj


def generate_inits(n, parent=None, rng=None):

    sigma2 = n / 2.5
    g2 = np.exp(-0.5 * ((x - n / 2) / sigma2) ** 2)
    inits.append(g2 / g2.sum())

    # Parent interpolation
    if parent is not None:
        p = np.interp(x, np.linspace(0, 1, len(parent)), parent)
        p = np.maximum(p, 0)
        ps = p.sum()
        if ps > 1e-10:

    noisy = np.ones(n) + rng.standard_normal(n) * 0.03

    inits.append(noisy / noisy.sum())

    return inits
