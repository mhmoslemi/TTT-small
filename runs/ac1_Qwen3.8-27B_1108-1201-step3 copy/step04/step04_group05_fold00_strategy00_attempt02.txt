The solution involves optimizing a sequence of non-negative coefficients to minimize the objective function \( \frac{2n \max(\text{convolve}(a,a))}{(\text{sum}(a))^2} \). The approach uses a combination of genetic algorithms and local optimization steps:

1. **Initialization**: Start with a population of 100 vectors of fixed length 512, normalized to sum 1. If a parent sequence is available, add an interpolated version to the population.
2. **Fitness Evaluation**: Compute the objective for each vector using exact boundaries and normalization.
3. **Selection (Mutation)**: Generate new vectors by:
   - **Mutation**: Adding small Gaussian noise and projecting to simplex (10 updates).
   - **Crossover**: Averaging two parent vectors and evaluating the result (50 updates).
4. **Updating**: Replace the population with the best performing vectors and any newly found improvements.
5. **Early Exit**: If a low objective is achieved (\( <1.5027 \)), stop early.
6. **Fallback**: Return the best uniform vector if no significant improvement is found or time runs out.
7. **Local Search**: If time permits, polish the best candidate with a Frank-Wolf update and re-evaluation.
