Wait, that's not right. By Cauchy-Schwarz: `(sum a_i * b_i)^2 <= (sum a_i^2)(sum b_i^2)`. Let `b_i = a_{n-1-i}`. Then:
`(sum a_i * a_{n-1-i})^2 <= (sum a_i^2)(sum a_{n-1-i}^2) = (sum a_i^2)^2`

So `sum a_i * a_{n-1-i} <= sum a_i^2`. That's an upper bound, not lower.

For a lower bound: by the rearrangement inequality, the minimum of `sum a_i * b_i` over all permutations of `b` is achieved when `a` and `b` are oppositely sorted. But here `b_i = a_{n-1-i}` is a fixed permutation (reversal), not arbitrary.

So the center peak `c_{n-1} = sum a_i * a_{n-1-i}` depends on the "symmetry" of the sequence. If the sequence is symmetric (`a_i = a_{n-1-i}`), then `c_{n-1} = sum a_i^2`, which can be made small by spreading mass evenly (= 1/n). If the sequence is "anti-symmetric" in some sense (large values at positions that map to small values under reversal), we can potentially make `c_{n-1}` smaller.

For example, if `a_0` is large and `a_{n-1}` is small, the term `a_0 * a_{n-1}` in `c_{n-1}` is small. But `a_0^2` appears in `c_0`, which might then be the peak.

So there's a tension: making the sequence "anti-symmetric" reduces the center peak but increases the edge peaks. The optimum balances these.

This suggests that the optimal sequence should have a "U-shape" or "V-shape" (large at edges, small in middle) or some other structure that balances the peaks.

Let me check: for a "U-shaped" sequence where `a_i` is large at the edges and small in the middle:
- `c_0 = a_0^2` (large)
- `c_{n-1} = sum a_i * a_{n-1-i}` (small, since large values are at edges that map to small values)
- `c_{2n-2} = a_{n-1}^2` (large)

So the peak would be at the edges. Not good.

For a "bell-shaped" sequence (large in middle, small at edges):
- `c_0 = a_0^2` (small)
- `c_{n-1} = sum a_i * a_{n-1-i}` (large, since the middle values correlate)
- Peak at center.

For a "uniform" sequence: all peaks equal at 1/n.

So the optimum is somewhere between uniform and some structured sequence. The parent sequence (score 1.5049) is presumably some structured sequence found by the previous optimization.

Let me think about what structure would be optimal. We want to minimize the maximum of all `c_k`. The "average" of all `c_k` is:

```python
import numpy as np
import time
from scipy.fft import rfft, irfft

def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(a, fft_size)
    return irfft(A * A, fft_size)[:size]

def compute_conv(a):
    """Compute auto-convolution."""
    return fast_convolve(a)

def compute_score_normalized(a):
    """Compute score for sequence with sum=1."""
    n = len(a)
    conv = fast_convolve(a)
    return 2.0 * n * conv.max()

def softmax(z):
    z = z - z.max()
    e = np.exp(z)
    return e / e.sum()

def lse_smoothed_obj_and_grad(a, T):
    """
    Compute the log-sum-exp smoothed objective and its gradient.
    Objective: (2n/T) * log(sum_k exp(T*c_k))
    Gradient: (2n/T) * (w ⊛ a) where w_k = exp(T*c_k)/sum exp(T*c_k)
    Cross-correlation: grad_i = 2 * sum_k w_k * a_{k-i} (with bounds)
    """
    n = len(a)
    conv = fast_convolve(a)
    shifted = T * conv
    shifted -= shifted.max()
    exp_shifted = np.exp(shifted)
    w = exp_shifted / exp_shifted.sum()
    
    # Gradient: grad_i = 2 * sum_k w_k * a_{k-i}
    # This is the cross-correlation of w with a
    # (w ⊛ a)_i = sum_k w_k * a_{k-i}
    # Using FFT: ifft(conj(FFT(w)) * FFT(a))
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    W = rfft(w, fft_size)
    A = rfft(a, fft_size)
    grad = 2.0 * irfft(np.conj(W) * A, fft_size)[:n]
    
    # Objective value (smoothed)
    log_sum_exp = shifted.max() + np.log(exp_shifted.sum())
    obj = (2.0 * n / T) * np.exp(log_sum_exp)
    
    return obj, grad
```

**Idea: Try to approach the problem from the "dual" side.**

The minimax problem is:
`min_a max_k c_k(a)` where `a >= 0, sum(a) = 1`

By minimax theorem (if the problem were convex in a and concave in k... but it's not exactly that form).

However, we can use a **variational approach**: introduce a distribution `p` over lags, and consider:
`max_p min_a sum_k p_k * c_k(a)`

The inner minimization is: `min_a sum_k p_k * (a*a)_k = min_a a^T (sum_k p_k Q_k) a`

subject to `a >= 0, sum(a) = 1`.

Let `M(p) = sum_k p_k Q_k`. The inner problem is `min a^T M(p) a s.t. a >= 0, 1^T a = 1`.

If `M(p)` is positive definite, this is a convex QP and has a unique solution. The optimal `a*` satisfies the KKT conditions:
`2*M(p)*a* + λ*1 + μ = 0` where `μ_i >= 0` for `a_i = 0` and `μ_i = 0` for `a_i > 0`.

On the support of `a*`: `2*M(p)*a* + λ = 0`, i.e., `(M(p)*a*)_i = const` for all `i` in the support.

This means that at the optimum, the "pressure" `M(p)*a*` is constant on the support. This is a useful condition!

**Algorithm: Alternating minimization**
1. Start with a distribution `p` over lags (e.g., uniform or peaked at the current maximum)
2. Solve the QP: `min a^T M(p) a s.t. a >= 0, sum(a) = 1` to get `a*`
3. Update `p`: set `p_k ∝ exp(β * c_k(a*))` (where `β` is a temperature parameter)
4. Repeat

This is essentially **fictitious play** or **mirror descent** on the dual.

The QP in step 2 can be solved with a projected gradient method or with a dedicated QP solver. Since `M(p)` is sparse (each `Q_k` has at most n nonzeros), we can compute `M(p) * a` efficiently.

`(M(p) * a)_i = sum_k p_k * (Q_k * a)_i = sum_k p_k * sum_j Q_{k,ij} * a_j = sum_k p_k * a_{k-i}` (with bounds)

Wait, `(Q_k * a)_i = sum_j Q_{k,ij} * a_j`. And `Q_{k,ij} = 1` if `i+j=k`, else 0. So `(Q_k * a)_i = a_{k-i}` (if `0 <= k-i < n`, else 0).

So `(M(p) * a)_i = sum_k p_k * a_{k-i}` (with bounds) = `(p ⊛ a)_i` (cross-correlation!).

This is the same cross-correlation we had before! So the QP gradient is:
`∇_a [a^T M(p) a] = 2*M(p)*a = 2*(p ⊛ a)`

And this can be computed via FFT.

So the inner QP is:
`min a^T M(p) a = min sum_i a_i * (p ⊛ a)_i`
`s.t. a >= 0, sum(a) = 1`

We can solve this with projected gradient:
- Gradient: `2*(p ⊛ a)`
- Project onto `{a >= 0, sum(a) = 1}`: water-filling / Euclidean projection onto the probability simplex

The projection onto the probability simplex is a well-known problem that can be solved in O(n log n) time.

This gives us a clean **alternating optimization** algorithm:
1. Given `p`: solve `min a^T M(p) a s.t. a >= 0, sum(a) = 1` using projected gradient
2. Given `a`: update `p_k ∝ exp(β * c_k(a))` (or `p_k = 1` for argmax, `0` otherwise for the "pure" minimax)
3. Repeat

This is very similar to the fictitious play approach described in the previous state-of-the-art, but with a cleaner implementation.

Let me implement this!

**Projected gradient for the QP:**
- Initialize `a = ones(n)/n`
- Iteratively:
  - Compute `g = 2*(p ⊛ a)` (via FFT cross-correlation)
  - Take a step: `a_new = a - step_size * g`
  - Project onto simplex: `a = proj_simplex(a_new)`
  - Adaptive step size (Barzilai-Borwein or backtracking)

**Simplex projection:**
The projection of `x` onto the probability simplex `{a >= 0, sum(a) = 1}` is:
`a_i = max(x_i - θ, 0)` where `θ` is chosen so that `sum_i max(x_i - θ, 0) = 1`.

`θ` can be found by sorting `x` in decreasing order and trying different "breakpoints."

This is the Duchi et al. (2008) algorithm, which runs in O(n log n).

```python
import numpy as np
import time
from scipy.fft import rfft, irfft

def fast_convolve(a):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(a, fft_size)
    return irfft(A * A, fft_size)[:size]

def cross_correlation(p, a):
    """Compute (p ⊛ a)_i = sum_k p_k * a_{k-i} (with a_m=0 for m out of [0,n))."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    P = rfft(p, fft_size)
    A = rfft(a, fft_size)
    return irfft(np.conj(P) * A, fft_size)[:n]

def softmax(z):
    z_shifted = z - z.max()
    e = np.exp(z_shifted)
    s = e.sum()
    if s < 1e-300:
        return np.ones(len(z)) / len(z)
    return e / s

def proj_simplex(v):
    """Project vector v onto the probability simplex {x >= 0, sum(x) = 1}."""
    n = len(v)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.nonzero(u * np.arange(1, n + 1) > (cssv - 1))[0][-1]
    theta = (cssv[rho] - 1) / (rho + 1.0)
    return np.maximum(v - theta, 0)

def compute_score(a):
    """Score for normalized sequence (sum=1)."""
    n = len(a)
    conv = fast_convolve(a)
    return 2.0 * n * conv.max()

def lse_objective_and_grad(a, T):
    """Log-sum-exp smoothed objective and gradient (w.r.t. a)."""
    n = len(a)
    conv = fast_convolve(a)
    shifted = T * conv - (T * conv).max()
    exp_s = np.exp(shifted)
    w = exp_s / exp_s.sum()
    # Gradient w.r.t. a: 4n * (w ⊛ a)
    grad_a = 4.0 * n * cross_correlation(w, a)
    # Objective
    obj = (2.0 * n / T) * np.exp((T * conv).max() + np.log(exp_s.sum()))
    return obj, grad_a

def softmax_grad(grad_a, a):
    """Convert gradient w.r.t. a to gradient w.r.t. z (softmax parameterization)."""
    return a * (grad_a - np.dot(a, grad_a))

def adam_optimize(a0, time_limit, T, lr=0.01, beta1=0.9, beta2=0.999, eps=1e-8):
    """Adam optimization in softmax parameterization."""
    n = len(a0)
    z = np.log(np.maximum(a0, 1e-30))
    m = np.zeros(n)
    v = np.zeros(n)
    t = 0
    best_a = a0.copy()
    best_score = compute_score(a0)
    t0 = time.monotonic()
    
    while time.monotonic() - t0 < time_limit:
        t += 1
        a = softmax(z)
        obj, grad_a = lse_objective_and_grad(a, T)
        grad_z = softmax_grad(grad_a, a)
        
        m = beta1 * m + (1 - beta1) * grad_z
        v = beta2 * v + (1 - beta2) * grad_z**2
        m_hat = m / (1 - beta1**t)
        v_hat = v / (1 - beta2**t)
        
        z = z - lr * m_hat / (np.sqrt(v_hat) + eps)
        z = np.clip(z, -30, 30)
        
        a = softmax(z)
        score = compute_score(a)
        if score < best_score:
            best_score = score
            best_a = a.copy()
    
    return best_a, best_score

def qp_projected_gradient(p, a0, n_iter=1000, time_limit=10.0):
    """
    Solve min a^T M(p) a s.t. a >= 0, sum(a) = 1
    using projected gradient with Barzilai-Borwein step size.
    """
    n = len(a0)
    a = a0.copy()
    a = proj_simplex(a)
    t0 = time.monotonic()
    
    a_prev = a.copy()
    g_prev = 2.0 * cross_correlation(p, a)
    step = 0.01
    best_a = a.copy()
    best_val = np.dot(a, cross_correlation(p, a))
    
    for it in range(n_iter):
        if time.monotonic() - t0 > time_limit:
            break
        
        a_new = a - step * g_prev
        a_new = proj_simplex(a_new)
        
        g_new = 2.0 * cross_correlation(p, a_new)
        
        # Barzilai-Borwein step size
        s = a_new - a
        y = g_new - g_prev
        ss = np.dot(s, s)
        sy = np.dot(s, y)
        if ss > 1e-20 and abs(sy) > 1e-20:
            step = ss / abs(sy)
            step = np.clip(step, 1e-6, 0.1)
```

"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using a multi-phase approach:
1. Alternating optimization (fictitious play): alternates between solving
   a QP (min a^T M(p) a s.t. a>=0, sum=1) via projected gradient and
   updating the distribution p over lags using softmax of convolutions.
2. Adam optimizer with log-sum-exp smoothing in softmax parameterization.
3. Pairwise coordinate descent with golden section search for exact 1D minimization.
4. Peak shaving heuristic for final polish.
5. Multi-length exploration (512, 768, 1024, 1536, 2048).

import numpy as np
import time
from scipy.fft import rfft, irfft


def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(a, fft_size)
    return irfft(A * A, fft_size)[:size]


def cross_correlation(p, a):
    """Compute (p * a)_i = sum_k p_k * a_{k-i} with a_m=0 for m out of [0,n)."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    P = rfft(p, fft_size)
    A = rfft(a, fft_size)
    return irfft(np.conj(P) * A, fft_size)[:n]


def softmax_fn(z):
    """Stable softmax."""
    z_shifted = z - z.max()
    e = np.exp(z_shifted)
    s = e.sum()
    if s < 1e-300:
        return np.ones(len(z)) / len(z)
    return e / s


def proj_simplex(v):
    """Project vector v onto the probability simplex {x >= 0, sum(x) = 1}."""
    n = len(v)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho_candidates = np.nonzero(u * np.arange(1, n + 1) > (cssv - 1))[0]
    if len(rho_candidates) == 0:
        return np.ones(n) / n
    rho = rho_candidates[-1]
    theta = (cssv[rho] - 1) / (rho + 1.0)
    return np.maximum(v - theta, 0)


def compute_score(a):
    """Score for normalized sequence (sum=1)."""
    n = len(a)
    conv = fast_convolve(a)
    return 2.0 * n * conv.max()


def lse_objective_and_grad_a(a, T):
    """Log-sum-exp smoothed objective and gradient w.r.t. a."""
    n = len(a)
    conv = fast_convolve(a)
    Tc = T * conv
    Tc_max = Tc.max()
    shifted = Tc - Tc_max
    exp_s = np.exp(shifted)
    w = exp_s / exp_s.sum()
    # Gradient w.r.t. a: 4n * (w cross-correlate a)
    grad_a = 4.0 * n * cross_correlation(w, a)
    # Objective value
    log_sum_exp = Tc_max + np.log(exp_s.sum())
    obj = (2.0 * n / T) * np.exp(log_sum_exp)
    return obj, grad_a


def softmax_gradient(grad_a, a):
    """Convert gradient w.r.t. a to gradient w.r.t. z in softmax parameterization."""
    return a * (grad_a - np.dot(a, grad_a))


def adam_optimize(a0, time_limit, T, lr_init=0.05, beta1=0.9, beta2=0.999, eps=1e-8, decay=0.9999):
    """Adam optimization in softmax parameterization with log-sum-exp smoothing."""
    n = len(a0)
    z = np.log(np.maximum(a0, 1e-30))
    m = np.zeros(n)
    v = np.zeros(n)
    t = 0
    best_a = a0.copy()
    best_score = compute_score(a0)
    t0 = time.monotonic()
    lr = lr_init
    
    while time.monotonic() - t0 < time_limit:
        t += 1
        a = softmax_fn(z)
        obj, grad_a = lse_objective_and_grad_a(a, T)
        grad_z = softmax_gradient(grad_a, a)
        
        m = beta1 * m + (1.0 - beta1) * grad_z
        v = beta2 * v + (1.0 - beta2) * (grad_z * grad_z)
        m_hat = m / (1.0 - beta1 ** t)
        v_hat = v / (1.0 - beta2 ** t)
        
        z = z - lr * m_hat / (np.sqrt(v_hat) + eps)
        z = np.clip(z, -30.0, 30.0)
        
        a = softmax_fn(z)
        score = compute_score(a)
        if score < best_score:
            best_score = score
            best_a = a.copy()
        
        lr *= decay
    
    return best_a, best_score

    """
    Solve min a^T M(p) a s.t. a >= 0, sum(a) = 1

    """
