GS for our problem:
- We want b = conv(a,a) to be as flat as possible
- b has length 2n-1
- In frequency domain: B(f) = |A(f)|^2 where A = FFT(a padded to L >= 2n-1)
- We want B to be constant, i.e., |A| to be constant

1. Start with a (length n), zero-pad to length L
2. A = FFT(a_padded)
3. Compute target magnitude: m = sqrt(sum(|A|^2) / L)
4. A_new = A * (m / |A|) (set magnitude to m, keep phase)
   Handle |A| = 0: set A_new = 0 where |A| = 0
5. a_padded_new = IFFT(A_new)
6. a_new = real(a_padded_new[:n]) (take first n elements)
7. Clip: a_new = max(a_new, 0)
8. Normalize: a_new = a_new / sum(a_new)

Wait, there's an issue. When we go from frequency to time domain, the result might be complex (if the original a is real, |A|^2 is real and even, so B is real and even, and IFFT(B) is real... but we're modifying the phase of A, not B).

Let me reconsider. We have:
- a is real, length n
- a_padded is a zero-padded to length L
- A = FFT(a_padded) (complex, length L)
- B = |A|^2 (real, non-negative, length L) -- this is the periodogram
- b = IFFT(B) (real, length L, first 2n-1 elements are the linear convolution)

We want b to be flat. In frequency domain, this means B should be flat (constant). But B = |A|^2, so we want |A| to be constant.

The GS step:
1. A = FFT(a_padded)
2. Set |A| to be constant: A_new = A / |A| * target_mag (where target_mag = sqrt(sum(|A|^2)/L))
3. a_new_padded = IFFT(A_new)
4. a_new = real(a_new_padded[:n])
5. Clip and normalize

But step 3 might give a complex result! Because A_new has the same phase as A but constant magnitude. Since A = FFT(real signal), A has the property A[L-k] = conj(A[k]) (Hermitian symmetry). Does A_new preserve this?

A_new[k] = A[k] / |A[k]| * target_mag
A_new[L-k] = A[L-k] / |A[L-k]| * target_mag = conj(A[k]) / |A[k]| * target_mag = conj(A[k] / |A[k]|) * target_mag = conj(A_new[k])

Yes! Hermitian symmetry is preserved. So IFFT(A_new) is real.

Given current a, compute b = conv(a,a). Find the top M peak locations k_1, ..., k_M.

The gradient of b[k_i] w.r.t. a is:

Wait, I derived earlier that:
- If 2p = k_i: db/da_p = a_p
- If 2p ≠ k_i and 0 <= k_i - p < n: db/da_p = 2 * a[k_i - p]
- Else: 0

The linearized constraint at the current point a:
b[k_i](a_new) ≈ b[k_i](a) + g_i^T (a_new - a)

We want b[k_i](a_new) <= t for all i.
So: b[k_i](a) + g_i^T (a_new - a) <= t
=> g_i^T a_new <= t + g_i^T a - b[k_i](a)

Now, g_i^T a = sum_p g_i[p] * a[p]. Let's compute this:
g_i^T a = sum_{p: 0<=k_i-p<n, 2p≠k_i} 2*a[k_i-p]*a[p] + sum_{p: 2p=k_i} a[p]*a[p]
= 2 * sum_{p: 0<=k_i-p<n, p≠k_i/2} a[p]*a[k_i-p] + (a[k_i/2])^2 if k_i even
= 2 * b[k_i] - (a[k_i/2])^2 if k_i even
= 2 * b[k_i] if k_i odd (no self-term)

Actually, for a quadratic f(a) = a^T M a, we have ∇f(a) = 2Ma, and ∇f(a)^T a = 2 a^T M a = 2f(a). So g_i^T a = 2*b[k_i](a).

Wait, is b[k_i] = a^T M_i a? Yes! Because b[k_i] = sum_{p,q: p+q=k_i} a[p]a[q] = a^T M_i a where M_i[p,q] = 1 if p+q=k_i.

So ∇b[k_i](a) = 2 M_i a, and (∇b[k_i](a))^T a = 2 a^T M_i a = 2 b[k_i](a).

Therefore: g_i^T a_new <= t + 2*b[k_i] - b[k_i] = t + b[k_i]

So the linearized constraint is simply:
g_i^T a_new <= t + b[k_i](a_current)

Where g_i = 2 * M_i * a_current.

minimize t
subject to: (2*M_i*a_cur)^T a_new <= t + b[k_i](a_cur), for i = 1,...,M

            a_new >= 0

"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
1. GS/IFT (Gerchberg-Saxton) for diverse initialization
2. Soft-max gradient descent (Adam) with adaptive temperature
3. LP-based peak equalization (linearized active-set method)
4. Adaptive coordinate descent
5. Multi-length exploration with simulated annealing restarts
"""

import numpy as np
import time
from scipy.fft import rfft, irfft, fft, ifft
from scipy.optimize import minimize
import cvxpy as cp


def fast_convolve(a):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(a, fft_size)
    return irfft(A * A, fft_size)[:size]


def gs_iterate(a, n_iters=100, clip_threshold=0.0):
    """
    Gerchberg-Saxton iterations to flatten the autocorrelation.
    """
    n = len(a)
    L = 1 << (2 * n - 1 - 1).bit_length()  # next power of 2 >= 2n-1
    a = np.maximum(np.asarray(a, dtype=np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        return a
    a = a / s
    
    for it in range(n_iters):
        a_padded = np.zeros(L)
        a_padded[:n] = a
        A = fft(a_padded)
        mag = np.abs(A)
        target_mag = np.sqrt(np.sum(mag**2) / L)
        # Avoid division by zero
        safe_mag = np.maximum(mag, 1e-15)
        A_new = A * (target_mag / safe_mag)
        # Preserve Hermitian symmetry (should already be there)
        a_new_padded = np.real(ifft(A_new))
        a = a_new_padded[:n]
        a = np.maximum(a, clip_threshold)
        s = a.sum()
        if s < 1e-15:
            a = np.ones(n) / n
        else:
            a = a / s
    
    return a


def softmax_from_z(z):
    z_shifted = z - np.max(z)
    exp_z = np.exp(z_shifted)
    s = exp_z.sum()
    if s < 1e-300:
        return np.ones_like(z) / len(z)
    return exp_z / s


def adam_softmax(a0, time_limit, T_init=0.05, T_final=0.001, lr=0.01,
                 beta1=0.9, beta2=0.999, eps=1e-8, schedule='exp',
                 restart_interval=5000, restart_noise=0.01):
    """
    Adam optimizer in log-space with soft-max temperature annealing.
    """
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 1e-300)
    a = a / a.sum()
    z = np.log(a)
    m = np.zeros(n)
    v = np.zeros(n)
    t = 0
    fft_size = 1 << (2 * n - 2).bit_length()
    t0 = time.monotonic()
    best_a = a.copy()
    best_score = 2.0 * n * fast_convolve(a).max()
    no_improve = 0
    max_no_improve = restart_interval
    
    while time.monotonic() - t0 < time_limit:
        t += 1
        elapsed = time.monotonic() - t0
        progress = min(1.0, elapsed / time_limit)
        
        # Temperature schedule
        if schedule == 'exp':
            T = T_init * (T_final / T_init) ** progress
        elif schedule == 'linear':
            T = T_init + (T_final - T_init) * progress
        elif schedule == 'cyclical':
            # Cyclical: oscillate between T_init and T_final
            cyc = 0.5 + 0.5 * np.sin(2 * np.pi * progress * 3)
            base = T_init * (T_final / T_init) ** progress
            T = base + (T_init - base) * cyc * 0.3
        else:
            T = T_init * (T_final / T_init) ** progress
        
        a_curr = softmax_from_z(z)
        
        # Compute soft-max weights
        b = fast_convolve(a_curr)
        max_b = b.max()
        exp_b = np.exp(b / T - max_b / T)
        w = exp_b / exp_b.sum()
        
        # Gradient: d(soft_max)/da_i = 2n * sum_k w[k] * a[k-i] (with boundary handling)
        # Use FFT for efficiency
        W = rfft(w, fft_size)
        A = rfft(a_curr, fft_size)
        corr = irfft(W * np.conj(A), fft_size)[:n]
        grad_a = 2.0 * n * corr
        
        # Transform to z-space
        S = np.dot(grad_a, a_curr)
        grad_z = a_curr * (grad_a - S)
        
        # Adam update
        m = beta1 * m + (1.0 - beta1) * grad_z
        v = beta2 * v + (1.0 - beta2) * (grad_z * grad_z)
        m_hat = m / (1.0 - beta1 ** t)
        v_hat = v / (1.0 - beta2 ** t)
        z = z - lr * m_hat / (np.sqrt(v_hat) + eps)
        
        a_new = softmax_from_z(z)
        conv_new = fast_convolve(a_new)
        score = 2.0 * n * conv_new.max()
        
        if score < best_score - 1e-14:
            best_score = score
            best_a = a_new.copy()
            no_improve = 0
        else:
            no_improve += 1
        
        # Adaptive restart
        if no_improve > max_no_improve:
            z = np.log(np.maximum(best_a, 1e-300)) + np.random.standard_normal(n) * restart_noise
            m = np.zeros(n)
            v = np.zeros(n)
            no_improve = 0
            lr = max(0.001, lr * 0.7)
        
        # Slow LR decay
        lr = max(0.0005, lr * (1.0 - 0.00005))
    
    return best_a, best_score


def lp_peak_equalize(a, M=10, max_iters=50, step_size=1.0):
    """
    LP-based peak equalization using linearized active-set method.
    """
    n = len(a)
    a = np.maximum(np.asarray(a, dtype=np.float64), 0.0)
    a = a / a.sum()
    best_a = a.copy()
    best_score = 2.0 * n * fast_convolve(a).max()
    
    for it in range(max_iters):
        b = fast_convolve(a)
        max_b = b.max()
        current_score = 2.0 * n * max_b
        
        # Find top M peak locations (excluding boundary peaks 0 and 2n-2 which are a_0^2 and a_{n-1}^2)
        b_search = b.copy()
        b_search[0] = b.max() * 0.5  # Deprioritize boundaries
        b_search[-1] = b.max() * 0.5
        peak_indices = np.argsort(b_search)[::-1][:M]
        
        # If all peaks are at the same level (within tolerance), stop
        peak_vals = b[peak_indices]
        if peak_vals.max() - peak_vals.min() < 1e-10 * peak_vals.max():
            break
        
        # Compute gradients for each peak
        # g_i[p] = 2*a[k_i - p] if 0 <= k_i - p < n (and p != k_i/2)
        # g_i[p] = a[p] if 2p == k_i
        grading_matrix = np.zeros((M, n))
        b_vals = np.zeros(M)
        for i, k in enumerate(peak_indices):
            b_vals[i] = b[k]
            for p in range(n):
                q = k - p
                if 0 <= q < n:
                    if 2 * p == k:
                        grading_matrix[i, p] = a[p]
                    else:
                        grading_matrix[i, p] = 2.0 * a[q]
        
        # LP: min t s.t. grading_matrix[i,:] @ a_new <= t + b_vals[i], sum(a_new)=1, a_new>=0
        a_var = cp.Variable(n, nonneg=True)
        t_var = cp.Variable()
        objective = cp.Minimize(t_var)
        constraints = [cp.sum(a_var) == 1]
        for i in range(M):
            constraints.append(grading_matrix[i] @ a_var - t_var <= b_vals[i])
        
        prob = cp.Problem(objective, constraints)
        try:
            prob.solve(solver=cp.ECOS, max_iters=5000, verbose=False)
        except Exception:
            try:
                prob.solve(solver=cp.CVXOPT, verbose=False)
            except Exception:
                break
        
        if a_var.value is None or t_var.value is None:
            break
        
        a_lp = np.maximum(a_var.value, 0)
        s = a_lp.sum()
        if s < 1e-15:
            break
        a_lp = a_lp / s
        
        # Check improvement
        b_lp = fast_convolve(a_lp)
        score_lp = 2.0 * n * b_lp.max()
        
        if score_lp < current_score - 1e-12:
            # Take a step (possibly partial)
            if step_size >= 1.0:
                a = a_lp
            else:
                a = (1 - step_size) * a + step_size * a_lp
                a = np.maximum(a, 0)
                a = a / a.sum()
            
            b_new = fast_convolve(a)
            score_new = 2.0 * n * b_new.max()
            if score_new < best_score:
                best_score = score_new
                best_a = a.copy()
        else:
            # LP didn't help; try smaller step
            for alpha in [0.5, 0.3, 0.1]:
                a_trial = (1 - alpha) * a + alpha * a_lp
                a_trial = np.maximum(a_trial, 0)
                a_trial = a_trial / a_trial.sum()
                score_trial = 2.0 * n * fast_convolve(a_trial).max()
                if score_trial < current_score:
                    a = a_trial
                    if score_trial < best_score:
                        best_score = score_trial
                        best_a = a.copy()
                    break
            else:
                # No improvement even with small steps
                if it > 5:
                    break
    
    return best_a, best_score


def adaptive_coord_descent(a0, time_limit, n_sweeps=100):
    """
    Coordinate descent with binary search on the optimal factor.
    """
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0)
    a = a / a.sum()
    best_a = a.copy()
    best_score = 2.0 * n * fast_convolve(a).max()
    t0 = time.monotonic()
    rng = np.random.default_rng(123)
    
    for sweep in range(n_sweeps):
        if time.monotonic() - t0 > time_limit:
            break
        
        order = rng.permutation(n)
        sweep_improved = False
        
        for i in order:
            if time.monotonic() - t0 > time_limit:
                break
            if a[i] < 1e-10:
                continue
            
            # Binary search on factor
            lo, hi = 0.01, 3.0
            best_factor = 1.0
            best_local_score = best_score
            
            for _ in range(12):
                mid = (lo + hi) / 2
                a_trial = a.copy()
                a_trial[i] *= mid
                s = a_trial.sum()
                if s < 1e-15:
                    lo = mid
                    continue
                a_trial = a_trial / s
                score = 2.0 * n * fast_convolve(a_trial).max()
                if score < best_local_score:
                    best_local_score = score
                    best_factor = mid
                    lo = mid
                else:
                    hi = mid
            
            if best_factor != 1.0:
                a[i] *= best_factor
                a = a / a.sum()
                if best_local_score < best_score:
                    best_score = best_local_score
                    best_a = a.copy()
                    sweep_improved = True
        
        if not sweep_improved:
            break
    
    return best_a, best_score


def interpolate_sequence(f, new_n):
    """Interpolate a sequence to a new length."""
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    s = f.sum()
    if s < 1e-15:
        return np.ones(new_n) / new_n
    f_norm = f / s
    old_x = np.linspace(0, 1, old_n)
    new_x = np.linspace(0, 1, new_n)
    f_interp = np.interp(new_x, old_x, f_norm)
    f_interp = np.maximum(f_interp, 0)
    ss = f_interp.sum()
    if ss > 1e-15:
        f_interp = f_interp / ss
    return f_interp


def diverse_inits(parent, n, rng):
    """Generate diverse initializations."""
    candidates = []
    
    if parent is not None:
        if len(parent) == n:
            p = np.maximum(parent, 0)
            p = p / p.sum()
            candidates.append(('parent', p.copy()))
            for scale in [0.01, 0.03, 0.05, 0.1, 0.2]:
                pert = p + rng.standard_normal(n) * scale
                pert = np.maximum(pert, 0)
                pert = pert / pert.sum()
                candidates.append((f'pert_{scale}', pert))
        else:
            interp = interpolate_sequence(parent, n)
            candidates.append(('parent_interp', interp))
            
            # GS on interpolated parent
            gs_parent = gs_iterate(interp, n_iters=50)
            candidates.append(('parent_gs', gs_parent))
    
    # GS from uniform
    uniform = np.ones(n) / n
    candidates.append(('uniform', uniform.copy()))
    gs_uniform = gs_iterate(uniform, n_iters=100)
    candidates.append(('gs_uniform', gs_uniform))
    
    # GS from gaussian
    x = np.linspace(-3, 3, n)
    gau = np.exp(-x**2 / 4)
    gau = np.maximum(gau, 1e-6)
    gau = gau / gau.sum()
    candidates.append(('gaussian', gau.copy()))
    gs_gau = gs_iterate(gau, n_iters=100)
    candidates.append(('gs_gaussian', gs_gau))
    
    # GS from triangular
    tri = np.linspace(0, 1, n) + np.linspace(1, 0, n)
    tri = np.maximum(tri, 0.01)
    tri = tri / tri.sum()
    gs_tri = gs_iterate(tri, n_iters=50)
    candidates.append(('gs_tri', gs_tri))
    
    # Random
    rand = np.abs(rng.standard_normal(n)) + 0.01
    rand = rand / rand.sum()

Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using a combined approach:
1. GS/IFT (Gerchberg-Saxton) for diverse initialization via spectral flatness

def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(a, fft_size)
    return irfft(A * A, fft_size)[:size]


def get_score(a):
    """Compute 2n*max(conv(a,a)) (for normalized a with sum=1)."""
    n = len(a)
    s = a.sum()
    if s < 1e-15:
        return np.inf
    b = fast_convolve(a)
    return 2.0 * n * b.max() / (s * s)


def softmax_from_z(z):
    """Convert log-domain z to probability vector."""
    z_shifted = z - np.max(z)
    exp_z = np.exp(z_shifted)
    s = exp_z.sum()
    if s < 1e-300:
        return np.ones_like(z) / len(z)
    return exp_z / s


def gs_iterate(a, n_iters=100):
    """
    Gerchberg-Saxton iterations to flatten the autocorrelation spectrum.
    Projects onto flat |FFT| in frequency domain and non-negative in time domain.
    """
    n = len(a)
    L = 1 << (2 * n - 1 - 1).bit_length()
    a = np.maximum(np.asarray(a, dtype=np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        return np.ones(n) / n
    a = a / s

    for it in range(n_iters):
        a_padded = np.zeros(L)
        a_padded[:n] = a
        A = fft(a_padded)
        mag = np.abs(A)
        target_mag = np.sqrt(np.sum(mag ** 2) / L)
        safe_mag = np.maximum(mag, 1e-15)
        A_new = A * (target_mag / safe_mag)
        a_new_padded = np.real(ifft(A_new))
        a = a_new_padded[:n]
        a = np.maximum(a, 0.0)
        s = a.sum()
        if s < 1e-15:
            a = np.ones(n) / n
        else:
            a = a / s

    return a


def adam_softmax(a0, time_limit, T_init=0.05, T_final=0.001, lr=0.01,
                 beta1=0.9, beta2=0.999, eps=1e-8, schedule='exp',
                 restart_interval=5000, restart_noise=0.01):
    """
    Adam optimizer in log-space with soft-max temperature annealing.
    """
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 1e-300)
    a = a / a.sum()
    z = np.log(a)
    m = np.zeros(n)
    v = np.zeros(n)
    t = 0
    fft_size = 1 << (2 * n - 2).bit_length()
    t0 = time.monotonic()
    best_a = a.copy()
    best_score = 2.0 * n * fast_convolve(a).max()
    no_improve = 0

    while time.monotonic() - t0 < time_limit:
        t += 1
        elapsed = time.monotonic() - t0
        progress = min(1.0, elapsed / time_limit)

        if schedule == 'exp':
            T = T_init * (T_final / T_init) ** progress
        elif schedule == 'linear':
            T = T_init + (T_final - T_init) * progress
        elif schedule == 'cyclical':
            cyc = 0.5 + 0.5 * np.sin(2 * np.pi * progress * 3)
            base = T_init * (T_final / T_init) ** progress
            T = base + (T_init - base) * cyc * 0.3
        else:
            T = T_init * (T_final / T_init) ** progress

        a_curr = softmax_from_z(z)
        b = fast_convolve(a_curr)
        max_b = b.max()
        exp_b = np.exp(b / T - max_b / T)
        w = exp_b / exp_b.sum()

        W = rfft(w, fft_size)
        A = rfft(a_curr, fft_size)
        corr = irfft(W * np.conj(A), fft_size)[:n]
        grad_a = 2.0 * n * corr

        S = np.dot(grad_a, a_curr)
        grad_z = a_curr * (grad_a - S)

        m = beta1 * m + (1.0 - beta1) * grad_z
        v = beta2 * v + (1.0 - beta2) * (grad_z * grad_z)
        m_hat = m / (1.0 - beta1 ** t)
        v_hat = v / (1.0 - beta2 ** t)
        z = z - lr * m_hat / (np.sqrt(v_hat) + eps)

        a_new = softmax_from_z(z)
        conv_new = fast_convolve(a_new)
        score = 2.0 * n * conv_new.max()

        if score < best_score - 1e-14:
            best_score = score
            best_a = a_new.copy()
            no_improve = 0
        else:
            no_improve += 1

        if no_improve > restart_interval:
            z = np.log(np.maximum(best_a, 1e-300)) + np.random.standard_normal(n) * restart_noise
            m = np.zeros(n)
            v = np.zeros(n)
            no_improve = 0
            lr = max(0.001, lr * 0.7)

        lr = max(0.0005, lr * (1.0 - 0.00005))

    return best_a, best_score


def lp_peak_equalize(a, M=10, max_iters=50, step_size=1.0):
    """
    LP-based peak equalization using linearized active-set method.
    Solves: min t s.t. g_k^T a_new - t <= b_k(a_cur), sum(a)=1, a>=0
    where g_k = gradient of b[k] at current point a_cur.
    """
    n = len(a)
    a = np.maximum(np.asarray(a, dtype=np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        return a, np.inf
    a = a / s
    best_a = a.copy()
    best_score = 2.0 * n * fast_convolve(a).max()

    for it in range(max_iters):
        b = fast_convolve(a)
        max_b = b.max()
        current_score = 2.0 * n * max_b

        # Find top M peak locations
        b_search = b.copy()
        b_search[0] = b_search[0] * 0.7  # Deprioritize boundary slightly
        b_search[-1] = b_search[-1] * 0.7
        peak_indices = np.argsort(b_search)[::-1][:M]

        peak_vals = b[peak_indices]
        if peak_vals.max() - peak_vals.min() < 1e-12 * max(peak_vals.max(), 1e-15):
            break

        # Build LP
        # x = [a_0,...,a_{n-1}, t], minimize t
        c = np.zeros(n + 1)
        c[-1] = 1.0

        A_ub = np.zeros((M, n + 1))
        b_ub = np.zeros(M)
        for i, k in enumerate(peak_indices):
            # g_i[p] = 2*a[k-p] if 0 <= k-p < n, else 0
            valid_start = max(0, k - n + 1)
            valid_end = min(n - 1, k)
            for p in range(valid_start, valid_end + 1):
                A_ub[i, p] = 2.0 * a[k - p]
            A_ub[i, -1] = -1.0
            b_ub[i] = b[k]

        A_eq = np.zeros((1, n + 1))
        A_eq[0, :n] = 1.0  # sum(a) = 1
        b_eq = np.array([1.0])

        bounds = [(0, None)] * n + [(0, None)]

        try:
            res = linprog(c, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq,
                          bounds=bounds, method='highs')
        except Exception:
            break

        if not res.success or res.x is None:
            break

        a_lp = np.maximum(res.x[:n], 0)
        s_lp = a_lp.sum()
        if s_lp < 1e-15:
            break
        a_lp = a_lp / s_lp
        t_lp = res.x[-1]

        # Evaluate actual score
        b_lp = fast_convolve(a_lp)
        score_lp = 2.0 * n * b_lp.max()

        if score_lp < current_score - 1e-13:
            if step_size >= 1.0:
                a = a_lp.copy()
            else:
                a = (1.0 - step_size) * a + step_size * a_lp
                a = np.maximum(a, 0)
                a = a / a.sum()
            score_new = 2.0 * n * fast_convolve(a).max()
            if score_new < best_score:
                best_score = score_new
                best_a = a.copy()
        else:
            # Try partial steps
            improved = False
            for alpha in [0.5, 0.3, 0.2, 0.1]:
                a_trial = (1.0 - alpha) * a + alpha * a_lp
                a_trial = np.maximum(a_trial, 0)
                st = a_trial.sum()
                if st < 1e-15:
                    continue
                a_trial = a_trial / st
                score_trial = 2.0 * n * fast_convolve(a_trial).max()
                if score_trial < current_score - 1e-13:
                    a = a_trial
                    if score_trial < best_score:
                        best_score = score_trial
                        best_a = a.copy()
                    improved = True
                    break
            if not improved and it > 3:
                break

    return best_a, best_score


def adaptive_coord_descent(a0, time_limit, n_sweeps=200):
    """
    Coordinate descent with binary search on the optimal multiplicative factor.
    """
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0)
    a = a / a.sum()
    best_a = a.copy()
    best_score = 2.0 * n * fast_convolve(a).max()
    t0 = time.monotonic()
    rng = np.random.default_rng(12345)

    for sweep in range(n_sweeps):
        if time.monotonic() - t0 > time_limit:
            break

        order = rng.permutation(n)
        sweep_improved = False

        for i in order:
            if time.monotonic() - t0 > time_limit:
                break
            if a[i] < 1e-12:
                continue

            # Binary search on factor in [0.05, 5.0]
            lo, hi = 0.05, 5.0
            best_factor = 1.0
            best_local_score = best_score

            for _ in range(14):
                mid = (lo + hi) / 2.0
                a_trial = a.copy()
                a_trial[i] *= mid
                s = a_trial.sum()
                if s < 1e-15:
                    lo = mid
                    continue
                a_trial = a_trial / s
                score = 2.0 * n * fast_convolve(a_trial).max()
                if score < best_local_score:
                    best_local_score = score
                    best_factor = mid
                    lo = mid
                else:
                    hi = mid

            if best_factor != 1.0:
                a[i] *= best_factor
                a = a / a.sum()
                if best_local_score < best_score:
                    best_score = best_local_score
                    best_a = a.copy()
                    sweep_improved = True

        if not sweep_improved:
            break

    return best_a, best_score


def basin_hopping(a0, time_limit, n_trials=100, noise_scales=None):
    """
    Basin hopping: perturb, locally optimize (short Adam + LP), accept if improved.
    """
    if noise_scales is None:
        noise_scales = [0.01, 0.02, 0.05, 0.1, 0.2, 0.3, 0.5]

    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0)
    a = a / a.sum()
    best_a = a.copy()
    best_score = 2.0 * n * fast_convolve(a).max()
    t0 = time.monotonic()
    rng = np.random.default_rng(999)

    for trial in range(n_trials):
        if time.monotonic() - t0 > time_limit:
            break

        scale = noise_scales[trial % len(noise_scales)]
        a_pert = best_a + rng.standard_normal(n) * scale
        a_pert = np.maximum(a_pert, 0)
        s = a_pert.sum()
        if s < 1e-15:
            continue
        a_pert = a_pert / s

        # Short local optimization
        rem = time_limit - (time.monotonic() - t0)
        if rem < 5:
            break
        t_adam = min(2.0, rem * 0.4)
        t_lp = min(3.0, rem * 0.4)

        a_local, _ = adam_softmax(a_pert, t_adam, T_init=0.02, T_final=0.001, lr=0.005, schedule='exp')
        a_local = np.maximum(a_local, 0)
        a_local = a_local / a_local.sum()

        a_lp, _ = lp_peak_equalize(a_local, M=8, max_iters=10, step_size=1.0)
        a_lp = np.maximum(a_lp, 0)
        a_lp = a_lp / a_lp.sum()

        score_local = 2.0 * n * fast_convolve(a_lp).max()
        if score_local < best_score - 1e-13:
            best_score = score_local
            best_a = a_lp.copy()

    return best_a, best_score


def interpolate_sequence(f, new_n):
    """Interpolate a sequence to a new length."""
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    s = f.sum()
    if s < 1e-15:
        return np.ones(new_n) / new_n
    f_norm = f / s
    old_x = np.linspace(0, 1, old_n)
    new_x = np.linspace(0, 1, new_n)
    f_interp = np.interp(new_x, old_x, f_norm)
    f_interp = np.maximum(f_interp, 0)
    ss = f_interp.sum()
    if ss > 1e-15:
        f_interp = f_interp / ss
    return f_interp


def evaluate_track(a, best_seq, best_score):
    """Evaluate a candidate and update best."""
    a = np.maximum(a, 0.0)
    s = a.sum()
    if s < 0.01:
        return best_seq, best_score
    a_norm = a / s
    try:
        score = float(evaluate_sequence(a_norm.tolist()))
    except Exception:
        score = get_score(a_norm)
    if np.isfinite(score) and score < best_score:
        best_score = score
        best_seq = a_norm.copy()
    return best_seq, best_score


def propose_candidate(seed=42, budget_s=1800.0):
    """
    Multi-phase optimization combining GS initialization, Adam soft-max,
    LP peak equalization, basin hopping, and coordinate descent.
    """
    rng = np.random.default_rng(seed)
    deadline = time.monotonic() + max(1.0, float(budget_s) - 15.0)

    best_seq = None
    best_score = float('inf')

    # Load parent
    parent = None
    try:
        p = np.asarray(height_sequence_1, dtype=np.float64)
        p = np.clip(p, 0.0, 1000.0)
        if p.ndim == 1 and p.size > 0 and np.isfinite(p).all() and p.sum() > 1e-10:
            parent = p / p.sum()
            p_score = float(evaluate_sequence(parent.tolist()))
            print(f"Parent: n={len(parent)}, score={p_score:.6f}")
            best_seq = parent.copy()
            best_score = p_score
    except Exception:
        pass

    if parent is None:
        n_default = 768
        uniform = np.ones(n_default) / n_default
        best_seq = uniform
        best_score = float(evaluate_sequence(uniform.tolist()))
        print(f"Default: n={n_default}, score={best_score:.6f}")

    n_parent = len(best_seq)
    print(f"Starting best: {best_score:.6f} (n={n_parent})")

    # === Phase 1: GS + Diverse Initialization (4% time) ===
    print(f"\n=== Phase 1: GS + Diverse Initialization ===")
    t_p1 = min(60.0, (deadline - time.monotonic()) * 0.04)
    t_p1_deadline = time.monotonic() + t_p1

    # Generate varied initializations
    inits = {}

    # GS from parent
    gs_parent = gs_iterate(best_seq, n_iters=80)
    s1 = 2.0 * n_parent * fast_convolve(gs_parent).max()
    inits['gs_parent'] = (s1, gs_parent)
    print(f"  gs_parent: {s1:.6f}")

    # GS from uniform
    uniform = np.ones(n_parent) / n_parent
    gs_uni = gs_iterate(uniform, n_iters=100)
    s2 = 2.0 * n_parent * fast_convolve(gs_uni).max()
    inits['gs_uniform'] = (s2, gs_uni)
    print(f"  gs_uniform: {s2:.6f}")

    # GS from Gaussian
    x = np.linspace(-3, 3, n_parent)
    gau = np.exp(-x ** 2 / 4)
    gau = np.maximum(gau, 1e-6)
    gau = gau / gau.sum()
    gs_gau = gs_iterate(gau, n_iters=80)
    s3 = 2.0 * n_parent * fast_convolve(gs_gau).max()
    inits['gs_gaussian'] = (s3, gs_gau)
    print(f"  gs_gaussian: {s3:.6f}")

    # Perturbed parent
    for scale in [0.02, 0.05, 0.1]:
        pert = best_seq + rng.standard_normal(n_parent) * scale
        pert = np.maximum(pert, 0)
        pert = pert / pert.sum()
        sp = 2.0 * n_parent * fast_convolve(pert).max()
        inits[f'pert_{scale}'] = (sp, pert)
        print(f"  pert_{scale}: {sp:.6f}")

    # Original parent
    sp = 2.0 * n_parent * fast_convolve(best_seq).max()
    inits['parent'] = (sp, best_seq.copy())

    # Sort by score
    sorted_inits = sorted(inits.items(), key=lambda x: x[1][0])
    print(f"  Best init: {sorted_inits[0][0]} (score={sorted_inits[0][1][0]:.6f})")

    # === Phase 2: Multi-start Adam (35% time) ===
    print(f"\n=== Phase 2: Multi-Start Adam ===")
    t_p2 = (deadline - time.monotonic()) * 0.35
    t_p2_deadline = time.monotonic() + t_p2

    n_starts = min(6, len(sorted_inits))
    time_per_start = t_p2 / n_starts

    for idx in range(n_starts):
        rem = t_p2_deadline - time.monotonic() - 30
        if rem < 20:
            break
        label, (init_score, init_a) = sorted_inits[idx]
        t_alloc = min(time_per_start, rem)
        if t_alloc < 15:
            continue

        print(f"  Start {idx + 1}/{n_starts}: {label} (init={init_score:.6f}), t={t_alloc:.0f}s")

        settings = [
            (0.05, 0.002, 0.008, 'exp'),
            (0.03, 0.001, 0.006, 'exp'),
            (0.04, 0.003, 0.010, 'cyclical'),
        ]

        best_from_start = init_a.copy()
        best_from_start_score = init_score

        for si, (Ti, Tf, lr, sched) in enumerate(settings):
            rem = t_p2_deadline - time.monotonic() - 15
            if rem < 8:

                init_a, t_sub, T_init=Ti, T_final=Tf, lr=lr, schedule=sched
            )
            if score_res < best_from_start_score:
                best_from_start_score = score_res
                best_from_start = a_res.copy()

        # LP polish
        rem = t_p2_deadline - time.monotonic() - 10

                best_from_start = a_lp.copy()

        best_seq, best_score = evaluate_track(best_from_start, best_seq, best_score)
        print(f"    Best from start: {best_score:.6f}")

    print(f"  After Phase 2: best={best_score:.6f}")

    print(f"\n=== Phase 3: LP Peak Equalization ===")

        score_actual = 2.0 * len(a_lp) * fast_convolve(a_lp).max()
        if score_actual < best_score - 1e-13:
            best_score = score_actual
            best_seq = a_lp.copy()
            print(f"  LP M={M_val}: NEW BEST {score_actual:.6f}")
        else:
            print(f"  LP M={M_val}: {score_actual:.6f}")

    # Adam after LP to escape LP artifacts
    rem = t_p3_deadline - time.monotonic() - 5
    if rem > 10:
        a_res, _ = adam_softmax(best_seq, min(rem, 30.0),
                                T_init=0.015, T_final=0.0005, lr=0.004, schedule='exp')
        best_seq, best_score = evaluate_track(a_res, best_seq, best_score)
        print(f"  Post-LP Adam: {best_score:.6f}")

    print(f"  After Phase 3: best={best_score:.6f}")

    # === Phase 4: Basin Hopping (15% time) ===
    print(f"\n=== Phase 4: Basin Hopping ===")
    t_p4 = (deadline - time.monotonic()) * 0.15

    a_bh, _ = basin_hopping(best_seq, t_p4, n_trials=50)
    best_seq, best_score = evaluate_track(a_bh, best_seq, best_score)
    print(f"  After basin hopping: {best_score:.6f}")

    # === Phase 5: Multi-length exploration (10% time) ===
    print(f"\n=== Phase 5: Multi-Length Exploration ===")
    t_p5 = (deadline - time.monotonic()) * 0.10
    t_p5_deadline = time.monotonic() + t_p5

    n_best = len(best_seq)
    alt_lengths = []
    for factor in [1.25, 1.5, 0.75, 2.0, 1.1, 1.33, 0.67]:
        alt_n = int(n_best * factor)
        if 256 <= alt_n <= 4096 and alt_n != n_best:

                alt_lengths.append(alt_n)

    for alt_n in alt_lengths[:4]:

                                lr=0.007, schedule='exp')
        a_lp_alt, _ = lp_peak_equalize(a_alt, M=10, max_iters=10, step_size=1.0)
