```python
def project_simplex(v):
    """Project v onto the probability simplex {x >= 0, sum(x) = 1}."""
    n = len(v)
    if v.sum() <= 0:
        return np.ones(n) / n
    # Sort in descending order
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.nonzero(u * np.arange(1, n+1) > (cssv - 1))[0][-1]
    theta = (cssv[rho] - 1) / (rho + 1.0)
    return np.maximum(v - theta, 0)
```

For a constant sequence, score = 2. To get below 2, we need max(conv(a,a)) < 1/n (when sum(a) = 1).

The sum of all convolution values is 1. There are 2n-1 of them. The average is 1/(2n-1) ≈ 1/(2n). So the average is about half of 1/n. This means it's definitely possible to have max < 1/n if the distribution is flat enough.

The question is: can we construct such a sequence?

Let me think about it in terms of the "energy" distribution. For the constant sequence, the convolution is a triangle with peak 1/n at the center and 0 at the edges. The "excess" energy at the center (above the flat level 1/(2n-1)) is 1/n - 1/(2n-1) ≈ 1/(2n). This excess needs to be "spread out" to the edges.

To spread it out, we need the sequence to have "anti-correlation" at certain lags - i.e., some products a[i]*a[j] with i+j = k should be small for k near the center.

For non-negative sequences, this means some a[i] or a[j] must be small. So we need a "banded" structure where the sequence has both large and small values in an alternating pattern.
