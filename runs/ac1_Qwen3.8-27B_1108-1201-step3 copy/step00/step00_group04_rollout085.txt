Actually, I can be smarter. Instead of trying fixed multipliers, I can analytically find the optimal δ.

The key observation: new_max(δ) is piecewise linear (or quadratic at k=2i). Between "breakpoints" (where the argmax changes), the objective is of the form:
obj(δ) = 2n * (A + B*δ + C*δ²) / (S+δ)²

where A, B, C depend on which k is the argmax.

For a linear piece (C=0): obj(δ) = 2n*(A+B*δ)/(S+δ)²
Setting derivative to zero: 2n*[B(S+δ)² - (A+B*δ)*2(S+δ)]/(S+δ)⁴ = 0
=> B(S+δ) - 2(A+B*δ) = 0
=> B*S + B*δ - 2A - 2B*δ = 0
=> B*S - B*δ - 2A = 0
=> δ = (B*S - 2A) / B = S - 2A/B

For a quadratic piece (C=1, at k=2i): obj(δ) = 2n*(A+B*δ+δ²)/(S+δ)²
This is harder to solve analytically.

So the approach would be:
1. Find all breakpoints of new_max(δ) (where two linear/quadratic pieces intersect).
2. In each interval, find the optimal δ (analytically for linear pieces, numerically for quadratic).
