Let me try a different approach. What about using the DFT perspective?

If we think of the sequence as a signal, the (circular) autocorrelation is the IDFT of |DFT(a)|². We want the circular autocorrelation to be flat, which means |DFT(a)|² should be constant, i.e., |DFT(a)| should be constant. This is the "flat magnitude spectrum" condition, satisfied by ZC (Zadoff-Chu) sequences and Barker sequences (approximately).

But we have LINEAR convolution, not circular. The linear convolution is related to the circular convolution by zero-padding: if we zero-pad a to length L >= 2n-1, then the linear convolution equals the first 2n-1 elements of the circular convolution of the zero-padded sequences.

So if we find a sequence a of length n such that its DFT (of length L >= 2n-1) has nearly constant magnitude, then the linear autocorrelation will be nearly flat.

But the constraint is a_j >= 0. This is a strong constraint on the DFT.

For a non-negative sequence, the DFT at frequency 0 is the sum (which is positive and large). The DFT at other frequencies can be controlled but are constrained by non-negativity.
