    n = len(f)
    # Objective: maximize sum(b) => minimize -sum(b)
    c = -np.ones(n)

Minimize max_k c[k] subject to sum(a) = 1, a >= 0.

By the "duality" of max and sum, if we can make all c[k] equal, that would be optimal. But that's not possible because the sum of all c[k] is (sum a)² = 1, and there are 2n-1 values, so the average is 1/(2n-1). If all c[k] = 1/(2n-1), then max = 1/(2n-1) and the objective = 2n/(2n-1) ≈ 1.

For a single sequence, a flat autocorrelation (except at lag 0) is the goal of "low autocorrelation" sequences. But for non-negative real sequences, this is very restrictive.

Actually, let me think about this problem from the perspective of the "convolution as a quadratic form."

c[k] = sum_j a[j] * a[k-j]

This is the (k-(n-1))-th coefficient of the polynomial (A(x))² where A(x) = sum_j a[j] x^j.

So we're looking at the coefficients of A(x)² and want to minimize the maximum coefficient.

If A(x) = sum_j a[j] x^j with a[j] >= 0 and sum a[j] = 1, then A(1) = 1 and A(x)² has non-negative coefficients summing to 1.

The problem becomes: find a polynomial A(x) = sum_{j=0}^{n-1} a_j x^j with a_j >= 0, A(1) = 1, that minimizes the maximum coefficient of A(x)².

This is a well-studied problem in the theory of "flat" polynomials and "low peak-to-average" sequences.

One approach: choose A(x) to be as "flat" as possible. For example, if A(x) = (1+x+...+x^{m-1})/m * (some other factor), the convolution might be flatter.
