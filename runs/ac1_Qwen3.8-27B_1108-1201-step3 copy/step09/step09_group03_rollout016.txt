    """Find the best delta for coordinate i via bisection."""
    n = len(a)
    k_start = i
    k_end = min(i + n - 1, 2*n - 2)
    c = a[k_start-i:k_end-i+1]  # a[k-i] for k in [k_start, k_end]
    
    # Binary search on delta in [-a[i], a[i]] (reasonable range)
    lo = -a[i]  # can't go below 0
    hi = a[i]  # reasonable upper bound
    
    def score_at_delta(delta):
        affected = conv[k_start:k_end+1] + 2*delta*c
        if 2*i >= k_start and 2*i <= k_end:
            idx = 2*i - k_start
            affected = affected.copy()
            affected[idx] = conv[2*i] + 2*delta*a[i] + delta*delta
        M_new = max(U, np.max(affected))
        S_new = S + delta
        if S_new <= 0:
            return np.inf
        return 2*n*M_new / (S_new**2)
    
    # Golden section search
    gr = (np.sqrt(5) - 1) / 2  # 0.618
    for _ in range(30):  # 30 iterations gives ~1e-9 precision
        m1 = lo + gr*(hi - lo)
        m2 = hi - gr*(hi - lo)
        f1 = score_at_delta(m1)
        f2 = score_at_delta(m2)
        if f1 < f2:
            hi = m2
        else:
            lo = m1
    delta = (lo + hi) / 2
    return delta, score_at_delta(delta)

**Approach: Solve the LP relaxation iteratively (best-response method)**

The key idea from the "state of the art" description:
- Fix `a`, solve for the best `b` that minimizes `max_k (a*b)[k]` (subject to `b >= 0, sum(b) = 1`)
- This is an LP: minimize `M` subject to `T @ b <= M, b >= 0, sum(b) = 1`
- Then update `a = (1-t)*a + t*b`
- Repeat

This is the Frank-Wolfe / conditional gradient method applied to the non-convex problem. It's guaranteed to make progress (or at least not make things worse) at each step.

The LP has `n` variables and `2n-1` constraints (plus non-negativity and sum=1). For n=1024, this is a 1024-variable LP with ~2000 constraints, which is very fast for modern solvers.

Let me implement this:

```python
def lp_best_response(a, solver):
    """Solve the LP: min M s.t. T@b <= M, b >= 0, sum(b)=1."""
    import cvxpy as cp
    n = len(a)
    b_var = cp.Variable(n, nonneg=True)
    M_var = cp.Variable()
    
    # Build T: T[k, j] = a[j] if 0 <= k-j < n, else 0
    # Actually, (a*b)[k] = sum_j a[k-j]*b[j] for valid indices
    # = sum_j T[k,j] * b[j] where T[k,j] = a[k-j] if 0 <= k-j < n
    
    # Use a sparse matrix for efficiency
    # T has (2n-1) rows and n columns
    # Row k: T[k,j] = a[k-j] for max(0, k-n+1) <= j <= min(n-1, k)
    
    rows = []
    cols = []
    vals = []
    for k in range(2 * n - 1):
        j_start = max(0, k - n + 1)
        j_end = min(n - 1, k)
        for j in range(j_start, j_end + 1):
            rows.append(k)
            cols.append(j)
            vals.append(a[k - j])
    
    T = scipy.sparse.coo_matrix((vals, (rows, cols)), shape=(2*n-1, n))
    
    constraints = [
        T @ b_var <= M_var,
        cp.sum(b_var) == 1
    ]
    prob = cp.Problem(cp.Minimize(M_var), constraints)
    prob.solve(solver=solver)
    
    b_val = np.asarray(b_var.value, dtype=np.float64)
    b_val = np.maximum(b_val, 0)
    s = b_val.sum()
    if s > 0:
        b_val = b_val / s
    return b_val, M_var.value
```

This is O(n^2) to build the matrix, which for n=1024 is about 1M entries. The LP solve should be fast (fraction of a second).

        sweep += 1
        any_improved = False

        suffix_max = np.maximum.accumulate(conv[::-1])[::-1]

                continue
