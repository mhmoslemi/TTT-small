In coordinate descent, when we change a_i, we need to maintain sum(a) = 1. One approach: after updating a_i, re-normalize. But this changes all other coordinates slightly.

where d_k = a_{k-i} (if valid) and base_k = (a*a)_k - t * d_k (the current value minus the i-contribution).

This is a ratio of a piecewise-linear function to a quadratic. We can minimize this over t >= 0 by:
1. Finding the critical points (where the argmax changes, or where the derivative is zero).
2. Evaluating F at those points and at t=0.

The derivative of F(t) is:
F'(t) = 2n * [d_{k*} * (s+t)^2 - 2 * (s+t) * max_k(base_k + t*d_k)] / (s+t)^4

This is a bit complex to solve analytically because the argmax can change. But we can numerically find the minimum by:
1. Computing all "breakpoints" where the argmax changes.
2. Between breakpoints, the function is [2n * (base_{k*} + t * d_{k*})] / (s+t)^2 which is a simple rational function.
3. The minimum of (base + dt) / (s+t)^2 over an interval can be found analytically.

The derivative of (base + dt)/(s+t)^2 is:
d * (s+t)^2 - (base + dt) * 2(s+t) = (s+t)[d(s+t) - 2(base + dt)] = (s+t)[ds - 2base - dt]

Setting to zero: t = (ds - 2base) / d (if d > 0)

So for each "active" k, the optimal t is (d_k * s - 2 * base_k) / d_k = s - 2*base_k/d_k (if d_k > 0).

This gives us a very efficient coordinate descent! For each coordinate, we can find the optimal value in O(n) time (since there are 2n-1 possible k values to check).

Total complexity per full sweep: O(n * 2n) = O(n^2). For n=960, that's about 1M operations per sweep, which is very fast.

"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
1. Exact coordinate descent (exploiting piecewise-linear structure)
2. Multiplicative weights mirror descent with log-sum-exp smoothing
3. Simulated annealing with diverse move operators
4. Nesterov-accelerated subgradient as final polish
Key innovation: exact coordinate descent using the fact that the objective
is a ratio of piecewise-linear to quadratic in each coordinate.
"""

import numpy as np
import time
from scipy.fft import rfft, irfft


def fast_convolve(a):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(a, fft_size)
    return irfft(A * A, fft_size)[:size]


def score_normalized(a):
    b = fast_convolve(a)
    return 2.0 * len(a) * b.max()


def full_score(a):
    """Compute the full objective 2n*max(conv)/(sum)^2."""
    s = a.sum()
    if s < 1e-15:
        return float('inf')
    b = fast_convolve(a)
    return 2.0 * len(a) * b.max() / (s * s)


def project_simplex(v):
    n = len(v)
    if n == 0:
        return v
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1) / (rho + 1.0)
    return np.maximum(v - theta, 0)


def exact_coord_descent(a, n_sweeps=100, time_limit=60.0):
    """
    Exact coordinate descent exploiting the piecewise-linear structure.
    For each coordinate i, the objective as a function of a_i is:
    2n * max_k (base_k + a_i * d_k) / (s + a_i)^2
    where base_k = conv(a,a)_k - a_i * d_k, d_k = a_{k-i} (if valid), s = sum(a) - a_i.
    Each piece is (base + d*t)/(s+t)^2 which has minimum at t = s - 2*base/d.
    """
    n = len(a)
    a = a.copy().astype(np.float64)
    best_score = full_score(a)
    t0 = time.monotonic()
    
    for sweep in range(n_sweps):
        if time.monotonic() - t0 > time_limit:
            break
        
        improved = False
        for i in range(n):
            if time.monotonic() - t0 > time_limit:
                break
            
            ai = a[i]
            if ai < 1e-15:
                # Try setting to a small value
                continue
            
            # Remove i-th contribution
            # d_k = a_{k-i} for valid k-i in [0, n-1]
            # k-i valid means k in [i, i+n-1], and k in [0, 2n-2]
            # So k ranges from max(0, i) to min(2n-2, i+n-1)
            k_min = max(0, i)
            k_max = min(2 * n - 2, i + n - 1)
            
            # d_k = a[k-i] for k in [k_min, k_max]
            d = np.zeros(2 * n - 1)
            valid_k = np.arange(k_min, k_max + 1)
            d[valid_k] = a[valid_k - i]
            
            # base_k = conv(a,a)_k - ai * d_k
            b = fast_convolve(a)
            base = b - ai * d
            
            s = a.sum() - ai  # sum of all other elements
            
            # For each k with d_k > 0, the optimal t is:
            # t_k = s - 2*base_k/d_k (from derivative of (base + d*t)/(s+t)^2 = 0)
            # But we need to check that k is still the argmax at t_k.
            
            # Strategy: try t = 0, t = current ai, and t_k for top contributors
            candidates = [0.0, ai]
            
            # For k where d_k > 0 and base_k + ai*d_k is large (near the max)
            current_conv = base + ai * d  # = b (the current convolution)
            peak_val = current_conv.max()
            threshold = 0.9 * peak_val
            active_k = np.where(current_conv >= threshold)[0]
            
            for k in active_k[:20]:
                dk = d[k]
                if dk > 1e-15:
                    tk = s - 2.0 * base[k] / dk
                    if tk > 0:
                        candidates.append(tk)
                    else:
                        candidates.append(0.0)
            
            # Also try the current peak k
            k_peak = int(np.argmax(current_conv))
            if d[k_peak] > 1e-15:
                tk_peak = s - 2.0 * base[k_peak] / d[k_peak]
                if tk_peak > 0:
                    candidates.append(tk_peak)
            
            # Evaluate at each candidate
            best_t = ai
            best_obj = full_score(a)
            
            for t in candidates:
                t = max(0.0, t)
                a[i] = t
                obj = full_score(a)
                if obj < best_obj:
                    best_obj = obj
                    best_t = t
            a[i] = best_t
            
            if best_obj < best_score - 1e-15:
                best_score = best_obj
                improved = True
        
        if not improved:
            break
    
    return a, best_score
