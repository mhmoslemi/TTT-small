def simplex_project(v):
    """Project vector v onto the probability simplex {x >= 0, sum(x)=1}."""
    n = len(v)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if cond.any():
        rho = np.nonzero(cond)[0][-1]
        theta = (cssv[rho] - 1.0) / (rho + 1.0)
        return np.maximum(v - theta, 0.0)
    else:
        return np.ones(n) / n

For a flat convolution `c[k] = C` for all k in some range, we'd need `sum a_i * a_{k-i} = C` for all k in that range. This is a system of equations that's related to "perfect autocorrelation" sequences.

In the continuous domain, the function with flat autocorrelation is a constant (which gives score 2). But in the discrete domain with the constraint that a is supported on {0, ..., n-1}, we can do better by making the sequence asymmetric.

The minimum of such a function can be found analytically (by taking the derivative and solving a cubic), but it's complex. Golden section is simpler and works well in practice.
