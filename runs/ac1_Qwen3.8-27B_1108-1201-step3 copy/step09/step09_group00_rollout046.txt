`2 * sum_k w_k * a_{k-j}` (for valid indices)

This is `2 * (W * a)[j]` where `W` is some "cross-correlation" operation determined by `w`.

If `w` is a delta at a single point `k*`, then the gradient is `2 * a_{k*-j}` (reversed and shifted), which can be computed in O(n).

If `w` has full support, the gradient is `2 * sum_k w_k * a_{k-j}` which is a convolution of `w` with `a_reversed`, computable in O(n log n) via FFT.

So the algorithm is:

2. Update `w`: `w_k <- exp((a*a)[k] / T) / sum exp((a*a)[j] / T)` (softmax with temperature T).
3. Update `a`: Solve `min sum_k w_k (a*a)[k] s.t. a in simplex` using projected gradient with FFT-based gradient computation.
4. Decrease T.
5. Repeat.

This is essentially a **double mirror descent** or **interleaved smoothing** approach.

"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using alternating mirror descent
with FFT-based gradient computation, LogSumExp smoothing, and L-BFGS polishing.
Key innovations: QP subproblem via projected gradient with simplex projection,
adaptive temperature scheduling, and multi-spectral initialization.

import numpy as np
import time
from scipy.fft import rfft, irfft
from scipy.optimize import minimize


def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(np.asarray(a, dtype=np.float64), fft_size)
    return irfft(A * A, fft_size)[:size]


def compute_grad_weighted(a, w):
    """Compute gradient of sum_k w_k * (a*a)[k] w.r.t. a.
    w is a probability vector over the 2n-1 lag indices.
    Returns 2 * sum_k w_k * a_{k-j} (appropriately shifted).
    """
    n = len(a)
    size = 2 * n - 1
    # We need: grad_j = 2 * sum_{k: 0<=k-j<n} w_k * a_{k-j}
    # Let i = k-j, so k = j+i, and 0 <= i < n, 0 <= j+i < 2n-1 (always true for j < n, i < n)
    # Also need 0 <= k < 2n-1, which means 0 <= j+i < 2n-1.
    # For j in [0, n-1] and i in [0, n-1]: j+i is in [0, 2n-2], so always valid.
    # grad_j = 2 * sum_{i=0}^{n-1} w_{j+i} * a_i
    # This is a cross-correlation of w and a!
    # Specifically: grad = 2 * vehicles(w, a) where vehicles is cross-correlation
    # cross_correlation(w, a)[j] = sum_i w_{j+i} * a_i
    # = sum_i a_i * w_{j+i}
    # This is the convolution of a with reversed w, shifted appropriately.
    
    # Let's compute it via FFT:
    # cross_corr[j] = sum_i a[i] * w[j+i]
    # Let's define w_rev[i] = w[size-1-i] (reverse w)
    # Then conv(a, w_rev)[j] = sum_i a[i] * w_rev[j-i] = sum_i a[i] * w[size-1-(j-i)] = sum_i a[i] * w[size-1-j+i]
    # We want w[j+i], so we need size-1-j+i = j+i, i.e., size-1-j = 0, i.e., j = size-1. That's not right.
    
    # Let me think differently.
    # cross_corr[j] = sum_i a[i] * w[j+i] for j = 0, ..., n-1
    # This is like a "cross-correlation" but with w going forward.
    # If we define w_ext[k] = w[k] for 0 <= k < 2n-1, then:
    # cross_corr[j] = sum_{i=0}^{n-1} a[i] * w_ext[j+i]
    # This is the (j-th element of the) "upper triangular" part of a Toeplitz-like product.
    
    # Alternative: Use the fact that this is related to the convolution structure.
    # (a*a)[k] = sum_i a[i] * a[k-i]
    # d/dj sum_k w[k] * (a*a)[k] = sum_k w[k] * (a[k-j] + a[k-j]) [by the chain rule]
    # = 2 * sum_k w[k] * a[k-j] (for valid k-j)
    # = 2 * sum_i w[j+i] * a[i] (substituting i = k-j)
    
    # So grad[j] = 2 * sum_{i=0}^{n-1} w[j+i] * a[i]
    # This is a "cross-correlation" of a with w.
    
    # To compute via FFT:
    # Let's zero-pad a to length L and w to length L.
    # The cross-correlation c[j] = sum_i a[i] * conj(w[j+i]) for complex, or sum_i a[i]*w[j+i] for real.
    # This is: c = ifft(fft(a) * conj(fft(w))) ... no, that gives circular cross-correlation.
    
    # Actually, the standard cross-correlation: (a ⋆ w)[j] = sum_i a[i+j] * w[i] = sum_i a[i] * w[i-j]
    # We want: sum_i a[i] * w[j+i] = (w ⋆ a)[j] ... let me verify.
    # (w ⋆ a)[j] = sum_i w[i+j] * a[i] ... yes! That's exactly what we want.
    # (w ⋆ a)[j] = sum_i w[i+j] * a[i] = sum_i a[i] * w[i+j] √
    
    # The cross-correlation (w ⋆ a)[j] = sum_i w[i+j] * a[i] can be computed as:
    # = (w_reversed * a)[j + n - 1] where * is linear convolution
    # Because: (w_rev * a)[m] = sum_i w_rev[i] * a[m-i] = sum_i w[n-1-i] * a[m-i]
    # Let j' = n-1-i, so i = n-1-j':
    # = sum_{j'} w[j'] * a[m - n + 1 + j']
    # For m = j + n - 1: = sum_{j'} w[j'] * a[j + j'] = sum_i w[i] * a[j+i] √
    
    # So: grad[j] = 2 * (w_rev * a)[j + n - 1]
    # Where w_rev is the reversal of w (w_rev[i] = w[n-1-i]) and * is linear convolution.
    
    # But w has length 2n-1, and we're reversing it... let me be more careful.
    
    # w has length 2n-1. Let w_ext = w (length 2n-1).
    # We want: g[j] = sum_{i=0}^{n-1} w_ext[j+i] * a[i] for j = 0, ..., n-1.
    
    # Method: Compute the linear convolution of a (length n) with w_ext_reversed (length 2n-1).
    # w_ext_reversed[i] = w_ext[2n-2-i] for i = 0, ..., 2n-2.
    # conv(a, w_ext_reversed)[m] = sum_i a[i] * w_ext_reversed[m-i] = sum_i a[i] * w_ext[2n-2-m+i]
    # We want this to equal sum_i a[i] * w_ext[j+i] when m = 2n-2-j:
    # conv(a, w_ext_reversed)[2n-2-j] = sum_i a[i] * w_ext[2n-2-(2n-2-j)+i] = sum_i a[i] * w_ext[j+i] √
    
    # So: g[j] = conv(a, w_ext_reversed)[2n-2-j] for j = 0, ..., n-1.
    # In array indexing: g = 2 * conv(a, w_rev)[2n-2-(n-1) : 2n-2-(-1)][::-1]
    # = 2 * conv(a, w_rev)[n-1 : 2n-2][::-1]
    # = 2 * conv(a, w_rev)[2n-2 : n-2 : -1]
    
    # Let me just compute the full convolution and extract the right elements.
    
    fft_size = 1 << (n + 2*n - 2 - 1).bit_length()  # need length n + 2n-2 - 1 = 3n-3
    A = rfft(a, fft_size)
    W_rev = rfft(w[::-1], fft_size)
    conv_result = irfft(A * W_rev, fft_size)
    
    # conv_result[m] = sum_i a[i] * w_rev[m-i] = sum_i a[i] * w[2n-2-(m-i)] = sum_i a[i] * w[2n-2-m+i]
    # We want g[j] = sum_i a[i] * w[j+i] = conv_result[2n-2-j]
    
    g = 2.0 * conv_result[2*n-2 - np.arange(n)]
    return g


def proj_simplex(v):
    """Project vector v onto the probability simplex {x: x>=0, sum(x)=1}."""
    n = len(v)
    if n == 0:
        return v
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.argmax(1 - u / np.arange(1, n+1) > 0)
    theta = (cssv[rho] - 1) / (rho + 1)
    return np.maximum(v - theta, 0)


def softmax_weights(b, T):
    """Compute softmax weights for the convolution values b with temperature T."""
    if T < 1e-10:
        # Hard argmax
        w = np.zeros(len(b))
        max_idx = np.where(b == b.max())[0]
        w[max_idx] = 1.0 / len(max_idx)
        return w
    b_shifted = b - b.max()
    exp_b = np.exp(b_shifted / T)
    w = exp_b / exp_b.sum()
    return w


def logsumexp_obj(a, T):
    """Compute (2n/T) * log(sum_k exp(T * (a*a)[k])) as a smooth approximation."""
    n = len(a)
    b = fast_convolve(a)
    b_max = b.max()
    log_sum_exp = b_max + T * np.log(np.exp((b - b_max) / T).sum() / len(b))
    # Actually: log(sum exp(T*b_k)) = T*b_max + log(sum exp(T*(b_k - b_max)))
    # = T*b_max + log(sum exp(T*(b_k - b_max)))
    # The smoothed max is: (1/T) * log(sum exp(T*b_k)) = b_max + (1/T)*log(sum exp(T*(b_k - b_max)))
    return 2.0 * n * (b_max + (1.0/T) * np.log(np.exp((b - b_max)).sum()))


def logsumexp_grad(a, T):
    """Gradient of the LogSumExp-smoothed objective."""
    n = len(a)
    b = fast_convolve(a)
    b_max = b.max()
    exp_b = np.exp((b - b_max))  # exp(T*(b-b_max)) with T=1 for the grad formula
    # d/d a_j [max_k (a*a)[k] smoothed] = sum_k w_k * 2*a_{k-j} where w_k = exp(b_k)/sum exp(b_k)
    w = exp_b / exp_b.sum()
    # This is the same as compute_grad_weighted(a, w)
    return compute_grad_weighted(a, w)


def projected_gradient_qp(a0, w, n_iters=200, lr=None):
    """Solve min sum_k w_k (a*a)[k] s.t. a in simplex using projected gradient."""
    n = len(a0)
    a = a0.copy()
    
    # Compute Lipschitz constant estimate
    # The Hessian of sum_k w_k (a*a)[k] is 2*Q where Q has (Q)_{ij} = w_{i+j} (approximately)
    # ||Q||_2 <= sum_i,j |Q_{ij}| ... this is loose. Better: ||Q||_2 <= max_row_sum
    # For now, use a simple step size.
    if lr is None:
        # Estimate: the objective value at a0 is sum_k w_k (a*a)[k]
        # The gradient norm gives us a scale
        g0 = compute_grad_weighted(a, w)
        lr = 1.0 / (2.0 * np.linalg.norm(g0) + 1e-10)
        # Actually, for a quadratic on the simplex, the Lipschitz constant of the gradient
        # is 2*||Q||_inf where ||Q||_inf is the max row sum of Q.
        # Q_{ij} = w_{i+j} (for valid i+j < 2n-1)
        # Row sum of Q: sum_j w_{i+j} for j=0,...,n-1
        # This is <= sum_k w_k = 1
        # So Lipschitz constant <= 2*1 = 2, giving lr >= 1/2
        # But this is very conservative. Let's use a line search or adaptive lr.
        lr = 0.5
    
    for it in range(n_iters):
        g = compute_grad_weighted(a, w)
        a_new = a - lr * g
        a_new = proj_simplex(a_new)
        
        # Simple adaptive lr: if the objective increased, reduce lr
        # (skip for efficiency, just use fixed lr)
        a = a_new
    
    return a


def alternating_mirror_descent(a0, time_limit, T_start=1.0, T_end=0.01, n_outer=50, n_inner_qp=100):
    """
    Alternating method:
    1. Given a, compute w = softmax(conv(a,a)/T).
    2. Given w, solve QP: min sum_k w_k (a*a)[k] s.t. a in simplex.
    3. Decrease T.
    """
    n = len(a0)
    a = a0.copy()
    t0 = time.monotonic()
    best_a = a.copy()
    best_score = 2.0 * n * fast_convolve(a).max()
    
    for outer in range(n_outer):
        if time.monotonic() - t0 > time_limit:
            break
        
        # Temperature schedule (geometric)
        T = T_start * (T_end / T_start) ** (outer / max(1, n_outer - 1))
        
        # Step 1: Compute w from current a
        b = fast_convolve(a)
        w = softmax_weights(b, T)
        
        # Step 2: Solve QP for a given w
        a_qp = projected_gradient_qp(a, w, n_iters=n_inner_qp)
        
        # Evaluate
        score = 2.0 * n * fast_convolve(a_qp).max()
        if score < best_score:
            best_score = score
            best_a = a_qp.copy()
        
        a = a_qp
        
        if outer % 10 == 0:
            elapsed = time.monotonic() - t0
            print(f"    AMD: outer={outer}, T={T:.4f}, score={best_score:.8f}, time={elapsed:.1f}s")
    
    return best_a, best_score


def nesterov_smoothed(a0, time_limit, T_stages=None, maxiter_per_stage=5000):
    """Nesterov-accelerated gradient descent on the LogSumExp-smoothed objective."""
    n = len(a0)
    z = np.log(np.maximum(a0, 1e-300))  # Work in log-domain
    t0 = time.monotonic()
    
    if T_stages is None:
        T_stages = [10.0, 5.0, 2.0, 1.0, 0.5, 0.2, 0.1, 0.05, 0.02]
    
    n_stages = len(T_stages)
    iters_per_stage = max(20, maxiter_per_stage // n_stages)
    
    for T in T_stages:
        if time.monotonic() - t0 > time_limit:
            break
        remaining = time_limit - (time.monotonic() - t0)
        if remaining < 2:
            break
        
        def func(z):
            a = np.exp(z - z.max())
            a = a / a.sum()
            b = fast_convolve(a)
            b_max = b.max()
            return 2.0 * n * (b_max + (1.0/T) * np.log(np.exp((b - b_max)).sum()))
        
        def jac(z):
            a = np.exp(z - z.max())
            a = a / a.sum()
            b = fast_convolve(a)
            b_max = b.max()
            w = np.exp(b - b_max)
            w = w / w.sum()
            grad_a = compute_grad_weighted(a, w)
            # Transform to z-space: d/dz_j = a_j * (d/da_j - sum_i d/da_i * a_i)
            S = np.dot(grad_a, a)
            return a * (grad_a - S)
        
        try:
            res = minimize(
                fun=func, x0=z, jac=jac, method='L-BFGS-B',
                options={'maxiter': iters_per_stage, 'ftol': 1e-18,
                         'gtol': 1e-14, 'maxfun': iters_per_stage * 200}
            )
            z = res.x
        except Exception:
            pass
    
    a = np.exp(z - z.max())
    return a / a.sum()


def structured_init(n, rng):
    """Generate structured initial sequences."""
    choice = rng.integers(0, 8)
    x = np.linspace(0, 1, n)
    if choice == 0:
        a = np.cos(np.pi * x / 2) ** 2
    elif choice == 1:
        a = np.sin(np.pi * x) ** 2
    elif choice == 2:
        a = np.exp(-4 * x * (1 - x))
    elif choice == 3:
        a = 0.5 + 0.3 * np.cos(2 * np.pi * 3 * x)
        a = np.maximum(a, 0)
    elif choice == 4:
        a = (1 - x) ** 1.5 + 0.1
    elif choice == 5:
        a = np.exp(-2 * (x - 0.3) ** 2) + 0.5 * np.exp(-2 * (x - 0.7) ** 2)
    elif choice == 6:
        # More aggressive shaping: raised cosine
        a = 0.5 * (1 + np.cos(2 * np.pi * x))
    else:
        # Water-drop shaped
        a = 1.0 - 0.5 * np.abs(2*x - 1)**0.5
        a = np.maximum(a, 0)
    
    a = np.maximum(a, 0)
    s = a.sum()
    if s < 1e-15:
        return np.ones(n) / n
    return a / s


def evaluate_local(a):
    """Fast local evaluation."""
    a = np.maximum(np.asarray(a, dtype=np.float64), 0)
    s = a.sum()
    if s < 0.01:
        return float('inf')
    n = len(a)
    b = fast_convolve(a)
    return float(2.0 * n * b.max() / (s * s))


def interpolate_sequence(f, new_n):
    """Interpolate sequence to new length."""
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    s = f.sum()
    if s < 1e-15:
        return np.ones(new_n) / new_n
    f_norm = f / s
    old_x = np.linspace(0, 1, old_n)
    new_x = np.linspace(0, 1, new_n)
    f_interp = np.interp(new_x, old_x, f_norm)
    f_interp = np.maximum(f_interp, 0)
    ss = f_interp.sum()
    if ss > 1e-15:
        f_interp = f_interp / ss
    return f_interp
