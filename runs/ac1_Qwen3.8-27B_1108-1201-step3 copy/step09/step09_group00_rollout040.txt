Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
1. Fast Nesterov LP with reduced constraints and adaptive restarts
2. Dual-ascent method for the minimax problem
3. Multi-stage L-BFGS with LogSumExp smoothing (aggressive temperature annealing)
4. Precise coordinate descent on peak-contributing elements
5. Basin-hopping perturbation for escaping local minima

import numpy as np
import cvxpy as cp
import time
from scipy.fft import rfft, irfft
from scipy.optimize import minimize, line_search

def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(np.asarray(a, dtype=np.float64), fft_size)
    return irfft(A * A, fft_size)[:size]

def build_conv_matrix_rows(a, rows):
    """Build rows of conv matrix: T[rows] @ b = convolve(a, b)[rows]."""
    n = len(a)
    T = np.zeros((len(rows), n))
    for idx, k in enumerate(rows):
        js = max(0, k - n + 1)
        je = min(n - 1, k)
        for j in range(js, je + 1):
            T[idx, j] = a[k - j]
    return T

def solve_lp_reduced(a_fixed, n_constraints, solver):
    """LP: min M s.t. conv(a,b)[k] <= M for top n_constraints k, sum(b)=1, b>=0."""
    n = len(a_fixed)
    b = fast_convolve(a_fixed)  # This is conv(a, a), but we need T @ b_var
    # Actually we need the convolution matrix T such that T @ b_var = conv(a_fixed, b_var)
    # T[k, j] = a_fixed[k - j] for valid j
    # To reduce, only use rows where conv is large
    
    # Find top positions
    conv_aa = fast_convolve(a_fixed)
    top_k = np.argsort(conv_aa)[::-1][:n_constraints]
    
    b_var = cp.Variable(n, nonneg=True)
    M_var = cp.Variable()
    T = build_conv_matrix_rows(a_fixed, top_k)
    constraints = [T @ b_var <= M_var, cp.sum(b_var) == 1]
    prob = cp.Problem(cp.Minimize(M_var), constraints)
    
    try:
        prob.solve(solver=solver)
        if prob.status in ('optimal', 'optimal_inaccurate'):
            b_val = np.asarray(b_var.value, dtype=np.float64)
            b_val = np.maximum(b_val, 0)
            s = b_val.sum()
            if s < 1e-15:
                return None
            return b_val / s
    except Exception:
        pass
    return None

def solve_lp_full(a_fixed, solver):
    """Full LP: min M s.t. conv(a,b)[k] <= M for all k, sum(b)=1, b>=0."""
    n = len(a_fixed)
    b_var = cp.Variable(n, nonneg=True)
    M_var = cp.Variable()
    size = 2 * n - 1
    T = np.zeros((size, n))
    for j in range(n):
        T[j:j+n, j] = a_fixed
    constraints = [T @ b_var <= M_var, cp.sum(b_var) == 1]
    prob = cp.Problem(cp.Minimize(M_var), constraints)
    
    try:
        prob.solve(solver=solver)
        if prob.status in ('optimal', 'optimal_inaccurate'):
            b_val = np.asarray(b_var.value, dtype=np.float64)
            b_val = np.maximum(b_val, 0)
            s = b_val.sum()
            if s < 1e-15:
                return None
            return b_val / s
    except Exception:
        pass
    
    # Try alternate solvers
    for alt in [cp.ECOS, cp.SCS, cp.CLARABEL, cp.PDLP]:
        if alt == solver:
            continue

- `T @ b_var` where T is the conv matrix (2n-1) x n
- The constraint is `T @ b_var <= M`

The matrix T is a "Toeplitz-like" matrix (actually a "reverse" or "anti-diagonal" structure). We can compute `T @ b` using FFT in O(n log n) instead of O(n^2). But cvxpy doesn't support this directly.

Alternative: use a first-order method (like projected subgradient) for the LP, which only requires matrix-vector products (which can be done with FFT).

**LP via Projected Subgradient (dual):**
The dual of the LP is:
```
max sum_k y[k]
s.t. A^T y <= 1 (where A is the conv matrix, so A^T y has components (A^T y)[i] = sum_k A[k,i] * y[k] = sum_k a[k-i] * y[k])
     y >= 0
```

We can solve this with projected gradient:
- Gradient of objective: `1` (all ones)
- Constraint: `A^T y <= 1`, `y >= 0`
- Projected gradient step: `y_new = max(0, y + lr * (1 - A^T y / max(A^T y)))` ... no, that's not right for inequality constraints.

Actually, for the dual:
```
max 1^T y
s.t. B^T y <= 1 (where B[k,i] = a[k-i])
     y >= 0
```

The Lagrangian is: `1^T y - λ^T (B^T y - 1) - μ^T y` where `λ >= 0, μ >= 0`.
`= sum_k y[k] (1 - (B^T λ)[k] - μ[k]) + sum_i λ[i]`

The dual function is finite only if `1 - (B^T λ)[k] - μ[k] <= 0` for all `k`, in which case it equals `sum_i λ[i]`.

So the dual of the dual (which is the primal back) is:
```
min sum_i λ[i]
s.t. (B^T λ)[k] + μ[k] >= 1 for all k
     λ >= 0, μ >= 0
```

**Coordinate Descent:**
At each step, pick a coordinate `j` and optimize `a_j` (given all other `a_i` fixed), subject to `a_j >= 0` and `sum(a) = 1` (which means we're optimizing over `a_j` with the constraint that the total sum remains 1, so we need to think about this differently).

Actually, it's easier to think of it this way: we're on the simplex, so changing `a_j` by `δ` means we need to compensate elsewhere. The simplest approach: change `a_j` to `a_j + δ` and compensate by scaling all other components: `a_i ← a_i * (1-δ) / (1-a_j)` for `i ≠ j` (to maintain sum=1). But this is complicated.

Simpler: use the "move mass from j to k" approach. Move `δ` from position `j` to position `k`:
`a_j ← a_j - δ, a_k ← a_k + δ` (with `0 <= δ <= a_j`).

The change in the convolution:
`Δb_m = -δ * a_{m-j} + δ * a_{m-k} = δ * (a_{m-k} - a_{m-j})`

We want to choose `δ` to minimize `max_m (b_m + Δb_m)`.

This is a 1D optimization problem! For a given pair `(j, k)`, we can find the optimal `δ` by bisection or by solving a small problem.

The constraint is: `b_m + δ * (a_{m-k} - a_{m-j}) <= M` for all `m`, where `M` is the current max.

We take `δ = min(δ_max, a_j)` and update.

def fast_convolve(a):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(np.asarray(a, dtype=np.float64), fft_size)
    return irfft(A * A, fft_size)[:size]

def eval_score(a):
    a = np.maximum(a, 0)
    s = a.sum()
    if s < 0.01:
        return float('inf')
    n = len(a)
    b = fast_convolve(a)
    return 2.0 * n * b.max() / (s * s)

def normalize(a):

def solve_lp(a_fixed, n_cons=None, solver=None):
    """LP: min M s.t. T @ b <= M, sum(b)=1, b>=0. Returns (b, M)."""
    if solver is None:

def lse_obj(z, n, T):
    a = softmax_from_z(z)
    b = fast_convolve(a)
    mb = b.max()
    return 2.0 * n * (mb + T * np.log(np.exp(b / T - mb / T).sum()))

def lse_grad(z, n, T):
    a = softmax_from_z(z)
    b = fast_convolve(a)
    mb = b.max()
    w = np.exp(b / T - mb / T)
    w = w / w.sum()
    h = np.correlate(w, a, mode='valid')
    c = np.dot(w, b)
    return 4.0 * n * a * (h - a * c)

def dual_fitting_check(a):
    """Check KKT conditions: find w on peaks s.t. h is constant on support."""
    n = len(a)
    b = fast_convolve(a)
    M = b.max()
    active = np.where(b >= M * 0.999)[0]
    
    # Try uniform w on active set
    w = np.zeros(2 * n - 1)
    w[active] = 1.0 / len(active)
    
    h = np.correlate(w, a, mode='valid')
    support = np.where(a > 1e-10)[0]
    
    if len(support) < 2:
        return h, support
    
    h_support = h[support]
    variation = h_support.max() - h_support.min()
    return h, support, variation

def interpolate_sequence(f, new_n):
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    s = f.sum()
    if s < 1e-15:
        return np.ones(new_n) / new_n
    f_norm = f / s
    old_x = np.linspace(0, 1, old_n)
    new_x = np.linspace(0, 1, new_n)
    f_interp = np.interp(new_x, old_x, f_norm)
    f_interp = np.maximum(f_interp, 0)
    ss = f_interp.sum()
    if ss > 1e-15:
        f_interp = f_interp / ss
    return f_interp
