And the objective function:

```python
def two_coord_eval(base, L, R, quad, c, t):
    """Evaluate max conv for given t (value of a[i])."""
    if t < 0: t = 0.0
    if t > c: t = c
    ct = c - t
    result = base + L * t + R * ct
    q2i, q2j, qij = quad
    if 0 <= q2i < len(base):
        result[q2i] += t * t
    if 0 <= q2j < len(base):
        result[q2j] += ct * ct
    if 0 <= qij < len(base):
        result[qij] += 2.0 * t * ct
    return np.max(result)
```

This is O(n) per evaluation. The minimize_scalar will call this ~30-50 times, so each 2-coord optimization is O(50n).
