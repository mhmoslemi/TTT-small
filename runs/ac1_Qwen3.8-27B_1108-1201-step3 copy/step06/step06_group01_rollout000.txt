So max is `1/n`, and score = `2 * n * (1/n) = 2`. ✓

So `max(conv(p,p)) < 1/n`! This means the peak of the auto-convolution is LESS than the value at the center for uniform. How is this possible?

The answer: the peak for our sequences is NOT at the center (k=n-1). It's at some other lag. The center value might be lower than 1/n, but some other lag has a higher value.

Let me reconsider. For a non-uniform sequence, `(p*p)_{n-1} = sum_j p_j * p_{n-1-j}`. This can be less than 1/n if the sequence is "anti-correlated" with its reversal (i.e., large values of p are at positions where p_{n-1-j} is small).

For example, if p is concentrated at the beginning: `p = (1, 0, 0, ..., 0)`, then `(p*p)_{n-1} = p_0 * p_{n-1} = 0`. But `(p*p)_0 = p_0^2 = 1`, so the peak is 1.

So the trade-off is: by making the sequence asymmetric (concentrated at one end), we reduce the center peak but increase the endpoint peaks.

The optimal sequence balances all peaks. The fact that we can get score < 2 means that the optimal strategy is to NOT be uniform, but to have a non-trivial shape that equalizes all the important peaks.

This makes sense! The problem is essentially: find a probability distribution on {0, ..., n-1} such that its auto-correlation is as "flat" as possible.

Now, a key question: what does the optimal sequence look like? Based on the signal processing literature, for the "minimum peak auto-correlation" problem with non-negative sequences, the optimal sequences tend to have a "U-shape" or "bathtub" shape - higher at the ends and lower in the middle. This is because:
- The center lag (k=n-1) involves products of `p_j` with `p_{n-1-j}`, which is like a "cross" product.
- Making the ends high and the middle low reduces this cross product.
- But the endpoint lags (k=0, k=2n-2) involve `p_0^2` and `p_{n-1}^2`, so we need to keep the ends from being too high.

The balance gives a U-shaped sequence where the peak auto-correlation is achieved at multiple lags simultaneously.

def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(a, fft_size)
    return irfft(A * A, fft_size)[:size]

def convolve_pair(a, b):
    """Linear cross-convolution via FFT."""
    n1, n2 = len(a), len(b)
    size = n1 + n2 - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(a, fft_size)
    B = rfft(b, fft_size)
    return irfft(A * B, fft_size)[:size]

def shift_matrix_vec(a, k):

def lbgfs_exact(a0, time_limit, T_init=10, T_min=1, maxiter=5000):

    """

    def log_space_from_a(a):
        return np.log(np.maximum(a, 1e-300))
    
    def a_from_log_space(z):

        a = np.exp(z_shifted)
        return a / a.sum()
    
    def objective(z, T):

        r = fast_convolve(a)
        # Soft max approximation of max
        r_shifted = r / T
        log_sum_exp = r_shifted.max() + np.log(np.exp(r_shifted - r_shifted.max()).sum())
        return 2.0 * n * T * log_sum_exp
    
    def gradient(z, T):
        a = a_from_log_space(z)
        r = fast_convolve(a)
        # Softmax weights
        r_shifted = r / T
        w = np.exp(r_shifted - r_shifted.max())
        w /= w.sum()
        # Gradient of soft max w.r.t. a
        grad_a = np.zeros(n)
        for idx in np.where(w > 1e-10)[0]:
            k = int(idx)
            wi = w[k]
            for j in range(n):
                j2 = k - j

        # grad_z = a * (grad_a - a * sum(grad_a * a))
        S = np.dot(grad_a, a)
        grad_z = a * (grad_a - a * S)
        return 2.0 * n * grad_z
    
    z0 = log_space_from_a(a0)
    t0 = time.monotonic()
    best_a = a0.copy()

def interpolate_sequence(f, new_n):
    """Interpolate a sequence to a new length."""
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    s = f.sum()
    if s < 1e-15:
        return np.ones(new_n) / new_n
    f_norm = f / s
    old_x = np.linspace(0, 1, old_n)
    new_x = np.linspace(0, 1, new_n)
    f_interp = np.interp(new_x, old_x, f_norm)
    f_interp = np.maximum(f_interp, 0)
    ss = f_interp.sum()
    if ss > 1e-15:
        f_interp = f_interp / ss
    return f_interp
