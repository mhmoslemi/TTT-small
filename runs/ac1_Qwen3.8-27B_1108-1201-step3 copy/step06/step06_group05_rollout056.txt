One more consideration: the "away step" in FW. For the simplex, the away step means we can increase some coordinates and decrease others (potentially setting some to zero). This can speed up convergence significantly.

The away-step FW algorithm:
1. Maintain f = (1-α) * f_old + α * g (standard FW step)
   But also consider: f_new = (1-α) * f + α * g - β * (some coordinate)
   where β is chosen to make some coordinate zero.

Actually, the standard away-step FW for the simplex works as follows:
- The current point f is in the simplex
- We find the FW direction g (vertex of the simplex that minimizes <∇f, v>)
  Wait, for our problem, the feasible set is the simplex {f >= 0, sum(f) = 1}, and the vertices are e_0, ..., e_{n-1}.
  
  The FW direction is the vertex that minimizes the linear approximation of the objective.
  But we're using the LP to find the direction, which is actually solving the "best response" problem, not just picking a vertex.
  
  Hmm, this is a bit different from standard FW. In standard FW for the simplex:
  - The direction is a vertex e_j (the one that most decreases the linear approximation)
  - The LP we're solving is more general: it finds the best direction in the entire feasible set {g >= 0, (f*g)_k <= M}
  
  So our approach is actually a "generalized FW" where the direction is not a vertex but an arbitrary point in a different feasible set. This is sometimes called the "conditional gradient method" or "Frank-Wolfe" in a more general sense.

  For this generalized version, the away-step doesn't directly apply in the standard way. But we can still use a "barycentric FW" where we represent f as a combination of previously chosen directions and allow away-steps from bad directions.

This is NOT the same as the standard FW linear minimization oracle. In standard FW, we minimize <∇J(f), g> over g in the feasible set. Here, we're maximizing sum(g) subject to (f*g)_k <= M.

The connection is: if we think of the problem as
minimize M
s.t. (f*f)_k <= M for all k
     f >= 0, sum(f) = 1

Then at a given f with M = max(f*f), the "best response" in g would be the g that most reduces M. The LP we're solving finds the g that is "most compatible" with the constraint (f*g)_k <= M, i.e., the g that keeps the convolution bounded while having the largest sum.

This is actually a valid (and good) direction for reducing the peak. If g = f (i.e., f is a fixed point), then we're at a local optimum.

"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using LP-based Frank-Wolfe with
precise parabolic line search, p-norm smoothed gradient descent, and
multi-length exploration.

Key improvements over previous approach:
1. LP-FW uses exact M (no relaxation factor)
2. Parabolic line search for higher precision
3. p-norm (p=2,4,8) smoothed gradients for stable optimization
4. Multi-length search (512, 768, 1024)
5. Strategic perturbation restarts
6. Spectral flatness-based initialization
"""

import numpy as np
from scipy.optimize import linprog
import time


def fast_convolve(a):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]


def obj_value(a):
    """Compute 2*n*max(conv(a,a))/(sum(a))^2."""
    a = np.asarray(a, dtype=np.float64)
    s = a.sum()
    if s < 1e-10:
        return np.inf
    a = a / s
    c = fast_convolve(a)
    return 2.0 * len(a) * c.max()


def project_simplex(v):
    n = len(v)
    if n == 1:
        return np.array([max(v[0], 0.0)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)


def solve_fw_lp(f, M, n):
    """Solve: max sum(g) s.t. (f*g)[k] <= M, g >= 0."""
    c_obj = -np.ones(n)
    A_ub = np.zeros((2 * n - 1, n))
    for j in range(n):
        A_ub[j:j + n, j] = f
    b_ub = np.full(2 * n - 1, M)
    bounds = [(0, None)] * n
    res = linprog(c_obj, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')
    if res.success:
        return res.x
    return None


def parabolic_line_search(f, g, n):
    """
    Find optimal alpha in [0,1] for f_new = (1-alpha)*f + alpha*g
    that minimizes max(f_new * f_new). Uses parabolic interpolation.
    """
    def phi(alpha):
        ft = (1.0 - alpha) * f + alpha * g
        ft = np.maximum(ft, 0.0)
        s = ft.sum()
        if s < 1e-15:
            return np.inf
        ft = ft / s
        return fast_convolve(ft).max()
    
    # Initial evaluations
    a0, a1, a2 = 0.0, 0.5, 1.0
    f0, f1, f2 = phi(a0), phi(a1), phi(a2)
    
    best_a = a0 if f0 < f1 and f0 < f2 else (a1 if f1 < f2 else a2)
    best_f = min(f0, f1, f2)
    
    # Parabolic interpolation (Brent-like)
    for _ in range(40):
        if a1 < a0:
            a0, a1 = a1, a0
            f0, f1 = f1, f0
        if a2 < a1:
            a1, a2 = a2, a1
            f1, f2 = f2, f1
        
        # Fit parabola through (a0,f0), (a1,f1), (a2,f2)
        denom = (a0 - a1) * (a0 - a2) * (a1 - a2)
        if abs(denom) < 1e-30:
            break
        num = f0 * (a1 - a2) * (a0 - a2) + f1 * (a0 - a1) * (a1 - a2) + f2 * (a0 - a2) * (a0 - a1)
        # Actually, let me use the standard formula
        # The vertex of the parabola through (x0,y0), (x1,y1), (x2,y2) is:
        # xv = x1 - 0.5 * ((x1-x0)²(y1-y2) - (x1-x2)²(y1-y0)) / ((x1-x0)(y1-y2) - (x1-x2)(y1-y0))
        
        d1 = a1 - a0
        d2 = a1 - a2
        if abs(d1 * (f1 - f2) - d2 * (f1 - f0)) < 1e-30:
            break
        xv = a1 - 0.5 * (d1 * d1 * (f1 - f2) - d2 * d2 * (f1 - f0)) / (d1 * (f1 - f2) - d2 * (f1 - f0))
        
        if not (a0 < xv < a2) or not np.isfinite(xv):
            break
        
        fx = phi(xv)
        
        if fx < best_f:
            best_f = fx
            best_a = xv
        
        if fx < f1:
            # New minimum is at xv
            if xv < a1:
                a2 = a1
                f2 = f1
            else:
                a0 = a1
                f0 = f1
            a1 = xv
            f1 = fx
        else:
            if xv < a1:
                a0 = xv
                f0 = fx
            else:
                a2 = xv
                f2 = fx
    
    return best_a, best_f


def pnorm_gradient(f, c, p):
    """Compute gradient of (1/p)*sum(c_k^p) where c = f*f."""
    n = len(f)
    if p <= 1 or c.max() < 1e-30:
        w = np.ones(len(c)) / len(c)
    else:
        max_c = c.max()
        c_norm = c / max_c
        w = (c_norm ** (p - 1)) * (max_c ** (p - 1))
        w = w / w.sum()
    
    # Gradient: g_j = 2 * sum_i f_i * w_{j+i} (appropriate indexing)
    # Using FFT-based correlation
    w_rev = w[::-1].copy()
    conv_len = n + len(w_rev) - 1
    fft_size = 1 << (conv_len - 1).bit_length()
    F = np.fft.rfft(f, fft_size)
    W = np.fft.rfft(w_rev, fft_size)
    conv = np.fft.irfft(F * W, fft_size)[:conv_len]
    indices = np.arange(2 * n - 2, 2 * n - 2 - n, -1)
    g = 2.0 * conv[indices]
    return g


def pnorm_gradient_descent(f0, time_limit, p_schedule=None):
    """
    Gradient descent on the p-norm smoothed objective.
    """
    if p_schedule is None:
        p_schedule = [2, 4, 8, 16, 32, 64]
    
    f = np.maximum(f0.astype(np.float64), 0.0)
    s = f.sum()
    f = f / s
    n = len(f)
    
    c = fast_convolve(f)
    best_obj = c.max()
    best_f = f.copy()
    
    t0 = time.monotonic()
    momentum = np.zeros(n)
    mu = 0.7
    
    for p in p_schedule:
        if time.monotonic() - t0 > time_limit * 0.85:
            break
        
        lr = 0.1 / (n ** 0.5)
        stage_start = time.monotonic()
        stage_time = time_limit / len(p_schedule) * 0.85
        no_improve = 0
        it = 0
        
        while time.monotonic() - stage_start < stage_time and time.monotonic() - t0 < time_limit * 0.85:
            it += 1
            c = fast_convolve(f)
            
            # p-norm objective value (for monitoring)
            max_c = c.max()
            if max_c < 1e-30:
                break
            obj_p = np.sum(c ** p) / (p * max_c ** (p - 1))
            
            g = pnorm_gradient(f, c, p)
            g_norm = np.linalg.norm(g)
            if g_norm < 1e-15:
                break
            
            # Backtracking line search
            step = lr / g_norm
            found = False
            for _ in range(20):
                momentum = mu * momentum - step * g
                f_trial = project_simplex(f + momentum)
                c_trial = fast_convolve(f_trial)
                if c_trial.max() <= c.max() + 1e-12:
                    found = True
                    break
                step *= 0.5
            
            if found:
                f = f_trial
                if c_trial.max() < best_obj - 1e-13:
                    best_obj = c_trial.max()
                    best_f = f.copy()
                    no_improve = 0
                else:
                    no_improve += 1
                lr = min(lr * 1.02, 1.0 / (n ** 0.3))
            else:
                no_improve += 1
                lr *= 0.8
                momentum = np.zeros(n)
            
            if no_improve > 50:
                rng = np.random.default_rng(hash((it, p)) & 0xFFFFFFFF)
                noise = rng.standard_normal(n) * 0.003
                f = project_simplex(best_f + noise)
                momentum = np.zeros(n)
                lr = 0.05 / (n ** 0.5)
                no_improve = 0
        
        if it % 50 == 0:
            print(f"    PD p={p}: it={it}, max_c={c.max():.10f}, best={best_obj:.10f}")
    
    return best_f, best_obj


def lp_fw_optimize(f0, time_limit, verbose=False):
    """
    LP-based Frank-Wolfe with exact M and parabolic line search.
    """
    f = np.maximum(f0.astype(np.float64), 0.0)
    s = f.sum()
    f = f / s
    n = len(f)
    
    c = fast_convolve(f)
    M = c.max()
    best_obj = M
    best_f = f.copy()
    
    t0 = time.monotonic()
    no_improve = 0
    it = 0
    
    while time.monotonic() - t0 < time_limit:
        it += 1
        
        # Solve LP with exact M
        g = solve_fw_lp(f, M, n)
        if g is None:
            # Try with slightly relaxed M
            g = solve_fw_lp(f, M * 1.001, n)
            if g is None:
                break
        
        g_sum = g.sum()
        if g_sum < 1e-15:
            break
        g = g / g_sum
        
        # Check convergence
        diff = np.max(np.abs(g - f))
        if diff < 1e-12:
            no_improve += 1
            if no_improve > 200:
                break
            continue
        elif diff < 1e-8:
            no_improve += 1
        else:
            no_improve = 0
        
        # Parabolic line search
        alpha, val = parabolic_line_search(f, g, n)
        
        if alpha > 1e-10 and val < M - 1e-14:
            f_new = (1.0 - alpha) * f + alpha * g
            f_new = np.maximum(f_new, 0.0)
            f_new = f_new / f_new.sum()
            f = f_new
            c = fast_convolve(f)
            M = c.max()
            
            if M < best_obj - 1e-14:
                best_obj = M
                best_f = f.copy()
                if verbose and it % 50 == 0:
                    print(f"    LP-FW iter {it}: obj={best_obj:.12f}")
        else:
            # No improvement possible in this direction
            no_improve += 2
        
        # Periodic perturbation to escape local optima
        if no_improve > 100 and it % 100 == 0:
            rng = np.random.default_rng(it * 7 + 3)
            noise = rng.standard_normal(n) * 0.001
            f = project_simplex(best_f + noise)
            c = fast_convolve(f)
            M = c.max()
            no_improve = 0
        
        if it % 200 == 0 and verbose:
            print(f"    LP-FW iter {it}: M={M:.10f}, best={best_obj:.10f}, no_improv={no_improve}")
    
    return best_f, best_obj


def make_hann(n):
    """Hann window (raised cosine)."""
    x = np.arange(n)
    a = 0.5 * (1 + np.cos(2 * np.pi * x / n))
    a = np.maximum(a, 0)
    s = a.sum()
    if s > 1e-15:
        a /= s
    return a


def make_parabola(n):
    """Parabolic (quadratic) shape."""
    x = np.arange(n) - (n - 1) / 2.0
    a = 1.0 - (x / (n / 2.0)) ** 2
    a = np.maximum(a, 0)
    s = a.sum()
    if s > 1e-15:
        a /= s
    return a


def make_super_gaussian(n, p=3):
    """Super-Gaussian: exp(-|x|^p)."""
    x = np.arange(n) - (n - 1) / 2.0
    x = x / (n / 3.0)
    a = np.exp(-np.abs(x) ** p)
    a = np.maximum(a, 0)
    s = a.sum()
    if s > 1e-15:
        a /= s
    return a


def interpolate_seq(f, new_n):
    """Interpolate sequence to new length."""
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    old_x = np.linspace(0, 1, old_n)
    new_x = np.linspace(0, 1, new_n)
    f_new = np.interp(new_x, old_x, f)
    f_new = np.maximum(f_new, 0)
    s = f_new.sum()
    if s > 1e-15:
        f_new /= s
    return f_new


def spectral_flatness_init(n, iters=200):
    """
    Initialize by minimizing spectral variance (encourages flat auto-correlation).
    Uses gradient descent on the variance of the convolution.
    """
    # Start with Hann window
    f = make_hann(n).copy()
    t0 = time.monotonic()
    lr = 0.01
    
    for it in range(iters):
        c = fast_convolve(f)
        mean_c = c.mean()
        # Gradient of sum((c_k - mean)^2) w.r.t. f
        # d/d f_j [sum_k (c_k - mean)^2] = 2 * sum_k (c_k - mean) * d c_k / d f_j
        # d c_k / d f_j = f_k - j (for valid indices)... 
        # Actually dc_k/df_j = f_{k-j} + f_{k-j} = 2*f_{k-j} (symmetric)
        # Wait: c_k = sum_i f_i * f_{k-i}, so dc_k/df_j = f_{k-j} (if 0 <= k-j < n) + f_{j-k} (if 0 <= j-k < n... but that's the same term when we sum over all i)
        # Actually: c_k = sum_{i: 0<=i<n, 0<=k-i<n} f_i * f_{k-i}
        # dc_k/df_j = f_{k-j} (if 0 <= k-j < n) [from the i=j term] 
        #              + (terms where k-i = j, i.e., i = k-j) → same thing
        # Wait, I need to be more careful.
        # c_k = sum_{i=max(0,k-n+1)}^{min(n-1,k)} f_i * f_{k-i}
        # dc_k/df_j = f_{k-j} [if 0 <= k-j < n and j is in the range]
        #            + f_{j-(k-j)}... no.
        # Let me just use: dc_k/df_j = f_{|k-j|} if |k-j| < n... no.
        # c_k = sum_i f_i f_{k-i}
        # dc_k/df_j: the term f_j appears when i=j (giving f_{k-j}) or when k-i=j (giving i=k-j, so f_{k-j} again)
        # If j != k-j (i.e., 2j != k), then dc_k/df_j = f_{k-j} + f_{k-j} = 2*f_{k-j}
        # If j == k-j (i.e., 2j == k), then dc_k/df_j = 2*f_j (since it's the square)
        # Actually: c_k = sum_i f_i * f_{k-i}
        # d/d f_j: derivative of f_i * f_{k-i} w.r.t. f_j is:
        #   if i = j: f_{k-j}
        #   if k-i = j (i.e., i = k-j): f_i = f_{k-j}
        #   If j = k-j (j = k/2): both terms give f_j, so total = 2*f_j
        #   Otherwise: total = f_{k-j} + f_{k-j} = 2*f_{k-j}
        # So dc_k/df_j = 2 * f_{k-j} (when 0 <= k-j < n)
        # (The factor of 2 accounts for both appearances)
        
        # Using FFT: the gradient is 2 * correlate(c_dev, f) where c_dev = c - mean
        # Actually: grad_j = 2 * sum_k (c_k - mean) * (dc_k/df_j) / 2
        #           = 2 * sum_k (c_k - mean) * f_{k-j}
        # This is a correlation: grad = 2 * correlate(c_dev, f)
        
        c_dev = c - mean_c
        # correlate(c_dev, f)_j = sum_k c_dev_k * f_{k-j}
        # Using FFT: this is the same as the gradient computation we did before
        c_dev_rev = c_dev[::-1].copy()
        conv_len = n + len(c_dev_rev) - 1
        fft_size = 1 << (conv_len - 1).bit_length()
        F = np.fft.rfft(f, fft_size)
        C = np.fft.rfft(c_dev_rev, fft_size)
        conv = np.fft.irfft(F * C, fft_size)[:conv_len]
        indices = np.arange(2 * n - 2, 2 * n - 2 - n, -1)
        grad = 2.0 * conv[indices]
        
        f_new = project_simplex(f - lr * grad)
        f = f_new
        
        if it % 50 == 0:
            c = fast_convolve(f)
            print(f"    Spectral init iter {it}: max={c.max():.8f}, var={c.var():.10f}")
        
        if time.monotonic() - t0 > 10:
            break
    
    return f

"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using LP-based Frank-Wolfe with
exact constraint M, parabolic line search, p-norm smoothed gradient descent,
and multi-length exploration.

Key improvements:
1. LP-FW uses exact M (no relaxation) for optimal FW directions
2. Parabolic (Brent-like) line search for high-precision step selection
3. Extended line search (alpha up to 2) for superlinear progress
4. p-norm (p=2,4,8,16) smoothed gradient descent for basin finding
5. Multi-length search with interpolation
6. Strategic perturbation restarts for escaping local optima
7. Coordinate descent polish for final precision
"""

import numpy as np
from scipy.optimize import linprog
import time


def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]


def project_simplex(v):
    """Euclidean projection onto the probability simplex."""
    n = len(v)
    if n == 1:
        return np.array([max(v[0], 0.0)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)


def solve_fw_lp(f, M, n):
    """Solve: max sum(g) s.t. (f*g)[k] <= M for all k, g >= 0."""
    c_obj = -np.ones(n)
    A_ub = np.zeros((2 * n - 1, n))
    for j in range(n):
        A_ub[j:j + n, j] = f
    b_ub = np.full(2 * n - 1, M)
    bounds = [(0, None)] * n
    res = linprog(c_obj, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')
    if res.success:
        return res.x
    return None


def phi_conv(f, g, alpha):
    """Evaluate max convolution of (1-alpha)*f + alpha*g (normalized)."""
    ft = (1.0 - alpha) * f + alpha * g
    ft = np.maximum(ft, 0.0)
    s = ft.sum()
    if s < 1e-15:
        return np.inf
    ft = ft / s
    return fast_convolve(ft).max()


def precise_line_search(f, g, n, alpha_max=1.5):
    """
    Parabolic line search for optimal alpha in [0, alpha_max].
    Minimizes max((1-alpha)*f + alpha*g)^2 convolution.
    """
    # Coarse grid to find approximate minimum
    grid = np.linspace(0.0, alpha_max, 16)
    vals = np.array([phi_conv(f, g, a) for a in grid])
    
    # Find best grid point
    idx = np.argmin(vals)
    best_a = grid[idx]
    best_f = vals[idx]
    
    # Refined search via parabolic interpolation
    a0 = grid[max(0, idx - 1)]
    a1 = grid[idx]
    a2 = grid[min(len(grid) - 1, idx + 1)]
    f0, f1, f2 = vals[max(0, idx - 1)], vals[idx], vals[min(len(grid) - 1, idx + 1)]
    
    for _ in range(35):
        # Ensure ordering a0 < a1 < a2
        if a0 > a1:
            a0, a1 = a1, a0
            f0, f1 = f1, f0
        if a1 > a2:
            a1, a2 = a2, a1
            f1, f2 = f2, f1
        
        # Parabolic vertex
        d1 = a1 - a0
        d2 = a1 - a2
        denom = d1 * (f1 - f2) - d2 * (f1 - f0)
        if abs(denom) < 1e-30:
            break
        xv = a1 - 0.5 * (d1 * d1 * (f1 - f2) - d2 * d2 * (f1 - f0)) / denom
        
        if not (a0 < xv < a2) or not np.isfinite(xv):
            break
        
        fx = phi_conv(f, g, xv)
        
        if fx < best_f:
            best_f = fx
            best_a = xv
        
        if fx < f1:
            if xv < a1:
                a2, f2 = a1, f1
            else:
                a0, f0 = a1, f1
            a1, f1 = xv, fx
        else:
            if xv < a1:
                a0, f0 = xv, fx
            else:
                a2, f2 = xv, fx
    
    return best_a, best_f


def pnorm_gradient(f, c, p):
    """Compute gradient of (1/p)*sum(c_k^p) where c = f*f (normalized)."""
    n = len(f)
    max_c = c.max()
    if max_c < 1e-30:
        return np.zeros(n)
    if p <= 1:
        w = np.ones(len(c))
    else:
        c_norm = c / max_c
        w = c_norm ** (p - 1)
    w = w / w.sum()
    
    # g_j = 2 * sum_i f_i * w_{j+i} via FFT correlation
    w_rev = w[::-1].copy()
    conv_len = n + len(w_rev) - 1
    fft_size = 1 << (conv_len - 1).bit_length()
    F = np.fft.rfft(f, fft_size)
    W = np.fft.rfft(w_rev, fft_size)
    conv = np.fft.irfft(F * W, fft_size)[:conv_len]
    indices = np.arange(2 * n - 2, 2 * n - 2 - n, -1)
    g = 2.0 * conv[indices]
    return g


def pnorm_gd(f0, time_limit, verbose=False):
    """
    p-norm smoothed gradient descent with adaptive stepping.
    Progresses through p values from smooth to sharp.
    """
    f = np.maximum(f0.astype(np.float64), 0.0)
    s = f.sum()
    f = f / s
    n = len(f)
    
    c = fast_convolve(f)
    best_obj = c.max()
    best_f = f.copy()
    
    t0 = time.monotonic()
    p_schedule = [2, 4, 8, 16, 32, 64]
    momentum = np.zeros(n)
    mu = 0.6
    
    for pi, p in enumerate(p_schedule):
        if time.monotonic() - t0 > time_limit * 0.9:
            break
        
        lr = 0.5 / np.sqrt(n)
        stage_start = time.monotonic()
        stage_time = time_limit * 0.9 / len(p_schedule)
        no_improve = 0
        it = 0
        
        while time.monotonic() - stage_start < stage_time and time.monotonic() - t0 < time_limit * 0.9:
            it += 1
            c = fast_convolve(f)
            g = pnorm_gradient(f, c, p)
            g_norm = np.linalg.norm(g)
            if g_norm < 1e-15:
                break
            
            step = lr / (g_norm + 1e-10)
            accepted = False
            
            for _ in range(15):
                momentum = mu * momentum - step * g
                f_trial = project_simplex(f + momentum)
                c_trial = fast_convolve(f_trial)
                if c_trial.max() <= c.max() + 1e-12:
                    f = f_trial
                    accepted = True
                    break
                step *= 0.5
            
            if accepted:
                if c_trial.max() < best_obj - 1e-13:
                    best_obj = c_trial.max()
                    best_f = f.copy()
                    no_improve = 0
                else:
                    no_improve += 1
            else:
                no_improve += 1
                lr *= 0.8
                momentum = np.zeros(n)
            
            if no_improve > 40:
                rng = np.random.default_rng((it * 31 + pi * 7) & 0xFFFFFFFF)
                noise = rng.standard_normal(n) * (0.002 + 0.002 / (pi + 1))
                f = project_simplex(best_f + noise)
                momentum = np.zeros(n)
                lr = 0.3 / np.sqrt(n)
                no_improve = 0
        
        if verbose:
            print(f"    pnorm_gd p={p}: iters={it}, max_c={fast_convolve(f).max():.10f}, best={best_obj:.10f}")
    
    return best_f, best_obj


def lp_fw(f0, time_limit, verbose=False):
    """
    LP-based Frank-Wolfe with exact M and precise line search.
    This is the main optimization engine.
    """
    f = np.maximum(f0.astype(np.float64), 0.0)
    s = f.sum()
    f = f / s
    n = len(f)
    
    c = fast_convolve(f)
    M = c.max()
    best_obj = M
    best_f = f.copy()
    
    t0 = time.monotonic()
    no_improve = 0
    it = 0
    
    while time.monotonic() - t0 < time_limit:
        it += 1
        
        # Solve LP with EXACT M
        g = solve_fw_lp(f, M, n)
        if g is None:
            # Small relaxation if infeasible (shouldn't happen)
            g = solve_fw_lp(f, M * 1.0001, n)
            if g is None:
                break
        
        g_sum = g.sum()
        if g_sum < 1e-15:
            break
        g = g / g_sum
        
        # Convergence check
        diff = np.max(np.abs(g - f))
        if diff < 1e-11:
            no_improve += 1
            if no_improve > 300:
                break
            continue
        elif diff < 1e-8:
            no_improve += 1
        else:
            no_improve = 0
        
        # Line search with extended range
        if no_improve > 50:
            alpha_max = 1.0
        else:
            alpha_max = 1.3
        
        alpha, val = precise_line_search(f, g, n, alpha_max)
        
        if alpha > 1e-10 and val < M - 1e-14:
            f_new = (1.0 - alpha) * f + alpha * g
            f_new = np.maximum(f_new, 0.0)
            f_new = f_new / f_new.sum()
            f = f_new
            c = fast_convolve(f)
            M = c.max()
            
            if M < best_obj - 1e-14:
                best_obj = M
                best_f = f.copy()
                if verbose and it % 100 == 0:
                    print(f"    LP-FW iter {it}: obj={best_obj:.12f}")
        else:
            no_improve += 3
        
        # Perturbation to escape local optima
        if no_improve > 80 and it % 50 == 0:
            rng = np.random.default_rng((it * 13 + 7) & 0xFFFFFFFF)
            scale = 0.001 + 0.002 * min(no_improve / 200.0, 1.0)
            noise = rng.standard_normal(n) * scale
            f = project_simplex(best_f + noise)
            c = fast_convolve(f)
            M = c.max()
            no_improve = 0
        
        if verbose and it % 500 == 0:
            print(f"    LP-FW iter {it}: M={M:.10f}, best={best_obj:.10f}, no_improv={no_improve}")
    
    return best_f, best_obj


def coord_descent(f0, time_limit, verbose=False):
    """
    Coordinate descent: adjust individual coordinates to reduce max convolution.
    On the simplex, changing f[j] requires rescaling others.
    """
    f = np.maximum(f0.astype(np.float64), 0.0)
    s = f.sum()
    f = f / s
    n = len(f)
    
    best_f = f.copy()
    best_obj = fast_convolve(f).max()
    t0 = time.monotonic()
    
    multis = [0.5, 0.65, 0.8, 0.9, 1.1, 1.3, 1.6]
    
    while time.monotonic() - t0 < time_limit:
        improved = False
        
        for j in range(n):
            if time.monotonic() - t0 > time_limit:
                break
            
            old_val = f[j]
            if old_val < 1e-12 or old_val > 0.5:
                continue
            
            best_j_obj = best_obj
            best_j_mult = 1.0
            
            for mult in multis:
                new_val = old_val * mult
                if new_val < 0 or new_val > 0.4:
                    continue
                denom = 1.0 - old_val
                if denom < 1e-10:
                    continue
                scale = (1.0 - new_val) / denom
                f_trial = f.copy()
                f_trial[j] = new_val
                mask = np.ones(n, dtype=bool)
                mask[j] = False
                f_trial[mask] *= scale
                f_trial = np.maximum(f_trial, 0.0)
                ss = f_trial.sum()
                if ss < 1e-15:
                    continue
                f_trial = f_trial / ss
                
                val = fast_convolve(f_trial).max()
                if val < best_j_obj - 1e-15:
                    best_j_obj = val
                    best_j_mult = mult
            
            if best_j_mult != 1.0:
                new_val = old_val * best_j_mult
                denom = 1.0 - old_val
                if denom > 1e-10:
                    scale = (1.0 - new_val) / denom
                    f[j] = new_val
                    mask = np.ones(n, dtype=bool)
                    mask[j] = False
                    f[mask] *= scale
                    f = np.maximum(f, 0.0)
                    f = f / f.sum()
                if best_j_obj < best_obj - 1e-15:
                    best_obj = best_j_obj
                    best_f = f.copy()
                    improved = True
        
        if not improved:
            break
    
    if verbose:
        print(f"    Coord descent done: best={best_obj:.12f}")
    return best_f, best_obj


def make_hann(n):
    """Hann window."""
    x = np.arange(n)
    a = 0.5 * (1.0 + np.cos(2.0 * np.pi * x / n))
    a = np.maximum(a, 0.0)
    s = a.sum()
    if s > 1e-15:
        a /= s
    return a


def make_parabola(n):
    """Parabolic shape."""
    x = np.arange(n) - (n - 1) / 2.0
    a = 1.0 - (x / (n * 0.55)) ** 2
    a = np.maximum(a, 0.0)
    s = a.sum()
    if s > 1e-15:
        a /= s
    return a


def make_super_gauss(n, p=3.0):
    """Super-Gaussian."""
    x = np.arange(n) - (n - 1) / 2.0
    x = x / (n * 0.3)
    a = np.exp(-np.abs(x) ** p)
    a = np.maximum(a, 0.0)
    s = a.sum()
    if s > 1e-15:
        a /= s
    return a


def interpolate_seq(f, new_n):
    """Interpolate to new length with slight smoothing."""
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    old_x = np.linspace(0, 1, old_n)
    new_x = np.linspace(0, 1, new_n)
    f_new = np.interp(new_x, old_x, f)
    # Light smoothing
    kernel = np.array([0.15, 0.2, 0.3, 0.2, 0.15])
    f_smooth = np.convolve(f_new, kernel, mode='same')
    f_smooth = np.maximum(f_smooth, 0.0)
    s = f_smooth.sum()
    if s > 1e-15:
        f_smooth /= s
    return f_smooth


def try_and_track(a, best_seq_ref, best_score_ref, label):
    """Evaluate sequence and update best if improved. Returns (best_seq, best_score)."""
    a = np.asarray(a, dtype=np.float64)
    a = np.maximum(a, 0.0)
    s = a.sum()
    if s < 1e-10:
        return best_seq_ref, best_score_ref
    score = float(evaluate_sequence(a.tolist()))
    if np.isfinite(score) and score < best_score_ref:
        best_seq_ref = a.copy()
        best_score_ref = score
        print(f"  NEW BEST [{label}]: {score:.8f} (n={len(a)})")
    return best_seq_ref, best_score_ref


def propose_candidate(seed=42, budget_s=1800, **kwargs):
    """
    Multi-phase optimization:
    1. p-norm smoothed GD for basin finding
    2. LP-FW with exact M (main workhorse, ~60% of time)
    3. LP-FW restarts with perturbation
    4. Multi-length exploration
    5. Coordinate descent polish
    """
    rng = np.random.default_rng(seed)
    total_budget = max(1.0, float(budget_s))
    deadline = time.monotonic() + total_budget - 15.0
    
    best_seq = None
    best_score = float('inf')
    
    # Get parent sequence
    parent = None
    try:
        p = np.asarray(height_sequence_1, dtype=np.float64)
        p = np.clip(p, 0.0, 1000.0)
        if p.ndim == 1 and p.size > 0 and np.isfinite(p).all() and p.sum() > 1e-10:
            parent = p / p.sum()
            p_score = float(evaluate_sequence(parent.tolist()))
            print(f"Parent: n={len(parent)}, score={p_score:.8f}")
            if p_score < best_score:
                best_score = p_score
                best_seq = parent.copy()
    except Exception:
        pass
    
    if parent is None:
        parent = make_hann(768)
        best_seq = parent.copy()
        best_score = float(evaluate_sequence(parent.tolist()))
        print(f"Default init (Hann 768): score={best_score:.8f}")
    
    n_parent = len(parent)
    
    # === Phase 1: Quick p-norm GD (15% of budget) ===
    print("\n=== Phase 1: p-norm Gradient Descent ===")
    t1 = min(180, total_budget * 0.15)
    print(f"  Time: {t1:.0f}s, n={n_parent}")
    
    a_opt, _ = pnorm_gd(parent, time_limit=t1, verbose=True)
    best_seq, best_score = try_and_track(a_opt, best_seq, best_score, "pnorm_gd")
    
    # Also try different initializations
    for shape_name, shape_fn in [("hann", make_hann), ("parab", make_parabola), ("supergauss", make_super_gauss)]:
        a_init = shape_fn(n_parent)
        best_seq, best_score = try_and_track(a_init, best_seq, best_score, f"init_{shape_name}")
    
    print(f"  After Phase 1: best={best_score:.8f}")
    
    # === Phase 2: Main LP-FW (45% of budget) ===
    print("\n=== Phase 2: LP-FW Main ===")
    t2 = min(800, total_budget * 0.45)
    print(f"  Time: {t2:.0f}s, n={len(best_seq)}")
    
    a_opt, _ = lp_fw(best_seq, time_limit=t2, verbose=True)
    best_seq, best_score = try_and_track(a_opt, best_seq, best_score, "lpfw_main")
    print(f"  After Phase 2: best={best_score:.8f}")
    
    # === Phase 3: LP-FW restarts (20% of budget) ===
    print("\n=== Phase 3: LP-FW Restarts ===")
    t3_total = total_budget * 0.20
    n_restarts = 3
    t3_each = t3_total / n_restarts
    
    for r in range(n_restarts):
        rem = deadline - time.monotonic() - 60
        if rem < 30:
            break
        t3 = min(t3_each, rem)
        print(f"  Restart {r}: t={t3:.0f}s")
        
        if r == 0:
            f_init = best_seq.copy()
        elif r == 1:
            noise = rng.standard_normal(len(best_seq)) * 0.003
            f_init = project_simplex(best_seq + noise)
        else:
            hann = make_hann(len(best_seq))
            f_init = 0.85 * best_seq + 0.15 * hann
            f_init = f_init / f_init.sum()
        
        a_opt, _ = lp_fw(f_init, time_limit=t3)
        best_seq, best_score = try_and_track(a_opt, best_seq, best_score, f"lpfw_r{r}")
    
    print(f"  After Phase 3: best={best_score:.8f}")
    
    # === Phase 4: Multi-length exploration (15% of budget) ===
    print("\n=== Phase 4: Multi-Length ===")
    for target_n in [1024, 512, 1280]:
        rem = deadline - time.monotonic() - 40
        if rem < 50:
            break
        
        f_interp = interpolate_seq(best_seq, target_n)
        best_seq, best_score = try_and_track(f_interp, best_seq, best_score, f"interp_{target_n}")
        
        # Quick GD
        t_gd = min(rem * 0.15, 40)
        if t_gd > 15:
            a_opt, _ = pnorm_gd(f_interp, time_limit=t_gd)
            best_seq, best_score = try_and_track(a_opt, best_seq, best_score, f"gd_{target_n}")
        
        # LP-FW
        rem2 = deadline - time.monotonic() - 30
        if rem2 > 30:
            t_lpfw = min(rem2 * 0.6, 150)
            a_opt, _ = lp_fw(a_opt, time_limit=t_lpfw)
            best_seq, best_score = try_and_track(a_opt, best_seq, best_score, f"lpfw_{target_n}")
        
        # Coordinate polish
        rem3 = deadline - time.monotonic() - 20
        if rem3 > 15:
            a_opt, _ = coord_descent(best_seq, time_limit=min(rem3, 30))
            best_seq, best_score = try_and_track(a_opt, best_seq, best_score, f"coord_{target_n}")
    
    print(f"  After Phase 4: best={best_score:.8f}")
    
    # === Phase 5: Final squeeze (5% of budget) ===
    print("\n=== Phase 5: Final Polish ===")
    rem = deadline - time.monotonic() - 5
    if rem > 10:
        # One more LP-FW on the best
        t5 = min(rem * 0.6, 60)
        a_opt, _ = lp_fw(best_seq, time_limit=t5)
        best_seq, best_score = try_and_track(a_opt, best_seq, best_score, "final_lpfw")
        
        # Coordinate descent
        rem2 = deadline - time.monotonic() - 3
        if rem2 > 10:
            a_opt, _ = coord_descent(best_seq, time_limit=min(rem2, 30))
            best_seq, best_score = try_and_track(a_opt, best_seq, best_score, "final_coord")
    
    # Fallback
    if best_seq is None:
        best_seq = np.ones(384) / 384
        best_score = float(evaluate_sequence(best_seq.tolist()))
    
    # Final verification
    fs = float(evaluate_sequence(best_seq.tolist()))
    if np.isfinite(fs):
        best_score = fs
    
    print(f"\nFINAL SCORE: {best_score:.10f} (n={len(best_seq)})")
    return [float(x) for x in best_seq]
