- Term i=k-j: a[k-j]*a[j], derivative w.r.t. a[j] is a[k-j]

Total derivative: 2*a[k-j] (if j != k-j and 0<=k-j<n)
If j == k-j (i.e., 2j=k): only one term exists (i=j=k-j), which is a[j]*a[j]=a[j]^2, derivative is 2*a[j].

So the subgradient of conv[k] w.r.t. a[j] is:
- 2*a[k-j] if 0<=k-j<n and 2j != k
- 2*a[j] if 2j == k (which implies 0<=j<n)
- 0 otherwise

But since 2*a[j] = 2*a[k-j] when 2j=k, we can just write:
- 2*a[k-j] if 0<=k-j<n
- 0 otherwise

Let me verify: a=[a0,a1,a2,a3], k=2, j=1:
2*a[k-j] = 2*a[1] = 2*a1. ✓ (matches my earlier calculation)

k=2, j=0: 2*a[2] = 2*a2. ✓
k=2, j=2: 2*a[0] = 2*a0. ✓
k=2, j=3: k-j = -1, invalid. 0. ✓

k=1, j=0: 2*a[1] = 2*a1. 
conv[1] = a0*a1 + a1*a0 = 2*a0*a1. d/d(a0) = 2*a1. ✓

k=0, j=0: 2*a[0] = 2*a0.
conv[0] = a0*a0 = a0^2. d/d(a0) = 2*a0. ✓

So the subgradient is simply: `grad[j] = 2*a[k-j] if 0 <= k-j < n else 0`.

This is great! It's very simple. The gradient of conv[k] w.r.t. a is just 2 * (a reversed and shifted by k positions).

Now, for the problem of minimizing max_k conv[k] (with normalization), the subgradient method would use:
a_new = a - lr * grad(a, k*) where k* = argmax conv[k]

But we also have the constraint sum(a) = constant (normalization). So we should project onto the constraint after each step, or use a Lagrangian approach.

Actually, since the objective is scale-invariant (we normalize), we can just minimize conv_max and normalize at the end. Or we can minimize the ratio directly.

Let me think about a more efficient approach. Since the subgradient is very simple (just a shifted version of a), we can compute gradient steps very efficiently using FFT!

grad[j] = 2*a[k*-j] (with bounds) is essentially a reflected and shifted copy of a.

So the update is: a_new[j] = a[j] - lr * 2 * a[k*-j] (with bounds check)

This is O(n) per step, which is very fast!

But wait, this is for a single peak. For the "multi-peak" subgradient, we'd average over multiple peaks:
grad[j] = (2/L) * sum_{l in L} a[l-j] (with bounds)

where L is the set of "important" lags (e.g., all lags where conv[l] > threshold * max).

This can be computed in O(n*L) or with FFT in O(n log n).

**Algorithm: Accelerated Subgradient with Multi-Peak Targeting**

1. Start from provided sequence (or random init)
2. Normalize to sum = sqrt(2n)
3. Repeat:
   a. Compute conv = fft_convolve(a, a)
   b. Identify "hot" lags: those where conv[k] > (1 - epsilon) * max(conv)
   c. Compute multi-peak subgradient
   d. Apply Nesterov momentum update
   e. Project to non-negativity
   f. Normalize
   g. If no improvement for many iterations, add random perturbation (SA-style)
4. Periodically do a "refinement" step using coordinate descent

Let me also think about the coordinate descent approach. For a fixed coordinate j, what's the optimal value?

If we fix all a[i] for i != j, then conv[k] as a function of a[j] is:
conv[k] = base[k] + a[j] * (2*a[k-j] if 0<=k-j<n else 0)

where base[k] is conv[k] with the terms involving a[j] removed.

So conv[k] is linear in a[j] (for a[j] >= 0). The peak is max_k (base[k] + a[j]*c[k]) where c[k] = 2*a[k-j] (with bounds).

We want to choose a[j] >= 0 to minimize max_k (base[k] + a[j]*c[k]).

This is a 1D convex optimization problem! The optimal a[j] is where the "active" constraints cross.

Specifically, if we sort the lags by their slope c[k], the optimal a[j] is where the line with steepest positive slope first meets the others.

This is like the "water filling" problem. If all c[k] <= 0, the optimal is a[j] = 0 (or as large as possible, depending on normalization). If all c[k] >= 0, the optimal is a[j] = 0.

Wait, that's not right. We want to MINIMIZE the max. If c[k] > 0 for some k, increasing a[j] increases conv[k]. If c[k] < 0 for some k... but wait, a[j] >= 0 and a[k-j] >= 0, so c[k] = 2*a[k-j] >= 0 always!

So increasing a[j] always increases (or doesn't change) all conv[k]. Therefore, the optimal is always a[j] = 0!

But that can't be right because we need sum(a) > 0. The issue is that we have a normalization constraint.

So the problem is: minimize max_k conv[k] subject to sum(a) = S and a[i] >= 0.

If we fix all coordinates except a[j], and we want sum(a) = S, then a[j] = S - sum_{i!=j} a[i]. If this is negative, the constraint is infeasible (we'd need to reduce other coordinates too).

This makes coordinate descent more complex. Let me think of a different approach.

What about **alternating minimization**? Split the coordinates into two groups (e.g., even and odd indices), optimize one group while fixing the other, then swap.

For a fixed group B, optimizing group A:
conv[k] = sum_{i in A, k-i in A} a[i]*a[k-i] + sum_{i in A, k-i in B} a[i]*a[k-i] + sum_{i in B, k-i in A} a[i]*a[k-i] + sum_{i in B, k-i in B} a[i]*a[k-i]

The last term is constant. The first three terms are bilinear in A. This is still non-trivial.

This is a sum of shifted/reversed copies of a, which can be computed with FFT in O(n log n)!

Again constant. Not useful.

If we increase a[j] by delta, conv[k] increases by delta * (a[k-j] + a[j-k]) (with bounds).
The "room" for a[j] is limited by: delta <= M / max_k (a[k-j] + a[j-k])

- y[k] > 0 implies (Ag)[k] = b[k] = M

```python
"""
Multi-phase optimization for minimizing normalized peak autocorrelation
of non-negative step functions. Uses Nesterov-accelerated subgradient
descent with multi-peak targeting, line search refinement, and simulated
annealing for exploration.
"""

import numpy as np
import time


def fft_convolve(a, b):
    """Compute linear convolution using FFT."""
    size = 1
    while size < len(a) + len(b) - 1:
        size <<= 1
    fa = np.fft.rfft(a, size)
    fb = np.fft.rfft(b, size)
    return np.fft.irfft(fa * fb, size)[:len(a) + len(b) - 1]


def local_score(a):
    """Compute the score 2*n*max(conv(a,a))/sum(a)^2."""
    a = np.clip(a, 0.0, 1000.0)
    n = len(a)
    s = np.sum(a)
    if s < 0.01:
        return np.inf
    conv = fft_convolve(a, a)
    return float(2.0 * n * np.max(conv) / (s * s))


def normalize_seq(a, S=None):
    """Normalize sequence to have a given sum."""
    if S is None:
        S = np.sqrt(2.0 * len(a))
    s = np.sum(a)
    if s < 1e-12:
        return np.full(len(a), S / len(a))
    return a * S / s


def multi_peak_gradient(a, hot_lags):
    """
    Compute the average subgradient over a set of hot lags.
    grad[j] = (2/L) * sum_{k in hot_lags} a[k-j] (if 0<=k-j<n else 0)
    """
    n = len(a)
    L = len(hot_lags)
    grad = np.zeros(n)
    for k in hot_lags:
        j_min = max(0, k - n + 1)
        j_max = min(k, n - 1)
        if j_min <= j_max:
            indices = np.arange(j_min, j_max + 1)
            grad[indices] += 2.0 * a[k - indices]
    grad /= L
    return grad


def find_hot_lags(conv, threshold_frac=0.95):
    """Find lags where conv value is above threshold_frac * max."""
    max_val = np.max(conv)
    threshold = threshold_frac * max_val
    hot = np.where(conv >= threshold)[0]
    return list(hot)


def nesterov_subgradient(a, time_limit, verbose=True, seed=42):
    """
    Nesterov-accelerated subgradient descent with multi-peak targeting.
    """
    n = len(a)
    S = np.sqrt(2.0 * n)
    a = normalize_seq(a.copy(), S)
    t0 = time.monotonic()
    rng = np.random.default_rng(seed)
    
    best_a = a.copy()
    best_conv_max = np.max(fft_convolve(a, a))
    
    # Nesterov momentum
    v = np.zeros(n)
    momentum = 0.9
    lr = 0.1 / np.sqrt(n)
    best_lr = lr
    
    # Threshold for hot lags (start tight, widen over time)
    threshold_frac = 0.99
    
    stall_count = 0
    step = 0
    no_improve_count = 0
    
    while time.monotonic() - t0 < time_limit:
        conv = fft_convolve(a, a)
        conv_max = np.max(conv)
        
        # Update best
        if conv_max < best_conv_max:
            best_conv_max = conv_max
            best_a = a.copy()
            no_improve_count = 0
        else:
            no_improve_count += 1
        
        # Find hot lags
        hot_lags = find_hot_lags(conv, threshold_frac)
        
        # Compute gradient
        grad = multi_peak_gradient(a, hot_lags)
        
        # Nesterov update
        v = momentum * v + grad
        a_new = a - lr * v
        a_new = np.maximum(a_new, 0.0)
        a_new = normalize_seq(a_new, S)
        
        # Adaptive learning rate
        new_conv_max = np.max(fft_convolve(a_new, a_new))
        if new_conv_max < conv_max:
            a = a_new
            lr = min(lr * 1.05, 1.0)
            stall_count = 0
        else:
            lr *= 0.9
            # Accept with some probability (SA-style) if not too bad
            if new_conv_max < conv_max * 1.01 and rng.random() < 0.3:
                a = a_new
            stall_count += 1
        
        if stall_count > 50:
            # Reset momentum and reduce learning rate
            v = np.zeros(n)
            lr *= 0.5
            stall_count = 0
        
        # Periodically widen the threshold
        if step % 100 == 0:
            threshold_frac = max(0.8, threshold_frac - 0.01)
        
        # Periodic diversity move
        if no_improve_count > 200 and rng.random() < 0.1:
            a = a + 0.05 * rng.standard_normal(n)
            a = np.maximum(a, 0.0)
            a = normalize_seq(a, S)
            v = np.zeros(n)
            no_improve_count = 0
        
        step += 1
        if verbose and step % 500 == 0:
            score = 2.0 * n * best_conv_max / (S * S)
            print(f"    Nesterov step {step}: score={score:.6f}, lr={lr:.6f}, threshold={threshold_frac:.2f}")
    
    return best_a


def line_search_refine(a, time_limit, verbose=True, seed=42):
    """
    Fine-grained refinement using line search on the subgradient direction.
    """
    n = len(a)
    S = np.sqrt(2.0 * n)
    a = normalize_seq(a.copy(), S)
    t0 = time.monotonic()
    rng = np.random.default_rng(seed)
    
    best_a = a.copy()
    best_conv_max = np.max(fft_convolve(a, a))
    
    step = 0
    no_improve = 0
    
    while time.monotonic() - t0 < time_limit:
        conv = fft_convolve(a, a)
        conv_max = np.max(conv)
        
        # Use multiple hot lags for smoother gradient
        threshold_frac = 0.9 + 0.05 * np.sin(step * 0.01)
        hot_lags = find_hot_lags(conv, threshold_frac)
        grad = multi_peak_gradient(a, hot_lags)
        
        # Line search: try different step sizes
        best_alpha = 0
        best_new_max = conv_max
        for alpha in [0.001, 0.005, 0.01, 0.02, 0.05, 0.1, 0.2, 0.5]:
            a_try = a - alpha * grad
            a_try = np.maximum(a_try, 0.0)
            a_try = normalize_seq(a_try, S)
            new_max = np.max(fft_convolve(a_try, a_try))
            if new_max < best_new_max:
                best_new_max = new_max
                best_alpha = alpha
        
        if best_alpha > 0:
            a = a - best_alpha * grad
            a = np.maximum(a, 0.0)
            a = normalize_seq(a, S)
            
            if best_new_max < best_conv_max:
                best_conv_max = best_new_max
                best_a = a.copy()
                no_improve = 0
            else:
                no_improve += 1
        else:
            no_improve += 1
        
        # If stuck, try a random perturbation
        if no_improve > 100:
            a = a * (1 + 0.02 * rng.standard_normal(n))
            a = np.maximum(a, 0.0)
            a = normalize_seq(a, S)
            no_improve = 0
        
        step += 1
        if verbose and step % 200 == 0:
            score = 2.0 * n * best_conv_max / (S * S)
            print(f"    LineSearch step {step}: score={score:.6f}, alpha={best_alpha:.4f}")
    
    return best_a


def simulated_annealing(a, time_limit, verbose=True, seed=42):
    """
    Simulated annealing to explore different basins.
    """
    n = len(a)
    S = np.sqrt(2.0 * n)
    a = normalize_seq(a.copy(), S)
    t0 = time.monotonic()
    rng = np.random.default_rng(seed)
    
    best_a = a.copy()
    best_conv_max = np.max(fft_convolve(a, a))
    current_conv_max = best_conv_max
    
    T = 0.01  # Initial temperature
    T_min = 0.0001
    cooling = 0.999
    
    step = 0
    while time.monotonic() - t0 < time_limit:
        # Generate perturbation
        a_new = a.copy()
        
        # Random move: modify a random block
        width = rng.integers(1, max(2, n // 20))
        start = int(rng.integers(0, n - width))
        scale = np.exp(rng.normal(0, 0.1, size=width))
        a_new[start:start + width] *= scale
        a_new = np.maximum(a_new, 0.0)
        a_new = normalize_seq(a_new, S)
        
        new_conv_max = np.max(fft_convolve(a_new, a_new))
        delta = new_conv_max - current_conv_max
        
        # Metropolis criterion
        if delta < 0 or rng.random() < np.exp(-delta / T):
            a = a_new
            current_conv_max = new_conv_max
            if new_conv_max < best_conv_max:
                best_conv_max = new_conv_max
                best_a = a_new.copy()
        
        T = max(T_min, T * cooling)
        step += 1
        
        if verbose and step % 1000 == 0:
            score = 2.0 * n * best_conv_max / (S * S)
            print(f"    SA step {step}: score={score:.6f}, T={T:.6f}")
    
    return best_a


def coordinate_descent_polish(a, time_limit, verbose=True, seed=42):
    """
    Coordinate descent: for each coordinate, try small perturbations.
    Focus on coordinates that contribute to the peak.
    """
    n = len(a)
    S = np.sqrt(2.0 * n)
    a = normalize_seq(a.copy(), S)
    t0 = time.monotonic()
    rng = np.random.default_rng(seed)
    
    best_a = a.copy()
    best_conv_max = np.max(fft_convolve(a, a))
    
    round_num = 0
    while time.monotonic() - t0 < time_limit:
        conv = fft_convolve(a, a)
        peak_idx = int(np.argmax(conv))
        
        # Find top contributors to the peak
        contribs = np.zeros(n)
        for j in range(n):
            i = peak_idx - j
            if 0 <= i < n:
                contribs[j] = a[j] * a[i]
        
        # Sort by contribution (descending)
        top_k = max(10, n // 10)
        top_indices = np.argsort(contribs)[-top_k:]
        
        improved = False
        for j in top_indices:
            if time.monotonic() - t0 > time_limit:
                    break
            
            # Try reducing a[j] slightly
            for factor in [0.9, 0.8, 0.7, 0.5]:
                a_try = a.copy()
                old_val = a_try[j]
                a_try[j] = a_try[j] * factor
                # Compensate by increasing a non-contributing coordinate
                other_idx = int(rng.integers(0, n))
                if other_idx != j:
```

```python
"""
Multi-phase optimization for minimizing normalized peak autocorrelation
of non-negative step functions. Combines Nesterov-accelerated subgradient
descent with multi-peak targeting, backtracking line search, coordinate
descent polishing, and simulated annealing for basin exploration.
"""

import numpy as np
import time


def fft_convolve(a, b):
    """Compute linear convolution of two 1-D arrays using FFT."""
    size = 1
    while size < len(a) + len(b) - 1:
        size <<= 1
    fa = np.fft.rfft(a, size)
    fb = np.fft.rfft(b, size)
    return np.fft.irfft(fa * fb, size)[:len(a) + len(b) - 1]


def local_score(a):
    """Compute the score 2*n*max(conv(a,a))/sum(a)^2."""
    a = np.clip(a, 0.0, 1000.0)
    n = len(a)
    s = np.sum(a)
    if s < 0.01:
        return np.inf
    conv = fft_convolve(a, a)
    return float(2.0 * n * np.max(conv) / (s * s))


def normalize_seq(a, S=None):
    """Normalize sequence to have a given sum."""
    if S is None:
        S = np.sqrt(2.0 * len(a))
    s = np.sum(a)
    if s < 1e-12:
        return np.full(len(a), S / len(a))
    return a * S / s


def multi_peak_gradient(a, hot_lags):
    """
    Compute the average subgradient over a set of hot lags.
    grad[j] = (2/L) * sum_{k in hot_lags} a[k-j] (if 0<=k-j<n else 0)
    """
    n = len(a)
    L = len(hot_lags)
    if L == 0:
        return np.zeros(n)
    grad = np.zeros(n)
    for k in hot_lags:
        j_min = max(0, k - n + 1)
        j_max = min(k, n - 1)
        if j_min <= j_max:
            indices = np.arange(j_min, j_max + 1)
            grad[indices] += 2.0 * a[k - indices]
    grad /= L
    return grad


def find_hot_lags(conv, threshold_frac=0.98):
    """Find lags where conv value is above threshold_frac * max."""
    max_val = np.max(conv)
    if max_val < 1e-15:
        return [0]
    threshold = threshold_frac * max_val
    hot = np.where(conv >= threshold)[0]
    return list(hot)


def nesterov_subgradient(a_init, time_limit, verbose=True, seed=42):
    """
    Nesterov-accelerated subgradient descent with multi-peak targeting
    and adaptive learning rate.
    """
    n = len(a_init)
    S = np.sqrt(2.0 * n)
    a = normalize_seq(a_init.copy(), S)
    t0 = time.monotonic()
    rng = np.random.default_rng(seed)

    best_a = a.copy()
    best_conv_max = np.max(fft_convolve(a, a))

    v = np.zeros(n)
    mu = 0.85  # momentum
    lr = 0.05 / np.sqrt(n)
    threshold_frac = 0.99

    stall_count = 0
    no_improve = 0
    step = 0

    while time.monotonic() - t0 < time_limit:
        conv = fft_convolve(a, a)
        conv_max = np.max(conv)

        if conv_max < best_conv_max:
            best_conv_max = conv_max
            best_a = a.copy()
            no_improve = 0
        else:
            no_improve += 1

        hot_lags = find_hot_lags(conv, threshold_frac)
        grad = multi_peak_gradient(a, hot_lags)

        # Center the gradient to approximately preserve sum
        grad_centered = grad - np.mean(grad)

        # Nesterov step
        v = mu * v + grad_centered
        a_new = a - lr * v
        a_new = np.maximum(a_new, 0.0)
        a_new = normalize_seq(a_new, S)

        new_conv_max = np.max(fft_convolve(a_new, a_new))

        if new_conv_max < conv_max:
            a = a_new
            lr = min(lr * 1.03, 0.5)
            stall_count = 0
        elif new_conv_max < conv_max * 1.005 and rng.random() < 0.4:
            a = a_new
            stall_count += 1
        else:
            lr *= 0.92
            stall_count += 1

        if stall_count > 30:
            v = np.zeros(n)
            lr = max(lr * 0.7, 0.001 / n)
            stall_count = 0

        # Adaptively widen threshold
        if step % 80 == 0:
            threshold_frac = max(0.85, threshold_frac - 0.005)

        # Diversity kicks when stuck
        if no_improve > 150:
            if rng.random() < 0.15:
                a = best_a + 0.03 * rng.standard_normal(n)
                a = np.maximum(a, 0.0)
                a = normalize_seq(a, S)
                v = np.zeros(n)
                lr = 0.05 / np.sqrt(n)
                no_improve = 0

        step += 1
        if verbose and step % 500 == 0:
            score = 2.0 * n * best_conv_max / (S * S)
            print(f"    Nesterov step {step}: score={score:.6f}, lr={lr:.6f}, thr={threshold_frac:.3f}, stall={stall_count}")

    return best_a


def line_search_refine(a_init, time_limit, verbose=True, seed=123):
    """
    Fine-grained refinement using multi-peak gradient with line search.
    """
    n = len(a_init)
    S = np.sqrt(2.0 * n)
    a = normalize_seq(a_init.copy(), S)
    t0 = time.monotonic()
    rng = np.random.default_rng(seed)

    best_a = a.copy()
    best_conv_max = np.max(fft_convolve(a, a))

    step = 0
    no_improve = 0
    lr = 0.01

    while time.monotonic() - t0 < time_limit:
        conv = fft_convolve(a, a)
        conv_max = np.max(conv)

        if conv_max < best_conv_max:
            best_conv_max = conv_max
            best_a = a.copy()
            no_improve = 0
        else:
            no_improve += 1

        # Oscillate threshold to explore different peaks
        threshold_frac = 0.92 + 0.06 * np.sin(step * 0.02)
        hot_lags = find_hot_lags(conv, threshold_frac)
        grad = multi_peak_gradient(a, hot_lags)
        grad_centered = grad - np.mean(grad)

        # Backtracking line search
        best_alpha = 0
        best_new_max = conv_max
        for alpha in [lr * 0.1, lr * 0.3, lr, lr * 2, lr * 5, lr * 10, lr * 20]:
            a_try = a - alpha * grad_centered
            a_try = np.maximum(a_try, 0.0)
            a_try = normalize_seq(a_try, S)
            new_max = np.max(fft_convolve(a_try, a_try))

                best_new_max = new_max
                best_alpha = alpha

        if best_alpha > 0:
            a = a - best_alpha * grad_centered
            a = np.maximum(a, 0.0)
            a = normalize_seq(a, S)
            if best_new_max < conv_max:
                lr = min(lr * 1.1, 0.5)
            else:
                lr *= 0.9
        else:
            lr *= 0.8

        # Restart if stuck
        if no_improve > 80:
            a = best_a * (1 + 0.02 * rng.standard_normal(n))
            a = np.maximum(a, 0.0)
            a = normalize_seq(a, S)
            lr = 0.01
            no_improve = 0

        step += 1
        if verbose and step % 200 == 0:
            score = 2.0 * n * best_conv_max / (S * S)
            print(f"    LineSearch step {step}: score={score:.6f}, lr={lr:.5f}")

    return best_a


def coordinate_descent_polish(a_init, time_limit, verbose=True, seed=456):
    """
    Targeted coordinate descent: perturb coordinates that contribute
    most to the current peak, with compensation on low-impact coords.
    """
    n = len(a_init)
    S = np.sqrt(2.0 * n)
    a = normalize_seq(a_init.copy(), S)
    t0 = time.monotonic()
    rng = np.random.default_rng(seed)

    best_a = a.copy()
    best_conv_max = np.max(fft_convolve(a, a))
    round_num = 0

    while time.monotonic() - t0 < time_limit:
        conv = fft_convolve(a, a)
        conv_max = np.max(conv)
        peak_idx = int(np.argmax(conv))

        # Compute contributions to peak
        contribs = np.zeros(n)
        j_min = max(0, peak_idx - n + 1)
        j_max = min(peak_idx, n - 1)
        for j in range(j_min, j_max + 1):
            contribs[j] = a[j] * a[peak_idx - j]

        # Also compute "slack" - how much each coord can be changed
        # without affecting the peak much
        top_k = max(5, n // 15)
        top_indices = np.argsort(contribs)[-top_k:]

        # Also find low-impact indices for compensation
        low_indices = np.argsort(contribs)[:max(3, n // 20)]

        improved_this_round = False

        for j in top_indices:
            if time.monotonic() - t0 > time_limit:
                break

            # Try reducing a[j]
            old_val = a[j]
            for factor in [0.95, 0.9, 0.85, 0.8, 0.7]:
                a_try = a.copy()
                a_try[j] = a_try[j] * factor
                # Compensate on a low-impact coordinate
                comp_idx = int(rng.integers(0, len(low_indices)))
                comp_j = low_indices[comp_idx]
                if comp_j != j:
                    a_try[comp_j] += old_val * (1 - factor) * rng.uniform(0.8, 1.2)

                a_try = np.maximum(a_try, 0.0)
                a_try = normalize_seq(a_try, S)
                new_conv = fft_convolve(a_try, a_try)
                new_max = np.max(new_conv)

                if new_max < best_conv_max:
                    best_conv_max = new_max
                    best_a = a_try.copy()
                    a = a_try
                    improved_this_round = True
                    break
                elif new_max < conv_max:
                    # Accept even if not best, to make progress
                    a = a_try
                    break

        # Also try increasing low-impact coords
        for j in low_indices[:3]:
            if time.monotonic() - t0 > time_limit:
                break
            for factor in [1.05, 1.1, 1.15]:
                a_try = a.copy()
                a_try[j] *= factor
                a_try = normalize_seq(a_try, S)
                new_max = np.max(fft_convolve(a_try, a_try))
                if new_max < best_conv_max:
                    best_conv_max = new_max
                    best_a = a_try.copy()
                    a = a_try
                    break

        round_num += 1
        if verbose and round_num % 20 == 0:
            score = 2.0 * n * best_conv_max / (S * S)
            print(f"    CoordDescent round {round_num}: score={score:.6f}")

    return best_a


def simulated_annealing_explore(a_init, time_limit, verbose=True, seed=789):
    """
    Simulated annealing to explore different basins of attraction.
    Uses structured block mutations.
    """
    n = len(a_init)
    S = np.sqrt(2.0 * n)
    a = normalize_seq(a_init.copy(), S)
    t0 = time.monotonic()
    rng = np.random.default_rng(seed)

    best_a = a.copy()
    best_conv_max = np.max(fft_convolve(a, a))
    current_conv_max = best_conv_max

    T = 0.005
    T_min = 0.00005
    cooling = 0.9995

    step = 0
    while time.monotonic() - t0 < time_limit:
        a_new = a.copy()

        # Choose mutation type
        mut_type = rng.integers(0, 4)

        if mut_type == 0:
            # Block perturbation
            width = int(rng.integers(1, max(2, n // 15)))
            start = int(rng.integers(0, n - width))
            scale = np.exp(rng.normal(0, 0.15, size=width))
            a_new[start:start + width] *= scale
        elif mut_type == 1:
            # Single coordinate kick
            j = int(rng.integers(0, n))
            a_new[j] *= np.exp(rng.normal(0, 0.3))
        elif mut_type == 2:
            # Symmetric perturbation (affect a[j] and a[n-1-j])
            j = int(rng.integers(0, n))
            j2 = n - 1 - j
            delta = rng.normal(0, 0.1)
            a_new[j] = max(0, a_new[j] + delta)
            if j2 != j:
                a_new[j2] = max(0, a_new[j2] - delta * 0.5)
        else:
            # Small random noise
            a_new += rng.normal(0, 0.02, n)

        a_new = np.maximum(a_new, 0.0)
        a_new = normalize_seq(a_new, S)

        new_conv_max = np.max(fft_convolve(a_new, a_new))
        delta = new_conv_max - current_conv_max

        if delta < 0 or rng.random() < np.exp(-delta / max(T, 1e-10)):
            a = a_new
            current_conv_max = new_conv_max
            if new_conv_max < best_conv_max:
                best_conv_max = new_conv_max
                best_a = a_new.copy()

        T = max(T_min, T * cooling)
        step += 1

        if verbose and step % 2000 == 0:
            score = 2.0 * n * best_conv_max / (S * S)
            print(f"    SA step {step}: score={score:.6f}, T={T:.6f}")

    return best_a


def make_structured_init(n, rng, kind):
    """Create a structured initial sequence."""
    t = np.arange(n, dtype=np.float64)
    if kind == 0:
        # Chirp
        alpha = 0.2 + 0.3 * rng.random()
        a = 1.0 + alpha * np.cos(np.pi * t * t / (n * 0.6))
    elif kind == 1:
        # Multi-tone
        a = np.ones(n)
        for _ in range(4):
            f = int(rng.integers(1, n // 4))
            amp = rng.uniform(0.05, 0.25)
            phase = rng.uniform(0, 2 * np.pi)
            a += amp * np.cos(2 * np.pi * f * t / n + phase)
    elif kind == 2:
        # Smoothed random
        from scipy.ndimage import gaussian_filter1d
        a = 1.0 + 0.4 * rng.standard_normal(n)
        a = gaussian_filter1d(a, sigma=max(1, n * 0.03))
    elif kind == 3:
        # Raised cosine window
        a = 1.0 + 0.3 * np.cos(np.pi * (2 * t / n - 1))
    else:
        # Power law decay from center
        center = n // 2
        a = 1.0 + 0.5 * np.exp(-np.abs(t - center) / (n * 0.15))

    return np.clip(a, 0.01, None)


def propose_candidate(seed=42, budget_s=1800, **kwargs):
    """
    Multi-phase optimization for minimizing the normalized peak
    autocorrelation of non-negative step functions.

    Phases:
    1. Nesterov subgradient (fast convergence)
    2. Line search refinement (fine-tuning)
    3. Coordinate descent (targeted peak reduction)
    4. Simulated annealing (basin exploration)
    5. Final polish
    """
    t_global = time.monotonic()
    deadline = t_global + budget_s - 30.0
    rng = np.random.default_rng(seed)

    best_score = np.inf
    best_seq = None

    # Get provided sequence
    provided_seq = None
    if 'height_sequence_1' in globals() and height_sequence_1 is not None:
        provided_seq = np.clip(np.asarray(height_sequence_1, dtype=np.float64), 0.01, 1000.0)
        print(f"Provided sequence: n={len(provided_seq)}, score={local_score(provided_seq):.6f}")
        best_score = local_score(provided_seq)
        best_seq = provided_seq.copy()

    if provided_seq is None:
        provided_seq = np.ones(640)
        best_seq = provided_seq.copy()
        best_score = local_score(provided_seq)
        print(f"No provided sequence, using constant init: score={best_score:.6f}")

    n = len(provided_seq)
    print(f"Working with n={n}, initial score={best_score:.6f}")

    def try_update(a):
        nonlocal best_score, best_seq
        a_clip = np.clip(a, 0.0, 1000.0)
        s = local_score(a_clip)
        if s < best_score:
            best_score = s
            best_seq = a_clip.copy()
            return True
        return False

    # Phase 1: Nesterov subgradient (main workhorse)
    print("\n=== Phase 1: Nesterov Subgradient ===")
    t_limit = min(500.0, (deadline - time.monotonic()) * 0.35)
    print(f"  Time limit: {t_limit:.0f}s")
    result = nesterov_subgradient(provided_seq, t_limit, verbose=True, seed=42)
    if try_update(result):
        print(f"  *** New best: {best_score:.6f} ***")
    print(f"  Phase 1 best: {best_score:.6f}")

    # Phase 2: Line search refinement
    print("\n=== Phase 2: Line Search Refinement ===")
    remaining = deadline - time.monotonic() - 60
    if remaining > 30:
        t_limit = min(250.0, remaining * 0.35)
        print(f"  Time limit: {t_limit:.0f}s")
        result = line_search_refine(best_seq, t_limit, verbose=True, seed=123)
        if try_update(result):
            print(f"  *** New best: {best_score:.6f} ***")
        print(f"  Phase 2 best: {best_score:.6f}")

    # Phase 3: Coordinate descent
    print("\n=== Phase 3: Coordinate Descent ===")
    remaining = deadline - time.monotonic() - 60
    if remaining > 30:
        t_limit = min(200.0, remaining * 0.35)
        print(f"  Time limit: {t_limit:.0f}s")
        result = coordinate_descent_polish(best_seq, t_limit, verbose=True, seed=456)
        if try_update(result):
            print(f"  *** New best: {best_score:.6f} ***")
        print(f"  Phase 3 best: {best_score:.6f}")

    # Phase 4: Simulated annealing exploration
    print("\n=== Phase 4: Simulated Annealing ===")
    remaining = deadline - time.monotonic() - 40
    if remaining > 30:
        t_limit = min(150.0, remaining * 0.4)
        print(f"  Time limit: {t_limit:.0f}s")
        result = simulated_annealing_explore(best_seq, t_limit, verbose=True, seed=789)
        if try_update(result):
            print(f"  *** New best: {best_score:.6f} ***")
        print(f"  Phase 4 best: {best_score:.6f}")

    # Phase 5: Try a different initialization angle
    print("\n=== Phase 5: Alternative Start ===")
    remaining = deadline - time.monotonic() - 30
    if remaining > 60:
        # Create a perturbed version of best and run Nesterov from there
        a_perturbed = best_seq * (1 + 0.05 * rng.standard_normal(n))
        a_perturbed = np.maximum(a_perturbed, 0.01)
        t_limit = min(80.0, remaining * 0.5)
        result = nesterov_subgradient(a_perturbed, t_limit, verbose=False, seed=999)
        if try_update(result):
            print(f"  *** Alt start: new best={best_score:.6f} ***")

        # Also try a structured init
        if time.monotonic() < deadline - 40:
            a_struct = make_structured_init(n, rng, int(rng.integers(0, 5)))
            t_per = min(60.0, (deadline - time.monotonic()) - 30)
            if t_per > 20:
                result = nesterov_subgradient(a_struct, t_per, verbose=False, seed=1111)
                if try_update(result):
                    print(f"  *** Structured init: new best={best_score:.6f} ***")

    # Phase 6: Final polish
    print("\n=== Phase 6: Final Polish ===")
    remaining = deadline - time.monotonic() - 10
    if remaining > 20:
        t_limit = min(remaining, 80.0)
        result = coordinate_descent_polish(best_seq, t_limit, verbose=False, seed=2024)
        if try_update(result):
            print(f"  *** Final polish: {best_score:.6f} ***")

    # One more Nesterov pass if time
    remaining = deadline - time.monotonic() - 5
    if remaining > 20:
        result = nesterov_subgradient(best_seq, min(remaining, 60.0), verbose=False, seed=3141)
        if try_update(result):
            print(f"  *** Extra Nesterov: {best_score:.6f} ***")

    # Final verification
    if best_seq is not None:
        final_list = [float(max(0.0, min(1000.0, x))) for x in best_seq]
        final_score = evaluate_sequence(final_list)
        print(f"\n=== FINAL: evaluate_score={final_score:.6f}, n={len(final_list)}, local={best_score:.6f} ===")
        return final_list

    # Fallback
    return [1.0] * 256
```
