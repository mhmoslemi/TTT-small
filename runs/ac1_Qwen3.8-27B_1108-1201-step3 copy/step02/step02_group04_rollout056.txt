Negative! So for `n=2`, the coefficient `a_3` is negative. But we only need `a_0, a_1` (since `n=2`), and they're both positive.

For `n=3` (m=5): we need `a_0, a_1, a_2` to be positive.
`sqrt(1+x+x^2+x^3+x^4) = sum a_k x^k`.
- `a_0 = 1`
- `2a_0*a_1 = 1` → `a_1 = 1/2`
- `2a_0*a_2 + a_1^2 = 1` → `2a_2 = 3/4` → `a_2 = 3/8`

All positive! And for `n=3`, we only need `a_0, a_1, a_2`.

For `n=4` (m=7): need `a_0, a_1, a_2, a_3`.
- `a_0 = 1`
- `a_1 = 1/2`
- `a_2 = 3/8`
- `2a_0*a_3 + 2a_1*a_2 = 0` → `2a_3 + 2*(1/2)*(3/8) = 0` → `a_3 = -3/16`

Negative again! But for `n=4`, we need `a_3` to be non-negative. So we can't use the exact square root.

The pattern: the coefficients of `sqrt(1+x+...+x^{2n-2})` are positive for `k < n` only when `n` is small. For larger `n`, some of the required coefficients become negative.

So the "ideal" initialization using the exact square root only works for small `n`. For larger `n`, we need a different approach.

**Alternative initialization: Use the `1/sqrt(1-x)` coefficients truncated**

`1/sqrt(1-x) = sum_{k=0}^{\infty} binom(2k,k)/4^k * x^k`

All coefficients are positive. Truncated to `n` terms and normalized, this gives a valid starting point. As I computed earlier, the score for this initialization is approximately `pi/2 ≈ 1.571` for large `n`, which is worse than our current 1.511.

**Better initialization: Use a "flattened" version**

What if we use `a_k = 1 / (k+1)^alpha` for some `alpha > 0`? For `alpha=0`, it's uniform (score 2). For `alpha=1`, it's the harmonic sequence. For `alpha` close to 0.5, it's close to the `1/sqrt(1-x)` coefficients.

"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using accelerated LP-guided
alternating optimization with adaptive step sizes, warm-started LPs,
and multi-resolution polishing. Focuses on n=512 with parent-guided
initialization, and optionally explores n=768.

import numpy as np
import scipy.optimize as optimize
import scipy.sparse as sparse
import time

def fast_convolve(a):
    """Linear auto-convolution using FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    result = np.fft.irfft(A * A, fft_size)
    return result[:size]

def make_lp_indices(n):
    """Precompute sparse matrix indices for the convolution constraint."""
    rows_list = []
    cols_list = []
    for i in range(n):
        for j in range(n):
            rows_list.append(i + j)
            cols_list.append(i)
    return np.array(rows_list, dtype=np.int32), np.array(cols_list, dtype=np.int32)

def lp_direction(f, M, rows, cols, n, prev_g=None, timeout=10):
    """Solve LP: max sum(g) s.t. g>=0, (f*g)[k]<=M for all k."""
    vals = np.tile(f, n)
    A = sparse.csc_matrix((vals, (rows, cols)), shape=(2 * n - 1, n))
    c = -np.ones(n)
    b = np.full(2 * n - 1, M)
    bounds = [(0, None)] * n
    
    # Use warm start if available
    options = {'disp': False, 'time_limit': timeout}
    if prev_g is not None:
        # HiGHS doesn't support warm starts directly in linprog,
        # but we can use it as a hint by checking feasibility
        pass
    
    res = optimize.linprog(c, A_ub=A, b_ub=b, bounds=bounds,
                          method='highs', options=options)
    if res.success:
        return np.maximum(res.x, 0.0)
    return None

def objective_normalized(f):
    """Compute the objective for a normalized (sum=1) sequence."""
    n = len(f)
    conv = fast_convolve(f)
    return 2.0 * n * conv.max()

def lp_alternate(f0, time_limit, verbose=True):
    """LP-guided alternating optimization with adaptive step size."""
    f = np.maximum(f0.astype(np.float64), 0.0)
    n = len(f)
    f_sum = f.sum()
    if f_sum < 1e-12:
        f = np.ones(n) / n
    else:
        f /= f_sum
    
    conv = fast_convolve(f)
    M = conv.max()
    best_obj = 2.0 * n * M
    best_f = f.copy()
    
    rows, cols = make_lp_indices(n)
    
    t0 = time.monotonic()
    t_step = 0.5  # Initial step size
    patience = 0
    iter_count = 0
    prev_g = None
    
    while time.monotonic() - t0 < time_limit:
        iter_count += 1
        
        g = lp_direction(f, M, rows, cols, n, prev_g)
        if g is None:
            break
        
        g_sum = g.sum()
        if g_sum < 1e-12:
            break
        g /= g_sum
        prev_g = g
        
        # Convergence check
        if np.max(np.abs(g - f)) < 1e-14:
            if verbose:
                print(f"    Converged at iter {iter_count}, obj={best_obj:.8f}")
            break
        
        # Line search with adaptive step
        improved = False
        for t_try in [t_step, 0.7*t_step, 0.5*t_step, 0.3*t_step, 0.15*t_step, 0.05*t_step]:
            f_new = (1.0 - t_try) * f + t_try * g
            f_new = np.maximum(f_new, 0.0)
            s = f_new.sum()
            if s < 1e-12:
                continue
            f_new /= s
            conv_new = fast_convolve(f_new)
            obj_new = 2.0 * n * conv_new.max()
            if obj_new < best_obj - 1e-14:
                f = f_new
                M = conv_new.max()
                best_obj = obj_new
                best_f = f.copy()
                patience = 0
                if obj_new < best_obj * 0.999:  # significant improvement
                    t_step = min(1.0, t_step * 1.2)
                improved = True
                break
        
        if not improved:
            patience += 1
            t_step *= 0.85
            if patience > 80:
                break
        
        if verbose and iter_count % 20 == 0:
            elapsed = time.monotonic() - t0
            print(f"    LP iter {iter_count}, obj={best_obj:.8f}, t={t_step:.3f}, elapsed={elapsed:.1f}s")
    
    return best_f, best_obj
