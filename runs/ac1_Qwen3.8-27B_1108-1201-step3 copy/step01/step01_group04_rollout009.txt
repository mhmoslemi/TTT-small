Actually, one more idea: I can use the **Fourier domain** to think about this problem. The convolution theorem says:
`conv(a, a) = IFFT(|FFT(a)|^2)`

So the peak of the convolution is the maximum of `IFFT(|FFT(a)|^2)`. This is exactly the PAPR (peak-to-average power ratio) of the sequence in the time domain, viewed through the frequency domain.

To minimize the peak of `IFFT(|FFT(a)|^2)`, we want `|FFT(a)|^2` to be as flat as possible (uniform power spectrum). This is the "flat spectrum" or "white noise" condition.

For a non-negative sequence, achieving a perfectly flat spectrum is impossible (since the zero frequency component is always positive and large). But we can get close.

The "flat spectrum" motivation suggests using **spectral normalization** as an alternative objective: minimize `max |FFT(a)|^2` (subject to `sum(a) = S`). This is equivalent to minimizing the peak of `|FFT(a)|` which is a convex problem in the magnitude domain (though non-convex in `a` itself due to the non-negativity constraint).

Actually, minimizing `max_k IFFT(|FFT(a)|^2)[k]` is the same as minimizing the peak of the autocorrelation, which is our original problem. The spectral view is useful for intuition but doesn't directly give a new algorithm.

However, it does suggest a **phase-only** approach: fix the magnitudes of the FFT to be as flat as possible, and adjust the phases to make the time-domain sequence non-negative. This is the "successive overrelaxation" (SOR) or "Gerchberg-Saxton" algorithm used in optics.

Algorithm:
1. Start with a non-negative sequence `a`.
2. Compute `A = FFT(a)`.
3. Modify the magnitudes: `|A_new[k]| = target_flat_spectrum[k]` (e.g., uniform except at DC).
4. Keep the phases: `A_new[k] = |A_new[k]| * exp(i * angle(A[k]))`.
5. `a_new = IFFT(A_new)`.
6. Project to non-negative: `a_new = max(a_new, 0)`.
7. Iterate.

This alternates between "flat spectrum" in frequency and "non-negative" in time. It's similar to the "alternating projections" method.

The target flat spectrum should be: `|A[k]|^2 = C` for k ≠ 0, and `|A[0]|^2 = (sum a)^2`. By Parseval: `sum_k |A[k]|^2 = sum_j a[j]^2 * N` (depending on normalization). Actually:

With the standard FFT normalization: `sum_k |A[k]|^2 = N * sum_j |a[j]|^2`.

And `|A[0]|^2 = (sum_j a[j])^2`.

If we want `|A[k]| = C` for k ≠ 0:
`(N-1) * C^2 + (sum a)^2 = N * sum a[j]^2`.

"""
Optimizes non-negative sequences to minimize 2*n*max(conv(a,a))/(sum(a))^2.
Uses FFT-based soft-max gradient descent, spectral flat-spectrum projection,
LP-based refinement, and multi-peak load balancing. Explores diverse initializations
across multiple sequence lengths within the time budget.

import numpy as np
import time
from numpy.fft import fft, ifft
from scipy.optimize import linprog


def linear_convolve(a, b):
    """Compute linear convolution using FFT."""
    n = len(a) + len(b) - 1
    size = 1
    while size < n:
        size *= 2
    fa = fft(a, size)
    fb = fft(b, size)
    return ifft(fa * fb).real[:n]


def compute_objective(a):
    """Compute 2*n*max(conv(a,a))/(sum(a))^2."""
    n = len(a)
    c = linear_convolve(a, a)
    max_c = float(c.max())
    s = float(a.sum())
    if s < 0.01:
        return float('inf')
    return float(2.0 * n * max_c / (s * s))


def normalize(a, target=None):
    """Normalize sequence to a target sum."""
    n = len(a)
    if target is None:
        target = np.sqrt(2.0 * n)
    s = a.sum()
    if s < 1e-15:
        return a.copy()
    return a * (target / s)


def soft_gradient_fft(a, beta, top_k=None):
    """
    Compute soft-max weighted gradient of max(conv(a,a)) using FFT.
    Returns (gradient, convolution).
    """
    n = len(a)
    c = linear_convolve(a, a)

    if top_k is not None and top_k < len(c):
        idx = np.argpartition(c, -top_k)[-top_k:]
        w = np.zeros_like(c)
        c_sub = c[idx]
        w[idx] = np.exp(beta * (c_sub - c_sub.max()))
    else:
        w = np.exp(beta * (c - c.max()))

    w_sum = w.sum()
    if w_sum > 0:
        w /= w_sum
    else:
        w[:] = 1.0 / len(c)

    # grad[j] = 2 * sum_i a[i] * w[j+i] = 2 * cross_corr(a, w)[j]
    N = 1
    while N < 3 * n:
        N *= 2
    fa = fft(a, N)
    fw = fft(w, N)
    cross = ifft(np.conj(fa) * fw).real
    grad = 2.0 * cross[:n]

    return grad, c


def hard_gradient(a):
    """Compute gradient at the single peak location."""
    n = len(a)
    c = linear_convolve(a, a)
    k_star = int(c.argmax())
    grad = np.zeros(n)
    lo = max(0, k_star - n + 1)
    hi = min(n - 1, k_star)
    for j in range(lo, hi + 1):
        grad[j] = 2.0 * a[k_star - j]
    return grad, c


def project_fixed_sum_nonneg(a, target):
    """Project onto {a >= 0, sum(a) = target} via normalization after clipping."""
    a = np.maximum(a, 0.0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(len(a)) * target / len(a)
        return a
    return a * (target / s)


def spectral_flat_projection(a, n_iters=50, target=None):
    """
    Alternating projections: flat spectrum in freq, non-negativity in time.
    Minimizes peak autocorrelation by promoting flat power spectrum.
    """
    n = len(a)
    if target is None:
        target = np.sqrt(2.0 * n)
    a = project_fixed_sum_nonneg(a.copy(), target)

    for _ in range(n_iters):
        A = fft(a)
        # Target: flat magnitude except DC
        dc = A[0]
        mag = np.abs(A)
        # Compute target flat level from energy
        # sum |A[k]|^2 = N * sum a[j]^2
        # Want |A[k]| = C for k != 0
        # (N-1)*C^2 + |dc|^2 = N * sum(a^2)
        energy = n * np.sum(a * a)
        dc_mag = abs(dc)
        C_sq = (energy - dc_mag * dc_mag) / (n - 1)
        if C_sq < 0:
            C_sq = 0
        C = np.sqrt(C_sq)

        # New spectrum: flat magnitude with current phases
        phases = np.angle(A)
        A_new = np.zeros(n, dtype=complex)
        A_new[0] = dc  # keep DC (determines sum)
        A_new[1:] = C * np.exp(1j * phases[1:])

        a_new = ifft(A_new).real
        a = project_fixed_sum_nonneg(a_new, target)

    return a


def lp_refine(a, M, n_vars=None):
    """
    Solve LP: max sum(g) s.t. conv(a,g) <= M elementwise, g >= 0.
    Returns g or None.
    """
    n = len(a)
    if n_vars is not None:
        n = n_vars
    if n > 3000:
        return None

    c_obj = -np.ones(n)
    # Build constraint matrix sparsely
    n_constraints = 2 * n - 1
    A_rows = []
    A_cols = []
    A_vals = []
    for m in range(n_constraints):
        lo = max(0, m - n + 1)
        hi = min(n - 1, m)
        for j in range(lo, hi + 1):
            A_rows.append(m)
            A_cols.append(j)
            A_vals.append(a[m - j])

    from scipy.sparse import csr_matrix
    A_mat = csr_matrix((A_vals, (A_rows, A_cols)), shape=(n_constraints, n))
    b = np.full(n_constraints, M)
    bounds = [(0.0, None)] * n

    try:
        res = linprog(c_obj, A_ub=A_mat, b_ub=b, bounds=bounds, method='highs',
                      options={'presolve': True, 'dual_feasibility_tolerance': 1e-9})
        if res.status == 0:
            return res.x
    except Exception:
        pass
    return None


def optimize_gradient(a0, deadline, beta_init=5.0, beta_max=50.0,
                      lr_init=0.3, max_iters=5000, top_k=None,
                      restart_interval=500, restart_magnitude=0.1):
    """
    Main gradient optimizer with soft-max gradient, adaptive beta,
    cosine-annealed LR, and periodic restarts.
    """
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0)
    target = np.sqrt(2.0 * n)
    a = project_fixed_sum_nonneg(a, target)

    score = compute_objective(a)
    best = a.copy()
    best_score = score

    it = 0
    while it < max_iters:
        if time.monotonic() > deadline - 20.0:
            break

        # Adaptive beta: increase over time to focus on peaks
        frac = min(1.0, it / max_iters)
        beta = beta_init + (beta_max - beta_init) * frac

        # Learning rate with cosine annealing + periodic restarts
        cycle = it % restart_interval
        cycle_frac = cycle / restart_interval
        lr = lr_init * 0.5 * (1.0 + np.cos(np.pi * cycle_frac))
        lr = max(lr, 0.01)

        grad, c = soft_gradient_fft(a, beta, top_k=top_k)

        # Remove mean (fixed-sum constraint)
        grad -= grad.mean()

        a = a - lr * grad
        a = project_fixed_sum_nonneg(a, target)

        # Periodic evaluation
        if (it + 1) % 200 == 0:
            s = compute_objective(a)
            if s < best_score:
                best_score = s
                best = a.copy()

        # Periodic restart to escape local minima
        if (it + 1) % restart_interval == 0 and it > 0:
            rng = np.random.default_rng(it)
            noise = rng.random(n) * restart_magnitude
            a = (1.0 - restart_magnitude) * a + restart_magnitude * noise
            a = project_fixed_sum_nonneg(a, target)

        it += 1

    # Final evaluation
    s = compute_objective(a)
    if s < best_score:
        best_score = s
        best = a.copy()

    return best, best_score

def generate_thue_morse(n):
    """Generate Thue-Morse sequence of length n (0/1, balanced)."""
    tm = [0]
    for _ in range(n.bit_length()):
        tm += [1 - x for x in tm]
    return np.array(tm[:n], dtype=np.float64)


def generate_quadratic_residues(n, p=None):
    """Generate sequence based on quadratic residues mod p."""
    if p is None:
        # Find next prime >= n
        p = n
        while True:
            is_prime = True
            for i in range(2, int(np.sqrt(p)) + 1):
                if p % i == 0:
                    is_prime = False
                    break
            if is_prime and p % 4 == 3:
                break
            p += 1
    # Legendre symbol
    qr = np.zeros(n)
    for j in range(n):
        if j == 0:
            qr[j] = 0
        else:
            qr[j] = 1 if pow(j, (p - 1) // 2, p) != p - 1 else 0
    return qr


def generate_initializations(rng, lengths):
    """Generate diverse initial sequences for various lengths."""
    inits = []
    for n in lengths:
        # Uniform
        inits.append(np.ones(n) * 0.5)
        # Random
        inits.append(rng.random(n) * 0.5 + 0.25)
        # Chirp
        i = np.arange(n, dtype=np.float64)
        inits.append(0.5 + 0.5 * np.cos(2 * np.pi * i * 3.0 / n))
        # Raised cosine
        inits.append(0.3 + 0.7 * np.cos(np.pi * i / n)**2)
        # Gaussian bump
        center = n / 2.0
        inits.append(np.exp(-0.5 * ((i - center) / (n * 0.2))**2))
        # Two-tone
        inits.append(np.where(i < n // 2, 1.0, 0.3))
        # Sine wave
        inits.append(np.abs(np.sin(2 * np.pi * i * 7.0 / n)) + 0.1)
        # Thue-Morse smoothed
        tm = generate_thue_morse(n)
        # Smooth it
        kernel = np.ones(5) / 5.0
        tm_smooth = np.convolve(tm, kernel, mode='same')
        inits.append(0.5 + 0.5 * tm_smooth)
        # Quadratic residues
        if n >= 8:
            qr = generate_quadratic_residues(n)
            inits.append(0.3 + 0.7 * qr)

    return inits

            best_score = score
            best_seq = seq.copy()
            print(f"  New best: score={best_score:.6f}, n={len(seq)}, time={time.monotonic()-t_start:.1f}s")

    # Try to use provided initial sequence
    try:
        provided = np.asarray(height_sequence_1, dtype=np.float64)
        if provided.size >= 16 and np.all(np.isfinite(provided)):
            for L in [128, 256, 512, 1024]:
                if L <= len(provided):
                    a0 = provided[:L].copy()
                    update_best(a0, compute_objective(a0))
    except NameError:
        pass

    # Generate initializations at various lengths
    lengths = [128, 256, 512, 1024, 2048, 4096]
    inits = generate_initializations(rng, lengths)

    # Sort by length (shorter first for quick wins)
    inits.sort(key=lambda x: len(x))

    print(f"Starting search with {len(inits)} initializations, budget={budget_s}s")

    # Phase 1: Quick gradient optimization on all initializations
    for idx, a0 in enumerate(inits):
        if time.monotonic() > deadline - 60.0:
            break
        n = len(a0)
        t0 = time.monotonic()

        # Time allocation based on length
        time_per = min(30.0, max(10.0, (deadline - 60.0 - (time.monotonic() - t_start)) / max(1, len(inits) - idx)))
        mini_deadline = min(deadline - 30.0, t0 + time_per)

        if n <= 1024:
            seq, score = optimize_with_lp(a0, mini_deadline, max_lp_iters=30,
                                          grad_iters_between=100)
        else:
            seq, score = optimize_gradient(a0, mini_deadline,
                                           beta_init=5.0, beta_max=40.0,
                                           lr_init=0.25,
                                           max_iters=3000,
                                           restart_interval=400,
                                           restart_magnitude=0.08)

        if score < best_score:
            update_best(seq, score)

        elapsed = time.monotonic() - t0
        print(f"  Init {idx+1}/{len(inits)}: n={n}, score={score:.6f}, time={elapsed:.1f}s, best={best_score:.6f}")

    # Phase 2: Intensive refinement on best candidate
    if best_seq is not None:
        print(f"\nPhase 2: Intensive refinement (current best={best_score:.6f})")
        refine_deadline = deadline - 10.0
        n_best = len(best_seq)

        # Try spectral flat projection as a new starting point
        a_spec = spectral_flat_projection(best_seq, n_iters=30)
        s_spec = compute_objective(a_spec)
        if s_spec < best_score:
            update_best(a_spec, s_spec)

        # Multiple refinement passes
        for pass_i in range(8):
            if time.monotonic() > refine_deadline - 5.0:
                break

            if n_best <= 1024:
                seq, score = optimize_with_lp(best_seq, refine_deadline,
                                              max_lp_iters=50, grad_iters_between=100)
            else:
                # Multi-peak gradient for large n
                seq, score = optimize_gradient(best_seq, refine_deadline,
                                               beta_init=10.0, beta_max=60.0,
                                               lr_init=0.15,
                                               max_iters=5000,
                                               top_k=16,
                                               restart_interval=500,
                                               restart_magnitude=0.05)

            if score < best_score:
                update_best(seq, score)
                best_seq = seq
            else:
                # Try a different approach: spectral projection from current best
                a_spec2 = spectral_flat_projection(best_seq, n_iters=50)
                s2 = compute_objective(a_spec2)
                if s2 < best_score:
                    update_best(a_spec2, s2)
                    best_seq = a_spec2
                else:
                    break

    # Phase 3: Try different lengths around the best one
    if best_seq is not None and time.monotonic() < deadline - 30.0:
        print(f"\nPhase 3: Length exploration near n={len(best_seq)}")
        n_best = len(best_seq)
        candidate_lengths = set()
        for factor in [0.5, 0.75, 1.0, 1.25, 1.5, 2.0, 3.0]:
            L = int(n_best * factor)
            L = max(64, min(8192, L))
            # Make power of 2 for FFT efficiency
            L = 1 << int(round(np.log2(L)))
            L = max(64, min(8192, L))
            candidate_lengths.add(L)

        for L in sorted(candidate_lengths):
            if time.monotonic() > deadline - 15.0:
                break
            if L == n_best:
                continue

            # Use the best sequence as template (pad or truncate)
            if L <= n_best:
                a0 = best_seq[:L].copy()
            else:
                a0 = np.zeros(L)
                a0[:n_best] = best_seq
                # Interpolate the zeros
                for i in range(n_best, L):
                    a0[i] = best_seq[-1] * 0.5 + 0.25

            mini_deadline = min(deadline - 10.0, time.monotonic() + 40.0)
            if L <= 1024:
                seq, score = optimize_with_lp(a0, mini_deadline, max_lp_iters=30)
            else:
                seq, score = optimize_gradient(a0, mini_deadline,
                                               beta_init=10.0, beta_max=50.0,
                                               lr_init=0.2, max_iters=3000,
                                               top_k=8, restart_interval=400)
            if score < best_score:
                update_best(seq, score)

    # Final validation
    if best_seq is not None:
        final_score = compute_objective(best_seq)
        print(f"\nFinal: n={len(best_seq)}, score={final_score:.6f}")
        try:
            eval_score = float(evaluate_sequence([float(x) for x in best_seq]))
            print(f"evaluate_sequence: {eval_score:.6f}")
        except Exception as e:
            print(f"evaluate_sequence error: {e}")
        return [float(x) for x in best_seq]

    # Fallback
    print("Fallback: uniform sequence")
    return [1.0] * 256
