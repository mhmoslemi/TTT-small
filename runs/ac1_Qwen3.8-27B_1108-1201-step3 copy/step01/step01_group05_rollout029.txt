Let me think of a faster approach. Instead of solving the full LP, I can use a **first-order approximation**:

The LP is: max 1^T g s.t. A g <= M, g >= 0.

The KKT conditions give: g = max(0, lambda - A^T mu) for some dual variables mu >= 0, lambda >= 0.

A first-order method:
1. Initialize mu = 0, lambda = 1.
2. Compute g = max(0, lambda - A^T mu) / sum(max(0, lambda - A^T mu)).
3. Update: for each constraint m that is violated (A[m,:] @ g > M), increase mu[m].
4. Repeat.

This is essentially the **Dantzig-Wolfe decomposition** or **column generation** approach, but much simpler.

Actually, a even simpler approach: **multiplicative weight update**.

1. Initialize g = 1/n (uniform).
2. Compute b = convolve(p, g).
3. For each m, compute the "violation ratio" r_m = b[m] / M.
4. Update: g <- g * exp(-eta * w) where w_j = sum_m r_m * p[m-j] (with appropriate bounds).
   Actually, w_j = (r * p)[j] where r * p is the cross-correlation.
   More precisely: w_j = sum_m r_m * p[|m-j|]... no.
   
   The gradient of the constraint "A g <= M" with respect to g_j is A[:, j] = the column of the convolution matrix.
   So the "pressure" on g_j is: w_j = sum_m mu_m * A[m, j] where mu_m are the dual variables.
   
   In the multiplicative weight approach: mu_m = max(0, (A g)_m - M) / M (or some smooth approximation).
   Then w_j = sum_m mu_m * A[m, j] = sum_m mu_m * p[j] * 1[j <= m <= j+n-1]... 
   
   Actually, A[m, j] = p[j] if 0 <= m-j <= n-1.
   So w_j = p[j] * sum_{m: max(0, j) <= m <= min(2n-2, j+n-1)} mu_m.
   = p[j] * (prefix sum of mu at j+n-1 - prefix sum of mu at j-1).
   
   Then update: g_j <- g_j * exp(-eta * w_j) / normalization.

This is O(n) per iteration (after computing prefix sums), compared to O(n^2) for the LP. Much faster!

"""
Step-function search minimizing 2*n*max(convolve(p,p))/(sum(p))^2.
Uses a combination of soft best-response (multiplicative weights) and exact LP
for finding low-peak autocorrelation non-negative sequences.
"""

import time
import numpy as np
from scipy.fft import fft, ifft, next_fast_len
from scipy.optimize import linprog
from scipy.sparse import csr_matrix

# --- Core functions ---

def _conv_sq(p):
    """Self-convolution of p (full, length 2n-1)."""
    n = int(np.asarray(p).size)
    if n == 0:
        return np.empty(0)
    L = next_fast_len(2 * n - 1)
    F = fft(p, L)
    c = np.real(ifft(F * F))
    return c[:2 * n - 1]

def _cross_conv(p, q):
    """Cross-convolution of p and q (full, length 2n-1 for equal length)."""
    n = int(np.asarray(p).size)
    m = int(np.asarray(q).size)
    L = next_fast_len(n + m - 1)
    Fp = fft(p, L)
    Fq = fft(q, L)
    c = np.real(ifft(Fp * Fq))
    return c[:n + m - 1]

def _score(p):
    """Compute the objective: 2*n*max(conv)/(sum)^2."""
    p = np.asarray(p, dtype=np.float64)
    n = int(p.size)
    s = float(p.sum())
    if s < 1e-12:
        return np.inf
    c = _conv_sq(p)
    cmax = float(np.max(c)) if c.size > 0 else 0.0
    return 2.0 * n * cmax / (s * s)

def _project_simplex(v):
    """Project onto {x >= 0, sum(x) = 1}."""
    v = np.asarray(v, dtype=np.float64)
    n = int(v.size)
    if n == 0:
        return v
    v = np.where(np.isfinite(v), v, 0.0)
    u = np.sort(v)[::-1]
    cssum = np.cumsum(u)
    idx = np.arange(1, n + 1, dtype=np.float64)
    cond = (u * idx) > (cssum - 1.0)
    if not np.any(cond):
        return np.full(n, 1.0 / n)
    k = int(np.count_nonzero(cond) - 1)
    theta = (cssum[k] - 1.0) / float(k + 1)
    out = np.maximum(v - theta, 0.0)
    s = float(out.sum())
    if
