For a non-negative sequence to have flat autocorrelation, we'd need something like a "bang-bang" sequence (0s and 1s) with good autocorrelation properties, scaled down. But the non-negativity constraint makes it harder than the complex case.

Let me think about binary sequences. If f takes values in {0, c} with c = 1/weight (so sum = 1), and the binary pattern has low autocorrelation...

For a binary sequence of length n with weight w (number of 1s), f = (1/w) * b where b is 0-1.
(f*f)[k] = (1/w^2) * (b*b)[k]
max(f*f) = (1/w^2) * max(b*b)
score = 2*n*max(b*b)/w^2

For a "random" binary sequence with w = n/2:
(b*b)[k] ≈ w for k near n-1 (center), with fluctuations of order sqrt(w).
max(b*b) ≈ w + O(sqrt(w))
score ≈ 2*n*(w+O(sqrt(w)))/w^2 = 2n/(n/2) * (1 + O(1/sqrt(w))) = 4*(1+O(1/sqrt(n)))

That's worse than uniform (score 2). So binary sequences with weight n/2 are bad.

What about low-weight binary sequences? If w is small:
(b*b)[k] is at most w (when all 1s can overlap), but typically much less.
For w=1: f has one nonzero, score = 2n*(1/w^2)*1/w^2... wait let me redo.

If w=1: f has one element = 1, rest 0. (f*f)[0] = 1, max = 1. score = 2n*1/1 = 2n. Terrible.

So low-weight is bad. The sweet spot is somewhere between.

Actually, I think the key insight for the LP approach is:

The LP finds the best g to "mix" with f. If f is close to optimal, the LP will give g ≈ f (no improvement). If f is far from optimal, the LP gives a direction that significantly reduces the peak.

The challenge is: the LP is a local method (it only considers one step). To make global progress, we need:
1. Good initializations
2. Perturbations to escape local minima
3. Multiple restarts

```python
import numpy as np
import scipy.sparse as sp
from scipy.optimize import linprog
import time

def fast_score(f):
    f = np.asarray(f, dtype=np.float64)
    f = np.clip(f, 0.0, 1000.0)
    s = f.sum()
    if s < 0.01:
        return np.inf
    conv = np.convolve(f, f)
    return float(2.0 * len(f) * conv.max() / (s * s))

def build_conv_matrix(n, f):
    # A is (2n-1) x n, A[k,j] = f[k-j] if 0 <= k-j < n else 0
    # Using the structure: for each row k, the non-zero columns are j in [max(0,k-n+1), min(n-1,k)]
    rows = []
    cols = []
    vals = []
    for k in range(2*n-1):
        j_start = max(0, k - n + 1)
        j_end = min(n - 1, k)
        for j in range(j_start, j_end + 1):
            rows.append(k)
            cols.append(j)
            vals.append(f[k - j])
    A = sp.coo_matrix((vals, (rows, cols)), shape=(2*n-1, n)).tocsr()
    return A

def solve_lp(f, M, time_limit=5.0):
    n = len(f)
    A = build_conv_matrix(n, f)
    c = -np.ones(n)
    b = np.full(2*n-1, M)
    bounds = [(0, None)] * n
    try:
        res = linprog(c, A_ub=A, b_ub=b, bounds=bounds, method='highs',
                      options={'time_limit': time_limit})
        if res.status == 0:
            return np.maximum(res.x, 0)
    except:
        pass
    return None
```

Now, let me think about what's different from the previous approach:

1. **Spectral initialization**: Instead of just random/cosine, I'll try initializing with sequences that are designed to have flat autocorrelation. For example, the Fourier transform of a "flat" sequence.

2. **Adaptive LP with multiple M levels**: Instead of just M = max(f*f), try M = max(f*f) * (1 - delta) for several delta values. This forces more aggressive reduction.

3. **Subgradient descent as a fast inner loop**: Between LP calls, do a few steps of subgradient descent on the score function. This is much faster than LP and can make small improvements.

4. **Population-based search**: Keep a small population of diverse sequences and periodically crossbreed them.

```python
def subgradient_step(f, num_steps=10, lr=0.01):
    """Subgradient descent on the score function."""
    n = len(f)
    for _ in range(num_steps):
        conv = np.convolve(f, f)
        k_max = np.argmax(conv)
        M = conv[k_max]
        s = f.sum()
        if s < 1e-10:
            break
        # Subgradient of max_k (f*f)[k] w.r.t. f[j]
        # (f*f)[k_max] = sum_j f[j]*f[k_max-j]
        # d/d(f[j]) = f[k_max-j] + f[k_max-j] (if j != k_max-j) or 2*f[j] (if j = k_max-j)
        # Actually, d/d(f[j]) of sum_i f[i]*f[k-i] = f[k-j] + (1 if j == k-j else 0)*f[j]
        # Wait, more carefully: (f*f)[k] = sum_i f[i]*f[k-i]
        # d/d(f[j]) (f*f)[k] = f[k-j] + f[k-j] = 2*f[k-j] (for j != k-j)
        # If j = k-j (i.e., k is even and j = k/2): d/d(f[j]) = 2*f[j]... 
        # Actually no. Let's think again.
        # (f*f)[k] = sum_i f[i] * f[k-i]
        # The term f[i]*f[k-i] contributes to d/d(f[j]) when i=j or k-i=j
        # i=j: contributes f[k-j]
        # k-i=j, i=k-j: contributes f[k-j] (if k-j != j) or f[j] (if k-j = j)
        # So d/d(f[j]) = f[k-j] + f[k-j] = 2*f[k-j] generally
        # If k-j = j (i.e., k even, j=k/2): d/d(f[j]) = 2*f[j] (same thing)
        # Wait, that's still 2*f[k-j] = 2*f[j]. So it's always 2*f[k-j].
        
        # Hmm, let me verify with a simple example.
        # f = [a, b, c], k = 2
        # (f*f)[2] = f[0]*f[2] + f[1]*f[1] + f[2]*f[0] = a*c + b^2 + c*a = 2ac + b^2
        # d/da = 2c, d/db = 2b, d/dc = 2a
        # Using formula 2*f[k-j]: d/da = 2*f[2] = 2c ✓, d/db = 2*f[1] = 2b ✓, d/dc = 2*f[0] = 2a ✓
        
        # So the subgradient of score w.r.t. f[j] is:
        # d(score)/d(f[j]) = 2n/s^2 * 2*f[k_max-j] - 4n*M*f[j]/s^3
        # = (2n/s^2) * (2*f[k_max-j] - 4*M*f[j]/s)
        
        # We want to decrease score, so we go in the negative subgradient direction.
        # New f[j] = f[j] - lr * d(score)/d(f[j])
        # = f[j] - lr * (2n/s^2) * (2*f[k_max-j] - 4*M*f[j]/s)
        
        # But we need to project onto f >= 0 and maintain sum = 1 (or just f >= 0).
        
        # Actually, since score is scale-invariant, we don't need to maintain sum=1.
        # We just need f >= 0.
        
        # Let me simplify: we want to reduce (f*f)[k_max] while not increasing other lags too much.
        # A simple heuristic: reduce f[j] where f[k_max-j] is large (and j is in range).
        
        n = len(f)
        k = k_max
        # Build the subgradient
        grad = np.zeros(n)
        for j in range(n):
            idx = k - j
            if 0 <= idx < n:
                grad[j] = 2.0 * f[idx]
            else:
                grad[j] = 0.0
        # Also subtract the "sum" gradient
        # d(score)/d(f[j]) = 2n*grad[j]/s^2 - 4n*M*f[j]/s^3
        # = (2n/s^2)*(grad[j] - 2*M*f[j]/s)
        grad = grad - 2.0 * M * f / s
        # Step
        f_new = f - lr * grad
        f_new = np.maximum(f_new, 0)
        # Don't renormalize (scale invariant)
        f = f_new
    return f
```

Hmm, the subgradient approach is a bit tricky because the score involves both the max of the convolution AND the sum. Let me simplify.

Since the score is scale-invariant, I can work with sum(f)=1 and just minimize max_conv = max_k (f*f)[k].

The subgradient of max_conv w.r.t. f[j] is:
- If the max is unique at k*: d(max_conv)/d(f[j]) = 2*f[k*-j] (if 0 <= k*-j < n) else 0
- If there are multiple max lags, average the subgradients.

To minimize max_conv subject to sum(f)=1 and f>=0, use projected subgradient:
1. Compute g = subgradient of max_conv
2. f_new = f - lr * g
3. Project onto {x >= 0, sum(x) = 1}

The projection onto {x >= 0, sum(x) = 1} can be done via a simple algorithm (water-filling).

Actually, let me think about this more carefully. The problem is:
minimize max_k (f*f)[k]
subject to f >= 0, sum(f) = 1

This is a min-max problem. The subgradient approach works but converges slowly. The LP approach is better because it solves a related linear program exactly.

Let me focus on making the LP approach faster and more effective:

Key improvements:
1. **Warm start the LP solver** with the previous solution
2. **Use a tighter time limit** per LP call (2-3 seconds instead of 10) to do more iterations
3. **Adaptive step size**: use a larger step when the LP solution is very different from f, smaller when it's similar
4. **Perturbation at the right time**: when the LP stops making progress, add a structured perturbation
5. **Try multiple n values** in parallel (sequential, but with different time budgets)

Let me also think about a completely different approach: **direct non-convex optimization**.

The score function is:
score(f) = 2n * max_k sum_j f[j]*f[k-j] / (sum f)^2

If I fix the max to be achieved at a specific lag k*, the problem becomes:
minimize sum_j f[j]*f[k*-j]
subject to f[j]*f[k*-j'] <= M for all other lags k'
f >= 0, sum(f) = 1

This is still non-convex, but if I fix which lag achieves the max, it's a quadratic program with linear constraints. Not great, but potentially useful.

Actually, I think the best approach is still the LP-based one, but with better engineering:

1. **Fast convolution using FFT**: For large n, compute f*f using FFT instead of direct convolution. This is O(n log n) vs O(n^2).

2. **Sparse LP with better structure**: The constraint matrix A has a banded Toeplitz-like structure. I can exploit this for faster factorization.

3. **Multi-start with diverse initializations**: 
   - Random
   - Cosine / B-spline
   - Anti-symmetric perturbations of uniform
   - Random with "gaps" (blocks of zeros)
   - Sequences based on known low-peak autocorrelation patterns

4. ** annealing schedule for step size**: Start with large steps (t=0.5) and gradually reduce to small steps (t=0.01). Periodically "reheat" with a jump.

5. **Post-processing**: After the main search, do a fine-grained coordinate descent or Nelder-Mead on the best sequence.

Let me write the final code:

```python
"""
LP-driven iterative optimization with spectral initialization, adaptive
step sizes, FFT-accelerated convolution, and structured perturbations to
minimize the peak autocorrelation of a non-negative step function.

Score = 2*n*max(f*f)/(sum(f))^2, scale-invariant. Target: < 1.5027.
"""
import numpy as np
import scipy.sparse as sp
from scipy.optimize import linprog
import time


def fast_score(f):
    """Compute score quickly (same as evaluate_sequence but on numpy array)."""
    f = np.asarray(f, dtype=np.float64)
    f = np.clip(f, 0.0, 1000.0)
    s = f.sum()
    if s < 0.01:
        return np.inf
    n = len(f)
    if n <= 1024:
        conv = np.convolve(f, f)
    else:
        # Use FFT for larger sizes
        nfft = 2 * n
        F = np.fft.rfft(f, nfft)
        conv = np.fft.irfft(F * F, nfft)[:2*n-1]
    return float(2.0 * n * conv.max() / (s * s))


def fft_conv(f):
    """Full linear convolution via FFT."""
    n = len(f)
    nfft = 2 * n
    F = np.fft.rfft(f, nfft)
    return np.fft.irfft(F * F, nfft)[:2*n-1]


def direct_conv(f):
    """Full linear convolution directly."""
    return np.convolve(f, f)


def conv(f):
    """Choose convolution method based on size."""
    if len(f) <= 2048:
        return direct_conv(f)
    else:
        return fft_conv(f)


def build_conv_matrix(n, f):
    """Build sparse (2n-1) x n matrix where A[k,j] = f[k-j] for valid k-j."""
    # For row k, columns j range from max(0, k-n+1) to min(n-1, k)
    # Total non-zeros = n*(2n-1) - (n-1)*n/2*2 = 2n^2 - n - n^2 + n = n^2
    # Actually: sum over k=0 to 2n-2 of (min(n-1,k) - max(0,k-n+1) + 1)
    # = n*(2n-1) - ... let me just compute the offsets
    # Row k has min(n, k+1, 2n-1-k) non-zeros
    # Total = sum_{k=0}^{2n-2} min(n, k+1, 2n-1-k)
    # For k=0 to n-1: k+1 non-zeros (when k+1 <= n and k+1 <= 2n-1-k, i.e., k <= n-1 and k >= 0)
    # For k=n to 2n-2: 2n-1-k non-zeros
    # Total = sum_{k=0}^{n-1}(k+1) + sum_{k=n}^{2n-2}(2n-1-k) = n(n+1)/2 + n(n-1)/2 = n^2
    
    rows = []
    cols = []
    vals = []
    for k in range(2*n-1):
        j_start = max(0, k - n + 1)
        j_end = min(n - 1, k)
        count = j_end - j_start + 1
        rows.extend([k] * count)
        cols.extend(range(j_start, j_end + 1))
        vals.extend(f[k - j_start : k - j_start + count])
    A = sp.coo_matrix((vals, (rows, cols)), shape=(2*n-1, n)).tocsr()
    return A


def solve_lp(f, M, x0=None, time_limit=3.0):
    """Solve max sum(g) s.t. A*f-star-g <= M*1, g >= 0. Here A is built from f."""
    n = len(f)
    A = build_conv_matrix(n, f)
    c = -np.ones(n)
    b = np.full(2*n-1, M)
    bounds = [(0, None)] * n
    try:
        options = {'time_limit': time_limit}
        if x0 is not None:
            options['presolve'] = True
            res = linprog(c, A_ub=A, b_ub=b, bounds=bounds, method='highs',
                         options=options, x0=x0)
        else:
            res = linprog(c, A_ub=A, b_ub=b, bounds=bounds, method='highs',
                         options=options)
        if res.status == 0:
            return np.maximum(res.x, 0.0)
    except Exception:
        pass
    return None


def lp_step(f, t, M_shrink=1.0, time_limit=3.0):
    """One LP-driven step. Returns updated f (not normalized)."""
    c = conv(f)
    M = c.max() * M_shrink
    if M < 1e-15:
        return f
    g = solve_lp(f, M, time_limit=time_limit)
    if g is None:
        return f
    gs = g.sum()
    if gs < 1e-10:
        return f
    # Normalize g to have same sum as f
    s = f.sum()
    g = g * (s / gs)
    f_new = (1.0 - t) * f + t * g
    return np.maximum(f_new, 0.0)


def normalize(f):
    s = f.sum()
    if s < 1e-10:
        return f
    return f / s


def make_initial(n, rng, method):
    """Create initial sequence of length n."""
    if method == 'uniform':
        a = np.ones(n)
    elif method == 'cosine':
        x = np.linspace(0, np.pi, n)
        a = 0.5 * (1 + np.cos(x))
    elif method == 'sinc':
        x = np.linspace(-1, 1, n)
        a = np.sinc(x)  # sin(pi*x)/(pi*x)
        a = np.maximum(a, 0)
    elif method == 'gaussian':
        x = np.arange(n, dtype=float)
        a = np.exp(-0.5 * ((x - n/2) / (n/6))**2)
    elif method == 'two_gaussians':
        x = np.arange(n, dtype=float)
        a = np.exp(-0.5 * ((x - n/4) / (n/12))**2) + np.exp(-0.5 * ((x - 3*n/4) / (n/12))**2)
    elif method == 'antisymmetric':
        # f[j] = 1 + e*sin(2*pi*j/n) type perturbation
        x = np.arange(n, dtype=float)
        a = 1.0 + 0.5 * np.sin(2 * np.pi * x / n)
    elif method == 'antisymmetric2':
        x = np.arange(n, dtype=float)
        a = 1.0 + 0.5 * np.sin(4 * np.pi * x / n)
    elif method == 'bumpy':
        x = np.arange(n, dtype=float)
        a = 1.0 + 0.3 * np.sin(2*np.pi*x/n) + 0.2 * np.sin(4*np.pi*x/n) + 0.1 * np.sin(6*np.pi*x/n)
    elif method == 'random':
        a = rng.random(n)
    elif method == 'random_smooth':
        a = rng.random(n)
        # Smooth it
        kernel = np.ones(5) / 5
        a = np.convolve(a, kernel, 'same')
    elif method == 'binary_low_weight':
        # Sparse binary pattern
        w = max(2, n // 8)
        a = np.zeros(n)
        idx = rng.choice(n, size=w, replace=False)
        a[idx] = 1.0
    elif method == 'periodic_3':
        # Period-3 pattern: [a, b, c, a, b, c, ...]
        a = np.tile([1.0, 0.5, 0.8], n // 3 + 1)[:n]
    elif method == 'periodic_5':
        a = np.tile([1.0, 0.3, 0.7, 0.6, 0.4], n // 5 + 1)[:n]
    else:
        a = np.ones(n)
    a = np.maximum(a, 0.0)
    if a.sum() < 1e-10:
        a = np.ones(n)
    return a / a.sum()


def block_perturb(f, rng, max_width=None):
    """Random block multiplicative perturbation."""
    n = len(f)
    if max_width is None:
        max_width = max(3, n // 16)
    cand = f.copy()
    w = int(rng.integers(1, max_width + 1))
    start = int(rng.integers(0, max(1, n - w + 1)))
    stop = min(n, start + w)
    factor = np.exp(rng.normal(0, 0.3))
    cand[start:stop] *= factor
    cand = np.maximum(cand, 0)
    if cand.sum() < 1e-10:
        return f
    return cand / cand.sum()


def sinusoidal_perturb(f, rng, num_harmonics=3):
    """Add sinusoidal perturbations to escape local minima."""
    n = len(f)
    cand = f.copy()
    x = np.arange(n, dtype=float)
    for _ in range(num_harmonics):
        freq = rng.integers(1, n // 4 + 1)
        phase = rng.uniform(0, 2 * np.pi)
        amp = rng.uniform(0.05, 0.3)
        cand = cand * (1.0 + amp * np.sin(2 * np.pi * freq * x / n + phase))
    cand = np.maximum(cand, 0)
    if cand.sum() < 1e-10:
        return f
    return cand / cand.sum()


def run_lp_phase(f, deadline, t_init=0.4, t_min=0.02, t_decay=0.998,
                 lp_time=3.0, m_shrink=1.0):
    """Run LP iterations until deadline. Returns best f found."""
    f = f.copy()
    t = t_init
    best = f.copy()
    best_sc = fast_score(f)
    stall = 0
    it = 0
    rng_local = np.random.default_rng(it)
    
    while time.monotonic() < deadline:
        it += 1
        # Periodically reset M_shrink or perturb
        if stall > 40:
            f = sinusoidal_perturb(f, rng_local, num_harmonics=2)
            stall = 0
            t = max(t, 0.1)
        
        f_new = lp_step(f, t, M_shrink=m_shrink, time_limit=lp_time)
        moved = (not np.allclose(f_new, f, atol=1e-10))
        
        if not moved:
            f_new = block_perturb(f, rng_local)
        
        f = f_new
        t = max(t_min, t * t_decay)
        
        sc = fast_score(f)
        if sc < best_sc - 1e-10:
            best_sc = sc
            best = f.copy()
            stall = 0
        else:
            stall += 1
    
    return best, best_sc
```

"""
LP-driven optimization with multi-start, adaptive step sizes, and
structured perturbations to minimize the peak autocorrelation score
of a non-negative step function.
"""
import numpy as np
import scipy.sparse as sp
from scipy.optimize import linprog
import time


def fast_score(f):
    f = np.asarray(f, dtype=np.float64)
    f = np.clip(f, 0.0, 1000.0)
    s = f.sum()
    if s < 0.01:
        return np.inf
    n = len(f)
    if n <= 2048:
        cv = np.convolve(f, f)
    else:
        nfft = 2 * n
        F = np.fft.rfft(f, nfft)
        cv = np.fft.irfft(F * F, nfft)[:2*n-1]
    return float(2.0 * n * cv.max() / (s * s))


def conv_full(f):
    n = len(f)
    if n <= 2048:
        return np.convolve(f, f)
    else:
        nfft = 2 * n
        F = np.fft.rfft(f, nfft)
        return np.fft.irfft(F * F, nfft)[:2*n-1]


def build_A(n, f):
    rows_list = []
    cols_list = []
    vals_list = []
    for k in range(2*n-1):
        js = max(0, k - n + 1)
        je = min(n-1, k)
        cnt = je - js + 1
        rows_list.append(np.full(cnt, k))
        cols_list.append(np.arange(js, je+1))
        vals_list.append(f[k-js:k-js+cnt])
    rows = np.concatenate(rows_list)
    cols = np.concatenate(cols_list)
    vals = np.concatenate(vals_list)
    return sp.coo_matrix((vals, (rows, cols)), shape=(2*n-1, n)).tocsr()


def solve_lp(f, M, time_limit=3.0):
    n = len(f)
    A = build_A(n, f)
    c = -np.ones(n)
    b = np.full(2*n-1, M)
    bounds = [(0, None)] * n
    try:
        res = linprog(c, A_ub=A, b_ub=b, bounds=bounds, method='highs',
                     options={'time_limit': time_limit})
        if res.status == 0:
            return np.maximum(res.x, 0.0)
    except Exception:
        pass
    return None


def do_lp_step(f, t, shrink=1.0, lp_time=3.0):
    cv = conv_full(f)
    M = cv.max() * shrink
    if M < 1e-15:
        return None
    g = solve_lp(f, M, time_limit=lp_time)
    if g is None or g.sum() < 1e-12:
        return None
    # Scale g to same sum as f
    s_f = f.sum()
    s_g = g.sum()
    g = g * (s_f / s_g)
    new_f = (1.0 - t) * f + t * g
    new_f = np.maximum(new_f, 0.0)
    return new_f


def init_seq(n, method, rng):
