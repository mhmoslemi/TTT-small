### Approach and Rationale
The previous program primarily used linear programming (LP) to iteratively refine sequences. Our goal is to improve upon this by:
1. **Reducing High-Dimensionality Issues**: Using FFT-accelerated convolution calculations to minimize numerical overhead.
2. **Better Handling of Objective Smoothness**: Employing a smoothed version of the convolution maximum rather than segment-based LP constraints.
3. **Breaking Through Local Optima**: Adding an opponent phase that models the decision space more adversarially by considering how each component contributes to the convolution maximum.

This approach combines number theory with convex optimization and potentially better global exploration using factored updates and gradient projection.

### Mathematical Specification
We target the following smooth surrogate for the rigorous upper bound:

Let $F_T(a) = (2n/T) \cdot \log\left[\sum_{k=0}^{2n-2} \exp(b_k/T)\right]$, where $b_k = \text{full convolution}(a)$.

The constraints are:
- $n \geq 2$, meaning each $a_i$ must be non-negative.
- $0 \leq a_i \leq 1000$, with sum normalization $\sum a_i \approx 1$.

We'll solve two-stage surrogates:
1. First: a **convolution smoothing** to find the primary contribution.
2. Then: an **opponent-based optimization** to identify binding constraints from other positions.

### Implementation Procedure
1. **Initialization**:
   - Use a three-point strategy: cosine decay, exponential decay, and uniform noise.
   - Generate 15 initial candidates if no parent sequence exists.

2. **Phase 1: Convolution Smoothing** (Nesterov-style projection)
   - Build a sparse matrix of first-degree autocorrelation.
   - Smooth the convolution maximum using the LogSumExp penalty.
   - Compute gradient projection with FFT convolution.

3. **Phase 2: Opponent Simulation** (credit assignment)
   - For each position $i$, simulate its contribution by temporarily removing other coordinates' best response.
   - Update positions only if they have nonzero contribution and if their adjustment improves overall score.
   - Project back onto the simplex after each small perturbation.

4. **Stopping Conditions**:
   - When a candidate sequence yields a score below $\epsilon=1.502$.
   - When local optimization fails to improve for 200 steps.
   - When catastrophic cooling happens (score > 300*n) but this is unlikely.

def build_sparse_conv(n, T_mode=True):
    """Build sparse autocorrelation matrix for full convolution."""
    size = 2*n-1
    row_index, col_index, data = [], [], []
    
    # Create band structure for autocorrelation (like before)
    for i in range(n):  # input start points
        for j in range(i, size):
            if (j//n) == i or j == i and T_mode: # representative indices
                idx = j - i  # convolution point index
                # For each convolution point, add the input index as factor
                if idx < n: 
                    row_index.append(j)
                    col_index.append(i)
                    data.append(1.0)
                else:
                    break
    # Construct the matrix
    T_mat = np.zeros((size, n))
    for i in range(n):
        T_mat[i, i] = 1.0

def opponent_response(a, n,):
    """Simulates how a position changes the conv results when others adjust adversarially."""
    conv = np.convolve(a, a, mode='full')
    max_val = np.max(conv)
    
    # Identify top k contributing positions by importance

            'weight': a[i],
            'unsmoothed': b_val,
            'smoothed_down': nesterov_update(a[i] * 0.9, n) * 0.9
        })
    # Update the position with the response having highest gradient
    most_contribution = np.argmax([r['weight']*r['smoothed_down'] for r in responses])

def adversary_trick(a, n):
    """Attributes value contributions across positions via FT methods."""
    # Compute convolution bounds with smoothing

### Search Choices and Useful Variations
We maintain temperature parameter $T$ in $[1, 500]$, sequence length in $[3, 2000]$, and sampled candidates from multiple families:

1. **Gradient Adjustment Frequency**: Biweekly adjustment after 100 steps.
2. **Initial Families**: 
   - Linear segment (cosine decay)
   - Optimization residuals (exp weights)
   - Periodic noise (gaussian variations)
3. **Temperature Sweeping**:
   - Start high to explore, then decrease by $25\%$ each phase.

### Compute Budget and Robustness
Time budget splits as:
- $30\%$ for initial generation
- $40\%$ for heavy optimization (nesterov projection)
- $30\%$ for adversary phase

Handles:
- Time-out with sequence of 1-element fallback
- Type errors (clones defensive checks)
- Memory usage (sparse matrices)

### Validation and Return Contract
At every optimization step, we measure the score using the provided evaluate_sequence. If the system crashes, we have a parent normalization safeguard.

The algorithm returns the sequence with the smallest value found under 1800 seconds. If no improvement found, it outputs the highest-dimensional candidate validated during the session.
