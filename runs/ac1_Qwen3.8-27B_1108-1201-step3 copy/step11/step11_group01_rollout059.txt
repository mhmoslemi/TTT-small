**Method 2: Active-set peak reduction (new)**

Idea: Instead of using all peaks (as in LSE) or just the top one (as in subgradient), use a fixed active set of the top K peaks and optimize directly.

Algorithm:
1. Compute `b = a*a`
2. Find the top K peaks: `k_1, ..., k_K`
3. For the current active set, compute the "combined gradient":
   `g_j = (1/K) * sum_{i=1}^{K} a_{k_i - j}` (for valid indices)
4. Take a gradient descent step: `a_new = a - eta * g`
5. Project to simplex: `a_new = project_to_simplex(a_new)`
6. Update the active set if needed
7. Use adaptive step size

This is similar to the previous "subgradient_polish" but with the top K peaks instead of a threshold.

**Method 3: Alternating coordinate descent with LP**

Instead of Nesterov acceleration, use simple alternating:
1. Fix `a`, solve LP for `b*`
2. Set `a = b*`
3. Repeat

This is simpler but converges slower. However, it might escape different local minima.

def peak_reduction(a0, time_limit, K=50, eta_start=0.1, eta_end=0.001):
    """
    Polishing method that targets the top-K convolution peaks simultaneously.
    Uses Adam-like adaptive steps with momentum.
    """
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) / n
    a = a / s
    
    z = z_from_a(a)
    best_a = a.copy()
    best_score = score_normalized(a)
    t0 = time.monotonic()
    
    # Adam parameters
    beta1 = 0.9
    beta2 = 0.999
    eps = 1e-8
    m = np.zeros(n)  # First moment
    v = np.zeros(n)  # Second moment
    t = 0
    
    while time.monotonic() - t0 < time_limit:
        t += 1
        b = fast_convolve(a)
        
        # Find top K peaks
        K_actual = min(K, len(b))
        top_idx = np.argpartition(b, -K_actual)[-K_actual:]
        
        # Compute combined gradient
        g = np.zeros(n)
        for k in top_idx:
            js = max(0, k - n + 1)
            je = min(n - 1, k)
            idx = np.arange(js, je + 1)
            g[idx] += a[k - idx]
        g /= K_actual
        
        # Transform to z-space gradient
        S = np.dot(g, a)
        grad_z = a * (g - S)
        
        # Adam update
        m = beta1 * m + (1 - beta1) * grad_z
        v = beta2 * v + (1 - beta2) * grad_z ** 2
        m_hat = m / (1 - beta1 ** t)
        v_hat = v / (1 - beta2 ** t)
        
        eta = eta_start * (eta_end / eta_start) ** (t / max(1, int(10000)))
        z = z - eta * m_hat / (np.sqrt(v_hat) + eps)
        
        a_new = softmax_from_z(z)
        sc = score_normalized(a_new)
        
        if sc < best_score:
            best_score = sc
            best_a = a_new.copy()
        
        a = a_new
    
    return best_a, best_score

def nesterov_lp(a0, time_limit, max_iters=5000000):

        if sy < 1e-15:

        else:
            y_new = y_new / sy

            if elapsed - last_print > 5:
                print(f"    PeakRed t={t} ({elapsed:.0f}s): score={local_best_score:.8f}")
                last_print = elapsed
    
    return local_best_a, local_best_score
