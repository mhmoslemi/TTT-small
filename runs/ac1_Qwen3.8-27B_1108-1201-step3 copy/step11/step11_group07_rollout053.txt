The Lipschitz constant L: |∇f(a) - ∇f(b)| <= L * |a - b|. The Hessian of f involves the second derivatives of LSE, which are bounded by 1/T. So L ~ O(n^2 / T) approximately. This might be hard to estimate.

Or I can use a simpler approach: just do gradient descent with a fixed step size and momentum (heavy ball), which is simpler to implement.

Actually, let me use a different approach that I think will be more effective:

**Approach: Iterative water-filling / power allocation**

The key insight: We want to minimize max(c) subject to sum(a) = 1, a >= 0.

By KKT conditions, at the optimum:
- For each i with a_i > 0: sum_{k in S} ∂c(k)/∂a(i) = λ / a_i (where S is the set of active peaks)

This gives: a_i * sum_{k in S} 2*a(k-i) = λ (constant for all active i)

This is a system of equations that's hard to solve directly, but it suggests an iterative algorithm:
1. Start with a
2. Compute c, find S (active peaks)
3. For each i, compute s_i = sum_{k in S} 2*a(k-i)
4. Update: a_i <- a_i * sqrt(λ / s_i) (or a_i <- a_i * exp(-eta * s_i / sum(s)))
5. Re-normalize

This is similar to the multiplicative weights approach but with a more principled step size.

**Approach: Direct QP on the active set**

At the optimum, suppose the active set is S (peaks of c). Then we're solving:
minimize max_{k in S} c(k)
subject to a >= 0, sum(a) = 1
(with the understanding that at the optimum, c(k) = c(k') for all k, k' in S, and c(k) < max for k not in S)

This is equivalent to:
minimize t
subject to c(k) <= t for all k in S
         c(k) < t for all k not in S (this is the "inactive" constraint)
         a >= 0, sum(a) = 1

If we ignore the inactive constraints, this is a QCQP:
minimize t
subject to a^T D_k a <= t for all k in S (where D_k is a matrix such that c(k) = a^T D_k a)
         a >= 0, sum(a) = 1

Each constraint a^T D_k a <= t is a quadratic constraint. This can be solved as a SDP relaxation or directly with a QCQP solver.

But for n=1200, this QP has 1200 + 1 variables and |S| + n + 1 constraints. If |S| is small (say 10-100), this might be tractable.

Actually, the constraint a^T D_k a <= t can be written as a linear constraint on the lifted matrix X = aa^T:

"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
1. FISTA (accelerated proximal gradient) with LogSumExp smoothing and adaptive temperature annealing
2. Spectral-domain power spectrum flattening for initialization
3. Active-set multiplicative weight refinement
4. Multi-length exploration with interpolation rescaling
Key: O(n log n) per iteration via FFT, enabling thousands of iterations in budget.
"""

import numpy as np
import time
from scipy.fft import rfft, irfft

def fast_convolve(a):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(a, fft_size)
    return irfft(A * A, fft_size)[:size]

def compute_lse_objective_and_grad(a, T):
    """Compute LSE-smoothed objective and its gradient.
    a: 1D array, sum(a) = 1, a >= 0
    Returns: (obj, grad) where obj = 2n * LSE(c, T), grad = nabla obj
    """
    n = len(a)
    fft_size = 1 << (2*n - 2).bit_length()
    A = rfft(a, fft_size)
    c = irfft(A * A, fft_size)[:2*n-1]
    
    c_max = c.max()
    exp_c = np.exp((c - c_max) / T)
    w = exp_c / exp_c.sum()
    lse = c_max + T * np.log(exp_c.sum())
    obj = 2.0 * n * lse
    
    # grad(i) = 4n * sum_j w(i+j) * a(j)
    W = rfft(w, fft_size)
    grad = 4.0 * n * irfft(W * np.conj(A), fft_size)[:n]
    
    return obj, grad

def project_simplex(v):
    """Project v onto the probability simplex {x >= 0, sum(x) = 1}."""
    n = len(v)
    if n == 0:
        return v
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.nonzero(u * np.arange(1, n+1) > (cssv - 1))[0][-1]
    theta = (cssv[rho] - 1) / (rho + 1.0)
    return np.maximum(v - theta, 0)

def estimate_lipschitz(a, T):
    """Estimate Lipschitz constant of the gradient."""
    n = len(a)
    # The Hessian involves w and a, bounded roughly by 4n * (1/T) * max(c) * 2
    # Crude estimate: L ~ 8n^2 / T
    c = fast_convolve(a)
    return 8.0 * n * c.max() / T

def fista_optimize(a0, T_init, T_final, n_iters, time_budget):
    """FISTA optimization with LSE smoothing.
    a0: initial point (sum=1, a>=0)
    Returns best point found.
    """
    n = len(a0)
    a = a0.copy()
    a_prev = a.copy()
    t = 1.0
    best_a = a.copy()
    best_score = evaluate_local(a)
    t0 = time.monotonic()
    
    # Adaptive step size (backtracking)
    L = estimate_lipschitz(a, T_init)
    step = 1.0 / L
    max_step = 1.0 / (4.0 * n)  # upper bound on step
    step = min(step, max_step)
    
    T = T_init
    n_T_steps = max(1, n_iters // 20)
    T_ratio = (T_final / T_init) ** (1.0 / n_T_steps)
    
    for it in range(n_iters):
        if time.monotonic() - t0 > time_budget:
            break
        
        # Update temperature
        if (it + 1) % n_T_steps == 0:
            T = max(T * T_ratio, T_final)
        
        # FISTA momentum
        t_new = (1.0 + np.sqrt(1.0 + 4.0 * t * t)) / 2.0
        y = a + (t - 1.0) / t_new * (a - a_prev)
        y = np.maximum(y, 0)
        y = y / y.sum()  # renormalize to stay on simplex
        
        # Compute gradient at y
        obj, grad = compute_lse_objective_and_grad(y, T)
        
        # Gradient step + projection
        z = y - step * grad
        a_new = project_simplex(z)
        
        # Check improvement
        score = 2.0 * n * fast_convolve(a_new).max()
        if score < best_score:
            best_score = score
            best_a = a_new.copy()
        
        # Backtracking: if the step is too large, reduce it
        # (simplified: just check if objective increased)
        if obj > 2.0 * n * fast_convolve(a_new).max() * 1.5:
            step *= 0.5
        
        a_prev = a
        a = a_new
        t = t_new
    
    return best_a, best_score

def evaluate_local(a):
    """Evaluate score locally."""
    a = np.maximum(np.asarray(a, dtype=np.float64), 0)
    s = a.sum()
    if s < 0.01:
        return float('inf')
    n = len(a)
    b = fast_convolve(a)
    return float(2.0 * n * b.max() / (s * s))

def normalize(a):
    a = np.maximum(a, 0)
    s = a.sum()
    if s < 1e-15:
        return np.ones(len(a)) / len(a)
    return a / s

def spectral_flatten(a, n_iters=200, time_budget=30.0):
    """Flatten the power spectrum to reduce autocorrelation peaks."""
    n = len(a)
    a = normalize(a.copy())
    best_a = a.copy()
    best_score = evaluate_local(a)
    fft_size = 1 << (2*n - 2).bit_length()
    t0 = time.monotonic()
    
    lr = 0.01
    for it in range(n_iters):
        if time.monotonic() - t0 > time_budget:
            break
        
        A = rfft(a, fft_size)
        P = np.abs(A) ** 2
        P_mean = P.mean()
        
        # Direction to flatten P
        r = (P - P_mean) / (P_mean + 1e-15)
        H = np.zeros(A.shape, dtype=np.complex128)
        valid = P > 1e-10
        H[valid] = -r[valid] * A[valid]
        # Enforce real output
        h = irfft(H, fft_size)[:n]
        h -= h.mean()
        h_norm = np.linalg.norm(h)
        if h_norm < 1e-15:
            break
        h = h / h_norm
        
        # Line search
        for scale in [lr, lr*0.5, lr*0.1]:
            a_new = a + scale * h
            a_new = np.maximum(a_new, 0)
            s = a_new.sum()
            if s < 1e-15:
                continue
            a_new = a_new / s
            sc = evaluate_local(a_new)
            if sc < best_score:
                best_score = sc
                best_a = a_new.copy()
                a = a_new.copy()
            break
        
        if it % 50 == 0:
            lr *= 0.8
    
    return best_a, best_score

def multiplicative_refine(a, n_iters=5000, time_budget=50.0):
    """Multiplicative weights refinement targeting the active peaks."""
    n = len(a)
    a = normalize(a.copy())
    best_a = a.copy()
    best_score = evaluate_local(a)
    t0 = time.monotonic()
    eta = 0.05
    
    for it in range(n_iters):
        if time.monotonic() - t0 > time_budget:
            break
        
        c = fast_convolve(a)
        c_max = c.max()
        
        # Active set: peaks within 1% of max
        threshold = c_max * 0.99
        active = np.where(c >= threshold)[0]
        
        # Compute subgradient
        g = np.zeros(n)
        N = 1 << (2*n - 2).bit_length()
        w = np.zeros(2*n-1)
        w[active] = 1.0 / len(active)
        W = rfft(w, N)
        A = rfft(a, N)
        g = 4.0 * n * irfft(W * np.conj(A), N)[:n]
        
        # Multiplicative update
        a_new = a * np.exp(-eta * g / (g.max() + 1e-10))
        a_new = np.maximum(a_new, 0)
        s = a_new.sum()
        if s < 1e-15:
            eta *= 0.5
            continue
        a_new = a_new / s
        
        sc = evaluate_local(a_new)
        if sc < best_score:
            best_score = sc
            best_a = a_new.copy()
            a = a_new.copy()
        else:
            eta *= 0.8
            if eta < 1e-6:
                break
    
    return best_a, best_score

def diverse_init(n, rng):
    """Generate diverse initial sequences."""
    candidates = []
    x = np.linspace(0, 1, n)
    
    # Various shapes
    for alpha in [0.5, 1.0, 2.0, 3.0, 5.0]:
        a = (x * (1-x)) ** alpha
        candidates.append(normalize(a))
    
    # Cosine
    a = 0.5 * (1 + np.cos(2*np.pi*x))
    candidates.append(normalize(a))
    
    # Sine
    a = np.sin(np.pi*x)**2
    candidates.append(normalize(a))
    
    # Edge-peaked
    a = np.exp(-3*x) + np.exp(-3*(1-x))
    candidates.append(normalize(a))
    
    # Two bumps
    a = np.exp(-10*(x-0.3)**2) + np.exp(-10*(x-0.7)**2)
    candidates.append(normalize(a))
    
    # Random smooth
    for _ in range(3):
        coeffs = rng.normal(0, 1, 8)
        a = np.zeros(n)
        for i, c in enumerate(coeffs):
            a += c * np.cos(2*np.pi*(i+1)*x + rng.uniform(0, 2*np.pi))
        a = np.maximum(a + 1.0, 0)
        candidates.append(normalize(a))
    
    # Uniform
    candidates.append(np.ones(n) / n)
    
    return candidates

def interpolate_sequence(f, new_n):
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    f_norm = normalize(f)
    old_x = np.linspace(0, 1, old_n)
    new_x = np.linspace(0, 1, new_n)
    f_interp = np.interp(new_x, old_x, f_norm)
    return normalize(np.maximum(f_interp, 0))

"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
1. FFT-based spectral power spectrum flattening for fast initialization
2. FISTA (accelerated proximal gradient) with p-norm smoothing and adaptive p
3. Subgradient multiplicative weight updates for active-set refinement
4. Multi-restart with diverse perturbations
5. Multi-length exploration
All core operations are O(n log n) via FFT, enabling high iteration counts.
"""

import numpy as np
import time
from scipy.fft import rfft, irfft

# Global RNG for reproducibility
_global_rng = np.random.default_rng(12345)

def fast_convolve(a):
    """Linear auto-convolution via FFT. O(n log n)."""
    n = len(a)
    fft_size = 1 << (2 * n - 1).bit_length()
    A = rfft(a, fft_size)
    return irfft(A * A, fft_size)[:2 * n - 1]

def cross_corr(w, a):
    """Cross-correlation: result[i] = sum_k w[k] * a[k-i] (valid indices only)."""
    n = len(a)
    fft_size = 1 << (len(w) + n - 1).bit_length()
    W = rfft(w, fft_size)
    A = rfft(a, fft_size)
    return irfft(W * np.conj(A), fft_size)[:n]

def compute_pnorm_obj_grad(a, p):
    """Compute p-norm smoothed objective and gradient.
    f(a) = (mean(c^p))^(1/p) where c = conv(a,a)
    grad(i) = [2/(2n-1)] * c^{p-1} ⊛ a / f^{p-1}
    """
    n = len(a)
    fft_size = 1 << (2 * n - 1).bit_length()
    A = rfft(a, fft_size)
    c = irfft(A * A, fft_size)[:2 * n - 1]
    c = np.maximum(c, 0)  # autocorrelation of non-neg seq is non-neg
    
    c_p = c ** p
    mean_c_p = c_p.mean()
    f = mean_c_p ** (1.0 / p)
    
    if f < 1e-30:
        obj = 0.0
        grad = np.zeros(n)
    else:
        obj = 2.0 * n * f
        # grad(i) = [2n * (1/p) * f^{1-p} * (1/(2n-1)) * p] * sum_k c(k)^{p-1} * a(k-i)
        #         = [2n / (2n-1)] * f^{1-p} * (c^{p-1} ⊛ a)(i)
        c_pm1 = c ** (p - 1)
        grad = (2.0 * n / (2 * n - 1)) * (f ** (1 - p)) * cross_corr(c_pm1, a)
    
    return obj, grad

def compute_subgrad(a):
    """Compute subgradient of max(c) at a.
    Uses the largest few peaks (active set heuristic).
    Returns gradient vector of length n.
    """
    n = len(a)
    c = fast_convolve(a)
    c_max = c.max()
    
    # Active set: peaks within 0.1% of max
    threshold = c_max * (1.0 - 0.001)
    active = np.where(c >= threshold)[0]
    
    # Subgradient: uniform weight over active peaks
    w = np.zeros(2 * n - 1)
    w[active] = 1.0 / len(active)
    
    # grad(i) = 2 * sum_k w[k] * a(k-i)
    grad = 2.0 * cross_corr(w, a)
    
    return grad, c, active
