2. Compute the exact subgradient at the active set.
3. Project the negative subgradient onto the feasible set (non-negative, fixed sum) using a mirror map (logarithmic barrier or multiplicative weights).
4. Take the step.

This is essentially what the "state of the art" approach does, but I can make it more efficient and add diversification.

Additionally, I'll add:
- **Spectral projection**: After each step, project onto the set of sequences with "flattened" power spectrum (in a soft sense).
- **Multi-scale optimization**: Optimize at different "scales" (effectively different lengths) and interpolate.

Let me also think about the specific structure of near-optimal sequences. From signal processing, we know that:
- Barker sequences have optimal autocorrelation properties but are complex/±1 valued
- m-sequences (maximal length sequences) have two-level autocorrelation
- For real, non-negative sequences, the optimal might be related to "Golay complementary sequences" made non-negative

Actually, I recall that the problem of minimizing the peak autocorrelation of a non-negative sequence is related to the design of "low peak-to-average power ratio" (low PAPR) sequences in OFDM. The Gibbs algorithm and its variants are used for this.

**Gibbs algorithm for PAPR reduction:**
1. Start with a random sequence
2. At each iteration, find the time-domain sample with the highest magnitude
3. Multiply the entire sequence by a phase (in time domain, this is a frequency-domain phase rotation)
4. For real sequences, this becomes a "sign flip" or "negation" approach

But our constraint is non-negativity, not constant magnitude. So a direct application doesn't work.

However, the analogous operation for non-negative sequences is: multiply the sequence by `exp(-λ * conv_with_active_set)` in log-space, which is what multiplicative weights does.

Minimizes 2*n*max(conv(a,a))/sum(a)^2 using:
1. Fast FFT-based auto-convolution
2. LogSumExp-smoothed gradient with aggressive multi-stage temperature annealing
3. Exact active-set subgradient steps interspersed with LSE steps
4. Diverse spectral-based initialization
5. Adaptive population with crossover and mutation
6. Final fine-grained polish with very low temperature
Key: combines LSE smoothing for global progress with exact subgradient
for local precision, plus spectral initialization for diverse starts.
"""

import numpy as np
import time
from scipy.fft import rfft, irfft
from scipy.optimize import minimize


def fast_convolve(a):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(np.asarray(a, dtype=np.float64), fft_size)
    return irfft(A * A, fft_size)[:size]


def normalize(a):
    a = np.maximum(a, 0)
    s = a.sum()
    if s < 1e-15:
        return np.ones(len(a)) / len(a)
    return a / s


def evaluate_local(a):
    a = np.maximum(np.asarray(a, dtype=np.float64), 0)
    s = a.sum()
    if s < 0.01:
        return float('inf')
    n = len(a)
    b = fast_convolve(a)
    return float(2.0 * n * b.max() / (s * s))


def softmax_from_z(z):
    z_shifted = z - z.max()
    exp_z = np.exp(z_shifted)
    s = exp_z.sum()
    if s < 1e-300:
        return np.ones(len(z)) / len(z)
    return exp_z / s


def z_from_a(a):
    return np.log(np.maximum(a, 1e-30))


def lse_objective_and_grad(z, T):
    """Compute LSE-smoothed objective and gradient in z-space (log-softmax parameterization).
    z: log-probabilities, a = softmax(z), sum(a)=1.
    Objective: 2*n*LSE(conv(a,a)/T) ... actually 2*n*T*log(sum(exp(b/T)))
    """
    n = len(z)
    a = softmax_from_z(z)
    b = fast_convolve(a)  # length 2n-1
    b_max = b.max()
    exp_b = np.exp((b - b_max) / T)
    lse = b_max + T * np.log(exp_b.sum())
    obj = 2.0 * n * lse
    
    # Gradient w.r.t. a: g_a[m] = (1/T) * sum_k exp_b[k] * (db[k]/da[m]) / sum(exp_b)
    # db[k]/da[m] = 2*a[k-m] (with appropriate bounds)
    # So g_a[m] = (2/T) * sum_k (exp_b[k]/sum(exp_b)) * a[k-m]
    
    w = exp_b / exp_b.sum()  # softmax weights, length 2n-1
    
    # cross-correlation: g_a[m] = (2/T) * sum_k w[k] * a[max(0,min(n-1,k-m))]
    # = (2/T) * (w cross-correlate a)[m]
    # Using FFT: this is the cross-correlation of w (length 2n-1) and a (length n)
    # We want: x[m] = sum_k w[k] * a[k-m] for m = 0, ..., n-1
    # This equals sum_j w[j+m] * a[j] (substituting j = k-m)
    # = cross-correlation of a and w at lag m
    
    # FFT approach: pad w to length >= (2n-1)+n-1 and use ifft(fft(a)*conj(fft(w)))
    N = 1 << (3 * n - 3 - 1).bit_length()  # need at least 3n-3
    A_f = rfft(a, N)
    W_f = rfft(w, N)
    # ifft(fft(w) * conj(fft(a))) gives sum_j w[j] * a[j-m] (circular, which equals linear for our padding)
    # Actually: ifft(fft(w)*conj(fft(a)))[m] = sum_j w[j+m] * conj(a[j]) = sum_j w[j+m] * a[j] (real)
    # That's what we want! x[m] = sum_j w[j+m] * a[j]
    cross = irfft(W_f * np.conj(A_f), N)
    g_a = (2.0 / T) * cross[:n]
    
    # Transform to z-space: grad_z = a * (g_a - dot(g_a, a))
    S = np.dot(g_a, a)
    grad_z = a * (g_a - S)
    
    return obj, grad_z


def exact_subgradient_step(z, step_size):
    """Take one step using the exact subgradient of max(b)."""
    n = len(z)
    a = softmax_from_z(z)
    b = fast_convolve(a)
    b_max = b.max()
    
    # Active set: indices where b[k] == b_max (or very close)
    tol = 1e-10
    active = np.where(b >= b_max - tol)[0]
    
    # Compute subgradient g[m] = (1/|active|) * sum_{k in active} 2*a[k-m]
    g = np.zeros(n)
    for k in active:
        js = max(0, k - n + 1)
        je = min(n - 1, k)
        for m in range(js, je + 1):
            g[m] += 2.0 * a[k - m]
    g /= len(active)
    
    # Transform to z-space: grad_z = a * (g - dot(g, a))
    S = np.dot(g, a)
    grad_z = a * (g - S)
    
    # Step
    z_new = z - step_size * grad_z
    return z_new

def gradient_descent_lse(z0, time_limit, T, lr0=0.1, momentum=0.9):
    """Simple gradient descent with momentum on LSE objective."""
    n = len(z0)
    z = z0.copy().astype(np.float64)
    v = np.zeros(n)
    t0 = time.monotonic()
    best_obj = float('inf')
    best_z = z.copy()
    
    it = 0
    while time.monotonic() - t0 < time_limit:
        obj, grad = lse_objective_and_grad(z, T)
        if obj < best_obj:
            best_obj = obj
            best_z = z.copy()
        
        # Momentum
        v = momentum * v + (1 - momentum) * grad
        z_new = z - lr0 * v
        z = z_new
        it += 1
        
        if it % 100 == 0:
            lr0 *= 0.8
    
    return best_z, best_obj


def spectral_init(n, rng):
    """Initialize with a sequence whose power spectrum is designed to be flat."""
    # Start with random phase in frequency domain
    fft_size = 1 << (2 * n - 1 - 1).bit_length()
    # Random flat power spectrum with random phases
    P = np.ones(fft_size // 2 + 1)
    phases = rng.uniform(0, 2 * np.pi, fft_size // 2 + 1)
    phases[0] = 0
    A = P * np.exp(1j * phases)
    # Ensure real inverse
    A_full = np.zeros(fft_size, dtype=np.complex128)
    A_full[:fft_size//2+1] = A
    # For real signal: A[k] = conj(A[fft_size-k])
    for k in range(1, fft_size // 2 + 1):
        A_full[fft_size - k] = np.conj(A_full[k])
    a_full = irfft(A_full, fft_size)[:n]
    a = np.maximum(a_full, 0)
    s = a.sum()
    if s < 1e-10:
        return np.ones(n) / n
    return a / s


def diverse_init(n, rng, n_starts=20):
    """Generate diverse initial sequences."""
    candidates = []
    x = np.linspace(0, 1, n)
    
    # 1. Uniform
    candidates.append(np.ones(n) / n)
    
    # 2. Gaussian centered
    for sigma in [0.1, 0.2, 0.3, 0.4]:

    candidates.append(normalize(a))

        for amp in [0.3, 0.5, 0.7]:
            a = 1 + amp * np.cos(2*np.pi*freq*x)
            a = np.maximum(a, 0)
            candidates.append(normalize(a))
    
    # 5. Two bumps
    for pos in [(0.25, 0.75), (0.2, 0.8), (0.3, 0.7)]:
        a = np.exp(-20*(x-pos[0])**2) + np.exp(-20*(x-pos[1])**2)
        candidates.append(normalize(a))
    
    # 6. Polynomial
    for deg in [2, 3, 4, 6]:
        a = (x * (1-x)) ** (deg/2.0)
        candidates.append(normalize(a))
    
    # 7. Random smooth (low-frequency Fourier)
    for _ in range(5):
        coeffs = rng.normal(0, 1, 8)
        a = np.zeros(n)
        for i, c in enumerate(coeffs):
            a += c * np.cos(2*np.pi*(i+1)*x + rng.uniform(0, 2*np.pi))
        a = np.maximum(a + 0.5, 0)
        candidates.append(normalize(a))
    
    # 8. Spectral init
    for _ in range(3):
        candidates.append(spectral_init(n, rng))
    
    # 9. Discrete "chirp"
    for _ in range(3):
        freq0 = rng.uniform(1, 5)
        freq1 = rng.uniform(5, 15)
        phases = freq0 * 2*np.pi*x + (freq1-freq0) * 2*np.pi*x**2
        a = 1 + 0.5*np.cos(phases)
        a = np.maximum(a, 0)
        candidates.append(normalize(a))
    
    return candidates[:n_starts]


def interpolate_sequence(f, new_n):
    """Interpolate sequence to new length."""
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    f_norm = normalize(f)
    old_x = np.linspace(0, 1, old_n)
    new_x = np.linspace(0, 1, new_n)
    f_interp = np.interp(new_x, old_x, f_norm)
    f_interp = np.maximum(f_interp, 0)
    return normalize(f_interp)


def active_set_descent(z0, time_limit, max_iters=10000):
    """Optimize using exact active-set subgradient with backtracking."""
    n = len(z0)
    z = z0.copy()
    best_score = evaluate_local(softmax_from_z(z))
    best_z = z.copy()
    t0 = time.monotonic()
    step_size = 0.1
    no_improve = 0
    
    for it in range(max_iters):
        if time.monotonic() - t0 > time_limit:
            break
        
        a = softmax_from_z(z)
        b = fast_convolve(a)
        b_max = b.max()
        score = 2.0 * n * b_max  # since sum(a)=1
        
        if score < best_score:
            best_score = score
            best_z = z.copy()
            no_improve = 0
        else:
            no_improve += 1
        
        if no_improve > 20:
            step_size *= 0.7
            if step_size < 1e-6:
                break
            no_improve = 0
        
        # Active set
        tol = b_max * 1e-4
        active = np.where(b >= b_max - tol)[0]
        
        # Subgradient
        g = np.zeros(n)
        for k in active:
            js = max(0, k - n + 1)
            je = min(n - 1, k)
            for m in range(js, je + 1):
                g[m] += 2.0 * a[k - m]
        g /= len(active)
        
        # z-space gradient
        S = np.dot(g, a)
        grad_z = a * (g - S)
        
        # Backtracking line search
        for scale in [1.0, 0.5, 0.25, 0.1, 0.05]:
            z_new = z - step_size * scale * grad_z
            a_new = softmax_from_z(z_new)
            sc = evaluate_local(a_new)
            if sc < score:
                z = z_new
                break
        else:
            # No improvement, reduce step
            step_size *= 0.5
    
    return best_z, best_score
