At the optimum, for all `j` with `a_j > 0`:
`sum_k λ_k * a_{k-j} = constant`

This means that the "blurred" version of `a` (blurred by the peak weights `λ`) should be constant on the support of `a`. We can use this to define a quality metric and a correction direction.

**Algorithm based on KKT:**
1. Compute `h = conv(a, a)`, find active peaks `A`
2. Set `λ_k = 1/|A|` for `k in A`, `λ_k = 0` otherwise
3. Compute `v_j = sum_k λ_k * a_{k-j}` for each `j`
4. On the support of `a`, `v_j` should be constant. If not, adjust `a` to make it more constant:
   - Where `v_j > average`, decrease `a_j`
   - Where `v_j < average`, increase `a_j`
5. Repeat

```python
def kkt_guided_step(a, n_active=10):
    n = len(a)
    h = fast_convolve(a)
    # Find top n_active peaks
    top_k = np.argsort(h)[::-1][:n_active]
    # Uniform weights on top peaks
    weights = np.zeros(2*n-1)
    for k in top_k:
        weights[k] = 1.0 / n_active
    # Compute v_j = sum_k weights[k] * a[k-j]
    v = np.zeros(n)
    for j in range(n):
        for k in top_k:
            m = k - j
            if 0 <= m < n:
                v[j] += weights[k] * a[m]
    # On support of a, v should be constant
    support = a > 1e-10
    if support.sum() > 0:
        mean_v = v[support].mean()
        # Correction: where v > mean, decrease a; where v < mean, increase a
        correction = mean_v - v
        # Apply correction to a (mirror descent style)
        a_new = a * (1.0 + 0.1 * correction / (a + 1e-10))
        a_new = np.maximum(a_new, 0)
        a_new = a_new / a_new.sum()
        return a_new
    return a
```

This is O(n * n_active) per step, which is very fast. We can take many iterations of this.
