"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
1. Nesterov-accelerated LSE-smoothed gradient with adaptive step size
2. FFT-based O(n log n) gradient computation
3. Multi-temperature annealing with running average tracking
4. Peak-shaving coordinate descent for final polish
5. Multi-length exploration with interpolation transfer
"""

import numpy as np
import time
from scipy.fft import rfft, irfft


def fast_autocorr(a):
    """Full convolution a*a using FFT. Returns array of length 2n-1."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(np.asarray(a, dtype=np.float64), fft_size)
    return irfft(A * A, fft_size)[:size]


def project_simplex(v):
    """Project vector v onto the probability simplex {x >= 0, sum(x) = 1}."""
    n = len(v)
    if v.sum() < 1e-15:
        return np.ones(n) / n
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.nonzero(u * np.arange(1, n + 1) > (cssv - 1))[0][-1]
    theta = (cssv[rho] - 1) / (rho + 1.0)
    w = np.maximum(v - theta, 0)
    s = w.sum()
    if s < 1e-15:
        return np.ones(n) / n
    return w / s


def compute_lse_grad(a, T):
    """
    Compute (value, gradient, weights) of LSE-smoothed max of autocorrelation.
    f_T(a) = (1/T) * log(sum_k exp(T * (a*a)_k))
    Returns: (f_val, grad, w) where w are the softmax weights.
    """
    n = len(a)
    b = fast_autocorr(a)
    Tb = T * b
    max_Tb = Tb.max()
    exp_Tb = np.exp(Tb - max_Tb)
    f_val = (max_Tb + np.log(exp_Tb.sum())) / T
    w = exp_Tb / exp_Tb.sum()
    
    # Gradient: grad[i] = 2 * sum_k w[k] * d(a*a)[k]/da[i]
    # Use FFT cross-correlation
    conv_len = n + (2 * n - 1) - 1  # = 3n-2
    fft_size = 1 << (conv_len - 1).bit_length()
    if conv_len > fft_size:
        fft_size *= 2
    
    A_rev = rfft(a[::-1].copy(), fft_size)
    W = rfft(w, fft_size)
    conv = irfft(A_rev * W, fft_size)
    grad = 2.0 * conv[n - 1:n - 1 + n]
    
    return f_val, grad, w

        a = np.ones(n) / n
    else:
        a = a / s
    
    best_a = a.copy()
    best_raw = 2.0 * n * fast_autocorr(a).max()  # Raw objective (sum=1 normalization)
    t0 = time.monotonic()
    
    temps = np.geomspace(T_start, T_end, n_stages)
    
    for si, T in enumerate(temps):
        if time.monotonic() - t0 > time_limit:
            break
        remaining = time_limit - (time.monotonic() - t0)
        if remaining < 5:
            break
        
        # Nesterov state
        x = a.copy()  # Current point
        y = a.copy()  # Extrapolation point
        x_prev = a.copy()
        
        # Initial step size (conservative)
        lr = 1.0 / (4.0 * n)

                y_new = x_new + momentum * (x_new - x)

One issue: the Nesterov acceleration with simplex projection. The standard Nesterov method works on smooth convex functions in unconstrained space. With the simplex constraint, we need to project after each step, which breaks the theoretical guarantees. However, in practice, this "projected Nesterov" often works well.

A better approach: use the **exponential weights** (mirror descent) for the simplex constraint instead of Euclidean projection. The Bregman divergence for the simplex (with entropy regularization) leads to the multiplicative weights update:
a_new[i] = a_old[i] * exp(-lr * grad[i]) / sum_j a_old[j] * exp(-lr * grad[j])

This is the **Hedge** algorithm or **multiplicative weights**. Combined with Nesterov acceleration, this gives the **accelerated Hedge** or **OSR (Online Subgradient with Regret)** method.

The advantage of multiplicative weights is that it naturally maintains non-negativity and the sum constraint (after normalization).

Let me use this approach:

```

    Compute grad = ∇f(y)
    # Multiplicative weights update
    z = y * exp(-lr_t * grad)
    z = z / z.sum()  # Normalize
    # Nesterov extrapolation
    y_new = z + momentum * (z - y_prev)
    y_new = project_simplex(y_new)  # Ensure feasibility
    y_prev = y
    y = y_new
```

The step size for multiplicative weights: lr_t = sqrt(2 * log(n) / (T * L)) where T is the total number of iterations and L is the gradient norm bound.

But we don't know T in advance, so we use a diminishing step size: lr_t = c / sqrt(t) for some constant c.

Actually, for the Nesterov-accelerated version, the step size should be 1/(L*t) (same as gradient descent Nesterov), and the update is:
z_i = y_i * exp(-lr_t * grad_i) / sum(y_j * exp(-lr_t * grad_j))

This is actually not quite right for Nesterov. Let me think...

The standard Nesterov for smooth convex f:
x_{t+1} = x_t - (1/L) ∇f(y_t)
y_{t+1} = x_{t+1} + (t/(t+2)) (x_{t+1} - x_t)

For the mirror descent version (with entropy regularizer):
x_{t+1} = argmin_x (1/L) <∇f(y_t), x> + D_Ω(x, y_t)
where D_Ω is the Bregman divergence and Ω is the regularizer.

For Ω(x) = sum x_i log x_i - sum x_i (negative entropy) and constraint sum(x)=1, x>=0:
x_{t+1}[i] = y_t[i] * exp(-grad_t[i]/L) / sum_j y_t[j] * exp(-grad_t[j]/L)

This is the multiplicative weights update. The Nesterov acceleration then applies to the y sequence.
