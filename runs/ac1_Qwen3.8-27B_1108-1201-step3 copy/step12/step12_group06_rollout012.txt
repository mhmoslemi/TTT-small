```
   b. Compute subgradient g = 2 * a reversed/shifted at k*
   c. Project g onto tangent space: g_proj = g - mean(g)*1 (or g - <g,a>/sum(a^2) * a for log-param)
   d. Take step: a_new = project_simplex(a - eta * g_proj)
   e. If a_new is better, accept; else reduce eta
4. Periodically re-identify active peaks and use their average
```

Actually, I think the most effective approach combines:
1. **Fast subgradient with momentum** (Nesterov acceleration) for the bulk of the optimization
2. **LSE refinement** at the end for fine-tuning
3. **Multiple diverse starting points** to avoid local minima

Let me now write the actual code. I'll focus on making it fast and effective:

Key design decisions:
- Use numpy FFT for all convolutions
- Use the top-K LSE with FFT-accelerated gradients for the main optimization
- Use Nesterov momentum for the subgradient method
- Try n values from 800 to 2000
- Use warm-starting from the parent sequence

Let me also think about the FFT-based gradient computation more carefully:

Given `w` (length 2n-1, the weights on the peaks) and `a` (length n):
We want `g[j] = sum_{k=0}^{2n-2} w[k] * a[k-j]` for j=0,...,n-1
(where a[k-j] = 0 if k-j not in [0,n-1])

This is the cross-correlation of w and a. In FFT terms:
`g = ifft(fft(w, N) * conj(fft(a, N)))[:n]`

Wait, let me verify. The cross-correlation of x and y is:
`(x ⋆ y)[j] = sum_k x[k+j] * conj(y[k])`

In numpy, `np.correlate(x, y, mode='full')` gives:
`c[j] = sum_k x[k] * conj(y[k-j+n-1])`

Hmm, let me just use the definition directly:
`g[j] = sum_k w[k] * a[k-j]`

Substituting m = k-j: `g[j] = sum_m w[m+j] * a[m]`

This is the cross-correlation of w and a (shifted). In FFT:
If we compute `ifft(FFT(w) * conj(FFT(a)))`, we get:
`(w ⋆ a)[j] = sum_k w[k+j] * a[k]` (for circular correlation with appropriate padding)

So with zero-padding to size N >= (2n-1) + n - 1 = 3n-2, we get:
`g = ifft(FFT(w,N) * conj(FFT(a,N)))[:n]`

Let me verify: 
`ifft(FFT(w,N) * conj(FFT(a,N)))[j] = sum_k w[k] * a[(k-j) mod N]`

For j < n and with N > 2n-1, `(k-j) mod N = k-j` when 0 <= k-j < N, which is true when 0 <= k and k-j >= 0, i.e., k >= j.
But we also need k-j < n (for a[k-j] to be non-zero), so k < j+n.
And k < 2n-1 (for w[k] to be non-zero).

So `g[j] = sum_{k=max(0,j)}^{min(2n-2, j+n-1)} w[k] * a[k-j]`

This is exactly what we want! (Since a[k-j] = 0 for k-j >= n, the upper bound is effectively min(2n-2, j+n-1) = j+n-1 for j < n.)

Great, so the FFT-based gradient is:
```python
def compute_grad_a(a, w, n):
    """Compute grad_a = (2n/T) * 2 * cross_correlate(w, a)[:, :]
    where w has length 2n-1."""
    fft_size = 1 << (3*n - 2).bit_length()  # Need N >= 3n-2
    W = rfft(w, fft_size)
    A = rfft(a, fft_size)
    g = irfft(W * np.conj(A), fft_size)[:n]
    return 4.0 * n * g  # (2n/T) * 2 = 4n/T, but T is factored out
```

Wait, I need to be more careful with the constants. Let me define:
- Objective: `f(a) = (2n/T) * LSE_T(b_top)` where `LSE_T(v) = log(sum(exp(v/T)))`... 

Actually, let me use the standard formulation. If we want to approximate `max_k b_k` (for k in the top set), we use:
`LSE(b_top) = log(sum_{k in top} exp(b_k / T)) * T`... 

No, the standard LogSumExp is: `log(sum(exp(b_top / T)))` which approximates `max(b_top)` as T→0.

So the smoothed objective is: `(2n) * T * log(sum_{k in S} exp(b_k / T))` where S is the set of peaks we're tracking.

The gradient: `d/da [(2n) * T * log(sum exp(b_k/T))] = (2n) * T * [sum_k exp(b_k/T) * (1/T) * db_k/da] / [sum_k exp(b_k/T)]`
`= (2n) * [sum_k exp(b_k/T) * db_k/da] / [sum_k exp(b_k/T)]`
`= (2n) * sum_k w_k * db_k/da`

where `w_k = exp(b_k/T) / sum_j exp(b_j/T)`.

And `db_k/da_i = 2*a_{k-i}` (as derived above).

So: `grad_a = (2n) * sum_k w_k * 2 * a_{k-i} = (4n) * cross_correlate(w_extended, a)`

where `w_extended` is w placed at the appropriate positions in a vector of length 2n-1.

Great, so the full gradient computation per LSE evaluation is:
1. Compute b = conv(a,a) via FFT: O(n log n)
2. Compute top-K indices and weights: O(K)
3. Compute grad_a via FFT cross-correlation: O(n log n)
4. Convert to z-gradient: O(n)

Total: O(n log n) per iteration, which is much faster than the full LSE (which was O(n^2) in the loop over k).

Now, for the L-BFGS optimizer, each function+gradient evaluation takes O(n log n). With n=1200, that's very fast. L-BFGS should be able to do many iterations per second.

Let me now write the complete solution:

```python
"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
1. FFT-accelerated top-K LogSumExp with L-BFGS
2. Nesterov-accelerated subgradient with active peak tracking
3. Multi-length exploration with diverse initializations
4. Symmetry exploitation and local refinement
"""

import numpy as np
import time
from scipy.fft import rfft, irfft
from scipy.optimize import minimize

def fast_convolve(a):
    """Fast linear convolution via FFT."""
    a = np.asarray(a, dtype=np.float64)
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(a, fft_size)
    return irfft(A * A, fft_size)[:size]

def score_normalized(a):
    """Score assuming sum(a)=1: returns 2*n*max(b)."""
    n = len(a)
    b = fast_convolve(a)
    return 2.0 * n * b.max()

def evaluate_safe(a):
    """Safely call evaluate_sequence."""
    try:
        a_list = [float(max(0.0, min(1000.0, x))) for x in a]
        if len(a_list) == 0:
            return float('inf')
        s = sum(a_list)
        if s < 0.01:
            return float('inf')
        return float(evaluate_sequence(a_list))
    except Exception:
        return float('inf')

def project_simplex(v):
    """Project onto probability simplex {x >= 0, sum(x) = 1}."""
    n = len(v)
    if v.sum() < 1e-15:
        return np.ones(n) / n
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    rho_arr = np.where(cond)[0]
    if len(rho_arr) == 0:
        return np.ones(n) / n
    rho = rho_arr[-1]
    theta = (cssv[rho] - 1) / (rho + 1.0)
    return np.maximum(v - theta, 0)

def topk_lse_obj_grad(z, T, topk, n):
    """
    Compute top-K LogSumExp objective and gradient w.r.t. z (log-param).
    a = softmax(z), working in log-space for positivity.
    """
    # Compute a from z (stable softmax)
    z_shifted = z - z.max()
    exp_z = np.exp(z_shifted)
    a = exp_z / exp_z.sum()
    
    # Compute convolution
    b = fast_convolve(a)
    
    # Get top-K peaks
    if topk >= len(b):
        topk = len(b)
    top_idx = np.argpartition(b, -topk)[-topk:]
    top_idx = np.sort(top_idx)
    b_top = b[top_idx]
    
    # LogSumExp
    max_b = b_top.max()
    exp_b = np.exp((b_top - max_b) / T)
    w_top = exp_b / exp_b.sum()
    lse_val = T * (max_b / T + np.log(exp_b.sum()))
    obj = 2.0 * n * lse_val
    
    # Build full weight vector (length 2n-1)
    w_full = np.zeros(len(b))
    for i, k in enumerate(top_idx):
        w_full[k] = w_top[i]
    
    # Compute grad_a via FFT cross-correlation
    # grad_a[j] = (4n) * sum_k w_full[k] * a[k-j] (for valid k-j)
    fft_size = 1 << (3 * n).bit_length()
    W = rfft(w_full, fft_size)
    A = rfft(a, fft_size)
    grad_a = 4.0 * n * irfft(W * np.conj(A), fft_size)[:n]
    
    # Convert to z-gradient: grad_z = a * (grad_a - dot(grad_a, a))
    S = np.dot(grad_a, a)
    grad_z = a * (grad_a - S)
    
    return obj, grad_z

def lse_lbfgs_optimize(a0, time_limit, T_start=50.0, T_end=0.5, n_stages=15, topk=30, max_iter_per_stage=50):
    """
    Multi-stage LSE L-BFGS optimization with decreasing temperature.
    """
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0).copy()
    s = a.sum()
    if s < 1e-15:
        return a0, score_normalized(a0)
    a = a / s
    
    z = np.log(np.maximum(a, 1e-300)).copy()
    best_a = a.copy()
    best_score = score_normalized(a)
    t0 = time.monotonic()
    
    for stage in range(n_stages):
        if time.monotonic() - t0 > time_limit:
            break
        remaining = time_limit - (time.monotonic() - t0)
        if remaining < 2:
            break
        
        # Temperature for this stage
        frac = stage / max(1, n_stages - 1)
        T = T_start * (T_end / T_start) ** frac
        
        def func(z_val):
            obj, _ = topk_lse_obj_grad(z_val, T, topk, n)
            return obj
        
        def jac(z_val):
            _, grad = topk_lse_obj_grad(z_val, T, topk, n)
            return grad
        
        try:
            res = minimize(
                fun=func, x0=z, jac=jac, method='L-BFGS-B',
                options={'maxiter': max_iter_per_stage, 'ftol': 1e-16,
                         'gtol': 1e-12, 'maxfun': max_iter_per_stage * 200,
                         'disp': False}
            )
            z = res.x
            a_new = np.exp(z - z.max())
            a_new = a_new / a_new.sum()
            sc = score_normalized(a_new)
            
            if sc < best_score:
                best_score = sc
                best_a = a_new.copy()
                
        except Exception as e:
            pass
    
    return best_a, best_score

def nesterov_subgrad(a0, time_limit, topk=20, n_iters=1000000):
    """
    Nesterov-accelerated subgradient with top-K peak averaging.
    """
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0).copy()
    s = a.sum()
    if s < 1e-15:
        return a0, score_normalized(a0)
    a = a / s
    
    y = a.copy()  # Nesterov's y
    best_a = a.copy()
    best_score = score_normalized(a)
    t0 = time.monotonic()
    eta0 = 1.0 / np.sqrt(n)  # Initial step size
    
    for it in range(n_iters):
        if time.monotonic() - t0 > time_limit:
            break
        
        # Compute convolution at y
        b = fast_convolve(y)
        
        # Get top-K peaks
        if topk >= len(b):
            topk_use = len(b)
        else:
            topk_use = topk
        top_idx = np.argpartition(b, -topk_use)[-topk_use:]
        b_top = b[top_idx]
        
        # Weights (simple: uniform over top-K, or softmax with small T)
        # Use softmax with T relative to the spread
        spread = b_top.max() - b_top.min()
        if spread > 1e-15:
            T_w = spread * 0.1
            exp_w = np.exp((b_top - b_top.max()) / T_w)
            w_top = exp_w / exp_w.sum()
        else:
            w_top = np.ones(topk_use) / topk_use
        
        # Build full weight vector
        w_full = np.zeros(len(b))
        for i, k in enumerate(top_idx):
            w_full[k] = w_top[i]
        
        # Compute subgradient via FFT cross-correlation
        # grad[j] = sum_k w_full[k] * 2 * a_y[k-j]
        # We need to use y (not a) for the gradient evaluation point
        fft_size = 1 << (3 * n).bit_length()
        W = rfft(w_full, fft_size)
        Y = rfft(y, fft_size)
        grad = 2.0 * irfft(W * np.conj(Y), fft_size)[:n]
        
        # Nesterov step
        t_k = (1.0 + np.sqrt(1.0 + 4.0 * (it + 1) ** 2)) / 2.0
        alpha = 2.0 / (t_k + 1.0)
        momentum = (t_k - 1.0) / t_k
        eta = eta0 / np.sqrt(it + 1)
        
        a_old = a.copy()
        a_new = project_simplex(a - eta * grad)
        y_new = a_new + momentum * (a_new - a_old)
        y_new = np.maximum(y_new, 0)
        sy = y_new.sum()
        if sy > 1e-15:
            y_new = y_new / sy
        else:
            y_new = a_new.copy()
        
        a = a_new
        y = y_new
        
        sc = score_normalized(a)
        if sc < best_score:
            best_score = sc
            best_a = a.copy()
        
        if (it + 1) % 50000 == 0:
            elapsed = time.monotonic() - t0
            print(f"    NSG iter={it+1} ({elapsed:.0f}s): score={best_score:.8f}")
    
    return best_a, best_score

def diverse_init(n, rng):
    """Generate diverse initial sequences."""
    choice = rng.integers(0, 10)
    x = np.linspace(0, 1, n)
    if choice == 0:
        a = np.sin(np.pi * x) ** 2
    elif choice == 1:
        a = 1.0 + 0.3 * np.cos(2 * np.pi * 2 * x) + 0.1 * np.cos(2 * np.pi * 5 * x)
    elif choice == 2:
        a = 1.0 + 0.2 * np.cos(2 * np.pi * 3 * x + 0.5) + 0.15 * np.cos(2 * np.pi * 7 * x + 1.0)
    elif choice == 3:
        a = np.exp(-0.5 * ((x - 0.3) / 0.15) ** 2) + 0.5 * np.exp(-0.5 * ((x - 0.7) / 0.15) ** 2)
    elif choice == 4:
        # Random Fourier
        k_max = 10
        coeffs = rng.normal(0, 1, k_max + 1)
        phases = rng.uniform(0, 2 * np.pi, k_max + 1)
        a = np.ones(n)
        for k in range(1, k_max + 1):
            a += coeffs[k] * np.cos(2 * np.pi * k * x + phases[k])
    elif choice == 5:
        a = 1.0 + 0.25 * np.sin(2 * np.pi * 4 * x) + 0.1 * np.cos(2 * np.pi * 11 * x)
    elif choice == 6:
        # Triangular
        a = 1.0 - 2.0 * np.abs(x - 0.5)
    elif choice == 7:
        # Flat top with edges
        a = np.ones(n)
        edge = max(1, n // 10)
        a[:edge] = np.linspace(0.5, 1.0, edge)
        a[-edge:] = np.linspace(1.0, 0.5, edge)
    elif choice == 8:
        #product of cosines
        a = np.abs(np.cos(np.pi * x) * np.cos(2 * np.pi * x) * np.cos(3 * np.pi * x))
    else:
        a = 1.0 + 0.2 * np.cos(2 * np.pi * np.arange(n) * 6.0 / n) + 0.1 * np.cos(2 * np.pi * np.arange(n) * 13.0 / n)
    
    a = np.maximum(a, 0.0)
    s = a.sum()
    if s < 1e-15:
        return np.ones(n) / n
    return a / s

def interpolate_to_length(a, new_n):
    """Interpolate sequence to new length."""
    old_n = len(a)
    if old_n == new_n:
        return a.copy()
    s = a.sum()
    if s < 1e-15:
        return np.ones(new_n) / new_n
    a_norm = a / s
    old_x = np.linspace(0, 1, old_n)
    new_x = np.linspace(0, 1, new_n)
    a_interp = np.interp(new_x, old_x, a_norm)
    a_interp = np.maximum(a_interp, 0)
    ss = a_interp.sum()
    if ss > 1e-15:
        a_interp = a_interp / ss
    return a_interp

def local_refinement(a0, time_limit, n_peaks=10):
    """
    Local refinement: focus on the top few peaks and use direct optimization.
    Uses the fact that at optimum, active peaks should have equal values.
    """
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0).copy()
    s = a.sum()
    if s < 1e-15:
        return a0, score_normalized(a0)
    a = a / s
    
    best_a = a.copy()
    best_score = score_normalized(a)
    t0 = time.monotonic()
    
    # Use very low temperature LSE focused on top peaks
    for T in [5.0, 2.0, 1.0, 0.5, 0.2, 0.1, 0.05]:
        if time.monotonic() - t0 > time_limit:
            break
        
        z = np.log(np.maximum(a, 1e-300))
        topk = max(5, n_peaks)
        
        def func(z_val):
            obj, _ = topk_lse_obj_grad(z_val, T, topk, n)
            return obj
        
        def jac(z_val):
            _, grad = topk_lse_obj_grad(z_val, T, topk, n)
            return grad
        
        try:
            res = minimize(
                fun=func, x0=z, jac=jac, method='L-BFGS-B',
                options={'maxiter': 100, 'ftol': 1e-16,
                         'gtol': 1e-14, 'maxfun': 5000, 'disp': False}
            )
            z = res.x
            a_new = np.exp(z - z.max())
            a_new = a_new / a_new.sum()
            sc = score_normalized(a_new)
            if sc < best_score:
                best_score = sc
                best_a = a_new.copy()
                a = a_new
        except Exception:
            pass
    
    return best_a, best_score
```

"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
1. FFT-accelerated top-K LogSumExp with L-BFGS (much faster than full LSE)
2. Nesterov-accelerated subgradient with active peak tracking via FFT cross-correlation
3. Multi-stage temperature annealing
4. Multi-length exploration with diverse initializations
5. Local refinement with peak equalization
Key innovation: O(n log n) gradient computation via FFT cross-correlation,
enabling far more optimizer iterations within the time budget.

import numpy as np
import time

from scipy.optimize import minimize

# Global state to avoid closures

def fast_convolve(a):
    """Fast linear convolution via FFT."""
    a = np.asarray(a, dtype=np.float64)
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(a, fft_size)
    return irfft(A * A, fft_size)[:size]


def score_normalized(a):
    """Score assuming sum(a)=1: returns 2*n*max(b)."""
    n = len(a)
    b = fast_convolve(a)
    return 2.0 * n * b.max()


def evaluate_safe(a):
    """Safely call evaluate_sequence."""
    try:
        a_list = [float(max(0.0, min(1000.0, x))) for x in a]
        if len(a_list) == 0:

        s = sum(a_list)
        if s < 0.01:

    except Exception:

def project_simplex(v):
    """Project onto probability simplex {x >= 0, sum(x) = 1}."""
    n = len(v)
    if v.sum() < 1e-15:
        return np.ones(n) / n
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    rho_arr = np.where(cond)[0]
    if len(rho_arr) == 0:
        return np.ones(n) / n
    rho = rho_arr[-1]
    theta = (cssv[rho] - 1) / (rho + 1.0)
    return np.maximum(v - theta, 0)


def topk_lse_obj_grad(z, T, topk, n):
    """
    Compute top-K LogSumExp smoothed objective and gradient w.r.t. log-parameter z.
    a = softmax(z). Objective: 2n * T * log(sum_{k in topK} exp(b_k/T)).
    Gradient computed in O(n log n) via FFT cross-correlation.
    """
    # Compute a from z (stable softmax)
    z_shifted = z - z.max()
    exp_z = np.exp(z_shifted)
    a = exp_z / exp_z.sum()

    # Compute convolution
    b = fast_convolve(a)

    # Get top-K peaks
    if topk >= len(b):
        topk = len(b)
    top_idx = np.argpartition(b, -topk)[-topk:]
    b_top = b[top_idx]

    # LogSumExp value
    max_b = b_top.max()
    scaled = (b_top - max_b) / T
    exp_b = np.exp(scaled)
    w_top = exp_b / exp_b.sum()
    lse_val = T * (max_b / T + np.log(exp_b.sum()))
    obj = 2.0 * n * lse_val

    # Build full weight vector (length 2n-1)
    w_full = np.zeros(len(b))
    for i, k in enumerate(top_idx):
        w_full[k] = w_top[i]

    # Compute grad_a via FFT cross-correlation:
    # grad_a[j] = (4n) * sum_k w_full[k] * a[k-j]
    # This equals 4n * (w_full cross-correlate a)
    fft_size = 1 << (3 * n).bit_length()
    W = rfft(w_full, fft_size)
    A = rfft(a, fft_size)
    grad_a = 4.0 * n * irfft(W * np.conj(A), fft_size)[:n]

    # Convert to z-gradient: grad_z = a * (grad_a - dot(grad_a, a))
    S = np.dot(grad_a, a)
    grad_z = a * (grad_a - S)

    return obj, grad_z


def lse_lbfgs_optimize(a0, time_limit, T_start, T_end, n_stages, topk, max_iter_per_stage):
    """
    Multi-stage LSE L-BFGS optimization with geometrically decreasing temperature.
    Returns (best_a, best_score).
    """
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0).copy()
    s = a.sum()
    if s < 1e-15:
        return a0.copy(), score_normalized(a0)
    a = a / s

    z = np.log(np.maximum(a, 1e-300)).copy()
    best_a = a.copy()
    best_score = score_normalized(a)
    t0 = time.monotonic()

    for stage in range(n_stages):
        if time.monotonic() - t0 > time_limit:
            break
        remaining = time_limit - (time.monotonic() - t0)
        if remaining < 2:
            break

        # Geometric temperature schedule
        frac = stage / max(1, n_stages - 1)
        T = T_start * (T_end / T_start) ** frac

        def _func(z_val):
            obj, _ = topk_lse_obj_grad(z_val, T, topk, n)
            return obj

        def _jac(z_val):
            _, grad = topk_lse_obj_grad(z_val, T, topk, n)
            return grad

        try:
            res = minimize(
                fun=_func, x0=z, jac=_jac, method='L-BFGS-B',
                options={'maxiter': max_iter_per_stage, 'ftol': 1e-16,
                         'gtol': 1e-12, 'maxfun': max_iter_per_stage * 300,
                         'disp': False}
            )
            z = res.x
            a_new = np.exp(z - z.max())
            a_new = a_new / a_new.sum()
            sc = score_normalized(a_new)

            if sc < best_score:
                best_score = sc
                best_a = a_new.copy()

        except Exception:
            pass

    return best_a, best_score


def nesterov_subgrad(a0, time_limit, topk, n_iters):
    """
    Nesterov-accelerated subgradient with top-K peak tracking.
    Uses FFT cross-correlation for O(n log n) gradient per step.
    """
    n = len(a0)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0).copy()
    s = a.sum()
    if s < 1e-15:
        return a0.copy(), score_normalized(a0)
    a = a / s

    y = a.copy()  # Nesterov lookahead
    best_a = a.copy()
    best_score = score_normalized(a)
    t0 = time.monotonic()
    eta0 = 2.0 / np.sqrt(n)

    for it in range(n_iters):
        if time.monotonic() - t0 > time_limit:
            break

        # Compute convolution at y (lookahead point)
        b = fast_convolve(y)

        # Get top-K peaks
        if topk >= len(b):
            topk_use = len(b)
        else:
            topk_use = topk
        top_idx = np.argpartition(b, -topk_use)[-topk_use:]
        b_top = b[top_idx]

        # Softmax weights over top peaks (with adaptive temperature)
        spread = b_top.max() - b_top.min()
        if spread > 1e-15:
            T_w = max(spread * 0.05, 1e-10)
            exp_w = np.exp((b_top - b_top.max()) / T_w)
            w_top = exp_w / exp_w.sum()
        else:
            w_top = np.ones(topk_use) / topk_use

        # Build full weight vector
        w_full = np.zeros(len(b))
        for i, k in enumerate(top_idx):
            w_full[k] = w_top[i]

        # Compute subgradient via FFT cross-correlation
        # grad[j] = 2 * sum_k w_full[k] * y[k-j]
        fft_size = 1 << (3 * n).bit_length()
        W = rfft(w_full, fft_size)
        Y = rfft(y, fft_size)
        grad = 2.0 * irfft(W * np.conj(Y), fft_size)[:n]

        # Nesterov step size
        t_k = (1.0 + np.sqrt(1.0 + 4.0 * (it + 1) ** 2)) / 2.0
        alpha = 2.0 / (t_k + 1.0)
        momentum = (t_k - 1.0) / t_k
        eta = eta0 / np.sqrt(it + 1)

        a_old = a.copy()
        a_new = project_simplex(a - eta * grad)
        y_new = a_new + momentum * (a_new - a_old)
        y_new = np.maximum(y_new, 0)
        sy = y_new.sum()
        if sy > 1e-15:
            y_new = y_new / sy
        else:
            y_new = a_new.copy()

        a = a_new
        y = y_new

        sc = score_normalized(a)
        if sc < best_score:
            best_score = sc
            best_a = a.copy()

        if (it + 1) % 100000 == 0:
            elapsed = time.monotonic() - t0
            print(f"    NSG iter={it+1} ({elapsed:.0f}s): score={best_score:.8f}")

    return best_a, best_score

def interpolate_to_length(a, new_n):
    """Interpolate a normalized sequence to a new length."""
    old_n = len(a)
    if old_n == new_n:
        return a.copy()
    s = a.sum()
    if s < 1e-15:
        return np.ones(new_n) / new_n
    a_norm = a / s
    old_x = np.linspace(0, 1, old_n)
    new_x = np.linspace(0, 1, new_n)
    a_interp = np.interp(new_x, old_x, a_norm)
    a_interp = np.maximum(a_interp, 0)
    ss = a_interp.sum()
    if ss > 1e-15:
        a_interp = a_interp / ss
    return a_interp
