c[n-1] = sum_{i=0}^{n-1} a[i]*a[n-1-i] = sum_{i=0}^{n-1} (n-i)*(i+1)
= sum of (n-i)(i+1) for i=0 to n-1
= sum of (ni + n - i^2 - i)
= n*sum(i) + n^2 - sum(i^2) - sum(i)
= n*n(n-1)/2 + n^2 - n(n-1)(2n-1)/6 - n(n-1)/2
= n^2(n-1)/2 + n^2 - n(n-1)(2n-1)/6 - n(n-1)/2

Actually, for a = [n, n-1, ..., 1], the convolution c[k] is related to the "autocorrelation" of the arithmetic sequence. Let me think...

c[k] = sum_{i=max(0,k-n+1)}^{min(n-1,k)} a[i]*a[k-i] = sum a[i]*a[k-i]

For a[i] = n-i:
c[k] = sum (n-i)(n-(k-i)) = sum (n-i)(n-k+i) over valid i.

Let j = k-i, so i = k-j:
c[k] = sum (n-k+j)(n-j) over valid j.

This is a sum of (n-k+j)(n-j) = n(n-k) - n*j + (n-k)*j - j^2 = n(n-k) + j(n-k-n) - j^2 = n(n-k) - k*j - j^2.

So c[k] = num_terms * n(n-k) - k * sum(j) - sum(j^2)

where j ranges over the valid range.

For 0 <= k <= n-1: i ranges from 0 to k, so j = k-i ranges from k down to 0, i.e., j = 0, 1, ..., k.
num_terms = k+1.
sum(j) = k(k+1)/2.
sum(j^2) = k(k+1)(2k+1)/6.

c[k] = (k+1)*n*(n-k) - k*k(k+1)/2 - k(k+1)(2k+1)/6
