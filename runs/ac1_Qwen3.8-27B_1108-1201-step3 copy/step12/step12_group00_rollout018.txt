f[i] = sum_j a[j] * w[j+i] = (a ⋆ w)[i] for i = 0, ..., n-1
= ifft(fft(a, N) * conj(fft(w, N)))[i] where N >= n + (2n-1) - 1 = 3n-2

g[i] = sum_j a[j] * w[i-j]
Let me rewrite: sum_j a[j] * w[i-j] = sum_j w[i-j] * a[j]
Let k = i-j: sum_k w[k] * a[i-k] = (w * a)[i] (convolution of w and a at index i)
= ifft(fft(w, N) * fft(a, N))[i] where N >= (2n-1) + n - 1 = 3n-2

So:
N = next_power_of_2(3*n - 2)
A_f = fft(a, N) = rfft(a, N) (for real signals)
W_f = rfft(w, N)

f = irfft(A_f * conj(W_f), N)[:n]  # cross-correlation (a ⋆ w)[0:n]
g = irfft(W_f * A_f, N)[:n]  # convolution (w * a)[0:n]

grad = f + g

Now, for the optimization algorithm, let me design a complete approach:

**Algorithm: Spectral-Gradient Frank-Wolfe with Nesterov Acceleration**

1. Initialize a (from parent or structured init)
2. Normalize: sum(a) = sqrt(2n)
3. Nesterov loop:
   a. Compute R = autocorr(y) (where y is the Nesterov lookahead point)
   b. Compute weights w on the peaks (LSE or top-k)
   c. Compute gradient g = weighted subgradient at y
   d. Find the FW vertex: v = sqrt(2n) * e_{argmin(g)}
   e. Nesterov update: z = (1-α)*y + α*v, y_new = z + momentum*(z-y)
   f. Project: y_new = max(y_new, 0), rescale to sum = sqrt(2n)
   g. Track best solution
4. Periodically evaluate and keep the best

Key improvements:
- Use LSE weighting for smoother gradients (not just the single max peak)
- Use Nesterov acceleration
- Periodic "reset" of Nesterov momentum to avoid overshooting
- Adaptive: if progress stalls, try a different initialization or length

Let me also add a **spectral shaping** step that works in the frequency domain:

**Spectral Shaping Step:**
1. Compute A = rfft(a, N)
2. Compute P = |A|^2
3. Compute target: P_target = P^α for some α < 1 (this compresses the dynamic range, making the spectrum flatter)
4. Update: A_new = A * (P_target / P)^(1/2) = A * P^((α-1)/2)
   (This reduces the amplitude at high-power frequencies and increases it at low-power frequencies)
5. a_new = irfft(A_new, N)[:n]
6. a_new = max(a_new, 0)
7. Rescale

The parameter α controls how aggressive the flattening is. α = 1 means no change. α = 0.5 means square-root compression.

Actually, a better approach: instead of P^α, use a "water-filling" approach:
- P_target(f) = max(P(f) - C, ε) for some constant C (shave the peaks)
- Then redistribute the shaved energy to the valleys

Or even simpler: P_target(f) = P(f) - C * max(0, P(f) - threshold)
Then A_new = A * sqrt(P_target / P)

1. Coarse scale: optimize a "smoothed" version of a (e.g., a convolved with a Gaussian) to find the global envelope
2. Fine scale: optimize the details within that envelope

"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using:
1. Nesterov-accelerated Frank-Wolfe with LSE multi-peak gradient (primary)
2. Spectral domain flattening (P^alpha compression)
3. Adaptive step size with backtracking
4. Multi-length exploration with interpolation transfer
5. Local peak shaving for final polish

import numpy as np
import time
from scipy.fft import rfft, irfft


def fast_autocorr(a):
    """Compute full linear autocorrelation via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(np.asarray(a, dtype=np.float64), fft_size)
    return irfft(A * A, fft_size)[:size]


def compute_objective(a):
    """Compute 2*n*max(conv(a,a))/(sum(a))^2."""
    n = len(a)
    s = a.sum()
    if s < 0.01:
        return float('inf')
    R = fast_autocorr(a)
    return 2.0 * n * R.max() / (s * s)


def gradient_lse(a, temp=1.0):
    """Compute LSE-weighted subgradient of max autocorrelation.
    
    Returns (gradient, R, max_R) where gradient[i] = sum_k w[k] * subgrad_k[i]
    and w[k] = exp(R[k]/temp) / sum(exp(R[k']/temp)).
    """
    n = len(a)
    R = fast_autocorr(a)
    max_R = R.max()
    if max_R < 1e-30:
        return np.zeros(n), R, max_R
    
    # LSE weights
    weights = np.exp((R - max_R) / temp)
    w_sum = weights.sum()
    if w_sum < 1e-30:
        # Fallback: uniform weight on max peak
        weights = np.zeros(len(R))
        weights[int(np.argmax(R))] = 1.0
    else:
        weights /= w_sum
    
    # Compute gradient via FFT
    # grad[i] = f[i] + g[i]
    # f[i] = sum_j a[j] * w[j+i] (cross-correlation of a and w)
    # g[i] = sum_j a[j] * w[i-j] (convolution of w and a)
    
    N = 1 << (3 * n - 2).bit_length()
    A_f = rfft(a, N)
    W_f = rfft(weights, N)
    
    f = irfft(A_f * np.conj(W_f), N)[:n]  # cross-correlation (a ⋆ w)
    g = irfft(W_f * A_f, N)[:n]  # convolution (w * a)
    
    grad = f + g
    return grad, R, max_R


def nesterov_fw_optimize(a0, time_limit, temp=1.0, verbose=True):
    """Nesterov-accelerated Frank-Wolfe with LSE gradient."""
    n = len(a0)
    norm = np.sqrt(2.0 * n)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0)
    s0 = a.sum()
    if s0 < 1e-15:
        a = np.ones(n) * norm / n
    else:
        a = a * norm / s0
    
    best_a = a.copy()
    best_score = compute_objective(a)
    t0 = time.monotonic()
    
    y = a.copy()
    avg_a = np.zeros(n)
    n_avg = 0
    n_iters = 0
    
    for t in range(1, 1000000):
        if time.monotonic() - t0 > time_limit:
            break
        
        # Compute gradient at y
        grad, R, max_R = gradient_lse(y, temp=temp)
        
        # FW vertex: put all mass at argmin of gradient
        i_min = int(np.argmin(grad))
        v = np.zeros(n)
        v[i_min] = norm
        
        # Nesterov update
        alpha = 2.0 / (t + 2.0)
        y_new = (1.0 - alpha) * y + alpha * v
        y_new = np.maximum(y_new, 0.0)
        s_y = y_new.sum()
        if s_y < 1e-15:
            y_new = y.copy()
        else:
            y_new = y_new * norm / s_y
        
        if t == 1:
            a_new = v.copy()
        else:
            momentum = (t - 1.0) / (t + 2.0)
            a_new = y_new + momentum * (y_new - y)
            a_new = np.maximum(a_new, 0.0)
            s_a = a_new.sum()
            if s_a < 1e-15:
                a_new = y_new.copy()
            else:
                a_new = a_new * norm / s_a
        
        y = y_new
        a = a_new
        n_iters += 1
        
        # Track best (use y for stability)
        score_y = compute_objective(y)
        if score_y < best_score:
            best_score = score_y
            best_a = y.copy()
        
        # Running average
        avg_a += a
        n_avg += 1
        if n_avg % 50 == 0:
            avg_check = avg_a / n_avg
            s_avg = avg_check.sum()
            if s_avg > 1e-15:
                avg_check = avg_check * norm / s_avg
                score_avg = compute_objective(avg_check)
                if score_avg < best_score:
                    best_score = score_avg
                    best_a = avg_check.copy()
        
        if verbose and n_iters % 200 == 0:
            elapsed = time.monotonic() - t0
            print(f"    NFW t={t} ({elapsed:.0f}s): best={best_score:.8f}, iter={n_iters}")
    
    return best_a, best_score


def spectral_flatten(a0, time_limit, alpha=0.7, verbose=False):
    """Spectral domain flattening: compress the power spectrum."""
    n = len(a0)
    norm = np.sqrt(2.0 * n)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0)
    s0 = a.sum()
    if s0 < 1e-15:
        a = np.ones(n) * norm / n
    else:
        a = a * norm / s0
    
    best_a = a.copy()
    best_score = compute_objective(a)
    t0 = time.monotonic()
    
    N = 1 << (2 * n - 1).bit_length()
    
    for step in range(10000):
        if time.monotonic() - t0 > time_limit:
            break
        
        A = rfft(a, N)
        P = np.abs(A) ** 2
        P_max = P.max()
        if P_max < 1e-30:
            break
        
        # Compress: P_new = P^alpha / (P^alpha).max() * P_max
        # This reduces dynamic range
        P_compressed = P ** alpha
        P_ratio = P_compressed / P  # This is P^(alpha-1), < 1 where P is large
        # Scale to maintain energy
        P_ratio = P_ratio * (P.sum() / P_compressed.sum())
        P_ratio = np.clip(P_ratio, 0.5, 2.0)  # Limit per-step change
        
        A_new = A * np.sqrt(P_ratio)
        a_new = irfft(A_new, N)[:n]
        a_new = np.maximum(a_new, 0.0)
        s_new = a_new.sum()
        if s_new < 1e-15:
            break
        a_new = a_new * norm / s_new
        
        score = compute_objective(a_new)
        if score < best_score:
            best_score = score
            best_a = a_new.copy()
            a = a_new
        else:
            # Reduce alpha (less aggressive)
            alpha = max(0.95, alpha * 0.99)
            if alpha > 0.999:
                break
    
    if verbose:
        print(f"    Spectral flatten: best={best_score:.8f}")
    return best_a, best_score


def peak_shave(a0, time_limit, seed=42, verbose=False):
    """Local coordinate descent: shave peaks by redistributing mass."""
    n = len(a0)
    rng = np.random.default_rng(seed)
    norm = np.sqrt(2.0 * n)
    a = np.maximum(np.asarray(a0, dtype=np.float64), 0.0)
    s0 = a.sum()
    if s0 < 1e-15:
        a = np.ones(n) * norm / n
    else:
        a = a * norm / s0
    
    best_a = a.copy()
    best_score = compute_objective(a)
    t0 = time.monotonic()
    stall = 0
    
    while time.monotonic() - t0 < time_limit:
        R = fast_autocorr(a)
        k_star = int(np.argmax(R))
        
        # Find the "source" index that contributes most to the peak
        js = max(0, k_star - n + 1)
        je = min(n - 1, k_star)
        idx = np.arange(js, je + 1)
        contrib = a[idx] * a[k_star - idx]
        src = idx[np.argmax(contrib)]
        
        # Find good "destination" indices (low contribution to all top peaks)
        top_k = np.argsort(R)[::-1][:5]
        peak_mask = np.zeros(n, dtype=bool)
        for k in top_k:
            js2 = max(0, k - n + 1)
            je2 = min(n - 1, k)
            peak_mask[js2:je2 + 1] = True
        
        candidates = np.where(~peak_mask)[0]
        if len(candidates) == 0:
            candidates = np.where(np.arange(n) != src)[0]
        
        # Pick from lowest-valued candidates
        candidates = candidates[np.argsort(a[candidates])]
        n_try = max(5, len(candidates) // 10)
        dst_candidates = candidates[:n_try]
        
        improved = False
        for dst in dst_candidates:
            for frac in [0.005, 0.01, 0.02, 0.05, 0.1]:
                amt = a[src] * frac
                if amt < 1e-18:
                    break
                a_trial = a.copy()
                a_trial[src] -= amt
                a_trial[dst] += amt
                if a_trial[src] < 0:
                    break
                s_t = a_trial.sum()
                if s_t < 1e-15:
                    continue
                a_trial = a_trial * norm / s_t
                score = compute_objective(a_trial)
                if score < best_score:
                    a = a_trial
                    best_score = score
                    best_a = a.copy()
                    improved = True
                    break
            if improved:
                break
        
        if not improved:
            # Random perturbation
            i = rng.integers(n)
            j = rng.integers(n)
            if i != j and a[i] > norm * 1e-8:
                frac = rng.uniform(0.01, 0.1)
                amt = a[i] * frac
                a_trial = a.copy()
                a_trial[i] -= amt
                a_trial[j] += amt
                if a_trial[i] >= 0:
                    s_t = a_trial.sum()
                    if s_t > 1e-15:
                        a_trial = a_trial * norm / s_t
                        score = compute_objective(a_trial)
                        if score < best_score:
                            a = a_trial
                            best_score = score
                            best_a = a.copy()
                            improved = True
            
            if not improved:
                stall += 1
                if stall > 200:
                    break
    
    if verbose:
        print(f"    Peak shave: best={best_score:.8f}")
    return best_a, best_score


def interpolate_sequence(f, new_n):
    """Interpolate a sequence to a new length."""
    old_n = len(f)
    if old_n == new_n:
        return f.copy()
    s = f.sum()
    if s < 1e-15:
        return np.ones(new_n)
    f_norm = f / s
    old_x = np.linspace(0.0, 1.0, old_n)
    new_x = np.linspace(0.0, 1.0, new_n)
    f_interp = np.interp(new_x, old_x, f_norm)
    f_interp = np.maximum(f_interp, 0.0)
    ss = f_interp.sum()
    if ss < 1e-15:
        return np.ones(new_n)
    return f_interp / ss


def structured_init(n, rng):
    """Create a structured initial sequence."""
    choice = rng.integers(0, 6)
    if choice == 0:
        x = np.linspace(0.0, np.pi, n)
        a = np.cos(x / 2.0) ** 2
    elif choice == 1:
        x = np.linspace(0.0, 1.0, n)
        a = np.sin(np.pi * x) ** 1.5
    elif choice == 2:
        x = np.linspace(0.0, 2.0 * np.pi, n)
        a = 0.5 + 0.3 * np.cos(2.0 * x) + 0.15 * np.cos(5.0 * x) + 0.05 * np.cos(9.0 * x)
    elif choice == 3:
        x = np.linspace(0.0, 1.0, n)
        a = np.exp(-4.0 * (x - 0.3) ** 2) + 0.7 * np.exp(-4.0 * (x - 0.7) ** 2)
    elif choice == 4:
        x = np.linspace(0.0, 1.0, n)
        a = (1.0 - np.abs(2.0 * x - 1.0)) ** 3
    else:
        # Raised cosine window
        x = np.linspace(0.0, 1.0, n)
        a = 0.5 * (1 + np.cos(2 * np.pi * x)) ** 2
    a = np.maximum(a, 0.0)
    s = a.sum()
    if s < 1e-15:
        return np.ones(n) / n
    return a / s


def lse_anneal_optimize(a0, time_limit, temp_start=50.0, temp_end=0.5, n_stages=8, verbose=False):
    """Anneal the LSE temperature for smoother-to-sharper optimization."""
    best_a = a0.copy()
    best_score = compute_objective(a0)
    t0 = time.monotonic()
    temps = np.geomspace(temp_start, temp_end, n_stages)
    
    for si, T in enumerate(temps):
        if time.monotonic() - t0 > time_limit:
            break
        remaining = time_limit - (time.monotonic() - t0)
        if remaining < 2:
            break
        stage_time = remaining * (1.0 / (n_stages - si))
        
        n = len(a0)
        a_stage, score_stage = nesterov_fw_optimize(a0, stage_time, temp=T, verbose=False)
        if score_stage < best_score:
            best_score = score_stage
            best_a = a_stage.copy()
            a0 = a_stage.copy()
    
    return best_a, best_score
