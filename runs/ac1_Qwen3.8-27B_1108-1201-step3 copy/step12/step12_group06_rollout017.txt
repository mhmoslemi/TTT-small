**Enhanced Peak Suppression:**

The key insight is that the subgradient of `max_k b_k` points in the direction of the anti-diagonal of `a`. To reduce the peak, we should:
1. Identify the peak position `k*`
2. Compute the "pressure" vector `p[j] = a[k*-j]` (the anti-diagonal)
3. Move mass AWAY from high-pressure positions (where `p[j]` is large) and TOWARD low-pressure positions
4. But we must maintain the sum constraint and non-negativity

A more sophisticated approach:
- Instead of just the max peak, use the top `m` peaks
- Use a "repulsion" force: positions that are in the anti-diagonal of multiple peaks get pushed down harder
- Use an adaptive step size based on the curvature

**Even better: Use the fact that `b = ifft(fft(a)^2)`**

In the frequency domain, `B = |A|^2` (where `A = fft(a)` padded appropriately). The constraint `max(b) <= M` becomes a constraint on the IFFT of `|A|^2`.

from scipy.fft import rfft, irfft
from scipy.optimize import minimize

def fast_convolve(a):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(np.asarray(a, dtype=np.float64), fft_size)
    return irfft(A * A, fft_size)[:size]

def evaluate_safe(a):

def project_simplex(v):
    n = len(v)
    if v.sum() < 1e-15:
        return np.ones(n) / n
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho_arr = np.where(u * np.arange(1, n + 1) > (cssv - 1))[0]
    if len(rho_arr) == 0:
        return np.ones(n) / n
    rho = rho_arr[-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0)

    """Direct optimization of max(b) via projected subgradient descent."""
    n = len(a0)
    a = np.maximum(a0, 0).astype(np.float64)
    a = a / a.sum()
    
    best_a = a.copy()
    best_score = score_normalized(a)
    t0 = time.monotonic()
    
    eta = 0.01
    prev_score = best_score
    patience = 0
    max_patience = 20000
    
    for step in range(n_steps):
        if time.monotonic() - t0 > time_limit:
            break
        
        b = fast_convolve(a)
        max_b = b.max()
        cur_score = 2.0 * n * max_b
        
        # Find active peaks (top few)
        top_k = max(1, min(5, len(b) // 100))
        sorted_idx = np.argsort(b)[::-1][:top_k]
        
        # Compute subgradient: sum of 2*a[k-j] for active peaks
        g = np.zeros(n)
        for k in sorted_idx:
            js = max(0, k - n + 1)
            je = min(n - 1, k)
            if js <= je:
                idx = np.arange(js, je + 1)
                # a[k - idx] = a[k-js], a[k-js-1], ..., a[k-je]
                g[idx] += 2.0 * a[k - idx]
        g /= float(top_k)
        
        # Projected gradient step (against gradient to minimize)
        a_upd = a - eta * g
        a_new = project_simplex(a_upd)
        
        sc_new = score_normalized(a_new)
        
        if sc_new < best_score:
            best_score = sc_new
            best_a = a_new.copy()
            patience = 0
        else:
            patience += 1
        
        a = a_new
        
        # Adaptive step size
        if patience % 100 == 0:
            if patience > max_patience:
                eta *= 0.7
                patience = max_patience // 2
            elif patience < max_patience // 2:
                eta = min(eta * 1.02, 0.05)
        
        if (step + 1) % 50000 == 0:
            print(f"  PSD step={step+1}: cur={cur_score:.8f} best={best_score:.8f} eta={eta:.6f}")
    
    return best_a, best_score

- Cross-correlation: overlap of the two bumps = 0 (if they don't overlap, i.e., `D >= w`, i.e., `n - 2w >= w`, i.e., `w <= n/3`)
  Wait, the cross-correlation is the convolution of bump 1 with bump 2, which is non-zero when they overlap. If the bumps don't overlap, the cross-correlation is 0.

Actually, one more important thought: the previous code used `cvxpy` for the LP. This might be slow for large `n`. Let me consider an alternative: instead of solving the LP exactly, use a few iterations of the "best response" computed by a simpler method.

The best response to `a` is: `b* = argmin_b max_k (a*b)_k` subject to `b >= 0, sum(b) = 1`.

This is equivalent to: find `b` that minimizes the maximum of `T(a) * b` where `T(a)` is the convolution matrix.

A simple approximation: `b* = argmin_b max_k (T(a) * b)_k` can be approximated by:
- Start with `b = a` (or uniform)
- Iteratively: find the peak `(T(a)*b)_k` and reduce `b_j` for `j` that contribute to that peak
- Normalize `b` after each step

This is like a "best response" computed by a few iterations of the same peak suppression method! So we can use peak suppression to approximate the LP.

This could be much faster than solving the LP with cvxpy.

def fast_cross_convolve(a, b):
    """Fast linear cross-convolution via FFT."""
    n = max(len(a), len(b))
    size = n + len(b) - 1  # Actually, size = len(a) + len(b) - 1
    size = len(a) + len(b) - 1
    fft_size = 1 << (size - 1).bit_length()
    A = rfft(a, fft_size)
    B = rfft(b, fft_size)
    return irfft(A * B, fft_size)[:size]

```python
def approx_best_response(a_fixed, n_iters=100):
    n = len(a_fixed)
    b = np.ones(n) / n
    
    for it in range(n_iters):
        prod = fast_cross_convolve(a_fixed, b)
        max_k = int(np.argmax(prod))
        
        # Subgradient of max(prod) w.r.t. b
        # prod[k] = sum_j a_fixed[j] * b[k-j]
        # d prod[k] / d b[l] = a_fixed[k-l] if 0 <= k-l < n
        g = np.zeros(n)
        js = max(0, max_k - n + 1)
        je = min(n - 1, max_k)
        idx = np.arange(js, je + 1)
        g[idx] = a_fixed[max_k - idx]
        
        # Projected gradient step
        b = b - 0.01 * g
        b = np.maximum(b, 0)
        s = b.sum()
        if s > 1e-15:
            b = b / s
    
    return b
```

This is much faster than solving the LP! Each iteration is O(n log n) for the FFT plus O(n) for the update.
