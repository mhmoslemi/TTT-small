Given iteration a_{t+1} = G(a_t) where G is the best-response map (possibly with damping), Anderson acceleration maintains a history of m points:

- F = [G(a_{t-m+1}) - a_{t-m+1}, ..., G(a_t) - a_t]

This is a m x m QP (or linear system if unconstrained).

For m=3 or m=5, this is very fast and can significantly accelerate convergence.

def fast_convolve(a):

def simplex_project(v):
    n = len(v)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if cond.any():
        rho = np.nonzero(cond)[0][-1]
        theta = (cssv[rho] - 1.0) / (rho + 1.0)
        return np.maximum(v - theta, 0.0)
    else:
        return np.ones(n) / n
