  Actually, you know what, let me just think about this problem from a high level:
  
  The objective is 2n * max(conv(a,a)) / (sum(a))^2.
  
  This is scale-invariant (if we multiply a by c, both max(conv) and sum^2 scale by c^2).
  
  So we can WLOG set sum(a) = 1, and minimize 2n * max(conv(a,a)).
  
  The constraint is a >= 0, sum(a) = 1.
  
  This is like finding a probability distribution on {0,...,n-1} that minimizes the maximum of its auto-convolution.
  
  The auto-convolution (a*a)[k] = P(X+Y=k) where X and Y are i.i.d. with the distribution a.
  
  So we want to minimize max_k P(X+Y=k).
  
  This is a well-known problem! It's related to "concentration functions" in probability theory.
  
  The minimum of max_k P(X+Y=k) over all probability distributions on {0,...,n-1} is known to be achieved by certain "spread out" distributions.
  
  For a uniform distribution on {0,...,n-1}: P(X+Y=k) = (n-|k-(n-1)|)/n^2, max = 1/n (at k=n-1).
  Score = 2n/n = 2.
  
  For other distributions, we can do better. The question is how much better.
  
  Actually, I recall that for the central limit theorem, the sum of two i.i.d. variables is "more spread out" than each individual variable. So the uniform distribution might not be optimal.
  
  Let me think about what distribution minimizes the max of the convolution:
  - We want P(X+Y=k) to be as equal as possible for all k.
  - The sum of all P(X+Y=k) is 1, and there are 2n-1 possible values of k.
  - So the minimum possible max is 1/(2n-1).
  - But we can't achieve this because the distribution is supported on {0,...,n-1}, and the convolution is supported on {0,...,2n-2}.
  - The "edges" (k=0 and k=2n-2) have P = P(X=0)^2 and P(X=n-1)^2 respectively.
  - To make the edges small, we need P(X=0) and P(X=n-1) to be small.
  
  This suggests a "U-shaped" or "ramp" distribution might work well.
