## 1. Approach and Rationale

The core idea is that **Pareto-optimal solutions** should be found by considering both the denominator (sum of coefficients) and specific **L₁-normalization factors**. The evaluation function is:
```python
score = (2 * n * max(convolve(a, a))) / (sum(a)) ** 2
```
Which can be rewritten as:
```python
score = (2 * n / (sum(a)**2)) * max(convolve(a, a))
```
So the contribution from each pair of coefficients is critical.

The constraints are:
1. Coefficients must be positive or zero.
2. Coefficients must not exceed 1000.
3. Time limit of 1800 seconds.

Key improvements:
- Maintain a **logarithmic-sum-normalization** to handle L2 sparsity.
- Use a **thresholding strategy** based on specific pairs' contributions.
- **Dramatically reduce** the number of evaluations while maintaining time for complex ones.

This addresses the **eigenvalue bottleneck** in the objective function by focusing on exact matrix inverse-convolution checks.

## 2. Mathematical Specification

We will consider each coefficient as a **latent factor** subject to pairwise constraints:
```python
def evaluate_sequence(seq):
    n = len(seq)
    conv = np.convolve(seq, seq, mode="full")
    s = np.sum(seq)
    if s < 0.01: return np.inf
    term = 2 * n * max(conv) / s**2
    return term
```
Our search will parameterize sequences by:
```python
def generate_latent_factors(n, alpha, beta):
    base_factor = np.exp(-beta * np.arange(n)**alpha)
    normalization = base_factor.sum()
    if normalization > 0:
        return (base_factor / normalization).tolist()
    else:
        # Fallback to exponential decay
        decay = 0.2 * (n-1)
        factors = []
        for i in range(n):
            factors.append(max(0.002, 1000 / np.exp(decay*i)))
        return factors
```

**Transformation pipeline:**
1. Normalize to fixed L1 sum initially (`c0 = np.exp(-beta*arange(alpha))`, `L1 = 1.0`).
2. Apply logarithmic clipping to preserve slot contributions.
3. Use a **differentiated Frank-Wolfe** algorithm targeting these specific pairs.
