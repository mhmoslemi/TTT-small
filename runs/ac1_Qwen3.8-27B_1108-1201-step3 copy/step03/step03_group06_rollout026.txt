Actually, let me reconsider the subgradient approach more carefully.

The objective is $f(a) = 2n \cdot \max_k (a*a)_k$ (with $\sum a = 1$).

The subgradient of $\max_k (a*a)_k$ at $a$ is any convex combination of $\{\nabla(a*a)_k : k \in S(a)\}$ where $S(a) = \arg\max_k (a*a)_k$.

For the projected subgradient method:
$a^{(t+1)} = \text{proj}_{\Delta}(a^{(t)} - \eta_t \cdot g^{(t)})$

where $g^{(t)}$ is a subgradient and $\eta_t$ is the step size.

The issue is that the subgradient method converges slowly (rate $O(1/\sqrt{T})$). To do better, we can:
1. Use Nesterov acceleration
2. Use a better step size (e.g., Polyak step size if we know the optimal value)
3. Use momentum

For the step size, a common choice is $\eta_t = C / \sqrt{t}$ where $C$ is chosen based on the diameter of the feasible set. The diameter of the probability simplex in $\ell_2$ is $\sqrt{2(n-1)/n} \approx \sqrt{2}$.

Another option is the "normalized" step size: $\eta_t = \eta_{\max} / (1 + L \cdot t)$ where $L$ is a Lipschitz constant of the subgradient.

For the subgradient of $(a*a)_k$, the $\ell_2$ norm is $\|\nabla(a*a)_k\|_2 = 2\|a\|_2$ (approximately, since the gradient is a shifted version of $2a$). So $L \approx 2\|a\|_2 / \min_{a \in \Delta} \|a\|_2$. For $a$ on the simplex, $\|a\|_2 \leq 1$ and $\|a\|_2 \geq 1/\sqrt{n}$. So $L$ could be large.

In practice, I'll use an adaptive step size with backtracking:
1. Try a step $\eta$.
2. If $f(a - \eta g) > f(a) + \delta$ (objective increased), reduce $\eta$ and retry.
3. Otherwise, accept and optionally increase $\eta$.

Let me also think about the "active set weighting" trick. Instead of using uniform weights on the active set, I can use weights that are proportional to how "peaked" each active constraint is. For example, if there are 3 active constraints with values 0.005, 0.0049, 0.0001, I should focus more on the first one.

In practice, using the gradient of the single most active constraint (the one that achieves the max) often works well.

Subgradient + LP hybrid optimizer for minimizing 2*n*max(conv(a,a))/(sum(a))^2.
Uses projected subgradient method with adaptive step size, periodic LP refinement,
and multi-length exploration.

import numpy as np
import time
from scipy.optimize import linprog

def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]

def project_simplex(v):
    """Euclidean projection onto the probability simplex."""
    n = len(v)
    if n == 1:
        return np.array([max(v[0], 0.0)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.arange(1, n + 1)
    cond = u * rho > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho_val = np.max(rho[cond])
    theta = (cssv[rho_val - 1] - 1.0) / rho_val
    return np.maximum(v - theta, 0.0)

def subgradient_max_conv(a):
    """Compute subgradient of max_k (a*a)_k.
    Uses the single most active constraint for efficiency.
    Returns (gradient, active_index, max_val).
    """
    n = len(a)
    conv = fast_convolve(a)
    k_star = int(np.argmax(conv))
    max_val = conv[k_star]
    
    # Gradient of (a*a)_{k_star} w.r.t. a
    # g[i] = 2 * a[k_star - i] if 0 <= k_star - i < n, else 0
    g = np.zeros(n)
    i_min = max(0, k_star - n + 1)
    i_max = min(n - 1, k_star)
    g[i_min:i_max+1] = 2.0 * a[k_star - i_max:k_star - i_min - 1:-1]
    
    return g, k_star, max_val

def subgradient_multi(a, top_k=3):
    """Compute weighted subgradient using top-k active constraints."""
    n = len(a)
    conv = fast_convolve(a)
    max_val = conv.max()
    
    # Get top-k indices
    indices = np.argpartition(conv, -top_k)[-top_k:]
    
    # Weight by how close to the max they are
    vals = conv[indices]
    weights = vals / vals.sum()
    
    # Compute weighted gradient
    g = np.zeros(n)
    for idx, k in enumerate(indices):
        i_min = max(0, k - n + 1)
        i_max = min(n - 1, k)
        g[i_min:i_max+1] += weights[idx] * 2.0 * a[k - i_max:k - i_min - 1:-1]
    
    return g, max_val

def objective_normalized(a):
    """Compute 2*n*max(conv(a,a)) assuming sum(a)=1."""
    n = len(a)
    conv = fast_convolve(a)
    return 2.0 * n * conv.max()

def build_lp_matrix(a):
    """Build constraint matrix for LP: (a*b)[k] <= M."""
    n = len(a)
    num_k = 2 * n - 1
    A_ub = np.zeros((num_k, n))
    for k in range(num_k):
        i_min = max(0, k - n + 1)
        i_max = min(n - 1, k)
        idx = np.arange(i_min, i_max + 1)
        A_ub[k, idx] = a[k - idx]
    return A_ub

def solve_lp_direction(a, M, top_k=None, conv=None):
    """Solve LP: max sum(b) s.t. b >= 0, (a*b)[k] <= M."""
    n = len(a)
    num_k = 2 * n - 1
    
    if top_k is not None and top_k < num_k and conv is not None:
        peaks = np.argpartition(conv, -top_k)[-top_k:]
        A_ub_full = build_lp_matrix(a)
        A_ub = A_ub_full[peaks]
        b_ub = np.full(len(peaks), M)
    else:
        A_ub = build_lp_matrix(a)
        b_ub = np.full(num_k, M)
    
    c = -np.ones(n)
    bounds = [(0, None)] * n
    
    try:
        res = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs',
                      options={'presolve': True})
        if res.success:
            return res.x
    except Exception:
        pass
    return None

        if b_sum < 1e-15:
            break
        b = b / b_sum

        a_new = project_simplex(a_new)

        f_new = 2.0 * n * conv_new.max()

            a_best = a_new.copy()
            a = a_new
            no_improve = 0
        else:
            no_improve += 1
            if no_improve > 5:
                step *= 0.7
            if no_improve > 30:
                noise = rng.standard_normal(n) * 0.005

                step = step_init * 0.5
