The constraint `sum_k c[k] = (sum a)^2 = 1` gives a lower bound `max_k c[k] >= 1/(2n-1)`.

So the optimal objective for length n is at least `2n/(2n-1)`.

Now, the "energy" constraint: `c[0] = a[0]^2`, `c[2n-2] = a[n-1]^2`. These must also be <= M.

A key structural insight: if we make `a[0]` and `a[n-1]` small, the edge peaks are small. But then we need to put that mass somewhere else, which might create internal peaks.

One effective strategy: make the sequence "compact" in the middle (like a Gaussian centered at n/2). This makes the edge peaks small. But the center peak `c[n-1]` will be large.

Another strategy: make the sequence "broad" and "flat" with small oscillations. This spreads the energy more uniformly across lags.

I think the best approach is:
1. Start with a broad, flat initialization (like a raised cosine or a truncated Gaussian).
2. Use iterative peak shaving to flatten the autocorrelation.
3. The peak shaving should focus on reducing the highest peaks without creating new ones.

def peak_shave(a, n_iter=10000, alpha=2.0):
    """Iteratively reduce the peak of the autocorrelation."""
    a = a.astype(np.float64).copy()
    s = a.sum()
    if s < 1e-15:
        a = np.ones(len(a)) / len(a)
        return a
    a = a / s
    n = len(a)
    
    best_a = a.copy()
    best_obj = 2.0 * n * fast_convolve(a).max()
    
    eta = 0.1  # step size
    
    for it in range(n_iter):
        c = fast_convolve(a)
        M = c.max()
        obj = 2.0 * n * M
        
        if obj < best_obj:
            best_obj = obj
            best_a = a.copy()
        
        # Compute weights: soft focus on peaks
        w = (c / M) ** alpha  # in [0, 1], peaks have weight ~1
        w_sum = w.sum()
        if w_sum < 1e-15:
            break
        w = w / w_sum  # normalize to sum to 1
        
        # Compute gradient: g[j] = sum_k w[k] * 2*a[k-j]
        # This is a cross-correlation
        g = np.zeros(n)
        for k in range(2*n-1):
            if w[k] > 1e-12:
                # g[j] += w[k] * 2 * a[k-j] for valid j
                j_min = max(0, k - n + 1)
                j_max = min(n - 1, k)
                for j in range(j_min, j_max + 1):
                    g[j] += 2 * w[k] * a[k - j]
        
        # Mirror descent update: a[j] *= exp(-eta * g[j])
        # To avoid underflow, center the gradient:
        g_centered = g - (a * g).sum()
        a = a * np.exp(-eta * g_centered)
        a = np.maximum(a, 0)
        s = a.sum()
        if s < 1e-15:
            a = best_a.copy()
            eta *= 0.5
            continue
        a = a / s
        
        # Adapt step size
        c = fast_convolve(a)
        new_obj = 2.0 * n * c.max()
        if new_obj > obj:
            eta *= 0.9
        else:
            eta = min(eta * 1.01, 0.5)
    
    return best_a

For mirror descent with the entropy barrier, the natural update is:
`a_j <- a_j * exp(-eta * g_j)` (before normalization)

The optimal step size depends on the "Lipschitz constant" of the objective. A simple adaptive scheme:
- Start with `eta = 0.1`.
- If the objective increases after an update, halve `eta`.
- If it decreases, optionally increase `eta` slightly.

Another approach: use a "barzilai-borwein" type step size based on the recent history of iterates.

Let me also think about the "alpha" parameter in `w = (c/M)^alpha`. 
- `alpha = 1`: uniform weight on all lags proportional to their value.
- `alpha -> infinity`: only the single maximum lag is weighted.
- `alpha = 2-4`: a good balance, focusing on the top few peaks.

I'll use `alpha` as a tunable parameter and try a few values.

Now, let me also think about potential issues:
1. **Convergence to a bad local optimum**: Mirror descent can get stuck. Using multiple restarts with different initializations helps.
2. **Sensitivity to step size**: Too large a step can cause oscillation; too small is slow. Adaptive step size helps.
3. **Numerical issues**: Very small `a[j]` values can underflow. Clipping to a minimum value (like 1e-30) helps.

"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using mirror descent (multiplicative 
peak shaving) with adaptive step size, FFT-based gradient computation, and 
multi-length exploration.
"""

import numpy as np
import time


def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 2 ** (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]


def compute_gradient(a, w, N):
    """Compute g[j] = sum_k w[k] * 2*a[k-j] using FFT cross-correlation."""
    W = np.fft.rfft(w, N)
    A = np.fft.rfft(a, N)
    g = 2.0 * np.fft.irfft(np.conj(W) * A, N)
    return g[:len(a)]


def mirror_descent_optimize(a0, time_limit, alpha=3.0, eta_init=0.05, 
                            top_k=100, min_eta=1e-6):
    """Mirror descent (multiplicative) peak shaving optimization."""
    a = np.maximum(a0.astype(np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(len(a)) / len(a)
    else:
        a = a / s
    n = len(a)
    
    # FFT size for cross-correlation
    N = 1
    while N < 3 * n:
        N *= 2
    
    c = fast_convolve(a)
    best_obj = 2.0 * n * c.max()
    best_a = a.copy()
    
    eta = eta_init
    t0 = time.monotonic()
    iter_count = 0
    
    while time.monotonic() - t0 < time_limit:
        c = fast_convolve(a)
        M = c.max()
        if M < 1e-15:
            break
        obj = 2.0 * n * M
        
        if obj < best_obj - 1e-12:
            best_obj = obj
            best_a = a.copy()
        
        # Compute weights focusing on peaks
        # Use top-k peaks with soft weighting
        if top_k < 2 * n - 1:
            top_idx = np.argpartition(c, -top_k)[-top_k:]
            w = np.zeros(2 * n - 1)
            peak_vals = c[top_idx]
            w[top_idx] = (peak_vals / M) ** alpha
        else:
            w = (c / M) ** alpha
        
        w_sum = w.sum()
        if w_sum < 1e-15:
            break
        w = w / w_sum
        
        # Compute gradient
        g = compute_gradient(a, w, N)
        
        # Mirror descent update (centered to maintain sum)
        g_centered = g - np.dot(a, g)
        # Clip to prevent overflow
        g_centered = np.clip(g_centered, -50.0, 50.0)
        a = a * np.exp(-eta * g_centered)
        a = np.maximum(a, 1e-30)
        s = a.sum()
        if s < 1e-15 or not np.isfinite(s):
            a = best_a.copy()
            eta *= 0.5
            continue
        a = a / s
        
        # Adapt step size
        c_new = fast_convolve(a)
        new_obj = 2.0 * n * c_new.max()
        if new_obj > obj * 1.001:
            eta *= 0.5
            if eta < min_eta:
                break
        elif new_obj < obj * 0.999:
            eta = min(eta * 1.05, 0.5)
        
        iter_count += 1
    
    return best_a, best_obj


def subgradient_optimize(a0, time_limit, lr_init=0.01, momentum=0.9, top_k=50):
    """Subgradient descent with momentum (additive version)."""
    a = np.maximum(a0.astype(np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(len(a)) / len(a)
    else:
        a = a / s
    n = len(a)
    
    N = 1
    while N < 3 * n:
        N *= 2
    
    v = np.zeros(n)
    c = fast_convolve(a)
    best_obj = 2.0 * n * c.max()
    best_a = a.copy()
    
    lr = lr_init
    t0 = time.monotonic()
    no_improve = 0
    
    while time.monotonic() - t0 < time_limit:
        c = fast_convolve(a)
        M = c.max()
        
        # Top-k peaks with softmax weighting
        top_idx = np.argpartition(c, -top_k)[-top_k:]
        peak_vals = c[top_idx]
        scaled = (peak_vals / M) ** 4.0
        w = np.zeros(2 * n - 1)
        w[top_idx] = scaled
        w_sum = w.sum()
        if w_sum < 1e-15:
            break
        w = w / w_sum
        
        g = compute_gradient(a, w, N)
        
        v = momentum * v - lr * g
        a = a + v
        a = np.maximum(a, 0.0)
        s = a.sum()
        if s < 1e-15:
            a = best_a.copy()
            v = 0
            lr *= 0.5
            continue
        a = a / s
        
        c = fast_convolve(a)
        cur_obj = 2.0 * n * c.max()
        
        if cur_obj < best_obj - 1e-12:
            best_obj = cur_obj
            best_a = a.copy()
            no_improve = 0
        else:
            no_improve += 1
        
        if no_improve > 100:
            # Perturb
            a = np.maximum(a + np.random.default_rng().standard_normal(n) * 0.01, 0)
            a = a / a.sum()
            v *= 0.5
            lr = max(0.001, lr * 0.8)
            no_improve = 0
        
        lr *= 0.9998
    
    return best_a, best_obj


def coordinate_descent(a_in, max_rounds=30, delta_frac=0.03):

                    best_obj = obj_test

            break
    
    return best_a


def gen_init(n, kind, rng):
    """Generate an initial sequence of length n."""
    if kind == 'uniform':
        return np.ones(n) / n
    elif kind == 'raised_cosine':
        x = np.arange(n)
        a = 0.5 * (1 + np.cos(2 * np.pi * x / n))
        a = np.maximum(a, 0)
        return a / a.sum()
    elif kind == 'broad_gaussian':
        x = np.arange(n)
        sigma = 0.4 * n
        a = np.exp(-0.5 * (x - n/2 + 0.5)**2 / sigma**2)
        return a / a.sum()
    elif kind == 'random_exp':
        a = rng.exponential(1.0, n)
        return a / a.sum()
    elif kind == 'random_dirichlet':
        return rng.dirichlet(np.ones(n) * 0.5)
    elif kind == 'two_humps':
        x = np.arange(n)
        a = np.exp(-0.5*(x - 0.25*n)**2/(0.1*n)**2) + np.exp(-0.5*(x - 0.75*n)**2/(0.1*n)**2)
        return a / a.sum()
    elif kind == 'anti_palindromic':
        # Try to make a[j] and a[n-1-j] "anti-correlated"
        a = np.ones(n)
        a[:n//2] = 1.0
        a[n//2:] = 0.1
        return a / a.sum()
    else:
        return np.ones(n) / n
