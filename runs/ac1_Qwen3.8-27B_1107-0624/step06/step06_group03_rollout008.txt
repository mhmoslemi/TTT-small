This has n variables and 2n-1 + n = 3n-1 constraints. For n=4096, that's ~12000 constraints and 4096 variables. This is a large LP but should be solvable with modern solvers.

However, cvxpy with CBC or GLPK might be slow for this size. Let me think about whether we can make it faster.

Actually, the constraint conv(a,g)[k] <= M can be written as:
sum_{i: valid} a[i]*g[k-i] <= M

This is a linear constraint in g. The constraint matrix is a convolution matrix (banded, with at most n non-zeros per row).

For n=4096, the LP has 4096 variables and 8191+4096 = 12287 constraints. This might be too slow for an LP solver within our time budget.

Alternative: Use a greedy/approximate approach to the LP. For example:
1. Start with g = a (which satisfies the constraints since conv(a,a) <= M).
2. Try to increase sum(g) by increasing individual g[i] while maintaining feasibility.
3. This is like a "water filling" or "greedy LP" approach.

Actually, I think a simpler approach is:
1. Identify the "bottleneck" constraints: lags k where conv(a,a)[k] is close to M.
2. For each such lag, the constraint is sum_i a[i]*g[k-i] <= M.
3. We want to increase the g's that are not "used" by these bottleneck constraints.

This is essentially finding g in the null space of the bottleneck constraints, in the positive orthant.

Let me think of an even simpler approach: **iterative thresholding**.

1. Compute conv(a,a), find the peak lag k*.
2. The constraint is c[k*] = sum_i a[i]*a[k*-i] <= M (tight).
3. To reduce c[k*], we should reduce a[i] for i that contribute most to c[k*], i.e., where a[i]*a[k*-i] is large.
4. Move the reduced mass to positions that don't contribute to c[k*].

This is a "peeling" or "mass redistribution" step.

Let me combine all these ideas into a practical algorithm:

**Algorithm:**
1. Start from the parent sequence (or a good initialization).
2. Alternate between:
   a. **Gradient step**: Compute the gradient using the exact peak (or top-K), take a step in the negative gradient direction (with simplex projection).
   b. **Peeling step**: Identify the peak lag, reduce the elements that contribute most to it, redistribute to "safe" positions.
   c. **Coordinate descent**: Optimize individual coordinates.
3. Use multiple sequence lengths.
4. Track the best solution found.

Let me now write the code. I'll focus on:
- Efficient FFT-based convolution and gradient computation
- A robust optimizer that combines multiple techniques
- Proper time management
- Trying different lengths

One more thought: **the "flat spectrum" initialization**. 

If we want the magnitude spectrum to be flat, we can start with random phase in the frequency domain and take the inverse FFT, then project to non-negative. This is like the "Gerchberg-Saxton" algorithm.

Specifically:
1. Start with W[f] = 1 for all f (flat magnitude).
2. Compute a = IFFT(W * exp(i*phi)) for some phase phi.
3. Project a to be non-negative: a = max(a, 0).
4. Recompute the spectrum: W_new = |FFT(a)|.
5. Keep the phase, update magnitude: W = W_new * exp(i*phi).
6. Repeat.

This would give a sequence with a relatively flat magnitude spectrum, which should have low peak convolution.

Actually, this is the key insight! Let me implement this as an initialization method.

But wait, for the full (linear) convolution, flat spectrum doesn't directly mean flat convolution. The full convolution corresponds to the product of the DFT only for periodic convolution. For linear convolution, we'd need to zero-pad.

If we zero-pad a to length 2n and compute the DFT, then |FFT_2n(a)|^2 corresponds to the periodic convolution of the zero-padded a with itself, which equals the linear convolution (since the zero-padding prevents wrap-around). So we DO want the zero-padded spectrum to be flat!

Let me implement this:
1. Zero-pad a to length N >= 2n (where N is a power of 2 for efficient FFT).
2. We want |FFT_N(a_padded)| to be as flat as possible.
3. The DC bin is fixed at sum(a).
4. Use Gerchberg-Saxton: alternate between enforcing flat magnitude in frequency domain and non-negativity in time domain.

This should give a good initialization!

"""
Optimized step function search using spectral initialization, 
subgradient descent, peeling, and coordinate descent.
Targets sequences up to length 16384 for better score (lower bound ~1+1/n).
"""
import numpy as np
import time
from scipy.optimize import minimize_scalar, linprog

def _next_pow2(n):
    k = 1
    while k < n:
        k <<= 1
    return max(4, k)

def _full_convolve(a, b):
    n, m = len(a), len(b)
    out_n = n + m - 1
    N = _next_pow2(out_n)
    fa = np.fft.rfft(a, N)
    fb = np.fft.rfft(b, N)
    r = np.fft.irfft(fa * fb, N)[:out_n]
    return r

def _score_norm(a):
    """Score with sum(a) = 1: 2n * max(conv(a,a))"""
    n = len(a)
    c = _full_convolve(a, a)
    return float(2.0 * n * c.max())

def _score(a):
    """Full score: 2n * max(conv) / (sum)^2"""
    n = len(a)
    s = float(a.sum())
    if s < 1e-15:
        return np.inf
    c = _full_convolve(a, a)
    return float(2.0 * n * c.max() / (s * s))

def _project_simplex(v):
    """Project v onto the probability simplex {x >= 0, sum(x) = 1}."""
    n = len(v)
    if n == 0:
        return v
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    idx = np.arange(1, n + 1, dtype=np.float64)
    cond = u * idx > (cssv - 1.0)
    if not np.any(cond):
        return np.ones(n) / n
    rho = np.where(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)

def _grad_conv(a, w):
    """Gradient of <w, conv(a,a)> wrt a.
    Result[i] = 2 * sum_k w[k] * a[k-i] (for valid k-i)
    This equals 2 * cross_correlation(w_padded, a)[i]
    """
    n = len(a)
    N = _next_pow2(2 * n)
    fa = np.fft.rfft(a, N)
    fw = np.fft.rfft(w, N)
    # cross_corr(w, a)[i] = sum_k w[k]*a[k-i] = ifft(conj(fft(w)) * fft(a))[i]
    h = np.fft.irfft(np.conj(fw) * fa, N)[:n]
    return 2.0 * h

def _spectral_init(n, iterations=200, seed=42):
    """Initialize a non-negative sequence with flat magnitude spectrum (zero-padded)."""
    rng = np.random.default_rng(seed)
    N = _next_pow2(2 * n)
    
    # Start with random complex spectrum with flat magnitude
    phase = rng.uniform(0, 2*np.pi, N//2 + 1)
    W = np.exp(1j * phase)
    # Zero out DC for now (will fix later)
    
    best_a = None
    best_score = np.inf
    
    for it in range(iterations):
        # Time domain: inverse FFT of W
        a_full = np.fft.irfft(W, N)[:n]
        # Enforce non-negativity
        a_full = np.maximum(a_full, 0.0)
        s = a_full.sum()
        if s < 1e-15:
            a_full = np.ones(n) / n
            s = 1.0
        a_full = a_full / s
        
        # Compute score
        sc = _score_norm(a_full)
        if sc < best_score:
            best_score = sc
            best_a = a_full.copy()
        
        # Frequency domain: compute spectrum of current a
        W_new = np.fft.rfft(a_full, N)
        
        # Enforce flat magnitude: keep phase of W, set magnitude to 1
        # But keep DC bin proportional to sum(a) = 1
        mag = np.ones(N//2 + 1)
        mag[0] = 1.0  # DC bin
        # Enforce Hermitian symmetry: W_new[-k] = conj(W_new[k])
        # rfft already handles this
        
        W = mag * np.exp(1j * np.angle(W_new))
    
    if best_a is not None:
        return best_a
    return np.ones(n) / n

def _subgradient_descent(a, deadline, lr=0.01, momentum=0.9):
    """Subgradient descent on the simplex using the exact peak."""
    n = len(a)
    a_curr = a.copy()
    v = np.zeros(n)  # momentum
    best_a = a_curr.copy()
    best_score = _score_norm(a_curr)
    
    # Adaptive learning rate
    current_lr = lr
    
    for it in range(1000000):
        if time.monotonic() > deadline:
            break
        
        c = _full_convolve(a_curr, a_curr)
        peak_idx = np.argmax(c)
        
        # Subgradient: weight concentrated at peak
        w = np.zeros(len(c))
        w[peak_idx] = 1.0
        
        grad = _grad_conv(a_curr, w)
        
        # Normalized gradient step
        v = momentum * v + (1 - momentum) * grad
        step = current_lr * v / (np.linalg.norm(v) + 1e-15)
        
        a_next = _project_simplex(a_curr - step)
        
        # Check improvement
        if it % 100 == 0:
            sc = _score_norm(a_next)
            if sc < best_score:
                best_score = sc
                best_a = a_next.copy()
        
        a_curr = a_next
        
        # Reduce learning rate periodically
        if it % 5000 == 0 and it > 0:
            current_lr *= 0.95
    
    return best_a, best_score

def _topk_softmax(a, beta, k):
    """Compute softmax weights on top-k elements of conv(a,a)."""
    c = _full_convolve(a, a)
    n_c = len(c)
    if k >= n_c:
        w = np.ones(n_c) / n_c
        return w, c
    
    # Find top-k
    thresh = np.partition(c, -k)[-k]
    mask = c >= thresh
    idx = np.where(mask)[0]
    if len(idx) == 0:
        idx = np.array([int(np.argmax(c))])
    
    c_topk = c[idx]
    c_max = c_topk.max()
    exps = np.exp((c_topk - c_max) / beta)
    w = np.zeros(n_c)
    w[idx] = exps / exps.sum()
    return w, c

def _adam_mirror(a, deadline, beta_schedule, top_k=100, lr=0.01):
    """Adam in log-space (mirror descent) with top-K smoothed max."""
    n = len(a)
    z = np.log(np.maximum(a, 1e-15))
    z = z - z.mean()
    
    best_a = a.copy()
    best_score = _score_norm(a)
    
    m_buf = np.zeros(n)
    v_buf = np.zeros(n)
    t = 0
    b1, b2, eps = 0.9, 0.999, 1e-8
    current_lr = lr
    
    for beta in beta_schedule:
        if time.monotonic() > deadline:
            break
        it_count = 0
        while it_count < 50000:
            if time.monotonic() > deadline:
                break
            it_count += 1
            t += 1
            
            a_curr = _softmax(z)
            c = _full_convolve(a_curr, a_curr)
            w, c = _topk_softmax(a_curr, beta, top_k)
            
            # Gradient in log-space
            grad_a = _grad_conv(a_curr, w)
            mean_g = float(np.dot(grad_a, a_curr))
            grad_z = n * 2.0 * a_curr * (grad_a - mean_g)
            
            if not np.all(np.isfinite(grad_z)):
                break
            
            m_buf = b1 * m_buf + (1 - b1) * grad_z
            v_buf = b2 * v_buf + (1 - b2) * (grad_z * grad_z)
            mh = m_buf / (1 - b1**t)
            vh = v_buf / (1 - b2**t)
            
            update = current_lr * mh / (np.sqrt(vh) + eps)
            upd_norm = np.linalg.norm(update)
            if upd_norm > 2.0:
                update = update / upd_norm * 2.0
            
            z = z - update
            z = np.clip(z, -40, 40)
            z = z - z.mean()
            
            if t % 100 == 0:
                a_chk = _softmax(z)
                sc = _score_norm(a_chk)
                if np.isfinite(sc) and sc < best_score:
                    best_score = sc
                    best_a = a_chk.copy()

        v_buf *= 0.5
        current_lr *= 0.9
    
    return best_a, best_score

def _softmax(z):
    z = z - z.max()
    e = np.exp(np.clip(z, -50, 50))
    s = e.sum()
    if s < 1e-300:
        return np.ones_like(z) / len(z)
    return e / s

def _peel_step(a, num_peels=5):
    """Peeling: reduce elements that contribute most to the peak lag."""
    n = len(a)
    a = a.copy()
    best_score = _score_norm(a)
    
    for _ in range(num_peels):
        c = _full_convolve(a, a)
        peak_idx = int(np.argmax(c))
        
        # Find which coordinates contribute most to the peak
        # c[peak_idx] = sum_i a[i]*a[peak_idx - i]
        contributions = np.zeros(n)
        for i in range(n):
            j = peak_idx - i
            if 0 <= j < n:
                contributions[i] = a[i] * a[j]
        
        # Reduce top contributors
        top_contrib = np.argsort(contributions)[-n//10:]
        total_reduce = a[top_contrib].sum() * 0.1  # reduce 10% of their mass
        
        # Distribute to "safe" positions (those with low contribution)
        safe = np.argsort(contributions)[:n//5]
        
        # Move mass
        for i in top_contrib:
            reduce_amt = a[i] * 0.05
            a[i] -= reduce_amt
            # Distribute to safe positions
            safe_weight = np.ones(len(safe)) / len(safe)
            a[safe] += reduce_amt * safe_weight
        
        a = np.maximum(a, 0)
        a = a / a.sum()
        
        sc = _score_norm(a)
        if sc < best_score:
            best_score = sc
        else:
            # Revert if it got worse
            # (simplified: just break)
            break
    
    return a, best_score

def _fista_topk(a, deadline, betas, top_k_schedule):
    """FISTA with top-K smoothed max, adaptive."""
    n = len(a)
    a_curr = a.copy()
    a_prev = a_curr.copy()
    t_val = 1.0
    best_a = a_curr.copy()
    best_score = _score_norm(a_curr)
    
    c_curr = _full_convolve(a_curr, a_curr)
    max_c = float(c_curr.max())
    
    for beta, top_k in zip(betas, top_k_schedule):
        if time.monotonic() > deadline:
            break
        
        # Estimate Lipschitz constant
        L = 8.0 * n / max(1e-10, max_c)
        step = 1.0 / L
        
        for it in range(20000):
            if time.monotonic() > deadline:
                break
            
            t_next = (1.0 + np.sqrt(1.0 + 4.0 * t_val * t_val)) / 2.0
            y = a_curr + ((t_val - 1.0) / t_next) * (a_curr - a_prev)
            y = np.maximum(y, 0.0)
            s_y = y.sum()
            if s_y > 1e-30:
                y = y / s_y
            else:
                y = np.ones(n) / n
            
            c_y = _full_convolve(y, y)
            w, _ = _topk_softmax(y, beta, top_k)
            grad = _grad_conv(y, w)
            
            a_next = _project_simplex(y - step * grad)
            
            if it % 200 == 0:
                sc = _score_norm(a_next)
                if sc < best_score:
                    best_score = sc
                    best_a = a_next.copy()
            
            a_prev = a_curr.copy()
            a_curr = a_next
            t_val = t_next
        
        # Update max_c for next phase
        c_curr = _full_convolve(a_curr, a_curr)
        max_c = float(c_curr.max())
    
    sc_final = _score_norm(a_curr)
    if sc_final < best_score:
        best_score = sc_final
        best_a = a_curr.copy()
    
    return best_a, best_score

def _lq_step(a, max_iter=1000):
    """LQ-type step: greedily find direction that reduces peak."""
    n = len(a)
    a = a.copy()
    c = _full_convolve(a, a)
    M = float(c.max())
    
    # Find the peak lag
    peak_lag = int(np.argmax(c))
    
    # For the peak lag, c[peak] = sum_i a[i]*a[peak-i]
    # We want to find g >= 0 such that:
    #   conv(a, g)[k] <= M for all k
    #   sum(g) is maximized
    # Approximate: just find g that has low correlation with a at the peak lag
    
    # Simple approach: g[i] = 1/a[i] (inversely proportional)
    # This ensures a[i]*g[i] is constant, reducing the peak contribution
    
    # Normalize
    g = 1.0 / (a + 1e-10)
    g = g / g.sum()
    
    # Blend
    t = 0.1
    a_new = (1 - t) * a + t * g
    a_new = np.maximum(a_new, 0)
    a_new = a_new / a_new.sum()
    
    return a_new
