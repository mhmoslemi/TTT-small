6. Clip: a_padded[i] = max(a_padded[i], 0) for i in [0, n)
7. Renormalize: a = a_padded[:n] / sum(a_padded[:n])
8. Go to 2

This is the "relaxed" GS algorithm. It should converge to a stationary point of the problem "minimize max linear autocorrelation subject to non-negativity and unit sum."

Actually, I realize there's another issue. The target for |A(ω)| should not be constant. If |A(ω)| is constant, then the (cyclic) autocorrelation is a delta at lag 0, which means the linear autocorrelation would be 0 for all non-zero lags. But that's impossible for a non-negative sequence (since b_0 = sum a_i^2 > 0, and b_k > 0 for k near 0 by continuity).

The actual target should be: |A(ω)|^2 should be as flat as possible, which corresponds to the cyclic autocorrelation being as close to a delta as possible. But since we can't make it a perfect delta (non-negativity constraint), we want it as close as possible.

In the GS algorithm, we don't need to explicitly choose a target. We just alternate between:
- Frequency domain: make |A| as uniform as possible (replace with its average magnitude)
- Time domain: enforce constraints (non-negativity, support)

But "make |A| as uniform as possible" isn't exactly right either. We want to minimize the PEAK of the autocorrelation, not make the spectrum flat. These are related but not identical objectives.

A better frequency-domain target: we want the IDFT of |A(ω)|^2 to have minimal peak (excluding lag 0). This is equivalent to making |A(ω)|^2 "smooth" in a certain sense.

Actually, for the purpose of the GS algorithm, using a flat target is a good heuristic. It often converges to sequences with low peak sidelobe level. Let's just use that.

```python
def _mirror_gradient_step(a, m_peaks=20, lr=0.1, n_steps=10000, deadline=None):
    """
    Mirror gradient descent with projection onto simplex.
    a: non-negative sequence with sum 1
    """
    n = len(a)
    a = a.copy()
    best_a = a.copy()
    best_sc = _score(a)
    
    for step in range(n_steps):
        if deadline is not None and time.monotonic() > deadline:
            break
        
        # Compute convolution
        b = _full_convolve(a, a)
        b_max = float(b.max())
        
        # Find top-m peaks
        # Use argpartition for efficiency
        if m_peaks >= len(b):
            peak_idx = np.arange(len(b))
        else:
            peak_idx = np.argpartition(b, -m_peaks)[-m_peaks:]
        
        # Compute mirror gradient
        # grad_p = (1/m) * sum_l a[k_l - p] (with bounds checking)
        grad = np.zeros(n)
        for k in peak_idx:
            # a[k-p] is valid when 0 <= k-p < n, i.e., k-n+1 <= p <= k
            lo = max(0, int(k) - n + 1)
            hi = min(n - 1, int(k))
            if lo <= hi:
                # grad[lo:hi+1] += a[k - hi : k - lo][::-1]
                # a[k-p] for p in [lo, hi] is a[k-hi : k-lo+1][::-1]
                grad[lo:hi+1] += a[k-hi:k-lo+1][::-1]
        
        # Handle the diagonal term (when 2p = k, we need an extra a_p)
        for k in peak_idx:
            if k % 2 == 0 and k // 2 < n:
                grad[k//2] += a[k//2]
        
        grad /= len(peak_idx)
        
        # Adaptive learning rate
        # Use: lr_step = lr * b_max / (grad_norm + eps)
        grad_norm = np.linalg.norm(grad)
        if grad_norm < 1e-15:
            break
        lr_step = lr * b_max / grad_norm
        
        # Take step
        a_new = a - lr_step * grad
        
        # Project onto simplex {a >= 0, sum(a) = 1}
        a_new = _project_simplex(a_new)
        
        if _score(a_new) < best_sc:
            best_sc = _score(a_new)
            best_a = a_new.copy()
        
        a = a_new
    
    return best_a, best_sc
```

Let me also think about the projection onto the simplex. The projection of a vector v onto {x >= 0, sum(x) = 1} is:
x_i = max(v_i - τ, 0) where τ is chosen so that sum(x) = 1.

To find τ, we can sort v in decreasing order: v_(1) >= v_(2) >= ... >= v_(n).
Then τ = (sum_{i=1}^{k} v_(i) - 1) / k where k = max{j : v_(j) > (sum_{i=1}^{j} v_(i) - 1) / j}.

This is O(n log n) using sorting, or O(n) using a selection algorithm.

```python
def _project_simplex(v):
    n = len(v)
    # Project onto {x >= 0, sum(x) = 1}
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n+1) > (cssv - 1)
    k = np.argmax(cond)
    tau = (cssv[k] - 1) / (k + 1)
    return np.maximum(v - tau, 0)
```

```python
        A = np.fft.fft(a_padded)

            A_new = mag_target * A / np.maximum(np.abs(A), 1e-30)

        a_padded[n:] = 0

        a_padded = np.maximum(a_padded, 0)
        
        # Renormalize
        s = a_padded.sum()

        a_padded = a_padded / s
```

Actually, a better approach for the frequency domain: instead of making |A| flat, we want to make the autocorrelation flat. The autocorrelation is the IDFT of |A|^2. So we want |A|^2 to be as flat as possible (except at DC, where it must be (sum a)^2 = 1).

Wait, |A(0)|^2 = (sum a)^2 = 1 (when sum a = 1). And the autocorrelation at lag 0 is sum a_i^2. The autocorrelation at lag τ is sum_i a_i a_{i+τ}.

The relationship is: r(τ) = IDFT(|A(ω)|^2)[τ] for the cyclic case.

So to minimize max_{τ != 0} r(τ), we want |A(ω)|^2 to be as close to a constant as possible (with the DC component fixed at 1).

The "flat" target in the magnitude domain means |A(ω)| = constant, which gives |A(ω)|^2 = constant, which gives a delta autocorrelation. That's the ideal, but not achievable.

In practice, the GS algorithm with flat magnitude target will converge to a solution where the autocorrelation is "as flat as possible" given the constraints. This is a good heuristic.

Wait, I need to be more careful about the mirror gradient step size. Let me think about this.

The function we're minimizing is f(a) = max_k b_k where b = conv(a,a). This function is not smooth and not convex in general. The mirror gradient gives a subgradient direction.

For the step size: if we take too large a step, we might overshoot and increase the peak elsewhere. If too small, we make no progress.

A good adaptive scheme:
- Start with lr = 0.5
- After each step, if the score decreased, increase lr slightly (multiply by 1.1)
- If the score increased, decrease lr (multiply by 0.5)
- Cap lr at some maximum

Actually, for non-smooth optimization, a better approach is:
- Use a fixed step size that decreases over time: lr_t = lr_0 / sqrt(t)
- This is the standard rate for subgradient methods on non-smooth functions

But since our function is actually smooth (it's a max of smooth functions), we can do better. The "active set" approach (using the top-m peaks) gives a smoothed version of the max, which is differentiable. The Lipschitz constant of this smoothed function is related to the second derivatives of b_k, which are bounded.

Let me use a practical approach:
- lr = c * b_max where c is a constant (e.g., 0.1)
- After each step, check if the score improved. If not, halve the step.
- This is essentially backtracking line search.

Let me also consider: should I use the exact max (m=1) or a smoothed version (m>1)?

Using m=1 (exact max):
- Pro: directly targets the worst peak
- Con: the active set changes rapidly, causing oscillation

Using m>1 (smoothed):
- Pro: more stable, less oscillation
- Con: might not reduce the actual maximum as effectively

A good compromise: use a "soft" active set where the weight of each peak is proportional to its value (or exp(value/beta) for some temperature beta). This is the log-sum-exp approach in disguise.

But for efficiency, let me just use a fixed m and average over the top-m. I'll try different m values in different phases.

Now let me think about another important aspect: the **symmetry** of the problem.

The convolution b_k = sum_{i+j=k} a_i a_j satisfies b_k = b_{2n-2-k} (by the substitution i' = n-1-i, j' = n-1-j).

Wait, is that right? Let me check:
b_k = sum_{i=0}^{n-1} a_i a_{k-i} (with a_j = 0 outside [0,n-1])
b_{2n-2-k} = sum_{i=0}^{n-1} a_i a_{2n-2-k-i}

Let j = 2n-2-k-i, so i = 2n-2-k-j.
b_{2n-2-k} = sum_{j: 0<=2n-2-k-j<=n-1} a_{2n-2-k-j} a_j
            = sum_{j: n-1-k <= j <= n-1} a_{n-1-(k-j)} a_j  (letting i' = n-1-i)

Hmm, this isn't quite the same as b_k unless a is symmetric (a_i = a_{n-1-i}).

Actually, let me redo this. b_k = sum_{i+j=k, 0<=i<n, 0<=j<n} a_i a_j.
b_{2n-2-k} = sum_{i+j=2n-2-k} a_i a_j.

Let i' = n-1-i, j' = n-1-j. Then i+j = 2n-2-i'-j', so i+j = 2n-2-k means i'+j' = k.
And a_i = a_{n-1-i'}, a_j = a_{n-1-j'}.
So b_{2n-2-k} = sum_{i'+j'=k} a_{n-1-i'} a_{n-1-j'} = b_k only if a is symmetric.

So the convolution is NOT symmetric in general. It's only symmetric if a is symmetric (a_i = a_{n-1-i}).

However, we can exploit a different symmetry: if we replace a with its reverse (a_i -> a_{n-1-i}), the convolution is the same:
conv(reverse(a), reverse(a))_k = sum_{i+j=k} a_{n-1-i} a_{n-1-j}
Let i' = n-1-i, j' = n-1-j: = sum_{i'+j'=2n-2-k} a_{i'} a_{j'} = conv(a,a)_{2n-2-k}

So conv(reverse(a), reverse(a)) is the reverse of conv(a,a). This means the maximum is the same regardless of whether we use a or its reverse. So the problem is symmetric under reversal, which is a minor point.

More importantly: if a is NOT symmetric, then conv(a,a) is NOT symmetric, and the peak could be at any position k from 0 to 2n-2. The most restrictive peak is typically near the middle (k ≈ n-1) because that's where the most terms contribute to the sum.

Actually, for a general non-negative sequence, b_{n-1} = sum_{i=0}^{n-1} a_i a_{n-1-i} is typically the largest because it has n terms (all valid), while b_0 = a_0^2 and b_{2n-2} = a_{n-1}^2 have only 1 term.

So the peak is usually near the middle, and the mirror gradient for k ≈ n-1 gives:
∂b_{n-1}/∂a_i = a_{n-1-i}

This means the gradient is the "reversed" sequence! So the mirror gradient step is:
a <- a - lr * reverse(a) (approximately, for the central peak)

This is a very intuitive operation: we're subtracting the reversed sequence from the original, which "de-correlates" the sequence from its reverse, reducing the central peak of the autocorrelation.

This is a beautiful insight! The optimal direction to reduce the central peak is to make the sequence "anti-symmetric" in some sense.

But of course, we also need to handle the constraint sum(a) = 1 and a >= 0.

```python
"""
Optimizer combining GS spectral shaping, mirror gradient descent,
and L-BFGS polish for minimizing 2*n*max(conv(a,a))/sum(a)^2.
"""
import numpy as np
import time
from scipy.optimize import minimize


def _next_pow2(n):
    k = 1
    while k < n:
        k <<= 1
    return max(2, k)


def _full_convolve(a, b):
    n, m = len(a), len(b)
    out_n = n + m - 1
    N = _next_pow2(out_n)
    fa = np.fft.rfft(a, N)
    fb = np.fft.rfft(b, N)
    r = np.fft.irfft(fa * fb, N)[:out_n]
    return r


def _score(a):
    n = len(a)
    s = float(a.sum())
    if s < 1e-15:
        return np.inf
    c = _full_convolve(a, a)
    return float(2.0 * n * c.max() / (s * s))


def _softmax(z):
    z = z - np.max(z)
    e = np.exp(np.clip(z, -700, 700))
    s = e.sum()
    if s < 1e-300:
        return np.ones_like(z) / len(z)
    return e / s


def _project_simplex(v):
    """Project v onto {x >= 0, sum(x) = 1}."""
    n = len(v)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    k = np.max(np.where(cond))
    tau = (cssv[k] - 1) / (k + 1)
    return np.maximum(v - tau, 0)


def _compute_mirror_grad(b, a, m_peaks):
    """
    Compute the mirror gradient for the top-m peaks of b.
    Returns gradient vector of length n.
    """
    n = len(a)
    nb = len(b)
    m = min(m_peaks, nb)
    
    # Get indices of top-m values
    if m >= nb:
        peak_idx = np.arange(nb)
    else:
        # Use argpartition for O(nb) selection
        part_idx = np.argpartition(-b, m - 1)[:m]
    
    grad = np.zeros(n)
    for k in part_idx:
        ki = int(k)
        # a[ki - p] for valid p: 0 <= ki-p < n => ki-n+1 <= p <= ki
        lo = max(0, ki - n + 1)
        hi = min(n - 1, ki)
        if lo <= hi:
            # grad[lo:hi+1] += a[ki-hi : ki-lo+1][::-1]
            seg = a[ki - hi:ki - lo + 1][::-1]
            grad[lo:hi + 1] += seg
        # Diagonal correction: if 2p = ki, add extra a_p
        if ki % 2 == 0:
            p = ki // 2
            if 0 <= p < n:
                grad[p] += a[p]
    
    grad /= float(m)
    return grad


def _mirror_descent(a_init, deadline, m_peaks_list=None, lr_init=0.3, 
                    total_steps=200000, check_interval=100):
    """
    Mirror gradient descent on the simplex.
    """
    if m_peaks_list is None:
        m_peaks_list = [50, 20, 10, 5, 3]
    
    n = len(a_init)
    a = a_init.copy()
    best_a = a.copy()
    best_sc = _score(a)
    
    step = 0
    lr = lr_init
    
    for m_peaks in m_peaks_list:
        steps_per_m = total_steps // len(m_peaks_list)
        for _ in range(steps_per_m):
            if time.monotonic() > deadline:
                break
            step += 1
            
            b = _full_convolve(a, a)
            b_max = float(b.max())
            
            # Compute mirror gradient
            grad = _compute_mirror_grad(b, a, m_peaks)
            grad_norm = np.linalg.norm(grad)
            if grad_norm < 1e-15:
                break
            
            # Adaptive step size
            step_size = lr * b_max / grad_norm
            
            # Take step
            a_new = a - step_size * grad
            a_new = _project_simplex(a_new)
            
            # Check score periodically
            if step % check_interval == 0:
                sc = _score(a_new)
                if sc < best_sc:
                    best_sc = sc
                    best_a = a_new.copy()
                    lr = min(lr * 1.02, lr_init * 2)
                else:
                    lr = max(lr * 0.9, 0.01)
            
            a = a_new
    
    # Final check
    sc_final = _score(a)
    if sc_final < best_sc:
        best_sc = sc_final
        best_a = a.copy()
    
    return best_a, best_sc


def _gs_flatten(a_init, n_iter=300, deadline=None):
    """
    GS-style iteration to flatten the power spectrum.
    """
    n = len(a_init)
    N = _next_pow2(2 * n - 1)
    
    a_padded = np.zeros(N)
    a_padded[:n] = a_init
    
    best_a = a_init.copy()
    best_sc = _score(a_init)
    
    for it in range(n_iter):
        if deadline is not None and time.monotonic() > deadline:
            break
        
        # DFT
        A = np.fft.fft(a_padded)
        
        # Flatten magnitude (keep phase)
        mag = np.abs(A)
        mag_mean = mag.mean()
        A_new = mag_mean * A / np.maximum(mag, 1e-30)
        
        # IDFT
        a_padded = np.fft.ifft(A_new).real
        
        # Zero out tail beyond n
        a_padded[n:] = 0
        
        # Clip to non-negative
        a_padded = np.maximum(a_padded, 0)
        
        # Renormalize
        s = a_padded.sum()
        if s < 1e-15:
            break
        a_padded = a_padded / s
        
        # Check every 20 iterations
        if it % 20 == 0:
            sc = _score(a_padded[:n])
            if sc < best_sc:
                best_sc = sc
                best_a = a_padded[:n].copy()
    
    return best_a, best_sc


def _smoobj(z, beta, n):
    a = _softmax(z)
    c = _full_convolve(a, a)
    c_max = float(c.max())
    shifted = (c - c_max) / beta
    e = np.exp(np.clip(shifted, -700, 0))
    s = e.sum()
    if s < 1e-300 or not np.isfinite(s):
        return 2.0 * n * c_max
    return 2.0 * n * (c_max + beta * np.log(s))


def _smograd(z, beta, n):
    a = _softmax(z)
    c = _full_convolve(a, a)
    c_max = float(c.max())
    shifted = (c - c_max) / beta
    e = np.exp(np.clip(shifted, -700, 0))
    s = e.sum()
    if s < 1e-300 or not np.isfinite(s):
        w = np.zeros_like(c)
        w[int(np.argmax(c))] = 1.0
    else:
        w = e / s
    a_rev = a[::-1]
    wc = _full_convolve(w, a_rev)
    h = wc[n - 1:2 * n - 1]
    W = float(np.dot(w, c))
    return 4.0 * n * a * (h - W)


def _lbfgs_polish(a_init, deadline, min_remaining=30.0):
    """L-BFGS with adaptive beta."""
    n = len(a_init)
    c_cur = _full_convolve(a_init, a_init)
    max_c = float(c_cur.max())
    
    if time.monotonic() + min_remaining > deadline:
        return a_init
    
    # Beta schedule
    c_sorted = np.sort(c_cur)[::-1]
```

```python
def _next_pow2(n):
    k = 1
    while k < n:
        k <<= 1
    return max(2, k)


def _full_convolve(a, b):
    n, m = len(a), len(b)
    out_n = n + m - 1
    N = _next_pow2(out_n)
    fa = np.fft.rfft(a, N)
    fb = np.fft.rfft(b, N)
    r = np.fft.irfft(fa * fb, N)[:out_n]
    return r


def _score(a):
    n = len(a)
    s = float(a.sum())
    if s < 1e-15:
        return np.inf
    c = _full_convolve(a, a)
    return float(2.0 * n * c.max() / (s * s))


def _softmax(z):
    z = z - np.max(z)
    e = np.exp(np.clip(z, -700, 700))
    s = e.sum()
    if s < 1e-300:
        return np.ones_like(z) / len(z)
    return e / s


def _project_simplex(v):
    """Project v onto {x >= 0, sum(x) = 1} via bisection on tau."""
    n = len(v)
    vmin = float(v.min())
    vmax = float(v.max())
    lo = vmin
    hi = vmax
    for _ in range(60):
        mid = (lo + hi) * 0.5
        s = np.maximum(v - mid, 0.0).sum()
        if s > 1.0:
            lo = mid
        else:
            hi = mid
    tau = (lo + hi) * 0.5
    result = np.maximum(v - tau, 0.0)
    # Ensure exact sum = 1
    s = result.sum()
    if s > 1e-15:
        result = result / s
    return result


def _compute_mirror_grad(b, a, m_peaks):
    """Compute mirror gradient for top-m peaks. O(n*m)."""
    n = len(a)
    nb = len(b)
    m = min(m_peaks, nb)
    if m >= nb:
        peak_idx = np.arange(nb)
    else:
        peak_idx = np.argpartition(-b, m - 1)[:m]
    grad = np.zeros(n)
    for k in peak_idx:
        ki = int(k)
        lo = max(0, ki - n + 1)
        hi = min(n - 1, ki)
        if lo <= hi:
            seg = a[ki - hi:ki - lo + 1][::-1]
            grad[lo:hi + 1] += seg
        if ki % 2 == 0:
            p = ki // 2
            if 0 <= p < n:
                grad[p] += a[p]
    grad /= float(m)
    return grad


def _mirror_descent(a_init, deadline, m_peaks_list=None, lr_init=0.4,
                    steps_per_m=30000, check_interval=50):

    if m_peaks_list is None:

    n = len(a_init)
    a = a_init.copy()
    best_a = a.copy()
    best_sc = _score(a)
    lr = lr_init
    total_steps = 0
    patience = 0
    for m_peaks in m_peaks_list:
        for _ in range(steps_per_m):
            if time.monotonic() > deadline:
                break
            total_steps += 1
            b = _full_convolve(a, a)
            b_max = float(b.max())
            grad = _compute_mirror_grad(b, a, m_peaks)
            grad_norm = np.linalg.norm(grad)
            if grad_norm < 1e-15:
                break
            step_size = lr * b_max / (grad_norm + 1e-15)
            a_new = a - step_size * grad
            a_new = _project_simplex(a_new)
            if total_steps % check_interval == 0:
                sc = _score(a_new)
                if sc < best_sc - 1e-12:
                    improved = best_sc - sc

                    patience = 0

                else:

                    lr = max(lr * 0.92, 0.02)

                        patience = 0

    sc_final = _score(a)

def _coord_descent(a_init, deadline, n_rounds=200, step_size=0.005):
    """Coordinate descent: try perturbing each element up/down."""

    rng = np.random.default_rng(12345)
    for rnd in range(n_rounds):
        if time.monotonic() > deadline:
            break
        order = rng.permutation(n)
        for i in order:
            if time.monotonic() > deadline:
                break
            orig = a[i]
            if orig < 1e-12:
                # Try small positive value
                a[i] = 1e-4
                s = a.sum()
                if s > 0.01:
                    sc = _score(a)
                    if sc < best_sc:
                        best_sc = sc
                        best_a = a.copy()
                    else:
                        a[i] = 0.0
                else:
                    a[i] = 0.0
                continue
            # Try decreasing
            delta = step_size * orig
            a[i] = orig - delta
            s = a.sum()
            if s > 0.01:
                a_norm = a / s
                sc = _score(a_norm)
                if sc < best_sc:
                    best_sc = sc
                    best_a = a_norm.copy()

                    continue
            # Try increasing

                    best_a = a_norm.copy()
                    a = a_norm.copy()
                    continue
            a[i] = orig
        if best_sc < _score(a):
            a = best_a.copy()
    return best_a, best_sc

            parent_raw = np.clip(parent_raw, 0.0, 1000.0)
            s = float(parent_raw.sum())
            if s > 0.01:
                parent = parent_raw / s
                n_parent = len(parent)
    except Exception:
        pass

    if parent is not None:
        print(f"Parent: n={n_parent}, score={_score(parent):.10f}")
        update_best(parent, _score(parent))
    else:
        n_parent = 4096
        t = np.linspace(0, 1, n_parent)
        parent = np.sin(np.pi * t) ** 0.5
        parent = parent / parent.sum()
        print(f"No parent, using tapered n={n_parent}")
        update_best(parent, _score(parent))

    n = len(parent)

    # Phase 1: GS flattening (fast initialization)
    print(f"\n[Phase 1] GS flatten (t={time.monotonic() - t_start:.1f}s)")
    a_gs, sc_gs = _gs_flatten(parent, n_iter=300, deadline=min(deadline - 100, t_start + 30))
    update_best(a_gs, sc_gs)

    # Phase 2: Mirror gradient descent (main workhorse)
    print(f"\n[Phase 2] Mirror gradient descent (t={time.monotonic() - t_start:.1f}s)")
    # First pass: coarse (larger m)
    a_m1, sc_m1 = _mirror_descent(best_seq, min(deadline - 300, t_start + 400),
                                  m_peaks_list=[80, 40, 20], lr_init=0.5,
                                  steps_per_m=15000, check_interval=50)
    update_best(a_m1, sc_m1)

    # Second pass: fine (smaller m)
    a_m2, sc_m2 = _mirror_descent(best_seq, min(deadline - 200, t_start + 800),
                                  m_peaks_list=[10, 5, 3, 2], lr_init=0.3,
                                  steps_per_m=20000, check_interval=30)
    update_best(a_m2, sc_m2)

    # Phase 3: L-BFGS polish
    print(f"\n[Phase 3] L-BFGS polish (t={time.monotonic() - t_start:.1f}s)")
    if best_seq is not None and time.monotonic() < deadline - 120:
        a_lb = _lbfgs_polish(best_seq, deadline, min_remaining=80.0)
        update_best(a_lb, _score(a_lb))

    # Phase 4: Subgradient polish
    print(f"\n[Phase 4] Subgradient polish (t={time.monotonic() - t_start:.1f}s)")
    if best_seq is not None and time.monotonic() < deadline - 80:
        a_sg, sc_sg = _subgrad_polish(best_seq, min(deadline - 60, time.monotonic() + 80),
                                      n_max_steps=2000, lr_init=0.015)
        update_best(a_sg, sc_sg)

    # Phase 5: Coordinate descent
    print(f"\n[Phase 5] Coordinate descent (t={time.monotonic() - t_start:.1f}s)")
    if best_seq is not None and time.monotonic() < deadline - 40:
        a_cd, sc_cd = _coord_descent(best_seq, min(deadline - 20, time.monotonic() + 60),
                                     n_rounds=100, step_size=0.003)
        update_best(a_cd, sc_cd)

    # Phase 6: Diverse restarts if time allows
    print(f"\n[Phase 6] Diverse restarts (t={time.monotonic() - t_start:.1f}s)")
    if best_seq is not None and time.monotonic() < deadline - 60:
        for i in range(3):
            if time.monotonic() > deadline - 30:
                break
            if i == 0:
                p_start = _perturb(best_seq, 0.03, rng)
            elif i == 1:
                p_start = _perturb_fourier(best_seq, rng, n_modes=5)
            else:
                p_start = _perturb(best_seq, 0.06, rng)
            a_r, sc_r = _mirror_descent(p_start, min(deadline - 20, time.monotonic() + 40),
                                        m_peaks_list=[10, 5, 3], lr_init=0.3,
                                        steps_per_m=8000, check_interval=30)
            update_best(a_r, sc_r)
            if sc_r < best_score + 0.001 and time.monotonic() < deadline - 15:
                a_r2, sc_r2 = _lbfgs_polish(a_r, deadline, min_remaining=10.0)
                update_best(a_r2, _score(a_r2))

    # Phase 7: Final fine polish
    print(f"\n[Phase 7] Final polish (t={time.monotonic() - t_start:.1f}s)")
    if best_seq is not None and time.monotonic() < deadline - 5:
        a_fin, sc_fin = _subgrad_polish(best_seq, deadline - 3, n_max_steps=500, lr_init=0.008)
        update_best(a_fin, sc_fin)

    # Final validation
    print(f"\n{'=' * 60}")
    if best_seq is not None:
        final = np.clip(best_seq, 0.0, 1000.0)
        s = float(final.sum())
        if s >= 0.01:
            sc_final = _score(final)
            print(f"FINAL: score={sc_final:.10f}, n={len(final)}, "
                  f"time={time.monotonic() - t_start:.1f}s")
            return [float(x) for x in final]

    # Fallback
    t = np.linspace(0, 1, 256)
    fallback = np.sin(np.pi * t) ** 0.5
    fallback = fallback / fallback.sum()
    print(f"FALLBACK: score={_score(fallback):.10f}")
    return [float(x) for x in fallback]
```
