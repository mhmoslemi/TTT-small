Let me think about this from a variational perspective. We want to minimize max_k c[k] subject to sum(a) = 1, a[i] >= 0.

**Algorithm: Alternating Minimization**

1. Normalize a to have sum 1.

3. Find the active set A = {k : c[k] >= max(c) - ε}.
4. Solve the subproblem: minimize sum_{k in A} c[k] subject to sum(a) = 1, a >= 0.

5. Repeat.

The QP in step 4: minimize sum_{k in A} sum_i a[i]*a[k-i] subject to sum a = 1, a >= 0.
This can be written as minimize a^T Q a where Q is a matrix determined by the active set.

For a fixed active set, this is a convex QP (Q is psd since it's a sum of outer products). We can solve it with any QP solver.

But the active set changes as we iterate, so this is a combinatorial problem. We can use a "warm start" approach: solve the QP, update the active set, repeat.

This is similar to the "active set method" for LPs but adapted for this problem.

This is a standard QP that can be solved with any solver.

The key algorithmic idea:
1. Start with a uniform (or parent) sequence.
2. Compute c = conv(a, a).
3. Select the top-K lags (where K is gradually increased or adaptive).
4. Solve the QP for the top-K lags.
5. Repeat.

This is essentially a "coordinate descent on the lag space" - we're selecting which lags to focus on and optimizing to reduce them.

Let me think about implementation. The QP:

1^T a = 1

So a = -λ * H^{-1} * 1, and λ = -1 / (1^T H^{-1} 1).

Let me now think about what specific improvements to make over the previous program:

1. **QP-based active set method**: Instead of just gradient descent, periodically solve the QP for the active set. This gives exact minimization over the current active set.

2. **Better smoothing schedule**: The top-K softmax approach in the previous program is a good approximation, but we can make it more aggressive (smaller K) in the later stages.

3. **Symmetry exploitation**: If we enforce that a is symmetric (a[i] = a[n-1-i]), we halve the number of variables and the problem becomes easier. But this might not be optimal.

4. **Multi-scale approach**: Start with a small sequence (e.g., n=64), optimize it well, then upscale and continue. This avoids getting stuck in bad local minima.

5. **Spectral shaping**: Periodically adjust the sequence in the frequency domain to flatten the power spectrum.

import numpy as np
import time
from scipy.optimize import minimize

def _next_pow2(n):
    k = 1
    while k < n:
        k <<= 1
    return max(2, k)

def _full_convolve(a, b):
    n, m = len(a), len(b)
    out_n = n + m - 1
    N = _next_pow2(out_n)
    fa = np.fft.rfft(a, N)
    fb = np.fft.rfft(b, N)
    r = np.fft.irfft(fa * fb, N)[:out_n]
    return r

def _score(a):
    n = len(a)
    s = float(a.sum())
    if s < 1e-15:
        return np.inf
    c = _full_convolve(a, a)
    return float(2.0 * n * c.max() / (s * s))

def _score_norm(a):
    n = len(a)
    c = _full_convolve(a, a)
    return float(2.0 * n * c.max())

def _proj_simplex(v):
    """Project v onto the probability simplex {x >= 0, sum(x) = 1}."""
    n = len(v)
    if n == 0:
        return v
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    idx = np.arange(1, n + 1, dtype=np.float64)
    cond = u * idx > (cssv - 1.0)
    rho = np.where(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)

def _compute_grad_conv(a, w):
    """Compute gradient of <w, conv(a,a)> wrt a using FFT."""
    n = len(a)
    N = _next_pow2(2 * n)
    fa = np.fft.rfft(a, N)
    fw = np.fft.rfft(w, N)
    h = np.fft.irfft(np.conj(fa) * fw, N)[:n]
    return 2.0 * h

def _topk_weights(c, k):
    """Get hard top-K weights (uniform over top K)."""
    n_c = len(c)
    if k >= n_c:
        w = np.ones(n_c) / n_c
    else:
        thresh = np.partition(c, n_c - k)[n_c - k]
        mask = c >= thresh
        w = mask.astype(float) / mask.sum()
    return w

def _topk_softmax_weights(c, beta, k):
    """Softmax weights over top-K elements."""
    n_c = len(c)
    k = min(k, n_c)
    thresh = np.partition(c, n_c - k)[n_c - k]
    mask = c >= thresh
    indices = np.where(mask)[0]
    c_top = c[indices]
    c_max = c_top.max()
    exp_vals = np.exp((c_top - c_max) / beta)
    w_sum = exp_vals.sum()
    w = np.zeros(n_c)
    if w_sum < 1e-300:
        w[indices[0]] = 1.0
    else:
        w[indices] = exp_vals / w_sum
    return w

def _logspace_adam(a_init, deadline, beta_schedule, lr_init, top_k, max_iter, momentum_decay=0.5):
    """Adam in log-space with top-K smoothed max."""
    n = len(a_init)
    z = np.log(np.maximum(a_init, 1e-15))
    z = z - z.mean()
    
    best_a = a_init.copy()
    best_score = _score_norm(a_init)
    
    m_buf = np.zeros(n)
    v_buf = np.zeros(n)
    t = 0
    b1, b2, eps = 0.9, 0.999, 1e-8
    current_lr = lr_init
    
    for beta in beta_schedule:
        if time.monotonic() > deadline:
            break
        it_in_phase = 0
        while it_in_phase < max_iter:
            if time.monotonic() > deadline:
                break
            it_in_phase += 1
            t += 1
            
            a = _softmax_normalize(z)
            c = _full_convolve(a, a)
            if beta > 0:
                w = _topk_softmax_weights(c, beta, top_k)
            else:
                w = _topk_weights(c, top_k)
            grad = _logspace_grad(a, c, w, n)
            
            if not np.all(np.isfinite(grad)):
                break
            
            m_buf = b1 * m_buf + (1.0 - b1) * grad
            v_buf = b2 * v_buf + (1.0 - b2) * (grad * grad)
            mh = m_buf / (1.0 - b1**t)
            vh = v_buf / (1.0 - b2**t)
            
            update = current_lr * mh / (np.sqrt(vh) + eps)
            update_norm = np.linalg.norm(update)
            if update_norm > 1.0:
                update = update * (1.0 / update_norm)
            
            z = z - update
            z = np.clip(z, -50.0, 50.0)
            z = z - z.mean()
            
            if t % 100 == 0:
                a_chk = _softmax_normalize(z)
                sc = _score_norm(a_chk)
                if np.isfinite(sc) and sc < best_score:
                    best_score = sc
                    best_a = a_chk.copy()
            
            if it_in_phase % 5000 == 0:
                current_lr = max(0.001, current_lr * 0.95)
        
        # Reset momentum at phase boundaries
        m_buf *= momentum_decay
        v_buf *= momentum_decay
    
    a_final = _softmax_normalize(z)
    sc_final = _score_norm(a_final)
    if np.isfinite(sc_final) and sc_final < best_score:
        best_score = sc_final
        best_a = a_final.copy()
    
    return best_a, best_score

def _logspace_grad(a, c, w, n):
    """Gradient in log-space."""
    grad_a = _compute_grad_conv(a, w)
    mean_grad = float(np.dot(grad_a, a))
    return 2.0 * n * a * (grad_a - mean_grad)

def _softmax_normalize(z):
    z = z - np.max(z)
    e = np.exp(np.clip(z, -50, 50))
    s = e.sum()
    if s < 1e-300:
        return np.ones_like(z) / len(z)
    return e / s
