This is like distributing "mass" 1 over 2n-1 positions (the convolution values) as evenly as possible, subject to the constraint that c = a * a for some non-negative a of length n.

The constraint is very restrictive. Not every distribution c can be written as a * a for non-negative a.

Let me think about what degrees of freedom we have. We have n parameters (a_0, ..., a_{n-1}) and 2n-1 constraints (the convolution values). But the convolution is determined by a, so really we have n free parameters and we're trying to minimize max(c).

For large n, the problem is: given n non-negative parameters, minimize the max of their pairwise "convolution products."

One approach: think of a as a "filter" and c as its "impulse response squared" (in a loose sense). We want the impulse response to be as flat as possible.

In Fourier terms: C(k) = A(k)^2 where A is the DFT of a (zero-padded to length 2n-1). We want |C(k)| to be as flat as possible, which means |A(k)| should be as flat as possible. But A(k) is the DFT of a non-negative sequence, which constrains the possible values of A(k).

Actually, for the LINEAR convolution, the relationship is:
If we zero-pad a to length N ≥ 2n-1 and take the DFT, then the DFT of the zero-padded c is |A(k)|^2.

So we want |A(k)|^2 to be as flat as possible, where A(k) = sum_{i=0}^{n-1} a_i * exp(-2πik/N) for k = 0, ..., N-1.

This is related to the "minimum PAPR" (peak-to-average power ratio) problem in communication systems! The goal is to find a sequence a with minimum PAPR, which is exactly min max|c| / mean|c|.

For the standard PAPR problem (complex sequences), the optimal solution is known to approach 1 as n → ∞ (using Golay complementary sequences or similar). For non-negative real sequences, the problem is harder.

Let me think about specific constructions:

1. **Golay sequences**: These have "complementary" autocorrelation properties. But they typically involve ±1 values, not non-negative.

2. **Binary sequences with low autocorrelation**: Barker codes, m-sequences, etc. But again, these use ±1.

3. **Non-negative constructions**: 
   - Uniform: J = 2
   - Weighted (tapered): J > 2 (we showed this)
   - The question is whether we can get below 2.

Actually, I think the key insight is about the "spacing" of non-zero elements. If we place non-zero elements at positions that are "far apart" (in a modular sense), the cross terms in the convolution will be smaller.

Let me think about this problem more systematically. The objective is:
minimize max_m (a*a)[m]  subject to  sum a_i = 1, a_i ≥ 0

This is a non-convex problem (because of the max). But we can write it as:
minimize t
subject to (a*a)[m] ≤ t for all m
sum a_i = 1
a_i ≥ 0

This IS a convex problem! The constraint (a*a)[m] ≤ t is a quadratic constraint (since (a*a)[m] is a quadratic form in a). And the objective is linear in t.

Wait, is (a*a)[m] ≤ t a convex constraint? (a*a)[m] = sum_k a_k * a_{m-k} is a quadratic form. The set {a : sum_k a_k * a_{m-k} ≤ t} is NOT necessarily convex because the quadratic form matrix might not be positive semidefinite.

Let's check: (a*a)[m] = a^T Q_m a where Q_m is the matrix with Q_m[k, m-k] = 1/2 (for valid k, m-k).

For m = 0: Q_0 has Q_0[0,0] = 1. This is positive semidefinite. ✓
For m = 1: Q_1 has Q_1[0,1] = Q_1[1,0] = 1/2. The matrix [[0, 1/2], [1/2, 0]] has eigenvalues ±1/2. NOT positive semidefinite! ✗

So the constraint is not convex in general. The problem is non-convex.

However, we can still use various optimization techniques:
1. Alternating projections
2. Gradient methods with the max (or a smoothed version)
3. Block coordinate descent
4. Spectral methods
