   d/dx = 10x-4 = 0, x = 0.4, y = 0.2.
   x^2+y^2 = 0.16+0.04 = 0.2.
   score = 6*0.2 = 1.2.
   
   Wait, that's below 2! And below 1.5!
   
   Let me verify: a = [0.4, 0.2, 0.4], sum = 1.
   conv[0] = 0.16
   conv[1] = 2*0.4*0.2 = 0.16
   conv[2] = 0.4^2 + 0.2^2 = 0.16 + 0.04 = 0.2
   conv[3] = 2*0.2*0.4 = 0.16
   conv[4] = 0.16
   
   max = 0.2, score = 2*3*0.2/1 = 1.2.
   
   Wow! So for n=3, we can achieve score = 1.2, much better than uniform (which gives 2).
   
   But wait, is the symmetric assumption optimal? Let me check without it.
   a = [a, b, c], sum = a+b+c = 1.
   conv[0] = a^2
   conv[1] = 2ab
   conv[2] = a*c + b^2
   conv[3] = 2bc
   conv[4] = c^2
   
   We want to minimize max(a^2, 2ab, ac+b^2, 2bc, c^2).
   
   By symmetry, the optimum should have a = c. Let's verify: if a > c, we can swap a and c, and the set {a^2, 2ab, ac+b^2, 2bc, c^2} becomes {c^2, 2cb, ca+b^2, 2ba, a^2} which has the same max. So the optimum is symmetric.
   
   With a = c = x, b = y, 2x+y = 1:
   max(x^2, 2xy, x^2+y^2) = x^2+y^2 (as shown before).
   
   Minimum at x=0.4, y=0.2, giving max = 0.2, score = 1.
