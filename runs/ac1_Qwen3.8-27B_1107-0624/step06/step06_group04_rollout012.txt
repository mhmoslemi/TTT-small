```python
    # Then sum_j z_{i+j} * x_j = sum_j z_{i+j} * x_rev_{n-1-j}
    # Let k = n-1-j: = sum_k z_{i+n-1-k} * x_rev_k
    # = (z_rev * x_rev)[i] where z_rev_j = z_{2n-2-j}
    # Wait: (z_rev * x_rev)[i] = sum_k z_rev_k * x_rev_{i-k} = sum_k z_{2n-2-k} * x_rev_{i-k}
    # That's not quite right either.
    
    # Let me just use the straightforward approach:
    # (M*x)_i = sum_j w_{i+j} * x_j
    # This equals the i-th element of the convolution of w and reversed-x, shifted appropriately.
    
    # Let rx = x[::-1] (reversed x, length n)
    # conv(w, rx)[k] = sum_j w_j * rx[k-j] = sum_j w_j * x_{n-1-(k-j)} = sum_j w_j * x_{n-1-k+j}
    # For k = n-1+i: conv(w, rx)[n-1+i] = sum_j w_j * x_j ... no that's not right either.
    
    # OK let me just do it directly with FFT:
    # We want h_i = sum_{j=0}^{n-1} w_{i+j} * x_j for i = 0, ..., n-1
    # Note that w has length 2n-1 (indices 0 to 2n-2), and i+j ranges from i to i+n-1, which is at most 2n-2. Good.
    
    # Method: h = ifft(fft(w, N) * fft(x_padded, N))[0:n] where x_padded is x placed at specific positions...
    
    # Actually, the simplest FFT method for Hankel matvec:
    # h_i = sum_j w_{i+j} * x_j
    # Let's define y_k = w_k for k = 0, ..., 2n-2
    # h_i = sum_j y_{i+j} * x_j
    # This is the cross-correlation of y and x, evaluated at "negative" lags... 
    # Actually it's: h_i = sum_j y_{i+j} * x_j = <y[i:], x> (inner product of y[i:] and x, truncated to length n)
    
    # The cleanest FFT approach:
    # h = ifft(fft(y, N) * conj(fft(x, N)))[:n] ... no, that gives circular cross-correlation.
    
    # Let me just use: create a matrix-free operator and use CG.
    # For the CG, I need to be able to compute M*x quickly.
    # 
    # Here's a clean FFT method:
    # h_i = sum_{j=0}^{n-1} w_{i+j} * x_j
    # = sum_{j=0}^{n-1} w_{i+j} * x_j
    # Let me define v_k = w_k (length 2n-1) and u_k = x_k (length n)
    # h_i = sum_j v_{i+j} * u_j
    # 
    # Method using FFT:
    # Step 1: Compute V = FFT(v, N) where N >= 3n-2
    # Step 2: Compute U = FFT(u, N) where u is zero-padded
    # Step 3: H = IFFT(V * conj(U)) -- this gives circular cross-correlation
    # But circular != linear for our purposes.
    
    # Actually, for N >= len(v) + len(u) - 1 = 3n-2, the circular correlation equals the linear correlation.
    # Linear cross-correlation: c[m] = sum_k v[k+m] * u[k] for m = -(n-1), ..., 2n-2-n+1 = ..., 
    # Hmm, I'm getting confused with the exact indexing.
    
    # Let me just use numpy's correlate or do it with a careful FFT.
    
    # Simplest approach that works:
    # h_i = sum_j w[i+j] * x[j] for i = 0..n-1, j = 0..n-1
    # This is the same as: for each i, take w[i:i+n] and compute dot product with x.
    # Using FFT: this is a "sliding dot product" which can be done with convolution.
    # 
    # h_i = dot(w[i:i+n], x) = sum_j w[i+j]*x[j]
    # Let x_rev = x[::-1]
    # h_i = sum_j w[i+j] * x_rev[n-1-j]
    # Let k = n-1-j: h_i = sum_k w[i+n-1-k] * x_rev[k]
    # = sum_k w_rev[k] * x_rev[k - (i+n-1-2n+2)] ... this is getting messy.
    
    # Let me just use the following clean approach:
    # h = np.correlate(w, x, mode='valid') -- but this might be slow for large n.
    # Actually np.correlate is O(n*m) in the worst case.
    
    # Better: use FFT-based convolution.
    # h_i = sum_j w[i+j] * x[j]
    # = sum_j w[i+j] * x[j]
    # Define: a = w (length 2n-1), b = x (length n)
    # We want the "anti-diagonal" sums of the outer product... no.
    
    # OK here's the cleanest way I can think of:
    # h_i = sum_{j=0}^{n-1} w_{i+j} * x_j
    # This is equivalent to: h = (w * x_flipped)[n-1 : 2n-1] where x_flipped = x[::-1]
    # Let's verify:
    # (w * x_flipped)[k] = sum_j w_j * x_flipped[k-j] = sum_j w_j * x_{n-1-k+j}
    # For k = n-1+i: = sum_j w_j * x_{n-1-n+1-i+j} = sum_j w_j * x_{j-i}
    # That gives sum_j w_j * x[j-i] which is different from what we want.
    
    # Let me try: h_i = sum_j w_{i+j} * x_j
    # = sum_j w_{i+j} * x_j
    # If I define the convolution (x * w)[k] = sum_j x_j * w_{k-j}:
    # (x * w)[i + 2n-2-j] ... no this is getting too complicated.
    
    # Let me just verify with a small example and use the right formula.
    # For n=3: w = [w0,w1,w2,w3,w4], x = [x0,x1,x2]
    # h_0 = w0*x0 + w1*x1 + w2*x2
    # h_1 = w1*x0 + w2*x1 + w3*x2
    # h_2 = w2*x0 + w3*x1 + w4*x2
    
    # Now (x * w)[k] = sum_j x_j * w[k-j]:
    # (x*w)[0] = x0*w0
    # (x*w)[1] = x0*w1 + x1*w0
    # (x*w)[2] = x0*w2 + x1*w1 + x2*w0
    # (x*w)[3] = x0*w3 + x1*w2 + x2*w1
    # (x*w)[4] = x0*w4 + x1*w3 + x2*w2
    # (x*w)[5] = x1*w4 + x2*w3
    # (x*w)[6] = x2*w4
    
    # So h_0 = (x*w)[2], h_1 = (x*w)[3], h_2 = (x*w)[4]
    # In general: h_i = (x * w)[n-1+i] for i = 0, ..., n-1
    
    # Let me verify: (x*w)[n-1+i] = sum_j x_j * w[n-1+i-j]
    # For n=3, i=0: sum_j x_j * w[2-j] = x0*w2 + x1*w1 + x2*w0 = h_0 ✓
    # For n=3, i=1: sum_j x_j * w[3-j] = x0*w3 + x1*w2 + x2*w1 = h_1 ✓
    # For n=3, i=2: sum_j x_j * w[4-j] = x0*w4 + x1*w3 + x2*w2 = h_2 ✓
    
    # So: h = convolve(x, w)[n-1 : 2n-1]
    # Or equivalently: h = convolve(w, x)[n-1 : 2n-1] (convolution is commutative)
```

Great! So the Hankel matvec is just a convolution! We can compute it in O(n log n) using FFT.

Now, for the fixed-point iteration:
1. Given w (length 2n-1), compute M*a = b where M_{i,j} = w_{i+j}
2. M*a = convolve(a, w)[n-1:2n-1] (by the formula above)
3. We want M*a = c*1 for some c
4. This means convolve(a, w)[n-1:2n-1] = c*1

To solve for a:
- In frequency domain: FFT(a) * FFT(w) = FFT(c*1_padded) ... but this isn't quite right because we're only looking at a subset of the convolution.

Actually, since convolve(a, w) has length 3n-2, and we're looking at positions n-1 to 2n-2, this is equivalent to a "centered" part of the convolution.

In the frequency domain (with zero-padding to size N ≥ 3n-2):
IFFT(FFT(a, N) * FFT(w, N))[n-1:2n-1] = c * 1

This doesn't give a simple frequency-domain equation. But we can still use CG to solve M*a = 1 (where M is the Hankel matrix), since we can compute M*x in O(n log n).

```python
def solve_hankel(w, n, num_iters=100):
    """Solve M*x = 1 where M_{i,j} = w_{i+j} using CG."""
    # M*x = convolve(x, w)[n-1:2n-1]
    b = np.ones(n)
    x = np.ones(n) / n  # initial guess
    
    N = _next_pow2(3 * n - 2)
    W = np.fft.rfft(w, N)
    
    r = b - _hankel_matvec(w, x, N, W)
    p = r.copy()
    rr = np.dot(r, r)
    
    for _ in range(num_iters):
        Ap = _hankel_matvec(w, p, N, W)
        pAp = np.dot(p, Ap)
        if pAp < 1e-30:
            break
        alpha = rr / pAp
        x = x + alpha * p
        r = r - alpha * Ap
        rr_new = np.dot(r, r)
        if rr_new < 1e-20:
            break
        p = r + (rr_new / rr) * p
        rr = rr_new
    
    return x

def _hankel_matvec(w, x, N, W):
    """Compute M*x where M_{i,j} = w_{i+j}, using precomputed FFT of w."""
    X = np.fft.rfft(x, N)
    conv = np.fft.irfft(X * W, N)
    n = len(x)
    return conv[n-1:2*n-1]
```

```python
def fixed_point_iteration(a_init, beta, num_fp_iters=50, num_cg_iters=50):
    n = len(a_init)

        conv = _full_convolve(a, a)

        w = np.exp((conv - cm) / beta)
        w = w / w.sum()

        a_new = solve_hankel(w, n, num_cg_iters)
        
        # Project to non-negative
        a_new = np.maximum(a_new, 0)
        a_new = a_new / a_new.sum()
        
        # Check convergence
        a = a_new
    
    return a
```

Looking at this problem, I need to minimize `2*n*max(convolve(a,a))/(sum(a))^2` over non-negative sequences. The key insight is that at an optimum, the "weighted autocorrelation" should be flat, leading to a fixed-point iteration using Hankel matrix structure that can be solved efficiently via FFT-based CG.

```python
"""
Fixed-point + FISTA + ADAM optimizer for minimizing 2*n*max(conv(a,a))/sum(a)^2.
Key innovation: uses Hankel matrix structure (M_{i,j} = w_{i+j}) with FFT-based CG
to solve the optimality condition directly, combined with spectral flattening and
log-space Adam for fine-tuning. Tries multiple sequence lengths.
"""
import numpy as np
import time


def _next_pow2(n):
    k = 1
    while k < n:
        k <<= 1
    return max(2, k)


def _full_convolve(a, b):
    n = len(a)
    m = len(b)
    out_n = n + m - 1
    N = _next_pow2(out_n)
    fa = np.fft.rfft(a, N)
    fb = np.fft.rfft(b, N)
    r = np.fft.irfft(fa * fb, N)[:out_n]
    return r


def _score(a):
    n = len(a)
    s = float(a.sum())
    if s < 1e-15:
        return np.inf
    c = _full_convolve(a, a)
    return float(2.0 * n * float(c.max()) / (s * s))


def _score_norm(a):
    n = len(a)
    c = _full_convolve(a, a)
    return float(2.0 * n * float(c.max()))


def _hankel_matvec(w, x, N, W_fft):
    """Compute M*x where M_{i,j} = w_{i+j} using precomputed FFT of w."""
    n = len(x)
    X = np.fft.rfft(x, N)
    conv = np.fft.irfft(X * W_fft, N)
    return conv[n - 1:2 * n - 1]


def _solve_hankel_cg(w, n, num_cg_iters=80, damp=0.0):
    """Solve (M + damp*I)*x = 1 where M_{i,j} = w_{i+j} using CG."""
    N = _next_pow2(3 * n - 2)
    W_fft = np.fft.rfft(w, N)
    b = np.ones(n)
    x = np.ones(n) / n

    def matvec(v):
        r = _hankel_matvec(w, v, N, W_fft)
        if damp > 0:
            r = r + damp * v
        return r

    r = b - matvec(x)
    p = r.copy()
    rr = float(np.dot(r, r))
    if rr < 1e-30:
        return x

    for _ in range(num_cg_iters):
        Ap = matvec(p)
        pAp = float(np.dot(p, Ap))
        if pAp < 1e-30:
            break
        alpha = rr / pAp
        x = x + alpha * p
        r = r - alpha * Ap
        rr_new = float(np.dot(r, r))
        if rr_new < 1e-24 * rr:
            break
        p = r + (rr_new / rr) * p
        rr = rr_new

    return x


def _fixed_point_iter(a_init, beta, num_fp=30, num_cg=60, damp=0.0, momentum=0.5):
    """Fixed-point iteration: update w from conv(a), solve Hankel system for a."""
    n = len(a_init)
    a = a_init.copy()
    s = a.sum()
    if s > 0:
        a = a / s
    else:
        a = np.ones(n) / n

    best_a = a.copy()
    best_sc = _score_norm(a)

    for fp_iter in range(num_fp):
        conv = _full_convolve(a, a)
        cm = float(conv.max())
        w = np.exp((conv - cm) / beta)
        w_sum = float(w.sum())
        if w_sum < 1e-30:
            w = np.zeros_like(conv)
            w[int(np.argmax(conv))] = 1.0
        else:
            w = w / w_sum

        a_new = _solve_hankel_cg(w, n, num_cg_iters=num_cg, damp=damp)
        a_new = np.maximum(a_new, 0.0)
        s_new = float(a_new.sum())
        if s_new < 1e-15:
            a_new = np.ones(n) / n
        else:
            a_new = a_new / s_new

        # Momentum
        a = (1.0 - momentum) * a + momentum * a_new

        sc = _score_norm(a)
        if sc < best_sc:
            best_sc = sc
            best_a = a.copy()

    return best_a, best_sc


def _proj_simplex(v):
    n = len(v)
    if n == 0:
        return v
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    idx = np.arange(1, n + 1, dtype=np.float64)
    cond = u * idx > (cssv - 1.0)
    if not np.any(cond):
        return np.ones(n) / n
    rho = np.where(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)


def _softmax_compute(z):
    z = z - np.max(z)
    e = np.exp(z)
    s = e.sum()
    if s < 1e-300:
        return np.ones_like(z) / len(z)
    return e / s


def _compute_grad_simplex(y, w):
    n = len(y)
    a_rev = y[::-1]
    wc = _full_convolve(w, a_rev)
    h = wc[n - 1:2 * n - 1]
    return 2.0 * h


def _fista_smoothed(a_init, beta, deadline, max_iter):
    n = len(a_init)
    a_curr = a_init.copy()
    s = a_curr.sum()
    if s > 0:
        a_curr = a_curr / s
    else:
        a_curr = np.ones(n) / n
    a_prev = a_curr.copy()
    t_val = 1.0

    c_init = _full_convolve(a_curr, a_curr)
    max_c_init = float(c_init.max())
    if beta <= 0:
        beta = 1e-6 * max_c_init
    L = 4.0 * n / beta
    step = 1.0 / L
    best_score = _score_norm(a_curr)
    best_a = a_curr.copy()

    for it in range(max_iter):
        if time.monotonic() > deadline:
            break

        t_next = (1.0 + np.sqrt(1.0 + 4.0 * t_val * t_val)) / 2.0
        y = a_curr + ((t_val - 1.0) / t_next) * (a_curr - a_prev)
        y = np.maximum(y, 0.0)
        s_y = y.sum()
        if s_y > 1e-30:
            y = y / s_y
        else:
            y = np.ones(n) / n

        c_y = _full_convolve(y, y)
        cm = float(c_y.max())
        c_shifted = (c_y - cm) / beta
        e = np.exp(c_shifted)
        w_sum = float(e.sum())
        if w_sum < 1e-300 or not np.isfinite(w_sum):
            w = np.zeros_like(c_y)
            w[int(np.argmax(c_y))] = 1.0
        else:
            w = e / w_sum

        grad = _compute_grad_simplex(y, w)
        a_next = _proj_simplex(y - step * grad)

        if it % 200 == 0 or it < 5:
            sc = _score_norm(a_next)
            if sc < best_score:
                best_score = sc
                best_a = a_next.copy()

        a_prev = a_curr.copy()
        a_curr = a_next
        t_val = t_next

    sc_final = _score_norm(a_curr)
    if sc_final < best_score:
        best_score = sc_final
        best_a = a_curr.copy()

    return best_a, best_score


def _adam_logspace(a_init, deadline, beta_schedule, lr_init, max_iter_total,
                   lr_decay_every=5000, lr_decay_factor=0.97, grad_clip=1.0):
    n = len(a_init)
    a_norm = a_init.copy()
    s = a_norm.sum()
    if s > 0:
        a_norm = a_norm / s
    else:
        a_norm = np.ones(n) / n

    z = np.log(np.maximum(a_norm, 1e-15))
    z = z - z.mean()

    best_a = a_norm.copy()
    best_score = _score_norm(a_norm)

    m_buf = np.zeros(n)
    v_buf = np.zeros(n)
    t = 0
    b1, b2, eps = 0.9, 0.999, 1e-8
    current_lr = lr_init
    no_improve_count = 0

    for beta in beta_schedule:
        if time.monotonic() > deadline:
            break
        while t < max_iter_total:
            if time.monotonic() > deadline:
                break
            t += 1

            a = _softmax_compute(z)
            c = _full_convolve(a, a)
            cm = float(c.max())
            c_shifted = (c - cm) / beta
            e = np.exp(c_shifted)
            s_w = float(e.sum())
            if s_w < 1e-300 or not np.isfinite(s_w):
                w = np.zeros_like(c)
                w[int(np.argmax(c))] = 1.0
            else:
                w = e / s_w

            # Gradient in log-space
            a_rev = a[::-1]
            wc = _full_convolve(w, a_rev)
            h = wc[n - 1:2 * n - 1]
            W = float(np.dot(w, c))
            grad = 2.0 * a * (h - W)

            if not np.all(np.isfinite(grad)):
                break

            m_buf = b1 * m_buf + (1.0 - b1) * grad
            v_buf = b2 * v_buf + (1.0 - b2) * (grad * grad)
            mh = m_buf / (1.0 - b1 ** t)
            vh = v_buf / (1.0 - b2 ** t)

            update = current_lr * mh / (np.sqrt(vh) + eps)
            update_norm = np.linalg.norm(update)
            if update_norm > grad_clip:
                update = update * (grad_clip / update_norm)

            z = z - update
            z = np.clip(z, -50.0, 50.0)
            z = z - z.mean()

            if t % 50 == 0:
                a_chk = _softmax_compute(z)
                sc = _score_norm(a_chk)
                if np.isfinite(sc) and sc < best_score:
                    best_score = sc
                    best_a = a_chk.copy()
                    no_improve_count = 0
                else:
                    no_improve_count += 1

            if t % lr_decay_every == 0:
                current_lr = max(0.0003, current_lr * lr_decay_factor)

            if no_improve_count > 80 and t > 2000:
                current_lr = max(0.0003, current_lr * 0.92)

    a_final = _softmax_compute(z)
    sc_final = _score_norm(a_final)
    if np.isfinite(sc_final) and sc_final < best_score:
        best_score = sc_final
        best_a = a_final.copy()

    return best_a, best_score


def _spectral_flatten(a_init, n_iter=300, deadline=None):
    n = len(a_init)
    a = a_init.copy()
    a = np.maximum(a, 0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n)
    a = a / a.sum()

    best_a = a.copy()
    best_score = _score_norm(a)
    N_fft = _next_pow2(2 * n - 1)

    for it in range(n_iter):
        if deadline is not None and time.monotonic() > deadline:
            break
        A = np.fft.rfft(a, N_fft)
        mag = np.abs(A)
        avg_mag = mag.mean()
        # Partial flattening (mix current with flat)
        mix = 0.5 + 0.3 * (it / max(n_iter, 1))
        target_mag = mix * avg_mag + (1 - mix) * mag
        phase = A / (mag + 1e-30)
        A_new = phase * target_mag
        a_new = np.fft.irfft(A_new, N_fft)[:n]
        a_new = np.maximum(a_new, 0)
        s_new = a_new.sum()
        if s_new < 1e-15:
            break
        a_new = a_new / s_new
        a = a_new
        if it % 20 == 0:
            sc = _score_norm(a)
            if sc < best_score:
                best_score = sc
                best_a = a.copy()

    sc_final = _score_norm(a)
    if sc_final < best_score:
        best_score = sc_final
        best_a = a.copy()

    return best_a, best_score


def _interp_profile(p, n_new):
    n0 = len(p)
    if n0 == n_new:
        return p.copy()
    x0 = np.linspace(0, 1, n0)
    x1 = np.linspace(0, 1, n_new)
    p_new = np.interp(x1, x0, p)
    p_new = np.maximum(p_new, 1e-12)
    return p_new / p_new.sum()


def _perturb(a, sigma, rng):
    z = np.log(np.maximum(a, 1e-15))
    z = z + sigma * rng.standard_normal(len(a))
    z = z - z.mean()
    return _softmax_compute(z)


def _make_profile(n, kind="uniform"):
    if kind == "uniform":
        return np.ones(n) / n
    elif kind == "cosine":
        t = np.linspace(0, 1, n)
        a = 1.0 + 0.3 * np.cos(2.0 * np.pi * t)
        a = np.maximum(a, 1e-10)
        return a / a.sum()
    elif kind == "tapered":
        t = np.linspace(0, 1, n)
        a = np.sin(np.pi * t) ** 0.3
        a = np.maximum(a, 1e-10)
        return a / a.sum()
    elif kind == "random":
        a = np.random.default_rng(0).random(n)
        return a / a.sum()
    else:
        return np.ones(n) / n


def _zadoff_chu_nonneg(n):
    """Create a non-negative sequence inspired by Zadoff-Chu (flat spectrum)."""
    # Use a chirp-like structure
    idx = np.arange(n)
    # Smooth chirp
    phase = 2.0 * np.pi * idx * (idx + 1) / (2 * n)
    a = np.abs(np.cos(phase)) + 0.5
    return a / a.sum()


def propose_candidate(seed=42, budget_s=1800):
    t_start = time.monotonic()
    deadline = t_start + max(1.0, float(budget_s) - 30.0)
    rng = np.random.default_rng(int(seed) % (2**63 - 1))

    best_seq = None
    best_score = np.inf

    # Load parent
    parent = None
    try:
        parent_raw = np.asarray(height_sequence_1, dtype=np.float64).ravel()
        if parent_raw.size > 0:
            parent_raw = np.clip(parent_raw, 0.0, 1000.0)
            s = float(parent_raw.sum())
            if s > 0.01:
                parent = parent_raw / s
    except Exception:
        parent = None

    # Determine working n values
    n_values = [4096, 8192, 16384]
    if parent is not None:
        n_parent = len(parent)
        if n_parent not in n_values:
            n_values.insert(0, n_parent)
        print(f"Parent: n={n_parent}, score={_score(parent):.10f}")
        best_seq = parent.copy()
        best_score = _score(parent)
    else:
        print("No parent available, starting from scratch")
        best_seq = _make_profile(4096, "uniform")
        best_score = _score(best_seq)
        print(f"Uniform n=4096: score={best_score:.10f}")

    # === Phase 1: Spectral flattening for quick improvement ===
    print("Phase 1: Spectral flattening")
    phase1_end = min(deadline, t_start + 40.0)
    a_work = best_seq.copy() / best_seq.sum()
    a_sf, sc_sf = _spectral_flatten(a_work, n_iter=200, deadline=phase1_end)
    sc_sf_full = _score(a_sf)
    if sc_sf_full < best_score:
        best_score = sc_sf_full
        best_seq = a_sf.copy()
        print(f"  Spectral flatten: score={sc_sf_full:.10f} t={time.monotonic()-t_start:.1f}s")

    a_work = best_seq.copy() / best_seq.sum()

    # === Phase 2: Fixed-point iteration (MAIN NEW IDEA) ===
    print("Phase 2: Fixed-point iteration with Hankel CG")
    phase2_end = min(deadline, t_start + 350.0)
    n_main = len(a_work)

    # Beta continuation for fixed-point
    c_curr = _full_convolve(a_work, a_work)
    max_cc = float(c_curr.max())

    betas_fp = []
    b = 0.02 * max_cc
    while b > 0.00001 * max_cc:
        betas_fp.append(b)
        b *= 0.5
    if len(betas_fp) > 10:
        betas_fp = betas_fp[:10]

    a_fp = a_work.copy()
    for i, b in enumerate(betas_fp):
        if time.monotonic() > phase2_end - 10:
            break
        remaining = phase2_end - time.monotonic() - 5
        n_fp_iters = min(40, max(10, int(remaining / max(len(betas_fp) - i, 1) / 5)))
        n_cg = min(80, max(30, int(n / 100)))

        a_fp, sc_fp = _fixed_point_iter(a_fp, b, num_fp=n_fp_iters, num_cg=n_cg,
                                         damp=0.01 * max_cc / n_main)
        a_fp = a_fp / a_fp.sum()
        sc_fp_full = _score(a_fp)
        if sc_fp_full < best_score:
            best_score = sc_fp_full
            best_seq = a_fp.copy()
            print(f"  FP beta={b:.6f}: score={sc_fp_full:.10f} t={time.monotonic()-t_start:.1f}s")

    print(f"End Phase 2: score={best_score:.10f}")
    a_work = best_seq.copy() / best_seq.sum()

    # === Phase 3: FISTA polish ===
    print("Phase 3: FISTA polish")
    phase3_end = min(deadline, t_start + 550.0)
    if time.monotonic() < phase3_end - 10:
        c_w = _full_convolve(a_work, a_work)
        max_cw = float(c_w.max())
        betas_fista = []
        b = 0.005 * max_cw
        while b > 0.00002 * max_cw:
            betas_fista.append(b)
            b *= 0.5
        if len(betas_fista) > 8:
            betas_fista = betas_fista[:8]

        a_fista = a_work.copy()
        for b in betas_fista:
            if time.monotonic() > phase3_end - 5:
                break
            per_t = phase3_end - time.monotonic() - 3
            a_fista, _ = _fista_smoothed(a_fista, b, time.monotonic() + min(30.0, per_t), 10000)
            a_fista = a_fista / a_fista.sum()
            sc_f = _score(a_fista)
            if sc_f < best_score:
                best_score = sc_f
                best_seq = a_fista.copy()
                print(f"  FISTA beta={b:.6f}: score={sc_f:.10f} t={time.monotonic()-t_start:.1f}s")

    a_work = best_seq.copy() / best_seq.sum()

    # === Phase 4: ADAM log-space fine-tuning ===
    print("Phase 4: ADAM log-space fine-tuning")

    if time.monotonic() < phase4_end - 20:
        c_w = _full_convolve(a_work, a_work)

            print(f"  ADAM: score={sc_adam:.10f} t={time.monotonic()-t_start:.1f}s")

    print("Phase 5: Multi-restart diversification")

            if r < 0.2:
                p_start = _perturb(a_work, 0.02 + 0.01 * i, rng)
            elif r < 0.4:
                p_start = _zadoff_chu_nonneg(n_best)
            elif r < 0.6:
                p_start = _perturb(a_work, 0.05, rng)
            elif r < 0.8:

                p_start = p_sf
            else:
                p_struct = _make_profile(n_best, ["cosine", "tapered"][i % 2])
                mix = 0.3
                p_start = mix * p_struct + (1 - mix) * a_work
                p_start = np.maximum(p_start, 1e-10)
                p_start = p_start / p_start.sum()

            # Quick fixed-point
            c_s = _full_convolve(p_start, p_start)

            beta_r = 0.01 * max_cs
            p_opt, _ = _fixed_point_iter(p_start, beta_r, num_fp=15,

            if time.monotonic() < phase5_end - 15:

                p_opt, _ = _fista_smoothed(p_opt, beta_f, time.monotonic() + max(2.0, per_restart * 0.2), 3000)
                p_opt = p_opt / p_opt.sum()

            # Quick Adam
            if time.monotonic() < phase5_end - 10:

    print("Phase 6: Larger n exploration")
    phase6_end = min(deadline, t_start + 1550.0)

                    a_l_opt = a_l_opt / a_l_opt.sum()
```
