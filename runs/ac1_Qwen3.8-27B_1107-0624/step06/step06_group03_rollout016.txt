from scipy.optimize import linprog

def lp_best_response(f):
    """Find g >= 0 maximizing sum(g) subject to (f*g)_j <= M for all j."""
    n = len(f)
    M = np.max(np.convolve(f, f))
    
    # Constraint matrix: A @ g <= M * ones(2n-1)
    # (f*g)_j = sum_k f_k * g_{j-k} for valid k
    # For constraint j: sum_{k=max(0,j-n+1)}^{min(j,n-1)} f_k * g[j-k] <= M
    # Let l = j-k, so k = j-l. Constraint j: sum_{l=max(0,j-n+1)}^{min(j,n-1)} f[j-l] * g_l <= M
    
    # This is a banded matrix. Row j has non-zeros at positions l where max(0,j-n+1) <= l <= min(j,n-1)
    # A[j, l] = f[j-l] for valid l
    
    # Using scipy.sparse for efficiency
    from scipy import sparse
    
    # Build sparse matrix
    rows = []
    cols = []
    vals = []
    for j in range(2*n-1):
        l_min = max(0, j-n+1)
        l_max = min(j, n-1)
        for l in range(l_min, l_max+1):
            rows.append(j)
            cols.append(l)
            vals.append(f[j-l])
    
    A = sparse.csr_matrix((vals, (rows, cols)), shape=(2*n-1, n))
    b = np.full(2*n-1, M)
    c = -np.ones(n)  # minimize -sum(g)
    
    result = linprog(c, A_ub=A, b_ub=b, bounds=[(0, None)]*n, method='highs')
    return result.x

One more thought: instead of solving the full LP at each iteration (which might take 0.1-1 second), I can use a **multiplicative weights** approximation. The LP:
max sum(g) s.t. A@w <= M, w >= 0

where A is the convolution matrix. The dual is:
min M * sum(y) s.t. A^T @ y >= 1, y >= 0

The primal solution at the optimum satisfies complementary slackness. But solving this directly is the LP.

An alternative is to use the **multiplicative weights algorithm (MWA)**:
Initialize w = uniform
Repeat:
  - Compute v = A @ w (i.e., f*w)
  - Find the violated constraints: j where v_j > M (or the largest v_j)
  - Update: w_k *= exp(-eta * (v_k - M)/M) for the violated constraints
  - Normalize w to sum=1

This is an approximate LP solver that runs in O(1/eta^2) iterations. Each iteration is O(n) (compute A@w via FFT, then update w). So total time is O(n^2/eta^2 / log n) (with FFT for the mat-vec).

Actually, this is essentially the exponential weights / multiplicative weights approach for the LP, which converges in O(sqrt(n)/epsilon) iterations to an epsilon-approximate solution. For our purposes (we don't need an exact LP solution, just a good direction), this might be sufficient.
