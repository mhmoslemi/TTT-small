1. Start with an initial `a` (e.g., parent or uniform)
2. At each iteration:
   a. Compute `c = conv(a, a)`
   b. Compute a "target" autocorrelation `c_target` (e.g., a smoothed version of `c` with the peak reduced)
   c. Find `a_new` whose autocorrelation is closer to `c_target`
   d. Update `a = a_new`

Step 2c is the hard part. One way: use the fact that in the frequency domain, if `C_target(f) = DFT(c_target)`, then we need `|A(f)|^2 = C_target(f)`, so `|A(f)| = sqrt(C_target(f))`. Then `A(f) = sqrt(C_target(f)) * exp(i * phase(f))`. We need to choose the phase so that `IFFT(A) >= 0`.

This is the **Gerchberg-Saxton** type alternating projection:
- Project onto the set of sequences with the desired power spectrum
- Project onto the set of non-negative sequences

Let me implement this:

**Gerchberg-Saxton for our problem:**

```
Initialize a (non-negative, sum = 1)
Repeat:
    1. Compute A = DFT(a)
    2. Compute C = |A|^2 (power spectrum)
    3. Compute c = IFFT(C) (autocorrelation, real)
    4. Design C_target: flatten the peaks of c
       e.g., C_target = C / c[k*] * (some smoothing)
       Or: C_target = max(C, epsilon * mean(C)) (raise the floor)
    5. Set |A_new| = sqrt(C_target), keep phase of A
    6. a_new = IFFT(A_new)
    7. Project a_new to non-negative: a_new = max(a_new, 0)
    8. Normalize: a_new = a_new / sum(a_new)
    9. a = a_new
```

This is promising! The key is step 4: how to design `C_target`.

A natural choice: `C_target[f] = C[f] / (c[k*] / c_mean)` where `c_mean = 1/(2n-1)`. But this doesn't quite work because we need `C_target` to be non-negative (which it is since `C >= 0`).

Actually, a better approach: We want to reduce the peak of `c` while keeping the sum fixed. So:
- `c_target[k] = min(c[k], c_max * tau)` for some `tau < 1` (clip the peaks)
- Then rescale so that `sum(c_target) = 1`
- `C_target = DFT(c_target)` (which should be non-negative if `c_target` is a valid PSD)

But `DFT(c_target)` might not be non-negative, so we need to be careful.

- Or simply: `C_target[f] = max(C[f], floor)` where `floor = tau * C_mean`

Let me think about this more carefully. The autocorrelation peak at lag `k*` is:
`c[k*] = (1/N) sum_f C[f] * exp(2*pi*i*f*k*/N)`

To reduce `c[k*]`, we want to reduce the contribution of frequencies that are "aligned" with lag `k*`. But this is complex.

- Make the autocorrelation more "spread out" (less peaked)
- The effect is to reduce the peak of the autocorrelation
