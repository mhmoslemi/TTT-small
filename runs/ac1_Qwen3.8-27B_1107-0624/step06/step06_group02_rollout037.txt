The number of non-zeros: for row k, the number of non-zeros is min(k+1, n, 2n-1-k). Total non-zeros = sum_{k=0}^{2n-2} min(k+1, n, 2n-1-k) = n^2 (as computed earlier).

For n=4096: ~16.7M non-zeros. As a CSR matrix, this is about 16.7M * (8 + 4 + 8) bytes ≈ 400MB. That's a lot!

2. **Reduce n** for the LP: use n=1024 or n=2048 for the LP, then use the result to guide optimization at n=4096.
3. **Use the structure**: The matrix is a "convolution matrix" which can be multiplied with a vector in O(n log n) using FFT. We could implement a custom LP solver that exploits this, but that's complex.
4. **Subset of constraints**: Instead of all 2n-1 constraints, use only a subset (e.g., every other constraint, or only the "tight" ones). This reduces the problem size.

Option 4 is interesting. At the current iterate a, only a few constraints are "active" (i.e., (a*a)[k] is close to M). We could use a "cutting plane" approach:
- Start with a small set of constraints (e.g., just k=0 and k=n-1)
- Solve the LP
- Check which constraints are violated by the solution
- Add the most violated constraint
- Repeat until no constraint is violated

This is the "separation oracle" approach for LPs. The separation is easy: just compute the full convolution and find the max.

```python
def _lp_separation_method(a, M, max_iters=100):
    """
    Solve: max sum(g) s.t. g >= 0, (a*g)[k] <= M for all k
    Using cutting plane / separation oracle.
    """
    n = len(a)
    active_constraints = [0, n-1]  # Start with endpoints and center
    
    for it in range(max_iters):
        # Build LP with only active constraints
        # Variables: g (n-dimensional, non-negative)
        # Constraints: for each k in active: sum_j a[k-j]*g[j] <= M (where valid)
        
        A_rows = []
        for k in active_constraints:
            row = np.zeros(n)
            j_start = max(0, k - (n - 1))
            j_end = min(n - 1, k)
            for j in range(j_start, j_end + 1):
                row[j] = a[k - j]
            A_rows.append(row)
        
        A = np.array(A_rows) if A_rows else None
        b = np.full(len(active_constraints), M) if A_rows else None
        
        if A is not None and len(A) > 0:
            c_obj = -np.ones(n)
            bounds = [(0, None)] * n
            result = linprog(c_obj, A_ub=A, b_ub=b, bounds=bounds, method='highs')
        
        if not result.success:
            break
        
        g = result.x
        g = np.maximum(g, 0)
        
        # Check all constraints
        conv = _convolve(a, g)
        violated = np.where(conv > M + 1e-10)[0]
        
        if len(violated) == 0:
            # All constraints satisfied
            s = g.sum()
            if s > 1e-10:
                g = g / s
            return g
        
        # Add the most violated constraint
        worst_k = violated[np.argmax(conv[violated])]
        if worst_k not in active_constraints:
            active_constraints.append(worst_k)
        
        if len(active_constraints) > 200:  # Cap to avoid too many constraints
            break
    
    # Fallback: use uniform blend
    s = g.sum()
    if s > 1e-10:
        g = g / s
    return g
```

from scipy.optimize import linprog

def _next_pow2(n):
    k = 1
    while k < n:
        k <<= 1
    return max(2, k)

def _convolve(a, b):
    n, m = len(a), len(b)
    N = _next_pow2(n + m - 1)
    fa = np.fft.rfft(a, N)
    fb = np.fft.rfft(b, N)
    return np.fft.irfft(fa * fb, N)[:n + m - 1]

    n = len(a)
    s = float(a.sum())

        return np.inf
    c = _convolve(a, a)
    return float(2.0 * n * c.max() / (s * s))

    n = len(a)
    c = _convolve(a, a)
    return float(2.0 * n * c.max())

        A_rows = []
        for k in active:
            row = np.zeros(n)
            j_start = max(0, k - (n - 1))
            j_end = min(n - 1, k)
            row[j_start:j_end+1] = a[k - j_start : k - j_end]  # a[k-j] for j in [j_start, j_end]
            A_rows.append(row)

            break

            # Remove the least violated constraint (other than the original)

                active.remove(rem_violations[0][1])
