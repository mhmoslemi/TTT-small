Actually, I want to try one more thing: **directly solving the linear system** for the active set problem.

The system is: `(a ⊛ w) = c_target` (constant), `sum(a) = 1`.

In Fourier space: `conj(A) * W = F(c_target)` where `A = FFT(a)`, `W = FFT(w)`, and `F(c_target) = FFT(c_target_zero_padded)`.

For a constant target `c_target` (a sequence of length `n` with all values `c_target`):
`F(c_target)[k] = c_target * sum_{j=0}^{n-1} exp(-2πi j k / N)`

This is `c_target * N * sinc(k*n/N)` (approximately, for large N).

The DC component is `c_target * n`.

So `conj(A)[k] * W[k] = c_target * D[k]` where `D[k] = sum_{j=0}^{n-1} exp(-2πi j k / N)`.

Thus `A[k] = c_target * conj(D[k]) / conj(W[k])` (taking conjugate).

And `sum(a) = A[0] = c_target * n / W[0]` (since `D[0] = n` and `W[0]` is real).

To get `sum(a) = 1`: `c_target = W[0] / n`.

So `A[k] = (W[0] / n) * conj(D[k]) / conj(W[k])`.

Then `a = ifft(A)`.

Let me implement this! It's a direct solution (no iteration needed) for the unconstrained problem. Then we project onto `a >= 0`.

```python
def _active_set_direct(a, n, tol_frac=0.005, n_iter=30):
    a = a.copy()
    a = a / a.sum()
    N = _next_pow2(3 * n)
    
    # Precompute D[k] = sum_{j=0}^{n-1} exp(-2pi i j k / N)
    # This is (1 - exp(-2pi i n / N)) / (1 - exp(-2pi i k / N)) for k != 0
    # and n for k = 0
    k_vals = np.arange(N // 2 + 1)
    D = np.exp(-2j * np.pi * n / N)
    # D[k] = (1 - exp(-2pi i n k / N)) / (1 - exp(-2pi i k / N))
    num = 1 - np.exp(-2j * np.pi * n * k_vals / N)
    den = 1 - np.exp(-2j * np.pi * k_vals / N)
    D = np.ones(N // 2 + 1, dtype=complex)
    mask = k_vals != 0
    D[mask] = num[mask] / den[mask]
    D[0] = n
    
    for it in range(n_iter):
        c = _full_convolve(a, a)
        c_max = float(c.max())
        active = c >= c_max * (1 - tol_frac)
        if active.sum() == 0:
            active[int(np.argmax(c))] = True
        w = np.zeros(2*n - 1)
        w[active] = 1.0 / active.sum()
        
        W = np.fft.rfft(w, N)
        W[0] = float(W[0]) + 1e-30  # avoid division by zero
        
        # A[k] = (W[0]/n) * conj(D[k]) / conj(W[k])
        A = (W[0] / n) * np.conj(D) / np.conj(W)
        
        a_new = np.fft.irfft(A, N)[:n]
        
        # Project onto a >= 0
        a_new = np.maximum(a_new, 0)
        s = a_new.sum()
        if s < 1e-15:
            break
        a_new = a_new / s
        
        sc_new = _score(a_new)
        sc_old = _score(a)
        if sc_new < sc_old:
            a = a_new
        else:
            # Dampen
            a = 0.5 * a + 0.5 * a_new
            a = np.maximum(a, 0)
            a = a / a.sum()
    
    return a
```

"""
Optimized step function search: L-BFGS + log-sum-exp smoothing, active-set
direct solve, parametric fitting, shrinkage, and multi-n exploration.
Target: minimize 2*n*max(conv(a,a))/sum(a)^2 below 1.5027.
"""
import numpy as np
import time


def _next_pow2(n):
    k = 1
    while k < n:
        k <<= 1
    return max(2, k)


def _full_convolve(a, b):
    n, m = len(a), len(b)
    out_n = n + m - 1
    N = _next_pow2(out_n)
    fa = np.fft.rfft(a, N)
    fb = np.fft.rfft(b, N)
    r = np.fft.irfft(fa * fb, N)[:out_n]
    return r


def _score(a):
    n = len(a)
    s = float(a.sum())
    if s < 1e-15:
        return np.inf
    c = _full_convolve(a, a)
    return float(2.0 * n * c.max() / (s * s))


def _softmax(z):
    z = z - np.max(z)
    e = np.exp(np.clip(z, -700, 700))
    s = e.sum()
    if s < 1e-300:
        return np.ones_like(z) / len(z)
    return e / s
