**One more thought: the "dual" problem.**

The primal is: `min t` s.t. `conv(a,a)[j] <= t for all j`, `sum a = 1`, `a >= 0`.

The Lagrangian is: `L(a, t, λ, μ) = t + sum_j λ_j (conv(a,a)[j] - t) + μ (sum a - 1) - sum_k ν_k a[k]`

where `λ_j >= 0`, `ν_k >= 0`.

The dual function is: `g(λ, μ) = min_{a >= 0} [sum_j λ_j conv(a,a)[j] + μ sum a + (1 - sum_j λ_j) t]`

For the `t` term: if `sum_j λ_j > 1`, the dual is `-inf` (unbounded below in `t`). So we need `sum λ_j <= 1`.

For the `a` term: `sum_j λ_j conv(a,a)[j] + μ sum a = sum_j a[j] (sum_m λ_{m+j} a[m]) + μ sum a[j]`. This is a quadratic form in `a`.
