Each f_k(t) is a ratio of a quadratic (or linear) to a quadratic, which is a "fractional quadratic" function. Its derivative can be set to zero to find critical points.

For the case e[k] = 0 (k ≠ 2i):
f_k(t) = (c[k] + delta*d[k]) / (S0+t)^2 where delta = t-a[i]
        = (A + B*t) / (S0+t)^2 where A = c[k] - a[i]*d[k], B = d[k]

f_k'(t) = [B*(S0+t)^2 - (A+B*t)*2*(S0+t)] / (S0+t)^4
        = [B*(S0+t) - 2*(A+B*t)] / (S0+t)^3
        = [B*S0 + B*t - 2A - 2B*t] / (S0+t)^3
        = [B*S0 - B*t - 2A] / (S0+t)^3
        = [B*(S0-t) - 2A] / (S0+t)^3

Setting to zero: B*(S0-t) - 2A = 0 → t = S0 - 2A/B (if B ≠ 0)
= S0 - 2*(c[k] - a[i]*d[k])/d[k]
= S0 - 2*c[k]/d[k] + 2*a[i]

For the case e[k] = 1 (k = 2i):
f_k(t) = (c[k] + (t-a[i])*d[k] + (t-a[i])^2) / (S0+t)^2
Let u = t - a[i]:
= (c[k] + u*d[k] + u^2) / (S0 + a[i] + u)^2
= (u^2 + d[k]*u + c[k]) / (S0' + u)^2 where S0' = S0 + a[i] = 1

f_k'(t) = [ (2u+d[k])*(S0'+u)^2 - (u^2+d[k]*u+c[k])*2*(S0'+u) ] / (S0'+u)^4
= [ (2u+d[k])*(S0'+u) - 2*(u^2+d[k]*u+c[k]) ] / (S0'+u)^3
= [ 2u*S0' + 2u^2 + d[k]*S0' + d[k]*u - 2u^2 - 2d[k]*u - 2c[k] ] / (S0'+u)^3
= [ 2u*S0' + d[k]*S0' - d[k]*u - 2c[k] ] / (S0'+u)^3
= [ u*(2S0' - d[k]) + d[k]*S0' - 2c[k] ] / (S0'+u)^3

Setting to zero: u*(2S0' - d[k]) + d[k]*S0' - 2c[k] = 0
u = (2c[k] - d[k]*S0') / (2S0' - d[k]) (if 2S0' ≠ d[k])

OK so for each k, we can compute the critical point t_k^*. The optimal t is the one that minimizes max_k f_k(t), which is at:
- t = 0 (boundary)
- t where two or more f_k(t) intersect at the maximum
- t = t_k^* for some k (if that's where the max is minimized)

For a practical implementation, I'll:
1. Find the top-K positions by c[k]
2. For each of these positions, compute t_k^*
3. Collect all candidate t values: {0} ∪ {t_k^* : k in top-K} ∪ {a[i]} (current value)
4. Evaluate F(t) at each candidate (using only the top-K positions for the max)
5. Pick the best t
6. Optionally, do a local refinement (golden section) around the best candidate

    while k < n:

    return max(2, k)

def _full_convolve(a, b):

    fb = np.fft.rfft(b, N)
    r = np.fft.irfft(fa * fb, N)[:out_n]

    rho = np.where(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
