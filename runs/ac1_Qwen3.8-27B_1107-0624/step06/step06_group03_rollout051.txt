One key improvement over the previous code: the coordinate descent. Instead of trying a fixed set of candidate values, I'll do a proper 1D optimization using the structure of the problem.

Actually, since we're on the simplex (sum a = 1), changing a[i] to t and renormalizing is different from just setting a[i] = t. Let me be more careful.

If we're on the simplex and want to change coordinate i:
Option 1: Set a[i] = t, then renormalize: a_new = a_old - a[i] + t, then a_new = a_new / (1 - a[i] + t).
Option 2: Set a[i] = t, keep sum = 1 by adjusting only a[i] (i.e., the new sum is 1 - a[i] + t, and we don't renormalize other coordinates).

Option 2 is simpler for the coordinate descent: we just change a[i] and the sum changes. The objective becomes:

where (a*a)[k]_new is as computed above.

After finding the optimal t*, we can renormalize the whole vector to sum = 1 (which doesn't change the score due to scale invariance).

So the 1D problem is: minimize f(t) = M(t) / (S + t)^2 for t >= 0, where:
- M(t) = max of {B_k + 2*t*a[k-i] for valid k where 2i != k} ∪ {B_{2i} + t^2 if 2i < 2n-1}
- S = 1 - a[i]

This is a 1D non-smooth optimization problem. We can use:
- Golden section search (works for unimodal functions)
- Or find the critical points analytically

The critical points of f(t) occur where:
1. The identity of the argmax changes (a different k becomes the max)
2. The derivative of f is zero at the current argmax

For case 2: if k* is the argmax and (a*a)[k*]_new = B_{k*} + 2*t*a[k*-i] (linear case), then:
f(t) = (B_{k*} + 2*t*a[k*-i]) / (S+t)^2
f'(t) = [2*a[k*-i]*(S+t)^2 - (B_{k*} + 2*t*a[k*-i])*2*(S+t)] / (S+t)^4
= [2*a[k*-i]*(S+t) - 2*(B_{k*} + 2*t*a[k*-i])] / (S+t)^3
= [2*a[k*-i]*S + 2*t*a[k*-i] - 2*B_{k*} - 4*t*a[k*-i]] / (S+t)^3
= [2*a[k*-i]*S - 2*B_{k*} - 2*t*a[k*-i]] / (S+t)^3
= 2*(a[k*-i]*S - B_{k*} - t*a[k*-i]) / (S+t)^3

Setting to zero: a[k*-i]*S - B_{k*} - t*a[k*-i] = 0
t* = (a[k*-i]*S - B_{k*}) / a[k*-i] = S - B_{k*}/a[k*-i]

For the quadratic case (k = 2i):
f(t) = (B_{2i} + t^2) / (S+t)^2
f'(t) = [2t*(S+t)^2 - (B_{2i} + t^2)*2*(S+t)] / (S+t)^4
= [2t*(S+t) - 2*(B_{2i} + t^2)] / (S+t)^3

Setting to zero: t = B_{2i} / S

We can evaluate f(t) at all these critical points and pick the best one. This is O(n) per coordinate, which is fast!

```python
"""
Improved optimizer for minimizing 2*n*max(conv(a,a))/sum(a)^2 over non-negative sequences.
Uses power-mean smoothing, top-K softmax Adam in log-space, proper 1D coordinate descent,
and multiple restart strategies. Key improvements over previous: power-mean gradient,
vectorized coordinate descent with analytical critical points, and adaptive learning rates.
"""
import numpy as np
import time


def _next_pow2(n):
    k = 1
    while k < n:
        k <<= 1
    return max(2, k)


def _full_convolve(a, b):
    n, m = len(a), len(b)
    out_n = n + m - 1
    N = _next_pow2(out_n)
    fa = np.fft.rfft(a, N)
    fb = np.fft.rfft(b, N)
    r = np.fft.irfft(fa * fb, N)[:out_n]
    return r


def _score(a):
    n = len(a)
    s = float(a.sum())
    if s < 1e-15:
        return np.inf
    c = _full_convolve(a, a)
    return float(2.0 * n * c.max() / (s * s))


def _score_norm(a):
    n = len(a)
    c = _full_convolve(a, a)
    return float(2.0 * n * c.max())


def _proj_simplex(v):
    n = len(v)
    if n == 0:
        return v
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    idx = np.arange(1, n + 1, dtype=np.float64)
    cond = u * idx > (cssv - 1.0)
    if not np.any(cond):
        return np.ones(n) / n
    rho = np.where(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)


def _grad_conv_convolution(a, w):
    """Gradient of <w, conv(a,a)> wrt a.
    grad_i = 2 * sum_k w_{i+k} * a_k  (cross correlation)
    Actually: d/da_i [sum_k w_k * (a*a)_k] = 2 * sum_k w_k * a[k-i] (valid k)
    = 2 * (a * w_reversed-ish)_i
    Let's use: grad_i = 2 * sum_{k: 0<=k<n, 0<=k-i+... }
    Simplest: grad = 2 * ifft(conj(fft(a)) * fft(ww)) where ww is w zero-padded
    Actually the correct formula: if c = a*a, then dc/da[i] = 2*a shifted.
    grad_i = 2 * sum_k c'_k * (dc_k/da_i) where c'_k = w_k
    dc_k/da_i = a[k-i] + a[k-i'] (accounting for both terms)
    This equals 2 * (a correlates with w) at position i
    """
    n = len(a)
    N = _next_pow2(2 * n)
    fa = np.fft.rfft(a, N)
    fw = np.fft.rfft(w, N)
    # cross_correlation: h[i] = sum_k a[k] * w[k+i]
    h = np.fft.irfft(np.conj(fa) * fw, N)[:n]
    return 2.0 * h


def _power_mean_weights(c, p):
    """Compute weights w_k = (c_k / M_p)^(p-1) for power mean smoothing.
    These are proportional to d M_p / d c_k."""
    c_clipped = np.maximum(c, 1e-30)
    cp = c_clipped ** p
    sum_cp = cp.sum()
    if sum_cp < 1e-300:
        return np.ones_like(c) / len(c)
    Mp = sum_cp ** (1.0 / p)
    return (c_clipped / Mp) ** (p - 1)


def _topk_softmax_weights(c, beta, k):
    n_c = len(c)
    if k >= n_c:
        k = n_c
    if k < n_c:
        topk_thresh = np.partition(c, -k)[-k]
        topk_mask = c >= topk_thresh
    else:
        topk_mask = np.ones(n_c, dtype=bool)
    topk_indices = np.where(topk_mask)[0]
    if len(topk_indices) == 0:
        topk_indices = np.array([int(np.argmax(c))])
    c_topk = c[topk_indices]
    c_max = float(c_topk.max())
    exp_vals = np.exp((c_topk - c_max) / beta)
    w_sum = float(exp_vals.sum())
    w = np.zeros(n_c)
    if w_sum < 1e-300 or not np.isfinite(w_sum):
        w[topk_indices[0]] = 1.0
    else:
        w[topk_indices] = exp_vals / w_sum
    return w


def _logspace_grad_power(a, n, p):
    """Compute gradient in log-space using power mean smoothing."""
    c = _full_convolve(a, a)
    w = _power_mean_weights(c, p)
    grad_a = _grad_conv_convolution(a, w)
    # In log-space with a = softmax(z): grad_z = a * (grad_a - a . grad_a)
    # But our objective is 2n * M_p(c) (with sum a = 1)
    # So grad_a of objective = 2n * grad_a_of_Mp
    # And grad_z = 2n * a * (grad_a - a . grad_a)
    mean_g = float(np.dot(grad_a, a))
    return 2.0 * n * a * (grad_a - mean_g)


def _logspace_grad_topk(a, n, beta, top_k):
    """Compute gradient in log-space using top-K softmax smoothing."""
    c = _full_convolve(a, a)
    w = _topk_softmax_weights(c, beta, top_k)
    grad_a = _grad_conv_convolution(a, w)
    mean_g = float(np.dot(grad_a, a))
    return 2.0 * n * a * (grad_a - mean_g)


def _softmax_normalize(z):
    z = z - np.max(z)
    e = np.exp(np.clip(z, -50, 50))
    s = e.sum()
    if s < 1e-300:
        return np.ones_like(z) / len(z)
    return e / s


def _adam_logspace(a_init, deadline, method, params, lr_init, max_iter):
    """Adam optimizer in log-space. method='power' or 'topk'.
    params is a list of dicts with phase parameters."""
    n = len(a_init)
    z = np.log(np.maximum(a_init, 1e-15))
    z = z - z.mean()

    best_a = a_init.copy()
    best_score = _score_norm(a_init)

    m_buf = np.zeros(n)
    v_buf = np.zeros(n)
    t = 0
    b1, b2, eps = 0.9, 0.999, 1e-8
    current_lr = lr_init

    for phase in params:
        if time.monotonic() > deadline:
            break
        p_val = phase.get('p', None)
        beta_val = phase.get('beta', None)
        top_k_val = phase.get('top_k', 100)
        phase_lr = phase.get('lr', current_lr)
        phase_iters = phase.get('iters', 20000)
        lr_decay = phase.get('lr_decay', 1.0)

        for it in range(phase_iters):
            if time.monotonic() > deadline:
                break
            t += 1
            a = _softmax_normalize(z)
            c = _full_convolve(a, a)

            if method == 'power':
                if p_val is not None:
                    w = _power_mean_weights(c, p_val)
                else:
                    w = np.ones(len(c)) / len(c)
            else:
                if beta_val is not None:
                    w = _topk_softmax_weights(c, beta_val, top_k_val)
                else:
                    w = np.ones(len(c)) / len(c)

            grad_a = _grad_conv_convolution(a, w)
            mean_g = float(np.dot(grad_a, a))
            grad = 2.0 * n * a * (grad_a - mean_g)

            if not np.all(np.isfinite(grad)):
                break

            m_buf = b1 * m_buf + (1.0 - b1) * grad
            v_buf = b2 * v_buf + (1.0 - b2) * (grad * grad)
            mh = m_buf / (1.0 - b1 ** t)
            vh = v_buf / (1.0 - b2 ** t)

            update = phase_lr * mh / (np.sqrt(vh) + eps)
            update_norm = np.linalg.norm(update)
            if update_norm > 0.5:
                update = update * (0.5 / update_norm)

            z = z - update
            z = np.clip(z, -50.0, 50.0)
            z = z - z.mean()

            if t % 100 == 0:
                a_chk = _softmax_normalize(z)
                sc = _score_norm(a_chk)
                if np.isfinite(sc) and sc < best_score:
                    best_score = sc
                    best_a = a_chk.copy()

        current_lr *= lr_decay
        m_buf *= 0.5
        v_buf *= 0.5

    a_final = _softmax_normalize(z)
    sc_final = _score_norm(a_final)
    if np.isfinite(sc_final) and sc_final < best_score:
        best_score = sc_final
        best_a = a_final.copy()

    return best_a, best_score


def _coord_descend_vec(a, n_topk, n_passes, deadline):

    a = a.copy()
    a = a / a.sum()
    best_score = _score_norm(a)
    conv_len = 2 * n - 1

    for pass_num in range(n_passes):
        if time.monotonic() > deadline:
            break
        # Recompute convolution
        c = _full_convolve(a, a)
        c_max_val = float(c.max())

        improved = 0
        for i in range(n):
            if time.monotonic() > deadline:
                break

            a_i = a[i]
            S = 1.0 - a_i  # sum of all other elements

            if S < 1e-15:

            # For k = 2i (if valid): (a*a)[2i] = B_2i + t^2
            # B_k = c[k] - 2*a[i]*a[k-i] (for linear case)
            # B_2i = c[2i] - a[i]^2 (for quadratic case)

            # D_k = 2*a[k-i] for valid k where k-i in [0,n-1] and k-i != i
            d_idx = np.arange(i, min(i + n, conv_len))
            a_at_d = a[d_idx - i]
            # Mask out k = 2i (the quadratic case)
            quad_mask = np.zeros(len(d_idx), dtype=bool)
            if 2 * i < conv_len:
                quad_pos = 2 * i
                if quad_pos >= i and quad_pos < i + n:
                    quad_mask[quad_pos - i] = True

            # Linear part: B_k = c[k] - 2*a_i*a[k-i], D_k = 2*a[k-i]
            B_lin = c[d_idx] - 2.0 * a_i * a_at_d
            D_lin = 2.0 * a_at_d
            B_lin = B_lin[~quad_mask]
            D_lin = D_lin[~quad_mask]
            d_idx_lin = d_idx[~quad_mask]

            # Quadratic part (k = 2i)
            has_quad = (2 * i < conv_len)
            if has_quad:
                B_quad = c[2 * i] - a_i * a_i

            # Generate candidate t values
            t_cands = [0.0, a_i, a_i * 0.5, a_i * 2.0, a_i * 0.1, a_i * 5.0, S * 0.5]

            # Critical points from top-K linear terms
            if len(B_lin) > 0:
                # Score at current t: B_k + D_k * a_i = c[k] (current conv values)
                scores_cur = B_lin + D_lin * a_i
                k_top = min(n_topk, len(B_lin))
                top_idx = np.argsort(scores_cur)[-k_top:]
                for j in top_idx:
                    if D_lin[j] > 1e-15:
                        t_star = S - B_lin[j] / D_lin[j]
                        if t_star > 0:
                            t_cands.append(min(t_star, 10.0 * max(a_i, S * 0.1)))
                            t_cands.append(t_star * 0.7)
                            t_cands.append(t_star * 1.3)

            # Quadratic critical point
            if has_quad:
                t_quad = B_quad / S if S > 1e-15 else 0
                if t_quad > 0:
                    t_cands.append(min(t_quad, 10.0 * max(a_i, S * 0.1)))

            # Filter and deduplicate
            t_cands = [max(0.0, min(tc, S * 3.0)) for tc in t_cands if np.isfinite(tc)]
            t_cands = list(set([round(tc, 12) for tc in t_cands]))
            if not t_cands:
                t_cands = [a_i]

            # Vectorized evaluation: for each t, compute max of (a*a)_new
            t_arr = np.array(t_cands)  # shape (K,)
            # Linear part: B_lin[None,:] + D_lin[None,:] * t_arr[None,:]  shape (n_lin, K)
            vals_lin = B_lin[:, None] + D_lin[:, None] * t_arr[None, :]
            max_lin = vals_lin.max(axis=0)  # shape (K,)

            if has_quad:
                vals_quad = B_quad + t_arr ** 2  # shape (K,)
                max_all = np.maximum(max_lin, vals_quad)
            else:
                max_all = max_lin

            # Objective: max_all / (S + t)^2
            f_vals = max_all / (S + t_arr) ** 2

            best_idx = int(np.argmin(f_vals))
            best_t = t_arr[best_idx]

            if abs(best_t - a_i) > 1e-10:
                a[i] = best_t
                a = a / a.sum()  # renormalize
                improved += 1

                if improved % 256 == 0:
                    sc = _score_norm(a)
                    if sc < best_score:
                        best_score = sc

        sc = _score_norm(a)
        if sc < best_score:
            best_score = sc
        print(f"    CD pass {pass_num}: improved={improved}, score={best_score:.10f}")
        if improved < 10:
            break

    a = a / a.sum()
    return a, best_score


def _structured_init(n, kind="cos_sum"):
    if kind == "uniform":
        return np.ones(n) / n
    elif kind == "cos_sum":
        a = np.ones(n)
        for freq in [1, 2, 3, 4, 5]:
            a += 0.2 * np.cos(2.0 * np.pi * freq * np.arange(n) / n + freq * 0.7)
        a = np.maximum(a, 0.01)
        return a / a.sum()
    elif kind == "tapered":
        t = np.linspace(0.01, 0.99, n)
        a = np.sin(np.pi * t) ** 0.5
        a = np.maximum(a, 1e-10)
        return a / a.sum()
    elif kind == "high_freq":
        a = np.ones(n)
        for freq in [5, 7, 11, 13]:
            a += 0.3 * np.cos(2.0 * np.pi * freq * np.arange(n) / n)
        a = np.maximum(a, 0.01)
        return a / a.sum()
    elif kind == "random":
        rng = np.random.default_rng(42)
        a = np.abs(rng.standard_normal(n)) + 0.1
        return a / a.sum()
    else:
        return np.ones(n) / n


def _interp_profile(p, n_new):
    n0 = len(p)
    if n0 == n_new:
        return p.copy()
    x0 = np.linspace(0, 1, n0)
    x1 = np.linspace(0, 1, n_new)
    p_new = np.interp(x1, x0, p)
    p_new = np.maximum(p_new, 1e-12)
    return p_new / p_new.sum()


def propose_candidate(seed=42, budget_s=1800):
    t_start = time.monotonic()
    deadline = t_start + max(1.0, float(budget_s) - 30.0)
    rng = np.random.default_rng(int(seed) % (2**63 - 1))

    best_seq = None
    best_score = np.inf

    # Load parent
    parent = None
    try:
        parent_raw = np.asarray(height_sequence_1, dtype=np.float64).ravel()
        if parent_raw.size > 0:
            parent_raw = np.clip(parent_raw, 0.0, 1000.0)
            s = float(parent_raw.sum())
            if s > 0.01:
                parent = parent_raw / s
    except Exception:
        parent = None

    if parent is not None:
        n_parent = len(parent)
        sc_parent = _score(parent)
        print(f"Parent: n={n_parent}, score={sc_parent:.10f}")
        best_seq = parent.copy()
        best_score = sc_parent
    else:
        n_parent = 4096
        parent = _structured_init(n_parent, "cos_sum")
        sc_parent = _score(parent)
        print(f"No parent. Structured init n={n_parent}, score={sc_parent:.10f}")
        best_seq = parent.copy()
        best_score = sc_parent

    # Try lengths: focus on 4096 (parent) and 8192
    lengths_to_try = [4096, 8192]
    if parent is not None and len(parent) == 8192:
        lengths_to_try = [8192, 4096]

    for n_try in lengths_to_try:
        if time.monotonic() > deadline - 120:
            break

        remaining = deadline - time.monotonic()
        print(f"\n=== n={n_try} (remaining: {remaining:.1f}s) ===")

        # Initialize
        if n_try == n_parent:
            a0 = parent.copy()
        else:
            a0 = _interp_profile(parent, n_try)
        a0 = a0 / a0.sum()

        sc0 = _score(a0)
        print(f"  Init: score={sc0:.10f}")
        if sc0 < best_score:
            best_score = sc0
            best_seq = a0.copy()

        a_work = a0.copy()

        # Phase 1: Power mean Adam (coarse to fine)
        c_curr = _full_convolve(a_work, a_work)
        max_cc = float(c_curr.max())
        p_schedule = [30, 50, 80, 120, 200, 300, 500]
        phase1_deadline = time.monotonic() + min(remaining * 0.25, 200.0)
        phase1_params = [
            {'p': p, 'lr': 0.015, 'iters': 15000, 'lr_decay': 0.9}
            for p in p_schedule
        ]
        a_work, sc1 = _adam_logspace(a_work, phase1_deadline, 'power', phase1_params, 0.015, 100000)
        a_work = a_work / a_work.sum()
        sc1_full = _score(a_work)
        if sc1_full < best_score:
            best_score = sc1_full
            best_seq = a_work.copy()
            print(f"  Phase1 power-mean: score={sc1_full:.10f} t={time.monotonic()-t_start:.1f}s")

        # Phase 2: Top-K softmax Adam (fine)
        c_curr = _full_convolve(a_work, a_work)
        max_cc = float(c_curr.max())
        phase2_deadline = time.monotonic() + min(remaining * 0.2, 150.0)
        beta_schedule = [
            {'beta': b, 'top_k': k, 'lr': lr, 'iters': iters, 'lr_decay': 0.95}
            for b, k, lr, iters in [
                (0.01 * max_cc, 200, 0.01, 20000),
                (0.005 * max_cc, 150, 0.008, 20000),
                (0.002 * max_cc, 100, 0.006, 20000),
                (0.001 * max_cc, 80, 0.005, 20000),
                (0.0005 * max_cc, 60, 0.004, 20000),
                (0.0002 * max_cc, 40, 0.003, 20000),
                (0.0001 * max_cc, 30, 0.002, 20000),
            ]
        ]
        a_work, sc2 = _adam_logspace(a_work, phase2_deadline, 'topk', phase2_params, 0.01, 100000)
        a_work = a_work / a_work.sum()
        sc2_full = _score(a_work)
        if sc2_full < best_score:
            best_score = sc2_full
            best_seq = a_work.copy()
            print(f"  Phase2 topk: score={sc2_full:.10f} t={time.monotonic()-t_start:.1f}s")

        # Phase 3: Coordinate descent
        phase3_deadline = time.monotonic() + min(remaining * 0.2, 120.0)
        a_cd, sc3 = _coord_descend_vec(a_work, n_topk=50, n_passes=5, deadline=phase3_deadline)
        sc3_full = _score(a_cd)
        if sc3_full < best_score:
            best_score = sc3_full
            best_seq = a_cd.copy()
            a_work = a_cd
            print(f"  Phase3 coord: score={sc3_full:.10f} t={time.monotonic()-t_start:.1f}s")

        # Phase 4: Fine polish with both methods alternating
        if time.monotonic() < deadline - 60:
            phase4_deadline = time.monotonic() + min(remaining * 0.15, 90.0)
            c_work = _full_convolve(a_work, a_work)
            max_cw = float(c_work.max())
            # Alternate power and topk
            p_fine = [200, 400, 600, 800]
            phase4_params_p = [{'p': p, 'lr': 0.003, 'iters': 10000, 'lr_decay': 0.9} for p in p_fine]
            a_work, sc4a = _adam_logspace(a_work, phase4_deadline, 'power', phase4_params_p, 0.003, 50000)
            a_work = a_work / a_work.sum()
            sc4a_full = _score(a_work)
            if sc4a_full < best_score:
                best_score = sc4a_full
                best_seq = a_work.copy()
                print(f"  Phase4a power-fine: score={sc4a_full:.10f} t={time.monotonic()-t_start:.1f}s")

            # More coordinate descent
            if time.monotonic() < deadline - 40:
                a_cd2, sc4b = _coord_descend_vec(a_work, n_topk=30, n_passes=3,
                                                 deadline=min(deadline - 30, time.monotonic() + 40))
                sc4b_full = _score(a_cd2)
                if sc4b_full < best_score:
                    best_score = sc4b_full
                    best_seq = a_cd2.copy()
                    a_work = a_cd2
                    print(f"  Phase4b coord2: score={sc4b_full:.10f} t={time.monotonic()-t_start:.1f}s")

        # Phase 5: Perturbation restarts
        if time.monotonic() < deadline - 30 and best_seq is not None:
            n_best = len(best_seq)
            a_base = best_seq.copy() / best_seq.sum()
            n_restarts = 3
            per_restart = max(10, (deadline - time.monotonic() - 20) / n_restarts)

            for ri in range(n_restarts):
                if time.monotonic() > deadline - 20:
                    break
                if ri == 0:
                    p_start = a_base + 0.015 * rng.standard_normal(n_best)
                elif ri == 1:
                    # Circular shift perturbation
                    shift = int(rng.integers(1, max(2, n_best // 2048) + 1))
                    p_start = np.roll(a_base, shift).copy()
                    p_start = 0.9 * p_start + 0.1 * a_base
                else:
                    # Frequency perturbation
                    freq = rng.uniform(1.0, 5.0)
                    pert = 0.02 * np.cos(2 * np.pi * freq * np.arange(n_best) / n_best)
                    p_start = a_base + pert

                p_start = np.maximum(p_start, 1e-10)
                p_start = p_start / p_start.sum()

                c_s = _full_convolve(p_start, p_start)
                max_cs = float(c_s.max())
                phase5_params = [
                    {'p': 100, 'lr': 0.005, 'iters': 8000, 'lr_decay': 0.9},
                    {'p': 300, 'lr': 0.003, 'iters': 8000, 'lr_decay': 0.9},
                    {'beta': 0.001 * max_cs, 'top_k': 50, 'lr': 0.003, 'iters': 8000, 'lr_decay': 0.9},
                ]
                p_best, sc_r = _adam_logspace(p_start, time.monotonic() + max(5, per_restart),
                                              'power', phase5_params, 0.005, 30000)
                p_best = p_best / p_best.sum()
                sc_r_full = _score(p_best)
                if sc_r_full < best_score:
                    best_score = sc_r_full
                    best_seq = p_best.copy()
                    print(f"  Restart {ri}: score={sc_r_full:.10f} t={time.monotonic()-t_start:.1f}s")

    # Final validation
    print(f"\n=== Final: best_score={best_score:.10f}, n={len(best_seq) if best_seq is not None else 0} ===")
    if best_seq is not None:
        final = np.clip(best_seq, 0.0, 1000.0)
        s = float(final.sum())
        if s < 0.01:
            final = np.ones(256) * (0.01 / 256)
        sc_final = _score(final)
        print(f"FINAL: score={sc_final:.10f}, n={len(final)}, time={time.monotonic()-t_start:.1f}s")
        return [float(x) for x in final]

    fallback = np.ones(256)
    print(f"FALLBACK: score={_score(fallback):.10f}")
    return [float(x) for x in fallback]
```
