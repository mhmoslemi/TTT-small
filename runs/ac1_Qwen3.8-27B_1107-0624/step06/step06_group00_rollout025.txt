Let me also think about **prospect of using the exact structure of the problem**. The convolution `(a*a)_k` is a quadratic form `a^T P_k a` where `P_k` has 1s on the k-th diagonal (and corresponding symmetric positions). The problem is:

Minimize `max_k a^T P_k a` subject to `1^T a = 1`, `a ≥ 0`.

This is a **quatically constrained optimization** problem. For small n (say n ≤ 50), we could potentially solve it with a general-purpose nonlinear solver. But for n=4096, we need approximate methods.

One approach for large n: **alternating minimization with the max constraint active**.

At the optimum, several constraints are likely active (multiple lags have `c_k = max`). We can identify the active set and solve a reduced problem.

The **KKT conditions** at the optimum:
- For the active lags `K = {k : c_k = t}`: there exist multipliers `λ_k ≥ 0` such that `2 * sum_k λ_k * P_k * a + 1^T a = 0` (stationarity, with the sum constraint).
- Actually, the Lagrangian is `L = max_k a^T P_k a - μ(1^T a - 1) - ν^T a` where `ν ≥ 0`.
- At the optimum, `2 * sum_{k∈K} λ_k P_k a = μ * 1 - ν` where `λ_k > 0` for active constraints.
- And `a_j > 0` implies `ν_j = 0`, so `(2 * sum_{k∈K} λ_k P_k a)_j = μ` for all `j` with `a_j > 0`.

This gives a system of equations that determines the optimal `a` given the active set `K` and multipliers `λ`.

This is similar to the LP approach but more principled. The LP approach essentially does:
- Fix `t = M` (current max).
- Find `g` that maximizes `sum(g)` subject to `P_k g ≤ M` for all k (linear approximation).
- Blend: `a ← (1-α)a + αg`.

A better approach might be:
- Fix the active set `K` (top few lags).
- Solve the KKT conditions directly for `a`.
- Check if the solution is consistent (i.e., the lags in `K` are indeed the max, and all other lags are ≤).
- If not, update the active set.

This is essentially a **semi-definite programming** or **quadratic programming** approach, but exploiting the specific structure.

For the KKT conditions with active set `K = {k_1, ..., k_m}`:
