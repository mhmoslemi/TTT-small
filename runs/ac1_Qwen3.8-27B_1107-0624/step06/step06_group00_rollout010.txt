This is equivalent to: minimize T subject to a^T Q_k a <= T for all k, sum a = 1, a >= 0, where Q_k is the matrix with 1's at positions (i, k-i) and (k-i, i).

The Lagrangian is: L = T + sum_k lambda_k (a^T Q_k a - T) - mu (sum a - 1) - sum_i nu_i a_i.

- For a_i > 0: sum_k lambda_k * (Q_k a)_i - mu = 0
  i.e., (sum_k lambda_k Q_k) a = mu * 1 (on the support of a)
- For a_i = 0: sum_k lambda_k * (Q_k a)_i - mu <= 0
- lambda_k >= 0, C_k <= T, lambda_k * (C_k - T) = 0

The first condition says that (sum_k lambda_k Q_k) a is constant (= mu) on the support of a.

This is similar to the "eigenvalue equation" (A a = lambda a) but with a sum of matrices weighted by lambda_k.

This suggests a **power iteration** approach:
1. Given a, compute C = conv(a, a) and identify active lags.
2. Form A = sum_{k active} lambda_k Q_k.
3. Compute b = A a (which is a vector of length n).
4. Update a to be proportional to b (or 1/b, depending on the direction).

But this requires forming the matrix A, which is expensive. However, we can compute A a without explicitly forming A:
(A a)_i = sum_k lambda_k (Q_k a)_i = sum_k lambda_k * a[k-i] (for valid k-i, with appropriate bounds)

This is a weighted sum of shifts of a, which can be computed using FFT!

Specifically, if we define the "weight sequence" w_k = lambda_k, then:
(A a)_i = sum_k w_k * a[k-i] (with bounds)

This is the cross-correlation of a and w (with w defined on the range 0 to 2n-2).

Using the FFT approach I described earlier, we can compute this in O(n log n).

So the algorithm becomes:
1. Compute C = conv(a, a).
2. Set lambda_k = 1 if C_k is in the top set, 0 otherwise (or use a smooth version).
3. Compute b = A a using FFT.
4. Update: a_new_i = a_i / b_i (or a_i * (mu / b_i)^alpha).
5. Normalize.

This is essentially the IPS algorithm I described earlier! The "pressure" on position i is b_i = sum_k lambda_k * a[k-i], and we update a_i to be inversely proportional to this pressure.

The intuition: if position i is contributing a lot to the active lags (high pressure), we reduce it. If it's contributing little, we keep it.

    s = float(a.sum())
    if s < 1e-15:
        return np.inf
    c = _fft_convolve(a, a)
    return float(2.0 * n * c.max() / (s * s))

def _score_norm(a):
    n = len(a)
    c = _fft_convolve(a, a)
    return float(2.0 * n * c.max())

def _softmax_stable(z):
    z = z - np.max(z)
    e = np.exp(z)
    s = e.sum()
    if s < 1e-300:
        return np.ones_like(z) / len(z)
    return e / s

def _compute_pressure(a, w):
    """Compute pressure b_i = sum_k w[k] * a[k-i] for valid k-i.
    w has length 2n-1, a has length n.
    Returns b of length n.
    """
    n = len(a)
    N = _next_pow2(3 * n - 2)
    fa = np.fft.rfft(a, N)
    fw = np.fft.rfft(w, N)
    R = np.fft.irfft(fa * np.conj(fw), N)
    indices = (N - np.arange(n)) % N
    return R[indices]

def _ips_iterate(a, deadline, alpha_start=2.0, alpha_end=0.1, active_thresh=0.95, max_iter=10000):
    """Iterative Proportional Scaling with adaptive alpha and active set."""
    n = len(a)
    T_current = _score_norm(a)
    best_a = a.copy()
    best_T = T_current
    patience = 0
    
    for it in range(max_iter):
        if time.monotonic() > deadline:
            break
        frac = min(1.0, it / max_iter)
        alpha = alpha_start * (alpha_end / alpha_start) ** frac
        
        c = _fft_convolve(a, a)
        T = c.max()
        
        # Identify active lags (within active_thresh fraction of max)
        threshold = T * active_thresh
        w = np.where(c >= threshold, c, 0.0)
        w = w / (w.sum() + 1e-30)
        
        # Compute pressure
        pressure = _compute_pressure(a, w)
        
        # Update: a_i = a_i / (1 + alpha * pressure_i)
        a = a / (1.0 + alpha * pressure)
        a = np.maximum(a, 1e-15)  # keep positive
        a = a / a.sum()
        
        T_new = _score_norm(a)
        if T_new < best_T:
            best_T = T_new
            best_a = a.copy()
            patience = 0
        else:
            patience += 1
            if patience > 50:
                # Restart from best
                a = best_a.copy()
                patience = 0
                # Slightly perturb the active threshold
                active_thresh = 0.90 + 0.10 * np.random.random()
        
        if it % 100 == 0:
            print(f"    IPS[{it}]: T={T_new:.10f}, score={2*n*T_new/a.sum()**2:.10f}")
    
    return best_a, best_T
