c[2] = a[0]*a[2] + a[1]*a[1] + a[2]*a[0] = 2*a[0]*a[2] + a[1]^2
...
c[n-1] = sum_{i=0}^{n-1} a[i]*a[n-1-i] (this is the "center" of the convolution)
...
c[2n-2] = a[n-1]^2

So the convolution has 2n-1 elements, going from k=0 to k=2n-2.

The "peak" that we try to minimize is max over ALL of these 2n-1 values.

For uniform a[i] = 1/n:
c[k] = (n-k) * (1/n)^2 for k = 0, 1, ..., n-1
c[k] = (2n-2-k) * (1/n)^2 for k = n, ..., 2n-2

So c[0] = 1/n, c[n-1] = 1/n, and the triangle peaks at k = n-1 with value 1/n.

Wait, c[n-1] = sum_{i=0}^{n-1} (1/n)(1/n) = n * (1/n^2) = 1/n. Yes.

And c[0] = (1/n)^2 = 1/n^2. Much smaller!

So for uniform, the max is at k = n-1 (the center) with value 1/n. Score = 2n * (1/n) = 2.

To improve, we want to make c[k] < 1/n for all k, especially at k = n-1.

c[n-1] = sum_i a[i] a[n-1-i]. This is like the "overlap" of a with its reverse.

For the score to be < 2, we need max_k c[k] < 1/n. But c[n-1] = sum a[i] a[n-1-i] >= (sum a[i])^2 / n = 1/n by Cauchy-Schwarz (applied to the vectors (a[0],...,a[n-1]) and (a[n-1],...,a[0])).

Wait: sum_i a[i] * a[n-1-i] <= sqrt(sum a[i]^2 * sum a[n-1-i]^2) = sum a[i]^2... no that's the upper bound.

By Cauchy-Schwarz: (sum_i a[i] b[i])^2 <= (sum a[i]^2)(sum b[i]^2).
With b[i] = a[n-1-i]: (sum a[i] a[n-1-i])^2 <= (sum a[i]^2)(sum a[n-1-i]^2) = (sum a[i]^2)^2.
So sum a[i] a[n-1-i] <= sum a[i]^2.

And by the other direction: there's no simple lower bound on sum a[i] a[n-1-i] in terms of (sum a[i])^2 / n.

Actually, we can have a[i] a[n-1-i] = 0 for all i (e.g., a is supported on the first half only). Then c[n-1] = 0! But then c[k] would be large for k in the first half.

So the tradeoff is: we want to minimize the peak of the entire convolution c[0], c[1], ..., c[2n-2].

This is essentially a "low-peak-factor" problem, similar to PAPR minimization in OFDM.

OK so let me now think about the best algorithm. I'll go with a combination approach:

1. **Phase 1**: Primal-dual with Frank-Wolfe (the "different" approach)
2. **Phase 2**: FISTA with exact subgradient (not smoothed max, but argmax)
3. **Phase 3**: Fine polishing with coordinate descent or very fine FISTA

"""
Primal-dual Frank-Wolfe + exact subgradient FISTA for low-autocorrelation
sequence design. Minimizes 2*n*max(a*a)/(sum(a))^2 for non-negative sequences.
"""
import numpy as np
import time

def _next_pow2(n):
    k = 1
    while k < n:
        k <<= 1
    return max(2, k)

def _convolve(a, b):
    n, m = len(a), len(b)
    N = _next_pow2(n + m - 1)
    fa = np.fft.rfft(a, N)
    fb = np.fft.rfft(b, N)
    return np.fft.irfft(fa * fb, N)[:n + m - 1]

def _score(a):
    n = len(a)
    s = float(a.sum())
    if s < 0.01:
        return np.inf
    c = _convolve(a, a)
    return float(2.0 * n * c.max() / (s * s))

def _score_norm(a):
    """Assumes a is already normalized to sum=1"""
    n = len(a)
    c = _convolve(a, a)
    return float(2.0 * n * c.max())

def _proj_simplex(v):
    n = len(v)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    idx = np.arange(1, n + 1, dtype=np.float64)
    cond = u * idx > (cssv - 1.0)
    if not np.any(cond):
        return np.ones(n) / n
    rho = np.where(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)

def _grad_at_argmax(a, w):
    """Compute gradient of sum_k w[k]*c[k] w.r.t. a, where c = a*a.
    w is a probability vector over the 2n-1 lags."""
    n = len(a)
    a_rev = a[::-1]
    wc = _convolve(w, a_rev)
    grad = 2.0 * wc[n - 1: 2 * n - 1]
    return grad

def _fw_primal_step(a, p, n_fw_steps, lr_schedule='standard'):
    """Run n_fw_steps of Frank-Wolfe on min a^T Q(p) a s.t. a in simplex.
    Q(p)[i,j] = p[i+j] (with bounds)."""
    n = len(a)
    a_curr = a.copy()
    a_prev = a_curr.copy()
    t_val = 1.0
    
    for fw_it in range(n_fw_steps):
        # Compute gradient: grad = 2 * Q(p) * a
        # Q(p)*a[i] = sum_j p[i+j] * a[j] = conv(a_rev, p)[i+n-1]
        a_rev = a_curr[::-1]
        ap = _convolve(a_rev, p)
        grad = 2.0 * ap[n - 1: 2 * n - 1]
        
        # Find minimizer vertex
        s = int(np.argmin(grad))
        
        # Step size
        if lr_schedule == 'standard':
            gamma = 2.0 / (fw_it + 2)
        else:  # 'nesterov'
            t_next = (1.0 + np.sqrt(1.0 + 4.0 * t_val * t_val)) / 2.0
            y = a_curr + ((t_val - 1.0) / t_next) * (a_curr - a_prev)
            gamma = 2.0 / (t_next + 1.0)
        
        a_new = (1.0 - gamma) * a_curr + gamma * np.zeros(n)
        a_new = (1.0 - gamma) * a_curr
        a_new[s] += gamma
        
        if lr_schedule == 'nesterov':
            a_prev = a_curr
            a_curr = a_new
            t_val = t_next
        else:
            a_curr = a_new
    
    return a_curr

def _primal_dual(a_init, deadline, n_outer=5000, n_fw=5, temp_init=0.01, temp_decay=0.999):
    """Primal-dual algorithm for min_a max_k (a*a)[k] s.t. a in simplex."""
    n = len(a_init)
    a = a_init.copy()
    best_a = a.copy()
    best_sc = _score_norm(a)
    
    c = _convolve(a, a)
    max_c = float(c.max())
    
    # Initialize dual variable
    temp = temp_init * max_c
    c_shifted = (c - max_c) / temp
    np.clip(c_shifted, -100, 100, out=c_shifted)
    p = np.exp(c_shifted)
    p = p / p.sum()
    
    for it in range(n_outer):
        if time.monotonic() > deadline:
            break
        
        # Primal: Frank-Wolfe steps
        a = _fw_primal_step(a, p, n_fw, 'standard')
        
        # Evaluate
        if it % 50 == 0:
            c = _convolve(a, a)
            sc = float(2.0 * n * c.max())
            if sc < best_sc:
                best_sc = sc
                best_a = a.copy()
        
        # Dual: update p
        c = _convolve(a, a)
        max_c = float(c.max())
        temp = max(temp * temp_decay, 1e-10 * max_c)
        c_shifted = (c - max_c) / temp
        np.clip(c_shifted, -100, 100, out=c_shifted)
        p_new = np.exp(c_shifted)
        p_sum = p_new.sum()
        if p_sum > 0:
            p = p_new / p_sum
        else:
            p = np.zeros(2*n-1)
            p[int(np.argmax(c))] = 1.0
    
    # Final evaluation
    c = _convolve(a, a)
    sc = float(2.0 * n * c.max())
    if sc < best_sc:
        best_sc = sc
        best_a = a.copy()
    
    return best_a, best_sc

def _fista_subgrad(a_init, deadline, n_subgrad='top1', max_iter=100000):
    """FISTA with exact subgradient (argmax) instead of smoothed max."""
    n = len(a_init)
    a_curr = a_init.copy()
    a_prev = a_curr.copy()
    t_val = 1.0
    
    c = _convolve(a_curr, a_curr)
    max_c = float(c.max())
    step = 1.0 / (2.0 * max_c * 2.0)  # Lipschitz constant estimate
    # Actually, the Lipschitz constant of the subgradient is bounded by 2*||a||_1 * 2 = 4 (since grad = 2*conv(w, a_rev) and ||w||_1=1, ||a||_1=1)
    # More precisely, ||grad||_inf <= 2 * max(a) * 2 <= 4 * max(a)
    # But for the FISTA step, we need L such that f is L-smooth in the Lipschitz sense
    # For subgradients, we use step = 1/L where L bounds the norm of the subgradient
    # ||g||_2 <= 2 * ||a||_2 (since g = 2*conv(w, a_rev) and ||conv(w, a_rev)||_inf <= ||w||_1 * ||a_rev||_inf = max(a))
    # So L = 2 * max(a) is a bound on ||g||_inf, but for the proximal step we need something else
    # Let's just use a simple step size and adapt it
    
    step = 0.5 / max_c  # heuristic
    
    best_a = a_curr.copy()
    best_sc = _score_norm(a_curr)
    
    for it in range(max_iter):
        if time.monotonic() > deadline:
            break
        
        t_next = (1.0 + np.sqrt(1.0 + 4.0 * t_val * t_val)) / 2.0
        y = a_curr + ((t_val - 1.0) / t_next) * (a_curr - a_prev)
        y = np.maximum(y, 0.0)
        s_y = y.sum()
        if s_y > 1e-30:
            y = y / s_y
        else:
            y = np.ones(n) / n
        
        c_y = _convolve(y, y)
        c_max = float(c_y.max())
        
        if n_subgrad == 'top1':
            k_star = int(np.argmax(c_y))
            w = np.zeros(len(c_y))
            w[k_star] = 1.0
        elif n_subgrad == 'top3':
            top3 = np.argsort(c_y)[-3:]
            w = np.zeros(len(c_y))
            w[top3] = 1.0 / 3
        else:
            # top-k
            k = min(n_subgrad, len(c_y))
            topk = np.argsort(c_y)[-k:]
            w = np.zeros(len(c_y))
            w[topk] = 1.0 / k
        
        grad = _grad_at_argmax(y, w)
        a_next = _proj_simplex(y - step * grad)
        
        if it % 200 == 0:
            sc = _score_norm(a_next)
            if sc < best_sc:
                best_sc = sc
                best_a = a_next.copy()
        
        a_prev = a_curr
        a_curr = a_next
        t_val = t_next
    
    sc_final = _score_norm(a_curr)
    if sc_final < best_sc:
        best_sc = sc_final
        best_a = a_curr.copy()
    return best_a, best_sc

def _coord_refine(a_init, deadline, max_rounds=200):
    """Coordinate descent refinement."""
    n = len(a_init)
    a = a_init.copy()
    a = a / a.sum()
    best_a = a.copy()
    best_sc = _score_norm(a)
    rng = np.random.default_rng(42)
    
    for r in range(max_rounds):
        if time.monotonic() > deadline:
            break
        if n > 2048:
            indices = rng.choice(n, size=min(1024, n), replace=False)
        else:
            indices = np.arange(n)
        rng.shuffle(indices)
        
        improved = False
        for j in indices:
            if time.monotonic() > deadline:
                break
            old_val = a[j]
            for factor in [0.5, 0.7, 1.3, 2.0, 0.9, 1.1]:
                a[j] = old_val * factor
                s = a.sum()
                if s < 1e-30:
                    a[j] = old_val
                    continue
                a_norm = a / s
                sc = _score_norm(a_norm)
                if sc < best_sc - 1e-14:
                    best_sc = sc
                    best_a = a.copy()
                    improved = True
                else:
                    a[j] = old_val
        a = a / a.sum()
        if not improved and r > 30:
            break
    return best_a, best_sc

def _interp_profile(p, n_new):
    n0 = len(p)
    if n0 == n_new:
        return p.copy()
    x0 = np.linspace(0, 1, n0)

    p_new = np.interp(x1, x0, p * np.sqrt(n0))
    p_new = np.maximum(p_new, 1e-15)
    return p_new / p_new.sum()

Wait, I need to reconsider the step size in FISTA. The Lipschitz constant of the smoothed max function f_beta(a) = log(sum exp((c[k]-max)/beta)) is related to the second derivative, which involves the convolution operator. Let me think...

f_beta(a) = log(sum_k exp((c[k] - c_max) / beta)) where c = a*a.

∂f/∂a[j] = (1/beta) * sum_k w[k] * ∂c[k]/∂a[j] = (1/beta) * sum_k w[k] * 2*a[k-j] (for valid k-j)
= (2/beta) * (w * a_rev)[j+n-1]

The Hessian involves second derivatives which are more complex. For the FISTA step, we need L such that ||∇f(a) - ∇f(b)||_2 <= L * ||a - b||_2.

A rough bound: ||∇f||_inf <= (2/beta) * max(a) * sum(w) = 2*max(a)/beta.
And the Lipschitz constant of the gradient is at most 2 * (2/beta) * 2 * max(a) = 8*max(a)/beta (rough).

Actually, for the self-convolution, the Hessian of c[k] w.r.t. (a[i], a[j]) is:
∂²c[k]/∂a[i]∂a[j] = 2*δ_{i+j,k} (approximately, with bounds)

So the Hessian of f_beta = sum_k w[k] * c[k] / beta has entries:
H[i,j] = (2/beta) * sum_k w[k] * δ_{i+j, k'} (where k' involves the appropriate indices)

The spectral norm of this Hessian is bounded by (2/beta) * max_k w[k] * (number of (i,j) pairs with i+j = k) <= (2/beta) * max_k w[k] * n.

For uniform w (w[k] = 1/(2n-1)), this is (2/beta) * 1/(2n-1) * n ≈ 1/beta.
For concentrated w (w[k] = 1 at one point), this is 2/beta.

So L ≈ 2/beta (worst case) or L ≈ 4/beta (to be safe).
