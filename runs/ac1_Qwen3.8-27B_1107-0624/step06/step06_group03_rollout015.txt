2. Phase 1: Fine-grained Adam in log-space with very small beta (to directly target the max).
3. Phase 2: Extensive coordinate descent with golden section search per coordinate. Multiple passes.
4. Phase 3: Try n=8192 (interpolate and re-optimize).
5. Phase 4: Final polishing.

For the coordinate descent, the key optimization is:
- For each coordinate i, compute d_k (the "sensitivity vector")
- Find the range of t where the max is achieved (the active set changes)
- Within each segment, the function is a ratio of a linear (or quadratic) function to a quadratic, which has a closed-form minimum
- Use this to find the optimal t efficiently

Actually, for the linear case (ignoring the k=2i quadratic term for now):
f(t) = 2n * max_k (c_k + d_k*t) / (S0 + t)^2

The maximum is achieved at the k that maximizes c_k + d_k*t. As t varies, the active k changes at points where c_k + d_k*t = c_{k'} + d_{k'}*t, i.e., t = (c_{k'} - c_k)/(d_k - d_{k'}).

Within a region where a fixed k* is active:
f(t) = 2n * (c_{k*} + d_{k*}*t) / (S0 + t)^2

df/dt = 2n * [d_{k*}*(S0+t)^2 - (c_{k*}+d_{k*}*t)*2*(S0+t)] / (S0+t)^4
= 2n * [d_{k*}*(S0+t) - 2*(c_{k*}+d_{k*}*t)] / (S0+t)^3
= 0 when d_{k*}*(S0+t) = 2*(c_{k*}+d_{k*}*t)
d_{k*}*S0 + d_{k*}*t = 2*c_{k*} + 2*d_{k*}*t
d_{k*}*S0 - 2*c_{k*} = d_{k*}*t
t* = S0 - 2*c_{k*}/d_{k*} (if d_{k*} > 0)

So for each active k*, the optimal t is t* = S0 - 2*c_{k*}/d_{k*}.

This gives us a way to find the optimal t efficiently:
1. For the current t = a_old, find which k* is the argmax.
2. Compute t* = S0 - 2*c_{k*}/d_{k*}.
3. Check if k* is still the argmax at t*. If yes, t* is the optimal t (within that region).
4. If no, find the new argmax and repeat.
5. Also check the boundaries of the active region.

This is essentially a "chasing the optimum" approach that should converge in a few iterations.

Let me also think about the k=2i quadratic case. When k=2i:
(a*a)[2i]_new = (a*a)[2i] + (t-a_old)*(t+a_old) = (a*a)[2i] + t^2 - a_old^2

So the function becomes:
f(t) = 2n * max_k [(c_k + d_k*t) for k≠2i, (c_{2i} + t^2 - a_old^2) for k=2i] / (S0+t)^2

This is more complex but still 1D. We can handle it by:
- Checking if k=2i is in the active set
- If so, solving the resulting equation (which may be quadratic)
- If not, using the linear formula

For practical purposes, the k=2i term is usually not the dominant one (unless a[i] is very large), so we can often ignore it or handle it as a special case.

Let me now write the optimized algorithm. I'll focus on:

1. **Efficient FFT-based convolution** (already in the previous code)
2. **Smart coordinate descent with analytical 1D optimization**
3. **Adam in log-space for the initial phases**
4. **Multiple lengths (4096, 8192)**
5. **Aggressive beta schedule**

Let me also consider the "inverse problem" approach: instead of optimizing a directly, optimize the convolution target.

Given a target M = max_k (b*b)[k], we want to find b ≥ 0, sum(b) = 1, such that (b*b)[k] ≤ M for all k. The minimum M is what we're after.

This is a feasibility problem. We can binary search on M and check feasibility using SDP or LP. But for n=4096, the convolution has 8191 values, and the SDP would be very large. Not practical.

Let me stick with the direct optimization approach but make it more efficient.

**Key improvements over the previous program:**

1. **Better 1D coordinate optimization**: Use the analytical formula t* = S0 - 2*c_{k*}/d_{k*} with "chasing" to find the true 1D minimum.

2. **More CD passes**: Do more passes of coordinate descent (10+ instead of 3).

3. **Larger n**: Try n=8192.

4. **Better initialization for n=8192**: Interpolate the n=4096 solution.

5. **Aggressive final polishing**: After the main optimization, do a very fine CD with the analytical 1D solver.

Let me code this up:

"""
Optimized step function coefficient searcher.
Uses analytical 1D coordinate descent with active-set chasing,
Adam in log-space with top-K softmax smoothing,
and multi-length exploration (4096, 8192).
"""
import numpy as np
import time


def _next_pow2(n):
    k = 1
    while k < n:
        k <<= 1
    return max(2, k)


def _full_convolve(a, b):
    n, m = len(a), len(b)
    out_n = n + m - 1
    N = _next_pow2(out_n)
    fa = np.fft.rfft(a, N)
    fb = np.fft.rfft(b, N)
    r = np.fft.irfft(fa * fb, N)[:out_n]
    return r


def _score(a):
    n = len(a)
    s = float(a.sum())
    if s < 1e-15:
        return np.inf
    c = _full_convolve(a, a)
    return float(2.0 * n * c.max() / (s * s))


def _score_norm(a):
    """Score assuming sum(a) = 1."""
    n = len(a)
    c = _full_convolve(a, a)
    return 2.0 * n * c.max()


def _proj_simplex(v):
    n = len(v)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    idx = np.arange(1, n + 1, dtype=np.float64)
    cond = u * idx > (cssv - 1.0)
    if not np.any(cond):
        return np.ones(n) / n
    rho = np.where(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)


def _grad_conv(a, w):
    """Gradient of <w, conv(a,a)> wrt a. = 2 * cross_correlation(a, w)"""
    n = len(a)
    N = _next_pow2(2 * n)
    fa = np.fft.rfft(a, N)
    fw = np.fft.rfft(w, N)
    h = np.fft.irfft(np.conj(fa) * fw, N)[:n]
    return 2.0 * h


def _topk_weights(c, beta, k):
    """Softmax weights over top-k elements."""
    n_c = len(c)
    if k >= n_c:
        k = n_c
    if k < n_c:
        topk_thresh = np.partition(c, -k)[-k]
        topk_mask = c >= topk_thresh
    else:
        topk_mask = np.ones(n_c, dtype=bool)
    topk_indices = np.where(topk_mask)[0]
    if len(topk_indices) == 0:
        topk_indices = np.array([int(np.argmax(c))])
    c_topk = c[topk_indices]
    c_max = float(c_topk.max())
    exp_vals = np.exp(np.clip((c_topk - c_max) / beta, -50, 50))
    w_sum = float(exp_vals.sum())
    w = np.zeros(n_c)
    if w_sum < 1e-300 or not np.isfinite(w_sum):
        w[topk_indices[0]] = 1.0
    else:
        w[topk_indices] = exp_vals / w_sum
    return w


def _logspace_grad(a, w, n):
    """Gradient in log-space for normalized problem (sum a = 1)."""
    grad_a = _grad_conv(a, w)
    mean_grad = float(np.dot(grad_a, a))
    return 2.0 * n * a * (grad_a - mean_grad)


def _softmax_normalize(z):
    z = z - np.max(z)
    e = np.exp(np.clip(z, -50, 0))  # clip upper to 0 for stability
    s = e.sum()
    if s < 1e-300:
        return np.ones_like(z) / len(z)
    return e / s


def _adam_logspace(a_init, deadline, betas, lr_init, top_k, max_iter):
    """Adam in log-space with top-K smoothed max."""
    n = len(a_init)
    z = np.log(np.maximum(a_init, 1e-15))
    z = z - z.mean()
    
    best_a = a_init.copy()
    best_score = _score_norm(a_init)
    
    m_buf = np.zeros(n)
    v_buf = np.zeros(n)
    t = 0
    b1, b2, eps = 0.9, 0.999, 1e-8
    current_lr = lr_init
    
    for beta in betas:
        if time.monotonic() > deadline:
            break
        it_in_phase = 0
        while it_in_phase < max_iter:
            if time.monotonic() > deadline:
                break
            it_in_phase += 1
            t += 1
            
            a = _softmax_normalize(z)
            c = _full_convolve(a, a)
            w = _topk_weights(c, beta, top_k)
            grad = _logspace_grad(a, w, n)
            
            if not np.all(np.isfinite(grad)):
                break
            
            m_buf = b1 * m_buf + (1.0 - b1) * grad
            v_buf = b2 * v_buf + (1.0 - b2) * (grad * grad)
            mh = m_buf / (1.0 - b1 ** t)
            vh = v_buf / (1.0 - b2 ** t)
            
            update = current_lr * mh / (np.sqrt(vh) + eps)
            update_norm = np.linalg.norm(update)
            if update_norm > 2.0:
                update = update * (2.0 / update_norm)
            
            z = z - update
            z = np.clip(z, -60.0, 0.0 - np.max(z) + 60.0)
            # Actually let's just clip and renormalize
            z = np.clip(z, -60.0, 60.0)
            z = z - z.mean()
            
            if t % 100 == 0:
                a_chk = _softmax_normalize(z)
                sc = _score_norm(a_chk)
                if np.isfinite(sc) and sc < best_score:
                    best_score = sc
                    best_a = a_chk.copy()
            
            if it_in_phase % 5000 == 0:
                current_lr = max(0.0003, current_lr * 0.95)
        
        # Dampen momentum at phase boundaries
        m_buf *= 0.3
        v_buf *= 0.3
    
    a_final = _softmax_normalize(z)
    sc_final = _score_norm(a_final)
    if np.isfinite(sc_final) and sc_final < best_score:
        best_score = sc_final
        best_a = a_final.copy()
    
    return best_a, best_score


def _coord_cd_analytical(a, n_passes, deadline, rng=None):
    """
    Coordinate descent with analytical 1D optimization.
    For each coordinate i, find the optimal t by:
    1. Computing the sensitivity vector d_k
    2. Chasing the active constraint to find the 1D minimum
    """
    n = len(a)
    a = a.copy()
    s = a.sum()
    a = a / s  # normalize to sum=1
    
    if rng is None:
        rng = np.random.default_rng(42)
    
    best_score = _score_norm(a)
    
    for p in range(n_passes):
        if time.monotonic() > deadline:
            break
        order = rng.permutation(n)
        n_improved = 0
        
        for i in order:
            if time.monotonic() > deadline:
                break
            
            a_i = a[i]
            if a_i < 1e-15:
                continue
            
            # Compute sensitivity: d[k] = contribution coefficient for changing a[i]
            # (a*a)[k] changes by (t - a_i) * d[k] for k where 0 <= k-i < n, k != 2i
            # For k = 2i: change is (t^2 - a_i^2) = (t-a_i)*(t+a_i)
            
            # d[k] = 2*a[k-i] for 0 <= k-i < n, k != 2i
            # d[2i] = a_i + t (depends on t, handle separately)
            
            d = np.zeros(2 * n - 1)
            valid = np.arange(i, min(i + n, 2 * n - 1))
            d[valid] = 2.0 * a[valid - i]
            # Fix k = 2i: the coefficient there should be a_i + t (not 2*a_i)
            # For now, use 2*a_i as approximation (exact when t = a_i)
            # d[2*i] is already set to 2*a[i] which is the derivative at t = a_i
            
            # Current convolution
            c_curr = _full_convolve(a, a)
            c_base = c_curr - a_i * d  # c without the a[i] contribution (linear approx)
            
            S0 = 1.0 - a_i
            
            # Find optimal t by chasing active constraint
            # Start with current t
            t = a_i
            for chase_iter in range(20):
                # Find active constraint at current t
                c_at_t = c_base + d * t
                k_star = int(np.argmax(c_at_t))
                
                d_k = d[k_star]
                if d_k < 1e-15:
                    # Can't reduce this constraint by increasing t
                    # Try t = 0
                    break
                
                # Optimal t for this active constraint: t* = S0 - 2*c_base[k_star] / d_k
                t_new = S0 - 2.0 * c_base[k_star] / d_k
                t_new = max(0.0, t_new)
                
                if abs(t_new - t) < 1e-12 * max(1.0, t):
                    t = t_new
                    break
                t = t_new
            
            # Verify: check a few candidate values
            candidates = [0.0, t, a_i * 0.5, a_i * 1.5, a_i]
            candidates = [max(0.0, min(10.0 * max(a_i, 0.01), c)) for c in candidates]
            
            best_t = a_i
            best_f = np.inf
            for tc in candidates:
                c_trial = c_base + d * tc
                max_c = float(c_trial.max())
                f_val = 2.0 * n * max_c / ((S0 + tc) ** 2)
                if f_val < best_f:
                    best_f = f_val
                    best_t = tc
            
            if abs(best_t - a_i) > 1e-14:
                a[i] = best_t
                s_new = a.sum()
                if s_new > 1e-15:
                    a = a / s_new
                    n_improved += 1
        
        sc = _score_norm(a)
        if sc < best_score:
            best_score = sc
            print(f"    CD pass {p+1}: score={sc:.10f}, improved={n_improved}")
    
    return a, best_score


def _fista_coarse(a_init, deadline, beta_init, n_beta_stages):
    """Coarse FISTA with decreasing beta."""
    n = len(a_init)
    a_curr = a_init.copy()
    best_a = a_init.copy()
    best_score = _score_norm(a_init)
    
    c_init = _full_convolve(a_curr, a_curr)
    max_c = float(c_init.max())
    
    betas = [beta_init * (0.5 ** i) for i in range(n_beta_stages)]
    
    for beta in betas:
        if time.monotonic() > deadline:
            break
        
        a_curr_y = a_curr.copy()
        a_prev = a_curr.copy()
        t_fista = 1.0
        
        L = 16.0 * n / max(1e-10, max_c * beta)  # Lipschitz constant estimate
        step = 1.0 / L
        
        max_it = max(1000, int(60.0 * 500))  # max ~60 seconds per beta stage
        for it in range(max_it):
            if time.monotonic() > deadline:
                break
            
            t_next = (1.0 + np.sqrt(1.0 + 4.0 * t_fista * t_fista)) / 2.0
            y = a_curr + ((t_fista - 1.0) / t_next) * (a_curr - a_prev)
            y = np.maximum(y, 0.0)
            s_y = y.sum()
            y = y / max(s_y, 1e-30)
            
            c_y = _full_convolve(y, y)
            w = _topk_weights(c_y, beta, 200)
            grad = _grad_conv(y, w)
            
            a_next = _proj_simplex(y - step * grad)
            
            if it % 500 == 0:
                sc = _score_norm(a_next)
                if sc < best_score:
                    best_score = sc
                    best_a = a_next.copy()
                    max_c = float(c_y.max())  # update for Lipschitz
            
            a_prev = a_curr
            a_curr = a_next
            t_fista = t_next
        
        # Update best
        sc = _score_norm(a_curr)
        if sc < best_score:
            best_score = sc
            best_a = a_curr.copy()
    
    return best_a, best_score


def _interp_profile(p, n_new):
    n0 = len(p)
    if n0 == n_new:
        return p.copy()
    x0 = np.linspace(0, 1, n0)
    x1 = np.linspace(0, 1, n_new)
    p_new = np.interp(x1, x0, p)
    p_new = np.maximum(p_new, 1e-10)
    return p_new / p_new.sum()
