Our strategy is inspired by the Successive Over-Relaxation (SOR) principle and aims to optimize both the sequence's length and coefficients using a tailored-gradient approach. Key steps include:

1. Start from the parent sequence if available.
2. Split the sequence into blocks for directed optimization.
3. Project these blocks onto the simplex (non-negativity, sum=1) and evolve them using gradient ascent with adaptive momentum.
4. Balance exploration (new blocks) and exploitation (current optimization) via a convergence loop.
5. Iteratively expand sequences through coordinate doubling while monitoring progress towards the target score.
6. If improvement stalls, revert to the best candidate; otherwise, propose the optimized sequence.
