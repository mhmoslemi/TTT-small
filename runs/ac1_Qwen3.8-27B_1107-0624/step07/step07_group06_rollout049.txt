For k >= n: valid range is i=k-n+1 to n-1, width 2n-k-1. Peak at i=k/2.
- If k/2 is in [k-n+1, n-1], i.e., k-n+1 <= k/2 <= n-1, i.e., k <= 2n-2 and k >= 2n-2. So for k = 2n-2, the peak is at the boundary.
- For k < 2n-2: k/2 < n-1, and k/2 >= k-n+1 iff n-1 >= k/2 iff k <= 2n-2. So for all k < 2n-2, the peak is inside the valid range.

So for all k in [0, 2n-2], the peak of the parabola is inside the valid range. The sum is maximized when the width is largest AND the peak value is largest.

Width: for k <= n-1, width = k+1 (increasing with k). For k >= n-1, width = 2n-1-k (decreasing with k).
Peak value: f(k/2) = -(k/2)^2 + k*(k/2) + (k+1) = k^2/4 + k+1 (increasing with k).
