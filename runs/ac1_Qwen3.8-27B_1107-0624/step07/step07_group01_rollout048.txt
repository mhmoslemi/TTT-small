Let me think about a more targeted approach:

**Targeted approach: Multi-active-set Newton with line search**

1. Compute $c = a * a$
2. Identify the "active" peaks: the top $K$ values in $c$
3. Compute the subgradient of the max at these points: $g = \frac{1}{K} \sum_{k \in \mathcal{A}} \nabla c[k]$
4. Instead of a simple gradient step, solve for the "best" step:
   - We want to minimize $\max_{k \in \mathcal{A}} c[k + \delta]$ where $\delta$ is the change in $a$
   - Using the linear approximation: $c[k] + \nabla c[k] \cdot \delta$
   - We want to find $\delta$ (with $\sum \delta = 0$, $\|\delta\| \leq \Delta$) that minimizes $\max_{k \in \mathcal{A}} (c[k] + \nabla c[k] \cdot \delta)$
   - This is a linear programming problem in $n$ variables with $K+1$ constraints!
5. Solve the LP (or a relaxed version) to get the optimal direction
6. Line search for the step size
7. Project onto $a \geq 0$ and renormalize

The LP approach is interesting because it gives the exact optimal direction (within the linear approximation) rather than a gradient direction.

For $K = 5$ and $n = 16384$, this LP has 16384 variables and 6 constraints. That's very tractable!

Let me think about the LP-based approach more carefully.

Given active set $\mathcal{A}$ with $K$ indices, the LP is:
- Variables: $\delta \in \mathbb{R}^n$, $t \in \mathbb{R}$
- Minimize: $t$
- Subject to:
  - $g_k^T \delta - t \leq -c[k]$ for $k \in \mathcal{A}$ (i.e., $c[k] + g_k^T \delta \leq t$)
  - $\sum_j \delta[j] = 0$
  - $\delta[j] \geq -a[j]$ for all $j$ (non-negativity of $a + \delta$)

The $g_k[j] = 2 \cdot a[k-j]$ (for valid $k-j$), as derived above.

This LP has $n+1$ variables and $K + n + 1$ constraints. For $n = 16384$ and $K = 5$, that's 16385 variables and ~16400 constraints. This is a medium-sized LP that scipy can handle.

But actually, we don't need all the bound constraints $\delta[j] \geq -a[j]$ in the LP. We can solve the LP without them and then project the solution. Or we can use a very loose bound like $\delta[j] \geq -a[j] / 2$ to prevent $a$ from going too negative.

Actually, for the LP to be useful, the optimal solution should have $\|\delta\|$ small (linear approximation is valid). So we can add a trust region constraint: $\|\delta\|_2 \leq \Delta$. But that makes it a QP, not an LP.

Let me simplify: forget the trust region for now, just use the LP direction, and do a line search.

**Optimal equalization step**: Find $\delta$ such that $c[k] + g_k^T \delta = T$ for all $k \in \mathcal{A}$.

This is a system of $K$ linear equations in $n$ unknowns (plus the constraint $\sum \delta = 0$). We can solve for the minimum-norm solution using least squares.

This is much simpler than an LP! Let me derive it:

We want: $g_k^T \delta = T - c[k]$ for $k = k_1, ..., k_K$
And: $\sum_j \delta[j] = 0$

This is a system of $K+1$ equations in $n$ unknowns. The minimum-norm solution is:
$\delta = B^T (BB^T)^{-1} b$

where $B$ is the $(K+1) \times n$ matrix with rows $g_{k_1}, ..., g_{k_K}, \mathbf{1}^T$ and $b = [T - c[k_1], ..., T - c[k_K], 0]^T$.
