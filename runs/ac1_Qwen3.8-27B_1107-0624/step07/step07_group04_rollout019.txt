def _kkt_cg_solve(A_weights, S_idx, n):
    """Solve M*x = 1 where M[i,j] = A_weights[S_idx[i] + S_idx[j]] using CG."""
    p = len(S_idx)
    S_set = set(S_idx.tolist())

        # Compute M*v without forming M
        # Full vector: v_full where v_full[S_idx[i]] = v[i]
        v_full = np.zeros(n)
        v_full[S_idx] = v
        # H_A * v_full: (H_A * v_full)_i = A_weights[i] convolved with v_full... 
        # Actually, (H_A * v_full)_i = sum_j A_weights[i+j] * v_full[j]
        # This is the same as the Hankel matvec
        result_full = _hankel_matvec_generic(v_full, A_weights, n)
        return result_full[S_idx]
    
    # CG
    x = np.zeros(p)
    r = np.ones(p)
    p_vec = r.copy()
    rs = float(r @ r)

            break
        if not np.isfinite(rs_new):
            break

- Or directly if the support is known

If the support S is known, the solution is:
H_S * a_S = (ν/2) * 1, sum(a_S) = 1

where H_S is the |S|×|S| submatrix of H_{k*}.

This is the same system as before but with a single active point! And we can solve it using CG (since H_S is a submatrix of a Hankel matrix).

The advantage of assuming a single active point is that the system is simpler. The disadvantage is that the max might not be unique, in which case we need multiple active points.

**Practical hybrid approach:**

1. Start with the assumption that the max is at a single point (the center, for symmetric solutions).
2. Solve the QP / linear system.
3. Check if other c_k values exceed c_{k*}. If so, add them to the active set.
4. Iterate.

For the single-active-point case:
- k* = n-1 (center) for symmetric solutions
- H_{n-1} has (H_{n-1})_{i,j} = δ_{i+j, n-1}
- This means (H_{n-1} * v)_i = v_{n-1-i} (reversal!)
- So H_{n-1} is the reversal matrix!
- H_{n-1} * a = a_reversed
- The condition H_S * a_S = λ * 1 becomes a_S_reversed = λ * 1
- This means a_S is a constant vector (all equal)!

Wait, that can't be right. If a_S is constant, then a is a "block" of equal values on S and zero elsewhere. Let's check:
If a_i = 1/|S| for i in S and 0 elsewhere:
c_{n-1} = Σ_i a_i * a_{n-1-i} = (number of i in S such that n-1-i is also in S) / |S|^2

If S is symmetric around (n-1)/2, then n-1-i is in S whenever i is in S, so c_{n-1} = |S| / |S|^2 = 1/|S|.

And F = 2n * (1/|S|) / 1 = 2n/|S|.

To minimize this, we want |S| as large as possible, i.e., S = {0, ..., n-1} (full support), giving F = 2. Which is the uniform solution!

So for a single active point at the center with the constraint that a is symmetric, the optimal solution is uniform (F=2). This is worse than our target of 1.5.

The improvement comes from having MULTIPLE active points, which allows a to be non-constant and spread the mass more effectively.

OK so the single-active-point approach won't work. We need multiple active points.

Let me go back to the multi-active-point formulation. The key insight is:

For a given active set A with |A| = m and support S with |S| = p:
- We have m + p + 2 unknowns (μ_1..μ_m, a_{S_1}..a_{S_p}, t, ν)
- We have m + p + 2 equations (c_k = t for k in A, stationarity for i in S, sum(a) = 1, Σμ = 1)

The system is nonlinear (c_k = t is quadratic in a), but we can linearize:
- Given current a, compute c and t = max(c)
- Linearize c_k ≈ c_k^0 + 2*(H_k * a - H_k * a^0) = c_k^0 + 2*H_k*(a - a^0)
- Set c_k = t: c_k^0 + 2*H_k*(a - a^0) = t
- This gives: 2*H_k*a - t = 2*H_k*a^0 - c_k^0 for k in A

Combined with stationarity and sum constraint, this is a linear system!

But this is essentially the Newton method, which the previous code already implements.

**Let me try a different angle: what if I use a semidefinite programming (SDP) relaxation?**

The problem min max_k c_k subject to sum(a) = 1, a ≥ 0 is a QCQP (quatically constrained quadratic program). The SDP relaxation would be:

Let X = a*a^T (rank-1 constraint). Then c_k = Σ_{i+j=k} X_{i,j}.
The SDP relaxation drops the rank-1 constraint:
min max_k Σ_{i+j=k} X_{i,j}
subject to Σ_i X_{i,i} + 2*Σ_{i<j} X_{i,j} = 1 (this is (sum a)^2 = 1... wait no)

Hmm, actually sum(a) = 1 doesn't directly translate to a constraint on X. Let me think...

(sum a)^2 = Σ_i a_i^2 + 2Σ_{i<j} a_i a_j = trace(X) + 2*Σ_{i<j} X_{i,j}

Actually, (sum a)^2 = 1^T a * a^T 1 = 1^T X 1.

So the constraint is 1^T X 1 = 1, X ≥ 0 (PSD), X_{i,j} = a_i a_j (rank 1).

The SDP relaxation:
min t
subject to Σ_{i+j=k} X_{i,j} ≤ t for all k
1^T X 1 = 1
X ≥ 0

This is a linear program in X (linear objective, linear constraints, PSD constraint). It's a semidefinite program.

But the size is n×n, which for n=8192 is way too large for standard SDP solvers.

However, the constraints have a special structure (they're Hankel-like). Maybe we can exploit this.

Actually, I don't think SDP is practical here. Let me focus on the practical approaches.

**My final plan:**

1. Use the parent as the starting point
2. Implement a fast "active set KKT" method:
   - At each iteration, identify the active set A (top m convolution peaks)
   - Identify the support S
   - Solve the linearized system using CG (matrix-free Hankel matvec)
   - Update a
   - Check KKT conditions and adjust A, S
3. Use the central difference / subgradient method as a fallback
4. Try multiple n values
5. Try different initializations (not just the parent)

The key improvement over the previous code is:
- The KKT solve should converge in fewer iterations (directly solving the linear system vs. Newton with line search)
- The CG solve is matrix-free and fast (O(n log n) per iteration)
- We can use a tighter active set (fewer active points) for speed

Let me also add another idea: **spectral initialization**.

The optimal a should be an eigenvector of some matrix. Specifically, if we define the Hankel matrix H_A (weighted by the active set), then at optimality:
H_A * a = λ * 1 (on the support)

This means a is approximately an eigenvector of H_A (with the right-hand side being 1 instead of a). If we approximate 1 ≈ c * a (for some c), then a is approximately an eigenvector of H_A.

We could use power iteration or Lanczos to find the dominant eigenvector of H_A, and use it as the initial a.

But this is similar to what the optimization does anyway, so it might not help much.

"""
Optimized step function search using direct KKT active-set method with
matrix-free CG for Hankel systems, combined with L-BFGS polish and
multi-n exploration.
"""
import numpy as np
import time
from scipy.optimize import minimize


def _next_pow2(n):
    k = 1
    while k < n:
        k <<= 1
    return max(2, k)


def _full_convolve(a, b):
    n, m = len(a), len(b)
    out_n = n + m - 1
    N = _next_pow2(out_n)
    fa = np.fft.rfft(a, N)
    fb = np.fft.rfft(b, N)
    r = np.fft.irfft(fa * fb, N)[:out_n]
    return r


def _score(a):
    n = len(a)
    s = float(a.sum())
    if s < 1e-15:
        return np.inf
    c = _full_convolve(a, a)
    return float(2.0 * n * c.max() / (s * s))


def _softmax(z):
    z = z - np.max(z)
    e = np.exp(np.clip(z, -700, 700))
    s = e.sum()
    if s < 1e-300:
        return np.ones_like(z) / len(z)
    return e / s


def _hankel_matvec(v, W, n):
    """Compute (H_W * v)_i = sum_j W[i+j] * v[j] for i in [0,n-1]."""
    v_rev = v[::-1]
    out_len = len(v_rev) + len(W) - 1
    N = _next_pow2(out_len)
    F_v = np.fft.rfft(v_rev, N)
    F_W = np.fft.rfft(W, N)
    conv = np.fft.irfft(F_v * F_W, N)[:out_len]
    return conv[n - 1:2 * n - 1]


def _cg_hankel(W, n, rhs, S_idx=None, max_iter=200, tol=1e-14):
    """
    Solve (H_W restricted to S_idx) * x = rhs using CG.
    If S_idx is None, solve on full space [0, n-1].
    """
    if S_idx is not None:
        p = len(S_idx)
    else:
        p = n
        S_idx = np.arange(n)
    
    def matvec(v):
        v_full = np.zeros(n)
        v_full[S_idx] = v
        result_full = _hankel_matvec(v_full, W, n)
        return result_full[S_idx]
    
    x = np.zeros(p)
    r = rhs.copy()
    p_vec = r.copy()
    rs = float(r @ r)
    rs0 = rs
    if rs0 < 1e-40:
        return x
    for i in range(max_iter):
        Mp = matvec(p_vec)
        pHp = float(p_vec @ Mp)
        if abs(pHp) < 1e-40 or not np.isfinite(pHp):
            # Add regularization
            pHp += 1e-12
        alpha = rs / (pHp + 1e-15)
        if not np.isfinite(alpha):
            break
        x_new = x + alpha * p_vec
        r_new = r - alpha * Mp
        rs_new = float(r_new @ r_new)
        if not np.isfinite(rs_new) or rs_new > rs * (1 + 1e-6):
            break
        x = x_new
        r = r_new
        p_vec = (rs_new / rs) * p_vec + r
        rs = rs_new
        if rs < tol * tol * rs0:
            break
    return x

def _kkt_optimize(a_init, deadline, max_rounds=300, active_tol=1e-4, support_thresh=1e-10):
    """
    Direct KKT active-set optimizer.
    At each iteration:
    1. Identify active set A (convolution peaks) and support S
    2. Solve the linear system M*a_S = lambda*1, sum(a_S) = 1
    3. Check KKT conditions
    4. Update
    """
    n = len(a_init)
    a = a_init.copy()
    a = np.maximum(a, 0)
    s = a.sum()
    if s < 1e-15:
        return a, np.inf
    a /= s
    best_a = a.copy()
    best_sc = _score(a)
    
    for rnd in range(max_rounds):
        if time.monotonic() > deadline:
            break
        
        c = _full_convolve(a, a)
        c_max = float(c.max())
        
        # Active set
        tol = active_tol * c_max
        active = c >= (c_max - tol)
        if not active.any():
            active[int(np.argmax(c))] = True
        n_active = int(active.sum())
        
        # Weights (uniform for now)
        W = np.zeros(2 * n - 1)
        W[active] = 1.0 / n_active
        
        # Support
        support = a > support_thresh
        S_idx = np.where(support)[0]
        p = len(S_idx)
        
        if p < 2:
            # Expand support
            top2 = np.argsort(a)[::-1][:2]
            support[top2] = True
            S_idx = np.where(support)[0]
            p = len(S_idx)
        
        # Solve M*x = 1 where M[i,j] = W[S_idx[i] + S_idx[j]]
        x = _cg_hankel(W, n, np.ones(p), S_idx, max_iter=300)
        
        sum_x = float(np.sum(x))
        if sum_x <= 1e-15 or not np.isfinite(sum_x):
            break
        
        lam = 1.0 / sum_x
        a_S_new = lam * x
        
        # Check non-negativity
        min_as = float(a_S_new.min())
        if min_as < -1e-8:
            # Remove negative elements
            neg_mask = a_S_new < -1e-10
            n_removed = 0
            for idx in np.where(neg_mask)[0]:
                support[S_idx[idx]] = False
                n_removed += 1
            if n_removed == 0:
                break
            # Continue with reduced support (will re-solve)
            continue
        
        # Clip small negatives to zero
        a_S_new = np.maximum(a_S_new, 0)
        
        # Build new a
        a_new = np.zeros(n)
        a_new[S_idx] = a_S_new
        s_new = a_new.sum()
        if s_new < 1e-15:
            break
        a_new /= s_new
        
        sc_new = _score(a_new)
        if sc_new < best_sc - 1e-14:
            best_sc = sc_new
            best_a = a_new.copy()
        
        # Check convergence
        diff = np.linalg.norm(a_new - a)
        if diff < 1e-13:
            break
        
        # Check if we should expand support (KKT violation)
        # g_i = (H_W * a_new)_i for i not in support
        g = _hankel_matvec(a_new, W, n)
        not_support = ~support
        if not_support.any():
            max_g_ns = float(g[not_support].max())
            if max_g_ns > lam * 1.01:
                # Find the most violating index
                g_masked = np.where(not_support, g, -np.inf)
                add_idx = int(np.argmax(g_masked))
                support[add_idx] = True
                # Don't update a; re-solve with new support
                a = a_new  # Still update a for the active set computation
                continue
        
        a = a_new
    
    return best_a, best_sc
