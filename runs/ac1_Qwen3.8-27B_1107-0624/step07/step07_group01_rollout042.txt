- For `k < n/2`: `conv[k] = sum_{i=0}^{k} a[i]*a[k-i]`. If both i and k-i are < n/2, the product is 1. If one is >= n/2, the product is c.

OK let me think about this more carefully from the optimization perspective.

The objective in the `z`-space (where `a = softmax(z)`) is:
`f(z) = 2n * max_k sum_i a_i * a_{k-i}`

This is a non-smooth function (because of the max). The log-sum-exp smoothing gives:
`f_smooth(z) = 2n * (c_max + beta * log(sum exp((c_k - c_max)/beta)))`

where `c_k = conv(a,a)[k]`.

As beta → 0, `f_smooth → f`. The gradient involves the weights `w_k = exp((c_k - c_max)/beta) / sum exp((c_j - c_max)/beta)`.

For small beta, only the top few `c_k` have significant weight. The gradient then points in the direction that reduces those top values.

The issue with L-BFGS is that it's a first-order method that might not be efficient for this type of non-smooth (or nearly non-smooth) problem. The Hessian of the smooth approximation is ill-conditioned for small beta.

**Alternative: Use a "moreau envelope" type approach.**

The Moreau envelope of `f` at point `a` is:
`f_mu(a) = min_b { f(b) + (1/(2*mu)) * ||a-b||^2 }`

This is a smooth function that approximates `f` well when `mu` is small. The gradient of the Moreau envelope is `(a - b*/mu)` where `b*` is the argmin.

In practice, we can compute the Moreau envelope gradient by solving a small optimization problem at each step. But this might be too expensive.

**Simpler alternative: Proximal gradient / ISTA-FISTA**

If we can write the problem as `min g(x) + h(x)` where `g` is smooth and `h` is non-smooth but has a cheap prox, we can use proximal gradient methods.

In our case, `g(z) = 2n * log-sum-exp_normalized(c(z))/beta` (smooth) and `h(z) = 0` (no non-smooth part). So it's just a smooth optimization problem, and we can use any first-order or second-order method.

2. Combined with adaptive beta (starting large, decreasing over time).
3. Use the "effective active set" (top-k with k determined by the weights) for gradient computation.
4. Periodically switch to L-BFGS for the final polishing.
5. Use basin hopping to escape local minima.

Let me also consider: can we use the convexity of the problem in a clever way?

The problem `min max_k c_k(a)` subject to `a >= 0, sum(a) = 1` can be written as:
`min t` subject to `c_k(a) <= t` for all k, `a >= 0`, `sum(a) = 1`.

Each constraint `c_k(a) <= t` is `a^T Q_k a <= t` where `Q_k` is a symmetric matrix (the quadratic form corresponding to the k-th convolution value). This is a non-convex constraint (quadratic inequality).

So the problem is a QCQP (Quadratically Constrained Quadratic Program), which is NP-hard in general. But for our specific structure, there might be special properties.

One approach: use a "rKKT" (relaxed KKT) method. At the optimum, there exist multipliers `lambda_k >= 0` such that:
`2 * sum_k lambda_k * Q_k * a = \mu * 1 + \nu` (gradient of objective = combination of constraint gradients)
where `\mu` is the multiplier for the sum constraint and `\nu` is the vector of multipliers for the non-negativity constraints.

This is a system of equations that we can try to solve iteratively.

def _next_pow2(n):
    k = 1
    while k < n:

def _full_convolve(a, b):

    N = _next_pow2(out_n)
    fa = np.fft.rfft(a, N)
    fb = np.fft.rfft(b, N)
    r = np.fft.irfft(fa * fb, N)[:out_n]
    return r

def _objective_grad_z(z, beta, n):

    c = _full_convolve(a, a)
    c_max = c.max()
    shifted = (c - c_max) / beta
    e = np.exp(shifted)
    s = e.sum()
    if s < 1e-300:
        obj = 2.0 * n * c_max
        w = np.zeros_like(c)
        w[int(np.argmax(c))] = 1.0
    else:
        obj = 2.0 * n * (c_max + beta * np.log(s))
        w = e / s
    
    a_rev = a[::-1]
    wc = _full_convolve(w, a_rev)
    h = wc[n - 1:2 * n - 1]
    W = float(np.dot(w, c))
    grad_a = 4.0 * n * (h - W)

    correction = float(np.dot(grad_a, a))
    grad_z = a * (grad_a - correction)
    
    return obj, grad_z


def _adam_smooth(z0, beta_schedule, n, max_iter, deadline, reserve_time=30.0):
    """Optimize using Adam with a beta schedule."""
    z = z0.copy()
    m = np.zeros_like(z)
    v = np.zeros_like(z)
    beta1, beta2, eps = 0.9, 0.999, 1e-8
    lr = 1.0
    best_a = _softmax(z)
    best_sc = _score(best_a)
    t = 0
    
    for t in range(max_iter):
        if time.monotonic() + reserve_time > deadline:
            break
        
        # Get current beta from schedule
        if t < len(beta_schedule):
            beta = beta_schedule[t]
        else:
            beta = beta_schedule[-1]
        
        obj, grad_z = _objective_grad_z(z, beta, n)
        
        # Adam update
        t += 1
        m = beta1 * m + (1 - beta1) * grad_z
        v = beta2 * v + (1 - beta2) * grad_z ** 2
        m_hat = m / (1 - beta1 ** t)
        v_hat = v / (1 - beta2 ** t)
        z = z - lr * m_hat / (np.sqrt(v_hat) + eps)
        z = z - z.mean()
        z = np.clip(z, -50.0, 50.0)
        
        # Evaluate every 100 steps
        if (t + 1) % 100 == 0:
            a_check = _softmax(z)
            sc = _score(a_check)
            if sc < best_sc:
                best_sc = sc
                best_a = a_check.copy()
        
        # Adaptive lr
        if (t + 1) % 500 == 0:
            sc_now = _score(_softmax(z))
            if sc_now < best_sc:
                lr *= 1.05
            else:
                lr *= 0.85
            lr = min(lr, 5.0)
    
    # Final check
    a_final = _softmax(z)
    sc_final = _score(a_final)
    if sc_final < best_sc:
        best_a = a_final.copy()
        best_sc = sc_final
    
    return best_a, best_sc


def _lbfgs_smooth(a_init, beta, n, max_iter, ftol=1e-20, gtol=1e-16):
    z0 = np.log(np.maximum(a_init, 1e-18))
    z0 = z0 - z0.mean()
    
    def fun(z):
        obj, _ = _objective_grad_z(z, beta, n)
        return obj
    
    def jac(z):
        _, g = _objective_grad_z(z, beta, n)
        return g
    
    try:
        result = minimize(fun, z0, jac=jac, method='L-BFGS-B',
                          options={'maxiter': max_iter, 'ftol': ftol,
                                   'gtol': gtol, 'maxcor': 100,
                                   'maxls': 100, 'disp': False})
        a_out = _softmax(result.x)
        return a_out
    except Exception:
        return a_init.copy()


def _nesterov_subgrad(a_init, deadline, k_active=5, max_steps=50000, lr_init=0.03, momentum=0.9):
    """Nesterov-accelerated subgradient descent in z-space."""
    n = len(a_init)
    z = np.log(np.maximum(a_init, 1e-18))
    z = z - z.mean()
    v = np.zeros_like(z)  # velocity
    best_a = a_init.copy()
    best_sc = _score(a_init)
    lr = lr_init
    stall = 0
    
    for i in range(max_steps):
        if time.monotonic() > deadline:
            break
        
        # Nesterov lookahead
        z_look = z - momentum * v
        a = _softmax(z_look)
        c = _full_convolve(a, a)
        
        idx = np.argsort(c)[::-1][:k_active]
        w = np.zeros_like(c)
        w[idx] = 1.0 / len(idx)
        
        a_rev = a[::-1]
        wc = _full_convolve(w, a_rev)
        h = wc[n - 1:2 * n - 1]
        W = float(np.dot(w, c))
        grad_a = 2.0 * n * (h - W)
        
        correction = float(np.dot(grad_a, a))
        grad_z = a * (grad_a - correction)
        
        gnorm = np.linalg.norm(grad_z)
        if gnorm < 1e-16:
            break
        
        v = momentum * v + lr * grad_z / (n * a.sum())
        z = z - v
        z = z - z.mean()
        z = np.clip(z, -80.0, 80.0)
        
        if (i + 1) % 1000 == 0:
            a_check = _softmax(z)
            sc = _score(a_check)
            if sc < best_sc - 1e-12:
                best_sc = sc
                best_a = a_check.copy()
                lr *= 1.03
                stall = 0
            else:
                stall += 1
                lr *= (0.95 if stall < 20 else 0.85)
                if lr < 1e-10:
                    break
    
    a_final = _softmax(z)
    sc_final = _score(a_final)
    if sc_final < best_sc:
        best_a = a_final.copy()
        best_sc = sc_final
    
    return best_a, best_sc


def _kkt_newton(a_init, deadline, k_active=4, max_iter=100):
    """
    Newton iteration on the KKT conditions.
    At optimum: grad_f = lambda * 1 (for the sum constraint)
    where f = 2n * max_k c_k / (sum a)^2, and we're on the simplex.
    
    We use the active set to compute the gradient and solve a Newton system.
    """
    n = len(a_init)
    z = np.log(np.maximum(a_init, 1e-18))
    z = z - z.mean()
    best_a = a_init.copy()
    best_sc = _score(a_init)
    
    for it in range(max_iter):
        if time.monotonic() > deadline:
            break
        
        a = _softmax(z)
        c = _full_convolve(a, a)
        idx = np.argsort(c)[::-1][:k_active]
        
        # Check if active set is stable
        w = np.zeros_like(c)
        w[idx] = 1.0 / len(idx)
        
        a_rev = a[::-1]
        wc = _full_convolve(w, a_rev)
        h = wc[n - 1:2 * n - 1]
        W = float(np.dot(w, c))
        grad_a = 2.0 * n * (h - W)
        correction = float(np.dot(grad_a, a))
        grad_z = a * (grad_a - correction)
        
        gnorm = np.linalg.norm(grad_z)
        if gnorm < 1e-12:
            break
        
        # Newton step: solve H * delta = -grad
        # Approximate Hessian as diagonal (from the smooth approximation)
        # Or use a barzilai-borwein step
        # For simplicity, use a scaled gradient step with backtracking
        alpha = 1.0
        improved = False
        for _ in range(30):
            z_try = z - alpha * grad_z / (n * gnorm)
            z_try = z_try - z_try.mean()
            a_try = _softmax(z_try)
            sc_try = _score(a_try)
            if sc_try < best_sc:
                best_sc = sc_try
                best_a = a_try.copy()
                z = z_try
                improved = True
                break
            alpha *= 0.7
        
        if not improved:
            alpha *= 0.5
            if alpha < 1e-15:
                break
            z = z - alpha * grad_z / (n * gnorm)
            z = z - z.mean()
    
    return best_a, best_sc


def _make_chirp(n, freq=1.0, eps=0.3):
    t = np.arange(n)
    a = 1.0 + eps * np.cos(2.0 * np.pi * freq * t * t / n)
    a = np.maximum(a, 1e-10)
    return a / a.sum()


def _make_asymmetric(n, rng, strength=0.3):
    """Create an asymmetric sequence (key insight: asymmetry helps)."""
    t = np.arange(n)
    # Linear ramp + noise
    ramp = 1.0 + strength * (2.0 * t / n - 1.0)
    noise = 0.1 * rng.standard_normal(n)
    a = ramp + noise
    a = np.maximum(a, 1e-10)
    return a / a.sum()


def _make_tapered_asymmetric(n, power=0.5, asym=0.2):
    """Tapered but asymmetric."""
    t = np.linspace(0, 1, n)
    center = 0.4 + asym  # shift center
    a = np.exp(-power * ((t - center) / (1 - center)) ** 2)
    a = np.maximum(a, 1e-10)
    return a / a.sum()


def _interpolate_to_n(a, target_n):
    n_cur = len(a)
    if n_cur == target_n:
        return a.copy()
    t_old = np.linspace(0, 1, n_cur)
    t_new = np.linspace(0, 1, target_n)
    a_interp = np.interp(t_new, t_old, a)
    a_interp = np.maximum(a_interp, 1e-12)
    a_interp = a_interp / a_interp.sum()
    return a_interp


def _basin_hop_structured(a_current, deadline, rng, n_hops=8, reserve=20.0):
    """Basin hopping with structured perturbations in Fourier space."""
    n = len(a_current)
    best_a = a_current.copy()
    best_sc = _score(a_current)
    time_per_hop = max(20.0, (deadline - reserve - time.monotonic()) / n_hops)
    
    for h in range(n_hops):
        if time.monotonic() > deadline - reserve:
            break
        hop_deadline = time.monotonic() + time_per_hop * 0.8
        
        pert_type = h % 4
        z = np.log(np.maximum(best_a, 1e-18))
        z = z - z.mean()
        
        if pert_type == 0:
            # Low-frequency Fourier perturbation
            fa = np.fft.rfft(z)
            for _ in range(3 + h):
                k = int(rng.integers(1, max(2, n // 8)))
                amp = rng.uniform(0.03, 0.1) * (1 + h * 0.1)
                phase = rng.uniform(0, 2 * np.pi)
                fa[k] += amp * np.exp(1j * phase)
                if k < len(fa) - 1:
                    fa[-k] += amp * np.exp(-1j * phase)
            z_pert = np.fft.irfft(fa, n)
        elif pert_type == 1:
            # Block perturbation
            n_blocks = 4 + h
            block_sz = max(1, n // n_blocks)

def _multi_beta_lbfgs(a_start, deadline, reserve_time=60.0):
    """L-BFGS with multiple beta values, adaptive."""
    n = len(a_start)
    c_cur = _full_convolve(a_start, a_start)
    max_c = float(c_cur.max())
    if max_c < 1e-30:
        return a_start
    
    current_a = a_start.copy()
    current_sc = _score(current_a)
    
    # Start with moderate beta, decrease
    base_beta = max_c * 0.1
    betas = base_beta * np.array([1.0, 0.5, 0.25, 0.1, 0.05, 0.02,
                                   0.01, 0.005, 0.002, 0.001,
                                   0.0005, 0.0002, 0.0001, 5e-5,
                                   2e-5, 1e-5, 5e-6, 2e-6, 1e-6])
    
    for i, beta in enumerate(betas):
        if time.monotonic() + reserve_time > deadline:
            break
        remaining = deadline - reserve_time - time.monotonic()
        if remaining < 10:
            break
        
        scale = max(1.0, (n / 4096.0))
        max_iter = min(8000, max(200, int(remaining / (0.003 * scale * 20))))
        
        a_new = _lbfgs_smooth(current_a, beta, n, max_iter)
        sc = _score(a_new)
        
        if sc < current_sc - 1e-16:
            current_a = a_new
            current_sc = sc
        
        if current_sc < 1.5001:
            break
    
    return current_a

Let me also add one more idea: **iterative active set refinement**.

The idea is:
1. Start with an active set A (indices where conv ≈ max).
2. For this active set, solve the KKT conditions (find a such that the gradient of the "average" of the active values is zero on the simplex).
3. Check if the solution is valid (i.e., the inactive values are ≤ the active values).
4. If not, update the active set (add the most violated inactive index, remove the least active index from A).
5. Repeat.

This is similar to the "active set" method for linear programming, adapted to our problem.

The KKT condition for a fixed active set A with uniform weights:
- Let `g_A(a) = (1/|A|) * sum_{k in A} conv(a,a)[k]`.
- We want `grad g_A(a) = \lambda * 1` (the gradient is constant, meaning it's proportional to the sum constraint gradient).
- Equivalently, `grad g_A(a) - mean(grad g_A(a)) = 0` on the simplex.

This gives a system of n equations in n unknowns (the values of a, with the constraint sum(a)=1 reducing it to n-1).

For a linear approximation, this is easy. For the quadratic form, it's a system of quadratic equations. We can solve it with Newton's method.

"""
Optimizer for minimizing 2*n*max(conv(a,a))/(sum(a))^2 using:
1. Adam optimizer with adaptive log-sum-exp smoothing
2. Nesterov-accelerated subgradient descent in z-space
3. L-BFGS with progressive beta tightening
4. Asymmetric initializations (key insight: anti-symmetry reduces center peak)
5. Structured basin hopping in Fourier space
6. Multi-length exploration
7. Final aggressive micro-polishing

import numpy as np
import time
from scipy.optimize import minimize


def _next_pow2(n):
    k = 1
    while k < n:
        k <<= 1
    return max(2, k)


def _full_convolve(a, b):
    n, m = len(a), len(b)
    out_n = n + m - 1
    N = _next_pow2(out_n)
    fa = np.fft.rfft(a, N)
    fb = np.fft.rfft(b, N)
    r = np.fft.irfft(fa * fb, N)[:out_n]
    return r


def _score(a):
    n = len(a)
    s = float(a.sum())
    if s < 1e-15:
        return np.inf
    c = _full_convolve(a, a)
    return float(2.0 * n * c.max() / (s * s))


def _softmax(z):
    z = z - np.max(z)
    e = np.exp(z)
    s = e.sum()
    if s < 1e-300:
        return np.ones_like(z) / len(z)
    return e / s


def _objective_grad_z(z, beta, n):
    """Compute smoothed objective and gradient w.r.t. z."""
    a = _softmax(z)
    c = _full_convolve(a, a)
    c_max = c.max()
    shifted = (c - c_max) / beta
    e = np.exp(shifted)
    s = e.sum()
    if s < 1e-300 or not np.isfinite(s):
        obj = 2.0 * n * c_max
        w = np.zeros_like(c)
        w[int(np.argmax(c))] = 1.0
    else:
        obj = 2.0 * n * (c_max + beta * np.log(s))
        w = e / s

    a_rev = a[::-1]
    wc = _full_convolve(w, a_rev)
    h = wc[n - 1:2 * n - 1]
    W = float(np.dot(w, c))
    grad_a = 4.0 * n * (h - W)
    correction = float(np.dot(grad_a, a))
    grad_z = a * (grad_a - correction)
    return obj, grad_z


def _grad_subgrad(a, n, k_active):
    """Subgradient of max conv at the top-k active indices."""
    c = _full_convolve(a, a)
    idx = np.argsort(c)[::-1][:k_active]
    w = np.zeros_like(c)
    w[idx] = 1.0 / len(idx)
    a_rev = a[::-1]
    wc = _full_convolve(w, a_rev)
    h = wc[n - 1:2 * n - 1]
    W = float(np.dot(w, c))
    return 2.0 * n * (h - W)


def _adam_optimize(z0, n, beta_list, deadline, reserve_time=60.0):
    """Adam optimizer with progressive beta tightening."""
    z = z0.copy()
    m = np.zeros_like(z)
    v = np.zeros_like(z)
    b1, b2, eps = 0.85, 0.999, 1e-8
    lr = 0.5
    t = 0
    best_a = _softmax(z)
    best_sc = _score(best_a)
    best_z = z.copy()

    for beta in beta_list:
        if time.monotonic() + reserve_time > deadline:
            break
        iters_in_phase = 0
        patience = 0
        while patience < 50000:
            if time.monotonic() + reserve_time > deadline:
                break
            iters_in_phase += 1
            t += 1
            obj, grad_z = _objective_grad_z(z, beta, n)
            # Gradient clipping
            gnorm = np.linalg.norm(grad_z)
            if gnorm > 10.0 * n:
                grad_z = grad_z * 10.0 * n / gnorm

            m = b1 * m + (1 - b1) * grad_z
            v = b2 * v + (1 - b2) * grad_z ** 2
            m_hat = m / (1 - b1 ** t)
            v_hat = v / (1 - b2 ** t)
            z = z - lr * m_hat / (np.sqrt(v_hat) + eps)
            z = z - z.mean()
            z = np.clip(z, -40.0, 40.0)

            if iters_in_phase % 2000 == 0:
                a_check = _softmax(z)
                sc = _score(a_check)
                if sc < best_sc - 1e-13:
                    best_sc = sc
                    best_a = a_check.copy()
                    best_z = z.copy()
                    patience = 0
                    lr = min(lr * 1.02, 3.0)
                else:
                    patience += 2000
                    if patience > 10000:
                        lr *= 0.7
                        if lr < 0.01:
                            break
        # Phase summary
        a_phase = _softmax(z)
        sc_phase = _score(a_phase)
        if sc_phase < best_sc:
            best_sc = sc_phase
            best_a = a_phase.copy()
            best_z = z.copy()

    return best_a, best_sc


def _lbfgs_phase(a_init, beta, n, max_iter=5000):
    """Single L-BFGS phase at given beta."""
    z0 = np.log(np.maximum(a_init, 1e-18))
    z0 = z0 - z0.mean()

    def fun(z):
        obj, _ = _objective_grad_z(z, beta, n)
        return obj

    def jac(z):
        _, g = _objective_grad_z(z, beta, n)
        return g

    try:
        result = minimize(fun, z0, jac=jac, method='L-BFGS-B',
                          options={'maxiter': max_iter, 'ftol': 1e-22,
                                   'gtol': 1e-16, 'maxcor': 80,
                                   'maxls': 100, 'disp': False})
        return _softmax(result.x)
    except Exception:
        return a_init.copy()


def _multi_beta_lbfgs(a_start, deadline, reserve_time=60.0):
    """Progressive L-BFGS with decreasing beta."""
    n = len(a_start)
    c_cur = _full_convolve(a_start, a_start)
    max_c = float(c_cur.max())
    if max_c < 1e-30:
        return a_start
    current_a = a_start.copy()
    current_sc = _score(current_a)

    # Geometric beta schedule
    ratios = [0.15, 0.08, 0.04, 0.02, 0.01, 0.005,
              0.002, 0.001, 0.0005, 0.0002, 0.0001,
              5e-5, 2e-5, 1e-5, 5e-6, 2e-6, 1e-6]
    for ratio in ratios:
        if time.monotonic() + reserve_time > deadline:
            break
        remaining = deadline - reserve_time - time.monotonic()
        if remaining < 5:
            break
        beta = max_c * ratio
        scale = max(1.0, (n / 8192.0))
        max_iter = min(10000, max(500, int(remaining / (0.005 * scale * 15))))
        a_new = _lbfgs_phase(current_a, beta, n, max_iter)
        sc = _score(a_new)
        if sc < current_sc - 1e-17:
            current_a = a_new
            current_sc = sc
        if current_sc < 1.5002:
            break
    return current_a


def _nesterov_subgrad(a_init, deadline, k_active=5, max_steps=40000,
                      lr_init=0.04, momentum=0.9):
    """Nesterov-accelerated subgradient in z-space."""
    n = len(a_init)
    z = np.log(np.maximum(a_init, 1e-18))
    z = z - z.mean()
    vel = np.zeros_like(z)
    best_a = a_init.copy()
    best_sc = _score(a_init)
    lr = lr_init
    stall = 0

    for i in range(max_steps):
        if time.monotonic() > deadline:
            break
        z_look = z - momentum * vel
        a = _softmax(z_look)
        c = _full_convolve(a, a)
        idx = np.argsort(c)[::-1][:k_active]
        w = np.zeros_like(c)
        w[idx] = 1.0 / len(idx)
        a_rev = a[::-1]
        wc = _full_convolve(w, a_rev)
        h = wc[n - 1:2 * n - 1]
        W = float(np.dot(w, c))
        grad_a = 2.0 * n * (h - W)
        corr = float(np.dot(grad_a, a))
        grad_z = a * (grad_a - corr)

        gnorm = np.linalg.norm(grad_z)
        if gnorm < 1e-15:
            break
        vel = momentum * vel + lr * grad_z / (n * a.sum())
        z = z - vel
        z = z - z.mean()
        z = np.clip(z, -60.0, 60.0)

        if (i + 1) % 2000 == 0:
            a_check = _softmax(z)
            sc = _score(a_check)
            if sc < best_sc - 1e-13:
                best_sc = sc
                best_a = a_check.copy()
                lr = min(lr * 1.03, 0.5)
                stall = 0
            else:
                stall += 2000
                if stall > 20000:
                    lr *= 0.7
                    if lr < 1e-8:
                        break
                    stall = 0
                elif stall > 8000:
                    lr *= 0.9

    a_final = _softmax(z)
    sc_final = _score(a_final)
    if sc_final < best_sc:
        best_a = a_final.copy()
        best_sc = sc_final
    return best_a, best_sc


def _direct_projected_subgrad(a_init, deadline, k_active=4, max_steps=20000):
    """Subgradient in a-space with simplex projection and backtracking."""
    n = len(a_init)
    a = a_init.copy()
    best_a = a.copy()
    best_sc = _score(a)
    alpha = 1.0 / np.sqrt(n)

    for i in range(max_steps):
        if time.monotonic() > deadline:
            break
        c = _full_convolve(a, a)
        idx = np.argsort(c)[::-1][:k_active]
        w = np.zeros_like(c)
        w[idx] = 1.0 / len(idx)
        a_rev = a[::-1]
        wc = _full_convolve(w, a_rev)
        h = wc[n - 1:2 * n - 1]
        W = float(np.dot(w, c))
        g = 2.0 * (h - W)

        # Backtracking line search
        sc_cur = best_sc
        improved = False
        for _ in range(15):
            a_try = a - alpha * g
            # Project to simplex: a_try >= 0, sum(a_try) = 1
            a_try = np.maximum(a_try, 0.0)
            s = a_try.sum()
            if s > 1e-15:
                a_try = a_try / s
            sc_try = _score(a_try)
            if sc_try < best_sc:
                best_sc = sc_try
                best_a = a_try.copy()
                a = a_try
                improved = True
                break
            alpha *= 0.7

        if improved:
            alpha = min(alpha * 1.05, 1.0)
        else:
            alpha *= 0.8
            if alpha < 1e-12:
                break

    return best_a, best_sc


def _make_chirp(n, freq=1.0, eps=0.3):
    t = np.arange(n)
    a = 1.0 + eps * np.cos(2.0 * np.pi * freq * t * t / n)
    a = np.maximum(a, 1e-10)
    return a / a.sum()


def _make_asymmetric_ramp(n, rng, strength=0.2):
    t = np.arange(n) / n
    a = 1.0 + strength * (2.0 * t - 1.0) + 0.05 * rng.standard_normal(n)
    a = np.maximum(a, 1e-10)
    return a / a.sum()


def _make_exp_asymmetric(n, center_frac=0.3, width=0.15, rng=None):
    t = np.linspace(0, 1, n)
    a = np.exp(-((t - center_frac) / width) ** 2)
    if rng is not None:
        a += 0.05 * np.abs(rng.standard_normal(n))
    a = np.maximum(a, 1e-10)
    return a / a.sum()


def _make_two_bump(n, rng, pos1=0.25, pos2=0.75, amp1=1.0, amp2=0.6):
    t = np.linspace(0, 1, n)
    a = amp1 * np.exp(-((t - pos1) / 0.1) ** 2) + amp2 * np.exp(-((t - pos2) / 0.08) ** 2)
    if rng is not None:
        a += 0.02 * np.abs(rng.standard_normal(n))
    a = np.maximum(a, 1e-10)
    return a / a.sum()


def _interpolate_to_n(a, target_n):
    n_cur = len(a)
    if n_cur == target_n:
        return a.copy()
    t_old = np.linspace(0, 1, n_cur)
    t_new = np.linspace(0, 1, target_n)
    a_interp = np.interp(t_new, t_old, a)
    a_interp = np.maximum(a_interp, 1e-12)
    a_interp = a_interp / a_interp.sum()
    return a_interp


def _basin_hop(a_current, deadline, rng, n_hops=12, reserve=30.0):
    """Structured basin hopping with Fourier, block, and smooth perturbations."""
    n = len(a_current)
    best_a = a_current.copy()
    best_sc = _score(a_current)
    time_per_hop = max(15.0, (deadline - reserve - time.monotonic()) / max(1, n_hops))

    for h in range(n_hops):
        if time.monotonic() > deadline - reserve:
            break
        hop_deadline = time.monotonic() + time_per_hop * 0.85
        pt = h % 4
        z = np.log(np.maximum(best_a, 1e-18))
        z = z - z.mean()

        if pt == 0:
            # Low-frequency Fourier perturbation
            fa = np.fft.rfft(z.astype(np.float64))
            n_mod = 3 + h // 2
            for _ in range(n_mod):
                k = int(rng.integers(1, max(2, n // 6)))
                amp = rng.uniform(0.02, 0.08) * (1.0 + 0.05 * h)
                ph = rng.uniform(0, 2 * np.pi)
                if k < len(fa):
                    fa[k] = fa[k] + amp * np.exp(1j * ph)
                if k > 0 and k < len(fa):
                    fa[k] = fa[k].conjugate() if k == len(fa) - 1 else fa[k]
            # Redo properly
            fa = np.fft.rfft(z.astype(np.float64))
            for _ in range(n_mod):
                k = int(rng.integers(1, max(2, n // 6)))
                amp = rng.uniform(0.02, 0.08) * (1.0 + 0.05 * h)
                ph = rng.uniform(0, 2 * np.pi)
                if k < len(fa):
                    fa[k] += amp * np.cos(ph) + 1j * amp * np.sin(ph)
            z_pert = np.real(np.fft.irfft(fa, n))
        elif pt == 1:
            # Block perturbation
            z_work = z.copy()
            n_blocks = 5 + h
            bsz = max(1, n // n_blocks)
            for _ in range(n_blocks):
                start = int(rng.integers(0, max(1, n - bsz)))
                end = min(n, start + bsz)
                z_work[start:end] += rng.normal(0, 0.04)
            z_pert = z_work
        elif pt == 2:
            # Smooth Gaussian perturbation
            length_scale = max(2, n // (15 + h))
            kernel = np.exp(-np.arange(n) ** 2 / (2.0 * length_scale ** 2))
            kernel /= max(kernel.sum(), 1e-30)
            noise = rng.standard_normal(n)
            z_pert = z + 0.04 * np.convolve(noise, kernel, mode='same')
        else:
            # Random smooth + sharp mix
            sig = 0.03 + 0.01 * h
            z_pert = z + sig * rng.standard_normal(n)
            # Add a few sharp features
            for _ in range(3):
                idx2 = int(rng.integers(0, n))
                width2 = int(rng.integers(1, max(2, n // 200)))
                z_pert[max(0, idx2 - width2):min(n, idx2 + width2 + 1)] += \
                    rng.uniform(-0.05, 0.05)

        z_pert = z_pert - z_pert.mean()
        z_pert = np.clip(z_pert, -40.0, 40.0)
        a_pert = _softmax(z_pert)

        # Quick L-BFGS from perturbation
        if time.monotonic() < hop_deadline:
            c_p = _full_convolve(a_pert, a_pert)
            mc = c_p.max()
            beta = mc * 0.01
            max_iter = min(4000, max(100, int((hop_deadline - time.monotonic()) / 0.003)))
            if max_iter > 100:
                a_opt = _lbfgs_phase(a_pert, beta, n, max_iter)
                sc_opt = _score(a_opt)
                if sc_opt < best_sc:
                    best_sc = sc_opt

    return best_a, best_sc


def _active_set_check(a, k=5):

def propose_candidate(seed=42, budget_s=1800):

    """
    t_start = time.monotonic()

    best_seq = None
    best_score_val = np.inf
