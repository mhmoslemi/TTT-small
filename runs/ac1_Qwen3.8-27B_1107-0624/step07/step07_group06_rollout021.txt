The issue is that the "payoff" values c_k are very small (order 1/n), so the regret in absolute terms is small, but when multiplied by 2n, it becomes large in score terms.

Let me redo the calculation. The MWA (Multiplicative Weights Algorithm) for the min-max problem gives:
max_k (1/T) sum_t p_k^t c_k(a^t) <= v + O(sqrt(log(K)/T)) * C

where C is the range of c_k values. But this is a bound on the "average" payoff, not the max.

Actually, the standard MWA bound is:
(1/T) sum_t max_k c_k(a^t) <= v + O(sqrt(log(K)/T)) * C

So the average of the max payoffs is bounded. This means that for most t, max_k c_k(a^t) is close to v.

But we want a single a with small max_k c_k, not an average.

The "follow-the-regularized-leader" or "exponential weights" approach gives a bound on the average, and the "Median Lemma" (Cesa-Bianchi et al.) gives that at least T/2 of the iterates are within 2x the average. So at least T/2 iterates have max_k c_k <= 2v + O(sqrt(log(K)/T)) * C.

This is still a bound on the max, not on a single iterate's max.

To get a single good iterate, we can use "optimal external prediction" or just keep track of the best iterate so far.

In practice, the MWA approach should work well for our problem. Let me just implement it and see.

Let me also consider: the "inner" problem (solving the QP) might not need to be solved exactly. A few steps of projected gradient should suffice, since the MWA is robust to approximate solutions.

"""
Minimax-based optimizer for the step function peak minimization problem.
Uses multiplicative weights to balance the autocorrelation peaks,
combined with L-BFGS smoothing and Newton active-set refinement.
"""

import numpy as np
import time
from scipy.optimize import minimize

def _next_pow2(n):
    k = 1
    while k < n:
        k <<= 1
    return max(2, k)

def _full_convolve(a, b):
    n, m = len(a), len(b)
    out_n = n + m - 1
    N = _next_pow2(out_n)
    fa = np.fft.rfft(a, N)
    fb = np.fft.rfft(b, N)
    r = np.fft.irfft(fa * fb, N)[:out_n]
    return r

def _score(a):
    n = len(a)
    s = float(a.sum())
    if s < 0.01:
        return np.inf
    c = _full_convolve(a, a)
    return float(2.0 * n * c.max() / (s * s))

def _softmax(z):
    z = z - np.max(z)
    e = np.exp(np.clip(z, -700, 700))
    s = e.sum()
    if s < 1e-300:
        return np.ones_like(z) / len(z)
    return e / s

def _proj_simplex(v):
    """Project v onto the probability simplex {x >= 0, sum(x) = 1}."""
    n = len(v)
    if n == 0:
        return v
    if np.all(v <= 0):
        return np.ones(n) / n
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.where(u * np.arange(1, n+1) > (cssv - 1))[0][-1]
    theta = (cssv[rho] - 1) / (rho + 1.0)
    return np.maximum(v - theta, 0)

def _hankel_matvec(p, a):
    """Compute H(p) @ a where H(p)[i,j] = p[i+j].
    This is a cross-correlation: result[i] = sum_j p[i+j] * a[j].
    """
    n = len(a)
    m = len(p)
    N = _next_pow2(2 * n + m)
    # We want result[i] = sum_{j=0}^{n-1} p[i+j] * a[j] for i = 0, ..., n-1
    # This is (flip(a) * p)[n-1 + i] where flip(a)[k] = a[n-1-k]
    a_rev = a[::-1]
    fa = np.fft.rfft(a_rev, N)
    fp = np.fft.rfft(p, N)
    r = np.fft.irfft(fa * fp, N)
    return r[n-1 : 2*n-1]

def _hankel_matvec_T(p, a):
    """Compute H(p)^T @ a where H(p)[i,j] = p[i+j].
    Since H is symmetric, this is the same as _hankel_matvec(p, a).
    """
    return _hankel_matvec(p, a)

def _minimize_hankel_qp(p, n, max_iter=200, lr_init=0.5):
    """Solve min a^T H(p) a s.t. a in simplex, using projected Nesterov gradient."""
    a = np.ones(n) / n
    a_nest = a.copy()
    t = 1.0
    best_a = a.copy()
    best_val = float(a @ _hankel_matvec(p, a))
    
    for it in range(max_iter):
        grad = 2.0 * _hankel_matvec(p, a_nest)
        t_new = (1.0 + np.sqrt(1.0 + 4.0 * t * t)) / 2.0
        lr = 2.0 / (t_new + 1.0)  # Nesterov step size
        a_new = a_nest - lr * grad
        a_new = _proj_simplex(a_new)
        a_nest = a_new + ((t / t_new) - 1.0) * (a_new - a)
        a = a_new
        
        val = float(a @ _hankel_matvec(p, a))
        if val < best_val:
            best_val = val
            best_a = a.copy()
    
    return best_a

def _mwa_optimize(a_init, deadline, n_outer=500, n_inner=100, eta_init=1.0):
    """Multiplicative Weights Algorithm for the min-max autocorrelation problem."""
    n = len(a_init)
    K = 2 * n - 1  # number of lags
    
    # Initialize p as uniform
    p = np.ones(K) / K
    
    a = a_init.copy()
    a = _proj_simplex(a)
    
    best_a = a.copy()
    best_score = _score(a)
    
    eta = eta_init
    
    for outer in range(n_outer):
        if time.monotonic() > deadline:
            break
        
        # Inner: solve the QP min a^T H(p) a s.t. a in simplex
        a_new = _minimize_hankel_qp(p, n, max_iter=n_inner)
        a = a_new
        
        # Compute autocorrelation
        c = _full_convolve(a, a)
        
        # Update p using multiplicative weights
        c_max = float(c.max())
        if c_max < 1e-30:
            break
        # p_k *= exp(-eta * c_k / c_max), then normalize
        log_p = np.log(p) - eta * c / c_max
        log_p -= log_p.max()
        p = np.exp(log_p)
        p /= p.sum()
        
        # Decay eta
        eta *= 0.999
        
        # Check score
        sc = _score(a)
        if sc < best_score:
            best_score = sc
            best_a = a.copy()
            if outer % 50 == 0:
                print(f"    MWA iter {outer}: score={best_score:.10f}")
    
    return best_a, best_score
