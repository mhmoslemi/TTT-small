```python
def mirror_descent_qp(a, p, n_iters, eta=None):
    """Solve min a^T Q a s.t. sum(a)=1, a>=0 using mirror descent."""
    n = len(a)
    a = a.copy()
    
    for t in range(n_iters):
        # Compute gradient: grad = 2*Q*a
        # (Qa)_i = sum_j p[i+j] * a[j] = crosscorr(p, a)[i]
        q_a = _hankel_matvec(p, a)  # FFT-based
        grad = 2 * q_a
        
        # Step size
        if eta is None:
            eta = 1.0 / (1.0 + t * 0.1)
        
        # Mirror descent update
        log_ratio = -eta * grad
        log_ratio = log_ratio - log_ratio.max()  # for numerical stability
        new_a = a * np.exp(log_ratio)
        s = new_a.sum()
        if s < 1e-300:
            new_a = a.copy()
        else:
            new_a = new_a / s
        
        # Accept or reject (using the objective value)
        obj_old = a @ q_a  # a^T Q a
        q_a_new = _hankel_matvec(p, new_a)
        obj_new = new_a @ q_a_new
        
        if obj_new < obj_old:
            a = new_a
        else:
            eta *= 0.5
    
    return a
```

But we also have the constraint sum(a) = 1. So the full system is:
H a = c * 1
1^T a = 1

This is a (n+1) x (n+1) system:
[H  1] [a]   [c*1]
[1^T  0] [c] = [1  ]

This is a bordered Hankel system. I'm not sure if GCD iteration applies directly. But we can solve it as:
From the first equation: H a = c * 1 => a = c * H^{-1} * 1 (if H is invertible).
Substituting into the second: c * 1^T H^{-1} * 1 = 1 => c = 1 / (1^T H^{-1} * 1).
Then: a = H^{-1} * 1 / (1^T H^{-1} * 1).

So we just need to compute H^{-1} * 1 (solve H x = 1) and then normalize.
