    # where (shifted a)_j = a_{k-j} for active k
    
    # Let me compute it directly using convolution:
    # grad_j = sum_k w_k * d c_k / d a_j
    # = sum_k w_k * [a_{k-j} * (2 if k≠2j else 1) * [0<=k-j<=n-1]]
    # = 2 * sum_k w_k * a_{k-j} * [0<=k-j<=n-1] - sum_k w_k * a_{k-j} * [k=2j] * [0<=k-j<=n-1]
    # = 2 * h_j - w_{2j} * a_j * [0<=2j<=2n-2]
    # where h_j = sum_k w_k * a_{k-j} * [0<=k-j<=n-1]
    
    # h is the cross-correlation of w and a (with w as the first argument):
    # h[j] = sum_k w[k] * a[k-j] for valid k-j
    # = np.correlate(w, a, 'full')[j + (len(a)-1)] ... 
    
    # Let me verify: np.correlate(w, a, 'full')
    # For w of length L1 and a of length L2:
    # result has length L1 + L2 - 1
    # result[k] = sum_i w[i] * a[i + k - (L1-1)] (for valid i)
    
    # Actually, np.correlate(a, v, 'full')[k] = sum_n a[n+k] * conj(v[n])
    # So np.correlate(w, a, 'full')[k] = sum_n w[n+k] * conj(a[n])
    
    # We want h[j] = sum_k w[k] * a[k-j]
    # Let m = k-j, so k = m+j:
    # h[j] = sum_m w[m+j] * a[m] (for valid m and m+j)
    # = np.correlate(w, a, 'full')[j] (if we use the right convention)
    
    # Let me just use FFT:
    # h = ifft(fft(a, N) * conj(fft(w, N))) gives circular cross-correlation
    # For linear, zero-pad to N >= n + len(w) - 1 >= n + 2n - 2 - 1 = 3n - 3
    
    # Actually, let me just compute it the simple way for correctness:
    a_rev = a[::-1]
    # h[j] = sum_k w[k] * a[k-j] = (w * a_rev)[j + n - 1] ... 
    # Actually: sum_k w[k] * a[k-j], let l = k-j, k = l+j
    # = sum_l w[l+j] * a[l]
    # This is the cross-correlation of w and a at lag j
    # = np.correlate(w, a, 'full')[j + (n-1)] ... 
    
    # I'll use the convolution with reversed w:
    # sum_l w[l+j] * a[l] = sum_l a[l] * w[l+j]
    # = (a * flip(w))[j + len(w) - 1 - ... ]
    
    # You know what, let me just use the approach from the previous code which I know works:
    # The previous code computes:
    # a_rev = a[::-1]
    # wc = _full_convolve(w, a_rev)
    # h = wc[n-1:2*n-1]
    
    # This gives h[j] = sum_k w[k] * a_rev[k-j+n-1] ... let me verify
    # _full_convolve(w, a_rev)[m] = sum_i w[i] * a_rev[m-i]
    # a_rev[x] = a[n-1-x]
    # So _full_convolve(w, a_rev)[m] = sum_i w[i] * a[n-1-m+i]
    # For m = n-1+j: = sum_i w[i] * a[n-1-(n-1+j)+i] = sum_i w[i] * a[i-j]
    # This is what we want: h[j] = sum_i w[i] * a[i-j] (for valid i-j)
    
    # Great, so the previous code's computation is correct.
    # The full gradient of sum_k w_k * c_k with respect to a is:
    # 2 * h - correction (for the k=2j diagonal terms)
    # But the previous code just uses 4*n*a*(h-W) which accounts for the softmax parameterization.
    
    # For the raw gradient (w.r.t. a directly):
    # d/da_j [sum_k w_k * c_k] = 2 * h[j] - w[2j]*a[j] (if 2j valid)
    # But since we're working in the softmax parameterization z, we use:
    # d/dz_j = (a_j * grad_a_j - a_j * sum_i a_i * grad_a_i) for the simplex constraint
    
    # The previous code's formula 4*n*a*(h-W) where W = dot(w,c) seems to be:
    # W is the "average" and h is the "local" gradient, so h-W is the centered version
    # The factor 4*n comes from the 2*n in the score and the 2 from the bilinear form
    
    # Let me just use the same formula as the previous code for consistency
    wc = _full_convolve(w, a_rev)
    h = wc[n-1:2*n-1]
    W = float(np.dot(w, c))
    return 4.0 * n * a * (h - W)

def _next_pow2(n):
    k = 1
    while k < n:

def _full_convolve(a, b):
    n, m = len(a), len(b)
    out_n = n + m - 1
    N = _next_pow2(out_n)
    fa = np.fft.rfft(a, N)
    fb = np.fft.rfft(b, N)
    r = np.fft.irfft(fa * fb, N)[:out_n]
    return r

def _resample(a, new_n):
    old_n = len(a)
    if old_n == new_n:
        return a.copy()
    x_old = np.linspace(0, 1, old_n)
    x_new = np.linspace(0, 1, new_n)
    a_new = np.interp(x_new, x_old, a)
    a_new = np.maximum(a_new, 0.0)
    s = a_new.sum()
    if s > 1e-15:
        a_new = a_new / s
    return a_new

Key insight: The previous code was pretty thorough. To beat it, I need to either:
1. Explore a different region of the landscape
2. Be more efficient in the same region

Let me think about approach 3. What about:
- **Alternating minimization**: Fix all but one element, optimize that element, move to the next
- **Mirror descent with entropic regularization**: This is what softmax parameterization + gradient descent already does
- **Stochastic subgradient**: Instead of using all active constraints, use a random subset

Actually, let me think about this problem from a different angle. The key issue is that we're trying to minimize the peak of the autocorrelation. This is a well-studied problem in signal processing.

One approach that's known to work well: **WFA (Weighted Fast Algorithm)** for peak fitting, adapted for non-negative signals. The idea is:
1. Initialize a
2. Compute the "residual" at each position: how much each peak exceeds a target
3. Update a to reduce the residual

Another approach: **Iterative projection onto the feasible set**. We want:
- a >= 0
- sum(a) = 1 (normalization)
- max_k c_k <= T (target)

We can alternately project onto {a >= 0, sum(a) = 1} and {max_k c_k <= T}, decreasing T over time.

The projection onto {max_k c_k <= T} is non-convex (since c_k is bilinear), so this isn't straightforward.

Let me try a different approach: **Use the parent more effectively by exploring the "manifold" of sequences that have similar convolution profiles**.

Actually, I think the most promising improvement is:
1. Use a better L-BFGS schedule with more iterations at small beta
2. Add a "simulated annealing" component where we occasionally increase beta
3. Try n=16384 more aggressively
4. Use a "two-scale" approach: optimize a coarse version, then refine

Let me also think about whether there's a structural insight I'm missing.

The score is 2n * max_k c_k / S^2. For a "good" sequence, we want:
- c_k to be as uniform as possible (all close to the average)
- The average of c_k is: sum_k c_k / (2n-1) = (sum_i a_i)^2 / (2n-1) = S^2 / (2n-1)
- So we want max_k c_k to be close to S^2/(2n-1)

"""
Targeted optimizer combining L-BFGS with cyclical annealing, peak-surgery
subgradient refinement, frequency-domain rephasing restarts, and multi-n
exploration to minimize 2*n*max(conv(a,a))/sum(a)^2 below 1.5027.

import numpy as np
import time
from scipy.optimize import minimize


def _next_pow2(n):
    k = 1
    while k < n:
        k <<= 1
    return max(2, k)


def _full_convolve(a, b):
    n, m = len(a), len(b)
    out_n = n + m - 1
    N = _next_pow2(out_n)
    fa = np.fft.rfft(a, N)
    fb = np.fft.rfft(b, N)
    r = np.fft.irfft(fa * fb, N)[:out_n]
    return r


def _score(a):
    n = len(a)
    s = float(a.sum())
    if s < 1e-15:
        return np.inf
    c = _full_convolve(a, a)
    return float(2.0 * n * c.max() / (s * s))


def _softmax(z):
    z = z - np.max(z)
    e = np.exp(np.clip(z, -700, 700))
    s = e.sum()
    if s < 1e-300:
        return np.ones_like(z) / len(z)
    return e / s


def _lse_val(z, beta, n):
    a = _softmax(z)
    c = _full_convolve(a, a)
    c_max = float(c.max())
    shifted = (c - c_max) / beta
    e = np.exp(np.clip(shifted, -700, 0))
    s = e.sum()
    if s < 1e-300 or not np.isfinite(s):
        return 2.0 * n * c_max
    return 2.0 * n * (c_max + beta * np.log(s))


def _lse_grad(z, beta, n):
    a = _softmax(z)
    c = _full_convolve(a, a)
    c_max = float(c.max())
    shifted = (c - c_max) / beta
    e = np.exp(np.clip(shifted, -700, 0))
    s = e.sum()
    if s < 1e-300 or not np.isfinite(s):
        w = np.zeros_like(c)
        w[int(np.argmax(c))] = 1.0
    else:
        w = e / s
    a_rev = a[::-1]
    wc = _full_convolve(w, a_rev)
    h = wc[n - 1:2 * n - 1]
    W = float(np.dot(w, c))
    return 4.0 * n * a * (h - W)


def _lbfgs_multi(a_init, deadline, min_remain=10.0):
    """L-BFGS with cyclical annealing: decreasing beta with occasional bumps."""
    n = len(a_init)
    c_cur = _full_convolve(a_init, a_init)
    max_c = float(c_cur.max())
    if max_c < 1e-15:
        return a_init

    c_sorted = np.sort(c_cur)[::-1]
    gap = c_sorted[0] - c_sorted[min(30, len(c_sorted) - 1)]
    if gap < max_c * 0.001:
        gap = max_c * 0.001
    base_beta = max(gap, max_c * 0.002)

    # Create a cyclical schedule: mostly decreasing, with occasional bumps
    n_stages = 20
    betas = []
    for i in range(n_stages):
        frac = i / max(1, n_stages - 1)
        b = base_beta * (1.0 - frac) ** 2.5
        # Cyclical bump: every 5 stages, slightly increase
        if i > 0 and i % 5 == 0 and frac < 0.7:
            b = betas[-1] * 1.2
        betas.append(max(b, base_beta * 0.0001))

    current_a = a_init.copy()
    current_sc = _score(current_a)
    z = np.log(np.maximum(current_a, 1e-30))
    z = z - z.mean()

    for i, beta in enumerate(betas):
        if time.monotonic() + min_remain > deadline:
            break
        remaining = deadline - min_remain - time.monotonic()
        if remaining < 3:
            break

        scale = max(1.0, n / 4096.0)
        est_per = 0.002 * scale
        max_iter = min(6000, max(30, int(remaining / (est_per * 10))))

        def _fn(z_):
            return _lse_val(z_, beta, n)

        def _gr(z_):
            return _lse_grad(z_, beta, n)

        try:
            result = minimize(
                _fn, z, jac=_gr, method='L-BFGS-B',
                options={'maxiter': max_iter, 'ftol': 1e-17,
                         'gtol': 1e-14, 'maxcor': 80, 'maxls': 50}
            )
            a_new = _softmax(result.x)
            sc_new = _score(a_new)
            if sc_new < current_sc - 1e-15:
                current_a = a_new
                current_sc = sc_new
                z = np.log(np.maximum(a_new, 1e-30))
                z = z - z.mean()
        except Exception:
            pass

    return current_a


def _peak_surgery(a_init, deadline, top_k=5, max_rounds=200):
    """Aggressively target the top-k worst convolution peaks."""
    n = len(a_init)
    a = a_init.copy()
    s = a.sum()
    a = a / s
    best_a = a.copy()
    best_sc = _score(a)
    stall = 0
    max_stall = 60

    for rnd in range(max_rounds):
        if time.monotonic() > deadline:
            break
        c = _full_convolve(a, a)
        c_max = float(c.max())
        sc = 2.0 * n * c_max
        if sc < best_sc - 1e-13:
            best_sc = sc
            best_a = a.copy()
            stall = 0
        else:
            stall += 1

        if stall >= max_stall:
            break

        # Select top-k peaks (cyclical: vary k)
        k_eff = min(top_k + (rnd % 3), len(c))
        top_idx = np.argsort(c)[::-1][:k_eff]

        # Build weighted subgradient for these peaks
        w = np.zeros_like(c)
        for idx in top_idx:
            w[idx] = c[idx] / float(np.sum(c[top_idx]))

        a_rev = a[::-1]
        wc = _full_convolve(w, a_rev)
        h = wc[n - 1:2 * n - 1]
        grad = 2.0 * h
        grad = grad - np.mean(grad)

        gnorm = np.linalg.norm(grad)
        if gnorm < 1e-16:
            break

        # Backtracking line search with more aggressive initial step
        alpha = min(0.1, 2.0 / (gnorm + 1e-15))
        improved = False
        for _ in range(50):
            a_try = a - alpha * grad
            a_try = np.maximum(a_try, 0.0)
            s_try = a_try.sum()
            if s_try < 1e-15:
                alpha *= 0.5
                continue
            a_try = a_try / s_try
            c_try = _full_convolve(a_try, a_try)
            sc_try = 2.0 * n * float(c_try.max())
            if sc_try < sc - 1e-14:
                a = a_try
                improved = True
                break
            alpha *= 0.4

        if not improved:
            # Try small random kick
            if stall > 10:
                sigma = 0.005 * (stall / max_stall)
                perturb = sigma * np.random.randn(n) * a
                a_try = a + perturb
                a_try = np.maximum(a_try, 0.0)
                s_try = a_try.sum()
                if s_try > 1e-15:
                    a_try = a_try / s_try
                    sc_try = _score(a_try)
                    if sc_try < best_sc:
                        a = a_try
                        best_sc = sc_try
                        best_a = a.copy()
                        stall = 0

    return best_a, best_sc


def _rephase_restart(a_base, rng, n_modes=8):
    """Create a new sequence by rephasing the FFT and clipping negatives."""
    n = len(a_base)
    A = np.fft.rfft(a_base)
    mag = np.abs(A)
    # Random new phases
    phases = rng.uniform(0, 2 * np.pi, size=mag.shape)
    # Keep some structure: blend original and random phases
    blend = 0.3
    new_A = mag * (blend * np.exp(1j * np.angle(A)) +
                   (1 - blend) * np.exp(1j * phases))
    a_new = np.fft.irfft(new_A, n)
    a_new = np.maximum(a_new, 0.0)
    # Also try: use magnitude only (zero phase)
    a_zero = np.fft.irfft(mag, n)
    a_zero = np.maximum(a_zero, 0.0)
    s1 = a_new.sum()
    s2 = a_zero.sum()
    if s1 > 1e-10 and s2 > 1e-10:
        # Pick the one with better initial score
        sc1 = 2.0 * n * float(_full_convolve(a_new, a_new).max()) / (s1 * s1)
        sc2 = 2.0 * n * float(_full_convolve(a_zero, a_zero).max()) / (s2 * s2)
        if sc1 < sc2:
            return a_new / s1
        else:
            return a_zero / s2
    elif s1 > 1e-10:
        return a_new / s1
    elif s2 > 1e-10:
        return a_zero / s2
    # Fallback: perturbation
    z = np.log(np.maximum(a_base, 1e-30)) + 0.1 * rng.standard_normal(n)
    z = z - z.mean()
    return _softmax(z)


def _resample(a, new_n):
    old_n = len(a)
    if old_n == new_n:
        return a.copy()
    x_old = np.linspace(0, 1, old_n)
    x_new = np.linspace(0, 1, new_n)
    a_new = np.interp(x_new, x_old, a)
    a_new = np.maximum(a_new, 0.0)
    s = a_new.sum()
    if s > 1e-15:
        a_new = a_new / s
    return a_new


def _perturb(a, sigma, rng):
    n = len(a)
    z = np.log(np.maximum(a, 1e-30))
    z = z + sigma * rng.standard_normal(n)
    z = z - z.mean()
    return _softmax(z)


def _variance_penalty_optimize(a_init, deadline, n_iter=2000):
    """Optimize with a combined max + variance penalty on convolution."""
    n = len(a_init)
    a = a_init.copy()
    a = a / a.sum()
    best_a = a.copy()
    best_sc = _score(a)

    lr = 0.01
    for it in range(n_iter):
        if time.monotonic() > deadline:
            break
        c = _full_convolve(a, a)
        c_max = float(c.max())
        c_mean = float(c.mean())
        sc = 2.0 * n * c_max

        if sc < best_sc - 1e-13:
            best_sc = sc
            best_a = a.copy()

        # Weight: exponential emphasis on peaks + variance term
        beta = c_max * 0.01
        shifted = (c - c_max) / beta
        w_exp = np.exp(np.clip(shifted, -700, 0))
        w_exp = w_exp / w_exp.sum()

        # Add variance emphasis: weight proportional to (c - c_mean)^2
        var_w = (c - c_mean) ** 2
        var_w = var_w / (var_w.sum() + 1e-30)

        w = 0.7 * w_exp + 0.3 * var_w

        a_rev = a[::-1]
        wc = _full_convolve(w, a_rev)
        h = wc[n - 1:2 * n - 1]
        grad = 2.0 * h
        grad = grad - np.mean(grad)

        if sc_opt < best_score:
            best_seq = a_opt.copy()
            best_score = sc_opt
            print(f"  BEST: {best_score:.10f} (n={n_best}) [pert_{label}] t={time.monotonic()-t_start:.1f}s")

    # === Phase 7: Final ultra-fine L-BFGS + surgery (remaining time) ===
    print(f"\n[P7] Final polish (t={time.monotonic()-t_start:.1f}s)")
    remaining = deadline - time.monotonic()
    if remaining > 15:
        a_fin = _lbfgs_multi(best_seq, deadline - 3, min_remain=0)
        sc_fin = _score(a_fin)
        if sc_fin < best_score:
            best_seq = a_fin.copy()
            best_score = sc_fin
            print(f"  BEST: {best_score:.10f} [final_lbfgs] t={time.monotonic()-t_start:.1f}s")

    # Final peak surgery with remaining time
    if time.monotonic() < deadline - 2:
        a_fin2, sc_fin2 = _peak_surgery(best_seq, deadline - 1, top_k=3, max_rounds=100)
        if sc_fin2 < best_score:
            best_seq = a_fin2.copy()
            best_score = sc_fin2
            print(f"  BEST: {best_score:.10f} [final_surgery] t={time.monotonic()-t_start:.1f}s")

    # Final validation
    print(f"\n{'='*60}")
    if best_seq is not None:
        final = np.clip(best_seq, 0.0, 1000.0)
        s = float(final.sum())
        if s < 0.01:
            final = np.ones(256)
        sc_final = _score(final)
        print(f"FINAL: score={sc_final:.10f}, n={len(final)}, time={time.monotonic()-t_start:.1f}s")
        return [float(x) for x in final]

    fallback = np.ones(256)
    print(f"FALLBACK: score={_score(fallback):.10f}")
    return [float(x) for x in fallback]
