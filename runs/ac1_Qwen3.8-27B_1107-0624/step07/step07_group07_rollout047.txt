OK let me try to think about what kind of sequence would minimize the max of the full convolution.

The key realization is: for a symmetric sequence (a_j = a_{n-1-j}), the convolution is also symmetric, and the center is at m = n-1. For such sequences, the center value is sum_j a_j * a_{n-1-j} = sum_j a_j^2 (by symmetry). And by the same Cauchy-Schwarz argument applied to the "half" convolution, the center should be the max for symmetric non-negative sequences.

Wait, that's not quite right. Let me think again.

For a symmetric sequence, (a*a)[n-1] = sum_j a_j * a[n-1-j] = sum_j a_j^2.

And (a*a)[n-1+k] for k > 0: this involves summing a_{n-1+k-i} * a_i over valid i. Let's substitute j = n-1-i, so i = n-1-j:
(a*a)[n-1+k] = sum_j a_{k+j} * a_j (summing over valid j where both 0 <= j < n and 0 <= k+j < n, i.e., 0 <= j < n-k).

So (a*a)[n-1+k] = sum_{j=0}^{n-k-1} a_j * a_{j+k}.

And (a*a)[n-1] = sum_{j=0}^{n-1} a_j^2.

Now, by Cauchy-Schwarz: (a*a)[n-1+k] = sum_{j=0}^{n-k-1} a_j * a_{j+k} <= sqrt(sum_{j=0}^{n-k-1} a_j^2) * sqrt(sum_{j=0}^{n-k-1} a_{j+k}^2) <= sum_{j=0}^{n-k-1} a_j^2 <= sum_{j=0}^{n-1} a_j^2 = (a*a)[n-1].

So for SYMMETRIC non-negative sequences, the center IS the maximum! And the score is 2n * sum(a^2) / (sum a)^2 >= 2.

For ASYMMETRIC sequences, the maximum can be off-center, and potentially the center can be made smaller while keeping the off-center values also small.

So the key insight is: **use asymmetric sequences** where the convolution peaks are off-center and can be made smaller than sum(a^2).
