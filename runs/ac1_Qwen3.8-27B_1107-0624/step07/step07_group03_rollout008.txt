Actually, let me think about this differently. The problem is:
- Minimize `max(c)` subject to `sum(a) = 1, a >= 0`
- where `c = a * a` (full convolution)

This is a non-convex problem in general, but if we fix the active set S (indices where c[k] = max), then we want to minimize the average of c[k] for k in S, which IS convex (it's a quadratic form).

So the algorithm should be:
1. Identify active set S
2. Solve: minimize (1/|S|) * sum_{k in S} c[k] subject to sum(a)=1, a>=0
3. Check if the solution has c[k] <= max for all k not in S
4. If not, update S and repeat

Step 2 is a convex quadratic program! We can solve it with scipy or even directly.

The objective is: `(1/|S|) * sum_{k in S} sum_i sum_j a[i] a[j] * 1[i+j=k]`
= `(1/|S|) * sum_{(i,j): i+j in S} a[i] a[j]`

This is `a^T Q a / |S|` where `Q[i,j] = 1/|S|` if `i+j in S`, else 0.

So we're minimizing `a^T Q a` subject to `sum(a) = 1, a >= 0`.

This can be solved with scipy.optimize.minimize (SLSQP or trust-constr) or even projected gradient methods.

But wait - the Q matrix is n x n which for n=8192 would be 8192^2 = 67M elements. That's about 536MB for float64. Might be too much.

However, we only need to compute `Q @ a` for the gradient, which can be done via FFT!

`Q @ a` at index i = `(1/|S|) * sum_j Q[i,j] * a[j] = (1/|S|) * sum_{j: i+j in S} a[j]`

Let `S_vec` be the indicator vector of the active set (length 2n-1). Then:
`(Q @ a)[i] = (1/|S|) * sum_{j: i+j in S} a[j] = (1/|S|) * (a_rev * S_vec)[i + n - 1]`

where `a_rev = a[::-1]` and `*` denotes convolution. This can be computed via FFT!

So the gradient of `a^T Q a` is `2 * Q @ a`, and we can compute it efficiently.

The Hessian is `2 * Q`, and Hessian-vector products can also be computed via FFT.

This gives us a very efficient way to solve the subproblem! We can use L-BFGS-B or conjugate gradient on the Logistics.
