`F(a) = (2 * n * ||a * a||_\infty) / (a·1)²`

We model conformal optimization via the coordinates:

The active set `𝒮` is defined as:
`𝒮 = { i | (aₖᶻₖ) for certain k reaches a relative maximum }`

`active[i] = (|z[i]| >= (μ + η * max(|z[a]|)))`

   The `next_pow2` function refers to FFT padded lengths ensuring reals-mod-consistency.

</Section3>

<Section4>
Search Choices and Variations

The following indexed variations are systematically treated as separate dimensions:

1. `keep_permutations[0]` : Uniform selection with length growth 
2. `keep_permutations[1]` : Sinewave perturbation📈
3. `keep_permutations[2]` : Cosine-normal with frequency jittering
4. `keep_permutations[3]` : Bounded wave cleanup
5. `keep_permutations[4]` : Overparameterized mixed approach fallback

Each variation `i` in `[1,5]` is assigned a `priority[i]` and starting temperature `T[i]` defined programmatically.

The central optimization has a handover at `score=best_obj` which is evaluated with `np.inf` truncation.

Failure conditions are met by switching to an `allow-gradient-override` strategy.

</Section4>

<Section5>
Computational Budget and Robustness

FFTProfiler dominates the cost with `O(n log n)` complexity. Budget calculation must include:

- Initial safe time: `budget * 0.3` allows parameter exploration
- `budget * 0.5`   for iterations
- `budget * 0.2`   for fallback

To manage analytical complexity, we use candidate length `n_i = 2048` to `8192` (powers of two only).
