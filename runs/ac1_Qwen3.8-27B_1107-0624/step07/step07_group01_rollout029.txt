An alternative smoothing: use a **power mean** instead of log-sum-exp:
$\|c\|_p = (\sum c[m]^p)^{1/p}$ for large $p$.

As $p \to \infty$, this approaches $\max(c)$. For finite $p$, it's smooth and well-behaved.

The gradient of $\|c\|_p$ with respect to $f[i]$ is:
$\frac{\partial \|c\|_p}{\partial f[i]} = \frac{1}{p} \|c\|_p^{1-p} \sum_m p c[m]^{p-1} \frac{\partial c[m]}{\partial f[i]} = \|c\|_p^{1-p} \sum_m c[m]^{p-1} \frac{\partial c[m]}{\partial f[i]}$

$= \|c\|_p^{1-p} \sum_m c[m]^{p-1} \cdot 2 f[m-i]$

        v -= v.mean()

        a_new = np.maximum(a_new, 0)

            stall = 0
            alpha = min(alpha * 1.02, 1.0)  # increase step size
        else:
            stall += 1
            alpha *= 0.95
        
        a = a_new

Now, let me think about the **frequency domain approach** more carefully.

**Frequency domain phase optimization:**

The idea is to directly optimize the phases $\theta_k$ of the DFT $F[k] = |F[k]| e^{i\theta_k}$ to minimize the peak of $c = IFFT(F^2)$.

At each iteration:
1. Compute $c = IFFT(F^2).real[:2n-1]$
2. Find the peak $m^* = \arg\max c$
3. Compute the "phase gradient": for each $k$, the derivative of $c[m^*]$ with respect to $\theta_k$ is:
   $\frac{\partial c[m^*]}{\partial \theta_k} = -2|F[k]|^2 \sin(2\theta_k + 2\pi k m^*/N)$
4. Update: $\theta_k \leftarrow \theta_k - \eta \frac{\partial c[m^*]}{\partial \theta_k}$
5. Reconstruct $f = IFFT(F).real[:n]$
6. Project: $f = \max(f, 0)$
7. Recompute $F = FFT(f, N)$
8. Normalize

The step 4-5 is a gradient descent on the phases, and step 6-7 is the projection.

But there's a subtlety: after the projection (step 6), the phases change in a non-trivial way. So the "phase gradient" computed in step 4 is only valid for the current $F$, and after the projection, we need to recompute everything.

This is essentially an alternating optimization:
- Update phases (frequency domain step)
- Update amplitudes (time domain projection)

It's similar to the Gerchberg-Saxton / Fienup algorithm for phase retrieval.
