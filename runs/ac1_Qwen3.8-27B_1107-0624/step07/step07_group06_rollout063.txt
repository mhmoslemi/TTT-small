   e. Update λ by gradient descent: λ <- λ - η * grad, projected to the simplex.
3. Return a* = x / (1^T x) (normalized) and t* = 1 / (2 * f(λ)).

The gradient descent step (e) is a projection onto the simplex, which can be done efficiently.

This is essentially the **multiplicative weight update** or **mirror descent** on the dual!
