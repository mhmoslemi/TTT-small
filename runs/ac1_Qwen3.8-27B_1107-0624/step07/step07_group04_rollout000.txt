    # Only work on free variables
    r = rhs.copy()  # residual
    r[~free_mask] = 0
    p = r.copy()

    if rs_old < 1e-30:

        # Actually, since p is zero on bound variables, Hp should be fine

        if abs(pHp) < 1e-30:

        x += alpha * p

Hmm, but there's a subtlety with the bound constraints. When I have variables at the bound (a_i = 0), I need to make sure the Newton step doesn't push them negative. The proper way to handle this is the active set method:

1. Solve the QP ignoring bounds (on the free set)
2. Check if any free variable would go negative
3. If so, add the most-violated variable to the bound set
4. Repeat

This is the "armijo" active set method. Let me implement it properly:

```python
def solve_qp_hankel(W, n, bound_set):
    """Solve min a^T H a s.t. sum(a) = 1, a_i = 0 for i in bound_set."""
    free = ~bound_set
    n_free = np.sum(free)
    if n_free == 0:
        a = np.zeros(n)
        a[0] = 1
        return a
    
    # Solve: H_ff * a_f = lambda * 1_f, sum(a_f) = 1
    # a_f = H_ff^{-1} 1_f / (1_f^T H_ff^{-1} 1_f)
    
    # First solve: H_ff * x = 1_f
    rhs = np.zeros(n)
    rhs[free] = 1.0
    x = cg_solve_H(rhs, W, n, free_mask=free)
    
    # Denominator: 1_f^T * x_f = sum(x[free])
    denom = np.sum(x[free])
    if abs(denom) < 1e-30:
        return np.ones(n_free) / n_free  # fallback
    
    a = x / denom
    a[bound_set] = 0
    return a
```

Wait, but CG is solving `H_full * x = rhs` where `H_full` is the full n×n matrix, but `rhs` is zero on the bound set. The solution `x` will generally be non-zero on the bound set too. I need to be more careful.

The proper approach is:
- The KKT conditions on the free set are: `H_ff a_f + H_fb * 0 = lambda * 1_f`
- So I need to solve `H_ff a_f = lambda * 1_f`

But I don't have explicit access to `H_ff`. I only have the full `H` via the matvec.

One approach: use CG to solve `H x = 1` (full system), then use `x_f = x[free]` as an approximation. But this isn't exact because `H_ff` is a submatrix, not the full `H`.

A better approach: use a "Galerkin" projection. Define the matvec on the free subspace:
`matvec_free(v_f) = H_ff * v_f = (H * v_full)[free]` where `v_full` has `v_full[free] = v_f` and `v_full[bound] = 0`.

Then solve `H_ff a_f = 1_f` using CG with this restricted matvec.

```python
def cg_on_free(rhs_f, W, n, free, max_iter=200, tol=1e-10):
    """Solve H_ff * x = rhs_f using CG with restricted matvec."""
    x_f = np.zeros_like(rhs_f)
    r_f = rhs_f.copy()
    p_f = r_f.copy()
    rs = np.dot(r_f, r_f)
    rs0 = rs
    if rs0 < 1e-30:
        return x_f
    
    for i in range(max_iter):
        # Compute H_ff * p_f
        p_full = np.zeros(n)
        p_full[free] = p_f
        Hp_full = hankel_matvec(p_full, W, n)
        Hp_f = Hp_full[free]
        
        pHp = np.dot(p_f, Hp_f)
        if abs(pHp) < 1e-30:
            break
        
        alpha = rs / pHp
        x_f += alpha * p_f
        r_f -= alpha * Hp_f
        
        rs_new = np.dot(r_f, r_f)
        if not np.isfinite(rs_new) or rs_new > rs * 1.01:
            break
        
        beta = rs_new / rs
        p_f = beta * p_f + r_f
        rs = rs_new
        
        if np.sqrt(rs) < tol * np.sqrt(rs0):
            break
    
    return x_f
```

This is O(n log n) per CG iteration, and typically converges in O(sqrt(κ)) iterations where κ is the condition number. For well-conditioned Hankel matrices, this should be fast.

            break

            # Actually, we need to map back to the original index
            free_indices = np.where(free)[0]
            worst = free_indices[idx]
            bound[worst] = True
            a = a_qp
            a[bound] = 0
            a /= a.sum()
            continue
    
    return a
