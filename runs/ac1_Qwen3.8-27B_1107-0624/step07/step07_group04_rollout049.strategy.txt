## Mathematical Specification

Assume representing sequence coefficients as `a = [a₁, a₂, ..., aₙ]` with:
- `∑ aᵢ = s ≥ 0.01` (defensive sum condition)
- `aᵢ ≥ 0` (non-negative)

Define:
- **Transformation**: Normalize to unit 'exponential scale' (`log(∑ exp(λ(x))) / λ` structure)
- **Objective**: Minimize `F(a) = (2 * n * max(convolve(a, a))) / (s)²`
- **Surrogate**: Smooth approximation `F_smooth(a) = 2 * n * log_sum_exp(α * convolve(a, a))`

This maintains the problem structure while adding optimized gradients.

    # Initialize L-BFGS
    best_score = np.inf

    initial_seq = np.log(np.array(seq))
    initial_a = np.exp(initial_seq)
    n_val = initial_a.sum()
    
    # Smoothed convolution normalization factors
    scaled_conv = np.convolve(initial_a, initial_a, mode='full')
    conv_max = scaled_conv.max()
    
    tol = 1e-12
    if conv_max < tol:
        # Degenerate case; return uniform
        return np.ones(n) / n
    
    scaled_beta = 0.05  # Example parameter
    
    # Smooth optimization objective
    def smooth_smoobj(z, beta, dimension):
        a = np.exp(z)
        a_sum = a.sum()
        if a_sum < 0.01:
            # If sum too low, prop up s
            return np.inf
        convolve_result = np.convolve(a, a, mode='full')
        conv_max = convolve_result.max()
        # Score shift
        shifted = (convolve_result - conv_max)
        # Smoothed max
        smooth_max = np.log(np.sum(np.exp(beta * shifted)))
        score = 2.0 * dimension * (conv_max + smooth_max) / (a_sum ** 2)
        return score
    
    # Run L-BFGS on the log-scale space
    try:
        result = minimize(smooth_smoobj, initial_seq, method='L-BFGS-B', 
                          bounds=(-5, 5), options={'maxiter': 3000})
        final_seq = np.exp(result.x)
        final_score = evaluate_sequence(final_seq.tolist())
        return final_seq, final_score
    except:
        # Fallback to quartet profile
        return None, best_score

def trial_n(sequence, n):
    if n > 65536 or n < 0.5 * sequence.length:
