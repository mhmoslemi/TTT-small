The minimum can be found by:
1. Identifying the "active" k values (those achieving the max at the current t)
2. Solving the 1D problem on the active set
3. Checking if the solution is valid (the active set is correct)
4. If not, updating the active set and repeating

For a simple implementation, I can use the following:
- Start with t = a[i]
- Compute g(t) = max(k affected) [c^(-i)[k] + f_k(t)]
- The subgradient at t is: the f'_k(t) of an active k
  - If the quadratic is active: subgrad = 2t
  - If an affine at k* is active: subgrad = 2*a[k*-i]
  - If multiple are tied: convex hull of their subgradients

If 0 is in the subgradient, we're at the optimum.
Otherwise, use bisection on the subgradient to find the optimum.

But computing the subgradient requires knowing the active set, which requires evaluating g(t). This is O(n) per evaluation (over the affected k values).

For a full coordinate descent pass: n coordinates * O(n) per coordinate = O(n^2) = 67M for n=8192. This is feasible.

But I also need to compute c^(-i) for each i, which is O(n log n) per FFT. So the total is n * O(n log n) = O(n^2 log n) ≈ 8.7 * 10^8 for n=8192. This might be too slow.

Optimization: Instead of computing c^(-i) from scratch for each i, I can use the relation:
c^(-i)[k] = c[k] - (contribution of a[i] to c[k])

Where c = conv(a,a) is computed once. So:
c^(-i)[k] = c[k] - a[i]*(2*a[k-i] if k != 2i else a[i])

Then: conv(a_new, a_new)[k] = c^(-i)[k] + a_new[i]*(2*a[k-i] if k != 2i else a_new[i])
= c[k] - a[i]*(2*a[k-i] or a[i]) + a_new[i]*(2*a[k-i] or a_new[i])

For k != 2i: = c[k] + (a_new[i] - a[i]) * 2*a[k-i]
For k = 2i: = c[k] - a[i]^2 + a_new[i]^2

So I can compute the new c[K] for affected k from the old c[K] in O(1) per k!

This means: for each coordinate i, I can evaluate the objective in O(n) time (over affected k), and a full pass is O(n^2). No FFT needed!

For n=8192: O(n^2) = 67M operations per pass. In Python with numpy, this is maybe 1-2 seconds per pass. We can do 50-100 passes in the time budget.

"""
Optimizer for minimizing 2*n*max(conv(a,a))/sum(a)^2.
Key innovation: Fast Gauss-Seidel coordinate descent exploiting self-convolution
structure (O(n^2) per pass), combined with multi-n L-BFGS and structured restarts.
"""
import numpy as np
import time
from scipy.optimize import minimize


def _next_pow2(n):
    k = 1
    while k < n:
        k <<= 1
    return max(2, k)


def _full_convolve(a, b):
    n, m = len(a), len(b)
    out_n = n + m - 1
    N = _next_pow2(out_n)
    fa = np.fft.rfft(a, N)
    fb = np.fft.rfft(b, N)
    r = np.fft.irfft(fa * fb, N)[:out_n]
    return r


def _score(a):
    n = len(a)
    s = float(a.sum())
    if s < 1e-15:
        return np.inf
    c = _full_convolve(a, a)
    return float(2.0 * n * c.max() / (s * s))


def _softmax(z):
    z = z - np.max(z)
    e = np.exp(np.clip(z, -700, 700))
    s = e.sum()
    if s < 1e-300:
        return np.ones_like(z) / len(z)
    return e / s


def _lsobj(z, beta, n):
    a = _softmax(z)
    c = _full_convolve(a, a)
    c_max = float(c.max())
    shifted = (c - c_max) / beta
    e = np.exp(np.clip(shifted, -700, 0))
    s = e.sum()
    if s < 1e-300 or not np.isfinite(s):
        return 2.0 * n * c_max
    return 2.0 * n * (c_max + beta * np.log(s))


def _lsgrad(z, beta, n):
    a = _softmax(z)
    c = _full_convolve(a, a)
    c_max = float(c.max())
    shifted = (c - c_max) / beta
    e = np.exp(np.clip(shifted, -700, 0))
    s = e.sum()
    if s < 1e-300 or not np.isfinite(s):
        w = np.zeros_like(c)
        w[int(np.argmax(c))] = 1.0
    else:
        w = e / s
    a_rev = a[::-1]
    wc = _full_convolve(w, a_rev)
    h = wc[n - 1:2 * n - 1]
    W = float(np.dot(w, c))
    return 4.0 * n * a * (h - W)


def _run_lbfgs(a_init, deadline, min_time_remaining=30.0):

    current_a = a_init.copy()

def _make_lsobj_wrapper(beta, n):

def _coord_descent(a, deadline, max_passes=200, recompute_every=5):
    """Gauss-Seidel coordinate descent for min max(conv(a,a))/sum(a)^2."""
    n = len(a)
    a = a.copy()
    s = a.sum()
    if s < 1e-15:
        return a, np.inf
    a = a / s
    c = _full_convolve(a, a)
    best_sc = _score(a)
    best_a = a.copy()
    c_buf = np.empty(2 * n - 1, dtype=np.float64)

    for pass_num in range(max_passes):
        if time.monotonic() > deadline:
            break

        for i in range(n):
            old_ai = a[i]
            if old_ai < 1e-18:
                continue

            k_lo = i
            k_hi = min(i + n - 1, 2 * n - 2)
            k_hi_i = k_hi - i
            a_ki = a[0:k_hi_i + 1]
            c_aff = c[k_lo:k_hi + 1]
            quad_pos = 2 * i - k_lo  # = i

            lo = 0.0
            hi = 2.0 * old_ai

            # Evaluate at boundaries and current
            def eval_t(t):
                np.multiply(2.0 * (t - old_ai), a_ki, out=c_buf[:len(a_ki)])
                c_buf[:len(c_aff)] = c_aff + c_buf[:len(c_aff)]
                if 0 <= quad_pos < len(c_buf):
                    c_buf[quad_pos] = c[k_lo + quad_pos] - old_ai * old_ai + t * t
                denom = (1.0 + t - old_ai)
                denom = denom * denom
                if denom < 1e-30:
                    return 1e30
                return c_buf[:len(c_aff)].max() / denom

            f_cur = eval_t(old_ai)
            f_lo = eval_t(lo)
            if f_lo <= f_cur:
                best_t = lo
            else:
                f_hi = eval_t(hi)
                if f_hi <= f_cur:
                    best_t = hi
                else:
                    # Golden section search
                    gr = (np.sqrt(5.0) - 1.0) / 2.0
                    t1 = hi - gr * (hi - lo)
                    t2 = lo + gr * (hi - lo)
                    f1 = eval_t(t1)
                    f2 = eval_t(t2)
                    for _ in range(20):
                        if f1 < f2:
                            hi = t2
                            t2 = t1
                            f2 = f1
                            t1 = hi - gr * (hi - lo)
                            f1 = eval_t(t1)
                        else:
                            lo = t1
                            t1 = t2
                            f1 = f2
                            t2 = lo + gr * (hi - lo)
                            f2 = eval_t(t2)
                    best_t = (lo + hi) / 2.0

            if abs(best_t - old_ai) > 1e-16:
                # Update c in place
                for k in range(k_lo, k_hi + 1):
                    if k == 2 * i:
                        c[k] = c[k] - old_ai * old_ai + best_t * best_t
                    else:
                        c[k] = c[k] + (best_t - old_ai) * 2.0 * a[k - i]
                a[i] = best_t

        # Recompute c periodically to avoid drift
        if (pass_num + 1) % recompute_every == 0:
            s = a.sum()
            if s < 1e-15:
                break
            a = a / s
            c = _full_convolve(a, a)
            sc = _score(a)
            if sc < best_sc - 1e-13:
                best_sc = sc
                best_a = a.copy()

    # Final check
    s = a.sum()
    if s > 1e-15:
        a = a / s
        sc = _score(a)
        if sc < best_sc:
            best_sc = sc
            best_a = a.copy()

    return best_a, best_sc
