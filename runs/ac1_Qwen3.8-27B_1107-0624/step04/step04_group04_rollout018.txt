    Uses projected gradient with backtracking line search.
    """
    a = np.ones(n) / n  # initial guess

    for it in range(max_iter):
        # Compute gradient: 2 * H @ a
        Ha = _hankel_mv(lam, a)  # O(n log n) via FFT
        grad = 2.0 * Ha
        
        # Project gradient onto {sum(d) = 0}
        grad = grad - grad.mean()
        
        # Line search

        obj_current = _hankel_quad(lam, a)

            a_new = np.maximum(a_new, 0)

            obj_new = _hankel_quad(lam, a_new)
            if obj_new < obj_current:
                break
            step *= 0.5
        
        if np.linalg.norm(a_new - a) < tol:
            break
        a = a_new
    
    return a

The active set method for this QP:
1. Identify the set `F = {i : a[i] > 0}` (free variables).
2. Solve the unconstrained QP on `F`: `H_FF a_F = -mu/2 * 1_F`, `sum_F a = 1`.
3. Check if any `a[i] < 0` for `i in F`. If so, remove the most negative from `F` and repeat.
4. Check KKT conditions for variables not in `F`: `2 (H a)[i] - mu >= 0`. If violated, add the most violated to `F`.
