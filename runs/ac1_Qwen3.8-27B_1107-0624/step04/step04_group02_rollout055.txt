"""
LP-based alternating optimization for minimizing 2*n*max(conv(a,a))/sum(a)^2.
Combines LP projection (from state-of-the-art approach), L-BFGS with logsumexp,
active-set subgradient method, and local search.

import numpy as np
from scipy.optimize import minimize, linprog
import time

def _next_pow2(n):
    k = 1
    while k < n:
        k <<= 1
    return max(2, k)

def _full_convolve(a, b):
    n, m = len(a), len(b)
    out_n = n + m - 1
    N = _next_pow2(out_n)
    fa = np.fft.rfft(a, N)
    fb = np.fft.rfft(b, N)
    r = np.fft.irfft(fa * fb, N)[:out_n]
    return r

def _softmax_fn(z):
    z = np.asarray(z, dtype=np.float64)
    z = z - np.max(z)
    e = np.exp(z)
    s = e.sum()
    if s < 1e-300 or not np.isfinite(s):
        return np.ones_like(z) / len(z)
    return e / s

def _score_norm_fn(a):
    n = len(a)
    c = _full_convolve(a, a)
    return float(2.0 * n * c.max())

def _score_fn(a):
    n = len(a)
    s = float(a.sum())
    if s < 1e-15:
        return np.inf
    c = _full_convolve(a, a)
    return float(2.0 * n * c.max() / (s * s))

def _convolve_matrix(a):
    """Build the (2n-1) x n convolution matrix T such that T @ b = conv(a, b)."""
    n = len(a)
    T = np.zeros((2*n-1, n))
    for k in range(2*n-1):
        lo = max(0, k - n + 1)
        hi = min(n-1, k)
        for j in range(lo, hi+1):
            T[k, j] = a[k - j]
    return T

The key is that the perturbation [1+ε, 1+ε, 1-2ε] makes the convolution peak (at the center) decrease from 3 to 3-3ε², while keeping the sum the same. This gives a lower objective.

Let me redo the KKT analysis. The objective is `f(a) = 2n * M / S^2` where M = max(C) and C = conv(a,a).

Wait, that's not right either. Let me be very careful.

The condition `0≤(n-1)-i≤n-1` is `0≤i≤n-1`, so all i from 0 to n-1 are valid.

`conv[n-1] = sum_{i=0}^{n-1} a[i] * a[n-1-i]`

Now, `d/d(a_j) of conv[n-1]`:
- The term where i=j: derivative of `a[j]*a[n-1-j]` w.r.t. a_j is `a[n-1-j]`
- The term where i=n-1-j (i.e., j = n-1-i): derivative of `a[n-1-j]*a[j]` w.r.t. a_j is `a[n-1-j]`

Wait no, if j ≠ n-1-j, then both terms appear separately in the sum, and each contributes `a[n-1-j]`. So the total derivative is `2*a[n-1-j]`? No wait...

- If I set i = j: the term is a[j] * a[n-1-j]. Derivative w.r.t. a_j is a[n-1-j].
- If I set i = n-1-j: the term is a[n-1-j] * a[j]. Derivative w.r.t. a_j is a[n-1-j].
- These are the same term if j = n-1-j, i.e., 2j = n-1.

So for j ≠ (n-1)/2: derivative = 2 * a[n-1-j]
For j = (n-1)/2 (n odd): derivative = 2 * a[j]

Wait, I'm double-counting. The sum `sum_i a[i] * a[n-1-i]` for i and n-1-i being different indices gives two terms that are the same (a[i]*a[n-1-i] = a[n-1-i]*a[i]). But in the sum, they appear as separate terms (one at index i and one at index n-1-i).

So the sum has n terms (i=0 to n-1). When differentiating w.r.t. a_j:
- Term i=j: a[j]*a[n-1-j], derivative = a[n-1-j]
- Term i=n-1-j: a[n-1-j]*a[j], derivative = a[n-1-j]
- All other terms: derivative = 0 (they don't involve a_j)
- Exception: if j = n-1-j, these are the same term, and derivative = 2a[j]

So for j ≠ n-1-j: `d(conv[n-1])/d(a_j) = 2*a[n-1-j]`
For j = n-1-j (n odd, j = (n-1)/2): `d(conv[n-1])/d(a_j) = 2*a[j]`

In all cases: `d(conv[n-1])/d(a_j) = 2*a[n-1-j]`

So the KKT condition `∇M_j = 2M/S` becomes:
`2*a[n-1-j] = 2M/S`
`a[n-1-j] = M/S`
`a[j] = M/S` (replacing j with n-1-j)

This means all a_j are equal to M/S, which gives the constant sequence. But we showed the constant sequence is NOT optimal!

The resolution: at the optimum, the max might NOT be unique. If multiple lags achieve the max, the subdifferential is the convex hull of the individual gradients, and the KKT condition becomes:
`0 ∈ conv{∇C[k]/S² - 2MC[k]∇S/S³ : C[k] = M}`

This allows for non-constant solutions where the max is achieved at multiple lags.

This is a crucial insight! The optimal solution likely has the convolution peak achieved at multiple lags (a "flat top"), and the KKT conditions involve an average of the gradients over the active set.

This is exactly what the "top-K" approach in the previous program is trying to do! By averaging the gradient over the top-K lags, it approximates the subdifferential of the max.

So the key to improving is:
1. Identify the correct active set (the set of lags where the convolution is at its maximum or very close)
2. Use the averaged gradient over this active set
3. Optimimize with this gradient

The previous program used a fixed K (top-K with K=3, 5, 8). A better approach might be to dynamically determine the active set based on how close each lag is to the maximum.

Let me now think about the LP approach again in this context.

The LP: max sum(b) s.t. b ≥ 0, conv(a,b)[k] ≤ M for all k.

The dual: min M * sum(y_k) s.t. sum_k y_k * T[k,j] ≥ 1 for all j, y_k ≥ 0.

The dual constraint `sum_k y_k * T[k,j] ≥ 1` means: for each j, the weighted sum of the convolution values (weighted by the dual variables) at lag k must be at least 1.

By strong duality, the optimal LP value equals the optimal dual value. The dual variables y_k are non-zero only for constraints that are binding at the primal optimum.

This is related to the active set idea: the dual variables identify which convolution constraints are tight, which is the active set.

So the LP approach naturally identifies the active set and uses it for the gradient! This is a theoretical advantage over the fixed top-K approach.

Let me now design the algorithm:

```
Algorithm: LP-Active-Set Optimization
1. Initialize a (normalized to sum=1)
2. Repeat:
   a. Compute C = conv(a, a), M = max(C)
   b. Solve LP: max sum(b) s.t. b ≥ 0, conv(a,b)[k] ≤ M for all k
   c. From the LP dual, identify the active set A = {k : y_k > 0}
   d. Compute the "active set gradient": g_j = (1/|A|) sum_{k in A} d(C[k])/d(a_j)
   e. Update a using gradient descent on the active-set objective
   f. Normalize a to sum=1
3. Return best a
```

Actually, the LP dual variables give us the weights for the active set, not just a uniform average. So the gradient should be:
`g_j = sum_k y_k * d(C[k])/d(a_j) / sum_k y_k`

This is a weighted average over the active set, with weights given by the dual variables.

"""
LP-active-set optimizer for minimizing 2*n*max(conv(a,a))/sum(a)^2.
Uses LP projection to identify active set, combined with L-BFGS and local search.
"""
import numpy as np
from scipy.optimize import minimize, linprog
from scipy.sparse import csr_matrix
import time

def _next_pow2(n):
    k = 1
    while k < n:
        k <<= 1
    return max(2, k)

def _full_convolve(a, b):
    n, m = len(a), len(b)
    out_n = n + m - 1
    N = _next_pow2(out_n)
    fa = np.fft.rfft(a, N)
    fb = np.fft.rfft(b, N)
    r = np.fft.irfft(fa * fb, N)[:out_n]
    return r

def _softmax_fn(z):
    z = np.asarray(z, dtype=np.float64)
    z = z - np.max(z)
    e = np.exp(z)
    s = e.sum()
    if s < 1e-300 or not np.isfinite(s):
        return np.ones_like(z) / len(z)
    return e / s

def _score_norm_fn(a):
    n = len(a)
    c = _full_convolve(a, a)
    return float(2.0 * n * c.max())

def _score_fn(a):
    n = len(a)
    s = float(a.sum())
    if s < 1e-15:
        return np.inf
    c = _full_convolve(a, a)
    return float(2.0 * n * c.max() / (s * s))

def _build_lp_matrices(a):
    """Build A_ub and b_ub for the LP: max sum(b) s.t. conv(a,b) <= M, b >= 0.
    The constraint is T @ b <= M * ones, where T is the convolution matrix.
    We encode non-negativity as -b <= 0.
    """
    n = len(a)
    # Build T as sparse matrix: T[k, j] = a[k-j] if 0 <= k-j <= n-1
    # T has shape (2n-1, n)
    # Column j: non-zeros at rows j, j+1, ..., j+n-1 (clipped to 0..2n-2)
    # Value at row (j+i), col j is a[i]
    
    rows = []
    cols = []
    data = []
    for j in range(n):
        for i in range(n):
            k = j + i
            if k < 2 * n - 1:
                rows.append(k)
                cols.append(j)
                data.append(a[i])
    
    T = csr_matrix((data, (rows, cols)), shape=(2*n-1, n))
    
    # Full constraint matrix: [T; -I] @ b <= [M*ones; 0]
    # A_ub = [T; -I] (shape (2n-1+n, n))
    # b_ub = [M*ones; 0]
    
    return T  # We'll handle the rest in the solve function

def _solve_lp(a, M, timeout=5.0):
    """Solve LP: max sum(b) s.t. conv(a,b) <= M, b >= 0.
    Returns b (optimal solution) and dual variables y.
    """
    n = len(a)
    # Build T: (2n-1) x n convolution matrix
    rows = np.repeat(np.arange(n), n)  # column index repeated
    # Actually, let me build it properly
    row_idx = []
    col_idx = []
    data = []
    for j in range(n):
        for i in range(n):
            k = j + i
            row_idx.append(k)
            col_idx.append(j)
            data.append(a[i])
    
    row_idx = np.array(row_idx)
    col_idx = np.array(col_idx)
    data = np.array(data)
    
    T = csr_matrix((data, (row_idx, col_idx)), shape=(2*n-1, n))
    
    # A_ub = [T; -I], b_ub = [M*ones; 0]
    from scipy.sparse import eye as sp_eye
    A_ub = T  # We'll handle non-negativity via bounds
    b_ub = np.full(2*n-1, M)
    
    # Objective: min -sum(b) (to maximize sum(b))
    c_obj = -np.ones(n)
    
    # Bounds: 0 <= b_j <= inf
    bounds = [(0, None)] * n
    
    res = linprog(c_obj, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')
    
    if res.status == 0:
        b_opt = res.x
        # Get dual variables from the inequality constraints (first 2n-1)
        y = -res.ineqlin.marginals[:2*n-1]  # dual variables for T@b <= M
        y = np.maximum(y, 0)  # ensure non-negative
        return b_opt, y
    else:
        return None, None

def _active_set_gradient(a, y_active, C):
    """Compute gradient using active set weights from LP dual.
    y_active: weights for each lag (from LP dual)
    C: convolution array
    Returns gradient of weighted sum of C values w.r.t. a.
    """
    n = len(a)
    # Normalize weights
    y_sum = y_active.sum()
    if y_sum < 1e-15:
        # Fallback: uniform over top values
        k = int(np.argmax(C))
        y_active = np.zeros_like(C)
        y_active[k] = 1.0
        y_sum = 1.0
    
    y_w = y_active / y_sum
    
    # Gradient: grad_j = sum_k y_w[k] * d(C[k])/d(a_j)
    # d(C[k])/d(a_j) = a[k-j] (if 0<=k-j<=n-1) + a[j-k] (if 0<=j-k<=n-1)
    # For efficiency, use the convolution structure:
    # grad = conv(y_w, a_reversed)[n-1:2n-1] + conv(y_w, a)[0:n]  (approximately)
    
    # Actually, let's use the direct formula:
    # grad_j = sum_k y_w[k] * (a[k-j] + a[j-k]) where indices are valid
    
    # This can be computed as:
    # term1_j = sum_k y_w[k] * a[k-j] = (conv(y_w, a_reversed))[n-1+j - (n-1)]
    # Let me just do it directly for clarity (O(n * |A|))
    
    # More efficient: use FFT
    # grad_j = sum_k y_w[k] * a[(k-j) mod nothing] ... 
    
    # Let's use the convolution interpretation:
    # sum_k y_w[k] * a[k-j] = (y_w * a_rev)[j] where a_rev is a reversed and we take the right part
    # Actually: sum_k y_w[k] * a[k-j] for valid k,j is the cross-correlation
    
    # Simplest: use the property that if we define f = y_w (padded to length 2n-1)
    # then sum_k f[k] * a[k-j] = (f * a)[j + something]
    
    # Let me just compute it with two convolutions:
    # Part 1: sum_k y_w[k] * a[k-j] for 0<=k-j<=n-1
    #         = sum_i a[i] * y_w[i+j] for 0<=i<=n-1 and 0<=i+j<=2n-2
    #         This is the (anti-)diagonal sum, which equals corr at lag j
    #         = (y_w_flip * a)[j + (2n-2) - (n-1)] ... I'm getting confused
    
    # Let me just do it the brute force way for the active set only
    active_idx = np.where(y_w > 1e-10)[0]
    grad = np.zeros(n)
    for k in active_idx:
        w = y_w[k]
        if w < 1e-15:
            continue
        # d(C[k])/d(a_j) for j = 0..n-1
        # = a[k-j] if 0<=k-j<=n-1, plus a[j-k] if 0<=j-k<=n-1
        lo1 = max(0, k - (n-1))
        hi1 = min(n-1, k)
        # For j in [lo1, hi1]: a[k-j]
        if lo1 <= hi1:
            grad[lo1:hi1+1] += w * a[k-hi1:k-lo1+1][::-1]
        lo2 = max(0, k)  # j-k >= 0 => j >= k
        hi2 = min(n-1, k + n - 1)  # j-k <= n-1 => j <= k+n-1
        # For j in [lo2, hi2]: a[j-k]
        if lo2 <= hi2:
            grad[lo2:hi2+1] += w * a[0:hi2-lo2+1]
    
    return grad

def _lp_iteration(a, deadline, n_iter=200):
    """Perform LP-based iterations to improve a."""
    n = len(a)
    a = a / a.sum()  # normalize
    best_a = a.copy()
    best_score = _score_norm_fn(a)
    
    for it in range(n_iter):
        if time.monotonic() > deadline - 2.0:
            break
        
        C = _full_convolve(a, a)
        M = float(C.max())
        
        # Solve LP
        b_opt, y_dual = _solve_lp(a, M)
        
        if b_opt is None:
            break
        
        # Rescale b to have same sum as a
        S = a.sum()
        b_scaled = b_opt * (S / b_opt.sum()) if b_opt.sum() > 1e-15 else a.copy()
        
        # Combine
        t = 0.3  # step size
        a_new = (1 - t) * a + t * b_scaled
        a_new = np.maximum(a_new, 0)
        a_new = a_new / a_new.sum()
        
        sc = _score_norm_fn(a_new)
        if sc < best_score:
            best_score = sc
            best_a = a_new.copy()
            a = a_new.copy()
            if it % 10 == 0:
                print(f"    LP iter {it}: score={best_score:.10f}")
        else:
            # Try smaller step
            t = 0.1
            a_new2 = (1 - t) * a + t * b_scaled
            a_new2 = np.maximum(a_new2, 0)
            a_new2 = a_new2 / a_new2.sum()
            sc2 = _score_norm_fn(a_new2)
            if sc2 < best_score:
                best_score = sc2
                best_a = a_new2.copy()
                a = a_new2.copy()
            else:
                # No improvement, try to use the dual info for gradient step
                break
    
    return best_a, best_score

def _run_lbfgs_continuation(a_init, deadline, rng, max_wall_time=None):

            log_sum = float(np.log(s_))
