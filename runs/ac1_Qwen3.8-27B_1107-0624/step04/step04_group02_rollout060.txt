def lp_step(b, M, solver='highs'):
    """
    One LP step: solve the linearized problem to find improvement direction.
    b: current sequence (sum = 1, non-negative)
    M: current max of b*b
    Returns: new sequence (sum = 1, non-negative)
    """
    n = len(b)
    c = np.convolve(b, b)  # or use FFT
    # Build constraint matrix
    # A[k, j] = 2*b[k-j] if 0 <= k-j <= n-1, else 0
    # A[k, n] = -1
    # b_vec[k] = c[k]
    # Equality: sum(delta) = 0
    # Bounds: delta[j] >= -b[j], t >= 0
    # Objective: minimize t
    
    # This is a bit expensive to build the full matrix for n=4096
    # Let's use a sparse representation
    
    from scipy.sparse import lil_matrix, csr_matrix
    from scipy.optimize import linprog
    
    # Number of inequality constraints: 2n-1
    # Number of variables: n (delta) + 1 (t)
    A = lil_matrix((2*n-1, n+1))
    b_vec = np.zeros(2*n-1)
    for k in range(2*n-1):
        lo = max(0, k - n + 1)
        hi = min(n - 1, k)
        for j in range(lo, hi + 1):
            A[k, j] = 2.0 * b[k - j]
        A[k, n] = -1.0
        b_vec[k] = c[k]
    
    A = csr_matrix(A)
    
    # Equality constraint: sum(delta) = 0
    A_eq = np.zeros((1, n+1))
    A_eq[0, :n] = 1.0
    b_eq = np.zeros(1)
    
    # Objective: minimize t
    c_obj = np.zeros(n+1)
    c_obj[n] = 1.0
    
    # Bounds
    bounds = [(-b[j], None) for j in range(n)] + [(0, None)]
    
    result = linprog(c_obj, A_ub=A, b_ub=b_vec, A_eq=A_eq, b_eq=b_eq,
                     bounds=bounds, method='highs')
    
    if result.success:
        delta = result.x[:n]
        b_new = b + delta
        b_new = np.maximum(b_new, 0)

(b+δ)⊛(b+δ) ≈ b⊛b + b⊛δ + δ⊛b = c + 2(b⊛δ) (since b⊛δ = δ⊛b for... wait, no, linear convolution is NOT commutative in the same way.

Actually, (a⊛b)[k] = sum_j a[j]b[k-j] and (b⊛a)[k] = sum_j b[j]a[k-j]. These are the same! (Substitute i = k-j in the first: sum_i a[k-i]b[i] = sum_i b[i]a[k-i].) So yes, b⊛δ = δ⊛b.

So (b+δ)⊛(b+δ) ≈ c + b⊛δ + δ⊛b = c + 2(b⊛δ). Correct.

Now, (b⊛δ)[k] = sum_j b[j]·δ[k-j] where 0≤j≤n-1 and 0≤k-j≤n-1.
= sum_j b[j]·δ[k-j] for j from max(0, k-n+1) to min(n-1, k).

So the constraint matrix A[k, j] = b[k-j] if 0≤k-j≤n-1, else 0. And we multiply by 2.

This is correct.

Let me also think about whether the LP might have numerical issues. If b has very small values (close to 0), the constraints involving those entries will be very loose, which is fine. The main issue would be if b has very large dynamic range, but since we normalize to sum=1 and keep values non-negative, the values are at most 1 (in practice much smaller).

One concern: the LP might find a δ that makes some b[j] + δ[j] very negative (even though we have the bound δ[j] ≥ -b[j]). The bound should prevent this, but numerical issues might cause tiny violations. I'll clip to 0 after the step.

Another concern: the LP might be infeasible. This could happen if c + 2(b⊛δ) ≤ t is impossible for any δ with sum(δ)=0 and δ ≥ -b. But since δ=0, t=max(c) is always feasible, the LP should always have a feasible solution.

Wait, is that right? At δ=0, the constraint becomes c[k] ≤ t for all k, which is satisfied by t = max(c). And sum(δ)=0 is satisfied. And δ=0 ≥ -b (since b ≥ 0). So yes, the LP is always feasible.

Now, will the LP always give t < max(c)? Not necessarily. If the current b is already optimal, the LP will give t = max(c) and δ = 0. In that case, we've converged.

In practice, the LP should give t < max(c) as long as we're not at the optimum, because we can always find a small perturbation that reduces the max.

1. Generate diverse initial profiles
2. For each profile (sorted by score):

   c. Polish with local search
3. Multi-restart: perturb the best solution and repeat
4. Try different n values
5. Return the best solution found

Let me also think about the L-BFGS approach. The previous solution used a softmax parameterization with logsumexp smoothing. This is good but might get stuck in local minima.

An alternative: use the "water-filling" approach. At each iteration, identify the lag(s) that achieve the maximum, and try to reduce them while keeping other lags bounded. This is related to the LP approach but without the full LP solve.

Actually, let me think about a simpler approach: **mirror descent** on the probability simplex.

The problem is: minimize f(a) = max_k (a⊛a)[k] subject to a ≥ 0, sum(a) = 1.

This is a convex problem... wait, is it? f(a) = max of quadratic forms. Each quadratic (a⊛a)[k] is convex iff the corresponding Hessian is PSD.

For lag k, the quadratic form is aᵀ Q_k a where Q_k[j, k-j] = 1/2 (and Q_k[j,j] = 1 if k=2j).

The Hessian of (a⊛a)[k] with respect to a is 2Q_k. This is PSD iff Q_k is PSD.

Q_k is a symmetric matrix. For k=0: Q_0[0,0] = 1, rest 0. PSD. ✓
For k=n-1: Q_{n-1}[j, n-1-j] = 1/2. This is (1/2)·P where P is the reversal matrix. P has eigenvalues ±1, so Q_{n-1} is NOT PSD.

So f(a) is NOT convex. Maximum of non-convex functions is also non-convex.

This means we can't use standard convex optimization. We need to deal with the non-convexity.

The LP linearization approach handles this by working within a "trusted region" where the linearization is valid.

Let me also consider: what if we reformulate the problem?

Let u = a⊛a (the convolution). Then we want to minimize max(u) subject to u = a⊛a, a ≥ 0, sum(a) = 1.

The constraint u = a⊛a is quadratic (non-convex). So this doesn't help directly.

What about: minimize t subject to (a⊛a)[k] ≤ t, a ≥ 0, sum(a) = 1?

This is a non-convex QCQP (quadratically constrained quadratic program). We could use SDP relaxations, but that might be too expensive for n=4096.

Let me stick with the LP iterative approach.

One more idea: **alternating minimization**. Fix the "shape" of the sequence (e.g., its histogram or its Fourier coefficients) and optimize the "phase" (i.e., the assignment of values to positions). But this doesn't quite make sense for a 1D sequence.

"""
LP-linearized optimizer for minimizing 2*n*max(conv(a,a))/sum(a)^2.
Uses successive LP linearization, L-BFGS continuation, and local search.
Key innovation: iterative LP that linearizes the quadratic autocorrelation
constraints at the current point to find descent directions.
"""
import numpy as np
from scipy.optimize import minimize, linprog
from scipy.sparse import lil_matrix, csr_matrix
from scipy.fft import rfft, irfft
import time


def _next_pow2(n):
    k = 1
    while k < n:
        k <<= 1
    return max(2, k)


def _full_convolve(a, b):
    n, m = len(a), len(b)
    out_n = n + m - 1
    N = _next_pow2(out_n)
    fa = rfft(a, N)
    fb = rfft(b, N)
    r = irfft(fa * fb, N)[:out_n]
    return r


def _score_norm(a):
    """Score with sum(a)=1 normalization: 2*n*max(conv(a,a))."""
    n = len(a)
    s = a.sum()
    if s < 1e-15:
        return np.inf
    a_norm = a / s
    c = _full_convolve(a_norm, a_norm)
    return float(2.0 * n * c.max())


def _score_fn(a):
    """Full score: 2*n*max(conv(a,a))/sum(a)^2."""
    n = len(a)
    s = float(a.sum())
    if s < 1e-15:
        return np.inf
    c = _full_convolve(a, a)
    return float(2.0 * n * c.max() / (s * s))


def _softmax_fn(z):
    z = np.asarray(z, dtype=np.float64)
    z = z - np.max(z)
    e = np.exp(z)
    s = e.sum()
    if s < 1e-300 or not np.isfinite(s):
        return np.ones_like(z) / len(z)
    return e / s


def _make_beta_profile(n, alpha, beta_param):
    """Beta-distribution-like profile."""
    j = np.arange(n, dtype=np.float64)
    t = j / max(1, n - 1)
    t = np.clip(t, 1e-10, 1 - 1e-10)
    a = t ** (alpha - 1) * (1 - t) ** (beta_param - 1)
    a = np.maximum(a, 0)
    s = a.sum()
    if s < 1e-30:
        return np.ones(n) / n
    return a / s


def _make_poly_profile(n, coeffs):
    """Polynomial profile: a[j] = prod(coeffs[i] * t + (1-coeffs[i])) or similar."""
    # Actually, let's do: a[j] = 1 + sum_i c_i * (t - 0.5)^i
    t = np.linspace(0.0, 1.0, n)
    u = 2.0 * t - 1.0
    a = np.ones(n)
    for i, c in enumerate(coeffs):
        a += c * u ** (i + 1)
    a = np.maximum(a, 1e-12)
    return a / a.sum()


def _make_exp_profile(n, rate):
    """Exponential decay profile."""
    j = np.arange(n, dtype=np.float64)
    t = j / max(1, n - 1)
    a = np.exp(-rate * t)
    return a / a.sum()


def _make_dual_exp_profile(n, rate1, rate2):
    """Dual exponential: exp(-r1*t) for t<0.5, exp(-r2*(1-t)) for t>=0.5."""
    j = np.arange(n, dtype=np.float64)
    t = j / max(1, n - 1)
    a = np.where(t < 0.5, np.exp(-rate1 * t), np.exp(-rate2 * (1 - t)))
    return a / a.sum()


def _lp_linearized_step(b, max_iter=1):
    """
    One step of LP linearization.
    b: current sequence, sum(b)=1, b>=0
    Returns improved sequence or b itself if no improvement.
    """
    n = len(b)
    c = _full_convolve(b, b)
    M = float(c.max())
    
    # Build LP
    # Variables: delta[0..n-1], t
    # Minimize t
    # Subject to: c[k] + 2*(b*delta)[k] <= t for k=0..2n-2
    #             sum(delta) = 0
    #             delta[j] >= -b[j]
    #             t >= 0
    
    n_con = 2 * n - 1
    n_var = n + 1  # delta + t
    
    # Build constraint matrix A (n_con × n_var)
    # A[k, j] = 2*b[k-j] if 0<=k-j<=n-1, else 0; A[k, n] = -1
    # Use sparse
    
    rows = []
    cols = []
    vals = []
    b_ub = c.copy()
    
    for k in range(n_con):
        lo = max(0, k - n + 1)
        hi = min(n - 1, k)
        for j in range(lo, hi + 1):
            rows.append(k)
            cols.append(j)
            vals.append(2.0 * b[k - j])
        # t column
        rows.append(k)
        cols.append(n)
        vals.append(-1.0)
    
    A = csr_matrix((vals, (rows, cols)), shape=(n_con, n_var))
    
    # Equality: sum(delta) = 0
    A_eq = np.zeros((1, n_var))
    A_eq[0, :n] = 1.0
    b_eq = np.zeros(1)
    
    # Objective: minimize t
    c_obj = np.zeros(n_var)
    c_obj[n] = 1.0
    
    # Bounds: delta[j] >= -b[j], no upper bound; t >= 0
    bounds = [(-b[j], None) for j in range(n)] + [(0, None)]
    
    try:
        result = linprog(c_obj, A_ub=A, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq,
                         bounds=bounds, method='highs',
                         options={'presolve': True, 'time_limit': 30})
        if result.success and result.x is not None:
            delta = result.x[:n]
            t_val = result.x[n]
            b_new = b + delta
            b_new = np.maximum(b_new, 0)
            s = b_new.sum()
            if s < 1e-15:
                return b.copy(), M
            b_new = b_new / s
            return b_new, M
        else:
            return b.copy(), M
    except Exception:
        return b.copy(), M


def _lp_optimize(b_init, deadline, max_iters=200, line_search=True):
    """
    LP linearization optimization loop.
    """
    n = len(b_init)
    b = b_init.copy()
    b = np.maximum(b, 0)
    b = b / b.sum()
    best_b = b.copy()
    best_score = _score_norm(b)
    
    print(f"  LP start: score={best_score:.10f}")
    
    for it in range(max_iters):
        if time.monotonic() > deadline - 5.0:
            break
        
        b_new, _ = _lp_linearized_step(b)
        if b_new is None or np.allclose(b_new, b):
            break
        
        # Line search
        if line_search:
            found = False
            for alpha in [1.0, 0.5, 0.25, 0.125, 0.0625]:
                b_trial = b + alpha * (b_new - b)
                b_trial = np.maximum(b_trial, 0)
                s = b_trial.sum()
                if s < 1e-15:
                    continue
                b_trial = b_trial / s
                sc = _score_norm(b_trial)
                if sc < best_score * (1 - 1e-10):
                    b = b_trial
                    best_b = b_trial.copy()
                    best_score = sc
                    found = True
                    break
            if not found:
                # Try the LP solution directly
                b_trial = b_new
                sc = _score_norm(b_trial)
                if sc < best_score:
                    b = b_trial
                    best_b = b_trial.copy()
                    best_score = sc
                else:
                    break  # No improvement possible
        else:
            b = b_new
            sc = _score_norm(b)
            if sc < best_score:
                best_b = b.copy()
                best_score = sc
            else:
                break
        
        if it % 10 == 0:
            print(f"  LP iter {it}: score={best_score:.10f}")
    
    print(f"  LP done: score={best_score:.10f}")
    return best_b, best_score

    n = len(a)
    s = float(a.sum())
    if s < 1e-15:
        return np.inf
    a_n = a / s
    c = _full_convolve(a_n, a_n)
    return float(2.0 * n * c.max())


def _score_fn(a):
    n = len(a)
    s = float(a.sum())
    if s < 1e-15:
        return np.inf
    c = _full_convolve(a, a)
    return float(2.0 * n * c.max() / (s * s))


def _softmax_fn(z):
    z = np.asarray(z, dtype=np.float64)
    z = z - np.max(z)
    e = np.exp(z)
    s = e.sum()
    if s < 1e-300 or not np.isfinite(s):
        return np.ones_like(z) / len(z)
    return e / s


def _make_beta_profile(n, alpha, beta_p):
    j = np.arange(n, dtype=np.float64)
    t = j / max(1, n - 1)
    t = np.clip(t, 1e-10, 1 - 1e-10)
    a = t ** (alpha - 1) * (1.0 - t) ** (beta_p - 1)
    a = np.maximum(a, 0.0)
    s = a.sum()
    if s < 1e-30:
        return np.ones(n) / n
    return a / s


def _make_poly_profile(n, c1, c2, c3=0.0):
    t = np.linspace(0.0, 1.0, n)
    u = 2.0 * t - 1.0
    a = 1.0 + c1 * u + c2 * u ** 2 + c3 * u ** 3
    a = np.maximum(a, 1e-12)
    return a / a.sum()


def _make_exp_profile(n, rate):
    j = np.arange(n, dtype=np.float64)
    t = j / max(1, n - 1)
    a = np.exp(-rate * t)
    return a / a.sum()


def _make_sine_profile(n, freq, offset):
    j = np.arange(n, dtype=np.float64)
    t = j / max(1, n - 1)
    a = 1.0 + offset * np.sin(2.0 * np.pi * freq * t + 0.5)
    a = np.maximum(a, 1e-12)
    return a / a.sum()


def _lp_linearized_step(b):
    n = len(b)
    c = _full_convolve(b, b)
    n_con = 2 * n - 1
    n_var = n + 1

    rows = []
    cols = []
    vals = []

    for k in range(n_con):
        lo = max(0, k - n + 1)
        hi = min(n - 1, k)
        for j in range(lo, hi + 1):
            rows.append(k)
            cols.append(j)
            vals.append(2.0 * b[k - j])
        rows.append(k)
        cols.append(n)
        vals.append(-1.0)

    A = csr_matrix((vals, (rows, cols)), shape=(n_con, n_var))

    A_eq = np.zeros((1, n_var))
    A_eq[0, :n] = 1.0
    b_eq = np.zeros(1)

    c_obj = np.zeros(n_var)
    c_obj[n] = 1.0

    bounds = [(-b[j], None) for j in range(n)] + [(0.0, None)]

    try:
        result = linprog(c_obj, A_ub=A, b_ub=c, A_eq=A_eq, b_eq=b_eq,
                         bounds=bounds, method='highs',
                         options={'presolve': True, 'time_limit': 20})
        if result.success and result.x is not None:
            delta = result.x[:n]
            b_new = b + delta
            b_new = np.maximum(b_new, 0.0)
            s = b_new.sum()
            if s < 1e-15:
                return b.copy()
            return b_new / s
        return b.copy()
    except Exception:
        return b.copy()


def _lp_optimize(b_init, deadline, max_iters=300):
    n = len(b_init)
    b = np.maximum(b_init, 0.0)
    b = b / b.sum()
    best_b = b.copy()
    best_score = _score_norm(b)
    print(f"  LP start: score={best_score:.10f}")

    stall_count = 0
    for it in range(max_iters):
        if time.monotonic() > deadline - 10.0:
            break

        b_lp = _lp_linearized_step(b)
        if np.allclose(b_lp, b, atol=1e-14):
            break

        found_improvement = False
        for alpha in [1.0, 0.75, 0.5, 0.25, 0.125]:
            b_trial = b + alpha * (b_lp - b)
            b_trial = np.maximum(b_trial, 0.0)
            s = b_trial.sum()
            if s < 1e-15:
                continue
            b_trial = b_trial / s
            sc = _score_norm(b_trial)
            if sc < best_score * (1.0 - 1e-12):
                b = b_trial.copy()
                best_b = b_trial.copy()
                best_score = sc
                found_improvement = True
                break

        if not found_improvement:
            stall_count += 1
            if stall_count >= 5:
                break
        else:
            stall_count = 0

        if it % 20 == 0:
            print(f"  LP iter {it}: score={best_score:.10f}")

    print(f"  LP done: score={best_score:.10f} (iters={it+1})")
    return best_b, best_score


def _run_lbfgs_continuation(a_init, deadline, beta_scale=1.0):
    n = len(a_init)
    z = np.log(np.maximum(a_init, 1e-15))
    z = z - z.mean()

    best_a = a_init.copy()
    best_score = _score_norm(a_init)

    c0 = _full_convolve(a_init, a_init)
    max_c0 = float(c0.max())

    beta_starts = [0.05, 0.02, 0.01, 0.005, 0.002, 0.001, 0.0005, 0.0002]
    betas = [b * max_c0 * beta_scale for b in beta_starts]

    remaining = deadline - time.monotonic()
    per_level = max(3.0, remaining / len(betas))

    for beta in betas:
        if time.monotonic() > deadline - 3.0:
            break
        level_deadline = min(deadline, time.monotonic() + per_level)

        def obj(z_):
            a_ = _softmax_fn(z_)
            c_ = _full_convolve(a_, a_)
            cm_ = float(c_.max())
            shifted = (c_ - cm_) / beta
            e_ = np.exp(shifted)
            s_ = e_.sum()
            if s_ < 1e-300:
                return 2.0 * n * cm_
            return 2.0 * n * (cm_ + beta * float(np.log(s_)))

        def grad_fn(z_):
            a_ = _softmax_fn(z_)
            c_ = _full_convolve(a_, a_)
            cm_ = float(c_.max())
            shifted = (c_ - cm_) / beta
            e_ = np.exp(shifted)
            s_ = e_.sum()
            if s_ < 1e-300:
                w = np.zeros_like(c_)
                w[int(np.argmax(c_))] = 1.0
            else:
                w = e_ / s_
            W = float(np.dot(w, c_))
            a_rev = a_[::-1]
            w_conv = _full_convolve(w, a_rev)
            h = w_conv[n - 1:2 * n - 1]
            g = 4.0 * n * a_ * (h - W)
            if not np.all(np.isfinite(g)):
                return np.zeros_like(z_)
            return g

        try:
            result = minimize(
                obj, z, jac=grad_fn,
                method='L-BFGS-B',
                options={'maxiter': 500, 'ftol': 1e-16, 'gtol': 1e-8,
                         'maxls': 50, 'maxfun': 3000}
            )
            if result.x is not None and np.all(np.isfinite(result.x)):
                z_new = result.x
                a_new = _softmax_fn(z_new)
                s_new = _score_norm(a_new)
                if np.isfinite(s_new) and s_new < best_score:
                    best_score = s_new
                    best_a = a_new.copy()
                    z = z_new.copy()
        except Exception:
            pass

    return best_a, best_score


def _local_search(a_init, deadline, n_trials=10000, seed=42):
    rng = np.random.default_rng(seed)
    n = len(a_init)
    a = a_init.copy()
    best_a = a.copy()
    best_score = _score_norm(a)

    for it in range(n_trials):
        if time.monotonic() > deadline - 2.0:
            break

        block_size = int(rng.integers(2, min(30, n // 8)))
        start = int(rng.integers(0, n - block_size))

        a_trial = a.copy()
        pert = rng.uniform(0.9, 1.1, size=block_size)
        a_trial[start:start + block_size] *= pert
        a_trial = np.maximum(a_trial, 1e-15)
        a_trial /= a_trial.sum()

        sc = _score_norm(a_trial)
        if sc < best_score:
            best_score = sc
            best_a = a_trial.copy()
            a = a_trial.copy()
        elif rng.random() < 0.03 and sc < best_score * 1.003:
            a = a_trial.copy()

    return best_a, best_score


def _topk_adam(a_init, deadline, lr=0.01, k_top=5):
    n = len(a_init)
    z = np.log(np.maximum(a_init, 1e-15))
    z = z - z.mean()

    best_a = a_init.copy()
    best_score = _score_norm(a_init)

    m = np.zeros(n)
    v = np.zeros(n)
    t = 0
    b1, b2, eps = 0.85, 0.999, 1e-8

    for it in range(100000):
        if time.monotonic() > deadline - 2.0:
            break

        t += 1
        a_curr = _softmax_fn(z)
        c = _full_convolve(a_curr, a_curr)
        k_actual = min(k_top, len(c))
        top_idx = np.argsort(c)[-k_actual:]

        grad = np.zeros(n)
        for k_val in top_idx:
            k_val = int(k_val)
            lo = max(0, k_val - (n - 1))
            hi = min(n - 1, k_val)
            if lo <= hi:
                grad[lo:hi + 1] += 2.0 * a_curr[k_val - hi:k_val - lo + 1][::-1]
        grad /= k_actual
        grad *= 4.0 * n

        m = b1 * m + (1 - b1) * grad
        v = b2 * v + (1 - b2) * (grad * grad)
        mh = m / (1 - b1 ** t)
        vh = v / (1 - b2 ** t)
        z = z - lr * mh / (np.sqrt(vh) + eps)
        z = np.clip(z, -80, 80)
        z = z - z.mean()

        if t % 20 == 0:
            a_new = _softmax_fn(z)
            sc = _score_norm(a_new)
            if sc < best_score:
                best_score = sc
                best_a = a_new.copy()

    return best_a, best_score


def _interp_profile(p0, n_new):
    p0 = np.asarray(p0, dtype=np.float64).ravel()
    n0 = len(p0)
    if n0 == n_new:
        return p0 / p0.sum()
    x0 = np.linspace(0.0, 1.0, n0)
    x1 = np.linspace(0.0, 1.0, n_new)
    p = np.interp(x1, x0, p0)
    p = np.maximum(p, 1e-12)
    return p / p.sum()
