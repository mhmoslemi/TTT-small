Let me formalize:

Given active set S (lags where c[k] = max), the KKT conditions for the problem
minimize max_{k in S} c[k] subject to sum(a) = 1, a >= 0

(at an interior point where a[j] > 0 for all j) are:
- For each k in S: c[k] = t (same value)
- For each j: 2 * sum_{k in S} a[k-j] / |S| = mu (same value, the Lagrange multiplier)

Wait, more precisely, the Lagrangian is:
L = t - sum_{k in S} lambda_k (t - c[k]) - mu (sum(a) - 1) - sum_j nu_j a[j]

KKT:
∂L/∂t = 1 - sum_{k in S} lambda_k = 0
∂L/∂a[j] = sum_{k in S} 2*lambda_k*a[k-j] - mu - nu_j = 0
For a[j] > 0: nu_j = 0, so sum_{k in S} 2*lambda_k*a[k-j] = mu.

With the normalization sum(lambda_k) = 1, if we set lambda_k = 1/|S| (uniform weights on active set), we get:
sum_{k in S} a[k-j] = mu*|S|/2 for all j with a[j] > 0.

This is a linear system in a (and mu). If all a[j] > 0, we have n+1 unknowns and n+1 equations (n equations from the KKT + 1 from sum(a)=1).

The matrix is: A[j,i] = |number of k in S such that k-i = j| = |number of k in S such that k = i+j|

So A[j,i] = 1 if (i+j) in S, else 0.

This is a banded/structured matrix that can be solved efficiently!

For the full active set S = {0, 1, ..., 2n-2}, A[j,i] = 1 for all j,i (since i+j ranges from 0 to 2n-2). So A = ones(n,n), and the system is n*a[j] = mu*n/2, giving a[j] = mu/2 for all j, and sum = n*mu/2 = 1, so mu = 2/n, a[j] = 1/n. This gives the uniform solution with score 2.

import numpy as np
import time

def _next_pow2(n):
    k = 1
    while k < n:
        k <<= 1
    return max(2, k)

def _full_convolve(a, b):
    n, m = len(a), len(b)
    out_n = n + m - 1
    N = _next_pow2(out_n)
    fa = np.fft.rfft(a, N)
    fb = np.fft.rfft(b, N)
    r = np.fft.irfft(fa * fb, N)[:out_n]
    return r

def _score_fn(a):
    n = len(a)
    s = float(a.sum())
    if s < 1e-15:
        return np.inf
    c = _full_convolve(a, a)
    return float(2.0 * n * c.max() / (s * s))

def _score_norm_fn(a):
    """Assumes sum(a) = 1"""
    n = len(a)
    c = _full_convolve(a, a)
    return float(2.0 * n * c.max())

def _active_set_solve(S, n, max_iter=100):
    """
    Solve the KKT system for a given active set S.
    Returns the optimal a (with sum=1, a>=0) for this active set.
    
    S: set/array of active lag indices
    n: length of sequence
    """
    S = np.array(sorted(set(S)), dtype=np.int64)
    m = len(S)
    
    # Build matrix A: A[j,i] = 1 if (i+j) in S
    # S has values in [0, 2n-2]
    # Use a lookup approach
    S_set = np.zeros(2*n-1, dtype=bool)
    S_set[S] = True
    
    # A[j,i] = 1 if S_set[i+j]
    # Efficient construction: for each k in S, A[j, k-j] = 1 for valid j
    # A is n x n
    # A[j, i] = S_set[j+i]
    # So A = S_set[np.arange(n)[:,None] + np.arange(n)[None,:]]
    A = S_set[np.arange(n)[:, None] + np.arange(n)[None, :]].astype(np.float64)
    
    # Solve: A @ a = mu' * ones, ones^T @ a = 1, a >= 0
    # Start with all indices free
    free = np.arange(n)
    fixed_vals = np.zeros(n)
    
    for outer in range(max_iter):
        if len(free) == 0:
            break
        
        A_ff = A[np.ix_(free, free)]
        # System: A_ff @ a_f = mu' * ones(len(free))
        #         ones^T @ a_f = 1 (assuming fixed are all 0)
        # Combine: [A_ff, ones; ones^T, 0] @ [a_f; mu'] = [mu'*ones; 1]
        # This is: A_ff @ a_f - mu' * ones = 0
        #          ones^T @ a_f = 1
        
        # From first: a_f = mu' * A_ff^{-1} @ ones
        # Substitute: mu' * ones^T @ A_ff^{-1} @ ones = 1
        # mu' = 1 / (ones^T @ A_ff^{-1} @ ones)
        
        try:
            ones = np.ones(len(free))
            # Solve A_ff @ x = ones
            x = np.linalg.solve(A_ff, ones)
            mu_prime = 1.0 / np.sum(x)  # since a_f = mu' * x, and sum(a_f) = mu' * sum(x) = 1
            a_f = mu_prime * x
        except np.linalg.LinAlgError:
            # Singular, use lstsq
            try:
                x, _, _, _ = np.linalg.lstsq(A_ff, ones, rcond=None)
                mu_prime = 1.0 / np.sum(x)
                a_f = mu_prime * x
            except:
                break
        
        # Check non-negativity
        if np.all(a_f >= -1e-12):
            # Converged
            a = fixed_vals.copy()
            a[free] = np.maximum(a_f, 0)
            # Renormalize
            s = a.sum()
            if s > 0:
                a /= s
            return a, True

        min_idx = np.argmin(a_f)
        a_f[min_idx] = 0
        # Remove from free
        remove_global = free[min_idx]
        free = np.delete(free, min_idx)
        fixed_vals[remove_global] = 0
    
    # Didn't converge cleanly, return best attempt
    a = fixed_vals.copy()
    if len(free) > 0:
        a[free] = np.maximum(a_f, 0)
    s = a.sum()
    if s > 0:
        a /= s
    return a, False
