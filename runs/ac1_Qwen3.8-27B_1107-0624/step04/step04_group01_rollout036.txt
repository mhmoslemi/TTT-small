Let me think about the active-set balancing more carefully.

Suppose at the current point a, the convolution values are c = conv(a,a), and the max is at lags S = {k : c[k] > c_max - tol}.

We want to find a direction d (on the tangent space of the simplex: sum d = 0) such that:
- c_k decreases for k in S (at least the ones with highest c_k)
- c_k doesn't increase too much for k not in S

The directional derivative of q_k in direction d is:
Dq_k(d) = 2 * sum_i d[i] * a[k-i]

So we want to minimize max_{k in S} Dq_k(d) subject to sum d = 0, and ||d|| ≤ 1.

This is a linear program in d (for fixed a). But d has n variables, so it's a large LP.

Alternatively, we can use a greedy approach: find the d that most reduces the maximum, step in that direction, repeat.

The steepest descent direction for f(a) = max_k q_k(a) is:
d = -argmin_{g ∈ ∂f(a)} ||g||^2 (projected onto the tangent space of the simplex)

The subgradient g = sum_{k in S} λ_k ∇q_k(a) where λ is the minimum-norm combination.

For simplicity, let's use the uniform average: g = (1/|S|) sum_{k in S} ∇q_k(a).

Then the projected steepest descent direction is:
d = -P_T(g) where P_T is projection onto the tangent space {v : sum v = 0}.
P_T(g) = g - (sum(g)/n) * 1

And we take a step: a_new = a + α * d (then project to simplex if needed).

The step size α can be determined by line search.

Actually, I realize there's a subtlety. The gradient ∇q_k(a) has components:
[∇q_k(a)]_j = 2*a[k-j] (for k-j in [0,n-1])

This is essentially 2 times a "shifted and reversed" version of a. Specifically, if we reverse a to get a_rev[i] = a[n-1-i], then:
[∇q_k(a)]_j = 2 * a[k-j] = 2 * a_rev[n-1-k+j]

So ∇q_k(a) is 2 * a_rev shifted by (n-1-k) and zero-padded.

This can be computed via circular convolution if we embed in a larger array.

For the uniform average of active gradients:
g = (1/|S|) sum_{k in S} 2*a[k-j] (for each j)
= 2 * (1/|S|) sum_{k in S} a[k-j]
= 2 * (convolution of a with the indicator of S, evaluated at j)

So g = 2 * conv(a, indicator_S)[n-1 + something]... let me be more careful.

g[j] = (2/|S|) * sum_{k in S, k-j in [0,n-1]} a[k-j]
= (2/|S|) * sum_{i in [0,n-1]} a[i] * |{k in S : k = j+i}|
= (2/|S|) * sum_{i} a[i] * indicator_{j+i ∈ S}
= (2/|S|) * (a * indicator_S reversed)[j]

This is 2/|S| times the cross-correlation of a with the indicator of S.

We can compute this with FFT!

OK so the algorithm is:
1. Compute c = conv(a, a)
2. Find active set S = {k : c[k] ≥ c_max - tol}
3. Compute g = 2/|S| * cross_corr(a, indicator_S)  [using FFT]
4. Project g onto tangent space: g_t = g - mean(g)*1
5. Take step: a_new = simplex_project(a - α * g_t)
6. Line search for α

This is O(n log n) per iteration! Much better than computing all gradients.

"""
Convex optimization for minimum peak autocorrelation of non-negative sequences.
Uses subgradient descent with active-set identification and balancing,
exploiting the convexity of max(conv(a,a)) over the probability simplex.
"""
import numpy as np
import time

def _next_pow2(n):
    k = 1
    while k < n:
        k <<= 1
    return max(2, k)

def _full_convolve(a, b):
    n, m = len(a), len(b)
    out_n = n + m - 1
    N = _next_pow2(out_n)
    fa = np.fft.rfft(a, N)
    fb = np.fft.rfft(b, N)
    r = np.fft.irfft(fa * fb, N)[:out_n]
    return r

def _score(a):
    n = len(a)
    s = float(a.sum())
    if s < 1e-15:
        return np.inf
    c = _full_convolve(a, a)
    return float(2.0 * n * c.max() / (s * s))

def _score_norm(a):
    """Score assuming sum(a)=1: returns 2*n*max(conv(a,a))"""
    n = len(a)
    c = _full_convolve(a, a)
    return float(2.0 * n * c.max())

def _softmax(z):
    z = z - np.max(z)
    e = np.exp(z)
    s = e.sum()
    if s < 1e-300:
        return np.ones_like(z) / len(z)
    return e / s

def _proj_simplex(v):
    """Project v onto the probability simplex {a: sum(a)=1, a>=0}"""
    n = len(v)
    if n == 0:
        return v
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.nonzero(u * np.arange(1, n + 1) > (cssv - 1))[0][-1]
    theta = (cssv[rho] - 1) / (rho + 1.0)
    return np.maximum(v - theta, 0)

def _subgradient_max_conv(a, tol=0.01):
    """
    Compute an approximate subgradient of max_k conv(a,a)[k].
    Returns (gradient, active_set_size, max_val)
    Uses soft-max weighting with tolerance-based active set.
    """
    n = len(a)
    c = _full_convolve(a, a)
    c_max = float(c.max())
    # Active set: lags within tol of max (relative)
    threshold = c_max * (1.0 - tol)
    active = c >= threshold
    n_active = int(active.sum())
    if n_active == 0:
        active[int(np.argmax(c))] = True
        n_active = 1
    
    # Subgradient: (2/n_active) * cross_corr(a, indicator_active)
    # cross_corr(a, b)[j] = sum_i a[i] * b[i+j] (with appropriate indexing)
    # We want: g[j] = (2/n_active) * sum_{k in active} a[k-j]
    #          = (2/n_active) * sum_i a[i] * active[j+i]
    # This is the cross-correlation of a with active, shifted appropriately.
    
    # Using FFT: conv(a, active) gives us sum_i a[i]*active[k-i]
    # We want sum_i a[i]*active[j+i] = conv(active, a_rev)[j + n - 1] where a_rev = a[::-1]
    # Actually, let me just use the direct formula with FFT.
    
    # g[j] = (2/n_active) * sum_{k in active} a[k-j] (a[x]=0 for x out of [0,n-1])
    # Let b = active (as a float array of length 2n-1)
    # Then g[j] = (2/n_active) * sum_i a[i] * b[j+i]
    # This is the cross-correlation <a, shift_j(b)>
    
    # Using FFT: correlate(a, b) can be done as:
    # conv(a_rev, b)[n-1+j] where a_rev = a[::-1]
    
    a_rev = a[::-1]
    # We need conv of a_rev (length n) with b (length 2n-1)
    # But b is defined on [0, 2n-2], and we need the correlation at shift j for j in [0, n-1]
    # conv(a_rev, b)[k] = sum_i a_rev[i] * b[k-i]
    # We want sum_i a[i] * b[j+i] = sum_i a[n-1-i'] * b[j+n-1-i'] where i' = n-1-i
    # = conv(a_rev, b)[j + n - 1]
    
    # So g[j] = (2/n_active) * conv(a_rev, b)[j + n - 1] for j = 0, ..., n-1
    
    b_float = active.astype(np.float64)
    conv_ab = _full_convolve(a_rev, b_float)
    # conv_ab has length n + (2n-1) - 1 = 3n - 2
    # We need conv_ab[j + n - 1] for j = 0, ..., n-1
    g = (2.0 / n_active) * conv_ab[n-1 : 2*n-1]
    
    return g, n_active, c_max

def _adam_optimize(a_init, deadline, beta_schedule, max_iter=200000, lr=0.01):
    """Adam optimizer in log-space with beta-continuation for soft-max."""
    n = len(a_init)
    z = np.log(np.maximum(a_init, 1e-15))
    z = z - z.mean()
    
    best_a = a_init.copy()
    best_score = _score_norm(a_init)
    
    m_buf = np.zeros(n)
    v_buf = np.zeros(n)
    t = 0
    b1, b2, eps = 0.9, 0.999, 1e-8
    current_lr = lr
    
    for beta in beta_schedule:
        if time.monotonic() > deadline:
            break
        it_in_phase = 0
        while it_in_phase < max_iter:
            if time.monotonic() > deadline:
                break
            it_in_phase += 1
            t += 1
            
            a = _softmax(z)
            c = _full_convolve(a, a)
            cm = float(c.max())
            c_shifted = (c - cm) / beta
            e = np.exp(c_shifted)
            s = float(e.sum())
            if s < 1e-300 or not np.isfinite(s):
                w = np.zeros_like(c)
                w[int(np.argmax(c))] = 1.0
            else:
                w = e / s
            
            # Gradient: 4*n*a*(h-W) where h = cross_corr(w, a), W=dot(w, c)
            a_rev = a[::-1]
            wc = _full_convolve(w, a_rev)
            h = wc[n - 1:2 * n - 1]
            W = float(np.dot(w, c))
            grad = 4.0 * n * a * (h - W)
            
            if not np.all(np.isfinite(grad)):
                break
            
            m_buf = b1 * m_buf + (1.0 - b1) * grad
            v_buf = b2 * v_buf + (1.0 - b2) * (grad * grad)
            mh = m_buf / (1.0 - b1 ** t)
            vh = v_buf / (1.0 - b2 ** t)
            
            update = current_lr * mh / (np.sqrt(vh) + eps)
            max_update = 0.5
            update_norm = np.linalg.norm(update)
            if update_norm > max_update:
                update = update * (max_update / update_norm)
            
            z = z - update
            z = np.clip(z, -50.0, 50.0)
            z = z - z.mean()
            
            if t % 50 == 0:
                sc = _score_norm(a)
                if np.isfinite(sc) and sc < best_score:
                    best_score = sc
                    best_a = a.copy()
            
            if it_in_phase % 3000 == 0:
                current_lr = max(0.002, current_lr * 0.98)
    
    a_final = _softmax(z)
    sc_final = _score_norm(a_final)
    if np.isfinite(sc_final) and sc_final < best_score:
        best_score = sc_final
        best_a = a_final.copy()
    
    return best_a, best_score

def _subgradient_optimize(a_init, deadline, tol=0.005, max_iter=50000):
    """
    Subgradient descent with exact max and active-set identification.
    Uses backtracking line search for monotone convergence.
    """
    n = len(a_init)
    a = a_init.copy()
    a = a / a.sum()  # normalize
    
    best_a = a.copy()
    best_score = _score_norm(a)
    best_max_conv = float(_full_convolve(a, a).max())
    
    # Initial step size
    alpha = 0.01
    min_alpha = 1e-10
    patience = 500
    no_improve = 0
    
    for it in range(max_iter):
        if time.monotonic() > deadline:
            break
        
        c = _full_convolve(a, a)
        c_max = float(c.max())
        
        # Check improvement
        if c_max < best_max_conv - 1e-12:
            best_max_conv = c_max
            best_a = a.copy()
            no_improve = 0
        else:
            no_improve += 1
        
        if no_improve > patience and alpha < min_alpha:
            break
        
        # Compute subgradient
        g, n_active, _ = _subgradient_max_conv(a, tol=tol)
        
        # Project onto tangent space of simplex (sum = 0)
        g_t = g - np.mean(g)
        
        if np.linalg.norm(g_t) < 1e-15:
            break
        
        # Backtracking line search
        f0 = c_max
        found_step = False
        for ls in range(30):
            a_trial = a - alpha * g_t
            a_trial = _proj_simplex(a_trial)
            c_trial = _full_convolve(a_trial, a_trial)
            f_trial = float(c_trial.max())
            
            if f_trial < f0 - 1e-12:  # Sufficient decrease
                a = a_trial
                found_step = True
                break
            alpha *= 0.5
        
        if not found_step:
            alpha *= 0.5
            if alpha < min_alpha:
                # Try a smaller tolerance for active set
                tol = max(0.001, tol * 0.5)
                continue
        
        # Decay alpha slowly
        if it % 10000 == 0:
            alpha *= 0.95
    
    return best_a, _score_norm(best_a)

def _balance_active_set(a, n_active_max=20, tol=0.001, max_iter=200):
    """
    Try to balance the values in the active set by solving a small QP-like problem.
    """
    n = len(a)
    a = a.copy()
    
    for _ in range(max_iter):
        if time.monotonic() > 0:  # placeholder for deadline check
            break
            
        c = _full_convolve(a, a)
        c_max = float(c.max())
        
        # Find top lags
        if n_active_max is not None:
            # Get indices of top n_active_max values
            top_idx = np.argsort(c)[::-1][:n_active_max]
            # Only include those within tol of max
            active = c >= c_max * (1.0 - tol)
            active_set = np.where(active)[0]
            if len(active_set) > n_active_max:
                # Keep the top ones
                active_vals = c[active_set]
                keep = np.argsort(active_vals)[::-1][:n_active_max]
                active_set = active_set[keep]
        else:
            active = c >= c_max * (1.0 - tol)
            active_set = np.where(active)[0]
        
        if len(active_set) <= 1:
            break
        
        # Compute the subgradient (uniform average over active set)
        b = np.zeros(2*n-1)
        b[active_set] = 1.0
        a_rev = a[::-1]
        conv_ab = _full_convolve(a_rev, b)
        g = (2.0 / len(active_set)) * conv_ab[n-1 : 2*n-1]
        
        # Project to tangent space
        g_t = g - np.mean(g)
        g_norm = np.linalg.norm(g_t)
        if g_norm < 1e-15:
            break
        
        # Take a small step
        step = 0.01 / g_norm
        a_new = _proj_simplex(a - step * g_t)
        
        c_new = _full_convolve(a_new, a_new)
        if c_new.max() < c_max:
            a = a_new
        else:
            step *= 0.5
            if step < 1e-10:
                break
    
    return a

def _make_profile(n, kind="uniform"):
    if kind == "uniform":
        return np.ones(n) / n
    elif kind == "sinusoidal":
        t = np.linspace(0, 1, n)
        a = 1.0 + 0.3 * np.cos(2.0 * np.pi * t)
        a = np.maximum(a, 1e-10)
        return a / a.sum()
    elif kind == "tapered":
        t = np.linspace(0, 1, n)
        a = np.sin(np.pi * t) ** 0.5
        a = np.maximum(a, 1e-10)
        return a / a.sum()
    else:
        return np.ones(n) / n

def _perturb(a, sigma, rng):
    z = np.log(np.maximum(a, 1e-15))
    z = z + sigma * rng.standard_normal(len(a))
    z = z - z.mean()
    return _softmax(z)

def _interp_profile(p, n_new):
    n0 = len(p)
    if n0 == n_new:
        return p.copy()
    x0 = np.linspace(0, 1, n0)
    x1 = np.linspace(0, 1, n_new)
    p_new = np.interp(x1, x0, p)
    p_new = np.maximum(p_new, 1e-12)
    return p_new / p_new.sum()

"""
Convex optimization for minimum peak autocorrelation of non-negative sequences.
Exploits convexity of max(conv(a,a)) over the simplex using:
1. Soft-max Adam with aggressive beta continuation for initial convergence
2. Exact subgradient with Nesterov acceleration for refinement
3. Active-set balancing for precision
4. Multi-length exploration
"""
import numpy as np
import time


def _next_pow2(n):
    k = 1
    while k < n:
        k <<= 1
    return max(2, k)


def _full_convolve(a, b):
    n, m = len(a), len(b)
    out_n = n + m - 1
    N = _next_pow2(out_n)
    fa = np.fft.rfft(a, N)
    fb = np.fft.rfft(b, N)
    r = np.fft.irfft(fa * fb, N)[:out_n]
    return r


def _score(a):
    n = len(a)
    s = float(a.sum())
    if s < 1e-15:
        return np.inf
    c = _full_convolve(a, a)
    return float(2.0 * n * c.max() / (s * s))


def _score_norm(a):
    n = len(a)
    c = _full_convolve(a, a)
    return float(2.0 * n * c.max())


def _softmax(z):
    z = z - np.max(z)
    e = np.exp(z)
    s = e.sum()
    if s < 1e-300:
        return np.ones_like(z) / len(z)
    return e / s


def _proj_simplex(v):
    n = len(v)
    if n == 0:
        return v
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.nonzero(u * np.arange(1, n + 1) > (cssv - 1))[0]
    if len(rho) == 0:
        return np.ones(n) / n
    rho = rho[-1]
    theta = (cssv[rho] - 1) / (rho + 1.0)
    return np.maximum(v - theta, 0)


def _grad_soft_max(a, beta, n):
    """Compute gradient of 2*n*beta*log(sum exp(q_k/beta)) w.r.t. a."""
    c = _full_convolve(a, a)
    c_shifted = c / beta
    c_shifted = c_shifted - c_shifted.max()
    e = np.exp(c_shifted)
    s = float(e.sum())
    if s < 1e-300 or not np.isfinite(s):
        w = np.zeros_like(c)
        w[int(np.argmax(c))] = 1.0
    else:
        w = e / s
    a_rev = a[::-1]
    wc = _full_convolve(w, a_rev)
    grad = 4.0 * n * wc[n - 1:2 * n - 1]
    return grad, c


def _subgradient_exact(a, tol_frac=0.005):
    """
    Compute subgradient of max_k q_k(a) using active-set averaging.
    Returns (gradient, c_max, n_active)
    """
    n = len(a)
    c = _full_convolve(a, a)
    c_max = float(c.max())
    threshold = c_max - tol_frac * c_max
    active = (c >= threshold).astype(np.float64)
    n_active = int(active.sum())
    if n_active == 0:
        idx = int(np.argmax(c))
        active = np.zeros_like(c)
        active[idx] = 1.0
        n_active = 1
    a_rev = a[::-1]
    conv_ab = _full_convolve(a_rev, active)
    g = (2.0 / n_active) * conv_ab[n - 1:2 * n - 1]
    return g, c_max, n_active

        y_new = a_new + ((t_k - 1.0) / t_new) * (a_new - a)
        y_new = np.maximum(y_new, 0.0)
        y_sum = y_new.sum()
        if y_sum > 0:
            y_new = y_new / y_sum
        else:
            y_new = a_new.copy()
        c_new = _full_convolve(a_new, a_new)
        mc_new = float(c_new.max())
        if mc_new < best_mc - 1e-14:
            best_mc = mc_new
            best_a = a_new.copy()
            no_improve = 0
        else:
            no_improve += 1
        if no_improve > patience:
            tol_frac = max(0.0005, tol_frac * 0.5)
            no_improve = 0
            patience = int(patience * 1.3)
            if tol_frac < 0.0005:
                break
        a = a_new
        y = y_new
        t_k = t_new

    # Final check
    c_best = _full_convolve(best_a, best_a)
    if float(c_best.max()) < best_mc:
        best_mc = float(c_best.max())
    return best_a, _score_norm(best_a)


def _balance_step(a, n_top=20, max_iter=500):
    """Iteratively balance the top convolution lags."""
    n = len(a)
    a = a.copy() / a.sum()
    for _ in range(max_iter):
        c = _full_convolve(a, a)
        c_max = float(c.max())
        order = np.argsort(c)[::-1]
        active_set = order[:n_top]
        threshold = c[active_set[-1]]
        active = (c >= threshold - 1e-15).astype(np.float64)
        n_act = int(active.sum())
        if n_act <= 1:
            break
        a_rev = a[::-1]
        conv_ab = _full_convolve(a_rev, active)
        g = (2.0 / n_act) * conv_ab[n - 1:2 * n - 1]
        g_t = g - np.mean(g)
        g_norm = np.linalg.norm(g_t)
        if g_norm < 1e-15:
            break
        step = 0.5 / (n * g_norm)
        for ls in range(20):
            a_trial = _proj_simplex(a - step * g_t)
            c_trial = _full_convolve(a_trial, a_trial)
            if float(c_trial.max()) < c_max - 1e-14:
                a = a_trial
                break
            step *= 0.5
        else:
            break
    return a


def _perturb(a, sigma, rng):
    z = np.log(np.maximum(a, 1e-15))
    z = z + sigma * rng.standard_normal(len(a))
    z = z - z.mean()
    return _softmax(z)


def _interp_profile(p, n_new):
    n0 = len(p)
    if n0 == n_new:
        return p.copy()
    x0 = np.linspace(0, 1, n0)
    x1 = np.linspace(0, 1, n_new)
    p_new = np.interp(x1, x0, p)
    p_new = np.maximum(p_new, 1e-12)
    return p_new / p_new.sum()


def propose_candidate(seed=42, budget_s=1800):
    """
    Multi-phase convex optimization for min 2*n*max(conv(a,a))/sum(a)^2.
    Combines soft-max Adam, Nesterov subgradient, active-set balancing,
    and multi-length exploration.
    """
    t_start = time.monotonic()
    deadline = t_start + max(1.0, float(budget_s) - 25.0)
    rng = np.random.default_rng(int(seed) % (2**63 - 1))
    best_seq = None
    best_score = np.inf

    def update_best(p, sc=None, label=""):
        nonlocal best_seq, best_score
        if p is None:
            return
        p = np.asarray(p, dtype=np.float64).ravel()
        p = np.clip(p, 0.0, 1000.0)
        s = float(p.sum())
        if s < 0.01:
            return
        if sc is None:
            sc = _score(p)
        if np.isfinite(sc) and sc < best_score:
            best_seq = p.copy()
            best_score = float(sc)
            print(f"  NEW BEST: {best_score:.10f} (n={len(p)}) [{label}] t={time.monotonic()-t_start:.1f}s")

    # Load parent
    parent = None
    try:
        parent_raw = np.asarray(height_sequence_1, dtype=np.float64).ravel()
        if parent_raw.size > 0:
            parent_raw = np.clip(parent_raw, 0.0, 1000.0)
            s = parent_raw.sum()
            if s > 0.01:
                parent = parent_raw / s
    except Exception:
        parent = None

    if parent is not None:
        n_main = len(parent)
        a0 = parent.copy()
        sc0 = _score(parent)
        print(f"Parent loaded: n={n_main}, score={sc0:.10f}")
        update_best(parent, sc0, "parent")
    else:
        n_main = 2048
        a0 = np.ones(n_main) / n_main
        print(f"No parent found, using uniform n={n_main}")

    # === Phase 1: Quick Adam convergence (0 - 150s) ===
    p1_end = min(deadline, t_start + 150.0)
    c0 = _full_convolve(a0, a0)
    mc0 = float(c0.max())
    beta_sched = [
        0.015 * mc0, 0.008 * mc0, 0.004 * mc0,
        0.002 * mc0, 0.001 * mc0, 0.0005 * mc0,
    ]
    p1, _ = _adam_logspace(a0, p1_end, beta_sched, lr=0.015, max_iter=200000)
    update_best(p1, _score(p1), "p1_adam")
    print(f"Phase 1 done: best={best_score:.10f} t={time.monotonic()-t_start:.1f}s")

    # === Phase 2: Extended Adam with very small beta (150s - 550s) ===
    p2_end = min(deadline, t_start + 550.0)
    if best_seq is not None and time.monotonic() < p2_end - 10:
        c_best = _full_convolve(best_seq, best_seq)
        mc_best = float(c_best.max())
        beta_fine = [
            0.0004 * mc_best, 0.0002 * mc_best, 0.0001 * mc_best,
            0.00005 * mc_best, 0.00002 * mc_best, 0.00001 * mc_best,
        ]
        p2, _ = _adam_logspace(best_seq, p2_end, beta_fine, lr=0.008, max_iter=300000)
        update_best(p2, _score(p2), "p2_fine_adam")
    print(f"Phase 2 done: best={best_score:.10f} t={time.monotonic()-t_start:.1f}s")

    # === Phase 3: Nesterov subgradient refinement (550s - 950s) ===
    p3_end = min(deadline, t_start + 950.0)
    if best_seq is not None and time.monotonic() < p3_end - 10:
        # Multiple rounds with decreasing tolerance
        chunks = [
            (0.005, 0.4),
            (0.002, 0.35),
            (0.001, 0.25),
        ]
        for i, (tol, frac) in enumerate(chunks):
            if time.monotonic() > p3_end - 10:
                break
            sub_deadline = min(p3_end - 5, time.monotonic() + (p3_end - p2_end) * frac)
            p3, _ = _nesterov_subgradient(best_seq, sub_deadline, tol_frac=tol, max_iter=40000)
            update_best(p3, _score(p3), f"p3_nest_tol{tol}")

        # Active-set balancing
        if best_seq is not None and time.monotonic() < p3_end - 5:
            p_bal = _balance_step(best_seq, n_top=30, max_iter=300)
            update_best(p_bal, _score(p_bal), "p3_balance")
    print(f"Phase 3 done: best={best_score:.10f} t={time.monotonic()-t_start:.1f}s")

    # === Phase 4: Multi-restart (950s - 1350s) ===
    p4_end = min(deadline, t_start + 1350.0)
    if best_seq is not None and time.monotonic() < p4_end - 30:
        n_restarts = 5
        per_r = (p4_end - time.monotonic() - 20) / n_restarts
        for i in range(n_restarts):
            if time.monotonic() > p4_end - 15:
                break
            sigma = 0.015 + 0.01 * i
            p_start = _perturb(best_seq, sigma, rng)
            c_s = _full_convolve(p_start, p_start)
            mc_s = float(c_s.max())
            bs = [0.008 * mc_s, 0.004 * mc_s, 0.002 * mc_s, 0.001 * mc_s]
            adam_dl = time.monotonic() + per_r * 0.5
            p_ad, _ = _adam_logspace(p_start, adam_dl, bs, lr=0.01, max_iter=40000)
            nest_dl = min(p4_end - 10, time.monotonic() + per_r * 0.5)
            p_sub, _ = _nesterov_subgradient(p_ad, nest_dl, tol_frac=0.002, max_iter=20000)
            update_best(p_sub, _score(p_sub), f"p4_restart{i}")
    print(f"Phase 4 done: best={best_score:.10f} t={time.monotonic()-t_start:.1f}s")

    # === Phase 5: Multi-length exploration (1350s - 1650s) ===
    p5_end = min(deadline, t_start + 1650.0)
    if best_seq is not None and time.monotonic() < p5_end - 30:
        for target_n in [1024, 4096, 8192]:
            if time.monotonic() > p5_end - 40:
                break
            if target_n == len(best_seq):
                continue
            p_int = _interp_profile(best_seq, target_n)
            sc_int = _score(p_int)
            update_best(p_int, sc_int, f"p5_interp_{target_n}")
            if time.monotonic() > p5_end - 40:
                continue
            c_int = _full_convolve(p_int, p_int)
            mc_int = float(c_int.max())
            bs_int = [0.005 * mc_int, 0.002 * mc_int, 0.001 * mc_int, 0.0005 * mc_int]
            remaining = min(150.0, p5_end - time.monotonic() - 30)
            if remaining > 40:
                ad_dl = time.monotonic() + remaining * 0.55
                p_ad, _ = _adam_logspace(p_int, ad_dl, bs_int, lr=0.008, max_iter=30000)
                ne_dl = min(p5_end - 10, time.monotonic() + remaining * 0.45)
                p_sub, _ = _nesterov_subgradient(p_ad, ne_dl, tol_frac=0.002, max_iter=15000)
                update_best(p_sub, _score(p_sub), f"p5_opt_{target_n}")
    print(f"Phase 5 done: best={best_score:.10f} t={time.monotonic()-t_start:.1f}s")

    # === Phase 6: Final ultra-fine polish (1650s - deadline) ===
    if best_seq is not None and time.monotonic() < deadline - 15:
        c_fin = _full_convolve(best_seq, best_seq)
        mc_fin = float(c_fin.max())
        beta_ultra = [0.00002 * mc_fin, 0.00001 * mc_fin, 0.000005 * mc_fin]
        ad_dl2 = min(deadline - 10, time.monotonic() + (deadline - time.monotonic()) * 0.5)
        p_fa, _ = _adam_logspace(best_seq, ad_dl2, beta_ultra, lr=0.003, max_iter=100000)
        update_best(p_fa, _score(p_fa), "p6_ultra_adam")
        if time.monotonic() < deadline - 10:
            p_fs, _ = _nesterov_subgradient(best_seq, deadline - 5, tol_frac=0.0005, max_iter=20000)
            update_best(p_fs, _score(p_fs), "p6_ultra_nest")
        # Final balance
        if best_seq is not None:
            p_fb = _balance_step(best_seq, n_top=20, max_iter=200)
            update_best(p_fb, _score(p_fb), "p6_final_balance")

    print(f"Phase 6 done: best={best_score:.10f} t={time.monotonic()-t_start:.1f}s")

    # Final output
    if best_seq is not None:
        final = np.clip(best_seq, 0.0, 1000.0)
        s = float(final.sum())
        if s < 0.01:
            final = np.ones(256) / 256
        sc_final = _score(final)
        print(f"FINAL: score={sc_final:.12f}, n={len(final)}, time={time.monotonic()-t_start:.1f}s")
        try:
            sc_eval = float(evaluate_sequence([float(x) for x in final]))
            print(f"Evaluator confirms: {sc_eval:.12f}")
        except Exception as ex:
            print(f"Eval error: {ex}")
        return [float(x) for x in final]

    fallback = np.ones(256) / 256
    print(f"FALLBACK: score={_score(fallback):.10f}")
    return [float(x) for x in fallback]
