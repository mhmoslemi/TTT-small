Let me explore idea 3 (spectral method):

In the frequency domain (FFT of length N = 2^ceil(log2(2n-1))):
- `A = FFT(a, N)`
- `C = A * conjugate(A)` ... wait, no. For real `a`, `FFT(a*a) = FFT(a) * FFT(a)` (element-wise product, not conjugate).

Actually, `FFT(a*b) = FFT(a) * FFT(b)` in the DFT (no conjugate needed for linear convolution). So:
- `A = FFT(a, N)` (complex)
- `C_freq = A * A` (element-wise)
- `c = IFFT(C_freq)` (real, non-negative)

We want to minimize `max(c)`. In the frequency domain, this is:
- Minimize `max(IFFT(A*A))` subject to `IFFT(A)[0...n-1] >= 0` and `sum(IFFT(A)[0...n-1]) = 1`.

This is still a complex problem in the frequency domain.

Let me try another approach: **Direct minimization of the L_p norm**.

For large p, `||c||_p = (sum c[k]^p)^(1/p) ≈ max(c)`. The L_p norm is smooth for p > 1, and its gradient is:
```
∇(||c||_p)[j] = (1/p) * ||c||_p^(1-p) * sum_{k: valid} p*c[k]^(p-1) * a[k-j]
```
= `||c||_p^(1-p) * sum_{k: valid} c[k]^(p-1) * a[k-j]`

This is well-defined and smooth. As p → ∞, it approaches the max.

The advantage of L_p over logsumexp is that it might converge faster for moderate p values, and we can use a continuation method (increase p gradually).

Let me also think about a **proximal gradient** approach:

We want to minimize `f(a) = ||a*a||_∞` subject to `sum(a) = 1` and `a >= 0`.

The proximal gradient method would be:
```
a_{k+1} = prox_{g, step}(a_k - step * ∇f(a_k))
```
where `g` is the indicator of the constraint set `{a: sum(a)=1, a>=0}`.

The proximal operator of `g` with respect to the Euclidean norm is the projection onto the simplex `{a: sum(a)=1, a>=0}`, which has a known closed form (water-filling).

This is a clean approach! Let me implement it:

1. Compute gradient of smooth approximation to `||a*a||_∞`.
2. Take a gradient step.
3. Project onto the simplex.
4. Repeat.

For the smooth approximation, I'll use logsumexp or L_p norm.

The projection onto the simplex `{a: sum(a)=1, a>=0}` is:
```
proj(a)[i] = max(a[i] - tau, 0)
```
where `tau` is chosen so that `sum_i max(a[i] - tau, 0) = 1`.

This can be found by sorting `a` in decreasing order and finding the right threshold.

Let me also consider **accelerated proximal gradient (FISTA)**:
```
y_k = a_k + (t_{k-1} - 1)/(t_k + 1) * (a_k - a_{k-1})
a_{k+1} = proj(y_k - step * ∇f(y_k))
t_{k+1} = (1 + sqrt(1 + 4*t_k^2))/2
```

This gives O(1/k^2) convergence rate, which is much better than O(1/k) for plain proximal gradient.

Multi-phase optimizer: FISTA + L-BFGS continuation + local search.
Key innovations: FISTA with simplex projection for fast progress,
symmetry exploitation, and adaptive beta scheduling.

import numpy as np
from scipy.optimize import minimize
import time

def _next_pow2(n):
    k = 1
    while k < n:
        k <<= 1
    return max(2, k)

def _full_convolve(a, b):
    n, m = len(a), len(b)
    out_n = n + m - 1
    N = _next_pow2(out_n)
    fa = np.fft.rfft(a, N)
    fb = np.fft.rfft(a if b is a else b, N)
    r = np.fft.irfft(fa * fb, N)[:out_n]
    return r

def _score_norm(a):
    n = len(a)
    c = _full_convolve(a, a)
    return float(2.0 * n * c.max())

def _project_simplex(v, target=1.0):
    n = len(v)
    if n == 0:
        return v.copy()
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - target)
    if not np.any(cond):
        return np.full(n, target / n)
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - target) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)

def _ls_value_and_grad(y, beta):
    """Compute logsumexp value and gradient w.r.t. y for the convolution max."""
    n = len(y)
    c = _full_convolve(y, y)
    c_max = c.max()
    # Safe beta
    b = min(beta, 500.0 / max(c_max, 1e-15))
    c_shifted = (c - c_max) / b
    e = np.exp(c_shifted)
    s = e.sum()
    if s < 1e-300:
        val = c_max
        w = np.zeros_like(c)
        w[int(np.argmax(c))] = 1.0
    else:
        val = c_max + b * float(np.log(s))
        w = e / s
    # Gradient: grad[j] = sum_{k valid} w[k] * y[k-j]
    # = cross-correlation of w and y
    N_fft = _next_pow2(2 * n)
    Y = np.fft.fft(y, N_fft)
    W = np.fft.fft(w, N_fft)
    grad = np.fft.ifft(W * np.conj(Y)).real[:n]
    return val, grad, c_max

def _softmax(z):

def _make_profile(n, kind, params=None):
    """Create various profile types."""
    if params is None:
        params = {}
    t = np.linspace(0.0, 1.0, n)
    u = 2.0 * t - 1.0  # in [-1, 1]
    
    if kind == 'uniform':
        a = np.ones(n)
    elif kind == 'linear':
        slope = params.get('slope', 1.0)
        a = 1.0 + slope * u
    elif kind == 'quadratic':
        a1 = params.get('a1', 0.5)
        a2 = params.get('a2', 0.3)
        a = 1.0 + a1 * u + a2 * u * u
    elif kind == 'bathtub':
        depth = params.get('depth', 0.5)
        a = 1.0 - depth * np.cos(np.pi * t)  # high at edges
    elif kind == 'gaussian':
        width = params.get('width', 0.3)
        a = np.exp(-((t - 0.5) ** 2) / (2.0 * width ** 2))
    elif kind == 'raised_cosine':
        alpha = params.get('alpha', 1.0)
        a = 0.5 * (1.0 + np.cos(2.0 * np.pi * (t - 0.5) * alpha))
    elif kind == 'power':
        p = params.get('p', 2.0)
        a = (1.0 - np.abs(u)) ** p
    elif kind == 'cosh':

        a = np.cosh(k * u)  # U-shaped
    elif kind == 'sech':
        k = params.get('k', 2.0)
        a = 1.0 / np.cosh(k * u)  # peaked in middle
    else:
        a = np.ones(n)
    
    a = np.maximum(a, 1e-12)
    return a / a.sum()
