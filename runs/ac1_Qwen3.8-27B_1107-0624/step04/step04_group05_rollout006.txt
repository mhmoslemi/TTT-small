Actually, (a*a)_k = sum_i a_i * a_{k-i} (with valid indices). This is a bilinear form, but since we're correlating a with itself shifted, it's a quadratic form.

Let me write it as: (a*a)_k = a^T B_k a where (B_k)_{ij} = 1 if i + j = k (with valid indices), and we need to be careful about the factor of 1/2 for off-diagonal.

Actually: a^T B_k a = sum_{i,j} B_{ij} a_i a_j. If B_{ij} = 1 when i+j=k (i≠j) and B_{ii} = 1 when 2i=k, then:
a^T B_k a = sum_{i: 2i=k} a_i^2 + sum_{i≠j, i+j=k} a_i a_j = (a*a)_k

So B_k is a matrix with 1s on the "anti-diagonal" i+j=k (within the valid range). This matrix is symmetric. Is it positive semidefinite?

B_k is essentially a permutation matrix (part of a reversal matrix). The eigenvalues of a reversal matrix are ±1. So B_k has eigenvalues +1 and -1 (for the part within the valid range). Therefore B_k is NOT positive semidefinite in general.

This means (a*a)_k is NOT a convex function of a in general. The optimization is non-convex.

However, for a >= 0, (a*a)_k >= 0, and the function is still "nice" in some sense. The max of non-convex quadratics is also non-convex.

So we're dealing with a non-convex optimization problem. This explains why heuristics are needed.

**Given the non-convexity, let me focus on practical improvements:**

1. **More diverse starting points**: Try more profile types, including:
   - "Sawtooth" profiles: a_j = (j+1)/n^2 (linearly increasing)
   - "Step" profiles: a_j = 1/m for j < m, 0 otherwise (for various m)
   - "Double bump" profiles with different parameters
   - Profiles optimized to have specific spectral properties

2. **Longer runs on the best candidate**: Instead of spreading time across many candidates, focus most of the time on the single best candidate.

3. **Hybrid approach**: Alternate between:
   - Global optimization (Adam) to explore
   - Local optimization (LP, coordinate descent) to exploit

4. **New: "Peak shaving" via projected gradient**:
   - Compute the subgradient of f(a) = max_k (a*a)_k at the current a
   - The subgradient is in the convex hull of the gradients of the active (a*a)_k's
   - Take a step in the negative subgradient direction
   - Project back to a >= 0, sum(a) = 1

5. **New: "Mutual information" approach**:
   - Think of a as a probability distribution
   - The convolution a*a is the distribution of X+Y where X and Y are i.i.d. with distribution a
   - We want to minimize the peak of X+Y
   - This is like finding a distribution that makes the sum of two i.i.d. copies as "flat" as possible
   - This is related to the "central limit theorem" - the sum tends to be Gaussian, which has a peak
   - But we want to MINIMIZE the peak, so we want the opposite of CLT behavior
   - This suggests using a distribution that's as "anti-concentrated" as possible

Actually, this is a great way to think about it! We want a distribution on {0, 1, ..., n-1} such that the sum of two i.i.d. copies has minimum peak.

The CLT says that for "typical" distributions, the sum tends to be approximately Gaussian, with peak ≈ 1/sqrt(2π*variance). To minimize the peak, we want to maximize the variance of the sum, which means maximizing the variance of a.

The maximum variance of a distribution on {0, ..., n-1} is achieved by putting mass at the two endpoints: P(0) = P(n-1) = 1/2, variance = (n-1)^2/4.

But as I computed earlier, this gives a terrible convolution peak at the center (c_{n-1} = 1/2).

So there's a tradeoff: high variance helps spread out the sum, but the "gap" in the middle creates a high peak at the center of the convolution.

The optimal solution balances these effects. It's probably a distribution that's "bimodal" but with some mass in the middle to fill the gap.

This suggests that good profiles are:
- Bimodal with peaks near the edges
- Some mass in the middle to reduce the center peak
- The exact shape balances the edge peaks vs. center peak

The previous program's best profiles seem to be in this family (asymmetric profiles with more mass on one side).

Key improvements over the previous program:
1. **More aggressive LP refinement** with bisection on M
2. **Subgradient descent** on the max convolution (new)
3. **Better time allocation** - spend more time on the best candidate
4. **More diverse initializations** including bimodal profiles
5. **Coordinate perturbation** for escaping local minima
6. **Better hyperparameter tuning** for Adam

"""
Optimized step function search combining:
1. Diverse bimodal/asymmetric profile initialization
2. Adam optimization in logit space with adaptive smooth-max
3. LP best-response with bisection on M
4. Subgradient descent on peak convolution
5. Coordinate perturbation for local minima escape
6. Multi-restart with time-based allocation
Targets score < 1.5027.
"""
import numpy as np
from scipy.optimize import linprog
from scipy.sparse import csr_matrix
import time


def _next_pow2(n):
    k = 1
    while k < n:
        k <<= 1
    return max(2, k)


def _full_convolve(a):
    a = np.asarray(a, dtype=np.float64).ravel()
    n = a.size
    if n == 0:
        return np.array([])
    if n <= 512:
        c = np.convolve(a, a)
    else:
        N = _next_pow2(2 * n - 1)
        fa = np.fft.rfft(a, N)
        c = np.fft.irfft(fa * fa, N)[:2 * n - 1]
        c = np.maximum(c, 0.0)
    return c


def _smooth_max_and_weights(c, beta):
    c = np.asarray(c, dtype=np.float64).ravel()
    mval = float(c.max())
    if beta < 1e-13:
        w = np.zeros_like(c)
        mask = c >= mval - 1e-9
        cnt = int(mask.sum())
        if cnt == 0:
            w[int(np.argmax(c))] = 1.0
        else:
            w[mask] = 1.0 / cnt
        return mval, w
    x = (c - mval) / beta
    ex = np.exp(np.minimum(x, 0.0))
    s = float(ex.sum())
    if not np.isfinite(s) or s <= 0.0:
        ex = np.zeros_like(c)
        ex[int(np.argmax(c))] = 1.0
        s = 1.0
    val = mval + beta * float(np.log(s))
    w = ex / s
    return val, w


def _conv_cross_corr(w, p):
    """
    Compute the gradient of sum_k w_k * (p*p)_k with respect to p.
    (p*p)_k = sum_j p_j * p_{k-j}
    d/dp_i [sum_k w_k * (p*p)_k] = sum_k w_k * (p_{k-i} + p_{k-i} if diagonal)
    = 2 * (w * p_reversed)_i - correction for diagonal
    Actually: d(p*p)/dp_i = p_{k-i} for each k, summed over k with weight w_k
    = sum_k w_k * p_{k-i} (where p_{k-i} is valid only when 0 <= k-i < n)
    This is a cross-correlation of w with p.
    """
    n = len(p)
    N = _next_pow2(2 * n - 1)
    fw = np.fft.rfft(w, N)
    # Cross-correlation: sum_k w_k * p_{k-i}
    # This is the same as the convolution of w with reversed p, shifted
    fp_rev = np.fft.rfft(p[::-1], N)
    h = np.fft.irfft(fw * fp_rev, N)
    return h[n - 1:2 * n - 1]


def _softmax_from_z(z, floor=1e-14):
    z = np.asarray(z, dtype=np.float64).ravel()
    z = np.clip(z, -60.0, 60.0)
    z = z - float(np.max(z))
    e = np.exp(z)
    p = e + floor
    s = float(p.sum())
    if not np.isfinite(s) or s <= 0.0:
        p = np.ones_like(e) / float(e.size)
    else:
        p = p / s
    return p


def _normalize_nonneg(a):
    a = np.asarray(a, dtype=np.float64).ravel()
    a = np.clip(a, 1e-15, 1000.0)
    s = float(a.sum())
    if not np.isfinite(s) or s <= 1e-30:
        return None
    return a / s


def _score_norm(p):
    n = len(p)
    c = _full_convolve(p)
    return float(2.0 * n * c.max())


def _build_conv_matrix(a):
    """Build sparse matrix A such that (A @ b)_k = (a * b)_k (cross-convolution)."""
    n = len(a)
    rows = []
    cols = []
    vals = []
    for k in range(2 * n - 1):
        j_start = max(0, k - n + 1)
        j_end = min(n - 1, k)
        if j_start <= j_end:
            idx = np.arange(j_start, j_end + 1)
            rows.extend([k] * len(idx))
            cols.extend(idx.tolist())
            vals.extend(a[k - idx].tolist())
    A = csr_matrix((vals, (rows, cols)), shape=(2 * n - 1, n))
    return A


def _lp_solve(a, M):
    """Solve LP: max sum(b) s.t. (a*b)_k <= M for all k, b >= 0."""
    n = len(a)
    A_ub = _build_conv_matrix(a)
    c_obj = -np.ones(n)
    b_ub_arr = M * np.ones(2 * n - 1)
    bounds = [(0, None)] * n
    res = linprog(c_obj, A_ub=A_ub, b_ub=b_ub_arr, bounds=bounds, method='highs')
    if res.success:
        return np.maximum(res.x, 0.0)
    return None


def _lp_refine_bisection(a, deadline, max_iters=80):
    """
    LP refinement with bisection on M.
    For each iteration:
    1. Find the minimum M* (by bisection) such that the LP is feasible
       and gives a b with max(b*b) < current max(a*a)
    2. Update a toward b
    """
    n = len(a)
    current_best = a.copy()
    current_score = _score_norm(a)
    c = _full_convolve(a)
    M_cur = float(c.max())
    
    t_step = 0.3
    stall_count = 0
    
    for it in range(max_iters):
        if time.monotonic() > deadline:
            break
        
        # Bisection on M: find smallest M such that LP gives b with lower peak
        M_lo = M_cur * 0.3
        M_hi = M_cur
        
        # First check if M_cur works
        b = _lp_solve(a, M_cur)
        if b is None:
            break
        s_b = float(b.sum())
        if s_b < 1e-10:
            break
        b_norm = b / s_b
        sc_b = _score_norm(b_norm)
        
        if sc_b >= current_score:
            # Try smaller M
            found = False
            for _ in range(5):
                M_mid = (M_lo + M_hi) / 2
                b_mid = _lp_solve(a, M_mid)
                if b_mid is None:
                    M_hi = M_mid
                    continue
                s_mid = float(b_mid.sum())
                if s_mid < 1e-10:
                    M_hi = M_mid
                    continue
                b_mid = b_mid / s_mid
                sc_mid = _score_norm(b_mid)
                if sc_mid < current_score:
                    b = b_mid
                    s_b = s_mid
                    b_norm = b_mid
                    found = True
                    M_lo = M_mid
                else:
                    M_hi = M_mid
            if not found:
                stall_count += 1
                if stall_count > 8:
                    break
                # Try a random perturbation
                a = a + 0.01 * np.random.randn(n)
                a = np.maximum(a, 1e-12)
                a = a / a.sum()
                M_cur = float(_full_convolve(a).max())
                continue
            else:
                M_cur = M_mid
        else:
            M_lo = M_cur
        
        # Line search for step size
        best_sc = current_score
        best_t = 0.0
        for tc in [0.1, 0.15, 0.2, 0.25, 0.3, 0.4, 0.5, 0.6]:
            a_try = (1.0 - tc) * a + tc * b_norm
            a_try = np.maximum(a_try, 1e-12)
            a_try = a_try / a_try.sum()
            sc_try = _score_norm(a_try)
            if sc_try < best_sc:
                best_sc = sc_try
                best_t = tc
        
        if best_t == 0.0:
            stall_count += 1
            if stall_count > 8:
                break
            # Perturb
            a = a + 0.005 * np.random.randn(n)
            a = np.maximum(a, 1e-12)
            a = a / a.sum()
            M_cur = float(_full_convolve(a).max())
            continue
        
        a_new = (1.0 - best_t) * a + best_t * b_norm
        a_new = np.maximum(a_new, 1e-12)
        a_new = a_new / a_new.sum()
        sc_new = _score_norm(a_new)
        
        if sc_new < current_score - 1e-12:
            current_score = sc_new
            current_best = a_new.copy()
            stall_count = 0
        else:
            stall_count += 1
            if stall_count > 10:
                break
        
        a = a_new
        c = _full_convolve(a)
        M_cur = float(c.max())
    
    return current_best, current_score


def _subgradient_descent(a, deadline, lr=0.01, max_iters=2000):
    """
    Subgradient descent on f(a) = max_k (a*a)_k.
    The subgradient at a is the average of gradients of active (a*a)_k.
    """
    n = len(a)
    current_best = a.copy()
    current_score = _score_norm(a)
    a_cur = a.copy()
    
    for it in range(max_iters):
        if time.monotonic() > deadline:
            break
        
        c = _full_convolve(a_cur)
        c_max = float(c.max())
        
        # Find active set (entries within 1% of max)
        threshold = c_max * 0.99
        active = c >= threshold
        n_active = int(active.sum())
        if n_active == 0:
            active[int(np.argmax(c))] = True
            n_active = 1
        
        # Average gradient of active convolution entries
        # grad of (a*a)_k w.r.t. a_i = a_{k-i} + a_{k-i} (for i != k-i) or 2*a_i (for i = k-i)
        # Simplified: grad = sum_{k active} a_{k-i} (cross-correlation of active mask with a)
        w = active.astype(np.float64) / n_active
        g = _conv_cross_corr(w, a_cur)
        
        # Project gradient to maintain sum constraint
        g = g - float(np.mean(g))
        
        # Step
        a_new = a_cur - lr * g
        a_new = np.maximum(a_new, 1e-12)
        a_new = a_new / a_new.sum()
        
        sc = _score_norm(a_new)
        if sc < current_score - 1e-12:
            current_score = sc
            current_best = a_new.copy()
            a_cur = a_new
        else:
            a_cur = a_new  # Still move (to explore)
        
        # Decay learning rate
        lr = max(0.0001, lr * 0.999)
    
    return current_best, current_score


def _adam_logit(p0, deadline, rng, lr=0.05, beta_frac=0.08, beta_decay=0.93,
                no_imp_limit=500):
    p0 = np.asarray(p0, dtype=np.float64).ravel()
    p0 = np.maximum(p0, 1e-12)
    p0 = p0 / p0.sum()
    n = p0.size
    
    z = np.log(p0)
    z -= float(np.mean(z))
    
    b1, b2, eps = 0.9, 0.999, 1e-8
    m = np.zeros(n)
    v = np.zeros(n)
    t_adam = 0
    
    p = p0.copy()
    c = _full_convolve(p)
    maxc = float(c.max())
    beta = max(1e-4, beta_frac * maxc)
    
    best_p = p0.copy()
    best_z = z.copy()
    best_score = float(2.0 * n * maxc)
    no_imp = 0
    base_lr = lr
    
    while time.monotonic() < deadline:
        _, w = _smooth_max_and_weights(c, beta)
        g = _conv_cross_corr(w, p)
        
        vp = g
        dot = float(np.dot(p, vp))
        gz = p * (vp - dot)
        gz -= float(np.mean(gz))
        
        if not np.all(np.isfinite(gz)):
            z = best_z.copy()
            m.fill(0.0)
            v.fill(0.0)
            t_adam = 0
            continue
        
        t_adam += 1
        m = b1 * m + (1.0 - b1) * gz
        v = b2 * v + (1.0 - b2) * (gz * gz)
        mh = m / (1.0 - b1 ** t_adam)
        vh = v / (1.0 - b2 ** t_adam)
        z = z - lr * mh / (np.sqrt(vh) + eps)
        
        if not np.all(np.isfinite(z)):
            z = best_z.copy()
            m.fill(0.0)
            v.fill(0.0)
            t_adam = 0
            continue
        
        z = np.clip(z, -60.0, 60.0)
        z -= float(np.mean(z))
        p = _softmax_from_z(z)
        c = _full_convolve(p)
        maxc = float(c.max())
        score = float(2.0 * n * maxc)
        
        if np.isfinite(score):
            if score < best_score - 1e-14:
                best_score = score
                best_p = p.copy()
                best_z = z.copy()
                no_imp = 0
            else:
                no_imp += 1
                if no_imp % 200 == 0:
                    lr = max(0.005, lr * 0.93)
        else:
            z = best_z.copy()
            m.fill(0.0)
            v.fill(0.0)
            t_adam = 0
            continue
        
        if t_adam % 30 == 0:
            beta = max(5e-5, beta * beta_decay)
            if c.size >= 2:
                top5 = np.sort(c)[::-1][:5]
                gap = top5[0] - top5[-1]
                if gap < beta * 0.05:
                    beta = max(5e-5, beta * 0.7)
        
        if no_imp > no_imp_limit:
            ns = 0.05 if best_score < 1.51 else 0.1
            z = best_z + ns * rng.normal(size=n)
            z = np.clip(z, -60.0, 60.0)
            z -= float(np.mean(z))
            p = _softmax_from_z(z)
            c = _full_convolve(p)
            maxc = float(c.max())
            beta = max(1e-4, beta_frac * maxc)
            m.fill(0.0)
            v.fill(0.0)
            t_adam = 0
            lr = base_lr
            no_imp = 0
    
    return best_p, best_score


def _coordinate_perturb(a, deadline, n_trials=5000):
    """Random coordinate perturbation (hill climbing)."""
    n = len(a)
    rng = np.random.default_rng(12345)
    current_best = a.copy()
    current_score = _score_norm(a)
    a_cur = a.copy()
    
    for trial in range(n_trials):
        if time.monotonic() > deadline:
            break
        
        # Pick a random coordinate and perturb it
        i = rng.integers(0, n)
        delta = rng.normal(0, 0.01)
        a_try = a_cur.copy()
        a_try[i] = max(1e-12, a_try[i] + delta)
        a_try = a_try / a_try.sum()
        
        sc = _score_norm(a_try)
        if sc < current_score:
            current_score = sc
            current_best = a_try.copy()
            a_cur = a_try
    
    return current_best, current_score


def _make_profile_linear(n, eta):
    t = np.linspace(0.0, 1.0, n)
    a = 1.0 + eta * (t - 0.5)
    a = np.maximum(a, 1e-12)
    return a / a.sum()


def _make_profile_exponential(n, lam, direction=1):
    t = np.arange(n, dtype=np.float64)
    if direction == 1:
        a = np.exp(-lam * t / n)
    else:
        a = np.exp(-lam * (n - 1 - t) / n)
    a = np.maximum(a, 1e-12)
    return a / a.sum()


def _make_profile_bimodal(n, c1, c2, s1, s2):
    t = np.linspace(0.0, 1.0, n)
    a = np.exp(-0.5 * ((t - c1) / s1) ** 2) + np.exp(-0.5 * ((t - c2) / s2) ** 2)
    a = np.maximum(a, 1e-12)
    return a / a.sum()


def _make_profile_cosine(n, freq, amp, phase=0.0):
    t = np.arange(n, dtype=np.float64)
    a = 1.0 + amp * np.cos(2.0 * np.pi * freq * t / n + phase)
    a = np.maximum(a, 1e-12)
    return a / a.sum()


def _make_profile_quadratic(n, a1, a2):
    t = np.linspace(0.0, 1.0, n)
    a = 1.0 + a1 * t + a2 * t * t
    a = np.maximum(a, 1e-12)
    return a / a.sum()


def _make_profile_cubic(n, a1, a3):
    t = np.linspace(0.0, 1.0, n)
    u = 2.0 * t - 1.0
    a = 1.0 + a1 * u + a3 * u ** 3
    a = np.maximum(a, 1e-12)
    return a / a.sum()


def _make_profile_asym_gauss(n, center, width, skew):
    t = np.linspace(0.0, 1.0, n)
    x = (t - center) / width
    a = np.exp(-0.5 * x * (x + skew))
    a = np.maximum(a, 1e-12)
    return a / a.sum()


def _make_profile_bell_asym(n, center, width_r, width_l):
    """Asymmetric bell: different widths on left and right."""
    t = np.linspace(0.0, 1.0, n)
    x = t - center
    a = np.where(x >= 0, np.exp(-0.5 * (x / width_r) ** 2),
                 np.exp(-0.5 * (x / width_l) ** 2))
    a = np.maximum(a, 1e-12)
    return a / a.sum()


def _make_profile_power_law(n, alpha, direction=1):
    """Power-law decay profile."""
    t = np.arange(1, n + 1, dtype=np.float64)
    if direction == 1:
        a = t ** (-alpha)
    else:
        a = (n + 1 - t) ** (-alpha)
    a = np.maximum(a, 1e-12)
    return a / a.sum()


def _interp_profile(p0, n_new):
    p0 = np.asarray(p0, dtype=np.float64).ravel()
    n0 = p0.size
    if n0 == n_new:
        return _normalize_nonneg(p0)
    x0 = np.linspace(0.0, 1.0, n0)
    x1 = np.linspace(0.0, 1.0, n_new)
    return _normalize_nonneg(np.interp(x1, x0, p0))


def propose_candidate(seed=42, budget_s=1800, **kwargs):
    t_start = time.monotonic()
    deadline = t_start + max(10.0, float(budget_s) - 8.0)
    rng = np.random.default_rng(int(seed) % (2**63 - 1))
