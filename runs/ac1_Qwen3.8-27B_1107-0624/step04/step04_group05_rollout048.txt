So the problem is: minimize `max_k sum_i a[i]*a[k-i]` (over valid i) subject to `sum(a) = 1, a >= 0`.

This is a much more interesting problem! Now the question is: what's the optimal sequence?

For a symmetric (palindromic) sequence, c[n-1] = sum(a_i * a[n-1-i]) = sum(a_i^2) (since a is palindromic). So for palindromic sequences, the issue is different.

For non-palindromic sequences, the convolution peak can be elsewhere.

Let me think about this differently. The convolution `c = a * a` (using numpy) has the property that `c[k] = <a, shift_k(reverse(a))>` where shift_k is a circular... no, linear shift.

Actually, let's think of it in the Fourier domain. The DFT of the convolution is the product of the DFTs: `C = A * A` (element-wise). So `|C| = |A|^2` (since A is real). The peak of c is related to the peak of `|A|^2` in a different sense (it's an inverse DFT).

Actually, `c = IDFT(DFT(a) * DFT(a))` (with appropriate zero-padding). So `c = IDFT(|A|^2)` (for real a). The peak of c is the maximum of the inverse DFT of `|A|^2`.
