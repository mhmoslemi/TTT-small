For f(x) = (α+1)x^α on [0,1]:
(f*f)(x) for x in [0,1] = (α+1)^2 * B(α+1, α+1) * x^{2α+1}
At x=1: (α+1)^2 * Γ(α+1)^2/Γ(2α+2)

Score = 2*(α+1)^2 * Γ(α+1)^2/Γ(2α+2)

Using Stirling's approximation for large α:
Γ(α+1) ≈ √(2πα) * (α/e)^α
Γ(2α+2) ≈ √(4πα) * (2α/e)^{2α}

So Γ(α+1)^2/Γ(2α+2) ≈ 2πα * (α/e)^{2α} / (√(4πα) * (2α/e)^{2α})

For large α, this goes to 0! So in principle, we can make the score arbitrarily small by using a very steep power law!

But wait, there's a catch. In the discrete case, if the sequence is very concentrated (most of the mass at one end), then c[0] = a[0]^2 (or c[2n-2] = a[n-1]^2) might be large.

For a[i] ∝ (i+1)^α, the largest element is a[n-1] ∝ n^α. So c[2n-2] = a[n-1]^2 ∝ n^{2α}. And sum(a) ∝ n^{α+1}. So c[2n-2]/(sum)^2 ∝ n^{2α}/n^{2α+2} = 1/n^2. And the score contribution from this term is 2n * 1/n^2 = 2/n.

Meanwhile, the center term c[n-1] ∝ n^{2α} * n / n^{2α+2} = 1/n (roughly). Score contribution: 2n/n = 2.

Hmm wait, let me be more careful. For a[i] = (i+1)^α (unnormalized):
sum = sum_{i=1}^{n} i^α ≈ n^{α+1}/(α+1)
c[n-1] = sum_{i=1}^{n} i^α * (n+1-i)^α ≈ n^{2α} * ∫0^1 t^α(1-t)^α dt = n^{2α} * B(α+1,α+1) = n^{2α} * Γ(α+1)^2/Γ(2α+2)

Score = 2n * c[n-1] / (sum)^2 ≈ 2n * n^{2α} * Γ(α+1)^2/Γ(2α+2) / (n^{2α+2}/(α+1)^2)
= 2 * (α+1)^2 * Γ(α+1)^2/Γ(2α+2)

Which is the same as the continuous formula! So the asymptotic score for the power law is:
S(α) = 2*(α+1)^2 * Γ(α+1)^2/Γ(2α+2)

Let me compute this for various α:

So as α increases, the score decreases rapidly! The theoretical minimum is 0 (as α→∞).
