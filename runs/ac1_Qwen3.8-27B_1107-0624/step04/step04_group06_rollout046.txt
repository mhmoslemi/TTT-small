Let me think about this differently. The score is:

The constraints are:

- sum a[i] = 1
- a[0]^2 <= max_val (corner peak)
- (2a[0]*a[1] + ...) <= max_val (near-corner peaks)
- ...
- sum a[i]*a[n-1-i] <= max_val (center peak)
- ...
- a[n-1]^2 <= max_val (other corner peak)

We want to minimize max_val.

This is a non-convex problem (min of max of quadratics), but we can approach it iteratively.

**New approach: Iterative Peak Reduction**

1. Start with a initial guess (e.g., the parent sequence)
2. Identify the current maximum peak location k*
3. Compute the gradient of (a*a)[k*] with respect to a
4. Use a projected gradient step to reduce this peak
5. Repeat, but also consider the top-K peaks simultaneously

The gradient of (a*a)[k] with respect to a[i] is:
d/d a[i] [(a*a)[k]] = a[k-i] + a[i-k] (with appropriate bounds, treating a[j] = 0 for j out of range)

Actually more carefully:
(a*a)[k] = sum_j a[j]*a[k-j]
d/d a[i] = a[k-i] + a[i-k] (if both indices are valid)

So the subgradient of max_k (a*a)[k] is a convex combination of these gradients for the active peaks.
