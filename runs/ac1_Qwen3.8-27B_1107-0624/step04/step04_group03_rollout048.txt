r^{n-1} * n vs r^{2n-1-1/ln(r)} * 1/ln(r)

Ratio = [r^{2n-1-1/ln(r)} * 1/ln(r)] / [r^{n-1} * n]
= r^{n-1/ln(r)} * 1/(n*ln(r))

Let u = n*ln(r) (this is c in my parametrization). Then 1/ln(r) = n/u.
= r^{n-n/u} * 1/(n * u/n) = r^{n(1-1/u)} * 1/u
= (e^{ln(r)})^{n(1-1/u)} * 1/u = e^{u(1-1/u)} * 1/u = e^{u-1} / u

So the ratio is e^{u-1}/u. This is > 1 when e^{u-1} > u, i.e., when u-1 > ln(u), i.e., when u > 1 (approximately; for u=1, e^0=1 and ln(1)=0, so 1>0, ratio = 1/1 = 1).

More precisely: e^{u-1} > u ⟺ u-1 > ln(u). For u > 1, u-1 > ln(u) is true (by the inequality ln(x) < x-1 for x ≠ 1, applied to x = u).

So for u > 1 (c > 1), the max is in the right half:
max = r^{2n-1-1/ln(r)} * 1/ln(r) = e^{(2n-1-1/ln(r))*ln(r)} / ln(r)
= e^{(2n-1)*ln(r) - 1} / ln(r)
= e^{2u - ln(r) - 1} / ln(r)  [since (2n-1)*ln(r) = 2n*ln(r) - ln(r) = 2u - ln(r)]
≈ e^{2u-1} / ln(r)  [for large n, ln(r) = u/n is small]

And sum^2 = [(r^n-1)/(r-1)]^2 = [(e^u - 1)/(u/n)]^2 = n^2 * (e^u-1)^2 / u^2

Score = 2n * max / sum^2 = 2n * e^{2u-1}/ln(r) / (n^2 * (e^u-1)^2/u^2)
= 2 * e^{2u-1} * u^2 / (n * ln(r) * (e^u-1)^2)
= 2 * e^{2u-1} * u^2 / (n * (u/n) * (e^u-1)^2)
= 2 * e^{2u-1} * u^2 / (u * (e^u-1)^2)
= 2 * e^{2u-1} * u / (e^u-1)^2
= 2u * e^{2u-1} / (e^u-1)^2
= 2u * e^{2u-1} / (e^u-1)^2

Let me verify for u = c = 3:
= 2*3 * e^{5} / (e^3-1)^2 = 6 * 148.4 / (19.09)^2 = 890.4 / 364.4 = 2.443
