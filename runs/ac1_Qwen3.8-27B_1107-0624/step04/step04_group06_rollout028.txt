```python
def _score_norm(p):
    n = len(p)
    c = _full_convolve(p)
    return float(2.0 * n * c.max())

def _sca_step(a, M_target=None):
    """One SCA iteration: solve the LP linearization."""
    n = len(a)
    c = _full_convolve(a)
    
    # Build constraint matrix A where row k is h_k (the cross-correlation profile)
    # A[k, j] = a[k-j] if 0 <= k-j < n, else 0
    rows = []
    cols = []
    vals = []
    for k in range(2 * n - 1):
        j_start = max(0, k - n + 1)
        j_end = min(n - 1, k)
        for j in range(j_start, j_end + 1):
            rows.append(k)
            cols.append(j)
            vals.append(2.0 * a[k - j])
    
    A = csr_matrix((vals, (rows, cols)), shape=(2 * n - 1, n))
    
    # Constraint: A a - M <= c  =>  A a - [0,...,0,1] [a;M] <= c
    # We have variables (a_0, ..., a_{n-1}, M)
    # A_ub has shape (2n-1, n+1): the a-part is A, the M-part is -I
    A_ub = csr_matrix(np.hstack([np.asarray(A.todense()), -np.eye(2*n-1)]))
    # This is dense! For n=1024, it's 2047 x 1025 ≈ 2M entries. Should be OK.
    
    b_ub = c.copy()  # 2*sum a_j h_k(j) - M <= c_k
    
    # Objective: minimize M, i.e., c_obj = [0,...,0,1]
    c_obj = np.zeros(n + 1)
    c_obj[-1] = 1.0
    
    # Bounds: a_j >= 0, M is free
    bounds = [(0, None)] * n + [(None, None)]
    
    # Equality constraint: sum a_j = 1
    A_eq = np.zeros((1, n + 1))
    A_eq[0, :n] = 1.0
    b_eq = np.array([1.0])
    
    res = linprog(c_obj, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq,
                  bounds=bounds, method='highs')
    
    if res.success:
        a_new = np.maximum(res.x[:n], 0.0)
        a_new = a_new / a_new.sum()
        return a_new, float(res.x[n])
    return None, None
```

Let me also think about the convergence of SCA. The key question is: does SCA converge to a local minimum for this problem? 

In general, SCA converges to a stationary point if:
1. The linearization is a valid upper bound (the "locally tight" approximation property).
2. The step is accepted only if it improves the objective.

For our problem, the linearization of $(a*a)_k$ around $a^{(t)}$ is:
$(a*a)_k \approx c_k + 2 \sum_j (a_j - a_j^{(t)}) a_{k-j}^{(t)}$

This is NOT an upper bound for $(a*a)_k$ in general (quadratic functions can be above or below their linearization). So SCA might not converge in the standard sense. However, in practice, if we use a line search (only accept steps that improve the objective), we should still make progress.

A better approach: use the "concave-convex procedure" (CCCP) or "difference of convex functions" (DC) method. But our objective is not naturally a difference of convex functions.

Alternatively, we can use a "majorization-minimization" (MM) approach:
1. Find a (possibly loose) upper bound on $(a*a)_k$ that is linear in a and tight at the current point.
2. Minimize the sum of these upper bounds.
3. Update.

For $(a*a)_k = \sum_i a_i a_{k-i}$, a valid upper bound is:
$(a*a)_k \leq \max_i a_i^{(t)} \cdot \sum_i a_i$ (by replacing $a_{k-i}$ with its max)

But this is very loose. A tighter bound:
$(a*a)_k \leq \sum_i a_i \cdot \max(a_{k-i}^{(t)}, a_{k-i})$

This is still not linear. 

Actually, for the SCA approach, I think the key is to use a "step size" parameter:
$a^{new} = (1-\lambda) a + \lambda a_{LP}$

where $\lambda \in (0, 1]$ is chosen by a line search. This ensures that we stay close to the current point and the linearization remains approximately valid.

Let me also think about a different formulation: instead of minimizing M, we can minimize a weighted sum of the convolution coefficients:
$\sum_k w_k (a*a)_k$

where $w_k$ are chosen to emphasize the peak. This is a standard quadratic objective, and we can use a QP solver.

But the LP approach should be sufficient and faster.
