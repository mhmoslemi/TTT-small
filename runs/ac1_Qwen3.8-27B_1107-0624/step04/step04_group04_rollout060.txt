Active-set subgradient optimization for minimizing 2*n*max(conv(a,a))/sum(a)^2.
Uses exact active set gradients with backtracking line search,
combined with L-BFGS polish and multi-length search.
"""

import time
from scipy.optimize import minimize

def _next_pow2(n):
    k = 1
    while k < n:
        k <<= 1
    return max(2, k)

def _full_convolve(a, b):
    n, m = len(a), len(b)
    out_n = n + m - 1
    N = _next_pow2(out_n)
    fa = np.fft.rfft(a, N)
    fb = np.fft.rfft(b, N)
    r = np.fft.irfft(fa * fb, N)[:out_n]
    return r

def _score_norm(a):
    n = len(a)
    c = _full_convolve(a, a)
    return float(2.0 * n * c.max())

def _score_fn(a):
    n = len(a)
    s = float(a.sum())
    if s < 1e-15:
        return np.inf
    c = _full_convolve(a, a)
    return float(2.0 * n * c.max() / (s * s))

def _project_simplex(v):
    """Project v onto probability simplex {x >= 0, sum(x) = 1}."""
    n = len(v)
    if n == 1:
        return np.ones(1)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.arange(1, n + 1)
    cond = u * rho > (cssv - 1.0)
    if not np.any(cond):
        return np.ones(n) / n
    rho_val = rho[cond][-1]
    theta = (cssv[rho_val - 1] - 1.0) / rho_val
    return np.maximum(v - theta, 0.0)

    """
    Compute the average gradient of conv(a,a)[k] for k in [k_min, k_max].
    grad[m] = (2/L) * sum_{j = max(0, k_min-m)}^{min(n-1, k_max-m)} a[j]
    where L = k_max - k_min + 1.

    prefix_hi = np.zeros(n)
    prefix_lo[valid] = prefix[lo[valid]]
    prefix_hi[valid] = prefix[hi[valid] + 1]
    
    sums = prefix_hi - prefix_lo
    return (2.0 / L) * sums

Actually, I just realized something important. The gradient I computed is:
∂conv[k]/∂a[m] = 2 * a[k-m] (if 0 <= k-m < n)

This means the gradient of conv[k] is 2 * (a flipped and shifted by k). In the frequency domain, this is 2 * exp(2πi*k*m/N) * A(ω) (for circular convolution). For linear convolution, it's similar but with the zero-padding.

grad[m] = (2/|A|) * sum_{k in A} a[k-m] * I(0 <= k-m < n)

In the frequency domain:
FFT(grad)[ω] = (2/|A|) * sum_{k in A} exp(2πi*k*ω/N) * FFT(a)[ω] (approximately, for circular)

This is a "filtering" operation: the active set gradient is the sequence a filtered by the transfer function H(ω) = (2/|A|) * sum_{k in A} exp(2πi*kω/N).

If A is a contiguous block [k_min, k_max], then H(ω) is a Dirichlet kernel (sinc-like function) centered at ω=0 with bandwidth proportional to 1/(k_max-k_min).

This means the active set gradient is a "low-pass filtered" version of a (for small active sets) or a "high-pass filtered" version (for large active sets). This makes sense: a small active set gives a sharp gradient (pointing in a specific direction), while a large active set gives a smooth gradient (averaging over many directions).

Let me also think about one more potential improvement: **the "dual ascent" method**.

The dual variable λ_k corresponds to the "weight" of constraint k. At the optimum, λ_k = 0 for inactive constraints and λ_k > 0 for active ones, with sum_k λ_k = 1.

I could iteratively:
1. Given current λ (weights on the constraints), solve the QP: min sum_k λ_k * conv(a,a)[k] s.t. sum(a) = 1, a >= 0
2. Update λ: λ_k = max(0, λ_k + η * (conv(a,a)[k] - t)) where t is the current max

This is the "dual ascent" or "multiplicative weights" approach. It's related to the "column generation" method in LP.

The QP in step 1 has Hessian H = sum_k λ_k * H_k, which is a weighted sum of the individual Hessian matrices. If λ is spread over many k's, H is better conditioned (more isotropic), which helps the QP solver.
