One more thought: the "active set" method. At the optimum, the KKT conditions say that the gradient of the objective (which is a weighted average of the gradients of the active $c_k$'s) should be in the normal cone of the feasible set. For the simplex constraint ($\sum a = 1, a \geq 0$), this means:
- If $a_j > 0$: the $j$-th component of the gradient should be constant (equal to the Lagrange multiplier).
- If $a_j = 0$: the $j$-th component of the gradient should be $\geq$ the Lagrange multiplier.

The gradient of $c_k$ with respect to $a_j$ is $2a_{k-j}$ (when $0 \leq k-j \leq n-1$). So the weighted gradient is:
$g_j = 2 \sum_k w_k a_{k-j}$ (summed over active $k$'s with weights $w_k$).

At the optimum, $g_j$ should be constant for all $j$ with $a_j > 0$.

This gives a system of equations that can be solved iteratively. But it's a fixed-point iteration, not a direct solve.

An alternative: use the "follow-the-regularized-leader" or "mirror descent" approach:
1. Start with $a$ and compute $c = a * a$.
2. Find the active set: $S = \{k : c_k \geq M - \epsilon\}$ for a small $\epsilon$.
3. Compute the weighted gradient $g_j = 2 \sum_{k \in S} w_k a_{k-j}$.
4. Update: $a_j \leftarrow a_j - \eta (g_j - \bar{g})$ where $\bar{g} = \sum_j a_j g_j$ (to maintain the constraint).
5. Project back onto the simplex.
6. Repeat.

This is essentially gradient descent on the max function, which should converge (albeit slowly) to a local minimum.
