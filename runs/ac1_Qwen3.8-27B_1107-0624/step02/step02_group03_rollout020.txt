OK this is getting too complicated with the gradient computation. Let me take a step back and think about what will actually work best.

The key insight is: **this is a convex optimization problem**. The function `f(a) = max_k conv(a,a)_k` is convex in `a`, and we're minimizing it over the simplex `{a >= 0, sum(a) = 1}`.

The best approaches for this:
1. **Cutting plane / bundle method**: This is essentially what the LP approach does. At each step, we find a direction that violates the current bound, then move in that direction.

2. **Subgradient method with Nesterov acceleration**: Simple but can be slow.

3. **Proximal gradient on the smoothed problem**: Smooth the max with log-sum-exp, then use mirror descent.

I think the most promising approach is to **improve the LP-based method** with:
- Better line search
- Adaptive M (try slightly tighter bounds)
- Symmetry enforcement
- Multi-start with different initializations

Let me also think about the **dual problem**. The primal is:
```
minimize max_k (a*a)_k
subject to sum(a) = 1, a >= 0
```

Introduce variable t:
```
minimize t
subject to (a*a)_k <= t for all k
         sum(a) = 1
         a >= 0
```

The dual (Lagrangian) would involve:
- Multipliers λ_k >= 0 for the constraints (a*a)_k <= t
- Multiplier ν for sum(a) = 1
- Multipliers μ_i >= 0 for a_i >= 0

This is complicated because of the quadratic constraints.

Let me focus on a practical approach. I'll combine:
1. LP-based direction finding (the main workhorse)
2. A simple subgradient method as a backup
3. Multi-resolution (start at n=128, go to n=256, then n=512)
4. Symmetry enforcement (a[i] = a[n-1-i])

For the symmetry, if I enforce it, I only need to optimize n/2 variables. This halves the LP size and might help convergence.

Actually, let me think about whether symmetry is truly optimal. By convexity, if `a` is optimal, then `(a + reverse(a))/2` is also optimal and is symmetric. So yes, we can WLOG assume symmetry.

Strategy: LP-based cutting plane method with symmetry enforcement,

    """Objective: 2*n*max(conv(a,a))/sum(a)^2"""
    n = len(a)
    s = float(a.sum())
    if s < 1e-30:
        return np.inf
    c = np.convolve(a, a)
    return float(2.0 * n * c.max() / (s * s))

def project_simplex(v):
    """Project v onto the probability simplex {x >= 0, sum(x) = 1}."""
    n = len(v)
    if n == 0:
        return v
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.nonzero(u * np.arange(1, n + 1) > (cssv - 1))[0][[-1]]
    theta = (cssv[rho] - 1) / (rho + 1.0)
    w = np.maximum(v - theta, 0)
    return w

        if g is None:
            break
        
        # Adaptive line search
        best_t, best_s = 0.0, best_sc
        # Try full step first
        sc_g = 2.0 * n * float(np.convolve(g, g).max())
        if sc_g < best_sc - 1e-12:
            best_t, best_s = 1.0, sc_g
        else:
            for t in [0.7, 0.5, 0.3, 0.2, 0.1, 0.05]:
                fn = norm1((1 - t) * f + t * g)
                fn = sym(fn)
                if fn is None:
                    continue
                sn = 2.0 * n * float(np.convolve(fn, fn).max())
                if sn < best_s:
                    best_s, best_t = sn, t
        
        if best_t > 0 and best_s < best_sc - 1e-14:
            f = norm1((1 - best_t) * f + best_t * g)
            f = sym(f)
            best_f, best_sc = f.copy(), best_s
            M = float(np.convolve(f, f).max())
            no_imp = 0
            it += 1
            if verbose and it % 25 == 0:
                print(f"    LP iter {it}: score={best_sc:.10f}, t={best_t:.2f}")
        else:
            no_imp += 1
    
    return best_f, best_sc

def subgrad_polish(f_init, deadline, verbose=True):
    """Subgradient method with momentum on the max-conv objective."""
    n = len(f_init)
    f = sym(f_init)
    f = norm1(f)
    if f is None:
        return None, np.inf
    
    best_f = f.copy()
    best_sc = obj(f)
    
    # Momentum
    v = np.zeros(n)
    beta1, beta2 = 0.9, 0.999
    it = 0
    lr = 0.05
    
    # Softmax temperature
    beta_smooth = 0.1 * float(np.convolve(f, f).max())
    
    while time.monotonic() < deadline:
        it += 1
        
        c = np.convolve(f, f)
        max_c = float(c.max())
        
        # Soft argmax weights
        x = (c - max_c) / beta_smooth
        w = np.exp(x)
        w_sum = w.sum()
        if w_sum > 0:
            w = w / w_sum
        else:
            w = np.zeros_like(c)
            w[np.argmax(c)] = 1.0
        
        # Subgradient
        # s_j = 2 * sum_k w_k * f_{k-j} (zero-padded)
        s = np.zeros(n)
        for j in range(n):
            k_end = min(n, 2 * n - 1 - j)
            if k_end > 0:
                s[j] = 2.0 * np.dot(w[j:j + k_end], f[:k_end])
        
        # Add small regularization
        s += 1e-10 * f
        
        # Adam update
        # (simplified: just use a fixed step with momentum)
        v = beta1 * v + (1 - beta1) * s
        s_hat = v / (1 - beta1 ** it)
        
        # Step size: decrease over time
        eta = lr / np.sqrt(it + 1)
        
        f_new = f - eta * s_hat
        
        # Project onto simplex with symmetry
        # First project
        f_new = project_simplex_sym(f_new, n)
        
        sc = obj(f_new)
        if sc < best_sc - 1e-15:
            best_sc = sc
            best_f = f_new.copy()
        
        f = f_new
        
        # Decrease smoothing
        if it % 1000 == 0:
            beta_smooth = max(1e-6, beta_smooth * 0.8)
        
        if verbose and it % 5000 == 0:
            print(f"    Subgrad iter {it}: score={best_sc:.10f}")
    
    return best_f, best_sc

def project_simplex_sym(v, n):
    """Project v onto {x >= 0, sum(x) = 1, x symmetric}."""
    # First enforce symmetry
    v = sym(v)
    # Then project onto simplex
    n = len(v)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.nonzero(u * np.arange(1, n + 1) > (cssv - 1))[0]
    if len(rho) == 0:
        return np.ones(n) / n
    rho = rho[-1]
    theta = (cssv[rho] - 1) / (rho + 1.0)
    w = np.maximum(v - theta, 0)
    # Re-enforce symmetry after projection
    w = sym(w)
    w = norm1(w)
    return w
