```
1. Start with initial logits z (where a = softmax(z) * S_target)
2. Repeat until deadline:
   a. Compute a = softmax(z) (normalized to sum=1)
   b. Compute c = conv(a, a)
   c. Compute w = softmax(c / beta)
   d. Compute grad_z = gradient of L(z) = logsumexp(c/beta) w.r.t. z
      (using the chain rule: dL/dz = diag(a) * (grad_a - dot(a, grad_a)))
   e. Adam step on z
   f. Decay beta
3. Return the best a found
```

The chain rule for the log-space parametrization:
- `a_i = exp(z_i) / sum_j exp(z_j)` (softmax)
- `∂a_i/∂z_j = a_i * (δ_{ij} - a_j)`
- `∂L/∂z_j = sum_i (∂L/∂a_i) * (∂a_i/∂z_j) = sum_i grad_a[i] * a_i * (δ_{ij} - a_j)`
  `= a_j * (grad_a[j] - sum_i grad_a[i] * a_i)`
  `= a_j * (grad_a[j] - dot(grad_a, a))`

So `grad_z = a * (grad_a - dot(grad_a, a))` which is the standard "softmax gradient" formula.

This is clean and efficient.

The smooth surrogate is `2n * logsumexp(c/beta)`. As `beta -> 0`, this approaches `2n * max(c)`.

```python
Multi-phase optimization for minimizing 2n*max(conv(a,a))/sum(a)^2.
Uses smooth-max gradient descent in log-space with FFT-based gradients,
adaptive temperature, and multi-start strategy.
"""
import numpy as np
import time

def compute_score(a):
    """Compute 2n * max(conv(a,a)) / sum(a)^2."""
    a = np.asarray(a, dtype=np.float64).ravel()
    n = a.size
    if n == 0:
        return np.inf
    s = float(a.sum())
    if s < 0.01:
        return np.inf
    c = np.convolve(a, a)
    return float(2.0 * n * float(c.max()) / (s * s))

def next_pow2(n):
    k = 1
    while k < n:
        k <<= 1
    return max(2, k)

def full_convolve_fft(a):
    """Full linear convolution using FFT."""
    n = a.size
    N = next_pow2(2 * n - 1)
    fa = np.fft.rfft(a, N)
    c = np.fft.irfft(fa * fa, N)[:2 * n - 1]
    return np.maximum(c, 0.0)  # numerical safety

def softmax_z(z):
    """Numerically stable softmax."""
    z = z - float(np.max(z))
    e = np.exp(z)
    s = e.sum()
    return e / s

def logit_optimize(a_init, deadline, rng, lr=0.05, beta_init=None, beta_decay=0.995):
    """Optimize using smooth-max gradient descent in log-space."""
    a = np.asarray(a_init, dtype=np.float64).ravel().copy()
    a = np.maximum(a, 1e-15)
    a = a / a.sum()
    n = a.size
    
    if beta_init is None:
        c0 = full_convolve_fft(a)
        beta_init = 0.1 * float(c0.max())
    
    z = np.log(a)
    z -= float(np.mean(z))  # center for numerical stability
    
    # Adam state
    b1, b2, eps = 0.9, 0.999, 1e-8
    m = np.zeros(n)
    v = np.zeros(n)
    t = 0
    
    beta = beta_init
    best_score = compute_score(a)
    best_a = a.copy()
    no_imp = 0
    base_lr = lr
    
    while time.monotonic() < deadline:
        # Compute convolution
        c = full_convolve_fft(a)
        
        # Compute weights (softmax of c/beta)
        w = softmax_z(c / beta)
        
        # Compute grad_a using FFT
        N = next_pow2(3 * n)
        a_r = a[::-1]
        fa_r = np.fft.rfft(a_r, N)
        fw = np.fft.rfft(w, N)
        conv_w_ar = np.fft.irfft(fw * fa_r, N)

        grad_z -= float(np.mean(grad_z))
        
        # Numerical check
        if not np.all(np.isfinite(grad_z)):
            z = np.log(best_a)
            z -= float(np.mean(z))
            m.fill(0.0)
            v.fill(0.0)
            t = 0
            continue
        
        # Adam update
        t += 1
        m = b1 * m + (1 - b1) * grad_z
        v = b2 * v + (1 - b2) * (grad_z * grad_z)

            a = softmax_z(z)
```
