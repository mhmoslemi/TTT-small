The problem of minimizing the peak-to-average ratio of the autocorrelation (or convolution in this case) is related to the "sidelobe suppression" problem in radar/sonar. The optimal waveform for minimum peak sidelobe level (PSL) is known to be related to the "Cardinal LCM" or "minimum PSL" design.

For the unconstrained case (complex waveforms), the optimal sequences are related to "Barker sequences" (for small n) or "Golay complementary pairs". But for the non-negative real case, the problem is different.

One approach from the literature: use the "MSE" (minimum energy) method or "RLS" (recursive least squares) method to iteratively reduce the peak sidelobe. The basic idea is:
1. Start with an initial sequence a
2. Compute c = conv(a, a)
3. Identify the peak: k* = argmax c[k]
4. Update: a ← a - μ * ∇c[k*] / ||∇c[k*]||^2 (gradient step to reduce c[k*])
5. Project onto {a >= 0, sum(a) = 1}
6. Repeat

This is essentially a projected subgradient method. The issue is that it only reduces one peak at a time and might oscillate.

A better approach is to use all peaks simultaneously:
1. Compute c = conv(a, a)
2. Compute weights w_k ∝ c[k]^p for large p (or w_k = 1 if c[k] is in the top few, 0 otherwise)
3. Update: a ← a - μ * sum_k w_k * ∇c[k] / ||sum_k w_k * ∇c[k]||^2
4. Project onto {a >= 0, sum(a) = 1}
5. Repeat
