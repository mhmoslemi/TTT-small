def fast_score(s):
    """Compute 2n*max(conv(s,s))/(sum(s))^2."""
    n = len(s)
    total = s.sum()
    if total < 1e-15:
        return float('inf')
    conv = np.convolve(s, s)
    return 2.0 * n * conv.max() / (total * total)

def subgradient_max_conv(s):
    """
    Compute the subgradient of max_k conv(s,s)[k] with respect to s.
    Returns (gradient, active_lags, max_val).
    """
    n = len(s)
    conv = np.convolve(s, s)
    max_val = conv.max()
    # Active set: lags where conv is close to max
    tol = max_val * 1e-6
    active = np.where(conv >= max_val - tol)[0]
    
    # For each active lag k, the gradient w.r.t. s[j] is:

                if k == 2 * j:
                    grad[j] += 0.5 * s[j]  # 0.5 because we're averaging over active set
                else:
                    grad[j] += 0.5 * s[kj]
    grad /= len(active)

            break
        
        conv = np.convolve(s, s)
        k_star = conv.argmax()
        max_conv = conv[k_star]
        
        # Compute gradient
        grad = np.zeros(n)
        for j in range(n):
            idx = k_star - j
            if 0 <= idx < n:
                if k_star == 2 * j:

                else:
                    grad[j] = 2.0 * s[idx]

        # (optional: add gradients from other peaks with smaller weight)

        if grad_max < 1e-15:

        # Line search
        best_eta = eta

            if best_obj < best_score - 1e-12:

Actually, for a monotonically increasing sequence s[0] < s[1] < ... < s[n-1]:
conv[n-1] = sum_i s[i]*s[n-1-i]
This pairs s[0] with s[n-1], s[1] with s[n-2], etc.
By the rearrangement inequality, this is the MINIMUM of all possible pairings!

So a monotone sequence minimizes the center convolution value! This is a key insight.

But we also need to check the other lags. For a monotone sequence, the other lags might be higher.

Let me explore this. For s = [1, 2, 3, ..., n]:
sum = n(n+1)/2
conv[n-1] = sum_i i*(n+1-i) = (n+1)*sum(i) - sum(i^2) = (n+1)*n(n+1)/2 - n(n+1)(2n+1)/6
= n(n+1)[(n+1)/2 - (2n+1)/6] = n(n+1)(3n+3-2n-1)/6 = n(n+1)(n+2)/6

max(conv) ≥ conv[n-1] = n(n+1)(n+2)/6

Objective ≥ 2*n * n(n+1)(n+2)/6 / (n(n+1)/2)^2
= 2*n * n(n+1)(n+2)/6 / (n^2(n+1)^2/4)
= 2*n * 4(n+2) / (6*n*(n+1))
= 8(n+2) / (6(n+1))
= 4(n+2)/(3(n+1))
→ 4/3 as n→∞

So for large n, a monotonically increasing sequence gives an objective approaching 4/3 ≈ 1.333! That's well below the target of 1.5027!

But we need to check the other lags. For a linearly increasing sequence, what are the other convolution values?

s = [1, 2, ..., n] (n elements)

For d = 1: sum_{i=1}^{n-1} (i+1)*i = sum(i^2 + i) from 1 to n-1
