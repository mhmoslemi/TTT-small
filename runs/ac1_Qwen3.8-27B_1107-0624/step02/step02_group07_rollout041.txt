**Alternative: Semidefinite Programming / Moment Methods**

The constraints `conv(s,s)[m] <= t` for all m can be written as quadratic constraints. For fixed m, `conv(s,s)[m] = sum_k s[k]*s[m-k] <= t`. This is a quadratic constraint.

For non-negative s, these are actually convex constraints! Because if s >= 0, then the function `f(s) = sum_k s[k]*s[m-k]` is... hmm, is it convex?

`f(s) = sum_k s[k]*s[m-k]`. The Hessian of f is: for the term s[k]*s[m-k], the second derivatives are d^2/ds[k]^2 = 0, d^2/ds[m-k]^2 = 0, d^2/(ds[k]ds[m-k]) = 1.

So the Hessian has 1's at positions (k, m-k) and (m-k, k). This is not positive semidefinite in general (it has eigenvalues 1 and -1 for 2x2 blocks). So f is not convex.

However, if we restrict to the case where k = m-k (i.e., m is even and k = m/2), then the term is s[m/2]^2 which is convex. The cross terms are not convex.

So the problem is non-convex. We need heuristics.

Let me think about what makes this problem tractable:

1. The problem is scale-invariant (normalization doesn't matter).
2. The feasible set (s >= 0, sum(s) = 1) is a simplex.
3. The objective is the max of linear functions of (s⊗s) where ⊗ denotes the appropriate tensor product.

But the quadratic form is not convex (as I showed above), so the QP is non-convex. However, for the specific structure of the problem (the bilinear form sum_k s[k]*s[m-k]), there might be a special structure we can exploit.

For m = n-1: `c[n-1] = sum_k s[k]*s[n-1-k]`. Let's define the pairing: for k < n-1-k, the term is s[k]*s[n-1-k], and for k = n-1-k (only if n is odd), the term is s[(n-1)/2]^2.

So `c[n-1] = sum_{k < n-1-k} s[k]*s[n-1-k] + (possibly s[(n-1)/2]^2)`.

This is like a "matching" problem: we're pairing up elements of s and summing the products. To minimize this, we want to pair large elements with small elements.

By the rearrangement inequality, the minimum of `sum s[k]*s[n-1-k]` over permutations of s is achieved when one sequence is sorted ascending and the other descending. But here the pairing is fixed (k is paired with n-1-k), so we can't permute.

However, we CAN choose s! So the question is: what non-negative s with sum = 1 minimizes `sum_k s[k]*s[n-1-k]`?

For even n = 2m: `c[n-1] = sum_{k=0}^{2m-1} s[k]*s[2m-1-k] = 2*sum_{k=0}^{m-1} s[k]*s[2m-1-k]` (since the pairing is symmetric).

To minimize this with sum(s) = 1 and s >= 0: by the rearrangement inequality, the minimum is achieved when we make one of each pair (s[k], s[2m-1-k]) as large as possible and the other as small as possible.

Specifically, if we set s[0] = 1 and all others = 0, then `c[n-1] = s[0]*s[2m-1] = 0`. But then `c[0] = s[0]^2 = 1`, so the max of conv is 1, and the objective is `2n*1/1 = 2n`. That's terrible.

So we need to balance: minimize the peak of the ENTIRE convolution, not just one lag.

**Another idea: Use the structure of the problem**

We want `IDFT(S(ω)^2)` to be as flat as possible. This means we want `S(ω)^2` to be as concentrated at DC as possible (since a flat time-domain signal has all its energy at DC in the frequency domain).

This means we want `S(ω) ≈ 0` for ω ≠ 0, which means s is approximately uniform. But uniform s gives a triangular conv, not flat.

The resolution: we can't make S(ω)^2 perfectly concentrated at DC while keeping s >= 0. The optimal solution balances these constraints.

```python
import numpy as np
import time
from scipy.optimize import linprog

"""
Iterative pressure-equalization algorithm for minimizing the peak of self-convolution
of non-negative sequences. Uses FFT-based cross-correlation for efficient gradient
computation, adaptive annealing, LP refinement, and diverse initialization.
"""


def fast_score(s):
    """Compute 2n*max(conv(s,s))/(sum(s))^2 efficiently."""
    n = len(s)
    total = np.sum(s)
    if total < 1e-15:
        return float('inf')
    conv = np.convolve(s, s)
    return float(2.0 * n * np.max(conv) / (total * total))


def compute_pressure_fft(s, w, N):
    """
    Compute pressure[k] = sum_j w[j+k] * s[j] for k=0..n-1.
    This is the cross-correlation (w cross-correlate s) at lags 0..n-1.
    Uses FFT for O(n log n) computation.
    """
    n = len(s)
    W = np.fft.rfft(w, N)
    S = np.fft.rfft(s, N)
    # Cross-correlation: IFFT(conj(W) * S)
    result = np.fft.irfft(np.conj(W) * S, N)[:n]
    return result


def pressure_optimize(s, deadline, rng, use_lp=True, verbose=False):
    """
    Main optimization loop using pressure equalization with adaptive annealing.
    Minimizes max(conv(s,s)) subject to s >= 0, sum(s) = 1.
    """
    n = len(s)
    s = s.copy().astype(np.float64)
    s = np.maximum(s, 0.0)
    total = s.sum()
    if total < 1e-15:
        s = np.ones(n) / n
        total = 1.0
    s = s / total

    best_s = s.copy()
    best_score = fast_score(s)
    current_score = best_score

    # FFT size (need N >= 2*(2n-1) + n for cross-correlation without aliasing)
    N = 1
    while N < 4 * n + 10:
        N *= 2

    # Parameters
    eta = 0.8
    beta = 4.0
    no_improve = 0
    patience = 80
    momentum = np.zeros(n)
    mom_rate = 0.7

    it = 0
    while time.monotonic() < deadline:
        it += 1

        # Compute convolution
        conv = np.convolve(s, s)
        peak = conv.max()
        current_score = 2.0 * n * peak  # sum(s) = 1

        # Anneal beta: start high (focus on peak), decrease over time
        # But maintain minimum emphasis
        beta = max(2.0, 8.0 * np.exp(-it / 500.0) + 2.0)

        # Compute weights emphasizing peaks
        # w[m] = exp(beta * (conv[m] - peak) / peak)
        # At peak: w = 1. At mean: w = exp(-beta*(peak-mean)/peak)
        scaled = beta * (conv - peak) / max(peak, 1e-15)
        w = np.exp(scaled)

        # Compute pressure via FFT cross-correlation
        pressure = compute_pressure_fft(s, w, N)

        # Center pressure for redistribution
        p_mean = np.mean(pressure)
        p_std = np.std(pressure)
        if p_std < 1e-15:
            break

        # Momentum-smoothed update direction
        direction = (pressure - p_mean) / p_std
        momentum = mom_rate * momentum + (1 - mom_rate) * direction

        # Adaptive step size
        # Use the standard deviation of the direction to normalize
        dir_range = np.max(momentum) - np.min(momentum)
        if dir_range < 1e-15:
            break

        effective_eta = eta * min(1.0, dir_range)

        # Multiplicative update
        log_update = -effective_eta * momentum
        # Clip to prevent numerical issues
        log_update = np.clip(log_update, -3.0, 3.0)
        s_new = s * np.exp(log_update)
        s_new = np.maximum(s_new, 0.0)
        s_sum = s_new.sum()
        if s_sum < 1e-10:
            s_new = s.copy()
            s_new[-1] += 1 - s_new.sum()
        else:
            s_new = s_new / s_sum

        # Evaluate new score
        new_score = fast_score(s_new)

        if new_score < best_score - 1e-12:
            best_score = new_score
            best_s = s_new.copy()
            no_improve = 0
            s = s_new
            current_score = new_score
        elif new_score < current_score * 1.001:
            # Accept slightly worse for exploration
            s = s_new
            current_score = new_score
            no_improve += 1
        else:
            no_improve += 1

        # Adaptive parameter adjustment
        if no_improve >= patience:
            eta *= 0.85
            no_improve = 0
            if eta < 0.05:
                # More aggressive reset: add noise
                noise_scale = 0.05 * np.mean(s)
                s = s + noise_scale * rng.standard_normal(n)
                s = np.maximum(s, 1e-10)
                s = s / s.sum()
                eta = 0.8
                beta = rng.choice([3.0, 5.0, 8.0, 12.0])
                momentum *= 0.1
                no_improve = 0

        # Periodic LP refinement
        if use_lp and n <= 512 and it % 300 == 299:
            M = peak
            # Build constraint matrix: conv(s, b)[k] <= M for all k
            # conv(s,b)[k] = sum_j s[j] * b[k-j]
            # For each output k, the constraint is: sum_j s[j] * b[k-j] <= M
            # This is: for each k, sum_j s[j shifted] * b[j] <= M
            A = np.zeros((2 * n - 1, n))
            for j in range(n):
                # b[j] appears in conv[s, b][j], conv[s, b][j+1], ..., conv[s, b][j+n-1]
                # with coefficients s[0], s[1], ..., s[n-1]
                A[j:j + n, j] = s
            c_obj = -np.ones(n)  # maximize sum(b)
            b_ub = np.full(2 * n - 1, M)
            bounds = [(0.0, None)] * n
            try:
                res = linprog(c_obj, A_ub=A, b_ub=b_ub, bounds=bounds,
                             method='highs', options={'time_limit': 5.0, 'presolve': True})
                if res.success and res.x is not None:
                    b = np.maximum(res.x, 0.0)
                    b_sum = b.sum()
                    if b_sum > 1e-10:
                        b = b / b_sum
                        # Try various blend ratios
                        for t in [0.1, 0.2, 0.3, 0.5, 0.7]:
                            cand = (1.0 - t) * s + t * b
                            cand = np.maximum(cand, 0.0)
                            cand_sum = cand.sum()
                            if cand_sum > 1e-10:
                                cand = cand / cand_sum
                            sc = fast_score(cand)
                            if sc < best_score:
                                best_score = sc
                                best_s = cand.copy()
                                s = cand.copy()
                                current_score = sc
                                no_improve = 0
                                if verbose:
                                    print(f"    LP improvement: {sc:.6f} (t={t})")
                                break
            except Exception:
                pass

        # Periodic "kick" to escape local minima
        if it % 1000 == 999 and current_score > best_score * 1.001:
            # Random perturbation weighted by inverse pressure
            perturbation = rng.standard_normal(n) * 0.02 * np.mean(s)
            s = s + perturbation
            s = np.maximum(s, 1e-10)
            s = s / s.sum()
            current_score = fast_score(s)

    return best_s, best_score


def coordinate_descent_refine(s, deadline, rng, max_rounds=50):
    """
    Simple coordinate descent: try shifting mass between pairs of positions.
    """
    n = len(s)
    s = s.copy().astype(np.float64)
    s = np.maximum(s, 0.0) / s.sum()
    best_score = fast_score(s)
    best_s = s.copy()

    for rnd in range(max_rounds):
        if time.monotonic() > deadline:
            break
        improved = False
        # Random pair of indices
        for _ in range(200):
            if time.monotonic() > deadline:
                break
            i, j = rng.integers(0, n, size=2)
            if i == j:
                continue
            if s[i] < 1e-10 or s[j] < 1e-10:
                continue
            # Try moving mass from i to j (or vice versa)
            for frac in [0.01, 0.05, 0.1, 0.2, 0.5]:
                # Move from i to j
                amount = frac * s[i]
                s_trial = s.copy()
                s_trial[i] -= amount
                s_trial[j] += amount
                sc = fast_score(s_trial)
                if sc < best_score - 1e-12:
                    best_score = sc
                    best_s = s_trial.copy()
                    s = s_trial.copy()
                    improved = True
                    break
                # Move from j to i
                s_trial[i] = s[i]
                s_trial[j] = s[j] - frac * s[j]
                s_trial[i] += frac * s[j]
                sc = fast_score(s_trial)
                if sc < best_score - 1e-12:
                    best_score = sc
                    best_s = s_trial.copy()
                    s = s_trial.copy()
                    improved = True
                    break
        if not improved and rnd > 20:
            break

    return best_s, best_score


def generate_candidates(n, rng, hseq=None):
    """Generate diverse starting candidates for sequence of length n."""
    candidates = []

    def add_candidate(s, label):
        s = np.maximum(s, 0.0).astype(np.float64)
        total = s.sum()
        if total < 1e-10:
            return
        s = s / total
        sc = fast_score(s)
        candidates.append((sc, s.copy(), label))

    # Uniform
    add_candidate(np.ones(n), "uniform")

    # Height sequence (resized)
    if hseq is not None and len(hseq) > 10:
        x_old = np.linspace(0.0, 1.0, len(hseq))
        x_new = np.linspace(0.0, 1.0, n)
        h_r = np.interp(x_new, x_old, hseq)
        add_candidate(h_r, "height_seq")

        # If same length, use directly
        if len(hseq) == n:
            add_candidate(hseq, "height_seq_direct")

    # Cosine windows
    x = np.arange(n) / max(n - 1, 1)
    for alpha in [0.5, 1.0, 1.5, 2.0, 3.0]:
        s = np.cos(np.pi * alpha * x) ** 2
        add_candidate(s, f"cos_{alpha}")

    # Gaussian bumps
    for center in [0.3, 0.5, 0.7]:
        for width in [0.2, 0.35, 0.5]:
            s = np.exp(-((x - center) ** 2) / (2 * width**2))
            add_candidate(s, f"gauss_{center}_{width}")

    # Two-level
    for frac in [0.3, 0.4, 0.5, 0.6]:
        k = max(1, int(frac * n))
        for ratio in [0.3, 0.5, 2.0, 3.0]:
            s = np.ones(n)
            s[:k] = ratio
            add_candidate(s, f"two_level_{frac}_{ratio}")

    # Alternating
    s = np.ones(n)
    s[::2] = 1.5
    add_candidate(s, "alternating")
    s[::2] = 0.7
    add_candidate(s, "alternating_low")

    # Sine modulation
    for freq in [1, 2, 3, 4]:
        for amp in [0.1, 0.3, 0.5]:
            s = 1.0 + amp * np.sin(2 * np.pi * freq * np.arange(n) / n)
            add_candidate(s, f"sine_f{freq}_a{amp}")

    # Random
    for _ in range(5):
        s = rng.random(n) + 0.1
        add_candidate(s, "random")

    # Triangular (peak in center)
    s = np.abs(np.arange(n) - n / 2) + 1
    s = 1.0 / s
    add_candidate(s, "triangular")

    # Edge-enhanced
    s = np.ones(n)
    s[:n//4] = 2.0
    s[3*n//4:] = 2.0
    add_candidate(s, "edge_enhanced")

    candidates.sort(key=lambda x: x[0])
    return candidates
```
