```python
def minimize_1d(f, lo, hi, iters=40):
    """Golden section search."""
    golden = (5**0.5 - 1) / 2  # ~0.618
    a, b = lo, hi
    c = b - golden * (b - a)
    d = a + golden * (b - a)
    fc = f(c)
    fd = f(d)
    for _ in range(iters):
        if fc < fd:
            b = d
            d = c
            fd = fc
            c = b - golden * (b - a)
            fc = f(c)
        else:
            a = c
            c = d
            fc = fd
            d = a + golden * (b - a)
            fd = f(d)
    return (a + b) / 2
```

- s[1] appears when k-j=1, j=k-1: term is s[k-1]*s[1] (valid if 0<=k-1<2, i.e., k in [1,2])

For k=1: j=1 gives s[1]*s[0] = 0.5*0.25 = 0.125. j=k-1=0 gives s[0]*s[1] = 0.25*0.
