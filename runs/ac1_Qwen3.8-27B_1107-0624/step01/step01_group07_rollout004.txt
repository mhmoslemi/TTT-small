def compute_objective(a):
    """Compute 2*n*max(conv(a,a))/sum(a)^2."""
    n = len(a)
    S = a.sum()
    if S < 1e-10:
        return np.inf
    c = np.convolve(a, a, mode='full')
    return 2.0 * n * c.max() / (S * S)

def build_conv_matrix(a):
    """Build matrix A (shape 2n-1 x n) such that A @ g = convolve(a, g)."""
    n = len(a)
    A = np.zeros((2 * n - 1, n))
    for j in range(n):
        A[j:j + n, j] = a
    return A

def lp_direction(a, M, max_iter=1000):
    """Solve LP: max sum(g) s.t. conv(a,g) <= M, g >= 0."""
    n = len(a)
    if n > 2048:
        return None
    A = build_conv_matrix(a)
    c_obj = -np.ones(n)
    b_ub = np.full(2 * n - 1, M)
    bounds = [(0.0, None)] * n
    try:
        res = linprog(c_obj, A_ub=A, b_ub=b_ub, bounds=bounds, method='highs',
                      options={'maxiter': max_iter})
        if res.status == 0:
            return res.x
    except Exception:
        pass
    return None

def upsample(a, factor):
    """Upsample by inserting (factor-1) zeros between elements, then smooth."""
    n = len(a)
    # Insert zeros
    a_up = np.zeros(n * factor)
    a_up[::factor] = a
    # Smooth with a simple kernel
    k = factor // 2 + 1
    kernel = np.exp(-0.5 * (np.arange(-k, k+1) / (k*0.5)) ** 2)
    kernel = kernel / kernel.sum()
    a_up = np.convolve(a_up, kernel, mode='same')
    a_up = np.clip(a_up, 0, None)
    if a_up.sum() < 1e-10:
        a_up = a
    return a_up / a_up.sum()

For a[i] = r^i (i=0..n-1), r > 1:
sum(a) = (r^n - 1)/(r-1)
c[k] = sum_{valid i} r^i * r^{k-i} = sum r^k = (number of valid i) * r^k for k < n

Wait, that's interesting! For a geometric sequence, c[k] = r^k * (number of valid pairs) for the "inner" part.

Actually: c[k] = sum_i a[i]*a[k-i] = sum_i r^i * r^{k-i} = sum_i r^k = (number of valid i) * r^k

For k < n: valid i from 0 to k, so c[k] = (k+1) * r^k
For k >= n: valid i from k-n+1 to n-1, so c[k] = (2n-1-k) * r^k

The maximum is at either k = n-1 or k = n (boundary of the two regions):
c[n-1] = n * r^{n-1}
c[n] = (n-1) * r^n

c[n]/c[n-1] = (n-1)r/n

If (n-1)r < n, i.e., r < n/(n-1), then c[n-1] > c[n], so max is at k=n-1.
If r > n/(n-1), max is at k=n (or possibly further out).

For r = 1 (uniform): c[k] = k+1 for k<n, = 2n-1-k for k>=n. Max = n at k=n-1.
This gives the uniform case we already know (objective = 2).

For r slightly above 1: the sequence is slightly increasing, and the max shifts.

For r = n/(n-1) (the critical value): c[n-1] = c[n] = n * r^{n-1}.

Let's try r = 1.01 for n = 512:
r < n/(n-1) = 512/511 ≈ 1.002, so max is at k = n-1.
c[n-1] = n * r^{n-1} = 512 * 1.01^{511}

1.01^{511} ≈ e^{511*0.00995} ≈ e^{5.084} ≈ 161.4
c[n-1] ≈ 512 * 161.4 ≈ 82,637

objective = 2*512*82637/16200^2 = 1024*82637/262,440,000 ≈ 84,619,288/262,440,000 ≈ 0.322

Oh wait, I think I made an error. Let me reconsider.

For a[i] = r^i, the auto-convolution at lag k is:
c[k] = sum_{i: 0<=i<n, 0<=k-i<n} r^i * r^{k-i} = sum_{valid i} r^k

The number of valid i's for k < n is k+1 (i goes from 0 to k).
For k >= n, it's 2n-1-k (i goes from k-n+1 to n-1).

So c[k] = (k+1) * r^k for 0 <= k < n
c[k] = (2n-1-k) * r^k for n <= k <= 2n-2

For n=512, r=1.01:
c[511] = 512 * 1.01^511
c[512] = 511 * 1.01^512

Ratio c[512]/c[511] = (511/512) * 1.01 = 0.998 * 1.01 = 1.008 > 1

So c[512] > c[511]! The max is NOT at k=n-1.

Let me find where the max is. For k >= n: c[k] = (2n-1-k) * r^k
This is maximized when d/dk [(2n-1-k) * r^k] = 0
= -r^k + (2n-1-k) * r^k * ln(r) = 0
= -1 + (2n-1-k) * ln(r) = 0
= 2n-1-k = 1/ln(r)
= k = 2n-1-1/ln(r)

For r=1.01: ln(r) ≈ 0.00995, 1/ln(r) ≈ 100.5
k = 2*512-1-100.5 = 923.5

But k only goes up to 2n-2 = 1022.
