Given a sequence a (length n), padded to length N >= 2n-1:
- A(ω) = DFT_N(a) (zero-padded DFT)
- The circular autocorrelation is c[k] = IDFT_N(|A(ω)|^2)[k]
- The linear autocorrelation is a "unwrapped" version of c

We want to minimize max of the linear autocorrelation. A necessary condition is that the circular autocorrelation is small everywhere.

The power spectrum |A(ω)|^2 has N values. Its geometric mean is (product |A(ω)|^2)^{1/N} = (product |A(ω)|)^{2/N}.

By AM-GM: mean(|A(ω)|^2) >= (geometric mean of |A(ω)|^2).

The mean of |A(ω)|^2 is N * mean(|a|^2) (by Parseval, with appropriate normalization).

So we want |A(ω)|^2 to be as close to constant as possible.

**Spectral algorithm:**
1. Compute A = DFT(a, N)
2. Compute target magnitude: |A_target(ω)| = (|A(ω)| * |A(0)|)^α for some 0 < α < 1 (geometric mean with the DC component, raised to α).
   - Actually, |A(0)| = sum(a) is the DC component.
   - We want other frequencies to have similar magnitude to DC.
   - |A_target(ω)| = |A(ω)|^(1-α) * |A(0)|^α for α in (0,1]. This pulls peaks down and valleys up.
3. Preserve the phase: A_new(ω) = |A_target(ω)| * exp(i * angle(A(ω)))
4. a_new = IDFT(A_new)
5. Project: a_new = max(0, a_new), renormalize to sum = 1.
6. Iterate.

This is similar to the "error reduction" algorithm in phase retrieval, but applied to the magnitude constraint in the frequency domain.

The parameter α controls the aggressiveness: α=1 means set all magnitudes to |A(0)| (perfect flattening), α=0 means no change.

"""

import time
import numpy as np
import scipy.optimize as so

def next_pow2(m):
    L = 1
    while L < m:
        L <<= 1
    return L

def norm_nonneg(a):
    a = np.asarray(a, dtype=np.float64).ravel()
    if a.size == 0:
        return np.ones(16)
    a = np.clip(a, 0.0, 1000.0)
    s = a.sum()
    if s < 1e-12:
        return np.ones(a.size)
    return a / s

def score_fft(a, direct=1024):
    """Compute score = 2*n*max(conv)/sum^2 using FFT for speed."""
    a = np.asarray(a, dtype=np.float64).ravel()
    n = a.size
    if n == 0:
        return np.inf
    a = np.clip(a, 0.0, 1000.0)
    s = a.sum()
    if s < 1e-10:
        return np.inf
    if n <= direct:
        c = np.convolve(a, a)
    else:
        L = next_pow2(2*n - 1)
        P = np.fft.rfft(a, L)
        c = np.fft.irfft(P*P, L)[:2*n-1]
    c = np.maximum(c, 0.0)
    m = c.max()
    return 2.0 * n * m / (s*s)

def greedy(n):

def lp_direction(f, M, max_iters=50, time_limit=60.0):

    """
    n = len(f)
    ncons = 2*n - 1

        for k in range(ncons):
            lo = max(0, k - n + 1)
            hi = min(k, n - 1)
            if lo <= hi:

        c = -np.ones(n)

        except Exception:
            return None, 0.0
        if res is None or not res.success or res.x is None:

    else:

            except Exception:

            if res is None or not res.success or res.x is None:

                return None, 0.0

def spectral_flatten(a, n_iter=200, time_budget=30.0):
    """Spectral flattening: iteratively reduce peaks in the power spectrum."""
    n = len(a)
    f = norm_nonneg(a).copy()
    t0 = time.monotonic()
    best_f = f.copy()
    best_score = score_fft(f)
    
    N = next_pow2(2*n - 1)
    
    for it in range(n_iter):
        if time.monotonic() - t0 > time_budget:
            break
        
        A = np.fft.rfft(f, N)
        mag = np.abs(A)
        phase = A / (mag + 1e-30)
        
        # Target: flatten the magnitude
        # DC component is fixed (sum of f)
        dc = mag[0]
        # Geometric mean of non-DC magnitudes
        non_dc_mag = mag[1:]
        log_mean = np.log(np.maximum(non_dc_mag, 1e-30)).mean()
        target_mag = np.exp(log_mean)
        
        # Blend: pull magnitudes toward target
        alpha = 0.3  # aggressiveness
        new_mag = np.maximum(mag, 1e-30)
        new_mag = new_mag ** (1-alpha) * np.concatenate([[dc], np.full(len(non_dc_mag), target_mag)]) ** alpha
        new_mag[0] = dc  # preserve DC
        
        new_A = new_mag * phase
        new_f = np.fft.irfft(new_A, N)[:n]
        new_f = np.maximum(new_f, 0)
        ns = new_f.sum()
        if ns < 1e-10:
            break
        new_f = new_f / ns
        
        sc = score_fft(new_f)
        if sc < best_score:
            best_score = sc
            best_f = new_f.copy()
            f = new_f
        else:
            # Try smaller alpha
            alpha = alpha * 0.5
            if alpha < 0.01:
                break
    
    return best_f, best_score
