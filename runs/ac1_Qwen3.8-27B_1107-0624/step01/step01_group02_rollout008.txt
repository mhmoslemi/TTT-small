**Softmax-smoothed subgradient:**
The objective (normalized) is $f(a) = 2n \cdot \max_k c[k]$.
We approximate $\max_k c[k] \approx \text{softmax}_\beta(c) = (1/\beta) \log \sum_k e^{\beta c[k]}$.
The gradient with respect to $a_j$ is:
$\frac{\partial}{\partial a_j} \text{softmax}_\beta(c) = \frac{1}{Z} \sum_k e^{\beta c[k]} \frac{\partial c[k]}{\partial a_j}$

where $Z = \sum_k e^{\beta c[k]}$ and $\frac{\partial c[k]}{\partial a_j} = a[k-j]$ (with $a[m] = 0$ for $m < 0$ or $m \geq n$).

So the gradient at coordinate $j$ is:
$\nabla_j = \frac{\sum_k e^{\beta c[k]} \cdot a[k-j]}{Z} \cdot 2n$

This can be computed efficiently using a weighted sum, which is essentially a cross-correlation of the softmax weights with $a$.

**LP direction:**
For a given $a$ with current peak $M = \max_k c[k]$, solve:
$$\max \sum_j g_j \quad \text{s.t.} \quad \sum_j a[k-j] g_j \leq M \text{ for all } k, \quad g_j \geq 0$$

The optimal $g$ gives a direction to move. If $\sum g > 1$, we can move towards $g$ (renormalized) to reduce the peak.

**Greedy coordinate descent:**
For each coordinate $j$, try adjusting $a[j]$ by a small amount (while maintaining non-negativity and maintaining the sum), and accept if it improves the score.

            if g.sum() > 1 + 1e-6:

        return np.ones(a.size) / a.size

def softmax_grad(a, beta, c=None):
    """Compute 2n * softmax_beta(c) cross-correlated with a."""
    n = a.size
    if c is None:
        c = np.convolve(a, a)
    # Softmax weights
    max_c = c.max()
    w = np.exp(beta * (c - max_c))
    sw = w.sum()
    if sw < 1e-300:
        w = np.zeros_like(c)
        w[c.argmax()] = 1.0
    else:
        w /= sw

    # = conv(w, a_flipped)[j + n - 1] where a_flipped = a[::-1]
    af = a[::-1]
    cf = np.convolve(w, af)
    grad = 2.0 * n * cf[n-1:2*n-1]
    return grad
