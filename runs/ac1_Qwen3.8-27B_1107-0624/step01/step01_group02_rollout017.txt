Actually, let me reconsider. The gradient of $\sum_k w_k (f*f)_k$ with respect to $f_i$ is:

$\frac{\partial}{\partial f_i} \sum_k w_k \sum_j f_j f_{k-j}$

$= \sum_k w_k \frac{\partial}{\partial f_i} (f*f)_k$

$= \sum_k w_k [f_{k-i} \cdot \mathbb{1}(0 \leq k-i < n) + f_{i-k} \cdot \mathbb{1}(0 \leq i-k < n)]$

$= \sum_k w_k f_{k-i} \cdot \mathbb{1}(0 \leq k-i < n) + \sum_k w_k f_{i-k} \cdot \mathbb{1}(0 \leq i-k < n)$

For the first term: let $j = k-i$, so $k = i+j$, $j \in [0, n-1]$, $k \in [i, i+n-1]$.
$= \sum_{j=0}^{n-1} w_{i+j} f_j \cdot \mathbb{1}(i+j \leq 2n-2)$

For the second term: let $j = i-k$, so $k = i-j$, $j \in [0, n-1]$, $k \in [i-n+1, i]$.
$= \sum_{j=0}^{n-1} w_{i-j} f_j \cdot \mathbb{1}(i-j \geq 0)$

So the gradient is:
$g_i = \sum_{j=0}^{n-1} w_{i+j} f_j + \sum_{j=0}^{n-1} w_{i-j} f_j$ (with appropriate bounds on the weights)

This is essentially $g = (w \star f) + (w \star f)_{\text{reversed}}$ where $\star$ denotes cross-correlation.

I can compute this using FFT:
- $a = \text{FFT}(w)$ (length $2n-1$)
- $b = \text{FFT}(f)$ (padded to length $\geq 3n-2$)
- Cross-correlation: $\text{IFFT}(a \cdot \overline{b})$

Actually, for the optimization, I don't need the exact gradient. I can use a subgradient of the max function, which is simpler:

The subgradient of $\max_k (f*f)_k$ at $f$ is any convex combination of the gradients of the active $(f*f)_k$ functions. If only one lag $k^*$ is active, the subgradient is the gradient of $(f*f)_{k^*}$.

The gradient of $(f*f)_{k^*}$ with respect to $f_i$ is:
$f_{k^*-i}$ (if $0 \leq k^*-i < n$) + $f_{i-k^*}$ (if $0 \leq i-k^* < n$)

So for a single active lag $k^*$:
$grad_i = f_{k^*-i} \cdot \mathbb{1}(0 \leq k^*-i < n) + f_{i-k^*} \cdot \mathbb{1}(0 \leq i-k^* < n)$

This is just a shifted and reversed version of $f$! Very cheap to compute.

For multiple active lags (soft-max), we average:
$grad_i = \sum_k w_k [f_{k-i} \cdot \mathbb{1}(0 \leq k-i < n) + f_{i-k} \cdot \mathbb{1}(0 \leq i-k < n)]$

This is the cross-correlation of $w$ and $f$, which I can compute with FFT.
