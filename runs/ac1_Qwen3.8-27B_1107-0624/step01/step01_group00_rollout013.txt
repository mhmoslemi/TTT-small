Hmm wait, I think there might be an issue with my Nesterov implementation. Let me use a simpler and more standard form:

Standard Nesterov (FISTA):
- $y_k = x_k + \frac{\beta_k - 1}{\beta_{k+1}} (x_k - x_{k-1})$
- $x_{k+1} = \text{proj}(y_k - \eta_k \nabla f(y_k))$
- $\beta_{k+1} = \frac{1 + \sqrt{1 + 4\beta_k^2}}{2}$

Or the simpler heavy-ball variant:
- $v_k = \beta v_{k-1} - \eta \nabla f(x_k)$
- $x_{k+1} = \text{proj}(x_k + v_k)$

Let me use the simpler heavy-ball form which is more robust:

Actually, I realize the key issue might be simpler than I think. Let me look at what the previous code does differently and where it might be losing performance:

1. It uses top-L lags (L=120) with a small $\tau$ (0.30). This means it only focuses on 120 out of potentially thousands of lags. The issue is that as the optimization progresses, the "active set" of lags near the max changes, and the top-L selection might miss important ones.

2. The learning rate starts at 0.12 and decays. This might be too aggressive initially.

3. The momentum is 0.9 (heavy ball).

My improvements:
1. Use all lags with softmax (no top-L restriction). This is more stable.
2. Start with a larger $\tau$ and decrease it geometrically.
3. Use a more careful learning rate (perhaps backtracking).

The issue might be that L=120 is too small or too large. Let me try a different approach: use all lags but with a very peaked softmax (small $\tau$) to effectively focus on the top lags.

def _to_sum1(a):
    s = a.sum()
    if s <= 1e-15:
        return np.full(a.size, 1.0 / a.size)
    return a / s


def _proj_simplex(v, target=1.0):
    v = np.asarray(v, dtype=np.float64)
    n = v.size
    if n == 0:
        return v
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.arange(1, n + 1)
    cond = u * rho > (cssv - target)
    if not np.any(cond):
        return np.zeros(n)
    idx = np.max(rho[cond]) - 1
    theta = (cssv[idx] - target) / (idx + 1)
    return np.maximum(v - theta, 0.0)


def _fft_conv_sq(a, m):
    fa = np.fft.rfft(a, m)
    return np.fft.irfft(fa * fa, m)[:2 * a.size - 1]


def _fft_grad(a, w, m_grad):
    n = a.size
    a_rev = a[::-1]
    fa = np.fft.rfft(a_rev, m_grad)
    fw = np.fft.rfft(w, m_grad)
    conv = np.fft.irfft(fa * fw, m_grad)
    return 2.0 * conv[n - 1:2 * n - 1]

        m_conv <<= 1
    m_grad = 1
    while m_grad < 3 * n - 2:
        m_grad <<= 1
    
    c = _fft_conv_sq(a, m_conv)
    best_mc = c.max()
    best_a = a.copy()
    best_score = float('inf')

            best_a = a.copy()
            stall_count = 0
        else:
            stall_count += 1
        
        # Softmax weights (all lags)
        c_shift = c - mc
        w = np.exp(c_shift / tau)
        w = w / w.sum()
        
        # Gradient
        grad = _fft_grad(a, w, m_grad)
