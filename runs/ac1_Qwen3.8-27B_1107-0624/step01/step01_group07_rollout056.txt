We want to minimize `f(a) = 2*n*max_k(c_k) / S^2` where `S = sum(a)`.

By homogeneity, we can fix `S = 1` and minimize `2*n*max_k(c_k)`.

The constraint set is `{a: a >= 0, sum(a) = 1}` (the probability simplex).

The subgradient of `g(a) = max_k(c_k)` at a point where the max is at `k*` is:

Let me also add a **novel element**: the "spectral gap" method.

**Spectral Gap Method:**
1. Compute the DFT of `a` (padded to length >= 2n-1)
2. Compute the power spectrum `P = |DFT(a)|^2`
3. The autocorrelation is `c = IDFT(P)`
4. The peak of `c` is at some index `k*`
5. To reduce the peak, we can "notch" the spectrum at frequencies that contribute to `c[k*]`
   - `c[k*] = (1/N) * sum_f P[f] * exp(2*pi*i*f*k*/N)`
   - The "phase" at each frequency is `exp(2*pi*i*f*k*/N)`
   - Frequencies where the phase is close to 1 (i.e., `f*k* ≈ 0 mod N/2`) contribute positively
   - We can reduce P at those frequencies
6. Update: `P_new = P * (1 - alpha * Re(exp(2*pi*i*f*k*/N)))` for the "bad" frequencies
7. Transform back: `a_new = real(IDFT(sqrt(P_new) * phase(DFT(a))))`
8. Enforce non-negativity and normalize

This is a form of "Grimme's method" or "iterative amplitude and phase retrieval."

Actually, a simpler version: just do `a_new = max(0, a - lr * c_shifted)` where `c_shifted` is the autocorrelation shifted to align with `a`. This is essentially the "water-filling" or "proportional fair" approach.

Let me think about what `c_shifted` should be. We want to reduce `a_i` proportionally to how much it contributes to the peak. The contribution of `a_i` to `c[k*]` is proportional to `a[k*-i]` (as computed before). So the update should be:

`a_new[i] = a[i] - lr * a[k*-i]` (for valid k*-i)

This is the same as the subgradient step! So the subgradient method and this "contribution-based" method are the same.

from scipy.sparse import csr_matrix

def compute_objective(a):
    n = len(a)
    S = a.sum()
    if S < 1e-10:
        return np.inf
    c = np.convolve(a, a, mode='full')
    return 2.0 * n * c.max() / (S * S)

def get_subgrad(a, k_star):
    """Compute subgradient of max_k conv(a,a)_k w.r.t. a at peak index k_star."""
    n = len(a)
    sg = np.zeros(n)
    i_min = max(0, k_star - (n - 1))
    i_max = min(n - 1, k_star)
    if i_min <= i_max:
        idx = k_star - np.arange(i_min, i_max + 1)
        sg[i_min:i_max + 1] = 2.0 * a[idx]
    return sg

def project_simplex(v):
    """Project vector v onto the probability simplex {x >= 0, sum(x) = 1}."""
    n = len(v)
    if v.sum() < 1e-15:
        return np.ones(n) / n
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.nonzero(u * np.arange(1, n + 1) > (cssv - 1))[0][-1]
    theta = (cssv[rho] - 1) / (rho + 1.0)
    w = np.maximum(v - theta, 0)
    return w / w.sum()

def optimize_subgrad(a, deadline, rng, use_momentum=True, beta=0.7):
    """Subgradient descent with momentum and adaptive step size."""

def lp_direction(a, M):
    """Solve LP: max sum(g) s.t. conv(a,g) <= M, g >= 0."""
    n = len(a)
    # Build convolution matrix (2n-1 x n)
    # A[k, j] = a[k-j] if 0 <= k-j < n
    A = csr_matrix((2*n-1, n))
    for j in range(n):
        A[j:j+n, j] = a
    A = A.tocsr()
    
    c_obj = -np.ones(n)
    b_ub = np.full(2*n-1, M)
    bounds = [(0, None)] * n
    
    try:
        res = linprog(c_obj, A_ub=A, b_ub=b_ub, bounds=bounds, method='highs')
        if res.status == 0:
            return res.x
    except Exception:
        pass
    return None
