        grads = np.zeros((len(active), n))

    c = np.convolve(s, s)
    max_c = c.max()
    # Find active constraints
    threshold = max_c - 1e-10
    active = c >= threshold

        k = np.argmax(c)
        # grad of c[k] wrt s[i] = s[k-i] if 0 <= k-i < n
        grad = np.zeros(n)
        valid_i = range(max(0, k-n+1), min(n, k+1))

Let me also think about a completely different angle: **what if we think of this as a matrix problem?**

Define a matrix M where `M[i,j] = s[i] * s[j]`. Then `c[k] = sum_{i+j=k} M[i,j]` = sum of anti-diagonal k.

We want all anti-diagonal sums to be equal. The constraint is that M is a rank-1 matrix of the form `s * s^T` (outer product) with `s >= 0`.

So we're looking for a rank-1 non-negative matrix whose anti-diagonal sums are as equal as possible.

This is a niche problem, but it suggests an approach: start with a matrix that has equal anti-diagonal sums (like a "constant-anti-diagonal" matrix) and find the closest rank-1 non-negative approximation.

A constant-anti-diagonal matrix would have `M[i,j] = t` for all i,j with i+j = k, for the same t across all k. But the total sum would be `sum_k (number of elements on anti-diagonal k) * t = (n^2) * t` (approximately, since the total number of elements is n^2). And the sum of anti-diagonal k is `(min(k+1, 2n-1-k)) * t`, which varies with k. So we can't have all anti-diagonal sums equal with a constant matrix.

The ideal anti-diagonal sum is `(sum s)^2 / (2n-1)`. For a rank-1 matrix `s*s^T`, the anti-diagonal sum is `c[k] = sum_i s[i]*s[k-i]`.

Wait, I realize there might be an issue with the gradient computation. Let me double-check.

We want to minimize `f(s) = max_k c[k]` where `c[k] = sum_i s[i] * s[k-i]`.

The smooth surrogate is `F(s) = T * log(sum_k exp(c[k]/T))`.

The gradient of F is:
`dF/ds[i] = sum_k (exp(c[k]/T) / sum_j exp(c[j]/T)) * dc[k]/ds[i]`
`= sum_k weights[k] * s[k-i]` (for valid k-i, i.e., 0 <= k-i < n)

So `grad[i] = sum_k weights[k] * s[k-i]` where `0 <= k-i < n`, i.e., `k >= i` and `k <= i + n - 1`.

So `grad[i] = sum_{k=i}^{i+n-1} weights[k] * s[k-i] = sum_{j=0}^{n-1} weights[i+j] * s[j]`

Yes, that's what I had. Good.

Now, the direction of steepest descent is `-grad`. We want to decrease s where grad is large, which means decreasing s where the "weighted sum of contributions to all c[k]" is large.

Intuitively, if s[i] contributes a lot to the peak c[k*], then grad[i] will be large (because weights[k*] is large and s[k*-i] is the coefficient), so we'll decrease s[i].

This makes sense!

Now, let me think about the step size. The gradient has magnitude roughly:
`||grad|| ≈ ||weights * s||` (in some sense). Since weights sum to 1 and are concentrated near the max, `grad[i] ≈ s[k*-i]` (for the dominant k*). So `||grad|| ≈ ||s||_{whatever} ≈ O(1/√n)` (since s is on the simplex).

A step of `eta * grad` with `eta = c_max / ||grad||` would change s by about c_max in the direction of grad. Since c_max ≈ 1/n (for a good sequence), this is a small step.

Actually, let me just use `eta = 1.0` and rely on backtracking. Or better, normalize the gradient:

`eta = alpha / ||grad||_2^2` for some alpha (like 0.1).

This gives a step that reduces the squared gradient by a factor, which is a standard choice.

Let me also think about a potential issue: the projection onto the simplex might undo the effect of the gradient step if the step is too large. For example, if the step makes some elements negative, the projection will set them to 0 and redistribute the mass, which might not be in the desired direction.

To handle this, we should keep the step size small enough that the projection doesn't change the step much. A rule of thumb: `eta * max|grad| < min(s) / 2`.

    theta = (cv[rho[-1]] - 1) / (rho[-1] + 1)
    return np.maximum(v - theta, 0)

def smooth_grad(s, weights):
    """Compute gradient of the smooth surrogate."""
    n = len(s)
    grad = np.zeros(n)
    for i in range(n):
        grad[i] = np.dot(weights[i:i+n], s)

def build_c_matrix(s):
    """Build matrix for conv(s, b) as M @ b."""
    n = len(s)
    M = np.zeros((2*n-1, n))
    for j in range(n):
        M[j:j+n, j] = s

    """Find LP direction to reduce peak."""
    n = len(s)
    A = build_c_matrix(s)
    c = -np.ones(n)

                      options={'time_limit': 3.0})

    return None

def lp_opt(s, max_iters=50, deadline=None):
    """LP-guided optimization."""
    n = len(s)
    s = np.maximum(s, 0.0)
    s = s / s.sum()
    best_s = s.copy()
    best_sc = fast_score(s)
    
    for it in range(max_iters):
        if deadline and time.monotonic() > deadline:
            break
        
        c = np.convolve(s, s)
        M = c.max()
        b = lp_direction(s, M)
        if b is None:
            break
        
        # Line search for blending
        best_t = 0.0
        for t in [0.1, 0.2, 0.3, 0.5, 0.7, 1.0]:
            cand = (1-t)*s + t*b
            cand = np.maximum(cand, 0)
            if cand.sum() < 1e-10:

            cand = cand / cand.sum()
            sc = fast_score(cand)
            if sc < best_sc:

                best_s = cand.copy()
                best_t = t

        s = (1-best_t)*s + best_t*b
        s = np.maximum(s, 0)
        s = s / s.sum()
    
    return best_s, best_sc
