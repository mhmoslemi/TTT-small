```
                score = 2*N*M
                if score < best: update best
                
                # Soft subgradient
                tau = adaptive_temperature
                S = exp((b - M) / tau)
                S /= sum(S)
                grad = 2 * cross_corr(a, S)  # via FFT
                
                # Mirror descent step
                eta = adaptive_step_size
                a = a * exp(-eta * grad)
                a = max(0, a)
                a = a / sum(a)
                
                # Periodic LP refinement
                if iter % fp == 0:
                    solve LP, blend direction
                
                # Periodic perturbation
                if no_improve > threshold:
                    a = random_perturb(a)
```

For the step size, I'll use a Polyak-type step: `eta = (M - M_min) / (||grad||^2 + eps)` where `M_min` is a lower bound on the optimal value.

For the lower bound on the optimal `M`: since `sum(b) = (sum a)^2 = 1` and `b` has `2n-1` entries, `M >= 1/(2n-1)`. So `M_min = 1/(2n-1)`.

Actually, a better lower bound: since `b[k] >= 0` for all `k` and `sum b = 1`, we have `M >= 1/(2n-1)`. But we can do better. Since `b[0] = a[0]^2 >= 0` and `b[2n-2] = a[n-1]^2 >= 0`, and by symmetry `b[k] = b[2n-2-k]`, the effective number of "free" entries is roughly `n`. So `M >= 1/n` is a rough bound. But this might not be tight.

Let me just use `M_min = 1/(2*n)` as a conservative lower bound.

Now, for the step size in mirror descent, the theoretical step for minimizing a convex function with Lipschitz gradient would be `eta = 1/L`. But our function isn't smooth. The subgradient norm bounds the step.

Let me use a simple approach: try multiple step sizes and pick the best (line search).

Let me also add a "deflation" step: after computing the subgradient, explicitly zero out or reduce the mass at positions with very high subgradient values. This is like a "hard" version of the soft subgradient.

**One more idea: Alternating Direction Method of Multipliers (ADMM)**

We want to minimize `max_k b[k]` subject to `sum(a) = 1, a >= 0`.

ADMM formulation:
- Introduce `u = convolve(a, a)` (but this is quadratic, complicating things)
- Alternatively: minimize `t` subject to `convolve(a,a)[k] <= t` for all k, `sum(a) = 1`, `a >= 0`.

This is hard to decompose.

**Alternative: Proximal method / Away-step forward-backward**

On the simplex, we can use away-step forward-backward splitting. The "away step" allows coordinates to actually go to zero, which is important for discrete structures.

```python
def normalize_nonneg(a, target=1.0):
    """Normalize a 1-D array to sum 1, keeping it non-negative."""
    a = np.asarray(a, dtype=np.float64)
    if a.size == 0:
        return np.ones(1, dtype=np.float64)
    if a.ndim != 1:
        a = a.reshape(-1)
    a = np.clip(a, 0.0, None)
    s = float(a.sum())
    if not np.isfinite(s) or s <= 1e-300:
        a = np.ones_like(a, dtype=np.float64)
        s = float(a.size)
    a = a / s
    return a


def score_normalized(a):
    """Score for a normalized sum-1 nonnegative sequence: 2*n*max(conv)."""
    a = np.asarray(a, dtype=np.float64)
    if a.size == 0:
        return np.inf
    c = np.convolve(a, a)
    m = float(c.max())
    if not np.isfinite(m):
        return np.inf
    return float(2.0 * a.size * m)


def compute_score(a):
    """Exact internal score matching evaluate_sequence for valid positive input."""
    a = np.asarray(a, dtype=np.float64)
    if a.size == 0:
        return np.inf
    a = np.clip(a, 0.0, None)
    s = float(a.sum())
    if s < 1e-12:
        return np.inf
    c = np.convolve(a, a)
    m = float(c.max())
    if not np.isfinite(m):
        return np.inf
    return float(2.0 * a.size * m / (s * s))


def resize_to_length(a, N):
    """Resize a sequence to exact length N."""
    a = np.asarray(a, dtype=np.float64)
    m = a.size
    if m <= 1:
        return np.full(max(1, N), 1.0 / max(1, N), dtype=np.float64)
    if m == N:
        return normalize_nonneg(a)
    if m < N:
        x = np.linspace(0.0, float(m - 1), N)
        i0 = np.floor(x).astype(np.int64)
        i1 = np.minimum(i0 + 1, m - 1)
        frac = x - i0
        out = a[i0] * (1.0 - frac) + a[i1] * frac
        return normalize_nonneg(np.maximum(out, 0.0))
    else:
        out = np.zeros(N, dtype=np.float64)
        for i in range(N):
            lo = (i * m) // N
            hi = ((i + 1) * m) // N
            if hi > lo:
                out[i] = a[lo:hi].sum()
        return normalize_nonneg(out)

def fft_cross_correlation(a, b):
    """
    Compute cross-correlation: out[i] = sum_j a[j] * b[i+j]
    where a has length n and b has length m. out has length n.
    Uses FFT for efficiency.
    """
    a = np.asarray(a, dtype=np.float64)
    b = np.asarray(b, dtype=np.float64)
    n = a.size
    m = b.size
    need = n + m - 1
    size = 1
    while size < need:
        size <<= 1

    fa = np.zeros(size, dtype=np.float64)
    fa[:n] = a

    # We want out[i] = sum_j a[j] * b[i+j]
    # This is the convolution of a with reversed b, shifted appropriately.
    # conv(a, b_rev)[i + m - 1] = sum_j a[j] * b_rev[(i+m-1)-j] = sum_j a[j] * b[m-1-i+j]
    # Hmm, let me think differently.
    # Using: out[i] = sum_{j=0}^{n-1} a[j] * b[i+j]
    # Let b_rev[k] = b[m-1-k]. Then b[i+j] = b_rev[m-1-i-j].
    # conv(a, b_rev)[m-1+i] = sum_j a[j] * b_rev[m-1+i-j] = sum_j a[j] * b[i+j] (when valid)
    frb = np.zeros(size, dtype=np.float64)
    frb[:m] = b[::-1]

    result = np.fft.irfft(np.fft.rfft(fa, size) * np.fft.rfft(frb, size), size)
    idx = (m - 1) + np.arange(n, dtype=np.int64)
    idx = np.minimum(idx, size - 1)
    return result[idx]


def soft_subgradient(a, b, temperature):
    """
    Compute the soft subgradient of max(b) where b = convolve(a,a).
    Returns grad of shape (n,) such that grad[i] = 2 * sum_j a[j]*S[i+j]
    where S is the softmax over b values.
    """
    a = np.asarray(a, dtype=np.float64)
    b = np.asarray(b, dtype=np.float64)
    n = a.size
    M = float(b.max())
    e = (b - M) / temperature
    e = np.clip(e, -50.0, 0.0)
    S = np.exp(e)
    s = float(S.sum())
    if s <= 1e-300:
        S = np.zeros_like(b)
        S[int(np.argmax(b))] = 1.0
    else:
        S = S / s
    grad = 2.0 * fft_cross_correlation(a, S)
    return grad


def mirror_descent_step(a, grad, eta):
    """Multiplicative weight update: a_new[i] proportional to a[i] * exp(-eta * grad[i])."""
    log_step = -eta * grad
    log_step = np.clip(log_step, -30.0, 30.0)
    weights = np.exp(log_step)
    a_new = a * weights
    a_new = np.maximum(a_new, 0.0)
    s = float(a_new.sum())
    if s <= 1e-300:
        return normalize_nonneg(a)
    return a_new / s


def make_initial(N, kind, rng, best_seq=None, provided_seq=None):
    """Create an initial normalized nonnegative sequence of length N."""
    N = int(max(2, N))

    if kind == -1 and best_seq is not None:
        return resize_to_length(best_seq, N)
    if kind == -2 and provided_seq is not None:
        return resize_to_length(provided_seq, N)
    if kind == -1 or kind == -2:
        kind = 3

    x = np.linspace(0.0, 1.0, N)

    if kind == 0:
        mu = float(rng.uniform(0.2, 0.8))
        sigma = float(rng.uniform(0.1, 0.35))
        a = np.exp(-0.5 * ((x - mu) / sigma) ** 2)

    elif kind == 1:
        alpha = float(rng.choice([-2.5, -1.5, -0.7, 0.7, 1.5, 2.5]))
        a = np.exp(alpha * (x - 0.5))

    elif kind == 2:
        alpha = float(rng.uniform(-0.5, 1.5))
        beta = float(rng.uniform(-0.5, 1.5))
        xs = np.linspace(1.0 / (N + 1), float(N) / (N + 1), N)
        a = xs ** alpha * (1.0 - xs) ** beta

    elif kind == 3:
        # Two adjacent blocks
        L = N // 2
        a = np.zeros(N, dtype=np.float64)
        if L > 0:
            a[:L] = (2.0 / 3.0) / L
        if N - L > 0:
            a[L:] = (1.0 / 3.0) / (N - L)

    elif kind == 4:
        # Multi-block
        K = int(rng.integers(2, 6))
        masses = rng.dirichlet(np.ones(K))
        lengths = (N / K * rng.dirichlet(np.ones(K))).astype(np.int64)
        lengths = np.maximum(1, lengths)
        while lengths.sum() < N:
            lengths[int(rng.integers(K))] += 1
        while lengths.sum() > N:
            i = int(np.argmax(lengths))
            if lengths[i] > 1:
                lengths[i] -= 1
            else:
                break
        a = np.zeros(N, dtype=np.float64)
        pos = 0
        for L, p in zip(lengths, masses):
            L = int(L)
            if L > 0 and pos + L <= N:
                a[pos:pos + L] = float(p) / L
                pos += L
            elif L > 0:
                a[pos:N] = float(p) / max(1, N - pos)
                break

    elif kind == 5:
        # Smooth noise
        base = rng.normal(0.0, 1.0, size=N)
        wlen = max(1, min(N, 1 + max(1, N // 30)))
        if wlen > 1:
            w = np.ones(wlen, dtype=np.float64)
            w /= w.sum()
            base = np.convolve(base, w, mode="same")
        a = np.exp(0.6 * base)

    elif kind == 6:
        # Symmetric two-hump
        h = float(rng.uniform(0.3, 0.7))
        a = np.where(x < h, 1.2, 0.8)
        # Make it symmetric
        a = 0.5 * (a + a[::-1])

    elif kind == 7:
        # Cosine taper (raised cosine)
        a = 0.5 + 0.5 * np.cos(2.0 * np.pi * (x - 0.5))

    elif kind == 8:
        # Superposition of shifted copies
        n_copies = int(rng.integers(2, 5))
        a = np.zeros(N, dtype=np.float64)
        for _ in range(n_copies):
            center = float(rng.uniform(0.1, 0.9))
            width = float(rng.uniform(0.05, 0.25))
            a += np.exp(-0.5 * ((x - center) / width) ** 2)

    else:
        a = rng.random(N)

    return normalize_nonneg(np.maximum(a, 0.0))


def choose_active_rows(c, max_rows):
    """Choose the most important convolution-lag rows for the LP."""
    c = np.asarray(c, dtype=np.float64)
    m = c.size
    if max_rows >= m:
        return np.arange(m, dtype=np.int64)
    k = int(max(1, min(max_rows, m)))
    if k == m:
        return np.arange(m, dtype=np.int64)
    return np.argpartition(c, -k)[-k:].astype(np.int64)


def build_active_matrix(f, rows):
    """Build the dense active LP matrix A."""
    f = np.asarray(f, dtype=np.float64)
    n = f.size
    rows = np.asarray(rows, dtype=np.int64)
    A = np.zeros((rows.size, n), dtype=np.float64)
    for r, k in enumerate(rows):
        k = int(k)
        jlo = max(0, k - n + 1)
        jhi = min(n, k + 1)
        if jhi > jlo:
            A[r, jlo:jhi] = f[k - (jlo + np.arange(jhi - jlo, dtype=np.int64))]
    return A


def solve_lp_direction(f, M, rows):
    """Solve the LP direction finding problem."""
    if linprog is None:
        return None
    f = np.asarray(f, dtype=np.float64)
    n = f.size
    if n > 3072:
        return None
    if M <= 1e-300:
        return None

    try:
        A = build_active_matrix(f, rows)
    except Exception:
        return None

    if A.size == 0 or not np.any(A):
        return None

    A = A / M
    cvec = -np.ones(n, dtype=np.float64)
    bvec = np.ones(A.shape[0], dtype=np.float64)

    try:
        res = linprog(cvec, A_ub=A, b_ub=bvec, bounds=(0.0, None), method="highs")
    except Exception:
        return None

    if res is not None and res.status == 0 and res.x is not None:
        g = np.asarray(res.x, dtype=np.float64)
        g = np.clip(g, 0.0, None)
        if float(g.sum()) > 1e-12:
            return g
    return None


def random_perturb(f, rng, scale=0.1):
    """Random multiplicative perturbation for nonnegative sequences."""
    f = np.asarray(f, dtype=np.float64)
    n = f.size
    h = np.maximum(f, 0.0).copy()
    if n > 1:
        h = h * np.exp(rng.normal(0.0, float(scale), size=n))
        # Block perturbation
        w1 = max(1, n // 600)
        w2 = max(2, n // 6)
        if w2 > w1:
            width = int(rng.integers(w1, w2 + 1))
            start = int(rng.integers(0, max(1, n - width + 1)))
            h[start:start + width] *= np.exp(float(scale) * 2.0 * rng.normal(0.0, 1.0, size=width))
    return normalize_nonneg(h)


def local_search(a, time_limit, rng, state):
    """
    Main local search: mirror descent + LP refinement + annealing.
    """
    a = normalize_nonneg(a)
    n = a.size
    if n < 2:
        a = np.array([1.0 / 3.0, 2.0 / 3.0], dtype=np.float64)
        n = 2

    b = np.convolve(a, a)
    M = float(b.max())
    best_score = float(2.0 * n * M)
    best = a.copy()

    old_state_score = state["score"]
    if best_score < old_state_score - 1e-12:
        state["score"] = best_score
        state["seq"] = best.copy()
        print(f"  local init: score={best_score:.10f} n={n}", flush=True)

    deadline = time.monotonic() + max(0.0, float(time_limit))
    it = 0
    no_improve = 0
    temperature = 0.08 * M  # soft-max temperature
    base_eta = 2.0

    while time.monotonic() < deadline:
        it += 1

        b = np.convolve(a, a)
        M = float(b.max())
        cur_score = float(2.0 * n * M)

        if cur_score < best_score - 1e-10:
            best_score = cur_score
            best = a.copy()
            if best_score < state["score"] - 1e-12:
                state["score"] = best_score
                state["seq"] = best.copy()
                if best_score < old_state_score - 1e-5:
                    print(f"  iter {it}: score={best_score:.10f} n={n} M={M:.6e}", flush=True)
                old_state_score = best_score
            no_improve = 0
            temperature *= 0.95
            temperature = max(temperature, 0.01 * M)
        else:
            no_improve += 1

        # Annealing: reheat and perturb if stuck
        if no_improve > 40:
            temperature = min(0.5 * M, temperature * 1.5)
            a = random_perturb(a, rng, 0.12)
            no_improve = 0
            continue

        # Compute soft subgradient
        grad = soft_subgradient(a, b, temperature)

        # Adaptive step size with line search
        grad_norm_sq = float(np.dot(grad, grad))
        if grad_norm_sq > 1e-300:
            # Polyak-like step
            M_lb = 1.0 / (2.0 * n)  # lower bound on optimal M
            eta_polyak = (M - M_lb) / (grad_norm_sq + 1e-12)
            eta_polyak = min(eta_polyak, base_eta)
            eta_polyak = max(eta_polyak, 0.01)
        else:
            eta_polyak = base_eta

        # Try multiple step sizes
        etas = [eta_polyak * 0.25, eta_polyak * 0.5, eta_polyak, eta_polyak * 2.0]
        # Also try the base_eta
        etas.append(base_eta)
        etas = [max(0.005, min(e, 10.0)) for e in etas]

        best_h = a
        best_cur = cur_score
        for eta in etas:
            h = mirror_descent_step(a, grad, eta)
            sc = score_normalized(h)
            if sc < best_cur:
                best_cur = sc
                best_h = h

        if best_cur < cur_score - 1e-12:
            a = best_h
            continue

        # LP refinement
        if linprog is not None and n <= 2048 and (it % 3 == 0 or no_improve > 10):
            if n <= 512:
                max_rows = 2 * n - 1
            elif n <= 1024:
                max_rows = min(2 * n - 1, 800)
            else:
                max_rows = min(2 * n - 1, 500)

            rows = choose_active_rows(b, max_rows)
            g = solve_lp_direction(a, M, rows)

            if g is not None:
                Sg = float(g.sum())
                if Sg > 1.0 + 1e-5:
                    g_norm = g / Sg
                    ts = (0.05, 0.1, 0.2, 0.35, 0.5, 0.7, 1.0)
                    best_blend = a
                    best_blend_sc = cur_score
                    for t in ts:
                        h = (1.0 - t) * a + t * g_norm
                        h = normalize_nonneg(h)
                        sc = score_normalized(h)
                        if sc < best_blend_sc:
                            best_blend_sc = sc
                            best_blend = h
                    if best_blend_sc < cur_score - 1e-12:
                        a = best_blend
                        continue

        # Deflation step: reduce mass at positions contributing most to peak
        # Find positions i where a[i] * a[n-1-i] is large (for symmetric-ish contributions)
        if no_improve > 15:
            # Compute per-position "pressure"
            pressure = np.zeros(n, dtype=np.float64)
            for i in range(n):
                j = n - 1 - i
                if 0 <= j < n:
                    pressure[i] = a[i] * a[j]
            # Reduce top-pressure positions
            top_k = max(1, n // 20)
            top_idx = np.argsort(pressure)[-top_k:]
            a[top_idx] *= 0.5
            a = normalize_nonneg(a)
            sc = score_normalized(a)
            if sc > cur_score:
                a = best  # revert
            continue

        # Small random nudge to escape stagnation
        a = random_perturb(a, rng, 0.03)

    # Final check
    b = np.convolve(a, a)
    final_sc = float(2.0 * n * float(b.max()))
    if final_sc < best_score:
        best_score = final_sc
        best = a.copy()

    if best_score < state["score"] - 1e-12:
        state["score"] = best_score
        state["seq"] = best.copy()

    return best, best_score

        state["score"] = fb1_sc
        state["seq"] = fb1.copy()

        if state["score"] < 1.51:

    # Final refinement phase: progressively upscale and polish
    same_size_stuck = 0

            break

        cur_n = state["seq"].size
        if cur_n < 256:

        elif cur_n < 512:

        elif cur_n < 1024:
            next_n = 1024

        else:
            next_n = cur_n

        seq = resize_to_length(state["seq"], next_n)
        limit = min(90.0, hard_deadline - time.monotonic() - 20.0)
        if limit < 15.0:
            break

        old_score = state["score"]
        local_search(seq, limit, rng, state)

        if next_n == cur_n and state["score"] >= old_score - 1e-9:
            same_size_stuck += 1
            if same_size_stuck >= 3:
                break
        else:
            same_size_stuck = 0

    # Verify with official evaluator
    if state["seq"] is None:
        return [float(1.0 / 3.0), float(2.0 / 3.0)]

    cand = [float(x) for x in np.asarray(state["seq"], dtype=np.float64)]

    try:
        official = evaluate_sequence(cand)
        if np.isfinite(official):
            print(f"FINAL: official score={official:.12f} n={len(cand)}", flush=True)
    except Exception as e:
        print(f"evaluate_sequence error: {e}", flush=True)

    return cand
```
