Actually, I just realized something important. Let me re-examine the objective:

F(s) = 2n * max_k (s*s)[k] / (sum(s))^2

For the uniform sequence s = (1/n, ..., 1/n):
- (s*s)[k] is a triangle: (n-|k-(n-1)|)/n^2 for |k-(n-1)| < n, else 0
- max = n/n^2 = 1/n
- F = 2n * (1/n) / 1 = 2

For a "two-point" sequence s = (a/n, 0, ..., 0, b/n) where a+b = n:
- (s*s) has non-zero values only at lags 0, n-1, 2n-2
- (s*s)[0] = (a/n)^2
- (s*s)[n-1] = 2ab/n^2
- (s*s)[2n-2] = (b/n)^2
- max = max(a^2, 2ab, b^2) / n^2
- F = 2n * max(a^2, 2ab, b^2) / n^2 = 2 * max(a^2, 2ab, b^2) / n

To minimize: minimize max(a^2, 2ab, b^2) subject to a+b=n, a,b >= 0.
- If a = b = n/2: max = 2*(n/2)^2 = n^2/2. F = 2*(n^2/2)/n = n. That's terrible for large n!
- If a = n, b = 0: max = n^2. F = 2n. Even worse.

So two-point sequences are bad. We need more spread.

What about a "block" sequence: s = (1/m, ..., 1/m, 0, ..., 0) where the first m elements are 1/m?
- (s*s)[k] for k = 0, ..., 2m-2: (m-|k-(m-1)|)/m^2
- max = 1/m at k = m-1
- F = 2n * (1/m) / 1 = 2n/m
- To minimize: maximize m. If m = n, F = 2 (uniform).
- If m = n/2, F = 4. Worse.

So blocks are bad. We want the mass spread over all n positions.

This confirms that the uniform sequence is a natural "baseline" and we need a non-trivial structure to beat it.

The key insight from the LP approach: the optimal sequence is NOT uniform. It has a specific structure that makes the convolution "flatter" than the uniform triangle.
