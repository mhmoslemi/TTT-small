Actually, `h[i] = sum_{j=0}^{n-1} weights_norm[i+j] * a[j]` can be computed using a different approach.

Notice that `h` is the cross-correlation of `weights_norm` (length 2n-1) with `a` (length n), but with a specific indexing.

Let me define:
- `w = weights_norm` (length 2n-1)
- `a` (length n)
- `h[i] = sum_{j=0}^{n-1} w[i+j] * a[j]` for i = 0, ..., n-1

This is the "anti-diagonal" of the outer product `w ⊗ a^T`, specifically the anti-diagonals starting from the top-left.

An efficient way: 
- Reverse w: `w_rev = w[::-1]` (length 2n-1)
- `h[i] = sum_j w[n-1-(n-1-i-j)] * a[j]`... this is getting messy.

Let me try another approach. Define:
- `b = w` (length 2n-1)
- `v = a` (length n)
- We want `h[i] = sum_j b[i+j] * v[j]` for i = 0,...,n-1

This is the same as the convolution of `b` with `v` evaluated at specific positions, but "shifted".

Actually: `(b * v)[k] = sum_j b[j] * v[k-j]` (standard convolution)
We want: `h[i] = sum_j b[i+j] * v[j] = sum_j b[i+j] * v[j]`

Let `m = i+j`: `h[i] = sum_m b[m] * v[m-i]` (with v[m-i]=0 for m-i < 0 or m-i >= n)
= `(b * v_rev_flipped)[i + something]`...

OK, I think the cleanest way is:
`h[i] = sum_j b[i+j] * v[j]`
Let `b2 = b` and we're computing a "skew" convolution.

In terms of standard convolution:
`h[i] = sum_j b[i+j] * v[j]`
= `sum_j b_rev[(2n-2)-(i+j)] * v[j]` where `b_rev = b[::-1]`
= `sum_j b_rev[2n-2-i-j] * v[j]`

Let `k = j`: `h[i] = sum_k b_rev[2n-2-i-k] * v[k]`
= `(b_rev * v)[2n-2-i]` (standard convolution, evaluated at position 2n-2-i)

So `h[i] = convolve(b_rev, v, 'full')[2n-2-i]`

Where `b_rev = b[::-1]` has length 2n-1, and `v = a` has length n.
The full convolution has length (2n-1) + n - 1 = 3n-2.
We want positions 2n-2-i for i=0,...,n-1, which are positions n-1, n, ..., 2n-2.

So: `h = convolve(b_rev, v, 'full')[n-1:2n-1][::-1]`

Or equivalently: `h_rev = convolve(b_rev, v, 'full')[n-1:2n-1]` and `h = h_rev[::-1]`.
