The second-order change at k=n-1: ε^2 * sum q[i]*q[n-1-i] = ε^2 * (q*q)[n-1] (self-convolution of q at n-1).

For other k: first-order change is 2ε/n * (q*q)[k] (approximately, for the cross terms).

So the question is whether there's a direction q such that:
- (q*q)[n-1] > 0 (increases the peak at center)
- max_k ≠ n-1 (perturbation of (p*p)[k]) > 2ε/n * (q*q)[k] for all k

    no_improve = 0

        c = np.convolve(p, p)
        k_star = np.argmax(c)
        
        # Gradient
        valid_lo = max(0, k_star - n + 1)
        valid_hi = min(k_star, n - 1)
        if valid_lo > valid_hi:
            break
        grad = np.zeros(n)
        grad[valid_lo:valid_hi+1] = 2.0 * p[k_star - valid_hi : k_star - valid_lo + 1][::-1]
        
        # Subtract mean to project to tangent of simplex
        grad_centered = grad - grad[valid_lo:valid_hi+1].mean()
        
        # Source: high p, high grad_centered
        # Sink: low p, low grad_centered
        
        # Simple approach: move mass from argmax(p * grad) to argmin(p * grad)
        # among valid positions
        product = p * np.abs(grad)
        
        # Top source
        source = valid_lo + np.argmax(product[valid_lo:valid_hi+1])
        
        # Bottom sink (among all positions, prefer low product and low p)
        # Actually, let's find positions where grad is negative (below average)
        sinks = np.where((grad < grad[valid_lo:valid_hi+1].mean()) & (p < p.mean()))[0]
        if len(sinks) == 0:
            sinks = np.argsort(grad)[:10]
        sink = sinks[np.argmin(p[sinks])]
        
        # Transfer amount
        alpha = min(p[source] * 0.05, 1e-3)
        p[source] -= alpha
        p[sink] += alpha
        
        p = np.clip(p, 0, None)
        p = p / p.sum()

        if c_new < best_c:
            best_c = c_new
            best = p.copy()
            no_improve = 0
        else:
            no_improve += 1
        
        step_count += 1
    
    return best, 2.0 * n * best_c

If the peak is at k*, we want to minimize c[k*] = sum_i p[i]*p[k*-i].

This is a quadratic minimization: minimize p^T Q p subject to sum p = 1, p >= 0, where Q is the "reflection" matrix (Q[i,j] = 1 if i+j=k*, else 0, with Q[j,j] = 1 if 2j=k*).

R is a symmetric 0-1 matrix. p^T R p = sum_{i+j=k*} p[i]*p[j] (with the p[j]^2 term counted once when 2j=k*).

Actually, for i ≠ j: p[i]*p[j] appears twice (once as i, once as j). For i = j (when 2i=k*): p[i]^2 appears once.

So p^T R p = 2*sum_{i<j, i+j=k*} p[i]*p[j] + sum_{i: 2i=k*} p[i]^2.

This is a quadratic form. On the simplex, the minimum of a quadratic form is achieved at an extreme point (vertex) if the matrix is positive semi-definite, or on the boundary in general.

R is a permutation matrix (reversal), so it's orthogonal. Its eigenvalues are +1 and -1. So R is indefinite (has both positive and negative eigenvalues). The quadratic form p^T R p is not convex.
