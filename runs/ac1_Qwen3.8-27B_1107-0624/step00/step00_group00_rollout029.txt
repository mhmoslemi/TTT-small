    # Using FFT: cross-correlation of y and f = ifft(FFT(y) * conj(FFT(f)))
    # But we need to be careful about the indexing.
    # Actually, (A^T y)[j] = sum_k A[j,k] y[k] = sum_k f[k-j] y[k]
    # Let m' = k - j, then = sum_{m'} f[m'] y[m' + j] = (y shifted * f)[0]... 
    # This is the cross-correlation: (y ⊛ f)[j] = sum_k y[k] f[k-j]
    # Which is the same as the convolution of y and reversed f, evaluated at j.
    # Or: it's the "correlation" which can be computed as:
    # corr[j] = sum_k y[k] * f[k-j] for valid k, j.
    # Using FFT: corr = ifft(FFT(y, n=2n-1) * conj(FFT(f, n=2n-1)))
    # Actually, let me just use np.correlate or compute via FFT.
    
    # Let me compute (A^T y)[j] = sum_{k=max(j,0)}^{min(m-1, j+n-1)} y[k] * f[k-j]
    # This is the cross-correlation of y and f at lag j.
    # np.correlate(y, f, mode='full')[n-1+j] or similar.
    
    # Simpler: use the fact that (A^T y)[j] = sum_k y[k] * f[k-j]
    # = sum_k y[k] * f[k-j] for 0 <= k-j < n
    # This is the convolution of y (reversed) and f, or equivalently:
    # Let y_rev[k] = y[m-1-k], then (y_rev * f)[m-1-j] = (A^T y)[j]
    
    # Actually, let me just compute it directly using the convolution:
    # (A^T y)[j] = sum_k y[k] * f[k-j] where the sum is over k such that 0 <= k-j < n and 0 <= k < m.
    # = sum_{k=j}^{j+n-1} y[k] * f[k-j] (for j <= m-1-n+1 = n-1)
    # For j in [0, n-1]: (A^T y)[j] = sum_{i=0}^{n-1} y[j+i] * f[i]
    #   (where y[j+i] is 0 if j+i >= m)
    
    # This is a "sliding dot product" of y with f. Can be computed with FFT.
    # Specifically, it's the cross-correlation: corr[j] = <y[j:j+n], f>
    # = Re{ ifft(FFT(y) * conj(FFT(f))) }[j] (with appropriate length)
    
    # Let me use a direct FFT computation:
    N_fft = 1
    while N_fft < 2 * n - 1:
        N_fft *= 2
    F = np.fft.rfft(f, N_fft)
    Y = np.fft.rfft(y, N_fft)
    # Cross-correlation: ifft(Y * conj(F))
    corr = np.fft.irfft(Y * np.conj(F), N_fft)
    # corr[j] = sum_k y[k] * f[k-j] (circular, but we made it long enough)
    # Actually: ifft(Y * conj(F))[j] = sum_k y[k] f[k-j] (mod N_fft)
    # For our purposes, we want the "linear" cross-correlation.
    # Since N_fft >= 2n-1 and both f and y have support in [0, n-1] and [0, 2n-2] respectively,
    # the linear cross-correlation is the first n elements of corr (with appropriate indexing).
    
    # Hmm, let me be more careful.
    # ifft(Y * conj(F))[j] = sum_{k=0}^{N_fft-1} y[k] * f[(k-j) mod N_fft]
    # For j in [0, n-1] and assuming N_fft >= 2n-1:
    #   = sum_{k=j}^{j+n-1} y[k] * f[k-j] (since f is zero outside [0, n-1])
    #   = sum_{i=0}^{n-1} y[j+i] * f[i]
    # Which is exactly (A^T y)[j]. ✓
    
    Aty = corr[:n]  # (A^T y)[0:n]
    
    # MW update
    # Primal update: x <- x * exp(-eta * (Aty - 1))
    r = Aty - 1.0  # dual residual
    x = x * np.exp(-eta * r)
    x = np.maximum(x, 0)
    x_sum = x.sum()
    if x_sum < 1e-30:
        x = np.ones(n) / n
    else:
        x = x / x_sum
    
    # Dual update: y <- y * exp(eta * (Ax - M))
    s = Ax - M  # primal residual
    y = y * np.exp(eta * s)
    y = np.maximum(y, 0)
    y_sum = y.sum()
    if y_sum < 1e-30:
        y = np.ones(m) / m
    else:
        y = y / y_sum
    
    return x, y
