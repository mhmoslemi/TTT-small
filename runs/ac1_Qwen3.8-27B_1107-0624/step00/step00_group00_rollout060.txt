The minimum possible value of $\max_k P(X+Y = k)$ is at least $1/(2n-1)$ (by averaging). The question is whether we can achieve this (or close to it) for a product distribution (i.e., $P(X+Y=k) = \sum_i P(X=i)P(Y=k-i)$).

For a uniform distribution on $\{0,...,n-1\}$, $P(X+Y=k) = (k+1)/n^2$ for $k < n$ and $(2n-1-k)/n^2$ for $k \geq n$. The max is $1/n$ (at $k = n-1$).

The ratio of max to average is $(1/n) / (1/(2n-1)) \approx 2$. So the uniform distribution gives about twice the average.

To do better, we need a distribution where the sum distribution is flatter. This is related to the theory of "sum-free sets" and "Sidon sets" in additive combinatorics.

A Sidon set (or B_2 sequence) is a set where all pairwise sums are distinct. If we could make $a$ supported on a Sidon set, then the convolution would have distinct "peaks" at the sum positions, potentially reducing the max.

But we're dealing with a probability distribution, not a 0-1 sequence. And the support size is limited by $n$.

For a 0-1 sequence supported on a Sidon set of size $m$ in $\{0,...,n-1\}$, the convolution has $m$ non-zero values (at the diagonal) and $m(m-1)/2$ values (at the off-diagonal sums). If all sums are distinct (Sidon), there are $m(m+1)/2$ distinct non-zero values. The max would be at most... hmm, this doesn't directly help.

Let me also consider: maybe the best approach for large $n$ is to use a sequence that's close to uniform but with small perturbation that reduces the peak. The uniform sequence has max = $S^2/n$ (at the center of the convolution). If we can reduce the center value while keeping other values low, we win.

The center value (for a palindromic sequence) is $\sum_i a_i a_{n-1-i}$. By Cauchy-Schwarz, this is at most $\sum a_i^2$ (achieved when $a_i = a_{n-1-i}$, i.e., when the sequence is symmetric). Wait, that's the same sequence! So for symmetric sequences, the center value = $\sum a_i^2$ (the "energy" of the sequence).

Hmm, actually: $\sum_i a_i a_{n-1-i} \leq \sqrt{\sum a_i^2 \sum a_{n-1-i}^2} = \sum a_i^2$ by Cauchy-Schwarz. Equality when $a_i = c \cdot a_{n-1-i}$ for all $i$, which means the sequence is symmetric (up to scaling, but since it's symmetric, $c=1$).

So for symmetric sequences, the center of the convolution = $\sum a_i^2 = \|a\|_2^2$.
