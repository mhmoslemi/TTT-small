    c = np.convolve(p, p)
    M = c.max()
    # Find lags near the peak
    active = c >= threshold_frac * M
    # Compute gradient: sum of contributions from active lags
    grad = np.zeros_like(p)
    for k in np.where(active)[0]:
        # Contribution to grad from lag k: 2 * p[k-j] for valid j
        j_start = max(0, k - (len(p)-1))

        for j in range(j_start, j_end+1):

    # Exponentiated gradient update
    p_new = p * np.exp(-eta * grad)
    p_new = np.clip(p_new, 0, None)
    if p_new.sum() > 0:
        p_new /= p_new.sum()
    else:

    return p_new

def expgrad_step(p, eta, threshold_frac=0.85):
    """One step of exponentiated gradient."""
    n = len(p)
    c = np.convolve(p, p)
    M = c.max()

    active = c >= threshold_frac * M
    active_indices = np.where(active)[0]

        return p, c, M

For n = 6962, this is always true for alpha > 0 (since the quadratic in alpha has positive leading coefficient and the constant is -1, the positive root is very small).

So the peak is at k = n-2 for alpha > 0.
Peak value: ((n-1)(1+alpha^2) + 2*alpha) / n^2

We want to minimize this. Taking derivative w.r.t. alpha:
d/dalpha [(n-1)(1+alpha^2) + 2*alpha] / n^2 = (2*(n-1)*alpha + 2) / n^2

This is always positive for alpha > 0! So the peak increases with alpha. The minimum is at alpha = 0, which gives the uniform sequence with score 2.

So the alternating pattern doesn't help! The problem is that for even n, the "alignment" of the alternating pattern with the triangular envelope works against us.

What if we use a different frequency? Let me try f = 1/4: p_j = (1 + alpha * cos(πj/2)) / n.

This gives the pattern: [1, alpha, -1, -alpha, 1, alpha, -1, -alpha, ...] repeating with period 4.

The self-convolution of cos(πj/2) with itself:
cos(πj/2) * cos(π(k-j)/2) = (1/2)[cos(πk/2) + cos(πj/2 + πj/2 - πk/2)]
= (1/2)[cos(πk/2) + cos(πj - πk/2)]
= (1/2)[cos(πk/2) + cos(πj)cos(πk/2) + sin(πj)sin(πk/2)]

Hmm, this is getting complicated. The point is that the cross terms might not cancel as nicely.

Let me try a different approach entirely. Instead of parametric families, let me use a more powerful optimization method.

**New idea: Use scipy.optimize.minimize with a smooth approximation.**

The objective f(p) = 2n * max_k (p*p)_k can be approximated by:
f_smooth(p, tau) = 2n / tau * log(sum_k exp(tau * (p*p)_k))

For small tau, this is close to the max. For larger tau, it's more "mean-like." I can start with a moderate tau and decrease it.

The gradient of f_smooth is:
∂f_smooth/∂p_j = (2n/tau) * [sum_k exp(tau*c_k) * tau * (∂c_k/∂p_j) / sum_k exp(tau*c_k)]
= 2n * [sum_k exp(tau*c_k) * 2*p_{k-j}] / [sum_k exp(tau*c_k)] (for valid k-j)
= 2n * 2 * p ⋆ w where w_k = exp(tau*c_k) / sum_k exp(tau*c_k)

This is a weighted average of the gradients at each lag, weighted by the softmax of the convolution values. It's smooth and well-defined!

I can use this with scipy.optimize.minimize or just implement my own gradient descent.

But the constraint p >= 0, sum(p) = 1 makes it a constrained optimization. I can use:
- Projected gradient descent
- Log barrier method
- Or parameterize p = softmax(x) and optimize over x

Let me use the softmax parameterization:
p_j = exp(x_j) / sum_k exp(x_k)

Then I optimize over x (unconstrained). The gradient w.r.t. x is:
∂f/∂x_j = (∂f/∂p_j - (sum_k ∂f/∂p_k) * exp(x_j)) / sum_k exp(x_k)
= (∂f/∂p_j - mean_i(∂f/∂p_i)) * ...

∂f/∂x_j = sum_m (∂f/∂p_m) * (∂p_m/∂x_j)
= sum_m (∂f/∂p_m) * (p_m * (delta_{mj} - p_j))
