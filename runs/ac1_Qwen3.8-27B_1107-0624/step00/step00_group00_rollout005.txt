This is a 3-variable optimization. By symmetry, maybe the optimal is symmetric: $a = [x, y, x]$.
- Conv: $[x^2, 2xy, y^2+2x^2, 2xy, x^2]$
- Max = $\max(x^2, 2xy, y^2+2x^2)$
- Constraint: $2x + y = 1$, so $y = 1-2x$.

Max = $\max(x^2, 2x(1-2x), (1-2x)^2+2x^2)$

Let $f_1 = x^2$, $f_2 = 2x-4x^2$, $f_3 = 1-4x+6x^2$.

At $x = 0.25$: $f_1 = 0.0625$, $f_2 = 0.5-0.25 = 0.25$, $f_3 = 1-1+0.375 = 0.375$. Max = 0.375.
At $x = 1/3$: $f_1 = 1/9$, $f_2 = 2/3-4/9 = 2/9$, $f_3 = 1-4/3+6/9 = 1-4/3+2/3 = 1/3$. Max = 1/3.

Score = $2*3*Max/1 = 6*Max$.
At $x = 1/3$: Score = $6/3 = 2$.
At $x = 0.25$: Score = $6*0.375 = 2.25$.
