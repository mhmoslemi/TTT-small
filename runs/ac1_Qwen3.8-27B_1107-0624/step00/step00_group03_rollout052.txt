  - Combined: i in [max(0, k-n+1), min(n-1, k)]

So the valid i range is [lo, hi] where lo = max(0, k-n+1) and hi = min(n-1, k).

For the subgradient:
d/ds[j] (s*s)[k] = 2*s[k-j] if j is in [lo, hi] AND k-j is in [0, n-1].

But if j is in [lo, hi], then by definition 0 <= j < n and 0 <= k-j < n (since j >= k-n+1 means k-j <= n-1, and j <= k means k-j >= 0). So the condition is just j in [lo, hi].

And k-j is in [k-hi, k-lo] = [max(0, k-(n-1)), min(n-1, k)] = [max(0, k-n+1), min(n-1, k)] = [lo, hi].

So: sg[j] = 2*s[k-j] for j in [lo, hi], else 0.

In numpy:
```python
lo = max(0, k - n + 1)
hi = min(n - 1, k)
j = np.arange(lo, hi + 1)
sg[j] = 2 * s[k - j]
```

This is O(min(n, k+1, 2n-1-k)) = O(n) in the worst case.

OK let me now write the full algorithm. I'll use a combination of:
1. Subgradient descent with the top-K peaks.
2. Simulated annealing for exploration.
3. Periodic random restarts.
4. Multiple initializations.

Let me also think about the learning rate schedule. A common approach is:
- lr_t = lr_0 / (1 + t * decay)
- Or lr_t = lr_0 * (1 - t/T)^power

For subgradient methods, a common choice is lr_t = c / sqrt(t).

Let me also consider using **momentum** to smooth out the noisy subgradients:
- v_t = beta * v_{t-1} + (1-beta) * sg_t
- s_{t+1} = s_t - lr * v_t

This can help with convergence.

import numpy as np
import time

"""
Algorithm: Hybrid subgradient descent with simulated annealing for minimizing
the peak of the self-convolution of a non-negative sequence.

The objective min 2n*max(conv(s,s))/(sum(s))^2 is scale-invariant, so we
normalize sum(s)=1 and minimize max(conv(s,s)).

We use:
1. Multiple initializations (random, structured, given sequence)
2. Subgradient descent with top-K peak weighting
3. Simulated annealing to escape local minima
4. Momentum for smoothing
5. Periodic restarts
"""

def fast_objective(s):
    """Compute 2n*max(conv(s,s))/(sum(s))^2 efficiently."""
    c = np.convolve(s, s)
    max_c = c.max()
    sum_s = s.sum()
    if sum_s <= 0:
        return np.inf
    n = len(s)
    return 2.0 * n * max_c / (sum_s * sum_s)

def subgradient_topk(s, top_k=10):
    """Compute weighted subgradient using top-K convolution peaks."""
    n = len(s)
    c = np.convolve(s, s)
    # Find top K peak indices
    if top_k >= len(c):
        peak_indices = np.argsort(c)[::-1]
    else:
        # Use argpartition for efficiency
        part_idx = np.argpartition(c, -top_k)[-top_k:]
        peak_indices = part_idx[np.argsort(c[part_idx])[::-1]]
    
    weights = c[peak_indices]
    if weights.sum() <= 0:
        return np.zeros(n), c.max(), peak_indices
    weights = weights / weights.sum()
    
    sg = np.zeros(n)
    for w, k in zip(weights, peak_indices):
        lo = max(0, k - n + 1)
        hi = min(n - 1, k)
        if lo <= hi:
            j = np.arange(lo, hi + 1)
            sg[j] += w * s[k - j]
    
    return sg, c.max(), peak_indices

def normalize(s):
    """Normalize s to have sum 1, ensuring non-negativity."""
    s = np.clip(s, 0, None)
    s_sum = s.sum()
    if s_sum <= 0:
        return np.ones(len(s)) / len(s)
    return s / s_sum

def random_init(n, rng):
    """Generate a random non-negative sequence."""
    # Use a mixture of uniform and exponential
    if rng.random() < 0.5:
        s = np.exp(rng.normal(0, 0.5, n))
    else:
        s = rng.exponential(1.0, n)
    return normalize(s)

def structured_init(n, rng):
    """Generate a structured non-negative sequence."""
    # Random block structure
    n_blocks = rng.integers(2, 8)
    boundaries = np.sort(rng.choice(np.arange(1, n), n_blocks - 1, replace=False))
    s = np.zeros(n)
    for i in range(n_blocks):
        start = 0 if i == 0 else boundaries[i-1]
        end = boundaries[i] if i < n_blocks-1 else n
        s[start:end] = rng.exponential(1.0)
    return normalize(s)

def propose_candidate(seed=42, budget_s=1800, **kwargs):

    Search for the best sequence using hybrid subgradient + simulated annealing.
    """

    deadline = time.monotonic() + max(0.0, float(budget_s) - 5.0)
    
    # Get initial sequence
    if 'height_sequence_1' in dir() or 'height_sequence_1' in globals():
        try:
            parent = np.clip(np.asarray(height_sequence_1, dtype=np.float64), 0, 1000.0)
        except:
            parent = np.ones(256)
    else:
        parent = np.ones(256)
    
    if parent.ndim != 1 or parent.size == 0 or not np.isfinite(parent).all():
        parent = np.ones(256)
    
    n = parent.size
    print(f"Sequence length: {n}")
    
    # Normalize parent
    s = normalize(parent)
    best_s = s.copy()
    best_obj = fast_objective(s)
    print(f"Initial objective: {best_obj:.6f}")
    
    # Simulated annealing parameters
    T = 0.01  # Initial temperature
    T_min = 1e-8
    cooling = 0.9999  # Cooling rate per iteration
    lr = 0.01  # Base learning rate
    
    # Momentum
    beta = 0.9
    momentum = np.zeros(n)
    
    top_k = 10
    
    it = 0
    no_improve = 0
    best_no_improve_lr = lr
    restart_count = 0
    
    while time.monotonic() < deadline:
        it += 1
        obj = best_obj  # Use current best as reference
        
        # Compute subgradient
        sg, max_c, peak_indices = subgradient_topk(s, top_k)
        
        # Adaptive learning rate
        lr_t = lr / (1.0 + 0.01 * np.sqrt(it))
        
        # Momentum update
        momentum = beta * momentum + (1 - beta) * sg
        s_trial = s - lr_t * momentum
        
        # Project: non-negativity and normalization
        s_trial = np.clip(s_trial, 0, None)
        s_trial = normalize(s_trial)
        
        # Evaluate
        trial_obj = fast_objective(s_trial)
        
        # Simulated annealing acceptance
        if trial_obj < best_obj:
            s = s_trial
            best_obj = trial_obj
            best_s = s_trial.copy()
            no_improve = 0
        elif trial_obj < obj or rng.random() < np.exp(-(trial_obj - obj) / max(T, T_min)):
            s = s_trial
            no_improve += 1
        else:
            no_improve += 1
        
        # Cool down

            no_improve = 0

            # Reset temperature for exploration
            T = max(T * 10, 0.005)
        
        # Periodic progress reporting

    # Final verification with evaluate_sequence
    final_score = float(evaluate_sequence(best_s.tolist()))
    print(f"Final score (via evaluate_sequence): {final_score:.6f}")
    
    return [float(x) for x in best_s]

import numpy as np
import time

"""
Algorithm: Smoothed (log-sum-exp) gradient descent for minimizing the peak
of the self-convolution of a non-negative sequence.

Uses a family of smooth approximations to the max function with decreasing
sharpness (increasing beta), combined with adaptive learning rates and
simulated annealing for exploration.
"""

def soft_max_and_weights(c, beta):
    """Compute soft max and softmax weights."""
    c_max = c.max()
    shifted = beta * (c - c_max)
    # Numerical stability
    shifted_max = shifted.max()
    exp_shifted = np.exp(shifted - shifted_max)
    weights = exp_shifted / exp_shifted.sum()
    soft_max = c_max + (shifted_max - np.log(exp_shifted.sum())) / beta
    return soft_max, weights

def compute_soft_objective_and_grad(s, beta):
    """Compute soft objective and gradient."""
    c = np.convolve(s, s)
    soft_max, weights = soft_max_and_weights(c, beta)
    # Gradient of soft_max w.r.t. s:
    # d(soft_max)/d(s[j]) = sum_k weights[k] * d(c[k])/d(s[j])
    # = sum_k weights[k] * 2*s[k-j] (for valid k-j)
    # = 2 * (correlation of weights and s)[j]
    grad = 2.0 * np.correlate(weights, s, 'full')[:len(s)]

def normalize(s):

    if s_sum <= 0:
