Let me also think about the "soft max" approach for the gradient. Instead of using the hard max (which is non-smooth), I can use:
$\text{soft\_max}(c, \beta) = \frac{1}{\beta} \log \sum_k e^{\beta c_k}$

This is smooth and its gradient is:
$\partial \text{soft\_max} / \partial a_i = \sum_k p_k \cdot 2 a_{k-i}$
where $p_k = e^{\beta c_k} / \sum_j e^{\beta c_j}$.

As $\beta \to \infty$, this approaches the subgradient of the hard max. For finite $\beta$, it's a smoothed approximation.

The objective with soft max: $f_\beta(a) = 2n \cdot \text{soft\_max}(a*a, \beta) / s^2$.

This is smooth (except for the $1/s^2$ term, which is smooth for $s > 0$), so we can use standard gradient descent or even L-BFGS.

The first term is a convolution of $p$ with $a$: $(p * a)_i = \sum_k p_k a_{k-i}$. This can be computed with one FFT!

Optimizes non-negative sequences to minimize 2n*max(conv(a,a))/(sum(a))^2.
Uses alternating LP relaxation (for b) and FFT-based gradient descent (for a).
The LP finds the maximum-sum sequence b whose convolution with a stays bounded,
guiding a toward flatter convolution profiles.

import numpy as np
import time
from scipy.optimize import linprog
from scipy.sparse import csr_matrix
from scipy.fft import fft, ifft

def _compute_convolution(a):
    """Full linear self-convolution via FFT."""
    n = a.size
    size = 2 * n - 1
    N = 1 << (size - 1).bit_length()
    Af = fft(a, N)
    return np.real(ifft(Af * Af, N))[:size]

def _cross_correlation(p, a):
    """Compute g[i] = sum_j p[j+i]*a[j] for i=0..n-1 where p has length 2n-1 and a has length n."""
    n = a.size
    size_p = p.size  # 2n-1
    N = 1 << (n + size_p - 2).bit_length()
    Pf = fft(p, N)
    Af = fft(a, N)
    return np.real(ifft(Pf * np.conj(Af), N))[:n]

def _solve_lp(a, M):
    """Solve max sum(b) s.t. (a*b)_k <= M for all k, b >= 0."""
    n = a.size
    num_rows = 2 * n - 1
    
    # Build sparse matrix
    row_idx = []
    col_idx = []
    data = []
    for k in range(num_rows):
        j_lo = max(0, k - n + 1)
        j_hi = min(k, n - 1)
        for j in range(j_lo, j_hi + 1):
            b_col = k - j
            val = a[j]
            if val > 1e-14:
                row_idx.append(k)
                col_idx.append(b_col)
                data.append(val)
    
    if not data:
        return np.zeros(n)
    
    A = csr_matrix((data, (row_idx, col_idx)), shape=(num_rows, n))
    
    res = linprog(
        c=-np.ones(n),
        A_ub=A.tocsc(),
        b_ub=np.full(num_rows, M),
        bounds=[(0.0, None)] * n,
        method='highs',
        options={'presolve': True, 'time_limit': 100, 'dual_feasibility_tolerance': 1e-8}
    )
    
    if res.x is not None and np.all(np.isfinite(res.x)):
        return np.clip(res.x, 0, None)
    return np.zeros(n)
