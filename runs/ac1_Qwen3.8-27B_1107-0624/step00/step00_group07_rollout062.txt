Great! So the gradient of the objective (w.r.t. the constraint `sum(a) = S`) is:
- If `k*` is the unique argmax: `grad[j] = 2*a[k*-j]` (indicator that `0 <= k*-j < n`)
- If there are multiple argmaxes, it's a weighted combination.

The subgradient direction for minimizing `max(b)` is to move `a` in the direction that decreases `b[k*]`. Since `b[k*]` depends on `a` through `a[k*-j]`, we should decrease `a[j]` for `j` where `k*-j` is in range, weighted by `a[k*-j]`.

```
    a = a / sum(a) * S  # renormalize
    a = max(a, 0)  # project onto non-negativity
    a = a / sum(a) * S  # renormalize again

```

Let's try a linearly increasing sequence: `a[i] = (i+1)/n * c` (so that sum = c*(n+1)/2).

Hmm, this is getting complicated. Let me just implement the numerical optimization and let it find the good shapes.

2. Use FFT-based gradient descent with:
   - Soft-max over top peaks
   - Multiplicative updates (maintain positivity)

3. After the main optimization, try a few LP-based refinement steps
4. Return the best sequence found

def _next_pow2(x):
    """Smallest power of 2 >= x."""
    p = 1
    while p < x:
        p *= 2
    return p

def _compute_conv(a, fft_size):
    """Auto-convolution via FFT."""
    A = np.fft.rfft(a, n=fft_size)
    return np.fft.irfft(A * A, n=fft_size)[:2*len(a)-1]
