**Clean approach: Mirror descent / multiplicative weights**

The problem is: minimize max_k c[k] subject to a >= 0, sum a = 1.

Mirror descent with entropy regularization:

- = sum_k softmax(c_t / tau)[k] * 2 * a_t[k-j]

This is a "smoothed" gradient that accounts for all near-max lags.

As tau -> 0, this converges to using only the argmax.
As tau -> infinity, this uses all lags equally.

The computation is:
G_t = 2 * (softmax(c_t/tau) ⊛ a_t)  (cross-correlation)

from scipy.optimize import linprog

def solve_lp_for_b(f, M):
    """Solve: max sum b s.t. convolve(f, b) <= M, b >= 0."""
    n = len(f)
    c = 2 * n - 1  # number of convolution outputs
    
    # Objective: maximize sum b, i.e., minimize -sum b
    c_obj = -np.ones(n)
    
    # Constraints: for each k in 0..2n-2, sum_j f[j] * b[k-j] <= M
    # b[k-j] is only defined for k-j in [0, n-1], i.e., j in [k-n+1, k]
    # For a given j (variable index), which constraints does it appear in?
    # b[j] appears in constraint k if j = k - j' for some valid j', i.e., k = j + j' for j' in [0, n-1]
    # So b[j] appears in constraints k = j, j+1, ..., j+n-1 (that are in [0, 2n-2])
    
    # Build A_ub (upper bound constraints): A_ub @ b <= b_ub
    # A_ub[k, j] = f[j] if k-j in [0, n-1] (i.e., j in [k-n+1, k] and j in [0,n-1])
    # Actually: constraint k: sum_{j: max(0,k-n+1) <= j <= min(k, n-1)} f[j] * b[k-j] <= M
    # Let l = k-j, so j = k-l. Then: sum_{l: max(0, k-n+1) <= k-l <= min(k,n-1)} f[k-l] * b[l] <= M
    # l ranges from max(0, k-n+1) to min(k, n-1), and j = k-l ranges from k-min(k,n-1) to k-max(0,k-n+1)
    
    # More simply: constraint k: sum_{j=0}^{n-1} f[j] * b[k-j] <= M (with b[m]=0 if m not in [0,n-1])
    # In matrix form: A[k, l] = f[k-l] if 0 <= k-l <= n-1, else 0
    # i.e., A[k, l] = f[k-l] if l in [max(0, k-n+1), min(k, n-1)], else 0
    
    # This is a "Toyobi" / "convolution" matrix.
    # It's sparse! Each row k has at most min(n, k+1, 2n-1-k) nonzeros.
    
    from scipy.sparse import csr_matrix
    
    rows = []
    cols = []
    data = []
    for k in range(c):
        lo = max(0, k - n + 1)
        hi = min(k, n - 1)
        for l in range(lo, hi + 1):
            rows.append(k)
            cols.append(l)
            data.append(f[k - l])
    
    A_ub = csr_matrix((data, (rows, cols)), shape=(c, n))
    b_ub = np.full(c, M)
    
    # Bounds: b >= 0
    bounds = [(0, None)] * n
    
    result = linprog(c_obj, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')
    
    if result.success:
        return result.x
    else:
        return None
