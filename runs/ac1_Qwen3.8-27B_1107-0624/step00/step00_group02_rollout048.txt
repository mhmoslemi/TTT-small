2. Compute c = convolve(a, a), find k* = argmax(c).
3. Compute gradient: g[j] = 2*a[k*-j] for valid j (i.e., 0 <= k*-j < n).

5. Clip: a = max(a, 0).

7. Repeat.

```python
def lp_step(f, M, solver=' highs'):
    """
    Given current sequence f and peak M = max(f*f),
    solve the LP: max sum(g) s.t. f*g <= M (elementwise), g >= 0.
    """
    n = len(f)
    # The convolution constraint: for each k, sum_i f[i]*g[k-i] <= M
    # This is a (2n-1) x n matrix times g <= M
    
    # Build the Toeplitz-like matrix
    # A[k, j] = f[k-j] if 0 <= k-j < n, else 0
    # So A is the "convolution matrix" of f
    
    from scipy.optimize import linprog
    # c = -1 for all variables (we maximize sum(g) = minimize -sum(g))
    c_obj = -np.ones(n)
    A_ub = convolution_matrix(f)  # (2n-1) x n
    b_ub = np.full(2*n-1, M)
    bounds = [(0, None)] * n
    res = linprog(c_obj, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')
    if res.success:
        return res.x
    return None
```

The convolution matrix is (2n-1) x n where row k has f[k-j] in column j (if valid). This is a Toeplitz matrix.

For n=1000, this matrix has about 1 million entries, which is fine.

Let me think about the overall algorithm:

1. Start with a good initial sequence (the parent or a random one).
2. Repeat:
   a. Normalize f to have sum = sqrt(2n) (or any convenient normalization).
   b. Compute M = max(conv(f, f)).
   c. Solve the LP to get g.
   d. Normalize g to have the same sum as f.
   e. Update: f = (1-t)*f + t*g.
   f. Check if improvement was made.
3. Return the best f found.

The step size t should be small to ensure monotone improvement.
