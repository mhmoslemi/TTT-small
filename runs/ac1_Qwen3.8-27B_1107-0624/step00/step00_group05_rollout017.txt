import time
import cvxpy as cp

def solve_lp_direction(f, M):
    """Solve LP to find direction g that maximizes sum(g) subject to f*g <= M."""
    n = len(f)
    g = cp.Variable(n, nonneg=True)
    
    # Build constraints: (f * g)[k] <= M for k = 0, ..., 2n-2
    # (f * g)[k] = sum_i f[i] * g[k-i] (valid indices only)
    # This is a Toeplitz matrix times g
    
    # Build the Toeplitz matrix efficiently
    # Row k, col j: f[k-j] if 0 <= k-j < n, else 0
    first_col = np.zeros(2*n-1)
    for i in range(n):
        first_col[i] = f[i]
    # Actually, the Toeplitz matrix for convolution has:
    # T[k, j] = f[k-j] if 0 <= k-j < n
    # This is not exactly a standard Toeplitz (which would have T[k,j] = t[k-j])
    # Let me just build it as a sparse matrix.
    
    import scipy.sparse as sp
    rows = []
    cols = []
    vals = []
    for k in range(2*n-1):
        i_start = max(0, k - n + 1)
        i_end = min(n - 1, k)
        for i in range(i_start, i_end + 1):
            j = k - i
            rows.append(k)
            cols.append(j)
            vals.append(f[i])
    
    T = sp.csr_matrix((vals, (rows, cols)), shape=(2*n-1, n))
    
    constraints = [T @ g <= M]
    objective = cp.Maximize(cp.sum(g))
    prob = cp.Problem(objective, constraints)
    
    # Solve with GLOP or ECOS
    try:
        prob.solve(solver=cp.ECOS, max_iters=10000)
    except:
        try:
            prob.solve(solver=cp.GLPK)
        except:
            return None
    
    if g.value is not None and np.isfinite(g.value).all():
        return np.maximum(0, g.value)
    return None

- When $i = j$: $a_j \cdot a_{k-j}$
- When $k-i = j$, i.e., $i = k-j$: $a_{k-j} \cdot a_j$

If $j \neq k-j$ (i.e., $k \neq 2j$), these are two distinct terms, so the derivative is $a_{k-j} + a_{k-j} = 2a_{k-j}$.
If $j = k-j$ (i.e., $k = 2j$), it's a single term $a_j^2$, so the derivative is $2a_j = 2a_{k-j}$.

So in all cases: $\frac{\partial (a*a)[k]}{\partial a_j} = 2a_{k-j}$ (when $0 \leq k-j < n$), and 0 otherwise.

This is clean! The subgradient of the max is a convex combination of these vectors.

**Projected subgradient descent:**
1. Normalize $a$ to have sum 1.
2. Find the set $K = \{k : (a*a)[k] = M\}$ (active set).
3. Compute the subgradient: $s_j = \frac{1}{|K|} \sum_{k \in K} 2a_{k-j}$ (with $a_{k-j} = 0$ if $k-j$ out of range).
4. Update: $a_{\text{new}} = a - \eta \cdot s$ (projected onto the simplex: non-negative, sum = 1).

This is O(n * |K|) per step, which is much faster than an LP.

But subgradient descent is slow to converge. We can accelerate it with:
- Polyak step size
- Nesterov acceleration
- Averaging

Let me combine this with the LP approach: use the LP for occasional "large steps" and subgradient for "small steps" in between.

Actually, let me think about a simpler but effective approach:

**Approach: Iterated LP with warm starts**

1. Start with $f_0 = \text{normalized height\_sequence\_1}$.
2. For each iteration:
   a. Compute $M = \max_k (f*f)[k]$.
   b. Solve the LP to get $g$.
   c. If the LP is infeasible or returns a bad direction, try a random perturbation.
   d. Blend: $f_{\text{new}} = (1-\alpha) f + \alpha \cdot \text{normalize}(g)$.
   e. Accept if the new peak is lower.

    n = len(f)

        coeffs = f[i_start:i_end+1]

        # For i = i_start to i_end: g[k-i]
        # So the coefficient vector for g is: coeffs[j] * g[k - (i_start + j)]

    return None

Wait, building the row in a loop is O(n) per constraint, and we have O(|active|) constraints, so total O(n * |active|). For |active| ~ 50 and n ~ 4500, that's about 225,000 operations per LP setup. That's fine.

For the center constraint ($k = n-1$), all $n$ variables appear. For edge constraints, fewer appear.

Let me think of a faster approach.

**Faster approach: Use the structure of the problem**

The key observation is that the constraint $(f*g)[k] \leq M$ can be written as a dot product: $\text{row}_k \cdot g \leq M$ where $\text{row}_k$ is a shifted version of $f$.

Specifically, $\text{row}_k[j] = f[k-j]$ if $0 \leq k-j < n$, else 0.

This is a "reversed and shifted" version of $f$. I can precompute these rows efficiently using array operations.

Actually, let me think about this differently. Instead of solving an LP, let me use a **direct optimization** approach.

**Direct approach: Minimize the peak using coordinate descent**

At each step:
1. Find the position $k^*$ where the convolution peaks.
2. Reduce the convolution at $k^*$ by adjusting $a$.
3. Make sure other positions don't increase too much.

The gradient of $(a*a)[k^*]$ w.r.t. $a_j$ is $2a_{k^*-j}$ (as derived earlier).

To reduce $(a*a)[k^*]$, we should decrease $a_j$ where $a_{k^*-j}$ is large (and vice versa).

This gives a natural coordinate descent / active set strategy.

**Combined approach:**
1. Use the LP for global direction (every K iterations).
2. Use gradient-based local search between LP calls.
3. Add random restarts to escape local minima.

For the constraint $(f*g)[k] \leq M$:
The coefficient of $g_j$ in this constraint is $f[k-j]$ if $0 \leq k-j < n$, else 0.

So the constraint matrix $A$ (with shape |active| × n) has:
$A[m, j] = f[k_m - j]$ if $0 \leq k_m - j < n$, else 0.

I can build this using broadcasting:

```python
import numpy as np
import time
from scipy.optimize import linprog

def propose_candidate(seed=42, budget_s=1800, **kwargs):
    """
    Minimize 2*n*max(conv(a,a))/(sum(a))^2 using LP-guided local search.
    Combines LP direction finding with step-size adaptation and random perturbations.
    """
    rng = np.random.default_rng(seed)
    deadline = time.monotonic() + max(0.0, float(budget_s) - 5.0)
    
    # Initial sequence
    a = np.clip(np.asarray(height_sequence_1, dtype=np.float64), 0.0, 1000.0).astype(np.float64)
    n = len(a)
    
    # Normalize
    S = a.sum()
    if S < 0.01:
        a = np.ones(n) / np.sqrt(2.0 / n)
    
    best = a.copy()
    best_S = best.sum()
    best_score = float(evaluate_sequence(best.tolist()))
    print(f"Initial: score={best_score:.6f}, n={n}")
    
    no_improve_count = 0
    iter_count = 0
    
    while time.monotonic() < deadline:
        conv = np.convolve(best, best)
        M = conv.max()
        
        # Find active constraints
        threshold = 0.9 * M
        active = np.where(conv >= threshold)[0]
        
        # Build constraint matrix A (|active| x n)
        # A[m, j] = best[k_m - j] if 0 <= k_m - j < n
        k_active = active.astype(np.int64)
        j_idx = np.arange(n)
        diff = k_active[:, None].astype(np.float64) - j_idx[None, :].astype(np.float64)
        
        # Safe indexing
        diff_int = np.clip(diff.astype(np.int64), 0, n - 1)
        mask = (diff >= 0) & (diff < n)
        A = np.where(mask, best[diff_int], 0.0)
        
        # Solve LP: max sum(g) s.t. A @ g <= M, g >= 0
        c = -np.ones(n)  # minimize -sum(g) = maximize sum(g)
        res = linprog(c, A_ub=A, b_ub=np.full(len(active), M), bounds=[(0, None)] * n, method='highs')
        
        if res.status != 0 or res.x is None:
            # Fallback: random perturbation
            candidate = best * np.exp(rng.normal(0, 0.05, n))
            candidate = np.maximum(0, candidate)
            candidate = candidate / candidate.sum() * best_S
            score = float(evaluate_sequence(candidate.tolist()))
            if score < best_score:
                best = candidate
                best_S = best.sum()
                best_score = score
            no_improve_count += 1
            iter_count += 1
            continue
        
        g = np.maximum(0, res.x)
        g_sum = g.sum()
        if g_sum < 1e-10:
            no_improve_count += 1
            iter_count += 1
            continue
        
        # Rescale g to match best's sum
        g = g / g_sum * best_S
        
        # Try different step sizes
        improved = False
        for t in [0.5, 0.3, 0.1, 0.05, 0.02, 0.01]:
            candidate = (1 - t) * best + t * g
            candidate = np.maximum(0, candidate)
            cand_S = candidate.sum()
            if cand_S < 0.01:
                continue
            score = float(evaluate_sequence(candidate.tolist()))
            if score < best_score:
                best = candidate
                best_S = cand_S
                best_score = score
                improved = True
                if iter_count % 10 == 0:
                    print(f"Iter {iter_count}: score={best_score:.6f}, t={t}, |active|={len(active)}")
                break
        
        if improved:
            no_improve_count = 0
        else:
            no_improve_count += 1
        
        # If stuck for too long, try a larger random perturbation
        if no_improve_count > 20:
            candidate = best * np.exp(rng.normal(0, 0.3, n))
            candidate = np.maximum(0, candidate)
            candidate = candidate / candidate.sum() * best_S
            score = float(evaluate_sequence(candidate.tolist()))
            if score < best_score:
                best = candidate
                best_S = best.sum()
                best_score = score
                no_improve_count = 0
                print(f"Iter {iter_count}: escaped local min, score={best_score:.6f}")
            else:
                # Try even larger perturbation
                candidate = best * np.exp(rng.normal(0, 0.5, n))
                candidate = np.maximum(0, candidate)
                candidate = candidate / candidate.sum() * best_S
                score = float(evaluate_sequence(candidate.tolist()))
