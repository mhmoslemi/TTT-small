The solution implements a bilateral diffusion search strategy to find an optimal sequence of non-negative heights for a step function. Unlike previous perturbation approaches, this method maintains two complementary sequences—original and reversed—to explore distinct search spaces. Each iteration applies random block mutations with exponential scaling or reflection to the least performing sequence, evaluating both the original and the mutated version. If an improvement is found, the best candidate is updated and its role swapped. A 10% chance uncertainty budget ensures diversity by occasionally mutating even the best-performing sequence. The algorithm runs for 1800 seconds but exits early if a target bound of 1.5 is exceeded.

def mutate_sequence(seq, rng, max_block_size=None):

        else:  # Exponential scaling (65% of the time)

def mutate_random(seq, rng):
    """Perform random mutation suitable for all seqTypes."""
    scale = np.exp(rng.normal(0.0, 0.12, size=len(seq)))
    # Ensure we don't introduce negatives or inf
    new_seq = np.clip(seq, 0.0, 1000.0) * scale
    return new_seq.tolist()
