```python
def project_simplex(v):
    """Project v onto the simplex {x >= 0, sum(x) = 1}."""
    n = len(v)
    if n == 0:
        return v
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.nonzero(u * np.arange(1, n+1) > (cssv - 1))[0][-1]
    theta = (cssv[rho] - 1) / (rho + 1.0)
    return np.maximum(v - theta, 0)
```

def solve_direction(a, M):
    """Solve LP to find direction g that maximizes sum(g) subject to a*g <= M."""
    n = len(a)
    
    # Constraint matrix: A[i, j] = a[i-j] if valid, 0 otherwise
    # For output position k: sum_j A[k, j] * g[j] <= M
    # A[k, j] = a[j] if 0 <= k-j < n, else 0
    # Wait, let me re-derive.
    # (a * g)[k] = sum_i a[i] * g[k-i]
    # For this to be valid: 0 <= i < n and 0 <= k-i < n
    # So i goes from max(0, k-n+1) to min(n-1, k)
    # Let j = k - i, so j goes from max(0, k-n+1) to min(n-1, k)
    # (a * g)[k] = sum_j a[k-j] * g[j]
    
    # So A[k, j] = a[k-j] if 0 <= k-j < n, else 0
    
    # Build constraint matrix (2n-1 rows, n columns)
    # This is a banded matrix (Toeplitz-like)
    
    A_ub = np.zeros((2*n - 1, n))
    for k in range(2 * n - 1):

        j_min = max(0, k - n + 1)
        j_max = min(n - 1, k)
        for j in range(j_min, j_max + 1):

    c = -np.ones(n)

    else:
        return None

OK so now I understand the problem correctly. The convolution is NOT the autocorrelation in the traditional sense. It's the convolution, which for a with itself is related to but different from the autocorrelation.

Specifically, if we define the autocorrelation as `R[k] = sum_i a[i] * a[i+k]` (for valid i), then:
`np.convolve(a, a)[k] = sum_i a[i] * a[k-i]`

These are different! The autocorrelation R[k] = np.convolve(a, a)[n-1+k]... no that's not right either.
