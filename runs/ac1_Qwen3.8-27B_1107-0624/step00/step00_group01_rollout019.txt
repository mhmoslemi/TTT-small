The LP is: max sum(b) s.t. (a*b)[k] ≤ M for all k, b ≥ 0.

The constraint matrix is the convolution matrix of a (not the generic one). Since a is fixed, the matrix A has A[k,i] = a[k-i] (if valid). This is a banded matrix (actually, it's a "convolution matrix" which is a special type of structured matrix).

For a good initial a (close to optimal), M is close to the optimal max, and the LP should have a solution b that's close to a (since a is already good). So the update a_new = (1-t)*a + t*b would be a small perturbation.

The LP with n=6121 variables and 12241 constraints might take a few seconds to solve. Over 1800 seconds, we might do 300-1000 LP solves. Each LP solve gives a guaranteed improvement (or tells us we're at a local optimum).

But implementing the LP correctly and efficiently is complex. Let me focus on the gradient-based approach first.

"""
Gradient-based optimization of step function coefficients to minimize
J(a) = 2n * max(a*a) / (sum(a))^2 using log-sum-exp smoothing and
FFT-accelerated gradients, combined with multiple restart strategies.
"""

import numpy as np

def convolve_fft(a):
    """Fast self-convolution using FFT. Returns array of length 2*len(a)-1."""
    n = len(a)
    size = 1
    while size < 2 * n - 1:
        size *= 2
    fa = np.fft.rfft(a, size)
    result = np.fft.irfft(fa * fa, size)
    return result[:2 * n - 1]

def compute_J(a):
    """Compute the objective J(a) = 2n * max(a*a) / S^2."""
    n = len(a)
    c = convolve_fft(a)
    S = np.sum(a)
    if S < 0.01:
        return 1e15, c
    max_c = np.max(c)
    J = 2.0 * n * max_c / (S * S)
    return J, c

def smooth_J_and_grad(a, tau):
    """Compute smooth objective and gradient using log-sum-exp."""
    n = len(a)
    c = convolve_fft(a)
    S = np.sum(a)
    if S < 0.01:
        return 1e15, np.zeros(n)
    
    # Log-sum-exp (numerically stable)
    c_max = np.max(c)
    shifted = (c - c_max) / tau
    exp_shifted = np.exp(shifted)
    sum_exp = np.sum(exp_shifted)
    log_sum_exp = c_max / tau + np.log(sum_exp)
    smooth_max = tau * log_sum_exp  # This approximates max(c)
    
    # Probability weights
    p = exp_shifted / sum_exp
    
    J = 2.0 * n * smooth_max / (S * S)
    
    # Gradient computation using FFT
    # d(smooth_max)/da[i] = tau * sum_k p[k] * dc[k]/da[i]
    # dc[k]/da[i] = a[k-i] (if 0≤k-i≤n-1) + a[i-k] (if 0≤i-k≤n-1)
    # sum_k p[k] * a[k-i] = cross-correlation
    # sum_k p[k] * a[i-k] = convolution
    
    size = 1
    while size < 4 * n:
        size *= 2
    
    a_fft = np.fft.rfft(a, size)
    p_fft = np.fft.rfft(p, size)
    
    # cross[i] = sum_k p[k] * a[k-i] (for valid indices)
    cross = np.fft.irfft(np.conj(a_fft) * p_fft, size)[:n]
    # conv[i] = sum_k a[k] * p[i-k] (for valid indices)  
    conv_part = np.fft.irfft(a_fft * p_fft, size)[:n]
    
    grad_smooth_max = tau * (cross + conv_part)
    
    # Full gradient of J = 2n * smooth_max / S^2
    grad = (2.0 * n / (S * S)) * grad_smooth_max - (4.0 * n * smooth_max / (S ** 3)) * np.ones(n)
    
    return J, grad

def simplex_project(v, target_sum):
    """Project v onto {x >= 0, sum(x) = target_sum}."""
    n = len(v)

    # Standard simplex projection

    return result
