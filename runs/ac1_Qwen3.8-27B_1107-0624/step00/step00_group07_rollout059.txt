The constraint matrix for the convolution has a special structure: it's a "Toeplitz-like" matrix (actually, it's the convolution matrix, which is a sum of shifted identity matrices). Each row k has nonzeros in columns max(0, k-n+1) to min(n-1, k), with value f[j] in column j.

Alternative: Instead of solving the full LP, we can use a first-order method on the dual.

The dual of the LP:
- Primal: max `c^T g` s.t. `A g <= M * 1`, `g >= 0` (where c = 1 vector, A is the convolution matrix)
- Dual: min `M * 1^T y` s.t. `A^T y >= c`, `y >= 0`

The dual has 13465 variables and 6733 constraints. Still large.

Alternatively, we can use a subgradient method on the primal:
- Start with `g = f` (or some initial guess).
- Find the most violated constraint: `k* = argmax (f*g)[k]`.
- If `(f*g)[k*] > M`, scale down: `g *= M / (f*g)[k*]`.
- Project back to `g >= 0`.
- Repeat until all constraints are satisfied.
- Then, to increase `sum(g)`, add mass where constraints are not tight.

This is essentially a cutting plane / constraint generation approach. Let me think about whether this converges.

Actually, a simpler approach: **Multiplicative Weight Updates / Mirror Descent on the LP**

For the LP: max `sum(g)` s.t. `A g <= M`, `g >= 0`:
- Initialize `g = 1/n` (uniform).
- At each iteration, find the most violated constraint: `k* = argmax (A g)[k]`.
- Update: `g[i] *= exp(-eta * A[k*, i])` (for all i).
- This is the multiplicative weight update for LPs.

After enough iterations, `g` will be approximately feasible. Then we normalize and use it.

The number of iterations needed is O(n * log(n) / epsilon) for epsilon-optimality, which might be too many.

**Phase 1: Iterative tapering**

The idea: if the convolution has a peak at position k*, we want to reduce the contributions to that peak. The contribution of `a[i]` to `c[k*]` is `a[k*-i]` (times `a[i]`). So we want to reduce `a[i]` for positions where `a[k*-i]` is large.

This is equivalent to: `a[i] *= (1 / (1 + eta * a[k*-i]))` for the peak positions.

But we might have multiple peaks. A better approach:

1. Compute `c = conv(a, a)`.
2. Let `T` be the target maximum (initially `max(c)`, decreasing over time).
3. For positions where `c[k] > T`, compute the "excess": `E[k] = c[k] - T`.
4. The "pressure" on `a[i]` is: `P[i] = sum_{k: c[k]>T} E[k] * a[k-i] / c[k]` (weighted by relative excess).
5. Update: `a[i] *= exp(-eta * P[i])`.
6. Renormalize.
