    return 2.0 * n * M / (S * S)

Let me also think about the "shape" of a good sequence. If we want c[k] to be roughly constant (flat), what shape should a have?

In the frequency domain: c = a * a (linear convolution) corresponds to C = |A|^2 (where A is the DFT of zero-padded a).

For c to be flat (constant), we need |A|^2 to be constant, i.e., |A[k]| = constant for all k. This means a is a "flat spectrum" signal, like white noise.

But a must be non-negative! A non-negative sequence with a flat spectrum is essentially a "random" non-negative signal. But we've seen that random non-negative sequences give worse scores than the constant sequence.

The issue is that the linear convolution has a "triangular" envelope due to the zero-padding. Even if the circular autocorrelation is flat, the linear convolution has the triangular edge effects.

To compensate for the triangular envelope, we want c[k] to follow the triangular shape but scaled down. The "ideal" c[k] proportional to the number of valid pairs (the triangular envelope) would mean c[k]/m(k) = constant, where m(k) is the number of pairs.

m(k) = min(k+1, n, 2n-1-k)

So the "ideal" c[k] = (S^2/(2n-1)) * 1 (uniform) is not quite right. Actually, the sum of all c[k] = S^2, and there are 2n-1 values. The "average" is S^2/(2n-1). But the "natural" distribution (from a constant sequence) is triangular: c[k] = m(k) * (S/n)^2.

For the constant sequence: c[k] = m(k) * S^2/n^2, and max = n * S^2/n^2 = S^2/n. Score = 2.

For a "flatter" distribution: c[k] = S^2/(2n-1) for all k. Max = S^2/(2n-1). Score = 2n/(2n-1) ≈ 1.

So the theoretical minimum is 1, achieved by a perfectly flat convolution. This is the "ideal" we're targeting.
