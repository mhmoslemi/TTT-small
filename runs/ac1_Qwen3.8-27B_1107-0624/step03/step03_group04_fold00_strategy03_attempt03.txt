- Periodically reset dimension vectors to escape local minima
- Scale all step sizes to favor normalized sequences over others

### Compute budget and robustness
- Maximum runtime: 1800 seconds, but clock time is tracked
- Each evaluation: bounded time to prevent overflow
- Built-in exponential smoothing of the search trajectory
- Fallback to minimal random search if optimization parameters blow up

### Validation and return contract
- Every major adjustment is scored using `evaluate_sequence`
- If theoretical minimum is hit, we verify via secondary analysis
- Final output is formatted as a list of floats
