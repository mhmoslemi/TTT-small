    return 2.0 * n * grad_z, p, c, w, mval

Let me simplify the gradient computation. Instead of the full analytical gradient, I can use the following:

The objective is f(z) = 2n * S(c, beta) where c = conv(p, p), p = softmax(z), and S(c, beta) = logsumexp(beta * c) / beta (smooth max).

The gradient:
df/dz = 2n * (1/beta) * d(logsumexp(beta*c))/dz
= 2n * sum_k w_k * (dc_k/dz)
where w_k = exp(beta*c_k) / sum_j exp(beta*c_j)

dc_k/dz_i = dc_k/dp_i * dp_i/dz_i + sum_{j!=i} dc_k/dp_j * dp_j/dz_i

This is complex. Let me just use the cross-correlation approach:

F = sum_k w_k c_k = <w, conv(p,p)>

The gradient of F w.r.t. p:
dF/dp_i = sum_k w_k * dc_k/dp_i

Now, c_k = sum_j p_j * p_{k-j} (with valid indices).
dc_k/dp_i: p_i appears in c_k when j=i (term p_i * p_{k-i}) or when k-j=i i.e. j=k-i (term p_{k-i} * p_i).
So dc_k/dp_i = p_{k-i} + p_{k-i} = 2*p_{k-i} (when both i and k-i are valid and i != k-i)
dc_k/dp_i = p_i (when i = k-i, i.e., k = 2i)

So dF/dp_i = sum_k w_k * 2*p_{k-i} (approximately, ignoring the diagonal)
= 2 * sum_k w_k * p_{k-i}
= 2 * (cross-correlation of w and p at lag i)

This is the key formula. The cross-correlation can be computed efficiently via FFT.

Let me define: xcorr_i = sum_k w_k * p_{k-i} for valid indices.
Then dF/dp_i = 2 * xcorr_i (approximately).

And then:
dF/dz_i = p_i * (dF/dp_i - sum_j p_j * dF/dp_j)
= p_i * (2*xcorr_i - 2*sum_j p_j * xcorr_j)
= 2*p_i * (xcorr_i - <p, xcorr>)

This is clean. Let me implement this.

For the FFT computation of xcorr:
xcorr_i = sum_k w_k * p_{k-i}

where w has length 2n-1 (indices 0 to 2n-2) and p has length n (indices 0 to n-1).
We need xcorr_i for i in [0, n-1].

xcorr_i = sum_{k=i}^{2n-2} w_k * p_{k-i} (with p_{k-i} = 0 if k-i >= n)
= sum_{m=0}^{min(n-1, 2n-2-i)} w_{m+i} * p_m

This is the cross-correlation of w and p. Using FFT:
Let N >= (2n-1) + n - 1 = 3n - 2.
xcorr = ifft(fft(w, N) * conj(fft(p, N)))[:n]

Wait, I need to be careful about the convention. Let me verify:
ifft(fft(w) * conj(fft(p)))[i] = sum_n w[n] * p[(n-i) mod N]

With sufficient zero-padding (N >= len(w) + len(p) - 1), this gives the linear cross-correlation:
= sum_n w[n] * p[n-i] (where p is zero outside [0, n-1])

So xcorr[i] = sum_n w[n] * p[n-i] for i in [0, ...]

This is exactly what we want (with the understanding that p[n-i] = 0 when n-i is outside [0, n-1]).

Great, so the gradient computation is:
1. Compute p = softmax(z)
2. Compute c = conv(p, p)
3. Compute w = softmax(beta * c) (the weights for smooth-max)
4. Compute xcorr = ifft(fft(w, N) * conj(fft(p, N)))[:n]
5. grad_z = 2 * n * p * (xcorr - dot(p, xcorr))

This should be efficient (O(n log n) per iteration).

Now, for the L-BFGS optimization, I'll use scipy.optimize.minimize with:
- fun = objective (smooth-max score)
- jac = gradient
- method = 'L-BFGS-B'
- options: maxiter, ftol, gtol

The challenge is that the smooth-max approximation changes with beta. I'll use an adaptive beta that starts large (smooth) and decreases (sharper) over iterations.

Actually, for L-BFGS to work well, the objective should be smooth and the gradient should be accurate. If I change beta during optimization, the objective changes, which can hurt convergence. So I'll use a fixed beta for each L-BFGS call, and do multiple L-BFGS calls with decreasing beta (like a continuation method).

"""
Multi-phase optimization minimizing 2*n*max(conv(a,a))/sum(a)^2.
Uses L-BFGS in softmax space with adaptive smooth-max, LP refinement,
diverse structured initializations, and multi-scale exploration.
"""
import numpy as np
from scipy.optimize import linprog, minimize
from scipy.sparse import csr_matrix
import time


def _next_pow2(n):
    k = 1
    while k < n:
        k <<= 1
    return max(2, k)


def _full_convolve(a):
    a = np.asarray(a, dtype=np.float64).ravel()
    n = a.size
    if n == 0:
        return np.array([])
    N = _next_pow2(2 * n - 1)
    fa = np.fft.rfft(a, N)
    c = np.fft.irfft(fa * fa, N)[:2 * n - 1]
    c = np.maximum(c, 0.0)
    return c


def _softmax(z, floor=1e-15):
    z = np.asarray(z, dtype=np.float64).ravel()
    z = np.clip(z, -500.0, 500.0)
    z = z - float(np.max(z))
    e = np.exp(z)
    p = e + floor
    s = float(p.sum())
    if s <= 0:
        return np.ones_like(e) / float(e.size)
    return p / s


def _score_norm(p):
    n = len(p)
    c = _full_convolve(p)
    return float(2.0 * n * c.max())


def _smooth_max_score(z, beta, n):
    """Compute smooth-max score and its gradient w.r.t. z."""
    p = _softmax(z)
    c = _full_convolve(p)
    mval = float(c.max())
    x = (c - mval) / beta
    # Clip to prevent overflow
    x = np.clip(x, -50.0, 50.0)
    ex = np.exp(x)
    s = float(ex.sum())
    if not np.isfinite(s) or s <= 0:
        return 2.0 * n * mval, np.zeros_like(z)
    val = mval + beta * float(np.log(s))
    w = ex / s
    
    # Gradient computation
    n_p = n
    N = _next_pow2(3 * n_p - 2)
    fw = np.fft.rfft(w, N)
    fp = np.fft.rfft(p, N)
    xcorr = np.fft.irfft(fw * np.conj(fp), N)[:n_p]
    
    dot = float(np.dot(p, xcorr))
    grad_z = 2.0 * n * p * (xcorr - dot)
    
    if not np.all(np.isfinite(grad_z)):
        grad_z = np.zeros_like(z)
    
    return 2.0 * n * val, grad_z


def _lbfgs_optimize(p0, deadline, rng, beta_start=0.1, beta_end=0.01, 
                     n_continuation=5, maxiter_per_stage=200):
    """L-BFGS optimization with continuation on beta."""
    n = len(p0)
    z = np.log(np.maximum(p0, 1e-15))
    z -= float(np.mean(z))
    
    best_p = p0.copy()
    best_score = _score_norm(p0)
    time_per_stage = max(5.0, (deadline - time.monotonic()) / n_continuation)
    
    for stage in range(n_continuation):
        if time.monotonic() > deadline:
            break
        t_remaining = deadline - time.monotonic()
        if t_remaining < 5.0:
            break
        
        # Interpolate beta
        frac = stage / max(1, n_continuation - 1)
        beta = beta_start * (beta_end / beta_start) ** frac
        
        stage_end = min(deadline, time.monotonic() + time_per_stage)
        
        def obj_fn(z):
            val, _ = _smooth_max_score(z, beta, n)
            return val
        
        def jac_fn(z):
            _, grad = _smooth_max_score(z, beta, n)
            return grad
        
        try:
            res = minimize(obj_fn, z, jac=jac_fn, method='L-BFGS-B',
                          options={'maxiter': maxiter_per_stage, 'ftol': 1e-10, 
                                   'gtol': 1e-8, 'maxfun': 5000})
        except Exception:
            break
        
        p_new = _softmax(res.x)
        sc_new = _score_norm(p_new)
        if sc_new < best_score:
            best_score = sc_new
            best_p = p_new.copy()
        z = res.x
    
    return best_p, best_score


def _lp_refine(a, deadline, t=0.3, max_solves=15, top_k=-1):
    """LP-based refinement. If top_k > 0, only use top-k constraints."""
    n = len(a)
    current_best = a.copy()
    current_score = _score_norm(a)
    c = _full_convolve(a)
    M = float(c.max())
    n_solves = 0
    
    while time.monotonic() < deadline and n_solves < max_solves:
        n_solves += 1
        
        # Determine which constraints to use
        if top_k > 0 and top_k < 2 * n - 1:
            top_indices = np.argsort(c)[::-1][:top_k]
            k_list = top_indices
        else:
            k_list = np.arange(2 * n - 1)
        
        rows = []
        cols = []
        vals = []
        b_vec = []
        for k in k_list:
            j_start = max(0, k - n + 1)
            j_end = min(n - 1, k)
            if j_start <= j_end:
                idx = np.arange(j_start, j_end + 1)
                row_idx = len(rows) // max(1, len(idx)) if len(idx) > 0 else 0
                # We need to track row index separately
                pass
        
        # Build sparse matrix
        row_list = []
        col_list = []
        val_list = []
        row_idx = 0
        for k in k_list:
            j_start = max(0, k - n + 1)
            j_end = min(n - 1, k)
            if j_start <= j_end:
                idx = np.arange(j_start, j_end + 1)
                row_list.extend([row_idx] * len(idx))
                col_list.extend(idx.tolist())
                val_list.extend(a[k - idx].tolist())
                b_vec.append(M)
                row_idx += 1
        
        n_rows = len(b_vec)
        A_ub = csr_matrix((val_list, (row_list, col_list)), shape=(n_rows, n))
        c_obj = -np.ones(n)
        res = linprog(c_obj, A_ub=A_ub, b_ub=np.array(b_vec), 
                     bounds=[(0, None)] * n, method='highs')
        
        if not res.success:
            break
        b = np.maximum(res.x, 0.0)
        s_b = float(b.sum())
        if s_b < 1e-10:
            break
        b_norm = b / s_b
        a_new = (1.0 - t) * a + t * b_norm
        a_new = np.maximum(a_new, 1e-15)
        a_new = a_new / a_new.sum()
        sc_new = _score_norm(a_new)
        if sc_new < current_score:
            current_score = sc_new
            current_best = a_new.copy()
        a = a_new
        c = _full_convolve(a)
        M = float(c.max())
        t = max(0.1, t * 0.95)
    
    return current_best, current_score


def _make_chirp(n):
    """Chirp-like sequence: a_j = 1 + eps * sin(2*pi * j^2 / n) (non-negative part)"""
    j = np.arange(n)
    a = 1.0 + 0.5 * np.sin(2.0 * np.pi * j * j / n)
    a = np.maximum(a, 0.01)
    return a / a.sum()


def _make_m_seq_like(n):
    """M-sequence-inspired: alternating pattern with smooth transitions"""
    j = np.arange(n)
    # Use a sum of harmonics
    a = np.zeros(n)
    for k in [1, 3, 5, 7, 11]:
        a += np.cos(2.0 * np.pi * k * j / n + 0.3 * k)
    a = a - a.min() + 0.1
    return a / a.sum()


def _make_profile_linear(n, eta):
    t = np.linspace(0.0, 1.0, n)
    a = 1.0 + eta * (t - 0.5) * 2.0
    a = np.maximum(a, 0.01)
    return a / a.sum()


def _make_profile_cosine(n, freq, amp):
    t = np.arange(n)
    a = 1.0 + amp * np.cos(2.0 * np.pi * freq * t / n)
    a = np.maximum(a, 0.01)
    return a / a.sum()


def _make_profile_quadratic(n, c):
    t = np.linspace(-1.0, 1.0, n)
    a = 1.0 + c * t * t
    a = np.maximum(a, 0.01)
    return a / a.sum()


def _make_profile_fourier(n, coeffs):
    """Create sequence from Fourier coefficients: a_j = 1 + sum_k c_k * cos(2*pi*k*j/n + phase_k)"""
    j = np.arange(n)
    a = np.ones(n)
    for k, amp, phase in coeffs:
        a += amp * np.cos(2.0 * np.pi * k * j / n + phase)
    a = np.maximum(a, 0.01)
    return a / a.sum()

"""
Multi-phase optimization minimizing 2*n*max(conv(a,a))/sum(a)^2.
Uses L-BFGS in softmax space with adaptive smooth-max continuation,
top-K LP refinement, diverse structured initializations (chirps, Fourier,
m-sequences), and multi-scale exploration to beat 1.506320.
"""
import numpy as np
from scipy.optimize import linprog, minimize
from scipy.sparse import csr_matrix
import time


def _next_pow2(n):
    k = 1
    while k < n:
        k <<= 1
    return max(2, k)


def _full_convolve(a):
    a = np.asarray(a, dtype=np.float64).ravel()
    n = a.size
    if n == 0:
        return np.array([])
    N = _next_pow2(2 * n - 1)
    fa = np.fft.rfft(a, N)
    c = np.fft.irfft(fa * fa, N)[:2 * n - 1]
    c = np.maximum(c, 0.0)
    return c


def _softmax(z, floor=1e-15):
    z = np.asarray(z, dtype=np.float64).ravel()
    z = np.clip(z, -500.0, 500.0)
    z = z - float(np.max(z))
    e = np.exp(z)
    p = e + floor
    s = float(p.sum())
    if s <= 0 or not np.isfinite(s):
        return np.ones_like(e) / float(e.size)
    return p / s


def _score_norm(p):
    n = len(p)
    c = _full_convolve(p)
    return float(2.0 * n * c.max())


def _smooth_max_score_and_grad(z, beta, n):
    """Compute smooth-max score and gradient w.r.t. z. Returns (score, grad)."""
    p = _softmax(z)
    c = _full_convolve(p)
    mval = float(c.max())
    x = (c - mval) / beta
    x = np.clip(x, -50.0, 50.0)
    ex = np.exp(x)
    s = float(ex.sum())
    if not np.isfinite(s) or s <= 0:
        return 2.0 * n * mval, np.zeros_like(z)
    val = mval + beta * float(np.log(s))
    w = ex / s

    # Gradient: 2*n * p * (xcorr(w,p) - dot(p, xcorr(w,p)))
    N = _next_pow2(3 * n - 2)
    fw = np.fft.rfft(w, N)
    fp = np.fft.rfft(p, N)
    xcorr = np.fft.irfft(fw * np.conj(fp), N)[:n]

    dot = float(np.dot(p, xcorr))
    grad_z = 2.0 * n * p * (xcorr - dot)

    if not np.all(np.isfinite(grad_z)):
        grad_z = np.zeros_like(z)

    return 2.0 * n * val, grad_z


def _lbfgs_optimize(p0, deadline, beta_start=0.08, beta_end=0.005,
                    n_continuation=5, maxiter_per_stage=300, maxfun_per_stage=5000):
    """L-BFGS optimization with continuation on beta (smooth-max temperature)."""
    n = len(p0)
    z = np.log(np.maximum(p0, 1e-15))
    z -= float(np.mean(z))

    best_p = p0.copy()
    best_score = _score_norm(p0)

    for stage in range(n_continuation):
        if time.monotonic() > deadline:
            break
        t_remaining = deadline - time.monotonic()
        if t_remaining < 5.0:
            break

        frac = stage / max(1, n_continuation - 1)
        beta = beta_start * (beta_end / beta_start) ** frac

        def obj_fn(z_inner):
            val, _ = _smooth_max_score_and_grad(z_inner, beta, n)
            return val

        def jac_fn(z_inner):
            _, grad = _smooth_max_score_and_grad(z_inner, beta, n)
            return grad

        try:
            res = minimize(obj_fn, z, jac=jac_fn, method='L-BFGS-B',
                          options={'maxiter': maxiter_per_stage, 'ftol': 1e-12,
                                   'gtol': 1e-9, 'maxfun': maxfun_per_stage,
                                   'maxls': 50})
        except Exception:
            break

        p_new = _softmax(res.x)
        sc_new = _score_norm(p_new)
        if sc_new < best_score:
            best_score = sc_new
            best_p = p_new.copy()
        if np.all(np.isfinite(res.x)):
            z = res.x
        # Re-center z to prevent drift
        z -= float(np.mean(z))

    return best_p, best_score


def _lp_refine(a, deadline, t=0.35, max_solves=15, top_k=-1):
    """LP-based refinement: find direction b maximizing sum(b) s.t. conv(a,b)<=M."""
    n = len(a)
    current_best = a.copy()
    current_score = _score_norm(a)
    c = _full_convolve(a)
    M = float(c.max())
    n_solves = 0

    while time.monotonic() < deadline and n_solves < max_solves:
        n_solves += 1

        if top_k > 0 and top_k < 2 * n - 1:
            top_indices = np.argsort(c)[::-1][:top_k]
            k_list = top_indices
        else:
            k_list = np.arange(2 * n - 1)

        row_list = []
        col_list = []
        val_list = []
        b_vec = []
        row_idx = 0
        for k in k_list:
            j_start = max(0, k - n + 1)
            j_end = min(n - 1, k)
            if j_start <= j_end:
                idx = np.arange(j_start, j_end + 1)
                row_list.extend([row_idx] * len(idx))
                col_list.extend(idx.tolist())
                val_list.extend(a[k - idx].tolist())
                b_vec.append(M)
                row_idx += 1

        n_rows = len(b_vec)
        if n_rows == 0:
            break
        A_ub = csr_matrix((val_list, (row_list, col_list)), shape=(n_rows, n))
        c_obj = -np.ones(n)
        res = linprog(c_obj, A_ub=A_ub, b_ub=np.array(b_vec),
                     bounds=[(0, None)] * n, method='highs')

        if not res.success:
            break
        b = np.maximum(res.x, 0.0)
        s_b = float(b.sum())
        if s_b < 1e-10:
            break
        b_norm = b / s_b
        a_new = (1.0 - t) * a + t * b_norm
        a_new = np.maximum(a_new, 1e-15)
        a_new = a_new / a_new.sum()
        sc_new = _score_norm(a_new)
        if sc_new < current_score:
            current_score = sc_new
            current_best = a_new.copy()
        a = a_new
        c = _full_convolve(a)
        M = float(c.max())
        t = max(0.05, t * 0.92)

    return current_best, current_score


def _make_chirp(n):
    j = np.arange(n)
    a = 1.0 + 0.5 * np.sin(2.0 * np.pi * j * j / n)
    a = np.maximum(a, 0.01)
    return a / a.sum()


def _make_m_seq_like(n):
    j = np.arange(n)
    a = np.zeros(n)
    for k in [1, 3, 5, 7, 11, 13]:
        a += np.cos(2.0 * np.pi * k * j / n + 0.3 * k)
    a = a - a.min() + 0.1
    return a / a.sum()


def _make_profile_linear(n, eta):
    t = np.linspace(0.0, 1.0, n)
    a = 1.0 + eta * (t - 0.5) * 2.0
    a = np.maximum(a, 0.01)
    return a / a.sum()


def _make_profile_cosine(n, freq, amp):
    t = np.arange(n)
    a = 1.0 + amp * np.cos(2.0 * np.pi * freq * t / n)
    a = np.maximum(a, 0.01)
    return a / a.sum()


def _make_profile_quadratic(n, c):
    t = np.linspace(-1.0, 1.0, n)
    a = 1.0 + c * t * t
    a = np.maximum(a, 0.01)
    return a / a.sum()


def _make_profile_fourier(n, coeffs):
    j = np.arange(n)
    a = np.ones(n)
    for k, amp, phase in coeffs:
        a += amp * np.cos(2.0 * np.pi * k * j / n + phase)
    a = np.maximum(a, 0.01)
    return a / a.sum()


def _make_profile_semicircle(n, sharp=1.0):
    t = np.linspace(-1.0, 1.0, n)
    a = np.sqrt(np.maximum(1.0 - t * t, 0.0)) ** sharp + 0.05
    return a / a.sum()

                _update(p_lp2, sc_lp2, 'LP_topK50')

    # --- Phase 4: Post-LP L-BFGS polish ---
    phase4_end = t_start + 1350.0
    if best_seq is not None and time.monotonic() < phase4_end:
        time_per = min(120.0, phase4_end - time.monotonic() - 10.0)
        if time_per > 15.0:
            print(f"  Post-LP L-BFGS polish (budget {time_per:.0f}s)")
            p_pol, sc_pol = _lbfgs_optimize(best_seq, time.monotonic() + time_per, rng,
                                             beta_start=0.03, beta_end=0.001,
                                             n_continuation=4, maxiter_per_stage=300)
            _update(p_pol, sc_pol, 'post_lp_polish')

    # --- Phase 5: Multi-restart with different perturbations ---
    phase5_end = deadline - 40.0
    if best_seq is not None and time.monotonic() < phase5_end:
        n_best = best_seq.size
        n_restarts = 4
        per_r = max(25.0, (phase5_end - time.monotonic()) / max(1, n_restarts))
        for i in range(n_restarts):
            if time.monotonic() > phase5_end:
                break
            per = min(per_r, phase5_end - time.monotonic() - 5.0)
            if per < 12:
                break
            noise = 0.04 + 0.06 * i
            z = np.log(np.maximum(best_seq, 1e-12))
            z = z + noise * rng.normal(size=n_best)
            z -= z.mean()
            p_s = _softmax(z)
            sc_s = _score_norm(p_s)
            _update(p_s, sc_s, f'restart{i}_init')
            p_r, sc_r = _lbfgs_optimize(p_s, time.monotonic() + per, rng,
                                         beta_start=0.05, beta_end=0.003,
                                         n_continuation=3, maxiter_per_stage=250)
            _update(p_r, sc_r, f'restart{i}_n{n_best}')

    # --- Phase 6: Final LP + polish ---
    if best_seq is not None and time.monotonic() < deadline - 10 and best_seq.size <= 4096:
        per = min(50.0, deadline - time.monotonic() - 5.0)
        if per > 10:
            p_final, sc_final = _lp_refine(best_seq, time.monotonic() + per,
                                            t=0.15, max_solves=8, top_k=30)
            _update(p_final, sc_final, 'final_LP')

    # --- Final validation ---
    if best_seq is not None:
        final = np.clip(best_seq, 0.0, 1000.0)
        s = float(final.sum())
        if s > 0.01:
            final = final / s
        else:
            final = _make_profile_linear(1024, 1.0)

        exact_sc = _score_norm(final)
        print(f"FINAL: score={exact_sc:.10f} n={final.size}")

        try:
            eval_sc = float(evaluate_sequence([float(x) for x in final]))
            if np.isfinite(eval_sc):
                print(f"EVAL: {eval_sc:.10f}")
            else:
                print("EVAL returned inf!")
        except Exception as e:
            print(f"EVAL error: {e}")

        return [float(x) for x in final]

    # Fallback
    fb = _make_profile_linear(1024, 1.0)
    print(f"FALLBACK n=1024")
    return [float(x) for x in fb]
