Actually, one more thought: the problem has a nice structure that I can exploit. The objective is:
f(a) = 2n * max_k (a*a)[k] / (sum a)^2

If I fix the active set {k1, k2, ..., km} (the positions where the max is achieved), then:
f(a) = 2n * max(g1(a), ..., gm(a)) / (sum a)^2

where gk(a) = (a*a)[k].

Each gk is a quadratic form: gk(a) = a^T Q_k a where Q_k is a "shifted reverse" matrix.

If I fix the active set and the value of the max (say T), the problem becomes:
minimize T
subject to: gk(a) <= T for k in active set
            sum(a) = 1
            a >= 0

This is a quadratically constrained optimization problem. For small active sets (2-4 constraints), this is tractable.

For 2 constraints g1(a) <= T and g2(a) <= T:
This is an intersection of two quadratic regions, which defines a "lens" shape. The minimum T is where the two quadratics are tangent (or touch at a boundary point).

Multi-strategy optimization for minimizing 2n*max(conv(a,a))/sum(a)^2.
Combines KKT fixed-point, adaptive soft-max Adam, and scipy polish.
"""

def compute_score(a):
    a = np.asarray(a, dtype=np.float64).ravel()
    n = a.size
    if n == 0:
        return np.inf
    s = float(a.sum())
    if s < 0.01:
        return np.inf
    c = np.convolve(a, a)
    return float(2.0 * n * c.max() / (s * s))

def next_pow2(n):
    k = 1
    while k < n:
        k <<= 1
    return max(2, k)

def full_convolve_fft(a):
    n = a.size
    if n == 0:
        return np.array([], dtype=np.float64)
    if n <= 64:
        return np.convolve(a, a)
    N = next_pow2(2 * n - 1)
    fa = np.fft.rfft(a, N)
    c = np.fft.irfft(fa * fa, N)[:2 * n - 1]
    c = np.maximum(c, 0.0)
    return c

def compute_h(w, a):
    """h[i] = sum_k w[k] * a[k-i] (valid indices only)"""
    n = len(a)
    # h[i] = sum_k w[k] * a[k-i] where k-i is in [0, n-1]
    # Equivalently: h = ifft(w * fft(a_reversed)) with appropriate slicing
    # Or: h[i] = (w_rev * a)[i] where w_rev = w reversed
    # Let's use: h[i] = sum_k w[k] a[k-i]
    # Let j = k-i, k = i+j: h[i] = sum_j w[i+j] a[j]
    # This is a "Hankel" product. We can compute it via FFT:
    # h[i] = sum_j w[i+j] a[j]
    # Define W_rev[m] = w[2n-2-m] (reverse of w)
    # Then h[i] = sum_j W_rev[2n-2-i-j] a[j] = (W_rev * a)[2n-2-i]... 
    # Hmm, this is getting complicated. Let me use a direct approach with FFT.
    # 
    # Alternative: h[i] = (a * w_padded)[i + n - 1] where w_padded is w with appropriate padding
    # Actually, the simplest is: h[i] = sum_k w[k] a[k-i]
    # Note that this is the cross-correlation of w and a at lag i, but with a flip.
    # 
    # Let me use: define b = a reversed. Then h[i] = sum_k w[k] a[k-i] = sum_k w[k] b[n-1-(k-i)]
    # = sum_k w[k] b[n-1-k+i] = (w * b)[n-1+i] (convolution of w and b, evaluated at n-1+i)
    
    b = a[::-1]

    fw = np.fft.rfft(w, N)
    fb = np.fft.rfft(b, N)
    conv = np.fft.irfft(fw * fb, N)
    # h[i] = conv[n-1+i] for i = 0, ..., n-1
    return conv[n-1:2*n-1]

def soft_max_weights(c, beta):
    mval = float(c.max())
    if beta < 1e-14:
        w = np.zeros_like(c)
        mask = c >= mval - 1e-10 * max(1, mval)
        cnt = int(np.count_nonzero(mask))
        if cnt == 0:
            w[int(np.argmax(c))] = 1.0
        else:
            w[mask] = 1.0 / cnt
        return mval, w
    x = (c - mval) / beta
    x = np.clip(x, -60.0, 0.0)
    ex = np.exp(x)
    s = float(np.sum(ex))
    if s < 1e-300:
        ex = np.zeros_like(c)
        ex[int(np.argmax(c))] = 1.0
        s = 1.0
    val = mval + beta * float(np.log(s))
    w = ex / s
    return val, w
