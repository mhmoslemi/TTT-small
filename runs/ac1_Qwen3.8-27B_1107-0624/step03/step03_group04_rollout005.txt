        alpha = 0.5 + 0.5 * (1 - t)  # Start with more flattening, reduce over time
        phase = np.angle(fa)
        current_mag = np.abs(fa)
        new_mag = current_mag * (1 - alpha) + target_mag * alpha
        # Preserve DC
        new_mag[0] = fa[0].real
        
        new_fa = new_mag * np.exp(1j * phase)
        a_new = np.fft.irfft(new_fa, N)[:n]
        a_new = np.maximum(a_new, 0.0)
        s = a_new.sum()
        if s < 1e-20:
            break
        a_new = a_new / s
        
        # Relaxation
        a_new = (1 - relax) * a + relax * a_new
        a_new = np.maximum(a_new, 0.0)
        a_new = a_new / a_new.sum()
        
        sc = _score(a_new)
        if sc < best_score:
            best_score = sc
            best_a = a_new.copy()
        
        a = a_new
    
    return best_a

Hmm, but I realize the soft flattening with alpha might not be ideal. Let me think about this differently.

The key insight is: in the Fourier domain, we want |A_k| to be as flat as possible. The "pressure" to flatten is proportional to how much |A_k| deviates from the mean. So we could use:

|A_k|_new = mean(|A|) + gamma * (|A_k| - mean(|A|))

where gamma < 1 controls the strength of flattening. gamma = 0 gives full flattening, gamma = 1 gives no change.

Or alternatively, we could directly minimize the variance of |A_k| subject to the non-negativity constraint. This is a more principled approach.

Actually, let me think about this problem from a different angle. The objective is:

score = 2n * max_k (a*a)[k] / (sum a)^2

Let's normalize sum(a) = 1. Then score = 2n * max_k (a*a)[k].

We want to minimize max_k (a*a)[k] subject to a >= 0, sum(a) = 1.

This is equivalent to: minimize t subject to (a*a)[k] <= t for all k, a >= 0, sum(a) = 1.

The constraint (a*a)[k] <= t is quadratic in a. This is a non-convex QCQP.

However, we can use the following observation: if we fix all variables except a_i, the constraint (a*a)[k] <= t becomes quadratic in a_i, which is a "single-variable" quadratic constraint. This could be handled by a bisection/coordinate descent approach.

**Coordinate Descent Approach:**
For each coordinate i:
- Fix all a_j for j != i
- The autocorrelation values that involve a_i are: (a*a)[k] for k where the term a_i * a_{k-i} appears
- Specifically, (a*a)[k] = sum_j a_j * a_{k-j}. The terms involving a_i are: a_i * a_{k-i} (if k-i is in [0, n-1])
- So (a*a)[k] = (a*a)_without_i[k] + a_i * a_{k-i} for k = i, i+1, ..., i+n-1 (approximately)
- We want to find a_i that minimizes max_k (a*a)[k] subject to a_i >= 0 and sum(a) = 1

This is a 1D optimization problem! For a fixed a_i, the max autocorrelation as a function of a_i is the max of several linear functions (since each (a*a)[k] is linear in a_i when other variables are fixed). The minimum of the max of linear functions is a convex optimization problem in 1D, solvable by bisection or ternary search.

Wait, but we also have the constraint sum(a) = 1. If we change a_i, we need to adjust another variable to maintain the sum. This complicates things.

Alternative: work in the "simplex" coordinate system. Fix the sum constraint by expressing one variable in terms of the others. Or use the logit parameterization.

Actually, let me think about this more carefully. The coordinate descent with sum constraint:
- We have a_0 + a_1 + ... + a_{n-1} = 1
- Fix a_1, ..., a_{n-1}, optimize a_0 = 1 - sum(a_1, ..., a_{n-1})
- But this makes a_0 depend on all others, which is not great for coordinate descent

Better approach: use the logit (or softmax) parameterization:
- z_0, ..., z_{n-1} are free parameters
- a_i = exp(z_i) / sum(exp(z_j))
- Optimize over z

In this parameterization, the sum constraint is automatically satisfied, and the non-negativity is automatic. The objective becomes:
f(z) = 2n * max_k (softmax(z) * softmax(z))[k]

This is a smooth function of z (if we use a smooth max), and we can use gradient descent.

But this is essentially what the previous program does! The logit-space Adam optimization.

So let me think about what's different about my approach:

1. **GS provides a different trajectory in the optimization landscape**: While gradient descent follows the steepest descent direction, GS alternates between two "projections" (flat magnitude in Fourier domain, non-negativity in time domain). This can escape local minima that trap gradient descent.

2. **GS is very fast**: Each iteration is O(n log n), so we can do millions of iterations in the time budget.

3. **The combination of GS + LP + gradient might be more effective than any single method alone**.

Let me also think about a key question: what does the optimal solution look like?

For large n, the optimal sequence should have a nearly flat power spectrum. This means it's approximately the impulse response of an all-pass filter. The impulse response of a high-order all-pass filter tends to be "spread out" with oscillations. But our constraint is non-negativity, so the optimal solution is the "closest" non-negative sequence to a flat-spectrum sequence.

I suspect the optimal solution has a "bell-like" shape with some oscillations, concentrated in the middle of the sequence.

Let me now write the full program:

```python
"""
Hybrid GS + LP + Gradient optimization for minimizing 2n*max(conv(a,a))/sum(a)^2.

Key innovations:
1. Gerchberg-Saxton (GS) iterations for spectrum flattening (fast, O(n log n) per step)
2. LP-based spreading for fine-tuning
3. Smooth-max gradient descent for final polish
4. Multi-length search with adaptive time allocation
5. Diverse initialization strategies
"""

import numpy as np
import time
from scipy.optimize import linprog


def _next_pow2(n):
    k = 1
    while k < n:
        k <<= 1
    return max(2, k)


def _fft_convolve(a):
    a = np.asarray(a, dtype=np.float64).ravel()
    n = a.size
    if n == 0:
        return np.array([])
    if n <= 128:
        return np.convolve(a, a)
    N = _next_pow2(2 * n - 1)
    fa = np.fft.rfft(a, N)
    c = np.fft.irfft(fa * fa, N)[:2 * n - 1]
    mn = float(c.min())
    if mn < 0.0:
        c = c - mn
    return c


def _score(a):
    a = np.asarray(a, dtype=np.float64).ravel()
    n = a.size
    s = float(a.sum())
    if s < 1e-10:
        return np.inf
    c = _fft_convolve(a)
    return float(2.0 * n * c.max() / (s * s))


def _gs_optimize(a0, deadline, n_iter=50000, relax_start=0.8, relax_end=0.3, flatten_alpha=1.0):
    """
    Gerchberg-Saxton optimization: alternate between
    - Fourier domain: flatten magnitude spectrum
    - Time domain: enforce non-negativity
    """
    a = np.asarray(a0, dtype=np.float64).copy()
    a = np.maximum(a, 0.0)
    s = a.sum()
    if s < 1e-20:
        return a
    a = a / s
    n = len(a)
    N = _next_pow2(2 * n - 1)
    
    best_a = a.copy()
    best_score = _score(a)
    no_improve = 0
    
    for it in range(n_iter):
        if time.monotonic() > deadline:
            break
        
        # Progressive relaxation
        t_frac = it / max(1, n_iter)
        relax = relax_start + (relax_end - relax_start) * t_frac
        # Progressive flattening strength
        alpha = flatten_alpha * (1.0 - 0.3 * t_frac)
        
        fa = np.fft.rfft(a, N)
        dc = fa[0].real  # This is sum(a) = 1 after normalization
        
        # Target: flat magnitude
        target_mag = dc / np.sqrt(2 * n - 1)
        
        # Soft flattening
        phase = np.angle(fa)
        current_mag = np.abs(fa)
        new_mag = (1.0 - alpha) * current_mag + alpha * target_mag
        new_mag[0] = dc  # Preserve DC
        
        new_fa = new_mag * np.exp(1j * phase)
        a_new = np.fft.irfft(new_fa, N)[:n]
        a_new = np.maximum(a_new, 0.0)
        s_new = a_new.sum()
        if s_new < 1e-20:
            break
        a_new = a_new / s_new
        
        # Relaxation
        if relax < 1.0:
            a_new = (1.0 - relax) * a + relax * a_new
            a_new = np.maximum(a_new, 0.0)
            s_new = a_new.sum()
            if s_new < 1e-20:
                break
            a_new = a_new / s_new
        
        sc = _score(a_new)
        if sc < best_score - 1e-12:
            best_score = sc
            best_a = a_new.copy()
            no_improve = 0
        else:
            no_improve += 1
            if no_improve > 5000:
                # Try a restart with perturbation
                rng = np.random.default_rng(it * 31 + 7)
                a_pert = a * (1.0 + 0.1 * rng.standard_normal(n))
                a_pert = np.maximum(a_pert, 0.0)
                a_pert = a_pert / a_pert.sum()
                a = a_pert
                no_improve = 0
                continue
        
        a = a_new
    
    return best_a


def _gs_multi_restarts(a0, deadline, n_restarts=5, rng=None):
    """Try GS from multiple perturbed starting points."""
    if rng is None:
        rng = np.random.default_rng(12345)
    
    a = np.asarray(a0, dtype=np.float64).copy()
    a = np.maximum(a, 0.0)
    a = a / a.sum()
    n = len(a)
    
    best_a = a.copy()
    best_score = _score(a)
    
    for r in range(n_restarts):
        if time.monotonic() > deadline:
            break
        
        sub_deadline = min(deadline, time.monotonic() + (deadline - time.monotonic()) / (n_restarts - r))
        
        if r == 0:
            a_start = a.copy()
        else:
            noise = 0.1 * r * rng.standard_normal(n)
            a_start = a * (1.0 + noise)
            a_start = np.maximum(a_start, 0.0)
            a_start = a_start / a_start.sum()
        
        a_res = _gs_optimize(a_start, sub_deadline, n_iter=20000, relax_start=0.7, relax_end=0.2)
        sc = _score(a_res)
        if sc < best_score:
            best_score = sc
            best_a = a_res.copy()
    
    return best_a


def _make_conv_matrix(a):
    n = len(a)
    A = np.zeros((2 * n - 1, n))
    for j in range(n):
        A[j:j + n, j] = a
    return A


def _lp_spread(a, M):
    n = len(a)
    c_obj = -np.ones(n)
    A = _make_conv_matrix(a)
    b = np.full(2 * n - 1, M)
    res = linprog(c_obj, A_ub=A, b_ub=b,
                  bounds=[(0, None)] * n, method='highs')
    if res.success:
        return res.x
    return None


def _lp_refine(a, deadline, max_iter=5000, inflate=1.001, blend=0.3):
    """LP-based spreading refinement."""
    a = np.asarray(a, dtype=np.float64).copy()
    n = len(a)
    s = a.sum()
    if s < 1e-10:
        return a
    a = a / s
    
    best_a = a.copy()
    best_score = _score(a)
    no_imp = 0
    blend_cur = blend
    inflate_cur = inflate
    
    # Pre-compute conv matrix
    A = _make_conv_matrix(a)
    
    for it in range(max_iter):
        if time.monotonic() > deadline:
            break
        
        c = _fft_convolve(a)
        M = float(c.max())
        M_lp = M * inflate_cur
        g = _lp_spread(a, M_lp)
        
        if g is None:
            break
        
        sum_g = float(g.sum())
        if sum_g <= 1.0 + 1e-7:
            no_imp += 1
            if no_imp % 10 == 0:
                inflate_cur = min(1.005, inflate_cur * 1.1)
            if no_imp > 200:
                break
            continue
        
        g = g / sum_g
        a_new = (1.0 - blend_cur) * a + blend_cur * g
        a_new = np.maximum(a_new, 0.0)
        s_new = a_new.sum()
        if s_new < 1e-10:
            break
        a_new = a_new / s_new
        
        # Update conv matrix
        A = _make_conv_matrix(a_new)
        
        c_new = _fft_convolve(a_new)
        score_new = _score(a_new)
        
        if score_new < best_score - 1e-13:
            best_score = score_new
            best_a = a_new.copy()
            no_imp = 0
        else:
            no_imp += 1
            if no_imp % 50 == 0:
                blend_cur = max(0.1, blend_cur * 0.95)
                inflate_cur = max(1.0005, inflate_cur * 0.98)
            if no_imp > max(100, n):
                a = best_a.copy()
                blend_cur = blend
                inflate_cur = inflate
                no_imp = 0
                A = _make_conv_matrix(a)
        
        a = a_new
    
    return best_a


def _smooth_max_grad(a, beta):
    """Compute smooth max value and gradient w.r.t. a (with sum=1 constraint)."""
    n = len(a)
    c = _fft_convolve(a)
    mval = float(c.max())
    x = (c - mval) / beta
    x = np.clip(x, -50.0, 50.0)
    ex = np.exp(x)
    s = float(ex.sum())
    if not np.isfinite(s) or s <= 0:
        return mval, np.zeros(n)
    w = ex / s
    
    # Gradient of smooth_max w.r.t. a_i
    # d/d a_i [sum_k w_k * c_k] where c_k = sum_j a_j * a_{k-j}
    # = 2 * sum_k w_k * a_{k-i} (for valid k-i)
    N = _next_pow2(2 * n - 1)
    fw = np.fft.rfft(w, N)
    fa_rev = np.fft.rfft(a[::-1], N)
    h_full = np.fft.irfft(fw * fa_rev, N)
    h = h_full[n - 1:2 * n - 1]
    grad = 2.0 * h
    
    # Project gradient to simplex (subtract mean to maintain sum=1)
    grad = grad - np.dot(a, grad)
    # Actually, for the logit parameterization:
    # f(a) where a = softmax(z), df/dz_i = a_i * (df/da_i - sum_j a_j * df/da_j)
    # But here we want df/da directly for use in the simplex
    return mval + beta * float(np.log(s)), grad


def _gradient_polish(a, deadline, max_iter=50000, lr=0.02, beta_init=None):
    """
    Gradient polishing in logit space with adaptive beta.
    Uses smooth max approximation.
    """
    a = np.asarray(a, dtype=np.float64).copy()
    a = np.maximum(a, 1e-15)
    a = a / a.sum()
    n = len(a)
    
    z = np.log(a)
    z -= float(np.mean(z))
    
    c = _fft_convolve(a)
    c_max = float(c.max())
    if beta_init is not None:
        beta = beta_init
    else:
        beta = max(1e-6, 0.05 * c_max)
    
    best_a = a.copy()
    best_score = float(2.0 * n * c_max)
    best_z = z.copy()
    
    no_imp = 0
    base_lr = lr
    prev_z = z.copy()
    prev_grad = None
    bb_scale = 1.0
    
    b1 = 0.9
    b2 = 0.999
    eps = 1e-8
    m = np.zeros(n)
    v_arr = np.zeros(n)
    adam_t = 0
    
    for it in range(max_iter):
        if time.monotonic() > deadline:
            break
        
        p = a
        c = _fft_convolve(p)
        mval = float(c.max())
        x = (c - mval) / beta
        x = np.clip(x, -50.0, 50.0)
        ex = np.exp(x)
        s = float(ex.sum())
        if not np.isfinite(s) or s <= 0:
            break
        w = ex / s
        
        N = _next_pow2(2 * n - 1)
        fw = np.fft.rfft(w, N)
        fp_rev = np.fft.rfft(p[::-1], N)
        h_full = np.fft.irfft(fw * fp_rev, N)
        h = h_full[n - 1:2 * n - 1]
        vp = 2.0 * h + 1e-7 * p
        dot = float(np.dot(p, vp))
        gz = p * (vp - dot)
        gz -= float(np.mean(gz))
        
        if not np.all(np.isfinite(gz)):
            z = best_z.copy()
            m = np.zeros(n)
            v_arr = np.zeros(n)
            adam_t = 0
            beta = max(1e-6, 0.05 * float(_fft_convolve(a).max()))
            continue
        
        # BB step size
        if prev_grad is not None and np.all(np.isfinite(prev_grad)):
            sz = z - prev_z
            sg = gz - prev_grad
            dot_ss = float(np.dot(sz, sz))
            dot_sg = float(np.dot(sz, sg))
            if dot_ss > 1e-20:
                bb_candidate = dot_ss / max(abs(dot_sg), 1e-20)
                bb_candidate = np.clip(bb_candidate, 0.1, 10.0)
                bb_scale = 0.7 * bb_scale + 0.3 * bb_candidate
        prev_z = z.copy()
        prev_grad = gz.copy()
        
        cur_lr = base_lr * bb_scale
        
        adam_t += 1
        m = b1 * m + (1.0 - b1) * gz
        v_arr = b2 * v_arr + (1.0 - b2) * (gz * gz)
        mh = m / (1.0 - b1 ** adam_t)
        vh = v_arr / (1.0 - b2 ** adam_t)
        z_new = z - cur_lr * mh / (np.sqrt(vh) + eps)
        
        if not np.all(np.isfinite(z_new)):
            continue
        
        z_new = np.clip(z_new, -60.0, 60.0)
        z_new -= float(np.mean(z_new))
        e = np.exp(z_new)
        a_new = e / e.sum()
        
        c = _fft_convolve(a_new)
        c_max_new = float(c.max())
        score = float(2.0 * n * c_max_new)
        
        if score < best_score - 1e-12:
            best_score = score
            best_a = a_new.copy()
            best_z = z_new.copy()
            no_imp = 0
        else:
            no_imp += 1
            if no_imp % 500 == 0:
                base_lr = max(0.002, base_lr * 0.95)
        
        # Adaptive beta
        if it % 200 == 0 and it > 200:
            top5 = np.sort(c)[::-1][:min(5, len(c))]
            if len(top5) > 1:
                peak_gap = top5[0] - top5[-1]
                if peak_gap < beta * 0.5:
                    beta = max(1e-10, beta * 0.6)
                elif peak_gap > beta * 5.0:
                    beta = min(0.5 * c_max_new, beta * 1.3)
        
        # Annealing restart
        if no_imp > max(3000, 5 * n):
            rng = np.random.default_rng(it * 104729 + 13)
            noise_scale = 0.2 * best_score
            z_restart = best_z + noise_scale * rng.standard_normal(n)
            z_restart = np.clip(z_restart, -60.0, 60.0)
            z_restart -= np.mean(z_restart)
            e = np.exp(z_restart)
            a_new = e / e.sum()
            z = z_restart
            m = np.zeros(n)
            v_arr = np.zeros(n)
            adam_t = 0
            base_lr = lr
            bb_scale = 1.0
            prev_grad = None
            beta = max(1e-6, 0.05 * float(_fft_convolve(a_new).max()))
            no_imp = 0
            a = a_new
            z = z_new  # Keep going from new position
            continue
        
        a = a_new
        z = z_new
    
    return best_a


def _make_flat_spectrum_init(n, rng):
    """Initialize from flat magnitude spectrum with random phases."""
    N = _next_pow2(2 * n - 1)
    phases = rng.uniform(0, 2 * np.pi, N // 2 + 1)
    X = np.zeros(N // 2 + 1, dtype=complex)
    target_mag = 1.0 / np.sqrt(2 * n - 1)
    X[0] = 1.0  # DC
    for k in range(1, N // 2 + 1):
        X[k] = target_mag * np.exp(1j * phases[k])
    
    # Make full spectrum (conjugate symmetric)
    X_full = np.zeros(N, dtype=complex)
    X_full[:N//2+1] = X
    for k in range(1, N//2+1):
        X_full[N-k] = np.conj(X[k])
    
    a = np.real(np.fft.ifft(X_full))[:n]
    a = np.abs(a)
    a = np.maximum(a, 1e-10)
    s = a.sum()
    if s < 1e-20:
        return np.ones(n) / n
    return a / s


def _make_bell_profile(n, width=0.3):
    t = np.linspace(0.0, 1.0, n)
    a = np.exp(-((t - 0.5) / width) ** 2)
    a = np.maximum(a, 1e-12)
    return a / a.sum()


def _make_linear_profile(n, eta=1.5):
    t = np.linspace(0.0, 1.0, n)
    a = 1.0 + eta * (t - 0.5)
    a = np.maximum(a, 1e-12)
    return a / a.sum()


def _interpolate_profile(p0, n_new):
    p0 = np.asarray(p0, dtype=np.float64).ravel()
    n0 = p0.size
    if n0 == n_new:
        s = p0.sum()
        if s > 1e-30:
            return p0.copy() / s
        return np.ones(n_new) / n_new
    x0 = np.linspace(0.0, 1.0, n0)
    x1 = np.linspace(0.0, 1.0, n_new)
    p = np.interp(x1, x0, p0)
    p = np.maximum(p, 0.0)
    s = p.sum()
    if s < 1e-30:
        return np.ones(n_new) / n_new
    return p / s


def _peak_shave(a, deadline, max_iter=3000, n_peaks=8, strength=0.05):
    """Targeted peak shaving."""
    a = np.asarray(a, dtype=np.float64).copy()
    a = np.maximum(a, 1e-15)
    a = a / a.sum()
    n = len(a)
    
    best_score = float(2.0 * n * _fft_convolve(a).max())
    best_a = a.copy()
    no_imp = 0
    str_cur = strength
    
    for it in range(max_iter):
        if time.monotonic() > deadline:
            break
        
        c = _fft_convolve(a)
        c_max = float(c.max())
        top_idx = np.argsort(c)[::-1][:n_peaks]
        top_vals = c[top_idx]
        med = np.median(c)
        weights = np.maximum(top_vals - med, 0)
        wsum = weights.sum()
        if wsum < 1e-15:
            weights = np.ones(n_peaks) / n_peaks
        else:
            weights = weights / wsum
        
        # Compute pressure on each coordinate
        pressure = np.zeros(n)
        for k, w in zip(top_idx, weights):
            lo = max(0, k - n + 1)
            hi = min(n - 1, k)
            for ii in range(lo, hi + 1):
                j = k - ii
                if 0 <= j < n:
                    pressure[ii] += w * a[j]
        
        a_new = a * np.exp(-str_cur * pressure / (pressure.max() + 1e-15))
        a_new = np.maximum(a_new, 1e-15)
        a_new = a_new / a_new.sum()
        
        c_new = _fft_convolve(a_new)
        score_new = float(2.0 * n * c_new.max())
        
        if score_new < best_score - 1e-13:
            best_score = score_new
            best_a = a_new.copy()
            no_imp = 0
            str_cur = min(0.15, str_cur * 1.005)
        else:
            no_imp += 1
            if no_imp % 100 == 0:
                str_cur = max(0.01, str_cur * 0.95)
            if no_imp > 500:
                a = best_a.copy()
                str_cur = strength
                no_imp = 0
        
        a = a_new
    
    return best_a


def propose_candidate(seed=42, budget_s=1800):
    """
    Multi-phase optimization combining GS, LP, and gradient methods.
    
    Phases:
    1. Diverse initialization (parent, flat-spectrum, bell profiles)
    2. GS optimization (fast spectrum flattening)
    3. Gradient polish (Adam in logit space)
    4. LP refinement
    5. Peak shaving
    6. Final fine polish
    """
    t_start = time.monotonic()
    deadline = t_start + budget_s - 30.0
    rng = np.random.default_rng(int(seed) % (2**63 - 1))
    
    best_score = np.inf
    best_seq = None
    
    # Get parent sequence
    parent = None
    try:
        p = np.asarray(height_sequence_1, dtype=np.float64)
        if p.ndim == 1 and p.size > 0 and np.all(np.isfinite(p)) and np.all(p >= 0):
            s = p.sum()
            if s > 0.01:
                parent = p / s
                sc = _score(parent)
                if np.isfinite(sc) and sc < best_score:
                    best_score = sc
                    best_seq = parent.copy()
                print(f"Parent: score={sc:.10f}, n={parent.size}", flush=True)
    except Exception:
        pass
    
    # Determine lengths to try
    lengths = []
    if parent is not None:
        lengths.append(parent.size)
    for ln in [512, 768, 1024]:
        if ln not in lengths:
            lengths.append(ln)
    
    print(f"Lengths to try: {lengths}", flush=True)
    
    # Phase 1: Generate diverse initializations
    print(f"Phase 1: Initialization", flush=True)
    init_pool = []
    
    for n_t in lengths:
        if parent is not None:
            init_pool.append(('parent', n_t, _interpolate_profile(parent, n_t)))
        
        init_pool.append(('bell', n_t, _make_bell_profile(n_t, 0.35)))
        init_pool.append(('bell_wide', n_t, _make_bell_profile(n_t, 0.5)))
        init_pool.append(('linear', n_t, _make_linear_profile(n_t, 1.5)))
        init_pool.append(('flat_spec', n_t, _make_flat_spectrum_init(n_t, rng)))
    
    # Quick evaluation
    init_scores = []
    for name, n_t, a0 in init_pool:
        sc = _score(a0)
        init_scores.append((sc, name, n_t, a0))
    init_scores.sort(key=lambda x: x[0])
    
    print("  Top 5 inits:", flush=True)
    for sc, name, n_t, _ in init_scores[:5]:
        print(f"    {name} (n={n_t}): {sc:.8f}", flush=True)
    
    # Phase 2: GS optimization on top candidates
    top_inits = init_scores[:6]
    for sc0, name, n_t, a0 in top_inits:
        if time.monotonic() > deadline - 400:
            break
        if sc0 > best_score * 1.1 and name != 'parent':
            continue
        
        # GS optimization
        gs_deadline = min(deadline - 300, time.monotonic() + 300.0)
        print(f"Phase 2: GS on {name} (n={n_t}), start={sc0:.8f}, budget={gs_deadline - time.monotonic():.0f}s", flush=True)
        a_gs = _gs_optimize(a0, gs_deadline, n_iter=100000, relax_start=0.8, relax_end=0.3)
        sc_gs = _score(a_gs)
        print(f"  GS result: {sc_gs:.10f}", flush=True)
        if sc_gs < best_score:
            best_score = sc_gs
            best_seq = a_gs.copy()
        
        # Gradient polish after GS
        if time.monotonic() < deadline - 200:
            grad_deadline = min(deadline - 150, time.monotonic() + 200.0)
            a_grad = _gradient_polish(a_gs, grad_deadline, max_iter=30000, lr=0.03)
            sc_grad = _score(a_grad)
            print(f"  Gradient result: {sc_grad:.10f}", flush=True)
            if sc_grad < best_score:
                best_score = sc_grad
                best_seq = a_grad.copy()
            a_gs = a_grad
        
        # LP refinement
        if time.monotonic() < deadline - 100 and n_t <= 1024:
            lp_deadline = min(deadline - 80, time.monotonic() + 120.0)
            a_lp = _lp_refine(a_gs, lp_deadline, max_iter=3000, inflate=1.001, blend=0.2)
            sc_lp = _score(a_lp)
            print(f"  LP result: {sc_lp:.10f}", flush=True)
            if sc_lp < best_score:
                best_score = sc_lp
                best_seq = a_lp.copy()
    
    # Phase 3: GS multi-restart on the best found so far
    if best_seq is not None and time.monotonic() < deadline - 100:
        ms_deadline = min(deadline - 50, time.monotonic() + 100.0)
        print(f"Phase 3: GS multi-restart, budget={ms_deadline - time.monotonic():.0f}s", flush=True)
        a_ms = _gs_multi_restarts(best_seq, ms_deadline, n_restarts=3, rng=rng)
        sc_ms = _score(a_ms)
        print(f"  Multi-restart GS: {sc_ms:.10f}", flush=True)
        if sc_ms < best_score:
            best_score = sc_ms
            best_seq = a_ms.copy()
    
    # Phase 4: Peak shaving
    if best_seq is not None and time.monotonic() < deadline - 50:
        ps_deadline = min(deadline - 30, time.monotonic() + 50.0)
        a_ps = _peak_shave(best_seq, ps_deadline, max_iter=2000, n_peaks=8, strength=0.03)
        sc_ps = _score(a_ps)
        print(f"Phase 4: Peak shave: {sc_ps:.10f}", flush=True)
        if sc_ps < best_score:
            best_score = sc_ps
            best_seq = a_ps.copy()
    
    # Phase 5: Final gradient polish
    if best_seq is not None and time.monotonic() < deadline - 20:
        fp_deadline = min(deadline - 15, time.monotonic() + 80.0)
        print(f"Phase 5: Final polish, budget={fp_deadline - time.monotonic():.0f}s", flush=True)
        a_fine = _gradient_polish(best_seq, fp_deadline, max_iter=20000, lr=0.01, beta_init=1e-6)
        sc_fine = _score(a_fine)
        print(f"  Final polish: {sc_fine:.10f}", flush=True)
        if sc_fine < best_score:
            best_score = sc_fine
            best_seq = a_fine.copy()
    
    # Phase 6: One more LP pass
    if best_seq is not None and time.monotonic() < deadline - 10:
        lp_deadline2 = deadline - 5
        if lp_deadline2 - time.monotonic() > 15 and best_seq.size <= 1024:
            a_last = _lp_refine(best_seq, lp_deadline2, max_iter=2000, inflate=1.0005, blend=0.1)
            sc_last = _score(a_last)
            if sc_last < best_score:
                best_score = sc_last
                best_seq = a_last.copy()
            print(f"  Final LP: {sc_last:.10f}", flush=True)
    
    # Final validation
    if best_seq is None:
        best_seq = _make_bell_profile(512, 0.35)
        best_score = _score(best_seq)
    
    final_seq = np.clip(best_seq, 0.0, 1000.0)
    
    # Evaluate with authoritative function
    try:
        sc_eval = float(evaluate_sequence(final_seq.tolist()))
        if np.isfinite(sc_eval):
            print(f"Evaluate_sequence score: {sc_eval:.10f}", flush=True)
            if sc_eval < best_score:
                best_score = sc_eval
    except Exception as e:
        print(f"Eval error: {e}", flush=True)
    
    print(f"FINAL: score={best_score:.10f}, n={final_seq.size}, time={time.monotonic()-t_start:.1f}s", flush=True)
    return [
