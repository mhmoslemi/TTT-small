$\text{cross\_corr}(w, a) = \text{fft\_ifft}(\text{fft}(w) \cdot \overline{\text{fft}(a)})$ (with appropriate zero-padding and slicing)

Or equivalently: $\text{cross\_corr}(w, a)_j = (\tilde{w} * a)_j$ where $\tilde{w}$ is $w$ reversed and centered.

Let me just implement it with the FFT:

```python
def _conv_gradient(w, a):
    """Compute gradient of sum_k w_k * (a*a)_k with respect to a.
    Returns 2 * cross_correlation(w, a) approximately.
    w has length 2n-1, a has length n.
    """
    n = len(a)
    N = _next_pow2(2 * n - 1)
    fw = np.fft.rfft(w, N)
    fa = np.fft.rfft(a[::-1], N)
    # cross_corr(w, a)_j = sum_k w_k * a_{k-j}
    # This is the same as convolve(w, a_reversed) with appropriate offset
    h = np.fft.irfft(fw * fa, N)
    # The result needs appropriate slicing
    # convolve(w, a[::-1]) has length 3n-2
    # We want the part that corresponds to cross-correlation at lags 0 to n-1
    # Actually, let me think about this more carefully.
    # cross_corr(w, a)_j = sum_k w_k a_{k-j}
    # Let b = a[::-1], so b[i] = a[n-1-i]
    # convolve(w, b)_m = sum_k w_k b_{m-k} = sum_k w_k a[n-1-(m-k)] = sum_k w_k a[n-1-m+k]
    # We want cross_corr(w, a)_j = sum_k w_k a_{k-j}
    # Set n-1-m+k = k-j => n-1-m = -j => m = n-1+j
    # So cross_corr(w, a)_j = convolve(w, a[::-1])_{n-1+j}
    # convolve(w, a[::-1]) has length (2n-1) + n - 1 = 3n-2
    # n-1+j ranges from n-1 to 2n-2, which is within [0, 3n-3] for n >= 1.
    h = h[:3*n-2]  # trim
    return 2.0 * h[n-1:2*n-1]
```

Length = $3 + 2 - 1 = 4 = 3n-2 = 4$. ✓

Also, I want to try a "direct" approach: instead of smooth max, use a "top-k" approach where we only look at the top k lags and try to equalize them. This is like a "water-filling" approach.

Algorithm (top-k equalization):
1. Find the top k lags (those with the largest convolution values).
2. Compute the gradient for each of these lags.
3. Find a direction that reduces all top-k lags simultaneously.
4. Take a step in that direction.

This is similar to the LP approach but simpler.

Actually, the LP approach does exactly this: it finds the best direction (in terms of maximizing the step with all constraints active). Let me focus on making the LP approach work well.

The LP I'll use:
Variables: $\delta \in \mathbb{R}^n$, $t \in \mathbb{R}$
Minimize: $t$
Subject to:
- $\sum_j \delta_j = 0$ (maintain normalization, to first order)
- $a_j + \delta_j \geq 0$ for all $j$ (maintain non-negativity)
- $2 \sum_j \text{grad}_k[j] \cdot \delta_j \leq \epsilon$ for all active $k$ (reduce the active lags)

where $\text{grad}_k[j] = 2 a_{k-j}$ (gradient of $(a*a)_k$ w.r.t. $a_j$) and $\epsilon$ is a small negative number (to ensure decrease).

Wait, actually I want to minimize the max, so the constraint should be:
$2 \sum_j \text{grad}_k[j] \cdot \delta_j \leq 0$ for all active $k$

This ensures that all active lags decrease (to first order).

But this might be too restrictive. Let me instead minimize $t$ subject to:
$2 \sum_j \text{grad}_k[j] \cdot \delta_j \leq t$ for all active $k$
$|\delta_j| \leq \Delta$ for all $j$ (step size limit)
$\sum_j \delta_j = 0$

Then take a step $\alpha \cdot \delta$ where $\alpha$ is chosen by line search.

Actually, let me simplify. The "cross-convolution LP" from the previous code is:
Maximize $\sum_j b_j$
Subject to: $(a*b)_k \leq M$ for all $k$
$b_j \geq 0$

where $M$ is the current max of $a*a$.

This finds a sequence $b$ that, when cross-convolved with $a$, stays below $M$. If we then set $a \leftarrow (a + b) / (1 + \sum b)$, the new max should be lower.

The intuition: $b$ represents the "best direction" to move that keeps the cross-convolution bounded. Since the gradient of the max of $a*a$ is related to the cross-convolution of $a$ with the "active" lags, this LP finds a good descent direction.

I'll keep this LP approach but also add the "direct" LP I described above.

```python
"""
Multi-phase optimization to minimize 2*n*max(a*a)/sum(a)^2 for non-negative sequences.
Strategy: (1) diverse initialization, (2) Adam smooth-max in logit space,
(3) LP-based refinement via cross-convolution and direct linearized min-max,
(4) multi-scale, (5) final polish.
"""
import numpy as np
from scipy.optimize import linprog
from scipy.sparse import csr_matrix
import time


def _next_pow2(n):
    k = 1
    while k < n:
        k <<= 1
    return max(2, k)


def _full_convolve(a):
    a = np.asarray(a, dtype=np.float64).ravel()
    n = a.size
    if n == 0:
        return np.array([])
    if n <= 256:
        return np.convolve(a, a)
    N = _next_pow2(2 * n - 1)
    fa = np.fft.rfft(a, N)
    c = np.fft.irfft(fa * fa, N)[:2 * n - 1]
    c = np.maximum(c, 0.0)
    return c


def _score(a):
    n = len(a)
    c = _full_convolve(a)
    return float(2.0 * n * c.max())


def _smooth_max_weights(c, beta):
    c = np.asarray(c, dtype=np.float64)
    mval = float(c.max())
    if beta < 1e-12:
        w = np.zeros_like(c)
        mask = c >= mval - 1e-10
        cnt = int(mask.sum())
        if cnt == 0:
            w[int(np.argmax(c))] = 1.0
        else:
            w[mask] = 1.0 / cnt
        return mval, w
    x = (c - mval) / beta
    ex = np.exp(x)
    s = float(ex.sum())
    if not np.isfinite(s) or s <= 0.0:
        ex = np.zeros_like(c)
        ex[int(np.argmax(c))] = 1.0
        s = 1.0
    val = mval + beta * float(np.log(s))
    w = ex / s
    return val, w


def _conv_gradient(w, a):
    """Compute 2 * cross_correlation(w, a) where w has length 2n-1 and a has length n.
    This gives the gradient of sum_k w_k * (a*a)_k w.r.t. a (approximately, ignoring diagonal correction).
    """
    n = len(a)
    N = _next_pow2(3 * n - 1)  # need enough padding for convolve(w, a[::-1])
    fw = np.fft.rfft(w, N)
    fa = np.fft.rfft(a[::-1], N)
    h = np.fft.irfft(fw * fa, N)
    # cross_corr(w, a)_j = convolve(w, a[::-1])_{n-1+j}
    # convolve(w, a[::-1]) has length (2n-1) + n - 1 = 3n-2
    return 2.0 * h[n - 1:2 * n - 1]


def _cross_convolve(a, b):
    """Compute cross-convolution (a*b) for the LP constraints.
    Returns array of length 2n-1 where (a*b)_k = sum_j a_j b_{k-j}.
    """
    n = len(a)
    N = _next_pow2(2 * n - 1)
    fa = np.fft.rfft(a, N)
    fb = np.fft.rfft(b, N)
    return np.fft.irfft(fa * fb, N)[:2 * n - 1]


def _softmax_from_z(z, floor=1e-15):
    z = np.asarray(z, dtype=np.float64).ravel()
    z = np.clip(z, -60.0, 60.0)
    z = z - float(np.max(z))
    e = np.exp(z)
    p = e + floor
    s = float(p.sum())
    if not np.isfinite(s) or s <= 0.0:
        p = np.ones_like(e) / float(e.size)
    else:
        p = p / s
    return p


def _normalize(a):
    a = np.asarray(a, dtype=np.float64).ravel()
    a = np.maximum(a, 0.0)
    s = float(a.sum())
    if s < 1e-30:
        return None
    return a / s


def _make_profile_power(n, alpha):
    t = np.arange(1, n + 1, dtype=np.float64)
    a = t ** alpha
    a = np.maximum(a, 1e-12)
    return a / a.sum()


def _make_profile_linear(n, eta):
    t = np.linspace(0.0, 1.0, n)
    a = 1.0 + eta * (1.0 - 2.0 * t)
    a = np.maximum(a, 1e-12)
    return a / a.sum()


def _make_profile_exp_decay(n, lam):
    t = np.arange(n, dtype=np.float64)
    a = np.exp(-lam * t / n)
    a = np.maximum(a, 1e-12)
    return a / a.sum()


def _make_profile_cosine(n, freq, amp):
    t = np.arange(n)
    a = 1.0 + amp * np.cos(2.0 * np.pi * freq * t / n)
    a = np.maximum(a, 1e-12)
    return a / a.sum()


def _make_profile_gaussian(n, center, width):
    t = np.linspace(0.0, 1.0, n)
    a = np.exp(-0.5 * ((t - center) / width) ** 2)
    a = np.maximum(a, 1e-12)
    return a / a.sum()


def _interp_profile(p0, n_new):
    p0 = np.asarray(p0, dtype=np.float64).ravel()
    n0 = p0.size
    if n0 == n_new:
        return _normalize(p0)
    x0 = np.linspace(0.0, 1.0, n0)
    x1 = np.linspace(0.0, 1.0, n_new)
    return _normalize(np.interp(x1, x0, p0))


def _adam_logit(p0, deadline, rng, lr=0.05, beta_frac=0.1, beta_decay=0.92,
                no_imp_limit=400, top_k=None):
    """Adam optimizer in logit space with smooth max.
    Optionally uses top-k hard max instead of smooth max.
    """
    p0 = np.asarray(p0, dtype=np.float64).ravel()
    p0 = np.maximum(p0, 1e-12)
    p0 = p0 / p0.sum()
    n = p0.size

    z = np.log(p0)
    z -= float(np.mean(z))

    b1, b2, eps = 0.9, 0.999, 1e-8
    m = np.zeros(n)
    v = np.zeros(n)
    t_adam = 0

    p = p0.copy()
    c = _full_convolve(p)
    maxc = float(c.max())
    beta = max(1e-3, beta_frac * maxc)

    best_p = p0.copy()
    best_z = z.copy()
    best_score = float(2.0 * n * maxc)
    no_imp = 0
    base_lr = lr

    while time.monotonic() < deadline:
        # Compute weights
        if top_k is not None and top_k < c.size:
            # Hard top-k
            sidx = np.argsort(c)[::-1]
            w = np.zeros_like(c)
            w[sidx[:top_k]] = 1.0 / top_k
        else:
            _, w = _smooth_max_weights(c, beta)

        # Compute gradient
        g = _conv_gradient(w, p)

        # Project gradient (remove mean component for the simplex constraint)
        dot = float(np.dot(p, g))
        gz = p * (g - dot)
        gz -= float(np.mean(gz))

        if not np.all(np.isfinite(gz)):
            z = best_z.copy()
            m.fill(0.0)
            v.fill(0.0)
            t_adam = 0
            no_imp += 1
            continue

        # Adam update
        t_adam += 1
        m = b1 * m + (1.0 - b1) * gz
        v = b2 * v + (1.0 - b2) * (gz * gz)
        mh = m / (1.0 - b1 ** t_adam)
        vh = v / (1.0 - b2 ** t_adam)
        z = z - lr * mh / (np.sqrt(vh) + eps)

        if not np.all(np.isfinite(z)):
            z = best_z.copy()
            m.fill(0.0)
            v.fill(0.0)
            t_adam = 0
            no_imp += 1
            continue

        z = np.clip(z, -60.0, 60.0)
        z -= float(np.mean(z))
        p = _softmax_from_z(z)
        c = _full_convolve(p)
        maxc = float(c.max())
        score = float(2.0 * n * maxc)

        if np.isfinite(score):
            if score < best_score - 1e-14:
                best_score = score
                best_p = p.copy()
                best_z = z.copy()
                no_imp = 0
            else:
                no_imp += 1
                if no_imp % 200 == 0:
                    lr = max(0.002, lr * 0.9)
        else:
            z = best_z.copy()
            m.fill(0.0)
            v.fill(0.0)
            t_adam = 0
            no_imp += 1
            continue

        # Adapt beta
        if t_adam % 30 == 0:
            beta = max(1e-4, beta * beta_decay)

        # Resort if stuck
        limit = max(100, no_imp_limit)
        if no_imp > limit:
            ns = min(0.2, 0.05 + 0.1 * (no_imp - limit) / limit)
            z = best_z + ns * rng.normal(size=n)
            z = np.clip(z, -60.0, 60.0)
            z -= float(np.mean(z))
            p = _softmax_from_z(z)
            c = _full_convolve(p)
            maxc = float(c.max())
            beta = max(1e-3, beta_frac * maxc)
            m.fill(0.0)
            v.fill(0.0)
            t_adam = 0
            lr = base_lr
            no_imp = 0

    return best_p, best_score


def _lp_cross_convolve_refine(a, M, return_sum=True):
    """LP: maximize sum(b) subject to (a*b)_k <= M for all k, b >= 0."""
    n = len(a)
    # Build constraint matrix A where (A @ b)_k = (a*b)_k
    rows = []
    cols = []
    vals = []
    for k in range(2 * n - 1):
        j_start = max(0, k - n + 1)
        j_end = min(n - 1, k)
        for j in range(j_start, j_end + 1):
            rows.append(k)
            cols.append(j)
            vals.append(a[k - j])
    A = csr_matrix((vals, (rows, cols)), shape=(2 * n - 1, n))
    c_obj = -np.ones(n)
    b_ub = M * np.ones(2 * n - 1)
    bounds = [(0, None)] * n
    res = linprog(c_obj, A_ub=A, b_ub=b_ub, bounds=bounds, method='highs')
    if res.success and res.x is not None:
        return np.maximum(res.x, 0.0)
    return None


def _lp_direct_refine(a, delta_max=0.1, n_active=None):
    """LP: minimize t subject to 2*grad_k . delta <= t for active k,
    sum(delta) = 0, |delta_j| <= delta_max."""
    n = len(a)
    c = _full_convolve(a)
    M = float(c.max())

    # Identify active lags
    if n_active is None:
        n_active = max(1, int(0.05 * c.size))
    # Active lags: those where c_k is within some fraction of M
    threshold = M * 0.999
    active = np.where(c >= threshold)[0]
    if len(active) == 0:
        active = np.array([int(np.argmax(c))])
    # Also include the top n_active
    sidx = np.argsort(c)[::-1]
    active = np.unique(np.concatenate([active, sidx[:n_active]]))

    # Build LP
    # Variables: delta (n) + t (1) = n+1 variables
    n_vars = n + 1

    # Objective: minimize t => c_vec = [0, 0, ..., 0, 1]
    c_vec = np.zeros(n_vars)
    c_vec[-1] = 1.0

    # Inequality constraints: 2 * grad_k . delta - t <= 0 for each active k
    # i.e., 2 * sum_j (2*a_{k-j}) * delta_j - t <= 0
    # grad of (a*a)_k w.r.t. a_j = 2 * a_{k-j} (approximately)
    # So 2 * grad_k . delta = 4 * sum_j a_{k-j} * delta_j
    # Wait, let me be more careful.
    # (a*a)_k = sum_j a_j a_{k-j}
    # d/d a_m [(a*a)_k] = a_{k-m} + a_{k-m} = 2 a_{k-m} (when m != k/2)
    # So the linearized constraint is:
    # (a*a)_k + 2 * sum_m a_{k-m} * delta_m <= t
    # 2 * sum_m a_{k-m} * delta_m - t <= - (a*a)_k
    # We want this to decrease, so: 2 * sum_m a_{k-m} * delta_m - t <= -(a*a)_k + epsilon
    # For a step in the direction of reducing the max, we want:
    # 2 * sum_m a_{k-m} * delta_m - t <= 0 (reduce to at most 0, i.e., the max stays the same)
    # Actually, we want to minimize t where t represents the maximum first-order change.
    # Let me redefine: minimize t subject to
    #   2 * sum_m a_{k-m} * delta_m <= t for all active k
    #   sum_m delta_m = 0
    #   |delta_m| <= delta_max
    #
    # The optimal delta will reduce all active lags by approximately t/2.

    A_rows = []
    A_cols = []
    A_vals = []
    b_vals = []

    for k in active:
        row_idx = len(A_rows)
        # 2 * sum_m a_{k-m} * delta_m - t <= 0
        # => 2 * sum_m a_{k-m} * delta_m <= t
        # => 2 * sum_m a_{k-m} * delta_m - 1 * t <= 0
        j_start = max(0, k - n + 1)
        j_end = min(n - 1, k)
        for j in range(j_start, j_end + 1):
            A_rows.append(row_idx)
            A_cols.append(j)
            A_vals.append(2.0 * a[k - j])
        A_rows.append(row_idx)
        A_cols.append(n)  # t variable
        A_vals.append(-1.0)
        b_vals.append(0.0)

    if A_rows:
        A_ineq = csr_matrix((A_vals, (A_rows, A_cols)), shape=(len(b_vals), n_vars))
    else:
        A_ineq = csr_matrix((0, n_vars))

    # Equality: sum(delta) = 0
    A_eq_row = np.zeros(n_vars)
    A_eq_row[:n] = 1.0
    A_eq = A_eq_row.reshape(1, -1)
    b_eq = np.array([0.0])

    # Bounds: |delta_j| <= delta_max, t is free (but bounded by delta_max * max_active_count)
    bounds = [( -delta_max, delta_max)] * n + [(None, None)]

    res = linprog(c_vec, A_ub=A_ineq, b_ub=b_vals, A_eq=A_eq, b_eq=b_eq,
                  bounds=bounds, method='highs')
    if res.success and res.x is not None:
        delta = res.x[:n]
        # Ensure non-negativity of a + delta
        if float(np.min(a + delta)) < 0:
            # Scale down delta
            scale = float(np.min(a) / max(1e-30, -float(np.min(delta))))
            if scale > 0:
                delta = delta * min(1.0, scale)
        return np.maximum(delta, -a + 1e-15)
    return None


def _lp_refine_cycle(a, deadline, t_blend=0.3, max_iters=30):
    """Alternate between cross-convolution LP and direct LP."""
    n = len(a)
    best = a.copy()
    best_sc = _score(a)

    for it in range(max_iters):
        if time.monotonic() > deadline:
            break

        c = _full_convolve(a)
        M = float(c.max())

        # Cross-convolution LP
        b = _lp_cross_convolve_refine(a, M)
        if b is not None:
            s_b = float(b.sum())
            if s_b > 1e-10:
                b_n = b / s_b
                a_new = (1.0 - t_blend) * a + t_blend * b_n
                a_new = np.maximum(a_new, 1e-15)
                a_new = a_new / a_new.sum()
                sc = _score(a_new)
                if sc < best_sc:
                    best_sc = sc
                    best = a_new.copy()
                a = a_new
                t_blend = max(0.1, t_blend * 0.95)
                continue

        # Direct LP
        delta = _lp_direct_refine(a, delta_max=0.05)
        if delta is not None:
            a_new = a + delta
            a_new = np.maximum(a_new, 1e-15)
            a_new = a_new / a_new.sum()
            sc = _score(a_new)
            if sc < best_sc:
                best_sc = sc
                best = a_new.copy()
            a = a_new
            continue

        break

    return best, best_sc
