4. **Active-set refinement**: This involves identifying regions where the convolution has high values and adjusting the fields to balance these peaks.

The candidate sequence is built by iteratively refining an existing sequence, either starting from the parent's values or generating a new sequence using the tapered profile. The optimization is performed in phases:

- **Sort and Precompute**: The sequence is sorted, and the convolution is computed to find the maximum and other targets.
- **Active-set refinement**: The program adjusts the sequence to spread the convolution evenly.
- **Influence propagation**: Multi-profile candidates are generated for more diversity in the search.
- **Interval splitting and ordering**: These steps are crucial for maintaining the efficiency of the optimizer.

### Search Choices

The program alternates between using the parent's initial sequence and generated tapered profiles (if parent unavailable). The active regions are divided into segments based on the current best, and the convolution points are adjusted within these segments. The "glitch" variable guides this process, ensuring segments don't become constant or degrade too much.

### Objective & Constraints

The objective is minimized under:
- Non-negative coefficients.
- The sequence length can change dynamically (power-of-two basis).
- The maximum value in the convolution must be reduced without affecting the overall sum too much.

The program uses finite-difference gradients and a relaxation technique to ensure valid ranges.
