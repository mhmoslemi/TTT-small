    while k < n:

But we don't know the gap `c_max - c_second` a priori. We can estimate it at each step and adjust.

**Adaptive β strategy:**
1. Start with `β = 1 / (2 * c_max)` (very smooth)
2. At each L-BFGS convergence, compute the new `c` and estimate the gap
3. Set next `β = min(β * 2, 20 / (c_max - c_second + ε))`
4. Stop when `β * gap > 50` or time runs out

Let me also think about what else could help:

**Idea: Use a "peak reduction" approach**

Instead of minimizing the smoothed max, what if we:
1. Find the current peak position
2. Compute the gradient of just that one peak
3. Take a Newton step to reduce it
4. Repeat

This is essentially the K=1 active set method. The advantage is that it's very targeted.

For K=1 (single peak at position k*):
- Objective: minimize `c_{k*} = sum_j a[j] * a[k*-j]` subject to `sum a = 1, a >= 0`
- This is a quadratic minimization with a quadratic objective (not necessarily convex!)
- The Hessian is `2 * H_{k*}` where `H_{k*}` is the Hankel matrix with 1s on the `k*`-th anti-diagonal
- `H_{k*}` is not PSD in general, so this is a non-convex quadratic!

Wait, `H_{k*}` has entries `H_{k*}[i,j] = 1` if `i+j = k*`, else 0. This is a "reversed identity" matrix (anti-diagonal). Its eigenvalues are ±1 (it's an involution: `H^2 = I`). So the Hessian `2*H_{k*}` has eigenvalues ±2, and the quadratic form is indefinite!

This means minimizing a single peak is a non-convex problem. We need to be careful.

However, if we use K > 1 (multiple peaks), the Hessian becomes `2 * sum_{k in S} w_k * H_k`, which might be PSD for the right choice of S and weights. This is the key insight behind the KKT approach.

**Idea: Use the "flatness" criterion**

At the optimum, the active peaks should all be equal (by complementary slackness). So we can use a "flatness" measure:
`flatness = (max_c - min_active) / max_c` where `active` are the top K peaks.

We want to minimize both `max_c` and `flatness` simultaneously. This suggests a two-stage approach:
1. First, minimize `max_c` (using any method)
2. Then, among sequences with `max_c` near the current best, minimize `flatness`

But this is essentially what the KKT method does.

**Let me try a different angle: use the structure of the optimal solution**

For the "flat convolution" problem with `a >= 0`, the optimal solution tends to have a "smooth" profile (no sharp features). This is because sharp features in `a` create sharp features in `a*a`.

What if we parameterize `a` as a smooth function? E.g., `a[i] = f(i/n)` where `f` is a smooth function from [0,1] to [0,∞)?

We could use:
- Gaussian: `f(t) = exp(-α(t-μ)^2)`
- Polynomial: `f(t) = (1-t^2)^p` (for t in [0,1] with appropriate extension)
- Spline: piecewise polynomial

But this restricts the search space too much. The optimal solution likely has some fine structure.

**Better idea: Multi-scale approach**

1. First, optimize a "coarse" version (e.g., 256 points) to get the general shape
2. Then, upsample and optimize at higher resolution (1024, 4096, 16384, 32768)
3. At each level, the lower-level solution provides a good initialization

This is similar to the "multi-grid" approach in PDE solvers.

**Let me combine ideas into a final algorithm:**

1. **Phase 0**: Load parent, or create a good initial profile
2. **Phase 1**: Coarse optimization (n=1024 or 2048) with smoothed L-BFGS
3. **Phase 2**: Multi-scale upsample + fine L-BFGS at target n
4. **Phase 3**: KKT-based Newton for final polish (K=1, 2, 3, 5, 10)
5. **Phase 4**: Multiple restarts with different β schedules

Let me also consider: what if we use a **different objective function** that's easier to optimize but has a similar optimum?

For example, instead of `max_k c_k`, use `sum_k c_k^p` for large p. As `p → ∞`, this approaches `max_k c_k` (to the power p). And `sum c_k^p` is a sum of smooth functions, which might be easier to optimize.

The gradient of `sum_k c_k^p` is `2p * sum_k c_k^{p-1} * a[k-i]` (for valid k-i). This is the same structure as before, with `w_k = c_k^{p-1} / sum_j c_j^{p-1}`.

So `p`-norm minimization is equivalent to smooth max minimization with `β = p-1` (approximately). This is the same as the log-sum-exp approach!

OK so I think the log-sum-exp approach is the right one. Let me focus on making it work well.

**Key improvements over the previous approach:**
1. Better β schedule (adaptive, based on gap estimation)
2. Use L-BFGS with more memory (maxcor=100) for better curvature approximation
3. Multi-scale initialization (coarse to fine)
4. More aggressive final polish with K=1,2,3 Newton steps
5. Better line search (exact Newton step when possible)
6. Periodic "diversification" steps to escape local minima

"""
Optimized step function coefficient minimizer using adaptive log-sum-exp smoothing
with L-BFGS, multi-scale initialization, and KKT-based Newton polishing.
Target: minimize 2*n*max(conv(a,a))/sum(a)^2 to below 1.5027.
"""
import numpy as np
import time
from scipy.optimize import minimize

def _next_pow2(n):
    k = 1
    while k < n:
        k <<= 1
    return max(2, k)

def _full_convolve(a, b):
    n, m = len(a), len(b)
    out_n = n + m - 1
    N = _next_pow2(out_n)
    fa = np.fft.rfft(a, N)
    fb = np.fft.rfft(b, N)
    r = np.fft.irfft(fa * fb, N)[:out_n]
    return r

def _score(a):
    n = len(a)
    s = float(a.sum())
    if s < 1e-15:
        return np.inf
    c = _full_convolve(a, a)
    return float(2.0 * n * c.max() / (s * s))

def _softmax(z):
    z = z - np.max(z)
    e = np.exp(np.clip(z, -700, 700))
    s = e.sum()
    if s < 1e-300:
        return np.ones_like(z) / len(z)
    return e / s

def _log_softmax_grad(z):
    """Given z in log-space, return (a, grad_fn closure-free helper)."""
    return _softmax(z)

def _smooth_obj_grad(z, beta, n):
    """Compute smoothed objective value and gradient w.r.t. z."""
    a = _softmax(z)
    c = _full_convolve(a, a)
    c_max = float(c.max())
    
    # Compute weights w_k = exp(beta * c_k) / sum exp(beta * c_j)
    beta_c = beta * (c - c_max)  # shift for numerical stability
    e = np.exp(np.clip(beta_c, -700, 0))
    s = float(e.sum())
    if s < 1e-300 or not np.isfinite(s):
        w = np.zeros_like(c)
        w[int(np.argmax(c))] = 1.0
    else:
        w = e / s
    
    # Smoothed objective (up to the constant 2n which we can ignore for optimization)
    smoothed_val = c_max + np.log(s) / beta
    
    # Gradient w.r.t. a:
    # d/da[i] = 2 * sum_k w[k] * a[k-i] for valid (k-i)
    # = 2 * conv(w, a[::-1])[n-1:2n-1]
    a_rev = a[::-1]
    wc = _full_convolve(w, a_rev)
    grad_a = 2.0 * wc[n-1:2*n-1]
    
    # Gradient w.r.t. z via softmax chain rule:
    # dz[i] = a[i] * (grad_a[i] - sum_j a[j]*grad_a[j])
    mean_g = float(np.dot(a, grad_a))
    grad_z = a * (grad_a - mean_g)
    
    return smoothed_val, grad_z

def _lbfgs_smooth(z_init, beta, deadline, min_remaining=10.0):
    """Run L-BFGS on the smoothed objective."""
    n = len(z_init)
    
    def obj_fn(z_inner):
        val, _ = _smooth_obj_grad(z_inner, beta, n)
        return val
    
    def grad_fn(z_inner):
        _, g = _smooth_obj_grad(z_inner, beta, n)
        return g
    
    remaining = deadline - min_remaining - time.monotonic()
    if remaining < 5:
        return z_init
    
    est_per_iter = 0.002 * max(1.0, n / 4096.0)
    max_iter = min(5000, max(20, int(remaining / max(est_per_iter, 0.001))))
    
    try:
        result = minimize(
            obj_fn, z_init, jac=grad_fn,
            method='L-BFGS-B',
            options={'maxiter': max_iter, 'ftol': 1e-18, 'gtol': 1e-14,
                     'maxcor': 80, 'maxls': 100}
        )
        return result.x
    except Exception:
        return z_init

def _adaptive_smooth_optimize(z_init, deadline, min_remaining=30.0, max_beta_steps=30):
    """Adaptive beta schedule with L-BFGS."""
    n = len(z_init)
    a = _softmax(z_init)
    c = _full_convolve(a, a)
    c_max = float(c.max())
    
    # Initial beta: small enough for smooth optimization
    beta = 1.0 / (c_max * 2.0)
    
    z = z_init.copy()
    best_z = z.copy()
    best_score = _score(a)
    
    print(f"  Starting adaptive smooth opt: n={n}, c_max={c_max:.6f}, beta={beta:.6f}, score={best_score:.8f}")
    
    for step in range(max_beta_steps):
        if time.monotonic() + min_remaining > deadline:
            break
        
        remaining = deadline - min_remaining - time.monotonic()
        if remaining < 10:
            break
        
        # Run L-BFGS at current beta
        z_new = _lbfgs_smooth(z, beta, deadline, min_remaining)
        a_new = _softmax(z_new)
        c_new = _full_convolve(a_new, a_new)
        c_max_new = float(c_new.max())
        sc_new = _score(a_new)
        
        if sc_new < best_score:
            best_score = sc_new
            best_z = z_new.copy()
        
        z = z_new
        
        # Estimate gap
        c_sorted = np.sort(c_new)[::-1]
        gap = c_max_new - c_sorted[min(1, len(c_sorted)-1)]
        if gap < 1e-15:
            break
        
        # Check if beta is sharp enough
        if beta * gap > 50:
            print(f"  Step {step}: beta={beta:.4f}, c_max={c_max_new:.8f}, score={sc_new:.8f}, gap={gap:.2e}, beta*gap={beta*gap:.1f} - SHARP ENOUGH")
            # Try increasing beta a bit more for final precision
            beta = beta * 2
            continue
        
        # Increase beta
        old_beta = beta
        beta = min(beta * 2.0, 100.0 / gap)
        print(f"  Step {step}: beta {old_beta:.4f} -> {beta:.4f}, c_max={c_max_new:.8f}, score={sc_new:.8f}, gap={gap:.2e}")
        
        if beta - old_beta < 1e-10:
            break
    
    return _softmax(best_z), best_score, best_z

def _kkt_newton_single_peak(a_init, deadline, max_rounds=100):
    """Newton method targeting the single maximum peak (K=1)."""
    n = len(a_init)
    a = a_init.copy()
    s = a.sum()
    if s < 1e-15:
        return a, np.inf
    a = a / s
    best_a = a.copy()
    best_sc = _score(a)
    
    for rnd in range(max_rounds):
        if time.monotonic() > deadline:
            break
        
        c = _full_convolve(a, a)
        c_max = float(c.max())
        k_star = int(np.argmax(c))
        
        # Gradient of c_{k*} w.r.t. a:
        # g[i] = 2 * a[k*-i] if 0 <= k*-i < n
        g = np.zeros(n)
        lo = max(0, k_star - n + 1)

        if lo <= hi:

            # g[lo] = 2*a[k*-lo], g[lo+1] = 2*a[k*-lo-1], ..., g[hi] = 2*a[k*-hi]
            # So g[lo:hi+1] = 2 * [a[k*-lo], a[k*-lo-1], ..., a[k*-hi]]
            # = 2 * a[k*-hi : k*-lo+1 : -1] ... 
            # Actually: a[k*-lo], a[k*-lo-1], ..., a[k*-hi] is a slice a[k*-lo : k*-hi-1 : -1]

            pass

        for i in range(lo, hi+1):
            g[i] = 2.0 * a[k_star - i]
        
        # Project gradient to sum=0 (null space of sum constraint)
        g = g - np.mean(g)
        g_norm = float(np.linalg.norm(g))
        if g_norm < 1e-15:
            break
        
        # Hessian of c_{k*}: H[i,j] = 2 if i+j = k*, else 0
        # This is 2 * H_{k*} where H_{k*} is the anti-diagonal matrix
        # H_{k*} * v = v reversed and shifted
        # (H_{k*} * v)[i] = v[k*-i] if 0 <= k*-i < n
        
        # Solve H * dx = -g (Newton step)
        # (H * dx)[i] = 2 * dx[k*-i] (for valid k*-i)
        # So we need: 2 * dx[k*-i] = -g[i] for all i where valid
        # dx[k*-i] = -g[i]/2, i.e., dx[j] = -g[k*-j]/2 (for valid k*-j)
        
        dx = np.zeros(n)
        for i in range(lo, hi+1):
            dx[i] = -g[k_star - i] / 2.0
        # But this doesn't account for the constraint sum(dx) = 0
        # We need to solve H * dx = -g_proj where g_proj is the projected gradient

        # Find dx minimizing (1/2) dx^T H dx + g^T dx subject to 1^T dx = 0
        # KKT: H dx + g + lambda * 1 = 0, 1^T dx = 0
        # dx = -H^{-1}(g + lambda*1)
        # 1^T dx = -1^T H^{-1}(g + lambda*1) = 0
        # lambda = -1^T H^{-1} g / 1^T H^{-1} 1
        
        # H^{-1} = H (since H^2 = 2I... wait, let me check)
        # (H * v)[i] = 2 * v[k*-i] (for valid)
        # (H * (H*v))[i] = 2 * (H*v)[k*-i] = 2 * 2 * v[(k*-i)-k*] ... 
        # Hmm, this is getting complicated with the boundary effects.
        
        # Let me just use the direct solution:
        # H dx = -g means: 2*dx[k*-i] = -g[i] for all valid i
        # dx[i] = -g[k*-i]/2 for all valid i (where k*-i is in [0,n-1])
        
        dx2 = np.zeros(n)
        for i in range(lo, hi+1):
            j = k_star - i
            dx2[j] = -g[i] / 2.0
        # This gives H*dx2 = -g (approximately, ignoring boundary effects)
        
        # Enforce sum constraint: dx = dx2 - mean(dx2)
        dx = dx2 - np.mean(dx2)
        
        # Check if this is a descent direction: g^T dx < 0
        if float(np.dot(g, dx)) >= 0:

            dx = -g / max(g_norm, 1e-30)

        alpha = 1.0
        step_done = False
        for ls in range(40):
            a_try = a + alpha * dx
            a_try = np.maximum(a_try, 0)

            if s_try < 1e-15:
                alpha *= 0.5
                continue
            a_try = a_try / s_try
            c_try = _full_convolve(a_try, a_try)
            c_max_try = float(c_try.max())
            if c_max_try < c_max - 1e-15:

                step_done = True
                break
            alpha *= 0.5
            if alpha < 1e-15:
                break
        
        if not step_done:

            for trial in [0.01, 0.005, 0.001, 0.0005]:

                s_try = a_try.sum()
                if s_try < 1e-15:
                    continue
                a_try = a_try / s_try

                if float(c_try.max()) < c_max - 1e-15:

                    step_done = True
                    break
        
        sc = _score(a)
        if sc < best_sc - 1e-16:
            best_sc = sc
            best_a = a.copy()
        elif sc >= best_sc + 1e-10:
            a = best_a.copy()
        
        if not step_done:
            break
    
    return best_a, best_sc

def _make_initial_profile(n, kind="tapered"):
    if kind == "tapered":
        t = np.linspace(0, 1, n)
        a = np.sin(np.pi * t) ** 0.8
        a = np.maximum(a, 1e-10)
        return a / a.sum()
    elif kind == "gaussian":
        t = np.linspace(0, 1, n)
        a = np.exp(-2.0 * (t - 0.5) ** 2) + 0.01
        return a / a.sum()
    elif kind == "cos":
        t = np.linspace(0, 1, n)
        a = 0.5 + 0.5 * np.cos(np.pi * t)
        a = np.maximum(a, 1e-10)
        return a / a.sum()
    elif kind == "uniform":
        return np.ones(n) / n
    else:
        return np.ones(n) / n

def _resample(a, n_new):
    n_old = len(a)
    x_old = np.linspace(0, 1, n_old)
    x_new = np.linspace(0, 1, n_new)
    a_new = np.interp(x_new, x_old, a)
    a_new = np.maximum(a_new, 0)
    s = a_new.sum()
    if s < 1e-15:
        return np.ones(n_new) / n_new
    return a_new / s

def _perturb(a, sigma, rng):
    z = np.log(np.maximum(a, 1e-30))
    z = z + sigma * rng.standard_normal(len(a))
    z = z - z.mean()
    return _softmax(z)
