Let m = k - j. As k ranges from k_min to k_max, m ranges from k_min - j to k_max - j.
(Ba)_j = (1/|K|) * sum_{m=max(0, k_min-j)}^{min(n-1, k_max-j)} a_m

This is a "sliding window sum" of a! Which can be computed in O(n) using a prefix sum.

So if K is contiguous, Ba can be computed in O(n) total! That's excellent.

Let me verify: For a contiguous K = {k_min, ..., k_max} with length L = k_max - k_min + 1:
(Ba)_j = (1/L) * (prefix_a[min(n-1, k_max-j)+1] - prefix_a[max(0, k_min-j)])

where prefix_a[i] = sum_{m=0}^{i-1} a_m.

This is O(n) for all j. 

Now, the focal set K: at any point, the constraints that are "active" (c_k close to max) form a contiguous range around the peak(s). Since the convolution of a non-negative sequence is a "unimodal-like" shape (not necessarily unimodal, but the peaks are typically clustered), the active set should be contiguous.

Actually, for non-negative a, the convolution c = conv(a,a) is not necessarily unimodal. It can have multiple peaks. But in practice, for the kinds of profiles we're dealing with, the active constraints will be a small number of contiguous ranges.

Wait, there's an issue. The FW update `a = (1-γ)a + γ e_{j*}` increases a_{j*} and decreases all other a_j. This is correct for the FW method.

But I realize there's a subtlety: the FW method for min a^T B a on the simplex will converge to a vertex (one of the e_j) if B is PSD. If B is not PSD, it may converge to an interior point or a face.

For our problem, B = (1/L) sum_{k in K} Q_k. Is B PSD? Q_k has eigenvalues in {-1, 0, 1} (since it's a "partial permutation" matrix). The sum of such matrices is not necessarily PSD.

In practice, for the focal set near the center (k ≈ n-1), Q_k is close to the identity (for k = n-1, Q_k = J the reversal matrix, which has eigenvalues ±1). So B near the center is not PSD, and the QP is non-convex. The FW method may find a local minimum.

This is fine for our purposes - we're using FW as a heuristic to navigate the non-convex landscape.

Let me also think about the **mirror descent with exact subgradient** approach as a complementary method:

At a point a, the subgradient of f(a) = max_k c_k(a) is:
g = ∇c_{k*}(a) = 2 * Q_{k*} a (where k* = argmax c_k)

The mirror descent update (with entropy mirror) is:
a_new_j = a_j * exp(-η * g_j) / Z

where Z = sum_j a_j * exp(-η * g_j) is a normalization constant.

This is equivalent to:
log(a_new_j / a_j) = -η * g_j + log(Z)
So in log-space: log(a_new) = log(a) - η * g + constant

Since g = 2 * Q_{k*} a, we have:
log(a_new_j) ∝ log(a_j) - 2η * a_{k*-j}

This means: where a_{k*-j} is large (i.e., where the "partner" element is large), we decrease a_j. This makes sense: to reduce c_{k*} = sum a_j a_{k*-j}, we decrease the elements that are paired with large partners.

The step size η can be chosen by backtracking or by a fixed schedule.

Let me combine both approaches:
1. Use FW to quickly navigate towards a good region
2. Use mirror descent with exact subgradient for fine-tuning
3. Alternate between them

Step function optimizer using adaptive focal Frank-Wolfe with exact
subgradient mirror descent for minimizing 2*n*max(conv(a,a))/sum(a)^2.
Innovations: O(n) FW iterations via prefix-sum convolution with focal set,
Fisher-Rao mirror descent with exact max-subgradient, multi-scale strategy.

import numpy as np
import time
from scipy.optimize import minimize

def _next_pow2(n):
    k = 1
    while k < n:
        k <<= 1
    return max(2, k)

def _full_convolve(a, b):
    n, m = len(a), len(b)
    out_n = n + m - 1
    N = _next_pow2(out_n)
    fa = np.fft.rfft(a, N)
    fb = np.fft.rfft(b, N)
    r = np.fft.irfft(fa * fb, N)[:out_n]
    return r

def _score(a):
    n = len(a)
    s = float(a.sum())
    if s < 1e-15:
        return np.inf
    c = _full_convolve(a, a)
    return float(2.0 * n * c.max() / (s * s))

def _normalize(a):
    a = np.maximum(a, 0.0)
    s = a.sum()
    if s < 1e-30:
        return np.ones_like(a) / len(a)
    return a / s

def _fw_iterate(a, k_min, k_max, max_iter=50000, tol=1e-14):
    """
    Frank-Wolfe for min sum_{k=k_min}^{k_max} c_k(a) on the simplex.
    Uses O(n) per iteration via prefix sums.
    """
    n = len(a)
    L = k_max - k_min + 1
    a = _normalize(a.copy())
    best_a = a.copy()
    best_obj = np.inf
    stalled = 0
    
    for it in range(max_iter):
        # Compute Ba = (1/L) * sum_{k=k_min}^{k_max} Q_k a using prefix sums
        prefix = np.zeros(n + 1)
        np.cumsum(a, out=prefix[1:])
        
        Ba = np.zeros(n)
        # Vectorize: for each j, Ba[j] = (1/L) * sum_{m=max(0,k_min-j)}^{min(n-1,k_max-j)} a[m]
        # m range: [max(0, k_min-j), min(n-1, k_max-j)]
        # Let's compute this vectorized
        j_idx = np.arange(n)
        m_lo = np.maximum(0, k_min - j_idx)
        m_hi = np.minimum(n - 1, k_max - j_idx)
        valid = m_lo <= m_hi
        Ba[valid] = (prefix[m_hi[valid] + 1] - prefix[m_lo[valid]]) / L
        
        obj = float(a @ Ba)
        if obj < best_obj - tol:
            best_obj = obj
            best_a = a.copy()
            stalled = 0
        else:
            stalled += 1
            if stalled > 5000:
                break
        
        # FW step
        j_star = int(np.argmin(Ba))
        Ba_j = Ba[j_star]
        Bjj = (1.0 / L) if (2 * j_star >= k_min and 2 * j_star <= k_max) else 0.0
        dBa = Ba_j - obj
        dBd = Bjj - 2.0 * Ba_j + obj
        
        if dBd > 1e-15:
            gamma = np.clip(-dBa / dBd, 0.0, 1.0)
        else:
            gamma = 2.0 / (it + 2)
        
        if gamma < 1e-15:
            break
        
        # Update: a = (1-gamma)*a + gamma*e_{j_star}
        a *= (1.0 - gamma)
        a[j_star] += gamma
        # Renormalize (should already be on simplex, but floating point)
        s = a.sum()
        if abs(s - 1.0) > 1e-12:
            a /= s
    
    return best_a

def _mirror_descent_step(a, c, k_star, eta):
    """
    Mirror descent (Fisher-Rao) step using exact subgradient of c_{k_star}.
    Subgradient: g_j = 2 * a_{k_star - j} (if valid), else 0.
    Update: a_j <- a_j * exp(-eta * g_j) / Z
    """
    n = len(a)
    # Compute subgradient
    g = np.zeros(n)
    j_idx = np.arange(n)
    partner = k_star - j_idx
    valid = (partner >= 0) & (partner < n)
    g[valid] = 2.0 * a[partner[valid]]
    
    # Mirror descent update
    # log(a_new_j) = log(a_j) - eta * g_j + const
    # a_new_j = a_j * exp(-eta * g_j) / Z
    log_weights = -eta * g
    log_weights -= log_weights.max()  # for numerical stability
    weights = np.exp(log_weights)
    a_new = a * weights
    s = a_new.sum()
    if s < 1e-30:
        return a
    a_new /= s
    return a_new
