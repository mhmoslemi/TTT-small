Let me focus on a practical improvement:

**Key improvement idea**: Use a **multiplicative update** (like the one used in non-negative matrix factorization) instead of additive gradient descent.

The multiplicative update for minimizing `max_k conv(a,a)[k]` subject to `sum(a)=1, a>=0` would be:
```
a[j] *= exp(-eta * (grad[j] - lambda))
```
where `grad[j]` is the subgradient component and `lambda` is chosen to maintain the sum constraint.

This naturally maintains non-negativity and can be more stable than additive updates.

Actually, let me think about this differently. The objective is:
`f(a) = max_k (A_k a)` where `A_k` is the quadratic form... no, it's not linear.

`f(a) = max_k sum_{i+j=k} a[i]*a[j]`

The gradient at a point where the max is achieved at k* is:
`df/da[j] = 2*a[k*-j]` (with the special case `k*=2j` giving `a[j]`)

For the subgradient (when max is achieved at multiple points), we can use any convex combination.

A natural choice is the "mean subgradient":
`subgrad[j] = (1/|S|) * sum_{k in S} 2*a[k-j]` (with appropriate handling)

Then the update is:
`a[j] = a[j] - eta * (subgrad[j] - mean(subgrad))` (projected onto simplex)

Or multiplicatively:
`a[j] = a[j] * exp(-eta * (subgrad[j] - mean(subgrad)))`

The multiplicative version is better because it naturally maintains positivity.

Let me code this up with some improvements over the previous approach:

1. **Multiplicative gradient descent** as the main workhorse (faster per iteration than L-BFGS for this problem).
2. **Adaptive active set** with careful tolerance.
3. **Periodic L-BFGS polishing**.
4. **Multiple restarts** from the parent with small perturbations.
5. **Try n values around the parent's n**.

Let me also think about the computation per iteration:
- Computing conv(a,a): O(n log n) via FFT
- Computing the subgradient: O(n log n) via FFT (convolution of weights with reversed a)
- Update: O(n)

So each iteration is O(n log n). For n=16384, this is about 16384 * 14 ≈ 230K operations. At ~100M ops/sec in Python (with numpy), that's about 2-3 ms per iteration. So in 1800 seconds, we can do about 600K iterations. That's a lot!

But each FFT call in numpy has overhead, so realistically maybe 1000-5000 iterations. Still a lot.

Multi-phase optimizer using multiplicative gradient descent with adaptive 
active-set tracking, combined with periodic L-BFGS polishing.
Key innovations:
- Multiplicative (exponentiated) gradient updates for natural non-negativity
- Adaptive active-set with hysteresis
- Backtracking line search
- Periodic L-BFGS for fine-tuning
- Multiple n exploration

import numpy as np
import time
from scipy.optimize import minimize

def _next_pow2(n):
    k = 1
    while k < n:
        k <<= 1
    return max(2, k)

def _full_convolve(a, b):
    n, m = len(a), len(b)
    out_n = n + m - 1
    N = _next_pow2(out_n)
    fa = np.fft.rfft(a, N)
    fb = np.fft.rfft(b, N)
    r = np.fft.irfft(fa * fb, N)[:out_n]
    return r

def _score(a):
    n = len(a)
    s = float(a.sum())
    if s < 1e-15:
        return np.inf
    a_norm = a / s
    c = _full_convolve(a_norm, a_norm)
    return float(2.0 * n * c.max())

def _conv_and_score(a):
    n = len(a)
    s = float(a.sum())
    if s < 1e-15:
        return np.inf, None
    a_norm = a / s
    c = _full_convolve(a_norm, a_norm)
    sc = float(2.0 * n * c.max())
    return sc, c

def _subgradient(a, c, tol_frac=0.005):
    """Compute the mean subgradient of max(conv(a,a)) w.r.t. a.
    
    Returns: gradient vector of length n
    """
    n = len(a)
    c_max = float(c.max())
    active = c >= (c_max - tol_frac * c_max)
    n_active = int(active.sum())
    if n_active == 0:
        idx = int(np.argmax(c))
        active = np.zeros_like(c, dtype=bool)
        active[idx] = True
        n_active = 1
    
    # subgrad[j] = (1/n_active) * sum_{k in active} d conv[k]/d a[j]
    # d conv[k]/d a[j] = 2*a[k-j] if k-j in [0,n-1] and k != 2j
    #                    = a[j] if k == 2j
    # This equals: conv(w_active, a_rev)[n-1+j] where a_rev = a[::-1]
    # But we need to handle the diagonal case.
    
    # Actually, let's use the convolution formula directly:
    # sum_{k in active} 2*a[k-j] (with the factor of 2 accounting for both terms)
    # = 2 * sum_{k in active} a[k-j]
    # = 2 * (w_active * a_rev)[n-1+j] ... 
    
    # Wait, I need to be careful. Let me define:
    # w = active / n_active (length 2n-1)
    # a_rev = a[::-1] (length n)
    # conv(w, a_rev)[j + (n-1)] = sum_i w[i] * a_rev[j+n-1-i]
    # = sum_i w[i] * a[n-1-(j+n-1-i)]
    # = sum_i w[i] * a[i-j]
    # = sum_{k} w[k] * a[k-j]  (reindexing)
    # 
    # So conv(w, a_rev)[n-1+j] = sum_k w[k] * a[k-j]
    
    # The gradient of conv(a,a)[k] w.r.t. a[j]:
    # = a[k-j] (if k-j in [0,n-1]) + a[k-j] (if k-j in [0,n-1], from the other term)
    # But if k-j = j (i.e., k=2j), it's just a[j] (single term)
    # So it's 2*a[k-j] if k != 2j, and a[j] if k = 2j.
    
    # The "2*a[k-j]" approximation misses the diagonal correction.
    # For large n, the diagonal is a small fraction, so the approximation is good.
    
    # Let's use the convolution approach:
    a_rev = a[::-1]
    w = np.zeros(2*n-1)
    w[active] = 1.0 / n_active
    wc = _full_convolve(w, a_rev)
    grad = 2.0 * wc[n-1:2*n-1]
    
    # Diagonal correction: for k in active where k=2j (j in [0,n-1]):
    # The true gradient is a[j] instead of 2*a[j], so we subtract a[j] for each such k.
    # k = 2j means j = k/2, so we need k to be even.
    for k_idx in np.where(active)[0]:
        k_val = int(k_idx)
        if k_val % 2 == 0:
            j_val = k_val // 2
            if 0 <= j_val < n:
                grad[j_val] -= a[j_val] / n_active
    
    return grad, n_active

def _lbfgs_step(a_init, deadline, min_remaining=20.0, verbose=False):
    """Single L-BFGS step with smooth approximation."""
    n = len(a_init)
    a = a_init.copy()
    s = a.sum()
    a = a / s
    
    c0 = _full_convolve(a, a)
    c0_max = float(c0.max())
    best_a = a.copy()
    best_sc = 2.0 * n * c0_max
    
    z = np.log(np.maximum(a, 1e-30))
    z = z - z.mean()
    
    # Compute gap for beta
    c_sorted = np.sort(c0)[::-1]
    gap = c_sorted[0] - c_sorted[min(50, len(c_sorted)-1)]
    if gap < c0_max * 0.005:
        gap = c0_max * 0.005
    
    # A few beta levels
    betas = gap * np.array([0.1, 0.05, 0.01, 0.005, 0.001])
    
    for beta in betas:
        if time.monotonic() + min_remaining > deadline:
            break
        
        def obj(z_):
            a_ = _softmax(z_)
            c_ = _full_convolve(a_, a_)
            return 2.0 * n * _soft_max(c_, beta)
        
        def grad(z_):
            a_ = _softmax(z_)
            c_ = _full_convolve(a_, a_)
            w_ = _soft_max_weights(c_, beta)
            a_rev_ = a_[::-1]
            wc_ = _full_convolve(w_, a_rev_)
            grad_a = 2.0 * wc_[n-1:2*n-1]
            W = float(np.dot(grad_a, a_))
            return a_ * (grad_a - W)
        
        try:
            result = minimize(obj, z, jac=grad, method='L-BFGS-B',
                            options={'maxiter': 2000, 'ftol': 1e-16, 'gtol': 1e-14, 'maxcor': 50})
            a_new = _softmax(result.x)
            sc_new = _score(a_new)
            if sc_new < best_sc - 1e-14:
                best_sc = sc_new
                best_a = a_new.copy()
                z = np.log(np.maximum(a_new, 1e-30))
                z = z - z.mean()
        except Exception:
            pass
    
    return best_a, best_sc

def _softmax(z):
    z = z - np.max(z)
    e = np.exp(np.clip(z, -700, 700))
    s = e.sum()
    if s < 1e-300:
        return np.ones_like(z) / len(z)
    return e / s

def _soft_max(c, beta):
    c_max = float(c.max())
    shifted = (c - c_max) / beta
    e = np.exp(np.clip(shifted, -700, 0))
    s = e.sum()
    if s < 1e-300:
        return c_max
    return c_max + beta * np.log(s)

def _soft_max_weights(c, beta):
    c_max = float(c.max())
    shifted = (c - c_max) / beta
    e = np.exp(np.clip(shifted, -700, 0))
    s = e.sum()
    if s < 1e-300:
        w = np.zeros_like(c)
        w[int(np.argmax(c))] = 1.0
        return w
    return e / s
