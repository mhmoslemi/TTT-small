    denominator = (np.sum(sequence)) ** 2
    if denominator < np.finfo(float).eps:
        return np.inf
    return float(2.0 * n * max_conv / denominator)

def geometric_resampling(cand, k=2):
    """Resample candidates geometrically to double or halve the length."""
    n_prev = len(cand)
    cand_new_length = n_prev * k  # double, or maybe octagon? We'll double for a while.
    x = np.linspace(0, 1, n_prev)
    # But keep the important parts: optimize at the new scale
    cand_resampled = np.interp(x, np.linspace(0, 1, cand_new_length), cand)
    cand_resampled = np.maximum(cand_resampled, 0.0).astype(float)
    return cand_resampled

### Detailed Rationale and Analysis:

#### 1. Approach and Rationale:

The previous program performed well but was computationally intensive due to several phases. This version seeks a more focused and efficient optimization through:

- **Geometric Resampling**: Instead of fixed length, we use a base length (10000) and scale candidates by factors of 2 or 0.5, enabling analysis across problem dimensions.

- **Asymmetric Perturbation**: Orchestrated to break symmetry and explore areas missed by uniform methods. Perturbations are guided by sine variations, offering less aggressive but effective deviation.

- **Simplex Optimization via scipy**: We use downhill simplex (Nelder-Mead) which is gradient-free and suits floating-point optimization under scalability constraints.

- **Refined Search Cycles**: We break the search into cycles that systematically attempt component-wise optimization, geometric resampling, and asymmetric perturbations.

We've tried to absorb the technical nuances of previous methods into an intrinsic🔄 dimensional framework while ensuring budget adherence.

#### 2. Mathematical Specification:

We represent sequences as floating-point numbers of length \( n \). The objective is \( 2 \cdot n \cdot \max(\text{full convolution}) / (\sum a)^2 \).

Constraints:

- Sequences must be non-negative after conversion.
- Individual elements capped at 1000 in simulation (evaluator does).
- Sum criterion: must be at least 0.01 (evaluator normalizes to validate this).
- Search space defined by geometric progression and asymmetric variations.

We map these via:

- Normalization: \(a \rightarrow a / \sum a\) preserves the objective value but alignment yields favorable convergence.
- Full convolution: \(mode='full'\) was confirmed in the evaluator function.
- Usecase dependencies: we default to 10000 if parent unavailable, or scale parent appropriately.

The simplex method's major advantage is that it handles \(n\)-dimension objective space without requiring derivatives, making it suitable.
