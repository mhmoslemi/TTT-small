To get a flat sum distribution, we need a non-uniform marginal distribution. This is a classic problem in probability theory.

One approach: Use the "Fourier" (characteristic function) method. The characteristic function of the sum is the square of the characteristic function of the marginal. We want the sum distribution to be flat, which means its Fourier transform should be concentrated at the DC component.

The sum distribution is flat (uniform on {0, ..., 2n-2}) iff φ(θ)^2 = (1/(2n-1)) * sum_{k=0}^{2n-2} e^{ikθ} for all θ.

This is the squared magnitude of the Dirichlet kernel, which is not a valid characteristic function squared (it doesn't satisfy the positive definiteness condition in general).

def _full_convolve(a, b):
    n, m = len(a), len(b)
    out_n = n + m - 1
    N = _next_pow2(out_n)
    fa = np.fft.rfft(a, N)
    fb = np.fft.rfft(b, N)
    r = np.fft.irfft(fa * fb, N)[:out_n]
    return r
