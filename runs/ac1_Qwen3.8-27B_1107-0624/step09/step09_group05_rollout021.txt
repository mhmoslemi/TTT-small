Let me also think about the active-set method more carefully.

The active-set gradient descent:
1. Compute $c = a * a$
2. Identify active set $S$ (peaks near max)
3. Compute gradient $g = \frac{1}{|S|} \sum_{k \in S} \nabla c_k$
4. Compute residual $r = g - \bar{g}$ where $\bar{g} = \frac{1}{n} \sum_i g_i$
5. Try step $a' = a - \eta r$, project to simplex
6. If score improves, accept; else, reduce $\eta$

The key question: what percentile to use for the active set?

If I use the top 1% (percentile 99), I get about 328 points out of 32767. This might be too many.
If I use the top 0.1% (percentile 99.9), I get about 33 points. This might be better.
If I use the top 0.01% (percentile 99.99), I get about 3 points. This is close to a single-point active set.

I think a good approach is to start with a large active set (top 5%) and gradually tighten to a small active set (top 0.1%) as the optimization progresses. This is analogous to the beta schedule in L-BFGS.

```python
def _active_set_phase(a_init, deadline, min_time=30):
    n = len(a_init)
    a = a_init.copy() / a_init.sum()
    best_a = a.copy()
    best_sc = 2.0 * n * float(_full_convolve(a, a).max())
    
    # Start with a large active set, gradually tighten
    percentile = 95.0  # top 5%
    min_percentile = 99.9  # tighten to top 0.1%
    eta = 0.1  # initial step size
    no_improve = 0
    
    while time.monotonic() + min_time < deadline:
        c = _full_convolve(a, a)
        c_max = float(c.max())
        cur_sc = 2.0 * n * c_max
        
        if cur_sc < best_sc - 1e-14:
            best_sc = cur_sc
            best_a = a.copy()
            no_improve = 0
        else:
            no_improve += 1
        
        if no_improve > 50:
            # Tighten active set
            percentile = max(min_percentile, percentile + 0.5)
            eta = max(0.001, eta * 0.5)
            no_improve = 0
        
        # Identify active set
        thresh = np.percentile(c, percentile)
        active = c >= thresh
        n_act = max(1, int(active.sum()))
        
        # Compute gradient
        w = np.zeros(len(c))
        w[active] = 1.0 / n_act
        g = _grad_from_weights(w, a, n)
        lam = float(np.mean(g))
        r = g - lam
        
        # Line search
        improved = False
        for e in [eta, eta*0.5, eta*0.25, eta*0.1, eta*0.01]:
            a_new = a - e * r
            a_new = np.maximum(a_new, 0.0)
            s = a_new.sum()
            if s < 1e-10:
                continue
            a_new = a_new / s
            c_new = _full_convolve(a_new, a_new)
            sc_new = 2.0 * n * float(c_new.max())
            if sc_new < cur_sc - 1e-14:
                a = a_new
                improved = True
                break
        
        if not improved:
            eta = max(0.0001, eta * 0.5)
            if eta < 0.0001:
                break
        
        # Gradually tighten
        if improved:
            percentile = max(min_percentile, percentile + 0.1)
    
    return best_a, best_sc
```
