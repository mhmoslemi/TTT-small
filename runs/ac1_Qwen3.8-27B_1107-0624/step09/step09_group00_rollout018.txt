import time
from scipy.optimize import minimize

def _full_convolve(a, b):
    n, m = len(a), len(b)
    out_n = n + m - 1
    k = 1
    while k < out_n:
        k <<= 1
    N = max(2, k)
    fa = np.fft.rfft(a, N)
    fb = np.fft.rfft(b, N)
    r = np.fft.irfft(fa * fb, N)[:out_n]
    return r

def _score(a):
    n = len(a)
    s = float(a.sum())
    if s < 1e-15:
        return np.inf
    c = _full_convolve(a, a)
    return float(2.0 * n * c.max() / (s * s))

def _normalize(a):
    a = np.maximum(a, 0.0)
    s = a.sum()
    if s < 1e-30:
        return np.ones_like(a) / len(a)

One more thought: the geometric sequence `a[j] = r^j` for `r` slightly above 1 gives a convolution that's not too peaked. Let me compute what `r` to use.

For `a[j] = r^j`, `j = 0, ..., n-1`:
- `c[k] = (k+1) * r^k` for `0 <= k <= n-1`
- `c[k] = (2n-1-k) * r^k` for `n <= k <= 2n-2`

The max is somewhere. For `r > 1`, the right-side terms grow like `r^k` while the left-side also grow. The max is likely at or near `k = 2n-2` (the last element) for large `r`, or somewhere in the middle for `r` close to 1.

For `r` close to 1: `c[k] ≈ (k+1)` for `k < n` (triangular) and `c[k] ≈ (2n-1-k)` for `k >= n`. The max is at `k = n-1` or `k = n`, value ≈ `n`. Score = `2n*n/(n^2) = 2` (same as uniform, since geometric with r≈1 is close to uniform).

For the score to be better than 2, we need the max to be less than `n` (when `sum ≈ n`, i.e., r close to 1). But for r exactly 1, the max IS n. So we need r to deviate from 1 enough to make the convolution non-symmetric.
