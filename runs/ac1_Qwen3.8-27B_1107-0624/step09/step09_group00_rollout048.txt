So a perfectly flat autocorrelation is impossible for non-negative sequences. The best we can do is to make the "sidelobes" (k ≠ n-1) as close to c[n-1] as possible, or equivalently, to make c[n-1] as small as possible relative to the mean of c.

The mean of c is `sum_k c[k] / (2n-1) = (sum a)^2 / (2n-1)`.

So we want `c[n-1] / mean(c) = (2n-1) * sum(a^2) / (sum(a))^2` to be as close to 1 as possible.

By Cauchy-Schwarz, `sum(a^2) >= (sum a)^2 / n`, so the ratio is at least `(2n-1)/n ≈ 2` for large n.

Wait, that's the ratio of the "zero-lag" autocorrelation to the mean. But the MAX of c might not be at n-1!

For non-negative sequences, I argued earlier that the max is at n-1. Let me verify this claim.

Claim: For non-negative a of length n, max_k (a*a)[k] = (a*a)[n-1].

Proof attempt: For k < n-1, (a*a)[k] = sum_{j=max(0,k-n+1)}^{min(k,n-1)} a[j] * a[k-j]. The number of terms is k+1 (for k < n-1). For k = n-1, the number of terms is n.

But having more terms doesn't necessarily mean a larger sum! For example, if a = [0, 0, ..., 0, 1] (last element is 1), then:
- (a*a)[n-1] = a[n-1]*a[0] + a[n-2]*a[1] + ... + a[0]*a[n-1] = 0 (all cross terms are 0 since only a[n-1] = 1)

Wait no: (a*a)[n-1] = sum_{j=0}^{n-1} a[j]*a[n-1-j]. If a[n-1] = 1 and all others 0, then (a*a)[n-1] = a[0]*a[n-1] + ... + a[n-1]*a[0] = 0 + ... + 0 = 0. And (a*a)[2n-2] = a[n-1]*a[n-1] = 1.

So the max is at 2n-2, not n-1! My claim was wrong.

So for non-negative sequences, the max of the linear autocorrelation can be at the ends (k=0 or k=2n-2) or in the middle (k=n-1), depending on the sequence structure.

This changes the problem significantly! The "peak" we need to minimize could be at the edges (a[0]^2 or a[n-1]^2) or in the middle (sum a[j]*a[n-1-j]).

For a "bell-shaped" sequence (large in the middle, small at edges):
- c[0] = a[0]^2 (small)
- c[n-1] = sum a[j]*a[n-1-j] (large, since a is large in the middle)
- c[2n-2] = a[n-1]^2 (small)
- Max is at n-1.

For a "U-shaped" sequence (large at edges, small in middle):
- c[0] = a[0]^2 (large)
- c[n-1] = sum a[j]*a[n-1-j] (smaller, since the large elements don't align)
- c[2n-2] = a[n-1]^2 (large)
- Max is at 0 or 2n-2.

For a "flat" sequence:
- All c[k] are similar, max ≈ n * a^2 (at n-1)

So the optimal sequence shape depends on the trade-off between edge peaks and center peak.

This is a crucial insight! The previous approaches probably converged to a "bell-shaped" or "flat" profile, but maybe a slightly "U-shaped" or "bimodal" profile could be better!

    elif kind == "bimodal_wide":
        t = np.linspace(0, 1, n)
        a = np.exp(-8.0 * (t - 0.3) ** 2) + np.exp(-8.0 * (t - 0.7) ** 2)
        a = np.maximum(a, 1e-10)
        return a / a.sum()
    elif kind == "trimodal":
        t = np.linspace(0, 1, n)
        a = (np.exp(-15.0 * (t - 0.25) ** 2) +
             np.exp(-15.0 * (t - 0.5) ** 2) +
             np.exp(-15.0 * (t - 0.75) ** 2))
        a = np.maximum(a, 1e-10)
        return a / a.sum()
    elif kind == "u_shape":
        t = np.linspace(0, 1, n)
        a = 1.0 + 3.0 * (2.0 * t - 1.0) ** 2
        a = np.maximum(a, 1e-10)
        return a / a.sum()
    elif kind == "random":
        a = rng.random(n)
        a = np.maximum(a, 1e-10)
        return a / a.sum()
    else:
        return np.ones(n) / n


def _cross_correlation_fft(w, a):
    """Compute sum_k w[k] * a[k-j] for j=0..n-1 using FFT."""
    n = len(a)
    N_fft = 2 * n
    W = np.fft.rfft(w, N_fft)
    A = np.fft.rfft(a, N_fft)
    result = np.fft.irfft(W * np.conj(A), N_fft)
    return result[:n]


def _mirror_descent(a_init, deadline, eta_init=0.05, eta_decay=0.995,
                    eta_min=0.0001, tol_frac_start=0.05, tol_frac_end=0.0001,
                    tol_decay=0.99):
    """Mirror descent with multiplicative updates for L-infinity autocorrelation minimization."""
    n = len(a_init)
    a = _normalize(a_init.copy())
    best_a = a.copy()
    best_sc = 2.0 * n * float(_full_convolve(a, a).max())
    eta = eta_init
    tol_frac = tol_frac_start
    stall = 0
    max_stall = 2000

    while time.monotonic() < deadline:
        c = _full_convolve(a, a)
        c_max = float(c.max())
        current_sc = 2.0 * n * c_max

        if current_sc < best_sc - 1e-14:
            best_sc = current_sc
            best_a = a.copy()
            stall = 0
        else:
            stall += 1

        if stall > max_stall:
            a = best_a.copy()
            eta = max(eta_min, eta * 0.5)
            tol_frac = max(tol_frac_end, tol_frac * 0.5)
            stall = 0
            if eta <= eta_min and tol_frac <= tol_frac_end * 2:
                break

        # Active set: peaks within tolerance of max
        tol = tol_frac * c_max
        active = c >= (c_max - tol)
        n_active = int(active.sum())
        if n_active == 0:
            idx = int(np.argmax(c))
            active = np.zeros_like(c, dtype=bool)
            active[idx] = True
            n_active = 1

        # Inverse-gap weighting for more aggressive peak targeting
        eps = 1e-10 * c_max
        w = np.zeros_like(c)
        w[active] = 1.0 / (c_max - c[active] + eps)
        w = w / w.sum()

        # Compute driving force: D[j] = sum_k w[k] * a[k-j] (cross-correlation)
        D = _cross_correlation_fft(w, a)
        D = 2.0 * D
        # Center the force (project onto sum-zero subspace for stability)
        D = D - np.mean(D)

        # Multiplicative update: a_new[j] = a[j] * exp(-eta * D[j])
        log_scale = -eta * D
        log_scale = log_scale - np.max(log_scale)
        a_new = a * np.exp(log_scale)
        a_new = np.maximum(a_new, 0.0)
        s = a_new.sum()
        if s < 1e-30:
            a_new = a.copy()
        else:
            a_new = a_new / s
        a = a_new

        # Adaptive step size
        if current_sc > best_sc * 1.001:
            eta = max(eta_min, eta * 0.9)
        elif stall > 500:
            eta = max(eta_min, eta * 0.98)
            tol_frac = max(tol_frac_end, tol_frac * tol_decay)
        else:
            eta = min(eta_init * 2, eta * 1.002)
            tol_frac = max(tol_frac_end, tol_frac * 0.999)

    return best_a, _score(best_a)


def _smoobj(z, beta, n):
    a = _softmax(z)
    c = _full_convolve(a, a)
    c_max = float(c.max())
    shifted = (c - c_max) / beta
    e = np.exp(np.clip(shifted, -700, 0))
    s = e.sum()
    if s < 1e-300 or not np.isfinite(s):
        return 2.0 * n * c_max
    return 2.0 * n * (c_max + beta * np.log(s))


def _smograd(z, beta, n):
    a = _softmax(z)
    c = _full_convolve(a, a)
    c_max = float(c.max())
    shifted = (c - c_max) / beta
    e = np.exp(np.clip(shifted, -700, 0))
    s = e.sum()
    if s < 1e-300 or not np.isfinite(s):
        w = np.zeros_like(c)
        w[int(np.argmax(c))] = 1.0
    else:
        w = e / s
    a_rev = a[::-1]
    wc = _full_convolve(w, a_rev)
    h = wc[n - 1:2 * n - 1]
    W = float(np.dot(w, c))
    return 4.0 * n * a * (h - W)


class _LbfgsProblem:
    def __init__(self, beta, n):
        self.beta = beta
        self.n = n

    def f(self, z):
        return _smoobj(z, self.beta, self.n)

    def g(self, z):
        return _smograd(z, self.beta, self.n)


def _run_lbfgs(a_init, deadline, min_time_remaining=30.0):
    """L-BFGS with aggressive beta annealing schedule."""
    n = len(a_init)
    c_cur = _full_convolve(a_init, a_init)
    max_c = float(c_cur.max())
    if max_c < 1e-15:
        return a_init

    # Estimate initial beta from peak structure
    c_sorted = np.sort(c_cur)[::-1]
    gap_idx = min(50, len(c_sorted) - 1)
    gap = c_sorted[0] - c_sorted[gap_idx]
    if gap < max_c * 0.001:
        gap = max_c * 0.001
    base_beta = max(gap, max_c * 0.003)

    # More aggressive annealing: more steps, smaller final beta
    betas = base_beta * np.array([
        1.0, 0.7, 0.5, 0.35, 0.25, 0.18, 0.12, 0.08, 0.055,
        0.04, 0.028, 0.02, 0.014, 0.01, 0.007, 0.005, 0.0035,
        0.0025, 0.0018, 0.0012, 0.0008, 0.0005, 0.0003, 0.0002,
        0.00012, 0.00008, 0.00005, 0.00003, 0.00002, 0.00001
    ])

    current_a = a_init.copy()
    current_sc = _score(current_a)
    z = np.log(np.maximum(current_a, 1e-30))
    z = z - z.mean()

    for i, beta in enumerate(betas):
        if time.monotonic() + min_time_remaining > deadline:
            break
        remaining = deadline - min_time_remaining - time.monotonic()
        if remaining < 3:
            break

        # Scale max iterations with n
        scale = max(1.0, n / 16384.0)
        est_time = 0.003 * scale
        max_iter = min(8000, max(30, int(remaining / (est_time * 20))))

        prob = _LbfgsProblem(beta, n)
        try:
            result = minimize(
                prob.f, z, jac=prob.g, method='L-BFGS-B',
                options={'maxiter': max_iter, 'ftol': 1e-20, 'gtol': 1e-16,
                         'maxcor': 150, 'maxls': 50}
            )
            a_new = _softmax(result.x)
            sc_new = _score(a_new)
            if sc_new < current_sc - 1e-15:
                current_a = a_new
                current_sc = sc_new
                z = np.log(np.maximum(a_new, 1e-30))
                z = z - z.mean()
        except Exception:
            pass

    return current_a


def _quick_optimize(a_init, deadline, min_time_remaining=10.0):
    """Combined mirror descent + L-BFGS optimization."""
    if time.monotonic() < deadline - min_time_remaining - 10:
        md_deadline = min(deadline - min_time_remaining - 10, time.monotonic() + 30)
        a_md, sc_md = _mirror_descent(a_init, md_deadline,
                                       eta_init=0.03, eta_min=0.0005,
                                       tol_frac_start=0.03, tol_frac_end=0.0005)
        a = a_md
    else:
        a = a_init.copy()

    if time.monotonic() < deadline - min_time_remaining:
        lbfgs_deadline = min(deadline - min_time_remaining, time.monotonic() + 40)
        a = _run_lbfgs(a, lbfgs_deadline, min_time_remaining=5.0)

    return a


def _stochastic_ils(a_init, deadline, rng, min_time_remaining=30.0):
    """Stochastic ILS with diverse perturbations including structural changes."""
    n = len(a_init)
    current_a = _normalize(a_init.copy())
    current_sc = _score(current_a)
    best_a = current_a.copy()
    best_sc = current_sc

    strategies = [
        ('global_small', 0.003),
        ('global_med', 0.015),
        ('global_large', 0.05),
        ('block', 0.04),
        ('sparse', 0.1),
        ('mirror_seg', 0.02),
        ('gaussian_blend', 0.3),
        ('subsample', 0.0),
        ('global_small', 0.002),
        ('asymmetric', 0.03),
    ]

    attempt = 0
    while time.monotonic() + min_time_remaining < deadline:
        kind, sigma = strategies[attempt % len(strategies)]

        if kind == 'global_small' or kind == 'global_med' or kind == 'global_large':
            z = np.log(np.maximum(current_a, 1e-30))
            z = z + sigma * rng.standard_normal(n)
            z = z - z.mean()
            a_perturbed = _softmax(z)
        elif kind == 'block':
            block_size = max(30, n // 6)
            start = int(rng.integers(0, max(1, n - block_size)))
            a_perturbed = current_a.copy()
            z = np.log(np.maximum(a_perturbed[start:start + block_size], 1e-30))
            z = z + sigma * rng.standard_normal(block_size)
            a_perturbed[start:start + block_size] = np.exp(z - np.max(z))
            a_perturbed = _normalize(a_perturbed)
        elif kind == 'sparse':
            n_perturb = max(20, n // 10)
            idx = rng.choice(n, size=n_perturb, replace=False)
            a_perturbed = current_a.copy()
            factors = np.exp(sigma * rng.standard_normal(n_perturb))
            a_perturbed[idx] *= factors
            a_perturbed = _normalize(a_perturbed)
        elif kind == 'mirror_seg':
            seg_len = max(20, n // 15)
            start = int(rng.integers(0, max(1, n - seg_len)))
            a_perturbed = current_a.copy()
            seg = a_perturbed[start:start + seg_len].copy()
            a_perturbed[start:start + seg_len] = seg[::-1]
            z = np.log(np.maximum(a_perturbed, 1e-30))
            z = z + 0.004 * rng.standard_normal(n)
            z = z - z.mean()
            a_perturbed = _softmax(z)
        elif kind == 'gaussian_blend':
            # Blend with a random Gaussian profile
            center = 0.2 + 0.6 * rng.random()
            width = 0.05 + 0.3 * rng.random()
            t = np.linspace(0, 1, n)
            g = np.exp(-((t - center) / width) ** 2)
            g = np.maximum(g, 1e-10)
            g = g / g.sum()
            a_perturbed = (1 - sigma) * current_a + sigma * g
            a_perturbed = _normalize(a_perturbed)
        elif kind == 'subsample':
            # Randomly zero out some elements then re-optimize
            n_zero = n // 20
            idx = rng.choice(n, size=n_zero, replace=False)
            a_perturbed = current_a.copy()
            a_perturbed[idx] = 0.0
            a_perturbed = _normalize(a_perturbed)
            # Add small noise to avoid exact zeros causing issues
            a_perturbed = a_perturbed + 1e-8 * rng.random(n)
            a_perturbed = _normalize(a_perturbed)
        elif kind == 'asymmetric':
            # Create asymmetric perturbation
            t = np.linspace(0, 1, n)
            shift = (rng.random() - 0.5) * 0.1
            a_perturbed = current_a.copy()
            # Shift the profile slightly
            shifted_t = t - shift
            if len(a_init) > 1:
                a_shifted = np.interp(shifted_t, t, a_init, left=0, right=0)
                a_perturbed = (1 - sigma) * a_perturbed + sigma * a_shifted
            a_perturbed = _normalize(a_perturbed)
        else:
            a_perturbed = current_a.copy()

        opt_deadline = min(deadline - min_time_remaining, time.monotonic() + 12)
        a_opt = _quick_optimize(a_perturbed, opt_deadline, min_time_remaining=3)
        sc_opt = _score(a_opt)

        if sc_opt < best_sc - 1e-12:
            best_sc = sc_opt
            best_a = a_opt.copy()
            current_a = a_opt.copy()
            print(f"    ILS NEW BEST: {best_sc:.10f} ({kind}, sigma={sigma})")
        elif sc_opt < current_sc - 1e-12:
            current_a = a_opt.copy()

        attempt += 1

    return best_a, best_sc


def _resample(a, new_n):
    old_n = len(a)
    if old_n == new_n:
        return a.copy()
    x_old = np.linspace(0, 1, old_n)
    x_new = np.linspace(0, 1, new_n)
    a_new = np.interp(x_new, x_old, a)
    a_new = np.maximum(a_new, 0.0)
    s = a_new.sum()
    if s > 1e-15:
        a_new = a_new / s
    return a_new


def _lp_direction(a, M, max_iter=200):
    """
    Approximate the LP direction: find g >= 0 maximizing sum(g)
    subject to (a*g)[k] <= M for all k.
    Uses projected subgradient method as an approximation.
    """
    n = len(a)
    g = np.ones(n) / n
    best_g = g.copy()
    best_sum = g.sum()

    for it in range(max_iter):
        # Check constraints
        ag = _full_convolve(a, g)
        violation = ag - M
        if np.max(violation) > 1e-12:
            # Scale down
            scale = M / max(np.max(ag), 1e-15)
            g = g * scale
        else:
            # Try to increase g where it doesn't violate constraints
            # Gradient of objective is 1, so increase all equally
            # but where constraints are tight, we can't increase
            tight = ag >= M * 0.99
            # Increase g where not tight
            can_increase = ~tight
            if can_increase.sum() > 0:
                g[can_increase] += 0.01 / n
            else:
                # All tight, try redistributing
                # Decrease g where a is small (less impact on constraints)
                a_sorted_idx = np.argsort(a)[:n // 4]
                g[a_sorted_idx] *= 0.95
                g = _normalize(g)
                continue

        g = np.maximum(g, 0)
        s = g.sum()
        if s > best_sum:
            best_sum = s
            best_g = g.copy()

    return best_g
