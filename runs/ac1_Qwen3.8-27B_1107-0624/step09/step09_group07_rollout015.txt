def _next_pow2(n):
    k = 1
    while k < n:
        k <<= 1
    return max(2, k)

    out_n = n + m - 1
    N = _next_pow2(out_n)
    fa = np.fft.rfft(a, N)
    fb = np.fft.rfft(b, N)
    r = np.fft.irfft(fa * fb, N)[:out_n]
    return r

    if s < 1e-15:
        return np.inf
    c = _full_convolve(a, a)
    return float(2.0 * n * c.max() / (s * s))

For example: a = [0.1, 0.1, 0.1, ..., 0.1, 0.7] (n elements, last one is 0.7, rest are 0.1, normalized).
c[n-1] = 0.1*0.7 + 0.1*0.1*(n-2) + 0.7*0.1 = 0.07 + 0.01*(n-2) + 0.07
For n = 100: c[n-1] = 0.14 + 0.98 = 1.12? No wait, that doesn't seem right.

Let me redo: a = [0.1, 0.1, ..., 0.1, 0.7] with n-1 elements of 0.1 and one element of 0.7.
Sum = (n-1)*0.1 + 0.7 = 0.1n - 0.1 + 0.7 = 0.1n + 0.6.

For normalization, let's say (n-1)*x + y = 1 where y is the last element.

c[n-1] = x*y + x*x*(n-2) + y*x = 2*x*y + x^2*(n-2)

With (n-1)*x + y = 1: y = 1 - (n-1)*x.

c[n-1] = 2*x*(1-(n-1)*x) + x^2*(n-2) = 2x - 2(n-1)x^2 + (n-2)x^2 = 2x - (2n-2-n+2)x^2 = 2x - n*x^2.

sum(a^2) = (n-1)*x^2 + (1-(n-1)*x)^2 = (n-1)x^2 + 1 - 2(n-1)x + (n-1)^2*x^2
= 1 - 2(n-1)x + (n-1)*x^2*(1 + n-1) = 1 - 2(n-1)x + n(n-1)*x^2

For x = 1/n (uniform): c[n-1] = 2/n - 1/n = 1/n. sum(a^2) = 1/n. Same (symmetric).

For x = 0.01, n = 100: y = 1 - 99*0.01 = 0.01. So it's uniform! Let me pick x = 0.005, n = 100.
y = 1 - 99*0.005 = 1 - 0.495 = 0.505.
c[n-1] = 2*0.005 - 100*0.005^2 = 0.01 - 0.0025 = 0.0075.
sum(a^2) = 99*0.005^2 + 0.505^2 = 99*0.000025 + 0.255 = 0.002475 + 0.255 = 0.2575.

So c[n-1] = 0.0075 << sum(a^2) = 0.2575. The center is much smaller than the energy!

Wait, a has n elements: a[0]=x, a[1]=x, ..., a[n-2]=x, a[n-1]=y.

= a[0]*a[n-2] + a[1]*a[n-3] + ... + a[n-2]*a[0]
= x*x + x*x + ... + x*x (n-1 terms, each = x^2)
= (n-1)*x^2

For n=100, x=0.005: c[n-2] = 99*0.000025 = 0.002475. Still small.

c[n-1] = 0.0075 (computed above).
c[n] = sum_i a[i]*a[n-i] = a[0]*a[n] + ... but a[n] doesn't exist. 
c[n] = sum_{i=1}^{n-1} a[i]*a[n-i] = a[1]*a[n-1] + a[2]*a[n-2] + ... + a[n-1]*a[1]
= x*y + x*x + ... + y*x
= x*y + (n-3)*x^2 + y*x
= 2*x*y + (n-3)*x^2
= 2*0.005*0.505 + 97*0.000025
= 0.00505 + 0.002425
= 0.007475

So c[n-1] ≈ c[n] ≈ 0.0075. The max is around 0.0075.

Score = 2*100*0.0075/1 = 1.5! 

So a sequence that's mostly small with one large element at the end gives a score of about 1.5!

This is the key insight: **a highly asymmetric sequence with one dominant term at the edge gives a score close to 1.5.**

Let me verify: if a = [0, 0, ..., 0, 1] (all mass at the last position), then:

So we can't concentrate all mass at one point. We need a balance.

What about c[2n-2] = a[n-1]^2 = y^2?
