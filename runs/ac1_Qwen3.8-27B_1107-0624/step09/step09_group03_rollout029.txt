Let me think more carefully about the peak shaving approach.

Given current a with sum S, and peaks at positions k_1, ..., k_m in a*a with values v_1, ..., v_m (all close to max), we want to find a_new such that:
- sum(a_new) = S
- a_new >= 0
- (a_new * a_new)[k_i] <= v_target for all i

A linearized version: (a_new * a_new)[k] ≈ (a*a)[k] + 2 * (corr direction) . (a_new - a)

Where the "corr direction" for lag k is: d_i = a[k-i] (with appropriate bounds).

So the constraint becomes: 2 * sum_i d_i * (a_new[i] - a[i]) <= v_target - (a*a)[k]

This is a linear constraint! So the problem becomes:
min ||a_new - a||^2
s.t. 2 * D @ a_new <= v_target - (a*a)[k] + 2 * D @ a (for each peak k)
     sum(a_new) = S
     a_new >= 0

Where D is the matrix with rows being the "correlation directions" for each peak.

This is a quadratic program with linear constraints, solvable by standard methods.

To reduce (a*a)[k*], we go in the direction -grad. But we need to maintain sum(a) = S, so we use the "tangent" gradient: grad_t = grad - mean
