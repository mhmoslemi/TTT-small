Actually, let me think about a simpler improvement: **direct optimization of the weights w**.

At any point, given a and the active set S (peaks near the max), the "effective" objective is f_w(a) = sum_{k in S} w[k]*c[k]. The gradient is g = sum w[k]*grad_k(a). At the optimum, g should be constant (on the support).

So we can have an outer loop that adjusts w to make g as constant as possible, and an inner loop that adjusts a to reduce f_w(a).

This is like a "dual ascent" method.

Let me code this up:

```
Outer loop:
  1. Compute c = conv(a,a), find active set S
  2. For each k in S, compute grad_k(a)
  3. Find w >= 0, sum(w) = 1, that minimizes the variance of g_w = sum w[k]*grad_k(a) on the support
     (This is a convex QP or can be done with gradient descent on w)
  4. With fixed w, do several steps of projected gradient / Newton on a to minimize f_w(a)
  5. Update active set, repeat
```

The key insight is that by optimizing w, we're finding the "correct" combination of active peaks that defines the true objective at the optimum.

For step 3, the variance of g_w on the support is:
Var(g_w) = mean(g_w^2) - mean(g_w)^2 (on the support)

This is a quadratic in w: w^T A w - (w^T b)^2 / |S| where A and b are computed from the gradients.

Actually, it's simpler: we want g_w to be as constant as possible. This means we want to minimize ||g_w - mean(g_w)||^2. This is equivalent to maximizing the "alignment" of g_w with the all-ones vector.

Let me define: for each k in S, let v_k = grad_k(a) - mean(grad_k(a)) (the centered gradient on the support). Then g_w - mean(g_w) = sum w[k]*v_k. We want to minimize ||sum w[k]*v_k||^2.

This is: minimize w^T (sum_k sum_l v_k v_l^T) w = minimize w^T G w where G[k,l] = v_k · v_l.

Subject to w >= 0, sum w = 1.

This is a QP! We can solve it with CVXOPT or scipy.

For |S| = maybe 10-50 active peaks, this QP is tiny and can be solved quickly.

Then with the optimal w, we do gradient descent on a.

This is a much more principled approach than the previous "top-K with equal weights" method!

Let me also think about the Newton step. With the optimal w, the Hessian of f_w(a) is:
H = sum_k w[k] * H_k where (H_k)[i,j] = 2*1[i+j=k]

As we discussed, H is a Hankel matrix: H[i,j] = 2*w[i+j] (for i+j < 2n-1, with appropriate boundary handling).

We can compute H*v in O(n log n) using FFT, and use CG to solve H*delta = -g in about 20-50 iterations. Each CG iteration is O(n log n). So a Newton step costs about 50 * n log n ≈ 50 * 16384 * 14 ≈ 11 million operations. That's fast!

Actually, for the Newton step to be a descent direction, we need g^T * H^{-1} * g > 0 (i.e., H PD in the direction of g). If H is indefinite, we can project g onto the "positive" subspace of H.

A simpler approach: use H + sigma*I where sigma is chosen so that H + sigma*I is PD. We can estimate sigma from the smallest eigenvalue (using a few Lanczos iterations) or just use a heuristic.
