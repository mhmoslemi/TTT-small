**Improved KKT Newton Details:**

The KKT system (for a given active set S) is:
`H * lambda = g` where H is the |S| x |S| matrix with `H[k,k'] = sum_i (delta_{i+k, i'+k'} ... )`

Actually, let me re-derive. We want to solve:
`minimize max_{k in S} c[k]` subject to `sum(a) = 1, a >= 0`

At the optimum (interior, a > 0), the KKT conditions are:
`sum_{k in S} lambda_k * grad c[k] = mu * 1`
`c[k] = c_max` for k in S
`lambda_k >= 0`

The gradient of `c[k]` with respect to `a` is: `(grad c[k])[j] = a[j+k] + a[j-k]` (with out-of-range = 0, and factor of 2 for k=0).

So the condition is: `sum_{k in S} lambda_k * (a shifted by k + a shifted by -k) = mu * 1`

This is a linear system in `(lambda, mu)` where the "matrix" is the Hankel matrix (or a block of it).

The Newton step is: given the current `a`, solve the KKT system to find the direction that would make `c[k]` equal for all k in S. Then take a step in that direction.

def _next_pow2(n):
    k = 1
    while k < n:
        k <<= 1
    return max(2, k)


def _full_convolve(a, b):
    n, m = len(a), len(b)
    out_n = n + m - 1
    N = _next_pow2(out_n)
    fa = np.fft.rfft(a, N)
    fb = np.fft.rfft(b, N)
    r = np.fft.irfft(fa * fb, N)[:out_n]
    return r

    n = len(a)
    s = float(a.sum())
    if s < 1e-15:
        return np.inf
    c = _full_convolve(a, a)
    return float(2.0 * n * c.max() / (s * s))

    """Conjugate gradient solver for the Hankel system H x = rhs."""
    x = np.zeros(n)

    rs0 = rs
    if rs0 < 1e-30:

            break
        alpha = rs / pHp
        if not np.isfinite(alpha):
            break
        x = x + alpha * p
        r_new = r - alpha * Hp
        rs_new = float(r_new @ r_new)
        if not np.isfinite(rs_new):
            break
        x = x  # already updated
        r = r_new
        beta = rs_new / rs
        p = r + beta * p
        rs = rs_new
        if rs < tol * tol * rs0:
            break
        # Anti-stalling

            rs = float(r @ r)
    return x
