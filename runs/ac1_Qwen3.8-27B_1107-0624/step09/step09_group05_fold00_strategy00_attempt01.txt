OLS is particularly suited for identifying important components in a system by iteratively selecting the most significant basis vectors.

1. The problem involves optimizing a step function with specific properties (non-negative coefficients with upper bound 1000).

The selection of "important" peaks (components) is guided by the OLS algorithm, where each new component is chosen to reduce the residual spectral norm. The OLS algorithm works by:
- **Iterative Refinement**: Start with a set of basis vectors and iteratively solve least-squares problems to select the "most important" component.
- **Parametrization**: Use a basis of a given length (initially 256) with a uniform initial distribution `[MakeProfile(256, "uniform")]`.
- **Orthogonalization**: At each step, select a new component orthogonal to the existing Q basis, meaning it minimizes the residual structure in the direction of the selected index or bin, not the natural peak, allowing for a more balanced spectral response.

The process is:

1. **Initialize Basis Vectors**: Start with `n_basis` uniformly distributed unit-length steps.
2. **Orthogonalize**: Repeatedly find a new column vector that is orthogonal to the existing ones, reducing the residual error via QR decomposition.
3. **Refine**: At each step, update the candidate to better match the target peak structure, ensuring non-negative coefficients and no exceedance of the upper bound.

```python
        bin_index_low = max(0, int(bin_start * (length + 1)))
        bin_index_high = min(length, int(bin_end * (length + 1)))
        bins.append((bin_index_low, bin_index_high))
    return bins

def find_orthogonal_component(Q, a, max_len_nf):
    """Find an orthogonal component to the existing Q vectors using QR."""
    # Project a onto the existing Q space
    Q = Q[0:max_len_nf, :]  # Enforce finite precision projection
    proj = a @ Q  # Project candidate onto Q
    residual = a - proj  # Compute residual
    
    if np.linalg.norm(residual) < 1e-8:
        # Candidate already fits within the basis
        return None
    
    # Let's try to select the new most important bin
    best_gain = -np.inf
    best_bin_center = None
    best_k = None
    
    # Try all generated bins
    for bin_start, bin_end in bins:
        # Get the segment of residual that corresponds to [i, j]
        seg = residual[int(bin_start):int(bin_end) + 1] if bin_start < bin_end else residual
        
        # Compute projection norm and related error for this segment
        seg_gain = -np.linalg.norm(seg)**2 * (len(seg) + 1)  # Example gain formula, in sample context
        if seg_gain > best_gain:
            best_gain = seg_gain
            best_bin_center = bin_center
        
    return np.array(best_bin_center)  # Return the new candidate component

# --- Main Algorithm ---

def propose_candidate_main():
    """Main propose function using OLS-inspired refinement."""
    global height_sequence_1  # We access the provided parent candidate
    
    # If parent is available, extract existing coefficients (clipped to [0,1000])
    if 'height_sequence_1' in globals():
        parent_candidate = height_sequence_1.copy()
        # Defensive clipping and normalization (as the evaluator does)
        parent_candidate = np.clip(parent_candidate, 0, 1000)
        parent_candidate = parent_candidate / np.sum(parent_candidate)  # Optionally normalize if needed
    
    # Strategy:
    # 1. Start with a base profile of 256 steps, all set to 1.
    base_length = 256
    candidate = np.ones(base_length, dtype=float) / np.sqrt(2 * base_length)
    
    # 2. Enforce non-negative and within bounds:
    candidate = np.clip(candidate, 0, 1000)
    n = len(candidate)
    sum_val = np.sum(candidate)
    normalized = candidate.copy() / sum_val
    objective_val = evaluate_sequence(normalized)  # This returns a float, we need to keep track of low values
    
    # 3. Instead of using a fixed surface like the given program, we adapt by using orthogonalization:
    Q = np.identity(n)  # Initialize Q with the identity matrix for full basis
    nf_used = int(np.ceil(n/3))  # For example, we'll use only 1/3 the length of the candidate to keep nf manageable
    
    # Complexity: We'll only compute and use up to 900 coefficients to avoid being too slow.
    max_nf = 900
    
    # Build basis iteratively up to max_nf
    basis_components = []
    candidate_history = [normalized]
    best_obj = objective_val
    
    # Important bin centers (auditory targets):
    bins = generate_important_bins(max_nf)  # Generate bin pairs for the unconstrained minimization
    
    # For each n from 1 up to max_nf, find the next best component orthogonal to the previous ones
    for i in range(max_nf):
        if i == 0:
            # Select initial column vector (e.g., a uniform distribution over [0, base_length])
            bin_start, bin_end = bins[i]
            kernel = np.ones((2*base_length+1), dtype=float) / base_length  # Example kernel, could be other
            candidate_new = kernel
            candidate_new = np.clip(candidate_new, 0, 1000)
            candidate_new = candidate_new / np.sum(candidate_new)
            # This candidate_new will be added to Q and The final candidate is an optimization of the selected columns
        
        else:
            # Use orthogonalization procedure to find the next candidate
            bin_center = bins[i]
            candidate_adjusted = find_orthogonal_component(Q, candidate, bin_center)
            candidate_adjusted = np.clip(candidate_adjusted, 0, 1000)
            
            # Project to get a balanced candidate
            candidate_orthogonal = candidate_adjusted / np.sum(candidate_adjusted)
            candidate_history.append(candidate_orthogonal)
            
            # After finding a candidate, use least-angle regression (LARS) to refine (perturb selected indices)
            selector = [1 if candidate_history[i][j] != candidate_history[i-1][j] else 0 for j in range(n)]
            candidate_raised = candidate.copy() * selector + candidate_adjusted * (1-selector)
            candidate_raised = np.clip(candidate_raised, 0, 1000) / np.sum(candidate_raised)
            
            # Check if this candidate improves the objective
            obj_val_check = np.infty
            for j in range(i):
                candidate_j = candidate_history[j].copy()
                if candidate_j.size == candidate.size and (candidate_j - candidate_orthogonal).sum() < 1e-8:
                    obj_val_check = best_obj
    
            if obj_val_check > best_obj + 1e-8 * (max_nf - i):
                # We keep the best candidate found so far
                candidate = candidate_orthogonal.copy()
                best_obj = obj_val_check
    
    # Step 4: The final candidate is the one with the minimal objective (stored as best_obj)
    return candidate
```

### Search Choices and Useful Variations
- **Base Length**: We start with 256 segments, which is manageable and within the computational limits.
- **Orthogonalization Frequency**: We compute orthogonal components once for every 3 to 5 candidate lengths to balance time and diversity.
- **Kernel Selection**: The initial kernel may be a uniform distribution or a raised cosine for auditory suitability.

### Compute Budget and Robustness
- **Time Constraints**: The algorithm is designed for up to 1800 seconds but breaks the search into manageable steps.
- **Fallback**: If the main optimization fails to find a better candidate, we use the initial uniformly distributed segment as a fallback.

### Validation and Return Contract
- **Defensive Checks**: The candidate is always clipped to [0,1000] and normalized to have a small average (>=0.01).
- **Objective Calculation**: The returned candidate must have an objective as calculated by the provided function.
- **Quality Assurance**: The final candidate is chosen such that its objective is minimal, ensuring the best improvement.
