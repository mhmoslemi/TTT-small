   - Try multiple sigma values: 0.01, 0.05, 0.1, 0.2 (relative to a.max())

2. **Coordinate swapping**: Pick two random coordinates and swap their values.
   - This preserves the sum and the set of values, just changes positions.
   - Can change the convolution pattern significantly.

3. **Block rotation**: Take a contiguous block of coordinates and move it to a different position.
   - This preserves the block structure but changes the phase.
   - Since the score is invariant under shifts, this might not help much for single blocks.
   - But for multiple blocks, it can change the relative phases.

4. **Symmetry breaking**: If the solution is approximately symmetric, add an anti-symmetric perturbation.
   - `a_pert[j] = a[j] + eps * (a[j] - a[n-1-j])`
   - This breaks the symmetry while preserving the sum.

5. **Coordinate zeroing**: Set some random coordinates to zero and redistribute their mass.
   - This can change the support of the sequence.

The objective is `2n * max_k (a*a)[k] / (sum a)^2`.

With `sum(a) = 1`, this is `2n * max_k (a*a)[k]`.

Now, `(a*a)[k] = sum_{j} a[j] * a[k-j]` where the sum is over valid j.

Note that `(a*a)[n-1] = sum_{j=0}^{n-1} a[j] * a[n-1-j]`. If `a` is symmetric (a[j] = a[n-1-j]), this becomes `sum_j a[j]^2`, which is the L2 norm squared.

For a general (non-symmetric) `a`, `(a*a)[n-1]` is the "cross-correlation" of `a` with its reverse.

The maximum of the convolution can be at any position k, not just n-1. For a symmetric sequence, by the properties of convolution, the peak is at k=n-1 (the center). For non-symmetric sequences, the peak can be elsewhere.

def _next_pow2(n):
    k = 1
    while k < n:
        k <<= 1
    return max(2, k)


def _full_convolve(a, b):
    n, m = len(a), len(b)
    out_n = n + m - 1
    N = _next_pow2(out_n)
    fa = np.fft.rfft(a, N)
    fb = np.fft.rfft(b, N)
    r = np.fft.irfft(fa * fb, N)[:out_n]
    return r


def _score(a):
    n = len(a)
    s = float(a.sum())
    if s < 1e-15:
        return np.inf
    c = _full_convolve(a, a)
    return float(2.0 * n * c.max() / (s * s))


def _softmax(z):
    z = z - np.max(z)
    e = np.exp(np.clip(z, -700, 700))
    s = e.sum()
    if s < 1e-300:
        return np.ones_like(z) / len(z)
    return e / s


def _soft_max_value(c, beta):
    c_max = float(c.max())
    if beta < 1e-30:
        return c_max
    shifted = (c - c_max) / beta
    e = np.exp(np.clip(shifted, -700, 0))
    s = e.sum()
    if s < 1e-300:
        return c_max
    return c_max + beta * np.log(s)


def _soft_max_weights(c, beta):
    c_max = float(c.max())
    shifted = (c - c_max) / beta
    e = np.exp(np.clip(shifted, -700, 0))
    s = e.sum()
    if s < 1e-300:
        w = np.zeros_like(c)
        w[int(np.argmax(c))] = 1.0
        return w
    return e / s

    w = _soft_max_weights(c, beta)
    a_rev = a[::-1]
    wc = _full_convolve(w, a_rev)
    grad = 2.0 * wc[n - 1:2 * n - 1]
    return grad


def _smoobj(z, beta, n):
    a = _softmax(z)
    c = _full_convolve(a, a)
    return 2.0 * n * _soft_max_value(c, beta)


def _smograd(z, beta, n):
    a = _softmax(z)
    grad_a = _grad_soft_structured(a, beta, n)
    W = float(np.dot(grad_a, a))
    return a * (grad_a - W)

    def __call__(self, z):

        return _smograd(z, self.beta, self.n)
