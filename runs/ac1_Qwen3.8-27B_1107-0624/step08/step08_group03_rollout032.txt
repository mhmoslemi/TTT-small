The QP is: minimize `t` subject to:
- `f_k = t` for `k in S` (consistency constraints)
- `f_k <= t` for `k not in S` (maintained constraints)
- `sum_j a_j = 1`
- `a_j = 0` for `j in N`
- `a_j >= 0` for `j not in N`

The Lagrangian for the "equality-constrained" subproblem (ignoring the inequality constraints for `k not in S` and `j not in N`):

`L = t + sum_{k∈S} λ_k (f_k - t) - μ(sum a - 1)`

KKT:
- `∂L/∂t = 1 - sum_{k∈S} λ_k = 0`
- `∂L/∂a_j = sum_{k∈S} λ_k * 2 * a_{k-j} - μ = 0` (for `j not in N`)

From the second equation: `sum_{k∈S} λ_k * a_{k-j} = μ/2` for all `j not in N`.

This means: the "convolution" of the weight vector `λ` (restricted to active peaks) with `a` must be constant on the support of `a`.

In the frequency domain: `DFT(λ_S) * DFT(a)` has DC component `μ/2 * |supp(a)|` and all other components are 0 (on the support).

This is a strong constraint! It means that `a` must be such that its DFT, when multiplied by `DFT(λ_S)`, gives a constant on the support.

If the support is the full range (all `a_j > 0`), then `DFT(a) * DFT(λ_S)` must be a delta (only DC). This means `DFT(a) = c / DFT(λ_S)` for some constant `c`, i.e., `a` is the IDFT of `1/DFT(λ_S)`.

This gives us a direct formula for `a` in terms of `λ`! We can then use the constraints `f_k = t` for `k in S` to determine `λ`.

But this is still nonlinear because `f_k = a^T D_k a` is quadratic in `a`, and `a` depends on `λ`.

However, we can solve this iteratively:
1. Start with an initial `λ`
2. Compute `a = IDFT(1/DFT(λ_S))` (normalized, projected to non-negative)
3. Check which constraints are active
4. Update `λ` to satisfy the active constraints
5. Repeat

This is essentially a fixed-point iteration on the KKT conditions.

Let me also think about the **HIO (Hybrid Input-Output) / spectral shaping** approach:

1. Start with `a` (non-negative, sum = 1)
2. Zero-pad to length `M = 2n` (or next power of 2)
3. Compute `A = FFT(a_padded)`
4. Compute target spectrum: `|A_target| = constant` (or some desired shape)
5. Form `A_new = |A_target| * A / |A|` (replace magnitude, keep phase)
6. `a_new = IDFT(A_new)[0:n]`
7. Project: `a_new = max(a_new, 0)`, normalize
8. Repeat

The "target spectrum" can be chosen to be:
- Constant (flat)
- Raised cosine
- Some other shape

The key parameter is how aggressive the replacement is. If we replace with a pure constant, we might lose too much information. A common approach is to use a "shrinkage": `|A_new| = (1-ρ)|A| + ρ * |A_target|` for some `ρ ∈ [0,1]`.

import time

    while k < n:
        k <<= 1
    return max(2, k)

        b = a
    n, m = len(a), len(b)
    out_n = n + m - 1
    N = _next_pow2(out_n)
    fa = np.fft.rfft(a, N)
    fb = np.fft.rfft(b, N)

    s = float(a.sum())

    """Euclidean projection onto the probability simplex."""
    n = len(v)
    if n == 0:
        return v
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1
    rho = np.where(u * np.arange(1, n+1) > cssv)[0][-1]
    theta = cssv[rho] / (rho + 1.0)
    return np.maximum(v - theta, 0)

def _hio_spectral(a_init, deadline, max_iters=2000, rho=0.5, label=""):
    """Hybrid Input-Output / spectral shaping algorithm."""
    n = len(a_init)
    a = np.maximum(a_init, 0)
    a = a / a.sum()
    best_a = a.copy()
    best_sc = _score(a)
    
    M = _next_pow2(2 * n - 1)
    
    for it in range(max_iters):
        if time.monotonic() > deadline:
            break
        
        # Forward: time -> freq
        a_padded = np.zeros(M)
        a_padded[:n] = a
        A = np.fft.fft(a_padded)
        
        # Target: flat spectrum (or raised cosine)
        mag = np.abs(A)
        phase = np.angle(A)
        target_mag = np.ones(M)
        target_mag[0] = mag[0]  # keep DC
        # Actually, for our problem, we want the SPECTRAL DENSITY |A|^2 to be flat
        # which means |A| should be constant
        # But |A| = |sum a_j e^{-iωj}| and sum a_j = 1, so |A(0)| = 1
        # So the flat target for |A| is 1/sqrt(M) * something
        # Let's use: target |A| = mean(|A|) for non-DC bins
        target_mag[1:] = np.mean(mag[1:])
        
        # Shrinkage
        new_mag = (1 - rho) * mag + rho * target_mag
        A_new = new_mag * np.exp(1j * phase)
        
        # Inverse: freq -> time
        a_new = np.fft.ifft(A_new).real[:n]
        a_new = np.maximum(a_new, 0)
        s = a_new.sum()
        if s < 1e-15:
            break
        a_new = a_new / s
        
        sc = _score(a_new)
        if sc < best_sc - 1e-14:
            best_sc = sc
            best_a = a_new.copy
        
        a = a_new
    
    return best_a, best_sc

def _active_set_qp(a_init, deadline, max_iter=200, tol_active=0.001):
    """Active-set method based on KKT conditions."""
    n = len(a_init)
    a = np.maximum(a_init, 0)
    s = a.sum()
    if s < 1e-15:
        return a, _score(a)
    a = a / s
    best_a = a.copy()
    best_sc = _score(a)
    
    for it in range(max_iter):
        if time.monotonic() > deadline:
            break
        
        c = _full_convolve(a, a)
        c_max = float(c.max())
        tol = tol_active * c_max
        active = c >= (c_max - tol)
        if active.sum() == 0:
            active[int(np.argmax(c))] = True
        n_active = int(active.sum())
        
        # Solve for a such that:
        # (1) c_k = c_max for k in active (approximately)
        # (2) sum a = 1
        # (3) a >= 0
        # Using the gradient condition: sum_{k in active} w_k * a[k-j] = const for all j
        
        # The gradient of the objective w.r.t. a[j] (for active set S):
        # g[j] = 2 * sum_{k in S} (1/|S|) * a[k-j]
        # We want g[j] = constant (the KKT condition)
        # This means: conv(a, w_S)[j] = const for all j
        # In frequency: A(ω) * W_S(ω) = DC only
        # So: A(ω) = C / W_S(ω) for ω ≠ 0, A(0) = sum(a) = 1
        
        w = np.zeros(2*n-1)
        w[active] = 1.0 / n_active
        
        M = _next_pow2(2*n-1)
        W = np.fft.rfft(w, M)
        A_freq = np.fft.rfft(a, M)
        
        # Target: A_target(ω) = 1 / W(ω) (up to a constant)
        # But we need W(ω) to be non-zero
        safe_W = np.where(np.abs(W) > 1e-10, W, 1e-10 * np.exp(1j*np.angle(W+1e-10)))
        A_target = 1.0 / safe_W
        A_target[0] = 1.0  # DC = sum(a) = 1
        
        # Blended update
        blend = 0.3 + 0.7 * (it / max_iter)  # increase blend over time
        A_new = (1 - blend) * A_freq + blend * A_target * (A_freq / np.abs(A_freq + 1e-10)).real  # hmm this is getting complicated
        
        # Simpler: just use the KKT condition directly
        # Compute the "deficit": how far g[j] is from being constant
        w_padded = np.zeros(M)
        w_padded[:2*n-1] = w
        W_full = np.fft.fft(w_padded)
        
        a_padded = np.zeros(M)
        a_padded[:n] = a
        A_full = np.fft.fft(a_padded)
        
        # Desired: A_full * W_full = C * delta (only DC)
        # So: A_desired = C * delta / W_full (for non-DC)
        #     A_desired[0] = 1 (DC)
        C = 1.0 / n_active  # normalization
        
        A_des = np.zeros(M, dtype=complex)
        A_des[0] = 1.0
        for k in range(1, M):
            if abs(W_full[k]) > 1e-10:
                A_des[k] = C / W_full[k]
            else:
                A_des[k] = A_full[k]  # keep original
        
        # Blend
        alpha = 0.2 + 0.6 * (it / max_iter)
        A_blend = (1 - alpha) * A_full + alpha * A_des
        
        a_try = np.fft.ifft(A_blend).real[:n]
        a_try = np.maximum(a_try, 0)
        s_try = a_try.sum()
        if s_try < 1e-15:
            break
        a_try = a_try / s_try
        
        sc_try = _score(a_try)
        if sc_try < best_sc - 1e-14:
            a = a_try
            best_sc = sc_try
            best_a = a.copy()
        else:
            # Try smaller step
            alpha_half = alpha * 0.5
            A_blend2 = (1 - alpha_half) * A_full + alpha_half * A_des
            a_try2 = np.fft.ifft(A_blend2).real[:n]
            a_try2 = np.maximum(a_try2, 0)
            s_try2 = a_try2.sum()
            if s_try2 > 1e-15:
                a_try2 = a_try2 / s_try2
                sc_try2 = _score(a_try2)
                if sc_try2 < best_sc - 1e-14:
                    a = a_try2
                    best_sc = sc_try2
                    best_a = a.copy()
    
    return best_a, best_sc

Let me also add a **coordinate descent** method that's very simple but can be effective:
- Cycle through coordinates
- For each coordinate, find the optimal value (given all others fixed)
- This is exact for each coordinate step

For coordinate `j`, the objective is:
`score = 2n * max_k c_k / s^2`

where `c_k = sum_i a_i * a_{k-i}`. The terms involving `a_j` are:
- `c_{k} += a_j * a_{k-j}` for each k (when `k-j` is in range)

So `c_k = c_k_base + a_j * (a_{k-j} + a_{k-j})` = `c_k_base + 2*a_j*a_{k-j}` (if `k ≠ 2j`)
or `c_k = c_k_base + a_j^2` (if `k = 2j`)

This makes the coordinate update a 1D optimization problem: minimize `max_k (c_k_base + a_j * b_k)` where `b_k = 2*a_{k-j}` (or `b_k = a_j` for `k=2j`).

This is a "minimax" problem in 1D, which can be solved by binary search on the level `t`: find the smallest `t` such that there exists `a_j >= 0` with `c_k_base + a_j * b_k <= t` for all `k`.

The constraint is: `a_j * b_k <= t - c_k_base` for all `k` with `b_k > 0`.
So: `a_j <= (t - c_k_base) / b_k` for all `k` with `b_k > 0`.
And: `a_j >= 0`.

The minimum `t` is achieved when the tightest constraint is active. We can binary search on `t`.

But this is `O(n)` per coordinate and `O(n)` coordinates, so `O(n^2)` per sweep. For `n = 16384`, that's about `2.7 * 10^8` operations per sweep, which might be too slow.

"""
Multi-strategy optimizer for min 2*n*max(conv(a,a))/sum(a)^2.
Combines Nesterov mirror descent, HIO spectral shaping,
refined active-set methods, and multi-scale optimization.
"""
import numpy as np
import time

def _next_pow2(n):
    k = 1
    while k < n:
        k <<= 1
    return max(2, k)

def _full_convolve(a, b=None):
    if b is None:
        b = a
    n, m = len(a), len(b)
    out_n = n + m - 1
    N = _next_pow2(out_n)
    fa = np.fft.rfft(a, N)
    fb = np.fft.rfft(b, N)
    return np.fft.irfft(fa * fb, N)[:out_n]

def _score(a):
    n = len(a)
    s = float(a.sum())
    if s < 1e-15:
        return np.inf
    c = _full_convolve(a, a)
    return float(2.0 * n * c.max() / (s * s))

def _softmax(z):
    z = z - np.max(z)
    e = np.exp(np.clip(z, -700, 700))
    s = e.sum()
    if s < 1e-300:
        return np.ones_like(z) / len(z)
    return e / s

def _make_smooth_random(n, rng, alpha=2.0):

    kernel /= kernel.sum()
    a = np.convolve(a, kernel, mode='same')

    n = len(a_init)

    a = a / a.sum()
    z = np.log(a)
    z = z - z.mean()
    z_prev = z.copy()
    best_a = a.copy()
    best_sc = _score(a)
    
    lr0 = 0.05 * lr_scale
    patience = 0
    best_pat_sc = best_sc
    
    for t in range(1, max_steps + 1):

            break
        
        a = _softmax(z)
        c = _full_convolve(a, a)
        c_max = float(c.max())
        
        # Adaptive temperature for soft active set
        # Start wide, narrow over time
        frac = min(1.0, t / 5000.0)
        if frac < 0.1:
            eps = c_max * 0.05

            eps = c_max * 0.02
        elif frac < 0.6:
            eps = c_max * 0.005
        else:
            eps = c_max * 0.001
