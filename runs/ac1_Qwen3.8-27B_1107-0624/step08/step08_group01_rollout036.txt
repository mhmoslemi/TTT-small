One thing I want to try that's different from the previous approach: **use a "dual" update where we explicitly track which peaks are active and try to make them all equal.**

The idea: at the optimum, the top few peaks should all be equal (by the KKT conditions, if the solution is in the interior). So we can:
1. Identify the top K peaks.
2. Compute the "deficit" of each peak relative to the max.
3. Use this deficit to construct a gradient that pushes the peaks toward equality.

This is like a "log barrier" or "entropy" approach: instead of just minimizing the max, we minimize max + epsilon * (variance of top-K peaks), which encourages flat peaks.

Let me implement this as a "peak variance regularizer" added to the LSE objective.

Actually, the LSE with small tau already does this (it's a smooth approximation to the max, and with small tau it concentrates on the top peak). To encourage flat peaks, we could use a "sum of top-K" instead of "max":

$\text{sum\_topK}(c) = \sum_{k \in \text{topK}} c_k$

This is a convex function (sum of the largest K elements) and its subgradient is 1 at the top-K positions and 0 elsewhere.

The advantage of using sum-of-topK instead of max is that it naturally encourages the top-K peaks to be flat (if one peak increases while another decreases, the sum stays the same, so the gradient pushes to equalize them).

Actually, the subgradient of sum-of-topK is just the indicator of the top-K set. So the gradient descent step would be:
- Compute $c = a * a$.
- Find the top-K positions.
- Gradient = $\sum_{k \in \text{topK}} \frac{\partial c_k}{\partial a} = \sum_{k \in \text{topK}} 2 a_{k-i}$.
- Take a projected gradient step.

This is simpler than LSE and might work better! Let me use this as the primary method.

For the "valid range" of the gradient: $\frac{\partial c_k}{\partial a_i} = 2 a_{k-i}$ (for $0 \leq k-i < n$). So:
$\text{grad}_i = 2 \sum_{k \in \text{topK}} a_{k-i} \cdot \mathbf{1}[0 \leq k-i < n]$

This can be computed as: for each $k$ in topK, add $2 \cdot a_{k-i}$ (for valid $i$) to grad. Using FFT:
$\text{grad}_i = 2 \cdot (\mathbf{1}_{\text{topK}} * a_{\text{rev}})_i$ (in the valid range).

Where $\mathbf{1}_{\text{topK}}$ is a vector with 1's at the top-K positions and 0's elsewhere.

This is exactly the same computation as before (with $w = \mathbf{1}_{\text{topK}} / K$ instead of the LSE weights). So the implementation is the same, just with a different $w$.

The advantage is that we don't need to tune the temperature $\tau$. We just need to choose $K$ (the number of peaks to consider).

**Algorithm: Top-K gradient descent**
1. Compute $c = a * a$.
2. Find the top-K positions.
3. $w_k = 1/K$ for $k$ in topK, 0 otherwise.
4. $\text{grad}_i = 2 \sum_k w_k a_{k-i}$ (valid range).
5. $a_{\text{new}} = \text{proj}_{\Delta}(a - \alpha \cdot \text{grad})$.
6. Adapt $\alpha$ (backtracking or fixed).

- $K=1$: equivalent to subgradient of the max. Can be noisy.
- $K$ large: more stable but less focused.
- $K$ adaptive: start with large K, decrease over time.

        return best_a

    c_sorted = np.sort(c_cur)[::-1]
    gap = c_sorted[0] - c_sorted[min(30, len(c_sorted) - 1)]
    if gap < c_max * 0.001:
        gap = c_max * 0.001
    base_beta = max(gap, c_max * 0.001)

    betas = base_beta * np.array(
        [1.0, 0.4, 0.15, 0.06, 0.025, 0.01, 0.005, 0.002,
         0.001, 0.0005, 0.0002, 0.0001, 0.00005, 0.00002, 0.00001]
    )

    z = np.log(np.maximum(a, 1e-30))
    z = z - z.mean()

    for beta in betas:
        if time.monotonic() + min_remaining > deadline:
            break
        remaining = deadline - min_remaining - time.monotonic()
        if remaining < 3.0:
            break

        scale = max(1.0, n / 4096.0)
        est_time = 0.003 * scale
        max_iter = min(3000, max(20, int(remaining / (est_time * 20))))

        def _obj(z_val):
            a_val = _softmax_fn(z_val)
            c_val = _full_convolve(a_val, a_val)
            cm = float(c_val.max())
            shifted = (c_val - cm) / beta
            e_val = np.exp(np.clip(shifted, -700, 0.0))
            S_val = e_val.sum()
            if S_val < 1e-300:
                return 2.0 * n * cm
            return 2.0 * n * (cm + beta * np.log(S_val))

        def _grad(z_val):
            a_val = _softmax_fn(z_val)
            c_val = _full_convolve(a_val, a_val)
            cm = float(c_val.max())
            shifted = (c_val - cm) / beta
            e_val = np.exp(np.clip(shifted, -700, 0.0))
            S_val = e_val.sum()
            if S_val < 1e-300:
                w_val = np.zeros_like(c_val)
                w_val[int(np.argmax(c_val))] = 1.0
            else:
                w_val = e_val / S_val
            a_rev = a_val[::-1]
            wc = _full_convolve(w_val, a_rev)
            h = wc[n - 1:2 * n - 1]
            return 4.0 * n * a_val * (h - float(np.dot(w_val, c_val)))

        try:
            result = minimize(
                _obj, z, jac=_grad, method='L-BFGS-B',
                options={'maxiter': max_iter, 'ftol': 1e-18,
                         'gtol': 1e-14, 'maxcor': 60, 'maxls': 40}
            )
            a_new = _softmax_fn(result.x)
            a_new = np.maximum(a_new, 0.0)
            s_new = a_new.sum()
            if s_new > 1e-15:
                a_new = a_new / s_new
                sc_new = _score(a_new)
                if sc_new < best_sc - 1e-15:
                    best_sc = sc_new
                    best_a = a_new.copy()
                    z = np.log(np.maximum(best_a, 1e-30))
                    z = z - z.mean()
        except Exception:
            pass

    return best_a


def _peak_flatten(a_init, deadline, n_iters=2000):
    """Fine peak flattening: iterative reduction of peak spread."""
    n = len(a_init)
    a = a_init.copy()
    s = float(a.sum())
    if s < 1e-15:
        return a_init, _score(a_init)
    a = a / s
    best_a = a.copy()
    best_sc = 2.0 * n * float(_full_convolve(a, a).max())

    alpha = 0.02
    for it in range(n_iters):
        if time.monotonic() > deadline:
            break
        c = _full_convolve(a, a)
        c_max = float(c.max())
        sc = 2.0 * n * c_max

        if sc < best_sc - 1e-14:
            best_sc = sc
            best_a = a.copy()

        # Focus on top peaks
        top_idx = np.argpartition(c, -20)[-20:]
        w = np.zeros(len(c))
        w[top_idx] = 1.0 / len(top_idx)

        a_rev = a[::-1]
        wc = _full_convolve(w, a_rev)
        h = wc[n - 1:2 * n - 1]
        grad = 2.0 * h

        gnorm = np.linalg.norm(grad)
        if gnorm < 1e-15:
            break

        a_try = a - (alpha / gnorm) * grad
        a_try = _proj_simplex(a_try, 1.0)
        c_try = _full_convolve(a_try, a_try)
        sc_try = 2.0 * n * float(c_try.max())

        if sc_try < sc:
            a = a_try
            alpha = min(0.05, alpha * 1.01)
        else:
            alpha *= 0.8
            if alpha < 1e-8:
                break

    return best_a, best_sc


def _resample(a, new_n):
    old_n = len(a)
    if old_n == new_n:
        return a.copy()
    x_old = np.linspace(0, 1, old_n)
    x_new = np.linspace(0, 1, new_n)
    a_new = np.interp(x_new, x_old, a)
    a_new = np.maximum(a_new, 0.0)
    s = a_new.sum()
    if s > 1e-15:
        a_new = a_new / s
    return a_new


def _perturb(a, sigma, rng):
    n = len(a)
    z = np.log(np.maximum(a, 1e-30))
    z = z + sigma * rng.standard_normal(n)
    z = z - z.mean()
    return _softmax_fn(z)


def propose_candidate(seed=42, budget_s=1800):
    """Main search function: multi-phase optimization with top-K gradient descent."""
    t0 = time.monotonic()
    deadline = t0 + budget_s - 12.0
    rng = np.random.default_rng(int(seed) % (2**63 - 1))

    # Load parent
    parent = None
    try:
        parent_raw = np.asarray(height_sequence_1, dtype=np.float64).ravel()
        if parent_raw.size > 0:
            parent_raw = np.clip(parent_raw, 0.0, 1000.0)
            s = float(parent_raw.sum())
            if s > 0.01:
                parent = parent_raw / s
    except Exception:
        pass

    if parent is not None:
        best_a = parent.copy()
        best_score = _score(best_a)
        n_parent = len(parent)
        print(f"Parent: n={n_parent}, score={best_score:.10f}")
    else:
        n_parent = 12288
        best_a = np.ones(n_parent) / n_parent
        best_score = _score(best_a)
        print(f"No parent, uniform n={n_parent}, score={best_score:.10f}")

    # === Phase 1: Top-K accelerated gradient descent (largest phase) ===
    print(f"\n[P1] Top-K accel GD (t={time.monotonic()-t0:.1f}s)")
    p1_deadline = min(deadline - 600.0, t0 + 900.0)
    a1, sc1 = _accel_topk(best_a, p1_deadline, top_k_start=80, top_k_end=2, n_phases=6)
    if sc1 < best_score:
        best_a = a1.copy()
        best_score = sc1
        print(f"  NEW BEST: {best_score:.10f} [topk_gd] t={time.monotonic()-t0:.1f}s")
    else:
        print(f"  No improvement: {sc1:.10f} vs {best_score:.10f}")

    # === Phase 2: LSE L-BFGS fine tuning ===
    print(f"\n[P2] LSE L-BFGS (t={time.monotonic()-t0:.1f}s)")
    p2_deadline = min(deadline - 400.0, t0 + 1200.0)
    a2 = _lse_lbfgs_phase(best_a, p2_deadline, min_remaining=20.0)
    sc2 = _score(a2)
    if sc2 < best_score:
        best_a = a2.copy()
        best_score = sc2
        print(f"  NEW BEST: {best_score:.10f} [lse_lbfgs] t={time.monotonic()-t0:.1f}s")
    else:
        print(f"  No improvement: {sc2:.10f} vs {best_score:.10f}")

    # === Phase 3: Peak flattening ===
    print(f"\n[P3] Peak flatten (t={time.monotonic()-t0:.1f}s)")
    p3_deadline = min(deadline - 300.0, t0 + 1400.0)
    a3, sc3 = _peak_flatten(best_a, p3_deadline, n_iters=5000)
    if sc3 < best_score:
        best_a = a3.copy()
        best_score = sc3
        print(f"  NEW BEST: {best_score:.10f} [peak_flat] t={time.monotonic()-t0:.1f}s")
    else:
        print(f"  No improvement: {sc3:.10f} vs {best_score:.10f}")

    # === Phase 4: Second top-K pass with smaller K ===
    print(f"\n[P4] Top-K fine (t={time.monotonic()-t0:.1f}s)")
    p4_deadline = min(deadline - 200.0, t0 + 1550.0)
    a4, sc4 = _accel_topk(best_a, p4_deadline, top_k_start=10, top_k_end=1, n_phases=4)
    if sc4 < best_score:
        best_a = a4.copy()
        best_score = sc4
        print(f"  NEW BEST: {best_score:.10f} [topk_fine] t={time.monotonic()-t0:.1f}s")
    else:
        print(f"  No improvement: {sc4:.10f} vs {best_score:.10f}")

    # === Phase 5: Multi-n exploration ===
    print(f"\n[P5] Multi-n (t={time.monotonic()-t0:.1f}s)")
    n_best = len(best_a)
    n_targets = [16384, 32768, 8192, 24576]
    for nt in n_targets:
        if time.monotonic() > deadline - 80.0:
            break
        if nt == n_best:
            continue
        a_r = _resample(best_a, nt)
        sc_r = _score(a_r)
        print(f"  n={nt}: resampled score={sc_r:.10f}")
        rem = deadline - time.monotonic() - 60.0
        if rem < 20:
            continue
        a_opt, sc_opt = _accel_topk(a_r, t0 + time.monotonic() - t0 + min(120, rem * 0.4),
                                     top_k_start=40, top_k_end=2, n_phases=3)
        if sc_opt < best_score:
            best_a = a_opt.copy()
            best_score = sc_opt
            n_best = nt
            print(f"  NEW BEST: {best_score:.10f} (n={nt}) [multin] t={time.monotonic()-t0:.1f}s")

    # === Phase 6: Diverse restarts ===
    print(f"\n[P6] Restarts (t={time.monotonic()-t0:.1f}s)")
    if time.monotonic() < deadline - 30.0:
        restarts = [
            _perturb(best_a, 0.01, rng),
            _perturb(best_a, 0.03, rng),
            _perturb(best_a, 0.05, rng),
        ]
        # Also try palindromic version
        pal = (best_a + best_a[::-1]) / 2.0
        pal = pal / pal.sum()
        restarts.append(pal)

        for i, a_r in enumerate(restarts):
            if time.monotonic() > deadline - 20.0:
                break
            rem = deadline - time.monotonic() - 15.0
            if rem < 10:
                break
            a_opt, sc_opt = _accel_topk(a_r, t0 + time.monotonic() - t0 + min(60, rem * 0.5),
                                         top_k_start=20, top_k_end=1, n_phases=2)
            if sc_opt < best_score:
                best_a = a_opt.copy()
                best_score = sc_opt
                print(f"  NEW BEST: {best_score:.10f} [restart_{i}] t={time.monotonic()-t0:.1f}s")

    # === Phase 7: Final peak flatten ===
    print(f"\n[P7] Final polish (t={time.monotonic()-t0:.1f}s)")
    if time.monotonic() < deadline - 2.0:
        a_fin, sc_fin = _peak_flatten(best_a, deadline - 1.0, n_iters=3000)
        if sc_fin < best_score:
            best_a = a_fin.copy()
            best_score = sc_fin
            print(f"  NEW BEST: {best_score:.10f} [final_flat]")

        # One more L-RFGS if time
        rem = deadline - 1.0 - time.monotonic()
        if rem > 10.0:
            a_fin2 = _lse_lbfgs_phase(best_a, deadline - 0.5, min_remaining=2.0)
            sc_fin2 = _score(a_fin2)
            if sc_fin2 < best_score:
                best_a = a_fin2.copy()
                best_score = sc_fin2
                print(f"  NEW BEST: {best_score:.10f} [final_lbfgs]")

    # Final validation
    print(f"\n{'='*60}")
    final = np.clip(best_a, 0.0, 1000.0)
    s = float(final.sum())
    if s < 0.01:
        final = np.ones(256) / 256.0
    sc_final = _score(final)
    print(f"FINAL: score={sc_final:.10f}, n={len(final)}, time={time.monotonic()-t0:.1f}s")
    return [float(x) for x in final]
