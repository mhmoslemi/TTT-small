6. **Key mathematical insight I missed**: The objective `max_k c[k]` where `c = a*a` (full convolution) can be written as:
`max_k sum_j a[j] * a[k-j]`

This is the maximum over k of the "reconvolution" of a with itself. In the frequency domain:
`c[k] = (1/2π) ∫ |A(f)|^2 * e^{ikf} df` (continuous)
or `c[k] = (1/N) sum_m |A[m]|^2 * e^{2πikm/N}` (discrete, with appropriate N)

So `max_k c[k]` is the maximum of the inverse Fourier transform of `|A|^2`. This is related to the "peak-to-average power ratio" (PAPR) of the sequence `|A|^2`.

We want to minimize the PAPR of `|A(f)|^2` by choosing `a` (and hence `A`). This is a well-known problem in radar and communications!

The "PAPR reduction" techniques from that literature might be useful:
- **Matrix Flooding Algorithm (MFA)**: Iteratively reduce the peaks by projecting onto the feasible set.
- **Successive Overrelaxation (SOR)**: Similar to Gauss-Seidel but with relaxation.
- **Projection Onto Convex Sets (POCS)**: Alternate between projections onto the sets {a >= 0}, {sum a = 1}, and {max_k c[k] <= t}.

The POCS approach is interesting:
1. Start with some `a`.
2. Project onto `{max_k c[k] <= t}`: This means reducing the amplitude of `c` at its peaks. In the frequency domain, this corresponds to modifying `|A|^2`. But projecting onto this set is non-trivial.

Actually, a simpler version:
1. Compute `c = a*a`.
2. Find peaks of `c` that exceed a threshold.
3. Modify `a` to reduce those peaks (e.g., by reducing the corresponding frequency components).
4. Project back to `{a >= 0, sum a = 1}`.
5. Repeat.

This is similar to the "peak reduction" algorithms in OFDM.

Let me think about a concrete algorithm:

**Algorithm: Iterative Peak Reduction**
1. Normalize `a` so that `sum a = 1`.
2. Compute `c = a*a` (full convolution).
3. Find the peak lag `k*` where `c` is maximized.
4. Compute the "error" at the peak: `e = c[k*] - target` where `target` is some value below the current peak.
5. Compute a correction to `a` that reduces `c[k*]` by `e`.
   - The gradient of `c[k*]` w.r.t. `a` is `2*a[k*-p]` (for valid p).
   - So the steepest descent direction is `a[k*-p]` (reversed).
   - Subtract a small multiple of this from `a`.
6. Project `a` onto `{a >= 0, sum a = 1}`.
7. Repeat.

This is essentially what the subgradient method does, but I can make it more sophisticated by handling multiple peaks simultaneously.

**Algorithm: Multi-Peak Reduction with Equalization**
1. Find the top-k peaks of `c`.
2. Compute the average gradient over these peaks.
3. Take a step in the negative gradient direction.
4. Project onto the simplex.
5. Adaptive step size (backtracking line search).
6. Repeat.

This is similar to the previous code's approach but with better step size selection.

import numpy as np
import time

def _next_pow2(n):
    k = 1
    while k < n:
        k <<= 1
    return max(2, k)

def _fft_convolve(a, b):
    n, m = len(a), len(b)
    out_n = n + m - 1
    N = _next_pow2(out_n)
    fa = np.fft.rfft(a, N)
    fb = np.fft.rfft(b, N)
    return np.fft.irfft(fa * fb, N)[:out_n]

def _score(a):
    n = len(a)
    s = float(a.sum())
    if s < 1e-15:
        return np.inf
    c = _fft_convolve(a, a)
    return float(2.0 * n * c.max() / (s * s))

def _score_norm(a):
    n = len(a)
    c = _fft_convolve(a, a)
    return float(2.0 * n * c.max())

def _softmax(z):
    z = z - z.max()
    e = np.exp(z)
    s = e.sum()
    if s < 1e-300:
        return np.ones_like(z) / len(z)
    return e / s

def _lse_grad(a, c, beta):
    """FFT-accelerated gradient of log-sum-exp(beta*c) w.r.t. a."""
    n = len(a)
    bc = beta * c
    bc_shifted = bc - bc.max()
    e = np.exp(bc_shifted)
    Z = e.sum()
    if Z < 1e-300 or not np.isfinite(Z):
        w = np.zeros(len(c))
        w[np.argmax(c)] = 1.0
    else:
        w = e / Z
    
    # g[p] = 2 * sum_m a[m] * w[m+p]
    # Use FFT cross-correlation
    N = _next_pow2(n + len(c) - 1)
    A = np.fft.rfft(a, N)
    W = np.fft.rfft(w, N)
    cross = np.fft.irfft(np.conj(A) * W, N)
    g = 2.0 * cross[:n]
    return g

def _adam_lse(a_init, deadline, beta_start, beta_end, lr_start, lr_end,
              max_iter=100000, eval_interval=50):
    """Adam in log-space optimizing log-sum-exp(beta * c)."""
    n = len(a_init)
    z = np.log(np.maximum(a_init, 1e-15))
    z = z - z.mean()
    m_buf = np.zeros(n)
    v_buf = np.zeros(n)
    t = 0
    b1, b2, eps = 0.9, 0.999, 1e-8
    best_a = a_init.copy()
    best_score = _score_norm(a_init)
    
    while t < max_iter:
        if time.monotonic() > deadline - 5:
            break
        t += 1
        frac = min(1.0, t / max_iter)
        
        # Adaptive beta: smooth polynomial schedule
        beta = beta_start * (beta_end / beta_start) ** (frac ** 0.5)
        lr = lr_start * (lr_end / lr_start) ** (frac ** 0.7)
        
        a = _softmax(z)
        c = _fft_convolve(a, a)
        
        # Compute gradient
        g = _lse_grad(a, c, beta)
        
        if not np.all(np.isfinite(g)):
            g = np.zeros(n)
        
        # Log-space gradient: a * (g - <a,g>)
        W = float(np.dot(a, g))
        z_grad = a * (g - W)
        
        if not np.all(np.isfinite(z_grad)):
            z_grad = np.zeros(n)
        
        # Adam update
        m_buf = b1 * m_buf + (1.0 - b1) * z_grad
        v_buf = b2 * v_buf + (1.0 - b2) * (z_grad * z_grad)
        mh = m_buf / (1.0 - b1 ** t)
        vh = v_buf / (1.0 - b2 ** t)
        update = lr * mh / (np.sqrt(vh) + eps)
        
        # Clip update
        update_norm = np.linalg.norm(update)
        if update_norm > 0.5:
            update = update * (0.5 / update_norm)
        
        z = z - update
        z = np.clip(z, -60.0, 60.0)
        z = z - z.mean()
        
        # Evaluate periodically

            a_cur = _softmax(z)
            sc = _score_norm(a_cur)
            if np.isfinite(sc) and sc < best_score:
                best_score = sc
                best_a = a_cur.copy()
    
    a_final = _softmax(z)
    sc_final = _score_norm(a_final)
    if np.isfinite(sc_final) and sc_final < best_score:

    return best_a, best_score

def _subgrad_polish(a, deadline, max_iter=50000, top_k=5):
    """Subgradient method with adaptive step size and backtracking."""
    n = len(a)
    a = a.copy() / a.sum()
    best_a = a.copy()
    best_score = _score_norm(a)
    lr = 0.01
    
    for it in range(max_iter):
        if time.monotonic() > deadline - 3:
            break
        
        c = _fft_convolve(a, a)
        c_max = float(c.max())
        
        # Find top-k peaks
        sorted_idx = np.argsort(c)[::-1]
        active = sorted_idx[:top_k]
        
        # Check if peaks are close enough to be "active"
        active = [active[0]]
        for idx in active[1:]:
            if c[idx] > c_max * 0.995:
                active = sorted_idx[:top_k]
                break
        
        # Compute subgradient (average over active peaks)
        g = np.zeros(n)
        for k in active:
            lo = max(0, k - n + 1)
            hi = min(k, n - 1)
            if lo <= hi:
                g[lo:hi+1] += 2.0 * a[k-hi:k-lo+1][::-1]
        g /= len(active)
        
        # Project to tangent space (sum = 0)
        g = g - g.mean()
        
        g_norm = np.linalg.norm(g)
        if g_norm < 1e-15:
            break
        
        # Backtracking line search
        best_local_lr = 0
        best_local_score = best_score
        for trial_lr in [lr, lr*0.5, lr*0.25, lr*0.1, lr*0.05]:
            a_trial = a - trial_lr * g / g_norm
            a_trial = np.maximum(0, a_trial)
            s = a_trial.sum()
            if s < 1e-15:
                continue
            a_trial /= s
            sc = _score_norm(a_trial)
            if sc < best_local_score - 1e-12:
                best_local_lr = trial_lr
                best_local_score = sc
                best_local_a = a_trial
                break
        
        if best_local_lr > 0:
            a = best_local_a
            if best_local_score < best_score:
                best_score = best_local_score
                best_a = a.copy()
            lr = min(lr * 1.01, 0.05)
        else:
            lr *= 0.5
            if lr < 1e-10:
                break
    
    return best_a, best_score

def _kkt_polish(a, deadline, max_iter=5000):

        # We want c[k] + sum_p M[k,p] * d[p] = target for all active k
        # And sum_p d[p] = 0

```python
import numpy as np
import time

def _next_pow2(n):
    k = 1
    while k < n:
        k <<= 1
    return max(2, k)

def _fft_convolve(a, b):
    n, m = len(a), len(b)
    out_n = n + m - 1
    N = _next_pow2(out_n)
    fa = np.fft.rfft(a, N)
    fb = np.fft.rfft(b, N)
    return np.fft.irfft(fa * fb, N)[:out_n]

def _score(a):
    n = len(a)
    s = float(a.sum())
    if s < 1e-15:
        return np.inf
    c = _fft_convolve(a, a)
    return float(2.0 * n * c.max() / (s * s))

def _score_norm(a):
    """Assumes sum(a) ≈ 1."""
    n = len(a)
    c = _fft_convolve(a, a)
    return float(2.0 * n * c.max())

def _softmax(z):
    z = z - z.max()
    e = np.exp(z)
    s = e.sum()
    if s < 1e-300:
        return np.ones_like(z) / len(z)
    return e / s

def _mse_grad(a, c, beta):
    """
    FFT-accelerated gradient of log(sum_k exp(beta*c_k)) w.r.t. a.
    Returns the gradient vector g where g[p] = 2 * sum_m a[m] * w[m+p].
    """
    n = len(a)
    lc = len(c)
    bc = beta * c
    bc -= bc.max()
    e = np.exp(bc)
    Z = e.sum()
    if Z < 1e-300 or not np.isfinite(Z):
        w = np.zeros(lc)
        w[np.argmax(c)] = 1.0
    else:
        w = e / Z
    
    N = _next_pow2(n + lc - 1)
    A = np.fft.rfft(a, N)
    W = np.fft.rfft(w, N)
    cross = np.fft.irfft(np.conj(A) * W, N)
    return 2.0 * cross[:n]

def _adam_optimize(a_init, deadline, beta_start, beta_end, lr_start, lr_end,
                   max_iter=200000, eval_interval=50, use_mse_flat=False,
                   flat_weight=0.0):
    """Adam optimizer in log-space with LSE gradient."""
    n = len(a_init)
    z = np.log(np.maximum(a_init, 1e-15))
    z -= z.mean()
    m_buf = np.zeros(n)
    v_buf = np.zeros(n)
    t = 0
    b1, b2, eps = 0.9, 0.999, 1e-8
    best_a = a_init.copy()
    best_score = _score_norm(a_init)
    patience = 0
    lr_mult = 1.0
    
    while t < max_iter:
        if time.monotonic() > deadline - 5:
            break
        t += 1
        frac = min(1.0, t / max_iter)
        
        # Adaptive parameters (quadratic schedule for smoother transition)
        beta = beta_start * (beta_end / beta_start) ** (frac ** 0.6)
        lr = lr_start * (lr_end / lr_start) ** (frac ** 0.7) * lr_mult
        
        a = _softmax(z)
        c = _fft_convolve(a, a)
        
        # Main LSE gradient
        g = _mse_grad(a, c, beta)
        
        # Optional: add flatness penalty gradient
        if use_mse_flat and flat_weight > 0:
            c_mean = c.mean()
            d = c - c_mean
            N2 = _next_pow2(n + len(d) - 1)
            A2 = np.fft.rfft(a, N2)
            D = np.fft.rfft(d, N2)
            cross2 = np.fft.irfft(np.conj(A2) * D, N2)
            g_flat = 4.0 * flat_weight * cross2[:n]

        # Adam
        m_buf = b1 * m_buf + (1.0 - b1) * z_grad
        v_buf = b2 * v_buf + (1.0 - b2) * (z_grad * z_grad)
        mh = m_buf / (1.0 - b1 ** t)
        vh = v_buf / (1.0 - b2 ** t)
        update = lr * mh / (np.sqrt(vh) + eps)

def _subgrad_refine(a, deadline, max_iter=50000, top_k=5):
    """Subgradient method with backtracking."""
    n = len(a)
    a = a.copy() / a.sum()
    best_a = a.copy()
    best_score = _score_norm(a)
    lr = 0.01
    
    for it in range(max_iter):
        if time.monotonic() > deadline - 3:
            break
        
        c = _fft_convolve(a, a)
        c_max = float(c.max())
        
        # Top-k peaks
        sorted_idx = np.argsort(c)[::-1]
        active = [sorted_idx[0]]
        for idx in sorted_idx[1:top_k]:
            if c[idx] >= c_max * 0.998:
                active.append(int(idx))
        
        # Subgradient
        g = np.zeros(n)
        for k in active:
            lo = max(0, k - n + 1)
            hi = min(k, n - 1)
            if lo <= hi:
                g[lo:hi+1] += 2.0 * a[k-hi:k-lo+1][::-1]
        g /= len(active)
        g -= g.mean()
        
        gn = np
