Let me now think about the L-BFGS smoothing more carefully.

The smoothed objective is:
f(a) = 2n * (C_max + beta * log(sum_k exp((C_k - C_max)/beta)))

where C_k = conv(a,a)[k] and C_max = max_k C_k.

Wait, actually the standard log-sum-exp smoothing is:
f(a) = beta * log(sum_k exp(C_k / beta))

As beta -> 0, this approaches max_k C_k.

But computing `sum_k exp(C_k / beta)` for large n and small beta can cause numerical overflow. The standard trick is to factor out the max:
f(a) = C_max + beta * log(sum_k exp((C_k - C_max) / beta))

This is numerically stable.

The gradient:
df/da_i = (1/beta) * sum_k exp((C_k - C_max)/beta) * dC_k/da_i / (sum_j exp((C_j - C_max)/beta))
= sum_k p_k * dC_k/da_i

where p_k = exp((C_k - C_max)/beta) / sum_j exp((C_j - C_max)/beta)

And dC_k/da_i = 2 * a[k-i] (as derived earlier, with a[j]=0 for invalid j).

So: df/da_i = 2 * sum_k p_k * a[k-i] = 2 * (correlate(p, a))[i] (approximately)

This can be computed efficiently via FFT!

Now for the active-set QP:

Given an active set S (indices k where C(a)[k] ≈ max), we solve:
minimize sum_{k in S} alpha_k * a^T H_k a
subject to sum(a) = 1, a >= 0

where alpha_k are weights (e.g., uniform over S, or proportional to C(a)[k]).

The Hessian of the objective is H = sum_{k in S} alpha_k * H_k, which is a Hankel matrix with:
H_{i,j} = 2 * sum_{k in S} alpha_k * delta_{i+j, k} = 2 * W[i+j]

where W[m] = sum_{k in S, k=m} alpha_k = alpha_m if m in S, else 0.

Wait, that's not right. W[m] = alpha_m if m in S, else 0. But H_{i,j} = 2 * sum_k alpha_k * delta_{i+j,k} = 2 * alpha_{i+j} if i+j in S, else 0.

So the Hankel matrix is H_{i,j} = 2 * W[i+j] where W[m] = alpha_m for m in S and 0 otherwise.

This is exactly what `_hankel_matvec` computes! Great.

The QP is:
minimize (1/2) a^T (2H_W) a = a^T H_W a  [the factor doesn't matter for the argmin]
subject to 1^T a = 1, a >= 0

Wait, let me be precise. The objective is:
f(a) = sum_{k in S} alpha_k * a^T H_k a = a^T (sum_k alpha_k H_k) a = a^T H a

where H_{i,j} = sum_k alpha_k * 2 * delta_{i+j,k} = 2 * W[i+j]

So the Hessian of f is 2H (since f = a^T H a, the Hessian is H + H^T = 2H since H is symmetric).

Actually, for f(a) = a^T M a where M is symmetric, the gradient is 2Ma and the Hessian is 2M.

In our case, M = H (the Hankel matrix with H_{i,j} = 2*W[i+j]). So the gradient is 2Ha and the Hessian is 2H.

The KKT conditions for min a^T H a subject to 1^T a = 1, a >= 0 are:
- 2Ha + lambda * 1 - mu = 0 (where mu >= 0 is the multiplier for a >= 0)
- 1^T a = 1
- a_i >= 0, mu_i >= 0, a_i * mu_i = 0

On the active set (a_i > 0): 2Ha + lambda * 1 = 0
So: Ha = -(lambda/2) * 1

Two equations:
Ha = -(lambda/2) * 1
1^T a = 1

Let's solve: from the first equation, a = -(lambda/2) * H^{-1} * 1 = c * H^{-1} * 1 where c = -lambda/2.
From the second: c * 1^T H^{-1} 1 = 1, so c = 1 / (1^T H^{-1} 1).
Thus a = (H^{-1} 1) / (1^T H^{-1} 1).

We need a_i >= 0 for all i in the support. If some a_i < 0, we need to remove those indices from the support and re-solve.

The CG solver computes H^{-1} 1 (or rather, the solution of H x = 1).

This is exactly what the previous code's `_qp_active_solve` does. Good.

        return np.inf

    conv_len = len(W) + len(v_rev) - 1
    N = _next_pow2(conv_len)
    FW = np.fft.rfft(W, N)
    Fv = np.fft.rfft(v_rev, N)
    conv = np.fft.irfft(FW * Fv, N)[:conv_len]
    return 2.0 * conv[n - 1:2 * n - 1]


def _cg_solve(W, n, rhs, max_iter=2000, tol=1e-14):
    """Solve H*x = rhs using CG with Hankel Hessian."""
    x = np.zeros(n)
    r = rhs.copy()
    p = r.copy()
    rs = float(r @ r)
    rs0 = rs
    if rs0 < 1e-30:
        return x
    stalled = 0
    for i in range(max_iter):

        pHp = float(p @ Hp)

        x += alpha * p
        r -= alpha * Hp

            s_sub = a_sub_new.sum()
            if s_sub < 1e-15:
                break
            a_sub_new = a_sub_new / s_sub
            a_new = np.zeros(n)
            a_new[support] = a_sub_new

        val_new = float(a_new @ _hankel_matvec(a_new, W, n))
        if not np.isfinite(val_new):
            break
        if val_new < best_val - 1e-15:
            best_val = val_new
            best_a = a_new.copy()
        a = a_new

        grad = _hankel_matvec(a, W, n)
        support = a > 1e-10
        if support.any():
            lam = float(grad[support].mean())
            resid = float(np.max(np.abs(grad[support] - lam)))
            off = ~support
            if off.any():
                resid = max(resid, float(np.max(lam - grad[off])))
        else:
            resid = np.inf
        if resid < 1e-11 * (float(np.max(np.abs(grad))) + 1e-15):
            break

    return best_a


def _newton_active(a_init, deadline, max_rounds=120):
    """Active-set QP with progressive tolerance tightening."""
    n = len(a_init)
    a = a_init.copy()
    a = np.maximum(a, 0)
    s = a.sum()
    if s < 1e-15:
        return a, _score(a)
    a = a / s
    best_a = a.copy()
    best_sc = _score(a)

    tol_schedule = [0.01, 0.005, 0.002, 0.001, 0.0005, 0.0002,
                    0.0001, 0.00005, 0.00002, 0.00001, 0.000005,
                    0.000002, 0.000001, 0.0000005, 0.0000002, 0.0000001]
    tol_idx = 0
    rounds_per_tol = 4

    for rnd in range(max_rounds):
        if time.monotonic() > deadline:
            break

        c = _full_convolve(a, a)
        c_max = float(c.max())
        tol = tol_schedule[min(tol_idx, len(tol_schedule) - 1)]
        active = c >= (c_max - tol * c_max)
        n_active = int(active.sum())
        if n_active == 0:
            active[int(np.argmax(c))] = True
            n_active = 1

        W = np.zeros(2 * n - 1)
        W[active] = 1.0 / n_active

        a_qp = _active_qp_solve(W, n, a, max_outer=60, cg_iter=1200)
        sc_qp = _score(a_qp)

        if sc_qp < best_sc - 1e-14:
            best_sc = sc_qp
            best_a = a_qp.copy()
            a = a_qp.copy()
        else:
            grad = _hankel_matvec(a, W, n)
            g_t = grad - float(np.mean(grad))
            gn = float(np.linalg.norm(g_t))
            if gn > 1e-15:
                Hg = _cg_solve(W, n, g_t, max_iter=400)
                H1 = _cg_solve(W, n, np.ones(n), max_iter=400)
                H1_s = float(np.sum(H1))
                if abs(H1_s) > 1e-20 and np.isfinite(H1_s):
                    lam = float(np.sum(Hg)) / H1_s
                    dx = -Hg + lam * H1
                    dx = dx - float(np.mean(dx))
                else:
                    dx = -g_t / gn
                alpha = 1.0
                for ls in range(50):
                    a_try = a + alpha * dx
                    a_try = np.maximum(a_try, 0)
                    s_try = a_try.sum()
                    if s_try < 1e-15:
                        alpha *= 0.5
                        continue
                    a_try = a_try / s_try
                    sc_try = _score(a_try)
                    if sc_try < _score(a) - 1e-15:
                        a = a_try
                        if sc_try < best_sc:
                            best_sc = sc_try
                            best_a = a.copy()
                        break
                    alpha *= 0.5
                    if alpha < 1e-14:
                        break

        if (rnd + 1) % rounds_per_tol == 0:
            tol_idx += 1
        sc = _score(a)
        if sc < best_sc:
            best_sc = sc
            best_a = a.copy()

    return best_a, best_sc


def _nesterov_subgrad(a_init, deadline, max_steps=5000):
    """Nesterov-accelerated subgradient with adaptive step."""
    n = len(a_init)
    z = np.log(np.maximum(a_init, 1e-30))
    z = z - z.mean()
    y = z.copy()
    best_a = a_init.copy()
    best_sc = _score(a_init)
    patience = 0
    lr_base = 0.05
    momentum = 0.9

    for i in range(max_steps):
        if time.monotonic() > deadline:
            break
        a = _softmax(y)
        c = _full_convolve(a, a)
        c_max = float(c.max())

        tol = 0.001 * c_max
        active = c >= (c_max - tol)
        if active.sum() == 0:
            active[int(np.argmax(c))] = True
        w = np.zeros_like(c)
        w[active] = 1.0 / active.sum()

        a_rev = a[::-1]
        conv_len = len(w) + len(a_rev) - 1
        N = _next_pow2(conv_len)
        Fw = np.fft.rfft(w, N)
        Fa = np.fft.rfft(a_rev, N)
        conv = np.fft.irfft(Fw * Fa, N)[:conv_len]
        h = conv[n - 1:2 * n - 1]
        W_val = float(np.dot(w, c))
        grad = 4.0 * n * a * (h - W_val)
        gn = float(np.linalg.norm(grad))
        if gn < 1e-15:
            break

        t_k = 1.0 + momentum
        lr = lr_base / (1.0 + 0.001 * i)
        z_new = y - lr * (grad / gn)
        y = momentum * y + (1 - momentum) * (z + lr * (grad / gn))
        y = np.clip(y, -50.0, 50.0)
        y = y - y.mean()
        z = z_new

        if i % 50 == 0:
            a_check = _softmax(y)
            sc = _score(a_check)
            if sc < best_sc - 1e-12:
                best_sc = sc
                best_a = a_check.copy()
                patience = 0
            else:
                patience += 1
                if patience > 40:
                    y = np.log(np.maximum(best_a, 1e-30))
                    y = y - y.mean()
                    lr_base *= 0.7
                    patience = 0

    a_final = _softmax(y)
    sc_final = _score(a_final)
    if sc_final < best_sc:
        best_sc = sc_final
        best_a = a_final.copy()
    return best_a, best_sc


def _shrink_reopt(a, deadline, min_time=60.0):
    """Zero out smallest elements and re-optimize."""
    n = len(a)
    best_a = a.copy()
    best_sc = _score(a)
    a_sorted = np.argsort(a)

    for frac in [0.05, 0.1, 0.15, 0.25]:
        if time.monotonic() + min_time > deadline:
            break
        n_zero = max(1, int(n * frac))
        a_try = best_a.copy()
        a_try[a_sorted[:n_zero]] = 0.0
        s_try = a_try.sum()
        if s_try < 1e-10:
            continue
        a_try = a_try / s_try
        sc_try = _score(a_try)
        if sc_try < best_sc - 1e-12:
            best_sc = sc_try
            best_a = a_try.copy()
            a_sorted = np.argsort(best_a)
            if time.monotonic() + min_time > deadline:
                break
            a_re = _run_lbfgs(best_a, deadline, min_time_remaining=min_time, aggressive=True)
            sc_re = _score(a_re)
            if sc_re < best_sc:
                best_sc = sc_re
                best_a = a_re

    return best_a, best_sc


def _make_profile(n, kind="tapered"):
    if kind == "uniform":
        return np.ones(n) / n
    elif kind == "tapered":
        t = np.linspace(0, 1, n)
        a = np.sin(np.pi * t) ** 0.5
        a = np.maximum(a, 1e-10)
        return a / a.sum()
    elif kind == "cos":
        t = np.linspace(0, 1, n)
        a = 0.5 + 0.5 * np.cos(np.pi * t)
        a = np.maximum(a, 1e-10)
        return a / a.sum()
    elif kind == "flat_top":
        t = np.linspace(0, 1, n)
        a = np.ones(n) * 0.1
        inner = (t > 0.1) & (t < 0.9)
        a[inner] = 1.0
        return a / a.sum()
    else:
        return np.ones(n) / n


def _resample(a, n_new):
    n_old = len(a)
    x_old = np.linspace(0, 1, n_old)
    x_new = np.linspace(0, 1, n_new)
    a_new = np.interp(x_new, x_old, a)
    a_new = np.maximum(a_new, 0)
    s = a_new.sum()
    if s < 1e-15:
        return np.ones(n_new) / n_new
    return a_new / s


def propose_candidate(seed=42, budget_s=1800):
    """
    Multi-phase optimizer: aggressive L-BFGS beta continuation,
    active-set QP with progressive tightening, Nesterov subgradient,
    shrinkage, and multi-n exploration up to 65536.
    """
    t_start = time.monotonic()
    deadline = t_start + max(1.0, float(budget_s) - 25.0)
    rng = np.random.default_rng(int(seed) % (2**63 - 1))

    best_seq = None
    best_score = np.inf

    def update_best(p, sc=None, label=""):
        nonlocal best_seq, best_score
        if p is None:
            return
        p = np.asarray(p, dtype=np.float64).ravel()
        p = np.clip(p, 0.0, 1000.0)
        s = float(p.sum())
        if s < 0.01:
            return
        if sc is None:
            sc = _score(p)
        if np.isfinite(sc) and sc < best_score:
            prev = best_score
            best_seq = p.copy()
            best_score = float(sc)
            print(f"  NEW BEST: {best_score:.10f} (n={len(p)}) [{label}] "
                  f"improve={prev - best_score:.2e} t={time.monotonic()-t_start:.1f}s")

    # Load parent
    parent = None
    n_parent = 0
    try:
        parent_raw = np.asarray(height_sequence_1, dtype=np.float64).ravel()
        if parent_raw.size > 0:
            parent_raw = np.clip(parent_raw, 0.0, 1000.0)
            s = float(parent_raw.sum())
            if s > 0.01:
                parent = parent_raw / s
                n_parent = len(parent)
                par_sc = _score(parent)
                print(f"Parent: n={n_parent}, score={par_sc:.10f}")
                update_best(parent, par_sc, "parent")
    except Exception:
        pass

    if parent is None:
        n_parent = 16384
        parent = _make_profile(n_parent, "tapered")
        print(f"No parent, using tapered n={n_parent}")
        update_best(parent, _score(parent), "init")

    n_main = n_parent

    # Phase 1: Aggressive L-BFGS
    print(f"\n[Phase 1] Aggressive L-BFGS n={n_main} (t={time.monotonic()-t_start:.1f}s)")
    a1 = _run_lbfgs(parent, deadline, min_time_remaining=800.0, aggressive=True)
    sc1 = _score(a1)
    update_best(a1, sc1, "lbfgs_p1")
    print(f"  After L-BFGS: score={sc1:.10f}")

    # Phase 2: Active-set QP (first pass)
    print(f"\n[Phase 2] Active-set QP (t={time.monotonic()-t_start:.1f}s)")
    if time.monotonic() < deadline - 600:
        a2, sc2 = _newton_active(best_seq, min(deadline - 600, time.monotonic() + 350), max_rounds=100)
        update_best(a2, sc2, "aqp_1")
        print(f"  After AQP: score={sc2:.10f}")

    # Phase 3: Nesterov subgradient
    print(f"\n[Phase 3] Nesterov subgrad (t={time.monotonic()-t_start:.1f}s)")
    if time.monotonic() < deadline - 500:
        a3, sc3 = _nesterov_subgrad(best_seq, min(deadline - 500, time.monotonic() + 150), max_steps=3000)
        update_best(a3, sc3, "nesterov_1")
        print(f"  After Nesterov: score={sc3:.10f}")

    # Phase 4: Second AQP (tighter)
    print(f"\n[Phase 4] Active-set QP round 2 (t={time.monotonic()-t_start:.1f}s)")
    if time.monotonic() < deadline - 400:
        a4, sc4 = _newton_active(best_seq, min(deadline - 400, time.monotonic() + 250), max_rounds=120)
        update_best(a4, sc4, "aqp_2")
        print(f"  After AQP2: score={sc4:.10f}")

    # Phase 5: Shrinkage
    print(f"\n[Phase 5] Shrinkage (t={time.monotonic()-t_start:.1f}s)")
    if time.monotonic() < deadline - 300:
        a5, sc5 = _shrink_reopt(best_seq, deadline, min_time=150.0)
        update_best(a5, sc5, "shrink")
        print(f"  After shrink: score={sc5:.10f}")

    # Phase 6: Multi-n exploration
    print(f"\n[Phase 6] Multi-n exploration (t={time.monotonic()-t_start:.1f}s)")
    n_candidates = [32768, n_main // 2 if n_main > 2048 else 4096]
    for n_try in n_candidates:
        if time.monotonic() > deadline - 150:
            break
        if n_try == n_main:
            continue
        if n_try < 1024:
            continue
        a_init = _resample(best_seq, n_try)
        a_opt = _run_lbfgs(a_init, deadline, min_time_remaining=80.0, aggressive=True)
        sc_opt = _score(a_opt)
        update_best(a_opt, sc_opt, f"n_{n_try}_lbfgs")
        print(f"  n={n_try} L-BFGS: score={sc_opt:.10f}")

        if sc_opt < best_score + 0.005 and time.monotonic() < deadline - 100:
            a_np, sc_np = _newton_active(a_opt, min(deadline - 80, time.monotonic() + 100), max_rounds=60)
            update_best(a_np, sc_np, f"n_{n_try}_aqp")
            print(f"  n={n_try} AQP: score={sc_np:.10f}")

    # Phase 7: Final polish on best
    print(f"\n[Phase 7] Final polish (t={time.monotonic()-t_start:.1f}s)")
    if best_seq is not None and time.monotonic() < deadline - 10:
        # Final ultra-tight AQP
        a_fin, sc_fin = _newton_active(best_seq, deadline - 3, max_rounds=80)
        update_best(a_fin, sc_fin, "final_aqp")

        # Final L-BFGS with tiny beta
        if time.monotonic() < deadline - 5:
            n = len(best_seq)
            c_best = _full_convolve(best_seq, best_seq)
            mb = float(c_best.max())
            z = np.log(np.maximum(best_seq, 1e-30))
            z = z - z.mean()
            beta_fin = mb * 1e-10
            remaining = deadline - 5 - time.monotonic()
            if remaining > 3:
                max_iter = min(3000, max(100, int(remaining / 0.005)))
                try:
                    result = minimize(
                        lambda z_local: _smoobj(z_local, beta_fin, n),
                        z,
                        jac=lambda z_local: _smograd(z_local, beta_fin, n),
                        method='L-BFGS-B',
                        options={'maxiter': max_iter, 'ftol': 1e-20, 'gtol': 1e-15,
                                 'maxcor': 80, 'maxls': 300}
                    )
                    a_fl = _softmax(result.x)
                    update_best(a_fl, _score(a_fl), "final_lbfgs_tiny")
                except Exception:
                    pass

    # Final validation
    print(f"\n{'=' * 60}")
    if best_seq is not None:
        final = np.clip(best_seq, 0.0, 1000.0)
        s = float(final.sum())
        if s < 0.01:
            final = _make_profile(256, "uniform")
        sc_final = _score(final)
        print(f"FINAL: score={sc_final:.10f}, n={len(final)}, "
              f"time={time.monotonic()-t_start:.1f}s")
        return [float(x) for x in final]

    fallback = _make_profile(16384, "tapered")
    print(f"FALLBACK: score={_score(fallback):.10f}")
    return [float(x) for x in fallback]
