**Active-set Newton (improved):**
At the end of the L-BFGS phase, we have a good approximate solution. Now we refine using the active-set method:
1. Find the active set K (lags where c[k] is within epsilon of the max).
2. Solve the linear system to find a direction d that equalizes the active peaks.
3. Take a step in direction d with a line search.
4. Repeat.

The linear system:
For active lags k_1, ..., k_s, we want:
`c[k_i] + ∇c[k_i]·d = λ` for all i = 1, ..., s
`sum(d) = 0`

This is (s+1) equations in n unknowns. The minimum-norm solution:
`d = G^T (G G^T)^{-1} b`

where `G` is (s+1) × n with rows `∇c[k_i]` for i=1..s and `ones(n)`, and `b = [λ, λ, ..., λ, 0]^T`.

But we need to determine λ. We can set λ = the current max (which means we're looking for a direction that keeps the active peaks at the same level while trying to reduce others... that's not quite right).

Actually, the standard approach for minimizing the max of quadratic functions is:
- At a KKT point, there exist multipliers μ_i >= 0 such that:
  `sum_i μ_i * ∇c[k_i] + λ * ones = 0` (for the free variables)
  `c[k_i] = λ_max` for all active i
  `sum(a) = 1`

This is a system of nonlinear equations (because c[k_i] = λ_max is nonlinear in a). We can solve it iteratively:
1. Given current a, find the active set.
2. Solve for the direction d that would equalize the active peaks (linearization).
3. Take a step and update.

For the linearized problem:
`c[k_i] + ∇c[k_i]·d = c[k_j] + ∇c[k_j]·d` for all pairs (i,j) in K
`sum(d) = 0`

This means: `(∇c[k_i] - ∇c[k_j])·d = c[k_j] - c[k_i]` for all pairs.

Equivalently, there exists λ such that:
`∇c[k_i]·d = λ - c[k_i]` for all i in K
`sum(d) = 0`

The minimum-norm solution is:
`d = G^T (G G^T)^{-1} (λ * 1_K - c_K)`

where `G` has rows `∇c[k_i]` and `ones`, and `c_K = [c[k_1], ..., c[k_s]]^T`.

But λ is unknown. We can eliminate it by noting that the last row of G is `ones`, and the last component of the RHS is 0. So:
`d = G^T (G G^T)^{-1} b` where `b = [λ - c[k_1], ..., λ - c[k_s], 0]^T`.

To determine λ: multiply the constraint `sum(d) = 0` by 1^T:
`1^T * d = 1^T * G^T * (GG^T)^{-1} * b = 0`

This gives us an equation in λ. Let's write `GG^T = H` (an (s+1)×(s+1) matrix). Then:
`d = G^T H^{-1} b`
`1^T G^T H^{-1} b = 0`

`1^T G = [sum(∇c[k_1]), ..., sum(∇c[k_s]), n]` (the last component is n since the last row of G is ones).

So `1^T G = [2, 2, ..., 2, n]`.

Thus: `[2, 2, ..., 2, n] * H^{-1} * [λ-c[k_1], ..., λ-c[k_s], 0]^T = 0`.

This is a linear equation in λ (since y depends linearly on λ through b). We can solve for λ.

def _newton_polish(a, deadline, max_iter=5000):
    """Newton-type polish using active-set linearization with polynomial line search."""
    n = len(a)
    a = a.copy() / a.sum()
    best_a = a.copy()

        c = _fft_convolve(a, a)
        c_max = float(c.max())
        
        # Find active set (top peaks within tolerance)
        tol = c_max * (1.0 - 1e-4)
        active = np.where(c >= tol)[0]
        if len(active) > 12:
            top_idx = np.argsort(c[active])[::-1][:12]
            active = active[top_idx]
        s = len(active)
        if s < 1:
            active = np.array([np.argmax(c)])
            s = 1
        
        # Build gradient matrix: rows are ∇c[k] for k in active
        # ∇c[k][m] = 2*a[k-m] (with a out of range = 0)
        G = np.zeros((s, n))
        for i, k in enumerate(active):
            lo = max(0, k - n + 1)
            hi = min(k, n - 1)
            if lo <= hi:
                G[i, lo:hi+1] = 2.0 * a[k-hi:k-lo+1][::-1]
        
        # Solve for direction: minimize max_i (c[k_i] + G[i]·d) s.t. sum(d)=0
        # Linearized: find d such that G[i]·d ≈ -(c[k_i] - c_target) for all i
        # Use: d = G^T (G G^T + λI)^{-1} * (-c_active + c_mean)
        # Plus constraint sum(d) = 0 via projection
        
        c_active = c[active]
        c_mean = c_active.mean()
        target = c_mean  # try to equalize to the mean of active peaks
        
        # Minimum norm solution to G d = (target - c_active) with sum(d) = 0
        # Augmented system: [G; 1^T] d = [target - c_active; 0]
        G_aug = np.vstack([G, np.ones(n)])
        b_aug = np.concatenate([target - c_active, [0.0]])
        
        # d = G_aug^T (G_aug G_aug^T)^{-1} b_aug
        H = G_aug @ G_aug.T  # (s+1) x (s+1)

def _subgradient_refine(a, deadline, max_iter=50000, top_k=5):
    """Subgradient method with adaptive step size and top-k peak averaging."""
    n = len(a)
    a = a.copy() / a.sum()
    best_a = a.copy()
    best_score = _score_norm(a)
    lr = 0.002
    patience = 0
    
    for it in range(max_iter):
        if time.monotonic() > deadline:
            break
        
        c = _fft_convolve(a, a)
        c_max = float(c.max())
        
        # Top-k peaks
        sorted_idx = np.argsort(c)[::-1]
        active = []
        for idx in sorted_idx[:top_k]:
            if c[idx] >= c_max * 0.9995:
                active.append(idx)
        if not active:
            active = [int(sorted_idx[0])]
        
        # Average subgradient
        g = np.zeros(n)
        for k in active:
            lo = max(0, k - n + 1)
            hi = min(k, n - 1)
            if lo <= hi:
                g[lo:hi+1] += 2.0 * a[k-hi:k-lo+1][::-1]
        g /= len(active)
        
        # Project to tangent space of simplex (remove component in direction of a)
        # The tangent space of {a: sum=1, a>=0} at interior point is {d: sum(d)=0}
        g_tan = g - np.mean(g)
        
        g_norm = np.linalg.norm(g_tan)
        if g_norm < 1e-15:
            break
        
        # Polyak step size
        gap = c_max - c.mean()
        if gap > 1e-15:
            lr_polyak = gap / (g_norm * g_norm + 1e-15)
            lr = 0.5 * lr + 0.5 * min(lr_polyak, 0.01)
        
        step = lr * g_tan / g_norm
        a_new = a - step
        a_new = np.maximum(0, a_new)
        s_new = a_new.sum()
        if s_new < 1e-15:
            break
        a_new /= s_new
        
        sc_new = _score_norm(a_new)
        if sc_new < best_score:
            best_score = sc_new
            best_a = a_new.copy()
            a = a_new
            patience = 0
        else:
            patience += 1
            lr *= 0.995
            if patience > 200:
                lr *= 0.5
                patience = 0
                if lr < 1e-10:
                    break
    
    return best_a, best_score


def _coordinate_descent(a, deadline, max_rounds=500):
    """Cyclical coordinate descent on the peak-affecting coordinates."""
    n = len(a)
    a = a.copy() / a.sum()
    best_a = a.copy()
    best_score = _score_norm(a)
    
    round_num = 0
    while round_num < max_rounds:
        if time.monotonic() > deadline:
            break
        round_num += 1
        improved = False
        
        c = _fft_convolve(best_a, best_a)
        k_max = int(np.argmax(c))
        
        lo = max(0, k_max - n + 1)
        hi = min(k_max, n - 1)
        
        # Try coordinates that contribute to the peak
        step = max(1, (hi - lo + 1) // 50)
        for j in range(lo, hi + 1, step):
            old_val = best_a[j]
            if old_val < 1e-15:
                continue
            for scale in [0.8, 0.9, 1.1, 1.25]:
                a_cand = best_a.copy()
                a_cand[j] = old_val * scale
                s = a_cand.sum()
                if s < 1e-15:
                    continue
                a_cand /= s
                c_cand = _fft_convolve(a_cand, a_cand)
                sc = float(c_cand.max()) * 2.0 * n
                if sc < best_score * (1.0 - 1e-12):
                    best_score = sc
                    best_a = a_cand.copy()
                    improved = True
                    break
            if improved:
                break
        
        if not improved:
            # Broader search
            any_improve = False
            step2 = max(1, n // 100)
            for j in range(0, n, step2):
                old_val = best_a[j]
                if old_val < 1e-15:
                    continue
                for scale in [0.7, 0.85, 1.2, 1.4]:
                    a_cand = best_a.copy()
                    a_cand[j] = old_val * scale
                    s = a_cand.sum()
                    if s < 1e-15:
                        continue
                    a_cand /= s
                    c_cand = _fft_convolve(a_cand, a_cand)
                    sc = float(c_cand.max()) * 2.0 * n
                    if sc < best_score * (1.0 - 1e-12):
                        best_score = sc
                        best_a = a_cand.copy()
                        any_improve = True
                        improved = True
                        break
                if improved:
                    break
                if time.monotonic() > deadline:
                    return best_a, best_score
            if not any_improve:
                break
    
    return best_a, best_score


def propose_candidate(seed=42, budget_s=1800):
    """
    Multi-phase optimizer:
    1. Load parent, normalize.
    2. Scipy L-BFGS on LSE-smoothed objective (multi-temperature).
    3. Adam in log-space (backup/refinement).
    4. Active-set Newton polish.
    5. Subgradient refinement.
    6. Coordinate descent.
    7. Random restarts with quick re-optimization.
    8. Final polish.
    """
    t_start = time.monotonic()
    deadline = t_start + max(1.0, float(budget_s) - 30.0)
    rng = np.random.default_rng(int(seed) % (2**63 - 1))
    
    # Load parent
    try:
        parent = np.asarray(height_sequence_1, dtype=np.float64).ravel()
        parent = np.clip(parent, 0.0, 1000.0)
        if parent.sum() > 0.01:
            a = parent / parent.sum()
        else:
            raise ValueError("sum too small")
    except Exception:
        n = 8192
        a = np.ones(n) / n
        print("Using default uniform initialization")
    
    n = len(a)
    best_a = a.copy()
    best_score = _score_full(a)
    print(f"Initial: n={n}, score={best_score:.10f}, t={time.monotonic()-t_start:.1f}s")
    
    # Phase 1: Scipy L-BFGS (0 - 400s)
    phase1_end = min(deadline, t_start + 400.0)
    if time.monotonic() < phase1_end:
        print(f"Phase 1: Scipy L-BFGS multi-temperature")
        a_opt, sc = _scipy_lbfgs_phase(a, phase1_end, n_temps=4)
        full_sc = _score_full(a_opt)
        print(f"Phase 1 done: score={full_sc:.10f}, t={time.monotonic()-t_start:.0f}s")
        if full_sc < best_score:
            best_score = full_sc
            best_a = a_opt.copy()
    
    # Phase 2: Adam log-space refinement (400 - 650s)
    phase2_end = min(deadline, t_start + 650.0)
    if time.monotonic() < phase2_end:
        print(f"Phase 2: Adam log-space refinement")
        c_best = _fft_convolve(best_a, best_a)
        max_cb = float(c_best.max())
        a_opt2, sc2 = _adam_log_space(
            np.log(np.maximum(best_a, 1e-15)) - np.log(np.maximum(best_a, 1e-15)).mean(),
            phase2_end, T_start=max_cb * 0.01, T_end=max_cb * 0.0001,
            lr_start=0.02, lr_end=0.002, max_iter=100000
        )
        full_sc2 = _score_full(a_opt2)
        print(f"Phase 2 done: score={full_sc2:.10f}, t={time.monotonic()-t_start:.0f}s")
        if full_sc2 < best_score:
            best_score = full_sc2
            best_a = a_opt2.copy()
    
    # Phase 3: Newton active-set polish (650 - 900s)
    phase3_end = min(deadline, t_start + 900.0)
    if time.monotonic() < phase3_end:
        print(f"Phase 3: Newton active-set polish")
        a_opt3, sc3 = _newton_polish(best_a, phase3_end, max_iter=3000)
        full_sc3 = _score_full(a_opt3)
        print(f"Phase 3 done: score={full_sc3:.10f}, t={time.monotonic()-t_start:.0f}s")
        if full_sc3 < best_score:
            best_score = full_sc3
            best_a = a_opt3.copy()
    
    # Phase 4: Subgradient refinement (900 - 1100s)
    phase4_end = min(deadline, t_start + 1100.0)
    if time.monotonic() < phase4_end:
        print(f"Phase 4: Subgradient refinement")
        a_opt4, sc4 = _subgradient_refine(best_a, phase4_end, max_iter=80000, top_k=5)
        full_sc4 = _score_full(a_opt4)
        print(f"Phase 4 done: score={full_sc4:.10f}, t={time.monotonic()-t_start:.0f}s")
        if full_sc4 < best_score:
            best_score = full_sc4
            best_a = a_opt4.copy()
    
    # Phase 5: Coordinate descent (1100 - 1300s)
    phase5_end = min(deadline, t_start + 1300.0)
    if time.monotonic() < phase5_end:
        print(f"Phase 5: Coordinate descent")
        a_opt5, sc5 = _coordinate_descent(best_a, phase5_end, max_rounds=300)
        full_sc5 = _score_full(a_opt5)
        print(f"Phase 5 done: score={full_sc5:.10f}, t={time.monotonic()-t_start:.0f}s")
        if full_sc5 < best_score:
            best_score = full_sc5
            best_a = a_opt5.copy()
    
    # Phase 6: Random restarts (1300 - 1600s)
    phase6_end = min(deadline, t_start + 1600.0)
    if time.monotonic() < phase6_end:
        print(f"Phase 6: Random restarts")
        n_restarts = 4
        time_per = max(30.0, (phase6_end - time.monotonic()) / n_restarts)
        for r in range(n_restarts):
            if time.monotonic() > phase6_end - time_per * 0.5:
                break
            sigma = 0.003 + 0.002 * r
            z = np.log(np.maximum(best_a, 1e-15))
            z = z + sigma * rng.standard_normal(n)
            z = z - z.mean()
            a_pert = _softmax_stable(z)
            
            c_p = _fft_convolve(a_pert, a_pert)
            max_cp = float(c_p.max())
            sub_dl = min(phase6_end - 5, time.monotonic() + time_per * 0.7)
            
            a_pert_opt, sc_pert = _adam_log_space(
                z, sub_dl, T_start=max_cp * 0.005, T_end=max_cp * 0.0001,
                lr_start=0.015, lr_end=0.001, max_iter=50000
            )
            
            # Quick Newton polish
            if time.monotonic() < phase6_end - 10:
                a_pert_opt, _ = _newton_polish(a_pert_opt, phase6_end - 5, max_iter=500)
            
            full_sc_pert = _score_full(a_pert_opt)
            print(f"  Restart[{r}] sigma={sigma:.4f}: score={full_sc_pert:.10f} t={time.monotonic()-t_start:.0f}s")
            if full_sc_pert < best_score:
                best_score = full_sc_pert
                best_a = a_pert_opt.copy()
    
    # Phase 7: Final ultra-fine polish (1600 - deadline)
    if time.monotonic() < deadline - 20:
        print(f"Phase 7: Final polish")
        a_fin, _ = _newton_polish(best_a, deadline - 30, max_iter=2000)
        full_sc_fin = _score_full(a_fin)
        if full_sc_fin < best_score:
            best_score = full_sc_fin
            best_a = a_fin.copy()
        
        if time.monotonic() < deadline - 10:
            a_fin2, _ = _coordinate_descent(best_a, deadline - 5, max_rounds=100)
            full_sc_fin2 = _score_full(a_fin2)
            if full_sc_fin2 < best_score:
                best_score = full_sc_fin2
                best_a = a_fin2.copy()
    
    # Final validation
    final = np.clip(best_a, 0.0, 1000.0)
    s = float(final.sum())
    if s < 0.01:
        final = np.ones(256) * 0.01
    sc_final_check = _score_full(final)
    print(f"FINAL: score={sc_final_check:.10f}, n={len(final)}, time={time.monotonic()-t_start:.1f}s")
    return [float(x) for x in final]
