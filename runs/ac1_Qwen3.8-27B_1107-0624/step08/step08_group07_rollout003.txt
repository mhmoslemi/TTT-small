Actually, let me think about this more carefully. The primal has n variables and 2n-1 inequality constraints (plus n non-negativity constraints). The dual has 2n-1 variables and n inequality constraints (plus 2n-1 non-negativity constraints).

However, the key insight from the "state of the art" approach is to use the LP solution as a DIRECTION, not as the final answer. The LP gives us a point g that has conv(a, g) bounded by M. We then blend: a_new = (1-t)*a + t*g.

The idea is that g is "flat" relative to a, so blending reduces the peak of conv(a_new, a_new).

Let me also consider a **different approach entirely**: 

**Spectral method**: The convolution b = conv(a,a) can be analyzed in the frequency domain. In the frequency domain, B(omega) = |A(omega)|^2 (for the circular convolution; for linear convolution, it's more complex but related).

If we could make |A(omega)|^2 as flat as possible, the time-domain convolution would be as "spread out" as possible, reducing the peak.

For the linear convolution, the relationship is:
B[k] = IDFT(A(omega) * A(omega)) [with zero-padding]

If we want B to be flat (all B[k] = 1/(2n-1)), we need the IDFT of |A|^2 to be a delta... no, that's not right either.

Actually, for the DFT with zero-padding to length N >= 2n-1:
B_dft[m] = sum_k B[k] * exp(-2πi*m*k/N)
A_dft[m] = sum_j a[j] * exp(-2πi*m*j/N)
B_dft[m] = A_dft[m] * A_dft[m] (since B = linear conv of a with a)

Wait, that's for the circular convolution of the zero-padded sequences. For linear convolution zero-padded to N, we have:
B_dft[m] = A_dft[m]^2 (not |A_dft[m]|^2, because it's a, not a* convolved with a)

Hmm, actually for real a, the linear convolution a*a zero-padded to N has DFT equal to A_dft[m]^2 where A_dft is the N-point DFT of a (zero-padded).

So we want A_dft[m]^2 to be as "flat" as possible in the sense that its IDFT has minimal peak.

The IDFT of A_dft[m]^2 gives us B[k] (for k = 0, ..., N-1, with B[k] = 0 for k >= 2n-1).

We want to minimize max B[k] = max_k IDFT(A_dft^2)[k].

This is equivalent to: find A_dft[m] (constrained by a[j] >= 0 and a being zero for j >= n) such that the IDFT of A_dft^2 has minimal peak.

This is still non-convex and hard, but gives a different perspective.

One approach: iteratively modify A_dft[m] to flatten B. This is similar to the "spectral flattening" or "flat spectrum" algorithms used in signal processing.

**Iterative spectral flattening:**
1. Start with some a (e.g., uniform).
2. Compute B = conv(a, a).
3. For each lag k where B[k] > target, reduce the contribution.
4. In frequency domain: A_new[m] = A[m] * exp(-alpha * B_dft_contrib[m]) or something similar.
5. Transform back, project onto {a >= 0, support in [0, n-1]}.
6. Repeat.

Actually, a cleaner version:
1. Compute B = conv(a, a).
2. Compute the "excess" at each lag: E[k] = max(0, B[k] - threshold).
3. The gradient of sum E[k] w.r.t. a gives a direction to reduce peaks.
4. Take a step in that direction, projecting back to a >= 0.

This is essentially a projected subgradient method with a focus on the peaks.

Row k: [a[k], a[k-1], ..., a[0], 0, ..., 0, a[1], a[2], ...] (shifted versions of a)

The matrix A has A[k,i] = a[k-i] if 0 <= k-i < n, else 0.

import numpy as np

def _next_pow2(n):
    k = 1
    while k < n:
        k <<= 1
    return max(2, k)

def _fft_convolve(a, b):
    n, m = len(a), len(b)
    out_n = n + m - 1
    N = _next_pow2(out_n)
    fa = rfft(a, N)
    fb = rfft(b, N)
    return irfft(fa * fb, N)[:out_n]

def _score(a):
    n = len(a)
    s = float(a.sum())
    if s < 1e-15:
        return np.inf
    c = _fft_convolve(a, a)
    return float(2.0 * n * c.max() / (s * s))

def _score_unnormalized(a):
    """Score assuming sum(a) = 1, returns 2*n*max(convolution)."""
    n = len(a)
    c = _fft_convolve(a, a)
    return float(2.0 * n * c.max())

def _softmax_stable(z):
    z = z - np.max(z)
    e = np.exp(z)
    s = e.sum()
    if s < 1e-300:
        return np.ones_like(z) / len(z)
    return e / s

def _smoothed_grad_fft(a, c, T):

    So grad[j] = sum_k p[k] * (a[k-j] + a[j-k])

    Wait, p[k] is NOT symmetric in general. Let me just compute it directly.

def _lp_direction(a, M, deadline):
    """Solve LP to find direction g that maximizes sum(g) subject to conv(a,g) <= M, g >= 0.
    
    Returns the normalized direction g/sum(g) or None if infeasible.
    """
    n = len(a)
    # Primal: max 1^T g s.t. A*g <= M*1, g >= 0
    # where A[k,j] = a[j] if 0 <= k-j < n (i.e., a[k-j] when valid)
    # Actually: (conv(a,g))[k] = sum_j a[j]*g[k-j] (g[m]=0 for m not in [0,n-1])
    # So (conv(a,g))[k] = sum_{j: 0<=k-j<n} a[j]*g[k-j]
    # Let i = k-j: = sum_{i: 0<=i<n, 0<=k-i<n} a[k-i]*g[i]
    # So coefficient of g[i] in row k is a[k-i] if 0 <= k-i < n, else 0.
    
    # A[k, i] = a[k-i] if 0 <= k-i < n, else 0
    # k ranges from 0 to 2n-2 (2n-1 rows)
    # i ranges from 0 to n-1 (n columns)
    
    # This is a large LP. For n=8192, it's 8192 vars, 16383 constraints.
    # Let's try to solve it with scipy's linprog (HiGHS).
    
    # Actually, for very large n, this might be too slow. Let's subsample the constraints.
    # We only need the "active" constraints (those close to binding).
    
    c = _fft_convolve(a, a)  # Not needed here, we use conv(a, g)
    # Actually we need the constraints conv(a, g)[k] <= M for all k.
    # The binding ones are those where conv(a, g) is closest to M.
    # Initially, conv(a, g) for g = a is c = conv(a,a), and the binding constraints are where c is close to max(c).
    
    # For the first LP, let's use a subset of constraints (the ones most likely to be binding).
    # After solving, check if any other constraints are violated, add them, and re-solve.
    
    # Start with the top constraints
    # We don't know conv(a,g) until we solve, so let's start with all constraints
    # but subsample if n is too large.
    
    if n > 4096:
        # Subsample: use every other constraint, plus the top ones
        all_k = np.arange(2*n - 1)
        # We'll use a subset
        step = max(1, (2*n-1) // 4096)
        k_subset = np.arange(0, 2*n-1, step)
        # Also add the peak positions of conv(a,a)
        c_aa = _fft_convolve(a, a)
        top_idx = np.argsort(c_aa)[::-1][:64]
        k_subset = np.unique(np.concatenate([k_subset, top_idx]))
    else:
        k_subset = np.arange(2*n - 1)
    
    K = len(k_subset)
    
    # Build the constraint matrix (sparse would be ideal, but let's use dense for now if K*n is manageable)
    if K * n > 50_000_000:  # Too large for dense
        # Use a different approach: iterate
        return None
    
    A_ub = np.zeros((K, n))
    for idx, k in enumerate(k_subset):
        # A_ub[idx, i] = a[k-i] if 0 <= k-i < n
        i_max = min(k, n-1)
        i_min = max(0, k - (n-1))
        for i in range(i_min, i_max + 1):
            A_ub[idx, i] = a[k - i]
    
    b_ub = np.full(K, float(M))
    c_obj = -np.ones(n)  # Minimize -sum(g) = maximize sum(g)
    
    bounds = [(0, None)] * n
    
    try:
        t_lp_start = time.monotonic()
        result = linprog(c_obj, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')
        t_lp_end = time.monotonic()
        print(f"    LP solved in {t_lp_end - t_lp_start:.1f}s, status={result.status}")
        
        if result.status != 0:
            return None
        
        g = result.x
        s = g.sum()
        if s < 1e-10:
            return None
        
        # Verify: check if any constraints are violated (for the ones we didn't include)
        if len(k_subset) < 2*n - 1:
            conv_ag = _fft_convolve(a, g)
            if conv_ag.max() > M * 1.01:
                # Constraint violated, need to add constraints and re-solve
                # For now, just scale g down
                scale = M / conv_ag.max() * 0.99
                g = g * scale
                s = g.sum()
                if s < 1e-10:
                    return None
        
        return g / s  # Normalize to sum = 1
    
    except Exception as e:
        print(f"    LP failed: {e}")
        return None

def _adam_logspace(a_init, deadline, T_start, T_end, lr, max_iter, 
                   active_k=5, eval_interval=50):

    n = len(a_init)
    z = np.log(np.maximum(a_init, 1e-15))
    z = z - z.mean()
    m_buf = np.zeros(n)
    v_buf = np.zeros(n)
    t = 0
    b1, b2, eps = 0.9, 0.999, 1e-8
    best_a = a_init.copy()
    best_score = _score_unnormalized(a_init)
    patience = 0
    lr_mult = 1.0
    
    while t < max_iter:
        if time.monotonic() > deadline:
            break
        t += 1
        frac = min(1.0, t / max_iter)
        T = T_start * (T_end / T_start) ** (frac ** 0.6)
        cur_lr = lr * (0.1 + 0.9 * (1 - frac)) * lr_mult
        
        a = _softmax_stable(z)
        c = _fft_convolve(a, a)
        
        # Compute gradient
        if T < T_start * 0.05:
            # Active set gradient
            c_max = float(c.max())
            tol = c_max * 0.99
            active = np.where(c >= tol)[0]
            if len(active) == 0:
                active = np.array([np.argmax(c)])
            elif len(active) > active_k:
                top_idx = np.argsort(c[active])[::-1][:active_k]
                active = active[top_idx]
            
            # Softmax weights over active set
            c_act = c[active]
            T_act = (c_act.max() - c_act.min()) * 0.1 + 1e-10
            w = np.exp((c_act - c_act.max()) / T_act)
            w = w / w.sum()
            
            grad = np.zeros(n)

                if w[idx] < 1e-6:

                    # Contribution to grad[j] = w[idx] * (a[k-j] + a[j-k])
                    # First term: a[k-j] is non-zero when 0 <= k-j < n, i.e., k-n+1 <= j <= k

                        # a[j-k] for j = j2_lo, ..., j2_hi
                        # = a[j2_lo-k], a[j2_lo-k+1], ..., a[j2_hi-k]
                        grad[j2_lo:j2_hi+1] += w[idx] * a[j2_lo-k:j2_hi-k+1]
        else:
            # Smoothed gradient via FFT
            grad, p = _smoothed_grad_fft(a, c, T)
        
        if not np.all(np.isfinite(grad)):
            grad = np.zeros(n)
        
        # Project to tangent space of simplex (subtract weighted mean)
        W = float(np.dot(a, grad))
        z_grad = a * (grad - W)
        
        if not np.all(np.isfinite(z_grad)):
            z_grad = np.zeros(n)
        
        m_buf = b1 * m_buf + (1.0 - b1) * z_grad
        v_buf = b2 * v_buf + (1.0 - b2) * (z_grad * z_grad)
        mh = m_buf / (1.0 - b1 ** t)
        vh = v_buf / (1.0 - b2 ** t)
        update = cur_lr * mh / (np.sqrt(vh) + eps)
        
        # Clip update norm
        update_norm = np.linalg.norm(update)
        if update_norm > 0.5:
            update = update * (0.5 / update_norm)
        
        z_new = z - update
        z_new = np.clip(z_new, -60.0, 60.0)
        z_new = z_new - z_new.mean()
        z = z_new
        
        # Check score periodically
        if t % eval_interval == 0:
            a_cur = _softmax_stable(z)
            sc = _score_unnormalized(a_cur)
            if sc < best_score:
                best_score = sc
                best_a = a_cur.copy()
                patience = 0
            else:
                patience += 1
            
            if patience > 15:
                lr_mult *= 0.7
                patience = 0
                if lr_mult < 0.05:
                    # Restart from best with perturbation
                    z = np.log(np.maximum(best_a, 1e-15))
                    z = z - z.mean()
                    z += 0.02 * np.random.randn(n)
                    z = z - z.mean()
                    m_buf = np.zeros(n)
                    v_buf = np.zeros(n)
                    lr_mult = 0.5
    
    a_final = _softmax_stable(z)
    sc_final = _score_unnormalized(a_final)
    if sc_final < best_score:
        best_score = sc_final
        best_a = a_final.copy()
    return best_a, best_score

def _peak_shaving(a, deadline, max_iters=10000):
    """Iteratively shave the highest peaks of the convolution."""
    n = len(a)
    a = a.copy() / a.sum()
    best_a = a.copy()
    best_score = _score_unnormalized(a)
    lr = 0.01
    
    for it in range(max_iters):
        if time.monotonic() > deadline:
            break
        
        c = _fft_convolve(a, a)
        c_max = float(c.max())
        
        # Find all peaks above threshold
        threshold = c_max * 0.995
        peaks = np.where(c >= threshold)[0]
        
        # Compute subgradient (average over peaks)
        grad = np.zeros(n)
        for k in peaks:
            # db[k]/da[j] = a[k-j] + a[j-k]
            j1_lo = max(0, k - n + 1)
            j1_hi = min(n - 1, k)
            if j1_lo <= j1_hi:
                grad[j1_lo:j1_hi+1] += a[k-j1_hi:k-j1_lo+1]
            j2_lo = max(0, k)
            j2_hi = min(n - 1, k + n - 1)
            if j2_lo <= j2_hi:
                grad[j2_lo:j2_hi+1] += a[j2_lo-k:j2_hi-k+1]
        
        grad /= len(peaks)
        
        # Project to tangent space
        W = float(np.dot(a, grad))
        grad_t = grad - W * a  # This keeps sum(a) approximately constant
        
        # Actually, for the simplex, the tangent projection is:
        # grad_t = grad - (sum(grad) / n) * ones
        # But we also want to maintain a >= 0.
        # Let's use the simpler projection:
        grad_t = grad - np.mean(grad)
        
        g_norm = np.linalg.norm(grad_t)
        if g_norm < 1e-15:
            break
        
        a_new = a - lr * grad_t / g_norm
        a_new = np.maximum(0, a_new)
        s = a_new.sum()
        if s < 1e-15:
            break
        a_new /= s
        
        sc = _score_unnormalized(a_new)
        if sc < best_score:
            best_score = sc
            best_a = a_new.copy()
            a = a_new
            lr = min(lr * 1.001, 0.05)
        else:
            lr *= 0.95
            if lr < 1e-6:
                break
    
    return best_a, best_score

def _lp_refinement(a, deadline, max_rounds=10):
    """Use LP direction finding to refine the sequence."""
    n = len(a)
    a = a.copy() / a.sum()
    best_a = a.copy()
    best_score = _score_unnormalized(a)
    
    for round_num in range(max_rounds):
        if time.monotonic() > deadline:
            break
        
        c = _fft_convolve(a, a)
        M = float(c.max())
        
        # Find LP direction
        g = _lp_direction(a, M, deadline)
        if g is None:
            break
        
        # Try different blending parameters
        improved = False
        for t in [0.3, 0.2, 0.1, 0.05, 0.02]:
            a_cand = (1 - t) * a + t * g
            a_cand = np.maximum(0, a_cand)
            s = a_cand.sum()
            if s < 1e-15:
                continue
            a_cand /= s
            sc = _score_unnormalized(a_cand)
            if sc < best_score:
                best_score = sc
                best_a = a_cand.copy()
                a = a_cand
                improved = True
                break
        
        if not improved:
            # Try smaller t
            for t in [0.01, 0.005, 0.001]:
                a_cand = (1 - t) * a + t * g
                a_cand = np.maximum(0, a_cand)
                s = a_cand.sum()
                if s < 1e-15:
                    continue
                a_cand /= s
                sc = _score_unnormalized(a_cand)
                if sc < best_score:
                    best_score = sc
                    best_a = a_cand.copy()
                    a = a_cand
                    improved = True
                    break
        
        if not improved:
            break
        
        print(f"    LP round {round_num}: score={best_score:.10f}")
    
    return best_a, best_score
