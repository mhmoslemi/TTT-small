Peak-targeting gradient optimizer with frequency-domain flattening
and multi-scale n exploration for minimizing 2*n*max(conv(a,a))/sum(a)^2.
"""

import time
from scipy.optimize import minimize

def _next_pow2(n):
    k = 1
    while k < n:
        k <<= 1
    return max(2, k)

def _full_convolve(a, b):
    n, m = len(a), len(b)
    out_n = n + m - 1
    N = _next_pow2(out_n)
    fa = np.fft.rfft(a, N)
    fb = np.fft.rfft(b, N)
    r = np.fft.irfft(fa * fb, N)[:out_n]
    return r

    n = len(a)
    s = float(a.sum())
    if s < 1e-15:
        return np.inf
    c = _full_convolve(a, a)
    return float(2.0 * n * c.max() / (s * s))

def _simplex_project(v, s=1.0):
    n = len(v)
    if n == 0:
        return v.copy()
    u = np.sort(v)[::-1]
    cv = np.cumsum(u)
    rho = np.arange(1, n + 1)[u * np.arange(1, n + 1) > (cv - s)]
    if len(rho) == 0:
        return np.full(n, s / n)
    rho = rho[-1]
    theta = (cv[rho - 1] - s) / rho
    return np.maximum(v - theta, 0.0)

    """Gradient of sum of top-k values of conv(a,a) w.r.t. a."""
    n = len(a)
    c = _full_convolve(a, a)
    top_idx = np.argsort(c)[::-1][:k]
    grad = np.zeros(n)
    for j in top_idx:
        i_lo = max(0, j - (n - 1))
        i_hi = min(n - 1, j)

            jmi = j - i
            if 0 <= jmi < n:
                grad[i] += 2.0 * a[jmi]
                if i == jmi:
                    grad[i] -= a[jmi]

`= 2 * sum_{j in K} a_{j-m} * [0 <= j-m < n] - a_m * [2m in K] * [0 <= 2m < 2n-1]`

Let `S[m] = sum_{j in K} a_{j-m} * [0 <= j-m < n]`. This is the cross-correlation of the indicator of K with a, evaluated at m.

`S[m] = sum_{j in K, 0 <= j-m < n} a_{j-m}`

Let `k' = j - m`, so `j = k' + m`:
`S[m] = sum_{k': 0 <= k' < n, k'+m in K} a_{k'}`

This is: for each `k'` in `[0, n-1]`, add `a[k']` if `k' + m` is in K.

So `S[m] = sum_{k'=0}^{n-1} a[k'] * [k' + m in K]`

This can be computed as: create an array `indicator_K` of length `2n-1` where `indicator_K[j] = 1` if `j in K` and 0 otherwise. Then:
`S[m] = sum_{k'=0}^{n-1} a[k'] * indicator_K[k' + m]`

This is a "circulant" matrix-vector product, which can be computed with FFT.

But since k is small, the direct computation is fine:
For each j in K (|K| = k elements), for each m in [max(0, j-n+1), min(n-1, j)], add a[j-m] to S[m].

One more consideration: the `_simplex_project` function. I need to make sure it's correct.

The projection onto the simplex `{x : x >= 0, sum(x) = 1}` is:
1. Sort the components of v in descending order: `u_1 >= u_2 >= ... >= u_n`
2. Find the largest `rho` such that `u_rho + rho * lambda > 0` where `lambda = (1 - sum_{i=1}^{rho} u_i) / rho`
3. Set `x_i = max(v_i - lambda, 0)`

The standard algorithm:
```python
def _simplex_project(v, s=1.0):
    n = len(v)
    u = np.sort(v)[::-1]
    cv = np.cumsum(u)
    # Find rho: largest rho such that u[rho] + (s - cv[rho-1])/rho > 0
    # i.e., u[rho] * rho + s - cv[rho-1] > 0
    # i.e., rho * u[rho] > cv[rho-1] - s
    rho_candidates = np.where(u * np.arange(1, n+1) > (cv - s))[0]
    if len(rho_candidates) == 0:
        return np.full(n, s/n)
    rho = rho_candidates[-1] + 1  # 1-indexed
    theta = (cv[rho-1] - s) / rho
    return np.maximum(v - theta, 0.0)
```
