Instead of smoothing the max, use a "boustrophedon" approach:
1. Find the current maximum lag k*
2. Compute the gradient of (a*a)[k*] with respect to a
3. Take a step in the direction that reduces (a*a)[k*] while keeping (a*a)[k] <= (a*a)[k*] for all other k
4. Repeat

This is essentially what the active set Newton does, but with a simpler gradient step.

**Better approach: Use the "maximum principle" more aggressively**

At the optimum, the values (a*a)[k] for k in the active set should all be equal (to the max). So we can set up the equations:
(a*a)[k1] = (a*a)[k2] = ... = (a*a)[km] = t

This gives m equations in n+1 unknowns (n components of a plus t). Combined with sum a = 1 and a >= 0, we have a well-defined problem.

The challenge is choosing the right active set. My idea: start with a small active set (just the top few lags), solve the equations, then check if the solution is valid (i.e., all inactive lags are below t). If not, add the violating lag to the active set and repeat.

This is essentially the active set method, but I'll implement it more carefully.

**Implementation details:**

For the inner QP: min (1/m) sum_{k in S} (a*a)[k] s.t. sum a = 1, a >= 0

This is equivalent to: min a^T H a s.t. sum a = 1, a >= 0
where H = (1/m) sum_{k in S} H_k

The Hessian H is a symmetric Hankel matrix. For a Hankel matrix, we can use:
- FFT-based matrix-vector products (O(n log n))
- The matrix is symmetric, so CG converges in at most n steps (usually much fewer)

For the equality-constrained QP without inequality constraints:
min a^T H a s.t. 1^T a = 1
Solution: a = H^{-1} 1 / (1^T H^{-1} 1)

If this solution has all non-negative entries, great. Otherwise, we need to handle the bounds.

For handling bounds, I'll use a "shrinking" approach:
1. Solve the equality-constrained QP
2. If some a[i] < 0, set a[i] = 0 and remove i from the problem
3. Repeat until all a[i] >= 0

This is the standard active set method for QPs.

def _cg_solve_H(w, n, rhs, max_iter=500, tol=1e-14):
    """Solve H(w) x = rhs where H(w)[j1,j2] = W*delta(j1,j2) + w[j1+j2]"""
    x = np.zeros(n)
    r = rhs.copy()
    p = r.copy()
    rs = float(r @ r)
    rs0 = rs
    if rs0 < 1e-30:
        return x
    for i in range(max_iter):
        Hp = _hankel_matvec(p, w, n)
        pHp = float(p @ Hp)
        if abs(pHp) < 1e-30 or not np.isfinite(pHp):
            break
        alpha = rs / pHp
        x = x + alpha * p
        r = r - alpha * Hp
        rs_new = float(r @ r)
        if not np.isfinite(rs_new) or rs_new > rs * 1.01:
            x = x - alpha * p
            r = r + alpha * Hp
            break
        p = r + (rs_new / rs) * p
        rs = rs_new
        if rs < tol * tol * rs0:
            break
    return x

def _line_search(a, d, w, n, alpha_max=2.0):
    """Line search with non-negativity constraint."""
    c_cur = _selfconv(a)
    c_max_cur = float(c_cur.max())
    alpha = alpha_max
    best_alpha = 0
    best_val = np.inf
    
    for ls in range(60):
        a_try = a + alpha * d
        if np.any(a_try < 0):
            # Find max alpha that keeps a >= 0
            neg = a_try < 0
            if neg.any():
                alpha_max_valid = np.min(-a[neg] / d[neg]) if np.any(d[neg] < 0) else 0
                alpha = max(0, alpha_max_valid * 0.9)
            else:
                alpha *= 0.5
            if alpha < 1e-15:
                break
        s_try = float(a_try.sum())
        if s_try < 0.01:
            alpha *= 0.5
            if alpha < 1e-15:
                break
            continue
        a_try = a_try / s_try
        c_try = _selfconv(a_try)
        c_max_try = float(c_try.max())
        val = c_max_try
        if val < c_max_cur - 1e-15:
            best_alpha = alpha
            best_val = val
            break
        alpha *= 0.5
        if alpha < 1e-15:
            break
    if best_alpha > 0:
        a_new = a + best_alpha * d
        a_new = np.maximum(a_new, 0)
        s = a_new.sum()
        if s > 0.01:
            a_new = a_new / s
            return a_new, best_alpha
    return a, 0

def _make_weights(c, beta, n):
    """Create smooth weights from convolution values."""
    c_max = float(c.max())
    shifted = (c - c_max) / beta
    e = np.exp(np.clip(shifted, -700, 0))
    s = e.sum()
    if s < 1e-300:
        w = np.zeros_like(c)
        w[int(np.argmax(c))] = 1.0
    else:
        w = e / s
    return w

def _hard_weights(c, n, k_active=100):
    """Create hard active set weights (top k_active lags)."""
    w = np.zeros(2*n-1)
    sorted_idx = np.argsort(c)[::-1]
    # Find tolerance
    c_max = c[sorted_idx[0]]
    # Take all lags within tolerance of max
    tol = 0.01 * c_max
    active = c >= (c_max - tol)
    n_active = int(active.sum())
    if n_active < k_active:
        # Take top k_active
        active = np.zeros(2*n-1, dtype=bool)
        active[sorted_idx[:k_active]] = True
        n_active = k_active
    w[active] = 1.0 / n_active
    return w
