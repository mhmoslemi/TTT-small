The key issue with gradient-based methods is that they converge linearly (or sublinearly for subgradient methods). Near the optimum, the active set is small and fixed, so we can switch to a method that converges superlinearly.

**Superlinear convergence via active set QP**:
When the active set S is fixed, the problem locally becomes:
minimize max_{k in S} a^T T_k a
subject to sum(a) = 1, a >= 0

This is a smooth optimization problem (the max is smooth when all active lags are equal). The KKT conditions are:
- There exist multipliers λ_k >= 0, sum λ_k = 1, such that:
  sum_k λ_k * 2 * T_k a = μ * 1 (for the sum constraint)
  plus complementary slackness for a[j] >= 0.

This is a system of equations that we can solve iteratively (Newton's method on the KKT conditions).

**Newton's method on the KKT system**:
- Variables: a (n variables), λ (|S| multipliers), μ (1 multiplier for sum)
- Equations:
  1. sum_k λ_k * grad_k(a) - μ * 1 = 0 (n equations) [plus complementarity]
  2. c_k(a) = t for k in S (|S| equations) [all active lags equal]
  3. sum(a) = 1 (1 equation)
  4. sum(λ) = 1 (1 equation)

This is a nonlinear system. Newton's method on this system would converge quadratically.

But implementing this correctly is non-trivial. Let me use a simpler approach:

**Active set iteration**:
1. Fix the active set S.
2. Solve the equality-constrained problem: minimize c_k(a) for all k in S (all equal) subject to sum(a) = 1, a >= 0.
3. This is equivalent to finding a such that c_k(a) = c_l(a) for all k,l in S, and a is in the "critical" set (KKT conditions).
4. We can solve this by alternating:
   a. Given a, compute the "ideal" t = mean_{k in S} c_k(a).
   b. Find the direction d that equalizes c_k in the sense that c_k(a + αd) ≈ t for all k in S.
   c. This is a linear system: T_k d ≈ t - c_k(a) for k in S, where T_k d = grad_k(a) - (grad_k(a))^T a (projection to tangent space).
   d. Solve for d (least squares if overdetermined).
   e. Take a step: a_new = a + α * d, project onto simplex.
   f. Update active set.

This is essentially a Gauss-Newton method for the equalization problem.

Let me implement this. The linear system in step (c) is:
For k in S: grad_k(a)^T d ≈ t - c_k(a)
Additional constraint: 1^T d = 0 (to preserve sum(a))
Additional constraint: d >= -a (to maintain non-negativity) [handled by projection]

The matrix of the system is |S|+1 by n, and we want the minimum-norm solution.

For |S| = 5 and n = 8192, the system matrix is 6 x 8192, which is very wide. The minimum-norm solution is:

This is computationally cheap: A A^T is 6x6, and we can compute A^T (A A^T)^{-1} b in O(n * |S|^2).
