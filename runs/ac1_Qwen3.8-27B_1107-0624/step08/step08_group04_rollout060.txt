**Spectral method**:
- DFT a to get A (with zero-padding to size N >= 2n-1).
- The circular autocorrelation R_circ = IFFT(|A|^2).
- We want R_circ to be as flat as possible (except for the main lobe).
- In the frequency domain, |A|^2 should be as flat as possible.
- Constraint: |A|^2 >= 0, and A must be the DFT of a non-negative, real sequence.

This is a non-convex problem in the frequency domain. But we can use iterative methods:
1. Compute |A|^2.
2. Modify |A|^2 to be flatter (e.g., replace with sqrt(|A|^2 * target_level) or similar).
3. Inverse DFT to get a new a.
4. Project a onto a >= 0 (set negative values to 0).
5. Repeat.

This is similar to the "gerchberg-saxton" or "error reduction" algorithm used in phase retrieval.

Let me try to formalize this:

**Spectral balancing algorithm**:
1. Initialize a (e.g., from the parent).
2. Loop:
   a. Compute A = FFT(a, N) where N >= 2n-1.
   b. Compute P = |A|^2 (power spectrum).
   c. Compute the "target" power spectrum: T = sum(P) / N (flat spectrum).
   d. Blend: P_new = (1-alpha) * P + alpha * T. (Or use a smoother blend.)
   e. Update: A_new = A * sqrt(P_new / P) (adjust amplitudes while keeping phases).
   f. a_new = IFFT(A_new)[:n].
   g. Project: a_new = max(a_new, 0).
   h. Normalize: a_new = a_new / sum(a_new).
   i. Check convergence.

This is essentially the " hybrid input-output" (HIO) algorithm from phase retrieval, adapted for our problem.

The advantage is that each iteration is O(N log N) (two FFTs), and it might converge to a flat autocorrelation.

Let me think about whether this would work well...

The issue is that the "flat target" T = sum(P)/N might not be achievable because of the constraint a >= 0. The projection onto a >= 0 will introduce ripples in the spectrum.

A better target might be: T[k] = max(P[k], T_min) where T_min is some floor. Or use a "water-filling" approach: raise the low-frequency components and lower the high-frequency ones.

Actually, for the autocorrelation to be flat, we need |A[k]|^2 to be constant (for circular autocorrelation). So the target is |A[k]|^2 = C for all k. The constraint is that a = IFFT(A) must be non-negative.

This is exactly the "flat spectrum" problem. The algorithm above should work, but the convergence might be slow.

Let me combine this with the time-domain approach:

**Combined algorithm**:
1. Start from the parent sequence.
2. Alternate between:
   a. Spectral balancing (a few iterations).
   b. Time-domain subgradient (a few iterations).
   c. QP refinement (if time permits).
3. Monitor the score and keep the best.

Let me now write the code. I'll focus on:
1. Using the parent as a starting point.
2. A spectral balancing method (new idea).
3. An improved subgradient method with adaptive step size.
4. A QP refinement using the active-set approach.
5. Multi-scale exploration.

Let me also think about the time budget:
- 1800 seconds total.
- Reserve 20 seconds for final evaluation.
- So 1780 seconds for optimization.

For n = 16384:
- FFT of size 32768: ~0.1ms
- Convolution (via FFT): ~0.3ms
- Score computation: ~0.5ms
- Subgradient step (one iteration): ~1ms

So we can do:

- ~1,000,000 spectral iterations in 1800s.
- ~1000 CG solves (each with 1000 iterations) in 1800s.

That's plenty of iterations. The key is choosing the right algorithm and hyperparameters.

"""
Multi-method optimizer for flat-top autocorrelation problem:
Combines spectral balancing (Gerchberg-Saxton style), adaptive subgradient,
active-set QP with preconditioned CG, and multi-scale exploration.
"""
import numpy as np
import time
from scipy.optimize import minimize

def _next_pow2(n):
    k = 1
    while k < n:
        k <<= 1
    return max(2, k)

def _full_convolve(a, b):
    n, m = len(a), len(b)
    out_n = n + m - 1
    N = _next_pow2(out_n)
    fa = np.fft.rfft(a, N)
    fb = np.fft.rfft(b, N)
    r = np.fft.irfft(fa * fb, N)[:out_n]
    return r

def _score(a):
    n = len(a)
    s = float(a.sum())
    if s < 1e-15:
        return np.inf
    c = _full_convolve(a, a)
    return float(2.0 * n * c.max() / (s * s))

def _softmax(z):
    z = z - np.max(z)
    e = np.exp(np.clip(z, -700, 700))
    s = e.sum()
    if s < 1e-300:
        return np.ones_like(z) / len(z)
    return e / s

def _hankel_matvec(v, W, n):
    V = v[::-1]
    out_len = len(V) + len(W) - 1
    N = _next_pow2(out_len)
    F_V = np.fft.rfft(V, N)
    F_W = np.fft.rfft(W, N)
    conv = np.fft.irfft(F_V * F_W, N)[:out_len]
    return 2.0 * conv[n - 1:2 * n - 1]

def _cg_solve(W, n, rhs, max_iter=500, tol=1e-12, preconditioner=None):
    x = np.zeros(n)
    if preconditioner is None:
        # Compute diagonal for Jacobi preconditioning
        e_diag = _hankel_matvec(np.eye(n)[:, 0], W, n)  # first column
        # Actually, for Hankel H[i,j] = 2*W[i+j], H[i,i] = 2*W[2i]
        diag = 2.0 * W[2 * np.arange(n)]
        diag = np.maximum(diag, 1e-30)
        preconditioner = 1.0 / diag
    
    r = rhs.copy()
    z = preconditioner * r
    p = z.copy()
    rz = float(r @ z)
    rz0 = rz
    if rz0 < 1e-30:
        return x
    for i in range(max_iter):
        Hp = _hankel_matvec(p, W, n)
        pHp = float(p @ Hp)
        if abs(pHp) < 1e-30 or not np.isfinite(pHp):
            break
        alpha = rz / pHp
        x = x + alpha * p
        r = r - alpha * Hp
        z_new = preconditioner * r
        rz_new = float(r @ z_new)
        if not np.isfinite(rz_new) or abs(rz_new) < 1e-30:
            break
        beta = rz_new / rz
        p = z_new + beta * p
        rz = rz_new
        if abs(rz) < tol * tol * abs(rz0):
            break
    return x

def _spectral_balance(a, deadline, max_iters=5000, alpha_init=0.5, alpha_decay=0.9999, min_time_remaining=10.0):
    """Balance the power spectrum to flatten the autocorrelation."""
    n = len(a)
    N = _next_pow2(2 * n - 1)
    a = a.copy()
    s = a.sum()
    if s < 1e-15:
        return a
    a = a / s
    best_a = a.copy()
    best_sc = _score(a)
    
    alpha = alpha_init
    patience = 0
    
    for it in range(max_iters):
        if time.monotonic() + min_time_remaining > deadline:
            break
        
        # FFT
        A = np.fft.rfft(a, N)
        P = np.abs(A) ** 2
        
        # Target: flat spectrum
        P_mean = P.sum() / len(P)
        
        # Blend towards flat
        P_new = (1 - alpha) * P + alpha * P_mean
        
        # Update amplitudes, keep phases
        phase = np.angle(A)
        amp = np.sqrt(P_new)
        A_new = amp * np.exp(1j * phase)
        
        # Inverse FFT
        a_new = np.fft.irfft(A_new, N)[:n]
        
        # Project onto a >= 0
        a_new = np.maximum(a_new, 0)
        s_new = a_new.sum()
        if s_new < 1e-15:
            break
        a_new = a_new / s_new
        
        # Check score
        if it % 50 == 0:
            sc = _score(a_new)
            if sc < best_sc - 1e-14:
                best_sc = sc
                best_a = a_new.copy()
                patience = 0
            else:
                patience += 1
                if patience > 20:
                    # Reset to best and reduce alpha
                    a_new = best_a.copy()
                    alpha *= 0.5
                    patience = 0
        
        a = a_new
        alpha = max(alpha * alpha_decay, 0.01)
    
    return best_a

def _adaptive_subgradient(a_init, deadline, max_steps=20000, min_time_remaining=10.0):
    """Adaptive subgradient with momentum and automatic step size."""
    n = len(a_init)
    a = a_init.copy()
    s = a.sum()
    if s < 1e-15:
        return a
    a = a / s
    best_a = a.copy()
    best_sc = _score(a)
    
    # Momentum buffer
    v = np.zeros(n)
    beta_mom = 0.9
    
    # Adaptive step size
    step = 0.01
    step_min = 0.0001
    step_max = 0.1
    
    c_max_ema = None
    
    for it in range(max_steps):
        if time.monotonic() + min_time_remaining > deadline:
            break
        
        c = _full_convolve(a, a)
        c_max = float(c.max())
        
        if c_max_ema is None:
            c_max_ema = c_max
        else:
            c_max_ema = 0.99 * c_max_ema + 0.01 * c_max
        
        # Active set: correlations above mean
        c_mean = c.sum() / len(c)
        excess = np.maximum(c - c_mean, 0)
        excess_max = excess.max()
        if excess_max < 1e-15:
            break
        
        # Normalize excess
        w = excess / excess_max
        
        # Gradient: d/d(a_i) sum_k w[k] * c[k]
        a_rev = a[::-1]
        wc = _full_convolve(w, a_rev)
        grad = wc[n - 1:2 * n - 1]
        
        # Also add a term to maintain positivity (repulsive force at 0)
        grad = grad + 0.01 * a  # small regularization
        
        # Momentum update
        v = beta_mom * v - step * grad
        a_new = a + v
        
        # Project onto simplex (a >= 0, sum a = 1)
        a_new = np.maximum(a_new, 0)
        s_new = a_new.sum()
        if s_new < 1e-15:
            a_new = a.copy()
        else:
            a_new = a_new / s_new
        
        # Adaptive step size
        sc_new = _score(a_new)
        if sc_new < best_sc * (1 - 1e-10):
            # Good step, maybe increase
            step = min(step * 1.05, step_max)
        elif sc_new > best_sc * (1 + 0.01):
            # Bad step, decrease
            step = max(step * 0.7, step_min)
            a_new = a  # reject step
        
        a = a_new
        
        if it % 100 == 0:
            sc = _score(a)
            if sc < best_sc - 1e-14:
                best_sc = sc
                best_a = a.copy()
    
    sc_final = _score(a)
    if sc_final < best_sc:
        best_sc = sc_final
        best_a = a.copy()
    return best_a

def _lbfgs_smoothed(a_init, deadline, betas=None, min_time_remaining=10.0):
    """L-BFGS with log-sum-exp smoothing."""
    n = len(a_init)
    
    if betas is None:
        c = _full_convolve(a_init, a_init)
        c_max = float(c.max())
        c_sorted = np.sort(c)[::-1]
        gap = c_sorted[0] - c_sorted[min(50, len(c_sorted) - 1)]
        base_beta = max(gap * 0.3, c_max * 0.002)
        ratios = np.array([1.0, 0.5, 0.25, 0.1, 0.05, 0.025, 0.01, 0.005,
                           0.0025, 0.001, 0.0005, 0.00025, 0.0001, 0.00005])
        betas = base_beta * ratios
    
    z = np.log(np.maximum(a_init, 1e-30))
    z = z - z.mean()
    
    best_a = a_init.copy()
    best_sc = _score(a_init)
    
    for beta in betas:
        if time.monotonic() + min_time_remaining > deadline:
            break
        
        # Define objective and gradient
        def obj(z_local):
            a = _softmax(z_local)
            c = _full_convolve(a, a)
            c_max = float(c.max())
            shifted = (c - c_max) / beta
            e = np.exp(np.clip(shifted, -700, 0))
            s = e.sum()
            if s < 1e-300:
                return 2.0 * n * c_max
            return 2.0 * n * (c_max + beta * np.log(s))
        
        def grad(z_local):
            a = _softmax(z_local)
            c = _full_convolve(a, a)
            c_max = float(c.max())
            shifted = (c - c_max) / beta
            e = np.exp(np.clip(shifted, -700, 0))
            s = e.sum()
            if s < 1e-300:
                w = np.zeros_like(c)
                w[int(np.argmax(c))] = 1.0
            else:
                w = e / s
            a_rev = a[::-1]
            wc = _full_convolve(w, a_rev)
            h = wc[n - 1:2 * n - 1]
            W_val = float(np.dot(w, c))
            return 4.0 * n * a * (h - W_val)
        
        remaining = deadline - min_time_remaining - time.monotonic()
        if remaining < 2:
            break
        max_iter = min(3000, max(30, int(remaining / 0.01)))
        
        try:
            result = minimize(
                obj, z, jac=grad, method='L-BFGS-B',
                options={'maxiter': max_iter, 'ftol': 1e-18, 'gtol': 1e-14,
                         'maxcor': 50, 'maxls': 100}
            )
            a_new = _softmax(result.x)
            sc_new = _score(a_new)
            if sc_new < best_sc - 1e-15:
                best_sc = sc_new
                best_a = a_new.copy()
                z = np.log(np.maximum(a_new, 1e-30))
                z = z - z.mean()
        except Exception:
            pass
    
    return best_a

def _active_set_qp(a_init, deadline, max_rounds=100, min_time_remaining=10.0):
    """Active-set QP with progressive tightening."""
    n = len(a_init)
    a = a_init.copy()
    a = np.maximum(a, 0)
    s = a.sum()
    if s < 1e-15:
        return a
    a = a / s
    best_a = a.copy()
    best_sc = _score(a)
    
    tol_schedule = [0.005, 0.002, 0.001, 0.0005, 0.0002, 0.0001,
                    0.00005, 0.00002, 0.00001, 0.000005, 0.000002, 0.000001]
    tol_idx = 0
    rounds_per_tol = 8
    
    for rnd in range(max_rounds):
        if time.monotonic() + min_time_remaining > deadline:
            break
        
        c = _full_convolve(a, a)
        c_max = float(c.max())
        tol = tol_schedule[min(tol_idx, len(tol_schedule) - 1)]
        active = c >= (c_max - tol * c_max)
        if active.sum() == 0:
            active[int(np.argmax(c))] = True
        n_active = int(active.sum())
        
        W = np.zeros(2 * n - 1)
        W[active] = 1.0 / n_active
        
        # Solve QP on active set
        # Try full support first
        y = _cg_solve(W, n, np.ones(n), max_iter=400, tol=1e-12)
        oney = float(np.sum(y))
        if abs(oney) > 1e-20 and np.isfinite(oney):
            a_qp = y / oney
            a_qp = np.maximum(a_qp, 0)
            s_qp = a_qp.sum()
            if s_qp > 1e-15:
                a_qp = a_qp / s_qp
                sc_qp = _score(a_qp)
                if sc_qp < best_sc - 1e-14:
                    best_sc = sc_qp
                    best_a = a_qp.copy()
                    a = a_qp.copy()
        
        # Also try: blend current with QP solution
        for t in [0.3, 0.5, 0.7]:
            a_blend = (1 - t) * a + t * best_a
            a_blend = np.maximum(a_blend, 0)
            s_blend = a_blend.sum()
            if s_blend > 1e-15:
                a_blend = a_blend / s_blend
                sc_blend = _score(a_blend)
                if sc_blend < best_sc - 1e-14:
                    best_sc = sc_blend
                    best_a = a_blend.copy()
                    a = a_blend.copy()
        
        if (rnd + 1) % rounds_per_tol == 0:
            tol_idx += 1
        
        # Convergence check
        sc = _score(a)
        if sc < best_sc:
            best_sc = sc
            best_a = a.copy()
    
    return best_a

def _resample(a, n_new):
    n_old = len(a)
    x_old = np.linspace(0, 1, n_old)
    x_new = np.linspace(0, 1, n_new)
    a_new = np.interp(x_new, x_old, a)
    a_new = np.maximum(a_new, 0)
    s = a_new.sum()
    if s < 1e-15:
        return np.ones(n_new) / n_new
    return a_new / s

def _make_profile(n, kind="tapered"):
    if kind == "uniform":
        return np.ones(n) / n
    elif kind == "tapered":
        t = np.linspace(0, 1, n)
        a = np.sin(np.pi * t) ** 0.5
        a = np.maximum(a, 1e-10)
        return a / a.sum()
    elif kind == "cos":
        t = np.linspace(0, 1, n)
        a = 0.5 + 0.5 * np.cos(np.pi * t)
        a = np.maximum(a, 1e-10)
        return a / a.sum()
    elif kind == "centered":
        t = np.linspace(0, 1, n)
        a = np.exp(-4.0 * (t - 0.5) ** 2) + 0.01
        return a / a.sum()
    else:
        return np.ones(n) / n

def _next_pow2(n):
    k = 1
    while k < n:
        k <<= 1
    return max(2, k)


def _full_convolve(a, b):
    n, m = len(a), len(b)
    out_n = n + m - 1
    N = _next_pow2(out_n)
    fa = np.fft.rfft(a, N)
    fb = np.fft.rfft(b, N)
    r = np.fft.irfft(fa * fb, N)[:out_n]
    return r


def _score(a):
    n = len(a)
    s = float(a.sum())
    if s < 1e-15:
        return np.inf
    c = _full_convolve(a, a)
    return float(2.0 * n * c.max() / (s * s))


def _softmax(z):
    z = z - np.max(z)
    e = np.exp(np.clip(z, -700, 700))

def _hankel_matvec(v, W, n):
    V = v[::-1]
    out_len = len(V) + len(W) - 1
    N = _next_pow2(out_len)
    F_V = np.fft.rfft(V, N)
    F_W = np.fft.rfft(W, N)
    conv = np.fft.irfft(F_V * F_W, N)[:out_len]
    return 2.0 * conv[n - 1:2 * n - 1]


def _cg_solve(W, n, rhs, max_iter=500, tol=1e-12):
    x = np.zeros(n)
    r = rhs.copy()
    diag = 2.0 * W[2 * np.arange(n)]

    prec = 1.0 / diag
    z = prec * r

    rz = float(r @ z)

        return x
    for i in range(max_iter):
        Hp = _hankel_matvec(p, W, n)
        pHp = float(p @ Hp)

        r = r_new
        z = z_new

    best_a = a.copy()
    best_sc = _score(a)
    tol_schedule = [0.01, 0.005, 0.002, 0.001, 0.0005, 0.0002,
                    0.0001, 0.00005, 0.00002, 0.00001, 0.000005,
                    0.000002, 0.000001]
    tol_idx = 0
    rounds_per_tol = 6
    for rnd in range(max_rounds):
        if time.monotonic() + min_time_remaining > deadline:
            break
        c = _full_convolve(a, a)
        c_max = float(c.max())
        tol = tol_schedule[min(tol_idx, len(tol_schedule) - 1)]
        active = c >= (c_max - tol * c_max)
        if active.sum() == 0:
            active[int(np.argmax(c))] = True
        n_active = int(active.sum())
        W = np.zeros(2 * n - 1)
        W[active] = 1.0 / n_active
        # Solve QP: min a^T H a s.t. sum(a)=1, a>=0
        # KKT on full support: H*a = lambda*1, 1^T a = 1
        y = _cg_solve(W, n, np.ones(n), max_iter=500, tol=1e-12)
        oney = float(np.sum(y))
        if abs(oney) > 1e-20 and np.isfinite(oney) and oney > 0:
            a_qp = y / oney
            a_qp = np.maximum(a_qp, 0)
            s_qp = a_qp.sum()
            if s_qp > 1e-15:
                a_qp = a_qp / s_qp
                sc_qp = _score(a_qp)
                if sc_qp < best_sc - 1e-14:
                    best_sc = sc_qp
                    best_a = a_qp.copy()
                    a = a_qp.copy()
                # Also try blends
                for t in [0.3, 0.5, 0.7, 0.9]:
                    a_blend = (1.0 - t) * a + t * a_qp
                    a_blend = np.maximum(a_blend, 0)
                    s_b = a_blend.sum()
                    if s_b > 1e-15:
                        a_blend = a_blend / s_b
                        sc_b = _score(a_blend)
                        if sc_b < best_sc - 1e-14:
                            best_sc = sc_b
                            best_a = a_blend.copy()
                            a = a_blend.copy()
        # Damped Newton step fallback
        g = _hankel_matvec(a, W, n)
        g_centered = g - g.mean()
        gn = float(np.linalg.norm(g_centered))
        if gn > 1e-14:
            Hg = _cg_solve(W, n, g, max_iter=300, tol=1e-11)
            H1 = _cg_solve(W, n, np.ones(n), max_iter=300, tol=1e-11)
            H1_sum = float(np.sum(H1))
            if abs(H1_sum) > 1e-20:
                lam = float(np.sum(Hg)) / H1_sum
                dx = -Hg + lam * H1
                dx = dx - dx.mean()
            else:
                dx = -g_centered / gn
            dx_norm = float(np.linalg.norm(dx))
            if dx_norm > 1e-15:
                dx = dx / dx_norm * gn
                for ls in range(30):
                    alpha_ls = min(1.0, 0.1 / (gn / max(dx_norm, 1e-15)))
                    a_try = a + alpha_ls * dx
                    a_try = np.maximum(a_try, 0)
                    s_try = a_try.sum()
                    if s_try < 1e-15:
                        alpha_ls *= 0.5
                        continue
                    a_try = a_try / s_try
                    sc_try = _score(a_try)
                    if sc_try < best_sc * 0.9999:
                        a = a_try
                        if sc_try < best_sc:
                            best_sc = sc_try
                            best_a = a_try.copy()
                        break
                    alpha_ls *= 0.5
                    if alpha_ls < 1e-10:
                        break
        if (rnd + 1) % rounds_per_tol == 0:
            tol_idx += 1
        sc = _score(a)
        if sc < best_sc:
            best_sc = sc
            best_a = a.copy()
    return best_a


def _flatten_direct(a_init, deadline, max_iters=500, min_time_remaining=10.0):
    """Direct gradient on (sum of squared excess correlations)."""
    n = len(a_init)
    a = a_init.copy()
    a = np.maximum(a, 0)
    a = a / a.sum()
    best_a = a.copy()
    best_sc = _score(a)
    step = 0.05
    for it in range(max_iters):
        if time.monotonic() + min_time_remaining > deadline:
            break
        c = _full_convolve(a, a)
        c_mean = c.sum() / len(c)
        c_max = float(c.max())
        excess = np.maximum(c - c_mean, 0)
        excess_max = excess.max()
        if excess_max < 1e-15:
            break
        w = excess / excess_max
        a_rev = a[::-1]
        wc = _full_convolve(w, a_rev)
        grad = wc[n - 1:2 * n - 1]
        a_new = a - step * grad
        a_new = np.maximum(a_new, 0)
        s_new = a_new.sum()
        if s_new < 1e-15:
            step *= 0.5
            continue
        a_new = a_new / s_new
        sc_new = _score(a_new)
        if sc_new < best_sc:
            best_sc = sc_new
            best_a = a_new.copy()
            a = a_new
            step = min(step * 1.02, 0.1)
        else:
            a = 0.5 * a + 0.5 * a_new
            a = np.maximum(a, 0)
            a = a / a.sum()
            step *= 0.7
            if step < 0.001:
                break
    return best_a


def _resample(a, n_new):
    n_old = len(a)
    x_old = np.linspace(0, 1, n_old)
    x_new = np.linspace(0, 1, n_new)
    a_new = np.interp(x_new, x_old, a)
    a_new = np.maximum(a_new, 0)
    s = a_new.sum()
    if s < 1e-15:
        return np.ones(n_new) / n_new
    return a_new / s


def _make_profile(n, kind="tapered"):
    if kind == "uniform":
        return np.ones(n) / n
    elif kind == "tapered":
        t = np.linspace(0, 1, n)
        a = np.sin(np.pi * t) ** 0.5
        a = np.maximum(a, 1e-10)
        return a / a.sum()
    elif kind == "cos":
        t = np.linspace(0, 1, n)
        a = 0.5 + 0.5 * np.cos(np.pi * t)
        a = np.maximum(a, 1e-10)
        return a / a.sum()
    elif kind == "centered":
        t = np.linspace(0, 1, n)
        a = np.exp(-4.0 * (t - 0.5) ** 2) + 0.01
        return a / a.sum()
    else:
        return np.ones(n) / n


def _perturb(a, sigma, rng):
    n = len(a)
    z = np.log(np.maximum(a, 1e-30))
    z = z + sigma * rng.standard_normal(n)
    z = z - z.mean()
    return _softmax(z)


def propose_candidate(seed=42, budget_s=1800):
    """
    Multi-method optimizer: spectral balancing, adaptive subgradient,
    L-BFGS smoothing, active-set QP, direct flattening, and multi-scale.
    """
    t_start = time.monotonic()
    deadline = t_start + max(1.0, float(budget_s) - 20.0)
    rng = np.random.default_rng(int(seed) % (2**63 - 1))
    best_seq = None
    best_score = np.inf

    def update_best(p, sc=None, label=""):
        nonlocal best_seq, best_score
        if p is None:
            return
        p = np.asarray(p, dtype=np.float64).ravel()
        p = np.clip(p, 0.0, 1000.0)
        s = float(p.sum())
        if s < 0.01:
            return
        if sc is None:
            sc = _score(p)
        if np.isfinite(sc) and sc < best_score:
            prev = best_score
            best_seq = p.copy()
            best_score = float(sc)
            print(f"  NEW BEST: {best_score:.10f} (n={len(p)}) [{label}] "
                  f"improve={prev - best_score:.2e} t={time.monotonic() - t_start:.1f}s")

    # Load parent
    parent = None
    n_parent = 0
    try:
        parent_raw = np.asarray(height_sequence_1, dtype=np.float64).ravel()
        if parent_raw.size > 0:
            parent_raw = np.clip(parent_raw, 0.0, 1000.0)
            s = float(parent_raw.sum())
            if s > 0.01:
                parent = parent_raw / s
                n_parent = len(parent)
                par_sc = _score(parent)
                print(f"Parent: n={n_parent}, score={par_sc:.10f}")
                update_best(parent, par_sc, "parent")
    except Exception:
        pass

    if parent is None:
        n_parent = 16384
        parent = _make_profile(n_parent, "tapered")
        update_best(parent, _score(parent), "init")

    n_opt = len(best_seq) if best_seq is not None else n_parent

    # Phase 1: L-BFGS from parent (establish a good baseline)
    print(f"\n[Phase 1] L-BFGS from parent (n={n_opt}, t={time.monotonic()-t_start:.1f}s)")
    a1 = _lbfgs_smoothed(best_seq, deadline, min_time_remaining=700.0)
    update_best(a1, _score(a1), "lbfgs_1")

    # Phase 2: Spectral balancing (new method)
    print(f"\n[Phase 2] Spectral balancing (t={time.monotonic()-t_start:.1f}s)")
    if best_seq is not None and time.monotonic() < deadline - 500:
        a2 = _spectral_balance(best_seq, deadline, max_iters=4000, alpha_init=0.35,
                               alpha_decay=0.9997, min_time_remaining=300.0)
        update_best(a2, _score(a2), "spectral_1")

    # Phase 3: Adaptive subgradient
    print(f"\n[Phase 3] Adaptive subgradient (t={time.monotonic()-t_start:.1f}s)")
    if best_seq is not None and time.monotonic() < deadline - 400:
        a3 = _adaptive_subgradient(best_seq, deadline, max_steps=20000, min_time_remaining=250.0)
        update_best(a3, _score(a3), "subgrad_1")

    # Phase 4: L-BFGS round 2 (from improved point)
    print(f"\n[Phase 4] L-BFGS round 2 (t={time.monotonic()-t_start:.1f}s)")
    if best_seq is not None and time.monotonic() < deadline - 350:
        a4 = _lbfgs_smoothed(best_seq, deadline, min_time_remaining=200.0)
        update_best(a4, _score(a4), "lbfgs_2")

    # Phase 5: Active-set QP
    print(f"\n[Phase 5] Active-set QP (t={time.monotonic()-t_start:.1f}s)")
    if best_seq is not None and time.monotonic() < deadline - 300:
        a5 = _active_set_qp(best_seq, deadline, max_rounds=100, min_time_remaining=180.0)
        update_best(a5, _score(a5), "active_qp_1")

    # Phase 6: Direct flattening
    print(f"\n[Phase 6] Direct flattening (t={time.monotonic()-t_start:.1f}s)")
    if best_seq is not None and time.monotonic() < deadline - 250:
        a6 = _flatten_direct(best_seq, deadline, max_iters=300, min_time_remaining=150.0)
        update_best(a6, _score(a6), "flatten_1")

    # Phase 7: Spectral balancing v2
    print(f"\n[Phase 7] Spectral v2 (t={time.monotonic()-t_start:.1f}s)")
    if best_seq is not None and time.monotonic() < deadline - 200:
        a7 = _spectral_balance_v2(best_seq, deadline, max_iters=3000, min_time_remaining=120.0)
        update_best(a7, _score(a7), "spectral_v2")

    # Phase 8: Second round of subgradient + QP
    print(f"\n[Phase 8] Subgrad + QP round 2 (t={time.monotonic()-t_start:.1f}s)")
    if best_seq is not None and time.monotonic() < deadline - 150:
        a8a = _adaptive_subgradient(best_seq, deadline, max_steps=15000, min_time_remaining=80.0)
        update_best(a8a, _score(a8a), "subgrad_2")
        if best_seq is not None and time.monotonic() < deadline - 100:
            a8b = _active_set_qp(best_seq, deadline, max_rounds=80, min_time_remaining=60.0)
            update_best(a8b, _score(a8b), "active_qp_2")

    # Phase 9: Multi-scale exploration
    print(f"\n[Phase 9] Multi-scale (t={time.monotonic()-t_start:.1f}s)")
    n_candidates = [16384, 8192]
    for n_try in n_candidates:
        if time.monotonic() > deadline - 80:
            break
        if n_try == n_opt and best_seq is not None and len(best_seq) == n_try:
            continue
        if best_seq is not None:
            a_init = _resample(best_seq, n_try)
        else:
            a_init = _make_profile(n_try, "tapered")
        a_ms = _lbfgs_smoothed(a_init, deadline, min_time_remaining=40.0)
        update_best(a_ms, _score(a_ms), f"multiscale_n{n_try}")
        if time.monotonic() < deadline - 50:
            a_ms_qp = _active_set_qp(a_ms, deadline, max_rounds=40, min_time_remaining=30.0)
            update_best(a_ms_qp, _score(a_ms_qp), f"multiscale_n{n_try}_qp")

    # Phase 10: Final ultra-tight polish
    print(f"\n[Phase 10] Final polish (t={time.monotonic()-t_start:.1f}s)")
    if best_seq is not None and time.monotonic() < deadline - 10:
        a_fin = _active_set_qp(best_seq, deadline, max_rounds=60, min_time_remaining=3.0)
        update_best(a_fin, _score(a_fin), "final_qp")
        if time.monotonic() < deadline - 5:
            a_fl = _flatten_direct(best_seq, deadline, max_iters=200, min_time_remaining=3.0)
            update_best(a_fl, _score(a_fl), "final_flatten")
        if time.monotonic() < deadline - 3:
            a_sg = _adaptive_subgradient(best_seq, deadline, max_steps=5000, min_time_remaining=2.0)
            update_best(a_sg, _score(a_sg), "final_subgrad")

    # Final output
    print(f"\n{'=' * 60}")
    if best_seq is not None:
        final = np.clip(best_seq, 0.0, 1000.0)
        s = float(final.sum())
        if s < 0.01:
            final = _make_profile(256, "uniform")
        sc_final = _score(final)
        print(f"FINAL: score={sc_final:.10f}, n={len(final)}, time={time.monotonic()-t_start:.1f}s")
        return [float(x) for x in final]
    fallback = _make_profile(8192, "tapered")
    print(f"FALLBACK: score={_score(fallback):.6f}")
    return [float(x) for x in fallback]
