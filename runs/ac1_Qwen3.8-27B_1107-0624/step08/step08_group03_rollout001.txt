So f_unif = 2n * (1/n) = 2.

The theoretical minimum is 2n/(2n-1) ≈ 1, but as I showed earlier, this is unachievable with non-negative a.

The key insight is: we want the "middle" of the convolution (around lag n-1) to be small. For a = [p, q, q, p]:
conv[3] = 2p² + 2q² = 2(p² + q²)
With p + q = 1/2: p² + q² = p² + (1/2-p)² = 2p² - p + 1/4, minimized at p = 1/4, value 1/8.
So conv[3] = 2*(1/8) = 1/4 at the symmetric point. f = 8*(1/4) = 2.

But conv[2] = q² + 2p², which at p=1/8 is (3/8)² + 2*(1/8)² = 9/64 + 2/64 = 11/64 ≈ 0.172.
And conv[3] = 2*(1/64 + 9/64) = 20/64 = 5/16 = 0.3125.
f = 8*0.3125 = 2.5.
