**Prolate spheroidal wave functions (PSWF):**
The PSWF are the eigenfunctions of the time-frequency localization operator. The first PSWF has the property of being maximally concentrated in a given bandwidth. Its autocorrelation is also a PSWF and has a specific shape.

For our problem, we want a function whose autocorrelation is as flat as possible near zero lag (to minimize the peak). This is somewhat related but not exactly the same.

Actually, for the continuous problem: minimize `max |R_f(t)|` where `R_f(t) = ∫ f(s)f(s+t)ds` and `∫ f = 1`, `f >= 0`.

If f is a box function (uniform), then R_f is a triangle with peak 1/T (where T is the width). The "flatness" is poor.

If f is a sinc function (bandlimited), then R_f is also a sinc, which oscillates. The peak at t=0 is the energy, and it decays as 1/t.

The optimal for minimizing max |R_f| / (∫f)^2 is probably a function that's "as flat as possible" in the frequency domain, which would be a box in frequency = sinc in time. But sinc isn't non-negative.

For non-negative functions, the optimal might be a "raised cosine" or similar smooth non-negative function.

"""
Optimizer for minimizing 2*n*max(conv(a,a))/sum(a)^2.
Uses: L-BFGS with log-sum-exp, cyclic coordinate descent, momentum subgradient,
window-function initializations, and multiple n values.

import numpy as np
import time
from scipy.optimize import minimize


def _next_pow2(n):
    k = 1
    while k < n:
        k <<= 1
    return max(2, k)


def _full_convolve(a, b):
    n, m = len(a), len(b)
    out_n = n + m - 1
    N = _next_pow2(out_n)
    fa = np.fft.rfft(a, N)
    fb = np.fft.rfft(b, N)
    r = np.fft.irfft(fa * fb, N)[:out_n]
    return r


def _score(a):
    n = len(a)
    s = float(a.sum())
    if s < 1e-15:
        return np.inf
    c = _full_convolve(a, a)
    return float(2.0 * n * c.max() / (s * s))


def _softmax(z):
    z = z - np.max(z)
    e = np.exp(np.clip(z, -700, 700))
    s = e.sum()
    if s < 1e-300:
        return np.ones_like(z) / len(z)
    return e / s


def _lsobj(z, beta, n):
    a = _softmax(z)
    c = _full_convolve(a, a)
    c_max = float(c.max())
    shifted = (c - c_max) / beta
    e = np.exp(np.clip(shifted, -700, 0))
    s = e.sum()
    if s < 1e-300 or not np.isfinite(s):
        return 2.0 * n * c_max
    return 2.0 * n * (c_max + beta * np.log(s))


def _lsgrad(z, beta, n):
    a = _softmax(z)
    c = _full_convolve(a, a)
    c_max = float(c.max())
    shifted = (c - c_max) / beta
    e = np.exp(np.clip(shifted, -700, 0))
    s = e.sum()
    if s < 1e-300 or not np.isfinite(s):
        w = np.zeros_like(c)
        w[int(np.argmax(c))] = 1.0
    else:
        w = e / s
    a_rev = a[::-1]
    wc = _full_convolve(w, a_rev)
    h = wc[n - 1:2 * n - 1]
    W = float(np.dot(w, c))
    return 4.0 * n * a * (h - W)

    if max_c < 1e-15:
        return a_init

    c_sorted = np.sort(c_cur)[::-1]

`new_c[k] = c[k]` for k outside [i, i+n-1]

- Otherwise, find where f'(r) = 0 (or where the subgradient contains 0)

Optimizer for minimizing 2*n*max(conv(a,a))/sum(a)^2.
Key novel approach: Cyclic coordinate descent with exact 1D optimization,
combined with L-BFGS log-sum-exp, momentum subgradient, and multi-n exploration.

import numpy as np
import time
from scipy.optimize import minimize

_curr_beta = 1.0
_curr_n = 1


def _next_pow2(n):
    k = 1
    while k < n:
        k <<= 1
    return max(2, k)


def _full_convolve(a, b):
    n, m = len(a), len(b)
    out_n = n + m - 1
    N = _next_pow2(out_n)
    fa = np.fft.rfft(a, N)
    fb = np.fft.rfft(b, N)
    r = np.fft.irfft(fa * fb, N)[:out_n]
    return r


def _score(a):
    n = len(a)
    s = float(a.sum())
    if s < 1e-15:
        return np.inf
    c = _full_convolve(a, a)
    return float(2.0 * n * c.max() / (s * s))


def _softmax(z):
    z = z - np.max(z)
    e = np.exp(np.clip(z, -700, 700))
    s = e.sum()
    if s < 1e-300:
        return np.ones_like(z) / len(z)
    return e / s


def _lsobj(z, beta, n):
    a = _softmax(z)
    c = _full_convolve(a, a)
    c_max = float(c.max())
    shifted = (c - c_max) / beta
    e = np.exp(np.clip(shifted, -700, 0))
    s = e.sum()
    if s < 1e-300 or not np.isfinite(s):
        return 2.0 * n * c_max
    return 2.0 * n * (c_max + beta * np.log(s))


def _lsgrad(z, beta, n):
    a = _softmax(z)
    c = _full_convolve(a, a)
    c_max = float(c.max())
    shifted = (c - c_max) / beta
    e = np.exp(np.clip(shifted, -700, 0))
    s = e.sum()
    if s < 1e-300 or not np.isfinite(s):
        w = np.zeros_like(c)
        w[int(np.argmax(c))] = 1.0
    else:
        w = e / s
    a_rev = a[::-1]
    wc = _full_convolve(w, a_rev)
    h = wc[n - 1:2 * n - 1]
    W = float(np.dot(w, c))
    return 4.0 * n * a * (h -
