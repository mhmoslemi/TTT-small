**Alternative approach: Use the "moment problem" perspective.**

The convolution values c[k] = sum_i a[i]*a[k-i] are "moments" of the distribution a (in a generalized sense). We want to choose a (non-negative, sum=1) to minimize max(c).

This is related to the "truncated moment problem" and "positive definite sequences". A sequence c is the convolution of a non-negative sequence with itself if and only if the corresponding Toeplitz matrix is positive semidefinite and the sequence c satisfies certain conditions.

Specifically, c is "feasible" (i.e., c = a*a for some a >= 0) iff:
1. c[0] >= 0, c[2n-2] >= 0 (trivially true since they're squares)
2. The Toeplitz matrix T_c = [c[i-j]] is PSD (this is necessary for c to be a valid convolution of a with itself, by the positive definiteness of the associated kernel)
3. There exists a non-negative a such that a*a = c (this is the hard part)

Condition 3 is equivalent to: the "square root" of the Toeplitz matrix T_c exists and is non-negative. This is not easily characterized.

However, we can use a relaxation: minimize max(c) subject to T_c being PSD and c >= 0. This is an SDP relaxation. The optimal value of this SDP gives a lower bound on the true optimum.

For n = 16384, the SDP would have a 16384×16384 PSD matrix, which is too large for standard SDP solvers.

But for small n (e.g., n = 16, 32, 64), we could solve the SDP to get a lower bound and understand the structure.
