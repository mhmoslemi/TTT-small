3. This can be done by: a[m] <- a[m] * (C / (sum_{k in active} a[k-m]))^eta for some small eta.

This is the "equalization" idea: make the contributions from all peaks equal for each element.

Let me now write the code. I'll combine several approaches:

1. **Initialization**: Start from the parent sequence or a uniform sequence.
2. **Phase 1**: Use the LP-based SOTA approach (simplified) to make quick progress.
3. **Phase 2**: Use the equalization idea to fine-tune.
4. **Phase 3**: Use coordinate descent or other local methods for final polish.

```python
import numpy as np
import time

def _next_pow2(n):
    k = 1
    while k < n:
        k <<= 1
    return max(2, k)

def _fft_convolve(a, b):
    n, m = len(a), len(b)
    out_n = n + m - 1
    N = _next_pow2(out_n)
    fa = np.fft.rfft(a, N)
    fb = np.fft.rfft(b, N)
    return np.fft.irfft(fa * fb, N)[:out_n]

def _score(a):
    n = len(a)
    s = float(a.sum())
    if s < 1e-15:
        return np.inf
    c = _fft_convolve(a, a)
    return float(2.0 * n * c.max() / (s * s))

def _score_norm(a):
    """Assume a is normalized (sum=1). Returns 2n * max(c)."""
    n = len(a)
    c = _fft_convolve(a, a)
    return float(2.0 * n * c.max())
```

```python
def _solve_dual_lp(f, M):
    """
    Solve the dual LP:
    min M * sum(y)
    s.t. sum_{k=j}^{j+n-1} y[k] >= 1/f[j] for j=0,...,n-1
         y[k] >= 0
    
    Returns y (the dual variables) and the optimal dual objective value.
    Uses O(n) DP.
    """
    n = len(f)
    # S[k] = sum_{i=0}^{k} y[i], S[-1] = 0
    # Constraints:
    # S[k] >= S[k-1] (monotonicity)
    # S[j+n-1] >= S[j-1] + 1/f[j] for j=0,...,n-1
    # Minimize S[2n-2]
    
    # DP: dist[k] = minimum S[k] satisfying all constraints up to k
    dist = np.zeros(2*n-1)  # dist[k] = S[k]
    # dist[-1] = 0 implicitly
    
    for k in range(2*n-1):
        # Monotonicity: S[k] >= S[k-1]
        if k == 0:
            dist[k] = 0.0  # S[0] >= S[-1] = 0
        else:
            dist[k] = dist[k-1]
        
        # Sliding window constraint: S[j+n-1] >= S[j-1] + 1/f[j]
        # This constraint involves S[k] when j+n-1 = k, i.e., j = k-n+1
        if k >= n-1:
            j = k - n + 1
            if j < n:  # valid j
                if j == 0:
                    lower = 1.0 / f[0]  # S[n-1] >= 1/f[0] (since S[-1]=0)
                else:
                    lower = dist[j-1] + 1.0 / f[j]
                dist[k] = max(dist[k], lower)
    
    # Recover y from S
    y = np.zeros(2*n-1)
    y[0] = dist[0]  # y[0] = S[0] - S[-1] = S[0]
    for k in range(1, 2*n-1):
        y[k] = dist[k] - dist[k-1]
    
    dual_obj = M * dist[2*n-2]
    return y, dual_obj
```

Let me redo:

Now, from the dual solution y, I need to get the primal solution g. By complementary slackness:
- g[j] > 0 only if the dual constraint j is active: sum_{k=j}^{j+n-1} y[k] = 1/f[j]
- y[k] > 0 only if the primal constraint k is active: (f*g)[k] = M

So the support of g is the set of j where the window sum equals 1/f[j].

To find g on its support, we solve:
(f*g)[k] = M for all k with y[k] > 0
g[j] = 0 for all j not in the support

This is a linear system. Let me denote the support as J and the active constraints as K.
For k in K: sum_{j in J, 0<=k-j<n} f[j]*g[k-j] = M

This is a system with |K| equations and |J| unknowns. In general, |K| might not equal |J|.

At a vertex of the polytope, we have exactly n linearly independent active constraints. These come from a mix of g[j] = 0 constraints and (f*g)[k] = M constraints.

This is getting complicated. Let me use a simpler approach: instead of solving the full LP, I'll use the dual solution to define a direction.

**Simplified update using dual info:**

The dual variable y[k] tells us how "tight" the constraint (f*g)[k] <= M is. If y[k] > 0, the constraint is tight.

The subgradient of the objective (with respect to f) at the current point is related to the autoconvolution. Specifically, the gradient of (f*f)[k] with respect to f[m] is f[k-m] (if valid).

For the max function, the subgradient is the weighted average of the gradients of the active constraints, where the weights are the dual variables.

So the subgradient direction is:
sg[m] = sum_k y[k] * f[k-m] / sum_k y[k] (normalized)

This is the cross-correlation of y and f, normalized.

The update would be to move f in the direction that reduces the weighted sum of the active peaks:
f_new = f - eta * sg (or some variant)

But we also need to maintain f >= 0 and sum(f) = constant.

Actually, let me think about this more carefully. The SOTA approach doesn't use the subgradient directly. It solves the LP to get a new point g, then interpolates.

Let me try a different approach: **Use the dual to determine a multiplicative update.**

The idea: if y[k] > 0 (constraint k is tight), then we want to reduce (f*g)[k]. For the direction g = f (i.e., moving in the direction of f itself), we'd check if (f*f)[k] = M for all k with y[k] > 0. If so, we need to move in a direction that reduces these peaks.

A natural direction is: g[m] = 1 / (sum_{k: y[k]>0} f[k-m]) (inverse of the "load" at position m).

This is the "equalization" direction: it makes the contribution from each peak proportional to 1/load.
