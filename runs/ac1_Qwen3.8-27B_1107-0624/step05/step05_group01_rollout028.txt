For the left half, `a[i] = c[n-1-i] = 1/((n-i)^{3/4})`.
For small i: `a[i] ≈ 1/n^{3/4}`.
`conv(a,a)[k] ≈ (k+1) / n^{3/2}` for small k.

This is much smaller than the right-half values (which are about `n^{-1/2}`), so the left half doesn't contribute to the maximum.

So the asymptotic score for `c[i] = 1/(i+1)^p` is:
`Score(p) = 2 * B(1-p,1-p) * (1-p)^2`

Let me minimize this over `p in (0,1)`.

`f(p) = 2 * (1-p)^2 * Gamma(1-p)^2 / Gamma(2-2p)`

Let `q = 1-p` (so `q in (0,1)`):
`f(q) = 2 * q^2 * Gamma(q)^2 / Gamma(2q)`

Using `Gamma(2q) = (2^{2q-1}/sqrt(pi)) * Gamma(q) * Gamma(q+1/2)` (Legendre's duplication formula):
`Gamma(2q) = 2^{2q-1} * Gamma(q) * Gamma(q+1/2) / sqrt(pi)`
