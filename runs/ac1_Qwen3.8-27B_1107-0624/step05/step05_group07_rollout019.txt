Actually, let me think about this differently. For n=3:
`(a*a)[0] = a[0]^2`
`(a*a)[1] = 2*a[0]*a[1]`
`(a*a)[2] = 2*a[0]*a[2] + a[1]^2`
`(a*a)[3] = 2*a[1]*a[2]`
`(a*a)[4] = a[2]^2`

With `a[0] + a[1] + a[2] = 1`, `a[i] >= 0`.

We want to minimize `max(a[0]^2, 2a[0]a[1], 2a[0]a[2]+a[1]^2, 2a[1]a[2], a[2]^2)`.

If we set `a[1] = 0`: minimize `max(a[0]^2, 2a[0]a[2], a[2]^2)` with `a[0]+a[2]=1`.
`a[0]^2 = a[2]^2` when `a[0] = a[2] = 1/2`. Then `2a[0]a[2] = 1/2 > 1/4`. So max = 1/2.

If we set `a[1] > 0`: Let's try to make all 5 values equal to some `T`.
`a[0]^2 = T`
`2a[0]a[1] = T` → `a[1] = T/(2a[0])`
`a[2]^2 = T` → `a[2] = sqrt(T)` (assuming a[0] = a[2] for symmetry... but we don't need symmetry)

Actually, let's not assume symmetry. Let `a[0]^2 = T, 2a[0]a[1] = T, 2a[0]a[2] + a[1]^2 = T, 2a[1]a[2] = T, a[2]^2 = T`.

From the first: `a[0] = sqrt(T)`.
From the fifth: `a[2] = sqrt(T)`.
From the second: `2*sqrt(T)*a[1] = T` → `a[1] = sqrt(T)/2`.
Check third: `2*sqrt(T)*sqrt(T) + (sqrt(T)/2)^2 = 2T + T/4 = 9T/4`. This should equal T, so `9T/4 = T` → `T = 0`. Contradiction.

So we can't make all 5 equal. Let's just minimize the max.

By symmetry, let's try `a[0] = a[2]`. Then `a[1] = 1 - 2a[0]`.
`(a*a)[0] = a[0]^2`
`(a*a)[1] = 2a[0]a[1] = 2a[0](1-2a[0])`
`(a*a)[2] = 2a[0]^2 + a[1]^2 = 2a[0]^2 + (1-2a[0])^2`
`(a*a)[3] = 2a[1]a[2] = 2a[0](1-2a[0])` (same as [1])
`(a*a)[4] = a[2]^2 = a[0]^2` (same as [0])

So we need to minimize `max(a[0]^2, 2a[0](1-2a[0]), 2a[0]^2 + (1-2a[0])^2)`.

Let `x = a[0]`. Then we minimize `max(x^2, 2x(1-2x), 2x^2 + (1-2x)^2)`.

`f1 = x^2`
`f2 = 2x - 4x^2`
`f3 = 2x^2 + 1 - 4x + 4x^2 = 6x^2 - 4x + 1`

At `x = 1/3`: `f1 = 1/9, f2 = 2/9, f3 = 6/9 - 4/3 + 1 = 2/3 - 4/3 + 1 = 1/3`. Max = 1/3.
