def _next_pow2(n):
    k = 1
    while k < n:
        k <<= 1
    return max(2, k)

def _full_convolve(a, b):
    n, m = len(a), len(b)
    out_n = n + m - 1
    N = _next_pow2(out_n)
    fa = np.fft.rfft(a, N)
    fb = np.fft.rfft(b, N)
    r = np.fft.irfft(fa * fb, N)[:out_n]
    return r

    c = _full_convolve(a, a)
    return float(2.0 * n * c.max())

        k <<= 1
    return max(2, k)

Let me also think about the projection onto the simplex. For a vector $v$ of length $n$, the projection $P$ onto $\{x \ge 0, \sum x = 1\}$ is:

$\lambda = \text{the unique value such that } \sum_i \max(v_i - \lambda, 0) = 1$

We can find $\lambda$ by binary search or by sorting.

Sorting approach:
1. Sort $v$ in decreasing order: $v_{(1)} \ge v_{(2)} \ge ... \ge v_{(n)}$.
2. For each $j = 1, ..., n$, define $\lambda_j = (v_{(1)} + ... + v_{(j)} - 1) / j$.
3. Find the largest $j$ such that $v_{(j)} > \lambda_j$.
4. Then $\lambda = \lambda_j$ and $P_i = \max(v_i - \lambda, 0)$.

This is $O(n \log n)$ due to sorting. For $n = 8192$, this is fast.

Let me code the projection:

```python
def _proj_simplex(v):
    n = len(v)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.where(u - (cssv - 1.0) / np.arange(1, n+1) > 0)[0]
    if len(rho) == 0:
        return np.ones(n) / n
    rho = rho[-1] + 1  # 1-indexed
    theta = (cssv[rho-1] - 1.0) / rho
    return np.maximum(v - theta, 0.0)
```
