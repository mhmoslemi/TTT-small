Multi-phase optimization for minimizing 2*n*max(conv(a,a))/sum(a)^2.
Uses aggressive Adam, peak-pair L-BFGS, adaptive block descent, and entropy regularization.

import numpy as np
from scipy.optimize import minimize
import time

def _next_pow2(n):
    k = 1
    while k < n:
        k <<= 1
    return max(2, k)

def _full_conv(a, b):
    n, m = len(a), len(b)
    out_n = n + m - 1
    N = _next_pow2(out_n)
    return np.fft.irfft(np.fft.rfft(a, N) * np.fft.rfft(b, N), N)[:out_n]

def _score(a):
    n = len(a)
    s = a.sum()
    if s < 1e-15:
        return np.inf
    c = _full_conv(a, a)
    return 2.0 * n * c.max() / (s * s)

def _conv(a):
    return _full_conv(a, a)

def _softmax(z):
    z = z - z.max()
    e = np.exp(z)
    s = e.sum()
    if s < 1e-300:
        return np.ones_like(z) / len(z)
    return e / s

def _lse_obj(z, beta, n, ent_coeff=0.0):
    a = _softmax(z)
    c = _full_conv(a, a)
    cm = c.max()
    if cm < 1e-300:
        return 0.0

    ms = shifted.max()
    lse = cm + beta * (ms + np.log(np.sum(np.exp(shifted - ms))))
    obj = 2.0 * n * lse
    if ent_coeff > 0:
        # Negative entropy of c (encourages flatness)
        c_pos = np.maximum(c, 1e-30)
        entropy = -np.sum(c_pos * np.log(c_pos))
        obj += ent_coeff * entropy

**Another idea: Use the Wiener-Khinchin theorem.**

The convolution `c = conv(a,a)` has DFT `C = |A|^2` (where `A = DFT(a)` padded to appropriate length). Wait, that's for the autocorrelation, not the convolution.

For the convolution: `C = A * A` (product in frequency domain), where `A = DFT(a)`.

So `c = IDFT(|A|^2)` if we're doing autocorrelation, or `c = IDFT(A^2)` for self-convolution.

Wait, for self-convolution `c = a * a` (convolution), the DFT is `C = A^2` (not `|A|^2` unless `a` is real and we're doing circular correlation).

For a real sequence `a`, `A[k] = conj(A[N-k])` (Hermitian symmetry). So `A^2[k]` does NOT have Hermitian symmetry in general, meaning `c = IDFT(A^2)` is not necessarily real. But since `a` is real, `conv(a,a)` is real, so the imaginary part must cancel out.

Actually, `DFT(conv(a,a)) = DFT(a) * DFT(a) = A * A` (element-wise product). Since `a` is real, `A[N-k] = conj(A[k])`, so `(A*A)[N-k] = A[N-k]^2 = conj(A[k])^2 = conj(A[k]^2) = conj((A*A)[k])`. So `A^2` does have Hermitian symmetry, and `IDFT(A^2)` is real. Good.

So `c_k` is the inverse DFT of `A^2`. The peak of `c` is the `L_infty` norm of `IDFT(A^2)`.

Minimizing `||IDFT(A^2)||_infty` subject to `sum(a) = 1` (which means `A[0] = 1` for the DFT of the zero-padded sequence... wait, `sum(a) = DFT(a)[0] = A[0]`).

And `a >= 0` means the IDFT of `A` is non-negative.

This is a problem in the frequency domain: minimize `||IDFT(A^2)||_infty` subject to `A[0] = 1`, `A` has Hermitian symmetry, and `IDFT(A) >= 0`.

The constraint `IDFT(A) >= 0` is the hard one (it's a semi-infinite constraint in the frequency domain).

If we ignore the non-negativity constraint, the problem becomes: minimize `||IDFT(A^2)||_infty` subject to `A[0] = 1` and Hermitian symmetry. This is still hard but might have a more tractable structure.

For the unconstrained problem (without `a >= 0`), the optimal `A` might be one where `A^2` is as flat as possible in the time domain. This is related to "minimum peak-to-average power ratio" (PAPR) problems in communications.

The "TSP" (Time Sharing between Phase) or "MU" (Minimax over Unit vectors) algorithms are used for PAPR reduction. These might be applicable here.

**Key insight from PAPR reduction**: The problem of minimizing `||IDFT(B)||_infty` for `B = A^2` is equivalent to minimizing the peak of `IDFT(A^2)` by adjusting `A`. This is like a "phase retrieval" problem where we adjust the phases of `A` to minimize the peak of `IDFT(A^2)`.

But our problem has the additional constraint that `IDFT(A) >= 0` (non-negativity of `a`), which makes it harder.

**Practical algorithm inspired by PAPR reduction:**

1. Start with a feasible `a` (non-negative, sum=1).
2. Compute `A = DFT(a)` and `B = A^2`.
3. Compute `c = IDFT(B)` (the convolution).
4. Find the peak of `c`.
5. Adjust `A` to reduce the peak: `A_new = A * (1 - α * IDFT(peak_mask))` or similar.
6. Project back to the feasible set: `a_new = max(0, IDFT(A_new))` and renormalize.
7. Iterate.

This is similar to the "projected gradient descent" approach but in the frequency domain.
