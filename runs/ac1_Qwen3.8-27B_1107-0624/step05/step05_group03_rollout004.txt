**Algorithm 1: Subgradient with top-K smoothing**

```python
def subgradient_optimize(a_init, n_iters, deadline):
    n = len(a_init)
    z = np.log(a_init + 1e-30)
    z = z - z.mean()
    
    best_score = 2*n*max(conv(a_init, a_init))
    best_a = a_init.copy()
    
    eta0 = 0.1  # initial step size
    
    for it in range(n_iters):
        if time.monotonic() > deadline:
            break
        
        a = softmax(z)
        c = fft_convolve(a, a)
        c_max = c.max()
        score = 2*n*c_max
        
        if score < best_score:
            best_score = score
            best_a = a.copy()
        
        # Top-K smoothing
        K = 5
        top_k = np.argsort(c)[-K:]
        # Softmax weights over top K
        beta = 50  # temperature for the weights
        w = np.zeros(len(c))
        w[top_k] = np.exp(beta * c[top_k])
        w[top_k] /= w[top_k].sum()
        
        # Compute h[l] = sum_k w[k]*a[k-l]
        w_rev = w[::-1]
        h_full = fft_convolve(w_rev, a)  # length 2n-1
        h = h_full[n-1::-1]  # length n
        
        # Gradient: grad[l] = 2*a[l]*(h[l] - c_weighted)
        c_weighted = np.dot(w, c)
        grad = 2 * a * (h - c_weighted)
        
        # Step size: decrease over time
        eta = eta0 / (1 + it * 0.01)
        
        z = z - eta * grad
        z = z - z.mean()
        z = np.clip(z, -50, 50)
    
    return best_a, best_score
```

This is a clean subgradient method. The key advantage over the previous approach is that it directly targets the max (or a smoothed version) without needing logsumexp continuation.

**Algorithm 2: Multiplicative weights / Mirror descent**

Instead of using softmax parameterization, we can use multiplicative updates directly:
a_new[i] = a[i] * exp(-eta * grad[i])

This is equivalent to mirror descent with the entropic regularizer, which is the same as gradient descent in the log domain. So it's the same as Algorithm 1.

**Algorithm 3: Projection onto the constraint set**

After each gradient step, we need to project back to the constraint set {a >= 0, sum a = 1}. In the log-softmax parameterization, this is automatically handled (softmax always gives a probability vector).

But we could also work in the original space with explicit projection:
1. Compute gradient of 2n*max(c) w.r.t. a.
2. Take a step: a_new = a - eta * grad.
