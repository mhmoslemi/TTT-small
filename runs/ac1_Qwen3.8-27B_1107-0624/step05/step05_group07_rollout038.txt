Let me think about the Hessian. The objective is `f(a) = max_k (a*a)_k`. At the optimum, suppose the max is attained at positions `S = {k_1, ..., k_m}`. The Hessian of `(a*a)_{k_i}` is `2*Q_{k_i}` (a constant matrix). So the Hessian of the smoothed objective is a weighted combination of these matrices.

For L-BFGS, we're already approximating the Hessian. The issue is that with very small smoothing, the objective becomes "spiky" and L-BFGS struggles.

**New idea: Use the Hessian directly for a Newton-like step**

If the max is at position `k*`, then locally the objective is `(a*a)_{k*} = a^T Q_{k*} a` (approximately, if the max is unique). We can do a Newton step:
- Hessian: `H = 2*Q_{k*}` (the matrix with 1s on the anti-diagonal for position k*)
- Gradient: `g = 2*Q_{k*} a`
- Newton step: `Δa = -H^{-1} g` (but H might not be invertible)

The issue is that `Q_{k*}` is not positive definite (it has eigenvalues ±1 for the center case). So Newton's method doesn't directly apply.

However, we can project the Newton step onto the feasible set. Or we can use a "conjugate gradient" approach on the quadratic subproblem.

Actually, for the quadratic `(a*a)_{k*} = sum_i a_i a_{k*-i}`, the problem of minimizing this subject to `sum(a) = 1, a >= 0` is a Quadratic Programming (QP) problem! We can solve it exactly (or approximately) using QP solvers.

**Algorithm: QP-based iteration**

1. Start with current `a`.
2. Find `k* = argmax(conv(a,a))`.
3. Solve QP: minimize `(a'*a')_{k*}` subject to `sum(a') = 1, a' >= 0, ||a' - a||^2 <= ε^2` (for some small ε to ensure progress).
4. Update `a = a'`.
5. Repeat.

This is like a trust-region method where the model is the quadratic at the current max position.

But solving a QP at each iteration might be slow. Let's think of a faster approach.

**Faster approach: One step of the QP**

The QP is: minimize `a'^T Q a'` subject to `1^T a' = 1, a' >= 0`.

The KKT conditions are:
- `2Qa' + λ*1 + μ = 0` (stationarity, μ >= 0 for inequality)
- `1^T a' = 1` (primal feasibility for equality)
- `a' >= 0, μ >= 0, μ_i * a'_i = 0` (complementary slackness)

If we ignore the non-negativity constraint (and hope the solution is non-negative), we get:
`2Qa' + λ*1 = 0`
`1^T a' = 1`

From the first: `a' = -λ/2 * Q^{-1} 1` (if Q is invertible).
But Q (the anti-diagonal matrix) has eigenvalues ±1, so it's invertible but not PSD.

Actually, `Q^2 = I` for the anti-diagonal matrix (reversal), so `Q^{-1} = Q`. Thus `a' = -λ/2 * Q * 1`.

`Q * 1` is the vector with all 1s reversed, which is still all 1s (for the full anti-diagonal). Wait, `Q_{n-1}` is the reversal matrix: `(Q_{n-1})_{i,j} = 1 if i+j = n-1`. So `(Q_{n-1} * 1)_i = 1` for all i. So `a' = -λ/2 * 1`, which gives `n * (-λ/2) = 1`, so `λ = -2/n` and `a' = 1/n` (uniform!).

So the unconstrained minimizer of `(a*a)_{n-1}` subject to `sum(a) = 1` is the uniform vector! And `(a*a)_{n-1} = 1/n` at the uniform vector.

This makes sense: the uniform vector minimizes the center peak (among symmetric sequences). But for non-center peaks, the optimal might be different.

For peak at position `k ≠ n-1`: `Q_k` is not the full reversal matrix. It's a partial anti-diagonal. The unconstrained minimizer of `a^T Q_k a` subject to `1^T a = 1` would be different.

"""
Multi-phase optimizer for step function sequence minimization.
Combines: (1) L-BFGS with adaptive log-sum-exp smoothing, (2) peak-targeting
mirror descent with top-k weighting, (3) structured asymmetry perturbations,
(4) multi-n exploration. Designed for fine-tuning near-optimal solutions.

import numpy as np
from scipy.optimize import minimize
import time


def _next_pow2(n):
    k = 1
    while k < n:
        k <<= 1
    return max(2, k)


def _full_convolve(a, b):
    n, m = len(a), len(b)
    out_n = n + m - 1
    N = _next_pow2(out_n)
    fa = np.fft.rfft(a, N)
    fb = np.fft.rfft(b, N)
    r = np.fft.irfft(fa * fb, N)[:out_n]
    return r


def _score_norm_fn(a):
    n = len(a)
    c = _full_convolve(a, a)
    return float(2.0 * n * c.max())


def _score_fn(a):
    n = len(a)
    s = float(a.sum())
    if s < 1e-15:
        return np.inf
    c = _full_convolve(a, a)
    return float(2.0 * n * c.max() / (s * s))


def _softmax_fn(z):
    z = np.asarray(z, dtype=np.float64)
    z = z - np.max(z)
    e = np.exp(z)
    s = e.sum()
    if s < 1e-300 or not np.isfinite(s):
        return np.ones_like(z) / len(z)
    return e / s


def _lse_obj(z, beta, n):
    """Log-sum-exp smoothed objective. beta: smoothing parameter (smaller = sharper)."""
    a = _softmax_fn(z)
    c = _full_convolve(a, a)
    cm = float(c.max())
    vals = np.clip((c - cm) / beta, -500, 500)
    lse = cm + beta * float(np.log(np.sum(np.exp(vals))))
    return 2.0 * n * lse


def _lse_grad(z, beta, n):
    """Gradient of log-sum-exp smoothed objective w.r.t. z (log-softmax parameter)."""
    a = _softmax_fn(z)
    c = _full_convolve(a, a)
    cm = float(c.max())
    vals = np.clip((c - cm) / beta, -500, 500)
    e = np.exp(vals)
    w = e / e.sum()
    W = float(np.dot(w, c))
    # h[j] = sum_k w_k * a_{k-j} (cross-correlation of w and a)
    # Computed via FFT: xcorr(w, a)[j] = sum_m w[m+j] * a[m]
    N = _next_pow2(3 * n - 2)
    W_fft = np.fft.rfft(w, N)
    A_fft = np.fft.rfft(a, N)
    h_full = np.fft.irfft(W_fft * np.conj(A_fft), N)[:n]
    # Gradient of LSE w.r.t. a: 2n * 2 * h_full = 4n * h_full
    # But we also need to account for the W term subtraction for the max
    # Actually the full gradient of (2n * lse) w.r.t. a:
    # lse = max_c + beta * log(sum exp((c-max_c)/beta))
    # dlse/dc_k = w_k (the softmax weights)
    # d/d(a) [sum_k w_k c_k] = 2 * cross_corr(w, a) [valid part]
    # So grad_a = 2n * 2 * h_full = 4n * h_full
    # But we also need the gradient of the W term... actually W is just a scalar
    # that doesn't affect the gradient structure. The gradient of the smoothed
    # max w.r.t. a is: 2 * sum_k w_k * Q_k * a = 2 * cross_corr(w, a)
    grad_a = 4.0 * n * h_full
    # Convert to gradient w.r.t. z via softmax Jacobian
    grad_a_dot_a = float(np.dot(grad_a, a))
    grad_z = a * (grad_a - grad_a_dot_a)
    return grad_z


def _peak_subgrad(a, top_k=1):
    """Compute weighted subgradient targeting top-k peaks of convolution."""
    n = len(a)
    c = _full_convolve(a, a)
    cm = float(c.max())
    kmax = int(np.argmax(c))
    if top_k == 1:
        # Single peak subgradient
        if 0 <= kmax <= n - 1:
            grad = np.zeros(n)
            j_lo = max(0, kmax - n + 1)
            j_hi = min(n - 1, kmax)
            idx = np.arange(j_lo, j_hi + 1)
            grad[idx] = 2.0 * a[kmax - idx]
        else:
            grad = np.zeros(n)
            j_lo = kmax - n + 1
            j_hi = n - 1
            idx = np.arange(j_lo, j_hi + 1)
            grad[idx] = 2.0 * a[kmax - idx]
        grad = grad - np.mean(grad)
        return grad, kmax, cm
    else:
        # Top-k weighted
        idx_sorted = np.argsort(c)[::-1][:top_k]
        weights = c[idx_sorted] - cm + c.max()
        weights = np.exp(weights * 5.0)
        weights = weights / weights.sum()
        grad = np.zeros(n)
        N = _next_pow2(3 * n - 2)
        A_fft = np.fft.rfft(a, N)
        for w_i, k_i in zip(weights, idx_sorted):
            w_single = np.zeros(2 * n - 1)
            w_single[k_i] = w_i
            W_fft = np.fft.rfft(w_single, N)
            h = np.fft.irfft(W_fft * np.conj(A_fft), N)[:n]
            grad += 2.0 * h
        grad = 2.0 * n * (grad - np.mean(grad))
        return grad, kmax, cm


def _mirror_descent(a_init, deadline, top_k=1, lr_init=0.3, decay=0.9999):
    """Mirror descent with peak-targeting subgradient and Polyak averaging."""
    n = len(a_init)
    z = np.log(np.maximum(a_init, 1e-15))
    z = z - z.mean()
    best_a = a_init.copy()
    best_score = _score_norm_fn(a_init)
    lr = lr_init
    z_avg = z.copy()
    it = 0

    while time.monotonic() < deadline:
        a = _softmax_fn(z)
        c = _full_convolve(a, a)
        grad, kmax, cm = _peak_subgrad(a, top_k)
        if not np.all(np.isfinite(grad)):
            break
        z = z - lr * grad
        z = np.clip(z, -80, 80)
        z = z - z.mean()
        z_avg = (it / (it + 1)) * z_avg + (1 / (it + 1)) * z
        it += 1
        lr = lr_init * (decay ** it)
        if it % 20 == 0:
            a_avg = _softmax_fn(z_avg)
            sc = _score_norm_fn(a_avg)
            if sc < best_score:
                best_score = sc
                best_a = a_avg.copy()
            if it % 2000 == 0:
                print(f"      MD iter {it}: best={best_score:.10f}, lr={lr:.6f}, peak@{kmax}")

    return best_a, best_score


def _run_lbfgs(a_init, deadline, beta_list=None, maxiter_per_beta=2000):
    """L-BFGS with continuation over beta values."""
    n = len(a_init)
    z = np.log(np.maximum(a_init, 1e-15))
    z = z - z.mean()
    best_a = a_init.copy()
    best_score = _score_norm_fn(a_init)

    c0 = _full_convolve(a_init, a_init)
    max_c0 = float(c0.max())

    if beta_list is None:
        fracs = [0.02, 0.01, 0.005, 0.003, 0.002, 0.001, 0.0005,
                 0.0003, 0.0002, 0.0001, 0.00005, 0.00003, 0.00002, 0.00001]
        beta_list = [b * max_c0 for b in fracs]

    for idx, beta in enumerate(beta_list):
        if time.monotonic() > deadline - 5:
            break
        remaining = len(beta_list) - idx
        time_per = max(2.0, (deadline - time.monotonic()) / max(1, remaining))
        maxiter = max(100, min(maxiter_per_beta, int(time_per * 50)))
        try:
            result = minimize(
                _lse_obj, z, args=(beta, n),
                method='L-BFGS-B', jac=_lse_grad,
                options={'maxiter': maxiter, 'ftol': 1e-18, 'gtol': 1e-12,
                         'maxls': 40, 'maxfun': maxiter * 6}
            )
            if result.x is not None and np.all(np.isfinite(result.x)):
                a_new = _softmax_fn(result.x)
                s_new = _score_norm_fn(a_new)
                if np.isfinite(s_new) and s_new < best_score:
                    best_score = s_new
                    best_a = a_new.copy()
                    z = result.x.copy()
                    print(f"      L-BFGS beta={beta:.2e}: score={best_score:.10f}")
        except Exception:
            pass

    return best_a, best_score

def _make_asymmetric_profiles(n, rng):
    """Generate diverse asymmetric initial profiles."""
    t = np.linspace(0, 1, n)
    u = 2 * t - 1
    profiles = []
    # Linear ramps
    for slope in [0.5, 1.0, 1.5, 2.0, 3.0, 5.0, -1.0, -2.0, -3.0]:
        a = 1.0 + slope * (t - 0.5)
        a = np.maximum(a, 1e-12)
        profiles.append(a / a.sum())
    # Exponential ramps
    for rate in [1.0, 2.0, 3.0, 5.0, -1.0, -2.0, -3.0]:
        a = np.exp(rate * (t - 0.5))
        profiles.append(a / a.sum())
    # Power laws
    for p in [0.5, 1.0, 2.0, 3.0, -1.0]:
        a = np.maximum(t - 0.01, 1e-12) ** p
        profiles.append(a / a.sum())
    # Mixed
    a = np.exp(-2.0 * (t - 0.3)) * (1 + 0.5 * np.sin(4 * np.pi * t))
    a = np.maximum(a, 1e-12)
    profiles.append(a / a.sum())
    a = np.exp(-2.0 * (t - 0.7)) * (1 + 0.5 * np.cos(4 * np.pi * t))
    a = np.maximum(a, 1e-12)
    profiles.append(a / a.sum())
    return profiles


def _interp_profile(p0, n_new):
    p0 = np.asarray(p0, dtype=np.float64).ravel()
    n0 = len(p0)
    if n0 == n_new:
        return p0 / p0.sum()
    x0 = np.linspace(0.0, 1.0, n0)
    x1 = np.linspace(0.0, 1.0, n_new)
    p = np.interp(x1, x0, p0)
    p = np.maximum(p, 1e-12)
    return p / p.sum()

        p_best, sc_best = _run_lbfgs(best_seq, per_dl, beta_list=ultra_betas, maxiter_per_beta=3000)
        _update(p_best, sc_best, "ultra_lbfgs")
        
        # Mirror descent very fine
        if time.monotonic() < phase5_end - 40:
            per_dl2 = min(phase5_end - 30, time.monotonic() + 80.0)
            p_best2, sc_best2 = _mirror_descent(best_seq, per_dl2, top_k=1, lr_init=0.2)
            _update(p_best2, sc_best2, "ultra_mirror")
            
            # L-BFGS after mirror
            if time.monotonic() < phase5_end - 30:
                per_dl3 = min(phase5_end - 20, time.monotonic() + 40.0)
                p_best3, sc_best3 = _run_lbfgs(best_seq, per_dl3,
                                                beta_list=[1e-6 * _full_convolve(best_seq, best_seq).max()],
                                                maxiter_per_beta=2000)
                _update(p_best3, sc_best3, "lbfgs_final")
        
        # Coordinate descent
        if time.monotonic() < phase5_end - 15:
            per_dl4 = min(phase5_end - 5, time.monotonic() + (phase5_end - time.monotonic()) * 0.4)
            p_best4, sc_best4 = _coord_descent_fine(best_seq, per_dl4)
            _update(p_best4, sc_best4, "coord_descent")
    
    # ===== Final: One more round of finest optimization =====
    if best_seq is not None and time.monotonic() < deadline - 10:
        c = _full_convolve(best_seq, best_seq)
        mc = float(c.max())
        per_dl = min(deadline - 5, time.monotonic() + 20.0)
        p_best, sc_best = _run_lbfgs(best_seq, per_dl,
                                      beta_list=[0.5e-6 * mc],
                                      maxiter_per_beta=5000)
        _update(p_best, sc_best, "last_lbfgs")

    print(f"\n=== FINAL: score={best_score:.10f}, n={len(best_seq) if best_seq is not None else 0} ===")

    # Validation
    if best_seq is not None:
        final_seq = np.clip(best_seq, 0.0, 1000.0)
        s = float(final_seq.sum())
        if s > 0.01:
            final_seq = final_seq / s
        sc_final = _score_fn(final_seq)
        print(f"Final validated score: {sc_final:.10f}")
        
        if len(final_seq) <= 10000:
            try:
                sc_eval = float(evaluate_sequence([float(x) for x in final_seq]))
                print(f"Evaluator score: {sc_eval:.10f}")
            except Exception as ex:
                print(f"evaluate_sequence failed: {ex}")
        
        return [float(x) for x in final_seq]

    # Fallback
    n_fb = 4096
    fallback = _make_asymmetric_profiles(n_fb, rng)[4]
    print(f"FALLBACK: n={n_fb}, score={_score_fn(fallback):.10f}")
    return [float(x) for x in fallback]
