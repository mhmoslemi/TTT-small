Improvements over previous: adaptive line search, Nesterov momentum, symmetry exploitation,
multi-scale smoothing schedule, and coordinate descent polishing.

import time
from scipy.optimize import linprog
import scipy.sparse as sp

def _next_pow2(n):
    k = 1
    while k < n:
        k <<= 1
    return max(2, k)

def _full_convolve(a, b):
    n, m = len(a), len(b)
    out_n = n + m - 1
    N = _next_pow2(out_n)
    fa = np.fft.rfft(a, N)
    fb = np.fft.rfft(b, N)
    return np.fft.irfft(fa * fb, N)[:out_n]

def _softmax(z):

def _build_lp_indices(n):
    rows_list = []
    cols_list = []
    for k in range(2 * n - 1):
        j_start = max(0, k - n + 1)
        j_end = min(k, n - 1)
        j_range = np.arange(j_start, j_end + 1)
        rows_list.append(np.full(len(j_range), k, dtype=np.int32))
        cols_list.append(j_range.astype(np.int32))
    return np.concatenate(rows_list), np.concatenate(cols_list)

def _solve_lp(f, M, rows, cols, timeout=30):
    n = len(f)
    vals = f[rows - cols]
    A = sp.csc_matrix((vals, (rows, cols)), shape=(2 * n - 1, n))
    c_obj = -np.ones(n)
    b_ub = np.full(2 * n - 1, M)
    bounds = [(0, None)] * n
    try:
        res = linprog(c_obj, A_ub=A, b_ub=b_ub, bounds=bounds, method='highs',
                      options={'time_limit': timeout})
        if res.status != 0:
            return None
        return np.maximum(res.x, 0.0)
    except Exception:
        return None

def _lp_step_adaptive(f, rows, cols):
    """LP step with adaptive line search."""
    n = len(f)
    c, M = _conv_max(f)
    g_0 = _solve_lp(f, M, rows, cols, timeout=30)
    if g_0 is None or g_0.sum() < 1e-15:
        return f, M, 0.0
    
    g = g_0 / g_0.sum()
    
    # Adaptive line search: try increasing then decreasing t
    best_t = 0.0
    best_sc = _score_norm(f)
    
    # Try a range of t values with adaptive refinement
    candidates = [0.1, 0.2, 0.3, 0.5, 0.7, 0.9, 1.0]
    best_in_range = None
    for t in candidates:
        f_cand = (1.0 - t) * f + t * g
        sc = _score_norm(f_cand)
        if best_in_range is None or sc < best_in_range[1]:
            best_in_range = (t, sc)
    
    if best_in_range[1] < best_sc:
        # Refine around the best t
        t_best = best_in_range[0]
        for _ in range(5):
            t_lo = max(0.0, t_best - 0.1)
            t_hi = min(1.0, t_best + 0.1)
            t_mid = (t_lo + t_hi) / 2
            f_mid = (1.0 - t_mid) * f + t_mid * g
            sc_mid = _score_norm(f_mid)
            f_lo = (1.0 - t_lo) * f + t_lo * g
            sc_lo = _score_norm(f_lo)
            f_hi = (1.0 - t_hi) * f + t_hi * g
            sc_hi = _score_norm(f_hi)
            
            if sc_lo < sc_mid:
                t_hi = t_best
                t_best = (t_lo + t_best) / 2
            elif sc_hi < sc_mid:
                t_lo = t_best
                t_best = (t_best + t_hi) / 2
            else:
                t_best = t_mid
            
            if t_best < best_t or sc_mid < best_sc:
                best_t = t_best
                best_sc = sc_mid
    
    if best_t > 0.0:
        f = (1.0 - best_t) * f + best_t * g
        f = np.maximum(f, 0.0)
        f = f / f.sum()
    return f, M, best_t

   - Scale all other coordinates: a[j] *= (1 - x) / (1 - old_a[i]) for j != i
   - This maintains sum = 1.
3. Evaluate the objective.

But this is O(n) per coordinate update, and O(n^2) per full pass, which for n=2048 gives ~4M operations per pass. That's fast enough.

1. Set a[i] = x
2. Don't worry about the sum
3. At the end of a full pass, normalize

This works because the objective doesn't change under scaling.

Let me now think about the binary search for the optimal x_i.

Given the current a (with a[i] = current value), I want to find the optimal new value x for a[i] (treating all other coordinates as fixed).

The convolution values as functions of x:
- For k != 2i: c_k(x) = c_k_base + 2*x*a[k-i] (where c_k_base = c_k - 2*current_a[i]*a[k-i])
- For k = 2i: c_k(x) = c_k_base + x^2 (where c_k_base = c_k - current_a[i]^2)

Wait, I need to be more careful. Let's say current a[i] = x0. The current convolution is c_k.

When I change a[i] from x0 to x:
- The convolution entry at lag k changes by:
  - Delta c_k = (new terms with a[i]=x) - (old terms with a[i]=x0)
  - = [2*x*a[k-i] or x^2] - [2*x0*a[k-i] or x0^2]

More precisely:
- For k != 2i (and k-i in [0,n-1]): Delta c_k = 2*(x-x0)*a[k-i]
- For k = 2i: Delta c_k = x^2 - x0^2

So c_k(x) = c_k + 2*(x-x0)*a[k-i] (for k != 2i)
           c_k(x) = c_k + x^2 - x0^2 (for k = 2i)

I want to minimize max_k c_k(x) over x >= 0.

Since c_k(x) is convex in x for each k, and the max of convex functions is convex, the minimum is unique (or on an interval).

Binary search approach:
- Lower bound: x = 0
- Upper bound: x = 2 * x0 (or some reasonable bound)
- For a candidate V (target max value), check feasibility:
  - For all k != 2i with a[k-i] > 0: need c_k + 2*(x-x0)*a[k-i] <= V
    => x <= (V - c_k) / (2*a[k-i]) + x0
  - For all k != 2i with a[k-i] = 0: need c_k <= V (must hold)
  - For k = 2i: need c_{2i} + x^2 - x0^2 <= V => x <= sqrt(V - c_{2i} + x0^2)
  
  The maximum feasible x is the min of all upper bounds. If this max feasible x >= 0, then V is feasible.

- Binary search on V to find the minimum feasible V.
- The optimal x is the maximum feasible x at the optimal V (or we can just set x to the value that achieves the max).

Actually, there's a simpler way. The optimal x is the point where the maximum of the "active" constraints is minimized. This is the 1D version of Chebyshev approximation.

For the linear constraints (k != 2i):
c_k(x) = (c_k - 2*x0*a[k-i]) + 2*x*a[k-i] = A_k + B_k * x

where A_k = c_k - 2*x0*a[k-i] and B_k = 2*a[k-i] >= 0.

For the quadratic constraint (k = 2i):
c_{2i}(x) = (c_{2i} - x0^2) + x^2

The optimal x minimizes max(A_k + B_k * x for all k, (c_{2i} - x0^2) + x^2).

This is a convex 1D problem. I can solve it by:
1. If no constraint is active at x=0 (i.e., max_k c_k(0) is achieved at the quadratic term), use the analytical solution.
2. Otherwise, binary search on V.
