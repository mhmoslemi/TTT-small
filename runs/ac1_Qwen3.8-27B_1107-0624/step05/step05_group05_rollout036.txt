```python
def hotspot_reduction(a, alpha):
    n = len(a)
    conv = full_convolve(a, a)
    k_star = np.argmax(conv)
    # For each i, the contribution to conv[k_star] is a[i] * a[k_star - i]
    # We want to reduce a[i] where a[k_star - i] is large
    contrib = np.zeros(n)
    for i in range(n):
        j = k_star - i
        if 0 <= j < n:
            contrib[i] = a[i] * a[j]
    # Remove mass proportional to contribution, add to low-contribution positions
    total_contrib = contrib.sum()
    if total_contrib < 1e-15:
        return a
    # Scale down high-contribution elements
    scale = 1 - alpha * contrib / total_contrib
    a_new = a * scale
    # Redistribute the removed mass to low-contribution positions
    removed = a - a_new
    # Add to positions with low contribution
    low_mask = contrib < np.median(contrib)
    if low_mask.sum() > 0:
        a_new[low_mask] += removed.sum() * low_mask / low_mask.sum()
    # Normalize
    a_new = np.maximum(a_new, 0)
    a_new = a_new / a_new.sum()
    return a_new
```

**Better approach: Use the subgradient of the max**

The subgradient of `f(a) = max_k conv[k]` at a point where `conv[k*]` is the maximum is the gradient of `conv[k*]`, which is:
`grad[a, i] = a[k*-i] + a[i-k*]` (with boundary handling, i.e., 0 if index out of range).

We can use this to do a projected gradient descent step:
`a_new = a - eta * grad`, then project back to `a >= 0`, `sum(a) = 1`.

But since the max is non-smooth, we should use a smoothing technique (log-sum-exp) or a "majorize" approach.

**Majorization approach:**
At the current point, `conv[k*]` is the maximum. We majorize the objective by a quadratic:
`max_k conv[k] <= conv[k*] + grad_{k*}^T (a - a_current) + (1/(2L))||a - a_current||^2`

Where `L` is a Lipschitz constant. Then we minimize this upper bound, which gives a closed-form solution.

Hybrid optimizer: LP + Adam (log-sum-exp) + Hot-spot directed search + Annealing restarts.
Minimizes 2*n*max(conv(a,a))/sum(a)^2 for non-negative sequences.

import scipy.sparse as sp

def _next_pow2(n):
    k = 1
    while k < n:
        k <<= 1
    return max(2, k)

def _full_convolve(a, b):
    n, m = len(a), len(b)
    out_n = n + m - 1
    N = _next_pow2(out_n)
    fa = np.fft.rfft(a, N)
    fb = np.fft.rfft(b, N)
    return np.fft.irfft(fa * fb, N)[:out_n]

def _score(a):
    n = len(a)
    s = float(a.sum())
    if s < 1e-15:
        return np.inf
    c = _full_convolve(a, a)
    return float(2.0 * n * c.max() / (s * s))

def _score_norm(a):
    n = len(a)
    c = _full_convolve(a, a)
    return float(2.0 * n * c.max())

def _softmax(z):
    z = z - np.max(z)
    e = np.exp(z)
    s = e.sum()
    if s < 1e-300:

    return e / s

    rows_list = []

        j_range = np.arange(j_start, j_end + 1)
        rows_list.append(np.full(len(j_range), k, dtype=np.int32))
        cols_list.append(j_range.astype(np.int32))
