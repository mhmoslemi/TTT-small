    fb = np.fft.rfft(b, N)

Let me use the direct approach: update a directly, then project onto the simplex.

Projecting onto the simplex {a >= 0, sum(a) = 1} can be done efficiently:
1. a_new = a - lr * grad
2. Project: find the largest t such that a_new - t >= 0 and sum(a_new - t) = 1.
   This is: t = (sum(a_new) - 1) / n, but we also need a_new[i] - t >= 0 for all i.
   The proper projection is: sort a_new in descending order, find the threshold.

Actually, the standard simplex projection is:
Given v, find the closest point to v on {x >= 0, sum(x) = 1}.
Algorithm: sort v in descending order: v_(1) >= v_(2) >= ... >= v_(n).
Find the largest m such that v_(m) - (sum_{i=1}^m v_(i) - 1)/m > 0.
Then the projection is max(v_i - threshold, 0) where threshold = (sum_{i=1}^m v_(i) - 1)/m.

This is O(n log n) per step.

Alternatively, I can use the mirror descent / exponential family approach which naturally keeps things in the interior:
a_new = a * exp(-lr * grad) / sum(a * exp(-lr * grad))

This is the multiplicative weight update, which is equivalent to gradient descent in the negative entropy (Fisher) metric on the simplex.

Let me use this approach as it's simple and effective:

def multiplicative_step(a, grad, lr):
    # Compute step in log-space
    z = np.log(np.maximum(a, 1e-300)) - lr * grad
    z = z - z.max()  # numerical stability
    a_new = np.exp(z)
    a_new = a_new / a_new.sum()
    return a_new
