   This is a QP (quadratic objective, quadratic constraint). But the constraint is non-convex (it's a difference of convex functions... wait, `(a*a)[k*]` is convex in `a`? No, it's a quadratic form with a non-negative definite matrix, so it IS convex!).

Wait, `(a*a)[k] = ∑_i ∑_j M_{ij} a_i a_j` where `M` is a symmetric matrix. Is `M` positive semidefinite?

`(a*a)[k] = ∑_i a_i * (2 * a_{k-i})` (from our earlier derivative analysis, the quadratic form has matrix entries related to the shift).

Actually, `(a*a)[k]` as a function of `a` is a quadratic form: `(a*a)[k] = a^T M_k a` where `M_k` is a symmetric matrix with `(M_k)_{ij} = 1/2` if `i + j = k` and both `i, j ∈ [0, n-1]` (and we need to handle the diagonal case).

Wait, let me be more careful. `(a*a)[k] = ∑_i a_i a_{k-i}`. This is a quadratic form in `a`. The matrix `M_k` has:
- `(M_k)_{i, k-i} = 1` if `0 ≤ k-i ≤ n-1` (and `i ≠ k-i`)
- `(M_k)_{i, i} = 1/2` if `2i = k` (for the symmetric part)

Actually, for a quadratic form `a^T M a = ∑_{i,j} M_{ij} a_i a_j`, we need:
`(a*a)[k] = ∑_i a_i a_{k-i} = ∑_{i,j} δ_{i+j=k} a_i a_j = ∑_{i,j} (M_k)_{ij} a_i a_j`

where `(M_k)_{ij} = 1` if `i + j = k` and `i, j ∈ [0, n-1]`, else 0.

But this matrix is not symmetric in the usual sense for the quadratic form. Let me rewrite:
`∑_{i,j} δ_{i+j=k} a_i a_j = ∑_{i: 0≤i≤n-1, 0≤k-i≤n-1} a_i a_{k-i}`

For the quadratic form `a^T M a`, we need `M` to be symmetric, and `a^T M a = ∑_{i,j} M_{ij} a_i a_j`. So we can set:
`M_{ij} = 1/2` if `i + j = k` and `i ≠ j` (both `(i,j)` and `(j,i)` contribute)
`M_{ii} = 1` if `2i = k`

This matrix `M` is a "bidiagonal" (or "anti-diagonal") matrix. Is it positive semidefinite?

For `k = 0`: `M = diag(1, 0, ..., 0)`. PSD. ✓
For `k = 1`: `M` has `M_{0,1} = M_{1,0} = 1/2`. The eigenvalues of `[[0, 1/2], [1/2, 0]]` are `±1/2`. NOT PSD!

So `(a*a)[k]` is NOT a convex function of `a` for `k > 0`. This means the QP approach doesn't directly work.

However, `(a*a)[0] = ∑ a_i^2` IS convex. And `max_k (a*a)[k]` is the max of non-convex functions, so it's non-convex in general.

OK so the problem is non-convex. This explains why the optimization is tricky.

Let me go back to the practical approach. I'll refine the previous algorithm with:

1. **Better multiplicative update**: Use a softmax over all lags (not just active set) to compute the "pressure" at each position. This gives a smoother gradient signal.

2. **Alternating between multiplicative and additive updates**: The multiplicative update is good for maintaining non-negativity and making relative adjustments. The additive (gradient) update is good for fine-tuning.

3. **Nesterov momentum on the gradient step**: This can significantly speed up convergence.

4. **Adaptive beta**: Use a beta that adapts based on the "flatness" of the autocorrelation. If the top few lags are close together, increase beta (sharpen the max). If they're far apart, decrease beta (smooth more).

5. **Frequency-domain initialization**: Create an initial sequence by specifying a power spectrum in the frequency domain and taking the inverse FFT. A flat power spectrum gives a "white noise" like autocorrelation with low peak.

Let me now write the code:

```python
"""
Step function optimization via refined multiplicative equalization + Nesterov-accelerated
projected gradient on LSE-smoothed objective, with frequency-domain initialization.

Key improvements over previous approach:
  1. Softmax-weighted multiplicative update (uses ALL lags, not just active set)
  2. Nesterov-accelerated projected gradient for faster convergence
  3. Frequency-domain initialization with flat power spectrum target
  4. Adaptive beta based on autocorrelation flatness
  5. Better time management with early termination
"""

import numpy as np
from scipy.optimize import minimize
import time


def fast_conv(a):
    """Linear self-convolution via FFT. Returns array of length 2n-1."""
    n = len(a)
    M = 2 * n - 1
    M_fft = 1 << (M - 1).bit_length()
    A = np.fft.rfft(a, M_fft)
    return np.fft.irfft(A * A, M_fft)[:M]


def compute_score(a):
    """Exact score: 2n * max(conv(a,a)) / (sum(a))^2."""
    n = len(a)
    c = fast_conv(a)
    S = float(a.sum())
    if S < 1e-12:
        return np.inf
    return 2.0 * n * float(np.max(c)) / (S * S)


def lse_grad(a, beta):
    """LSE-smoothed score and gradient. Returns (score, grad)."""
    n = len(a)
    c = fast_conv(a)
    S = float(a.sum())
    if S < 1e-12:
        return 1e10, np.zeros(n)
    c_max = float(c.max())
    scaled = beta * (c - c_max)
    # Numerical stability: subtract max before exp
    exp_scaled = np.exp(scaled)
    log_sum = np.log(exp_scaled.sum())
    L = c_max + log_sum / beta
    score = 2.0 * n * L / (S * S)
    p = exp_scaled / exp_scaled.sum()
    
    # Gradient computation: grad_L[j] = 2 * sum_m p[m] * a[abs(m-j)] (with boundary handling)
    # Actually: grad_L[j] = 2 * (p * a_flip)[j] where the convolution is at the right lag
    # More precisely: L = c_max + (1/beta) * log(sum_m exp(beta*(c_m - c_max)))
    # dL/dj = sum_m p_m * dc_m/dj = sum_m p_m * 2*a[m-j] (with zero convention)
    # = 2 * sum_m p_m * a[m-j]
    # This is 2 * (p * a)[j] where the convolution is the cross-correlation at lag j
    # (p conv a)[j] = sum_m p[m] * a[m-j]
    
    # Compute cross-correlation of p and a at lags 0..n-1
    # (p * a)[j] = sum_m p[m] a[m-j] for j = 0, ..., n-1
    # This is the cross-correlation: sum_m p[m] a[m-j]
    # = sum_m p[m+j] a[m] (by change of variable)
    # = (a * p_rev)[j + (n-1)] ... hmm let me just use FFT directly
    
    # (p * a)[j] = sum_{m=0}^{2n-2} p[m] * a[m-j]
    # For this to be non-zero, we need 0 ≤ m-j ≤ n-1, i.e., j ≤ m ≤ j+n-1
    # So (p * a)[j] = sum_{m=j}^{j+n-1} p[m] * a[m-j] = sum_{t=0}^{n-1} p[j+t] * a[t]
    # = (a conv p)[j + n - 1 - ... ] 
    
    # Let me just compute it via circular correlation using FFT
    M_fft = 1 << (3 * n - 2).bit_length()
    P = np.fft.rfft(p, M_fft)
    A_f = np.fft.rfft(a, M_fft)
    # cross[j] = sum_m p[m] a[m-j] = sum_t p[j+t] a[t] (for t = 0..n-1)
    # This is the cross-correlation of p with a, evaluated at lag j
    # In FFT terms: if we compute ifft(conj(P) * A_f), we get sum_m p[m+j] a[m]
    # which is sum_t p[t+j] a[t] = cross[j]. 
    # Wait: ifft(conj(P) * A_f)[j] = (1/M) sum_m exp(2πij/M) conj(P[m]) A_f[m]
    # = (1/M) sum_m exp(2πij/M) P[-m] A_f[m]
    # = sum_k p[k+j] a[k] (circular)
    # For our purpose (no wraparound since we padded enough), this gives cross[j].
    cross = np.fft.irfft(np.conj(P) * A_f, M_fft)[:n]
    g = 2.0 * cross
    
    S2 = S * S
    S3 = S2 * S
    grad = (2.0 * n) * (g / S2 - 2.0 * L / S3)
    return score, grad


def nesterov_projected_grad(a, beta, n_iters=500, target_sum=None, deadline=None):
    """
    Nesterov-accelerated projected gradient on LSE-smoothed score.
    Projects onto {a >= 0, sum(a) = target_sum}.
    """
    n = len(a)
    if target_sum is None:
        target_sum = float(a.sum())
    a = np.clip(a.astype(np.float64), 0.0, 1000.0).copy()
    a = a * (target_sum / a.sum())  # normalize
    
    y = a.copy()
    t_k = 1.0
    best_a = a.copy()
    best_sc = compute_score(a)
    
    for it in range(n_iters):
        if deadline is not None and time.monotonic() > deadline:
            break
        
        sc, grad = lse_grad(y, beta)
        
        # Step size
        # Use a heuristic: step = alpha / (it + 1) where alpha is chosen based on initial gradient norm
        gn = float(np.linalg.norm(grad))
        if gn < 1e-15:
            break
        step = 0.5 / (it + 1)  # diminishing step
        # Or: step = (sc - lower_bound) / (gn*gn + 1e-30)
        # lower_bound for the LSE score is at least 2n / (2n-1) (from Parseval)
        lower_bound = 2.0 * n / (2 * n - 1)
        step = min(step, (sc - lower_bound) / (gn * gn + 1e-30))
        step = max(step, 1e-8)
        
        y_new = y - step * grad
        
        # Project onto {a >= 0, sum(a) = target_sum}
        y_new = np.maximum(y_new, 0.0)
        y_new_sum = y_new.sum()
        if y_new_sum < 1e-12:
            y_new = np.ones(n) * (target_sum / n)
        else:
            y_new = y_new * (target_sum / y_new_sum)
        
        # Nesterov update
        t_new = (1.0 + np.sqrt(1.0 + 4.0 * t_k * t_k)) / 2.0
        a_new = y_new + ((t_k - 1.0) / t_new) * (y_new - y)
        a_new = np.clip(a_new, 0.0, 1000.0)
        a_new = a_new * (target_sum / a_new.sum())
        
        y = y_new
        a = a_new
        t_k = t_new
        
        sc_a = compute_score(a)
        if sc_a < best_sc:
            best_sc = sc_a
            best_a = a.copy()
    
    return best_sc, best_a


def softmax_multiplicative(a, n_iters=200, temperature=50.0, alpha=0.3, deadline=None):
    """
    Softmax-weighted multiplicative equalization.
    Uses ALL lags weighted by softmax of their values.
    At optimum, the weighted average of 2*a_{k-i} over k should be constant.
    """
    n = len(a)
    a = np.clip(a.astype(np.float64), 0.0, 1000.0).copy()
    S = a.sum()
    if S < 1e-12:
        a[:] = 1.0
        S = n
    best_a = a.copy()
    best_sc = compute_score(a)
    
    M_fft = 1 << (3 * n - 2).bit_length()
    
    for it in range(n_iters):
        if deadline is not None and time.monotonic() > deadline:
            break
        
        c = fast_conv(a)
        c_max = float(c.max())
        c_min = float(c.min())
        if c_max < 1e-15:
            break
        
        # Softmax weights over all lags
        # Scale by temperature to control how "peaked" the weights are
        w = np.exp((c - c_max) / (c_max * temperature + 1e-15))
        w = w / w.sum()
        
        # Compute pressure: p[i] = sum_k w[k] * 2 * a[k-i] (with zero convention)
        W = np.fft.rfft(w, M_fft)
        A_f = np.fft.rfft(a, M_fft)
        cross = np.fft.irfft(np.conj(W) * A_f, M_fft)[:n]
        p = 2.0 * cross
        p = np.maximum(p, 1e-15)
        
        # Multiplicative update: a[i] <- a[i] * (1 - alpha + alpha * mean(p)/p[i])
        p_mean = p.mean()
        factor = 1.0 - alpha + alpha * (p_mean / p)
        a = a * factor
        a = np.clip(a, 0.0, 1000.0)
        
        # Renormalize
        S_new = a.sum()
        if S_new < 1e-12:
            a[:] = 1.0
            S = n
            break
        a = a * (S / S_new)
        
        sc = compute_score(a)
        if sc < best_sc:
            best_sc = sc
            best_a = a.copy()
    
    return best_sc, best_a


def freq_init(n, rng, target_peak_ratio=1.0):
    """
    Initialize a sequence with a target peak-to-average ratio in autocorrelation.
    Uses frequency domain: choose |A(ω)|^2 to be as flat as possible.
    """
    M = 2 * n - 1
    M_fft = 1 << (M - 1).bit_length()
    
    # Target: flat power spectrum => flat autocorrelation
    # |A[m]|^2 = C (constant) for all m
    # This gives A[m] = sqrt(C) * exp(i*φ[m])
    # a = ifft(A) should be real and non-negative
    # For real a: A[m] = conj(A[M_fft-m])
    # For non-negative a: need careful phase selection
    
    # Strategy: random phases, take real part, clip to non-negative
    C = n * n / M_fft  # so that sum(a)^2 ≈ n^2
    phases = 2 * np.pi * rng.random(M_fft // 2 + 1)
    A = np.zeros(M_fft // 2 + 1, dtype=np.complex128)
    A[:] = np.sqrt(C) * np.exp(1j * phases)
    # Make it conjugate symmetric (for real a)
    A_full = np.zeros(M_fft, dtype=np.complex128)
    A_full[:M_fft//2+1] = A
    for m in range(1, M_fft//2 + 1):
        A_full[M_fft - m] = np.conj(A[m])
    
    a = np.fft.ifft(A_full)[:n]
    a = np.real(a)
    a = np.maximum(a, 0.0)
    
    if a.sum() < 1e-6:
        a = np.ones(n)
    
    return a


def run_lbfgs(a0, beta, maxiter=3000, maxfun=60000, deadline=None):
    """Run L-BFGS-B on LSE-smoothed score."""
    n = len(a0)
    a0 = np.clip(a0.astype(np.float64), 0.0, 1000.0).copy()
    if a0.sum() < 1e-6:
        a0[:] = 1.0
    bounds = [(0.0, 1000.0)] * n
    
    def obj_wrapper(x, b):
        return lse_grad(x, b)
    
    options = {'ftol': 1e-14, 'gtol': 1e-12, 'maxiter': maxiter, 'maxfun': maxfun, 'maxls': 50}
    if deadline is not None:
        remaining = deadline - time.monotonic()
        if remaining < 2.0:
            sc, _ = lse_grad(a0, beta)
            return compute_score(a0), a0
        options['maxfun'] = min(maxfun, max(100, int(remaining * 300)))
        options['maxiter'] = min(maxiter, max(100, int(remaining * 80)))
    
    try:
        res = minimize(
            obj_wrapper, a0, args=(beta,),
            method='L-BFGS-B', jac=True, bounds=bounds,
            options=options
        )
        a_out = np.clip(res.x, 0.0, 1000.0)
    except Exception:
        a_out = a0
    exact_sc = compute_score(a_out)
    return exact_sc, a_out


def exact_subgrad_polish(a, total_iters=500, deadline=None):
    """
    Projected subgradient descent on the exact max-conv objective with Nesterov momentum.
    """
    n = len(a)
    a = np.clip(a.astype(np.float64), 0.0, 1000.0).copy()
    S = a.sum()
    if S < 1e-12:
        a[:] = 1.0
        S = n
    a = a * (n / S)  # normalize to sum = n
    S_target = n
    
    y = a.copy()
    t_k = 1.0
    best_a = a.copy()
    best_sc = compute_score(a)
    sc_lb = 2.0 * n / (2 * n - 1)  # theoretical lower bound
    
    for it in range(total_iters):
        if deadline is not None and time.monotonic() > deadline:
            break
        
        c = fast_conv(y)
        M_val = float(c.max())
        k_star = int(np.argmax(c))
        sc = 2.0 * n * M_val / (S_target * S_target)
        
        # Subgradient at y
        sg = np.zeros(n)
        j_start = max(0, k_star - n + 1)
        j_end = min(k_star, n - 1)
        if j_end >= j_start:
            sg[j_start:j_end + 1] = 2.0 * y[j_start:j_end + 1][::-1]
        
        # Also account for the 1/(sum)^2 factor
        # grad of 2n*M/(S^2) w.r.t. a: = 2n * (sg/S^2 - 2*M*sg_sum/S^3)
        # where sg_sum = sum(sg * ...) hmm, let me just use the raw subgradient of M
        # and handle the normalization separately
        
        gn = float(np.linalg.norm(sg))
        if gn < 1e-15:
            break
        
        # Step size
        step = (sc - sc_lb) / (gn * gn + 1e-30)
        step = min(step, 1.0 / (it + 1))
        step = max(step, 1e-10)
        
        y_new = y - step * sg
        y_new = np.maximum(y_new, 0.0)
        y_new_sum = y_new.sum()
        if y_new_sum < 1e-12:
            y_new = np.ones(n) * 1.0
        else:
            y_new = y_new * (S_target / y_new_sum)
        
        # Nesterov
        t_new = (1.0 + np.sqrt(1.0 + 4.0 * t_k * t_k)) / 2.0
        a_new = y_new + ((t_k - 1.0) / t_new) * (y_new - y)
        a_new = np.clip(a_new, 0.0, 1000.0)
        a_new = a_new * (S_target / a_new.sum())
        
        y = y_new
        a = a_new
        t_k = t_new
        
        sc_a = compute_score(a)
        if sc_a < best_sc:
            best_sc = sc_a
            best_a = a.copy()
    
    return best_sc, best_a
```

import numpy as np

def fast_conv(a):
    """Linear self-convolution via FFT. Returns array of length 2n-1."""
    n = len(a)
    M = 2 * n - 1
    M_fft = 1 << (M - 1).bit_length()
    A = np.fft.rfft(a, M_fft)
    return np.fft.irfft(A * A, M_fft)[:M]


def compute_score(a):
    """Exact score: 2n * max(conv(a,a)) / (sum(a))^2."""
    n = len(a)
    c = fast_conv(a)
    S = float(a.sum())
    if S < 1e-12:
        return np.inf
    return 2.0 * n * float(np.max(c)) / (S * S)


def compute_score_fast(a, c=None):
    """Score computation reusing pre-computed convolution if available."""
    n = len(a)
    if c is None:
        c = fast_conv(a)
    S = float(a.sum())
    if S < 1e-12:
        return np.inf
    return 2.0 * n * float(np.max(c)) / (S * S)


def lse_grad(a, beta):
    """LSE-smoothed score and gradient. Returns (score, grad)."""
    n = len(a)
    c = fast_conv(a)
    S = float(a.sum())
    if S < 1e-12:
        return 1e10, np.zeros(n)
    c_max = float(c.max())
    scaled = beta * (c - c_max)
    exp_scaled = np.exp(scaled)
    log_sum = np.log(exp_scaled.sum())
    L = c_max + log_sum / beta
    score = 2.0 * n * L / (S * S)
    p = exp_scaled / exp_scaled.sum()

    # Gradient: grad_L[i] = 2 * sum_m p[m] * a[m-i] (cross-correlation)
    M_fft = 1 << (3 * n - 2).bit_length()
    P = np.fft.rfft(p, M_fft)
    A_f = np.fft.rfft(a, M_fft)
    cross = np.fft.irfft(np.conj(P) * A_f, M_fft)[:n]
    g = 2.0 * cross

    S2 = S * S
    S3 = S2 * S
    grad = (2.0 * n) * (g / S2 - 2.0 * L / S3)
    return score, grad


def nesterov_projected_grad(a, beta, n_iters=300, target_sum=None, deadline=None):

def softmax_multiplicative(a, n_iters=100, temperature=30.0, alpha=0.35, deadline=None):
    """
    Softmax-weighted multiplicative equalization.
    Uses ALL lags weighted by softmax to compute pressure at each position.
    At optimum, weighted average of 2*a[k-i] should be constant on support.
    """
    n = len(a)
    a = np.clip(a.astype(np.float64), 0.0, 1000.0).copy()
    S = a.sum()
    if S < 1e-12:
        a[:] = 1.0
        S = n
    best_a = a.copy()
    best_sc = compute_score(a)

    M_fft = 1 << (3 * n - 2).bit_length()

    for it in range(n_iters):
        if deadline is not None and time.monotonic() > deadline:
            break

        c = fast_conv(a)
        c_max = float(c.max())
        if c_max < 1e-15:
            break

        # Softmax weights (higher temperature = flatter weights)
        # Use c_max * temperature as scale to make temperature dimensionless
        w = np.exp((c - c_max) / (c_max * temperature + 1e-15))
        w_sum = w.sum()
        if w_sum < 1e-15:
            w = np.zeros(len(c))
            w[int(np.argmax(c))] = 1.0
        else:
            w = w / w_sum

        # Cross-correlation: p[i] = sum_k w[k] * 2 * a[k-i]
        A_f = np.fft.rfft(a, M_fft)
        W = np.fft.rfft(w, M_fft)
        cross = np.fft.irfft(np.conj(W) * A_f, M_fft)[:n]
        p = 2.0 * cross
        p = np.maximum(p, 1e-15)

        # Damped multiplicative update
        p_mean = p.mean()
        factor = 1.0 - alpha + alpha * (p_mean / p)
        a = a * factor
        a = np.clip(a, 0.0, 1000.0)

        # Renormalize to preserve sum
        S_new = a.sum()
        if S_new < 1e-12:
            a[:] = 1.0
            S = n
            break
        a = a * (S / S_new)

        sc = compute_score(a)
        if sc < best_sc:
            best_sc = sc
            best_a = a.copy()

    return best_sc, best_a


def active_set_multiplicative(a, n_iters=100, threshold_frac=0.98, alpha=0.4, deadline=None):

        S = n
    best_a = a.copy()

        c_max = float(c.max())
        if c_max < 1e-15:
            break

        # Active set

        w = (c >= threshold).astype(np.float64)
        w_sum = w.sum()
        if w_sum == 0:

            w_sum = 1.0
        else:

        cross = np.fft.irfft(np.conj(W) * A_f, M_fft)[:n]

        p = np.maximum(p, 1e-15)

        sc = compute_score(a)
        if sc < best_sc:
            best_sc = sc
            best_a = a.copy()

    return best_sc, best_a


def freq_init(n, rng):

    phases = 2.0 * np.pi * rng.random(M_fft // 2 + 1)
    A = np.zeros(M_fft, dtype=np.complex128)
    A[:M_fft // 2 + 1] = np.sqrt(C) * np.exp(1j * phases[:M_fft // 2 + 1])
    for m in range(1, M_fft // 2 + 1):
        A[M_fft - m] = np.conj(A[m])

    a = np.real(np.fft.ifft(A)[:n])
    a = np.maximum(a, 0.0)
    if a.sum() < 1e-6:
        a = np.ones(n)
    return a


def run_lbfgs(a0, beta, maxiter=5000, maxfun=100000, deadline=None):
    """Run L-BFGS-B on LSE-smoothed score with non-negativity bounds."""
    n = len(a0)
    a0 = np.clip(a0.astype(np.float64), 0.0, 1000.0).copy()
    S0 = a0.sum()
    if S0 < 1e-6:
        a0[:] = 1.0

    bounds = [(0.0, 1000.0)] * n

    def obj_wrapper(x, b):
        return lse_grad(x, b)

    options = {'ftol': 1e-15, 'gtol': 1e-13, 'maxiter': maxiter,
               'maxfun': maxfun, 'maxls': 50}
    if deadline is not None:
        remaining = deadline - time.monotonic()
        if remaining < 3.0:
            sc, _ = lse_grad(a0, beta)
            return compute_score(a0), a0
        options['maxfun'] = min(maxfun, max(200, int(remaining * 400)))
        options['maxiter'] = min(maxiter, max(200, int(remaining * 100)))

    try:
        res = minimize(
            obj_wrapper, a0, args=(beta,),
            method='L-BFGS-B', jac=True, bounds=bounds,
            options=options
        )
        a_out = np.clip(res.x, 0.0, 1000.0)
    except Exception:
        a_out = a0
    exact_sc = compute_score(a_out)
    return exact_sc, a_out


def exact_subgrad_nesterov(a, total_iters=1000, deadline=None):
    """
    Projected subgradient descent on exact max-conv objective with Nesterov momentum.
    """
    n = len(a)
    a = np.clip(a.astype(np.float64), 0.0, 1000.0).copy()
    S_target = n
    S_init = a.sum()
    if S_init < 1e-12:
        a[:] = 1.0
    else:
        a = a * (S_target / S_init)

    x_prev = a.copy()
    y = a.copy()
    t_k = 1.0
    best_a = a.copy()
    best_sc = compute_score(a)
    sc_lb = 2.0 * n / (2.0 * n - 1)

    for it in range(total_iters):
        if deadline is not None and time.monotonic() > deadline:
            break

        c = fast_conv(y)
        M_val = float(c.max())
        k_star = int(np.argmax(c))
        sc = 2.0 * n * M_val / (S_target * S_target)

        # Subgradient of max at peak lag
        sg = np.zeros(n)
        j_start = max(0, k_star - n + 1)
        j_end = min(k_star, n - 1)
        if j_end >= j_start:
            sg[j_start:j_end + 1] = 2.0 * y[j_start:j_end + 1][::-1]

        gn = float(np.linalg.norm(sg))
        if gn < 1e-15:
            break

        step = (sc - sc_lb) / (gn * gn + 1e-30)
        step = min(step, 3.0 / (np.sqrt(it + 1.0) + 1.0))
        step = max(step, 1e-12)

        x_new = y - step * sg
        x_new = np.maximum(x_new, 0.0)
        x_new_sum = x_new.sum()
        if x_new_sum < 1e-12:
            x_new = np.ones(n) * 1.0
        else:
            x_new = x_new * (S_target / x_new_sum)

        t_new = (1.0 + np.sqrt(1.0 + 4.0 * t_k * t_k)) / 2.0
        y = x_new + ((t_k - 1.0) / t_new) * (x_new - x_prev)
        y = np.clip(y, 0.0, 1000.0)
        y_sum = y.sum()
        if y_sum < 1e-12:
            y = x_new.copy()
        else:
            y = y * (S_target / y_sum)

        x_prev = a.copy()
        a = x_new
        t_k = t_new

        sc_a = compute_score(a)
        if sc_a < best_sc:
            best_sc = sc_a
            best_a = a.copy()

    return best_sc, best_a


def perturb_best(best_a, rng, strategy=0):
    """Generate a perturbed version of the best sequence for escape."""
    n = len(best_a)
    if strategy == 0:
        # Gaussian multiplicative perturbation
        scale = 0.03 + 0.07 * rng.random()
        a_pert = best_a * (1.0 + scale * rng.standard_normal(n))
    elif strategy == 1:
        # Targeted: reduce peak contributors, boost others
        c = fast_conv(best_a)
        k_star = int(np.argmax(c))
        contrib = np.zeros(n)
        j_start = max(0, k_star - n + 1)
        j_end = min(k_star, n - 1)
        if j_end >= j_start:
            contrib[j_start:j_end + 1] = best_a[j_start:j_end + 1][::-1]
        top_k = max(10, n // 50)
        top_idx = np.argsort(contrib)[::-1][:top_k]
        bot_idx = np.argsort(contrib)[:n - top_k]
        a_pert = best_a.copy()
        total_red = 0.0
        for j in top_idx:
            red = a_pert[j] * 0.1
            a_pert[j] -= red
            total_red += red
        if len(bot_idx) > 0:
            a_pert[bot_idx] += total_red / len(bot_idx)
    elif strategy == 2:
        # Low-frequency sinusoidal modulation
        freq = 1.0 + 3.0 * rng.random()
        phase = 2.0 * np.pi * rng.random()
        amp = 0.02 + 0.05 * rng.random()
        x = np.arange(n, dtype=np.float64) / n
        a_pert = best_a * (1.0 + amp * np.cos(2.0 * np.pi * freq * x + phase))
    elif strategy == 3:
        # Block swap
        a_pert = best_a.copy()
        block_size = max(32, n // 64)
        n_blocks = n // block_size
        if n_blocks > 2:
            b1, b2 = rng.choice(n_blocks, size=2, replace=False)
            s1, s2 = b1 * block_size, b2 * block_size
            a_pert[s1:s1 + block_size], a_pert[s2:s2 + block_size] = \
                a_pert[s2:s2 + block_size].copy(), a_pert[s1:s1 + block_size].copy()
    else:
        # Random restart on a subset
        a_pert = best_a.copy()
        n_rand = max(100, n // 4)
        idx = rng.choice(n, size=n_rand, replace=False)
        a_pert[idx] = np.clip(1.0 + 0.5 * rng.standard_normal(n_rand), 0.01, 100.0)

    a_pert = np.clip(a_pert, 0.0, 1000.0)
    S = a_pert.sum()
    if S < 1e-12:
        a_pert = np.ones(n)
    else:
        a_pert = a_pert * (len(best_a) / S)
    return a_pert


def propose_candidate(seed=42, budget_s=2400, **kwargs):
    """
    Search for a non-negative sequence minimizing the evaluation function.
    Combines softmax multiplicative equalization, Nesterov-accelerated projected
    gradient, and high-beta L-BFGS with adaptive scheduling.
    """
    rng = np.random.default_rng(seed)
    t_start = time.monotonic()
    total_budget = float(budget_s)
    deadline = t_start + total_budget - 20.0  # 20s buffer

    # Load parent
    parent = None
    try:
        if 'height_sequence_1' in globals() and height_sequence_1 is not None:
            p = np.asarray(height_sequence_1, dtype=np.float64).ravel()
            if p.size >= 64:
                parent = np.clip(p, 0.0, 1000.0)
    except Exception:
        pass

    best_score = np.inf
    best_a = np.ones(8192)

    def _report(sc, a, label):
        nonlocal best_score, best_a
        if sc < best_score:
            best_score = sc
            best_a = a.copy()
            print(f"  [{label}] NEW BEST: {sc:.8f} (n={len(a)}, t={time.monotonic()-t_start:.0f}s)")
            return True
        return False

    # Determine primary length
    primary_n = 8192
    if parent is not None:
        pn = parent.size
        if 2048 <= pn <= 16384:
            primary_n = pn

    print(f"Primary length: {primary_n}")
    if parent is not None:
        print(f"Parent: len={parent.size}, score={compute_score(parent):.8f}")
    print(f"Total budget: {total_budget}s, deadline at t={deadline - t_start:.0f}s")

    # ==================================================================
    # Phase 0: Initial setup (5% time)
    # ==================================================================
    phase0_dl = t_start + 0.05 * total_budget
    print(f"\n{'='*60}")
    print(f"Phase 0: Setup")
    print(f"{'='*60}")

    a_cur = None
    if parent is not None:
        if parent.size >= primary_n:
            a_par = parent[:primary_n].copy()
        else:
            a_par = np.pad(parent, (0, primary_n - parent.size), mode='edge')
        a_par = np.clip(a_par, 0.0, 1000.0)
        a_par = a_par * (primary_n / a_par.sum())
        _report(compute_score(a_par), a_par, "parent")
        a_cur = a_par.copy()

    if a_cur is None:
        a_freq = freq_init(primary_n, rng)
        a_freq = a_freq * (primary_n / a_freq.sum())
        _report(compute_score(a_freq), a_freq, "freq_init")
        a_cur = a_freq.copy()

    # Quick L-BFGS to establish a good starting point
    if time.monotonic() < phase0_dl - 2:
        sc, a_opt = run_lbfgs(a_cur, 50, maxiter=2000, maxfun=30000, deadline=phase0_dl)
        _report(sc, a_opt, "phase0 lbfgs")
        a_cur = a_opt

    print(f"  After Phase 0: best = {best_score:.8f}")

    # ==================================================================
    # Phase 1: Main optimization loop (55% time)
    # ==================================================================
    phase1_dl = t_start + 0.60 * total_budget
    print(f"\n{'='*60}")
    print(f"Phase 1: Main Optimization (t < {phase1_dl - t_start:.0f}s)")
    print(f"{'='*60}")

    a_cur = best_a.copy()
    n = len(a_cur)
    iteration = 0
    no_improve = 0
    prev_best = best_score
    perturb_count = 0

    while time.monotonic() < phase1_dl:
        iteration += 1
        remaining = phase1_dl - time.monotonic()
        if remaining < 15:
            break

        # --- Step A: Softmax multiplicative (all lags) ---
        temp = max(2.0, 40.0 / (1.0 + 0.03 * iteration))
        alpha_mult = min(0.6, 0.25 + 0.005 * iteration)
        n_iters_a = min(60, max(10, int(remaining / 40)))
        sc_a, a_a = softmax_multiplicative(a_cur, n_iters=n_iters_a,
                                            temperature=temp, alpha=alpha_mult,
                                            deadline=phase1_dl)
        if sc_a < best_score:
            _report(sc_a, a_a, f"iter={it} softmax_mult")
            a_cur = a_a
        else:
            a_cur = a_a  # Still use the result as new starting point

        # --- Step B: Nesterov projected gradient ---
        if time.monotonic() < phase1_dl - 5:
            beta_pg = min(200.0, 20.0 * (1.0 + 0.05 * iteration))
            n_iters_b = min(150, max(20, int(remaining / 30)))
            sc_b, a_b = nesterov_projected_grad(a_cur, beta_pg, n_iters=n_iters_b,
                                                 target_sum=n, deadline=phase1_dl)
            if sc_b < best_score:
                _report(sc_b, a_b, f"iter={it} nesterov")
                a_cur = a_b

        # --- Step C: Active set multiplicative (aggressive) ---
        if time.monotonic() < phase1_dl - 5:
            threshold = max(0.95, 0.99 - 0.001 * iteration)
            sc_c, a_c = active_set_multiplicative(a_cur, n_iters=30,
