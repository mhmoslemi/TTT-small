sum_{m=0}^{n-1} a[m]*p[m+j] = (ra * p)[n-1+j]

where ra = a[::-1] and * denotes linear convolution.

So: grad_L[j] = sum_k p[k]*a[k-j]*I(valid) + a[j]*sum_k p[k]*I(valid)
= (ra * p)[n-1+j] + a[j] * (sum of p from index j to j+n-1)

The first term is easy via FFT. The second term is a[j] times a sliding window sum of p.

Let me code this up properly:

```python
def lse_score_grad(a, beta):
    n = len(a)
    c = fast_conv(a)
    S = float(a.sum())
    if S < 1e-12:
        return 1e10, np.zeros(n)
    c_max = float(c.max())
    scaled = beta * (c - c_max)
    # Numerical stability: subtract max before exp
    exp_scaled = np.exp(scaled - scaled.max())  # Actually scaled already has max = 0
    exp_scaled_sum = exp_scaled.sum()
    p = exp_scaled / exp_scaled_sum
    log_sum = np.log(exp_scaled_sum)
    L = c_max + log_sum / beta
    score = 2.0 * n * L / (S * S)
    
    # Gradient of L w.r.t. a
    # grad_L[j] = (ra * p)[n-1+j] + a[j] * window_sum_p[j]
    ra = a[::-1]
    # Compute ra * p via FFT (lengths n and 2n-1, result length 3n-2)
    conv_len = n + (2*n-1) - 1  # = 3n-2
    M_fft = 1 << (conv_len - 1).bit_length()
    RA = np.fft.rfft(ra, M_fft)
    P = np.fft.rfft(p, M_fft)
    rp = np.fft.irfft(RA * P, M_fft)[:conv_len]
    first_part = rp[n-1:n-1+n]  # indices n-1 to 2n-2
    
    # Window sum: window_sum_p[j] = sum_{k=j}^{j+n-1} p[k] (with p=0 outside [0,2n-2])
    p_pad = np.zeros(2*n)  # indices 0 to 2n-1, p is in [0, 2n-2]
    p_pad[:2*n-1] = p
    p_cs = np.concatenate([[0.0], np.cumsum(p_pad)])
    # window_sum_p[j] = p_cs[min(j+n, 2*n-1)] - p_cs[j]  ... 
    # Actually: sum_{k=j}^{min(j+n-1, 2n-2)} p[k] = p_cs[min(j+n, 2*n-1)] - p_cs[j]
    # p_cs has length 2n+1 (indices 0 to 2n)
    # p_cs[i] = sum_{k=0}^{i-1} p_pad[k]
    # sum_{k=j}^{hi} p[k] = p_cs[hi+1] - p_cs[j]
    hi = np.minimum(np.arange(n) + n, 2*n-1)  # hi[j] = min(j+n, 2n-1)
    # Actually we want sum from j to j+n-1 (inclusive), which is p_cs[j+n] - p_cs[j]
    # But j+n-1 might exceed 2n-2, so we need to cap
    # sum_{k=j}^{min(j+n-1, 2n-2)} p[k] = p_cs[min(j+n, 2n-1)] - p_cs[j]
    # p_cs[2n-1] = sum_{k=0}^{2n-2} p_pad[k] = sum p (since p_pad[2n-1] = 0)
    # So for j+n >= 2n-1, i.e., j >= n-1: window = p_cs[2n-1] - p_cs[j]
    # For j+n < 2n-1: window = p_cs[j+n] - p_cs[j]
    window = p_cs[np.minimum(np.arange(n) + n, 2*n-1)] - p_cs[np.arange(n)]
    # Wait, p_cs has length 2n+1 (from the cumsum of 2n elements + 1 prepended zero)
    # p_cs[i] for i in 0..2n
    # p_cs[2n] = sum of all p_pad = sum(p)
    # We want: sum_{k=j}^{hi} p_pad[k] where hi = min(j+n-1, 2n-2)
    # = p_cs[hi+1] - p_cs[j] = p_cs[min(j+n, 2n-1)] - p_cs[j]
    # p_cs has valid indices 0 to 2n
    # min(j+n, 2n-1) is in [n, 2n-1], valid index
    
    second_part = a * window
    grad_L = first_part + second_part
    
    S2 = S * S
    S3 = S2 * S
    grad = 2.0 * n * (grad_L / S2 - 2.0 * L * a / S3)
    
    return score, grad
```
