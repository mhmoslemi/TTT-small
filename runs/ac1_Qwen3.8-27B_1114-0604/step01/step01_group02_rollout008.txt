        if S_new > 1e-10:

So `conv[k] = r^k * min(k+1, n, 2n-1-k)`.

The maximum is either at `k=0` (value `r^0 * 1 = 1`) or at some `k` where `r^k * min(k+1, n, 2n-1-k)` is maximized.

For `r < 1`, `r^k` is decreasing, so the max is at small `k`. Specifically, for `k < n`, `conv[k] = r^k * (k+1)`. The max of `r^k * (k+1)` is at `k ≈ -1/ln(r)` (in continuous approximation).

If `r` is close to 1, the max is at large `k` (near `k ≈ n-1`), and `conv[n-1] ≈ r^{n-1} * n`. The sum is `≈ n * r^{n/2}` (roughly). Then `obj ≈ 2n * n * r^{n-1} / (n^2 * r^n) = 2/r ≈ 2` for `r ≈ 1`.

If `r` is small (say `r = 0.5`), the max is at `k = 0` with value 1. `sum = (1-0.5^n)/(0.5) ≈ 2`. `obj = 2n * 1 / 4 = n/2`. That's terrible for large n.

So geometric decay doesn't seem to help for large n.

What about a "two-sided" geometric: `a[j] = r^{|j-n/2|}`? This puts mass in the center. That's bad (as we saw, central concentration gives high center convolution).

What about mass at the edges? `a[j] = r^{min(j, n-1-j)}`? For `r < 1`, this is high at the edges and low in the center.

Let me not get too deep into analytical analysis and just focus on a good numerical optimization.

Here's my refined plan:

1. **Use the full log-sum-exp gradient** (not top-k) for a smoother, more informative gradient.
2. **Adaptive temperature scheduling**: Start with large t, decrease geometrically.
3. **Diverse initializations**: Include the previous best, U-shaped, sinusoidal, random, geometric, etc.
4. **Adam with restarts**: When stuck, restart from best with perturbation.
5. **Try n = 2048** (same as before) but also consider **n = 4096** for more "attack surface".
6. **Post-processing**: After the main optimization, do a few rounds of:
   - Identifying the top peaks
   - Directly reducing those peaks by adjusting the corresponding a[j] values
   - This is like a "peak-shaving" step

Let me also think about the "peak shaving" idea more carefully. If the max convolution is at position `k*`, then:
- `conv[k*] = sum_j a[j] a[k*-j]`
- To reduce this, we want to decrease `a[j]` for `j` where `a[j] a[k*-j]` is large.
- But decreasing `a[j]` also affects other convolution entries.

A simple heuristic: for the peak at `k*`, decrease `a[j]` proportional to `a[k*-j]` (the "partner" values). This directly reduces the peak while distributing the reduction.

Actually, let me think about this differently. The gradient of the max (at the max point) is:
`d max / d a[i] = 2 * a[k*-i]` (where `k*` is the argmax)

So the steepest descent direction for reducing the max is `a[i] -= lr * a[k*-i]`. This means we should decrease `a[i]` proportional to `a[k*-i]`.

But this is exactly what the gradient-based method does (with the soft-max approximation). So the main improvement is in the smoothing/annealing and the initialization.

Let me write the final code:

```python
"""
Optimized search for minimizing 2n*max(conv(a,a))/(sum(a))^2 using
log-sum-exp smoothed gradient with Adam optimizer, adaptive temperature
annealing, diverse initializations, and peak-shaving post-processing.
"""

import numpy as np
import time


def fast_self_conv(a):
    """Linear self-convolution via real FFT."""
    n = len(a)
    M = 2 * n - 1
    M_fft = 1 << (M - 1).bit_length()
    A = np.fft.rfft(a, M_fft)
    return np.fft.irfft(A * A, M_fft)[:M]


def compute_score(n, a):
    """Compute the objective value."""
    c = fast_self_conv(a)
    S = a.sum()
    if S < 1e-10:
        return np.inf
    return 2.0 * n * float(np.max(c)) / (S * S)


def grad_logsumexp(a, c, t):
    """
    Compute gradient of 2n * LSE(c, t) / S^2 with respect to a.
    Returns (grad, LSE_value, S).
    """
    n = a.size
    S = float(a.sum())
    
    # Softmax weights
    c_max = float(np.max(c))
    w = np.exp((c - c_max) / t)
    w_sum = float(np.sum(w))
    w = w / w_sum
    LSE = c_max + t * np.log(w_sum)
    
    # d LSE / d a[i] = 2 * sum_k w[k] * a[k-i]
    # = 2 * (w_rev * a)[2n-2-i] where w_rev = w[::-1]
    w_rev = w[::-1]
    conv_len = (2 * n - 1) + n - 1
    M_fft = 1 << (conv_len - 1).bit_length()
    W_rev = np.fft.rfft(w_rev, M_fft)
    A = np.fft.rfft(a, M_fft)
    conv_wa = np.fft.irfft(W_rev * A, M_fft)
    
    # grad_LSE[i] = 2 * conv_wa[2n-2-i] for i in [0, n-1]
    # indices: for i=0, conv_wa[2n-2]; for i=n-1, conv_wa[n-1]
    grad_LSE = 2.0 * conv_wa[n - 1:2 * n - 1][::-1]
    
    # d f / d a[i] = 2n * (grad_LSE[i] / S^2 - 2*LSE/S^3)
    S2 = S * S
    S3 = S2 * S
    grad = (2.0 * n / S2) * grad_LSE - (4.0 * n * LSE / S3)
    
    return grad, LSE, S


def adam_step(a, grad, m, v, step, lr, beta1=0.9, beta2=0.999, eps=1e-8):
    """Adam update, returns new a."""
    m[:] = beta1 * m + (1 - beta1) * grad
    v[:] = beta2 * v + (1 - beta2) * grad * grad
    m_hat = m / (1 - beta1 ** step)
    v_hat = v / (1 - beta2 ** step)
    a = a - lr * m_hat / (np.sqrt(v_hat) + eps)
    return np.clip(a, 0.0, 1000.0)


def init_uniform(n):
    return np.ones(n) * 1.0


def init_cos(n, freq, alpha, rng):
    x = np.linspace(0.0, 1.0, n, endpoint=False)
    a = 1.0 + alpha * np.cos(2.0 * np.pi * freq * x)
    return np.clip(a, 0.0, 1000.0)
