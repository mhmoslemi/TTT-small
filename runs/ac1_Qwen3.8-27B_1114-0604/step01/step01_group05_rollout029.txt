- Minimize t subject to b[k] <= t for all k, a >= 0, sum(a) = 1.

This is a nonlinear program (NLP) because the constraints b[k] <= t are quadratic in a.

1. Start with a current solution a.
2. Compute b = conv(a, a), find the "active" constraints (k where b[k] is close to max).
3. Solve a reduced problem: minimize t subject to b[k] <= t for k in the active set, a >= 0, sum(a) = 1.
4. Update the active set and repeat.

The reduced problem is still an NLP, but with fewer constraints.

4. Update t.

If we increase a[i] by δ, the change in b[k] is:
Δb[k] = 2δ * a[k-i] (for k in [i, i+n-1], i.e., where k-i is a valid index)

Actually, when k-i = i (k = 2i), there's only one term a[i]*a[i] = a[i]^2, and Δ(a[i]^2) = 2a[i]*δ. So Δb[2i] = 2a[i]*δ.
When k-i ≠ i but 0 ≤ k-i < n, there are two terms, and Δb[k] = 2δ*a[k-i].
When k-i < 0 or k-i ≥ n, Δb[k] = 0.

So the pattern is: Δb[k] = 2δ * a[k-i] for k ∈ [i, i+n-1] (with the understanding that a[k-i] is the "other" factor).

This means: increasing a[i] increases b[k] by 2δ*a[k-i] for k in [i, i+n-1].
Decreasing a[i] decreases b[k] by 2δ*a[k-i] for k in [i, i+n-1].

**Key insight for coordinate descent**: If we decrease a[i], ALL affected b[k] values decrease (since a[k-i] ≥ 0). So decreasing a[i] can never make the max worse! The only "cost" is that we need to add the mass back somewhere else (to maintain sum=1), and that will increase some other b[k] values.

So the coordinate descent step is:
1. Choose coordinate i to decrease.
2. Decrease a[i] by δ.
3. Add δ to some other coordinate(s) to maintain sum=1.
4. Check if the max of b improved.

The "best" coordinate to decrease is the one that most reduces the current max. The max is b[k*] for some k*. The reduction in b[k*] from decreasing a[i] is 2δ*a[k*-i] (if 0 ≤ k*-i < n). So we want to maximize a[k*-i] (i.e., find i such that a[k*-i] is large, equivalently, find the large element that "pairs" with a[i] at position k*).

But we also need to consider: adding δ to coordinate j increases b[k] by 2δ*a[k-j] for k in [j, j+n-1]. The maximum increase is 2δ*max(a) (roughly). So we need 2δ*max(a) ≤ the reduction in the current max, i.e., 2δ*max(a) ≤ 2δ*a[k*-i], which means max(a) ≤ a[k*-i]. This is only possible if a[k*-i] = max(a).

So the strategy is:
1. Find k* = argmax(b).
2. Find the pair (i, j) = (i, k*-i) (or equivalently (k*-i, i)) that maximizes a[i]*a[k*-i] (the largest product term in b[k*]).
3. Decrease the larger of a[i] and a[k*-i] by δ.
4. Add δ to a coordinate that minimizes the maximum increase in b.

import numpy as np

def fft_conv(a):
    """Linear full convolution a*a via FFT, clipped to non-negative."""
    a = np.asarray(a, dtype=np.float64)
    n = a.size
    if n == 0:
        return np.empty(0, dtype=np.float64)
    if n == 1:
        return np.array([a[0] * a[0]], dtype=np.float64)
    need = 2 * n - 1
    size = 1
    while size < need:
        size <<= 1
    F = np.fft.rfft(a, size)
    b = np.fft.irfft(F * F, size)[:need]
    return np.maximum(b, 0.0)


def fast_score(a):
    """Compute 2*n*max(conv(a,a)) with sum(a) assumed to be 1."""
    a = np.asarray(a, dtype=np.float64)
    n = a.size
    if n == 0:
        return float('inf')
    S = float(np.sum(a))
    if S <= 0 or not np.isfinite(S):
        return float('inf')
    b = fft_conv(a)
    M = float(np.max(b))
    if not np.isfinite(M):
        return float('inf')
    return float(2.0 * n * M / (S * S))


def smooth_max_topk(b, beta, topk=64):
    """
    Smooth max focusing on top-k elements.
    Returns (smooth_max_value, weights_vector_of_length_2n-1).
    """
    b = np.asarray(b, dtype=np.float64)
    m = b.size
    if m == 0:
        return float('inf'), np.empty(0)
    mx = float(np.max(b))
    if mx <= 0:
        w = np.ones(m) / m
        return 0.0, w
    # Use top-k selection for sharper focus
    if topk < m:
        # Find top-k indices
        if topk >= m:
            idx = np.arange(m)
        else:
            # Use argpartition for efficiency
            part_idx = np.argpartition(b, -topk)[-topk:]
            idx = part_idx
        # Weights only on top-k
        x = beta * (b[idx] - mx)
        x = np.clip(x, -745.0, 0.0)
        e = np.exp(x)
        Z = float(np.sum(e))
        if Z <= 0 or not np.isfinite(Z):
            e = np.zeros(len(idx))
            e[int(np.argmax(b[idx]))] = 1.0
            Z = 1.0
        w_topk = e / Z
        w = np.zeros(m, dtype=np.float64)
        w[idx] = w_topk
        G = mx + float(np.log(Z)) / beta
    else:
        x = beta * (b - mx)
        x = np.clip(x, -745.0, 0.0)
        e = np.exp(x)
        Z = float(np.sum(e))
        if Z <= 0 or not np.isfinite(Z):
            e = np.zeros(m)
            e[int(np.argmax(b))] = 1.0
            Z = 1.0
        w = e / Z
        G = mx + float(np.log(Z)) / beta
    return float(G), w


def corr_vector(p, w):
    """
    Compute s[i] = sum_j p[j] * w[i+j] for i=0..n-1.
    This is the gradient of sum_k w[k]*b[k] w.r.t. p[i] (times 2).
    Uses FFT for efficiency.
    """
    p = np.asarray(p, dtype=np.float64)
    w = np.asarray(w, dtype=np.float64)
    n = p.size
    m = w.size
    if n == 0 or m == 0:
        return np.zeros(n, dtype=np.float64)
    need = n + m - 1
    size = 1
    while size < need:
        size <<= 1
    P = np.fft.rfft(p, size)
    # We need s[i] = sum_j p[j] * w[i+j]
    # This is a cross-correlation. Let's use the trick:
    # s[i] = sum_j p[j] * w[i+j]
    # Let's define w_rev[j] = w[m-1-j], then:
    # s[i] = sum_j p[j] * w[i+j] = sum_j p[j] * w_rev[m-1-i-j]
    # This is the convolution (p * w_rev)[m-1-i]
    w_rev = w[::-1].copy()
    WR = np.fft.rfft(w_rev, size)
    C = np.fft.irfft(P * WR, size)[:need]
    # s[i] = C[m-1-i] for i=0..n-1
    # C has indices 0..m-1 in the relevant range
    s = C[m - n : m][::-1].copy()
    return np.ascontiguousarray(s, dtype=np.float64)


def project_simplex(v, target=1.0):
    """Project v onto {x >= 0, sum(x) = target}."""
    v = np.asarray(v, dtype=np.float64)
    nv = v.size
    if nv == 0:
        return v
    if target <= 0:
        return np.zeros(nv, dtype=np.float64)
    if not np.all(np.isfinite(v)):
        return np.full(nv, target / nv, dtype=np.float64)
    lo = float(np.min(v)) - 1.0
    hi = float(np.max(v)) + 1.0
    for _ in range(60):
        mid = 0.5 * (lo + hi)
        s = float(np.sum(np.maximum(v - mid, 0.0)))
        if s > target:
            lo = mid
        else:
            hi = mid
    tau = 0.5 * (lo + hi)
    q = np.maximum(v - tau, 0.0)
    s = float(np.sum(q))
    if s <= 0 or not np.isfinite(s):
        q = np.full(nv, target / nv, dtype=np.float64)
    else:
        q *= target / s
    return q


def normalize_simplex(p):
    """Clamp nonnegative and normalize to sum 1."""
    p = np.asarray(p, dtype=np.float64).copy()
    if p.size == 0:
        return p
    p = np.where(np.isfinite(p), p, 0.0)
    p = np.maximum(p, 0.0)
    s = float(np.sum(p))
    if s <= 0 or not np.isfinite(s):
        return np.full(p.shape, 1.0 / float(p.size), dtype=np.float64)
    p *= 1.0 / s
    return p


def block_to_p(n, B, c):
    """Convert block log-weights to full sequence."""
    L = n // B
    z = np.zeros(B, dtype=np.float64)
    if B > 1:
        c = np.asarray(c, dtype=np.float64).reshape(-1)
        m = min(B - 1, c.size)
        if m > 0:
            z[:m] = c[:m]
    z = z - np.max(z)
    wb = np.exp(z)
    s = float(np.sum(wb))
    if s <= 0 or not np.isfinite(s):
        wb = np.ones(B) / B
    else:
        wb /= s
    H = wb / L
    return np.repeat(H, L)


def block_obj(c, n, B, beta, topk):
    """Block-constant objective and gradient."""
    L = n // B
    z = np.zeros(B, dtype=np.float64)
    if B > 1:
        c = np.asarray(c, dtype=np.float64).reshape(-1)
        m = min(B - 1, c.size)
        if m > 0:
            z[:m] = c[:m]
    if not np.all(np.isfinite(z)):
        return float('inf'), np.zeros(max(0, B - 1), dtype=np.float64)
    z = z - np.max(z)
    wb = np.exp(z)
    s = float(np.sum(wb))
    if s <= 0 or not np.isfinite(s):
        wb = np.ones(B) / B
    else:
        wb /= s
    H = wb / L
    p = np.repeat(H, L)
    b = fft_conv(p)
    G, w = smooth_max_topk(b, beta, topk)
    if not np.isfinite(G):
        return float('inf'), np.zeros(max(0, B - 1), dtype=np.float64)
    svec = corr_vector(p, w)
    svec = np.maximum(svec, 0.0)
    g = 2.0 * svec
    Gsum = g.reshape(B, L).sum(axis=1)
    Wavg = float(np.dot(wb, Gsum))
    gradz = (wb / L) * (Gsum - Wavg)
    grad = n * gradz[:-1]
    grad = np.where(np.isfinite(grad), grad, 0.0)
    return float(n * G), grad.astype(np.float64)


def run_block_lbfgs(c0, n, B, beta, topk, max_iter=80):
    """Run L-BFGS-B on block log-weights."""
    if not HAVE_SCIPY:
        return np.asarray(c0, dtype=np.float64)
    c0 = np.asarray(c0, dtype=np.float64).reshape(-1)
    expected = max(0, B - 1)
    if c0.size != expected:
        tmp = np.zeros(expected, dtype=np.float64)
        m = min(tmp.size, c0.size)
        if m > 0:
            tmp[:m] = c0[:m]
        c0 = tmp
    c0 = np.clip(c0, -5.0, 5.0)
    bounds = [(-5.0, 5.0)] * expected
    options = {"maxiter": max_iter, "ftol": 1e-10, "gtol": 1e-5, "maxls": 30}
    try:
        res = minimize(block_obj, c0, args=(n, B, beta, topk),
                       method="L-BFGS-B", jac=True, bounds=bounds, options=options)
        c = np.asarray(res.x, dtype=np.float64)
    except Exception:
        c = c0
    if not np.all(np.isfinite(c)):
        c = c0
    return np.clip(c, -5.0, 5.0)


def gen_starts(n, rng, count=12):
    """Generate diverse starting profiles."""
    starts = []
    # Uniform
    starts.append(np.full(n, 1.0 / n, dtype=np.float64))
    x = np.linspace(0.0, 1.0, n, dtype=np.float64)
    # Monotone profiles (various slopes)
    for a in (-4.0, -2.0, -1.0, 1.0, 2.0, 4.0):
        z = a * (x - 0.5)
        p = np.exp(z)
        p = p / p.sum()
        starts.append(p)
    # Power law profiles
    for alpha in (0.3, 0.7, 1.5, 2.0):
        p = np.power(np.arange(1, n + 1, dtype=np.float64), alpha)
        p = p / p.sum()
        starts.append(p)
    # Bimodal
    p = np.ones(n, dtype=np.float64)
    p[:n // 4] = 1.8
    p[3 * n // 4:] = 1.8
    p /= p.sum()
    starts.append(p)
    # Random smooth
    for _ in range(3):
        zc = rng.normal(size=n) + 1j * rng.normal(size=n)
        z = np.real(np.fft.ifft(zc))[:n]
        z = z - float(np.mean(z))
        z = 1.2 * np.tanh(z)
        p = np.exp(z)
        p = p / p.sum()
        starts.append(p)
    return starts[:count]


def active_gradient_refine(p0, deadline, rng, beta_start=5000.0, beta_end=500000.0,
                           topk_start=8, topk_end=512, max_iter=500000):
    """
    Main refinement: projected gradient with adaptive top-k and beta.
    """
    p = normalize_simplex(p0)
    n = p.size
    if n == 0:
        return p, float('inf')
    # Break symmetry
    if n > 1 and float(np.max(np.abs(p - p.mean()))) < 1e-14:
        t = 0.1 * np.arange(n, dtype=np.float64)
        p = normalize_simplex(p * (1.0 + 1e-4 * np.sin(t)))

    best_p = p.copy()
    best_score = fast_score(p)
    step = 1.0
    no_improve = 0
    it = 0
    total_iter = max_iter

    while it < total_iter and time.monotonic() < deadline:
        it += 1
        # Adaptive scheduling
        frac = float(it) / float(total_iter)
        beta = beta_start * (beta_end / beta_start) ** frac
        topk = max(4, int(topk_start + (topk_end - topk_start) * frac))
        topk = min(topk, 2 * n - 1)

        b = fft_conv(p)
        M = float(np.max(b))
        G, w = smooth_max_topk(b, beta, topk)
        if not np.isfinite(G):
            break
        cur_smooth = float(n) * G
        cur_score = float(2.0 * n * M)

        if cur_score < best_score - 1e-10:
            best_score = cur_score
            best_p = p.copy()
            no_improve = 0
        else:
            no_improve += 1

        if it % 500 == 0:
            print(f"  ag it={it} beta={beta:.0f} topk={topk} best={best_score:.8f} step={step:.2e} noimp={no_improve}")

        if no_improve > 1500:
            # Tighten: increase beta, reduce step
            beta *= 2.0
            step *= 0.5
            no_improve = 0
            if step < 1e-8:
                break

        svec = corr_vector(p, w)
        svec = np.maximum(svec, 0.0)
        g = 2.0 * svec
        grad = g - float(np.mean(g))
        gnorm = float(np.linalg.norm(grad))
        if not np.isfinite(gnorm) or gnorm < 1e-15:
            break

        accepted = False
        base = step
        for mult in (1.0, 0.5, 0.25, 0.1, 0.05, 0.02, 0.01, 0.005, 0.002, 0.001):
            alpha = base * mult
            q = project_simplex(p - alpha * grad, 1.0)
            qb = fft_conv(q)
            m2 = float(np.max(qb))
            G2, _ = smooth_max_topk(qb, beta, topk)
            if not np.isfinite(G2):
                continue
            if float(n) * G2 < cur_smooth - 1e-14:
                p = q
                cur_smooth = float(n) * G2
                accepted = True
                if float(2.0 * n * m2) < best_score - 1e-10:
                    best_score = float(2.0 * n * m2)
                    best_p = p.copy()
                    no_improve = 0
                break

        if not accepted:
            step *= 0.4
            if step < 1e-8:
                break
        else:
            if step < 3.0:
                step = min(3.0, step * 1.15)

    return best_p, best_score


def coord_descent_refine(p0, deadline, rng, max_passes=5):
    """
    Greedy coordinate descent: find peak-contributing coordinates and
    redistribute mass to low-impact coordinates.
    """
    p = normalize_simplex(p0).copy()
    n = p.size
    best_p = p.copy()
    best_score = fast_score(p)
    print(f"  CD start score={best_score:.8f}")

    for pnum in range(max_passes):
        if time.monotonic() >= deadline:
            break
        b = fft_conv(p)
        M = float(np.max(b))
        k_star = int(np.argmax(b))

        # Find coordinates that contribute most to b[k_star]
        # b[k_star] = sum_j a[j]*a[k_star - j]
        # The "other" index for coordinate j is k_star - j
        contrib = np.zeros(n, dtype=np.float64)
        for j in range(n):
            other = k_star - j
            if 0 <= other < n:
                contrib[j] = p[j] * p[other]

        # Sort by contribution (descending)
        order = np.argsort(-contrib)
        # Also find "safe" coordinates to add mass to (low impact on max)
        # A coordinate j is "safe" if adding to it doesn't increase b near the max
        # The increase in b[k] from adding delta to a[j] is 2*delta*a[k-j]
        # Max increase is 2*delta*max(a) roughly
        # We want to add to coordinates where the "neighborhood" is small

        # Strategy: move mass from top contributors to bottom contributors
        top_count = min(n // 10, 200)
        bottom_count = min(n // 10, 200)
        top_idx = order[:top_count]
        bottom_idx = order[-bottom_count:]

        # Compute total mass to move
        total_move = 0.0
        for i in top_idx:
            # We can reduce p[i] by at most p[i] (to zero)
            total_move += p[i]
        total_move *= 0.05  # Only move 5% of the mass in top contributors
        if total_move <= 0:
            break

        # Distribute to bottom coordinates
        n_bottom = len(bottom_idx)
        if n_bottom == 0:
            break
        add_each = total_move / n_bottom

        improved = False
        for i in top_idx:
            reduce_amt = min(p[i], total_move / len(top_idx))
            if reduce_amt <= 0:
                continue
            p[i] -= reduce_amt
            # Distribute to bottom
            for j in bottom_idx:
                p[j] += reduce_amt / n_bottom

        # Renormalize
        s = float(np.sum(p))
        if s > 0 and np.isfinite(s):
            p /= s
        else:
            p = best_p.copy()
            break
        p = np.maximum(p, 0.0)

        sc = fast_score(p)
        if sc < best_score - 1e-10:
            best_score = sc
            best_p = p.copy()
            improved = True
            print(f"  CD pass {pnum}: score={best_score:.8f}")
        else:
            p = best_p.copy()  # Revert
            # Try smaller step
            print(f"  CD pass {pnum}: no improvement, reverting")
            # Reduce the step size
            total_move *= 0.5
            if total_move < 1e-10:
                break

    return best_p, best_score


def coord_descent_v2(p0, deadline, rng, num_rounds=20000):
    """
    More refined coordinate descent: at each step, pick the coordinate that
    most reduces the max, and add mass to the best target.
    """
    p = normalize_simplex(p0).copy()
    n = p.size
    best_p = p.copy()
    best_score = fast_score(p)
    b = fft_conv(p)
    M = float(np.max(b))
    k_star = int(np.argmax(b))

    # Precompute "impact" of each coordinate on b[k_star]
    # Reducing p[i] reduces b[k_star] by 2*delta*p[k_star-i] (if valid)
    impact = np.zeros(n, dtype=np.float64)
    for i in range(n):
        other = k_star - i
        if 0 <= other < n:
            impact[i] = p[other]

    # "Safety" of adding to coordinate j: max increase in b is ~2*delta*max(a)
    # But more precisely, the max increase at position k is 2*delta*p[k-j]
    # The worst case is 2*delta*max(p)
    # We want to add to j where the max of p[k-j] over k in [j, j+n-1] is smallest
    # This is approximately the coordinate where p is "small" in its neighborhood

    # For efficiency, just use: safety[j] = p[j] (adding to small p is safer)
    # Actually, safety should be based on the max of p in the range [0, n-1] shifted by j
    # Which is just max(p) for any j. So safety is the same for all j.
    # Better: use the average of p as a proxy.

    step_size = 1e-4
    for r in range(num_rounds):
        if time.monotonic() >= deadline:
            break
        # Pick the coordinate with highest impact (most reduces the peak)
        # But also consider: we can only reduce p[i] by at most p[i]
        # Score: impact[i] * min(p[i], step_size)
        effective = impact * np.minimum(p, step_size)
        i_src = int(np.argmax(effective))
        if effective[i_src] <= 0:
            break

        # Pick target: minimize the increase in max
        # The increase at position k from adding delta to p[j] is 2*delta*p[k-j]
        # The max increase is 2*delta*max(p[k-j] for valid k) = 2*delta*max(p)
        # So all targets have the same max increase. Use: minimize the increase
        # at the current peak position k_star.
        # Increase at k_star from adding to j: 2*delta*p[k_star-j] (if valid)
        # We want p[k_star-j] to be small.
        target_impact = np.zeros(n, dtype=np.float64)
        for j in range(n):
            other = k_star - j
            if 0 <= other < n:
                target_impact[j] = p[other]
            else:
                target_impact[j] = 0.0

        # Pick j with smallest target_impact (and j != i_src)
        target_impact[i_src] = np.inf
        j_dst = int(np.argmin(target_impact))
        if target_impact[j_dst] >= np.inf:
            break

        delta = min(step_size, p[i_src])
        if delta <= 0:
            break

        p[i_src] -= delta
        p[j_dst] += delta

        # Update impact vector (approximate)
        # Recompute if needed (expensive, so do every 50 steps)
        if r % 50 == 0:
            b = fft_conv(p)
            M = float(np.max(b))
            k_star = int(np.argmax(b))
            sc = float(2.0 * n * M)
            if sc < best_score - 1e-10:
                best_score = sc
                best_p = p.copy()
            # Update impact
            impact = np.zeros(n, dtype=np.float64)
            for i in range(n):
                other = k_star - i
                if 0 <= other < n:
                    impact[i] = p[other]
            target_impact = np.zeros(n, dtype=np.float64)
            for j in range(n):
                other = k_star - j
                if 0 <= other < n:
                    target_impact[j] = p[other]
                else:
                    target_impact[j] = 0.0

        # Occasionally check score
        if r % 200 == 0:
            b = fft_conv(p)
            M = float(np.max(b))
            sc = float(2.0 * n * M)
            if sc < best_score - 1e-10:
                best_score = sc
                best_p = p.copy()

    return best_p, best_score


def official_score(seq):
    """Call the authoritative evaluator."""
    try:
        val = evaluate_sequence(seq)
        val = float(val)
    except Exception:
        return float('inf')
    if np.isfinite(val):
        return val
    return float('inf')


def propose_candidate(seed=42, budget_s=2400):
    """
    Main search function. Returns a list of non-negative floats minimizing
    the evaluation function.
    """
    try:
        seed = int(seed)
    except Exception:
        seed = 42
    try:
        budget_s = float(budget_s)
    except Exception:
        budget_s = 2400.0

    if budget_s <= 0:
        return [1.0]

    start_time = time.monotonic()
    reserve = 60.0
    deadline = start_time + max(0.0, budget_s - reserve)

    rng = np.random.default_rng(seed)

    # Choose sequence length
    N = 8192

    # Get initial best
    best_score = float('inf')
    best_p = np.full(N, 1.0 / N, dtype=np.float64)

    # Try to use height_sequence_1 if available
    try:
        if 'height_sequence_1' in globals() and height_sequence_1 is not None:
            hs = np.array(height_sequence_1, dtype=np.float64)
            if hs.size == N and np.all(hs >= 0) and np.all(np.isfinite(hs)):
                hs = normalize_simplex(hs)
                sc = fast_score(hs)
                if np.isfinite(sc) and sc < best_score:
                    best_score = sc
                    best_p = hs.copy()
                    print(f"Using height_sequence_1: score={best_score:.8f}")
    except Exception:
        pass

    # Phase 1: Block L-BFGS for better initialization
    if time.monotonic() < deadline - 300:
        print("Phase 1: Block L-BFGS optimization")
        best_c = np.zeros(16, dtype=np.float64)
        best_B_score = fast_score(best_p)

        for B in (8, 16, 32, 64, 128):
            if time.monotonic() >= deadline - 250:
                break
            if B >= N or N % B != 0:
                continue
            for beta, topk in [(5000, 16), (20000, 64), (100000, 256)]:
                if time.monotonic() >= deadline - 250:
                    break
                c0 = np.zeros(B - 1, dtype=np.float64)
                # Also try some structured inits
                x = np.linspace(0, 1, B - 1, dtype=np.float64)
                inits = [
                    c0,
                    2.0 * (x - 0.5),
                    -2.0 * (x - 0.5),
                    3.0 * np.cos(2 * np.pi * x),
                    rng.normal(0, 1, B - 1),
                ]
                for c_init in inits:
                    if time.monotonic() >= deadline - 250:
                        break
                    c = run_block_lbfgs(c_init, N, B, beta, topk, max_iter=60)
                    p = block_to_p(N, B, c)
                    sc = fast_score(p)
                    if np.isfinite(sc) and sc < best_B_score:
                        best_B_score = sc
                        best_c = c.copy()

            p_B = block_to_p(N, B, best_c)
            sc_B = fast_score(p_B)
            if np.isfinite(sc_B) and sc_B < best_score:
                best_score = sc_B
                best_p = p_B.copy()
                print(f"  Block B={B}: score={best_score:.8f}")

    # Phase 2: Active-set gradient refinement (main phase)
    # Use multiple starts
    all_starts = [best_p]
    remaining = deadline - time.monotonic()
    if remaining > 200:
        for ps in gen_starts(N, rng, count=8):
            sc = fast_score(ps)
            if np.isfinite(sc) and sc < 2.5:  # Only use reasonable starts
                all_starts.append(ps)

    # Score and sort starts
    scored_starts = []
    for ps in all_starts:
        sc = fast_score(ps)
        scored_starts.append((sc, ps))
    scored_starts.sort(key=lambda x: x[0])

    # Allocate time among top starts
    top_starts = scored_starts[:4]
    total_time = deadline - time.monotonic() - 300  # Reserve 300s for later phases
    fracs = [0.45, 0.30, 0.15, 0.10]

    for idx, (sc_s, p_s) in enumerate(top_starts):
        if time.monotonic() >= deadline - 300:
            break
        frac = fracs[idx] if idx < len(fracs) else 0.1
        alloc = total_time * frac
        sub_deadline = time.monotonic() + alloc
        print(f"Phase 2: Active gradient refine, start {idx}, initial score={sc_s:.8f}, alloc={alloc:.0f}s")

        p_fit, sc_fit = active_gradient_refine(
            p_s, sub_deadline, rng,
            beta_start=5000.0, beta_end=500000.0,
            topk_start=8, topk_end=512,
            max_iter=300000
        )
        if np.isfinite(sc_fit) and sc_fit < best_score:
            best_score = sc_fit
            best_p = p_fit.copy()
            print(f"  After active gradient: score={best_score:.8f}")

    # Phase 3: Coordinate descent refinement
    if time.monotonic() < deadline - 120:
        print("Phase 3: Coordinate descent refinement")
        cd_deadline = min(deadline - 60, time.monotonic() + 120)
        p_cd, sc_cd = coord_descent_v2(best_p, cd_deadline, rng, num_rounds=50000)
        if np.isfinite(sc_cd) and sc_cd < best_score:
            best_score = sc_cd
            best_p = p_cd.copy()
            print(f"  After CD v2: score={best_score:.8f}")

    # Phase 4: Final short active gradient polish
    if time.monotonic() < deadline - 60:
        print("Phase 4: Final polish")
        polish_deadline = deadline - 30
        p_pol, sc_pol = active_gradient_refine(
            best_p, polish_deadline, rng,
            beta_start=100000.0, beta_end=1000000.0,
            topk_start=16, topk_end=128,
            max_iter=100000
        )
        if np.isfinite(sc_pol) and sc_pol < best_score:
            best_score = sc_pol
            best_p = p_pol.copy()
            print(f"  After polish: score={best_score:.8f}")

    # Final cleanup
    final_p = normalize_simplex(best_p)
    final_p = np.maximum(final_p, 0.0)
    final_p = np.minimum(final_p, 1000.0)
    final_seq = [float(x) for x in final_p]

    # Verify with official scorer
    off = official_score(final_seq)
    print(f"Official score: {off:.8f}")

    if not np.isfinite(off) or off > 2.0 + 1e-9:
        # Fallback to uniform
        return [1.0] * N

    return final_seq
