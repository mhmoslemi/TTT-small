    n = len(a)
    # Find top K peaks

    n = len(a)
    # Find top K peaks
    if K >= len(c):
        peaks = np.argsort(c)[::-1]
    else:
        peaks = np.argpartition(c, -K)[-K:]
    vals = c[peaks]
    M = vals[0] if vals[0] >= vals.max() else vals.max()
    # Actually, peaks from argpartition are not sorted, so:
    M = vals.max()
    wts = np.exp((vals - M) / temp)
    wts /= wts.sum()
    
    g = np.zeros(n)
    for i in range(len(peaks)):
        k = peaks[i]
        w = wts[i]
        if w < 1e-15:
            continue
        j_lo = max(0, k - n + 1)
        j_hi = min(k, n - 1)
        if j_lo > j_hi:
            continue
        # g[j] += 2 * w * a[k-j] for j in [j_lo, j_hi]
        # k-j ranges from k-j_hi to k-j_lo
        slice_a = a[k - j_hi : k - j_lo + 1]  # a[k-j_hi], ..., a[k-j_lo]
        g[j_lo:j_hi+1] += 2.0 * w * slice_a[::-1]
    
    return g, M, wts.sum()

Wait, I realize there's an issue with my approach. The mirror descent step as I've defined it might be too aggressive or not aggressive enough. Let me think about the learning rate more carefully.

The objective we're trying to minimize (with sum=1 normalization) is $\phi(a) = \max_k c[k]$ where $c = a * a$.

The mirror descent update is:
$a_j^{new} \propto a_j \cdot \exp(-\eta \cdot g_j)$

where $g_j$ is the subgradient. For the max at a single point $k^*$:
$g_j = 2 \cdot a[k^* - j]$ (for valid $j$)

So the update is:
$a_j^{new} \propto a_j \cdot \exp(-2\eta \cdot a[k^* - j])$

This means: elements $a_j$ that are "responsible" for the peak (i.e., $a[k^* - j]$ is large) get decreased. This makes sense!

The learning rate $\eta$ controls how aggressively we reduce the responsible elements. If $\eta$ is too large, we might overcorrect and create new peaks elsewhere. If too small, convergence is slow.

A good strategy:
- Start with moderate $\eta$ (e.g., 0.1-1.0)
- Decrease $\eta$ geometrically over time
- Use the "no improvement" counter to trigger restarts

Let me also think about whether I should add a "regularization" term to the gradient. If I add a small $\epsilon$ to the gradient, I get:
$g_j^{reg} = g_j + \epsilon \cdot \delta_{j,0}$ (or some other regularizer)

This would prevent any element from going exactly to zero, maintaining support. But it also shifts the optimum. Maybe better to just clip at a small positive value (like $1e-8$).

Actually, I think the key issue is: with mirror descent, the elements that get reduced will asymptotically approach 0 but never reach it (due to the multiplicative update). This is good because it maintains full support. But it might slow down convergence if we need some elements to be exactly 0 for the optimal solution.

For this problem, I don't think the optimal solution requires exact zeros (it's more likely to have a smooth-ish shape), so this should be fine.

Let me now think about potential issues:
1. **Numerical stability**: The exponential in the mirror descent can underflow. Solution: subtract the max before exponentiating (like in softmax).
2. **Convergence**: The problem is non-convex (in the original coordinates), so we might converge to a local minimum. Solution: multiple restarts with different initializations.
3. **Time management**: Need to ensure we return within the time budget.

    conv_len = 2*n - 1
    N = 1 << (conv_len - 1).bit_length()
    A = np.fft.rfft(a, N)
    return np.fft.irfft(A * A, N)[:conv_len]

    """Compute the weighted-peak gradient via FFT cross-correlation."""
    n = len(a)
    conv_len = 2*n - 1
    if K >= conv_len:
        peaks = np.argsort(c)[::-1]
    else:
        peaks = np.argpartition(c, -K)[-K:]
    vals = c[peaks]
    M = float(vals.max())
    if temp < 1e-15:

        top = np.argmax(vals)
        wts = np.zeros(len(vals))
        wts[top] = 1.0
    else:
        wts = np.exp((vals - M) / temp)
        wts /= wts.sum()

    A = np.fft.rfft(a, N)
    W = np.fft.rfft(w, N)
    g = np.fft.irfft(np.conj(A) * W, N)[:n]
    
    return g, M

def mirror_step(a, g, eta):
    """One mirror descent step: a_j *= exp(-eta * g_j), renormalize."""
    n = len(a)
    # Compute in log domain for stability
    log_a = np.where(a > 1e-300, np.log(a), -700)
    log_new = log_a - eta * g
    log_new -= log_new.max()
    new_a = np.exp(log_new)
    S = new_a.sum()
    if S < 1e-300:
        return a
    new_a /= S
    return new_a

            a = best_a * (1.0 + scale * rng.standard_normal(n))
