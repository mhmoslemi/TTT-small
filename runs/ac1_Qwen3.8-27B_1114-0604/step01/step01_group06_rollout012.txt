- When k-j = i, i.e., j = k-i: a_{k-i} * a_i (requires 0 <= k-i < n, same condition)

       c_k = B_k (when k-i < 0 or k-i >= n)

where B_k is the part not involving a_i.

This is a 1D minimax problem, which can be solved by bisection or by directly computing the optimal a_i.

    cross = np.fft.irfft(fp * np.conjugate(fa), _NFFT_BIG)
    return 2.0 * cross[:_N], M

"""
Multi-phase optimization minimizing 2*n*max(conv(a,a))/(sum(a))^2.
Works on the simplex (sum(a)=1, a>=0) to reduce max autocorrelation peak.

Phase 1: Smoothed projected gradient (logsumexp surrogate) with momentum,
         decreasing tau from large to small for progressive sharpening.
Phase 2: Exact subgradient method with adaptive step size and random restarts.
Phase 3: Local coordinate search for final improvement.

Starts from provided sequence when available; uses diverse restarts to

_N = 0
_NFFT = 0
_NFFT_BIG = 0


def _init(n):
    global _N, _NFFT, _NFFT_BIG
    _N = n
    _NFFT = 1 << (2 * n - 1).bit_length()
    _NFFT_BIG = 1 << (3 * n - 2).bit_length()


def _conv(a):
    fa = np.fft.rfft(a, _NFFT)
    c = np.fft.irfft(fa * fa, _NFFT)[:2 * _N - 1]
    return np.maximum(c, 0.0)


def _smooth_grad(a, tau):
    c = _conv(a)
    M = float(c.max())
    d = (c - M) / tau
    np.clip(d, -745.0, 0.0, out=d)
    e = np.exp(d)
    se = float(e.sum())
    if se <= 0 or not np.isfinite(se):
        return M, np.zeros(_N)
    p = e / se
    F = M + tau * float(np.log(se))
    fp = np.fft.rfft(p, _NFFT_BIG)
    fa = np.fft.rfft(a, _NFFT_BIG)
    cross = np.fft.irfft(fp * np.conjugate(fa), _NFFT_BIG)
