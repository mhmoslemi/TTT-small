**Key insight from the LP approach in the strategy:**

The strategy mentions: "maximizing sum(b) subject to b >= 0 and ||f*g||_inf <= M"

This is saying: given a fixed f and a fixed peak M, find the b that maximizes sum(b) while keeping the cross-correlation bounded. The insight is that at the optimum, the cross-correlation peaks are all binding (equal to M). This suggests that at the global optimum of our problem, the convolution peaks should be as equal as possible.

So an alternative approach:
1. Start with some sequence a
2. Compute c = conv(a, a), find M = max(c)
3. Solve the LP: maximize sum(b) subject to (a*b)[k] <= M for all k, b >= 0
4. Update a = (1-t)*a + t*b (after normalizing b)
5. Repeat

This is a fixed-point iteration that should converge to a point where the peaks are "balanced."

The LP can be solved efficiently because the constraint matrix (a*b)[k] <= M is linear in b.

Let me think about the size of this LP:
- Variables: b_0, ..., b_{n-1} (n variables)
- Constraints: (a*b)[k] <= M for k = 0, ..., 2n-2 (2n-1 constraints)
- Plus: b_i >= 0 (n constraints)

"""
LP-based optimizer for minimizing 2n*max(conv(a,a))/(sum(a))^2.
Uses alternating LP steps with adaptive relaxation, combined with gradient polishing.
"""

import numpy as np
import time
from scipy.optimize import linprog, minimize

# --- Fast convolution ---

def fft_self_conv(a):
    n = len(a)
    M = 2*n - 1
    L = 1 << (M-1).bit_length()
    A = np.fft.rfft(a, L)
    return np.fft.irfft(A*A, L)[:M]

def fft_conv(a, b):
    na, nb = len(a), len(b)
    M = na + nb - 1
    L = 1 << (M-1).bit_length()
    A = np.fft.rfft(a, L)
    B = np.fft.rfft(b, L)
    return np.fft.irfft(A*B, L)[:M]

# --- Objective helpers ---

def true_score(a):
    n = len(a)
    c = fft_self_conv(a)
    S = a.sum()
    if S < 1e-10:
        return np.inf
    return 2.0 * n * float(c.max()) / (S*S)

def smooth_score_and_grad(a, T):
    n = len(a)
    c = fft_self_conv(a)
    S = a.sum()
    if S < 1e-10:
        return np.inf, np.zeros(n)
    tc = T * c
    tc_max = tc.max()
    ev = np.exp(tc - tc_max)
    LSE = tc_max + np.log(ev.sum())
    M = LSE / T
    w = ev / ev.sum()
    score = 2.0 * n * M / (S*S)
    a_rev = a[::-1]
    cross = fft_conv(a_rev, w)
    g = 2.0 * cross[n-1:2*n-1]
    gradient = 2.0 * n * (S*g - 2.0*M) / (S**3)
    return score, gradient

# --- LP step ---

def build_toeplitz(a):
    """Build the (2n-1) x n Toeplitz constraint matrix for conv(a, b)."""
    n = len(a)
    A = np.zeros((2*n-1, n))
    for k in range(2*n-1):
        i_start = max(0, k - (n-1))
        i_end = min(k, n-1)
        if i_start <= i_end:
            A[k, i_start:i_end+1] = a[k-i_start:k-i_end+1][::-1]
    return A

def lp_step(a, M):
    """Solve max sum(b) s.t. conv(a,b)[k] <= M for all k, b >= 0."""
    n = len(a)
    A = build_toeplitz(a)
    c_obj = -np.ones(n)
    b_ub = np.full(2*n-1, M)
    bounds = [(0, None)] * n
    res = linprog(c_obj, A_ub=A, b_ub=b_ub, bounds=bounds, method='highs')
    if res.status != 0:
        return None
    return res.x
