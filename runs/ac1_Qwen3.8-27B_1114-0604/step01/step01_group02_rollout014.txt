If `|A(f)|^2` is constant (flat power spectrum), then the autocorrelation is a delta function at lag 0, which is ideal. This corresponds to a "chirp" or "maximum distance" sequence in the complex domain.

For real non-negative sequences, we can't achieve a perfectly flat power spectrum. But we can try to make the power spectrum as flat as possible.

A sequence with a flat power spectrum has the property that its energy is "spread out" in the time domain. For non-negative sequences, this means the values should vary in a pseudorandom-like fashion.

But wait - the issue with non-negative sequences is that they have a large DC component (the mean), which corresponds to a large peak at lag 0 of the circular autocorrelation. For the linear autocorrelation, this shows up as a large center value.

- Non-negativity → large DC → large center peak
- We want to minimize the peak → want flat power spectrum → want low DC

The best we can do with non-negative sequences is to make the DC component as small as possible relative to the AC components. For a sequence with mean μ and standard deviation σ, the DC component is `(n*μ)^2` and the total energy is `n*(μ^2+σ^2)`. The "peakiness" is related to `(n*μ)^2 / (n*(μ^2+σ^2)) = n*μ^2/(μ^2+σ^2)`.

To minimize this, we want `σ/μ` to be large (high coefficient of variation). But for non-negative sequences, `σ/μ` is bounded by 1 (achieved by a 0-1 sequence).

"""
Optimized step function search using adaptive gradient descent with
multi-scale peak targeting and structured restarts.
"""

import numpy as np
import time

def fast_self_conv(a):
    n = len(a)
    M = 2 * n - 1
    M_fft = 1 << (M - 1).bit_length()
    A = np.fft.rfft(a, M_fft)
    return np.fft.irfft(A * A, M_fft)[:M]

def compute_score(n, a):
    c = fast_self_conv(a)
    S = float(a.sum())
    if S < 0.01:
        return np.inf
    return float(2.0 * n * np.max(c) / (S * S))

def softmax_grad(a, c, n, k, temperature_scale=0.1):
    """Compute gradient using softmax-weighted top-k peaks."""
    S = float(a.sum())
    S2 = S * S
    S3 = S2 * S
    
    k_act = min(k, len(c))
    if k_act == 1:
        idx = np.argmax(c)
        vals = np.array([c[idx]])
        wts = np.array([1.0])
    else:
        idx = np.argpartition(c, -k_act)[-k_act:]
        vals = c[idx]
        top = float(vals.max())
        temp = temperature_scale * top
        wts = np.exp((vals - top) / temp)
        wts /= wts.sum()
    
    M_w = float(np.dot(vals, wts))
    grad = np.zeros(n)
    
    for i in range(k_act):
        ki = int(idx[i])
        wi = float(wts[i])
        if wi < 1e-15:
            continue
        j_lo = max(0, ki - n + 1)
        j_hi = min(ki, n - 1)
        if j_lo > j_hi:
            continue
        grad[j_lo:j_hi+1] += wi * 2.0 * a[j_lo:j_hi+1][::-1]
    
    # d/d a_j [2n * M_w / S^2] = 2n * (grad_c_j / S^2 - 2 * M_w / S^3)
    grad = 2.0 * n * (grad / S2 - 2.0 * M_w / S3)
    return grad, M_w, S

def adam_step(a, g, m, v, t, lr):
    b1, b2, eps = 0.9, 0.999, 1e-8
    m[:] = b1 * m + (1 - b1) * g
    v[:] = b2 * v + (1 - b2) * g * g
    mh = m / (1 - b1**t)
    vh = v / (1 - b2**t)
    a[:] -= lr * mh / (np.sqrt(vh) + eps)

def clamp_nonneg(a):
    a[:] = np.maximum(a, 0.0)
    a[:] = np.minimum(a, 1000.0)
    if a.sum() < 0.01:
        a[:] += 0.01 / len(a)

        score = float(2.0 * n * np.max(c) / (S * S))
        
        if score < best_score - 1e-10:
            best_score = score
            best_a = a.copy()
            no_improve = 0
        else:
            no_improve += 1
        
        # Adaptive patience and temperature

            # Restart from best with perturbation

            clamp_nonneg(a)
            m[:] = 0
            v[:] = 0
            t = 0
