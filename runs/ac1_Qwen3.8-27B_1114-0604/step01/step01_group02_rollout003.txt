  Phase 1: LP-based direction finding (solve max sum(b) s.t. b>=0, conv(f,b)<=M)
  Phase 2: Adam gradient refinement with adaptive top-k smoothing
  Phase 3: Fine polish with small steps
  
Uses n=4096 for more degrees of freedom than the previous n=2048.

import numpy as np
import time
from scipy.optimize import linprog
from scipy.sparse import csr_matrix


def fast_self_conv(a):
    """Linear self-convolution via FFT."""
    n = len(a)
    M = 2 * n - 1
    M_fft = 1 << (M - 1).bit_length()
    A = np.fft.rfft(a, M_fft)
    return np.fft.irfft(A * A, M_fft)[:M]


def compute_objective(n, a):
    """Compute the objective value."""
    c = fast_self_conv(a)
    S = a.sum()
    if S < 1e-10:
        return np.inf, c
    return 2.0 * n * float(np.max(c)) / (S * S), c


def topk_weights(c, k, temp_frac=0.1):
    """Get top-k peaks with exponential soft-max weights."""
    k_act = min(k, len(c))
    if k_act <= 0:
        return np.array([]), np.array([])
    idx = np.argpartition(c, -k_act)[-k_act:]
    vals = c[idx]
    order = np.argsort(vals)[::-1]
    idx = idx[order]
    vals = vals[order]
    top = float(vals[0])
    if top > 1e-12:
        temp = temp_frac * top
        wts = np.exp((vals - top) / temp)
        wts = wts / wts.sum()
    else:
        wts = np.ones(k_act) / k_act
    return idx, wts


def grad_topk(a, c, k, temp_frac=0.1):
    """Compute gradient using top-k weighted peaks."""
    n = len(a)
    S = float(a.sum())
    idx, wts = topk_weights(c, k, temp_frac)
    grad_c = np.zeros(n)
    for i in range(idx.size):
        ki = int(idx[i])
        wi = float(wts[i])
        if wi <= 1e-15:
            continue
        j_start = max(0, ki - n + 1)
        j_end = min(ki, n - 1)
        if j_start > j_end:
            continue
        grad_c[j_start:j_end+1] += wi * 2.0 * a[j_start:j_end+1][::-1]
    M = sum(float(wts[i]) * float(c[idx[i]]) for i in range(idx.size))
    S2 = S * S
    S3 = S2 * S
    grad = 2.0 * n * (grad_c / S2 - 2.0 * M / S3)
    return grad


def solve_lp_direction(f, M):
    """Solve LP: max sum(b) s.t. b>=0, conv(f,b) <= M.
    Returns the optimal b vector."""
    n = len(f)
    # Build sparse constraint matrix
    rows = []
    cols = []
    data = []
    for k in range(2 * n - 1):
        j_start = max(0, k - n + 1)
        j_end = min(k, n - 1)
        for j in range(j_start, j_end + 1):
            rows.append(k)
            cols.append(j)
            data.append(f[k - j])
    
    A_ub = csr_matrix((data, (rows, cols)), shape=(2 * n - 1, n))
    b_ub = np.full(2 * n - 1, M)
    c_obj = -np.ones(n)  # minimize -sum = maximize sum
    
    res = linprog(c_obj, A_ub=A_ub, b_ub=b_ub, bounds=[(0, None)] * n, method='highs')
    
    if res.success:
        return res.x
    return np.zeros(n)


def clamp(a):
    """Enforce non-negativity and upper bound."""
    a = np.clip(a, 0.0, 1000.0)
    if a.sum() < 1e-3:
        a += 1e-3 / a.size
    return a


def resize_sequence(a, new_n):
    """Resize sequence to new length using interpolation."""
    old_n = len(a)
    if old_n == new_n:
        return a.copy()
    old_x = np.linspace(0, 1, old_n)
    new_x = np.linspace(0, 1, new_n)
    return np.interp(new_x, old_x, a)


def adam_step(a, g, m, v, t, lr):
    """Adam update in place."""
    b1, b2, eps = 0.9, 0.999, 1e-8
    m[:] = b1 * m + (1 - b1) * g
    v[:] = b2 * v + (1 - b2) * g * g
    mh = m / (1 - b1**t)
    vh = v / (1 - b2**t)
    a -= lr * mh / (np.sqrt(vh) + eps)

            elif parent.size > 10:

    except:
        pass

    x = np.linspace(0, 1, n)

    inits.append(("edge", np.clip(1 + 0.3*np.cos(2*np.pi*x), 0.01, 1000)))

    best_score = np.inf
    best_a = None
    
    # Allocate time to each initialization
    time_per = (deadline - start) / len(inits)
    
    for tag, a0 in inits:
        time_left = deadline - time.monotonic()
        if time_left < 5:
            break
        alloc = min(time_per, time_left)
        
        # Optimize from this initialization
        score, a_best = refine(a0, start + alloc, rng, n, init_lr=0.5)
        
        if score < best_score:
            best_score = score
            best_a = a_best
            print(f"[{tag}] new best: {best_score:.6f}")
    
    # Final polish on global best
    if best_a is not None:
        remaining = deadline - time.monotonic()
        if remaining > 10:
            score, a_best = refine(best_a, deadline, rng, n, init_lr=0.01)
            if score < best_score:
                best_score = score
                best_a = a_best
    
    out = [float(x) for x in best_a]
    verified = float(evaluate_sequence(out))
    print(f"Final: {best_score:.6f}, verified: {verified:.6f}, n={n}")
    return out

Binary search on M:
- For a given M, check if there exists a non-negative a with sum(a) = S and max(conv(a,a)) <= M
- This is a feasibility check, which can be formulated as an LP:
  - Variables: a[0], ..., a[n-1]
  - Constraints: a[i] >= 0, sum(a) = S, and for each k: sum_j a[j]*a[k-j] <= M

Wait, the constraint sum_j a[j]*a[k-j] <= M is quadratic (bilinear), not linear! So it's not an LP.

Hmm, that's a problem. The LP from the "previous state of the art" works because it fixes one sequence (f) and optimizes the other (g). The constraint conv(f, g) <= M is linear in g.

So the LP approach is:
- Fix f, find g that maximizes sum(g) subject to conv(f, g) <= M, g >= 0
- This is a valid LP

But we can't directly set up an LP to find a that minimizes max(conv(a,a)) because the constraint is quadratic in a.

OK so the LP is only useful as a direction-finding step within an outer loop.

Let me think about another approach: **alternating minimization**.

Define the problem as: minimize max_k conv(a,a)[k] / (sum a)^2 subject to a >= 0.

This is equivalent to: minimize t subject to a >= 0, sum(a) = 1, and for all k: conv(a,a)[k] <= t.

The constraint conv(a,a)[k] <= t is: sum_j a[j]*a[k-j] <= t, which is a quadratic constraint. This is a quadratic programming (QP) problem!

Actually, it's a non-convex QP (the quadratic form is indefinite in general). But for the specific structure of convolution, the Hessian of conv(a,a)[k] w.r.t. a is a symmetric matrix that's always positive semi-definite (it's related to the autocorrelation matrix).

Wait, is it? Let's check. conv(a,a)[k] = sum_j a[j]*a[k-j]. The Hessian w.r.t. a is:
H[i,j] = d²(conv_k)/da[i]da[j]

For i ≠ j: H[i,j] = 1 if j = k-i (and k-j = i), i.e., if i+j = k. So H[i,j] = 1 if i+j = k and i≠j.
For i = j: H[i,i] = 2 if 2i = k, else 0.

So H is a permutation matrix (up to the diagonal), which is symmetric and has eigenvalues ±1. So it's indefinite! The QP is non-convex.

This means we can't solve it directly with a convex solver. We need to use global optimization or heuristics.
