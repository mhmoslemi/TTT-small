**Key insight**: If we want p*p to be as flat as possible, we want the Fourier transform of p to be as flat as possible (by Parseval/Plancherel). The FT of p*p is |P(f)|^2 where P is the DTFT of p.

So we want |P(f)|^2 to be as flat as possible, i.e., |P(f)| to be as constant as possible.

For a non-negative sequence with sum 1, P(0) = 1. The question is how flat we can make |P(f)| for f in (0, 1) (normalized frequency).

If |P(f)| = c for all f, then by Parseval: sum_k (p*p)^2[k] = (1/2pi) integral |P(f)|^4 df = c^4.
Also sum_k (p*p)[k] = P(0)^2 = 1.
If p*p has 2n-1 entries and is constant, each entry = 1/(2n-1), and sum of squares = 1/(2n-1)^2.
So c^4 = 1/(2n-1)^2, c = 1/sqrt(2n-1).
And max(p*p) = 1/(2n-1), score = 2n/(2n-1) ≈ 1.

But this is only achievable if there exists a non-negative sequence whose DTFT has constant magnitude. This is the "flat spectrum" problem.

For a finite sequence of length n, the DTFT P(f) = sum_{i=0}^{n-1} p[i] * e^{-2πif} is a polynomial in e^{-2πif} of degree n-1. For |P(f)| to be constant on [0,1], P(f) would need to be a monomial (up to a phase), which means p has only one nonzero entry. But then p*p also has only one nonzero entry, contradicting flatness.

So we can't achieve perfect flatness. But we can get close.

def spectral_flatten(p, n_iterations=100):
    """Iteratively flatten the spectrum while maintaining non-negativity."""
    n = len(p)
    p = p.copy()
    p = np.maximum(p, 0)
    p /= p.sum()
    
    for it in range(n_iterations):
        P = np.fft.fft(p)
        mag = np.abs(P)
        # Target: flat magnitude
        target_mag = np.ones(n)  # or some other target
        # Update: keep phase, use target magnitude
        phase = np.angle(P)
        P_new = target_mag * np.exp(1j * phase)
        p_new = np.fft.ifft(P_new).real
        p_new = np.maximum(p_new, 0)
        p_new /= p_new.sum()
        p = p_new
    return p

def _fft_conv(p):
    """Compute p*p (full convolution) using FFT."""
    n = len(p)
    N = 1 << (2*n-1).bit_length()
    P = np.fft.rfft(p, N)
    c = np.fft.irfft(P*P, N)[:2*n-1]
    return np.maximum(c, 0)

def _score(p):
    """Compute 2n*max(p*p)/(sum(p))^2."""
    n = len(p)
    s = p.sum()
    if s < 1e-12:
        return np.inf
    c = _fft_conv(p)
    return 2.0 * n * c.max() / (s*s)

def _project_simplex(v):
    """Project vector v onto the probability simplex."""
    n = len(v)
    if np.all(v <= 0):
        return np.ones(n) / n
    # Standard simplex projection
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.where(u * np.arange(1, n+1) > (cssv - 1))[0][-1]
    theta = (cssv[rho] - 1) / (rho + 1)
    return np.maximum(v - theta, 0)
