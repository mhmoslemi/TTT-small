        g[lo1:hi1+1] += wk * a[k-hi1:k-lo1+1][::-1]  # a[k-j] for j=lo1..hi1
    lo2 = max(0, k)
    hi2 = min(n - 1, k + n - 1)
    if hi2 >= lo2:
        g[lo2:hi2+1] += wk * a[lo2-k:hi2-k+1]  # a[j-k] for j=lo2..hi2
```

This is $O(|A| \cdot n)$ per gradient computation. With $|A| = 200$ and $n = 6121$, that's about 1.2M operations, which is fine.

But actually, I realize that using FFT for the gradient is cleaner and potentially faster for large active sets. Let me use the FFT approach:

$g = \text{circular cross-correlation of } a \text{ and } w \text{ (at lags } 0, ..., n-1) + \text{circular convolution of } w \text{ and } a \text{ (at indices } 0, ..., n-1)$

Wait, I derived that:
- $g^{(1)}_j = \sum_t a[t] w[t+j] = (a \star w)_j$ (cross-correlation)
- $g^{(2)}_j = \sum_t a[t] w[j-t] = (w * a)_j$ (convolution)

For the cross-correlation via FFT: $(a \star w)_j = \text{irfft}(\text{rfft}(a) \cdot \text{conj}(\text{rfft}(w)))[j]$ (with appropriate zero-padding).

For the convolution via FFT: $(w * a)_j = \text{irfft}(\text{rfft}(w) \cdot \text{rfft}(a))[j]$ (with appropriate zero-padding).

So $g_j = \text{irfft}(\hat{a} \cdot \bar{\hat{w}})[j] + \text{irfft}(\hat{w} \cdot \hat{a})[j] = \text{irfft}(\hat{a}(\bar{\hat{w}} + \hat{w}))[j]$

(where $\hat{a} = \text{rfft}(a, L)$, $\hat{w} = \text{rfft}(w, L)$, and $L$ is the FFT size).

So I can compute the gradient with just 2 FFTs (one forward for $a$, one forward for $w$, then one IFFT of the product).

Wait, I already have $\hat{a}$ from the convolution computation! So I just need one extra FFT for $w$ and one IFFT.

This is very efficient. Let me implement this.

Now, for the soft-max weights $w$:
$w_k = \exp(\beta \cdot c_k) / \sum_l \exp(\beta \cdot c_l)$

where $c = a * a$ (the convolution) and $\beta > 0$ is the "temperature" (larger $\beta$ = more concentrated on the max).

As $\beta \to \infty$, $w$ concentrates on the argmax, and the gradient becomes the true subgradient.
As $\beta \to 0$, $w$ becomes uniform, and the gradient becomes the average of all $\nabla c_k$, which is less targeted.

I'll use an adaptive $\beta$ that increases over time (annealing).

**Complete algorithm:**

2. For each iteration:
   a. Compute c = fft_convolve(a)

   e. Compute gradient g via FFT
   f. Adam update: a = a - lr * adam(g)
   g. Clip a to [0, inf]
   h. Renormalize a to sum = 1
   i. Update beta (anneal)
3. Return best
```
