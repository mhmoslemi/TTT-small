# Mathematical Specification

We are to find a sequence `a` of length `n` that minimizes:

`score = (2 * n * max(convolve(a, a))) / (sum(a))²`

Where `convolve(a, a)` is the full linear convolution of `a` with itself, resulting in a sequence of `2*n-1` elements.

**Define the normalized sequence:**
   `s = sum(a)`

**Define the convolution maximum:**
   `M = max_{k=0}^{2*n-2} | (a * a)[k] |`
   (Note: `a * a` refers to the full convolution via FFT as the evaluator does.)

The objective is to minimize `2 * n * M / s²`.

**Constraints:**
   - `a[i]` must be finite and non-negative.
   - `sum(a) >= 0.01`, else `score = inf`.
   - `a[i] <= 1000` for all `i` (evaluator's clipping, but we enforce this via normalization).

**Algorithmic Formulation:**

1. **Initial Candidate Generation:**
   - **Sine Piece:** `a[i] = 1*(if*i/n<= something)`
   - **Exponential Piece:** `a[i] = exp(-0.5*(i-i0)²/damping)`
   - Normalize by `s = np.sum(a)` to get `a_normalized = a / s`
   - `s_normalized = s / len(a)` (a proxy for the original normalization)

2. **Mixed-Length Scan:**
   - The evaluation function scales linearly with `n` and exponentially with `M`. To keep `M` relatively lower, we must scan longer and shorter lengths.

3. **Gradient Optimization:**
   - Compute gradient of `M` with respect to the sequence (`∂(M)/∂a[i]`). We can approximate this with finite differences.
   - Then, use gradient information to locally push amplitudes toward reducing `M`.
