    m = len(p)
    c = _conv_full(p, p)

    idx = np.argsort(c)[::-1][:K]

Now let me think about the MMD with top-K more carefully.

The objective is $f(a) = 2m \cdot \max_k c[k]$ where $c = a * a$ and $m = len(a)$.

The gradient of $\max_k c[k]$ (at the point where the max is attained at a specific $k^*$) with respect to $a[i]$ is $c[k^*]$'s derivative: $a[k^* - i]$ (for valid indices).

If the max is attained at multiple points, we can use the average gradient.

For the multiplicative update on the simplex:
$a_{\text{new}}[i] \propto a[i] \exp(-\alpha \cdot h[i])$

where $h[i]$ is the "effective gradient" (projected to account for the simplex constraint).

The projection onto the simplex constraint $\sum a = 1$ for the exponential family is handled by the normalization step.

The "projected gradient" for the non-negativity constraint is handled by the fact that the multiplicative update automatically keeps $a$ non-negative.

So the algorithm is:
1. Compute $c = a * a$.
2. Find top-K peaks: $k_1, ..., k_K$.
3. Compute $h[i] = \sum_{j=1}^K w_j \cdot a[k_j - i]$ (with zero padding for out-of-range indices).
4. Update: $a \leftarrow a \odot \exp(-\alpha h) / \sum(a \odot \exp(-\alpha h))$.

The weights $w_j$ can be set to $c[k_j]$ (so larger peaks get more weight) or uniform.

Let me also add a "centering" step: since the simplex constraint means $\sum a = 1$, the effective direction should be the part of $h$ that's "orthogonal" to the all-ones vector. In practice, we can subtract the mean: $h \leftarrow h - \text{mean}(h)$. But for the multiplicative update, this isn't strictly necessary since the normalization handles it.

Actually, for the multiplicative update $a \leftarrow a \exp(-\alpha h) / Z$, the direction is determined by $h - \text{mean}(h \cdot a)/\sum a = h - \text{mean}(h \cdot a)$ (the $a$-weighted mean). But the normalization step effectively does this, so we don't need to explicitly subtract.

        cur_score = float(2.0 * m * np.max(c))

        k_idx = np.argsort(c)[::-1][:K]
        peak_vals = c[k_idx]

            best = p.copy()
            best_score = cur_score

        h = np.zeros(m)
        total_w = np.sum(peak_vals)
        if total_w <= 0:
            break
        for j in range(K):
            k = k_idx[j]
            w = peak_vals[j] / total_w
            # h[i] += w * a[k-i] for valid i
            # a[k-i] is valid when 0 <= k-i < m

                # = a[k - i_min .. k - i_max] in reverse
                # indices in a: k - i_max, k - i_max + 1, ..., k - i_min
                a_slice = a[k - i_max : k - i_min + 1]
                h[i_min : i_max + 1] += w * a_slice[::-1]
        
        # Normalize h to have unit max for stable step size
        h_max = np.max(h)
        if h_max <= 1e-15:
            break
        
        # Try several step sizes
        best_trial = None
        best_trial_score = cur_score
        for a_mult in [0.3, 0.5, 0.8, 1.0, 1.5, 2.0]:
            a_trial = alpha * a_mult
            dec = np.exp(-a_trial * h / h_max)
            p_trial = p * dec
            p_trial = np.maximum(p_trial, floor)
            s = p_trial.sum()
            if s <= 0:

            sc = _exact_score(p_trial)
            if sc < best_trial_score:

                best_trial = p_trial

        it += 1
    
    return best, best_score

        return np.zeros(m)

    h = np.zeros(m)
