The minimax duality says: min_a max_k c[k] = max_{p in simplex} min_a p^T c.

The iteration alternates between:

- Inner (min over a): given p, minimize p^T c over a >= 0, sum(a) = 1.

If we do one inner gradient step per outer step, we're essentially doing:
1. p = softmax(c/tau) [outer step, instantaneous]
2. a ← a - eta * grad(p^T c) [one inner gradient step]

This is a "saddle point" iteration. It should converge to a saddle point of the Lagrangian, which corresponds to the solution of the minimax problem.

The convergence rate depends on:
- The "sharpness" of tau (smaller tau = sharper max = closer to true argmax).

Another idea: **Fenchel dual / Bregman divergence**.

def _fft_conv(a):
    """Linear convolution a*a via FFT, returns non-negative array of length 2n-1."""
    n = len(a)
    N = 1 << (2 * n - 1).bit_length()
    A = np.fft.rfft(a, N)
    c = np.fft.irfft(A * A, N)[:2 * n - 1]
    return np.maximum(c, 0.0)


def _grad_weighted_conv(a, p, N):
    """
    Gradient of sum_k p[k] * (a*a)[k] w.r.t. a.
    Uses cross-correlation: g[i] = 2 * sum_m a[m] * p[i+m].
    """
    n = len(a)
    A = np.fft.rfft(a, N)
    P = np.fft.rfft(p, N)
    g = np.fft.irfft(np.conjugate(A) * P, N)[:n]
    return 2.0 * g


def _score_internal(a):
    """Fast internal score (scale-invariant)."""
    n = len(a)
    s = float(np.sum(a))
    if s <= 1e-12:
        return np.inf
    c = _fft_conv(a)
    return float(2.0 * n * c.max() / (s * s))


def _resample_to_length(a, n):
    """Resample sequence to length n via linear interpolation."""
    m = len(a)
    if m == n:
        return a.copy()
    if m == 1:
        return np.full(n, a[0])
    x_old = np.linspace(0.0, 1.0, m)
    x_new = np.linspace(0.0, 1.0, n)
    return np.interp(x_new, x_old, a)
