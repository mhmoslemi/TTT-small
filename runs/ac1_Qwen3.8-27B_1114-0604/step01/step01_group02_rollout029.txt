Let me think about what kind of sequence has a flat autocorrelation. In signal processing, this is the "ideal" autocorrelation, which corresponds to a sequence with a flat power spectrum. For a finite-length real non-negative sequence, this is impossible to achieve exactly, but we can approximate it.

A sequence with a flat power spectrum (within the passband) would be ideal. One way to approximate this is to use a sequence whose DFT is approximately constant in magnitude.

For a length-n sequence, the DFT is `A[k] = sum_j a[j] * exp(-2*pi*i*j*k/n)`. We want |A[k]| to be approximately constant for all k.

The autocorrelation is the IFFT of |A[k]|^2. If |A[k]| is constant, the autocorrelation is a delta at lag 0, which means c[n-1] (the "zero lag" in the full convolution) would be large and all others would be small. But wait, that's the periodic autocorrelation, not the aperiodic one.

The aperiodic autocorrelation (which is what we're computing with linear convolution) is different. For a finite sequence, the aperiodic autocorrelation at lag 0 is `sum a[i]^2`, and at lag k it's `sum a[i]*a[i+k]`.

The full linear convolution (a*a) at index k is actually the "cross-correlation" at a specific offset. Let me think...

Actually, `(a*a)[k] = sum_i a[i]*a[k-i]`. If we define the "autocorrelation" as `R[m] = sum_i a[i]*a[i+m]` (for m >= 0), then:
- `(a*a)[n-1+m] = R[m]` for m = 0, 1, ..., n-1 (the "right side")
- `(a*a)[n-1-m] = R[m]` for m = 0, 1, ..., n-1 (the "left side", by symmetry)

So the full convolution is symmetric, and the "center" (index n-1) is R[0] = sum a[i]^2.

So to minimize the max of the convolution, we want to minimize:
- R[0] = sum a[i]^2 (the energy)
- R[1] = sum a[i]*a[i+1] (adjacent products)
- R[2] = sum a[i]*a[i+2]
- etc.

All of these should be small relative to S^2 = (sum a[i])^2.

For R[0]: By Cauchy-Schwarz, R[0] >= S^2/n. Equality when all a[i] are equal.
For R[1]: This depends on the structure. For a uniform sequence, R[1] = (n-1)*c^2, which is close to R[0].

So for a uniform sequence, all R[m] are approximately n*c^2, and the max is at m=0 (or m=1, they're close). The objective is 2.

To get below 2, we need to make some R[m] smaller while keeping them all below S^2/n (approximately).

The key insight: we need a sequence where the autocorrelation R[m] is much less than S^2/n for all m > 0, and R[0] = S^2/n (which requires the sequence to be as "flat" as possible).

But R[0] = S^2/n only when the sequence is constant! So there's a fundamental tension: to minimize R[0], we want the sequence to be flat, but to minimize R[m] for m > 0, we want the sequence to be "random" or "correlation-free".

This is the fundamental optimization problem. The solution must balance these competing objectives.

For the previous solution achieving 1.52, the structure must have R[0] somewhat above S^2/n (so the sequence isn't perfectly flat) but R[m] for m > 0 is sufficiently small.

"""
Hybrid optimizer for minimum-peak self-convolution sequences.
Uses continuation method with log-sum-exp smoothing, L-BFGS-B,
and multiplicative (mirror) descent for non-negative refinement.
"""

import numpy as np
import time
from scipy.optimize import minimize

def fast_self_conv(a):
    n = len(a)
    M = 2 * n - 1
    M_fft = 1 << (M - 1).bit_length()
    A = np.fft.rfft(a, M_fft)
    return np.fft.irfft(A * A, M_fft)[:M]

def objective_and_grad(a, t):
    """Compute the log-sum-exp smoothed objective and its gradient."""
    n = len(a)
    c = fast_self_conv(a)
    S = a.sum()
    if S < 1e-10:
        return np.inf, np.zeros(n)
    
    # Log-sum-exp with temperature t
    c_max = c.max()
    z = (c - c_max) / t
    # Handle overflow: z is <= 0
    log_sum_exp = c_max + t * np.log(np.exp(z).sum())
    
    # Softmax weights
    w = np.exp(z)
    w /= w.sum()
    
    # Objective
    obj = 2.0 * n * log_sum_exp / (S * S)
    
    # Gradient
    # g_j = 2 * sum_k w[k] * a[k-j] (with a[m]=0 outside [0,n-1])
    # Use np.correlate: np.correlate(w, a, 'full')[j] = sum_n w[n+j]*a[n]
    # which is exactly what we want.
    corr = np.correlate(w, a, mode='full')
    # corr has length (2n-1) + n - 1 = 3n-2
    # We want corr[0:n] (j = 0 to n-1)
    g = 2.0 * corr[:n]
    
    # Full gradient of obj = 2n * LSE / S^2
    # d(obj)/d(a_j) = 2n * (g_j/S^2 - 2*LSE*a_j/S^3)
    grad = (2.0 * n) * (g / (S * S) - 2.0 * log_sum_exp * a / (S**3))
    
    # Clip: the true objective uses max, which is >= LSE
    # So the smoothed objective is a lower bound. For the gradient,
    # it's an approximation that gets better as t -> 0.
    
    return obj, grad

def multiplicative_update(a, c, S, learning_rate, iterations=100):
    """Perform multiplicative (mirror) descent updates."""
    n = len(a)
    a = a.copy()
    for _ in range(iterations):
        # Compute gradient of the smoothed objective
        # Simple subgradient of max: use the argmax
        k_max = np.argmax(c)
        # df/da_j = 4n*a[k_max-j]/S^2 - 4n*max_c*a_j/S^3
        j_start = max(0, k_max - n + 1)
        j_end = min(k_max, n - 1)
        grad = np.zeros(n)
        grad[j_start:j_end+1] = 4.0 * n * a[j_start:j_end+1][::-1] / (S*S) - 4.0*n*c[k_max]*a/(S**3)
        # Multiplicative update: a_j <- a_j * exp(-lr * grad_j)
        a = a * np.exp(-learning_rate * grad)
        a = np.clip(a, 0, 1000)
        S = a.sum()
        if S < 1e-10:
            a += 0.1
            S = a.sum()
        c = fast_self_conv(a)
    return a

For zero-padded sequences (length L > len(x) + len(y) - 1), there's no wrap-around for the "valid" range.

So if x = w (length 2n-1, zero-padded to L) and y = a (length n, zero-padded to L):
z[m] = sum_n w[n] * a[n-m]

We want: g[j] = sum_k w[k] * a[k-j]

Compare with z[m] = sum_n w[n] * a[n-m]:
If we set m = -j (mod L), then z[-j mod L] = sum_n w[n] * a[n+j mod L]

Wait, there's a problem with L-BFGS-B and the temperature continuation. L-BFGS-B uses a fixed number of past gradients (m=10 by default) for its approximation. When we change the temperature, the function changes completely, so the old gradient information is useless. We should reset the L-BFGS-B state at each temperature stage (which is what happens since we call minimize() separately for each stage).

But there's another issue: the log-sum-exp objective is a LOWER BOUND on the true max objective. As t decreases, the approximation gets better, but the objective value also increases (since LSE(c, t) increases with 1/t for fixed c... wait no, LSE(c, t) -> max(c) as t -> 0, and LSE(c, t) -> mean(c) as t -> infinity. So LSE increases as t decreases, which means the smoothed objective increases as t decreases. The true objective (with max) is the limit.

So the continuation method should work: start with a smooth (low) objective, optimize it, then decrease t (making the objective harder and closer to the true one), and optimize again. The key is that the solution of the smooth problem is a good starting point for the less smooth one.

Let me also think about whether L-BFGS-B is the best choice. For n=2048, L-BFGS-B stores O(m*n) memory (m=10 by default, so about 20k floats, which is fine). Each iteration requires a gradient evaluation (O(n log n) with FFT) and a line search (several more gradient evaluations). So each iteration is O(n log n), and convergence in ~100 iterations gives O(100 * n log n) total per stage. For n=2048, that's about 100 * 2048 * 11 ≈ 2.3 million operations per stage, times 8 stages = 18 million operations. At ~100M ops/sec in Python/numpy, that's about 0.2 seconds per initialization. With ~8 initializations per n, that's about 1.6 seconds per n. With 3-4 n values, that's about 6 seconds total. Well within budget.

Actually, the line search in L-BFGS-B can be expensive. Each line search step requires a function evaluation (which includes an FFT), and the line search might take 10-30 function evaluations per iteration. So it's more like 100 * 20 * n log n per stage. Still manageable.

Let me also add a "direct max" approach as a final polish: once t is very small, the log-sum-exp is essentially the max, and we can use a subgradient method or coordinate descent.

For coordinate descent: fix all variables except a[j], and find the optimal a[j]. The objective as a function of a[j] is:
`f(a[j]) = 2n * max_k c_k(a) / S(a)^2`

where c_k(a) = c_k_base + 2*a[j]*a[k-j] (for valid k) and S(a) = S_base + a[j].

This is a piecewise function, and finding its minimum is non-trivial. But we can do a line search: for a candidate a[j], compute the resulting max_conv and S, and evaluate the objective.

Actually, for a given j, the objective as a function of a[j] = x is:
- S = S_base + x
- c_k = c_k_base + 2*x*a[k-j] (for k where 0 <= k-j < n)
- max_c = max_k c_k

The function max_k (c_k_base + 2*x*a[k-j]) is the max of linear functions of x, so it's convex in x. The objective is `2n * max_c / (S_base + x)^2`, which is the ratio of a convex function to a convex function... not necessarily convex.

But we can do a ternary search or golden section search on x in [0, 1000] for each j. This would be O(n * 30 * n log n) per full pass (30 function evals per j, n choices of j, each eval is O(n log n)). For n=2048, that's 2048 * 30 * 2048*11 ≈ 1.4 billion operations. Too slow.

Instead, for the coordinate search, I'll just do a few evaluations per j (like a simple line search with 5-10 points).

OK, let me also think about a completely different approach:

**Approach: Direct optimization of the "peak ratio"**

Instead of smoothing the max, what if we directly optimize using the fact that at the optimum, multiple peaks are active (tie)? If exactly K peaks are active (all equal to the max), then the objective is smooth in a neighborhood, and we can solve a system of equations.

At the optimum with the sum constraint:
1. `c_{k_1} = c_{k_2} = ... = c_{k_K} = M` (K active peaks)
2. `c_k <= M` for all other k
3. `sum a = S` (normalization)
4. KKT conditions for non-negativity

This is a nonlinear system. We could try to solve it with Newton's method, but it's complex.

Let me stick with the continuation + L-BFGS-B approach, augmented with a few other tricks:

1. **Adaptive temperature**: Instead of geometric schedule, use t = (max_c - median_c) / alpha. As optimization progresses, the spread decreases and t adapts automatically.

2. **Multiple的温度 starting points**: Start with several different t values in parallel (not really parallel, but interleaved).

3. **Nesterov acceleration**: Between L-BFGS-B calls, do a few Nesterov steps with the current gradient.

4. **Randomized restarts**: If progress stalls, perturb the current best and restart.

"""
Optimization of non-negative sequences minimizing 2*n*max(conv(a,a))/sum(a)^2.
Uses continuation method (log-sum-exp smoothing) with L-BFGS-B,
muxiplicative descent, and Nesterov-accelerated gradient steps.
"""

import numpy as np
import time
from scipy.optimize import minimize

def fast_self_conv(a):
    """Linear self-convolution via real FFT."""
    n = len(a)
    M = 2 * n - 1
    M_fft = 1 << (M - 1).bit_length()
    A = np.fft.rfft(a, M_fft)
    return np.fft.irfft(A * A, M_fft)[:M]

def smooth_objective_and_grad(a, t):
    """Log-sum-exp smoothed objective and gradient.
    
    f(a) = 2n * LSE_t(conv(a,a)) / (sum(a))^2
    """
    n = len(a)
    c = fast_self_conv(a)
    S = float(a.sum())
    if S < 1e-10:
        return 1e10, np.zeros(n)
    
    c_max = float(c.max())
    z = (c - c_max) / t
    # Numerically stable log-sum-exp
    z_max = z.max()  # should be 0
    log_sum = z_max + np.log(np.exp(z - z_max).sum())
    LSE = c_max + t * log_sum
    
    # Softmax weights
    w = np.exp(z - z_max)
    w /= w.sum()
    
    # Objective
    obj = 2.0 * n * LSE / (S * S)
    
    # Gradient via FFT cross-correlation
    # g[j] = 2 * sum_k w[k] * a[k-j]
    L = 1 << (3 * n - 2).bit_length()
    W = np.fft.rfft(w, L)
    A = np.fft.rfft(a, L)
    corr = np.fft.irfft(W * np.conj(A), L)
    g = 2.0 * corr[:n]
    
    # df/da_j = 2n * (g_j/S^2 - 2*LSE*a_j/S^3)
    S2 = S * S
    S3 = S2 * S
    grad = 2.0 * n * (g / S2 - 2.0 * LSE * a / S3)
    
    return obj, grad

def nesterov_step(a, grad, v, lr, mu=0.9):
    """One Nesterov-accelerated gradient step with projection onto [0, 1000]."""
    v = mu * v - lr * grad
    a_new = a + v  # (this is the "lookahead" step in Nesterov)
    a_new = np.clip(a_new, 0, 1000)
    return a_new, v

def multiplicative_descent(a, n_iters=100, lr=0.05):
    """Multiplicative (mirror) descent for non-negative variables.
    
    Uses the subgradient of the true (non-smooth) max objective.
    """
    n = len(a)
    a = a.copy()
    for i in range(n_iters):
        c = fast_self_conv(a)
        S = float(a.sum())
        if S < 1e-10:
            a[:] = 1.0
            S = n
            continue
        
        # Find all peaks that are within 1% of the max
        c_max = c.max()
        active = np.where(c >= 0.99 * c_max)[0]
        
        # Subgradient: average over active peaks
        grad = np.zeros(n)
        for k in active:
            j_start = max(0, k - n + 1)
            j_end = min(k, n - 1)
            if j_start <= j_end:
                grad[j_start:j_end+1] += 2.0 * a[j_start:j_end+1][::-1]
        grad /= len(active)
        # Full gradient of obj = 2n * max_c / S^2
        grad = (2.0 * n) * (grad / (S*S) - 2.0 * c_max * a / (S**3))
        
        # Multiplicative update
        a = a * np.exp(-lr * grad / (np.abs(grad).max() + 1e-10))
        a = np.clip(a, 1e-10, 1000)
    
    return a

def optimize_continuation(a0, deadline, rng, verbose=True):
    """Continuation method: optimize with decreasing log-sum-exp temperature."""
    n = len(a0)
    a = a0.copy()
    best_a = a.copy()
    best_score = evaluate_sequence(a.tolist())
    
    # Initial temperature
    c0 = fast_self_conv(a)
    t = max(0.01, (c0.max() - c0.min()) / 5.0)
    t_min = max(0.001, t * 1e-5)
    
    while time.monotonic() < deadline:
        # Define the objective function for L-BFGS-B
        def fun_and_grad(x):
            o, g = smooth_objective_and_grad(x, t)
            if not np.isfinite(o):
                return 1e10, np.zeros_like(x)
            return o, g
        
        # L-BFGS-B optimization
        try:
            result = minimize(fun_and_grad, a, method='L-BFGS-B',
                             bounds=[(0, 1000)] * n,
                             options={'maxiter': 80, 'ftol': 1e-12, 'gtol': 1e-8})
            a = np.clip(result.x, 0, 1000)
        except Exception as e:
            if verbose:
                print(f"  L-BFGS-B error: {e}")
            # Fallback: Nesterov steps
            v = np.zeros(n)
            for _ in range(50):
                o, g = smooth_objective_and_grad(a, t)
                a, v = nesterov_step(a, g, v, lr=0.1)
        
        # Check score
        c = fast_self_conv(a)
        S = a.sum()
        score = 2.0 * n * c.max() / (S*S)
        if np.isfinite(score) and score < best_score:
            best_score = score
            best_a = a.copy()
            if verbose:
                print(f"  t={t:.6f} score={score:.6f}")
        
        # Cool down
        t *= 0.5
        if t < t_min:
            break
        
        # Time check
        if time.monotonic() > deadline - 2:
            break
    
    return best_score, best_a

The longest Barker code has length 13. For longer sequences, we can use "approximate Barker codes" or other low-autocorrelation sequences.

For non-negative reals, we can take the absolute value of a Barker code (or any low-autocorrelation real sequence) and use it as an initialization. But this might not be the best since the absolute value operation changes the autocorrelation properties.

A better approach: start from a sequence that has "balanced" values (close to 1) with small perturbations that reduce the autocorrelation peaks. The perturbations should be "correlation-antagonistic" - they should make adjacent products small.

For example: a[i] = 1 + epsilon * (-1)^i would give alternating high-low values. The autocorrelation at odd lags would be reduced (since products of adjacent elements alternate sign in the perturbation), but at even lags it would be enhanced. So this isn't great.

A better perturbation: a[i] = 1 + epsilon * sin(2*pi*i/p) for some period p. This creates a periodic modulation that can reduce autocorrelation at specific lags.

"""
Optimizes non-negative sequences to minimize 2*n*max(conv(a,a))/(sum(a))^2.
Strategy: Continuation method with log-sum-exp smoothing + L-BFGS-B,
combined with Nesterov-accelerated gradient steps and multiplicative (mirror) descent.
Multiple sequence lengths and diverse initializations are explored.
"""

import numpy as np
import time
from scipy.optimize import minimize
import sys


def fast_self_conv(a):
    """Linear self-convolution via real FFT."""
    n = len(a)
    M = 2 * n - 1
    M_fft = 1 << (M - 1).bit_length()
    A = np.fft.rfft(a, M_fft)
    return np.fft.irfft(A * A, M_fft)[:M]


def true_score(a):
    """Compute the true (non-smoothed) objective value."""
    n = len(a)
    c = fast_self_conv(a)
    S = float(a.sum())
    if S < 0.01:
        return np.inf
    return float(2.0 * n * c.max() / (S * S))


def smooth_obj_grad(a, t, scale_reg=0.0):
    """Log-sum-exp smoothed objective and gradient.
    
    f(a) = 2n * LSE_t(conv(a,a)) / (sum(a))^2 + scale_reg*(sum(a)-1)^2
    """
    n = len(a)
    c = fast_self_conv(a)
    S = float(a.sum())
    if S < 1e-10:
        return 1e10, np.zeros(n)

    c_max = float(c.max())
    z = (c - c_max) / t
    z_clipped = np.clip(z, -50, 50)
    exp_z = np.exp(z_clipped)
    log_sum = np.log(exp_z.sum())
    LSE = c_max + t * log_sum

    # Softmax weights
    w = exp_z / exp_z.sum()

    # Objective
    obj = 2.0 * n * LSE / (S * S)

    # Gradient via FFT cross-correlation:
    # g[j] = 2 * sum_k w[k] * a[k-j]
    L = 1 << (3 * n + 1).bit_length()
    W = np.fft.rfft(w, L)
    A = np.fft.rfft(a, L)
    corr = np.fft.irfft(W * np.conj(A), L)
    g = 2.0 * corr[:n]

    S2 = S * S
    S3 = S2 * S
    grad = 2.0 * n * (g / S2 - 2.0 * LSE * a / S3)

    if scale_reg > 0:
        obj += scale_reg * (S - 1.0) ** 2
        grad += 2.0 * scale_reg * (S - 1.0) / n * np.ones(n)

    return obj, grad


def smooth_obj_only(a, t, scale_reg=0.0):
    """Objective only (no gradient) for L-BFGS-B with numerical grad if needed."""
    obj, _ = smooth_obj_grad(a, t, scale_reg)
    return obj


def nesterov_optimize(a0, deadline, rng, lr_init=0.05, mu=0.9, t_init=None, verbose=False):
    """Nesterov-accelerated gradient descent with adaptive temperature."""
    n = len(a0)
    a = a0.copy()
    v = np.zeros(n)
    best_a = a.copy()
    best_score = true_score(a)

    if t_init is None:
        c0 = fast_self_conv(a)
        t_init = max(0.01, (c0.max() - c0.min()) / 3.0)

    t = t_init
    lr = lr_init
    stall = 0

    while time.monotonic() < deadline:
        obj, grad = smooth_obj_grad(a, t, scale_reg=0.01)
        if not np.isfinite(obj):
            a = a0 * (1.0 + 0.1 * rng.standard_normal(n))
            a = np.clip(a, 0, 1000)
            v = np.zeros(n)
            continue

        # Nesterov step
        v = mu * v - lr * grad
        a_new = a + v
        a_new = np.clip(a_new, 0, 1000)

        # Check if step improved
        score_new = true_score(a_new)
        if np.isfinite(score_new) and score_new < best_score:
            best_score = score_new
            best_a = a_new.copy()
            stall = 0
            if verbose and stall == 0 and best_score < 1.55:
                print(f"    Nesterov: score={best_score:.6f}, t={t:.6f}, lr={lr:.6f}")
        else:
            stall += 1
            a_new = a  # Revert

        a = a_new

        # Adaptive temperature
        if stall > 20:
            t *= 0.7
            lr *= 0.8
            v *= 0.5
            stall = 0
            if t < 0.001:
                break

        # Every 100 steps, re-evaluate
        if stall > 100:
            # Try a restart with perturbation
            a = best_a * (1.0 + 0.05 * rng.standard_normal(n))
            a = np.clip(a, 0, 1000)
            v = np.zeros(n)
            lr = max(0.001, lr * 0.5)
            stall = 0

    return best_score, best_a


def multiplicative_descent(a, n_iters=50, lr=0.03):
    """Multiplicative (mirror) descent using subgradient of true max objective."""
    n = len(a)
    a = a.copy()
    for i in range(n_iters):
        c = fast_self_conv(a)
        S = float(a.sum())
        if S < 1e-10:
            a[:] = 1.0
            S = n
            continue

        c_max = c.max()
        # Active set: peaks within 0.5% of max
        threshold = c_max * 0.995
        active = np.where(c >= threshold)[0]

        # Average subgradient over active peaks
        grad = np.zeros(n)
        for k in active:
            j_start = max(0, k - n + 1)
            j_end = min(k, n - 1)
            if j_start <= j_end:
                grad[j_start:j_end + 1] += 2.0 * a[j_start:j_end + 1][::-1]
        grad /= max(1, len(active))

        # Full gradient of obj = 2n * max_c / S^2
        S2 = S * S
        S3 = S2 * S
        grad = 2.0 * n * (grad / S2 - 2.0 * c_max * a / S3)

        # Normalize gradient for stable updates
        g_scale = np.abs(grad).max()
        if g_scale > 1e-12:
            grad = grad / g_scale

        # Multiplicative update
        a = a * np.exp(-lr * grad)
        a = np.clip(a, 1e-8, 1000)

    return a


def lbgfsb_optimize(a0, t, maxiter, scale_reg=0.01):
    """Single L-BFGS-B call at fixed temperature."""
    n = len(a0)

    def fun_and_grad(x):
        o, g = smooth_obj_grad(x, t, scale_reg)
        if not np.isfinite(o):
            return 1e10, np.zeros(n)
        if not np.all(np.isfinite(g)):
            g = np.zeros(n)
        return o, g

    try:
        result = minimize(fun_and_grad, a0, method='L-BFGS-B',
                          bounds=[(0.0, 1000.0)] * n,
                          options={'maxiter': maxiter, 'ftol': 1e-12,
                                   'gtol': 1e-8, 'maxls': 30})
        return np.clip(result.x, 0, 1000)
    except Exception:
        return a0


def continuation_optimize(a0, deadline, rng, verbose=True):
    """Continuation method: L-BFGS-B with decreasing log-sum-exp temperature,
    interleaved with Nesterov steps."""
    n = len(a0)
    a = a0.copy()
    best_a = a.copy()
    best_score = true_score(a)

    c0 = fast_self_conv(a)
    t = max(0.01, (c0.max() - c0.min()) / 4.0)
    t_min = max(0.0005, t * 1e-5)
    n_lbfgsb_iters = max(30, min(100, 200000 // max(1, n // 512)))

    stage = 0
    while time.monotonic() < deadline - 5:
        stage += 1
        lbl = f"  stage {stage} t={t:.6f}" if verbose else ""

        # L-BFGS-B phase
        remaining = deadline - time.monotonic()
        if remaining > 5:
            a = lbgfsb_optimize(a, t, n_lbfgsb_iters, scale_reg=0.01)
            score = true_score(a)
            if np.isfinite(score) and score < best_score:
                best_score = score
                best_a = a.copy()
                if verbose:
                    print(f"{lbl} L-BFGS-B -> {best_score:.6f}")

        # Nesterov phase (short)
        nesterov_deadline = min(deadline - 5, time.monotonic() + min(30, remaining * 0.3))
        if nesterov_deadline > time.monotonic() + 2:
            sc, aa = nesterov_optimize(a, nesterov_deadline, rng,
                                       lr_init=0.05, t_init=t)
            if sc < best_score:
                best_score = sc
                best_a = aa.copy()
                if verbose:
                    print(f"{lbl} Nesterov -> {best_score:.6f}")
                a = aa.copy()

        # Cool down
        t *= 0.5
        if t < t_min:
            # Switch to very fine Nesterov + multiplicative
            break

    # Final multiplicative polish
    if time.monotonic() < deadline - 2:
        a2 = multiplicative_descent(best_a, n_iters=30, lr=0.02)
        score2 = true_score(a2)
        if np.isfinite(score2) and score2 < best_score:
            best_score = score2
            best_a = a2.copy()

    return best_score, best_a


def build_initializations(n, rng, parent=None):
    """Build diverse initializations for sequence of length n."""
    x = np.linspace(0, 1, n)
    inits = []

    if parent is not None and len(parent) == n:
        inits.append(("parent", np.clip(parent, 0, 1000).copy()))

    inits.append(("uniform", np.ones(n)))
    inits.append(("sin1", np.clip(1.0 + 0.5 * np.sin(2 * np.pi * x), 0.01, None)))
    inits.append(("sin2", np.clip(1.0 + 0.7 * np.sin(4 * np.pi * x), 0.01, None)))
    inits.append(("sin3", np.clip(1.0 + 0.4 * np.cos(6 * np.pi * x), 0.01, None)))
    inits.append(("sin5", np.clip(1.0 + 0.3 * np.sin(10 * np.pi * x), 0.01, None)))
    inits.append(("gauss", np.exp(-3.0 * (x - 0.5) ** 2) + 0.05))
    inits.append(("bimodal", np.clip(1.0 + 0.8 * np.cos(4 * np.pi * x), 0.01, None)))
    inits.append(("trimodal", np.clip(1.0 + 0.6 * np.cos(6 * np.pi * x), 0.01, None)))
    inits.append(("rand", 0.5 + rng.random(n)))
    inits.append(("ramp_up", np.linspace(0.01, 2.5, n)))
    inits.append(("ramp_down", np.linspace(2.5, 0.01, n)))
    inits.append(("noise_sin", np.clip(1.0 + 0.4 * np.sin(2 * np.pi * x) + 0.2 * rng.standard_normal(n), 0.01, None)))
    inits.append(("noise_cos", np.clip(1.0 + 0.4 * np.cos(4 * np.pi * x) + 0.2 * rng.standard_normal(n), 0.01, None)))

    return inits
