Wait, let me double-check the gradient formula.

$(f*f)_k = \sum_{i=0}^{n-1} f[i] \cdot f[k-i]$ (where $f[m] = 0$ for $m < 0$ or $m \geq n$).

$\frac{\partial}{\partial f[j]} (f*f)_k = \frac{\partial}{\partial f[j]} \sum_i f[i] f[k-i]$

$f[j]$ appears in the sum when:
1. $i = j$: term is $f[j] \cdot f[k-j]$, derivative is $f[k-j]$ (if $0 \leq k-j < n$)
2. $k-i = j$, i.e., $i = k-j$: term is $f[k-j] \cdot f[j]$, derivative is $f[k-j]$ (if $0 \leq k-j < n$)

If $j \neq k-j$ (i.e., $2j \neq k$): both conditions give the same value $f[k-j]$, and they're different terms, so total = $2f[k-j]$.
If $j = k-j$ (i.e., $2j = k$): it's the same term $f[j]^2$, derivative is $2f[j] = 2f[k-j]$.

So in all cases: $\frac{\partial}{\partial f[j]} (f*f)_k = 2 f[k-j]$ if $0 \leq k-j < n$, else 0.

Great, so the gradient is simply $2 \cdot$ (reversed and shifted $f$).

Now for the optimization:

At each step:
1. Compute $c = f*f$ (self-convolution).
2. Find the top $m$ peaks of $c$.
3. Compute a blended gradient: $g = \sum_{r=1}^{m} w_r \cdot \nabla (f*f)_{k_r}$ where $w_r$ are soft-max weights.
4. Take a step: $f_{new} = f - \eta \cdot g$, then project onto the simplex.

The projection onto the simplex $\{x \geq 0, \sum x = 1\}$ is a well-known operation.

Let me also think about the step size. Since we're on the simplex and the function values are of order $1/n$ (for the convolution), the step size should be tuned accordingly.

Actually, let me think about normalization. If $\sum f = 1$, then the convolution values are of order $1/n$ (for a uniform sequence, the center is $1/n$). The max is of order $1/n$. The objective is $2n \cdot (1/n) / 1 = 2$. 

For the gradient: $\nabla (f*f)_k$ has entries of order $2/n$ (since each $f[k-j] \approx 1/n$). So the gradient magnitude is about $2/n$ per component, or about $2$ in $\ell_2$ norm (since there are $n$ components each of size $2/n$, the norm is $2/n \cdot \sqrt{n} = 2/\sqrt{n}$).

A reasonable step size might be $\eta \approx 1/\sqrt{n}$ or so. Let's use adaptive step sizes.
