For non-negative sequences, the problem is harder. But we can think of it as: we want a non-negative sequence whose autocorrelation is as flat as possible.

One approach: start with a sequence that has low autocorrelation (like a random sequence) and then "rectify" it (take the absolute value or add a constant) to make it non-negative.

Actually, here's an idea: take a sequence a = b + c where b is a random ±1 sequence (which has low autocorrelation) and c is a large enough constant to make a non-negative. Then a = c + b has autocorrelation:
(a*a)[k] = c^2*(2n-1-|k|) + 2c*(b*1)[k] + (b*b)[k].

The first term is the autocorrelation of the constant sequence (a triangle).
The second term is the "DC bias" of b (close to 0 if b has zero mean).
The third term is the autocorrelation of b (small for a good low-autocorrelation sequence).

The peak is dominated by the first term (the triangle from the constant). This gives us back to the uniform-like case.

So adding a constant to a low-autocorrelation sequence doesn't help much.

Let me try another approach. What if we use a periodic structure?

Consider a sequence that's periodic with period P: a[i] = a[i mod P] for all i.
If n is a multiple of P, the self-convolution has a specific structure.

For a periodic sequence with period P and n = m*P:
(a*a)[k] = sum_i a[i]*a[k-i].
For k < P: (a*a)[k] = m * (a_P * a_P)[k mod P] + (correction terms from the boundaries)...
