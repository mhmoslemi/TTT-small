Let me now think about the exponentiated gradient method in more detail.

The exponentiated gradient (EG) method for minimizing $f(a) = \max_k (a*a)_k$ subject to $a_i \geq 0, \sum a_i = 1$:

At each iteration:
1. Compute $g_i = \nabla_i f(a) = \frac{1}{|A|} \sum_{k \in A} 2 a_{k-i}$ where $A$ is the active set (lags where $f$ is achieved or near-achieved)
2. Update: $a_i \leftarrow a_i \exp(-\eta g_i) / Z$ where $Z = \sum_j a_j \exp(-\eta g_j)$

This is a multiplicative weights update. The key is choosing $\eta$ well.

For the subgradient of the max function, we use the average over the active set. The active set can be defined as:
- All lags where $(a*a)_k \geq (1-\epsilon) \max_k (a*a)_k$
- Or the top-K lags

Let me think about computational cost. For $n = 2048$:
- FFT convolution: O(n log n) ≈ 2048 * 11 ≈ 22528 operations
- Gradient computation: O(n * |A|) where |A| is the active set size
- Total per iteration: O(n log n + n * |A|)

With |A| = 20 and n = 2048, each iteration takes about 2048 * 20 = 40960 operations for the gradient plus the FFT. That's very fast. We can do thousands of iterations in a few seconds.

Let me also think about the step size $\eta$. In EG, the step size controls the "exploration" vs "exploitation" trade-off. A good adaptive scheme:
- Start with $\eta = 1/n$ (small)
- Increase $\eta$ by 10% if the score improved
- Decrease $\eta$ by 20% if the score worsened
- Cap $\eta$ at some maximum (e.g., $10/n$)

Actually, for the convex problem of minimizing the max of linear functions (which is what we get if we fix the active set), the EG method has convergence guarantees. But our problem is not exactly convex (the convolution is quadratic), so we need to be more careful.

Let me also think about a different approach: **proximal gradient method**.

The proximal gradient method for minimizing $f(a) + g(a)$ where $f$ is smooth and $g$ is convex (here, $g$ is the indicator of the non-negative simplex):
$a^{(t+1)} = \text{prox}_{\eta g}(a^{(t)} - \eta \nabla f(a^{(t)}))$

The proximal operator of the simplex constraint is the Euclidean projection onto the simplex. But computing this is O(n log n) using the algorithm in Duchi et al. (2011).

However, the exponentiated gradient (which is the mirror descent with the negative entropy) might be better suited for the non-negativity constraint, as it naturally maintains non-negativity.

$\frac{\partial f_\epsilon}{\partial a_i} = \frac{1}{\sum_k \exp((a*a)_k / \epsilon)} \sum_k \exp((a*a)_k / \epsilon) \frac{\partial (a*a)_k}{\partial a_i}$
