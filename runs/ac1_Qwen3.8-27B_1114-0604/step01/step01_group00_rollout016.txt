Let me also think about the "spectral" starting point more carefully.

If I want f to have a flat auto-convolution, I want IFFT(FFT(f, N)^2) to be flat.
Let G = FFT(f, N). Then IFFT(G^2) should be flat.
Let H = G^2. Then IFFT(H) = c (constant) means H = FFT(c) = c * N * delta_0.
So G^2 = c * N * delta_0, which means G[0] = sqrt(c*N) and G[k] = 0 for k != 0.
This gives f = IFFT([sqrt(cN), 0, 0, ...]) = (sqrt(cN)/N) * [1, 1, 1, ...] = uniform!

So the "flat auto-convolution" in the frequency domain corresponds to the uniform sequence in the time domain. This confirms that the uniform is the "naive" optimal and we need a more sophisticated approach.

The issue is that we're minimizing the MAX of the auto-convolution, not the auto-convolution itself. The max is a non-smooth function, and the optimal solution is at a "kink" where multiple lags achieve the max simultaneously.
