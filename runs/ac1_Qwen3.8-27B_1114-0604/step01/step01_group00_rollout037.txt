`∂(f*f)_k / ∂f[m] = f[k-m] + f[m] * ∂f[k-m]/∂f[m]`

The second term is non-zero only when k-m = m, i.e., m = k/2. In that case, it's f[m].

But wait, when I write `sum_m f[m] * f[k-m]`, both f[m] and f[k-m] depend on f. So:

`∂/∂f[m'] of sum_m f[m] * f[k-m]`
= `sum_m [δ_{m,m'} * f[k-m] + f[m] * δ_{k-m,m'}]`
= `f[k-m'] + f[k-m']` (when 0 ≤ k-m' < n)
= `2 * f[k-m']` (when 0 ≤ k-m' < n, else 0)

Wait, the second term: `f[m] * δ_{k-m, m'}`. This is non-zero when m = k-m', i.e., m = k-m'. But we're summing over m, so this contributes `f[k-m']` when k-m' is in [0, n-1].

So the total is `f[k-m'] + f[k-m'] = 2*f[k-m']` (when 0 ≤ k-m' < n, else 0).

But wait, when m' = k-m' (i.e., 2m' = k), the term in the sum is f[m'] * f[m'] = f[m']^2, and its derivative is 2*f[m']. This is consistent with the formula `2*f[k-m'] = 2*f[m']`.

So the gradient is `grad[m'] = 2 * f[k-m']` (for 0 ≤ k-m' < n, else 0).

The factor of 2 doesn't matter for the direction, so I'll drop it:
`grad[m'] = f[k-m']` (for 0 ≤ k-m' < n, else 0).

In my code above, I have:
```python
grad[lo:hi+1] += w * f[k - hi : k - lo : -1]
```

Let me verify: for m = lo, the index into f is k - lo. For m = hi, the index is k - hi. So the slice f[k-hi : k-lo+1 : -1] gives [f[k-hi], f[k-hi+1], ..., f[k-lo]]. But I want grad[lo] = f[k-lo], grad[lo+1] = f[k-lo-1], ..., grad[hi] = f[k-hi].

So I need: grad[lo:hi+1] = f[k-lo : k-hi-1 : -1] = f[k-lo] down to f[k-hi].

In numpy: `f[k-hi:k-lo+1][::-1]` or `f[k-lo:k-hi-1:-1]`.

Let me just use: `grad[lo:hi+1] = w * f[k-hi:k-lo+1][::-1]`

- hi = min(3, 4) = 3
- We want: grad[0] = f[3], grad[1] = f[2], grad[2] = f[1], grad[3] = f[0]

Step function optimizer using exact-subgradient mirror descent with
adaptive step sizing, progressive peak focusing, and greedy local search.
Minimizes 2*n*max(conv(f,f))/(sum(f))^2 for non-negative sequences.
"""
import numpy as np

def _conv(f):
    """Full linear convolution f*f via FFT."""
    n = len(f)
    size = 1 << (2 * n - 1).bit_length()
    F = np.fft.rfft(f, size)
    return np.fft.irfft(F * F, size)[:2 * n - 1]


def _score_from_conv(c, n):
    """Score = 2*n*max(c) when sum(f)=1."""
    return 2.0 * n * c.max()


def _mirror_step(f, grad, eta):
    """Mirror descent step on the simplex."""
    log_f = np.log(f + 1e-30) - eta * grad
    log_f -= log_f.max()
    f_new = np.exp(log_f)
    s = f_new.sum()
    if s < 1e-300:
        return f.copy()
    return f_new / s


def _compute_gradient(c, f, top_k, n):
    """Compute weighted subgradient targeting top-k lags."""
    total_len = 2 * n - 1
    if top_k >= total_len:
        k_idx = np.arange(total_len)
        weights = np.ones(top_k) / top_k
    else:
        k_idx = np.argpartition(c, -top_k)[-top_k:]
        k_idx = k_idx[np.argsort(c[k_idx])[::-1]]
        w_raw = c[k_idx].astype(np.float64).copy()
        w_min = w_raw.min()
        w_raw = w_raw - w_min
        w_sum = w_raw.sum()
        if w_sum < 1e-30:
            w_raw = np.ones(top_k) / top_k
        else:
            w_raw /= w_sum
        weights = w_raw
    
    grad = np.zeros(n)
    for idx, w in zip(k_idx, weights):
        k = int(idx)
        lo = max(0, k - n + 1)
        hi = min(k, n - 1)
        if lo > hi:
