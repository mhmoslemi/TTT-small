For the LP, I need to be careful about the constraint matrix. Let me precompute it efficiently.

For block-constant f with values h[0..B-1] (each repeated L times) and block-constant g with values k[0..B-1]:

The constraint `(f*g)[pos] <= t` for position pos in [0, 2n-2]:

`(f*g)[pos] = sum_{a=0}^{B-1} sum_{b=0}^{B-1} h[a] * k[b] * overlap(a, b, pos)`

where `overlap(a, b, pos)` = number of i in [0, n) such that `i // L == a` and `pos - i` is in [0, n) and `(pos-i) // L == b`.

Let's compute this: i is in [a*L, (a+1)*L - 1] and pos-i is in [b*L, (b+1)*L - 1].
So i is in [a*L, (a+1)*L-1] ∩ [pos - (b+1)*L + 1, pos - b*L].

The overlap = max(0, min((a+1)*L-1, pos-b*L) - max(a*L, pos-(b+1)*L+1) + 1).

For the LP, the coefficient of k[b] in constraint `pos` is:
`coef[b, pos] = sum_a h[a] * overlap(a, b, pos)`

And the constraint is: `sum_b k[b] * coef[b, pos] - t <= 0`.

The constraint matrix has (2n-1) rows and (B+1) columns (B for k, 1 for t).

For B=128, n=8192: 16383 rows, 129 columns. The matrix is 16383 * 129 ≈ 2.1M entries. This is small.

But computing the matrix might take a bit. Let me think about how to do it efficiently.

For each b in [0, B-1] and pos in [0, 2n-2]:
coef[b, pos] = sum_a h[a] * overlap(a, b, pos)

I can compute this as: for each b, the function pos -> overlap(b's interaction with h, pos) is a "smeared" version of h. Specifically:

`coef[b, pos] = sum_a h[a] * overlap(a, b, pos)`

For fixed b, as pos varies, the overlap with each a is a triangular function. The sum is a piecewise-linear function of pos.

Actually, let me think of it differently. Define the "block interaction kernel" for block b:
`K_b[pos] = sum_a h[a] * overlap(a, b, pos)`

This is the convolution of the "block-constant" vector h (expanded to full length) with the indicator of block b, truncated.

More precisely: if I define `H[pos] = h[pos // L]` for pos in [0, n) (the expanded f), and `I_b[pos] = 1` if pos is in block b (i.e., b*L <= pos < (b+1)*L), 0 otherwise, then:

`K_b[pos] = (H * I_b)[pos] = sum_j H[j] * I_b[pos-j]`

This is just the convolution of H with the indicator of block b! And I can compute this via FFT.

So: `K_b = convolve(H, I_b)` for each b. Then `coef[b, pos] = K_b[pos]`.

I can compute all K_b at once by doing B convolutions (or one big one with a structured matrix).

For B=128 and n=8192, each convolution is O(n log n) via FFT. Total: B * n log n ≈ 128 * 8192 * 13 ≈ 13.6M operations. This is fast.

```python
def compute_lp_matrix(h, B, L, n):
    """
    Compute the constraint coefficient matrix for the LP.
    h: block values of f, shape (B,)
    Returns: coef matrix of shape (2n-1, B) where coef[pos, b] = (f * I_b)[pos]
    """
    # Expand h to full length
    H = np.repeat(h, L)  # length n
    
    # For each block b, compute convolve(H, I_b)
    # I_b is 1 for positions b*L to (b+1)*L-1, 0 otherwise
    
    # We can do this as: K = convolve(H, I) where I is the "block indicator" matrix
    # But it's easier to just do B convolutions.
    
    coef = np.zeros((2*n-1, B))
    size = 1
    while size < 3*n-1:  # max convolution length
        size <<= 1
    
    H_fft = np.fft.rfft(H, size)
    
    for b in range(B):
        I_b = np.zeros(n)
        I_b[b*L:(b+1)*L] = 1.0
        I_b_fft = np.fft.rfft(I_b, size)
        K_b = np.fft.irfft(H_fft * I_b_fft, size)[:2*n-1]
        coef[:, b] = K_b
    
    return coef
```

Better approach: compute the convolution in the time domain for each b. Since I_b is just an indicator, `(H * I_b)[pos] = sum_j H[j] * I_b[pos-j] = sum_{j in [pos-(b+1)*L+1, pos-b*L] ∩ [0,n)} H[j]`.

This is just a sum of H over a sliding window! I can compute this with a prefix sum.

```python
def compute_lp_matrix_fast(h, B, L, n):
    H = np.repeat(h, L)  # length n
    prefix = np.concatenate([[0], np.cumsum(H)])  # length n+1
    
    coef = np.zeros((2*n-1, B))
    for b in range(B):
        lo = b*L
        hi = (b+1)*L  # exclusive
        for pos in range(2*n-1):
            # sum of H[j] for j in [pos-hi+1, pos-lo] ∩ [0, n)

            j_hi = min(n, pos - lo + 1)  # exclusive
            if j_lo < j_hi:
                coef[pos, b] = prefix[j_hi] - prefix[j_lo]
    
    return coef
```

This is O((2n-1) * B) which for n=8192, B=128 is about 4M operations. Fast!

    Given p (length n) and w (length 2n-1, the softmax weights on the conv),

    """

    # c = conv(p, p)
    c = np.fft.irfft(P * P, size)[:2*n-1]
