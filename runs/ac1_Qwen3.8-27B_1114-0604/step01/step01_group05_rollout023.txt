Now, the question is: can we do better than 4/3?

From the formula `f(p) = 2 * B(p+1,p+1) * (p+1)^2 = 2(p+1)^2 (p!)^2 / (2p+1)!`, this is decreasing in p. So in principle, higher p should give better scores. But the issue is that for large p, the sequence is so concentrated that the "effective n" is much smaller, and the endpoint values matter.

The condition for the center to dominate is: `c[n] >> c[2n-2]`, i.e., `n^{2p+1} B(p+1,p+1) >> n^{2p}`, i.e., `n * B(p+1,p+1) >> 1`.

`B(p+1,p+1) = (p!)^2/(2p+1)!`. Using Stirling's approximation: `(p!)^2 ≈ p^{2p} e^{-2p} (2πp)`, `(2p+1)! ≈ (2p)^{2p} e^{-2p} (4πp)^{1/2} * 2p` (roughly).

Actually, let's use the Beta function asymptotic: `B(p+1,p+1) ≈ √π / (2^{2p+1} √p)` for large p (from the central binomial coefficient relation).

More precisely: `B(p+1,p+1) = (p!)^2/(2p+1)! = 1/[(2p+1) * C(2p, p)]`. And `C(2p,p) ≈ 4^p / √(πp)`. So `B(p+1,p+1) ≈ √(πp) / [4^p * (2p+1)] ≈ √π / [4^p * √(2p)]` for large p.

The condition `n * B(p+1,p+1) >> 1` becomes `n * √π / [4^p * √(2p)] >> 1`, or `4^p << n√π/√(2p)`.

For n = 8192: `4^p << 8192 * 1.77 / √(2p)`. For p=5: `4^5 = 1024`, `8192*1.77/√10 ≈ 4515`. So 1024 < 4515, condition holds.
For p=7: `4^7 = 16384`, `8192*1.77/√14 ≈ 3847`. So 16384 > 3847, condition fails.

So for n=8192, we can use p up to about 6 before the endpoints start mattering.
