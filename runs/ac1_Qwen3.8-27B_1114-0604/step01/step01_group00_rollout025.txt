For complex sequences, the minimum PAPR is achieved by certain sequences (like Barker sequences for short lengths). For real, non-negative sequences, the problem is different.

Actually, I recall that for the problem of minimizing the peak of the autocorrelation (convolution) of a non-negative sequence, the optimal solution is related to the "flat top" window or certain polynomial approximations.

Let me try a different approach: use the Fourier domain.

The DFT of the circular convolution is the product of the DFTs. For linear convolution, we can use zero-padding.

If we define F = FFT(f, 2n-1), then conv(f,f) = IFFT(F^2, 2n-1).

We want to minimize max(IFFT(F^2)) subject to sum(f) = 1, f >= 0.

The constraint sum(f) = 1 means F[0] = 1 (the DC component).

The constraint f >= 0 is hard to express in the Fourier domain.

Without the f >= 0 constraint, we could try to make F^2 as "flat" as possible (minimizing its peak in the time domain). This is the "flat spectrum" problem.

But with f >= 0, we're restricted to a subset of the Fourier domain (the image of the概率 simplex under FFT).

This is getting too theoretical. Let me just implement a practical optimization algorithm.

**Final practical algorithm:**

1. **Initialization**: Start from the given sequence. Also try a "one-sided bump" (mass concentrated on the left) and a "random" start.

2. **Main loop** (until time runs out):
   a. Compute c = conv(f, f) via FFT
   b. Find the top K peaks (K=3)
   c. Compute a combined "anti-peak" direction:
      - For each peak at position k_i, the gradient of c[k_i] w.r.t. f is:
        grad_i[j] = f[k_i - j] (for 0 <= k_i - j < n, else 0)
      - Combined gradient: grad = sum_i w_i * grad_i (where w_i are weights based on peak values)
      - Center the gradient: grad = grad - mean(grad) (to maintain sum(f) = 1)
   d. Take a step: f = f - alpha * grad
   e. Project to simplex: f = max(f, 0); f = f / sum(f)
   f. Adaptive alpha: if peak increased, halve alpha; if decreased, increase alpha (up to a max)
   g. Every N iterations, try a "perturbation" (add noise and re-optimize)

3. **Polish** (last 20% of time):
   - Coordinate descent: for each pair (i, j), try moving a small amount of mass from i to j
   - Accept only if it reduces the peak
   - Use the current peak position to guide the move (move FROM positions that contribute to the peak)

    grad[j_min:j_max+1] = f[idx_start:idx_end][::-1]

"""
Optimizes a step function to minimize 2*n*max(conv(f,f))/(sum(f))^2.
Uses peak-targeting gradient descent with adaptive step size,
LP-inspired direction finding, and coordinate descent polish.
"""

import numpy as np
import time


def _convolve(a, b):
    """Linear convolution via FFT."""
    n = len(a) + len(b) - 1
    size = 1 << (n - 1).bit_length()
    A = np.fft.rfft(a, size)
    B = np.fft.rfft(b, size)
    return np.fft.irfft(A * B, size)[:n]


def _peak_grad(f, k):
    """Gradient of conv(f,f)[k] with respect to f."""
    n = len(f)
    j_min = max(0, k - n + 1)
    j_max = min(n - 1, k)
    if j_min > j_max:
        return np.zeros(n)
    idx_start = k - j_max
    idx_end = k - j_min + 1
    result = np.zeros(n)
    result[j_min:j_max + 1] = f[idx_start:idx_end][::-1]
    return result


def _project_simplex(v):
    """Project v onto {x >= 0, sum x = 1}."""
    n = len(v)
    if v.sum() < 1e-300:
        return np.ones(n) / n
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.arange(1, n + 1)
    cond = u * rho > (cssv - 1)
    rho_final = np.max(np.where(cond)[0])
    theta = (cssv[rho_final] - 1.0) / (rho_final + 1)
    return np.maximum(v - theta, 0.0)


def _eval_score(f):
    """Compute the objective without calling evaluate_sequence (faster)."""
    n = len(f)
    c = _convolve(f, f)
    return 2.0 * n * c.max() / (f.sum() ** 2)
