    n = len(a)

This is a non-convex QP (quadratic objective and constraints). CVXPY can't handle this directly.

But we can use a "successive convex approximation" (SCA) approach:
1. Start with a feasible point a^0.
2. Linearize the quadratic constraints at a^0: a^T Q_m a ≈ 2*(a^0)^T Q_m * a - (a^0)^T Q_m * a^0.
3. Solve the resulting LP: minimize t subject to 2*(a^0)^T Q_m * a - (a^0)^T Q_m * a^0 <= t, sum(a)=1, a>=0.
4. Update a^{k+1} with some damping.
5. Repeat.

This is a "quadratic reformulation" or "successive linear programming" approach. It's guaranteed to make progress (non-increasing objective) if the step is small enough.

The LP in step 3 has 2n constraints (for each m) and n variables. The constraint matrix has a very specific structure (each row is an anti-diagonal), so it might be solvable quickly.
