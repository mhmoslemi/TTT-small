1. **Subgradient method**: Use the subgradient of the max (which is the average of the gradients at the active peaks). Not smooth, but converges for convex problems.
2. **Bundle method**: Use multiple subgradients to build a piecewise linear model.
3. **Active set method**: Identify the active peaks and solve the equality-constrained problem.

For our problem, the active set method seems most promising:
1. Identify the set S of peaks where c_k = max.
2. Solve: minimize average of c_k for k in S, subject to a >= 0, sum(a) = 1, c_k = c_k' for all k, k' in S (equal peak heights).
3. Check if the solution is optimal (all other peaks are <= the common height).
4. If not, add the offending peak to S and repeat.

This is a quadratic program (QP) at each step! Let me formalize:

Given active set S, solve:
minimize (1/|S|) * sum_{k in S} c_k(a)
subject to: a >= 0, sum(a) = 1

This is a QP (minimize a quadratic function subject to linear constraints). The objective is:
(1/|S|) * sum_{k in S} a^T H_k a

where H_k is the Hessian matrix for the k-th lag. This is a convex QP (since each H_k is PSD, their average is also PSD).

We can solve this QP using a standard solver or a custom method (e.g., projected gradient on the QP, or ADMM).

The advantage of this approach:
- No smoothing needed (we're directly minimizing the active peaks).
- The QP is convex, so we get the exact solution for the given active set.
- If the solution is feasible (all inactive peaks are below the active peaks), it's the global optimum.

This is essentially the "smoothing-free" version of what the previous approach was doing with the "top-k" idea.

However, solving the QP at each active set update might be expensive. For n = 4096, the QP has 4096 variables and 4096 + 1 constraints (nonnegativity + sum). The Hessian is dense (n x n), which would be 16M entries for n = 4096. That's manageable but might be slow.

Alternatively, we can use the structure of the Hessian (it's a sum of "Hankel"-like matrices) to compute matrix-vector products efficiently via FFT.

Actually, the QP with Hessian H = (1/|S|) * sum_{k in S} H_k has a special structure. The matrix-vector product H * v can be computed as:
(H * v)[j] = (1/|S|) * sum_{k in S} sum_i H_k[j,i] * v[i]
= (1/|S|) * sum_{k in S} v[k-j] (for valid indices)
= (1/|S|) * sum_{k in S} (v shifted by k-j)

This is (1/|S|) * sum_k (v * indicator_{k-shifted}) which can be computed via convolution with the indicator of S.

Specifically: (H * v)[j] = (1/|S|) * sum_{k in S} v[k-j]

Let u = v (padded to length N), and let S_indicator be a vector of length 2n-1 with 1 at positions in S and 0 elsewhere. Then:
(H * v)[j] = (1/|S|) * sum_{k in S} v[k-j] = (1/|S|) * (cross-correlation of S_indicator and v)[j]

This can be computed via FFT in O(n log n)!

So the QP can be solved using a first-order method (e.g., FISTA) with fast matrix-vector products. The overall algorithm is:

1. Start with S = {argmax(c)}.
2. Solve the QP: min (1/|S|) * sum_{k in S} c_k(a) s.t. a >= 0, sum(a) = 1.
3. Check: compute c(a) for the solution. If all c_k for k not in S are <= max_{k in S} c_k, we're done.
4. Otherwise, add the violating peak to S and go to step 2.

This is an "incremental active set" method. Each QP solve is done with FISTA (converging in O(1/eps) iterations for the QP, with each iteration being O(n log n)).

The number of active set updates is at most 2n-1 (in the worst case), but in practice it should be much smaller (maybe 10-100).
