For coordinate descent, at each step I pick a coordinate `j` and try to optimize it.

Given all other coordinates fixed, the score as a function of `a_j = v` is:

The new score is `2n * max_m (a'*a')_m / s'^2`.

Wait, let me be more careful. Let `a'` be `a` with `a_j` replaced by `v`.

`(a'*a')_m = sum_i a'_i * a'_{m-i}`

The only terms that change are those involving index `j`:
- `i = j`: `a'_j * a'_{m-j} = v * a_{m-j}` (if `m-j != j`, else `v * v = v^2`)
- `i = m-j`: `a'_{m-j} * a'_j = a_{m-j} * v` (if `m-j != j`, else same as above)

So:
- If `m != 2j`: `(a'*a')_m = (a*a)_m - a_j * a_{m-j} - a_{m-j} * a_j + v * a_{m-j} + a_{m-j} * v`
  `= (a*a)_m - 2*a_j*a_{m-j} + 2*v*a_{m-j}`
  `= (a*a)_m + 2*(v - a_j)*a_{m-j}`

- If `m == 2j`: `(a'*a')_m = (a*a)_m - a_j^2 + v^2`
  `= (a*a)_m + v^2 - a_j^2`

So the change in `(a*a)_m` is:
- For `m != 2j`: `2*(v - a_j)*a_{m-j}` (linear in `v`)
- For `m == 2j`: `v^2 - a_j^2` (quadratic in `v`)

The score is `2n * max_m f_m(v) / (s - a_j + v)^2` where:
- `f_m(v) = (a*a)_m + 2*(v-a_j)*a_{m-j}` for `m != 2j`
- `f_{2j}(v) = (a*a)_{2j} + v^2 - a_j^2` for `m = 2j`
