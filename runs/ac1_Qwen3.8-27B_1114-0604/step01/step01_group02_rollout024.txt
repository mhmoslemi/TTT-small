Let me think about what the "best achievable" value is for non-negative sequences.

For a binary sequence (a_i ∈ {0, 1}), the convolution at lag k counts the number of pairs (i,j) with a_i = a_j = 1 and i+j = k (or i-j = k depending on convention). This is related to the "additive energy" of the set.

For a set S of size m in {0, 1, ..., n-1}, the additive energy is E(S) = |{(a,b,c,d) ∈ S^4 : a+b=c+d}|. This equals sum_k (number of representations of k as sum of two elements of S)^2.

The self-convolution at lag k is the number of representations of k as a sum of two elements of S. We want to minimize the maximum of these.

For a "Sidon set" (all pair sums are distinct), the max would be 1, but Sidon sets have at most O(sqrt(n)) elements, so the sum would be O(sqrt(n)), and the objective would be 2n * 1 / (sqrt(n))^2 = 2. That's not better than uniform.

For a "difference set" (all non-zero differences appear equally often), we'd get a nearly flat autocorrelation. The parameters satisfy m(m-1) = λ(n-1). For a (v, k, λ) difference set in a group of order v: k(k-1) = λ(v-1).

Example: v = 7, k = 3, λ = 1 (the Fano plane). The set {0, 1, 3} in Z_7 has the property that every non-zero element is written exactly once as a difference of two elements of the set.

But we're not working in a cyclic group of order n; we're working with the integers 0 to n-1 and the "full" (non-cyclic) convolution. So the difference set analogy isn't direct.

However, the general principle is: we want a set (or distribution) where the pair sums are as uniformly distributed as possible.

For the continuous (real-valued) case, the optimal solution is probably related to a "flat top" distribution.
