Actually, let me reconsider the problem from scratch.

The objective is: score = 2 * n * max(b) / (sum(a))^2

where b = full_convolution(a, a) (length 2n-1).

Scale invariance: score is unchanged if we scale a by any positive constant.

So WLOG, let sum(a) = 1. Then score = 2 * n * max(b).

We want to minimize max(b) = max_{k=0}^{2n-2} sum_{i} a[i] * a[k-i] (with a[j] = 0 for j < 0 or j >= n).

Note that b is a palindromic sequence: b[k] = b[2n-2-k]. So we only need to consider k = 0, ..., n-1.

Also, b[k] for k >= n is the same as b[2n-2-k] for k <= n-2.

So effectively, we're minimizing max_{k=0}^{n-1} b[k] where b[k] = sum_{i=max(0,k-n+1)}^{min(k,n-1)} a[i]*a[k-i].

Now, here's a key observation: b[n-1] = sum_{i=0}^{n-1} a[i]*a[n-1-i]. This is the "autocorrelation at lag n-1" (or equivalently, the inner product of a with its time-reversal).

For the uniform sequence, b[n-1] = 1/n.

Can we make b[n-1] < 1/n while keeping all other b[k] <= b[n-1]?

b[n-1] = sum_i a[i]*a[n-1-i].

If we let c[i] = a[i] and d[i] = a[n-1-i] (the flip), then b[n-1] = sum_i c[i]*d[i] = c · d.

By Cauchy-Schwarz: c · d <= ||c||_2 * ||d||_2 = ||a||_2^2.

And ||a||_2^2 = sum a[i]^2 >= 1/n (by QM-AM, since (sum a[i])^2 <= n * sum a[i]^2).

So b[n-1] <= sum a[i]^2, and sum a[i]^2 >= 1/n. But b[n-1] can be < 1/n!

For example, if a is concentrated on the first half and d (the flip) is concentrated on the second half, then c · d is small.
