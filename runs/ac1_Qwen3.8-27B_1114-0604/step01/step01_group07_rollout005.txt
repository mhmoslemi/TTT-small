**Approach: "Water-filling" on the convolution**

The idea: we want to minimize $\max_k c_k$ subject to $c = a*a$, $a \geq 0$, $\sum a = 1$.

This is equivalent to: find the smallest $M$ such that there exists $a \geq 0$, $\sum a = 1$, with $(a*a)_k \leq M$ for all $k$.

This is a feasibility problem for a given $M$. We can binary search on $M$.

For a given $M$, the constraints are:
- $(a*a)_k = \sum_i a_i a_{k-i} \leq M$ for all $k$
- $a_i \geq 0$
- $\sum a_i = 1$

This is a quadratic program (or more precisely, a set of quadratic inequalities). It's non-convex in general (the quadratic forms $a_i a_{k-i}$ are indefinite).

However, we can use the fact that for fixed $a$, the constraints are quadratic in $a$. One approach is to use multiplicative weight updates:

For each "violated" constraint (where $(a*a)_k > M$), penalize the elements $a_i$ that contribute to that lag.

This is similar to the "follow the perturbative leader" or "multiplicative weights" algorithm.

**Concrete algorithm:**

    For each i:
        g_i = sum over k in violated of a_{|k-i|} (with boundary handling)
    Update: a_i = a_i * exp(-eta * g_i)
    Normalize: a = a / sum(a)
    if max(convolve(a,a)) < target: M = max(convolve(a,a)) * (1 - epsilon)
