我们要最小化序列的标签函数 `score`，即 \( \frac{2n}{\text{sum}(a)^2} \times \max(\text{convolve}(a, a)) \)。

通过一个卷积操作，卷积函数左移的序列其可调整范围。缩放序列可以使其在无上限的情况下展开（rolling），但这不影响标签值，只影响结构。

import numpy as np

def evaluate_sequence(sequence):
    # 输入验证
    if not isinstance(sequence, list):
        return np.inf
    if not sequence:
        return np.inf
    # 检查每个元素类型 -> 支持bool
    if any(isinstance(x, bool) for x in sequence):
        return np.inf
    # 检查浮点类型，如果是整型也行只要是数字即可。
    sequence = [float(x) for x in sequence]
    # 保护针对负数和无穷大
    sequence = [max(0, x) for x in sequence]
    sequence = [min(1000.0, x) for x in sequence]
    n = len(sequence)
    b_sequence = np.convolve(sequence, sequence)
    max_b = max(b_sequence)
    sum_a = np.sum(sequence)
    if sum_a < 0.01:
        return np.inf
    return float(2 * n * max_b / (sum_a ** 2))
