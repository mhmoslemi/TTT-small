- A combination: alpha * max_approx + beta * (some measure of flatness)

Actually, maximizing the entropy of the convolution (while keeping the sum fixed) would push toward flatness. But the sum of the convolution is always (sum a_i)^2, so it's fixed. The entropy of a fixed-sum distribution is maximized when it's uniform. So maximizing the Shannon entropy of the convolution would work!

But the entropy is not differentiable at zeros, and the convolution values need to be positive. We could add a small epsilon.

Let me also think about **spectral methods**. The linear convolution in the time domain is multiplication in the frequency domain (with appropriate zero-padding). So:
FFT(a * a) = FFT(a) * FFT(a) = |FFT(a)|^2 (if a is real)

Wait no, that's for circular convolution. For linear convolution, we need to zero-pad to length 2n-1 (or a power of 2 >= 2n-1).

So if A = FFT(a, padded to length N), then the linear convolution c has DFT C[m] = A[m] * A[m] = A[m]^2 (for real a).

So c_k = (1/N) * sum_m A[m]^2 * exp(2*pi*i*m*k/N)

The max of c_k is related to the "time-domain peak" of a sequence whose DFT is A[m]^2.

This gives us a spectral perspective: we want to choose a (non-negative, sum 1) such that the time-domain peak of |A|^2 (interpreted as a DFT) is minimized.

This is related to the "peak-to-average power ratio" (PAPR) problem in OFDM systems! The goal is to minimize the PAPR of the signal, where the "signal" here is the inverse DFT of |A|^2.

There are well-known algorithms for PAPR reduction:
- Tone reservation
- Selective mapping
- Partial transmit sequence

But these are for complex signals. For our real, non-negative problem, the constraints are different.

However, the spectral insight is useful: we can work in the frequency domain and optimize |A|^2 subject to the constraint that the inverse DFT is non-negative and has sum 1.

Let me now write the actual algorithm. I'll use a combination of:
1. Time-domain gradient optimization (like the previous code but with better starts)
2. A spectral-domain refinement step
3. Active-set polishing

For the starts, I'll try:
- Cosine-tapered: a_i ∝ (1 + cos(pi * i / (n-1))) / 2 (smooth taper at both ends)
- Raised cosine: a_i ∝ cos^2(pi * (i - (n-1)/2) / n)
- Gaussian: a_i ∝ exp(-((i - (n-1)/2)^2) / (2 * sigma^2)) for various sigma
- Previous best (resampled)
- Random smooth: sum of a few Gaussians

Actually, let me reconsider the time budget. With n = 16384:
- One FFT: ~O(16384 * log(16384)) ≈ 16384 * 14 ≈ 229K operations
- One forward + inverse FFT for convolution: ~460K operations
- Gradient computation: similar
- L-BFGS with 1000 function evaluations: ~460M operations

Python's numpy FFT is implemented in C, so each call is very fast (maybe 0.1-1ms). 1000 evaluations should take a few seconds.

With the time budget of 2400s, we can afford many optimization runs.

Let me write the code now. I'll structure it as:

1. Set up the problem (choose n, prepare FFT sizes)
2. Generate diverse starting points
3. Run L-BFGS from each start (with the log-sum-exp smoothed max)
4. Take the best result and do active-set polishing
5. Return the best sequence found

For the active-set polishing, I'll:
1. Compute the convolution
2. Find the top m lags (where m is adaptive)
3. Use a barrier method or projected gradient to minimize the max of just those m quadratic forms
4. Iterate: expand the active set if new lags appear

Let me also add a "two-phase" approach:
- Phase 1: Coarse optimization with tau = 0.01 (quick convergence)
- Phase 2: Fine optimization with tau = 1e-5 (tighter approximation)
- Phase 3: Active-set polish

import numpy as np
import time
from scipy.optimize import minimize

"""
Algorithm: Multi-scale spectral optimization for minimum peak convolution.

We minimize the score 2n * max(a*a) / (sum(a))^2 over non-negative sequences a.
Since the score is scale-invariant, we work with sum(a) = 1.

Key insights:
1. The linear convolution a*a in the time domain corresponds to |FFT(a)|^2 in frequency.
2. We want the time-domain peak of the convolution to be as low as possible.
3. We use a multi-phase approach: coarse smooth optimization, fine optimization,
   and active-set polishing.

Parameterization: a_i = exp(z_i) / sum(exp(z_j)) (softmax/log-space)
This ensures a_i > 0 and automatically handles the sum constraint.
"""

# Global state for the optimizer
_N = 0
_NFFT = 0
_TAU = 1e-6
_DEADLINE = 0.0


def _init(n, tau=1e-6):
    global _N, _NFFT, _TAU
    _N = int(n)
    _NFFT = 1 << (3 * _N - 2).bit_length()  # next power of 2 >= 2n-1
    _TAU = float(tau)


def _softmax(z):
    z = np.asarray(z, dtype=np.float64).ravel()
    z = z - np.max(z)
    e = np.exp(z)
    s = e.sum()
    if s <= 0 or not np.isfinite(s):
        return np.full_like(z, 1.0 / z.size)
    return e / s


def _fft_conv(a):
    """Compute linear convolution a*a using FFT."""
    n = a.size
    N = _NFFT
    L = 2 * n - 1
    fa = np.fft.rfft(a, N)
    c = np.fft.irfft(fa * fa, N)[:L]
    return c


def _score(a):
    """Compute the score for sequence a (assumes sum a = 1 for speed)."""
    s = a.sum()
    if s < 1e-12:
        return np.inf
    c = _fft_conv(a)
    m = c.max()
    return 2.0 * a.size * m / (s * s)


def _obj_grad(z, tau=None):
    """Smoothed maximum of convolution + gradient."""
    if tau is None:
        tau = _TAU
    n = _N
    N = _NFFT
    L = 2 * n - 1

    z = np.asarray(z, dtype=np.float64).ravel()
    z = np.clip(z, -50.0, 50.0)

    a = _softmax(z)
    fa = np.fft.rfft(a, N)
    c = np.fft.irfft(fa * fa, N)[:L]
    c = np.maximum(c, 1e-300)  # avoid log(0)

    m = c.max()
    if not np.isfinite(m):
        return 1e12, np.zeros(n)

    # log-sum-exp approximation to max
    diff = (c - m) / tau
    diff = np.clip(diff, -745.0, 0.0)
    e = np.exp(diff)
    se = e.sum()
    if se <= 0 or not np.isfinite(se):
        return 1e12, np.zeros(n)

    p = e / se  # "attention" weights on the convolution values

    # Gradient of the smoothed max w.r.t. a
    # d(smoothed_max)/da = 2 * (p * a) (where * is correlation, not convolution)
    # More precisely: d c_k / d a_i = a_i * a_{k-i} + a_{k-i} * a_i (for valid indices)
    # So d(sum_k p_k * c_k)/d a_i = 2 * sum_k p_k * a_{k-i} * a_i... 
    # Actually, let me derive this more carefully.
    
    # c_k = sum_j a_j * a_{k-j} (linear convolution)
    # d c_k / d a_i = a_{k-i} + a_{k-i} = 2 * a_{k-i} (if 0 <= k-i < n)
    # Wait, that's not right either. Let me think again.
    # c_k = sum_j a_j * a_{k-j} where the sum is over j such that 0<=j<n and 0<=k-j<n
    # d c_k / d a_i: 
    #   If we differentiate a_j with respect to a_i, we get delta_{j,i} * a_{k-i}
    #   If we differentiate a_{k-j} with respect to a_i, we get delta_{k-j,i} = delta_{j,k-i} * a_i
    #   So d c_k / d a_i = a_{k-i} (if 0<=k-i<n) + a_i (if i<=k<n... wait)
    #   Actually: d c_k / d a_i = a_{k-i} [if 0 <= k-i < n] + a_{k-i} [if i is the second index]
    #   Hmm, let me be more careful.
    #   c_k = sum_{j=max(0,k-n+1)}^{min(k,n-1)} a_j * a_{k-j}
    #   d c_k / d a_i = a_{k-i} (from the first factor, when j=i) + a_{k-i} (from the second factor, when k-j=i, i.e., j=k-i)
    #   But these are the same term if j=i and j=k-i simultaneously, i.e., i=k-i, i.e., k=2i.
    #   So: d c_k / d a_i = a_{k-i} + a_{k-i} = 2*a_{k-i} if i != k-i (i.e., k != 2i)
    #                d c_k / d a_i = 2*a_i if k = 2i
    #   Wait no. Let me redo.
    #   c_k = sum_j a_j * a_{k-j}
    #   d c_k / d a_i = (d/d a_i) sum_j a_j * a_{k-j}
    #   = sum_j [delta_{j,i} * a_{k-j} + a_j * delta_{k-j,i}]
    #   = a_{k-i} + a_{k-i}  (the first term picks j=i, giving a_{k-i}; the second picks j=k-i, giving a_{k-i})
    #   = 2 * a_{k-i}
    #   (provided 0 <= k-i < n)
    #   
    #   So d c_k / d a_i = 2 * a_{k-i} if 0 <= k-i < n, else 0.
    #
    #   This means: d(sum_k p_k c_k)/d a_i = 2 * sum_k p_k * a_{k-i} (for valid k-i)
    #   = 2 * (p * a)_{reversed and shifted}... 
    #   Let me define q[i] = sum_k p_k * a_{k-i} for valid k-i.
    #   This is the cross-correlation of p and a!
    #   q = correlate(p, a) in numpy terms, or equivalently:
    #   q[i] = sum_k p[k] * a[k-i] = (p * a_reversed)[i + n - 1]... 
    #   
    #   Actually, let me use the FFT approach.
    #   q[i] = sum_{k} p[k] * a[k-i] where 0 <= k < 2n-1 and 0 <= k-i < n
    #   This is the cross-correlation of p (length 2n-1) and a (length n).
    #   
    #   Using FFT: 
    #   corr = ifft(fft(p) * conj(fft(a)))  (circular correlation)
    #   But we need linear correlation, so we need to pad.
    
    # Let me use a different approach. Define:
    # h[i] = d F / d a_i where F = sum_k p_k * c_k
    # h[i] = 2 * sum_{k} p[k] * a[k-i] for 0<=k-i<n, summed over valid k
    # 
    # This is 2 * (p * reverse(a))... no.
    # 
    # Let's think of it as: h = 2 * (p circ_conv a) truncated
    # where p has length 2n-1 and a has length n.
    # 
    # Actually, the simplest way: 
    # h[i] = 2 * sum_{k=i}^{i+n-1} p[k] * a[k-i]  (k ranges so that k-i is in [0,n-1] and k is in [0,2n-2])
    # So for each i, h[i]/2 = sum_{j=0}^{n-1} p[i+j] * a[j] (where p[i+j] is 0 if i+j >= 2n-1)
    # 
    # This is a sliding dot product = cross-correlation of p and a.
    # We can compute it with FFT:
    #   Pad p to length N (already have it from the FFT of a)
    #   h[i]/2 = ifft(fft(p) * conj(fft(a)))[i] ... circular correlation
    #   But we need linear, so pad appropriately.
    
    # Let me just use the FFT trick:
    # h[i] = 2 * (cross-correlation of p and a)[i]
    # cross_corr[i] = sum_j p[i+j] * a[j] for j=0..n-1 (this is the "reverse" correlation)
    # 
    # In FFT terms: cross_corr = ifft(conj(fft(p_padded)) * fft(a_padded))
    # Wait, let me be careful with the convention.
    # 
    # numpy's correlation: np.correlate(p, a, mode='valid') would give what we want
    # but it's O(n^2). For FFT:
    # 
    # We want: h[i] = sum_{j=0}^{n-1} p[i+j] * a[j] for i = 0, ..., n-1
    # (with p[i+j] = 0 if i+j >= 2n-1)
    # 
    # This is equivalent to: h = ifft(fft(p) * conj(fft(a)))[:n] (circular correlation, 
    # with appropriate padding to make it linear)
    # 
    # Let me verify: circular correlation of p (length L) and a (length L) is:
    # corr[i] = sum_j p[j] * a[(i-j) mod L]
    # 
    # Hmm, that's not quite what I want. Let me use a different approach.
    # 
    # Alternative: note that h[i] = sum_j p[i+j] * a[j]
    # Let's define p_rev = reverse(p), so p_rev[k] = p[L-1-k] where L = 2n-1
    # Then h[i] = sum_j p[i+j] * a[j] = sum_j p_rev[L-1-i-j] * a[j]
    # This is (p_rev * a) for linear convolution, evaluated at index L-1-i.
    #
    # So h = reverse(convolve(p_rev, a))[0:n]... this is getting confusing.
    #
    # Let me just use the direct FFT formula:
    # h[i] = sum_{j=0}^{n-1} a[j] * p[i+j]
    # 
    # Define P[m] = FFT of p (padded to length N)
    # Define A[m] = FFT of a (padded to length N)
    # 
    # The linear convolution (p * a)[k] = sum_j p[j] * a[k-j]
    # We want sum_j a[j] * p[i+j] = sum_j a[j] * p[(i+j)] 
    # Let l = i+j, then j = l-i, and this becomes sum_l a[l-i] * p[l]
    # = sum_l p[l] * a[l-i]
    # This is the cross-correlation! 
    # cross_corr[i] = sum_l p[l] * a[l-i] (for valid l, l-i)
    # 
    # In FFT: cross_corr = ifft(conj(P) * A) (circular, with padding for linearity)
    # 
    # Wait, let me be very precise. The DFT convention in numpy:
    # FFT: X[k] = sum_n x[n] * exp(-2*pi*i*k*n/N)
    # IFFT: x[n] = (1/N) * sum_k X[k] * exp(2*pi*i*k*n/N)
    # 
    # Correlation: (f corr g)[n] = sum_m f[m] * conj(g[m-n]) (circular)
    # In DFT: FFT(f corr g) = conj(FFT(f)) * FFT(g)
    # (assuming g is real, conj is trivial)
    #
    # So: cross_corr = ifft(conj(P) * A)
    # where P = FFT(p, N), A = FFT(a, N)
    #
    # This gives circular correlation. For linear correlation, we need N >= (2n-1) + n - 1 = 3n-2.
    # 
    # We already have N = next_pow2(3n-2) from _init! Great.
    #
    # So: h = 2 * ifft(conj(fft(p, N)) * fft(a, N))[:n]
    # But we need to be careful about the circular vs linear distinction.
    # With N >= 3n-2, the circular correlation equals the linear correlation for the first n values.
    
    # Compute h
    fp = np.fft.rfft(p, N)
    fa2 = np.fft.rfft(a, N)
    h = 2.0 * np.fft.irfft(np.conjugate(fp.real) * fa2, N)[:n].real
    # Wait, for real signals: conj(fft(p)) = fft(reverse(p))[0]... 
    # Actually for real signals, conj(FFT(p)[k]) = FFT(p)[N-k]
    # And the correlation formula is: corr = ifft(conj(FFT(p)) * FFT(a))
    # For real p and a: conj(FFT(p)) = FFT(p) reversed (with index 0 fixed)
    # 
    # Let me just use the full complex FFT to be safe:
    fp_c = np.fft.fft(p, N)
    fa_c = np.fft.fft(a, N)
    h = 2.0 * np.fft.ifft(np.conjugate(fp_c) * fa_c, N)[:n].real
    
    # Now grad w.r.t. z: a = softmax(z), so da_i/dz_j = a_i * (delta_{ij} - a_j)
    # grad_z_j = sum_i h[i] * da_i/dz_j = sum_i h[i] * a_i * (delta_{ij} - a_j)
    #          = h[j] * a_j - a_j * sum_i h[i] * a_i
    
    s_h = np.dot(h, a)
    grad_z = a * (h - s_h)
    
    # The objective value (smoothed max):
    F = m + tau * np.log(se)
    
    # Scale for numerical stability
    scale = float(n)
    val = F * scale
    grad_z = grad_z * scale
    
    # Small regularization to break symmetry
    val += 1e-12 * np.dot(z, z)
    grad_z += 2e-12 * z
    
    return float(val), grad_z


def _run_l_bfgs(z0, tau, maxfun=1000, maxiter=300):
    """Run L-BFGS with the given initial point and tau."""
    global _TAU
    old_tau = _TAU
    _TAU = tau
    
    def mc(z):
        return _obj_grad(z, tau)
    
    n = _N
    bounds = [(-50.0, 50.0)] * n
    opts = {"maxfun": maxfun, "maxiter": maxiter, "ftol": 1e-14, "pgtol": 1e-12, "disp": False}
    
    try:
        res = minimize(mc, z0, jac=True, method="L-BFGS-B", bounds=bounds, options=opts)
        _TAU = old_tau
        return res
    except Exception as e:
        _TAU = old_tau
        return None


def _cosine_taper(n):
    """a_i ∝ cos^2(pi * i / (2*(n-1)))"""
    i = np.arange(n)
    a = np.cos(np.pi * i / (2 * (n - 1))) ** 2
    a = np.maximum(a, 1e-10)
    return a / a.sum()


def _raised_cosine(n, width=1.0):
    """Raised cosine with adjustable width."""
    i = np.arange(n)
    x = (i - (n - 1) / 2.0) / (width * n / 2.0)
    a = np.cos(np.pi * x / 2.0) ** 2
    a = np.maximum(a, 1e-10)
    return a / a.sum()


def _gaussian(n, sigma_ratio=0.3):
    i = np.arange(n)
    center = (n - 1) / 2.0
    a = np.exp(-0.5 * ((i - center) / (sigma_ratio * n)) ** 2)
    a = np.maximum(a, 1e-10)
    return a / a.sum()


def _triangular(n):
    i = np.arange(n)
    a = np.minimum(i + 1, n - i)
    a = np.maximum(a, 1.0)
    return a / a.sum()


def _two_level(n, ratio=2.0, n_low=None):
    """Two-level sequence: low values in the middle, high at the ends (or vice versa)."""
    if n_low is None:
        n_low = n // 3
    a = np.ones(n)
    # High at ends, low in middle
    a[:n_low] = ratio
    a[n - n_low:] = ratio
    # Or low at ends, high in middle (try both)
    return a / a.sum()


def _two_level_inv(n, ratio=2.0, n_low=None):
    """Low at ends, high in middle."""
    if n_low is None:
        n_low = n // 3
    a = np.ones(n)
    a[:n_low] = 1.0 / ratio
    a[n - n_low:] = 1.0 / ratio
    return a / a.sum()


def _make_starts(n, rng):
    """Generate diverse starting points."""
    starts = []
    
    def add_start(a):
        a = np.asarray(a, dtype=np.float64)
        a = np.maximum(a, 1e-10)
        a = a / a.sum()
        z = np.log(a) - np.log(a).mean()
        z = np.clip(z, -30.0, 30.0)
        sc = _score(a)
        if np.isfinite(sc):
            starts.append((sc, z, a.copy()))
    
    # Cosine taper
    add_start(_cosine_taper(n))
    
    # Raised cosine with various widths
    for w in (0.5, 0.7, 1.0, 1.5, 2.0):
        add_start(_raised_cosine(n, w))
    
    # Gaussian with various sigmas
    for sig in (0.2, 0.3, 0.4, 0.5, 0.7, 1.0):
        add_start(_gaussian(n, sig))
    
    # Triangular
    add_start(_triangular(n))
    
    # Two-level (high at ends)
    for ratio in (0.5, 0.7, 1.5, 2.0, 3.0):
        for frac in (0.1, 0.2, 0.3, 0.5):
            n_low = int(frac * n)
            add_start(_two_level(n, ratio, n_low))
    
    # Two-level inverted (low at ends)
    for ratio in (0.5, 0.7, 1.5, 2.0, 3.0):
        for frac in (0.05, 0.1, 0.15, 0.25):
            n_low = int(frac * n)
            add_start(_two_level_inv(n, ratio, n_low))
    
    # Previous best (resampled)
    try:
        g = globals().get("height_sequence_1")
        if g is not None:
            g = np.asarray(g, dtype=np.float64)
            if g.size > 1:
                g = np.maximum(g, 1e-300)
                if np.all(np.isfinite(g)) and g.sum() > 0:
                    g = g / g.sum()
                    # Resample to length n
                    x_old = np.linspace(0, 1, g.size)
                    x_new = np.linspace(0, 1, n)
                    g_new = np.interp(x_new, x_old, g)
                    add_start(g_new)
    except Exception:
        pass
    
    # Random smooth starts
    i = np.arange(n)
    u = np.linspace(0, 1, n)
    for _ in range(10):
        a = np.ones(n)
        for m in range(1, 8):
            c1 = 0.3 * rng.standard_normal()
            c2 = 0.3 * rng.standard_normal()
            a += c1 * np.sin(2 * np.pi * m * u + rng.standard_normal())
            a += c2 * np.cos(2 * np.pi * m * u + rng.standard_normal())
        a = np.maximum(a, 1e-10)
        add_start(a)
    
    # Sort by score
    starts.sort(key=lambda x: x[0])
    # Keep top K
    return starts[:min(len(starts), 20)]


def _active_set_polish(a0, deadline, m_max=50):
    """
    Polish using active-set method.
    Identify the top-m lags where the convolution is near its max,
    and optimize to reduce the max of just those.
    """
    n = a0.size
    N = _NFFT
    a = np.asarray(a0, dtype=np.float64).copy()
    a = np.maximum(a, 1e-15)
    a = a / a.sum()
    
    best_a = a.copy()
    best_score = _score(a)
    best_maxc = best_score / (2.0 * n)
    
    tau = 1e-7
    no_improve = 0
    it = 0
    
    while time.monotonic() < deadline:
        c = _fft_conv(a)
        F = c.max()
        
        if F < best_maxc - 1e-15:
            best_a = a.copy()
            best_score = 2.0 * n * F
            best_maxc = F
        
        # Smooth max with very small tau
        diff = (c - F) / tau
        diff = np.clip(diff, -745.0, 0.0)
        e = np.exp(diff)
        se = e.sum()
        if se <= 0 or not np.isfinite(se):
            break
        p = e / se
        
        # Compute gradient
        fp_c = np.fft.fft(p, N)
        fa_c = np.fft.fft(a, N)
        h = 2.0 * np.fft.ifft(np.conjugate(fp_c) * fa_c, N)[:n].real
        
        s_h = np.dot(h, a)
        g = a * (h - s_h)
        
        # Line search in log-space
        b = np.log(np.maximum(a, 1e-300))
        b = b - b.mean()
        
        accepted = False
        for eta in (1e-5, 3e-5, 1e-4, 3e-4, 1e-3, 3e-3, 1e-2, 3e-2, 1e-1, 0.5, 1.0, 3.0, 10.0):
            b_t = np.clip(b - eta * g * n, -50.0, 50.0)
            a_t = _softmax(b_t)
            F_t = _fft_conv(a_t).max()
            if F_t < F - 1e-16:
                a = a_t
                b = b_t
                accepted = True
                break
        
        if not accepted:
            no_improve += 1
            if no_improve > 100:
                break
        else:
            no_improve = 0
        
        it += 1
        if it % 100 == 0:
            cur = 2.0 * n * F
            print(f"  polish it={it} cur={cur:.9f} best={best_score:.9f} "
                  f"time_left={max(0, deadline-time.monotonic()):.0f}s")
    
    return best_a


def _polish_with_expanded_set(a0, deadline, m_list=(10, 30, 80, 200)):
    """
    Active-set polish with expanding active set.
    At each stage, identify the top-m lags and run gradient steps
    focusing on those.
    """
    n = a0.size
    N = _NFFT
    a = np.asarray(a0, dtype=np.float64).copy()
    a = np.maximum(a, 1e-15)
    a = a / a.sum()
    
    best_a = a.copy()
    best_score = _score(a)
    best_maxc = best_score / (2.0 * n)
    
    rng = np.random.default_rng(12345)
    
    for m in m_list:
        if time.monotonic() > deadline:
            break
        
        # Identify top-m lags
        c = _fft_conv(a)
        F = c.max()
        top_lags = np.argsort(c)[-m:]
        top_max = c[top_lags].min()
        
        # Run gradient steps focusing on top-m lags
        tau = max(1e-8, (F - top_max) * 0.1)
        b = np.log(np.maximum(a, 1e-300))
        b = b - b.mean()
        
        stuck = 0
        for it in range(500):
            if time.monotonic() > deadline - 10:
                break
            
            c = _fft_conv(a)
            F = c.max()
            
            if F < best_maxc - 1e-15:
                best_a = a.copy()
                best_score = 2.0 * n * F
                best_maxc = F
            
            # Pseudo-marginal distribution concentrated on top-m lags
            c_focus = c.copy()
            # Down-weight non-top-m lags
            mask = np.zeros_like(c, dtype=bool)
            mask[top_lags] = True
            c_focus[~mask] *= 0.01
            
            diff = (c_focus - F) / tau
            diff = np.clip(diff, -745.0, 0.0)
            e = np.exp(diff)
            se = e.sum()
            if se <= 0 or not np.isfinite(se):
                break
            p = e / se
            
            fp_c = np.fft.fft(p, N)
            fa_c = np.fft.fft(a, N)
            h = 2.0 * np.fft.ifft(np.conjugate(fp_c) * fa_c, N)[:n].real
            
            s_h = np.dot(h, a)
            g = a * (h - s_h)
            
            accepted = False
            for eta in (1e-5, 3e-5, 1e-4, 3e-4, 1e-3, 1e-2, 3e-2, 0.1, 0.3):
                b_t = np.clip(b - eta * g * n, -50.0, 50.0)
                a_t = _softmax(b_t)
                F_t = _fft_conv(a_t).max()
                if F_t < F - 1e-16:
                    a = a_t
                    b = b_t
                    accepted = True
                    stuck = 0
                    break
            
            if not accepted:
                # Random perturbation
                for scale in (0.01, 0.05, 0.2):
                    b_t = np.clip(b + scale * rng.standard_normal(n), -50.0, 50.0)
                    a_t = _softmax(b_t)
                    F_t = _fft_conv(a_t).max()
                    if F_t < best_maxc - 1e-15:
                        a = a_t
                        b = b_t
                        stuck = 0
                        break
                else:
                    stuck += 1
                    if stuck > 50:
                        break
        
        print(f"  active-set m={m}: best_score={best_score:.9f}")
    
    return best_a
