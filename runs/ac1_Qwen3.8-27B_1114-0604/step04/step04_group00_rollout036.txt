The score is 2n * max(c) / S^2. If we normalize S=1, it's 2n * max(c). The "average" of c is 1/(2n-1) (since sum(c) = S^2 = 1). So the score is 2n * max(c) = 2n * (2n-1) * max(c) / (2n-1) = 2n * (2n-1) * (max(c) / mean(c)) / (2n-1) = 2n * (max/mean).

Score = 2n * max(c) = 2n * mean(c) * (max/mean) = 2n/(2n-1) * (max/mean).

So the score is proportional to the "peak factor" of the convolution (ratio of max to mean). Minimizing the score is equivalent to minimizing the peak factor of conv(a,a).

Let me think about a **Frank-Wolfe (conditional gradient)** approach:

The problem: min f(a) = max_k c_k(a) subject to a in simplex (sum=1, a>=0)

Frank-Wolfe:
- At each iteration, compute subgradient g of f at current a
- Find the vertex v of the simplex that minimizes <g, v> (i.e., v is a unit vector in the direction of the smallest component of g)
- Update: a_new = (1-t)*a + t*v

But this is for the max of linear functions, and our problem is more complex (conv is quadratic in a).

Actually, the problem min max_k c_k(a) s.t. a in simplex is a minimax problem where each c_k is convex in a (since c_k = a^T M_k a where M_k is a symmetric matrix). Wait, is c_k convex in a? c_k = sum_i a[i]*a[k-i], which is a quadratic form. It's convex if the corresponding matrix is PSD.

The matrix for c_k has M_k[i,j] = 1 if j = k-i (i.e., i+j=k). This is a permutation matrix (anti-diagonal), which is orthogonal, so it's PSD (eigenvalues are ±1). Wait, the quadratic form a^T M_k a where M_k[i,j] = 1 if i+j=k... Let me think.

c_k = sum_i a[i] * a[k-i] = sum_i a[i] * (M_k a)[i] where (M_k a)[i] = a[k-i].
So M_k is the "reversal" matrix shifted by k. It's a symmetric matrix with 1s on the k-th anti-diagonal.

For the quadratic form a^T M_k a: the eigenvalues of M_k depend on k. For k = n-1 (the center), M_k is the full reversal matrix, which has eigenvalues +1 and -1, so it's NOT PSD. This means c_k is NOT convex in a in general.

So the problem is non-convex, which explains why we need heuristics.

    score = 2.0 * n * L / (S * S)
    p = exp_scaled / exp_scaled.sum()

    M2 = 2 * n - 1
    M3 = M2 + n - 1  # 3n - 2

    S3 = S2 * S

        if pn not in lengths_to_try:
            lengths_to_try.insert(0, pn)

    for n in lengths_to_try:
        if time.monotonic() > phase0_end:
            break
        # Build initializations
        x = np.arange(n, dtype=np.float64) / n
        inits = [
            np.ones(n) * 0.5,
            np.maximum(0.3 + 0.7 * np.cos(2 * np.pi * x) ** 2, 0.01),
            np.maximum(0.2 + 0.6 * np.cos(2 * np.pi * x) + 0.2 * np.cos(4 * np.pi * x), 0.01),
            np.clip(0.5 + 0.3 * rng.standard_normal(n), 0.01, 5.0),
        ]
        if parent is not None:
            inits.insert(0, upsample(parent, n))

        for i, a0 in enumerate(inits):
            if time.monotonic() > phase0_end:
                break
            a_f = fienup_spectral(a0, n_iters=150)
            sc = compute_score(a_f)
            update_best(sc, a_f, f"Fienup n={n} i={i}")

    print(f"  Phase 0 best: {best_score:.8f}")

    # ================================================================
    # Phase 1: Annealed optimization on best + parent (45%)
    # ================================================================
    phase1_end = t_start + 0.55 * (total_budget - 35.0)
    print(f"\n=== Phase 1: Annealed L-BFGS+FISTA (to t={phase1_end - t_start:.0f}s) ===")

    # Anneal on current best
    a_work = best_a.copy()
    sc, a_opt = annealed_optimization(a_work, time_budget=(phase1_end - time.monotonic()) * 0.6)
    update_best(sc, a_opt, "Anneal-main")
    a_work = a_opt

    # Anneal on parent at its native length
    if parent is not None and time.monotonic() < phase1_end - 60:
        remaining = (phase1_end - time.monotonic()) * 0.4
        sc_p, a_p_opt = annealed_optimization(parent, time_budget=remaining)
        update_best(sc_p, a_p_opt, "Anneal-parent")
        if sc_p < compute_score(a_work):
            a_work = a_p_opt

    # Anneal on a resampled version at different length
    if time.monotonic() < phase1_end - 60:
        n_resample = 8192 if len(a_work) != 8192 else 6144
        a_rs = upsample(a_work, n_resample)
        remaining = (phase1_end - time.monotonic()) * 0.5
        sc_rs, a_rs_opt = annealed_optimization(a_rs, time_budget=remaining)
        update_best(sc_rs, a_rs_opt, f"Anneal-resample n={n_resample}")
        if sc_rs < compute_score(a_work):
            a_work = a_rs_opt

    print(f"  Phase 1 best: {best_score:.8f}")

    # ================================================================
    # Phase 2: Fienup + peak coordinate descent (15%)
    # ================================================================
    phase2_end = t_start + 0.70 * (total_budget - 35.0)
    print(f"\n=== Phase 2: Fienup + Peak CD (to t={phase2_end - t_start:.0f}s) ===")

    # Fienup on best
    a_f2 = fienup_spectral(best_a, n_iters=200)
    sc = compute_score(a_f2)
    update_best(sc, a_f2, "Fienup-2")

    # Peak coordinate descent
    if time.monotonic() < phase2_end - 20:
        a_cd = peak_coordinate_descent(best_a, n_sweeps=20, n_top=100)
        sc = compute_score(a_cd)
        update_best(sc, a_cd, "Peak-CD")

    # Fienup on perturbed best
    a_pert = best_a * (1.0 + 0.05 * rng.standard_normal(len(best_a)))
    a_pert = np.clip(a_pert, 0.0, 1000.0)
    a_pert = a_pert / a_pert.sum()
    if time.monotonic() < phase2_end - 20:
        a_fp = fienup_spectral(a_pert, n_iters=200)
        sc = compute_score(a_fp)
        update_best(sc, a_fp, "Fienup-pert")

    print(f"  Phase 2 best: {best_score:.8f}")

    # ================================================================
    # Phase 3: Fine-grained final annealing (20%)
    # ================================================================
    phase3_end = deadline
    print(f"\n=== Phase 3: Final fine annealing (to t={phase3_end - t_start:.0f}s) ===")

    # High-beta L-BFGS sequence
    for beta in [5000, 10000, 20000, 50000, 100000]:
        if time.monotonic() > phase3_end - 20:
            break
        elapsed = time.monotonic() - t_start
        remaining = phase3_end - time.monotonic()
        if remaining < 20:
            break
        maxiter = min(5000, int(remaining * 3))
        maxfun = min(50000, maxiter * 10)
        if maxiter < 100:
            break
        sc, a_hi = run_lbfgs(best_a, beta, maxiter=maxiter, maxfun=maxfun)
        update_best(sc, a_hi, f"HighLSE beta={beta}")
        if sc < best_score:
            best_a = a_hi

        # Fista polish
        if time.monotonic() < phase3_end - 15:
            n_fista = min(2000, int((phase3_end - time.monotonic()) * 2))
            if n_fista > 100:
                sc_f, a_ff = fista_lse(best_a, beta, n_iters=n_fista)
                update_best(sc_f, a_ff, f"FISTA-polish beta={beta}")
                if sc_f < best_score:
                    best_a = a_ff

    # Final peak coordinate descent
    if time.monotonic() < deadline - 15:
        a_cd_final = peak_coordinate_descent(best_a, n_sweeps=10, n_top=120)
        sc = compute_score(a_cd_final)
        update_best(sc, a_cd_final, "Final-CD")

    # ================================================================
    # Final verification
    # ================================================================
    out = [float(max(0.0, min(1000.0, x))) for x in best_a]
    if sum(out) < 0.01:
        out = [0.5] * 64

    verified = float(evaluate_sequence(out))
    elapsed = time.monotonic() - t_start
    print(f"\n{'=' * 60}")
    print(f"FINAL: internal={best_score:.8f}, verified={verified:.8f}")
    print(f"Length: {len(out)}, Time: {elapsed:.1f}s / {total_budget}s")
    print(f"{'=' * 60}")
    return out
