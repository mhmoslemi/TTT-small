Let me now think about the simplex projection. The Euclidean projection of a vector `v` onto the probability simplex `{x >= 0, sum(x) = 1}` is:

`proj(v)_i = max(0, v_i - tau)` where `tau` is chosen so that `sum_i max(0, v_i - tau) = 1`.

To find `tau`: sort `v` in decreasing order: `v_(1) >= v_(2) >= ... >= v_(n)`. Then:
`tau = (sum_{i=1}^k v_(i) - 1) / k` where `k` is the largest index such that `v_(k) > (sum_{i=1}^k v_(i) - 1) / k`.

This can be computed in `O(n log n)` (dominated by the sort). For `n = 7000`, this is fast.

Actually, there's an `O(n)` expected-time algorithm using the "find the k-th largest" trick, but `O(n log n)` is fine for our purposes.

Let me also think about the **backtracking line search** for the subgradient method:

At iteration `t`:
- Current point: `a_t`
- Subgradient: `g_t`
- Proposed direction: `d_t = -g_t` (or with momentum: `d_t = -g_t + beta * d_{t-1}`)
- Find step size `eta`: start with `eta_0`, and reduce by factor `0.5` until `F(a_t + eta * d_t) < F(a_t) - c * eta * ||g_t||^2` (Armijo condition).

But evaluating `F` at each trial step requires computing the convolution, which is `O(n log n)`. So the line search adds a constant factor (typically 5-10 evaluations).

For the subgradient method on a non-smooth function, the Armijo condition might be too strict. Instead, we can use:
`F(a_t + eta * d_t) < F(a_t)` (just require decrease).

Or use a **barzilai-borwein** step size: `eta = <g_t - g_{t-1}, a_t - a_{t-1}> / ||g_t - g_{t-1}||^2`.

Let me think about what will actually work well in practice. Given that the previous approach achieved 1.506868, and we need to beat that, I think the key improvements are:

1. **Better local optimization**: The L-BFGS on LSE-smoothed objective probably converges to a point where the LSE gradient is zero, but the exact max gradient is not zero. So the final point is not a true stationary point of the original problem. We need to do a final "exact" optimization step.

2. **Multi-peak handling**: At the optimum, there are likely multiple peaks that are equal (or very close). The optimizer should handle this correctly.

3. **Convergence to a KKT point**: At the optimum, the gradient of the active objective should be in the span of the constraint gradients (non-negativity + sum constraint). This means: `g_j = lambda * a_j + mu` for all `j` (where `lambda` is for the non-negativity constraint and `mu` is for the sum constraint), with `g_j >= 0` for `a_j = 0`.

Actually, for the problem `min max_k (a*a)_k s.t. a >= 0, sum(a) = 1`, the KKT conditions are:
- There exist weights `w_k >= 0, sum w_k = 1` supported on the active peaks (where `(a*a)_k = max`).
- The gradient `g = sum_k w_k * grad (a*a)_k` satisfies: `g_j - nu = lambda_j` for all `j`, where `nu` is the Lagrange multiplier for the sum constraint, `lambda_j >= 0` is the multiplier for `a_j >= 0`, and `lambda_j * a_j = 0`.
- At the optimum: for `a_j > 0`, `g_j = nu` (constant). For `a_j = 0`, `g_j >= nu`.

So at the optimum, the weighted gradient is **constant over the support of `a`**! This is a useful stationarity condition we can check.

**Algorithm**: 
1. Start from a good initialization.
2. Iterate:
   a. Find all peaks where `(a*a)_k >= max * (1 - eps)`.
   b. Compute the gradient `g = sum_k w_k * grad_k` with `w_k` proportional to something (e.g., exponential weights).
   c. Check stationarity: is `g` approximately constant over the support? If yes, we're close to a KKT point.
   d. If not, take a step to reduce the "non-constancy" of `g` over the support.
3. The step should be in the direction that reduces the peak while maintaining the sum constraint.

A practical implementation:
- Direction: `d_j = -(g_j - mean(g_j * 1_{a_j > 0}))` for `j` in the support. This pushes the gradient toward being constant.
- But we also need to ensure the peak actually decreases. So we might need to project this direction.

"""
Hybrid optimizer for step function peak minimization.
Combines multi-peak projected subgradient with top-k LSE L-BFGS refinement.
Uses exact simplex projection and Barzilai-Borwein step sizes.
"""

import numpy as np
from scipy.optimize import minimize
import time


def fast_conv(a):
    """Linear self-convolution via FFT. Returns array of length 2n-1."""
    n = len(a)
    M = 2 * n - 1
    M_fft = 1 << (M - 1).bit_length()
    A = np.fft.rfft(a, M_fft)
    return np.fft.irfft(A * A, M_fft)[:M]


def compute_score(a):
    """Exact score: 2n * max(conv) / sum^2."""
    n = len(a)
    c = fast_conv(a)
    S = float(np.sum(a))
    if S < 1e-12:
        return np.inf
    return float(2.0 * n * np.max(c) / (S * S))


def project_simplex(v):
    """Euclidean projection onto probability simplex {x >= 0, sum(x) = 1}."""
    n = len(v)
    if n == 0:
        return v
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.where(u * np.arange(1, n + 1) > (cssv - 1))[0][-1]
    theta = (cssv[rho] - 1) / (rho + 1.0)
    return np.maximum(v - theta, 0)


def topk_lse_score_grad(a, beta, k=3):
    """
    Score and gradient of top-k LSE smoothed objective.
    Only considers the k largest convolution values.
    """
    n = len(a)
    c = fast_conv(a)
    S = float(np.sum(a))
    if S < 1e-12:
        return 1e10, np.zeros(n)
    
    # Find top-k indices
    # Use argpartition for efficiency when k << 2n-1
    if k < len(c):
        top_k_idx = np.argpartition(c, -k)[-k:]
        top_k_vals = c[top_k_idx]
    else:
        top_k_idx = np.arange(len(c))
        top_k_vals = c
    
    # LSE of top-k values
    c_max = float(top_k_vals.max())
    scaled = beta * (top_k_vals - c_max)
    exp_scaled = np.exp(scaled - scaled.max())
    p = exp_scaled / exp_scaled.sum()
    L = c_max + float(np.log(exp_scaled.sum())) / beta
    
    score = 2.0 * n * L / (S * S)
    
    # Gradient
    # dL/dc_j = p_j for j in top_k, 0 otherwise
    # dc_j/da_i = 2 * a_{j-i} for valid i
    grad = np.zeros(n)
    for idx, pk in zip(top_k_idx, p):
        k_val = int(idx)
        j_start = max(0, k_val - n + 1)
        j_end = min(k_val, n - 1)
        if j_end >= j_start:
            grad[j_start:j_end+1] += pk * 2.0 * a[k_val - j_start:k_val - j_start + (j_end - j_start + 1)][::-1]
    
    # d(score)/da = 2n * (dL/da / S^2 - 2L * d(1/S^2)/da)
    # d(1/S^2)/da_j = -2/S^3
    S2 = S * S
    S3 = S2 * S
    grad = (2.0 * n) * (grad / S2 - 2.0 * L / S3)
    
    return score, grad


def multi_peak_subgrad(a, n_iters=10000, f_lb=1.0, momentum=0.9, 
                        peak_frac=0.005, verbose=False):
    """
    Multi-peak subgradient with momentum and adaptive step size.
    Uses exact simplex projection.
    """
    n = len(a)
    a = a.astype(np.float64).copy()
    S = a.sum()
    if S < 1e-12:
        return a
    a = a / S
    
    v = np.zeros(n)  # momentum
    best_a = a.copy()
    best_sc = compute_score(a)
    
    # BB step size state
    a_prev = a.copy()
    g_prev = None
    eta = 0.1
    
    for it in range(n_iters):
        c = fast_conv(a)
        S_a = float(a.sum())
        peak_val = float(c.max())
        sc = 2.0 * n * peak_val / (S_a * S_a)
        
        if sc < best_sc:
            best_sc = sc
            best_a = a.copy()
            if verbose and it % 1000 == 0:
                print(f"    iter {it}: sc={sc:.10f}")
        
        # Find hot peaks
        threshold = peak_val * (1.0 - peak_frac)
        hot_idx = np.where(c >= threshold)[0]
        
        # Compute weighted gradient
        # Weight by exponential of normalized peak values
        hot_vals = c[hot_idx]
        w = (hot_vals - peak_val * (1 - peak_frac)) / (peak_frac * peak_val + 1e-30)
        w = np.exp(50 * w)  # sharp weighting toward the peak
        w = w / w.sum()
        
        g = np.zeros(n)
        for hi, wi in zip(hot_idx, w):
            k_val = int(hi)
            j_start = max(0, k_val - n + 1)
            j_end = min(k_val, n - 1)
            if j_end >= j_start:
                idx = np.arange(j_start, j_end + 1)
                g[idx] += wi * 2.0 * a[k_val - idx]
        
        S2 = S_a * S_a
        S3 = S2 * S_a
        g = (2.0 * n) * (g / S2 - 2.0 * peak_val / S3)
        
        # BB step size
        if g_prev is not None:
            s = a - a_prev
            y = g - g_prev
            ys = float(np.dot(y, s))
            yy = float(np.dot(y, y))
            if yy > 1e-30 and abs(ys) > 1e-30:
                eta_bb = ys / yy
                eta_bb = max(1e-8, min(eta_bb, 1.0))
                eta = 0.7 * eta + 0.3 * eta_bb
        a_prev = a.copy()
        g_prev = g.copy()
        
        gnorm = float(np.linalg.norm(g))
        if gnorm < 1e-15:
            break
        
        # Cap step size
        eta = min(eta, (sc - f_lb) / (gnorm * gnorm + 1e-30) + 1e-8)
        eta = min(eta, 0.5)
        
        # Momentum step
        v = momentum * v - eta * g
        a_new = a + v
        a = project_simplex(a_new)
    
    return best_a


def nesterov_multi_peak(a, n_iters=10000, f_lb=1.0, peak_frac=0.01, verbose=False):
    """Nesterov-accelerated multi-peak subgradient."""
    n = len(a)
    a = a.astype(np.float64).copy()
    S = a.sum()
    if S < 1e-12:
        return a
    a = a / S
    
    y = a.copy()
    t = 1.0
    best_a = a.copy()
    best_sc = compute_score(a)
    
    for it in range(n_iters):
        c = fast_conv(y)
        Sy = float(y.sum())
        peak_val = float(c.max())
        sc = 2.0 * n * peak_val / (Sy * Sy)
        
        if sc < best_sc:
            best_sc = sc
            best_a = y.copy()
        
        # Multi-peak gradient
        threshold = peak_val * (1.0 - peak_frac)
        hot_idx = np.where(c >= threshold)[0]
        hot_vals = c[hot_idx]
        w = (hot_vals - threshold) / (peak_frac * peak_val + 1e-30)
        w = np.exp(30 * w)
        w = w / w.sum()
        
        g = np.zeros(n)
        for hi, wi in zip(hot_idx, w):
            k_val = int(hi)
            j_start = max(0, k_val - n + 1)
            j_end = min(k_val, n - 1)
            if j_end >= j_start:
                idx = np.arange(j_start, j_end + 1)
                g[idx] += wi * 2.0 * y[k_val - idx]
        
        S2 = Sy * Sy
        S3 = S2 * Sy
        g = (2.0 * n) * (g / S2 - 2.0 * peak_val / S3)
        
        gnorm = float(np.linalg.norm(g))
        if gnorm < 1e-15:
            break
        
        step = (sc - f_lb) / (gnorm * gnorm + 1e-30)
        step = min(step, 0.3)
        
        t_new = (1.0 + np.sqrt(1.0 + 4.0 * t * t)) / 2.0
        theta = (t - 1.0) / t_new
        t = t_new
        
        y_new = y - step * g
        a_new = y_new + theta * (y_new - a)
        a = project_simplex(a_new)
        y = a.copy()
    
    return best_a


def run_lbfgs_topk(a0, beta, k, maxiter=20000, maxfun=100000):
    """L-BFGS on top-k LSE smoothed objective."""
    n = len(a0)
    a0 = np.clip(a0.astype(np.float64), 0.0, 1000.0).copy()
    S = a0.sum()
    if S < 1e-6:
        a0[:] = 0.5
        S = a0.sum()
    a0 = a0 / S
    
    def func(x):
        x = np.maximum(x, 0)
        Sx = x.sum()
        if Sx < 1e-12:
            return 1e10, np.zeros_like(x)
        sc, gr = topk_lse_score_grad(x, beta, k)
        return sc, gr
    
    res = minimize(
        func, a0,
        method='L-BFGS-B', jac=True,
        bounds=[(0.0, 1000.0)] * n,
        options={'ftol': 1e-20, 'gtol': 1e-15,
                 'maxiter': maxiter, 'maxfun': maxfun, 'maxls': 100}
    )
    a_out = np.clip(res.x, 0.0, 1000.0)
    S_out = a_out.sum()
    if S_out > 1e-12:
        a_out = a_out / S_out
    exact_sc = compute_score(a_out)
    return exact_sc, a_out


def spectral_init(n, rng):
    """Initialize using spectral/flat spectrum approach."""
    # Try to make |FFT(a)|^2 as flat as possible
    # This minimizes the peak of a*a
    a = np.ones(n) / n
    # Add random phase-like modulation (but keep non-negative)
    for _ in range(5):
        freq = rng.integers(1, n)
        amp = 0.1 * rng.random()
        a = a * (1.0 + amp * np.cos(2 * np.pi * freq * np.arange(n) / n + rng.uniform(0, 2*np.pi)))
    a = np.clip(a, 0, 1000)
    S = a.sum()
    if S > 0:
        a = a / S
    return a


def diverse_init(n, rng, parent=None):
    """Generate diverse initializations."""
    inits = []
    
    if parent is not None:
        if len(parent) == n:
            inits.append(parent.astype(np.float64).copy())
        else:
            x_old = np.linspace(0, 1, len(parent))
            x_new = np.linspace(0, 1, n)
            inits.append(np.interp(x_new, x_old, parent).copy())
    
    x = np.arange(n, dtype=np.float64) / n
    
    # Uniform
    inits.append(np.ones(n) / n)
    
    # U-shaped (mass at edges)
    inits.append(np.maximum(0.01, (2*x - 1)**2) / np.maximum(0.01, (2*x - 1)**2).sum())
    
    # Cosine window
    inits.append(np.maximum(0.01, np.cos(np.pi * x)) / np.maximum(0.01, np.cos(np.pi * x)).sum())
    
    # Spectral init
    inits.append(spectral_init(n, rng))
    
    # Random
    inits.append(np.clip(rng.standard_normal(n), 0.01, None))
    inits[-1] = inits[-1] / inits[-1].sum()
    
    # W-shaped
    inits.append(np.maximum(0.01, ((4*x - 1)**2) * ((4*x - 3)**2)) )
    inits[-1] = inits[-1] / inits[-1].sum()
    
    return inits
