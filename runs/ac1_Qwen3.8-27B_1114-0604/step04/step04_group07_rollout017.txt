Optimizer for minimizing 2n*max(self-conv)/(sum)^2 over non-negative sequences.
Uses log-space parameterization, adaptive LSE smoothing, L-BFGS, and peak-shaving.
"""

from scipy.optimize import minimize
import time


def fast_conv(a):
    """Fast linear self-convolution via FFT."""
    n = len(a)
    M = 2 * n - 1
    M_fft = 1 << (M - 1).bit_length()
    A = np.fft.rfft(a, M_fft)
    return np.fft.irfft(A * A, M_fft)[:M]


def compute_score(a):
    """Compute the exact score: 2n * max(conv) / sum^2."""
    n = len(a)
    c = fast_conv(a)
    S = float(a.sum())
    if S < 1e-12:
        return np.inf
    return 2.0 * n * float(c.max()) / (S * S)

    """
    LSE-smoothed score and gradient w.r.t. w where a = exp(w).

    """

    a = np.exp(w_shift)
    n = len(a)

    c_max = float(c.max())

    scaled = np.clip(scaled, -700, 700)
    exp_scaled = np.exp(scaled)
    p = exp_scaled / exp_scaled.sum()
    L = c_max + float(np.log(exp_scaled.sum())) / beta

**Peak-shaving algorithm:**
Given current `a` with score `S0`:
1. Compute `b = a * a`, find `k* = argmax(b)`
2. Compute contributions: `contrib[j] = a[j] * a[k*-j]` (for valid j)
3. For each j in the contributing set (in order of decreasing contribution):
   a. Try reducing `a[j]` by a small amount `delta`
   b. Redistribute `delta` to non-contributing elements (those that don't affect `b[k*]`)
   c. If the new score < S0, accept; else revert
4. Repeat for multiple rounds

The key question is: where to redistribute? The safest place is an element that:
- Doesn't contribute to `b[k*]` (i.e., `a[k*-j] = 0` or `j` is not in the contributing set)
- Doesn't contribute much to other high lags

A simple heuristic: redistribute uniformly to all non-contributing elements.
