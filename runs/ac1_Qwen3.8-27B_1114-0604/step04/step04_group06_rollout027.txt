rows 0 to i-1: 0
rows i to i+n-1: f[0], f[1], ..., f[n-1]
rows i+n to 2n-2: 0

```python

    n = len(f)
    A = np.zeros((2*n-1, n))
    for i in range(n):
        A[i:i+n, i] = f
    return A
```
