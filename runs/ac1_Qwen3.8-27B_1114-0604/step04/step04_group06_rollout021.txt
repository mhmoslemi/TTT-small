Actually, I recall now that this is related to the concept of "peak-to-average power ratio" (PAPR) or the "autocorrelation peak" problem in sequence design. The problem of finding sequences with low autocorrelation peaks is well-studied.

For a sequence of length n with sum S, the "average" value of the autocorrelation (summed over all lags) is:
`sum_k c[k] = (sum_i a[i])^2 = S^2`

There are 2n-1 values of c[k], so the average value is `S^2/(2n-1)`. For the score to be < 2, we need `max(c) < S^2/n`. Since the average is `S^2/(2n-1)`, we need the peak to be less than `S^2/n`, which is about twice the average (for large n). This is achievable!

So the problem is: find a non-negative sequence of length n that minimizes the peak of its autocorrelation relative to its sum.

This is essentially a "minimum peak autocorrelation" problem for non-negative sequences.

Key approaches:
1. **Random + optimization**: Start with a random non-negative sequence and use gradient-based optimization.
2. **Greedy construction**: Build the sequence greedily to keep autocorrelation peaks low.
