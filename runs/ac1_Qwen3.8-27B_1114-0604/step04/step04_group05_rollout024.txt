2. Find k* = argmax_k C_k (the current peak without coordinate j)
   - But wait, the peak might change when we vary x. We need to find all k that could be the maximizer for some x in [0, hi].
3. For each candidate k*, compute the optimal x from the formula above
4. Check that x is in the valid range and that k* is indeed the maximizer at that x
5. Pick the best valid x

This is O(n) per coordinate (to compute C_k and find all candidates), which is much better than O(n * log(precision)) for golden section.

Actually, step 2 is the tricky part. The set of k that could be the maximizer depends on x. For a given k, the condition that k is the maximizer is:
C_k + 2*x*a_{k-j} >= C_{k'} + 2*x*a_{k'-j} for all k' (with appropriate adjustments for k=2j case)

This is a system of linear inequalities in x (for k ≠ 2j case). The feasible x for each k is an interval. The global optimum is at one of the breakpoints or at the critical point within the feasible interval.

For a practical implementation:
1. Compute C_k for all k
2. For the current peak k_0 = argmax C_k, compute x_0 from the formula
3. Check if x_0 is valid (k_0 is still the max at x_0, and x_0 >= 0)
4. If not, try neighboring peaks
5. Also check x = 0 as a candidate

This should be very efficient and give exact 1D solutions.

Let me also think about the spectral initialization more carefully:

If we want `a*a` to be flat, we want `|DFT(a)|^2` to be... well, `DFT(a*a) = DFT(a) * DFT(a)` (with appropriate padding). If we want `a*a` to be flat (constant), then `DFT(a*a)` should be a delta at 0, which means `|DFT(a)|` should be a delta, which means `a` is an impulse. Contradiction.

What we actually want is: `a*a` has a small maximum. Since `a` is non-negative, `DFT(a)` is real and positive at DC (equal to sum a). The magnitude `|DFT(a)|` is |DFT(a)| = |Σ a_k e^{-2πik/n}|.

For a non-negative sequence, the DC component is the largest. The higher frequency components are smaller. So `|DFT(a)|^2` is dominated by the DC term, and `a*a ≈ (sum a)^2 / n * 1 + ...` (the DC term gives a constant, the rest gives the fluctuations).

The "fluctuations" in `a*a` come from the higher frequency components of `|DFT(a)|^2`. To minimize the peak, we want to minimize the contribution of higher frequencies.

One approach: design `a` so that `|DFT(a)|` decays rapidly (smooth time-domain signal → fast-decaying spectrum). But this makes `a` concentrated, which increases the peak.

Another approach: design `a` so that `|DFT(a)|^2` has a specific shape. For example, if `|DFT(a)|^2` is a low-pass filter (smooth decay), then `a*a` is a smooth bump (peaked at center). If `|DFT(a)|^2` is bandpass, then `a*a` has oscillations.

The optimal trade-off is what we're trying to find.

"""
Optimized step function search using:
1. Spectral-shaped initializations (Gaussian, raised-cosine, random+shaping)
2. LSE-smoothed L-BFGS with adaptive beta continuation
3. Exact 1D coordinate descent using closed-form solutions
4. Subgradient method with Polyak steps for final polishing

import numpy as np
from scipy.optimize import minimize
import time
import math


def fast_conv(a):
    n = len(a)
    M = 2 * n - 1
    M_fft = 1 << (M - 1).bit_length()
    A = np.fft.rfft(a, M_fft)
    return np.fft.irfft(A * A, M_fft)[:M]


def compute_score(a):
    n = len(a)
    c = fast_conv(a)
    S = float(a.sum())
    if S < 1e-12:
        return np.inf
    return 2.0 * n * float(c.max()) / (S * S)


def lse_score_grad_a(a, beta):
    n = len(a)
    c = fast_conv(a)
    S = float(a.sum())
    if S < 1e-12:
        return 1e10, np.zeros(n)
    c_max = float(c.max())
    scaled = beta * (c - c_max)
    exp_scaled = np.exp(scaled)
    log_sum = np.log(exp_scaled.sum())
    L = c_max + log_sum / beta
    score = 2.0 * n * L / (S * S)
    p = exp_scaled / exp_scaled.sum()
    rev_a = a[::-1]
    M2 = 3 * n - 2
    M2_fft = 1 << (M2 - 1).bit_length()
    RA = np.fft.rfft(rev_a, M2_fft)
    P = np.fft.rfft(p, M2_fft)
    conv_res = np.fft.irfft(RA * P, M2_fft)[n - 1:2 * n - 1]
    g = 2.0 * conv_res
    S2 = S * S
    S3 = S2 * S
    grad = (2.0 * n) * (g / S2 - 2.0 * L / S3)
    return score, grad


def subgradient_exact(a):
    """Compute exact subgradient and function value."""
    n = len(a)
    c = fast_conv(a)
    k_star = int(c.argmax())
    M = float(c[k_star])
    S = float(a.sum())
    score = 2.0 * n * M / (S * S)
    sg = np.zeros(n)
    js = max(0, k_star - n + 1)
    je = min(k_star, n - 1)
    if je >= js:
        idx = k_star - np.arange(js, je + 1)
        sg[js:je + 1] = a[idx]
    S2 = S * S
    S3 = S2 * S
    grad = (2.0 * n) * (sg / S2 - 2.0 * M / S3)
    return score, grad, k_star, M, S


def exact_1d_solve(a, j):
    """
    Exact 1D optimization of coordinate j.
    Uses the closed-form solution for the 1D subproblem.
    Returns the best value of a[j] and the corresponding score.
    """
    n = len(a)
    a_j_old = a[j]
    S0 = float(a.sum()) - a_j_old  # Sum excluding a[j]
    
    # Compute C_k = (a*a)_k with a[j] = 0
    a[j] = 0.0
    C = fast_conv(a)  # This is (a*a) with a[j]=0
    # a[j] is still 0 after this
    
    # For coordinate j, varying x = a[j]:
    # (a*a)_k(x) = C_k + 2*x*a[k-j] if 0<=k-j<n and k!=2j
    #              = C_k + x^2 if k==2j
    #              = C_k otherwise (if k-j out of range)
    
    S = S0  # Will be S0 + x
    
    best_score = compute_score(a)  # score at x=0
    best_x = 0.0
    
    # Candidate 1: x = 0 (already computed)
    
    # Find candidate peaks and compute optimal x for each
    # The peak at x=0 is at k0 = argmax(C)
    k0 = int(C.argmax())
    
    # For the current peak, compute optimal x
    candidates = []
    
    # Check k0 and nearby peaks
    # Sort by C_k value, take top ~50
    top_k_vals = np.argsort(C)[::-1][:min(50, len(C))]
    
    for k in top_k_vals:
        k = int(k)
        if k == 2 * j:
            # p(x) = C_k + x^2, q(x) = (S0 + x)^2
            # x* = C_k / S0 (if S0 > 0)
            if S0 > 1e-15:
                x_star = C[k] / S0
            else:
                continue
        else:
            # Check if k-j is in range
            kj = k - j
            if 0 <= kj < n:
                a_kj = a[kj]  # Note: a[j] is 0 right now, but a[kj] might be j
                if kj == j:
                    # This means k = 2j, which we handled above
                    # Actually this can't happen since k != 2j
                    continue
                if a_kj > 1e-15:
                    # x* = S0 - C_k / a_{k-j}
                    x_star = S0 - C[k] / a_kj
                else:
                    continue
            else:
                # No cross term, (a*a)_k = C_k for all x
                # Score is C_k / (S0+x)^2, minimized at x -> inf (but we have upper bound)
                # Actually this means increasing x only helps through the denominator
                # So we'd want x as large as possible, but other peaks might dominate
                # Skip for now
                continue
        
        if x_star < 0:
            x_star = 0.0
        # Upper bound: don't make x too large (say, 10*S0)
        x_star = min(x_star, 10.0 * S0)
        
        candidates.append(x_star)
    
    # Also try x = S0 * some_fraction (to increase sum)
    for frac in [0.1, 0.5, 1.0, 2.0]:
        candidates.append(frac * S0)
    
    # Evaluate each candidate
    for x in candidates:
        x = max(0.0, x)
        a[j] = x
        sc = compute_score(a)
        if sc < best_score:
            best_score = sc
            best_x = x
    
    a[j] = best_x
    return best_score


def coord_descent_exact(a, n_sweeps=5, top_k=100, time_budget=60.0, t_start=None):
    """Coordinate descent using exact 1D solves."""
    n = len(a)
    a = a.astype(np.float64).copy()
    best_score = compute_score(a)
    deadline = (t_start + time_budget) if (t_start is not None) else np.inf
    
    for sweep in range(n_sweeps):
        if time.monotonic() > deadline:
            break
        
        score, grad, k_star, M, S = subgradient_exact(a)
        if score < best_score:
            best_score = score
        
        # Select coordinates to optimize
        # Priority: coordinates with large |gradient| and coordinates near the peak
        order = np.argsort(np.abs(grad))[::-1][:top_k]
        
        for j in order:
            if time.monotonic() > deadline:
                break
            sc = exact_1d_solve(a, int(j))
            if sc < best_score:
                best_score = sc
    
    final_sc = compute_score(a)
    if final_sc < best_score:
        best_score = final_sc
    
    return best_score, a


def run_lbfgs_a(a0, beta, maxiter=2000, maxfun=50000, time_budget=None, t_start=None):
    n = len(a0)
    a0 = np.clip(a0.astype(np.float64), 0.0, 1000.0).copy()
    if a0.sum() < 1e-6:
        a0[:] = 1.0 / n
    bounds = [(0.0, 1000.0)] * n
    
    deadline = (t_start + time_budget) if (time_budget is not None and t_start is not None) else None
    
    def objective_and_grad(x):
        if deadline is not None and time.monotonic() > deadline:
            raise TimeoutError
        return lse_score_grad_a(x, beta)
    
    try:
        res = minimize(
            objective_and_grad, a0, method='L-BFGS-B', jac=True, bounds=bounds,
            options={'ftol': 1e-14, 'gtol': 1e-11,
                     'maxiter': maxiter, 'maxfun': maxfun, 'maxls': 50}
        )
        a_out = np.clip(res.x, 0.0, 1000.0)
    except (TimeoutError, Exception):
        a_out = a0
    
    exact_sc = compute_score(a_out)
    return exact_sc, a_out


def continuation_lbfgs_adaptive(a0, time_budget, t_start, betas=None, maxiter_per_stage=2000):
    """L-BFGS continuation with adaptive beta."""
    if betas is None:
        betas = [50, 100, 300, 1000, 3000, 10000, 30000, 100000]
    
    a = a0.copy()
    best_score = compute_score(a)
    best_a = a.copy()
    deadline = t_start + time_budget
    
    for i, beta in enumerate(betas):
        if time.monotonic() > deadline - 5:
            break
        remaining = deadline - time.monotonic()
        # Allocate more time to later stages
        frac = 0.3 if i < 3 else 0.2 if i < 6 else 0.15
        time_alloc = min(remaining * frac, 60.0)
        if time_alloc < 5:
            time_alloc = remaining * 0.2
            if time_alloc < 3:
                break
        
        sc, a_out = run_lbfgs_a(a, beta, maxiter=maxiter_per_stage,
                                  maxfun=10000, time_budget=time_alloc, t_start=t_start)
        if sc < best_score:
            best_score = sc
            best_a = a_out.copy()
            print(f"    AdaptLBFGS beta={beta}: {sc:.8f} (t={time.monotonic()-t_start:.0f}s)")
        a = a_out
    
    return best_score, best_a


def subgradient_method(a_init, n_steps=50000, time_budget=None, t_start=None):
    """
    Subgradient method with decreasing step size and averaging.
    For min f(a) = 2n*max(a*a)/(sum a)^2 subject to a >= 0.
    """
    n = len(a_init)
    x = a_init.astype(np.float64).copy()
    x_avg = x.copy()
    best_score = compute_score(x)
    best_a = x.copy()
    deadline = (t_start + time_budget) if (time_budget is not None and t_start is not None) else np.inf
    
    # Normalization: work with sum = 1 for stability
    S_init = x.sum()
    
    # Lower bound on score
    # score >= 2n/(2n-1) (from averaging argument)
    LB = 2.0 * n / (2 * n - 1)
    
    for t in range(1, n_steps + 1):
        if time.monotonic() > deadline:
            break
        
        score, grad, k_star, M, S = subgradient_exact(x)
        if score < best_score:
            best_score = score
            best_a = x.copy()
        
        # Polyak step size
        gap = score - LB
        gnorm2 = float(grad.dot(grad))
        if gnorm2 < 1e-30:
            break
        step = gap / gnorm2
        # Cap the step
        step = min(step, 1.0 / (t ** 0.5 * 0.01))
        
        x_new = x - step * grad
        x_new = np.clip(x_new, 0.0, 1000.0)
        
        # Normalize to maintain sum
        S_new = x_new.sum()
        if S_new > 1e-12:
            x_new = x_new * (S_init / S_new)
        
        # Averaging
        x_avg = x_avg + (x_new - x_avg) / t
        x = x_new
    
    # Check averaged solution
    x_avg_clip = np.clip(x_avg, 0.0, 1000.0)
    if x_avg_clip.sum() > 1e-12:
        sc_avg = compute_score(x_avg_clip)
        if sc_avg < best_score:
            best_score = sc_avg
            best_a = x_avg_clip
    
    return best_score, best_a


def spectral_init_gaussian(n, center_frac=0.5, width_frac=0.1):
    """Gaussian-shaped initialization."""
    x = np.arange(n, dtype=np.float64)
    center = center_frac * n
    width = width_frac * n
    a = np.exp(-0.5 * ((x - center) / width) ** 2)
    return a


def spectral_init_raised_cosine(n):
    """Raised cosine window."""
    x = np.arange(n, dtype=np.float64) / n
    a = 0.5 * (1 + np.cos(2 * np.pi * x))
    return a


def spectral_init_flat_spectrum(n, rng, n_taps=10):
    """
    Generate a sequence with a relatively flat power spectrum (within the 
    passband), then project to non-negative.
    """
    # Generate random phase sequence with flat magnitude
    M_fft = 1 << (n - 1).bit_length()
    A = np.zeros(M_fft // 2 + 1, dtype=np.complex128)
    A[0] = n  # DC
    for k in range(1, M_fft // 2 + 1):
        A[k] = np.exp(2j * np.pi * rng.uniform(0, 1))
    
    a = np.fft.irfft(A, M_fft)[:n]
    a = np.clip(a, 0.0, None)
    s = a.sum()
    if s > 1e-12:
        a = a / s
    else:
        a = np.ones(n) / n
    return a


def spectral_shaped_init(n, rng, shape='gaussian'):
    """Generate diverse spectral initializations."""
    if shape == 'gaussian':
        a = spectral_init_gaussian(n, center_frac=0.5, width_frac=rng.uniform(0.05, 0.2))
    elif shape == 'raised_cosine':
        a = spectral_init_raised_cosine(n)
    elif shape == 'flat_spectrum':
        a = spectral_init_flat_spectrum(n, rng)
    elif shape == 'bimodal':
        x = np.arange(n, dtype=np.float64)
        a = np.exp(-0.5 * ((x - 0.25*n) / (0.05*n))**2) + np.exp(-0.5 * ((x - 0.75*n) / (0.05*n))**2)
    else:
        a = np.ones(n) / n
    return np.clip(a, 0.0, None)


def refine_candidate(a_init, time_budget, t_start):
    """Multi-stage refinement pipeline."""
    a = a_init.copy()
    best_score = compute_score(a)
    best_a = a.copy()
    deadline = t_start + time_budget
    
    def try_update(sc, a_cand):
        nonlocal best_score, best_a
        if sc < best_score:
            best_score = sc
            best_a = np.clip(a_cand, 0.0, 1000.0).copy()
    
    # Stage 1: LSE-LBFGS continuation
    if time.monotonic() < deadline - 10:
        alloc = min(deadline - time.monotonic(), time_budget * 0.5)
        sc, a_opt = continuation_lbfgs_adaptive(a, alloc, t_start)
        try_update(sc, a_opt)
        a = best_a
    
    # Stage 2: Coordinate descent with exact 1D
    if time.monotonic() < deadline - 5:
        alloc = min(deadline - time.monotonic(), time_budget * 0.3)
        sc, a_opt = coord_descent_exact(a, n_sweeps=10, top_k=50,
                                         time_budget=alloc, t_start=t_start)
        try_update(sc, a_opt)
        a = best_a
    
    # Stage 3: Subgradient method
    if time.monotonic() < deadline - 3:
        alloc = min(deadline - time.monotonic() - 2, time_budget * 0.2)
        sc, a_opt = subgradient_method(a, n_steps=20000,
                                        time_budget=alloc, t_start=t_start)
        try_update(sc, a_opt)
        a = best_a
    
    # Final: quick coordinate descent
    if time.monotonic() < deadline - 1:
        sc, a_opt = coord_descent_exact(a, n_sweeps=3, top_k=30,
                                         time_budget=min(deadline - time.monotonic(), 10.0),

"""

import numpy as np

def fast_conv(a):
    n = len(a)
    M = 2 * n - 1
    M_fft = 1 << (M - 1).bit_length()
    A = np.fft.rfft(a, M_fft)
    return np.fft.irfft(A * A, M_fft)[:M]


def compute_score(a):
    n = len(a)
    c = fast_conv(a)
    S = float(a.sum())
    if S < 1e-12:
        return np.inf
    return 2.0 * n * float(c.max()) / (S * S)


def lse_score_grad_a(a, beta):
    n = len(a)
    c = fast_conv(a)
    S = float(a.sum())
    if S < 1e-12:
        return 1e10, np.zeros(n)
    c_max = float(c.max())
    scaled = beta * (c - c_max)
    exp_scaled = np.exp(scaled)
    log_sum = np.log(exp_scaled.sum())
    L = c_max + log_sum / beta
    score = 2.0 * n * L / (S * S)
    p = exp_scaled / exp_scaled.sum()
    rev_a = a[::-1]
    M2 = 3 * n - 2
    M2_fft = 1 << (M2 - 1).bit_length()
    RA = np.fft.rfft(rev_a, M2_fft)
    P = np.fft.rfft(p, M2_fft)
    conv_res = np.fft.irfft(RA * P, M2_fft)[n - 1:2 * n - 1]
    g = 2.0 * conv_res
    S2 = S * S
    S3 = S2 * S
    grad = (2.0 * n) * (g / S2 - 2.0 * L / S3)
    return score, grad


def subgradient_exact(a):
    n = len(a)
    c = fast_conv(a)
    k_star = int(c.argmax())
    M = float(c[k_star])
    S = float(a.sum())
    score = 2.0 * n * M / (S * S)
    sg = np.zeros(n)
    js = max(0, k_star - n + 1)
    je = min(k_star, n - 1)
    if je >= js:
        idx = k_star - np.arange(js, je + 1)
        sg[js:je + 1] = a[idx]
    S2 = S * S
    S3 = S2 * S
    grad = (2.0 * n) * (sg / S2 - 2.0 * M / S3)
    return score, grad, k_star, M, S


def exact_1d_solve(a, j):
    n = len(a)
    a_j_old = a[j]
    S0 = float(a.sum()) - a_j_old

    if S0 < 1e-15:
        return compute_score(a)

    a[j] = 0.0
    C = fast_conv(a)

    best_score = np.inf
    best_x = 0.0

    a[j] = 0.0
    sc0 = compute_score(a)
    best_score = sc0
    best_x = 0.0

    top_count = min(80, len(C))

    candidates = set()

        score, grad, k_star, M, S = subgradient_exact(a)

        order = np.argsort(np.abs(grad))[::-1][:top_k]

def run_lbfgs_a(a0, beta, maxiter=2000, maxfun=50000, time_budget=None, t_start=None):
    n = len(a0)
    a0 = np.clip(a0.astype(np.float64), 0.0, 1000.0).copy()

    def objective_and_grad(x):
        if deadline is not None and time.monotonic() > deadline:
            raise TimeoutError
        return lse_score_grad_a(x, beta)

    try:
        res = minimize(
            objective_and_grad, a0, method='L-BFGS-B', jac=True, bounds=bounds,
            options={'ftol': 1e-14, 'gtol': 1e-11,
                     'maxiter': maxiter, 'maxfun': maxfun, 'maxls': 50}
        )
        a_out = np.clip(res.x, 0.0, 1000.0)
    except (TimeoutError, Exception):
        a_out = a0

    exact_sc = compute_score(a_out)
    return exact_sc, a_out

def subgradient_method(a_init, n_steps=50000, time_budget=None, t_start=None):
    n = len(a_init)
    x = a_init.astype(np.float64).copy()
    x_avg = np.zeros(n)
    best_score = compute_score(x)
    best_a = x.copy()
    deadline = (t_start + time_budget) if (time_budget is not None and t_start is not None) else np.inf

    S_init = x.sum()
    LB = 2.0 * n / (2.0 * n - 1.0)

    for t in range(1, n_steps + 1):
        if time.monotonic() > deadline:
            break

        score, grad, k_star, M, S = subgradient_exact(x)
        if score < best_score:
            best_score = score
            best_a = x.copy()

        gap = score - LB
        gnorm2 = float(grad.dot(grad))
        if gnorm2 < 1e-30:
            break
        step = gap / gnorm2
        step = min(step, 5.0 / (t + 1) ** 0.5)

        x_new = x - step * grad
        x_new = np.clip(x_new, 0.0, 1000.0)

        S_new = x_new.sum()
        if S_new > 1e-12:
            x_new = x_new * (S_init / S_new)

        x_avg += (x_new - x_avg) / t
        x = x_new

        if t % 5000 == 0:
            x_avg_clip = np.clip(x_avg, 0.0, 1000.0)

def spectral_init_gaussian(n, center_frac=0.5, width_frac=0.1):

    M_fft = 1 << (n - 1).bit_length()

    a = np.clip(a, 0.0, None)
    s = a.sum()
    if s > 1e-12:
        a = a / s
    else:
        a = np.ones(n) / n
    return a

        inits.append((f"rand_sm_{ri}", a_rand))

    inits.append(("uniform", np.ones(n) / n))

    # Spectral perturbation of best
    M_fft = 2 * n - 1
    M_fft = 1 << (M_fft - 1).bit_length()
    A = np.fft.rfft(best_a, M_fft)
    amp = np.abs(A) * (1.0 + 0.25 * rng.standard_normal(len(A)))
    amp = np.clip(amp, 0, None)
    phase = np.angle(A) + 0.15 * rng.standard_normal(len(A))
    A_new = amp * np.exp(1j * phase)
    a_pert = np.fft.irfft(A_new, M_fft)[:n]
    a_pert = np.clip(a_pert, 0, None)
    if a_pert.sum() > 1e-12:
        inits.append(("spec_pert", a_pert / a_pert.sum()))

    p2_end = t_start + (time.monotonic() - t_start) + p2
    per_init_time = p2 / (len(inits) + 2)

    for idx, (name, a_init) in enumerate(inits):
        if time.monotonic() > p2_end - 10:
            break
        t_remain = p2_end - time.monotonic()
        time_alloc = min(t_remain * 0.85, per_init_time * 1.4)
        if time_alloc < 12:
            break

        a_init = np.clip(a_init, 0.0, None)
        if a_init.sum() < 1e-12:
            continue

        sc, a_opt = refine_candidate(a_init, time_alloc, t_start)
        try_update(sc, a_opt, f"init:{name}")

    # ==================================================================
    # Phase 3: Intensive optimization of best (20% budget)
    # ==================================================================
    p3 = effective_budget * 0.20
    print(f"\n{'='*60}")
    print(f"Phase 3: Intensive optimization (budget={p3:.0f}s)")
    print(f"{'='*60}")

    p3_end = t_start + (time.monotonic() - t_start) + p3

    if time.monotonic() < p3_end - 20:
        alloc = min(p3_end - time.monotonic(), p3 * 0.35)
        sc, a_opt = run_lbfgs_a(best_a, 50000, maxiter=10000, maxfun=50000,
                                 time_budget=alloc, t_start=t_start)
        try_update(sc, a_opt, "LBFGS_50k")

    if time.monotonic() < p3_end - 10:
        alloc = min(p3_end - time.monotonic(), p3 * 0.35)
        sc, a_opt = coord_descent_exact(best_a, n_sweeps=25, top_k=100,
                                         time_budget=alloc, t_start=t_start)
        try_update(sc, a_opt, "CoordDesc_25sweeps")

    if time.monotonic() < p3_end - 5:
        alloc = min(p3_end - time.monotonic(), p3 * 0.3)
        sc, a_opt = subgradient_method(best_a, n_steps=50000,
                                        time_budget=alloc, t_start=t_start)
        try_update(sc, a_opt, "Subgrad_50k")

    if time.monotonic() < p3_end - 2:
        sc, a_opt = coord_descent_exact(best_a, n_sweeps=10, top_k=60,
                                         time_budget=min(p3_end - time.monotonic(), 30.0),
                                         t_start=t_start)
        try_update(sc, a_opt, "Final_CoordDesc")

    # ==================================================================
    # Phase 4: Try other lengths (5% budget)
    # ==================================================================
    p4 = effective_budget * 0.05
    print(f"\n{'='*60}")
    print(f"Phase 4: Other lengths (budget={p4:.0f}s)")
    print(f"{'='*60}")

    p4_end = t_start + (time.monotonic() - t_start) + p4
    n_best = len(best_a)

    for factor in [1.3, 0.7, 1.6]:
        if time.monotonic() > p4_end - 15:
            break
        tl = int(n_best * factor)
        if tl < 256 or tl > 50000:
            continue
        x_old = np.arange(n_best, dtype=np.float64)
        x_new = np.linspace(0, n_best - 1, tl)
        a_res = np.interp(x_new, x_old, best_a)
        a_res = np.clip(a_res, 0.0, None)
        if a_res.sum() < 1e-12:
            continue
        time_alloc = min(p4_end - time.monotonic() - 5, 30.0)
        if time_alloc < 10:
            continue
        sc, a_opt = refine_candidate(a_res, time_alloc, t_start)
        try_update(sc, a_opt, f"n={tl}")

    # ==================================================================
    # Final verification
    # ==================================================================
    out = [float(max(0.0, min(1000.0, x))) for x in best_a]
    if sum(out) < 0.01:
        out = [0.5] * 64

    verified = float(evaluate_sequence(out))
    elapsed = time.monotonic() - t_start
    print(f"\n{'='*60}")
    print(f"FINAL: internal={best_score:.8f}, verified={verified:.8f}")
    print(f"Length: {len(out)}, Time: {elapsed:.1f}s / {budget_s}s")
    print(f"{'='*60}")
    return out
