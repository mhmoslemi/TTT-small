def compute_convolve_max(a):
    """Compute the maximum of the full convolution of a with itself."""
    conv = np.convolve(a, a)
    return np.max(conv), np.argmax(conv)

def subgradient_step(a, eta, n):
    """One step of projected subgradient descent."""
    conv = np.convolve(a, a)
    m_star = np.argmax(conv)
    # Gradient: g[j] = 2*a[m_star - j] for valid j
    g = np.zeros(n)
    # Valid range: 0 <= m_star - j <= n-1 => m_star-(n-1) <= j <= m_star
    j_lo = max(0, m_star - (n - 1))

    for j in range(j_lo, j_hi + 1):

    a_new = a - eta * g

    a_new = np.maximum(a_new, 0)
    s = np.sum(a_new)
    if s > 0:

    else:

**Mirror descent with negative entropy:**

The update is:
$a_{\text{new}}[j] = \frac{a[j] \exp(-\eta \cdot g_j)}{\sum_k a[k] \exp(-\eta \cdot g_k)}$

where $g_j = 2a[m^* - j]$ is the subgradient.

This is equivalent to:
$a_{\text{new}} \propto a \cdot \exp(-\eta \cdot \text{shift}(a, m^*))$

where "shift" means the appropriate shift/reversal.

For $m^* = n-1$ (center), $\text{shift}(a, n-1)[j] = a[n-1-j]$ (reversed $a$).
So $a_{\text{new}}[j] \propto a[j] \cdot \exp(-\eta \cdot a[n-1-j]) = a[j] \cdot a[n-1-j]^{-\eta \cdot \text{something}}$... not quite.

Actually, it's:
$a_{\text{new}}[j] = \frac{a[j] \exp(-2\eta a[n-1-j])}{\sum_k a[k] \exp(-2\eta a[n-1-k])}$

This downweights positions $j$ where the "partner" $a[n-1-j]$ is large. Intuitively, if position $j$ and position $n-1-j$ both have large values, their product contributes to the center peak, so we downweight both.
