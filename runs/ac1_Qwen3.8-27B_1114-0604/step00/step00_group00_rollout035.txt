This is a significant reduction. It suggests that the optimal sequence has a very specific structure that I haven't identified yet.

Let me think about what kind of sequence could achieve this. The convolution $c[k] = \sum_j a_j a_{k-j}$ is a sum of products. To minimize the maximum, we want the products to "cancel out" at every position. But since all $a_j \geq 0$, there's no cancellation - all terms are positive. So the sum is always positive and the peak is where the most (largest) terms contribute.

The only way to reduce the peak is to make the sequence "spread out" in a way that no single lag collects too many large products. This is similar to the problem of minimizing the peak of a sum of shifted copies of a function.

One idea: use a sequence that's "spread out" in frequency domain. If $\hat{a}(\omega)$ is the DFT of $a$, then $\hat{c}(\omega) = |\hat{a}(\omega)|^2$. A flat $|\hat{a}(\omega)|^2$ (i.e.,flat $|\hat{a}(\omega)|$) would give a flat $c$ (in the circular case). For the linear case, it's more complex, but the idea is similar.

A sequence with flat magnitude spectrum is called a "perfect" sequence. For real non-negative sequences, this is very restrictive. But we can approximate it.

Another idea: use a "low-PAPR" sequence. Low-PAPR sequences are designed to have a low peak-to-average power ratio in their squared magnitude (which is related to the autocorrelation). This is a well-studied problem in communications.

The Golay complement / Barker sequence approach: find a sequence whose autocorrelation has a small peak. For non-negative real sequences, this is harder because we can't use negative values.

I think the LP-based iterative method is the most practical approach for this problem. Let me implement it carefully.

"""
LP-based iterative optimization for minimizing 2n*max(a*a)/sum(a)^2.
Uses the "water-filling" LP to find descent directions, combined with
multiple starting points and sequence lengths.
"""

import numpy as np
import time
from scipy.optimize import linprog
from scipy.sparse import csr_matrix

def build_conv_matrix(n, f):
    """Build the (2n-1) x n sparse convolution constraint matrix.
    A[k, i] = f[k-i] if 0 <= k-i <= n-1 else 0."""
    lens = np.minimum(n, 2*n - 1 - np.arange(n))
    total = int(lens.sum())
    cols = np.repeat(np.arange(n, dtype=np.int32), lens)
    cumsum = np.concatenate([[0], np.cumsum(lens)[:-1]])
    offsets = np.arange(total, dtype=np.int32) - cumsum[np.repeat(np.arange(n), lens)]
    rows = cols + offsets
    data = f[offsets]
    return csr_matrix((data, (rows, cols)), shape=(2*n - 1, n))

def run_lp_iteration(a, M):
    """Solve the LP: max sum(b) s.t. b >= 0, (a*b)_k <= M for all k."""
    n = len(a)
    A = build_conv_matrix(n, a)
    c_obj = -np.ones(n)
    b_ub = np.full(2*n - 1, M)
    bounds = [(0, None)] * n
    res = linprog(c_obj, A_ub=A, b_ub=b_ub, bounds=bounds, method='highs')
    if res.status != 0:
        return None
    return np.maximum(res.x, 0.0)

def evaluate_seq(a):
    """Compute the objective value for a numpy array."""
    S = float(np.sum(a))
    if S < 0.01:
        return float('inf')
    c = np.convolve(a, a)
    M = float(np.max(c))
    return 2.0 * len(a) * M / (S * S)

def propose_candidate(seed=42, budget_s=2400, **kwargs):

    deadline = time.monotonic() + max(0.0, budget_s - 5.0)

        nonlocal best_a, best_score
        score = evaluate_seq(a)
        if score < best_score:
            best_score = score
            best_a = a.copy()
        return score
    
    # Try different sequence lengths and initial patterns

        init_patterns.append(('alt2', a_alt2.copy()))
        
        # Smooth cosine
        t = np.arange(n)
        for P in [4, 8, 16, 32]:

            a_cos = np.maximum(a_cos, 0.01)
