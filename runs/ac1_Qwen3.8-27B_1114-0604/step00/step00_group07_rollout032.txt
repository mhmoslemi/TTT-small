```python
from scipy.optimize import linprog
from scipy.sparse import csr_matrix

def solve_lp_direction(a, M):
    """Solve: maximize sum(g) s.t. (a*g)_j <= M, g >= 0."""
    n = len(a)
    # Build constraint matrix A such that A @ g <= M * ones(2n-1)
    # Row j: sum_k a_k * g_{j-k} (for valid k, j-k)
    # This is a Toeplitz-like matrix
    
    # Build the matrix
    rows = []
    cols = []
    vals = []
    for j in range(2 * n - 1):
        for k in range(n):
            idx = j - k  # index of g
            if 0 <= idx < n:
                rows.append(j)
                cols.append(idx)
                vals.append(a[k])
    
    A = csr_matrix((vals, (rows, cols)), shape=(2*n-1, n))
    b_vec = np.full(2*n-1, M)
    c = -np.ones(n)  # Minimize -sum(g) = maximize sum(g)
    
    res = linprog(c, A_ub=A, b_ub=b_vec, bounds=[(0, None)] * n, method='highs')
    return res.x
```

Actually, for periodic autocorrelation, the condition is that the power spectrum is flat, which means `|f̂(k)|^2` is constant for all frequencies `k`. For a real, non-negative function, this means `f` has all frequencies present with equal amplitude. The simplest such function is a white noise-like function, but for a deterministic function, we can use a (truncated) chirp or a (truncated) m-sequence.

But for APERIODIC autocorrelation, the condition is different. We want `∫_0^{1-t} f(x) f(x+t) dx` to be constant for `t ∈ [0,1]`. This is a much stronger condition.

For `f = 1` (constant), the aperiodic autocorrelation is `1-t`, which is not flat.
For `f = x` (ramp), the aperiodic autocorrelation is `∫_0^{1-t} x(x+t) dx = ∫_0^{1-t} (x^2 + tx) dx = (1-t)^3/3 + t(1-t)^2/2 = (1-t)^2(1-t)/3 + t(1-t)^2/2 = (1-t)^2[(1-t)/3 + t/2] = (1-t)^2(3+2t)/6`. This decreases with `t`, so it's not flat either.
