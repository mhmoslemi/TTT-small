**Alternative: Subgradient method with projection**

The objective is $F(a) = \frac{2n \cdot \max_k b_k}{S^2}$ where $S = \sum a$. Since it's scale-invariant, fix $S = \sqrt{2n}$ and minimize $\max_k b_k$.

- If the max is achieved at a unique $k^*$: $\frac{\partial b_{k^*}}{\partial a_i} = 2 a_{k^*-i}$ (if $k^*$ valid) or $2a_i$ (if $k^* = 2i$).
- If the max is achieved at multiple $k$ values: any convex combination of the subgradients.

So a subgradient descent step would be:
1. Find $k^* = \arg\max b_k$.
2. Compute the subgradient: $g_i = 2 a_{k^*-i}$ (or $2a_i$ if $k^* = 2i$) for each $i$.
3. Update: $a \leftarrow \text{project}(a - \eta \cdot g)$ where project means projecting onto the simplex $\{a \geq 0, \sum a = \text{const}\}$.

This is much faster: $O(n)$ per step (for the subgradient computation) plus $O(n \log n)$ for the projection (or $O(n)$ with a sorting-based projection).

The projection onto the simplex $\{a \geq 0, \sum a = S\}$ can be done in $O(n \log n)$ using a sorting algorithm, or approximately in $O(n)$ using the fact that the projection has a specific structure.

```python
def project_simplex(v, S):
    """Project v onto {a >= 0, sum(a) = S}."""
    n = len(v)
    # The projection is: a_i = max(v_i - tau, 0) where tau is chosen so that sum(a) = S
    # This is equivalent to finding tau such that sum(max(v_i - tau, 0)) = S
    
    # Sort v in decreasing order
    sorted_v = np.sort(v)[::-1]
    # Find the largest rho such that sum_{i=1}^{rho} (sorted_v[i-1] - tau) = S
    # where tau = (sum_{i=1}^{rho} sorted_v[i-1] - S) / rho
    
    cumsum = np.cumsum(sorted_v)
    # For each possible rho (1 to n), check if sorted_v[rho-1] > (cumsum[rho-1] - S) / rho >= sorted_v[rho] (if rho < n)
    rho = np.arange(1, n+1)
    tau = (cumsum - S) / rho
    # Conditions: sorted_v[rho-1] > tau and (if rho < n) sorted_v[rho] <= tau
    # i.e., sorted_v[rho-1] > (cumsum[rho-1] - S) / rho
    # and sorted_v[rho] <= (cumsum[rho-1] - S) / rho (for rho < n)
    
    # Actually, the standard algorithm is:
    # 1. Sort v in decreasing order.
    # 2. Find the largest rho in {1, ..., n} such that sorted_v[rho-1] > (sum_{i=1}^{rho} sorted_v[i-1] - S) / rho.
    # 3. Set tau = (sum_{i=1}^{rho} sorted_v[i-1] - S) / rho.
    # 4. a_i = max(v_i - tau, 0).
    
    # Condition: sorted_v[rho-1] > (cumsum[rho-1] - S) / rho
    # i.e., rho * sorted_v[rho-1] > cumsum[rho-1] - S
    # i.e., rho * sorted_v[rho-1] + S > cumsum[rho-1]
    
    condition = rho * sorted_v + S > cumsum
    # Also need tau >= -max(v) or something to ensure non-negativity... actually the max(v_i - tau, 0) handles it.
    # But we also need tau to be such that sum(max(v_i - tau, 0)) = S.
    
    valid_rho = np.where(condition)[0]
    if len(valid_rho) == 0:
        rho_val = 1
    else:
        rho_val = valid_rho[-1] + 1  # 1-indexed
    
    tau_val = (cumsum[rho_val - 1] - S) / rho_val
    result = np.maximum(v - tau_val, 0.0)
    
    # Numerical fix
    diff = S - np.sum(result)
    if abs(diff) > 1e-10:
        result += diff / n  # rough correction
        result = np.maximum(result, 0.0)
    
    return result
```

To get below 2, we need $m > \sqrt{n}$, which means the set is NOT a perfect Sidon set (some differences repeat). But we want to minimize the maximum repetition.

So the problem becomes: find a set $A \subseteq \{0, \ldots, n-1\}$ of size $m$ that minimizes $\frac{2n \cdot \lambda}{m^2}$ where $\lambda = \max_k |A \cap (k-A)|$.

We want $\frac{2n\lambda}{m^2} < 2$, i.e., $\lambda < m^2/n$.

For a random set of size $m$, the expected value of $|A \cap (k-A)|$ is $m^2/n$ (for $k \neq 0$). The maximum over $k$ of $|A \cap (k-A)|$ is approximately $m^2/n + O(m/\sqrt{n})$ (by concentration inequalities). So for large $m$, the max is close to the mean, and the objective is close to 2.

To get significantly below 2, we need $\lambda$ to be significantly below $m^2/n$. This means the set should be "more Sidon-like" than a random set.

But from the above, the best we can do with exact Sidon sets is $\lambda = 1$ and $m \approx \sqrt{n}$, giving objective $\approx 2$.

So we need a "relaxed Sidon" set: a set of size $m > \sqrt{n}$ with $\lambda$ small but > 1.

For example, if $m = c\sqrt{n}$ for $c > 1$, then the mean of $|A \cap (k-A)|$ is $\frac{m^2}{n} = c^2$. We want $\lambda < c^2$ (to get objective < 2). For a random set, $\lambda \approx c^2 + O(c/\sqrt{n} \cdot \sqrt{c^2}) = c^2 + O(c^{3/2}/\sqrt{n})$, which is close to $c^2$. So the objective is $\approx 2n \cdot c^2 / (c^2 n) = 2$.

The general problem is: minimize $\frac{2n \max_k b_k}{S^2}$ over $a \geq 0$, $a \neq 0$.

For a general non-negative sequence (not just 0-1), the analysis is more complex. The key is that we can use different weights to "shape" the autocorrelation.

Let me think about this differently. The objective is scale-invariant, so fix $S = 1$ (i.e., $a$ is a probability distribution on $\{0, \ldots, n-1\}$). Then the objective is $2n \cdot \max_k b_k$ where $b = a * a$.

We want to minimize $\max_k b_k$. The sum of all $b_k$ is 1 (since $S = 1$), and there are $2n-1$ values. So the average is $\frac{1}{2n-1} \approx \frac{1}{2n}$. The minimum possible max is at least $\frac{1}{2n-1}$, giving a lower bound on the objective of $\frac{2n}{2n-1} \approx 1$.

But achieving this would require $b_k$ to be exactly uniform, which is impossible for a finite sequence.

For a "good" sequence, we'd like $b_k \approx \frac{1}{2n}$ for all $k$, with small deviations. The optimal $\max_k b_k$ is approximately $\frac{1}{2n} + \epsilon$, and the objective is approximately $1 + 2n\epsilon$.

So the question is: how small can $\epsilon$ be?

For a random probability distribution (e.g., $a_i = \text{Beta}(\alpha, \beta)$ normalized), the $b_k$ values are concentrated around $\frac{1}{2n}$ with standard deviation approximately $\frac{1}{2n\sqrt{n}}$ (rough estimate). So $\epsilon \approx \frac{1}{2n\sqrt{n}} \cdot \sqrt{\log n}$ (max of $2n$ Gaussian-like variables). The objective would be $\approx 1 + \frac{\sqrt{\log n}}{\sqrt{n}}$, which for $n = 6121$ is $\approx 1 + \frac{4.1}{78} \approx 1.05$. That's great!
