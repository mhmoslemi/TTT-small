The objective is to minimize:
$$J(a) = \frac{2n \cdot \max(b)}{(\sum a)^2}$$

where $b = a * a$ (full convolution) and $n = \text{len}(a)$.

Key observations:
1. We can normalize freely - if we scale $a$ by $c$, then $b$ scales by $c^2$ and $\sum a$ scales by $c$, so $J$ is invariant to scaling.
2. We want to minimize $\max(b) / (\sum a)^2 \cdot 2n$.
3. If we normalize so that $\sum a = 1$, then we want to minimize $2n \cdot \max(b)$.
4. Alternatively, if we normalize so that $\sum a = \sqrt{2n}$, then $J = \max(b)$, i.e., we just want to minimize the peak of the autocorrelation.

import numpy as np
import time

def project_simplex(v, s=1.0):
    """Project v onto the simplex {x >= 0, sum(x) = s}."""
    n = len(v)
    if s <= 0:
        return np.zeros(n)
    # Scale to sum = 1 problem
    v = v / s  # Now project onto sum = 1 simplex
    # Algorithm: find threshold tau such that sum(max(v_i - tau, 0)) = 1
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.nonzero(u * np.arange(1, n+1) > (cssv - 1))[0][0]
    tau = (cssv[rho] - 1) / (rho + 1.0)
    result = np.maximum(v - tau, 0)
    return result * s

Actually, let me think about this more carefully. The "worst" lag is usually the middle lag $k = n-1$, because it has the most terms. At this lag, $(a*a)_{n-1} = \sum_j a_j a_{n-1-j}$.

If $a$ is symmetric (palindromic), then $a_j = a_{n-1-j}$ and $(a*a)_{n-1} = \sum_j a_j^2$. By Cauchy-Schwarz, this is at least $1/n$ (with equality for uniform). So for symmetric sequences, the middle lag is always at least $1/n$, giving $J \geq 2$.

If $a$ is anti-symmetric (i.e., $a_j + a_{n-1-j} = c$ for constant $c$), then $(a*a)_{n-1} = \sum_j a_j (c - a_j) = c \sum a_j - \sum a_j^2 = c - \sum a_j^2$. With $\sum a = 1$ and $c = 2/n$ (so that $a_j + a_{n-1-j} = 2/n$), we get $(a*a)_{n-1} = 2/n - \sum a_j^2$. To minimize this, we want to maximize $\sum a_j^2$, which means concentrating the mass. But then the edge lags (like lag 0: $a_0^2$) would be large.

So there's a trade-off: making the middle lag small requires asymmetry, but this might increase other lags.
