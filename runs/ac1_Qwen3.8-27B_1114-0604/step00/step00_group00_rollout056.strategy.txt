Instead of gradient-based methods or simple uniform distributions, we focus on structured candidates that minimize the maximum autocorrelation spike. The key idea is to trade discrete structure (which reduces the peak convolution) with continuous optimization of coefficients. We found that comb-like structures with appropriate spacing between active elements significantly reduce the objective by isolating significant energy contributions in non-overlapping regions.

The main bottleneck addressed is the overly smooth structure of the initial parent sequence. By considering comb filter candidates with controlled phase and amplitude, we target several orders of magnitude lower objective values. Specifically, we consider sequences with active values spaced apart to avoid overlap in autocorrelation, which keeps the maximum values low while allowing the sum to be significantly increased relative to the peak.

2. Mathematical specification
The problem: Minimize 2*n*max(convolve(a,a)[k] for k from 0 to 2*n-2)/sum(a)^2 given a_i in [0,1000].

Main constraints:
- Active elements are spaced at least a factor of `p` apart (with `p` being the phase) to avoid autocorrelation overlap.
- Each active segment has a base amplitude `b` and optional exponential decay.

Periodicity and phase spacing: Every `p` elements, only one is active. This creates a sparse structure that controls the autocorrelation peaks.

We define:
- `T`: sequence length (which we optimize, default 256)
- `p`: phase spacing (defaults to 4, but optimized via schedule)
- `a`: coefficients (must be nonnegative, bounded)
- `sum_a = S >= 0.01`
- `convolve(a,a)`: full convolution of length 2*T-1

The objective becomes:
`objective = (2*T * max_conv) / (S)^2`

We balance two competing interests:
1. Low autocorrelation maximum (√(max_conv) should be spread to minimize relative peak)
2. High sum to offset peak energy

3. Implementation procedure
We generate candidates by combining a base periodic comb structure with randomized exponential variations and optimized decay. The structure is defined by three hyperparameters:
1. Base frequency `f` (for the comb filter)
2. Maximum active value `M_a` (not fixed at 1000)
3. Decay factors `d` (for each active segment)

Steps:
a. Parent validation and initialization:
   - Start from the provided `height_sequence_1` or use a random uniform sequence (fallback)
   - Normalize sum to at least 0.01 (if too low, repair by scaling)

b. Core comb search:
   i. Define a comb filter with spacing `p` (extract phase-separated indices)
   ii. For each candidate position, generate an amplitude distribution that mitigates autocorrelation peaks
   iii. Add exponential decay factors (varying amplitude) to enhance sum/score ratio
   iv. For each candidate, compute the full convolution and sum
   v. Solve smallest eigencandidate
