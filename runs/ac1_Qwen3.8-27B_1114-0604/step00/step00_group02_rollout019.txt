    """Project x onto {y >= 0, sum(y) = S} using sorting-based method."""

OK so it's not easy to beat uniform for small n. But for n=2, we could (score 16/9 < 2). And the target for n=6962 is 1.5027, which is much less than 2.

Let me think about what's different for large n. For large n, the convolution has 2n-1 ≈ 2n values, and the "average" value is 1/(2n-1) ≈ 1/(2n). The uniform sequence has max = 1/n = 2/(2n), which is twice the average. So the "peak-to-average ratio" for uniform is 2.

If we can make the convolution more uniform (closer to the average), we can get a lower score. The theoretical minimum score is 1 (when all C(k) are equal to the average 1/(2n)).

For large n, the key is to make the convolution as flat as possible. This is related to the "flat autocorrelation" problem.

One approach is to use **Golay complementary sequences** or **Barker sequences**, but those are for ±1 sequences, not nonnegative real sequences.

For nonnegative real sequences, the problem is different. Let me think about it from a Fourier perspective.

The DFT of the convolution is the square of the DFT: DFT(C) = |DFT(f)|^2.

So maximizing the minimum of C is equivalent to making |DFT(f)|^2 as uniform as possible, i.e., making DFT(f) have constant magnitude (a "flat spectrum" or "white noise" sequence).

But we also need f >= 0, which is a constraint on the time-domain signal.

So the problem is: find a nonnegative sequence f with sum S whose DFT has as flat a magnitude spectrum as possible.

This is related to the "minimum magnitude spectrum" problem and has connections to zippered synthesis and other techniques.

One approach: start with a random phase DFT (which gives a flat spectrum), take the inverse DFT, and then project onto the nonnegative cone (iteratively, like in the "alternating projections" or "Gerchberg-Saxton" algorithm).

**Gerchberg-Saxton / Hybrid Input-Output (HIO) algorithm adapted:**
1. Start with a random f >= 0, sum = S
2. Compute F = DFT(f)
3. Set |F| to a target value (e.g., constant = S/sqrt(n))
4. Compute f' = IDFT(F)
5. Replace f' with max(f', 0) and normalize to sum S
6. Repeat

This might converge to a good solution! The key insight is that a flat power spectrum corresponds to a flat autocorrelation (by Wiener-Khinchin), which gives a low peak in the convolution.

Wait, but the DFT of the full (linear) convolution is not exactly |DFT(f)|^2. That's only for circular convolution. For linear convolution, the relationship is more complex.

However, if we zero-pad f to length 2n (or more), the circular convolution of the zero-padded sequence equals the linear convolution. So:
- Zero-pad f to length 2n: f_padded = [f, 0, 0, ..., 0] (length 2n)
- Circular convolution of f_padded with itself = linear convolution of f with f (for the first 2n-1 samples)
- DFT of circular convolution = |DFT(f_padded)|^2

So if we want the linear convolution of f with itself to be flat, we want |DFT(f_padded)|^2 to be flat, i.e., |DFT(f_padded)| to be constant.

DFT(f_padded) = DFT of [f, 0, ..., 0] (length 2n) = DFT_{2n}(f) (the 2n-point DFT of f zero-padded to 2n).

So the problem becomes: find f >= 0, sum f = S, such that |DFT_{2n}(f)| is as constant as possible.

This is a "phase retrieval" type problem: we want to find a nonnegative f whose 2n-point DFT has constant magnitude.

The Gerchberg-Saxton algorithm for this:
1. Initialize f >= 0, sum f = S
2. Compute F = DFT_{2n}(f) (zero-padded to 2n)
3. Set |F| = S/sqrt(2n) (constant magnitude, since |F(0)| = sum f = S, and for a flat spectrum, all magnitudes should be S/sqrt(2n)... wait, that's not right)

Actually, for a flat power spectrum: |F(k)|^2 = S^2/(2n) for all k. So |F(k)| = S/sqrt(2n) for all k.

But F(0) = sum f = S, so |F(0)| = S. This is much larger than S/sqrt(2n) for large n. So we can't have a truly flat spectrum including DC.

The best we can do is to have |F(k)| as equal as possible for k = 1, ..., 2n-1 (excluding DC), with |F(0)| = S fixed.

By Parseval: sum_k |F(k)|^2 = (2n) * sum_i f_padded[i]^2 = (2n) * sum_i f[i]^2 (since the rest are zero).

So sum_k |F(k)|^2 = 2n * ||f||^2.

If |F(k)| = c for k = 1, ..., 2n-1, then:
S^2 + (2n-1)*c^2 = 2n * ||f||^2

By Cauchy-Schwarz: ||f||^2 >= S^2/n, so:
S^2 + (2n-1)*c^2 >= 2n * S^2/n = 2S^2
(2n-1)*c^2 >= S^2
c >= S/sqrt(2n-1)

So the minimum constant magnitude (for non-DC) is at least S/sqrt(2n-1), achieved when f is uniform (||f||^2 = S^2/n).
