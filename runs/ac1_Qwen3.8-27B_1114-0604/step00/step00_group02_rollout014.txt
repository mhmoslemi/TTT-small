**Alternative approach: Use the LP-based method from the state-of-the-art, but with a twist.**

The idea:
1. Start with a sequence `a` (normalized to have sum S).
2. Compute `c = convolve(a, a)` and find `M = max(c)`.
3. Identify the "active" set: indices `k` where `c[k] >= M - delta` for some small `delta`.
4. Solve an LP: find `d` that maximizes `sum d` (or minimizes some proxy) subject to:
   - `sum d = 0` (maintain normalization)
   - `a[i] + d[i] >= 0` for all `i` (non-negativity, for small steps)
   - `sum_j a[j] * d[k-j] <= 0` for active `k` (don't increase active constraints to first order)
5. Update: `a <- (a + t * d) / sum(a + t*d) * S` for small `t`.
6. Repeat.

The LP in step 4 has `n` variables (`d[0], ..., d[n-1]`) and `O(n)` constraints. For `n = 10000`, this is a large LP but solvable with modern solvers.

However, the constraint `sum_j a[j] * d[k-j] <= 0` is linear in `d` (since `a` is fixed), so the LP is well-defined.

The objective could be to minimize the weighted sum of the active constraints, or to maximize a "spread" metric.

But since we're constraining `(a*d)[k] <= 0` for active `k`, the objective would typically be 0 at the optimum unless there's a trade-off.
