Actually, let me think about this problem from the perspective of the Fourier transform.

The linear convolution c = a * a (length 2n-1) has DFT (with zero-padding to length 2n-1 or longer):
C[k] = |A[k]|^2 where A is the DFT of the zero-padded a.

By the inversion formula:
c[m] = (1/L) * sum_k C[k] * exp(2*pi*i*m*k/L) = (1/L) * sum_k |A[k]|^2 * exp(2*pi*i*m*k/L)

where L is the DFT length (>= 2n-1).

The max of c is at most sum_k |A[k]|^2 / L = (n/L) * sum_j a[j]^2 (by Parseval for the zero-padded sequence, sum_k |A[k]|^2 = L * sum_j a[j]^2... wait, let me be careful with normalization).

With the DFT defined as A[k] = sum_j a[j] * exp(-2*pi*i*j*k/L), Parseval says sum_k |A[k]|^2 = L * sum_j a[j]^2.

So c[m] = (1/L) * sum_k |A[k]|^2 * exp(2*pi*i*m*k/L)

And max_m c[m] <= (1/L) * sum_k |A[k]|^2 = sum_j a[j]^2.

So M <= sum(a[j]^2), which is what we already knew.

To make M small, we want the |A[k]|^2 to be as "flat" as possible (so that the inverse DFT doesn't have large peaks). This is related to the concept of "low PAPR" sequences.

But we also have the constraint that a[j] >= 0, which constrains the possible DFTs.

For a nonnegative sequence, A[0] = sum a[j] = S (the total sum). This is the DC component and is always the largest in magnitude (since all terms are nonnegative, A[0] = sum a[j] >= |A[k]| for all k).

So |A[0]|^2 = S^2 dominates. The contribution to c[m] from k=0 alone is S^2/L for all m. So c[m] >= S^2/L for all m (approximately, for large L).

Actually, c[m] = (1/L) * sum_k |A[k]|^2 * exp(2*pi*i*m*k/L)
>= (1/L) * |A[0]|^2 * 1 = S^2/L (this is a lower bound, since the other terms could be negative)

But the maximum is at most (1/L) * sum_k |A[k]|^2 = sum a[j]^2.

For the uniform sequence, A[0] = n (if a = [1,...,1]), A[k] = 0 for k != 0. So c[m] = n^2/L for all m... but that's the circular convolution. For the linear convolution with L = 2n-1, it's not exactly this.

    n = len(a)

    # Use next power of 2 for efficiency
    fft_size = 1
    while fft_size < size:
        fft_size *= 2
    A = np.fft.rfft(a, fft_size)
    C = A * A
    c = np.fft.irfft(C, fft_size)[:size]
