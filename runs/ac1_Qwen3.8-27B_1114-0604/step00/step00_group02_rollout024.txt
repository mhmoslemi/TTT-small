```python
def solve_lp_for_direction(a, M):
    n = len(a)
    # Build the constraint matrix T where T[k, i] = a[k-i] if 0 <= k-i < n, else 0
    # This is a Toeplitz matrix
    # The constraint is T @ g <= M * ones(2n-1)
    
    # For efficiency, we can solve the dual:
    # minimize M * sum(lambda)
    # subject to: T^T @ lambda >= ones(n)
    #             lambda >= 0
    
    # T^T @ lambda >= 1 means: for each i, sum_k T[k,i] * lambda[k] >= 1
    # T[k,i] = a[k-i] if 0 <= k-i < n
    # So: sum_k a[k-i] * lambda[k] >= 1 for each i
    # Let j = k-i: sum_j a[j] * lambda[j+i] >= 1
    # This is: (a * lambda)[i] >= 1 for each i (where lambda is padded)
    
    # The dual has 2n-1 variables (lambda[0], ..., lambda[2n-2]) and n constraints.
    # For n=500, that's 999 variables and 500 constraints. Manageable.
    
    # Actually, let's just solve the primal directly with linprog.
    # Primal: max 1^T g s.t. T g <= M*1, g >= 0
    # In linprog form: min -1^T g s.t. T g <= M*1, -g <= 0
    # c = -ones(n)
    # A_ub = [T; -I] (shape (3n-1, n))
    # b_ub = [M*ones(2n-1); zeros(n)]
    
    # This is a (3n-1) × n matrix, which for n=500 is 1499 × 500. OK.
    
    # Build T (Toeplitz matrix)
    # T[k, i] = a[k-i] if 0 <= k-i < n, else 0
    # This is the "convolution matrix" of a
    col = a  # T[k, i] depends on k-i, so the first column is a[0], a[1], ..., a[n-1], 0, ..., 0
    # Actually, T is upper-toeplitz with first column [a[0], a[1], ..., a[n-1], 0, ..., 0]^T
    # Wait, T[k, i] = a[k-i] for 0 <= k-i < n.
    # For fixed i, as k varies: T[0,i] = a[-i] = 0 (if i>0), T[i,i] = a[0], T[i+1,i] = a[1], ..., T[i+n-1,i] = a[n-1]
    # So the i-th column has a[0] at row i, a[1] at row i+1, etc.
    # The first column (i=0) is [a[0], a[1], ..., a[n-1], 0, ..., 0]^T (length 2n-1)
    
    # Using scipy.linalg.toeplitz:
    # toeplitz(col, row) creates a matrix where the first column is col and the first row is row.
    # We want T[k,i] = a[k-i] for 0 <= k-i < n.
    # First column (i=0): [a[0], a[1], ..., a[n-1], 0, ..., 0]^T (2n-1 elements)
    # First row (k=0): [a[0], 0, 0, ..., 0] (n elements)
    
    col = np.zeros(2*n-1)
    col[:n] = a
    row = np.zeros(n)
    row[0] = a[0]
    T = scipy.linalg.toeplitz(col, row)
    
    # Solve LP
    c = -np.ones(n)
    A_ub = np.vstack([T, -np.eye(n)])
    b_ub = np.concatenate([M * np.ones(2*n-1), np.zeros(n)])
    
    result = linprog(c, A_ub=A_ub, b_ub=b_ub, method='highs')
    if result.success:
        return -result.fun, result.x  # (sum(g), g)
    else:
        return None
```

Wait, I need to be careful with the Toeplitz matrix construction. Let me verify:

T[k, i] should equal a[k-i] if 0 <= k-i <= n-1, and 0 otherwise.

For the first column (i=0): T[k, 0] = a[k] if 0 <= k < n, else 0.
So col = [a[0], a[1], ..., a[n-1], 0, 0, ..., 0]^T (length 2n-1). ✓

For the first row (k=0): T[0, i] = a[-i] if 0 <= -i < n, else 0. Since -i < 0 for i > 0, T[0, i] = 0 for i > 0. And T[0,0] = a[0].
So row = [a[0], 0, 0, ..., 0] (length n). ✓

Great, the Toeplitz construction is correct.

Now, for the LP to be useful, the optimal g should have sum(g) > 1 (since a is feasible with sum = 1). If sum(g) = 1, the iteration doesn't change a.

Actually, I realize there might be a numerical issue. If a is very close to uniform, the LP might give sum(g) very close to 1, and the improvement per iteration would be tiny.

Let me think about an alternative: instead of the LP, use a "mirror descent" or "multiplicative weight" update.

The multiplicative weight update for this problem would be:
g[i] = a[i] * exp(-η * (a*a)[k*(i)])

where k*(i) is the lag that's "responsible" for position i contributing to the peak. This is a heuristic.

Actually, a simpler approach: use the "gradient" of the objective in the log-domain:
g[i] = a[i] * exp(-η * sg[i])

where sg[i] = a[k*-i] + a[i-k*] (the subgradient at position i).

This is a "mirror descent" step with the KL divergence as the Bregman divergence. It naturally preserves non-negativity.

Let me combine all these ideas into a comprehensive algorithm:

1. Generate diverse initializations
2. For the best initialization, apply:
   a. Mirror descent (gradient-based, in log-space)
   b. LP-based update
   c. Local search (block perturbations)
3. Return the best found

Let me also think about the choice of n. The score is 2n * max_b / S^2. For a given "shape" (normalized to sum=1), the score is 2n * max_b. If I have a shape that gives max_b = c/n (i.e., the convolution is proportional to 1/n), then score = 2c. To get score < 2, I need c < 1.

For the uniform sequence, max_b = 1/n (with sum=1), so c = 1 and score = 2.

For a "flat convolution" sequence, max_b ≈ 1/(2n-1), so c ≈ n/(2n-1) < 1, and score ≈ 2n/(2n-1) < 2.
