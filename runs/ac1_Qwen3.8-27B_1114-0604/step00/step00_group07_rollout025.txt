def objective_and_subgrad(a):
    """Compute objective and subgradient wrt a (assuming sum(a)=1)."""
    n = len(a)
    c = np.convolve(a, a)
    max_c = np.max(c)
    obj = 2 * n * max_c  # since sum(a) = 1
    # Subgradient: for k* = argmax(c), subgrad[j] = 2*a[k*-j] if 0 <= k*-j < n
    k_star = np.argmax(c)
    subgrad = np.zeros(n)
    # subgrad[j] = 2*a[k_star - j] if 0 <= k_star - j < n
    lo = max(0, k_star - (n-1))
    hi = min(n-1, k_star)
    for j in range(lo, hi+1):
        subgrad[j] = 2 * a[k_star - j]
    return obj, subgrad

    n = len(f)
    for _ in range(max_iter):
        # Build constraint matrix with only active_k constraints
        rows = []
        cols = []
        vals = []

**Alternative: Use the analytical structure of the LP.**

The LP is: max sum(g) s.t. (f*g)[k] <= M for all k, g >= 0.

By complementary slackness, at the optimum, either g[j] = 0 or (f^T g at position j) = M. Wait, that's not quite right. Let me think about the KKT conditions.

The LP in standard form:
max 1^T g
s.t. A g <= b (where b = M * 1)
     g >= 0

KKT conditions:
- Primal feasibility: Ag <= b, g >= 0
- Dual feasibility: y >= 0 (dual variables for Ag <= b), A^T y + s = 1 (s >= 0 are dual variables for g >= 0)
- Complementary slackness: y[k] * (b[k] - (Ag)[k]) = 0 for all k, g[j] * s[j] = 0 for all j

From complementary slackness:
- For each k: either y[k] = 0 or (Ag)[k] = M
- For each j: either g[j] = 0 or s[j] = 0, i.e., (A^T y)[j] = 1

So at the optimum, for each j with g[j] > 0, we have (A^T y)[j] = 1. And for each k with y[k] > 0, we have (Ag)[k] = M.

This means the solution is determined by:
1. The set of j with g[j] > 0 (call it J)
2. The set of k with y[k] > 0 (call it K)

And the system is:
- For j in J: sum_{k in K} A[k,j] * y[k] = 1
- For k in K: sum_{j in J} A[k,j] * g[j] = M

If |J| = |K|, this is a square system that can be solved directly.

This is the basis of the **active set method** for LPs. The SOTA description mentions "the optimum is attained at an extreme point determined by an active set of binding inequalities."

So the algorithm would be:
1. Start with a guess for the active sets J and K
2. Solve the resulting linear system
3. Check KKT conditions
4. Adjust the active sets
5. Repeat

This is essentially the simplex method or an interior point method applied to this specific LP.
