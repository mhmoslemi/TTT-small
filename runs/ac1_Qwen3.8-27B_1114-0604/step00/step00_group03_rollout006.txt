The projection onto the probability simplex can be done efficiently using the algorithm from Duchi et al. (2012):

```
def project_simplex(v):
    # Project v onto {x >= 0, sum(x) = 1}
    n = len(v)
    if np.sum(v) <= 1:
        # Already in the simplex (if all non-negative)
        return v / np.sum(v) if np.sum(v) > 0 else np.ones(n)/n
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.nonzero(u * np.arange(1, n+1) > (cssv - 1))[0][-1]
    theta = (cssv[rho] - 1) / (rho + 1.0)
    return np.maximum(v - theta, 0)
```

The gradient with respect to $x$ is:
$\frac{\partial L}{\partial x_m} = \sum_j \frac{\partial L}{\partial a_j} \frac{\partial a_j}{\partial x_m}$

where $\frac{\partial a_j}{\partial x_m} = a_j(\delta_{jm} - a_m)$ (the Jacobian of the softmax).

So $\frac{\partial L}{\partial x_m} = \sum_j \frac{\partial L}{\partial a_j} a_j (\delta_{jm} - a_m) = a_m \frac{\partial L}{\partial a_m} - a_m \sum_j \frac{\partial L}{\partial a_j} a_j$

This is a standard result. Let $G_j = \frac{\partial L}{\partial a_j}$ (the gradient w.r.t. $a$). Then:
$\frac{\partial L}{\partial x_m} = a_m (G_m - \sum_j G_j a_j)$

This is simple to compute.

Let me use this approach: optimize over $x$ using L-BFGS, with $a = \text{softmax}(x)$.

The objective function is $L(x) = 2n \cdot \text{soft\_max}(\tau, \text{convolve}(\text{softmax}(x), \text{softmax}(x)))$.
