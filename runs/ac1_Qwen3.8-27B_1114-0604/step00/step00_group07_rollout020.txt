**Practical approach: Gradient-based with smoothing**

Since max(c) is non-smooth, I'll use a smoothed approximation:
smoothed_max(c) = (1/alpha) * log(sum(exp(alpha * c)))

For large alpha, this approximates max. The gradient is:
∇_f smoothed_max = (f*f) weighted by softmax(alpha * c)

So: ∇_f smoothed_max[i] = sum_k softmax(alpha*c)[k] * ∂(f*f)[k]/∂f[i]
= sum_k softmax(alpha*c)[k] * f[k-i] (for valid k-i)

This is like a "weighted" convolution where the weights are the softmax of the convolution values.

Then we do gradient descent on E(f) = 2n * smoothed_max(c) / S^2.

∇E = (2n/S^2) * ∇smoothed_max - (4n * smoothed_max / S^3) * ones

Update: f <- f - lr * ∇E, then project to f >= 0.

This is computationally expensive (O(n^2) per step for the convolution and the gradient), but for n up to a few thousand and a few hundred iterations, it should be feasible.

Actually, for n = 6733, O(n^2) = ~45 million operations per convolution, and we need several convolutions per iteration. With 2400 seconds, we can probably do a few hundred iterations.
