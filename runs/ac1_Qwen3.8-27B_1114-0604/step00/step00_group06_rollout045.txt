Let me also think about what the optimal asymmetric sequence looks like. 

For the LP to make progress, we need: max sum(b) > sum(a) subject to (a*b)_k <= M.

This means there exists a non-negative b with (a*b)_k <= M for all k and sum(b) > sum(a). Intuitively, b should put more mass where a is small (so that a*b stays bounded) and less mass where a is large.

If a is "left-heavy" (large on the left, small on the right), then b should be "right-heavy" (small on the left, large on the right). The mix (1-t)a + tb will be more balanced (but still asymmetric), and the convolution should be flatter.

So the overall strategy is:
1. Start with a left-heavy or right-heavy sequence.
2. The LP method finds a "right-heavy" or "left-heavy" b that's complementary.
3. Mixing them produces a more balanced sequence with lower max convolution.
4. Repeat.

This is essentially an "alternation" method: alternate between left-heavy and right-heavy sequences, each time reducing the peak.

def build_lp_matrix(a):
    """Build the sparse constraint matrix for the LP.
    A[k, j] = a[k-j] if 0 <= k-j < len(a), else 0.
    The constraint is A @ b <= M * ones.
    """
    n = len(a)
    rows = []
    cols = []
    vals = []
    for k in range(2 * n - 1):
        j_lo = max(0, k - n + 1)
        j_hi = min(n - 1, k)
        for j in range(j_lo, j_hi + 1):
            i = k - j
            rows.append(k)
            cols.append(j)
            vals.append(a[i])
    return csr_matrix((vals, (rows, cols)), shape=(2 * n - 1, n))

def lp_step(a, M):
    """Solve: max sum(b) s.t. (a*b)_k <= M for all k, b >= 0."""
    n = len(a)
    c = -np.ones(n)
    A = build_lp_matrix(a)
    res = linprog(c, A_ub=A, b_ub=np.full(2 * n - 1, M),
                  bounds=[(0, None)] * n, method='highs')
    if res.status != 0:
        return None
    return res.x
