Let me also consider a completely different approach: **use cvxpy to solve a sequence of QP problems**.

The idea: minimize $t$ subject to $(a*a)[k] \leq t$ for all $k$, $a \geq 0$, $\sum a = n$.

This is a non-convex QP because the constraints $(a*a)[k] \leq t$ are quadratic. However, we can use a **successive convex approximation** (SCA) approach:
1. Fix the current iterate $a^{(k)}$.
2. Linearize: $(a*a)[k] \approx (a^{(k)} * a)[k] + (a * a^{(k)})[k] - (a^{(k)} * a^{(k)})[k]$ (this is the standard linearization of a bilinear term).
3. Solve the resulting LP: minimize $t$ subject to the linearized constraints, $a \geq 0$, $\sum a = n$.
4. Update $a^{(k+1)}$ and repeat.

This is the **convex-concave procedure** (CCCP) applied to the bilinear problem. It's known to converge to a stationary point.

The LP at each iteration has $2n-1$ constraints (one for each lag) plus the simplex constraint. Using a solver like scipy's linprog or cvxpy with a faster solver, this should be efficient.

Let me estimate the size: $n$ variables, $2n-1 + 1$ constraints (the $2n-1$ bilinear constraints + the sum constraint). For $n = 5582$, that's about 5582 variables and 11163 constraints. This is a moderate-sized LP that can be solved quickly.

```python
import cvxpy as cp

def sca_iteration(a_current, n):
    """One SCA iteration: solve the linearized LP."""
    a = cp.Variable(n)
    t = cp.Variable()
    
    constraints = [a >= 0, cp.sum(a) == n]
    
    # Linearized constraints: for each k, (a*a_current)[k] + (a_current*a)[k] - (a_current*a_current)[k] <= t
    # (a*a_current)[k] = sum_j a[j] * a_current[k-j]  (this is linear in a)
    # (a_current*a)[k] = sum_j a_current[j] * a[k-j]  (this is also linear in a, by symmetry)
    # Actually (a*a_current)[k] = (a_current*a)[k] by commutativity of convolution
    # So the linearization is: 2 * (a*a_current)[k] - (a_current*a_current)[k] <= t
    
    a_current_conv = compute_conv(a_current)
    
    for k in range(2*n - 1):
        # (a * a_current)[k] = sum_j a[j] * a_current[k-j]
        # This is a linear function of a: sum_j a[j] * a_current[k-j]
        # The coefficient of a[j] is a_current[k-j] (if 0 <= k-j <= n-1)
        coeff = np.zeros(n)
        lo = max(0, k - (n-1))
        hi = min(n-1, k)
        for j in range(lo, hi+1):
            coeff[j] = a_current[k-j]
        # (a * a_current)[k] = dot(coeff, a)
        constraint = 2 * cp.matmul(coeff, a) - a_current_conv[k] <= t
        constraints.append(constraint)
    
    objective = cp.Minimize(t)
    prob = cp.Problem(objective, constraints)
    prob.solve(solver=cp.ECOS)  # or CLARABEL
    
    if a.value is not None:
        return np.maximum(0, a.value)
    return a_current
```
