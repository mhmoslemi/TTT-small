from scipy.optimize import linprog
import time

def compute_convolution(f):
    """Compute self-convolution of f."""
    return np.convolve(f, f)

def compute_subgradient(f, C):
    """Compute subgradient of max C[k] at f."""
    k_star = np.argmax(C)
    n = len(f)
    # g[m] = 2*f[k_star - m] if 0 <= k_star - m < n
    g = np.zeros(n)
    valid_m = range(max(0, k_star - n + 1), min(n, k_star + 1))
    for m in valid_m:
        g[m] = 2 * f[k_star - m]
    return g

def mirror_descent_step(f, C, eta):
    """One step of mirror descent (exponentiated gradient)."""
    n = len(f)
    k_star = np.argmax(C)
    # Subgradient: g[m] = 2*f[k_star-m] for valid m
    g = np.zeros(n)
    lo = max(0, k_star - n + 1)
    hi = min(n, k_star + 1)
    for m in range(lo, hi):
        g[m] = 2 * f[k_star - m]
    # Mirror descent update
    log_f = np.log(f + 1e-300)
    log_f_new = log_f - eta * g
    f_new = np.exp(log_f_new - log_f_new.max())
    f_new = f_new / f_new.sum()
    return f_new

D(f, f_t) = sum f[m] * log(f[m]/f_t[m])

The solution to this is:

where Z = sum f_t[m] * exp(-η * g_t[m]).

**Key insight about the problem structure:**

The objective is scale-invariant (multiplying f by c doesn't change the score). So we can fix sum(f) = 1 and minimize max C[k].

The problem is:
minimize: max_k C[k]
subject to: sum f = 1, f >= 0

This is a semi-infinite (well, finite but with many constraints) optimization problem.

**Approach: Alternating between "reduce the peak" and "maintain feasibility"**

At each step:
1. Find k* = argmax C
2. Compute the "influence" of each f[m] on C[k*]: influence[m] = 2*f[k*-m] (for valid m)
3. Reduce f[m] for high-influence m and increase f[m] for low-influence m
4. Check if any other C[k] becomes the new maximum

This is essentially what mirror descent does.

**Alternative: "Water-filling" approach**

Think of it as: we have a "budget" of total mass = 1 to distribute among n positions. The "cost" of putting mass at position m is how much it increases the max convolution. We want to find the distribution that minimizes the max cost.

This is reminiscent of the "equalizing" problem in communications (e.g., equal-power water-filling).

Let me try a different angle: **Iterative "peel off the peak" method**

1. Start with f = uniform (or the given initial).
2. Compute C = f*f, find k* = argmax C.
3. The "excess" at k* is C[k*] - (mean of C) = C[k*] - 1/(2n-1).
4. To reduce C[k*], we need to reduce the products f[j]*f[k*-j].
5. The most efficient way is to reduce the largest f[j] among those contributing to C[k*].
6. Move the "peeled off" mass to positions that don't contribute to C[k*] (or contribute to positions where C is already low).

This is a greedy approach. Let me formalize it:

At each step:
- k* = argmax C
- Among all j with f[j] > 0 and 0 <= k*-j < n (i.e., j contributes to C[k*]):

- We want to decrease f[j] for j that has high f[k*-j] (contributes a lot to C[k*])
- And increase f[j'] for j' that has low max_k f[k-j'] (contributes little to any C[k])
