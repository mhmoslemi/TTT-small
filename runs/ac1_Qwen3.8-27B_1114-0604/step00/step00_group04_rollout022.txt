**Approach 11: Subgradient method for the max**

The function `f(a) = max_k (a*a)[k]` has subgradients. At a point where the max is achieved at lag k*, the subgradient with respect to `a[i]` is:

We can use subgradient descent:

But this only uses one subgradient. A better approach uses the average subgradient over all active lags (those where `(a*a)[k]` is close to the max).

This is related to projected subgradient methods. The projection onto `{a >= 0, sum(a) = 1}` is just: clip to [0, ∞) and normalize.

Let me formalize:
1. Fix `sum(a) = 1`
2. Compute `c = a*a` (convolution)
3. Find the "active set": lags k where `c[k] >= (1-delta) * max(c)` for some small delta
4. Subgradient: `g[i] = sum_{k in active} w_k * a[k-i]` (weighted sum over active lags, with w_k being the weight for each active lag, normalized to sum to 1)
5. Update: `a[i] = max(0, a[i] - eta * g[i])`
6. Normalize: `a = a / sum(a)`
7. Repeat

This is O(n²) per iteration and doesn't require any LP solver!

    # Build constraint matrix
    diag_idx = rows - cols
    vals = a_safe[diag_idx]
    C = sparse.csr_matrix((vals, (rows, cols)), shape=(2 * n - 1, n))
    
    # LP: min -sum(b) s.t. C @ b <= M, b >= 0
    c_obj = -np.ones(n)
    b_ub = np.full(2 * n - 1, M)
    
    t0 = time.monotonic()
    res = linprog(c_obj, A_ub=C, b_ub=b_ub, bounds=[(0, None)] * n,
                  method='highs', options={'presolve': True})
    lp_time = time.monotonic() - t0
    
    if res.success:
        return res.x, lp_time
    return None, lp_time

def coordinate_descent_polish(a, max_sweeps=50, verbose=False):
    """Polish using coordinate descent with grid search."""
    n = len(a)
    a = a.copy()
    current_obj = compute_obj(a)
    
    for sweep in range(max_sweeps):
        improved = False
        conv = np.convolve(a, a)
        S = np.sum(a)
        
        for i in range(n):
            # Profile: how does changing a[i] to x affect the convolution?
            # (a*a)[k] changes by (x - a[i]) * a[k-i] for valid k
            # Valid k: 0 <= k-i < n, i.e., i <= k <= i+n-1 (clipped to [0, 2n-2])
            k_min = i
            k_max = min(2 * n - 2, i + n - 1)
            
            # The new convolution at affected lags:
            # new_conv[k] = conv[k] + (x - a[i]) * a[k-i] for k in [k_min, k_max]
            # Unaffected: conv[k] for k outside [k_min, k_max]
            
            # Precompute: m[k-i] = a[k-i] for k in [k_min, k_max]
            # and c[k] = conv[k] - a[i] * a[k-i] for k in [k_min, k_max]
            idx = np.arange(k_min, k_max + 1)
            m = a[idx - i]  # a[k-i] for each affected k
            c = conv[idx] - a[i] * m  # baseline (without the a[i]*a[k-i] term)
            
            # Baseline max for unaffected lags
            if k_min > 0:
                unaffected_max = np.max(conv[:k_min])
            else:
                unaffected_max = 0.0
            if k_max < 2 * n - 2:
                unaffected_max = max(unaffected_max, np.max(conv[k_max + 1:]))
            
            # Baseline sum without a[i]
            S_base = S - a[i]
            
            # Grid search for x
            x_max = max(10.0 * max(a[i], 1.0 / n), S_base)
            x_grid = np.linspace(0, x_max, 50)
            
            best_x = a[i]
            best_local_obj = current_obj
            
            for x in x_grid:
                new_S = S_base + x
                if new_S < 1e-10:
                    continue
                # New max of convolution
                new_affected_max = np.max(c + x * m)
                new_M = max(new_affected_max, unaffected_max)
                new_obj = 2.0 * n * new_M / (new_S * new_S)
                if new_obj < best_local_obj:
                    best_local_obj = new_obj
                    best_x = x
            
            if best_x != a[i]:
                a[i] = best_x
                S = S_base + best_x
                conv[idx] = c + best_x * m
                improved = True
        
        new_obj = compute_obj(a)  # verify
        if new_obj < current_obj:
            current_obj = new_obj
        elif compute_obj(a) > current_obj * 1.001:
            a[i] = a[i]  # no change, shouldn't happen
        
        if verbose and sweep % 5 == 0:
            print(f"    CD sweep {sweep}: obj = {current_obj:.6f}")
    
    return a, current_obj
