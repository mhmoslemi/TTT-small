**Let me also consider the "coordinate descent" approach more carefully:**

At each step, we pick a pair $(i, j)$ and transfer mass from one to the other. The key question is: which pair to pick?

If the peak is at position $k^*$, the change in the peak is:
$\Delta = 2\delta(a_{k^*-i} - a_{k^*-j})$

We want $\Delta < 0$, so we want $a_{k^*-i} < a_{k^*-j}$ (for $\delta > 0$).

The "best" pair is the one with the largest $a_{k^*-j} - a_{k^*-i}$.

But we also need to check that other positions don't exceed the current peak. For position $k \neq k^*$:
$\Delta_k = 2\delta(a_{k-i} - a_{k-j})$

We need $\Delta_k \leq M - (a*a)[k]$ for all $k$, where $M = (a*a)[k^*]$ is the current peak.

This gives constraints on $\delta$:
$\delta \leq (M - (a*a)[k]) / (2(a_{k-i} - a_{k-j}))$ for all $k$ where $a_{k-i} > a_{k-j}$.

The maximum safe $\delta$ is the minimum of all these upper bounds (and also $\delta \leq a_j$ for non-negativity).

This is an $O(n)$ check per pair, and we'd need to check $O(n^2)$ pairs in the worst case. For $n = 6121$, that's too slow.

Instead, we can use a greedy approach: pick the pair $(i, j)$ that best reduces the peak (largest $a_{k^*-j} - a_{k^*-i}$), and use a small step size.

**Let me now think about what the "state of the art" LP approach is really doing:**

The LP finds a direction $d$ (with $\sum d_i = 0$ and $d_i \geq -a_i$) that maximizes the "room" before hitting the peak constraint. Essentially, it solves:

maximize $\sum d_i$ (or some linear objective)
subject to $(a+td) * (a+td) \leq M$ for all $k$ and $t \in [0,1]$

This is a QP (quadratic constraints), not a LP. But if we linearize (consider only the first-order effect), it becomes:

maximize $\sum d_i$
subject to $2(P_k a)_i d_i + d_i^2 (P_k)_{ii} \leq M - (a*a)[k]$ for all $k$

Which is approximately:
$\sum_i d_i (P_k a)_i \leq (M - (a*a)[k]) / 2$ for all $k$

This is a LP! The idea is to find a direction that makes the most progress toward reducing the peak.

For our implementation, we can simplify this to: find a direction $d$ (with $\sum d_i = 0$, $-a_i \leq d_i$) such that the first-order decrease in the peak is maximized, subject to not increasing any other convolution value.

This is equivalent to:
maximize $-2 \sum_i d_i (P_{k^*} a)_i$ (decrease in peak)
subject to $2 \sum_i d_i (P_k a)_i \leq M - (a*a)[k]$ for all $k \neq k^*$
and $\sum d_i = 0$, $-a_i \leq d_i$, $d_i \leq \infty$

This is a LP with $2n-1$ constraints and $n$ variables. For $n = 6121$, this is a moderate-sized LP that can be solved with scipy or cvxpy.

def simplex_project(v, S):
    """Project v onto the simplex {x: x_i >= 0, sum(x) = S}."""
    n = len(v)
    if n == 0:
        return v
    u = np.sort(v)[::-1]
    css = np.cumsum(u)
    cond = u * np.arange(1, n+1) > (css - S)
    if not np.any(cond):
        return np.full(n, S / n)
    k = np.max(np.where(cond)[0])
    theta = (css[k] - S) / (k + 1)
    return np.maximum(v - theta, 0)
