Actually, here's a key observation. If we define s = sum(a), then we can write:
score = 2n * max_k(c[k]) / s^2

If we fix the direction of a (i.e., fix a/||a||), then increasing the scale doesn't change the score (it's homogeneous of degree 0). So we can normalize, say, s = 1, and minimize max_k(c[k]).

With s = 1: minimize max_k(c[k]) subject to a >= 0, sum(a) = 1.

This is a convex optimization problem! The constraint sum(a) = 1 is linear, a >= 0 is linear, and we're minimizing the max of linear functions of a (since c[k] is a quadratic in a, not linear...).

Wait, c[k] = sum_i a[i]*a[k-i] is quadratic in a, not linear. So minimizing max c[k] is not convex in general.

But if we fix c[k] <= t for all k and minimize t, subject to a >= 0, sum(a) = 1, then we have:
minimize t
subject to sum_i a[i]*a[k-i] <= t for all k
a >= 0
sum(a) = 1

The constraints sum_i a[i]*a[k-i] <= t are NOT convex (they're constraints on quadratic forms that are not necessarily convex).

However, sum_i a[i]*a[k-i] = a^T P_k a where P_k is a symmetric matrix. For this to be a convex constraint, we'd need P_k to be positive semidefinite. 

P_k has (P_k)_{ij} = 1 if j = i+k (or i = j+k), i.e., it's a permutation matrix (shift matrix). These are NOT positive semidefinite in general (they have eigenvalues on the unit circle, including -1).

So this is a non-convex problem. We need heuristics.
