Let me also think about the projection. After the gradient step `f_new = f - η * grad`, we need to project onto `{f >= 0, sum(f) = 1}`. The projection onto the non-negative simplex is:
1. Set negative values to 0
2. Subtract a threshold from all positive values to make the sum equal to 1
3. Set values below the threshold to 0
(This is the Euclidean projection onto the simplex, which can be done in O(n log n) using sorting, or O(n) in expected time using median-of-medians.)

Actually, a simpler approach: use multiplicative updates to maintain non-negativity:
`f[i] *= exp(-η * grad[i] / f[i])` or `f[i] = f[i] * exp(-η * grad[i])`

But this doesn't automatically normalize. We can normalize after each step.

Let me also consider the **smoothed objective** more carefully. Instead of log-sum-exp, I could use a power approximation:
`max(b) ≈ (sum_k b[k]^p)^(1/p)` for large p.

The gradient of this is:
`∂/∂f[i] (sum_k b[k]^p)^(1/p) = (sum_k b[k]^p)^(1/p-1) * sum_k p*b[k]^(p-1) * ∂b[k]/∂f[i]`
= C * sum_k b[k]^(p-1) * f[k-i]
= C * (b^(p-1)) * f  [convolution]

This is also a convolution, so still O(n log n).

For the objective to be close to 1 (the theoretical lower bound), we need `b` to be almost uniform. Since `sum(b) = 1` (normalized) and there are `2n-1` elements, each element should be about `1/(2n-1)`.

The constraint is that `b` must be the autocorrelation of a non-negative sequence. The set of valid autocorrelations (of non-negative sequences) is a subset of the set of positive semidefinite sequences.

In the frequency domain, `B(ω) = |F(ω)|² >= 0` for all ω. The constraint that f >= 0 is a time-domain constraint that's hard to express in frequency.

However, if we ignore the f >= 0 constraint, the problem becomes: minimize max(b) subject to b being a valid autocorrelation (i.e., its DTFT is non-negative) and sum(b) = 1. The optimum would be b = uniform, which corresponds to F being a "white noise" sequence. But white noise in frequency means f is a delta function in time, which is non-negative but has sum = 1 only if it's (1, 0, 0, ..., 0). And for f = (1, 0, ..., 0), b = (1, 0, ..., 0), max(b) = 1, objective = 2n. Terrible!

So the f >= 0 constraint and the requirement that f be spread out (to make sum(f) large relative to the peak) are in tension.
