2. `a_new = a - lr * g`
3. `a_final = project_to_simplex(a_new)` (Euclidean projection onto `{x >= 0, sum(x) = 1}`)

The projection onto the simplex can be done in O(n log n) using the following:
- Find `tau` such that `sum(max(a_i - tau, 0)) = 1`.
- `a_final[i] = max(a[i] - tau, 0)`.

This is better than just clipping and rescaling because it's the true Euclidean projection.

```python
def project_to_simplex(v):
    """Project v onto the probability simplex {x >= 0, sum(x) = 1}."""
    n = len(v)
    # Binary search for tau
    lo, hi = v.min() - 1, v.max() + 1
    for _ in range(60):  # ~1e-18 precision
        mid = (lo + hi) / 2
        if np.sum(np.maximum(v - mid, 0)) >= 1:
            lo = mid
        else:
            hi = mid
    tau = (lo + hi) / 2
    return np.maximum(v - tau, 0)
```
