                    = a[k-m] + a[m-k] if 2m != k (with a[j] = 0 for invalid j)
                    = a[k-m] if only one of (k-m, m-k) is in [0,n)
                    = 0 if neither is in [0,n)

This is the "autocorrelation gradient."

For the objective M = max_k C[k], the subgradient at a is:
- If there's a unique maximizer k*, the subgradient is dC[k*]/da.
- If there are multiple maximizers, the subgradient is any convex combination of their gradients.

**Practical algorithm: Subgradient descent with projection**

1. Initialize a (e.g., uniform, or random positive).
2. Normalize to S = n (mean = 1).
3. Loop:
   a. Compute C = conv(a, a).
   b. Find k* = argmax C.
   c. Compute gradient g = dC[k*]/da.
   d. Step: a_new = a - lr * g.
   e. Project: a_new = max(0, a_new).
   f. Renormalize: a_new = a_new * (S / sum(a_new)).
   g. Accept if objective improved, otherwise reduce lr.
4. Return best found.

No wait, C[k] = sum_{i+j=k, 0<=i<n, 0<=j<n} a[i]*a[j].

Let me use a different approach. C[k] = sum_i a[i]*a[k-i] where the sum is over all i such that 0 <= i < n and 0 <= k-i < n, i.e., max(0, k-n+1) <= i <= min(k, n-1).

For the alternating sequence:
- If k is even: a[i] and a[k-i] have the same parity (both even or both odd indices).
  - If i is even: a[i] = x, and k-i is even, so a[k-i] = x. Product = x^2.
  - If i is odd: a[i] = y, and k-i is odd (since k is even), so a[k-i] = y. Product = y^2.
  - Number of even i in [max(0,k-n+1), min(k,n-1)]: depends on k and n.
  
This is getting complicated. Let me just accept that for a simple periodic pattern, the convolution will have a periodic structure with some peaks.

**Let me try a completely different approach: use the given `height_sequence_1` and apply targeted local search with a smarter perturbation strategy.**

Given that the target is 1.5027 and we're at 2.0, we need a significant improvement. The local search with random perturbations probably won't find it.

Let me think about what kind of sequence could achieve 1.5:
Score = 2n * M / S^2 = 1.5
=> M = 0.75 * S^2 / n

If S = n (mean 1): M = 0.75n.

So we need max C[k] = 0.75n. The average C[k] is n^2/(2n-1) ≈ n/2 = 0.5n. So we need the peak to be only 1.5x the average. That's not too far from flat!

For the uniform sequence, the peak is n (2x the average). We need to get it down to 0.75n (1.5x the average).

**New idea: Use a sequence that's a sum of carefully placed "bumps"**

If we place many small bumps at specific locations, the convolution will have peaks at the differences between bump locations. If the differences are well-spread, the peaks will be smaller.

This is like a "Golomb ruler" or "Costas array" approach!

A Costas array is a permutation p of {1, ..., n} such that all differences p[j]-p[i] for j>i are distinct. If we place unit bumps at positions p[1], ..., p[n] (with appropriate spacing), the autocorrelation will have at most one peak per lag, leading to a flatter overall autocorrelation.

But our sequence is continuous and non-negative, not a permutation. So we can think of it as placing weighted bumps at various positions.

**Practical algorithm: Start from a random sequence and use gradient-based optimization**

Let me code up the subgradient approach:

1. Start with a random positive sequence of length n.
2. Normalize to sum = n.
3. Compute C = conv(a, a).
4. Find k* = argmax C.
5. Compute the "gradient" g where g[m] = a[k*-m] + a[m-k*] (with a[j]=0 for invalid j).
6. Update: a = a - lr * g.
7. Clip to non-negative: a = max(0, a).
8. Renormalize to sum = n.
9. Repeat with decreasing learning rate.

The issue with this approach is that it only reduces C at one lag at a time, and might create new peaks at other lags.

**Better approach: Use the "top-k" lags**

Instead of just the max lag, use a weighted combination of the top few lags. This gives a smoother "gradient" that accounts for multiple peaks.

**Even better: Use a smooth approximation of the max**

Instead of max_k C[k], use a soft-max: F = (1/T) * log(sum_k exp(T*C[k])). As T → ∞, this approaches max. For finite T, it's smooth and differentiable.

The gradient of F with respect to a[m] is:
dF/da[m] = (1/T) * sum_k exp(T*C[k]) * dC[k]/da[m] / sum_k exp(T*C[k])

This is a weighted average of the gradients, with weights proportional to exp(T*C[k]). For large T, it's concentrated on the max; for small T, it's spread out.

This is a much better approach! Let me code this up.
