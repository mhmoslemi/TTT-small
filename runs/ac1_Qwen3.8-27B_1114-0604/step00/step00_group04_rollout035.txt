Actually, one more mathematical insight. The score is:

This can be rewritten as:
score = 2*n * max_k c[k] / sum_k c[k]

Let p[k] = c[k] / sum(c) (a probability distribution). Then:
score = 2*n * max_k p[k]

We want to minimize the peak of this probability distribution. The minimum possible value of max p[k] is 1/(2n-1) (uniform distribution), giving score = 2n/(2n-1).

So we're essentially trying to make the distribution of c as uniform as possible.

This is related to the "energy spreading" problem. One way to think about it: we want the polynomial A(x)^2 to have coefficients as equal as possible.

If A(x) = sum a_i x^i, then A(x)^2 = sum_k c_k x^k.
We want c_k ≈ sum(c)/(2n-1) for all k.

This is equivalent to wanting |A(e^{2πik/(2n-1)})|^2 to be as constant as possible (by Parseval's theorem for the DFT of c).

Actually, that's not quite right. The DFT of c is related to |A(ω)|^2 where ω = e^{2πi/(2n-1)}, but only if c is periodic with period 2n-1. Since c has length 2n-1, its DFT at frequency m is:
C[m] = sum_k c[k] * e^{-2πimk/(2n-1)}

And by the convolution theorem:
C[m] = A(ω^m)^2 where A(ω) = sum a_i ω^i

Wait, that's not right either. The DFT of the linear convolution is not simply the product of DFTs (that's for circular convolution).

Let me think differently. The sum of all c[k] is (sum a_i)^2. We want all c[k] to be equal, i.e., c[k] = (sum a_i)^2 / (2n-1) for all k.

This means A(x)^2 = ((sum a_i)^2/(2n-1)) * (1 + x + x^2 + ... + x^{2n-2})

So A(x) = (sum a_i)/sqrt(2n-1) * sqrt(1 + x + ... + x^{2n-2})

But sqrt(1 + x + ... + x^{2n-2}) is not a polynomial in general, so this is impossible with a polynomial A(x). However, we can get close.

The closest we can get is to find A(x) such that A(x)^2 is as close to a constant times (1 + x + ... + x^{2n-2}) as possible.

This is a "polynomial approximation" problem. One approach is to minimize the L2 distance:
minimize ||A(x)^2 - c*(1+x+...+x^{2n-2})||_2^2

where c = (sum a_i)^2/(2n-1) is determined by a.

This is a quartic optimization problem in the coefficients of A. It might be solvable with iterative methods.

def _proj_simplex_exact(v):
    """Exact projection onto the probability simplex."""
    n = len(v)
    if v.sum() < 1e-15:
        return np.ones(n) / n
    # Algorithm from Wang & Carreira-Perpinan (2013)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.where(u * np.arange(1, n+1) > (cssv - 1))[0][-1]
    theta = (cssv[rho] - 1) / (rho + 1)
    return np.maximum(v - theta, 0)

Multiple initializations, sequence lengths, and adaptive parameters are used.
The key insight is that the objective equals 2n * max_k p[k] where p[k] = c[k]/sum(c)
is the normalized convolution, so we minimize the peak of this distribution.

    """Linear convolution of a with itself using FFT."""

    size = 1
    while size < 2 * n - 1:

    """
    Gradient of (1/T)*log(sum(exp(T*c))) w.r.t. a, where c = conv(a,a).
    Returns (gradient, c).

    n = len(a)
    c = _conv_fft(a)

def _proj_simplex(v):
    """Exact projection onto the probability simplex {x >= 0, sum(x) = 1}."""
    n = len(v)
    v_sum = v.sum()
    if v_sum < 1e-15:
        return np.ones(n) / n
    u = np.sort(v)[::-1]
    cv = np.arange(1, n + 1)
    cssv = np.cumsum(u)
    cond = u * cv > (cssv - 1.0)
    rho = np.where(cond)[0]

        return np.ones(n) / n
    rho = rho[-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
