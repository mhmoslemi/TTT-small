The "tail" (uniform part) contributes a triangular autocorrelation with peak ≈ (n-tail_length)/n^2 ≈ 1/n (where tail_length is the number of uniform terms).

The cross terms between head and tail are small (since head values are ~1/sqrt(n) and tail values are ~1/n, the cross terms are ~1/n^{3/2}).

So the max autocorrelation is approximately max(1/(2n), 1/n) = 1/n (from the uniform tail).
f ≈ 2n * 1/n = 2.

So the hybrid approach also gives f ≈ 2! The uniform tail dominates.

To get f < 2, we need the autocorrelation of the "tail" to also be flatter than triangular. But the tail is approximately uniform (since we've already used the "ideal" decaying pattern for the head), so its autocorrelation is approximately triangular.

Hmm, this suggests that for large n, it's very hard to get below 2.

Wait, but what if we make the ENTIRE sequence follow the "ideal" decay pattern, but stretched out?

If p[k] = C * (2k+1)/2^{k+1} for k = 0, ..., n-1, with C chosen so that sum = 1, then:
C = 1/S(n) where S(n) = sum_{k=0}^{n-1} (2k+1)/2^{k+1} → 3.
The autocorrelation is approximately flat (value ≈ C^2 = 1/S(n)^2 ≈ 1/9) for the first n lags.
f ≈ 2n/9.

For n = 9: f ≈ 2. For n < 9: f < 2. For n > 9: f > 2.

So the "ideal" decay pattern is only useful for n <= 9!

For n > 9, we need a different approach.

Let me think about what happens if we use a SLOWER decay. Instead of (2k+1)/2^{k+1}, what if we use (2k+1)/r^{k+1} for r > 2?

The sum would be larger (since the tail decays slower), and the autocorrelation would be less flat (more peak at the center).

Actually, let me think about this problem from a completely different angle.

**Key Insight**: The objective is 2n * max(conv(p,p)) where sum(p) = 1 and p >= 0.

For ANY sequence, max(conv(p,p)) >= (sum p)^2 / (2n-1) = 1/(2n-1).
So f >= 2n/(2n-1).

The question is: what's the actual minimum for non-negative p?

I believe the answer depends on n:
- For small n (n <= ~9), the "ideal" sequence achieves f < 2.
- For large n, the minimum is close to 2 (but maybe slightly below).

Let me verify: for the uniform sequence, f = 2 exactly. Can we do slightly better than 2 for large n?

Consider p = uniform + ε * (some perturbation). The autocorrelation of uniform is triangular with peak 1/n. A perturbation that reduces the center of the triangle (without increasing the ends) would reduce the max.

For the full convolution of a length-n sequence, the "center" is at index n-1. The value there is sum p[i]*p[n-1-i].

For uniform, this is n*(1/n)^2 = 1/n.
For a sequence where p[0] and p[n-1] are slightly smaller than average, the center value decreases.

But reducing p[0] also reduces conv[0] = p[0]^2, and reducing p[n-1] reduces conv[2n-2] = p[n-1]^2. So we're trading the center peak for end peaks.

If we reduce p[0] by δ and p[n-1] by δ (and increase the middle by 2δ/n to maintain sum), then:
- conv[0] decreases by 2δ/n (first order)
- conv[n-1] (center) decreases by 4δ/n (first order, since both p[0] and p[n-1] contribute)
- conv[2n-2] decreases by 2δ/n

The center decreases faster than the ends! So this perturbation reduces the max.

But we need to be careful: the second-order effects and the effects on intermediate lags matter.

Let me be more precise. Let p[i] = (1+δ_i)/n where sum δ_i = 0 and δ_i >= -1.
conv[p,p][k] = (1/n^2) * sum_i (1+δ_i)(1+δ_{k-i}) (with appropriate bounds)
= (1/n^2) * [numerator + sum δ_i + sum δ_{k-i} + sum δ_i * δ_{k-i}]
= (1/n^2) * [numerator + 2*numerator*mean(δ) + sum δ_i * δ_{k-i}] (approximately, for k in the middle)

Since mean(δ) = 0, the first-order correction is zero (for the middle lags). The second-order correction is (1/n^2) * sum δ_i * δ_{k-i}, which is the autocorrelation of δ.

So the perturbation to the autocorrelation is (1/n^2) * autocorr(δ)[k]. To reduce the center peak, we need autocorr(δ)[n-1] < 0. This means δ should be "anti-correlated" with its reverse: sum δ_i * δ_{n

"""
Iterative multiplicative weight search for minimum autocorrelation peak sequences.
Combines LP-based dual updates with greedy top-peak reduction for small n,
and a global random restart strategy across multiple sequence lengths.
"""

import numpy as np
import time
from scipy.optimize import linprog


def ideal_sequence(n):
    """Construct the 'ideal' non-negative sequence with flat first-n autocorrelation."""
    a = np.zeros(n, dtype=np.float64)
    a[0] = 1.0
    for k in range(1, n):
        s = 0.0
        for i in range(1, k):
            s += a[i] * a[k - i]
        a[k] = (1.0 - 2.0 * s) / (2.0 * a[0])
    s = a.sum()
    if s < 1e-15:
        return np.ones(n) / n
    return a / s


def generate_candidates(n, rng, count=30):
    """Generate diverse initial candidates of length n."""
    cands = [ideal_sequence(n)]
    # Random
    for _ in range(min(5, count // 5)):
        x = rng.random(n)
        cands.append(x / x.sum())
    # Cosine window
    k = np.arange(n)
    w = np.cos(np.pi * k / (2 * n)) ** 2
    cands.append(w / w.sum())
    # Power law
    for alpha in [0.5, 1.0, 1.5, 2.0]:
        w = (1.0 - np.arange(n) / n) ** alpha
        if w.sum() > 0:
            cands.append(w / w.sum())
    # Two-bump
    for frac in [0.25, 0.35]:
        w = np.zeros(n)
        w[np.arange(int(frac * n))] = 1.0
        w[np.arange(n - int(frac * n), n)] = 1.0
        if w.sum() > 0:
            cands.append(w / w.sum())
    cands.append(np.ones(n) / n)
    return cands


def solve_lp_dual(p, p2, M):
    """
    Solve: max sum(g) s.t. A @ g <= M, g >= 0
    where A[i,j] = conv(p,g)[i] coefficient for g[j], i.e. A[i,j] = p[(i-j) mod n] (circular).
    Returns g.
    """
    n = len(p)
    # A[i,j] = circular convolution coefficient: (p * g)_circ[i] = sum_j p[(i-j)%n] * g[j]
    # So A[i,j] = p[(i-j) % n]
    A = np.array([[p[(i - j) % n] for j in range(n)] for i in range(n)], dtype=np.float64)
    c = np.zeros(n)  # maximize 0 (we just need a feasible solution that maximizes sum)
    # Actually maximize sum(g), so c = -ones (scipy minimizes)
    c = -np.ones(n)
    res = linprog(c, A_ub=A, b_ub=np.full(n, M), bounds=[(0, None)] * n,
                  method='highs', options={'presolve': True, 'time_limit': 30})
    if res.status == 0:
        return res.x
    return None


def lp_iteration(p, p2, t=0.15, dual_iters=1):
    """One LP-based iteration."""
    n = len(p)
    M = np.max(p2)
    g = None
    for _ in range(dual_iters):
        g = solve_lp_dual(p, p2, M)
        if g is None:
            break
        gs = g.sum()
        if gs < 1e-15:
            break
        g = g / gs
        p_new = (1.0 - t) * p + t * g
        p_new = np.clip(p_new, 1e-30, None)
        p_new = p_new / p_new.sum()
        p2 = np.convolve(p_new, p_new, mode='full')
        p = p_new
    return p, p2


def greedy_top_reduce(p, p2, iterations=5):
    """Find the top peak positions and redistribute mass to reduce them."""
    n = len(p)
    for _ in range(iterations):
        # Find top 3 peak indices
        top_idx = np.argsort(p2)[-3:]
        # Reduce mass at source positions that contribute to these peaks
        # For peak at index k in full conv, contributing pairs are (i, k-i)
        # Reduce p at positions that appear in multiple top peaks
        reduce_scores = np.zeros(n)
        for k in top_idx:
            for i in range(max(0, k - n + 1), min(n, k + 1)):
                j = k - i
                if 0 <= j < n:
                    reduce_scores[i] += p2[k] * p[i] * p[j]
        # Reduce the top contributors
        top_reduce = np.argsort(reduce_scores)[-2:]
        total_reduce = 0.0
        for idx in top_reduce:
            amt = min(p[idx] * 0.1, 0.5 / n)
            p[idx] -= amt
            total_reduce += amt
        # Distribute to low positions
        low_positions = np.argsort(p)[:n // 4]
        for lp in low_positions:
            p[lp] += total_reduce / len(low_positions)
        p = np.clip(p, 1e-30, None)
        p = p / p.sum()
        p2 = np.convolve(p, p2[:0], mode='full')  # placeholder
        p2 = np.convolve(p, p, mode='full')
    return p, p2


def mixed_iteration(p, p2, rng):
    """One iteration: LP step + small perturbation."""
    n = len(p)
    # LP step with small step size
    M = np.max(p2)
    g = solve_lp_dual(p, p2, M)
    if g is not None:
        gs = g.sum()
        if gs > 1e-15:
            g = g / gs
            t = 0.1
            p = (1.0 - t) * p + t * g
            p = np.clip(p, 1e-30, None)
            p = p / p.sum()
    # Small random perturbation
    noise = rng.normal(0, 0.02, n)
    p = p * np.exp(noise)
    p = np.clip(p, 1e-30, None)
    p = p / p.sum()
    p2 = np.convolve(p, p, mode='full')
    return p, p2

    rng = np.random.default_rng(seed)

        # Start from ideal sequence

        cur_score = 2.0 * n * np.max(p2)
