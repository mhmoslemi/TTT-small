**Algorithm: Subgradient method with projection**

1. Initialize f (e.g., uniform or from height_sequence_1, normalized to sum=1).
2. Repeat:
   a. Compute c = f*f (self-convolution).
   b. Find the active set A = {k : c[k] ≈ max(c)} (within some tolerance).
   c. Compute the "average gradient" G = (1/|A|) * sum_{k in A} 2*shift_k(f), where shift_k(f)[j] = f[k-j] if valid.
   d. Take a step: f_new = f - alpha * G.
   e. Project f_new onto {f >= 0, sum(f) = 1} (Euclidean projection).
   f. f = f_new.
3. Return f.
