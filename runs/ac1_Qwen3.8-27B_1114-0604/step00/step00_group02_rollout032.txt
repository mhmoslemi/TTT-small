**New strategy: Iterative peak reduction**

1. Start with a sequence a.
2. Compute a*a and find the peak location k*.
3. Find a "small" perturbation δa such that:
   - (a + δa) is still non-negative.
   - sum(a + δa) = sum(a).
   - The peak at k* is reduced.
4. Apply the perturbation.
5. Repeat.

For step 3, the key constraint is reducing (a*a)[k*]. We have:
(a + δa)(a + δa)[k*] ≈ (a*a)[k*] + 2(a * δa)[k*] (ignoring the quadratic term)

So we need (a * δa)[k*] < 0 to reduce the peak. Since a ≥ 0, we need δa to be "negatively correlated" with a at lag k*.

But δa must preserve sum = 0 (to maintain normalization) and a + δa ≥ 0.

One simple approach: 
- Find j such that a[k*-j] is large (contributing to the peak).
- Decrease a[j] slightly and increase a[j'] at a position where a[k*-j'] is small.

This is like a "swap" operation. Let me formalize:

Pick two indices j and j' such that:
- a[j] > 0 (so we can decrease it).
- a[k* - j] > a[k* - j'] (so moving mass from j to j' reduces the peak).
- The change in the peak is: 2ε(a[k*-j'] - a[k*-j]) < 0 (where ε is the amount moved).

We also need to check that other lags don't increase. This is the tricky part.

A simpler heuristic: 
- Find the peak at k*.
- The peak is (a*a)[k*] = Σ a[i]·a[k*-i].
- To reduce it, we want to "spread out" the mass of a so that fewer pairs (i, k*-i) both have large values.
- One way: find the position i* that contributes most to the peak (i.e., a[i*]·a[k*-i*] is maximized) and reduce a[i*] (or a[k*-i*]), moving the mass to a position where it doesn't contribute as much.

This is essentially what the LP does, but in a greedy manner.

```python
def greedy_peak_reduction(a, num_steps=100):
    n = len(a)
    for step in range(num_steps):
        conv = np.convolve(a, a)
        k_star = np.argmax(conv)
        peak = conv[k_star]
        
        # Find the "worst" position to modify
        # The contribution of a[j] to the peak is a[j] * a[k_star - j]
        # (for valid j)
        # We want to move mass from a position with high contribution to one with low contribution.
        
        valid_j = np.arange(max(0, k_star - n + 1), min(n, k_star + 1))
        if len(valid_j) == 0:
            break
        
        a_rev = np.zeros(n)
        for j in valid_j:
            if 0 <= k_star - j < n:
                a_rev[j] = a[k_star - j]
        
        contribution = a * a_rev  # contribution of each position to the peak
        
        # Find the position with highest contribution (source) and lowest (target)
        source = np.argmax(contribution)
        # Target: position with low a[k* - j] and low a[j] (to avoid creating new peaks)
        # Simple heuristic: position with minimum a[k* - j]
        target = np.argmin(a_rev)
        
        if source == target:
            break
        
        # Move a small amount from source to target
        eps = min(a[source], peak * 0.01)
        a[source] -= eps
        a[target] += eps
        
        # Renormalize (should be exact since we moved equal amounts)
    
    return a
```

**Algorithm: Iterative "peak shaving"**

1. Start with a sequence a (normalized to sum = 1).
2. Compute conv = a*a.
3. Find the peak: k* = argmax(conv).
4. Compute the "subgradient": for each j, grad[j] = a_padded(k*-j) + a_padded(j-k*).
5. Take a small step: a_new = a - α · grad.
6. Project: a_new = max(a_new, 0); a_new = a_new / sum(a_new).
7. Repeat.

The step size α can be chosen by a line search (try several values and pick the best).
