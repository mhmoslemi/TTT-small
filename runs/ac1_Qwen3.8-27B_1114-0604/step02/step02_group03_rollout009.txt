1. Compute the autocorrelation c = conv(a, a).
2. Find the peak: k* = argmax c.
3. The gradient of c[k*] w.r.t. a is: 2*a[k*-j] (for valid j) + 2*a[j-k*] (for valid j).
   More precisely: d(c[k*])/d(a[j]) = a[k*-j] + a[j-k*].
4. So the "direction" to decrease c[k*] is: for each j, move a[j] in the direction that decreases a[k*-j] + a[j-k*].
   Since a >= 0, we can only decrease a[j] (or increase it, but that might increase other c[k]).
5. The best move is to decrease a[j] where a[k*-j] + a[j-k*] is large (these positions contribute most to the peak).
6. Where to put the removed mass? Put it where it contributes least to all c[k].

This is essentially a greedy approach. But it's slow if done one position at a time.

The key insight for coordinate descent: if I transfer a small amount of mass from position i to position j, the change in c[k] is:
Δc[k] ≈ 2*dv*(a[k-j] - a[k-i]) + O(dv^2)

where dv is the amount transferred. (The exact formula includes quadratic terms.)

So the "best" transfer is one that reduces the peak. Specifically, I want to find (i, j, dv) that minimizes max(c + Δc).

A good heuristic:
- i should be a position where a[i] is large AND a[k*-i] is large (where k* is the peak lag). This way, reducing a[i] reduces c[k*].
- j should be a position where a[j] is small AND a[k*-j] is small for all k near the peak. This way, adding mass at j doesn't increase any c[k] much.

**Approach: Spectral factorization / Wald's method**

We want to find a >= 0 such that the autocorrelation c = IFFT(|FFT(a)|^2) is as flat as possible.

The "target" autocorrelation is c_target[k] = 1/(2n-1) for all k (uniform).

In the frequency domain, this corresponds to |A_target(f)|^2 = DFT(c_target) = delta(f=0) (a pure DC component).

But we can't have a time-domain signal that's a delta in frequency and non-negative in time (that would be a constant, which gives a triangular autocorrelation).

So the "target" is not achievable. Instead, we want to find the a >= 0 that makes c as close to uniform as possible.

This is a min-max problem: minimize max_k (c[k] - 1/(2n-1)).

One approach: **Alternating minimization**
1. Fix the "shape" of c (e.g., c[k] = alpha + beta * some_kernel[k])
2. Find a >= 0 that best matches this target c (this is a feasibility problem)
3. Adjust alpha, beta to minimize the max deviation

Step 2 is: find a >= 0 such that conv(a,a) ≈ c_target. This is a quadratic equality constraint, which is hard in general.

But there's an approximation: if we work in the log domain (let a = exp(x)), then conv(exp(x), exp(x)) ≈ c_target becomes a system of equations in x. This is still nonlinear but can be solved iteratively.
