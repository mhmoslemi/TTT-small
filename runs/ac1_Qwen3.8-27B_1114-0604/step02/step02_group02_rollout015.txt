The key issue with gradient-based methods on this problem:

The "smoothed max" idea is interesting:
Instead of max(c), use (1/T) * log(sum(exp(T*c[k]))). As T → ∞, this approaches max(c). For finite T, it's smooth and we can use exact gradients.

The gradient of the log-sum-exp with respect to f[i]:
∂/∂f[i] [(1/T) log(sum_k exp(T*c[k]))] = (1/T) * sum_k [T * (dc[k]/df[i]) * exp(T*c[k])] / sum_k exp(T*c[k])
= sum_k [dc[k]/df[i] * softmax_k(T*c)]

where softmax_k(T*c) = exp(T*c[k]) / sum_j exp(T*c[j]).

And dc[k]/df[i] = f[k-i] (if k-i is in [0, n-1] and k is in [i, i+n-1], else 0).

So the gradient is:
grad[i] = sum_{k=i}^{i+n-1} f[k-i] * softmax_k(T*c)

This is a weighted average of f[k-i] over the affected k values, with weights proportional to exp(T*c[k]).

For large T, the weights concentrate on the argmax, recovering the original subgradient.
For small T, the weights are more spread out, giving a smoother gradient.

This "annealed gradient" is a well-known technique in log-sum-exp optimization. Let me use it!

The algorithm:
1. Start with small T (smooth gradient).
2. Gradually increase T (sharper gradient, converging to the true max).
3. Use exponential gradient (mirror descent) with this smoothed gradient.
4. Periodically reset T to escape local minima.

This is essentially a "continuation method" for the max function.
