# Approach and rationale

Analyzing the given evaluation function:

evaluate_sequence(sequence) computes:
2 * n * max(convolve(sequence)) / (sum(sequence)) ** 2

where `sequence` is a list of non-negative floats, and `convolve` is the linear convolution with full mode (resulting in 2*n-1 elements).

Our goal is to minimize this value, ideally approaching 1.5027.

The previous solution achieved 1.515664. The problem with sinusoidal initialization is that it may get trapped in regions where the peaks of the self-convolution are poorly aligned. To overcome this, we use a systematic approach:

1. **Initialization**: Start with a combinatorial perturbation strategy. This ensures diversity in initial candidates, preventing premature convergence.
2. **Core Optimization**: Use accelerated convex optimization techniques (e.g., ADMM or gradient projection) on explicit representations of the normalized self-convolution peaks.
3. **Final Polish**: Optimize using finite differences or other precise methods to verify and slightly improve the solution.

This approach uses combinatorial structure to guide the search efficiently through large solution spaces, leveraging convex methods for global structure refinement, and applying local searches with finite difference gradients to achieve high accuracy.

# Mathematical specification

1. **Representation**:
   - All sequences q used in the SEARCH phase are of length n, normalized so that their L1 norm is 1 and remain positive.
   - The goal is to minimize the peak density metric: f(q) = 2 * n * M(q) / S(q)^2, where:
     - S(q) = sum(q)
     - M(q) = max(s_i) where s_i is the i-th element of the linear convolution of q with itself.

2. **Constraints**:
   - q[i] >= 0 for all i.

3. **Optimization Design**:
   - For SEARCH phase: Represent q as a finite set of "peak activations" (binary 0-1 vectors) combined using simplex projection.
   - Use combinatorial generation to create initial candidates, then ADMM with block-wise updates.

4. **Helpers**:
   - `_peak_indices(q)`: Identify indices where convolution peaks occur.
   - `_admm_step(z, linear, quadratic)`: Perform one ADMM iteration.

5. **Return Contract**:
   - Propose a final candidate (numpy array) that passed exact validation.

        # Strong update direction: ratio between convolution and current function
        update_step = grad[conv_idx]
        
        # Gradient descent update formula
        q_new = q - (update_step > 0.5) * 0.5 * grad[conv_idx] * rho * gamma
        
        # Project to non-negative with max 1000
        q_new[q_new<0] = 0
        q_new[q_new>1000] = 1000
        
        q = q_new
    
    return best_q, best_score

# --- Final structure optimization with Finite Differences ---
def _finite_difference(q, epsilon=0.0001):
    """Compute approximate gradient using central differences for refinement."""
    grad = np.zeros_like(q)
    n_val = len(q)
    total_sum = np.sum(q)
    conv = _fft_convolve(q)
    
    for idx in range(n_val):
        # Positive direction
        q_plus = q.copy()
        q_plus[idx] += epsilon
        s_plus = np.sum(q_plus)
        c_plus = _fft_convolve(q_plus)
        pos_cost_plus = 2 * n_val * np.max(c_plus) / (s_plus ** 2)
        # Negative direction
        q_minus = q.copy()
        q_minus[idx] -= epsilon
        s_minus = np.maximum(0.01, np.sum(q_minus))
        if s_minus < 0.01:
            # Avoid NaN, skip calculation for negative sum
            continue
        c_minus = _fft_convolve(q_minus)
        pos_cost_minus = 2 * n_val * np.max(c_minus) / (s_minus ** 2)
        
        # Approximate derivative
        der = (pos_cost_plus - pos_cost_minus) / (2 * epsilon)
        grad[idx] = der * (np.floor(total_sum + 100) - np.sum(q)) * 5.0
        
    # Constrain gradient to be more than a threshold
    if np.max(grad) < 0.001:
        return None
        
    return grad
