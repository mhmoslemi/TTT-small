So `dc[k]/da[j] = a[k-j] + a[2j-k]` (with the understanding that terms outside [0,n-1] are 0, and if k-j = 2j-k = j (i.e., k=2j), it's `2*a[j]`).

Actually, let me be even more careful. `c[k] = sum_{i: 0<=i<n, 0<=k-i<n} a[i] * a[k-i]`.

The valid range for i is `max(0, k-(n-1)) <= i <= min(n-1, k)`.

`dc[k]/da[j]`:
- Term where i=j (if j is in valid range): contributes `a[k-j]`
- Term where k-i=j, i.e., i=k-j (if k-j is in valid range): contributes `a[j]`
- If j = k-j (i.e., k=2j), these are the same term, so total contribution is `2*a[j]` (or just `a[j]` if we count it once... no, in the sum, when i=j=k-j, the term is `a[j]*a[j] = a[j]^2`, and its derivative is `2*a[j]`).

So in general: `dc[k]/da[j] = a[k-j] * 1_{valid} + a[2j-k] * 1_{valid}` where `1_{valid}` means the index is in [0, n-1].

And `k-j` is valid means `0 <= k-j < n`, i.e., `k-n+1 <= j <= k`.
And `2j-k` is valid means `0 <= 2j-k < n`, i.e., `k/2 <= j < (k+n)/2`.

For the log-sum-exp approximation of max:
`L = (1/beta) * log(sum_k exp(beta * c[k]))`
`dL/da[j] = (1/beta) * sum_k exp(beta*c[k]) * dc[k]/da[j] / sum_k exp(beta*c[k])`
`= sum_k w[k] * dc[k]/da[j]` where `w[k] = exp(beta*c[k]) / sum_m exp(beta*c[m])`.

So the gradient is a weighted sum of the "shifted" versions of a.

This is actually a nice structure: the gradient at position j is a weighted average of `a[k-j]` and `a[2j-k]` over different k, with weights proportional to `exp(beta * c[k])`.

        h2 = conv_wa[0:2*n-2:2]  # h2[j] = conv_wa[2j]
        h = max(0, h1 + h2)
        h /= h.max()
        
        # Line search
        for alpha in [alpha0, alpha0*2, alpha0*4, ...]:
            a_new = normalize(a * exp(-alpha * h))
            sc = score(a_new, L)
            if sc < score_val:
                accept
                break
        
        a = a_new
    
    return best_a, best_score

def _next_pow2(x):
    """Next power of 2 >= x."""
    L = 1
    while L < x:
        L <<= 1
    return L

def _fft_score(a, L=None):
    """Compute (score, convolution) for a with sum=1."""
    n = len(a)
    if L is None:
        L = _next_pow2(2 * n - 1)
    F = np.fft.rfft(a, L)
    c = np.fft.irfft(F * F, L)[:2*n-1]
    c = np.maximum(c, 0.0)
    sc = float(2.0 * n * c.max())
    return sc, c

def _normalize(a, floor=1e-15):
    """Clip to [0, 1000], ensure sum = 1."""
    a = np.clip(a, 0.0, 1000.0)
    s = a.sum()
    if s <= 0 or not np.isfinite(s):
        return None
    a = a / s
    a = np.maximum(a, floor)
    a = a / a.sum()
    return a

def _gradient(a, c, L, top_k=10, beta=50.0):
    """
    Compute the "gradient" h for multiplicative update.
    Uses top-K or softmax weighting on the convolution.
    Returns h (normalized to max=1).
    """
    n = len(a)
    conv_len = 2 * n - 1
    
    if top_k is not None and top_k < conv_len:
        # Top-K approach
        kth = np.argpartition(c, -top_k)[-top_k:]
        max_c = c.max()
        # Exponential weights based on gap from max
        gaps = max_c - c[kth]
        scale = max(max_c * 0.05, 1e-10)
        w = np.exp(-gaps / scale)
        w = w / w.sum()
        # Place weights at correct positions
        w_full = np.zeros(L)
        w_full[kth] = w
    else:
        # Softmax over all positions
        max_c = c.max()
        if max_c < 1e-15:
            return np.ones(n) / n
        w_full = np.exp(beta * (c - max_c))
        w_full = np.concatenate([w_full, np.zeros(L - conv_len)])
        w_sum = w_full.sum()
        if w_sum <= 0:
            return np.ones(n) / n
