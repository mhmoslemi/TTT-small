Idea: **Multiplicative Update Method (MUM)**

Instead of using Adam (which can push values negative, requiring clipping), use a purely multiplicative update:
a_new[m] = a[m] * exp(-eta * g[m])

where g[m] is the gradient (or subgradient) of the objective. This naturally maintains non-negativity and has nice convergence properties for certain problems.

The update becomes:
a_new[m] = a[m] * exp(-eta * 2n/S^2 * (2*a[k*-m] - 2*M))
         = a[m] * exp(-4*eta*n/S^2 * (a[k*-m] - M))

For the soft-max version:
a_new[m] = a[m] * exp(-4*eta*n/S^2 * (sum_k w_k * a[k-m] - M_w))

This is a "repulsion" update: elements that are close to the peak positions (in the flipped sense) get reduced, and others get increased.

The advantage of MUM over Adam:
1. No clipping needed (always non-negative)
2. Better conditioned for sparse solutions
3. The step size adapts naturally (large elements get smaller updates)

The disadvantage:
1. Can be slow to converge
2. The exponential can underflow

To mitigate underflow, I can normalize after each step: a = a / a.max() * target_max.

Let me try a hybrid: use MUM for the first few phases (when the solution is far from optimal) and switch to Adam for the fine-tuning.

Actually, let me think about another approach: **Coordinate Descent / Block Updates**.

The idea is to update one "block" of variables at a time. For example, divide the sequence into K blocks, and in each iteration, update one block optimally (or near-optimally) while keeping the others fixed.

For a single block update: fix all elements except block j, and minimize the objective over block j. This is a smaller problem (1/K the size) and can be solved more accurately.

But the objective is still non-convex (max of quadratics), so this doesn't help much.

Let me try yet another approach: **Spectral Method**.

The convolution a * a has Fourier transform |A(ω)|^2 where A is the DTFT of a. So max(conv(a,a)) = max_ω |A(ω)|^2 / (2π) (up to constants). Wait, that's for the circular convolution. For the linear convolution, it's more complicated.

Actually, for the linear convolution, we can embed a in a zero-padded sequence of length 2n-1 and compute the circular convolution. Then the DFT gives the "spectrum" of the linear convolution.

But minimizing the peak of |A(ω)|^2 is the "flat spectrum" or "low PSL" problem, which is NP-hard in general. However, for the non-negative case with fixed support, there might be better structure.

    sc, aa = optimize_phase(best_a, t1, rng, lr0=0.1, topk=8, patience=150, temp_frac=0.5)
    if sc < best_score:
        best_score, best_a = sc, aa
    print(f"Phase 1: {best_score:.6f} ({time.monotonic() - start:.0f}s)")
    # Phase 2: medium
    t2 = start + 0.40 * total_time
    sc, aa = optimize_phase(best_a, t2, rng, lr0=0.03, topk=16, patience=300, temp_frac=0.2)
    if sc < best_score:
        best_score, best_a = sc, aa
    print(f"Phase 2: {best_score:.6f} ({time.monotonic() - start:.0f}s)")
    # LP refinement
    if time.monotonic() < deadline - 60.0:
        a_lp = lp_refine(best_a, 60.0)
        c_lp = fast_self_conv(a_lp)
        S_lp = float(a_lp.sum())
        sc_lp = compute_score(n, c_lp, S_lp)
        print(f"LP: {sc_lp:.6f}")
        if np.isfinite(sc_lp) and sc_lp < best_score:
            best_score, best_a = sc_lp, np.clip(a_lp, 0.0, 1000.0)
    # Phase 3: fine
    t3 = start + 0.70 * total_time
    if time.monotonic() < t3:
        sc, aa = optimize_phase(best_a, t3, rng, lr0=0.005, topk=32, patience=500, temp_frac=0.1)
        if sc < best_score:
            best_score, best_a = sc, aa
    print(f"Phase 3: {best_score:.6f} ({time.monotonic() - start:.0f}s)")
    # Phase 4: ultra-fine
    sc, aa = optimize_phase(best_a, deadline, rng, lr0=0.001, topk=48, patience=800, temp_frac=0.05)
    if sc < best_score:
        best_score, best_a = sc, aa
    print(f"Phase 4: {best_score:.6f} ({time.monotonic() - start:.0f}s)")
    out = [float(max(0.0, min(1000.0, x))) for x in best_a]
    verified = float(evaluate_sequence(out))
    print(f"FINAL: internal={best_score:.6f}, verified={verified:.6f}, n={n}, t={time.monotonic() - start:.0f}s")
    return out
