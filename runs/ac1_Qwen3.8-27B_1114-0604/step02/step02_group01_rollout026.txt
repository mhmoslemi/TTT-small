```python
    """Solve min a^T A a s.t. a >= 0, sum(a) = 1 using active set."""
    free = np.ones(n, dtype=bool)
    a = np.zeros(n)
    
    for _ in range(max_active_set_iters):
        if not free.any():
            break
        idx = np.where(free)[0]
        A_sub = A[np.ix_(idx, idx)]
        b_sub = np.ones(len(idx))
        try:
            a_sub = np.linalg.solve(A_sub, b_sub)

            a_sub = np.linalg.lstsq(A_sub, b_sub, rcond=None)[0]
        norm = a_sub.sum()
        if abs(norm) < 1e-15:
            a_sub = np.ones(len(idx)) / len(idx)
        else:
            a_sub = a_sub / norm
        
        a[idx] = a_sub
        # Check if all free variables are non-negative
        if (a_sub >= -1e-10).all():
            # Clamp small negatives
            a[np.maximum(a_sub, 0)] = ... # careful

        # Find the most negative variable and fix it
        worst = idx[np.argmin(a_sub)]
```

```python
def optimize_softmax(a, tau_init=1.0, tau_final=50.0, n_iters=5000, lr_init=0.1):
    """Optimize using soft-max approximation with FISTA."""
    n = len(a)
    a = a.copy()
    a = np.maximum(a, 0)
    a /= a.sum()
    
    best_a = a.copy()
    best_score = compute_score(a)
    
    # FISTA variables
    y = a.copy()
    t = 1.0
    
    for it in range(n_iters):
        # Anneal tau
        progress = it / n_iters
        tau = tau_init + (tau_final - tau_init) * progress**2
        
        # Compute Q = conv(a, a)
        Q = autocorr_fft(a)
        
        # Compute softmax weights
        tau_Q = tau * Q
        tau_Q -= tau_Q.max()  # numerical stability
        p = np.exp(tau_Q)
        p /= p.sum()
        
        # Compute gradient: 2 * (A_p * a)
        grad = 2.0 * hankel_matvec(p, a)
        
        # FISTA step
        t_new = (1 + np.sqrt(1 + 4*t*t)) / 2
        y = a + ((t-1)/t_new) * (a - y)
        y = np.maximum(y - lr * grad, 0)
        s = y.sum()
        if s < 1e-10:
            y = a
        else:
            y = project_simplex(y)
        
        a_new = y
        t = t_new
        
        # Evaluate and update best
        score = compute_score(a_new)
        if score < best_score:
            best_score = score
            best_a = a_new.copy()
        
        # Restart FISTA every 100 iterations (helps with non-convexity)
        if (it+1) % 100 == 0:
            y = a_new.copy()
            t = 1.0
        
        a = a_new
    
    return best_a, best_score
```

```python
# --- Helper functions ---

def _fft_convolve(a):
    """Full linear convolution a*a via FFT."""
    n = len(a)
    size = 1 << (2*n - 1).bit_length()
    F = np.fft.rfft(a, size)
    return np.fft.irfft(F * F, size)[:2*n-1]

def _hankel_mv(p, a):
    """Compute r[i] = sum_j p[i+j]*a[j] for i=0..n-1 using FFT."""
    n = len(a)
    L = 1 << (n + len(p) - 1).bit_length()
    A = np.fft.rfft(a, L)
    P = np.fft.rfft(p, L)
    R = np.fft.irfft(np.conj(A) * P, L)
    return R[:n]

def _project_simplex(v):
    """Project v onto {x >= 0, sum(x) = 1}."""
    n = len(v)
    if n == 0:
        return v
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.nonzero(u * np.arange(1, n+1) > (cssv - 1))[0][-1]
    theta = (cssv[rho] - 1) / (rho + 1.0)
    return np.maximum(v - theta, 0)

    n = len(a)
    s = a.sum()
    if s < 0.01:
        return np.inf
    Q = _fft_convolve(a)
    return 2.0 * n * Q.max() / (s * s)
```

Let me also think about **the dual approach** more seriously.

The problem: min_a max_k Q_k(a) s.t. sum(a)=1, a>=0.

By minimax (von Neumann, in the compact convex case):
min_{a in simplex} max_k Q_k(a) = max_{p in simplex} min_{a in simplex} sum_k p_k * Q_k(a)

The inner problem: min_a a^T A_p a s.t. a in simplex, where A_p = sum_k p_k M_k.

If A_p is PSD, this is a convex QP. The solution (in the interior) is:
a = A_p^{-1} * 1 / (1^T A_p^{-1} * 1)

We can compute A_p * x using the Hankel matvec trick in O(n log n). And A_p^{-1} * 1 can be computed using CG (if A_p is SPD) in O(n^{1.5} log n) total (n^{1.5} iterations, each O(n log n)).

For the active set: if the unconstrained solution has negative components, we fix them to 0 and re-solve.

The outer problem (max over p) can be solved using:
- Gradient ascent: p_k <- p_k + eta * (Q_k(a) - t) where t = sum_k p_k Q_k(a) (the current value).
- Or: p_k <- p_k * exp(eta * Q_k(a)) (exponential / MWU update).

This gives us a complete primal-dual algorithm:

```
Initialize a (e.g., uniform) and p (e.g., uniform).
Iterate:
  1. Given p, solve inner QP to get a*.
  2. Compute Q_k(a*) for all k.
  3. Update p: p_k <- p_k * exp(eta * Q_k(a*)). Normalize.
  4. Check convergence.
```

The advantage of this approach:
- The inner QP is a well-defined optimization problem with a known structure.
- The outer update is simple and has good theoretical properties.
- We can use the FFT-based matvec for the inner solve.

The disadvantage:
- The inner QP might be non-convex (if A_p is not PSD).
- The CG-based solve might be slow if A_p is ill-conditioned.

Let me estimate the number of outer iterations needed. The MWU convergence rate is O(1/epsilon) iterations to get an epsilon-approximate solution (in the gap between primal and dual objectives). For epsilon = 0.01 (relative), we need about 100 iterations. Each inner solve takes maybe 100-500 CG iterations, each O(n log n). Total: 100 * 500 * 80K = 4e9 flops ≈ a few seconds. Very feasible!

This is much more efficient than the soft-max FISTA approach (which needs thousands of iterations).

Let me implement this primal-dual approach.

**Key implementation details:**

1. Inner QP solve: min a^T A_p a s.t. a >= 0, sum(a) = 1.
   - Compute the unconstrained solution: solve A_p * x = 1, then a = x / sum(x).
   - If all a[i] >= 0, done.
   - Otherwise, use active set: fix the most negative component to 0, re-solve on the reduced system.
   - For the solve, use CG with the FFT-based matvec, or a direct method if the system is small.

2. For CG to work, A_p needs to be SPD. If it's not, add a small regularization: (A_p + eps*I).
   - Alternatively, use the "symmetrized" CG (which works for symmetric indefinite matrices but may not converge).
   - Or, use a direct solve with the structure of A_p (Hankel matrix).
