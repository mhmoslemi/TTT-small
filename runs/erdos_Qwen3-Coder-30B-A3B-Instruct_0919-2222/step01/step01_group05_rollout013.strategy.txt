### 1. Mathematical reformulation

Write `w = Σ_i h_i = n/2` (because `dx·w = 1`).  
For any shift `d`

\[
C_5(d)=w - \!\!\sum_{i} h_i h_{i+d},
\qquad
C_5(h)=\max_d C_5(d).
\]

Thus we must **maximise the minimum auto‑correlation**  

\[
\min_{d}\sum_i h_i h_{i+d}.
\]

The product term is bilinear → non‑convex.  We will treat it with a **McCormick envelope** (linear outer approximation) to obtain a tractable linear programme (LP) that gives a *lower bound* on the achievable `C5` and, more importantly, a useful initial `h`.

### 2. Convex‑relaxation LP (first‑stage initializer)

**Variables**

* `h_i ∈ [0,1]`  (continuous) for `i = 0,…,n−1`.
* `u_{i,d}`   approximates `h_i·h_{i+d}` on the overlapping region for each shift `d∈{-n+1,…,n-1}` (only indices where both `i` and `i+d` are inside `[0,n-1]`).
* `t` – the scalar upper bound on all `C5(d)` (the objective to minimise).

**Constraints**

1. **Integral**  Σ_i h_i = n/2.  
2. **Box**    0 ≤ h_i ≤ 1.  
3. **McCormick envelope** (valid for `h_i, h_j ∈[0,1]`):  

   ```
   u_{i,d} ≥ 0
   u_{i,d} ≤ h_i
   u_{i,d} ≤ h_{i+d}
   u_{i,d} ≥ h_i + h_{i+d} – 1
   ```

4. **Definition of C5(d)** – for each shift `d`

   ```
   s_d = Σ_{i} u_{i,d}
   t  ≥ w – s_d                (since C5(d) = w – s_d)
   ```

5. **Objective** – minimise `t`.

All constraints are linear → a standard LP.  Solve with **cvxpy** (solver ECOS or SCS).  The LP is small enough for `n ≤ 60` (≈ n·(2n‑1) auxiliary variables ≈ 7 000 for n = 60).

**Outcome** – a fractional vector `ĥ` (often already near a binary pattern) and a lower bound `t*`.  
We **evaluate the true C5** on `ĥ` (using the exact product, not the envelope).  If it already beats the record we can return it; otherwise we use `ĥ` as a seed for the subsequent non‑convex refinements.

### 3. Binary rounding & deterministic worst‑shift swap hill‑climber

Binary vectors (0/1) with exactly `n/2` ones are natural because they maximise the term `w – Σ h_i h_{i+d}` at `d=0` (zero contribution) while exposing the trade‑off for other shifts.

**Rounding**  
Take the `n/2` largest components of `ĥ` and set them to 1, the rest to 0 → `h⁰`.  Compute its `C5`.

**Worst‑shift identification**  
Compute the full correlation `corr = np.correlate(h,1-h,'full')`.  
Find the shift `d*` where `corr` attains the maximum (i.e. the worst shift).

**Swap move** – *targeted to d⁎*  

* Find any index `i` with `h_i = 1` and `h_{i+d*}=0`.
* Find any index `j` with `h_j = 0` and `h_{j+d*}=1`.
* Swapping `h_i ↔ h_j` strictly reduces `C5(d*)` by at least one unit (and never increases any shift by more than one), therefore never worsens the max unless a different shift becomes the new worst.  

**Greedy loop**  

```
repeat
    compute worst shift d*
    if a beneficial (i,j) swap exists:
         perform the swap
    else
         break   # local optimum for binary case
```

Each iteration costs O(n²) to test all candidate pairs (≈ 400 for n = 42), trivial in time.  The loop stops when no swap can improve the current worst shift.  The result is a **locally optimal binary pattern**.

### 4. Fractional mass‑transfer simulated annealing (global escape)

Binary local optimum may still be sub‑optimal because the true optimum can be fractional.  We now perform a **simulated‑annealing (SA) phase** that works directly on continuous `h`.

**Move definition** – transfer a small amount `δ` from one index to another while keeping the sum exact:

1. Pick two distinct indices `i, j`.  
2. Choose `δ ∈ (0, δ_max]` where  
   `δ_max = min( h_i, 1‑h_j, Δ )`.  
   (`Δ` is a decreasing schedule value, e.g. `Δ=0.2` at the start, halved every 200 SA steps).
3. Set `h_i ← h_i – δ`, `h_j ← h_j + δ`.  
4. Clip to `[0,1]` (the clipping never violates the sum because we limited δ).

**Objective** – true `C5(h)`.  
**Acceptance** – Metropolis rule: accept if `C5_new ≤ C5_curr`; otherwise accept with probability `exp( − (C5_new‑C5_curr)/T )`, where `T` is the annealing temperature.

**Cooling schedule** – geometric: `T ← T0 * α^k` (e.g. `T0 = 0.02`, `α = 0.995`).  The temperature is tied to the current best `C5` (e.g. `T0 = 0.05 * C5_initial`) so that early exploration tolerates modest increases.

**Termination** – stop when time budget for SA is exhausted (≈ 30 % of total) or after a fixed number of iterations without improvement.

Because each SA step needs a full correlation recomputation (`O(n²)`), we keep `n` modest (≤ 60).  The SA stage can also *re‑discover* binary‑like structures; we keep the best vector found (binary or fractional).

### 5. Projected sub‑gradient (or smoothed‑max) refinement

The objective `C5(h)` is a pointwise max of affine functions `w‑Σ_i h_i h_{i+d}`.  Its sub‑gradient for a given worst shift set `D*` (all `d` attaining the max) is:

\[
\frac{∂C_5}{∂h_i}= -\sum_{d∈D*}
\Bigl[\,\mathbf{1}_{\{i+d\text{ in range}\}}\;h_{i+d}
      + \mathbf{1}_{\{i-d\text{ in range}\}}\;h_{i-d}\Bigr].
\]

**Projected update**  

```
g = subgradient(h)                     # vector of size n
h ← h – η·g        (η = step size, e.g. η = 0.1 initially, decay ~1/√iter)
Project h onto the simplex {h∈[0,1]^n : Σh = n/2}
```

The projection onto a box plus an equality hyperplane can be performed in two passes:

1. **Shift to satisfy the sum** – subtract the mean excess `μ = (Σh – n/2)/n` from all entries.  
2. **Clamp** – clip to `[0,1]`; if clipping changes the sum, re‑adjust by distributing the residual uniformly over the unclipped entries (standard Euclidean projection onto simplex with box constraints).

We iterate this gradient descent for a few hundred steps (or until the improvement falls below 1e‑7).  Because the sub‑gradient points directly at the worst shifts, this phase refines the fractional solution obtained from SA and can shave the final few 10⁻⁵ needed to beat the record.
