In the discrete implementation the integral is evaluated as

```
dx = 2.0/n
corr = np.correlate(h, 1-h, mode='full') * dx
C5 = np.max(corr)
```

The optimisation problem is non‑convex because each shift contributes a concave quadratic term, but we can attack it with a **smooth‑max + projected gradient** scheme, followed by a short **local exchange** phase. This approach is fundamentally different from the simulated‑annealing routine that was used previously.

--------------------------------------------------------------------
### 1.  Reformulation

For a fixed shift `s` (integer offset, `s∈{-(n-1)…(n-1)}`) let  

\[
P_s(h)=\sum_{i:\,0\le i,i+s<n}h_i\,h_{i+s}
\]

(the discrete analogue of \(\int h(x)h(x+s)\,dx\)).  
Because the total mass `M = ∑ h_i = n/2` is constant,

\[
C_s(h)=\sum_i h_i - P_s(h)=M-P_s(h).
\]

Hence  

\[
C_5(h)=\max_s C_s(h)=M-\min_s P_s(h).
\]

Minimising `C_5` is equivalent to **maximising** the minimal auto‑correlation  

\[
t(h)=\min_s P_s(h).
\]

--------------------------------------------------------------------
### 2.  Smooth approximation of the max

Direct sub‑gradient on `max_s C_s` is noisy.  We replace the hard max by a **soft‑max** (log‑sum‑exp) with a temperature β > 0:

\[
F_\beta(h)=\frac1\beta\log\!\Bigl(\sum_{s}e^{\beta C_s(h)}\Bigr) .
\]

*For β→∞,  \(F_\beta\)  converges to the true max.*  
The gradient of `F_β` is a convex combination of the gradients of the individual `C_s`:

\[
\nabla F_\beta(h) = \sum_{s} w_s \,\nabla C_s(h), \qquad
w_s = \frac{e^{\beta C_s(h)}}{\sum_{t}e^{\beta C_t(h)}} .
\]

For a given shift `s` the derivative of `C_s` w.r.t. component `h_i` is

\[
\frac{\partial C_s}{\partial h_i}= 
\begin{cases}
1 - h_{i+s} &\text{if }0\le i+s<n,\\[4pt]
1           &\text{otherwise.}
\end{cases}
\]

Thus the gradient can be assembled efficiently by a single pass over all shifts.

--------------------------------------------------------------------
### 3.  Projection onto the feasible set  

After a gradient step we must enforce  

* box constraints  `0 ≤ h ≤ 1`,
* the linear equality  `∑ h = n/2`.

The Euclidean projection onto the intersection of a hyperplane and the box is a **water‑filling** problem:

Find a scalar λ such that  

\[
x_i = \operatorname{clip}\bigl(y_i - \lambda,\;0,\;1\bigr),\qquad
\sum_i x_i = n/2 .
\]

Because the clipped sum is monotone decreasing in λ, λ can be found by a short binary search:

```
low  = np.min(y) - 1.0          # guarantees all x_i = 1  → sum = n
high = np.max(y)                # guarantees all x_i = 0  → sum = 0
repeat ~50 times:
    mid = (low+high)/2
    x   = np.clip(y-mid,0,1)
    if x.sum() > n/2: low  = mid
    else:             high = mid
```

The final `x` is the projected point and satisfies the constraints up to machine precision.

### 4.  Gradient descent scheme

```

    record best C5 obtained so far (using provided evaluator)
```
