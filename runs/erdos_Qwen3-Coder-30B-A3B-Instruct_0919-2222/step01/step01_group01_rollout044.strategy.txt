### 2. Smooth surrogate for `max`

The non‑differentiable `max` is replaced by the **log‑sum‑exp** (soft‑max) with a temperature parameter `β>0`:

\[
F_{\beta}(h)=\frac{1}{\beta}\log\Bigl(\sum_{s} \exp\bigl(\beta\,C_s(h)\bigr)\Bigr),\qquad
C_s(h)=\frac{2}{n}\Bigl(S-\!P_s(h)\Bigr),
\]

where  

* `S = ∑ h_i = n/2` (constant),  
* `P_s(h) = ∑_{i:0≤i+s<n} h_i h_{i+s}` is the auto‑product for shift `s`.

When `β→∞`, `F_β(h)` → `max_s C_s(h)`.  
Using a moderate `β` yields a **smooth, differentiable objective** whose gradient can be written analytically, enabling efficient projected‑gradient steps.

---

### 3. Analytic gradient of the surrogate

For a single shift `s`

\[
\frac{\partial C_s}{\partial h_i}= \frac{2}{n}
\begin{cases}
1-h_{i+s}, & 0\le i+s<n,\\[4pt]
1, & \text{otherwise}.
\end{cases}
\]

Define the soft‑max weights  

\[
w_s=\frac{\exp(\beta C_s)}{\sum_{t}\exp(\beta C_t)} .
\]

The gradient of `F_β` is the weighted sum of the per‑shift gradients:

\[
\nabla F_{\beta}(h)=\sum_{s} w_s \,\nabla C_s(h) .
\]

Because `S` is constant, the term “`1`” appears for **every** index `i` in every shift, so we can compute the gradient efficiently:

1. Initialise `g = np.zeros(n)`.  
2. For each shift `s`:  
   * add `w_s` to **all** entries of `g` (the constant part).  
   * subtract `w_s * h_{i+s}` from the overlapping entries `i` (the `-h_{i+s}` part).  

The loop is `O(n²)` but with `n≤100` it is negligible; a pure‑Python implementation is fast enough, and the whole gradient computation is vectorised using NumPy.

### 4. Projection onto the feasible set

After a gradient step `h←h−η∇F_β` we must enforce  

* box constraints `0 ≤ h_i ≤ 1`,  
* the linear equality `∑ h_i = n/2`.

This is the Euclidean **projection onto a capped simplex**.  
The projection can be performed by a **single one‑dimensional root‑finding** for a Lagrange multiplier `λ`:

* Define `proj_i(λ)=clip(h_i−λ,0,1)`.  
* The sum `S(λ)=∑ proj_i(λ)` is a monotone decreasing piecewise‑linear function of `λ`.  
* Find `λ*` such that `S(λ*) = n/2`.  

A binary search on `λ` in the interval `[min(h)−1, max(h)]` converges in ≤ 50 iterations to machine precision.  The resulting vector `proj_i(λ*)` is the projected `h`.

### 6. Warm‑start via LP relaxation (optional, high‑impact)

A **linear program** provides a provably optimal lower bound on the minimal product sum `t = min_s P_s(h)`.  
Formulation:

* Variables: `h_i ∈ [0,1]`, `w_{i,s} ∈ [0,1]` (intended to model `h_i·h_{i+s}`), scalar `t`.  
* For each overlapping pair `(i,i+s)`:  
  * `w_{i,s} ≤ h_i`, `w_{i,s} ≤ h_{i+s}`, `w_{i,s} ≥ h_i + h_{i+s} - 1`.  (McCormick envelope – exact when `h_i` is binary, a tight convex hull for `[0,1]`).  
* Sum constraint: `∑ h_i = n/2`.  
* For every shift `s`: `∑_{i} w_{i,s} ≥ t`.  
* Objective: **maximize** `t`.

Because the LP is convex, any optimal solution yields a **feasible** `h` (the `w`’s are merely auxiliary).  Solving it with `cvxpy` + `CBC` (or `ECOS`) is fast for `n≤70` (≈ 5000 variables).  

The LP solution is used as an **initial point** for the gradient phase: after solving, we simply project the `h` from the LP onto the box (it already satisfies the sum).  Empirically this starting point is far closer to the global optimum than the random or uniform initialisations.

### 7. Local exchange polishing (post‑gradient)

When the gradient phase terminates, we have a high‑quality continuous vector `h`.  A quick **pair‑exchange** heuristic can still shave off a few hundredths of the bound:

1. Pick two indices `i, j` uniformly at random.  
2. Propose moving a small amount `δ = min(ε, h_i, 1−h_j)` from `i` to `j` (with `ε≈0.02`).  
3. Project the altered vector with the same capped‑simplex routine (or simply adjust the global sum because the move conserves total mass).  
4. Accept the move if it reduces the true `C_max`; otherwise reject (or accept with a tiny annealing probability that decays very fast).  

We run this exchange loop for a fixed number of trials (e.g. 10 000) or until the elapsed time drops below a final threshold (≈ 5 s).  This step is essentially the same move set used by the original annealer but now **guided** by a high‑quality starting point.
