**Goal**  
Find a step function `h` on `[0,2]` (discretised with `n` points, `0 ≤ h[i] ≤ 1`, `∑h = n/2`) that minimizes  

```
C₅(h) = max_k  ∫₀² h(x)·(1‑h(x+k)) dx
```

In the discrete setting the objective is  

```
C₅(h) = dx · max_s  [ Σ_i h[i] – Σ_i h[i]·h[i+s] ] ,
dx = 2/n ,  s = -(n‑1)…(n‑1) .
```

Equivalently we must maximise the *minimum* auto‑correlation  

```
p(s) = Σ_i h[i]·h[i+s]          (zero‑padded outside the interval)
```

because  

```
C₅ = dx·( n/2 – min_s p(s) ) .
```

The problem is highly non‑convex, but the structure of the objective admits a very effective **smooth‑max + projected gradient** scheme, complemented by a few global‑search tricks. The plan below is a complete algorithmic pipeline that differs fundamentally from the previous simulated‑annealing approach.

### 1.  Core optimisation routine – Smoothed‑max gradient descent  

1. **Pre‑compute all correlations**  
   * `prod = np.correlate(h, h, mode='full')` gives the vector `p(s)` for all shifts.  
   * `C = sum_h – prod` (where `sum_h = n/2` is constant).  

2. **Smooth approximation of the max**  
   Choose a temperature `β > 0`.  Define  

   ```
   w_s = exp( β·(C_s – C_max) )            # C_max = max_s C_s
   w_s ← w_s / Σ_t w_t                     # softmax weights, numerically stable
   ```

   The smoothed objective is  

   ```
   F(h) = Σ_s w_s · C_s        →   F → max_s C_s  as β → ∞ .
   ```

3. **Gradient of the smoothed objective**  
   For a shift `s` the derivative of `C_s` w.r.t. `h[i]` is  

   ```
   dC_s/ dh[i] = 1                    if i+s is outside [0,n‑1]
               = 1 – h[i+s]          otherwise.
   ```

   The full gradient is the weighted sum  

   ```
   g[i] = Σ_s w_s · dC_s/ dh[i] .
   ```

   This can be built in `O(n²)` by a simple loop over shifts:
   * start with `g = Σ_s w_s` (adds `1` for every shift to every component),
   * for each shift `s` subtract `w_s·h[i+s]` on the overlapping indices only.

4. **Projected gradient step**  
   *Update*  

   ```
   h' = h – η·g                      (η = step‑size)
   ```

   then **project** `h'` onto the feasible set  

   ```
   S = { x ∈ ℝⁿ : 0 ≤ x_i ≤ 1 , Σ x_i = n/2 } .
   ```

   The projection is a Euclidean projection onto a capped simplex and can be performed by a fast 1‑D root‑find for the Lagrange multiplier `λ`:

   ```
   find λ such that  Σ_i clip( h'_i – λ , 0 , 1 ) = n/2 .
   x_i = clip( h'_i – λ , 0 , 1 ) .
   ```

   A binary search on `λ` converges in ≤ 50 iterations (the function is monotone).

5. **Parameter schedules**  

   * **Step‑size** – start with `η₀ ≈ 0.1` (scaled by `dx`) and decay as  

     ```
     η_t = η₀ / sqrt(t+1) .
     ```

   * **Temperature** – start with a low temperature (`β₀ ≈ 3`) to smooth the landscape, then **anneal**:  

     ```
     β_t = β₀ + (β_max – β₀)·(t / T)   (linear ramp up)
     ```

     where `β_max ≈ 30‑50` and `T` is the total number of gradient iterations (e.g. `T=2000`).  This “soft‑max annealing” mimics the max‑operator gradually while avoiding early‑stage plateaus.
