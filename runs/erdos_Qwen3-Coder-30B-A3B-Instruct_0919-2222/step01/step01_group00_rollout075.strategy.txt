**Goal** – Produce a step‑function `h` on `[0,2]` (discretised as a vector `h[i]`) that satisfies  

* `0 ≤ h[i] ≤ 1` for every entry,  
* `∑ h[i]·dx = 1`  (`dx = 2/n`),  

and minimises  

```
C5(h) = max_k  ∫_0^2 h(x)·(1‑h(x+k)) dx
```

The evaluator uses a full‑mode correlation `np.correlate(h, 1‑h)·dx`.  
The known best bound is ≈ 0.38224; we aim for ≤ 0.3807.

The following plan departs from the earlier SLSQP‑only approach and combines a **low‑dimensional global search**, an **efficient projection onto the feasible set**, a **smooth surrogate for the max**, and a **multi‑stage refinement** that gradually lifts the resolution of the representation.

### 1. Problem‑specific parametrisation (piecewise constant)

1. **Choose a modest number of steps `S`.**  
   - Typical values: `S ∈ {8, 10, 12, 14}`.  
   - Each step occupies `seg_len = n_points // S` samples.  
   - `n_points` is later chosen as a multiple of `S` (e.g. `n_points = 140` for `S=14`).

2. **Define the decision variables** as the heights of the steps:
   ```
   h_step = [s_0, s_1, …, s_{S‑1}],   0 ≤ s_j ≤ 1
   ```
   The full discretised vector is built by repeating each `s_j` `seg_len` times.

3. **Linear equality constraint** derived from the integral:
   ```
   (dx·seg_len)·∑_j s_j  =  1   →   ∑_j s_j = S/2
   ```
   Hence the average height must be exactly ½.  This is a **capped simplex** constraint (each component bounded in `[0,1]` and total sum fixed).

4. **Optional symmetry** (optional but useful):  
   Force `s_j = 1 - s_{S-1‑j}` or `s_j = s_{S‑1‑j}` if the problem’s optimal shape appears symmetric.  
   This halves the number of free variables and reduces search space.  Symmetry can be turned on/off after a quick experimental test.

### 2. Efficient projection onto the capped simplex

When a candidate vector `v` (e.g. after a DE mutation or a gradient step) does not satisfy the equality and box constraints, we **project** it onto the feasible set:

1. **Shift**: set `v' = v + λ` where λ is a scalar.
2. **Clamp**: `w = clip(v', 0, 1)`.
3. Choose λ such that `∑ w = S/2`.  

   This is a one‑dimensional root‑finding problem that is monotone in λ.  
   - Use a **bisection** on λ in the interval `[‑max(v), 1‑min(v)]`.  
   - In each bisection step compute `∑ clip(v+λ, 0, 1)`.  
   - Converge to machine precision (`≈ 1e‑10`) within ≤ 30 iterations (O(S) work).

All optimisation steps will call this projector, guaranteeing feasibility *exactly* (no penalty needed).

### 3. Fast evaluation of the objective

1. Build the full vector `h_full` from `h_step` via `np.repeat`.  
2. Compute the full‑mode correlation using **FFT** for O(n log n) speed (critical for the many evaluations in global search):

   ```
   H   = np.fft.rfft(h_full)

   corr = np.fft.irfft(H * np.conj(G), n=2*n-1)

   ```
   (The FFT on real data produces exactly the same result as `np.correlate`.)

3. The evaluator returns `C5`.  Because the projection guarantees `∑h·dx=1`, no extra penalty term is required.

### 5. Local refinement with a smooth surrogate

The DE phase yields a decent candidate, but DE’s stochastic nature may stop short of a local optimum.  To polish the solution we switch to **gradient‑based optimisation** on the full discretisation (`n = 140` or `200`).

#### 5.1 Smoothed max objective

Replace the non‑differentiable max by a **log‑sum‑exp** (LSE) with a temperature `τ`:
```
F_τ(h) = τ·log( Σ_k exp( C_k(h) / τ ) )
```
where `C_k(h) = dx·∑_i h[i]·(1 ‑ h[i + shift_k])` (the same correlation values).  
As `τ → 0`, `F_τ → max_k C_k`.  Use a schedule: start with `τ = 0.05` to obtain a smooth landscape, then halve `τ` every few iterations until `τ ≈ 1e‑4`.

#### 5.2 Gradient computation

From the correlation formula we have a **closed‑form gradient** for any shift `k`:
```
∂C_k/∂h[j] = (1 ‑ h[j+k])·dx   (if j+k in range) +
             (‑h[j‑k])·dx       (if j‑k in range)
```
The gradient of `F_τ` is a weighted sum of the per‑shift gradients:
```
∇F_τ = Σ_k w_k·∇C_k,   w_k = exp(C_k/τ) / Σ_j exp(C_j/τ)
```
All operations are vectorised with NumPy, O(n²) cost per iteration (still cheap for n ≤ 200).

#### 5.3 Projected gradient descent (PGD)

1. **Take a step**: `h_new = h – η·∇F_τ` (η – line‑search or fixed small step).  
2. **Project** `h_new` onto the capped simplex (the same projector as in §2).  
3. **Adjust step size** via backtracking (Armijo) to ensure descent of `F_τ`.  
4. Iterate until either the improvement in `C5` falls below `1e‑5` or the allocated time for this stage expires.

Because the projection is exact, the integral constraint stays satisfied throughout.

1. Randomly pick two indices `i, j`.

### 9. Anticipated failure modes & mitigations

| Failure mode | Reason | Mitigation |
|--------------|--------|------------|
| **DE stagnates** (no improvement after many generations) | Too many dimensions or too tight population | Use the staged‑dimensional approach; keep `S` ≤ 14; restart DE with a different random seed after a fixed number of generations. |
| **Projection infeasible** (no λ satisfies sum after clamping) | All components hit bounds 0 or 1, yet required sum impossible | In such a case automatically **redistribute** the excess to interior components: after clamping, if `∑w ≠ target`, spread the difference uniformly among non‑saturated entries (iterative water‑filling). |
| **Gradient step leaves feasible box** | Large η or high τ may push values outside `[0,1]` | Use backtracking line‑search that halves η until projected descent is observed. |
| **Numerical overflow in LSE** (exp of large numbers) | Very large `C_k/τ` for small τ | Subtract `max(C_k)` before exponentiation (standard log‑sum‑exp stabilisation). |
| **FFT aliasing** (wrap‑around) | Using `rfft` without zero‑padding replicates circular convolution, not the required linear correlation | Zero‑pad `h_full` and `1‑h_full` to length `2*n` before the FFT, then keep only the first `2*n‑1` samples (exactly what `np.correlate(...,mode='full')` produces). |
| **Local optimiser violates constraint** | Numerical tolerance may cause slight drift in the equality constraint | After each SLSQP iteration re‑project onto the capped simplex, or enforce the constraint via a high‑weight penalty if projection slows convergence. |
| **Time overrun** | Too many DE generations or PGD iterations | Insert explicit checks `if time.time() - start > budget_s - 2: break` in every outer loop. |
