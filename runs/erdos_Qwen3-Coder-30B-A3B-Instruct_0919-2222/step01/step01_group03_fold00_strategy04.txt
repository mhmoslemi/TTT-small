**1. Problem Reformulation**

- Discretise the interval `[0,2]` into `n` equally spaced points (`dx = 2/n`).  
- Define a vector `h ∈ [0,1]^n` with the linear constraint  
  `∑_{i=0}^{n‑1} h_i = n/2`  (equivalently `∫ h = 1`).  

- For each integer shift `s ∈ {-(n‑1),…,n‑1}` the *overlap* is  

  `f_s(h) = Σ_{i∈I_s} h_i (1 − h_{i+s})`  

  where `I_s = { i | 0 ≤ i < n, 0 ≤ i+s < n }`.  
  The constant to bound is  

  `C₅(h) = dx·max_s f_s(h)`.

Our goal: **minimise** `max_s f_s(h)`.  

**2. Smooth‑max Approximation**

Replace the non‑smooth `max` by a differentiable soft‑max:

```
M_β(h) = (1/β)·log( Σ_s exp( β·f_s(h) ) )
```

As `β → ∞`, `M_β → max_s f_s`. For a moderate `β` the function is smooth, enabling gradient‑based optimisation.

`M_β` can be written as a weighted sum  

`M_β(h) = Σ_s w_s·f_s(h)`  

with softmax weights  

`w_s = exp(β·f_s) / Σ_t exp(β·f_t)`.  
All `w_s ≥ 0` and `Σ_s w_s = 1`.

**3. Analytic Gradient of each `f_s`**

For a fixed shift `s ≥ 0` the overlapping index set is `i = 0,…,n-1‑s`, `j = i+s`.  

```
∂f_s/∂h_i = 1 − h_j          (i ∈ I_s)
∂f_s/∂h_j = −h_i             (j = i+s)
```

For a negative shift the same formula holds with `i` and `j` exchanged.  
For `s = 0` both formulas collapse to `∂f_0/∂h_i = 1 − 2·h_i`.

Thus the gradient of the smooth objective is

```
∇M_β(h) = Σ_s w_s·g_s   where   g_s[i] = {1 − h_{i+s}   if i∈I_s}
                                            {−h_{i‑s}    if i‑s∈I_s}
```

The contribution for each shift can be computed with vectorised slices; no explicit loops over entries are needed once the index pairs `(i,j)` are pre‑computed.

The Euclidean projection onto the intersection of a hyperplane and a box is performed by a 1‑D root‑finding for a Lagrange multiplier `λ`:
