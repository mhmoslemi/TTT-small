### 2.  Formulate the smooth surrogate of `max C(s)`

For a vector `h` define

```
C(s) = target_sum - p(s)          # p(s) = Σ_i h[i]·h[i+s]
```

Introduce a temperature parameter `β > 0` and the soft‑max

```
Fβ(h) = (1/β) * log( Σ_s exp( β·C(s) ) ) .
```

*When β → ∞, `Fβ → max_s C(s)`.*  
For moderate β the function is smooth and its gradient can be written analytically.

Compute for each shift `s` the correlation `p(s)` using a single call to `np.correlate(h, h, mode='full')`.  
Then `C(s) = target_sum - p(s)`.

Define the normalised weights

```
w(s) = exp(β·C(s)) / Σ_t exp(β·C(t)) .
```

The gradient of `Fβ` w.r.t. `h[i]` is the weighted sum of the gradients of each `C(s)`:

```
∂Fβ/∂h[i] = Σ_s w(s) · ∂C(s)/∂h[i] .
```

For a concrete shift `s` the derivative is

```
∂C(s)/∂h[i] =  1                     if i+s is outside [0,n‑1]
                1 - h[i+s]          otherwise .
```

(When `s = 0` the second case reduces to `1 - h[i]`; the formula works uniformly.)

Thus the full gradient can be assembled by looping over all shifts, adding a constant `w(s)` to every entry of the gradient and subtracting `w(s)·h[i+s]` only on the overlapping indices.  In practice:

```
grad = np.zeros(n)
for each shift s:
    grad += w(s)                         # adds w(s) to all i
    overlapping i = max(0,-s) … min(n, n-s)-1
    grad[overlap] -= w(s) * h[overlap + s]
```

This operation is O(n²) but with `n ≤ 100` it is negligible.

### 3.  Projected gradient step

Given a current `h` and a step size `η`:

1. **Gradient descent**: `h̃ = h - η·grad`.  (We are minimising `Fβ`.)
2. **Projection onto the feasible set**  
   The feasible set is the intersection of the box `[0,1]^n` with the hyperplane `Σ h = target_sum`.  
   The Euclidean projection onto this *capped simplex* can be performed by a **simple one‑dimensional root find**:

   *Define*  
   `φ(λ) = Σ_i clip( h̃[i] - λ , 0 , 1 )`.  

   `φ(λ)` is monotone decreasing in `λ`.  
   Find `λ*` such that `φ(λ*) = target_sum`.  
   A binary search on the interval  
   `λ_low = min(h̃) - 1`  (all components become 1)  
   `λ_high = max(h̃)`      (all components become 0)  
   converges in ≤ 50 iterations.  

   Finally set  

   `h_new[i] = clip( h̃[i] - λ* , 0 , 1 )`.

   This yields a point that simultaneously respects the sum constraint and the bounds.

3. **Safeguard**: after projection, force any tiny numerical violations (e.g. values < 1e‑12 or > 1‑1e‑12) back to the exact bound.
