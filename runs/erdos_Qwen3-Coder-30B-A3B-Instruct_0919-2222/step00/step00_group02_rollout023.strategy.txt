**Goal** – produce a step function h on [0,2] with average ½ that minimises  

\[
C_5(h)=\max_{k\in\mathbb Z}\int_0^2 h(x)\bigl(1-h(x+k)\bigr)\,dx
       =\frac{2}{n}\;\max_{k}\; \sum_{i=0}^{n-1}h_i\bigl(1-h_{i+k}\bigr)
\]

for a discretisation of length \(n\) (sampling step \(dx=2/n\)).  
We must return a vector \(h\in[0,1]^n\) with \(\sum_i h_i=n/2\) and the corresponding bound
\(c_5=\max_k\sum_i h_i(1-h_{i+k})\cdot\frac{2}{n}\).

The problem is a non‑convex max‑min quadratic programme.  The best known bound is
\(c_5\approx0.38092\); we aim for a tighter bound (≤ 0.3807) within a 600 s CPU budget.

The strategy consists of three tightly coupled stages:

1. **Exploratory search over problem size**  
2. **Directed binary local optimisation (worst‑shift swaps + simulated annealing)**  
3. **Continuous refinement via projected soft‑max gradient descent**  

Each stage is time‑controlled, re‑initialises automatically, and records the globally best solution.

### 2. Directed binary local optimisation  

All binary searches work on a *balanced* 0/1 vector \(a\in\{0,1\}^n\) with
\(\sum a=n/2\).  Binary vectors are attractive because the overlap count
\(\sum_i a_i(1-a_{i+k})\) is integer and the neighbourhood structure
(*swap a 1 with a 0*) preserves the balance constraint exactly.

#### 2.1. Evaluation routine  

* `corr = np.correlate(a, 1-a, mode='full')` gives the counts for every shift
  \(-n+1\ldots n-1\).  
* `max_cnt = corr.max()` is the integer worst‑overlap for the current vector,
  and the associated shift index `s = corr.argmax() - (n-1)`.

All higher‑level logic works exclusively with `max_cnt`; the final bound is
`c = 2*max_cnt/n`.

#### 2.2. Worst‑shift‑focused swaps  

For the current worst shift \(s\) we can classify the *mismatched* positions:

*If \(s\ge0\)*  
```
i ∈ M₁  ⇔ a[i]=1 and a[i+s]=0          (1‑aligned with a 0)
j ∈ M₀  ⇔ a[j]=0 and a[j+s]=1          (0‑aligned with a 1)
```
*If \(s<0\)* the same definition uses indices `i-s` and `j-s`.

Every swap \((i\in M₁,\,j\in M₀)\) eliminates **two** mismatches for shift \(s\)
and therefore reduces `max_cnt` by at least 2 unless another shift becomes the new
maximum.  This is a powerful descent direction.

Algorithm (inner loop):

1. Compute `M₁` and `M₀` for the current worst shift.  
2. If both sets are non‑empty, pick a random pair \((i,j)\) from them,
   perform the swap, recompute `corr`, and accept the swap **iff**
   `new_max_cnt ≤ current_max_cnt`.  
   If it is accepted, update the current vector and possibly the global best.
3. If at least one set is empty (rare near a local optimum) fall back to a
   *random balanced swap*: pick any `i` with `a[i]=1` and any `j` with `a[j]=0`,
   try the same acceptance test.
4. Repeat until a pre‑set iteration limit (e.g. `2·n` attempts) is exhausted
   **or** no improvement occurs for `n` consecutive attempts.

This deterministic descent quickly drives the maximum overlap down to a local
minimum that is often very close to the optimum for the given \(n\).

#### 2.3. Simulated‑annealing escape  

The worst‑shift descent can become trapped when every improving swap would make a
different shift the new worst one, creating a plateau.  To cross such plateaus we
run a lightweight simulated‑annealing wrapper:

* Starting from the best binary vector found by the deterministic descent,
  perform a *fixed‑budget* annealing phase (e.g. `max_iters = 5·n·log n`):
  * Propose a random balanced swap (as in 2.2, step 3).  
  * Compute `Δ = new_max_cnt – cur_max_cnt`.  
  * Accept unconditionally if `Δ≤0`; otherwise accept with probability
    `exp(-Δ/T)` where temperature `T` decays exponentially from
    `T₀ = 0.5` to `T_f = 1e‑4` over the allocated iterations.
* Keep the best vector ever seen during the annealing run.

The annealing phase adds only a few hundred thousand correlation calls,
which is cheap for \(n≤200\).

#### 2.4. Multi‑start strategy  

For each \(n\) we perform **multiple independent restarts** (default 5,
or as many as the remaining time permits).  
Each restart uses a fresh random balanced seed; the deterministic descent is
run first, followed by the annealing escape.  The best of all restarts is stored
as `best_h_n`.

### 3. Continuous refinement (fractional h)

Binary vectors often achieve the integer target \(\max\_cnt\approx
\lfloor0.3807\,n/2\rfloor\).  To push the bound below the integer ceiling we
allow fractional entries and perform a *projected soft‑max gradient descent*.

#### 3.1. Soft‑max surrogate  

Define the vector of overlap counts
\[
o_k(h)=\sum_i h_i\bigl(1-h_{i+k}\bigr), \qquad k\in\{-n+1,\dots,n-1\}.
\]
Instead of the non‑smooth max we minimise
\[
f_\alpha(h)=\frac{1}{\alpha}\log\Bigl(\sum_k e^{\alpha\,o_k(h)}\Bigr),
\]
with a growing smoothing parameter \(\alpha\).  For \(\alpha\to\infty\) the
surrogate converges to \(\max_k o_k\).

#### 3.2. Gradient of a single shift  

For a fixed shift \(k\) the gradient (component‑wise) is
\[
\frac{\partial o_k}{\partial h_i}=1-
\bigl[\;h_{i+k}\,\mathbf{1}_{i+k<n}
+\;h_{i-k}\,\mathbf{1}_{i-k\ge0}\;\bigr].
\]
All indices outside \([0,n-1]\) contribute zero.  This expression is vectorised
with NumPy slices.

The gradient of the soft‑max surrogate is a convex combination of these per‑shift
gradients:
\[
\nabla f_\alpha(h)=\sum_k p_k\,\nabla o_k(h),\qquad
p_k=\frac{e^{\alpha o_k}}{\sum_j e^{\alpha o_j}}.
\]

#### 3.3. Projection onto the feasible set  

After a gradient step we must enforce:
* box constraints \(0\le h_i\le1\);
* linear constraint \(\sum_i h_i = n/2\).

The Euclidean projection onto the intersection of a hyperplane and a box is the
well‑known *water‑filling* problem.  The optimal solution has the form

\[
h_i^{\text{proj}} = \operatorname{clip}\bigl(v_i-\lambda,\;0,\;1\bigr)
\]

for some scalar \(\lambda\).  The monotone function
\(\phi(\lambda)=\sum_i\operatorname{clip}(v_i-\lambda,0,1)\) is decreasing, so
\(\lambda\) is found by a short binary search (≈ 40 iterations) to satisfy
\(\phi(\lambda)=n/2\).  This projection is fully vectorised and cheap.

#### 3.4. Continuation schedule  

* Initialise \(h^{(0)}\) with the best binary vector found for the current \(n\),
  promoted to float (0 → 0.0, 1 → 1.0).  
* Perform a **nested loop** over increasing values of \(\alpha\):
  \(\alpha\in\{1,5,10,20,40,80\}\).  
  For each \(\alpha\) run a fixed number of gradient steps (e.g. \(T_\alpha=
  200\) steps).  
  Step size is scaled as \(\eta = \eta_0/\sqrt{t+1}\) with \(\eta_0\)≈ 0.2.
* After each step compute the true max overlap
  `c = 2*max(o_k)/n`; if it is lower than the current global best, update the
  record.

Because the surrogate becomes steeper with larger \(\alpha\), the method first
moves quickly in a smooth landscape and then refines the exact max.

#### 3.5. Time allocation  

The continuous phase is only started for the **largest** problem size that
still has remaining budget (typically the last \(n\) in the list).  If the binary
search already beats the target bound we may skip the continuous phase to spare
time.
