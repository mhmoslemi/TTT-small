### 1.  High‑level plan
We will treat the problem as a **continuous constrained optimization** followed by a **combinatorial polishing** phase.  
The continuous phase uses a *smooth approximation* of the max‑over‑shifts, enabling fast gradient information. The polishing phase works on a binary (step‑function) version of the solution and performs cheap, O(n) swap updates that directly reduce the true objective.  
The two phases are repeated on several discretisations (different numbers of sample points) and with several random restarts, always respecting the 600 s wall‑clock budget.

### 2.  Mathematics of the smooth surrogate

For a discretisation with `n` points (`dx = 2/n`) define  

```
c_k(h) = Σ_i h[i]·(1 – h[i+k])          for k = -(n‑1)…(n‑1)
```

(the correlation computed by `np.correlate`).  
The original objective is  

```
F(h) = max_k c_k(h)·dx .
```

Introduce the *log‑sum‑exp* (LSE) surrogate with a temperature‑like parameter `α>0`  

```
Φ_α(h) = (1/α)·log Σ_k exp(α·c_k(h)) .
```

As `α → ∞`, `Φ_α → max_k c_k`. For moderate `α` the function is smooth, differentiable and its gradient is a weighted sum of the shift‑gradients.

### 3.  Gradient of the surrogate

For a fixed `k`  

```
∂c_k/∂h[i] = (1 – h[i+k])·1_{i+k∈[0,n)}  –  h[i‑k]·1_{i‑k∈[0,n)} .
```

Hence  

```
∇Φ_α(h) = Σ_k w_k·∇c_k(h)  ,   w_k = exp(α·c_k)/Σ_j exp(α·c_j) .
```

All `w_k` are non‑negative and Σ w_k = 1.  
The weighted sum can be evaluated **in O(n²)** by two explicit loops, or **in O(n log n)** using FFT‑based convolutions – both are cheap for `n≤300`.

A convenient O(n) formulation using prefix sums:

```
forward[i] = Σ_{j=i}^{n‑1} (1 – h[j])        # sum of (1‑h) to the right of i
backward[i] = Σ_{j=0}^{i}   h[j]             # sum of h to the left of i
∇c_k contribution for shift k = (1 – h[i+k]) – h[i‑k] .
```

With the weights `w_k` we form the final gradient by convolving `w` with the vectors `(1‑h)` and `h`.

### 4.  Feasible set and projection

Constraints:  

* Box: `0 ≤ h[i] ≤ 1`.  
* Linear equality: `Σ_i h[i] = n/2` (because `∫ h = 1` on a length‑2 interval).

After a gradient step we **project** onto the intersection of the hyper‑plane and the box.  
The projection is the classic “water‑filling” algorithm:

1. Clip the vector to `[0,1]`.  
2. Compute the surplus/deficit `δ = Σ h – n/2`.  
3. While `|δ|` exceeds a tiny tolerance, adjust all *free* components (those strictly inside (0,1)) by the same amount `Δ = δ / (#free)`.  
4. If any component hits a bound, remove it from the free set and repeat.

Because `n` is small, sorting the components (`O(n log n)`) is acceptable.

* **Parameters**

### 7.  Combinatorial polishing (binary local search)

We work directly with the integer correlation `c = correlate(h_bin, 1‑h_bin)` and its maximum.

* **Data structures**  
  - `c` (length `2n‑1`) maintained incrementally.  
  - Two index sets: `ONES = {i | h[i]=1}` and `ZEROS = {i | h[i]=0}`.

* **Swap update (O(n))**  
  For a swap `(i ∈ ONES, j ∈ ZEROS)` we apply the change `Δ = -1` at `i` then `+1` at `j`.  
  The incremental update for one index `p` and change `δ` is:

  ```
  for q = p … n‑1:   shift = q‑p;   c[shift+off] += δ·(1‑h[q])
  for q = 0 … p:    shift = p‑q;   c[shift+off] -= δ·h[q]
  ```

  (`off = n‑1`). After the two updates we toggle `h[i]` and `h[j]` and update the index sets.

* **Targeted move selection**  
  - Identify the worst shift `s* = argmax c`.  
  - Build the set  
    `A = { i∈ONES | i+s*∈[0,n) and h[i+s*]=0 }`  (these contribute 1 to `c[s*]`).  
    `B = { j∈ZEROS | j+s*∈[0,n) and h[j+s*]=1 }`.  
  - If both are non‑empty, pick random `i∈A`, `j∈B` and perform the swap – this **guarantees** a reduction of `c[s*]` by exactly 1 (the contribution of the pair `(i,i+s*)`).  
  - If `A` or `B` is empty, fall back to a random swap (uniform pick from ONES×ZEROS).

* **Acceptance rule**  
  Accept the swap **iff** the new maximum `max(c)` does not increase.  
  Occasionally (e.g. 1 % of attempts) accept a worsening swap with probability `exp(-(Δmax)/τ)` where `τ` decays over time – a lightweight simulated‑annealing flavour to escape shallow plateaus.

* **Termination**  
  - Stop when a full pass of `|ONES|·|ZEROS|` attempts yields no improvement, or when the global time budget is near exhaustion.  
  - The best binary `h_bin` encountered is kept.

Because each swap costs O(n) and `n ≤ 300`, millions of swaps are feasible well within the 600 s limit.
