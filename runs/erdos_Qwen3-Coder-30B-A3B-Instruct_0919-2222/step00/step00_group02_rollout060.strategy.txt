Projection algorithm:

Given vector v (float), target sum s ( = n/2). We want x_i = clip(v_i - λ, 0, 1) where λ solves sum_i x_i = s.

def project_onto_box_and_sum(v, target):
    lo = -1.0  # v_i - λ > 1 => λ < v_i -1, ensure sum > target? For lower bound set lo such that sum_i clip(v_i - lo, 0, 1) >= target.
    hi = 1.0  # set hi = max(v_i) + 1? Actually need upper bound for λ where sum = 0.
    # Better compute bounds:
    lo = np.min(v) - 1.0  # ensures v_i - lo >=1 => all clipped to 1 => sum = n
    hi = np.max(v) + 1.0  # ensures v_i - hi <=0 => all clipped to 0 => sum=0
    # binary search for λ
    for _ in range(50):
        mid = (lo + hi) / 2
        x = np.clip(v - mid, 0, 1)
        s = x.sum()
        if s > target:
            lo = mid
        else:
            hi = mid
    return np.clip(v - hi, 0, 1)  # hi is final
```
