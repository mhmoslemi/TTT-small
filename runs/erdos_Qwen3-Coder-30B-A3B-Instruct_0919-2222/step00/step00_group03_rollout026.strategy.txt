**Goal** – Produce a step‑function `h` on `[0,2]` (discretised into `n` equally spaced points) with
\[
\sum_{i=0}^{n-1}h_i\,dx=1,\qquad 0\le h_i\le 1,
\]
that minimises  
\[
C_5=\max_{k}\int_0^2 h(x)\bigl(1-h(x+k)\bigr)dx
      \approx\max_{d=-n+1}^{n-1}\Bigl(\sum_{i}h_i\bigl(1-h_{i+d}\bigr)\Bigr)dx ,
\]
where `dx = 2/n` and out‑of‑range indices are treated as zero.

The optimisation is a *min–max* problem with a quadratic term
\(h_i\,h_{i+d}\).  The exact optimum can be obtained by a **mixed‑integer linear programme (MILP)**
that linearises each product while keeping the only integer variables the
binary indicators of the set (the `h_i`).  The resulting programme is
moderately sized for `n≈200` and can be solved with an open‑source MILP
solver inside the 600 s budget.

### 1. MILP formulation (binary variables only)

| Symbol | Meaning |
|--------|---------|
| `n`    | number of sample points (even, `dx=2/n`) |
| `h_i`  | binary decision variable, `h_i∈{0,1}` |
| `y_{i,d}` | continuous auxiliary variable representing the product `h_i·h_{i+d}` (only for `d≥1` and `i+d<n`) |
| `T`    | non‑negative continuous variable that will be `T = \max_d\bigl( n/2-\sum_i y_{i,d}\bigr)` |
| `dx`   | spacing `2/n` (constant) |
| `C5`   | final bound `C5 = T·dx` |

**Constraints**

1. **Mass constraint** – exactly half the points are `1`:
   \[
   \sum_{i=0}^{n-1} h_i = \frac{n}{2}.
   \]

2. **McCormick linearisation for each product** (for every shift `d=1,…,n-1` and every overlapping index `i=0,…,n-d-1`):
   \[
   \begin{aligned}
   y_{i,d} &\le h_i,\\
   y_{i,d} &\le h_{i+d},\\
   y_{i,d} &\ge h_i + h_{i+d} - 1,\\
   0 &\le y_{i,d}\le 1 .
   \end{aligned}
   \]
   *If `h_i` and `h_{i+d}` are binary these three inequalities force
   `y_{i,d}=h_i·h_{i+d}` exactly.*

3. **Shift‑overlap constraints** – for every shift `d` we demand
   \[
   \sum_{i=0}^{n-d-1} y_{i,d} + T \;\ge\; \frac{n}{2}.
   \]
   Re‑arranged, this is
   \[
   T \;\ge\; \frac{n}{2} - \sum_i y_{i,d}\;,
   \]
   which is equivalent to
   \[
   \bigl(n/2 - \sum_i y_{i,d}\bigr)dx \;\le\; C5 .
   \]
   Because the correlation is symmetric for negative shifts, it is enough
   to enforce the constraints for `d=0,…,n-1` (the case `d=0` reduces to
   `T≥0` and can be omitted).

4. **Variable domains** – `h_i` binary, `y_{i,d}` continuous `[0,1]`,
   `T≥0`.

**Objective**

\[
\min\;T .
\]

Since `dx` is a constant factor, minimising `T` also minimises the
desired `C5 = T·dx`.

**Size estimate for a given `n`**

- Number of binary variables: `n` (the `h_i`).
- Number of continuous `y` variables: \(\frac{n(n-1)}{2}\) (all unordered pairs).
- Number of linear constraints:
  * 1 mass constraint,
  * 3 per `y` (≈ \(3n(n-1)/2\)),
  * 1 per shift (`n` constraints).

For `n = 200` this yields ≈ 20 000 continuous variables, ≈ 60 000 linear
