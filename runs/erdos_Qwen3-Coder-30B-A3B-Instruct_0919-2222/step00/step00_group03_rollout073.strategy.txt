**Goal**  
Find a step function `h` on `[0,2]` with values in `[0,1]` and total mass `∫₀²h=1` (i.e. exactly half of the 2‑unit interval contains “height 1”) that minimises  

\[
C_5=\max_{k}\int_0^2 h(x)\,\bigl(1-h(x+k)\bigr)\,dx .
\]

The program must return a discretised version of `h` (`h_values`), the achieved bound `c5_bound= C_5` and the number of samples `n_points`.  
A bound below 0.3807 is the target; the current record is ≈0.38092.

--------------------------------------------------------------------
### 1. Discrete formulation

Take an integer `n` (`n` even) and sample the interval with step `dx = 2/n`.  
Let  

* `h_i  ∈ [0,1]` be the value of `h` on the `i`‑th sub‑interval (`i = 0,…,n‑1`);
* `∑_i h_i = n/2` (equivalent to the integral constraint).

For a discrete shift `d (0 ≤ d ≤ n‑1)` the overlap integral becomes  

\[
c_d = \sum_{i=0}^{n-d-1} h_i\bigl(1-h_{i+d}\bigr)\,dx
     = \Bigl(\frac{n}{2} - \sum_{i=0}^{n-d-1} h_i h_{i+d}\Bigr)dx .
\]

Define auxiliary products  

\[
y_{i,d}=h_i h_{i+d}\qquad (0\le i\le n-d-1,\;1\le d\le n-1),
\]

so that  

\[
c_d = \Bigl(\frac{n}{2} - \sum_i y_{i,d}\Bigr)dx .
\]

Introduce the scalar `T = max_d (\frac{n}{2}-∑_i y_{i,d})`.  
Then the optimisation problem is

\[
\begin{aligned}
\min\;& T \\
\text{s.t. }&\sum_i h_i = \frac n2,\\
            &0\le h_i\le 1,\\
            &y_{i,d}\le h_i,\; y_{i,d}\le h_{i+d},\\
            &y_{i,d}\ge h_i+h_{i+d}-1,\\
            &\sum_{i=0}^{n-d-1} y_{i,d} \;\ge\; \frac n2 - T
               \qquad\forall d=1,\dots,n-1,\\
            &T\ge 0 .
\end{aligned}
\]

The three “product” inequalities constitute the **McCormick envelope** of the bilinear term on the unit square; together with `h_i∈{0,1}` they enforce `y_{i,d}=h_i h_{i+d}` exactly.  For the *continuous* version we keep `h_i` binary (the optimum is known to be at an extreme point) and let `y_{i,d}` be continuous.

--------------------------------------------------------------------
### 2. Mixed‑Integer Linear Program (MILP)

*Variables*  

* `h_i` – binary (0/1), `i=0..n‑1`.  
* `y_{i,d}` – continuous in `[0,1]`.  
* `T` – continuous, lower‑bounded by 0.

*Constraints*  

* **Mass** : `∑ h_i  = n/2`.  
* **Product envelope** (for every `d≥1` and every valid `i`) :

  ```
  y[i,d] ≤ h[i]
  y[i,d] ≤ h[i+d]
  y[i,d] ≥ h[i] + h[i+d] - 1
  ```

* **Shift bound** :

  ```
  Σ_i y[i,d] + T ≥ n/2          (for each d = 1,…,n‑1)
  ```

* **Box constraints** on `h` and `y` are implied by their types.

*Objective*  

`minimise  T`.

Because `T` appears linearly, this is a genuine **MILP**.  The only integer variables are the `n` binary `h_i`; the auxiliary `y` variables remain continuous, which keeps the problem size tractable even for a few hundred sample points.

### 5. Heuristic refinement (fallback / polishing)

If the MILP finishes early or if the time limit is reached before the largest `n` finishes, improve the current best solution with a cheap **swap‑based hill‑climber**:

1. **Data structure** – keep the binary vector `h`, the current convolution `c = np.correlate(h, 1‑h, mode="full") * dx`, and the current maximum `M = c.max()`.

2. **Swap move** – pick uniformly at random an index `i` with `h[i]=1` and an index `j` with `h[j]=0`.  Swapping them preserves the mass.

3. **Incremental update** – for each shift `d` that involves `i` or `j` the term `h_i (1‑h_{i+d})` changes.  Re‑compute the affected entries of `c` (cost `O(n)`, acceptable for n ≤ 200) and obtain the new maximum `M'`.

4. **Acceptance rule** – if `M' < M` accept the swap; otherwise reject.  Optionally use a simulated‑annealing temperature that decays with the remaining time to escape shallow local minima.

5. **Termination** – repeat until the allocated time expires.

Because each swap preserves the half‑mass constraint, the final vector is always feasible.  This stage often shaves a few thousandths off the bound obtained from the MILP, especially when the MILP was stopped early.
