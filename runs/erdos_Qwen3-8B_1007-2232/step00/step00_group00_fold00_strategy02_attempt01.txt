### Rational for the Approach
**Central Idea**: Combine differential evolution with convex optimization to explore promising regions around a parent solution while ensuring feasibility. The approach leverages the parent's structure but allows for significant transformation through random rotations of patterns. 

**Key Breakthrough**: Instead of performing arithmetic operations on the function values, we maintain and transform structural patterns. This preserves scalability while introducing diversity through random pattern rotations. The method combines random exploration with structured optimization (gradient descent) to escape local optima.

**Motivation**: The fractal nature of the problem suggests that near-optimal solutions may have repeating structures. This approach explicitly searches for and enhances these structural features through randomness and local optimization.

**Constraints**: 
- Discretization to integer samples is handled through exact rotations and convolutions
- N-point to 3-point transformation maintains mathematical integrity
- Feasibility constraints enforced through projection after each optimizer step

**Bottleneck Addressed**: Local optimization can easily get stuck in suboptimal structures. This method introduces purposeful structural change and systematic fine-tuning to explore diverse regions.

### Mathematical Formulation

**Representation**: 
- Integer-valued vectors representing point patterns
- Support for any grid size $n$ (default 81/2 points)

**Objective**: 
- $min_{h}[max_{k} \iint h(x)(1-h(x+k)) dx]$

**Constraints**:
- $0 ≤ h_i ≤ 1$ 
- $\sum h_i = n/2$

**Structural Rotation**:
- Transformation operator $R_{a}: [0,1]^n → [0,1]^n$
  $$R_a(h) = [h_{\lfloor a \cdot i \rfloor} \mod n]$$
- Directional selection probabilities $\rho_k = \frac{\deg k}{\sum \deg}$ based on vertex degree

**Feasibility Projection**:
- After all operations, project back to constraint set:
  $$P(h) = \min_{h'\in \mathcal{F}} \|h-h'\|_2 \quad \text{s.t.} \quad h \in [0,1]^n, \sum h= n/2$$

**Algorithm Structure**:
1. Initialize population with $3$ adapted parent patterns
2. Perform pattern rotations with controlled randomness
3. Apply gradient descent with line search
4. Repair to feasible set

**Solver Usage**:
- Implement own feasible set projection
- Use exact arithmetic for gradient computation
- No commercial solvers required

   ```python
   def rotate_pattern(h, alpha):
       n = len(h)
       h_rot = np.roll(h, int(alpha))
       return np.take(h_rot, np.random.permutation(n), axis=-1)
   ```

   ```python
   def project_feasible(h):
       n = len(h)
       # Make integral exactly n/2
       h_proj = h.copy()
       excess = np.sum(h_proj) - n/2.0
       if excess != 0:
           h_proj += excess / n
           h_proj = np.clip(h_proj, 0, 1)
       return h_proj
   ```

   ```python
   def objective(h):
       dx = 2.0 / n
       corr = np.correlate(h, (1 - h), mode='full')
       return np.max(corr) * dx
   ```
