This kernel implements the "outgoing" version of the Triangle Multiplicative Update (TriMul) operator used in AlphaFold3 and similar models. The kernel is optimized for the NVIDIA H100 GPU (sm_90), using techniques like TMA (Tensor Memory Access), thread-block clusters, and shared memory for efficient performance. The main operations are: applying LayerNorm, projecting the input through linear layers, applying gates, performing the pairwise multiplication (using an einsum-style operation), and applying normalization and final output projection. The kernel is designed to be fast and efficient for large sequence lengths up to 1024 and high dimensions, ensuring low runtime (target: 1000 microseconds) on H100 hardware.
