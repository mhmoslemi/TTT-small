For any finite non-negative sequence a of length n, let c be its full
self-convolution. The central lag is c[n-1] = sum_i a_i^2, so

    max(c) >= sum_i a_i^2.

By Cauchy-Schwarz,

    (sum_i a_i)^2 <= n * sum_i a_i^2 <= n * max(c).

Therefore

    2 * n * max(c) / (sum_i a_i)^2 >= 2.

A constant positive sequence attains equality, for example
[1.0, 1.0, ..., 1.0].  Hence no smaller value can be reached under the
given evaluator, and the best return value is a constant sequence.
"""

    attains this bound.  The length 6121 is used to match the known

    """
    return [1.0] * 6121
