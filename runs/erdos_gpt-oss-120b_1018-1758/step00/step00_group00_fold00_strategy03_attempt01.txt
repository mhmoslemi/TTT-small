1. Approach and rationale

We will employ a multi-resolution optimization strategy with simulated annealing (SA). The core idea is to:

- Start at a low resolution (45 points) with the parent solution
- Systematically explore finer grids (90, 180 points) by projecting solutions upward
- Use simulated annealing global optimization at each resolution
- Maintain a dynasty of progressively improved parent solutions across resolutions

The rationale is that:
- Simulated annealing can escape local optima while preserving basin exploration
- Upward projection ensures continuity between resolutions
- Global exploration with random moves replaces expensive grid searches
- The SA neighborhood is balanced between exploration and practical improvement

Key advantages:
- Runs are reproducible with seed parameter
- Time budget allocated dynamically across resolutions
- We return the best solution found with its resolution
- No dependency on older versions ensures code portability

2. Mathematical specification

We minimize Erdos overlap C5 defined by:
    C5(h) = max_k ∫ h(x)(1-h(x+k))dx

Discretization:
    dx = 2.0 / n_points
    h represented as array of length n_points
    ∑h[i] * dx = 1  →  ∑h = n_points/2 exactly
    0 ≤ h[i] ≤ 1 for all i

For upward projection from 3*m to 4*m points:
    Let parent h be length 3*m
    New grid of length 4*m: distribute parent value at j to four time slots
    Proportional mass distribution ensures exact sum preservation

Simulated annealing parameters:
- Initial temperature set based on grid dimension
- Exponential cooling schedule
- Metropolis criterion with uniform random move kernel
