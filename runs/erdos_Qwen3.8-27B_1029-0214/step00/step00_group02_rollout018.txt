Actually, here's an idea: use a "mirror descent" or "follow-the-regularized-leader" approach.

Or even simpler: use coordinate descent. For each coordinate j:
- Fix all other h[i] for i ≠ j
- The constraint is h[j] = n/2 - sum_{i≠j} h[i]
- So actually, once we fix n-1 coordinates, the last is determined!

Wait, that's only if we parameterize with n-1 free variables. Let me use this:
- Free variables: h[0], h[1], ..., h[n-2] (n-1 variables)
- h[n-1] = n/2 - sum(h[0]...h[n-2])
- Constraints: 0 ≤ h[i] ≤ 1 for all i

Then we can use scipy.optimize.minimize with the objective f(x) = max_k c[k] * dx.

The gradient of c[k] with respect to h[j] (for j < n-1):
dc[k]/dh[j] = (1-h[j-L_k]) * I[j-L_k valid] - h[j+L_k] * I[j+L_k valid]

where L_k is the lag corresponding to index k in the full correlation.
