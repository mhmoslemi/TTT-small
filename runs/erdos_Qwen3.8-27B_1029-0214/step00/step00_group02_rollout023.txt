Let me implement a "smart" local search:

For a mass transfer h[i] += d, h[j] -= d:
The change in the correlation at lag k is:
Δc[k] = d * (∂c[k]/∂h[i] - ∂c[k]/∂h[j])

We want to minimize max_k c[k], so we want moves that decrease the active lags (those at the maximum).

The subgradient approach:
1. Find the active set A = {k : c[k] ≈ max}
2. Compute g[i] = sum_{k in A} ∂c[k]/∂h[i] / |A|
3. We want to decrease h where g[i] > 0 and increase h where g[i] < 0
4. The best move is: i = argmax g, j = argmin g, d > 0 small

This is essentially a subgradient method!

```python
def compute_subgradient(h, n):
    """Compute subgradient of max correlation."""
    dx = 2.0 / n
    corr = np.correlate(h, 1 - h, mode="full")
    max_val = np.max(corr)
    
    # Find active lags (within tolerance of max)
    tol = 1e-4
    active = np.where(corr >= max_val - tol)[0]
    
    grad = np.zeros(n)
    for idx in active:
        k = idx - (n - 1)
        if k >= 0:
            # c[k] = sum_{n_idx=0}^{n-1-k} h[n_idx+k] * (1-h[n_idx])
            # ∂c[k]/∂h[i]:
            # If i = n_idx (i in [0, n-1-k]): contribution is -h[i+k]
            # If i = n_idx+k (i in [k, n-1]): contribution is (1-h[i-k])
            for n_idx in range(n - k):
                grad[n_idx + k] += (1 - h[n_idx])
                grad[n_idx] -= h[n_idx + k]

            k_abs = -k
            # c[-k_abs] = sum_{n_idx=k_abs}^{n-1} h[n_idx-k_abs] * (1-h[n_idx])
            for n_idx in range(k_abs, n):
                grad[n_idx - k_abs] += (1 - h[n_idx])
                grad[n_idx] -= h[n_idx - k_abs]
    
    grad /= len(active)
    return grad, max_val * dx
```
