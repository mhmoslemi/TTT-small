1. Approach and rationale

The supplied evaluation is the exact non-smooth minimax quantity
C5 = max_{k=-(n-1),...,n-1}  dx * sum_i h_i (1 - h_{i+k}),
where the summation is restricted to the finite-support overlap exactly as implemented by
max(np.correlate(h, 1-h, mode="full")) * dx.
The previous plans considered smoothing the maximum or linear factorizations of active correlations. This plan takes a materially different route: it optimizes the original epigraph reformulation using a general nonlinear constrained minimization routine, with exact derivative formulas for all selected correlation constraints, and retains the unmodified evaluator as the only acceptance and final certification mechanism.

The central idea is to introduce an auxiliary scalar variable t and impose exactly the constraints that every finite-support lag correlation is no larger than t:

  minimize t
  subject to sum_i h_i = n/2,
            0 <= h_i <= 1,
            dx * sum_{valid i} h_i (1 - h_{i+k}) <= t  for selected representative correlations.

The difficult term max_k is removed; the remaining constraints are smooth algebraic functions of h. The resulting optimization problem is still nonconvex and only local, so the global KKT solution is not claimed. The reason this can improve a tight parent by a gap of order 1e-4 is that direct epigraph equality constraints allow the optimizer to simultaneously lower the flat set of active correlations. Unlike LSE surrogate smoothing, this optimization never reduces the problem to a single smoothed stellar point; unlike a one-step linearized descent plan, the nonlinear constraint model is optimized directly inside the feasible box and sum constraint. The method can exploit changes in the simultaneous active-lag set, especially after resolution refinement.

The vital safety property is exact acceptance: every returned vector is made feasible and re-scored using the actual evaluator. No surrogate constraint-set value, smoothed penalty, circular correlation, or "minimum autocorrelation" replacement can determine acceptance. The parent or fallback is always retained if local optimizations fail. The target C5 ≤ 0.3808 is a heuristic goal; the program returns the best certified value found, and never claims optimality.

The algorithm is a multistart, multiresolution structured search:
- validate and repair parent;
- generate transferred constructions at one or more grids;
- apply exact nonlinear epigraph optimization over the selected correlation support set;
- try algebraic symmetry, rolling, annealing, and binary projections only as cheap candidate proposals, accepting them only by exact score;
- stop before the wall-clock deadline and return the best valid vector.
