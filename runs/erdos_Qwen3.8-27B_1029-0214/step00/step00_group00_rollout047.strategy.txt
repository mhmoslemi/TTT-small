1. Approach and rationale

The supplied construction is already very close to the target bound, so the algorithm should not rely on coarse simulated annealing or generic global random search. The main difficulty is that a exact minimax optimizer sees many equality-like active constraints at the smallest differences, because the discrete evaluator is

    C5(h) = max_{all lags} dx * sum_{pair in support} h_i * (1-h_j),   dx = 2/n,

with sum h_i = n/2 and 0 <= h_i <= 1. A local search that directly changes all constraints by merely penalizing the maximum, or that minimizes a smooth log-sum-exp surrogate, often stalls once several peaks are almost tied.

The new approach is to generate a sequence of fixed exact target values t and solve a targeted violation-minimization subproblem

    minimize   Q_t(h) = sum_{k in A_t} [max(C_k(h) - t, 0)]^2
    subject to 0 <= h_i <= 1,
               sum_i h_i = n/2,
               h_i approximately in a trust box around the current point.

Here C_k(h) denotes the k-th term of the same finite-support cross-correlation as the exact evaluator, and A_t is a controlled active set determined from the current iterate. This is not a convex formulation; the quadratic is nonconvex because of the bilinear terms h_i * h_j. It is a feasibility-seeking nonlinear least-squares method. At a fixed t, any feasible point with max C_k <= t has objective 0. If a strict feasible point is found, it is globally accepted using the authoritative evaluator. If the local minimizer of Q_t cannot reduce violations to zero, it is still used as a high-quality trial direction and is accepted only if its exact C5 is smaller. By lowering t adaptively, we force the solver to attack the upper envelope directly rather than minimizing a generic smooth surrogate over the whole space.

Why this should improve the near-optimal parent: the gap from the current bound to 0.3808 is around 5e-5. A feasible move to the global target requires a small reshaping of h and may require redistributing tiny amounts of mass among variables that appear in top lags. Solving a fixed-t violation least-squares problem gives an exact scalar objective at each t, avoiding the discontinuity and gradient branch pathology of max-subgradient active set methods. The use of a trust box around the current valid vector keeps proposals near the parent basin and keeps feasibility easy, while random seeds, symmetrization, and multiscale transforms allow exploration when one basin is stuck.

Important limitations and hypotheses.

    - The problem is not globally convex. The least-squares subproblem inherits the h_i h_j products and can have local minima/saddle outcomes. No global optimality is claimed.
    - In ordinary continuous/improved local methods a direct CVXPy/BFGS/global MILP solution would require a convex formulation supported by the solver. We do not attempt that. Our only rigorous global verification is the final authoritative evaluator on the feasibility-corrected candidate. This is a heuristic globalization wrapped around local exact nonlinear solution stages.
    - Improvement depends on the supplied parent or other valid seeds. If global bound is not found within the time budget, the method returns the best valid bound discovered.
    - The qualitative mathematical basis is correct: exact cross-correlation terms contain products of h entries, while the boundaries of the matrix need exact offsets r and shorter supports n-r. The manual formulas in Section 2 enumerate exactly the same terms as the user evaluator.

2. Mathematical specification

2.1 Discrete decision vector and exact objective

For a returned grid size n >= 1 and integer n/2 meaning sum(h) = n/2 as a floating computation tolerance, define

    dx = 2.0 / n,
    S = n / 2.

A vector h = (h0,...,h_{n-1}) is acceptably feasible iff:

    0 <= h_i <= 1 + 0 only on numeric tolerance after projection,
    |sum(h) - S| is below a specified tolerance, preferably max(1e-10, 1e-11 n),
    all entries finite.

The authoritative evaluator is exactly

    E(h) = max(np.correlate(h, 1 - h, mode="full")) * dx,

over all 2n-1 lags. Use as final accepted C5 exactly this formula, never a circular correlation nor 1 - minimum autocorrelation.

2.2 Manual finite-support correlation set for gradients

Every term can be enumerated either in the same order as numpy or in a self-consistent order. The numerical order does not matter for max values; it must only be consistent for value and derivative computations. One canonical finite-support list of length 2n - 1 is:

    k = 0:     T_0 = dx * sum_{i=0}^{n-1} h[i] * (1 - h[i]).
For r = 1,...,n - 1, let e = n - r.

    k = 2r:     T_{2r}    = dx * sum_{i=0}^{e-1} h[i] * (1 - h[i+r]).
    k = 2r+1:   T_{2r+1}  = dx * sum_{i=0}^{e-1} h[i+r] * (1 - h[i]).

The union of these terms covers all cross-correlation boundary terms from h and 1-h. The maximum over this set equals the maximum over np.correlate(...,full). r=0 appears once because positive and negative zero-lag terms are identical product values.

This enumeration explicitly includes partial supports: for shift r the sums have e = n-r entries.

2.3 Derivatives needed by the least-squares subproblem

Let dx be common to all scaled expressions below. T[k] means one term above.

For k=0

    grad_k(T_0)[i] = dx * (1 - 2 h[i]), i=0,...,n-1.

For positive term k=2r, r>=1, e=n-r:

    grad_k(T_k)[0:e] += dx * (1 - h[r:n])
    grad_k(T_k)[r:n] += -dx * h[0:e].

For negative term k=2r+1, r>=1, e=n-r:

    grad_k(T_k)[r:n] += dx * (1 - h[0:e])
    grad_k(T_k)[0:e] += -dx * h[r:n].

In a generic array g of length n initialized to zero, add contributions exactly as shown. The values are scaled terms. Thus if target t is a scaled upper bound C5 (not raw sum), remain in scaled coordinates. Derivatives w.r.t. h include dx.

The TLV subproblem objective is

    W_x = sum_{k in A} q_k(d_k)^2,
    where d_k = max(T_k(x) - t, + small_numerical_asymmetry).

for p=2,

    penalty = max(T_k - t,0)^2.
   ceo derivative = 2 * max(T_k - t,0) * grad_k(T_k) if T_k>t,
    derivative = 0 if T_k <= t.

This is C^1 except at the exact threshold; the zero gradient we assign at the threshold is acceptable for SLSQP. The resulting logic is a least-squares penalty on violations above the fixed target. SLSQP supports this because the only truly nonlinear behavior is in the scalar objective, and only the one linear equality plus box bounds are placed as constraints.

The TLV problem being solved for fixed x,target_t,bounds A is:

    minimize W(h) = sum_{k in A} max(C_k(h) - target_t, 0)^2
    subject to sum(h) - n/2 = 0,
               box_low_i <= h_i <= box_upper_i.

The subproblem is nonconvex because of products between variables, so its local model is a heuristic direction generator. All candidate outbound acceptance uses exact E-projected h rather than its W.
