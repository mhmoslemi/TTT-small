G'(s) = sum_n h'[n+s] * q'[n]
= sum_n (h[n+s] + d*(δ_{n+s,i} - δ_{n+s,j})) * (q[n] + d*(δ_{n,j} - δ_{n,i}))
= sum_n h[n+s]*q[n] 
  + d * sum_n h[n+s]*(δ_{n,j} - δ_{n,i})
  + d * sum_n (δ_{n+s,i} - δ_{n+s,j})*q[n]
  + d² * sum_n (δ_{n+s,i} - δ_{n+s,j})*(δ_{n,j} - δ_{n,i})

The first term is G(s).

Second term: d * sum_n h[n+s]*(δ_{n,j} - δ_{n,i})
= d * (h[j+s] - h[i+s]) [if the indices are valid, i.e., 0≤j+s<N and 0≤i+s<N]
= d * (h[j+s] - h[i+s])

But we need to be careful: h[j+s] is only in the sum if 0 ≤ j+s < N (i.e., if the term is actually present in G(s)). Similarly for h[i+s].

So: Second term = d * (h[j+s] * 1[0≤j+s<N] - h[i+s] * 1[0≤i+s<N])

Third term: d * sum_n (δ_{n+s,i} - δ_{n+s,j}) * q[n]
= d * (q[i-s] * 1[0≤i-s<N] - q[j-s] * 1[0≤j-s<N])

Fourth term: d² * sum_n (δ_{n+s,i} - δ_{n+s,j}) * (δ_{n,j} - δ_{n,i})
= d² * (1[0≤i-s<N] * (δ_{i,j} - δ_{i,i}) - 1[0≤j-s<N] * (δ_{j,j} - δ_{j,i}))
= d² * (1[0≤i-s<N] * (δ_{i,j} - 1) - 1[0≤j-s<N] * (1 - δ_{j,i}))
= d² * (1[0≤i-s<N] * (δ_{i,j} - 1) - 1[0≤j-s<N] + 1[0≤j-s<N] * δ_{j,i})

Since i ≠ j: δ_{i,j} = 0 and δ_{j,i} = 0.
= d² * (-1[0≤i-s<N] - 1[0≤j-s<N])

So the total change:
ΔG(s) = d * (h[j+s]*1[0≤j+s<N] - h[i+s]*1[0≤i+s<N] + q[i-s]*1[0≤i-s<N] - q[j-s]*1[0≤j-s<N])
        + d² * (-1[0≤i-s<N] - 1[0≤j-s<N])

Now, in terms of the D and Q vectors:
D[s+(N-1)] = h[j+s]*1[0≤j+s<N] - h[i+s]*1[0≤i+s<N] + q[i-s]*1[0≤i-s<N] - q[j-s]*1[0≤j-s<N]
Q[s+(N-1)] = -1[0≤i-s<N] - 1[0≤j-s<N]
