    """Project h onto {x ∈ [0,1]^n : sum(x) = n_target}."""
    n = len(h)
    # Bisection on lambda
    lo, hi = -2.0, 2.0
    for _ in range(100):

        projected = np.clip(h - mid, 0, 1)
        s = np.sum(projected)
        if s > n_target:

        else:
            hi = mid

    g = 1 - h
    corr = np.correlate(h, g, mode="full") * dx
    return np.max(corr)

    n = n_points
    dx = 2.0 / n
    g = 1 - h
    corr = np.correlate(h, g, mode="full")

So we want to maximize min_k |A ∩ (A-k)|.

This is equivalent to finding a set A of measure 1 in [0,2] such that A has large intersection with all its translates.

For A = [0,1]: |A ∩ (A-k)| = 1-|k| for |k| ≤ 1, so min = 0. C5 = 1.
For A = [0, 0.5] ∪ [1, 1.5]: for k = 0.5, A ∩ (A-0.5) = [0,0.5] ∩ ([-0.5,0] ∪ [0.5,1]) = {0, 0.5} (measure 0). C5 = 1.

What about a "thickened" Cantor set? If A is the middle-thirds Cantor set scaled to have measure 1... but the Cantor set has measure 0.

What about A being a periodic pattern? If A consists of many small intervals of width w spaced evenly:
A = ∪_j [j*w, j*w + w/2] ∩ [0,2] (approximately)

Then |A| ≈ 1 (if we choose the right number and width).
For small shifts k < w/2, |A ∩ (A-k)| ≈ |A| (nearly full overlap).
For shifts k ≈ w, the overlap decreases.

The minimum overlap occurs at shifts that are multiples of the spacing.

This suggests a "multi-scale" approach: use a function that has structure at multiple scales.

    return float(np.max(corr))

    g = 1.0 - h
    corr = np.correlate(h, g, mode="full")
    cmax = np.max(corr)
    exps = np.exp((corr - cmax) / beta)
    logsumexp = cmax + beta * np.log(np.sum(exps))
    obj = logsumexp * dx
    w = exps / np.sum(exps)

                grad[:n - t] += wj * (1.0 - h[t:])
                grad[t:] -= wj * h[:n - t]
