1. Approach and rationale
-------------------------

1.1 Core problem addressed
The exact returned score is

```text
C5(h) = max_lag  np.correlate(h, 1-h, mode="full")[lag] * dx,
dx = 2 / N.
```

This is a finite-support maximal linear-correlation objective. It is nonconvex because terms include products of components of `h`. A direct convex formulation is not justified. The primary purpose of this program is therefore not to prove optimality but to deterministically improve the supplied parent construction and, if suitable interpolations/refinements are found, produce a smaller valid return score.

The supplied parent is treated as a trusted outer memory. It is retained unless a directly evaluated better feasible vector is found. The search uses three complementary mechanisms:

* a deterministic feasibility repair mechanism that keeps `0 <= h_i <= 1` and `sum(h) = N/2` simultaneously, not by single-coordinate renormalization;
* a resolution ladder starting from the parent length and moving to larger sample counts. These larger grids can reveal non-parent lags and finer local variations;
* an exact pairwise descent mechanism. Feasible updates are made through directions `h <- h + d(e_i - e_j)`. This sum-preserving direction changes only two components, so the box constraints can be enforced exactly and the full correlation vector at the new point is known exactly as a scalar quadratic in `d`.

The second method is the principal computational engine, while multi-resolution transfer is how it is applied. This method is materially different from a general nonlinear optimization workflow by exploiting the exact quadratic feasibility in every two-coordinate direction. Pairwise updates keep feasibility exact without needing a global projection in each step. The line search also uses the original objective components directly, not a modified/rewarded likelihood. No convexity or global optimality is claimed.

1.2 Why this can improve the record
Pairwise descent globally adjusts coordinates in a controlled two-variable way. Every coordinate is a possible accept/reject term due to boundary lags too, so the search does not exploit the mid-lag near cylinder simplification. Multi-scale results because increasing the process step rate captures parenting lag values unprotected sampling grids. The program advances transfer-time candidates only after direct validation of feasibility and score. This method is not guaranteed prudent before we measure numerical results; its planned output may provide a few more improvements than simple random or adaptive sampling. With specified exact resumptions, one is informed as yes: the known installed parent is always reduced-resolution candidate fallback older means.

Mathematical facts the algorithm uses are:

* every accepted pair direction preserves the integral constraint exactly in the discrete formula `sum(h)=N/2`;
* moving by a single pair change preserves `0/1` bounds via a closed-form interval;
* for fixed current `h`, all objective terms after the pair change are known analytically in `d`;
* terminal accepted candidates are judged with the same objective (linear full correlation boundary terms) rather than circular or Fourier-smoothed objectives.
