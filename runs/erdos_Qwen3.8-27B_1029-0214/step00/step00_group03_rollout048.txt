Now, the algorithm for a given pair (i,j):
1. Compute L(s) for all s (or equivalently all m from 0 to 2N-2)
2. Compute Q(s) (only non-zero at s=0, s=i-j, s=j-i)
3. Find d* that minimizes max_s (c_0(s) + d*L(s) + d^2*Q(s)) subject to box constraints on d

For step 3, I'll use bisection on T (the target max value):
- For a given T, find the set of d values satisfying all constraints
- If the set is non-empty, T is feasible; otherwise not
- Binary search for the minimum feasible T

The feasibility check for a given T:
- Start with d_interval = [d_min, d_max] (box constraint)
- For each s where Q(s) = 0: c_0(s) + d*L(s) ≤ T
  → if L(s) > 0: d ≤ (T - c_0(s))/L(s)
  → if L(s) < 0: d ≥ (T - c_0(s))/L(s)
  → if L(s) = 0: need c_0(s) ≤ T (if not, infeasible)
- For each s where Q(s) = 1: c_0(s) + d*L(s) + d^2 ≤ T
  → d^2 + L(s)*d + (c_0(s) - T) ≤ 0
  → discriminant = L(s)^2 - 4*(c_0(s)-T) = L(s)^2 + 4*(T - c_0(s))
  → if discriminant < 0: infeasible
  → else: d ∈ [(-L(s) - sqrt(disc))/2, (-L(s) + sqrt(disc))/2]

We intersect all these intervals with d_interval and check if the result is non-empty.

This is O(N) per feasibility check, and we need O(log(precision)) iterations of bisection.

import numpy as np
from scipy.optimize import minimize
import time

def compute_correlation(h):
    """Compute np.correlate(h, 1-h, mode='full')"""
    return np.correlate(h, 1.0 - h, mode="full")

def evaluate_c5(h):
    """Compute C5 = max(correlation) * dx"""
    N = len(h)
    dx = 2.0 / N
    corr = compute_correlation(h)
    return np.max(corr) * dx

def project_to_feasible(h, N):
    """Project h to satisfy 0<=h<=1 and sum(h)=N/2"""
    target = N / 2.0
    h = np.clip(h, 0.0, 1.0)
    s = np.sum(h)
    if abs(s - target) < 1e-10:
        return h
    # Bisection on offset
    if s > target:
        # Need to reduce sum
        lo, hi = -1.0, 0.0
    else:
        lo, hi = 0.0, 1.0
    for _ in range(100):
        mid = (lo + hi) / 2
        h_new = np.clip(h + mid, 0.0, 1.0)
        s_new = np.sum(h_new)
        if s_new > target:
            hi = mid
        else:
            lo = mid
    h = np.clip(h + (lo + hi) / 2, 0.0, 1.0)
    # Fix residual
    s = np.sum(h)
    residual = target - s
    # Distribute residual
    if residual > 0:
        # Add to elements with h < 1
        order = np.argsort(h)
        for idx in order:
            room = 1.0 - h[idx]
            add = min(room, residual)
            h[idx] += add
            residual -= add
            if abs(residual) < 1e-12:
                break
    else:
        # Remove from elements with h > 0
        order = np.argsort(-h)
        for idx in order:
            room = h[idx]
            rem = min(room, -residual)
            h[idx] -= rem
            residual += rem
            if abs(residual) < 1e-12:
                break
    return h

def solve_pair_subproblem(c0, L, Q_nonzero, d_lo, d_hi):
    """
