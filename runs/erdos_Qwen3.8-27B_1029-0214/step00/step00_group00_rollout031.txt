    corr = np.correlate(h, 1 - h, mode="full")

    corr = np.correlate(h, 1 - h, mode="full") * dx
    m = np.max(corr)
    if alpha * m > 500:
        # numerically stable
        shifted = corr - m
        return m + np.log(np.sum(np.exp(alpha * shifted))) / alpha

One issue: the log-sum-exp approximation, even with high alpha, adds a small positive bias to the true max. Specifically:
log-sum-exp(alpha * (c - m)) / alpha ≈ log(sum(exp(alpha*(c_k - m))))/alpha
= log(e^0 + sum_{k≠argmax} exp(alpha*(c_k - m))))/alpha
≈ log(1 + S * exp(-alpha * d))/alpha  where S is the number of near-max terms and d is the typical gap

For alpha=10000 and d=0.001: exp(-10) ≈ 4.5e-5, so the bias is about log(1 + S*4.5e-5)/10000 ≈ S*4.5e-5/10000 ≈ S*4.5e-9. This is negligible.

But if d is very small (like 1e-5), then exp(-alpha*d) = exp(-0.1) ≈ 0.9, and the bias is log(1+S*0.9)/10000 which could be significant.

In practice, when several lags are very close to the max, the log-sum-exp still gives a good approximation because it's smoothly interpolating between them.

    dx = 2.0 / n
