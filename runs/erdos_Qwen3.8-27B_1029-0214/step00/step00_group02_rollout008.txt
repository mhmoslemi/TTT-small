∂c[k*]/∂h[i] = (1-h[i-k*]) - h[i+k*] (approximately, considering both terms where h[i] appears)

Wait, c[k] = sum_n h[n+k]*(1-h[n]). h[i] appears in:
- Term n=i: h[i+k]*(1-h[i]), derivative w.r.t. h[i] is -h[i+k]
- Term n=i-k: h[i]*(1-h[i-k]), derivative w.r.t. h[i] is (1-h[i-k])

So ∂c[k]/∂h[i] = (1-h[i-k]) - h[i+k] (for valid indices)

If the active lag is k*, then to decrease the score, I want to move h[i] in the direction that decreases c[k*]. If ∂c[k*]/∂h[i] > 0, decreasing h[i] helps. If < 0, increasing h[i] helps.

So the "descent direction" for position i is: decrease h[i] if ∂c[k*]/∂h[i] > 0, increase if < 0.

A pair move (s → t) helps if:
∂c[k*]/∂h[s] * (-1) + ∂c[k*]/∂h[t] * (+1) < 0
i.e., -∂c[k*]/∂h[s] + ∂c[k*]/∂h[t] < 0
i.e., ∂c[k*]/∂h[t] < ∂c[k*]/∂h[s]

So we should move from positions with high partial derivative to positions with low partial derivative.

import numpy as np
import time

def compute_score(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr)) * dx, int(np.argmax(corr)) - (len(h) - 1)

def compute_score_only(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr)) * dx

def gridify(h, M):
    n = len(h)
    target = M * n // 2
    H = np.round(h * M).astype(np.int32)
    H = np.clip(H, 0, M)
    err = target - int(H.sum())
    if err > 0:
        order = np.argsort(H)
        i = 0
        while err > 0:
            idx = int(order[i % n])
            if H[idx] < M:
                H[idx] += 1
                err -= 1
            i += 1
    elif err < 0:
        order = np.argsort(-H)
        i = 0
        while err < 0:
            idx = int(order[i % n])
            if H[idx] > 0:
                H[idx] -= 1
                err += 1
            i += 1
    return H

def gradient_of_corr(h, k):
    """Compute partial derivative of c[k] w.r.t. each h[i]."""
    n = len(h)
    grad = np.zeros(n)
    one_minus_h = 1.0 - h
    # c[k] = sum_n h[n+k] * (1-h[n]) for valid n
    # h[i] appears as h[n+k] when n = i-k, and as (1-h[n]) when n = i
    # d/dh[i] of h[n+k]*(1-h[n]):
    #   when n+k = i (n = i-k): (1-h[i-k]) [if i-k valid]
    #   when n = i: -h[i+k] [if i+k valid]
    
    if k >= 0:
        # valid n: 0 to n-1-k
        for i in range(n):
            # h[i] as h[n+k]: n = i-k, valid if 0 <= i-k <= n-1-k, i.e., k <= i <= n-1
            if k <= i <= n - 1:
                grad[i] += one_minus_h[i - k]
            # h[i] as (1-h[n]): n = i, valid if 0 <= i <= n-1-k, i.e., 0 <= i <= n-1-k
            if 0 <= i <= n - 1 - k:
                grad[i] -= h[i + k]
    else:
        kk = -k
        # valid n: kk to n-1
        for i in range(n):
            # h[i] as h[n+k] = h[n-kk]: n = i+kk, valid if kk <= i+kk <= n-1, i.e., 0 <= i <= n-1-kk
            if 0 <= i <= n - 1 - kk:
                grad[i] += one_minus_h[i + kk]
            # h[i] as (1-h[n]): n = i, valid if kk <= i <= n-1
            if kk <= i <= n - 1:
                grad[i] -= h[i - kk]
    return grad
