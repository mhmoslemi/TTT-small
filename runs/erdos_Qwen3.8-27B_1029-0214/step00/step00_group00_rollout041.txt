  ΔC_k = -1 * [(1-h[i-m_k])*[i-m_k valid first] - h[i+m_k]*[i+m_k valid second]]
         + 1 * [(1-h[j-m_k])*[j-m_k valid first] - h[j+m_k]*[j+m_k valid second]]

Where m_k is the lag for the k-th term.

This gives an O(1) update per (swap, lag) pair, and there are O(n) lags, so O(n) per swap evaluation. With O(n^2) possible swaps, that's O(n^3) per full sweep. For n=46, that's about 100K operations, which is very fast.

def lse_obj_grad(h, s):
    n = len(h)
    terms = compute_c5_all(h)
    m = np.max(terms)
    exp_terms = np.exp(terms - m)
    Z = np.sum(exp_terms)
    obj = (m + np.log(Z)) / s
    weights = exp_terms / Z
    dx = 2.0 / n
    grad = np.zeros(n)
    for k in range(2 * n - 1):
        m_lag = k - (n - 1)
        w = weights[k] * dx
        if abs(w) < 1e-15:
            continue
        if m_lag >= 0:
            e = n - m_lag
            grad[m_lag:] += w * (1.0 - h[:e])
            grad[:e] -= w * h[m_lag:]
        else:
            a = -m_lag
            e = n - a
            grad[:e] += w * (1.0 - h[a:])
            grad[a:] -= w * h[:e]
    return obj, grad / s
