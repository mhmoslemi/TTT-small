1. Approach and rationale

1.1 Central idea

The supplied evaluator is a nonsmooth, nonconvex minimization over the original vector

`h ∈ R^n`, `dx = 2/n`, `0 <= h_i <= 1`, `sum(h) = n/2`,

of the finite-support directed overlap score

`C5(h) = max_l dx * sum_valid_i h_i * (1 - h_{i-(l-(n-1))})`.

The supplied evaluator is

`C5(h) = max(np.correlate(h, 1-h, mode="full")) * (2/n)`.

The approach proposed here is materially different from a smooth auxiliary-objective search and different from an auxiliary smooth relaxation in transformed variables. It uses the original vector of values `h`, maintains explicit feasibility on the box-plus-sum polytope, and performs **sequential linearized minimax exploitation**. At each incumbent `h^k`, only highest-overlap lags are selected. Each selected lag is locally linearized exactly once by its true gradient. A small convex optimization subproblem in the original `h` variables selects a trial point that reduces the *linearized* worst lag, while forcing feasibility and staying within a trust region. A short deterministic line search then evaluates the **real NP correlate objective** on convex combinations of the incumbent and the trial. If the real objective improves, the incumbent is updated; otherwise the model step is rejected and the search adapts or moves to a different start/resolution.

1.2 Why the approach is reasonable

The objective is close to a maximum of many near-active constraints. At a near-optimal parent, the dominant lags form an index subset that can be represented by affine linearizations of their gradients. A convex active-set linear model is weak locally, but within a small trust radius it gives sensible improvement directions without requiring smooth surrogates, auxiliary variables, or periodic relaxation. Feasibility in the original variables is simple because the feasible set is the intersection of a box with a single hyperplane. Projection or water-filling can be performed correctly and cheaply.

The real evaluator is used both for incumbent scoring and acceptance. Convexity is claimed only for the local **linearized model**, not for the original problem. No global optimum is claimed. A valid upper bound is produced only by producing a tested feasible vector whose exact correlate score is checked. The very small target gap (from `.38085` to `.3808`) justifies a parent-guided active-set/local/nonmonotone method with multistart and multiresolution capabilities, rather than a blind low-dimensional representation family.

1.3 Main limitations

- Linearized model steps can move in a direction that is excellent for the active model but poor under the true products. Exact line search is used to reject such steps.
- Omitted nonactive lags can become maximum after a step. A sufficient number of currently highest lags is carried into the model, and explicit objective line search guards acceptance.
- The original problem is nonconvex; local progress is not a proof of global optimality or of failure elsewhere. The time budget is used for multiple starts/resolutions and exact verification.
- Convex subproblem solvers can be sensitive to tolerances. All accepted candidates are independently revalidated with box and sum feasibility plus the exact objective.
- Increasing resolution adds more lags and can be both a benefit and a source of obstruction. Transfers from the parent are tested and compared using the actual metric; the parent remains the fallback.

2. Mathematical specification

2.1 Exact problem on discrete samples

For a vector `h` of length `n`:

- `dx = 2.0 / n`
- sample constraints:
  - `h_i ∈ [0, 1]`
  - `sum(h) = n/2` specifically, mathematically, not by heuristic clipping.
- The correlated overlap value used for scoring is computed by:

`q_raw = np.correlate(h, 1-h, mode="full")`

`C(h) = max(q_raw) * dx`.

This is the bound that the returned construction certifies: if a returned vector has exact score at successful acceptance `bestC`, then the constructed upper bound is `bestC`.

2.2 Equivalent analytical lag representation for gradients

For indexing, define a lag offset from the middle full correlation vector:

`m = 0, ..., 2n-2` (total `2n-1` correlations)

`s = m - (n-1)` (integer lag offset in `-(n-1),...,+(n-1)`)

The gradient form that matches the np finite-support correlation order is:

For `s >= 0` and overlap length `L = n - s`:

`q_s = dx * sum_{i=s}^{n-1} h_i * (1 - h_{i-s})`

Equivalently, with first product index as `i` and offset parameter `s`.

For `s < 0`; let `r = -s` and `L = n - r`:

`q_s = dx * sum_{i=0}^{n-1-r} h_i * (1 - h_{i+r})`

The gradient of the scaled correlation term `q_s` with respect to `h` is computed entrywise:

If `s >= 0`, `L = n - s`:

- contribution from terms where `h_k` appears as the first factor:
  - `g[k] += dx * (1 - h_{k-s})` for `k = s, ..., n-1`
  - vector slice update: `g[s:n] += dx * (1 - h[:L])`
- contribution from terms where `h_k` appears as the second factor (inside complement, with negative derivative):
  - `g[k] += -dx * h_{k+s}` for `k = 0, ..., n-1-s`
  - vector slice update: `g[:L] -= dx * h[s:n]`

For `s < 0`, `r = -s`, `L = n - r`:

- first-factor positions `k = 0, ..., n-1-r`:
  - `g[:L] += dx * (1 - h[r:])`
- second-factor positions `k = r, ..., n-1`:
  - `g[r:] -= dx * h[:L]`

For `s = 0`, the two updates give `g = dx * (1 - 2h)`, as expected for `dx * sum_i h_i(1-h_i)`.
