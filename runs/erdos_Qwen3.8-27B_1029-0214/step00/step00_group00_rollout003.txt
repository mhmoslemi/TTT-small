```python
            best_h = h.copy()
    
    # Final validation
    best_h = project_h(best_h, len(best_h))
    best_c5 = compute_c5(best_h)
    
    return best_h, best_c5, len(best_h)
```

Hmm, but this is quite basic. Let me think about what additional techniques would help.

Key insight: the problem is to minimize a max of (2n-1) bilinear functions subject to linear constraints. This is a non-convex problem, but locally around a good point, the active set (which lags are near the maximum) determines the geometry.

A more sophisticated approach:
1. Identify the active lags (those within, say, 5% of the maximum)
2. Try to simultaneously reduce all active lags
3. This is like a multi-objective optimization problem

For the LP approach:
- Linearize the active constraints
- Solve the LP to find a direction that reduces all active lags simultaneously
- This gives a better direction than the smoothed gradient

Let me implement this:

    corr = np.correlate(h, 1.0 - h, mode="full")
    tau = float(np.max(corr))
    
    # Select active lags (within 10% of max)
    threshold = tau - 0.1 * tau
    active = np.where(corr >= threshold)[0]
    
    if len(active) == 0:
        return None

    if len(active) > 80:
        # Keep the top 80 by value
        sorted_idx = active[np.argsort(corr[active])[::-1][:80]]
        active = sorted_idx

    # s.t. t >= C_k(h) + grad_k · (h_new - h) for k in active
