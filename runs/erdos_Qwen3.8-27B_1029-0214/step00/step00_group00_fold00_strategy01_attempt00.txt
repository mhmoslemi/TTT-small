1. Approach and rationale

The central idea is to perform a derivative-free global/nonconvex search in a raw representation that is always repaired to a feasible box-plus-sum step vector, then always judge candidates by the exact provided discrete objective. This is materially different from smooth-maxima, local linear programming, or QP-majorization plans. Instead of trying to convexify or linearize the bilinear overlap terms, this plan treats the nonconvex discrete objective as a black box, but removes the feasibility bottleneck by using one canonical joint projection onto the set

K_n = {h ∈ R^n : 0 ≤ h_i ≤ 1, ∑ h_i = n/2}.

Let raw variables be z ∈ R^n. A candidate step vector is produced by the continuous map

T_n(z) = clip(z - λ(z), 0, 1),

where λ(z) is chosen so that

∑_{i=0}^{n-1} clip(z_i - λ(z), 0, 1) = n/2.

For every feasible h, setting z = h gives T_n(z) = h, because ∑ z = n/2. Therefore the transformed search does not restrict the feasible set. Every raw candidate is converted to (or corrected to) a feasible vector before evaluation, and no candidate is accepted unless its exact official score is computed and stored as a feasible vector. If the supplied parent is available, it is first validated and becomes the fallback best solution; the algorithm only replaces it when an exact scored candidate is better. This gives a practical improvement path and a guaranteed no-worse-than-parent behavior whenever the parent is available and valid.

Why this addresses the bottleneck:

- The hard constraints are the simultaneous box and equality constraints. The scalar-threshold projection is a standard మరియు reliable joint projection; it avoids clipping-plus-rescaling, which can violate one constraint after fixing the other.
- The objective is nonconvex and nonsmooth because it is a maximum over 2n-1 lag overlaps. The plan does not require gradients, Hessians, convex relaxations, active-set quadratics, or any assumption of convexity.
- The nonconvex search is handled by a projected population/stochastic update scheme with many deterministic and stochastic candidate patterns around the parent and around the current best. Because every candidate is scored by the authoritative np.correlation objective, all surrogate or stochastic decisions are only proposals; acceptance is exact.
- The supplied 45-point parent construction is used directly; it is transformed to other resolutions by measurable-function resampling when beneficial. Resolution changes are allowed because the returned vector is always checked in its own exact resolution.

Hypotheses vs facts:
- Fact: T_n(z) returns values in the feasible interval and enforces the sum constraint up to numerical tolerance; a final repair enforces the sum exactly to a very tight tolerance while preserving bounds.
- Fact: The candidate acceptance routine only uses exact np.correlation(..., mode='full') scoring, including all 2n-1 lags, not a reduced, circular, symmetric-only, or autocorrelation-derived surrogate.
- Fact: If a valid parent is supplied and fallback best storage/acceptance is implemented as specified, the returned solution cannot be worse than the exact exact-scored score of the repaired parent, because the parent vector is saved first and only smaller exact scores are used for updates. If no candidate improves, the parent is returned.
- Hypothesis/heuristic: Population search, descendant/ancestor patches, symmetrization, resolution lifting, and coordinate-transfer scans will find better local minima than the supplied parent. This is not mathematically guaranteed, but it is empirically appropriate for a small-resolution nonsmooth discrete design problem.

2. Mathematical specification

Discrete model and exact objective.

For a chosen integer resolution n ≥ 7, define

dx = 2.0 / n,
target_sum = n / 2.

A vector h ∈ R^n is a discrete candidate step function on uniform cells [i dx, (i+1) dx). The official discrete constraints are:

0 ≤ h_i ≤ 1 for all i,
∑_{i=0}^{n-1} h_i = n/2.

The authoritative objective is exactly:

C(h,n) = dx * max( np.correlate(h, 1_h, mode="full") ),

where 1_h is the array of the same shape with entries 1 - h_i. The full correlation output contains all 2n-1 lag terms, both directions and boundary-truncated terms. Do not replace the maximum over this full output by another formula such as 1 minus a minimum autocorrelation. Do not replace np.correlation by any manually reordered formula unless it is first verified to produce identical floating values for the actual code; the recommended implementation directly uses np.correlation as the only authoritative objective.

The score to minimize is C(h,n). A vector h is valid if all entries are finite, 0 ≤ h_i ≤ 1 (after a tiny numerical clip tolerance), and the sum is 0 or very close to n/2. All lower C values are better. A numerical tolerance of 1e-9 or smaller for the sum residual is acceptable during search, but final return must pass after an explicit force-sum repair, and the returned bound must be recomputed on the final returned vector.

Joint box-and-sum projection T_n.

Input: raw vector z ∈ R^n, target S = n/2, tolerance tol.

Define for scalar λ:

g(λ) = ∑ clip(z_i - λ, 0, 1).

g is continuous and monotonically nonincreasing: if λ increases, every clipped value stays the same or decreases, so the sum cannot increase. As λ → -∞, all entries go to 1 and g(λ) → n. As λ → +∞, all entries go to 0 and g(λ) → 0. Since S = n/2 ∈ (0,n), there exists λ with g(λ)=S.

Implementation of λ:
- Bracket λ:
  lo = min(z) - 2 * (max(z) - min(z) + 1) - 2,
  hi = max(z) + 2 * (max(z) - min(z) + 1) + 2.
  Recompute g(lo) and g(hi). While g(lo) < S, replace lo by lo - 2 * (hi - lo + 2) and recompute. While g(hi) > S, replace hi by hi + 2 * (hi - lo + 2) and recompute.
- Bisect λ for up to 100 evaluations:
  mid = 0.5*(lo+hi).
  If g(mid) > S, move lo to mid; otherwise move hi to mid.
  Stop when hi-lo is below 1e-10 or after 60-100 iterations.
- Set h = clip(z - lo, 0, 1). Choose λ final as lo.

- If residual > 0 (sum too small): let cap = sum(max(1 - h, 0)). If cap > 1e-14, set h_i += residual * max(1 - h_i, 0) / cap.
