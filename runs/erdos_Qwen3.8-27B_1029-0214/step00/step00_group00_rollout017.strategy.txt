1. Approach and rationale

The central idea is to treat the exact returned discrete objective as a finite set of literal constraints and solve the epigraph problem

    minimize t
    subject to 0 <= h_i <= 1,
               sum_i h_i = n/2,
               L_k(h) <= t  for every allowed lag k,

where L_k(h) is exactly the entry of np.correlate(h, 1-h, mode="full") multiplied by dx = 2/n for the corresponding finite-support cross-correlation lag. Instead of perturbing a smoothed surrogate or using a linear procedure only, the primary optimization is a local exact max-constraint solver. This directly attacks the active slopes that determine the upper envelope. The method starts from the validated supplied construction, transfers devil's advocate variants if the parent is available, refines on the same grid, and then moves to selected finer piecewise-constant grids. Every proposal that can become the output is repaired to the discrete constraints and accepted by the authoritative evaluator formula. This is robust because the parent construction is never discarded unless a valid feasible vector with a smaller exact objective has found one.

The problem is not convex: each lag constraint contains the bilinear product h_i h_{i+r}. Therefore the method is not a global optimizer and its output cannot be certified globally optimal. It is a deterministic local/nonlinear minimax refinement. The expected mathematical property is that the parent is likely near a local extremum but with the exact constraints and their exact gradients the solver can search directions that reduce several active overlap constraints at the same time. Multi-resolution variation is important because a coarser structured optimum may be improved by allowing more breakpoints, or by rounding points onto finer grids, but the final returned grid is whatever single feasible vector with the smallest authoritatively evaluated bound has actually found.

Important differences from a generic active-constraint LP/smoothed-gradient search:
- The primary formulation is the full epigraph of the same discrete objective; the maximization variable t is a true independent variable optimized with all exact nonlinear lag constraints, not a heuristic max-penalty.
- The objective is linear in the decision vector, while the nonlinearities are only in the constraints, which use exact manually enumerated finite-support cross-correlation terms.
- Candidate acceptance does not use surrogate objective values or linear-model predictions; only the exact evaluator formula may claim an improvement.
- Parent variants mirror/flip constraints and different coercive transformations are tried as coherent symmetric or complementary map changes rather than just restarting random nodes.

Bottlenecks addressed:
- The max objective is nonsmooth, and the only useful directions are those that decrease all currently maximum or near-maximum lag terms. The epigraph solver provides exact gradients for all active constraints simultaneously.
- A single fixed grid resolution may have too few degrees of freedom; simultaneous truncation and sum constraints make ad hoc grid changes dangerous. The transfer and exact projection procedure keeps feasibility while allowing resolution optimizations.
- The supplied parent may already be a valid local point; the best valid remaining fallback always includes a repaired exact evaluation of the validated parent, so a later failure cannot make the output worse than the parent from exact objective.
