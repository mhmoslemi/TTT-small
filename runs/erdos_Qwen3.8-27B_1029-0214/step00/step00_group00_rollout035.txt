from scipy.optimize import minimize
import time

def compute_correlations(h, n):
    """Compute all 2n-1 correlation terms (scaled by dx)."""
    dx = 2.0 / n
    corr = np.correlate(h, 1 - h, mode="full")
    return corr * dx

def lsq_gradient(h, n, beta, T):
    """Compute gradient of log-sum-exp objective."""
    dx = 2.0 / n
    # Softmax weights
    T_max = np.max(T)
    weights = np.exp(beta * (T - T_max))
    weights /= np.sum(weights)
    
    # Gradient is weighted sum of individual gradients
    grad = np.zeros(n)
    
    # k=0: T_0 = dx * sum_i h[i]*(1-h[i])
    # dT_0/dh[i] = dx * (1 - 2*h[i])
    grad += weights[0] * dx * (1 - 2*h)
    
    # For k=2r, r>=1: T = dx * sum_{i=0}^{n-r-1} h[i]*(1-h[i+r])
    # dT/dh[i] for i in [0, n-r): += dx * (1-h[i+r])
    # dT/dh[i] for i in [r, n): += -dx * h[i-r]
    for r in range(1, n):
        e = n - r
        w = weights[2*r]
        grad[:e] += w * dx * (1 - h[r:])
        grad[r:] += -w * dx * h[:e]
        
        w = weights[2*r+1]
        grad[r:] += w * dx * (1 - h[:e])
        grad[:e] += -w * dx * h[r:]
    
    return grad

The problem is equivalent to: given a binary (or real-valued) sequence of length n with sum n/2, minimize the maximum aperiodic cross-correlation with its complement.

For binary sequences, this is related to "low autocorrelation" sequences. The well-known constructions include:
- Reed-Muller sequences
- Legendre sequences (for prime n)
- Barker sequences (for small n)

But our problem is different because we're correlating h with (1-h), not h with h.

For a binary sequence h (0-1 valued), the cross-correlation with (1-h) at shift r is:
R(r) = sum_{i=0}^{n-r-1} h[i] * (1-h[i+r])

This equals the number of positions where h has a 1 and h shifted by r has a 0.

If we let a[i] = 2*h[i] - 1 (so a[i] ∈ {-1, +1}), then:
h[i] = (1+a[i])/2, 1-h[i+r] = (1-a[i+r])/2
h[i]*(1-h[i+r]) = (1+a[i])(1-a[i+r])/4 = (1 - a[i]*a[i+r] + a[i] - a[i+r])/4

So R(r) = sum_{i=0}^{n-r-1} (1 - a[i]*a[i+r] + a[i] - a[i+r])/4
= (n-r)/4 - (1/4)*sum a[i]*a[i+r] + (1/4)*sum a[i] - (1/4)*sum a[i+r]

If the sequence is "balanced" (sum a[i] ≈ 0), then:
R(r) ≈ (n-r)/4 - (1/4)*A(r)

where A(r) = sum_{i=0}^{n-r-1} a[i]*a[i+r] is the aperiodic autocorrelation.

To minimize max_r R(r), we want to maximize min_r A(r) (make the autocorrelation as large as possible, i.e., as positive as possible). But wait, that doesn't sound right because we want the max R(r) to be small.

R(r) = (n-r)/4 - A(r)/4 + (sum a[i] - sum a[i+r])/4

If sum a[i] = 0 (balanced), then:
R(r) = (n-r)/4 - A(r)/4

To minimize max_r R(r), we want A(r) to be as large as possible for the r where (n-r) is large. But A(r) can be negative...

Actually, for a balanced sequence (n/2 ones, n/2 zeros), sum a[i] = 0. Then:
R(r) = (n-r)/4 - A(r)/4

The term (n-r)/4 is large for small r. So we need A(r) to be close to (n-r) for small r, meaning a[i] ≈ a[i+r] for most i. But that's hard to achieve for all r simultaneously.

For r=1: R(1) = (n-1)/4 - A(1)/4. If a is "smooth" (few transitions), A(1) is large.

            total_room = room.sum()
            if total_room < 1e-15:
                break
            s = min(res / total_room, 1.0)
            h[mask] = np.minimum(h[mask] + s * room, 1.0)

            total_cap = cap.sum()
            if total_cap < 1e-15:

            h[mask] = np.maximum(h[mask] - s * cap, 0.0)
    return h

    T = compute_T(h, n)
    tmax = T.max()
    shifted = beta * (T - tmax)
    exp_vals = np.exp(shifted)
    log_sum = np.log(exp_vals.sum())
    w = exp_vals / exp_vals.sum()
    val = tmax + log_sum / beta
    
    dx = 2.0 / n
    grad = np.zeros(n)
    grad += w[0] * dx * (1.0 - 2.0 * h)
    for r in range(1, n):
        e = n - r
        grad[:e] += w[2*r] * dx * (1.0 - h[r:])
        grad[r:] += (-w[2*r] * dx) * h[:e]
        grad[r:] += w[2*r+1] * dx * (1.0 - h[:e])
        grad[:e] += (-w[2*r+1] * dx) * h[r:]
    
    return val, grad

Let me double-check the gradient formula:

T_{2r} = dx * sum_{i=0}^{n-r-1} h[i] * (1 - h[i+r])

∂T_{2r}/∂h[j]:
- If j < n-r: h[j] appears as the first factor → ∂/∂h[j] = dx * (1 - h[j+r])
- If j ≥ r: h[j] appears as h[i+r] where i = j-r < n-r → ∂/∂h[j] = dx * (-h[j-r])
- So for j in [0, min(n-r, r)): both terms contribute
- For j in [0, n-r): first term
- For j in [r, n): second term

In array notation:
grad[:n-r] += w[2r] * dx * (1 - h[r:])  [first term: j from 0 to n-r-1, h[j+r]]
grad[r:] += -w[2r] * dx * h[:n-r]       [second term: j from r to n-1, h[j-r]]

Similarly for T_{2r+1} = dx * sum_{i=0}^{n-r-1} h[i+r] * (1 - h[i]):
∂T_{2r+1}/∂h[j]:
- If j ≥ r: h[j] appears as h[i+r] where i = j-r → ∂/∂h[j] = dx * (1 - h[j-r])
- If j < n-r: h[j] appears as h[i] where i = j → ∂/∂h[j] = dx * (-h[j+r])

In array notation:
grad[r:] += w[2r+1] * dx * (1 - h[:n-r])   [first term: j from r to n-1]
grad[:n-r] += -w[2r+1] * dx * h[r:]         [second term: j from 0 to n-r-1]
