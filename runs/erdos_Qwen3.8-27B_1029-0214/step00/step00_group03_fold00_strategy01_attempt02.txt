1. Approach and rationale

1.1 Central idea
The submitted evaluator defines a finite-support, exact nonconvex minimax objective. Every returned vector must satisfy only two structural constraints:

- zero-one box bounds, `0 <= h[i] <= 1`;
- an equi-measure sum, `sum(h) == n_points / 2`.

The objective is

`C5(h) = max_k np.correlate(h, 1 - h, mode="full")[k] * (2.0 / n_points)`.

No global convex formulation is available because products of entries of `h` and `1-h` create bilinear/indefinite terms. Therefore the plan does not claim convergence to the global optimum. It instead constructs a monotone, exact-objective reducing optimizer that uses several complementary mechanisms designed to exploit the parent construction and finely polish it:

1. exact one-dimensional pair-preserving updates, where the whole objective vector is known exactly along each feasible solver direction;
2. projected log-sum-exp descent that approximates the nonsmooth maximum symmetrically and uses a soft gradient of the active/active-substitution terms;
3. a linear active-gradient descent direction subproblem, solved as a bounded LP, followed by exact line search against the original metric;
4. a local epigraph nonlinear solver for variables consisting of `h` and an auxiliary threshold `t`, used from the best vector, transferred vectors, and randomized feasible starts;
5. optional resolution transfer and reoptimization, because another final discretization length can sometimes produce a smaller returned objective.

The search strategy is intentionally local/nonsmooth rather than global. The mathematical component is sound because every accepted point is rounded and validated in the feasible set and scored using the authoritative evaluator. The nonconvexity limitation is explicit: this is a construction method, not a proof of global optimality.

1.2 Why this should be materially effective compared with simple local methods
The parent construction is already close to the current record, so the improvement is likely in the last digit of the objective and may require:

- suppressing inactive but soon-active correlations through a smooth-max approximation, instead of optimizing merely one active lag;
- considering sum-preserving local moves over large dimensions, not only a single active correlation;
- using a nonlinear 1D exact formula along pair directions, which bounds objective transitions exactly and avoids invalid trial states;
- treating the maximal correlation expi t as an epigraph variable and allowing `SL_n_eqp_sq` to optimize the exact nonlinear terms;
- retaining all candidates and spending time on several starting candidates, because the bilinear landscape may contain shallow local basins.

1.3 Important limitations and hypotheses
- The original optimization is nonconvex; none of these stages proves optimality.
- Smooth log-sum-exp stages and LP descent directions monitor an approximation or first-order surrogate, not necessarily the true nonsmooth objective. Candidate points are accepted only if reduced by the exact objective. Exact local acceptance test is mandatory.

2.2 Internal exact term representation
Choose one unambiguous internal convention for speed, pairing, smoothing, and gradients.

For lag `s = -N+1, ..., N-1`, internal correlation term:

`G(s) = sum_{p = lower}^{upper-1} h[p] * (1 - h[p + s])`,

where overlap conditions are:

`lower = max(0, -s)`, `upper = min(N, N - s)`.

`m = s + (N - 1)`, so `m = 0,...,2N-2`.

The resulting set `{G(s)}` is the same set of linear finite correlation values as the evaluator under possible reversal. Therefore the internal score

`score_internal(h) = max_m G(m) * dx`

should equal `C5_exact(h)`.

The product zeros outside are handled only by summing over valid overlaps. This matches the evaluator exactly because the evaluator discards non-overlap terms in linear correlation. This is not the continuous-underline integral convention where outside `1-h` could be 1. Follow the evaluator as literally state.

2.3 Exact gradient for internal term
For one internal lag `s`, the derivative of `G(s)` with respect to component `i` is:

`d G(s) / d h_i = q(i + s) - h(i - s)`,

where term:

`q(j) = 1 - h[j]`;
`h(j)` is `h_j`, and invalid component references outside `0..N-1` are zero.

Alternatively, the sum contribution is only valid when both indices are in range:

- add `q(i+s)` if `i` and `i+s` are valid;
- subtract `h(i-s)` if `i-s` and `i` are valid.

For every lag, gradient vector can be constructed in O(N). Return an array of shape `(2N-1, N)`, row m equals the gradient vector of `G(s)` for corresponding lag.

Special case `s=0`:

`G(0) = sum_i h_i (1-h_i)` and derivative is `1 - 2 h_i`.

Handle numerical invalid occurrence. This is compatible with the evaluator up to reindexing/reversal as described.
