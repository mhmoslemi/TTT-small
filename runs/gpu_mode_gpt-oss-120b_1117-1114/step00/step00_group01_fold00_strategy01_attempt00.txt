2. **Mathematical Specification**  
   Let `config["dim"]` denote the input feature dimension, and `config["hidden_dim"]` denote the hidden dimension. Given an input tensor `x` of shape `[B, N, N, C]` and an optional mask tensor of shape `[B, N, N]`, the TriMul forward operation is defined as:  
   ```python  
   batch_size, seq_len, _, dim = x.shape  
   hidden_dim = config["hidden_dim"]  
   left_proj = LinearProjection(dim, hidden_dim)(x)  
   right_proj = LinearProjection(dim, hidden_dim)(x)  
   left_gate = SigmoidGate(LinearProjection(dim, hidden_dim)(x))  
   right_gate = SigmoidGate(LinearProjection(dim, hidden_dim)(x))  
   out_gate = SigmoidGate(LinearProjection(dim, hidden_dim)(x))  
   # Apply mask (if available)  
   if mask is not None:  
       mask_expanded = mask.unsqueeze(-1)  
       left_proj = left_proj * mask_expanded  
       right_proj = right_proj * mask_expanded  
   # Then the core computation is:  
   # out_temp[b, i, j, k] = σ(out_gate[b, i, j, k]) *  
   #   sum_{d=0}^{seq_len-1} (left_proj[b, i, d, k] * right_proj[b, j, d, k])  
   # For dimensions, let:  
   #   B = batch_size  
   #   N = seq_len  
   #   C = dim  
   #   H = hidden_dim  
   #   The output tensor `out_temp` has shape [B, N, N, H]  
   ```  
   Let `x_norm` be the normalized input `[B, N, N, C]`. The core triangular part for this is computed as:  
   ```python  
   out_temp[i, j, :] = sum_{d} left_proj[i, d, :] * right_proj[j, d, :]   [for each (b, k)]  
   ```  
   Then normalization and projection:  
   ```python  
   out = LayerNorm(H)(out_temp)  
   out = LinearLayer(H, hidden_dim)(out) * out_gate   [element-wise linear and then gate]  
   out = final output as linear projection  
   ```
