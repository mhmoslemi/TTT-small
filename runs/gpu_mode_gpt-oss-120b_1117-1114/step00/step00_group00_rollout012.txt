- We must implement the forward pass only.
- Input shape (batch, seq_len, seq_len, dim).
- There's a mask (same shape except no channel dim) that can be applied to left and right after projection (set to zero for masked positions). mask shape [bs, N, N]; we will expand to broadcast to hidden_dim channel.

- The TriMul operation:

Given input X: shape [B, N, N, dim].

x_norm = LayerNorm(dim) applied over the dim dimension (the last axis). That yields same shape [B, N, N, dim]. Since dim is small (128, 384), we can compute it in PyTorch (the host). We can also compute PyTorch's LayerNorm on dtype float32.

Then:

left = left_proj(x_norm)  # shape [B,N,N,hidden_dim] (linear projection without bias)
right = right_proj(x_norm)  # same shape

mask expands to [B,N,N,1], multiply left/right.

Compute left_gate = sigmoid(left_gate_proj(x_norm)) # shape [B,N,N,hidden_dim]; sigmoid
Compute right_gate = sigmoid(right_gate_proj(x_norm)) # shape same
Compute out_gate = sigmoid(out_gate_proj(x_norm))  # shape [B,N,N,hidden_dim] (or shape [B,N,N, hidden_dim])? Actually out_gate is a linear projection from dim to hidden_dim, then sigmoid. In original code, out_gate = self.out_gate(x).sigmoid() -> shape [B,N,N,hidden_dim].

Now left = left * left_gate, right = right * right_gate.

Now compute out: contraction via einsum: '... i k d, ... j k d -> ... i j d' i.e., for each b, i, j, d: sum over k (left[b,i,k,d] * right[b,j,k,d]).

Interpretation: left is shape [B, N, N, hidden_dim]. Note left's second dimension is i, third dimension is k. right's second dim is j, third dim is k. So both have a dimension of shape N (k). We need sum over the third (k) dimension for each pair (i,j). It's similar to a batched matrix multiplication but with shape [B, N, N, hidden_dim] where we treat hidden_dim as extra channel, and we need to compute a product between left slice (i,k) and right (j,k) for each hidden_dim.

One can reinterpret: For each batch b and channel d, we have left[b,:,:,d] (N,N) and right[b,:,:,d] (N,N). We need compute out[b,:,:,d] = left[b,:, :, d] @ right[b,:, :, d].T? Actually left's dimensions: left[b,i,k] and right[b,j,k]. If we consider left as N_i x N_k matrix and right as N_j x N_k matrix, the contraction over k yields something like out[i,j] = sum_k left[i,k] * right[j,k], which is essentially left @ right^T (since right[j,k] but we want sum over k; matrix multiplication left (i,k) times right (j,k) transposed gives sum over k left[i,k] * right[j,k]?). Wait typical matrix multiplication C = A @ B where A shape (i,k), B shape (k,j) -> C[i,j] = sum_k A[i,k] * B[k,j]. Here we have sum over k of A[i,k] * B[j,k], which is A @ B^T where B^T shape (k,j). Indeed left (i,k) * right (j,k) = left (i,k) * right_transposed(k,j) => C[i,j] = sum_k left[i,k] * right_T[k,j] = sum_k left[i,k] * right[j,k] (since B_T[k,j] = B[j,k]). So out = left @ right^T for each channel d separately.

Thus we can compute out for each hidden_dim channel d as a matrix multiplication between left and right transpose. This is similar to batched GEMM across channel dimension.

So we can implement the core operation as a batched matrix multiply: For each b, d: out[b,:,:,d] = left[b,:,:,d] @ right[b,:,:,d].transpose(-1,-2) (with k dimension as axis=2). But left shape is [B,N,N, hidden_dim] where we treat last dim as channel (vector). We can reorder to [B, hidden_dim, N, N]. Then out shape [B, hidden_dim, N, N]. This is a set of independent matrix multiplications, each of size N x N. That's N^2 * hidden_dim multiplies for each batch.

Thus the key is to compute many small matrix multiplications of size N x N, performing them on GPU using Triton effectively. However, typical GEMM implementation in Triton uses block dimensions for M, N, K (K is the reduction dimension). Here K = N of size up to 1024. So we need an efficient kernel for batched GEMM over hidden_dim dimension.

We can treat hidden_dim as "batch dimension" for matrix multiply; each channel is independent. We can launch kernel per batch and per hidden_dim channel. So grid dimension: total number of (B * hidden_dim) tasks.

Then each task computes a matrix multiplication: M=N, N=N, K=N.

We can reuse a standard block matrix multiplication Triton kernel (like matmul). We'll implement a generic blocked matmul for each (b, d) slice.

Also we need to incorporate mask: The mask is applied to left and right before the multiplication (left = left * mask, right = right * mask). The mask shape after unsqueeze: [B,N,N,1] (or [B,N,N]) broadcasted across hidden_dim. This will zero out elements left[i,k] or right[j,k] whichever is masked. This is fine.

Thus the core kernel is just standard matmul.

Given constraints, we can also factor use of built-in torch.nn.functional.linear for projection and gates, and use torch.nn.functional.layer_norm for normalizations, but we need to incorporate weight and bias manually.

     ```
     mean = input_tensor.mean(dim=-1, keepdim=True)
     var = input_tensor.var(dim=-1, unbiased=False, keepdim=True)

     ```
   - However norm_weight shape [dim], bias shape [dim]. Broadcast.

3. Compute projections:

   Use torch.nn.functional.linear for each projection:

   ```
   left = torch.nn.functional.linear(x_norm, left_proj_weight)

   Similarly for right.

   left_gate = torch.nn.functional.linear(x_norm, left_gate_weight).sigmoid()

   ```
   left = left * left_gate
   right = right * right_gate
   ```

   ```
   left_h = left.to(torch.float16)
   right_h = right.to(torch.float16)
   ```

    left_ptr, right_ptr, out_ptr,
    B, H, N,
    stride_left_bn, stride_left_hn, stride_left_in, stride_left_kn,
    stride_right_bn, stride_right_hn, stride_right_kn, stride_right_jn,
    stride_out_bn, stride_out_hn, stride_out_in, stride_out_jn,
    BLOCK_M: tl.constexpr, BLOCK_N: tl.constexpr, BLOCK_K: tl.constexpr
):
    pid = tl.program_id(0)
    total_h = H
    b = pid // total_h
    h = pid % total_h

    # offsets for M and N dimensions
    offs_m = tl.arange(0, BLOCK_M)
    offs_n = tl.arange(0, BLOCK_N)

    # Determine offsets along M,N
    # We need to iterate blocks of rows (i) and columns (j). Typically we need nested loops for blockwise multiplication? But the kernel as given earlier uses loops over K dimension and compute block MxN for each block of K.

    # We'll loop over block-k dimension: for loop over start_k from 0 to N step BLOCK_K.

    # Compute pointer offsets for left and right.
    # left_ptr + (b * stride_left_bn + h * stride_left_hn + i * stride_left_in + k * stride_left_kn)
    # right_ptr + (b * stride_right_bn + h * stride_right_hn + k * stride_right_kn + j * stride_right_jn)

    # Note: we need to compute per output block (i_block, j_block). But we have only 1 program ID per (b,h). So each program ID must compute all blocks of output matrix (i,j) via loops over i and j? Typically matrix multiplication kernels use 2D grid: program_id(0) for M, program_id(1) for N. But we have only 1 dimension. We can launch 2D grid splitting across M and N, but we also need to include batch and channel tasks.

    We could use 2D grid: (grid_m, grid_n) where each block processes a submatrix of output for given (b,h). However we also need to incorporate b and h into grid.

    Approach: Use 2D grid where axis0 is (b*H + h) and axis1 is block-n index. But typical manage with 3D grid: (dim0, dim1, dim2). In Triton, grid = (grid_m, grid_n, batch_chan), we can pass three dimensions.

    Let's define:

    grid = (tl.cdiv(N, BLOCK_M), tl.cdiv(N, BLOCK_N), bs * hidden_dim)

    Then kernel receives program_id(0) for block_i, program_id(1) for block_j, program_id(2) for batch_chan.

    That is easier.

    So modify: In custom_kernel we compute grid = (grid_m, grid_n, total_tasks).

    Then inside kernel:

    pid = tl.program_id(0) -> block_i
    pid_j = tl.program_id(1) -> block_j
    pid_bn = tl.program_id(2) -> batch_chan

    b = pid_bn // H
    h = pid_bn % H

    # Set start indices:
    offs_m = block_i * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_n = block_j * BLOCK_N + tl.arange(0, BLOCK_N)

    # Initialize accumulation
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # Loop over k
    for k in range(0, tl.cdiv(N, BLOCK_K)):
        k_offset = k * BLOCK_K + tl.arange(0, BLOCK_K)
        # compute mask for valid k
        mask_k = k_offset < N
        mask_m = offs_m < N
        mask_n = offs_n < N

        # Compute left block pointer
        left_offset_ptr = left_ptr + \
            b * stride_left_bn + h * stride_left_hn + \
            offs_m[:, None] * stride_left_in + k_offset[None, :] * stride_left_kn

        # right block pointer
        right_offset_ptr = right_ptr + \
            b * stride_right_bn + h * stride_right_hn + \
            k_offset[:, None] * stride_right_kn + offs_n[None, :] * stride_right_jn

        a = tl.load(left_offset_ptr, mask=mask_m[:, None] & mask_k[None, :], other=0.0).to(tl.float32)
        b_mat = tl.load(right_offset_ptr, mask=mask_k[:, None] & mask_n[None, :], other=0.0).to(tl.float32)

        acc += tl.dot(a, b_mat) # but dot expects shape (M,K) and (K,N)? It expects 2D? We can use tl.dot for each row? Actually we can use tl.dot for 2D dot? The standard approach uses `tl.dot(a, b)` where a shape (M,K), b shape (K,N) returns (M,N) dot product.

        # However tl.dot currently expects dimension alignment: typically you do a * b? In many examples they compute `tl.dot(a, b)` where a is (BLOCK_M, BLOCK_K) and b is (BLOCK_K, BLOCK_N). This returns accumulator of (BLOCK_M, BLOCK_N). Yes, TL's dot is defined that way.

        # After dot, accumulate.

        # Increment pointers if needed (but using offsets computed each iteration is fine)
    # End loop

    # store result; apply mask for final out.
    out_ptr_offset = out_ptr + \
        b * stride_out_bn + h * stride_out_hn + \
        offs_m[:, None] * stride_out_in + offs_n[None, :] * stride_out_jn

    tl.store(out_ptr_offset, acc.to(tl.float32), mask=mask_m[:, None] & mask_n[None, :])

def layer_norm(x, weight, bias, eps=1e-5):
    mean = x.mean(dim=-1, keepdim=True)
    var = x.var(dim=-1, unbiased=False, keepdim=True)
    inv_std = torch.rsqrt(var + eps)

    if weight is not None:
        y = y * weight
    if bias is not None:
        y = y + bias
    return y

def custom_kernel(data):
    """
    Triton-accelerated forward pass of the Triangle Multiplicative Update (TriMul) operation.
    ...
    """
    input_tensor, mask_tensor, weights, config = data
    device = input_tensor.device
    dtype = input_tensor.dtype
    bs, N, _, dim = input_tensor.shape
    hidden_dim = config["hidden_dim"]
    # LayerNorm
    norm_weight = weights["norm.weight"]
    norm_bias = weights["norm.bias"]
    x = layer_norm(input_tensor, norm_weight, norm_bias, eps=1e-5)
    # Projections
    left_proj_weight = weights["left_proj.weight"]
    right_proj_weight = weights["right_proj.weight"]
    left = torch.nn.functional.linear(x, left_proj_weight)  # shape [bs,N,N,hidden_dim]
    right = torch.nn.functional.linear(x, right_proj_weight)
    # Mask handling
    if config.get("nomask", False):
        mask = torch.ones_like(mask_tensor, dtype=x.dtype, device=device)
    else:
        mask = mask_tensor.to(x.dtype)
    mask = mask.unsqueeze(-1)  # [bs,N,N,1]
    left = left * mask
    right = right * mask
    # Gates
    left_gate_weight = weights["left_gate.weight"]
    right_gate_weight = weights["right_gate.weight"]
    out_gate_weight = weights["out_gate.weight"]
    left_gate = torch.nn.functional.linear(x, left_gate_weight).sigmoid()
    right_gate = torch.nn.functional.linear(x, right_gate_weight).sigmoid()
    out_gate = torch.nn.functional.linear(x, out_gate_weight).sigmoid()
    # Apply gates
    left = left * left_gate
    right = right * right_gate
    # Convert left/right to half for kernel
    left_h = left.to(torch.float16)
    right_h = right.to(torch.float16)
    # Permute for matmul
    left_perm = left_h.permute(0, 3, 1, 2).contiguous()
    right_perm = right_h.permute(0, 3, 2, 1).contiguous()  # transpose k and j
    # Allocate output tensor
    out_perm = torch.empty((bs, hidden_dim, N, N), dtype=torch.float32, device=device)
    # Strides
    stride_left_b, stride_left_h, stride_left_i, stride_left_k = left_perm.stride()
    stride_right_b, stride_right_h, stride_right_k, stride_right_j = right_perm.stride()
    stride_out_b, stride_out_h, stride_out_i, stride_out_j = out_perm.stride()
    # Grid configuration
    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 64
    grid = (
        triton.cdiv(N, BLOCK_M),
        triton.cdiv(N, BLOCK_N),
        bs * hidden_dim,
    )
    # Launch kernel
    tri_mul_matmul_kernel[grid](
        left_perm,
        right_perm,
        out_perm,
        bs,
        hidden_dim,
        N,
        stride_left_b,
        stride_left_h,
        stride_left_i,
        stride_left_k,
        stride_right_b,
        stride_right_h,
        stride_right_k,
        stride_right_j,
        stride_out_b,
        stride_out_h,
        stride_out_i,
        stride_out_j,
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
    )
    # Permute back to [bs, N, N, hidden_dim]
    out = out_perm.permute(0, 2, 3, 1).contiguous()
    # Output layernorm
    to_out_norm_weight = weights["to_out_norm.weight"]
    to_out_norm_bias = weights["to_out_norm.bias"]
    out = layer_norm(out, to_out_norm_weight, to_out_norm_bias, eps=1e-5)
    # Apply output gate
    out = out * out_gate
    # Final linear projection
    to_out_weight = weights["to_out.weight"]
    out = torch.nn.functional.linear(out, to_out_weight)
    return out

@triton.jit
def tri_mul_matmul_kernel(
    left_ptr, right_ptr, out_ptr,
    B, H, N,
    stride_left_b, stride_left_h, stride_left_i, stride_left_k,
    stride_right_b, stride_right_h, stride_right_k, stride_right_j,
    stride_out_b, stride_out_h, stride_out_i, stride_out_j,
    BLOCK_M: tl.constexpr,
    BLOCK_N: tl.constexpr,
    BLOCK_K: tl.constexpr,
):
    pid_i = tl.program_id(0)   # block row
    pid_j = tl.program_id(1)   # block col
    pid_bc = tl.program_id(2)  # batch * channel

    b = pid_bc // H
    h = pid_bc % H

    # compute offsets
    offs_i = pid_i * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_j = pid_j * BLOCK_N + tl.arange(0, BLOCK_N)

    # masks for i and j
    mask_i = offs_i < N
    mask_j = offs_j < N

    # accumulator
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # iterate over k
    for k in range(0, tl.cdiv(N, BLOCK_K)):
        offs_k = k * BLOCK_K + tl.arange(0, BLOCK_K)
        mask_k = offs_k < N

        # pointers for left (B,H,i,k)
        left_offset = (b * stride_left_b
                       + h * stride_left_h
                       + offs_i[:, None] * stride_left_i
                       + offs_k[None, :] * stride_left_k)

        # pointers for right (B,H,k,j)
        right_offset = (b * stride_right_b
                        + h * stride_right_h
                        + offs_k[:, None] * stride_right_k
                        + offs_j[None, :] * stride_right_j)

        # load blocks
        a = tl.load(left_ptr + left_offset,
                    mask=mask_i[:, None] & mask_k[None, :],
                    other=0.0).to(tl.float32)
        b_mat = tl.load(right_ptr + right_offset,
                        mask=mask_k[:, None] & mask_j[None, :],
                        other=0.0).to(tl.float32)

        acc += tl.dot(a, b_mat)
    # store result
    out_offset = (b * stride_out_b
                  + h * stride_out_h
                  + offs_i[:, None] * stride_out_i
                  + offs_j[None, :] * stride_out_j)

    tl.store(out_ptr + out_offset,
             acc,
             mask=mask_i[:, None] & mask_j[None, :])
```

"""
Triton‑accelerated forward pass of the Triangle Multiplicative Update (TriMul).

The operation consists of:
1. Layer‑norm on the input tensor (host‑side).
2. Linear projections to obtain `left` and `right` tensors and three sigmoid gates.
3. Application of the mask (if present) and gates.
4. A batched matrix multiplication:
       out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]
   which is equivalent to a per‑channel GEMM `left @ right.T`.
   This heavy N³ reduction is performed by a custom Triton kernel.
5. Layer‑norm on the hidden dimension, gating with `out_gate`,
   and a final linear projection back to `dim`.

All tensors are kept on the GPU; only the large matmul is moved to Triton.
The kernel processes each (batch, hidden_channel) pair independently using a
2‑D grid over the output matrix blocks.
"""
import torch
import torch.nn.functional as F
import triton
import triton.language as tl

def _layer_norm(x: torch.Tensor, weight: torch.Tensor, bias: torch.Tensor, eps: float = 1e-5) -> torch.Tensor:
    """Simple LayerNorm without moving data off‑device."""
    mean = x.mean(dim=-1, keepdim=True)
    var = x.var(dim=-1, unbiased=False, keepdim=True)
    inv_std = torch.rsqrt(var + eps)
    y = (x - mean) * inv_std
    if weight is not None:
        y = y * weight
    if bias is not None:
        y = y + bias
    return y

@triton.jit
def _tri_mul_matmul_kernel(
    left_ptr, right_ptr, out_ptr,
    B, H, N,
    stride_left_b, stride_left_h, stride_left_i, stride_left_k,
    stride_right_b, stride_right_h, stride_right_k, stride_right_j,
    stride_out_b, stride_out_h, stride_out_i, stride_out_j,
    BLOCK_M: tl.constexpr, BLOCK_N: tl.constexpr, BLOCK_K: tl.constexpr,
):
    # 2‑D grid over output matrix blocks and a 1‑D grid over (batch, channel)
    pid_i = tl.program_id(0)   # block row (i)
    pid_j = tl.program_id(1)   # block col (j)
    pid_bc = tl.program_id(2)  # batch * channel

    b = pid_bc // H
    h = pid_bc % H

    # Offsets for the i and j dimensions
    offs_i = pid_i * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_j = pid_j * BLOCK_N + tl.arange(0, BLOCK_N)

    mask_i = offs_i < N
    mask_j = offs_j < N

    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # Loop over the reduction dimension k
    for k in range(0, tl.cdiv(N, BLOCK_K)):
        offs_k = k * BLOCK_K + tl.arange(0, BLOCK_K)
        mask_k = offs_k < N

        # left: shape (B, H, i, k)
        left_offset = (
            b * stride_left_b
            + h * stride_left_h
            + offs_i[:, None] * stride_left_i
            + offs_k[None, :] * stride_left_k
        )
        a = tl.load(left_ptr + left_offset,
                    mask=mask_i[:, None] & mask_k[None, :],
                    other=0.0).to(tl.float32)

        # right: shape (B, H, k, j)
        right_offset = (
            b * stride_right_b
            + h * stride_right_h
            + offs_k[:, None] * stride_right_k
            + offs_j[None, :] * stride_right_j
        )
        b_mat = tl.load(right_ptr + right_offset,
                        mask=mask_k[:, None] & mask_j[None, :],
                        other=0.0).to(tl.float32)

        acc += tl.dot(a, b_mat)   # (BLOCK_M, BLOCK_N) accumulation

    # Store the result
    out_offset = (
        b * stride_out_b
        + h * stride_out_h
        + offs_i[:, None] * stride_out_i
        + offs_j[None, :] * stride_out_j
    )
    tl.store(out_ptr + out_offset,
             acc,
             mask=mask_i[:, None] & mask_j[None, :])


def custom_kernel(data):
    """
    Forward pass of TriMul using Triton for the heavy N³ reduction.

    Args:
        data: Tuple (input_tensor, mask_tensor, weights_dict, config_dict)
            - input_tensor: torch.Tensor of shape [B, N, N, dim]
            - mask_tensor:  torch.Tensor of shape [B, N, N] (bool or 0/1)
            - weights_dict: mapping from layer name to weight tensors
            - config_dict: contains "dim", "hidden_dim", optional "nomask"

    Returns:
        torch.Tensor of shape [B, N, N, dim] (float32)
    """
    input_tensor, mask_tensor, weights, config = data
    device = input_tensor.device
    B, N, _, dim = input_tensor.shape
    hidden_dim = config["hidden_dim"]
    eps = 1e-5

    # ---- LayerNorm on the input -------------------------------------------------
    norm_weight = weights["norm.weight"]
    norm_bias = weights["norm.bias"]
    x = _layer_norm(input_tensor, norm_weight, norm_bias, eps=eps)  # [B,N,N,dim]

    # ---- Linear projections ------------------------------------------------------
    left_proj_w = weights["left_proj.weight"]
    right_proj_w = weights["right_proj.weight"]
    left = F.linear(x, left_proj_w)   # [B,N,N,hidden_dim]
    right = F.linear(x, right_proj_w)

    # ---- Mask handling ----------------------------------------------------------
    if config.get("nomask", False):
        mask = torch.ones_like(mask_tensor, dtype=x.dtype, device=device)
    else:
        mask = mask_tensor.to(x.dtype)
    mask = mask.unsqueeze(-1)      # [B,N,N,1]
    left = left * mask
    right = right * mask

    # ---- Gates ------------------------------------------------------------------
    left_gate_w = weights["left_gate.weight"]
    right_gate_w = weights["right_gate.weight"]
    out_gate_w = weights["out_gate.weight"]

    left_gate = torch.sigmoid(F.linear(x, left_gate_w))
    right_gate = torch.sigmoid(F.linear(x, right_gate_w))
    out_gate = torch.sigmoid(F.linear(x, out_gate_w))

    left = left * left_gate
    right = right * right_gate

    # ---- Prepare for Triton matmul (convert to half) ---------------------------
    left_h = left.to(torch.float16)
    right_h = right.to(torch.float16)

    # left: (B,N,N,hidden) -> (B,hidden,N,N)   i dimension = 2, k dimension = 3
    left_perm = left_h.permute(0, 3, 1, 2).contiguous()
    # right: (B,N,N,hidden) -> (B,hidden,N,N) but we need (k,j) order -> transpose last two dims
    right_perm = right_h.permute(0, 3, 2, 1).contiguous()

    out_perm = torch.empty((B, hidden_dim, N, N), dtype=torch.float32, device=device)

    # ---- Strides ---------------------------------------------------------------
    stride_left_b, stride_left_h, stride_left_i, stride_left_k = left_perm.stride()
    stride_right_b, stride_right_h, stride_right_k, stride_right_j = right_perm.stride()
    stride_out_b, stride_out_h, stride_out_i, stride_out_j = out_perm.stride()

    # ---- Triton launch ---------------------------------------------------------
    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 64

    grid = (
        triton.cdiv(N, BLOCK_M),
        triton.cdiv(N, BLOCK_N),
        B * hidden_dim,
    )
    _tri_mul_matmul_kernel[grid](
        left_perm,
        right_perm,
        out_perm,
        B,
        hidden_dim,
        N,
        stride_left_b,
        stride_left_h,
        stride_left_i,
        stride_left_k,
        stride_right_b,
        stride_right_h,
        stride_right_k,
        stride_right_j,
        stride_out_b,
        stride_out_h,
        stride_out_i,
        stride_out_j,
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
    )

    # ---- Rearrange back to original layout --------------------------------------
    out = out_perm.permute(0, 2, 3, 1).contiguous()   # [B,N,N,hidden_dim]

    # ---- Output LayerNorm -------------------------------------------------------
    to_out_norm_w = weights["to_out_norm.weight"]
    to_out_norm_b = weights["to_out_norm.bias"]
    out = _layer_norm(out, to_out_norm_w, to_out_norm_b, eps=eps)

    # ---- Output gate ------------------------------------------------------------
    out = out * out_gate

    # ---- Final linear projection ------------------------------------------------
    to_out_w = weights["to_out.weight"]
    out = F.linear(out, to_out_w)   # [B,N,N,dim]

    return out
