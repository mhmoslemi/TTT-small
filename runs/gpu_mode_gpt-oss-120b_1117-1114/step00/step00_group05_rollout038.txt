The problem is to produce a Triton kernel for core compute: out = einsum('... i k d, ... j k d -> ... i j d', left, right), where left and right are masked and gated projections: left = (input @ left_proj_weight.T) * mask * left_gate, etc. The rest (LayerNorms, linear projections, gates, out_gate, to_out_norm, final linear) can be done in PyTorch. However, we have to implement at least part of the operations in a kernel—preferably the einsum, which is the main heavy computation.

The kernel must compute for each batch b, i, j, d (feature dimension hidden_dim) the sum over k (seq_len) of left[b,i,k,d] * right[b,j,k,d]. The shape involved: left: [B,N,N,hidden_dim] but left should be [B,N,N,hidden_dim] after projection over dim? Actually input shape [B,N,N,dim]. After linear projection: left_proj applied on last dimension dim -> hidden_dim, producing shape [B,N,N,hidden_dim]; similarly right.

Thus left_ijkd and right_jk? Wait right = right_proj(x). shape [B,N,N,hidden_dim]. Then we compute out_{b,i,j,d} = sum_{k} left_{b,i,k,d} * right_{b,j,k,d}. So for each i and j you sum over k: it's like for each pair (i,j), dot product across k dimension of vectors left[b,i,:,d] and right[b,j,:,d]; but note that left dimension has indices i,k,d, and right has j,k,d; they share the same k and d.

Thus we need to compute a per-d dot product across k. This is essentially a batched matrix multiplication: for each d, compute L_d (B,N,N) with axes (i,k) and R_d (B,N,N) with axes (j,k). Then out_{b,i,j,d} = sum_k L_{b,i,k,d} * R_{b,j,k,d}. This is like for each d, matrix multiplication of left vector across k dimension: left[b,:, :, d] shape (N,N?) Actually left_{b,i,k,d} (i,k). Right_{b,j,k,d} (j,k). So treat left as B x N x N x D (i,k) and right as B x N x N x D (j,k). For each d we do (left[..., :, :, d]) dot (right[..., :, :, d].transpose(-2,-1)? Wait right is j,k index, but we want sum over k = inner dimension. left index is (i,k). Right index is (j,k). So need to align on k: = sum_k left[i,k] * right[j,k]. That is matrix multiplication of left (i * k) and right (j * k) but we need to treat right as having k as second dimension, but typical matmul is (i,k) @ (k,j). So we need to transpose right to (k,j). But right currently shaped (j,k). So we can permute axes.

Thus we could compute out[...,d] = left[...,d] @ right[...,d].transpose(-2,-1). But left is (i,k) and right is (j,k) shape. If we treat left as (N,N) matrix (i,k) and right as (N,N) matrix (j,k), we need to multiply left (N,N) with right^T (N,N). So out = left @ right^T.

Thus we could also compute with torch.einsum.

Goal: implement this with Triton, focusing on the heavy multiplication.

We have constraints: B up to 2, N up to 1024, hidden_dim can be 128 or 384. So hidden_dim moderate.

We need to make kernel compute per block of i,j.

Standard approach: use blocked matmul: For each d we compute across hidden dims. But we can fuse hidden dim as vectorization across d dimension.

Simplify: Use TRT (triton) to compute out in float16 for speed, then cast to float32 later.

We need to pass left and right pointer memory as contiguous arrays. In PyTorch, left and right will be contiguous with shape [B,N,N,hidden_dim] (N^2 * hidden_dim). We'll compute out shape [B,N,N,hidden_dim].

We need to implement a Triton kernel that loops over k dimension and accumulates dot product.

We also need to incorporate mask and gates but those can be computed in PyTorch before the kernel.

@triton.jit
def trimul_einsum_kernel(
    left_ptr, right_ptr, out_ptr,
    B, N, H,
    stride_left_b, stride_left_i, stride_left_k, stride_left_h,
    stride_right_b, stride_right_j, stride_right_k, stride_right_h,
    stride_out_b, stride_out_i, stride_out_j, stride_out_h,
    BLOCK_I: tl.constexpr, BLOCK_J: tl.constexpr, BLOCK_K: tl.constexpr, BLOCK_H: tl.constexpr
):
    pid_b = tl.program_id(0)
    pid_i = tl.program_id(1)
    pid_j = tl.program_id(2)

    i0 = pid_i * BLOCK_I
    j0 = pid_j * BLOCK_J

    offs_i = i0 + tl.arange(0, BLOCK_I)
    offs_j = j0 + tl.arange(0, BLOCK_J)

    mask_i = offs_i < N
    mask_j = offs_j < N

    # Loop over hidden blocks
    num_h_blocks = tl.cdiv(H, BLOCK_H)
    for hb in range(0, num_h_blocks):
        h0 = hb * BLOCK_H
        offs_h = h0 + tl.arange(0, BLOCK_H)
        mask_h = offs_h < H

        acc = tl.zeros((BLOCK_I, BLOCK_J, BLOCK_H), dtype=tl.float32)

        # Loop over k blocks
        num_k_blocks = tl.cdiv(N, BLOCK_K)
        for kb in range(0, num_k_blocks):
            k0 = kb * BLOCK_K
            offs_k = k0 + tl.arange(0, BLOCK_K)
            mask_k = offs_k < N

            # Load left tile (I,K,H)
            left_ptrs = left_ptr + pid_b * stride_left_b \
                + offs_i[:, None, None] * stride_left_i \
                + offs_k[None, :, None] * stride_left_k \
                + offs_h[None, None, :] * stride_left_h
            left = tl.load(left_ptrs,
                mask=mask_i[:, None, None] & mask_k[None, :, None] & mask_h[None, None, :],
                other=0.0).to(tl.float32)

            # Load right tile transposed (K,J,H)
            right_ptrs = right_ptr + pid_b * stride_right_b \
                + offs_k[:, None, None] * stride_right_k \
                + offs_j[None, :, None] * stride_right_j \
                + offs_h[None, None, :] * stride_right_h
            right = tl.load(right_ptrs,
                mask=mask_k[:, None, None] & mask_j[None, :, None] & mask_h[None, None, :],
                other=0.0).to(tl.float32)

            # accumulate using dot per hidden
            for h in range(0, BLOCK_H):
                # slice matrices
                left_mat = left[:, :, h]   # (I, K)
                right_mat = right[:, :, h] # (K, J)
                acc[:, :, h] += tl.dot(left_mat, right_mat)

        # store result for this hidden block
        out_ptrs = out_ptr + pid_b * stride_out_b \
            + offs_i[:, None, None] * stride_out_i \
            + offs_j[None, :, None] * stride_out_j \
            + offs_h[None, None, :] * stride_out_h
        mask_store = mask_i[:, None, None] & mask_j[None, :, None] & mask_h[None, None, :]
        tl.store(out_ptrs, acc, mask=mask_store)

    hidden_dim = config["hidden_dim"]
    device = input_tensor.device

    norm_bias = weights["norm.bias"]
    x = torch.nn.functional.layer_norm(input_tensor, (dim,), weight=norm_weight, bias=norm_bias)

    # Projections
    left = torch.nn.functional.linear(x, weights["left_proj.weight"])
    right = torch.nn.functional.linear(x, weights["right_proj.weight"])

    if not config.get("nomask", False):

        left = left * mask_unsq
        right = right * mask_unsq
    else:
        # still broadcast mask of ones for consistency (optional)
        # no need
        pass

    # Gating
    left_gate = torch.nn.functional.linear(x, weights["left_gate.weight"]).sigmoid()
    right_gate = torch.nn.functional.linear(x, weights["right_gate.weight"]).sigmoid()
    out_gate = torch.nn.functional.linear(x, weights["out_gate.weight"]).sigmoid()

    left = left * left_gate
    right = right * right_gate

    # Cast to bfloat16 for triton kernel (or float16)
    left_half = left.to(torch.bfloat16)
    right_half = right.to(torch.bfloat16)

    # Allocate output tensor (float32)
    bs, N, _, _ = left_half.shape
    out = torch.empty((bs, N, N, hidden_dim), dtype=torch.float32, device=device)

    # Strides
    stride_left_b, stride_left_i, stride_left_k, stride_left_h = left_half.stride()
    stride_right_b, stride_right_j, stride_right_k, stride_right_h = right_half.stride()
    stride_out_b, stride_out_i, stride_out_j, stride_out_h = out.stride()

    # Block sizes
    BLOCK_I = 32
    BLOCK_J = 32
    BLOCK_K = 32
    BLOCK_H = 32

    grid = (bs, triton.cdiv(N, BLOCK_I), triton.cdiv(N, BLOCK_J))
    trimul_einsum_kernel[grid](
        left_half,
        right_half,
        out,
        bs,
        N,
        hidden_dim,
        stride_left_b,
        stride_left_i,
        stride_left_k,
        stride_left_h,
        stride_right_b,
        stride_right_j,
        stride_right_k,
        stride_right_h,
        stride_out_b,
        stride_out_i,
        stride_out_j,
        stride_out_h,
        BLOCK_I=BLOCK_I,
        BLOCK_J=BLOCK_J,
        BLOCK_K=BLOCK_K,
        BLOCK_H=BLOCK_H,
    )

    # at this point out is float32
    # Apply output LayerNorm
    to_out_norm_weight = weights["to_out_norm.weight"]
    to_out_norm_bias = weights["to_out_norm.bias"]

    # Apply out_gate
    out = out * out_gate

    # Final linear projection to original dim
    to_out_weight = weights["to_out.weight"]
    out = torch.nn.functional.linear(out, to_out_weight)

    return out

"""
TriMul forward (outgoing version) with a fused Triton kernel.

The input tensor x ∈ ℝ^{B×N×N×C} is first layer‑normalized, projected to a hidden
dimension H and gated.  The heavy O(N³·H) operation

    out_{b,i,j,:} = Σ_{k=0}^{N‑1} left_{b,i,k,:} * right_{b,j,k,:}

is implemented in a custom Triton kernel.  The kernel iterates over blocks of the
sequence dimensions (i, j) and over blocks of the hidden dimension, accumulating
the dot‑product across the k‑dimension with `tl.dot`.  The result is returned as
float32, after which a second layer‑norm, an output gate, and a final linear
projection produce the tensor of shape [B, N, N, C].

Only the core O(N³·H) part is offloaded to Triton; the surrounding linear layers,
gates, and normalizations are performed with PyTorch for simplicity.
"""

import torch
import triton
import triton.language as tl


@triton.jit
def trimul_einsum_kernel(
    left_ptr,           # *const half*   [B,N,N,H]
    right_ptr,          # *const half*   [B,N,N,H]
    out_ptr,            # *float*        [B,N,N,H]
    B, N, H,
    stride_left_b, stride_left_i, stride_left_k, stride_left_h,
    stride_right_b, stride_right_j, stride_right_k, stride_right_h,
    stride_out_b, stride_out_i, stride_out_j, stride_out_h,
    BLOCK_I: tl.constexpr,
    BLOCK_J: tl.constexpr,
    BLOCK_K: tl.constexpr,
    BLOCK_H: tl.constexpr,
):
    pid_b = tl.program_id(0)   # batch
    pid_i = tl.program_id(1)   # i‑tile
    pid_j = tl.program_id(2)   # j‑tile

    i0 = pid_i * BLOCK_I
    j0 = pid_j * BLOCK_J

    offs_i = i0 + tl.arange(0, BLOCK_I)
    offs_j = j0 + tl.arange(0, BLOCK_J)

    mask_i = offs_i < N
    mask_j = offs_j < N

    # number of hidden blocks
    num_h_blocks = tl.cdiv(H, BLOCK_H)
    for hb in range(0, num_h_blocks):
        h0 = hb * BLOCK_H
        offs_h = h0 + tl.arange(0, BLOCK_H)
        mask_h = offs_h < H

        # accumulator for this hidden block
        acc = tl.zeros((BLOCK_I, BLOCK_J, BLOCK_H), dtype=tl.float32)

        # loop over k dimension
        num_k_blocks = tl.cdiv(N, BLOCK_K)
        for kb in range(0, num_k_blocks):
            k0 = kb * BLOCK_K
            offs_k = k0 + tl.arange(0, BLOCK_K)
            mask_k = offs_k < N

            # ---- Load left[i, k, h] ------------------------------------------------
            left_ptrs = (
                left_ptr
                + pid_b * stride_left_b
                + offs_i[:, None, None] * stride_left_i
                + offs_k[None, :, None] * stride_left_k
                + offs_h[None, None, :] * stride_left_h
            )
            left = tl.load(
                left_ptrs,
                mask=mask_i[:, None, None] & mask_k[None, :, None] & mask_h[None, None, :],
                other=0.0,
            ).to(tl.float32)  # (I, K, H)

            # ---- Load right transposed: right_T[k, j, h] (= right[j, k, h]) -------------
            right_ptrs = (
                right_ptr
                + pid_b * stride_right_b
                + offs_k[:, None, None] * stride_right_k
                + offs_j[None, :, None] * stride_right_j
                + offs_h[None, None, :] * stride_right_h
            )
            right = tl.load(
                right_ptrs,
                mask=mask_k[:, None, None] & mask_j[None, :, None] & mask_h[None, None, :],
                other=0.0,
            ).to(tl.float32)  # (K, J, H)

            # ---- Accumulate dot products per hidden slice -----------------------------
            for h in range(0, BLOCK_H):
                # left[...,h] : (I, K), right[...,h] : (K, J)
                acc[:, :, h] += tl.dot(left[:, :, h], right[:, :, h])

        # ---- Write the block result -------------------------------------------------
        out_ptrs = (
            out_ptr
            + pid_b * stride_out_b
            + offs_i[:, None, None] * stride_out_i
            + offs_j[None, :, None] * stride_out_j
            + offs_h[None, None, :] * stride_out_h
        )
        mask_store = mask_i[:, None, None] & mask_j[None, :, None] & mask_h[None, None, :]
        tl.store(out_ptrs, acc, mask=mask_store)


def custom_kernel(data):
    """
    Forward pass of the outgoing TriMul operator.
    Args:
        data: Tuple (input_tensor, mask, weights, config)
            - input_tensor: torch.Tensor [B, N, N, C] (float32)
            - mask: torch.Tensor [B, N, N] (bool or 0/1)
            - weights: dict of torch.Tensors containing the model weights
            - config: dict with keys "dim", "hidden_dim", "nomask" (bool)
    Returns:
        torch.Tensor of shape [B, N, N, C] (float32)
    """
    import torch
    import triton

    input_tensor, mask, weights, config = data
    dim = config["dim"]
    hidden_dim = config["hidden_dim"]
    device = input_tensor.device
    dtype = input_tensor.dtype

    # -------------------------------------------------------------------------
    # 1. Input layer‑norm
    # -------------------------------------------------------------------------
    norm_weight = weights["norm.weight"]
    norm_bias = weights["norm.bias"]
    x = torch.nn.functional.layer_norm(
        input_tensor,
        (dim,),
        weight=norm_weight,
        bias=norm_bias,
        eps=1e-5,
    )  # [B,N,N,dim]

    # -------------------------------------------------------------------------
    # 2. Linear projections (float32)
    # -------------------------------------------------------------------------
    left = torch.nn.functional.linear(x, weights["left_proj.weight"])
    right = torch.nn.functional.linear(x, weights["right_proj.weight"])

    # -------------------------------------------------------------------------
    # 3. Optional mask (broadcasted on hidden dimension)
    # -------------------------------------------------------------------------
    if not config.get("nomask", False):
        mask_ = mask.to(dtype).unsqueeze(-1)  # [B,N,N,1]
        left = left * mask_
        right = right * mask_

    # -------------------------------------------------------------------------
    # 4. Gating (sigmoid)
    # -------------------------------------------------------------------------
    left_gate = torch.nn.functional.linear(x, weights["left_gate.weight"]).sigmoid()
    right_gate = torch.nn.functional.linear(x, weights["right_gate.weight"]).sigmoid()
    out_gate = torch.nn.functional.linear(x, weights["out_gate.weight"]).sigmoid()

    left = left * left_gate
    right = right * right_gate

    # -------------------------------------------------------------------------
    # 5. Cast to bfloat16 and compute the core O(N³·H) einsum with Triton
    # -------------------------------------------------------------------------
    left_bf16 = left.to(torch.bfloat16)
    right_bf16 = right.to(torch.bfloat16)

    B, N, _, _ = left_bf16.shape
    out = torch.empty((B, N, N, hidden_dim), dtype=torch.float32, device=device)

    # Strides (in elements)
    s_l_b, s_l_i, s_l_k, s_l_h = left_bf16.stride()
    s_r_b, s_r_j, s_r_k, s_r_h = right_bf16.stride()
    s_o_b, s_o_i, s_o_j, s_o_h = out.stride()

    # Blocking parameters (tuned for typical N up to 1024, hidden_dim ≤ 384)
    BLOCK_I = 32
    BLOCK_J = 32
    BLOCK_K = 32
    BLOCK_H = 32

    grid = (
        B,
        triton.cdiv(N, BLOCK_I),
        triton.cdiv(N, BLOCK_J),
    )
    trimul_einsum_kernel[grid](
        left_bf16,
        right_bf16,
        out,
        B,
        N,
        hidden_dim,
        s_l_b,
        s_l_i,
        s_l_k,
        s_l_h,
        s_r_b,
        s_r_j,
        s_r_k,
        s_r_h,
        s_o_b,
        s_o_i,
        s_o_j,
        s_o_h,
        BLOCK_I=BLOCK_I,
        BLOCK_J=BLOCK_J,
        BLOCK_K=BLOCK_K,
        BLOCK_H=BLOCK_H,
    )

    # -------------------------------------------------------------------------
    # 6. Output layer‑norm, output gating, final linear projection
    # -------------------------------------------------------------------------
    out = torch.nn.functional.layer_norm(
        out,
        (hidden_dim,),
        weight=weights["to_out_norm.weight"],
        bias=weights["to_out_norm.bias"],
        eps=1e-5,
    )
    out = out * out_gate
    out = torch.nn.functional.linear(out, weights["to_out.weight"])

    return out
