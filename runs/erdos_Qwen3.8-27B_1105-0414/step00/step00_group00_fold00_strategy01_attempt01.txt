1. Approach and rationale

### 1.1 Central idea

The objective is a nonconvex finite-support cross-correlation minimization. The authoritative score is determined entirely by a discrete array `h` of length `n`, with `dx = 2/n`, and only by values available at the supplied grid:

`C5(h) = max_lag np.correlate(h, 1-h, mode="full")[lag] * dx`, using both positive and negative lags because the `full` mode contains them.

A completely different approach from earlier general smoothing/SLSQP ideas is to optimize on an exact integer level-lattice and allow only states with exact feasibility. Instead of repeatedly solving smooth surrogate continuous relaxations, the primary search operates directly on dyadic integer vectors `q` with entries in `{0,1,...,D}` and exactly fixed sum, so that

`h_i = q_i / D`, `0 <= h_i <= 1`, `sum_i h_i = (1/D) sum_i q_i = n/2`.

For each fixed state, the score can be evaluated exactly in integer arithmetic by

`M(q,D) = max_lag np.correlate(q, D-q, mode="full")[lag]`,

`C(q,D) = dx * M(q,D) / D^2`.

This is not just a relaxation: for dyadic states it is exactly the same correlation objective up to the harmless exact scale `D^2`. The returned vector is always exactly in shape constraints at creation time, and its final reported value is confirmed through the actual task evaluator.

The parent is `n=45` and report is already close to `0.38085`. A direct improvement therefore requires fine local adjustment and the ability to escape local plateaus of a hard max. This plan gives both in a way not covered by earlier smooth-lag suggestions:

- Exact two-index lattice migration along malformed but worthwhile combinations of heights, rather than only local one-unit coordinate attempts or smooth projections.
- Stochastic restarts on top of exact neighbor moves, maintaining exact sum without a separate clipping/rescaling step.
- Multi-level dyadic zooming: best coarse states are refined to `D=2,4,8,16,...` after already having discovered candidate optimal structure. Each higher level gives extra continuous-like degree of freedom without changing the requested exact solution in an uncontrolled way.
- Different lengths are optionally compared (and the parent-derived constructions are always retained as seeds), because exact reported objective depends on returned resolution.
- Acceptance is always under the exact official objective; secondary routines are only used for stronger transitions. Therefore, this cannot return an invalid lower number.
