1. Approach and rationale

1.1 Central idea

The task is a finite-dimensional nonconvex minimax problem over a simple
polytope: the vector h lives in the box [0,1]^n and satisfies one scalar
equality sum_i h_i = n/2. The exact objective is the maximum of 2n−1 scalar
terms

    F(h) = dx * max_p (correlate(h, 1-h)[p]),  dx = 2/n.

Because the feasible set is so simple and n is small (in the order 100),
evaluations of F are cheap. A globally reliable exact proof is not expected.
The proposed method is a deterministic, exact-replay descent method built
around active correlation constraints. It does not rely on a convex
relaxation optimism, a stochastic Metaheuristic alone, or a direct
nonconvex nonlinear epigraph solver. Instead:

* active or near-active correlation terms are converted into conservative
  feasible descent directions with zero sum, which preserves the integral
  constraint;
* for each candidate direction, the exact original objective is minimized
  along the feasible one-dimensional segment generated by that direction,
  including both the positive and negative side of the direction;
* every accepted move is checked only by the actual requested evaluator, and
  no approximate objective is ever returned as feasible;
* multiple promising candidate vectors are maintained (parent, symmetrized
  parent, transferred coarsened/rescaled parents, few fallback material
  constructions) and are repeatedly polished and recombined;
* a global parent fallback is retained at all times.

This addresses the bottleneck of nonconvexity/nonsmoothness differently from
a direct epigraph NLP or full simulated annealing: the nonconvex subproblem
is never made convex, but nonconvex information is used only to suggest
feasible one-dimensional underwater segments, while the final scalar value
used for every move is computed by the true full-modes correlation.

1.2 Why this could improve the supplied parent

The current solution is already near the known material boundary, so the
interesting improvement is likely in a low-dimensional local basin. The set
size and sample count are small enough that many exact one-dimensional
section evaluations can be spent. A batch of active terms often shares
common variables; subtracting the mean of their summed gradient can produce
a zero-sum direction that makes small shifts in h which reduce
the rough maximum. If graded exact line minimization finds a section value
lower than the current full vector, the true solution has improved. Exact
paragraph recomputation of the global score is the criterion. Parent exactness
is required; no branch or solver “success” status is trusted.

1.3 Limitations and factual status

* This is a local/global-heuristic method. No optimality is established from
  a pass, so accepted local stagnation may need random mixtures.
* Elements labeled “recommended” or “acceptable” are heuristic tunings. Elements
  labeled “exact” or “derive” are facts or formulas to be followed exactly.
* The main simple, cheaper candidates may be coarse versions of the parent,
  but the highest variability of items involving h_i * h_j should be retained.
* The final comparator always treats the actual evaluator.

* No closures or duplicated functions except top-level helpers,

* Return an actual algorithmic combination. If initial construction values

1. Approach and rationale

1.1 Central problem shape

The returned vector h represents samples over [0,2] with

    dx = 2 / n,
    sum_i h_i = n / 2,
    0 <= h_i <= 1.

The exact score is

    C(h) = dx * max_p raw_p(h),
    raw(h) = np.correlate(h, 1-h, mode="full").

The feasible set is a simple polytope: coordinatewise box cuts combined with a single linear equality. The objective is a maximum of full-lag bilinear terms over 2n-1 lags. It is nonconvex because the terms contain products of h coordinates, and nonsmooth because of the maximum. The implementation should therefore never certify optimality or use relaxed feasibility; the only accepted objective value is obtained by recomputing the exact full-mode correlation after construction.

1.2 Proposed method

The proposed method is a deterministic/global-mixed exact-replay line-search method built from active correlation constraints. The key substantive differences from earlier proposals are:

* There is no direct nonconvepigraph solver, no cvxpy epigraph formulation, and no no stochastic-annealing-main-loop.
