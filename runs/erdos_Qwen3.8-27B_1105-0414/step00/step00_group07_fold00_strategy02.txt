1. Approach and rationale

1.1 Central idea

The parent construction is a discrete feasible vector h of length n satisfying two very simple restraints:

    0 <= h[i] <= 1,        sum_i h[i] = n/2,        dx = 2/n.

The primary difficulty is that the objective,

    C(h) = dx * max_p np.correlate(h, 1-h, mode="full")[p],

is neither convex nor smooth. Prior proposals in the prompt family focus largely on direct discrete-coordinate rewrites, active correlations, pairwise moves, annealing, and epigraph-type local solvers. These are often trapped at nearby local minima because they require repeated long-line repair of both box and integral constraints.

The new plan searches in a different feasible manifold. It uses the scalar logit latent variable u[i] and a scalar root-induced shift c. Every candidate is of the exact form

    h_i(c,u) = logistic(u_i + c)         for finite u, h in (0,1),

or slight edge-preserving generalizations using a learned latent transition scale. The scalar c is not fixed by hand. It is chosen so that exactly, up to high numerical tolerance,

    sum_i logistic(u_i + c) = n/2.

Therefore the integral constraint and the box constraints are enforced jointly for every candidate. There is no separate clip-and-rescale jumper. Feasible directions can be computed analytically with respect to latent variables without infecting the sum constraint, while every candidate is still scored on the exact的天空 correlation metric, not a surrogate.

The search is performed first in nested Fourier/polynomial latent bases, then in the full latent dimension using the identity basis. This creates a global-to-local process: smooth low-dimensional families avoid the huge discrete nonlinearity, initialized from the parent in a mathematically controlled way; increasing dimensions retain useful features and allow more autonomous local movement without stack-scale infeasibility. Parents are processed through logit transform and compressed basis fits, then reconstructed with exact hidden scalar root. In other words, the plan does not copy the parent or replay only exact h-coordinate values; it treats the parent as a starting latent signal in a logit-space direct optimization.

1.2 Why it can improve the current record

Building directions in the logit manifold gives several advantages against classical h-space active line proposals:

* Constraint preservation is structural rather than reactive. Active set proposals on h may alter nearby integrals or necessary sample constraints; latent update changes the rational pattern while first-order weight around constraint averages keep sum effects bounded.
* The logit manifold can span subtle fractional amounts and tiny border transitions, but latent coordinate directions represent possible moves. In the h-metric, any realistic local adjustment has small effect after shrink; in latent terms, coordinates may have same moving shape even despite separation 0/1 comparator target.
* Smooth low-dimensional optimization can explore qualitatively different shape-level structures instead of muting existing bit transitions. Base expansion lets less arbitrary transition-sequence constructions become polychromatic gradient spice from composition.
* Exact quadratic max retained means assignments export metrics from np correlate. No optimized criterion can issue a smaller score than exact validator. Recordkeeping of on valid candidates prevents rightward equal decisions stemming from prior bad nonsmooth assignment approximations.
