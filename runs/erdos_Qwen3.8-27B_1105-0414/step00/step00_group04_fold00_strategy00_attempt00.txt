The problem is a nonconvex constrained minimax problem: for a fixed `n`, minimize `max_k corr_k(h)` subject to `0 <= h_i <= 1` and `sum_i h_i = n/2`. Global optimality is not claimed. The plan instead performs **multi-start annealed nonsmooth minimax optimization**, keeping every candidate that is better using the **exact evaluator**.

The method:
- Uses the exact correlation objective and exact feasibility repair.
- Replaces the nonsmooth max by a warm-started log-sum-exp surrogate and is annealed to small temperature.
Re-weights by the dominating lags.
Uses constrained optimizer SLSQP with box and equality constraints.
- Continues robust iterate polishing.
Adds simpler variance: random smooth/continuous and random binary feasible starts.
- Returns the globally best value (as exact `evaluator` score where smaller is better) and permitted smaller dimension for same score over within tolerance.
Provenance now includes local fallback.
