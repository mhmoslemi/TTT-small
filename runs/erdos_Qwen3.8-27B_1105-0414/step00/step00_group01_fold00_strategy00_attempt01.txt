1. Approach and rationale

Goal: return a valid vector `h` with the smallest exact value of

`C5(h) = max_lag np.correlate(h, 1.0 - h, mode="full")[lag] * (2 / len(h))`.

The supplied evaluator is finite-support, linear correlation with the fundamental interval boundaries retained. We will not replace it by a circular autocorrelation or by a minimum-average autocorrelation inequality. Every candidate is judged by the exact evaluator, and every feasibility repair is performed before acceptance.

The objective is a maximum over `2N-1` different bilinear lag expressions. It is piecewise quadratic and generally nonconvex. A direct convex lag-epigraph formulation is not available because each stock has products `h_i h_j`. Therefore this plan makes no global-optimal claim. It seeks a tightened parent bound by a combination of

1. exact correction of the supplied parent and several deterministic siblings derived by thresholding, translation, smoothing, and resolution transfer;
2. monotone descent on smooth global approximations to the lag maximum, projected exactly onto `0 <= h <= 1` and `sum(h)=N/2`;
3. a plateau-oriented convex linearized linear program over the currently dominant lags to move away from one-sided smoothing optima;
4. soft-target minimization, which allows slightly reduced tails while the maximum target is still being pushed down;
5. a valid fallback strategy retaining the best exact feasible vector found so far.

The main bottleneck of a naive gradient method is the nonsmooth maximum: once one lag decreases, another one becomes active with almost the same value. The smoothing schedule first moves all near-dominant lags jointly, and the LP correction forces a linearized common-descent direction for their gradients. Target softplus avoids spending effort on lags already far below a proposed level. These choices are heuristics that augment exact evaluation; acceptance is driven only by the true evaluator.

The current bound is extremely tight. Therefore the dominant use of `initial_h_values` is not merely as an arbitrary seed, but as the anchor of a local, exact-exact, directed perturbation procedure. The return should be the best exact feasible vector found, with priority given to the parent or parent-derived candidates initialized at the same resolution. Candidate resolutions near the parent are preferred because the problem asks for smaller sequences than about `2k`, while very large `N` would consume much of the budget with little structural advantage. If a different resolution predicate is incompatible or time-constrained, the parent resolution is recovered as fallback.

`0 <= h[i] <= 1` for every `i`,
`sum_i h[i] = N/2`.

`C5_score(h) = max_{lag} corr(h, 1 - h, lag) * dx`,

For `d >= 0`,
