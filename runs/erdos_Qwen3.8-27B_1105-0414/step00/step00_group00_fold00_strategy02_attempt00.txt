## 1. Approach and rationale

### 1.1 Central idea
The authoritative objective is the exact finite-support discrete objective

    C5(h) = max_{m=0,...,2n-2} dx * np.correlate(h, 1-h, mode='full')[m]

where dx = 2 / n, 0 <= h_i <= 1, and sum_i h_i = n / 2. This is a nonconvex max of bilinear terms. The previous direction of using only smoothed objective gradients on a continuous relaxation is likely to be trapped by boundary constraints and by the flat, discrete tie structure of the max objective. Therefore the proposed solution is centered on exact integer-grid search and exchange, rather than gradient descent as the primary mechanism.

Map every accepted and every final-evaluated search point to an exact integer grid state:

    h_i = q_i / Q,   q_i integer, 0 <= q_i <= Q,   sum_i q_i = N = n Q / 2.

The denominator Q is a power of two, so h_i and 1 - h_i are exactly representable dyadic floats. The sum constraint is enforced by an integer sum-of-integers constraint, not through sequential clipping and rescaling. The objective on q is then exactly:

    R_m(q) = sum over valid finite-support pairs, scale after multiply by dx:
             q_i_left * (Q - q_i_right)

    C5(q) = dx * max_m R_m(q) / Q^2.

Every move and every escape move is scored by the true discrete objective. Smooth maxima or gradients are only auxiliary; they guide state transfer directions and can be used to generate candidate integer states but never decide acceptance. The final returned vector is exactly from the integer-grid representation, except when yielding the supplied parent construction if that already satisfies tolerance better and is retained as fallback.

### 1.2 Why this addresses the bottleneck
The main nonconvex difficulty is that changing h_i affects many terms h_i(1-h_j) and h_j(1-h_i) at different finite-support lags. If one treats the objective as smooth max after smoothing, boundary terms and multiple tied active lags make gradient steps unstable, especially near binary states. The exact integer formulation exposes the same boundary structure and permits exact incremental recomputation of the whole 2n-1 lag vector after each exchange.

The primary search consists of:

1. The supplied parent is validated, scaled/rounded to a feasible Q grid, and scored exactly.
2. A deterministic exact gradient-guided pair-transfer greedy move engine performs large and small integer exchanges if they strictly improve the true max.
3. A Metropolis exact-score simulated annealing pass over valid integer states escapes local optima using exact objective evaluations.
4. Around each incumbent integer state, a short exact local greedy pass immediately re-optimizes the exact objective itself when annealing proposes a better state.
5. A short secondary optional continuous log-sum-exp smooth pass creates additional starting points, but every accepted continuous starting point is downward-rounded to an integer grid and locally greedy polished before it can be returned.
6. The parent original is always preserved as the fallback if it is valid; no returned candidate replaces it unless its exact or official re-score is provably no worse under tolerance.

### 1.3 Honest limitations
This is not a global optimizer and makes no claim of optimality or guaranteed improvement over the parent. The result is always bounded by exact re-evaluation of the returned construction, and it always has a valid parent fallback. Discretization on a finite grid can miss some continuous improvements, but the grid is very fine and the transition steps provide smooth pathways. The discrete objective and grid score use exact integers; all final bounds are re-checked in the official floating evaluator. The algebraic update formulas must be verified against numpy's actual correlate assignment before being trusted; if verification fails in implementation, fall back to recomputing full correlations for candidate moves and follow local dependencies.

This is a materially different approach from the earlier smoothing-heavy proposal: the central trusted decision is exact integer-transfer simulated annealing using exact finite-boundary correlation updates, not a smooth min-max continuous relaxation; gradients are secondary; continuous solvers only feed integer states; and the final object is exactly feasible on a dyadic integer grid.

## 2. Mathematical specification

### 2.1 Variables and exact constraints
For returned length n:

    dx = 2.0 / n.
    Target integer units N = n * Q // 2, with Q = 2^b and b fixed default 18 (usable alternative 16 or 20; see Section 4). Because Q is even, N is integer for all n.

    corr_m = sum_{i=max(0,-k)}^{min(n, n-1-k+1)-1} x_{i+k} * y_i.

For our problem x = q, y = Q - q, so exact scaled raw correlation:

    R_m(q) = sum monomial valid pairs: q_{i+k} (Qu - q_i).

Then:

    C5_float(q) = dx * max_m R_m(q) / Q^2.

The exact dimension must be 2n-1; all lag endpoints included. The convention above must be verified against local initial sanity tests before using algebraic update formulas. If mismatch, use brute force correlate to match; do not mix.

For update formulas below offset = n-1 and lag from first coordinate t and partner s follows the same convention: term X_p Y_j gives output offset + (p - j) where p is first (h) coordinate, j is second (complement). This matches the earlier algebraic formula and must pass sanity.
