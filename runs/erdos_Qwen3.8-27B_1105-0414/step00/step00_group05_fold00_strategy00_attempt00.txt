1. Approach and rationale

1.1. Central idea

The discrete Erdős overlap problem is a finite, bounded, multilinear minimax problem. The evaluator documents the target quantity exactly as a finite-support cross-correlation: for a length-n vector h, dx = 2/n and
    C(h) = max_k dx * Cor_k(h, 1-h),
where k ranges over all values present in
    np.correlate(h, 1-h, mode="full").
The supplied parent h has n_points = 42, values in [0,1], and sum h = 21. The current reported C5-level is about 0.38085; the goal is an achieved constructed vector with C(h) ≤ 0.3808 while retaining exact feasibility. This is a small local gain, so a globally certified method is not required; the bottleneck is an operational exact construction and a reliable search mechanism.

The program will not replace the objective by a Fourier, circular correlation, autocorrelation, or 1-min-adjacent-covariance heuristic unless the full finite-support boundary terms are explicitly included. Every accepted candidate is returned as a dyadic vector with exact integer numerator sum, then scored with the exact evaluator representation before being stored. The main search is an exact scored, non-differentiable local-minimax search over a dense dyadic feasible grid. It combines:
- dense dyadic integer encoding, so that 0 ≤ h_i ≤ 1, sum(h_i) = n/2, and the final floating array is exact to binary floating-point arithmetic;
- parent initialization and stochastic rounding;
- projected stochastic/weight-smoothed gradient descent, where the descent direction comes from a continuously scored log-sum-exp surrogate, but the actual acceptance is always the true evaluator objective;
- local pair-transfer line searches in the exact integer representation, which preserve the sum constraint exactly by construction;
- random global jump and restart stages;
- optional mixed-integer linear subproblem attempts for binary candidates if CVXPY/CBC is available.

The method is local in the nonconvex sense. It does not claim that the returned value is the global optimum of the original continuous problem or of the discretized problem. It seeks a valid vector with a score below the supplied target by using a high-resolution dyadic feasibility domain and aggressive local exact scoring. If search fails, a validated valid construction is always kept as fallback.

1.2. Why this addresses the bottleneck

The current parent is already in the deep basin of the given construction; existing construct is already close to the value. Improving by 5×10^-5 in C requires a relative perturbation order 10^-4. A purely coarse integer search cannot find such small changes, while a purely continuous vector leaves the exact sum constraint. A dyadic grid with 12–16 fractional denominator bits both:
- allows perturbations at least one or more orders of magnitude smaller than the required improvement;
- preserves an integer numerator sum target exactly, avoiding the usual projection clipping trap and loss of feasibility.

A gradient surrogate can move in the full vector space using more global information; but the bounded max and boundary offsets can fail with nonconvex local maxima. Pair transfers solve the small correlation max after randomly directed trial moves and specifically use the bilinear finite-support structure. Stochastic rounding and jumping prevent deterministic trapping. The parent candidate is always preserved. Therefore the pipeline returns the best exact objective discovered among many tested feasible arrangements.

1.3. Justified facts versus heuristics

Justified:
- dyadic vectors h = k/Q with integers satisfying sum k = nQ/2 satisfy n> bounds and sum in a strict floating representation because Q = 2^B and target and individual entries are representable dyadic binary fractions, and intermediate sums remain within safe floating ranges for planned dimensions;
- preserving transfer between two coordinates maintains sum change zero mathematically and integer bounds? (through limits);
- evaluating objective with np.correlate(h, 1-h, mode="full") * dx is aligned to the task evaluator;
- using zero substitutions or autocorrelation identities without need to bias offset linear boundary terms can give a different target problem by enforced technique. Actual formula is applied as given.

Hypotheses/heuristics:
