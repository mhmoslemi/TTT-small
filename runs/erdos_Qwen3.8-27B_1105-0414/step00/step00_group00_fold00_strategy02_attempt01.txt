1. Approach and rationale

1.1 Central idea
The authoritative bound is
\[
C_5(h)=\max_t\left(\frac{2}{m}\,\operatorname{correlate}(h,\,1-h,\text{mode}=\text{"full"})_t\right),
\]
where m = len(h_values). In a fixed-size finite-support evaluation, the denominator 2/m is constant while the search proceeds, so the only meaningful competition is the maximum overlap count. The proposed construction is a disciplined finite combinatorial search over the exact supplied evaluated metric, using a parent construction only when it is supplied as a valid seed.

The method has two main ingredients:

- Cardinality-preserved local and basin-hopping search. Each candidate vector remains a {0,1} sequence with a fixed target number of ones. Let the number of ones be m/2 whenever the parent or sample usage points toward that density. That prevents degenerate all-zero/all-one samples from looking trivially good against the stated boundary-normalized construction.
- An exact-score guided greedy repeated swap engine. At every move we preserve the cardinality. Multi-swap perturbations periodically escape a local optimum and feed new starting points into an exhaustive local descent.

The task is dominated by the sharp maximum over roughly 2m finite-support correlations, so solving a relaxation is not useful unless the exact max-overlap is recomputed after rounding. The search method is therefore separation-based: every evaluated vector is tested directly on the evaluator, and the maximum exact objective is stored before returning. Nothing claims global optimality: it is only accepted by exact evaluator after move acceptance.

1.2 What problem the approach attacks

- No global guarantee is possible in a time-capped nonconvex max-correlation Boolean program. The final score is exact for the requested finite lattice structure only, and it remains an upper bound of C5 only if it adheres to the expected boundary structure and exact integral constraints.
