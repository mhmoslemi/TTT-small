1. Central idea

The discrete objective

C(h) = max_j [ np.correlate(h, 1-h, mode="full")[j] * dx ]

is nonconvex because most correlation terms contain products of two components of h. This plan does not attempt to solve the nonconvex global problem directly in R^n. Its primary computational engine is instead a globally valid one-dimensional minimization over carefully chosen feasible line segments.

For a current feasible vector h and a direction v whose sum is zero, define the feasible line

    H(α) = h + α v,   α ∈ [L, U]

where [L,U] is the maximal interval over which all components stay in [0,1]. Along such a line, every correlation term is a quadratic function of α. More specifically, because the term is of the form a_i(α)(1-b_i(α)) with a_i and b_i affine in α, the coefficient of α^2 is nonpositive: the term is a concave quadratic. Therefore, for any proposed upper bound τ, the set { α : correlation_term(α)*dx ≤ τ } is a union of at most two intervals. The feasible set along the line for C(H(α))*dx ≤ τ is the intersection of many such unions. Membership in that feasible set can be checked exactly by interval subtraction. This permits a bisection search for the best objective value on the whole line segment, not merely a local line search.

The algorithm repeatedly performs the following loop:

1. Maintain a feasible incumbent h and its exact evaluated score.
2. Construct many directions v: active-rate-gradient directions, random tangent directions, low-frequency directions, and short-swap directions.
3. For each direction, solve the best exact one-dimensional improvement globally, or as tightly as desired numerically, using the quadratic/sublevel structure above.
4. Reconstruct and re-feasibilize the line's best point, re-evaluate it with the official metric, and accept it only if it improves the incumbent under exact evaluation.
5. When the current incumbent appears stuck, generate diversified feasible starting points from the incumbent by interpolation, perturbations, and thresholding.

This approach is robust because the primary optimization is performed on exactly the original finite products, with no smooth surrogate, no circular correlation substitution, and no relaxation used for acceptance. Its limitation is explicit: solving a line exactly does not make the full finite-dimensional problem globally solvable by coordinate-line moves alone. Extensive random directions and stochastic diversification are therefore essential to escape poor regions.

The strategy is also well matched to the known structure of the problem. The zero-lag term is ∑ h_i(1-h_i)*dx. To make the maximum small, the vector must be strongly near binary, since a binary or nearly binary vector makes the zero-lag contribution very small. The algorithm purposely preserves the supplied parent and refines it through line moves before accepting large resolution changes.

2. Mathematical specification

2.1 Discrete vector notation and the authoritative score

Let n be an integer and

    dx = 2 / n.

The vector is h = (h_0,...,h_{n-1}) with h_i ∈ [0,1] and

    sum_i h_i = n/2.

For any candidate vector y, define

    scorer(y) = float(max( np.correlate(y, 1 - y, mode="full") * (2/len(y)) )).

All final accepted values use scorer directly. No alternative score is used for acceptance.

The finite correlation in the defined signed-lag order is represented by T_j, j=0,...,2n-2. The midpoint index is

    c = n - 1.

For d=0,...,n-1:

    Term index c+d:
        T_{-}(d) = sum_{i=0}^{n-d-1} h_{i+d} (1 - h_i)
    for d=0 this is center. The corresponding row for lag -d is:
        T_{+}(d) = sum_{i=0}^{n-d-1} h_i (1 - h_{i+d})

More exactly define arrays:

    Q[c]   = sum_i h_i(1-h_i)
    Q[c+d] = sum_{i=0}^{n-d-1} h_{i+d}(1-h_i),       d=1,...,n-1
    Q[c-d] = sum_{i=0}^{n-d-1} h_i(1-h_{i+d}),       d=1,...,n-1

Then

    C(h) = max_j Q[j] * dx.

This indexing is chosen to correspond with np.correlate order whenever possible. If a particular coding environment orders rows differently, the line-expression helper must be generated directly from the definition above and still tested by recomputing scorer from the actual np.correlate expression. The line solver itself does not rely on matching official row order for correctness, because candidate points are always scored by scorer.

2.2 Feasible line segment

Given h and direction v, enforce

    sum_i v_i = 0.

Define T = n/2. If h has sum T, then for every α, sum_i (h_i + αv_i)=T, up to floating arithmetic. For each index i:

If v_i > η:
    α lower limit αL_i = -h_i / v_i
    α upper limit αU_i = (1 - h_i) / v_i
If v_i < -η:
    α lower limit αL_i = (h_i - 1) / (-v_i)   (negative)
    α upper limit αU_i = h_i / (-v_i)
If |v_i| ≤ η:
    no restriction.

Let

    L = max_i lower_limit_i
    U = min_i upper_limit_i

If L < -η, set L = max(L, -10*max(1, U)), etc. The important condition is that α=0 lies in the interval. If U-L is smaller than 1e-12 or no interval contains 0, discard the line.

A tiny expansion tolerance of about 1e-12 may be subtracted/added to L,U for numerical stability, with subsequent projection repair.

2.3 Correlation as exactly concave quadratic in α

For a line H_i(α)=h_i+αv_i, define scaled scan values directly as arrays A,D,E such that

    Q_j(α) = A_j + D_j α + E_j α^2

and

    C_line(α) = dx * max_j (A_j + D_j α + E_j α^2).

For the center term:
    A_c = sum_i h_i(1-h_i)
    D_c = sum_i v_i(1-2h_i)
    E_c = -sum_i v_i^2

For positive signed lag row c+d, d=1,...,n-1:
    A_{c+d}=sum_{i=0}^{n-d-1} h_{i+d}(1-h_i)
    D_{c+d}=sum v_{i+d}(1-h_i) - sum h_{i+d}v_i
    E_{c+d}=-sum v_{i+d}v_i

For negative signed lag row c-d, d=1,...,n-1:
    A_{c-d}=sum_{i=0}^{n-d-1} h_i(1-h_{i+d})
    D_{c-d}=sum v_i(1-h_{i+d}) - sum h_i v_{i+d}
    E_{c-d}=-sum v_i v_{i+d}

The E coefficients are nonpositive because they are negative dot products. If floating error makes a tiny E positive, set it to zero by thresholding. This does not materially change the expression for meaningful directions.

2.4 Sublevel intervals along a line

For a proposed scaled score level s, the line condition is

    A_j + D_j α + E_j α^2 ≤ s/dx    (A_j,D_j,E_j are unscaled)

or equivalently use scaled coefficient arrays A2:A_j dx, D2_j, E2_j. Choose one convention and use it consistently.

For each concave quadratic g_j(α)=E2_j α² + D2_j α + A2_j:

If E2_j is treated as exactly zero and D2_j is exactly zero, the condition is either always true or impossible.

If E2_j is effectively zero and D2_j ≠ 0:

    g_j(α) ≤ s describes a ray.

If D2_j > 0:
    α ≤ (s-A2_j)/D2_j, therefore the excluded interval is ((s-A2_j)/D2_j, +∞).
If D2_j < 0:
    α ≥ (s-A2_j)/D2_j, therefore the excluded interval is (-∞,(s-A2_j)/D2_j).

If E2_j < -a_eps:
    The quadratic opens downward. Its maximum over the relevant interval occurs at
        α_vertex = -D2_j/(2E2_j)
    and the maximum value is
        A2_j - D2_j^2/(4E2_j).
    The set where g_j > s is the open interval between the two real roots of
        E2_j α² + D2_j α + (A2_j - s) = 0.
    Let ε.roots be computed from a nonnegative discriminant. If the discriminant is numerically negative, no exclusion is needed. If the two roots are r1,r2 with r1<r2, remove r1<α<r2.

The full feasibility test for level s starts with the allowed interval [L,U] and, for each row j, subtracts the portion of that row's over-level interval from the current union of allowed intervals. If no allowed interval remains, line α value at score s is impossible. Otherwise any remaining point is feasible at level s in line arithmetic.

2.5 Global-in-line minimization by bisection

For each line, compute initial sampled hits at endpoints, α=0, and 24 to 64 uniform line samples. Let u be the best sampled score. A valid lower bound is

    ℓ = max_j min_{α∈[L,U]} scaled_term_j(α).

Because each term is concave, its minimum on [L,U] occurs at an endpoint. If any min values are negative due to line nonphysical floating noise, lower-bound floor using 0: scores cannot be negative for actual feasible points, but this lemma is only a bound for line algebra.

If u ≤ incumbent_score - accept_eps, run bisection:

    low = BottomBarrier guaranteed <= global line minimum
    high = u

For about 35 numerical iterations, shrink using the feasibility set at mid=(low+high)/2. When feasible, set high=mid and keep the feasible point in the current interval. When infeasible, set low=mid. Finish when high-low is at most 1e-11 absolute score tolerance, or when remaining time is too small.

The result of bisection is a target high level and a candidate feasible point in an interval verified feasible for that approximate level. Score the candidate using the concatenated vector and exact scorer only.

3.1 Required top-level interface and foundational helpers

The final program must define a top-level function

    run(seed=42, budget_s=1100, **kwargs)

The following top-level helper roles are required. Argument names can vary, but their behavior must match.

3.2 exact_score(h)

- Flatten h to 1-D float.
- If length n is 0 or any nonfinite values, return +inf.
- dx = 2.0/n.
- values = np.correlate(h, 1.0 - h, mode="full") * dx.
- If values contain NaN/Inf, return +inf.
- Return float(max(values)).

This is authoritative.

3.3 is_feasible(h, tol=1e-9)

Return True iff:
- finite 1-D float length n≥2,
- all values >= -tol and <= 1+tol,
- abs(sum_value - n/2) <= tol.

The actual numeric values used for acceptance are clipped during final projection before reversing numerical slack. The returned vector must satisfy all bounds and the target sum to within the stated tolerance.

3.4 repair_feasible(raw_h, initial_tol=1e-12, final_tol=1e-10)

This is a joint projection repair used after a line step, a random restart, a resolution transfer, or just before finalization. It must never run the unacceptable sequence where clipping is followed by independent normalization without subsequent exact bound-checking.

Inputs: raw numeric vector, possibly 1-D or flat.
Output: feasible numeric vector with exact area.

Algorithm:
1. Flatten. Replace all nonfinite entries by 0.5.
2. Target T = n/2.
3. Clip the vector to [0,1], giving y.
4. For up to three correction passes:
   a. residual = T - sum(y)
   b. If abs(residual) <= final_tol, break.
   c. If residual > 0:
       - Compute available slack_i = 1 - y_i.
       - Choose a stable deterministic order, for example original order or descending slack.
       - Add ε=min(remaining residual, slack_i) to y_i for chosen index, then subtract ε from remaining residual.
     If residual < 0:
       - Remove a amount from entries sorted by descending current y_i or by a predetermined stable order.
       - Similar exact transfer, never allowing values below 0.
   d. If after full passes a tiny imbalance using floating point remains:
       - Choose index i with y_i + residual possible inside [0,1]; set y_i += residual. This single compensation solves the residual within the bound if it is small; apply one equal bound clip if quantization creates a tiny violation.
       - Recompute residual one more time.
5. Clip one final time only if necessary, but if clipping changed sum by >final_tol, rerun a correction pass.
6. Return clipped vector and ensure target reached to 1e-9.
