1. **Approach and Rationale**

The construction to be improved is represented by a discrete vector `h ∈ ℝ^n` with entries in `[0,1]` and fixed sum `n/2`. The official objective is the maximum over all finite-support lag values of the scalar cross-correlation `h ⋆ (1-h)` using `np.correlate(..., mode="full")` and the mesh factor `dx = 2/n`.

The main challenge is that the objective is:

1. nonsmooth because it contains a maximum over lag values;
2. nonconvex because each lag contains products `h_i(1-h_j)`; and
3. constrained by both a box `0 ≤ h_i ≤ 1` and an affine sum constraint.

A direct CVXPY call on the original objective is not possible in disciplined convex form. The plan therefore becomes a hybrid local minimization method that uses:

1. a **smooth upper surrogate** for the maximum: log-sum-exp over lag values;
2. an explicit gradient computation for that surrogate;
3. a feasible projection onto the box/sum constraint;
4. exact-enough line-search testing using the official objective, even though the optimizer minimizes a smooth surrogate;
5. a local nonlinear constrained optimizer (`scipy.optimize.minimize`, method `SLSQP`) for densification;
6. multiple initializations and dimensional transfers, including transfer from the supplied `initial_h_values`;
7. an optional binary/combinatorial local refinement for nearby even-length subproblems;
8. a validated best-candidate storage returning the best exact score found under the caller-supplied time budget.

No global optimality is claimed. The final acceptance criterion is always exact evaluation with the same metric as the problem statement.

2. **Mathematical Specification**

**2.1 Discrete representation and official objective**

For working dimension `n`:

```text
dx = 2.0 / n
target = n / 2
target_integral = target * dx = 1
```

For a candidate array `h` length `n`:

```text
g = 1 - h
scores = np.correlate(h, g, mode="full") * dx
C(h)  = max(scores)
```

The length of `scores` is `2n-1`. The output ordering used by `np.correlate` corresponds to offsets/lags

```text
k = - (n-1), -(n-2), ..., -1, 0, 1, ..., n-1
score[ index ]  = C_k
where index = k + (n - 1)
```

Using NumPy’s convention, for offset `k` the contribution is

```text
C_k(h) = sum over valid i,j with i - j = k of h_i (1 - h_j)
```

The bounds on `i` are

```text
i_min = max(0, k)
i_max = min(n - 1, n + k - 1)
```

and the complementary index is `j = i - k`. Without manual custom code, always re-evaluate the final candidate with the official `np.correlate` call.

**2.2 Feasible set**

The feasible set is

```text
h ∈ [0,1]^n     and     sum_i h_i = n/2
```

This is a convex prompt power polytope. Projection onto it is used to preserve feasibility. Let `v` be any vector. The Euclidean rule for projection is

```text
π_λ(v)_i = clip(v_i - λ, 0, 1)
```

where `λ` solves

```text
sum_i π_λ(v)_i = n/2
```

The mapping `λ -> sum_i π_λ(v)_i` decreases monotonically from `n` at `λ <= min(v)-1` to `0` at `λ >= max(v)+1`. Use bracketed bisection to solve this equation. Tolerance can be `1e-13` absolute in sum, and after each projection apply a small final sum correction so that the numerical sum is within requested tolerance.

**2.3 Smooth surrogate and its analytic gradient**

Let

```text
C(h) = (C_{-(n-1)}(h), ..., C_{n-1}(h))
```

After scaling by `dx`, all entries are nonnegative and comparable to the objective. For `β > 0`, define

```text
F_β(h) = (1/β) log( sum_l exp(β C_l(h)) )
```

where `l` indicates lag indices. This is a smooth upper bound for the objective:

```text
max_l C_l(h) <= F_β(h)
```

The first-order weights are

```text
w_l = exp(β C_l(h)) / sum_m exp(β C_m(h))
```

Numerically compute using `C_max = max(C_l)`:

```text
r_l = exp(β(C_l - C_max))
Z = sum_l r_l
w_l = r_l / Z
log_sum = β C_max + log Z
F_β = log_sum / β
```

The gradient is obtained by linearity:

```text
∇_h F_β = sum_l w_l ∇C_l
```

For a fixed lag `k`, write the pair set as `P_k = {(i,j): i-j=k}`. The contribution to `∇C_k` is

```text
∂C_k / ∂h_i += 1 - h_j
∂C_k / ∂h_j -= h_i
```

valid for all `(i,j)` in `P_k`.

In a computational helper:

- `grad = zeros(n)`.
- For every lag `k` from `-(n-1)` to `n-1` with weight `p_k = w_t`, t lag array index:
  - if `k >= 0`: `i = arange(k, n)`, `j = i - k`;
  - if `k < 0`: `i = arange(0, n+k)`, `j = i - k`;
  - new scores with `p_k != 0` can be skipped for speed.
  - `grad[i] += p_k * (1 - h[j])`;
  - `grad[j] -= p_k * h[i]`.

This orientation must match `np.correlate(h,1-h,"full")`. The program should include a compact check using a small random vector, though the final objective remains `np.correlate` evaluation.

**2.4 Direct objective and projections**

When solving for directions in local nonlinear solver, the smooth objective has gradient returning values `F_β` and `grad` scaled by `dx`. Since the smooth objective is an upper majorant, not a relaxation over feasibility, line search and best storage are judged with the exact max objective. A smooth loss that decreases can oscillate exact values across active lags. This is intentionally allowed.
