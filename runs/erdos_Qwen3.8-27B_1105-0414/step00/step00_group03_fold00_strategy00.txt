1. Approach and rationale

Central idea:
- Preserve the supplied parent construction as a high-quality local basin, then improve it with a hierarchy of solvers that are all judged using the original exact evaluator.
- The dominant difficulty is that the objective is a nonconvex max-of-bilinear-forms problem with box and exact-sum constraints. Therefore, do not rely on a single convex CVXPY model or on a purely global derivative-free method kept independent of the exact score.
- Use three complementary mechanisms:
  1. A smooth log-sum-exp surrogate of the maximum with exact analytic gradient, solved under the original box and sum constraints by SLSQP. Multiple beta levels and multiple starting points reduce the chance of stopping at the first poor stationary point.
  2. A complement-fixed linear-programming minimum-margin field. At each inner step, the complement `b = 1 - h` is temporarily fixed, making each lag criterion linear in `h`; this generates diverse globally inspired feasible candidates. Candidates are accepted only after exact scoring of the restored `h(1-h)` objective.
  3. Nonsmooth one-dimensional exact line polishing along pairs of coordinates and along active-gradient/randomly perturbed directions. This refines the discrete, piecewise geometry after smooth optimization and can reduce the max over active lags.
- Maintain a validated best candidate at all times. Never return a candidate unless it is finite, 0 bounded, and has sum `n_points/2` within high precision after a final feasibility repair. If no improvement occurs, return the validated parent or algorithmically constructed fallback.
- Higher-resolution refinements are allowed when the budget is large, but candidates are always re-evaluated with their own exact metric. A parent of `n_points=45` is preserved and also used as transfer material.

It is justified:
- The exact objective is finite-dimensional and directly computable from `np.correlate(h, 1-h, full)*dx`.
- A log-sum-exp surrogate is a standard smooth approximation to a maximum, with gradient exactly matching the linear combination of the component gradients when using softmax weights. This is genuinely differentiable except for surrogate approximation; the true objective is still required for acceptance.
- The complement-fixed LP is a legitimate convex subproblem for that fixed complement. It is not claimed to solve the original nonconvex problem or to provide a global lower bound; it is only a proposal mechanism. Acceptance always uses exact scoring.
- Feasibility repair is explicitly characterized as Euclidean projection onto `0 <= z <= 1, sum z = n/2`, plus an exact residual adjustment. This joint-feasibility operation is valid for arbitrary proposals.

Justified hypotheses/heuristics:
- Starting from the parent will be useful. If the parent is already a record construction, local gradient and line moves have a realistic chance of a small margin improvement.
- Smooth surrogates followed by exact nonsmooth polishing often overcome only gradient-stabilized stagnation.
- Multi-resolution transfer is likely to capture improvements missed at the supplied resolution, but no guarantee is made because finite-grid optimizations can be grid-sensitive.
- The pair line moves are robust coordinatewise nonsmooth moves, but exhaustive pair polishing need not explore 3-coordinate coupled moves. They are therefore used as a complementary search stage after SLSQP/LP.

2. Mathematical specification

Representation and domain
- Let `n = len(h)`, an integer passed through runtime information. If no parent is present, an algorithmic fallback creates a vector of chosen default size `about 80-120` using only formulas or seeded random construction; never a hard-coded long table.
- Let `dx = 2.0 / n`. A vector `h` must represent each sample with width `dx`.
- Constraints:
```text
0 <= h[i] <= 1 for all i
sum_i h[i] = n / 2
```
and no numerical proposition should be used unless the final returned vector has been repaired with an exact repair routine.

Exact objective
- Define `b[i] = 1 - h[i]`.
- The authoritative exact evaluator is:
```text
score_exact(h) = max_k [ np.correlate(h, b, mode="full") * dx ]
```
where `k` covers all `2*n - 1` correlations.

Pair-offset interpretation and gradient indexing
- For indices `i,j = 0,...,n-1`, define the exact finite-support lag index
```text
r(i,j) = i - j + n - 1,    0 <= r <= 2*n - 2.
```
Then the full-correlation value at index `r` aggregated from all pairs satisfying `r(i,j)=r` is
```text
F_r(h) = dx * sum over (i,j) with i-j+n-1=r of h[i] * (1 - h[j]).
```
- This uses the same pair-index orientation that `np.correlate` must have for the evaluator. A sanity check is that for `h=[1,0]`, the first suitable full-correlation component involving the positive edge pair receives the overlapped `h=1, b=1` product; this verifies that the offset formula is not reversed. If that correction holds, gradient indices are correct.

Exact component derivatives
- Let `v = 1 - h`.
- For a weighted weighted maximum approximation `G(h) = sum_r w_r F_r(h)`, where `w_r` are nonnegative weights summing approximately one, the derivative is:
```text
(dG/dh)[p] = dx * [ sum_j w_{p-j+n-1} * v[j]
                  - sum_i w_{i-p+n-1} * h[i] ].
```
- Define two retained integer matrices of shape `(n,n)` for the run.
```text
Ix[p,j] = p - j + n - 1
Iy[p,i] = i - p + n - 1
```
With a supplied weight vector `w` of length `2*n-1`, gradient is computed by matrix take/sum:
```text
grad[p] = dx * ( sum_j w[Ix[p,j]] * v[j]
                - sum_i w[Iy[p,i]] * h[i] ).
```

Smooth surrogate
- Let `F = (F_0,...,F_{2n-2})`.
- For positive beta, define log-sum-exp value:
```text
soft(h; beta) = (log sum_r exp(beta*F_r(h))) / beta.
```
- The gradient of the normalized log-sum-exp is represented by the expression above with weights:
```text
w_r = exp(beta*F_r - logsumexp(beta*F)) / normalization
```
or, for stable implementation, subtract `m = max(beta*F)` and use
```text
raw = exp(beta*F - m); denom = sum(raw); w = raw / denom;
soft_value = (m + log(denom)) / beta.
```
Optionally subtract `log(2n-1)` inside the smooth value; this does not change weights and only offsets the surrogate value. The solver internally optimizes the surrogate value, while acceptance uses the exact max score.
- Increasing beta improves the maximum approximation, but too-abrupt divergence can create a near-subgradient objective with poor conditioning. Therefore use a beta ladder rather than one huge beta.

Euclidean capped-simplex projection
- Given arbitrary input `z` and target `s = n/2`, project onto
```text
P = {y : 0 <= y_i <= 1, sum_i y_i = s }.
```
- The Euclidean projection can be written as `y_i = clip(z_i + lambda, 0, 1)`, where the unique lambda solves `sum_i clip(z_i + lambda, 0, 1) = s` whenever the target is feasible. Find lambda by bracketing followed by 60-80 binary bisection iterations.
- Bracketing must guarantee the initial bracket covers the solution. Start from extremal values of `z`. Include enough offset so below gives clipped sum below the target, and above gives clipped sum above the target. Because the target is unknown only after clipping, don't use blind ten iterations only; use enough iterations to get sum tolerance below `1e-9`, then call exact residual fixing.

Joint exact feasibility repair

1. Convert to a flat float array.
2. Replace nonfinite values with 0.5 or a feasible heuristic.
3. Clip to zero and one.
4. If `abs(sum - target) > tolerance`, run the Euclidean capped-simplex projection.
5. Re-clip floating small roundoff at bounds.
6. Perform residual exact adjustment so final sum is as close to target as floating arithmetic permits. This adjustment changes only coordinates that have heading space up or down, adding or subtracting residual spread monotonically over bounded free coordinates; if no residual is possible, do not force an invalid vector.
7. Validate `min(h) >= -1e-10`, `max(h) <= 1+1e-10`, `abs(sum(h)-target) <= 1e-8` or stricter; afterward store within tolerance.
- Successive clipping/ad-hoc rescaling is not the joint mechanism; projection plus residual correction is.
