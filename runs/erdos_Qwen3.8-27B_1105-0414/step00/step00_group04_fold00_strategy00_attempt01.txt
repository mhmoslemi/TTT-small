1. Approach and rationale

The problem is a finite, box-constrained, equality-constrained minimax problem over continuous step values. The supplied evaluator is authoritative: for a length-n vector `h`, with `dx = 2/n`, the score is
`C5(h) = max_k [np.correlate(h, 1-h, mode="full") * dx]`.
This uses linear correlation with finite support and includes both lag directions; do not replace it with any circular, autocorrelation-only, or endpoint-simplified surrogate unless the surrogate is used only to generate or filter local candidates and every accepted candidate is finally scored by the exact evaluator.

The main bottleneck at `n` close to 70 is that the current construction is already a near-minimum of a highly nonconvex minimax problem. The effective local search should therefore combine several complementary mechanisms:

- Exact-objective parent preservation. Keep the supplied parent, repair it if numerically infeasible, and only replace it by a candidate whose exact score is strictly better under the real evaluator.

- Two local nonlinear solvers:
  1. a smooth-log-sum-exp minimization with analytic gradients over `h`;
  2. a direct epigraph SLSQP formulation minimizing an auxiliary scalar `t` subject to `t >= C_k(h)` for active or all lags.
  These address different neighborhoods: the smooth method optimizes a differentiable approximation of the maximum and preserves bounds/equality, while the epigraph method pushes `t` itself and can better exploit actively binding lag constraints. Both remain nonsmooth/nonconvex in principle and are therefore used as local procedures, not as proof of optimality.

- A low-cost active-gradient lexicographic descent as a final finalist and fallback when SLSQP has little runtime. It only uses gradients of the top correlation terms and exact line searches over step sizes, then repairs feasibility with a proper joint projection.

- Multi-resolution transfer. Since smaller valid sequences are explicitly preferred, after optimizing the parent length, transfer the best feasible vector to a carefully chosen family of smaller and moderately larger lengths by interpolation or resampling, repair feasibility, and rerun the local search. Final comparison uses the exact score; ties use smaller `n_points` as a secondary criterion.

- A candidate pool plus averaging/crossover. Symmetrizations, complement, reversal, random overlays, and averages of two good candidates are extremely cheap, exactly preserve the mean constraint when both inputs are feasible, and often enter different basins.

- Dyadic final feasibility. To satisfy the strict feasibility constraint robustly, each returned vector is mapped to exactly representable dyadic values with a large dyadic denominator and a controlled exact target sum. This may change the objective by a very small amount; the resulting vector is always re-scored exactly before accepted as final.

This plan does not claim to find a global optimum. It aims to locate feasible improvements over the supplied parent and emit the best validated vector found before the deadline. It distinguishes mathematically exact parts (objective, feasibility repair, final scoring, dyadic exact sum) from heuristic parts (random starts, crossover, active smooth gradients, chosen resolutions). Heuristic candidates are always accepted only after exact evaluator scoring.

2. Mathematical specification

Represent the step function vector as a length-n float vector `h` whose entries are samples on `[0, 2]`. The sampled midpoint/dyadic interpretation only affects construction and rounding; the evaluator uses the given length only.

Let
`dx = 2.0 / n`
and
`q = 1 - h`.
The exact objective is
`C5(h) = max_{m = 0}^{2n-2} c_m(h) * dx`,
where `c_m = np.correlate(h, q, mode="full")[m]`.

For analytic work and epigraph constraints, use the exact linear-correlation index formula matching a standard linear finite-support correlation. For length `n`:
- Output index `m = 0, ..., 2n-2`.
- Define offset `s_m = n - 1 - m`, ranging from `+n-1` down to `-(n-1)`.
- The offset is in the direction used by `np.correlate(h, q)`: if `s_m >= 0`, the `h` index is the leading index and the `q` index is separated to the right by `s_m`; if `s_m < 0`, the `q` index is separated to the left.
- Valid source `h` indices are
  `a_min = max(0, -s_m)`,
  `a_max = min(n-1, n-1 - s_m)`,
  and `a = a_min, ..., a_max`.
- Corresponding `q` indices are `b = a + s_m`.

Then, matching the finite-support correlation order,
`c_m(h) = sum_{a=a_min}^{a_max} h[a] * (1 - h[a + s_m])`.

Sanity check: at `m=n-1`, `s_m=0`, this is `sum_i h[i]*(1-h[i])`, matching the central zero-lag dot product from the exact evaluator. At `m=0` and `m=2n-2`, corresponding endpoints are lone products involving far endpoints. A coder can implement a debug comparison with `np.correlate`, but this formula is the one used to formulate constraints and gradients.

The constraints are:
`0 <= h[i] <= 1` for all `i`,
`sum_i h[i] = n/2`.
Equivalently, the evaluator’s `sum(h)*dx = 1`.

For every correlation term `m`, define the scalar constraint function
`phi_m(h, t) = t - c_m(h) * dx`.
Local epigraph problem:
`minimize t` subject to `phi_m(h,t) >= 0`, the equality sum, and the box bounds. This is nonsmooth/nonconvex because each `phi_m` contains products `h[a] h[a+s]` and is not globally convex in variables `(h,t)`. SLSQP is acceptable because it can accept arbitrary smooth constraint functions, but the method is only locally valid.

For smooth minimization, define for `alpha > 0` the finite objective over the finite correlation range in full:
`S_alpha(h) = (1/alpha) log(sum_m exp(alpha * c_m(h) * dx))`.
For numerical stability, compute equivalent shifted formula:
`g_m(h) = c_m(h) * dx`,
`gmax = max_m g_m(h)`,
`A_m = exp(alpha * (g_m - gmax))`,
`W = sum_m A_m`,
`S_alpha(h) = gmax + log(W) / alpha`.
This has the same gradient as
`(1/alpha) log(sum_m exp(alpha * g_m))`:
`grad S_alpha = sum_m (A_m / W) * grad g_m`.
All terms are bounded and smooth on feasible samples.

Analytic gradient of `g_m`. Let `U_m` be the set of shifted pairs `(a, b=a+s_m)`. Start with `grad_m = zeros(n)`. For every pair `(a,b)`, the term contribution to `g_m/dx` is `h[a]*(1-h[b])`. Its derivatives are:
- if indexing is the same (`a == b`): contribution `1 - 2*h[a]`;
- if different:
  `d/dh[a]` has `+(1-h[b])`;
  `d/dh[b]` has `-h[a]`.
Multiply each accumulated derivative by `dx`.

For `m != n-1`, each pair has an order that appears once in the correlation. The generic loop handles correct combination even at the zero shift when `s_m=0` because adding both contributions yields the same combined derivative. Do not attempt circular terms or boundary zero-fill; valid pair lists are precisely as prescribed.

The objective value and accepted best score must not depend on `S_alpha`; all final values and candidate acceptances (both final output, and from start final field, at the exact maximum and no Parent, if available). Transfers between smooth values and foc initial.

- derivative with respect to `t` is `1`;
- derivative with respect to `h` is `- grad(c_m * dx)`.
