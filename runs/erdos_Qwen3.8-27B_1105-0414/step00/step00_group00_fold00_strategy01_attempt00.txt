1. Approach and rationale

1.1 Central idea
The supplied evaluator is the authoritative exact finite-support correlation:

    C5(h) = max_k dx * correlate(h, 1-h, k)
          = max(full correlation values) * (2/n_points).

The objective is nonconvex because it contains bilinear products h[i]*(1-h[j]) and because the outer maximum activates different index sets as design variables change. Instead of constructing a global convex relaxation (which would not solve the nonconvex problem reliably and could produce misleading upper bounds), this plan directly optimizes exact minimax subproblems built from the worst lag values, and accepts/proceeds only when the final full correlation actually improves. The essential engineering choices are:

- Work with the actual variables on a holder of equal-length samples with exactly sum = n/2.
- Maintain a globally valid feasible best vector at all times.
- Use a direct epigraph solver: minimize t subject to exact constraints selected from the worst lags. This makes local directions respect several worst shift values simultaneously, improving precision without smoothing over all n lags.
- Use exact candidate rejection: every proposed design is transformed into a strictly feasible dyadic vector, re-evaluated with the exact supplied metric, and only accepted if feasible and strictly better.
- Use a multi-resolution schedule centered around the supplied parent and a pair-exchange/line-search polish on the exact objective. This catches high-resolution variable movement that a full-resolution parent duplication cannot expose immediately.

1.2 Why this may improve the supplied parent
The parent at the current discrete length is already near a local minimax configuration. A full-dimensional local gradient smooth approximation can get stuck because of active components incorrectly propagated and very sharp max geometry. The epigraph method enforces exact constraints on the active correction values selected during each solve. The dyadicillère pair-exchange filter preserves the actual overlap objective numerically and can uncover small 1e-5-level improvements that survive after quantization. Multi-resolution can refine the parent with a half-length/double-mass scaling of boundary terms, then check exact values returned. The pipeline therefore primarily seeks high-quality local and multi-resolution searches, not an untested global convex relaxation.

1.3 Coherent primary method
The primary method is direct nonlinear minimax on selected correlations. It has three components:

- Exact repair/quantization to available box and integral constraints.
