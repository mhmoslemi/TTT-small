Let vector `h` length `n` represent sample array on [0,2] with grid spacing `dx=2/n`. The task objective is substantially:

```
r = np.correlate(h, np.ones(n)-h, mode="full")
F = dx * max(r)
```

Full correlation has `2n-1` outputs `m=0..2n-2`. For `m`, shift `k=m-(n-1)`. The orientation of correlation is the NumPy function output orientation; eventually derivative of constraints if used must mirror it to avoid mistakes. Final objective always recomputes raw formula.

A valid candidate yields `c5_bound=F(h)` recomputed on the returned `h` before output. The bound not inward smoothing.

2.2 Constraints

Candidate vector `h` must satisfy:

- pointwise: `-small ≤ h_i ≤ 1+small`, where `small` is an implementation tolerance;
- mass: `sum_i h_i=n/2`, or equivalent `sum_i h_i*dx = 1`;
- finite and float.

The packaged strategy will usually return a dyadic vector:

`h_i=y_i/D`, where `y_i∈Z`, `0≤y_i≤D`, `D=2^e`, `sum_i y_i=T`, and `T=round(D*n/2)`. If `n` is even, `T=(n//2)D`. If `n` is odd but D power-of-two, `T=nD//2` is integer. This ensures mathematical exactness in rationals. Float sum still checked. The guarantee is sufficient for the wording and typical numerical grader.

The initial parent must not be copied as literal table; parent is read once and algorithmically transformed and optimized.
