1. Approach and rationale

1.1 Central idea
The central idea is a direct, feasibility-preserving exact search for the discrete nonconvex max-overlifton objective. Instead of relying only on random global sampling or on projecting unconstrained points after every update, the returned candidate is always feasible at the feasible stage, and any solver-generated point is repaired before it can be accepted. The final candidate is judged exclusively by the supplied evaluator formula, not by a smoothed surrogate.

The proposed method has two complementary layers.

Layer A: exact feasible local polishing.  
On the feasible slice defined by `0 <= h_i <= 1` and `sum(h_i) = n/2`, the algorithm repeatedly explores 1-D exchange directions of the form

    h_i -> h_i + t
    h_j -> h_j - t

which preserve the sum exactly by construction. For each pair `(i,j)`, the exact original maximum-overlap function is searched over the full feasible interval of `t`. This gives a true descent step for the discrete objective without any constraint projection.

Layer B: direct continuous nonconvex epigraph optimization with analytic derivatives.  
The problem is also formulated as the smooth nonlinear program

    minimize q
    subject to q >= C_l(h) for every lag l
               sum_i h_i = n/2
               0 <= h_i <= 1

This formulation is not convex because `C_l(h)` is bilinear. However, SciPy's SLSQP can handle general smooth nonlinear constraints and bounds locally. The objective direction is local/mathematical первой search but is well suited to reduce several near-active caps slightly at once, where pair changes tend to move one cap down only by moving another cap up. After each SLSQP solve, the continuous result is repaired to exact feasible box/sum validity and then polished again by the exact feasible exchange search. Only repaired and re-evaluated feasible points may update the best answer.

1.2 Why this differs from the previous proposal
The earlier proposal mixed many vague stages: epigraph cvxpy use, common population/genetic/pair polish in one undifferentiated algorithm, numerical epigraph and a broad pool history without a precise update rule. The current plan is materially different in three substantive ways:

1. The primary one is the feasibility-preserving exact 1-D line search on pair-exchange directions with analytic candidate ranking. Feasibility is never approximately enforced in the main descent loop; the sum is exactly conserved by construction, and the exact evaluator is used to verify every accepted improvement.

2. For the continuous solver, the method uses a scientifically explicit SLSQP epigraph formulation with analytic Jacobians and SciPy-compatible signs. It does not pretend that cvxpy can solve the bilinear epigraph as a convex program. 2.2 Correlation indexing and derivative formula
Correlation convention must agree with `np.correlate(h, 1-h, mode='full')`. For two arrays `a` and `v` of length `n`, full correlation satisfies

    corr[k] = sum_i a_i * v_{i + d_val(k)}

where the row of full output `k` corresponds to the shift

    d = n - 1 - k.

Explanation: `np.correlate(a,v,'full')` is `convolve(a, v[::-1])`. The output index `k` uses element `v_{n-1-k+i}`, so let `d = n-1-k`. If `d >= 0`, the valid indices are `i = 0, ..., n-d-1`. If `d < 0`, the valid indices are `i = -d, ..., n-1`.

For each shift `d`, define the raw/un-scaled bilinear lag

    B_d(h) = sum_i h_i * (1 - h_{i+d})      valid indices only.

Then the evaluator's objective component is

For `d = 0`, `c_0 = dx * sum_i h_i (1-h_i)`. Edge lags include only their valid overlaps; no normalization by an integral of one is imposed.

Derivative needed by SLSQP and by the guided pair ranking. For a single shift `d`, derivative wrt `h` of `c_d = dx * B_d` is:

For every valid pair `(p,q)` with `q = p+d`:

For `d=0`, `p=q`, so the two contributions add:

    d/dh_i c_0 = dx * ((1 - h_i) + (-h_i)) = dx*(1 - 2 h_i)
