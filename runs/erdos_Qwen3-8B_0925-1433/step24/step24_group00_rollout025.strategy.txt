Objective: Minimize the maximum overlap integral over all lags k, computed as max_k [∫ h(x)(1 - h(x + k)) dx] dx → max(np.correlate(h, 1-h, mode="full")) * dx.

Constraints:
- 0 ≤ h[i] ≤ 1 for all i
- sum(h) = n_points / 2

Gradient computation: For the current solution, find the lag kmax that maximizes the correlation. Compute the analytical gradient for this kmax as (1 - h[y + kmax]) - h[y - kmax] for each y, wrapping indices with zero-padding.
