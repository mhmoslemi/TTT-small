For example, the cross-correlation of h with itself using mode 'full' includes all lags, including the zero lag. So, to get the autocorrelation for lags 1 to n-1, we can compute:

Alternatively, for the cross-correlation using mode 'full', the result for lag k is at index k + n -1. For example, for lag 0, it's at index n-1 (center of the array). For lag 1, it's at index n-1 +1 = n. Wait, perhaps I need to think more carefully.

The cross-correlation of h with itself for lag k is the sum_{i} h[i] * h[i +k], for i=0 to n -k -1. When using mode 'full', the result has length m + n -1, where m is the length of h (assumed to be same for both arrays). So, for h of length n, the cross-correlation for lag k is in position n -1 +k. For example:

- Lag 0 is at positions n-1 (midpoint).
- Lag 1 is at position n (midpoint +1).
- Lag -1 is at position n-2.

But for our purposes, the lags we need are k=1 to n-1. These correspond to positions n to 2n-2 (since for k=1, it's n-1 +1 = n, and for k=n-1, it's n-1 + (n-1) = 2n-2).
