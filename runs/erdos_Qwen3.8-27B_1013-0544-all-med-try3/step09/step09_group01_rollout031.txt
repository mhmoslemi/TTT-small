            #   j-k in [0, n-1] means k in [j-(n-1), j]
            #   Also k in [-(n-1), n-1]
            #   So k in [max(j-n+1, -(n-1)), min(j, n-1)]
            
            # Term 2: -h[j+k] for k in [max(-(n-1), -j), min(n-1, n-1-j)]
            #   j+k in [0, n-1] means k in [-j, n-1-j]
            
            # Let me just compute the full gradient vector:
            b = np.zeros(n_corr)  # b[idx] = dc_{k}/dh[j] where k = idx-(n-1)
            
            # Term 1: for k where 0 <= j-k < n, i.e., j-n+1 <= k <= j
            lo1 = max(j - n + 1, -(n-1))
            hi1 = min(j, n-1)
            for k_idx in range(lo1, hi1 + 1):
                idx = k_idx + (n-1)
                b[idx] += (1.0 - best_h[j - k_idx])
            
            # Term 2: for k where 0 <= j+k < n, i.e., -j <= k <= n-1-j
            lo2 = max(-j, -(n-1))
            hi2 = min(n-1-j, n-1)
            for k_idx in range(lo2, hi2 + 1):
                idx = k_idx + (n-1)
                b[idx] -= best_h[j + k_idx]
            
            b *= dx
            
            # Now minimize max_k (c_vec[idx] + b[idx]*delta) over delta in [delta_lo, delta_hi]
            delta_lo = -best_h[j]
            delta_hi = 1.0 - best_h[j]
            
            # Bisection on subgradient
            lo = delta_lo
            hi = delta_hi
            for _ in range(40):
                mid = (lo + hi) / 2.0
                vals = c_vec + b * mid
                f_mid = vals.max()
                # Find active set
                active_mask = vals >= f_mid - 1e-14
                if active_mask.any():
                    b_min = b[active_mask].min()
                    b_max = b[active_mask].max()
                    if b_min <= 0 and b_max >= c_min := 0:
                        break
                    if b_max < 0:
                        lo = mid
                    else:  # b_min > 0
                        hi = mid
                else:
                    break
            
            delta_opt = (lo + hi) / 2.0
            
            # Apply update
            new_hj = best_h[j] + delta_opt
            if abs(delta_opt) > 1e-15:
                best_h[j] = new_hj
                # Recompute c_vec
                new_c = compute_c5_vec(best_h, n).max()
                if new_c < best_c - 1e-16:
                    best_c = new_c
                    improved = True
                    c_vec = compute_c5_vec(best_h, n)
                else:
                    best_h[j] = new_hj  # Keep it anyway (might be same or slightly worse due to rounding)
                    c_vec = compute_c5_vec(best_h, n)
        
        if not improved:
            break
    
    return best_h, best_c

Wait, there's an issue. When I update h[j], the c_vec changes for ALL k, not just the ones I computed the gradient for. So after each coordinate update, I need to recompute c_vec. That makes it O(n * n * n_corr) per pass = O(n^3) which is too slow for n=1000.

Let me optimize: instead of recomputing the full c_vec after each update, I can update it incrementally.

When h[j] changes by δ, c_k changes by δ * (dc_k/dh[j]) = δ * b[k] (as computed above). So:
c_vec_new = c_vec + δ * b

This is O(n_corr) per update, and we do n updates per pass, so O(n * n_corr) = O(n^2) per pass. For n=1000, that's 10^6 per pass, very fast!

But wait, b depends on the current h values (it includes terms like 1-h[j-k] and h[j+k]). After updating h[j], the b vectors for future updates will be different. So we need to recompute b for each j using the current h.

The computation of b for a given j is O(n) (the range of valid k is O(n)). So the total per pass is O(n * n) = O(n^2) for computing all b vectors, plus O(n * n_corr) = O(n^2) for the c_vec updates. Total: O(n^2) per pass.

For n=1000: 10^6 per pass. Even 1000 passes would be 10^9, which might be too slow in Python. Let me check: each pass involves n=1000 iterations, each doing O(n)=1000 operations (for computing b) and O(n_corr)=2000 operations (for updating c_vec). Plus the bisection (40 iterations × O(n_corr)=2000 each = 80000). So per j: ~81000 operations. Per pass: ~8.1 × 10^7. In Python, this might take ~1-2 seconds per pass. So 100 passes ≈ 100-200 seconds. That's reasonable!

Actually, the bisection is the bottleneck. Let me optimize it.

In the bisection, at each iteration I compute `vals = c_vec + b * mid` which is O(n_corr), then find the max and active set which is O(n_corr). So each bisection iteration is O(n_corr) = O(n). With 40 iterations, that's O(n * 40) = O(40n) per j.

Alternative: I can find the optimal δ more directly.

The function f(δ) = max_k (c_k + b_k * δ) is convex piecewise linear. Its minimum over [δ_lo, δ_hi] can be found as follows:

Claim: The minimum is at δ* where either:
- δ* = δ_lo and all active b_k ≥ 0
- δ* = δ_hi and all active b_k ≤ 0
- δ* is an intersection point of two lines l_i and l_j on the upper envelope, where b_i ≤ 0 ≤ b_j.

For the intersection case: δ* = (c_i - c_j) / (b_j - b_i) where i and j are "adjacent" on the upper envelope.

A practical O(n) algorithm:
1. Find the line i with minimum b_i (most negative slope). Call it i_min.
2. Find the line j with maximum b_j (most positive slope). Call it j_max.
3. If b_i_min ≥ 0: return δ_lo
4. If b_j_max ≤ 0: return δ_hi
5. Compute δ_candidate = (c_i_min - c_j_max) / (b_j_max - b_i_min)
6. Clamp to [δ_lo, δ_hi]
7. Verify: check that at δ_candidate, the max is indeed achieved by lines with mixed signs. If not, adjust.

Actually, step 5 might not give the exact answer because the upper envelope might not be determined by i_min and j_max. But it's a good approximation.

Let me use a hybrid: compute the candidate from step 5, then do a few bisection steps around it to refine.

Actually, let me think about this more carefully. The upper envelope of lines {a_k + b_k * δ} is a convex piecewise linear function. The minimum over [δ_lo, δ_hi] occurs where the subgradient contains 0.

The subgradient at δ is {b_k : a_k + b_k * δ = f(δ)}.

0 is in the subgradient iff there exist k1, k2 with b_k1 ≤ 0 ≤ b_k2 and a_k1 + b_k1 * δ = a_k2 + b_k2 * δ = f(δ).

From a_k1 + b_k1 * δ = a_k2 + b_k2 * δ:
δ = (a_k1 - a_k2) / (b_k2 - b_k1)

And we need a_k1 + b_k1 * δ = f(δ) = max_k (a_k + b_k * δ).

So the algorithm is:
1. For all pairs (k1, k2) with b_k1 ≤ 0 ≤ b_k2, compute δ = (a_k1 - a_k2) / (b_k2 - b_k1).
2. Check if δ is in [δ_lo, δ_hi] and if a_k1 + b_k1 * δ = max_k (a_k + b_k * δ).
3. Return the δ that minimizes f(δ).

This is O(n^3) in the worst case (O(n^2) pairs, O(n) check each). Too slow.

Better approach: use the fact that the upper envelope can be computed in O(n log n) using the convex hull trick (if lines are sorted by slope). But that's complex to implement correctly.

For practical purposes, let me just use the bisection approach but with fewer iterations (20 instead of 40). The precision of 20 bisection iterations is (hi-lo)/2^20 which is more than enough.

Actually, I realize there's an even simpler optimization. Since f(δ) is convex, I can use the "cutting plane" approach:
- Evaluate f at δ=0 (or the midpoint)
- This gives a lower bound on the minimum
- The active set at this point gives a subgradient
- Use the subgradient to determine which direction to go
- Repeat

But the bisection is already O(n) per iteration and converges in ~20 iterations, so it's fine.

Let me also consider: do I need to recompute b from scratch for each j? 

b[idx] = dx * [(1-h[j-k])*1_{valid} - h[j+k]*1_{valid}]

This depends on h[j-k] and h[j+k] for various k. After updating h[j], the next b computation for j+1 will use h[j+1-k] and h[j+1+k], which mostly haven't changed. So there's a lot of reuse, but implementing it efficiently in Python is tricky.

Let me just compute b from scratch each time. It's O(n) per j, which is fine.

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5_vec(h, n):
    dx = 2.0 / n
    return np.correlate(h, 1 - h, mode='full') * dx

def compute_c5(h, n):
    return float(compute_c5_vec(h, n).max())

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h.copy(), 0.0, 1.0)
    for _ in range(500):
        diff = target - h.sum()
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            room = 1.0 - h
            tot = room.sum()
            if tot < 1e-14:
                break
            h += (diff / tot) * room
        else:
            tot = h.sum()
            if tot < 1e-14:
                break
            h += (diff / tot) * h
    return np.clip(h, 0.0, 1.0)

def smooth_max_obj(x, n, alpha, mu):
    c = compute_c5_vec(x, n)
    m = c.max()
    sh = alpha * (c - m)
    mx = sh.max()
    if mx > 500:
        val = m + (mx + np.log(np.sum(np.exp(sh - mx)))) / alpha
    else:
        val = m + np.log(np.sum(np.exp(sh))) / alpha
    if mu > 0:
        val += mu * (x.sum() - n / 2.0) ** 2
    return float(val)

def smooth_max_grad(x, n, alpha, mu):
    c = compute_c5_vec(x, n)
    m = c.max()
    sh = alpha * (c - m)
    mx = sh.max()
    w = np.exp(sh - mx)
    w /= w.sum()
    dx = 2.0 / n
    grad = np.zeros(n)
    for mm in range(2 * n - 1):
        if w[mm] < 1e-14:
            continue
        k = mm - (n - 1)
        wm = w[mm] * dx
        if k >= 0:
            nv = n - k
            grad[0:nv] += wm * (1.0 - x[k:n])
            grad[k:n] += wm * (-x[0:nv])
        else:
            kk = -k
            nv = n - kk
            grad[kk:n] += wm * (1.0 - x[0:nv])
            grad[0:nv] += wm * (-x[kk:n])
    if mu > 0:
        grad += 2.0 * mu * (x.sum() - n / 2.0)
    return grad

def coord_descent_exact(h, n, deadline, max_passes=None):
    """Exact single-coordinate descent exploiting 1D convexity."""
    best_h = h.copy()
    c_vec = compute_c5_vec(best_h, n)
    best_c = c_vec.max()
    n_corr = 2 * n - 1
    
    if max_passes is None:
        max_passes = 200
    
    passed = 0
    for pass_idx in range(max_passes):
        if time.time() > deadline:
            break
        improved = False
        pass_improvement = 0.0
        
        for j in range(n):
            # Compute b[idx] = dc_{idx}/dh[j]
            b = np.zeros(n_corr)
            
            # Term 1: (1-h[j-k]) for valid k where 0 <= j-k < n
            # k ranges: j-n+1 <= k <= j, clamped to [-(n-1), n-1]
            lo1 = max(j - n + 1, -(n-1))
            hi1 = min(j, n-1)
            if lo1 <= hi1:
                ks = np.arange(lo1, hi1 + 1)
                idxs = ks + (n - 1)
                b[idxs] += (1.0 - best_h[j - ks])
            
            # Term 2: -h[j+k] for valid k where 0 <= j+k < n
            # k ranges: -j <= k <= n-1-j, clamped to [-(n-1), n-1]
            lo2 = max(-j, -(n-1))
            hi2 = min(n - 1 - j, n-1)
            if lo2 <= hi2:
                ks = np.arange(lo2, hi2 + 1)
                idxs = ks + (n - 1)
                b[idxs] -= best_h[j + ks]
            
            b *= (2.0 / n)
            
            # Find optimal delta to minimize max(c_vec + b*delta) over [delta_lo, delta_hi]
            delta_lo = -best_h[j]
            delta_hi = 1.0 - best_h[j]
            
            if delta_hi - delta_lo < 1e-15:
                continue
            
            # Bisection on subgradient
            lo = delta_lo
            hi = delta_hi
            for _ in range(30):
                mid = (lo + hi) * 0.5
                vals = c_vec + b * mid
                f_mid = vals.max()
                # Check if 0 is in subgradient
                # Active set: indices where vals[idx] >= f_mid - tol
                active = vals >= f_mid - 1e-13
                if not active.any():
                    break
                b_act_min = b[active].min()
                b_act_max = b[active].max()
                if b_act_min <= 1e-15 and b_act_max >= -1e-15:
                    lo = mid
                    hi = mid
                    break
                elif b_act_min > 1e-15:
                    # All active slopes positive, f increasing, go left
                    hi = mid
                else:
                    # All active slopes negative, f decreasing, go right
                    lo = mid
            
            delta_opt = (lo + hi) * 0.5
            
            if abs(delta_opt) > 1e-14:
                best_h[j] += delta_opt
                # Update c_vec incrementally
                c_vec += b * delta_opt
                new_c = c_vec.max()
                if new_c < best_c - 1e-15:
                    best_c = new_c
                    improved = True
                    pass_improvement += (best_c - new_c)  # This is negative, so we track decrease
                # Note: c_vec might have small numerical errors accumulate, 
                # so periodically recompute
                if j % 200 == 0:
                    c_vec = compute_c5_vec(best_h, n)
                    best_c = c_vec.max()
        
        if not improved:
            break
        passed += 1
    
    # Final recompute for accuracy
    best_h = project_feasible(best_h, n)
    best_c = compute_c5(best_h, n)
    return best_h, best_c

def run_lbfgs(h, n, deadline, alphas, mu=0.01, maxiter_per=None):

    best_c = compute_c5(best_h, n)

            break

                         args=(n, alpha, mu), method='L-BFGS-B',
                         bounds=bounds,
                         options={'maxiter': maxit, 'ftol': 1e-20,
                                  'gtol': 1e-16, 'maxfun': maxit * 8,
                                  'maxls': 50, 'maxcor': 50})
            h_new = project_feasible(res.x, n)
            c_new = compute_c5(h_new, n)
            if c_new <= best_c:
                best_c = c_new
                best_h = h_new
        except Exception:
            pass
    
    return best_h, best_c

def active_shift_obj(x, n, active, alpha, mu):
    c = compute_c5_vec(x, n)
    vals = c[active]
    mx = vals.max()
    sh = alpha * (vals - mx)
    smx = sh.max()
    if smx > 500:
        val = mx + (smx + np.log(np.sum(np.exp(sh - smx)))) / alpha
    else:
        val = mx + np.log(np.sum(np.exp(sh))) / alpha
    if mu > 0:
        val += mu * (x.sum() - n / 2.0) ** 2
    return float(val)

def active_shift_grad(x, n, active, alpha, mu):
    c = compute_c5_vec(x, n)
    vals = c[active]
    mx = vals.max()
    sh = alpha * (vals - mx)
    smx = sh.max()
    w = np.exp(sh - smx)
    w /= w.sum()
    dx = 2.0 / n
    grad = np.zeros(n)
    for wi, idx in zip(w, active):

        wm = wi * dx
        if k >= 0:
            nv = n - k
            grad[0:nv] += wm * (1.0 - x[k:n])
            grad[k:n] += wm * (-x[0:nv])
        else:
            kk = -k
            nv = n - kk
            grad[kk:n] += wm * (1.0 - x[0:nv])
            grad[0:nv] += wm * (-x[kk:n])
    if mu > 0:
        grad += 2.0 * mu * (x.sum() - n / 2.0)
    return grad

Wait, I need to double-check the coordinate descent logic. When I update h[j] by delta_opt, I update c_vec incrementally as c_vec += b * delta_opt. But b was computed at the OLD h[j]. After the update, the b for the NEXT j will be computed with the new h[j]. This is correct because in coordinate descent, we compute the gradient at the current point.

However, there's a subtlety: the b vector I computed is the exact derivative of c_k with respect to h[j] at the current h. The 1D problem min_δ max_k (c_k + b_k * δ) gives the exact minimizer of the 1D slice, which is what we want for coordinate descent.

But wait - c_k is a QUADRATIC function of h (it has terms like h[i]*h[i+k]). So the derivative b_k = dc_k/dh[j] is correct at the current point, but c_k + b_k * δ is only a LINEAR approximation. The true c_k as a function of δ (with h[j] → h[j]+δ) is:

c_k(δ) = c_k(0) + δ * b_k + δ^2 * (second order terms)

The second order terms come from the fact that h[j] appears in products h[j]*h[j+k'] and h[j+k'']*h[j]. Let me check:

c_k = dx * sum_{valid i} h[i]*(1-h[i+k])

For the change in h[j] by δ:
- If j appears as h[i] (i=j): the term h[j]*(1-h[j+k]) changes from h[j]*(1-h[j+k]) to (h[j]+δ)*(1-h[j+k]), change = δ*(1-h[j+k])
- If j appears as h[i+k] (i+k=j, i=j-k): the term h[j-k]*(1-h[j]) changes from h[j-k]*(1-h[j]) to h[j-k]*(1-h[j]-δ), change = -δ*h[j-k]

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5_vec(h, n):
    dx = 2.0 / n
    return np.correlate(h, 1 - h, mode='full') * dx

def compute_c5(h, n):
    return float(compute_c5_vec(h, n).max())

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h.copy(), 0.0, 1.0)
    for _ in range(500):
        diff = target - h.sum()
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            room = 1.0 - h
            tot = room.sum()
            if tot < 1e-14:
                break
            h += (diff / tot) * room
        else:
            tot = h.sum()
            if tot < 1e-14:
                break
            h += (diff / tot) * h
    return np.clip(h, 0.0, 1.0)

def smooth_max_obj(x, n, alpha, mu):
    c = compute_c5_vec(x, n)
    m = c.max()
    sh = alpha * (c - m)
    mx = sh.max()
    if mx > 500:
        val = m + (mx + np.log(np.sum(np.exp(sh - mx)))) / alpha
    else:
        val = m + np.log(np.sum(np.exp(sh))) / alpha
    if mu > 0:
        val += mu * (x.sum() - n / 2.0) ** 2
    return float(val)

def smooth_max_grad(x, n, alpha, mu):
    c = compute_c5_vec(x, n)
    m = c.max()
    sh = alpha * (c - m)
    mx = sh.max()
    w = np.exp(sh - mx)
    w /= w.sum()
    dx = 2.0 / n
    grad = np.zeros(n)
    for mm in range(2 * n - 1):
        if w[mm] < 1e-14:
            continue
        k = mm - (n - 1)
        wm = w[mm] * dx
        if k >= 0:
            nv = n - k
            grad[0:nv] += wm * (1.0 - x[k:n])
            grad[k:n] += wm * (-x[0:nv])
        else:
            kk = -k
            nv = n - kk
            grad[kk:n] += wm * (1.0 - x[0:nv])
            grad[0:nv] += wm * (-x[kk:n])
    if mu > 0:
        grad += 2.0 * mu * (x.sum() - n / 2.0)
    return grad

    mx = vals.max()

    if mu > 0:
        val += mu * (x.sum() - n / 2.0) ** 2
    return float(val)

def active_shift_grad(x, n, active, alpha, mu):

    final_n = len(best_h)
    best_h = project_feasible(best_h, final_n)
    best_c = compute_c5(best_h, final_n)

    return best_h, best_c, final_n
