1. m=a in first factor: h[a]*(1-h[a-d]) → 0. Change: -(1-h[a-d]) if a-d valid.
2. m-d=a in second factor (m=a+d): h[a+d]*(1-h[a]) → h[a+d]*1. Change: +h[a+d] if a+d valid.
   (Old: h[a+d]*(1-1)=0, New: h[a+d]*(1-0)=h[a+d])
3. m=b in first factor: 0 → h[b]*(1-h[b-d]) = (1-h[b-d]). Change: +(1-h[b-d]) if b-d valid.
4. m-d=b in second factor (m=b+d): h[b+d]*(1-h[b]) → h[b+d]*0. Change: -h[b+d] if b+d valid.
   (Old: h[b+d]*(1-0)=h[b+d], New: h[b+d]*(1-1)=0)

So:
Δc[idx] = [-(1-h[a-d])] + [h[a+d]] + [(1-h[b-d])] + [-h[b+d]]  (all using OLD h, with 0 for invalid indices)

where d = idx - (n-1).

term1 = np.where((a-d >= 0) & (a-d < n), -(1-h[a-d]), 0)
term2 = np.where((a+d >= 0) & (a+d < n), h[a+d], 0)

This is 4 vector operations of length 2n-1, which is fast.
