Now let me think about the SPSA algorithm:

SPSA (Simultaneous Perturbation Stochastic Approximation):
1. Start with h_0
2. At iteration k:
   a. Generate random perturbation Δ_k (±1 for each component)
   b. Evaluate F(h + c_k * Δ_k) and F(h - c_k * Δ_k)
   c. Update: h_{k+1} = h_k - a_k * (F(h + c_k*Δ) - F(h - c_k*Δ)) / (2*c_k) * Δ
   d. Project to feasible set

Parameters: a_k = a/(k+1)^α, c_k = c/(k+1)^γ
Typical: α = 0.6, γ = 0.6, a ~ 0.1, c ~ 0.01

SPSA is great for high-dimensional problems because it only needs 2 function evaluations per iteration regardless of dimension.

Let me also think about a "coordinate descent" approach:
- Pick one component h[i] at a time
- Find the optimal value of h[i] (given all others fixed) that minimizes the max
- This is a 1D optimization problem

For a fixed set of other h values, changing h[i] by δ changes each c_k by:
Δc_k = d_k * δ (approximately, for small δ)
where d_k = ∂c_k/∂h[i]

So the max changes by max_k (c_k + d_k * δ) * dx (approximately)

The optimal δ minimizes max_k (c_k + d_k * δ). This is a 1D convex optimization problem (minimizing the max of linear functions).

We can solve it analytically:
min_δ max_k (c_k * dx + d_k * dx * δ)
= dx * min_δ max_k (a_k + b_k * δ)

where a_k = c_k, b_k = d_k.

The optimal δ is where the two "active" constraints (the ones giving the max) are equal. This can be found by:
- For δ where the max is achieved by constraint j: c_j + d_j * δ = max
- We want to find δ where c_j + d_j * δ = c_i + d_i * δ for the critical pair (j, i)

This is the "bisection on the subgradient" approach, which is related to the "level method" in optimization.

This is actually a very promising approach! Let me implement it:

**1D subgradient/level method:**
1. Compute all c_k and all d_k = ∂c_k/∂h[i] for a given i
2. Find δ that minimizes max_k (c_k + d_k * δ)
3. Update h[i] += clip(δ, h[i], 1-h[i]) (respecting bounds)
4. Repeat for all i

This is essentially a coordinate descent with exact 1D minimization at each step. It should converge faster than gradient descent because it takes the optimal step in each coordinate direction.

The 1D problem min_δ max_k (a_k + b_k * δ) can be solved by:
- If all b_k = 0, any δ is optimal
- Otherwise, sort by b_k / a_k ratios... 

Actually, the standard approach is:
- The function f(δ) = max_k (a_k + b_k * δ) is convex (max of linear functions)
- Find the minimum by binary search on the subgradient
- The subgradient at δ is the set {b_k : k ∈ argmax_k (a_k + b_k * δ)}
- f is minimized when 0 ∈ subgradient, i.e., when there exist k1, k2 in argmax with b_{k1} < 0 < b_{k2} (or b_k = 0 for some k in argmax)

A simple approach:
- Start with δ = 0
- Find argmax k*
- If b_{k*} > 0, decrease δ
- If b_{k*} < 0, increase δ
- Use bisection

Or even simpler: use the formula for the minimum of max of linear functions.
The minimum occurs at a "breakpoint" where two lines cross. We can find it by:
- For each pair (i, j), find the crossing point: δ_ij = (a_j - a_i) / (b_i - b_j) (if b_i ≠ b_j)
- The minimum of f is at the δ where the upper envelope changes from a line with negative slope to one with positive slope

But this is O(K^2) which for K = 2n-1 ≈ 1000-2000 is 1M-4M operations per coordinate. For n=500 coordinates, that's 500M-2B operations per full sweep. Too slow.

Better approach: Use the fact that f(δ) = max_k (a_k + b_k δ) and do a few iterations of the following:
1. Evaluate f(δ) and find argmax k*
2. If b_{k*} > 0, the optimal δ is to the left
3. If b_{k*} < 0, the optimal δ is to the right
4. Bisection

With 30 bisection iterations, we get a very accurate solution. Each iteration is O(K) = O(n). So per coordinate: O(n * 30) = O(30n). For n=500: 15K ops per coordinate, 500 coordinates: 7.5M ops per sweep. Very fast!

But wait, we also need to respect the constraint that h[i] ∈ [0, 1]. So δ is bounded.

And we also need to maintain the integral constraint. If we change h[i] by δ, we need to compensate elsewhere. This makes the 1D approach more complex.

Alternative: Use the "pair move" approach where we transfer mass from position i to position j, maintaining the integral automatically.

For a pair (i, j), transferring δ from i to j:
h[i] → h[i] - δ
h[j] → h[j] + δ

The change in c_k is:
Δc_k = (-δ) * ∂c_k/∂h[i] + δ * ∂c_k/∂h[j] = δ * (∂c_k/∂h[j] - ∂c_k/∂h[i])

So the new c_k = c_k + δ * (d_k[j] - d_k[i]) where d_k[i] = ∂c_k/∂h[i].

We want to minimize max_k (c_k + δ * e_k) where e_k = d_k[j] - d_k[i].

This is again a 1D convex optimization! And we can solve it with bisection in O(K * log(1/ε)) time.

**This is the key algorithmic improvement**: Instead of using gradient descent or random search, use exact 1D minimization for each pair move. This should converge much faster and more reliably.

def solve_1d_max(a, b, lo, hi):
    """Solve min_{delta in [lo,hi]} max_k (a[k] + b[k]*delta)"""
    # Bisection on subgradient
    for _ in range(50):
        mid = (lo + hi) / 2
        vals = a + b * mid
        k_max = np.argmax(vals)
        if b[k_max] > 1e-15:
            hi = mid  # optimal is to the left
        elif b[k_max] < -1e-15:
            lo = mid  # optimal is to the right
        else:
            break
    return (lo + hi) / 2

                # Δc_k = δ * (∂c_k/∂h[j] - ∂c_k/∂h[i])
                
                # Instead of computing all ∂c_k/∂h, let me just try a few step sizes
                # and pick the best one.

                best_delta = 0
                best_max = c_all.max()
                
                for delta in [-0.01, -0.005, -0.002, 0.002, 0.005, 0.01]:

                        continue
                    # Move delta from i to j (positive delta means i→j)
                    # h[i] decreases by delta, h[j] increases by delta
                    if h[i] - delta < -1e-10 or h[i] - delta > 1 + 1e-10:
                        continue
                    if h[j] + delta < -1e-10 or h[j] + delta > 1 + 1e-10:
                        continue
                    
                    h[i] -= delta
                    h[j] += delta
                    c_test = compute_all_lags(h, n)
                    max_test = c_test.max()
                    if max_test < best_max:
                        best_max = max_test
                        best_delta = delta
                    h[i] += delta
                    h[j] -= delta

                    h[j] += best_delta
                    h = project_feasible(h, n)
                    c_new = compute_all_lags(h, n)
                    max_new = c_new.max()
                    if max_new < best_c - 1e-14:
                        best_c = float(max_new)
                        best_h = h.copy()
                        improved = True
                        c_all = c_new
        
        if not improved:
            break
    
    return best_h, best_c

def compute_grad_for_position(h, n, i):
    """Compute ∂c_k/∂h[i] for all k."""
    dx = 2.0 / n
    grad = np.zeros(2*n - 1)
    center = n - 1
    
    # Lag 0
    grad[center] = (1.0 - 2.0 * h[i]) * dx

def compute_grad_vec_for_pos(h, n, i):
    dx = 2.0 / n
    center = n - 1
    grad = np.zeros(2*n - 1)
    grad[center] = (1.0 - 2.0*h[i]) * dx
    
    # For positive lags m = 1, 2, ..., n-1
    # grad[center+m] = dx * [(1-h[i-m])*I(m<=i) - h[i+m]*I(i+m<n)]
    # grad[center-m] = dx * [(1-h[i+m])*I(i+m<n) - h[i-m]*I(m<=i)]
    
    m = np.arange(1, n)
    # I(m <= i) = (m <= i)
    mask_pos = m <= i  # positions where i >= m, i.e., i is in [m, n-1]
    mask_neg = m < n - i  # positions where i <= n-1-m, i.e., i+m < n
    
    # For grad[center+m]:
    # term1 = (1-h[i-m]) for m <= i, else 0
    # term2 = -h[i+m] for i+m < n, else 0
    t1 = np.zeros(n-1)
    t2 = np.zeros(n-1)
    t1[mask_pos] = 1.0 - h[np.maximum(i - m[mask_pos], 0)]
    t2[mask_neg] = -h[i + m[mask_neg]]
    grad[center+1:2*center+1] = dx * (t1 + t2)
    
    # For grad[center-m]:
    # term1 = (1-h[i+m]) for i+m < n, else 0
    # term2 = -h[i-m] for m <= i, else 0
    t1b = np.zeros(n-1)
    t2b = np.zeros(n-1)
    t1b[mask_neg] = 1.0 - h[i + m[mask_neg]]
    t2b[mask_pos] = -h[np.maximum(i - m[mask_pos], 0)]
    grad[0:center] = dx * (t1b + t2b)

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1 - h, mode='full')
    return float(np.max(c) * dx)

def compute_all_lags(h, n):
    dx = 2.0 / n
    return np.correlate(h, 1 - h, mode='full') * dx

def project_feasible(h, n):
    target_sum = n / 2.0
    h = np.clip(h.copy(), 0.0, 1.0)
    for _ in range(1000):
        diff = target_sum - h.sum()
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            room = 1.0 - h
            tot = room.sum()
            if tot < 1e-14:
                break
            h += (diff / tot) * room
        else:
            tot = h.sum()
            if tot < 1e-14:
                break
            h += (diff / tot) * h
    return np.clip(h, 0.0, 1.0)

def smooth_max_value(c, alpha):
    m = c.max()
    shifted = alpha * (c - m)
    mx = shifted.max()
    if mx > 500:
        return float(m + (mx + np.log(np.sum(np.exp(shifted - mx)))) / alpha)
    return float(m + np.log(np.sum(np.exp(shifted))) / alpha)

def smooth_max_weights(c, alpha):
    m = c.max()
    shifted = alpha * (c - m)
    mx = shifted.max()
    if mx > 500:
        w = np.exp(shifted - mx)
    else:
        w = np.exp(shifted)
    return w / w.sum()

def smooth_max_grad(h, n, alpha):
    dx = 2.0 / n
    c = compute_all_lags(h, n)
    w = smooth_max_weights(c, alpha)
    grad = np.zeros(n)
    for k in range(2 * n - 1):
        if w[k] < 1e-14:
            continue
        lag = k - (n - 1)
        if lag == 0:
            grad += w[k] * (1.0 - 2.0 * h)
        elif lag > 0:
            grad[lag:n] += w[k] * (1.0 - h[0:n - lag])
            grad[0:n - lag] += w[k] * (-h[lag:n])
        else:
            idx = -lag
            grad[0:n - idx] += w[k] * (1.0 - h[idx:n])
            grad[idx:n] += w[k] * (-h[0:n - idx])
    return grad * dx

def lbfgsb_optimize(h, n, alpha, deadline, maxiter=3000):
    target_sum = n / 2.0
    
    def obj_and_grad(x):
        x = np.clip(x, 0.0, 1.0)
        c = compute_all_lags(x, n)
        obj_val = smooth_max_value(c, alpha)
        diff = x.sum() - target_sum
        obj_val += 1e8 * diff * diff
        grad = smooth_max_grad(x, n, alpha)
        grad += 2.0 * 1e8 * diff * np.ones(n)
        return obj_val, grad
    
    bounds = [(0.0, 1.0)] * n
    try:
        res = minimize(obj_and_grad, h, method='L-BFGS-B',
                       bounds=bounds, jac=True,
                       options={'maxiter': maxiter, 'ftol': 1e-18, 'maxls': 50,
                                'iprint': -1})
        return project_feasible(np.clip(res.x, 0, 1), n)
    except Exception:
        return project_feasible(h.copy(), n)

def interpolate_h(h_src, n_src, n_dst):
    x_src = np.linspace(0, 2, n_src)
    x_dst = np.linspace(0, 2, n_dst)
    h_dst = np.interp(x_dst, x_src, h_src)
    return project_feasible(h_dst, n_dst)

def spsa_optimize(h, n, deadline, rng, c0=0.05, a_scale=0.05, alpha_a=0.6, alpha_c=0.6):
    """SPSA optimization."""
    h = h.copy()
    best_h = h.copy()
    best_c = compute_c5(h, n)
    k = 0
    
    while time.time() < deadline:
        c_k = c0 / (k + 1) ** alpha_c
        a_k = a_scale / (k + 1) ** alpha_a
        
        # Random perturbation (±1)
        delta = rng.choice([-1, 1], size=n).astype(float)
        
        # Evaluate at h + c_k * delta and h - c_k * delta
        h_plus = np.clip(h + c_k * delta, 0, 1)
        h_minus = np.clip(h - c_k * delta, 0, 1)
        h_plus = project_feasible(h_plus, n)
        h_minus = project_feasible(h_minus, n)
        
        f_plus = compute_c5(h_plus, n)
        f_minus = compute_c5(h_minus, n)
        
        # Update
        g = (f_plus - f_minus) / (2 * c_k) * delta
        h = h - a_k * g
        h = project_feasible(h, n)
        
        c_val = compute_c5(h, n)
        if c_val < best_c:
            best_c = c_val
            best_h = h.copy()
        
        k += 1
    
    return best_h, best_c

        a_k = a_scale / (k + 1) ** alpha_a
        
        delta = rng.choice([-1, 1], size=n).astype(float)
