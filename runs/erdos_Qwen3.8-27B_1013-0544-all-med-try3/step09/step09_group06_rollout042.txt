def compute_effect_matrix(h, n):
    n_lags = 2*n - 1
    # For each p, compute p+m-(n-1) for all m
    # m ranges from 0 to 2n-2
    # p+m-(n-1) ranges from p-(n-1) to p+(n-1)
    # Valid when 0 <= p+m-(n-1) <= n-1, i.e., n-1-p <= m <= n-1+p
    
    # Vectorized:
    p_idx = np.arange(n)[:, None]  # (n, 1)
    m_idx = np.arange(n_lags)[None, :]  # (1, n_lags)
    
    idx1 = p_idx + m_idx - (n-1)  # (n, n_lags)
    idx2 = p_idx - m_idx + (n-1)  # (n, n_lags)
    
    valid1 = (idx1 >= 0) & (idx1 < n)
    valid2 = (idx2 >= 0) & (idx2 < n)
    
    # Safe indexing
    idx1_safe = np.where(valid1, idx1, 0)
    idx2_safe = np.where(valid2, idx2, 0)
    
    term1 = np.where(valid1, -(1.0 - h[idx1_safe]), 0.0)
    term2 = np.where(valid2, h[idx2_safe], 0.0)
    
    return term1 + term2

For a transfer of δ from p to q (h[p] -= δ, h[q] += δ):
Δc[m] = δ * dx * [(effect[q, m]) - (effect[p, m])]
where effect[p, m] = (1 - h[p+m-(n-1)]) - h[p-m+(n-1)]

Great, so the effect is linear in δ. For the binary case (δ = 1), this matches what I had before.

Now, for the local search strategy:
- At each step, find the critical lag m* (the one with maximum c[m])
- For each pair (p, q) at offset m* (i.e., q = p + m* or p = q + m*):
  - If transferring from p to q reduces c[m*]:
    - Compute the full Δc = δ * dx * (effect[q] - effect[p])
    - Check if max(c + Δc) < c.max()
    - If yes, accept (with optimal δ via line search)

For the optimal δ: we want to maximize the reduction of the maximum. The maximum will be at some lag m̃. We want:

For m̃ = m* (the critical lag): δ ≤ (c[m*] - c[m*] + ε) / (dx * (effect[q,m*] - effect[p,m*])) ... this doesn't make sense.

Actually, we want to reduce c[m*] while not increasing any other c[m] above the new c[m*]. Let's say we want the new max to be c[m*] - t for some t > 0.

The constraint is: for all m, c[m] + δ * dx * (effect[q,m] - effect[p,m]) ≤ c[m*] - t

For m = m*: δ * dx * (effect[q,m*] - effect[p,m*]) ≤ -t → δ ≥ t / (dx * (effect[p,m*] - effect[q,m*])) (assuming effect[p,m*] > effect[q,m*])

The maximum feasible t is:
t = min over m≠m*: (c[m*] - c[m]) / (1 + (effect[p,m] - effect[q,m]) / (effect[p,m*] - effect[q,m*])) * ...

def compute_c_all(h, n):
    dx = 2.0 / n
    return np.correlate(h, 1 - h, mode='full') * dx

def compute_effect(h, n):
    """Compute effect[p, m] = (1-h[p+m-(n-1)]) - h[p-m+(n-1)] for all p, m."""
    n_lags = 2*n - 1
    p_idx = np.arange(n)[:, None]
    m_idx = np.arange(n_lags)[None, :]
    idx1 = p_idx + m_idx - (n-1)
    idx2 = p_idx - m_idx + (n-1)
    valid1 = (idx1 >= 0) & (idx1 < n)
    valid2 = (idx2 >= 0) & (idx2 < n)
    idx1_safe = np.clip(idx1, 0, n-1)
    idx2_safe = np.clip(idx2, 0, n-1)
    term1 = np.where(valid1, 1.0 - h[idx1_safe], 0.0)
    term2 = np.where(valid2, -h[idx2_safe], 0.0)
    return term1 + term2
