1. Maintain a set of "active" shifts S
2. Minimize max_{k in S} c_k (approximately, using a weighted average with high weights on active shifts)
3. After each optimization step, add the new worst shift to S
4. Repeat

This is like a "restart" strategy: each time we find a new worst shift, we add it to the set we're optimizing against.

Actually, I think the most effective approach given the tight target is:

1. Start from parent
2. Do a few rounds of L-BFGS with the standard smooth max (as in the previous solution) to get to a good local minimum
3. Then do a very targeted "single-shift" optimization:
   - Find k* = argmax c_k
   - Minimize c_{k*} directly (it's a smooth function of h)
   - Project to feasible set
   - Repeat for a few iterations
4. Then do a "pair of shifts" optimization (minimize max(c_{k1*}, c_{k2*}))
5. Continue with more active shifts

The "single-shift" optimization is:
minimize c_{k*}(h) = sum_i h[i]*(1-h[i+k*]) * dx
subject to sum(h) = n/2, 0 ≤ h ≤ 1

This is a separable quadratic! c_{k*}(h) = sum_i h[i] - sum_i h[i]*h[i+k*] (all times dx).

The gradient is: dc_{k*}/dh[i] = dx * [(1-h[i+k*]) - h[i-k*]] (with boundary conditions)

I can minimize this with L-BFGS-B very efficiently since it's a single smooth function.

After minimizing c_{k*}, a new worst shift might appear. I then minimize that, etc.

This is essentially the **cyclical coordinate descent on the active set** approach.

Let me implement this:

```python
def minimize_single_shift(h, n, k, deadline):
    """Minimize c_k while maintaining feasibility."""
    dx = 2.0 / n
    
    def obj_single(x, kk, nn, ddx):
        # c_kk = ddx * sum_i x[i] * (1 - x[i+kk]) for valid i
        if kk >= 0:
            nv = nn - kk
            if nv <= 0:
                return 0.0
            return float(ddx * np.sum(x[0:nv] * (1.0 - x[kk:nn])))
        else:
            kka = -kk
            nv = nn - kka
            if nv <= 0:
                return 0.0
            return float(ddx * np.sum(x[kka:nn] * (1.0 - x[0:nv])))
    
    def grad_single(x, kk, nn, ddx):
        g = np.zeros(nn)
        if kk >= 0:
            nv = nn - kk
            if nv > 0:
                g[0:nv] += ddx * (1.0 - x[kk:nn])
                g[kk:nn] += ddx * (-x[0:nv])
        else:
            kka = -kk
            nv = nn - kka
            if nv > 0:
                g[kka:nn] += ddx * (1.0 - x[0:nv])
                g[0:nv] += ddx * (-x[kka:nn])
        return g
    
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': lambda x, nn=n: x.sum() - nn/2.0, 
             'jac': lambda x, nn=n: np.ones(nn)}]
    
    res = minimize(obj_single, h, jac=grad_single, args=(k, n, dx),
                   method='SLSQP', bounds=bounds, constraints=cons,
                   options={'maxiter': 500, 'ftol': 1e-20})
    
    h_new = project_feasible(res.x, n)
    return h_new
```

This is the **method of conditional gradients** or **Frank-Wolfe** type approach applied to the max of functions.
