The idea is: if h[i] > h[j], then h[i](1-h[j]) is large, and by reducing h[i] and increasing h[j], we reduce this product (since h[i] decreases and (1-h[j]) decreases).

But this is a greedy approach. What if reducing the worst lag increases another lag? The local search only accepts moves that reduce the overall max, so it should be fine, but it might miss moves that temporarily increase one lag while the max stays the same.

**New idea: Use a penalty-based approach**

Instead of minimizing max_k f_k(h), minimize:
f(h) = sum_k exp(alpha * f_k(h))  (or just the top m lags)

with a much higher alpha than before. This makes the optimization more aggressive in reducing the top lags.

**Another idea: Use the structure of the problem**

The overlap at lag k for binary h is:
overlap(k) = dx * |{i: h[i]=1, h[i+k]=0}|

For a binary sequence of length n with n/2 ones, this is:
overlap(k) = dx * (n/2 - |{i: h[i]=1, h[i+k]=1}|)
           = dx * (n/2 - A(k))

where A(k) is the "autocorrelation" of the binary sequence at lag k.

So minimizing max_k overlap(k) is equivalent to maximizing min_k A(k) (for k ≠ 0).

This is the "minimum autocorrelation" problem for balanced binary sequences! The optimal sequences for this are related to m-sequences, Welch sequences, etc.

For n=500 (even), we need exactly 250 ones. The autocorrelation A(k) = sum_{i=0}^{n-1-k} h[i]h[i+k] for k > 0, and A(-k) = sum_{i=k}^{n-1} h[i]h[i-k] for k > 0 (which is the same as A(k) for the "full" correlation).

Wait, actually for non-periodic correlation:
A(k) = sum_{i=0}^{n-1-k} h[i] * h[i+k] for k ≥ 0
A(-k) = sum_{i=0}^{n-1-k} h[i+k] * h[i] for k ≥ 0 (same as A(k))

Hmm no, that's not right either. The full correlation has 2n-1 terms. For lag m (where m can be negative):
corr[lag m] = sum_{i} h[i+m] * h[i] (for valid indices)

For our problem, the overlap at lag m is:
sum_i h[i] * (1 - h[i+m]) for valid i

= sum_i h[i] - sum_i h[i]h[i+m]

The first term depends on which indices are valid (boundary effect), and the second term is the autocorrelation.

For the "interior" lags (|m| << n), the boundary effect is small. So the key is to minimize the maximum of:
(n/2 - boundary_correction(m)) - A(m)

where A(m) is the autocorrelation.

This suggests that if we optimize the autocorrelation to be as flat as possible, we'll minimize the overlap.

1. A very aggressive fine-grained local search (1e-5 to 1e-6 step sizes)
2. A SLSQP pass with the exact objective (using the active set of top 3 lags)
3. A "shake" and re-optimize loop (perturb slightly, then re-optimize)
4. Try a few different n values near 500

        if time.time() > deadline:
            break
        g = _obj_smooth_jac(h_curr, n, alpha)
        v = momentum * v + lr * g
        h_new = project_feasible(h_curr - v, n)
        c_new = compute_c5(h_new, n)
        if c_new < best_c - 1e-15:
            best_c = c_new
            best_h = h_new.copy()
            stagnation = 0
        else:
            stagnation += 1
            if stagnation > 200:
                lr *= 0.7
                v *= 0.5
                stagnation = 0
                if lr < 1e-6:
                    break
        h_curr = h_new
    
    return best_h, best_c

def run(seed=42, budget_s=1100, **kwargs):
    t0 = time.time()
    deadline = t0 + budget_s - 3
    rng = np.random.RandomState(seed)
    
    # Get initial solution
    try:
        h_init = np.array(initial_h_values, dtype=float).copy()
        n = len(h_init)
    except Exception:
        n = 500
        h_init = np.full(n, 0.5)
    
    h_best = project_feasible(h_init, n)
    c_best = compute_c5(h_best, n)
    
    # Phase 1: Ultra-fine local search (main workhorse)
    alloc1 = min(400, (deadline - t0) * 0.40)
    if alloc1 > 30:
        h_new, c_new = ultra_fine_search(h_best, n, t0 + alloc1, top_k=3)
        if c_new < c_best:
            c_best = c_new
            h_best = h_new
    
    # Phase 2: SLSQP with top-3 active lags
    if time.time() < deadline - 30:
        for top_m in [2, 3, 4]:
            if time.time() > deadline - 15:
                break
            h_new = slsqp_solve(h_best, n, top_m, alpha=500000, maxiter=4000, ftol=1e-16)
            c_new = compute_c5(h_new, n)
            if c_new < c_best:
                c_best = c_new
                h_best = h_new
    
    # Phase 3: Ultra-fine search again after SLSQP
    if time.time() < deadline - 30:
        alloc3 = min(300, (deadline - time.time()) * 0.35)
        if alloc3 > 20:
            h_new, c_new = ultra_fine_search(h_best, n, time.time() + alloc3, top_k=4)
            if c_new < c_best:
                c_best = c_new
                h_best = h_new
    
    # Phase 4: Multi-pair search
    if time.time() < deadline - 20:
        alloc4 = min(150, (deadline - time.time()) * 0.25)
        if alloc4 > 15:
            h_new, c_new = multi_pair_search(h_best, n, time.time() + alloc4)
            if c_new < c_best:
                c_best = c_new
                h_best = h_new
    
    # Phase 5: Another SLSQP pass with higher alpha
    if time.time() < deadline - 20:
        for top_m in [3, 5]:
            if time.time() > deadline - 10:
                break
            h_new = slsqp_solve(h_best, n, top_m, alpha=2000000, maxiter=3000, ftol=1e-16)
            c_new = compute_c5(h_new, n)
            if c_new < c_best:
                c_best = c_new
                h_best = h_new
    
    # Phase 6: Final ultra-fine polish
    if time.time() < deadline - 5:
        h_new, c_new = ultra_fine_search(h_best, n, deadline - 2, top_k=2)
        if c_new < c_best:
            c_best = c_new
            h_best = h_new
    
    # Phase 7: Try slight perturbations and re-optimize
    if time.time() < deadline - 15:
        for scale in [5e-5, 1e-4, 2e-4]:
            if time.time() > deadline - 8:
                break
            h_pert = h_best + rng.normal(0, scale, n)
            h_pert = project_feasible(h_pert, n)
            c_pert = compute_c5(h_pert, n)
            if c_pert < c_best + 0.001:
                # Re-optimize from perturbed
                if time.time() < deadline - 8:
                    h_new, c_new = ultra_fine_search(h_pert, n, deadline - 5, top_k=3)
                    if c_new < c_best:
                        c_best = c_new
                        h_best = h_new
    
    # Phase 8: Gradient step for final polish
    if time.time() < deadline - 5:
        h_new, c_new = gradient_step(h_best, n, alpha=1000000, lr=0.5, max_iter=2000, deadline=deadline - 2)
        if c_new < c_best:
            c_best = c_new
            h_best = h_new
    
    # Final projection and evaluation
    h_best = project_feasible(h_best, n)
    c_best = compute_c5(h_best, n)
    
    return h_best, c_best, n
