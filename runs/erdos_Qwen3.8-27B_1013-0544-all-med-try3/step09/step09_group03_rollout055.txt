Actually, here's a key idea: **The overlap at lag k is essentially the cross-correlation of h with (1-h) at shift k.** For a binary function, this is the number of 1s in h that are followed (after k steps) by a 0. 

For a periodic binary pattern with period P, the overlap at lag k depends only on k mod P. Specifically:
overlap(k) ≈ (n/P) * c_{k mod P} * dx = 2*c_{k mod P}/P (for small k)

where c_j = number of i in [0,P-1] with h_periodic[i]=1 and h_periodic[(i+j) mod P]=0.

We want to minimize max_j(2*c_j/P) = 2*max_j(c_j)/P.

The sum of c_j over j=0,...,P-1 is (P/2)² = P²/4 (each of the P/2 ones in the period pairs with P/2 zeros across all shifts).
Average c_j = P/4.
So max c_j ≥ P/4, giving C₅ ≥ 2*(P/4)/P = 1/2.

But wait, this is for the periodic case where ALL shifts within the period contribute equally. In the actual finite array, the shifts near the edges have fewer pairs, so the effective overlap is lower for large |k|.

For the actual finite array of length n with period P (n = m*P):
overlap(k) for k < n ≈ (n-k)/P * c_{k mod P} * dx = (n-k)*2*c_{k mod P}/(nP)

For k < P: ≈ 2*c_{k mod P}/P (approximately)
For k ≈ n/2: ≈ c_{k mod P}/P
For k ≈ n: ≈ 0
