    """Compute the change in each lag when h[pos] changes by delta (from old to old+delta)."""
    old_val = h[pos]
    deltas = np.zeros(2*n-1)
    for lag_idx in range(2*n-1):
        lag = lag_idx - (n-1)
        d = 0.0
        if lag == 0:
            # h[pos]*(1-h[pos]) changes
            d = delta * (1 - 2*old_val)
        elif lag > 0:
            # pos as first index: h[pos]*(1-h[pos+lag])
            if pos + lag < n:
                d += delta * (1 - h[pos+lag])
            # pos as second index: h[pos-lag]*(1-h[pos])
            if pos - lag >= 0:
                d += h[pos-lag] * (-delta)
        else:

            # pos as first index: h[pos]*(1-h[pos-m])
            if pos - m >= 0:
                d += delta * (1 - h[pos-m])
            # pos as second index: h[pos+m]*(1-h[pos])
            if pos + m < n:
                d += h[pos+m] * (-delta)
        deltas[lag_idx] = d
    return deltas

                        else:

                            h[i] -= delta

Actually, the simplest correct approach for the incremental update:

For lag ℓ (where c_ℓ = sum over valid pairs (a, a+ℓ) of h[a]*(1-h[a+ℓ])):

When h[i] changes by di and h[j] changes by dj:
- The pair (i, i+ℓ) [if valid] changes: (h[i]+di)*(1-h[i+ℓ]+dj_correction) - h[i]*(1-h[i+ℓ])
  where dj_correction = dj if i+ℓ == j, else 0
- The pair (i-ℓ, i) [if valid] changes: h[i-ℓ]*((1-h[i]) - (1-h[i]+di)) = -di * h[i-ℓ]
  (assuming i-ℓ != j)
- The pair (j, j+ℓ) [if valid] changes: (h[j]+dj)*(1-h[j+ℓ]+di_correction) - h[j]*(1-h[j+ℓ])
  where di_correction = di if j+ℓ == i, else 0
- The pair (j-ℓ, j) [if valid] changes: h[j-ℓ]*(-dj)
  (assuming j-ℓ != i)

Plus cross terms when i and j are in the same pair.

For small di, dj (which is our case), we can use the linear approximation:
Δc_ℓ ≈ di * (1-h[i+ℓ]) [if i+ℓ valid, as first] 
       + (-di) * h[i-ℓ] [if i-ℓ valid, as second]
       + dj * (1-h[j+ℓ]) [if j+ℓ valid, as first]
       + (-dj) * h[j-ℓ] [if j-ℓ valid, as second]
       + cross_term [O(di*dj), negligible]

Where cross_term only applies when i+ℓ == j or j+ℓ == i or i-ℓ == j or j-ℓ == i.

Let me verify: for lag ℓ > 0, c_ℓ = sum_{a=0}^{n-1-ℓ} h[a]*(1-h[a+ℓ]).

If I change h[i] by di:
- Term a=i (if i ≤ n-1-ℓ): h[i]*(1-h[i+ℓ]) → (h[i]+di)*(1-h[i+ℓ]), change = di*(1-h[i+ℓ])
- Term where a+ℓ = i, i.e., a = i-ℓ (if 0 ≤ i-ℓ and i-ℓ ≤ n-1-ℓ, i.e., ℓ ≤ i ≤ n-1):
  h[i-ℓ]*(1-h[i]) → h[i-ℓ]*(1-h[i]-di), change = -di*h[i-ℓ]

Similarly for h[j] by dj.

If i+ℓ = j (i.e., j = i+ℓ): 
- The term a=i involves both h[i] and h[j]: (h[i]+di)*(1-(h[j]+dj)) - h[i]*(1-h[j]) = di*(1-h[j]) - h[i]*dj - di*dj
- My linear formula gives: di*(1-h[j]) + (-dj)*h[i] = di*(1-h[j]) - h[i]*dj ✓ (the -di*dj is second order)

So the linear formula is correct to first order. For small deltas (which we use), this is fine.

np.correlate(h, g, mode='full')[k] = sum_i h[i] * g[i + k - (n-1)]

where g[i+k-(n-1)] = 0 if index out of [0, n-1].

Let lag = k - (n-1). Then:

When h[pos] changes by δ:
- In the sum, h[pos] appears as h[i] when i = pos: term is h[pos]*(1-h[pos+lag]), change = δ*(1-h[pos+lag]) if pos+lag in [0,n-1]
- h[pos] appears as h[i+lag] when i+lag = pos, i.e., i = pos-lag: term is h[pos-lag]*(1-h[pos]), change = h[pos-lag]*(-δ) = -δ*h[pos-lag] if pos-lag in [0,n-1]

- lag = 0: δ*(1-h[pos]) - δ*h[pos] = δ*(1-2h[pos]) ✓
- lag > 0: δ*(1-h[pos+lag]) - δ*h[pos-lag] (with validity checks) ✓

    """Compute Δc_raw for the move h[i]+=di, h[j]+=dj (linear approx)."""
    delta_c = np.zeros(2*n-1)
    # Position i, part 1 (as first index in pair)
    ks = n - 1 - i
    ke = 2*(n-1) - i + 1
    delta_c[ks:ke] += di * (1 - h[0:n])
    # Position i, part 2 (as second index in pair)
    ks = i
    ke = n + i

    # Position j, part 1

    ke = 2*(n-1) - j + 1
    delta_c[ks:ke] += dj * (1 - h[0:n])
    # Position j, part 2
    ks = j
    ke = n + j
    delta_c[ks:ke] += -dj * h[n-1::-1]
    return delta_c

Bisection approach: Binary search on C. For a given C, check if there exists h with ∫h=1, h∈[0,1], and max_k ∫h(x)(1-h(x+k))dx ≤ C. This is a feasibility problem. If I can solve it efficiently, I can binary search to find the optimal C.

The feasibility check: ∫h(x)(1-h(x+k))dx ≤ C for all k, ∫h=1, 0≤h≤1.
This is: -∫h(x)h(x+k)dx ≤ C-1 for all k, i.e., ∫h(x)h(x+k)dx ≥ 1-C for all k.

The function ∫h(x)h(x+k)dx is a quadratic form in h. So we're asking: does there exist h in the polytope {∫h=1, 0≤h≤1} such that h^T Q_k h ≥ 1-C for all k?

This is a system of quadratic constraints. Checking feasibility of this system is generally NP-hard (since it includes the case of checking if a quadratic is non-negative on a polytope). So bisection with exact feasibility checks isn't practical.

However, I could use a relaxation: replace the quadratic constraints with linear ones using the fact that for h∈[0,1], h^T Q_k h is bounded. But this would give a weaker (worse) bound.

Let me stick with the direct optimization approach but make it faster and more effective.

This is a convex problem! Each c_k is a quadratic function (actually, it's c_k = dx * (sum_i h[i] - sum_i h[i]*h[i+k]), and the second term is a quadratic form). Wait, is it convex or concave?

c_k = dx * sum_i h[i](1-h[i+k]) = dx * (sum_i h[i] - sum_i h[i]h[i+k])

The Hessian of sum_i h[i]h[i+k] with respect to h: for k≠0, the (i,j) entry is 1 if j=i+k or j=i-k, 0 otherwise. This is the adjacency matrix of a cyclic-like graph, which has both positive and negative eigenvalues. So the quadratic form is indefinite, meaning c_k is neither convex nor concave in general.

                    break
                for _ in range(50):
                    i1 = np.random.randint(0, n - 1)
                    i2 = np.random.randint(0, n - 1)
                    if i1 == i2:
                        continue
                    delta = 0.1 * np.random.randn()
                    delta *= 0.3
                    di = delta
                    dj = -delta
                    if h[i1] + di < 0 or h[i1] + di > 1:
                        continue
                    if h[i2] + dj < 0 or h[i2] + dj > 1:
                        continue
                    dc = lag_delta_vectorized(h, n, i1, di, i2, dj)
                    new_c = c_raw + dc
                    if new_c.max() < best_c_raw - 1e-13:
                        h[i1] += di
                        h[i2] += dj
                        c_raw = new_c
                        best_c_raw = new_c.max()
                        best_h = h.copy()
                        no_improve_count = 0
                        break
                if no_improve_count > 2000:
                    break
    
    return best_h, best_c_raw * dx

def gradient_smooth_max(h, n, alpha, deadline, lr=1.0, momentum=0.9, max_iter=5000):
    """Simple gradient method with smooth max."""
    h_curr = h.copy()
    best_h = h_curr.copy()
    best_c = compute_c5(h_curr, n)
    v = np.zeros(n)
    dx = 2.0 / n
    
    for it in range(max_iter):
        if time.time() > deadline:
            break
        c = np.correlate(h_curr, 1 - h_curr, mode='full') * dx
        m = c.max()
        shifted = alpha * (c - m)
        mx = shifted.max()
        if mx > 500:
            w = np.exp(shifted - mx)
        else:
            w = np.exp(shifted)
        w = w / w.sum()
        
        # Compute gradient of smooth max
        grad = np.zeros(n)
        for k in range(2 * n - 1):
            if w[k] < 1e-6:
                continue
            lag = k - (n - 1)
            if lag == 0:
                grad += w[k] * (1.0 - 2.0 * h_curr)
            elif lag > 0:
                grad[lag:n] += w[k] * (1.0 - h_curr[0:n - lag])
                grad[0:n - lag] += -w[k] * h_curr[lag:n]
            else:
                m_abs = -lag
                grad[0:n - m_abs] += w[k] * (1.0 - h_curr[m_abs:n])
                grad[m_abs:n] += -w[k] * h_curr[0:n - m_abs]
        
        v = momentum * v + lr * grad
        h_new = project_feasible(h_curr - v, n)
        c_new = compute_c5(h_new, n)
        if c_new < best_c - 1e-14:
            best_c = c_new
            best_h = h_new.copy()
        h_curr = h_new
        if it % 1000 == 999:
            lr = max(0.05, lr * 0.8)
    
    return best_h, best_c

def slsqp_top_lags(h, n, top_m, alpha=100000, maxiter=2000):
    """SLSQP optimization focusing on top lags."""
    dx = 2.0 / n
    c = compute_all_lags(h, n)
    top_idx = np.argsort(c)[-top_m:]
    
    def obj(x):
        cc = np.correlate(x, 1 - x, mode='full') * dx
        active = cc[top_idx]
        m = active.max()
        shifted = alpha * (active - m)
        mx = shifted.max()
        if mx > 500:
            return float(m + (mx + np.log(np.sum(np.exp(shifted - mx)))) / alpha)
        return float(m + np.log(np.sum(np.exp(shifted))) / alpha)
    
    def obj_jac(x):
        cc = np.correlate(x, 1 - x, mode='full') * dx
        active = cc[top_idx]
        m = active.max()
        shifted = alpha * (active - m)
        mx = shifted.max()
        if mx > 500:
            w = np.exp(shifted - mx)
        else:
            w = np.exp(shifted)
        w = w / w.sum()
        grad = np.zeros(n)
        for i_idx in range(len(top_idx)):
            k = top_idx[i_idx]
            lag = k - (n - 1)
            if w[i_idx] < 1e-6:
                continue
            if lag == 0:
                grad += w[i_idx] * (1.0 - 2.0 * x)
            elif lag > 0:
                grad[lag:n] += w[i_idx] * (1.0 - x[0:n - lag])
                grad[0:n - lag] += -w[i_idx] * x[lag:n]
            else:
                m_abs = -lag
                grad[0:n - m_abs] += w[i_idx] * (1.0 - x[m_abs:n])
                grad[m_abs:n] += -w[i_idx] * x[0:n - m_abs]
        return grad * dx
    
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': lambda x: np.sum(x) - n / 2.0,
             'jac': lambda: np.ones(n)}]
    
    try:
        res = minimize(obj, h, jac=obj_jac, method='SLSQP', bounds=bounds,
                       constraints=cons, options={'maxiter': maxiter, 'ftol': 1e-14})
        return project_feasible(res.x, n)
    except Exception:
        return h.copy()

def block_perturb_search(h, n, deadline, rng, max_iters=2000):
    """Try block moves to escape local optima."""
    h = h.copy()
    c_raw = np.correlate(h, 1 - h, mode='full')
    best_c_raw = float(c_raw.max())
    best_h = h.copy()
    dx = 2.0 / n
    
    for it in range(max_iters):
        if time.time() > deadline:
            break
        # Pick a random block and shift it
        block_len = rng.randint(3, max(4, n // 20))
        start = rng.randint(0, n - block_len)
        end = start + block_len
        # Target: another random block
        t_start = rng.randint(0, n - block_len)
        while t_start + block_len <= start + 1 or t_start >= end - 1:
            # Handle overlap by just trying
            break
        t_end = t_start + block_len
        
        # Try shifting mass from source block to target block
        src_vals = h[start:end].copy()
        dst_vals = h[t_start:t_end].copy()
        
        for frac in [0.3, 0.5, 0.7]:
            new_src = src_vals * (1 - frac)
            add = src_vals * frac
            # Distribute add to dst where there's room
            room = np.clip(1.0 - dst_vals, 0, None)
            room_total = room.sum()
            if room_total < 1e-10:
                continue
            add = add * min(1.0, room_total / max(add.sum(), 1e-10))
            h[start:end] = new_src
            h[t_start:t_end] = np.clip(dst_vals + add, 0, 1)
            h = project_feasible(h, n)
            c_raw_test = np.correlate(h, 1 - h, mode='full')
            if c_raw_test.max() < best_c_raw - 1e-12:
                best_c_raw = c_raw_test.max()
                best_h = h.copy()
                c_raw = c_raw_test
            else:
                h[start:end] = src_vals
                h[t_start:t_end] = dst_vals
    
    return best_h, best_c_raw * dx

def run(seed=42, budget_s=1100, **kwargs):
    t0 = time.time()
    np.random.seed(seed)
    deadline = t0 + budget_s - 3
    
    try:
        h_init = np.array(initial_h_values, dtype=float).copy()
        n_init = len(h_init)
    except Exception:
        h_init = np.full(500, 0.5)
        n_init = 500
    
    best_h = project_feasible(h_init, n_init)
    best_c = compute_c5(best_h, n_init)
    
    # Phase 1: Quick gradient to polish initial (30s)
    grad_deadline = t0 + min(30, (deadline - t0) * 0.15)
    h_g, c_g = gradient_smooth_max(best_h, n_init, 500, grad_deadline, lr=1.5, momentum=0.92)
    if c_g < best_c:
        best_c = c_g
        best_h = h_g
    
    # Phase 2: Fast local search - main optimization (majority of time)
    ls_deadline = grad_deadline + min(200, (deadline - grad_deadline) * 0.5)
    h_ls, c_ls = fast_local_search(best_h, n_init, ls_deadline, max_rounds=200000)
    if c_ls < best_c:
        best_c = c_ls
        best_h = h_ls
    
    # Phase 3: SLSQP polish on top lags
    if time.time() < deadline - 60:
        slq_deadline = time.time() + min(40, (deadline - time.time()) * 0.2)
        h_s = slsqp_top_lags(best_h, n_init, top_m=5, maxiter=2000)
        c_s = compute_c5(h_s, n_init)
        if c_s < best_c:
            best_c = c_s
            best_h = h_s
        # Another SLSQP with different top_m
        if time.time() < deadline - 40:
            h_s = slsqp_top_lags(best_h, n_init, top_m=8, maxiter=2000)
            c_s = compute_c5(h_s, n_init)
            if c_s < best_c:
                best_c = c_s
                best_h = h_s
    
    # Phase 4: More fast local search
    if time.time() < deadline - 30:
        ls2_deadline = min(deadline - 10, time.time() + (deadline - time.time()) * 0.4)
        h_ls2, c_ls2 = fast_local_search(best_h, n_init, ls2_deadline, max_rounds=100000)
        if c_ls2 < best_c:
            best_c = c_ls2
            best_h = h_ls2
    
    # Phase 5: Try different resolutions
    n_alternatives = [400, 550, 600, 450]
    for n_alt in n_alternatives:
        if time.time() > deadline - 50:
            break
        remaining = deadline - time.time() - 10
        if remaining < 30:
            break
        # Interpolate to new resolution
        x_old = np.linspace(0, 2, len(best_h))
        x_new = np.linspace(0, 2, n_alt)
        h_alt = np.interp(x_new, x_old, best_h)
        h_alt = project_feasible(h_alt, n_alt)
        
        alloc = min(40, remaining * 0.3)
        if alloc < 15:
            break
        
        # Quick gradient
        h_a, c_a = gradient_smooth_max(h_alt, n_alt, 300, time.time() + alloc * 0.4)
        if c_a < best_c:
            best_c = c_a
            best_h = h_a
        
        # Fast local search
        h_a2, c_a2 = fast_local_search(h_a, n_alt, time.time() + alloc * 0.9, max_rounds=50000)
        if c_a2 < best_c:
            best_c = c_a2
            best_h = h_a2
    
    # Phase 6: Block perturbation to escape local optima
    if time.time() < deadline - 15:
        rng = np.random.RandomState(seed + 100)
        n_best = len(best_h)
        h_bp, c_bp = block_perturb_search(best_h, n_best, min(deadline - 5, time.time() + 20), rng)
        if c_bp < best_c:
            best_c = c_bp
            best_h = h_bp
            # Follow up with local search
            if time.time() < deadline - 5:
                h_ls3, c_ls3 = fast_local_search(best_h, n_best, deadline - 2, max_rounds=50000)
                if c_ls3 < best_c:
                    best_c = c_ls3
                    best_h = h_ls3
    
    # Phase 7: Final fast local search polish
    if time.time() < deadline - 2:
        n_best = len(best_h)
        h_final, c_final = fast_local_search(best_h, n_best, deadline - 1, max_rounds=100000)
        if c_final < best_c:
            best_c = c_final
            best_h = h_final
    
    # Ensure feasibility
    best_h = project_feasible(best_h, len(best_h))
    best_c = compute_c5(best_h, len(best_h))
    
    return best_h, best_c, len(best_h)
