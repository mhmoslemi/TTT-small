## 1. Approach and Rationale

The core idea is to use **deterministic search and gradient-based optimization on the positive grid** rather than continuous representations. While previous approaches discretized the continuous domain, we go further by:

- **Exploiting the periodic structure**: The function is defined on [0,2] with potential benefit from periodicity (even though periodicity isn't required by the problem, it reduces decision space)
- **Partitioned representation**: Breaking the domain into segments and ensuring strict feasibility at each step
- **Curriculum optimization**: Starting from coarse grids and refining towards finer resolutions while maintaining the best valid candidates
- **Projection-based repair**: Ensuring all points follow [0,1] bounds and maintain integral constraint (sumerivative to the parent's projection method but more robust)
- **Hybrid local-global search**: Combining simulated annealing with very limited L-BFGS-B refinement

This approach more thoroughly explores discrete and grid-based structures that often perform better than continuous relaxations. The main advantage is that it guarantees feasibility internally while allowing for systematic search across resolutions. Key limitations include being grid-based (may miss optimal continuous solutions) and requiring careful projection to maintain the integral constraint.

## 2. Mathematical Specification

### Representation:
$$
h: \mathbb{R} \to [0,1], \quad h(x+2) \quad \text{not necessarily defined} \\
\boxed{ \text{Smooth function} }
$$

*Representation options*:
- Option A (Default): Discretized grid $n$ points, 0 ≤ h[i] ≤ 1 with ∑h[i] = n/2
- Option B: Two-periodic extension $h(x+2)=h(x)$, suitable for [0,2] with repetition

### Objective:
$$
\boxed{C = \max_{k \in \mathbb{Z},\ ||k||\_{\infty} < 4} \int_{0}^{2} h(x)(1-h(x+k))dx}
$$

### Constraint handling:
$$
\boxed{0 \leq h(x) \leq 1}, \quad \int h(x)dx = 1
$$

*Projection method*:
For any solution $s$:
$$
\text{target} = \frac{n}{2}, \quad h_{proj}[i] = \text{clip}(s[i], 0, 1) + (\text{target} - \sum \text{clip}(s,0,1))
$$

### Metric:
$$
\boxed{\text{Overlap integral} = \max_{k} \frac{1}{\Delta x} \sum_{i} h[i](1-h[i+k]) \Delta x}
$$

*Dimensions*:
- $n$: Number of grid points (500-1000 recommendations)
- $\Delta x = 2/n$: Grid spacing
- $k$: Shift index (integer in [-n+1, n-1])

```python
        remaining = deadline - time.time()
        if remaining < 0 or remaining < 30:
            continue
            
        # Reset projection level but keep best solution
        h_cur = best_h.copy()
        start_time = time.time()
        iterations = 0
        max_iter = maxiter if remaining > maxiter else int(remaining)
        
        for it in range(max_iter):
            h_cur = optimize_projected(h_cur, n, alpha, mu, decay[0]*(it/max_iter+0.1))
            iterations += 1
            
            if iterations % 20 == 0:
                s_cur = compute_c5(h_cur, n)
                if s_cur < best_score:
                    best_score = s_cur
                    best_h = h_cur.copy()
                    
            time_used = time.time() - start_time
            if time_used > remaining - 5:
                break
                
        time_used = time.time() - start_time
        if time_used > remaining - 5:
            break
            
    return best_h, best_score
```

```python
def compute_c5_vec(h, n):
    dx = 2.0 / n
    if len(h) < n:
        h = np.pad(h, [0, n-len(h)], 'mean')
    correlation = np.correlate(h, 1-h, mode='full')

def compute_c5(h, n):
```
