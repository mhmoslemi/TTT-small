- k < 0 (kk=-k): ∂c_k/∂h[i] = (1-h[i-kk]) * [i≥kk] - h[i+kk] * [i≤n-1-kk]

So g[i] = Σ_{k∈A, k≥0} [(1-h[i+k])*[i+k<n] - h[i-k]*[i≥k]] + Σ_{k∈A, k<0, kk=-k} [(1-h[i-kk])*[i≥kk] - h[i+kk]*[i≤n-1-kk]]

This can be computed in O(n * |A|) naively, but with the structure it's O(n * |A|) where |A| is the number of active shifts.

If |A| ≈ 20 (say), then O(20 * 500) = O(10000) to compute g. That's fast.

Actually, I can compute g more efficiently by noting that for each active shift k, the contribution to g is a "shifted" version of (1-h) minus a "shifted" version of h. So:

g[i] += (1-h[i+k]) for i = 0..n-1-k (from the first term of positive shifts)
g[i] -= h[i-k] for i = k..n-1 (from the second term)

This is just array operations! For a given k:
g[0:n-k] += (1-h[k:n])
g[k:n] -= h[0:n-k]

For negative shift kk:
g[kk:n] += (1-h[0:n-kk])
g[0:n-kk] -= h[kk:n]

So computing g for all active shifts is O(n * |A|) with simple array operations. Very fast!

def compute_c5_vec(h, n):
    dx = 2.0 / n
    return np.correlate(h, 1.0 - h, mode='full') * dx

def compute_c5(h, n):
    return float(compute_c5_vec(h, n).max())

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h.copy(), 0.0, 1.0)
    for _ in range(3000):
        diff = target - h.sum()
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            room = 1.0 - h
            tot = room.sum()
            if tot < 1e-15:
                break
            h += (diff / tot) * room
        else:
            tot = h.sum()
            if tot < 1e-15:
                break
            h += (diff / tot) * h
    return np.clip(h, 0.0, 1.0)

def compute_smooth_max(h, n, alpha):
    c = compute_c5_vec(h, n)
    m = c.max()
    sh = alpha * (c - m)

        smx = sh.max()

        w = np.exp(sh - smx)
    else:
