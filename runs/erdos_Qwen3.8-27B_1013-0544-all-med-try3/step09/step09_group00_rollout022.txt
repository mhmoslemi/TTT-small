- Or at a boundary (δ = lo or δ = hi)

2. The function f(δ) = max_k (c[k] + b_k * δ) 
3. Find the δ that minimizes f over [lo, hi]

To find the minimum: the subgradient of f at δ is the set {b_k : k is active at δ}. The minimum is where 0 ∈ subgradient, i.e., there exist active k with b_k > 0 and b_k < 0 (or b_k = 0 for some active k).

In 1D, the minimum of a convex piecewise linear function occurs at a "kink point" or at a boundary. The kink points are where two lines c[i] + b_i*δ = c[j] + b_j*δ intersect AND both are on the upper envelope.

A practical algorithm:
1. Evaluate f at lo, hi, and maybe the midpoint
2. Use the fact that f is convex to narrow down
3. At the optimal point, the active set has lines with both positive and negative slopes (or zero slope)

Let me use a simpler approach: **binary search on the subgradient**.

At δ, the subgradient is {b_k : c[k] + b_k*δ = f(δ)}. 
- If all b_k > 0 for active k, move δ down (decrease δ)
- If all b_k < 0 for active k, move δ up (increase δ)
- If there's a mix, we're at the minimum (or very close)

This is equivalent to: find δ such that the active set contains lines with both positive and negative slopes.

1. Start with δ₀ = 0 (or the current pair direction)
2. Evaluate f(δ₀) and find active set A
3. If max(b_k for k in A) < 0: δ is too high, decrease
   If min(b_k for k in A) > 0: δ is too low, increase
   Otherwise: done
4. Use bisection to find the optimal δ

import numpy as np

def compute_c5_vec(h, n):
    dx = 2.0 / n
    return np.correlate(h, 1.0 - h, mode='full') * dx

def compute_c5(h, n):
    return float(compute_c5_vec(h, n).max())

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h.copy(), 0.0, 1.0)
    for _ in range(5000):
        diff = target - h.sum()
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            room = 1.0 - h
            tot = room.sum()
            if tot < 1e-15:
                break
            h += (diff / tot) * room
        else:
            tot = h.sum()
            if tot < 1e-15:
                break
            h += (diff / tot) * h
    return np.clip(h, 0.0, 1.0)

def compute_c5_obj(x, n, alpha, mu):
    c = compute_c5_vec(x, n)
    m = c.max()
    sh = alpha * (c - m)
    smx = sh.max()
    if smx > 400:
        val = m + (smx + np.log(np.sum(np.exp(sh - smx)))) / alpha
    else:
        val = m + np.log(np.sum(np.exp(sh))) / alpha
    if mu > 0:
        val += mu * (x.sum() - n / 2.0) ** 2
    return float(val)

def compute_c5_grad(x, n, alpha, mu):
    c = compute_c5_vec(x, n)
    m = c.max()
    sh = alpha * (c - m)
    smx = sh.max()
    w = np.exp(sh - smx)
    w /= w.sum()
    dx = 2.0 / n
    grad = np.zeros(n)
    for mm in range(len(c)):
        if w[mm] < 1e-14:
            continue
        k = mm - (n - 1)
        wm = w[mm] * dx
        if k >= 0:
            nv = n - k
            grad[0:nv] += wm * (1.0 - x[k:n])
            grad[k:n] += wm * (-x[0:nv])
        else:
            kk = -k
            nv = n - kk
            grad[kk:n] += wm * (1.0 - x[0:nv])
            grad[0:nv] += wm * (-x[kk:n])
    if mu > 0:

    return grad
