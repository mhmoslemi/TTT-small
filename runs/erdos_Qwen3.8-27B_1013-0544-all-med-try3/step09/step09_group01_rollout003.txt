    y = h.copy()

Actually, I realize I should also try a completely different approach: **coordinate descent with restarts**.

For coordinate descent:
- Fix all variables except h[i]
- Optimize h[i] to minimize the max overlap
- This is a 1D problem that can be solved exactly

For a fixed h[i] = t (0 ≤ t ≤ 1), the overlap at shift k is:
- If i is in the "first" part: c_k += t * (1-h[i+k]) * dx
- If i is in the "second" part: c_k += (1-t) * h[i-k] * dx

So changing h[i] from old value to new value t affects multiple c_k values. The objective is max_k c_k, and we want to find t that minimizes this max.

This is a piecewise-linear function of t (each c_k is linear in t), so the minimum of the max is at a breakpoint. We can find it by:
1. Computing all affected c_k values at t=0 and t=1
2. Finding the t where the two "most constrained" c_k values equalize

This is O(n) per coordinate, O(n²) per full pass. For n=500, that's 250k per pass, doable in a few seconds for many passes.
