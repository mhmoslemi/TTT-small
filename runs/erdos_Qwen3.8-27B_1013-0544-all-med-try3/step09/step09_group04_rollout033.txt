```python
def softmin_obj(h, n, alpha):
    c = compute_c5_vec(h, n)
    m = c.max()
    shifted = alpha * (c - m)
    # For numerical stability
    max_shifted = shifted.max()
    if max_shifted > 500:
        logsum = max_shifted + np.log(np.sum(np.exp(shifted - max_shifted)))
    else:
        logsum = np.log(np.sum(np.exp(shifted)))
    return m + logsum / alpha

def softmin_grad(h, n, alpha):
    c = compute_c5_vec(h, n)
    m = c.max()
    shifted = alpha * (c - m)
    max_shifted = shifted.max()
    w = np.exp(shifted - max_shifted)
    w /= w.sum()
    # Weighted sum of gradients of c_k
    dx = 2.0 / n
    grad = np.zeros(n)
    for idx in range(len(w)):
        if w[idx] < 1e-15:
            continue
        k = idx - (n - 1)  # actual lag
        wm = w[idx] * dx
        if k >= 0:
            nv = n - k
            grad[0:nv] += wm * (1.0 - h[k:n])
            grad[k:n] += wm * (-h[0:nv])
        else:
            kk = -k
            nv = n - kk
            grad[kk:n] += wm * (1.0 - h[0:nv])
            grad[0:nv] += wm * (-h[kk:n])
    return grad
```

But actually, I can vectorize it more. For a given lag $k \geq 0$:
$\frac{\partial c_k}{\partial h[j]} = (1-h[j+k]) \cdot \mathbf{1}_{j < n-k} - h[j-k] \cdot \mathbf{1}_{j \geq k}$

So the gradient contribution from lag $k$ is:
- Add $wm \cdot (1-h[k:])$ to positions $0$ to $n-k-1$
- Add $wm \cdot (-h[:n-k])$ to positions $k$ to $n-1$

This is what the code does. The total cost over all lags is $O(n^2)$ since there are $O(n)$ lags and each takes $O(n)$.

For the full correlation $c_k$ (k from 0 to 2n-2), the gradient $\partial c_k / \partial h$ has a specific structure. Let me think...

For lag $s = k - (n-1)$:
- If $s \geq 0$: $\partial c_k / \partial h[j] = (1-h[j+s]) \cdot \mathbf{1}_{j \leq n-1-s} - h[j-s] \cdot \mathbf{1}_{j \geq s}$
- If $s < 0$ (let $t = -s$): $\partial c_k / \partial h[j] = (1-h[j-t]) \cdot \mathbf{1}_{j \geq t} - h[j+t] \cdot \mathbf{1}_{j \leq n-1-t}$

$\text{grad}[j] = \sum_k w_k \cdot dx \cdot \frac{\partial c_k}{\partial h[j]}$

$= dx \cdot \sum_{s \geq 0} w_{s+n-1} [(1-h[j+s]) \cdot \mathbf{1}_{j \leq n-1-s} - h[j-s] \cdot \mathbf{1}_{j \geq s}] + dx \cdot \sum_{t > 0} w_{n-1-t} [(1-h[j-t]) \cdot \mathbf{1}_{j \geq t} - h[j+t] \cdot \mathbf{1}_{j \leq n-1-t}]$
