            if tot < 1e-15:

2. For each a (one-position), compute Δf_a(k*) - this is O(1) per a
3. Sort a's by Δf_a(k*) (most negative first)
4. For each b (zero-position), compute Δf_b(k*) - O(1) per b
5. Sort b's by Δf_b(k*)
6. Try the top few (a,b) combinations (e.g., top 10 a's × top 10 b's = 100 candidates)
7. For each candidate, compute the full new overlap and check if max decreased
8. Accept the best

The raw correlation (before multiplying by dx) is:
corr[idx] = ∑_{i: 0≤i<n, 0≤i+idx-(n-1)<n} h[i] · (1-h[i+idx-(n-1)])

Let k = idx - (n-1). Then:
corr[n-1+k] = ∑_{i: 0≤i<n, 0≤i+k<n} h[i] · (1-h[i+k])

When h[p] changes by δ (δ = -1 for 1→0, δ = +1 for 0→1):
New corr[n-1+k] = corr[n-1+k] + δ · [contribution of position p]

The contribution of position p to corr[n-1+k]:
- As the "first" element (i=p): h[p]·(1-h[p+k]) if 0≤p+k<n
  Change: δ · (1-h[p+k]) (before the change, h[p] was its old value)
  Wait, this is tricky. Let's say h[p] changes from h[p]_old to h[p]_old + δ.
  The term i=p: was h[p]_old · (1-h[p+k]), now (h[p]_old+δ)·(1-h[p+k])
  Change: δ·(1-h[p+k])
  
- As the "second" element (i+k=p, i=p-k): h[p-k]·(1-h[p]) if 0≤p-k<n
  Was: h[p-k]·(1-h[p]_old), now: h[p-k]·(1-h[p]_old-δ)
  Change: -δ·h[p-k]

So the total change at shift k when h[p] changes by δ:
Δ(k) = δ·(1-h[p+k])·[0≤p+k<n] - δ·h[p-k]·[0≤p-k<n]
      = δ · [(1-h[p+k])·[0≤p+k<n] - h[p-k]·[0≤p-k<n]]

For δ = -1 (1→0):
Δ(k) = -[(1-h[p+k])·[0≤p+k<n] - h[p-k]·[0≤p-k<n]]
      = h[p-k]·[0≤p-k<n] - (1-h[p+k])·[0≤p+k<n]

For δ = +1 (0→1):
Δ(k) = (1-h[p+k])·[0≤p+k<n] - h[p-k]·[0≤p-k<n]

This makes sense:
- When h[p] goes 1→0: we lose the contribution of p as a "first" element (reducing overlap where p+k is 0) and gain the contribution of p as a "second" element (increasing overlap where p-k is 1).
- When h[p] goes 0→1: the opposite.

Great. Now for a pair (a: 1→0, b: 0→1):
Δ_total(k) = Δ_a(k) + Δ_b(k) where:
Δ_a(k) = h[a-k]·[0≤a-k<n] - (1-h[a+k])·[0≤a+k<n]
Δ_b(k) = (1-h[b+k])·[0≤b+k<n> - h[b-k]·[0≤b-k<n]

And the new correlation is: corr + Δ_total
New max = max(corr + Δ_total) · dx
