Let me now think about the **subgradient method** in detail:

Given h, compute C_k for all k. Let k* be the argmax.
The subgradient of C(h) at h is: ∇C_{k*}(h) (or any convex combination of active gradients).

Step: h_new = h - step_size * ∇C_{k*}(h)
Then project h_new back to the feasible set.

The step size can be chosen by:
- Barzilai-Borwein
- Backtracking line search
- Fixed decreasing schedule

The key advantage: this directly attacks the worst correlation, which is what we care about.

**Efficient subgradient computation:**
∂C_k/∂h[i] = dx * (1-h[i+k] - h[i-k]) (with appropriate bounds)

This can be computed as:
grad[i] = dx * ((1-h[i+k] if i+k < n else 0) - (h[i-k] if i-k >= 0 else 0))

For the active set (multiple k's with C_k close to max), we average the gradients.

**Implementation detail**: We can compute the gradient for all lags simultaneously using FFT, but for simplicity, we'll just compute it for the top few lags.

Now let me also think about **binary local search** more carefully:

Given a binary h (n/2 ones, n/2 zeros), the objective is:
C(h) = max_k C_k(h) where C_k = |{i : h[i]=1, h[i+k]=0}|

To flip bit i from 1 to 0:
- For each k, C_k changes by: -1 if h[i+k]=0 (we remove a 1→0 pair at lag k)
  +1 if h[i-k]=1 (we add a 1→0 pair at lag k... wait)

Let me think more carefully. If we flip h[i] from 1 to 0:
- For lag k > 0: 
  - Pair (i, i+k): was h[i]=1, h[i+k]=?. If h[i+k]=0, we LOST a contribution to C_k. C_k decreases by 1.
  - Pair (i-k, i): was h[i-k]=?, h[i]=1. If h[i-k]=1, we had a contribution h[i-k]=(1-h[i]) = 0, so no contribution. After flip, h[i]=0, so h[i-k]*(1-h[i]) = h[i-k]*1. If h[i-k]=1, we GAINED a contribution. C_k increases by 1.
  
  Wait, I need to be more careful. C_k = ∑_j h[j]*(1-h[j+k]).
  
  If we flip h[i] from 1 to 0:
  - Term j=i: was h[i]*(1-h[i+k]) = 1*(1-h[i+k]). Now it's 0*(1-h[i+k]) = 0. Change: -(1-h[i+k]).
  - Term j=i-k: was h[i-k]*(1-h[i]) = h[i-k]*(1-1) = 0. Now it's h[i-k]*(1-0) = h[i-k]. Change: +h[i-k].
  
  So ΔC_k = -(1-h[i+k]) + h[i-k] (with appropriate boundary conditions)
  = h[i+k] - 1 + h[i-k] (for k > 0, assuming 0 ≤ i-k < n and 0 ≤ i+k < n)

For binary h: ΔC_k = h[i+k] - 1 + h[i-k] ∈ {-2, -1, 0, 1}

Similarly, flipping h[i] from 0 to 1:
  - Term j=i: was 0. Now 1*(1-h[i+k]) = 1-h[i+k]. Change: +(1-h[i+k]).
  - Term j=i-k: was h[i-k]*(1-0) = h[i-k]. Now h[i-k]*(1-1) = 0. Change: -h[i-k].
  
  ΔC_k = (1-h[i+k]) - h[i-k]

So for binary h, we can compute the effect of flipping any bit on all lags in O(n) time.

**Efficient binary local search:**
1. Precompute C_k for all k
2. For each bit i, compute ΔC_k for all k (O(n) work)
3. The new max is max_k(C_k + ΔC_k)
4. If new max < current max, accept the flip
5. Repeat until no improving flip is found

This is O(n²) per full pass, and we might need many passes. For n=500, that's 250K per pass, very fast.

But we need to maintain the sum constraint: if we flip a 1 to 0, we need to flip a 0 to 1 somewhere else. So it's really a "swap" operation: move a 1 from position i to position j.

For a swap (move 1 from i to j):
- Effect on C_k: ΔC_k = (effect of removing 1 at i) + (effect of adding 1 at j)

This is still O(n) per swap candidate.

**Simulated annealing on binary assignments:**
- Temperature schedule: start high, decrease geometrically
- Move: swap two bits (1 at i → 0, 0 at j → 1)
- Accept if max correlation decreases, or with probability exp(Δ/T) if it increases

This should be able to escape local minima.

import numpy as np

import time

def compute_c5_vec(h, n):
    dx = 2.0 / n
    return np.correlate(h, 1 - h, mode='full') * dx

def compute_c5(h, n):
    return float(np.max(compute_c5_vec(h, n)))

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h.copy(), 0.0, 1.0)
    for _ in range(5000):
        diff = target - h.sum()
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            room = 1.0 - h
            tot = room.sum()
            if tot < 1e-15:
                break
            h += (diff / tot) * room
        else:
            tot = h.sum()
            if tot < 1e-15:
                break
            h += (diff / tot) * h
    return np.clip(h, 0.0, 1.0)

def logsumexp_obj(x, n, alpha, mu):
    c = compute_c5_vec(x, n)
    m = c.max()
    shifted = alpha * (c - m)
    mx = shifted.max()
    if mx > 20:
        val = m + (mx + np.log(np.sum(np.exp(shifted - mx)))) / alpha
    else:
        val = m + np.log(np.sum(np.exp(shifted))) / alpha
    val += mu * (x.sum() - n / 2.0) ** 2
    return float(val)

def logsumexp_grad(x, n, alpha, mu):
    c = compute_c5_vec(x, n)
    m = c.max()
    shifted = alpha * (c - m)
    mx = shifted.max()
    w = np.exp(shifted - mx)
    w /= w.sum()
    dx = 2.0 / n
    grad = np.zeros(n)
    ncorr = 2 * n - 1
    center = n - 1
    for idx in range(ncorr):
        if w[idx] < 1e-12:
            continue
        k = idx - center
        wm = w[idx] * dx
        if k >= 0:
            nv = n - k
            if nv > 0:
                grad[0:nv] += wm * (1.0 - x[k:n])
                grad[k:n] += wm * (-x[0:nv])
        else:
            kk = -k
            nv = n - kk
            if nv > 0:
                grad[kk:n] += wm * (1.0 - x[0:nv])
                grad[0:nv] += wm * (-x[kk:n])
    grad += 2.0 * mu * (x.sum() - n / 2.0)
    return grad

def subgradient_step(h, n, n_active=5, step_scale=0.01):
    """Take a step in the negative subgradient direction of the max correlation."""
    c_vec = compute_c5_vec(h, n)
    c_max = c_vec.max()
    # Find active lags (within 1% of max)
    threshold = c_max - 0.01 * c_max
    active = np.where(c_vec >= threshold)[0]
    if len(active) > n_active:
        active = active[:n_active]  # Take top n_active
    
    dx = 2.0 / n
    ncorr = 2 * n - 1
    center = n - 1
    grad = np.zeros(n)
    
    for idx in active:
        k = idx - center
        if k >= 0:
            nv = n - k
            if nv > 0:
                grad[0:nv] += dx * (1.0 - h[k:n])
                grad[k:n] += dx * (-h[0:nv])
        else:
            kk = -k
            nv = n - kk
            if nv > 0:
                grad[kk:n] += dx * (1.0 - h[0:nv])
                grad[0:nv] += dx * (-h[kk:n])
    
    # Normalize gradient
    gnorm = np.linalg.norm(grad)
    if gnorm < 1e-15:
        return h.copy()
    
    # Step size: use a simple schedule
    step = step_scale / (np.sqrt(c_max + 1e-10))
    h_new = h - step * grad / gnorm
    
    # Project onto feasible set
    h_new = project_feasible(h_new, n)
    
    # Also enforce bounds
    h_new = np.clip(h_new, 0, 1)
    h_new = project_feasible(h_new, n)
    
    return h_new

def binary_simulated_annealing(h, n, deadline, t_max=1.0, t_min=0.001, cooling=0.995):
    """Simulated annealing on binary patterns."""
    order = np.argsort(-h)
    h_cur = np.zeros(n)
    h_cur[order[:n//2]] = 1.0
    
    c_cur = compute_c5(h_cur, n)
    best_h = h_cur.copy()
    best_c = c_cur
    
    T = t_max
    rng = np.random.RandomState(777)
    
    while T > t_min and time.time() < deadline:
        ones = np.where(h_cur == 1)[0]
        zeros = np.where(h_cur == 0)[0]
        i = rng.choice(ones)
        j = rng.choice(zeros)
        
        h_new = h_cur.copy()
        h_new[i] = 0
        h_new[j] = 1
        c_new = compute_c5(h_new, n)
        
        delta = c_new - c_cur
        if delta < 0 or rng.random() < np.exp(-delta / T):
            h_cur = h_new
            c_cur = c_new
            if c_cur < best_c:
                best_c = c_cur
                best_h = h_cur.copy()
        
        T *= cooling
    
    return best_h, best_c

def slqp_optimize(h, n, deadline, alpha=500000, maxiter=2000):
    """SLSQP optimization."""
    def obj_fn(x, na, al):
        c = compute_c5_vec(x, na)
        m = c.max()
        sh = al * (c - m)
        mx = sh.max()
        if mx > 20:
            return float(m + (mx + np.log(np.sum(np.exp(sh - mx)))) / al)
        else:
            return float(m + np.log(np.sum(np.exp(sh))) / al)
    
    def sq_fn(x, na):
        return float(x.sum() - na / 2.0)
    
    def sq_jac_fn(x, na):
        return np.ones(na)
    
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': sq_fn, 'jac': sq_jac_fn, 'args': (n,)}]
    try:
        res = minimize(obj_fn, h, args=(n, alpha), method='SLSQP',
                      bounds=bounds, constraints=cons,
                      options={'maxiter': maxiter, 'ftol': 1e-16, 'iprint': 0})
        if res is not None and hasattr(res, 'x'):
            h_new = project_feasible(res.x, n)
            c_new = compute_c5(h_new, n)
            return h_new, c_new
    except Exception:
        pass
    return h.copy(), compute_c5(h, n)

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5_vec(h, n):
    dx = 2.0 / n
    return np.correlate(h, 1 - h, mode='full') * dx

def compute_c5(h, n):
    return float(np.max(compute_c5_vec(h, n)))

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h.copy(), 0.0, 1.0)
    for _ in range(5000):
        diff = target - h.sum()
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            room = 1.0 - h
            tot = room.sum()
            if tot < 1e-15:
                break
            h += (diff / tot) * room
        else:
            tot = h.sum()
            if tot < 1e-15:
                break
            h += (diff / tot) * h
    return np.clip(h, 0.0, 1.0)

def lse_obj(x, n, alpha, mu):
    c = compute_c5_vec(x, n)
    m = c.max()
    sh = alpha * (c - m)
    mx = sh.max()
    if mx > 20:
        val = m + (mx + np.log(np.sum(np.exp(sh - mx)))) / alpha
    else:
        val = m + np.log(np.sum(np.exp(sh))) / alpha
    val += mu * (x.sum() - n / 2.0) ** 2
    return float(val)

def lse_grad(x, n, alpha, mu):
    c = compute_c5_vec(x, n)
    m = c.max()
    sh = alpha * (c - m)
    mx = sh.max()
    w = np.exp(sh - mx)
    w /= w.sum()
    dx = 2.0 / n
    grad = np.zeros(n)
    ncorr = 2 * n - 1
    center = n - 1
    for idx in range(ncorr):
        if w[idx] < 1e-12:
            continue
        k = idx - center
        wm = w[idx] * dx
        if k >= 0:
            nv = n - k
            if nv > 0:
                grad[0:nv] += wm * (1.0 - x[k:n])
                grad[k:n] += wm * (-x[0:nv])
        else:
            kk = -k
            nv = n - kk
            if nv > 0:
                grad[kk:n] += wm * (1.0 - x[0:nv])
                grad[0:nv] += wm * (-x[kk:n])
    grad += 2.0 * mu * (x.sum() - n / 2.0)
    return grad

def subgradient_step(h, n, n_active=8, step_scale=0.015):
    c_vec = compute_c5_vec(h, n)
    c_max = c_vec.max()
    if c_max < 1e-10:
        return h.copy()
    threshold = c_max - 0.02 * c_max
    active = np.where(c_vec >= threshold)[0]
    if len(active) > n_active:
        active = active[np.argsort(-c_vec[active])[:n_active]]
    dx = 2.0 / n
    center = n - 1
    grad = np.zeros(n)
    for idx in active:
        k = idx - center
        if k >= 0:
            nv = n - k
            if nv > 0:
                grad[0:nv] += dx * (1.0 - h[k:n])
                grad[k:n] += dx * (-h[0:nv])
        else:
            kk = -k
            nv = n - kk
            if nv > 0:
                grad[kk:n] += dx * (1.0 - h[0:nv])
                grad[0:nv] += dx * (-h[kk:n])
    gnorm = np.linalg.norm(grad)
    if gnorm < 1e-15:
        return h.copy()
    step = step_scale
    h_new = h - step * grad / gnorm
    h_new = np.clip(h_new, 0.0, 1.0)
    h_new = project_feasible(h_new, n)
    return h_new

def subgradient_descent(h, n, deadline, n_iter=5000):
    best_h = h.copy()
    best_c = compute_c5(h, n)
    step_scale = 0.02
    stagnant = 0
    for it in range(n_iter):
        if time.time() > deadline:
            break
        h_new = subgradient_step(h, n, n_active=8, step_scale=step_scale)
        c_new = compute_c5(h_new, n)
        if c_new < best_c - 1e-12:
            best_c = c_new
            best_h = h_new.copy()
            stagnant = 0
            step_scale = min(0.08, step_scale * 1.02)
        else:
            stagnant += 1
            if stagnant > 50:
                step_scale = max(0.003, step_scale * 0.9)
                h_new = h + 0.005 * np.random.randn(n)
                h_new = project_feasible(h_new, n)
                c_new = compute_c5(h_new, n)
                if c_new < best_c:
                    best_c = c_new
                    best_h = h_new.copy()
                stagnant = 0
            if stagnant > 200:
                break
        h = h_new
    return best_h, best_c

    if alpha_list is None:
        alpha_list = [200, 1000, 5000, 20000, 100000, 500000, 2000000]

        mu_list = [50, 500, 2000, 10000, 50000, 200000, 1000000]
    best_h = h.copy()

            h_new = project_feasible(res.x, n)

def slqp_optimize(h, n, deadline, alpha=500000, maxiter=2000):
    def _obj(x, na, al):
        c = compute_c5_vec(x, na)
        m = c.max()
        sh = al * (c - m)
        mx = sh.max()
        if mx > 20:
            return float(m + (mx + np.log(np.sum(np.exp(sh - mx)))) / al)
        return float(m + np.log(np.sum(np.exp(sh))) / al)
    def _sq(x, na):
        return float(x.sum() - na / 2.0)
    def _sqj(x, na):
        return np.ones(na)
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': _sq, 'jac': _sqj, 'args': (n,)}]
    try:
        res = minimize(_obj, h, args=(n, alpha), method='SLSQP',
                      bounds=bounds, constraints=cons,
                      options={'maxiter': maxiter, 'ftol': 1e-16, 'iprint': 0})
        if res is not None and hasattr(res, 'x'):
            h_new = project_feasible(res.x, n)
            c_new = compute_c5(h_new, n)
            return h_new, c_new
    except Exception:
        pass
    return h.copy(), compute_c5(h, n)

def binary_local_search(h, n, deadline, max_passes=150):

def binary_anneal(h, n, deadline, t_max=0.5, t_min=0.005, cooling=0.997):
    order = np.argsort(-h)
    h_cur = np.zeros(n)
    h_cur[order[:n // 2]] = 1.0
    c_cur = compute_c5(h_cur, n)
    best_h = h_cur.copy()
    best_c = c_cur
    T = t_max
    rng = np.random.RandomState(314)
    while T > t_min and time.time() < deadline:
        ones = np.where(h_cur == 1)[0]
        zeros = np.where(h_cur == 0)[0]
        if len(ones) == 0 or len(zeros) == 0:
            break
        i = rng.choice(ones)
        j = rng.choice(zeros)
        h_new = h_cur.copy()
        h_new[i] = 0
        h_new[j] = 1
        c_new = compute_c5(h_new, n)
        delta = c_new - c_cur
        if delta < 0 or rng.random() < np.exp(-delta / max(T, 1e-10)):
            h_cur = h_new
            c_cur = c_new
            if c_cur < best_c:
                best_c = c_cur
                best_h = h_cur.copy()
        T *= cooling
    return best_h, best_c
