- **Descent criterion**: -∇²C₅ < 0 for each component

---

### Detailed Formulation

**Objective Function**:
```math
C_5(h) = \sup_k \frac{1}{n} \left| \sum_{i=1}^n h_i (1 - h_{i+k}) \right| \quad \text{subject to} \quad \sum h_i = \frac{n}{2}, \, 0 \leq h_i \leq 1
```

**Projection Method**:
Define the feasible set:
```math
\mathcal{F} = \{ h \in \mathbb{R}^n : \sum h_i = \frac{n}{2}, \, 0 \leq h_i \leq 1 \}
```
The projection operator is given by:
```math
P(h) = h_0 + \frac{(\sum h_i) - \sum h_i^0}{n} \mathbf{1} + \min_{0 \leq \lambda_i \leq 1} \left( ||h_i - (h_{i, \text{clip}}) + \lambda_i (h_{i, \text{clip}} - h_i) ||_2^2 \right)
```

**Projection Method**:
```python
def project_to_feasibility(h, target_sum=1, dx=0.0333):
    """
    Projects vector to satisfying both sum and bounds constraints.
    """
    dx = 2.0 / len(h)
    target = target_sum / dx
    
    # Simplex projection
    h_unit = h / (np.sum(h) if np.sum(h) > 0 else 1)
    h_corrected = h_unit * target * dx
    
    # Clip bounds and reproject if needed
    if not np.all((0 <= h_corrected <= 1)):
        h_final = np.clip(h_corrected, 0, 1)
        deficit = target*dx - np.sum(h_final)*dx
        if deficit > 1e-6:
            # Add fractional adjustment to most extreme values
            diff = np.linspace(-0.5*(deficit/(target*dx-0)), 
                             0.5*(deficit/(target*dx-0)), len(h_final))
            h_final += diff * h_final.clip(0.5,0.5)  # Choosing representative points
        assert np.all((0 <= h_final <= 1)), "Feasibility preserved failed"
    return h_final
```
