    """Compute gradient of g_k(h) * dx where g_k is the k-th correlation value."""
    n = len(h)
    dx = 2.0 / n
    shift = k - (n - 1)

Let me think about what kind of optimization can achieve this level of precision.

For the subgradient method, the step size needs to be very small near the optimum. The convergence rate is O(1/√T) for the max of smooth functions, which is slow.

For coordinate descent, if the function is "nice" (locally quadratic), it can converge geometrically. But C₅ is the max of many quadratics, so it's piecewise quadratic. Near the optimum, the active set (which lags are binding) is fixed, and the function is quadratic. So coordinate descent should work well in the final phase.

The key insight: near the optimum, only a few lags are active (achieving the max). If we can identify these, we can do a more targeted optimization.

Let me try a different approach: **Identify active constraints, then solve a QP**

Near the optimum:
- C₅ = max_k g_k(h)
- Suppose lags k₁, ..., k_m are active (g_{k_i} = C₅)
- Then locally, C₅ = max(g_{k_1}, ..., g_{k_m})
- We want to minimize this max

This is equivalent to: minimize t subject to g_{k_i}(h) ≤ t for all i, which is a QCQP. Since each g_k is quadratic (specifically, a sum of bilinear terms), this is a non-convex QCQP.

But if we linearize the quadratic terms around the current point, we get a QP (or even an LP if we ignore the Hessian). This gives an approximate solution that we can use as a step.

Actually, let me think about this differently. The function g_k(h) = sum_i h[i+shift]*(1-h[i]) is bilinear. If we write it as:
g_k(h) = sum_i h[i+shift] - sum_i h[i+shift]*h[i]

The first term is linear. The second term is a sum of products of pairs. If we fix all variables except one (say h[j]), then:
g_k(h) = (linear in h[j]) - (linear in h[j]) * (fixed values)
= (a*h[j] + b) - (c*h[j] + d)
= (a-c)*h[j] + (b-d)

So for a single variable, g_k is linear! And C₅ = max_k (linear in h[j]) is the max of linear functions, which is convex. So coordinate descent is a convex optimization in each coordinate.

This means for coordinate j, the optimal value is at one of the breakpoints of the max of linear functions, or at the boundary (0 or 1).

The breakpoints occur where two of the linear functions cross. So there are at most O(n) breakpoints (one for each pair of active lags).

In practice, we can just do a ternary search or bisection on the 1D convex function.
