But here's a trick: for the max to decrease, ALL entries of new_corr must be ≤ current_max - δ for some δ > 0. This is equivalent to:
max(corr + C[i] - D[j]) ≤ current_max - δ
⟺ for all m: corr[m] + C[i][m] - D[j][m] ≤ current_max - δ
⟺ for all m: C[i][m] - D[j][m] ≤ current_max - δ - corr[m]
⟺ D[j][m] - C[i][m] ≥ corr[m] - current_max + δ for all m

Let R[m] = current_max - corr[m] (the "slack" at position m).
Then we need: D[j][m] - C[i][m] ≥ -R[m] + δ for all m.

This is a system of linear inequalities in (i,j). Still not easy to solve directly.

Let me just go with the straightforward approach but optimize it with numpy:

```python
def binary_local_search_fast(h_init, n, deadline, max_sweeps=2000, n_restarts=5, seed=42):
    target = n // 2
    idx = np.argsort(h_init)[::-1]
    h = np.zeros(n)
    h[idx[:target]] = 1.0
    dx = 2.0 / n
    
    best_c = np.inf
    best_h = h.copy()
    rng = np.random.RandomState(seed)
    
    for restart in range(n_restarts):
        if time.time() > deadline:
            break
        
        if restart > 0:
            for _ in range(rng.randint(5, 15)):
                oi = np.where(h == 1)[0]
                zi = np.where(h == 0)[0]
                a = rng.choice(oi)
                b = rng.choice(zi)
                h[a], h[b] = h[b], h[a]
        
        corr = np.correlate(h, 1-h, mode='full').astype(float)
        cur_max = corr.max()
        
        for sweep in range(max_sweeps):
            if time.time() > deadline:
                break
            
            zeros = np.where(h == 0)[0]
            ones = np.where(h == 1)[0]
            
            if len(zeros) == 0 or len(ones) == 0:
                break
            
            best_improve = 0
            best_i = -1
            best_j = -1
            
            # For each zero i, compute ci vector
            # ci[m] = (1-h[i-(m-(n-1))]) * 1[i<=m<=i+n-1] - h[i+(m-(n-1))] * 1[n-1-i<=m<=2n-2-i]
            
            for i in zeros:
                ci = np.zeros(2*n-1)
                # Positive part: (1-h[i-k]) for k valid, placed at m = n-1+k
                # i-k valid: 0 <= i-k < n => i-(n-1) <= k <= i
                # m = n-1+k: i <= m <= n-1+i
                m_lo = max(i, 0)
                m_hi = min(i+n-1, 2*n-2)
                ks = np.arange(m_lo, m_hi+1) - (n-1)  # k values
                idxs = i - ks  # i-k values
                valid = (idxs >= 0) & (idxs < n)
                ci[m_lo:m_hi+1][valid] = 1.0 - h[idxs[valid]]
                
                # Negative part: h[i+k] for k valid, placed at m = n-1+k
                # i+k valid: 0 <= i+k < n => -i <= k <= n-1-i
                # m = n-1+k: n-1-i <= m <= 2n-2-i
                m_lo2 = max(n-1-i, 0)
                m_hi2 = min(2*n-2-i, 2*n-2)
                ks2 = np.arange(m_lo2, m_hi2+1) - (n-1)
                idxs2 = i + ks2
                valid2 = (idxs2 >= 0) & (idxs2 < n)
                ci[m_lo2:m_hi2+1][valid2] -= h[idxs2[valid2]]
                
                # Now for each one j, compute new_max = max(corr + ci - cj)
                # To speed up, precompute the "base" = corr + ci
                base = corr + ci
                base_max = base.max()
                
                if base_max >= cur_max + 1e-10:
                    # Can't improve by setting i to 1 (regardless of j)
                    # Actually we still might, because cj could be large
                    # But if base_max is already > cur_max, we need cj to bring it down
                    # Let's still try
                    pass
                
                for j in ones:
                    # Compute cj
                    cj = np.zeros(2*n-1)
                    m_lo = max(j, 0)
                    m_hi = min(j+n-1, 2*n-2)
                    ks = np.arange(m_lo, m_hi+1) - (n-1)
                    idxs = j - ks
                    valid = (idxs >= 0) & (idxs < n)
                    cj[m_lo:m_hi+1][valid] = 1.0 - h[idxs[valid]]
                    
                    m_lo2 = max(n-1-j, 0)
                    m_hi2 = min(2*n-2-j, 2*n-2)
                    ks2 = np.arange(m_lo2, m_hi2+1) - (n-1)
                    idxs2 = j + ks2
                    valid2 = (idxs2 >= 0) & (idxs2 < n)
                    cj[m_lo2:m_hi2+1][valid2] -= h[idxs2[valid2]]
                    
                    new_corr = base - cj
                    new_max = new_corr.max()
                    improve = cur_max - new_max
                    if improve > best_improve:
                        best_improve = improve
                        best_i = i
                        best_j = j
                        
            if best_improve > 1e-10:
                # Make the swap
                h[best_i], h[best_j] = 1.0, 0.0
                corr = np.correlate(h, 1-h, mode='full').astype(float)
                cur_max = corr.max()
            elif best_improve > -1e-10:
                # No improvement, stop
                break
            else:
                break
        
        cur_c = cur_max * dx
        if cur_c < best_c:
            best_c = cur_c
            best_h = h.copy()
    
    return best_h, best_c
```

Wait, this is O(n³) per sweep (n zeros × n ones × n for the max). For n=250, that's 15.6M per sweep. In numpy with vectorized operations, maybe 0.1-0.5s per sweep. With 500 sweeps, 50-250s. OK.

# Precompute all change vectors
# ci[i] for i in zeros, cj[j] for j in ones

# Then new_corr[i,j] = corr + ci[i] - cj[j]
# new_max[i,j] = max(corr + ci[i] - cj[j])

# This is a matrix of shape (n_zeros, n_ones)
# new_max[i,j] = max_m (corr[m] + ci[i,m] - cj[j,m])

# We can compute this as:
# For each m, the contribution to new_max[i,j] is corr[m] + ci[i,m] - cj[j,m]
# new_max[i,j] = max_m (corr[m] + ci[i,m] - cj[j,m])

# This is the element-wise max over m of (corr[m] + ci[i,m] - cj[j,m])
# = max of (n_zeros × n_ones × (2n-1)) tensor

# In numpy:
# all_vals = corr[None, None, :] + ci[:, None, :] - cj[None, :, :]  # shape (nz, no, 2n-1)
# new_maxes = all_vals.max(axis=2)  # shape (nz, no)

# new_maxes has 125*125 = 15625 elements.

This is much better! The entire sweep can be done with a few large numpy operations:
1. Compute all_vals (62MB)
2. Take max along axis 2 (15625 elements)
3. Find argmin
4. Apply the best swap
