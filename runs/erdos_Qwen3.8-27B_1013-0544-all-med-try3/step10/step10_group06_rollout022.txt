Let me also add a **coordinate descent** phase: for each coordinate i, find the optimal value of h[i] given all other coordinates fixed. Since the objective is the max of bilinear terms, for a fixed i, the objective as a function of h[i] is the max of several linear functions (each bilinear term becomes linear in h[i] when all other variables are fixed). Wait, actually for a fixed i:
f_k(h) = ∑ h[n]*(1-h[n+k]) (for the relevant pairs)
As a function of h[i], this is:
- If i appears as the first factor: contribution is (1-h[j]) * h[i] for some j
- If i appears as the second factor: contribution is -h[j] * h[i] for some j
- If i appears in both: contribution is h[i] - h[i]*h[j] or h[i] - h[i]*h[i] = h[i](1-h[i])

So f_k as a function of h[i] is linear (or quadratic for lag=0). The max over k is the max of several linear (or quadratic) functions.

For lag ≠ 0, f_k is linear in h[i]:
f_k(h) = a_k * h[i] + b_k (for some a_k, b_k)

So the max is max_k (a_k * h[i] + b_k), which is a convex piecewise-linear function of h[i]. The minimum is at a kink point or at the boundary [0,1].

The kink points are where two different lags have the same value:
a_k1 * h[i] + b_k1 = a_k2 * h[i] + b_k2
h[i] = (b_k2 - b_k1) / (a_k1 - a_k2)

So for each coordinate i, I can:
1. Compute a_k and b_k for all lags k.
2. Find all kink points in [0, 1].
3. Evaluate f at each kink point and at 0 and 1.
4. Set h[i] to the value that minimizes f.

This is exact coordinate descent! It's more efficient than gradient-based methods.

  h[i] appears in f_k if:
    - i < n-k: as first factor, term is h[i]*(1-h[i+k]), coefficient of h[i] is (1-h[i+k])
    - i >= k: as second factor, term is h[i-k]*(1-h[i]), coefficient of h[i] is -h[i-k]
  
  So a_k(i) = (1-h[i+k]) * [i < n-k] + (-h[i-k]) * [i >= k]
  And b_k(i) = f_k - a_k(i) * h[i]

If k < 0 (lag = k, let idx = -k):
  f_k = ∑_{j=idx}^{n-1} h[j]*(1-h[j-idx])
  h[i] appears in f_k if:
    - i >= idx: as first factor, term is h[i]*(1-h[i-idx]), coefficient is (1-h[i-idx])
    - i < n-idx: as second factor, term is h[i+idx]*(1-h[i]), coefficient is -h[i+idx]
  
  So a_k(i) = (1-h[i-idx]) * [i >= idx] + (-h[i+idx]) * [i < n-idx]

If k = 0:
  f_0 = ∑ h[j]*(1-h[j])
  h[i] appears as: h[i]*(1-h[i]), which is h[i] - h[i]²
  This is quadratic, not linear.

For k=0, the optimal h[i] (ignoring other lags) is 0.5 (minimizing h[i](1-h[i])). But we need to consider all lags together.

For the max over k ≠ 0:
f(h) = max_{k≠0} (a_k(i) * h[i] + b_k(i))

This is a convex piecewise-linear function. The minimum is where the subgradient contains 0, which means there exist k1, k2 with a_k1 < 0 < a_k2 (or a_k1 = 0) and the lines intersect at h[i].

Actually, for a convex piecewise-linear function, the minimum is at a kink point where the slope changes from negative to positive. The slope of f at h[i] (away from kinks) is a_k* where k* is the maximizing lag.

So the algorithm for each coordinate i:
1. For each lag k, compute a_k(i) and b_k(i).
2. The function g(t) = max_k (a_k * t + b_k) for t ∈ [0,1].
3. Find the minimum of g on [0,1].
   - The minimum is at t=0, t=1, or at a kink point.
   - Kink points: for each pair (k1, k2), solve a_k1 * t + b_k1 = a_k2 * t + b_k2 → t = (b_k2 - b_k1) / (a_k1 - a_k2)
   - But there are O(n²) pairs of lags, which is too many.
   
   Alternative: The minimum of max of lines is where the slope changes sign.
   - Sort the lines by slope (a_k).
   - The upper envelope changes at most O(n) times.
   - We can find the minimum by binary search or by computing the upper envelope.

Actually, for a simpler approach: since we only need to find where the slope goes from negative to positive:
- Start at t=0, find which k maximizes g(t). Let k* be that lag.
- The slope at t (away from kinks) is a_k*(t).
- If a_k* < 0, increase t until we hit a kink or t=1.
- If a_k* > 0, decrease t until we hit a kink or t=0.
- If a_k* = 0, we're at a minimum.

But finding the next kink is still O(n) per step, and there could be O(n) steps.

For a practical implementation, I'll just evaluate g(t) at a few candidate points:
- t = 0, 1
- t = h[i] (current value)
- A few random points in [0,1]
- Points where the current top 3 lags cross

This is approximate but fast.

Actually, let me simplify. For each coordinate i, the gradient of the smooth max with respect to h[i] is:
g_i = ∑_k w_k * a_k(i)

Where w_k are the smooth max weights. Setting g_i = 0 gives:
∑_k w_k * a_k(i) * h[i] + ∑_k w_k * b_k(i) = 0
h[i] = -∑_k w_k * b_k(i) / ∑_k w_k * a_k(i)

This is a closed-form update! It's like a weighted average of the "ideal" values for each lag.

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(c) * dx)

def compute_all_lags(h, n):
    dx = 2.0 / n
    return np.correlate(h, 1.0 - h, mode='full') * dx

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h.copy(), 0.0, 1.0)
    for _ in range(3000):
        d = target - h.sum()
        if abs(d) < 1e-15:
            break
        if d > 0:
            r = 1.0 - h
            s = r.sum()
            if s < 1e-15: break
            h += (d / s) * r
        else:
            s = h.sum()
            if s < 1e-15: break
            h += (d / s) * h
    return np.clip(h, 0.0, 1.0)

def _sm_val(c, a):
    m = c.max()
    s = a * (c - m)
    mx = s.max()
    if mx > 500:
        return m + (mx + np.log(np.sum(np.exp(s - mx)))) / a
    return m + np.log(np.sum(np.exp(s))) / a

def _sm_w(c, a):
    m = c.max()
    s = a * (c - m)
    mx = s.max()
    if mx > 500:
        w = np.exp(s - mx)
    else:
        w = np.exp(s)
    return w / w.sum()

def _grad(h, n, a):
    dx = 2.0 / n
    c = compute_all_lags(h, n)
    w = _sm_w(c, a)
    g = np.zeros(n)
    for k in range(2 * n - 1):
        if w[k] < 1e-15: continue
        lag = k - (n - 1)
        if lag == 0:
            g += w[k] * (1.0 - 2.0 * h)
        elif lag > 0:
            g[:n-lag] += w[k] * (1.0 - h[lag:])
            g[lag:] += w[k] * (-h[:n-lag])
        else:
            ix = -lag
            g[ix:] += w[k] * (1.0 - h[:n-ix])
            g[:n-ix] += w[k] * (-h[ix:])
    return g * dx

def _lbfgs(h, n, a, dl, mi=2000):
    def og(x):
        x = np.clip(x, 0, 1)
        c = compute_all_lags(x, n)
        v = _sm_val(c, a)
        d = x.sum() - n / 2.0
        v += 1e10 * d * d
        g = _grad(x, n, a) + 2e10 * d
        return v, g
    try:
        r = minimize(og, h, method='L-BFGS-B', jac=True,
                     bounds=[(0.0, 1.0)] * n,
                     options={'maxiter': mi, 'ftol': 1e-20, 'gtol': 1e-14,
                              'maxls': 40, 'iprint': -1})
        return project_feasible(np.clip(r.x, 0, 1), n)
    except:
        return project_feasible(h.copy(), n)

def _tls(h, n, dl, rng, tc=5):

    b = h.copy()
    bc = compute_c5(b, n)
    while time.time() < dl:

        ti = np.argsort(ca)[-tc:]
        imp = False

            if time.time() > dl: break
            si = False

                j = i + m
                if b[i] > b[j] + 1e-11:
                    d = min(sc, (b[i] - b[j]) * 0.25)
                    if d < 1e-13: continue
                    t = b.copy()
                    t[i] -= d; t[j] += d

                        ca = compute_all_lags(b, n)
                        ti = np.argsort(ca)[-tc:]
                elif b[j] > b[i] + 1e-11:
                    d = min(sc, (b[j] - b[i]) * 0.25)
                    if d < 1e-13: continue
                    t = b.copy()
                    t[i] += d; t[j] -= d
                    t = project_feasible(t, n)

                    if ct < bc - 1e-15:
                        b = t; bc = ct; imp = True; si = True
                        ca = compute_all_lags(b, n)
                        ti = np.argsort(ca)[-tc:]

    return b, bc
