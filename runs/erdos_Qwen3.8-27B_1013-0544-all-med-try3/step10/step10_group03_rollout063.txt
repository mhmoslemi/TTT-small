If s < 0: valid i are -s ≤ i < n.

For s < 0, let s = -|s|:

∂/∂h[i]:
- If i is in [|s|, n-1]: term h[i](1-h[i+s]) contributes (1-h[i+s]).
- If i is in [0, n-1-|s|] (so i+|s| is in [|s|, n-1]): term h[i+|s|](1-h[i]) contributes -h[i+|s|].

In both cases (s ≥ 0 and s < 0), with kk = |s|:
∂full[k]/∂h[i] = (1-h[i+s]) * [kk ≤ i (if s<0) or 0 ≤ i (if s≥0)] ... 

Let me just use a unified formula. For shift s (positive means h and h shifted right by s):
- The correlation pairs are: (i, i+s) for valid i.
- If s ≥ 0: i ranges from 0 to n-1-s. Pairs: (i, i+s) for i = 0,..., n-1-s.
- If s < 0: i ranges from -s to n-1. Pairs: (i, i+s) for i = -s,..., n-1.

In all cases, the pairs are (i, j) where j - i = s and both are in [0, n-1].

For a specific i, h[i] appears in:
- Pair (i, i+s) if 0 ≤ i+s < n: contributes (1-h[i+s]) * dx
- Pair (i-s, i) if 0 ≤ i-s < n: contributes -h[i-s] * dx

So: ∂(dx * full[k])/∂h[i] = dx * [(1-h[i+s]) * 1{0≤i+s<n} - h[i-s] * 1{0≤i-s<n}]

This is clean and can be vectorized.

    dx = 2.0 / n
    return np.correlate(h, 1-h, mode='full') * dx

def compute_c5(h, n):
    return float(compute_c5_vec(h, n).max())

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h.astype(float), 0.0, 1.0)
    for _ in range(200):
        diff = target - h.sum()
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            room = 1.0 - h
            tot = room.sum()
            if tot < 1e-15:
                break
            h = h + (diff / tot) * room
        else:
            tot = h.sum()
            if tot < 1e-15:
                break
            h = h + (diff / tot) * h
    return np.clip(h, 0.0, 1.0)

def smooth_max_obj(x, n, alpha, top_k):
    """Smoothed max of correlation values, focusing on top-k."""
    c = np.correlate(x, 1-x, mode='full') * (2.0/n)
    # Get top-k
    if top_k < len(c):
        idx = np.argpartition(-c, top_k)[:top_k]
        vals = c[idx]
    else:
        vals = c
    m = vals.max()
    sh = alpha * (vals - m)
    smx = sh.max()
    if smx > 500:
        val = m + (smx + np.log(np.sum(np.exp(sh - smx)))) / alpha
    else:
        val = m + np.log(np.sum(np.exp(sh))) / alpha
    return float(val)

def smooth_max_grad(x, n, alpha, top_k):
    c = np.correlate(x, 1-x, mode='full') * (2.0/n)
    if top_k < len(c):
        idx = np.argpartition(-c, top_k)[:top_k]
        vals = c[idx]
    else:
        idx = np.arange(len(c))
        vals = c
    m = vals.max()
    sh = alpha * (vals - m)
    smx = sh.max()
    w = np.exp(sh - smx)
    w /= w.sum()
    
    dx = 2.0 / n
    grad = np.zeros(n)
    n_corr = 2 * n - 1
    for wi, corr_idx in zip(w, idx):
        if wi < 1e-15:
            continue
        s = corr_idx - (n - 1)  # actual shift
        kk = abs(s)
        wm = wi * dx
        if s >= 0:
            # valid i: 0 <= i < n-s
            nv = n - s
            # (1-h[i+s]) for i in [0, nv-1]: contributes to grad[0:nv]
            grad[0:nv] += wm * (1.0 - x[s:n])
            # -h[i-s] for i in [s, n-1]: contributes to grad[s:n]
            grad[s:n] += wm * (-x[0:nv])
        else:
            # s < 0, kk = -s
            # valid i: kk <= i < n
            # (1-h[i+s]) for i in [kk, n-1]: h[i+s] = h[i-kk], for i in [kk, n-1], i-kk in [0, n-kk-1]
            nv = n - kk
            grad[kk:n] += wm * (1.0 - x[0:nv])
            # -h[i-kk] for i in [0, n-kk-1]: 
            grad[0:nv] += wm * (-x[kk:n])
    return grad

    best_h = h.copy()
    
    # Optimization phases

    phase_configs = [
