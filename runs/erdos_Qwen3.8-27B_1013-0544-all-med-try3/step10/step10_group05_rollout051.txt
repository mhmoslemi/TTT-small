```python
            # delta_c[j_idx, k] = const_i[k] - spm[j_idx, k]
            # new_c[j_idx, k] = c_vec[k] + delta_c[j_idx, k]
            # new_max[j_idx] = max_k new_c[j_idx, k]
            
            # Vectorized:
            new_c_max = (c_vec[None, :] + const_i[None, :] - spm).max(axis=1)
            
            # Find the j that gives the smallest new_max
            best_j_idx = new_c_max.argmin()
            if new_c_max[best_j_idx] < best_c - 1e-15:
                j = zeros_idx[best_j_idx]
                h[i] = 0
                h[j] = 1
                best_c = new_c_max[best_j_idx]
                improved = True
                break  # Restart after one swap
        
        if not improved:
            break
    
    return h, best_c
```

This is O(n²) per swap (precomputing spm) + O(n * n_zeros) per i. For n=500, n_zeros=250:
- Precompute spm: 250 * 999 ≈ 250K ops
- For each i (250 of them): 250 * 999 ≈ 250K ops
- Total per round: 250 * 250K = 62.5M ops
