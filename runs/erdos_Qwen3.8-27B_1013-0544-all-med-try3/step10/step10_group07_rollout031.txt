```python
def lssq_obj_and_grad(x, n, alpha):
    h = np.clip(x, 0, 1)
    corr = np.correlate(h, 1 - h, mode='full')
    m = corr.max()
    if m <= 0:
        return 0.0, np.zeros(n)
    shifted = alpha * (corr - m)
    max_s = shifted.max()
    exp_s = np.exp(shifted - max_s)
    w = exp_s / exp_s.sum()
    
    # Gradient
    grad = np.zeros(n)
    for m_idx in range(2 * n - 1):
        wi = w[m_idx]
        if wi < 1e-16:
            continue
        k = m_idx - (n - 1)
        # (1-h[j+k]) for j where 0<=j+k<n
        js = max(0, -k)
        je = min(n - 1, n - 1 - k)
        if js <= je:
            grad[js:je+1] += wi * (1 - h[js+k:je+k+1])

        je2 = min(n - 1, k + n - 1)
        if js2 <= je2:
            grad[js2:je2+1] -= wi * h[js2-k:je2-k+1]
    
    val = m + (max_s + np.log(exp_s.sum())) / alpha
    return val, grad
```

```python
            # For each j in ones, compute B and D
            # B[m] = -(1-h[j+m-(n-1)]) if 0<=j+m-(n-1)<n
            # D[m] = h[j-m+(n-1)] if 0<=j-m+(n-1)<n
            # 
            # Vectorize: for all j simultaneously
            # B[j_idx, m] = -(1-h[j+m-(n-1)])
            # This is a 2D array of shape (len(ones), n_corr)
            
            for j_idx, j in enumerate(ones):
                idx_b = j + m_range - (n-1)
                mask_b = (idx_b >= 0) & (idx_b < n)
                B = np.zeros(n_corr)
                B[mask_b] = -(1 - h[idx_b[mask_b]])
                
                idx_d = j - m_range + (n-1)
                mask_d = (idx_d >= 0) & (idx_d < n)
                D = np.zeros(n_corr)
                D[mask_d] = h[idx_d[mask_d]]
                
                delta = base_delta + B + D
                
                # Cross terms
                xt1 = j - i + (n-1)  # where i+m-(n-1) = j
                if 0 <= xt1 < n_corr:
                    delta[xt1] += 1
                xt2 = i - j + (n-1)  # where i-m+(n-1) = j
                if 0 <= xt2 < n_corr:
                    delta[xt2] += 1
                
                new_corr = corr + delta
                new_max = new_corr.max() * dx
                
                if cur_max - new_max > best_improvement:
                    best_improvement = cur_max - new_max
                    best_i = i
                    best_j = j
                    best_new_corr = new_corr
        
        if best_i >= 0:
            h[best_i] = 1.0
            h[best_j] = 0.0
            corr = best_new_corr
            cur_max = corr.max() * dx
            improved = True
            if cur_max < best_c:
                best_c = cur_max
                best_h = h.copy()
        
        if not improved:
            break
    
    return best_h, best_c
```

This is O(n²) per sweep (n zeros * n ones * O(n) per evaluation) = O(n³) per sweep. For n=250, that's 15.6M per sweep. In Python, this might take 5-10 seconds per sweep. That's still slow.

Let me vectorize more aggressively. The key is to vectorize over j for a fixed i:

```python
def vectorized_binary_search_v2(h, n, deadline, max_sweeps=200):
    dx = 2.0 / n
    h = np.round(h).clip(0, 1)
    corr = np.correlate(h, 1 - h, mode='full').astype(float)
    cur_max = corr.max() * dx
    best_c = cur_max
    best_h = h.copy()
    
    n_corr = 2 * n - 1
    m_range = np.arange(n_corr)
    
    for sweep in range(max_sweeps):
        if time.time() > deadline:
            break
        
        improved = False
        ones = np.where(h == 1)[0]
        zeros = np.where(h == 0)[0]
        
        best_imp = 1e-10
        best_i, best_j = -1, -1
        best_delta = None
        
        for i in zeros:
            # A and C for this i
            idx_a = i + m_range - (n-1)
            mask_a = (idx_a >= 0) & (idx_a < n)
            A = np.zeros(n_corr)
            A[mask_a] = 1 - h[idx_a[mask_a]]
            
            idx_c = i - m_range + (n-1)
            mask_c = (idx_c >= 0) & (idx_c < n)
            C = np.zeros(n_corr)
            C[mask_c] = -h[idx_c[mask_c]]
            
            base = A + C  # shape (n_corr,)
            
            # Vectorize over all j in ones
            # B[j_idx, m] = -(1-h[j+m-(n-1)]) if valid
            # idx_b = ones[:, None] + m_range[None, :] - (n-1)
            # shape: (len(ones), n_corr)
            
            idx_b = ones[:, None] + m_range[None, :] - (n-1)
            mask_b = (idx_b >= 0) & (idx_b < n)
            # B = np.where(mask_b, -(1-h[np.clip(idx_b, 0, n-1)]), 0)
            # But we need to be careful with out-of-bounds
            B = np.zeros((len(ones), n_corr))
            B[mask_b] = -(1 - h[np.clip(idx_b[mask_b], 0, n-1)])
            
            idx_d = ones[:, None] - m_range[None, :] + (n-1)
            mask_d = (idx_d >= 0) & (idx_d < n)
            D = np.zeros((len(ones), n_corr))
            D[mask_d] = h[np.clip(idx_d[mask_d], 0, n-1)]
            
            # delta[j_idx, m] = base[m] + B[j_idx, m] + D[j_idx, m] + cross
            deltas = base[None, :] + B + D  # shape (len(ones), n_corr)
            
            # Cross terms
            # xt1 = j - i + (n-1), add 1 at that position
            xt1 = ones - i + (n-1)  # shape (len(ones),)
            valid_xt1 = (xt1 >= 0) & (xt1 < n_corr)
            if np.any(valid_xt1):
                deltas[valid_xt1, xt1[valid_xt1]] += 1
            
            # xt2 = i - j + (n-1), add 1 at that position
            xt2 = i - ones + (n-1)  # shape (len(ones),)
            valid_xt2 = (xt2 >= 0) & (xt2 < n_corr)
            if np.any(valid_xt2):
                deltas[valid_xt2, xt2[valid_xt2]] += 1
            
            # new_corr[j_idx, m] = corr[m] + deltas[j_idx, m]
            new_corrs = corr[None, :] + deltas  # shape (len(ones), n_corr)
            new_maxes = new_corrs.max(axis=1) * dx  # shape (len(ones),)
            
            # Find best j for this i
            improvements = cur_max - new_maxes
            best_j_idx = improvements.argmax()
            if improvements[best_j_idx] > best_imp:
                best_imp = improvements[best_j_idx]
                best_i = i
                best_j = ones[best_j_idx]
                best_delta = deltas[best_j_idx]
        
        if best_i >= 0:
            h[best_i] = 1.0
            h[best_j] = 0.0
            corr = corr + best_delta
            cur_max = corr.max() * dx
            improved = True
            if cur_max < best_c:
                best_c = cur_max
                best_h = h.copy()
        
        if not improved:
            break
    
    return best_h, best_c
```

For n=250, the inner vectorized operation creates a (125, 499) array and does max over axis=1. That's about 62K elements, which is very fast in numpy. The outer loop is over 125 zeros. So each sweep is 125 * (vectorized op on 125x499 array) ≈ 125 * (62K ops) ≈ 7.8M ops. In numpy, this should take about 50-100ms per sweep. So we can do thousands of sweeps!

This is a major speedup over the previous O(n³) per sweep approach.

Let me also think about whether there's a smarter initialization. The Erdős problem is related to difference sets. For n=250 (so 125 ones in 250 positions), a good initial pattern might be based on a known difference set or a structured pattern.

Actually, let me think about what the optimal pattern looks like. For the cyclic version of the problem (where we work mod n), the optimal set is one where the autocorrelation is as uniform as possible. For a set of size m in Z_n, the autocorrelation at shift k is:
C(k) = |{x ∈ S : x+k ∈ S}|

The total sum of autocorrelations is sum_k C(k) = m (each element contributes to exactly m shifts... wait no).

Actually, sum_k C(k) = sum_k |{x : x ∈ S, x+k ∈ S}| = |{(x,y) ∈ S×S : y-x = k for some k}| = |S×S| = m².

And C(0) = m (each x satisfies x + 0 = x).

So sum_{k≠0} C(k) = m² - m = m(m-1).

For n = 2m (our case), the average autocorrelation at nonzero shifts is m(m-1)/(n-1) = m(m-1)/(2m-1) ≈ m/2 for large m.

The minimum possible maximum autocorrelation (for the cyclic case) is at least this average, so at least ≈ m/2 = n/4.

For our non-cyclic case, the boundary effects reduce the autocorrelation at large shifts.
