- The subgradient at the maximizing lag k* is: ∂corr_{k*}/∂h[i] = (1-h[i+k*]) - h[i-k*] (for the appropriate lags)
- Update: h[i] ← clip(h[i] - lr * subgrad[i], 0, 1)
- Then project onto the integral constraint: h ← h + (target - sum(h))/n (uniform shift)
- Repeat

This is O(n) per iteration (for the subgradient) + O(n) for the update. Much faster than SLSQP!

And we can use **accelerated subgradient** (Nesterov) for faster convergence.

After the continuous optimization converges, we round to binary:

def project_feasible(h, n):
    """Project to [0,1] with sum = n/2."""
    target = n / 2.0
    h = np.clip(h, 0.0, 1.0)
    for _ in range(200):
        diff = target - h.sum()
        if abs(diff) < 1e-12:
            break
        if diff > 0:

            if s < 1e-12: break
            h += diff / s * room
        else:
            s = h.sum()
            if s < 1e-12: break
            h += diff / s * h

def binarize(h, n):
    """Convert continuous to binary: top n/2 values become 1."""
    target = n // 2
    idx = np.argsort(h)[::-1]
    h_bin = np.zeros(n)
    h_bin[idx[:target]] = 1.0
