For c(L) with L > 0:

∂c(L)/∂h[m] = dx * [ (1-h[m+L]) * 1_{m < n-L} + (-h[m-L]) * 1_{m >= L} ]

For c(-L) with L > 0:
c(-L) = sum_{i=0}^{n-1-L} h[i+L] * (1-h[i]) * dx

∂c(-L)/∂h[m] = dx * [ (1-h[m-L]) * 1_{m >= L} + (-h[m+L]) * 1_{m < n-L} ]

Now, for the local search, if we transfer amount d from position p to position q (h[p] -= d, h[q] += d):
Δc(L) = dx * d * (∂c(L)/∂h[q]/dx - ∂c(L)/∂h[p]/dx)
= d * [ (1-h[q+L])*1_{q<n-L} - h[q-L]*1_{q>=L} - (1-h[p+L])*1_{p<n-L} + h[p-L]*1_{p>=L} ]

This is very efficient to compute! For each candidate lag L, we can compute the "gain" of transferring from p to q in O(1).

**Optimized local search algorithm:**

```
For each iteration:
  1. Compute all correlations (O(n²) or use FFT)
  2. Find the K worst lags (largest correlations)
  3. For each worst lag L:
     a. For each position m, compute g[m] = ∂c(L)/∂h[m] (the "sensitivity")
     b. We want to find (p, q) that maximizes g[p] - g[q] (transfer from p to q)
        subject to h[p] > 0 and h[q] < 1
     c. The best (p, q) is (argmax g among h>0, argmin g among h<1)
     d. But we also need to check that this doesn't hurt other lags too much
  4. Choose the best move overall and apply it
  5. Limit the step size to avoid overshooting
```

Actually, step 3b is the key insight. For a given lag L, the best single transfer to reduce c(L) is:
- Find p with maximum g[p] where h[p] > 0 (source)
- Find q with minimum g[q] where h[q] < 1 (destination)
- Transfer from p to q

But we need to be careful: this reduces c(L) but might increase other correlations. So we should:
- Try the move
- Check if the overall max decreased
- If yes, keep it; if no, try a smaller step or a different move

Let me also think about the step size. The optimal step size for reducing c(L) while keeping c(L) >= 0 would be limited by:
- h[p] (can't go below 0)
- 1 - h[q] (can't go above 1)
- The point where c(L) starts increasing again (if we overshoot)

For a small step, the change in c(L) is approximately linear in d. So a small step is safe.

```python
import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1 - h, mode='full')
    return float(np.max(c) * dx)

def compute_all_lags(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1 - h, mode='full')
    return c * dx

def project_feasible(h, n):
    target_sum = n / 2.0
    h = np.clip(h.copy(), 0.0, 1.0)
    for _ in range(200):
        diff = target_sum - h.sum()
        if abs(diff) < 1e-12:
            break
        if diff > 0:
            room = 1.0 - h
            tot = room.sum()
            if tot < 1e-15:
                break
            h += (diff / tot) * room
        else:
            tot = h.sum()
            if tot < 1e-15:
                break
            h += (diff / tot) * h
    return np.clip(h, 0.0, 1.0)

def grad_lag(h, n, L):
    """
    Compute ∂c(L)/∂h for positive lag L.
    c(L) = sum_{i=0}^{n-1-L} h[i]*(1-h[i+L]) * dx
    ∂c(L)/∂h[m] = dx * [(1-h[m+L]) if m < n-L else 0] + dx * [-h[m-L] if m >= L else 0]
    """
    dx = 2.0 / n
    grad = np.zeros(n)
    if L > 0 and L < n:
        # First term: (1-h[m+L]) for m in [0, n-L-1]
        grad[0:n-L] += (1.0 - h[L:n])
        # Second term: -h[m-L] for m in [L, n-1]
        grad[L:n] -= h[0:n-L]
    return grad * dx

def grad_neg_lag(h, n, L):
    """
    Compute ∂c(-L)/∂h for positive L (i.e., negative lag -L).
    c(-L) = sum_{i=0}^{n-1-L} h[i+L]*(1-h[i]) * dx
    ∂c(-L)/∂h[m] = dx * [(1-h[m-L]) if m >= L else 0] + dx * [-h[m+L] if m < n-L else 0]
    """
    dx = 2.0 / n
    grad = np.zeros(n)
    if L > 0 and L < n:
        # First term: (1-h[m-L]) for m in [L, n-1]
        grad[L:n] += (1.0 - h[0:n-L])
        # Second term: -h[m+L] for m in [0, n-L-1]
        grad[0:n-L] -= h[L:n]
    return grad * dx

def focused_local_search(h, n, deadline, rng, K=5, max_iters=500000):
    """
    Local search that focuses on the worst K lags.
    Uses gradient information to find the best transfer for each lag.
    """
    h = h.copy()
    best_h = h.copy()
    best_c = compute_c5(h, n)
    it = 0
    no_improve = 0
    base_step = 0.05
    step_decay = 0.999
    
    while it < max_iters and time.time() < deadline:
        c_all = compute_all_lags(h, n)
        max_c = c_all.max()
        
        if max_c < best_c - 1e-14:
            best_c = float(max_c)
            best_h = h.copy()
            no_improve = 0
            # Reset step size
            base_step = max(0.01, base_step * 1.1)
        else:
            no_improve += 1
        
        if no_improve > 5000:
            # Restart with perturbation
            h = best_h + rng.normal(0, 0.005, n)
            h = project_feasible(h, n)
            no_improve = 0
            base_step = 0.02
        
        # Find top K lags
        top_idx = np.argpartition(c_all, -K)[-K:]
        top_idx = top_idx[np.argsort(c_all[top_idx])[::-1]]
        
        improved = False
        for k_idx in top_idx:
            if time.time() > deadline:
                break
            lag = k_idx - (n - 1)
            if lag == 0:
                continue
            L = abs(lag)
            if L >= n:
                continue
            
            if lag > 0:
                g = grad_lag(h, n, L)
            else:
                g = grad_neg_lag(h, n, L)
            
            # Find best transfer: max g[p] (source, h[p]>0) to min g[q] (dest, h[q]<1)
            # We want g[p] - g[q] > 0 to reduce c(L)
            # (Since Δc = d * (g[q] - g[p]), we want g[q] < g[p])
            
            # But we also need to ensure we don't increase c(L) for the wrong direction
            # Actually, Δc(L) = d * (g[q] - g[p]) where d is the transfer amount
            # We want Δc(L) < 0, so g[q] < g[p]
            
            valid_src = np.where(h > 1e-6)[0]
            valid_dst = np.where(h < 1.0 - 1e-6)[0]
            
            if len(valid_src) == 0 or len(valid_dst) == 0:
                continue
            
            p = valid_src[np.argmax(g[valid_src])]
            q = valid_dst[np.argmin(g[valid_dst])]
            
            if g[p] <= g[q]:
                continue
            
            # Step size: limited by h[p] and 1-h[q]
            max_d = min(h[p], 1.0 - h[q]) * 0.5
            d = min(base_step, max_d)
            
            if d < 1e-8:
                continue
            
            # Try the move
            h_old = h.copy()
            h[p] -= d
            h[q] += d
            h = project_feasible(h, n)
            
            c_new = c_all.copy()
            # We need to recompute at least the affected lags
            # For efficiency, just recompute the max
            max_new = compute_c5(h, n)
            
            if max_new < best_c - 1e-12:
                # Great, keep the move
                improved = True
                c_all = compute_all_lags(h, n)
            else:
                # Revert
                h = h_old
            
            # Also try a smaller step
            if not improved:
                d_small = d * 0.1
                h[p] -= d_small
                h[q] += d_small
                h = project_feasible(h, n)
                max_new = compute_c5(h, n)
                if max_new < best_c - 1e-12:
                    improved = True
                else:
                    h = h_old
        
        if not improved:
            base_step *= step_decay
            if base_step < 0.001:
                # Try random moves
                p = rng.randint(n)
                q = rng.randint(n)
                if p == q:
                    it += 1
                    continue
                d = rng.uniform(-0.01, 0.01)
                h[p] -= d
                h[q] += d
                h = project_feasible(h, n)
                max_new = compute_c5(h, n)
                if max_new < best_c - 1e-12:
                    improved = True
                    base_step = max(base_step, 0.005)
                else:
                    h = project_feasible(best_h + rng.normal(0, 0.003, n), n)
        
        it += 1
    
    return best_h, best_c
```

- Find the transfer that best reduces the weighted sum

The gradient of the weighted sum is: Σ w_k * ∂c_k/∂h
And the best transfer is from the position with max weighted gradient to the position with min weighted gradient.

```python
def weighted_gradient_local_search(h, n, deadline, rng, K=10, weight_temp=1000):
    """
    Local search using a weighted combination of top lags.
    At each step, compute a weighted gradient and take a step in the negative direction.
    """
    h = h.copy()
    best_h = h.copy()
    best_c = compute_c5(h, n)
    dx = 2.0 / n
    
    it = 0
    step = 0.03
    no_improve = 0
    
    while time.time() < deadline:
        c_all = compute_all_lags(h, n)
        max_c = c_all.max()
        
        if max_c < best_c - 1e-12:
            best_c = float(max_c)
            best_h = h.copy()
            no_improve = 0
            step = min(0.05, step * 1.05)
        else:
            no_improve += 1
        
        if no_improve > 10000:
            h = best_h + rng.normal(0, 0.003, n)
            h = project_feasible(h, n)
            no_improve = 0
            step = 0.01
        
        # Compute weights for top K lags
        # Use softmax-like weights
        top_idx = np.argpartition(c_all, -K)[-K:]
        # Weights: exponential of (c - max) / temperature
        c_top = c_all[top_idx]
        w = np.exp((c_top - c_top.max()) * weight_temp)
        w = w / w.sum()
        
        # Compute weighted gradient
        wg = np.zeros(n)
        for i, k_idx in enumerate(top_idx):
            if w[i] < 1e-8:
                continue
            lag = k_idx - (n - 1)
            if lag == 0:
                # c(0) = sum h[i](1-h[i]) * dx
                # ∂c(0)/∂h[m] = (1 - 2h[m]) * dx
                wg += w[i] * (1.0 - 2.0 * h) * dx
            else:
                L = abs(lag)
                if L >= n:
                    continue
                if lag > 0:
                    g = grad_lag(h, n, L)
                else:
                    g = grad_neg_lag(h, n, L)
                wg += w[i] * g
        
        # Find best transfer: from max wg to min wg
        valid_src = np.where(h > 1e-6)[0]
        valid_dst = np.where(h < 1.0 - 1e-6)[0]
        
        if len(valid_src) == 0 or len(valid_dst) == 0:
            step *= 0.9
            continue
        
        p = valid_src[np.argmax(wg[valid_src])]
        q = valid_dst[np.argmin(wg[valid_dst])]
        
        if wg[p] <= wg[q]:
            # No improvement possible with weighted gradient
            step *= 0.95
            if step < 0.001:
                # Try random perturbation
                h = best_h + rng.normal(0, 0.002, n)
                h = project_feasible(h, n)
                step = 0.01
            continue
        
        # Apply move
        max_d = min(h[p], 1.0 - h[q]) * 0.8
        d = min(step, max_d)
        
        h[p] -= d
        h[q] += d
        h = project_feasible(h, n)
        
        it += 1
    
    return best_h, best_c
```

```python
    return np.clip(h, 0.0, 1.0)

def grad_lag_pos(h, n, L):
    """∂c(L)/∂h * (1/dx) for L > 0."""
    g = np.zeros(n)
    if L > 0 and L < n:
        g[0:n-L] += (1.0 - h[L:n])
        g[L:n] -= h[0:n-L]
    return g

def grad_lag_neg(h, n, L):
    """∂c(-L)/∂h * (1/dx) for L > 0."""
    g = np.zeros(n)
    if L > 0 and L < n:
        g[L:n] += (1.0 - h[0:n-L])
        g[0:n-L] -= h[L:n]
    return g

def compute_weighted_grad(h, n, c_all, K, temp):
    """Compute weighted gradient focusing on top K lags."""
    top_idx = np.argpartition(c_all, -K)[-K:]
    c_top = c_all[top_idx]
    w = np.exp((c_top - c_top.max()) * temp)
    w = w / w.sum()
    
    dx = 2.0 / n
    wg = np.zeros(n)
    for i, k_idx in enumerate(top_idx):
        if w[i] < 1e-10:
            continue
        lag = k_idx - (n - 1)
        if lag == 0:
            wg += w[i] * (1.0 - 2.0 * h)
        else:
            L = abs(lag)
            if L >= n:
                continue
            if lag > 0:
                g = grad_lag_pos(h, n, L)
            else:
                g = grad_lag_neg(h, n, L)
            wg += w[i] * g
    return wg * dx

def focused_search(h, n, deadline, rng, K=10, temp=500, initial_step=0.02):
    """Main local search using weighted gradient."""
    h = h.copy()
    best_h = h.copy()
    best_c = compute_c5(h, n)
    step = initial_step

    dx = 2.0 / n

        max_c = float(c_all.max())
        
        if max_c < best_c - 1e-12:
            best_c = max_c
            best_h = h.copy()
            no_improve = 0
            step = min(0.04, step * 1.02)
        else:
            no_improve += 1
        
        if no_improve > 20000:
            # Perturb and restart
            h = best_h + rng.normal(0, 0.003, n)
            h = project_feasible(h, n)
            no_improve = 0
            step = 0.005
            continue
        
        if no_improve > 5000:
            step = max(0.001, step * 0.9)
        
        # Compute weighted gradient
        wg = compute_weighted_grad(h, n, c_all, K, temp)
        
        # Find best transfer
        valid_src = np.where(h > 1e-5)[0]
        valid_dst = np.where(h < 1.0 - 1e-5)[0]
        
        if len(valid_src) == 0 or len(valid_dst) == 0:
            continue
        
        p = valid_src[np.argmax(wg[valid_src])]
        q = valid_dst[np.argmin(wg[valid_dst])]
        
        if wg[p] - wg[q] < 1e-10:
            # No direction to improve
            if no_improve > 1000:
                h = best_h + rng.normal(0, 0.002, n)
                h = project_feasible(h, n)
            continue

        max_d = min(h[p], 1.0 - h[q]) * 0.7
        d = min(step, max_d)
        
        if d < 1e-9:
            continue
        
        # Apply
        h[p] -= d
        h[q] += d
        h = project_feasible(h, n)
    
    return best_h, best_c
```

Wait, I realized there might be an issue with my gradient computation. Let me double-check.

For c(L) = sum_{i=0}^{n-1-L} h[i] * (1-h[i+L]) * dx:

∂c(L)/∂h[m] = dx * [d/dh[m] of sum_{i=0}^{n-1-L} h[i]*(1-h[i+L])]

The term h[m] appears in the sum:
- As h[i] when i = m (if m < n-L): contribution is (1-h[m+L])
- As h[i+L] when i+L = m, i.e., i = m-L (if m-L >= 0, i.e., m >= L): contribution is -h[m-L]

So ∂c(L)/∂h[m] = dx * [(1-h[m+L]) * 1_{m < n-L} - h[m-L] * 1_{m >= L}]

This matches what I had. Good.

Now, for the transfer from p to q (h[p] -= d, h[q] += d):
Δc(L) = d * [∂c(L)/∂h[q] - ∂c(L)/∂h[p]]
= d * dx * [(1-h[q+L])*1_{q<n-L} - h[q-L]*1_{q>=L} - (1-h[p+L])*1_{p<n-L} + h[p-L]*1_{p>=L}]

We want Δc(L) < 0, so we want:
(1-h[q+L])*1_{q<n-L} - h[q-L]*1_{q>=L} < (1-h[p+L])*1_{p<n-L} - h[p-L]*1_{p>=L}

The left side is (∂c/∂h[q])/dx and the right side is (∂c/∂h[p])/dx.
So we want ∂c/∂h[q] < ∂c/∂h[p], which means q should have lower gradient and p should have higher gradient.

This is exactly what my code does: find p with max wg and q with min wg.

def compute_c5(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1 - h, mode='full')
    return float(np.max(c) * dx)

def compute_all_lags(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1 - h, mode='full')
    return c * dx

def project_feasible(h, n):
    target_sum = n / 2.0
    h = np.clip(h.copy(), 0.0, 1.0)
    for _ in range(200):

        if abs(diff) < 1e-12:
            break
        if diff > 0:
            room = 1.0 - h
            tot = room.sum()
            if tot < 1e-15:
                break
            h += (diff / tot) * room

            if tot < 1e-15:
