```python
def compute_swap_delta(h, i, j, n):
    """Compute delta corr vector when h[i]: 0->1, h[j]: 1->0"""
    delta = np.zeros(2*n-1)
    # Affected n values for each k
    # n = i-k: valid if 0<=i-k<n and 0<=i<n (always true for i)
    # n = j-k: valid if 0<=j-k<n
    # n = i: valid if 0<=i<n and 0<=i+k<n
    # n = j: valid if 0<=j<n and 0<=j+k<n
    # For k in [-(n-1), n-1]:
    for k in range(-(n-1), n):
        total = 0.0
        # n = i-k
        n_val = i - k
        if 0 <= n_val < n:
            before = h[i] * (1 - h[n_val])  # h_old[i] = 0, so this is 0
            # After: h_new[i] = 1, (1-h_new[n_val])
            if n_val == i:
                after = 1.0 * 0.0  # h_new[i]=1, 1-h_new[i]=0
            elif n_val == j:
                after = 1.0 * 1.0  # h_new[i]=1, 1-h_new[j]=1 (since h[j] was 1, now 0)
            else:
                after = 1.0 * (1 - h[n_val])
            total += after - before
        # n = j-k
        n_val = j - k
        if 0 <= n_val < n:
            before = h[j] * (1 - h[n_val])  # h_old[j] = 1
            if n_val == i:
                after = 0.0 * 1.0  # h_new[j]=0, 1-h_new[i]=1
            elif n_val == j:
                after = 0.0 * 0.0  # h_new[j]=0, 1-h_new[j]=0
            else:
                after = 0.0 * (1 - h[n_val])
            total += after - before
        # n = i
        if 0 <= i + k < n:
            before = h[i+k] * (1 - h[i])  # (1-h_old[i]) = 1
            if i + k == i:  # k=0
                after = 1.0 * 0.0  # h_new[i]=1, 1-h_new[i]=0
            elif i + k == j:
                after = 0.0 * 0.0  # h_new[j]=0, 1-h_new[i]=0
            else:
                after = h[i+k] * 0.0  # 1-h_new[i]=0
            total += after - before
        # n = j
        if 0 <= j + k < n:
            before = h[j+k] * (1 - h[j])  # (1-h_old[j]) = 0
            if j + k == i:
                after = 1.0 * 1.0  # h_new[i]=1, 1-h_new[j]=1
            elif j + k == j:  # k=0
                after = 0.0 * 1.0  # h_new[j]=0, 1-h_new[j]=1
            else:
                after = h[j+k] * 1.0  # 1-h_new[j]=1
            total += after - before
        
        delta[k + (n-1)] = total
    return delta
```

    for k in [0, i-j, j-i]:

                if 0 <= n_val < n and 0 <= n_val + k < n:

            for n_val in affected_n:

                if n_val == i: h_n = 0.0

                before = h_nk * (1 - h_n)

                h_n_new = h_n
                if nk == i: h_nk_new = 1.0
                if nk == j: h_nk_new = 0.0
                if n_val == i: h_n_new = 1.0
                if n_val == j: h_n_new = 0.0
                after = h_nk_new * (1 - h_n_new)
                actual += after - before
            delta[k + off] = actual

For period p, the pattern is a binary string of length p with p/2 ones (if p is even). The correlation at shift k depends only on k mod p (approximately, ignoring boundary effects).

For p=50: pattern of 25 ones and 25 zeros in 50 positions. The autocorrelation of the pattern determines the quality.

This is a much smaller problem! I can brute-force or use local search on the period-p pattern.

But wait, for the pattern to have exactly n/2 = 125 ones in n=250 positions with period 50, the period must have exactly 25 ones (since 250/50 = 5 repetitions). 25 ones in 50 positions works.

Let me think about what period gives the best result. For period p, the "effective" problem is on a cyclic group of size p. The autocorrelation at shift d (mod p) is the number of pairs (i,j) in the pattern with j-i = d (mod p).

We want to minimize max_d (number of 0s followed by 1s at distance d), which is (p/2) - (autocorrelation at d).

So we want to maximize min_d autocorrelation(d) over d ≠ 0.

The average autocorrelation is (p/2)²/p = p/4. So the minimum is at most p/4, giving max overlap ≥ p/2 - p/4 = p/4, and C₅ ≥ (p/4) * 2/p = 1/2.

Hmm, that's the same bound as before. But with boundary effects, we might do better.

Actually, for a cyclic group, the sum of autocorrelations over all non-zero shifts is (p/2)(p/2 - 1) (total ordered pairs minus the p/2 pairs at shift 0). So the average non-zero autocorrelation is (p/2)(p/2-1)/(p-1) ≈ p/4 - 1/2.

So min autocorrelation ≤ p/4 - 1/2, giving max overlap ≥ p/2 - p/4 + 1/2 = p/4 + 1/2.

C₅ ≥ (p/4 + 1/2) * 2/p = 1/2 + 1/p.

For p=50: C₅ ≥ 0.52. That's worse than what we have (0.38). So pure periodic patterns are not competitive.

The boundary effects in the non-cyclic case are what allow us to beat 0.5. The shifts near the boundary have fewer terms, so they naturally have lower correlation.
