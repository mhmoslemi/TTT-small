11. **Another key idea: Use the structure of the problem**

The integral h(x)(1-h(x+k)) is the "non-overlap" at shift k. Intuitively, we want h to be such that for every shift k, h(x) and h(x+k) don't overlap much.

If h is a "sparse" function (mostly 0 with some 1s), then h(x)(1-h(x+k)) is 1 only where h(x)=1 and h(x+k)=0. So we want the support of h to have minimal "cross-correlation" with its complement.

This is related to the concept of a "difference set" or "Singer difference set" in finite geometry. For the discrete case with n points and n/2 ones, we want a subset S of {0,...,n-1} with |S|=n/2 that minimizes max_k |S ∩ (S+k)^c| = max_k (|S| - |S ∩ (S+k)|).

So we want to minimize max_k (n/2 - |S ∩ (S+k)|) which is equivalent to maximizing min_k |S ∩ (S+k)|.

This is the "autocorrelation" of the set S! We want the autocorrelation to be as flat as possible (no large peaks at any non-zero shift).

For fractional h, this generalizes naturally.

import numpy as np

def compute_c5_vec(h, n):
    dx = 2.0 / n
    return np.correlate(h, 1 - h, mode='full') * dx

def compute_c5(h, n):
    return float(compute_c5_vec(h, n).max())

def project_feasible(h, n):
    """Project h to satisfy sum(h) = n/2 and 0 <= h <= 1."""
    target = n / 2.0
    h = np.clip(h.astype(float), 0.0, 1.0)
    for _ in range(10000):
        diff = target - h.sum()
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            room = 1.0 - h
            tot = room.sum()
            if tot < 1e-14:
                break
            h += (diff / tot) * room
        else:
            tot = h.sum()
            if tot < 1e-14:
                break
            h += (diff / tot) * h
    return np.clip(h, 0.0, 1.0)

def coord_desc_pass(h, c_vec, n, max_c_target=None):
    """One full pass of coordinate descent. Returns updated h, c_vec, and improvement."""
    total_improve = 0.0
    for i in range(n):
        cur_val = h[i]
        if cur_val == 0.0 or cur_val == 1.0:
            # Still check if moving helps
            pass

        a = np.zeros(2 * n - 1)
        a[n-1 : n+i+1] += (1.0 - h[i::-1])

        # b = c_vec - cur_val * a
