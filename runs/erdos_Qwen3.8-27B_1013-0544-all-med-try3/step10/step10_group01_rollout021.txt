For k = 0: out[0] = sum_{m=0}^{n-1} h[m] * (1-h[m])
For k > 0: out[k] = sum_{m=0}^{n-1-k} h[m+k] * (1-h[m])
For k < 0: let kk = -k > 0: out[-kk] = sum_{m=kk}^{n-1} h[m] * (1-h[m-kk])
           = sum_{m=0}^{n-1-kk} h[m+kk] * (1-h[m])
           
Hmm wait, that's the same as for positive k. Let me re-check.

For k = -1: out[-1] = sum_m h[m-1] * (1-h[m]) where m-1 >= 0 and m-1 < n and 0 <= m < n
= sum_{m=1}^{n-1} h[m-1] * (1-h[m])
= sum_{m=0}^{n-2} h[m] * (1-h[m+1])

OK so for k < 0 (k = -kk, kk > 0):
out[k] = sum_{m=kk}^{n-1} h[m-kk] * (1-h[m])
Let j = m - kk: = sum_{j=0}^{n-1-kk} h[j] * (1-h[j+kk])

So the "overlap at lag kk" for positive kk is:
sum_{j=0}^{n-1-kk} h[j+kk] * (1-h[j])  (from out[kk])
or equivalently
sum_{j=0}^{n-1-kk} h[j] * (1-h[j+kk])  (from out[-kk], by substitution)

Wait, these are different:
out[kk] = sum_j h[j+kk]*(1-h[j]) = "h at position j+kk is 1, and h at position j is 0"
out[-kk] = sum_j h[j]*(1-h[j+kk]) = "h at position j is 1, and h at position j+kk is 0"

These are not the same in general (for non-binary h, they're different). But for the max, we take the max over ALL out[k] values (k from 0 to 2n-2), so we're taking the max over both "directions" of each lag.

OK, so the gradient computation needs to handle both cases.

For out[k] where k >= 0:
out[k] = sum_{m=0}^{n-1-k} h[m+k] * (1-h[m])

∂out[k]/∂h[i]:
- If i = m+k for some m in [0, n-1-k]: contributes (1-h[m]) = (1-h[i-k])
- If i = m for some m in [0, n-1-k]: contributes -h[m+k] = -h[i+k]

So:
∂out[k]/∂h[i] = (1-h[i-k]) * [k ≤ i ≤ n-1] + (-h[i+k]) * [0 ≤ i ≤ n-1-k]
               = (1-h[i-k]) * [i ≥ k] (for i in [k, n-1]) + (-h[i+k]) * [i ≤ n-1-k] (for i in [0, n-1-k])

For k=0:
∂out[0]/∂h[i] = (1-h[i]) + (-h[i]) = 1 - 2h[i] ✓

For out[k] where k < 0, let kk = -k > 0:
out[-kk] = sum_{m=kk}^{n-1} h[m-kk] * (1-h[m])
Let j = m-kk: = sum_{j=0}^{n-1-kk} h[j] * (1-h[j+kk])

∂out[-kk]/∂h[i]:
- If i = j for some j in [0, n-1-kk]: contributes (1-h[j+kk]) = (1-h[i+kk])
- If i = j+kk for some j in [0, n-1-kk]: contributes -h[j] = -h[i-kk]

So:
∂out[-kk]/∂h[i] = (1-h[i+kk]) * [0 ≤ i ≤ n-1-kk] + (-h[i-kk]) * [kk ≤ i ≤ n-1]

This matches what I had before. Good.

Now, let me think about the gradient more efficiently. Instead of looping over all lags, I can vectorize.

For a given set of weights w[k] (k = 0..2n-2), the gradient is:
grad[i] = sum_k w[k] * ∂out[k]/∂h[i] * dx

This can be computed as two convolutions:
- For positive lags (k >= 0): contribution to grad[i] from lag k is w[k] * (1-h[i-k]) for i >= k
- For negative lags (k = -kk): contribution to grad[i] from lag -kk is w[-kk] * (1-h[i+kk]) for i <= n-1-1-kk

Actually, let me just implement it as a loop for clarity, and it should be fast enough with numpy vectorization inside.

For n=1000, there are 1999 lags. For each lag k, the gradient update touches O(n-|k|) elements. Total work: sum_k (n-|k|) ≈ n². With numpy vectorization, this is about 2n² multiplications, which is 2 * 10^6 for n=1000. Very fast.

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5_vec(h, n):
    dx = 2.0 / n
    return np.correlate(h, 1.0 - h, mode='full') * dx

def compute_c5(h, n):
    return float(compute_c5_vec(h, n).max())

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h.copy(), 0.0, 1.0)
    for _ in range(200):
        diff = target - h.sum()
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            room = 1.0 - h
            tot = room.sum()
            if tot < 1e-15:
                break
            h = h + (diff / tot) * room
        else:
            tot = h.sum()
            if tot < 1e-15:
                break
            h = h + (diff / tot) * h
    return np.clip(h, 0.0, 1.0)

def smooth_max_val(c, alpha):
    m = c.max()
    sh = alpha * (c - m)
    smx = sh.max()
    if smx > 400:
        val = m + (smx + np.log(np.sum(np.exp(sh - smx)))) / alpha
    else:
        val = m + np.log(np.sum(np.exp(sh))) / alpha
    return float(val)

def corr_grad_single(k, x, n):
    """Gradient of out[k] (before * dx) with respect to x."""
    n = len(x)
    grad = np.zeros(n)
    if k >= 0:
        nv = n - k
        if nv > 0:
            grad[k:n] += (1.0 - x[0:nv])
            grad[0:nv] += (-x[k:n])
    else:
        kk = -k
        nv = n - kk
        if nv > 0:
            grad[0:nv] += (1.0 - x[kk:n])
            grad[kk:n] += (-x[0:nv])
    return grad

def smooth_max_grad(c, alpha, x, n):
    m = c.max()
    sh = alpha * (c - m)
    smx = sh.max()
    w = np.exp(sh - smx)
    w /= w.sum()
    dx_val = 2.0 / n
    grad = np.zeros(n)
    for mm in range(len(c)):
        if w[mm] < 1e-12:
            continue
        k = mm - (n - 1)
        wg = w[mm] * dx_val
        if k >= 0:
            nv = n - k
            if nv > 0:
                grad[k:n] += wg * (1.0 - x[0:nv])
                grad[0:nv] += wg * (-x[k:n])
        else:
            kk = -k
            nv = n - kk
            if nv > 0:
                grad[0:nv] += wg * (1.0 - x[kk:n])
                grad[kk:n] += wg * (-x[0:nv])
    return grad

def active_grad(c, w_active, active_idx, x, n):
    """Gradient using only active indices with given weights."""
    dx_val = 2.0 / n
    grad = np.zeros(n)
    for idx, wi in zip(active_idx, w_active):
        k = idx - (n - 1)
        wg = wi * dx_val
        if k >= 0:
            nv = n - k
            if nv > 0:
                grad[k:n] += wg * (1.0 - x[0:nv])
                grad[0:nv] += wg * (-x[k:n])
        else:
            kk = -k
            nv = n - kk
            if nv > 0:
                grad[0:nv] += wg * (1.0 - x[kk:n])
                grad[kk:n] += wg * (-x[0:nv])
    return grad

def obj_full(x, n, alpha, mu):
    c = compute_c5_vec(x, n)
    val = smooth_max_val(c, alpha)
    if mu > 0:
        val += mu * (x.sum() - n / 2.0) ** 2
    return val

def grad_full(x, n, alpha, mu):
    c = compute_c5_vec(x, n)
    g = smooth_max_grad(c, alpha, x, n)
    if mu > 0:
        g += 2.0 * mu * (x.sum() - n / 2.0)
    return g

def obj_active(x, n, active_idx, alpha, mu):
    c = compute_c5_vec(x, n)
    vals = c[active_idx]
    mx = vals.max()
    sh = alpha * (vals - mx)
    smx = sh.max()
    if smx > 400:
        val = mx + (smx + np.log(np.sum(np.exp(sh - smx)))) / alpha
    else:
        val = mx + np.log(np.sum(np.exp(sh))) / alpha
    if mu > 0:
        val += mu * (x.sum() - n / 2.0) ** 2
    return float(val)

def grad_active(x, n, active_idx, alpha, mu):
    c = compute_c5_vec(x, n)
    vals = c[active_idx]
    mx = vals.max()
    sh = alpha * (vals - mx)
    smx = sh.max()
    w = np.exp(sh - smx)
    w /= w.sum()
    g = active_grad(c, w, active_idx, x, n)
    if mu > 0:
        g += 2.0 * mu * (x.sum() - n / 2.0)
    return g

def upsample(h_old, n_old, n_new):
    if n_old == n_new:
        return h_old.copy()
    x_old = np.linspace(0, 2, n_old, endpoint=False) + 1.0/n_old
    x_new = np.linspace(0, 2, n_new, endpoint=False) + 1.0/n_new
    h_new = np.interp(x_new, x_old, h_old)
    return project_feasible(h_new, n_new)

def make_beatty(n, alpha_param):
    h = np.zeros(n)
    n_ones = n // 2
    positions = []
    for k in range(1, 4 * n):
        pos = int(k * alpha_param) % n
        if pos not in positions:
            positions.append(pos)
            if len(positions) >= n_ones:
                break
    for pos in positions:
        h[pos] = 1.0
    remaining = n / 2.0 - h.sum()
    if abs(remaining) > 1e-10:
        zeros = np.where(h < 0.5)[0]
        if len(zeros) > 0:
            h[zeros[0]] += remaining
    return project_feasible(h, n)

def make_random_binary(n, rng):
    h = np.zeros(n)
    n_ones = n // 2
    idx = rng.choice(n, size=n_ones, replace=False)
    h[idx] = 1.0
    return project_feasible(h, n)

def pair_exchange(h, n, i, j, d):
    """Try moving d from h[i] to h[j]. Returns (improved_h, improved_c) or (None, c)."""
    h[i] -= d
    h[j] += d
    h = np.clip(h, 0, 1)
    h = project_feasible(h, n)
    c = compute_c5(h, n)
    return h, c

def active_set_optimize(h, n, deadline, top_k=20, alphas=None, max_rounds=30):
    best_h = h.copy()
    best_c = compute_c5(h, n)
    bounds = [(0.0, 1.0)] * n
    if alphas is None:
        alphas = [5000, 20000, 100000, 500000, 2000000, 10000000]
    
    for rnd in range(max_rounds):
        if time.time() > deadline - 20:
            break
        c_vec = compute_c5_vec(best_h, n)
        max_val = c_vec.max()
        threshold = max_val - max(1e-9, 0.002 * max_val)
        active = np.where(c_vec >= threshold)[0]
        if len(active) > top_k:
            active = np.array(np.argsort(-c_vec[active])[:top_k])
        if len(active) == 0:
            break
        
        for alpha in alphas:
            if time.time() > deadline - 15:
                break
            maxit = max(200, int((deadline - time.time()) * 2))
            try:
                res = minimize(obj_active, best_h, jac=grad_active,
                              args=(n, active, alpha, 0.001), method='L-BFGS-B',
                              bounds=bounds,
                              options={'maxiter': maxit, 'ftol': 1e-20,
                                       'gtol': 1e-14, 'maxfun': maxit * 8,
                                       'maxls': 50, 'maxcor': 80})
                h_new = project_feasible(res.x, n)
                c_new = compute_c5(h_new, n)
                if c_new < best_c - 1e-15:
                    best_c = c_new
                    best_h = h_new
                # Re-evaluate active set after improvement
                if alpha > 100000:
                    break  # Move to next round
            except Exception:
                pass
    return best_h, best_c

def grad_descent_pair(h, n, deadline, max_steps=500000):
    best_h = h.copy()
    best_c = compute_c5(h, n)
    dx_val = 2.0 / n
    steps = 0
    step_sizes = [0.01, 0.005, 0.002, 0.001, 0.0005, 0.0002, 0.0001, 0.00005, 0.00002, 0.00001, 0.000005]
    
    for step in step_sizes:
        stagnant = 0
        while time.time() < deadline and steps < max_steps:
            c_vec = compute_c5_vec(best_h, n)
            max_val = c_vec.max()
            tol = max(1e-9, 0.001 * max_val)
            active = np.where(c_vec >= max_val - tol)[0]
            
            # Compute gradient at active lags (uniform weight)
            grad = np.zeros(n)
            for idx in active:
                k = idx - (n - 1)
                if k >= 0:
                    nv = n - k
                    if nv > 0:
                        grad[k:n] += (1.0 - best_h[0:nv]) * dx_val
                        grad[0:nv] += (-best_h[k:n]) * dx_val
                else:
                    kk = -k
                    nv = n - kk
                    if nv > 0:
                        grad[0:nv] += (1.0 - best_h[kk:n]) * dx_val
                        grad[kk:n] += (-best_h[0:nv]) * dx_val
            if len(active) > 0:
                grad /= len(active)
            
            # Find best pair to swap
            pos_mask = (grad > 1e-10) & (best_h > 1e-10) & (best_h < 1.0 - 1e-10)
            neg_mask = (grad < -1e-10) & (best_h > 1e-10) & (best_h < 1.0 - 1e-10)
            
            if not pos_mask.any() or not neg_mask.any():
                stagnant += 1
                if stagnant > 3:
                    break
                continue
            
            pos_idx = np.where(pos_mask)[0]
            neg_idx = np.where(neg_mask)[0]
            
            # Find best pair
            best_gain = 0
            best_i = -1
            best_j = -1
            for i in pos_idx[:30]:
                gi = grad[i]
                for j in neg_idx[:30]:
                    g = gi - grad[j]
                    if g > best_gain:
                        best_gain = g
                        best_i = i
                        best_j = j
            
            if best_i < 0 or best_gain < 1e-12:
                stagnant += 1
                if stagnant > 3:
                    break
                continue
            
            amt = min(step, best_h[best_i], 1.0 - best_h[best_j])
            if amt < 1e-12:
                break
            
            old_i = best_h[best_i]
            old_j = best_h[best_j]
            best_h[best_i] -= amt
            best_h[best_j] += amt
            best_h = project_feasible(best_h, n)
            c_new = compute_c5(best_h, n)
            steps += 1
            
            if c_new < best_c - 1e-16:
                best_c = c_new
                stagnant = 0
            else:
                best_h[best_i] = old_i
                best_h[best_j] = old_j
                best_h = project_feasible(best_h, n)
                stagnant += 1
                if stagnant > 10:
                    break
    return best_h, best_c

    # Phase 3: Subgradient + projection
    # Phase 4: Fine pair search (limited)

Let me think about the subgradient approach more carefully.

For the minimax problem: min_h max_k f_k(h)
The subgradient at h is the gradient of f_k(h) where k = argmax.
A standard approach (Khardon's algorithm, or just projected subgradient descent):
- h_{t+1} = project(h_t - alpha_t * subgrad_t)
- alpha_t = step size (diminishing)

For our problem, the "subgradient" is the correlation gradient at the single max lag. This is very cheap to compute.

But pure subgradient descent converges slowly. A better approach is the " averaged subgradient" or "Pixiu" method, but those are complex.

An alternative: use the subgradient information to guide the pair search. The subgradient tells us which h[i] should increase and which should decrease to reduce the max overlap. We just need to maintain the sum constraint.

OK, let me just write a clean, efficient solution. Here's my final plan:

1. n=1000
2. Run L-BFGS with smooth max, alpha from 10 to 500000 (each for ~20s)
3. Run active set L-BFGS (focus on top 10-30 lags), alpha from 10000 to 10000000
4. Run gradient-guided pair search (cheap, many iterations)
5. Run one more active set round
6. Return best found

Let me also add a "balancing" heuristic: after the main phases, check which lags are the top few, and try to equalize them with small adjustments.

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5_vec(h, n):
    dx = 2.0 / n
    return np.correlate(h, 1.0 - h, mode='full') * dx

def compute_c5(h, n):
    return float(compute_c5_vec(h, n).max())

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h.copy(), 0.0, 1.0)
    for _ in range(200):
        diff = target - h.sum()
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            room = 1.0 - h
            tot = room.sum()
            if tot < 1e-15:
                break
            h = h + (diff / tot) * room
        else:
            tot = h.sum()
            if tot < 1e-15:
                break
            h = h + (diff / tot) * h
    return np.clip(h, 0.0, 1.0)

def smooth_max_val(c, alpha):
    m = c.max()
    sh = alpha * (c - m)
    smx = sh.max()
    if smx > 400:
        val = m + (smx + np.log(np.sum(np.exp(sh - smx)))) / alpha
    else:
        val = m + np.log(np.sum(np.exp(sh))) / alpha
    return float(val)

def smooth_max_grad(c, alpha, x, n):
    m = c.max()
    sh = alpha * (c - m)
    smx = sh.max()
    w = np.exp(sh - smx)
    w /= w.sum()
    dx_val = 2.0 / n
    grad = np.zeros(n)
    for mm in range(len(c)):
        if w[mm] < 1e-13:
            continue
        k = mm - (n - 1)
        wg = w[mm] * dx_val
        if k >= 0:
            nv = n - k
            if nv > 0:
                grad[k:n] += wg * (1.0 - x[0:nv])
                grad[0:nv] += wg * (-x[k:n])
        else:
            kk = -k
            nv = n - kk
            if nv > 0:
                grad[0:nv] += wg * (1.0 - x[kk:n])
                grad[kk:n] += wg * (-x[0:nv])
    return grad

def active_smooth_obj(x, n, active_idx, alpha, mu):
    c = compute_c5_vec(x, n)
    vals = c[active_idx]
    mx = vals.max()
    sh = alpha * (vals - mx)
    smx = sh.max()
    if smx > 400:
        val = mx + (smx + np.log(np.sum(np.exp(sh - smx)))) / alpha
    else:
        val = mx + np.log(np.sum(np.exp(sh))) / alpha
    if mu > 0:
        val += mu * (x.sum() - n / 2.0) ** 2
    return float(val)

def active_smooth_grad(x, n, active_idx, alpha, mu):
    c = compute_c5_vec(x, n)
    vals = c[active_idx]
    mx = vals.max()
    sh = alpha * (vals - mx)
    smx = sh.max()
    w = np.exp(sh - smx)
    w /= w.sum()
    dx_val = 2.0 / n
    grad = np.zeros(n)
    for idx, wi in zip(active_idx, w):
        if wi < 1e-13:
            continue
        k = idx - (n - 1)
        wg = wi * dx_val
        if k >= 0:
            nv = n - k
            if nv > 0:
                grad[k:n] += wg * (1.0 - x[0:nv])
                grad[0:nv] += wg * (-x[k:n])
        else:
            kk = -k
            nv = n - kk
            if nv > 0:
                grad[0:nv] += wg * (1.0 - x[kk:n])
                grad[kk:n] += wg * (-x[0:nv])
    if mu > 0:
        grad += 2.0 * mu * (x.sum() - n / 2.0)
    return grad

def full_smooth_obj(x, n, alpha, mu):
    c = compute_c5_vec(x, n)
    val = smooth_max_val(c, alpha)
    if mu > 0:
        val += mu * (x.sum() - n / 2.0) ** 2
    return val

def full_smooth_grad(x, n, alpha, mu):
    c = compute_c5_vec(x, n)
    g = smooth_max_grad(c, alpha, x, n)
    if mu > 0:
        g += 2.0 * mu * (x.sum() - n / 2.0)
    return g

def upsample_h(h_old, n_old, n_new):
    if n_old == n_new:
        return project_feasible(h_old.copy(), n_new)
    x_old = np.linspace(0.0, 2.0, n_old)
    x_new = np.linspace(0.0, 2.0, n_new)
    h_new = np.interp(x_new, x_old, h_old)
    return project_feasible(h_new, n_new)

def make_beatty(n, alpha_param):
    h = np.zeros(n)
    n_ones = n // 2
    used = set()
    for k in range(1, 6 * n):
        pos = int(k * alpha_param) % n
        if pos not in used:
            used.add(pos)
            h[pos] = 1.0
            if len(used) >= n_ones:
                break
    remaining = n / 2.0 - h.sum()
    if abs(remaining) > 1e-10:
        zeros = np.where(h == 0)[0]
        if len(zeros) > 0:
            h[zeros[0]] += remaining
    return project_feasible(h, n)

def make_random_binary(n, rng):
    h = np.zeros(n)
    n_ones = n // 2
    idx = rng.choice(n, size=n_ones, replace=False)
    h[idx] = 1.0
    return project_feasible(h, n)

def phase_smooth_max(h, n, deadline, alphas, mu_list):
    best_h = h.copy()
    best_c = compute_c5(h, n)
    bounds = [(0.0, 1.0)] * n
    for i, (alpha, mu) in enumerate(zip(alphas, mu_list)):
        if time.time() > deadline - 10:
            break
        rem = deadline - time.time()
        if rem < 15:
            break
        maxit = max(100, min(5000, int(rem * 3)))
        try:
            res = minimize(full_smooth_obj, best_h, jac=full_smooth_grad,
                          args=(n, alpha, mu), method='L-BFGS-B',
                          bounds=bounds,
                          options={'maxiter': maxit, 'ftol': 1e-22,
                                   'gtol': 1e-16, 'maxfun': maxit * 12,
                                   'maxls': 60, 'maxcor': 100})
            h_new = project_feasible(res.x, n)
            c_new = compute_c5(h_new, n)
            if c_new < best_c - 1e-16:
                best_c = c_new
                best_h = h_new
        except Exception:
            pass
    return best_h, best_c

def phase_active(h, n, deadline, top_k=20, alphas=None, rounds=30):
    best_h = h.copy()
    best_c = compute_c5(h, n)
    bounds = [(0.0, 1.0)] * n
    if alphas is None:
        alphas = [10000, 50000, 200000, 1000000, 5000000, 20000000]
    for rnd in range(rounds):
        if time.time() > deadline - 15:
            break
        c_vec = compute_c5_vec(best_h, n)
        max_val = c_vec.max()
        threshold = max_val - max(1e-10, 0.0015 * max_val)
        active = np.where(c_vec >= threshold)[0]
        if len(active) > top_k:
            active = np.array(np.argsort(-c_vec[active])[:top_k])
        if len(active) == 0:
            break
        for alpha in alphas:
            if time.time() > deadline - 10:
                break
            rem = deadline - time.time()
            if rem < 10:
                break
            maxit = max(150, min(4000, int(rem * 2.5)))
            try:
                res = minimize(active_smooth_obj, best_h, jac=active_smooth_grad,
                              args=(n, active, alpha, 0.001), method='L-BFGS-B',
                              bounds=bounds,
                              options={'maxiter': maxit, 'ftol': 1e-22,
                                       'gtol': 1e-15, 'maxfun': maxit * 8,
                                       'maxls': 50, 'maxcor': 100})
                h_new = project_feasible(res.x, n)
                c_new = compute_c5(h_new, n)
                if c_new < best_c - 1e-16:
                    best_c = c_new
                    best_h = h_new
            except Exception:
                pass
    return best_h, best_c

def phase_grad_pair(h, n, deadline, step_sizes=None, max_steps=200000):
    best_h = h.copy()
    best_c = compute_c5(h, n)
    dx_val = 2.0 / n
    if step_sizes is None:
        step_sizes = [0.005, 0.002, 0.001, 0.0005, 0.0002, 0.0001, 0.00005, 0.00002, 0.00001, 0.000005]
    steps = 0
    for step in step_sizes:
        if time.time() > deadline - 5:
            break
        stagnant = 0
        while time.time() < deadline and steps < max_steps:
            c_vec = compute_c5_vec(best_h, n)
            max_val = c_vec.max()
            tol = max(1e-10, 0.001 * max_val)
            active = np.where(c_vec >= max_val - tol)[0]
            if len(active) == 0:
                break
            grad = np.zeros(n)
            for idx in active:
                k = idx - (n - 1)
                if k >= 0:
                    nv = n - k
                    if nv > 0:
                        grad[k:n] += (1.0 - best_h[0:nv]) * dx_val
                        grad[0:nv] += (-best_h[k:n]) * dx_val
                else:
                    kk = -k
                    nv = n - kk
                    if nv > 0:
                        grad[0:nv] += (1.0 - best_h[kk:n]) * dx_val
                        grad[kk:n] += (-best_h[0:nv]) * dx_val
            grad /= len(active)
            pos_mask = (grad > 1e-8) & (best_h > 5e-5) & (best_h < 1.0 - 5e-5)
            neg_mask = (grad < -1e-8) & (best_h > 5e-5) & (best_h < 1.0 - 5e-5)
            if not pos_mask.any() or not neg_mask.any():
                stagnant += 1
                if stagnant > 5:
                    break
                continue
            pos_idx = np.where(pos_mask)[0]
            neg_idx = np.where(neg_mask)[0]
            best_gain = 0.0
            best_i = -1
            best_j = -1
            for i in pos_idx[:40]:
                gi = grad[i]
                for j in neg_idx[:40]:
                    g = gi - grad[j]
                    if g > best_gain:
                        best_gain = g
                        best_i = i
                        best_j = j
            if best_i < 0 or best_gain < 1e-10:
                stagnant += 1
                if stagnant > 5:
                    break
                continue
            amt = min(step, best_h[best_i], 1.0 - best_h[best_j])
            if amt < 1e-12:
                break
            old_i = best_h[best_i]
            old_j = best_h[best_j]
            best_h[best_i] -= amt
            best_h[best_j] += amt
            best_h = project_feasible(best_h, n)
            c_new = compute_c5(best_h, n)
            steps += 1
            if c_new < best_c - 1e-16:
                best_c = c_new
                stagnant = 0
            else:
                best_h[best_i] = old_i
                best_h[best_j] = old_j
                best_h = project_feasible(best_h, n)
                stagnant += 1
                if stagnant > 15:
                    break
    return best_h, best_c

def phase_fine_pairs(h, n, deadline, radius=20, deltas=None, max_evals=2000):
    best_h = h.copy()
    best_c = compute_c5(h, n)
    if deltas is None:
        deltas = [0.001, 0.0005, 0.0002, 0.0001, 0.00005, 0.00002, 0.00001]
    total_evals = 0
    for d in deltas:
        if time.time() > deadline - 3:
            break
        for i in range(n):
            if time.time() > deadline - 3 or total_evals > max_evals:
                break
            lo = max(0, i - radius)
            hi = min(n, i + radius + 1)
            for j in range(lo, hi):
                if i == j or total_evals > max_evals:
                    continue
                if best_h[i] + d <= 1.0 + 1e-10 and best_h[j] - d >= -1e-10:
                    old_i = best_h[i]
                    old_j = best_h[j]
                    best_h[i] += d
                    best_h[j] -= d
                    best_h = project_feasible(best_h, n)
                    c = compute_c5(best_h, n)
                    total_evals += 1
                    if c < best_c - 1e-16:
                        best_c = c
                    else:
                        best_h[i] = old_i
                        best_h[j] = old_j
                        best_h = project_feasible(best_h, n)
                if best_h[i] - d >= -1e-10 and best_h[j] + d <= 1.0 + 1e-10:
                    old_i = best_h[i]
                    old_j = best_h[j]
                    best_h[i] -= d
                    best_h[j] += d
                    best_h = project_feasible(best_h, n)
                    c = compute_c5(best_h, n)
                    total_evals += 1
                    if c < best_c - 1e-16:
                        best_c = c
                    else:
                        best_h[i] = old_i
                        best_h[j] = old_j
                        best_h = project_feasible(best_h, n)
    return best_h, best_c

def run(seed=42, budget_s=1100, **kwargs):
    t0 = time.time()
    deadline = t0 + budget_s - 5
    rng = np.random.RandomState(seed)

    try:
        h0 = np.array(initial_h_values, dtype=float).copy()
        n0 = len(h0)
    except Exception:
        h0 = np.full(500, 0.5)
        n0 = 500

    n = 1000
    h = upsample_h(h0, n0, n)
    best_c = compute_c5(h, n)
    best_h = h.copy()

    golden = (1.0 + np.sqrt(5.0)) / 2.0
    alts = [
        make_beatty(n, golden / 2.0),
        make_beatty(n, np.sqrt(2.0) / 2.0),
        make_beatty(n, np.sqrt(3.0) / 3.0),
        make_random_binary(n, rng),
        make_random_binary(n, rng),
    ]
    for alt in alts:
        c_alt = compute_c5(alt, n)
        if c_alt < best_c:
            best_c = c_alt
            best_h = alt.copy()

    # Phase 1: Smooth max L-BFGS warmup
    p1_end = min(t0 + 180, deadline - 500)
    if p1_end > t0 + 20:
        h1, c1 = phase_smooth_max(best_h, n, p1_end,
            alphas=[10, 50, 200, 1000, 5000, 20000, 100000, 500000],
            mu_list=[0.05, 0.02, 0.01, 0.005, 0.002, 0.001, 0.0005, 0.0002])
        if c1 < best_c:
            best_c = c1
            best_h = h1

    # Phase 2: Active set optimization (first round)
    p2_end = min(t0 + 420, deadline - 350)
    if p2_end > time.time() + 20:
        h2, c2 = phase_active(best_h, n, p2_end, top_k=15,
                              alphas=[5000, 20000, 100000, 500000, 2000000, 10000000, 50000000],
                              rounds=30)
        if c2 < best_c:
            best_c = c2
            best_h = h2

    # Phase 3: Gradient-guided pair search
    p3_end = min(t0 + 620, deadline - 250)
    if p3_end > time.time() + 20:
        h3, c3 = phase_grad_pair(best_h, n, p3_end,
            step_sizes=[0.003, 0.001, 0.0005, 0.0002, 0.0001, 0.00005, 0.00002, 0.00001, 0.000005],
            max_steps=200000)
        if c3 < best_c:
            best_c = c3
            best_h = h3

    # Phase 4: Active set (second round, more aggressive)
    p4_end = min(t0 + 800, deadline - 180)
    if p4_end > time.time() + 20:
        h4, c4 = phase_active(best_h, n, p4_end, top_k=25,
                              alphas=[20000, 100000, 500000, 2000000, 10000000, 50000000, 200000000],
                              rounds=25)
        if c4 < best_c:
            best_c = c4
            best_h = h4

    # Phase 5: Fine pair search
    p5_end = min(t0 + 920, deadline - 80)
    if p5_end > time.time() + 15:
        h5, c5 = phase_fine_pairs(best_h, n, p5_end, radius=15,
                                   deltas=[0.0005, 0.0002, 0.0001, 0.00005, 0.00002, 0.00001],
                                   max_evals=5000)
        if c5 < best_c:
            best_c = c5
            best_h = h5

    # Phase 6: Final gradient pair search
    p6_end = min(t0 + 1020, deadline - 30)
    if p6_end > time.time() + 10:
        h6, c6 = phase_grad_pair(best_h, n, p6_end,
            step_sizes=[0.0005, 0.0002, 0.0001, 0.00005, 0.00002, 0.00001, 0.000005, 0.000002],
            max_steps=100000)
        if c6 < best_c:
            best_c = c6
            best_h = h6

    # Phase 7: Final active set polish
    if time.time() < deadline - 15:
        h7, c7 = phase_active(best_h, n, deadline - 5, top_k=30,
                              alphas=[100000, 1000000, 10000000, 100000000],
                              rounds=10)
        if c7 < best_c:
            best_c = c7
            best_h = h7

    best_h = project_feasible(best_h, n)
    best_c = compute_c5(best_h, n)

    return best_h, best_c, n
