This is valid as a subgradient of the max (since at the max, the subgradient of f is the subgradient of the active component).

The subgradient descent step: h ← P_feasible(h - α * ∇O_{k*})

where P_feasible is the projection onto [0,1]^n ∩ {sum = n/2}.

For the learning rate, I can use a diminishing schedule: α_t = 1/sqrt(t) or α_t = 1/t.

```python
            if ip == j:
                t1 = 1.0  # 1 - h_new[j] = 1 - 0
            elif ip == i:
                t1 = 0.0  # 1 - h_new[i] = 1 - 1
            else:
                t1 = 1.0 - h[ip]
        t2 = 0.0
        if 0 <= j + l < n:
            jp = j + l
            if jp == i:
                t2 = 0.0  # 1 - h_new[i] = 1 - 1
            elif jp == j:
                t2 = 1.0  # 1 - h_new[j] = 1 - 0
            else:
                t2 = 1.0 - h[jp]
        t3 = 0.0
        if 0 <= i - l < n:
            im = i - l
            if im == j:
                t3 = 1.0  # h_old[j] = 1
            elif im == i:
                t3 = 0.0  # h_old[i] = 0
            else:
                t3 = h[im]
        t4 = 0.0
        if 0 <= j - l < n:
            jm = j - l
            if jm == i:
                t4 = 0.0  # h_old[i] = 0
            elif jm == j:
                t4 = 1.0  # h_old[j] = 1
            else:
                t4 = h[jm]
        
        delta[ml] = t1 - t2 - t3 + t4
    
    return delta
```

Wait, this is O(n) per pair with a Python loop over 2n-1 elements. For n=250, that's 499 iterations in Python, each doing a few operations. That's fast.

But I can vectorize it:

```python
def compute_delta_corr(h, i, j, n):
    """Compute delta for all 2n-1 correlation entries when h[i]:0→1, h[j]:1→0."""
    lags = np.arange(-(n-1), n)  # length 2n-1
    ar = np.arange(2*n-1)
    
    # term1: (1 - h_new[i+l])
    idx1 = i + lags
    mask1 = (idx1 >= 0) & (idx1 < n)
    # h_new at idx1: same as h except h[j]=0, h[i]=1
    t1 = np.zeros(2*n-1)
    t1[mask1] = 1.0 - h[idx1[mask1]]
    # Fix: if idx1 == j, h_new[j] = 0, so 1-h_new[j] = 1
    t1[mask1 & (idx1 == j)] = 1.0
    # Fix: if idx1 == i (l=0), h_new[i] = 1, so 1-h_new[i] = 0
    t1[mask1 & (idx1 == i)] = 0.0
    
    # term2: (1 - h_new[j+l])
    idx2 = j + lags
    mask2 = (idx2 >= 0) & (idx2 < n)
    t2 = np.zeros(2*n-1)
    t2[mask2] = 1.0 - h[idx2[mask2]]
    t2[mask2 & (idx2 == i)] = 0.0  # 1 - h_new[i] = 0
    t2[mask2 & (idx2 == j)] = 1.0  # 1 - h_new[j] = 1
    
    # term3: h_old[i-l]
    idx3 = i - lags
    mask3 = (idx3 >= 0) & (idx3 < n)
    t3 = np.zeros(2*n-1)
    t3[mask3] = h[idx3[mask3]]
    # h_old[i]=0, h_old[j]=1, so no fix needed (we're using old values)
    # But if idx3 == i, h[i]=0 (correct). If idx3 == j, h[j]=1 (correct).
    
    # term4: h_old[j-l]
    idx4 = j - lags
    mask4 = (idx4 >= 0) & (idx4 < n)
    t4 = np.zeros(2*n-1)
    t4[mask4] = h[idx4[mask4]]
    
    return t1 - t2 - t3 + t4
```

This is fully vectorized and O(n) in numpy. For n=250, each call is 499 operations on small arrays. Very fast.
