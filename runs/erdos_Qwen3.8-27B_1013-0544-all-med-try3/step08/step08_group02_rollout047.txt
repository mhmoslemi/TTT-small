- Projected gradient: take a step in -grad direction, then project

This is essentially what the previous code's `subgrad_refine` does. Let me make it more effective.

Actually, let me think about this more carefully. The maximum of the correlation vector is achieved at one or more shifts. The gradient of the max (using the smooth max with infinite alpha) is the average of the gradients of the active shifts.

For a small transfer δ from position j to position i:
- h[i] += δ, h[j] -= δ
- The change in c_k is:
  ∂c_k/∂h[i] * δ + ∂c_k/∂h[j] * (-δ) = δ * (∂c_k/∂h[i] - ∂c_k/∂h[j])

For the max to decrease, we need:
δ * (∂c_max/∂h[i] - ∂c_max/∂h[j]) < 0

So we want ∂c_max/∂h[i] < ∂c_max/∂h[j], meaning we transfer from high-gradient to low-gradient positions.

- Use a backtracking line search instead of fixed step

∂c_k/∂h[x] = dx * (1 - h[x+k]) - dx * h[x-k] (for valid indices)

The second derivative:
∂²c_k/∂h[x]∂h[y] = -dx * δ_{y,x+k} - dx * δ_{y,x-k}

So for a transfer δ from j to i:
Δc_k ≈ dx * δ * [(1-h[i+k]) - h[i-k] - (1-h[j+k]) + h[j-k]] + dx * δ² * [higher order]

Actually the second order term:
When h[i] changes by δ and h[j] changes by -δ:
The change in ∑ h[x]*(1-h[x+k]) is:
- Term where x=i: δ*(1-h[i+k])
- Term where x+k=i (i.e., x=i-k): h[i-k]*(-δ) = -δ*h[i-k]
- Term where x=j: -δ*(1-h[j+k])
- Term where x+k=j (i.e., x=j-k): h[j-k]*(δ) = δ*h[j-k]

So the first-order change is:

And the second-order term (if i and j are k apart for the specific shift k):
If j = i+k: the term h[i]*(1-h[j]) = h[i]*(1-h[i+k]) changes by δ*(1-h[i+k]) - h[i]*(−δ) = δ*(1-h[i+k]+h[i])

For the local search, I'll use the following efficient approach:
1. Compute the gradient of the smooth max at the current point
2. For each position i, the "descent direction" is -grad[i]
3. Transfer from positions with high grad to positions with low grad
4. Use a line search to find the optimal δ

But this is still O(n²) if we try all pairs. Let me limit it:
- Only consider pairs (i,j) where grad[i] - grad[j] has the right sign
- Use a limited number of pairs per iteration (e.g., the top 50 most promising)

Actually, for n=500, O(n²) = 250,000 is manageable if each evaluation is fast. The correlate is O(n) in numpy (it's implemented in C). So 250,000 * O(500) = 125M operations. At ~100M ops/sec, that's ~1.25 seconds per full pass. With 10 passes, that's 12.5 seconds. Feasible!

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5_vec(h, n):
    dx = 2.0 / n
    return np.correlate(h, 1 - h, mode='full') * dx

def compute_c5(h, n):
    return float(compute_c5_vec(h, n).max())

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h.copy(), 0.0, 1.0)
    for _ in range(5000):
        diff = target - h.sum()
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            room = 1.0 - h
            mask = room > 1e-12
            tot = room[mask].sum()
            if tot < 1e-12:
                break
            h[mask] += (diff / tot) * room[mask]
        else:
            mask = h > 1e-12
            tot = h[mask].sum()
            if tot < 1e-12:
                break
            h[mask] += (diff / tot) * h[mask]
    return np.clip(h, 0.0, 1.0)

def sm_obj(h, n, alpha, mu):
    c = compute_c5_vec(h, n)
    m = c.max()
    sh = alpha * (c - m)
    mx = sh.max()
    if mx > 500:
        val = m + (mx + np.log(np.sum(np.exp(sh - mx)))) / alpha
    else:
        val = m + np.log(np.sum(np.exp(sh))) / alpha
    if mu > 0:
        val += mu * (h.sum() - n/2.0)**2
    return float(val)

def sm_grad(h, n, alpha, mu):
    c = compute_c5_vec(h, n)
    m = c.max()
    sh = alpha * (c - m)
    mx = sh.max()
    w = np.exp(sh - mx)
    w /= w.sum()
    dx = 2.0 / n
    grad = np.zeros(n)
    for mm in range(2*n-1):
        if w[mm] < 1e-14:
            continue
        k = mm - (n-1)
        wm = w[mm] * dx
        if k >= 0:
            nv = n - k
            grad[0:nv] += wm * (1.0 - h[k:n])
            grad[k:n] += wm * (-h[0:nv])
        else:
            kk = -k
            nv = n - kk
            grad[kk:n] += wm * (1.0 - h[0:nv])
            grad[0:nv] += wm * (-h[kk:n])
    if mu > 0:
        grad += 2.0 * mu * (h.sum() - n/2.0)
    return grad

def act_obj(h, n, active, alpha, mu):
    c = compute_c5_vec(h, n)
    vals = c[active]
    mx = vals.max()
    sh = alpha * (vals - mx)
    smx = sh.max()
    if smx > 500:
        val = mx + (smx + np.log(np.sum(np.exp(sh - smx)))) / alpha
    else:
        val = mx + np.log(np.sum(np.exp(sh))) / alpha
    if mu > 0:
        val += mu * (h.sum() - n/2.0)**2
    return float(val)

def act_grad(h, n, active, alpha, mu):
    c = compute_c5_vec(h, n)
    vals = c[active]
    mx = vals.max()
    sh = alpha * (vals - mx)
    smx = sh.max()
    w = np.exp(sh - smx)
    w /= w.sum()
    dx = 2.0 / n
    grad = np.zeros(n)
    for wi, idx in zip(w, active):
        k = idx - (n-1)
        wm = wi * dx
        if k >= 0:
            nv = n - k
            grad[0:nv] += wm * (1.0 - h[k:n])
            grad[k:n] += wm * (-h[0:nv])
        else:
            kk = -k
            nv = n - kk
            grad[kk:n] += wm * (1.0 - h[0:nv])
            grad[0:nv] += wm * (-h[kk:n])
    if mu > 0:
        grad += 2.0 * mu * (h.sum() - n/2.0)
    return grad

def lbfgs_run(h, n, deadline, alphas, mu=0.01):
    best_h = project_feasible(h, n)
    best_c = compute_c5(best_h, n)
    bounds = [(0.0, 1.0)] * n
    for alpha in alphas:
        rem = deadline - time.time()
        if rem < 10:
            break
        maxit = max(500, int(rem * 2.5))
        try:
            res = minimize(sm_obj, best_h, jac=sm_grad,
                          args=(n, alpha, mu), method='L-BFGS-B',
                          bounds=bounds,
                          options={'maxiter': maxit, 'ftol': 1e-22,
                                   'gtol': 1e-18, 'maxfun': maxit*10,
                                   'maxls': 50, 'maxcor': 60})
            h_new = project_feasible(res.x, n)
            c_new = compute_c5(h_new, n)
            if c_new < best_c:
                best_c = c_new
                best_h = h_new
        except:
            pass
    return best_h, best_c

def active_refine(h, n, deadline):
    best_h = project_feasible(h, n)
    best_c = compute_c5(best_h, n)
    bounds = [(0.0, 1.0)] * n
    alpha_list = [100000, 500000, 2000000, 10000000, 50000000]
    for _ in range(20):
        if time.time() > deadline - 5:
            break
        c_vec = compute_c5_vec(best_h, n)
        max_val = c_vec.max()
        tol = max(1e-8, 0.0001 * max_val)
        active = np.where(c_vec >= max_val - tol)[0]
        if len(active) > 8:
            active = np.array(np.argsort(-c_vec[active])[:8])
        for alpha in alpha_list:
            if time.time() > deadline - 3:
                break
            maxit = max(300, int((deadline - time.time()) * 1.5))
            try:
                res = minimize(act_obj, best_h, jac=act_grad,
                              args=(n, active, alpha, 0.001), method='L-BFGS-B',
                              bounds=bounds,
                              options={'maxiter': maxit, 'ftol': 1e-22,
                                       'gtol': 1e-18, 'maxfun': maxit*10,
                                       'maxls': 40, 'maxcor': 40})
                h_new = project_feasible(res.x, n)
                c_new = compute_c5(h_new, n)
                if c_new < best_c - 1e-16:
                    best_c = c_new
                    best_h = h_new
            except:
                pass
    return best_h, best_c

def pair_descent(h, n, deadline):
    best_h = project_feasible(h, n)
    best_c = compute_c5(best_h, n)
    deltas = [0.002, 0.001, 0.0005, 0.0002, 0.0001]
    for d in deltas:
        improved = True
        while improved and time.time() < deadline - 1:
            improved = False
            for i in range(0, n, 1):
                if time.time() > deadline - 1:
                    break
                for j in range(i+1, n, 1):
                    if time.time() > deadline - 1:
                        break
                    # Only try nearby pairs for speed with large n
                    if n > 800 and abs(i-j) > 100:
                        continue
                    if best_h[i] + d <= 1.0 and best_h[j] - d >= 0.0:
                        best_h[i] += d; best_h[j] -= d
                        best_h = project_feasible(best_h, n)
                        c = compute_c5(best_h, n)
                        if c < best_c - 1e-17:
                            best_c = c
                            improved = True
                        else:
                            best_h[i] -= d; best_h[j] += d
                    if best_h[i] - d >= 0.0 and best_h[j] + d <= 1.0:
                        best_h[i] -= d; best_h[j] += d
                        best_h = project_feasible(best_h, n)
