def binary_simulated_annealing(h, n, deadline, T0=1.0, T1=0.01, max_sweeps=100):
    """Simulated annealing for binary optimization."""
    h = h.copy().astype(float)
    dx = 2.0 / n
    g = np.correlate(h, 1 - h, mode='full') * dx
    current_c = g.max()
    best_h = h.copy()
    best_c = current_c
    
    ones = list(np.where(h == 1)[0])
    zeros = list(np.where(h == 0)[0])
    
    total_sweeps = max_sweeps
    for sweep in range(total_sweeps):
        if time.time() > deadline:
            break
        T = T0 * (T1 / T0) ** (sweep / total_sweeps)
        for _ in range(len(ones)):  # one swap per "temperature step"
            if time.time() > deadline:
                break
            i = random.choice(ones)  # or random
            j = random.choice(zeros)
            h[i], h[j] = 0, 1
            ones.remove(i)
            ones.append(j)
            zeros.remove(j)
            zeros.append(i)
            g = np.correlate(h, 1 - h, mode='full') * dx
            new_c = g.max()
            delta = new_c - current_c
            if delta < 0 or random.random() < np.exp(-delta / T):

                if new_c < best_c:
                    best_c = new_c
                    best_h = h.copy()

The smooth approximation max_k g[k] ≈ (∑ g[k]^p)^(1/p) for large p is a standard technique. For p=100 or p=200, this is a very good approximation and is smooth enough for gradient-based optimization.

The gradient of (∑ g[k]^p)^(1/p) with respect to h[i] can be computed analytically:
∂/∂h[i] [(∑ g[k]^p)^(1/p)] = (1/p) (∑ g[k]^p)^(1/p-1) * ∑_k p*g[k]^(p-1) * ∂g[k]/∂h[i]

And ∂g[k]/∂h[i] can be computed from the correlation structure.

Actually, for the 'full' correlation g[m] = ∑_l h[l] * (1-h[l+m-n+1]):
∂g[m]/∂h[i] = (1-h[i+m-n+1]) + h[i-(m-n+1)] (when the indices are valid)
= (1-h[i+k]) + h[i-k] where k = m-n+1 (when valid)

Wait, let me be more careful:
g[m] = ∑_l h[l] * f[l+m-n+1] where f = 1-h

∂g[m]/∂h[i] = ∂/∂h[i] ∑_l h[l] * f[l+m-n+1]
= f[i+m-n+1] + ∑_l h[l] * ∂f[l+m-n+1]/∂h[i]
= (1-h[i+m-n+1]) + ∑_l h[l] * (-δ(l+m-n+1, i))
= (1-h[i+m-n+1]) - h[i-m+n-1]

where the first term is valid when 0≤i+m-n+1<n, and the second term is valid when 0≤i-m+n-1<n.

So: ∂g[m]/∂h[i] = (1-h[i+m-n+1]) * [0≤i+m-n+1<n] - h[i-m+n-1] * [0≤i-m+n-1<n]

This is O(n) per (i,m) pair, and we have O(n²) such pairs, so the full gradient is O(n³). For n=250, that's 15.6M operations, which is feasible.

But actually, for the power approximation, the gradient is:
∇f = (1/p) * (∑g^p)^(1/p-1) * ∑_k p*g[k]^(p-1) * ∇g[k]

The inner sum ∑_k p*g[k]^p-1 * ∇g[k] is a weighted sum of the correlation derivatives. This can be computed as a convolution!

∂/∂h[i] ∑_k w[k] * g[k] = ∑_k w[k] * [(1-h[i+k]) - h[i-k]] (with appropriate bounds)

This is like a weighted "cross-correlation" of w with h and (1-h). It can be computed in O(n) per i using FFT, or O(n²) total using direct computation.

For n=250, O(n²) = 62500 operations for the full gradient. That's very fast!

```python
def power_objective(h, n, p):
    """Compute (sum g^p)^(1/p) approximation to max g."""
    dx = 2.0 / n
    g = np.correlate(h, 1-h, mode='full') * dx
    return (np.sum(g**p))**(1.0/p)

def power_gradient(h, n, p):
    """Gradient of (sum g^p)^(1/p) with respect to h."""
    dx = 2.0 / n
    g = np.correlate(h, 1-h, mode='full') * dx
    # w[k] = p * g[k]^(p-1) * (1/p) * (sum g^p)^(1/p-1) = g[k]^(p-1) * (sum g^p)^(1/p-1)
    S = np.sum(g**p)
    w = g**(p-1) * S**(1.0/p - 1.0)
    # Now compute grad[i] = sum_k w[k] * d_gk/d_hi
    # d_gk/d_hi = (1-h[i+k]) - h[i-k] (with bounds)
    # This is: cross_corr(w, 1-h) - cross_corr(w, h) evaluated at position i
    # More precisely:
    # grad[i] = sum_{k: valid} w[k] * (1-h[i+k]) - sum_{k: valid} w[k] * h[i-k]
    # = sum_k w[k]*(1-h[i+k]) - sum_k w[k]*h[i-k]
    # The first sum is like a correlation of w with (1-h)
    # The second sum is like a correlation of w with h (reversed)
    
    # Using the 'full' correlate:
    # np.correlate(a, b, 'full')[m] = sum_i a[i] * b[i+m-n+1] (for appropriate lengths)
    # Actually, let me just use direct computation for clarity (n=250 is small)
    
    ng = len(g)  # 2n-1
    grad = np.zeros(n)
    
    # g[m] corresponds to shift k = m - n + 1
    # d_g[m]/d_h[i] = (1-h[i+k]) if 0<=i+k<n, minus h[i-k] if 0<=i-k<n
    # where k = m-n+1
    
    for m in range(ng):
        k = m - n + 1
        wkm = w[m]
        if abs(wkm) < 1e-15:
            continue
        # (1-h[i+k]) part: valid for i in max(0,-k) to min(n-1-k, n-1)
        i_lo = max(0, -k)
        i_hi = min(n - 1, n - 1 - k)
        if i_lo <= i_hi:
            grad[i_lo:i_hi+1] += wkm * (1 - h[i_lo+k:i_hi+k+1])
        # -h[i-k] part: valid for i in max(0,k) to min(n-1, n-1+k)
        i_lo2 = max(0, k)
        i_hi2 = min(n - 1, n - 1 + k)
        if i_lo2 <= i_hi2:
            grad[i_lo2:i_hi2+1] -= wkm * h[i_lo2-k:i_hi2-k+1]
    
    return grad
```
