Actually, let me reconsider the approach. The key insight is:

For a pairwise move h[i] += ε, h[j] -= ε, the change in C₅ is approximately:
ΔC₅ ≈ ε * (g[i] - g[j]) where g is the subgradient

So the best move is to find (i,j) that maximizes g[i] - g[j] (for the + direction) or g[j] - g[i] (for the - direction).

But C₅ is not smooth (it's a max), so this is only a first-order approximation. Still, it should guide the search well.

Let me use this to create a more efficient coordinate descent:

1. Compute subgradient g
2. Find the pair (i,j) that maximizes g[i] - g[j] (move from j to i)
3. Try that move with various step sizes
4. If accepted, recompute g and repeat
5. If not, try the next best pair

This is like a "best improvement" coordinate descent.

But computing all n² pairs is expensive. Instead, I can:
- Sort by gradient: i₁ > i₂ > ... > iₙ
- The best pair is (i₁, iₙ) (move from iₙ to i₁)
- Also try (i₁, i_{n-1}), (i₂, iₙ), etc.

This is O(n log n) per iteration.

            for i in top_up:
                if found: break
                for j in top_dn:
                    if i == j: continue
                    h[i] += step
                    h[j] -= step
                    c = compute_c5(h, n)
                    if c < best_c - 1e-15:
                        best_c = c
                        total_moves += 1
                        found = True
                        break
                    else:
                        h[i] -= step
                        h[j] += step
            if not found:
                stall += 1
                # Try random moves
                for _ in range(20):
                    if time.time() > deadline: return h, best_c
                    i = rng.randint(n)
                    j = rng.randint(n)
                    if i == j: continue
                    if h[i] + step <= 1.0 + 1e-10 and h[j] - step >= -1e-10:
                        h[i] += step
                        h[j] -= step
                        c = compute_c5(h, n)
                        if c < best_c - 1e-15:
                            best_c = c
                            total_moves += 1
                            found = True
                            break
                        else:
                            h[i] -= step
                            h[j] += step
                if not found:
                    stall += 1
            else:
                stall = 0
                h = np.clip(h, 0.0, 1.0)
                h = project_feasible(h, n)
    
    return h, best_c

def smooth_obj(x, n, alpha, mu):
    c = compute_c5_vec(x, n)
    m = c.max()
    sh = alpha * (c - m)
    mx = sh.max()
    if mx > 500:
        val = m + (mx + np.log(np.sum(np.exp(sh - mx)))) / alpha
    else:
        val = m + np.log(np.sum(np.exp(sh))) / alpha
    val += mu * (x.sum() - n / 2.0) ** 2
    return float(val)

def smooth_grad_fn(x, n, alpha, mu):
    c = compute_c5_vec(x, n)
    m = c.max()
    sh = alpha * (c - m)
    mx = sh.max()
    w = np.exp(sh - mx)
    w /= w.sum()
    grad = np.zeros(n)
    for mm in range(2 * n - 1):
        if w[mm] < 1e-12:
            continue
        g = shift_grad(x, n, mm)
        grad += w[mm] * g
    grad += 2.0 * mu * (x.sum() - n / 2.0)
    return grad
