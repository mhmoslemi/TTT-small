### 2. Mathspecification

**Representation**: Piecewise-constant function $h(x)$ approximated by $n$ samples $h[i]$ on $[0,2]$

**Variables**: $h[i] \in \mathbb{R}, 0 \leq h[i] \leq 1$

**Objective**:
$$\min_{h} \max_{k=-\infty}^{\infty} \Bigg| \int_0^2 h(x)(1-h(x+k))  dx \Bigg|$$
for integer shifts $k$, measured discretely via convolution.

**Constraints**:
1. $0 \leq h[i] \leq 1, \forall i$
2. $\sum_{i} h[i] \frac{2}{n} = 1 \iff \sum_{i} h[i] = \frac{n}{2}$

**Parametrization**: Use Fourier series truncation at $N_{\text{freq}}$ terms to enforce statistical regularity. Let $h(x) = \sum_{j=1}^{N_{\text{freq}}} a_j \cdot \sin(2\pi j x)$ for $x \in [0,0.5]$, and repeat periodic boundary.

**Critical Insight**: The Fourier transform of the autocorrelation $\hat{S}(\omega)$ shows optimization is equivalent to setting $\hat{S}(\omega) \propto |\omega|$ for the optimal spectrum.

### 3. Implementation Procedure

**Steps**:
a) **Period Detection & Index Transformation**  
   - Define: $I_{\text{max}} = \round{\sqrt{n}}$  
   - Compute fundamental harmonic $k_{\text{freq}} = \floor{\sqrt{n}}$

$b) **HarmonicGenerate**($n, N_{\text{freq}}$, $\alpha=1.3$, $\beta=0.8$):
   - Ensure $n$ is even
   - Initialize coefficients $a_j \sim \mathcal{U}(0.7,0.9)$ for $j=1$ to $N_{\text{freq}}$, clipped
   - Apply frequency tapering: $a_j = a_j \cdot \exp(-(j/N_{\text{freq}})^{0.5})$
   - Normalize $\sum a_j = \alpha$ while retaining intervals
   - Project to [0,1] via soft clipping: $\exp(a_j)/(\sum \exp(a_j))$

c) **OverlapEstimate**($h$, $n$):
   - Compute convolution via FFT
   - Find peak using Simpson's rule
   - Return max(peak, $\beta \cdot \max_j\mathbb{E}[a_j])$

d) **ParRefine**($h$, $n$, $\tau=0.0005$):
   - Use $m = \round{\log_2(n)} \times I_{\text{max}}$ phase iterations
   - L-BFGS-B on projected space with bound tightening
   - Early termination if improvement < $\tau$

e) Run **ParGenerate** and **ParRefine** with $n \in \{2048, 4096, \dots\}$ until $n/2 > 10^6$ samples
  
f) Post-filter out candidates scoring > initial record
