Heuristic: for the peak shift k*, we want p_j[k*] to be as large as possible (to reduce corr[k*] + p_i[k*] - p_j[k*]).

This reduces the search to O(n) per i (just look up the best j for the relevant shift), giving O(n²) per sweep instead of O(n³).

Actually, it's even simpler: for the current worst shift k*, the delta at k* is:
delta[k*] = p_i[k*] - p_j[k*]

To minimize corr[k*] + delta[k*], we want to maximize p_j[k*] (for a fixed i). And we also need p_i[k*] to be small.

So the greedy approach:
1. Find k* = argmax(corr)
2. For each i in zeros, compute score_i = p_i[k*] (we want this to be small or negative)
3. For each j in ones, compute score_j = p_j[k*] (we want this to be large)
4. Try the pair (i, j) that maximizes (score_j - score_i) = p_j[k*] - p_i[k*]
5. Check if the full max decreases (compute the full new_max)
6. If yes, accept; if no, try the next best pair

Actually, for a fixed h[i] = t, corr_k is:
- If i and i+s_k are both in [0,n): corr_k = (1-h[i+s_k])*t + (rest)
- If i and i-s_k are both in [0,n): corr_k = -h[i-s_k]*t + (rest)

- Neither: corr_k = (rest) (independent of t)

This gives a coordinate descent method! At each step:
1. Pick variable i (cyclically or randomly)
2. Compute the current contribution of h[i] to each corr_k
3. Find the optimal h[i] that minimizes the max corr (subject to the sum constraint)
4. Update h[i]

The sum constraint makes this slightly tricky. If we change h[i] by δ, we need to change some other h[j] by -δ to maintain the sum. This couples the coordinates.

Alternative: use a Lagrangian relaxation for the sum constraint. Minimize:
max_k corr_k + λ * (sum(h) - n/2)

For fixed λ, the optimal h[i] is found by minimizing:
max_k (a_k * h[i] + b_k) + λ * h[i]

def compute_c5(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1 - h, mode='full')

def project_to_sum(h, target):
    """Project h onto {x: sum(x) = target, 0 <= x <= 1} via bisection on lambda."""
    def sum_at_lam(lam):
        return np.clip(h + lam, 0.0, 1.0).sum()
    lo = -h.max() - 2.0
    hi = 1.0 - h.min() + 2.0
    for _ in range(80):
        mid = (lo + hi) * 0.5
        if sum_at_lam(mid) < target:
            lo = mid
        else:
            hi = mid
    return np.clip(h + (lo + hi) * 0.5, 0.0, 1.0)

def smoothed_max_gradient(h, n, alpha):
    """Compute gradient of (1/alpha)*log(sum exp(alpha*corr_k)) * dx."""

    dx = 2.0 / n
    m = corr.max()
    sh = alpha * (corr - m)
    sm = sh.max()
    p = np.exp(sh - sm)
    p /= p.sum()

        pk = p[idx]
        if pk < 1e-15:

        # First term: (1-h[i-s]) for i in [max(0,s), min(n, s+n))
        i1 = max(0, s)
        i2 = min(n, s + n)
        if i1 < i2:

        j1 = max(0, -s)
        j2 = min(n, n - s)

def slsqp_optimize(h, n, alpha, deadline, maxiter=2000):
    """SLSQP with log-sum-exp objective."""
    dx = 2.0 / n
    target = n / 2.0
    
    def obj(x):
        g = np.correlate(x, 1 - x, mode='full') * dx
        m = g.max()
        sh = alpha * (g - m)
        sm = sh.max()
        return m + (sm + np.log(np.exp(sh - sm).sum())) / alpha
    
    def cons_fun(x):
        return x.sum() - target
    
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': cons_fun}]
    try:
        res = minimize(obj, h, method='SLSQP', bounds=bounds,
                       constraints=cons,
                       options={'maxiter': maxiter, 'ftol': 1e-16})
        return project_to_sum(res.x, target)
    except Exception:
        return h

def coordinated_refinement(h, n, deadline, n_iter=10000):

    h = h.copy()
    rng = np.random.RandomState(12345)

            break
        i = it % n
        # Fix all other variables, optimize h[i]
        # h[i] = t, we need sum(others) + t = target
        # So t = target - sum(others) fixed! 
        # This means in coordinate descent with equality constraint, 
        # changing h[i] by delta requires changing another variable by -delta.
        # Let's use a pair swap instead.
        
        # Actually, let's do: pick i, compute optimal h[i] if we could change it freely,
        # then adjust the sum by modifying the "most flexible" other variable.
        # This is complex. Let's just do a small perturbation + gradient step.
        
        # Instead: subgradient step on random subset
        idx = rng.choice(n, size=min(50, n), replace=False)
        g = smoothed_max_gradient(h, n, 100.0)

        c = compute_c5(h, n)

def multi_worst_shift_opt(h, n, deadline, n_top=10, n_iter=5000):
    """Optimize by focusing on the top n_top worst shifts simultaneously."""
    target = n / 2.0
    best_h = h.copy()
    best_c = compute_c5(h, n)
    h = h.copy()
    
    for it in range(n_iter):
        if time.time() > deadline:
            break
        corr = np.correlate(h, 1 - h, mode='full')
        # Get top n_top shifts
        top_idx = np.argsort(corr)[-n_top:]
        
        # Average gradient of top shifts
        dx = 2.0 / n
        grad = np.zeros(n)
        for idx in top_idx:
            s = idx - (n - 1)
            i1 = max(0, s)
            i2 = min(n, s + n)
            if i1 < i2:
                grad[i1:i2] += (1.0 - h[i1 - s:i2 - s])
            j1 = max(0, -s)
            j2 = min(n, n - s)
            if j1 < j2:
                grad[j1:j2] -= h[j1 + s:j2 + s]
        
        grad /= n_top
        eta = 0.05 / np.sqrt(1.0 + it * 0.05)
        h_new = h - eta * grad
        h_new = project_to_sum(h_new, target)
        
        c = compute_c5(h_new, n)
        if c < best_c - 1e-15:
            best_c = c
            best_h = h_new.copy()
            h = h_new
        else:
            # Reduce step
            eta *= 0.5
            if eta < 1e-8:
                break
    
    return best_h, best_c
