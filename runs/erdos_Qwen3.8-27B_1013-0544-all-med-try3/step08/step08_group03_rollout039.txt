Note that R(k) + R(-k) = ∫ h(x)(1-h(x+k)) dx + ∫ h(x)(1-h(x-k)) dx

Let me substitute y = x+k in the first integral and y = x-k in the second:

= ∫ (1-h(y))[h(y-k) + h(y+k)] dy

So R(k) + R(-k) = ∫ (1-h(y))[h(y-k) + h(y+k)] dy

And R(k) - R(-k) = ∫ h(x)(1-h(x+k)) dx - ∫ h(x)(1-h(x-k)) dx
= ∫ [h(x)(1-h(x+k)) - h(x)(1-h(x-k))] dx
= ∫ h(x)[h(x-k) - h(x+k)] dx

So if we want R(k) = R(-k) for all k (symmetric overlaps), we need ∫ h(x)[h(x-k) - h(x+k)] dx = 0 for all k.

This is a strong condition. It essentially says that h is "balanced" in a certain sense.

This is automatically satisfied if h has a specific structure. For example, if h is "centrally symmetric" in a certain way.

**Alternative: Use CVXPY with a relaxation**

We can formulate:

subject to:

z ≥ h[i] - h[i+k]
z ≥ 0
z ≤ h[i]
z ≤ 1 - h[i+k]

This gives a linear relaxation! Then:
minimize t
subject to:
  sum_i z[i,k] * dx ≤ t for all active k
  z[i,k] ≥ h[i] - h[i+k]
  0 ≤ z[i,k] ≤ min(h[i], 1-h[i+k])

  0 ≤ h ≤ 1

This is a linear program! But the relaxation might be loose.

Actually, for the McCormick relaxation to be tight, we need h[i] and h[i+k] to be at their bounds (0 or 1) or z to be at the "right" vertex. In general, the relaxation will give a lower bound on the true optimal value.

The true problem is: min max_k sum_i h[i](1-h[i+k]) dx
The LP relaxation gives: min max_k sum_i z[i,k] dx (with McCormick constraints)

The LP optimum ≤ true optimum, so it's a lower bound, not an upper bound. This doesn't directly help us find a better upper bound.

**Another idea: Submodularity and min-cut**

The objective sum_i h[i](1-h[i+k]) for a fixed k is a quadratic function of h. If h were binary, this would be a submodular (or supermodular) function depending on the sign of the interaction.

def compute_c5(h, n):
    dx = 2.0 / n
    return float(np.max(np.correlate(h, 1 - h, mode='full')) * dx)

def compute_c5_vec(h, n):
    dx = 2.0 / n
    return np.correlate(h, 1 - h, mode='full') * dx

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h.copy(), 0.0, 1.0)
    for _ in range(1000):
        diff = target - h.sum()
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            room = 1.0 - h
            tot = room.sum()
            if tot < 1e-14:
                break
            h += (diff / tot) * room
        else:
            tot = h.sum()
            if tot < 1e-14:
                break
            h += (diff / tot) * h
    return np.clip(h, 0.0, 1.0)

def make_obj_and_grad(n, alpha, use_penalty=False, mu=0.0):
    """Create objective and gradient for log-sum-exp smoothed max."""
    def obj(h):
        c = compute_c5_vec(h, n)
        mx = c.max()
        sh = alpha * (c - mx)
        s = np.log(np.exp(sh).sum())
        val = mx + s / alpha
        if use_penalty:
            val += mu * (h.sum() - n / 2.0) ** 2
        return float(val)
    def grad(h):
        c = compute_c5_vec(h, n)
        mx = c.max()
        sh = alpha * (c - mx)
        w = np.exp(sh)
        w /= w.sum()
        dx = 2.0 / n
        g = np.zeros(n)
        for m in range(2 * n - 1):
            if w[m] < 1e-13:
                continue
            k = m - (n - 1)

            if k >= 0:

                g[0:nv] += wm * (1.0 - h[k:n])
                g[k:n] += wm * (-h[0:nv])
            else:

    best_c = compute_c5(h, n)
    bounds = [(0.0, 1.0)] * n

        if time.time() > deadline - 5:
            break
        obj, grad = make_obj_and_grad(n, alpha, use_penalty=True, mu=10.0)
        try:
            res = minimize(obj, h, jac=grad, method='L-BFGS-B',
                          bounds=bounds,
                          options={'maxiter': max_per_phase, 'ftol': 1e-16,
                                   'gtol': 1e-12, 'maxfun': max_per_phase * 20})
            h_new = project_feasible(res.x, n)
            c_new = compute_c5(h_new, n)
            if c_new < best_c:
                best_c = c_new
                h = h_new
        except Exception:
            pass
    
    return h, best_c

def pair_local_search(h, n, deadline, step_sizes=None, radius=100):

The theoretical minimum (if we could make all correlations exactly equal) would be:
average_correlation = (1/(2n-1)) * sum_k R(k) = (1/(2n-1)) * sum_k sum_i h[i](1-h[i+k]) dx

This is hard to compute in general, but for a "typical" h, the average correlation is roughly:
≈ (1/(2n-1)) * sum_k (n-|k|) * avg[h(i)(1-h(i+k))] * dx
≈ (1/(2n-1)) * n^2 * avg[h(1-h)] * (2/n)
≈ n/2 * avg[h(1-h)]

For h with mean 1/2, if h is "spread out" (many values near 1/2), then avg[h(1-h)] ≈ 1/4 * (some factor depending on variance).

If h is binary (half 0s, half 1s), avg[h(1-h)] = 0 (since h(1-h) = 0 for binary h).
Then the average correlation would be 0, but the maximum would be much higher.

If h is uniform (all 1/2), avg[h(1-h)] = 1/4, and all correlations are ≈ 1/2 (for small k) or less (for large k). The max is 1/2.

So the optimal is somewhere in between: we want h to be "as far from 1/2 as possible" (to reduce h(1-h)) but also "as balanced as possible" (to avoid large correlations at specific shifts).

This suggests the optimal h should be "bimodal" - concentrated near 0 and 1, with a smooth transition. This is exactly what a sigmoid-like function would give.

            nv = n - kk
            g[kk:n] += wm * (1.0 - h[0:nv])
            g[0:nv] += wm * (-h[kk:n])
    return obj_val, g

def pen_obj_grad(h, n, alpha, mu):
    """Penalty method: log-sum-exp + quadratic penalty on sum constraint."""
    val, g = ls_exp_obj_grad(h, n, alpha)
    val += mu * (h.sum() - n / 2.0) ** 2
    g += 2.0 * mu * (h.sum() - n / 2.0)
    return val, g

def run_lbfgs(h, n, deadline, alphas, maxiter):
    """Run L-BFGS-B with schedule of alpha values."""
    h = project_feasible(h, n)
    best_c = compute_c5(h, n)
    bounds = [(0.0, 1.0)] * n
    
    for alpha in alphas:
        if time.time() > deadline - 3:
            break
        def obj(x):
            return pen_obj_grad(x, n, alpha, mu=5.0)[0]
        def grad(x):
            return pen_obj_grad(x, n, alpha, mu=5.0)[1]
        try:
            res = minimize(obj, h, jac=grad, method='L-BFGS-B',
                          bounds=bounds,
                          options={'maxiter': maxiter, 'ftol': 1e-18,
                                   'gtol': 1e-14, 'maxfun': maxiter * 30,
                                   'maxls': 50})
            h_new = project_feasible(res.x, n)
            c_new = compute_c5(h_new, n)
            if c_new < best_c - 1e-15:
                best_c = c_new
                h = h_new
        except Exception:
            pass
    return h, best_c

def topk_refine(h, n, deadline, k=15, maxiter=300):
    """Refine using top-k active constraints."""
    h = project_feasible(h, n)
    best_c = compute_c5(h, n)
    bounds = [(0.0, 1.0)] * n
    
    for _ in range(20):
        if time.time() > deadline - 3:
            break
        c = compute_c5_vec(h, n)
        top_idx = np.argsort(c)[-k:]
        
        def obj(x):
            cc = compute_c5_vec(x, n)
            return float(np.mean(cc[top_idx]))
        def grad(x):
            g = np.zeros(n)
            dx = 2.0 / n
            for m in top_idx:
                ks = m - (n - 1)
                if ks >= 0:
                    nv = n - ks
                    g[0:nv] += (dx / k) * (1.0 - x[ks:n])
                    g[ks:n] += (dx / k) * (-x[0:nv])
                else:
                    kk = -ks
                    nv = n - kk
                    g[kk:n] += (dx / k) * (1.0 - x[0:nv])
                    g[0:nv] += (dx / k) * (-x[kk:n])
            return g
        
        try:
            res = minimize(obj, h, jac=grad, method='L-BFGS-B',
                          bounds=bounds,
                          options={'maxiter': maxiter, 'ftol': 1e-18,
                                   'gtol': 1e-14})
            h_new = project_feasible(res.x, n)
            c_new = compute_c5(h_new, n)
            if c_new < best_c - 1e-15:
                best_c = c_new
                h = h_new
            else:
                break
        except Exception:
            break
    return h, best_c

def fine_local_search(h, n, deadline, radius=None):
    """Fine local search with pair moves at multiple scales."""
    if radius is None:
        radius = min(100, n // 3)
    h = project_feasible(h, n)
    best_c = compute_c5(h, n)
    step_sizes = [0.005, 0.002, 0.001, 0.0005, 0.0002, 0.0001, 0.00005]
    
    for step in step_sizes:
        while time.time() < deadline:
            improved = False
            for i in range(n):
                if time.time() > deadline:
                    return h, best_c
                lo = max(0, i - radius)
                hi = min(n, i + radius)
                for j in range(lo, hi):
                    if i == j:
                        continue
                    # Move from j to i
                    if h[j] >= step and h[i] + step <= 1.0:
                        h[j] -= step
                        h[i] += step
                        c = compute_c5(h, n)
                        if c < best_c - 1e-14:
                            best_c = c
                            improved = True
                        else:
                            h[j] += step
                            h[i] -= step
                    # Move from i to j
                    if h[i] >= step and h[j] + step <= 1.0:
                        h[i] -= step
                        h[j] += step
                        c = compute_c5(h, n)
                        if c < best_c - 1e-14:
                            best_c = c
                            improved = True
                        else:
                            h[i] += step
                            h[j] -= step
            if not improved:
                break
    return h, best_c

def gradient_step(h, n, alpha, lr):
    """One gradient step with projection."""
    _, g = ls_exp_obj_grad(h, n, alpha)
    h_new = h - lr * g
    h_new = project_feasible(h_new, n)
    return h_new
