    c = np.correlate(h, 1 - h, mode='full')

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h, 0.0, 1.0)
    for _ in range(1000):
        diff = target - h.sum()
        if abs(diff) < 1e-13:
            break
        if diff > 0:
            room = 1.0 - h
            s = room.sum()
            if s < 1e-12: break
            h = h + diff / s * room
        else:
            s = h.sum()
            if s < 1e-12: break
            h = h + diff / s * h
    return np.clip(h, 0.0, 1.0)

- Change some h[j+l] from 0 to 1 where h[j]=1 (also reduces the sum by 1)

But we need to maintain the binary constraint (equal number of 0s and 1s), so we must also do the reverse:
- Change h[i'] from 0 to 1 where h[i'+l]=1 (increases the sum by 1)
- Change h[j'-l] from 1 to 0 where h[j']=1 (increases the sum by 1)

Net effect: we swap one 0→1 and one 1→0. The change in the lag-l overlap is:
- Remove contribution from position i: -1 (if h[i]=1, h[i+l]=0)
- Add contribution from position i': +1 (if h[i']=0, h[i'+l]=1)
- Remove contribution from position j+l: -1 (if h[j]=1, h[j+l]=0, changing h[j+l] to 1 removes the "1-h[j+l]" factor)

Let's say we swap: h[a] goes from 0 to 1, h[b] goes from 1 to 0.

The overlap at lag l (for l > 0) is:
O(l) = sum_{i=0}^{n-1-l} h[i] * (1 - h[i+l])

After the swap:
- If a ≤ n-1-l: the term h[a]*(1-h[a+l]) changes from 0*(1-h[a+l]) = 0 to 1*(1-h[a+l]) = 1-h[a+l]
  - Change: +(1-h[a+l])
- If b ≤ n-1-l: the term h[b]*(1-h[b+l]) changes from 1*(1-h[b+l]) = 1-h[b+l] to 0*(1-h[b+l]) = 0
  - Change: -(1-h[b+l])
- If a+l < n (i.e., a < n-l): the term h[a-l]*(1-h[a]) changes from h[a-l]*1 to h[a-l]*0
  - Change: -h[a-l]
- If b+l < n (i.e., b < n-l): the term h[b-l]*(1-h[b]) changes from h[b-l]*0 to h[b-l]*1
  - Change: +h[b-l]

So the total change in O(l) for a swap (a: 0→1, b: 1→0) is:
delta_O(l) = [1-h[a+l] if a ≤ n-1-l else 0] - [1-h[b+l] if b ≤ n-1-l else 0]
           - [h[a-l] if a-l ≥ 0 else 0] + [h[b-l] if b-l ≥ 0 else 0]

(For binary h, h[a+l] ∈ {0,1}, etc.)

This is a constant-time computation for a specific l! So we can quickly evaluate the effect of a swap on any specific lag.

But the objective is MAX over all lags, so we need to check all lags. However, if we know that the current max is at l*, and the swap reduces O(l*), we can quickly check if any other lag increases above the new max.

Strategy:
1. Compute all O(l) values, find l* = argmax
2. For candidate swap (a, b), compute delta_O(l*) quickly
3. If delta_O(l*) < 0, check if the new O(l*) is less than the second-max lag value (or check a few nearby lags)
4. If safe, make the swap

This is much faster than recomputing the full correlation each time.

    h = h.copy()

        lags = np.correlate(h, 1-h, mode='full')

        values = lags * dx
        l_star = int(np.argmax(values))
        current_max = values[l_star]
        # Second max
        sorted_vals = np.sort(values)[::-1]
        second_max = sorted_vals[1] if len(sorted_vals) > 1 else 0
        
        # Find the effective lag index
        # lags index j corresponds to lag l = j - (n-1)
        lag = l_star - (n - 1)
        
        improved = False
        # Try to find a swap that reduces the worst lag
        ones = np.where(h == 1)[0]
        zeros = np.where(h == 0)[0]
        
        best_delta = 0
        best_a = -1
        best_b = -1
        
        for a in zeros:
            for b in ones:
                # Compute delta for lag
                d = 0.0
                # h[a] goes 0→1
                if a + abs(lag) < n and lag != 0:
                    # term h[a]*(1-h[a+lag]) changes from 0 to (1-h[a+lag])
                    if 0 <= a + lag < n:
                        d += (1 - h[a + lag])
                    if 0 <= a - lag < n:
                        d -= h[a - lag]
                # h[b] goes 1→0
                if 0 <= b + lag < n:
                    d -= (1 - h[b + lag])
                if 0 <= b - lag < n:
                    d += h[b - lag]
                
                if d < best_delta:
                    best_delta = d
                    best_a = a
                    best_b = b
        
        if best_a >= 0 and best_delta < 0:
            h[best_a], h[best_b] = 1.0, 0.0
            best_c = compute_c5(h, n)
            best_h = h.copy()
            improved = True
        
        if not improved:
            break
    
    return best_h, best_c

Hmm, but this only considers the effect on one lag (the worst). A swap might reduce the worst lag but increase another lag to become the new worst. We need to be more careful.

Actually, for the objective max_l O(l), a swap is beneficial if and only if:
max_l (O(l) + delta_O(l)) < max_l O(l) = O(l*)

This is equivalent to: for all l, O(l) + delta_O(l) < O(l*)

Which means: delta_O(l) < O(l*) - O(l) for all l.

In particular, delta_O(l*) < 0 is necessary but not sufficient. We also need delta_O(l) < O(l*) - O(l) for all other l.

A sufficient condition (that's easy to check): delta_O(l) < 0 for all l. This means the swap reduces ALL lags simultaneously. This is very restrictive but safe.

A less restrictive condition: delta_O(l*) < 0 and for all l ≠ l*, O(l) + delta_O(l) ≤ O(l*). We can check this for the top few lags.

For efficiency, let me check against the top 5 lags:
