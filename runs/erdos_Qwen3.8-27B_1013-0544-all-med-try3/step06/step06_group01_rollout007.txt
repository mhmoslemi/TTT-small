def binary_simulated_annealing(h, n, deadline, start_temp=0.1, end_temp=0.01):
    dx = 2.0 / n
    corr = np.correlate(h, 1-h, mode='full').astype(float)
    cur_max = corr.max() * dx
    s_range = np.arange(-(n-1), n)
    
    best_c = cur_max
    best_h = h.copy()
    rng = np.random.RandomState(123)
    
    n_iter = 100000
    t0 = time.time()
    elapsed_total = deadline - t0
    
    for it in range(n_iter):
        if time.time() > deadline:
            break
        T = start_temp * (end_temp / start_temp) ** (it / n_iter)
        
        # Random swap
        ones = np.where(h == 1)[0]
        zeros = np.where(h == 0)[0]
        i = rng.choice(zeros)
        j = rng.choice(ones)
        
        # Compute delta
        i_s = i - s_range
        i_p = i + s_range
        vi_s = (i_s >= 0) & (i_s < n)
        v_i_p = (i_p >= 0) & (i_p < n)
        A = np.where(vi_s, 1.0 - h[i_s], 0.0) - np.where(v_i_p, h[i_p], 0.0)

        vj_s = (j_s >= 0) & (j_s < n)
        vj_p = (j_p >= 0) & (j_p < n)
        B = -np.where(vj_s, 1.0 - h[j_s], 0.0) + np.where(vj_p, h[j_p], 0.0)
        
        delta = A + B
        new_max = np.max(corr + delta) * dx

        if delta_c < 0 or rng.random() < np.exp(-delta_c / T):
            corr = corr + delta
            h[i], h[j] = 1.0, 0.0
            cur_max = new_max
            if cur_max < best_c:

Now let me think about **structured initial solutions**. 

One idea: use a "low autocorrelation" binary sequence. The Thue-Morse sequence has good autocorrelation properties. But we need exactly n/2 ones.

Another idea: use the "every other" pattern with some perturbation. For n=250, take positions 0, 1, 3, 4, 6, 7, 9, 10, ... (pairs of consecutive ones separated by single zeros). This gives a somewhat balanced distribution.

Actually, let me think about what patterns minimize the maximum overlap. If we think of the set S of positions with h=1, we want to minimize max_s |S ∩ (S+s)^c| (where the complement is in the valid range). This is equivalent to maximizing min_s |S ∩ (S+s)|.

For a "uniform" distribution of S, the autocorrelation at shift s would be approximately |S|(n-|s|)/n = (n/2)(n-|s|)/n = (n-|s|)/2. The overlap would be (n-|s|) - (n-|s|)/2 = (n-|s|)/2, giving C₅ ≈ (n/2)*(2/n) = 1. That's the random case.

To do better, we need the autocorrelation to be HIGHER than average at the shifts where the valid range is largest (small |s|). This means we want S to be "clustered" at small shifts but "spread" at large shifts.

One construction: take S to be a "block" of n/2 consecutive positions. Then:
- At shift s: autocorr(s) = max(0, n/2 - |s|) for |s| < n/2, else 0
- Overlap at shift s: (n-|s|) - autocorr(s) for the valid range
  - For |s| < n/2: (n-|s|) - (n/2-|s|) = n/2
  - For |s| ≥ n/2: (n-|s|) - 0 = n-|s|
- Max overlap: n/2 (for |s| < n/2)
- C₅ = (n/2) * (2/n) = 1.0

That's terrible. A block is bad.

What about alternating? S = {0, 2, 4, ..., n-2} (every other position):
- At shift s: autocorr(s) depends on the parity
  - s even: autocorr(s) = (n/2 - |s|/2) for |s| < n/2 (approximately)
  - s odd: autocorr(s) = 0
- Overlap at odd shifts: (n-|s|) - 0 = n-|s| (max at s=1: n-1)
- C₅ ≈ (n-1) * (2/n) ≈ 2.0

Even worse! Alternating is terrible because at odd shifts, there's no overlap at all.

So we need a more nuanced structure. The key is to have SOME overlap at ALL shifts, not too many at any shift.

This is exactly the "minimum cross-correlation" or "low Peak-to-Average Power Ratio (PAPR)" problem in signal processing! 

One known construction for low PAPR is the **Golay complementary sequence** or **Barker sequence**, but these have specific lengths.

For our problem, I think the best approach is to use a **greedy construction** that places ones to maximize the minimum autocorrelation:

1. Start with an empty set S
2. For each position i (in some order), decide whether to add i to S
3. At each step, add the position that maximizes the minimum autocorrelation

But this is O(n³) and might not find the global optimum.

A better approach: start with a random solution and use the local search / simulated annealing I described above.

Let me now think about the **continuous optimization** approach. The problem is:
minimize t
subject to: ∑_i h[i]*(1-h[i+k])*dx ≤ t for all k
0 ≤ h[i] ≤ 1
∑_i h[i] = n/2

The constraint ∑_i h[i]*(1-h[i+k]) ≤ t/dx is NOT linear (it's bilinear). However, if we fix the values of h at the "bad" positions, it becomes linear.

One approach: **alternating minimization**. Fix some variables, optimize others linearly, then swap. This is similar to the "Frank-Wolfe" or "conditional gradient" method.

Actually, a cleaner approach: use the **epigraph form** and solve as a sequence of LPs.

minimize t
subject to: ∑_i h[i]*(1-h[i+k]) ≤ t/dx for all k
∑_i h[i] = n/2
0 ≤ h[i] ≤ 1

The constraint ∑_i h[i]*(1-h[i+k]) = ∑_i h[i] - ∑_i h[i]*h[i+k] ≤ t/dx

If we linearize around the current point h₀:
h[i]*h[i+k] ≈ h₀[i]*h[i+k] + h₀[i+k]*h[i] - h₀[i]*h₀[i+k]

This gives a linear constraint:
∑_i h₀[i]*h[i+k] + h₀[i+k]*h[i] - h₀[i]*h₀[i+k] ≥ (n/2 - t/dx)

This is the **linearization approach** (similar to cutting plane). We can solve this LP and then update h₀.

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1 - h, mode='full')
    return float(np.max(c) * dx)

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h, 0.0, 1.0)
    for _ in range(5000):
        diff = target - h.sum()
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            room = 1.0 - h
            s = room.sum()
            if s < 1e-14:
                break
            h = h + diff / s * room
        else:
            s = h.sum()
            if s < 1e-14:
                break
            h = h + diff / s * h
    return np.clip(h, 0.0, 1.0)

def to_binary(h, n):
    target = n // 2
    idx = np.argsort(h)[::-1]
    h_bin = np.zeros(n)
    h_bin[idx[:target]] = 1.0
    return h_bin

def binary_local_search(h, n, deadline, max_sweeps=50000):
    """Vectorized binary local search."""
    dx = 2.0 / n
    corr = np.correlate(h, 1 - h, mode='full').astype(float)
    cur_max = corr.max()
    s_range = np.arange(-(n - 1), n)
    
    best_c = cur_max * dx
    best_h = h.copy()
    
    for sweep in range(max_sweeps):
        if time.time() > deadline:
            break
        
        ones = np.where(h == 1)[0]
        zeros = np.where(h == 0)[0]
        if len(ones) == 0 or len(zeros) == 0:
            break
        
        found = False
        for i in zeros:
            # Compute A (contribution from i going 0->1)
            i_s = i - s_range
            i_p = i + s_range
            vi_s = (i_s >= 0) & (i_s < n)
            v_i_p = (i_p >= 0) & (i_p < n)
            A = np.where(vi_s, 1.0 - h[i_s], 0.0) - np.where(v_i_p, h[i_p], 0.0)
            
            # Vectorize over j (all ones)
            js = ones[:, None] - s_range[None, :]
            jp = ones[:, None] + s_range[None, :]
            vjs = (js >= 0) & (js < n)
            vjp = (jp >= 0) & (jp < n)
            h_js = np.where(vjs, h[np.clip(js, 0, n-1)], 0.0)
            h_jp = np.where(vjp, h[np.clip(jp, 0, n-1)], 0.0)
            B = np.where(vjs, h_js - 1.0, 0.0) + h_jp
            
            new_maxes = (corr[None, :] + A[None, :] + B).max(axis=1)
            j_idx = np.argmin(new_maxes)
            
            if new_maxes[j_idx] < cur_max - 1e-12:
                j = ones[j_idx]
                delta = A + B[j_idx]
                corr += delta
                h[i] = 1.0
                h[j] = 0.0
                cur_max = new_maxes[j_idx]
                found = True
                if cur_max * dx < best_c:
                    best_c = cur_max * dx
                    best_h = h.copy()
                break
        
        if not found:
            break
    
    return best_h, best_c

def binary_annealing(h, n, deadline, n_iter=200000, seed=42):
    """Simulated annealing on binary solutions."""
    dx = 2.0 / n
    corr = np.correlate(h, 1 - h, mode='full').astype(float)
    cur_max = corr.max()
    s_range = np.arange(-(n - 1), n)
    rng = np.random.RandomState(seed)
    
    best_c = cur_max * dx
    best_h = h.copy()
    
    start_T = 0.05
    end_T = 0.001
    
    for it in range(n_iter):
        if time.time() > deadline:
            break
        T = start_T * (end_T / start_T) ** (it / n_iter)
        
        ones = np.where(h == 1)[0]
        zeros = np.where(h == 0)[0]
        if len(ones) == 0 or len(zeros) == 0:
            break
        
        i = rng.choice(zeros)
        j = rng.choice(ones)
        
        i_s = i - s_range
        i_p = i + s_range
        vi_s = (i_s >= 0) & (i_s < n)
        v_i_p = (i_p >= 0) & (i_p < n)
        A = np.where(vi_s, 1.0 - h[i_s], 0.0) - np.where(v_i_p, h[i_p], 0.0)
        
        j_s = j - s_range
        j_p = j + s_range
        vj_s = (j_s >= 0) & (j_s < n)
        vj_p = (j_p >= 0) & (j_p < n)
        B = np.where(vj_s, h[j_s] - 1.0, 0.0) + np.where(vj_p, h[j_p], 0.0)
        
        delta = A + B
        new_max = (corr + delta).max()
        
        delta_c = (new_max - corr.max()) * dx
        if delta_c < 0 or rng.random() < np.exp(-delta_c / T):
            corr += delta
            h[i] = 1.0
            h[j] = 0.0
            if new_max * dx < best_c:
                best_c = new_max * dx
                best_h = h.copy()
    
    return best_h, best_c

def slsqp_optimize(h, n, alpha, maxiter, deadline):
    """SLSQP with smooth max approximation."""
    dx = 2.0 / n
    
    def obj(x):
        g = np.correlate(x, 1 - x, mode='full') * dx
        m = g.max()
        shifted = alpha * (g - m)
        sm = shifted.max()
        return m + (sm + np.log(np.exp(shifted - sm).sum())) / alpha
    
    def cons_fun(x):
        return x.sum() - n / 2.0
    
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': cons_fun}]
    try:
        res = minimize(obj, h, method='SLSQP', bounds=bounds,
                       constraints=cons,
                       options={'maxiter': maxiter, 'ftol': 1e-14})
        return project_feasible(res.x, n)
    except Exception:
        return h
