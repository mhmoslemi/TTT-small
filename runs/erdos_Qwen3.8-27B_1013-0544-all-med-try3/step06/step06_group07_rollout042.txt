Let me try a different approach: **Frank-Wolfe (Conditional Gradient) Method**

The Frank-Wolfe method works as follows:
- At each iteration, solve a linear minimization over the feasible set
- Take a step towards the linear minimizer

For our problem:
- Objective: f(h) = max_k c_k(h) (non-smooth)
- We can use the smooth version f_β(h) = smooth_max(c_1(h), ..., c_{2n-1}(h), β)
- The gradient of f_β is: ∇f_β = (1/β) · (∑ exp(β·c_k) · ∇c_k) / (∑ exp(β·c_k))
  = weighted average of ∇c_k with weights proportional to exp(β·c_k)

For the Frank-Wolfe method:
- Linear minimization: min_{h ∈ feasible} ⟨∇f_β, h⟩
  The feasible set is {h : 0 ≤ h[i] ≤ 1, ∑h[i] = n/2}
  The linear minimization is: for each coordinate, if ∇f_β[i] > 0, set h[i] = 0; if < 0, set h[i] = 1. Then adjust to meet the sum constraint by partially filling the remaining.

This is actually very efficient! The linear minimization over the constraint set is essentially a "sort and threshold" operation.

Let me formalize:
min_{h: 0≤h≤1, ∑h=n/2} ⟨g, h⟩ where g = ∇f_β

The solution is: sort g in increasing order. Set h[i] = 1 for the n/2 smallest g[i], and h[i] = 0 for the rest. (If there's a tie at the boundary, split.)

Actually that's not quite right. We want to minimize ⟨g, h⟩ = ∑ g[i]·h[i]. To make this small, we want h[i] = 1 where g[i] is most negative and h[i] = 0 where g[i] is most positive.

So: sort indices by g[i] in increasing order. Set h[i] = 1 for the first n/2 indices (most negative g), h[i] = 0 for the rest.

This gives a vertex of the feasible polytope. The Frank-Wolfe step is:
h_new = (1-γ)·h_old + γ·h_vw
where h_vw is the vertex solution and γ is the step size.

The step size can be chosen by line search or using the standard FW schedule γ = 2/(t+2).
