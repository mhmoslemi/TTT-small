Actually, the key insight is:

- So new_c = c + A_i - B_j
- We want min_j max(new_c) = min_j max(c + A_i - B_j)

If I precompute all B_j (the effect of h[j]+=d for all j), that's the B matrix of shape (n, 2n-1). Computing it is O(n²) which for n=250 is 62500 operations - very fast.

Then for each i:
- A_i = B[i] (the effect of h[i]+=d)
- D = c + A_i  (shape (2n-1,))

- This is: M = D[None, :] - B  (shape (n, 2n-1))
- result = M.max(axis=1)  (shape (n,))
- best_j = result.argmin()

Total per i: O(n * (2n-1)) = O(n²) for the matrix op.
Total per pass: O(n³) but all in numpy vectorized ops.
