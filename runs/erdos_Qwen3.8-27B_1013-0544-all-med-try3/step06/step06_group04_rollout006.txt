**Feasibility check for a given C:**
Given target C, we want to find h such that:
- 0 ≤ h ≤ 1
- sum(h) = n/2
- For all k: overlap(k, h) ≤ C

We use cutting planes: start with some h₀, linearize the overlapping constraints at h₀, solve the LP, check if the solution satisfies the original (non-linear) constraints. If not, add more cutting planes at the new point.

minimize 0 (feasibility)
subject to:
- 0 ≤ h ≤ 1
- sum(h) = n/2
- For each cutting plane (added at iteration t): overlap(k_t, h_t) + ∇overlap(k_t, h_t)·(h - h_t) ≤ C

If the LP is infeasible, then C is too low. If it's feasible and the solution satisfies all original constraints within tolerance, we're done.

This is a standard branch-and-cut / cutting plane approach.

Actually, let me think about what coordinate descent to use. The key insight is:

If we change h[j] by δ (and adjust another element to maintain the sum constraint), how does it affect all lags?

For a change δ at position j:
- Lag k is affected if either i=j or i+k=j for some valid i
- The change in overlap(k) ≈ grad_k[j] * δ

So a good coordinate descent would:
1. Find the worst lag k*
2. For each pair (j, j'), compute the "cost" of moving mass from j to j'
3. Pick the best move

But this is O(n²) per step, which might be too slow for n=300-500.

A simpler but effective approach: For the worst lag k*, compute the gradient and move in the negative gradient direction (with projection). This is essentially a subgradient method.

Let me implement a "mirror descent" style approach:
- Compute the subgradient of the max at the current point
- Take a step in the negative subgradient direction
- Project onto the feasible set

The subgradient of max_k f_k(h) at h is the average of the gradients of all active f_k (those at the max).

```python
def subgradient_step(h, n, step_size):
    """Take a subgradient step to reduce the max overlap."""
    c = compute_all_lags(h, n)
    c_max = c.max()
    # Active set: lags within epsilon of max
    active = c >= c_max - 1e-4
    n_active = active.sum()

    subgrad = np.zeros(n)

            lag = k - (n-1)
            subgrad += lag_gradient(h, n, lag)
    subgrad /= n_active
    
    # Projected gradient step
    h_new = h - step_size * subgrad
    h_new = project_feasible(h_new, n)
    return h_new
```

import numpy as np

def compute_c5(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1 - h, mode='full')
    return float(np.max(c) * dx)

def compute_all_lags(h, n):
    dx = 2.0 / n
    return np.correlate(h, 1 - h, mode='full') * dx

def project_feasible(h, n):
    target_sum = n / 2.0
    h = np.clip(h.copy(), 0.0, 1.0)
    for _ in range(1000):
        diff = target_sum - h.sum()
        if abs(diff) < 1e-15:
            break
        if diff > 0:
            room = 1.0 - h
            tot = room.sum()
            if tot < 1e-15:
                break
            h += (diff / tot) * room
        else:
            tot = h.sum()
            if tot < 1e-15:
                break
            h += (diff / tot) * h
    return np.clip(h, 0.0, 1.0)

def lag_gradient(h, n, lag):
    grad = np.zeros(n)
    m = abs(lag)
    if m >= n:
        return grad
    if lag == 0:
        grad[:] = 1.0 - 2.0 * h
    elif lag > 0:
        grad[:n-m] += (1.0 - h[m:])
        grad[m:] -= h[:n-m]
    else:
        grad[m:] += (1.0 - h[:n-m])
        grad[:n-m] -= h[m:]
    return grad

def cp_feasibility(h_start, n, c_target, deadline, max_planes=60):
    """Cutting plane feasibility for C ≤ c_target."""
    h_curr = h_start.copy()
    plane_grads = []
    plane_offsets = []
    
    for it in range(max_planes):
        if time.time() > deadline:
            return None, False
        
        c = compute_all_lags(h_curr, n)
        c_max_idx = np.argmax(c)
        if c[c_max_idx] <= c_target + 1e-10:
            # Check all lags
            if c.max() <= c_target + 1e-9:
                return h_curr, True
        
        # Add cutting plane at worst violator
        violators = np.where(c > c_target + 1e-10)[0]
        if len(violators) == 0:
            break
        
        # Add top violators
        top_v = violators[np.argsort(c[violators])[-min(5, len(violators)):]]
        for vi in reversed(top_v):  # Add worst first
            if len(plane_grads) >= max_planes:
                break
            lag = vi - (n - 1)
            grad = lag_gradient(h_curr, n, lag)
            offset = c_target - c[vi] + grad @ h_curr
            plane_grads.append(grad)
            plane_offsets.append(offset)
        
        # Solve LP
        h_var = cp.Variable(n)
        cons = [
            cp.sum(h_var) == n / 2.0,
            h_var >= 0,
            h_var <= 1
        ]
        for g, off in zip(plane_grads, plane_offsets):
            cons.append(g @ h_var <= off)
        
        prob = cp.Problem(cp.Minimize(0), cons)
        try:
            prob.solve(solver=cp.GLOP, verbose=False)
        except Exception:
            try:
                prob.solve(solver=cp.CBC, verbose=False)
            except Exception:
                return None, False
        
        if prob.status not in ['optimal', 'optimal_inaccurate']:
            return None, False
        
        h_new = h_var.value
        if h_new is None:
            return None, False
        h_curr = project_feasible(np.clip(h_new, 0, 1), n)
    
    # Final verification
    c = compute_all_lags(h_curr, n)
    if c.max() <= c_target + 1e-9:
        return h_curr, True
    return None, False

            # minimized when h is as close to 0 or 1 as possible)

                    delta = 0.01

                                h_try[k] -= delta
                                break
                    c_try = compute_c5(h_try, n)
                    if c_try < best_c - 1e-12:
                        best_c = c_try
                        best_h = h_try.copy()
                        h_curr = h_try

        if m >= n:
            break

        # For lag > 0: moving mass from position i to i+m reduces overlap
