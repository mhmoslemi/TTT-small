The overall objective max_k f_k(h) is the max of piecewise linear functions, which is piecewise linear.
So the 1D subproblem can be solved by checking the breakpoints!

But the breakpoints depend on all the other h_i values, and there could be many of them. In practice, for a single coordinate, the number of breakpoints is bounded by the number of lags (2n-1), so it's at most 2n-1 intervals. This is very tractable!

**Coordinate descent plan:**
For each coordinate j:
1. For each lag k, compute f_k as a function of h_j (it's linear in h_j for each k).
2. The objective is max_k f_k(h_j) which is piecewise linear in h_j.
3. The breakpoints are at h_j = 0, h_j = 1, and at values where the argmax changes.
4. The minimum of a piecewise linear function on [0,1] is at a breakpoint or at 0 or 1.
5. Find the h_j that minimizes the max.

This is essentially a 1D minimax problem that can be solved efficiently!
