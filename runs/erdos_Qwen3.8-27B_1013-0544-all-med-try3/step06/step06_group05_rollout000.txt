For the Frank-Wolfe method:
- Objective: minimize C5 = max_k c_k = max_k (1 - R(k)) = 1 - min_k R(k)
  So we want to maximize min_k R(k)
  Smooth: maximize (∑ R(k)^p)^{1/p} / n^{1/p} (or just maximize ∑ R(k)^p for simplicity, since the monotone transformation doesn't change the optimum)
  
  Actually, maximizing ∑ R(k)^p for large p approximates maximizing min R(k). But we can also use the log-sum-exp trick on -R:
  maximize -log(∑ exp(-R(k)/t)) / t for small t

  Let me use the power approach: maximize F(h) = (∑_k R(k)^p)^{1/p}
  This is equivalent to maximizing ∑_k R(k)^p (since the p-th root is monotonic).

- Gradient of ∑ R(k)^p with respect to h[i]:
  ∂/∂h[i] ∑_k R(k)^p = ∑_k p*R(k)^{p-1} * ∂R(k)/∂h[i]
  = p * ∑_k R(k)^{p-1} * dx * (h[(i+k)%n] + h[(i-k)%n])
  = p * dx * (A ⊛ h)[i] + p * dx * (A ⊛ h)[(-i)%n]
  
  where A[k] = R(k)^{p-1} and (A⊛h)[m] = ∑_k A[k]*h[(k+m)%n]

  Note: (A⊛h)[i] + (A⊛h)[(-i)%n]
  Now (A⊛h)[(-i)%n] = ∑_k A[k]*h[(k-i)%n]
  
  So grad[i] = p*dx * ((A⊛h)[i] + (A⊛h)[(n-i)%n])

  And (A⊛h) can be computed with one FFT.

- Linear oracle: Given gradient g, find h' ∈ [0,1]^n, ∑h' = n/2 that minimizes ∑ g[i]*h'[i].

```python
    # So ∂c(l)/∂h[j] = (1-h[j-l]) * 1[0<=j-l<n] - h[j+l] * 1[0<=j+l<n]
    
    # grad[j] = sum_l w_l * ∂c(l)/∂h[j]
    # = sum_l w_l * (1-h[j-l]) * 1[0<=j-l<n] - sum_l w_l * h[j+l] * 1[0<=j+l<n]
    # = sum_l w_l * 1[0<=j-l<n] - sum_l w_l * h[j-l] * 1[0<=j-l<n] - sum_l w_l * h[j+l] * 1[0<=j+l<n]
    
    # Let's define the lags: l goes from -(n-1) to n-1
    # w_l = c(l)^(p-1) where c(l) = np.correlate(h, 1-h, mode='full')[l+(n-1)] * dx
    
    # Term 1: sum_l w_l * 1[0<=j-l<n] = sum_l w_l * 1[max(0,j-n+1) <= l <= min(j, n-1)]
    #         This is the sum of w_l over a range.
    
    # Term 2: sum_l w_l * h[j-l] * 1[0<=j-l<n] = sum_m w_{j-m} * h[m] * 1[0<=m<n]
    #         where m = j-l, so l = j-m
    #         = sum_m h[m] * w_{j-m} for 0<=m<n and 0<=j-m in lag range
    
    # Term 3: sum_l w_l * h[j+l] * 1[0<=j+l<n] = sum_m w_{m-j} * h[m] for 0<=m<n
    #         where m = j+l, so l = m-j
    
    # Terms 2 and 3 together: sum_m h[m] * (w_{j-m} + w_{m-j}) * 1[valid]
    
    # This is getting complex. Let me just do a direct O(n*(2n)) computation.
    
    grad = np.zeros(n)
    for j in range(n):
        s = 0.0
        for l in range(-(n-1), n):
            wl = w[l + (n-1)]  # w at lag l
            # Term: (1-h[j-l]) if 0<=j-l<n
            im = j - l
            if 0 <= im < n:
                s += wl * (1.0 - h[im])
            # Term: -h[j+l] if 0<=j+l<n
            im2 = j + l
            if 0 <= im2 < n:
                s -= wl * h[im2]
        grad[j] = s
    
    # Multiply by (1/f) * p for the full gradient of (sum c^p)^(1/p)
    # Actually for minimizing sum c^p, the gradient is:
    # p * sum_k c_k^(p-1) * dc_k/dh[j]
    # We computed sum_l w_l * dc(l)/dh[j] where w_l = c(l)^(p-1)
    # So grad[j] * p is the gradient of sum c^p
    
    return grad * p  # gradient of sum_k c_k^p
```
