import numpy as np
from scipy.optimize import minimize
import time
import random

def compute_c5(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1 - h, mode='full')
    return float(np.max(c) * dx)

def compute_all_g(h, n):
    dx = 2.0 / n
    return np.correlate(h, 1 - h, mode='full') * dx

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h, 0.0, 1.0)
    for _ in range(1000):
        diff = target - h.sum()
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            room = 1.0 - h
            s = room.sum()
            if s < 1e-14:
                break
            h = h + diff / s * room
        else:
            s = h.sum()
            if s < 1e-14:
                break
            h = h + diff / s * h
    return np.clip(h, 0.0, 1.0)

def to_binary(h, n):
    target = int(n // 2)
    idx = np.argsort(h)[::-1]
    h_bin = np.zeros(n)
    h_bin[idx[:target]] = 1.0
    return h_bin

def slsqp_step(h, n, alpha, maxiter, deadline):
    # Smooth max approximation
    def obj(x):
        g = np.correlate(x, 1 - x, mode='full') * (2.0 / n)
        m = g.max()
        sh = alpha * (g - m)
        sm = sh.max()
        return m + (sm + np.log(np.exp(sh - sm).sum())) / alpha
    
    def cons_fun(x):
        return x.sum() - n / 2.0
    
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': cons_fun}]
    try:
        res = minimize(obj, h, method='SLSQP', bounds=bounds,
                       constraints=cons,
                       options={'maxiter': maxiter, 'ftol': 1e-15})
        return project_feasible(res.x, n)
    except Exception:
        return h

**Approach: Direct minimization of the max using a "peeling" strategy**

1. Start with h, compute all g(k)
2. Find the k* that achieves the max
3. Move h in the direction that most reduces g(k*) while keeping all other g(k) from increasing too much
4. This is like a constrained optimization: minimize g(k*) subject to g(k) ≤ current_max for all k

This can be solved as a QP (quadratic program) at each step:
- Objective: minimize g(k*) (which is linear in h)
- Constraints: g(k) ≤ g_max for all k (linear in h)
- Box constraints: 0 ≤ h ≤ 1
- Sum constraint: sum(h) = n/2

Wait, but g(k) = sum_i h[i]*(1-h[i+k]) is NOT linear in h! It's bilinear. So this doesn't work directly.

Unless... we linearize. If we fix all variables except one, then g(k) IS linear in that variable. So coordinate descent works:

For coordinate i:
g(k) = ... + h[i]*(1-h[i+k]) + h[i-k]*(1-h[i]) + ... (terms involving h[i])
= ... + h[i] - h[i]*h[i+k] + h[i-k] - h[i-k]*h[i] + ...
= ... + h[i]*(1 - h[i+k] - h[i-k]) + h[i-k] + ...

So for fixed other variables, g(k) is linear in h[i]. The coefficient of h[i] in g(k) is:
- (1 - h[i+k]) if i+k is valid (h[i] appears as the "first" factor)
- (-h[i-k]) if i-k is valid (h[i] appears in (1-h[...]) as the subtracted term)
- Both if both i+k and i-k are valid

So the coefficient is: (1 - h[i+k]) - h[i-k] (with appropriate zero-padding for out-of-bounds indices).

This means we CAN do coordinate descent! For each coordinate i, we find the value of h[i] that minimizes the max of all g(k), given all other h fixed.

For a single coordinate change from h[i] = a to h[i] = b, each g(k) changes by:
Δg(k) = (b - a) * coeff(k, i)

where coeff(k, i) is the coefficient of h[i] in g(k).

So we need to find b ∈ [0,1] that minimizes max_k (g(k) + (b-a)*coeff(k,i)).

This is a 1D optimization: minimize max_k (c_k + b * d_k) where c_k = g(k) - a*coeff(k,i) and d_k = coeff(k,i).

The minimum of max_k (c_k + b*d_k) over b ∈ [0,1] can be found analytically:
- It's the minimum of the upper envelope of lines
- The optimal b is where two lines cross (or at a boundary)

This is a linear programming problem in 1D, solvable in O(K log K) where K is the number of lags.

This coordinate descent approach is much more efficient than SLSQP for this problem! Each coordinate update is O(n log n) (compute all g(k), find the optimal b). A full sweep is O(n^2 log n). For n=250, that's about 250 * 250 * 8 ≈ 500,000 operations per sweep. Very fast!

OK so the gradient of c[m] with respect to h[j] is:
(1 - h[j-m]) * I(0 ≤ j-m < n) - h[j+m] * I(0 ≤ j+m < n)

where m is the correlation index (0 to 2n-2).

Now, for coordinate descent on h[j], we need to find the value of h[j] that minimizes max_m (c[m] + (new_h[j] - old_h[j]) * grad[m,j]).

Let a = old_h[j], b = new_h[j], Δ = b - a.
New c[m] = c[m] + Δ * grad[m,j]

We want to minimize max_m (c[m] + Δ * grad[m,j]) over Δ ∈ [-a, 1-a].

This is: minimize max_m (c[m] + Δ * g_m) where g_m = grad[m,j].

The function f(Δ) = max_m (c[m] + Δ * g_m) is a convex piecewise-linear function of Δ.
The minimum is at a point where either:
- Two lines cross: c[m1] + Δ*g[m1] = c[m2] + Δ*g[m2]
- Or at a boundary: Δ = -a or Δ = 1-a

To find the optimal Δ, we can:
1. Evaluate f at Δ = -a and Δ = 1-a
2. Find all crossing points of pairs of lines (there are at most 2n-1 lines, so O((2n)^2) crossings)
3. Check f at each crossing point that falls in [-a, 1-a]
4. Take the minimum

But O((2n)^2) is O(n^2) per coordinate, and we have n coordinates, so O(n^3) per sweep. For n=250, that's about 15.6 million operations per sweep. Each operation is cheap (just arithmetic), so a sweep might take a fraction of a second. We could do many sweeps.

Actually, there's a more efficient way. The minimum of max of linear functions over an interval can be found in O(K log K) time where K is the number of lines, using a "lower envelope" or by binary search on the value.

But for our purposes, O(K^2) per coordinate is fine since K = 2n-1 ≈ 500, so K^2 ≈ 250,000 per coordinate, and n=250 coordinates gives about 62.5 million per sweep. That might be too slow in Python.

Actually, the simplest effective approach: for each coordinate j, the optimal b is at a crossing point or boundary. The crossing points are at:
Δ* = (c[m2] - c[m1]) / (g[m1] - g[m2]) for pairs (m1, m2) with g[m1] ≠ g[m2]

But we don't need ALL crossing points. We just need the one that gives the minimum. We can use the fact that the optimal Δ is where the "upper envelope" has its minimum, which is at a vertex of the upper envelope.

A practical approach: 
1. Start with Δ = 0
2. Find which m achieves the max at Δ=0 (call it m*)
3. The derivative of f at Δ=0 is g[m*] (if m* is unique)
4. Move in direction -sign(g[m*]) until we hit a boundary or the active set changes
5. Repeat

This is like a simplex method in 1D, and it converges in at most K+1 steps.

**Simplified coordinate descent:**

6. Pick the b that gives the smallest max

```python
import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1 - h, mode='full')
    return float(np.max(c) * dx)

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h, 0.0, 1.0)
    for _ in range(500):
        diff = target - h.sum()
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            room = 1.0 - h
            s = room.sum()
            if s < 1e-14:
                break
            h = h + diff / s * room
        else:
            s = h.sum()
            if s < 1e-14:
                break
            h = h + diff / s * h
    return np.clip(h, 0.0, 1.0)

def to_binary(h, n):
    target = n // 2
    idx = np.argsort(h)[::-1]
    out = np.zeros(n)
    out[idx[:target]] = 1.0
    return out

def binary_local_search(h_bin, n, deadline, max_sweeps=5000):
    """Greedy binary local search: try all single swaps."""
    best_c = compute_c5(h_bin, n)
    ones = np.where(h_bin == 1)[0].tolist()
    zeros = np.where(h_bin == 0)[0].tolist()
    
    for sweep in range(max_sweeps):
        if time.time() > deadline:
            break
        improved = False
        for i in zeros[:]:
            if time.time() > deadline:
                break
            for j in ones[:]:
                h_bin[i], h_bin[j] = 1.0, 0.0
                c = compute_c5(h_bin, n)
                if c < best_c - 1e-15:
                    best_c = c
                    improved = True
                    ones.remove(j)
                    ones.append(i)
                    zeros.remove(i)
                    zeros.append(j)
                    break
                else:
                    h_bin[i], h_bin[j] = 0.0, 1.0
            if improved:
                break  # Restart the sweep
        if not improved:
            break
    
    return h_bin, best_c

def coord_descent(h, n, deadline, max_sweeps=200000, rng=None):
    """Coordinate descent exploiting bilinear structure."""
    if rng is None:
        rng = np.random.RandomState(42)
    
    best_h = h.copy()
    best_c = compute_c5(best_h, n)
    dx = 2.0 / n
    n_corr = 2 * n - 1
    c_full = np.correlate(best_h, 1 - best_h, mode='full')
    
    pre = n - 1  # offset for correlation indexing
    
    for sweep in range(max_sweeps):
        if time.time() > deadline:
            break
        
        old_max = c_full.max()
        improved = False
        
        # Determine order
        if sweep % 3 == 0:
            order = np.arange(n)
        elif sweep % 3 == 1:
            order = np.arange(n-1, -1, -1)
        else:
            order = rng.permutation(n)
        
        for j in order:
            a = best_h[j]
            
            # Compute gradient: dc[m]/dh[j] for all m
            # lag = m - (n-1)
            # dc[m]/dh[j] = (1-h[j-lag])*I(0<=j-lag<n) - h[j+lag]*I(0<=j+lag<n)
            m_arr = np.arange(n_corr)
            lag = m_arr - pre
            
            idx1 = j - lag  # j - (m - n + 1) = j + n - 1 - m
            valid1 = (idx1 >= 0) & (idx1 < n)
            idx2 = j + lag  # j + (m - n + 1)
            valid2 = (idx2 >= 0) & (idx2 < n)
            
            grad = np.zeros(n_corr)
            grad[valid1] = (1.0 - best_h[idx1[valid1]])
            grad[valid2] -= best_h[idx2[valid2]]
            
            # Find best b in [0,1] minimizing max(c_full + (b-a)*grad)
            best_b = a
            best_val = c_full.max()
            
            # Try boundaries
            for b_cand in (0.0, 1.0):
                if b_cand == a:
                    continue
                val = (c_full + (b_cand - a) * grad).max()
                if val < best_val:
                    best_val = val
                    best_b = b_cand
            
            # Try crossing points of top K lines
            K = 15
            top_idx = np.argpartition(c_full, -K)[-K:]
            for s in range(K):
                m1 = int(top_idx[s])
                g1 = grad[m1]
                for t in range(s+1, K):
                    m2 = int(top_idx[t])
                    g2 = grad[m2]
                    dg = g1 - g2
                    if abs(dg) < 1e-14:
                        continue
                    delta = (c_full[m2] - c_full[m1]) / dg
                    b_cand = a + delta
                    if 0.0 <= b_cand <= 1.0:
                        val = (c_full + (b_cand - a) * grad).max()
                        if val < best_val:
                            best_val = val
                            best_b = b_cand
            
            if best_b != a:
                c_full += (best_b - a) * grad
                best_h[j] = best_b
                improved = True
        
        # Project to maintain constraint
        best_h = project_feasible(best_h, n)
        c_full = np.correlate(best_h, 1 - best_h, mode='full')
        
        # Update best
        cur_c = c_full.max() * dx
        if cur_c < best_c:
            best_c = cur_c
        
        # Convergence
        if not improved or abs(c_full.max() - old_max) < 1e-13:
            break
    
    return best_h, best_c

def slsqp_polish(h, n, deadline, alphas=None):
    if alphas is None:
        alphas = [500, 2000, 10000, 50000, 200000, 1000000, 5000000]
    
    best_h = h.copy()
    best_c = compute_c5(best_h, n)
    
    for alpha in alphas:
        if time.time() > deadline:
            break
        
        def obj(x):
            g = np.correlate(x, 1 - x, mode='full') * (2.0 / n)
            m = g.max()
            sh = alpha * (g - m)
            sm = sh.max()
            return m + (sm + np.log(np.exp(sh - sm).sum())) / alpha
        
        bounds = [(0.0, 1.0)] * n
        cons = [{'type': 'eq', 'fun': lambda x: x.sum() - n/2.0}]
        
        try:
            res = minimize(obj, best_h, method='SLSQP', bounds=bounds,
                          constraints=cons, options={'maxiter': 300, 'ftol': 1e-16})
            new_h = project_feasible(res.x, n)
            new_c = compute_c5(new_h, n)
            if new_c < best_c:
                best_c = new_c
                best_h = new_h
        except:
            pass
    
    return best_h, best_c
