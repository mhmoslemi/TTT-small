The current local search:

A better approach:

- Choose the globally best move
- This way, we're not stuck optimizing one lag while others get worse

Even better: use the gradient to determine the best move.

For a given gradient g (subgradient of the max), the best feasible direction from h is:
- We want to minimize g^T * d subject to:
  - h + d is feasible (0 ≤ h+d ≤ 1, sum(h+d) = N/2)
  - ||d|| ≤ δ (small step)

The optimal d is essentially: move mass from indices where g is positive (increasing h there increases the objective) to indices where g is negative (increasing h there decreases the objective), while respecting the box and sum constraints.

This is a simple water-filling problem! The optimal direction is:
- For each index j, if g[j] < 0, we want to increase h[j]
- For each index j, if g[j] > 0, we want to decrease h[j]
- The total increase must equal the total decrease (sum constraint)
- Respecting bounds: can't increase h[j] past 1, can't decrease past 0

This gives us a very efficient "best direction" computation.

def best_direction(h, grad, N, max_step=0.01):
    """Find the best feasible direction to reduce grad^T * d."""
    # We want to minimize grad^T * d subject to:
    # 0 <= h+d <= 1, sum(d) = 0, ||d||_inf <= max_step
    # 
    # The optimal solution: move mass from high-grad to low-grad
    # sorted by grad
    order = np.argsort(grad)
    d = np.zeros(N)
    
    # Source indices (high grad, we decrease h)
    # Sink indices (low grad, we increase h)
    
    # Simple approach: for each pair (source, sink) in order of most beneficial,
    # move mass
    total_move = 0.0
    for i in range(N):
        for j in range(N-1, -1, -1):
            if i == j:
                continue
            if grad[i] > 0 and grad[j] < 0:
                # Moving from i to j reduces objective by (grad[i] - grad[j]) * delta

                if delta > 1e-10:
                    d[i] -= delta
                    d[j] += delta
                    total_move += delta
    return d

import numpy as np
import time

def compute_c5(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1 - h, mode='full')
    return float(np.max(c) * dx)

def compute_all_lags(h, n):
    dx = 2.0 / n
    return np.correlate(h, 1 - h, mode='full') * dx

def project_feasible(h, n):
    target_sum = n / 2.0
    h = np.clip(h.copy(), 0.0, 1.0)
    for _ in range(500):
        diff = target_sum - h.sum()
        if abs(diff) < 1e-15:
            break
        if diff > 0:
            room = 1.0 - h
            tot = room.sum()
            if tot < 1e-15:
                break
            h += (diff / tot) * room
        else:
            tot = h.sum()
            if tot < 1e-15:
                break
            h += (diff / tot) * h
    return np.clip(h, 0.0, 1.0)

def compute_gradient(h, n, weights):
    """Compute weighted sum of lag gradients.
    weights: array of length 2n-1, same indexing as compute_all_lags.
    """
    dx = 2.0 / n
    N = n
    grad = np.zeros(N)
    
    # Weight for lag 0
    w0 = weights[N-1]
    grad += w0 * (1 - 2*h)
    
    # For m = 1 to N-1:
    for m in range(1, N):
        W_m = weights[N-1+m] + weights[N-1-m]
        if W_m < 1e-15:
            continue
        grad[:N-m] += W_m * (1 - h[m:])
        grad[m:] -= W_m * h[:N-m]
    
    return dx * grad

def projected_gradient_step(h, n, alpha, eta, max_inner=50):
    """One projected gradient step with backtracking line search."""
    N = n
    c = compute_all_lags(h, N)
    # Compute weights
    c_max = c.max()
    shifted = alpha * (c - c_max)
    e = np.exp(shifted - shifted.max())
    weights = e / e.sum()
    
    grad = compute_gradient(h, N, weights)
    
    # Projected gradient step with line search
    best_h = h.copy()
    best_c = compute_c5(h, N)
    for _ in range(max_inner):
        h_try = project_feasible(h - eta * grad, N)
        c_try = compute_c5(h_try, N)
        if c_try < best_c:
            best_c = c_try
            best_h = h_try
        eta *= 0.5
        if eta < 1e-10:
            break
    return best_h, best_c

def gradient_descent(h, n, deadline, alpha_start=50, alpha_end=100000, 
                     eta_start=0.01, max_iter=1000):
    """Projected gradient descent with increasing alpha."""
    N = n
    h_curr = h.copy()
    best_h = h_curr.copy()
    best_c = compute_c5(h_curr, N)
    eta = eta_start
    
    for it in range(max_iter):
        if time.time() > deadline:
            break
        # Increase alpha over iterations
        progress = min(1.0, it / (max_iter * 0.8))
        alpha = alpha_start * (alpha_end / alpha_start) ** progress
        
        h_new, c_new = projected_gradient_step(h_curr, N, alpha, eta)
        if c_new < best_c - 1e-15:
            best_c = c_new
            best_h = h_new.copy()
        
        if c_new < best_c:
            h_curr = h_new
            # Reset eta if we made progress
            eta = max(eta * 1.1, eta_start * 0.5)
        else:
            eta *= 0.7
        
        # If no improvement for a while, reduce eta
        if it % 100 == 99 and eta < eta_start * 0.01:
            break
    
    return best_h, best_c

The key insight: at the optimum, the gradient of the max should be "balanced" in the sense that no feasible direction reduces the max. This is a KKT condition.

A good local search:
1. Compute the active lags (top few)
2. For each active lag, find the best pair to adjust
3. Among all candidates, pick the one that most reduces the max
4. Make that adjustment
5. Repeat

I need to be smarter. Instead of recomputing the full correlation after each move, I should compute the change analytically.

When we change h[i] by -δ and h[j] by +δ (where j = i + m for some lag m), the change in c[lag] is:

For a specific lag ℓ:
- If ℓ = m (or -m): the change involves the terms where h[i] or h[j] appears
- For other lags: h[i] and h[j] might also appear

Let me compute the change in c[ℓ] when h[i] → h[i] - δ and h[j] → h[j] + δ:

c[ℓ] = dx * Σ_{k} h[k] * (1-h[k+ℓ]) (for appropriate range)

The change in c[ℓ] is:
Δc[ℓ] = dx * [change from h[i] terms + change from h[j] terms]

h[i] appears in c[ℓ] as:
- h[i] * (1-h[i+ℓ]) if i+ℓ is valid → change: -δ * (1-h[i+ℓ])
- h[i-ℓ] * (1-h[i]) if i-ℓ is valid → change: -h[i-ℓ] * (-δ) = h[i-ℓ] * δ

h[j] = h[i+m] appears in c[ℓ] as:
- h[j] * (1-h[j+ℓ]) if j+ℓ is valid → change: +δ * (1-h[j+ℓ])
- h[j-ℓ] * (1-h[j]) if j-ℓ is valid → change: -h[j-ℓ] * δ

So:
Δc[ℓ] = dx * [-δ*(1-h[i+ℓ]) * 1{i+ℓ valid} + δ*h[i-ℓ] * 1{i-ℓ valid} + δ*(1-h[j+ℓ]) * 1{j+ℓ valid} - δ*h[j-ℓ] * 1{j-ℓ valid}]

= dx * δ * [-(1-h[i+ℓ]) * 1{i+ℓ valid} + h[i-ℓ] * 1{i-ℓ valid} + (1-h[j+ℓ]) * 1{j+ℓ valid} - h[j-ℓ] * 1{j-ℓ valid}]

This is O(1) per lag! So I can compute the change in ALL lags in O(N) time (one per lag), and then check if the max decreased. This makes the local search O(N²) per round (O(N) moves × O(N) cost per move evaluation), which for N=300 is 90,000 per round. At ~0.1ms per round, we can do 100,000+ rounds in a minute.

def compute_lag_change(h, N, i, j, delta, lags=None):
    """Compute the change in each lag's value when h[i] += delta and h[j] -= delta.
    Returns array of changes, same shape as compute_all_lags output."""
    dx = 2.0 / N
    if lags is None:
        lags = np.arange(-(N-1), N)
    
    changes = np.zeros(2*N - 1)
    
    # For each lag ℓ:
    # Δc[ℓ] = dx * [change from h[i] terms + change from h[j] terms]
    # h[i] increases by delta:
    #   - In term h[i]*(1-h[i+ℓ]): contributes delta*(1-h[i+ℓ]) if i+ℓ valid
    #   - In term h[i-ℓ]*(1-h[i]): contributes -delta*h[i-ℓ] if i-ℓ valid
    # h[j] decreases by delta:
    #   - In term h[j]*(1-h[j+ℓ]): contributes -delta*(1-h[j+ℓ]) if j+ℓ valid
    #   - In term h[j-ℓ]*(1-h[j]): contributes delta*h[j-ℓ] if j-ℓ valid
    
    for idx, ell in enumerate(lags):
        chg = 0.0
        # h[i] terms
        ip = i + ell
        if 0 <= ip < N:
            chg += delta * (1 - h[ip])
        im = i - ell
        if 0 <= im < N:
            chg -= delta * h[im]
        # h[j] terms (h[j] decreases by delta, so contribution is negative)
        jp = j + ell
        if 0 <= jp < N:
            chg -= delta * (1 - h[jp])
        jm = j - ell
        if 0 <= jm < N:
            chg += delta * h[jm]
        changes[idx] = dx * chg
    
    return changes
