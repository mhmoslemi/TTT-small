Let me define:
- f_all[k] for k = 0, ..., 2n-2 (from np.correlate(h, 1-h, 'full'))
- lag(k) = k - (n-1)

For coordinate i, the partial derivative ∂f_all[k]/∂h[i]:

f_all[k] = sum_j h[j] * (1 - h[j + lag(k)])
where the sum is over valid j (0 ≤ j ≤ n-1 and 0 ≤ j+lag(k) ≤ n-1).

h[i] appears in this sum in two ways:
1. As h[j] with j = i: contributes (1 - h[i + lag(k)]) if 0 ≤ i+lag(k) ≤ n-1
2. As h[j+lag(k)] with j+lag(k) = i, i.e., j = i - lag(k): contributes -h[j] = -h[i - lag(k)] if 0 ≤ i-lag(k) ≤ n-1

So: ∂f_all[k]/∂h[i] = (1 - h[i + lag(k)]) * [0 ≤ i+lag(k) ≤ n-1] - h[i-lag(k)] * [0 ≤ i-lag(k) ≤ n-1]

Now, f_all[k] as a function of h[i] (with other h's fixed) is:
f_all[k](t) = f_all[k] - old_hi * grad_k + t * grad_k = f_all[k] + (t - old_hi) * grad_k

where grad_k = ∂f_all[k]/∂h[i].

So I want to minimize max_k (f_all[k] + (t - old_hi) * grad_k) over t ∈ [0, 1].

Let a_k = grad_k and b_k = f_all[k] - old_hi * grad_k (= f_all[k] at h[i]=0).

Then I want min_{t∈[0,1]} max_k (a_k * t + b_k).

This is a 1D convex piecewise-linear optimization. I'll solve it by evaluating at candidate points.

For efficiency, I'll use the following approach:
1. Compute a (length 2n-1) and b (length 2n-1).
2. The function g(t) = max_k (a_k * t + b_k) is convex.
3. Find its minimum on [0,1].

To find the minimum efficiently:
- The minimum is at t=0, t=1, or at a point where the derivative changes sign.
- The derivative (subgradient) at t is a_{k*(t)} where k*(t) = argmax_k (a_k * t + b_k).
- So the minimum is at the point where a_{k*(t)} = 0 (or the subgradient contains 0).

A practical approach:
1. Evaluate g at t=0 and t=1.
2. Do a ternary search (or binary search on the subgradient) to find the minimum.
