   Simplified: 0 ≤ t ≤ min(h[i], 1-h[j]) (assuming h is already in [0,1])

   For this 2-variable problem, each lag becomes:
   L_k = C_k + t * D_k
   
   where D_k is the net effect of transferring t from i to j on lag k.
   
   Then I need to minimize max_k (C_k + t * D_k) over t in [0, min(h[i], 1-h[j])].
   
   This is a 1D convex optimization (max of linear functions = convex). The minimum is at a point where two constraints are tight, or at the boundary.

   I can find the optimal t by:
   1. Evaluating at t=0 and t=t_max
   2. Finding the point where the maximum switches from one lag to another
   3. Or just using a ternary/golden section search on [0, t_max]

   This is O(n) per pair evaluation (to compute all lags), and there are O(n^2) pairs, so one full pass is O(n^3). For n=300, that's 27 million operations per pass, which is fine.

   But we don't need to check all pairs. We can focus on pairs that are likely to be useful:
   - Pairs where h[i] > 0.5 and h[j] < 0.5 (transferring from high to low)
   - Pairs that are "close" to each other (small |i-j|)
   - Pairs that affect the worst lag

ΔL_k = t * (∂L_k/∂h[j] - ∂L_k/∂h[i]) = t * D_k

So L_k(t) = L_k + t * D_k, which is linear in t. The min over t of max_k (L_k + t * D_k) is a 1D LP (or equivalently, a 1D convex optimization).

The optimal t is at a point where two or more constraints are tight, or at the boundary of the feasible region [0, t_max].

To find it: the function f(t) = max_k (L_k + t * D_k) is a convex piecewise-linear function of t. Its minimum is at a breakpoint or at the boundary.

The breakpoints are at values of t where L_k + t * D_k = L_l + t * D_l for some pair (k,l), i.e., t = (L_l - L_k) / (D_k - D_l) (when D_k ≠ D_l).

But there are O(n^2) such breakpoints for O(n) lags, so it's not practical to enumerate them. Instead, I'll use a ternary search or golden section search on the 1D function f(t).

Since f is convex and piecewise linear, ternary search converges in O(log(range/epsilon)) iterations.

    if h[i] < h[j]:
        i, j = j, i
    t_max = min(h[i], 1.0 - h[j])
    if t_max < 1e-12:
        return 0.0
    
    # Compute D_k = grad_k[j] - grad_k[i] for all k
    # Actually, let's just evaluate f(t) directly for speed
    
    best_t = 0.0
    best_f = compute_c5(h, n)
    
    # Golden section search
    gr = (np.sqrt(5) - 1) / 2
    a, b = 0.0, t_max
    c1 = b - gr * (b - a)
    c2 = a + gr * (b - a)
    
    h[i] -= c1; h[j] += c1
    f1 = compute_c5(h, n)
    h[i] += c1; h[j] -= c1
    
    h[i] -= c2; h[j] += c2
    f2 = compute_c5(h, n)
    h[i] += c2; h[j] -= c2
    
    for _ in range(40):
        if f1 < f2:
            b = c2; c2 = c1; f2 = f1
            c1 = b - gr * (b - a)
            h[i] -= c1; h[j] += c1
            f1 = compute_c5(h, n)
            h[i] += c1; h[j] -= c1
        else:
            a = c1; c1 = c2; f1 = f2
            c2 = a + gr * (b - a)
            h[i] -= c2; h[j] += c2
            f2 = compute_c5(h, n)
            h[i] += c2; h[j] -= c2
    
    t_opt = (a + b) / 2
    h[i] -= t_opt; h[j] += t_opt
    f_opt = compute_c5(h, n)
    h[i] += t_opt; h[j] -= t_opt
    
    if f_opt < best_f:
        h[i] -= t_opt
        h[j] += t_opt
        best_f = f_opt
        best_t = t_opt

Now let me think about what's really going to make the difference. The previous program got 0.380865 and we need 0.38085. The difference is 1.5e-5.

I think the key improvements are:
1. **Better gradient computation** - use the exact gradient of the smooth max rather than numerical approximations
2. **Smarter line search** - use the fact that the objective is piecewise quadratic to find exact 1D minima
3. **More thorough local search** - try more pairs and use exact 1D optimization for each

Let me focus on making the local search really good. The key insight is that for a pair (i,j), the objective as a function of the transfer t is the max of linear functions (since each L_k is linear in t for fixed i,j). The minimum of this convex piecewise-linear function can be found exactly.

Wait, is each L_k linear in t? Let's check:
L_k = sum_i h[i](1-h[i+k])
After transfer: h[i] → h[i] - t*δ_{i,i0} + t*δ_{i,j0}

L_k(t) = sum_i (h[i] - t*δ_{i,i0} + t*δ_{i,j0})*(1 - h[i+k] + t*δ_{i+k,j0} - t*δ_{i+k,i0})

This has quadratic terms in t! Specifically:
- (-t*δ_{i,i0})*(t*δ_{i+k,j0}) = -t² * δ_{i,i0}*δ_{i+k,j0}
- (t*δ_{i,j0})*(-t*δ_{i+k,i0}) = -t² * δ_{i,j0}*δ_{i+k,i0}

So L_k(t) is actually quadratic in t, not linear! The quadratic term is non-zero only when {i0, j0} and {i0+k, j0+k} have a specific relationship.

Specifically:
- Term 1: i = i0 and i+k = j0, i.e., k = j0 - i0
- Term 2: i = j0 and i+k = i0, i.e., k = i0 - j0

So for lag k = j0 - i0: there's a -t² term (or +t², let me be careful)
For lag k = i0 - j0 = -(j0 - i0): there's another quadratic term.

Let me work this out more carefully:
L_k(t) = L_k(0) + t * A_k + t² * B_k

where:
A_k = sum_i [(-δ_{i,i0} + δ_{i,j0})*(1-h[i+k]) + h[i]*(δ_{i+k,j0} - δ_{i+k,i0})]
   = (-(1-h[i0+k]) + (1-h[j0+k])) + (h[j0-k] - h[i0-k])
   [where the terms only contribute when the indices are valid]

B_k = sum_i [(-δ_{i,i0})*(δ_{i+k,j0}) + (δ_{i,j0})*(-δ_{i+k,i0})]
   = -δ_{i0+k,j0} - δ_{j0+k,i0}
   [contributing only when valid]

So B_k is:
- For k = j0 - i0: B = -1 (from first term, i = i0, i+k = i0 + j0 - i0 = j0) → -1
  Also check second term: i = j0, i+k = j0 + j0 - i0 = 2j0 - i0. This equals i0 only if 2j0 = 2i0, i.e., j0 = i0 (impossible since they're different). So B_k = -1 for k = j0-i0.
  
- For k = i0 - j0: B = -δ_{i0+k,j0} - δ_{j0+k,i0}
  First term: i0 + (i0-j0) = 2i0 - j0. Equals j0 only if 2i0 = 2j0, impossible.
  Second term: j0 + (i0-j0) = i0. Equals i0 ✓. So B = -1 for k = i0-j0.

- For all other k: B_k = 0.

So:
- L_{j0-i0}(t) = L_{j0-i0}(0) + A_{j0-i0} * t - t²
- L_{i0-j0}(t) = L_{i0-j0}(0) + A_{i0-j0} * t - t²
- L_k(t) = L_k(0) + A_k * t for all other k

This is very useful! The max of these functions is:
f(t) = max(L_{j0-i0}(0) + A_{j0-i0}*t - t², L_{i0-j0}(0) + A_{i0-j0}*t - t², max_k (L_k(0) + A_k*t))

The first two are concave quadratics (opening downward), the rest are linear. The max of these is... not necessarily convex! The -t² terms make it concave in those directions.

Hmm, so the 1D problem is not convex. This makes exact optimization harder. But for small t (which is typically the case in local search), the quadratic term is negligible and the function is approximately linear/convex.

For practical purposes, I'll just do a golden section or ternary search on the 1D function. It might have a local minimum that's not global, but in practice (for small t ranges) it should work fine.

Actually wait - the -t² term means the function goes to -infinity as t → ±∞ for those specific lags. But since we're bounded by t ∈ [0, t_max] and t_max is small (at most 1), the quadratic term is at most -1, which is a significant effect.

Let me just use a dense grid + refinement approach for the 1D search:
1. Evaluate f(t) at N points in [0, t_max]
2. Find the best point
3. Do golden section search around it

For N=50 points, this is 50 * O(n) = 50 * 300 = 15000 operations per pair. With golden section, another 40 * O(n) = 12000. Total: ~27000 per pair.

If I check 1000 pairs per "round", that's 27M operations per round. In numpy, this might take 1-2 seconds. So I can do ~50-100 rounds in a minute. That should be enough.

import numpy as np
from scipy.optimize import minimize
import time

def compute_all_lags(h, n):
    dx = 2.0 / n
    return np.correlate(h, 1.0 - h, mode='full') * dx

def compute_c5(h, n):
    return float(np.max(compute_all_lags(h, n)))

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h.copy(), 0.0, 1.0)
    for _ in range(200):
        diff = target - h.sum()
        if abs(diff) < 1e-15:
            break
        if diff > 0:
            room = 1.0 - h
            tot = room.sum()
            if tot < 1e-15:
                break
            h += (diff / tot) * room
        else:
            tot = h.sum()
            if tot < 1e-15:
                break
            h += (diff / tot) * h
    return np.clip(h, 0.0, 1.0)

def smooth_max(c, alpha):
    m = c.max()
    shifted = alpha * (c - m)
    mx = shifted.max()
    if mx > 500:
        return float(m + (mx + np.log(np.sum(np.exp(shifted - mx)))) / alpha)
    return float(m + np.log(np.sum(np.exp(shifted))) / alpha)

def smooth_max_and_weights(c, alpha):
    m = c.max()
    shifted = alpha * (c - m)
    mx = shifted.max()
    e = np.exp(shifted - mx)
    s = e.sum()
    p = e / s
    val = float(m + (mx + np.log(s)) / alpha)
    return val, p

def grad_lag(h, n, k):
    g = np.zeros(n)
    if k >= 0:
        i1 = np.arange(0, n - k)
        g[i1] += (1.0 - h[i1 + k])
        i2 = np.arange(k, n)
        g[i2] -= h[i2 - k]
    else:
        m = -k
        i1 = np.arange(0, n - m)
        g[i1] += (1.0 - h[i1 + m])
        i2 = np.arange(m, n)
        g[i2] -= h[i2 - m]
    return g

def full_gradient(h, n, alpha):
    """Gradient of smooth max of all lags."""
    c = compute_all_lags(h, n)
    _, p = smooth_max_and_weights(c, alpha)
    grad = np.zeros(n)
    for k_idx in range(2 * n - 1):
        if p[k_idx] < 1e-10:
            continue
        k = k_idx - (n - 1)
        grad += p[k_idx] * grad_lag(h, n, k)
    return grad

def projected_gradient_step(h, n, grad, step_size):
    """Take a gradient step and project onto feasible set."""
    h_new = h - step_size * grad
    # Project onto {0 <= h <= 1, sum(h) = n/2}
    # Use bisection on lambda
    target = n / 2.0
    lo, hi = -2.0, 2.0
    for _ in range(60):
        mid = (lo + hi) / 2
        h_proj = np.clip(h_new - mid, 0.0, 1.0)
        s = h_proj.sum()
        if s > target:
            lo = mid
        else:
            hi = mid
    h_proj = np.clip(h_new - (lo + hi) / 2, 0.0, 1.0)
    return h_proj

def gradient_descent(h, n, deadline, alpha_start=100, alpha_end=10000):
    """Smooth gradient descent with adaptive step size."""
    h = h.copy()
    best_h = h.copy()
    best_c = compute_c5(h, n)
    step = 0.01
    current_alpha = alpha_start
    n_total = 2 * n - 1
    log_alpha_start = np.log(alpha_start)
    log_alpha_end = np.log(alpha_end)
    total_iters = 5000
    it = 0
    while time.time() < deadline and it < total_iters:
        # Schedule alpha
        frac = it / total_iters
        current_alpha = np.exp(log_alpha_start + frac * (log_alpha_end - log_alpha_start))
        
        c = compute_all_lags(h, n)
        c_val = compute_c5(h, n)
        if c_val < best_c:
            best_c = c_val
            best_h = h.copy()
        
        grad = full_gradient(h, n, current_alpha)
        grad_norm = np.linalg.norm(grad)
        if grad_norm < 1e-10:
            break
        
        # Backtracking line search
        alpha_try = step
        for _ in range(20):
            h_trial = projected_gradient_step(h, n, grad, alpha_try)
            c_trial = compute_c5(h_trial, n)
            if c_trial < c_val - 1e-15:
                break
            alpha_try *= 0.5
        
        if alpha_try > 0:
            h = h_trial
            step = min(step * 1.1, 0.05)
        else:
            step *= 0.5
            if step < 1e-8:
                break
        it += 1
    
    return best_h, best_c

def pair_optimize(h, n, i, j, c_current):
    """Find optimal transfer from i to j (assuming h[i] >= h[j])."""
    if h[i] < h[j]:
        i, j = j, i
    t_max = min(h[i], 1.0 - h[j])
    if t_max < 1e-10:
        return 0.0, c_current
    
    # Evaluate on a grid
    n_grid = 20
    t_grid = np.linspace(0, t_max, n_grid)
    c_grid = np.zeros(n_grid)
    for idx, t in enumerate(t_grid):
        h[i] -= t
        h[j] += t
        c_grid[idx] = compute_c5(h, n)
    h[i] += t_grid[-1]
    h[j] -= t_grid[-1]
    
    best_idx = np.argmin(c_grid)
    if c_grid[best_idx] >= c_current - 1e-14:
        return 0.0, c_current
    
    # Refine with golden section
    if best_idx == 0:
        a, b = 0.0, t_grid[1]
    elif best_idx == n_grid - 1:
        a, b = t_grid[-2], t_max
    else:
        a, b = t_grid[max(0, best_idx-1)], t_grid[min(n_grid-1, best_idx+1)]
    
    gr = (np.sqrt(5) - 1) / 2
    c1 = b - gr * (b - a)
    c2 = a + gr * (b - a)
    
    h[i] -= c1; h[j] += c1
    f1 = compute_c5(h, n)
    h[i] += c1; h[j] -= c1
    
    h[i] -= c2; h[j] += c2
    f2 = compute_c5(h, n)
    h[i] += c2; h[j] -= c2
    
    for _ in range(30):
        if f1 < f2:
            b = c2; c2 = c1; f2 = f1
            c1 = b - gr * (b - a)
            h[i] -= c1; h[j] += c1
            f1 = compute_c5(h, n)
            h[i] += c1; h[j] -= c1
        else:
            a = c1; c1 = c2; f1 = f2
            c2 = a + gr * (b - a)
            h[i] -= c2; h[j] += c2
            f2 = compute_c5(h, n)
            h[i] += c2; h[j] -= c2
    
    t_opt = (a + b) / 2
    f_opt = min(f1, f2, c_current)
    
    # Evaluate at the final point
    h[i] -= t_opt; h[j] += t_opt
    f_final = compute_c5(h, n)
    if f_final < f_opt:
        f_opt = f_final
    h[i] += t_opt; h[j] -= t_opt
    
    if f_opt < c_current - 1e-14:
        h[i] -= t_opt
        h[j] += t_opt
        return t_opt, f_opt
    else:
        return 0.0, c_current

def local_search_pairs(h, n, deadline, max_rounds=500):
    """Intensive local search using pair transfers."""
    h = h.copy()
    best_c = compute_c5(h, n)
    rng = np.random.RandomState(123)
    
    for rnd in range(max_rounds):
        if time.time() > deadline:
            break
        
        c = compute_all_lags(h, n)
        k_star = int(np.argmax(c))
        lag = k_star - (n - 1)
        
        # Determine valid range for this lag
        if lag >= 0:
            valid_start = 0
            valid_end = n - lag
        else:
            valid_start = -lag
            valid_end = n
        
        # Generate candidate pairs
        # Priority 1: pairs within valid range with large h difference
        # Priority 2: random pairs
        candidates = []
        
        # Add pairs from valid range sorted by |h[i] - h[j]|
        valid_idx = np.arange(valid_start, valid_end)
        if len(valid_idx) > 2:
            # Take top 50 pairs by |difference|
            diffs = np.abs(h[valid_idx][:, None] - h[valid_idx][None, :])
            np.fill_diagonal(diffs, 0)
            flat_idx = np.argsort(diffs.ravel())[::-1][:100]
            for fi in flat_idx:
                ii, jj = np.unravel_index(fi, diffs.shape)
                if ii < jj:
                    candidates.append((valid_idx[ii], valid_idx[jj]))
            # Remove duplicates
            candidates = list(set(candidates))[:100]
        
        # Add some random pairs
        for _ in range(50):
            i = rng.randint(n)
            j = rng.randint(n)
            if i != j:
                candidates.append((min(i,j), max(i,j)))
        
        improved = False
        for i, j in candidates:
            if time.time() > deadline:
                break
            if h[i] < h[j]:
                i, j = j, i
            _, best_c_new = pair_optimize(h, n, i, j, best_c)
            if best_c_new < best_c - 1e-12:
                best_c = best_c_new
                improved = True
        
        if not improved:
            # Try more random pairs
            any_improve = False
            for _ in range(200):
                if time.time() > deadline:
                    break
                i = rng.randint(n)
                j = rng.randint(n)
                if i == j:
                    continue
                _, best_c_new = pair_optimize(h, n, i, j, best_c)
                if best_c_new < best_c - 1e-12:
                    best_c = best_c_new
                    any_improve = True
            if not any_improve:
                break
    
    return h, best_c

def active_set_refine(h, n, deadline):
    """Optimize focusing on the top few active lags."""
    h = h.copy()
    best_c = compute_c5(h, n)
    
    for _ in range(20):
        if time.time() > deadline:
            break
        c = compute_all_lags(h, n)
        top_m = 3
        top_idx = np.argsort(c)[-top_m:]
        
        # Optimize smooth max of just the active lags
        def active_obj(x):
            cc = compute_all_lags(x, n)
            active = cc[top_idx]
            return smooth_max(active, 10000)
        
        def sum_con(x):
            return x.sum() - n / 2.0
        
        def sum_con_jac(x):
            return np.ones(n)
        
        bounds = [(0.0, 1.0)] * n
        cons = [{'type': 'eq', 'fun': sum_con, 'jac': sum_con_jac}]
        
        try:
            res = minimize(active_obj, h, method='SLSQP', bounds=bounds,
                         constraints=cons, options={'maxiter': 2000, 'ftol': 1e-16})
            h_new = project_feasible(res.x, n)
            c_new = compute_c5(h_new, n)
            if c_new < best_c:
                best_c = c_new
                h = h_new
            else:
                break
        except:
            break
    
    return h, best_c

def optimize_quick(h, n, deadline):
    """Quick optimization at a given resolution."""
    h = project_feasible(h.copy(), n)
    best_c = compute_c5(h, n)
    
    if time.time() < deadline - 20:
