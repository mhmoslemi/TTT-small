The correlation changes at most O(n) entries. Specifically:
- For shift d ≥ 0: c[d] changes if a or b is in the range [0, n-1-d] (as the "second" factor) or [d, n-1] (as the "first" factor).
- The change at each affected shift is at most ±2.

So after a swap, the new c array differs from the old one in at most 2n entries, each by at most 2.

If the current max is M at shift d*, then after the swap:
- If d* is affected: new c[d*] = old c[d*] + delta (|delta| ≤ 2)
- If d* is not affected: new c[d*] = M (unchanged)
- Other shifts that were M - 1 could now be M + 1 if affected

So the new max is at most M + 2, and at least M (if d* not affected) or M - 2 (if d* affected and delta = -2).

To check if a swap improves things, we need:
- max(new c) < M
- This requires: (1) d* is affected and c[d*] decreased, AND (2) no other shift increased above M.

Since each shift changes by at most 2, and we need the max to decrease by at least 1 (since values are integers for binary), we need:
- The shifts that were at M must all decrease (or at least one must decrease and none increase)
- No shift at M-1 can increase by 2 (to become M+1)

Let me think about an efficient local search:

1. Compute c = correlate(h, 1-h), find all shifts where c[d] = M (the max).
2. For a swap (a, b), compute the delta for each of these "max" shifts.
3. If all max shifts decrease (or at least one decreases and none stay or increase), and no non-max shift increases above M, then the swap improves.

But checking "no non-max shift increases above M" requires checking all shifts, which is O(n). However, a shift can increase by at most 2, so only shifts at M-1 can become M+1. We only need to check shifts at M-1.

So the algorithm is:
- Identify "critical" shifts: those at M and M-1
- For each swap, check only the critical shifts
- This reduces the per-swap cost from O(n) to O(|critical|) which is typically small

```python
def local_search_binary(h, n, deadline):
    """Efficient local search on binary vectors."""
    h = h.copy()
    c = np.correlate(h, 1-h, mode='full')
    max_c = c.max()
    best_max = max_c
    
    ones = np.where(h == 1)[0]
    zeros = np.where(h == 0)[0]
    
    improved = True
    while improved:
        improved = False
        best_swap = None
        best_new_max = max_c
        
        for i in zeros:
            for j in ones:
                # Try swapping i and j
                h[i], h[j] = 1, 0
                c_new = np.correlate(h, 1-h, mode='full')
                new_max = c_new.max()
                if new_max < best_new_max:
                    best_new_max = new_max
                    best_swap = (i, j)
                h[i], h[j] = 0, 1
                c = np.correlate(h, 1-h, mode='full')  # restore (or just keep old c)
        
        if best_swap is not None:
            i, j = best_swap
            h[i], h[j] = 1, 0
            c = np.correlate(h, 1-h, mode='full')
            max_c = c.max()
            best_max = min(best_max, max_c)
            ones = np.where(h == 1)[0]
            zeros = np.where(h == 0)[0]
            improved = True
    
    return h, best_max
```
