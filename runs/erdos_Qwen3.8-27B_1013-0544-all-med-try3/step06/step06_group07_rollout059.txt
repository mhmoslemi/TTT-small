**Proper Coordinate Descent with Equality Constraint**

At each step, pick coordinate p. The constraint sum(h) = n/2 means that if we change h[p] from t_old to t_new, the total change in sum is (t_new - t_old). We need to distribute this change across all other coordinates.

The simplest way: distribute uniformly. If we change h[p] by δ, we change all other coordinates by -δ/(n-1).

But this is a coupled change. The objective as a function of t_new becomes more complex.

Alternative: Use a "pivot" coordinate. Pick p and q. Change h[p] by δ and h[q] by -δ. Then the sum is maintained. The objective becomes a function of δ (1D), and we can minimize it exactly.

This is a 2-coordinate coordinate descent! At each step:
1. Pick pair (p, q)
2. Compute the 1D objective as a function of δ: h[p] += δ, h[q] -= δ
3. Find optimal δ
4. Update

The 1D objective is max_j (s_j * δ + d_j) where s_j and d_j can be computed from the current h.

This is clean and maintains feasibility exactly!

```python
def two_coordinate_step(h, p, q):
    """Find optimal δ such that h[p]+=δ, h[q]-=δ minimizes C5."""
    n = len(h)
    dx = 2.0 / n
    
    # Save current values
    hp = h[p]
    hq = h[q]
    
    # Set h[p] = 0, h[q] = 0 temporarily to get the "base" correlation
    # Actually, let's compute the effect analytically
    
    # Current correlation
    corr = np.correlate(h, 1.0 - h, mode='full')
    
    # Effect of changing h[p] by δ and h[q] by -δ:
    # For each lag j, the change in c_j is:
    # Δc_j = δ * (contribution of h[p] being increased) + (-δ) * (contribution of h[q] being increased)
    #       = δ * S_p,j - δ * S_q,j
    # where S_p,j is the "sensitivity" of c_j to h[p]
    
    # S_p,j = (coefficient of h[p] in c_j) - (coefficient of (1-h[p]) in c_j)
    # ... this is getting complicated. Let me just compute it numerically.
    
    # Set h[p] = 0, h[q] = 0
    h[p] = 0.0
    h[q] = 0.0
    corr_base = np.correlate(h, 1.0 - h, mode='full')
    
    # Now c_j(δ) where h[p] = δ, h[q] = -δ:
    # We need to be careful: h[p] = hp + δ, h[q] = hq - δ
    # So let's set h[p] = hp, h[q] = hq and compute the linear effect of δ
    
    h[p] = hp
    h[q] = hq
    
    # Compute sensitivity of c_j to h[p]:
    # c_j = sum h[a]*(1-h[b]) over valid (a,b) pairs
    # dc_j/dh[p] = (sum of (1-h[b]) where a=p) - (sum of h[a] where b=p)
    
    # Let me compute this by finite difference for clarity:
    eps = 1e-8
    h[p] = hp + eps
    corr_p = np.correlate(h, 1.0 - h, mode='full')
    h[p] = hp
    
    h[q] = hq + eps
    corr_q = np.correlate(h, 1.0 - h, mode='full')
    h[q] = hq
    
    # dc_j/dh[p] ≈ (corr_p - corr) / eps
    # dc_j/dh[q] ≈ (corr_q - corr) / eps
    # 
    # c_j(δ) = c_j + δ * dc_j/dh[p] - δ * dc_j/dh[q]
    #         = c_j + δ * (dc_j/dh[p] - dc_j/dh[q])
    
    sensitivity = (corr_p - corr_q)  # This is eps * (dc/dh[p] - dc/dh[q])
    # So c_j(δ) ≈ corr[j] + (δ/eps) * sensitivity[j]
    # Let's define s_j = sensitivity[j] / eps = dc_j/dh[p] - dc_j/dh[q]
    
    s = sensitivity / eps
    d = corr  # base value
    
    # Minimize max_j (d[j] + δ * s[j]) * dx over δ such that:
    # 0 ≤ hp + δ ≤ 1 and 0 ≤ hq - δ ≤ 1
    # i.e., -hp ≤ δ ≤ 1-hp and hq-1 ≤ δ ≤ hq
    
    lo = max(-hp, hq - 1.0)
    hi = min(1.0 - hp, hq)
    
    if lo >= hi:
        return h  # no feasible δ
    
    # Minimize max_j (d[j] + s[j]*δ) over δ ∈ [lo, hi]
    # This is a 1D convex minimization
    
    def g(delta):
        return np.max(d + s * delta)
    
    from scipy.optimize import minimize_scalar
    res = minimize_scalar(g, bounds=(lo, hi), method='bounded', options={'xatol': 1e-14})
    
    h[p] = hp + res.x
    h[q] = hq - res.x
    
    return h
```

    h = np.clip(h, 0.0, 1.0)
    for _ in range(50):
        s = h.sum()
        if abs(s - target_sum) < 1e-12:
            break
        diff = target_sum - s
        if diff > 0:
            mask = h < 1.0
        else:
