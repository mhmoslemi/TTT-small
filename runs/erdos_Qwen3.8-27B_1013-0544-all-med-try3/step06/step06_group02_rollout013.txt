def gradient_directed_search(h, n, deadline, alpha=10000):
    """Efficient local search guided by the smooth-max gradient."""
    best_c = compute_c5(h, n)
    best_h = h.copy()
    
    while time.time() < deadline:
        g = smooth_max_grad(h, n, alpha, mu=0)  # Gradient without constraint penalty
        # Normalize gradient for direction
        g_avg = g.mean()
        g_centered = g - g_avg
        
        # Sort by gradient (we want to move mass from high-g to low-g)
        order = np.argsort(g_centered)
        
        improved = False
        # Try moves: take from high gradient, give to low gradient
        for k_idx in range(n // 2):
            i = order[n - 1 - k_idx]  # High gradient
            j = order[k_idx]           # Low gradient
            diff = g_centered[i] - g_centered[j]
            if diff < 1e-10:
                continue
            
            # Determine direction: move mass from i to j
            # Amount: try a small step
            step = min(0.01, 0.5 * abs(diff))
            
            if h[i] - step >= 0 and h[j] + step <= 1:
                h[i] -= step
                h[j] += step
                c = compute_c5(h, n)
                if c < best_c - 1e-14:
                    best_c = c
                    best_h = h.copy()
                    improved = True
                else:
                    h[i] += step
                    h[j] -= step
            elif h[i] + step <= 1 and h[j] - step >= 0:
                h[i] += step
                h[j] -= step
                c = compute_c5(h, n)
                if c < best_c - 1e-14:
                    best_c = c
                    best_h = h.copy()
                    improved = True
                else:
                    h[i] -= step
                    h[j] += step
        
        if not improved:
            # Try smaller steps
            alpha *= 2
            if alpha > 1e6:
                break
    
    return best_h, best_c

1. **Coordinate descent**: For each coordinate i, find the optimal value of h[i] (given all other h[j]) that minimizes the objective. This is a 1D optimization problem (minimize a function of one variable).
2. **Cyclic**: Go through coordinates in order, updating each one.

For coordinate i, the objective as a function of h[i] = t is:

where c_k(j, t) is the contribution to shift k's correlation from position j, as a function of t.

For a given shift k, the correlation is:
c_k = sum_j h[j+k](1-h[j]) (for k >= 0, say)

The terms involving h[i] = t are:
- If i >= k: h[i] appears as h[j+k] with j = i-k, contributing t * (1-h[i-k])
- If i <= n-1-k: h[i] appears as h[j] with j = i, contributing h[i+k] * (1-t)

So c_k(t) = (other terms) + t*(1-h[i-k]) * I[i>=k] + h[i+k]*(1-t) * I[i<=n-1-k]
= (other terms) + t*(1-h[i-k])*I[i>=k] + h[i+k]*I[i<=n-1-k] - t*h[i+k]*I[i<=n-1-k]

This is linear in t! So for a fixed k, c_k is linear in t.

Therefore f(t) = max_k (a_k * t + b_k) is a piecewise linear function of t (convex, as max of linear functions).

The minimum of f(t) over t ∈ [0,1] occurs at a breakpoint or at the boundary. The breakpoints are where two lines cross.

This means coordinate descent is very efficient! For each coordinate, we can find the optimal t in O(n) time (compute all the a_k and b_k, then find the min of the max of lines).

But wait, we also have the constraint sum(h) = n/2. If we change h[i], we need to adjust another coordinate to maintain the constraint. So pure coordinate descent doesn't directly work.

We can handle this by:
- Using the penalty method (add mu*(sum(h) - n/2)² to the objective)
- Or using the "two-coordinate" method: update h[i] and h[j] simultaneously

For the two-coordinate method, we fix all h except h[i] and h[j], and optimize over (t_i, t_j) subject to t_i + t_j = h[i] + h[j] (to maintain the sum constraint). This reduces to a 1D problem: set t_i = h[i] + s, t_j = h[j] - s, and minimize f(s) over s ∈ [-h[i], 1-h[j]].

f(s) = max_k (a_k * s + b_k) is again piecewise linear. We can find the minimum in O(n) time.

    # such that c_k(t) <= V for all k. This is a system of linear inequalities in t:
    # a_k * t + b_k <= V for all k
    # ⟹ t <= (V - b_k) / a_k for a_k > 0
    # ⟹ t >= (V - b_k) / a_k for a_k < 0
    # So we need max_{k: a_k<0} (V-b_k)/a_k <= t <= min_{k: a_k>0} (V-b_k)/a_k
    # plus t ∈ [lo, hi]
    # The smallest V for which this is feasible is our answer.
    # This is a linear program in (t, V) but in 2D, so we can solve it geometrically.
    
    # Simpler approach: since f(t) is convex piecewise linear with at most 2n-1 breakpoints,
    # we can find all breakpoints and evaluate f at each.
    
    # But that's O(n²) in the worst case. For n=300, that's 90000, which is fine for 
    # a single coordinate update but might be slow for many updates.
    
    # Let's use a simpler approach: ternary search or golden section search
    # Since f is convex (piecewise linear), golden section works.
    
    def f_of_t(t):
        h_test = h.copy()
        h_test[i] = t
        h_test[j] = h[i] + h[j] - t
        c = np.max(np.correlate(h_test, 1 - h_test, mode='full')) * (2.0/n)
        return c
    
    # Golden section search
    gr = (np.sqrt(5) - 1) / 2  # golden ratio conjugate
    a, b = lo, hi
    c_point = b - gr * (b - a)
    d_point = a + gr * (b - a)
    f_c = f_of_t(c_point)
    f_d = f_of_t(d_point)
    
    for _ in range(50):
        if f_c < f_d:
            b = d_point
            d_point = c_point
            f_d = f_c
            c_point = b - gr * (b - a)
            f_c = f_of_t(c_point)
        else:
            a = c_point
            c_point = d_point
            f_c = f_d
            d_point = a + gr * (b - a)
            f_d = f_of_t(d_point)
    
    t_opt = (a + b) / 2
    return t_opt, h[i] + h[j] - t_opt
```

```python
import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h, n):
    dx = 2.0 / n
    return float(np.max(np.correlate(h, 1 - h, mode='full')) * dx)

def compute_c5_vec(h, n):
    dx = 2.0 / n
    return np.correlate(h, 1 - h, mode='full') * dx

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h.copy(), 0.0, 1.0)
    for _ in range(500):
        diff = target - h.sum()
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            room = 1.0 - h
            tot = room.sum()
            if tot < 1e-14:
                break
            h += (diff / tot) * room
        else:
            tot = h.sum()
            if tot < 1e-14:
                break
            h += (diff / tot) * h
        h = np.clip(h, 0.0, 1.0)
    return h

def smooth_max_objective(h, n, alpha, mu):
    c = compute_c5_vec(h, n)
    m = c.max()
    d = alpha * (c - m)  # All <= 0
    # log(sum(exp(d))) is safe since d <= 0
    log_sum = np.log(np.sum(np.exp(d)))
    val = m + log_sum / alpha
    val += mu * (h.sum() - n / 2.0) ** 2
    return float(val)

def smooth_max_gradient(h, n, alpha, mu):
    c = compute_c5_vec(h, n)
    m = c.max()
    d = alpha * (c - m)
    e = np.exp(d)
    w = e / e.sum()
    
    grad = np.zeros(n)
    dx = 2.0 / n
    for k_idx in range(2 * n - 1):
        if w[k_idx] < 1e-14:
            continue
        k = k_idx - (n - 1)
        wm = w[k_idx] * dx
        if k >= 0:
            nv = n - k
            grad[0:nv] += wm * (1.0 - h[k:n])
            grad[k:n] += wm * (-h[0:nv])
        else:
            kk = -k
            nv = n - kk
            grad[kk:n] += wm * (1.0 - h[0:nv])
            grad[0:nv] += wm * (-h[kk:n])
    if mu > 0:
        grad += 2.0 * mu * (h.sum() - n / 2.0) * np.ones(n)
    return grad

def lbfgs_optimize(h, n, deadline, max_time_per_alpha=30, alpha_list=None):
    """L-BFGS-B optimization with increasing alpha."""
    if alpha_list is None:
        alpha_list = [100, 500, 2000, 10000, 50000, 200000, 1000000, 5000000]
    
    h = project_feasible(h, n)
    best_c = compute_c5(h, n)
    bounds = [(0.0, 1.0)] * n
    
    for alpha in alpha_list:
        if time.time() > deadline:
            break
        mu = max(10.0, alpha * 0.01)
        
        def obj(x):
            return smooth_max_objective(x, n, alpha, mu)
        
        def grad(x):
            return smooth_max_gradient(x, n, alpha, mu)
        
        t_budget = min(max_time_per_alpha, deadline - time.time())
        if t_budget < 3:
            break
        
        try:
            res = minimize(obj, h, jac=grad, method='L-BFGS-B',
                          bounds=bounds,
                          options={'maxiter': 500, 'ftol': 1e-16,
                                   'gtol': 1e-12, 'maxfun': 5000,
                                   'maxls': 50})
            h_new = project_feasible(res.x, n)
            c_new = compute_c5(h_new, n)
            if c_new < best_c - 1e-15:
                best_c = c_new
                h = h_new
        except Exception:
            pass
    
    return h, best_c

def local_search(h, n, deadline):
    """Efficient local search using gradient-guided pair moves."""
    h = project_feasible(h, n)
    best_c = compute_c5(h, n)
    best_h = h.copy()
    
    step_sizes = [0.05, 0.02, 0.01, 0.005, 0.002, 0.001, 0.0005, 0.0002, 0.0001]
    
    for step in step_sizes:
        if time.time() > deadline:
            break
        
        improved_any = False
        while time.time() < deadline:
            if time.time() - (deadline - (deadline - time.time())) > 10**9:
                pass  # placeholder
            
            improved = False
            g = smooth_max_gradient(h, n, 10000, mu=0)
            
            # Sort by gradient: we want to move from high gradient to low gradient
            order = np.argsort(g)
            
            # Try n/2 pairs: highest gradient with lowest gradient
            n_tried = min(n // 2, 200)
            for k_idx in range(n_tried):
                if time.time() > deadline:
                    return best_h, best_c
                
                i = order[n - 1 - k_idx]  # High gradient (want to decrease)
                j = order[k_idx]           # Low gradient (want to increase)
                
                # Move: decrease h[i], increase h[j]
                if h[i] - step >= 0 and h[j] + step <= 1:
                    h[i] -= step
                    h[j] += step
                    c = compute_c5(h, n)
                    if c < best_c - 1e-14:
                        best_c = c
                        best_h = h.copy()
                        improved = True
                        improved_any = True
                    else:
                        h[i] += step
                        h[j] -= step
                
                # Also try the reverse: increase h[i], decrease h[j]
                if h[i] + step <= 1 and h[j] - step >= 0:
                    h[i] += step
                    h[j] -= step
                    c = compute_c5(h, n)
                    if c < best_c - 1e-14:
                        best_c = c
                        best_h = h.copy()
                        improved = True
                        improved_any = True
                    else:
                        h[i] -= step
                        h[j] += step
            
            if not improved:
                break
        
        if not improved_any:
            continue
    
    return best_h, best_c
