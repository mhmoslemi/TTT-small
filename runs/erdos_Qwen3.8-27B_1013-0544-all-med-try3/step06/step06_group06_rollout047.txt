            if s < 1e-13:

Actually, V depends on h, and h changes after each move. So I do need to update V. But I can update it incrementally:
When h[i] changes by δ and h[j] changes by -δ:
- V changes because h has changed
- V[a, k] depends on h through: (1-h[a-k]) and h[a+k]
- So V[a, k] changes by: -δ_change[a-k] * 𝟙(a-k valid) + δ_change[a+k] * 𝟙(a+k valid)

where δ_change[a] = δ if a=i, -δ if a=j, 0 otherwise.

So the update to V is sparse! Only rows a where a-k = i or a-k = j or a+k = i or a+k = j are affected.

For a change in h[i] by δ:
V[a, k] changes by:
- If a-k = i: -(1) * δ... wait, V[a,k] = (1-h[a-k])*𝟙 + ... 
  If a-k = i, then the term (1-h[a-k]) = (1-h[i]) changes by -δ.
  So V[a,k] += -δ (from the (1-h) term)
  Also, if a+k = i, then the term -h[a+k] = -h[i] changes by -δ... wait.
  V[a,k] = (1-h[a-k])*𝟙(0≤a-k<n) - h[a+k]*𝟙(0≤a+k<n)
  If a+k = i: V[a,k] -= h[i] → V[a,k] changes by -δ (since h[i] increases by δ)

So for a change h[i] += δ:
- For all a, k: V[a,k] changes by:
  - -δ if a-k = i (i.e., a = i+k) and 0≤i<n (always true)
  - -δ if a+k = i (i.e., a = i-k) and 0≤i<n (always true)

V[a,k] = (1-h[a-k])*𝟙(0≤a-k<n) - h[a+k]*𝟙(0≤a+k<n)

∂V[a,k]/∂h[i]:
- First term: (1-h[a-k]) changes by -δ if a-k = i, i.e., a = i+k
  Contribution: -δ * 𝟙(a = i+k, 0≤i<n) = -δ * 𝟙(a = i+k)
- Second term: -h[a+k] changes by -δ if a+k = i, i.e., a = i-k
  Contribution: -δ * 𝟙(a = i-k, 0≤i<n) = -δ * 𝟙(a = i-k)

So: ΔV[a,k] = -δ * (𝟙(a = i+k) + 𝟙(a = i-k)) for k≠0
For k=0: V[a,0] = 1-2h[a], so ΔV[a,0] = -2δ * 𝟙(a=i)

This is very sparse! For each k, only 2 rows change (a = i+k and a = i-k).

Similarly for h[j] -= δ (i.e., h[j] changes by -δ):
ΔV[a,k] = δ * (𝟙(a = j+k) + 𝟙(a = j-k)) for k≠0
ΔV[a,0] = 2δ * 𝟙(a = j)

This means I can update V in O(n) time per move (since for each of the 2n-1 values of k, at most 4 rows change).

This makes the pair sweep much faster!
