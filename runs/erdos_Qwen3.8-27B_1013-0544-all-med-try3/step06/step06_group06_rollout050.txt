So for position p, the affected j range is [n-1-p, 2n-2-p] (length p+1) and also [0, n-1-p] (from the other direction).

Actually, the full set of j where position p matters is:
- p is the source: j ∈ [n-1-p, 2n-2-p] (i.e., n-1-p to 2n-2-p, that's p+1 values)
- p is the target: j ∈ [0, n-1-p] (i.e., 0 to n-1-p, that's n-p values)

Total: p+1 + n-p = n+1 values affected by position p.

For a swap of positions i and j, the total affected correlation indices are those affected by i OR by j, which is at most 2(n+1) indices.

So for each swap, we need to update at most 2(n+1) ≈ 502 correlation values (for n=250), then find the max. That's O(n) per swap, and O(n³) per full sweep.

In Python, with numpy vectorization, each swap evaluation might take ~10-50 μs. A full sweep of C(125,1)*C(125,1) ≈ 15625 swaps would take 0.15-0.8 seconds. With 500 seconds for binary search, that's 600-3000 sweeps. That should be more than enough.

Actually, for the continuous optimization, let me use a different strategy: **proximal gradient method** (also known as ISTA/FISTA) adapted for the max constraint.

The idea:
- We want to minimize f(h) = max_k g_k(h) subject to h ∈ [0,1], sum(h) = n/2
- Use a soft-max approximation: f_α(h) = (1/α) log(sum_k exp(α*g_k(h)))
- The gradient of f_α is: (1/α) * sum_k exp(α*g_k) * ∇g_k / sum_k exp(α*g_k)
  = sum_k p_k * ∇g_k where p_k = exp(α*g_k) / sum exp(α*g_k)
- Take a gradient step: h ← prox_{[0,1], sum=n/2}(h - η * ∇f_α(h))

The proximal operator for the constraint {h ∈ [0,1], sum(h) = n/2} can be computed via bisection on a threshold:
prox(h, t) = clip(h - t, 0, 1) where t is chosen so that sum(prox) = n/2.

This is a clean and efficient algorithm. Let me implement it.

For the gradient of g_k with respect to h:
g_k = dx * sum_p h[p] * (1-h[p+k]) (with bounds, for shift k = j-(n-1))

∂g_k/∂h[q] = dx * [(1-h[q+k']) * I(0≤q+k'≤n-1) - h[q+k''] * I(0≤q+k''≤n-1)]

where k' and k'' depend on the specific correlation index.

Actually, let me just use the formula I derived earlier. For the full correlation output[j]:
output[j] = sum_p h[p] * (1-h[p + j - n + 1])

Let k = j - (n-1). Then:
output[j] = sum_p h[p] * (1-h[p+k])

∂output[j]/∂h[q]:
- h[q] appears as h[p] when p=q: coefficient is (1-h[q+k]) if 0≤q+k≤n-1
- h[q] appears as h[p+k] when p+k=q, i.e., p=q-k: coefficient is -h[q-k] if 0≤q-k≤n-1

So ∂output[j]/∂h[q] = (1-h[q+k]) * I(0≤q+k≤n-1) - h[q-k] * I(0≤q-k≤n-1)

where k = j - (n-1).

For the weighted sum:
∇f_α(q) = dx * sum_j p_j * [(1-h[q+k_j]) * I(0≤q+k_j≤n-1) - h[q-k_j] * I(0≤q-k_j≤n-1)]

This can be computed efficiently if we precompute the weights p_j for each j.

For n=250, there are 499 values of j, and for each j we need to update 250 values of q. That's 499*250 = 124,750 operations per gradient computation. Very fast.

```python
def compute_grad_softmax(h, alpha, n):
    """Compute gradient of softmax approximation of max_k g_k."""
    dx = 2.0 / n
    c = np.correlate(h, 1 - h, mode='full')  # length 2n-1
    g = c * dx
    # Softmax weights
    ag = alpha * g
    ag_max = ag.max()
    exp_ag = np.exp(ag - ag_max)
    p = exp_ag / exp_ag.sum()  # weights for each correlation index
    
    # Compute gradient
    # For correlation index j (0 to 2n-2), shift k = j - (n-1)
    grad = np.zeros(n)
    for j in range(2 * n - 1):
        w = p[j] * dx
        if w < 1e-15:
            continue
        k = j - (n - 1)
        # h[q] as source: (1-h[q+k]) for q+k in [0, n-1]
        # q ranges from max(0, -k) to min(n-1, n-1-k)
        q_lo = max(0, -k)
        q_hi = min(n-1, n-1-k)
        if q_lo <= q_hi:
            idx = np.arange(q_lo, q_hi + 1) + k
            grad[q_lo:q_hi+1] += w * (1 - h[idx])
        # h[q] as target: -h[q-k] for q-k in [0, n-1]
        # q ranges from max(0, k) to min(n-1, n-1+k)
        q_lo2 = max(0, k)
        q_hi2 = min(n-1, n-1+k)
        if q_lo2 <= q_hi2:
            idx2 = np.arange(q_lo2, q_hi2 + 1) - k
            grad[q_lo2:q_hi2+1] -= w * h[idx2]
    
    return grad
```
