Let me think of a truly fast local search. 

For a transfer of δ from position j to position i (h[i] += δ, h[j] -= δ), the change in c_k for a specific shift k:

c_k = dx * ∑_{i valid} h[i+k'](1-h[i''])  (using different index names to avoid confusion)

The change in c_k is:
Δc_k = dx * [∑ (terms involving h[i] or h[j] in the product h[a](1-h[b])]

h[i] appears in:
- As h[a] where a = i: contributes dx * (1-h[b]) for each b such that (a,b) is a valid pair in c_k
- As h[b] where b = i: contributes -dx * h[a] for each a such that (a,b) is a valid pair in c_k

Similarly for h[j].

For a specific shift k (where k is the shift index in the full correlate, shift = k - (n-1)):

If shift > 0: c_k = dx * ∑_{t=0}^{n-1-shift} h[t+shift](1-h[t])
- h[i] appears as h[t+shift] with t = i-shift (if 0 ≤ i-shift ≤ n-1-shift, i.e., shift ≤ i ≤ n-1): contribution = dx*(1-h[i-shift])
- h[i] appears as h[t] with t = i (if 0 ≤ i ≤ n-1-shift): contribution = -dx*h[i+shift]

So Δc_k from changing h[i] by δ:
= δ * dx * [(1-h[i-shift])*1_{shift≤i≤n-1} - h[i+shift]*1_{0≤i≤n-1-shift}]

And similarly for h[j]:
= -δ * dx * [(1-h[j-shift])*1_{shift≤j≤n-1} - h[j+shift]*1_{0≤j≤n-1-shift}]

So the total change in c_k is:
Δc_k = δ * dx * [(1-h[i-shift])*1_{shift≤i≤n-1} - h[i+shift]*1_{0≤i≤n-1-shift} 
                 - (1-h[j-shift])*1_{shift≤j≤n-1} + h[j+shift]*1_{0≤j≤n-1-shift}]

This is O(1) per shift! So for K active shifts, the evaluation is O(K).

With K active shifts and O(n^2) pairs, the total work is O(K*n^2). For K=20, n=500, that's 5M operations per full pass. That's fast!

Actually, for a fixed i, the best j to pair with can be found by looking at which j minimizes the objective. Since the change in c_k is linear in the "interaction" between i and j (they just add), I can precompute for each i and each k the "partial derivative" term, and then the total change is just the sum over k of w_k * (term_i_k + term_j_k) * δ.

So for fixed i:
total_change(j) = δ * ∑_k w_k * dx * [term(i,k) - term(j,k)]

where term(i,k) = (1-h[i-shift_k])*1_{valid} - h[i+shift_k]*1_{valid} (for +shift) or the appropriate formula.

This means for fixed i, the best j is the one that maximizes ∑_k w_k * term(j,k) (if we're sending mass from j to i) or minimizes it (if sending from i to j).

So I can precompute for each position p and each active shift k, the value term(p,k), and then for fixed i, the best j is found by looking at the vector [∑_k w_k * term(j,k)] over all j.

This reduces the pair search to O(K*n + n^2) per pass (precompute all terms in O(K*n), then for each i find best j in O(n), total O(n^2)).

def fast_local_search(h, n, active_indices, alpha, deadline, max_rounds=100):

    h = h.copy()
    best_c = compute_c5(h, n)

            break

        c_sub = c[active_indices]
        m = c_sub.max()

        mx = sh.max()

        w = exp_sh / (np.sum(exp_sh) + 1e-30)

        # where term(j, k) is the partial derivative of c_k w.r.t. h[j]
        scores = np.zeros(n)

            if wi < 1e-10:
                continue

                term = dx * (1 - 2*h)

                term[:n-shift] -= dx * h[shift:]

                term[m2:] -= dx * h[:n-m2]

        #   for h[i] += delta, h[j] -= delta:

        # The gradient of the smooth max is the weighted sum of ∂c_k/∂h[j] = scores[j] (scaled)
        # Actually, scores IS the gradient of the smooth max!
        # So the steepest descent direction is -scores.
        # But we need to maintain the constraint sum(h) = n/2.
        # So we transfer from high scores to low scores.

        # Transfer δ from j to i: new h has h[i]+=δ, h[j]-=δ

        # We want this to be negative, so grad[i] < grad[j]

        improved = False

        # Best j: high score (we want to decrease h[j])

                    j = order[n-1-j_idx]  # high score
                    if i == j:

                    if scores[i] >= scores[j]:
                        continue
                    if h[i] + d > 1.0 or h[j] - d < 0.0:
                        continue
                    h[i] += d
                    h[j] -= d
                    c_new = smooth_max_active(np.correlate(h, 1-h, mode='full') * dx, active_indices, alpha)
                    if c_new < best_c - 1e-12:

                        improved = True
                    else:
                        h[i] -= d
                        h[j] += d
            if improved:

        if not improved:

            for d in deltas:
                for i_idx in range(min(20, n)):

                        else:
                            h[i] += d
                            h[j] -= d
                if improved:
                    break
        if not improved:
            break
    
    return h, best_c

            tot = h.sum()
            if tot < 1e-15:
                break
            h += (diff / tot) * h

def compute_c5(h, n):
    dx = 2.0 / n
    return float(np.max(np.correlate(h, 1 - h, mode='full') * dx))

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h.copy(), 0.0, 1.0)
    for _ in range(1000):
        diff = target - h.sum()
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            room = 1.0 - h
            tot = room.sum()
            if tot < 1e-15:
                break
            h += (diff / tot) * room
        else:
            tot = h.sum()
            if tot < 1e-15:
                break
            h += (diff / tot) * h
    return np.clip(h, 0.0, 1.0)

def smooth_max_val(c, indices, alpha):
    c_sub = c[indices]
    m = c_sub.max()
    sh = alpha * (c_sub - m)
    mx = sh.max()
    return float(m + np.log(np.sum(np.exp(sh - mx)) + 1e-30) / alpha)

def smooth_max_grad(c, indices, alpha, h, n):
    dx = 2.0 / n
    c_sub = c[indices]
    m = c_sub.max()
    sh = alpha * (c_sub - m)
    mx = sh.max()
    exp_sh = np.exp(sh - mx)
    w = exp_sh / (np.sum(exp_sh) + 1e-30)
    grad = np.zeros(n)
    for idx, wi in zip(indices, w):
        if wi < 1e-8:
            continue
        shift = int(idx) - (n - 1)
        if shift == 0:
            grad += wi * dx * (1.0 - 2.0 * h)
        elif shift > 0:
            g = np.zeros(n)
            g[shift:] = dx * (1.0 - h[:n - shift])
            g[:n - shift] -= dx * h[shift:]
            grad += wi * g
        else:

            g = np.zeros(n)
