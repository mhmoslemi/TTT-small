5. new_max = np.max(C[None,None,:] + F_z[:,None,:] - F_o[None,:,:], axis=2) (shape |Z| x |O|)
6. Find (i*, j*) = argmin(new_max)
7. If new_max[i*,j*] * dx < current_max * dx, make the swap
8. Update C, F, etc.

This is O(n³) per iteration but with small constant. For n=250, should be fast.

After each swap, we need to update:
- C (the correlation array): O(n) change
- F: only rows i and j change, so O(n) update
- Z and O sets: O(1)

This is much better than the previous O(n²) per swap evaluation!

2. Phase 2: Simulated annealing (escape local minima)

- As the second factor (h[p] in the 1-h[p+s] part): this means p+s = i for some i, so i = p-s. Present if 0≤p-s<n and 0≤p<n. Contribution: h[p-s]*(1-h[p])

- Term 2: h[i-s]*(1-h[i]) changes. Old: h[i-s]*1 = h[i-s]. New: h[i-s]*0 = 0. Change: -h[i-s]. Valid for 0≤i-s<n, i.e., s ∈ [i-(n-1), i].

So the change in C[n-1+s] when h[i] goes 0→1 is:
ΔC_s = (1-h[i+s]) [if 0≤i+s<n] - h[i-s] [if 0≤i-s<n]

This is exactly B[i, s_idx] as I defined it! Good.

Now, when h[i] goes 0→1, the change to B[i', s] for a DIFFERENT position i':

Case 1: i'+s = i, so s = i-i'. The term (1-h[i'+s]) = (1-h[i]) changes from 1 to 0. So B[i', s] decreases by 1.

Case 2: i'-s = i, so s = i'-i. The term h[i'-s] = h[i] changes from 0 to 1. So B[i', s] changes by -1 (since it's -h[i'-s]).
This is valid if 0 ≤ i'-s = i < n (always true) AND the term was present.
So: B[i', (i'-i)+(n-1)] -= 1 for all i'.

Similarly for h[j] going 1→0:
Case 1: i'+s = j, so s = j-i'. The term (1-h[i'+s]) = (1-h[j]) changes from 0 to 1. B[i', s] increases by 1.

So: B[i', (i'-j)+(n-1)] += 1 for all i'.

So the update is:
For i (0→1): for all i' in [0,n): B[i', (i-i')+(n-1)] -= 1 and B[i', (i'-i)+(n-1)] -= 1
For j (1→0): for all i' in [0,n): B[i', (j-i')+(n-1)] += 1 and B[i', (i'-j)+(n-1)] += 1

import numpy as np
import time

def compute_c5_val(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(c) * dx)

def to_binary(h, n):
    target = n // 2
    idx = np.argsort(h)[::-1]
    hb = np.zeros(n)
    hb[idx[:target]] = 1.0
    return hb

def compute_B_matrix(h, n):
    B = np.zeros((n, 2*n-1))
    for s_idx in range(2*n-1):
        s = s_idx - (n-1)
        lo1 = max(0, -s)
        hi1 = min(n, n - s)
        lo2 = max(0, s)
        hi2 = min(n, n + s)

            B[lo1:hi1, s_idx] += 1.0 - h[lo1+s:hi1+s]
        if hi2 > lo2:

def update_B_swap(B, i, j, n):

    for ip in range(n):

        B[ip, (ip - i) + np] -= 1.0
        B[ip, (j - ip) + np] += 1.0
