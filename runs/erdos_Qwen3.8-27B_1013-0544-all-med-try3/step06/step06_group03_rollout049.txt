For the coordinate descent, here's a cleaner formulation:
- For coordinate i, if we change h[i] by δ (and compensate by changing h[j] by -δ for some j), the change in c[k] is:
  δ * (s_i[k] - s_j[k])
  
- If we compensate by spreading -δ uniformly over all j ≠ i, the change is:
  δ * (s_i[k] - mean(s_j[k] for j ≠ i))

The second option (uniform compensation) is easier to compute because mean(s_j[k]) can be precomputed.

Actually, let me think about this even more carefully. The "uniform compensation" approach is:
- h[i] += δ
- h[j] -= δ/(n-1) for all j ≠ i

This maintains the sum constraint. The change in c[k] is:
δ * s_i[k] - (δ/(n-1)) * sum_{j≠i} s_j[k]
= δ * (s_i[k] - (sum_j s_j[k] - s_i[k])/(n-1))
= δ * (s_i[k] * n/(n-1) - sum_j s_j[k] / (n-1))

We can precompute mean_s[k] = sum_j s_j[k] / n, so:
= δ * (s_i[k] * n/(n-1) - n * mean_s[k] / (n-1))
= δ * n/(n-1) * (s_i[k] - mean_s[k])

So for uniform compensation, the change in c[k] is proportional to (s_i[k] - mean_s[k]), which we can precompute for all i and k.
