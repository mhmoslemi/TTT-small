   The gradient of the LSE objective:
   f(h) = m + (1/α) * log(∑ exp(α(C(s) - m)))
   where m = max C(s)
   
   ∂f/∂h[i] = (1/α) * ∑_s α * exp(α(C(s)-m)) / ∑_t exp(α(C(t)-m)) * ∂C(s)/∂h[i]
            = ∑_s w_s * ∂C(s)/∂h[i]
   where w_s = exp(α(C(s)-m)) / ∑_t exp(α(C(t)-m)) (softmax weights)
   
   And ∂C(s)/∂h[i] is the same formula as before for each lag s.
   
   So the gradient is a weighted sum of the per-lag gradients, with softmax weights. This is O(n²) to compute (n lags, each requiring O(n) work for the gradient).

   For n=500: 500 lags * 500 work = 250,000 operations per gradient evaluation. That's fast!

       dx = 2.0 / n
       c = np.correlate(x, 1 - x, mode='full') * dx
       m = c.max()
       sh = alpha * (c - m)
       mx = sh.max()
       exp_sh = np.exp(sh - mx)
       weights = exp_sh / exp_sh.sum()
       
       # Gradient is weighted sum of per-lag gradients
       g = np.zeros(n)
       for s_offset in range(2 * n - 1):

               g[:n-sp] -= w * x[sp:] * dx
