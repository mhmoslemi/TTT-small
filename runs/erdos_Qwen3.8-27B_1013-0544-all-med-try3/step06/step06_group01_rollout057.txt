For a 2-swap (move 1s from j1,j2 to i1,i2):
The delta is the sum of the 4 individual position changes, accounting for interactions.

Let me derive it:
Before: h[i1]=h[i2]=0, h[j1]=h[j2]=1
After: h[i1]=h[i2]=1, h[j1]=h[j2]=0

The change in corr[p] for lag l = p-(n-1):
= [h_new[i1]*(1-h_new[i1+l]) - h_old[i1]*(1-h_old[i1+l])]
+ [h_new[i2]*(1-h_new[i2+l]) - h_old[i2]*(1-h_old[i2+l])]
+ [h_new[j1]*(1-h_new[j1+l]) - h_old[j1]*(1-h_old[j1+l])]
+ [h_new[j2]*(1-h_new[j2+l]) - h_old[j2]*(1-h_old[j2+l])]
+ [h_new[i1-l]*(1-h_new[i1]) - h_old[i1-l]*(1-h_old[i1])]
+ [h_new[i2-l]*(1-h_new[i2]) - h_old[i2-l]*(1-h_old[i2])]
+ [h_new[j1-l]*(1-h_new[j1]) - h_old[j1-l]*(1-h_old[j1])]
+ [h_new[j2-l]*(1-h_new[j2]) - h_old[j2-l]*(1-h_old[j2])]

Where h_new differs from h_old only at positions i1, i2, j1, j2.

For the first 4 terms (m = i1, i2, j1, j2):
- h_new[i1] = 1, h_old[i1] = 0: contribution = 1*(1-h_new[i1+l]) - 0 = 1 - h_new[i1+l]
- h_new[i2] = 1, h_old[i2] = 0: contribution = 1 - h_new[i2+l]
- h_new[j1] = 0, h_old[j1] = 1: contribution = 0 - 1*(1-h_old[j1+l]) = -(1-h_old[j1+l]) = -1 + h_old[j1+l]
- h_new[j2] = 0, h_old[j2] = 1: contribution = -1 + h_old[j2+l]

For the last 4 terms (m+l = i1, i2, j1, j2, i.e., m = i1-l, i2-l, j1-l, j2-l):
- h_new[i1] = 1, h_old[i1] = 0: contribution = h_new[i1-l]*(1-1) - h_old[i1-l]*(1-0) = -h_old[i1-l]
- h_new[i2] = 1, h_old[i2] = 0: contribution = -h_old[i2-l]
- h_new[j1] = 0, h_old[j1] = 1: contribution = h_new[j1-l]*(1-0) - h_old[j1-l]*(1-1) = h_new[j1-l]
- h_new[j2] = 0, h_old[j2] = 1: contribution = h_new[j2-l]

So the total delta for lag l:
= (1 - h_new[i1+l]) + (1 - h_new[i2+l]) + (h_old[j1+l] - 1) + (h_old[j2+l] - 1)
  + (-h_old[i1-l]) + (-h_old[i2-l]) + h_new[j1-l] + h_new[j2-l]

Now, h_new differs from h_old only at {i1, i2, j1, j2}:
- h_new[i1+l]: if i1+l is in {i1,i2,j1,j2}, use new value; else h_old[i1+l] = h[i1+l]
- Similarly for others.

Since i1, i2, j1, j2 are all distinct (they should be), the "coincidence" cases are:
- i1+l = j1 or j2 (or i2)
- i2+l = j1 or j2 (or i1)
- j1+l = i1 or i2 (or j2)
- j2+l = i1 or i2 (or j1)
- i1-l = j1 or j2 (or i2)
- etc.

These are special cases that require handling. In most cases (for large n), the probability of coincidence is low, so we can approximate:

delta_approx[l] = (1 - h[i1+l]) + (1 - h[i2+l]) + (h[j1+l] - 1) + (h[j2+l] - 1)
                 + (-h[i1-l]) + (-h[i2-l]) + h[j1-l] + h[j2-l]
= 2 - h[i1+l] - h[i2+l] + h[j1+l] + h[j2+l] - h[i1-l] - h[i2-l] + h[j1-l] + h[j2-l]

(with boundary handling: h[x] = 0 if x out of range)

Then for the special cases, add correction terms.

```python
def two_swap_delta(h, i1, i2, j1, j2, n):
    """Compute change in corr when h[i1]:0->1, h[i2]:0->1, h[j1]:1->0, h[j2]:1->0"""
    changed = {i1: 1, i2: 1, j1: 0, j2: 0}  # new values
    m_range = np.arange(-(n-1), n)
    delta = np.zeros(2*n-1)
    
    # For each position in {i1, i2, j1, j2}, compute contribution
    for pos, new_val in changed.items():
        old_val = 1.0 - new_val  # since these are binary
        # Term m=pos: new_val*(1-h_new[pos+l]) - old_val*(1-h_old[pos+l])
        # = new_val - new_val*h_new[pos+l] - old_val + old_val*h_old[pos+l]
        # = (new_val - old_val) - new_val*h_new[pos+l] + old_val*h_old[pos+l]
        # = (2*new_val - 1) - new_val*h_new[pos+l] + old_val*h_old[pos+l]
        
        # For binary: new_val - old_val = ±1
        # If new_val=1, old_val=0: = 1 - h_new[pos+l]
        # If new_val=0, old_val=1: = -1 + h_old[pos+l]
        
        # Term m=pos-l: h_new[pos-l]*(1-new_val) - h_old[pos-l]*(1-old_val)
        # If new_val=1: = 0 - h_old[pos-l] = -h_old[pos-l]
        # If new_val=0: = h_new[pos-l] - 0 = h_new[pos-l]
        
        for l in m_range:
            p = l + n - 1  # position in corr array
            
            # Term m=pos
            if new_val == 1:
                # Contribution: 1 - h_new[pos+l]
                idx = pos + l
                if 0 <= idx < n:
                    hv = changed.get(idx, h[idx])
                    delta[p] += 1.0 - hv
                # (if idx out of range, term doesn't exist, no contribution)
            else:
                # Contribution: -1 + h_old[pos+l]
                idx = pos + l
                if 0 <= idx < n:
                    delta[p] += -1.0 + h[idx]
            
            # Term m=pos-l
            m = pos - l
            if 0 <= m < n:
                if new_val == 1:
                    # Contribution: -h_old[pos-l] = -h[m]
                    # But h[m] might have changed!
                    hv = changed.get(m, h[m])
                    # Wait, we need h_old[m], not h_new[m]
                    # h_old[m] = h[m] unless m is in changed
                    if m in changed:
                        h_old_m = 1.0 - changed[m]  # since changed gives new values
                    else:
                        h_old_m = h[m]
                    delta[p] += -h_old_m
                else:
                    # Contribution: h_new[pos-l] = h_new[m]
                    hv = changed.get(m, h[m])
                    delta[p] += hv
    return delta
```

import numpy as np
import time

def compute_c5(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1 - h, mode='full')
    return float(np.max(c) * dx)

def fast_correlate(h):
    return np.correlate(h, 1.0 - h, mode='full')

def one_swap_delta(h, i, j, n):
    """Delta in corr when h[i]: 0->1, h[j]: 1->0"""
    delta = np.zeros(2 * n - 1)
    lags = np.arange(-(n - 1), n)
    
    idx = i + lags
    msk = (idx >= 0) & (idx < n)
    delta[msk] += 1.0 - h[idx[msk]]
    
    idx = i - lags
    msk = (idx >= 0) & (idx < n)
    delta[msk] -= h[idx[msk]]
    
    idx = j + lags
    msk = (idx >= 0) & (idx < n)
    delta[msk] -= 1.0 - h[idx[msk]]
    
    idx = j - lags
    msk = (idx >= 0) & (idx < n)
    delta[msk] += h[idx[msk]]
    
    return delta

def local_search(h, n, deadline, max_sweeps=2000, seed=42, mode='first'):
    """Binary local search. mode='first' for first-improvement, 'best' for best-improvement."""
    dx = 2.0 / n
    corr = fast_correlate(h).copy()
    cur_c = float(corr.max()) * dx
    ones = np.where(h == 1)[0].tolist()
    zeros = np.where(h == 0)[0].tolist()
    rng = np.random.RandomState(seed)
    
    for sweep in range(max_sweeps):
        if time.time() > deadline:
            break
        improved = False
        if mode == 'best':
            # Best improvement: try all pairs, apply the best
            best_delta = None
            best_i, best_j = -1, -1
            best_c = cur_c
            for i in zeros:
                for j in ones:
                    d = one_swap_delta(h, i, j, n)
                    nc = float((corr + d).max()) * dx
                    if nc < best_c - 1e-15:
                        best_c = nc
                        best_i, best_j = i, j
                        best_delta = d
            if best_i >= 0:
                h[best_i], h[best_j] = 1.0, 0.0
                corr += best_delta
                cur_c = best_c
                ones.remove(best_j)
                ones.append(best_i)
                zeros.remove(best_i)
                zeros.append(best_j)
                improved = True
        else:
            # First improvement
            for i in zeros:
                if time.time() > deadline:
                    break
                found = False
                for j in ones:
                    d = one_swap_delta(h, i, j, n)
                    nc = float((corr + d).max()) * dx
                    if nc < cur_c - 1e-15:
                        h[i], h[j] = 1.0, 0.0
                        corr += d
                        cur_c = nc
                        ones.remove(j)
                        ones.append(i)
                        zeros.remove(i)
                        zeros.append(j)
                        improved = True
                        found = True
                        break
                if found:
                    break
        if not improved:
            break
    
    return h, cur_c

def random_binary(n, seed):
    rng = np.random.RandomState(seed)
    h = np.zeros(n)
    idx = rng.choice(n, n // 2, replace=False)
    h[idx] = 1.0
    return h

def upsample_binary(h_old, n_old, n_new):
    """Upsample a binary solution from n_old to n_new"""
    h_new = np.zeros(n_new)
    for i in range(n_new):
        # Map position i in new grid to position in old grid
        pos = i * n_old / n_new
        idx = int(pos)
        if idx >= n_old:
            idx = n_old - 1
        h_new[i] = h_old[idx]
    # Fix the count
    n_ones = int(h_new.sum())
    target = n_new // 2
    if n_ones > target:
        # Remove some ones
        ones = np.where(h_new == 1)[0]
        to_remove = n_ones - target
        rng = np.random.RandomState(0)
        for i in rng.choice(ones, to_remove, replace=False):
            h_new[i] = 0
    elif n_ones < target:
        # Add some ones
        zeros = np.where(h_new == 0)[0]
        to_add = target - n_ones
        rng = np.random.RandomState(0)
        for i in rng.choice(zeros, to_add, replace=False):
            h_new[i] = 1
    return h_new

One important optimization: in the local search, I can skip computing the full delta if I can quickly determine that the swap won't improve. Specifically:
- If the current max is at position p*, and the swap doesn't decrease corr[p*], then the max can only stay the same or increase.
- So I only need to check swaps that decrease the current maximum.

For the current max at position p*, the swap (i,j) changes corr[p*] by:
delta[p*] = (1-h[i+l*]) - h[i-l*] - (1-h[j+l*]) + h[j-l*]
where l* = p* - (n-1)

For this to be negative (decrease the max), we need:
(1-h[i+l*]) - h[i-l*] - (1-h[j+l*]) + h[j-l*] < 0
h[j-l*] - h[i-l*] + h[i+l*] - h[j+l*] < 0

This gives a quick filter! I can precompute for each zero i: A_i = h[i+l*] - h[i-l*]
And for each one j: B_j = h[j-l*] - h[j+l*]
Then the condition is B_j - A_i < 0, i.e., B_j < A_i.

So I can:
1. Find the current max position p*
2. Compute A_i for all zeros and B_j for all ones
3. Only try pairs where B_j < A_i
4. Among those, compute the full delta and check the actual new max

This should significantly reduce the number of pairs to check!
