The key insight is: the gradient of F(h) = max_d f_d(h) * dx at h is:
- If there's a unique maximizer d*: ∇F = dx * ∇f_{d*}(h)
- If there are multiple maximizers: ∇F is any convex combination of {dx * ∇f_{d*} for d* in argmax}

For the projected gradient method:
1. Compute ∇F(h)
2. Find the best step size α > 0 such that F(project(h - α∇F)) < F(h)
3. Update h = project(h - α∇F)

The projection is: project(x) = argmin ||y - x||² subject to sum(y) = n/2, 0 ≤ y ≤ 1.

This is the Euclidean projection onto a simplex-like set (actually onto the intersection of the hyperplane sum = n/2 with the hypercube [0,1]^n). The projection can be computed efficiently:
1. First project onto [0,1]^n: clip to [0,1]
2. Then adjust to satisfy sum = n/2 (the project_feasible function does this)

But this two-step projection is not the exact Euclidean projection. The exact projection onto {y: sum(y) = n/2, 0 ≤ y ≤ 1} requires a more careful algorithm (bisection on the Lagrange multiplier). However, for our purposes, the two-step approximation should work well enough.
