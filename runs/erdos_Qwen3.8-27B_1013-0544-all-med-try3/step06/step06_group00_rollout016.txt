5. Update h^t = h^{t+1}

minimize (rho/2)||h - h^t||^2 + ∇c_{k*}(h^t)^T h
subject to 0≤h≤1, sum(h)=n/2

This can be solved efficiently using:
- The optimality condition: rho*(h - h^t) + g = λ * 1 + μ (where μ handles the bounds)
- h_i = clip(h^t_i - g_i/rho - λ/rho, 0, 1)
- Find λ by bisection

This is exactly the same as projecting (h^t - g/rho) onto the feasible set!

Which is just gradient descent with step size 1/rho and projection!

So we're back to projected gradient descent. The advantage of the AL formulation is that we can use a variable step size (rho) and it has a more principled connection to the augmented Lagrangian.

def slsqp_smooth(h, n, alpha, maxiter=3000, ftol=1e-14):
    dx = 2.0 / n
    def obj(x):
        g = np.correlate(x, 1.0 - x, mode='full') * dx
        m = g.max()
        shifted = alpha * (g - m)
        sm = shifted.max()
        logsum = sm + np.log(np.exp(shifted - sm).sum())
        return m + logsum / alpha
    def grad(x):
        g = np.correlate(x, 1.0 - x, mode='full') * dx
        m = g.max()
        shifted = alpha * (g - m)
        sm = shifted.max()
        exps = np.exp(shifted - sm)
        weights = exps / exps.sum()
        # gradient of logsum = weights * alpha * dg/dx
        # gradient of m = 0 (almost, for the smooth part)
        # Total gradient = weights * alpha * dg/dx / alpha = weights * dg/dx

        # = (1/alpha) * sum_k alpha*exp(alpha*(g_k-m)) / sum_k exp(alpha*(g_k-m)) * dg_k/dx
        # = sum_k weights_k * dg_k/dx
        # So gradient is the weighted sum of individual gradients
        grad_out = np.zeros(n)
        for k in range(len(g)):
            if weights[k] > 1e-12:
                s = k - (n-1)
                grad_out += weights[k] * ((1.0 - shift_h(x, s)) - shift_h(x, -s)) * dx
        return grad_out
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': lambda x: x.sum() - n/2.0,
             'jac': lambda x: np.ones(n)}]
    try:

                       constraints=cons, options={'maxiter': maxiter, 'ftol': ftol})

    n = len(h)
    out = np.zeros(n)
    if s >= 0:
        if s < n:
            out[s:] = h[:n-s]

        if -s < n:
