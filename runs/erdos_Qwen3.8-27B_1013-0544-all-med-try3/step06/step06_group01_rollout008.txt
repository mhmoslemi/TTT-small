The key insight: when we swap h[i] and h[j], the correlation changes only at lags m where the "window" [i, i] or [j, j] or [i+m, ...] etc. is affected. Actually, the simplest approach: a change at position p affects corr[n-1+m] for all m such that the term involving h[p] exists in the sum. The term h[p]*(1-h[p-m]) exists when 0 ≤ p-m < n, i.e., p-n+1 ≤ m ≤ p. The term h[p-m+p]... wait, I'm overcomplicating this.

In the sum corr[n-1+m] = sum_{i'=max(0,m)}^{min(n-1, n-1+m)} h[i'] * (1-h[i'-m]):
- h[p] appears as the first factor when i' = p (if p is in the valid range for this m)
- h[p] appears as the second factor when i'-m = p, i.e., i' = p+m (if p+m is in the valid range)

So h[p] affects corr at lag m if:
- p is a valid first factor: 0 ≤ p < n and 0 ≤ p-m < n → max(-(n-1), p-(n-1)) ≤ m ≤ min(n-1, p)
  More simply: p-n+1 ≤ m ≤ p (and also -(n-1) ≤ m ≤ n-1)
- p is a valid second factor: 0 ≤ p+m < n and 0 ≤ (p+m)-m = p < n → -p ≤ m ≤ n-1-p (and also -(n-1) ≤ m ≤ n-1)

So h[p] affects lags m in:
[p-n+1, p] ∪ [-p, n-1-p]

For p in [0, n-1], this is [p-n+1, p] ∪ [-p, n-1-p]. The union is:
[max(p-n+1, -(n-1)), min(p, n-1)] ∪ [max(-p, -(n-1)), min(n-1-p, n-1)]
= [p-n+1, p] ∪ [-p, n-1-p] (since p-n+1 ≥ -(n-1) and n-1-p ≤ n-1)

The union of [p-n+1, p] and [-p, n-1-p]:
- If p < n/2: [p-n+1, p] and [-p, n-1-p] → union is [p-n+1, n-1-p]
- If p ≥ n/2: [p-n+1, p] and [-p, n-1-p] → union is [-p, p]

In either case, the range of affected lags has length n. So for each position p, changing h[p] affects n lags.

For a swap (i, j), the affected lags are the union of the ranges for i and j, which is at most 2n lags (but since the full range is 2n-1, it could be the entire range).

So in the worst case, we still need to check all 2n-1 lags. The analytical formula just avoids recomputing the full correlation.
