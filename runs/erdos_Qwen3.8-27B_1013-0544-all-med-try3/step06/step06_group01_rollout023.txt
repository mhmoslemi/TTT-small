Δ[k] = (1-h[i-k])*[0≤i-k<n] + h[j+k]*[0≤j+k<n] - h[i+k]*[0≤i+k<n] - (1-h[j-k])*[0≤j-k<n]

Plus special corrections at k=i-j (add +2) and k=j-i (add +2).

Wait, I showed earlier that at k=0, the formula gives 2 but the true change is 0. Let me re-examine.

The issue at k=0: the formula double-counts. When k=0:
- i-k = i and i+k = i (same position)
- j-k = j and j+k = j (same position)

So the four terms become:
(1-h[i]) + h[j] - h[i] - (1-h[j]) = (1-0) + 1 - 0 - (1-1) = 1+1-0-0 = 2

But the true change is 0 (as verified). The problem is that when k=0, the "first" and "second" appearances of h[i] (and h[j]) are the same term in the sum, so we should only count it once.

The correct formula for k≠0:
Δ[k] = (1-h[i-k])*[0≤i-k<n] + h[j+k]*[0≤j+k<n] - h[i+k]*[0≤i+k<n] - (1-h[j-k])*[0≤j-k<n]

For k=0:
Δ[0] = 0 (always, for binary h)

For k=i-j (assuming i≠j):
Special correction: +2 (as derived)

For k=j-i (assuming i≠j):
Special correction: +2 (as derived)

At k=j-i:

But h_new[i+k] = h_new[j] = 0, so the new contribution should be 0 instead of -1.
The old term was -h[i+k] = -1. New term is -h_new[i+k] = 0. Change: +1.

j-k = j-(j-i) = i. So (1-h[j-k]) = (1-h[i]) = 1.

Total correction at k=j-i: +2. ✓

So the complete formula:
For all k (in the range -(n-1) to n-1):
Δ[k] = (1-h[i-k])*[0≤i-k<n] + h[j+k]*[0≤j+k<n] - h[i+k]*[0≤i+k<n] - (1-h[j-k])*[0≤j-k<n]

Then:
- If k=0: Δ[0] = 0 (override)
- If k=i-j: Δ[k] += 2
- If k=j-i: Δ[k] += 2
