<h4>2. Mathematical specification</h4>
We represent the step function $h(x)$ using $M$ harmonics:

$$h(x) = \sum_{k=0}^{M-1} a_k \cos\left(2\pi\frac{k}{N}\cdot x\right) + b_k\sin\left(2\pi\frac{k}{N}\cdot x\right)$$

with boundary condition integral over $[0,2]$ equals 1.

The autocorrelation-like overlap integral is:
$$C_5 = \max_k \left|\int_0^2 h(x)\left(1-h(x+k)\right)dx\right|$$

We use frequency $N$ to control the "graininess" of the resulting function, with $N=20$ being the base frequency. The number of harmonics $M$ is adaptive, starting from 1 to 20.

The variables are $(a_k,b_k)$ for k from 0 to M-1, with:
- $a_0 = \frac{1}{2}$ to normalize the zero-frequency
- Box constraints on coefficients
- Feasibility determined by meeting integral constraint

Using sinusoids allows for closed-form computation of integrals, drastically reducing evaluation cost compared to discrete grid approaches. The Fourier transform enables these computations via fast convolutions.
