For each zero position i, I want to find the best one position j to swap with. The key insight is:
- The change in overlap at lag m when swapping i (0→1) and j (1→0) is:
  Δ[m] = (1-h[i+m]) - (1-h[j+m]) - h[i-m] + h[j-m]
  
- I want to minimize max_m (c[m] + Δ[m])

- If I focus on the top K lags (where c[m] is largest), I can approximate this as:
  minimize max_{m in top_K} (c[m] + Δ[m])

- For a fixed set of critical lags, this becomes: for each (i,j) pair, compute the max over critical lags of (c[m] + Δ[m]) and pick the (i,j) that minimizes this.

- To vectorize: For a fixed i, Δ[m] = A_i[m] - B_j[m] where:
  A_i[m] = (1-h[i+m]) - h[i-m] (depends only on i and m)
  B_j[m] = (1-h[j+m]) - h[j-m] (depends only on j and m)
  
  So for fixed i and critical lags M = {m1, m2, ..., mK}:
  We want j that minimizes max_{l} (c[m_l] + A_i[m_l] - B_j[m_l])
  
  This is still hard to vectorize perfectly, but we can use a heuristic:
  - For each j, compute the "worst case" over critical lags: worst_j = max_l (c[m_l] + A_i[m_l] - B_j[m_l])
  - Pick the j with minimum worst_j

  To vectorize over j: For each critical lag m_l, compute the vector over all j of (c[m_l] + A_i[m_l] - B_j[m_l]). Then take the max over l for each j. This is K vector operations of length |ones|, which is fast.

Let me code this up:

```python
def vectorized_greedy_step(h, corr, n, K):
    """
    For each zero position i, find the best one position j to swap with.
    Focus on top K critical lags.
    Return the best (i, j, new_corr, new_c) found.
    """
    dx = 2.0 / n
    cur_c = corr.max() * dx
    
    # Find top K lags
    top_k = np.argsort(corr)[::-1][:K]
    
    ones_idx = np.where(h == 1)[0]
    zeros_idx = np.where(h == 0)[0]
    
    best_ij = None
    best_new_c = cur_c
    
    for i in zeros_idx:
        # A_i[m] for each critical lag m
        # A_i[m] = (1-h[i+m]) - h[i-m]
        # Need to handle boundaries
        
        A = np.zeros(K)
        for l, m in enumerate(top_k):
            im = i + m
            imn = i - m
            a_val = 0.0
            if 0 <= im < n:
                a_val += 1.0 - h[im]
            if 0 <= imn < n:
                a_val -= h[imn]
            A[l] = a_val
        
        # For each j in ones_idx, compute worst case
        # B_j[m] = (1-h[j+m]) - h[j-m]
        # worst_j = max_l (c[top_k[l]] + A[l] - B_j[top_k[l]])
        
        # Vectorize over j
        # For each critical lag m_
        valid_masks = []
        for l, m in enumerate(top_k):
            jm = ones_idx + m
            jmn = ones_idx - m
            mask_pos = (jm >= 0) & (jm < n)
            mask_neg = (jmn >= 0) & (jmn < n)
            
            B_pos = np.zeros(len(ones_idx))
            B_neg = np.zeros(len(ones_idx))
            B_pos[mask_pos] = 1.0 - h[jm[mask_pos]]
            B_neg[mask_neg] = h[jmn[mask_neg]]
            valid_masks.append(B_pos - B_neg)
        
        # worst_j[l] for each lag, then max over l
        # worst_j[j_idx] = max_l (c[top_k[l]] + A[l] - B_j[top_k[l]])
        
        # Build array: shape (K, len(ones_idx))
        # For each l: c[top_k[l]] + A[l] - valid_masks[l]
        # Then take max over axis=0
        
        worst = np.zeros(len(ones_idx))
        for l in range(K):
            val = corr[top_k[l]] + A[l] - valid_masks[l]
            if l == 0:
                worst = val
            else:
                worst = np.maximum(worst, val)
        
        best_j_idx = np.argmin(worst)
        new_c_worst = worst[best_j_idx] * dx
        
        if new_c_worst < best_new_c - 1e-14:
            best_new_c = new_c_worst
            best_ij = (i, ones_idx[best_j_idx])
    
    if best_ij is not None:
        i, j = best_ij
        # Actually perform the swap and recompute corr
        h[i], h[j] = 1.0, 0.0
        # Recompute correlation (expensive but necessary for accuracy)
        corr = np.correlate(h, 1 - h, mode='full')
        return h, corr, corr.max() * dx, True
    
    return h, corr, cur_c, False
```

For fixed j and m: g(j,m) is a scalar

For a fixed i, this becomes: minimize over j: max_{m in M} (corr[m] + g(i,m) - g(j,m))

Let's define for each j: score(j) = max_{m in M} (corr[m] + g(i,m) - g(j,m))

We want the j with minimum score(j).

To compute this for all j simultaneously:
- For each m in M, compute the vector v_m[j] = corr[m] + g(i,m) - g(j,m) for all j in ones
- Then score(j) = max_m v_m[j]
- Pick j with minimum score

The computation of g(j,m) for all j and a fixed m:
g(j,m) = (1-h[j+m]) - h[j-m]

For all j in ones_idx:
- j+m: need to check bounds
- j-m: need to check bounds

This can be vectorized with numpy.

```python
def compute_best_swap(h, corr, n, K):
    """Find the best swap (i in zeros, j in ones) using K-critical-lag heuristic."""
    dx = 2.0 / n
    cur_max = corr.max()
    
    # Top K lags
    top_k = np.argsort(corr)[::-1][:K]
    
    ones_idx = np.where(h == 1)[0]
    zeros_idx = np.where(h == 0)[0]
    
    if len(ones_idx) == 0 or len(zeros_idx) == 0:
        return None, None
    
    best_score = np.inf
    best_i = -1
    best_j = -1
    
    for i in zeros_idx:
        # Compute g(i, m) for each critical m
        gi = np.zeros(K)
        for l, m in enumerate(top_k):
            im = i + m
            imn = i - m
            val = 0.0
            if 0 <= im < n:
                val += 1.0 - h[im]
            if 0 <= imn < n:
                val -= h[imn]
            gi[l] = val
        
        # For each j in ones_idx, compute g(j, m) for each critical m
        # Then score(j) = max_l (corr[top_k[l]] + gi[l] - g(j, top_k[l]))
        
        # Vectorize over j
        scores = np.zeros(len(ones_idx))
        first = True
        for l, m in enumerate(top_k):
            jm = ones_idx + m
            jmn = ones_idx - m
            
            g_jm = np.zeros(len(ones_idx))
            mask_pos = (jm >= 0) & (jm < n)
            mask_neg = (jmn >= 0) & (jmn < n)
            g_jm[mask_pos] += 1.0 - h[jm[mask_pos]]
            g_jm[mask_neg] -= h[jmn[mask_neg]]
            
            v = corr[m] + gi[l] - g_jm
            if first:
                scores = v
                first = False
            else:
                np.maximum(scores, v, out=scores)
        
        best_j_local = np.argmin(scores)
        local_score = scores[best_j_local]
        
        if local_score < best_score:
            best_score = local_score
            best_i = i
            best_j = ones_idx[best_j_local]
    
    return best_i, best_j
```

```python
def compute_c5(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1 - h, mode='full')
    return float(np.max(c) * dx)

def to_binary(h, n):
    """Convert continuous h to binary with exactly n/2 ones."""
    target = n // 2
    # Get the top n/2 indices
    idx = np.argsort(h)[::-1]
    h_bin = np.zeros(n)
    h_bin[idx[:target]] = 1.0
    return h_bin

def project_feasible(h, n):
    """Project h to satisfy 0<=h<=1 and sum(h) = n/2."""
    target = n / 2.0
    h = np.clip(h, 0.0, 1.0)
    for _ in range(10000):
        diff = target - h.sum()
        if abs(diff) < 1e-12:
            break
        if diff > 0:
            room = 1.0 - h
            s = room.sum()
            if s < 1e-14:
                break
            h = h + diff / s * room
        else:
            s = h.sum()
            if s < 1e-14:
                break
            h = h + diff / s * h
    return np.clip(h, 0.0, 1.0)

        for i in zeros_idx:
            # Compute g(i, m) for each critical m
            # g(x, m) = (1-h[x+m]) - h[x-m]
            gi = np.empty(K)
            for l in range(K):
                m = top_k_idx[l]
                im = i + m
                imn = i - m
                val = 0.0
                if 0 <= im < n:
                    val += 1.0 - h[im]
                if 0 <= imn < n:
                    val -= h[imn]
                gi[l] = val
            
            # For each j, compute score = max_l (corr[top_k[l]] + gi[l] - g(j, top_k[l]))
            # Vectorize over j
            scores = np.empty(len(ones_idx))
            first = True
            for l in range(K):
                m = top_k_idx[l]
                jm = ones_idx + m
                jmn = ones_idx - m
                
                g_j = np.zeros(len(ones_idx))
                mp = (jm >= 0) & (jm < n)
                mn = (jmn >= 0) & (jmn < n)
                if np.any(mp):
                    g_j[mp] += 1.0 - h[jm[mp]]
                if np.any(mn):
                    g_j[mn] -= h[jmn[mn]]
                
                v = corr[m] + gi[l] - g_j
                if first:
                    scores = v
                    first = False
                else:
                    np.maximum(scores, v, out=scores)
            
            best_local = np.argmin(scores)
            if scores[best_local] < best_score:
                best_score = scores[best_local]
                best_i = i
                best_j = ones_idx[best_local]
        
        if best_i < 0 or best_score >= cur_max - 1e-14:
            break
        
        # Perform swap
        h[best_i], h[best_j] = 1.0, 0.0
        corr = np.correlate(h, 1 - h, mode='full')
        cur_max = corr.max()
    
    return h, corr.max() * dx, corr

def simulated_annealing(h, n, T_max, T_min, n_steps, deadline, seed):
    """Simulated annealing with random swaps."""
    dx = 2.0 / n
    rng = np.random.RandomState(seed)
    corr = np.correlate(h, 1 - h, mode='full')
    cur_max = corr.max()
    best_h = h.copy()
    best_max = cur_max
    
    for step in range(n_steps):
        if time.time() > deadline:
            break
        
        T = T_max * (T_min / T_max) ** (step / max(n_steps - 1, 1))
        
        ones_idx = np.where(h == 1)[0]
        zeros_idx = np.where(h == 0)[0]
        
        if len(ones_idx) == 0 or len(zeros_idx) == 0:
            break
        
        i = zeros_idx[rng.randint(len(zeros_idx))]
        j = ones_idx[rng.randint(len(ones_idx))]
        
        # Perform swap
        h[i], h[j] = 1.0, 0.0
        new_corr = np.correlate(h, 1 - h, mode='full')
        new_max = new_corr.max()
        
        delta = new_max - cur_max
        if delta < 0 or rng.random() < np.exp(-delta / max(T, 1e-10)):
            cur_max = new_max
            corr = new_corr
            if cur_max < best_max:
                best_max = cur_max
                best_h = h.copy()
        else:
            # Revert
            h[i], h[j] = 0.0, 1.0
    
    return best_h, best_max * dx
```

```python
def compute_score_matrix(h, zeros_idx, ones_idx, top_k, corr, n):
    """Compute the score matrix for all (zero, one) pairs."""
    K = len(top_k)
    
    # G_zeros[i_idx, l] = g(zeros_idx[i_idx], top_k[l])
    # g(x, m) = (1-h[x+m]) - h[x-m]
    
    G_zeros = np.zeros((len(zeros_idx), K))
    G_ones = np.zeros((len(ones_idx), K))
    
    for l, m in enumerate(top_k):
        # For zeros
        im = zeros_idx + m
        imn = zeros_idx - m
        mask_p = (im >= 0) & (im < n)
        mask_n = (imn >= 0) & (imn < n)
        G_zeros[:, l][mask_p] += 1.0 - h[im[mask_p]]
        G_zeros[:, l][mask_n] -= h[imn[mask_n]]
        
        # For ones
        jm = ones_idx + m
        jmn = ones_idx - m
        mask_p = (jm >= 0) & (jm < n)
        mask_n = (jmn >= 0) & (jmn < n)
        G_ones[:, l][mask_p] += 1.0 - h[jm[mask_p]]
        G_ones[:, l][mask_n] -= h[jmn[mask_n]]
    
    # Score matrix: score[i_idx, j_idx] = max_l (corr[top_k[l]] + G_zeros[i_idx, l] - G_ones[j_idx, l])
    # Shape: (|zeros|, K) + (|ones|, K) broadcast to (|zeros|, |ones|, K), then max over K
    
    # corr[top_k] has shape (K,)
    # G_zeros has shape (|zeros|, K)
    # G_ones has shape (|ones|, K)
    
    # score[i,j,l] = corr[top_k[l]] + G_zeros[i,l] - G_ones[j,l]
    # Using broadcasting:
    # (K,) + (|zeros|, K) - (|ones|, K) → need to reshape
    # (|zeros|, K) + (K,) - (|ones|, K) doesn't broadcast directly
    
    # Let's do: G_zeros[:, :, np.newaxis] - G_ones[np.newaxis, :, :] + corr[top_k][np.newaxis, np.newaxis, :]
    # Shape: (|zeros|, |ones|, K)
    # Then max over axis=2
    
    # But this creates a (|zeros|, |ones|, K) array which for 125*125*30 = 468,750 elements
    # That's fine memory-wise.
    
    score_matrix = G_zeros[:, :, np.newaxis] - G_ones[np.newaxis, :, :]
    score_matrix += corr[top_k][np.newaxis, np.newaxis, :]
    score_matrix = score_matrix.max(axis=2)
    
    # Find the minimum
    flat_idx = np.argmin(score_matrix)
    i_idx, j_idx = np.unravel_index(flat_idx, score_matrix.shape)
    
    return score_matrix[i_idx, j_idx], zeros_idx[i_idx], ones_idx[j_idx]
```

Only terms where l ∈ {i, j} or l+m ∈ {i, j} change.
