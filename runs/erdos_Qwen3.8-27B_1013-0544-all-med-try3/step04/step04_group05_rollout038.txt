Wait, I realize there's an issue with my `nesterov_gradient` function. The Nesterov momentum with the "y = x + ((t-1)/t_new) * (x_prev)" update is for minimizing convex functions with known Lipschitz constant. Since our problem is non-convex (the max of bilinear functions), the Nesterov acceleration might not help and could even hurt.

For non-convex problems, plain momentum (without Nesterov's increasing t_k) is often better. Let me use plain momentum:

```python
vel = momentum * vel + (1 - momentum) * grad
x_new = project(x + step * vel)
```

This is the "heavy ball" method or "-gradient descent with momentum". It's known to work well in practice for non-convex problems.

Let me also reconsider the step size. For the subgradient method, the step size should decrease over time for convergence. A common schedule is:
- α_t = α_0 / (1 + t * decay)
- Or: α_t = c / sqrt(t) (for O(1/sqrt(n)) convergence)

But in practice, a fixed small step with momentum works well for escaping local minima.

Let me also think about the active set more carefully. The max of the correlation is achieved at one or a few lags. The subgradient should be computed only for the active lags (those achieving the max). If we include too many lags, the gradient points in a compromise direction that doesn't reduce the max.

So the key is: **use a small active set** (just the top 5-10 lags) for the subgradient, not dozens.

import numpy as np
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)

def project_h(h, target_sum):
    h = np.clip(h.astype(float).copy(), 0.0, 1.0)
    for _ in range(300):
        diff = target_sum - h.sum()
        if abs(diff) < 1e-14:
            break
        free = (h > 1e-12) & (h < 1.0 - 1e-12)
        if free.sum() == 0:
            free = np.ones(len(h), dtype=bool)
        h[free] += diff / free.sum()
        h = np.clip(h, 0.0, 1.0)
    return h

def compute_subgrad(h, lags):
    n = len(h)
    grad = np.zeros(n)
    for lag in lags:
        if lag == 0:
            grad += (1.0 - 2.0 * h)
        elif lag > 0:
            grad[lag:] += (1.0 - h[:-lag])
            grad[:n - lag] -= h[lag:]
        else:
            m = -lag
            grad[:n - m] += (1.0 - h[m:])
            grad[m:] -= h[:n - m]
    return grad

def smooth_max_val(x, beta):
    m = np.max(x)
    x_shift = np.clip(beta * (x - m), -400, 400)
    return m + np.log(np.sum(np.exp(x_shift)) / len(x)) / beta

def weighted_subgrad(h, lags, weights):
    n = len(h)
    grad = np.zeros(n)
    for lag, w in zip(lags, weights):
        if w < 1e-14:
            continue
        if lag == 0:
            grad += w * (1.0 - 2.0 * h)
        elif lag > 0:
            grad[lag:] += w * (1.0 - h[:-lag])
            grad[:n - lag] -= w * h[lag:]
        else:
            m = -lag
            grad[:n - m] += w * (1.0 - h[m:])
            grad[m:] -= w * h[:n - m]
    return grad

def prox_grad_smooth(h0, target, time_fn, max_iters, m_lags):

    n = len(h0)
    best = h0.copy()
    best_c5 = compute_c5(best)
    vel = np.zeros(n)
    step = 0.01
    momentum = 0.9

            break

        max_c = np.max(corr)
        beta = 200.0  # Fixed beta for speed

        probs = np.exp(shifted)
        probs /= probs.sum()
        
        top_idx = np.argsort(probs)[::-1][:m_lags]

        w_top = probs[top_idx]

        gn = np.linalg.norm(g)
        if gn < 1e-14:
