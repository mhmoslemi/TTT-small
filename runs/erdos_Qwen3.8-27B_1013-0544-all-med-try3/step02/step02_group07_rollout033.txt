This is interesting! If we use a binary solution, we automatically get 0 at lag 0, which might be the hardest lag to optimize.

Let me think about what binary patterns minimize the max correlation. This is equivalent to finding a binary sequence of length 70 with 35 ones that minimizes the maximum "cross-correlation" between the sequence and its complement at all shifts.

This is related to the problem of "bent functions" in coding theory, or more practically, to finding "balanced" binary sequences with low autocorrelation.

For a binary sequence, corr at lag d = number of i where h[i]=1, h[i+d]=0 (for d>0) or h[i]=0, h[i+d]=1 (for d<0). This is the "Hamming distance" between h and its shift, divided by... wait, it's just the count.

corr[d] for d>0 = #{i : h[i]=1, h[i+d]=0}
This is the number of "10" patterns at distance d.

Similarly, the "01" patterns at distance d = #{i : h[i]=0, h[i+d]=1} = #{i : h[i+d]=1, h[i]=0} = corr for lag -d.

Total transitions at distance d = corr[d] + corr[-d] = #{i : h[i] ≠ h[i+d]}

For a binary sequence with 35 ones and 35 zeros, the average number of "10" pairs at distance d is approximately (35/70) * (35/70) * (70-d) ≈ 0.25*(70-d) for large d.

To minimize the max, we want all lags to have about the same number of "10" pairs. This is like a "balanced" or "equidistributed" sequence.

The theoretical minimum for a binary sequence would be when all lags have the same number of transitions, which is approximately (70-d)/4 for each lag d. The max would then be at d=0... but d=0 is 0 for binary. So the max would be at d=1: approximately (70-1)/4 ≈ 17.25. C5 ≈ 17.25 * 2/70 ≈ 0.493.

That's worse than our current 0.38! So binary solutions are NOT good. The continuous relaxation is important.

import numpy as np
from scipy.optimize import minimize, Bounds
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)

def smooth_max(x, beta):
    m = np.max(x)
    return m + np.log(np.sum(np.exp(beta * (x - m)))) / beta

def project_h(h, target_sum):
    h = h.copy()
    for _ in range(50):
        h = np.clip(h, 0.0, 1.0)
        s = h.sum()
        if abs(s - target_sum) < 1e-13:
            break
        diff = target_sum - s
        free = (h > 1e-12) & (h < 1.0 - 1e-12)
        if free.sum() > 0:
            h[free] += diff / free.sum()
        else:
            h += diff / len(h)
    return np.clip(h, 0.0, 1.0)

def _obj_smooth(h, beta, dx):
    corr = np.correlate(h, 1.0 - h, mode="full")
    return smooth_max(corr, beta) * dx

def _con_sum(h, target_sum):
    return h.sum() - target_sum

def slsqp_solve(h0, beta, target_sum, dx, maxiter=3000, ftol=1e-14):
    n = len(h0)
    bounds = Bounds(np.zeros(n), np.ones(n))
    res = minimize(_obj_smooth, h0, args=(beta, dx), method='SLSQP',
                   bounds=bounds,
                   constraints=[{'type': 'eq', 'fun': _con_sum, 'args': (target_sum,)}],
                   options={'maxiter': maxiter, 'ftol': ftol})
    return res.x

def coordinate_descent(h, target_sum, dx, n_sweeps=20, deadline=None):
    """1D coordinate descent with golden section search."""
    n = len(h)
    best_h = h.copy()
    best_c5 = compute_c5(h)
    
    for sweep in range(n_sweps):
        if deadline is not None and time.time() > deadline - 10:
            break
        improved = False
        for j in range(n):
            if deadline is not None and time.time() > deadline - 10:
                break
            # Minimize over h[j] in [0,1] keeping sum constraint
            # If we change h[j] by delta, we need to adjust another coordinate
            # Simple approach: change h[j] and renormalize via projection
            # But projection changes all coordinates...
            # Alternative: fix the "adjustment" to be distributed
            # Actually, let's just do: try a few values of h[j], project, evaluate
            
            h_orig = best_h[j]
            for new_val in [0.0, 0.25, 0.5, 0.75, 1.0, h_orig - 0.1, h_orig + 0.1, h_orig - 0.05, h_orig + 0.05]:
                if new_val < 0 or new_val > 1:
                    continue
                h_trial = best_h.copy()
                h_trial[j] = new_val
                h_trial = project_h(h_trial, target_sum)
                c5 = compute_c5(h_trial)
                if c5 < best_c5 - 1e-12:
                    best_h = h_trial
                    best_c5 = c5
                    improved = True
        
        if not improved:
            break
    
    return best_h, best_c5

def targeted_search(h, target_sum, dx, n_rounds, deadline):
    """Targeted search: reduce worst lags via pair transfers."""
    n = len(h)
    best_h = h.copy()
    best_c5 = compute_c5(h)
    rng = np.random.default_rng(777)
    
    for r in range(n_rounds):
        if time.time() > deadline - 30:
            break
        h_cur = best_h.copy()
        corr = np.correlate(h_cur, 1.0 - h_cur, mode="full")
        top_lags = np.argsort(corr)[::-1][:5]
        
        for k_idx in top_lags:
            if time.time() > deadline - 30:
                break
            d = k_idx - (n - 1)
            if d == 0:
                # Lag 0: corr = sum h[i]*(1-h[i]), minimize by making h binary
                # Try pushing values toward 0 or 1
                for _ in range(20):
                    j = rng.integers(n)
                    if h_cur[j] > 0.5:
                        h_cur[j] = min(1.0, h_cur[j] + 0.1)
                    else:
                        h_cur[j] = max(0.0, h_cur[j] - 0.1)
                    h_trial = project_h(h_cur, target_sum)
                    c5 = compute_c5(h_trial)
                    if c5 < best_c5:
                        best_h = h_trial.copy()
                        best_c5 = c5
                continue
            
            ad = abs(d)
            if ad >= n:
                continue
            
            # Find pairs contributing most to this lag
            if d > 0:
                pairs = [(i, i+d) for i in range(n - d)]
            else:
                pairs = [(i, i+ad) for i in range(n - ad)]
            
            contribs = []
            for i, j in pairs:
                if d > 0:
                    c = h_cur[i] * (1 - h_cur[j])
                else:
                    c = h_cur[j] * (1 - h_cur[i])
                contribs.append(c)
            
            # Sort by contribution, try to reduce top ones
            order = np.argsort(contribs)[::-1][:15]
            for idx in order:
                i, j = pairs[idx]
                if d > 0:
                    # contribution = h[i]*(1-h[j]), reduce by increasing h[j] or decreasing h[i]
                    hi, hj = h_cur[i], h_cur[j]
                else:
                    # contribution = h[j]*(1-h[i]), reduce by increasing h[i] or decreasing h[j]
                    hi, hj = h_cur[j], h_cur[i]
                
                if hi < 0.02 or hj > 0.98:
                    continue
                
                for amount in [0.03, 0.05, 0.08, 0.12]:
                    h_trial = h_cur.copy()
                    if d > 0:
                        h_trial[i] = max(0, h_trial[i] - amount)
                        h_trial[j] = min(1, h_trial[j] + amount)
                    else:
                        h_trial[j] = max(0, h_trial[j] - amount)
                        h_trial[i] = min(1, h_trial[i] + amount)
                    h_trial = project_h(h_trial, target_sum)
                    c5 = compute_c5(h_trial)
                    if c5 < best_c5 - 1e-12:
                        best_h = h_trial.copy()
                        best_c5 = c5
                        h_cur = h_trial.copy()
                        break
        
        # Occasionally add perturbation to escape local minima
        if r % 30 == 29:
            h_pert = best_h + rng.normal(0, 0.03, n)
            h_pert = project_h(h_pert, target_sum)
            if compute_c5(h_pert) < best_c5:
                best_h = h_pert.copy()
                best_c5 = compute_c5(best_h)
    
    return best_h, best_c5

def make_starts(n, target_sum, seed):
    """Generate diverse starting points."""
    starts = []
    rng = np.random.default_rng(seed)
    x = np.linspace(0, 2, n)
    
    # Sinusoidal
    for freq in [1, 2, 3]:
        for amp in [0.4, 0.6]:
            h = np.clip(0.5 + amp * np.sin(2 * np.pi * freq * x / 2), 0, 1)
            starts.append(project_h(h, target_sum))
    
    # Bump functions
    for c in [0.3, 0.5, 0.7]:
        for w in [0.1, 0.2, 0.3]:
            h = np.exp(-((x - c) ** 2) / w)
            h = np.clip(h, 0, 1)
            starts.append(project_h(h, target_sum))
    
    # Random
    for _ in range(4):
        h = project_h(rng.uniform(0, 1, n), target_sum)
        starts.append(h)
    
    return starts

        h_init = np.array(initial_h_values, dtype=float).copy()
    else:
        h_init = np.full(70, 0.5)

    n = len(h_init)
    dx = 2.0 / n
    target_sum = n / 2.0
    h_init = project_h(h_init, target_sum)
    best_h = h_init.copy()
    best_c5 = compute_c5(best_h)

    for beta in [20, 50, 100, 200, 400]:
        if time.time() > deadline - 80:
            break
        try:
            h_new = slsqp_solve(best_h, beta, target_sum, dx, maxiter=2000, ftol=1e-14)
            h_new = project_h(h_new, target_sum)
            c5 = compute_c5(h_new)
            if c5 < best_c5:
                best_h, best_c5 = h_new.copy(), c5
        except Exception:
            pass

    if deadline - time.time() > 180:
        starts = make_starts(n, target_sum, seed)
        for h0 in starts:
            if time.time() > deadline - 50:
                break
            for beta in [80, 200]:
                if time.time() > deadline - 25:
                    break
                try:
                    h_new = slsqp_solve(h0, beta, target_sum, dx, maxiter=1500, ftol=1e-13)
                    h_new = project_h(h_new, target_sum)
                    c5 = compute_c5(h_new)
                    if c5 < best_c5:
                        best_h, best_c5 = h_new.copy(), c5
                except Exception:
                    pass

    if time.time() < deadline - 40:
        best_h, best_c5 = targeted_search(best_h, target_sum, dx, 120, deadline)

    if time.time() < deadline - 25:
        best_h, best_c5 = coordinate_descent(best_h, target_sum, dx, 12, deadline)

    if time.time() < deadline - 20:
        rng = np.random.default_rng(seed + 42)
        for _ in range(4):
            if time.time() > deadline - 12:
                break
            h0 = best_h + rng.normal(0, 0.04, n)
            h0 = project_h(h0, target_sum)
            for beta in [300, 600]:
                if time.time() > deadline - 8:
                    break
                try:
                    h_new = slsqp_solve(h0, beta, target_sum, dx, maxiter=3000, ftol=1e-14)
                    h_new = project_h(h_new, target_sum)
                    c5 = compute_c5(h_new)
                    if c5 < best_c5:
                        best_h, best_c5 = h_new.copy(), c5
                except Exception:
                    pass

    if time.time() < deadline - 10:
        best_h, best_c5 = targeted_search(best_h, target_sum, dx, 40, deadline)

    if time.time() < deadline - 5:
        try:
            h_new = slsqp_solve(best_h, 1000, target_sum, dx, maxiter=5000, ftol=1e-15)
            h_new = project_h(h_new, target_sum)
            c5 = compute_c5(h_new)
            if c5 < best_c5:
                best_h, best_c5 = h_new.copy(), c5
        except Exception:
            pass

    best_h = project_h(best_h, target_sum)
    best_c5 = compute_c5(best_h)
    return best_h, best_c5, n
