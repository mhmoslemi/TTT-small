The smooth max of corr values: s_β(corr) = m + log(Σ exp(β(c_i - m)))/β

ds_β/dh[j] = (1/β) * Σ_i [β * exp(β(c_i - m)) / Σ_l exp(β(c_l - m))] * (dc_i/dh[j])

And dc_i/dh[j] is the subgradient for lag i.

This is O(n²) per gradient evaluation (n lags × n dimensions), which for n=70 is 4900 flops per gradient. SLSQP might call this many times but it should be OK.

    d = lag_idx - (n - 1)

            h = project_feasible(h - lr * grad, ts_f)
            if it % 1000 == 999:
                c5 = compute_c5(h)
                if c5 < best_c5:
                    best_h = h.copy()
                    best_c5 = c5
                    h = best_h.copy()
        c5 = compute_c5(h)
        if c5 < best_c5:
            best_h = h.copy()
            best_c5 = c5

    # Phase 8: Final SLSQP
    if budget_s - (time.time() - t0) > 15:
        n_f = len(best_h)
        dx_f = 2.0 / n_f
        ts_f = n_f / 2.0
        bnds_f = Bounds(np.zeros(n_f), np.ones(n_f))
        cs_f = [{'type': 'eq', 'fun': con_eq, 'jac': con_eq_jac, 'args': (ts_f,)}]
        for beta in [10000, 50000, 100000]:
            if budget_s - (time.time() - t0) < 8:
                break
            try:
                res = minimize(smooth_max_obj, best_h, args=(dx_f, beta),
                              jac=smooth_max_grad,
                              method='SLSQP', bounds=bnds_f,
                              constraints=cs_f,
                              options={'maxiter': 10000, 'ftol': 1e-16})
                h_new = project_feasible(res.x, ts_f)
                c5 = compute_c5(h_new)
                if c5 < best_c5:
                    best_h = h_new.copy()
                    best_c5 = c5
            except Exception:
                pass

    return best_h, best_c5, len(best_h)
