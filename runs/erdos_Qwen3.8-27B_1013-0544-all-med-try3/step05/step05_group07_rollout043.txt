    h = np.where(h > 0.5, 1.0, 0.0)
    # Ensure correct number of ones

The soft minimax objective is:
F(x) = m(x) + (1/α) * log(Σ_k exp(α * (c_k(x) - m(x))))

where m(x) = max_k c_k(x) and c_k(x) = Σ_i x_i * (1 - x_{i+k}) * dx.

The gradient is:
∇F = ∇m + (1/α) * Σ_k exp(α(c_k - m)) / Σ_j exp(α(c_j - m)) * ∇c_k

The term ∇m is the subgradient of max, which is ∇c_{k*} where k* = argmax.

So: ∇F = (1 + p_{k*}) * ∇c_{k*} + Σ_{k≠k*} p_k * ∇c_k

where p_k = exp(α(c_k - m)) / Σ_j exp(α(c_j - m)).

And ∇c_k can be computed as described.

For the continuous refinement, the key insight is:
- Start from a binary (or near-binary) solution
- The "active" shifts (those at the maximum) define a system of equations
- We want to distribute the "slack" among nearby values to reduce the maximum

A simple approach: **Projected gradient descent on the active shifts**.

1. Compute all shift values c(k)
2. Identify active set A = {k : c(k) > max - ε}
3. Compute gradient of max(c(A)) at current point (= average gradient over A)
4. Take a small step in the negative gradient direction
5. Project back to feasible set
6. Repeat

This is essentially what the subgradient method does, but restricted to the active set.

Let me also try: **Solving the KKT conditions directly**.

At the optimum:
- h[i] ∈ [0,1] for all i
- ∑h[i] = n/2
- There exist multipliers λ_k ≥ 0 for the active constraints (c(k) = max) and μ for the sum constraint such that:
  ∂/∂h[i] [max_k c(k)] = μ + λ'_i (where λ'_i is the KKT multiplier for the box constraint)

For active shifts with h[i] ∈ (0,1):
Σ_{k ∈ A} λ_k * ∂c(k)/∂h[i] = μ

This is a system of linear equations that we can solve!

But this requires knowing the active set and the box constraint multipliers, which is iterative.

def project_feasible(h, b=0.0, a=1.0):
    target = (a - b) * len(h) / 2.0 + b * len(h)
    # Actually let's keep it simple: target = n/2 for h in [0,1]
    h = np.clip(h, b, a)
    target = len(h) / 2.0

        if diff > 0:

            s = room.sum()
            if s < 1e-15: break
            h += diff / s * room
        else:
            s = h.sum() - b * len(h)
            if s < 1e-15: break

    dx = 2.0 / n
    g = np.zeros(n)
    if k >= 0:
        g[k:] += (1.0 - h[:n-k])
        g[:n-k] += -h[k:]
    else:
        g[:n+k] += -h[-k:]
        g[-k:] += (1.0 - h[:n+k])
    return g * dx

    best_h = h.copy()
    best_c = compute_c5(h, n)
    lr = lr_init
    mom = 0.7
    v = np.zeros(n)
    
    for it in range(100000):
        if time.time() > deadline:
            break
        cdx = np.correlate(h, 1 - h, mode='full') * (2.0/n)
        m = cdx.max()
        active = np.where(cdx >= m - tol)[0]
        
        # Average gradient over active shifts
        g_avg = np.zeros(n)
        for idx in active:
            k = idx - (n - 1)
            g_avg += grad_max_shift(h, n, k)
        g_avg /= len(active)
        
        v = mom * v - lr * g_avg
        h_new = project_feasible(h + v)
        c_new = compute_c5(h_new, n)
        
        if c_new < best_c - 1e-14:
            best_c = c_new
            best_h = h_new.copy()
            h = h_new
            lr = min(lr * 1.01, 1.0)
        else:
            h = project_feasible(h - 0.5 * v)
            v *= 0.5
            lr *= 0.95
            if lr < 1e-8:
                break
    
    return best_h, best_c
