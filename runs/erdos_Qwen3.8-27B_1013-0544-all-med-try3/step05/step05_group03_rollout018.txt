One more thought: the `project_feasible` function uses a simple "add to room" or "scale down" approach. This might not be optimal. A better projection would minimize the distance to the feasible set, which is:
- Project onto {h : sum h = n/2, 0 ≤ h ≤ 1}

The exact projection can be found by bisection on a Lagrange multiplier:
h_proj[i] = clip(h[i] - mu, 0, 1) where mu is chosen so that sum(h_proj) = n/2.

This is the Euclidean projection, which is better than the ad-hoc method. Let me use this instead:

def project_feasible(h, n):
    target = n / 2.0
    # Euclidean projection onto {h : sum h = target, 0 <= h <= 1}
    # Use bisection on mu: h_proj = clip(h - mu, 0, 1), choose mu so sum = target
    lo = h.min() - 1.0
    hi = h.max() + 1.0
    for _ in range(100):
        mu = (lo + hi) / 2
        h_proj = np.clip(h - mu, 0.0, 1.0)
        s = h_proj.sum()
        if s > target:
            lo = mu
        else:
            hi = mu
    return np.clip(h - (lo + hi) / 2, 0.0, 1.0)
