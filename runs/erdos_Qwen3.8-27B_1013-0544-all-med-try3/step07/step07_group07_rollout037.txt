**Practical implementation:**

For the binary local search, I'll compute the delta for a swap (i, j) as follows:
1. Precompute the "set effect" and "clear effect" vectors for each position
2. The delta for swap (i,j) = set_effect[i] + clear_effect[j] + small correction

Where:
set_effect[i][k] = 1 - h[i+k-(n-1)] for 0≤i+k-(n-1)<n, k≠n-1
                 = 0 for k=n-1 or invalid

clear_effect[j][k] = -(1-h[j+k-(n-1)]) for 0≤j+k-(n-1)<n, k≠n-1
                   = 0 for k=n-1 or invalid

Correction:
- At k = j-i+n-1: +1 (because set_effect used h[j]=1 but should use h_new[j]=0)
  Wait: set_effect[i][j-i+n-1] = 1-h[i+(j-i+n-1)-(n-1)] = 1-h[j] = 1-1 = 0.
  But the true value is 1-h_new[j] = 1-0 = 1. So correction = +1. ✓
- At k = i-j+n-1: +1 (because clear_effect used h[i]=0 but should use h_new[i]=1)
  clear_effect[j][i-j+n-1] = -(1-h[j+(i-j+n-1)-(n-1)]) = -(1-h[i]) = -(1-0) = -1.
  But the true value is -(1-h_new[i]) = -(1-1) = 0. So correction = +1. ✓

- Third-party terms:
  At k = i-i'+(n-1) for i'≠i,j: -h[i']  (i.e., -h[i-k+(n-1)] where valid)
  At k = j-i'+(n-1) for i'≠i,j: +h[i']  (i.e., +h[j-k+(n-1)] where valid)

The third-party terms can be written as:
third_party[k] = -h[i-k+(n-1)] + h[j-k+(n-1)] (for valid indices, with exclusions)

The exclusions are:
- In -h[i-k+(n-1)]: exclude when i-k+(n-1) = i (k=n-1) or i-k+(n-1) = j (k=i-j+n-1)
- In +h[j-k+(n-1)]: exclude when j-k+(n-1) = i (k=j-i+n-1) or j-k+(n-1) = j (k=n-1)

So:
- At k=n-1: both excluded → 0 ✓
- At k=i-j+n-1: first term excluded (gives -h[j]=-1 excluded), second term: j-(i-j+n-1)+(n-1) = 2j-i
  → +h[2j-i] (if valid and ≠i,j)
- At k=j-i+n-1: first term: i-(j-i+n-1)+(n-1) = 2i-j → -h[2i-j] (if valid and ≠i,j)
  Second term excluded → 0

For other k: third_party[k] = -h[i-k+(n-1)] + h[j-k+(n-1)] (with validity checks)

This means the third-party terms are essentially two shifted copies of h (one negated). They are non-zero for O(n) values of k.

**Efficient computation:**

For a fixed i, I can precompute:

- The "third-party from i" part: -h[i-k+(n-1)] for valid k (this is just -h reversed and shifted)

For a fixed j:
- clear_effect[j]: O(n) work  
- The "third-party from j" part: +h[j-k+(n-1)] for valid k
