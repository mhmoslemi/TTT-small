But random search is very inefficient - most random swaps won't improve. Let me use a smarter approach:

**Guided search**: Focus on swaps that involve positions near the argmax of the correlation.

The idea: if c[m*] is the maximum, then we want to decrease c[m*]. This means we want to either:
- Set h[i]=0 where h[i]=1 and the position contributes to c[m*]
- Set h[i]=1 where h[i]=0 and the position would reduce c[m*]

For c[n-1+k] = sum_i h[i]*(1-h[i+k]), the contributing positions are those i where h[i]=1 and h[i+k]=0.

So to decrease c[m*], we should:
- Move a 1 out of the "h[i]=1" positions (i.e., set some h[i]=0 where it contributes)
- Move a 0 into the "h[i+k]=0" positions (i.e., set some h[i+k]=1 where it's 0)

This gives us a set of "good" swap candidates.

    zeros_arr = np.where(h == 0)[0].copy()

        max_stuck_rounds = 200

def pgd_step(h, n, alpha, n_iters=200, deadline=0.0):

    dx = 2.0 / n
    best_h = h.copy()
    best_c = compute_c5(h, n)
    for _ in range(n_iters):
        if time.time() > deadline:
            break
        c = np.correlate(h, 1 - h, mode='full')
        a = alpha * c
        sm = a.max()
        exp_c = np.exp(a - sm)
        p = exp_c / exp_c.sum()
        grad = np.zeros(n)
        for k in range(-(n-1), n):
            pk = p[k + n - 1]
            if pk < 1e-16:
                continue
            i_min = max(0, k)
            i_max = min(n - 1, n - 1 + k)
            if i_min <= i_max:
                grad[i_min:i_max+1] += pk * (1.0 - h[i_min - k:i_max - k + 1])
            i_min2 = max(0, -k)
            i_max2 = min(n - 1, n - 1 - k)
            if i_min2 <= i_max2:
                grad[i_min2:i_max2+1] -= pk * h[i_min2 + k:i_max2 + k + 1]
        gnorm = np.linalg.norm(grad)
        if gnorm < 1e-14:
            break
        direction = -grad / gnorm
        step = min(float(n) / (4.0 * alpha), 0.5)
        accepted = False
        for ls in range(30):
            h_new = project(h + step * (0.5 ** ls) * direction, n)
            c_new = compute_c5(h_new, n)
            if c_new < best_c - 1e-15:
                h = h_new
                best_c = c_new
                best_h = h.copy()
                step = step * (0.5 ** ls)
                accepted = True
                break
        if not accepted:
            break
    return best_h, best_c
