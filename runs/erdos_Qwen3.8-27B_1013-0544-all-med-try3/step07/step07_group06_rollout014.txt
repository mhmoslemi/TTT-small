Let me think about the vectorized approach more carefully.

For a fixed zero position i, the delta for pairing with one position j is:
delta_ij[τ] = V[j][τ] - V[i][τ] + corrections(i,j,τ)

where V[p][τ] = h[p+τ] - h[p-τ] (with out-of-range = 0).

The corrections are:
- At τ=0: -2 (always, since h[i]=0, h[j]=1)
- At τ=j-i: +1 (if |j-i| ≤ n-1)
- At τ=i-j: +1 (if |i-j| ≤ n-1)

So for fixed i, delta_ij = V[j] - V[i] + c_0*δ_{τ,0} + c_1*δ_{τ,j-i} + c_2*δ_{τ,i-j}

The most "interesting" part is V[j] - V[i], which is a vector of length 2n-1.

To find the j that minimizes max(corr + delta_ij), I need to find j that minimizes max(corr + V[j] - V[i] + corrections).

This is hard to vectorize over j because the corrections depend on j.

However, I can ignore the corrections (they only affect 3 out of 2n-1 entries) and compute:
max(corr + V[j] - V[i]) for all j simultaneously.

This is: max over k of (corr[k] + V[j,k] - V[i,k]) = max over k of (corr[k] - V[i,k] + V[j,k])

Let base = corr - V[i] (length 2n-1, computed once for fixed i).
Then for each j: score[j] = max(base + V[j])

I can compute this for all j at once:
scores = (base[None, :] + V[ones_indices, :]).max(axis=1)

Where V[ones_indices, :] has shape (n_ones, 2n-1) and base[None, :] has shape (1, 2n-1).
The result scores has shape (n_ones,).

This is O(n_ones * n) which for n_ones=125 and n=250 is ~31K operations per i. For all i (125 zeros): ~4M operations. This is very fast!

Then I pick the best j for each i, apply the correction (re-verify), and make the flip.

This is a HUGE speedup over the O(n³) per sweep approach!

- If i₀+τ ≠ j₀: change = h[i₀+τ]*0 - h[i₀+τ]*1 = -h[i₀+τ]
- If i₀+τ = j₀: change = h_new[j₀]*0 - h[j₀]*1 = 0*0 - 1*1 = -1

Case 2: i = j₀. Term: h[j₀+τ] * (1-h[j₀]). Old: h[j₀+τ] * 0. New: h_new[j₀+τ] * 1.
- If j₀+τ ≠ i₀: change = h[j₀+τ]*1 - h[j₀+τ]*0 = h[j₀+τ]
- If j₀+τ = i₀: change = h_new[i₀]*1 - h[i₀]*0 = 1*1 - 0 = 1

Case 3: i+τ = i₀, i.e., i = i₀-τ. Term: h[i₀] * (1-h[i₀-τ]). Old: 0*(1-h[i₀-τ]). New: 1*(1-h_new[i₀-τ]).
- If i₀-τ ≠ j₀: change = 1*(1-h[i₀-τ]) - 0 = 1-h[i₀-τ]
- If i₀-τ = j₀: change = 1*(1-h_new[j₀]) - 0*(1-h[j₀]) = 1*1 - 0 = 1

Case 4: i+τ = j₀, i.e., i = j₀-τ. Term: h[j₀] * (1-h[j₀-τ]). Old: 1*(1-h[j₀-τ]). New: 0*(1-h_new[j₀-τ]).
- If j₀-τ ≠ i₀: change = 0 - 1*(1-h[j₀-τ]) = -(1-h[j₀-τ])
- If j₀-τ = i₀: change = 0 - 1*(1-h_new[i₀]) = -1*0 = 0

Now, there are overlaps:
- Case 1 and Case 3 overlap when i₀ = i₀-τ, i.e., τ=0. Then i₀+τ = i₀ and i = i₀.
- Case 1 and Case 4 overlap when i₀ = j₀-τ, i.e., τ = j₀-i₀.
- Case 2 and Case 3 overlap when j₀ = i₀-τ, i.e., τ = j₀-i₀.
- Case 2 and Case 4 overlap when j₀ = j₀-τ, i.e., τ=0.
- Case 1 and Case 2 overlap when i₀ = j₀, impossible.
- Case 3 and Case 4 overlap when i₀-τ = j₀-τ, i.e., i₀=j
