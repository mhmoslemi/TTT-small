The objective is to minimize max_k |cross-correlation at shift k| (well, it's not absolute value, it's the raw cross-correlation of h with 1-h).

For binary h, c[k] = #{i : h[i]=1, h[i+k-(n-1)]=0} (for valid indices).

To minimize the max, we want the intersections |A ∩ (B - k)| to be as uniform as possible across all k.

The average intersection size is |A||B|/n = (n/2)²/n = n/4.
So we want each |A ∩ (B-k)| to be as close to n/4 as possible.

This is related to the concept of a "biplane" or "symmetric balanced incomplete block design" in design theory. If n = v and |A| = |B| = k = v/2, we want a 2-(v, k, λ) design... but that's not quite the right framework.

Actually, this is more like: we have a v-element set, partitioned into A and B each of size v/2. We want the "cross-differences" to be as uniform as possible. The cross-difference multiset is {a-b : a∈A, b∈B}. We want each element to appear roughly (v/2)²/(v-1) ≈ v/4 times.

This is related to the "difference set" concept. A (v, k, λ) difference set is a k-subset D of a v-group such that every non-identity element is a difference of exactly λ pairs from D. Here we want a "cross-difference set" where the cross-differences between A and B are uniform.

For practical purposes, this suggests that we want A to be a "random-looking" subset (like a pseudorandom sequence) to ensure uniform cross-correlations.

**Unfortunately, purely random subsets won't be optimal** because the boundary effects (non-circular correlation) matter, and we're minimizing the max, not the variance.

def compute_c5(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1 - h, mode='full')
    return float(np.max(c) * dx)

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h, 0.0, 1.0)
    for _ in range(200):
        diff = target - h.sum()
        if abs(diff) < 1e-13:
            break
        if diff > 0:
            room = 1.0 - h
            s = room.sum()
            if s < 1e-14:
                break
            h = h + diff / s * room
        else:
            s = h.sum()
            if s < 1e-14:
                break
            h = h + diff / s * h
    return np.clip(h, 0.0, 1.0)

def slsqp_smooth(h, n, alpha, maxiter, deadline):
    dx = 2.0 / n
    def obj(x):
        g = np.correlate(x, 1 - x, mode='full') * dx
        m = g.max()
        sh = alpha * (g - m)
        sm = sh.max()
        return m + (sm + np.log(np.exp(sh - sm).sum())) / alpha
    def cons_fun(x):
        return x.sum() - n / 2.0
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': cons_fun}]
    try:
        res = minimize(obj, h, method='SLSQP', bounds=bounds,
                       constraints=cons,
                       options={'maxiter': maxiter, 'ftol': 1e-15})
        return project_feasible(res.x, n)
    except Exception:
        return h

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1 - h, mode='full')
    return float(np.max(c) * dx)

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h, 0.0, 1.0)
    for _ in range(200):
        diff = target - h.sum()
        if abs(diff) < 1e-13:
            break
        if diff > 0:
            room = 1.0 - h
            s = room.sum()
            if s < 1e-14:
                break
            h = h + diff / s * room
        else:
            s = h.sum()
            if s < 1e-14:
                break
            h = h + diff / s * h
    return np.clip(h, 0.0, 1.0)

def to_binary(h, n):
    target = n // 2
    sorted_idx = np.argsort(h)[::-1]
    h_bin = np.zeros(n)
    h_bin[sorted_idx[:target]] = 1.0
    return h_bin

def slsqp_smooth(h, n, alpha, maxiter, deadline):
    dx = 2.0 / n
    n_corr = 2 * n - 1
    def obj(x):
        g = np.correlate(x, 1 - x, mode='full') * dx
        m = g.max()
        sh = alpha * (g - m)
        sm = sh.max()
        return m + (sm + np.log(np.exp(sh - sm).sum())) / alpha
    def cons_fun(x):
        return x.sum() - n / 2.0
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': cons_fun}]
    try:
        res = minimize(obj, h, method='SLSQP', bounds=bounds,
                       constraints=cons,
                       options={'maxiter': maxiter, 'ftol': 1e-15})
        return project_feasible(res.x, n)
    except Exception:
        return h

    # Phase 5: SLSQP polish
    p5 = t0 + 0.93 * (budget_s - 5)
    if time.time() < p5:
        h = best_h.copy() + 0.02 * rng.randn(n)
        h = project_feasible(h, n)
        for alpha in [100000, 1000000, 10000000]:
            if time.time() > p5:
                break
            h = slsqp_smooth(h, n, alpha, 3000, p5)
            c = compute_c5(h, n)
            if c < best_c:
                best_c = c
                best_h = h.copy()
    # Phase 6: Final greedy + SLSQP
    if time.time() < dl - 5:
        hg, cg = greedy_local_search(best_h, n, dl - 10, max_sweeps=1000, seed=seed + 200)
        if cg < best_c:
            best_c = cg
            best_h = hg.copy()
        if time.time() < dl - 3:
            h = best_h + 0.01 * rng.randn(n)
            h = project_feasible(h, n)
            h = slsqp_smooth(h, n, 5000000, 2000, dl - 2)
            c = compute_c5(h, n)
            if c < best_c:
                best_c = c
                best_h = h.copy()
    best_h = project_feasible(best_h, n)
    best_c = compute_c5(best_h, n)
    return best_h, best_c, n
