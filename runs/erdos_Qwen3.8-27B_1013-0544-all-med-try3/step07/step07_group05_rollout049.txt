```python
def ternary_minimax(a, b, delta_lo, delta_hi, iters=40):
    """Minimize max_k(a[k] + b[k]*delta) over delta in [delta_lo, delta_hi]"""
    for _ in range(iters):
        d1 = delta_lo + (delta_hi - delta_lo) / 3
        d2 = delta_hi - (delta_hi - delta_lo) / 3
        v1 = np.max(a + b * d1)
        v2 = np.max(a + b * d2)
        if v1 < v2:
            delta_hi = d2
        else:
            delta_lo = d1
    best = (delta_lo + delta_hi) / 2
    return best, np.max(a + b * best)
```

- minimize max_k (c[k] + δ * coeff[k]) over δ ∈ [δ_lo, δ_hi]
  where δ_lo = t_lo - h[i], δ_hi = t_hi - h[i], t_lo = max(0, s-1), t_hi = min(1, s)

The vector coeff has 2n-1 elements. Computing it:
For each k (0 to 2n-2):
  A(k, i) = (1-h[i-k]) if 0≤i-k<n, minus h[i+k] if 0≤i+k<n
  A(k, j) = (1-h[j-k]) if 0≤j-k<n, minus h[j+k] if 0≤j+k<n
