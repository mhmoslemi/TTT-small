grad[i] = (1-h[i+|k*|]) * [0 ≤ i ≤ n-1-|k*|] + (-h[i-|k*|]) * [|k*| ≤ i ≤ n-1]

Let me verify with the example:
k*=1, h = [0.2, 0.5, 0.8, 0.3], n=4
grad[i] = (1-h[i-1]) * [1 ≤ i ≤ 3] + (-h[i+1]) * [0 ≤ i ≤ 2]

grad[0] = 0 + (-h[1]) = -0.5
grad[1] = (1-h[0]) + (-h[2]) = 0.8 - 0.8 = 0
grad[2] = (1-h[1]) + (-h[3]) = 0.5 - 0.3 = 0.2
grad[3] = (1-h[2]) + 0 = 0.2

Let me verify: c(1) = h[1]*(1-h[0]) + h[2]*(1-h[1])
