**Coordinate Descent with Exact Line Search:**

For coordinate i, given all other h[j] (j≠i):
- f_k(t) = a_k + b_k * t where t = h[i]
- We need: a_k = f_k(h) - h[i] * b_k (using current f_k values)
- b_k = (1-h[i+k])*I1(k) - h[i-k]*I2(k)

The key computation is b_k for all k. Let me vectorize this.

For coordinate i:
- I1(k) = 1 iff 0 ≤ i+k ≤ n-1, i.e., -i ≤ k ≤ n-1-i
  In terms of the array index (n-1+k): range is [n-1-i, n-1+n-1-i] = [n-1-i, 2n-2-i]
  The values h[i+k] for k in this range: h[0], h[1], ..., h[n-1]
  
- I2(k) = 1 iff 0 ≤ i-k ≤ n-1, i.e., i-(n-1) ≤ k ≤ i
  In terms of the array index (n-1+k): range is [n-1+i-(n-1), n-1+i] = [i, n-1+i]
  The values h[i-k] for k in this range: h[i-(i-(n-1))], ..., h[i-i] = h[n-1], ..., h[0]

So:
```python
def compute_b(i, h, n):
```

Let me define: c_k = f_k[n-1+k] - h[i] * b[n-1+k]

```python
def line_search(f_full, b, current, n):
    # f_full is the full correlation array (length 2n-1)
    # b is the b_full array (length 2n-1)
    # current is the current value of h[i]
    # Returns optimal t in [0, 1]
    
    c = f_full - current * b
    # g(t) = max(c + t*b) * dx
    # Find t in [0,1] minimizing max(c + t*b)
    
    lo, hi = 0.0, 1.0
    for _ in range(50):
        mid = (lo + hi) / 2
        vals = c + mid * b
        max_val = vals.max()
        # Subgradient: b values at the argmax
        active = vals >= max_val - 1e-14
        min_b = b[active].min()
        max_b = b[active].max()
        if min_b > 1e-12:
            hi = mid  # g increasing, go left
        elif max_b < -1e-12:
            lo = mid  # g decreasing, go right
        else:
            break
    t = (lo + hi) / 2.0
    return min(1.0, max(0.0, t))
```

Each line search is O(n * 50) = O(n). With n=250, that's 12500 operations. For 250 coordinates: 3.125 million per sweep. Very fast!

```python
            break

        for i in range(n):
            b = np.zeros(2*n-1)
            b[n-1-i : 2*n-1-i] += (1.0 - h)
            b[i : n+i] -= h[::-1]

            if abs(t_new - h[i]) > 1e-14:

                h[i] = t_new

        for i in range(n-1, -1, -1):
```
