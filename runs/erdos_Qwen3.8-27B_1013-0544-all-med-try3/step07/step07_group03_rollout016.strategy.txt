### Approach and Rationale
Our approach aims to improve the Erdős minimum overlap constant by **optimizing for larger function supports** instead of fixed spatial periodicity. The core insight is that the optimal overlap is minimized by functions with **broader, flatter profiles** rather than sharp transitions. This method expands the hyperparameter space to include longer support lengths, reducing autocorrelation peaks by averaging out discontinuity effects. The strategy systematically explores function shapes that avoid alignments of significant patterns across all lags.

Key differentiators:
- **Beyond local optima**: While prior work used continuous optimization in tight periodic assumptions, here we enable unconstrained support expansion.
- **Space-filling curve initialization**: We start from configurations that avoid pattern-based assumptions, better preparing for global optimization.
- **Phase-separated shifts**: Slow cooling schedule for global exploration followed by fast adaptation prevents stalling at noise-vs-signal balance points.

**Major risk**: Longer support functions might be harder to optimize computationally. Mitigation: Use decaying time budgets per function length and prioritize shorter durations for evaluations.

<a name="mathspec"></a>
### Mathematical Specification
We optimize a function h(x) on [0,2] represented on discrete grid x_i. Let:
- n = resolution points
- Support length L = floor(n/3) to n (maximum)
- Constraints: ∑h[i] * (2/n) ≈ 1 (feasibility projection)

Objective: Minimize
C₅(n, L) = max_{k∈lags} [ (2/n) × ℂ(h, 1-h, k) ]

Where ℂ(h, 1-h, k) is the grid-aligned overlap integral at lag k:

ℂ(h, 1-h, k) = ∑_{i=0}^{n-|k|-1} h[i] * (1 - h[i+k])

We use a **hierarchical time budget** slicing:
- 1/3 for period discovery
- 1/3 for cooling schedule
- 1/3 for cross-resolution consolidation

<a name="impdetail"></a>
### Implementation Procedure
This method self-validates all candidates using the problem's exact eval_metric. Candidates must:
1. Have finite objective values
2. Pass exact integral check (sum(h)*dx = 1)
3. Reuse parental structure for restarts

**Main Loop Steps**:
1. Grid initialization ($(n=150, 250)$)
   ```python
   def init_grid(n):
       if n % 2 != 0: n += 1  # Force even resolution
       h = np.heaviside(np.random.random(n)-0.5, 0.5).astype(float)
       # Stretch support randomly between floor(n/3) and n
       L = min(n*2//3, random.randrange(n//3, n))
       focus = random.rand(2)*n  # Target coverage areas
       return h, L   # Returns (function, recommended support)
   ```

2. Consistency check:
   ```python
   def project_feasible(h_vec, n):
       dx = 2.0/n
       target = n/2.0
       total = h_vec.sum()
       # Distribute to satisfy integral constraint
       delta = target - total
       if abs(delta) < 1e-8: return h_vec.clip(0,1)
       # Apply difference to maximize min/max balance
       mask = np.argsort(h_vec)[:max(int(abs(delta)), 1)] if delta < 0 else \
              np.argsort(h_vec)[-max(int(abs(delta)), 1):]
       h_vec[mask] += delta/len(mask) * (1 - h_vec[mask])/(1.0-sum(h_vec[mask]))
       return np.clip(project_feasible(h_vec, n), 0, 1)
   ```

3. Optimizer core (using memory-inspired scheduling):
   ```python
   def adaptive_slsqp(h, n, alpha=500, deadline):
       def obj(x): return 1 - np.log1p(np.exp(alpha*(c_vals - alpha)))
       bounds = [(0,1)]*n
       # Hierarchical objective including self-projection
       x0 = np.random.dirichlet([2]*200)[:n]  # Scrambled simplex start
       cons = ({'type':'eq','fun':lambda x: x.sum()-n/2})
       try: return minimize(obj, x0, bounds=bounds, 
                           constraints=cons, tol=1e-5,
                           options={'maxiter':deadline,'ftol':1e-9})
       except: fallback = project_feasible(x0[:n], n)
       return optimize_with_augmentation(fallback, obj, deadlines)
   ```

4. Objective evaluation with binning:
   ```python
   def compute_c5(h_vec, n):
       dx = 2.0/n
       corr = np.correlate(h_vec, 1-h_vec, mode='full')
       c_vals = (corr[:n] + corr[-n:]) / (n/len(h_vec))  # Lazy lag overlap
       return dx * max_max_overlap(c_vals, n)  # Custom median-filtered peak finder
   ```
