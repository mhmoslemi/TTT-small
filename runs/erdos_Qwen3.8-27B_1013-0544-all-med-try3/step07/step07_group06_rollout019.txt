This is O(n) to check for a given (i,j) pair.

So the algorithm is:
1. Compute gain[i,k] for all i,k: O(n²)
2. For the peak k*: find best i (min gain_i[k*] over h[i]=0) and best j (max gain_j[k*] over h[j]=1)
3. Check if the swap improves the max: O(n)
4. If yes, apply; if no, try second-best i, etc.

This is O(n²) per swap application, and we might do O(n) swaps. Total O(n³) = 15.6M for n=250. In Python with numpy vectorization, this should take a few seconds.

```python
    # Contributions from i (0→1): (1-h[i+k]) - h[i-k]
    idx_ip = i + lags  # i+k
    v_ip = (idx_ip >= 0) & (idx_ip < n)
    idx_im = i - lags  # i-k
    v_im = (idx_im >= 0) & (idx_im < n)
    
    delta = np.zeros(2*n-1)
    delta[v_ip] += (1.0 - h[np.clip(idx_ip, 0, n-1)][v_ip])
    delta[v_im] -= h[np.clip(idx_im, 0, n-1)][v_im]
    
    # Contributions from j (1→0): -(1-h[j+k]) + h[j-k]
    idx_jp = j + lags  # j+k
    v_jp = (idx_jp >= 0) & (idx_jp < n)
    idx_jm = j - lags  # j-k
    v_jm = (idx_jm >= 0) & (idx_jm < n)
    
    delta[v_jp] -= (1.0 - h[np.clip(idx_jp, 0, n-1)][v_jp])
    delta[v_jm] += h[np.clip(idx_jm, 0, n-1)][v_jm]
    
    return delta
```

Also, I should consider the **dual problem**. The minimax problem:
min_h max_k c[k]
can be written as:
min_h t s.t. c[k] ≤ t ∀k, constraints on h

The dual (for the continuous relaxation) involves:
max_{λ ≥ 0, Σλ=1} min_h Σ_k λ_k * c[k] + constraints

The inner minimization Σ_k λ_k * c[k] = Σ_k λ_k * Σ_i h[i](1-h[i+k]) = Σ_i h[i] * (1 - Σ_k λ_k * h[i+k])... this is still bilinear.

For fixed λ, the problem is:
min_h Σ_i h[i] * (1 - (λ*h)[i]) subject to constraints
= min_h Σ_i h[i] - Σ_i h[i] * (λ*h)[i]
= min_h n/2 - Σ_i h[i] * (λ*h)[i]  (since Σh = n/2 is fixed)
= max_h Σ_i h[i] * (λ*h)[i] - n/2

And (λ*h)[i] = Σ_k λ[k] * h[i+k-(n-1)] (cross-correlation)

So Σ_i h[i] * (λ*h)[i] is the "quadratic form" h^T A h where A is a circulant-like matrix defined by λ.

This is a quadratic program! For fixed λ, we solve:
max_h h^T A h - n/2 s.t. 0≤h≤1, Σh=n/2

This is a non-convex QP (maximizing a quadratic) but can be tackled with standard methods.

The full algorithm would be:
1. Initialize λ (e.g., uniform or based on current peaks)
2. Solve the QP for h
3. Update λ based on which constraints are active (dual update)
4. Repeat

This is essentially the **cutting-plane / column generation** approach to the minimax problem. It converges to the optimal solution (for the continuous relaxation).

However, solving the QP at each step might be expensive. And we need to handle the non-convexity.

An alternative: use the **exponential weighting** (follow-the-perturbed-leader) approach:
- At each iteration, solve: min_h Σ_k c[k] * exp(β * c[k]_prev) 
  where c[k]_prev is the correlation from the previous iterate
- This weights the lags by their current "importance"
- The inner problem is: min_h Σ_k w_k * c[k] = min_h Σ_i h[i] * (1 - Σ_k w_k * h[i+k_norm])
  = min_h n/2 - Σ_i h[i] * (w * h)[i]
  = max_h (w*h) ⊙ h - n/2

This is the same QP with λ = w / sum(w).

```python
def compute_c5(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1 - h, mode='full')
    return float(np.max(c) * dx)

def get_corr(h, n):
    return np.correlate(h, 1 - h, mode='full')

def project_fit(h, target):
    """Project h to {0<=x<=1, sum=x=target}"""
    h = h.astype(float).copy()
    lo, hi = h.min() - 0.5, h.max() + 0.5
    for _ in range(100):
        mid = (lo + hi) / 2
        pm = np.clip(h - mid, 0, 1)
        if pm.sum() > target:
            lo = mid
        else:
            hi = mid
    out = np.clip(h - (lo+hi)/2, 0, 1)
    d = target - out.sum()
    if abs(d) > 1e-9:
        m = (out > 1e-6) & (out < 1 - 1e-6)
        if m.any():
            out[m] += d / m.sum()
    return np.clip(out, 0, 1)

def to_binary(h, n):
    t = n // 2
    idx = np.argpartition(h, -t)[-t:]
    b = np.zeros(n)
    b[idx] = 1.0
    return b

def smooth_max(h, n, alpha):
    dx = 2.0 / n
    c = get_corr(h, n) * dx
    cm = c.max()
    sh = alpha * (c - cm)
    sm = sh.max()
    e = np.exp(sh - sm)
    val = cm + (sm + np.log(e.sum())) / alpha
    pw = e / e.sum()
    return val, pw
    
def smooth_grad(h, n, pw):
    """Gradient of smooth max at h with weights pw (over 2n-1 correlations)."""
    lags = np.arange(-(n-1), n)
    j = np.arange(n)
    
    # For each j: grad[j] = sum_k pw[k] * [(1-h[j+lag_k]) - h[j-lag_k]] (valid only)
    idx1 = j[:, None] + lags[None, :]
    v1 = (idx1 >= 0) & (idx1 < n)
    idx2 = j[:, None] - lags[None, :]
    v2 = (idx2 >= 0) & (idx2 < n)
    
    h1 = np.where(v1, h[np.clip(idx1, 0, n-1)], 0.0)
    h2 = np.where(v2, h[np.clip(idx2, 0, n-1)], 0.0)
    
    g1 = (pw[None, :] * (1.0 - h1) * v1).sum(axis=1)
    g2 = (pw[None, :] * h2 * v2).sum(axis=1)
    
    return g1 - g2

def grad_descent(h, n, deadline, alphas=None):

        for step in range(20000):

            val, pw = smooth_max(h, n, alpha)
            g = smooth_grad(h, n, pw)
            h_new = project_fit(h - lr * g, target)
            val_new, _ = smooth_max(h_new, n, alpha)
```

```python
def peak_directed_search(h, n, deadline, max_iter=5000):
    """Try to reduce the peak correlation by targeted swaps."""
    h = to_binary(h, n).copy()
    corr = get_corr(h, n)
    cur = corr.max()
    best_c = cur
    best_h = h.copy()
    
    lags = np.arange(-(n-1), n)
    n_corr = 2*n - 1
    p_plus = np.arange(n)[:, None] + lags[None, :]
    p_minus = np.arange(n)[:, None] - lags[None, :]
    v_plus = (p_plus >= 0) & (p_plus < n)
    v_minus = (p_minus >= 0) & (p_minus < n)
    pp_c = np.clip(p_plus, 0, n-1)
    pm_c = np.clip(p_minus, 0, n-1)
    
    ones = np.where(h==1)[0].tolist()
    zeros = np.where(h==0)[0].tolist()
    
    for it in range(max_iter):
        if time.time() > deadline:
            break
        
        # Find peak lag
        peak_idx = corr.argmax()
        peak_lag = peak_idx - (n-1)
        peak_val = corr[peak_idx]
        
        # For each zero position i, compute how much flipping i to 1 would
        # reduce the peak
        best_gain = 0
        best_i = -1
        best_j = -1
        best_delta = None
        
        # Precompute delta_i for all zeros (expensive: O(n_zeros * n_corr))
        # For n=250: 125 * 499 = 62K ops. OK.
        
        for i in zeros:
            di = np.zeros(n_corr)
            ip = pp_c[i]; v1 = v_plus[i]
            im = pm_c[i]; v2 = v_minus[i]
            di[v1] += (1.0 - h[ip[v1]])
            di[v2] -= h[im[v2]]
            
            # At the peak, the change is di[peak_idx]
            # We want di[peak_idx] to be most negative
            gain = -di[peak_idx]  # positive = good
            if gain > best_gain:
                best_gain = gain
                best_i = i
                best_delta_i = di
        
        if best_gain <= 0 or best_i < 0:
            break  # Can't improve the peak
        
        # Now find the best j (1→0) that minimizes the overall max
        # delta_total = best_delta_i + delta_j
        # We want max(corr + best_delta_i + delta_j) < cur
        # = max(corr + best_delta_i) - max increase from delta_j
        base = corr + best_delta_i
        base_max = base.max()
        
        best_j_gain = 0
        for j in ones:
            dj = np.zeros(n_corr)
            jp = pp_c[j]; v3 = v_plus[j]
            jm = pm_c[j]; v4 = v_minus[j]
            dj[v3] -= (1.0 - h[jp[v3]])
            dj[v4] += h[jm[v4]]
            
            new_max = (base + dj).max()
            improvement = cur - new_max
            if improvement > best_j_gain:
                best_j_gain = improvement
                best_j = j
                best_delta_total = base + dj
        
        if best_j < 0 or best_delta_total[best_delta_total.argmax()] >= cur:
            break
        
        # Apply swap
        h[best_i] = 1.0
        h[best_j] = 0.0
        corr = best_delta_total
        cur = corr.max()
        ones.remove(best_j)
        ones.append(best_i)
        zeros.remove(best_i)
        zeros.append(best_j)
        
        if cur < best_c:
            best_c = cur
            best_h = h.copy()
    
    return best_h, best_c * (2.0/n)
```

For all zeros i simultaneously:
delta_i[i, k] = (1-h[i+lag_k]) - h[i-lag_k] for valid indices

```python
import numpy as np

def compute_c5(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1 - h, mode='full')
    return float(np.max(c) * dx)

def get_corr(h, n):
    return np.correlate(h, 1 - h, mode='full')

def project_fit(h, target):
    h = h.astype(float).copy()
    lo = h.min() - 0.5
    hi = h.max() + 0.5
    for _ in range(100):
        mid = (lo + hi) / 2.0
        pm = np.clip(h - mid, 0.0, 1.0)
        if pm.sum() > target:
            lo = mid
        else:
            hi = mid
    out = np.clip(h - (lo + hi) / 2.0, 0.0, 1.0)
    d = target - out.sum()
    if abs(d) > 1e-9:
        m = (out > 1e-7) & (out < 1.0 - 1e-7)
        if m.any():
            out[m] += d / m.sum()
    return np.clip(out, 0.0, 1.0)

def to_binary(h, n):
    t = n // 2
    idx = np.argpartition(-h, t)[:t]
    b = np.zeros(n)
    b[idx] = 1.0
    return b

def smooth_max_val(h, n, alpha):
    dx = 2.0 / n
    c = get_corr(h, n) * dx
    cm = c.max()
    sh = alpha * (c - cm)
    sm = sh.max()
    e = np.exp(sh - sm)
    val = cm + (sm + np.log(e.sum())) / alpha
    pw = e / e.sum()
    return val, pw

def smooth_grad(h, n, pw):
    lags = np.arange(-(n - 1), n)
    j = np.arange(n)
    idx1 = j[:, None] + lags[None, :]
    v1 = (idx1 >= 0) & (idx1 < n)
    idx2 = j[:, None] - lags[None, :]
    v2 = (idx2 >= 0) & (idx2 < n)
    h1 = np.where(v1, h[np.clip(idx1, 0, n - 1)], 0.0)
    h2 = np.where(v2, h[np.clip(idx2, 0, n - 1)], 0.0)
    g1 = (pw[None, :] * (1.0 - h1) * v1).sum(axis=1)
    g2 = (pw[None, :] * h2 * v2).sum(axis=1)
    return g1 - g2

        t_s5 = max(5.0, p5_end - time.time() - 2)
        h_s5, c_s5 = sa_binary(best_h, best_n, time.time() + t_s5, seed=seed + 88888)
        if c_s5 < best_c:
            best_c = c_s5; best_h = h_s5
            if time.time() < p5_end - 1:
                h_g5b, c_g5b = greedy_ls(best_h, best_n, p5_end, rng_seed=seed + 77777)
                if c_g5b < best_c:
                    best_c = c_g5b; best_h = h_g5b

    # Ensure feasibility of final answer
    best_h = project_fit(best_h, best_n / 2.0)
    # Round if very close to binary
    if np.all((best_h < 0.01) | (best_h > 0.99)):
        best_h = to_binary(best_h, best_n)
    best_c = compute_c5(best_h, best_n)
    return best_h, best_c, best_n
```
