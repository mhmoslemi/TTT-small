But this is O(n) per swap. And we need to check if the new max is lower, which is another O(n). So each swap candidate is O(n). With O(n²) candidates, total is O(n³) per full search. For n=250, that's ~15.6M operations. In Python, that might take a few seconds per full sweep.

Actually, a much simpler approach: just use np.correlate to recompute after each accepted swap. np.correlate in numpy is implemented in C and is fast (O(n²) but with low constant). For n=250, it's 250*499 ≈ 125K multiply-adds, which takes microseconds.

So the strategy:
1. Pick a candidate swap (a, j)
2. Compute delta at the current worst lag k* (O(1))
3. If delta < 0, do the swap, recompute full correlation (O(n) in C via np.correlate), update max
4. If delta ≥ 0, reject

The O(1) check at k* is the key filter. The full recompute only happens when we accept.

For candidate selection: instead of trying all O(n²) pairs, use heuristics:
- For the worst lag k*, the "problem" is pairs (i, i+k*) where h[i]=0, h[i+k*]=1
- Moving h[i+k*] to 0 and h[i] to 1 fixes this specific pair
- But it might create problems at other lags
- So: try all "fixing" moves for the worst lag, pick the best one

Number of "fixing" moves for worst lag k* = number of i where h[i]=0 and h[i+k*]=1, which is exactly c_{k*} ≈ 47 for our case. So we only evaluate 47 candidates per step!

After doing one move, the worst lag might change, so we recompute.

This gives O(n) total per accepted move (47 candidates × O(1) check + 1 full recompute). Very fast!

def compute_c5(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1 - h, mode='full')
    return float(np.max(c) * dx)

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h, 0.0, 1.0)
    for _ in range(10000):
        diff = target - h.sum()
        if abs(diff) < 1e-13:
            break
        if diff > 0:
            room = 1.0 - h
            s = room.sum()
            if s < 1e-14:
                break
            h = h + diff / s * room
        else:
            s = h.sum()
            if s < 1e-14:
                break
            h = h + diff / s * h
    return np.clip(h, 0.0, 1.0)

def logsumexp_obj(x, n, alpha):
    dx = 2.0 / n
    c = np.correlate(x, 1 - x, mode='full') * dx
    m = c.max()
    shifted = alpha * (c - m)
    sm = shifted.max()
    return m + (sm + np.log(np.exp(shifted - sm).sum())) / alpha

def slsqp_smooth(h, n, alpha, maxiter, deadline):
    def obj(x):
        return logsumexp_obj(x, n, alpha)
    def con(x):
        return x.sum() - n / 2.0
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': con}]
    try:
        res = minimize(obj, h, method='SLSQP', bounds=bounds,
                       constraints=cons,
                       options={'maxiter': maxiter, 'ftol': 1e-15})
        return project_feasible(res.x, n)
    except Exception:
        return h
