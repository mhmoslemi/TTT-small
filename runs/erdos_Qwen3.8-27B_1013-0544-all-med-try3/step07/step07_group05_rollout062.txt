1. Start with h
2. If sum(h) > n/2: need to reduce. Reduce the largest values first (they have the most "room" to go down).
3. If sum(h) < n/2: need to increase. Increase the smallest values first.

This is a water-filling problem. The exact solution:
- Want to find τ such that sum(clip(h - τ, 0, 1)) = n/2 (for the case sum(h) > n/2)
- Or sum(clip(h + τ, 0, 1)) = n/2 (for the case sum(h) < n/2)

We can solve for τ via bisection since the function is monotonically decreasing in τ.

    # grad[j] = sum_k w[k] * (1-h[j-lags[k]])*[j-lags[k]>=0] - sum_k w[k] * h[j+lags[k]]*[j+lags[k]<n]

    # This is a convolution of (1-h) with w (flipped for positive lags)

The 1D optimization for a fixed pair (i,j):

- The max over k can be found in O(n log n) (sort the c values)
- Actually, the max as a function of d is the max of O(n) linear functions, which is convex
- We can minimize it using ternary search or golden section in O(n log n * log(1/ε))

Wait, c[k] as a function of d (where h[i] += d, h[j] -= d):

So c[k](d) is linear in d for each k! The max of linear functions is convex. We can minimize it with ternary search.

But computing all c[k](d) for a given d is O(n) (one correlation). So ternary search takes O(n * log(1/ε)) evaluations. For n=250, that's about 250 * 30 = 7500 operations per pair evaluation. With 1000 pairs per second, we can do maybe 100-300 pair evaluations per second.

    #     → contributes +d*h[j+m] for p = j

    # g[m] = (1-h[i-m])*[0<=i-m<n] - h[i+m]*[0<=i+m<n]
    #        - (1-h[j-m])*[0<=j-m<n] + h[j+m]*[0<=j+m<n]

    # max_m c_new[m] = max_m (c_old[m] + d*g[m])

    # → h[j]-1 <= d <= h[j]

    # term_i = (1-h[i-m])*[0<=i-m<n] - h[i+m]*[0<=i+m<n]
    # term_j = -(1-h[j-m])*[0<=j-m<n] + h[j+m]*[0<=j+m<n]

    term_i[valid_i1] = (1 - h[i - m_vals[valid_i1]])

    term_i[valid_i2] -= h[i + m_vals[valid_i2]]

    valid_j2 = (j + m_vals >= 0) & (j + m_vals < n)
    term_j[valid_j2] += h[j + m_vals[valid_j2]]

    # c_new[m] = c_old[m] + d * g[m]
    # Find d in [d_lo, d_hi] that minimizes max_m (c_old[m] + d*g[m])
    
    # Evaluate at a few points (golden section or just bisection on subgradient)
    # The function f(d) = max_m (c_old[m] + d*g[m]) is convex
    # f'(d) (right derivative) = g[m*] where m* = argmax
    # We want f'(d) ≈ 0, i.e., g[m*] ≈ 0 where m* = argmax
    
    # Ternary search
    a, b = d_lo, d_hi
    for _ in range(30):
        m1 = a + (b-a)/3
        m2 = b - (b-a)/3
        f1 = np.max(c_old + m1*g)
        f2 = np.max(c_old + m2*g)
        if f1 < f2:
            b = m2
        else:
            a = m1
    return (a+b)/2

import time

    c = np.correlate(h, 1-h, mode='full')
    return float(np.max(c) * dx)

    h = h.copy()

    idx1 = np.where(v1, P - L, 0)

        return (d_lo + d_hi) / 2
    a, b = d_lo, d_hi
    for _ in range(30):
        m1 = a + (b - a) / 3.0
        m2 = b - (b - a) / 3.0
        if np.max(c_old + m1 * g) < np.max(c_old + m2 * g):
            b = m2
        else:
            a = m1
    return (a + b) / 2

def lbfgs_smooth(h, n, alpha, penalty, maxiter=200):
    """One L-BFGS-B run with given alpha and penalty."""
    def fun_grad(x):
        dx_ = 2.0 / n
        c = np.correlate(x, 1-x, mode='full') * dx_
        c_max = c.max()
        c_sh = alpha * (c - c_max)
        c_sh -= c_sh.max()
        exp_c = np.exp(c_sh)
        w_sum = exp_c.sum()
        w = exp_c / w_sum
        f = (c_max * alpha + np.log(w_sum)) / alpha + penalty * (np.sum(x) - n/2)**2
        
        # Gradient
        n_full = 2*n - 1
        lags = np.arange(-(n-1), n)
        p = np.arange(n)
        P, L = np.meshgrid(p, lags, indexing='ij')
        
        grad = np.zeros(n)
        v1 = (P - L >= 0) & (P - L < n)
        mask1 = v1.astype(np.float64) * w[None, :]
        grad += mask1.sum(axis=1)
        idx1 = np.where(v1, P - L, 0)
        grad -= (mask1 * x[idx1]).sum(axis=1)
        
        v2 = (P + L >= 0) & (P + L < n)
        mask2 = v2.astype(np.float64) * w[None, :]
        idx2 = np.where(v2, P + L, 0)
        grad -= (mask2 * x[idx2]).sum(axis=1)
        
        grad += 2.0 * penalty * (np.sum(x) - n/2)
        return f, grad
    
    bounds = [(0.0, 1.0)] * n

                      bounds=bounds, options={'maxiter': maxiter, 'gtol': 1e-8})
        return project_exact(res.x, n)
    except Exception:
        return h.copy()
