- Resampling: Successively refine solutions to higher resolutions
- Optimization Rounds:

a. Projector:

```python
def project(h, n):
    target = n / 2.0
    h = h.copy()
    lo, hi = -2.0, 2.0
    for _ in range(100):
        mid = (lo + hi) / 2
        hp = np.clip(h - mid, 0.0, 1.0)
        if abs(hp.sum() - target) < 1e-6:
            break
        lo = mid if hp.sum() > target else hi
    h = np.clip(h - (lo + hi) / 2, 0.0, 1.0)
    return h
```
