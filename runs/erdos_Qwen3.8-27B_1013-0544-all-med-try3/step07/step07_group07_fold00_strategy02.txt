Genetic algorithms are population-based and can explore multiple regions of the solution space simultaneously. We start with a random population of binary step functions (which are easier to handle and represent) and evolve them over generations. We also introduce a local search step to refine solutions. Additionally, we will use a multi-resolution strategy: after finding good candidates at a lower resolution, we will refine them to higher resolutions by converting the binary step function to a continuous one and then further optimizing.

    # Evaluate fitness for all
    fitness_values = [fitness(ind) for ind in population]
    # Elitism: keep the best individual
    best_index = np.argmin(fitness_values)
    best_ind = population[best_index]
    best_fit = fitness_values[best_index]

    for gen in range(n_gen):
        # Select parents
        selected = []
        for _ in range(pop_size):
            # Tournament selection
            tournament_indices = rnd.choice(range(pop_size), size=3)
            tournament_fitness = [fitness_values[i] for i in tournament_indices]
            winner_index = tournament_indices[np.argmin(tournament_fitness)]
            selected.append(population[winner_index])

        # Crossover
        next_gen = []
        for i in range(0, pop_size, 2):
            par1, par2 = selected[i], selected[i+1]
            if rnd.random() < crossover_rate:
                # One-point crossover
                cx_point = rnd.randint(1, n-1)
                child1 = np.concatenate([par1[:cx_point], par2[cx_point:]])
                child2 = np.concatenate([par2[:cx_point], par1[cx_point:]])
                next_gen.append(child1)
                next_gen.append(child2)
            else:
                next_gen.append(par1)
                next_gen.append(par2)

        # Mutation
        for i in range(len(next_gen)):
            ind = next_gen[i]

            if rnd.random() < mutation_rate:
