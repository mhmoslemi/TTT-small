Actually, the precomputation of g in a Python loop will be slow. Let me vectorize:

```python
def precompute_g(h, n):
    """g[x, k] = (1-h[x+t]) - h[x-t] where t = k-(n-1)"""
    g = np.zeros((n, 2*n-1))
    for x in range(n):
        t = np.arange(-(n-1), n)  # shape (2n-1,)
        # x+t valid
        vp = (x + t >= 0) & (x + t < n)
        if vp.any():
            g[x, vp] += 1.0 - h[x + t[vp]]
        # x-t valid
        vm = (x - t >= 0) & (x - t < n)
        if vm.any():
            g[x, vm] -= h[x - t[vm]]
    return g
```
