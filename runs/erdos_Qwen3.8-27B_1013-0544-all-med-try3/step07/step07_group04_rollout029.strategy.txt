### 1. Approach and Rationale
We tackle the Erdős minimum overlap problem using a multi-resolution heuristic called **Adaptive Overlap Reduction (AOR)**. The core idea is to minimize the maximum overlap over all shifts by leveraging the following observation: the optimal function is necessarily piecewise constant with a few critical transitions. 

Key contributions of this strategy:
- **Resolution independence**: We systematically vary function resolution (discrete points) to escape local optima
- **Overlap-adaptive optimization**: We prioritize low-overlap regions during optimization
- **Gradient projection**: We use projected gradients to enforce integral constraints
- **Overlap-aware mutations**: Small perturbations focus on maximizing low-gap lags

The approach builds upon the provided solution by:
1. Using adaptive resolution exploration
2. Implementing an overlap-aware gradient projection
3. Employing a balance between annealing-based exploration and gradient descent refinement
4. Carefully managing execution time within the 1100-second budget

This strategy is designed to improve the current record of 0.38085 by better coordinating the search across different resolutions and function behaviors.

### 2. Mathematical Specification
Our goal is to find a step function $h:[0,2]\rightarrow[0,1]$ with $\int h(x)dx=1$ that minimizes:
$$
C_5 = \max_{k \in \mathbb{Z}} \int_0^2 h(x)(1-h(x+k))dx
$$

We represent $h$ as a function on $n$ discrete points spaced by $\Delta x = 2/n$. The discrete objective is computed via:
$$
C_5^{\text{disc}} = \frac{\max_k \sum_{i=0}^{n-1} h[i] \cdot (1-h[(i+k) \mod (2n)])}{n}
$$

Constraints are enforced by:
- $\sum_{i=0}^{n-1} h[i] = n/2$
- $0 \leq h[i] \leq 1$
