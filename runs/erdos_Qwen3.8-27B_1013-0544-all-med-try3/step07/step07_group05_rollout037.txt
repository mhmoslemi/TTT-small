```python
            # First part: (1-h[j-k]) * [0<=j-k<n]
            jp = j - k
            if 0 <= jp < n:
                s1 += w[i] * (1.0 - h[jp])
            # Second part: h[j] * [0<=j+k<n]
            jq = j + k
            if 0 <= jq < n:
                s2 += w[i] * h[j]  # h[j] is constant, so = h[j] * sum of w[i] for valid i
        grad[j] = dx * (s1 - s2)
    return grad
```
