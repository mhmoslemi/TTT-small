  - If i+m < n: c(-m) changes by 0 - h[i+m] = -h[i+m] (h[i'-m]=h[i] goes from 0 to 1)

Similarly for changing h[j] from 1 to 0:
- For k >= 0 where j+k < n: c(k) changes by 0 - (1-h[j+k]) = -(1-h[j+k])
- For k = -m where m > 0:
  - If j >= m: c(-m) changes by 0 - (1-h[j-m]) = -(1-h[j-m])
  - If j+m < n: c(-m) changes by h[j+m] - 0 = h[j+m]

So the total change in c(k) for all k is:
Δc(k) = [contribution from i going 0→1] + [contribution from j going 1→0]

This can be computed in O(n) for all k simultaneously. So the total cost per SA step is O(n) for the update + O(1) for the acceptance check (just need to find max of c).

            tot = room.sum()

        else:

            if tot < 1e-15:

    """Binary simulated annealing with swap moves."""
    if init is not None:
        h = np.zeros(n)
        # Round init to binary, keeping track of which are closer to 1
        sorted_idx = np.argsort(-init)
        h[sorted_idx[:n//2]] = 1.0
    else:

        ones = rng.choice(n, n//2, replace=False)
        h[ones] = 1.0
    
    best_c = compute_c5(h, n)
    best_h = h.copy()
    current_c = best_c
    
    t = t_init
    min_t = 1e-10
    n_evals = 0
    
    while time.time() < deadline and t > min_t:
        # Pick random i, j to swap
        i = rng.randint(n)
        j = rng.randint(n)
        if i == j:
            continue
        if h[i] == h[j]:
            continue
        
        h[i], h[j] = h[j], h[i]
        new_c = compute_c5(h, n)

            if new_c < best_c:
                best_c = new_c
                best_h = h.copy()
        else:
            h[i], h[j] = h[j], h[i]
        
        t *= cooling
    
    return best_h, best_c

    target = n / 2.0
    h = np.clip(h.copy(), 0.0, 1.0)
    for _ in range(500):
        diff = target - h.sum()
        if abs(diff) < 1e-15:
            break

            room = 1.0 - h

            if tot < 1e-15:
                break
            h += (diff / tot) * room
        else:
            tot = h.sum()
            if tot < 1e-15:
                break
            h += (diff / tot) * h

    m = c.max()
