Let me reconsider. In the fine search, after changing h[i] by δ, the sum changes by δ. The projection needs to subtract δ/n from all other elements (approximately). If δ is very small (like 1e-5), then δ/n = 4e-8, which won't push any element out of [0,1] unless it's already very close to 0 or 1.

1. Change h[i] by δ.
2. Add -δ/n to all other elements (or distribute among non-boundary elements).
3. Clip to [0,1].

This is O(n) and very fast.

        return np.ones(n)

        c = np.correlate(x, 1 - x, mode='full') * dx
        m = c.max()
        shifted = alpha * (c - m)
        mx = shifted.max()
        if mx > 300:
            return float(m + (mx + np.log(np.sum(np.exp(shifted - mx)))) / alpha)
        return float(m + np.log(np.sum(np.exp(shifted))) / alpha)

                       bounds=bounds, constraints=cons,
                       options={'maxiter': 10000, 'ftol': 1e-18})
