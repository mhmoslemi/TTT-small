1. Approach and rationale

We adopt a hybrid optimization approach combining local search with perturbation techniques to minimize the AC1 upper bound. Our method starts with the provided parent sequence and applies two types of perturbations: block perturbations (affecting contiguous portions of the sequence) and point perturbations (affecting individual elements). Each candidate is evaluated using the exact `evaluate_sequence` function which performs full convolution. 

The key idea is to balance exploration (block perturbations) and exploitation (point perturbations) of the search space. Our method leverages the scale invariance of the AC1 objective (both numerator and denominator scale quadratically with the scaling factor) by focusing on relative improvements rather than absolute changes. We define a fallback mechanism that ensures we always return a nonnegative sequence within the bounds [0, 1000].

The search process runs for a fixed number of steps (1000) to find a high-quality solution without excessive computational time. The algorithm tolerance (0.6) guides our balance between aggressive and conservative search steps, though this should be further tested in production.

    AC1(a) = 2*n*max(convolve(a, a)) / (sum(a))²

2) Upper bound: `a_i ≤ 1000` for all `i`
3) Minimum sum: `sum(a) ≥ 0.01`

The search uses:
- Block perturbations: Modify a contiguous subsequence of random length (between 8 and 50) by introducing random values.

- Fallback: Uniform random initialization if initial evaluation fails.
