The LP maximizes the sum of the new sequence under the constraint that its convolution with the current sequence does not exceed the current maximum autocorrelation bound. This leverages the fact that optimizing the convolution bound improves the AC1 metric. The use of an LP ensures theoretical guarantees while maintaining sparse representation to avoid quadratic memory costs. The iterative update approach allows for progressive refinement, and fallback mechanisms handle numerical instability or solver failures. This method addresses the bottlenecks of brute-force search and dense convolution matrix generation.

```python
def block_perturbation(f, rng):
    n = len(f)
    width = int(rng.integers(max(1, n//200), max(2, n//12)))
    start = rng.integers(0, n - width)
    stop = start + width
    f[start:stop] *= np.exp(rng.normal(0.0, 0.12))
    if rng.random() < 0.35:
        f = 0.5 * (f + f[::-1])
    return np.clip(f, 0, 1000)
```
