To address the problem of minimizing the AC1 upper bound by finding a suitable sequence of coefficients, we employ a stochastic local search strategy that combines block and point perturbations to explore the solution space efficiently. The approach involves initializing with a given sequence, then iteratively perturbing candidates to improve the objective function until a stopping criterion is met.

### Approach and Rationale
The AC1 objective is scale-invariant, meaning the optimal sequence can be scaled without affecting the value. Block perturbations explore larger regions by modifying contiguous segments, while point perturbations focus on smaller changes. This combination balances exploration and exploitation. The perturbation width is adaptively sized relative to the sequence length, and factors are drawn from a uniform distribution to encourage valid proposals.

### Mathematical Specification
- **Variables**: A sequence of nonnegative real numbers with components clamped in [0, 1000].
- **Objective**: Minimize AC1 = \( \frac{2n \max(\text{convolve}(a, a, \text{mode}='full'))}{(\sum a)^2} \).
- **Constraints**: 
  - Nonnegative coefficients with \( \sum a \geq 0.01 \) after clipping.
  - Individual coefficients \( [0, 1000] \).

### Core Update Procedure
1. **Initialization**: Start with the given sequence or a fallback ones array to meet sum constraints.
2. **Perturbation Cycles**: For each iteration:
   - **Block Perturbation (50% chance)**:
     - Select a random contiguous block size (1-5% of the sequence length).
     - Apply a random multiplicative factor (0.5-1.5).
     - Clip coefficients to [0, 1000].
   - **Point Perturbation (50% chance)**:
     - Modify 3 random coefficients with factors (0.5-1.5).
     - Clip coefficients to [0, 1000].
3. **Early Termination**: Stop if no improvement is detected for 500 steps.
4. **Objective Handling**: Only valid candidates (nonnegative sum >= 0.01) are evaluated.

### Search Choices and Variations
- **Normalization**: Candidates are normalized by value for balance.
- **Improvement Tracking**: The best candidate is retained and re-evaluated periodically.
- **Fallback**: If evaluations suggest instability, restart from the current best candidate.

### Compute Budget and Robustness
- **Time Complexity**: Up to \( O(10^4 \cdot n) \) for 4498-length sequences, approximate due to FFT-based convolutions.
- **Early Exit**: Stops if no improvement is detected for 500 consecutive steps.
