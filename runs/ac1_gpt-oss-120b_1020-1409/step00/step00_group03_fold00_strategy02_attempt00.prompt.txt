```python
def evaluate_sequence(sequence: list) -> float:
    """
    Evaluates a sequence of coefficients with enhanced security checks.
    Returns np.inf if the input is invalid.
    """
    if not isinstance(sequence, list):
        return np.inf
    if not sequence:
        return np.inf
    for x in sequence:
        if isinstance(x, bool) or not isinstance(x, (int, float)):
            return np.inf
        if np.isnan(x) or np.isinf(x):
            return np.inf
    sequence = [float(x) for x in sequence]
    sequence = [max(0, x) for x in sequence]
    sequence = [min(1000.0, x) for x in sequence]
    n = len(sequence)
    b_sequence = np.convolve(sequence, sequence)
    max_b = max(b_sequence)
    sum_a = np.sum(sequence)
    if sum_a < 0.01:
        return np.inf
    return float(2 * n * max_b / (sum_a**2))
```

1. **Approach and Rationale**  
The central idea is to minimize the AC1 upper bound by iteratively updating the sequence through linear programming (LP) optimization. The LP maximizes the sum of the new sequence under the constraint that its convolution with the current sequence does not exceed the current maximum autocorrelation bound. This leverages the fact that optimizing the convolution bound improves the AC1 metric. The use of an LP ensures theoretical guarantees while maintaining sparse representation to avoid quadratic memory costs. The iterative update approach allows for progressive refinement, and fallback mechanisms handle numerical instability or solver failures. This method addresses the bottlenecks of brute-force search and dense convolution matrix generation.

2. **Mathematical Specification**  
The objective is to minimize the AC1 value:  
\[
\text{AC1}(a) = \frac{2 \cdot n \cdot \max(\text{convolve}(a, a))}{(\sum a_j)^2}
\]  
subject to:  
- \( a_j \geq 0 \) for all \( j \)  
- \( \sum a_j \geq 0.01 \)  
- \( \max_k (\text{convolve}(a, a)[k]) \leq M \)  

The LP formulation for a given sequence \( f \):  
- Variables \( x = \{x_j\}_{j=1}^n \) (non-negative)  
- Maximize convex objective: \( \sum_{j=1}^n x_j \)  
- Constraints:  
  \[
  \sum_{i=1}^n f[i] \cdot x_{k-i} \leq M \quad \forall k = 0 \text{ to } 2n-2
  \]  
  (with \( x_i = 0 \) for out-of-bounds indices)  
- Solution \( g = \text{normalized } x \) (scaled to energy level \( \sqrt{2n} \))  
- Update rule: \( \text{candidate} = \alpha f + (1-\alpha) g \) with \( \alpha = 0.9 \)

```python
def solve_lp(f):
    n = len(f)
    M_val = np.convolve(f, f, mode='full').max()
    x = cp.Variable(n, nonneg=True)
    obj = cp.Maximize(cp.sum(x))
    constraints = []
    for k in range(2*n-1):
        s_expr = 0
        for i in range(n):
            idx = k - i
            if 0 <= idx < n:
                s_expr += f[i] * x[idx]
        constraints.append(s_expr <= M_val)
    prob = cp.Problem(obj, constraints)
    res = prob.solve(cp.ECOS, time_limit=5)
    return res, x.value
```
