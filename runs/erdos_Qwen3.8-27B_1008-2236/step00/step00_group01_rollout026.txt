For the coordinate descent, the key insight is:
- For fixed h[-i], out[k] is linear in h[i]: out[k] = a_k + s_k * h[i]
- We want to find h[i] in [0,1] that minimizes max_k (a_k + s_k * h[i])
- This is a 1D problem solvable in O(n log n)

The optimal h[i] is the point where the "ceilings" of the lines a_k + s_k*h have their minimum maximum. This is the point where the top 2 (or more) lines intersect at the same height, balanced.

Efficient solution:
1. For h=0: max_f = max_k a_k
2. For h=1: max_f = max_k (a_k + s_k)
3. The function g(h) = max_k(a_k + s_k*h) is piecewise linear and convex (max of linear functions)
4. Its minimum is where the subgradient contains 0, i.e., where some lines with positive slope and some with negative slope are all achieving the max simultaneously.

Algorithm:
- Sort lines by slope
- Use a convex hull / upper envelope approach
- Or simply: binary search on h, at each step compute g(h) and its subgradient

def smooth_max_obj(h, beta):
    out = np.correlate(h, 1.0 - h, mode='full')
    m = np.max(out)
    return m + np.log(np.sum(np.exp(beta * (out - m)))) / beta

feasible(h, n):

            room = 1.0 - h
            tr = room.sum()
            if tr < 1e-13:
                break
            h = h + diff * room / tr
        else:
            room = h.copy()
            tr = room.sum()
            if tr < 1e-13:
