    # For shift s = k-(n-1), d(corr_k)/d(h[i]) = dx * [(1-h[i+s])1_{valid} - h[i-s]1_{valid}]

        s_vals = np.arange(2*n-1) - (n-1)  # shift values

        valid1 = (i + s_vals >= 0) & (i + s_vals < n)
        valid2 = (i - s_vals >= 0) & (i - s_vals < n)
        term1 = np.sum(w[valid1] * (1 - h[i + s_vals[valid1]]))
        term2 = np.sum(w[valid2] * h[i - s_vals[valid2]])
        grad[i] = dx * (term1 - term2)
    
    return smooth_max, grad

For s=0: m=i=m+s, so both conditions give the same term. d/dh[i] of h[i]*(1-h[i]) = 1-2h[i].

For s≠
0: d(corr_s)/d(h[i]) = (1-h[i+s])*dx (if 0≤i+s<n) + (-h[i-s])*dx (if 0≤i-s<n)

Now, the total gradient:
grad[i] = sum_s d(corr_s)/d(h[i]) * w_s (where w_s are the softmax weights)
= dx * [sum_{s: i+s valid, s≠0} (1-h[i+s])*w_{s+n-1} + sum_{s: i-s valid, s≠0} (-h[i-s])*w_{s+n-1} + (1-2h[i])*w_{n-1}]
