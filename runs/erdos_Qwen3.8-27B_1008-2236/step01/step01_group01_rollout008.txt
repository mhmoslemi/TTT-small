For np.correlate(h, 1-h, mode="full"):
- Output has 2n-1 elements
- Element k (0-indexed) corresponds to shift s = k - (n-1)
- c[k] = Σ_{i: 0≤i<n, 0≤i-s<n} h[i] * (1-h[i-s])

When h[i] goes 1→0 and h[j] goes 0→1:
Δc[k] = -(1-h[i-s]) * [0≤i-s<n] - h[i+s] * [0≤i+s<n] + (1-h[j-s]) * [0≤j-s<n] - h[j+s] * [0≤j+s<n]

Let me verify: 
- Original contribution of h[i]=1 to c[k]: h[i]*(1-h[i-s]) = 1*(1-h[i-s]) if i-s valid, else 0
- Also, h[i] appears in (1-h[i'-s]) when i'-s = i, i.e., i' = i+s: contribution h[i+s]*1 = h[i+s] (if i+s valid)
- After h[i]=0: both contributions become 0
- So removal: -(1-h[i-s])*[i-s valid] - h[i+s]*[i+s valid]

- Original contribution of h[j]=0 to c[k]: 0 (h[j]=0)
- h[j] in (1-h[j'-s]) when j'-s = j, i.e., j' = j+s: contribution h[j+s]*(1-h[j]) = h[j+s]*1 = h[j+s] (if j+s valid)
- After h[j]=1: h[j]*(1-h[j-s]) = 1*(1-h[j-s]) if j-s valid; and h[j+s]*(1-h[j]) = h[j+s]*0 = 0
- So addition: (1-h[j-s])*[j-s valid] - h[j+s]*[j+s valid]

Total Δc[k] = -(1-h[i-s])*[i-s valid] - h[i+s]*[i+s valid] + (1-h[j-s])*[j-s valid] - h[j+s]*[j+s valid]

Let me define for position p and shift s:
- L(p, s) = 1-h[p-s] if 0≤p-s<n, else 0  (left neighbor in the shift)
- R(p, s) = h[p+s] if 0≤p+s<n, else 0  (right neighbor)

Then Δc[k] = -L(i, s_k) - R(i, s_k) + L(j, s_k) - R(j, s_k)

Where s_k = k - (n-1).

I can precompute L and R as n × (2n-1) matrices:
L[p, k] = 1-h[p-s_k] if valid, else 0
R[p, k] = h[p+s_k] if valid, else 0

Then for swap (i, j): Δc = -L[i] - R[i] + L[j] - R[j]

And new_c = c + Δc, new_max = new_c.max()

This is O(n) to compute Δc (vector addition) and O(n) to compute new_max. Per swap: O(n).
All swaps per pass: O(n²) * O(n) = O(n³). For n=45: ~91,000. Fast!

But I can do even better: precompute D[p, k] = L[p,k] - R[p,k] (the "net contribution" of position p at lag k when it's a 1).
Then Δc for swap (i→0, j→1) = -D[i] + (L[j] - R[j]) 

Wait, that's not quite right. Let me redo:
- Removing h[i]=1: Δ = -L[i] - R[i]
- Adding h[j]=1: Δ = +L[j] - R[j]

So Δc = -L[i] - R[i] + L[j] - R[j] = (L[j] - R[j]) - (L[i] + R[i])

Let me define:
- RemoveCost[p, k] = L[p,k] + R[p,k] (cost of removing a 1 at position p)
- AddCost[p, k] = L[p,k] - R[p,k] (change from adding a 1 at position p)

Δc = AddCost[j] - RemoveCost[i]

For the swap to be improving: max(c + AddCost[j] - RemoveCost[i]) < c_max

I can precompute these matrices (n × (2n-1)) and then for each pair (i,j):
new_max = max(c + AddCost[j] - RemoveCost[i])

This is O(2n) per pair. Total per pass: O(n² * n) = O(n³). For n=45: fast.

Even better: I can find the best swap by:
For each j (position to set to 1), define V_j[k] = c[k] + AddCost[j][k]
Then for each i (position to set to 0), check max(V_j - RemoveCost[i]) < c_max

Or: for each pair, new_max = max(V_j - RemoveCost[i])

To find the best (minimizing new_max), I can:
For each j, for each i: new_max(i,j) = max_k (V_j[k] - RemoveCost[i][k])

This is a min-max problem. For n=45, brute force is fine.

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    c = np.correlate(h, 1.0 - h, mode="full") * dx
    return float(c.max())

def project_feasible(h):
    n = len(h)
    target = n / 2.0
    h = np.clip(h, 0.0, 1.0)
    diff = target - h.sum()
    h += diff / n
    h = np.clip(h, 0.0, 1.0)
    diff = target - h.sum()
    if abs(diff) > 1e-12:
        idx = np.argsort(h) if diff < 0 else np.argsort(1.0 - h)
        for i in idx:
            adj = min(abs(diff), 1.0 - h[i]) if diff > 0 else min(abs(diff), h[i])
            h[i] += adj if diff > 0 else -adj
            diff = target - h.sum()
            if abs(diff) < 1e-12:
                break
    return h

def make_initial(n):
    h = np.zeros(n)
    h[0::2] = 1.0
    if n % 2 == 1:
        h[n // 2] = 0.5
    return project_feasible(h)

def lse_gradient(h, lam=80.0):
    n = len(h)
    dx = 2.0 / n
    c = np.correlate(h, 1.0 - h, mode="full") * dx
    cs = lam * c
    cs -= cs.max()
    w = np.exp(cs)
    w /= w.sum()
    grad = np.zeros(n)
    for k in range(2 * n - 1):
        if w[k] < 1e-10:
            continue
        s = k - (n - 1)
        jm1 = max(0, s)
        jm2 = min(n, n + s)
        if jm1 < jm2:
            idx = np.arange(jm1, jm2)
            grad[idx] += w[k] * (1.0 - h[idx - s])
        jm1b = max(0, -s)
        jm2b = min(n, n - s)
        if jm1b < jm2b:
            idx2 = np.arange(jm1b, jm2b)
            grad[idx2] -= w[k] * h[idx2 + s]
    return grad * dx, c.max()

def lse_optimize(h, tl=10.0, lam=80.0):
    n = len(h)
    h = project_feasible(h.copy())
    c0 = compute_c5(h)
    best_h, best_c = h.copy(), c0
    t0 = time.time()
    alpha = 0.05
    for alpha in [0.05, 0.03, 0.02, 0.01, 0.005, 0.003, 0.002, 0.001]:
        for _ in range(300):
            if time.time() - t0 > tl:
                return best_h, best_c
            g, _ = lse_gradient(h, lam)
            h_new = project_feasible(h - alpha * g)
            cv = compute_c5(h_new)
            if cv < compute_c5(h) - 1e-12:
                h = h_new
                if cv < best_c:
                    best_h, best_c = h.copy(), cv
            else:
                break
    return best_h, best_c

def binary_local_search(h, max_passes=200):
    n = len(h)
    hb = np.where(h >= 0.5, 1.0, 0.0).copy()
    target = n / 2
    if hb.sum() < target:
        need = int(target - hb.sum())
        order = np.argsort(h)[::-1]
        for i in range(need):
            hb[order[i]] = 1.0
    elif hb.sum() > target:
        excess = int(hb.sum() - target)
        order = np.argsort(h)
        for i in range(excess):
            hb[order[i]] = 0.0
    dx = 2.0 / n
    c = np.correlate(hb, 1.0 - hb, mode="full")
    cmax = c.max()
    ones = set(np.where(hb > 0.5)[0].tolist())
    zeros = set(np.where(hb < 0.5)[0].tolist())
    for _ in range(max_passes):
        improved = False
        for i in sorted(ones):
            for j in sorted(zeros):
                if i == j:
                    continue
                s_all = np.arange(-(n - 1), n)
                Li = np.where((i - s_all >= 0) & (i - s_all < n), 1.0 - 0.0, 0.0)
                Ri = np.where((i + s_all >= 0) & (i + s_all < n), 0.0, 0.0)
                Lj = np.where((j - s_all >= 0) & (j - s_all < n), 1.0, 0.0)
                Rj = np.where((j + s_all >= 0) & (j + s_all < n), 1.0, 0.0)
                idx_i = np.where((i - s_all >= 0) & (i - s_all < n))[0]

def slsqp_refine(h0, maxiter=600):

    def sfun(x):
        return float(x.sum() - 0.5 * len(x))

        return np.ones(len(x))
    def c5obj(x):
        dx = 2.0 / len(x)
        c = np.correlate(x, 1.0 - x, mode="full") * dx
        return float(c.max())
    bounds = [(0, 1)] * n
    cons = [{'type': 'eq', 'fun': sfun, 'jac': sjac}]
    try:
        r = minimize(c5obj, h0, method='SLSQP', bounds=bounds,
                     constraints=cons, options={'maxiter': maxiter, 'ftol': 1e-14})
        return project_feasible(r.x), compute_c5(project_feasible(r.x))
    except:
        return h0, compute_c5(h0)

            hp = project_feasible(best_h + rng.normal(0, s, best_n))
            hs, cs = slsqp_refine(hp, 400)
            if cs < best_c5:
                best_h, best_c5 = hs, cs
                best_n = len(hs)
                hb, cb = fast_binary_ls(best_h, 100)
                if cb < best_c5:
                    best_h, best_c5 = hb, cb

    # Final polish
    if time.time() - ts < budget_s - 5:
        hs, cs = slsqp_refine(best_h, 500)
        if cs < best_c5:
            best_h, best_c5 = hs, cs

    best_h = project_feasible(best_h)
    final_c5 = compute_c5(best_h)
    return best_h, min(final_c5, best_c5), len(best_h)
