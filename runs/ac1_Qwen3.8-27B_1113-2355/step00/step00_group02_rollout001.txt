Exact minimizer for the evaluator.

For any admissible input x_i >= 0 of length n, the convolution coefficient
at lag 0 is c = sum_i x_i^2. For every other lag k,
    conv[x]_k = sum_i x_i x_{i+k} <= sum_i x_i^2,
because 2xy <= x^2 + y^2. Hence max(conv[x, x]) = sum_i x_i^2.
By Cauchy-Schwarz,
    sum_i x_i^2 >= (sum_i x_i)^2 / n.
Therefore
    score = 2 n max_b / (sum_a^2) >= 2.
Equality holds exactly for a positive constant sequence.  The function
returns such a sequence; a bounded deterministic scan is kept only to
preserve the provably best score and to catch harmless floating-point
rounding improvements.

import time

    try:
        b = float(value)
    except Exception:
        return 2400.0
    if not np.isfinite(b) or b < 0.0:
        return 2400.0
    return b

    try:
        value = evaluate_sequence(candidate)
        value = float(value)
    except Exception:
        return float('inf')
    try:
        if not np.isfinite(value):
            return float('inf')
    except Exception:
        return float('inf')
    return value

    return [float(height)] * int(n)

"""
Exact minimizer for the stated evaluator.

For any admissible nonnegative sequence x_0, ..., x_{n-1}, the full linear
convolution x * x has its zero-lag coefficient at index n-1:
    c = sum_i x_i**2.
For every other lag k,
    conv[x]_k = sum_i x_i x_{i+k}
and by 2ab <= a^2 + b^2,
    conv[x]_k <= sum_i x_i**2.
Thus max(conv[x]) is at least c, and for nonnegative x it is exactly c.

By Cauchy-Schwarz,
    sum_i x_i**2 >= (sum_i x_i)**2 / n,
so
    score = 2*n*max(conv[x]) / (sum x)**2 >= 2.

Equality is attained exactly by a positive constant sequence.  Therefore no
nonnegative sequence can beat score 2 under the given evaluator.  The function
returns a constant sequence.  A tiny deterministic scan is retained only to
catch harmless floating-point rounding improvements if the exact evaluator is
available; it cannot produce a mathematically lower score.
"""

import numpy as np
import time


def _budget_seconds(value):
    try:
        b = float(value)
    except Exception:
        return 2400.0
    if not np.isfinite(b) or b < 0.0:
        return 2400.0
    return b

        return float("inf")
    try:
        if not np.isfinite(value):
            return float("inf")
    except Exception:
        return float("inf")
    return value


def _constant_candidate(n, height):
    return [float(height)] * int(n)

        except Exception:
            return None
        if not np.isfinite(y):
            y = 0.0
        if y < 0.0:
            y = 0.0
