        >= 2*n*sum(a_i^2) / (sum a)^2
        >= 2,

by Cauchy-Schwarz. Equality is achieved exactly when all a_i are equal
and positive. Hence the global minimizer is any positive constant
sequence. This function returns such a sequence, choosing a length
compatible with the provided hint when possible and bounded for fast
evaluation.
"""


def choose_constant_length(upper_length=6962):
    """
    Return a positive integer length for the constant sequence.

    The global hint ``height_sequence_1`` is used only to pick a sensible
    length; the value is capped to keep downstream evaluation fast.
    """
    length = int(upper_length)
    hinted_length = globals().get("height_sequence_1")

    if hinted_length is not None:
        try:
            m = len(hinted_length)
            if m > 0:
                length = int(m)
        except Exception:
            pass

    if length < 1:
        length = 1
    if length > int(upper_length):
        length = int(upper_length)

    return length
