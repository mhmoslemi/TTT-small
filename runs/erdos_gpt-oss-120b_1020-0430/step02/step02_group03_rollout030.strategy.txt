    ```
        h_c = np.clip(h, 0, 1)
        diff = target - np.sum(h_c)
        if abs(diff) < 1e-3:
            return h_c
        i = rng.integers(0, len(h_c))
        for _ in range(max_iters):
            # Adjust h_c[i] within [0,1] to correct sum
            max_add = min(1 - h_c[i], diff) if diff >= 0 else -h_c[i]
            min_add = max(-h_c[i], diff) if diff <= 0 else 1
            add = rng.uniform(min_add, max_add) if max_add > min_add else 0
            h_c[i] += add
            diff -= add
            if abs(diff) < 1e-3:
                break
        return np.clip(h_c, 0, 1)
    ```

        `res = minimize(smooth_obj, x0=h, method="SLSQP", bounds=bounds, constraints=cons)`
        `final_h = res.x`

  2. **Post-Processing**:
        `final_h = repair(final_h, target_sum)`
        `computed_c5 = compute_c5(final_h)`

##### Step d. Repair & Acceptance Criteria:
    After each new candidate:
    - If `smooth_obj` improves AND `computed_c5 < current_best`, accept the candidate.
    - Else, revert if not improving.

##### Step e. Scaling & Final Export:
    Ensure `final_h` is repair intact, and convert to list.
