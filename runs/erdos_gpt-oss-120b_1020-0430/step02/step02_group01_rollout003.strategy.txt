- In discrete form: max₋₌₋₍ₙ₋₁₎¹⁾ (2/n) * ∑h[i](1-h[i+k])dx

**Constraints**:
- 0 ≤ h[i] ≤ 1 for all i
- ∑h[i] = n/2
- Grid points are constrained to [0,2]

**Surrogate Function**:
- Softmax normalization: objβ(h) = (1/β) * [maxₖcₖ + log(∑ₖexp(β(cₖ - maxₖcₖ)))]
- cₖ is the correlation at lag k
- β parameter (5-200) controls approximation accuracy

        except:
            # Fallback to coordinate-wise update
            x_new = coordinate_update(x, target, nu)
        
        try:
            c_new = compute_c5(x_new)
            if c_new < best_c:
                best_x = x_new
                best_c = c_new

            pass
        
        # Repair if needed
        if abs(target - np.sum(x_new)) > 1e-12:
            repair_indices(x_new, target)

    return {"x": best_x, "best_c": best_c}
