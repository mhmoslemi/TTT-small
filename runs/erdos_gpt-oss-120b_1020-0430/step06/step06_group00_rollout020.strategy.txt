### Approach and Rationale
The current implementation uses local optimization techniques (gradient-based and simulated annealing) which often get stuck in local optima, especially in high dimensions (n=512). The goal is to use a global optimization method, namely multi-objective genetic algorithms (NSGA-II) combined with local search, to escape local optima and find better solutions. The key idea is to have a population-based method that explores a wide range of solutions and then refines them locally. We will use a multi-resolution approach: start from a coarse grid (e.g., 128 points), then go to medium (256) and fine (512) grids. At each grid, we perform genetic algorithm (GA) steps (selection, crossover, mutation) and repair constraints by adjusting the function to maintain the integral constraint. Then, we apply local search (gradient-based refinement) to polish the solution. The objective is to minimize the maximum overlap integral (C5). Since the problem is non-convex and highly multimodal, a global method is necessary to improve on the current local optimum.

### Mathematical Specification
**Representation**: A real-valued vector `h` of length `n_points` (resolution) where `0 <= h[i] <= 1` for all `i` and `sum(h) = n_points / 2`.

**Objective**: Minimize `C5 = max_k integral h(x) * (1-h(x+k)) dx`, discretized as `max(np.correlate(h, 1-h, mode='full')) * (2.0 / n_points)`.

**Constraints**:
- `0 <= h[i] <= 1` for all `i`
- `sum(h) = n_points / 2`

   def repair_vector(v, target_sum, max_attempts=10000):
       # Clip to [0,1]
       v = np.clip(v, 0, 1)
       # Redistribution
       current_sum = np.sum(v)
       if abs(current_sum - target_sum) < 1e-10:
           return v, current_sum
       target_sum = min(target_sum, len(v))
       target_sum = max(target_sum, 0)
       diff = target_sum - current_sum
       attempts = 0
       while abs(diff) > 1e-5 and attempts < max_attempts:
           idx = np.random.randint(0, len(v))
           # Adjust one element
           if diff > 0: # Need to add
               if v[idx] < 1 - 1e-10: # Allow adding until 1
                   available = 1 - v[idx]
                   add_amount = np.random.random() * min(available, diff)
                   v[idx] += add_amount
               diff -= add_amount
           else: # Need to remove
               if v[idx] > 0:
                   remove_amount = np.random.random() * min(v[idx], -diff)
                   v[idx] -= remove_amount
               diff += remove_amount
           current_sum = np.sum(v)
           diff = target_sum - current_sum
           attempts += 1
       return v, current_sum
   ```

   def gradient_refine(h, rng, step=0.015, max_iter=15, target_sum=None):
       h_old = h.copy()
       n_points = h.size
       if target_sum is None:
           target_sum = n_points/2.0
       for it in range(max_iter):
           # Compute worst shift gradient
           corr = np.correlate(h, 1.0 - h, mode='full')
           idx = np.argmax(corr) - (n_points - 1)
           k = abs(idx)
           grad = np.zeros_like(h)
           if k == 0:
               grad[:] = 1.0 - 2.0 * h
           else:
               grad[:n_points-k] = 1.0 - h[k:]
               grad[k:] = -h[:n_points-k]
           # Adjust step direction
           sign = -1.0 if corr[idx] > 0 else 1.0
           h = h + step * sign * grad
           # Clip and repair
           h = np.clip(h, 0, 1)
           h_repaired, _ = repair_vector(h, target_sum)
           h = h_repaired
       return h
   ```
