GA handles the global exploration while gradient-based methods handle local exploitation. The approach addresses the non-convex nature of the problem and the challenge of efficiently evaluating the objective function.

Mathematical specification:
We represent h as a real-valued vector where each element 0 ≤ h[i] ≤ 1.0 and the sum of h equals exactly n_points/2. The objective is to minimize the maximum cross-correlation between h and (1-h), scaled by (2/n_points). The GA will search the space [0,1]^{n_points} subject to the equality constraint. Repair mechanisms are used to maintain feasibility.

Implementation procedure:
The algorithm consists of these stages:
1. Start with provided initial solution if available
2. Multi-phase multi-resolution GA:
   - Phase 1: Binary search space (lower computational cost)
   - Phase 2: Real-valued search space (higher precision)
3. Local optimization with gradient-based refinement and continuous SA
4. Upsampling to finer resolutions
5. Final repair and verification

For GA implementation:
- Population size: 40
- Crossover: Single-point
- Mutation: Cauchy-sampled with limiting factor
- Selection: Tournament (size=3)
- Constraint repair: Enforce sum while maintaining bounds
- Objective: Negative cross-correlation maxima

For local optimization, reuse the existing gradient_refine and continuous_SA implementations.

Search choices and variations:
- GA variant: (1) Binary, (2) Real-valued
- Crossover variant: (1) Single-point, (2) Polynomial
- Mutation variant: (1) Cauchy, (2) Gaussian
- Temperature schedule for SA: Fast cooling initial, slow final approach

Computebudget and robustness:
- Initial Call: Real-valued GA on 128-points with 300s
- Binary GA: 256-points with 200s
- Local refinement: 512-points with gradient SA
- Final refinement: 1024-points (if time permits)
- Time monitoring between phases
- Fallback preparation after each GA phase
- Constraint handling by random repair if violated

Validation and return contract:

2. Check sum is exact n_points/2
