### 1. Approach and rationale
We address the Erdős minimum overlap problem by optimizing a step function h(x) over a unit interval [0,2] with integral 1. The core challenge is minimizing the maximum overlap with its shifted version. The current solution (C=0.38087) uses a gradient-free optimizer with fine-tuning, but may be trapped in local optima.

Our approach leverages the observation that optimal solutions often exhibit symmetry (even coverage). By enforcing this constraint and optimizing at multiple resolutions (360, 720, etc.), we aim to escape local optima. Key improvements include:
- Symmetric representation: Reduce dimensionality by reflecting function values
- Resolution doubling: Successive optimization refines solutions
- Population-based: Uses multiple initial samples to avoid premature convergence

### 2. Mathematical specification
**Variables**: h ∈ [0,1]ⁿ (step function values), n even
**Objective**: min maxₖ ∫₀² h(x)(1-h(x+k))dx (overlap integral)
**Constraints**: ∑h = n/2 (integral condition); 0 ≤ h_i ≤ 1

**Symmetric representation**:
- Consider h for x∈[0,1] (first n/2 samples)
- Reflect to get [1,2]: h_left[::-1]
- Total integral = 2 ∑_{first n/2} values = n/2 → ∑_{first n/2} = n/4

**Optimization formulation**:
SLSQP solves:
min - ∑_k w_k log(∫h(x)(1-h(x+k))dx)
subject to ∑h = n/2, 0 ≤ h_i ≤ 1
Weighting emphasizes large overlaps (higher gradients)

**Dimensions**: 
- 180 variables for n=360 solution
- Doubled resolution uses 360 variables

### 3. Implementation procedure
**Parent handling**:
1. `valid_parent(h, n)`: Return symmetric version, adjust integral
2. `upsample(h, n)`: Interpolate to double resolution (if feasible)

**Optimization sequence**:
1. Generate multiple initial points (symmetric + asymmetric variants)
2. SLSQP phase with: 
   - Surrogate objective (log-sum-exp of overlaps)
   - Constraint enforcement via collocation
   - One-step iterative clipping/truncation
3. Gradient refinement: Projected gradient descent
4. Local search: Binary swap optimization (delta < 0 preferred)

**Termination**:
- Track best candidate after failures (timeout/solver error)
- Maintain fallback solution by period halving
- Budget allocation: 40% initial search, 30% per resolution level

**Failure recovery**:
