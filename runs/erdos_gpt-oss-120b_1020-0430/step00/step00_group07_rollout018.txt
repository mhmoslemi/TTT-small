Bounded simplex projection algorithm:

Given vector v ∈ R^n, we need to find projection onto set {x : 0 ≤ x_i ≤ 1, sum x_i = s}, where s = n/2.

Algorithm: Use water-filling: start with x = np.clip(v, 0, 1). Then compute sum_x. If sum_x = s, done. def project_onto_bounded_simplex(v, s):
    # Clip to [0,1]
    x = np.clip(v, 0, 1)
    # Use simple algorithm: use algorithm for projection onto simplex with upper bound 1.
    # Equivalent to projection onto simplex with lower bound 0 and upper bound 1.
    # Use method based on sorting.
    # Let u = sorted(x_i) descending.
    # Find rho such that ...
    #
    # Actually general algorithm: shift each variable by λ and clip to [0,1]:
    # Find λ such that sum_i clip(v_i - λ, 0, 1) = s.
    # This is a 1-D root-finding problem for λ, convex piecewise linear.
    # Use binary search or bisection.
    #
    # We'll implement binary search on λ in [min(v_i - 1), max(v_i)].
    low = -1.0  # because v_i-1 could be as low as -1
    high = 1.0   # because v_i can be up to 1, after subtract λ.
    for _ in range(50):
        lam = (low + high) / 2
        x = np.clip(v - lam, 0, 1)
        total = x.sum()
        if total > s:
            low = lam
        else:

def random_move(h, cur_c5, step):
    n = len(h)
    # choose two indices i,j
    i = np.random.randint(0, n)
    j = np.random.randint(0, n-1)
    if j >= i:
        j += 1
    hi = h[i]; hj = h[j]
    max_up = min(step, 1 - hi, hj)
    max_down = min(step, hi, 1 - hj)
    max_delta = max_up + max_down
    if max_delta <= 0:
        return h, cur_c5
    # sample delta in [-max_down, max_up]
    delta = np.random.uniform(-max_down, max_up)
    if delta == 0:
        return h, cur_c5
    h_new = h.copy()
    h_new[i] = hi + delta
    h_new[j] = hj - delta
    new_c5 = compute_c5_local(h_new)
    # acceptance: greedy
    if new_c5 < cur_c5 - 1e-12:
        return h_new, new_c5
    else:
        return h, cur_c5
