### Approach and Rationale
The current approach relies heavily on DE for global optimization followed by SLSQP for refinement. This method is prone to local optima, especially in high dimensions. The key bottleneck is balancing exploration and exploitation at multiple scales without getting trapped in local minima.

The new approach introduces multi-resolution optimization with adaptive subspace clustering and refined perturbations. By decomposing the high-dimensional problem into lower-dimensional manifolds (resolved by `n_points`), we can:
1. Search diverse configurations efficiently at coarse scales
2. Refine these configurations meaningfully at finer scales
3. Leverage gradient-like updates for faster convergence
4. Prevent premature convergence to local optima

The core innovation is using linear interpolation to distill lower-resolution information into higher-resolution search spaces, combining the benefits of coarse exploration with the fidelity of fine-grained representation.

### Mathematical Specification
- **Representation**: `h` as vector with `n_points` samples
- **Objective**: Minimize `C5 = (2/n_points) * max_knp.correlate(h, 1-h, mode="full")[k]`
- **Constraints**: `0 ≤ h[i] ≤ 1`, `∑ h[i] = n_points/2`
- **Math Transformations**:
  - Correlation computed via `mode="full"` gives `2n_points-1` elements
  - Normalization factor `dx=2/n_points`
  - Projection: `proj = proj_to_feasible(v, target=n_points/2)`
  - Subspace Mapping: `interp` coefficients derived from Fourier transforms
- **Updates**:
  - Linear updates: `candidate = orig + alpha * basis`
  - Gradient-based refinement: `grad approx = (compute_c5(candidate) - compute_c5(prev)) / alpha`
- **Algorithmic Bounds**: Each optimization reduces dimensionality by `log2(resolution_ratio)`

def project_to_feasible(v, target):
    """Enforce sum(h)=n/2 with value bounds [0,1]"""
    n = len(v)
    lo, hi = -2.0, 2.0
    for _ in range(60):
        mid = (lo+hi)*0.5
        x_low = np.clip(v + mid, 0.0, 1.0)
        s_low = np.sum(x_low)
        if s_low < target: lo = mid
        else: hi = mid
    return np.clip(v + (lo+hi)*0.5, 0, 1)

def interpolate_parent_to_new_size(parent: np.ndarray, old_n, new_n):
    """Linear interpolation preserving endpoint values"""
    xs_old = np.linspace(0, 2, old_n)
    xs_new = np.linspace(0, 2, new_n)
    return np.interp(xs_new, xs_old, parent)

def f_transform(h):
    """Fourier transform to identify correlation features"""
    corr_full = np.correlate(h, 1-h, mode="full")
    coeffs = np.abs(np.fft.rfft(corr_full))
    return coeffs

    # Gradient-boltzmann resampling (core algorithm innovation)
    temperature = 0.1 * (1 + math.log10(n_targets[0]/n_base))
    thermal_sample = random_gaussian_walk(global_best, temperature)
    candidate_improvement = compute_c5(thermal_sample) < compute_c5(global_best)

    if candidate_improvement:
        # Refine with particle swarm
        results = optimize_with_spsa(thermal_sample, max_evals=100)
        global_best = results[0]
        global_min_c5 = results[1]

## Stage 2: Calibration
# Knowledge distillation from provenance-aware kernels
for i in range(5):  # Sample multiple thermal paths
    perturbation = np.random.normal(0, 0.1, len(global_best))
    trial_point = global_best + perturbation
    trial_point = project_to_feasible(trial_point, len(global_best)/2)
    trial_c5 = compute_c5(trial_point)
    if trial_c5 < global_min_c5:
        global_best = trial_point
        global_min_c5 = trial_c5

# Stage 3: Final polishing
print("Final hybrid refinement")
best_sol = hill_climb(global_best)
return best_sol.tolist(), float(compute_c5(best_sol)), int(len(global_best))
