## Approach and Rationale

The core of the problem is to minimize the maximum overlap (or correlation) between the function h and (1-h) over all shifts. The current record is about 0.3808.

### Key Idea
We will use a combination of techniques:
1. **Multi-resolution optimization**: Start from a lower resolution (n=360) and then refine to a higher resolution (n=720) to escape local minima.
2. **Simulated Annealing (SA)**: This will allow us to explore the solution space more effectively, especially when subject to a sum constraint and box constraints.
3. **Gradient-based optimization**: We will use SLSQP (Sequential Least Squares Programming) as a local optimizer, but we will tune the parameter β to control the barrier in the barrier method (via softmax) in order to balance between feasibility and optimality.

We will also use a parent solution (initial_h_values) of length 360 provided as a global variable. Our strategy is to:
- First optimize at n=360 (if initial_h_values is available, use it as a starting point).
- Then, if we find a solution with a lower C value, refine it to n=720 by interpolation and further optimization.

### Limitations and Heuristics
- The main challenge is the high dimensionality and non-convexity of the problem.
- We must ensure that during optimization, we maintain the constraints: h[i] in [0,1] and sum(h)=n/2.

We will use a two-phase approach:
1. **Global exploration** with Simulated Annealing to find a good candidate and satisfy the constraints.
2. **Local refinement** with SLSQP (using a barrier method via softmax) to further improve the solution.

To handle the constraints, we will:
- Use a repair function to adjust the function so that the sum is exactly n/2 and each h[i] is in [0,1].

### Innovation over the previous strategy
The previous strategy used hill climbing and SLSQP with a fixed set of β values. We will:
- Implement SA to jump out of local minima.
- Use a multi-resolution approach (starting from 360 and then going to 720) with SA at each resolution.
- Use a more principled way of moving between resolutions: interpolate the solution from lower to higher resolution and then re-run SA.

## Mathematical Specification

### Representation
- h: a vector of n real numbers in [0,1] at each point on [0,2], with n equally spaced points.

### Constraints
1. 0 ≤ h[i] ≤ 1 for all i.
2. sum(h) = n/2.

### Objective
Minimize C = max_k ∫ h(x) * (1-h(x+k)) dx, discretized as:
   C = max_{k} (np.correlate(h, 1-h, mode='full')[k] * (2.0/n))
where k from 0 to 2*n-1.

### Formulation for Optimization
We cannot directly minimize the maximum autocorrelation because it is non-convex. Therefore, we split the problem:

1. **Simulated Annealing (SA)**:
   - State: h vector (feasible, so ensuring sum(n/2) and bounds).
   - Transition: Generate a neighboring solution by transferring a small amount (epsilon) from one random point to another (ensuring bounds).
   - Acceptance: Use Metropolis criterion based on the change in the objective (C) and temperature T.

2. **Gradient-based optimization (SLSQP)**:
   - We use a barrier method by softmax as described in the previous code. We set a parameter β to control the barrier.
   - The objective function is:
        F(h) = (1/β) * log(sum(exp(β * (x_i - x_max)))) 
     but note: the original formulation in the previous code is:
        softmax_obj(x) = (m + log(sum(exp(bc-m)))) / β
     where bc = np.correlate(x,1-x,mode='full') and m = max(bc).
   - We set the sum constraint and box constraints.
