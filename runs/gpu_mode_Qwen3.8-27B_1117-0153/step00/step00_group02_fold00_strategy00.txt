We are going to implement the TriMul operator in Triton, focusing on the outgoing version as described in the AlphaFold3 paper. The operator involves several steps: normalization, projections, gating, and then a pairwise multiplication that sums over the sequence dimension.

The main challenge is the operation `out = einsum('...ikd,...jkd->...ijd', left, right)`, which for a given batch and channel, sums over the third dimension (the sequence index) over the common element. This is equivalent to, for each pair (i, j), summing over k: left[b,i,k,d] * right[b,j,k,d]. Since the sequence length can be up to 1024, the k-loop runs N times (where N is the sequence length) and then the i and j loops are N x N, so the total operations per channel are O(N^3). However, we can use blocked execution and optimize by tiling the sequences.

We note that the operation can be broken down as:
  input: [B, N, N, C] for the current state, then we have two projected tensors [B, N, N, D] and two gates (left_gate, right_gate, out_gate) which produce [B, N, N, D] but then we clamp by taking sigmoid and multiplying by the weights and then the einsum.

  6. Then the einsum is done.
