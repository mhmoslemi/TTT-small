subject to 0 ≤ h ≤ 1, sum(h) = n/2

This is equivalent to:
find the smallest t such that there exists h with:
c_k(h) ≤ t for all k, 0 ≤ h ≤ 1, sum(h) = n/2

Where c_k(h) = sum_i h[i] * (1-h[i+k]) (with appropriate indexing for full correlation).

Note that c_k(h) is a concave function of h (it's a sum of products h[i]*(1-h[i+k]) which are... wait, is it concave or convex?

h[i]*(1-h[i+k]) = h[i] - h[i]*h[i+k]

The Hessian of this with respect to (h[i], h[i+k]) is:
[0, -1; -1, 0]

Eigenvalues: 1 and -1. So it's indefinite! The function is neither convex nor concave.

This confirms it's a non-convex optimization problem. SLSQP with a smooth approximation should work locally, but might get stuck in local optima.

        hfin = _fix_sum(hfin, len(best_h) / 2.0)
        c5f = _compute_c5(hfin)
        if c5f < best_c5:
            best_c5, best_h = c5f, hfin.copy()

    # Validate
    best_h = np.clip(best_h, 0.0, 1.0)
    best_h = _fix_sum(best_h, len(best_h) / 2.0)
    best_c5 = _compute_c5(best_h)

    return best_h, best_c5, len(best_h)
