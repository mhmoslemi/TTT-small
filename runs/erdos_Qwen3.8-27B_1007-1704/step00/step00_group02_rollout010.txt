    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return np.max(corr) * dx

def make_initial(h_src, n):
    """Interpolate from source to new size."""
    n_src = len(h_src)
    x_src = np.linspace(0, 2, n_src, endpoint=False)
    x_new = np.linspace(0, 2, n, endpoint=False)
    h_new = np.interp(x_new, x_src, np.append(h_src, h_src[0]))
    # Fix sum
    h_new = np.clip(h_new, 0, 1)
    diff = n / 2.0 - np.sum(h_new)
    # Adjust
    for _ in range(100):
        if abs(diff) < 1e-10:
            break
        if diff > 0:
            mask = h_new < 1.0
            if not mask.any():
                break
            step = min(diff / mask.sum(), 1.0 - h_new[mask])
            h_new[mask] += step.max() if step.size > 0 else 0
        else:
            mask = h_new > 0.0
            if not mask.any():
                break
            step = max(diff / mask.sum(), -h_new[mask])

The Erdős minimum overlap problem is related to finding sets A ⊂ [0,1] such that for all nonzero k, |A ∩ (A+k)| is small. This is related to difference sets and Sidon sets.

For the continuous case with the integral constraint, the optimal solution might have a specific structure. The n=45 initial solution with C₅ ≈ 0.38085 is already quite good.

Let me also think: for n=45 (odd), sum(h) = 22.5. This means we can't have a 0/1 solution. We need at least one fractional value.

Let me add a 0/1 search for even n: for n=46, try random subsets of size 23 and compute C₅.

Actually, for 0/1 solutions with n even:
- h is 0/1 with exactly n/2 ones
- 1-h is 0/1 with exactly n/2 ones (the complement)
- h*(1-h) is 0 everywhere (disjoint supports)
- np.correlate(h, 1-h, mode='full') is the cross-correlation of two complementary binary sequences

For a binary sequence h and its complement 1-h:
corr[k] = Σ_i h[i] * (1-h)[i-k] (approximately, depending on convention)

This counts the number of positions where h has a 1 and 1-h has a 1 at the shifted position, i.e., where h[i]=1 and h[i-k]=0.

So corr[k] = #{i : h[i]=1, h[i-k]=0}

And we want to minimize max_k corr[k].

Total: Σ_k corr[k] = Σ_k Σ_i h[i](1-h[i-k]) = n * (n/2) * (n/2) / n = n²/4 (roughly, for large n)

Wait, more carefully: for each pair (i,j) with h[i]=1, h[j]=0, there's exactly one k such that j = i-k (mod n in circular sense). So Σ_{k in group} corr[k] = (n/2)² = n²/4.

Number of lags: 2n-1 (for mode='full', not circular).

So the average is about (n²/4) / (2n-1) ≈ n/8.
The max must be at least n/8 (by averaging).

C₅ = max_k corr[k] * dx = max_k corr[k] * 2/n ≥ (n/8) * 2/n = 1/4 = 0.25.

So the theoretical lower bound for the 0/1 case is 0.25, achieved if all correlations are exactly n/8. But that's for circular correlation. For linear (full mode), the edge effects matter.

For the initial n=45 solution with C₅ ≈ 0.38, we have max corr ≈ 0.38 * 45/2 ≈ 8.55. The "average" would be about (22.5)²/89 ≈ 5.7. So the max is about 1.5× the average.

To improve, we want to make the correlations more uniform. This is essentially a "balanced" binary sequence problem.

                                       time_limit=min(rem - 5, 30.0), step0=0.12)
            if c5_ls < c5_now:
                h_init, c5_now = h_ls, c5_ls

        # Binary search for even n
        if n % 2 == 0:
            rem = budget_s - (time.time() - t0)
            if rem > 10:
                h_bin, c5_bin = binary_search(h_init, iters=20000,
                                              time_limit=min(rem - 3, 18.0))
                if c5_bin < c5_now:
                    h_init, c5_now = h_bin, c5_bin

        if c5_now < best_c5:
            best_h = h_init.copy()
            best_c5 = c5_now

    # Final polish
    rem = budget_s - (time.time() - t0)
    if rem > 8:
        h_f, c5_f = local_search(best_h, iters=60000,
                                  time_limit=max(rem - 1, 2), step0=0.06)
        if c5_f < best_c5:
            best_h, best_c5 = h_f, c5_f

    rem = budget_s - (time.time() - t0)
    if rem > 5:
        h_sa, c5_sa = sa_search(best_h, iters=30000, time_limit=max(rem - 1, 2))
        if c5_sa < best_c5:
            best_h, best_c5 = h_sa, c5_sa

    return best_h, best_c5, len(best_h)
