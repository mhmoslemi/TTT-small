Δc[r] = (1 - h[j+r]) * 1_{j+r valid} - h[j-r] * 1_{j-r valid}

But this assumes h[j] was 0 (which it is, since we're setting it to 1 for the first time). And h[j+r] and h[j-r] are the current values (before the change).

After setting h[j] = 1, the new correlation is c + Δc.

But wait, I'm computing Δc using the current h (before the change). Since h[j] = 0 currently:
- In the "first factor" role: h[j] changes from 0 to 1, so the contribution at lag r (where j+r is valid) changes from 0*(1-h[j+r]) to 1*(1-h[j+r]) = 1-h[j+r]. So Δ = 1-h[j+r].
- In the "second factor" role: h[j] changes from 0 to 1, so the term h[j-r]*(1-h[j]) changes from h[j-r]*1 to h[j-r]*0 = 0. So Δ = -h[j-r].

Actually, for each candidate j, I need to compute the vector Δc_j of length 2n-1. I can precompute this for all j simultaneously!

For all j and all r: Δc[j, r] = (1-h[j+r])*1_{valid} - h[j-r]*1_{valid}

This is a 2D array of size n * (2n-1). For n=300, that's 300*599 ≈ 180K values. I can compute this with numpy indexing.

Then new_max[j] = (c + Δc[j, :]).max() for each j.

This is O(n * (2n)) = O(n²) per step, and O(n³) total. But with numpy vectorization, each step is fast.

```python
def greedy_construct_vectorized(n, deadline):
    h = np.zeros(n)
    c = np.zeros(2*n - 1)
    target = n // 2
    
    for step in range(target):
        if time.time() > deadline:
            break
        # Compute delta for all positions at once
        # delta[j, r_idx] = (1-h[j+r]) - h[j-r] for valid indices
        # r ranges from -(n-1) to n-1, r_idx = r + (n-1)
        r_vals = np.arange(-(n-1), n)  # shape (2n-1,)
        j_vals = np.arange(n)  # shape (n,)
        
        # j + r: shape (n, 2n-1)
        jr = j_vals[:, None] + r_vals[None, :]
        # j - r: shape (n, 2n-1)
        jmr = j_vals[:, None] - r_vals[None, :]
        
        # Valid masks
        valid_jr = (jr >= 0) & (jr < n)
        valid_jmr = (jmr >= 0) & (jmr < n)
        
        # Compute delta (only for positions where h[j] == 0)
        jr_clipped = np.clip(jr, 0, n-1)
        jmr_clipped = np.clip(jmr, 0, n-1)
        
        delta = np.zeros((n, 2*n-1))
        delta[valid_jr] = (1 - h[jr_clipped[valid_jr]])
        delta[valid_jmr] -= h[jmr_clipped[valid_jmr]]
        
        # Only consider positions where h[j] == 0
        delta[h == 1] = np.inf  # Mark as invalid
        
        # Compute new max for each j
        new_c = c[None, :] + delta  # shape (n, 2n-1), but inf rows
        new_max = new_c.max(axis=1)
        
        # Find best position
        best_pos = np.argmin(new_max)
        h[best_pos] = 1
        c += delta[best_pos]
    
    return h
```

```python
    c = np.correlate(h, 1 - h, mode='full') * (2.0 / n)
    m = c.max()
    s = alpha * (c - m)
    mx = s.max()
    if mx > 500:

    return m + np.log(np.sum(np.exp(s))) / alpha

def _smo_grad(h, n, alpha):
    c = np.correlate(h, 1 - h, mode='full') * (2.0 / n)
    m = c.max()
    s = alpha * (c - m)
    mx = s.max()
    w = np.exp(s - mx)
    w /= w.sum()
    dx = 2.0 / n
    grad = np.zeros(n)
    for mi in range(2 * n - 1):
        if w[mi] < 1e-12:
            continue
        k = mi - (n - 1)
        wm = w[mi] * dx
        if k >= 0:
            nv = n - k
            grad[:nv] += wm * (1.0 - h[k:])
            grad[k:] += wm * (-h[:nv])
        else:
            kk = -k
            nv = n - kk
            grad[kk:] += wm * (1.0 - h[:nv])
            grad[:nv] += wm * (-h[kk:])
    return grad

                h_cur, c_cur = h_g, c_g
            else:
                h_cur, c_cur = h_i, c_i

            # Gradient refine
            if time.time() < deadline - 20:
                dr = min(time.time() + max(15, n_alloc * 0.25), deadline - 10)
                h_cur, c_cur = grad_refine(h_cur, n_try, dr)

            # Round back and search again
            h_bin = make_binary(h_cur, n_try, rng)
            if time.time() < deadline - 15:
                ds = min(time.time() + max(15, n_alloc * 0.25), deadline - 8)
                h_bin, c_bin = pair_search(h_bin, n_try, ds, rng)
                if c_bin < c_cur:
                    h_cur, c_cur = h_bin, c_bin

            # Final gradient polish
            if time.time() < deadline - 10:
                dp = min(time.time() + 15, deadline - 5)
                h_cur, c_cur = grad_refine(h_cur, n_try, dp)

            c_eval = compute_c5(h_cur, n_try)
            if c_eval < best_c:
                best_c = c_eval
                best_h = h_cur.copy()
                best_n = n_try

    best_h = project_feasible(best_h, best_n)
    best_c = compute_c5(best_h, best_n)
    return best_h, best_c, best_n
```
