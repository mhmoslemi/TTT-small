   - This is a weighted average of individual subgradients, weighted by softmax over the c_k values.
   - Use backtracking line search or fixed step size.
   - Project to feasible set after each step.

2. **The projection** needs to handle both the box constraints [0,1] and the sum constraint. This is the key challenge.

For the projection onto {h : 0 ≤ h[i] ≤ 1, sum(h) = n/2}:
This is a Wasserstein/projection problem. We can solve it by:
- Find λ such that sum_i clip(h[i] - λ, 0, 1) = n/2
- This is a 1D root-finding problem (bisection on λ)

This is much more efficient than iterative projection!

3. **Accelerated projected gradient (FISTA)**:

import numpy as np
from scipy.optimize import minimize
import time

def project_feasible(h, n):
    """Project h onto {0<=h<=1, sum(h)=n/2} using bisection on lambda."""
    target = n / 2.0
    lo, hi = -1.0, 1.0
    
    def sum_at_lam(lam):
        return np.clip(h - lam, 0, 1).sum()
    
    # Find lambda such that sum = target
    for _ in range(100):
        mid = (lo + hi) / 2
        s = sum_at_lam(mid)
        if s > target:
            lo = mid
        else:
            hi = mid
        if hi - lo < 1e-15:
            break
    return np.clip(h - (lo + hi) / 2, 0, 1)

def compute_c5(h, n):
    dx = 2.0 / n
    corr = np.correlate(h, 1 - h, mode='full')
    return float(np.max(corr) * dx)

def compute_corr(h, n):

    return np.correlate(h, 1 - h, mode='full') * dx

def lse_gradient(h, n, alpha):
    """Compute gradient of log-sum-exp smoothed objective."""
    dx = 2.0 / n
    c = np.correlate(h, 1 - h, mode='full') * dx
    # Softmax weights
    c_shift = c - c.max()
    w = np.exp(alpha * c_shift)
    w = w / w.sum()
    
    # For each lag m (corresponding to index k in full output),
    # the gradient of c_m w.r.t. h[j] is:
    # (1 - h[j+m]) if j+m < n, minus h[j-m] if j-m >= 0
    # where m = k - (n-1)
    
    grad = np.zeros(n)
    for k in range(len(c)):
        mk = w[k]
        if mk < 1e-15:
            continue
        m = k - (n - 1)
        # Contribution from h[j] * (1 - h[j+m]) for valid j
        if m >= 0:
            # j ranges from 0 to n-1-m
            js = np.arange(0, n - m)
            grad[js] += mk * (1 - h[js + m])
        else:
            # j ranges from -m to n-1
            js = np.arange(-m, n)
            grad[js] += mk * (1 - h[js + m])  # h[js+m] is valid since m<0
        # Contribution from -h[j] * h[j-m] for valid j (i.e., -h[j-m] when j-m valid)
        if m <= 0:
            # j ranges from -m to n-1 (i.e., j-m >= 0)
            js = np.arange(-m, n)
            grad[js] -= mk * h[js - m]
        else:
            # j ranges from 0 to n-1-m
            js = np.arange(0, n - m)
            grad[js] -= mk * h[js - m]
    
    return grad

    if abs(h.sum() - target) < 1e-12:

    dx = 2.0 / n
    corr = np.correlate(h, 1 - h, mode='full')
    return float(np.max(corr) * dx)

def single_lag_gradient(h, n, m):
    grad = np.zeros(n)
    if m >= 0:
        grad[:n-m] += (1.0 - h[m:n])
        grad[m:n] -= h[:n-m]
    else:
        p = -m
        grad[p:n] += (1.0 - h[:n-p])
        grad[:n-p] -= h[p:n]
    return grad

def weighted_subgradient(h, n, c, top_k=10, alpha=200):
    """Compute weighted average of subgradients for top_k lags."""
    # c is the full correlation * dx, shape (2n-1,)
    # Use softmax over top_k lags
    idx = np.argsort(c)[::-1][:top_k]
    vals = c[idx] - c[idx[0]]
    w = np.exp(alpha * vals)
    w /= w.sum()
    
    grad = np.zeros(n)
    for k, idx_k in enumerate(idx):
        m = idx_k - (n - 1)
        grad += w[k] * single_lag_gradient(h, n, m)
    return grad

def fista_projected(h, n, max_iter=5000, step_init=None, top_k=10, alpha_lse=200):
    """FISTA with projected weighted subgradient."""
    dx = 2.0 / n
    x = h.copy()
    z = h.copy()
    t = 1.0
    step = step_init if step_init else 1.0 / np.sqrt(max_iter)
    
    for it in range(max_iter):
        c = np.correlate(z, 1 - z, mode='full') * dx
        grad = weighted_subgradient(z, n, c, top_k, alpha_lse)
        
        # Backtracking line search or fixed step
        y = x - step * grad
        x_new = project_feasible(y, n)
        
        # Momentum
        t_new = (1 + np.sqrt(1 + 4*t*t)) / 2
        z = x_new + ((t-1)/t_new) * (x_new - x)
        z = project_feasible(z, n)
        x = x_new
        t = t_new
        step *= 0.999  # Slight decay
        
    return x

This changes things significantly. FISTA is guaranteed to work for convex problems, but for non-convex problems, it's just a heuristic. In practice, it often works well, but we should be aware of this.

Given the non-convexity, the optimization landscape might have multiple local optima. This makes the restart strategy even more important.

2. **The quadratic nature**: Since c_k is quadratic (specifically, it's a difference of products), the gradient is:

So the Hessian is a sparse matrix (at most 2 non-zero entries per row), which means it's like a shifted identity. Its eigenvalues are in [-1, 1] (roughly), so the curvature is bounded.

This is actually good news! It means the problem is "low curvature" and gradient methods should work well.

```python
def fista_step(z, n, alpha, idx, step):
    """One FISTA step: compute gradient at z, take step, project."""
    dx = 2.0 / n
    s1, s2, v1, v2 = idx
    c = np.correlate(z, 1.0 - z, mode='full') * dx
    cs = c - c.max()
    w = np.exp(alpha * cs)
    w /= w.sum()
    
    h1 = z[s1]
    h2 = z[s2]
    t1 = ((1.0 - h1) * v1 * w[None, :]).sum(axis=1)
    t2 = (h2 * v2 * w[None, :]).sum(axis=1)
    grad = (t1 - t2) / alpha
    
    x_new = project_feasible(z - step * grad, n)
    return x_new, c
```

Now let me think about the step size more carefully. Since the objective is non-convex, FISTA's theoretical guarantees don't directly apply. However, in practice, FISTA with a moderate step size works well.

The key insight is that the "effective" Lipschitz constant of the smooth part of the gradient is:
L_eff = (1/α) * max_k ||∇²c_k|| * (concentration factor)

For a single c_k, ||∇²c_k|| ≈ 2 (each row of the Hessian has at most 2 non-zero entries of magnitude 1).

For the log-sum-exp, the Hessian is:
∇²f_α = Σ_k p_k * (1/α) * ∇²c_k * α + (1/α) * Σ_k (∂p_k) * ∇c_k
= Σ_k p_k * ∇²c_k + (1/α) * Σ_k (∂p_k) * ∇c_k

The first term has norm ≤ max_k ||∇²c_k|| ≈ 2.
The second term has norm ≤ (1/α) * Σ_k ||∂p_k|| * ||∇c_k||

= 4 * max||∇c||^2 * Σ_k p_k
= 4 * max||∇c||^2
