3. For each pair (i, j), the move h[i]+=d, h[j]-=d changes the objective by approximately d*(g[i]-g[j])

5. For the best pair (argmax g, argmin g), do a line search

So the gradient matrix G[i, m] = ∂c[m]/∂h[i] can be computed as:

```python
def compute_grad_matrix(h, n):
    dx = 2.0 / n
    c_len = 2 * n - 1
    G = np.zeros((n, c_len))
    for p in range(n):
        for k in range(-n+1, n):
            m = k + n - 1
            if k >= 0:
                if k <= p <= n-1:
                    G[p, m] += dx * (1.0 - h[p-k])
                if 0 <= p < n-k:
                    G[p, m] += dx * (-h[p+k])
            else:
                kk = -k
                if 0 <= p < n-kk:
                    G[p, m] += dx * (1.0 - h[p+kk])
                if kk <= p < n:
                    G[p, m] += dx * (-h[p-kk])
    return G
```
