Now, for the binary local search, I want to find a swap (i,j) that minimizes the maximum correlation. The key insight is:

After the swap, the new correlations are corr + Δ, where Δ is the delta vector. The new max is max(corr + Δ). We want this to be less than the current max.

For efficiency, we can:
1. Identify the "critical" shifts (those at or near the current max)
2. For a candidate swap, check if it reduces the critical shifts
3. Also check that it doesn't increase other shifts above the new max

This is still O(n) per candidate swap (to check all shifts), but we can precompute things.

**Efficient binary local search:**

For a binary h with n/2 ones, the swap delta is:
Δc_k = h[j+k] - h[i+k] - h[i-k] + h[j-k] (+ 1 if k=±(i-j))

I can precompute for each position p the vector v_p[k] = h[p+k] - h[p-k] (the "asymmetry" at position p).

Then Δc_k = v_j[k] - v_i[k] (with the correction for k=±(i-j)).

So for each pair (i,j), the delta is just v_j - v_i (plus correction). The new max is max(corr + v_j - v_i).

To find a good swap, I want to minimize max(corr + v_j - v_i) over all (i ∈ zeros, j ∈ ones).

This is still O(n²) in the worst case, but I can be smarter:
- Focus on i that are "bad" (where v_i has large negative values at the critical shifts)
- Focus on j that are "good" (where v_j has large positive values at the critical shifts)

Or, I can use a different formulation. The new max is:
max_k (corr[k] + v_j[k] - v_i[k])

For this to be less than curr_max, we need:
v_j[k] - v_i[k] < curr_max - corr[k] for all k

In particular, for critical k (where corr[k] ≈ curr_max), we need v_j[k] - v_i[k] < 0, i.e., v_j[k] < v_i[k].

So I want zeros i with high v_i at critical shifts, and ones j with low v_j at critical shifts.

def binary_local_search_v2(h0, n, deadline, max_sweeps=1000, n_restarts=3, seed=42):
    n_half = n // 2
    dx = 2.0 / n
    # Snap to binary
    idx = np.argsort(h0)[::-1]
    h = np.zeros(n)
    h[idx[:n_half]] = 1.0
    corr = np.correlate(h, 1 - h, mode='full').copy()
    cur_c = corr.max() * dx
    best_c = cur_c
    best_h = h.copy()
    
    m_range = np.arange(-(n-1), n)
    
    for restart in range(n_restarts):
        if time.time() > deadline:
            break

                a = rng.choice(oi)
                b = rng.choice(zi)
                h[a], h[b] = 0.0, 1.0

        ones_set = set(np.where(h == 1)[0])

                break

            # v_p[k] = h[p+k] - h[p-k] (with h[out of range] = 0)
            # But we only need v_i for zeros and v_j for ones

            # And ones j where v_j is LOW at critical shifts

                v[p, valid1] += h[pk[valid1]]
                # h[p-k] for k in range(-(n-1), n)
                pk2 = p - m_range  # positions p-k
                valid2 = (pk2 >= 0) & (pk2 < n)
                v[p, valid2] -= h[pk2[valid2]]

            o_list = list(ones_set)

            z_order = sorted(z_list, key=lambda i: -v[i, k_star])
            
            for i in z_order:
                if time.time() > deadline:
                    break
                # For this zero, find best one j
                # Need v[j, top_idx] - v[i, top_idx] to reduce the max
                # Score for j: max(top_idx) of (corr[k] + v[j,k] - v[i,k])
                # = max over top_idx of (corr[k] - v[i,k]) + v[j,k]

                # Vectorized: (len(ones) x top_M) matrix
                v_j = v[o_list, top_idx]  # (n_ones, top_M)
                new_vals = v_j + base[None, :]  # (n_ones, top_M)
                new_maxes = new_vals.max(axis=1)  # (n_ones,)
                
                # Find j with minimum new_max
                best_local = np.argmin(new_maxes)
                if new_maxes[best_local] < cur_max_raw - 1e-10:
                    j = o_list[best_local]
                    # Verify full correlation (not just top_M)
                    # Compute actual delta
                    delta = v[j] - v[i]
                    # Correction for k = i-j and k = j-i
                    k_ij = n - 1 + (i - j)
                    k_ji = n - 1 + (j - i)
                    if 0 <= k_ij < 2*n-1:
                        delta[k_ij] += 1
                    if 0 <= k_ji < 2*n-1:
                        delta[k_ji] += 1
                    new_corr = corr + delta
                    actual_max = new_corr.max()
                    if actual_max < cur_max_raw - 1e-10:
                        # Accept the swap
                        h[i], h[j] = 1.0, 0.0
                        corr = new_corr
                        cur_c = corr.max() * dx
                        zeros_set.remove(i)
                        ones_set.add(i)
                        ones_set.remove(j)
                        zeros_set.add(j)
                        # Recompute v (or update incrementally)
                        # For now, recompute (expensive but correct)
                        v = np.zeros((n, 2*n-1))
                        for p in range(n):
                            pk = p + m_range
                            valid1 = (pk >= 0) & (pk < n)
                            v[p, valid1] += h[pk[valid1]]
                            pk2 = p - m_range
                            valid2 = (pk2 >= 0) & (pk2 < n)
                            v[p, valid2] -= h[pk2[valid2]]
                        improved = True
                        if cur_c < best_c:
                            best_c = cur_c
                            best_h = h.copy()
                        break  # restart sweep with new state
            
            if not improved:
                break
    
    return best_h, best_c

The bottleneck is recomputing v after each swap. Let me think if I can update v incrementally.

When h[i] changes from 0 to 1 and h[j] changes from 1 to 0:
- v[p, n-1+k] = h[p+k] - h[p-k]
- This changes if p+k = i or p+k = j or p-k = i or p-k = j
- i.e., p = i-k or p = j-k or p = i+k or p = j+k

For a given swap (i: 0→1, j: 1→0):
- Δv[p, n-1+k] changes if p+k ∈ {i,j} or p-k ∈ {i,j}
  - p+k = i → p = i-k, v change: +1 (for h[p+k] = h[i] going 0→1)
  - p+k = j → p = j-k, v change: -1 (for h[p+k] = h[j] going 1→0)
  - p-k = i → p = i+k, v change: -1 (for h[p-k] = h[i] going 0→1, and it's subtracted)
  - p-k = j → p = j+k, v change: +1 (for h[p-k] = h[j] going 1→0, and it's subtracted, so -(-1) = +1)

So for each k, the affected p values are: i-k, j-k, i+k, j+k.
Total affected (p,k) pairs: 4 × (2n-1) = O(n) per swap.

So I can update v in O(n) per swap instead of O(n²)!

Let me code this up properly:

```python
def update_v_after_swap(v, h, n, i, j, m_range):
    """Update v matrix after swapping h[i]: 0->1, h[j]: 1->0."""
    # For each k in m_range:
    # p = i-k: v[p, n-1+k] += 1 (h[p+k]=h[i] goes 0->1)
    # p = j-k: v[p, n-1+k] -= 1 (h[p+k]=h[j] goes 1->0)
    # p = i+k: v[p, n-1+k] -= 1 (h[p-k]=h[i] goes 0->1, subtracted)
    # p = j+k: v[p, n-1+k] += 1 (h[p-k]=h[j] goes 1->0, subtracted)
    
    for k_idx in range(2*n-1):
        k = m_range[k_idx]
        p1 = i - k
        p2 = j - k
        p3 = i + k
        p4 = j + k
        if 0 <= p1 < n:
            v[p1, k_idx] += 1
        if 0 <= p2 < n:
            v[p2, k_idx] -= 1
        if 0 <= p3 < n:
            v[p3, k_idx] -= 1
        if 0 <= p4 < n:
            v[p4, k_idx] += 1
```

    target = n / 2.0

        diff = target - h.sum()
        if abs(diff) < 1e-14:
            break
        if diff > 0:

            if s < 1e-14:

def compute_c5(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1 - h, mode='full')
    return float(np.max(c) * dx)

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h, 0.0, 1.0)
    for _ in range(100):
        diff = target - h.sum()
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            room = 1.0 - h
            s = room.sum()
            if s < 1e-14:
                break
            h = h + diff / s * room
        else:
            s = h.sum()
            if s < 1e-14:
                break
            h = h + diff / s * h
    return np.clip(h, 0.0, 1.0)

def snap_binary(h, n):
    idx = np.argsort(h)[::-1]
    hb = np.zeros(n)
    hb[idx[:n // 2]] = 1.0
    return hb

def compute_v(h, n):
    v = np.zeros((n, 2 * n - 1))
    m_start = -(n - 1)
    for k_idx in range(2 * n - 1):
        k = m_start + k_idx
        idx1 = np.arange(n) + k
        valid1 = (idx1 >= 0) & (idx1 < n)
        if valid1.any():
            v[np.where(valid1)[0], k_idx] += h[idx1[valid1]]
        idx2 = np.arange(n) - k
        valid2 = (idx2 >= 0) & (idx2 < n)
        if valid2.any():
            v[np.where(valid2)[0], k_idx] -= h[idx2[valid2]]
    return v

def update_v(v, n, i, j):
    m_start = -(n - 1)
    for k_idx in range(2 * n - 1):
        k = m_start + k_idx
        p1 = i - k
        p2 = j - k
        p3 = i + k
        p4 = j + k

        if 0 <= p2 < n:

    if 0 <= k_ji < 2 * n - 1:

    return delta

def slsqp_smooth(h, n, alpha, maxiter, deadline):
    dx = 2.0 / n
    def obj(x):
        g = np.correlate(x, 1 - x, mode='full') * dx
        m = g.max()
        sh = alpha * (g - m)
        sm = sh.max()
        return m + (sm + np.log(np.exp(sh - sm).sum())) / alpha
    def cons_fun(x):
        return x.sum() - n / 2.0
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': cons_fun}]
    try:
        res = minimize(obj, h, method='SLSQP', bounds=bounds,
                       constraints=cons,
                       options={'maxiter': maxiter, 'ftol': 1e-14})
        return project_feasible(res.x, n)
    except Exception:
        return h
