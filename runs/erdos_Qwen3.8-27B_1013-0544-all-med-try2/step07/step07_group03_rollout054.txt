```python
def compute_c5(h, n):
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h, 0.0, 1.0)
    for _ in range(200):
        diff = target - h.sum()
        if abs(diff) < 1e-13:
            break
        if diff > 0:
            room = 1.0 - h
            s = room.sum()
            if s < 1e-14:
                break
            h = h + diff / s * room
        else:
            s = h.sum()
            if s < 1e-14:
                break
            h = h + diff / s * h
    return np.clip(h, 0.0, 1.0)

def slsqp_call(h, n, alpha, maxiter, ftol):
    dx = 2.0 / n
    def obj(x):
        g = np.correlate(x, 1.0 - x, mode='full') * dx
        m = g.max()
        shifted = alpha * (g - m)
        sm = shifted.max()
        return m + (sm + np.log(np.exp(shifted - sm).sum())) / alpha
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': lambda x: x.sum() - n/2.0}]
    try:
        res = minimize(obj, h, method='SLSQP', bounds=bounds,
                       constraints=cons, options={'maxiter': maxiter, 'ftol': ftol})
        return project_feasible(res.x, n)
    except Exception:
        return project_feasible(h, n)
```

Let me derive the gradient:

The objective is: f(x) = max_k g_k(x) + (1/α) * log(Σ_k exp(α(g_k(x) - max_j g_j(x))))

where g_k(x) = (dx) * corr_k(x) and corr_k is the k-th element of np.correlate(x, 1-x).

For the log-sum-exp term, the gradient with respect to x[j] is:
(1/α) * Σ_k w_k * d(corr_k)/dx[j] * α * dx = dx * Σ_k w_k * d(corr_k)/dx[j]

where w_k = exp(α(g_k - g_max)) / Σ_j exp(α(g_j - g_max)) are the softmax weights.

Now, d(corr_k)/dx[j]:
np.correlate(x, 1-x, mode='full')[n-1+k] = Σ_i x[i] * (1-x[i+k]) for valid i, i+k

So d/dx[j] of this:
- If j = i for some i: (1-x[j+k])
- If j = i+k for some i: -x[j-k]

More precisely:
- Term 1: if 0 ≤ j+k < n, then x[j] appears as x[i] with i=j, contributing (1-x[j+k])
- Term 2: if 0 ≤ j-k < n, then x[j] appears as x[i+k] with i=j-k, contributing -x[j-k]

But wait, there's also the case where j appears in both terms (when j+k and j-k are both in range). In that case, the total contribution is (1-x[j+k]) - x[j-k].

Also, when j+k = j (i.e., k=0), we have x[j]*(1-x[j]), and d/dx[j] = 1-2x[j].

Let me be more careful:

corr[n-1+k] = Σ_{i: 0≤i<n, 0≤i+k<n} x[i] * (1-x[i+k])

For a fixed j:
- j appears as i when j+k < n: contributes (1-x[j+k]) if 0 ≤ j+k < n
- j appears as i+k when j-k ≥ 0: contributes -x[j-k] if 0 ≤ j-k < n
- If k = 0: j appears as both i and i+k, so the term is x[j]*(1-x[j]) and derivative is 1-2x[j]

Wait, for k=0: corr[n-1] = Σ_i x[i]*(1-x[i]). The derivative w.r.t. x[j] is 1-2x[j]. ✓

For k ≠ 0:
- If 0 ≤ j+k < n: x[j] appears in term i=j, contributing (1-x[j+k])
- If 0 ≤ j-k < n: x[j] appears in term i=j-k, contributing -x[j-k]
- Note: these are independent since k≠0 means j+k≠j-k

So: d(corr[n-1+k])/dx[j] = (1-x[j+k]) * [0≤j+k<n] - x[j-k] * [0≤j-k<n] for k≠0
And: d(corr[n-1])/dx[j] = 1-2x[j]

The total gradient of the log-sum-exp part:
dF/dx[j] = dx * Σ_k w_k * d(corr[n-1+k])/dx[j]

And the gradient of the max term (which is subgradient, but for SLSQP we can use the same):
d(max)/dx[j] = dx * d(corr[n-1+k*])/dx[j] where k* is the argmax

Actually, for the full objective f = max + logsum/α, the gradient is:
∇f = dx * Σ_k (w_k + [k=k*]) * d(corr_k)/dx

Wait, that's not quite right either. Let me think again.

f(x) = m(x) + (1/α) * log(Σ_k exp(α(m_k(x) - m(x))))

where m_k = corr_k * dx and m = max_j m_j.

∇f = ∇m + (1/α) * ∇log(Σ_k exp(α(m_k - m)))

The second term: let z_k = α(m_k - m). Then:
(1/α) * Σ_k (dz_k/dx_j) * exp(z_k)/Σ exp(z_k)

dz_k/dx_j = α * (dm_k/dx_j - dm/dx_j)

So: (1/α) * Σ_k α(dm_k/dx_j - dm/dx_j) * w_k = Σ_k (dm_k/dx_j - dm/dx_j) * w_k

= Σ_k dm_k/dx_j * w_k - dm/dx_j * Σ_k w_k = Σ_k dm_k/dx_j * w_k - dm/dx_j

And ∇m = dm/dx_j (subgradient at the max point, so dm_k*/dx_j)

So: ∇f = dm/dx_j + Σ_k dm_k/dx_j * w_k - dm/dx_j = Σ_k dm_k/dx_j * w_k

Wait, that's only if the max term's gradient exactly cancels. Let me redo:

∇f = ∇m + Σ_k w_k * ∇(m_k - m) = ∇m + Σ_k w_k * ∇m_k - Σ_k w_k * ∇m = ∇m + Σ_k w_k * ∇m_k - ∇m = Σ_k w_k * ∇m_k

So the gradient of the full objective is simply: ∇f = Σ_k w_k * ∇m_k = dx * Σ_k w_k * ∇corr_k

This is beautiful! The max term's gradient cancels out, and we just need the weighted sum of the correlation gradients.

```python
def obj_and_grad(x, n, alpha):
    dx = 2.0 / n
    g = np.correlate(x, 1.0 - x, mode='full') * dx
    m = g.max()
    shifted = alpha * (g - m)
    sm = shifted.max()
    exps = np.exp(shifted - sm)
    w = exps / exps.sum()
    f = m + (sm + np.log(exps.sum())) / alpha
    
    # Gradient computation using FFT correlations
    s1 = np.correlate(1.0 - x, w, mode='full')  # length 2n-1
    s2 = np.correlate(x, w, mode='full')  # length 2n-1
    grad = dx * (s1[n-1:n-1+n] - s2[n-1:n-1+n])
    
    return f, grad
```
