    h = np.clip(h.copy(), 0.0, 1.0)
    for _ in range(500):
        diff = target - h.sum()
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            room = 1.0 - h
            tot = room.sum()
            if tot < 1e-14:
                break
            h += (diff / tot) * room
        else:
            tot = h.sum()
            if tot < 1e-14:
                break
            h += (diff / tot) * h

    m = c.max()

    mx = shifted.max()

            grad[k:n] += wm * (-h[0:nv])

            grad[0:nv] += wm * (-h[kk:n])

Actually, I want to add one more improvement: a "gradient-guided pair search" that only tries moves in the direction of negative gradient. This should be much more efficient than blind pair search.

For a pair (i,j), moving d from j to i changes the objective by approximately:
Δ ≈ d * (g[i] - g[j])

So we should only try pairs where g[i] < g[j] (moving from high gradient to low gradient).

This reduces the number of effective pairs by about half, and we can also prioritize pairs with larger |g[i] - g[j]|.

                    continue
