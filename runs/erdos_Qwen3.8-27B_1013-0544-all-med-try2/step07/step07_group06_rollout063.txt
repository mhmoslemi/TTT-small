The problem is: min F(h) = max_k f_k(h) subject to h ∈ C = {0 ≤ h ≤ 1, sum(h) = n/2}.

We can write this as: min F(h) + I_C(h) where I_C is the indicator of C.

Proximal gradient: h_{t+1} = prox_{α_t I_C}(h_t - α_t ∇F(h_t))

The proximal operator for C is just the projection onto C (which we already have: project_feasible).

So: h_{t+1} = project_feasible(h_t - α_t ∇F_smooth(h_t))

This is essentially what Adam does (with adaptive step sizes), but the proximal gradient has a cleaner theoretical foundation.

The key is choosing α_t. For the smooth max with parameter α_sm, the Lipschitz constant of ∇F_smooth is roughly α_sm * L where L is related to the problem structure. So α_t should be about 1/(α_sm * L).

Let me estimate L: the second derivative of f_k with respect to h is bounded by 1 (since f_k is bilinear in h). So the Hessian of the smooth max is bounded by α_sm * (sum of weights) * 1 = α_sm * 1 * 1 = α_sm (roughly). Wait, that's not right.

Actually, f_k(h) is bilinear in h (it's a sum of products h[i]*h[j]). The Hessian of f_k has entries that are bounded by 1 (the cross terms) or 0 (the diagonal). So ||∇²f_k|| ≤ 2 (roughly).

For the smooth max: F_smooth(h) = (1/α) log(Σ exp(α f_k(h)))
∇F_smooth = (Σ exp(α f_k) ∇f_k) / (Σ exp(α f_k))
∇²F_smooth = α * Cov_w(∇f_k) where Cov_w is the weighted covariance

||∇²F_smooth|| ≤ α * max_k ||∇f_k||² ≤ α * C (for some constant C depending on n)

So the Lipschitz constant of ∇F_smooth is O(α * n) roughly. This means the step size should be O(1/(α * n)).

def compute_c5(h, n):
    dx = 2.0 / n
    return float(np.max(np.correlate(h, 1 - h, mode='full')) * dx)

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h.copy(), 0, 1)
    for _ in range(100):
        d = target - h.sum()
        if abs(d) < 1e-14:
            break
        if d > 0:
            room = 1.0 - h
            s = room.sum()
            if s < 1e-14: break
            h += (d / s) * room
        else:
            s = h.sum()
            if s < 1e-14: break
            h += (d / s) * h
    return np.clip(h, 0, 1)

def smax_val(x, n, alpha, mu):
    c = np.correlate(x, 1-x, mode='full') * (2.0/n)
    m = c.max()
    s = alpha * (c - m)
    mx = s.max()
    val = m + (mx + np.log(np.sum(np.exp(s - mx)))) / alpha
    if mu > 0:
        val += mu * (x.sum() - n/2.0)**2
    return val

    m = c.max()

        if c_try < best_c:
            best_c = c_try
            best_h = h_try.copy()
        attempt += 1
    return best_h, best_c

def try_other_n(bh, n, end_time, alpha, mu):
    best_h, best_c = bh.copy(), compute_c5(bh, n)
    best_n = n
    candidates = []
    for factor in (0.97, 1.03, 1.33, 1.5, 2.0):
        nt = int(n * factor)
        if 50 <= nt <= 1500 and nt != n:
            candidates.append(nt)
    for nt in candidates:
        if time.time() > end_time - 5:
            break
        remaining = end_time - time.time()
        if remaining < 15:
            break
        alloc = min(28, remaining - 5)
        x_old = np.linspace(0.0, 2.0, n)
        x_new = np.linspace(0.0, 2.0, nt)
        hi = project_feasible(np.interp(x_new, x_old, bh), nt)
        hi, ci = do_lbfgs(hi, nt, time.time() + alloc * 0.55, alpha, mu, 200)
        if time.time() < end_time - 4:
            hi, ci = greedy_opt(hi, nt, min(time.time() + alloc * 0.4, end_time - 3), 0.5 * alpha)
        if ci < best_c:
            best_c = ci
            best_h = hi.copy()
            best_n = nt
    return best_h, best_c, best_n

def run(seed=42, budget_s=1100, **kwargs):
    t0 = time.time()
    dl = t0 + budget_s - 3
    try:
        h0 = np.array(initial_h_values, dtype=float).copy()
    except Exception:
        h0 = np.full(300, 0.5)
    n = len(h0)
    h0 = project_feasible(h0, n)
    bh = h0.copy()
    bc = compute_c5(bh, n)

    # Phase 1: L-BFGS moderate alpha
    e = min(t0 + 80, dl - 550)
    bh, bc = do_lbfgs(bh, n, e, 3000, 100, 300)

    # Phase 2: Greedy exact line search
    e = min(t0 + 190, dl - 450)
    bh, bc = greedy_opt(bh, n, e, alpha=5000, n_pairs=30)

    # Phase 3: L-BFGS high alpha
    e = min(t0 + 330, dl - 350)
    bh, bc = do_lbfgs(bh, n, e, 80000, 800, 400)

    # Phase 4: Greedy sharp
    e = min(t0 + 440, dl - 280)
    bh, bc = greedy_opt(bh, n, e, alpha=80000, n_pairs=35)

    # Phase 5: L-BFGS very high
    e = min(t0 + 570, dl - 220)
    bh, bc = do_lbfgs(bh, n, e, 400000, 4000, 300)

    # Phase 6: L-BFGS extreme
    if time.time() < dl - 350:
        e = min(t0 + 680, dl - 350)
        bh, bc = do_lbfgs(bh, n, e, 1500000, 15000, 250)

    # Phase 7: Greedy extreme
    if time.time() < dl - 250:
        e = min(t0 + 780, dl - 250)
        bh, bc = greedy_opt(bh, n, e, alpha=500000, n_pairs=40)

    # Phase 8: Multi-restart
    if time.time() < dl - 200:
        e = min(t0 + 880, dl - 200)
        bh, bc = multi_restart(bh, n, e, 200000, 2000, seed)

    # Phase 9: Try different n
    if time.time() < dl - 130:
        e = min(t0 + 980, dl - 130)
        bh, bc, n = try_other_n(bh, n, e, 200000, 2000)

    # Phase 10: Final L-BFGS
    if time.time() < dl - 10:
        e = dl - 4
        bh, bc = do_lbfgs(bh, n, e, 2000000, 20000, 300)
        if time.time() < dl - 2:
            bh, bc = greedy_opt(bh, n, dl - 1, alpha=1000000, n_pairs=20)

    bh = project_feasible(bh, n)
    bc = compute_c5(bh, n)
    return bh, bc, n
