```python
def subgradient_step(h, n, lr):
    dx = 2.0 / n
    corr = np.correlate(h, 1-h, mode='full') * dx
    max_val = corr.max()
    # Find all lags achieving (near) the max
    threshold = max_val - 1e-6
    max_lags = np.where(corr >= threshold)[0]
    
    # Compute subgradient as average over max lags
    grad = np.zeros(n)
    for lag_idx in max_lags:
        k = lag_idx - (n-1)  # actual lag
        for i in range(n):
            ipk = i + k
            imk = i - k
            s = 0.0
            if 0 <= ipk < n:
                s += (1 - h[ipk])
            if 0 <= imk < n:
                s -= h[imk]
            grad[i] += s
    grad /= len(max_lags)
    
    # Update
    h_new = h - lr * grad
    return h_new
```

```python
def compute_subgradient_at_lag(h, n, k):
    grad = np.zeros(n)
    # term 1: (1-h[i+k]) for 0 <= i+k < n, i.e., -k <= i < n-k
    if k >= 0:
        i_start, i_end = 0, n - k
        grad[i_start:i_end] += (1 - h[k:k+i_end-i_start])
    else:
        i_start, i_end = -k, n
        grad[i_start:i_end] += (1 - h[0:i_end-i_start])
    # term 2: -h[i-k] for 0 <= i-k < n, i.e., k <= i < n+k
    if k >= 0:
        i_start, i_end = k, n
        grad[i_start:i_end] -= h[0:i_end-i_start]
    else:
        i_start, i_end = 0, n + k
        grad[i_start:i_end] -= h[-k:i_end+k]
    return grad
```

**Faster deterministic local search:**
Instead of trying all (i,j) pairs, for each i (zero), try only a few promising j's (ones). The promising j's are those that would reduce the current maximum correlation the most.

For the current maximum at lag k*, the change from swapping (i,j) is:
δ[k*] = (1-h[i+k*]) - h[i-k*] - (1-h[j+k*]) + h[j-k*] (approximately, ignoring cross-terms)

To minimize δ[k*], we want h[j+k*] + h[j-k*] to be small (preferably 0) and h[i+k*] + h[i-k*] to be large (preferably 2).

So for a given i, the best j to swap with is one where both j+k* and j-k* are 0 (if possible).

This gives us a heuristic: for each i, pick the j that minimizes δ[k*] (or more generally, the new max correlation).

This reduces the per-sweep cost from O(n³) to O(n²) (for each i, we try all j's in O(n) time to find the best one, using a precomputed score).

Actually, even better: for a fixed k*, we can precompute for each position j: score_j = h[j+k*] + h[j-k*]. Then for each i, the best j is the one with the smallest score_j (among ones). This is O(n) to precompute, O(n) to find the best j for each i (if we sort), giving O(n log n) per i, O(n² log n) per sweep.

But this only optimizes the current maximum lag. The swap might increase other lags. So we still need to verify the full max.

A practical approach:
1. For each i (zero), compute the "score" for each j (one) based on the current max lag
2. Pick the top few j's (say, 5-10) for each i
3. For each (i, j) pair, compute the full delta and check if it improves
4. Make the best swap

This reduces the number of full delta computations from O(n²) to O(n * 10) = O(10n) per sweep.

```python
                    if cur_c < best_c:
                        best_c = cur_c
                        best_h = h_bin.copy()
                    break
                else:
                    h_bin[i], h_bin[j] = 0.0, 1.0
            if not improved:
                break
    
    return best_h, best_c
```
