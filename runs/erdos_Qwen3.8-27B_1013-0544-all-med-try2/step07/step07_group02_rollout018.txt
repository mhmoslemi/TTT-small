Wait, this projection isn't quite right. The set {h : 0≤h≤1, sum(h)=n/2} is the intersection of the box [0,1]^n with the hyperplane sum(h)=n/2. The projection onto this set is not simply a shifted clip.

The correct projection onto {h : 0≤h≤1, sum(h)=S} is:
h* = argmin_h ||h - v||² s.t. 0≤h≤1, sum(h)=S

This is solved by: h*_i = clip(v_i - τ, 0, 1) for some τ chosen so that sum(h*) = S.

Since sum(clip(v_i - τ, 0, 1)) is a decreasing function of τ, we can find τ by bisection. This is what I had above, and it's correct.

Let me verify: if v_i - τ > 1, then h*_i = 1. If v_i - τ < 0, then h*_i = 0. Otherwise h*_i = v_i - τ.

sum(h*) = sum(clip(v_i - τ, 0, 1)) = S

This is indeed the Euclidean projection onto the intersection of the box and the hyperplane. Good.

Now, the proximal gradient method:
h_{k+1} = proj_{C}(h_k - η * ∇f(h_k))

where C = {h : 0≤h≤1, sum(h)=n/2} and η is the step size.

For convergence, we need η < 2/L where L is the Lipschitz constant of ∇f.

The Lipschitz constant of the soft-max objective's gradient:
∇f(h) = dx * sum_s w_s * ∇c_s(h)
||∇f(h) - ∇f(h')|| ≤ dx * (sum_s |w_s - w_s'| * ||∇c_s|| + sum_s w_s * ||∇c_s(h) - ∇c_s(h')||)

This is complex to bound. In practice, for the soft-max with parameter alpha:
L ≈ 2 * alpha * dx + 2 * dx

So η ≈ 1 / (2 * alpha * dx + 2 * dx) = 1 / (2*dx*(alpha+1))

For dx = 2/400 = 0.005 and alpha = 1000: L ≈ 2*0.005*1001 ≈ 10. So η ≈ 0.1.

This means we can take steps of size ~0.1 in the h-space, which is reasonable.
