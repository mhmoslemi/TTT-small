    # This is a convex function, so ternary search works
    lo, hi = 0.0, 1.0

        m1 = lo + (hi - lo) / 3
        m2 = hi - (hi - lo) / 3
        f1 = np.max(base + A * m1)
        f2 = np.max(base + A * m2)
        if f1 < f2:
            hi = m2
        else:
            lo = m1
    t = (lo + hi) / 2
    return t, np.max(base + A * t)

Let me also think about the sum constraint. In coordinate descent, when I change h[i], the sum constraint is violated. I need to either:

This is still convex in t (max of affine + quadratic with positive coefficient... wait, the quadratic in t is λ*(S-t-n/2)^2 which is convex in t). So the total is convex, and ternary search works!

Actually wait: max of convex functions is convex. max_k(base_k + A_k*t) is convex. λ*(S-t-n/2)^2 is convex. But max of one + another ≠ max of both. The total objective is:

This is convex (sum of convex functions). 

But actually, for the coordinate descent to work well, I should make λ small enough that it doesn't dominate, but large enough to maintain feasibility.

Let me also think about an alternative: **Frank-Wolfe (conditional gradient) method**. 

The problem is: minimize f(h) = max_k corr_k * dx subject to h ∈ [0,1]^n, sum(h) = n/2.

Frank-Wolfe iterates:
1. Given current h, compute the linearization: g = ∇f(h) (or a subgradient)
2. Solve: min_{s ∈ [0,1]^n, sum(s)=n/2} g · s
3. Update: h ← (1-γ)h + γs

Step 2 is a linear program: min g·s subject to 0≤s≤1, sum(s)=n/2. The solution is: s_i = 1 if g_i is small, s_i = 0 if g_i is large, and at most one s_i is fractional. Specifically, sort g, set s_i = 1 for the n/2 smallest g_i (or the first k where the cumulative sum hits n/2).

This is very efficient! The subgradient of f(h) = max_k corr_k is any weighted average of the gradients of the active correlations.

Let me compute the gradient of corr_k with respect to h:
corr_k = ∑_j h[j] * (1-h[j+k]) (for valid j)

∂corr_k/∂h[i] = 
- (1-h[i+k]) if i+k is valid (i is first factor)
- -h[i-k] if i-k is valid (i is in 1-h, second factor)
- For k=0: (1-2*h[i]) [since h[i]*(1-h[i]) has derivative 1-2h[i]]

So the gradient is sparse: for each k, only 2 coordinates are affected (i and i+k, or i and i-k).

The full gradient of f(h) = max_k corr_k * dx with respect to h is:
∇f = dx * ∑_{k ∈ active} w_k * ∇corr_k

where w_k ≥ 0, sum w_k = 1.

For a subgradient, we can use w_k = 1/|active| for all active k, or w_k proportional to something else.

This gives us a Frank-Wolfe method that's very efficient:
- Compute correlations: O(n^2) (or O(n * 2n) = O(n^2) using the full correlate)
- Find active set: O(n)
- Compute subgradient: O(n * |active|) ≈ O(n^2) worst case, but usually |active| is small
- FW step (sort and threshold): O(n log n)
- Update: O(n)

Total per iteration: O(n^2) dominated by the correlation computation.
For n=350: ~122500 per iteration. Can do ~10000 iterations in a minute.

This is much faster than SLSQP! And it's a proper optimization method with convergence guarantees.

Let me implement this:

```python
def frank_wolfe(h, deadline, max_iter=50000):
    n = len(h)
    target_sum = n / 2.0
    dx = 2.0 / n
    h = h.astype(float).copy()
    best_c5 = compute_c5(h)
    
    for it in range(max_iter):
        if time.time() > deadline:
            break
        
        # Compute correlations
        corr = np.correlate(h, 1.0 - h, mode='full')
        c5 = float(np.max(corr) * dx)
        if c5 < best_c5:
            best_c5 = c5
        
        # Find active set (top lags)
        # Use a tolerance to include near-active lags
        max_val = corr.max()
        threshold = max_val - 1e-6  # include lags within 1e-6 of max
        active = np.where(corr >= threshold)[0]
        
        if len(active) == 0:
            active = np.array([np.argmax(corr)])
        
        # Compute subgradient
        # For each active lag, compute its gradient contribution
        # lag for index idx: k = idx - (n-1)
        grad = np.zeros(n)
        for idx in active:
            k = idx - (n-1)
            # ∂corr_k/∂h[i]:
            # For k >= 0: corr_k = sum_{j=0}^{n-1-k} h[j]*(1-h[j+k])
            #   ∂/∂h[i] = (1-h[i+k]) if 0<=i<=n-1-k  [i is j]
            #             + (-h[i-k]) if k<=i<=n-1    [i is j+k]
            # For k < 0: let m = -k > 0
            #   corr_{-m} = sum_{j=0}^{n-1-m} h[j+m]*(1-h[j])
            #   ∂/∂h[i] = (1-h[i-m]) if m<=i<=n-1   [i is j+m]
            #             + (-h[i+m]) if 0<=i<=n-1-m  [i is j]
            
            if k >= 0:
                # i as first factor: 0 <= i <= n-1-k
                mask1 = np.arange(n) <= (n-1-k)
                grad[mask1] += (1.0 - h[np.arange(n)[mask1] + k])
                # i as second factor (j+k = i): k <= i <= n-1
                mask2 = np.arange(n) >= k
                grad[mask2] += (-h[np.arange(n)[mask2] - k])
            else:
                m = -k
                # i as first factor (j+m = i): m <= i <= n-1
                mask1 = np.arange(n) >= m
                grad[mask1] += (1.0 - h[np.arange(n)[mask1] - m])
                # i as second factor (j = i): 0 <= i <= n-1-m
                mask2 = np.arange(n) <= (n-1-m)
                grad[mask2] += (-h[np.arange(n)[mask2] + m])
        
        # Actually, let me verify: for k=0
        # corr_0 = sum h[j]*(1-h[j])
        # ∂/∂h[i] = 1 - 2*h[i]
        # Using the formula for k=0 (k>=0 case):
        # mask1: 0<=i<=n-1, grad += 1-h[i]
        # mask2: 0<=i<=n-1, grad += -h[i]
        # Total: 1-h[i]-h[i] = 1-2h[i] ✓
        
        # Normalize: the subgradient of max is (1/|active|) * sum of gradients of active
        # Actually, any convex combination works. Let me use uniform weights.
        grad /= len(active)
        
        # Frank-Wolfe step: minimize grad · s subject to 0<=s<=1, sum(s)=n/2
        # Solution: sort grad, pick the smallest n/2 coordinates to set to 1
        # (since we want to minimize grad·s)
        sorted_idx = np.argsort(grad)
        s = np.zeros(n)
        s[sorted_idx[:int(target_sum)]] = 1.0
        # target_sum = n/2 should be integer
        # If n is odd, we need to be more careful, but n=350 is even
        
        # Learning rate
        gamma = 2.0 / (it + 2)  # standard FW rate
        # Or use strong Wolfe line search
        
        # Update
        h_new = (1 - gamma) * h + gamma * s
        
        # Check if we can improve with a line search
        # f(h + t*(s-h)) for t in [0,1]
        # Since f is not convex (it's max of non-convex functions), 
        # standard FW line search might not apply directly.
        
        h = h_new
        h = np.clip(h, 0, 1)
        # Project to sum constraint
        # Actually, the convex combination of two feasible points is feasible
        # h is feasible (0<=h<=1, sum=n/2) and s is feasible (0<=s<=1, sum=n/2)
        # So h_new is feasible. No projection needed!
        
    return h, best_c5
```

Wait, there's an issue. The Frank-Wolfe method is designed for convex optimization. Our problem is:
minimize max_k corr_k (subject to constraints)

The function max_k corr_k is NOT convex in h (because corr_k involves products h[i]*h[j]). So Frank-Wolfe is not directly applicable.

However, we can still use a "linearized" version as a heuristic:
1. Linearize the objective at the current point: L(h) = f(h_current) + ∇f(h_current) · (h - h_current)
2. Minimize L over the constraint set (this is the FW step)
3. Update

This is essentially a subgradient method with a specific projection (the FW projection gives the extreme point of the constraint set in the direction of -∇f).

For our problem, the constraint set {h : 0≤h≤1, sum(h)=n/2} has extreme points that are 0-1 valued (exactly n/2 ones and n/2 zeros). The FW step finds the 0-1 vector s that minimizes the linearized objective.

This should still make progress, even though the objective is non-convex. It's like doing a "greedy" step in the direction that most reduces the linearized objective.

Let me also add a line search: after computing the FW step direction d = s - h, do a 1D line search along h + t*d for t ∈ [0,1] to minimize f.

Actually, for the line search, since the direction goes toward a 0-1 vertex, the path h + t*(s-h) goes from h toward a vertex. Along this path, f might not be convex, but we can still find a good t.

Let me implement this with a simple line search (evaluate at several points and pick the best):

```python
def fw_step(h, grad, n, target_sum):
    # Find the point in the constraint set that minimizes grad · x
    sorted_idx = np.argsort(grad)
    s = np.zeros(n)
    s[sorted_idx[:int(target_sum)]] = 1.0
    return s

def line_search(h, direction, n, max_evals=20):
    # Find t in [0,1] minimizing f(h + t*direction)
    best_t = 0.0
    best_f = compute_c5(h)
    for t in np.linspace(0, 1, max_evals):
        if t == 0: continue
        h_test = h + t * direction
        f = compute_c5(h_test)
        if f < best_f:
            best_f = f
            best_t = t
    return best_t, best_f
```

def smooth_max(x, beta):
    m = np.max(x)
    shifted = np.clip(beta * (x - m), -700.0, 700.0)
    return m + np.log(np.sum(np.exp(shifted))) / beta

def project_feasible(h, target_sum):
    h = np.clip(h, 0.0, 1.0).copy()

        s = h.sum()
        if abs(s - target_sum) < 1e-14:
            break

        if cnt == 0:
