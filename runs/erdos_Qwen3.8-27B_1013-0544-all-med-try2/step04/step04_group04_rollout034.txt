Let me also think about whether the dual ascent will converge. The dual update is:
  λ ← λ + η * (sum(h) - target)

If sum(h) > target, λ increases, which makes the objective penalize large sums more, pushing h down. If sum(h) < target, λ decreases, pushing h up. This should converge if η is small enough.

However, there's a coupling: after each L-BFGS-B call, I project h to satisfy the constraint. So after projection, sum(h) = target exactly. Then the dual update gives:
  λ ← λ + η * (target - target) = λ

So λ never changes! That's a problem.

The fix: don't project after each L-BFGS-B call. Instead, let the L-BFGS-B solve the Lagrangian subproblem, and only project at the end. Or, project but compute the dual update based on the unprojected solution.
