```python
def swap_delta(h, i0, j0, n):
    """Compute the change in all correlation values when swapping h[i0] and h[j0].
    Assumes h[i0]=1 and h[j0]=0."""
    # Δc[ℓ] = -(1-h[i0+ℓ])*[i0+ℓ in range] + h[i0-ℓ]*[i0-ℓ in range]
    #          + (1-h[j0+ℓ])*[j0+ℓ in range] - h[j0-ℓ]*[j0-ℓ in range]
    
    # For lag ℓ (where ℓ = k - (n-1), k is the correlate index):
    # The valid range for ℓ is [-(n-1), n-1]
    
    # Let's work with the correlate index k directly.
    # c_full[k] = sum over i of h[i] * g[i + k - (n-1)]
    # where g = 1-h
    
    # Actually, let me just compute it directly.
    # For a given ℓ, c[ℓ] involves h[i] for i in [max(0,-ℓ), min(n-1, n-1-ℓ)]
    # and g[i+ℓ] for the same range.
    
    # Change from h[i0]: 1→0
    # - Direct: -g[i0+ℓ] for ℓ where 0 ≤ i0+ℓ ≤ n-1, i.e., -i0 ≤ ℓ ≤ n-1-i0
    # - Via g: +h[i0-ℓ] for ℓ where 0 ≤ i0-ℓ ≤ n-1, i.e., i0-(n-1) ≤ ℓ ≤ i0
    
    # Change from h[j0]: 0→1
    # - Direct: +g[j0+ℓ] for ℓ where 0 ≤ j0+ℓ ≤ n-1
    # - Via g: -h[j0-ℓ] for ℓ where 0 ≤ j0-ℓ ≤ n-1
    
    delta = np.zeros(2*n-1)  # indexed by k = ℓ + (n-1), so ℓ = k-(n-1)
    
    # For i0 (1→0):
    # Direct: -g[i0+ℓ] for -i0 ≤ ℓ ≤ n-1-i0
    lo1, hi1 = -i0, n-1-i0
    # ℓ in [lo1, hi1], g[i0+ℓ] = 1-h[i0+ℓ]
    idx = np.arange(lo1, hi1+1) + (n-1)  # convert to correlate index
    delta[idx] -= (1 - h[i0+np.arange(lo1, hi1+1)])
    
    # Via g: +h[i0-ℓ] for i0-(n-1) ≤ ℓ ≤ i0
    lo2, hi2 = i0-(n-1), i0
    idx2 = np.arange(lo2, hi2+1) + (n-1)
    delta[idx2] += h[i0-np.arange(lo2, hi2+1)]
    
    # For j0 (0→1):
    # Direct: +g[j0+ℓ] for -j0 ≤ ℓ ≤ n-1-j0
    lo3, hi3 = -j0, n-1-j0
    idx3 = np.arange(lo3, hi3+1) + (n-1)
    delta[idx3] += (1 - h[j0+np.arange(lo3, hi3+1)])
    
    # Via g: -h[j0-ℓ] for j0-(n-1) ≤ ℓ ≤ j0
    lo4, hi4 = j0-(n-1), j0
    idx4 = np.arange(lo4, hi4+1) + (n-1)
    delta[idx4] -= h[j0-np.arange(lo4, hi4+1)]
    
    return delta
```

Let me also try a **subgradient method** for the continuous case:
1. Compute all lags
2. Find the active lags (those at the max)
3. Compute the subgradient with respect to h for the active lags
4. Take a projection gradient step

The gradient of f_k(h) = dx * ∑ h[i]*(1-h[i+k]) with respect to h[j] is:
- From the "h[i]" term: dx * (1-h[j+k]) if j+k is in range
- From the "(1-h[i+k])" term: -dx * h[j-k] if j-k is in range

So ∂f_k/∂h[j] = dx * [(1-h[j+k])*[j+k valid] - h[j-k]*[j-k valid]]

The subgradient of max_k f_k is the average of gradients of the active lags (or just the gradient of one active lag).

Let me implement this:

```python
def subgradient_step(h, n, step_size, alpha_top=5):
    c_all = compute_all_lags(h, n)
    dx = 2.0 / n
    # Get top lags
    top_lags = np.argsort(c_all)[-alpha_top:]
    # Compute gradient as average of active lag gradients
    grad = np.zeros(n)
    for k_idx in top_lags:
        lag = k_idx - (n - 1)
        for j in range(n):
            # (1-h[j+lag]) if j+lag in [0,n-1]
            if 0 <= j + lag < n:
                grad[j] += (1 - h[j + lag])
            # -h[j-lag] if j-lag in [0,n-1]
            if 0 <= j - lag < n:
                grad[j] -= h[j - lag]
    grad *= dx / len(top_lags)
    # Gradient descent step
    h_new = h - step_size * grad
    # Project
    h_new = project_feasible(h_new, n)
    return h_new
```

This is O(n²) per step (due to the inner loop over j for each active lag). For n=300 and 5 active lags, that's 5*300 = 1500 operations per step, which is fast.

But I can vectorize it:

```python
def subgradient_step_vec(h, n, step_size, alpha_top=5):
    c_all = compute_all_lags(h, n)
    dx = 2.0 / n
    top_lags = np.argsort(c_all)[-alpha_top:]
    grad = np.zeros(n)
    for k_idx in top_lags:
        lag = k_idx - (n - 1)
        if lag == 0:
            grad += (1 - h) - h  # (1-h) - h = 1 - 2h
            # Wait, for lag=0: ∂f_0/∂h[j] = (1-h[j]) - h[j] = 1-2h[j]
            # Actually f_0 = dx * ∑ h[i](1-h[i]) = dx * ∑(h[i] - h[i]²)
            # ∂f_0/∂h[j] = dx * (1 - 2h[j])
            grad += (1 - 2*h)
        elif lag > 0:
            # (1-h[j+lag]) for j in [0, n-lag-1]
            grad[:n-lag] += (1 - h[lag:])
            # -h[j-lag] for j in [lag, n-1]
            grad[lag:] -= h[:n-lag]
        else:
            # lag < 0
            m = -lag
            # (1-h[j+lag]) = (1-h[j-m]) for j in [m, n-1]
            grad[m:] += (1 - h[:n-m])
            # -h[j-lag] = -h[j+m] for j in [0, n-m-1]
            grad[:n-m] -= h[m:]
    grad *= dx / len(top_lags)
    h_new = h - step_size * grad
    return project_feasible(h_new, n)
```

This is O(n * alpha_top) per step, which is very fast.
