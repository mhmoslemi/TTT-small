  - Compute (B[None,:] - A[one_positions, :]).max(axis=1): O(n_ones * n) = O(n²/2)
  - Total per i: O(n²)
- Total per sweep: O(n³) = O(n/2 * n²) = O(n³/2)

For n=250: 250³/2 ≈ 7.8 million operations per sweep. With numpy vectorization, maybe 10-50ms per sweep. We could do thousands of sweeps!

But wait, after each swap, A changes (because h changed). So we need to recompute A after each swap. Recomputing A is O(n²). So each swap costs O(n²) to update A + O(n²) for the search = O(n²) per swap.

Actually no - we only change two positions (i and j). The change in A is:
- A[i, :] changes because h[i] changed from 0 to 1.
- A[j, :] changes because h[j] changed from 1 to 0.
- All other A[p, :] might also change if they reference h[i] or h[j].

Specifically, A[p, k] references h[p-k] and h[p+k]. So A[p, k] changes if p-k = i or p-k = j or p+k = i or p+k = j.
- p-k = i → k = p-i: A[p, p-i] changes (by +1 if h went 0→1, or -1 if 1→0, for the first term; or by -1 or +1 for the second term)
- p+k = i → k = i-p: A[p, i-p] changes.

So for each position p, at most 4 entries of A[p, :] change. Total changes: O(n) per swap (4 changes per p, for all n positions).

Wait, that's not right. For position p, A[p, k] = (1-h[p-k])·[valid] - h[p+k]·[valid].
If h[i] changes by δ_i (from 0 to 1, so δ_i = +1):
- A[p, k] changes by: -(δ_i)·[p-k=i] + (-δ_i)·[p+k=i] = -δ_i·[k=p-i] - δ_i·[k=i-p]
  Wait: (1-h[p-k]) changes by -δ_i when p-k=i. And -h[p+k] changes by -δ_i when p+k=i.
  So A[p, k] changes by -δ_i·[k=p-i] - δ_i·[k=i-p].
  
  For δ_i = +1: A[p, p-i] -= 1 and A[p, i-p] -= 1.

If h[j] changes by δ_j (from 1 to 0, so δ_j = -1):
- A[p, k] changes by -δ_j·[k=p-j] - δ_j·[k=j-p] = +1·[k=p-j] +1·[k=j-p]
  So A[p, p-j] += 1 and A[p, j-p] += 1.

So per swap, we update:
- For all p: A[p, p-i] -= 1, A[p, i-p] -= 1, A[p, p-j] += 1, A[p, j-p] += 1
  (with validity checks)

This is O(n) updates per swap (4 per position p, for n positions = 4n updates). Very fast!

So the algorithm per sweep:
1. For each zero position i (in some order):
   a. Compute B = corr + A[i]
   b. Find best j: new_maxs = (B[None,:] - A[one_positions,:]).max(1); apply +2 correction; pick argmin
   c. If new_max < current_max: perform swap, update corr, update A, update positions
2. If no improvement in a full sweep, stop.

The cost per sweepStep (one i): O(n²) for the matrix operation.
Total per sweep: O(n² * n_zeros) = O(n³) but with good constants.
Per swap: O(n) to update A.

For n=250, this should be very fast. Let me estimate:
- B[None,:] - A[one_positions,:] is a (125, 499) matrix subtraction. ~62K operations.
- .max(axis=1) on that: another ~62K operations.
- Total per i: ~125K operations.
- Per sweep (125 i's): ~15.6M operations.
- In numpy, maybe 5-20ms per sweep.
- 10000 sweeps: 50-200 seconds.

That's very feasible within the time budget!

But wait, I should also think about the strategy for which i to try. If we try all zeros in order and swap the first one that improves, we might get stuck. Better to:
- Try all zeros, find the swap that gives the best improvement
- Or: use a greedy approach where we pick the swap with the largest reduction in max

Let me also think about whether we should try all (i,j) pairs or just the "best" j for each i.

For each i, we find the best j (minimizing the new max). Then we pick the i that gives the overall best result. Or we can just do a "first improvement" strategy: for each i, if the best j gives an improvement, do it and restart.

The "first improvement" strategy is simpler and often works well in practice.

Let me also consider: should we use n=250 or a different n? The problem says smaller sequences are preferred. Let me try n=250, n=200, n=300, etc.

Actually, for the binary search to work well, n should be even (so n/2 is an integer). Let me stick with n=250.

**Another idea: Simulated annealing / random restarts**

After finding a local optimum, we can:
1. Randomly swap a few positions (destroy)
2. Run the local search again (repair)
3. Keep the best

This is a simple form of iterated local search.

**Yet another idea: Use the continuous relaxation**

The continuous SLSQP approach from the previous code can also be useful. The idea is:
1. Start from the binary solution
2. Slightly perturb (add noise)
3. Run SLSQP to find a continuous local minimum
4. Project back to binary (threshold at 0.5)
5. Run binary local search

This can escape binary local optima by "tunneling" through the continuous space.

**Let me now write the code:**

Key components:
1. `compute_c5(h, n)` - compute the C5 value
2. `compute_A(h, n)` - compute the profile matrix A
3. `update_A(A, h, i, j, delta_i, delta_j, n)` - update A after a swap
4. `binary_local_search(h, n, deadline, ...)` - the main local search
5. `run(seed=42, budget_s=1100, **kwargs)` - the main function

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1 - h, mode='full')
    return float(np.max(c) * dx)

def compute_A(h, n):
    """Compute A[p, k] = (1-h[p-k])*[0<=p-k<n] - h[p+k]*[0<=p+k<n]"""
    A = np.zeros((n, 2*n-1))
    ks = np.arange(2*n-1)
    for p in range(n):
        q1 = p - ks  # = p-k
        m1 = (q1 >= 0) & (q1 < n)
        A[p, m1] += 1.0 - h[q1[m1]]
        q2 = p + ks  # = p+k
        m2 = (q2 >= 0) & (q2 < n)
        A[p, m2] -= h[q2[m2]]
    return A

def update_A_after_swap(A, i, j, n):
    """Update A after h[i] goes 0->1 and h[j] goes 1->0.
    A[p, p-i] -= 1, A[p, i-p] -= 1 (clamped to valid range)
    A[p, p-j] += 1, A[p, j-p] += 1 (clamped to valid range)
    """
    ks = np.arange(2*n-1)
    # For h[i]: 0->1, delta_i = +1
    # A[p,k] changes by -1*[k=p-i] - 1*[k=i-p]
    for p in range(n):
        k1 = p - i
        k2 = i - p
        if 0 <= k1 < 2*n-1:
            A[p, k1] -= 1.0
        if 0 <= k2 < 2*n-1:
            A[p, k2] -= 1.0
        k3 = p - j
        k4 = j - p
        if 0 <= k3 < 2*n-1:
            A[p, k3] += 1.0
        if 0 <= k4 < 2*n-1:
            A[p, k4] += 1.0

def binary_local_search_v2(h, n, deadline, max_sweeps=10000, seed=42):
    """Fast binary local search using precomputed A matrix."""
    target = n // 2
    dx = 2.0 / n
    idx = np.argsort(h)[::-1]
    h = np.zeros(n)
    h[idx[:target]] = 1.0
    
    corr = np.correlate(h, 1 - h, mode='full').copy()
    cur_max = corr.max()
    A = compute_A(h, n)
    
    ones = np.where(h == 1)[0]
    zeros = np.where(h == 0)[0]
    
    rng = np.random.RandomState(seed)
    
    for sweep in range(max_sweeps):
        if time.time() > deadline:
            break
        improved = False
        # Try each zero position
        shuffled_zeros = zeros.copy()
        rng.shuffle(shuffled_zeros)
        for i in shuffled_zeros:
            if time.time() > deadline:
                break
            B = corr + A[i]
            # For all one positions:
            # new_max_no_corr = (B[None,:] - A[ones,:]).max(axis=1)
            vals = B[None, :] - A[ones, :]
            new_maxs = vals.max(axis=1)
            # Apply +2 correction at k = i - j
            k_corr = i - ones  # shape (n_ones,)
            valid = (k_corr >= 0) & (k_corr < 2*n-1)
            if valid.any():
                corr_vals = B[k_corr[valid]] - A[ones[valid], k_corr[valid]] + 2.0
                new_maxs[valid] = np.maximum(new_maxs[valid], corr_vals)
            
            best_idx = np.argmin(new_maxs)
            if new_maxs[best_idx] < cur_max - 1e-12:
                j = ones[best_idx]
                # Perform swap
                h[i], h[j] = 1.0, 0.0
                corr = corr + A[i] - A[j]
                k_c = i - j
                if 0 <= k_c < 2*n-1:
                    corr[k_c] += 2.0
                cur_max = corr.max()
                update_A_after_swap(A, i, j, n)
                # Update ones and zeros
                ones = np.delete(ones, best_idx)
                ones = np.append(ones, i)
                zeros = zeros[np.where(zeros != i)[0]]
                zeros = np.append(zeros, j)
                improved = True
                break  # restart sweep for this i
        if not improved:
            break
    
    return h, cur_max * dx

    dl = t0 + budget_s - 5

A[p, k] = (1-h[p-k])·[0≤p-k<n] - h[p+k]·[0≤p+k<n]

So A[p, p-i] -= δ and A[p, i-p] -= δ.
