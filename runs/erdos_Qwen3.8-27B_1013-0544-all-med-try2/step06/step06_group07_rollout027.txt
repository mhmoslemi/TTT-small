Actually, I realize there might be an issue with my approach. Let me think about what the subgradient of the max is.

f(h) = max_k g_k(h) where g_k(h) = sum_i h[i]*(1-h[i+k]) * dx

The subgradient of f at h is the convex hull of {grad g_k(h) : k in K*} where K* = {k : g_k(h) = f(h)}.

So the subgradient is a convex combination of the gradients of all active lags. The simplest choice is to pick the single worst lag, which is what I'm doing. A potentially better choice is to average over all (approximately) active lags.

Let me modify the subgradient to average over the top few lags:

```python
def subgrad_topk(h, n, k=3):
    corr = np.correlate(h, 1.0 - h, mode="full")
    # Find top k lags
    top_idx = np.argsort(corr)[::-1][:k]
    max_val = corr[top_idx[0]]
    # Only include lags within epsilon of the max
    active = [i for i in top_idx if corr[i] > max_val - 0.01/max_val]
    grad = np.zeros(n)
    for ki in active:
        lag = ki - (n - 1)
        if lag >= 0:
            idx = np.arange(n - lag)
            grad[idx] += (1.0 - h[idx + lag])
            grad[idx + lag] -= h[idx]
        else:
            la = -lag
            idx = np.arange(n - la)
            grad[idx + la] += (1.0 - h[idx])
            grad[idx] -= h[idx + la]
    grad /= len(active)
    return grad
```

This should give a better descent direction when multiple lags are near the maximum.

One more idea: **Use the dual problem**. The problem is:
min_h max_k g_k(h)

The dual (for the relaxed problem where h is a probability distribution) is:
max_p min_h sum_k p_k g_k(h)

where p is a probability distribution over k. The inner problem is:
min_h sum_k p_k sum_i h[i]*(1-h[i+k])*dx + lambda*(sum(h) - n/2)

= min_h sum_i [sum_k p_k * (1-h[i+k])*dx * h[i] + lambda * h[i]]

This is a sum of terms each depending on h[i] and h[i+k], so it's a quadratic form in h. Minimizing a quadratic form subject to 0<=h<=1 and sum(h)=n/2 is a convex QP (if the quadratic form is convex).

But the quadratic form h^T A h where A depends on p might not be convex. So this dual approach might not work directly.

    h = np.clip(h, 0.0, 1.0)

        diff = target_sum - h.sum()
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            mask = h < 1.0 - 1e-14
        else:
            mask = h > 1e-14
        cnt = mask.sum()
        if cnt == 0:
            break
        h[mask] += diff / cnt
        h = np.clip(h, 0.0, 1.0)
    h = np.clip(h, 0.0, 1.0)
