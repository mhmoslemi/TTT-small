```python
import cvxpy as cp

def sca_step(h0, n):
    """One SCA iteration: linearize and solve LP"""
    dx = 2.0 / n
    corr0 = np.correlate(h0, 1 - h0, mode='full')
    m_range = np.arange(-(n-1), n)
    
    h = cp.Variable(n)
    t = cp.Variable()
    constraints = [h >= 0, h <= 1, cp.sum(h) == n/2]
    
    for k in range(2*n - 1):
        shift = k - (n - 1)
        # Linearize corr[k] at h0
        # corr[k] = sum_i h[i] * (1-h[i+shift])
        # ≈ sum_i [h0[i]*(1-h0[i+shift]) + (1-h0[i+shift])*h[i] - h0[i]*h[i+shift]]
        # = corr0[k] + sum_i [(1-h0[i+shift])*h[i] - h0[i]*h[i+shift]]
        
        # Compute the linear coefficient for each h[i]
        # h[i] appears in: (1-h0[i+shift])*h[i] - h0[i-shift]*h[i]
        # (the second term comes from the -h0[i']*h[i'+shift] term where i'+shift = i, so i' = i-shift)
        
        coeff = np.zeros(n)
        idx = np.arange(n)
        ip = idx + shift  # i + shift
        im = idx - shift  # i - shift
        
        # (1 - h0[i+shift]) term: valid when 0 <= i+shift < n
        mask_p = (ip >= 0) & (ip < n)
        coeff[mask_p] += (1 - h0[ip[mask_p]])
        
        # -h0[i-shift] term: valid when 0 <= i-shift < n
        mask_m = (im >= 0) & (im < n)
        coeff[mask_m] -= h0[im[mask_m]]
        
        constraints.append(cp.sum(coeff * h) + corr0[k] * dx <= t)
    
    prob = cp.Problem(cp.Minimize(t), constraints)
    prob.solve(solver=cp.GLOP)  # or CPLEX, GUROBI if available
    
    if t.value is not None and h.value is not None:
        h_new = np.clip(h.value, 0, 1)
        h_new = project_feasible(h_new, n)
        return h_new
    return h0
```

```python
    return float(np.max(c) * dx)

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h, 0.0, 1.0).copy()
    for _ in range(100):
        diff = target - h.sum()
        if abs(diff) < 1e-12:
            break
        if diff > 0:
            room = 1.0 - h
            s = room.sum()
            if s < 1e-14:
                break
            h += diff / s * room
        else:
            s = h.sum()
            if s < 1e-14:
                break
            h += diff / s * h
    return np.clip(h, 0.0, 1.0)

    idx = np.argsort(h)[::-1]

    h_b[idx[:n // 2]] = 1.0
    return h_b

def slsqp_opt(h, n, alpha, maxiter, ftol):
    dx = 2.0 / n
    def obj(x):
        g = np.correlate(x, 1.0 - x, mode='full') * dx
        m = g.max()
        shifted = alpha * (g - m)
        sm = shifted.max()
        logsum = sm + np.log(np.exp(shifted - sm).sum())
        return m + logsum / alpha
    def cons_fun(x):
        return x.sum() - n / 2.0
    bounds = [(0.0, 1.0)] * n

    try:
        res = minimize(obj, h, method='SLSQP', bounds=bounds,
                       constraints=cons, options={'maxiter': maxiter, 'ftol': ftol})
        return project_feasible(res.x, n)

        return h
```

**Alternative: Frank-Wolfe (Conditional Gradient) method**

The Frank-Wolfe method works for minimizing a convex function over a convex polytope. Our problem is non-convex, but we can apply it to the linearized subproblem at each SCA iteration.

At each SCA iteration:
1. Linearize the objective: L(h) = max_k [corr0[k] + grad_k^T (h - h0)]
2. This is a convex function (max of linear functions)
3. Minimize L(h) over the polytope P = {h: 0≤h≤1, sum(h)=n/2}

The Frank-Wolfe step:
- Given current h_t, find the "linear minimizer" s_t = argmin_{s∈P} ∇L(h_t)^T s
- Update: h_{t+1} = (1-γ_t) h_t + γ_t s_t

The linear minimizer over P:
min_s grad^T s subject to 0≤s≤1, sum(s)=n/2

This is: set s[i] = 1 for the n/2 smallest components of grad, and s[i] = 0 for the rest. (If there are ties at the boundary, we can split.)

This is O(n log n) per Frank-Wolfe step (for the sorting)!

This is MUCH faster than solving an LP! Let me implement this.

```python
def frank_wolfe_sca(h0, n, max_iter=1000, deadline=None):
    """SCA with Frank-Wolfe inner solves"""
    dx = 2.0 / n
    h = h0.copy()
    prev_c = compute_c5(h, n)
    
    for it in range(max_iter):
        if deadline and time.time() > deadline:
            break
        
        # Compute corr and active lag
        corr = np.correlate(h, 1 - h, mode='full')
        k_star = np.argmax(corr)
        s_shift = k_star - (n - 1)
        
        # Compute gradient of f_{k_star} at h
        idx = np.arange(n)
        ip = idx + s_shift
        im = idx - s_shift
        grad = np.zeros(n)
        mp = (ip >= 0) & (ip < n)
        mm = (im >= 0) & (im < n)
        grad[mp] += (1.0 - h[ip[mp]])
        grad[mm] -= h[im[mm]]
        
        # Frank-Wolfe: find s = argmin grad^T s s.t. 0≤s≤1, sum(s)=n/2
        # s[i] = 1 for n/2 smallest grad components
        sorted_idx = np.argsort(grad)
        s = np.zeros(n)
        s[sorted_idx[:n//2]] = 1.0
        
        # Step size: backtracking line search
        # Full step: gamma = 2/(t+2) for FW, or backtracking
        best_gamma = 0.0
        best_val = compute_c5(h, n)
        for gamma in [1.0, 0.5, 0.25, 0.1, 0.05]:
            h_try = (1 - gamma) * h + gamma * s
            h_try = np.clip(h_try, 0, 1)
            h_try = project_feasible(h_try, n)
            val = compute_c5(h_try, n)
            if val < best_val:
                best_val = val
                best_gamma = gamma
        
        if best_gamma > 0:
            h = (1 - best_gamma) * h + best_gamma * s
            h = np.clip(h, 0, 1)
            h = project_feasible(h, n)
            prev_c = best_val
        else:
            # No improvement with this gradient direction
            # Try a different active lag
            # Or just stop
            break
    
    return h, compute_c5(h, n)
```

The gradient of the log-sum-exp:
f(h) = m + (1/alpha) * log(sum_k exp(alpha * (c_k - m)))
where m = max_k c_k, c_k = corr[k]*dx

∂f/∂h[i] = sum_k w_k * ∂c_k/∂h[i]
where w_k = exp(alpha*(c_k - m)) / sum_j exp(alpha*(c_j - m))

This is a convex combination of the individual gradients! So the gradient computation is:
1. Compute all c_k (one np.correlate call)
2. Compute weights w_k (exp and normalize)
3. Compute gradient as weighted sum of individual gradients

Step 3 is O(n²) in the worst case (summing over all k). But we can optimize:
grad[i] = sum_k w_k * [(1-h[i+s_k])*[valid] - h[i-s_k]*[valid]]
= sum_k w_k * (1-h[i+s_k])*[valid_p] - sum_k w_k * h[i-s_k]*[valid_m]

For the first term: sum_k w_k * (1-h[i+s_k]) * [0≤i+s_k<n]
= sum_{s: 0≤i+s<n} w_{s+n-1} * (1-h[i+s])

This is like a weighted correlation of w with (1-h)! Specifically:
first_term[i] = (w * (1-h))[i] (cross-correlation at a specific lag)

Wait, let me think more carefully. For a fixed i:
sum_k w_k * (1-h[i+s_k]) * [0≤i+s_k<n]

where s_k = k - (n-1). So i+s_k = i + k - n + 1. Let j = i + k - n + 1, so k = j - i + n - 1.

sum_{j: 0≤j<n} w_{j-i+n-1} * (1-h[j]) * [valid k]

This is: (1-h) * w convolution at a specific offset. It's like a cross-correlation.

Actually, this is getting complicated. Let me just do it in a vectorized way:

```python
def compute_lse_gradient(h, n, alpha):
    """Compute gradient of log-sum-exp smoothed objective"""
    dx = 2.0 / n
    corr = np.correlate(h, 1 - h, mode='full') * dx
    m = corr.max()
    shifted = alpha * (corr - m)
    sm = shifted.max()
    weights = np.exp(shifted - sm)
    weights /= weights.sum()
    
    n_corr = 2 * n - 1
    grad = np.zeros(n)
    idx = np.arange(n)
    
    for k in range(n_corr):
        if weights[k] < 1e-10:
            continue
        s = k - (n - 1)
        ip = idx + s
        im = idx - s
        mp = (ip >= 0) & (ip < n)
        mm = (im >= 0) & (im < n)
        grad[mp] += weights[k] * (1.0 - h[ip[mp]])
        grad[mm] -= weights[k] * h[im[mm]]
    
    return grad
```

This is O(n * n_corr) = O(n²) in the worst case. For n=400, that's 160K operations. With the sparsity check (weights[k] < 1e-10), it's typically much faster when alpha is large (only a few lags have significant weight).

Then the Frank-Wolfe step is:
1. Compute gradient: O(n²) but often much less
2. Find s = top-n/2: O(n log n)
3. Line search: a few O(n²) correlation computations

Total per FW step: O(n²) ≈ 160K for n=400. Very fast!

We can do thousands of FW steps in the time budget. This is much better than SLSQP!
