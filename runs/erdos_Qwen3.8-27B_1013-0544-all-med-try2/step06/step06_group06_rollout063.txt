Let me use a smarter approach: only evaluate a subset of candidates, or use the analytical derivative to quickly assess which swaps are promising.

For a swap (i: 0→1, j: 1→0), the change in g_k (for the "generic" case where no boundary effects) is:
Δg_k = dx * (h[j+s_k] - h[i+s_k])

where s_k = k - (n-1).

So the new g_k = g_k + dx * (h[j+s_k] - h[i+s_k]) for the affected k values.

The max of the new g can be bounded: new_max <= max(max(g_k + dx*(h[j+s_k]-h[i+s_k]) for affected k), max(g_k for unaffected k))

This gives a quick filter: if the upper bound is already >= current max, skip this candidate.

Let me implement this efficiently:

For each i in zeros, I can precompute the vector d_i[k] = h[clamp(i+s_k, 0, n-1)] (with appropriate boundary handling).
For each j in ones, d_j[k] = h[clamp(j+s_k, 0, n-1)].

Then for the swap (i, j): new_g[k] = g[k] + dx*(d_j[k] - d_i[k]) for affected k.

The affected k are those where i+s_k is valid OR j+s_k is valid.

1. For the binary local search, use a "greedy" approach:

   - For each k that achieves (or nearly achieves) the max, find the swap that most reduces g_k
   - Try that swap

```python
    return float(np.max(np.correlate(h, 1-h, mode='full')) * dx)

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h, 0.0, 1.0)
    for _ in range(500):
        diff = target - h.sum()
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            room = 1.0 - h
            if room.sum() < 1e-14: break
            h += diff / room.sum() * room
        else:
            if h.sum() < 1e-14: break
            h += diff / h.sum() * h
    return np.clip(h, 0.0, 1.0)

    g = np.correlate(h, 1-h, mode='full') * (2.0/n)
```

```python
def softmax_grad(h, n, alpha):
    g = np.correlate(h, 1-h, mode='full') * (2.0/n)
    m = g.max()
    p = np.exp(alpha*(g - m))
    p /= p.sum()
    dx = 2.0/n
    grad = np.zeros(n)
    for k in range(2*n-1):
        pk = p[k]
        if pk < 1e-15: continue
        s = k - (n-1)
        # Term 1: (1-h[j+s]) for j where 0<=j+s<n
        # j+s >= 0 → j >= -s; j+s < n → j < n-s
        # j in [max(0, -s), min(n-1, n-1-s)]
        t1_min = max(0, -s)
        t1_max = min(n-1, n-1-s)
        if t1_min <= t1_max:
            grad[t1_min:t1_max+1] += pk * dx * (1 - h[t1_min+s:t1_max+1+s])
        # Term 2: -h[j-s] for j where 0<=j-s<n
        # j-s >= 0 → j >= s; j-s < n → j < n+s
        # j in [max(0, s), min(n-1, n-1+s)]
        t2_min = max(0, s)
        t2_max = min(n-1, n-1+s)
        if t2_min <= t2_max:
            grad[t2_min:t2_max+1] -= pk * dx * h[t2_min-s:t2_max+1-s]
    return grad
```
