Let me also think about a **custom projected gradient method** that might be more effective:

The subgradient of max_k f_k(h) at h is the average of the gradients of the active functions (those achieving the max). We can compute this:
- For each active lag k, the gradient of f_k w.r.t. h is:
  - For k=0: (1-2h) * dx
  - For k≠0: a vector that's (1-h[shifted])*dx in one part and -h[shifted]*dx in another part

Then we take a step in the negative subgradient direction and project.

```python
def subgradient_minimize(h, n, n_iters, deadline, step_init=0.01):
    dx = 2.0 / n
    best_h = h.copy()
    best_c = compute_c5(h, n)
    step = step_init
    
    for it in range(n_iters):
        if time.time() > deadline:
            break
        corr = np.correlate(h, 1-h, mode='full') * dx
        max_val = corr.max()
        # Active set: lags within 1% of max
        active = corr > max_val - 0.01 * max_val
        
        # Compute subgradient (average of active gradients)
        grad = np.zeros(n)
        for idx in np.where(active)[0]:
            k = idx - (n - 1)
            if k == 0:
                grad += (1.0 - 2.0 * h) * dx
            elif k > 0:
                # f_k = sum_{i=0}^{n-1-k} h[i]*(1-h[i+k])
                # df/dh[i] = (1-h[i+k]) for i in [0, n-1-k]
                #          - h[i-k] for i in [k, n-1] (from the h[i-k]*(1-h[i]) term)
                grad[:n-k] += (1.0 - h[k:]) * dx
                grad[k:] -= h[:n-k] * dx
            else:
                ak = -k
                # f_k = sum_{i=ak}^{n-1} h[i]*(1-h[i-ak])
                # df/dh[i] = (1-h[i-ak]) for i in [ak, n-1]
                #          - h[i+ak] for i in [0, n-1-ak]
                grad[ak:] += (1.0 - h[:-ak]) * dx
                grad[:n-ak] -= h[ak:] * dx
        grad /= np.sum(active)
        
        h = project_feasible(h - step * grad, n)
        c = compute_c5(h, n)
        if c < best_c:
            best_c, best_h = c, h.copy()
        
        # Decay step size
        step *= 0.999
    
    return best_h, best_c
```
