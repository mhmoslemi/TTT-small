The second condition is: corr[k] + Δr[k] < M for all k, which means Δr[k] < M - corr[k] for all k.

This is hard to check efficiently without computing all of Δr.

Alternative: just compute the full Δr vector (O(n)) and check the max of corr + Δr.

Let me vectorize the Δr computation:

```python
def compute_delta_corr(h, i, j, d, n):
    """Compute the change in correlation when h[i]+=d, h[j]-=d."""
    g = 1.0 - h
    offset = n - 1
    delta = np.zeros(2*n-1)
    
    # h[i] += d contributes d * g[i+lag] for valid lag
    # i+lag in [0, n-1] => lag in [-i, n-1-i]
    # corr index = lag + offset in [offset-i, offset+n-1-i] = [n-1-i, 2n-2-i]
    lo = max(0, n-1-i)
    hi = min(2*n-2, 2*n-2-i)
    if lo <= hi:
        lags = np.arange(lo, hi+1) - offset  # these are the lag values
        idx = i + lags  # indices into g
        valid = (idx >= 0) & (idx < n)
        delta[lo:hi+1][valid] += d * g[idx[valid]]
    
    # g[i] -= d contributes -d * h[i-lag] for valid lag
    # i-lag in [0, n-1] => lag in [i-n+1, i]
    # corr index in [offset+i-n+1, offset+i] = [i, n-1+i]
    lo = max(0, i)
    hi = min(2*n-2, n-1+i)
    if lo <= hi:
        lags = np.arange(lo, hi+1) - offset
        idx = i - lags
        valid = (idx >= 0) & (idx < n)
        delta[lo:hi+1][valid] -= d * h[idx[valid]]
    
    # h[j] -= d contributes -d * g[j+lag]
    lo = max(0, n-1-j)
    hi = min(2*n-2, 2*n-2-j)
    if lo <= hi:
        lags = np.arange(lo, hi+1) - offset
        idx = j + lags
        valid = (idx >= 0) & (idx < n)
        delta[lo:hi+1][valid] -= d * g[idx[valid]]
    
    # g[j] += d contributes d * h[j-lag]
    lo = max(0, j)
    hi = min(2*n-2, n-1+j)
    if lo <= hi:
        lags = np.arange(lo, hi+1) - offset
        idx = j - lags
        valid = (idx >= 0) & (idx < n)
        delta[lo:hi+1][valid] += d * h[idx[valid]]
    
    return delta
```

This is O(n) per pair move, which is a huge improvement over O(n²) for the full correlate.

Now for the pair search, the algorithm becomes:
1. Precompute corr = np.correlate(h, 1-h, mode='full')
2. For each pair (i, j) with i < j:

This is O(n) per pair try, so O(n³) per pass (n² pairs * n per pair). For n=250, that's 15.6M per pass, which should be very fast (under 1 second in numpy).
