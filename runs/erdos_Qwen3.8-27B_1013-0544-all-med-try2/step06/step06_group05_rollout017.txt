```python
def lp_linearize_step(h, n, active_threshold=0.005):
    dx = 2.0 / n
    c_vals = np.correlate(h, 1 - h, mode='full') * dx
    max_c = c_vals.max()
    active = np.where(c_vals >= max_c - active_threshold)[0]
    
    # Build LP: min t
    # s.t. for k in active: c_k + grad_k · (h_new - h) <= t
    #      0 <= h_new <= 1
    #      sum(h_new) = n/2
    #
    # Variables: h_new[0..n-1], t
    # Constraints: |active| + 2n + 1
    
    # Gradient of f_k at h:
    # ∂f_k/∂h[m] = dx * [(1 - h[m+k]) - h[m-k]] (with zero padding)
    
    import cvxpy as cp
    
    h_new = cp.Variable(n)
    t = cp.Variable()
    
    constraints = [h_new >= 0, h_new <= 1, cp.sum(h_new) == n/2]
    
    # Pad h for easy indexing
    n_pad = 2 * n - 1
    hp = np.zeros(n_pad)
    hp[n-1:n-1+n] = h
    
    for idx in active:
        k = idx - (n - 1)  # actual shift
        m = np.arange(n)
        grad = dx * ((1 - hp[m + k + n - 1]) - hp[m - k + n - 1])
        constraints.append(c_vals[idx] + grad @ (h_new - h) <= t)
    
    prob = cp.Problem(cp.Minimize(t), constraints)
    prob.solve(solver=cp.ECOS)  # or CBC, or GLOP
    
    if h_new.value is not None and np.all(np.isfinite(h_new.value)):
        return np.clip(h_new.value, 0, 1)
    return h.copy()
```

```python
                idx_maxD = np.argmax(D)
                idx_minD = np.argmin(D)
                u_cross = (c_vals[idx_minD] - c_vals[idx_maxD]) / (D[idx_maxD] - D[idx_minD])
                candidates.append(u_cross)
            
            best_delta = 0
            best_val = np.inf
            for d in candidates:
                if d < delta_min - 1e-10 or d > delta_max + 1e-10:
                    d = np.clip(d, delta_min, delta_max)
                val = np.max(c_vals + d * D)
                if val < best_val:
                    best_val = val
                    best_delta = d
            
            if best_val < best_c - 1e-12:
                best_c = best_val
                best_move = (i, j, best_delta)
    
    return best_move, best_c
```

This is O(n²) per call, with each inner iteration being O(n) (for computing D and evaluating the max). Total: O(n³) per call = 250³ = 15.6M operations. In numpy, this should take maybe 1-5 seconds.

But wait, I'm computing D inside the inner loop, which allocates a new array each time. That's 62500 array allocations of size 499. This might be slow due to memory allocation overhead.

Let me vectorize: precompute the "D contribution" of each position, then combine.

For position i, define:
- A[i] = (1 - hp[i:i+2n-1])  (the "1-h[i+k]" part)
- B[i] = hp[i:i+2n-1][::-1]  (the "h[i-k]" part)

Then D_{ij} = A[i] - B[i] - A[j] + B[j] = (A[i] - A[j]) - (B[i] - B[j])

So I can precompute A and B (each is n × (2n-1) = 250 × 499 ≈ 125K values, total 250K). That's fine memory-wise.

Then for each pair (i,j), D = (A[i] - A[j]) - (B[i] - B[j]) = (A[i] - B[i]) - (A[j] - B[j]) = C[i] - C[j] where C[i] = A[i] - B[i].

Wait, that's NOT right. Let me redo:
D_{ij}[k] = (1-h[i+k]) - h[i-k] - (1-h[j+k]) + h[j-k]
           = [(1-h[i+k]) - h[i-k]] - [(1-h[j+k]) - h[j-k]]
           = C[i][k] - C[j][k]

where C[i][k] = (1-h[i+k]) - h[i-k] for k in [-(n-1), n-1].

So C is an n × (2n-1) matrix, and D_{ij} = C[i] - C[j].

Then the objective for a move from j to i is:
max_k [c[k] + δ * (C[i][k] - C[j][k])]

And I need to find the best (i, j, δ) triple.

This is now O(n²) pairs × O(1) to form D (just subtract two precomputed rows) × O(n) to evaluate the max = O(n³) total. But the constant is small since it's all numpy operations on vectors of length 499.

For n=250: 250² * 499 ≈ 31M floating point operations. In numpy, this should take 1-3 seconds. That's acceptable for a few iterations.

But actually, I realize that just finding the BEST pair is expensive. What I really want is to do many rounds of:
1. Find a good (i,j,δ) move
2. Apply it
3. Update c_vals and C
4. Repeat

Each round is O(n²) for the search + O(n) for the update. So O(n²) per round, and I can do many rounds.

Actually, updating C after changing h[i] by δ and h[j] by -δ:
- C[i][k] changes by: (1-(h[i]+δ+k)) - (h[i]+δ-k) ... wait, C[i] depends on h at positions i±k, not on h[i] itself (unless k=0).

Hmm, C[i][k] = (1-h[i+k]) - h[i-k]. If I change h[i] by δ, then C[i'[k'] changes for positions where i'+k' = i or i'-k' = i, i.e., i' = i-k' or i' = i+k'. So ALL rows of C change!

This makes the update expensive. Let me just recompute C after each move: O(n * (2n-1)) = O(n²) per update.

Total per iteration: O(n²) for finding best move + O(n²) for update = O(n²). For n=250, that's ~125K operations per iteration. I can do thousands of iterations easily.

Wait, finding the best move is O(n² * (2n-1)) = O(n³) if I evaluate the max for each pair. Let me think of a faster way.

For a fixed i, the best j is the one that minimizes max_k [c[k] + δ * (C[i][k] - C[j][k])] over j and δ.

This is hard to do in sub-quadratic time. But for n=250, O(n³) ≈ 15M operations is fine (takes <1 second in numpy).

Let me just go with the straightforward approach:

def pair_optimize(h, n, deadline, max_rounds=1000):
    dx = 2.0 / n
    best_c = compute_c5(h, n)
    best_h = h.copy()
    n_pad = 2 * n - 1
    
    for round_num in range(max_rounds):

            break
        
        hp = np.zeros(n_pad)
        hp[n-1:n-1+n] = h
        c_vals = np.correlate(h, 1 - h, mode='full') * dx
        
        # Precompute C: C[i][k_idx] = (1-h[i+k]) - h[i-k]
        # k_idx = k + (n-1), k in [-(n-1), n-1]
        # h[i+k] = hp[i+k+n-1] -> for k_idx: hp[i + k_idx]
        # h[i-k] = hp[i-k+n-1] -> for k_idx: hp[i + 2*(n-1) - k_idx] = hp[i + n_pad - 1 - k_idx]
        
        # C[i] = 1 - hp[i:i+n_pad] (for the i+k part, valid when i+k < n, i.e., handled by padding)
        # Wait, I need to be careful with bounds. Let me use the padding approach.
        
        # Actually, let me just compute C in a vectorized way:
        # C[i][k_idx] where k_idx = 0..n_pad-1 corresponds to k = k_idx - (n-1)
        # h[i+k] = h[i + k_idx - (n-1)] which in hp is at position i + k_idx - (n-1) + (n-1) = i + k_idx
        # So (1-h[i+k]) = 1 - hp[i + k_idx] for k_idx = 0..n_pad-1
        # But i + k_idx can go up to i + n_pad - 1 = i + 2n - 2, and hp has length 2n-1
        # So valid for i + k_idx < 2n-1, i.e., k_idx < 2n-1-i
        # For k_idx >= 2n-1-i, h[i+k] = 0 (out of range), so 1-h[i+k] = 1
        
        # Similarly, h[i-k] = h[i - k_idx + (n-1)] which in hp is at position i - k_idx + (n-1) + (n-1) = i + 2(n-1) - k_idx
        # Valid when 0 <= i + 2(n-1) - k_idx < 2n-1
        # i.e., i + 2n - 2 - (2n-1+1) < k_idx <= 2n-2-i
        # i.e., i - 1 < k_idx <= 2n-2-i
        # For k_idx outside this range, h[i-k] = 0

        # Pad h with zeros on both sides
        # hp2 = [0, 0, ..., 0, h[0], h[1], ..., h[n-1], 0, 0, ..., 0] with n-1 zeros on each side
        # Then h[i+k] = hp2[(i+n-1) + k] for any k, and h[i-k] = hp2[(i+n-1) - k]
        # C[i][k_idx] where k = k_idx - (n-1):
        #   (1-h[i+k]) = 1 - hp2[i+n-1+k] = 1 - hp2[i+n-1+k_idx-(n-1)] = 1 - hp2[i+k_idx]
        #   h[i-k] = hp2[(i+n-1)-(k_idx-(n-1))] = hp2[i+2(n-1)-k_idx]
        
        # So C[i] = 1 - hp2[i:i+n_pad] and hp2[i+2(n-1):i+2(n-1)-n_pad+1:-1]
        # = 1 - hp2[i:i+n_pad] and hp2[i:i+n_pad][::-1]
        
        # This is the same as before. Let me just compute it directly:
        
        A = 1.0 - hp[np.arange(n)[:,None] + np.arange(n_pad)[None,:]]  # A[i][k_idx] = 1 - hp[i+k_idx]
        # But this might go out of bounds! hp has length n_pad = 2n-1
        # i + k_idx can be at most (n-1) + (2n-2) = 3n-3, which exceeds 2n-2 for n > 1
        # So I need to handle bounds.
        
        # Let me use np.take with mode='clip' or just pad more.
        
        # Alternative: use a larger padding
        n_pad2 = 3 * n - 1  # This is enough: max index is (n-1) + (2n-2) = 3n-3 < 3n-1 ✓
        hp2 = np.zeros(n_pad2)
        hp2[n:n+n] = h  # h is at positions n, n+1, ..., 2n-1
        
        # Now h[i+k] where k = k_idx - (n-1):
        # h[i+k] = hp2[(n+i) + (k_idx-(n-1))] = hp2[n+i+n-1+k_idx-(n-1)] = hp2[n+i+k_idx]
        # Wait, let me redo. If h[t] is stored at hp2[n+t], then:
        # h[i+k] = hp2[n + (i+k)] = hp2[n + i + k_idx - (n-1)] = hp2[i + 1 + k_idx]
        # h[i-k] = hp2[n + (i-k)] = hp2[n + i - k_idx + (n-1)] = hp2[2n-1 + i - k_idx]
        
        # k_idx ranges from 0 to 2n-2
        # i + 1 + k_idx ranges from i+1 to i+1+2n-2 = i+2n-1. Max is (n-1)+2n-1 = 3n-2 < 3n-1 ✓
        # 2n-1 + i - k_idx ranges from 2n-1+i-(2n-2) to 2n-1+i = i+1 to 2n-1+i

        idx1 = np.arange(n)[:,None] + 1 + np.arange(2*n-1)[None,:]  # shape (n, 2n-1), for h[i+k]

        A = 1.0 - hp2[idx1]  # A[i][k_idx] = 1 - h[i+k]
        B = hp2[idx2]  # B[i][k_idx] = h[i-k]
