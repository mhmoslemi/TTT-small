2. Find the top K shifts (e.g., K=5 or K=10)
3. Minimize the maximum of just those K correlations (using a smooth max or even just their average)
4. This gives a direction to move
5. Project and repeat

This is much more efficient because we only need to compute gradients for K correlations instead of all 2n-1.

Actually, even better: at the optimum, the subgradient condition says that 0 must be in the convex hull of the active gradients. So if I can find a set of weights w on the active constraints such that ∑ w_k * grad_k = 0 (on the interior), I'm at a local optimum.

```python
def active_set_gradient(h, n, K=10):
    """Compute gradient using only top-K active constraints."""
    dx = 2.0 / n
    c = np.correlate(h, 1.0 - h, mode='full') * dx
    
    # Get top K shifts
    top_k = np.argsort(c)[::-1][:K]
    
    # Equal weights (or softmax weights for top K)
    c_top = c[top_k]
    alpha = 100  # sharp
    w = np.exp(alpha * (c_top - c_top.max()))
    w /= w.sum()
    
    # Compute gradient: grad[j] = dx * sum_k w_k * [(1-h[j+s_k]) - h[j-s_k]]
    grad = np.zeros(n)
    for idx in range(K):
        s = top_k[idx] - (n - 1)  # actual shift
        w_k = w[idx] * dx
        # (1-h[j+s]) for valid j+s
        for j in range(max(0, -s), min(n, n-s)):
            grad[j] += w_k * (1 - h[j+s])
        # -h[j-s] for valid j-s
        for j in range(max(0, s), min(n, n+s)):
            grad[j] -= w_k * h[j-s]
    return grad, c
```
