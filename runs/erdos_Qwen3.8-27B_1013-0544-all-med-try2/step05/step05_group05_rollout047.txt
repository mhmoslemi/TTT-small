   A practical approach: use ternary search or binary search on the subgradient. The subgradient at v is the set of a(k,i) for k that achieve the max. If the subgradient contains 0, we're at the optimum. If all subgradients are positive, decrease v; if all negative, increase v.

                   a[ks + n - 1] += (1.0 - h[idx]) * dx

               k2_lo = max(-(n-1), -i)
               k2_hi = min(n-1, n-1-i)

                   idx = i + ks  # valid indices for h

               # = max_k (corr[k] + a[k]*(v - h[i]))
               base = corr - a * h[i]
               # Minimize max_k (base[k] + a[k]*v) over v in [0,1]
               # This is a 1D convex problem
               # Use binary search on the "crossing point"
               # At v=0: max_k base[k]
               # At v=1: max_k (base[k] + a[k])

               # For convex piecewise linear, it's at a point where the
               # subgradient straddles 0.

                       hi = mid  # Need to decrease v

                       improved = True
                   # else: keep the change (might help in next sweep)

               break
       return h, best_c

   Let me also think about a different approach: **bisection on t with LP relaxation**.

   For a given t, can we find h such that all correlations ≤ t? This is:
   min t subject to:
   - For all k: sum_{valid j} h[j+k]*(1-h[j])*dx ≤ t
   - 0 ≤ h[i] ≤ 1
   - sum(h) = n/2

   The constraint sum_{valid j} h[j+k]*(1-h[j])*dx ≤ t is:
   sum h[j+k]*dx - sum h[j+k]*h[j]*dx ≤ t
   
   The term sum h[j+k]*h[j] is a product of two variables, making this non-convex.

   However, if we use the trick of introducing auxiliary variables z_jk = h[j+k]*h[j], we get a bilinear constraint which is still non-convex.

   So LP relaxation won't directly work. But we could use a different approach:

   **Semidefinite programming (SDP) relaxation**: Introduce X = h*h^T (outer product). Then h[j+k]*h[j] = X[j+k, j]. The constraint becomes:
   sum_j h[j+k]*dx - sum_j X[j+k,j]*dx ≤ t
   
   This is linear in h and X! And we have the constraint X = h*h^T (rank-1 PSD). If we relax the rank constraint to just X ⪰ 0 and trace(X) = sum(h²) ≤ sum(h) = n/2 (since h[i]² ≤ h[i] for h[i] ∈ [0,1]), we get an SDP relaxation.

   But this is a large SDP (n×n matrix), and for n=250, that's 62500 variables plus 250 more. This might be too slow with the available solvers.

   Now let me think about the incremental correlation update for binary swaps.

   If we swap h[i] and h[j] (or set h[i]=1, h[j]=0), the change in correlation c(k) is:
   Δc(k) = a(k,i) * Δh[i] + a(k,j) * Δh[j]
   
   where a(k,i) is the coefficient of h[i] in c(k), as computed above.

   So for a swap (h[i] += δ, h[j] -= δ):
   Δc(k) = (a(k,i) - a(k,j)) * δ
   
   We want to find if there exists a swap that reduces the max. This can be checked by:
   - For each pair (i,j), compute the change in the max correlation
   - If the max decreases, perform the swap

   But checking all O(n²) pairs is expensive. A heuristic: only check pairs where i is at a "high" correlation position and j is at a "low" one.

   Actually, for binary solutions, the swap is h[i]: 0→1 and h[j]: 1→0. The change in c(k) is:
   Δc(k) = a(k,i) - a(k,j) (since δ=1)
   
   We want max_k (c(k) + a(k,i) - a(k,j)) < max_k c(k).
   
   This means for all k with c(k) = max: c(k) + a(k,i) - a(k,j) < max, i.e., a(k,i) - a(k,j) < 0 for all active k.
   And for other k: c(k) + a(k,i) - a(k,j) ≤ max (which is usually automatically satisfied if c(k) < max).

   So the condition is: for all active lags k*, a(k*,i) < a(k*,j).

   This is a useful criterion! We can precompute a(k,i) for all i and the active k's, then quickly check which swaps would help.

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h, n):
    dx = 2.0 / n
    return float(np.max(np.correlate(h, 1.0 - h, mode='full') * dx))

def compute_corr(h, n):
    dx = 2.0 / n
    return np.correlate(h, 1.0 - h, mode='full') * dx

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h, 0.0, 1.0)
    for _ in range(200):
        diff = target - h.sum()
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            room = 1.0 - h
            s = room.sum()
            if s < 1e-14:
                break
            h += diff / s * room
        else:
            s = h.sum()
            if s < 1e-14:
                break
            h += diff / s * h
    return np.clip(h, 0.0, 1.0)

def coeff_a(h, n, i):
    """Compute a(k, i) for all lags k (index = k + n - 1 in the corr array)."""
    dx = 2.0 / n
    a = np.zeros(2 * n - 1)
    # Term 1: (1-h[i-k])*dx for k where 0 <= i-k <= n-1
    # k ranges from i-(n-1) to i
    k1_lo = max(0, i - (n - 1))
    k1_hi = min(i, n - 1)
    if k1_hi >= k1_lo:
        ks = np.arange(k1_lo, k1_hi + 1)
        a[ks + n - 1] += (1.0 - h[i - ks]) * dx
    # Term 2: -h[i+k]*dx for k where 0 <= i+k <= n-1
    k2_lo = max(-(n - 1), -i)
    k2_hi = min(n - 1, n - 1 - i)
    if k2_hi >= k2_lo:
        ks = np.arange(k2_lo, k2_hi + 1)
        a[ks + n - 1] -= h[i + ks] * dx
    return a

def coord_descent(h, n, deadline, max_sweeps=500):
    """Coordinate descent with exact 1D minimization."""
    dx = 2.0 / n
    corr = compute_corr(h, n)
    best_c = corr.max()
    
    for sweep in range(max_sweeps):
        if time.time() > deadline:
            break
        sweep_improved = False
        for i in range(n):
            if time.time() > deadline:
                break
            a = coeff_a(h, n, i)
            base = corr - a * h[i]
            # Minimize max_k (base[k] + a[k]*v) over v in [0,1]
            lo, hi = 0.0, 1.0
            for _ in range(50):
                mid = (lo + hi) / 2.0
                vals = base + a * mid
                smax = vals.max()
                max_mask = vals >= smax - 1e-13
                amin = a[max_mask].min()
                amax = a[max_mask].max()
                if amin <= 0 and amax >= 0:
                    lo = hi = mid
                    break
                elif amin > 0:
                    hi = mid
                else:
                    lo = mid
            v_new = (lo + hi) / 2.0
            delta = v_new - h[i]
            if abs(delta) > 1e-10:
                h[i] = v_new
                corr += a * delta
                c_new = corr.max()
                if c_new < best_c - 1e-15:
                    best_c = c_new
                    sweep_improved = True
        if not sweep_improved:
            break
    
    # Verify
    corr = compute_corr(h, n)
    best_c = corr.max()
    return h, best_c

def subgrad_polish(h0, n, deadline, max_iter=100000):
    best_h = h0.copy()
    best_c = compute_c5(best_h, n)
    lr = 0.05
    dx = 2.0 / n
    for it in range(max_iter):
        if time.time() > deadline:
            break
        corr = compute_corr(best_h, n)
        m = corr.max()
        k = int(np.argmax(corr))
        lag = k - (n - 1)
        grad = np.zeros(n)
        if lag >= 0:
            grad[lag:] += dx * (1.0 - best_h[:n - lag])
            grad[:n - lag] -= dx * best_h[lag:]
        else:
            to = -lag
            grad[:n - to] += dx * (1.0 - best_h[to:])
            grad[to:] -= dx * best_h[:n - to]
        ng = np.linalg.norm(grad)
        if ng < 1e-14:
            break
        grad /= ng
        found = False
        for f in [1.0, 0.5, 0.25, 0.1, 0.05, 0.01, 0.005, 0.001]:
            step = lr * f
            ht = project_feasible(best_h - step * grad, n)
            ct = compute_c5(ht, n)
            if ct < m - 1e-13:
                best_h = ht
                found = True
                break
        if not found:
            lr *= 0.9
            if lr < 1e-13:
                break
        else:
            c = compute_c5(best_h, n)
            if c < best_c:
                best_c = c
    return best_h, best_c

def binary_local_search_fast(h0, n, deadline, max_sweeps=5000, seed=123):
    """Binary local search with incremental correlation update."""
    target = n // 2
    idx = np.argsort(h0)[::-1]
    h_bin = np.zeros(n)
    h_bin[idx[:target]] = 1.0
    corr = compute_corr(h_bin, n)
    best_c = corr.max()
    rng = np.random.RandomState(seed)
    
    # Precompute a(k,i) for all i
    # This is expensive for large n, so we'll compute on the fly
    for sweep in range(max_sweeps):
        if time.time() > deadline:
            break
        ones = np.where(h_bin == 1)[0]
        zeros = np.where(h_bin == 0)[0]
        rng.shuffle(ones)
        rng.shuffle(zeros)
        improved = False
        m = corr.max()
        # Find active lags
        active = np.where(corr >= m - 1e-12)[0]
        
        for i in zeros:
            if time.time() > deadline or improved:
                break
            a_i = coeff_a(h_bin, n, i)
            for j in ones:
                # For binary: h[i] 0->1, h[j] 1->0
                # Delta corr = a_i - a_j (since delta_i = 1, delta_j = -1)
                a_j = coeff_a(h_bin, n, j)
                delta_corr = a_i - a_j
                new_corr = corr + delta_corr
                new_m = new_corr.max()
                if new_m < m - 1e-14:
                    h_bin[i] = 1.0
                    h_bin[j] = 0.0
                    corr = new_corr
                    m = new_m
                    best_c = m
                    improved = True
                    break
    return h_bin, best_c

def slsqp_opt(h0, n, alpha, maxiter, deadline):
    dx = 2.0 / n
    def obj(x):
        corr = np.correlate(x, 1.0 - x, mode='full') * dx
        g = corr
        m = g.max()
        sh = g - m
        return m + (sh.max() + np.log(np.exp(sh - sh.max()).sum())) / alpha
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': lambda x: x.sum() - n / 2.0}]
    try:
        res = minimize(obj, h0, method='SLSQP', bounds=bounds,
                       constraints=cons, options={'maxiter': maxiter, 'ftol': 1e-16})
        return project_feasible(res.x, n)
    except Exception:
        return h0

- Term 1: (1-h[i-k])*dx = dx if h[i-k]=0, 0 if h[i-k]=1
- Term 2: -h[i+k]*dx = -dx if h[i+k]=1, 0 if h[i+k]=0

So a(k,i) = dx * (1_{h[i-k]=0} - 1_{h[i+k]=1}) for valid indices.

For binary h, a(k,i) ∈ {-dx, 0, dx}.

And delta_corr(k) = a(k,i) - a(k,j) ∈ {-2dx, -dx, 0, dx, 2dx}.

The key check is: max_k (corr[k] + a(k,i)[k] - a(k,j)[k]) < corr.max().

For this to hold, we need: for all k where corr[k] = max, a(k,i) - a(k,j) < 0 (strictly, or ≤ -ε for numerical safety).

And for other k: corr[k] + a(k,i) - a(k,j) ≤ max + ε (usually satisfied since corr[k] < max).

So the check reduces to: for all active k, a(k,i) < a(k,j) (with some margin).
