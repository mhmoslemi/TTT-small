The dual of the minimax problem (with the simplex constraint on λ) is:
max_{λ≥0, Σλ=1} min_{h: sum(h)=n/2, 0≤h≤1} Σ_k λ_k f_k(h)

The inner problem is:
min_h q(h) s.t. sum(h) = n/2, 0 ≤ h ≤ 1
where q(h) = Σ_k λ_k * corr_k(h) * dx

Since corr_k(h) = Σ_i h[i] - Σ_i h[i]h[i+k] (for appropriate ranges), we have:
q(h) = (n/2) * dx - dx * Σ_k λ_k Σ_i h[i]h[i+k]

So we're maximizing dx * Σ_k λ_k Σ_i h[i]h[i+k] = dx * h^T Q_λ h
where Q_λ is a symmetric matrix determined by λ.

This is a non-convex QP (maximizing a quadratic). However, we can use an alternating approach:
1. Given λ, solve the inner QP (approximately)
2. Update λ to be proportional to the current f_k values (like in a multiplicative weight update)
3. Iterate

For step 1, since it's non-convex, we can use:
- Projected gradient on the QP
- Or linearize the quadratic and solve the resulting QP
- Or use a trust-region method

def min_norm_subgrad(gradients, n):
    """Find minimum-norm convex combination of gradients."""
    m = len(gradients)
    if m == 1:
        return gradients[0]
    # Solve: min ||G^T λ||^2 s.t. sum(λ)=1, λ>=0
    # where G is n x m
    G = np.column_stack(gradients)  # n x m
    # QP: min λ^T (G^T G) λ s.t. 1^T λ = 1, λ >= 0
    # Use scipy
    from scipy.optimize import minimize as minscipy
    def qp_obj(lamb):
        v = G.T @ lamb
        return v @ v
    def qp_grad(lamb):
        return 2 * G @ (G.T @ lamb)
    cons = [{'type': 'eq', 'fun': lambda l: np.sum(l) - 1, 'jac': lambda l: np.ones(m)}]

    l0 = np.ones(m) / m

def grad_lag(h, L, n):
    g = np.zeros(n)
    om = 1.0 - h
    if L == 0:
        g[:] = om - h
    elif L > 0:
        g[L:] += om[:n-L]
        g[:n-L] -= h[L:]
    else:
        L2 = -L
        g[:n-L2] += om[L2:]
        g[L2:] -= h[:n-L2]
    return g
