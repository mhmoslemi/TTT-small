For the projected subgradient method:
- We want to minimize f(h) = max_k c_k(h) * dx subject to sum(h) = n/2, 0≤h≤1
- Subgradient of f at h: let K = argmax_k c_k * dx. Then ∇f = (dx) * (1/|K|) ∑_{k∈K} ∇c_k
  (subaverage of the active gradients)
- ∇c_k[j] = (1-h[j-k]) * 1[j-k valid] - h[j+k] * 1[j+k valid]
  (using the convention corr[m] = ∑_n h[n+m]*(1-h[n]), lag = m-(n-1))

Actually, let me use a simpler formulation. Let me just use the index directly.

corr[m] = ∑_n h[n+m] * (1-h[n]) for m = 0,...,2n-2 (numpy's correlate with mode='full')

∂corr[m]/∂h[j] = from term n+m=j: (1-h[n]) = (1-h[j-m]) [if 0≤j-m<n]
                + from term n=j: -h[n+m] = -h[j+m] [if 0≤j+m<n]

So ∂corr[m]/∂h[j] = (1-h[j-m]) * [0≤j-m<n] - h[j+m] * [0≤j+m<n]

For the subgradient method:
1. Compute corr = correlate(h, 1-h, 'full')
2. Find active set: K = {m : corr[m] = max(corr)} (or top few)
3. Compute subgradient: grad[j] = mean over m in K of ∂corr[m]/∂h[j]
4. Step: h_new = h - alpha * grad
5. Project: h_new = project_feasible(h_new, n)
6. Update alpha (e.g., alpha_t = c / (t + 1) or backtracking)

For the projection onto {sum(h) = n/2, 0≤h≤1}, the project_feasible function handles this (it's the Euclidean projection onto the intersection of the box and the hyperplane).

Actually, the exact projection onto {0≤h≤1, sum(h)=S} is:
- Find λ such that ∑ clip(h_i - λ, 0, 1) = S
- This can be done by bisection on λ.

        if x.sum() > S:
            lo = mid
        else:
            hi = mid
    return np.clip(h - (lo+hi)/2, 0, 1)

For a given lag, the gradient contribution is:

For the first term: j-lag ranges from 0 to n-1, so j ranges from max(0,lag) to min(n-1, n-1+lag).

def slsqp_smooth(h, n, alpha, maxiter, ftol):
    dx = 2.0 / n
    def obj(x):
        g = np.correlate(x, 1.0 - x, mode='full') * dx
        m = g.max()
        shifted = alpha * (g - m)
        sm = shifted.max()
        return m + (sm + np.log(np.exp(shifted - sm).sum())) / alpha
    def cons_fun(x):
        return x.sum() - n / 2.0
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': cons_fun}]
    try:
        res = minimize(obj, h, method='SLSQP', bounds=bounds,
                       constraints=cons, options={'maxiter': maxiter, 'ftol': ftol})
        return project_box_sum(np.clip(res.x, 0, 1), n / 2.0)
