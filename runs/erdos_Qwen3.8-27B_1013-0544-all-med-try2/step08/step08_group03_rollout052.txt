$$f_k(h) = \sum_i h[i](1-h[i+k])$$

The gradient of f_k with respect to h[j]:
- If j appears as h[i] (first factor): derivative is (1-h[j+k])
- If j appears as h[i+k] (second factor): derivative is -h[j-k]

So:
$$\frac{\partial f_k}{\partial h[j]} = \sum_{i: i=k...} (1-h[i+k]) \cdot \delta_{j,i} + \sum_{i: i+k=j} (-h[i]) \cdot \delta_{j,i+k}$$

More carefully:
$$f_k = \sum_i h[i](1-h[i+k])$$

For a specific index j:
- j appears in h[i] when i=j: contributes (1-h[j+k]) if j+k is in range
- j appears in h[i+k] when i+k=j, i.e., i=j-k: contributes -h[j-k] if j-k is in range

So:
$$\frac{\partial f_k}{\partial h[j]} = (1-h[j+k])\cdot\mathbf{1}[0\leq j+k < n] + (-h[j-k])\cdot\mathbf{1}[0\leq j-k < n]$$

- j+k < n means j < n-k = nv
- j-k ≥ 0 means j ≥ k

So for k ≥ 0:

def compute_c5_vec(h, n):
    dx = 2.0 / n
    return sp_correlate(h, 1.0 - h, mode='full', method='fft') * dx

def compute_c5(h, n):
    return float(np.max(compute_c5_vec(h, n)))

def project_euclidean(h, n):
    target = n / 2.0
    h = np.asarray(h, dtype=float)
    lo = -2.0
    hi = 3.0
    for _ in range(80):
        mid = (lo + hi) / 2.0
        s = np.clip(h - mid, 0.0, 1.0).sum()
        if s > target:
            lo = mid
        else:
            hi = mid
    h_p = np.clip(h - (lo + hi) / 2.0, 0.0, 1.0)
    diff = target - h_p.sum()
    if abs(diff) > 1e-12:
        free = (h_p > 1e-10) & (h_p < 1.0 - 1e-10)
        if free.sum() > 0:
            h_p[free] += diff / free.sum()
