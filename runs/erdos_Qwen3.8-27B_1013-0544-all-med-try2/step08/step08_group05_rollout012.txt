def slsqp_smooth(h, n, alpha, maxiter, deadline):
    dx = 2.0 / n
    def obj(x):
        c = np.correlate(x, 1 - x, mode='full') * dx
        m = c.max()
        a = alpha * (c - m)
        sm = a.max()
        return m + (sm + np.log(np.exp(a - sm).sum())) / alpha

    h = np.zeros(n)
    idx = np.argsort(h_init)[::-1]
    h[idx[:target]] = 1.0
    
    dx = 2.0 / n
    best_c = np.inf
    best_h = h.copy()
    rng = np.random.RandomState(seed)
    
    for restart in range(n_restarts):
        if time.time() > deadline:
            break
        if restart > 0:
            # Perturb: swap random pairs
            current_h = best_h if restart == 1 else h
            for _ in range(rng.randint(2, 6)):
                oi = np.where(current_h == 1)[0]
                zi = np.where(current_h == 0)[0]
                if len(oi) > 0 and len(zi) > 0:
                    a = rng.choice(oi)
                    b = rng.choice(zi)
                    current_h[a], current_h[b] = 0.0, 1.0
            h = current_h.copy()
        else:
            h = h_init.copy()
            h = np.where(h >= 0.5, 1.0, 0.0)
            # Ensure exact count
            s = h.sum()
            if s > target:
                ones = np.where(h == 1)[0]
                extra = int(s - target)
                for idx_r in rng.choice(ones, extra, replace=False):
                    h[idx_r] = 0.0
            elif s < target:
                zeros = np.where(h == 0)[0]
                need = int(target - s)
                for idx_r in rng.choice(zeros, need, replace=False):
                    h[idx_r] = 1.0
        
        out = np.correlate(h, 1 - h, mode='full').astype(float)
        cur_max = out.max()
        
        A = precompute_A(h, n)
        ones_idx = np.where(h == 1)[0]
        zeros_idx = np.where(h == 0)[0]
        
        no_improve = 0
        for sweep in range(max_sweeps):
            if time.time() > deadline:
                break
            improved = False
            # For each zero, find best one to swap with
            for i in zeros_idx:
                if time.time() > deadline - 1:
                    break
                Bi = out + A[i, :]
                # For all ones, compute new max
                new_maxs = (Bi[None, :] - A[ones_idx, :]).max(axis=1)
                j_idx = np.argmin(new_maxs)
                j = ones_idx[j_idx]
                new_max_val = new_maxs[j_idx]
                
                if new_max_val < cur_max - 1e-10:
                    # Accept swap
                    h[i] = 1.0
                    h[j] = 0.0
                    out = out + A[i, :] - A[j, :]
                    cur_max = new_max_val
                    # Update sets
                    zeros_idx = np.setdiff1d(zeros_idx, [i])
                    ones_idx = np.setdiff1d(ones_idx, [j])
                    ones_idx = np.concatenate([ones_idx, [i]])
                    # Recompute A (expensive but necessary)
                    A = precompute_A(h, n)
                    improved = True
                    break
            if not improved:
                break
            no_improve = 0
        else:
            no_improve += 1
        
        if cur_max * dx < best_c:
            best_c = cur_max * dx
            best_h = h.copy()
    
    return best_h, best_c

Actually, let me think about this more carefully. The objective is:
f(h) = max_k c_k(h) * dx

where c_k(h) = sum_i h[i] * (1-h[i-k]) is the k-th correlation coefficient.

For a fixed coordinate i, c_k(h) as a function of h[i] is:
c_k(h) = h[i] * (1-h[i-k]) + (terms not involving h[i])
= h[i] - h[i]*h[i-k] + const_k

Wait, h[i] appears in c_k in two ways:
1. As h[i] itself: contributes h[i] * (1-h[i-k]) to c_k (for valid i-k)
2. In (1-h[i]) when another term h[i+k] is multiplied by (1-h[i])

So c_k is actually quadratic in h[i]! Specifically:
c_k(h) = h[i]*(1-h[i-k]) + (1-h[i])*h[i+k] + (other terms)
= h[i] - h[i]*h[i-k] + h[i+k] - h[i]*h[i+k] + (other)
= h[i] - h[i]*(h[i-k] + h[i+k]) + h[i+k] + (other)

So for fixed other coordinates, c_k is a quadratic (concave) function of h[i]. The max of concave functions is not necessarily concave.

This means coordinate descent with line search could work, but the 1D subproblem is not trivially solvable.

Let me try a different approach: **simulated annealing on the continuous space**.

Or better: use the **Dinkelbach iteration** idea. The problem is:
minimize max_k c_k subject to constraints

This is equivalent to: find the minimum t such that there exists h with c_k(h) ≤ t for all k and the constraints hold.

For a fixed t, checking feasibility is: does there exist h with:
- 0 ≤ h_i ≤ 1
- sum(h) = n/2
- c_k(h) ≤ t for all k

The constraint c_k(h) ≤ t is: sum_i h[i] - sum_i h[i]*h[i+k] ≤ t
⟺ sum_i h[i]*h[i+k] ≥ sum_i h[i] - t

This is a set of quadratic inequality constraints, which makes it non-convex.

Let me also think about a key insight: the problem has a natural "dual" interpretation. 

C₅ = max_k ∫ h(x)(1-h(x+k)) dx

If we think of h as a probability density (after scaling), this is the expected value of (1-h) at position x+k given that h is "on" at x. We want to minimize the maximum "avoidance" across all shifts.

For a periodic function with period 2, the "ideal" solution would have h(x) + h(x+k) = 1 for all x and k simultaneously, which is impossible unless h is constant 1/2. But with the constraint ∫h = 1 (i.e., average = 1/2), the constant h=1/2 gives C₅ = ∫ (1/2)(1/2) dx = 1/2 * 2 * 1/4 = 1/4... wait that's not right.

For h = 1/2 everywhere: c_k = ∫ (1/2)(1-1/2) dx = ∫ 1/4 dx = 1/4 * 2 = 1/2. Wait no.

c_k = ∫₀² h(x)(1-h(x+k)) dx

For h = 1/2: c_k = ∫₀² (1/2)(1/2) dx = ∫₀² 1/4 dx = 1/2.

So C₅ = 1/2 for the constant solution. The optimal is ~0.38, which is significantly better.

Now, for a binary solution with exactly n/2 ones:
c_k = dx * (number of i with h[i]=1 and (1-h[i+lag])=1)
= dx * (number of pairs (i, i+lag) where h[i]=1 and h[i+lag]=0)

We want to minimize the maximum of this across all lags.

For a "well-distributed" binary sequence, this should be close to (n/2) * (n/2) / n * dx = (n/4) * (2/n) = 1/2... that's the random expectation.

But structured sequences can do much better. The key is to have the ones "aligned" with other ones at all lags simultaneously, which is the "Bose-Chaudhuri-Hocquenghem" type structure.

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(c) * dx)

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h, 0.0, 1.0)
    for _ in range(300):
        diff = target - h.sum()
        if abs(diff) < 1e-13:
            break
        if diff > 0:
            room = 1.0 - h
            s = room.sum()
            if s < 1e-14:
                break
            h = np.clip(h + (diff / s) * room, 0, 1)
        else:
            s = h.sum()
            if s < 1e-14:
                break
            h = np.clip(h + (diff / s) * h, 0, 1)
    return h

def slsqp_smooth(h, n, alpha, maxiter):
    dx = 2.0 / n
    def obj(x):
        c = np.correlate(x, 1 - x, mode='full') * dx
        m = c.max()
        a = alpha * (c - m)
        a_max = a.max()
        return m + (a_max + np.log(np.exp(a - a_max).sum())) / alpha
    def cons(x):
        return x.sum() - n / 2.0
    bounds = [(0.0, 1.0)] * n
    try:
        res = minimize(obj, h, method='SLSQP', bounds=bounds,
                       constraints=[{'type': 'eq', 'fun': cons}],
                       options={'maxiter': maxiter, 'ftol': 1e-14})
        if res.x is not None and res.fun < float('inf'):
            return project_feasible(res.x, n)
    except Exception:
        pass
    return h

def binary_round(h, n):
    target = n // 2
    idx = np.argsort(h)[::-1]
    b = np.zeros(n)
    b[idx[:target]] = 1.0
    return b

def precompute_delta_matrix(h, n):
    """A[p, k] = change in corr[k] from flipping position p (0->1)."""
    lags = np.arange(-(n - 1), n)
    pos = np.arange(n)[:, None]
    ip = pos + lags[None, :]
    im = pos - lags[None, :]
    hpad = np.zeros(3 * n)
    hpad[n:2*n] = h
    return (1.0 - hpad[n + ip]) - hpad[n + im]

def binary_local_search(h, n, deadline, max_iters=10000, seed=42):
    """Fast binary local search with vectorized evaluation."""
    target = n // 2
    h = binary_round(h, n)
    dx = 2.0 / n
    out = np.correlate(h, 1 - h, mode='full').astype(float)
    cur = out.max()
    A = precompute_delta_matrix(h, n)
    ones = np.where(h == 1)[0]
    zeros = np.where(h == 0)[0]
    rng = np.random.RandomState(seed)
    best_cur = cur
    best_h = h.copy()
    stalls = 0
    
    for it in range(max_iters):
        if time.time() > deadline:
            break
        if stalls > 200:
            break
        # Find best swap
        best_new = cur
        best_i = -1
        best_j = -1
        # Sample zeros for speed
        if len(zeros) > 40:
            sample = rng.choice(zeros, 40, replace=False)
        else:
            sample = zeros
        for i in sample:
            Bi = out + A[i, :]
            new_maxs = (Bi[None, :] - A[ones, :]).max(axis=1)
            j_idx = np.argmin(new_maxs)
            if new_maxs[j_idx] < best_new - 1e-12:
                best_new = new_maxs[j_idx]
                best_i = i
                best_j = ones[j_idx]
        
        if best_i >= 0:
            h[best_i], h[best_j] = 1.0, 0.0
            out = out + A[best_i, :] - A[best_j, :]
            cur = best_new
            A = precompute_delta_matrix(h, n)
            ones = np.where(h == 1)[0]
            zeros = np.where(h == 0)[0]
            stalls = 0
        else:
            stalls += 1
            # Perturb to escape local optimum
            if len(ones) > 0 and len(zeros) > 0:
                n_swaps = rng.randint(1, 4)
                for _ in range(n_swaps):
                    a = rng.choice(ones)
                    b = rng.choice(zeros)
                    h[a], h[b] = 0.0, 1.0
                out = np.correlate(h, 1 - h, mode='full').astype(float)
                cur = out.max()
                A = precompute_delta_matrix(h, n)
                ones = np.where(h == 1)[0]
                zeros = np.where(h == 0)[0]
        
        if cur * dx < best_cur * dx:
            best_cur = cur
            best_h = h.copy()
    
    return best_h, best_cur * dx

def subgradient_step(h, n, lr, t):
    """One subgradient step for min max_k c_k."""
    dx = 2.0 / n
    c = np.correlate(h, 1 - h, mode='full')
    k_max = np.argmax(c)
    lag = k_max - (n - 1)
    # Subgradient of c_k_max w.r.t. h
    # c_k = sum_i h[i] * (1-h[i+lag])
    # dc_k/dh[i] = (1-h[i+lag]) - h[i-lag] (with bounds)
    sg = np.zeros(n)
    for i in range(n):
        ip = i + lag
        im = i - lag
        term1 = (1 - h[ip]) if (0 <= ip < n) else 1
        term2 = h[im] if (0 <= im < n) else 0
        sg[i] = term1 - term2
    # Normalize
    sgn = np.linalg.norm(sg)
    if sgn > 0:
        h = h - lr * sg / sgn
    return project_feasible(h, n)
