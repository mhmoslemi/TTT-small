Actually, for the coordinate descent, the key operation for variable i is:
- Given current corr, and the "B" vector (how corr changes when h[i] changes), find h[i] that minimizes max(corr + B * h[i]).

This is: minimize max_k (corr[k] + B[k] * x) over x in [0,1].

This is a 1D optimization! We can solve it exactly:
- The function f(x) = max_k (corr[k] + B[k] * x) is convex in x (max of linear functions).
- The minimum of a convex piecewise-linear function on [0,1] occurs at a breakpoint or at the boundary.
- Breakpoints occur where two lines cross: corr[k1] + B[k1]*x = corr[k2] + B[k2]*x
- x = (corr[k2] - corr[k1]) / (B[k1] - B[k2])

So we can:
1. Evaluate f at x=0 and x=1
2. Check if the minimum is at a breakpoint: find the x where the "upper envelope" changes
3. The minimum of the upper envelope is at x* where the subgradient contains 0, i.e., there exist k1, k2 with B[k1] < 0 < B[k2] and corr[k1] + B[k1]*x* = corr[k2] + B[k2]*x*

For the 1D convex problem min_{x in [0,1]} max_k (a_k + b_k * x):
- If all b_k >= 0: minimum at x=0
- If all b_k <= 0: minimum at x=1
- Otherwise: the minimum is at x* = (a_j - a_i) / (b_i - b_j) where i,j are the two "active" constraints at the optimum, clipped to [0,1].

Finding the exact optimum requires identifying the upper envelope, which is O(n log n) using a convex hull trick, or O(n^2) naively.
