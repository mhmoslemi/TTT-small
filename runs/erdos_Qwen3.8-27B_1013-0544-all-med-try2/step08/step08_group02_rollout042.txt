The key optimization: precompute for each position i the vector Δc_i (the change in c when h[i] flips from 1 to 0). Then for a swap (i→0, j→1), Δc = Δc_i + Δc_j where Δc_j is the negative of the flip from 0 to 1.

Wait, Δc for flipping h[i] from 1 to 0 is:
Δc_k^(i, 1→0) = h[i+k] - 1 + h[i-k] (with boundary = 0)

And flipping h[j] from 0 to 1 is:
Δc_k^(j, 0→1) = 1 - h[j+k] - h[j-k] (with boundary = 0)

So total Δc_k = [h[i+k] - 1 + h[i-k]] + [1 - h[j+k] - h[j-k]]
              = h[i+k] + h[i-k] - h[j+k] - h[j-k]

For binary h, this simplifies further:
h[i+k] + h[i-k] - h[j+k] - h[j-k] ∈ {-2, -1, 0, 1, 2}

So for each position i, I can precompute the vector v_i where v_i[k] = h[i+k] + h[i-k] (with out-of-bounds = 0). This is a vector of length 2n-1.

Then for a swap (i, j): Δc = v_i - v_j, and new_c = c + v_i - v_j.
new_max = max(c + v_i - v_j)

This is O(n) per swap, and we can precompute all v_i in O(n²).

For n=500, precomputing is 250K operations (fast), and each swap evaluation is O(n) = O(500).

A full local search evaluating all n²/4 ≈ 62500 swaps would be 62500 * 500 = 31M operations. In numpy, if we vectorize, this could be done in a few seconds.

- For each position m: v[m, k] changes if i+s_k == m or i-s_k == m

  - i-s_k == m → s_k = i-m → k = i-m+(n-1). If valid, v[m, k] -= 1

So for each position i that flips, we update v[m, k] for O(n) values of m (specifically, m = i+s for valid s, and m = i-s for valid s).

Actually, v[m, k] = h[m+s_k] + h[m-s_k]. If h[i] changes by δ (from 1 to 0, δ=-1), then:
v[m, k] changes by δ if m+s_k = i (i.e., m = i-s_k) or m-s_k = i (i.e., m = i+s_k).

So for each k:
- m1 = i - s_k: if valid (0<=m1<n), v[m1, k] += δ
- m2 = i + s_k: if valid (0<=m2<n), v[m2, k] += δ

This is O(2n) updates per flip, which is O(n) per flip. Much better than O(n²)!

f(x) = (mean(c(x)^p))^(1/p) where c(x) = correlate(x, 1-x, 'full')

df/dx_j = (1/p) * (mean(c^p))^(1/p - 1) * d(mean(c^p))/dx_j
        = (1/p) * (mean(c^p))^(1/p - 1) * (1/(2n-1)) * sum_k p * c_k^(p-1) * dc_k/dx_j
        = (mean(c^p))^(1/p - 1) * (1/(2n-1)) * sum_k c_k^(p-1) * dc_k/dx_j

So the "weights" are w_k = c_k^(p-1) / sum(c_j^(p-1)), and the gradient is:
grad_j = (mean(c^p))^(1/p - 1) * sum_k w_k * dc_k/dx_j

The factor (mean(c^p))^(1/p - 1) is a scalar that doesn't affect the direction, only the magnitude. For L-BFGS-B, this is fine since the algorithm adapts to the scale.

So I can just compute: grad_j = sum_k w_k * dc_k/dx_j where w_k = c_k^(p-1) / sum(c_j^(p-1))

def compute_c5(h, n):
    dx = 2.0 / n
    return float(np.max(np.correlate(h, 1 - h, mode='full')) * dx)

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h.copy(), 0.0, 1.0)
    for _ in range(500):
        diff = target - h.sum()
        if abs(diff) < 1e-12:
            break
        if diff > 0:
            room = np.where(h < 1.0, 1.0 - h, 0.0)
            tot = room.sum()
            if tot < 1e-14:
                break
            h += (diff / tot) * room
        else:
            mask = h > 0.0
            tot = h[mask].sum()
            if tot < 1e-14:
                break
            h[mask] += (diff / tot) * h[mask]
    return np.clip(h, 0.0, 1.0)

def pm_obj(x, n, p, mu):
    c = np.correlate(x, 1 - x, mode='full')
    c_pos = np.maximum(c, 1e-12)
    val = float(np.mean(c_pos ** p) ** (1.0 / p))
    s = x.sum() - n / 2.0
    return val + mu * s * s

def pm_grad(x, n, p, mu):
    c = np.correlate(x, 1 - x, mode='full')
    c_pos = np.maximum(c, 1e-12)
    w = c_pos ** (p - 1)
    ws = w.sum()
    w = w / ws if ws > 1e-30 else np.ones(len(c)) / len(c)
    grad = np.zeros(n)
    center = n - 1
    for k in range(len(c)):
        wm = w[k]
        if wm < 1e-15:
            continue
        s = k - center
        if s >= 0:
            nv = n - s
            grad[:nv] += wm * (1.0 - x[s:])
            grad[s:] -= wm * x[:nv]
        else:
            ss = -s
            nv = n - ss
            grad[ss:] += wm * (1.0 - x[:nv])
            grad[:nv] -= wm * x[ss:]
    s_val = x.sum() - n / 2.0
    grad += 2.0 * mu * s_val
    return grad

    """v[i,k] = h[i+s_k] + h[i-s_k] where s_k = k-(n-1), OOB=0"""
    n_c = 2 * n - 1
    shifts = np.arange(n_c) - (n - 1)
    rows = np.arange(n)[:, None]
    idx1 = rows + shifts
    mask1 = (idx1 >= 0) & (idx1 < n)
    idx2 = rows - shifts
    mask2 = (idx2 >= 0) & (idx2 < n)
    v = np.where(mask1, h[np.clip(idx1, 0, n-1)], 0.0)
    v += np.where(mask2, h[np.clip(idx2, 0, n-1)], 0.0)
    return v

def update_v(v, idx, delta, n):
    n_c = 2 * n - 1
    shifts = np.arange(n_c) - (n - 1)
    m1 = idx - shifts
    mask1 = (m1 >= 0) & (m1 < n)
    cols1 = np.where(mask1)[0]
    v[m1[mask1], cols1] += delta
    m2 = idx + shifts
    mask2 = (m2 >= 0) & (m2 < n)
    cols2 = np.where(mask2)[0]
    v[m2[mask2], cols2] += delta

def binary_ls(h, n, deadline, rng, max_rounds=200):
    h = h.copy().astype(float)
    # Ensure binary
    h[h > 0.5] = 1.0
    h[h <= 0.5] = 0.0
    # Fix count
    target = n // 2
    cnt = int(h.sum())
    if cnt > target:
        ones = np.where(h == 1)[0]
        for i in rng.choice(ones, cnt - target, replace=False):
            h[i] = 0
    elif cnt < target:
        zeros = np.where(h == 0)[0]
        for j in rng.choice(zeros, target - cnt, replace=False):
            h[j] = 1
    c = np.correlate(h, 1 - h, mode='full')
    best_c5 = float(np.max(c) * 2.0 / n)
    v = flip_vectors(h, n)
    for _ in range(max_rounds):
        if time.time() > deadline:

        ones = np.where(h == 1)[0]
        zeros = np.where(h == 0)[0]
        if len(ones) == 0 or len(zeros) == 0:

        cur_max = np.max(c)
        best_impr = 1e-15
        best_i, best_j = -1, -1
        n_try = min(len(ones) * len(zeros), 30000)
