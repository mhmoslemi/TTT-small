```python
        B = np.zeros((len(idx), 2*n-1))

            ps = p - s
            pp = p + s

            B[i, vm] += h[pp[vm]]

            pp = p + s
```

For the fine local search, I should use the gradient to guide the search. The gradient tells me which direction to move. Then I only try a few specific moves per iteration.

Better approach for local search:
1. Compute the gradient of the smooth max
2. The gradient points in the direction of increase of the objective
3. To decrease the objective, I should move in the -gradient direction
4. But I need to maintain the constraint sum(h) = n/2
5. So I project the -gradient onto the constraint: subtract the mean
6. Then take a small step in that direction
7. Project back to [0,1] and sum = n/2

This is essentially projected gradient descent, which is what L-BFGS-B is already doing. The issue is that L-BFGS-B might get stuck in a local minimum of the smoothed objective that's not the true minimum of the max.

A better approach: use the subgradient of the TRUE max (not smoothed). The subdifferential of max(f₁, ..., fₘ) at a point where f₁ = f₂ = ... = fₖ = max is the convex hull of {∇f₁, ..., ∇fₖ}. So I can:
1. Identify the active set (shifts where c[k] is within ε of max)
2. Compute the average gradient of the active constraints
3. Take a step in the -average gradient direction (projected to maintain constraints)

This is like a "top-k" subgradient method.

Let me implement this:

```python
def subgrad_active(h, n, deadlock, top_k=20, steps=1000):
    best_c = compute_c5(h, n)
    c = np.correlate(h, 1.0 - h, mode='full') * (2.0 / n)
    
    for step in range(steps):
        if time.time() > deadline:
            break
        # Find active set
        m = c.max()
        active = np.where(c >= m - 1e-10)[0]
        # Compute average gradient of active constraints
        grad = np.zeros(n)
        for m_idx in active:
            s = m_idx - (n - 1)
            if s >= 0:
                nv = n - s
                grad[s:] += (1.0 - h[:nv])
                grad[:nv] -= h[s:]
            else:
                ss = -s
                nv = n - ss
                grad[:nv] += (1.0 - h[ss:])
                grad[ss:] -= h[:nv]
        grad /= (len(active) * (2.0/n))  # normalize
        # Project gradient to maintain sum constraint
        grad -= grad.mean()
        # Try a few step sizes
        for lr in [0.01, 0.005, 0.001, 0.0001]:
            h_new = h - lr * grad
            h_new = project_feasible(h_new, n)
            c_new = compute_c5(h_new, n)
            if c_new < best_c:
                best_c = c_new
                h = h_new
                c = np.correlate(h, 1.0 - h, mode='full') * (2.0 / n)
                break
    
    return h, best_c
```

```python
def make_B(idx_arr, h_arr, n, s):
    # idx_arr: array of indices
    # Returns B[i, m] = h_arr[idx_arr[i] - s[m]] + h_arr[idx_arr[i] + s[m]] (0 if out of range)
    n_idx = len(idx_arr)
    B = np.zeros((n_idx, 2*n-1))
    # idx_arr[:, None] - s[None, :] gives a (n_idx, 2n-1) matrix
    ps = idx_arr[:, None] - s[None, :]
    pp = idx_arr[:, None] + s[None, :]

    vm_p = (pp >= 0) & (pp < n)
    B[vm_s] = h_arr[ps[vm_s]]  # This doesn't work because of the 2D indexing
    # Need to do it differently
    B += h_arr[np.clip(ps, 0, n-1)] * vm_s
    B += h_arr[np.clip(pp, 0, n-1)] * vm_p
    return B
```
