For the local search, here's a key insight: if the max is achieved at a unique lag k*, then the subgradient is just ∂c[k*]/∂h. We can do a very targeted search:
- Find the best single coordinate move (change h[i] by d, adjust h[j] by -d)
- The optimal d can be found analytically for a single active constraint

For a single active constraint at lag k*:
f(h) = c[k*](h) = sum_n h[n+k*] * (1-h[n])

If we change h[a] += d and h[b] -= d:
f_new = f_old + d*(1-h[a-k*]) - d*h[a+k*] - d*(1-h[b-k*]) + d*h[b+k*]
= f_old + d * [(1-h[a-k*]) - h[a+k*] - (1-h[b-k*]) + h[b+k*]]
= f_old + d * [1-h[a-k*]-h[a+k*]-1+h[b-k*]+h[b+k*]]
= f_old + d * [h[b-k*]+h[b+k*]-h[a-k*]-h[a+k*]]

So the change is linear in d! The optimal d is:
- If the coefficient is negative: increase d (set h[a] up, h[b] down) as much as possible
- If positive: decrease d (set h[a] down, h[b] up) as much as possible

The maximum d is limited by: h[a]+d <= 1 and h[b]-d >= 0, so d_max = min(1-h[a], h[b]).

This means for a single active constraint, the best pair move is to set d = d_max (go to the boundary)!

But we have multiple active constraints (the max might be achieved or nearly achieved at several lags). So we want to minimize the max of several such linear functions.

This is a linear programming problem in d (for a fixed pair (a,b))! We want to minimize max_j (f_j + d * c_j) where c_j is the coefficient for constraint j.

The optimal d* is where the largest constraint is minimized, which can be found by binary search or by finding the intersection point.

This is a very efficient local search:
1. Identify top T active lags
2. For each pair (a,b) (or a smartly chosen subset), compute coefficients c_j for j=1..T
3. Find optimal d* by solving the 1D LP
4. Apply the best move found

The challenge is step 2: trying all O(n²) pairs is too expensive. Instead, we can:
- For each a, find the best b (the one that gives the most negative min_j c_j * d_max)
- Or use a greedy heuristic

Actually, let me simplify. For the local search, I'll do:
1. Compute the top T active lags
2. Compute the subgradient g = (1/T) * sum of individual gradients
3. Find the best pair (a,b) to swap: a = argmin(g), b = argmax(g)
4. For this pair, compute the optimal d by considering all T active constraints
5. Apply the move

This is O(n) per iteration (for computing g and finding argmin/argmax), plus O(T) for the 1D LP. Very fast!

Let me also add a "diversification" step: periodically try random pair moves to escape local optima.

from scipy.optimize import minimize

def compute_c5_vec(h, n):

    return sp_correlate(h, 1.0 - h, mode='full', method='fft') * dx

def compute_c5(h, n):
    return float(np.max(compute_c5_vec(h, n)))

def project_feasible(h, n):
    h = np.clip(h.copy(), 0.0, 1.0)
    target = n / 2.0
    for _ in range(200):
        diff = target - h.sum()
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            room = 1.0 - h
            tot = room.sum()
            if tot < 1e-14:
                break
            h += (diff / tot) * room
        else:
            tot = h.sum()
            if tot < 1e-14:
                break
            h += (diff / tot) * h
    return np.clip(h, 0.0, 1.0)

def grad_for_lag(h, n, k):
    """Gradient of c_full[m] w.r.t. h, where k = m - (n-1)"""
    nv = n - abs(k)
    grad = np.zeros(n)
    if k >= 0:
        grad[:nv] += 1.0 - h[k:]
        grad[k:] -= h[:nv]
    else:
        kk = -k
        grad[kk:] += 1.0 - h[:nv]
        grad[:nv] -= h[kk:]
    return grad

def active_local_search(h, n, deadline, top_T=10, max_iters=50000):
    """Active-set local search using pair swaps with optimal step."""
    best_h = h.copy()
    best_c = compute_c5(h, n)
    h = h.copy()
    
    for it in range(max_iters):
        if time.time() > deadline:
            break
        
        C = compute_c5_vec(h, n)
        cur_max = C.max()
        if cur_max < best_c - 1e-15:
            best_c = cur_max
            best_h = h.copy()
        
        # Find top T active lags
        top_idx = np.argsort(C)[-top_T:]

        for idx in top_idx:
            k = idx - (n - 1)
            g += grad_for_lag(h, n, k)
        g /= top_T

        a = int(np.argmin(g))
        b = int(np.argmax(g))

            sorted_g = np.argsort(g)
            found = False

                if h[idx_a] < 1.0 - 1e-12:
                    for idx_b in sorted_g[-20:]:
                        if idx_b != idx_a and h[idx_b] > 1e-12:
                            a, b = int(idx_a), int(idx_b)
                            found = True
                            break
                    if found:
                        break
            if not found:
                break

        if d_max < 1e-14:
            break

        # Change in c_full[m] = d * [(1-h[a-m+n-1])*valid1 - h[a+m-n+1]*valid2 
        #                              - (1-h[b-m+n-1])*valid3 + h[b+m-n+1]*valid4]
        # For top T active m values, compute the coefficient
        # We want to minimize max_j (C[j] + d * coeff[j])
        # where coeff[j] is the coefficient of d for that lag
        
        coeffs = np.zeros(len(top_idx))
        for li, m in enumerate(top_idx):
            k = m - (n + 1) + 1  # wait, k = m - (n-1)

            # coeff for h[a] change: (1-h[a-k]) * [0<=a-k<n] - h[a+k] * [0<=a+k<n]
            coeff_a = 0.0
            if 0 <= a - k < n:
                coeff_a += 1.0 - h[a - k]
            if 0 <= a + k < n:
                coeff_a -= h[a + k]
            coeff_b = 0.0
            if 0 <= b - k < n:
                coeff_b += 1.0 - h[b - k]
            if 0 <= b + k < n:
                coeff_b -= h[b + k]
            coeffs[li] = coeff_a - coeff_b  # change when h[a]+=d, h[b]-=d
        
        # Now find d in [0, d_max] that minimizes max_j (C[top_idx[j]] + d * coeffs[j])
        # This is a 1D convex optimization (min of max of linear functions)
        # Binary search on the value, or just try d=0 and d=d_max and the intersection
        
        # Simple approach: the optimal d is where the two largest (C_j + d*c_j) are equal
        # Or we can just do a coarse-to-fine search
        
        # Actually, since it's min max of linear functions in d, the optimal is at an intersection
        # of two of the lines, or at the boundary d=0 or d=d_max
        
        vals_at_0 = C[top_idx]
        vals_at_dmax = C[top_idx] + d_max * coeffs
        
        # If all coeffs are >= 0, the max can only increase, so d=0 is best
        # If all coeffs are <= 0, the max can only decrease, so d=d_max is best
        if np.all(coeffs > -1e-12):

        elif np.all(coeffs < 1e-12):
            d_opt = d_max
        else:
            # Find optimal d by binary search on the subgradient of the max
            lo, hi = 0.0, d_max
            for _ in range(30):
                mid = (lo + hi) / 2
                vals = C[top_idx] + mid * coeffs
                mx = vals.max()
                # Subgradient at mid: max of coeffs at the argmax positions
                active_at_mid = np.where(vals >= mx - 1e-12)[0]
                sg = np.mean(coeffs[active_at_mid])
                if sg > 0:
                    hi = mid
                elif sg < 0:
                    lo = mid
                else:
                    break
            d_opt = (lo + hi) / 2
        
        if d_opt < 1e-12:
            break
        
        # Apply the move
        h[a] += d_opt
        h[b] -= d_opt
        
    h = project_feasible(h, n)
    c = compute_c5(h, n)
    if c < best_c:
        best_c = c
        best_h = h.copy()
    return best_h, best_c

    """Gradient of correlation at shift s w.r.t. h"""
    grad = np.zeros(n)
    if s >= 0:
        nv = n - s
        grad[:nv] += 1.0 - h[s:]
        grad[s:] -= h[:nv]
    else:

        nv = n - ss
        grad[ss:] += 1.0 - h[:nv]

    if 0 <= b + s < n:
        c -= 1.0 - h[b + s]
    if 0 <= b - s < n:

    return c

            coeffs = np.array([coeff_at_shift(h, n, a, int(s)) - coeff_at_shift(h, n, b, int(s)) for s in top_s])
            
            # Solve 1D: min_d max_j (vals[j] + d*coeffs[j]) for d in [0, d_max]
            d_opt_fwd = solve_1d_lp(vals, coeffs, 0.0, d_max)
            
            # Also try reverse: h[a]-=d, h[b]+=d (coefficients negated)
            d_opt_rev = solve_1d_lp(vals, -coeffs, 0.0, d_max)
            
            # Evaluate
            if d_opt_fwd > 0:
                new_max_fwd = (vals + d_opt_fwd * coeffs).max()
            else:
                new_max_fwd = vals.max()
            if d_opt_rev > 0:
                new_max_rev = (vals + d_opt_rev * (-coeffs)).max()
            else:
                new_max_rev = vals.max()
            
            if new_max_fwd < new_max_rev:
                improvement = vals.max() - new_max_fwd
                if improvement > best_improvement:
                    best_improvement = improvement
                    best = (a, b, d_opt_fwd, 1)
            else:
                improvement = vals.max() - new_max_rev
                if improvement > best_improvement:
                    best_improvement = improvement
                    best = (a, b, d_opt_rev, -1)
    
    return best

def solve_1d_lp(vals, coeffs, lo, hi):
    """Solve min_{d in [lo,hi]} max_j (vals[j] + d*coeffs[j])"""
    if np.all(coeffs > -1e-14):
        return 0.0  # Can only increase, so stay at lo
    if np.all(coeffs < 1e-14):
        return hi  # Can only decrease, go to hi
    # Binary search on subgradient
    for _ in range(30):
        mid = 0.5 * (lo + hi)
        v = vals + mid * coeffs
        mx = v.max()
        act = np.where(v >= mx - 1e-12)[0]
        sg = np.mean(coeffs[act])
        if sg > 1e-12:
            hi = mid
        elif sg < -1e-12:
            lo = mid
        else:
            return mid
    return 0.5 * (lo + hi)

def active_local_search(h, n, deadline, T=25):
    best_h = h.copy()
    best_c = compute_c5(h, n)
    h = h.copy()
    stall = 0
    
    while time.time() < deadline:
        C = compute_c5_vec(h, n)
        cur_max = float(C.max())
        if cur_max < best_c - 1e-16:
            best_c = cur_max
            best_h = h.copy()
            stall = 0
        else:
            stall += 1
            if stall > 1000:
                break
        
        # Get top T shifts
        top_m = np.argsort(C)[-T:]
        top_s = top_m - (n - 1)
        
        move = find_best_pair_move(h, n, C, top_s, top_m, T)
        if move is None:
            break
        
        a, b, d, direction = move
        if d < 1e-12:
            break
        
        # Apply move
        if direction == 1:
            h[a] += d
            h[b] -= d
        else:
            h[a] -= d
            h[b] += d
        
    h = project_feasible(h, n)
    c = compute_c5(h, n)
    if c < best_c:
        best_c = c
        best_h = h.copy()
    return best_h, best_c

def frank_wolfe(h, n, deadline):
    best_h = h.copy()
    best_c = compute_c5(h, n)
    
    for it in range(100000):
        if time.time() > deadline:
            break
        
        C = compute_c5_vec(h, n)
        cur_max = C.max()
        if cur_max < best_c - 1e-16:
            best_c = float(cur_max)
            best_h = h.copy()
        
        # Top T for gradient
        T = 20
        top_m = np.argsort(C)[-T:]
        top_s = top_m - (n - 1)
        
        g = np.zeros(n)
        for s in top_s:
            g += grad_shift(h, n, int(s))
        g /= T
        
        # LSS: s[i]=1 for the n/2 indices with smallest g[i]
        idx = np.argsort(g)[:n // 2]
        s_vert = np.zeros(n)
        s_vert[idx] = 1.0
        
        # Step size: backtracking
        t = 2.0 / (it + 2)
        h_new = (1.0 - t) * h + t * s_vert
        c_new = compute_c5(h_new, n)
        
        if c_new < best_c:
            best_c = c_new
            best_h = h_new.copy()
        h = h_new
    
    return best_h, best_c
