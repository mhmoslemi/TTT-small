So the full gradient computation is:
1. Compute c = correlate(h, 1-h, 'full') → O(n log n) with FFT
2. Compute w = softmax(α * (c - c_max)) → O(n)
3. Compute v = 1 - 2*h → O(n)
4. Compute grad = (1/α) * correlate(w, v, 'valid') → O(n log n) with FFT

Total: O(n log n) per gradient evaluation!

Then the optimization loop:
1. Compute gradient: O(n log n)
2. Choose step size (backtracking or diminishing): O(1)
3. Take step: h_new = h - step * grad: O(n)
4. Project onto {0 ≤ h ≤ 1, sum(h) = n/2}: O(n log n) using bisection

For the projection, I need to find h_proj = clip(h - λ, 0, 1) such that sum(h_proj) = n/2.
This is a 1D equation in λ, solvable by bisection in O(log(1/ε) * n) time.

Total per iteration: O(n log n). With n=400, each iteration takes maybe 1-2 μs. So in 100 seconds, I can do ~50 million iterations. That's more than enough.

The question is: will the gradient method actually converge to a good solution? The log-sum-exp smoothing makes the objective smooth, and the gradient method should work well, especially with:
- Adaptive step size (barzilai-borwein or backtracking)
- Momentum (Nesterov acceleration)
- Increasing α over time (to approach the true max)

Let me also think about the binary local search improvement. The key insight is:

**For the binary case, the problem is equivalent to minimizing the maximum "disagreement" between h and its shifted version, where disagreement means one is 0 and the other is 1.**

A good heuristic: at each step, find the current maximum lag k*, then try to reduce c_{k*}. To reduce c_{k*} = ∑_i h[i](1-h[i+k*]):
- Find a position i where h[i]=1 and h[i+k*]=0 (these contribute to c_{k*})
- Swap h[i] with h[i+k*] (turn i from 1 to 0, turn i+k* from 0 to 1)
- This reduces c_{k*} by 1 (the pair (i, i+k*) no longer contributes)
- But it might increase other c_k values

This "targeted swap" heuristic should be much more efficient than random swaps.

import time

def compute_c5(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(c) * dx)

def project_feasible(h, n):
    target = n / 2.0
    h = np.asarray(h, dtype=float)
    # Bisection on shift parameter t: h_proj = clip(h + t, 0, 1), sum = target
    lo, hi = -1.0, 1.0
    for _ in range(60):
        mid = (lo + hi) * 0.5
        s = np.clip(h + mid, 0.0, 1.0).sum()
        if s > target:
            lo = mid
        else:
            hi = mid
    return np.clip(h + (lo + hi) * 0.5, 0.0, 1.0)

def greedy_binary_targeted(h_init, n, deadline, max_sweeps=2000):
    """Binary local search with targeted swaps along max lag direction."""
    dx = 2.0 / n
    h = np.zeros(n)
    idx = np.argsort(h_init)[::-1]
    h[idx[:n//2]] = 1.0
    corr = np.correlate(h, 1.0 - h, mode='full').astype(float)
    cur_c = corr.max() * dx
    best_h = h.copy()
    best_c = cur_c
    ones = np.where(h == 1)[0].tolist()
    zeros = np.where(h == 0)[0].tolist()

        if time.time() > deadline:
            break
        improved = False
        # Find current max lag

                # This is getting complicated. Let me just recompute from scratch for the affected range.

                # The correlation at index m is: sum_l h[l] * (1-h[m-l])

                            pass
                        else:

                # j goes 1->0:

                lo_i = max(0, i)

                    if 0 <= mj < n and mj != j:

                nc = new_corr.max() * dx
                if nc < cur_c - 1e-12:

                    corr = new_corr

                    zeros[ai], ones[bi] = j, i
                    improved = True
                    if cur_c < best_c:
                        best_c = cur_c
                        best_h = h.copy()
        
        if not improved:
            break
    
    return best_h, best_c

import numpy as np
import time

def compute_c5(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(c) * dx)

def project_feasible(h, n):
    target = n / 2.0
    lo, hi = -1.0, 1.0
    for _ in range(50):
        mid = (lo + hi) * 0.5
        s = np.clip(h + mid, 0.0, 1.0).sum()
        if s > target:
            lo = mid
        else:
            hi = mid
    return np.clip(h + (lo + hi) * 0.5, 0.0, 1.0)

def to_binary(h, n):
    idx = np.argsort(h)[::-1]
    h_b = np.zeros(n)
    h_b[idx[:n // 2]] = 1.0
    return h_b

def swap_delta(h, i, j, n):
    """Compute correlation change when h[i]:0->1 and h[j]:1->0."""
    v = 1.0 - 2.0 * h
    delta = np.zeros(2 * n - 1)
    # i: 0->1
    delta[i:i+n] += v
    if 2*i <= 2*n-2:

    # j: 1->0
    delta[j:j+n] -= v
    if 2*j <= 2*n-2:
        delta[2*j] += v[j]
    return delta
