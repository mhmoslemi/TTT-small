Now, ∂c[k]/∂h[i]:
The term h[j]*(1-h[j+m]) contributes to h[i] when:
- j = i: gives (1-h[i+m]) (if i+m is valid)
- j+m = i, i.e., j = i-m: gives -h[i-m] (if i-m is valid)

So ∂c[k]/∂h[i] = dx * [(1-h[i+m]) * I(0≤i+m<n) - h[i-m] * I(0≤i-m<n)]

where m = k - (n-1).

Great, so I can compute the gradient analytically.

Now for the SLSQP formulation:
Variables: h (n variables)
Objective: minimize t (auxiliary variable)
Constraints:
- c[k_i] ≤ t for i = 1,...,M (top M lags)
- sum(h) = n/2
- 0 ≤ h ≤ 1

But SLSQP handles inequality constraints as c(x) ≥ 0, so we'd write t - c[k_i] ≥ 0.

Actually, scipy's SLSQP handles both 'eq' and 'ineq' constraints where 'ineq' means fun(x) ≥ 0.

Let me reformulate:
- Variables: x = [h_0, ..., h_{n-1}, t] (n+1 variables)
- Objective: minimize x[n] (= t)
- Equality constraint: sum(x[0:n]) - n/2 = 0
- Inequality constraints: x[n] - c[k_i](x[0:n]) ≥ 0 for i=1,...,M
- Bounds: 0 ≤ x[i] ≤ 1 for i < n, t ≥ 0

The Jacobian of the objective is [0, 0, ..., 0, 1].
The Jacobian of constraint i is [-dc[k_i]/dh, 1] (a row vector of length n+1).

This is a well-defined NLP that SLSQP can handle. The key advantage is that we only need M inequality constraints (say M=10-30) instead of dealing with all 2n-1 correlations.

1. Start with top M lags from current h
2. Solve the NLP
3. Evaluate all 2n-1 correlations at the solution
4. If any correlation > t + epsilon, add it to the constraint set (replace the least active one)
5. Repeat until no new violations

def project_feasible(h, n):

        if abs(diff) < 1e-13:
            break
        if diff > 0:
            room = 1.0 - h

            if s < 1e-13: break
            h += diff / s * room
        else:

            if s < 1e-13: break
            h += diff / s * h

        return x[n]

        g[n] = 1.0

    # Equality: sum(h) - n/2 = 0

            g[n] = 1.0
            return g
        return {'type': 'ineq', 'fun': fun, 'jac': jac}

        return x[:n].sum() - n / 2.0
    def eq_jac(x):
        g = np.zeros(n_vars)
        g[:n] = 1.0
        return g

    for k in active_lags:
        cons.append(make_ineq(k))
