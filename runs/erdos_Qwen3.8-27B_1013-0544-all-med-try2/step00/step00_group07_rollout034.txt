Key optimization: Instead of trying ALL pairs, use a "greedy" approach where we only try pairs involving the current worst lag.

The idea: if lag l* is the worst, we want to decrease corr[l*]. The derivative of corr[l*] with respect to h[i] is:
d corr[l*] / dh[i] = (1 - h[i + k*]) * 1_{valid(i+k*)} - h[i - k*] * 1_{valid(i-k*)}

where k* = l* - (n-1).

So we want to increase h[i] where the derivative is most negative, and decrease h[i] where it's most positive.

This gives a natural "gradient" direction. We can do:
1. Compute the subgradient at the worst lag
2. Move in the negative gradient direction
3. Project to [0,1] and fix the sum constraint

This is essentially a subgradient method for the min-max problem.

```python
def subgradient_step(h, alpha):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    # Find worst lags
    max_val = np.max(corr)
    # Subgradient for the maximum: average over all maximizers
    mask = corr >= max_val - 1e-10
    worst_lags = np.where(mask)[0]
    
    # Compute subgradient
    grad = np.zeros(n)
    for l in worst_lags:
        k = l - (n - 1)
        for i in range(n):
            # d corr[l] / dh[i]
            # corr[l] = sum_{i'} h[i'+k] * (1-h[i']) for valid i'
            # d/dh[i]: 
            #   from h[i+k] term: (1-h[i]) if i+k valid
            #   from (1-h[i]) term: -h[i-k] if i-k valid
            val = 0.0
            if 0 <= i + k <= n - 1:
                val += (1.0 - h[i])
            if 0 <= i - k <= n - 1:
                val -= h[i - k]
            grad[i] += val / len(worst_lags)
    
    # Move in negative gradient direction
    h_new = h - alpha * grad
    h_new = np.clip(h_new, 0, 1)
    
    # Fix sum constraint
    target = n / 2.0
    current_sum = np.sum(h_new)
    if abs(current_sum - target) > 1e-10:
        # Distribute the correction
        diff = target - current_sum
        # Add to elements that are not at bounds
        free = (h_new > 1e-6) & (h_new < 1 - 1e-6)
        if np.sum(free) > 0:
            h_new[free] += diff / np.sum(free)
            h_new = np.clip(h_new, 0, 1)
        else:
            h_new = h  # Can't fix, revert
    
    return h_new, compute_c5(h_new)
```

```python
    dx = 2.0 / n
```
