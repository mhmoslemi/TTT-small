{"plan":"1. Approach and rationale\nUse derivative-free simulated annealing directly on feasible sample vectors. Each mutation transfers mass between two coordinates, so it preserves the required sum and box bounds by construction; the program evaluates every usable proposal with the exact finite-support correlation maximum. This is materially different from an epigraph nonlinear program and from projected gradient descent on a smoothed maximum: there is no epigraph variable, general-purpose optimizer, gradient, or smoothed objective. The method addresses the nonsmooth maximum with exact-score Metropolis acceptance and uses annealing to sometimes leave a locally good but improvable profile.\n\nThe exact correlation and feasibility checks below are mathematical requirements. The choice of exchange moves, annealing schedule, and multiple starts is a heuristic that may improve the supplied construction, but it is not guaranteed to improve it, reach 0.3808, or find a global optimum. The objective is generally nonconvex, and finite stochastic search provides no optimality certificate.\n\n2. Mathematical specification\nFor n samples let h be a real vector of length n, dx = 2/n, and m = n/2. The feasible set is P = {h: 0 ≤ h[i] ≤ 1 for every i, sum(h) = m}. The evaluator’s exact objective is C(h) = max(np.correlate(h, 1-h, mode='full')) × dx. It includes 2n−1 linear-correlation lags and partial overlaps at nonzero lags.\n\nFor explicit lag indexing, define q0(h) = dx × sum over i=0,...,n−1 of h[i](1−h[i]). For every integer s from 1 to n−1 define A_s(h) = dx × sum over i=0,...,n−s−1 of h[i](1−h[i+s]), and B_s(h) = dx × sum over i=0,...,n−s−1 of h[i+s](1−h[i]). The collection {q0, A_1, B_1, ..., A_(n−1), B_(n−1)} has exactly 2n−1 entries and is the set of values returned by the evaluator correlation before taking its maximum and multiplying by dx. The order does not affect the maximum. Do not use circular correlation or replace these sums with an autocorrelation identity; each nonzero shift has only n−s terms.\n\nA feasible pairwise transfer from coordinate i to coordinate j uses capacity c = min(h[i], 1−h[j]) and amount δ = ρu c, with 0 < ρ ≤ 1 and 0.2 ≤ u ≤ 1. Update h[i] to h[i]−δ and h[j] to h[j]+δ. This preserves the sum and keeps both entries in [0,1]. Sequential transfers preserve those properties mathematically; use a feasibility check and numerical repair after a sequence to handle floating-point roundoff.\n\nFor an arbitrary finite proposal y, the Euclidean projection onto P has p[i] = clip(y[i]−λ, 0, 1), where λ solves sum_i clip(y[i]−λ, 0, 1) = m. This follows from the box-and-sum constrained projection conditions. The sum is monotone nonincreasing in λ, so a bracketed bisection followed by bounded residual correction gives a joint box-and-mass repair. Do not clip and then rescale.\n\nFor a current feasible vector x and feasible proposal y, let Δ = C(y)−C(x). At temperature T > 0, accept y when Δ ≤ 0; otherwise accept it with probability exp(−Δ/T), using a seeded uniform random draw. Candidate ranking and acceptance use the exact C, not an approximation.\n\n3. Implementation procedure\n1. Implement a top-level function run(seed=42, **kwargs).
