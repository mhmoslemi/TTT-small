Let me be careful about the gradient computation. For q_p = dx * sum_{i=0}^{n-1-p} h[i+p](1-h[i]):
- ∂q_p/∂h[r] for r in [p, n-1]: dx*(1 - h[r-p]) (from h[r] appearing as h[i+p] where i=r-p)
- ∂q_p/∂h[r] for r in [0, n-1-p]: -dx*h[r+p] (from h[r] appearing as h[i] where i=r)

For q_{-p} = dx * sum_{i=0}^{n-1-p} h[i](1-h[i+p]):
- ∂q_{-p}/∂h[r] for r in [0, n-1-p]: dx*(1 - h[r+p]) (from h[r] appearing as h[i] where i=r)
- ∂q_{-p}/∂h[r] for r in [p, n-1]: -dx*h[r-p] (from h[r] appearing as h[i+p] where i=r-p)

For q_0 = dx * sum_i h[i](1-h[i]):
- ∂q_0/∂h[r] = dx*(1-2*h[r])

The correlate output: np.correlate(h, 1-h, mode='full') gives 2n-1 values.
The k-th lag (k from -(n-1) to n-1) is at index n-1+k.

For the inequality constraint: t - q_k(h) >= 0 for each k.
The Jacobian row for lag k is (-∂q_k/∂h[0], ..., -∂q_k/∂h[n-1], 1).

    m = n / 2.0
    y = np.clip(y.astype(np.float64), -1e6, 1e6)
    lo = y.min() - 1.0
    hi = y.max()
    for _ in range(80):
        mid = (lo + hi) / 2.0
        s = np.sum(np.clip(y - mid, 0.0, 1.0))
        if s > m:
            lo = mid
        else:
            hi = mid
    tau = (lo + hi) / 2.0
    x = np.clip(y - tau, 0.0, 1.0)
    # Fix residual
    r = m - np.sum(x)
    if r > 0:

                add = min(1.0 - x[i], r)

            if x[i] > 0.0 and r < 0:
                sub = min(x[i], -r)

                r += sub

def lag_gradient(h, n):
