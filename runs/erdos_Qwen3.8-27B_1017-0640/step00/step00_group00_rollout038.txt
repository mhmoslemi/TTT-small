def build_hull(m_vals, c_vals, idx_list):
    # Build upper hull. Returns list of (idx, breakpoint_start)
    if len(idx_list) == 0:
        return []
    order = sorted(range(len(idx_list)), key=lambda i: (m_vals[i], -c_vals[i]))
    # Remove duplicates (same slope, keep max intercept - already done by sort)
    hull = []
    for i in order:
        if len(hull) > 0 and m_vals[i] == hull[-1][0]:
            continue  # same slope, already have better
        if len(hull) == 0:

        else:

            dm = m_vals[i] - m_vals[prev_i]

Now for the line minimization, let me think about a simpler but correct approach.

For n=45, there are 89 lags. For each pair (a,b) with p=b-a, the quadratic coefficients are:
- A[44] = -2*dx (zero lag, index n-1 = 44)
- A[44+p] = dx (positive lag p)
- A[44-p] = dx (negative lag -p)
- All others A=0

The line minimization problem: min_{t in [L,U]} max_k (c_k + b_k*t + A_k*t^2)

A practical approach for small n:
1. Collect all "interesting" t values:
   - L, U, 0
   - For each quadratic k (3 of them): stationary point -b_k/(2*A_k) if in [L,U]
   - For each pair of curves (affine-affine, affine-quad, quad-quad): intersection in [L,U]

With O(n) segments, that's O(n) candidates total.

        best_h = np.full(n, 0.5); best_sc = sc(best_h, n)
    return best_h, float(best_sc), int(n)
