- We can normalize to sum(a) = 1 (or any fixed value)
- After normalization to sum = sqrt(2n), the score = max(conv(a,a))
- The convolution has 2n-1 entries that sum to (sum(a))^2 = 2n
- So the average entry of the convolution is 2n/(2n-1) ≈ 1
- We want the max to be as close to 1 as possible (the theoretical minimum)

The previous solution achieves max(c) ≈ 1.507 with n=8192. The average is ≈ 1. So we're at about 50% above the theoretical minimum.

To improve, we need to reduce the peak further. The peak is at some lag k*, and we want to "spread out" the energy from that lag to other lags.

In the frequency domain, the convolution c = IFFT(|FFT(a)|^2). To reduce c at lag k*, we need to modify |FFT(a)|^2 such that the IFFT has a smaller value at k*.

The FFT of an impulse at lag k* is exp(2πik*m/N). So the "component" of c at lag k* is (1/N) * sum_m |A_m|^2 * exp(2πik*m/N). To reduce this, we want to subtract energy from |A_m|^2 at frequencies where exp(2πik*m/N) is positive (i.e., where cos(2πkm/N) > 0).

This is exactly what the previous code does with the cosine-based shaping! The formula P_new = P * exp(-alpha * max(cos, 0)) reduces the power at frequencies that positively contribute to the peak lag.

So the approach is fundamentally sound. The question is how to make it more effective.

**Possible improvements:**

1. **Iterative refinement with decreasing alpha**: Start with a large alpha (aggressive reduction) and gradually decrease it (fine-tuning). The previous code does this but maybe the schedule is suboptimal.

2. **Simultaneous multi-lag targeting**: Instead of just the top-k lags, target all lags that are above the average. This gives a smoother, more global optimization.

3. **Phase optimization**: The previous code sometimes adds random phase noise. But we could also optimize the phase: for a given |A_m|, find the phase that minimizes the peak of IFFT(|A|^2). This is related to the "phase retrieval" problem.

4. **Non-uniform frequency grid**: Instead of shaping uniformly across frequencies, use a non-uniform grid that focuses more on the "important" frequencies.

5. **Hybrid time-frequency approach**: Alternate between time-domain (coordinate descent) and frequency-domain (spectral shaping) updates.

import numpy as np
import time
from scipy.fft import fft, ifft


def project_simplex(v, S):
    """Euclidean projection onto {x >= 0, sum(x) = S}."""
    n = len(v)
    if n == 0:
        return v
    v = np.asarray(v, dtype=np.float64)
    w = np.sort(v)[::-1]
    cumsum = np.cumsum(w)
    idx = np.arange(1, n + 1, dtype=np.float64)
    theta_candidates = (cumsum - S) / idx
    valid = theta_candidates <= w
    if not np.any(valid):
        theta = v.mean()
    else:
        rho = int(np.max(np.where(valid)[0]) + 1)
        theta = (cumsum[rho - 1] - S) / rho
    return np.maximum(v - theta, 0.0)


def fft_convolve_self(a):
    """Full self-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fsize = 1 << (size - 1).bit_length()
    A = fft(a, fsize)
    c = np.real(ifft(A * A))
    return c[:size]


def safe_normalize(a, n):
    """Clamp and normalize to sum = sqrt(2n)."""
    a = np.clip(np.asarray(a, dtype=np.float64), 0.0, 1000.0)
    s = a.sum()
    S = np.sqrt(2.0 * float(n))
    if s <= 1e-15:
        return np.ones(n) * S / n
    return a * (S / s)


def structured_init(n, rng, method="sin"):
    """Generate structured initializations."""
    t = np.arange(n) / n
    if method == "sin":
        a = 0.5 + 0.3 * np.sin(2 * np.pi * 3 * t) + 0.2 * np.sin(2 * np.pi * 7 * t) \
            + 0.1 * np.sin(2 * np.pi * 13 * t) + 0.05 * rng.standard_normal(n)
    elif method == "chirp":
        a = 0.5 + 0.3 * np.sin(2 * np.pi * (2 * t + 3 * t * t)) + 0.1 * rng.standard_normal(n)
    elif method == "ramp":
        a = 0.3 + 0.7 * t + 0.05 * rng.standard_normal(n)
    elif method == "bowl":
        # High at edges, low in middle
        a = 0.3 + 0.7 * (2 * t - 1) ** 2 + 0.05 * rng.standard_normal(n)
    elif method == "gaussian":
        a = 0.3 + 0.7 * np.exp(-8 * (t - 0.5) ** 2) + 0.05 * rng.standard_normal(n)
    elif method == "exp_decay":
        a = 0.3 + 0.7 * np.exp(-3 * t) + 0.05 * rng.standard_normal(n)
    elif method == "two_lobe":
        a = 0.3 + 0.35 * np.exp(-30 * (t - 0.2) ** 2) + 0.35 * np.exp(-30 * (t - 0.8) ** 2) \
            + 0.05 * rng.standard_normal(n)
    elif method == "alternating":
        a = np.where(np.arange(n) % 2 == 0, 1.0, 0.3) + 0.1 * rng.standard_normal(n)
    elif method == "piecewise":
        n_pieces = 128
        piece_len = max(1, n // n_pieces)
        heights = 0.3 + 0.7 * rng.random(n_pieces)
        a = np.repeat(heights, piece_len)
        if len(a) < n:
            a = np.concatenate([a, 0.3 + 0.7 * rng.random(n - len(a))])
        a = a[:n]
    elif method == "spectral_white":
        # Random phases, flat power spectrum
        N = 1 << (2 * n - 1).bit_length()
        A = exp(1j * rng.uniform(0, 2 * np.pi, N))
        A[0] = 1.0  # DC
        # Enforce Hermitian symmetry
        for k in range(1, N // 2 + 1):
            A[N - k] = np.conj(A[k])
        a = np.real(ifft(A))[:n]
        a = a - a.min() + 0.1
    else:
        a = 0.5 + 0.3 * rng.standard_normal(n)
    a = np.clip(a, 0.01, 3.0)
    return a


def spectral_shape_step(a, N, n, c, top_k, alpha, target, rng=None):
    """
    Single spectral shaping step. Modifies |A|^2 to reduce contribution
    to top-k peak lags.
    Returns (new_a, new_c).
    """
    S = a.sum()
    a_pad = np.zeros(N)
    a_pad[:n] = a
    A = fft(a_pad)
    P = np.abs(A) ** 2

    # Find top-k peak lags above target
    sorted_idx = np.argsort(c)[::-1]
    peak_indices = []
    for idx in sorted_idx[:top_k]:
        if c[idx] > target:
            peak_indices.append(int(idx))
        else:
            break

    if not peak_indices:
        return a, c

    # Weight by excess above target
    excess = np.array([c[k] - target for k in peak_indices])
    w = excess / excess.sum()

    # Effective cosine (weighted superposition)
    m = np.arange(N)
    cos_eff = np.zeros(N)
    for i, k in enumerate(peak_indices):
        cos_eff += w[i] * np.cos(2.0 * np.pi * m * k / N)

    # Only suppress where cos_eff > 0 (constructive interference at peak)
    suppression = np.maximum(cos_eff, 0.0)

    # Adaptive alpha based on current peak vs target
    peak_val = c[peak_indices[0]]
    alpha_eff = alpha * min(2.0, max(0.5, (peak_val - target) / max(peak_val * 0.1, 1e-10)))

    P_new = P * np.exp(-alpha_eff * suppression)

    # Reconstruct with same phase
    A_new = np.sqrt(P_new) * np.exp(1j * np.angle(A))
    a_new = np.real(ifft(A_new))[:n]
    a_new = project_simplex(a_new, S)

    c_new = fft_convolve_self(a_new)
    return a_new, c_new


def mirror_descent_step(a, c, top_k, eta, n):
    """
    Mirror descent (multiplicative weights) step.
    g_i = sum of a_j over active peak lags where i+j=k.
    a_i <- a_i * exp(-eta * g_i), then normalize.
    """
    S = a.sum()
    peak_idx = np.argsort(c)[::-1][:top_k]
    peak_vals = c[peak_idx]
    w = peak_vals / peak_vals.sum()

    # Compute subgradient
    g = np.zeros(n)
    for i, k in enumerate(peak_idx):
        k = int(k)
        # For lag k, the subgradient at position p is:
        # w * a[k-p] (from the pair (p, k-p))
        # Valid p: max(0, k-n+1) <= p <= min(k, n-1)
        p_lo = max(0, k - n + 1)
        p_hi = min(k, n - 1)
        for p in range(p_lo, p_hi + 1):
            q = k - p
            if q != p:
                g[p] += 2.0 * w[i] * a[q]
            else:
                g[p] += w[i] * a[p]

    # Normalize gradient
    g_max = g.max()
    if g_max > 1e-15:
        g = g / g_max

    # Multiplicative update
    a_new = a * np.exp(-eta * g)
    a_new = project_simplex(a_new, S)
    return a_new


def coordinate_swap_descent(a, c, n, n_top, max_time, start_time):
    """
    Coordinate swap: try moving mass from one coordinate to another.
    For the peak lag, identify pairs (i, j) where reducing a_i and increasing a_j
    would help, then try small swaps.
    """
    a = a.copy()
    S = a.sum()
    best_score = c.max()
    N = 1 << (2 * n - 1).bit_length()

    it = 0
    while time.monotonic() - start_time < max_time:
        it += 1
        c = fft_convolve_self(a)
        c_max = c.max()
        if c_max < best_score:
            best_score = c_max

        # Find peak lag
        peak_k = int(np.argmax(c))

        # Identify the "worst" coordinate (most contributing to peak)
        p_lo = max(0, peak_k - n + 1)
        p_hi = min(peak_k, n - 1)
        contribs = np.zeros(n)
        for p in range(p_lo, p_hi + 1):
            q = peak_k - p
            contribs[p] = a[p] * a[q]

        # Try swapping: reduce a source, increase a destination
        # Source: coordinate with high contribution to peak
        # Destination: coordinate that doesn't contribute to peak (or less)
        src_candidates = np.argsort(contribs)[::-1][:n_top]
        dst_candidates = np.where(contribs < contribs.mean())[0]
        if len(dst_candidates) < n_top:
            dst_candidates = np.argsort(contribs)[:n_top]

        improved = False
        for src in src_candidates[:min(10, n_top)]:
            if time.monotonic() - start_time > max_time:
                break
            src = int(src)
            for dst in dst_candidates[:min(10, n_top)]:
                if time.monotonic() - start_time > max_time:
                    break
                dst = int(dst)
                if dst == src:
                    continue

                # Try several swap fractions
                best_frac = 0.0
                best_cmax = c_max
                for frac in [0.1, 0.2, 0.3, 0.5]:
                    delta = frac * a[src]
                    a[src] -= delta
                    a[dst] += delta
                    if a[src] < 0:
                        a[src] += delta
                        a[dst] -= delta
                        continue
                    c_try = fft_convolve_self(a)
                    cm = c_try.max()
                    if cm < best_cmax:
                        best_cmax = cm
                        best_frac = frac
                    a[src] += delta
                    a[dst] -= delta

                if best_frac > 0:
                    delta = best_frac * a[src]
                    a[src] -= delta
                    a[dst] += delta
                    a = np.maximum(a, 0)
                    a = a * (S / a.sum())
                    improved = True

        if not improved and it % 20 == 0:
            # Perturb to escape
            idx = np.random.randint(n)
            a[idx] *= 1.05
            a = a * (S / a.sum())

    return a, best_score


def spectral_waterfill_loop(a_init, N, n, max_time, rng, top_k_init=8, alpha_init=0.5):
    """
    Improved iterative spectral water-filling with adaptive target.
    """
    a = a_init.copy()
    S = a.sum()
    best_a = a.copy()
    best_cmax = np.inf
    it = 0
    stall = 0
    start = time.monotonic()

    c = fft_convolve_self(a)
    best_cmax = c.max()
    current_peak = best_cmax
    target = current_peak * 0.99  # Adaptive target: 1% below current peak

    while time.monotonic() - start < max_time:
        it += 1
        top_k = min(100, top_k_init + it // 10)
        alpha = alpha_init / (1.0 + 0.03 * it)

        a_new = a.copy()
        for _ in range(3):  # 3 sub-iterations per outer loop
            if time.monotonic() - start > max_time:
                break
            c_curr = fft_convolve_self(a_new)
            peak_curr = c_curr.max()
            if peak_curr <= target:
                break
            a_new, c_new = spectral_shape_step(a_new, N, n, c_curr, top_k, alpha, target, rng)

        c_check = fft_convolve_self(a_new)
        actual_cmax = c_check.max()

        if actual_cmax < best_cmax:
            best_cmax = actual_cmax
            best_a = a_new.copy()
            a = a_new.copy()
            stall = 0
            # Tighten target
            target = max(best_cmax * 0.995, best_cmax - 0.005)
        else:
            a = a_new.copy()
            stall += 1
            if stall > 50:
                # Perturb and reset target
                a = project_simplex(a + rng.normal(0, 0.003 * S / np.sqrt(n), n), S)
                c_p = fft_convolve_self(a)
                target = max(c_p.max() * 0.99, c_p.max() - 0.01)
                if c_p.max() < best_cmax:
                    best_cmax = c_p.max()
                    best_a = a.copy()
                stall = 0

        if it % 200 == 0:
            print("    SW iter %d: peak=%.6f, target=%.6f" % (it, best_cmax, target))

    return best_a, best_cmax

    a = a_init.copy()

    rem = phase4_budget - (time.monotonic() - t3)
    if rem > 10:
        a_p2, sc2 = mirror_descent_loop(a_best, N, n, min(rem * 0.3, 40.0), rng)
        try_update(a_p2, n)
        a_best = global_a.copy()

    # Coordinate swap
    rem = phase4_budget - (time.monotonic() - t3)
    if rem > 5:
        c_curr = fft_convolve_self(a_best)
        a_p3, sc3 = coordinate_swap_descent(a_best, c_curr, n, 30, min(rem * 0.3, 30.0),
                                            time.monotonic())
        try_update(a_p3, n)
        a_best = global_a.copy()

    # One more combined pass
    rem = phase4_budget - (time.monotonic() - t3)
    if rem > 15:
        a_p4, sc4 = combined_optimize(a_best, N, n, min(rem * 0.8, 60.0), rng)
        try_update(a_p4, n)

    # === Try n=4096 as well if time permits ===
    rem_final = deadline - time.monotonic()
    if rem_final > 30 and budget_s > 2000:
        print("=== Bonus: trying n=4096 ===")
        n2 = 4096
        S2 = np.sqrt(2.0 * float(n2))
        N2 = 1 << (2 * n2 - 1).bit_length()

        # Downsample from best 8192-length sequence
        a_ds = global_a.reshape(64, 128).mean(axis=1).reshape(-1)
        # Pad/truncate to 4096
        if len(a_ds) < n2:
            a_ds = np.concatenate([a_ds, global_a[:n2 - len(a_ds)]])
        a_ds = a_ds[:n2]
        a_ds = safe_normalize(a_ds, n2)

        c_ds = fft_convolve_self(a_ds)
        sc_ds = c_ds.max()
        if sc_ds < global_best:
            print("  n=4096 downsample: %.6f" % sc_ds)
            global_best = sc_ds
            global_a = a_ds.copy()
            global_n = n2

        rem2 = deadline - time.monotonic()
        if rem2 > 20:
            a_opt, sc_opt = spectral_waterfill_loop(a_ds, N2, n2, min(rem2 * 0.5, 20.0),
                                                    rng, top_k_init=5, alpha_init=0.5)
            try_update(a_opt, n2)
            rem3 = deadline - time.monotonic()
            if rem3 > 10:
                a_opt2, sc_opt2 = mirror_descent_loop(a_opt, N2, n2, min(rem3 * 0.5, 15.0), rng)
                try_update(a_opt2, n2)

    # Also try a fresh 4096-length optimization from scratch
    rem_final2 = deadline - time.monotonic()
    if rem_final2 > 15:
        n2 = 4096
        S2 = np.sqrt(2.0 * float(n2))
        N2 = 1 << (2 * n2 - 1).bit_length()
        a_fresh = structured_init(n2, rng, "ramp")
        a_fresh = safe_normalize(a_fresh, n2)
        a_opt, sc_opt = spectral_waterfill_loop(a_fresh, N2, n2, min(rem_final2 * 0.5, 12.0),
                                                rng, top_k_init=5, alpha_init=0.6)
        try_update(a_opt, n2)

    # --- Final verification and return ---
    print("\n=== Final Result ===")
    print("Best score (internal): %.6f" % global_best)
    print("Sequence length: %d" % (len(global_a) if global_a is not None else 0))

    if global_a is not None:
        global_a = np.clip(global_a, 0.0, 1000.0)
        if global_a.sum() < 0.01:
            global_a = np.ones(256, dtype=np.float64)
        final_list = [float(x) for x in global_a]
        ver = evaluate_sequence(final_list)
        if np.isfinite(ver):
            print("Verified score: %.6f" % ver)
            if ver <= global_best + 0.001:
                print("Verification matches internal score.")
            else:
                print("Warning: verified score (%.6f) differs from internal (%.6f)" % (ver, global_best))
        else:
            print("Verification FAILED, using fallback")
            global_a = np.ones(256, dtype=np.float64)

    else:
        global_a = np.ones(256, dtype=np.float64)

    result = [float(x) for x in global_a]
    print("Returning sequence of length %d" % len(result))
    return result
