We want: `g[j] = 2 * sum_{k: 0<=k<2n-1} w[k] * a[k-j]` where `a[m] = 0` for m outside [0, n-1].

This is `g[j] = 2 * sum_{k} w[k] * a[k-j]`.

Let me define `b[m] = a[-m] = a[-m]` (time-reversed, with a[m]=0 for m < 0). Then `a[k-j] = b[j-k]`.

So `g[j] = 2 * sum_k w[k] * b[j-k] = 2 * (convolve(w, b))[j]`.

And `b` is the time-reverse of `a` (with zero padding on the left).

In FFT: `IFFT(FFT(w) * FFT(b))` gives `convolve(w, b)` (circular = linear if size is large enough).

So `g = 2 * IFFT(W * B)[:n]` where `W = FFT(w, N)`, `B = FFT(b, N)`, and `N >= (2n-1) + n - 1 = 3n-2`.

But `B = FFT(b) = FFT(time_reverse(a))`. For the DFT, `FFT(time_reverse(a))[m] = conj(FFT(a)[(N-m) mod N])` (for real a, this is `FFT(a)[(N-m) mod N]`).

So `B[m] = A[(N-m) mod N]` where `A = FFT(a, N)`.

This means `W * B[m] = W[m] * A[(N-m) mod N]`.

And `g = 2 * IFFT(W * B)[:n]`.

```python
def weighted_subgradient(a, w):
    n = len(a)
    N = 1 << (3*n - 2 - 1).bit_length()  # next power of 2 >= 3n-2
    A = fft(a, N)
    W = fft(w, N)
    # b = time_reverse of a (padded to N)
    # B[m] = A[(N-m) % N]
    B = A[(np.arange(N)) % N][::-1]  # This is A[0], A[N-1], A[N-2], ..., A[1]
    # Actually: B[m] = A[(N-m) % N]
    # B[0] = A[0], B[1] = A[N-1], B[2] = A[N-2], ...
    B = np.zeros(N, dtype=complex)
    B[0] = A[0]
    B[1:] = A[N-1:0:-1]  # A[N-1], A[N-2], ..., A[1]
    g = 2.0 * np.real(ifft(W * B))[:n]
    return g
```
