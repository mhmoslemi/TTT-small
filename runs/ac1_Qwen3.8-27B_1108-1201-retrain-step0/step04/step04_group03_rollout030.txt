(p*p)[k] = sum_i p[i]*p[k-i] = p^T B_k p / 2 + (some linear term)

Wait, (p*p)[k] = sum_{i=0}^{k} p[i]*p[k-i] (for k <= n-1). This is a quadratic form: p^T Q_k p where Q_k[i,j] = 1/2 if i+j = k.

A quadratic form p^T Q p is convex iff Q is positive semidefinite. Is Q_k PSF?

Q_k has rank 1 (it's an outer product-like matrix), so it's either PSD or has one negative eigenvalue. Let's see: Q_k = (1/2) * v_k * v_k^T where v_k[i] = 1 if i <= k and i >= k-n+1... 

Actually, (p*p)[k] = sum_i p[i]*p[k-i]. This is not a quadratic form in the standard sense because the indices are shifted. Let me write it as:

For k in [0, 2n-2]:
(p*p)[k] = sum_{i=max(0,k-n+1)}^{min(k,n-1)} p[i]*p[k-i]

This is a sum of products of pairs of p's. Each term p[i]*p[j] with i+j=k appears. So (p*p)[k] = sum_{i+j=k, 0<=i,j<=n-1} p[i]*p[j].

This is a quadratic form: p^T A_k p where A_k[i,j] = 1 if i+j=k, 0 otherwise. But A_k is not symmetric in the usual sense... wait, if i+j=k then j+i=k, so A_k[i,j] = A_k[j,i]. Yes, it is symmetric.

Is A_k PSD? A_k has 1's on the "anti-diagonal" (i+j=k) and 0's elsewhere. The eigenvalues of such a matrix: it's a permutation matrix (reversal on a subset), so its eigenvalues are ±1 (and possibly 0). So it's not PSD in general!

For example, if n=3, k=2: A_2 = [[0,0,1],[0,0,0],[1,0,0]]. Eigenvalues: sqrt(2), 0, -sqrt(2). Not PSD!

So max_k (p*p)[k] is NOT convex in p. The problem is non-convex. That's why we need more sophisticated methods.

However, each individual (p*p)[k] is a quadratic form (not necessarily convex), and we're maximizing over a finite set of them. The overall problem is a non-convex optimization.

Given this, let me focus on practical heuristic methods.

**Revised plan:**

1. Use **mirror descent** (multiplicative updates) with LSE-smoothed objective.
2. Anneal beta from low to high to gradually sharpen the max approximation.
3. Use **multiple restarts** with different initializations.
4. Try **symmetric sequences** (p[i] = p[n-1-i]) which might have special properties.
5. Try **different n values** and interpolate.
6. Use **FFT** for efficient gradient computation.

Let me also think about a **coordinate descent** approach:
- For each i, find the optimal p[i] given all other p[j] fixed.
- The objective is 2n * max_k (p*p)[k]. The k's that are affected by p[i] are those where i is in the range of the sum, i.e., k in [i, i+n-1] (approximately).
- For a fixed max, we want to minimize p[i] * (sum of p[k-i] over active k's). This is linear in p[i]!
- So the optimal p[i] is either 0 or the value that makes the constraint sum p = 1 tight.

This is promising! Coordinate descent where each step is a simple calculation.

Let me formalize:
- Let M = max_k (p*p)[k] be the current maximum.
- For coordinate i, the "pressure" on p[i] is:
  pressure[i] = sum_{k in active(i)} w[k] * (p[k-i] + p[i-k] if i-k >= 0)
  where w[k] = 1 if (p*p)[k] = M (or using softmax weights for smoothing), and active(i) = {k : 0 <= k-i <= n-1 or 0 <= i-k <= n-1}.

- Update: p[i] <- p[i] * (1 - eta * pressure[i]) / normalization

This is essentially the same as the mirror descent approach but done coordinate by coordinate. The full gradient version is more efficient with FFT.

def fft_convolve_self(a):
    """Full linear self-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fsize = 1 << (size - 1).bit_length()
    A = fft(a, fsize)
    c = np.real(ifft(A * A))
    return c[:size]

def project_simplex(v, S):
    """Project v onto {x >= 0, sum(x) = S}."""
    n = len(v)
    v = np.asarray(v, dtype=np.float64)
    w = np.sort(v)[::-1]
    cumsum = np.cumsum(w)
    idx = np.arange(1, n + 1, dtype=np.float64)
    tc = (cumsum - S) / idx
    valid = tc <= w
    if not np.any(valid):
        rho = n
    else:
        rho = int(np.max(np.where(valid)[0]) + 1)
    theta = (cumsum[rho - 1] - S) / rho
    return np.maximum(v - theta, 0.0)

def fft_convolve_self(a):
    """Full linear self-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fsize = 1 << (size - 1).bit_length()
    A = fft(a, fsize)
    c = np.real(ifft(A * A))
    return c[:size]

def compute_gradient(a, w, N):
    """
    Compute gradient of sum_k w[k]*c[k] where c = a*a (linear conv).
    grad[j] = 2 * sum_{m=0}^{n-1} w[j+m] * a[m] (w[k]=0 for k outside [0,2n-2])
    
    Uses FFT: grad = 2 * (cross-correlation of w and a)
    cross_corr[j] = (w_rev * a)[2n-2-j] where w_rev = w[::-1]
    """
    n = len(a)
    w_rev = w[::-1]
    W = fft(w_rev, N)
    A = fft(a, N)
    conv = np.real(ifft(W * A))
    # cross_corr[j] = conv[2n-2-j] for j = 0, ..., n-1
    # So cross_corr = conv[n-1 : 2*n-1][::-1]
    cross = conv[n-1:2*n-1][::-1]
    return 2.0 * cross

def project_simplex(v, S):
    """Project v onto {x >= 0, sum(x) = S}."""
