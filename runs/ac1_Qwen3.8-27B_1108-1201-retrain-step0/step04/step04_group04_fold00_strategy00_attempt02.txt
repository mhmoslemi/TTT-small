The primary approach is to use a spectral gradient descent method with a damping regularization strategy. This method evaluates the convolution of the sequence with itself using FFT for efficiency, and then adjusts the sequence to reduce the maximum value in the convolution while preserving the sum. The core idea is to:
1. Start with a sequence of all uniform values.
2. Compute its score and use FFT to analyze the convolution spectrum.
3. Generate new sequences by damping the harmonics with exponential decay.
4. Update the sequence based on the gradient of the score function to minimize the maximum convolution value.

import numpy as np
import math
from scipy.fft import fft, ifft

def spectral_gd(
    sequence: list[float],
    *args, **kwargs
):
    """
    Perform spectral gradient descent to find a sequence minimizing the score.
    The score is defined by evaluate_sequence() function. We assume the
    sequence passed is valid (non-negative, <=1000) and sum >=0.01.
    Uses FFT to compute the linear convolution.
    """
    n = len(sequence)
    score_val = evaluate_sequence(sequence)
