The circular convolution is the aliased version: c_circ[k] = c_lin[k] + c_lin[k+n] for k=0,...,n-1.

So c_circ[0] = c_lin[0] + c_lin[n] = a[0]^2 + c_lin[n]
And the max of c_lin is >= max of c_circ (since each c_circ[k] is a sum of two non-negative terms).

This means if we minimize max(c_circ), we get an upper bound on max(c_lin), but not a tight one. We need to work with the linear convolution directly.

For the FFT computation:
- Use zero-padding to N >= 2n-1 to get the linear convolution
- N = next_power_of_2(2n-1) for efficiency
