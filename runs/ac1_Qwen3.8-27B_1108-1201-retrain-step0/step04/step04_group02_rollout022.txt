**Alternative: Use the fact that the problem is a minimax problem.**

`min_a max_k c[k]` subject to `a >= 0, sum(a) = S`.

This is a (non-convex) minimax problem. We can approach it with:
1. **Saddle point methods**: Alternate between optimizing a (min) and the distribution over k (max).
2. **Mirror descent in the primal + multiplicative weights in the dual**: This is the "game" perspective.

The dual variable is a probability distribution p over the lags. The primal-dual update is:
- p ← softmax(eta * c) (or multiplicative weights: p[k] ∝ p[k] * exp(eta * c[k]))

This is exactly the LSE approach! The key is to choose the learning rate eta well.

For mirror descent / multiplicative weights, the optimal learning rate is related to the range of the "payoff" (here, c[k]). If c[k] is in [0, M], then eta = O(1/M) is optimal.

def fft_convolve_self(a):
    n = len(a)
    size = 2 * n - 1
    fsize = 1 << (size - 1).bit_length()
    A = fft(a, fsize)
    c = np.real(ifft(A * A))
    return c[:size]


def project_simplex(v, S):
    n = len(v)
    v = np.asarray(v, dtype=np.float64)
    w = np.sort(v)[::-1]
    cumsum = np.cumsum(w)
    idx = np.arange(1, n + 1, dtype=np.float64)
    tc = (cumsum - S) / idx
    valid = tc <= w
    if not np.any(valid):
        rho = n
    else:
        rho = int(np.max(np.where(valid)[0]) + 1)
    theta = (cumsum[rho - 1] - S) / rho
    return np.maximum(v - theta, 0.0)


def lse_grad(a, c, beta):
    """Gradient direction: 2 * sum_k p[k] * a[k-j] (unnormalized by 1/beta)."""
    n = len(a)
    size = 2 * n - 1
    cm = c.max()
    e = np.exp(beta * (c - cm))
    p = e / e.sum()
    p_rev = p[::-1]
    fsize = 1 << (size + n - 1).bit_length()
    A = fft(a, fsize)
    P = fft(p_rev, fsize)
    conv = np.real(ifft(A * P))[:size + n - 1]
    grad = 2.0 * conv[n-1 : 2*n-1][::-1]
    return grad

    S = a.sum()
