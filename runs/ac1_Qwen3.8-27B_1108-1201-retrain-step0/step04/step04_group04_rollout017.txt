The self-convolution b[k] = sum_i p[i] * p[k-i] is the probability that the sum of two independent random variables (each distributed as p) equals k.

So b is the distribution of X + Y where X and Y are i.i.d. with distribution p.

We want to minimize max_k P(X+Y = k).

By a general result in probability, for any distribution p on {0, 1, ..., n-1}, the distribution of X+Y has:
- Support on {0, 1, ..., 2n-2}
- P(X+Y = k) ≥ 0

The minimum possible max P(X+Y = k) is achieved when the distribution of X+Y is as uniform as possible over its support.

If the support of X+Y is all of {0, ..., 2n-2} (which requires p to have support on all of {0, ..., n-1}), then the minimum max is 1/(2n-1), giving score = 2n/(2n-1) ≈ 1.

But is it achievable? The distribution of X+Y is the convolution of p with itself. We need this to be (approximately) uniform.

This is exactly the problem of finding a "flat" convolution, which is related to the theory of "difference sets" and "cyclotomic numbers."

In fact, if we could find p such that p*p is exactly uniform, then p would be a "flat" sequence. For prime n, there are connections to quadratic residues and finite fields.

However, the non-negativity constraint (p ≥ 0) is the key difficulty. Without it, we could use complex sequences (like roots of unity) to achieve perfect flatness.

**Practical approaches to get closer to the limit:**

1. **Start from a structured sequence:**
   - Use a "Barker-like" or "m-sequence" pattern, but with non-negative values
   - Use a "Gold code" pattern with non-negative values

2. **Use the "inverse" of the convolution:**
   - If we want b to be flat, we need a such that a*a ≈ flat
   - This is like finding a "square root" of a flat sequence in the convolution algebra
   - In the frequency domain: |A(ω)|^2 ≈ flat, so |A(ω)| ≈ constant
   - But A must have non-negative coefficients!

3. **Iterative approach (Fienup/Gerchberg-Saxton adapted):**
   - Start with a target b (flat or nearly flat)
   - Compute A(ω) = sqrt(B(ω)) (choosing a phase)
   - Take inverse FFT to get a
   - Project to non-negative (set negative values to 0)
   - Recompute b from the projected a
   - Iterate

The challenge in step 3 is choosing the phase. For non-negative a, the phase of A(ω) is determined by a (it's the phase of the "analytic signal" of a). We can't freely choose the phase.

However, we can use a trick: since a ≥ 0, we have A(0) = sum a[i] ≥ 0 (real and positive). This gives us one phase constraint. For the other frequencies, the phase is determined by the structure of a.

"""
Minimize 2*n*max(self_conv)/sum^2 for non-negative sequences.

Key improvements over previous:
1. Theoretical 1/sqrt(i) initialization (optimal shape for alpha=0.5)
2. Multi-alpha shape exploration
3. Directed peak shaving (targeted coordinate descent on the max lag)
4. Adaptive LSE FISTA with exponential beta ramp
5. Frequency-domain "unfolding" to escape local minima
6. Multi-length exploration
"""
import numpy as np
import time
from scipy.fft import fft, ifft


def fft_convolve_self(a):
    """Full linear self-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fsize = 1 << (size - 1).bit_length()
    A = fft(a, fsize)
    c = np.real(ifft(A * A))
    return c[:size]


def project_simplex(v, S):
    """Project v onto {x >= 0, sum(x) = S}."""
    n = len(v)
    v = np.asarray(v, dtype=np.float64)
    w = np.sort(v)[::-1]
    cumsum = np.cumsum(w)
    idx = np.arange(1, n + 1, dtype=np.float64)
    tc = (cumsum - S) / idx
    valid = tc <= w
    if not np.any(valid):
        rho = n
    else:
        rho = int(np.max(np.where(valid)[0]) + 1)
    theta = (cumsum[rho - 1] - S) / rho
    return np.maximum(v - theta, 0.0)


def normalize_to_sum(a, S):
    """Clamp non-negative and rescale to sum S."""
    a = np.maximum(np.asarray(a, dtype=np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        return np.ones(len(a)) * S / len(a)
    return a * (S / s)


def make_init_alpha(n, alpha, S, rng, jitter=0.0):
    """Create initialization a[i] ∝ (i+1)^{-alpha} with optional jitter."""
    i = np.arange(n, dtype=np.float64) + 1.0
    a = np.power(i, -alpha)
    if jitter > 0:
        # Add a small oscillatory component to break the "pure power law"
        freq = rng.uniform(1, 5)
        a = a * (1.0 + jitter * np.cos(2.0 * np.pi * freq * i / n))
        a = np.maximum(a, 1e-10)
    return normalize_to_sum(a, S)


def lse_and_grad(a, beta, fsize):
    """Compute LSE value and its gradient."""
    n = len(a)
    c = fft_convolve_self(a)
    cm = c.max()
    e = np.exp(beta * (c - cm))
    tot = e.sum()
    if tot < 1e-300:
        return cm, np.zeros(n)
    w = e / tot
    # Gradient: grad_i = 2 * sum_k w[k] * a[k-i] (valid range)
    # This is 2 * cross_correlation(w, a)
    # Using FFT: cross_corr = ifft(fft(w) * conj(fft(a)))
    W = fft(w, fsize)
    A = fft(a, fsize)
    grad = 2.0 * np.real(ifft(W * np.conj(A)))[:n]
    return cm, grad


def fista_lse(a_init, n, S, max_time, rng, beta_start=5.0, beta_end=3000.0,
              ramp_frac=0.6, restart_interval=5000):
    """FISTA with LSE smoothing and adaptive beta."""
    a = normalize_to_sum(a_init, S)
    y = a.copy()
    t_k = 1.0
    fsize = 1 << (2 * n - 1).bit_length()
    start = time.monotonic()
    best_max = np.inf
    best_a = a.copy()
    stale = 0

    while time.monotonic() - start < max_time:
        elapsed = time.monotonic() - start
        progress = min(1.0, elapsed / max_time)
        
        # Adaptive beta: exponential ramp
        if progress < ramp_frac:
            beta = beta_start * np.exp(np.log(beta_end / beta_start) * (progress / ramp_frac) ** 0.7)
        else:
            beta = beta_end * (1.0 + 0.001 * (progress - ramp_frac) / (1.0 - ramp_frac))
        
        c = fft_convolve_self(y)
        cur_max = c.max()
        if cur_max < best_max - 1e-10:
            best_max = cur_max
            best_a = y.copy()
            stale = 0
        else:
            stale += 1
        
        # Compute gradient
        cm = c.max()
        e = np.exp(beta * (c - cm))
        tot = e.sum()
        if tot < 1e-300:
            break
        w = e / tot
        W = fft(w, fsize)
        A = fft(a, fsize)
        grad = 2.0 * np.real(ifft(W * np.conj(A)))[:n]
        gnorm = np.linalg.norm(grad)
        if gnorm < 1e-14:
            break
        
        # Step size: 1/L where L is Lipschitz constant of gradient
        # L ≈ 2 * beta * 2 * max(a) (rough bound)
        # Use adaptive step
        step = 1.0 / (beta * 2.0 * max(np.max(a), 1e-10))
        step = min(step, S / (gnorm + 1e-14))
        
        x_new = project_simplex(y - step * grad, S)
        t_new = 0.5 * (1.0 + np.sqrt(1.0 + 4.0 * t_k * t_k))
        y = x_new + ((t_k - 1.0) / t_new) * (x_new - a)
        y = np.maximum(y, 0.0)
        a = x_new
        t_k = t_new
        
        # Periodic restart with noise
        if stale > restart_interval or (stale > 1000 and rng.random() < 0.01):
            noise_scale = 0.05 * S / np.sqrt(n) * np.exp(-stale / 5000.0)
            if noise_scale > 1e-8:
                y = project_simplex(y + rng.normal(0, noise_scale, n), S)
                t_k = 1.0
                stale = 0
            else:
                # Larger perturbation
                idx = rng.choice(n, size=max(1, n//10), replace=False)
                y[idx] = 0
                y = project_simplex(y, S)
                t_k = 1.0
                stale = 0
    
    c_final = fft_convolve_self(best_a)
    if c_final.max() < best_max:
        best_max = c_final.max()
    return best_a, best_max


def directed_peak_shave(a_init, n, S, max_time, rng, max_iter=50000):

        products = a[idx] * a[k_star - idx]
        max_prod_idx = idx[np.argmax(products)]

            # and k where k-dest == dest (i.e., k = 2*dest)
            quad_src = 1.0 if 2 * src < 2 * n - 1 else 0.0  # b[2*src] has a[src]^2 term
