The constraint matrix has |K| rows and n columns. Each row k is: (f reversed and shifted by k).

Actually, for the best-response LP, there's a simpler approach: since all constraints are of the form (row_k) @ g ≤ M, and we're maximizing sum(g), this is a standard LP. The dual is:

The dual has |K| variables and n constraints. If |K| << n, the dual might be easier.

**Alternative: Frank-Wolfe (Conditional Gradient) method**

The problem min max_k c_k s.t. sum(f) = S, f ≥ 0 can be reformulated as:
min t s.t. c_k ≤ t for all k, sum(f) = S, f ≥ 0.

The Frank-Wolfe method for this would:
1. Linearize the objective at the current point
2. Solve the linear program (linear objective over the simplex)
3. Take a step towards the solution

But this still requires solving LPs.

**Simpler approach: Coordinate-wise optimization**

For each coordinate i, given all other coordinates fixed, find the optimal f_i. The objective as a function of f_i is:
max_k (h_k + f_i * g_k(i))

where h_k = c_k - f_i * g_k(i) (the part of c_k not involving f_i) and g_k(i) = 2*f_{k-i} (if valid).

This is a 1D convex piecewise-linear function. Its minimum is at a point where two lines cross (or at f_i = 0).

We can find the optimal f_i by:
1. Computing all the lines: for each k, the line is L_k(f_i) = h_k + f_i * g_k(i)
2. Finding the lower envelope
3. The minimum of the lower envelope is at a vertex

"""
Minimize 2*n*max(f*f)/sum(f)^2 over non-negative sequences.
Uses FISTA with adaptive LSE smoothing, multiplicative updates, 
and multi-scale exploration to find near-optimal sequences.
"""
import numpy as np
import time
from scipy.fft import fft, ifft


def fft_convolve_self(a):
    """Full linear self-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fsize = 1 << (size - 1).bit_length()
    A = fft(a, fsize)
    c = np.real(ifft(A * A))
    return c[:size]


def project_simplex(v, S):
    """Project v onto {x >= 0, sum(x) = S}."""
    n = len(v)
    v = np.asarray(v, dtype=np.float64)
    w = np.sort(v)[::-1]
    cumsum = np.cumsum(w)
    idx = np.arange(1, n + 1, dtype=np.float64)
    tc = (cumsum - S) / idx
    valid = tc <= w
    if not np.any(valid):
        return np.full(n, S / n)
    rho = int(np.max(np.where(valid)[0]))
    theta = (cumsum[rho] - S) / (rho + 1)
    return np.maximum(v - theta, 0.0)


def lse_gradient(a, c, beta):
    """Gradient of LSE_beta(c) with respect to a."""
    n = len(a)
    cm = c.max()
    e = np.exp(beta * (c - cm))
    tot = e.sum()
    if tot < 1e-300:
        return np.zeros(n)
    w = e / tot
    fsize = 1 << (len(w) + n - 1).bit_length()
    W = fft(w, fsize)
    A = fft(a, fsize)
    return 2.0 * np.real(ifft(W * np.conj(A)))[:n]


def subgradient_topk(a, c, top_k=10):
    """Subgradient using top-k lags (averaged)."""
    n = len(a)
    idx = np.argsort(c)[::-1][:top_k]
    # Weight by softmax of top-k values
    vals = c[idx]
    w = np.exp(vals - vals.max())
    w /= w.sum()
    
    grad = np.zeros(n)
    for i, k in enumerate(idx):
        # Gradient of c[k] = 2 * f[k-i] shifted
        lo = max(0, k - n + 1)
        hi = min(k, n - 1)
        js = np.arange(lo, hi + 1)
        grad[js] += w[i] * 2.0 * a[k - js]
    return grad


def multiplicative_update(a, c, S, beta=50.0, lr=0.1):
    """Multiplicative (mirror descent) update."""
    n = len(a)
    cm = c.max()
    w = np.exp(beta * (c - cm))
    tot = w.sum()
    if tot < 1e-300:
        return a.copy()
    w = w / tot
    fsize = 1 << (len(w) + n - 1).bit_length()
    W = fft(w, fsize)
    A = fft(a, fsize)
    rep = np.real(ifft(W * np.conj(A)))[:n]
    # Multiplicative update: reduce where repulsion is high
    a_new = a * np.exp(-lr * rep / max(a.max(), 1e-10))
    a_new = np.maximum(a_new, 1e-15)
    return project_simplex(a_new, S)

    a = project_simplex(a_init.copy(), S)
    y = a.copy()
    t = 1.0
    start = time.monotonic()
    best = np.inf
    best_a = a.copy()
    it = 0
    last_improve = 0
    stall_count = 0

    while time.monotonic() - start < max_time:
        it += 1
        beta = min(beta_max, beta_init * np.exp(beta_rate * it))
        
        c = fft_convolve_self(y)
        cur = c.max()
        if cur < best - 1e-10:
            best = cur
            best_a = y.copy()
            last_improve = it
            stall_count = 0
        else:
            stall_count += 1
        
        # Adaptive: if stalled, increase beta or add noise
        if stall_count > 1000:
            # Try multiplicative update
            if use_mult_update:
                y = multiplicative_update(y, c, S, beta=min(100.0, beta*0.5), lr=mult_lr)
                t = 1.0
            else:

                y = project_simplex(y + rng.normal(0, noise_scale, n), S)
                t = 1.0
            last_improve = it
            stall_count = 0

        grad = lse_gradient(y, c, beta)
        gnorm = np.linalg.norm(grad)
        if gnorm < 1e-12:
            break
        step = 1.0 / (2.0 * beta)

        t_new = 0.5 * (1.0 + np.sqrt(1.0 + 4.0 * t * t))
        y = x_new + ((t - 1.0) / t_new) * (x_new - a)
        y = np.maximum(y, 0.0)
        a = x_new
        t = t_new

    # Final check
    c_final = fft_convolve_self(a)
    if c_final.max() < best:

        best_a = a.copy()

def interpolate_sequence(a, new_n):
    """Interpolate sequence to new length."""
    n = len(a)
    if new_n == n:
        return a.copy()
    t_old = np.linspace(0, 1, n)
    t_new = np.linspace(0, 1, new_n)
    return np.interp(t_new, t_old, a)

- Or just: the optimal solution has at most n non-zero λ's (by complementary slackness)

Actually, for the dual LP: min M * 1^T λ s.t. A^T λ ≥ 1, λ ≥ 0.

The constraint A^T λ ≥ 1 means: for each coordinate i, sum_k λ_k * A[k, i] ≥ 1.

A[k, i] = f[k-i] (if 0 ≤ k-i < n).

So: sum_k λ_k * f[k-i] ≥ 1 for all i.

This means: (λ * f)(i) ≥ 1 for all i (where * is the cross-correlation).

The minimum of M * sum(λ) subject to (λ ⋆ f) ≥ 1, λ ≥ 0.

If we let μ_k = λ_k * M, this becomes:
min sum(μ) s.t. (μ ⋆ f) ≥ M, μ ≥ 0.

The optimal μ is the "minimum" set of weights on the lags such that the weighted cross-correlation with f is at least M everywhere.

For the primal, the optimal g is: g_i = max(0, sum_k λ_k * A[k,i] - ...). Actually by strong duality and complementary slackness, g_i > 0 only where (A^T λ)_i = 1 (the constraint is tight).

"""
Minimize 2*n*max(f*f)/sum(f)^2 over non-negative sequences.
Uses hybrid FISTA with adaptive LSE smoothing, exact subgradient steps,
multiplicative mirror-descent updates, and multi-scale exploration.
"""
import numpy as np
import time
from scipy.fft import fft, ifft


def fft_convolve_self(a):
    """Full linear self-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fsize = 1 << (size - 1).bit_length()
    A = fft(a, fsize)
    c = np.real(ifft(A * A))
    return c[:size]


def fft_cross_convolve(a, b):
    """Full linear cross-convolution of a and b via FFT."""
    n = max(len(a), len(b))
    size = len(a) + len(b) - 1
    fsize = 1 << (size - 1).bit_length()
    A = fft(a, fsize)
    B = fft(b, fsize)
    c = np.real(ifft(A * B))
    return c[:size]


def project_simplex(v, S):
    """Project v onto {x >= 0, sum(x) = S}. O(n log n)."""
    n = len(v)
    v = np.asarray(v, dtype=np.float64)
    w = np.sort(v)[::-1]
    cumsum = np.cumsum(w)
    idx = np.arange(1, n + 1, dtype=np.float64)
    tc = (cumsum - S) / idx
    valid = tc <= w
    if not np.any(valid):
        return np.full(n, S / n, dtype=np.float64)
    rho = int(np.max(np.where(valid)[0]))
    theta = (cumsum[rho] - S) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)


def lse_gradient(a, c, beta):
    """Gradient of LSE_beta(c) with respect to a."""
    n = len(a)
    cm = c.max()
    e = np.exp(beta * (c - cm))
    tot = e.sum()
    if tot < 1e-300:
        return np.zeros(n)
    w = e / tot
    fsize = 1 << (len(w) + n - 1).bit_length()
<    W = fft(w, fsize)
    A = fft(a, fsize)
    return 2.0 * np.real(ifft(W * np.conj(A)))[:n]


def exact_grad_peak(a, c, top_k=10):
    """
    Weighted gradient of the top-k peak lags of c.
    Returns gradient direction (to subtract for descent).
    """
    n = len(a)
    idx = np.argsort(c)[::-1][:top_k]
    vals = c[idx]
    # Exponential weighting favoring the highest peaks
    w = np.exp(100.0 * (vals - vals.max()))
    tot = w.sum()
    if tot < 1e-300:
        w = np.ones(top_k) / top_k
    else:
        w /= tot

    grad = np.zeros(n, dtype=np.float64)
    for i in range(top_k):
        k = int(idx[i])
        # Gradient of c[k] wrt a: 2*a[k-j] for valid j
        lo = max(0, k - n + 1)
        hi = min(k, n - 1)
        js = np.arange(lo, hi + 1)
        grad[js] += w[i] * 2.0 * a[k - js]
    return grad


def multiplicative_update(a, c, S, beta=50.0, lr=0.08):
    """Mirror descent (multiplicative) update to reduce peaks."""
    n = len(a)
    cm = c.max()
    e = np.exp(beta * (c - cm))
    tot = e.sum()
    if tot < 1e-300:
        return a.copy()
    w = e / tot
    fsize = 1 << (len(w) + n - 1).bit_length()
    W = fft(w, fsize)
    A = fft(a, fsize)
    rep = np.real(ifft(W * np.conj(A)))[:n]
    a_new = a * np.exp(-lr * rep / max(a.max(), 1e-10))
    a_new = np.maximum(a_new, 1e-15)
    s = a_new.sum()
    if s < 1e-10:
        return a.copy()
    return project_simplex(a_new * (S / s), S)


def subgradient_step(f, S, top_k=10, max_ls=8):
    """
    Exact subgradient step with bisection line search.
    Moves against the gradient of the peak lags.
    """
    n = len(f)
    c = fft_convolve_self(f)
    cur_peak = c.max()

    grad = exact_grad_peak(f, c, top_k=top_k)
    # Center the gradient to preserve sum
    grad_centered = grad - grad.mean()
    gnorm = np.linalg.norm(grad_centered)
    if gnorm < 1e-14:
        return f.copy(), cur_peak

    # Bisection on step size
    lo = 0.0
    hi = S / (gnorm * np.sqrt(n) + 1e-10) * 2.0
    best_f = f.copy()
    best_val = cur_peak

    for _ in range(max_ls):
        mid = (lo + hi) / 2.0
        f_try = project_simplex(f - mid * grad_centered, S)
        c_try = fft_convolve_self(f_try)
        val_try = c_try.max()
        if val_try < best_val * 1.0001:
            best_val = val_try
            best_f = f_try.copy()
            lo = mid
        else:
            hi = mid
    return best_f, best_val


def run_fista_loop(a_init, n, S, max_time, rng,
                   beta_init=10.0, beta_rate=0.002, beta_max=3000.0,
                   use_subgrad=False, subgrad_freq=50,
                   use_mult=False, mult_freq=200, mult_lr=0.06,
                   restart_patience=3000):
    """
    FISTA with adaptive beta, optional subgradient and multiplicative steps.
    """
    a = project_simplex(a_init.astype(np.float64).copy(), S)
    y = a.copy()
    t = 1.0
    start = time.monotonic()
    best = np.inf
    best_a = a.copy()
    it = 0
    last_improve = 0

    while time.monotonic() - start < max_time:
        it += 1
        beta = min(beta_max, beta_init * np.exp(beta_rate * it))

        c = fft_convolve_self(y)
        cur = c.max()
        if cur < best - 1e-12:
            best = cur
            best_a = y.copy()
            last_improve = it

        # Staleness: restart from best with small noise
        if it - last_improve > restart_patience:
            noise_scale = (0.002 + 0.003 * min((it - last_improve) / (2.0 * restart_patience), 1.0)) * S / np.sqrt(n)
            y = project_simplex(best_a + rng.normal(0, noise_scale, n), S)
            a = y.copy()
            t = 1.0
            last_improve = it
            continue

        # Choose update mode
        if use_subgrad and (it % subgrad_freq == 0):
            # Exact subgradient step
            y_new, val_new = subgradient_step(y, S, top_k=min(20, n // 500))
            if val_new < cur * 0.999:
                y = y_new
                a = y_new.copy()
                t = 1.0
                c_new = fft_convolve_self(y)
                if c_new.max() < best:
                    best = c_new.max()
                    best_a = y.copy()
                    last_improve = it
                continue

        if use_mult and (it % mult_freq == 0):
            # Multiplicative update
            y_new = multiplicative_update(y, c, S, beta=min(100.0, beta * 0.3), lr=mult_lr)
            c_new = fft_convolve_self(y_new)
            if c_new.max() <= cur * 1.01:
                y = y_new
                a = y_new.copy()
                t = 1.0
                if c_new.max() < best:
                    best = c_new.max()
                    best_a = y.copy()
                    last_improve = it
            continue

        # Standard FISTA step
        grad = lse_gradient(y, c, beta)
        gnorm = np.linalg.norm(grad)
        if gnorm < 1e-14:
            break
        step = 1.0 / (2.0 * beta)

        # Adaptive: if not improving, shrink step
        if it - last_improve > restart_patience // 3:
            step *= 0.5

        x_new = project_simplex(y - step * grad, S)
        t_new = 0.5 * (1.0 + np.sqrt(1.0 + 4.0 * t * t))
        y = x_new + ((t - 1.0) / t_new) * (x_new - a)
        y = np.maximum(y, 0.0)
        a = x_new
        t = t_new

    # Final check
    c_final = fft_convolve_self(a)
    if c_final.max() < best:
        best = c_final.max()
        best_a = a.copy()

    return best_a, best


def interpolate_seq(a, new_n):
    """Interpolate a sequence to a new length."""
    n = len(a)
    if new_n == n:
        return a.copy()
    t_old = np.linspace(0.0, 1.0, n)
    t_new = np.linspace(0.0, 1.0, new_n)
    return np.interp(t_new, t_old, a).astype(np.float64)

        if t4 > 20 and global_a is not None:
            n4 = len(global_a)
            S4 = np.sqrt(2.0 * n4)
            print("  Phase 4: Diverse restarts (%.0fs, n=%d)" % (t4, n4))
            inits = make_diverse_inits(n4, rng)
            # Also add perturbed best
            inits.append(global_a + rng.normal(0, 0.005 * S4 / np.sqrt(n4), n4))
            inits.append(global_a + rng.normal(0, 0.02 * S4 / np.sqrt(n4), n4))
            per_init = t4 / len(inits)
            for ii, ini in enumerate(inits):
                if time.monotonic() > deadline - 30:
                    break
                if per_init < 4:
                    break
                ini = project_simplex(np.maximum(ini, 0.01), S4)
                ai, mi = run_fista_loop(ini, n4, S4, per_init, rng,
                                         beta_init=15.0, beta_rate=0.003, beta_max=1000.0,
                                         use_subgrad=True, subgrad_freq=40)
                obji = 2.0 * n4 * mi / S4 ** 2
                if obji < global_best:
                    global_best = obji
                    global_a = ai.copy()
                    print("    Restart %d: obj=%.6f" % (ii, global_best))

    # --- Final intensive polish on the best ---
    remaining_final = deadline - time.monotonic()
    if remaining_final > 20 and global_a is not None:
        nf = len(global_a)
        Sf = np.sqrt(2.0 * nf)
        print("\n===== Final polish (%.0fs, n=%d) =====" % (remaining_final, nf))
        af, mf = run_fista_loop(global_a, nf, Sf, remaining_final * 0.8, rng,
                                 beta_init=500.0, beta_rate=0.0005, beta_max=10000.0,
                                 use_subgrad=True, subgrad_freq=10,
                                 restart_patience=8000)
        objf = 2.0 * nf * mf / Sf ** 2
        print("  Final polish: obj=%.6f" % objf)
        if objf < global_best:
            global_best = objf
            global_a = af.copy()

    # Verification
    if global_a is not None:
        final_list = [float(x) for x in np.clip(global_a, 0.0, 1000.0)]
        ver = evaluate_sequence(final_list)
        if np.isfinite(ver):
            print("\nFINAL: evaluate_sequence = %.6f (length=%d)" % (ver, len(final_list)))
        else:
            print("\nFINAL: evaluate_sequence rejected, using fallback")
            global_a = np.ones(256, dtype=np.float64) * (np.sqrt(2 * 256) / 256)
    else:
        print("\nNo valid solution found, using fallback")
        global_a = np.ones(256, dtype=np.float64) * (np.sqrt(2 * 256) / 256)

    global_a = np.clip(global_a, 0.0, 1000.0)
    if global_a.sum() < 0.01:
        global_a = np.ones(256, dtype=np.float64) * (np.sqrt(2 * 256) / 256)

    print("Returning length=%d, internal best=%.6f" % (len(global_a), global_best))
    return [float(x) for x in global_a]
