**Multiplicative Weight Descent (MWD):**

Minimize `f(a) = max_k c[k]` (or LSE approximation) subject to `a >= 0, sum(a) = S`.

Update rule:
1. Compute gradient `g` of the smoothed objective at current `a`
2. `a_new = a * exp(-eta * g)`
3. Normalize: `a_new = a_new * S / sum(a_new)`
4. Optionally: clip to [0, 1000] and renormalize

The step size `eta` should be small enough for convergence. A good heuristic is:
- `eta = 1 / max(g)` (or `eta = c / ||g||_infty` for some c < 1)
- Or use backtracking: try `eta`, if the objective increases, halve it.

For the LSE-smoothed objective:
- `f_smooth(a) = LSE(beta * c(a)) = c_max + (1/beta) * log(sum(exp(beta*(c-c_max))))`
- Gradient: `g[m] = 2 * sum_k w[k] * a[k-m]` where `w[k] = exp(beta*(c[k]-c_max)) / sum(exp(...))`

The LSE is a convex upper bound on the max, so minimizing LSE drives the max down.

**Key considerations:**
1. The step size should decrease over time (or use backtracking)
2. The beta should increase over time (to make LSE closer to max)
3. Need to handle the case where some `a[j]` become very small (underflow) - use log-domain or clipping

Let me also think about a "restart" strategy: if the objective stops improving for a while, add random noise to `a` and continue.

```python
def mwd_optimize(a_init, max_time, rng, beta_init=10, beta_rate=0.005, beta_max=5000):
    n = len(a_init)
    S = np.sqrt(2.0 * n)
    a = np.clip(a_init, 0, 1000).copy()
    a = a * S / a.sum()
    
    best_obj = compute_obj(a)
    best_a = a.copy()
    last_improve = 0
    it = 0
    start = time.monotonic()
    
    while time.monotonic() - start < max_time:
        it += 1
        beta = min(beta_max, beta_init * np.exp(beta_rate * it))
        
        c = fft_convolve_self(a)
        cur_obj = 2.0 * n * c.max() / (S * S)
        if cur_obj < best_obj - 1e-14:
            best_obj = cur_obj
            best_a = a.copy()
            last_improve = it
        
        # Compute LSE weights
        lse_val, w = lse_weights(c, beta)
        
        # Compute gradient
        g = smoothed_gradient(a, w)
        
        # Step size
        eta = 1.0 / max(np.max(np.abs(g)), 1e-10)
        eta = min(eta, 2.0 / beta)  # cap to avoid too-large steps
        
        # Multiplicative update
        log_a = np.log(np.maximum(a, 1e-300))
        log_a -= eta * g
        a_new = np.exp(log_a - log_a.max())  # avoid overflow
        a_new = a_new * S / a_new.sum()
        a_new = np.clip(a_new, 0, 1000)
        a_new = a_new * S / a_new.sum()
        
        # Check improvement
        obj_new = 2.0 * n * fft_convolve_self(a_new).max() / (S * S)
        if obj_new > cur_obj * 1.01:  # too much increase, reduce step
            eta *= 0.5
            log_a = np.log(np.maximum(a, 1e-300))
            log_a -= eta * g
            a_new = np.exp(log_a - log_a.max())
            a_new = a_new * S / a_new.sum()
            a_new = np.clip(a_new, 0, 1000)
            a_new = a_new * S / a_new.sum()
        
        a = a_new
        
        if it - last_improve > 3000:
            # Add noise to escape local minima
            noise = rng.normal(0, 0.01 * S / np.sqrt(n), n)
            a = a + noise
            a = np.maximum(a, 0)
            a = a * S / a.sum()
    
    return best_a, best_obj
```

Actually, here's another idea: **Use the fact that the problem is equivalent to minimizing the operator norm of a certain matrix**.

The convolution `c[k] = sum_j a[j]*a[k-j]` can be written as `a^T T_k a` where `T_k` is a (symmetric) Toeplitz matrix with 1s on the k-th diagonal.

So `max_k c[k] = max_k a^T T_k a`.

This is the maximum of a set of quadratic forms. We can write it as:
`max_k a^T T_k a = max_{p in simplex} sum_k p_k * a^T T_k a = max_{p in simplex} a^T (sum_k p_k T_k) a`

By minimax: `min_a max_p a^T (sum_k p_k T_k) a = min_a max_p a^T T(p) a`

This is a max-min problem. We can solve it iteratively:
- Given `a`, find `p* = argmax_p sum_k p_k * c[k]` (which is just the max, so `p*` is a point mass at the argmax)
- Given `p`, minimize `a^T T(p) a` subject to `a >= 0, sum a = S`

The inner problem is: minimize `a^T T(p) a` s.t. `a >= 0, sum a = S`.

This is a quadratic program! We could solve it exactly (or approximately) using CVXPY or a projected gradient method.

```python
def topk_gradient(a, k):
    """Compute gradient of sum of top-k convolution values."""
    n = len(a)
    c = fft_convolve_self(a)
    # Find top-k indices
    top_idx = np.argpartition(c, -k)[-k:]
    w = np.zeros(len(c))
    w[top_idx] = 1.0 / k
    # Gradient: g[m] = 2 * sum_l w[l] * a[l-m]
    fsize = 1 << (len(w) + n - 1).bit_length()
    W = fft(w, fsize)
    A = fft(a, fsize)
    g = 2.0 * np.real(ifft(W * np.conj(A)))[:n]
    return g, c
```

```python
"""
Minimize 2*n*max_conv/sum^2 over non-negative sequences.
Combines multiplicative weight descent (MWD) with top-k gradients,
FISTA with LSE smoothing, structured upsampling, and coordinate descent.
Key innovation: MWD with entropy mirror map avoids local minima that
trap projected gradient methods, and multi-scale search explores
different sequence lengths.
"""
import numpy as np
import time
from scipy.fft import fft, ifft


def fft_convolve_self(a):
    """Full self-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fsize = 1 << (size - 1).bit_length()
    A = fft(a, fsize)
    c = np.real(ifft(A * A))
    return c[:size]


def compute_obj(a):
    """Compute 2*n*max_conv/sum^2."""
    n = len(a)
    s = a.sum()
    if s < 1e-15:
        return np.inf
    c = fft_convolve_self(a)
    return 2.0 * n * c.max() / (s * s)


def project_simplex(v, S):
    """Project v onto {x >= 0, sum(x) = S}."""
    n = len(v)
    v = np.asarray(v, dtype=np.float64)
    mu = np.sort(v)[::-1]
    cumsum = np.cumsum(mu)
    idx = np.arange(1, n + 1, dtype=np.float64)
    cond = mu - (cumsum - S) / idx
    rho = np.where(cond > 0)[0]
    if len(rho) == 0:
        theta = 0.0
    else:
        theta = (cumsum[rho[-1]] - S) / (rho[-1] + 1)
    return np.maximum(v - theta, 0.0)


def lse_weights(c, beta):
    """Compute LSE value and softmax weights."""
    cm = c.max()
    shifted = beta * (c - cm)
    shifted -= shifted.max()
    e = np.exp(shifted)
    tot = e.sum()
    if tot < 1e-300:
        w = np.zeros(len(c))
        w[int(np.argmax(c))] = 1.0
        lse = cm
    else:
        w = e / tot
        lse = cm + np.log(tot) / beta
    return lse, w


def compute_smoothed_grad(a, w):
    """Gradient of sum_l w[l]*c[l] w.r.t. a. Uses FFT cross-correlation."""
    n = len(a)
    fsize = 1 << (len(w) + n - 1).bit_length()
    W = fft(w, fsize)
    A = fft(a, fsize)
    grad = 2.0 * np.real(ifft(W * np.conj(A)))[:n]
    return grad


def topk_subgradient(a, c, k):
    """Subgradient from top-k lags of the convolution."""
    n = len(a)
    k = min(k, len(c))
    idx = np.argpartition(c, -k)[-k:]
    w = np.zeros(len(c))
    w[idx] = 1.0 / k
    fsize = 1 << (len(w) + n - 1).bit_length()
    W = fft(w, fsize)
    A = fft(a, fsize)
    return 2.0 * np.real(ifft(W * np.conj(A)))[:n]


def mwd_optimize(a_init, max_time, rng, beta_init=20.0, beta_rate=0.008,
                 beta_max=20000.0, use_topk=False, topk_max=16):
    """
    Multiplicative Weight Descent with LSE or top-k smoothing.
    Uses entropy mirror map: a_new = a * exp(-eta * g), then normalize.
    """
    n = len(a_init)
    S = np.sqrt(2.0 * n)
    a = np.clip(np.asarray(a_init, dtype=np.float64), 0, 1000).copy()
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) * S / n
    else:
        a = a * (S / s)

    c = fft_convolve_self(a)
    best_obj = 2.0 * n * c.max() / (S * S)
    best_a = a.copy()
    last_improve = 0
    it = 0
    start = time.monotonic()
    eta_base = 1.0

    while time.monotonic() - start < max_time:
        it += 1
        beta = min(beta_max, beta_init * np.exp(beta_rate * it))

        cur_obj = 2.0 * n * c.max() / (S * S)
        if cur_obj < best_obj - 1e-13:
            best_obj = cur_obj
            best_a = a.copy()
            last_improve = it

        if use_topk:
            stuck = it - last_improve
            k = min(topk_max, 2 + stuck // 200)
            g = topk_subgradient(a, c, k)
        else:
            lse_val, w = lse_weights(c, beta)
            g = compute_smoothed_grad(a, w)

        gnorm_inf = np.max(np.abs(g))
        if gnorm_inf < 1e-15:
            break

        eta = eta_base / gnorm_inf
        eta = min(eta, 3.0 / max(beta, 1.0))

        # Multiplicative update in log domain
        log_a = np.log(np.maximum(a, 1e-300))
        log_a -= eta * g
        # Prevent overflow
        log_a -= log_a.max()
        a_new = np.exp(log_a)
        sn = a_new.sum()
        if sn < 1e-300:
            a_new = a.copy()
        else:
            a_new = a_new * (S / sn)
            a_new = np.clip(a_new, 0.0, 1000.0)
            sn2 = a_new.sum()
            if sn2 > 1e-15:
                a_new = a_new * (S / sn2)
            else:
                a_new = a.copy()

        # Evaluate new point
        c_new = fft_convolve_self(a_new)
        obj_new = 2.0 * n * c_new.max() / (S * S)

        if obj_new > cur_obj * 1.005:
            # Step too large, halve and retry
            eta *= 0.5
            log_a = np.log(np.maximum(a, 1e-300))
            log_a -= eta * g
            log_a -= log_a.max()
            a_new = np.exp(log_a)
            sn = a_new.sum()
            if sn > 1e-300:
                a_new = a_new * (S / sn)
                a_new = np.clip(a_new, 0.0, 1000.0)
                c_new = fft_convolve_self(a_new)

        a = a_new
        c = c_new

        # Adapt eta
        if obj_new < cur_obj:
            eta_base = min(eta_base * 1.02, 5.0)
        else:
            eta_base = max(eta_base * 0.98, 0.1)

        # Periodic noise to escape local minima
        stuck = it - last_improve
        if stuck > 2000 and it % 50 == 0:
            noise_scale = max(1e-5, 0.005 * S / np.sqrt(n) * np.exp(-stuck / 5000.0))
            a = a + rng.normal(0, noise_scale, n)
            a = np.maximum(a, 0.0)
            a = a * (S / a.sum())
            c = fft_convolve_self(a)

        if stuck > 20000:
            break

    return best_a, best_obj


def run_fista(a_init, max_time, rng, beta_init=20.0, beta_rate=0.01,
              beta_max=50000.0, step_scale=1.0, use_backtrack=True):
    """FISTA with adaptive LSE smoothing."""
    n = len(a_init)
    S = np.sqrt(2.0 * n)
    a = np.clip(np.asarray(a_init, dtype=np.float64), 0, 1000).copy()
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) * S / n
    else:
        a = a * (S / s)

    y = a.copy()
    t_mom = 1.0
    start = time.monotonic()
    c = fft_convolve_self(a)
    best_obj = 2.0 * n * c.max() / (S * S)
    best_a = a.copy()
    it = 0
    last_improve = 0
    step = step_scale / max(beta_init, 1.0)

    while time.monotonic() - start < max_time:
        it += 1
        beta = min(beta_max, beta_init * np.exp(beta_rate * it))
        lse_val, w = lse_weights(c, beta)
        g = compute_smoothed_grad(y, w)
        cur_obj = 2.0 * n * c.max() / (S * S)
        if cur_obj < best_obj - 1e-14:
            best_obj = cur_obj
            best_a = y.copy()
            last_improve = it

        gnorm = np.linalg.norm(g)
        if gnorm < 1e-15:
            break

        if use_backtrack:
            step_local = step
            x_trial = project_simplex(y - step_local * g, S)
            obj_trial = 2.0 * n * fft_convolve_self(x_trial).max() / (S * S)
            bt = 0
            while obj_trial > cur_obj + 1e-12 and step_local > 1e-14 and bt < 5:
                step_local *= 0.5
                x_trial = project_simplex(y - step_local * g, S)
                obj_trial = 2.0 * n * fft_convolve_self(x_trial).max() / (S * S)
                bt += 1
            if bt > 2:
                step = step_local * 0.8
            else:
                step = min(step * 1.02, 2.0 / max(beta, 1.0))
            x_new = x_trial
        else:
            step = step_scale / max(beta, 1.0)
            x_new = project_simplex(y - step * g, S)

        t_new = 0.5 * (1.0 + np.sqrt(1.0 + 4.0 * t_mom * t_mom))
        y = x_new + ((t_mom - 1.0) / t_new) * (x_new - a)
        y = np.maximum(y, 0.0)
        ys = y.sum()
        if ys > 1e-15:
            y = y * (S / ys)
        a = x_new
        t_mom = t_new
        c = fft_convolve_self(a)

        stuck = it - last_improve
        if stuck > 3000:
            t_mom = 1.0
            noise_scale = max(1e-6, 0.003 * S / np.sqrt(n) * np.exp(-stuck / 5000.0))
            y = project_simplex(y + rng.normal(0, noise_scale, n), S)
        if stuck > 20000:
            break

    return best_a, best_obj


def fast_coordinate_descent(a_init, max_time, rng, max_iter=None):
    """
    Fast coordinate descent: transfer mass from high-gradient to low-gradient
    coordinates at the peak lag. O(n) per iteration via FFT-based gradient.
    """
    n = len(a_init)
    S = np.sqrt(2.0 * n)
    a = np.clip(np.asarray(a_init, dtype=np.float64), 0, 1000).copy()
    a = a * (S / a.sum())
    c = fft_convolve_self(a)
    start = time.monotonic()
    best_obj = 2.0 * n * c.max() / (S * S)
    best_a = a.copy()
    last_improve = 0
    it = 0
    total_iter = 0

    while time.monotonic() - start < max_time:
        it += 1
        total_iter += 1
        cur_obj = 2.0 * n * c.max() / (S * S)
        if cur_obj < best_obj - 1e-14:
            best_obj = cur_obj
            best_a = a.copy()
            last_improve = it

        stuck = it - last_improve
        if stuck > 10000:
            break

        # Find top few peak lags
        top_k = min(5, 2 * n - 1)
        top_idx = np.argpartition(c, -top_k)[-top_k:]
        top_idx = top_idx[np.argsort(c[top_idx])[::-1]]

        # Compute combined gradient from top-k lags
        w = np.zeros(2 * n - 1)
        # Weight by how much above the "mean" each lag is
        c_mean = np.mean(c)
        weights = np.maximum(c[top_idx] - c_mean, 0)
        if weights.sum() < 1e-15:
            weights = np.ones(top_k)
        else:
            weights = weights / weights.sum()
        for i, idx in enumerate(top_idx):
            w[int(idx)] = weights[i]

        g = compute_smoothed_grad(a, w)

        # Find source (high g*a, large a) and target (low g, small a)
        src_score = g * a
        tgt_score = -g * (S / n - a)

        n_src = min(20, n // 2)
        n_tgt = min(20, n // 2)
        src_candidates = np.argsort(src_score)[::-1][:n_src]
        tgt_candidates = np.argsort(tgt_score)[:n_tgt]

        best_delta_obj = cur_obj + 1e-15
        best_move = None

        for j in src_candidates[:10]:
            for l in tgt_candidates[:10]:
                if j == l or a[j] < 1e-12:
                    continue
                delta = a[j] * 0.05
                if delta < 1e-14:
                    continue
                # Fast estimate: change in g at peak lags
                # New g at peak: reduce contribution from j, add from l
                # c[k] changes by: -delta*a[k-j] + delta*a[k-l]
                new_max = cur_max_est = c.max()
                # Approximate: check the top few lags
                for kk in top_idx[:3]:
                    kk = int(kk)
                    dj = a[max(0, min(n - 1, kk - int(j)))] if 0 <= kk - int(j) < n else 0.0
                    dl = a[max(0, min(n - 1, kk - int(l)))] if 0 <= kk - int(l) < n else 0.0
                    new_c_kk = c[kk] - delta * dj + delta * dl
                    if new_c_kk > new_max:
                        new_max = new_c_kk
                new_obj = 2.0 * n * new_max / (S * S)
                if new_obj < best_delta_obj:
                    best_delta_obj = new_obj
                    best_move = (int(j), int(l), delta)

        if best_move is not None:
            j, l, delta = best_move
            a[j] -= delta
            a[l] += delta
            # Update c incrementally
            for kk in range(max(0, int(j)), min(2 * n - 1, int(j) + n)):
                jj = kk - int(j)
                if 0 <= jj < n:
                    c[kk] -= delta * a[jj]
            for kk in range(max(0, int(l)), min(2 * n - 1, int(l) + n)):
                ll = kk - int(l)
                if 0 <= ll < n:
                    c[kk] += delta * a[ll]
            c = np.maximum(c, 0)
        else:
            # No improvement, try random perturbation
            if stuck > 500:
                j = int(rng.integers(0, n))
                l = int(rng.integers(0, n))
                if j != l and a[j] > 1e-12:
                    delta = a[j] * 0.02
                    a[j] -= delta
                    a[l] += delta
                    c = fft_convolve_self(a)

        # Periodic full recompute
        if it % 50 == 0:
            c = fft_convolve_self(a)

    return best_a, best_obj


def structured_upsample(a, factor=2, rng=None):
    """
    Upsample with structured high-frequency perturbation.
    Interpolates the base signal and adds a small random phase component
    to give the optimizer more degrees of freedom.
    """
    n = len(a)
    n_new = n * factor
    t_old = np.linspace(0, 1, n, endpoint=False)
    t_new = np.linspace(0, 1, n_new, endpoint=False)
    a_base = np.interp(t_new, t_old, a)

    if rng is not None:
        # Add small structured perturbation (zero-mean to preserve sum)
        freq = rng.integers(3, 10)
        phase = rng.uniform(0, 2 * np.pi)
        perturbation = np.sin(2 * np.pi * freq * t_new + phase)
        perturbation -= perturbation.mean()
        a_base = a_base + 0.02 * a_base.mean() / (n_new / n) * perturbation
        a_base = np.maximum(a_base, 0)

    if a_base.sum() < 1e-15:
        a_base = np.ones(n_new)
    return a_base


def make_diverse_init(n, method, rng):
    """Create various initial sequences for diverse starts."""
    S = np.sqrt(2.0 * n)
    tt = np.linspace(0, 1, n, endpoint=False)
    if method == "cosine":
        a = 0.5 + 0.5 * np.cos(2 * np.pi * tt)
    elif method == "gaussian":
        a = np.exp(-3.0 * (tt - 0.5) ** 2 / (0.2 ** 2))
    elif method == "random":
        a = rng.random(n) + 0.05
    elif method == "bimodal":
        a = np.exp(-10 * (tt - 0.3) ** 2) + np.exp(-10 * (tt - 0.7) ** 2)
    elif method == "sawtooth":
        a = np.abs((tt * 4) % 1 - 0.5) + 0.1
    elif method == "platypus":
        a = 1.0 + 0.3 * np.sin(2 * np.pi * 2 * tt) + 0.2 * np.sin(2 * np.pi * 5 * tt + 0.5)
        a = np.abs(a)
    else:
        a = np.ones(n)
    a = np.maximum(a, 0.001)
    return a * (S / a.sum())


def multi_beta_sweep(a_init, max_time, rng, betas=None):
    """
    Run MWD with a sequence of increasing betas (simulated annealing style).
    Each beta gets a fraction of the total time.
    """
    if betas is None:
        betas = [5, 10, 20, 50, 100, 200, 500, 1000, 3000, 10000]

    n = len(a_init)
    S = np.sqrt(2.0 * n)
    a = np.clip(np.asarray(a_init, dtype=np.float64), 0, 1000).copy()
    a = a * (S / a.sum())
    start = time.monotonic()

    best_obj = compute_obj(a)
    best_a = a.copy()

    # Allocate time proportionally (more time for higher betas)
    total_weight = sum(np.sqrt(b) for b in betas)
    for beta in betas:
        if time.monotonic() - start >= max_time:
            break
        frac = np.sqrt(beta) / total_weight
        t_alloc = frac * max_time * 0.7
        t_remaining = max_time - (time.monotonic() - start)
        t_alloc = min(t_alloc, t_remaining * 0.5)
        if t_alloc < 2:
            continue

        a, obj = mwd_optimize(a, t_alloc, rng, beta_init=beta,
                              beta_rate=0.002, beta_max=beta * 10,
                              use_topk=False)
        if obj < best_obj:
            best_obj = obj
            best_a = a.copy()
            print("    beta=%d: obj=%.6f" % (beta, obj))

    return best_a, best_obj


def propose_candidate(seed=42, budget_s=2400, **kwargs):
    """
    Search for non-negative sequence minimizing 2*n*max_conv/sum^2.
    Multi-phase: MWD refinement, FISTA, coordinate descent, upsampling.
    """
    rng = np.random.default_rng(seed)
    budget_s = float(budget_s)
    deadline = time.monotonic() + max(0.0, budget_s - 60.0)

    global_best_obj = np.inf
    global_best_a = None

    # Get starting point from previous best
    a_start = None
    try:
        a_start = np.asarray(height_sequence_1, dtype=np.float64).reshape(-1)
        a_start = np.clip(a_start, 0, 1000)
        if a_start.sum() < 0.01:
            a_start = None
    except Exception:
        a_start = None

    if a_start is None:
        n = 8192
        a_start = make_diverse_init(n, "cosine", rng)

    n0 = len(a_start)
    obj0 = compute_obj(a_start)
    print("Initial: n=%d, obj=%.6f" % (n0, obj0))
    global_best_obj = obj0
    global_best_a = a_start.copy()

    # === Phase 1: MWD with multi-beta sweep at current n (30% time) ===
    remaining = deadline - time.monotonic()
    p1_time = remaining * 0.30
    if p1_time > 60:
        print("\n=== Phase 1: MWD multi-beta (budget %.0fs) ===" % p1_time)
        a_mwd, obj_mwd = multi_beta_sweep(global_best_a, p1_time, rng,
                                          betas=[5, 10, 30, 100, 300, 1000, 3000, 10000])
        print("  MWD sweep: obj=%.6f" % obj_mwd)
        if obj_mwd < global_best_obj:
            global_best_obj = obj_mwd
            global_best_a = a_mwd.copy()

        # Also try MWD with top-k subgradient
        remaining1 = deadline - time.monotonic()
        if remaining1 > 30:
            a_mwd2, obj_mwd2 = mwd_optimize(global_best_a, remaining1 * 0.6, rng,
                                             beta_init=50, beta_rate=0.005,
                                             beta_max=50000, use_topk=True, topk_max=32)
            print("  MWD topk: obj=%.6f" % obj_mwd2)
            if obj_mwd2 < global_best_obj:
                global_best_obj = obj_mwd2
                global_best_a = a_mwd2.copy()

    # === Phase 2: FISTA with different hyperparameters (20% time) ===
    remaining = deadline - time.monotonic()
    p2_time = remaining * 0.20
    if p2_time > 30:
        print("\n=== Phase 2: FISTA (budget %.0fs) ===" % p2_time)
        variants = [
            (30, 0.012, 50000, 1.0, True),
            (100, 0.006, 100000, 0.7, True),
            (500, 0.003, 200000, 0.4, False),
        ]
        per_time = p2_time / len(variants)
        for i, (bi, br, bm, ss, bt) in enumerate(variants):
            if time.monotonic() >= deadline:
                break
            rem = min(per_time, deadline - time.monotonic())
            if rem < 5:
                break
            a_opt, obj_opt = run_fista(global_best_a, rem, rng,
                                       beta_init=bi, beta_rate=br,
                                       beta_max=bm, step_scale=ss,
                                       use_backtrack=bt)
            print("  FISTA%d: obj=%.6f" % (i + 1, obj_opt))
            if obj_opt < global_best_obj:
                global_best_obj = obj_opt
                global_best_a = a_opt.copy()

    # === Phase 3: Coordinate descent (15% time) ===
    remaining = deadline - time.monotonic()
    p3_time = remaining * 0.15
    if p3_time > 30:
        print("\n=== Phase 3: Coordinate descent (budget %.0fs) ===" % p3_time)
        a_cd, obj_cd = fast_coordinate_descent(global_best_a, p3_time, rng)
        print("  Coord descent: obj=%.6f" % obj_cd)
        if obj_cd < global_best_obj:
            global_best_obj = obj_cd
            global_best_a = a_cd.copy()

        # Quick FISTA polish after CD
        remaining3 = deadline - time.monotonic()
        if remaining3 > 10:
            a_pol, obj_pol = run_fista(global_best_a, remaining3 * 0.5, rng,
                                       beta_init=200, beta_rate=0.005,
                                       beta_max=100000, step_scale=0.5,
                                       use_backtrack=True)
            print("  FISA polish: obj=%.6f" % obj_pol)
            if obj_pol < global_best_obj:
                global_best_obj = obj_pol
                global_best_a = a_pol.copy()

    # === Phase 4: Upsample to 2n (20% time) ===
    remaining = deadline - time.monotonic()
    p4_time = remaining * 0.20
    n_current = len(global_best_a)
    if p4_time > 60 and n_current <= 16384:
        n2 = n_current * 2
        print("\n=== Phase 4: Upsample to n=%d (budget %.0fs) ===" % (n2, p4_time))
        a_up = structured_upsample(global_best_a, factor=2, rng=rng)
        S2 = np.sqrt(2.0 * n2)
        a_up = a_up * (S2 / a_up.sum())
        obj_up = compute_obj(a_up)
        print("  Upsampled initial: obj=%.6f" % obj_up)
        if obj_up < global_best_obj:
            global_best_obj = obj_up
            global_best_a = a_up.copy()

        # MWD on upsampled
        rem4 = min(p4_time * 0.5, deadline - time.monotonic())
        if rem4 > 20:
            a_up1, obj_up1 = mwd_optimize(a_up, rem4, rng,
                                          beta_init=5, beta_rate=0.005,
                                          beta_max=5000, use_topk=False)
            print("  MWD upsampled: obj=%.6f" % obj_up1)
            if obj_up1 < global_best_obj:
                global_best_obj = obj_up1
                global_best_a = a_up1.copy()

        # FISTA on upsampled
        rem4 = deadline - time.monotonic()
        if rem4 > 20:
            a_up2, obj_up2 = run_fista(global_best_a, rem4 * 0.6, rng,
                                       beta_init=10, beta_rate=0.008,
                                       beta_max=20000, step_scale=1.0,
                                       use_backtrack=False)
            print("  FISTA upsampled: obj=%.6f" % obj_up2)
            if obj_up2 < global_best_obj:
                global_best_obj = obj_up2
                global_best_a = a_up2.copy()

    # === Phase 5: Try a different n (fresh start) (10% time) ===
    remaining = deadline - time.monotonic()
    p5_time = remaining * 0.10
    if p5_time > 30:
        print("\n=== Phase 5: Fresh starts at different n (budget %.0fs) ===" % p5_time)
        # Try a few different n values with different initializations
        test_ns = [n0, n0 * 3 // 2, n0 * 2]
        test_ns = [x for x in test_ns if x <= 32768 and x >= 1024]
        # Remove duplicates
        test_ns = list(set(test_ns))
        per_time = p5_time / max(len(test_ns), 1)

        for nn in test_ns:
            if time.monotonic() >= deadline:
                break
            rem = min(per_time, deadline - time.monotonic())
            if rem < 10:
                break
            for method in ["cosine", "random"]:
                rem2 = rem / 2
                if rem2 < 5:
                    break
                a_t = make_diverse_init(nn, method, rng)
                a_opt, obj_opt = mwd_optimize(a_t, rem2, rng,
                                              beta_init=10, beta_rate=0.01,
                                              beta_max=5000, use_topk=False)
                print("  n=%d %s: obj=%.6f" % (nn, method, obj_opt))
                if obj_opt < global_best_obj:
                    global_best_obj = obj_opt
                    global_best_a = a_opt.copy()

    # === Phase 6: Final intensive polish (5% time) ===
    remaining = deadline - time.monotonic()
    p6_time = remaining * 0.90
    if p6_time > 10:
        print("\n=== Phase 6: Final polish (budget %.0fs) ===" % p6_time)
        # High-beta MWD
        a_pol, obj_pol = mwd_optimize(global_best_a, p6_time * 0.4, rng,
                                      beta_init=1000, beta_rate=0.003,
                                      beta_max=200000, use_topk=True, topk_max=64)
        print("  Final MWD: obj=%.6f" % obj_pol)
        if obj_pol < global_best_obj:
            global_best_obj = obj_pol
            global_best_a = a_pol.copy()

        # Final FISTA with very high beta
        rem6 = deadline - time.monotonic()
        if rem6 > 5:
            a_pol2, obj_pol2 = run_fista(global_best_a, rem6, rng,
                                         beta_init=5000, beta_rate=0.001,
                                         beta_max=500000, step_scale=0.3,
                                         use_backtrack=True)
            print("  Final FISTA: obj=%.6f" % obj_pol2)
            if obj_pol2 < global_best_obj:
                global_best_obj = obj_pol2
                global_best_a = a_pol2.copy()

    # Final verification
    if global_best_a is not None:
        final_list = [float(x) for x in np.clip(global_best_a, 0.0, 1000.0)]
        ver = evaluate_sequence(final_list)
        if np.isfinite(ver):
            print("\nFinal verified: obj=%.6f, n=%d" % (ver, len(final_list)))
            global_best_obj = ver
        else:
            print("WARNING: invalid result from evaluator, using fallback")
            n_fb = 8192
            global_best_a = np.ones(n_fb) * (np.sqrt(2 * n_fb) / n_fb)
            final_list = [float(x) for x in global_best_a]
    else:
        n_fb = 8192
        global_best_a = np.ones(n_fb) * (np.sqrt(2 * n_fb) / n_fb)
        final_list = [float(x) for x in global_best_a]

    return final_list
```
