- $k-i = j$ i.e. $i = k-j$: $a[k-j] \cdot a[j]$ (if valid and $k-j \neq j$)
- If $k = 2j$ (so $i = j$ and $k-i = j$ are the same): $a[j]^2$

So:
- If $k \neq 2j$: $b[k] = c_k + 2a[j]a[k-j]$ (if both $j$ and $k-j$ are valid indices)
  where $c_k = \sum_{i \neq j, i \neq k-j} a[i]a[k-i]$
- If $k = 2j$: $b[k] = c_k + a[j]^2$ (plus cross terms from other valid $i$)

This makes the max a piecewise-linear (or quadratic at $k=2j$) function of $a[j]$. The optimal $a[j]$ can be found by 1D search.

But doing this for all $j$ in each sweep is $O(n \cdot 2n) = O(n^2)$ per sweep, which for $n = 8192$ is about $134 \times 10^6$ operations per sweep. That's feasible but might be slow in Python.
