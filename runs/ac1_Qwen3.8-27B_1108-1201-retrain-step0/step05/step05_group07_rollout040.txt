Let me now think about FISTA more carefully.

FISTA (Beck & Teboulle, 2009):
- y_k = x_k + ((t_k - 1) / (t_{k+1})) * (x_k - x_{k-1})
- x_{k+1} = P(y_k - (1/L) * grad(f)(y_k))
- t_{k+1} = (1 + sqrt(1 + 4*t_k^2)) / 2

where P is the projection onto the constraint set, and L is the Lipschitz constant of the gradient.

For our problem:
- f(a) = LSE_beta(conv(a,a)) = (1/beta) * log(sum_k exp(beta * c_k))
- Constraint: a >= 0, sum(a) = S
- P(v) = project onto simplex {a >= 0, sum(a) = S}

The Lipschitz constant L: The gradient of f is grad = (2/beta) * conv(reversed_a, w) (approximately). The Hessian involves second derivatives of the convolution, which are bounded. For a practical approach, we can use backtracking line search instead of knowing L exactly.

**Backtracking line search for FISTA:**
- Start with step = 1/L (initial guess)
- Check: f(y - step * grad(y)) <= f(y) - 0.5 * step * ||grad(y)||^2
- If not, step *= 0.5 and retry

This should work well.

Let me now think about the **beta schedule**. The LSE with parameter beta approximates the max:
- beta small: LSE ≈ mean (smooth, easy to optimize)
- beta large: LSE ≈ max (sharp, harder to optimize but more accurate)

A good schedule:
- Start with beta = 10-50 (smooth enough for fast convergence)
- Increase beta geometrically: beta *= 1.01 or 1.05 per step
- Cap at beta = 5000-20000 (close to true max)

The key insight: at each beta level, we should converge well before increasing beta. One approach:
- For each beta level, run FISTA until convergence (or time budget)
- Then increase beta and continue

But this might be too slow. Alternative:
- Increase beta every K steps (e.g., K=100)
- Use the current iterate as warm start for the new beta

Let me also think about **coordinate descent** for the final polishing phase.

Coordinate descent:
- Pick a coordinate i
- Optimize over a_i while keeping other coordinates fixed
- The objective as a function of a_i is:
  obj(a_i) = 2n * max_k c_k(a_i) / (S)^2  (since S is fixed)
  where c_k(a_i) = c_k_original + a_i * (a[k-i] + a[i-k]) - a_i^2 * delta(k, 2i)
  (approximately, for the relevant lags)

Actually, since S is fixed, changing a_i requires adjusting another coordinate to maintain the sum. This makes coordinate descent more complex.

Alternative: **Block coordinate descent on pairs**. Pick two coordinates (i, j), optimize over a_i and a_j (with the constraint a_i + a_j = constant). This is a 2D optimization that can be done exactly.

Or even simpler: **Swap-based local search**. Pick two coordinates i, j. Transfer mass from one to the other: a_i -> a_i + delta, a_j -> a_j - delta. Find the optimal delta (or a few candidate deltas) and accept if it improves.

This is like a specialized form of simulated annealing / local search.

"""
Minimize 2*n*max(conv(a,a))/(sum(a))^2 over non-negative sequences.
Uses FISTA-momentum gradient descent on LSE-smoothed objective with adaptive beta,
swap-based local search, and multi-restart strategy.

import numpy as np
from scipy.fft import fft, ifft
import time


def fft_convolve_self(a):
    """Full linear self-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fsize = 1 << (size - 1).bit_length()
    A = fft(a, fsize)
    c = np.real(ifft(A * A))
    return c[:size]


def project_simplex(v, S):
    """Project v onto {x >= 0, sum(x) = S}."""
    n = len(v)
    v = np.asarray(v, dtype=np.float64).copy()
    if S <= 0:
        return np.zeros(n)
    w = np.sort(v)[::-1]
    cumsum = np.cumsum(w)
    idx = np.arange(1, n + 1, dtype=np.float64)
    tc = (cumsum - S) / idx
    valid = tc <= w
    if not np.any(valid):
        rho = n
    else:
        rho = int(np.max(np.where(valid)[0]) + 1)
    theta = (cumsum[rho - 1] - S) / rho
    result = np.maximum(v - theta, 0.0)
    # Correct for floating point
    diff = S - result.sum()
    if abs(diff) > 1e-12:
        idx_max = np.argmax(result)
        result[idx_max] += diff
        result[idx_max] = max(result[idx_max], 0.0)
    return result


def compute_lse_grad(a, c, beta):
    """Compute gradient of (1/beta)*log(sum exp(beta*c)) w.r.t. a."""
    n = len(a)
    cm = c.max()
    scaled = beta * (c - cm)
    scaled = np.clip(scaled, -700, 700)
    e = np.exp(scaled)
    tot = e.sum()
    if tot < 1e-300:
        return np.zeros(n)
    w = e / tot
    fsize = 1 << (len(w) + n - 1).bit_length()
    W = fft(w, fsize)
    A = fft(a, fsize)
    return 2.0 * np.real(ifft(W * np.conj(A)))[:n]


def lse_value(c, beta):
    """Compute LSE of c with given beta."""
    cm = c.max()
    scaled = beta * (c - cm)
    scaled = np.clip(scaled, -700, 700)
    return cm + np.log(np.exp(scaled).sum()) / beta


def obj_value_from_conv(n, c_max, S):
    """Compute objective from convolution max and sum."""
    if S < 0.01:
        return np.inf
    return 2.0 * n * c_max / (S * S)


def fista_lse_optimize(a0, S, max_time, rng, beta_init=10.0, beta_max=10000.0,
                       beta_growth=1.003, verbose=True):
    """
    FISTA-momentum optimization on LSE-smoothed objective.
    Minimizes max(conv(a,a)) subject to a>=0, sum(a)=S.
    """
    n = len(a0)
    a = project_simplex(a0, S).copy()
    a_prev = a.copy()
    t_mom = 1.0
    beta = beta_init

    c = fft_convolve_self(a)
    best_max = c.max()
    best_a = a.copy()
    no_improve = 0

    start = time.monotonic()
    it = 0

    while time.monotonic() - start < max_time:
        it += 1

        # FISTA momentum extrapolation
        t_new = (1.0 + np.sqrt(1.0 + 4.0 * t_mom * t_mom)) / 2.0
        momentum = (t_mom - 1.0) / t_new
        y = a + momentum * (a - a_prev)
        # Ensure y is non-negative for gradient computation
        y = np.maximum(y, 0.0)

        # Compute gradient at y
        c_y = fft_convolve_self(y)
        grad = compute_lse_grad(y, c_y, beta)
        gnorm = np.linalg.norm(grad)

        if gnorm < 1e-15:
            break

        # Adaptive step size: proportional to gap / gradient norm squared
        c_curr = fft_convolve_self(a)
        gap = c_curr.max() - c_curr[1:-1].mean() if len(c_curr) > 2 else c_curr.max()
        gap = max(gap, 1e-10)

        # Step size: balance between gap-based and norm-based
        step_gap = 2.0 * gap / (gnorm * gnorm + 1e-30)
        step_norm = 1.0 / gnorm
        step = min(step_gap, step_norm, 5.0 / (beta * S + 1e-10))
        step = max(step, 1e-8 / gnorm)

        # Take step with projection
        a_try = project_simplex(a - step * grad, S)

        # Check if we accepted (compare LSE values)

        lse_try = lse_value(fft_convolve_self(a_try), beta)

        if lse_try > lse_y + 1e-10:
            # Reject: try smaller step
            step *= 0.25
            a_try = project_simplex(a - step * grad, S)

        a_prev = a
        a = a_try
        t_mom = t_new

        # Update beta (adaptively increase)
        beta = min(beta_max, beta * beta_growth)

        # Track best using true max
        c = fft_convolve_self(a)
        cur_max = c.max()
        if cur_max < best_max - 1e-10:
            best_max = cur_max
            best_a = a.copy()
            no_improve = 0
        else:
            no_improve += 1

            noise_scale = max(0.003, 0.02 * (1.0 - elapsed_frac)) * S / np.sqrt(n)

            no_improve = 0

            print(f"    FISTA: it={it}, t={elapsed:.0f}s, beta={beta:.0f}, "
                  f"max={best_max:.6f}, obj={obj:.6f}, step={step:.2e}")

    return best_a, best_max


def local_search_swaps(a0, S, max_time, rng, verbose=True):
    """
    Local search using swap moves: a[i] += delta, a[j] -= delta.
    Accept if objective improves.
    """
    n = len(a0)
    a = a0.copy()
    c = fft_convolve_self(a)
    best_max = c.max()
    best_a = a.copy()
    no_improve = 0

    start = time.monotonic()
    it = 0
    delta_base = S / np.sqrt(n)

    while time.monotonic() - start < max_time:
        it += 1

        # Pick random pair
        i = rng.integers(0, n)
        j = rng.integers(0, n)
        if i == j:
            continue

        # Choose delta
        progress = (time.monotonic() - start) / max_time
        delta_scale = delta_base * (1.0 - 0.7 * progress)
        delta = delta_scale * rng.uniform(0.1, 1.0)

        # Ensure non-negativity
        if a[j] < delta:
            delta = a[j] * rng.uniform(0.5, 1.0)
            if delta < 1e-15:
                continue

        a_try = a.copy()
        a_try[i] += delta
        a_try[j] -= delta

        c_try = fft_convolve_self(a_try)
        max_try = c_try.max()

        if max_try < best_max - 1e-12:
            a = a_try
            best_max = max_try
            best_a = a.copy()
            no_improve = 0
        else:
            no_improve += 1

        if no_improve > 50000:
            # Inject larger perturbation

            obj = obj_value_from_conv(n, best_max, S)
            print(f"    LocalSearch: it={it}, t={elapsed:.0f}s, obj={obj:.6f}")

    return best_a, best_max


def coordinate_descent_polish(a0, S, max_time, rng, verbose=True):
    """
    Coordinate descent: pick a coordinate, optimize its value (1D search)
    while adjusting another coordinate to maintain the sum constraint.
    """
    n = len(a0)
    a = a0.copy()
    c = fft_convolve_self(a)
    best_max = c.max()
    best_a = a.copy()
    no_improve = 0

    start = time.monotonic()
    it = 0

    while time.monotonic() - start < max_time:
        it += 1

        # Pick two coordinates to swap mass between
        i = rng.integers(0, n)
        j = rng.integers(0, n)
        if i == j:
            continue

        # 1D optimization over delta: a[i] += delta, a[j] -= delta
        # Find optimal delta via golden section search
        lo = -a[i]  # a[i] + delta >= 0
        hi = a[j]   # a[j] - delta >= 0

        if hi - lo < 1e-12:
            continue

        # Sample a few candidate deltas
        best_delta = 0.0
        best_cmax = c.max()

        for frac in [0.1, 0.3, 0.5, 0.7, 0.9]:
            for sign in [1, -1]:
                d = sign * frac * (hi - lo) * 0.5
                if lo + d < -1e-12 or hi < d + 1e-12:
                    continue
                a_try = a.copy()
                a_try[i] += d
                a_try[j] -= d
                if a_try[i] < -1e-12 or a_try[j] < -1e-12:
                    continue
                a_try = np.maximum(a_try, 0.0)
                c_try = fft_convolve_self(a_try)
                if c_try.max() < best_cmax:
                    best_cmax = c_try.max()
                    best_delta = d

        if best_delta != 0.0:
            a[i] += best_delta
            a[j] -= best_delta
            a = np.maximum(a, 0.0)
            # Re-normalize sum
            a = project_simplex(a, S)

            c = fft_convolve_self(a)
            if c.max() < best_max - 1e-12:
                best_max = c.max()
                best_a = a.copy()
                no_improve = 0
            else:
                no_improve += 1
        else:
            no_improve += 1

        if no_improve > 20000:
            noise_scale = 0.005 * S / np.sqrt(n)
            a = project_simplex(best_a + rng.normal(0, noise_scale, n), S)
            no_improve = 0

        if verbose and it % 2000 == 0:
            elapsed = time.monotonic() - start
            obj = obj_value_from_conv(n, best_max, S)
            print(f"    CoordDesc: it={it}, t={elapsed:.0f}s, obj={obj:.6f}")

    return best_a, best_max

        print(f"\nPhase 2-{init_i}: FISTA-LSE, init_style={init_i}, time={t_per_init:.0f}s")
        a_opt, _ = fista_lse_optimize(a_init, S_main, t_per_init, rng,
                                       beta_init=5.0, beta_max=5000.0,
                                       beta_growth=1.005, verbose=False)
        update_global(a_opt, f"Phase 2-{init_i}")

    # === Phase 3: Local search refinement on best ===
    remaining = deadline - time.monotonic()
    if global_a is not None and remaining > 100:
        n3 = len(global_a)
        S3 = np.sqrt(2.0 * n3)
        a3 = project_simplex(global_a, S3)
        t3 = min(400, remaining * 0.25)
        print(f"\nPhase 3: Local search swaps, n={n3}, time={t3:.0f}s")
        a_opt, _ = local_search_swaps(a3, S3, t3, rng, verbose=True)
        update_global(a_opt, "Phase 3 local search")

    # === Phase 4: Coordinate descent polish ===
    remaining = deadline - time.monotonic()
    if global_a is not None and remaining > 80:
        n4 = len(global_a)
        S4 = np.sqrt(2.0 * n4)
        a4 = project_simplex(global_a, S4)
        t4 = min(300, remaining * 0.2)
        print(f"\nPhase 4: Coordinate descent, n={n4}, time={t4:.0f}s")
        a_opt, _ = coordinate_descent_polish(a4, S4, t4, rng, verbose=True)
        update_global(a_opt, "Phase 4 coord descent")

    # === Phase 5: Final FISTA polish on global best ===
    remaining = deadline - time.monotonic()
    if global_a is not None and remaining > 60:
        n5 = len(global_a)
        S5 = np.sqrt(2.0 * n5)
        a5 = project_simplex(global_a, S5)
        t5 = min(remaining - 30, 400)
        print(f"\nPhase 5: Final FISTA polish, n={n5}, time={t5:.0f}s")
        a_opt, _ = fista_lse_optimize(a5, S5, t5, rng,
                                       beta_init=200.0, beta_max=20000.0,
                                       beta_growth=1.01, verbose=True)
        update_global(a_opt, "Phase 5 final polish")

    # === Phase 6: Try alternate length (4096 or 16384) ===
    remaining = deadline - time.monotonic()
    if remaining > 200:
        alt_n = 4096 if (global_a is None or len(global_a) > 4096) else 16384
        S_alt = np.sqrt(2.0 * alt_n)
        t_alt = min(remaining - 50, 500)

        print(f"\nPhase 6: Alternate length n={alt_n}, time={t_alt:.0f}s")
        base_for_interp = global_a if global_a is not None else None
        a_alt = generate_init(alt_n, rng, base=base_for_interp)
        a_alt = project_simplex(a_alt, S_alt)

        a_opt, _ = fista_lse_optimize(a_alt, S_alt, t_alt * 0.7, rng,
                                       beta_init=10.0, beta_max=5000.0,
                                       beta_growth=1.005, verbose=False)
        update_global(a_opt, f"Phase 6 n={alt_n}")

    # === Phase 7: Multiple short FISTA restarts on best ===
    remaining = deadline - time.monotonic()
    if global_a is not None and remaining > 60:
        n7 = len(global_a)
        S7 = np.sqrt(2.0 * n7)
        n_restarts = min(5, int(remaining // 40))
        t_per = (remaining - 30) / max(1, n_restarts)

        print(f"\nPhase 7: {n_restarts} short restarts, {t_per:.0f}s each")
        for ri in range(n_restarts):
            if time.monotonic() > deadline - 20:
                break
            noise_scales = [0.005, 0.01, 0.02, 0.03, 0.05]
            ns = noise_scales[ri % len(noise_scales)]
            a_pert = project_simplex(global_a + rng.normal(0, ns * S7 / np.sqrt(n7), n7), S7)
            a_opt, _ = fista_lse_optimize(a_pert, S7, t_per, rng,
                                           beta_init=50.0, beta_max=10000.0,
                                           beta_growth=1.01, verbose=False)
            update_global(a_opt, f"Phase 7 restart {ri} (noise={ns})")

    # === Final verification ===
    if global_a is None:
        print("WARNING: No valid solution found, using fallback")
        global_a = np.ones(256) * 1.0
        global_best = obj_value_from_conv(256, fft_convolve_self(global_a).max(), global_a.sum())

    global_a = np.clip(global_a, 0.0, 1000.0)
    if global_a.sum() < 0.01:
        global_a = np.ones(256) * 1.0

    final_list = [float(x) for x in global_a]
    ver = evaluate_sequence(final_list)
    n_final = len(global_a)
    print(f"\n{'='*60}")
    print(f"FINAL RESULT: len={n_final}, internal_obj={global_best:.6f}")
    print(f"evaluate_sequence verdict: {ver:.6f}")
    print(f"{'='*60}")

    return final_list
