5. Specifically, the gradient of c[k*] w.r.t. a[i] is a[k*-i] (if k*-i is valid). So the direction of steepest increase in c[k*] is the vector v where v[i] = a[k*-i] (shifted and reversed a).
6. To reduce c[k*], we should move a in the direction -v, projected onto the tangent space of the simplex.

This is essentially what the previous solution does with exact subgradient. But I can make it more sophisticated by:
- Considering multiple peaks simultaneously (weighted by their height)
- Using a "soft" version where I include near-peaks as well
- Adapting the step size based on how much the peak actually decreases

Let me also think about **using the Hessian for a Newton step**:

The Hessian of c[k] = sum_i a[i]*a[k-i] w.r.t. a is:
H[i,j] = 1 if i+j=k (and i≠j), 2 if 2i=k... 

Actually, let me compute this more carefully. c[k] = sum_{i: 0≤i≤n-1, 0≤k-i≤n-1} a[i]*a[k-i]

∂c[k]/∂a[m] = a[k-m] (if k-m is valid) + a[m-(k-m)]... no.

c[k] = sum_i a[i]*a[k-i]
∂c[k]/∂a[m] = sum_i [δ_{i,m}*a[k-i] + a[i]*δ_{k-i,m}]
= a[k-m] + a[m] (if k-m is valid)

Wait, the second term: δ_{k-i,m} means i = k-m. So the second term is a[k-m] (if k-m is valid).

So ∂c[k]/∂a[m] = a[k-m] + a[k-m] = 2*a[k-m] (if k-m is valid, i.e., 0 ≤ k-m ≤ n-1)

Hmm wait, that's only if m ≠ k-m. If m = k-m (i.e., 2m = k), then:
c[k] contains the term a[m]*a[m] = a[m]^2, and ∂/∂a[m] of a[m]^2 = 2a[m].
From the formula: a[k-m] + a[k-m] = a[m] + a[m] = 2a[m]. ✓

So the gradient of c[k] is: (∇c[k])[m] = 2*a[k-m] if 0 ≤ k-m ≤ n-1, else 0.

This is just 2 times the reversed and shifted version of a!

The Hessian of c[k]: ∂²c[k]/∂a[m]∂a[p] = ∂/∂a[p] [2*a[k-m]] = 2*δ_{p, k-m}

So the Hessian H[m,p] = 2*δ_{p, k-m} (if k-m is valid). This is a permutation matrix (times 2)!

The Hessian of the objective (max of c[k]) would be the Hessian of the active c[k*] (at the maximum). So H = 2 * P where P is a permutation matrix.

A permutation matrix has eigenvalues that are roots of unity. So the Hessian is not positive definite (it has eigenvalues 2*exp(2πij/m) for various m). This confirms the non-convexity.

For a Newton step, we'd need to invert the Hessian, but since it's not positive definite, we can't use a standard Newton step. We could use a "damped Newton" or "Levenberg-Marquardt" approach, but it's not straightforward.

Minimize 2*n*max(conv(a,a))/sum(a)^2 over non-negative sequences.
Multi-phase approach: multi-scale optimization, adaptive LSE-FISTA,
peak-targeting with adaptive subgradient, and L-BFGS polishing.

from scipy.fft import fft, ifft
from scipy.optimize import minimize as scipy_minimize


def fft_convolve_self(a):
    n = len(a)
    size = 2 * n - 1
    fsize = 1 << (size - 1).bit_length()
    A = fft(a, fsize)
    c = np.real(ifft(A * A))
    return c[:size]


def project_simplex(v, S):
    n = len(v)
    v = np.asarray(v, dtype=np.float64)
    w = np.sort(v)[::-1]
    cumsum = np.cumsum(w)
    idx = np.arange(1, n + 1, dtype=np.float64)
    tc = (cumsum - S) / idx
    valid = tc <= w
    if not np.any(valid):
        rho = n
    else:
        rho = int(np.max(np.where(valid)[0]) + 1)
    theta = (cumsum[rho - 1] - S) / rho
    return np.maximum(v - theta, 0.0)


def lse_weights(c, beta):
    cm = c.max()
    shifted = beta * (c - cm)
    shifted = shifted - shifted.max()
    e = np.exp(shifted)
    tot = e.sum()
    if tot < 1e-300:
        return np.ones(len(c)) / len(c)
    return e / tot


def conv_gradient(y, w):
    n = len(y)
    y_rev = y[::-1]
    L = 1 << (len(w) + n - 1 - 1).bit_length()
    conv_wy = np.real(ifft(fft(w, L) * fft(y_rev, L)))
    cross = conv_wy[n - 1: 2 * n - 1]
    return 2.0 * cross


def topk_gradient(y, c, k, power=1.0):
    n = len(y)
    k = min(k, len(c))
    idx = np.argsort(c)[::-1][:k]
    vals = c[idx]
    w = np.maximum(vals, 1e-30) ** (power - 1.0) if power != 1.0 else np.ones(k) * vals
    wsum = w.sum()
    if wsum < 1e-30:
        w = np.ones(k) / k
    else:
        w = w / wsum
    w_full = np.zeros(len(c))
    w_full[idx] = w
    return conv_gradient(y, w_full)


def compute_obj(a):
    n = len(a)
    s = a.sum()
    if s < 1e-15:
        return np.inf
    c = fft_convolve_self(a)
    return 2.0 * n * c.max() / (s * s)


def run_adaptive_fista(a_init, max_time, rng, beta_start=10.0, mode="adaptive"):
    """FISTA with adaptive beta based on peak structure."""
    n = len(a_init)
    S = np.sqrt(2.0 * n)
    a = np.clip(np.asarray(a_init, dtype=np.float64), 0, 1000).copy()
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) * S / n
    else:
        a = a * (S / s)

    y = a.copy()
    t_mom = 1.0
    start = time.monotonic()
    best_conv = np.inf
    best_a = a.copy()
    it = 0
    last_improve = 0

    # Adaptive parameters
    beta = beta_start
    patience = 0

    while time.monotonic() - start < max_time:
        it += 1

        c = fft_convolve_self(y)
        cur_max = c.max()
        
        if cur_max < best_conv - 1e-14:
            best_conv = cur_max
            best_a = y.copy()
            last_improve = it
            patience = 0
        else:
            patience += 1

        # Adaptive beta: increase when making progress, oscillate when stuck
        if patience == 0:
            beta = min(beta * 1.01, 50000.0)
        elif patience < 500:
            beta = max(beta_start, beta * 0.999)
        else:
            # Oscillate to escape
            beta = beta_start * (1.0 + patience * 0.005) * (1.0 + 0.5 * np.sin(2.0 * np.pi * patience / 1000.0))
            beta = max(5.0, min(beta, 50000.0))

        step = 1.0 / max(beta, 1.0)

        # Choose gradient mode based on patience
        if patience < 200:
            w = lse_weights(c, beta)
            grad = conv_gradient(y, w)
        elif patience < 1000:
            k = min(32, 4 + patience // 100)
            grad = topk_gradient(y, c, k, power=1.5)
        else:
            # Strong peak targeting
            k = min(128, 16 + patience // 50)
            grad = topk_gradient(y, c, k, power=1.0)
            # Add small LSE component for stability
            w = lse_weights(c, beta * 0.1)
            grad = 0.7 * grad + 0.3 * conv_gradient(y, w)

        gnorm = np.linalg.norm(grad)
        if gnorm < 1e-15:
            break

        # Perturbation when very stuck
        if patience > 3000 and it % 100 == 0:
            noise_scale = max(1e-6, 0.003 * S / np.sqrt(n) * np.exp(-patience / 10000.0))
            if noise_scale > 1e-8:
                noise = rng.normal(0, noise_scale, n)
                y = project_simplex(y + noise, S)
                t_mom = 1.0
                patience = 0
                beta = beta_start

        # FISTA update
        x_new = project_simplex(y - step * grad, S)
        t_new = 0.5 * (1.0 + np.sqrt(1.0 + 4.0 * t_mom * t_mom))
        y = x_new + ((t_mom - 1.0) / t_new) * (x_new - a)
        y = np.maximum(y, 0.0)
        a = x_new
        t_mom = t_new

        if it % 5000 == 0:
            t_mom = 1.0

    return best_a, best_conv


def run_peak_sieve(a_init, max_time, rng):
    """Iterative peak suppression: directly target and reduce peaks."""
    n = len(a_init)
    S = np.sqrt(2.0 * n)
    a = np.clip(np.asarray(a_init, dtype=np.float64), 0, 1000).copy()

        it += 1
        c = fft_convolve_self(a)

        # Find top peaks
        k = min(8, it // 100 + 1)
        peak_idx = np.argsort(c)[::-1][:k]
        peak_vals = c[peak_idx]
        
        # Weighted combination of gradients from peaks
        total_grad = np.zeros(n)
        for i, pk in enumerate(peak_idx):
            weight = peak_vals[i] / peak_vals.sum()
            # Gradient of c[pk] w.r.t. a is 2 * a reversed and shifted

            grad_pk = np.zeros(n)
            valid_start = max(0, pk - n + 1)

            for m in range(valid_start, valid_end + 1):
                grad_pk[m] = 2.0 * a[pk - m]
            total_grad += weight * grad_pk

        gnorm = np.linalg.norm(total_grad)
        if gnorm < 1e-15:
            break

        # Backtracking line search
        alpha = S / gnorm
        for _ in range(20):

                break

            a = project_simplex(a + rng.normal(0, max(noise_scale, 1e-8), n), S)

    return best_a, best_conv

"""
Minimize 2*n*max(conv(a,a))/sum(a)^2 over non-negative sequences.
Multi-phase adaptive optimization: FISTA with transition from LSE smoothing
to peak-targeting gradients, L-BFGS polishing with increasing smoothness,
and multi-scale exploration to escape local minima.
"""
import numpy as np
import time
from scipy.fft import fft, ifft
from scipy.optimize import minimize as scipy_minimize


def fft_convolve_self(a):
    n = len(a)
    size = 2 * n - 1
    fsize = 1 << (size - 1).bit_length()
    A = fft(a, fsize)
    c = np.real(ifft(A * A))
    return c[:size]


def project_simplex(v, S):
    n = len(v)
    v = np.asarray(v, dtype=np.float64)
    w = np.sort(v)[::-1]
    cumsum = np.cumsum(w)
    idx = np.arange(1, n + 1, dtype=np.float64)
    tc = (cumsum - S) / idx
    valid = tc <= w
    if not np.any(valid):
        rho = n
    else:
        rho = int(np.max(np.where(valid)[0]) + 1)
    theta = (cumsum[rho - 1] - S) / rho
    return np.maximum(v - theta, 0.0)


def lse_weights(c, beta):
    cm = c.max()
    shifted = beta * (c - cm)
    shifted = shifted - shifted.max()
    e = np.exp(shifted)
    tot = e.sum()
    if tot < 1e-300:
        return np.ones(len(c)) / len(c)
    return e / tot


def conv_gradient(y, w):
    n = len(y)
    y_rev = y[::-1]
    L = 1 << (len(w) + n - 1 - 1).bit_length()
    conv_wy = np.real(ifft(fft(w, L) * fft(y_rev, L)))
    cross = conv_wy[n - 1: 2 * n - 1]
    return 2.0 * cross


def peak_weights(c, k, power=1.5):
    k = min(k, len(c))
    idx = np.argsort(c)[::-1][:k]
    w = np.zeros(len(c))
    w[idx] = np.maximum(c[idx], 1e-30) ** power
    s = w.sum()
    if s > 1e-30:
        w /= s
    else:
        w[idx] = 1.0 / k
    return w


def compute_obj(a):
    n = len(a)
    s = a.sum()
    if s < 1e-15:
        return np.inf
    c = fft_convolve_self(a)
    return 2.0 * n * c.max() / (s * s)


def run_adaptive_fista(a_init, max_time, rng, beta_start=10.0, mode="transition"):
    n = len(a_init)
    S = np.sqrt(2.0 * n)
    a = np.clip(np.asarray(a_init, dtype=np.float64), 0, 1000).copy()
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) * S / n
    else:
        a = a * (S / s)

    y = a.copy()
    t_mom = 1.0
    start = time.monotonic()
    best_a = a.copy()
    best_obj = compute_obj(a)
    it = 0
    last_improve = 0
    beta = beta_start

    while time.monotonic() - start < max_time:
        it += 1
        c = fft_convolve_self(y)
        cur_obj = 2.0 * n * c.max() / (S * S)

        if cur_obj < best_obj - 1e-12:
            best_obj = cur_obj
            best_a = y.copy()
            last_improve = it

        stuck = it - last_improve

        if stuck < 500:
            beta = beta_start + 0.01 * it
            beta = min(beta, 2000.0)
            w = lse_weights(c, beta)
            grad = conv_gradient(y, w)
            step = 1.0 / max(beta, 1.0)
        elif stuck < 2000:
            k = min(64, 4 + stuck // 50)
            w = peak_weights(c, k, power=1.5)
            grad = conv_gradient(y, w)
            gnorm = np.linalg.norm(grad)
            step = S / (gnorm + 1e-15) * 0.7
            lse_w = lse_weights(c, 50.0)
            grad = 0.8 * grad + 0.2 * conv_gradient(y, lse_w)
            step *= 0.8
        else:
            k = min(200, 32 + stuck // 20)
            w = peak_weights(c, k, power=1.0)
            grad = conv_gradient(y, w)
            gnorm = np.linalg.norm(grad)
            step = S / (gnorm + 1e-15) * 0.4

            if stuck > 3000 and it % 80 == 0:
                noise = rng.normal(0, 1.0, n)
                F = fft(noise)
                cutoff = max(3, n // 80)
                F[cutoff:-cutoff] *= 0.03
                noise = np.real(ifft(F))[:n]
                nnorm = np.linalg.norm(noise)
                if nnorm > 1e-15:
                    noise /= nnorm
                scale = 0.005 * S / np.sqrt(n) * np.exp(-stuck / 8000.0)
                if scale > 1e-9:
                    y = project_simplex(y + scale * noise, S)
                    t_mom = 1.0
                    continue

        gnorm = np.linalg.norm(grad)
        if gnorm < 1e-15:
            break

        x_new = project_simplex(y - step * grad, S)
        t_new = 0.5 * (1.0 + np.sqrt(1.0 + 4.0 * t_mom * t_mom))
        y = x_new + ((t_mom - 1.0) / t_new) * (x_new - a)
        y = np.maximum(y, 0.0)
        a = x_new
        t_mom = t_new

        if it % 4000 == 0:
            t_mom = 1.0

    return best_a, best_obj


def run_lbfgs_polish(a_init, max_time, rng):
    n = len(a_init)
    S = np.sqrt(2.0 * n)
    a = np.clip(np.asarray(a_init, dtype=np.float64), 0, 1000).copy()
    a = a * (S / max(a.sum(), 1e-15))

    start = time.monotonic()
    best_a = a.copy()
    best_obj = compute_obj(a)

    betas = [30.0, 80.0, 200.0, 500.0]
    for beta in betas:
        if time.monotonic() - start > max_time:
            break
        remaining = max_time - (time.monotonic() - start)
        if remaining < 15:
            break

        def obj_and_grad(x):
            xp = np.maximum(x, 0.0)
            b = fft_convolve_self(xp)
            cm = b.max()
            shifted = beta * (b - cm)
            shifted = shifted - shifted.max()
            e = np.exp(shifted)
            w = e / e.sum()
            obj_val = cm + np.log(e.sum()) / beta
            grad = conv_gradient(xp, w) / obj_val
            return obj_val, grad

        result = scipy_minimize(
            obj_and_grad, a.copy(), method='L-BFGS-B',
            jac=True, bounds=[(0, 1000)] * n,
            options={'maxiter': 80, 'maxls': 25, 'ftol': 1e-15,
                     'gtol': 1e-13, 'iprint': -1}
        )

        a_new = np.clip(result.x, 0, 1000)
        a_new = a_new * (S / max(a_new.sum(), 1e-15))
        obj_new = compute_obj(a_new)

        if obj_new < best_obj:
            best_obj = obj_new
            best_a = a_new.copy()
            a = a_new.copy()

    return best_a, best_obj


def run_direct_peak_reduce(a_init, max_time, rng):
    """Directly reduce peaks using line search."""
    n = len(a_init)
    S = np.sqrt(2.0 * n)
    a = np.clip(np.asarray(a_init, dtype=np.float64), 0, 1000).copy()
    a = a * (S / max(a.sum(), 1e-15))

    start = time.monotonic()
    best_a = a.copy()
    best_obj = compute_obj(a)
    it = 0

    while time.monotonic() - start < max_time:
        it += 1
        c = fft_convolve_self(a)
        cur_obj = 2.0 * n * c.max() / (S * S)

        if cur_obj < best_obj - 1e-12:
            best_obj = cur_obj
            best_a = a.copy()

        k = min(16, 2 + it // 200)
        idx = np.argsort(c)[::-1][:k]
        w = np.zeros(len(c))
        w[idx] = c[idx]
        ws = w.sum()
        if ws > 1e-30:
            w /= ws

        grad = conv_gradient(a, w)
        gnorm = np.linalg.norm(grad)
        if gnorm < 1e-15:
            break

        alpha = 0.5 * S / gnorm
        improved = False
        for _ in range(15):
            trial = project_simplex(a - alpha * grad, S)
            c_trial = fft_convolve_self(trial)
            obj_trial = 2.0 * n * c_trial.max() / (S * S)
            if obj_trial < cur_obj * (1.0 - 0.0005):
                a = trial
                improved = True
                break
            alpha *= 0.6

        if not improved:
            noise_scale = max(1e-8, 0.002 * S / np.sqrt(n) * np.exp(-it / 3000.0))
            a = project_simplex(a + rng.normal(0, noise_scale, n), S)

    return best_a, best_obj


def generate_inits(n, rng, S):
    inits = []
    t = np.linspace(0, 1, n, endpoint=False)

    for freq in [1, 2, 3, 5]:
        a = 0.5 + 0.5 * np.cos(2 * np.pi * freq * t)
        a = np.maximum(a, 0.01) * (S / a.sum())
        inits.append(a.copy())

    for _ in range(2):
        raw = rng.random(n)
        F = fft(raw)
        cutoff = max(3, n // 200)
        F[cutoff:-cutoff] *= 0.02
        smooth = np.real(ifft(F))[:n]
        smooth = np.maximum(smooth, 0.0)
        if smooth.sum() > 1e-10:
            inits.append(smooth * (S / smooth.sum()))

    return inits
