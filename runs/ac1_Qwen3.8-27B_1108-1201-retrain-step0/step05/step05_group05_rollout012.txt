Hmm, this is the issue with coordinate descent on the simplex. If I change a_j, I need to either:
1. Renormalize (divide by new sum) - but this changes all other coordinates
2. Keep the sum fixed by adjusting another coordinate - but which one?
3. Work in the "free" space (no sum constraint) and project at the end

Option 3 is cleanest: work with a ≥ 0 (no sum constraint), minimize max(b), then normalize at the end. But this doesn't quite work because the objective is scale-invariant, so max(b) alone doesn't capture the right thing.

- New a_j = t / (1 - a_j + t) * 1 ... no, that's not right either.

Let me think differently. On the simplex {a ≥ 0, sum(a) = 1}, a "coordinate step" means:
- Pick coordinate j
- Move along the line: a_j changes, and we distribute the change proportionally to all other coordinates
- Or: pick two coordinates j and k, move along the edge a_j + a_k = const

The second option (2D coordinate descent) is more standard for simplex-constrained problems.

For a 2D step between coordinates j and k:
- Fix a_j + a_k = c (constant)
- Let a_j = t, a_k = c - t, t ∈ [0, c]
- All other a_i are fixed
- The convolution changes: b_m = b_m^0 + (t - a_j^old) * (a_{m-j} + a_{m-k}) + (a_k^old - t) * (a_{m-k} + a_{m-j})
  Wait, this is getting complicated. Let me just do:
  b_m(t) = b_m^0 + (t - old_j) * a_{m-j} + (c-t - old_k) * a_{m-k}
  = b_m^0 + (t - old_j) * (a_{m-j} - a_{m-k})
  
  (since (c-t-old_k) = -(t-old_j))

So b_m(t) = b_m^0 + (t - old_j) * d_m where d_m = a_{m-j} - a_{m-k}.

Then f(t) = max_m b_m(t) / (sum)^2. But sum is constant (= 1) since we're on the simplex!

So f(t) = max_m (b_m^0 + (t - old_j) * d_m)

This is just the max of linear functions of t, which is a convex piecewise-linear function. Its minimum can be found by:
1. Finding the "valley" of the max of linear functions
2. This is where the positive-slope line crosses the negative-slope line

More precisely, f(t) = max of {b_m^0 + (t-old_j)*d_m : m = 0,...,2n-2}. The minimum of this convex PWL function is where the subgradient contains 0, i.e., where the max of the positive d_m's equals the max of the negative d_m's (in a weighted sense).

Actually, the minimum of max_i (a_i + b_i * t) is found at the point where the upper envelope has a "corner" with 0 slope, or at the leftmost/rightmost point if the function is monotone.

This can be found in O(n) time using a linear-time algorithm for the lower envelope, or O(n log n) by sorting.

In practice, for a quick coordinate descent step, I can:
1. Compute d_m = a_{m-j} - a_{m-k} for all m
2. Find the range of t where each m is the max
3. Find where the max changes from increasing to decreasing

But this is O(n) storage and O(n log n) time per step. For n=8192, that's fine.

Actually, there's a simpler approach: since f(t) is convex PWL, I can use ternary search or golden section search in O(log(1/eps)) evaluations, each O(n). So total O(n log(1/eps)) per coordinate step.

But actually, the exact minimum of a max of linear functions can be found in O(n) time:
- The minimum is at a point where at least two lines are tied for the max, and one has positive slope while the other has negative slope.
- We can find this by: for each pair (i,j) where d_i > 0 and d_j < 0, compute the intersection t_{ij} = (b_j^0 - b_i^0) / (d_i - d_j), and check if it's in [0, c]. Keep the one that minimizes f.

But checking all pairs is O(n^2). Instead, we can:
- Find the line with max slope (max d_m) and the line with min slope (min d_m)
- Their intersection gives a candidate
- But this might not be the actual minimum

A better approach: use the fact that the minimum of max_i (a_i + b_i*t) is the same as the minimum of the upper envelope. The upper envelope is a convex PWL function. Its minimum is either at t=0, t=c, or at a "vertex" where two adjacent edges of the upper envelope meet.

The vertices of the upper envelope can be found in O(n log n) time (sort by slope, then use a convex hull trick).

For simplicity, let me just use **golden section search** for the coordinate step. It's O(n * log(1/eps)) per step, which is fast enough.

"""
Minimize 2*n*max(conv(a,a))/(sum(a))^2 over non-negative sequences.
Uses L-BFGS in log-space with adaptive LSE smoothing, 2D coordinate descent,
and simulated annealing for global exploration.
"""
import numpy as np
import time
from scipy.fft import fft, ifft
from scipy.optimize import minimize


def fft_convolve_self(a):
    """Full linear self-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fsize = 1 << (size - 1).bit_length()
    A = fft(a, fsize)
    c = np.real(ifft(A * A))
    return c[:size]


def lse_obj_grad(a, beta):
    """LSE(beta, b) objective and gradient where b = a*a."""
    n = len(a)
    b = fft_convolve_self(a)
    b_max = b.max()
    if b_max < 1e-30:
        return 0.0, np.zeros(n)
    scaled = beta * (b - b_max)
    e = np.exp(scaled)
    tot = e.sum()
    if tot < 1e-300:
        return b_max, np.zeros(n)
    w = e / tot
    obj = b_max + np.log(tot) / beta
    fsize = 1 << (len(w) + n - 1).bit_length()
    W = fft(w, fsize)
    A = fft(a, fsize)
    grad = 2.0 * np.real(ifft(W * np.conj(A)))[:n]
    return obj, grad


def softmax(x):
    """Numerically stable softmax."""
    x = x - x.max()
    e = np.exp(x)
    return e / e.sum()


def lse_obj_grad_logspace(x, beta):
    """LSE objective and gradient in log-space (softmax) parametrization."""
    a = softmax(x)
    obj, g = lse_obj_grad(a, beta)
    ga = g @ a
    grad_x = a * (g - ga)
    return obj, grad_x


def lse_obj_logspace(x, beta):
    a = softmax(x)
    obj, _ = lse_obj_grad(a, beta)
    return obj


def objective_value(a):
    """Compute the actual objective."""
    a = np.clip(np.asarray(a, dtype=np.float64), 0.0, 1000.0)
    n = len(a)
    s = a.sum()
    if s < 0.01:
        return np.inf
    b = fft_convolve_self(a)
    return 2.0 * n * b.max() / (s * s)


def normalize_to_sum(a, S):
    a = np.clip(a, 0.0, 1000.0)
    s = a.sum()
    if s < 1e-30:
        return np.full(len(a), S / len(a))
    return a * (S / s)


def project_simplex(v, S):
    """Project v onto {x >= 0, sum(x) = S}."""
    n = len(v)
    v = np.asarray(v, dtype=np.float64)
    w = np.sort(v)[::-1]
    cumsum = np.cumsum(w)
    idx = np.arange(1, n + 1, dtype=np.float64)
    tc = (cumsum - S) / idx
    valid = tc <= w
    if not np.any(valid):
        rho = n
    else:
        rho = int(np.max(np.where(valid)[0]) + 1)
    theta = (cumsum[rho - 1] - S) / rho
    return np.maximum(v - theta, 0.0)


def run_lbfgs_logspace(x0, beta, maxiter, max_time, rng):
    """Run L-BFGS in log-space with LSE objective."""
    start = time.monotonic()
    n = len(x0)

    res = minimize(
        lse_obj_logspace,
        x0,
        args=(beta,),
        jac=lambda x: lse_obj_grad_logspace(x, beta)[1],
        method='L-BFGS-B',
        options={
            'maxiter': maxiter,
            'maxfun': maxiter * 2,
            'ftol': 1e-15,
            'gtol': 1e-12,
            'maxls': 50
        }
    )
    elapsed = time.monotonic() - start
    return res.x, res.fun, res.nfev, elapsed


def run_adaptive_lbfgs(a_init, max_time, rng, beta_schedule=None):

    Returns optimized a (sum=1) and the max convolution value.

        if phase < n_phases - 1:

def coordinate_descent_2d(a, max_time, rng, n_sweeps=5):
    """
    2D coordinate descent on the simplex. Pick pairs (j,k),
    optimize along the edge a_j + a_k = const using golden section.
    """
    n = len(a)
    a = normalize_to_sum(a, 1.0).copy()
    start = time.monotonic()
    best_max = fft_convolve_self(a).max()
    b = fft_convolve_self(a)

    golden = (np.sqrt(5.0) - 1.0) / 2.0

    sweeps = 0
    while time.monotonic() - start < max_time:
        sweeps += 1
        # Pick random pairs
        n_pairs = min(50, n // 4)
        for _ in range(n_pairs):
            if time.monotonic() - start > max_time - 2:
                break
            j, k = rng.integers(0, n, 2)
            if j == k:
                continue
            c = a[j] + a[k]
            if c < 1e-15:
                continue

            def f_1d(t):
                """Objective when a_j=t, a_k=c-t."""
                # b_m changes by (t - a[j]) * (a[m-j] + a[m+k] - a[m-k] - a[m-j])
                # Actually: b_m = sum_i a[i]*a[m-i]
                # Changing a[j] from old to t and a[k] from old to c-t:
                # The change in b_m is: (t - a[j])*(a[m-j]) + (c-t - a[k])*(a[m-k])
                # = (t - a[j])*(a[m-j] - a[m-k])  [since (c-t-a[k]) = -(t-a[j])]
                old_j = a[j]
                old_k = a[k]
                # d_m = a[m-j] - a[m-k] (with a[i]=0 for i out of range)
                # For linear convolution, index m ranges from 0 to 2n-2
                d = np.zeros(2 * n - 1)
                # a[m-j] is valid when 0 <= m-j <= n-1, i.e., j <= m <= j+n-1
                lo1 = max(0, j)
                hi1 = min(2 * n - 2, j + n - 1)
                if lo1 <= hi1:
                    d[lo1:hi1+1] += a[lo1 - j:hi1 - j + 1]
                # a[m-k] is valid when 0 <= m-k <= n-1, i.e., k <= m <= k+n-1
                lo2 = max(0, k)
                hi2 = min(2 * n - 2, k + n - 1)
                if lo2 <= hi2:
                    d[lo2:hi2+1] -= a[lo2 - k:hi2 - k + 1]

                delta = t - old_j
                b_new_max = np.max(b + delta * d)
                return b_new_max

            # Golden section search for t in [0, c]
            lo = 0.0
            hi = c
            for _ in range(40):
                m1 = hi - golden * (hi - lo)
                m2 = lo + golden * (hi - lo)
                f1 = f_1d(m1)
                f2 = f_1d(m2)
                if f1 < f2:
                    hi = m2
                else:
                    lo = m1
                if hi - lo < 1e-14 * max(1.0, c):
                    break
            t_opt = (lo + hi) / 2.0

            # Apply update
            a[j] = t_opt
            a[k] = c - t_opt
            a = np.maximum(a, 0.0)

            # Update b and best
            new_max = fft_convolve_self(a).max()
            if new_max < best_max:
                best_max = new_max
                b = fft_convolve_self(a)
            else:
                # Revert if worse (should rarely happen with exact min)
                a[j] = old_j
                a[k] = old_k

    return a, best_max


def support_refinement(a, max_time, rng):
    """
    Try to improve by setting small coordinates to zero.
    Iteratively: find the coordinate whose removal (and renormalization) most improves max(b).
    """
    n = len(a)
    a = normalize_to_sum(a, 1.0).copy()
    start = time.monotonic()
    b = fft_convolve_self(a)
    best_max = b.max()
    improved = True

    while improved and time.monotonic() - start < max_time:
        improved = False
        # Sort coordinates by value (ascending)
        order = np.argsort(a)
        # Try removing the smallest coordinates first
        n_try = min(50, n // 10)
        for i in range(n_try):
            if time.monotonic() - start > max_time - 5:
                break
            j = order[i]
            if a[j] < 1e-10:
                continue
            old_val = a[j]
            a[j] = 0.0
            s = a.sum()
            if s < 1e-15:
                a[j] = old_val
                continue
            a_new = a / s
            new_max = fft_convolve_self(a_new).max()
            if new_max < best_max - 1e-12:
                a = a_new
                best_max = new_max
                b = fft_convolve_self(a)
                improved = True
                # Re-sort
                order = np.argsort(a)
                n_try = min(50, n // 10)
            else:
                a[j] = old_val

    return a, best_max


def basin_hopping_saac(a_init, max_time, rng):
    """
    Simulated annealing in log-space with LSE-based local optimization.
    """
    n = len(a_init)
    a = normalize_to_sum(a_init, 1.0)
    x = np.log(np.maximum(a, 1e-10))
    start = time.monotonic()

    b = fft_convolve_self(a)
    best_a = a.copy()
    best_obj = b.max()
    cur_obj = best_obj

    T_init = 0.01 * best_obj
    T_final = 1e-8 * best_obj
    n_steps = int(max_time / 2.0)  # Estimate
    step = 0

    while time.monotonic() - start < max_time - 10:
        step += 1
        progress = (time.monotonic() - start) / max_time
        T = T_init * (T_final / T_init) ** progress
        noise_scale = T * 5.0

        # Propose: add noise in log-space
        x_prop = x + rng.normal(0, noise_scale, n)
        a_prop = softmax(x_prop)

        # Quick evaluation
        b_prop = fft_convolve_self(a_prop)
        obj_prop = b_prop.max()

        if obj_prop < cur_obj or rng.random() < np.exp(-(obj_prop - cur_obj) / max(T, 1e-30)):
            x = x_prop
            a = a_prop
            cur_obj = obj_prop

            if obj_prop < best_obj:
                best_obj = obj_prop
                best_a = a.copy()
                print("    SA step %d: new best max_b=%.10f" % (step, best_obj))

            # Occasionally do a local polish
            if step % 50 == 0 and time.monotonic() - start < max_time - 30:
                t_polish = min(5.0, (max_time - (time.monotonic() - start)) * 0.1)
                a_pol, max_pol = run_adaptive_lbfgs(a, t_polish, rng,
                                                     beta_schedule=[100, 500, 2000])
                if max_pol < best_obj:
                    best_obj = max_pol
                    best_a = a_pol.copy()
                a = a_pol
                x = np.log(np.maximum(a, 1e-30))
                cur_obj = max_pol

    return best_a, best_obj

    inits.append(np.sin(np.pi * tt) ** 4 + 0.01)
    inits.append(np.exp(-3.0 * (tt - 0.5) ** 2 / 0.1) + 0.01)
    inits.append(np.maximum(1.0 + 0.3 * np.sin(4 * np.pi * tt) + 0.2 * np.cos(10 * np.pi * tt), 0.01))
    inits.append(rng.random(n) + 0.1)
    inits.append(np.abs(rng.normal(0.5, 0.3, n)) + 0.05)

    # Block structures
    for nb in [8, 16, 32]:
        block_len = max(1, n // nb)
        heights = rng.uniform(0.3, 1.5, nb)
        block = np.repeat(heights, block_len)
        if len(block) < n:
            block = np.concatenate([block, np.full(n - len(block), heights[-1])])
        inits.append(block[:n] + 0.01)

    # Normalize all
    normalized = []
    for a in inits:
        a = np.asarray(a, dtype=np.float64)
        a = np.clip(a, 0, 1000)
        s = a.sum()
        if s > 0:
            normalized.append(a / s)
    return normalized


def upsample_sequence(a, factor):
    """Upsample by inserting zeros (or interpolating)."""
    n = len(a)
    new_len = n * factor
    new_a = np.zeros(new_len)
    for i, val in enumerate(a):
        new_a[i * factor] = val / factor
    return new_a


def downsample_sequence(a, factor):
    """Downsample by summing blocks."""
    n = len(a)
    new_len = n // factor
    result = np.zeros(new_len)
    for i in range(new_len):
        result[i] = a[i * factor:(i + 1) * factor].sum()
    return result


def propose_candidate(seed=42, budget_s=1800, **kwargs):
    """
    Multi-phase search combining L-BFGS in log-space, 2D coordinate descent,
    support refinement, and simulated annealing.
    """
    rng = np.random.default_rng(seed)
    total_start = time.monotonic()
    deadline = total_start + budget_s - 30

    print("Starting optimization, budget=%.0fs" % budget_s)

    # Get given sequence
    given = None
    try:
        given = np.asarray(height_sequence_1, dtype=np.float64).reshape(-1)
        if given.size >= 64 and np.sum(np.clip(given, 0, 1000)) > 0:
            given = np.clip(given, 0, 1000)
            print("Given sequence: length=%d, sum=%.2f" % (len(given), given.sum()))
    except Exception:
        pass

    # Determine n: use given length if available, else 8192
    n = 8192
    if given is not None:
        n = len(given)
        # Round to power of 2 for FFT efficiency
        n_pow2 = 1 << max(11, min(14, int(np.log2(n))))
        if abs(n - n_pow2) / n < 0.2:
            n = n_pow2
    print("Using n = %d" % n)

    S = 1.0  # Normalize to sum=1
    global_best = np.inf
    global_a = None

    def update_global(a):
        nonlocal global_best, global_a
        a_clipped = np.clip(a, 0, 1000)
        s = a_clipped.sum()
        if s < 0.01:
            return False
        obj = 2.0 * len(a_clipped) * fft_convolve_self(a_clipped).max() / (s * s)
        if obj < global_best:
            global_best = obj
            global_a = a_clipped.copy()
            return True
        return False

    # Phase 1: Quick screening of diverse inits
    print("\n=== Phase 1: Quick screening ===")
    p1_start = time.monotonic()
    p1_budget = min(120.0, (deadline - p1_start) * 0.08)

    inits = generate_inits(n, rng, given_seq=given)
    # Also try the given sequence if available
    candidates = []
    n_screen = min(6, len(inits))
    per_init_time = p1_budget / n_screen

    for i in range(n_screen):
        if time.monotonic() > deadline - (deadline - total_start) * 0.88:
            break
        t_alloc = min(per_init_time * 1.5, deadline - time.monotonic() - 60)
        if t_alloc < 5:
            break
        a_opt, max_b = run_adaptive_lbfgs(inits[i], t_alloc, rng,
                                           beta_schedule=[30, 100, 300, 1000])
        obj = 2.0 * n * max_b  # since sum=1
        candidates.append((obj, a_opt.copy()))
        print("  Screen %d: obj=%.6f" % (i, obj))
        update_global(a_opt)

    candidates.sort(key=lambda x: x[0])
    print("  Best after screening: obj=%.6f" % global_best)

    # Phase 2: Deep L-BFGS optimization on best candidates
    print("\n=== Phase 2: Deep L-BFGS optimization ===")
    p2_start = time.monotonic()
    p2_budget = min(600.0, (deadline - p2_start) * 0.35)

    n_deep = min(3, len(candidates))
    for i in range(n_deep):
        if time.monotonic() > deadline - 400:
            break
        t_alloc = (deadline - time.monotonic() - 400) * (0.7 / (n_deep - i))
        t_alloc = min(t_alloc, p2_budget / (n_deep - i) + 100)
        if t_alloc < 30:
            break
        print("  Deep opt from candidate %d (obj=%.6f), alloc=%.0fs" %
              (i, candidates[i][0], t_alloc))
        a_opt, max_b = run_adaptive_lbfgs(candidates[i][1], t_alloc, rng,
                                           beta_schedule=[50, 100, 200, 500, 1000, 2000, 5000, 10000, 20000, 50000])
        update_global(a_opt)
        print("  After deep opt %d: global best=%.6f" % (i, global_best))

    # Phase 3: 2D Coordinate Descent
    print("\n=== Phase 3: 2D Coordinate Descent ===")
    p3_start = time.monotonic()
    p3_budget = min(300.0, (deadline - p3_start) * 0.20)

    if global_a is not None:
        a_cd, max_cd = coordinate_descent_2d(global_a, p3_budget, rng)
        update_global(a_cd)
        print("  After CD: obj=%.6f" % global_best)

    # Phase 4: Support refinement
    print("\n=== Phase 4: Support refinement ===")
    p4_start = time.monotonic()
    p4_budget = min(150.0, (deadline - p4_start) * 0.12)

    if global_a is not None:
        a_sr, max_sr = support_refinement(global_a, p4_budget, rng)
        update_global(a_sr)
        print("  After support refinement: obj=%.6f" % global_best)

    # Phase 5: Simulated annealing for global exploration
    print("\n=== Phase 5: Simulated Annealing ===")
    p5_start = time.monotonic()
    p5_budget = min(400.0, (deadline - p5_start) * 0.25)

    if global_a is not None and p5_budget > 30:
        a_sa, max_sa = basin_hopping_saac(global_a, p5_budget, rng)
        update_global(a_sa)
        print("  After SA: obj=%.6f" % global_best)

    # Phase 6: Final polish with very high beta
    print("\n=== Phase 6: Final high-beta polish ===")
    p6_start = time.monotonic()
    p6_budget = max(20.0, deadline - p6_start - 10)

    if global_a is not None and p6_budget > 15:
        # Very high beta L-BFGS
        a_poly, max_poly = run_adaptive_lbfgs(global_a, p6_budget, rng,
                                               beta_schedule=[5000, 10000, 20000, 50000])
        update_global(a_poly)
        print("  After final polish: obj=%.6f" % global_best)

        # Quick CD polish
        remaining = deadline - time.monotonic() - 5
        if remaining > 10:
            a_final_cd, _ = coordinate_descent_2d(global_a, remaining * 0.5, rng)
            update_global(a_final_cd)
            print("  After final CD: obj=%.6f" % global_best)

    # Final verification
    if global_a is not None:
        global_a = np.clip(global_a, 0.0, 1000.0)
        if global_a.sum() < 0.01:
            global_a = np.ones(n) * np.sqrt(2.0 * n) / n
        final_list = [float(x) for x in global_a]
        ver = evaluate_sequence(final_list)
        print("\nVerification: obj=%.8f" % ver)
        if not np.isfinite(ver):
            print("  evaluate_sequence rejected! Using fallback.")
            global_a = np.ones(n) * np.sqrt(2.0 * n) / n
            final_list = [float(x) for x in global_a]
    else:
        global_a = np.ones(n) * np.sqrt(2.0 * n) / n
        final_list = [float(x) for x in global_a]

    elapsed = time.monotonic() - total_start
    print("Done in %.0fs. Final obj=%.8f, n=%d" % (elapsed, objective_value(global_a), len(global_a)))
    return [float(x) for x in np.clip(global_a, 0.0, 1000.0)]
