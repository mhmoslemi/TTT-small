```python
        ranked_candidates.sort(reverse=True, key=lambda x: x[0])
        top_scores = ranked_candidates[:8]
        best_seq = top_scores[0][1]
        best_n_opt = top_scores[0][2]
        best_obj = top_scores[0][0]
        
        current_phase += 1
        print(f"Top candidate: {best_obj:.8f} for n={best_n_opt}")
        
    return [float(x) for x in best_seq]
```

The multi-length optimization approach first assesses the problem's landscape including failures, time constraints, and initial values. It defines a set of lengths based on powers of two. For each length, it initializes a population and applies a four-phase optimization process:

- LSE Screening: minimizes a smoothed objective using FISTA.
- Basin Hopping: searches different regions using Fourier-domain mutations.
- Adaptive Mode Switching: cycles through different optimization modes.
- KKT Polish: refines the solution with tighter constraints.

After each phase, candidates are ranked and the top performers are kept, reducing the population size to avoid redundancy. The best sequence is returned, scaled appropriately. This method systematically explores different lengths and optimizes within each while maintaining a manageable population size.
