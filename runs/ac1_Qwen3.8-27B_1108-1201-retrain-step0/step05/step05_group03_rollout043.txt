11. **Key new idea: Use the connection to the water-filling problem**

The problem $\min_a \max_k (a*a)_k$ s.t. $a \geq 0, \sum a = S$ can be viewed as a "load balancing" problem. Each lag $k$ has a "load" $(a*a)_k$, and we want to balance the loads.

The gradient of the load at lag $k$ with respect to $a_i$ is $a_{k-i}$ (or $2a_i$ if $k = 2i$). This means that increasing $a_i$ increases the load at lag $k$ by $a_{k-i}$.

A natural algorithm is:
1. Find the lag $k^*$ with the highest load.
2. Find the coordinate $i^*$ that would most reduce the load at $k^*$ if decreased.
3. Move mass from $i^*$ to a coordinate that doesn't increase the peak load.

This is essentially a form of "steepest descent" on the active set.

Wait, this is O(n * |A|) which is too slow for large active sets and large $n$. I need a more efficient way to compute the subgradient.

The key observation: the gradient of $(a*a)_k$ with respect to $a$ is the "cross-correlation" of $a$ with a shifted version of itself. Specifically:
$g_k = \nabla_a (a*a)_k$

where $g_k[i] = a_{k-i}$ if $0 \leq k-i \leq n-1$ and $i \neq k/2$, and $g_k[i] = 2a_i$ if $2i = k$.

This is essentially the convolution of $a$ with a "shifted delta" at position $k$. More precisely:
$g_k = a * \delta_k$ (circular, restricted to valid range) + diagonal correction.

Actually, $g_k[i] = a[k-i]$ for valid $k-i$ is the same as the $k$-th "lag" of the cross-correlation of $a$ with itself, which is just a shifted version of $a$.

So $g_k[i] = a[k-i]$ means $g_k$ is $a$ reversed and shifted by $k$. In FFT terms:
$\hat{g}_k(\omega) = e^{ik\omega} \hat{a}(-\omega) = e^{ik\omega} \overline{\hat{a}(\omega)}$ (for real $a$).

So to compute the average subgradient over the active set:
$\bar{g}[\omega] = \frac{1}{|A|} \sum_{k \in A} e^{ik\omega} \overline{\hat{a}[\omega]}$

$= \overline{\hat{a}[\omega]} \cdot \frac{1}{|A|} \sum_{k \in A} e^{ik\omega}$

$= \overline{\hat{a}[\omega]} \cdot \hat{w}[\omega]$

where $w[k] = 1/|A|$ for $k \in A$ and $w[k] = 0$ otherwise, and $\hat{w}$ is the DFT of $w$.

So the subgradient can be computed as:
$\bar{g} = \text{IFFT}(\overline{\text{FFT}(a)} \cdot \text{FFT}(w))$ (appropriately sized)

This is $O(n \log n)$! Much better than $O(n \cdot |A|)$.

But wait, I need to be careful about the "diagonal correction" (the factor of 2 when $2i = k$). Let me handle this separately.

For $k \in A$ where $k$ is even (so $2i = k$ has a solution $i = k/2$):
The correction is: $g_k[k/2]$ should be $2a[k/2]$ instead of $a[k/2]$.
The difference is $a[k/2]$.

So the total correction is: $\sum_{k \in A, k \text{ even}} a[k/2]$ added to position $k/2$.

In the FFT-based computation, this is a small correction that we can add after the main FFT computation.

Let me reformulate:
1. Without the diagonal correction: $g_k[i] = a[k-i]$ for all valid $i$ (including $i = k/2$).
   This is just the "cross-correlation" which can be computed via FFT.
2. The diagonal correction adds $a[k/2]$ to position $k/2$ for each even $k \in A$.

So:
$\bar{g} = \text{IFFT}(\overline{\hat{a}} \cdot \hat{w}) + \text{correction}$

where correction[$k/2$] += $a[k/2] / |A|$ for each even $k \in A$.

The correction is small (at most $|A|/2$ non-zero entries) and can be computed directly.

Great, so the algorithm is:
1. Compute $c = a * a$ via FFT: $O(n \log n)$
2. Find active set $A$: $O(n)$
3. Compute $w = \mathbf{1}_A / |A|$: $O(n)$
4. Compute $\bar{g}$ via FFT: $O(n \log n)$
5. Add diagonal correction: $O(|A|)$
6. Projected gradient step: $O(n \log n)$ (for the simplex projection)

Total per iteration: $O(n \log n)$.

For $n = 16384$, each iteration is roughly $16384 \cdot 14 \approx 230$K operations. At maybe 100M ops/sec, that's about 2.3ms per iteration. So we can do about 400 iterations per minute, or about 1 million iterations in 2400 seconds. That's plenty.

$\eta_t = \frac{R^2}{\|g_t\| \cdot t}$ or $\eta_t = \frac{R}{t^{1/2}}$

where $R$ is the radius of the feasible set.

But with the non-convexity of the problem, these guarantees don't apply. I'll use a practical approach:

- Use backtracking: if the objective increases, halve $\eta$

Actually, a better approach is to use the "heavy-ball" or "Nesterov" momentum:

17. **Let me also consider the "pair coordinate descent" approach**:

For the final polishing, I can use pair coordinate descent:
- Pick a pair of coordinates $(i, j)$
- Optimize over $a_i$ and $a_j$ (keeping $a_i + a_j = \text{const}$ to maintain the sum constraint)
- This is a 1D problem (parameterize by $a_i$, with $a_j = C - a_i$)
- The objective as a function of $a_i$ is $\max_k (c_k(a_i))$ where each $c_k$ is at most quadratic in $a_i$

For a given pair $(i, j)$ with $a_i + a_j = C$:
$(a*a)_k = c_k^{(0)} + a_i \cdot d_k^i + a_j \cdot d_k^j + a_i a_j \cdot e_k + a_i^2 \cdot f_k + a_j^2 \cdot g_k$

where $c_k^{(0)}$ is the convolution value with $a_i = a_j = 0$, and the $d, e, f, g$ terms are the contributions from the cross terms.

This is getting complicated. Let me simplify: for a pair $(i, j)$, the change in $(a*a)_k$ when we change $a_i$ by $\delta$ and $a_j$ by $-\delta$ is:
$\Delta (a*a)_k = \delta(a_{k-i} - a_{k-j}) + \delta^2(e_{ki} - e_{kj})$ (approximately, for small $\delta$)

where $e_{ki} = 1$ if $k = 2i$ (the self-term).

For small $\delta$, this is approximately linear: $\Delta (a*a)_k \approx \delta(a_{k-i} - a_{k-j})$.

So the direction of steepest decrease of the max is to increase $a_i$ and decrease $a_j$ where $a_{k-i} > a_{k-j}$ for the active $k$.

This gives a simple pair-update rule:
- For the active lag $k^*$, find the pair $(i, j)$ that maximizes $a_{k^*-i} - a_{k^*-j}$ (the "differential" at the active lag).
- Move mass from $j$ to $i$.

This is similar to the "steepest descent" on the active constraint.

Minimize 2*n*max(convolve(a,a)) / (sum(a))^2 over non-negative sequences.

Strategy: 
1. FFT-based subgradient descent with active-set tracking
2. LSE-smoothed FISTA for polishing

4. Multi-restart with spectral perturbation

import numpy as np
import time
from scipy.fft import fft, ifft


def fft_convolve_self(a):
    """Full linear self-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fsize = 1 << (size - 1).bit_length()
    A = fft(a, fsize)
    c = np.real(ifft(A * A))
    return c[:size]


def project_simplex(v, S):
    """Project v onto {x >= 0, sum(x) = S}."""
    n = len(v)
    v = np.asarray(v, dtype=np.float64).copy()
    w = np.sort(v)[::-1]
    cumsum = np.cumsum(w)
    idx = np.arange(1, n + 1, dtype=np.float64)
    tc = (cumsum - S) / idx
    valid = tc <= w
    if not np.any(valid):
        rho = n
    else:
        rho = int(np.max(np.where(valid)[0]) + 1)
    theta = (cumsum[rho - 1] - S) / rho
    return np.maximum(v - theta, 0.0)


def normalize(a, S):
    """Clip and rescale to sum = S."""
    a = np.clip(a, 0.0, 1000.0)
    s = a.sum()
    if s < 1e-15:
        return np.full(len(a), S / len(a))
    return a * (S / s)

    """Compute the objective directly."""
    a = np.clip(np.asarray(a, dtype=np.float64), 0.0, 1000.0)
    n = len(a)
    s = a.sum()
    if s < 0.01:
        return np.inf
    b = fft_convolve_self(a)
    return float(2.0 * n * b.max() / (s * s))


def subgradient_fft(a, c, active_set, fsize):
    """
    Compute the average subgradient over the active set using FFT.
    
    The gradient of (a*a)_k w.r.t. a is:
      g_k[i] = a[k-i] if 0 <= k-i < n (and i != k/2)
              = 2*a[i] if 2i == k
              = 0 otherwise
    
    Without the diagonal correction, g_k is the cross-correlation of a with delta_k,
    which in FFT is: conj(FFT(a)) * FFT(delta_k) = conj(FFT(a)) * exp(ik*omega)
    
    The average over the active set:
      avg_g[i] = (1/|A|) * sum_{k in A} a[k-i] (valid range)
    
    In FFT: avg_g = IFFT(conj(FFT(a)) * FFT(w)) where w[k] = 1/|A| for k in A
    Plus diagonal correction.
    """
    n = len(a)
    A_size = len(a)  # FFT size for a
    
    # Build the weight vector w
    w = np.zeros(fsize)
    for k in active_set:
        w[k] = 1.0 / len(active_set)
    
    # FFT computation
    A_fft = fft(a, fsize)
    W_fft = fft(w, fsize)
    g_fft = np.conj(A_fft) * W_fft
    g = np.real(ifft(g_fft, fsize))[:n]
    
    # Diagonal correction: for even k in active set, add a[k/2] to position k/2
    for k in active_set:
        if k % 2 == 0:
            i = k // 2
            if 0 <= i < n:
                g[i] += a[i] / len(active_set)
    
    return g


def lse_value_and_grad(a, c, beta, k_top, fsize):
    """Compute LSE value and gradient for top-k elements."""
    n = len(a)
    k = min(k_top, len(c))
    idx = np.argsort(c)[::-1][:k]
    c_top = c[idx]
    cm = c_top.max()
    scaled = beta * (c_top - cm)
    # Clip for numerical stability
    scaled = np.clip(scaled, -500, 500)
    e = np.exp(scaled)
    tot = e.sum()
    if tot < 1e-300:
        return cm, np.zeros(n)
    w = e / tot
    
    # Full weight vector
    w_full = np.zeros(fsize)
    w_full[idx] = w
    
    # Gradient via FFT
    A_fft = fft(a, fsize)
    W_fft = fft(w_full, fsize)
    g = np.real(ifft(np.conj(A_fft) * W_fft, fsize))[:n]
    
    # Diagonal correction
    for ki in idx:
        if ki % 2 == 0:
            i = ki // 2
            if 0 <= i < n:
                g[i] += w_full[ki] * a[i]
    
    val = cm + np.log(tot) / beta
    return val, g

            step_scale = 1.0

"""
Minimize 2*n*max(convolve(a,a)) / (sum(a))^2 over non-negative sequences.

Strategy:
1. FFT-based exact subgradient descent with active-set tracking (O(n log n) per iteration)
2. LSE-smoothed FISTA for escaping local minima
3. Active-set polishing with very tight constraint sets
4. Spectral initialization for better starting points
5. Try n=16384 as primary size (larger n allows closer to theoretical limit of 1)
6. Multi-phase time management with adaptive strategy switching
"""
import numpy as np
import time
from scipy.fft import fft, ifft


def fft_convolve_self(a):
    """Full linear self-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fsize = 1 << (size - 1).bit_length()
    A = fft(a, fsize)
    c = np.real(ifft(A * A))
    return c[:size]


def project_simplex(v, S):
    """Project v onto {x >= 0, sum(x) = S}."""
    n = len(v)
    v = np.asarray(v, dtype=np.float64).copy()
    w = np.sort(v)[::-1]
    cumsum = np.cumsum(w)
    idx = np.arange(1, n + 1, dtype=np.float64)
    tc = (cumsum - S) / idx
    valid = tc <= w
    if not np.any(valid):
        rho = n
    else:
        rho = int(np.max(np.where(valid)[0]) + 1)
    theta = (cumsum[rho - 1] - S) / rho
    return np.maximum(v - theta, 0.0)


def normalize_seq(a, S):
    """Clip and rescale to sum = S, maintain non-negativity."""
    a = np.clip(a, 0.0, 1000.0)
    s = a.sum()
    if s < 1e-15:
        return np.full(len(a), S / len(a))
    return a * (S / s)


def objective_value(a):
    """Compute the objective directly."""
    a = np.clip(np.asarray(a, dtype=np.float64), 0.0, 1000.0)
    n = len(a)
    s = a.sum()
    if s < 0.01:
        return np.inf
    b = fft_convolve_self(a)
    return float(2.0 * n * b.max() / (s * s))


def compute_subgradient_fft(a, active_set, fsize):
    """
    Compute average subgradient over active set using FFT.
    grad of (a*a)_k w.r.t. a_i = a[k-i] (valid) + a[i]*1[2i=k]
    Average over active set via FFT: IFFT(conj(FFT(a)) * FFT(w))
    """
    n = len(a)
    w = np.zeros(fsize)
    for k in active_set:
        if 0 <= k < fsize:
            w[k] = 1.0 / len(active_set)
    A_fft = fft(a, fsize)
    W_fft = fft(w, fsize)
    g = np.real(ifft(np.conj(A_fft) * W_fft, fsize))[:n]
    # Diagonal correction: add a[k/2]/|A| for even k in active set
    for k in active_set:
        if k % 2 == 0:
            i = k // 2
            if 0 <= i < n:
                g[i] += a[i] / len(active_set)
    return g


def compute_lse_gradient(a, c, beta, k_top, fsize):
    """Compute top-k LSE gradient using FFT."""
    n = len(a)
    k = min(k_top, len(c))
    idx = np.argsort(c)[::-1][:k]
    c_top = c[idx]
    cm = c_top.max()
    scaled = beta * (c_top - cm)
    scaled = np.clip(scaled, -500, 500)
    e = np.exp(scaled)
    tot = e.sum()
    if tot < 1e-300:
        return cm, np.zeros(n)
    w = e / tot
    w_full = np.zeros(fsize)
    w_full[idx] = w
    A_fft = fft(a, fsize)
    W_fft = fft(w_full, fsize)
    g = np.real(ifft(np.conj(A_fft) * W_fft, fsize))[:n]
    # Diagonal correction
    for ki in idx:
        if ki % 2 == 0:
            i = ki // 2
            if 0 <= i < n:
                g[i] += w_full[ki] * a[i]
    val = cm + np.log(tot) / beta
    return val, g


def spectral_init(n, rng):
    """
    Spectral flat-top initialization.
    Set |FFT(a)| approximately constant, phase = 0, then IFFT and clip.
    """
    size = 2 * n - 1
    fsize = 1 << (size - 1).bit_length()
    # Desired: flat spectrum in the passband
    A = np.zeros(fsize, dtype=np.complex128)
    # Use a raised-cosine window in frequency for smoothness
    freq_idx = np.arange(fsize)
    center = fsize // 2
    # Create a band-limited flat spectrum
    bandwidth = int(fsize * 0.4)
    for i in range(fsize):
        d = abs(i - center) if i > center else abs(i + fsize - center)
        if d <= bandwidth:
            A[i] = 1.0
        elif d <= bandwidth + int(bandwidth * 0.3):
            t = (d - bandwidth) / max(1, int(bandwidth * 0.3))
            A[i] = 0.5 * (1 + np.cos(np.pi * t))
    # Add some random phase to break symmetry (helps with non-negativity)
    phase = rng.uniform(0, 2 * np.pi, fsize)
    phase[fsize // 2] = 0  # Keep DC real
    A = A * np.exp(1j * phase)
    a = np.real(ifft(A, fsize))[:n]
    a = np.maximum(a, 0)
    s = a.sum()
    if s < 1e-10:
        a = np.ones(n)
    return a


def resample_sequence(a, n_target):
    """Resample a sequence to a different length using interpolation."""
    n_src = len(a)
    if n_src == n_target:
        return a.copy()
    t_old = np.linspace(0, 1, n_src)
    t_new = np.linspace(0, 1, n_target)
    return np.interp(t_new, t_old, a)


def run_subgradient_descent(a_init, S, max_time, rng, use_lse=False, beta_lse=30.0):
    """
    Main subgradient descent loop with adaptive step size.
    Uses exact subgradient or LSE-smoothed gradient.
    """
    n = len(a_init)
    a = normalize_seq(a_init.copy(), S)
    size = 2 * n - 1
    fsize = 1 << (size - 1).bit_length()

    start = time.monotonic()
    c = fft_convolve_self(a)
    best = c.max()
    best_a = a.copy()

    step_scale = 1.0
    patience = 0
    max_patience = 800
    it = 0
    k_top = max(8, int(0.04 * size))

    while time.monotonic() - start < max_time:
        it += 1
        c = fft_convolve_self(a)
        cur_max = c.max()

        if cur_max < best:
            best = cur_max
            best_a = a.copy()
            patience = 0
        else:
            patience += 1

        if patience > max_patience:
            progress = (time.monotonic() - start) / max_time
            if progress > 0.9:
                break
            noise_scale = 0.02 * S / np.sqrt(n) * (1.0 - progress)
            if noise_scale > 1e-12:
                a = project_simplex(a + rng.normal(0, noise_scale, n), S)
            patience = 0
            step_scale = 1.0
            continue

        # Compute gradient
        if use_lse:
            _, grad = compute_lse_gradient(a, c, beta_lse, k_top, fsize)
        else:
            threshold = cur_max - 1e-3 * cur_max
            active_set = np.where(c >= threshold)[0]
            if len(active_set) == 0:
                active_set = np.array([np.argmax(c)])
            grad = compute_subgradient_fft(a, active_set, fsize)

        gnorm = np.linalg.norm(grad)
        if gnorm < 1e-15:
            break

        # Adaptive step size
        base_step = 0.3 * cur_max / gnorm
        step = base_step * step_scale
        step = min(step, 2.0 * S / max(gnorm, 1e-15))

        # Projected gradient step
        a_new = project_simplex(a - step * grad, S)

        # Line search (quick check)
        c_new = fft_convolve_self(a_new)
        if c_new.max() < cur_max + 1e-12:
            a = a_new
            step_scale = min(3.0, step_scale * 1.08)
        else:
            # Halve and retry
            for _ in range(5):
                step *= 0.5
                a_new = project_simplex(a - step * grad, S)
                c_new = fft_convolve_self(a_new)
                if c_new.max() < cur_max + 1e-12:
                    break
            a = a_new
            step_scale = max(0.01, step_scale * 0.6)

        # Periodic Lescape: switch to LSE mode temporarily
        if not use_lse and it % 1500 == 0 and (time.monotonic() - start) / max_time < 0.6:
            for _ in range(100):
                c_tmp = fft_convolve_self(a)
                _, grad_lse = compute_lse_gradient(a, c_tmp, 20.0, k_top, fsize)
                gn = np.linalg.norm(grad_lse)
                if gn < 1e-15:
                    break
                st = 0.3 * c_tmp.max() / gn
                a = project_simplex(a - st * grad_lse, S)

    c_final = fft_convolve_self(a)
    if c_final.max() < best:
        best = c_final.max()
        best_a = a.copy()

    return best_a, best


def run_fista_lse(a_init, S, max_time, rng, beta_init=15.0, beta_rate=0.003, beta_max=300.0):
    """FISTA with LSE-smoothed objective and backtracking."""
    n = len(a_init)
    a = normalize_seq(a_init.copy(), S)
    y = a.copy()
    t_val = 1.0
    size = 2 * n - 1
    fsize = 1 << (size - 1).bit_length()
    k_top = max(8, int(0.04 * size))

    start = time.monotonic()
    best = fft_convolve_self(a).max()
    best_a = a.copy()

    it = 0
    while time.monotonic() - start < max_time:
        it += 1
        beta = min(beta_max, beta_init * np.exp(beta_rate * it))

        c = fft_convolve_self(y)
        cur_max = c.max()
        if cur_max < best:
            best = cur_max
            best_a = y.copy()

        _, grad = compute_lse_gradient(y, c, beta, k_top, fsize)
        gnorm = np.linalg.norm(grad)
        if gnorm < 1e-15:
            break

        # Backtracking line search
        step = min(1.0 / (2.0 * beta * 0.1), 0.5 * cur_max / max(gnorm, 1e-15))
        x_new = project_simplex(y - step * grad, S)
        for _ in range(6):
            c_new = fft_convolve_self(x_new)
            if c_new.max() < cur_max + 1e-13:
                break
            step *= 0.5
            x_new = project_simplex(y - step * grad, S)

        # FISTA momentum
        t_new = 0.5 * (1.0 + np.sqrt(1.0 + 4.0 * t_val * t_val))
        y_new = x_new + ((t_val - 1.0) / t_new) * (x_new - a)
        y_new = np.maximum(y_new, 0.0)
        y_new = project_simplex(y_new, S)

        a = x_new
        y = y_new
        t_val = t_new

        # Periodic restart to escape local minima
        if it % 2000 == 0 and rng.random() < 0.4:
            noise_scale = 0.01 * S / np.sqrt(n)
            y = project_simplex(y + rng.normal(0, noise_scale, n), S)
            t_val = 1.0

    c_final = fft_convolve_self(a)
    if c_final.max() < best:
        best = c_final.max()
        best_a = a.copy()

    return best_a, best


def run_active_polish(a_init, S, max_time, rng):
    """
    Final polishing with very tight active set (top 3-5 lags).
    Uses very small steps for precision.
    """
    n = len(a_init)
    a = normalize_seq(a_init.copy(), S)
    size = 2 * n - 1
    fsize = 1 << (size - 1).bit_length()

    start = time.monotonic()
    best = fft_convolve_self(a).max()
    best_a = a.copy()

    it = 0
    top_k = 4
    step_decay = 1.0

    while time.monotonic() - start < max_time:
        it += 1
        c = fft_convolve_self(a)
        cur_max = c.max()

        if cur_max < best:
            best = cur_max
            best_a = a.copy()
            step_decay = min(2.0, step_decay * 1.02)
        else:
            step_decay = max(0.1, step_decay * 0.7)

        # Top-k active set
        idx = np.argsort(c)[::-1][:top_k]
        w = np.zeros(fsize)
        for i in idx:
            w[i] = 1.0 / top_k

        A_fft = fft(a, fsize)
        W_fft = fft(w, fsize)
        g = np.real(ifft(np.conj(A_fft) * W_fft, fsize))[:n]
        for ki in idx:
            if ki % 2 == 0:
                i2 = ki // 2
                if 0 <= i2 < n:
                    g[i2] += a[i2] / top_k

        gnorm = np.linalg.norm(g)
        if gnorm < 1e-15:
            break

        step = 0.1 * cur_max / gnorm * step_decay
        a_new = project_simplex(a - step * g, S)

        c_new = fft_convolve_self(a_new)
        if c_new.max() < cur_max:
            a = a_new
        else:
            # Try even smaller step
            a_new = project_simplex(a - step * 0.1 * g, S)
            c_new2 = fft_convolve_self(a_new)
            if c_new2.max() < cur_max:
                a = a_new
                step_decay = max(0.01, step_decay * 0.3)

        # Very occasional tiny perturbation to escape
        if it % 1000 == 0 and (time.monotonic() - start) / max_time < 0.4:
            noise_scale = 0.0005 * S / np.sqrt(n)
            a = project_simplex(a + rng.normal(0, noise_scale, n), S)

    c_final = fft_convolve_self(a)
    if c_final.max() < best:
        best = c_final.max()
        best_a = a.copy()

    return best_a, best


def run_pair_descent(a_init, S, max_time, rng):
    """
    Pair coordinate descent: transfer mass between pairs of coordinates
    to reduce the peak convolution value.
    """
    n = len(a_init)
    a = normalize_seq(a_init.copy(), S)
    size = 2 * n - 1
    fsize = 1 << (size - 1).bit_length()

    start = time.monotonic()
    c = fft_convolve_self(a)
    best = c.max()
    best_a = a.copy()

    it = 0
    while time.monotonic() - start < max_time:
        it += 1
        c = fft_convolve_self(a)
        cur_max = c.max()

        if cur_max < best:
            best = cur_max
            best_a = a.copy()

        # Find the peak lag
        k_peak = np.argmax(c)

        # Find the best pair (i, j) to transfer mass from j to i
        # that reduces the peak the most
        # For lag k_peak, increasing a_i by δ changes (a*a)_{k_peak} by δ * a[k_peak - i]
        # We want to increase a_i where a[k_peak-i] is SMALL (to not increase peak)
        # and decrease a_j where a[k_peak-j] is LARGE (to reduce peak)

        # Compute the "contribution" at the peak lag for each coordinate
        contrib = np.zeros(n)
        lo = max(0, k_peak - n + 1)
        hi = min(k_peak, n - 1)
        for i in range(lo, hi + 1):
            j = k_peak - i
            if j == i:
                contrib[i] = 2.0 * a[i]
            else:
                contrib[i] = a[j]

        # Also consider the second and third peak lags
        top_lags = np.argsort(c)[::-1][:3]
        total_contrib = np.zeros(n)
        for kl in top_lags:
            lo2 = max(0, kl - n + 1)
            hi2 = min(kl, n - 1)
            for i in range(lo2, hi2 + 1):
                j = kl - i
                if j == i:
                    total_contrib[i] += 2.0 * a[i]
                else:
                    total_contrib[i] += a[j]

        # Transfer mass from high-contrib to low-contrib coordinates
        # Pick the coordinate with highest total_contrib to decrease
        # and the one with lowest (among positive a) to increase
        positive_mask = a > 1e-10 * a.max()
        if positive_mask.sum() < 2:
            break

        candidates = np.where(positive_mask)[0]
        if len(candidates) < 2:
            break

        # Source: highest contribution, Destination: lowest contribution
        src = candidates[np.argmax(total_contrib[candidates])]
        dst = candidates[np.argmin(total_contrib[candidates])]

        if src == dst:
            break

        # Determine transfer amount (small fraction)
        transfer = 0.01 * a[src]
        transfer = min(transfer, a[src] * 0.1)

        a[src] -= transfer
        a[dst] += transfer
        a = np.maximum(a, 0)
        a = normalize_seq(a, S)

    c_final = fft_convolve_self(a)
    if c_final.max() < best:
        best = c_final.max()
        best_a = a.copy()

    return best_a, best

        print("\n=== Phase 3: Active Polish (%.0fs) ===" % t3)
        a_opt, val_opt = run_active_polish(a_start, S, t3, rng)
        obj = update_global(a_opt, n_primary)
        print("  Phase 3 obj: %.8f" % obj)
        a_start = a_opt

    # Phase 4: Pair descent - 10% of remaining
    remaining = deadline - time.monotonic()
    t4 = remaining * 0.15
    if t4 > 15:
        print("\n=== Phase 4: Pair Descent (%.0fs) ===" % t4)
        a_opt, val_opt = run_pair_descent(a_start, S, t4, rng)
        obj = update_global(a_opt, n_primary)
        print("  Phase 4 obj: %.8f" % obj)
        a_start = a_opt

    # Phase 5: Try n = 32768 (if time permits)
    remaining = deadline - time.monotonic()
    if remaining > 180 and global_a is not None:
        n_large = 32768
        S_large = np.sqrt(2.0 * n_large)
        a_large = resample_sequence(global_a, n_large)
        a_large = normalize_seq(a_large, S_large)
        print("\n=== Phase 5: n=%d (%.0fs) ===" % (n_large, remaining))

        # Quick subgradient on larger n
        t5 = remaining * 0.6
        a_opt, val_opt = run_subgradient_descent(a_large, S_large, t5, rng, use_lse=False)
        obj = update_global(a_opt, n_large)
        print("  Phase 5 obj: %.8f" % obj)

        # Quick FISTA
        remaining2 = deadline - time.monotonic()
        if remaining2 > 30:
            a_opt, val_opt = run_fista_lse(a_opt, S_large, remaining2 * 0.7, rng,
                                           beta_init=10.0, beta_rate=0.001, beta_max=150.0)
            obj = update_global(a_opt, n_large)
            print("  Phase 5b obj: %.8f" % obj)

        # Quick polish
        remaining3 = deadline - time.monotonic()
        if remaining3 > 20:
            a_opt, val_opt = run_active_polish(a_opt, S_large, remaining3 * 0.8, rng)
            obj = update_global(a_opt, n_large)
            print("  Phase 5c obj: %.8f" % obj)

    # Phase 6: Final intensive polish on the best found
    remaining = deadline - time.monotonic()
    if remaining > 30 and global_a is not None:
        n_best = len(global_a)
        S_best = np.sqrt(2.0 * n_best)
        print("\n=== Phase 6: Final Polish (%.0fs, n=%d) ===" % (remaining, n_best))

        # High-beta FISTA
        t_fin = remaining * 0.4
        a_fin, _ = run_fista_lse(global_a, S_best, t_fin, rng,
                                 beta_init=50.0, beta_rate=0.0005, beta_max=500.0)
        update_global(a_fin, n_best)

        # Active polish
        remaining2 = deadline - time.monotonic()
        if remaining2 > 20:
            a_pol, _ = run_active_polish(a_fin, S_best, remaining2 * 0.8, rng)
            update_global(a_pol, n_best)

    # Also try a second restart with different initialization
    remaining = deadline - time.monotonic()
    if remaining > 200 and global_a is not None:
        print("\n=== Phase 7: Restart with different init (%.0fs) ===" % remaining)
        n_try = len(global_a)
        S_try = np.sqrt(2.0 * n_try)

        # Spectral init with different random phases
        a_alt = spectral_init(n_try, rng)
        a_alt = normalize_seq(a_alt, S_try)

        # Blend with best found
        blend = 0.3
        a_blend = (1 - blend) * global_a + blend * a_alt
        a_blend = normalize_seq(a_blend, S_try)

        t_restart = remaining * 0.5
        a_r, _ = run_subgradient_descent(a_blend, S_try, t_restart, rng, use_lse=False)
        update_global(a_r, n_try)

        remaining2 = deadline - time.monotonic()
        if remaining2 > 20:
            a_r2, _ = run_fista_lse(a_r, S_try, remaining2 * 0.8, rng,
                                    beta_init=10.0, beta_rate=0.002, beta_max=200.0)
            update_global(a_r2, n_try)

    # Final verification and cleanup
    if global_a is not None:
        global_a = np.clip(global_a, 0.0, 1000.0)
        if global_a.sum() < 0.01:
            global_a = np.ones(256) * (np.sqrt(512.0) / 256)
        final_list = [float(x) for x in global_a]
        ver = evaluate_sequence(final_list)
        print("\nFinal verification: %.8f" % ver)
        if not np.isfinite(ver):
            print("  evaluate_sequence rejected! Using fallback.")
            global_a = np.ones(256) * (np.sqrt(512.0) / 256)
            final_list = [float(x) for x in global_a]
            ver = evaluate_sequence(final_list)
            print("  Fallback score: %.8f" % ver)
    else:
        global_a = np.ones(256) * (np.sqrt(512.0) / 256)
        final_list = [float(x) for x in global_a]

    elapsed = time.monotonic() - start_total
    print("\nDone in %.1fs. Best objective: %.8f, sequence length: %d" %
          (elapsed, global_best, len(global_a)))
    return [float(x) for x in np.clip(global_a, 0.0, 1000.0)]
