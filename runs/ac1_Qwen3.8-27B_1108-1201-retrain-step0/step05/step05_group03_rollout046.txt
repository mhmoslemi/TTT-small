   But a has length n (with zero padding to N = 2n-1), so a[j] = S/(2n-1) for j = 0,...,n-1 and a[j] = 0 for j = n,...,2n-2.
   This is NOT constant (it's S/(2n-1) for the first n and 0 for the rest), so A[k] ≠ 0 for k != 0.

   Contradiction! The ideal flat convolution is unachievable with our constraint (a has only n non-zero elements out of N = 2n-1).

   So we need to find the best approximation. This is like a "truncated flat spectrum" problem.

   **Practical approach**: Minimize the variance of c (or the max of c) subject to a >= 0, sum(a) = S, a[j] = 0 for j >= n.

   In the frequency domain, this is: minimize max(IDFT(A²)) subject to:
   - IDFT(A)[j] >= 0 for j = 0,...,n-1
   - IDFT(A)[j] = 0 for j = n,...,N-1
   - A[N-k] = conj(A[k]) (for real a)
   - A[0] = S (real, positive)

   This is a non-convex optimization problem (the objective is max of a quadratic form in A, and the constraints include bilinear constraints from the zero-padding).

   I think the best practical approach is still gradient-based optimization in the time domain, with the LSE trick to smooth the max.

   2. Precompute the FFT size and reuse buffers
   3. Use the LSE gradient with full spectrum (not just top-k) for better accuracy
   4. Use Nesterov momentum
   5. Adaptive learning rate with backtracking
   6. Periodic restarts with both time-domain and frequency-domain perturbations

   The objective is 2n·max(c)/S². For a given "quality" of the sequence (measured by the ratio max(c)/avg(c)), the objective scales as 2n/(2n-1) · (max(c)/avg(c)) ≈ (max(c)/avg(c)) for large n. def fft_convolve_self(a):

    n = len(v)
    v = np.asarray(v, dtype=np.float64)

    # grad[0] = 2 * (w[0]*a[0] + w[1]*a[1] + w[2]*a[2]) = 2*(0.1*1 + 0.2*2 + 0.3*3) = 2*(0.1+0.4+0.9) = 2*1.4 = 2.8
    # grad[1] = 2 * (w[1]*a[0] + w[2]*a[1] + w[3]*a[2]) = 2*(0.2*1 + 0.3*2 + 0.2*3) = 2*(0.2+0.6+0.6) = 2*1.4 = 2.8
    # grad[2] = 2 * (w[2]*a[0] + w[3]*a[1] + w[4]*a[2]) = 2*(0.3*1 + 0.2*2 + 0.1*3) = 2*(0.3+0.4+0.3) = 2*1.0 = 2.0
    
    # Let me verify grad[0] directly:
    # d(c[0])/d(a[0]) = 2*a[0] = 2
    # d(c[1])/d(a[0]) = 2*a[1] = 4
    # d(c[2])/d(a[0]) = 2*a[2] = 6
    # d(c[3])/d(a[0]) = 0 (since 3-0=3 >= n=3)
    # d(c[4])/d(a[0]) = 0
    # grad[0] = 0.1*2 + 0.2*4 + 0.3*6 + 0.2*0 + 0.1*0 = 0.2 + 0.8 + 1.8 = 2.8 ✓
    
    # Great!
    
    N = 1 << (3 * n - 2).bit_length()  # FFT size for gradient computation
    w_padded = np.zeros(N)
    w_padded[:len(c)] = w
    a_padded = np.zeros(N)
    a_padded[:n] = a
    W = fft(w_padded, N)
    A_grad = fft(a_padded, N)
    grad = 2.0 * np.real(ifft(W * np.conj(A_grad)))[:n]
    
    return lse_val, grad
