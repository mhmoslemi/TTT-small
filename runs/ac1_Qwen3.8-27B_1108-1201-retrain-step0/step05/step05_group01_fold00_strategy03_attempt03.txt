<strategy>Approach and rationale  
The central idea is to minimize the maximum convolution value of a non-negative sequence with itself, given a normalized sum. This is achieved through a multi-start strategy combined with an iterative outer-loop optimization. The key novel aspect is the systematic search for a global minimum by:  
1. Evaluating diverse initialization families to avoid local minima  
2. Using a step-size adaptive penalty method to guide optimization  
3. Implementing a local gradient-based polishing step  
This differs from the previous linear warmup by being entirely gradient-based and leveraging smooth BFGS methods for faster convergence.  

Mathematical specification  
We wish to minimize f(a) = 2*n*max(convolve(a,a))/sum(a)**2 over non-negative sequences a. The normalizations are built into the calculation of S and the penalized objective. For a sequence of length n:  
- Sum(a) must be non-zero  
- The convolution is computed using full mode  
The optimization reformulates this as:  
minimize { max(b) }  
subject to ∑a_i = S and a_i ≥ 0  
where b = convolve(a,a)  
This is strictly convex for fixed normalization due to the ∑a_i constraint.  

Implementation procedure  
1. Initialization:  
   a. Use the supplied variable HEIGHT_SEQUENCE_1 if available  
   b. Otherwise generate multiple candidates of length 8192 with different structural properties  
2. Optimization:  
   a. For each candidate, compute LSE-based penalty objective function:  
      obj(x) = max(b.gradient) + β*(S - sum(x))**2 / n

      - Bounds: [0, S] for each coefficient (though clipping is handled by normalization)
      - Jacobian function
      - Time budget parameters
