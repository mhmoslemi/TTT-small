def run_spectral_shaping(a_init, S, max_time, rng):
    """Spectral shaping: iteratively flatten the autoconvolution."""
    n = len(a_init)
    a = normalize(a_init.copy(), S)
    size = 2 * n - 1
    fsize = 1 << (size - 1).bit_length()
    start = time.monotonic()
    best = fft_convolve_self(a).max()
    best_a = a.copy()
    
    # Start with a gentle shaping and increase aggressiveness
    alpha = 0.1
    
    while time.monotonic() - start < max_time:
        c = fft_convolve_self(a)
        M = c.max()
        
        if M < best:
            best = M
            best_a = a.copy()
        
        # Target level: slightly below current max
        target = M * (1.0 - alpha)
        
        # Shape: reduce peaks above target
        c_shaped = np.where(c > target, target, c)
        
        # Compute new a from shaped spectrum
        C_shaped = fft(c_shaped, fsize)
        
        # Complex square root
        # Need to be careful with the branch
        A_new = np.sqrt(C_shaped + 0j)
        
        # Enforce Hermitian symmetry
        for i in range(1, fsize // 2 + 1):
            j = fsize - i
            A_new[j] = np.conj(A_new[i])
        A_new[0] = np.abs(A_new[0])
        if fsize % 2 == 0:
            A_new[fsize//2] = np.abs(A_new[fsize//2])
        
        a_candidate = np.real(ifft(A_new, fsize))[:n]
        a_candidate = np.clip(a_candidate, 0, None)
        s = a_candidate.sum()
        if s < 1e-10:
            alpha *= 0.5
            continue
        a_candidate = a_candidate * (S / s)
        
        # Check if it's an improvement
        c_new = fft_convolve_self(a_candidate)
        if c_new.max() < M:
            a = a_candidate
            alpha = min(0.5, alpha * 1.1)  # Slightly more aggressive
        else:
            # Blend
            blend = 0.3
            a_new = (1 - blend) * a + blend * a_candidate
            a_new = normalize(a_new, S)
            c_blend = fft_convolve_self(a_new)
            if c_blend.max() < M:
                a = a_new
            else:
                alpha *= 0.7  # Less aggressive
    
    return best_a, best

But actually, there's a simpler way to think about this. If we just clip the peaks of c and then try to find a new a whose autoconvolution is close to the clipped c, we can use an iterative method:

1. Start with current a.
2. Compute c = a * a.
3. Define c_target = min(c, M) for some M < max(c).

   The gradient of ||a' * a' - c_target||^2 w.r.t. a' is 4 * (a' * (a' * a' - c_target)) (approximately, using the linearity of convolution).
   
   Actually, let's be more precise. Let F(a) = a * a (the autoconvolution operator). Then we want to minimize ||F(a) - c_target||^2.
   The gradient is: d/da ||F(a) - c_t||^2 = 2 * J(a)^T (F(a) - c_t) where J(a) is the Jacobian of F.
   J(a)_{k,i} = d(F(a))_k / da_i = 2 * a_{k-i} (as derived earlier).

   where ⋆ denotes cross-correlation.
   
   So the gradient is 4 * (a ⋆ (a * a - c_target))_i.
   
   This can be computed efficiently with FFT!
