Now, back to the optimization. The key insight is:
- We want to minimize max_k c[k] where c = conv(a, a)
- c[k] = sum_i a[i]*a[k-i] (pairs that sum to k)
- sum_k c[k] = S² (total sum of all convolution values)
- There are 2n-1 values

For the uniform sequence, c forms a triangle with peak S²/n at k = n-1.
To reduce the peak, we need to redistribute the mass of c.

The key degrees of freedom: We can shape a to make c more uniform. The constraint is a >= 0.

Now let me think about the algorithm:

**Algorithm: Iterative Convolution Flattening (ICF)**

1. Initialize a (e.g., from a good starting point)
2. Repeat:
   a. Compute c = conv(a, a)
   b. Identify the peaks (top-k values in c)
   c. Compute gradient of max(c) (or LSE of c) with respect to a
   d. Update a in the negative gradient direction
   e. Project to {a >= 0, sum(a) = S}
3. Return best a found
