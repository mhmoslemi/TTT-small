Let me also think about a key mathematical insight:

The problem is equivalent to: minimize max_k (a^T Q_k a) subject to a >= 0, 1^T a = S.

where Q_k is the matrix such that c[k] = a^T Q_k a.

This is a non-convex problem (quadratic objective with linear constraints). The LSE approximation makes it smooth but still non-convex.

One trick: we can write max_k f_k(a) = inf_{t: t >= f_k(a) for all k} t. This gives a min-max formulation:
minimize t
subject to a^T Q_k a <= t for all k
a >= 0
1^T a = S

This is a non-convex QCQP (quadratically constrained quadratic program) because the constraints are non-convex (a^T Q_k a is not convex in general).

However, if we relax a >= 0 to a being any real vector (removing non-negativity), the problem becomes:
minimize t
subject to a^T Q_k a <= t for all k
1^T a = S

This is still non-convex but has more structure. The optimal solution without the non-negativity constraint might give insight.

Actually, for the unconstrained (no non-negativity) case, this is related to the "minimum peak-to-average power ratio" (PAPR) problem, which has known solutions involving Golay sequences, Zadoff-Chu sequences, etc.

For real sequences without the non-negativity constraint, we could use sign changes to reduce the peak autocorrelation. But with non-negativity, we're limited.

def fft_convolve_self(a):
    """Full self-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    N = 1 << (size - 1).bit_length()
    A = fft(a, N)
    c = np.real(ifft(A * A))
    return c[:size]


def softmax_from_w(w):
    """Compute softmax(w) with numerical stability."""
    w_max = np.max(w)
    exp_w = np.exp(w - w_max)
    return exp_w / exp_w.sum()


def lse_and_grad(a, N, beta):
    """Compute LSE value and gradient of max(conv(a))."""
    n = len(a)
    a_P = np.zeros(N)
    a_P[:n] = a
    A = fft(a_P)
    c = np.real(ifft(A * A))[:2*n-1]
    
    # LSE with numerical stability
    c_max = np.max(c)
    exp_bc = np.exp(beta * (c - c_max))
    log_sum = np.log(exp_bc.sum()) + beta * c_max
    lse_val = log_sum / beta
    
    # p = softmax(beta * c)
    p = exp_bc / exp_bc.sum()
    
    # Gradient: (2/beta) * IFFT(FFT(p) * conj(FFT(a_P)))[:n]
    p_P = np.zeros(N)
    p_P[:2*n-1] = p
    grad = np.real(ifft(fft(p_P) * np.conj(A)))[:n] * (2.0 / beta)
    
    return lse_val, grad, c


def mirror_gradient(a, grad_a, S):
    """Compute mirror gradient for softmax parameterization."""
    mean_grad = np.dot(a, grad_a) / S
    return a * (grad_a - mean_grad)

def safe_softmax(w):
    """Numerically stable softmax."""
    w_shifted = w - np.max(w)
    e = np.exp(w_shifted)
    s = e.sum()
    if s < 1e-300:
        return np.ones(len(w)) / len(w)
    return e / s

    a_P = np.zeros(N, dtype=np.float64)

            break

        if not np.all(np.isfinite(w_new)):
            break

    n = len(a)

def safe_softmax(w):

    e = np.exp(w_shifted)
    s = e.sum()
