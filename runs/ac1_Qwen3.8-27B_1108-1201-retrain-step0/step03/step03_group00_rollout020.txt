3. Identify the "active set" K = {k : c[k] >= threshold * max(c)}.
4. For k in K, we want to reduce c[k]. The most effective way is to reduce the products a[i]*a[k-i] where these are large.
5. Update: a_new[i] = a[i] - eta * sum_{k in K} w_k * a[k-i] (approximately).
6. Project onto {a >= 0, sum(a) = S}.
7. Repeat.

This is essentially a gradient step where the gradient is concentrated on the active set.

def init_from_recursive(n):
    """Generate sequence using the recursive relation for flat convolution."""
    b = np.zeros(n)
    b[0] = 1.0
    for k in range(1, n):
        # b[k] = (1 - sum_{i=0}^{k-1} b[i]*b[k-i]) / (2*b[0])
