**Key improvement idea: Use a "peeling" strategy in Nesterov**

Instead of always using the top-K peaks with equal or proportional weights, use a "peeling" strategy:
1. First, identify the single highest peak
2. Take a step to reduce it
3. After a few iterations, the next highest peak becomes the new maximum
4. Now the subgradient automatically focuses on the new peak
5. This naturally "peels off" peaks one by one

The issue with this approach is that it might overshoot: reducing one peak might increase another. The weighted subgradient (top-K with proportional weights) handles this better by considering multiple peaks simultaneously.

**Better idea: Use "temperature" annealing for peak weights**

- When alpha is small (e.g., 1): all peaks are weighted roughly equally → smooth subgradient
- When alpha is large (e.g., 1000): only the highest peak matters → sharp subgradient

Anneal alpha from small to large over the course of the optimization. This is similar to the log-sum-exp continuation but applied to the peak weights rather than the objective.

**Alexandersen initialization:** 
The optimal solution for large n should have the property that `a*a` is nearly constant. If `a*a = c * 1` (exactly), then `P(x)^2 = c * (1 + x + x^2 + ... + x^{2n-2})`, so `P(x) = sqrt(c) * sqrt(1 + x + ... + x^{2n-2})`.

Actually, the standard way to take a "square root" of a polynomial is:
- If P(0) ≠ 0, then sqrt(P) can be computed by Newton's method: Q_{k+1} = 0.5 * (Q_k + P/Q_k)
- Start with Q_0 = [1, 0, 0, ...]

But for S(x) = 1 + x + ... + x^{2n-2}, all coefficients are 1, and S(0) = 1, so we can use Newton's method.

However, the "square root" of S in the polynomial ring might have very small or even negative coefficients (since S has zeros on the unit circle). Let me check.

S(x) = (1-x^{2n-1})/(1-x) has zeros at x = e^{2πik/(2n-1)} for k = 1, ..., 2n-2. These are all on the unit circle.

The square root sqrt(S) = sqrt((1-x^{2n-1})/(1-x)) = (1-x^{2n-1})^{1/2} / (1-x)^{1/2}
