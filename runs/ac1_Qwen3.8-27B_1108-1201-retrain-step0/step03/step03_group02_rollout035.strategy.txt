# Mathematical Specification

The optimization problem is defined over sequences `a = [a0, a1, ..., a_{n-1}]`
- `n` = length of the sequence
- `sum(a) = √(2n)`
- Convolution `c = convolve_full(a, a)` (mode='full') is `(2*n - 1)` long, `c[i] = sum_j a[j]*a[j+i]`
- We wish to minimize `2*n*max(c[1:]) / (sum(a))**2`

Define the derivative:
`d(i) = 2*(max(c)*s + (c[i] - mean(c))*(k-1)) / (max(c)*s)`

Where:
- `s = sum(a)^2`
- `k = n_i + i` (dimensionality parameter)

The optimization requires:
1. A non-negative sequence `a`
2. `sum(a) >= 0.01`
3. Each `a_j` must be in `[0, 1000]`
