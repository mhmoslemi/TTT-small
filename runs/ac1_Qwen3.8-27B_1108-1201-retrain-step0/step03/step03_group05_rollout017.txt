So f = 2n * n * max c / (n * integral a)^2 = 2 * max c / (integral a)^2.

So in the continuous limit, we want to minimize 2 * max_s c(s) / (integral a)^2 where c(s) = integral a(t) a(s-t) dt (over valid t).

This is a well-studied problem! It's related to the "minimum peak-to-average power ratio" (PAPR) problem for aperiodic autocorrelation.
