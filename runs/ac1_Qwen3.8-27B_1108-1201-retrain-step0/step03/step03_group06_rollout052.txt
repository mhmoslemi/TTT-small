In general: ∂c[k]/∂a[i] = 2*a[k-i] if 0 <= k-i < n and k-i ≠ i, or 2*a[i] if k = 2i. Which simplifies to: ∂c[k]/∂a[i] = 2*a[k-i] if 0 <= k-i < n, with the understanding that when k-i = i, it's still 2*a[i].

So the subgradient of max(c) at a is: 2 * a[k*-i] (reversed) where k* is the argmax of c.

More precisely, if S = {k : c[k] = max(c)} is the set of maximizing lags, then the subgradient is:
∂f/∂a[i] = 2 * sum_{k in S, 0<=k-i<n} w_k * a[k-i]

where w_k are weights summing to 1 over S.

For a single peak at k*: ∂f/∂a[i] = 2 * a[k*-i] (if 0 <= k*-i < n).

This is essentially 2 times the "reversed" sequence shifted by k*.

So the gradient descent step is: a[i] <- a[i] - lr * 2 * a[k*-i] (for the relevant i).

This is an interesting structure! The update at position i depends on the value at position k*-i. This is like a "reflection" operation.

For the center peak k* = n-1: the update is a[i] <- a[i] - 2*lr*a[n-1-i]. This is a "reflect and subtract" operation.

This suggests that the optimal sequence might have some symmetry or anti-symmetry property.

If a[i] = a[n-1-i] (symmetric), then the update at position i is a[i] - 2*lr*a[i] = a[i]*(1-2lr). So symmetric elements are uniformly scaled down. This would reduce all elements equally, which doesn't help (since the objective is scale-invariant).

If a[i] = -a[n-1-i] (anti-symmetric), but we need a >= 0, so this isn't directly possible. But we could have a[i] large when a[n-1-i] is small, and vice versa.

This suggests that the optimal sequence might have a "phase" structure where the first half and second half are somewhat "complementary" (one is large where the other is small).
