For each coordinate `i`, the objective `f(a) = max_k c[k]` as a function of `a_i` (with other coordinates fixed) is a piecewise-linear convex function (max of linear functions). The minimum can be found exactly.

With the sum constraint, we can't set `a_i = 0` (unless we compensate by increasing another coordinate). So the effective problem is:

Minimize `max_k c[k]` subject to `a_i + a_j = const` (for some pair `i, j`) and all other coordinates fixed.

This is a 1D problem in `a_i` (with `a_j = const - a_i`). The objective is the max of:
- Linear functions in `a_i` (from lags affected by `a_i`)
- Linear functions in `a_j = const - a_i` (from lags affected by `a_j`)
- Constants (lags affected by neither)

So it's still a max of linear functions, hence piecewise-linear convex. We can find the minimum by sorting the breakpoints.

This pair-coordinate descent might be effective! Let me think about the computational cost.

For a pair `(i, j)`:
- Affected lags from `a_i`: `k` in `[i, i+n-1]` (clipped to `[0, 2n-2]`).
- Affected lags from `a_j`: `k` in `[j, j+n-1]` (clipped to `[0, 2n-2]`).
- The union has at most `2n` lags, but typically about `n` (since the intervals overlap).

For each affected lag `k`, the coefficient of `a_i` is `a[k-i]` (if `i` is in range) and the constant term is `c[k] - a[i]*a[k-i]`. Similarly for `a_j`.

The piecewise-linear function has at most `2n` breakpoints (one per affected lag, where the "active" lag changes). Finding the minimum requires sorting these breakpoints and checking the value at each.

import numpy as np
import time
from scipy.fft import fft, ifft

def project_simplex(v, S):
    """Euclidean projection onto {x >= 0, sum(x) = S}."""
    n = len(v)
    if n == 0:
        return v
    v = np.asarray(v, dtype=np.float64).copy()
    w = np.sort(v)[::-1]
    cumsum = np.cumsum(w)
    idx = np.arange(1, n+1, dtype=np.float64)
    theta = (cumsum - S) / idx
    valid = theta <= w
    if not np.any(valid):
        rho = n
    else:
        rho = np.max(np.where(valid)[0]) + 1
    theta = (cumsum[rho-1] - S) / rho
    return np.maximum(v - theta, 0.0)

def fft_convolve_self(a):
    n = len(a)
    size = 2*n - 1
    fsize = 1 << (size-1).bit_length()
    A = fft(a, fsize)
    c = np.real(ifft(A*A))
    return c[:size]

def compute_conv_gradient(a, weights):
    """Gradient of sum_k weights[k] * c[k] w.r.t. a."""
    n = len(a)
    fsize = 1 << (2*n-1).bit_length()
    W = fft(weights, fsize)
    A = fft(a, fsize)
    # d(sum_k w[k] c[k])/da[i] = 2 * sum_k w[k] * a[k-i] (for valid k)
    # = 2 * (w * a)[i] (circular, with zero-padding)
    # Actually: c[k] = sum_i a[i]a[k-i], dc[k]/da[i] = a[k-i] + a[i-k] (for the linear convolution)
    # Wait, for c[k] = sum_j a[j]a[k-j], dc[k]/da[i] = a[k-i] (if k-i in range) + a[i-k] (if i-k in range)
    # But since c is the full linear convolution (not just autocorrelation), the derivative is:
    # dc[k]/da[i] = a[k-i] for k-i in [0,n-1]
    # So d(sum_k w[k] c[k])/da[i] = sum_k w[k] * a[k-i] (for valid k-i)
    # This is a cross-correlation of w with a.
    # Using FFT: ifft(fft(w) * conj(fft(a))) gives circular cross-correlation.
    # But we need linear cross-correlation, so we zero-pad.
    
    # Actually, let me think again.
    # c[k] = sum_{j} a[j] a[k-j] for k = 0,...,2n-2
    # d c[k] / d a[i] = a[k-i] (if 0 <= k-i < n) + a[i-k] (if 0 <= i-k < n)
    # Wait no. c[k] = sum_j a[j] a[k-j]. The term a[i] appears as a[j] when j=i (contributing a[k-i]) and as a[k-j] when k-j=i i.e. j=k-i (contributing a[k-i]... wait that's the same).
    # Actually in the sum c[k] = sum_j a[j] * a[k-j], a[i] appears when j=i (giving a[i]*a[k-i]) and when k-j=i, i.e., j=k-i (giving a[k-i]*a[i]).
    # These are the same term! So a[i] appears exactly once in c[k], contributing a[i]*a[k-i] (or equivalently a[k-i]*a[i]).
    # Therefore dc[k]/da[i] = a[k-i] if 0 <= k-i < n, else 0.
    # (And we also need 0 <= i < n, which is always true by definition.)
    
    # So d(sum_k w[k] * c[k]) / da[i] = sum_k w[k] * a[k-i] for k where 0 <= k-i < n
    # = sum_m w[i+m] * a[m] for m = 0,...,n-1 (where i+m < 2n-1)
    # This is a cross-correlation!
    
    # Using FFT: cross-correlation of w and a = ifft(conj(fft(a)) * fft(w))
    # But we need linear (not circular), so zero-pad.
    
    result = np.real(ifft(np.conj(A) * W))[:n]
    return result

def objective_and_conv(a):
    """Compute objective value and convolution."""
    n = len(a)
    S = np.sum(a)
    if S < 0.01:
        return np.inf, None
    c = fft_convolve_self(a)
    max_c = c.max()
    obj = 2.0 * n * max_c / (S * S)
    return obj, c

def run_fista_backtrack(a_init, n, S, max_time, rng, beta_start=20.0, beta_max=2000.0):

    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) * S / n
    else:
        a = a * (S / s)

    c = fft_convolve_self(a)
    beta = beta_start

        total = exp_bc.sum()
        if total < 1e-300:

        gnorm = np.linalg.norm(grad)
        if gnorm < 1e-15:

        trial_step = step
        accepted = False
        for _ in range(20):

            obj_new, _ = objective_and_conv(x_new)
            if obj_new < best_obj or obj_new < objective_and_conv(y)[0]:

                a = x_new
                if obj_new < best_obj:
                    best_obj = obj_new
                    best_a = x_new.copy()
                accepted = True
                step = min(trial_step * 1.5, 4.0 * S / n)
                break
            trial_step *= 0.5
        
        if not accepted:
            # Take a very small step
            step *= 0.5
            if step < 1e-10:
                # Random perturbation
                noise = rng.normal(0, 0.01 * S / np.sqrt(n), n)
                a = project_simplex(a + noise, S)
                step = S / (10 * n)
                t = 1.0
                continue
        
        # Nesterov momentum
        t_new = 0.5 * (1.0 + np.sqrt(1.0 + 4.0*t*t))
        y = a + ((t-1.0)/t_new) * (a - (y - trial_step * grad))  # This is getting complicated

        # Or better, let me use the standard FISTA update without the backtracking complexity
        t = t_new

import numpy as np
import time
from scipy.fft import fft, ifft

def project_simplex(v, S):
    n = len(v)
    v = np.asarray(v, dtype=np.float64).copy()
    w = np.sort(v)[::-1]
    cs = np.cumsum(w)
    idx = np.arange(1, n+1, dtype=np.float64)
    theta = (cs - S) / idx
    valid = theta <= w
    rho = n if not np.any(valid) else int(np.max(np.where(valid)[0])) + 1
    theta = (cs[rho-1] - S) / rho
    return np.maximum(v - theta, 0.0)

def conv_self(a):
    n = len(a)
    size = 2*n - 1
    fs = 1 << (size-1).bit_length()
    A = fft(a, fs)
    return np.real(ifft(A*A))[:size]

def conv_grad(a, w):
    """d(sum_k w[k]*c[k])/da, where c = a*a (linear conv)."""
    n = len(a)
    fs = 1 << (2*n-1).bit_length()
    W = fft(w, fs)
    A = fft(a, fs)
    return np.real(ifft(np.conj(A) * W))[:n]

def get_obj(a):
    n = len(a)
    S = a.sum()
    if S < 0.01:
        return np.inf
    c = conv_self(a)
    return 2.0 * n * c.max() / (S*S)

def normalize(a, S):
    a = np.clip(a, 0, 1000).astype(np.float64).copy()
    s = a.sum()
    if s < 1e-15:
        return np.ones(len(a)) * S / len(a)
    return a * (S / s)

def fista_logsumexp(a0, n, S, time_budget, rng, beta0=50, beta_end=3000):
    a = normalize(a0, S).copy()
    y = a.copy()
    t = 1.0
    start = time.monotonic()
    best_obj = get_obj(a)
    best_a = a.copy()
    it = 0
    lr = 2.0 * S / n  # initial learning rate
    
    while time.monotonic() - start < time_budget:
        it += 1
        frac = min(1.0, it / (time_budget * 100))  # rough progress
        beta = beta0 * (beta_end / beta0) ** frac
        
        c = conv_self(y)
        cm = c.max()
        eb = np.exp(beta * (c - cm))
        tot = eb.sum()
        w = eb / tot if tot > 1e-300 else np.ones(len(c))/len(c)
        
        g = conv_grad(y, w)
        gn = np.linalg.norm(g)
        if gn < 1e-15:
            break
        
        x = project_simplex(y - lr * g / gn, S)
        
        # Check improvement
        if it % 10 == 0:
            ox = get_obj(x)
            if ox < best_obj:
                best_obj = ox
                best_a = x.copy()
        
        t_new = 0.5 * (1.0 + np.sqrt(1.0 + 4.0*t*t))
        y = x + ((t-1.0)/t_new) * (x - a)
        y = np.maximum(y, 0.0)
        a = x
        t = t_new
        
        # Adaptive lr
        if it % 500 == 0:
            lr *= 0.95
        if it % 2000 == 0 and rng.random() < 0.2:
            noise = rng.normal(0, 0.005*S/np.sqrt(n), n)
            a = project_simplex(a + noise, S)
            y = a.copy()
            t = 1.0
    
    return best_a, best_obj

def peak_reduction(a0, n, S, time_budget, rng):
    """Directly target the peak lag with greedy coordinate moves."""
    a = normalize(a0, S).copy()
    start = time.monotonic()
    best_obj = get_obj(a)
    best_a = a.copy()
    
    while time.monotonic() - start < time_budget:
        c = conv_self(a)
        pk = c.argmax()
        pk_val = c[pk]
        
        # Find coordinates that contribute most to c[pk]
        # c[pk] = sum_i a[i]*a[pk-i]
        contrib = np.zeros(n)
        for i in range(n):
            j = pk - i
            if 0 <= j < n:
                contrib[i] = a[i] * a[j]
        
        # Move mass from high-contributing to low-contributing coordinates
        # Pick top contributor and a random low one
        if contrib.max() < 1e-10:
            break
        
        top_idx = contrib.argmax()
        # Find a random index with low contribution
        low_mask = contrib < np.mean(contrib)
        low_idx = np.where(low_mask)[0]
        if len(low_idx) == 0:
            break
        target_idx = low_idx[rng.integers(len(low_idx))]
        
        # Move a small amount of mass
        delta = 0.01 * S / n
        a[top_idx] -= delta
        a[target_idx] += delta
        a = np.maximum(a, 0)
        a = normalize(a, S)
        
        obj = get_obj(a)
        if obj < best_obj:
            best_obj = obj
            best_a = a.copy()
        else:
            # Revert
            a[top_idx] += delta
            a[target_idx] -= delta
            a = np.maximum(a, 0)
            a = normalize(a, S)
    
    return best_a, best_obj

def simulated_annealing(a0, n, S, time_budget, rng, T0=0.01, T_end=1e-6):
    a = normalize(a0, S).copy()
    start = time.monotonic()
    best_obj = get_obj(a)
    best_a = a.copy()
    c = conv_self(a)
    cur_obj = best_obj
    total_time = time_budget
    
    while time.monotonic() - start < time_budget:
        elapsed = time.monotonic() - start
        frac = elapsed / total_time
        T = T0 * (T_end / T0) ** frac
        
        # Random perturbation
        n_perturb = rng.integers(1, max(2, n//100))
        indices = rng.choice(n, n_perturb, replace=False)
        delta = rng.normal(0, 0.01*S/np.sqrt(n_perturb), n_perturb)
        
        a_new = a.copy()
        a_new[indices] += delta
        a_new = normalize(a_new, S)
        
        c_new = conv_self(a_new)
        obj_new = 2.0 * n * c_new.max() / (a_new.sum()**2)
        
        if obj_new < cur_obj or rng.random() < np.exp(-(obj_new - cur_obj) / max(T, 1e-15)):
            a = a_new
            cur_obj = obj_new
            if obj_new < best_obj:
                best_obj = obj_new
                best_a = a.copy()
    
    return best_a, best_obj

"""
Minimize 2*n*max_conv/sum^2 over non-negative sequences.
Strategy: Multi-phase optimization with adaptive log-sum-exp FISTA,
momentum-aware restarts, targeted peak polishing, and multi-n exploration.
Key improvements: adaptive beta cycling, momentum reset on stall,
greedy coordinate moves targeting the peak, and trying multiple lengths.
"""
import numpy as np
import time
from scipy.fft import fft, ifft


def project_simplex(v, S):
    """Euclidean projection onto {x >= 0, sum(x) = S}."""
    n = len(v)
    if n == 0:
        return np.array([], dtype=np.float64)
    v = np.asarray(v, dtype=np.float64).copy()
    w = np.sort(v)[::-1]
    cs = np.cumsum(w)
    idx = np.arange(1, n + 1, dtype=np.float64)
    theta = (cs - S) / idx
    valid = theta <= w
    if not np.any(valid):
        rho = n
    else:
        rho = int(np.max(np.where(valid)[0])) + 1
    theta = (cs[rho - 1] - S) / rho
    return np.maximum(v - theta, 0.0)


def conv_self(a):
    """Linear self-convolution via FFT. Returns array of length 2n-1."""
    n = len(a)
    size = 2 * n - 1
    fs = 1 << (size - 1).bit_length()
    A = fft(a, fs)
    c = np.real(ifft(A * A))
    return c[:size]


def conv_grad(a, w):
    """Gradient of sum_k w[k]*c[k] w.r.t. a, where c = a*a (linear conv).
    Uses the identity: dc[k]/da[i] = 2*a[k-i] if 0<=k-i<n, else 0.
    So g[i] = 2 * sum_m w[i+m] * a[m] = 2 * cross-correlation."""
    n = len(a)
    fs = 1 << (2 * n - 1).bit_length()
    A = fft(a, fs)
    W = fft(w, fs)
    return 2.0 * np.real(ifft(np.conj(A) * W))[:n]


def compute_obj(a):
    """Compute the objective value 2*n*max_conv/sum^2."""
    n = len(a)
    S = a.sum()
    if S < 0.01:
        return np.inf
    c = conv_self(a)
    return 2.0 * n * c.max() / (S * S)


def normalize_seq(a, S):
    """Clamp to [0,1000] and rescale to sum = S."""
    a = np.clip(np.asarray(a, dtype=np.float64), 0.0, 1000.0)
    s = a.sum()
    if s < 1e-15:
        return np.ones(len(a)) * S / len(a)
    return a * (S / s)


def softmax_weight(c, beta):
    """Compute softmax weights on convolution values."""
    c_max = c.max()
    exp_bc = np.exp(beta * (c - c_max))
    total = exp_bc.sum()
    if total < 1e-300:
        return np.full_like(c, 1.0 / len(c))
    return exp_bc / total


def fista_optimize(a_init, n, S, time_budget, rng, beta0=30.0, beta_end=3000.0,
                   lr_scale=1.0, perturb_interval=3000, perturb_prob=0.25):
    """FISTA with adaptive log-sum-exp smoothing and momentum-aware restarts."""
    a = normalize_seq(a_init, S).copy()
    y = a.copy()
    t = 1.0
    start = time.monotonic()
    best_obj = compute_obj(a)
    best_a = a.copy()
    it = 0
    lr = lr_scale * S / n
    stall = 0
    last_best = best_obj
    total_iters_expected = int(time_budget * 30)  # rough estimate

    while time.monotonic() - start < time_budget:
        it += 1
        frac = min(1.0, it / max(total_iters_expected, 1))
        # Cyclical beta: sweep up and down to avoid getting stuck
        cycle = int(it / max(1, total_iters_expected // 8))
        pos_in_cycle = (it % max(1, total_iters_expected // 8)) / max(1, total_iters_expected // 8)
        # Triangle wave: 0 -> 1 -> 0
        tri = 1.0 - abs(2.0 * pos_in_cycle - 1.0)
        beta = beta0 * (beta_end / beta0) ** (0.3 + 0.7 * tri)

        c = conv_self(y)
        w = softmax_weight(c, beta)
        g = conv_grad(y, w)
        gn = np.linalg.norm(g)
        if gn < 1e-15:
            break

        x = project_simplex(y - lr * g / gn, S)

        # Nesterov momentum
        t_new = 0.5 * (1.0 + np.sqrt(1.0 + 4.0 * t * t))
        y = x + ((t - 1.0) / t_new) * (x - a)
        y = np.maximum(y, 0.0)
        a = x
        t = t_new

        # Periodic objective check
        if it % 50 == 0:
            obj = compute_obj(a)
            if obj < best_obj - 1e-12:
                if best_obj < last_best and stall > 0:
                    pass
                best_obj = obj
                best_a = a.copy()
                stall = 0
                last_best = best_obj
            else:
                stall += 1

        # Adaptive learning rate
        if it % 1000 == 0:
            lr *= 0.97

        # Momentum reset and perturbation on stall
        if stall > 10 and it % perturb_interval < 50:
            if rng.random() < perturb_prob:
                noise_scale = 0.003 * S / np.sqrt(n) * (1.0 + 0.1 * stall)
                a = project_simplex(a + rng.normal(0, noise_scale, n), S)
                y = a.copy()
                t = 1.0
                stall = 0
                lr = lr_scale * S / n

    return best_a, best_obj


def peak_polish(a_init, n, S, time_budget, rng):
    """Targeted optimization focusing on the top 1-3 lags with small steps."""
    a = normalize_seq(a_init, S).copy()
    start = time.monotonic()
    best_obj = compute_obj(a)
    best_a = a.copy()
    it = 0
    base_lr = S / (4.0 * n)

    while time.monotonic() - start < time_budget:
        it += 1
        c = conv_self(a)
        top_k = min(3, 1 + it // 2000)
        top_idx = np.argpartition(c, -top_k)[-top_k:]
        top_vals = c[top_idx]
        tv_sum = top_vals.sum()
        if tv_sum < 1e-30:
            break
        w = np.zeros_like(c)
        w[top_idx] = top_vals / tv_sum

        g = conv_grad(a, w)
        gn = np.linalg.norm(g)
        if gn < 1e-15:
            break

        lr = base_lr * (1.0 + 0.5 * np.sin(0.001 * it))
        x = project_simplex(a - lr * g / gn, S)

        obj_x = compute_obj(x)
        if obj_x < best_obj:
            best_obj = obj_x
            best_a = x.copy()
            a = x
        else:
            # Try half step
            x_half = project_simplex(a - 0.5 * lr * g / gn, S)
            obj_half = compute_obj(x_half)
            if obj_half < compute_obj(a):
                a = x_half
            elif it % 500 == 0 and rng.random() < 0.3:
                noise = rng.normal(0, 0.001 * S / np.sqrt(n), n)
                a = project_simplex(a + noise, S)

    return best_a, best_obj


def greedy_peak_moves(a_init, n, S, time_budget, rng):
    """Greedy coordinate moves: shift mass from high-contributing to low-contributing coords at the peak."""
    a = normalize_seq(a_init, S).copy()
    start = time.monotonic()
    best_obj = compute_obj(a)
    best_a = a.copy()
    cur_obj = best_obj
    n_trials = 0

    while time.monotonic() - start < time_budget:
        c = conv_self(a)
        pk = int(c.argmax())
        pk_val = c[pk]

        # Compute contribution of each coordinate to c[pk]
        # c[pk] = sum_i a[i]*a[pk-i], so contrib[i] = a[i]*a[pk-i] (if 0<=pk-i<n)
        contrib = np.zeros(n)
        j_start = max(0, pk - (n - 1))
        j_end = min(n, pk + 1)
        for i in range(j_start, j_end):
            j = pk - i
            if 0 <= j < n:
                contrib[i] = a[i] * a[j]
                contrib[j] += a[j] * a[i]  # j also contributes (double counting is OK for ranking)

        # Find top contributors and low ones
        top_mask = contrib > np.percentile(contrib[contrib > 0], 90)
        low_mask = contrib < np.percentile(contrib[contrib > 0], 25) if np.any(contrib > 0) else np.zeros(n, dtype=bool)

        top_indices = np.where(top_mask)[0]
        low_indices = np.where(low_mask)[0]

        if len(top_indices) == 0 or len(low_indices) == 0:
            # Random perturbation
            a = project_simplex(a + rng.normal(0, 0.002 * S / np.sqrt(n), n), S)
            continue

        # Try several random moves
        for _ in range(5):
            src = top_indices[rng.integers(len(top_indices))]
            dst = low_indices[rng.integers(len(low_indices))]
            if src == dst:
                continue
            delta = rng.uniform(0.001, 0.01) * S / n
            a_trial = a.copy()
            a_trial[src] -= delta
            a_trial[dst] += delta
            if a_trial[src] < 0:
                delta = a_trial[src] + a[src]
                a_trial[src] = 0
                a_trial[dst] = a[dst] + delta
            a_trial = project_simplex(a_trial, S)

            obj_trial = compute_obj(a_trial)
            if obj_trial < cur_obj:
                a = a_trial
                cur_obj = obj_trial
                if obj_trial < best_obj:
                    best_obj = obj_trial
                    best_a = a_trial.copy()
                break
        else:
            # No improvement; small random kick
            a = project_simplex(a + rng.normal(0, 0.001 * S / np.sqrt(n), n), S)
            cur_obj = compute_obj(a)

    return best_a, best_obj
