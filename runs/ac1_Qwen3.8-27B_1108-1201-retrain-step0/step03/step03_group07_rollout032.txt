`Δc[k] ≈ δ * (∂c[k]/∂a[m] - ∂c[k]/∂a[m']) = δ * 2 * (a[k-m] - a[k-m'])`

- At the peak position k*, for each pair (m, m'), if a[k*-mod(m)] < a[k*-mod(m')], transfer mass from m' to m.
- The best m is the one where a[k*-m] is smallest (ideally 0).
- The best m' is the one where a[k*-m'] is largest.

    """Reduce the peak of conv(a,a) by transferring mass."""
    a = a.copy().astype(np.float64)
    n = len(a)
    S = a.sum()
    a = a / S
    
    c = fft_conv_self(a)
    cur_max = c.max()
    
    for step in range(n_max_steps):
        k_star = np.argmax(c)
        
        # Find the best (m, m') pair for mass transfer
        # We want: a[k_star - m] < a[k_star - m']
        # i.e., the "partner" of m at the peak is smaller
        
        # For each m in [0, n-1], the partner at k_star is a[k_star - m mod n]... 
        # Actually, for linear convolution, the partner is a[k_star - m] (valid if 0 <= k_star - m < n)
        
        partners = np.zeros(n)
        for m in range(n):
            j = k_star - m
            if 0 <= j < n:
                partners[m] = a[j]
            else:
                partners[m] = 0  # no contribution from this m at position k_star
        
        # We want to increase m where partners[m] is small and decrease m' where partners[m'] is large
        # But we also need m and m' to both contribute to the peak
        
        # Find m with smallest partner (but non-zero a[m])
        # Find m' with largest partner (but non-zero a[m'])
        
        valid_m = np.where((a > 1e-10) & (partners > 0))[0]
        if len(valid_m) < 2:
            break
        
        # Score: we want to transfer FROM m' (large partner) TO m (small partner)
        # The gain is proportional to (partners[m'] - partners[m]) * delta
        # But we also need to check that this doesn't increase other peaks
        
        # Simple heuristic: transfer from the m with largest a[m]*partners[m] 
        # to the m with smallest partners[m] (but a[m] > 0)
        
        products = a * partners
        m_source = np.argmax(products)  # largest contribution
        m_target = np.argmin(partners[partners > 0] if (partners > 0).any() else partners)
        
        if m_source == m_target:
            break
        
        # Transfer a small amount
        delta = 0.01 * a[m_source]
        a[m_source] -= delta
        a[m_target] += delta
        a = np.maximum(a, 0)
        a = a / a.sum()
        
        c = fft_conv_self(a)
        new_max = c.max()
        
        if new_max >= cur_max:
            # Revert
            a[m_source] += delta
            a[m_target] -= delta
            a = np.maximum(a, 0)
            a = a / a.sum()
            break
        
        cur_max = new_max
    
    return a, 2.0 * n * cur_max
