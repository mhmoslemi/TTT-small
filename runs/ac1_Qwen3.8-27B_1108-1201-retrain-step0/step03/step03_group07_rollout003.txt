    c = np.real(ifft(A*A))

def lp_direction(f, M):
    """
    Solve LP: max sum(b) subject to b >= 0, conv(f, b) <= M
    Returns the optimal b.
    """
    n = len(f)
    num_constraints = 2*n - 1
    
    # Build constraint matrix A (sparse would be ideal but let's use dense for simplicity)
    # Actually for n=4096, the matrix is 8191 x 4096 which is ~33M entries. That's too large for dense.
    # Let's use a different approach.
    
    # Alternative: use the structure. conv(f, b)[k] = sum_j f[k-j] * b[j]
    # For each k, the constraint involves f[max(0,k-n+1):min(n,k+1)] dotted with b
    
    # Actually, let's just build the sparse matrix
    from scipy.sparse import csr_matrix
    
    rows = []
    cols = []
    data = []
    
    for k in range(2*n - 1):
        j_lo = max(0, k - n + 1)
        j_hi = min(n - 1, k)
        for j in range(j_lo, j_hi + 1):
            rows.append(k)
            cols.append(j)
            data.append(f[k - j])
    
    A = csr_matrix((data, (rows, cols)), shape=(2*n-1, n))
    
    # Objective: minimize -sum(b)
    c_obj = -np.ones(n)
    
    res = linprog(c_obj, A_ub=A, b_ub=np.full(2*n-1, M), bounds=(0, None), method='highs')
    
    if res.status == 0:
        return res.x
    else:
        return None

Let me try a different tack: **use the full gradient (not top-k approximation)**.

The subgradient of max(c_0, ..., c_{2n-2}) can be any convex combination of the gradients of the active constraints. If we use the uniform distribution over ALL indices where c[k] is within epsilon of the max, we get a "smoothed" gradient that captures more information.

For n=4096, the convolution has 8191 values. Computing the gradient for all of them simultaneously would require:
grad[m] = 2 * sum_{k: c[k] ≈ max} w_k * a[k-m]

If we use a softmax weighting: w_k = exp(beta * c[k]) / sum_j exp(beta * c[j])

Then: grad = 2 * conv(w, a_rev)[n-1:2n-1]

This can be computed with a single FFT. The cost is O(n log n) per iteration, same as the top-k approach.

The advantage is that we get a smooth gradient that naturally handles the case where multiple peaks are active. We just need to tune beta (the temperature).

Let me implement this:

```python
def compute_softgrad(c, a, beta):
    """Compute smoothed subgradient using softmax weighting."""
    n = len(a)
    # Softmax weights
    c_shifted = c - c.max()
    w = np.exp(beta * c_shifted)
    w /= w.sum()
    
    # grad[m] = 2 * sum_k w[k] * a[k-m]
    a_rev = a[::-1]
    fsize = 1 << (len(c) + n - 1 - 1).bit_length()
    W = fft(w, fsize)
    R = fft(a_rev, fsize)
    full = np.real(ifft(W * R))
    grad = 2.0 * full[n-1:2*n-1]
    return grad
```

This is clean and efficient. The parameter beta controls the "sharpness":
- beta → 0: uniform weights (averages all peaks)
- beta → ∞: only the max peak

I'll anneal beta from low to high over the course of the optimization.

                        eta0=0.3, momentum=0.85, verbose=True):

    S = a.sum()
    a = np.maximum(a, 0.0)
    a = a * S / a.sum()

    while time.monotonic() - start < time_budget:

        progress = min(1.0, (time.monotonic() - start) / time_budget)
        beta = beta_start + (beta_end - beta_start) * progress * progress  # quadratic annealing

5. Update |A|^2 = |A|^2 / (|A|^2 + epsilon) to flatten it (iteratively reweighted least squares style)
6. Repeat
