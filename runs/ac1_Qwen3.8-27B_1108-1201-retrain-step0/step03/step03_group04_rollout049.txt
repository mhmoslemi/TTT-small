So for feasibility, we need k-A ⊆ A, i.e., A is symmetric about k/2. If A is symmetric, then k-A = A.

So the "all formulas work out" case is when A is symmetric about k/2. In that case, a[m] = S/|A| for all m in A, and 0 otherwise.

The peak value is: (a*a)[k] = sum_{i in A, k-i in A} a[i]*a[k-i] = |A| * (S/|A|)^2 = S^2/|A|.

To minimize this, we want to maximize |A|, subject to A being symmetric about k/2 and A ⊆ P (the participating set).

The maximum |A| is |P| (take A = P if P is symmetric about k/2).

P = [max(0, k-n+1), min(k, n-1)].
|P| = min(k, n-1) - max(0, k-n+1) + 1.

For k in [0, n-1]: |P| = k - 0 + 1 = k+1 (if k ≤ n-1)
Wait: max(0, k-n+1) = 0 when k-n+1 ≤ 0, i.e., k ≤ n-1. And min(k, n-1) = k when k ≤ n-1.
So for k in [0, n-1]: |P| = k+1.

For k in [n, 2n-2]: max(0, k-n+1) = k-n+1. min(k, n-1) = n-1.
So |P| = (n-1) - (k-n+1) + 1 = 2n-1-k.

P is symmetric about k/2 iff the interval [L, R] (where L=max(0,k-n+1), R=min(k,n-1)) is symmetric about k/2, i.e., L+R = k.

For k in [0, n-1]: L=0, R=k. L+R = k. ✓ Always symmetric!
For k in [n, 2n-2]: L=k-n+1, R=n-1. L+R = k-n+1+n-1 = k. ✓ Always symmetric!

So P is always symmetric about k/2! Great.

So the optimal solution for the single-lag QP is: a[m] = S/|P| for m in P, and 0 otherwise.
The peak value is S^2/|P|.

For k = n-1: |P| = n, peak = S^2/n = 2n/n = 2.
For k = n-2: |P| = n-1, peak = S^2/(n-1) = 2n/(n-1) ≈ 2 + 2/n.

But wait, this is only the solution to the single-lag problem! When we set a to be the solution for lag k, other lags might have higher peaks. So we need to check all lags.

If we set a[m] = S/|P_k| for m in P_k (the participating set for lag k):
What is (a*a)[j] for other lags j?

(a*a)[j] = sum_{i in P_k, j-i in P_k} (S/|P_k|)^2

The number of such i is |P_k ∩ (j - P_k)| = |P_k ∩ [j-R_k, j-L_k]| where P_k = [L_k, R_k].

This is the overlap of [L_k, R_k] with [j-R_k, j-L_k], which is the length of [max(L_k, j-R_k), min(R_k, j-L_k)] if non-empty.

This is getting complex. The point is: the single-lag optimal solution won't be the global optimum because other lags will spike.

"""
Minimize 2*n*max_conv/sum^2 over non-negative sequences.
Strategy: Multi-n exploration with structured initialization, adaptive FISTA,
peak-focused KKT polishing, and active-set QP refinement.
Key innovations: multiple sequence lengths, cosine-bell initialization,
per-coordinate Adam steps, analytical peak gradient exploitation,
and a box-solution feasibility check for certificate-based polishing.

import numpy as np
import time
from scipy.fft import fft, ifft


def project_simplex(v, S):
    """Euclidean projection of v onto {x >= 0, sum(x) = S}."""
    n = len(v)
    if n == 0:
        return v
    v = np.asarray(v, dtype=np.float64).copy()
    w = np.sort(v)[::-1]
    cumsum = np.cumsum(w)
    idx = np.arange(1, n + 1, dtype=np.float64)
    theta_candidates = (cumsum - S) / idx
    valid = theta_candidates <= w
    if not np.any(valid):
        rho = n
    else:
        rho = int(np.max(np.where(valid)[0]) + 1)
    theta = (cumsum[rho - 1] - S) / rho
    return np.maximum(v - theta, 0.0)


def fft_convolve_self(a):
    """Full self-convolution of a via FFT. Returns array of length 2n-1."""
    n = len(a)
    size = 2 * n - 1
    fsize = 1 << (size - 1).bit_length()
    A = fft(a, fsize)
    c = np.real(ifft(A * A))
    return c[:size]


def peak_gradient_analytical(a, k):
    """
    Exact gradient of (a*a)[k] w.r.t. a for linear convolution.
    grad[j] = 2*a[k-j] if 0<=k-j<n and 2j!=k
             = a[j]     if 2j==k (i.e., j=k/2)
             = 0        otherwise
    """
    n = len(a)
    grad = np.zeros(n)
    # Indices j where 0 <= k-j < n
    j_min = max(0, k - n + 1)
    j_max = min(n - 1, k)
    if j_min > j_max:
        return grad
    # For j in [j_min, j_max], k-j is in [0, n-1]
    m_indices = k - np.arange(j_min, j_max + 1)  # = k-j for each j
    vals = 2.0 * a[m_indices]
    # Handle the special case where 2j == k (i.e., j == k/2)
    if k % 2 == 0:
        j_half = k // 2
        if j_min <= j_half <= j_max:
            idx_in_range = j_half - j_min
            vals[idx_in_range] = a[j_half]  # only one copy
    grad[j_min:j_max + 1] = vals
    return grad


def softmax_weights(c, beta):
    """Compute softmax weights on convolution values."""
    c_max = c.max()
    exp_bc = np.exp(beta * (c - c_max))
    total = exp_bc.sum()
    if total < 1e-300:
        return np.full_like(c, 1.0 / len(c))
    return exp_bc / total


def run_adaptive_fista(a_init, n, S, max_time, rng, beta_init=30.0, beta_max=500.0):
    """
    FISTA with adaptive beta (starts low, increases) and backtracking.
    Uses softmax weights on the full convolution.
    """
    a = np.clip(a_init, 0.0, 1000.0).copy().astype(np.float64)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) * S / n
    else:
        a = a * (S / s)

    y = a.copy()
    t_mom = 1.0
    start = time.monotonic()
    best_score = np.inf
    best_local = a.copy()
    it = 0
    step = 2.0 * S / (n * 3.0)
    stall = 0

    while time.monotonic() - start < max_time:
        it += 1
        beta = min(beta_max, beta_init * (1.0 + 0.005 * it))

        c_y = fft_convolve_self(y)
        cur = c_y.max()
        if cur < best_score - 1e-13:
            best_score = cur
            best_local = y.copy()
            stall = 0
        else:
            stall += 1

        # Compute gradient using softmax-weighted combination
        if stall < 200:
            w = softmax_weights(c_y, beta)
        else:
            # Switch to top-1 when stalled
            top_idx = np.argmax(c_y)
            w = np.zeros_like(c_y)
            w[top_idx] = 1.0

        # Compute gradient via FFT cross-correlation
        fsize = 1 << (len(w) + n - 2).bit_length()
        W = fft(w, fsize)
        A_y = fft(y, fsize)
        grad = 2.0 * np.real(ifft(W * np.conj(A_y)))[:n]
        gnorm = np.linalg.norm(grad)
        if gnorm < 1e-15:
            break

        # Adaptive step with backtracking
        x_new = project_simplex(y - step * grad / max(gnorm, 1e-15), S)

        # Check improvement
        if it % 10 == 0:
            c_x = fft_convolve_self(x_new)
            if c_x.max() < cur:
                pass  # good direction
            elif stall > 100:
                step *= 0.7

        # Nesterov momentum
        t_new = 0.5 * (1.0 + np.sqrt(1.0 + 4.0 * t_mom * t_mom))
        y = x_new + ((t_mom - 1.0) / t_new) * (x_new - a)
        y = np.maximum(y, 0.0)
        a = x_new
        t_mom = t_new

        # Periodic perturbation to escape local minima
        if it % 2000 == 0 and rng.random() < 0.3:
            noise = rng.normal(0, 0.003 * S / np.sqrt(n), n)
            y = project_simplex(y + noise, S)
            t_mom = 1.0
            step = 2.0 * S / (n * 3.0)

    return best_local, best_score


def run_peak_adam(a_init, n, S, max_time, rng, lr_init=0.05, beta1=0.9, beta2=0.999):
    """
    Adam-style optimizer focused on the peak lag.
    Uses analytical gradient of the peak convolution value.
    """
    a = np.clip(a_init, 0.0, 1000.0).copy().astype(np.float64)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) * S / n
    else:
        a = a * (S / s)

    m = np.zeros(n)  # First moment
    v = np.zeros(n)  # Second moment
    start = time.monotonic()
    best_score = np.inf
    best_local = a.copy()
    it = 0

    while time.monotonic() - start < max_time:
        it += 1
        c = fft_convolve_self(a)
        cur = c.max()
        if cur < best_score - 1e-13:
            best_score = cur
            best_local = a.copy()

        # Get the peak lag(s)
        peak_lag = int(np.argmax(c))

        # Analytical gradient of peak
        grad = peak_gradient_analytical(a, peak_lag)
        gnorm = np.linalg.norm(grad)
        if gnorm < 1e-15:
            break

        # Adam update
        lr = lr_init / (1.0 + 0.001 * it)
        m = beta1 * m + (1 - beta1) * grad
        v = beta2 * v + (1 - beta2) * grad ** 2
        m_hat = m / (1 - beta1 ** (it + 1))
        v_hat = v / (1 - beta2 ** (it + 1))

        a_new = a - lr * m_hat / (np.sqrt(v_hat) + 1e-8)
        a_new = project_simplex(a_new, S)

        # Accept if improvement
        c_new = fft_convolve_self(a_new)
        if c_new.max() <= cur + 1e-12:
            a = a_new
        else:
            # Half step
            a_half = project_simplex(a - 0.5 * lr * m_hat / (np.sqrt(v_hat) + 1e-8), S)
            c_half = fft_convolve_self(a_half)
            if c_half.max() < cur:
                a = a_half
            elif it % 500 == 0 and rng.random() < 0.1:
                noise = rng.normal(0, 0.001 * S / np.sqrt(n), n)
                a = project_simplex(a + noise, S)

    return best_local, best_score


def run_box_solution_check(a, n, S):
    """
    For the current peak lag, check if the box solution (uniform on P_k)
    gives a better overall peak. If so, return the box solution.
    """
    c = fft_convolve_self(a)
    k = int(np.argmax(c))

    # P_k = [max(0, k-n+1), min(k, n-1)]
    L = max(0, k - n + 1)
    R = min(n - 1, k)
    P_size = R - L + 1

    # Box solution: uniform on P_k
    a_box = np.zeros(n)
    a_box[L:R + 1] = S / P_size

    c_box = fft_convolve_self(a_box)
    peak_box = c_box.max()
    peak_orig = c.max()

    if peak_box < peak_orig:
        return a_box, peak_box
    return None, peak_orig


def run_kkt_polish(a_init, n, S, max_time, rng):
    """
    KKT-based polishing: iteratively identify peak, solve single-lag QP,
    check feasibility, and adjust.
    """
    a = np.clip(a_init, 0.0, 1000.0).copy().astype(np.float64)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) * S / n
    else:
        a = a * (S / s)

    start = time.monotonic()
    best_score = np.inf
    best_local = a.copy()

    while time.monotonic() - start < max_time:
        c = fft_convolve_self(a)
        cur = c.max()
        if cur < best_score - 1e-13:
            best_score = cur
            best_local = a.copy()

        k = int(np.argmax(c))

        # Try box solution for this peak
        a_box, peak_box = run_box_solution_check(a, n, S)
        if a_box is not None:
            a = a_box
            continue

        # Gradient step with the peak lag only
        grad = peak_gradient_analytical(a, k)
        gnorm = np.linalg.norm(grad)
        if gnorm < 1e-15:
            break

        # Line search: try several step sizes
        best_step = 0
        best_a = a
        base_step = S / (n * 4.0)
        for mult in [4.0, 2.0, 1.0, 0.5, 0.25, 0.125]:
            step = base_step * mult
            a_try = project_simplex(a - step * grad, S)
            c_try = fft_convolve_self(a_try)
            if c_try.max() < cur:
                best_step = step
                best_a = a_try
                break

        if best_step > 0:
            a = best_a
        else:
            # Stuck: try perturbing
            if rng.random() < 0.5:
                noise = rng.normal(0, 0.002 * S / np.sqrt(n), n)
                a = project_simplex(a + noise, S)
            # Also try box solution with different lags
            for dk in range(1, 5):
                k2 = k + dk
                if 0 <= k2 < 2 * n - 1:
                    L2 = max(0, k2 - n + 1)
                    R2 = min(n - 1, k2)
                    if R2 >= L2:
                        a_test = np.zeros(n)
                        a_test[L2:R2 + 1] = S / (R2 - L2 + 1)
                        c_test = fft_convolve_self(a_test)
                        if c_test.max() < cur:
                            a = a_test
                            break

    return best_local, best_score


def run_multi_topk(a_init, n, S, max_time, rng):
    """
    Multi-scale top-k optimization: start with top-1, gradually increase.
    Uses weight interpolation between top-k levels.
    """
    a = np.clip(a_init, 0.0, 1000.0).copy().astype(np.float64)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n) * S / n
    else:
        a = a * (S / s)

    y = a.copy()
    t_mom = 1.0
    start = time.monotonic()
    best_score = np.inf
    best_local = a.copy()
    it = 0
    step = S / (n * 2.0)

    while time.monotonic() - start < max_time:
        it += 1
        # Cycle through top-k values: 1, 1, 1, 2, 2, 3, 3, 5, 5, 5, 10, ...
        phase = it // 300
        if phase < 3:
            top_k = 1
        elif phase < 5:
            top_k = 2
        elif phase < 7:
            top_k = 3
        elif phase < 10:
            top_k = 5
        else:
            top_k = min(20, top_k + 1)

        c = fft_convolve_self(y)
        cur = c.max()
        if cur < best_score - 1e-13:
            best_score = cur
            best_local = y.copy()

        # Top-k weights with smooth falloff
        top_indices = np.argpartition(c, -top_k)[-top_k:]
        top_vals = c[top_indices]
        w = np.zeros_like(c)
        w[top_indices] = top_vals ** 2  # Square for more concentration
        w_total = w.sum()
        if w_total > 1e-30:
            w /= w_total

        fsize = 1 << (len(w) + n - 2).bit_length()
        W = fft(w, fsize)
        A_y = fft(y, fsize)
        grad = 2.0 * np.real(ifft(W * np.conj(A_y)))[:n]
        gnorm = np.linalg.norm(grad)
        if gnorm < 1e-15:
            break

        x_new = project_simplex(y - step * grad / max(gnorm, 1e-15), S)

        t_new = 0.5 * (1.0 + np.sqrt(1.0 + 4.0 * t_mom * t_mom))
        y = x_new + ((t_mom - 1.0) / t_new) * (x_new - a)
        y = np.maximum(y, 0.0)
        a = x_new
        t_mom = t_new

        # Adapt step size
        if it % 50 == 0:
            c_x = fft_convolve_self(x_new)
            if c_x.max() < cur:
                step = min(step * 1.02, S / n)
            else:
                step *= 0.95

    return best_local, best_score


def cosine_bell_init(n, S):
    """Initialize with a cosine bell shape."""
    x = np.linspace(0, 1, n)
    a = np.cos(np.pi * (x - 0.5)) ** 2
    a = np.maximum(a, 0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n)
        s = n
    return a * (S / s)


def random_init(n, S, rng, smoothness=0):
    """Random initialization with optional smoothing."""
    a = rng.random(n)
    if smoothness > 0:
        kernel = np.ones(smoothness) / smoothness
        a = np.convolve(a, kernel, mode='same')
    a = np.maximum(a, 0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n)
        s = n
    return a * (S / s)


def hadamard_init(n, S):
    """
    Initialize based on Hadamard structure.
    For n = power of 2: use the all-ones row of the Hadamard matrix mapped to non-negative.
    This gives a flat sequence, which is a reasonable starting point.
    """
    if n & (n - 1) != 0:
        # Not power of 2, use next power of 2 and truncate
        n2 = 1 << (n - 1).bit_length()
        a_full = np.ones(n2) * 0.5 + 0.5 * np.cos(2 * np.pi * np.arange(n2) / n2)
        a = a_full[:n]
    else:
        # Use a Walsh-like pattern
        a = 0.5 + 0.5 * np.cos(2 * np.pi * np.arange(n) / n)
    a = np.maximum(a, 0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(n)
        s = n
    return a * (S / s)


def safe_normalize(a, n):
    """Clamp to [0,1000] and rescale to sum = sqrt(2n)."""
    a = np.clip(np.asarray(a, dtype=np.float64), 0.0, 1000.0)
    S = np.sqrt(2.0 * float(n))
    s = a.sum()
    if s <= 1e-15:
        return np.ones(n) * S / n
    return a * (S / s)


def resample_sequence(a_src, n_target):
    """Resample a sequence to a different length using interpolation."""
    n_src = len(a_src)
    if n_src == n_target:
        return a_src.copy()
    x_src = np.linspace(0, 1, n_src)
    x_tgt = np.linspace(0, 1, n_target)
    return np.interp(x_tgt, x_src, a_src)


def propose_candidate(seed=42, budget_s=2385, **kwargs):
    """
    Multi-strategy, multi-length optimization for minimizing
    2*n*max_conv/sum^2 over non-negative sequences.
    """
    rng = np.random.default_rng(seed)
    deadline = time.monotonic() + float(budget_s - 25.0)

    global_best = np.inf
    global_a = None
    global_n = 0

    # Get the parent sequence
    parent_a = None
    try:
        given = np.asarray(height_sequence_1, dtype=np.float64).reshape(-1)
        if given.size >= 32:
            parent_a = np.clip(given, 0, 1000)
    except Exception:
        pass

    # Candidate n values to try
    n_candidates = [4096, 8192, 12288, 16384]
    if parent_a is not None:
        parent_n = len(parent_a)
        if parent_n not in n_candidates:
            n_candidates.insert(0, parent_n)
        # Also try parent_n * 2 if reasonable
        if parent_n * 2 <= 32768 and parent_n * 2 not in n_candidates:
            n_candidates.append(parent_n * 2)

    # Remove duplicates while preserving order
    seen = set()
    n_candidates_unique = []
    for n in n_candidates:
        if n not in seen and 1024 <= n <= 32768:
            seen.add(n)
            n_candidates_unique.append(n)
    n_candidates = n_candidates_unique

    print("Trying n values: %s" % str(n_candidates))

    # Allocate time: more time to promising n values
    # First pass: quick evaluation of each n (10% of time each, max 200s)
    quick_time = min(150.0, 0.10 * (deadline - time.monotonic()))
    results = {}

    for n_try in n_candidates:
        if time.monotonic() > deadline - 60:
            break
        S_try = np.sqrt(2.0 * float(n_try))
        t0 = time.monotonic()

        # Generate multiple initializations
        inits = []
        if parent_a is not None:
            inits.append(safe_normalize(resample_sequence(parent_a, n_try), n_try))
        inits.append(cosine_bell_init(n_try, S_try))
        inits.append(random_init(n_try, S_try, rng, smoothness=16))
        inits.append(hadamard_init(n_try, S_try))

        best_n_score = np.inf
        best_n_a = None

        for init in inits:
            if time.monotonic() > t0 + quick_time:
                break
            # Quick FISTA
            a_q, score_q = run_adaptive_fista(init, n_try, S_try, min(8.0, quick_time / 2), rng,
                                              beta_init=20.0, beta_max=200.0)
            a_q = safe_normalize(a_q, n_try)
            c_q = fft_convolve_self(a_q)
            if c_q.max() < best_n_score:
                best_n_score = c_q.max()
                best_n_a = a_q.copy()

        obj_n = 2.0 * n_try * best_n_score / (S_try * S_try)
        results[n_try] = (best_n_score, best_n_a, obj_n)
        print("  n=%d: score=%.6f, obj=%.6f [%.0fs]" % (n_try, best_n_score, obj_n, time.monotonic() - t0))

    # Select the best n (and also the second best for diversity)
    sorted_ns = sorted(results.keys(), key=lambda x: results[x][0])
    best_n = sorted_ns[0]
    print("Best n: %d with score %.6f" % (best_n, results[best_n][0]))

    # === Main optimization on the best n ===
    n = best_n
    S = np.sqrt(2.0 * float(n))
    a_start = safe_normalize(results[n][1], n)
    global_best = results[n][0]
    global_a = a_start.copy()
    global_n = n
    obj_start = 2.0 * n * global_best / (S * S)
    print("Starting main optimization: n=%d, score=%.6f, obj=%.6f" % (n, global_best, obj_start))

    # Phase 1: Adaptive FISTA (30% of remaining time)
    remaining = deadline - time.monotonic()
    phase1_time = 0.30 * remaining
    if phase1_time > 10:
        print("Phase 1: Adaptive FISTA (%.0f sec)" % phase1_time)
        t0 = time.monotonic()
        a_p1, score_p1 = run_adaptive_fista(global_a, n, S, phase1_time, rng,
                                            beta_init=50.0, beta_max=1000.0)
        a_p1 = safe_normalize(a_p1, n)
        c_p1 = fft_convolve_self(a_p1)
        if c_p1.max() < global_best:
            global_best = c_p1.max()
            global_a = a_p1.copy()
            print("  FISTA: %.6f (obj %.6f) [%.0fs]" % (global_best, 2*n*global_best/S**2, time.monotonic()-t0))

    # Phase 2: Multi-top-k Nesterov (20% of remaining)
    remaining = deadline - time.monotonic()
    phase2_time = 0.20 * remaining
    if phase2_time > 10:
        print("Phase 2: Multi-top-k (%.0f sec)" % phase2_time)
        t0 = time.monotonic()
        a_p2, score_p2 = run_multi_topk(global_a, n, S, phase2_time, rng)
        a_p2 = safe_normalize(a_p2, n)
        c_p2 = fft_convolve_self(a_p2)
        if c_p2.max() < global_best:
            global_best = c_p2.max()
            global_a = a_p2.copy()
            print("  MultiTopK: %.6f (obj %.6f) [%.0fs]" % (global_best, 2*n*global_best/S**2, time.monotonic()-t0))

    # Phase 3: Peak Adam (20% of remaining)
    remaining = deadline - time.monotonic()
    phase3_time = 0.20 * remaining
    if phase3_time > 5:
        print("Phase 3: Peak Adam (%.0f sec)" % phase3_time)
        t0 = time.monotonic()
        a_p3, score_p3 = run_peak_adam(global_a, n, S, phase3_time, rng, lr_init=0.03)
        a_p3 = safe_normalize(a_p3, n)
        c_p3 = fft_convolve_self(a_p3)
        if c_p3.max() < global_best:
            global_best = c_p3.max()
            global_a = a_p3.copy()
            print("  Adam: %.6f (obj %.6f) [%.0fs]" % (global_best, 2*n*global_best/S**2, time.monotonic()-t0))

    # Phase 4: KKT polishing (15% of remaining)
    remaining = deadline - time.monotonic()
    phase4_time = 0.15 * remaining
    if phase4_time > 5:
        print("Phase 4: KKT Polish (%.0f sec)" % phase4_time)
        t0 = time.monotonic()
        a_p4, score_p4 = run_kkt_polish(global_a, n, S, phase4_time, rng)
        a_p4 = safe_normalize(a_p4, n)
        c_p4 = fft_convolve_self(a_p4)
        if c_p4.max() < global_best:
            global_best = c_p4.max()
            global_a = a_p4.copy()
            print("  KKT: %.6f (obj %.6f) [%.0fs]" % (global_best, 2*n*global_best/S**2, time.monotonic()-t0))

    # Phase 5: Explore second-best n (if time)
    remaining = deadline - time.monotonic()
    if remaining > 60 and len(sorted_ns) > 1:
        n2 = sorted_ns[1]
        S2 = np.sqrt(2.0 * float(n2))
        a2_start = safe_normalize(results[n2][1], n2)
        # Quick optimization on n2
        time_n2 = min(remaining * 0.3, 180.0)
        print("Exploring n=%d (%.0f sec)" % (n2, time_n2))
        a_p5, score_p5 = run_adaptive_fista(a2_start, n2, S2, time_n2 * 0.5, rng,
                                            beta_init=50.0, beta_max=800.0)
        a_p5 = safe_normalize(a_p5, n2)
        c_p5 = fft_convolve_self(a_p5)
        obj_p5 = 2.0 * n2 * c_p5.max() / (S2 * S2)
        if c_p5.max() < global_best:
            global_best = c_p5.max()
            global_a = a_p5.copy()
            global_n = n2
            print("  n=%d improved: %.6f (obj %.6f)" % (n2, global_best, obj_p5))
        else:
            print("  n=%d: %.6f (obj %.6f) - not better" % (n2, c_p5.max(), obj_p5))

    # Phase 6: Final ultra-fine polish
    remaining = deadline - time.monotonic()
    if remaining > 10:
        n = global_n
        S = np.sqrt(2.0 * float(n))
        print("Phase 6: Final polish (%.0f sec)" % remaining)

        # Very fine Adam polish
        t0 = time.monotonic()
        a_f1, _ = run_peak_adam(global_a, n, S, remaining * 0.5, rng, lr_init=0.005)
        a_f1 = safe_normalize(a_f1, n)
        c_f1 = fft_convolve_self(a_f1)
        if c_f1.max() < global_best:
            global_best = c_f1.max()
            global_a = a_f1.copy()
            print("  FineAdam: %.6f (obj %.6f) [%.0fs]" % (global_best, 2*n*global_best/S**2, time.monotonic()-t0))

        remaining2 = deadline - time.monotonic()
        if remaining2 > 5:
            a_f2, _ = run_kkt_polish(global_a, n, S, remaining2, rng)
            a_f2 = safe_normalize(a_f2, n)
            c_f2 = fft_convolve_self(a_f2)
            if c_f2.max() < global_best:
                global_best = c_f2.max()
                global_a = a_f2.copy()
                print("  FineKKT: %.6f (obj %.6f)" % (global_best, 2*n*global_best/S**2))

    # === Final output ===
    n_final = global_n
    final_list = [float(x) for x in np.clip(global_a, 0.0, 1000.0)]
    S_final = np.sqrt(2.0 * float(n_final))
    final_obj = 2.0 * n_final * global_best / (S_final * S_final)
    print("FINAL: length=%d, score=%.6f, objective=%.6f" % (len(final_list), global_best, final_obj))

    # Verify
    ver = evaluate_sequence(final_list)
    if np.isfinite(ver):
        print("Verified: %.6f" % ver)
    else:
        print("Verification failed, using fallback")
        # Fallback: use parent if available
        if parent_a is not None:
            final_list = [float(max(0.0, min(1000.0, x))) for x in parent_a]
            ver2 = evaluate_sequence(final_list)
            print("Fallback parent verified: %.6f" % ver2)
        else:
            final_list = [0.5] * 256

    return final_list
