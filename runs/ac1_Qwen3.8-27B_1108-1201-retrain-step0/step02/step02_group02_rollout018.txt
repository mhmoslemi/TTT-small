def lp_direction(a, M, solver='HiGHS'):
    """
    Solve the LP to find a direction that reduces the peak.
    Maximize sum(b) subject to (a*b)_k <= M for all k, b >= 0.
    """
    n = len(a)
    # Constraint: (a*b)_k = sum_j a_{k-j} * b_j <= M
    # For each k in [0, 2n-2], the constraint is:
    #   sum_{j=max(0,k-n+1)}^{min(k,n-1)} a_{k-j} * b_j <= M
    # 
    # This is a matrix A (size (2n-1) x n) where A[k,j] = a_{k-j} if 0<=k-j<n else 0
    
    # Build constraint matrix
    # A[k, j] = a[k-j] if 0 <= k-j < n else 0
    A = np.zeros((2*n-1, n))
    for j in range(n):
        valid_k = range(max(0, j), min(2*n-1, j+n))
        for k in valid_k:
            A[k, j] = a[k-j]
    
    # Maximize sum(b) = c^T b where c = (1,1,...,1)
    # LP standard form: minimize -c^T b subject to A b <= M, b >= 0
    c_obj = -np.ones(n)
    b_const = np.full(2*n-1, M)
    
    try:
        result = linprog(c_obj, A_ub=A, b_ub=b_const, bounds=[(0, None)]*n, method='highs')
        if result.success:
            return -result.x  # b*
        else:
            return None
    except Exception:
        return None

$(a*a)_k$ is a quadratic function of $a$ (bilinear, actually). So $\max_k (a*a)_k$ is the max of quadratic functions, which is not necessarily convex.

Actually, $(a*a)_k = \sum_j a_j a_{k-j}$ is a quadratic form in $a$. The matrix of this quadratic form has 1's on a specific diagonal pattern. For $k = n-1$, the matrix has 1's at positions $(j, n-1-j)$, which is a "reversal" matrix. This matrix is symmetric and has eigenvalues $\pm 1$ (for odd $n$) or $\pm 1, 0$ (for even $n$). So the quadratic form is NOT positive definite, meaning $(a*a)_{n-1}$ is NOT convex.

So the objective is not convex, and we can't use convex optimization techniques directly. The LP approach is not solving a convex relaxation; it's solving a related but different problem.

This means we need to be more careful about the optimization. The gradient-based approach (with soft-max smoothing) is probably the most reliable.

Let me go back to the gradient-based approach with the following improvements:
1. Better initialization (use the provided sequence)
2. Multiple n values
3. Periodic LP-based "kick" to escape local minima
4. Adaptive temperature for the soft-max
5. Better learning rate schedule

Let me also consider using Hessian information. The Hessian of $(a*a)_k$ is a constant matrix (since it's a quadratic form). So the Hessian of the soft-max is:
$H = 2 \sum_k w_k Q_k + \text{correction terms}$

where $Q_k$ is the matrix of the quadratic form $(a*a)_k$. This is expensive to compute for large $n$, so I'll skip it.

Instead, I'll use Adam, which adapts the learning rate per-coordinate based on the first and second moments of the gradient. This should be effective.

Hybrid LP-guided and gradient-based optimization for minimizing the

Key innovation: periodic LP-based direction computation to escape local minima,

import numpy as np

def fft_convolve(a, b):
    n = len(a)
    m = len(b)
    size = 1
    while size < n + m - 1:
        size <<= 1
    fa = np.fft.rfft(a, size)
    fb = np.fft.rfft(b, size)
    return np.fft.irfft(fa * fb, size)[:n + m - 1]


def local_score(a):
    a = np.clip(a, 0.0, 1000.0)
    n = len(a)
    if n == 0:
        return np.inf
    S = np.sum(a)
    if S < 0.01:
        return np.inf
    c = fft_convolve(a, a)
    return 2.0 * n * np.max(c) / (S * S)


def softmax_normalize(theta):
    t = theta - np.max(theta)
    e = np.exp(t)
    return e / np.sum(e)


def soft_max_value_grad(a, tau):

    c = fft_convolve(a, a)
    c_max = c.max()
    shifted = (c - c_max) / tau
    shifted = np.clip(shifted, -50, 50)
    exp_s = np.exp(shifted)
    sum_exp = exp_s.sum()
    w = exp_s / sum_exp
    value = c_max + tau * np.log(sum_exp)
    
    rev_a = a[::-1]
    corr = fft_convolve(rev_a, w)
    g = 2.0 * corr[n-1:2*n-1]
    
    return value, g, c, w

    n = len(a)

    for j in range(n):
        A[j:j+n, j] = a

    b_const = np.full(2*n-1, M)
    
    try:

                         bounds=[(0, None)]*n, method='highs',
                         options={'time_limit': max_time})
        if result.success and result.x is not None:
            b_star = -result.x
            if b_star.sum() > 1e-10:
                return b_star
    except Exception:
        pass
    return None
