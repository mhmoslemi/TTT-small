So `grad_k[j] = 2 * sum_i B_k[i,j] * a[i] = 2 * a[k-j]` if `0 <= k-j < n`, else 0.

Wait, `sum_i B_k[i,j] * a[i]`: `B_k[i,j] = 1` iff `i+j=k`, so `i=k-j`. This is valid iff `0 <= k-j < n`. So the sum is just `a[k-j]` if valid, else 0.

Therefore: `grad_k[j] = 2 * a[k-j]` if `0 <= k-j < n`, else 0.

At the current point `f`: `grad_k[j] = 2 * f[k-j]` if `0 <= k-j < n`, else 0.

So the linearized constraint `h_k(a) <= M` at point `f` is:
`h_k(f) + grad_k^T (a - f) <= M`
`f*f(k) + 2 * sum_j f[k-j] * (a[j] - f[j]) <= M` (sum over valid j)
`f*f(k) + 2 * sum_j f[k-j] * a[j] - 2 * sum_j f[k-j] * f[j] <= M`
`f*f(k) + 2 * (f*a)(k') - 2 * f*f(k) <= M`

Wait, `sum_j f[k-j] * a[j]` is... this is `(f*a)(k)`? Let me check.

`(f*a)(k) = sum_i f[i] * a[k-i]`. Let `j = k-i`, then `i = k-j`, and `(f*a)(k) = sum_j f[k-j] * a[j]`.

Yes! So `sum_j f[k-j] * a[j] = (f*a)(k)`.

And `sum_j f[k-j] * f[j] = (f*f)(k)`.

So the linearized constraint is:
`f*f(k) + 2*(f*a)(k) - 2*f*f(k) <= M`
`2*(f*a)(k) - f*f(k) <= M`

Interesting! So the linearized LP is:
```
minimize: M
subject to: 2*(f*a)(k) - f*f(k) <= M, for all k
            sum(a) = 1
            a >= 0
```

Or equivalently:
```
minimize: M
subject to: 2*(f*a)(k) <= M + f*f(k), for all k
            sum(a) = 1
            a >= 0
```

This is a LP! And it's a very clean formulation. Let me verify the dimensions:
- Variables: `a[0], ..., a[n-1], M` → n+1 variables
- Constraints: `2n-1` linear inequalities + `sum(a)=1` + `a>=0`

For n=256: 257 variables, ~511+1+256 constraints. Very manageable.

But wait, this is a linearization, so it's only valid locally. We need to iterate:

2. Check if `P(a_new) <= P(f)` (i.e., the actual objective decreased)
3. If not, do a line search: try `a_t = (1-t)*f + t*a_new` for `t in [0,1]`
4. Update `f = a_t*` (best t)
5. Repeat

This is essentially a scheme similar to the one described in the problem statement, but using a cleaner LP formulation.

                a >= 0

    ff = fast_convolve(f)  # length 2n-1

    # (f*a)(k) = sum_j C[k,j] * a[j] where C[k,j] = f[k-j] if valid

    if a_var.value is None:

    s = a_opt.sum()
    if s < 1e-10:

    a_opt /= s
    
    return a_opt, M_var.value

    diff = k_idx - j_idx  # (2n-1, n)

LP-based iterative optimizer for minimizing 2*n*max(conv(a,a))/(sum(a))^2.
Uses linearized LP subproblems with line search, combined with 
coordinate descent and multi-scale initialization.
"""

import numpy as np
import time
import cvxpy as cp
from scipy.optimize import minimize_scalar

def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    result = np.fft.irfft(A * A, fft_size)
    return result[:size]

def objective_from_conv(a, conv):
    """Compute objective given array and its convolution."""
    n = len(a)
    s = np.sum(a)
    if s < 1e-15:
        return float('inf')
    return 2.0 * n * conv.max() / (s * s)

def build_conv_matrix(f):
    """Build matrix C where C[k,j] = f[k-j] if 0<=k-j<n else 0."""
    n = len(f)
    C = np.zeros((2*n-1, n))
    for j in range(n):
        C[j:j+n, j] = f
    return C

def lp_solve(f, M_target, solver=None):
    """
    Solve: minimize M_new
    subject to: 2*(f*a)(k) - f*f(k) <= M_new for all k
                sum(a) = 1, a >= 0
    Returns (a_opt, M_opt) or None.
    """
    n = len(f)
    ff = fast_convolve(f)
    C = build_conv_matrix(f)
    
    a_var = cp.Variable(n)
    M_var = cp.Variable()
    
    constraints = [
        a_var >= 0,
        cp.sum(a_var) == 1,
        2 * C @ a_var - ff <= M_var
    ]
    
    prob = cp.Problem(cp.Minimize(M_var), constraints)
    
    try:
        prob.solve(solver=solver)
    except Exception:
        try:
            prob.solve(solver=cp.SCS)
        except Exception:
            return None
    
    if a_var.value is None or M_var.value is None:
        return None
    
    a_opt = np.maximum(a_var.value, 0.0)
    s = a_opt.sum()
    if s < 1e-10:
        return None
    a_opt /= s
    return a_opt, M_var.value

def line_search(f, direction, max_iter=50):
    """
    Find best t in [0,1] such that P((1-t)*f + t*direction) is minimized.
    """
    n = len(f)
    def f_of_t(t):
        a = (1 - t) * f + t * direction
        a = np.maximum(a, 0)
        s = a.sum()
        if s < 1e-10:
            return float('inf')
        a = a / s
        conv = fast_convolve(a)
        return 2.0 * n * conv.max() / (s * s)
    
    # Try a grid first
    best_t = 0.0
    best_val = f_of_t(0.0)
    for t in np.linspace(0.01, 1.0, 20):
        val = f_of_t(t)
        if val < best_val:
            best_val = val
            best_t = t
    
    # Refine with golden section
    if 0 < best_t < 1:
        lo = max(0, best_t - 0.05)
        hi = min(1, best_t + 0.05)
        result = minimize_scalar(f_of_t, bounds=(lo, hi), method='bounded', options={'xatol': 1e-4})
        if result.fun < best_val:
            best_t = result.x
            best_val = result.fun
    
    return best_t, best_val

def lp_iteration(f, max_iters=200, time_limit=60.0, verbose=False):
    """
    Iterate LP-based optimization.
    """
    n = len(f)
    f = np.maximum(f, 0).copy()
    s = f.sum()
    if s < 1e-12:
        f = np.ones(n) / n
    else:
        f /= s
    
    conv = fast_convolve(f)
    best_obj = 2.0 * n * conv.max()
    best_f = f.copy()
    
    t0 = time.monotonic()
    iter_count = 0
    stagnation = 0
    
    for it in range(max_iters):
        if time.monotonic() - t0 > time_limit:
            break
        
        M = conv.max()
        result = lp_solve(f, M)
        if result is None:
            break
        
        a_dir, M_lp = result
        
        # Line search
        t_best, obj_best = line_search(f, a_dir)
        
        if obj_best < best_obj - 1e-10:
            # Update
            f_new = (1 - t_best) * f + t_best * a_dir
            f_new = np.maximum(f_new, 0)
            s = f_new.sum()
            if s > 1e-10:
                f_new /= s
                f = f_new
                conv = fast_convolve(f)
                cur_obj = 2.0 * n * conv.max()
                if cur_obj < best_obj:
                    best_obj = cur_obj
                    best_f = f.copy()
                stagnation = 0
            else:
                break
        else:
            stagnation += 1
            if stagnation > 20:
                break
        
        iter_count += 1
        if verbose and it % 20 == 0:
            print("    LP iter %d: obj=%.6f, t=%.3f, M_lp=%.6f" % (it, best_obj, t_best, M_lp))
    
    return best_f, best_obj, iter_count

"""
LP-based iterative optimizer for minimizing 2*n*max(conv(a,a))/(sum(a))^2.
Uses linearized LP subproblems (cutting plane style) with line search,
combined with coordinate descent for fine-tuning and multi-scale search.
The LP linearizes the non-convex quadratic constraints around the current point,
giving a valid descent direction when the LP optimum improves on the current peak.
"""

import numpy as np
import time
import cvxpy as cp


def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    result = np.fft.irfft(A * A, fft_size)
    return result[:size]


def cross_convolve(a, b):
    """Linear cross-convolution via FFT."""
    n = len(a)
    m = len(b)
    size = n + m - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    B = np.fft.rfft(b, fft_size)
    result = np.fft.irfft(A * B, fft_size)
    return result[:size]


def build_conv_matrix(f):
    """Build matrix C where C[k,j] = f[k-j] if 0<=k-j<n else 0."""
    n = len(f)
    C = np.zeros((2 * n - 1, n))
    for j in range(n):
        C[j:j + n, j] = f
    return C


def lp_solve(f, ff, C, solver=None):
    """
    Solve: minimize M_new
    subject to: 2*C@a - ff <= M_new
                sum(a) = 1, a >= 0
    Returns (a_opt, M_opt) or None.
    """
    n = len(f)
    a_var = cp.Variable(n)
    M_var = cp.Variable()

    constraints = [
        a_var >= 0,
        cp.sum(a_var) == 1,
        2 * C @ a_var - ff <= M_var
    ]

    prob = cp.Problem(cp.Minimize(M_var), constraints)

    solvers_to_try = [solver, cp.CLARABEL, cp.SCS, cp.ECOS]
    if solver is None:
        solvers_to_try = [cp.CLARABEL, cp.SCS, cp.ECOS]

    last_err = None
    for s in solvers_to_try:
        if s is None:
            continue
        try:
            prob.solve(solver=s, verbose=False)
            if a_var.value is not None:
                break
        except Exception as e:
            last_err = e
            continue

    if a_var.value is None or M_var.value is None:
        return None

    a_opt = np.maximum(a_var.value, 0.0)
    s = a_opt.sum()
    if s < 1e-10:
        return None
    a_opt /= s
    return a_opt, float(M_var.value)


def line_search_precomputed(f, d, conv_f, conv_fd, conv_dd):
    """
    Fast line search along f -> d using precomputed convolutions.
    a(t) = (1-t)*f + t*d, both non-negative so no clamping needed.
    conv(a(t)) = (1-t)^2*conv_f + 2t(1-t)*conv_fd + t^2*conv_dd
    """
    n = len(f)
    sum_f = f.sum()
    sum_d = d.sum()

    def eval_t(t):
        s = (1 - t) * sum_f + t * sum_d
        if s < 1e-15:
            return float('inf')
        conv_t = (1 - t) ** 2 * conv_f + 2 * t * (1 - t) * conv_fd + t ** 2 * conv_dd
        return 2.0 * n * conv_t.max() / (s * s)

    best_t = 0.0
    best_val = eval_t(0.0)

    # Coarse grid
    ts = np.linspace(0.0, 1.0, 30)
    for t in ts:
        val = eval_t(t)
        if val < best_val:
            best_val = val
            best_t = t

    # Refine with bisection on the grid neighborhood
    if 0 < best_t < 1:
        idx = int(best_t * 29)
        lo = ts[max(0, idx - 1)]
        hi = ts[min(29, idx + 1)]
        for _ in range(30):
            mid1 = lo + (hi - lo) / 3.0
            mid2 = hi - (hi - lo) / 3.0
            if eval_t(mid1) < eval_t(mid2):
                hi = mid2
            else:
                lo = mid1
        best_t = (lo + hi) / 2.0
        best_val = eval_t(best_t)

    return best_t, best_val


def lp_iterate(f, time_limit, max_iters=500, verbose=False):
    """
    Main LP-based iteration loop.
    """
    n = len(f)
    f = np.maximum(f, 0.0).copy()
    s = f.sum()
    if s < 1e-12:
        f = np.ones(n) / n
    else:
        f /= s

    conv = fast_convolve(f)
    best_obj = 2.0 * n * conv.max()
    best_f = f.copy()

    t0 = time.monotonic()
    stagnation = 0
    max_stagnation = 30

    for it in range(max_iters):
        if time.monotonic() - t0 > time_limit:
            break

        M = conv.max()
        C = build_conv_matrix(f)
        result = lp_solve(f, conv, C)
        if result is None:
            break

        a_dir, M_lp = result

        # Precompute for fast line search
        conv_fd = cross_convolve(f, a_dir)
        conv_dd = fast_convolve(a_dir)

        t_best, obj_best = line_search_precomputed(f, a_dir, conv, conv_fd, conv_dd)

        if obj_best < best_obj - 1e-12 and t_best > 1e-6:
            f_new = (1 - t_best) * f + t_best * a_dir
            f_new = np.maximum(f_new, 0.0)
            s_new = f_new.sum()
            if s_new > 1e-10:
                f_new /= s_new
                f = f_new
                conv = fast_convolve(f)
                cur_obj = 2.0 * n * conv.max()
                if cur_obj < best_obj:
                    best_obj = cur_obj
                    best_f = f.copy()
                stagnation = 0
            else:
                break
        else:
            stagnation += 1
            if stagnation >= max_stagnation:
                break

        if verbose and it % 50 == 0:
            elapsed = time.monotonic() - t0
            print("    LP iter %d: best_obj=%.8f, elapsed=%.1fs" % (it, best_obj, elapsed))

    return best_f, best_obj


def coordinate_descent(f, time_limit):
    """
    Coordinate descent with O(n) per-coordinate updates.
    """
    n = len(f)
    f = np.maximum(f, 0.0).copy()
    f /= f.sum()
    conv = fast_convolve(f)
    best_obj = 2.0 * n * conv.max()
    best_f = f.copy()

    t0 = time.monotonic()
    sweeps = 0

    while time.monotonic() - t0 < time_limit:
        improved = False
        sweeps += 1

        for j in range(n):
            if time.monotonic() - t0 > time_limit - 0.5:
                break

            old_val = f[j]
            partner = np.zeros(2 * n - 1)
            # partner[k] = contribution coefficient of a[j] in conv(k)
            # conv(k) includes: a[j]*a[k-j] (if valid) + a[k-j]*a[j] (if valid, k-j != j)
            # Total: 2*a[j]*a[k-j] if k != 2j and valid, a[j]^2 if k=2j
            k_range = max(0, j)  # k-j >= 0 => k >= j
            k_end = min(2 * n - 2, j + n - 1)  # k-j <= n-1 => k <= j+n-1

            for k in range(k_range, k_end + 1):
                if k == 2 * j:
                    partner[k] = 2.0 * old_val  # derivative of a[j]^2 w.r.t. a[j]
                else:
                    partner[k] = 2.0 * f[k - j]

            # Try candidates
            candidates = [0.0, 0.25 * old_val, 0.5 * old_val, old_val,
                          1.5 * old_val, 2.0 * old_val, 3.0 * old_val]
            candidates = [c for c in candidates if 0 <= c <= 1.0]

            if old_val > 0:
                candidates.append(old_val * 0.75)
                candidates.append(old_val * 1.25)
                candidates.append(0.0)

            best_c = old_val
            best_c_obj = best_obj  # current

            for c in candidates:
                delta = c - old_val
                if abs(delta) < 1e-12:
                    continue
                # conv_new(k) = conv(k) + delta * partner[k] + delta^2 * I(k=2j)
                if 2 * j < len(conv):
                    conv_candidate = conv.copy()
                    conv_candidate += delta * partner
                    conv_candidate[2 * j] += delta * delta
                    s_new = f.sum() - old_val + c
                    if s_new < 1e-10:
                        continue
                    obj_c = 2.0 * n * conv_candidate.max() / (s_new * s_new)
                    # Normalize: we need conv of (f/s_new)
                    # (f_new/s_new)*(f_new/s_new) has conv = conv_candidate / s_new^2
                    # So max of conv = conv_candidate.max() / s_new^2
                    # And objective = 2n * conv_candidate.max() / s_new^2
                    if obj_c < best_c_obj:
                        best_c_obj = obj_c
                        best_c = c

            if abs(best_c - old_val) > 1e-10:
                f[j] = best_c
                f = f / f.sum()
                conv = fast_convolve(f)
                cur_obj = 2.0 * n * conv.max()
                if cur_obj < best_obj - 1e-12:
                    best_obj = cur_obj
                    best_f = f.copy()
                improved = True

        if not improved:
            break

    return best_f, best_obj


def anneal_local(f, time_limit, rng):
    """
    Informed local search: transfer mass from high-contributing positions
    to low-contributing positions, targeting peak reduction.
    """
    n = len(f)
    f = np.maximum(f, 0.0).copy()
    f /= f.sum()
    conv = fast_convolve(f)
    cur_obj = 2.0 * n * conv.max()
    best_obj = cur_obj
    best_f = f.copy()

    t0 = time.monotonic()

    while time.monotonic() - t0 < time_limit:
        frac = (time.monotonic() - t0) / max(time_limit, 1.0)
        T = 0.005 * (1.0 - frac) ** 2 + 0.0002

        max_c = conv.max()
        if max_c < 1e-15:
            break

        # Find peak positions
        peak_thresh = max_c * 0.8
        peak_positions = np.where(conv >= peak_thresh)[0]
        if len(peak_positions) == 0:
            peak_positions = np.array([np.argmax(conv)])

        # Pick a random peak
        k = int(rng.choice(peak_positions))

        # Find which (i,j) pairs contribute to this peak
        js = max(0, k - n + 1)
        je = min(n - 1, k)
        products = f[js:je + 1] * f[k - je:k - js + 1][::-1]
        total = products.sum()
        if total < 1e-15:
            continue

        probs = products / total
        top_j = js + int(rng.choice(je - js + 1, p=probs))

        # Find a good target (position with low contribution to peaks)
        target_j = int(rng.integers(n))
        for _ in range(8):
            cand = int(rng.integers(n))
            contrib = 0.0
            for pk in peak_positions[:5]:
                d1 = pk - cand
                if 0 <= d1 < n:
                    contrib += f[d1]
                d2 = cand + n - 1 - pk
                if 0 <= d2 < n:
                    contrib += f[d2]
            if contrib < f.mean():
                target_j = cand
                break

        if target_j == top_j:
            continue

        delta = f[top_j] * rng.uniform(0.02, 0.08)
        if delta < 1e-9:
            continue

        f[top_j] -= delta
        f[target_j] += delta
        if f[top_j] < 0:
            f[top_j] += delta
            f[target_j] -= delta
            continue

        new_conv = fast_convolve(f)
        new_obj = 2.0 * n * new_conv.max()
        delta_obj = new_obj - cur_obj

        if delta_obj < 0:
            cur_obj = new_obj
            conv = new_conv
            if cur_obj < best_obj:
                best_obj = cur_obj
                best_f = f.copy()
        else:
            if rng.random() < np.exp(-delta_obj / max(T, 1e-12)):
                cur_obj = new_obj
                conv = new_conv
            else:
                f[top_j] += delta
                f[target_j] -= delta

    return best_f, best_obj


def generate_initializations(n, rng, parent=None):
    """Generate diverse initializations."""
    x = np.arange(n, dtype=np.float64)
    inits = []

    # Uniform
    inits.append(('uniform', np.ones(n) / n))

    # Gaussian
    for sigma in [0.15, 0.25, 0.35]:
        g = np.exp(-0.5 * ((x - n * 0.5) / (sigma * n)) ** 2)
        g /= g.sum()
        inits.append(('gauss_%s' % sigma, g))

    # Cosine/sine
    for freq in [1, 2, 3, 5]:
        s = 0.5 * (1.0 + np.cos(2.0 * np.pi * freq * x / n))
        s /= s.sum()
        inits.append(('cos_%d' % freq, s))

    # Bimodal
    bi = np.zeros(n)
    w = max(1, n // 5)
    bi[:w] = 1.0
    bi[-w:] = 1.0
    bi /= bi.sum()
    inits.append(('bimodal', bi))

    # Ramp
    ramp = np.arange(1, n + 1, dtype=np.float64)
    ramp /= ramp.sum()
    inits.append(('ramp', ramp))

    # Random Dirichlet
    for alpha in [0.5, 1.0, 2.0, 5.0]:
        r = rng.dirichlet(np.ones(n) * alpha)
        inits.append(('dir_%s' % alpha, r))

    # Chirp
    chirp = 0.5 * (1.0 + np.cos(2.0 * np.pi * x * x / (2.0 * n)))
    chirp = np.maximum(chirp, 0.0)
    if chirp.sum() > 1e-10:
        chirp /= chirp.sum()
        inits.append(('chirp', chirp))

    # Walsh-like
    walsh = np.ones(n)
    for i in range(n):
        bit = (i >> (n.bit_length() - 1)) & 1
        if bit:
            walsh[i] = 0.3
    walsh /= walsh.sum()
    inits.append(('walsh', walsh))

    # Parent interpolation
    if parent is not None:
        if parent.size >= n:
            pp = np.maximum(parent[:n], 0.0).copy()
            if pp.sum() > 1e-10:
                pp /= pp.sum()
                inits.append(('parent', pp))
        else:
            pp = np.interp(np.linspace(0, 1, n),
                           np.linspace(0, 1, parent.size),
                           np.maximum(parent, 0))
            pp = np.maximum(pp, 0)
            if pp.sum() > 1e-10:
                pp /= pp.sum()
                inits.append(('parent_interp', pp))

    return inits

        a_cur = a0.copy()
        sub_budget = t_alloc / 4.0

        a_cur, _ = lp_iterate(a_cur, time_limit=sub_budget)
        record(a_cur)

        a_cur, _ = lp_iterate(a_cur, time_limit=sub_budget)
        record(a_cur)

        # Coordinate descent
        rem = deadline - time.monotonic() - 600
        if rem > 5:
            cd_budget = min(sub_budget, rem * 0.3)
            a_cur, _ = coordinate_descent(a_cur, time_limit=cd_budget)
            record(a_cur)

        # More LP
        rem = deadline - time.monotonic() - 600
        if rem > 5:
            a_cur, _ = lp_iterate(a_cur, time_limit=min(sub_budget, rem))
            record(a_cur)

    print("  Deep LP done. Best so far: %.6f" % best_score)

    # Phase 3: Local search / annealing
    print("\n=== Phase 3: Local search ===")
    if best_sequence is not None and time.monotonic() < deadline - 100:
        phase3_budget = min(400.0, deadline - time.monotonic() - 100)
        n_anneal = 3
        anneal_per = phase3_budget / n_anneal

        for i in range(n_anneal):
            if time.monotonic() > deadline - 100:
                break
            a_start = best_sequence.copy()
            a_start = np.maximum(a_start, 0.0)
            a_start /= a_start.sum()
            rng_a = np.random.default_rng(seed + 7000 + i * 111)
            a_opt, _ = anneal_local(a_start, time_limit=anneal_per, rng=rng_a)
            record(a_opt)

            # Follow up with LP
            if time.monotonic() < deadline - 100:
                a_opt, _ = lp_iterate(a_opt, time_limit=min(30.0, (deadline - time.monotonic() - 100) * 0.5))
                record(a_opt)

        print("  Local search done. Best so far: %.6f" % best_score)

    # Phase 4: Try to improve with larger dimension or different approach
    print("\n=== Phase 4: Exploration ===")
    if time.monotonic() < deadline - 60:
        # Try upsampling the best solution
        if best_sequence is not None:
            n_orig = len(best_sequence)
            for n_new in [n_orig * 2, n_orig + 64, n_orig + 128]:
                if time.monotonic() > deadline - 60:
                    break
                if n_new > 2048:
                    continue

                # Upsample by linear interpolation
                x_old = np.linspace(0, 1, n_orig)
                x_new = np.linspace(0, 1, n_new)
                a_up = np.interp(x_new, x_old, best_sequence)
                a_up = np.maximum(a_up, 0.0)
                a_up /= a_up.sum()

                t_alloc = min(120.0, deadline - time.monotonic() - 60)
                a_opt, _ = lp_iterate(a_up, time_limit=t_alloc)
                record(a_opt)

                if time.monotonic() < deadline - 60:
                    a_opt, _ = coordinate_descent(a_opt, time_limit=min(30.0, deadline - time.monotonic() - 60))
                    record(a_opt)

        # Try fresh random starts at the best dimension
        if best_sequence is not None:
            n_best = len(best_sequence)
            for trial in range(3):
                if time.monotonic() > deadline - 60:
                    break
                a_rand = rng.dirichlet(np.ones(n_best) * 0.8)
                t_alloc = min(60.0, deadline - time.monotonic() - 60)
                if t_alloc < 10:
                    break
                a_opt, _ = lp_iterate(a_rand, time_limit=t_alloc)
                record(a_opt)

    # Phase 5: Final polish
    print("\n=== Phase 5: Final polish ===")
    if best_sequence is not None and time.monotonic() < deadline - 5:
        a_best = best_sequence.copy()
        a_best = np.maximum(a_best, 0.0)
        a_best /= a_best.sum()

        # LP with long time
        rem = deadline - time.monotonic() - 5
        if rem > 10:
            a_opt, _ = lp_iterate(a_best, time_limit=rem * 0.4, max_iters=2000)
            record(a_opt)

        # Coordinate descent
        if time.monotonic() < deadline - 5:
            rem = deadline - time.monotonic() - 5
            if rem > 5:
                a_opt, _ = coordinate_descent(a_best, time_limit=rem * 0.5)
                record(a_opt)

        # Anneal
        if time.monotonic() < deadline - 5:
            rem = deadline - time.monotonic() - 5
            if rem > 3:
                rng_f = np.random.default_rng(seed + 99999)
                a_opt, _ = anneal_local(a_best, time_limit=rem * 0.8, rng=rng_f)
                record(a_opt)

    # Fallback
    if best_sequence is None:
        best_sequence = np.ones(128)
        best_score = safe_evaluate(best_sequence)

    elapsed = time.monotonic() - t_start
    print("\n=== FINAL ===")
    print("Time used: %.1fs / %.1fs" % (elapsed, budget_s))
    print("FINAL SCORE: %.8f" % best_score)
    print("Sequence length: %d" % len(best_sequence))

    return [float(x) for x in best_sequence]
