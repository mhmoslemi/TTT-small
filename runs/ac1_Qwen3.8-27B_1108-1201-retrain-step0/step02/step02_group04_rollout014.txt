Actually, let me think about the theoretical minimum more carefully.

The minimum of `max_k c[k]` subject to `sum(a) = 1`, `a >= 0`, where `c = conv(a,a)`.

We know `sum_k c[k] = 1` and there are `2n-1` values. So `max_k c[k] >= 1/(2n-1)`.

This gives `score >= 2n/(2n-1) ≈ 1 + 1/(2n-1)`.

For n=256, this lower bound is `512/511 ≈ 1.002`. But this is very optimistic; in practice, the constraint `c[k] = conv(a,a)[k]` is very restrictive.

A better lower bound: consider that `c[0] = sum a[i]^2 >= (sum a)^2/n = 1/n` (by Cauchy-Schwarz).
And `c[n-1] = sum a[i]*a[n-1-i]`. By the rearrangement inequality, this is at least `sum (a[i]^2)/n = 1/n` (when a is symmetric). But it can be less if a is asymmetric.

Actually, for non-negative `a`, `c[n-1] = sum a[i]*a[n-1-i] >= 0`, with equality when `a[i] = 0` whenever `a[n-1-i] > 0` (i.e., `a` is supported on at most one of each pair `{i, n-1-i}`).

So the best case for `c[n-1]` is 0 (when `a` is supported on, say, the first half). But then `c[0] = sum a[i]^2` for `i` in the first half, which is at least `(sum a)^2 / (n/2) = 2/n`.

So `max(c[0], c[n-1]) >= max(2/n, 0) = 2/n` in this case.

For uniform, `max = 1/n`. So we're looking for sequences where `max(c[0], c[n-1], ..., c[2n-2]) < 1/n`.

```python
import numpy as np
from scipy.optimize import linprog
from scipy.fft import rfft, irfft
import time

def fft_convolve(a, b):
    n = len(a)
    m = len(b)
    size = 1
    while size < n + m - 1:
        size <<= 1
    fa = rfft(a, size)
    fb = rfft(b, size)
    return irfft(fa * fb, size)[:n + m - 1]

def compute_score(a):
    a = np.clip(a, 0, 1000)
    n = len(a)
    s = np.sum(a)
    if s < 0.01:
        return np.inf
    c = fft_convolve(a, a)
    return 2.0 * n * np.max(c) / (s * s)

def solve_lp(f, M):
    n = len(f)
    # Build constraint matrix A: A[k, i] = f[i] if 0 <= k-i < n, else 0
    A = np.zeros((2*n-1, n))
    for i in range(n):
        for k in range(i, i+n):
            A[k, i] = f[i]
    c_obj = -np.ones(n)
    b_ub = np.full(2*n-1, M)
    bounds = [(0, None)] * n
    res = linprog(c_obj, A_ub=A, b_ub=b_ub, bounds=bounds, method='highs')
    if res.success:
        return res.x
    return None

def lp_iteration(a, f_current, M, rng):
    n = len(a)
    g = solve_lp(f_current, M)
    if g is None or np.sum(g) < 1e-10:
        return a, compute_score(a)
    # Rescale g to have same sum as a
    sum_g = np.sum(g)
    sum_a = np.sum(a)
    g = g * sum_a / sum_g
    # Binary search for best t
    best_t = 0
    best_score = compute_score(a)
    for t in [0.5, 0.25, 0.75, 0.125, 0.375, 0.625]:
        candidate = (1-t)*a + t*g
        candidate = np.clip(candidate, 0, 1000)
        s = compute_score(candidate)
        if s < best_score:
            best_score = s
            best_t = t
    if best_t > 0:
        a = (1-best_t)*a + best_t*g
        a = np.clip(a, 0, 1000)
    return a, compute_score(a)
