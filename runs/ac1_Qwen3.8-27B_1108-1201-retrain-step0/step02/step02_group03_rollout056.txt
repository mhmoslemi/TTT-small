      - Clip to non-negative: a_new = max(a_new, 0)
      - Rescale: a_new = a_new * S / sum(a_new)
3. Use adaptive step size (e.g., backtracking line search).

The advantage of this approach is simplicity and the ability to use large steps when the gradient is well-conditioned.

But the projection step (clip + rescale) might cause issues. A better approach might be to use a log-barrier or a different constraint handling method.

Let me think about yet another approach:

**Approach: Coordinate descent / Block coordinate descent**

Instead of updating all elements simultaneously, update blocks of elements. This can be more effective for non-convex problems.

For each block B of indices:
- Fix all elements outside B.
- Optimize the elements inside B to minimize the soft-max of the convolution.
- This is a lower-dimensional subproblem that can be solved more accurately.

The challenge is that the convolution couples all elements, so the subproblem is still complex. But for small blocks, we can use Newton's method or a similar approach.

Actually, I think the most promising approach is a combination of:
1. Good initialization (FFT-based)
2. Gradient descent with the correct gradient (or the 1/tau adjusted version)
3. Adaptive annealing of tau
4. Multiple restarts
5. Local polish with a different method

Let me also consider the **dual problem**. The Lagrangian dual of:
min max_k conv[k] subject to sum(a) = S, a >= 0

is:
max_{lambda >= 0, sum lambda = 1} min_{sum(a)=S, a>=0} sum_k lambda_k * conv[k] - S * nu

where the inner minimization is a quadratic program (since conv is quadratic in a).

Actually, this is getting complicated. Let me just focus on making the gradient descent approach work better.

**Key improvements I'll implement:**

1. **Correct gradient**: Use the true gradient (without the 1/tau factor) and adjust the learning rate to compensate.

2. **Adaptive tau**: Set tau based on the spread of the convolution values. Specifically, tau = (max(conv) - percentile(conv, 90)) / log(10) so that the top 10% of values have roughly equal weight.

3. **Better initialization**: Use the FFT phase method but with more iterations and different starting points.

4. **Multi-scale approach**: Start with a small n, optimize, then upsample and re-optimize.

5. **Post-optimization local search**: Use a simple coordinate descent or coordinate perturbation to polish the result.

6. **Try larger n**: The theoretical lower bound improves with n, so larger n might give better scores.

"""
Optimized step function search using gradient descent with correct gradient,
adaptive soft-max temperature, FFT-based initialization, and multi-scale refinement.
"""

import numpy as np
import time


def fft_convolve(a, b):
    """Compute linear convolution using FFT."""
    n = len(a)
    m = len(b)
    size = 1
    while size < n + m - 1:
        size <<= 1
    fa = np.fft.rfft(a, size)
    fb = np.fft.rfft(b, size)
    return np.fft.irfft(fa * fb, size)[:n + m - 1]


def local_score(a):
    """Compute the evaluation score for a sequence."""
    n = len(a)
    if n == 0:
        return np.inf
    sum_a = np.sum(a)
    if sum_a < 1e-10:
        return np.inf
    c = fft_convolve(a, a)
    return 2.0 * n * np.max(c) / (sum_a ** 2)


def softmax_normalize(theta):
    """Stable softmax."""
    t = theta - np.max(theta)
    e = np.exp(t)
    s = np.sum(e)
    return e / s


def compute_gradient(a, tau):
    """
    Compute the soft-max of conv(a,a) and its gradient w.r.t. a.
    Returns (value, gradient, conv).
    """
    n = len(a)
    c = fft_convolve(a, a)
    
    # Soft-max weights
    c_max = np.max(c)
    shifted = (c - c_max) / tau
    e = np.exp(shifted)
    s = np.sum(e)
    w = e / s
    value = c_max + tau * np.log(s)
    
    # Gradient: g[j] = 2 * sum_k w[k] * a[k-j] * [0 <= k-j < n]
    # = 2 * (rev(a) * w)[n-1 : 2n-1]
    a_rev = a[::-1]
    corr = fft_convolve(a_rev, w)
    g = 2.0 * corr[n-1 : 2*n-1]
    
    return value, g, c


def fft_phase_init(n, rng, n_iter=100):
    """Gerchberg-Saxton style initialization."""
    N = 2 * n - 1
    N_fft = 1
    while N_fft < N:
        N_fft <<= 1
    
    a = np.ones(n) / n
    for it in range(n_iter):
        A = np.fft.fft(a, N_fft)
        mag = np.abs(A)
        mag[mag < 1e-12] = 1e-12
        phase = A / mag
        a_full = np.fft.ifft(phase).real
        a = np.clip(a_full[:n], 0.0, None)
        s = np.sum(a)
        if s < 1e-10:
            a = np.ones(n) / n
        else:
            a = a / s
    return a


def upsample(a, new_n, rng):
    """Upsample a sequence to a longer length."""
    n = len(a)
    if new_n == n:
        return a.copy()
    x_old = np.linspace(0, 1, n)
    x_new = np.linspace(0, 1, new_n)
    a_interp = np.interp(x_new, x_old, a)
    a_interp += 0.01 * rng.standard_normal(new_n)
    a_interp = np.clip(a_interp, 0.001, None)
    return a_interp / np.sum(a_interp)


def optimize_direct(a_init, time_limit, rng, tau_init=None, tau_min=None):
    """
    Direct gradient descent on a (non-negative, normalized) with projected gradient.
    Uses adaptive tau and backtracking line search.
    """
    n = len(a_init)
    S = np.sqrt(2.0 * n)
    a = a_init.copy()
    a = a / np.sum(a) * S
    
    if tau_init is None:
        tau_init = 10.0 / n * S * S  # Scale with the problem
    if tau_min is None:
        tau_min = 0.1 / n * S * S
    
    # Compute initial tau based on conv spread
    c0 = fft_convolve(a, a)
    c_sorted = np.sort(c0)
    # tau such that top 20% have similar weight
    tau_init = max((c_sorted[-1] - c_sorted[int(0.8*len(c_sorted))]) / np.log(5), 1e-6 * S)
    
    best_a = a.copy()
    best_score = local_score(a)
    t0 = time.monotonic()
    
    # Adam optimizer on a directly (with projection)
    m = np.zeros(n)
    v = np.zeros(n)
    b1, b2, eps = 0.9, 0.999, 1e-8
    step = 0
    lr = 0.5  # Initial learning rate (will be scaled)
    
    while time.monotonic() - t0 < time_limit:
        elapsed = time.monotonic() - t0
        frac = min(1.0, elapsed / time_limit)
        
        # Adaptive tau: anneal from tau_init to tau_min
        tau = tau_init * (tau_min / tau_init) ** (frac ** 0.7)
        
        value, g, c = compute_gradient(a, tau)
        
        # Normalized gradient (scale-invariant direction)
        g_norm = np.linalg.norm(g)
        if g_norm < 1e-15:
            break
        g_norm = g / g_norm
        
        step += 1
        m = b1 * m + (1 - b1) * g_norm
        v = b2 * v + (1 - b2) * (g_norm ** 2)
        m_hat = m / (1 - b1 ** step)
        v_hat = v / (1 - b2 ** step)
        
        # Adaptive learning rate
        lr_adapt = lr / (1 + 0.1 * step)
        
        a_new = a - lr_adapt * m_hat / (np.sqrt(v_hat) + eps)
        
        # Project: clip to non-negative, renormalize
        a_new = np.clip(a_new, 0.0, None)
        s = np.sum(a_new)
        if s < 1e-10:
            a_new = a
        else:
            a_new = a_new / s * S
        
        # Check improvement
        new_score = local_score(a_new)
        if new_score < best_score:
            best_score = new_score
            best_a = a_new.copy()
        
        # Backtracking: if score worsened too much, take a smaller step
        if new_score > local_score(a) * 1.5:
            # Try a smaller step
            a_new = a - 0.1 * lr_adapt * m_hat / (np.sqrt(v_hat) + eps)
            a_new = np.clip(a_new, 0.0, None)
            s = np.sum(a_new)
            if s < 1e-10:
                a_new = a
            else:
                a_new = a_new / s * S
        
        a = a_new
        
        if step % 200 == 0:
            score = local_score(a)
            print(f"      step={step}, score={score:.6f}, best={best_score:.6f}, tau={tau:.2e}, t={elapsed:.1f}s")
    
    final_score = local_score(best_a)
    return best_a, min(best_score, final_score)


def optimize_softmax_param(theta_init, S, time_limit, rng, tau_init=None, tau_min=None):
    """
    Gradient descent on softmax-parameterized sequence.
    theta -> a = softmax(theta) * S
    """
    n = len(theta_init)
    theta = theta_init.copy()
    
    if tau_init is None:
        tau_init = 20.0 / n
    if tau_min is None:
        tau_min = 0.2 / n
    
    best_theta = theta.copy()
    a = softmax_normalize(theta) * S
    best_score = local_score(a)
    t0 = time.monotonic()
    
    m = np.zeros(n)
    v = np.zeros(n)
    b1, b2, eps = 0.85, 0.999, 1e-8
    step = 0
    lr0 = 1.0
    
    while time.monotonic() - t0 < time_limit:
        elapsed = time.monotonic() - t0
        frac = min(1.0, elapsed / time_limit)
        tau = tau_init * (tau_min / tau_init) ** (frac ** 0.6)
        
        a = softmax_normalize(theta) * S
        value, g_a, c = compute_gradient(a, tau)
        
        # Chain rule: d(soft_max)/d(theta) = a * (g_a - dot(a, g_a) / S)
        # (because da/dtheta = a * (I - a^T * 1 / S) approximately for softmax)
        inner = np.dot(a, g_a) / S
        g_theta = a * (g_a - inner)
        
        step += 1
        m = b1 * m + (1 - b1) * g_theta
        v = b2 * v + (1 - b2) * (g_theta ** 2)
        m_hat = m / (1 - b1 ** step)
        v_hat = v / (1 - b2 ** step)
        
        lr = lr0 / np.sqrt(1 + 0.3 * step)
        theta = theta - lr * m_hat / (np.sqrt(v_hat) + eps)
        
        if step % 300 == 0:
            a_check = softmax_normalize(theta) * S
            score = local_score(a_check)
            if score < best_score:
                best_score = score
                best_theta = theta.copy()
            if step % 1500 == 0:
                print(f"      step={step}, score={score:.6f}, best={best_score:.6f}, tau={tau:.2e}, t={elapsed:.1f}s")
    
    a_final = softmax_normalize(best_theta) * S
    score_final = local_score(a_final)
    if score_final < best_score:
        best_score = score_final
    return a_final, best_score


def coordinate_descent_polish(a_init, time_limit, rng, n_iter_per_coord=3):
    """
    Coordinate descent: optimize each coordinate (or small group of coordinates) 
    to reduce the max convolution value.
    """
    n = len(a_init)
    a = a_init.astype(np.float64).copy()
    S = np.sum(a)
    best = a.copy()
    best_score = local_score(a)
    t0 = time.monotonic()
    
    # Precompute: for each coordinate j, the contribution to conv
    # conv[k] = sum_i a[i]*a[k-i]
    # d(conv[k])/d(a[j]) = 2*a[k-j] (if valid)
    # To minimize max conv, we want to reduce a[j] where it contributes to peaks,
    # and increase where it doesn't.
    
    order = rng.permutation(n)
    it = 0
    
    while time.monotonic() - t0 < time_limit:
        j = order[it % n]
        it += 1
        
        # Compute the current conv
        conv = fft_convolve(a, a)
        max_conv = np.max(conv)
        
        # The gradient at coordinate j:
        # g[j] = 2 * sum_k w[k] * a[k-j]
        # For simplicity, use the max contrib:
        # a[j] contributes to conv[k] for all k, with value 2*a[j]*a[k-j]
        # To reduce max_conv, we should reduce a[j] if it contributes to the peak.
        
        # Simple approach: try increasing and decreasing a[j]
        old_val = a[j]
        
        # Try a few values
        for factor in [0.5, 0.7, 0.9, 1.1, 1.3, 1.5]:
            a_trial = a.copy()
            a_trial[j] = old_val * factor
            a_trial = np.clip(a_trial, 0, None)
            a_trial = a_trial / np.sum(a_trial) * S
            score = local_score(a_trial)
            if score < best_score:
                best_score = score
                best = a_trial.copy()
                a = a_trial
        
    return best, best_score


def peak_reduction(a_init, time_limit, rng):
    """
    Targeted peak reduction: identify the top peaks in the convolution and
    find which coordinates contribute most to them, then reduce those coordinates.
    """
    n = len(a_init)
    a = a_init.astype(np.float64).copy()
    S = np.sum(a)
    best = a.copy()
    best_score = local_score(a)
    t0 = time.monotonic()
    it = 0
    
    while time.monotonic() - t0 < time_limit:
        it += 1
        conv = fft_convolve(a, a)
        
        # Find top K peaks
        K = min(5, len(conv))
        top_indices = np.argsort(conv)[-K:]
        
        # For each peak, find the coordinates that contribute most
        contrib = np.zeros(n)
        for k in top_indices:
            for j in range(n):
                # a[j] contributes a[j]*a[k-j] to conv[k] (if valid)
                km = k - j
                if 0 <= km < n:
                    contrib[j] += a[j] * a[km]
        
        # Reduce the top contributors, increase the bottom ones
        n_reduce = max(2, n // 20)
        top_j = np.argsort(contrib)[-n_reduce:]
        bot_j = np.argsort(contrib)[:n_reduce]
        
        # Random scaling
        a[top_j] *= np.exp(rng.normal(-0.05, 0.02, size=len(top_j)))
        a[bot_j] *= np.exp(rng.normal(0.05, 0.02, size=len(bot_j)))
        
        a = np.clip(a, 0, None)
        s = np.sum(a)
        if s < 1e-10:
            a = best.copy()
        else:
            a = a / s * S
        
        score = local_score(a)
        if score < best_score:
            best_score = score
            best = a.copy()
    
    return best, best_score

The main issue is that gradient descent with soft-max can get stuck. The landscape is non-convex, and the soft-max approximation might not guide us well enough when tau is small.

Let me think about a fundamentally different approach:

**Approach: Spectral method with iterative refinement**

"""

import numpy as np
import time


def fft_convolve(a, b):
    """Compute linear convolution using FFT."""
    n = len(a)
    m = len(b)
    size = 1
    while size < n + m - 1:
        size <<= 1
    fa = np.fft.rfft(a, size)
    fb = np.fft.rfft(b, size)
    return np.fft.irfft(fa * fb, size)[:n + m - 1]


def local_score(a):
    """Compute the evaluation score for a sequence."""
    n = len(a)
    if n == 0:
        return np.inf
    sum_a = np.sum(a)
    if sum_a < 1e-10:
        return np.inf
    c = fft_convolve(a, a)
    return 2.0 * n * np.max(c) / (sum_a ** 2)


def softmax_normalize(theta):
    """Stable softmax."""
    t = theta - np.max(theta)
    e = np.exp(t)
    s = np.sum(e)
    return e / s


def compute_soft_max_grad(a, tau):
    """
    Compute soft-max of conv(a,a) and its gradient w.r.t. a.
    Returns (value, gradient, convolution).
    The gradient is the true gradient (no 1/tau factor).
    """
    n = len(a)
    c = fft_convolve(a, a)

    c_max = np.max(c)
    shifted = (c - c_max) / tau
    e = np.exp(shifted)
    s = np.sum(e)
    w = e / s
    value = c_max + tau * np.log(s)

    # grad[j] = 2 * sum_k w[k] * a[k-j] for 0<=k-j<n
    # = 2 * (rev(a) * w)[n-1 : 2n-1]
    a_rev = a[::-1]
    corr = fft_convolve(a_rev, w)
    g = 2.0 * corr[n - 1:2 * n - 1]

    return value, g, c


def fft_phase_init(n, rng, n_iter=100):
    """Gerchberg-Saxton style: flatten magnitude spectrum."""
    N = 2 * n - 1
    N_fft = 1
    while N_fft < N:
        N_fft <<= 1

    a = np.ones(n) / n
    for it in range(n_iter):
        A = np.fft.fft(a, N_fft)
        mag = np.abs(A)
        mag[mag < 1e-12] = 1e-12
        phase = A / mag
        a_full = np.fft.ifft(phase).real
        a = np.clip(a_full[:n], 0.0, None)
        s = np.sum(a)
        if s < 1e-10:
            a = np.ones(n) / n
        else:
            a = a / s
    return a

def upsample(a, new_n, rng):
    """Upsample a sequence to a longer length via interpolation + noise."""
    n = len(a)
    if new_n == n:
        return a.copy()
    x_old = np.linspace(0, 1, n)
    x_new = np.linspace(0, 1, new_n)
    a_interp = np.interp(x_new, x_old, a)
    a_interp += 0.015 * rng.standard_normal(new_n)
    a_interp = np.clip(a_interp, 0.001, None)
    return a_interp / np.sum(a_interp)

def optimize_direct(a_init, time_limit, rng, tau_init=None, tau_min=None):

    Uses backtracking and adaptive tau.

        c0 = fft_convolve(a, a)
        c_sorted = np.sort(c0)
        tau_init = max((c_sorted[-1] - c_sorted[int(0.85 * len(c_sorted))]) / np.log(4.0), 0.1 / n)
    if tau_min is None:
        tau_min = tau_init / 150.0

    best_a = a.copy()
    best_score = local_score(a)
    t0 = time.monotonic()

    m = np.zeros(n)
    v = np.zeros(n)
    b1, b2, eps = 0.9, 0.999, 1e-8
    step = 0
    base_lr = 0.3

    while time.monotonic() - t0 < time_limit:
        elapsed = time.monotonic() - t0
        frac = min(1.0, elapsed / time_limit)
        tau = tau_init * (tau_min / tau_init) ** (frac ** 0.5)

        value, g, c = compute_soft_max_grad(a, tau)

        # Normalize gradient for stability
        g_norm = np.linalg.norm(g)
        if g_norm < 1e-15:
            break
        g_unit = g / g_norm

        step += 1
        m = b1 * m + (1 - b1) * g_unit
        v = b2 * v + (1 - b2) * (g_unit ** 2)
        m_hat = m / (1.0 - b1 ** step)
        v_hat = v / (1.0 - b2 ** step)

        lr = base_lr / (1.0 + 0.1 * step) ** 0.5
        a_new = a - lr * m_hat / (np.sqrt(v_hat) + eps)

        # Project: non-negative + normalize
        a_new = np.clip(a_new, 0.0, None)
        s = np.sum(a_new)
        if s < 1e-10:
            a_new = a.copy()
        else:
            a_new = a_new / s * S

        new_score = local_score(a_new)
        current_score = local_score(a)

        if new_score < best_score:
            best_score = new_score
            best_a = a_new.copy()

        # Accept if not too bad
        if new_score < current_score * 1.3:
            a = a_new
        else:
            # Shrink step
            a_new = a - 0.1 * lr * m_hat / (np.sqrt(v_hat) + eps)
            a_new = np.clip(a_new, 0.0, None)
            s = np.sum(a_new)
            if s < 1e-10:
                a_new = a.copy()
            else:
                a_new = a_new / s * S
            a = a_new

        if step % 300 == 0:
            score = local_score(a)
            print(f"      step={step}, score={score:.6f}, best={best_score:.6f}, "
                  f"tau={tau:.2e}, t={elapsed:.1f}s")

    final_score = local_score(best_a)
    return best_a.copy(), min(best_score, final_score)

            top_lags = np.argsort(conv)[-n_top:]

            contrib = np.zeros(n)
            for lag in top_lags:
                for j in range(n):
                    km = lag - j
                    if 0 <= km < n:
                        contrib[j] += a[j] * a[km]

            n_reduce = max(3, n // 15)
            top_idx = np.argsort(contrib)[-n_reduce:]
            bot_idx = np.argsort(contrib)[:n_reduce]
            a[top_idx] *= np.exp(rng.normal(-0.04, 0.015, size=len(top_idx)))
            a[bot_idx] *= np.exp(rng.normal(0.04, 0.015, size=len(bot_idx)))

        elif r < 0.6:
            # Block perturbation
            n_blocks = int(rng.integers(2, 5))
            for _ in range(n_blocks):
                bw = max(1, int(rng.integers(1, max(2, n // 20))))
                bs = int(rng.integers(0, n - bw))
                a[bs:bs + bw] *= np.exp(rng.normal(0.0, 0.04, size=bw))

        elif r < 0.75:
            # Symmetry nudge
            sym = 0.5 * (a + a[::-1])
            a = a + 0.1 * (sym - a) + 0.005 * rng.standard_normal(n)

        elif r < 0.9:
            # Endpoint emphasis (U-shape reinforcement)
            half = n // 4
            a[:half] *= np.exp(rng.normal(0.02, 0.01, size=half))
            a[-half:] *= np.exp(rng.normal(0.02, 0.01, size=half))
            mid_start = n // 2 - half // 2
            mid_end = n // 2 + half // 2
            a[mid_start:mid_end] *= np.exp(rng.normal(-0.02, 0.01, size=mid_end - mid_start))

        else:
            # Global noise
            a = a * np.exp(rng.normal(0.0, 0.01, size=n))

        a = np.clip(a, 0.0, None)
        s = np.sum(a)
        if s < 1e-10:
            a = best.copy()
        else:
            a = a / s * S

        new_score = local_score(a)
        if new_score < best_score:
            best_score = new_score
            best = a.copy()
        else:
            delta = new_score - local_score(a)
            if delta < temp * 5:
                if rng.random() < np.exp(-max(delta, 0) / max(temp, 1e-12)):
                    pass  # stay (a is already updated)

        temp *= cooling

    return best.copy(), best_score
