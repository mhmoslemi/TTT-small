The problem is equivalent to: minimize max_k c[k] subject to a >= 0, sum(a) = 1.

This can be formulated as: find the minimum t such that there exists a >= 0, sum(a) = 1, and c[k] <= t for all k.

- sum(a) = 1
- For each k: sum_{i} a[i]*a[k-i] <= t

The constraints are quadratic in a, so this is a feasibility problem with quadratic constraints. It's NP-hard in general, but for large n, we can use relaxation or iterative methods.

**Approach: Iterative "peak shaving" with spectral projection**

1. Start with a good initial guess (e.g., the provided sequence or a ramp).
2. Iteratively:
   a. Compute c = conv(a, a)
   b. Identify the peak position k*
