Approach and Rationale

Our approach is to use a combination of gradient-based optimization and random sampling to search for a sequence of non-negative coefficients that minimizes the evaluation function. The evaluation function is defined as `2 * n * max(conv(a, a)) / (sum(a))^2`, where `conv(a, a)` is the full linear convolution. The goal is to achieve a score below the previous record of 1.512372.

Given the homogeneous nature of the evaluation function, we can fix the sum of the sequence to a manageable value (e.g., `sum(a) = sqrt(2 * n)` from the previous program) to simplify the optimization problem. This normalization converts the objective into `n * max(conv(a, a))`, which is positive and scale-invariant.

The standard approach from the previous program was to start with a uniform sequence (normalized), then repeatedly improve it by solving a linear program and taking a convex combination. We extend this by auditing the initial candidate and using gradient descent to break the 1.512 barrier.

The algorithm will use:
- Initialization: If a parent sequence exists, clip and normalize it and a few random copies, but avoid direct gradient descent on the parent if not normalized optimally.
- Optimization: Use gradient descent (analytical) as implemented in the previous `optimize_lm_style` function, but with adjusted hyperparameters and more thorough exploration.
- Validation: Re-evaluate new candidates strictly according to the evaluator's function to avoid surrogate errors.

We set the sum to `sqrt(2 * n)` for consistency with the theoretical minimum (2.0 for uniform). The convolution's maximum value will be minimized using coordinate-wise descent for each dimension factor.
