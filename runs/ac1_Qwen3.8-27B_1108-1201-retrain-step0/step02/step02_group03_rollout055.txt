def fft_convolve(a, b):
    """Linear convolution via FFT."""
    n, m = len(a), len(b)
    size = 1
    while size < n + m - 1:
        size <<= 1
    fa = np.fft.rfft(a, size)
    fb = np.fft.rfft(b, size)
    return np.fft.irfft(fa * fb, size)[:n + m - 1]

def compute_score(a):
    """Compute 2*n*max(conv(a,a))/sum(a)^2."""
    n = len(a)
    s = np.sum(a)
    if s < 1e-10:
        return np.inf
    c = fft_convolve(a, a)
    return 2.0 * n * np.max(c) / (s * s)

def project_simplex(v):
    """Project v onto the standard probability simplex {x >= 0, sum(x) = 1}."""
    n = len(v)
    if n == 0:
        return v
    # Algorithm from Duchi et al. (2012)
    if np.all(v <= 0):
        return np.ones(n) / n
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.where(u * np.arange(1, n+1) > (cssv - 1))[0][-1]
    theta = (cssv[rho] - 1) / (rho + 1)
    return np.maximum(v - theta, 0)

A better approach: use a step size `lr` that's independent of `tau`, and rely on the projection to keep things bounded. For the convex problem, a step size of `lr = 1/L` where `L` is the Lipschitz constant of the gradient would be optimal.

The gradient of the smoothed function `f_tau(a) = tau * log(sum exp(c_k/tau))` is `sum_k w_k * 2 * (C_k * a)`. The Hessian of `c_k` is `2*C_k` (a PSD matrix). The Hessian of `f_tau` is `sum_k w_k * 2*C_k + (1/tau) * Cov_w` where `Cov_w` is the covariance matrix of the gradients under the distribution `w`. The eigenvalues of `2*C_k` are bounded by `2*n` (roughly). So `L ≈ 2*n/tau` (roughly).

With `lr = 1/L ≈ tau/(2n)`, the Nesterov method converges in O(1/sqrt(T)) iterations for the smoothed problem. But we also need `tau` to be small enough that the smoothed problem is a good approximation.

The trade-off: large `tau` = easy to optimize but poor approximation; small `tau` = good approximation but hard to optimize.

The standard approach is to use a "path-following" strategy: start with large `tau`, solve the smoothed problem approximately, then decrease `tau` and continue from the current solution.
