Let me try a different approach: use numerical optimization with a good initialization.

Strategy:
1. Start with the previous program's output (score 1.512) or a good initial guess.
2. Use a projected subgradient method or proximal gradient method to minimize the max autocorrelation.
3. Use multiple restarts with different initializations.

For the subgradient method:
- At each iteration, compute all `f_k(a)` for k = 0, ..., 2n-2.
- Identify the set of "active" constraints (those with `f_k(a) >= max - epsilon`).
- Compute the gradient of the max (average of active gradients, or just the gradient of the single max).
- Take a step: `a_new = a - lr * grad`.
- Project to `sum a = 1, a >= 0`.

The projection onto `{a : sum a = 1, a >= 0}` (the simplex) is well-known: sort the elements, find the threshold, and clip.

Let me also consider using scipy's optimization tools. `scipy.optimize.minimize` with the objective being the max of the convolution values, using a smooth approximation like the log-sum-exp.

The log-sum-exp approximation: `max_k f_k ≈ (1/τ) * log(sum_k exp(τ*f_k))` for large τ. This is a smooth upper bound on the max, and as τ → ∞, it converges to the max.

This would allow us to use standard gradient-based optimization (L-BFGS, etc.) with a smooth objective.

import numpy as np
from scipy.optimize import minimize
import time

def compute_conv(a):
    """Compute full linear convolution of a with itself."""
    return np.convolve(a, a)

def smooth_max(conv, tau):
    """Smooth approximation of max using log-sum-exp."""
    c = np.max(conv)
    return c + np.log(np.sum(np.exp(tau * (conv - c)))) / tau

def smooth_max_grad(a, tau):
    """
    Gradient of smooth_max(conv(a,a), tau) w.r.t. a.
    
    smooth_max = (1/tau) * log(sum_k exp(tau * f_k))
    where f_k = conv(a,a)[k] = sum_i a[i]*a[k-i]
    
    d(smooth_max)/da[j] = (1/tau) * sum_k exp(tau*f_k) * df_k/da[j] / sum_k exp(tau*f_k)
                         = sum_k w_k * df_k/da[j]
    where w_k = exp(tau*f_k) / sum_k exp(tau*f_k) (softmax weights)
    
    df_k/da[j] = 2*a[k-j] if 0 <= k-j < n, else 0
    
    So d(smooth_max)/da[j] = 2 * sum_k w_k * a[k-j] * I[0 <= k-j < n]
                           = 2 * sum_m a[m] * w[j+m] (where m = k-j, so k = j+m)
                           = 2 * sum_{m=0}^{n-1} a[m] * w[j+m] (truncated to valid k)
    """
    n = len(a)
    conv = compute_conv(a)
    # Softmax weights
    shifted = tau * (conv - conv.max())
    w = np.exp(shifted)
    w /= np.sum(w)
    
    # grad[j] = 2 * sum_{m=0}^{n-1} a[m] * w[j+m] (where j+m < 2n-1)
    # This is O(n^2) directly, or O(n log n) with FFT.
    
    # FFT approach:
    # grad[j]/2 = sum_m a[m] * w[j+m] for m = max(0, j+m < 2n-1)
    # Let's define: for each j, sum over m where 0 <= m < n and 0 <= j+m < 2n-1
    # Since j >= 0 and m >= 0, j+m >= 0 always. And j+m < 2n-1 means m < 2n-1-j.
    # Since m < n and j >= 0, m < min(n, 2n-1-j). For j <= n-1: m < min(n, 2n-1-j).
    # If j <= n-1: 2n-1-j >= n, so m < n. So the constraint is just m < n.
    # So grad[j]/2 = sum_{m=0}^{n-1} a[m] * w[j+m] for all j = 0, ..., n-1.
    
    # This is the "Hankel" product. Using FFT:
    # Define x = a (length n), y = w (length 2n-1)
    # We want h[j] = sum_{m=0}^{n-1} x[m] * y[j+m] for j = 0, ..., n-1
    # 
    # Note that h[j] = (x * y_rev)[n-1+j] where y_rev[k] = y[2n-2-k] and * is convolution
    # Let's verify: (x * y_rev)[n-1+j] = sum_i x[i] * y_rev[n-1+j-i]
    # = sum_i x[i] * y[2n-2-(n-1+j-i)]
    # = sum_i x[i] * y[n-1-j+i]
    # Let m = i: = sum_m x[m] * y[n-1-j+m]
    # We want sum_m x[m] * y[j+m]. So we need n-1-j+m = j+m → n-1-j = j → j = (n-1)/2.
    # That only works for one j. So this approach doesn't directly work.
    
    # Alternative: use the fact that h[j] = <x, y[j:j+n]>
    # This is a matrix-vector product where the matrix is a "sliding window" of y.
    # For efficiency, we can use the FFT-based approach:
    # 
    # h[j] = sum_{m=0}^{n-1} x[m] * y[j+m]
    # Let's reverse y: y_rev[k] = y[2n-2-k]
    # h[j] = sum_{m=0}^{n-1} x[m] * y[2n-2-(2n-2-j-m)] = sum_{m=0}^{n-1} x[m] * y_rev[2n-2-j-m]
    # = (x * y_rev)[2n-2-j] (convolution)
    # Let's verify: (x * y_rev)[2n-2-j] = sum_i x[i] * y_rev[2n-2-j-i] = sum_i x[i] * y[2n-2-(2n-2-j-i)] = sum_i x[i] * y[i+j]

    h = conv_xy[2n-2:n-1:-1]  # indices 2n-2, 2n-3, ..., n-1 → n elements
    
    grad = 2.0 * h
