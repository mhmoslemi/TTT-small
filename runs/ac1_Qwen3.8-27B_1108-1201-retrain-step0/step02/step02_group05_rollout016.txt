**Key insight**: The log-sum-exp of c is a smooth upper bound on max(c), and it's tight when the temperature is small. By minimizing the log-sum-exp with decreasing temperature, we effectively minimize the max.

**Another key insight**: The gradient of log-sum-exp is a weighted average of the gradients of the individual c[k], with weights proportional to exp(c[k]/tau)/sum(exp(c[j]/tau)). So the gradient automatically focuses on the "hot" peaks.

**Improvement over previous approach**:
1. Use log-sum-exp instead of p-norm (more natural, better conditioned)
2. Use a more aggressive and adaptive annealing schedule
3. Add a "peak equalization" step that directly solves a small QP to equalize the top peaks
4. Try different initializations and sequence lengths
5. Use the gradient structure more efficiently

Let me also consider a completely different approach: **the method of conditional gradients (Frank-Wolfe) on the simplex**.

The problem is: minimize f(a) = max_k c_k(a) subject to a >= 0, sum(a) = 1.

Since c_k(a) = a^T Q_k a (where Q_k is the matrix for lag k of the convolution), this is a minimax quadratic problem on the simplex.

The Frank-Wolfe method would:
1. At current point a, compute the gradient of the active (or smoothed) objective
2. Find the vertex of the simplex that minimizes the linear approximation
3. Take a step toward that vertex

But the simplex has n vertices, and moving to a vertex means putting all mass in one coordinate, which is probably not good. So standard FW might not work well here.

Better: Use a projected gradient method or a barrier method on the simplex.

Actually, I think the most practical approach is:

1. **Parameterize** a = softmax(theta) (ensures a > 0 and sum(a) = 1)
2. **Optimize** the log-sum-exp of the convolution using L-BFGS
3. **Anneal** the temperature aggressively
4. **Polish** with a targeted local search

Let me also think about the "peak equalization" idea:

Suppose the top m peaks are at lags k_1, ..., k_m with values c_{k_1} >= c_{k_2} >= ... >= c_{k_m}. We want to find a small adjustment delta (with sum(delta) = 0, a + delta >= 0) that minimizes max(c_{k_i}(a + delta)).

To first order: c_{k_i}(a + delta) ≈ c_{k_i}(a) + 2 * (Q_{k_i} a) \cdot delta

So we want to minimize max_i (c_{k_i} + 2*(Q_{k_i} a) \cdot delta) subject to sum(delta) = 0, a + delta >= 0.

This is a linear program (or can be solved with a bisection on the target peak value). The constraint "a + delta >= 0" can be handled by clipping or by adding it to the LP.

This is essentially the LP from the "state of the art" description! The SOA was:
"maximize sum b_j subject to b_j >= 0 and ||f * g_0||_inf <= M"

Which is: find a direction g that, when added to f, keeps the convolution bounded by M. This is exactly what I described above.

So the SOA approach is: at each iteration, find a direction that keeps the convolution bounded, then move in that direction. This is a form of active set / constraint handling method.

Let me combine ideas:

**My proposed algorithm:**

1. **Initialization**: Use the provided sequence, plus several diverse initializations (chirp, random, structured patterns).

2. **Log-sum-exp optimization**: 
   - Parameterize a = softmax(theta)
   - Minimize 2n * LSE(c, tau) where LSE is log-sum-exp with temperature tau
   - Start with tau = 0.1 * max(c) and anneal down to tau = 1e-5 * max(c)
   - Use L-BFGS-B for the optimization

3. **Peak equalization (LP-based)**:
   - Identify the top m peaks (m = 5-20)
   - Solve an LP: maximize sum(g) subject to g >= 0, and for each top peak k_i, the linearized constraint 2*(Q_{k_i} a) \cdot g <= (M - c_{k_i}) * epsilon + M
   - Actually, let me reformulate: find g >= 0, sum(g) = 0 (or a + t*g >= 0 for small t) such that the peaks are reduced.
   - A simpler version: find the direction g (with sum(g) = 0) that most reduces the maximum peak. This is a linear program.

4. **Simulated annealing polish**:
   - Random perturbations focused on reducing the top peaks
   - Acceptance based on score improvement

Let me now think about efficiency. For n=256:
- Convolution via FFT: O(n log n) ≈ O(256 * 8) = O(2048) operations
- Gradient computation: O(n log n)
- Each L-BFGS iteration: O(n log n) for the function + gradient
- L-BFGS with 200 iterations: O(200 * n log n) per temperature
- With 10 temperatures: O(2000 * n log n) total

This should be fast enough. The LP step is the expensive part: it has 2n-1 = 511 constraints and n = 256 variables. Solving this LP might take O(n^3) = O(16 million) operations per iteration, and we might do 50-100 iterations. That's manageable.

Flat convolution optimization using log-sum-exp annealing, LP peak equalization,

def fft_convolve(a, b):
    """Compute linear convolution using FFT."""
    n = len(a)
    m = len(b)
    size = 1
    while size < n + m - 1:
        size <<= 1
    fa = np.fft.rfft(a, size)
    fb = np.fft.rfft(b, size)
    return np.fft.irfft(fa * fb, size)[:n + m - 1]

def softmax(theta):
    """Stable softmax."""
    t = theta - np.max(theta)
    e = np.exp(t)
    return e / np.sum(e)

def local_score(a):
    """Score for normalized sequence (sum=1): 2n * max(conv(a,a))."""
    n = len(a)
    c = fft_convolve(a, a)
    return 2.0 * n * np.max(c)

def lse_anneal(theta, n, tau_schedule, maxiter_per_tau, deadline=None):
    """Run L-BFGS with annealed LSE temperature."""
    best_theta = theta.copy()
    best_score = local_score(softmax(theta))
    
    for tau in tau_schedule:
        if deadline is not None and time.monotonic() > deadline - 10:
            break
        
        result = minimize(
            lse_obj_grad, theta.copy(),
            method='L-BFGS-B',
            jac=True, args=(tau,),
            options={'maxiter': maxiter_per_tau, 'ftol': 1e-15, 'gtol': 1e-12, 'maxfun': maxiter_per_tau * 5}
        )
        theta_new = result.x
        a_new = softmax(theta_new)
        s = local_score(a_new)
        
        if s < best_score:
            best_score = s
            best_theta = theta_new.copy()
        
        theta = best_theta
    
    return best_theta, best_score


def peak_equalize_lp(a, m_peaks=10, max_iter=50):
    """
    LP-based peak equalization.
    Find direction g (sum=0) that reduces the top peaks.
    Returns updated sequence.
    """
    n = len(a)
    c = fft_convolve(a, a)
    peak_val = np.max(c)
    
    # Get top peaks
    top_idx = np.argsort(c)[-m_peaks:]
    top_vals = c[top_idx]
    
    # We want to find g with sum(g)=0, a + g >= 0
    # such that c_k(a+g) is reduced for k in top_idx
    # Linearized: c_k(a+g) ≈ c_k + 2 * (Q_k a) \cdot g
    # Where (Q_k a)[j] = a[k-j] + a[j-k] (the "folded" values)
    
    # Compute the linearized contributions for each top peak
    # For peak at lag k: linearized reduction = 2 * sum_j g[j] * (a[k-j] + a[j-k])
    # We want to MAXIMIZE the minimum reduction across top peaks
    
    # This is a max-min LP:
    # maximize t
    # subject to: 2 * sum_j g[j] * fold_k[j] >= t - c[k] for each top peak k
    #              sum(g) = 0
    #              -a[j] <= g[j] <= ... (bounded)
    
    # Actually, let me reformulate more simply:
    # We want to minimize the maximum peak. Linearized:
    # c[k] + 2 * sum_j g[j] * fold_k[j] <= M for each top peak k
    # where M is the target peak value (we want to minimize M)
    
    # This is a linear program:
    # minimize M
    # subject to: 2 * fold_k @ g + c[k] <= M for each top peak k
    #              sum(g) = 0
    #              g[j] >= -a[j] (to keep a+g >= 0)
    #              g[j] <= some_upper_bound
    
    # Variables: g[0..n-1], M
    # c_lb = [c for g constraints, -inf for M]
    # c_ub = [ub for g constraints, +inf for M]
    # c_obj = [0, 0, ..., 0, 1] (minimize M)
    
    # Compute fold matrices for top peaks
    fold = np.zeros((len(top_idx), n))
    for idx, k in enumerate(top_idx):
        for j in range(n):
            fold[idx, j] = 0.0
            if 0 <= k - j < n:
                fold[idx, j] += a[k - j]
            if 0 <= j - k < n:
                fold[idx, j] += a[j - k]
    
    # LP: minimize M
    # subject to:
    #   2*fold[idx,j]*g[j] + c[top_idx[idx]] - M <= 0 for each idx  (inequality)
    #   sum(g) = 0  (equality)
    #   g[j] >= -a[j]  (lower bound)
    #   g[j] <= some_ub (upper bound, say 1)
    
    n_vars = n + 1  # n components of g + M
    
    # Objective: minimize M
    c_obj = np.zeros(n_vars)
    c_obj[-1] = 1.0
    
    # Inequality constraints: A_ub @ x <= b_ub
    # 2*fold @ g - M <= -c[top_idx]
    A_ub = np.zeros((len(top_idx), n_vars))
    for idx in range(len(top_idx)):
        A_ub[idx, :n] = 2.0 * fold[idx]
        A_ub[idx, -1] = -1.0
    b_ub = -c[top_idx]
    
    # Equality constraints: sum(g) = 0
    A_eq = np.zeros((1, n_vars))
    A_eq[0, :n] = 1.0
    b_eq = [0.0]
    
    # Bounds
    bounds = [(-a[i], 1.0) for i in range(n)]  # g bounds
    bounds.append((0.0, None))  # M >= 0
    
    result = linprog(c_obj, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq, 
                     bounds=bounds, method='highs')
    
    if result.success:
        g = result.x[:n]
        a_new = a + g
        a_new = np.maximum(a_new, 0)
        a_new = a_new / np.sum(a_new)
        return a_new
    else:
        return a.copy()


def simulated_annealing_polish(a_init, time_limit, rng):
    """Simulated annealing with targeted peak reduction."""
    current = a_init.astype(np.float64).copy()
    current_score = local_score(current)
    best = current.copy()
    best_score = current_score
    n = len(current)
    t0 = time.monotonic()
    temperature = 0.001
    cooling = 0.9999
    last_print = t0
    
    while time.monotonic() - t0 < time_limit:
        candidate = current.copy()
        r = rng.random()
        
        if r < 0.35:
            # Targeted peak reduction
            c = fft_convolve(current, current)
            peak_idx = int(np.argmax(c))
            # Find contributing indices
            contribs = np.zeros(n)
            for i in range(min(n, peak_idx + 1)):
                j = peak_idx - i
                if 0 <= j < n:
                    contribs[i] = current[i] * current[j]
            top_k = max(3, n // 15)
            top_idx = np.argsort(contribs)[-top_k:]
            candidate[top_idx] *= np.exp(rng.normal(-0.02, 0.01, size=len(top_idx)))
            other = np.setdiff1d(np.arange(n), top_idx)
            if len(other) > 0:
                n_inc = min(10, len(other))
                inc_idx = rng.choice(other, size=n_inc, replace=False)
                candidate[inc_idx] *= np.exp(rng.normal(0.02, 0.01, size=n_inc))
        elif r < 0.55:
            # Block perturbation
            width = max(1, int(rng.integers(1, max(2, n // 10))))
            start = int(rng.integers(0, n - width))
            candidate[start:start + width] *= np.exp(rng.normal(0.0, 0.03, size=width))
        elif r < 0.70:
            # Partial symmetrization
            current_sym = 0.5 * (current + current[::-1])
            candidate = current_sym * np.exp(rng.normal(0.0, 0.01, size=n))
        elif r < 0.85:
            # Small global perturbation
            candidate = current * np.exp(rng.normal(0.0, 0.01, size=n))
        else:
            # Value transfer (move mass from high to low peaks)
            c = fft_convolve(current, current)
            # Find a high and low value
            hi_idx = int(np.argmax(c))
            lo_idx = int(np.argmin(c[1:])) + 1  # avoid lag 0
            # Transfer from contributing to peak
            i_src = int(rng.integers(0, n))
            i_dst = int(rng.integers(0, n))
            if i_src != i_dst and current[i_src] > 1e-6:
                amount = current[i_src] * 0.02 * rng.random()
                candidate[i_src] -= amount
                candidate[i_dst] += amount
        
        candidate = np.maximum(candidate, 1e-10)
        candidate = candidate / np.sum(candidate)
        new_score = local_score(candidate)
        
        if new_score < current_score:
            current = candidate
            current_score = new_score
            if current_score < best_score:
                best_score = current_score
                best = current.copy()
        elif rng.random() < np.exp(-(new_score - current_score) / max(temperature, 1e-14)):
            current = candidate
            current_score = new_score
        
        temperature = max(temperature * cooling, 1e-10)
        
        if time.monotonic() - last_print > 5.0:
            last_print = time.monotonic()
            print(f"    SA: score={current_score:.6f}, best={best_score:.6f}, t={time.monotonic()-t0:.0f}s")
    
    return best, best_score


def make_chirp_init(n, alpha, rng):
    """Chirp-like initialization."""
    t = np.arange(n, dtype=np.float64)
    a = 1.0 + alpha * np.cos(np.pi * t * t / n)
    a = np.clip(a, 0.01, None)
    a += 0.05 * rng.standard_normal(n)
    a = np.clip(a, 0.01, None)
    return a / np.sum(a)


def make_random_init(n, rng, spread=0.3):
    """Random initialization."""
    a = 1.0 + spread * rng.standard_normal(n)
    a = np.clip(a, 0.01, None)
    return a / np.sum(a)


def make_bell_init(n, width, rng):
    """Bell-shaped initialization."""
    t = np.arange(n, dtype=np.float64)
    center = (n - 1) / 2.0
    a = np.exp(-0.5 * ((t - center) / width) ** 2)
    a += 0.03 * rng.standard_normal(n)
    a = np.clip(a, 0.005, None)
    return a / np.sum(a)


def one_minus_cosine_init(n, rng):
    """(1-cos) initialization - zero at edges, high in middle."""
    t = np.arange(n, dtype=np.float64)
    a = 1.0 - np.cos(2 * np.pi * t / n)
    a += 0.05 * rng.standard_normal(n)
    a = np.clip(a, 0.005, None)
    return a / np.sum(a)
