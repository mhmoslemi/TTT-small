Let me also think about a different approach: **direct optimization using the structure of the problem**.

The score is 2n * max_k (a^T C_k a) / (1^T a)^2 where C_k is the appropriate shift matrix.

Using the substitution b = a / (1^T a) (so 1^T b = 1), the score becomes 2n * max_k (b^T C_k b).

We want to minimize max_k (b^T C_k b) subject to b >= 0, 1^T b = 1.

This is a "minimax" problem: minimize the maximum of several quadratic functions over a convex set.

One approach: use a "z" variable.
min z
subject to b^T C_k b <= z for all k
         b >= 0, 1^T b = 1

This is a set of quadratic constraints, which is non-convex (each constraint b^T C_k b <= z is a "trust region" type constraint, which is non-convex when C_k is indefinite).

However, C_k for the convolution is a symmetric matrix with non-negative eigenvalues (it's a "shift" matrix, which is symmetric and PSD? Let me check).

C_k has entries (C_k)[i,j] = 1 if j = i+k or j = i-k (with bounds). Actually, for the linear convolution:
(a*a)[k] = sum_{j} a[j] * a[j+k] (for k >= 0, with j+k < n)

This can be written as a^T T_k a where T_k is a shift matrix. T_k is NOT symmetric in general (it's upper or lower triangular). But a^T T_k a = a^T (T_k + T_k^T)/2 a, so we can use the symmetric part.

The symmetric part of T_k (for k >= 0) has entries (S_k)[i,j] = 1/2 if j = i+k or j = i-k (within bounds). This is a banded matrix with 1/2 on the k-th superdiagonal and subdiagonal.

The eigenvalues of S_k: for k=0, it's the identity (eigenvalues all 1). For k=1, it's a tridiagonal matrix with 1/2 on the super/sub-diagonal. Its eigenvalues are cos(pi*m/(n+1)) for m=1,...,n, all in (-1, 1). So S_k is INDEFINITE for k >= 1.

This means the constraints b^T S_k b <= z are non-convex. So we can't solve this as a convex program directly.

However, we can use the following approach:
- Upper bound: max_k b^T S_k b <= lambda_max(S) * ||b||^2 where S = sum of all |S_k|... this is too loose.
- Better: use the fact that the sum of all convolution values is (sum a)^2 = 1 (after normalization). So the AVERAGE convolution value is 1/(2n-1). The maximum is at least the average, so max >= 1/(2n-1). The score is at least 2n/(2n-1) ≈ 1.

```python
"""
Optimization for minimizing peak linear autocorrelation of non-negative sequences.
Strategy: Fienup spectral flattening initialization + Adam gradient descent with
log-sum-exp smoothing + peak-targeted coordinate descent polish.
"""

import numpy as np
import time
from scipy.optimize import minimize

def fft_convolve(a, b=None):
    """Linear convolution via FFT."""
    if b is None:
        b = a
    n, m = len(a), len(b)
    size = 1
    while size < n + m - 1:
        size <<= 1
    fa = np.fft.rfft(a, size)
    fb = np.fft.rfft(b, size)
    return np.fft.irfft(fa * fb, size)[:n + m - 1]

def score_fast(a):
    """Compute 2n*max(conv(a,a))/(sum a)^2."""
    n = len(a)
    S = np.sum(a)
    if S < 1e-10:
        return np.inf
    conv = fft_convolve(a, a)
    return 2.0 * n * np.max(conv) / (S * S)

def smoothed_max(conv, tau):
    """Smooth max via log-sum-exp, returns value and gradient w.r.t. a."""
    n = len(conv)
    max_c = np.max(conv)
    shifted = (conv - max_c) / tau
    exp_vals = np.exp(shifted)
    w = exp_vals / np.sum(exp_vals)
    value = max_c + tau * np.log(np.sum(exp_vals))
    return value, w, max_c

def fienup_init(n, rng, n_iter=500, alpha=0.5):
    """
    Fienup-style iterative projection to flatten autocorrelation.
    Alternates between time-domain (non-negativity) and frequency-domain
    (magnitude flattening).
    """
    # Random non-negative initialization
    a = rng.random(n) + 0.1
    a = a / np.sum(a)
    
    L = 1
    while L < 2 * n - 1:
        L <<= 1
    
    best_a = a.copy()
    best_score = score_fast(a)
    
    for it in range(n_iter):
        # Zero-pad and FFT
        a_padded = np.zeros(L)
        a_padded[:n] = a
        A = np.fft.fft(a_padded)
        
        # Target magnitude (constant, set by energy)
        mag = np.abs(A)
        energy = np.sum(mag**2) / L  # = sum(a^2) by Parseval
        target = np.sqrt(energy)
        
        # Soft magnitude update
        # new_mag = mag * (target/mag)^alpha
        # = mag^(1-alpha) * target^alpha
        with np.errstate(divide='ignore', invalid='ignore'):
            ratio = target / mag
        ratio = np.where(mag > 1e-10, ratio, 1.0)
        ratio = np.clip(ratio, 0.1, 10.0)  # Prevent extreme changes
        new_mag = mag * ratio**alpha
        phase = np.angle(A)
        A_new = new_mag * np.exp(1j * phase)
        
        # Inverse FFT, take first n, clip
        a_new = np.real(np.fft.ifft(A_new, L))[:n]
        a_new = np.clip(a_new, 0.0, None)
        s = np.sum(a_new)
        if s < 1e-10:
            a = rng.random(n)
            a = a / np.sum(a)
        else:
            a = a_new / s
        
        # Track best
        if it % 50 == 0:
            sc = 2.0 * n * np.max(fft_convolve(a, a))
            if sc < best_score:
                best_score = sc
                best_a = a.copy()
    
    return best_a

def adam_optimize(a_init, n, time_limit, rng):
    """
    Adam optimization on log-parameterization (log a_i).
    Minimizes smooth max of conv(a,a) with sum(a) = 1 constraint.
    Uses simplex projection.
    """
    # Parameterize as a = softmax(theta) to ensure non-negativity and sum=1
    theta = np.log(a_init + 1e-30)
    m = np.zeros(n)
    v = np.zeros(n)
    step = 0
    beta1, beta2, eps = 0.9, 0.999, 1e-8
    lr = 5.0
    t0 = time.monotonic()
    best_theta = theta.copy()
    best_score = np.inf
    
    # Temperature schedule
    tau_start = 10.0 / n
    tau_end = 0.01 / n
    
    while time.monotonic() - t0 < time_limit:
        elapsed = time.monotonic() - t0
        frac = min(1.0, elapsed / time_limit)
        tau = tau_start * (tau_end / tau_start) ** (frac ** 0.5)
        
        # a = softmax(theta)
        t = theta - np.max(theta)
        e = np.exp(t)
        p = e / np.sum(e)  # a / 1 (sum = 1)
        
        # Compute smooth max and gradient
        conv = fft_convolve(p, p)
        max_c = np.max(conv)
        shifted = (conv - max_c) / tau
        exp_vals = np.clip(np.exp(shifted), 0, 1e30)
        w = exp_vals / np.sum(exp_vals)
        
        # Gradient of smooth max w.r.t. p:
        # d/dp_j [tau * log(sum_k exp((conv[k]-max)/tau))]
        # = 2 * sum_k w[k] * d conv[k]/d p[j]
        # conv[k] = sum_i p[i]*p[k-i] (for linear conv)
        # d conv[k]/d p[j] = p[k-j] + p[j+k'] (where valid)
        # = (correlation of p and w) * 2

        # d conv[k]/d p[j] = p[k-j] (if valid) + p[j+k]... no

        # = delta(i,j)*p[k-j] + delta(i,k-j)*p[j]

        # = 2*p[|k-j|] for |k-j| < n, with edge effects

        # grad_p[j] = 2 * (p corr w)[j] where (p corr w)[j] = sum_k p[k]*w[j+k] (circular)
        # For linear conv: grad_p[j] = 2 * sum_k w[k] * (p[k-j] + p[k-j] reflected)
        # Actually the simplest is: grad = 2 * fft_convolve(p, w) but that's not right either.
        
        # Let me think more carefully.
        # conv[k] = sum_i p[i] * p[i+k] for k >= 0 (with bounds 0 <= i < n, 0 <= i+k < n)
        # d conv[k] / d p[j] = p[j+k] (if j+k < n) + p[j-k] (if j-k >= 0)
        # So grad_smooth[j] = tau * sum_k w[k] * d(log(sum exp)/d conv[k]) * d conv[k]/d p[j]
        # = tau * sum_k w[k] * (d conv[k]/d p[j])  [since w is the softmax of (conv-max)/tau]

        corr = np.fft.irfft(np.conj(Fp) * Fw, size)[:n]

        # d conv[k] / d p[j] = p[k-j] (if 0<=k-j<n) + p[j-(k-j)]...

        # d/dp_j sum_i p[i]p[i+k] = p[j+k] (if valid) + p[j+k] (if j+k in range for the "other" i)

        # d/dp_j = p[k-j] (if max(0,k-n+1) <= j <= min(n-1,k)) + p[k-j] (if same condition with i=k-j)
