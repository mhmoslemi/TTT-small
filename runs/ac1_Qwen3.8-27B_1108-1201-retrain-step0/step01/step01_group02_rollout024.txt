The subgradient of `max_k b_k` at the current point is:
- If the max is unique at k*, the subgradient is `db_k*/da`
- If the max is achieved at multiple k's, the subgradient is any convex combination of `{db_k/da : k in argmax}`

For a practical method, I'll use a "soft" version where I weight all lags by how close they are to the maximum.

`grad[j] = sum_k softmax(b_k / temperature) * a[k-j]` (for valid k-j)

This is smooth and differentiable, and as temperature → 0, it concentrates on the argmax lags.

Let me now think about the efficient computation of grad:

`grad[j] = sum_{k=0}^{2n-2} w[k] * a[k-j]` where w[k] are the softmax weights.

Let me define: for each j in {0, ..., n-1}:
`grad[j] = sum_{m=0}^{n-1} a[m] * w[j+m]`

This is the "valid" cross-correlation of a with w (where w is longer).

Using numpy: `np.correlate(w, a, mode='valid')` should give this! Let me verify:
- `np.correlate(w, a, mode='full')` has length len(w) + len(a) - 1 = 3n-2
- The 'valid' mode gives length max(len(w), len(a)) - min(len(w), len(a)) + 1 = (2n-1) - n + 1 = n
- `np.correlate(w, a, 'valid')[j] = sum_m w[j+m] * a[m]` for m = 0, ..., n-1

Wait, I need to be careful about the definition. Let me check:
`np.correlate(in1, in2, mode)` computes:
`c_k = sum_n in1[n+k] * conj(in2[n])` for 'full' mode, where k ranges appropriately.

Actually, the numpy docs say: `c_k = sum_n a_n * conj(v_{n+k})` for the 'full' correlation of `v` with `a`.

So `np.correlate(w, a, 'full')[k] = sum_n w[n] * conj(a[n+k])`

For real signals and 'valid' mode (where the shorter array is fully contained in the longer):
If len(w) = 2n-1 > len(a) = n:
`np.correlate(w, a, 'valid')[k] = sum_{n=0}^{n-1} w[n+k] * a[n]` for k = 0, ..., n-1

Yes! So `grad = np.correlate(w, a, mode='valid')` where w has length 2n-1 and a has length n.

Let me verify with a small example:
- a = [a0, a1, a2] (n=3)
- w = [w0, w1, w2, w3, w4] (length 2n-1 = 5)
- grad[0] = w[0]*a[0] + w[1]*a[1] + w[2]*a[2]
- grad[1] = w[1]*a[0] + w[2]*a[1] + w[3]*a[2]
- grad[2] = w[2]*a[0] + w[3]*a[1] + w[4]*a[2]

And indeed, `np.correlate(w, a, 'valid')` should give [grad[0], grad[1], grad[2]].

Great, so the subgradient computation is O(n log n) using FFT (which is what np.correlate does internally for large arrays) or O(n^2) directly.

Now let me think about the overall algorithm:

```
Algorithm:
1. Initialize a (from previous best or random)
2. Normalize: a = a / sum(a)
3. Loop:
   a. Compute b = convolve(a, a)
   b. Compute weights: w[k] = exp(beta * b[k]) / sum(exp(beta * b)) for some beta > 0
      (This is a softmax that emphasizes the peak lags)
   c. Compute grad = correlate(w, a, 'valid')  [length n]
   d. Update: a_new = a - eta * grad
   e. Project: a_new = max(0, a_new); a_new = a_new / sum(a_new)
   f. If score(a_new) < score(a): accept, update a
      Else: reduce eta
   g. If stagnant for too long, restart with different eta or run LP step
4. Periodically run LP refinement
5. Final local search
```

The parameter beta controls how "peaked" the weights are. Large beta → focuses on the single worst lag. Small beta → more uniform weighting.

Let me also think about the learning rate schedule. A good approach is:
- Start with a moderate eta
- Use backtracking line search or Halley's method
- Periodically re-estimate the "curvature" to adapt eta

Let me also think about what local search moves would be effective:

1. **Single element adjustment**: Change one a_j by a small amount (adjusting another a_k to maintain the sum constraint).
2. **Pairwise adjustment**: Change two elements a_j and a_k.
3. **Block adjustment**: Change a contiguous block.
4. **Mirror/palinodic moves**: If the sequence is approximately symmetric, try to enforce or break symmetry.
5. **Frequency-domain moves**: Add a small sinusoid to the sequence (after projection).

I think the most effective moves are:
- **Targeted reduction of peak lags**: Identify the lag k* where b is maximized, and reduce the contributions to b_{k*}. The contributions come from pairs (j, k*-j). We can reduce a_j and/or a_{k*-j} for the pairs with the largest contribution.
- **Spreading**: If the sequence has "clumps" (regions of high a_j), spread them out.

```python
"""
Hybrid subgradient + LP + local search optimization for minimizing
peak auto-convolution of non-negative sequences.
"""

import numpy as np
from scipy.sparse import csr_matrix
from scipy.optimize import linprog
import time

def score_sequence(a):
    n = len(a)
    conv = np.convolve(a, a)
    max_b = conv.max()
    sum_a = a.sum()
    if sum_a < 0.01:
        return float('inf')
    return 2.0 * n * max_b / (sum_a ** 2)

def normalize(a):
    a = np.maximum(0, a)
    s = a.sum()
    if s < 1e-15:
        return a
    return a / s

def subgradient_step(a, beta=10.0, eta=0.01):
    """One subgradient step to flatten the auto-convolution."""
    n = len(a)
    b = np.convolve(a, a)
    # Softmax weights emphasizing peaks
    shifted_b = b - b.max()
    w = np.exp(beta * shifted_b)
    w /= w.sum()
    # Compute subgradient
    # grad[j] = sum_{k=0}^{2n-2} w[k] * a[k-j] for valid k-j
    # = sum_{m=0}^{n-1} a[m] * w[j+m]
    grad = np.correlate(w, a, mode='valid')
    # Update
    a_new = a - eta * grad
    a_new = np.maximum(0, a_new)
    s = a_new.sum()
    if s < 1e-15:
        return a, b, grad
    a_new = a_new / s
    return a_new, b, grad

def subgradient_optimize(a, time_limit=60.0, beta_init=5.0, eta_init=0.02, verbose=False):
    """Run subgradient method to minimize max auto-convolution."""
    start_time = time.monotonic()
    a = normalize(a.astype(np.float64).copy())
    n = len(a)
    best_a = a.copy()
    best_score = score_sequence(a)
    eta = eta_init
    beta = beta_init
    stagnant = 0
    
    while time.monotonic() - start_time < time_limit:
        b = np.convolve(a, a)
        max_b = b.max()
        score = 2.0 * n * max_b
        
        if score < best_score - 1e-10:
            best_score = score
            best_a = a.copy()
            stagnant = 0
        else:
            stagnant += 1
        
        if stagnant > 100:
            # Restart with different parameters
            eta *= 0.5
            beta *= 1.5
            stagnant = 0
            if eta < 1e-6:
                break
        
        # Compute step
        shifted_b = b - b.max()
        w = np.exp(beta * shifted_b)
        w /= w.sum()
        grad = np.correlate(w, a, mode='valid')
        
        a_new = a - eta * grad
        a_new = np.maximum(0, a_new)
        s = a_new.sum()
        if s < 1e-15:
            eta *= 0.5
            continue
        a_new = a_new / s
        
        if score_sequence(a_new) <= score + 1e-10:
            a = a_new
        else:
            # Try smaller step
            a_new = a - eta * 0.3 * grad
            a_new = np.maximum(0, a_new)
            s = a_new.sum()
            if s > 1e-15:
                a_new = a_new / s
                if score_sequence(a_new) <= score + 1e-10:
                    a = a_new
            eta *= 0.8
    
    return best_a, best_score

def lp_refine(a, time_limit=60.0, verbose=False):
    """LP-based refinement step."""
    start_time = time.monotonic()
    a = normalize(a.astype(np.float64).copy())
    n = len(a)
    best_a = a.copy()
    best_score = score_sequence(a)
    
    it = 0
    stagnant = 0
    while time.monotonic() - start_time < time_limit:
        elapsed = time.monotonic() - start_time
        remaining = time_limit - elapsed
        if remaining < 5:
            break
        
        b = np.convolve(a, a)
        M = b.max()
        score = 2.0 * n * M
        
        if score < best_score - 1e-10:
            best_score = score
            best_a = a.copy()
            stagnant = 0
        else:
            stagnant += 1
        
        if stagnant > 20:
            break
        
        # Build LP: maximize sum(g) s.t. convolve(a, g) <= M, g >= 0
        # convolve(a, g)_k = sum_j a[j] * g[k-j]
        # This is a matrix equation: A @ g <= M * ones
        # where A is (2n-1) x n with A[k,j] = a[j] if k-j is in [0,n-1]
        
        # Build the matrix
        n_rows = 2 * n - 1
        # A[k, j] = a[j] if 0 <= k-j < n, else 0
        # For row k, the non-zero entries are at columns j where 0 <= k-j < n
        # i.e., max(0, k-n+1) <= j <= min(n-1, k)
        
        # Use sparse matrix
        rows = []
        cols = []
        data = []
        for k in range(n_rows):
            j_start = max(0, k - n + 1)
            j_end = min(n - 1, k)
            for j in range(j_start, j_end + 1):
                rows.append(k)
                cols.append(j)
                data.append(a[j])
        
        A = csr_matrix((data, (rows, cols)), shape=(n_rows, n))
        
        c = -np.ones(n)  # maximize sum(g) = minimize -sum(g)
        b_ub = np.full(n_rows, M)
        bounds = [(0, None)] * n
        
        timeout = max(2.0, min(30.0, remaining * 0.3))
        try:
            res = linprog(c, A_ub=A, b_ub=b_ub, bounds=bounds, method='highs',
                          options={'presolve': True, 'time_limit': timeout})
            if res.success and res.x is not None:
                g = np.maximum(0, res.x)
                sum_g = g.sum()
                if sum_g > 1.0 + 1e-8:
                    g = g / sum_g
                    alpha = min(0.5, max(0.1, 2.0 / (1.0 + it)))
                    a_new = (1 - alpha) * a + alpha * g
                    a_new = normalize(a_new)
                    if score_sequence(a_new) <= score + 1e-10:
                        a = a_new
                    else:
                        alpha *= 0.3
                        a_new = (1 - alpha) * a + alpha * g
                        a_new = normalize(a_new)
                        a = a_new
                else:
                    break  # No improvement direction
            else:
                break
        except Exception:
            break
        
        it += 1
    
    return best_a, best_score

            contributions = np.array([a[j] * a[k_peak - j] for j in range(j_start, j_end + 1)])
            total = contributions.sum()
            if total > 0:
                # Find the pair with largest contribution and reduce both
                for _ in range(5):
                    idx = int(rng.choice(len(contributions), p=contributions/contributions.sum()))
                    j = j_start + idx
                    k = k_peak - j

                        reduce_factor = np.exp(-rng.uniform(0.01, 0.05))
                        candidate[j] *= reduce_factor
                        if j != k:
                            candidate[k] *= reduce_factor
                        candidate = normalize(candidate)
                        if score_sequence(candidate) < best_score:
```

However, we can use a smoothed version: replace max(b) with a softmax approximation: `logsumexp(beta * b) / beta`. For large beta, this approximates max(b). This is smooth, so we can use FISTA or even standard gradient descent with adaptive step size.

```python
def smooth_objective(a, beta=50.0):
    b = np.convolve(a, a)
    # Smoothed max: (1/beta) * log(sum(exp(beta * b)))
    # For numerical stability: (1/beta) * (beta * max(b) + log(sum(exp(beta * (b - max(b))))))
    max_b = b.max()
    log_sum = max_b + np.log(np.sum(np.exp(beta * (b - max_b))))
    return log_sum / beta

def smooth_gradient(a, beta=50.0):
    b = np.convolve(a, a)
    max_b = b.max()
    w = np.exp(beta * (b - max_b))
    w /= w.sum()
    # grad = d/db logsumexp * db/da
    # d/db logsumexp(beta*b) = beta * softmax(beta*b)
    # So grad = beta * w * db/da
    # But we want the gradient of (1/beta)*logsumexp, which is just softmax(beta*b) * db/da
    # db_k/da_j = a[k-j] (for valid k-j)
    # grad[j] = sum_k w[k] * a[k-j]
    return np.correlate(w, a, mode='valid')
```

Actually, the original approach (maximize sum(g) s.t. a*g <= M) already does this implicitly: if M = max(a*a), the only feasible g with maximum sum might be g = a (or close to it). If we decrease M slightly, we force g to be different.

Let me stick with the original LP formulation but add the trick of decreasing M slightly.

"""
Hybrid optimization for minimizing peak auto-convolution of non-negative sequences.
Combines subgradient descent with momentum, LP-based refinement, and targeted local search.
Key innovation: uses "U-shaped" initialization based on theoretical analysis of optimal structure.
"""

import numpy as np
from scipy.sparse import csr_matrix
from scipy.optimize import linprog
import time

# --- Helper functions ---

def normalize(a):
    a = np.maximum(0.0, a)
    s = a.sum()
    return a / s if s > 1e-15 else a

def score(a):
    n = len(a)
    b = np.convolve(a, a)
    return 2.0 * n * b.max() / (a.sum() ** 2)

def u_shaped_init(n):
    """Initialize with U-shaped sequence (large at ends, small in middle)."""
    t = np.arange(n, dtype=np.float64)
    # a_j proportional to 1/sqrt(j+1) from left, 1/sqrt(n-j) from right
    # Take the max (or product) to get U-shape
    left = 1.0 / np.sqrt(t + 1.0)
    right = 1.0 / np.sqrt(n - t)
    a = np.maximum(left, right)  # U-shape: large at both ends
    return normalize(a)

def raised_cosine_init(n):
    t = np.arange(n, dtype=np.float64)
    return normalize(0.5 * (1.0 + np.cos(2.0 * np.pi * t / n)))

def gaussian_init(n, sigma_frac=0.3):
    t = np.arange(n, dtype=np.float64)
    center = (n - 1) / 2.0
    sigma = sigma_frac * (n / 2.0)
    return normalize(np.exp(-0.5 * ((t - center) / sigma) ** 2))

def random_smooth_init(n, rng, n_bumps=5):
    a = np.zeros(n)
    for _ in range(n_bumps):
        center = float(rng.integers(0, n))
        width = float(rng.integers(max(2, n//20), max(3, n//3)))
        t = np.arange(n, dtype=np.float64)
        a += np.exp(-0.5 * ((t - center) / width) ** 2)
    return normalize(a)

def subgradient_optimize(a, time_limit=60.0, beta=10.0, eta=0.01, momentum=0.9, verbose=False):
    """Subgradient descent with momentum to flatten auto-convolution."""
    start = time.monotonic()
    a = normalize(a.astype(np.float64).copy())
    n = len(a)
    best_a = a.copy()
    best_score = score(a)
    v = np.zeros(n)  # momentum velocity
    stagnant = 0
    it = 0
    
    while time.monotonic() - start < time_limit:
        b = np.convolve(a, a)
        max_b = b.max()
        s = a.sum()
        sc = 2.0 * n * max_b / (s ** 2)
        
        if sc < best_score - 1e-12:
            best_score = sc
            best_a = a.copy()
            stagnant = 0
        else:
            stagnant += 1
        
        if stagnant > 200:
            if eta < 1e-7:
                break
            eta *= 0.5
            beta *= 1.3
            stagnant = 0
        
        # Compute gradient of smooth max
        shifted = b - b.max()
        w = np.exp(beta * shifted)
        w /= w.sum()
        grad = np.correlate(w, a, mode='valid')
        
        # Momentum update
        v = momentum * v - eta * grad
        a_new = a + v
        a_new = normalize(a_new)
        
        if score(a_new) <= sc + 1e-10:
            a = a_new
        else:
            # Retry without momentum
            a_new = a - eta * 0.5 * grad
            a_new = normalize(a_new)
            if score(a_new) <= sc + 1e-10:
                a = a_new
                v = np.zeros(n)
            else:
                eta *= 0.8
                v = np.zeros(n)
        
        it += 1
        if verbose and it % 100 == 0:
            print(f"      SG iter {it}: score={score(a):.6f}, eta={eta:.2e}")
    
    return best_a, best_score

def build_lp_matrix(a):
    """Build sparse matrix A where A @ g = convolve(a, g)."""
    n = len(a)
    n_rows = 2 * n - 1
    # A[k, j] = a[j] if 0 <= k-j < n
    rows = []
    cols = []
    data = []
    for j in range(n):
        # a[j] contributes to b[k] for k = j, j+1, ..., j+n-1
        k_range = range(j, j + n)
        rows.extend(k_range)
        cols.extend([j] * n)
        data.extend([a[j]] * n)
    return csr_matrix((data, (rows, cols)), shape=(n_rows, n))

def lp_refine(a, time_limit=60.0, verbose=False):
    """LP-based refinement: find direction that reduces peak cross-convolution."""
    start = time.monotonic()
    a = normalize(a.astype(np.float64).copy())
    n = len(a)
    best_a = a.copy()
    best_score = score(a)
    it = 0
    stagnant = 0
    
    while time.monotonic() - start < time_limit:
        remaining = time_limit - (time.monotonic() - start)
        if remaining < 3.0:
            break
        
        b = np.convolve(a, a)
        M = b.max()
        s = a.sum()
        sc = 2.0 * n * M / (s ** 2)
        
        if sc < best_score - 1e-12:
            best_score = sc
            best_a = a.copy()
            stagnant = 0
            if verbose:
                print(f"      LP iter {it}: score={sc:.6f}")
        else:
            stagnant += 1
        
        if stagnant > 15:
            break
        
        # LP: maximize sum(g) s.t. A@g <= M, g >= 0
        A = build_lp_matrix(a)
        c = -np.ones(n)
        b_ub = np.full(2*n-1, M)
        bounds = [(0, None)] * n
        
        timeout = max(1.0, min(20.0, remaining * 0.25))
        try:
            res = linprog(c, A_ub=A, b_ub=b_ub, bounds=bounds,
                          method='highs', options={'presolve': True, 'time_limit': timeout})
            if not res.success or res.x is None:
                break
            g = np.maximum(0, res.x)
            sum_g = g.sum()
            if sum_g <= 1.0 + 1e-8:
                # Try with tighter M
                M_tight = M * 0.99
                b_ub = np.full(2*n-1, M_tight)
                res = linprog(c, A_ub=A, b_ub=b_ub, bounds=bounds,
                              method='highs', options={'presolve': True, 'time_limit': timeout})
                if not (res.success and res.x is not None):
                    break
                g = np.maximum(0, res.x)
                sum_g = g.sum()
                if sum_g <= 1.0 + 1e-8:
                    break
            
            g = g / sum_g
            alpha = min(0.4, max(0.05, 1.0/(1.0 + 0.1*it)))
            a_new = (1 - alpha) * a + alpha * g
            a_new = normalize(a_new)
            new_sc = score(a_new)
            if new_sc <= sc + 1e-10:
                a = a_new
            else:
                a = (1 - alpha*0.3) * a + alpha*0.3 * g
                a = normalize(a)
        except Exception as e:
            if verbose:
                print(f"      LP error: {e}")
            break
        
        it += 1
    
    return best_a, best_score
