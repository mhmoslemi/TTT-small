Actually wait, is c[k] = sum_i a[i]*a[k-i] convex in a? It's a quadratic form: c[k] = a^T Q_k a where Q_k is a specific matrix. For c[k] to be convex, Q_k needs to be PSD.

Q_k has entries (Q_k)_{ij} = 1/2 if i + j = k or i + j = 2k-i... hmm, actually:
c[k] = sum_i a[i]*a[k-i] = sum_{i+j=k} a[i]*a[j]

or c[k] = 2*sum_{i+j=k, i<j} a[i]*a[j] (when k is odd)

The Hessian of c[k] with respect to a is:
For the term a[i]*a[j] (i≠j): the Hessian has 1 at positions (i,j) and (j,i).
For the term a[i]^2: the Hessian has 2 at position (i,i).

- Diagonal entries: 2 if 2i = k (i.e., i = k/2), else 0
- Off-diagonal (i,j): 1 if i+j=k, else 0

For k = n-1 (the center): the matrix has 1's where i+j=n-1. This is a "reversal" matrix (exchange matrix) with a 2 on the diagonal at position (k/2, k/2) if k is even.

The LP at each step:

The idea is: if we can find g with a larger sum while maintaining the same peak, then the blended sequence (1-α)a + αg will have a lower peak/sum ratio.

One issue: the LP constraint uses (a*g)[k] <= M, but we should really be checking that the autocorrelation of the new sequence is bounded. The blend (1-α)a + αg has autocorrelation:
((1-α)a + αg) * ((1-α)a + αg) = (1-α)^2 (a*a) + 2α(1-α)(a*g) + α^2 (g*g)

We only control the (a*g) term in the LP, not the (g*g) term. So for small α, the new autocorrelation peak is approximately:
(1-α)^2 * M + 2α(1-α) * M + α^2 * max(g*g)
= (1-α) * M + α^2 * max(g*g)
≈ M - αM + α^2 * max(g*g)

And the new sum is (1-α)*sum_a + α*sum_g.
