We need to minimize `2 * n * max_b / sum_a^2` where `b_sequence = np.convolve(sequence, sequence)` and `sum_a = np.sum(sequence)`.

The key insight is that for a normalized sequence where `sum_a = 1`, we want to minimize `2 * n * max_conv`. Or equivalently, for any normalization, the ratio `max_conv / sum_a^2` is what matters, and we multiply by `2*n`.

If we normalize `sum(f) = 1`, we minimize `2 * n * max(f*f)`.
If we normalize `sum(f) = sqrt(2*n)`, we minimize `max(f*f)`.
