If `a` has length `n` and `v` has length `2n-1`, then `c[m]` is valid for `m = 0, 1, ..., 2n-2` (since `m+j <= 2n-2` requires `m <= 2n-2-j`, and the most restrictive is `j=0` giving `m <= 2n-2`, and `m >= 0`).

So `grad[i] = c[i]` for `i = 0, ..., n-1`.

To compute `c` using FFT:
`c[m] = sum_j a[j] * v[m+j]`

Let `v_rev = v[::-1]` (length `2n-1`).
`c[m] = sum_j a[j] * v_rev[2n-2-(m+j)] = sum_j a[j] * v_rev[(2n-2-m)-j]`

This is the cross-correlation of `a` and `v_rev` at lag `2n-2-m`.

In standard terms: `(a ⋆ v_rev)[k] = sum_j a[j] * v_rev[k+j]`... no, cross-correlation is `(a ⋆ b)[k] = sum_j conj(a[j]) * b[j+k]`.

OK I'm overcomplicating this. Let me just use a simple approach:

For the gradient, I'll compute it directly but vectorize the inner product:

```python
# grad[i] = 2 * sum_{j=0}^{n-1} a[j] * v[i+j]

# We can write this as: for each i, take v[i:i+n] and dot with a
# This is a "sliding dot product" which can be done with a loop or FFT.

# Simple approach for n <= 5000:
grad = np.array([2.0 * np.dot(a, w[i:i+n]) for i in range(n)])
```

This is O(n^2) = 25M operations for n=5000, which should take about 0.025 seconds in numpy (each dot is fast). Actually each dot is O(n) and there are n of them, so total is O(n^2) = 25M for n=5000. Actually, I realize there might be an issue. Let me re-derive the gradient.

The score is: `score = 2n * M / S^2` where `M = max_k c[k]` and `c = conv(a,a)`, `S = sum(a)`.

Using softmax: `M ≈ tau * logsumexp(c/tau) = tau * (log(sum(exp(c/tau))) - max(c)/tau)`

Let `z_k = c[k]/tau`, `Z = sum(exp(z_k))`, `w_k = exp(z_k)/Z`.

`M_soft = tau * log(Z) = tau * (max(z) + log(sum(exp(z - max(z)))))`

`dM_soft/dz_k = tau * (1/Z) * exp(z_k) = tau * w_k`

`dz_k/da[i] = (1/tau) * dc[k]/da[i]`

`dM_soft/da[i] = sum_k (dM_soft/dz_k) * (dz_k/da[i]) = sum_k tau*w_k * (1/tau) * dc[k]/da[i] = sum_k w_k * dc[k]/da[i]`

Now, `c[k] = sum_j a[j] * a[k-j]` (for valid indices).

`dc[k]/da[i]`: The index `i` appears in `c[k]` in two ways:
1. As `j = i`: contributes `a[k-i]` if `0 <= k-i < n`
2. As `k-j = i`, i.e., `j = k-i`: contributes `a[k-i]` if `0 <= k-i < n`

So `dc[k]/da[i] = 2*a[k-i]` if `0 <= k-i < n`, else `a[k-i]` if only one term is valid, else 0.

Wait, case 1: `j = i`, need `0 <= i < n` (always true) and `0 <= k-i < n`.
Case 2: `j = k-i`, need `0 <= k-i < n` and `0 <= i < n` (always true).

So both cases require `0 <= k-i < n`. When this is satisfied:
- Case 1 contributes `a[k-i]`
- Case 2 contributes `a[j] = a[k-i]`

So `dc[k]/da[i] = 2*a[k-i]` when `0 <= k-i < n`.

Therefore: `dM_soft/da[i] = sum_k w_k * 2*a[k-i]` (where the sum is over k such that `0 <= k-i < n`, i.e., `i <= k <= i+n-1`)

`dM_soft/da[i] = 2 * sum_{k=i}^{i+n-1} w_k * a[k-i] = 2 * sum_{j=0}^{n-1} a[j] * w_{i+j}`

Great, so my earlier derivation was correct.

And the full gradient of the score:
`dscore/da[i] = (2n/S^2) * dM_soft/da[i] - (4n*M_soft/S^3) * 1`
`= (2n/S^2) * 2 * sum_j a[j]*w_{i+j} - 4n*M_soft/S^3`
`= (4n/S^2) * sum_j a[j]*w_{i+j} - 4n*M_soft/S^3`

```python
"""
Multi-method optimization for minimizing peak autocorrelation of non-negative sequences.
Combines softmax gradient descent, LP refinement, and perturbation-based search.
"""

import numpy as np
from scipy.sparse import csr_matrix
from scipy.optimize import linprog
from scipy.special import logsumexp
import time


def normalize_nonneg(a):
    a = np.maximum(0.0, a)
    s = a.sum()
    if s < 1e-15:
        return a
    return a / s


def score_sequence(a):
    n = len(a)
    conv = np.convolve(a, a)
    max_b = conv.max()
    sum_a = a.sum()
    if sum_a < 0.01:
        return float('inf')
    return 2.0 * n * max_b / (sum_a ** 2)


def softmax_grad_score(a, tau):
    """Compute score and gradient using softmax smoothing."""
    n = len(a)
    conv = np.convolve(a, a)
    sum_a = a.sum()
    S_sq = sum_a ** 2
    
    # Softmax weights
    scaled = conv / tau
    max_scaled = scaled.max()
    exp_scaled = np.exp(scaled - max_scaled)
    w = exp_scaled / exp_scaled.sum()
    
    # M_soft = tau * logsumexp(conv/tau)
    M_soft = tau * (max_scaled + np.log(exp_scaled.sum()))
    
    # Gradient of M_soft w.r.t. a[i] = 2 * sum_j a[j] * w[i+j]
    # Computed as sliding dot product
    grad_M = np.zeros(n)
    for i in range(n):
        grad_M[i] = 2.0 * np.dot(a, w[i:i+n])
    
    # Gradient of score
    # score = 2n * M / S^2
    # d(score)/da[i] = 2n/S^2 * dM/da[i] - 4n*M/S^3
    grad_score = (2.0 * n / S_sq) * grad_M - (4.0 * n * M_soft) / (S_sq * sum_a)
    
    score = 2.0 * n * M_soft / S_sq
    return score, grad_score


def softmax_gradient_descent(a, time_limit=60.0, initial_tau=None, verbose=True, min_tau=None):
    """Gradient descent with softmax smoothing."""
    start = time.monotonic()
    n = len(a)
    a = normalize_nonneg(a.copy().astype(np.float64))
    
    conv0 = np.convolve(a, a)
    if initial_tau is None:
        initial_tau = conv0.max() * 0.05
    if min_tau is None:
        min_tau = initial_tau * 1e-4
    
    best_a = a.copy()
    best_score = score_sequence(a)
    
    tau = initial_tau
    lr = 0.1
    stagnant = 0
    it = 0
    
    while time.monotonic() - start < time_limit:
        score, grad = softmax_grad_score(a, tau)
        
        # Step
        a_new = a - lr * grad
        a_new = np.maximum(0, a_new)
        a_new = normalize_nonneg(a_new)
        
        new_score = score_sequence(a_new)
        
        if new_score <= best_score + 1e-12:
            if new_score < best_score - 1e-14:
                best_score = new_score
                best_a = a_new.copy()
            a = a_new
            stagnant = 0
        else:
            # Reduce learning rate and retry
            for factor in [0.5, 0.1, 0.01]:
                a_try = a - lr * factor * grad
                a_try = np.maximum(0, a_try)
                a_try = normalize_nonneg(a_try)
                s_try = score_sequence(a_try)
                if s_try < best_score:
                    best_score = s_try
                    best_a = a_try.copy()
                    a = a_try
                    stagnant = 0
                    break
            else:
                stagnant += 1
                a = a_new  # still move a bit
        
        if stagnant > 50:
            # Reset with perturbation
            a = best_a + 0.05 * np.random.randn(n)
            a = np.maximum(0, a)
            a = normalize_nonneg(a)
            stagnant = 0
            tau = initial_tau * 0.5
        
        # Schedule
        tau = max(min_tau, tau * 0.995)
        if it % 50 == 0:
            lr = max(0.001, lr * 0.95)
        
        it += 1
        if verbose and it % 100 == 0:
            print(f"    GD iter {it}: score={best_score:.6f}, tau={tau:.2e}")
    
    return best_a, best_score


def build_conv_matrix(a):
    n = len(a)
    n_rows = 2 * n - 1
    col_idx = np.repeat(np.arange(n, dtype=np.int32), n)
    row_idx = np.concatenate([np.arange(j, j + n, dtype=np.int32) for j in range(n)])
    data = np.tile(a.astype(np.float64), n)
    return csr_matrix((data, (row_idx, col_idx)), shape=(n_rows, n))


def solve_lp_step(a, M, timeout=30.0):
    n = len(a)
    n_rows = 2 * n - 1
    A = build_conv_matrix(a)
    c = -np.ones(n)
    b = np.full(n_rows, M)
    bounds = [(0.0, None)] * n
    try:
        res = linprog(c, A_ub=A, b_ub=b, bounds=bounds, method='highs',
                      options={'presolve': True, 'time_limit': timeout})
        if res.success and res.x is not None:
            return np.maximum(0.0, res.x)
    except Exception:
        pass
    return None


def lp_refine(a, time_limit_s=120.0, max_iters=200, verbose=True):
    start_time = time.monotonic()
    a = normalize_nonneg(a.copy().astype(np.float64))
    n = len(a)
    best_a = a.copy()
    best_score = score_sequence(a)
    
    stagnant = 0
    it = 0
    for it in range(max_iters):
        elapsed = time.monotonic() - start_time
        if elapsed > time_limit_s:
            break
        
        conv = np.convolve(a, a)
        score = 2.0 * n * conv.max() / (a.sum() ** 2)
        
        if score < best_score - 1e-14:
            best_score = score
            best_a = a.copy()
            stagnant = 0
            if verbose and (it % 20 == 0 or it < 5):
                print(f"    LP iter {it:4d}: score={score:.6f}")
        else:
            stagnant += 1
        
        if stagnant > 30:
            if verbose:
                print(f"    LP stagnant at iter {it}, best={best_score:.6f}")
            break
        
        M = conv.max()
        remaining = time_limit_s - elapsed
        if remaining < 5.0:
            break
        
        timeout = max(2.0, min(30.0, remaining * 0.2))
        g = solve_lp_step(a, M, timeout=timeout)
        if g is None:
            break
        
        sum_g = g.sum()
        if sum_g <= 1.0 + 1e-10:
            if verbose:
                print(f"    LP no improvement at iter {it}")
            break
        
        g = g / sum_g
        alpha = min(0.5, max(0.05, 1.0 / (1.0 + 0.2 * it)))
        a_new = (1.0 - alpha) * a + alpha * g
        a_new = normalize_nonneg(a_new)
        new_score = score_sequence(a_new)
        
        if new_score <= score + 1e-14:
            a = a_new
        else:
            alpha2 = alpha * 0.3
            a_new = (1.0 - alpha2) * a + alpha2 * g
            a_new = normalize_nonneg(a_new)
            a = a_new
    
    if verbose:
        print(f"    LP done: best={best_score:.6f} after {it+1} iters, {time.monotonic()-start_time:.1f}s")
    return best_a, best_score


def local_search(a, time_limit_s=60.0, rng=None, verbose=True):
    if rng is None:
        rng = np.random.default_rng(0)
    start_time = time.monotonic()
    a = normalize_nonneg(a.copy().astype(np.float64))
    n = len(a)
    best_a = a.copy()
    best_score = score_sequence(a)
    accept_count = 0
    
    while time.monotonic() - start_time < time_limit_s:
        # Random perturbation
        strategy = rng.random()
        
        if strategy < 0.3:
            # Smooth perturbation
            width = max(2, int(rng.integers(n // 100, n // 5)))
            start = int(rng.integers(0, max(1, n - width)))
            stop = min(n, start + width)
            candidate = a.copy()
            candidate[start:stop] *= np.exp(rng.normal(0.0, 0.1, size=stop - start))
        elif strategy < 0.6:
            # Symmetrize + perturb
            candidate = 0.5 * (a + a[::-1])
            candidate *= np.exp(rng.normal(0.0, 0.05, size=n))
        elif strategy < 0.8:
            # Tikhonov-like: add small noise
            candidate = a + rng.normal(0.0, 0.02, size=n)
        else:
            # Larger move
            candidate = a * np.exp(rng.normal(0.0, 0.3, size=n))
        
        candidate = np.maximum(0, candidate)
        candidate = normalize_nonneg(candidate)
        score = score_sequence(candidate)
        
        if score < best_score:
            best_score = score
            best_a = candidate.copy()
            a = candidate.copy()
            accept_count += 1
            if verbose and accept_count % 50 == 0:
                print(f"    LS accept {accept_count}: score={best_score:.6f}")
    
    if verbose:
        print(f"    LS done: best={best_score:.6f}, {time.monotonic()-start_time:.1f}s")
    return best_a, best_score


def try_extend_length(a, n_target, rng):
    """Try to extend a sequence to a longer length."""
    n = len(a)
    if n_target <= n:
        return a
    
    # Interpolate to new length
    old_t = np.linspace(0, 1, n)
    new_t = np.linspace(0, 1, n_target)
    a_new = np.interp(new_t, old_t, a)
    a_new = normalize_nonneg(a_new)
    return a_new
```
