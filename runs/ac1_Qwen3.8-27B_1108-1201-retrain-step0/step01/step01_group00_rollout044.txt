  - The term a[k-j] * a[j] exists (when i=k-j, giving a[k-j]*a[j])
  
These are the same term if k-j = j, i.e., k = 2j. In that case, c[k] contains a[j]^2 (only once), and dc[k]/da[j] = 2*a[j].

If k ≠ 2j: c[k] contains a[j]*a[k-j] and a[k-j]*a[j] = 2*a[j]*a[k-j]. dc[k]/da[j] = 2*a[k-j].

If k-j is not in [0, n-1]: a[j] doesn't appear in c[k], so dc[k]/da[j] = 0.

So: dc[k]/da[j] = 2 * a[k-j] if 0 ≤ k-j < n, else 0.
(And when k = 2j, this gives 2*a[j] which is correct.)

Great, so the gradient is simple: ∇c[k*]_j = 2*a[k*-j] (if 0 ≤ k*-j < n, else 0).

Now, to minimize c[k*] subject to sum(a) = S and a ≥ 0:
- Lagrangian: L = c[k*] - λ*(sum(a) - S) + sum_i μ_i * a_i (μ_i ≤ 0 for a_i ≥ 0)
- KKT: 2*a[k*-j] - λ + μ_j = 0 for a_j > 0, and 2*a[k*-j] - λ ≤ 0 for a_j = 0
- So a_j > 0 implies a[k*-j] = λ/2 (constant for all active j)
- This means: in the optimal solution (for a fixed peak lag k*), all a[k*-j] for j in the active set are equal!

This is a very strong structural characterization. The optimal solution (for fixed k*) has a specific form where the "mirror" of the active set around k*/2 are all equal.

This suggests a direct algorithm:
1. Fix k* = n-1 (the center, which is typically the peak)
2. The constraint says a[n-1-j] = constant for all j in the active set
3. This means the sequence is... hmm, this is getting complicated because different j map to different positions.

Let me think differently. For k* = n-1:
∇c[n-1]_j = 2*a[n-1-j]

So the gradient is 2*reverse(a). To minimize c[n-1] = <a, reverse(a)> subject to sum(a) = S:
- We want to decrease the inner product of a with its reverse
- The gradient direction (for decreasing) is -reverse(a)
- Projected to the hyperplane sum = 0: direction = -reverse(a) + mean(reverse(a)) * 1
- Actually: -reverse(a) + (sum(reverse(a))/n) * 1 = -reverse(a) + (S/n) * 1

So the steepest descent direction (on the sphere sum=S) is:
d_j = -(reverse(a)_j - S/n) = S/n - a[n-1-j]

This tells us: increase a[j] where a[n-1-j] is small, and decrease a[j] where a[n-1-j] is large. In other words, make a[j] inversely correlated with a[n-1-j].

But we also need a[j] ≥ 0. So the projected gradient is:
d_j = max(0, S/n - a[n-1-j] - a[j]) ... no, this isn't quite right for projection onto the non-negative cone.

The correct projection: we want to move in direction d = S/n - a[n-1-j] (the negative gradient projected to sum=0), but we can only decrease a[j] to 0, not below. So:
- If a[j] + α*d[j] < 0 for some α > 0, we're constrained
- The effective step is limited by the most constrained component

This is getting complex. Let me just implement a practical version:

```
for each iteration:
    1. Compute c = conv(a, a), find k* = argmax(c)
    2. Compute gradient: g[j] = 2*a[k*-j] if 0 ≤ k*-j < n, else 0
    3. Project gradient to sum=0: g -= mean(g)
    4. For non-negativity: only allow negative movement where a[j] > 0
    5. Take a small step: a_new = a - η * g_projected
    6. If a_new has negatives, project back (set to 0 and renormalize)
    7. Check if score improved; if not, try smaller η
```

But this only optimizes for the CURRENT peak lag. The peak might shift after the step. This is the "active set" issue.

A more robust approach: use the soft-max but with a very small tau (close to the true max), combined with the exact gradient for the current peak lag as a "boost".

An alternative: use a "soft positivity" constraint. Let a = softplus(theta) * c where c is chosen to maintain the sum. softplus(x) = log(1+exp(x)) is always positive and approximately x for large x, approximately exp(x) for small x. This gives more flexibility near zero.

import numpy as np
import time

def fft_convolve(a, b):
    """Compute linear convolution using FFT."""
    n = len(a)
    m = len(b)
    size = 1
    while size < n + m - 1:
        size <<= 1
    fa = np.fft.rfft(a, size)
    fb = np.fft.rfft(b, size)
    return np.fft.irfft(fa * fb, size)[:n + m - 1]

def local_score(a):
    """Compute the evaluation score."""
    n = len(a)
    S = np.sum(a)
    if S < 0.01:
        return np.inf
    c = fft_convolve(a, a)
    return 2.0 * n * np.max(c) / (S * S)

def softmax_normalize(theta):
    """Stable softmax."""
    t = theta - np.max(theta)
    e = np.exp(t)
    return e / np.sum(e)

def compute_objective_and_grad(a, tau):
    """
    Compute the smoothed objective and its gradient.
    objective = soft_max(conv(a,a), tau)
    Returns (objective, grad_obj, conv)
    """
    n = len(a)
    c = fft_convolve(a, a)
    c_max = np.max(c)
    shifted = (c - c_max) / tau
    exp_s = np.exp(shifted)
    sum_exp = np.sum(exp_s)
    w = exp_s / sum_exp
    obj = c_max + tau * np.log(sum_exp)
    # Gradient: d obj / da[j] = 2 * sum_k w[k] * a[k-j] (with bounds)
    # This is 2 * (reverse(a) * w) [n-1 : 2n-1]
    rev_a = a[::-1]
    corr = fft_convolve(rev_a, w)
    grad = 2.0 * corr[n-1:2*n-1]
    return obj, grad, c

def optimize_smooth(n, theta_init, time_limit, rng, tau_start=None, tau_end=None):
    """
    Adam-based optimization of the smooth soft-max objective.
    """
    if tau_start is None:
        tau_start = 5.0 / n
    if tau_end is None:
        tau_end = 0.05 / n
    
    S = np.sqrt(2.0 * n)
    theta = theta_init.astype(np.float64).copy()
    m1 = np.zeros(n)
    m2 = np.zeros(n)
    b1, b2, eps = 0.9, 0.999, 1e-8
    step_count = 0
    best_theta = theta.copy()
    
    a_init = softmax_normalize(theta) * S
    best_score = local_score(a_init)
    
    t0 = time.monotonic()
    eval_count = 0
    
    while time.monotonic() - t0 < time_limit:
        elapsed = time.monotonic() - t0
        frac = min(1.0, elapsed / time_limit)
        # Use a smooth transition for tau
        tau = tau_start * (tau_end / tau_start) ** (frac ** 0.7)
        
        a = softmax_normalize(theta) * S
        obj, grad_a, c = compute_objective_and_grad(a, tau)
        
        # Also add exact peak gradient (weighted)
        k_star = int(np.argmax(c))
        peak_grad = np.zeros(n)
        for j in range(n):
            idx = k_star - j
            if 0 <= idx < n:
                peak_grad[j] = 2.0 * a[idx]
        
        # Combine: soft-max grad + alpha * peak grad
        alpha = 0.3
        combined = grad_a + alpha * peak_grad
        
        # Project to maintain sum constraint
        inner = np.dot(a, combined)
        g_theta = a * (combined - inner / S)
        
        step_count += 1
        m1 = b1 * m1 + (1 - b1) * g_theta
        m2 = b2 * m2 + (1 - b2) * (g_theta ** 2)
        m1_hat = m1 / (1.0 - b1 ** step_count)
        m2_hat = m2 / (1.0 - b2 ** step_count)
        
        # Adaptive learning rate
        lr = 1.5 / np.sqrt(step_count + 1)
        theta = theta - lr * m1_hat / (np.sqrt(m2_hat) + eps)
        
        # Evaluate actual score periodically
        eval_count += 1
        if eval_count % 10 == 1:
            a_new = softmax_normalize(theta) * S
            score = local_score(a_new)
            if score < best_score:
                best_score = score
                best_theta = theta.copy()
    
    return best_theta, best_score

def exact_peak_descent(a_init, time_limit, rng):
    """
    Direct descent on the exact peak: at each step, identify the peak lag,
    compute its gradient, and move in the negative gradient direction.
    """
    n = len(a_init)
    S = np.sum(a_init)
    current = a_init.copy()
    current_score = local_score(current)
    best = current.copy()
    best_score = current_score
    t0 = time.monotonic()
    stuck = 0
    
    while time.monotonic() - t0 < time_limit:
        c = fft_convolve(current, current)
        k_star = int(np.argmax(c))
        
        # Gradient of c[k_star] w.r.t. a
        grad = np.zeros(n)
        for j in range(n):
            idx = k_star - j
            if 0 <= idx < n:
                grad[j] = 2.0 * current[idx]
        
        # Project to sum=0: subtract mean
        proj = grad - np.mean(grad)
        
        # Move in negative projected gradient direction
        # Step size: small enough to maintain non-negativity
        eta = 0.001 * S
        # Limit step to avoid going negative
        for j in range(n):
            if proj[j] > 0 and current[j] < eta * proj[j]:
                eta = current[j] / (proj[j] + 1e-15) * 0.99
        
        candidate = current - eta * proj
        candidate = np.clip(candidate, 0, None)
        # Renormalize
        if np.sum(candidate) > 0:
            candidate = candidate * S / np.sum(candidate)
        
        new_score = local_score(candidate)
        if new_score < current_score:
            current = candidate
            current_score = new_score
            stuck = 0
            if current_score < best_score:
                best_score = current_score
                best = current.copy()
        else:
            stuck += 1
            if stuck > 1000:
                # Add randomness to escape
                current = current * np.exp(rng.normal(0, 0.01, n))
                current = np.clip(current, 0, None)
                current = current * S / np.sum(current)
                current_score = local_score(current)
                stuck = 0
    
    return best, best_score

def mass_transfer_search(a_init, time_limit, rng):
    """
    Local search that moves mass from peak contributors to non-contributors.
    """
    n = len(a_init)
    S = np.sum(a_init)
    current = a_init.copy()
    current_score = local_score(current)
    best = current.copy()
    best_score = current_score
    t0 = time.monotonic()
    
    while time.monotonic() - t0 < time_limit:
        c = fft_convolve(current, current)
        # Find top 3 peaks
        peak_indices = np.argsort(c)[-3:]
        
        # For each peak, find top contributors
        top_contribs = np.zeros(n)
        for k_p in peak_indices:
            for j in range(n):
                idx = int(k_p) - j
                if 0 <= idx < n:
                    top_contribs[j] += current[j] * current[idx]
        
        # Split into contributors and non-contributors
        threshold = np.percentile(top_contribs[top_contribs > 0], 70)
        high_idx = np.where(top_contribs > threshold)[0]
        low_idx = np.where(top_contribs <= threshold)[0]
        
        if len(high_idx) == 0 or len(low_idx) == 0:
            break
        
        # Move mass: decrease high, increase low
        n_move = min(len(high_idx), len(low_idx))
        h_sel = rng.choice(high_idx, size=n_move, replace=False)
        l_sel = rng.choice(low_idx, size=n_move, replace=False)
        
        delta = rng.uniform(0.002, 0.01) * S / n
        amounts = rng.dirichlet(np.ones(n_move)) * delta
        
        candidate = current.copy()
        for i in range(n_move):
            dec = amounts[i]
            if candidate[h_sel[i]] > dec:
                candidate[h_sel[i]] -= dec
                candidate[l_sel[i]] += dec
        
        candidate = np.clip(candidate, 0, None)
        candidate = candidate * S / np.sum(candidate)
        
        new_score = local_score(candidate)
        if new_score < current_score:
            current = candidate
            current_score = new_score
            if current_score < best_score:
                best_score = current_score
                best = current.copy()
        elif new_score - current_score < 0.005 and rng.random() < 0.05:
            # Occasional acceptance of slightly worse moves
            current = candidate
            current_score = new_score
    
    return best, best_score

    else:
        start = np.ones(256)
    
    n = len(start)
    S = np.sqrt(2.0 * n)
    
    s = local_score(start)
    print(f"Initial: n={n}, score={s:.6f}")
    best_score = s
    best_seq = start.copy()
    
    # Phase 1: Smooth gradient optimization (50% of time)
    print("\n=== Phase 1: Smooth gradient ===")
    p1_time = (deadline - time.monotonic()) * 0.45
    theta_init = np.log(start / np.sum(start) + 1e-10)
    theta_best, score1 = optimize_smooth(n, theta_init, p1_time, rng)
    a1 = softmax_normalize(theta_best) * S
    s1 = local_score(a1)
    print(f"  Score: {s1:.6f}")
    if s1 < best_score:
        best_score = s1
        best_seq = a1.copy()
