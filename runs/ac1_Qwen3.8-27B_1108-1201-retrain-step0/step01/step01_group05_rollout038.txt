**Key insight I might be missing:**

The problem is equivalent to: find a non-negative vector `a` of length `n` that minimizes `max_k (a ⊛ a)[k] / (sum a)^2`.

This is a "minimax" problem. At the optimum, the KKT conditions imply that the subgradient of `max_k c[k]` is in the span of the constraint gradients (non-negativity and sum).

For the non-negativity constraints, this means that at the optimum, if `a[m] > 0`, then the subgradient component `g[m]` must equal some constant `λ` (the Lagrange multiplier for the sum constraint). If `a[m] = 0`, then `g[m] >= λ` (the non-negativity constraint is active).

So at the optimum: `g[m] = λ` for all `m` with `a[m] > 0`, and `g[m] >= λ` for `m` with `a[m] = 0`.

This means that the subgradient should be "flat" (constant) over the support of `a` at the optimum!

This gives us a useful diagnostic: if the subgradient is not flat over the support of `a`, we're not at the optimum.

**New algorithm: "Flatten the subgradient"**

1. Compute the subgradient `g` (using all lags, or a good approximation).

```python
import numpy as np
import time
from scipy.fft import fft, ifft

def fft_convolve_self(a):
    n = len(a)
    size = 2 * n - 1
    fsize = 1 << (size - 1).bit_length()
    A = fft(a, fsize)
    c = np.real(ifft(A * A))
    return c[:size]

def compute_subgradient_fft(a, w):
    """Compute g[m] = 2 * sum_j a[j] * w[m+j] via FFT."""
    n = len(a)
    w_rev = w[::-1]
    size = 3 * n - 2
    fsize = 1 << (size - 1).bit_length()
    A = fft(a, fsize)
    W = fft(w_rev, fsize)
    conv = np.real(ifft(A * W))
    return 2.0 * conv[n-1 : 2*n-1][::-1]

def project_simplex(v, S):
    n = len(v)
    w = np.sort(v)[::-1]
    cumsum = np.cumsum(w)
    idx = np.arange(1, n + 1, dtype=np.float64)
    theta_candidates = (cumsum - S) / idx
    valid = theta_candidates <= w
    if not np.any(valid):
        rho = n
    else:
        rho = int(np.max(np.where(valid)[0]) + 1)
    theta = (cumsum[rho - 1] - S) / rho
    return np.maximum(v - theta, 0.0)

def mirror_descent_step(a, g, eta, S):
    """Multiplicative weights step with renormalization."""
    a_new = a * np.exp(-eta * g)
    a_new = np.maximum(a_new, 0.0)
    s = a_new.sum()
    if s < 1e-15:
        return np.full(len(a), S / len(a))
    return a_new * (S / s)

def spectral_flatten(a, alpha=0.85, n_rounds=3):
    n = len(a)
    S = a.sum()
    for _ in range(n_rounds):
        size = 2 * n - 1
        fsize = 1 << (size - 1).bit_length()
        A = fft(a, fsize)
        mag = np.abs(A)
        phase = np.exp(1j * np.angle(A))
        new_mag = mag.copy()
        # Compress dynamic range for non-DC components
        new_mag[1:] = mag[1:] ** alpha
        a_new = np.real(ifft(new_mag * phase, fsize))[:n]
        a_new = np.maximum(a_new, 0.0)
        s = a_new.sum()
        if s < 1e-15:
            return a
        a = a_new * (S / s)
    return a
```
