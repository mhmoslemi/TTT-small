## Approach and Rationale

The central idea is to use a hybrid optimization strategy that combines global search and local refinement to find sequences with low autocorrelation. The key limitation is that open-ended exploration in 4096-dimensional space is computationally expensive, so we target sequences with a small number of significant values. We assume the sequence must be non-negative with a positive sum and minimal maximum self-convolution value.

### Mathematical Specification

- **Variables**: A sequence `a` of 4096 non-negative floats with positive sum.
- **Objective**: Minimize `score = 2 * n * max(convolve(a, a)) / (sum(a))^2` where `convolve` is the full convolution.
- **Constraints**: Sum(a) ≥ 0.01, 0 ≤ a_i ≤ 1000.
- **Gradient Computation**: Use a smoothed max surrogate and FFT-based gradient estimation. The gradient is computed by:
  1. Calculating the full convolution `c` of `a` with itself using FFT.
  2. Trimming `c` to its first `2*n - 1` elements.
  3. Applying the `gradient_and_c` function from the previous program to estimate the gradient with temperature `T_factor`.

### Implementation Procedure

1. **Global Search Setup**:
   - Start with an initial sequence `p0` of 4096 uniform values.
   - Perform global search steps using a simplex optimization function with adaptive momentum and learning rates.
   - Track the best score encountered during global search.

2. **Local Refinement**:
   - Switch to local optimization when the global score reaches a threshold (0.49 < score < 1.49).
   - Use projection to enforce non-negativity and normalization.
   - Employ temperature decay and fine-tuning with a budget-aware approach.

3. **Termination Conditions**:
   - Check for large improvements externally scheduled.
   - Use a fallback mechanism if gradient calculations fail.

This approach balances meticulous tracking of global optima with local exploitation, guided by analytics and temperature-sensitive parameters.

        total = np.sum(p_normalized)
        if total < 0.01:
            return optimize_local(p_proj, budget_s)
        return p_normalized / total if total else p_proj*0.49

    # Main optimization sequence
    try:
        results = optimize_local(best_sequence, budget_s)
    except Exception as e:
        # Last-resort fallback mechanism
        best_sequence = np.ones(n_max) * 0.49
        best_score = 2.0 * n_max * max(np.convolve(best_sequence, best_sequence)) / (np.sum(best_sequence))**2
        
    # Post-optimization verification
    return list(best_sequence)

def evaluate_sequence_check(seq):
    try:
        n_seq = len(seq)
        conv_seq = np.convolve(seq, seq)
        max_conv = np.max(conv_seq)
        total_sum = np.sum(seq)
        score = float(2 * n_seq * max_conv / (total_sum**2))
        return score
    except:
        return float('inf')
