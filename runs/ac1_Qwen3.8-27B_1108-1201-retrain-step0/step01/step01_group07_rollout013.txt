For the non-smooth max, we can use subgradient methods or the `Nelder-Mead` method (which doesn't need gradients). But for high-dimensional problems, gradient-based methods are much better.

Actually, for the max function, we can use the following trick:
- The max of a set of values is the solution to a convex optimization: max t subject to t <= x_i for all i.
- The subgradient of max(x) is the uniform distribution over the argmax values (or the point mass at the unique argmax).

For scipy, we can use `scipy.optimize.minimize` with method='L-BFGS-B' and provide the gradient of the soft-max approximation.

def upsample(a, new_n):
    """Upsample a sequence to new length using linear interpolation."""
    old_n = len(a)
    x_old = np.linspace(0, 1, old_n)
    x_new = np.linspace(0, 1, new_n)
    return np.maximum(np.interp(x_new, x_old, a), 0.0)

def init_random(n, seed):
    """Random non-negative initialization."""
    rng = np.random.default_rng(seed)

    """Chirp initialization."""

    return np.maximum(a, 0.0)
