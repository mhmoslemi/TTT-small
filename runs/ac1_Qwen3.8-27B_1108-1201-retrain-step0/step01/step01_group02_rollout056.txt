Idea: Start with a uniform sequence. At each step, identify the lags where the convolution is above average, and "push down" the sequence at positions that contribute most to those lags.

More concretely:

2. Find the lag k* with maximum C[k*].
3. The gradient at k* tells us which positions to decrease: `dC[k*]/da[j] = 2*a[k*-j]`. So positions j where `a[k*-j]` is large should be decreased.
4. Decrement `a[j]` proportional to `a[k*-j]` for the peak lag, and increment other positions.

Let me code up a more efficient approach:

```python
def subgradient_optimize(a, n_steps, lr_schedule):
    a = a / a.sum()  # normalize to sum=1
    for step in range(n_steps):
        lr = lr_schedule(step)
        C = np.convolve(a, a)
        k_star = np.argmax(C)
        # Subgradient of C[k_star] w.r.t. a
        # dC[k_star]/da[j] = 2*a[k_star - j] if 0 <= k_star - j < n, else 0
        # (with special case when k_star = 2j)
        grad = np.zeros_like(a)
        for j in range(n):
            k = k_star - j
            if 0 <= k < n:
                if k_star == 2*j:
                    grad[j] = a[j]
                else:
                    grad[j] = 2*a[k]
        # Projected subgradient step: a <- proj_simplex(a - lr * grad)
        a = a - lr * grad
        # Project to simplex: a >= 0, sum(a) = 1
        a = np.maximum(a, 0)
        a = a / a.sum()
    return a
```

Let me also think about the **soft-max approach** more carefully.

Instead of minimizing `max_k C[k]`, minimize `f_t(a) = (1/t) * log(sum_k exp(t * C[k] / sum(a)^2))` for large t. As t → ∞, this approaches the max.

The gradient of `f_t` with respect to `a[j]` is:
`∂f_t/∂a[j] = sum_k p_k * ∂C[k]/∂a[j] / sum(a)^2 - 2 * f_t * a[j] / sum(a)^2`

where `p_k = exp(t*C[k]/sum(a)^2) / sum_l exp(t*C[l]/sum(a)^2)` are the "softmax weights."

For large t, `p_k` is concentrated on the argmax, recovering the subgradient. For moderate t, it's a weighted average over all lags, giving a smoother direction.

This is a nice approach because:
- It's differentiable (for any finite t).
- We can adaptively adjust t: start with small t (smooth, global view) and increase t (sharp, local refinement).
- The complexity per step is O(n log n) for the convolution + O(n) for the gradient.

Let me also consider the **frequency domain approach**. The convolution `C = a*a` has DFT `DFT(C) = |DFT(a)|^2` (for the circular convolution; for linear convolution, we need zero-padding).

This is a hard constraint in the frequency domain, so I don't think a pure frequency-domain approach will work well.

Let me think about it this way: we want to minimize max_k conv[k] subject to a >= 0, sum(a) = 1, len(a) = n.

This is a convex optimization problem! The objective max_k conv[k] is the maximum of linear functions of a (since each conv[k] is quadratic in a, but... wait, conv[k] = sum a[i]*a[k-i] is quadratic in a, not linear).

Hmm, so it's not convex in general. The constraint set (a >= 0, sum = 1) is convex, but the objective is non-convex (it's the max of quadratic functions).

However, we can use the following trick: introduce variables c_k >= conv[k] for all k, and minimize max c_k subject to c_k >= conv[k], a >= 0, sum(a) = 1. This is an SOCP (second-order cone program) if we relax the quadratic constraints, but actually the constraints c_k >= sum a[i]*a[k-i] are non-convex (they're the epigraph of a quadratic form).

So it's a non-convex optimization problem. We can use:
1. Alternating minimization: fix c, optimize a; fix a, optimize c.
2. Direct non-convex optimization (e.g., interior point, sequential quadratic programming).
3. Heuristic methods (gradient descent, simulated annealing, etc.).

For practical purposes, I think a combination of the following will work well:
1. Start with a good initial guess (modified ramp).
2. Use gradient-based optimization (soft-max smoothing + projected gradient).
3. Use the LP approach for periodic "big steps."
4. Use multiple initializations and lengths.

Let me now think about the specific optimization algorithm in detail.

**Soft-max gradient descent:**

Objective: minimize f(a) = max_k conv[k] subject to a >= 0, sum(a) = 1, len(a) = n.
(Then score = 2n * f(a).)

Soft-smoothed version: f_t(a) = (1/t) * log(sum_k exp(t * conv[k]))

Gradient: ∇f_t(a)_j = sum_k w_k * (∂conv[k]/∂a[j])
where w_k = exp(t*conv[k]) / sum_l exp(t*conv[l])

And ∂conv[k]/∂a[j] = 2*a[k-j] (if 0 <= k-j < n, accounting for the special case k = 2j).

As I derived earlier, this gradient can be computed as a cross-correlation, which is O(n log n) using FFT.

**Algorithm:**
1. Initialize a (e.g., ramp or modified ramp).
2. Set initial temperature t (e.g., t = n/10).
3. For each iteration:
   a. Compute conv = a * a (using FFT).
   b. Compute soft-max weights w_k.
   c. Compute gradient via cross-correlation.
   d. Take a projected gradient step: a ← proj_simplex(a - lr * grad).
   e. Optionally, increase t (anneal).
   f. Check convergence.

**Learning rate:** Use a diminishing schedule, e.g., lr = lr_0 / (1 + alpha * iter).

**Projection onto simplex:** Given x, find τ such that sum_i max(x_i - τ, 0) = 1. Use sorting or binary search.

Wait, I realize I should be more careful. The soft-max objective is:
`f_t(a) = (1/t) * log(sum_k exp(t * conv[k]))`

Its gradient is:
`∂f_t/∂a[j] = sum_k (t * exp(t*conv[k]) / sum_l exp(t*conv[l])) * (1/t) * ∂conv[k]/∂a[j]`
`= sum_k w_k * ∂conv[k]/∂a[j]`
`= 2 * cc[j]` (approximately, where cc is the cross-correlation)

Note: this doesn't include the derivative of w_k with respect to a (i.e., we're using the "fixed weights" gradient). For large t, w is concentrated on the argmax, and the derivative of w is negligible. For small t, this approximation is less accurate, but it still gives a reasonable descent direction.

So the algorithm is:
1. Compute conv = a * a.
2. Compute w = softmax(t * conv).
3. Compute cc = cross_correlation(a, w) (first n components).
4. grad = 2 * cc.
5. a ← proj_simplex(a - lr * grad).

This is very simple and efficient! Each step is O(n log n).

Let me also add the **normalization trick**: since the score is scale-invariant, we can work on the simplex (sum(a) = 1) without loss of generality.

import time

def score_sequence(a):
    n = len(a)
    conv = np.convolve(a, a)
    max_b = conv.max()
    sum_a = a.sum()
    if sum_a < 0.01:
        return float('inf')
    return 2.0 * n * max_b / (sum_a ** 2)

def proj_simplex(v):
    """Project v onto the probability simplex {x >= 0, sum(x) = 1}."""
    n = len(v)
    if n == 0:
        return v
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.where(u * np.arange(1, n+1) > (cssv - 1))[0][-1]
    theta = (cssv[rho] - 1) / (rho + 1.0)
    return np.maximum(v - theta, 0)

def softmax_gradient_step(a, t, lr):
    """One step of soft-max gradient descent on the simplex."""
    n = len(a)
    conv = np.convolve(a, a)
    
    # Soft-max weights
    tc = t * conv
    tc -= tc.max()
    exp_tc = np.exp(tc)
    w = exp_tc / exp_tc.sum()

    L = 2 * (3 * n - 2)  # Use next power of 2 for safety
