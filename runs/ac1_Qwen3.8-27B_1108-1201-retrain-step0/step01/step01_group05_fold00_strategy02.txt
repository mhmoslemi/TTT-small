    # Perform a final set of iterations with a custom learning rate  
    n = len(seq)  
    S = np.sqrt(2 * n)  
    budget_remaining = max(1.0, budget_remaining)   # Ensure minimum budget  
    seq = np.clip(seq, 0.0, 1000.0) / (sum(seq) / S) * S  # Normalize properly

    learning_rate = 0.01 * (S * 0.001)  # Base learning rate, scaled by simplex size

        budget_remaining *= 0.999  # Decay the remaining budget

# 4. Search choices and useful variations  

The primary sequence representation is a one-dimensional array. For the initializations, multiple possibilities exist:  

-   **Given Sequence** from parent (if available).  
-   **Smooth Sequence**: uses sine and cosine waves with base weights.  
-   **Uniform Sequence**: no blocking-like structure.  

The optimization process will proceed in two phases:  

1.  **Exploration Phase**:Attempts 3-4 initial sequence constructions (given, smooth, random) and applies Adam and/or Frank-Wolfe optimization.  

2.  **Refinement Phase**:Polishes the best sequence found with a slow, uniform Adam optimizer and re-validates.  

Key parameters:  

-   `n`: Length of sequence (fourrelet en 2048-8192).  
-   `S`: Simplex normalization constant.  
-   `learning_rate`: Adaptive learning.  
-   `budget_fraction`: Allocation between Adam and Frank-Wolfe (default 0.7 Adam, 0.3 Frank-Wolfe).  

Caller can supply the initial sequence as a keyword argument.  

# 5. Compute budget and robustness  

The dominant portion is the FFT within `evaluate_sequence` and `_convolve`. Each of these is computed on a sequence of length up to `n`, then padded to `2*n-1` points. This step must be repeated for each sequence of coefficients that the optimizer considers.  

The main optimization loop uses `max_time=2400`. It is advised to run at least 5-50 initializations (depending on length) to find the best starting point.  

Continuous monitoring: the function checks the wall time and completes once the budget is exceeded.
