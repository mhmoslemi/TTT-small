The question is: can we find a non-negative sequence where the convolution is more "flat" than the triangular shape of the uniform sequence?

For the uniform sequence, the convolution is triangular: [1, 2, 3, ..., n, n-1, ..., 2, 1].
The maximum is n at the center, and the values decrease linearly toward the edges.

To minimize the maximum, we'd want the convolution to be as flat as possible, ideally constant = S^2/(2n-1) everywhere. But that's impossible for a convolution of a sequence with itself (the convolution of a non-negative sequence always has some structure).

So the problem is: find a non-negative sequence whose auto-convolution is as flat as possible.

This is actually a well-studied problem! It's related to "flat-top" sequences, "minimum peak-to-average power ratio" (PAPR) sequences, and related topics in signal processing.

For the specific case of auto-convolution (not circular), we want:
minimize max_k c[k] subject to a >= 0, sum(a) = S (fixed)

This is equivalent to: minimize max_k c[k] / S where c = a * a (convolution).

The objective 2n*max_b/S^2 = 2n * max_k c[k] / S^2.

Since sum_k c[k] = S^2, we have max_k c[k] >= S^2/(2n-1).

The optimum would be achieved when c[k] is constant = S^2/(2n-1) for all k, giving objective = 2n/(2n-1).

But can we achieve a constant auto-convolution with a non-negative sequence? 

For the uniform sequence, c[k] = k+1 for 0 <= k <= n-1 and c[k] = 2n-1-k for n <= k <= 2n-2. This is the triangular shape.

To make it flatter, we need to reduce the center and increase the edges. But the edges are constrained by the structure of the convolution.

For example, c[0] = a[0]^2 and c[2n-2] = a[n-1]^2. These are always non-negative and can be made small if a[0] and a[n-1] are small.

But c[1] = 2*a[0]*a[1], which is also small if a[0] is small.

So there's a trade-off: making the edges smaller also makes the nearby values smaller, which means the center must be larger to maintain the total sum constraint.

This is the fundamental tension in the problem.

This gives us a spectral perspective: we want |DFT(a)|^2 to be as flat as possible (across the relevant frequencies).

This is similar to the "flat spectrum" or "low PAPR" problem!

For the linear auto-convolution, if we zero-pad a to length 2n-1 and take the DFT:

So we want |DFT(a_padded)|^2 to be as flat as possible.

This is exactly the minimum PAPR problem for the padded sequence!

import numpy as np
import time
from scipy.optimize import linprog
from scipy.fft import fft, ifft

def compute_obj(a):
    n = len(a)
    c = np.convolve(a, a)
    max_c = c.max()
    S = a.sum()
    if S < 0.01:
        return float('inf')
    return 2.0 * n * max_c / (S * S)

def normalize(a, target_sum=None):
    n = len(a)
    if target_sum is None:
        target_sum = np.sqrt(2 * n)
    S = a.sum()
    if S < 1e-12:
        return a
    return a * (target_sum / S)

def spectral_flatten(a, n_iters=500, alpha=0.5):
    """Use SORC-like iterations to flatten the auto-convolution."""
    n = len(a)
    N = 1
    while N < 2*n - 1:
        N *= 2
    a = a.copy().astype(np.float64)
    S = a.sum()
    
    for it in range(n_iters):
        a_pad = np.zeros(N)
        a_pad[:n] = a
        A = fft(a_pad)
        mag = np.abs(A)
        
        # Target: make |A| proportional to Dirichlet kernel
        # For simplicity, use a soft version: target = mean of non-DC mags
        mag_non_dc = mag[1:]
        target = np.median(mag_non_dc)  # use median for robustness
        
        # Modify magnitude (leave DC alone)
        for k in range(1, N):
            if mag[k] > 1e-10:
                factor = (target / mag[k]) ** alpha
                factor = min(factor, 10.0)  # clip to avoid instability
                A[k] *= factor
            else:
                A[k] = 0
        
        a_new = ifft(A).real[:n]
        a = np.maximum(a_new, 0)
        
        # Preserve sum
        S_new = a.sum()
        if S_new > 1e-10:
            a *= S / S_new
        else:
            a = np.ones(n)
            break
    
    return a

def lp_refine(f, M, max_iter=100):
    """LP-based refinement: given f, find g that maximizes sum(g) s.t. f*g <= M, g >= 0."""
    n = len(f)
    if n > 2048:
        return None
    
    c = -np.ones(n)
    A_ub = np.zeros((2*n-1, n))
    for m in range(2*n-1):
        lo = max(0, m - n + 1)
        hi = min(n-1, m)
        for j in range(lo, hi+1):
            A_ub[m, j] = f[m-j]
    
    b_ub = np.full(2*n-1, M)
    bounds = [(0, None)] * n
    
    try:
        res = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')
        if res.status == 0:
            return res.x
    except:
        pass
    return None

def optimize(a0, deadline, use_spectral=True, use_lp=True):
    """Main optimization routine for a single starting sequence."""
    n = len(a0)
    a = np.clip(a0.astype(np.float64), 0, 1000)
    if a.sum() < 1e-6:
        a = np.ones(n)
    a = normalize(a)
    S_target = a.sum()
    
    best = a.copy()
    best_score = compute_obj(a)
    
    # Phase 1: Spectral flattening
    if use_spectral and time.monotonic() < deadline - 60:
        a_spec = spectral_flatten(a, n_iters=300, alpha=0.3)
        s_spec = compute_obj(a_spec)
        if s_spec < best_score:
            best_score = s_spec
            best = a_spec.copy()
        a = best.copy()
    
    # Phase 2: LP-based refinement
    if use_lp and n <= 1024 and time.monotonic() < deadline - 30:
        c = np.convolve(a, a)
        M = c.max()
        
        for it in range(200):
            if time.monotonic() > deadline - 10:
                break
            
            g = lp_refine(a, M)
            if g is None:
                break
            
            g = normalize(g, S_target)
            
            # Try different blend factors
            improved = False
            for t in [1.0, 0.7, 0.5, 0.3, 0.1]:
                a_new = (1-t)*a + t*g
                a_new = np.maximum(a_new, 0)
                a_new = normalize(a_new, S_target)
                s_new = compute_obj(a_new)
                if s_new < best_score * (1 - 1e-6):
                    a = a_new
                    best = a.copy()
                    best_score = s_new
                    improved = True
                    break
            
            if not improved:
                # Gradient step to escape
                c = np.convolve(a, a)
                m_star = c.argmax()
                grad = np.zeros(n)
                lo = max(0, m_star - n + 1)
                hi = min(n-1, m_star)
                for j in range(lo, hi+1):
                    grad[j] = 2.0 * a[m_star - j]
                grad -= grad.mean()
                a = a - 0.01 * grad
                a = np.maximum(a, 0)
                a = normalize(a, S_target)
            
            # Update M
            c = np.convolve(a, a)
            M = c.max()
    
    # Phase 3: Gradient refinement
    if time.monotonic() < deadline - 5:
        for it in range(2000):
            if time.monotonic() > deadline - 3:
                break
            c = np.convolve(a, a)
            m_star = c.argmax()
            grad = np.zeros(n)
            lo = max(0, m_star - n + 1)
            hi = min(n-1, m_star)
            for j in range(lo, hi+1):
                grad[j] = 2.0 * a[m_star - j]
            grad -= grad.mean()
            
            lr = 0.05 * (1 - it/2000) + 0.001
            a = a - lr * grad
            a = np.maximum(a, 0)
            a = normalize(a, S_target)
            
            if (it+1) % 100 == 0:
                s = compute_obj(a)
                if s < best_score:
                    best_score = s
                    best = a.copy()
    
    return best, best_score
