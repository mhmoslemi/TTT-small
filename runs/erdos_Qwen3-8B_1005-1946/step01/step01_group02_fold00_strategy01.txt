The global search will use a random sampling method to explore the solution space, while the local search will use a simulated annealing method to escape local optima. The key innovation is the progressive refinement of the solution and the use of a valid parent solution to ensure feasibility during the optimization process. This approach addresses the bottleneck of getting stuck in local optima by combining exploration at coarser resolutions with exploitation at finer resolutions.

Mathematical specification:
We represent the step function h as a vector of length n_points with values in [0,1] and sum(h) * dx = 1, where dx = 2.0 / n_points. The objective is to minimize:
   C_5 = max_k (np.correlate(h, 1-h, mode='full')) * dx

The optimization is subject to:
   0 <= h[i] <= 1 for all i
   sum(h) * dx = 1

Implementation procedure:
1. Initialization:
   - Set the seed for reproducibility.
   - Start with the provided initial_h_values (n_points=752) if available.
   - If no initial solution is provided, use a random feasible solution:
        h = np.random.uniform(0, 1, n_points)
        scale_factor = (n_points / 2) / np.sum(h)
        h = h * scale_factor
        h = np.clip(h, 0, 1)

2. Global search:
   - Generate a set of random feasible solutions by:
        a. Drawing random values in [0,1] for each point.
        b. Scaling the vector so that sum(h) * dx = 1.
        c. Clipping the values to [0,1].
   - Evaluate the objective for each candidate solution.
   - Track the best solution found.

3. Local search (simulated annealing):
   - Start from the best solution found by the global search.
   - At each step, perturb the solution by adding random noise to a subset of indices.
   - Clip the values to [0,1] and scale to maintain the integral constraint.
   - Accept the new solution if it improves the objective or with a probability based on a temperature schedule.
   - Gradually reduce the temperature.

4. Resolution doubling:
   - Double the resolution (n_points *= 2) and project the best solution from the previous resolution.
   - The projection can be done by interpolation:
        h_new = np.interp(np.linspace(0, 2, n_points), np.linspace(0, 2, n_points//2), h_old)
   - Then, repeat the global search and local search at the new resolution.

5. Termination:
   - If the time budget is exceeded, return the best solution found.

Search choices and useful variations:
   - Global search: Random sampling with 100 evaluations per resolution.
   - Local search: Simulated annealing with 500 evaluations.
   - Neighborhood: Random noise addition to 10% of indices.
   - Temperature schedule: Exponential decay from 100 to 0.1.
   - Resolution progression: Doubling from 752 to 3008 points.

Compute budget and robustness:
   - The dominant cost is the correlation calculation, which is O(n^2) per evaluation.
   - Estimating the time: For n_points=752, one correlation is about 752*1503 ~ 1.1e6 operations, which in Python might take a few seconds. With 100+500 evaluations per resolution, it might take minutes per resolution.
   - We have 3 resolutions (752, 1504, 3008) so total evaluations: 3 * (100+500) = 1800 evaluations, each evaluation taking a few seconds -> total time around 1000 seconds.
