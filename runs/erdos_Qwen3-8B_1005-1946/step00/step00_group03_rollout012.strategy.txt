The core idea is to minimize the maximum overlap integral \( C_5 \) by performing a multi-resolution optimization using a combination of global and local search methods. The initial solution (n=70) is provided, and we aim to escape local optima by exploring the solution space through random bit flips while maintaining the integral constraint. The key bottleneck is the expensive computation of the overlap integral (\(O(n^2)\)), so simulated annealing is used to balance exploration and exploitation. The approach leverages the provided initial solution and allows transitions to higher resolutions (n=140, 280) if time permits, ensuring we don't get stuck in a suboptimal region.

The method is chosen because it handles non-convex optimization without requiring gradient information, making it suitable for discrete, combinatorial problems. The main limitation is the high computational cost for larger grids, but this is mitigated by adaptive cooling and early termination. The strategy is distinct from previous ones by focusing on repair mechanisms and multi-resolution transitions to improve robustness and avoid local minima.

### Mathematical Specification

**Representation**: The step function \( h \) is represented as a binary vector of length \( n_{\text{points}} \) (even) with exactly \( n_{\text{points}}/2 \) ones, representing the step function values.

**Objective**: Minimize \( C_5 = \max_k \int h(x)(1-h(x+k))  dx \), approximated by \( \max(\text{np.correlate}(h, 1-h, \text{mode}="full") \times (2.0/n_{\text{points}}) \).

**Constraints**: \( 0 \leq h[i] \leq 1 \) for all \( i \) and \( \sum h = n_{\text{points}}/2 \).

**Moves**: Two-bit flips (one 0→1 and one 1→0) to maintain the integral constraint.

**Simulated Annealing**: Start with \( T_0 = 10.0 \), cool by factor 0.95 every 100 iterations, accept worse moves with probability \( \exp(-\Delta C_5 / T) \) to escape local optima.

**Resolution Handling**: Use \( n_{\text{points}} \) list \([70, 140, 280]\). For n=70, start from initial_h_values; for others, generate random solutions. Track the best solution across resolutions.

import numpy as np
from scipy.stats import entropy
import time

def repair_solution(h, n):
    s = n / 2.0
    s0 = np.sum(h)
    # Adjust sum
    delta = (s - s0) / n
    h_adj = h + delta
    # Clip to [0,1]
    h_clip = np.clip(h_adj, 0, 1)
    s_clip = np.sum(h_clip)
    residual = s - s_clip
    if abs(residual) < 1e-5:
        return h_clip
    # Increase or decrease to match sum
    if residual > 0:
        # Find indices where h_clip < 1
        mask = h_clip < 1
        if np.sum(mask) == 0:
            return h_clip
        room = 1 - h_clip[mask]
        indices = np.argsort(room)[::-1]
        for i in indices:
            if residual <= 0:
                break
            add = min(room[i], residual)
            h_clip[i] += add
            residual -= add
    else:
        mask = h_clip > 0
        if np.sum(mask) == 0:
            return h_clip
        room = h_clip[mask]
        indices = np.argsort(room)
        for i in indices:
            if residual >= 0:
                break
            subtract = min(room[i], -residual)
            h_clip[i] -= subtract
            residual += subtract
    return h_clip

def objective(h):
    corr = np.correlate(h, 1-h, mode='full')
    return np.max(corr) * (2.0 / len(h))

def run(seed=42, budget_s=1100, **kwargs):
    np.random.seed(seed)
    # Use provided initial_h_values if available
    if 'initial_h_values' in kwargs:
        initial_h = kwargs['initial_h_values']
    else:
        initial_h = None
    
    n_points_list = [70, 140, 280]
    best_c5 = float('inf')
    best_h = None
    best_n = None
    
    for n in n_points_list:
        if n == 70 and initial_h is not None:
            h = initial_h.copy()
        else:
            h = np.random.rand(n)
            h = repair_solution(h, n)
        
        # Compute initial C5
        h_repaired = repair_solution(h, n)
        c5_val = objective(h_repaired)
        best_c5 = c5_val
        best_h = h_repaired
        best_n = n
        
        # Simulated annealing
        T = 10.0
        cooling_rate = 0.95
        max_iter = 1000
        start_time = time.time()
        
        for i in range(max_iter):
            if time.time() - start_time > budget_s:
                break
            
            # Generate neighbor
            indices = np.where(h == 0)[0]
            if len(indices) < 1:
                break
            i1 = np.random.choice(indices)
            indices1 = np.where(h == 1)[0]
            if len(indices1) < 1:
                break
            i2 = np.random.choice(indices1)
            
            # Flip bits
            h[i1] = 1
            h[i2] = 0
            h_repaired = repair_solution(h, n)
            new_c5 = objective(h_repaired)
            
            # Acceptance criterion
            if new_c5 < best_c5:
                best_c5 = new_c5
                best_h = h_repaired
                best_n = n
            else:
                prob = np.exp(-(new_c5 - best_c5) / T)
                if np.random.random() < prob:
                    best_c5 = new_c5
                    best_h = h_repaired
                    best_n = n
            
            # Cool temperature
            T *= cooling_rate
        
        # Early termination if improvement is minimal
        if best_c5 < 0.38085:
            break
    
    # Return best solution
    return best_h, best_c5, best_n
