# Mathematical specification

## Variables
- h ∈ ℝ^{n_points}, with h[i] ∈ [0,1], and ∑h[i] = n_points / 2.
- Objective: C = max_k (h ⋆ (1 - h))[k] * dx, where dx = 2.0 / n_points.
- Search space dimension: n_points.

## Constraints
1. 0 ≤ h[i] ≤ 1 for all i.
2. ∑h[i] = n_points / 2.

## Cross-correlation formulation
The overlap integral for a given shift k is:
$$ C_k = \text{sum}_{i=0}^{n_points-1} h[i] \times (1 - h[(i + k) \% n_points]) \times dx $$

The objective is $ C = \max_k C_k $.

## Feasibility projection
Project h onto feasible region via:
1. Clip h to [0,1].
2. Scale h to meet sum constraint via h = h * (n_points / (2 \times sum(h))).
3. Iterate until feasible.

### 2. Subgradient descent loop
1. **Parameters**:
   - Initial step size: 1.0
   - Step size decay: 0.99
   - Max iterations: 100,000
   - Update frequency check every 500 iterations
2. **Iteration steps**:
   a. Compute cross-correlation: `corr = np.correlate(h, 1 - h, mode="full")`.
   b. Identify maximum overlap and corresponding lags.
   c. Compute subgradient from contributions of all maximum lags.
   d. Update h = h - step_size × subgradient.
   e. Project h onto feasible region via clipping and scaling.
   f. Track best candidate with lowest C.
   g. Adjust step size by decay factor.

### 3. Subgradient computation
For each maximum lag k:
$$ grad_k[j] = (1 - h[(j + k) \% n]) - h[(j - k) \% n] $$
Sum contributions from all active k to form subgradient.

### 4. Feasibility projection
1. Clip h to [0,1].
2. Scale to sum h = n / 2.
3. Repeat until sum constraint satisfied without clippings exceeding 1.

### 5. Termination conditions
1. Time budget exhausted.
2. Max iteration count reached.
3. No improvement in C for 500 iterations.
