For a uniform sequence of length n: each element is `c = sum/n`. The autocorrelation at lag k is `c^2 * (n-|k|)` for `|k| < n`, and 0 otherwise. The max is at lag 0: `c^2 * n = n * (sum/n)^2 = sum^2/n`. So score = `2*n*(sum^2/n)/(sum^2) = 2`. That's why the uniform sequence gives score 2.

The key insight: if we can make the autocorrelation more uniform (flat), the max_b is reduced relative to sum_a^2.
