### Approach and Rationale  
The central idea is to minimize the AC1 upper bound by iteratively refining a non-negative coefficient sequence using gradient-based optimization. Unlike the supplied parent program, which relies solely on random block perturbations, this approach leverages gradient approximation through finite differences to guide improvements. The AC1 bound is defined as \( \frac{2n \cdot \max(\text{convolve}(a, a, \text{mode}="full"))} {(\sum a)^2} \), where the neural sequence is non-negative, with each coefficient in [0, 1000], and the sum being at least 0.01. The rationale for using gradient information is that it provides a data-driven direction for refinement, potentially leading to faster convergence than random methods. This method assumes that the gradient, when approximated numerically, captures meaningful improvements, though the staircase and undefined gradients at multiple maxima points are handled pragmatically. A key limitation is the computational cost of gradient approximation, which involves multiple convolution evaluations per iteration, but the time budget allows for adaptive control. By focusing on block-wise updates guided by gradients, we prioritize robustness and performance on large sequences like the parent sequence (length 4498).

### Mathematical Specification  
- **Variables**:  
  - `a`: A non-negative sequence of length `n`, with coefficients in [0, 1000].  
  - `s`: Sum of coefficients, \( s = \sum a \), must be ≥ 0.01.  
  - `conv(a, a)`: Full convolution result of length `2n-1`, elements indexed from 0 to `2n-1`.  
  - `max_b`: Maximum of `conv(a, a)` elements.  
  - AC1 score: \( \text{score} = \frac{2n \cdot \max_b}{s^2} \).  

- **Objective**: Minimize \( \text{score} \) via gradients derived from the score function.  
  - Gradient of score w.r.t. `a[i]` is approximated using central differences.  
  - Due to non-smoothness (from max operation), gradient is undefined at points where multiple operations achieve `max_b`; these are approximated or ignored.  

- **Family Size**: \( \frac{N}{10} \), where N is the dimension for gradient computation (e.g., 10 indices at a time for partial gradients to save Compute).  
- **Constraints**:  
  - Non-negativity: All `a[i] >= 0`.  
  - Bound: `a[i] <= 1000`.  
  - Sum constraint: \( s \ge 0.01 \).  
- **Implementation Note**: Use gradient descent with step size tuning and directional updates. The gradient is approximated for a subset of indices to balance cost and accuracy, following the steps below.  

### Implementation Procedure  
**1. Initialization**:  
   - Load the parent sequence `height_sequence_1` (if available) from global scope. If not, initialize as a default non-negative sequence (e.g., all elements set to a small value, but ensure sum ≥ 0.01).  
   - Clone the sequence and set initial candidate.  
   - Compute initial score using `evaluate_sequence` to enforce normalization.  
   - Set current best score and best candidate.  

**2. Gradient Computation**:  
   - For a gradient approximation, select a subset of indices (e.g., `top_n = min(500, n)` for large `n` to reduce computations).  
   - For each selected index `i`:  
     - Perform central difference: shift `a[i]` by ±epsilon (e.g., 0.01) to create two new sequences.  
     - Evaluate the score at each shifted sequence iteratively to compute gradient estimate \( \partial \text{score} / \partial a[i] = (S_{+} - S_{-}) / (2 \epsilon) \), where `S_{+}` and `S_{-}` are the scores after +ε and -ε shifts, respectively.  
     - Address undefined gradients (where multiple maxima exist) by ignoring or approximating these indices.  
   - Combine gradients to form a gradient vector; use partial gradients to avoid full O(n) evaluation.  

**3. Update Rules**:  
   - **Gradient Descent Direction**: Use the gradient vector to update `a` with a step-size parameter alpha (e.g., 0.001 to 0.01).  
     - `a_new = a_old - alpha \times \nabla \text{score}`  
   - **Step Size Tuning**: Externally adjust alpha based on Past improvement rate. For example, decrease alpha if insufficient progress.
