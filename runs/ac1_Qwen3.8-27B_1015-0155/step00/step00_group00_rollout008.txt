import numpy as np
import time

def initialize_sine(n, eps):
    """Generate 1 + eps*sin(2*pi*i/n) for i=0..n-1."""
    i = np.arange(n, dtype=np.float64)
    return 1.0 + eps * np.sin(2.0 * np.pi * i / n)

def local_search(best, best_score, rng, deadline):
    """Run local search to improve the score."""
    n = len(best)
    while time.monotonic() < deadline:
        # Generate perturbation
        candidate = best.copy()
        # Perturb a random block
        width = int(rng.integers(max(1, n//500), max(2, n//20)))
        start = int(rng.integers(0, max(1, n - width + 1)))
        stop = min(n, start + width)
        candidate[start:stop] *= float(np.exp(rng.normal(0.0, 0.05)))
        candidate = np.clip(candidate, 0.0, 1000.0)
        score = float(evaluate_sequence(candidate.tolist()))
        if np.isfinite(score) and score < best_score:
            best = candidate
            best_score = score
    return best, best_score

Actually, let me think about what the "right" perturbation is. The subgradient tells us to decrease a_i where (a_{k*-i} + a_{i-k*}) is large, and increase where it's small. For the sine sequence a_i = 1+ε*sin(2πi/n): a_{n-1-i} = 1-ε*sin(2π(i+1)/n). The product a_i * a_{n-1-i} is large where both are large, which is where sin is positive. To reduce the center autocorrelation, we want to make the sequence more "anti-correlated" with its reverse.

One approach: make a_i = 1 + ε*sin(2πi/n + φ) for some phase φ. The center autocorrelation is:

Sum over i: -ε^2*n/2 * cos(2π/n-2φ)

So c[n-1] ≈ n(1-ε^2/2*cos(2π/n-2φ)).

To minimize c[n-1], maximize cos(2π/n-2φ). For φ=π/n: cos(0)=1, c[n-1] ≈ n(1-ε²/2).
