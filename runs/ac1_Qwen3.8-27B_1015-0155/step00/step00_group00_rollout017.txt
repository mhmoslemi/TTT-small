**Simpler approach: Multiplicative update / gradient descent**

The objective is f(a) = max_k (a*a)[k] / (sum(a))^2 (times 2n, but that's constant).

Gradient of (a*a)[k] with respect to a[i]:
∂/∂a[i] [Σ_j a[j]*a[k-j]] = a[k-i] + a[k-i] = 2*a[k-i] (for the first sum) 
Wait, more carefully:
(a*a)[k] = Σ_{j=0}^{n-1} a[j] * a[k-j] (where a[·] = 0 outside [0,n-1])

∂(a*a)[k] / ∂a[i] = a[k-i] + a[k-i] (from the two terms where j=i and k-j=i)
Wait: the terms are a[j]*a[k-j]. Taking derivative w.r.t. a[i]:
- When j = i: derivative is a[k-i]
- When k-j = i, i.e., j = k-i: derivative is a[j] = a[k-i]
- These are the same term if i = k-i, i.e., k = 2i.

So ∂(a*a)[k]/∂a[i] = a[k-i] + a[k-i] = 2*a[k-i] if i ≠ k-i, and a[k-i] + a[k-i]... no.

Let me just do it directly. (a*a)[k] = Σ_j a[j] * a[k-j].
d/d(a[i]) of this = a[k-i] (from the term j=i) + Σ_j (d/d(a[i]) a[k-j]) * a[j]
The second sum: d/d(a[i]) a[k-j] is nonzero only when k-j = i, i.e., j = k-i. Then it contributes a[k-i] * 1.
So total: a[k-i] + a[k-i] = 2*a[k-i], unless k-i = i (i.e., k=2i), in which case we get a[i] + a[i] = 2*a[i] (same formula).

Wait, actually when k = 2i, j = i in both the first and second sum, so we get a[i] + a[i] = 2a[i]. And the formula 2*a[k-i] = 2*a[i] gives the same. So the gradient is simply 2*a[k-i] for all valid (k,i) pairs.

So ∂f/∂a[i] where f = max_k (a*a)[k]:
If we use subgradient: ∂f/∂a[i] = 2*a[k*-i] where k* = argmax.

But we're minimizing f / (sum a)^2, so:
∂(f/(S²))/∂a[i] = (∂f/∂a[i] * S² - f * 2*S) / S⁴ = (∂f/∂a[i] - 2*f/S) / S²

For gradient descent: a[i] -= η * ∂/∂a[i]

This is a simple subgradient method. But it only uses the one max point, which might be too myopic.

**Better: Use softmax approximation**

Instead of max, use a soft-max: F(a) = log(Σ_k exp(β*(a*a)[k]))/β for large β. This is smooth and its gradient is:
∂F/∂a[i] = (1/β) * Σ_k p_k * 2*a[k-i] where p_k = exp(β*(a*a)[k]) / Σ_j exp(β*(a*a)[j])

This gives a weighted gradient from all positions, weighted by how close they are to the max.

For computation: we need the full conv (O(n) values), then compute p_k (O(n)), then for each i, compute Σ_k p_k * a[k-i] which is a convolution of p with a, i.e., FFT-based O(n log n).

Total per iteration: O(n log n) for conv + O(n log n) for the gradient conv = O(n log n).

import numpy as np
import time


def fft_convolve(a, b):
    """Full linear convolution via FFT, O(n log n)."""
    n_out = len(a) + len(b) - 1
    N = 1
    while N < n_out:
        N <<= 1
    fa = np.fft.rfft(a, N)
    fb = np.fft.rfft(b, N)
    return np.fft.irfft(fa * fb, N)[:n_out]


def cross_corr_grad(a, p):
    """g[i] = sum_j a[j]*p[i+j] via FFT. a: len n, p: len 2n-1."""
    n = len(a)
    q = p[::-1]
    r = fft_convolve(a, q)
    idx = 2 * n - 2 - np.arange(n)
    return r[idx].copy()
