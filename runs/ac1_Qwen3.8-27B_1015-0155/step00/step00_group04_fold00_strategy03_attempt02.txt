1. Approach and Rationale

The central idea of this strategy is to use a sequence update mechanism based on solving a linear program (LP) to find a "correlation-reducing" direction. Unlike previous stochastic mutation or gradient-free methods, this approach explicitly iteratively improves the sequence by finding directions that decrease the maximum autocorrelation, as measured by the AC1 upper bound. The method leverages the L_infinity constraint from full convolution, offering a structured, optimization-driven convergence toward a lower score. This method is derived from a state of the art math- ematical approach, adapted to be computationally efficient by using a sparse or matrix-free LP setup, avoiding dense matrix operations. This differs substantively from earlier strategies by focusing on direction-based updates through LP solutions, which can systematically reduce the score, instead of relying on random mutations or approximating gradients with expensive finite-difference methods. The key advantage is faster convergence, as each update step targets binding constraints directly. However, this approach may get stuck in local minima if the feasible set is complex, and it requires careful handling of summation bounds and non-negative constraints to avoid invalid candidates. The iteration is adaptive, stopping when self-similarity is detected, ensuring a balance between speed and optimality.

2. Mathematical Specification

- Representation: The sequence is represented as a real-valued array a ∈ ℝⁿ, with components a_i ≥ 0 for all i, bounded by 0 ≤ a_i ≤ 1000, and the total sum S = ∥a∥₁ ≥ 0.01. The AC1 score is given by σ(a) = 2n / (S²) * max_k (convolve(a, a)[k]).

- Objective: Minimize the actual AC1 upper bound σ(a), not the normalized version from the state of the art, by optimizing the score directly.
