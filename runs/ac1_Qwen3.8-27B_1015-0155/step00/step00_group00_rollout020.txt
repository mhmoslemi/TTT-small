import numpy as np
import time


def my_conv(a):
    """Full linear convolution via FFT."""
    n = len(a)
    m = 2 * n - 1
    size = 1 << (m - 1).bit_length()
    fa = np.fft.rfft(a, size)
    return np.fft.irfft(fa * fa, size)[:m]


def subgrad_at_k(a, k):
    """Subgradient of c[k] = conv(a,a)[k] w.r.t. a."""
    n = len(a)
    g = np.zeros(n)
    if k < n:
        g[:k + 1] = 2.0 * a[k::-1]
    else:
        j0 = k - n + 1
        g[j0:] = 2.0 * a[n - 1:j0 - 1:-1]
    return g


def compute_subgradient(a, c, n, tol_frac=0.02):

    weights /= weights.sum()

        g += weights[int(np.where(c >= threshold)[0].tolist().index(k_idx))] * subgrad_at_k(a, int(k_idx))

    g = np.zeros(n)

Wait, there's an issue. The subgradient computation in a loop over active lags is O(|active| * n). If active is large (say n/2 lags), this is O(n^2) per iteration. For n=4806, that's about 11.5 million operations per subgradient computation. With 100k iterations, that's 1.15 trillion operations. Way too slow.

I need to make this O(n) per iteration. The subgradient for a single k is O(n) (just a shifted copy of a). But summing over many active lags is O(n * |active|).

Alternative: compute the subgradient more efficiently. Note that:
g[i] = (1/|A|) * sum_{k in A} 2*a[k-i] (for valid k-i)

This is a "smeared" version of a, where the smear is determined by the active set. If the active set is a contiguous block [k_min, k_max], then:
g[i] = 2 * sum_{k=k_min}^{k_max} a[k-i] / |A| (for valid k-i)
= 2 * (sum_{j: j in [k_min-i, k_max-i], j in [0,n-1]} a[j]) / |A|

This is a "windowed sum" of a, which can be computed in O(n) using a cumsum (prefix sum)!

Let me reformulate. For a contiguous active set [k0, k1] (a range of lags):
g[i] = 2 * (sum_{k=k0}^{k1} a[k-i]) / (k1-k0+1) (for valid k-i)

The inner sum is: sum_j a[j] where j = k-i, k in [k0,k1], so j in [k0-i, k1-i] ∩ [0, n-1].

This is: prefix_sum[min(n, k1-i+1)] - prefix_sum[max(0, k0-i)]

where prefix_sum[j] = sum_{t=0}^{j-1} a[t].
