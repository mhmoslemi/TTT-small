3. If the smooth max value didn't decrease, halve the step
4. Repeat until decrease

But this still has the issue that the smooth max is not exactly the max. For the final polish, we want to minimize the actual max.

For the actual max, we can use the **subgradient** (which is a convex combination of the gradients of the active components). At the optimum, the subgradient should be "balanced" in the sense that no single active component's gradient points in a strongly downward direction for the max.
