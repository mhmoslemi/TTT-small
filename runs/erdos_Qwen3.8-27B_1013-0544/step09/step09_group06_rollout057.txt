∂/∂h[j] of this = (1-h[j+m-(n-1)]) if j+m-(n-1) is a valid index for h
                   - h[m-(n-1)] if j is a valid index (i.e., j in [0,n-1], which it always is)
                   
Wait, that's not right either. Let me be very explicit.

Let A = h (length n), B = 1-h (length n).
correlate(A,B)[m] = Σ_{i: 0≤i<n, 0≤i+m-(n-1)<n} A[i+m-(n-1)] * B[i]

Let me write j = i+m-(n-1), so i = j-m+(n-1).
correlate(A,B)[m] = Σ_{j: 0≤j<n, 0≤j-m+(n-1)<n} A[j] * B[j-m+(n-1)]

∂/∂A[j'] of correlate(A,B)[m]:
- From A[j] = A[j']: contributes B[j'-m+(n-1)] if j'-m+(n-1) is valid (0 ≤ j'-m+(n-1) < n)
- From B[j-m+(n-1)] = B[j']: A[j'+m-(n-1)] * ∂B[j']/∂A[j'] = A[j'+m-(n-1)] * (-1) if j'+m-(n-1) is valid

Since B = 1-A, ∂B[i]/∂A[j] = -δ_{ij}.

So ∂correlate(A,B)[m]/∂A[j] = B[j-m+(n-1)] * 1_{valid} - A[j+m-(n-1)] * 1_{valid}
                              = (1-A[j-m+(n-1)]) * 1_{0≤j-m+(n-1)<n} - A[j+m-(n-1)] * 1_{0≤j+m-(n-1)<n}

This is the gradient of the m-th correlation w.r.t. h[j].

For the max, the subgradient is the gradient of an active (maximizing) correlation.

So the subgradient method would be:
1. Compute all correlations c[m]
2. Find active set: {m : c[m] ≈ max(c)}
3. Compute gradient: g[j] = mean over active m of ∂c[m]/∂h[j]
4. Update: h = h - step_size * g
5. Project to feasible set

This is O(n²) per iteration (to compute all correlations and the gradient), but each iteration is simple.

Actually, computing the gradient for a single m is O(n), and we need to do it for |active| values of m. If the active set is small (say 5-20), this is fast.

Let me also think about the **mirror descent** approach. Since we have box constraints (0 ≤ h ≤ 1) and a linear equality constraint (sum h = n/2), we can use:

- Or just Euclidean projection (simpler)

For the Euclidean case, the update is:
h_new = proj_feasible(h - α * g)

where proj_feasible clips to [0,1] and adjusts to satisfy the sum constraint.

The step size α can be chosen via backtracking line search.

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h, n):
    dx = 2.0 / n
    return float(np.max(np.correlate(h, 1.0 - h, mode='full')) * dx)

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h.copy(), 0.0, 1.0)
    for _ in range(500):
        diff = target - h.sum()
        if abs(diff) < 1e-15:
            break
        if diff > 0:
            room = 1.0 - h
            tot = room.sum()
            if tot < 1e-14:
                break
            h += (diff / tot) * room
        else:
            tot = h.sum()
            if tot < 1e-14:
                break
            h += (diff / tot) * h
    return np.clip(h, 0.0, 1.0)

def compute_correlations(h, n):
    return np.correlate(h, 1.0 - h, mode='full')

def grad_active(h, n, active_set):
    """Compute gradient of max correlation (averaged over active set)."""
    grad = np.zeros(n)
    for m in active_set:
        # ∂c[m]/∂h[j] = (1-h[j-m+(n-1)]) * 1_{valid} - h[j+m-(n-1)] * 1_{valid}
        # For j in range(n):
        #   first term valid when 0 <= j-m+(n-1) < n, i.e., m-(n-1) <= j < m-(n-1)+n = m+1
        #   second term valid when 0 <= j+m-(n-1) < n, i.e., (n-1)-m <= j < (n-1)-m+n = 2n-1-m
        idx1_lo = max(0, m - (n-1))
        idx1_hi = min(n, m + 1)
        idx2_lo = max(0, (n-1) - m)
        idx2_hi = min(n, 2*n-1-m)
        
        if idx1_hi > idx1_lo:
            j = np.arange(idx1_lo, idx1_hi)
            grad[j] += (1.0 - h[j - m + (n-1)])
        if idx2_hi > idx2_lo:
            j = np.arange(idx2_lo, idx2_hi)
            grad[j] -= h[j + m - (n-1)]
    grad /= len(active_set)
    return grad

def subgrad_fista(h, n, deadline, alpha_init=0.01, max_iter=50000):
    """FISTA with subgradient of max correlation."""
    h = h.copy()
    x = h.copy()
    t = 1.0
    alpha = alpha_init
    best_h = h.copy()
    best_c = compute_c5(h, n)
    
    for it in range(max_iter):
        if time.time() > deadline:
            break
        c = compute_correlations(h, n)
        cur_max = c.max()
        
        # Find active set (correlations within tolerance of max)
        tol = max(1e-6, 0.01 * cur_max)
        active_mask = c >= cur_max - tol
        active_set = np.where(active_mask)[0]
        
        if len(active_set) == 0:
            active_set = np.array([np.argmax(c)])
        # Limit active set size for efficiency
        if len(active_set) > 50:
            top_active = np.argsort(c[active_set])[::-1][:50]
            active_set = active_set[top_active]
        
        g = grad_active(h, n, active_set)
        
        # FISTA update
        y = x + ((t - 1) / (t + 1)) * (x - h) if it > 0 else x.copy()
        h_new = project_feasible(y - alpha * g, n)
        
        # Adaptive step size (reduce if no improvement)
        c_new = compute_c5(h_new, n)
        if c_new < best_c - 1e-12:
            best_h = h_new.copy()
            best_c = c_new
            # Optionally increase alpha slightly
            alpha *= 1.01
        elif c_new > best_c:
            alpha *= 0.8
        else:
            alpha *= 0.95
        
        t_next = (1.0 + np.sqrt(1.0 + 4.0 * t * t)) / 2.0
        x = h
        h = h_new
        t = t_next
    
    return best_h, best_c

**Approach: Alternating minimization with active set**

2. For the top T correlations, compute the gradient w.r.t. each h[j].
3. Solve a small QP: min_h (max of top T correlations) ≈ min_h Σ_{m in top} w_m * c_m(h)

4. Project to feasible set.

The QP in step 3 can be solved efficiently since it's a small problem.

The first term is linear, the second is quadratic (a special structured quadratic form).

This is a quadratic form: h^T Q h + c^T h where Q is a structured (banded) matrix.

    best_h = h.copy()
    best_c = compute_c5(h, n)
    
    for it in range(1000000):

        cur_max = c.max()

        active = np.argsort(c)[::-1][:top_k]

Wait, that's only the linear part. The quadratic part: if we write h[j] → h[j]+δ, then:
- In the term h[i]*(1-h[i+m-n+1]): if i = j+m-n+1 (the h[j] appears in the first factor), the change is δ*(1-h[i]) = δ*(1-h[j])... no wait.

Let me be very explicit. c[m] = Σ_i h[i] * (1-h[i+m-n+1])

If h[j] → h[j]+δ:
- Terms where i = j: h[j]*(1-h[j+m-n+1]) → (h[j]+δ)*(1-h[j+m-n+1]), change = δ*(1-h[j+m-n+1])
- Terms where i+m-n+1 = j, i.e., i = j-m+n-1: h[j-m+n-1]*(1-h[j]) → h[j-m+n-1]*(1-h[j]-δ), change = -δ*h[j-m+n-1]

So Δc[m] = δ*(1-h[j+m-n+1]) - δ*h[j-m+n-1] (both terms with validity checks)

This is LINEAR in δ! There's no quadratic term because the two occurrences of h[j] (as a factor and as part of (1-h)) are in different terms of the sum.

Wait, unless j appears as BOTH i AND i+m-n+1 in the same term. That would require j = i AND j = i+m-n+1, which means m = n-1. So for m = n-1 (the "diagonal"), we have:
c[n-1] = Σ_i h[i]*(1-h[i]) = Σ_i h[i] - Σ_i h[i]²

In this case, changing h[j] by δ:
Δc[n-1] = δ - 2*h[j]*δ - δ²

So there IS a quadratic term for the diagonal!

For m ≠ n-1, the change is linear in δ.

This is a crucial insight! For non-diagonal correlations, the objective is piecewise linear in each coordinate (when others are fixed). Only the diagonal (m=n-1) has a quadratic term.

This means the single-coordinate subproblem is:
min_{δ} max(
  max_{m≠n-1, m in top} (c[m] + δ * a_m),  // piecewise linear
  c[n-1] + δ * b + δ²  // quadratic (if diagonal is active)
)
subject to -h[j] ≤ δ ≤ 1-h[j]

This is a 1D minimax of linear and quadratic functions, which can be solved in closed form!

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h, n):
    dx = 2.0 / n
    return float(np.max(np.correlate(h, 1.0 - h, mode='full')) * dx)

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h.copy(), 0.0, 1.0)
    for _ in range(500):
        diff = target - h.sum()
        if abs(diff) < 1e-15:
            break
        if diff > 0:
            room = 1.0 - h
            tot = room.sum()
            if tot < 1e-14:
                break
            h += (diff / tot) * room
        else:
            tot = h.sum()
            if tot < 1e-14:
                break
            h += (diff / tot) * h
    return np.clip(h, 0.0, 1.0)

def get_gradient(h, n, top_k=20):
    """Gradient of max correlation, averaged over top-k active set."""
    c = np.correlate(h, 1.0 - h, mode='full')
    active = np.argsort(c)[::-1][:top_k]
    g = np.zeros(n)
    nm1 = n - 1
    for m in active:
        # ∂c[m]/∂h[j] for j in range(n):
        # (1-h[j-m+nm1]) if 0<=j-m+nm1<n, minus h[j+m-nm1] if 0<=j+m-nm1<n
        lo1 = max(0, m - nm1)
        hi1 = min(n, m + 1)
        if hi1 > lo1:
            j = np.arange(lo1, hi1)
            g[j] += (1.0 - h[j - m + nm1])
        lo2 = max(0, nm1 - m)
        hi2 = min(n, 2 * n - 1 - m)
        if hi2 > lo2:
            j = np.arange(lo2, hi2)
            g[j] -= h[j + m - nm1]
    g /= len(active)
    return g, c

def grad_momentum(h, n, deadline, lr=0.005, momentum=0.9, top_k=20, decay=0.9999):
    h = h.copy()
    v = np.zeros(n)
    best_h = h.copy()
    best_c = compute_c5(h, n)
    lr_cur = lr
    for it in range(10000000):
        if time.time() > deadline:
            break
        g, c = get_gradient(h, n, top_k)
        v = momentum * v - lr_cur * g
        h_new = project_feasible(h + v, n)
        c_new = compute_c5(h_new, n)
        if c_new < best_c:
            best_c = c_new
            best_h = h_new.copy()
        h = h_new
        lr_cur *= decay
    return best_h, best_c

def solve_1d_d(c_peak, a_coeff, diag_idx, unaff_max, lo, hi):
    """Solve 1D minimax: min_d max(max(c_peak + d*a), c_diag + d*b + d^2, unaff_max)"""
    T = len(c_peak)
    candidates = [lo, hi]
    for i in range(T):
        for j in range(i + 1, T):
            if i == diag_idx or j == diag_idx:
                continue
            da = a_coeff[i] - a_coeff[j]
            if abs(da) > 1e-15:
                d = (c_peak[j] - c_peak[i]) / da
                if lo <= d <= hi:
                    candidates.append(d)
    if diag_idx is not None:
        for i in range(T):
            if i == diag_idx:
                continue
            B = -(a_coeff[diag_idx] - a_coeff[i])
            C = -(c_peak[diag_idx] - c_peak[i])
            disc = B * B - 4.0 * C
            if disc >= 0:
                sq = np.sqrt(disc)
                d1 = (-B + sq) / 2.0
                d2 = (-B - sq) / 2.0
                if lo <= d1 <= hi:
                    candidates.append(d1)
                if lo <= d2 <= hi:
                    candidates.append(d2)
    for i in range(T):
        if abs(a_coeff[i]) > 1e-15:
            d = (unaff_max - c_peak[i]) / a_coeff[i]
            if lo <= d <= hi:
                candidates.append(d)
    best_d = lo
    best_val = float('inf')
    for d in candidates:
        d = float(np.clip(d, lo, hi))
        vals = c_peak + d * a_coeff
        if diag_idx is not None:
            vals[diag_idx] -= d * d
        v = max(float(vals.max()), unaff_max)
        if v < best_val:
            best_val = v
            best_d = d
    return best_d, best_val

def multi_cd(h, n, max_passes, deadline, top_k):
    h = h.copy()
    for _ in range(max_passes):
        if time.time() > deadline:
            break
        c = np.correlate(h, 1.0 - h, mode='full')
        current_max = float(c.max())
        k = min(top_k, 2 * n - 1)
        top_idx = np.argsort(c)[::-1][:k]
        c_peak = c[top_idx].astype(float)
        mask = np.ones(2 * n - 1, dtype=bool)
        mask[top_idx] = False
        unaff_max = float(c[mask].max()) if mask.any() else 0.0
        improved = False
        for p in range(n):
            if time.time() > deadline:
                break
            h0 = h[p]
            if h0 < 1e-12 or h0 > 1.0 - 1e-12:
                continue
            a_coeff = np.zeros(k)
            diag_idx = None
            nm1 = n - 1
            for idx in range(k):
                m = int(top_idx[idx])
                jf = p + m - nm1
                jb = p - m + nm1
                af = (1.0 - h[jf]) if 0 <= jf < n else 0.0
                ab = (-h[jb]) if 0 <= jb < n else 0.0
                a_coeff[idx] = af + ab
                if m == nm1:
                    diag_idx = idx
            lo = -h0
            hi = 1.0 - h0
            best_d, best_val = solve_1d_d(c_peak, a_coeff, diag_idx, unaff_max, lo, hi)
            if best_val < current_max - 1e-14:
                h[p] = float(np.clip(h0 + best_d, 0.0, 1.0))
                improved = True
                current_max = best_val
        if not improved:
            break
        h = project_feasible(h, n)
    return h, compute_c5(h, n)

def smooth_max(h, n, beta):
    c = np.correlate(h, 1.0 - h, mode='full')
    m = c.max()
    s = beta * (c - m)
    mx = s.max()
    lse = mx + np.log(np.sum(np.exp(s - mx)))
    return (m + lse / beta) * (2.0 / n)

def smooth_max_grad(h, n, beta):
    c = np.correlate(h, 1.0 - h, mode='full')
    m = c.max()
    s = beta * (c - m)
    mx = s.max()
    e = np.exp(s - mx)
    w = e / e.sum()  # softmax weights
    # Gradient is weighted average of individual gradients
    g = np.zeros(n)
    nm1 = n - 1
    for idx in range(len(w)):
        m_val = idx
        wi = w[idx]
        if wi < 1e-10:
            continue
        lo1 = max(0, m_val - nm1)
        hi1 = min(n, m_val + 1)
        if hi1 > lo1:
            j = np.arange(lo1, hi1)
            g[j] += wi * (1.0 - h[j - m_val + nm1])
        lo2 = max(0, nm1 - m_val)
        hi2 = min(n, 2 * n - 1 - m_val)
        if hi2 > lo2:
            j = np.arange(lo2, hi2)
            g[j] -= wi * h[j + m_val - nm1]
    return g * (2.0 / n)

def slbfgs(h, n, beta, deadline, maxiter=200):
    """L-BFGS-B on smooth max with integral constraint handled by reparameterization."""
    # Use logit parameterization to handle bounds
    # theta -> h = sigmoid(theta), but we need sum constraint
    # Instead, just use L-BFGS-B with bounds and a penalty for the sum
    
    def obj(x):
        hx = project_feasible(x, n)
        return smooth_max(hx, n, beta)
    
    def obj_grad(x):
        hx = project_feasible(x, n)
        g = smooth_max_grad(hx, n, beta)
        # Jacobian of projection is approximate; use straight-through
        return g
    
    bounds = [(0.0, 1.0)] * n
    try:
        res = minimize(obj, h, jac=obj_grad, method='L-BFGS-B',
                       bounds=bounds, options={'maxiter': maxiter, 'ftol': 1e-18})
        new_h = project_feasible(res.x, n)
        return new_h, compute_c5(new_h, n)
    except:
        return h, compute_c5(h, n)

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h, n):
    dx = 2.0 / n
    return float(np.max(np.correlate(h, 1.0 - h, mode='full')) * dx)

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h.copy(), 0.0, 1.0)
    for _ in range(500):
        diff = target - h.sum()
        if abs(diff) < 1e-15:
            break
        if diff > 0:
            room = 1.0 - h
            tot = room.sum()
            if tot < 1e-14:
                break
            h += (diff / tot) * room
        else:
            tot = h.sum()
            if tot < 1e-14:
                break
            h += (diff / tot) * h
    return np.clip(h, 0.0, 1.0)

def smooth_gradient(h, n, beta):
    """Gradient of smooth max of correlations using softmax weights."""
    c = np.correlate(h, 1.0 - h, mode='full')
    m = c.max()
    s = beta * (c - m)
    mx = s.max()
    e = np.exp(s - mx)
    w = e / e.sum()
    g = np.zeros(n)
    nm1 = n - 1
    for idx in range(len(w)):
        wi = w[idx]
        if wi < 1e-8:
            continue
        mv = idx
        lo1 = max(0, mv - nm1)
        hi1 = min(n, mv + 1)
        if hi1 > lo1:
            j = np.arange(lo1, hi1)
            g[j] += wi * (1.0 - h[j - mv + nm1])
        lo2 = max(0, nm1 - mv)
        hi2 = min(n, 2 * n - 1 - mv)
        if hi2 > lo2:
            j = np.arange(lo2, hi2)
            g[j] -= wi * h[j + mv - nm1]
    return g * (2.0 / n)

def grad_momentum(h, n, deadline, lr=0.01, momentum=0.93, beta=100, decay=0.99995):
    h = h.copy()
    v = np.zeros(n)
    best_h = h.copy()
    best_c = compute_c5(h, n)
    lr_cur = lr
    stall = 0
    for it in range(20000000):
        if time.time() > deadline:
            break
        g = smooth_gradient(h, n, beta)
        v = momentum * v - lr_cur * g
        h_new = project_feasible(h + v, n)
        c_new = compute_c5(h_new, n)
        if c_new < best_c - 1e-14:
            best_c = c_new
            best_h = h_new.copy()
            stall = 0
        else:
            stall += 1
            if stall > 200:
                lr_cur *= 0.9
                stall = 0
        h = h_new
        lr_cur *= decay
    return best_h, best_c

def solve_1d_d(c_peak, a_coeff, diag_idx, unaff_max, lo, hi):
    T = len(c_peak)
    candidates = [lo, hi]
    for i in range(T):
        for j in range(i + 1, T):
            if i == diag_idx or j == diag_idx:
                continue
            da = a_coeff[i] - a_coeff[j]
            if abs(da) > 1e-15:
                d = (c_peak[j] - c_peak[i]) / da
                if lo <= d <= hi:
                    candidates.append(d)
    if diag_idx is not None:
        for i in range(T):
            if i == diag_idx:
                continue
            B = -(a_coeff[diag_idx] - a_coeff[i])
            C = -(c_peak[diag_idx] - c_peak[i])
            disc = B * B - 4.0 * C
            if disc >= 0:
                sq = np.sqrt(disc)
                d1 = (-B + sq) / 2.0
                d2 = (-B - sq) / 2.0
                if lo <= d1 <= hi:
                    candidates.append(d1)
                if lo <= d2 <= hi:
                    candidates.append(d2)
    for i in range(T):
        if abs(a_coeff[i]) > 1e-15:
            d = (unaff_max - c_peak[i]) / a_coeff[i]
            if lo <= d <= hi:
                candidates.append(d)
    best_d = lo
    best_val = float('inf')
    for d in candidates:
        d = float(np.clip(d, lo, hi))
        vals = c_peak + d * a_coeff
        if diag_idx is not None:
            vals[diag_idx] -= d * d
        v = max(float(vals.max()), unaff_max)
        if v < best_val:
            best_val = v
            best_d = d
    return best_d, best_val

def multi_cd(h, n, max_passes, deadline, top_k):

    for _ in range(max_passes):
        if time.time() > deadline:
            break
        c = np.correlate(h, 1.0 - h, mode='full')
        current_max = float(c.max())
        k = min(top_k, 2 * n - 1)
        top_idx = np.argsort(c)[::-1][:k]
        c_peak = c[top_idx].astype(float)
        mask = np.ones(2 * n - 1, dtype=bool)
        mask[top_idx] = False
        unaff_max = float(c[mask].max()) if mask.any() else 0.0
        improved = False
        for p in range(n):
            if time.time() > deadline:
                break
            h0 = h[p]
            if h0 < 1e-12 or h0 > 1.0 - 1e-12:
                continue
            a_coeff = np.zeros(k)
            diag_idx = None
            nm1 = n - 1
            for idx in range(k):
                m = int(top_idx[idx])
                jf = p + m - nm1
                jb = p - m + nm1
                af = (1.0 - h[jf]) if 0 <= jf < n else 0.0
                ab = (-h[jb]) if 0 <= jb < n else 0.0
                a_coeff[idx] = af + ab
                if m == nm1:
                    diag_idx = idx
            lo = -h0
            hi = 1.0 - h0
            best_d, best_val = solve_1d_d(c_peak, a_coeff, diag_idx, unaff_max, lo, hi)
            if best_val < current_max - 1e-14:
                h[p] = float(np.clip(h0 + best_d, 0.0, 1.0))
                improved = True
                current_max = best_val
        if not improved:
            break
        h = project_feasible(h, n)
    return h, compute_c5(h, n)

def block_cd(h, n, block_size, max_passes, deadline, top_k, rng):
    """Block coordinate descent: optimize B consecutive coordinates together."""
    h = h.copy()
    for _ in range(max_passes):

            break
        c = np.correlate(h, 1.0 - h, mode='full')
        current_max = float(c.max())

        mask = np.ones(2 * n - 1, dtype=bool)
        mask[top_idx] = False
        unaff_max = float(c[mask].max()) if mask.any() else 0.0
        nm1 = n - 1
        improved = False
        for start in range(0, n, block_size):
            if time.time() > deadline:
                break
            end = min(start + block_size, n)
            idx = np.arange(start, end)
            h0 = h[idx].copy()
            if np.all(h0 < 1e-10) or np.all(h0 > 1.0 - 1e-10):
                continue
            # Try several random directions + coordinate directions
            directions = []
            for j in range(len(idx)):
                d = np.zeros(len(idx))
                d[j] = 1.0
                directions.append(d)
            for _ in range(2):
                d = rng.uniform(-1, 1, len(idx))
                d /= (np.linalg.norm(d) + 1e-15)
                directions.append(d)
            best_val = current_max
            best_delta = None
            for d in directions:
                d_pos = np.maximum(d, 0)
                d_neg = np.maximum(-d, 0)
                lo = 0.0
                hi_pos = np.min((1.0 - h0) / d_pos) if d_pos.any() else np.inf
                hi_neg = np.min(h0 / d_neg) if d_neg.any() else np.inf

                    if v < best_val:

                        best_delta = t * d
            if best_delta is not None and best_val < current_max - 1e-14:
