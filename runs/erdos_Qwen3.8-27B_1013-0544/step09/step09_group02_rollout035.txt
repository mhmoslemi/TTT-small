def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h.copy(), 0.0, 1.0)
    for _ in range(300):
        diff = target - h.sum()
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            room = 1.0 - h
            tot = room.sum()
            if tot < 1e-15:
                break
            h += (diff / tot) * room
        else:
            tot = h.sum()
            if tot < 1e-15:
                break
            h += (diff / tot) * h
    return np.clip(h, 0.0, 1.0)

def exact_coord_delta(h, p, c, n):
    h0 = h[p]
    if h0 <= 1e-12 or h0 >= 1.0 - 1e-12:
        return 0.0
    mlo = max(0, n - 1 - p)
    mhi = min(2 * n - 2, max(2 * n - 2 - p, p + n - 1))
    ms = np.arange(mlo, mhi + 1)
    jf = p + ms - (n - 1)
    jb = p - ms + (n - 1)
    vf = (jf >= 0) & (jf < n)
    vb = (jb >= 0) & (jb < n)
    vec = np.zeros(len(ms))
    if np.any(vf):
        vec[vf] += 1.0 - h[jf[vf]]
    if np.any(vb):
        vec[vb] -= h[jb[vb]]
    c_sub = c[mlo:mhi + 1]
    unaff = 0.0

        unaff = max(unaff, float(c[:mlo].max()))
    if mhi < 2 * n - 2:

    lo, hi = -h0, 1.0 - h0

        if mval <= unaff + 1e-14:

```python
def smooth_max_grad(h, n, alpha):
    c = np.correlate(h, 1-h, 'full')
    shifted = alpha * (c - c.max())
    p = np.exp(shifted)
    p /= p.sum()
    grad = np.zeros(n)
    one_minus_h = 1.0 - h
    for i in range(n):
        # First term: sum_k p[k] * (1-h)[i+k-(n-1)] for valid indices
        k_range1_lo = max(0, n-1-i)
        k_range1_hi = min(2*n-2, n-1+i)
        j_idx1 = i + np.arange(k_range1_lo, k_range1_hi+1) - (n-1)
        # j_idx1 should be in [0, n-1]
        grad[i] += np.dot(p[k_range1_lo:k_range1_hi+1], one_minus_h[j_idx1])
        
        # Second term: sum_k p[k] * h[i-k+(n-1)] for valid indices
        k_range2_lo = max(0, i-(n-1))  # = 0 since i < n
        k_range2_hi = min(2*n-2, i+n-1)
        j_idx2 = i - np.arange(k_range2_lo, k_range2_hi+1) + (n-1)
        # j_idx2 should be in [0, n-1]
        grad[i] -= np.dot(p[k_range2_lo:k_range2_hi+1], h[j_idx2])
    return grad / alpha
```

    c = np.correlate(h, 1-h, 'full')

    lse = c.max() + np.log(np.sum(np.exp(shifted))) / alpha

```python
def smooth_max_obj_grad(h, n, alpha):
    c = np.correlate(h, 1-h, 'full')
    shifted = alpha * (c - c.max())
    p = np.exp(shifted)
    p /= p.sum()
    
    T1 = np.correlate(1-h, p, 'full')[n-1:3*n-2-(n-1)]  # indices n-1 to 2n-2, length n
    # Wait, I need indices n-1 to n-1+n-1 = 2n-2, which is n elements
    # correlate(1-h, p, 'full') has length 3n-2, indices 0 to 3n-3
    # I want indices n-1 to 2n-2 (inclusive), which is n elements
    
    T2_full = np.correlate(h[::-1], p, 'full')  # length 3n-2
    # I want indices 2n-2-i for i=0,...,n-1, i.e., indices 2n-2, 2n-3, ..., n-1
    T2 = T2_full[n-1:2*n-1][::-1]  # indices n-1 to 2n-2, reversed
    
    grad = (T1 - T2) / alpha
    obj = (c.max() + np.log(np.sum(np.exp(shifted)))) / alpha * (2.0/n)
    return obj, grad
```

The key insight for improvement: the previous code's CD might be getting stuck because it optimizes one coordinate at a time. A "block" coordinate descent or a "top-K" simultaneous update might break the local minimum.

**New idea: "Top-K coordinate descent"**
Instead of updating one coordinate at a time, identify the K coordinates that most reduce the top correlation values, and update them simultaneously.

Or even simpler: after CD converges, do a "flatten" step:
1. Find the top K correlation values
2. Compute the gradient of each top correlation
3. Find the steepest descent direction for the min of the max of these K values
4. Take a step in that direction

The steepest descent direction for min max(c_k)_{k in S} is:
min_d max_{k in S} ∇c_k · d  subject to ‖d‖ ≤ 1, ∑d = 0

This is a linear program in d (with the constraint ∑d=0 for the sum constraint). But it's high-dimensional.

A simpler approach: d = -mean of the gradients of the top K correlations, projected to be orthogonal to 1 (to maintain the sum constraint).

Let me implement this:

```python
def flatten_step(h, n, K=5, step_size=0.01):
    c = np.correlate(h, 1-h, 'full')
    top_k = np.argsort(c)[-K:]  # indices of top K
    # Compute gradient of c[k] for each k in top_k
    grads = np.zeros((K, n))
    one_minus_h = 1.0 - h
    for idx, k in enumerate(top_k):
        # ∂c_k/∂h_i = (1-h)[i+k-(n-1)] - h[i-k+(n-1)] (with bounds)
        g = np.zeros(n)
        for i in range(n):
            j1 = i + k - (n-1)
            if 0 <= j1 < n:
                g[i] += one_minus_h[j1]
            j2 = i - k + (n-1)
            if 0 <= j2 < n:
                g[i] -= h[j2]
        grads[idx] = g
    # Direction: negative mean gradient, centered
    d = -grads.mean(axis=0)
    d -= d.mean()  # center to maintain sum constraint
    # Take a step
    max_step = step_size
    h_new = project_feasible(h + max_step * d / (np.linalg.norm(d) + 1e-15), n)
    c_new = compute_c5(h_new, n)
    c_old = compute_c5(h, n)
    if c_new < c_old:
        return h_new
    # Try smaller steps
    for s in [0.5, 0.25, 0.1, 0.05]:
        h_new = project_feasible(h + max_step * s * d / (np.linalg.norm(d) + 1e-15), n)
        c_new = compute_c5(h_new, n)
        if c_new < c_old:
            return h_new
    return h
```

Actually, I realize I can compute ∂c_k/∂h more efficiently using the correlate trick:
∂c_k/∂h = (1-h)[*+k-(n-1)] - h[*-k+(n-1)]

The first term is a shifted version of (1-h), and the second is a shifted and reversed version of h. So:
∂c_k/∂h = shift(1-h, k-(n-1)) - reverse_shift(h, k-(n-1))

where shift and reverse_shift appropriately pad with zeros.

This can be computed using np.roll or slicing.

This is a linear program! (Because c[k] is... wait, is it linear in h?)

c[k] = Σ_j h[j] * (1-h)[j+k-(n-1)]

This is NOT linear in h (it's bilinear). So it's not an LP.

However, if I linearize: fix h at the current point h₀, then:
c[k] ≈ Σ_j h₀[j] * (1-h)[j+k-(n-1)] + Σ_j h[j] * (1-h₀)[j+k-(n-1)] - Σ_j h₀[j] * (1-h₀)[j+k-(n-1)]

This is the first-order Taylor expansion, which is linear in h. Then I can solve:
minimize 0
subject to [linearized c][k] ≤ C_target for all k
0 ≤ h ≤ 1
sum(h) = n/2

This is an LP! And I can solve it with cvxpy.

The iterative scheme:
1. Start with h₀
2. Linearize c at h₀
3. Solve the LP with C_target = current max
4. Set h₀ = solution
5. Repeat

This is similar to the "cutting plane" or "linearization" approach. It should converge to a local optimum.

3. Otherwise, increase C_target slightly

This is like a "bisection + LP" approach:
- Binary search on C_target
