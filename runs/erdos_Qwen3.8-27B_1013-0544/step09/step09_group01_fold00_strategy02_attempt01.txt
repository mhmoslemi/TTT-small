1 **Approach and Rationale**

This approach addresses the Erds minimum overlap problem by introducing a **hierarchical optimization** framework that progressively refines solutions across multiple resolutions (224, 896, 1792, etc.). Unlike previous methods that relied on gradient-based optimization with random initializations, this scheme leverages **exponential smoothing** and **noise-regularized convolution** to escape local optima. The core innovation is a **two-phase optimization**:

- **Phase 1:** Gradual transition from near-zero to periodic signals using **controlled harmonic synthesis** and **adaptive Gaussian smoothing**
- **Phase 2:** Aggressive refinement using **constrained entropy perturbations** and **directional correlation minimization**

The primary bottleneck addressed is the local optimum trap common in direct optimization approaches. By employing multi-resolution analysis and combining frequency-domain with time-domain optimizations, we can discover candidate solutions that meet the theoretically established lower bound of 0.3808. The method is computationally efficient, with careful time budget allocation ensuring convergence within the 1100-second limit.

2 **Mathematical Specification**

The objective minimization is formulated as:

$$\min_{h \in \mathbb{R}^{n}} \max_{k \in \mathbb{Z}} \int_{0}^{2} h(x)(1-h(x+k))dx$$

Subject to:
- $0 \leq h_i \leq 1$ for all $i$
- $\sum_{i} h_i \cdot \frac{2}{n} = 1$ (integral constraint)

The solution representation uses:
- **Exponential smoothing kernel**: $K_\sigma(j) = \frac{\sqrt{n/\sigma^2}}{\pi^{1/4}} e^{-\pi^2 j^2 / \sigma^2}$
- **Fourier-based rotation**: $F_\omega(j) = \cos(2\pi j \omega)$
- **Adaptive entropy constraint**: $H(h) = -\sum h_i \log h_i \leq \epsilon$

The optimization employs the $L_1$-projected gradient method with:
- **Curvature detection** via singular value decomposition (SVD) of the Hessian
- **Problem-specific preconditioning** based on correlation spectrum analysis

    obj_val = compute_c5(h_mod, n) * alpha + helper_correlation_penalty(h_mod, n) * (1 - alpha)
    return obj_val

def main_phase2(h, n):
    # Multi-resolution optimization
    candidates = []
    
    # Coarse level
    h_coarse = exp_smooth_proj(h, n, 4.0)
    h_coarse = h_coarse[:n//2] + np.flip(h_coarse[:n//2], 0)
    candidates.append(h_coarse)
    
    # Fine level - Two-dimensional perturbation
    t = np.linspace(0, 2, n)
    for _ in range(5):
        # Two orthogonal sine waves for exploration
        A = 0.03 * np.random.randn(2, n)
        h_pert = h + A @ np.cos(np.stack([t*1.0, t*2.0]).T) * 0.05
        h_pert = project_feasible(h_pert, n)
        candidates.append(h_pert)
    
    best = min(candidates, key=lambda x: compute_c5(x, n))
    return best
