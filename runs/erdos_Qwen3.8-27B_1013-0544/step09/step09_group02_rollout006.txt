This suggests that at the optimum, the gradient of the active c_k with respect to h is constant across all free coordinates (equal to -μ).

**This is a key insight!** We can use this to design a better algorithm:

1. Compute the current active lag k*
2. Compute g[i] = ∂c_{k*}/∂h[i] for all i
3. For free coordinates, we want g[i] to be as equal as possible
4. Adjust h to equalize g[i] among free coordinates

This is essentially a "gradient balancing" step.

Let me formalize: for the active lag m*, the gradient with respect to h[p] is:
∂c_{m*}/∂h[p] = (1 - h[jf]) - h[jb] (where jf and jb are the indices affected)

∂c_{m*}/∂h[p] = (1-h[p+k*]) * 1_{p+k* valid} + h[p-k*] * (-1) * 1_{p-k* valid} * ... 

Actually let me be more careful. In the full correlation:
c_m = Σ_{i: 0≤i<n, 0≤i+(m-(n-1))<n} h[i] * (1-h[i+(m-(n-1))])

Let k = m - (n-1) be the actual lag.
c_m = Σ_{i: 0≤i<n, 0≤i+k<n} h[i] * (1-h[i+k])

∂c_m/∂h[p] = Σ_{i: 0≤i<n, 0≤i+k<n} [δ_{ip}(1-h[i+k]) - h[i]*δ_{i+k,p}]
= (1-h[p+k]) * 1_{0≤p+k<n} - h[p-k] * 1_{0≤p-k<n}

So the gradient at coordinate p for lag m is:
g[p] = (1 - h[p+k]) * 1_{valid} - h[p-k] * 1_{valid}

where k = m - (n-1).

At the optimum, for free coordinates, we want g[p] to be constant (all equal to -μ, where μ is the Lagrange multiplier for the sum constraint).

**Algorithm: Gradient Equalization**

1. Find the active lag m* (argmax of c)
2. Compute g[p] = (1-h[p+k*])*1_{valid} - h[p-k*]*1_{valid} for all p
3. For free coordinates (0 < h[p] < 1), we want to make g[p] as equal as possible
4. This means: if g[p] > average, decrease h[p]; if g[p] < average, increase h[p]
5. Step size proportional to the deviation

This is essentially a gradient descent step on the "variance of g among free coordinates."

But wait, this only works for a single active lag. If multiple lags are active (which is typical at the optimum), we need to consider the max of multiple gradients.

**Alternative: Subgradient with gradient equalization**

1. Find the set of active lags S (those within ε of the max)
2. For each active lag m in S, compute g_m[p]
3. The subgradient of max(c_m) is in the convex hull of {g_m : m ∈ S}
4. Use the "average" subgradient: ḡ[p] = (1/|S|) Σ_{m∈S} g_m[p]
5. Take a step in the direction -ḡ (projected to maintain feasibility)

This is the standard subgradient method, but with the twist of using the AVERAGE of active gradients rather than a single one. This should converge faster.

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h, n):
    dx = 2.0 / n
    return float(np.max(np.correlate(h, 1.0 - h, mode='full')) * dx)

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h.copy(), 0.0, 1.0)
    for _ in range(150):
        diff = target - h.sum()
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            room = 1.0 - h
            tot = room.sum()
            if tot < 1e-15:
                break
            h += (diff / tot) * room
        else:
            tot = h.sum()
            if tot < 1e-15:
                break
            h += (diff / tot) * h
    return np.clip(h, 0.0, 1.0)

def get_affected(p, n):
    mlo = max(0, n - 1 - p)
    mhi = min(2 * n - 2, max(2 * n - 2 - p, p + n - 1))
    return mlo, mhi

def cd_single(h, c, n, p):
    h0 = h[p]
    if h0 <= 1e-12 or h0 >= 1.0 - 1e-12:
        return 0.0
    mlo, mhi = get_affected(p, n)
    ms = np.arange(mlo, mhi + 1)
    jf = p + ms - (n - 1)
    jb = p - ms + (n - 1)
    vf = (jf >= 0) & (jf < n)
    vb = (jb >= 0) & (jb < n)
    vec = np.zeros(len(ms))
    if np.any(vf):
        vec[vf] += 1.0 - h[jf[vf]]
    if np.any(vb):
        vec[vb] -= h[jb[vb]]
    c_sub = c[mlo:mhi + 1]
    unaff = 0.0
    if mlo > 0:
        unaff = max(unaff, float(c[:mlo].max()))
    if mhi < 2 * n - 2:
        unaff = max(unaff, float(c[mhi + 1:].max()))
    lo, hi = -h0, 1.0 - h0
    for _ in range(44):
        mid = (lo + hi) * 0.5
        vals = c_sub + mid * vec
        mval = float(vals.max())
        if mval <= unaff + 1e-13:
            lo = hi = mid
            break
        active = vals >= mval - 1e-9
        vmin = float(vec[active].min())
        vmax = float(vec[active].max())
        if vmin > 1e-10:
            hi = mid
        elif vmax < -1e-10:
            lo = mid
        else:
            lo = hi = mid
            break
    return (lo + hi) * 0.5

def apply_delta(h, c, n, p, delta):
    if abs(delta) < 1e-14:
        return
    mlo, mhi = get_affected(p, n)
    ms = np.arange(mlo, mhi + 1)
    jf = p + ms - (n - 1)
    jb = p - ms + (n - 1)
    vf = (jf >= 0) & (jf < n)
    vb = (jb >= 0) & (jb < n)
    d = np.zeros(len(ms))
    if np.any(vf):
        d[vf] = delta * (1.0 - h[jf[vf]])
    if np.any(vb):
        d[vb] -= delta * h[jb[vb]]
    c[ms] += d
    h[p] = np.clip(h[p] + delta, 0.0, 1.0)

def coord_descent(h, n, max_passes, deadline, rng=None):
    h = h.copy()
    c = np.correlate(h, 1.0 - h, mode='full')
    for _pass in range(max_passes):
        if deadline is not None and time.time() > deadline:
            break
        order = np.arange(n)
        if rng is not None:
            rng.shuffle(order)
        improved = False
        for p in order:
            delta = cd_single(h, c, n, p)
            if abs(delta) > 1e-13:
                apply_delta(h, c, n, p, delta)
                improved = True
        if not improved:
            break
        h = project_feasible(h, n)
        if _pass % 15 == 14:
            c = np.correlate(h, 1.0 - h, mode='full')
    return h, compute_c5(h, n)

def lse_obj_and_grad(h, n, alpha):
    dx = 2.0 / n
    c = np.correlate(h, 1.0 - h, mode='full')
    ac = alpha * c
    mx = ac.max()
    ex = np.exp(ac - mx)
    lse = (mx + np.log(ex.sum())) / alpha
    w = ex / ex.sum()
    grad = np.zeros(n)
    for m in range(len(c)):
        if w[m] < 1e-12:
            continue
        k = m - (n - 1)
        lo_i = max(0, -k)
        hi_i = min(n, n - k)
        for i in range(lo_i, hi_i):
            j = i + k
            grad[i] += w[m] * ((1.0 - h[j]) - (1.0 if j == i else 0.0) * 0.0)
            if j != i:
                grad[j] += w[m] * (-h[i])
    return lse * dx, grad * dx

def lse_obj_fast(x, n, alpha):
    dx = 2.0 / n
    c = np.correlate(x, 1.0 - x, mode='full')
    ac = alpha * c
    mx = ac.max()
    ex = np.exp(ac - mx)
    return (mx + np.log(ex.sum())) / alpha * dx

def sum_con(x, n):
    return x.sum() - n / 2.0

def sum_con_jac(x, n):
    return np.ones(n)

def slsqp_lse_polish(h, n, alphas, maxiter_each, deadline):
    best_h = h.copy()
    best_c = compute_c5(h, n)
    for alpha in alphas:
        if deadline is not None and time.time() > deadline:
            break
        bounds = [(0.0, 1.0)] * n
        cons = [{'type': 'eq', 'fun': sum_con, 'jac': sum_con_jac, 'args': (n,)}]
        try:
            res = minimize(lse_obj_fast, best_h.copy(), args=(n, alpha), method='SLSQP',
                           bounds=bounds, constraints=cons,
                           options={'maxiter': maxiter_each, 'ftol': 1e-18})
            new_h = project_feasible(res.x, n)
            new_c = compute_c5(new_h, n)
            if new_c < best_c - 1e-15:
                best_h, best_c = new_h, new_c
        except Exception:
            pass
    return best_h, best_c

def multi_active_subgrad(h, n, max_iter, deadline, top_k=5):
    h = h.copy()
    best_c = compute_c5(h, n)
    lr = 0.05
    stall = 0
    for it in range(max_iter):
        if deadline is not None and time.time() > deadline:
            break
        c = np.correlate(h, 1.0 - h, mode='full')
        cmax = c.max()
        thresh = cmax - max(1e-6, 0.05 * cmax / (2.0 / n))
        idx = np.where(c >= thresh)[0]
        if len(idx) > top_k:
            top_idx = np.argsort(c[idx])[-top_k:]
            idx = idx[top_idx]
        sg = np.zeros(n)
        for m in idx:
            k = m - (n - 1)
            lo_i = max(0, -k)
            hi_i = min(n, n - k)
            for i in range(lo_i, hi_i):
                j = i + k
                sg[i] += (1.0 - h[j])
                if j != i:
                    sg[j] -= h[i]
        sg /= len(idx)
        h_new = project_feasible(h - lr * sg, n)
        c_new = compute_c5(h_new, n)
        if c_new < best_c - 1e-13:
            h = h_new
            best_c = c_new
            stall = 0
        else:
            lr *= 0.8
            stall += 1
            if stall > 60 or lr < 1e-12:
                break
    return h, best_c

def pair_move_cd(h, n, max_passes, deadline, rng):
    h = h.copy()
    best_c = compute_c5(h, n)
    c = np.correlate(h, 1.0 - h, mode='full')
    free = np.where((h > 1e-4) & (h < 1.0 - 1e-4))[0]
    if len(free) < 2:
        return h, best_c
    eps = 0.02
    for _pass in range(max_passes):
        if deadline is not None and time.time() > deadline:
            break
        improved = False
        for _it in range(min(200, len(free) * 2)):
            p = free[rng.randint(len(free))]
            q = free[rng.randint(len(free))]
            if p == q:
                continue
            for dp, dq in [(eps, 0), (-eps, 0), (0, eps), (0, -eps),
                           (eps, eps * 0.5), (eps, -eps * 0.5),
                           (eps * 0.5, eps), (-eps * 0.5, -eps * 0.5)]:
                h_save = (h[p], h[q])
                h[p] = np.clip(h[p] + dp, 0, 1)
                h[q] = np.clip(h[q] + dq, 0, 1)
                c_new = compute_c5(h, n)
                if c_new < best_c - 1e-14:
                    best_c = c_new
                    improved = True
                    free = np.where((h > 1e-4) & (h < 1.0 - 1e-4))[0]
                    break
                else:
                    h[p], h[q] = h_save
        if not improved:
            break
    return h, best_c
