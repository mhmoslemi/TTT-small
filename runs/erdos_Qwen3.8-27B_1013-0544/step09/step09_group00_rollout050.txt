Let me expand: t - t² - h[i] + h[i]² + (S-t) - (S-t)² - h[j] + h[j]²
= t - t² - h[i] + h[i]² + S - t - (S² - 2St + t²) - h[j] + h[j]²
= -2t² + 2St - S² + S - h[i] - h[j] + h[i]² + h[j]²
= -2t² + 2St - S² + S - h[i] - h[j] + h[i]² + h[j]²

Since S = h[i] + h[j]:
= -2t² + 2(h[i]+h[j])t - (h[i]+h[j])² + (h[i]+h[j]) - h[i] - h[j] + h[i]² + h[j]²
= -2t² + 2(h[i]+h[j])t - h[i]² - 2h[i]h[j] - h[j]² + h[i] + h[j] - h[i] - h[j] + h[i]² + h[j]²
= -2t² + 2(h[i]+h[j])t - 2h[i]h[j]

So Δc[n-1] = -2t² + 2S*t - 2*h[i]*h[j]

Let me verify: if t = h[i], then Δc[n-1] = -2h[i]² + 2S*h[i] - 2h[i]h[j] = -2h[i]² + 2h[i](h[i]+h[j]) - 2h[i]h[j] = 0. ✓
If t = h[j] (and S-t = h[i]), then Δc[n-1] = -2h[j]² + 2S*h[j] - 2h[i]h[j] = -2h[j]² + 2h[j]h[i] + 2h[j]² - 2h[i]h[j] = 0. ✓

So the 2D problem reduces to a 1D problem in t:
minimize max_k f_k(t)
where f_k(t) = c[k] + (t - h[i])*(a_i[k] - a_j[k]) for k ≠ n-1
and f_{n-1}(t) = c[n-1] - 2t² + 2S*t - 2*h[i]*h[j]

subject to max(0, S-1) ≤ t ≤ min(1, S)

This is: minimize max of (several linear functions) and (one quadratic) over an interval.

We can solve this with bisection on the target L:
For a given L, we need f_k(t) ≤ L for all k.
- For linear f_k(t) = A_k * t + B_k: t ≤ (L - B_k)/A_k if A_k > 0, t ≥ (L - B_k)/A_k if A_k < 0.
- For the quadratic f_{n-1}(t) = -2t² + 2S*t - 2*h[i]*h[j] + c[n-1] ≤ L:
  2t² - 2S*t + (2h[i]h[j] - c[n-1] + L) ≥ 0
  Let Q = 2h[i]h[j] - c[n-1] + L
  2t² - 2S*t + Q ≥ 0
  t² - S*t + Q/2 ≥ 0
  Roots: t = (S ± √(S² - 2Q))/2
  
  Wait: t² - St + Q/2 = 0, discriminant = S² - 2Q.
  If discriminant < 0: always positive (leading coeff positive), constraint always satisfied.
  If discriminant ≥ 0: roots are t1 = (S - √(S²-2Q))/2, t2 = (S + √(S²-2Q))/2.
  We need t ≤ t1 or t ≥ t2.

So the feasible set for t is an interval [lo, hi] (from linear constraints) intersected with (-∞, t1] ∪ [t2, ∞).

    else:

def exact_cd(h, n, num_passes, deadline, seed=0):
    """Exact coordinate descent with random ordering."""
    rng = np.random.RandomState(seed)
    h = h.copy()
    c = np.correlate(h, 1.0 - h, mode='full')
    for _ in range(num_passes):
        if time.time() > deadline:
            break
        improved = False
        order = rng.permutation(n)
        for p in order:
            h0 = h[p]
            if h0 < 1e-13 or h0 > 1.0 - 1e-13:
                continue
            xn = solve_1d_exact(c, h, p, n)
            if abs(xn - h0) > 1e-12:
                delta = xn - h0
                a = get_coeff(h, p, n)
                c += delta * a
                c[n-1] -= delta * delta
                h[p] = xn
                improved = True
        if not improved:
            break
        h = project_feasible(h, n)
    return h, compute_c5(h, n)
