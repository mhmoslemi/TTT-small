def lse_objective(x, n, alpha):
    c = np.correlate(x, 1.0 - x, mode='full')
    m = c.max()
    shifted = alpha * (c - m)
    mx = shifted.max()
    lse = mx + np.log(np.sum(np.exp(shifted - mx)))
    return (m + lse / alpha) * (2.0 / n)

def coord_descent(h, n, max_passes, deadline, rng, nbisect=50):
    h = h.copy()
    for _ in range(max_passes):
        if time.time() > deadline:
            break
        h, imp = cd_pass(h, n, rng, nbisect, deadline)

def lse_fun(x, n, alpha):
    c = np.correlate(x, 1.0 - x, mode='full')
    m = c.max()
    s = alpha * (c - m)
    mx = s.max()
    return (m + (mx + np.log(np.sum(np.exp(s - mx)))) / alpha) * (2.0 / n)

def sum_eq(x, n):
    return x.sum() - n / 2.0

def sum_eq_jac(x, n):
    return np.ones(n)

def slsqp_step(h, n, alpha, deadline):

    cons = [{'type': 'eq', 'fun': sum_eq, 'jac': sum_eq_jac, 'args': (n,)}]
    try:

                      bounds=bounds, constraints=cons,
                      options={'maxiter': 300, 'ftol': 1e-15})
        return project_feasible(res.x, n)
    except Exception:
        return h

Actually, I want to double-check one thing about the bisection logic. The issue is:

For a given T, I need to find if there exists x ∈ [0,1] such that:
1. For all non-diagonal m: c[m] + a[m]*(x-h0) ≤ T
2. For the diagonal m: c[m] + (x-h0) - (x²-h0²) ≤ T
3. x ∈ [0,1]

Condition 1 gives: x ∈ [xl, xh] (an interval)
Condition 2 gives: x ∈ [0, r1] ∪ [r2, 1] (the complement of (r1, r2))

Feasibility: [xl, xh] ∩ [0, r1] ∪ [r2, 1] ≠ ∅
This fails iff [xl, xh] ⊂ (r1, r2), i.e., xl > r1 AND xh < r2.

This is what I have. Good.

Now, for finding the best x given T:
- From condition 1: x ∈ [xl, xh]
- From condition 2: x ∉ (r1, r2)
- So x ∈ [xl, xh] \ (r1, r2) = [xl, min(xh, r1)] ∪ [max(xl, r2), xh]

I want to pick the x that minimizes the resulting max correlation. The maximum will be max(unaff, max of affected entries at x).

For non-diagonal entries: c[m] + a[m]*(x-h0) is linear in x, so the max over these is:
- If all a[m] ≥ 0: max at x = xh
- If all a[m] ≤ 0: max at x = xl
- In general: max of (max over a[m]>0 at xh, max over a[m]<0 at xl)

For the diagonal entry: c[m] + (x-h0) - (x²-h0²) is a concave quadratic in x (opening downward), so its max on [xl, xh] is at x = 0.5 (if 0.5 is in range) or at the nearest endpoint.

So the overall max is the max of several piecewise-linear/concave functions. The minimum of this max over x is a minimax problem in 1D, which can be solved by checking critical points.

For simplicity, I'll just try a few candidate x values (the endpoints, the midpoint, and the points where the diagonal constraint is tight). This should be good enough.

Actually, let me simplify further. The key insight is that after bisection, T is the minimum feasible value (within epsilon). At this T, the feasible set for x is small (a thin interval or two thin intervals). I just need to pick any x in the feasible set, and the resulting max will be ≈ T.

def project_feasible(h, n):
    target = n / 2.0

            if tot < 1e-15:
                break
            h = np.clip(h + d / tot * h, 0.0, 1.0)
