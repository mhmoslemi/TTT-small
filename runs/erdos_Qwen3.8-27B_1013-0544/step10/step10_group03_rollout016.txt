**Alternative: Use a "water-filling" approach**

The idea: at the optimum, the active constraints (shifts where c_k = max) should be "balanced". I can iteratively:
1. Compute the correlation
2. Find the max value m
3. For the active set (shifts where c_k > m - epsilon), compute a "pressure"
4. Adjust h to reduce the pressure at the most constrained shifts

This is essentially what the subgradient method does, but I can make it more targeted.

**Alternative: Use a "dual" approach**

The problem can be written as:
min max_k c_k s.t. sum(h) = n/2, 0 <= h <= 1

The Lagrangian dual involves finding weights w_k >= 0 that sum to 1 such that the weighted sum of c_k is minimized. The optimal solution has c_k = constant for all k with w_k > 0.

I can iteratively:
1. Solve the weighted least squares: min sum_k w_k * c_k s.t. constraints
2. Update w_k based on which c_k are largest (multiply-weights update)
3. Repeat

This is like the "cutting plane" or "multiplicative weights" approach.

For step 1, the weighted least squares is:
min sum_k w_k * c_k = min sum_k w_k * sum_i h[i](1-h[i+k_n])

This is a QP in the variables h[i]. But it's not convex in h because of the h² terms. However, for fixed weights, it's a separable function in each h[i] (since c_k depends on at most 2 h variables at a time... wait, no, c_k = sum_i h[i](1-h[i+k_n]) which is quadratic in h).

Actually, the objective sum_k w_k * c_k = sum_k w_k * sum_i h[i] - h[i]h[i+k_n]

This is a quadratic form in h. It's not convex in general (the Hessian has -w_k terms for the cross-products). So I can't directly use a QP solver.

But I can use coordinate descent on this objective! For each coordinate h[p], the objective is:
f(h[p]) = sum_k w_k * sum_i [h[i](1-h[i+k_n])]

For a fixed p, this is:
= const + h[p] * (sum_k w_k * (1 - h[p+k_n]) - sum_k w_k * (1 - h[p-k_n]))
  - h[p]² * (sum_k w_k where k_n = 0) [the self-term]

Wait, let me be more careful. c[m] = sum_i h[i] * (1-h)[i+m-(n-1)] for valid indices.

For coordinate p, the terms involving h[p] are:
- For each shift m where p is in the "h" part: contribution is h[p] * (1-h[p+m-(n-1)])
- For each shift m where p is in the "(1-h)" part: contribution is h[p+m+(n-1)] * (1-h[p])

So f(h[p]) = sum_{m: p in h-part} w_m * h[p](1-h[p+m-n+1])
             + sum_{m: p in (1-h)-part} w_m * h[p+m+n-1](1-h[p])
             + const

= h[p] * (sum_{m: p in h-part} w_m - sum_{m: p in h-part} w_m * h[p+m-n+1])
  - h[p] * (sum_{m: p in (1-h)-part} w_m * h[p+m+n-1])
  + const

Wait, this is linear in h[p]! Because the only h[p]² term is when p is both in the h-part and (1-h)-part for the same m, which means m = n-1 (the "diagonal" shift). For m = n-1: contribution is h[p] * (1-h[p]).

So f(h[p]) = A * h[p] - B * h[p]² + C (when there's a diagonal term)
or f(h[p]) = A * h[p] + C (when there's no diagonal term)

where A and B are sums of weights times neighboring values.

Since B >= 0 (weights are non-negative), the function is concave in h[p] when there's a diagonal term, and linear otherwise. So the minimum is at one of the endpoints (h[p] = 0 or h[p] = 1)!

Wait, that's a very interesting result! If the objective is concave in each coordinate (when there's a diagonal term), then the minimum over [0,1] is at one of the endpoints. This means the optimal solution for the weighted problem is binary!

But wait, the weighted problem is different from the original minimax problem. The original problem is min max_k c_k, while the weighted problem is min sum_k w_k c_k. These are different.

However, at the optimum of the original problem, for the "optimal" weights w* (from the dual), the solution also minimizes the weighted sum. And if the weighted sum is minimized by a binary solution, then... hmm, this is getting complicated.

2. For each active shift m, identify which coordinates h[p] affect c[m]

This is a form of "smart" coordinate ordering.

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h, n):
    dx = 2.0 / n
    return float(np.max(np.correlate(h, 1.0 - h, mode='full')) * dx)

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h.copy(), 0.0, 1.0)
    for _ in range(2000):
        diff = target - h.sum()
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            room = 1.0 - h
            tot = room.sum()
            if tot < 1e-14:
                break
            h = np.clip(h + (diff / tot) * room, 0.0, 1.0)
        else:
            tot = h.sum()
            if tot < 1e-14:
                break
            h = np.clip(h + (diff / tot) * h, 0.0, 1.0)
    return h

def solve_1d_bisect(c, h, p, n):
    h0 = h[p]
    m_min = n - 1 - p
    m_max = 2 * n - 2 - p
    ms = np.arange(m_min, m_max + 1)
    jf = p + ms - (n - 1)
    jb = p - ms + (n - 1)
    vf = (jf >= 0) & (jf < n)
    vb = (jb >= 0) & (jb < n)
    a = np.zeros(len(ms))
    if np.any(vf):
        a[vf] += (1.0 - h[jf[vf]])
    if np.any(vb):
        a[vb] -= h[jb[vb]]
    c_base = c[ms]
    diag_idx = np.where(ms == (n - 1))[0]
    has_diag = len(diag_idx) > 0
    if has_diag:
        c_diag = c_base[diag_idx[0]]
        a[diag_idx] = 0.0
    unaff = 0.0
    if m_min > 0:
        unaff = float(np.max(c[:m_min]))
    if m_max < 2 * n - 2:
        unaff = max(unaff, float(np.max(c[m_max + 1:])))
    cur_max = float(np.max(c))
    L_lo, L_hi = unaff, cur_max
    for _ in range(55):
        if L_hi - L_lo < 1e-13:
            break
        L = (L_lo + L_hi) / 2.0
        x_lo, x_hi = 0.0, 1.0
        feasible = True
        neg_mask = a < -1e-14
        pos_mask = a > 1e-14
        zero_mask = np.abs(a) <= 1e-14
        if np.any(zero_mask) and np.any(c_base[zero_mask] > L):
            feasible = False
        if feasible and np.any(neg_mask):
            x_lo = max(x_lo, float(np.max((L - c_base[neg_mask]) / a[neg_mask])))
        if feasible and np.any(pos_mask):
            x_hi = min(x_hi, float(np.min((L - c_base[pos_mask]) / a[pos_mask])))
        if x_lo > x_hi + 1e-12:
            feasible = False
        if feasible and has_diag:
            Cq = L - c_diag + h0 - h0 * h0
            disc = 1.0 - 4.0 * Cq
            if disc >= 0:
                r1 = (1.0 - np.sqrt(disc)) / 2.0
                r2 = (1.0 + np.sqrt(disc)) / 2.0
                xc_lo, xc_hi = max(x_lo, 0.0), min(x_hi, 1.0)
                if not (xc_lo < r1 and xc_hi > r2):
                    feasible = False
        if feasible:
            L_hi = L
        else:
            L_lo = L
    L = L_hi
    x_lo, x_hi = 0.0, 1.0
    neg_mask = a < -1e-14
    pos_mask = a > 1e-14
    if np.any(neg_mask):
        x_lo = max(x_lo, float(np.max((L - c_base[neg_mask]) / a[neg_mask])))
    if np.any(pos_mask):
        x_hi = min(x_hi, float(np.min((L - c_base[pos_mask]) / a[pos_mask])))
    x_lo = max(x_lo, 0.0)
    x_hi = min(x_hi, 1.0)
    if has_diag:
        Cq = L - c_diag + h0 - h0 * h0
        disc = 1.0 - 4.0 * Cq
        if disc >= 0:
            r1 = (1.0 - np.sqrt(disc)) / 2.0
            r2 = (1.0 + np.sqrt(disc)) / 2.0
            if h0 - r1 <= r2 - h0:
                x_hi = min(x_hi, r1)
            else:
                x_lo = max(x_lo, r2)
    if x_lo > x_hi:
        return h0
    return float(np.clip((x_lo + x_hi) / 2.0, 0.0, 1.0))

def exact_cd(h, n, max_passes, deadline, seed_rng=0):
    h = h.copy()
    c = np.correlate(h, 1.0 - h, mode='full')
    rng_local = np.random.RandomState(seed_rng)
    for it in range(max_passes):
        if time.time() > deadline:
            break
        improved = False
        order = rng_local.permutation(n)
        for p in order:
            h0 = h[p]
            if h0 < 1e-12 or h0 > 1.0 - 1e-12:
                continue
            xn = solve_1d_bisect(c, h, p, n)
            if abs(xn - h0) > 1e-12:
                delta = xn - h0
                m_min = n - 1 - p
                m_max = 2 * n - 2 - p
                ms = np.arange(m_min, m_max + 1)
                jf = p + ms - (n - 1)
                jb = p - ms + (n - 1)
                vf = (jf >= 0) & (jf < n)
                vb = (jb >= 0) & (jb < n)
                a = np.zeros(len(ms))
                if np.any(vf):
                    a[vf] += (1.0 - h[jf[vf]])
                if np.any(vb):
                    a[vb] -= h[jb[vb]]
                diag_i = np.where(ms == (n - 1))[0]
                c[ms] += delta * a
                if len(diag_i) > 0:
                    c[ms[diag_i[0]]] -= delta * delta
                h[p] = xn
                improved = True
        if not improved:
            break

        if abs(h.sum() - n / 2.0) > 1e-11:
            c = np.correlate(h, 1.0 - h, mode='full')
    return h, compute_c5(h, n)

def smooth_obj(x, n, alpha, mu):
    c = np.correlate(x, 1.0 - x, mode='full') * (2.0 / n)
    m = c.max()
    shifted = alpha * (c - m)
    mx = shifted.max()
    lse = mx + np.log(np.sum(np.exp(shifted - mx)))
    return m + lse / alpha + mu * (x.sum() - n / 2.0) ** 2

def lbfgsb_opt(h, n, alpha, mu, maxiter, deadline):
    bounds = [(0.0, 1.0)] * n
    try:
        res = minimize(smooth_obj, h, args=(n, alpha, mu), method='L-BFGS-B',
                       bounds=bounds, options={'maxiter': maxiter, 'ftol': 1e-18,
                                               'gtol': 1e-14, 'maxls': 30})
        return project_feasible(res.x, n)
    except Exception:
        return project_feasible(h, n)

def targeted_perturb(h, n, rng, scale):
    h = h.copy()
    boundary = (h > 0.1) & (h < 0.9)
    h[boundary] += rng.normal(0, scale, boundary.sum())
    return project_feasible(h, n)

def binarize_snap(h, n, threshold):
    h = h.copy()
    h[h < threshold] = 0.0
    h[h > 1.0 - threshold] = 1.0
    return project_feasible(h, n)
