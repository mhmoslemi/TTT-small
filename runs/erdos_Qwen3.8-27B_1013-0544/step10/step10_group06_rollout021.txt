The key realization is that for each coordinate p, I need to:
1. For each lag k (0 to 2n-2), compute a_k = coefficient of (x-h0) in c_k
2. Run bisection on T

The a_k can be computed as:
- offset = k - (n-1)
- a_k = 0
- if 0 <= p+offset < n: a_k += (1 - h[p+offset])  [first factor]
- if 0 <= p-offset < n: a_k -= h[p-offset]  [second factor]
- if offset == 0: special handling (quadratic)

For the bisection, I need:
- For each k, the constraint is c_k + (x-h0)*a_k <= T (linear in x for k≠diagonal)
- For k=diagonal: c_k + (x-h0)*(1-h0-x) <= T (quadratic in x)

From the linear constraints:
- If a_k > 0: x <= (T - c_k)/a_k + h0
- If a_k < 0: x >= (T - c_k)/a_k + h0
- If a_k = 0: need c_k <= T (no constraint on x)

This is O(n) per bisection step. With 50 bisection steps and n coordinates, that's O(n² * 50) per pass. For n=700, that's about 24.5 million operations per pass. In Python with numpy, this should take maybe 0.1-0.5 seconds per pass. So I can do 2000-10000 passes in 1100 seconds. That's plenty.
