c[n-1] = sum_i h[i] * (1-h[i]) = sum_i h[i] - sum_i h[i]^2

When we change h[p] from h0 to x:
New c[n-1] = c[n-1] - h0*(1-h0) + x*(1-x)
= c[n-1] - h0 + h0^2 + x - x^2

So the "a" coefficient for the diagonal is 0 (it's not linear in x), and the constant term changes by:
c_diag_new = c_diag - h0*(1-h0) + x*(1-x)

For the constraint c_diag_new <= L:
x*(1-x) <= L - c_diag + h0*(1-h0) = Cq

So x must satisfy x - x^2 <= Cq, i.e., x^2 - x + Cq >= 0.
Roots: x = (1 ± sqrt(1-4Cq))/2 = r1, r2 (if 1-4Cq >= 0).
The quadratic x^2 - x + Cq >= 0 is satisfied when x <= r1 or x >= r2.

    L = rng.randint(10, max(11, n // 4))
    # Two non-overlapping blocks
    a = rng.randint(0, n - L)
    b = rng.randint(0, n - L)
    if abs(a - b) < L:
        b = (a + L + rng.randint(0, n - 2*L)) % (n - L) if n > 2*L else (a + L) % n
    if abs(a - b) < L:
        return h  # Can't make non-overlapping, skip
    h[a:a+L], h[b:b+L] = h[b:b+L].copy(), h[a:a+L].copy()
    return h

def complement_block(h, n, rng):
    """Complement a contiguous block and re-project."""
    h = h.copy()
    L = rng.randint(20, max(21, n // 3))
    start = rng.randint(0, n - L)
    h[start:start+L] = 1.0 - h[start:start+L]
    return project_feasible(h, n)

def rotation_perturbation(h, n, rng):
    """Circularly shift by a random amount."""
    shift = rng.randint(1, n - 1)
    return np.roll(h, shift)

Hmm, but this is quite similar to the previous solution. Let me think about what's fundamentally different that could help.

Key differences from previous:
1. Block swap and complement block perturbations (more structured than pure noise)
2. Rotation perturbation
3. More aggressive CD passes

But I think the main issue is that the CD converges to the same local minimum regardless of the perturbation strategy. The problem is that the landscape is very "flat" near the optimum, and small perturbations don't help much.

Let me think about a fundamentally different approach:

**Idea: Use the problem's symmetry and structure**

The correlation c[k] = sum_i h[i+k]*(1-h[i]) has a specific structure. If h is a step function (values in {0,1}), then:
c[k] = number of i where h[i+k]=1 and h[i]=0

This is the number of "1→0" transitions at shift k. For a step function with m ones, c[k] + c[-k] = m (in the periodic case) or close to it.

For a step function, the maximum overlap is minimized when the ones are as "evenly spaced" as possible (like a low-discrepancy sequence).

**Idea: Optimize over step functions (binary)**

If we restrict h to be binary (0 or 1), the problem becomes:
minimize max_k c[k] where c[k] = number of i with h[i+k]=1, h[i]=0

This is a combinatorial problem. For n=700 with 350 ones, we're looking for a binary sequence that minimizes the maximum "1→0" count over all shifts.

This is related to the "irregularity problem" or "discrepancy" in combinatorics.

We could try:
1. Start with a random binary assignment (350 ones, 350 zeros)
2. Use local search (swap 0s and 1s) to minimize the max correlation
3. Then "relax" the binary solution by allowing non-binary values near 0.5

Actually, the relaxation step is interesting. If the binary solution has max correlation C_bin, then by allowing h to take values in [0,1], we can potentially reduce C below C_bin (by "smoothing" the boundaries).

But wait, the CD already does this implicitly - it allows h to take any value in [0,1].

**Idea: Use simulated annealing on the binary problem, then relax**

1. Find a good binary arrangement via simulated annealing
2. Use it as initial point for CD
3. CD will find the optimal non-binary relaxation

The advantage of this approach is that the binary search space has a well-understood structure, and simulated annealing can find globally good arrangements.

def binary_sa(h_binary, n, deadline, rng, iters_per_temp=100):

    cur_max = c.max()
    best_h = h.copy()
    best_max = cur_max

        if time.time() > deadline:

            T *= cool**5000
            if T < 0.01:
                T = 0.01

        old_val = h[p]
        h[p] = 1.0 - old_val
        new_c = np.correlate(h, 1.0 - h, mode='full')
        new_max = new_c.max()
        delta = new_max - cur_max
        if delta < 0 or rng.random() < np.exp(-delta / T):
            cur_max = new_max

But this is O(n) per flip due to the full correlate, and we need 100000 iterations. For n=700, that's 70M operations per iteration... no wait, correlate is O(n^2) = 490K per call. 100000 * 490K = 49 billion. Way too slow.

I need a faster way to evaluate the objective after a single flip. When we flip h[p] from 0 to 1 (or vice versa), only the correlations involving position p change. Specifically, c[k] changes for k in the range [n-1-p, 2n-2-p] (the correlations that involve h[p]).

Let me compute the change incrementally:
If h[p] changes by delta (delta = +1 or -1):
For each correlation index ms in [n-1-p, 2n-2-p]:
  c[ms] changes by delta * a[ms] where a[ms] is the "coefficient" from before.

This is exactly what the CD does! So I can use the same incremental update mechanism.

But for SA on binary, the flip is always delta = ±1, so it's simpler. Let me implement it with incremental updates:

Actually, for a binary flip (h[p] goes from 0 to 1 or 1 to 0), the change in c is:
delta_c[ms] = delta * a[ms] - delta^2 * (1 if ms == n-1 else 0)
= delta * a[ms] - (1 if ms == n-1 else 0)  [since delta^2 = 1]

Wait, let me redo. If h[p] changes from h0 to h0 + delta:
c[ms] changes by delta * a[ms] - delta^2 (for the diagonal)
For binary flip: delta = ±1, so delta^2 = 1.

So the incremental update is the same as in CD. Good.
