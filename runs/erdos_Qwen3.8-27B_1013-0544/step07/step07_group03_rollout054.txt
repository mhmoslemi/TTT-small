Alternatively, we can update f incrementally. When h[i] changes from 0 to 1:
- f[p, k] = (1-h[p-sh_k]) - h[p+sh_k]
- h[i] appears in f[p,k] when p-sh_k = i (so p = i+sh_k) or p+sh_k = i (so p = i-sh_k)
- For a given k (shift sh_k):

  - f[i-sh_k, k] changes: the second term h[i] changes from 0 to 1, so f decreases by 1

So when h[i] goes 0→1:
- For each k: f[i+sh_k, k] -= 1 (if i+sh_k is valid, i.e., 0 ≤ i+sh_k < n)
- For each k: f[i-sh_k, k] -= 1 (if i-sh_k is valid)

And when h[j] goes 1→0:
- For each k: f[j+sh_k, k] += 1
- For each k: f[j-sh_k, k] += 1

So for a swap (i: 0→1, j: 1→0), the update to f is:
- For each k: f[i+sh_k, k] -= 1; f[i-sh_k, k] -= 1; f[j+sh_k, k] += 1; f[j-sh_k, k] += 1

That's 4*(2n-1) = O(n) updates per accepted swap! Much better than O(n²).

Let me code this up:

```python
def update_f_after_swap(f, h, n, i, j):
    """Update f after swapping h[i] (0→1) and h[j] (1→0)."""
    shifts = np.arange(-(n-1), n)
    # h[i] goes 0→1: f[i+sh, k] -= 1, f[i-sh, k] -= 1
    # h[j] goes 1→0: f[j+sh, k] += 1, f[j-sh, k] += 1
    for k, sh in enumerate(shifts):
        p1 = i + sh
        if 0 <= p1 < n:
            f[p1, k] -= 1
        p2 = i - sh
        if 0 <= p2 < n:
            f[p2, k] -= 1
        p3 = j + sh
        if 0 <= p3 < n:
            f[p3, k] += 1
        p4 = j - sh
        if 0 <= p4 < n:
            f[p4, k] += 1
```

```python
def update_f_after_swap(f, n, i, j, shifts):
    # For h[i] 0→1: positions i+sh and i-sh get f decreased by 1
    # For h[j] 1→0: positions j+sh and j-sh get f increased by 1
    # i+sh is valid when 0 <= i+sh < n, i.e., -i <= sh < n-i
    # i-sh is valid when 0 <= i-sh < n, i.e., i-n < sh <= i
    # For a given k (index into shifts), sh = shifts[k]
    # f[i+sh, k]: row i+sh, col k. Valid if 0 <= i+shifts[k] < n
    # This is a diagonal pattern in the f matrix!
    
    # f[i+sh, k] where sh = shifts[k] = k - (n-1)
    # i + sh = i + k - (n-1)
    # So f[i + k - (n-1), k] -= 1 for valid (i + k - (n-1))
    # k ranges from 0 to 2n-2, so i+k-(n-1) ranges from i-(n-1) to i+n-1
    # Valid when 0 <= i+k-(n-1) < n, i.e., n-1-i <= k <= n-1-i+n-1 = 2(n-1)-i
    
    ks = np.arange(2*n-1)
    rows1 = i + ks - (n-1)  # = i + shifts[ks]
    msk1 = (rows1 >= 0) & (rows1 < n)
    f[rows1[msk1], ks[msk1]] -= 1
    
    rows2 = i - ks + (n-1)  # = i - shifts[ks]
    msk2 = (rows2 >= 0) & (rows2 < n)
    f[rows2[msk2], ks[msk2]] -= 1
    
    rows3 = j + ks - (n-1)
    msk3 = (rows3 >= 0) & (rows3 < n)
    f[rows3[msk3], ks[msk3]] += 1
    
    rows4 = j - ks + (n-1)
    msk4 = (rows4 >= 0) & (rows4 < n)
    f[rows4[msk4], ks[msk4]] += 1
```

This is O(n) vectorized operations, very fast.

def slsqp_step(h, n, alpha, maxiter):

        m = c.max()
        shifted = alpha * (c - m)
        sm = shifted.max()
        lse = sm + np.log(np.exp(shifted - sm).sum())
        return m + lse / alpha
    def cons_fun(x):
        return x.sum() - n / 2.0
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': cons_fun}]
    try:
        res = minimize(obj, h, method='SLSQP', bounds=bounds,
                       constraints=cons, options={'maxiter': maxiter, 'ftol': 1e-16})

        return h
