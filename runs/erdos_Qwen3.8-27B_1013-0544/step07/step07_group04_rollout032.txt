```python
def compute_pair_diff(h, i, j, n):
    """Compute d_l = dC(l)/dh[i] - dC(l)/dh[j] for all lags l."""
    dx = 2.0 / n
    off = n - 1
    L = 2 * n - 1
    d = np.zeros(L)
    
    for l in range(L):
        k = abs(l - off)
        if k == 0:
            # dC/dh[i] = dx * [(1-h[i])*1 - h[i]*1] = dx*(1-2h[i])
            # dC/dh[j] = dx * (1-2h[j])
            d[l] = dx * ((1-2*h[i]) - (1-2*h[j]))
        else:
            gi = 0.0
            if k <= i:
                gi += (1 - h[i-k])
            if i <= n-1-k:
                gi -= h[i+k]
            gj = 0.0
            if k <= j:
                gj += (1 - h[j-k])
            if j <= n-1-k:
                gj -= h[j+k]
            d[l] = dx * (gi - gj)
    
    return d
```

```python
    best_s = 0.0
    best_val = float(np.max(c))

    candidates = [0.0, lo, hi, 0.5*(lo+hi)]
    for s in candidates:
        v = float(np.max(c + s * d))

        if v2 != s:
            v = float(np.max(c + v2 * d))
        if v < best_val:
            best_val = v
            best_s = v2

    a, b = max(lo, best_s - abs(best_s)*0.5 - 0.1), min(hi, best_s + abs(best_s)*0.5 + 0.1)
    a = max(a, lo)

        if f1 < f2:
            b = m2
        else:
            a = m1
        if b - a < 1e-14:
            break
    
    s_opt = 0.5 * (a + b)
    s_opt = float(np.clip(s_opt, lo, hi))
```

Wait, ternary search doesn't work perfectly for piecewise-linear convex functions because of the kinks. Let me use a different approach.

Since f(s) = max_l (c_l + s*d_l) is convex and piecewise linear, the minimum occurs where 0 is in the subdifferential. The subdifferential at s is [min_{l in A(s)} d_l, max_{l in A(s)} d_l] where A(s) = {l : c_l + s*d_l = f(s)}.

So the optimal s is where the minimum d_l in A(s) ≤ 0 ≤ maximum d_l in A(s).

Algorithm (active set):
1. Start with s = 0 (or current value)
2. Find A(s) = argmax set
3. If min d_l in A ≤ 0 ≤ max d_l in A, we're done
4. Otherwise, if min d_l > 0, all active slopes are positive → decrease s
   If max d_l < 0, all active slopes are negative → increase s
5. Find the next kink: the s where another line becomes active
6. Go to step 2

Finding the next kink: if we need to decrease s, find the s' < s where some non-active line l' intersects the current max:
c_{l'} + s'*d_{l'} = f(s) = max_{l in A} (c_l + s*d_l)

This gives s' = (f(s) - c_{l'}) / d_{l'} for lines with d_{l'} < the current max slope.

This is getting complex. Let me just use a simpler approach: binary search on the "slope" of the convex function.

Actually, the simplest correct approach for a convex PL function:
1. Evaluate f at s=lo and s=hi
2. If f is decreasing throughout, optimum is at hi
3. If f is increasing throughout, optimum is at lo
4. Otherwise, binary search for the point where the slope changes sign

The slope at any non-kink point is d_{l*(s)} where l*(s) = argmax (c_l + s*d_l).

So:
1. Compute s_mid = (lo+hi)/2, find l* = argmax at s_mid
2. If d_{l*} > 0, the function is increasing at s_mid, so optimum is to the left: hi = s_mid
3. If d_{l*} < 0, the function is decreasing at s_mid, so optimum is to the right: lo = s_mid
4. Repeat

This binary search converges to a kink point in O(log(precision/interval)) iterations, each O(n). Total O(n log(n/precision)) which is fine.

But there's a subtlety: at a kink, the "slope" is not well-defined. The binary search might oscillate near a kink. That's OK because the function value at the kink is what we want.

```python
def pair_search_exact(h, c, i, j, n):
    """Try to improve by optimally adjusting h[i] and h[j] while keeping their sum."""
    x0 = h[i]
    y0 = h[j]
    S = x0 + y0
```

```python
def compute_c(h, n):
    return np.correlate(h, 1.0 - h, mode="full") * (2.0 / n)

def project_box_sum(v, n):
    v = np.nan_to_num(np.asarray(v, dtype=float).reshape(-1)).copy()
    tgt = 0.5 * n
    lo = float(v.min()) - 1.0
    hi = float(v.max()) + 1.0
    for _ in range(100):
        mid = 0.5 * (lo + hi)
        s = np.clip(v - mid, 0.0, 1.0).sum()
        if s > tgt:
            lo = mid
        else:
            hi = mid
    v = np.clip(v - 0.5 * (lo + hi), 0.0, 1.0)
    for _ in range(50):
        d = tgt - v.sum()
        if abs(d) < 1e-15:
            break
        m = (v > 1e-13) & (v < 1.0 - 1e-13)
        c = int(m.sum())
        if c > 0:
            v[m] += d / c
        else:
            v += d / n
        v = np.clip(v, 0.0, 1.0)

    c = compute_c(x, n)
    m = float(c.max())
    if alpha <= 0:
        return m
    sh = alpha * (c - m)
    s = float(np.exp(sh).sum())
    if s <= 0:
        return m
    return m + np.log(s) / alpha

    c = compute_c(x, n)
    m = float(c.max())
```
