4. Use a very high beta in the final optimization

For the pair polish, the key cost is evaluating C₅ for each candidate δ. With n=400, np.correlate(h, 1-h, mode='full') takes about 5-10 μs. A ternary search with 40 iterations per pair takes 400 μs. With 400*399/2 ≈ 80,000 pairs, that's 32 seconds per full sweep. We can afford about 30 sweeps in the budget.

But we don't need to try all pairs. We can be selective:
- Pairs where the gradient difference is large (indicating potential improvement)
- Pairs close to each other (local structure matters)
- Pairs where both h[i] and h[j] are in (0, 1) (boundary values can't move much)

Phase 1: Initial optimization (L-BFGS with increasing beta) - 30% of budget
Phase 2: Systematic pair polish with gradient-guided selection - 40% of budget  
Phase 3: Final L-BFGS Polish - 20% of budget
Phase 4: Very targeted pair polish on the top pairs - 10% of budget

For Phase 2, the key innovation is:
- Compute the gradient of the smoothed objective
- For each pair (i,j), estimate the potential improvement using the gradient direction (h[i] + δ, h[j] - δ)
- Prioritize pairs with the highest estimated improvement
- Do a line search on the top K pairs

- If min(a_k for active k) ≤ 0 ≤ max(a_k for active k), we're at the minimum
- If all active a_k > 0, move left
- If all active a_k < 0, move right

This is LINEAR in δ for each L! (ignoring the special case where i±L = j)

def pair_optimize_exact(h, n, i, j):
    """Find optimal delta for pair (i,j) using piecewise linear minimization."""
    dx = 2.0 / n
    hi0 = h[i]
    hj0 = h[j]
    lo = max(-hi0, hj0 - 1.0)
    hi = min(1.0 - hi0, hj0)
    if hi - lo < 1e-14:
        return h, erdos_c5(h, n)
    
    cur = erdos_c5(h, n)
    base_corr = np.correlate(h, 1.0 - h, mode='full') * dx
    
    # Compute A_L for each Lag
    # A_L = dx * [(1-h[i+L]) - h[i-L] - (1-h[j+L]) + h[j-L]]
    # where L ranges from -(n-1) to (n-1)
    # Corresponding to index n-1+L in base_corr
    
    mid = n - 1
    A = np.zeros(2 * n - 1)
    # For each lag index k (0 to 2n-2), L = k - mid
    # A[k] = dx * [(1-h[i+L])*valid(i+L) - h[i-L]*valid(i-L) - (1-h[j+L])*valid(j+L) + h[j-L]*valid(j-L)]
    
    # Vectorized:
    for k in range(2 * n - 1):
        L = k - mid
        val = 0.0
        if 0 <= i + L < n:
            val += (1.0 - h[i + L])
        if 0 <= i - L < n:
            val -= h[i - L]
        if 0 <= j + L < n:
            val -= (1.0 - h[j + L])
        if 0 <= j - L < n:
            val += h[j - L]
        A[k] = dx * val
    
    B = base_corr
    
    # Now minimize max_k (A[k]*d + B[k]) over d in [lo, hi]
    
    def eval_at(d):
        vals = A * d + B
        return float(np.max(vals)), vals
    
    # Binary search for the minimum
    best_d = 0.0
    best_c = cur
    
    # Check endpoints

    c_hi, _ = eval_at(hi)
    if c_lo < best_c:
        best_c = c_lo
        best_d = lo
    if c_hi < best_c:
        best_c = c_hi
        best_d = hi
