We can precompute the current correlate c. Then when we change h[i1] and h[i2] by d, we can update c for the affected lags only.

The affected lags are those k such that the shift k causes the pair (j, j+k) to include i1 or i2. The number of such k is at most 2n (but actually, for each of i1 and i2, the lags k for which i1 is in the sum or i1 is the shifted index, etc.).

Specifically, for a fixed index i, the lags k that are affected by changing h[i] are:
  k in [ -i, n-1-i ]   (because when k = -i, then j + k = j - i = 0 when j=i, and when k = n-1-i, then j+k = i + n-1-i = n-1)

So for i1, the lags k in [ -i1, n-1-i1 ] are affected, and for i2, lags in [ -i2, n-1-i2 ] are affected. The total number of lags is at most (n-1-i1 + i1 +1) + (n-1-i2+i2+1) = (n) + (n) = 2n, but with overlap.

n=700, so 1400 lags per variable. For 350 variables, total lags to update is 350*1400 = 490,000, which is acceptable.

But for each d in the scan, we would need to update the entire set of affected lags, and then take the max over all lags. But the max over all lags requires scanning 2n-1=1399 lags, which is cheap.

However, to compute the effect of d, we need to know for each affected lag k, the current value of S_k and how it changes with d.

For a lag k, the change in S_k when changing h[i1] and h[i2] by d is:
  Let a = 0
  If the term h[i1] appears as j in the sum (i.e., j=i1 and j+k in [0,n-1]), then the term h[i1]*(1-h[i1+k]) becomes (h[i1]+d)*(1-h[i1+k]), so change = d*(1-h[i1+k])
  If the term h[i1] appears as the shifted index (i.e., j+k = i1, so j = i1-k, and i1-k in [0,n-1]), then the term h[i1-k]*(1-h[i1]) becomes h[i1-k]*(1-(h[i1]+d)), so change = -d * h[i1-k]
  Similarly for i2.

But if a term involves both i1 and i2, for example if i1+k = i2, then the term h[i1]*(1-h[i2]) is changed to (h[i1]+d)*(1-h[i2]-d) = h[i1](1-h[i2]) - d*h[i1] - d*(1-h[i2]) - d^2.
So the change is -d*(h[i1] + 1 - h[i2]) - d^2.

This is quadratic.

So for each lag k, we can write:
  S_k_new = S_k + A_k * d + B_k * d^2
where B_k is -1 if the lag k has a term that includes both i1 and i2, else 0.
And A_k is the linear coefficient.

How to compute A_k and B_k for a given k and (i1,i2)?

For a fixed k, the sum S_k = sum_{j} h[j] * (1 - h[j+k]) for j such that 0<=j<n and 0<=j+k<n.

import numpy as np
import time
from scipy.optimize import minimize

def compute_c5(h, n):
    dx = 2.0 / n
    return float(np.max(np.correlate(h, 1.0 - h, mode='full')) * dx)

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h.copy(), 0.0, 1.0)
    for _ in range(200):
        diff = target - h.sum()
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            room = 1.0 - h
            tot = room.sum()
            if tot < 1e-15:
                break
            h = np.clip(h + (diff / tot) * room, 0.0, 1.0)
        else:
            tot = h.sum()
            if tot < 1e-15:
                break
            h = np.clip(h + (diff / tot) * h, 0.0, 1.0)
    return h

def project_symmetric(x, m, target_sum):
    x = np.clip(x.copy(), 0.0, 1.0)
    for _ in range(200):
        diff = target_sum - x.sum()
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            room = 1.0 - x
            tot = room.sum()
            if tot < 1e-15:
                break
            x = np.clip(x + (diff / tot) * room, 0.0, 1.0)
        else:
            tot = x.sum()
            if tot < 1e-15:
                break
            x = np.clip(x + (diff / tot) * x, 0.0, 1.0)
    return x

def build_symmetric(x, m):
    return np.concatenate([x, x[::-1]])

                improved = True

def _sym_sum_eq(x, target_sum):
    return x.sum() - target_sum

def _sym_sum_eq_jac(x, target_sum):
    return np.ones(len(x))

def symmetric_slsqp(x, n, maxiter=300):
    m = n // 2
    target_sum = n / 4.0
    def obj_func(x_s):
        h_full = build_symmetric(x_s, m)
        return compute_c5(h_full, n)
    bounds = [(0.0, 1.0)] * m
    cons = [{'type': 'eq', 'fun': _sym_sum_eq, 'jac': _sym_sum_eq_jac, 'args': (target_sum,)}]
    try:
        res = minimize(obj_func, x, method='SLSQP', bounds=bounds, constraints=cons,
                        options={'maxiter': maxiter, 'ftol': 1e-12})
        if res.x is not None:
            x_new = project_symmetric(res.x, m, target_sum)
            c_new = compute_c5(build_symmetric(x_new, m), n)
            return x_new, c_new
    except Exception:
        pass
    return x, compute_c5(build_symmetric(x, m), n)
