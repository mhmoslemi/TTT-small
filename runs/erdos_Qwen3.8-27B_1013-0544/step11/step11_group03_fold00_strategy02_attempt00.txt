- Sum over domain equals target integral: ∫₀ᴸ h(x) dx = 1
- Bounded domain: h(x) ∈ [0,1] for all x

## 2.2 Objective Function
The overlap integral is computed as:

C = maxₖ ( (∫₀² h(x) * [1 - h(x+k)] dx ) / (maximum possible) )

via discrete correlation operator:

C ≈ maxₖ [ dx * np.correlate(h, (1-h), mode='full')[k] ]

subject to h(x) ∈ [0,1] and ∫h dx=1

## 2.3 Transformation Between Grids
Base grid parent creation:

Given candidate h_parent on grid n_old, to create child on grid n_new:

```python
def interpolate_parent(parent, new_size):
    n_old = len(parent)
    if new_size >= n_old:
        x_old = np.linspace(0, 2, n_old)
        x_new = np.linspace(0, 2, new_size)
        child = np.interp(x_new, x_old, parent)
        project_feasible(child, new_size) # Maintains [0,1] and integral=1
        return child
    else:
        # Downsample exactly for larger grids
        downsampled = parent[::n_old//new_size] if n_old % new_size==0 else parent[:new_size]
        return project_feasible(downsampled, new_size)
```

## 2.4 Projection Function
```python
def project_feasible(h, n):
    """Project to satisfy [0,1] bounds and integral=1"""
    target = n/2.0
    for _ in range(200):
        diff = target - np.sum(h)
        if abs(diff) < 1e-13:
            break
        if diff > 0:
            room = 1.0 - h
            if room.sum() > 0:
                h += (diff / room.sum()) * room
            else:
                break
        else:
            content = h
            if content.sum() > 0:
                h += (diff / content.sum()) * -1 * content
            else:
                break
    return np.clip(h, 0, 1)
```

## 3.2 Hybrid Optimization

```python
def hybrid_optimize(initial, n, deadline):
    """Composite optimization using harmonic analysis, projection, and local search"""
    # Phase 0: Broad harmonic initialization
    best_point, phase_c = harmonic_init(initial.copy(), n)
    
    # Phase 1: Projected gradient descent
    for _ in range(10):  # With time budget monitoring
        def objective(x):
            return compute_smooth_objective(x.reshape(-1).astype(float), n)
        # Define simple box constraints
        cons = {'type': 'eq', 'fun': lambda x: np.sum(x) - n/2}
        res = minimize(objective, best_point.flatten(), method='SLSQP', 
                        bounds=[(0,1)]*n, constraints=cons)
        if not res.success:
            break
        best_point = res.x
        if compute_c5(best_point, n) < phase_c:
            phase_c = compute_c5(best_point, n)
    
    # Phase 2: Local Nelder-Mead refinement
    best_point, phase_c = nelder_mead_refine(best_point, n, deadline)
    return best_point, phase_c
```

## 3.3 Harmonic Initialization

```python
def harmonic_init(x0, n):
    # Use Fourier frequencies
    freqs = [0.7, 0.8, 0.9]  # Multi-scale basis frequencies
    phases = [0.1, 0.3, 0.5]  # Random phase bias
    
    n_freqs = 10
    h = np.zeros(n)
    freq_components = [np.cos(2*np.pi*freq*x*step) for freq,step in zip(freqs, [0.1]*len(freqs))]
    
    xs = np.linspace(0, 2, n)
    for i in range(n_freqs):
        amp = np.random.random() * 0.1
        freq = freqs[i%3] + (i*(n_freqs)**0.3)/n_freqs
        phase = phases[i%3] + np.random.random()*0.7
        h += amp * np.cos(freq*xs + phase)
    
    # Normalize integration
    dx = 2/n
    integral_val = np.sum(h) * dx
    if abs(integral_val-1) > 0.2:
        h *= 1/integral_val
        
    x0[:] = np.clip(h, 0, 1)
    return x0, compute_c5(x0, n)
```

  # 4. Search Choices and Variations

## 4.1 Phase Distribution
The initial optimization phase dedicated 30% computational resources to find good candidates, with subsequent phases shortening by 5%. This is because finer grids require more time to optimize but often yield better minima.

## 4.2 Basis Scaling
The basis frequencies for harmonic representation start at 0.7 and increase to 0.9. The number of frequency components is X = ceil(sqrt(n)) and increases with resolution until a maximum per grid point.

## 4.3 Dynamic Phase Adjustment
The harmonic basis and step sizes adapt with grid resolution: for finer grids, basis frequencies are increased by 0.05/max_n (to reduce low-frequency oscillations dominating).

## 4.4 Fail-Safe for Longest Run
When stuck, use increasing frequency basis oscillations (increasing from 0.1 to 0.2 to 0.3 per grid phase).

## 4.5 Adaptive Grid Step Sizes
Grid step sizes are increased by up to 50% when no improvement is detected for three consecutive grid steps.

## 4.6 Noise Level
Harmonic perturbations use amplitude level = (grid_edge_effect) where grid_edge_effect = 0.1 * (n**0.3)
