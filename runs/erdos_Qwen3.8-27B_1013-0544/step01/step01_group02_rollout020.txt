But we also need to handle the "multiple.active constraints" case. A better approach is to use the "smoothed" gradient:
grad_smooth = sum_k softmax(c, alpha)[k] * grad_shift(h, n, k-(n-1))

This gives a smooth approximation to the subgradient of the max.

Actually, this is exactly what the log-sum-exp SLSQP approach does. The gradient of the log-sum-exp objective is:
∂/∂h[j] sum_k exp(alpha * c_k) / alpha * sum_k exp(alpha * c_k)
= sum_k exp(alpha * c_k) / sum_k exp(alpha * c_k) * grad_shift(k)
= sum_k softmax_k * grad_shift(k)

So the SLSQP with log-sum-exp is already computing a "weighted sum of subgradients" where the weights are the softmax of the overlaps. At high alpha, this concentrates on the single worst shift.

OK so my approach is essentially the same as what the previous solution does, but I can make it more efficient by:
1. Computing the gradient analytically (faster than finite differences)
2. Using the gradient to guide the search

But SLSQP uses finite differences by default (or analytical if you provide jac). Let me provide the analytical Jacobian of the smooth objective!

The Jacobian of obj_smooth(h, n, alpha) with respect to h:
J[j] = sum_k w_k * grad_shift(k)[j]
where w_k = exp(alpha * c_k) / sum_m exp(alpha * c_m)

This is O(n * (2n-1)) = O(n²) per evaluation, which for n=80 is about 12800 operations. Very fast.

Let me implement this:

```python
def obj_smooth_jac(h, n, alpha):
    """Objective and its gradient."""
    dx = 2.0 / n
    c = np.correlate(h, 1 - h, mode='full') * dx
    m = c.max()
    shifted = alpha * (c - m)
    # Softmax weights
    mx = shifted.max()
    exp_shifted = np.exp(shifted - mx)
    weights = exp_shifted / exp_shifted.sum()
    obj = float(m + (mx + np.log(exp_shifted.sum())) / alpha)
    # Gradient: sum_k weights[k] * grad_shift(k)
    grad = np.zeros(n)
    for idx in range(len(c)):
        if weights[idx] < 1e-15:
            continue
        s = idx - (n - 1)
        lo = max(0, -s)
        hi = min(n-1, n-1-s)
        if lo > hi:
            continue
        grad[lo+s : hi+s+1] += weights[idx] * (1.0 - h[lo : hi+1])
        grad[lo : hi+1] -= weights[idx] * h[lo+s : hi+s+1]
    grad *= dx  # Wait, do I need to multiply by dx?
```
