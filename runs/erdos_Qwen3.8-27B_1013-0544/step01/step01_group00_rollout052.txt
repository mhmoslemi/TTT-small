   One more thought: I should also try the "dual" approach. The problem is:
   min_h max_k f_k(h) subject to constraints
   
   By duality (for the inner max), this is equivalent to:
   min_h max_{p ∈ Δ} sum_k p_k * f_k(h) subject to constraints
   where Δ is the simplex.
   
   The inner problem (for fixed p) is: min_h sum_k p_k * f_k(h) subject to constraints.
   This is a quadratic minimization (since f_k is bilinear in h), which can be solved with SLSQP.
   
   The outer problem is: max_{p ∈ Δ} [min_h sum_k p_k * f_k(h)]
   
   This is a max-min problem that can be solved by:
   - Start with p = uniform
   - Solve inner problem to get h*
   - Update p = argmax_k f_k(h*) (put all weight on the worst k)
   - Or: p_k ∝ f_k(h*) (softmax update)
   - Iterate

   min_{h, t} t subject to t >= f_k(h) for all k, sum(h) = n/2, 0<=h<=1
   
   Which is the epigraph formulation. The dual of the inequality constraints gives the p's.

def project_h(h, target):
    h = h.copy()
