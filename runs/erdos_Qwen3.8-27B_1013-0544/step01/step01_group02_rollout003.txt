The Frank-Wolfe method for min f(x) s.t. x ∈ P:
1. At each step, compute gradient g = ∇f(x)
2. Find s = argmin_{y ∈ P} <g, y>  (the "linear oracle")
3. Update: x_{t+1} = (1-γ_t) x_t + γ_t s

For our problem, P = {x : 0 ≤ x_i ≤ 1, sum(x) = n/2}.
The linear oracle is: find s ∈ P that minimizes <g, s> = sum_i g_i * s_i.
This is: minimize sum_i g_i * s_i s.t. 0 ≤ s_i ≤ 1, sum s_i = n/2.
The solution is: s_i = 1 if g_i is among the smallest n/2 values, 0 otherwise (with ties broken appropriately).

Wait, that's not quite right. We want to minimize sum g_i * s_i with sum s_i = n/2 and 0 ≤ s_i ≤ 1.
The greedy solution: set s_i = 1 for the n/2 indices with the smallest g_i, and 0 for the rest.
(n/2 is an integer since n=80, so this works perfectly.)

This is very efficient! The Frank-Wolfe step is O(n log n) for sorting.

def frank_wolfe_step(h, n, grad):
    """Compute Frank-Wolfe vertex: minimize <grad, s> s.t. s in P."""
    # Set s_i = 1 for n/2 indices with smallest grad_i
    k = n // 2
    idx = np.argpartition(grad, k)[:k]
    s = np.zeros(n)
    s[idx] = 1.0
    return s

def compute_c5(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1 - h, mode='full') * dx
    return float(c.max())

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h, 0.0, 1.0).copy()
    lo, hi = -3.0, 3.0
    for _ in range(80):
        mid = (lo + hi) / 2.0
        x = np.clip(h - mid, 0.0, 1.0)
        if x.sum() > target:
            lo = mid
        else:
            hi = mid
    tau = (lo + hi) / 2.0
    x = np.clip(h - tau, 0.0, 1.0)
    diff = target - x.sum()
    if abs(diff) > 1e-13:
        mask = (x > 1e-10) & (x < 1.0 - 1e-10)
        if mask.sum() > 0:
            x[mask] += diff / mask.sum()
            x = np.clip(x, 0.0, 1.0)
    return x

def get_correlations(h, n):
    dx = 2.0 / n
    return np.correlate(h, 1 - h, mode='full') * dx

def soft_gradient(h, n, alpha):
    c = get_correlations(h, n)
    m = c.max()
    shifted = alpha * (c - m)
    mx = shifted.max()
    weights = np.exp(shifted - mx)
    weights /= weights.sum()
    grad = np.zeros(n)
    for idx in range(len(weights)):
        w = weights[idx]
        if w < 1e-7:
            continue
        offset = idx - (n - 1)
        j1, j2 = max(0, -offset), min(n, n - offset)
        if j2 > j1:
            grad[j1:j2] += w * (1.0 - h[j1 + offset:j2 + offset])
        j3, j4 = max(0, offset), min(n, n + offset)
        if j4 > j3:
            grad[j3:j4] += w * (-h[j3 - offset:j4 - offset])
    return grad

    m = c.max()

        v = b2 * v + (1 - b2) * g * g

        c = compute_c5(h, n)
