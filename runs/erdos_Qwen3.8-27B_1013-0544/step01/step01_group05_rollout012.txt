The objective is: C5 = max_k ∫₀² h(x) (1 - h(x+k)) dx

In discrete form: C5 = max_k Σ_j h[j] (1 - h[j+k]) * dx  (with appropriate index handling)

The gradient of the k-th correlation term with respect to h[i] is:
- If i is in the "h(x)" part: coefficient is (1 - h[i+k]) (if i+k is valid)
- If i is in the "1-h(x+k)" part: coefficient is -h[i-k] (if i-k is valid)

This is exactly what compute_grad_lag computes. Good.

For the smooth max: (1/β) log Σ_k exp(β * c_k)
The gradient is: Σ_k (exp(β*c_k) / Σ_k' exp(β*c_k')) * grad(c_k)

where w_k = exp(β*c_k) / Σ_k' exp(β*c_k')

This is a convex combination of the individual gradients, weighted by how close each c_k is to the maximum. As β → ∞, this approaches the gradient of the max (which is just the gradient of the argmax).

def project_feasible(x, target_sum):
    lo = -1.0
    hi = 2.0
    for _ in range(100):
        mid = (lo + hi) * 0.5
        s = float(np.clip(x - mid, 0.0, 1.0).sum())
        if s > target_sum:
            lo = mid
        else:
            hi = mid
    return np.clip(x - (lo + hi) * 0.5, 0.0, 1.0)

def compute_c5(h, dx):
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr)) * dx

def compute_grad_lag(h, L):
    n = len(h)
    omh = 1.0 - h
    grad = np.zeros(n)
    if L == 0:
        grad[:] = omh[:] - h[:]
    elif L > 0:
        grad[L:] += omh[:n - L]
        grad[:n - L] -= h[L:]
    else:
        L2 = -L
        grad[:n - L2] += omh[L2:]
        grad[L2:] -= h[:n - L2]
    return grad

def smooth_grad(h, beta):
    n = len(h)
    corr = np.correlate(h, 1.0 - h, mode='full')
    bc = beta * corr
    bc -= np.max(bc)
    w = np.exp(bc)
    wsum = np.sum(w)
    w /= wsum
    nh = n - 1
    grad = np.zeros(n)
    for j in range(2 * n - 1):
        if w[j] > 1e-8:
            grad += w[j] * compute_grad_lag(h, j - nh)
    return grad

def active_grad(h, k):
    n = len(h)
    corr = np.correlate(h, 1.0 - h, mode='full')
    nh = n - 1
    top = np.argsort(corr)[-k:]
    grad = np.zeros(n)
    for j in top:
        grad += compute_grad_lag(h, j - nh)
    return grad / float(k)
