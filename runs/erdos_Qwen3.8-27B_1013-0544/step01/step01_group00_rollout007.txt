1. If i = n+k for some valid n: the term h[i]*(1-h[n]) changes. n = i-k. Valid if 0 <= i-k < N.
   Contribution to C(k): (1-h[i-k])*dx (linear in h[i], coefficient is (1-h[i-k])*dx)
   
   Wait, no. The term IS h[i]*(1-h[i-k])*dx. So as a function of h[i], it's (1-h[i-k])*dx * h[i]. Linear with slope (1-h[i-k])*dx.

2. If i = n for some valid n: the term h[n+k]*(1-h[i]) changes. n = i. Valid if 0 <= i+k < N.
   Contribution to C(k): -(h[i+k])*dx * h[i] + h[i+k]*dx. 
   As a function of h[i]: h[i+k]*dx - h[i+k]*dx * h[i]. Linear with slope -h[i+k]*dx.

So for k ≠ 0 (or more precisely, when the two cases don't overlap):
C(k) as a function of h[i] = S_k + slope_k * h[i]
where slope_k = dx * [(1-h[i-k])*1(0<=i-k<N) - h[i+k]*1(0<=i+k<N)]
and S_k is the rest of the sum.

For k = 0: C(0) = dx * sum h[n]*(1-h[n]) = dx * (sum h - sum h^2)
The term involving h[i] is h[i]*(1-h[i])*dx = (h[i] - h[i]^2)*dx
So C(0) = T_0 + dx*h[i] - dx*h[i]^2 where T_0 is the rest.

The objective min_{h[i] in [0,1]} max_k C(k) is a 1D problem. Since most terms are linear and one is quadratic (concave), the max is a piecewise function. The minimum can be found by:
1. Evaluating at all breakpoints (where two lines cross, or where a line crosses the parabola)
2. Evaluating at the boundaries 0 and 1
3. Finding the vertex of any parabola that's on the upper envelope

This is doable but complex. For a practical implementation, I'll just use a fine grid search over h[i] ∈ [0,1] (say 1000 points) and take the best.

But wait, I also need to maintain the sum constraint. If I change h[i] by δ, I need to change some other h[j] by -δ. 

One approach: **pairwise coordinate descent**. Pick a pair (i,j) and optimize both simultaneously while maintaining h[i]+h[j] = constant.

Another approach: **Use a Lagrange multiplier**. Introduce λ for the constraint sum(h) = N/2. The Lagrangian is:
L = max_k C(k) + λ*(sum(h) - N/2)

For coordinate descent on L, the optimal h[i] is found by minimizing:
max_k C(k)(h[i]) + λ*h[i]

This is the max of linear functions (plus one quadratic) shifted by λ*h[i]. The minimum is where the upper envelope is minimized, shifted by the linear term.

But λ needs to be updated (dual ascent) to satisfy the constraint. This is a min-max problem.

import numpy as np
from scipy.optimize import minimize
import time


def compute_c5(h):
    dx = 2.0 / len(h)
    corr = np.correlate(h, 1.0 - h, mode='full') * dx
    return float(np.max(corr))


def project_onto_simplex(h, target_sum):
    h = np.clip(h, 0.0, 1.0)
    lo, hi = -2.0, 2.0
    for _ in range(80):
        mid = (lo + hi) * 0.5
        s = np.sum(np.clip(h + mid, 0.0, 1.0))
        if s < target_sum:
            lo = mid
        else:
            hi = mid
    mu = (lo + hi) * 0.5
    return np.clip(h + mu, 0.0, 1.0)


def corr_array(h):
    dx = 2.0 / len(h)
    return np.correlate(h, 1.0 - h, mode='full') * dx


def gradient_of_corr(h, k_lag):
    """Gradient of the k-th correlation value w.r.t. h."""
    N = len(h)
    dx = 2.0 / N
    grad = np.zeros(N)
    # C(k) = dx * sum_n h[n+k] * (1-h[n]) for valid n
    # dC/dh[i] = dx * [(1-h[i-k])*1(0<=i-k<N) - h[i+k]*1(0<=i+k<N)]
    i_lo = max(0, k_lag)
    i_hi = min(N, N + k_lag)
    if i_lo < i_hi:
        j_lo = i_lo - k_lag
        j_hi = i_hi - k_lag
        grad[i_lo:i_hi] += dx * (1.0 - h[j_lo:j_hi])
    i_lo2 = max(0, -k_lag)
    i_hi2 = min(N, N - k_lag)
    if i_lo2 < i_hi2:
        j_lo2 = i_lo2 + k_lag
        j_hi2 = i_hi2 + k_lag
        grad[i_lo2:i_hi2] -= dx * h[j_lo2:j_hi2]
    return grad


def smooth_obj_grad(h, temp):
    N = len(h)
    C = corr_array(h)
    t = np.max(C)
    exps = (C - t) / temp
    exps_max = np.max(exps)
    p = np.exp(exps - exps_max)
    p_sum = np.sum(p)
    p /= p_sum
    obj = t + temp * (np.log(p_sum) + exps_max)
    grad = np.zeros(N)
    for idx in range(2 * N - 1):
        k = idx - (N - 1)
        pk = p[idx]
        if pk < 1e-15:
            continue
        i_lo = max(0, k)
        i_hi = min(N, N + k)
        if i_lo < i_hi:
            j_lo = i_lo - k
            j_hi = i_hi - k
            grad[i_lo:i_hi] += pk * (1.0 - h[j_lo:j_hi])
        i_lo2 = max(0, -k)
        i_hi2 = min(N, N - k)
        if i_lo2 < i_hi2:
            j_lo2 = i_lo2 + k
            j_hi2 = i_hi2 + k
            grad[i_lo2:i_hi2] -= pk * h[j_lo2:j_hi2]
    grad *= (2.0 / N)
    return obj, grad


def nesterov_projected_grad(h, temp, lr, beta, target_sum, n_steps=2000):
    N = len(h)
    v = np.zeros(N)
    h_cur = h.copy()
    best_h = h_cur.copy()
    best_c5 = compute_c5(h_cur)
    for it in range(n_steps):
        obj, g = smooth_obj_grad(h_cur, temp)
        v = beta * v + (1 - beta) * g
        h_new = h_cur - lr * v
        h_new = project_onto_simplex(h_new, target_sum)
        c5 = compute_c5(h_new)
        if c5 < best_c5:
            best_c5 = c5
            best_h = h_new.copy()
        h_cur = h_new
        if it % 500 == 0:
            lr *= 0.95
    return best_h, best_c5


def subgradient_step(h, max_lags, lr, target_sum, n_steps=500):
    N = len(h)
    h_cur = h.copy()
    best_h = h_cur.copy()
    best_c5 = compute_c5(h_cur)
    for it in range(n_steps):
        C = corr_array(h_cur)
        active = np.where(C > C[-1] - 1e-6)[0]
        if len(active) == 0:
            active = np.array([np.argmax(C)])
        g = np.zeros(N)
        for idx in active[:max_lags]:
            k = idx - (N - 1)
            g += gradient_of_corr(h_cur, k)
        g /= len(active[:max_lags])
        h_new = h_cur - lr * g

            h_cur = h_up
            c5_cur = c5_up
            h_n, c5_n = nesterov_projected_grad(h_cur, 0.01, lr=0.5, beta=0.9,
                                                target_sum=tgt, n_steps=2000)
            if c5_n < c5_cur:
                h_cur, c5_cur = h_n, c5_n
            if time_left() > 100:
                h_t, c5_t = t_slsqp_cuts(h_cur, max_iter=200, n_top=15)
                if c5_t < c5_cur:
                    h_cur, c5_cur = h_t, c5_t
            if c5_cur < c5_best:
                h_best = h_cur.copy()
                c5_best = c5_cur

    # Final: one more SLSQP polish at best resolution
    if time_left() > 60:
        h_t, c5_t = t_slsqp_cuts(h_best, max_iter=400, n_top=25)
        if c5_t < c5_best:
            h_best = h_t.copy()
            c5_best = c5_t

    h_best = np.clip(h_best, 0.0, 1.0)
    h_best = project_onto_simplex(h_best, len(h_best) * 0.5)
    c5_final = compute_c5(h_best)
    return h_best, c5_final, len(h_best)
