4. To reduce c_k, we want to either:

   - Increase h[i] where h[i+k] = 1 (doesn't change c_k directly but might help other lags)
   
   Wait, actually to reduce c_k = sum_i h[i] * (1-h[i+k]):
   - If we decrease h[i] by δ where (1-h[i+k]) > 0, c_k decreases by δ * (1-h[i+k])
   - But we need to increase some other h[j] by δ to maintain the sum constraint
   - Increasing h[j] by δ changes c_k by δ * (1-h[j+k]) (could increase or decrease c_k)
   
   So the net change in c_k from moving δ from i to j is:
   Δc_k = -δ * (1-h[i+k]) + δ * (1-h[j+k]) = δ * (h[i+k] - h[j+k])
   
   To reduce c_k, we want Δc_k < 0, i.e., h[i+k] < h[j+k].
   
   But we also need to consider the effect on other lags, especially other binding lags.

This gives us a principled way to choose moves:
- For the binding lag k*, find pairs (i, j) such that h[i+k*] < h[j+k*] (this reduces c_{k*})
- Among these, prefer pairs where the move also reduces or doesn't increase other binding lags

The problem is:

subject to 0 ≤ h[i] ≤ 1, sum(h) = n/2

5. Solve the LP
6. Set h_temp = h_new, repeat
