For the discrete version (which is what we're computing), the problem is:
- Find a binary (or gray) sequence of length n with sum = n/2
- That maximizes the minimum autocorrelation

This is related to "low autocorrelation" sequences, but we want HIGH minimum autocorrelation (not low maximum).

For a binary sequence with n/2 ones and n/2 zeros, the autocorrelation at lag k counts the number of positions where both h[i] and h[i+k] are 1 (with wraparound or without).

Without wraparound (which is what np.correlate with mode="full" gives us), the autocorrelation at lag k is:
R(k) = sum_{i=0}^{n-1-|k|} h[i]*h[i+|k|]

We want to maximize min_k R(k).

For a random binary sequence with n/2 ones, the expected autocorrelation at lag k is approximately (n-|k|)/4. The minimum would be around (n-n+1)/4 ≈ 0 for large k, which is bad.

To maximize the minimum, we want the autocorrelation to be as flat as possible. This suggests a structure where the 1s are evenly spaced.

If we put 1s at positions 0, 2, 4, ..., n-2 (every other position), then:
- R(0) = n/2
- R(1) = (n/2 - 1) (each 1 at even position has a 0 at the next, except boundaries)
  Actually: h = [1,0,1,0,...,1,0]. R(1) = sum h[i]*h[i+1] = 0 (no adjacent 1s)
  That's terrible.

If we put 1s at positions 0, 3, 6, 9, ... (every 3rd position), with n/2 of them:
- The spacing is 3, so there are n/3 ≈ n/2 ones (roughly)
- R(k) for k=1,2 would be low

Hmm, this approach doesn't seem to work well because the autocorrelation has peaks at multiples of the spacing and is low in between.

Maybe a better approach is to use a "smeared" version where h is not binary but takes intermediate values. The optimal solution likely has h taking values in {0, a, 1-a, 1} for some a, or taking a range of values.

    """Project h to {x: sum(x)=target, 0<=x<=1} via bisection on dual variable."""
    h = np.asarray(h, dtype=float)
    n = len(h)

        else:

    c = np.clip(corr, 0, None)
    if p == np.inf:
        return c.max()
    return (c**p).sum()**(1/p)

        g[corr == c.max()] = 1.0
        g /= g.sum()
        return g
    s = (c**p).sum()

    return (p * c**(p-1)) / s**((p-1)/p)

def project_constraint(h, target):
    h = np.asarray(h, dtype=float)
    lo, hi = -2.0, 2.0

        if s > target:
            lo = mid
        else:

    if abs(d) > 1e-14:

        c = m.sum()
        if c > 0:
            proj[m] += d / c

    return proj

def full_corr(h):

def p_norm_val(corr, p):
    c = np.clip(corr, 0, None)
    if p > 1e6:
        return float(c.max())
    return float((c ** p).sum() ** (1.0 / p))

def p_norm_weights(corr, p):
    c = np.clip(corr, 0, None)
    if p > 1e6:
        w = np.zeros_like(corr)
        mx = c.max()
        w[c >= mx - 1e-12] = 1.0
        s = w.sum()
        if s > 0:
            w /= s
        return w
    s = (c ** p).sum()
    if s < 1e-30:
        return np.ones(len(corr)) / len(corr)
    return c ** (p - 1) / s

def compute_gradient(x, weights):
    n = len(x)
    g = np.zeros(n)
    for li in range(len(weights)):
        wi = weights[li]
        if wi < 1e-16:
            continue
        k = li - (n - 1)
        if k >= 0:
            g[k:] += wi * (1.0 - x[:n - k])
            g[:n - k] -= wi * x[k:]
        else:
            g[:n + k] += wi * (1.0 - x[-k:])
            g[-k:] -= wi * x[:n + k]
    return g

        k = li - (n - 1)

        else:
            g[:n + k] += (1.0 - h[-k:])
            g[-k:] -= h[:n + k]

        return compute_gradient(x, w)
