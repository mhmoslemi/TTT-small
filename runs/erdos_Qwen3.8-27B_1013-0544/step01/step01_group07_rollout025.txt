def smooth_max_grad(h, t):
    n = len(h)
    r = np.correlate(h, 1-h, mode="full")  # length 2n-1
    # Softmax weights
    r_max = np.max(r)
    exp_r = np.exp(t * (r - r_max))
    p = exp_r / np.sum(exp_r)  # length 2n-1
    # p[k] corresponds to shift s = n-1-k
    # grad[j] = sum_k p[k] * ((1-h[j+s_k])*I(j+s_k in [0,n-1]) - h[j-s_k]*I(j-s_k in [0,n-1]))
    grad = np.zeros(n)
    for j in range(n):
        for k in range(2*n-1):
            s = n-1-k
            if 0 <= j+s < n:
                grad[j] += p[k] * (1-h[j+s])
            if 0 <= j-s < n:
                grad[j] -= p[k] * h[j-s]
    return grad
```

def binary_local_search(h_bin, dx, n_rounds=10000, seed=0):
    """Simulated annealing on binary sequence with swap moves"""
    n = len(h_bin)
    rng = np.random.RandomState(seed)
    h = h_bin.copy()
    ones = np.where(h == 1)[0]
    zeros = np.where(h == 0)[0]
    
    r = np.correlate(h, 1-h, mode="full")
    R = r * dx
    best_c5 = np.max(R)
    best_h = h.copy()
    
    # Start with high temperature
    T = best_c5 * 0.1
    T_min = 1e-6
    
    for it in range(n_rounds):
        # Pick a random swap
        i = ones[rng.randint(len(ones))]
        j = zeros[rng.randint(len(zeros))]
        
        # Compute the change in R from swapping h[i]=0->1, h[j]=1->0
        # ... (this is the expensive part, but O(n))
        
        # Actually, let me just recompute from scratch for simplicity
        # With n=160, np.correlate is fast
        h[i] = 1; h[j] = 0
        r_new = np.correlate(h, 1-h, mode="full")
        R_new = r_new * dx
        c5_new = np.max(R_new)
        
        # Accept/reject
        if c5_new < best_c5 or rng.rand() < np.exp(-(c5_new - best_c5) / T):
            # Accept
            ones = np.where(h == 1)[0]
            zeros = np.where(h == 0)[0]
            if c5_new < best_c5:
                best_c5 = c5_new
                best_h = h.copy()
        else:
            h[i] = 0; h[j] = 1  # Revert
        
        # Cool down
        T = max(T * 0.999, T_min)
    
    return best_h, best_c5
```

But this recomputes the full correlation each iteration, which is O(n^2) per iteration. For n=160 and 10000 iterations, that's 160*160*10000 = 256 million operations. Might be too slow in Python.

Better approach: incremental update. When we swap h[i] from 0 to 1:
- For each k in [0, 2n-2]: r[k] changes
  - The term h[i]*(1-h[i+s_k]) changes from 0 to (1-h[i+s_k]) if i+s_k is valid
  - The term h[i-s_k]*(1-h[i]) changes from h[i-s_k]*1 to h[i-s_k]*0 = 0 if i-s_k is valid

So Δr[k] = (1-h[i+s_k])*I(0≤i+s_k<n) - h[i-s_k]*I(0≤i-s_k<n)

When we swap h[j] from 1 to 0:
Δr[k] = -(1-h[j+s_k])*I(0≤j+s_k<n) + h[j-s_k]*I(0≤j-s_k<n)

Total change: Δr[k] = [(1-h[i+s_k])*I - h[i-s_k])*I] + [-(1-h[j+s_k])*I + h[j-s_k])*I]

This is O(n) to compute for all k. Then we can update the max in O(1) if we maintain a sorted structure, or O(n) if we just recompute.

For n=160, O(n) per step with 100000 steps = 16 million operations. That's very fast.
