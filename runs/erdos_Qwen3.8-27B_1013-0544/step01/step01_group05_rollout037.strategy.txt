1. **Approach and rationale**  
The central idea is to represent the step function \(h(x)\) as a piecewise constant function on a grid, and use **alternating least squares optimization** to minimize the maximum overlap integral. This approach leverages the separable structure of the optimization problem by fixing the positions of the step changes and optimizing the function heights separately. By iteratively updating function values (`heights`) and step positions (`breaks`), we escape local optima and gradually refine the solution. This method is hybrid between gradient-based and iterative reweighted least squares (IRLS) and is distinct from previous stochastic gradient methods and continuous basis approximations.  

The key bottleneck from previous methods was slow convergence, often getting stuck in local optima. This strategy addresses it by explicitly cyclically optimizing the functional form and step locations. The feasible set constraints (\(0 \leq h[i] \leq 1\) and \(\sum h_i = \text{target}\)) are maintained via projection after each update.

2. **Mathematical specification**  
- **Variables**: Let \(h\) be a vector of function values at grid points \([0, 2/n_{\text{points}}] \ldots [2]\). We introduce \(k\) break points (positions where \(h(x)\) changes) from 0 to \(N = n_{\text{points}}\). The step function is defined by the break indices \(b_0, b_1, \ldots, b_{m}\) (sorted) and \(m\) heights \(z_1, \ldots, z_m\) (values between 0 and 1).  
- **Objective**: Minimize \(C_5 = \max_k (\text{integral of } h(x)(1-h(x+k)) \text{ over []}\) equivalent to \(\max_k (\text{cross-correlation integral})\).  
- **Constraints**: \(0 \leq h_i \leq 1\) for all \(i\), and \(\sum h_i = N/2\).  
- **Optimization**:  
  - **Step 1**: Fix break points and optimize heights via gradient descent with projected feasible steps.  
  - **Step 2**: Fix heights and optimize break points (discrete indices) via combinatorial search (but high-dimensional and impractical directly).  
  Instead, we use a low-rank basis representation for breaks (via basis transformation) to make it smoothable and optimizable.  

3. **Implementation procedure**  
   - **Inputs**: `initial_h_values` (if provided), `n_points=70`, `dx=2.0/n_points`, `target_sum=n_points/2.0`.  
   - **Preprocessing**: Start from `initial_h_values` if available, otherwise uniform initialization.  
   - **Cyclic Optimization**:  
     - **Phase 1**: Iterate alternating between:  
        1. **Optimize Heights**: Use projected gradient descent (`project_feasible`) with step size scheduling based on `c5`. Track best solution \(h_{\text{best}}\) and \(C_5^{\text{best}}\).
