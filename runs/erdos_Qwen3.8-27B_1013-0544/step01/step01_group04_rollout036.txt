As τ → ∞, this approaches the max. For finite τ, we get a smooth approximation that we can optimize with gradient methods.

The gradient of the soft max is:
∇(1/τ * log(∑ exp(τ g_k))) = ∑_k p_k * ∇g_k where p_k = exp(τ g_k) / ∑_j exp(τ g_j)

This is a weighted average of the gradients of all terms, weighted by their "softmax" probabilities. This gives a smoother direction than using just the single active term.

Let me implement this:

```python
def soft_max_objective(h, dx, tau=100):
    n = len(h)
    c = np.correlate(h, 1.0 - h, mode='full') * dx
    max_c = np.max(c)
    shifted = c - max_c  # for numerical stability
    exp_vals = np.exp(tau * shifted)
    obj = max_c + np.log(exp_vals.sum()) / tau
    return obj

def soft_max_gradient(h, dx, tau=100):
    n = len(h)
    c = np.correlate(h, 1.0 - h, mode='full') * dx
    max_c = np.max(c)
    shifted = c - max_c
    exp_vals = np.exp(tau * shifted)
    p = exp_vals / exp_vals.sum()  # softmax probabilities
    
    # Gradient is weighted average of individual gradients
    grad = np.zeros(n)
    for k in range(len(c)):
        if p[k] < 1e-10:
            continue
        offset = k - (n - 1)
        lo1 = max(0, -offset)
        hi1 = min(n, n - offset)
        if hi1 > lo1:
            idx = np.arange(lo1, hi1)
            grad[idx] += p[k] * (1.0 - h[idx + offset])
        lo2 = max(0, offset)
        hi2 = min(n, n + offset)
        if hi2 > lo2:
            idx = np.arange(lo2, hi2)
            grad[idx] -= p[k] * h[idx - offset]
    
    return grad * dx
```

Wait, this loop over all k (which is 2n-1 = 179 for n=90) is expensive. For n=90, that's 179 iterations per gradient evaluation, each doing vector operations on arrays of length ~90. That's about 179*90 = 16110 operations, which is fine.

But actually, we can be smarter. Most of the p[k] will be very small (exponentially small if tau is large). So we can just use the top few terms.

def top_k_subgradient(h, dx, top_k=5):
    """Compute averaged subgradient from top_k active correlation terms."""
    n = len(h)
    c = np.correlate(h, 1.0 - h, mode='full')
    top_idx = np.argsort(c)[::-1][:top_k]
    top_vals = c[top_idx]
    w = top_vals / top_vals.sum()
    grad = np.zeros(n)
    for ii in range(top_k):
        m = top_idx[ii]
        offset = m - (n - 1)
        lo1 = max(0, -offset)
        hi1 = min(n, n - offset)
        if hi1 > lo1:
            idx = np.arange(lo1, hi1)
            grad[idx] += w[ii] * (1.0 - h[idx + offset])
        lo2 = max(0, offset)
        hi2 = min(n, n + offset)
        if hi2 > lo2:
            idx = np.arange(lo2, hi2)
            grad[idx] -= w[ii] * h[idx - offset]

The autocorrelation R_k is a sum of products h[i]*h[i+k]. To maximize the minimum R_k, we want all R_k to be as large as possible.

One approach: use **gradient ascent on the minimum R_k** (with a smoothing to make it differentiable).

Let me define the smoothed minimum:
min_k R_k ≈ -(1/τ) * log(∑_k exp(-τ*R_k))

The gradient of this is:
∇(-(1/τ) log(∑ exp(-τ R_k))) = (1/∑ exp(-τ R_k)) * ∑ exp(-τ R_k) * ∇R_k

= ∑ p_k * ∇R_k where p_k = exp(-τ R_k) / ∑_j exp(-τ R_j)

This weights the shifts with the LOWEST R_k more heavily (since exp(-τ R_k) is larger when R_k is small). This is exactly what we want!

    n = len(h)

    # R_k = sum_i h[i]*h[i+k]*dx for valid i
