The key idea: F(h) = max_k g_k(h) is convex in h (each g_k is a quadratic in h... wait, is it?).

Actually, g_k = dx * Σ_{i=0}^{n-1-k} h[i] - dx * Σ_{i=0}^{n-1-k} h[i]h[i+k] for k ≥ 0.

The term Σ h[i]h[i+k] = h^T S_k h / 2 where S_k is a symmetric shift matrix. Wait, more precisely:
Σ_{i=0}^{n-1-k} h[i]h[i+k] = h^T T_k h where T_k has 1s at positions (i, i+k) for i=0..n-1-k.
This is not symmetric. But h^T T_k h = Σ h[i]h[i+k] which equals Σ h[i+k]h[i] = h^T T_k^T h.
So h^T T_k h = h^T (T_k + T_k^T)/2 h = h^T S_k h where S_k = (T_k + T_k^T)/2.

So g_k is a quadratic form. The max of quadratics is not necessarily convex (quadratics can be non-convex). In this case, the quadratic part is -dx * h^T S_k h, and S_k is positive semi-definite (it's a sum of rank-1 matrices vv^T where v has k consecutive 1s... actually no, S_k has 1/2 at positions (i,i+k) and (i+k,i), which is PSD).

So g_k = linear - dx * h^T S_k h, which is a concave quadratic. The max of concave functions is not convex!

This means the problem is non-convex, and we can't use convex optimization methods directly. This explains why the problem is hard.

def evaluate_c5(h):

    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)

def smooth_max(x, tau):
    xm = tau * x
    mx = np.max(xm)
    return float(mx / tau + np.log(np.sum(np.exp(xm - mx))) / tau)

def project_feasible(h, target):
    h = np.array(h, dtype=float).copy()
    for _ in range(100):
        h = np.clip(h, 0.0, 1.0)
        d = target - h.sum()
        if abs(d) < 1e-14:
            break
        if d > 0:
            m = h < 1.0
        else:
            m = h > 0.0
        c = m.sum()
        if c == 0:
            break
        h[m] += d / c
    return h

def fourier_h(params, n, M):
    i = np.arange(n)
    h = np.full(n, 0.5)
    for j in range(1, M + 1):
        h += params[2*(j-1)] * np.cos(2.0 * np.pi * j * i / n)
        h += params[2*(j-1)+1] * np.sin(2.0 * np.pi * j * i / n)
    return h

def grad_gk(h, k, n, dx):

        kk = -k
        if n - kk > 0:
            grad[:n-kk] += dx * (1.0 - h[kk:])
            grad[kk:] -= dx * h[:n-kk]
    return grad
