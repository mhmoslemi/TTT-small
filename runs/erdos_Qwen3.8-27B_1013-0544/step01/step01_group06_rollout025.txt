Actually, you know what, let me try a completely different optimization approach: **proximal gradient with FISTA (Fast Iterative Shrinkage-Thresholding Algorithm)**.

The objective V(h) = smooth_max(f(h); alpha) is smooth with Lipschitz constant L (which we can estimate). FISTA is:

h_{k+1} = prox_{gamma * I_C}(y_k - gamma * ∇V(y_k))
y_{k+1} = h_{k+1} + (t_k - 1)/(t_{k+1} + 1) * (h_{k+1} - h_k)

where C = {h : 0 <= h <= 1, sum(h) = n/2} is the constraint set, and prox_{gamma * I_C} is the projection onto C (with step size gamma = 1/L).

This is essentially accelerated projected gradient descent. The key advantage is the O(1/k^2) convergence rate for smooth convex problems (though our problem is non-convex, the acceleration can still help).

The Lipschitz constant of ∇V: since V is a weighted sum of quadratics, its Hessian is bounded. For the smooth max, the Hessian is bounded by alpha times the Hessian of the individual quadratic functions. The individual f_k = sum h_i(1-h_{i+k}) has Hessian with entries -1 (where the cross terms are), so the spectral norm is bounded by about 2. Thus L ≈ 2*alpha.

So gamma ≈ 1/(2*alpha). For alpha=50, gamma ≈ 0.01. For alpha=200, gamma ≈ 0.0025.

This is much smaller than the lr=0.005 used in the previous code! The previous code was using a step size that's too large for the Lipschitz constant at high alpha, which could cause oscillations.

    if time.time() < deadline4:
        h_opt, c5_opt = optimize_phase(best_h, target, 400, deadline4, mom=0.5, lr_init=0.001)
        if c5_opt < best_c5:
            best_h, best_c5 = h_opt, c5_opt

    best_h = proj_box_sum(best_h, target)
    best_c5 = compute_c5(best_h)
    return best_h, best_c5, len(best_h)
