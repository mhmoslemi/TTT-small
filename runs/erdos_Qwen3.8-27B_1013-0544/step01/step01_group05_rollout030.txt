        elif 0 < L < n:
            grad[L:] += omh[:n - L]
            grad[:n - L] -= h[L:]
        elif -n < L < 0:
            L2 = -L
            grad[:n - L2] += omh[L2:]
            grad[L2:] -= h[:n - L2]
    return grad / float(len(active))

```python
def sym_obj_lse(x, n, dx, beta):
    h = build_sym(x, n)
    corr = np.correlate(h, 1.0 - h, mode='full') * dx
    mc = np.max(corr)
    shifted = beta * (corr - mc)
    # Clip to avoid overflow
    shifted = np.clip(shifted, -500, 500)
    return mc + float(np.log(np.sum(np.exp(shifted)))) / beta
```

Actually, since we subtract mc first, the maximum of shifted is 0, so exp(shifted) ≤ 1. The only issue is underflow for very negative values, which is fine (they just become 0). So no overflow issue.

But wait, there's a subtlety: the log-sum-exp gives (1/β)log(Σexp(β(corr-k - mc))) + mc. As β→∞, this approaches mc = max(corr). The gradient with respect to h is:
(1/β) * (Σ exp(β(corr_k - mc)) * β * ∂corr_k/∂h) / (Σ exp(β(corr_k - mc)))
= (Σ exp(β(corr_k - mc)) * ∂corr_k/∂h) / (Σ exp(β(corr_k - mc)))

This is the softmax-weighted average of the individual gradients. SLSQP will use finite differences to approximate this gradient, which should work fine.
