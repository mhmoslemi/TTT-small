The overlap at lag k is $O_k = \sum_i h[i+k](1-h[i])$. The gradient with respect to h[i] is:
$\partial O_k / \partial h[i] = (1-h[i-k]) - h[i+k]$

If the maximum is at lag k*, then the "force" on h[i] is:
$(1-h[i-k*]) - h[i+k*]$

This tells us: if h[i-k*] is small and h[i+k*] is large, we should decrease h[i]; if h[i-k*] is large and h[i+k*] is small, we should increase h[i].

This is like a "repulsion" from nearby 1's and "attraction" to nearby 0's (at the active lag distance).

We can use this for a **gradient descent** step:
$h[i] \leftarrow h[i] - \eta \cdot ((1-h[i-k*]) - h[i+k*])$

where $\eta$ is a step size.

1. Compute the active lag(s)
2. Compute the subgradient
3. Take a step in the negative subgradient direction
4. Project onto the feasible set

def subgradient_step(h, eta, momentum_v, alpha):
    """One step of projected subgradient with momentum."""
    n = len(h)
    target_sum = n / 2.0
    
    # Compute current overlaps
    ones_minus_h = 1.0 - h
    corr = np.correlate(h, ones_minus_h, mode="full")
    
    # Find top lags
    top_k = max(1, int(0.05 * len(corr)))  # top 5% of lags
    top_indices = np.argsort(corr)[-top_k:]
    
    # Average subgradient over top lags
    grad = np.zeros(n)
    for k_idx in top_indices:
        lag = k_idx - (n - 1)
        for i in range(n):
            g = 0.0
            if 0 <= i - lag < n:
                g += (1.0 - h[i - lag])
            if 0 <= i + lag < n:
                g -= h[i + lag]
            grad[i] += g / len(top_indices)
    
    # Momentum update
    momentum_v = alpha * momentum_v - eta * grad
    h_new = h + momentum_v
    
    # Project
    h_new = project_h(h_new, target_sum)
    
    return h_new, momentum_v
