Hmm, but this is very similar to the previous approach. Let me think about what's really different and likely to help.

The previous achieved 0.380980. We need 0.3808. That's a difference of about 0.0002. This is very tight.

Key differences I should try:
1. **L-BFGS-B** instead of or in addition to SLSQP - it's faster per iteration and might find slightly different optima
2. **More diverse multi-starts** - not just perturbations of the best, but genuinely different structures
3. **Different n** - maybe n=60 or n=100 gives a different landscape
4. **Exploiting symmetry**: The problem is symmetric under h → 1-h (complement) and under reversal x → 2-x. We can fix some symmetry to reduce the search space.

Wait, actually h → 1-h changes the constraint: ∫(1-h) = 2 - 1 = 1. So the complement is also feasible! And C₅(1-h) = max_k ∫(1-h)(x)h(x+k)dx = max_k ∫h(x+k)(1-h(x))dx. By change of variable, this is the same as C₅(h). So the problem is symmetric under h → 1-h.

This means we can WLOG assume h[0] ≥ 0.5 (or some other symmetry-breaking condition).

5. **Use the active set at the optimum**: At the optimum, there should be several lags k where C(k) = C₅ (the maximum). We can identify these and then solve a smaller LP: minimize t subject to C(k) ≤ t for active k, sum(h) = n/2, 0≤h≤1.

Wait, C(k) is quadratic in h, not linear. So it's not an LP.

But we can linearize: at the current point h*, C(k) ≈ C(k; h*) + ∇C(k; h*)^T (h - h*). This gives a linear approximation, and we can solve the LP to find a direction of improvement.

This is essentially a linearization-based method (like the method of centers or cutting planes for non-convex problems).

Let me implement this:

```python
def linearized_step(h, n):
    """One step of the linearized method: find direction that reduces max C(k)."""
    dx = 2.0 / n
    c_vals = np.correlate(h, 1 - h, mode='full') * dx
    m = c_vals.max()
    
    # Active set: lags where C(k) is close to max
    active = np.where(c_vals > m - 1e-4)[0]
    
    # For each active lag k, compute gradient of C(k) w.r.t. h
    # C(k) = sum_i h[i](1-h[i+lag])*dx where lag = k - (n-1)
    n_full = 2 * n - 1
    lags = np.arange(n_full) - (n - 1)
    
    # Build the LP: minimize t
    # Subject to: C(k; h) + grad_k^T (h - h_current) ≤ t for k in active
    #             sum(h) = n/2
    #             0 ≤ h ≤ 1
    # This is a linear program!
    
    from scipy.optimize import linprog
    
    # Variables: h[0], ..., h[n-1], t (total n+1 variables)
    # Objective: minimize t → c = [0, 0, ..., 0, 1]
    c_obj = np.zeros(n + 1)
    c_obj[-1] = 1
    
    # Inequality constraints: grad_k^T h + (C(k) - grad_k^T h_current) - t ≤ 0
    # i.e., grad_k^T h - t ≤ t_k where t_k = C(k; h_current) - grad_k^T h_current + m... 
    # Actually: C(k; h) + grad_k^T (h - h_cur) ≤ t
    # C(k; h_cur) + grad_k^T h - grad_k^T h_cur ≤ t
    # grad_k^T h - t ≤ grad_k^T h_cur - C(k; h_cur)
    
    A_ub = []
    b_ub = []
    for k in active:
        lag = int(lags[k])
        grad_k = np.zeros(n)
        if 0 <= lag < n:
            for j in range(n - lag):
                grad_k[j] = (1 - h[j + lag]) * dx
            for j in range(lag, n):
                grad_k[j] -= h[j - lag] * dx
        elif -n < lag < 0:
            la = -lag
            for j in range(la, n):
                grad_k[j] = (1 - h[j - la]) * dx
            for j in range(n - la):
                grad_k[j] -= h[j + la] * dx
        # Row: [grad_k, -1] · [h, t] ≤ grad_k^T h_cur - C(k; h_cur)
        row = np.zeros(n + 1)
        row[:n] = grad_k
        row[n] = -1
        A_ub.append(row)
        b_ub.append(grad_k @ h - c_vals[k])
    
    A_ub = np.array(A_ub)
    b_ub = np.array(b_ub)
    
    # Equality: sum(h) = n/2
    A_eq = np.zeros((1, n + 1))
    A_eq[0, :n] = 1.0
    b_eq = np.array([n / 2.0])
    
    # Bounds: 0 ≤ h_i ≤ 1, t ≥ 0
    bounds_lp = [(0, 1)] * n + [(0, None)]
    
    res = linprog(c_obj, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq,
                 bounds=bounds_lp, method='highs')
    
    if res.success:
        return res.x[:n], res.x[n]
    return None, None
```

This is a promising approach! At each iteration:
1. Find the active set (lags near the maximum)
2. Linearize C(k) at the current point
3. Solve the resulting LP to find a new h that reduces the linearized max
4. Update h and repeat

This is similar to the "method of centers" or " Kelley's cutting plane method" adapted for this non-convex problem.

The key advantage is that the LP can be solved very fast (especially with HiGHS), allowing many iterations.

- After the LP step, project to feasible set
- If the LP solution doesn't improve, try with a larger active set
- Use the LP solution as a warm start for SLSQP

def compute_c5(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1 - h, mode='full')
    return float(np.max(c) * dx)

def project_feasible(h, n):
    target_sum = n / 2.0
    h = np.clip(h.copy(), 0.0, 1.0)
    for _ in range(2000):
        diff = target_sum - h.sum()
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            room = 1.0 - h
            total = room.sum()
            if total < 1e-15:
                break
            h += (diff / total) * room
        else:
            total = h.sum()
            if total < 1e-15:
                break
            h += (diff / total) * h
    return np.clip(h, 0.0, 1.0)

    b_ub_list = []
