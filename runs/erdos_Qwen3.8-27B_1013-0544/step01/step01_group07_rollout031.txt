```python
def compute_gradient(h, t, dx):
    n = len(h)
    corr = np.correlate(h, 1-h, mode='full')
    tc = t * corr
    tc_max = np.max(tc)
    exp_tc = np.exp(tc - tc_max)
    w = exp_tc / np.sum(exp_tc)
    
    grad = np.zeros(n)
    for j in range(n):
        val = w[n-1] * (1-2*h[j])
        # m > 0 terms
        for m in range(1, min(j, n-1) + 1):
            val += w[n-1+m] * (1-h[j-m])
        for m in range(1, n-j):
            val -= w[n-1+m] * h[j+m]
        # p > 0 terms (m < 0)
        for p in range(1, n-j):
            val += w[n-1-p] * (1-h[j+p])
        for p in range(1, j):
            val -= w[n-1-p] * h[j-p]
        grad[j] = dx * val
    return grad
```

```python
def project_feasible(x, target_sum):
    """Project x onto {x : 0≤x[i]≤1, sum(x)=target_sum}"""
    n = len(x)
    # Bisection on lambda
    lo, hi = x.min() - target_sum, x.max()  # rough bounds
    # Actually, lambda ranges from -inf to inf
    # If sum(clip(x - lambda, 0, 1)) = target_sum
    
    # The function f(lambda) = sum(clip(x - lambda, 0, 1)) is continuous and decreasing
    # f(-inf) = sum(min(x, 1)) = sum(clip(x, 0, 1)) ≥ target_sum (if target_sum ≤ n)
    # f(inf) = 0 ≤ target_sum
    
    lo = x.min() - 1  # f(lo) ≥ n (all clipped to 1)
    hi = x.max() + 1  # f(hi) = 0 (all clipped to 0)
    
    for _ in range(60):
        mid = (lo + hi) / 2
        val = np.sum(np.clip(x - mid, 0, 1))
        if val > target_sum:
            lo = mid
        else:
            hi = mid
    
    return np.clip(x - (lo + hi) / 2, 0, 1)
```

    t0 = time.time()
    n = len(h)
    # Ensure h is binary
    # Sort by value, set top n/2 to 1, rest to 0
    sorted_idx = np.argsort(h)[::-1]
    h = np.zeros(n)
    h[sorted_idx[:int(target_sum)]] = 1.0
    
    best_c5 = compute_c5(h, dx)
    ones = np.where(h == 1)[0]
    zeros = np.where(h == 0)[0]

        if time.time() - t0 > time_limit:
            break

        best_swap = None
        corr = np.correlate(h, 1-h, mode='full')

            for j in zeros:

                h[j] = 1

                h[j] = 0

        h[i] = 0
        h[j] = 1
        ones = np.where(h == 1)[0]
        zeros = np.where(h == 0)[0]
        best_c5 = max_new * dx  # Wait, need to recompute

Actually, a simpler approach: since we only care about the maximum, we can:
1. Find the current max lag k*
2. For each swap, compute how corr[k*] changes (and check if any other lag becomes the new max)

The change in corr at lag k* due to swapping h[i] from 1 to 0 and h[j] from 0 to 1:

corr[k] = sum_n h[n+m]*(1-h[n]) where m = k-(n-1)

The change when h[i] goes from 1 to 0:
- h[i] appears as h[n+m] when n+m=i, i.e., n=i-m. Valid if 0≤i-m<n and 0≤n<n.
  The term h[n+m]*(1-h[n]) goes from 1*(1-h[i-m]) to 0, so change = -(1-h[i-m]) = h[i-m]-1
- h[i] appears as (1-h[n]) when n=i. Valid if 0≤i<n and 0≤i+m<n.
  The term h[i+m]*(1-h[n]) goes from h[i+m]*0 to h[i+m]*1, so change = h[i+m]

The change when h[j] goes from 0 to 1:
- h[j] appears as h[n+m] when n+m=j, i.e., n=j-m. Valid if 0≤j-m<n.
  The term goes from 0*(1-h[j-m]) to 1*(1-h[j-m]), so change = (1-h[j-m])
- h[j] appears as (1-h[n]) when n=j. Valid if 0≤j+m<n.
  The term goes from h[j+m]*1 to h[j+m]*0, so change = -h[j+m]

Total change in corr[k] for the swap (i: 1→0, j: 0→1):
Δcorr[k] = [h[i-m]-1 + h[i+m]] + [(1-h[j-m]) - h[j+m]]
         = h[i-m] - 1 + h[i+m] + 1 - h[j-m] - h[j+m]
         = h[i-m] + h[i+m] - h[j-m] - h[j+m]

where m = k-(n-1), and we need to handle boundary conditions (if index is out of range, the term is 0).

This gives us O(1) per (swap, lag) pair! So to check if a swap improves the maximum at lag k*, we just compute Δcorr[k*] in O(1).

But we also need to check if another lag becomes the new maximum. For that, we'd need to check all lags, which is O(n) per swap. So total is O(n² * n) = O(n³) per iteration, same as before.

However, we can use a heuristic: only check the top few lags (say top 5) after the swap. If none of them exceeds the new value at the old max lag, we're likely good.

Or even simpler: just check the old max lag. If it improves, accept the swap. This might miss cases where another lag becomes the new max, but it's a good heuristic.

   Old contribution = h_old[i+m] * 0 = 0.
   Delta = 1.
   
   Using formula: h[i+m] (using old values)... but old h[j] = 0, so formula gives 0. But the actual delta is 1!

So there's an issue when i+m = j. The formula using old values gives the wrong answer in this case.

To handle this correctly, I should compute the delta as:
Δcorr[k] = sum of (new_term - old_term) for all terms that are affected by the swap.

The affected terms are those where h[i] or h[j] appears:
- h[i] appears as h[n+m] when n = i-m
- h[i] appears as (1-h[n]) when n = i
- h[j] appears as h[n+m] when n = j-m
- h[j] appears as (1-h[n]) when n = j

If any of these indices coincide (e.g., i-m = j-m, i.e., i=j which is impossible since i≠j; or i-m = j, etc.), there could be interactions.

Let me just handle it by computing the delta directly:
For each affected (n, position) pair, compute old contribution and new contribution.

Actually, the simplest correct approach for small n is: just recompute corr after the swap. For n=160, one correlate call is O(n) ≈ 160 operations. With 6400 swaps, that's about 1M operations per iteration. With 1000 iterations, 1 billion operations. At ~100M ops/sec in numpy, that's about 10 seconds per 1000 iterations. That's fine!

Let me just do the naive approach: for each swap, modify h, compute corr, check max, revert.

import numpy as np
import time

def compute_c5(h, dx):
    corr = np.correlate(h, 1-h, mode='full')
    return float(np.max(corr) * dx)

def project_feasible(x, target_sum):
    n = len(x)
    lo = x.min() - 1.0
    hi = x.max() + 1.0
    for _ in range(60):
        mid = (lo + hi) / 2.0
        val = np.sum(np.clip(x - mid, 0.0, 1.0))
        if val > target_sum:
            lo = mid
        else:
            hi = mid
    return np.clip(x - (lo + hi) / 2.0, 0.0, 1.0)

def compute_gradient(h, t, dx):
    n = len(h)
    corr = np.correlate(h, 1-h, mode='full')
    tc = t * corr
    tc_max = np.max(tc)
    exp_tc = np.exp(tc - tc_max)
    w = exp_tc / np.sum(exp_tc)
    
    grad = np.zeros(n)
    for j in range(n):
        val = w[n-1] * (1.0 - 2.0*h[j])
        for m in range(1, min(j, n-1) + 1):
            val += w[n-1+m] * (1.0 - h[j-m])
        for m in range(1, n - j):
            val -= w[n-1+m] * h[j+m]
        for p in range(1, n - j):
            val += w[n-1-p] * (1.0 - h[j+p])
        for p in range(1, j):
            val -= w[n-1-p] * h[j-p]
        grad[j] = dx * val
    return grad

def gradient_descent(h, dx, target_sum, t, max_iter=200, time_limit=30):
    t0 = time.time()
    n = len(h)
    lr = 0.1
    obj = lambda x: float(np.max(np.correlate(x, 1-x, mode='full')) * dx)
    best_val = obj(h)
    
    for it in range(max_iter):
        if time.time() - t0 > time_limit:
            break
        grad = compute_gradient(h, t, dx)
        grad_norm = np.linalg.norm(grad)
        if grad_norm < 1e-10:
            break
        
        # Backtracking
        alpha = lr
        improved = False
        for _ in range(40):
            h_new = h - alpha * grad
            h_new = project_feasible(h_new, target_sum)
            val_new = obj(h_new)
            if val_new < best_val - 1e-12:
                h = h_new.astype(float)
                best_val = val_new
                improved = True
                break
            alpha *= 0.5
        
        if not improved:
            lr *= 0.5
            if lr < 1e-8:
                break
        else:
            lr = min(lr * 1.1, 1.0)
    
    return h, best_val

def binary_local_search(h, dx, max_iter=200, time_limit=30):
    t0 = time.time()
    n = len(h)
    n_ones = int(np.round(np.sum(h)))
    
    idx = np.argsort(h)[::-1]
    h = np.zeros(n)
    h[idx[:n_ones]] = 1.0
    
    best_c5 = compute_c5(h, dx)
    improved = True
    iters = 0
    
    while improved and iters < max_iter:
        if time.time() - t0 > time_limit:
            break
        iters += 1
        improved = False
        corr = np.correlate(h, 1-h, mode='full')
        max_val = np.max(corr)
        ones = np.where(h == 1)[0]
        zeros = np.where(h == 0)[0]
        
        best_improve = 1e-12
        best_swap = None
        
        for i in ones:
            for j in zeros:
                h[i] = 0
                h[j] = 1
                c = np.max(np.correlate(h, 1-h, mode='full'))
                h[i] = 1
                h[j] = 0
                improve = max_val - c
                if improve > best_improve:
                    best_improve = improve
                    best_swap = (i, j)
        
        if best_swap is not None:
            i, j = best_swap
            h[i] = 0
            h[j] = 1
            best_c5 = compute_c5(h, dx)
            improved = True
    
    return h, best_c5

def make_thue_morse(n):
    """Generate Thue-Morse based binary sequence of length n with n/2 ones."""
    # Thue-Morse: t(k) = popcount(k) % 2
    # We want n/2 ones. The Thue-Morse sequence has exactly n/2 ones for n=2^m.
    # For general n, we take first n and adjust.
    tm = np.zeros(n, dtype=int)
    for i in range(n):
        tm[i] = bin(i).count('1') % 2
    
    # Ensure exactly n//2 ones
    n_ones = np.sum(tm)
    target = n // 2
    if n_ones > target:
        # Remove some 1s (starting from the end)
        idx_1 = np.where(tm == 1)[0][::-1]
        for i in range(n_ones - target):
            tm[idx_1[i]] = 0
    elif n_ones < target:
        # Add some 1s (starting from the end)
        idx_0 = np.where(tm == 0)[0][::-1]
        for i in range(target - n_ones):
            tm[idx_0[i]] = 1
    
    return tm.astype(float)

def make_random_binary(n, seed):
    rng = np.random.RandomState(seed)
    h = np.zeros(n)
    ones = rng.choice(n, n // 2, replace=False)
    h[ones] = 1.0
    return h

    old_n = len(h)
    x_old = np.arange(old_n) / old_n * 2.0
    x_new = np.arange(new_n) / new_n * 2.0
    h_new = np.interp(x_new, x_old, h)
    return h_new
