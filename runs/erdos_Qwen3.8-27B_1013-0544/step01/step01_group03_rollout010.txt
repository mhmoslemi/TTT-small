One key improvement: instead of using SLSQP (which uses finite differences for gradients), I could implement the gradient analytically.

The objective is: f(x) = smooth_max(corr(x), tau) where corr(x) = correlate(x, 1-x).

The gradient of corr[k] with respect to x[n]:
corr[k] = sum_{valid n} x[n+k] * (1-x[n])

d(corr[k])/dx[m] = (1-x[m-k]) * [m-k is valid as first index and m is second] + (-x[m+k]) * [m is valid as first index and m+k is second]

More precisely:
