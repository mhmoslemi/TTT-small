where the sum is over valid i values.

So for shift L = k - (n-1):
- If L ≥ 0: c_L = Σ_{i=0}^{n-1-L} h[i] * (1-h[i+L])
- If L < 0: c_L = Σ_{i=-L}^{n-1} h[i] * (1-h[i+L]) = Σ_{i=0}^{n-1+L} h[i-L] * (1-h[i])

This corresponds to the integral ∫ h(x) (1-h(x+L*dx)) dx over the domain where both x and x+L*dx are in [0,2].

OK so for h = indicator of [0,1] (first half):
c_L for L > 0: Σ_{i=0}^{n/2-1-L} 1 * (1-1) + Σ_{i=n/2-L}^{n/2-1} 1 * 1... 

Let me just think in continuous terms. If h = 1 on [0,1] and 0 on (1,2]:
For shift δ > 0: ∫₀^{2-δ} h(x)(1-h(x+δ)) dx
= ∫₀^{1-δ} 1*(1-1) dx + ∫_{1-δ}^{1} 1*(1-0) dx + ∫₁^{2-δ} 0*(...) dx
Wait, that's not right either. Let me be more careful.

x ranges over [0, 2-δ] (so that x+δ ∈ [0,2]).
h(x) = 1 for x ∈ [0,1], 0 for x ∈ (1,2]
h(x+δ) = 1 for x+δ ∈ [0,1] i.e. x ∈ [-δ, 1-δ], 0 for x+δ ∈ (1,2] i.e. x ∈ (1-δ, 2-δ]

So 1-h(x+δ) = 0 for x ∈ [0, 1-δ], 1 for x ∈ (1-δ, 2-δ]

∫ h(x)(1-h(x+δ)) dx = ∫_{max(0,1-δ)}^{min(1,2-δ)} 1 * 1 dx

For 0 < δ ≤ 1: = ∫_{1-δ}^{1} dx = δ
For 1 < δ < 2: = 0 (since 1-δ < 0, so the integral is from 0 to 2-δ, but h(x)=0 for x>1, and for x<1, h(x+δ)=0 since x+δ>1... wait)

For δ > 1: h(x) = 1 for x ∈ [0,1]. For these x, x+δ ∈ [δ, 1+δ]. Since δ > 1, x+δ > 1, so h(x+δ) = 0. Thus 1-h(x+δ) = 1.
So ∫₀¹ 1*1 dx = 1.

Wait, but x must satisfy x+δ ≤ 2, so x ≤ 2-δ.
For δ > 1: x ∈ [0, min(1, 2-δ)].
- If 1 < δ < 2: x ∈ [0, 2-δ], and for all such x, h(x)=1 (since 2-δ < 1) and h(x+δ)=0 (since x+δ > 1). So integral = 2-δ.
- If δ = 2: integral = 0.

So for h = indicator of [0,1]:
C5_continuous = max(δ for δ∈(0,1], 2-δ for δ∈[1,2)) = max(1, 1) = 1.

That's terrible. C5 = 1 is the worst possible.

Now what about a more "spread out" function? Like h = 1/2 everywhere? Then h(1-h) = 1/4 everywhere, and C5 = 1/4 * 2 = 1/2. Still not great.

The smooth objective is:
f(h) = (1/β) log(Σ_k exp(β · c_k(h) · dx))

where c_k(h) = Σ_i h_i · (1 - h_{i+k}) (with appropriate bounds on i).

The gradient is:
∇f(h) = (1/β) · (Σ_k exp(β·c_k·dx) · β·dx · ∇c_k) / (Σ_k exp(β·c_k·dx))
       = dx · Σ_k p_k · ∇c_k

where p_k = exp(β·c_k·dx) / Σ_j exp(β·c_j·dx) (softmax weights).

And ∇c_k for shift L = k - (n-1):
If L > 0: (∇c_L)_j = (1 - h_{j+L}) for j < n-L, and -h_{j-L} for j ≥ L
If L = 0: (∇c_0)_j = 1 - 2h_j
If L < 0 (M = -L): (∇c_{-M})_j = (1 - h_{j-M}) for j ≥ M, and -h_{j+M} for j < n-M

So the total gradient is:
∇f_j = dx · Σ_k p_k · [(1 - h_{j+L_k}) · 1[j < n-L_k] - h_{j-L_k} · 1[j ≥ L_k]] (for L_k > 0)
     + dx · p_0 · (1 - 2h_j) (for L_k = 0)
     + dx · Σ_{k: L_k<0} p_k · [(1 - h_{j-|L_k|}) · 1[j ≥ |L_k|] - h_{j+|L_k|} · 1[j < n-|L_k|]]

    return (_g_start + _g_budget - 5.0) - time.time()

def project_feasible(x, target_sum):
    lo = float(x.min()) - 1.0
    hi = float(x.max()) + 1.0
    for _ in range(60):
        mid = (lo + hi) * 0.5
        s = float(np.clip(x - mid, 0.0, 1.0).sum())
        if s > target_sum:
            lo = mid
        else:
            hi = mid
    return np.clip(x - (lo + hi) * 0.5, 0.0, 1.0)

def compute_c5(h, dx):
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr)) * dx

def hard_grad(h, L):
    n = len(h)
    g = np.zeros(n)
    if L == 0:
        g[:] = 1.0 - 2.0 * h
    elif L > 0:
        g[:n-L] += (1.0 - h[L:])
        g[L:] += -h[:n-L]
    else:
        M = -L
        g[M:] += (1.0 - h[:n-M])
        g[:n-M] += -h[M:]
    return g

def smooth_obj(h, dx, beta):
    corr = np.correlate(h, 1.0 - h, mode='full')
    scaled = beta * corr * dx
    s_max = float(np.max(scaled))
    if s_max > 500:
        return float(np.max(corr)) * dx
    return (s_max + np.log(np.sum(np.exp(scaled - s_max)))) / beta

def smooth_grad(h, dx, beta):

    corr = np.correlate(h, 1.0 - h, mode='full')
    scaled = beta * corr * dx
    s_max = float(np.max(scaled))

        return hard_grad(h, k - n_half)
