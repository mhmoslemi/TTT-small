For a random set A of size n/2, |A ∩ (A-k)| ≈ n/4 for k ≠ 0, and |A ∩ A| = n/2 for k=0.

So C5 ≈ (n/2 - n/4) * 2/n = (n/4) * 2/n = 1/2 for random, matching the constant case.

For a difference set with parameters (v, k, λ), we have v = n, k = |A| = n/2, and the number of representations of each non-zero element as a difference of two elements of A is λ = k(k-1)/(v-1).

The autocorrelation at lag k (k≠0) is |A ∩ (A-k)| = λ (for a difference set).

So |A ∩ (A-k)| = (n/2)(n/2-1)/(n-1) ≈ n/4 for large n.

This gives the same n/4 as the random case! So difference sets don't help for 0-1 functions.

This suggests that the optimal solution is NOT a 0-1 function but rather a "fuzzy" set with values in (0,1). The intermediate values allow for better control of the correlation at each lag.
