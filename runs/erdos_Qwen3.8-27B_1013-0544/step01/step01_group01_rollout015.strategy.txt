### Math Details
The full correlation is defined for lags `k` from -(n-1) to (n-1). Each correlation point computes the integral of `h(x) * (1-h(x+k))` over available intervals in [0,2] (with periodic boundary approach effectively, via convolution mode 'full').

```python
# Example: Objective approximation using smooth_max
def smooth_max(x, beta=100.0):
    m = np.max(x)
    return m + (1/beta) * np.log(np.sum(np.exp(beta*(x-m))) + 1e-10)
```
