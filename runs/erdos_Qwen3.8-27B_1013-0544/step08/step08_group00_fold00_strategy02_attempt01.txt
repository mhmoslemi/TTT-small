### <Strategy>
#### 1. Approach and rationale
**Central idea**:  
We reframe the problem as a circular optimization by embedding the step function in a periodic domain. The key insight is that the overlap integral `C5` depends on pairs of samples spaced by `k` indices, which correspond to angular separations in a circular embedding. This allows us to prioritize shifts that maximize overlap, transfer structural properties between candidates, and exploit rotational symmetry.

**Justification**:  
The current method uses local refinement trapped in narrow basins. We introduce a "grayscale graph" where vertices (`h[i]`) are connected by edges representing shift distances (`k`). Each peak in the autocorrelation plot becomes a decision node. The algorithm dynamically spawns candidates from these nodes, validating them through a light gradient calculation. Bifurcation multiplies search directions, and adaptive thresholds prune paths with low autocorrelation reduction.

**Limitations**:  
- Assumes a sufficiently smooth autocorrelation plot; sudden jumps may cause premature pruning.  
- Relies on gradient estimation, which may be noisy in high dimensions.

---

#### 2. Mathematical specifications
**Representation**:  
- `h` is an array of length `n_points` (default 700) on `[0, 2]`.  
- `dx = 2.0 / n_points`, `constraints: sum(h) = n_points / 2`, `0 ≤ h[i] ≤ 1`.  

**Objective**:  
- Minimize `C5 = max_k (dx * sum(h[i] * (1 - h[k + i]))`, with `k` ranging over `(0, n_points - 1)` via `np.correlate(h, 1 - h, mode='full')`.

**Algorithm requirements**:  
- **Nonlinear objective**:  `C5` maximization.  
- **Equality constraint**: `sum(h) = n_points / 2`.  
- **Bounds**: `h[i] ∈ [0, 1]`.  
- **Gradient estimation**: Differences in `k` directions (with fallback to finite differences).

---

#### 3. Implementation procedure
**Initialization**:  
1. **Fallback**: Start from `initial_h_values` if available; otherwise, `random_start(n_points)`.  
2. **Projection**: Use `project_feasible(h, n)` from the parent code.  

**Search loop**:  
1. **Autocorrelation**:  
   - Compute `corr = np.correlate(h, 1 - h, mode='full')`, `C5 = dx * np.max(corr)`.  
   - Detect peaks: `peaks = (np.diff(np.sign(np.diff(corr))) < 0)[1:]`.  

2. **Candidate generation**:  
   - For each peak `k`:  
     - Solve a 1D optimization using `solve_1d_bisection` (adapted from parent) with gradients from `k`-neighbors.  
     - Spawn `C_candidates` via small mutations in `k` and `θ` directions.  

3. **Feasibility and scoring**:  
   - Project candidates to satisfy integral/box constraints.  
   - Score: `C5_new`, `local_improvement`.  

**Termination**:  
- Stop if `autocorrelation` plateau detected or time exceeded.  
- Validate terminal candidate via `compute_c5(...)`.

#### 4. Search choices and variations
**Core mechanism**:  
- **Bifurcation**: After each peak discovery, create candidates for all higher `k` values.  
- **Pruning threshold**: Remove a path if `delta_C5 < 0.8 * max_delta`.  

**Adaptive policies**:  
- **Mutation factor**: Gradually reduce by `0.95` over time.  
- **Resolution adjustment**: After plateau, double `n_points` and restart coordinate sampling.
