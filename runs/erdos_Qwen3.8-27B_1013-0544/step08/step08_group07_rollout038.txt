        # i.e., (n-1) - p <= s <= 2(n-1) - p
        s_lo2 = max(0, (n - 1) - p)
        s_hi2 = min(m - 1, 2 * (n - 1) - p)
        idx2 = np.arange(s_lo2, s_hi2 + 1)
        p_plus_l = p + (idx2 - (n - 1))  # = p + idx2 - n + 1
        effects[p, idx2] -= h[p_plus_l]
    
    return effects

Actually, for a binary h, flipping h[p] from 0 to 1 changes c[s] by:
- +1 for each valid (i, s) where p = i + l*(s) and h[i] = 0 (i.e., the term h[p]*(1-h[i]) goes from 0 to 1)
  Wait, this isn't right either. Let me think step by step.

c[s] = sum_i h[i+l]*(s) * (1-h[i]) for valid i.

When h[p] goes from 0 to 1:
- For terms where p = i + l*(s) (i.e., i = p - l*(s)): the term h[p]*(1-h[i]) goes from 0*(1-h[i]) = 0 to 1*(1-h[i]) = 1-h[i]
  So the change is +(1-h[i]) = 1-h[p-l*(s)]
- For terms where p = i (i.e., the term is h[p+l*(s)]*(1-h[p])): the term goes from h[p+l*(s)]*1 to h[p+l*(s)]*0
  So the change is -h[p+l*(s)]

Total change: (1-h[p-l*(s)]) - h[p+l*(s)] (with validity checks)

OK so my formula was correct. Let me implement it more efficiently.

For a given p and all s:
- l*(s) = s - (n-1)
- p - l*(s) = p - s + (n-1) = (p + n - 1) - s
  Valid when 0 ≤ (p+n-1-s) ≤ n-1, i.e., p ≤ s ≤ p+n-1
  Also need (p+n-1-s) to be a valid index in [0, n-1], which is the same condition.
  
- p + l*(s) = p + s - (n-1)
  Valid when 0 ≤ p+s-(n-1) ≤ n-1, i.e., (n-1-p) ≤ s ≤ 2(n-1-p)
  Wait: 0 ≤ p+s-(n-1) ≤ n-1
  ⟹ (n-1)-p ≤ s ≤ 2(n-1)-p

So for position p:
- First term active for s ∈ [max(0, p), min(2n-2, p+n-1)]
  Value: (1 - h[p + n - 1 - s])
- Second term active for s ∈ [max(0, n-1-p), min(2n-2, 2(n-1)-p)]
  Value: -h[p + s - (n-1)]
