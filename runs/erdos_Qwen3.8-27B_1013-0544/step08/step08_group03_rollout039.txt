For coordinate p, A[k] = (1-h[p+s])*I[0<=p+s<n] - h[p-s]*I[0<=p-s<n] where s = k-(n-1).

This can be computed in O(n) by noting:
- For k where s = k-(n-1), and 0<=p+s<n: A[k] includes (1-h[p+s])
  This means k-(n-1) is in [-p, n-1-p], so k is in [n-1-p, n-1+n-1-p] = [n-1-p, 2n-2-p]
  And p+s = p + k - (n-1) ranges from 0 to n-1
  
- Similarly for the second term.

So A[k] is non-zero only for O(n) values of k (which is all of them since k ranges over 2n-1 values). But computing each A[k] is O(1), so total is O(n) per coordinate. That's what I had.

def compute_c5(h, n):
    dx = 2.0 / n
    return float(np.max(np.correlate(h, 1.0 - h, mode='full')) * dx)

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h.copy(), 0.0, 1.0)
    for _ in range(5000):
        diff = target - h.sum()
        if abs(diff) < 1e-15:
            break
        if diff > 0:
            room = 1.0 - h
            tot = room.sum()
            if tot < 1e-15:
                break
            h += (diff / tot) * room
        else:
            tot = h.sum()
            if tot < 1e-15:
                break
            h += (diff / tot) * h
    return np.clip(h, 0.0, 1.0)

def smax_grad(h, n, mu):
    dx = 2.0 / n
    c = np.correlate(h, 1.0 - h, mode='full') * dx
    cs = c - c.max()
    ec = np.exp(cs / mu)
    w = ec / ec.sum()
    fc = w[n-1:].copy()
    fr = w[n-1::-1].copy()
    M = toeplitz(fc, fr)
    return dx * (M @ (1.0 - h) - M.T @ h)

            break
        alpha = mu * 0.4
        for it in range(iters_per_mu):
            if deadline is not None and time.time() > deadline:
                break
            g = smax_grad(h_curr, n, mu)
