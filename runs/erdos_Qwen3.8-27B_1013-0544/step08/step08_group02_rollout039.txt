def compute_c5(h, n):
    return float(np.max(np.correlate(h, 1.0 - h, mode='full')) * 2.0 / n)

    """Round h to binary maintaining sum = n/2."""
    h = np.asarray(h, dtype=float)
    order = np.argsort(h)[::-1]

    b[order[:n//2]] = 1.0

            delta[k] = new_val - old_val
    
    new_c = c + delta
    return float(np.max(new_c))
```

OK this is getting too convoluted. Let me take a step back and simplify.

**Simpler approach**: For n=500, just recompute the full correlation after each swap. Use numpy's correlate which is fast.

```python
def evaluate_swap(h, i, j, n):
    """Evaluate C5 after swapping h[i] and h[j]."""
    h[i], h[j] = h[j], h[i]
    c5 = compute_c5(h, n)
    h[i], h[j] = h[j], h[i]  # undo
    return c5
```

For n=500, compute_c5 does np.correlate (fast, ~30μs) + np.max + scalar mult. So ~50μs per evaluation.

With 5000 random swaps per iteration: 5000 * 50μs = 0.25 seconds per iteration.
We can do ~400 iterations in 100 seconds. That's plenty.

But random sampling is wasteful. Let me be smarter:

**Smarter approach**: 
1. Identify the active lags (those at or near the max)
2. For each active lag d, the swap (i,j) helps if it reduces the count at that lag
3. A swap (i,j) reduces c_d if: h[i+d] + h[i-d] - 1 + 1 - h[j-d] + h[i+d] - h[j+d] < 0
   (simplified, using the delta formula)
   
   Actually, it reduces c_d if delta_d < 0, i.e.:
   (h[i-d]-1)*[valid] + (1-h[j-d])*[valid] + h[i+d]*[valid] - h[j+d]*[valid] < 0
   
   For binary h: this is a combination of 0s and 1s. Let me enumerate:
   - (h[i-d]-1) is -1 or 0 (if i-d valid)
   - (1-h[j-d]) is 0 or 1 (if j-d valid)
   - h[i+d] is 0 or 1 (if i+d valid)
   - (-h[j+d]) is 0 or -1 (if j+d valid)
   
   So delta_d ranges from -2 to 2.
   
   For delta_d to be negative, we need the negative terms to dominate.
   Most favorable: h[i-d]=0 (gives -1), h[j-d]=1 (gives 0), h[i+d]=0 (gives 0), h[j+d]=1 (gives -1). Total: -2.
   Next: -1 in various combinations.

4. So the best swaps for a given lag d are those where:
   - i-d is a zero (or invalid)
   - j-d is a one
   - i+d is a zero (or invalid)
   - j+d is a one (or invalid)

This means: i is "surrounded by zeros" in the d-neighborhood (at distance d), and j is "surrounded by ones".

This gives a natural heuristic: for each active lag d, find positions i that are "1s with zeros at distance d" and positions j that are "0s with ones at distance d". Swapping such a pair will reduce c_d by 2.

Let me implement this heuristic:

```python
def targeted_swap_search(h, n, max_iters=1000, deadline=None):
    """Targeted local search for binary h."""
    h = h.copy()
    c = np.correlate(h, 1.0-h, mode='full')
    best_c5 = float(c.max()) * 2.0 / n
    ones = np.flatnonzero(h == 1)
    zeros = np.flatnonzero(h == 0)
    
    for it in range(max_iters):
        if deadline and time.time() > deadline:
            break
        cur_max = float(c.max())
        # Find active lags
        tol = 0.5
        active = np.flatnonzero(c >= cur_max - tol)
        
        best_gain = 0
        best_pair = None
        best_new_c = None
        
        # For each active lag, propose candidate swaps
        candidates = set()
        for k in active[:20]:  # limit to top 20 active lags
            d = k - (n-1)
            if d == 0:
                continue
            # Find i in ones such that h[i-d]=0 or invalid (good for reducing c at lag d)
            # And j in zeros such that h[j+d]=1 or invalid
            # Simplified: just try all (i,j) pairs but prioritize
            for i in ones:
                # Check if this i is "good" for reducing lag d
                score_i = 0
                if 0 <= i+d < n and h[i+d] == 0: score_i += 1
                if 0 <= i-d < n and h[i-d] == 0: score_i += 1
                if score_i > 0:
                    for j in zeros:
                        score_j = 0
                        if 0 <= j-d < n and h[j-d] == 1: score_j += 1
                        if 0 <= j+d < n and h[j+d] == 1: score_j += 1
                        if score_j > 0:
                            candidates.add((i, j, score_i + score_j))
        
        # Evaluate top candidates
        if candidates:
            candidates = sorted(candidates, key=lambda x: -x[2])[:200]
            for i, j, _ in candidates:
                old_i, old_j = h[i], h[j]
                h[i], h[j] = old_j, old_i
                new_max = float(np.max(np.correlate(h, 1.0-h, mode='full')))
                h[i], h[j] = old_i, old_j
                gain = cur_max - new_max
                if gain > best_gain:
                    best_gain = gain
                    best_pair = (i, j)
        
        # Also try random swaps
        for _ in range(100):
            i = ones[np.random.randint(len(ones))]
            j = zeros[np.random.randint(len(zeros))]
            old_i, old_j = h[i], h[j]
            h[i], h[j] = old_j, old_i
            new_max = float(np.max(np.correlate(h, 1.0-h, mode='full')))
            h[i], h[j] = old_i, old_j
            gain = cur_max - new_max
