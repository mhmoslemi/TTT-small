So C₅ = max_k (c[k] * dx) where dx = 2/n.

This means C₅ = (2/n) * max_k c[k].

For a fixed continuous function h(x), as n→∞, c[k]*dx → ∫h(x)(1-h(x+k))dx.

But for finite n, the discrete c[k]*dx is an approximation. The max over k might be achieved at a different k than in the continuous case.

The key point: for our purposes, we just need to find any discrete h of any length n that minimizes (2/n)*max(c[k]).

2. Multi-resolution search (small n → large n)
3. Fourier subspace optimization for escaping local minima

Let me use a simpler approach: just do a golden section search or ternary search on [0,1] for each coordinate. It's slower per coordinate (O(log(1/eps)) evaluations, each O(m)) but much simpler to implement correctly.

Actually, for the min of max of affine functions plus a concave quadratic, the minimum is at one of the "kink points" where two affine functions cross, or where the quadratic is tangent to the max, or at a boundary. But finding all kink points is O(m²) which is too slow.

The bisection approach (binary search on the optimal value t) is O(m * log(1/eps)) per coordinate, which is what the previous code uses. Let me stick with that but make it cleaner.

            pos = asg > 1e-14
            neg = asg < -1e-14
            if np.any(pos):
                U = min(U, float(np.min((t - b[pos]) / asg[pos])))
            if np.any(neg):
                L = max(L, float(np.max((t - b[neg]) / asg[neg])))
            if L > U + 1e-12:
                return False
        if g <= 0.25:
            disc = max(0.0, 1.0 - 4.0 * g)
            r1 = 0.5 - 0.5 * np.sqrt(disc)
            r2 = 0.5 + 0.5 * np.sqrt(disc)
            if not (L <= r1 + 1e-12 or U >= r2 - 1e-12):
                return False
        return True
    
    # Bounds for bisection
    lo_v = unaff
    if m:
        lo_v = max(lo_v, float(np.max(cseg)))
    lo_v = max(lo_v, qconst)
    hi_v = max(lo_v + 1e-10, qconst + 0.25, float(np.max(b + np.abs(asg))) if m else 0.0)
    hi_v += 1e-8
    
    for _ in range(45):
        mid = 0.5 * (lo_v + hi_v)
        if feasible(mid):
            hi_v = mid
        else:
            lo_v = mid
    
    t = hi_v
    # Find optimal x: minimize the objective at t (which equals t at optimum)
    # Just do a fine grid search
    g = max(0.0, t - qconst)
    L, U = 0.0, 1.0
    if m:
        pos = asg > 1e-14
        neg = asg < -1e-14
        if np.any(pos):
            U = min(U, float(np.min((t - b[pos]) / asg[pos])))
        if np.any(neg):
            L = max(L, float(np.max((t - b[neg]) / asg[neg])))
    
    # Build feasible intervals
    intervals = []
    if g <= 0.25:
        disc = max(0.0, 1.0 - 4.0 * g)
        r1 = 0.5 - 0.5 * np.sqrt(disc)
        r2 = 0.5 + 0.5 * np.sqrt(disc)
        if L <= min(U, r1) + 1e-12:
            intervals.append((max(L, 0.0), min(U, r1)))
        if max(L, r2) <= U + 1e-12:
            intervals.append((max(L, r2), U))
    else:
        intervals.append((max(L, 0.0), min(U, 1.0)))
    
    best_x = hp
    for (a, bb) in intervals:
        if a >= bb - 1e-14:
            continue
        # The objective at t is min of max of the terms, which at t=hi_v is t
        # So any x in the feasible set gives objective ≈ t
        # We want to pick the x that gives the LOWEST actual objective
        # which is min of max(unaff, qconst+x(1-x), max(cseg+asg*(x-hp)))
        # Just pick the midpoint for simplicity
        x = 0.5 * (a + bb)
        # Or pick the x that minimizes the quadratic: x=0.5 if in interval
        if 0.5 >= a and 0.5 <= bb:
            x = 0.5
        best_x = x
        break  # First feasible interval is fine
    
    # Actually, let me just evaluate a few candidates
    cands = [hp] + [0.5 * (a + bb) for a, bb in intervals] + [a for a, bb in intervals] + [bb for a, bb in intervals]
    best_x = hp
    best_f = 1e100
    for x in cands:
        if x < 0 or x > 1:
            continue
        f = max(unaff, qconst + x * (1 - x))
        if m:
            f = max(f, float(np.max(cseg + asg * (x - hp))))
        if f < best_f:
            best_f = f
            best_x = x
    return float(best_x)

def cd_pass(h, n, tlimit=3.0):
    h = project_feasible(h, n)
    c = np.correlate(h, 1.0 - h, mode='full')
    center = n - 1
    L = 2 * n - 1
    t0 = time.time()
    for p in range(n):
        if time.time() - t0 > tlimit:
            break
        hp = float(h[p])
        lo = min(p, center - p)
        hi = max(center + p, 2 * center - p)
        seg = hi - lo + 1
        s_arr = center - np.arange(lo, hi + 1, dtype=np.int32)
        j = p + s_arr
        i_idx = p - s_arr
        a = np.zeros(seg, dtype=float)
        vj = (j >= 0) & (j < n)
        vi = (i_idx >= 0) & (i_idx < n)
        if np.any(vj):
            a[vj] += 1.0 - h[j[vj]]
        if np.any(vi):
            a[vi] -= h[i_idx[vi]]
        off = center - lo
        cseg = np.empty(seg - 1, dtype=float)
        asg = np.empty(seg - 1, dtype=float)
        if off:
            cseg[:off] = c[lo:center]
            asg[:off] = a[:off]
        if hi > center:
            cseg[off:] = c[center + 1:hi + 1]
            asg[off:] = a[off + 1:]
        qconst = float(c[center]) - hp * (1.0 - hp)
        unaff = 0.0
        if lo > 0:
            unaff = max(unaff, float(c[:lo].max()))
        if hi + 1 < L:
            unaff = max(unaff, float(c[hi + 1:].max()))
        bx = _solve_1d(hp, cseg, asg, qconst, unaff)
        if abs(bx - hp) > 1e-15:
            dx = bx - hp
            if off:
                c[lo:center] += asg[:off] * dx
