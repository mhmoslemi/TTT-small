The problem involves minimizing the overlap integral C_5, which is a challenging non-convex optimization task. The initial approach uses local search and gradient-based methods, which may get stuck in local minima. A hybrid strategy is proposed that combines global exploration with local refinement. This includes systematically varying grid resolution using a geometric progression, applying multiple optimized restart patterns, implementing multi-start optimization with grid refinement, and incorporating binary calibration for even grids. The goal is to escape local minima and find a globally better solution with improved smoothness and sparsity.

2. **Mathematical specification**  
The objective is to minimize C_5 = max_k (dx * np.correlate(h, 1-h, mode="full")[k+n-1]) subject to:
- \( 0 \leq h[i] \leq 1 \) for all i
- \(\sum_h = n/2\)

The grid spacing is \( dx = 2.0/n \), and ignore autofixes from the Erdős formulation. The solution is represented as a 1D numpy array of floats, projected to the simplex to maintain constraints.

- **Deadline management**: Break early if time is insufficient, using exponential timing.
- **Binary calibration**: For even grids, use swap moves and feasibility checks.
- **Helper functions**: Define `project_simplex`, `compute_c5`, `smooth_val_grad` for efficient evaluation and gradient computation.
