**Key insight for exact coordinate descent:**

For coordinate p, changing h[p] from v₀ to v affects:

- c[n-1+k] for k≠0 by: δ * (1-h[p-k]) (if p-k is valid)
- c[n-1-k] for k≠0 by: -δ * h[p+k] (if p+k is valid)

So for each affected correlation c[i], the change is:
Δc[i] = a_i * δ (+ b_i * δ² for the diagonal)

where a_i is a constant depending on the neighbors of p.

The new objective is:
f(δ) = max_i (c[i] + a_i * δ + b_i * δ²)

For i ≠ n-1: linear in δ
For i = n-1: quadratic in δ (but we can ignore it since it's far from the max)

So f(δ) ≈ max_i (c[i] + a_i * δ) is the max of linear functions = convex piecewise linear.

The minimum of this over δ ∈ [max(0-v₀, 1-v₀), min(1-v₀, 1-v₀)] (i.e., δ ∈ [max(-v₀, 0-v₀), min(1-v₀, 1-v₀)] = [max(-v₀, 0), min(1-v₀, 1)]) 

Wait, v₀ ∈ [0,1], so v = v₀ + δ ∈ [0,1] means δ ∈ [-v₀, 1-v₀].

To find the minimum of f(δ) = max_i (m_i + a_i * δ) over δ ∈ [-v₀, 1-v₀]:

Method: The minimum occurs at a point where either:
- δ is at a boundary (-v₀ or 1-v₀), or
- Two (or more) constraints are active and their slopes bracket 0

Algorithm:
1. Compute m_i = c[i] and a_i for all affected i
2. Also compute the "unaffected" max: M_unaff = max of c[i] for unaffected i
3. f(δ) = max(M_unaff, max_affected (m_i + a_i * δ))
4. Find the minimum

For step 4, we can use the following:
- The function g(δ) = max_affected (m_i + a_i * δ) is convex piecewise linear
- f(δ) = max(M_unaff, g(δ)) is also convex piecewise linear
- Find the minimum of f over [-v₀, 1-v₀]

To find the minimum of a convex piecewise linear function:
- The minimum is where the subgradient contains 0
- The subgradient at δ is [min_active_slope, max_active_slope] where active means m_i + a_i*δ = g(δ)
- We want to find δ where min_active_slope ≤ 0 ≤ max_active_slope

Algorithm to find this:
1. Start with δ = 0
2. Find the active set (constraints achieving the max)
3. If all active slopes > 0, the function is increasing, so decrease δ
4. If all active slopes < 0, the function is decreasing, so increase δ
5. If there exist active slopes on both sides of 0, we've found the minimum
6. If we need to move, find the nearest breakpoint (where a different constraint becomes active) and jump there
7. Repeat

The number of breakpoints crossed is at most the number of constraints (n), but in practice it's much smaller (usually 1-5).

Actually, I just realized: I can use a much simpler approach. Since f is the max of linear functions (ignoring the diagonal), its minimum over an interval is at a point where two constraints cross, or at a boundary. The subgradient at the minimum contains 0.

I can find the minimum by:
1. Start at dv=0
2. Compute f(0) and identify the active constraint (the one giving the max)
3. If the active constraint's slope a_i > 0, move dv in the negative direction
4. If a_i < 0, move dv in the positive direction
5. Find the nearest breakpoint (where a different constraint becomes active) in the direction of movement
6. Jump to that breakpoint
7. Repeat

The number of iterations is at most the number of times the active constraint changes, which is O(n) in the worst case but typically O(1).

```python
    # if min g(dv).max() <= M_unaff, the minimum is at M_unaff (any dv where g(dv).max() <= M_unaff works)

            # Since c_aff[active] >= c_aff[j] + a_aff[j]*dv (active is max), we have:
            # c_aff[j] - c_aff[active] <= -dv*(a_aff[active] - a_aff[j]) ... wait this isn't quite right

            mask = a_aff < a_aff[active]

                dv_candidates = dv_candidates[(dv_candidates < dv) & (dv_candidates >= dv_lo)]

                # We want dv_j > dv

                if len(dv_candidates) > 0:
                    dv = float(dv_candidates.min())
                else:
                    dv = dv_hi
            else:
                dv = dv_hi
        
        # Check convergence
        # (in practice, this converges in 1-5 iterations)
```

```python
import numpy as np
import time

def compute_c5(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1.0 - h, mode='full')
    return float(c.max()) * dx

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h.copy(), 0.0, 1.0)
    for _ in range(500):
        diff = target - h.sum()
        if abs(diff) < 1e-13:
            break
        if diff > 1e-15:
            room = 1.0 - h
            tot = room.sum()
            if tot < 1e-15:
                break
            h += (diff / tot) * room
        elif diff < -1e-15:
            tot = h.sum()
            if tot < 1e-15:
                break
            h += (diff / tot) * h
    return np.clip(h, 0.0, 1.0)

def coord_descent(h, n, max_passes=100, deadline=None):
    """Exact coordinate descent using golden section search per coordinate."""
    h = h.copy()
    c = np.correlate(h, 1.0 - h, mode='full')
    
    for pidx in range(max_passes):
        if deadline is not None and time.time() > deadline:
            break
        any_improved = False
        for p in range(n):
            if deadline is not None and time.time() > deadline:
                break
            v0 = h[p]
            
            # Compute linear coefficients a[i] for the change in c
            a = np.zeros(2 * n - 1)
            # Forward: lag k, need 0 <= p-k < n
            klo = max(-(n-1), p - n + 1)
            khi = min(n-1, p)
            for k in range(klo, khi + 1):
                a[n-1+k] += (1.0 - h[p-k])
            # Backward: lag k, need 0 <= p+k < n
            klo = max(-(n-1), -p)
            khi = min(n-1, n - 1 - p)
            for k in range(klo, khi + 1):
                a[n-1+k] -= h[p+k]
            
            aff = (a != 0.0)
            if not aff.all():
                M_unaff = float(c[~aff].max())
            else:
                M_unaff = -1e18
            
            # Search range
            lo = max(-v0, -0.3)
            hi = min(1.0 - v0, 0.3)
            if v0 < 1e-10:
                lo = 0.0
            if v0 > 1.0 - 1e-10:
                hi = 0.0
            if lo >= hi - 1e-12:
                continue
            
            # Golden section search
            gr = (np.sqrt(5.0) - 1.0) / 2.0
            a_g, b_g = lo, hi
            c_g = b_g - gr * (b_g - a_g)
            d_g = a_g + gr * (b_g - a_g)
            
            def fval(dv):
                idx = np.where(aff)[0]
                vals = c[idx] + a[idx] * dv
                # Fix diagonal
                if (n-1) in idx:  # always true
                    vals[np.where(idx == n-1)[0][0]] = c[n-1] + a[n-1]*dv - dv*dv
                return max(M_unaff, float(vals.max()))
            
            fc = fval(c_g)
            fd = fval(d_g)
            for _ in range(40):
                if b_g - a_g < 1e-12:
                    break
                if fc < fd:
                    b_g = d_g
                    d_g = c_g
                    fd = fc
                    c_g = b_g - gr * (b_g - a_g)
                    fc = fval(c_g)
                else:
                    a_g = c_g
                    c_g = d_g
                    fc = fd
                    d_g = a_g + gr * (b_g - a_g)
                    fd = fval(d_g)
            
            dv_opt = (a_g + b_g) / 2.0
            v_new = float(np.clip(v0 + dv_opt, 0.0, 1.0))
            
            if abs(v_new - v0) > 1e-9:
                h[p] = v_new
                dv = v_new - v0
                c[aff] += a[aff] * dv
                c[n-1] -= dv * dv
                any_improved = True
        
        if not any_improved:
            break
    
    return h, compute_c5(h, n)
```

```python
                dv = v_new - v0
                c[aff] += a[aff] * dv
                c[n-1] -= dv * dv
                any_improved = True
        if not any_improved:
            break
        if (pidx + 1) % 8 == 0:
            h = project_feasible(h, n)
            c = np.correlate(h, 1.0 - h, mode='full')
    return h, compute_c5(h, n)

def binary_push_optimize(h, n, deadline=None):
    """Push toward binary then re-optimize."""
    h_bin = (h > 0.5).astype(float)
    h_bin = project_feasible(h_bin, n)
    h_opt, c_opt = coord_descent_fast(h_bin, n, max_passes=80, deadline=deadline)
    return h_opt, c_opt

def structured_init(n, kind, rng):
    x = np.linspace(0, 2, n, endpoint=False)
    if kind == 0:
        h = 0.5 + 0.45 * np.sin(2 * np.pi * x)
    elif kind == 1:
        h = 0.5 + 0.35 * np.sin(2 * np.pi * x) + 0.2 * np.sin(6 * np.pi * x)
    elif kind == 2:
        h = (np.sin(2 * np.pi * x) > 0).astype(float)
    elif kind == 3:
        h = (np.sin(3 * np.pi * x) > 0).astype(float)
    elif kind == 4:
        # Golay-like: alternating blocks
        blk = n // 6
        h = np.zeros(n)
        for i in range(0, n - blk + 1, 2 * blk + 1):
            h[i:i+blk] = 1.0
    else:
        h = rng.uniform(0, 1, n)
    return project_feasible(h, n)

def run(seed=42, budget_s=1100, **kwargs):
    t0 = time.time()
    rng = np.random.RandomState(seed)
    deadline = t0 + budget_s - 5

    try:
        h_init = np.array(initial_h_values, dtype=float).copy()
        n_init = len(h_init)
    except Exception:
        n_init = 500
        h_init = structured_init(n_init, 0, rng)

    best_h = project_feasible(h_init, n_init)
    best_c = compute_c5(best_h, n_init)

    # Phase 1: Aggressive coordinate descent on initial
    h1, c1 = coord_descent_fast(best_h, n_init, max_passes=200, deadline=deadline)
    if c1 < best_c:
        best_h, best_c = h1, c1

    # Phase 2: Binary push + re-optimize
    h2, c2 = binary_push_optimize(best_h, n_init, deadline)
    if c2 < best_c:
        best_h, best_c = h2, c2

    # Phase 3: More coordinate descent passes
    h3, c3 = coord_descent_fast(best_h, n_init, max_passes=300, deadline=deadline)
    if c3 < best_c:
        best_h, best_c = h3, c3

    # Phase 4: Try different n values
    x_best = np.linspace(0, 2, len(best_h), endpoint=False)
    for n_try in [200, 300, 400, 500, 600, 700, 800]:
        if time.time() > deadline - 60:
            break
        if n_try == len(best_h):
            continue
        x_try = np.linspace(0, 2, n_try, endpoint=False)
        h_try = np.interp(x_try, x_best, best_h)
        h_try = project_feasible(h_try, n_try)
        h_try, c_try = coord_descent_fast(h_try, n_try, max_passes=150, deadline=deadline)
        if c_try < best_c:
            best_h, best_c = h_try, c1 if False else c_try
            best_h, best_c = h_try, c_try

    # Phase 5: Perturbation restarts on best n
    n_best = len(best_h)
    x_best = np.linspace(0, 2, n_best, endpoint=False)
    if time.time() < deadline - 80:
        for r in range(6):
            if time.time() > deadline - 30:
                break
            if r == 0:
                hp = project_feasible(best_h + 0.05 * rng.randn(n_best), n_best)
            elif r == 1:
                hp = project_feasible(best_h + 0.15 * rng.randn(n_best), n_best)
            elif r == 2:
                hp = structured_init(n_best, r % 5, rng)
            elif r == 3:
                # Random binary with perturbation
                hb = (rng.uniform(0, 1, n_best) > 0.5).astype(float)
                hp = project_feasible(hb + 0.1 * rng.randn(n_best), n_best)
            else:
                hp = project_feasible(best_h + 0.03 * rng.randn(n_best), n_best)
            ho, co = coord_descent_fast(hp, n_best, max_passes=150, deadline=deadline)
            if co < best_c:
                best_h, best_c = ho, co

    # Phase 6: Final polish
    if time.time() < deadline - 5:
        h6, c6 = coord_descent_fast(best_h, len(best_h), max_passes=300, deadline=deadline)
        if c6 < best_c:
            best_h, best_c = h6, c6

    best_h = project_feasible(best_h, len(best_h))
    best_c = compute_c5(best_h, len(best_h))
    return best_h, best_c, len(best_h)
```
