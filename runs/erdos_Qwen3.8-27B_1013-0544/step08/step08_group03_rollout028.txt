g_0[p] = 1 - 2*h[p]

And the subgradient of f(h) = max_k c_k * dx is:
∂f/∂h = dx * (1/|K|) * sum_{k∈K} g_k where K = argmax(c)

We can use this for projected gradient descent:
1. Compute c, find K = {k : c[k] ≥ max(c) - eps}
2. Compute subgradient g = (dx/|K|) * sum_{k∈K} g_k
3. h_new = h - lr * g
4. Project to [0,1] and sum constraint

The step size lr can be chosen adaptively (barzilai-borwein or backtracking).

This should be faster than SLSQP because each iteration is O(n * |K|) for the gradient + O(n) for the projection.

But will it converge? Projected subgradient methods converge sublinearly. For a non-convex problem (which this is, due to bilinearity), it might get stuck. But combined with CD polishing, it might be effective.

**Let me also consider a different approach: alternating minimization**

The bilinear structure c_k = sum h[i+k]*(1-h[i]) suggests we can alternate:
- Fix h (the "first" copy), optimize (1-h) (the "second" copy) subject to constraints
- Then fix (1-h), optimize h

But the constraint is that both copies are related: the second is 1-h. So this doesn't directly help.

**Another idea: Use the fact that we can write the problem as a quadratic program**

minimize max_k sum_i h[i+k](1-h[i])
= minimize max_k (sum_i h[i+k] - sum_i h[i+k]h[i])
= minimize max_k (S_k - Q_k) where S_k = sum of h at positions i+k, Q_k = sum of products

The S_k terms are linear, Q_k are quadratic (but with specific structure - they're the autocorrelation).

This is a quadratically constrained quadratic program (QCQP), which is NP-hard in general. But for our specific structure, we might be able to use specialized solvers.

The idea: parameterize h as a function of some free parameters, use L-BFGS-B (which is fast for large problems), and optimize a smooth approximation of the max.

For the smooth approximation, use:
f_β(h) = (1/β) * log(sum_k exp(β * c_k(h)))

This is the "log-sum-exp" approximation to the max. As β → ∞, it converges to the max. For finite β, it's smooth and differentiable.

The gradient is:
∇f_β = (1/β) * sum_k [β * exp(β*c_k) / sum_j exp(β*c_j)] * ∇c_k
= sum_k w_k * ∇c_k where w_k = exp(β*c_k) / sum_j exp(β*c_j)

This is a weighted average of the gradients of the individual c_k, with weights proportional to their "importance" (larger c_k gets more weight).

This is essentially a smooth approximation to the subgradient of the max!

from scipy.optimize import minimize
import time

def compute_c5(h, n):
    dx = 2.0 / n
    return float(np.max(np.correlate(h, 1.0 - h, mode='full')) * dx)

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h.copy(), 0.0, 1.0)
    for _ in range(5000):
        diff = target - h.sum()
        if abs(diff) < 1e-15:
            break
        if diff > 0:
            room = 1.0 - h
            tot = room.sum()
            if tot < 1e-15:
                break
            h += (diff / tot) * room
        else:
            tot = h.sum()
            if tot < 1e-15:
                break
            h += (diff / tot) * h
    return np.clip(h, 0.0, 1.0)

def interpolate_h(h_old, n_old, n_new):
    x_old = np.linspace(0.0, 2.0, n_old)
    x_new = np.linspace(0.0, 2.0, n_new)
    return project_feasible(np.interp(x_new, x_old, h_old), n_new)

def cd_optimize(h, n, max_passes=100, deadline=None):
    h = h.copy()
    for _ in range(max_passes):
        if deadline is not None and time.time() > deadline:
            break
        c = np.correlate(h, 1.0 - h, mode='full').astype(np.float64)
        current_max = float(c.max())
        improved = False
        for p in range(n):
            if deadline is not None and time.time() > deadline:
                break
            h0 = h[p]
            if h0 <= 1e-13 or h0 >= 1.0 - 1e-13:
                continue
            A = np.zeros(2 * n - 1)
            # Term 1: (1-h[p-k]) for valid k
            k_lo = max(0, p - n + 1)
            k_hi = min(2 * n - 2, p)
            if k_lo <= k_hi:
                idx = p - np.arange(k_lo, k_hi + 1)
                A[k_lo:k_hi + 1] += (1.0 - h[idx])
            # Term 2: -h[p+k] for valid k
            k_lo2 = 0
            k_hi2 = min(2 * n - 2, n - 1 - p)
            if k_lo2 <= k_hi2:
                idx2 = p + np.arange(k_lo2, k_hi2 + 1)
                A[k_lo2:k_hi2 + 1] += -h[idx2]
            D = np.zeros(2 * n - 1)
            D[n - 1] = 1.0
            c0 = c - h0 * A + h0 * h0 * D
            # Grid + golden section to minimize max(c0 + t*A - t^2*D)
            grid = np.linspace(0.0, 1.0, 40)
            fvals = np.array([np.max(c0 + t * A - t * t * D) for t in grid])
            bi = int(np.argmin(fvals))
            lo = grid[max(0, bi - 1)]
            hi = grid[min(39, bi + 1)]
            t_star = grid[bi]
            if hi - lo > 1e-10:
                gr = (np.sqrt(5.0) - 1.0) / 2.0
                a, b = lo, hi
                c1 = b - gr * (b - a)
                d1 = a + gr * (b - a)
                fc1 = np.max(c0 + c1 * A - c1 * c1 * D)
                fd1 = np.max(c0 + d1 * A - d1 * d1 * D)
                for _ in range(30):
                    if fc1 < fd1:
                        b = d1; d1 = c1; fd1 = fc1
                        c1 = b - gr * (b - a)
                        fc1 = np.max(c0 + c1 * A - c1 * c1 * D)
                    else:
                        a = c1; c1 = d1; fc1 = fd1
                        d1 = a + gr * (b - a)
                        fd1 = np.max(c0 + d1 * A - d1 * d1 * D)
                t_star = (a + b) * 0.5
            f_star = np.max(c0 + t_star * A - t_star * t_star * D)
            f0 = np.max(c0)
            f1 = np.max(c0 + A - D)
            if min(f_star, f0, f1) < current_max - 1e-12:
                t_new = t_star
                if f0 <= f_star and f0 <= f1:
                    t_new = 0.0
                elif f1 <= f_star and f1 <= f0:
                    t_new = 1.0
                else:
                    t_new = max(0.0, min(1.0, t_star))
                c = c0 + t_new * A - t_new * t_new * D
                h[p] = t_new
                current_max = float(c.max())
                improved = True
        h = project_feasible(h, n)
        if not improved:
            break
    return h, compute_c5(h, n)

    dx = 2.0 / n
    target = n / 2.0
    
    def obj_grad(x):
        c = np.correlate(x, 1.0 -
