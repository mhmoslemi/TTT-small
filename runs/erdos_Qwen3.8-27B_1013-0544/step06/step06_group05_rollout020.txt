```python
    pos2 = i_indices + lags  # (n, 2n-1): i + lag
    valid2 = (pos2 >= 0) & (pos2 < n)
    
    # (1-h[i-lag]) where valid, else 0
    term1 = np.where(valid1, 1 - h[np.clip(pos1, 0, n-1)], 0.0)
    # h[i+lag] where valid, else 0
    term2 = np.where(valid2, h[np.clip(pos2, 0, n-1)], 0.0)
    
    return term1 - term2
```

This is a single vectorized operation on (n, 2n-1) arrays, which is very fast.

```python
            h[j] = 0.0
```

```python
                best_c5 = cur_max * dx
                best_h = h.copy()
```

Actually, can we update deltas incrementally too? After flipping h[i] from 0 to 1 and h[j] from 1 to 0:

For any position k (k ≠ i, j):
delta_k changes by:
- Due to h[i] going 0→1: delta_k[lag] gets -1 where k-lag=i (lag=k-i) and -1 where k+lag=i (lag=i-k)
- Due to h[j] going 1→0: delta_k[lag] gets +1 where k-lag=j (lag=k-j) and +1 where k+lag=j (lag=j-k)

So for each k≠i,j, at most 4 entries change by ±1.

For k=i: delta_i needs to be fully recomputed (since h[i] changed)
For k=j: delta_j needs to be fully recomputed

The incremental update would be:
- For all k≠i,j: update 4 entries each → O(n) total
- Recompute delta_i and delta_j: O(n) each → O(n) total
- Total: O(n) per swap

vs. full recomputation: O(n²) per swap.

```python
def compute_all_deltas(h, n):

    pos2 = i_idx + lags

    term2 = np.where(valid2, h[np.clip(pos2, 0, n-1)], 0.0)
    return term1 - term2
```

Alternative: use a simple gradient-based approach. The objective (smooth max) has a gradient that can be computed analytically.

For the smooth max: f(x) = m + (sm + log(sum(exp(sh))) / alpha) where sh = alpha*(g-m), sm = sh.max()
The gradient is: df/dx[i] = sum_k (exp(alpha*(g[k]-m))) / sum_j exp(alpha*(g[j]-m)) * dg[k]/dx[i]

And dg[k]/dx[i] = d/dx[i] [sum_j x[j](1-x[j+lag_k])] * dx
= [(1-x[i+lag_k]) - x[i-lag_k]] * dx (with bounds)

This is exactly deltas[i] * dx!

So the gradient of the smooth max at point h is:
grad[i] = sum_k softmax_k * deltas[i][k] * dx

where softmax_k = exp(alpha*(c[k]-m)) / sum_j exp(alpha*(c[j]-m))

This is a weighted sum of the delta vectors, where the weights are the softmax of the correlation values.

For the constrained problem (sum h = n/2, 0≤h≤1), we can use projected gradient descent:
1. Compute gradient
2. Take a step: h_new = h - lr * grad
3. Project to feasible set (clip to [0,1], then adjust sum)

This is much faster than SLSQP! And we can do many iterations.

```python
def smooth_gradient_polish(h, n, deadline, alpha=1000.0):
    dx = 2.0 / n
    best_h = h.copy()
    best_c5 = float(np.correlate(h, 1-h, mode='full').max() * dx)
    
    lr = 0.5  # learning rate
    for _ in range(1000000):
        if time.time() > deadline:
            break
        
        c = np.correlate(h, 1-h, mode='full')
        m = c.max()
        
        # Softmax weights
        sh = alpha * (c - m)
        sm = sh.max()
        weights = np.exp(sh - sm)
        weights /= weights.sum()
        
        # Gradient = weighted sum of deltas
        deltas = compute_all_deltas(h, n)
        grad = (weights[None, :] * deltas).sum(axis=0) * dx
        
        # Gradient step
        h_new = h - lr * grad
        
        # Project
        h_new = np.clip(h_new, 0, 1)
        diff = n/2.0 - h_new.sum()
        for _ in range(1000):
            if abs(diff) < 1e-12: break
            if diff > 0:
                room = 1.0 - h_new
                s = room.sum()
                if s < 1e-14: break
```
