Actually, for a "white noise" binary sequence (random), |H[m]|² ≈ N/4 for all m (on average), so the sum ≈ (N/4) * sum_{m=1}^{N-1} cos(2πmk/N) = 0 for k≠0 (by the Dirichlet kernel property). So CC[k] ≈ N/4 for all k, giving C₅ ≈ 1/2. This matches our earlier calculation.

To do better, we need to "shape" the spectrum so that the autocorrelation has lower peaks. This is essentially the "minimum peak sidelobe" sequencedesign problem.

One approach: use a genetic algorithm or simulated annealing in the frequency domain. But this is complex.

A simpler approach: use the fact that the problem is equivalent to finding a binary sequence with low aperiodic autocorrelation. There are known constructions:
- m-sequences (maximal length LFSR sequences): have three-valued autocorrelation
- Barker sequences: have low sidelobes but only exist for certain lengths
- Zadoff-Chu sequences: have constant autocorrelation (but complex-valued)

```python
def swap_delta_vec(h, i, j, n):
    delta = np.zeros(2*n-1)
    # i: 0 -> 1
    # Effect on c[s] where h[i] is the "first" term: s in [-i, n-1-i]
    s_lo = max(-i, -(n-1))
    s_hi = min(n-1-i, n-1)
    s_range = np.arange(s_lo, s_hi+1)
    valid = (i + s_range >= 0) & (i + s_range < n)
    delta[s_range[valid] + n-1] += (1.0 - h[i + s_range[valid]])
    # Effect where h[i] is the "second" term (m+s = i, m = i-s): s in [i-(n-1), i]
    s_lo = max(i-(n-1), -(n-1))
    s_hi = min(i, n-1)
    s_range = np.arange(s_lo, s_hi+1)
    valid = (i - s_range >= 0) & (i - s_range < n)
    delta[s_range[valid] + n-1] -= h[i - s_range[valid]]
    # j: 1 -> 0
    s_lo = max(-j, -(n-1))
    s_hi = min(n-1-j, n-1)
    s_range = np.arange(s_lo, s_hi+1)
    valid = (j + s_range >= 0) & (j + s_range < n)
    delta[s_range[valid] + n-1] -= (1.0 - h[j + s_range[valid]])
    s_lo = max(j-(n-1), -(n-1))
    s_hi = min(j, n-1)
    s_range = np.arange(s_lo, s_hi+1)
    valid = (j - s_range >= 0) & (j - s_range < n)
    delta[s_range[valid] + n-1] += h[j - s_range[valid]]
    return delta
```

This is O(n) per call but with numpy vectorization, it should be fast.

c_new[s] = sum_m h_new[m] * (1 - h_new[m+s])

where h_new differs from h_old at positions {i1, i2, j1, j2}.

```python
def two_swap_delta(h, i1, i2, j1, j2, n):
    """Delta in corr for 2-swap: h[i1],h[i2] 0->1; h[j1],h[j2] 1->0."""
    delta = np.zeros(2*n - 1)
    offset = n - 1
    flipped = {i1: 1, i2: 1, j1: 0, j2: 0}  # new values
    
    for s in range(-offset, offset + 1):
        # Find all m where m or m+s is in the flipped set
        # m in flipped: m = i1, i2, j1, j2 (if valid: 0<=m<n and 0<=m+s<n)
        # m+s in flipped: m = i1-s, i2-s, j1-s, j2-s (if valid)
        affected = set()
        for pos in [i1, i2, j1, j2]:
            if 0 <= pos < n and 0 <= pos + s < n:
                affected.add(pos)
            m = pos - s
            if 0 <= m < n and 0 <= pos < n:
                affected.add(m)
        for m in affected:
            if 0 <= m < n and 0 <= m + s < n:
                old_val = h[m] * (1 - h[m+s])
                new_h_m = flipped.get(m, h[m])
                new_h_mp = flipped.get(m+s, h[m+s])
                new_val = new_h_m * (1 - new_h_mp)
                delta[s + offset] += new_val - old_val
    return delta
```

For binary h, the "interaction" between two flips at positions a and b is:
- If a = b + s for some valid s (i.e., they're at a valid correlation distance), then:
