```python
def compute_delta_c(h, i0, j0, n):
    """Compute change in correlation when h[i0] 0->1 and h[j0] 1->0."""
    delta = np.zeros(2*n-1)
    # For each lag k (from -(n-1) to (n-1)):
    # delta[k] = h[j0+k] + h[j0-k] - h[i0-k] - h[i0+k] (with OOB = 0)
    lags = np.arange(-(n-1), n)
    # h[j0+lag] where valid
    idx1 = j0 + lags
    valid1 = (idx1 >= 0) & (idx1 < n)
    val1 = np.zeros(2*n-1)
    val1[valid1] = h[idx1[valid1]]
    idx2 = j0 - lags
    valid2 = (idx2 >= 0) & (idx2 < n)
    val2 = np.zeros(2*n-1)
    val2[valid2] = h[idx2[valid2]]
    idx3 = i0 - lags
    valid3 = (idx3 >= 0) & (idx3 < n)
    val3 = np.zeros(2*n-1)
    val3[valid3] = h[idx3[valid3]]
    idx4 = i0 + lags
    valid4 = (idx4 >= 0) & (idx4 < n)
    val4 = np.zeros(2*n-1)
    val4[valid4] = h[idx4[valid4]]
    delta = val1 + val2 - val3 - val4
    return delta
```

This is like the previous approach but faster because we focus on one lag at a time.

For a given critical lag k, the correlation is:
c[k] = ∑_i h[i+k] * (1-h[i])

To reduce c[k], we want to:
- Change a position i where h[i+k]=1 and h[i]=1 to h[i]=0 (reduces c[k] by 1)
- But we need to change another position from 0 to 1 to maintain the sum constraint
- The new 1 at position j will increase c[k] by (1-h[j-k]) if h[j-k]=0... wait no.

Actually, if we set h[i] from 1 to 0 (where h[i+k]=1): c[k] decreases by 1.
If we set h[j] from 0 to 1: c[k] increases by (1-h[j-k]).
Net change: -(1) + (1-h[j-k]) = -h[j-k]

So to reduce c[k], we want h[j-k]=1, i.e., j-k is a position with h=1.
But we also need to not increase other lags too much.

This gives a local improvement heuristic:
1. Find the lag k with maximum correlation
2. Find a one at position i such that h[i+k]=1 (contributing to c[k])
3. Find a zero at position j such that h[j-k]=1 (to minimize increase to c[k])
4. Check that the swap doesn't increase any other critical lag
5. If feasible, make the swap

This is O(n) per step (finding candidates) and we can do many steps.
