            s = h.sum()
            if s < 1e-14:

The issue with the max function is that it's non-smooth. The log-sum-exp smoothing makes it smooth but introduces bias. As α → ∞, the bias goes to 0, but the condition number of the Hessian grows, making optimization harder.

A better approach might be to use a **piecewise linear** approximation of the max:
f(h) ≈ max_{S ⊆ [K], |S| = m} (1/m) Σ_{k∈S} c_k(h)

Optimize over both h and S. This is a mixed-integer problem, but we can fix S to be the top m correlations at the current iterate.

Actually, for the continuous case, since h ∈ [0,1]^n and the constraint is Σh_i = n/2, the problem is:
min_t t
s.t. c_k(h) ≤ t for all k
0 ≤ h_i ≤ 1
Σ h_i = n/2

This is non-convex because c_k(h) = Σ_i h_{i+k}(1-h_i) is bilinear.

However, if we linearize: c_k(h) ≈ c_k(h₀) + Σ_i [(1-h_i)δh_{i+k} - h_{i+k}δh_i] (first-order Taylor), then we get a LP.

This suggests an **iterative linearization** approach:
1. Start with h₀
2. Linearize c_k around h₀
3. Solve the LP: min t s.t. c_k(h) ≤ t (linearized), constraints
4. Update h₀ = h
5. Repeat

This is like a sequential quadratic programming (SQP) approach but with linearization instead of quadratic model.
