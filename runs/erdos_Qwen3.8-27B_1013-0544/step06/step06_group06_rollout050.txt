The gradient of f with respect to h[i] involves the gradient of each corr[k] with respect to h[i], which is:
∂corr[k]/∂h[i] = (1-h[i+lag]) - h[i-lag] (roughly, for valid indices)

This is the same as g[i][k] for the appropriate k (up to a sign).

Actually, for the continuous case:
corr[k] = ∑_p h[p](1-h[p+lag_k])
∂corr[k]/∂h[i] = (1-h[i+lag_k]) - h[i-lag_k] (for valid indices, with boundary handling)

This is exactly what g[i][k] computes (for binary h). For continuous h, it's the same formula.

So the gradient of the log-sum-exp objective is:
∇f = (1/alpha) * ∑_k exp(alpha * corr[k]) * ∂corr[k]/∂h / ∑_k exp(alpha * corr[k])

This is a weighted average of the ∂corr[k]/∂h, weighted by exp(alpha * corr[k]).

For large alpha, this concentrates on the lags where corr is largest.
