  So f(h) = max_k c[k] is not necessarily concave. It's a general non-convex function.
  
  OK so standard convex optimization tools don't directly apply. But the smooth max (log-sum-exp) is still a smooth approximation that we can minimize with quasi-Newton methods.

```python
def _lbfgs_grad(x, n, alpha, penalty):
    target = n / 2.0
    dx = 2.0 / n
    c = np.correlate(x, 1.0 - x, mode='full')
    m = c.max()
    sh = np.clip(alpha * (c - m), -400, 400)
    w = np.exp(sh)
    w /= w.sum()
    grad = np.zeros(n)
    for p in range(n):
        # T1: k from max(0, n-1-p) to min(2n-2, 2n-2-p)
        klo = max(0, n - 1 - p)
        khi = min(2*n-2, 2*n-2-p)
        if khi >= klo:
            js = p + np.arange(klo, khi+1) - n + 1
            grad[p] += w[klo:khi+1] @ (1.0 - x[js])
        # T2: k from max(0, p) to min(2n-2, p+n-1)
        klo2 = max(0, p)
        khi2 = min(2*n-2, p + n - 1)
        if khi2 >= klo2:
            js2 = p - np.arange(klo2, khi2+1) + n - 1
            grad[p] -= w[klo2:khi2+1] @ x[js2]
    grad *= dx
    grad += 2.0 * penalty * (x.sum() - target)
    return grad
```
