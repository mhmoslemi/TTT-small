- For each position i, try changing h[i] to h[i]+delta for small delta
- To maintain the sum constraint, adjust one other position j
- The best j is the one that minimizes the increase in max correlation
- Accept the change if it reduces the max

- delta_corr[m] -= delta * h[i-m] at valid positions (i as second element, since (1-h) decreases)
Wait, this isn't quite right because changing h[i] also affects (1-h[i]) which appears when i is the second element.

Let me think about this more carefully. The correlation at lag m is:
C[m] = sum_v h[v] * (1-h[v+m])

If I change h[i] by delta:
- When v=i: term changes from h[i]*(1-h[i+m]) to (h[i]+delta)*(1-h[i+m]), change = delta*(1-h[i+m])
- When v+m=i (i.e., v=i-m): term changes from h[v]*(1-h[i]) to h[v]*(1-h[i]-delta), change = -delta*h[v] = -delta*h[i-m]

So the total change in C[m] is:
delta_C[m] = delta * (1-h[i+m]) - delta * h[i-m]
= delta * (1 - h[i+m] - h[i-m])

(with boundary conditions: if i+m or i-m is out of range, that term is 0)

This is O(n) to compute for all m. And if I also need to adjust h[j] by -delta (to maintain sum), the total change is:
total_delta_C[m] = delta * ((1-h[i+m]) - h[i-m] - (1-h[j+m]) + h[j-m])

This is still O(n) per (i,j,delta) combination.

For n=250, trying all pairs (i,j) with one delta value: 250*249 ≈ 62k combinations, each O(n)=250 operations. Total: ~15.6M operations per sweep. In numpy, this should take about 0.1 seconds.

                    jm = j + m_range
                    msk = (jm >= 0) & (jm < n)
                    d2[msk] += need * (1.0 - h[jm[msk]])
                    jmn = j - m_range
                    msk = (jmn >= 0) & (jmn < n)
                    d2[msk] -= need * h[jmn[msk]]
                    # interaction corrections
                    k1 = n - 1 + (j - i)
                    if 0 <= k1 < 2 * n - 1:
                        d1[k1] -= d * need
                        d2[k1] -= d * need
                    k2 = n - 1 + (i - j)
                    if 0 <= k2 < 2 * n - 1:
                        d1[k2] -= d * need
                        d2[k2] -= d * need
                    new_corr = corr + d1 + d2
                    nc = new_corr.max()
                    if nc < cur_max - 1e-10:
                        h[i] = ni
                        h[j] = nj
                        corr = new_corr
                        cur_max = nc
                        improved = True
                        if nc * dx < best_c:
                            best_c = nc * dx
                            best_h = h.copy()
                        break
                if improved:
                    break
        if not improved:
            break
    return best_h, best_c

def run(seed=42, budget_s=1100, **kwargs):
    t0 = time.time()
    dl = t0 + budget_s - 8
    rng = np.random.RandomState(seed)
    try:
        h0 = np.array(initial_h_values, dtype=float).copy()
        n = len(h0)
    except Exception:
        n = 250
        h0 = np.full(n, 0.5)
    best_h = project_feasible(h0, n)
    best_c = compute_c5(best_h, n)

    # Phase 1: SLSQP smooth optimization
    p1 = t0 + 0.15 * (budget_s - 8)
    h = best_h.copy()
    for alpha in [2000, 10000, 50000, 200000, 1000000]:
        if time.time() > p1:
            break
        h = slsqp_smooth(h, n, alpha, 1200, 1e-15)
        c = compute_c5(h, n)
        if c < best_c:
            best_c = c
            best_h = h.copy()
    # SLSQP from perturbed starts
    for attempt in range(3):
        if time.time() > p1:
            break
        hp = project_feasible(best_h + 0.05 * rng.randn(n), n)
        hp = slsqp_smooth(hp, n, 50000, 800, 1e-14)
        c = compute_c5(hp, n)
        if c < best_c:
            best_c = c
            best_h = hp.copy()

    # Phase 2: Binary SA with diverse starts
    p2 = t0 + 0.62 * (budget_s - 8)
    starts = [
        round_to_binary(best_h, n),
        thue_morse_binary(n, seed + 1),
        golden_binary(n, offset=0.3, seed=2),
        round_to_binary(best_h + 0.15 * rng.randn(n), n),
        thue_morse_binary(n, seed + 7),
    ]
    sa_seeds = [seed + 10, seed + 20, seed + 30, seed + 40, seed + 50]
    for k in range(len(starts)):
        if time.time() > p2:
            break
        end_t = p2 if k < len(starts) - 1 else p2
        # Give more time to earlier starts
        frac = (k + 1) / len(starts)
        end_k = t0 + (p2 - t0) * frac
        hb, cb = sa_binary(starts[k], n, min(end_k, dl), seed=sa_seeds[k],
                           t_start=0.015, t_end=0.000005, patience=50000)
        if cb < best_c:
            best_c = cb
            best_h = hb.copy()

    # Phase 3: Coord polish on best continuous
    p3 = t0 + 0.78 * (budget_s - 8)
    if time.time() < p3 - 5:
        hc, cc = coord_polish(best_h.copy(), n, p3)
        if cc < best_c:
            best_c = cc
            best_h = hc.copy()

    # Phase 4: SLSQP from best (possibly binary) solution
    p4 = t0 + 0.88 * (budget_s - 8)
    if time.time() < p4 - 15:
        hp = project_feasible(best_h + 0.02 * rng.randn(n), n)
        for alpha in [100000, 500000, 2000000]:
            if time.time() > p4:
                break
            hp = slsqp_smooth(hp, n, alpha, 1000, 1e-15)
            c = compute_c5(hp, n)
            if c < best_c:
                best_c = c
                best_h = hp.copy()

    # Phase 5: Final polish
    if time.time() < dl - 5:
        hc, cc = coord_polish(best_h.copy(), n, dl - 3)
        if cc < best_c:
            best_c = cc
            best_h = hc.copy()

    best_h = project_feasible(best_h, n)
    best_c = compute_c5(best_h, n)
    return best_h, best_c, n
