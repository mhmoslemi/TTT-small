When we swap positions i (0→1) and j (1→0):

- The new g[p] = corr_after_flipping_p_in_new_state - corr_new

The "flip p in new state" means: take h_new (which differs from h_old at positions i and j), then flip position p.

If p ≠ i and p ≠ j:

  In the new state, h_new[i]=1, h_new[j]=0.
  The new g[p,k] = (1-h_new[p-k])*s_p' - h_new[p+k]*s_p' where s_p' is based on h_new[p].
  
  If p ≠ i,j: s_p' = s_p (unchanged). But h_new[p-k] might differ from h_old[p-k] if p-k ∈ {i,j}.
  Similarly for h_new[p+k].
  
  So the correction to g[p,k] is:
  - If p-k = i: (1-h_new[i]) - (1-h_old[i]) = (1-1) - (1-0) = -1, so g changes by -s_p
  - If p-k = j: (1-h_new[j]) - (1-h_old[j]) = (1-0) - (1-1) = +1, so g changes by +s_p
  - If p+k = i: -(h_new[i] - h_old[i]) = -(1-0) = -1, so g changes by -s_p

Let me also think about the continuous relaxation more carefully. The continuous problem:
min max_k corr_k(h) subject to 0≤h≤1, Σh = n/2

This is a min-max problem with bilinear terms. It's non-convex, but we can use:
- Log-sum-exp smoothing
- Alternating direction methods
- Subgradient methods

For the log-sum-exp approach:
f_α(h) = (1/α) log Σ_k exp(α * corr_k(h))

This is a smooth upper bound on max_k corr_k(h), and as α→∞ it converges to the max.

The gradient of f_α with respect to h[p] can be computed:
∂f_α/∂h[p] = Σ_k w_k * ∂corr_k/∂h[p]

where w_k = exp(α*corr_k) / Σ_j exp(α*corr_j) (softmax weights).

And ∂corr_k/∂h[p]:
corr_k = Σ_i h[i+k](1-h[i])
∂corr_k/∂h[p] = (1-h[p-k]) if p appears as i+k (i.e., i=p-k)
              + h[p+k]*(-1) if p appears as i (i.e., i=p)
              = (1-h[p-k]) - h[p+k] (with appropriate boundary conditions)

This is exactly g[p, k]! So the gradient is:
∇f_α(h)[p] = Σ_k w_k * g[p, k]

where g is computed with the current continuous h (not just binary).

This means we can use gradient descent (or L-BFGS) on the smooth approximation!

g[p, m] where m corresponds to lag = m-(n-1):
g[p, m] = (1-x[p-lag]) if 0≤p-lag<n else 0, minus x[p+lag] if 0≤p+lag<n else 0

So:
grad[p] = Σ_m weights[m] * g[p,m]
         = Σ_m weights[m] * (1-x[p-(m-(n-1))]) * 1[0≤p-(m-(n-1))<n]
           - Σ_m weights[m] * x[p+(m-(n-1))] * 1[0≤p+(m-(n-1))<n]

Let w[lag] = weights[lag+n-1] for lag = -(n-1), ..., (n-1)

First term: Σ_{lag} w[lag] * (1-x[p-lag]) for valid p-lag
= Σ_{lag} w[lag] - Σ_{lag} w[lag]*x[p-lag] (for valid)
= W - A[p] where W = Σ w[lag] = 1 (since weights are probabilities)
and A[p] = Σ_{lag} w[lag]*x[p-lag] = (x * w_flip)[p] where w_flip[i] = w[-i]

Second term: B[p] = Σ_{lag} w[lag]*x[p+lag] = (w * x)[p]

So grad[p] = 1 - A[p] - B[p]

where A = correlate(x, w_flip) and B = correlate(w, x) in appropriate modes.

Actually, let me use numpy's correlate directly:
- A[p] = Σ_i x[i] * w[p-i] where w is defined on a grid of size 2n-1 centered at 0
- This is the cross-correlation of x and w

w_vec[m] = weights[m] for m=0,...,2n-2

A[p] = Σ_j x[j] * weights[p-j+n-1] (for valid indices)

This is the cross-correlation of x and weights (with appropriate alignment).

    # Phase 6: Final SA polish (10%)
    if time.time() < dl - 3:
        hb, cb = sa_with_pairs(best_h, n, dl, seed + 500, top_k=35)
        if cb < best_c:
            best_c = cb
            best_h = hb
    best_c = compute_c5(best_h, n)
    return best_h, best_c, n
