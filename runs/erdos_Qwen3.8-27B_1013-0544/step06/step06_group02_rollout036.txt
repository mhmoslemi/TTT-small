def compute_c5(h, n):

    return float(np.max(np.correlate(h, 1 - h, mode='full')) * dx)

def compute_all_lags(h, n):
    return np.correlate(h, 1 - h, mode='full') * (2.0 / n)

def compute_lag_gradient(c_lags, h, n, k):

    dx = 2.0 / n
    grad = np.zeros(n)
    if k >= 0:
        nv = n - k
        grad[0:nv] += (1.0 - h[k:n])
        grad[k:n] += (-h[0:nv])
    else:
        kk = -k
        nv = n - kk
        grad[kk:n] += (1.0 - h[0:nv])
        grad[0:nv] += (-h[kk:n])

        else:

            if tot < 1e-15:

            h += (diff / tot) * h

Wait, the constraint set is {h : 0 ≤ h ≤ 1, sum(h) = n/2}, which is a polytope (the intersection of a hypercube with a hyperplane). The Frank-Wolfe algorithm would work here:

1. At current h, compute the subgradient g of the objective
2. Solve the linear minimization: min_{y ∈ feasible} g · y
3. Take a step: h_new = (1-t)h + t*y where t is chosen by line search

The linear minimization over the polytope {h : 0 ≤ h ≤ 1, sum(h) = n/2} is:
- Sort g in descending order
- The optimal y has y[i] = 1 for the top n/4 indices, y[i] = 0 for the bottom 3n/4 indices, and y[i] = some value in [0,1] for one index (to make the sum exactly n/2)

Wait, sum(h) = n/2 means the average is 0.5. So we need exactly n/2 units of mass distributed among n coordinates, each in [0,1].

The linear minimization min g·y subject to 0 ≤ y ≤ 1, sum(y) = n/2:
- Sort g: g[π(1)] ≤ g[π(2)] ≤ ... ≤ g[π(n)]
- Set y[π(1)] = y[π(2)] = ... = y[π(n/2)] = 1 (the n/2 smallest g values get y=1)
- Set y[π(n/2+1)] = ... = y[π(n)] = 0
- This gives sum = n/2 exactly (if n is even)

Wait, that gives sum = n/2 * 1 = n/2. Yes! So the vertex is: y[i] = 1 if g[i] is among the n/2 smallest, else y[i] = 0.

This is a binary step function! The Frank-Wolfe algorithm would converge to a solution that's a convex combination of such binary step functions.

This is interesting! The Frank-Wolfe algorithm would naturally produce solutions that are mixtures of "threshold" functions. This is different from the smooth gradient approach.
