def fast_swap_eval(h, corr, i, j, n):

    # i goes 0->1, j goes 1->0
    # For each lag d, compute delta
    # delta[d] = (1-h[i-d]) - h[i+d] - (1-h[j-d]) + h[j+d]
    # where terms with out-of-bounds indices are 0
    # 
    # In terms of correlation index k = n-1+d:
    # delta[k] = (1-h[i-(k-(n-1))]) - h[i+(k-(n-1))] - (1-h[j-(k-(n-1))]) + h[j+(k-(n-1))]

    # For lag d = k-(n-1):
    # term1 = 1-h[a-d] if 0<=a-d<n else 0
    # term2 = h[a+d] if 0<=a+d<n else 0
    # term3 = 1-h[b-d] if 0<=b-d<n else 0

    # Actually, let me just compute it directly:
    d = np.arange(2*n-1) - (n-1)
    idx_a_minus = i - d  # indices for term1
    idx_a_plus = i + d   # indices for term2
    idx_b_minus = j - d  # indices for term3
    idx_b_plus = j + d   # indices for term4
    
    def safe_idx(idx, arr):
        """Get arr[idx] where valid, 0 elsewhere"""
        mask = (idx >= 0) & (idx < len(arr))
        result = np.zeros(len(idx))
        result[mask] = arr[idx[mask]]
        return result
    
    term1 = safe_idx(idx_a_minus, 1.0 - h)  # (1-h[i-d]) where valid
    term2 = safe_idx(idx_a_plus, h)          # h[i+d] where valid
    term3 = safe_idx(idx_b_minus, 1.0 - h)   # (1-h[j-d]) where valid
    term4 = safe_idx(idx_b_plus, h)          # h[j+d] where valid
    
    delta = term1 - term2 - term3 + term4

def fast_swap_delta(h, i, j, n):
    """Compute new_corr - old_corr when h[i] flips and h[j] flips.
    Assumes h[i]=1, h[j]=0 (swap to h[i]=0, h[j]=1)."""
    delta = np.zeros(2*n-1)
    new_h_i = 0.0  # h[i] goes 1->0
    new_h_j = 1.0  # h[j] goes 0->1
    old_h_i = 1.0
    old_h_j = 0.0
    
    for k in range(2*n-1):
        d = k - (n-1)
        # Affected m values: i-d, i, j-d, j
        total_delta = 0.0
        for m in [i-d, i, j-d, j]:
            if 0 <= m < n and 0 <= m+d < n:
                # Compute new term - old term
                # new: h'[m+d] * (1-h'[m])
                # old: h[m+d] * (1-h[m])
                a = m + d  # first index
                b = m      # second index
                # Get old values
                old_a = h[a]
                old_b = h[b]
                # Get new values
                new_a = old_a if a != i and a != j else (new_h_i if a == i else new_h_j)
                new_b = old_b if b != i and b != j else (new_h_i if b == i else new_h_j)
                total_delta += new_a * (1 - new_b) - old_a * (1 - old_b)
        delta[k] = total_delta
    return delta

Now, the question is: how to improve the continuous optimization?

The SLSQP approach uses a smooth max approximation:
f(h) = m + (1/α) * log(Σ exp(α*(g_k - m)))

where m = max(g_k) and g_k = c_k * dx.

As α → ∞, this approaches the true max. For finite α, it's a smooth approximation that SLSQP can handle.

The issue is that SLSQP might not converge well for large n (250 variables) with a non-convex objective. 

Alternative: use **projected gradient descent** or **L-BFGS-B** with the smooth max objective.

Or: use a **iterative reweighting** approach where we:
1. Find the current critical lags (those at or near the max)
2. Do a local linear optimization that specifically reduces those lags
3. Repeat

This is like the "cutting plane" method or "subgradient" method for minimax problems.

For the minimax problem:
minimize max_k g_k(h)
subject to 0 ≤ h ≤ 1, sum(h) = n/2

The subgradient of max_k g_k at h is the uniform distribution over the active set (lags where g_k = max). So the subgradient method would be:
h ← P(h - t * (1/|A|) * Σ_{k∈A} ∇g_k)

where P is projection onto the constraint set, t is the step size, and A is the active set.

The gradient of g_k = c(k) * dx = (Σ_m h[m+k]*(1-h[m])) * dx with respect to h:
∂g_k/∂h[i] = dx * [Σ_m (∂h[m+k]/∂h[i])*(1-h[m]) + h[m+k]*(∂(1-h[m])/∂h[i])]
= dx * [(1-h[i-k]) - h[i+k]] (with boundary conditions)

where the first term is from m+k=i (i.e., m=i-k) and the second is from m=i (i.e., m+k=i+k).

So ∂g_k/∂h[i] = dx * [(1-h[i-k])_valid - h[i+k]_valid]

This is a bilinear gradient (depends on h itself), which makes the problem non-convex.

For the active set approach:
1. Compute g_k for all k
2. Find active set A = {k : g_k ≥ max - ε}
3. Compute the average gradient over A: ∇f = (1/|A|) Σ_{k∈A} ∇g_k
4. Take a step in the -∇f direction
5. Project onto the constraint set
6. Repeat

This is essentially a subgradient method for the minimax problem. It's simple but can be slow to converge. To speed it up, we can:
- Use a decreasing step size: t_k = c/sqrt(k)
- Use a "mirror descent" variant with the KL divergence
- Use a "proximal" variant
