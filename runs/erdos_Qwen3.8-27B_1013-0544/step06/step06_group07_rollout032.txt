Now I can compute the gradient efficiently:

```python
def softmax_obj_grad(x, n, alpha):
    dx = 2.0 / n
    c = np.correlate(x, 1 - x, mode='full')
    c_max = c.max()
    sh = alpha * (c - c_max)
    max_sh = sh.max()
    p = np.exp(sh - max_sh)
    p_sum = p.sum()
    S = c_max + (max_sh + np.log(p_sum)) / alpha
    val = dx * S
    
    w = p / p_sum
    one_minus_x = 1 - x
    corr_res = np.correlate(one_minus_x, w, mode='full')
    term1 = corr_res[n-1 : 2*n-1]
    grad = dx * (term1 - x * w[n-1])
    
    return val, grad
```

This is O(n) for the correlation + O(n log n) for nothing (numpy's correlate is O(n^2) for small n but uses optimized BLAS). For n=250, this is very fast.
