- i2 (1→0) as second factor: +h[i2-k] for valid k
- j1 (0→1) as first factor: +(1-h[j1+k]) for valid k
- j1 (0→1) as second factor: -h[j1-k] for valid k
- j2 (0→1) as first factor: +(1-h[j2+k]) for valid k
- j2 (0→1) as second factor: -h[j2-k] for valid k

But wait, there are interactions: if i1+k = j1 or i1+k = j2, then the value of h at that position has changed. Similarly for other combinations.

This makes double swap evaluation more complex. For simplicity, let me just compute the new correlation directly when I try a double swap (it's O(n²) = O(62500) which is fine for a few hundred trials).
