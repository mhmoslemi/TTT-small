    cur_max = float(corr.max())
    best_max = cur_max
    best_h = h.copy()
    rng = np.random.RandomState(seed)
    
    while time.time() < deadline:
        improved = False
        zeros = np.where(h == 0)[0]
        ones = np.where(h == 1)[0]
        rng.shuffle(zeros)
        rng.shuffle(ones)
        
        # Precompute for each possible a (zero position)
        for a in zeros:
            if time.time() > deadline:
                break
            # Compute P_a + S_a (the a-dependent part of delta)
            s_all = np.arange(-(n-1), n)  # all possible shifts
            # P: 1-h[a+s] for valid a+s
            a_idx = a + s_all
            P = np.zeros(2*n-1)
            vP = (a_idx >= 0) & (a_idx < n)
            P[vP] = 1 - h[a_idx[vP]]
            # S: -h[a-s] for valid a-s
            a_idx2 = a - s_all
            S = np.zeros(2*n-1)
            vS = (a_idx2 >= 0) & (a_idx2 < n)
            S[vS] = -h[a_idx2[vS]]
            base_a = P + S
            
            for b in ones:
                if time.time() > deadline:
                    break
                # Q + R for this b
                b_idx = b + s_all
                Q = np.zeros(2*n-1)
                vQ = (b_idx >= 0) & (b_idx < n)
                Q[vQ] = -(1 - h[b_idx[vQ]])
                b_idx2 = b - s_all
                R = np.zeros(2*n-1)
                vR = (b_idx2 >= 0) & (b_idx2 < n)
                R[vR] = h[b_idx2[vR]]
                
                delta = base_a + Q + R
                # Cross term
                m0 = n - 1  # s=0
                delta[m0] -= 2
                m1 = n - 1 + (b - a)
                if 0 <= m1 < 2*n-1:
                    delta[m1] += 1
                m2 = n - 1 + (a - b)
                if 0 <= m2 < 2*n-1:
                    delta[m2] += 1
                
                new_corr = corr + delta
                new_max = float(new_corr.max())
                if new_max < cur_max:
                    h[a], h[b] = 1.0, 0.0
                    corr = new_corr
                    cur_max = new_max
                    if cur_max < best_max:

                        best_h = h.copy()
                    improved = True
                    break
        
        if not improved:
            break

But wait, I'm recomputing Q and R for each (a,b) pair. Let me precompute them for all b at once.

Actually, Q_b and R_b depend on b, so I can precompute them for all b:
- Q_b[m] = -(1-h[b+s]) where s = m-(n-1), so b+s = m-(n-1)+b. This is a shifted version of -(1-h).
- R_b[m] = h[b-s] = h[b-(m-(n-1))] = h[n-1+b-m]. This is a reversed and shifted version of h.

So Q_b is just -(1-h) shifted by b positions (in the correlation array), and R_b is h reversed and shifted.

Let me precompute: for each b in ones, compute Q_b + R_b. This is a (n/2) x (2n-1) matrix. For n=250, that's 125 * 499 = 62375 elements. Manageable.

Then for each (a,b) pair: delta = base_a + precomputed[b] + cross_{a,b}.
And max(corr + delta) = max(corr + base_a + precomputed[b] + cross_{a,b}).

The cross term only modifies 3 positions, so I can compute max(corr + base_a + precomputed[b]) first, and then check if the cross term changes the max at those 3 positions.

For the continuous case, I'll use the following approach:
1. Start from the best binary solution
2. Use L-BFGS-B to minimize a smooth approximation of max(corr)
3. The smooth approximation: f(h) = log(sum(exp(alpha * corr))) / alpha (log-sum-exp)
4. After optimization, check if the solution is still near-binary
5. If not, project back to binary and re-run

The key parameters are:
- alpha: controls the sharpness of the approximation (larger = closer to max)
- maxiter: number of L-BFGS-B iterations
- The constraint sum(h) = n/2 needs to be enforced
