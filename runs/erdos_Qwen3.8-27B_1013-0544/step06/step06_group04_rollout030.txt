**Key insight**: This problem is related to the construction of sequences with low autocorrelation (sidelobe constraints). Specifically, we want a binary sequence with flat autocorrelation sidelobes.

The periodic autocorrelation of a binary sequence is studied extensively in coding theory. The problem here is similar but with aperiodic correlation (due to the 'full' mode).

**Sidelobe optimization**: There are known algorithms for binary sequence design with low sidelobes:
- Baum-Seeling algorithm
- GOPPSA (Genetic algorithm)
- Greedy algorithms

But our problem is slightly different: we're minimizing the cross-correlation between h and 1-h, not the autocorrelation of h. However, they're related:

c = correlate(h, 1-h) = correlate(h, 1) - correlate(h, h) = (sum of h at valid positions) - autocorr(h)

So minimizing max(c) is approximately maximizing min(autocorr(h)) (away from lag 0), which is the opposite of the usual sidelobe minimization!

Wait, that's interesting. Usually we want to MINIMIZE sidelobes of autocorrelation. Here we want to MAXIMIZE the minimum sidelobe (to make the cross-correlation small). This is a different problem.

The "partial sum of h" depends on k (due to boundary effects), while the "partial autocorrelation" is the standard thing.

For k near n-1 (lag near 0), the partial sum is close to n/2 (the total), and the autocorrelation at lag 0 is |S| = n/2, so c ≈ 0. ✓

For k near 0 or 2n-2 (large lag), the partial sum is small (only a few terms), and the autocorrelation is also small.

The interesting lags are in the middle region.

```python
def peak_focused_search(h, n, deadline, seed=42):
    h = binarize(h, n).astype(float)
    dx = 2.0 / n
    corr = np.correlate(h, 1-h, mode='full').astype(float).copy()
    cur_max = corr.max()
    best_max = cur_max
    best_h = h.copy()
    rng = np.random.RandomState(seed)
    
    while time.time() < deadline:
        peak_idx = np.argmax(corr)
        d = int(peak_idx) - (n-1)
        
        if d == 0:
            # Shouldn't happen for binary, but handle it
            break
        
        # Compute delta_p for all positions p (change when h[p] goes 0->1)
        delta_p = np.zeros(n)
        pd = np.arange(n) + d
        pd_valid = (pd >= 0) & (pd < n)
        delta_p[pd_valid] += (1 - h[pd[pd_valid]])
        pmd = np.arange(n) - d
        pmd_valid = (pmd >= 0) & (pmd < n)
        delta_p[pmd_valid] -= h[pmd[pmd_valid]]
        
        zeros = np.where(h == 0)[0]
        ones = np.where(h == 1)[0]
        
        if len(zeros) == 0 or len(ones) == 0:
            break
        
        # We want to swap i (zero) with j (one) to reduce peak
        # Change at peak = delta_p[i] - delta_p[j]
        # Want this negative: delta_p[i] < delta_p[j]
        
        z_deltas = delta_p[zeros]
        o_deltas = delta_p[ones]
        
        # Sort zeros by delta (ascending) and ones by delta (descending)
        z_order = np.argsort(z_deltas)
        o_order = np.argsort(o_deltas)[::-1]
        
        improved = False
        for zi in z_order[:10]:
            i = zeros[zi]
            for oj in o_order[:10]:
                j = ones[oj]
                if i == j: continue
                # Compute full delta
                # Change at peak: delta_p[i] - delta_p[j]
                peak_change = delta_p[i] - delta_p[j]
                if peak_change >= 0: continue
                
                # Full delta computation
                full_delta = np.zeros(2*n-1)
                for d2 in range(-n+1, n):
                    if d2 == 0: continue
                    c_i = 0
                    if 0 <= i+d2 < n: c_i += (1-h[i+d2])
                    if 0 <= i-d2 < n: c_i -= h[i-d2]
                    c_j = 0
                    if 0 <= j+d2 < n: c_j -= (1-h[j+d2])
                    if 0 <= j-d2 < n: c_j += h[j-d2]
                    if c_i + c_j != 0:
                        full_delta[n-1+d2] = c_i + c_j
                
                new_corr = corr + full_delta
                new_max = new_corr.max()
                if new_max < cur_max:
                    h[i], h[j] = 1.0, 0.0
                    corr = new_corr
                    cur_max = new_max
                    best_max = cur_max
                    best_h = h.copy()
                    improved = True
                    break
            if improved: break
        
        if not improved:
            # Try steepest descent: just do the swap that most reduces peak
            # even if it might increase max elsewhere (hope it doesn't)
            best_oi = None
            best_change = 0
            for zi in z_order[:50]:
                i = zeros[zi]
                for oj in o_order[:50]:
                    j = ones[oj]
                    if i == j: continue
                    chg = delta_p[i] - delta_p[j]
                    if chg < best_change:
                        best_change = chg
                        best_oi = (i, j)
            
            if best_oi is not None and best_change < -2:
                i, j = best_oi
                # Apply and see
                full_delta = np.zeros(2*n-1)
                for d2 in range(-n+1, n):
                    if d2 == 0: continue
                    c_i = 0
                    if 0 <= i+d2 < n: c_i += (1-h[i+d2])
                    if 0 <= i-d2 < n: c_i -= h[i-d2]
                    c_j = 0
                    if 0 <= j+d2 < n: c_j -= (1-h[j+d2])
                    if 0 <= j-d2 < n: c_j += h[j-d2]
                    if c_i + c_j != 0:
                        full_delta[n-1+d2] = c_i + c_j
                new_corr = corr + full_delta
                if new_corr.max() <= cur_max + 1:  # allow slight increase
                    h[i], h[j] = 1.0, 0.0
                    corr = new_corr
                    cur_max = new_corr.max()
    
    return best_h, best_max * dx
```
