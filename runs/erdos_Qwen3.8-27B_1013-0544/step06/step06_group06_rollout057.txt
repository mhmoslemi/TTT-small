Actually, let me think more carefully. The key challenge is that the objective is the max of many linear functions (each correlation value). The soft-max approximation is:

f_α(h) = (1/α) log(Σ_k exp(α * c_k))

where c_k = correlation at lag k.

The gradient with respect to h[i] can be computed analytically.

For the correlation: c_k = Σ_p h[p] * (1-h[p+k]) (with appropriate bounds)

∂c_k/∂h[i] = (1-h[i+k]) - h[i-k] (with appropriate bounds)

So the gradient of f_α is:
∂f_α/∂h[i] = Σ_k (exp(α*c_k)/Σ_j exp(α*c_j)) * ∂c_k/∂h[i]

This gives us a smooth approximation whose gradient we can compute efficiently using FFT or direct computation.

Let me implement a projected gradient method with this soft-max loss:

1. Compute correlations c = correlate(h, 1-h)
2. Compute softmax weights w_k = exp(α*c_k) / Σ exp(α*c_j)
3. Compute gradient: grad[i] = Σ_k w_k * ∂c_k/∂h[i]
4. Update: h_new = h - lr * grad
5. Project h_new onto {0 ≤ h ≤ 1, sum(h) = n/2}

The projection onto the constraint set can be done with bisection on the Lagrange multiplier.

For the projection: minimize Σ (h_i - x_i)² subject to 0 ≤ h_i ≤ 1 and Σ h_i = n/2.
This is solved by h_i = clamp(x_i - λ, 0, 1) where λ is chosen so that Σ h_i = n/2.

This is a nice approach because:
- It's different from the previous greedy swap method

def thue_morse(n, seed=0):
    """Generate Thue-Morse-like binary sequence of length n."""
    rng = np.random.RandomState(seed)
    t = np.zeros(n, dtype=int)
    for i in range(1, n):
        t[i] = t[i >> 1] ^ (i & 1)
    target = n // 2
    num_ones = int(t.sum())
    if num_ones > target:
        ones_idx = np.where(t == 1)[0]
        rng.shuffle(ones_idx)
        t[ones_idx[:num_ones - target]] = 0
    elif num_ones < target:
        zeros_idx = np.where(t == 0)[0]
        rng.shuffle(zeros_idx)
        t[zeros_idx[:target - num_ones]] = 1
    return t.astype(float)

    elif num_ones < target:
        zi = np.where(t == 0)[0]
        rng.shuffle(zi)
        t[zi[:target - num_ones]] = 1
