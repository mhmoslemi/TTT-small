swap_delta involves:
- delta[i+m] += 1-h[i+m] for valid m (this is the same for all j pairs with the same i)
- delta[i-m] -= h[i-m] for valid m (same for all j)
- delta[j+m] -= 1-h[j+m] for valid m (same for all i pairs with the same j)
- delta[j-m] += h[j-m] for valid m (same for all i)
- delta[n-1] -= 2
- delta[n-1+j-i] += 1
- delta[n-1+i-j] += 1

The first four terms can be precomputed for each i and j separately:
- A[i] = contribution from changing h[i]: 0→1
- B[j] = contribution from changing h[j]: 1→0

Then delta[i,j] = A[i] + B[j] + cross_terms(i,j)

Where cross_terms are the last three terms (the -2 at n-1, and the +1 at n-1±(j-i)).

A[i] can be precomputed as a vector of length 2n-1 for each i. Similarly B[j].

Then for all pairs, delta[i,j] = A[i] + B[j] + cross(i,j).

The max of delta[i,j] over all (i,j) pairs is what we want to minimize.

But computing the max over all 15625 pairs for a vector of length 499 is 15625*499 ≈ 7.8 million operations. In numpy, this could be done as a 3D array of shape (125, 125, 499), which is 125*125*499 ≈ 7.8M floats ≈ 62MB. That's feasible!
