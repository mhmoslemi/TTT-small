Let me try yet another approach: **alternating projection**.

1. Start with binary h
2. For each step:

sum_k p_k * x[i-k] is the cross-correlation of p and x at position i.

- sum_k p_k * x[i-k] = (p ⋆ x)[i] (correlation)

We can compute both using np.convolve or np.correlate, which are O(n log n) with FFT.

Let me implement a "best improvement" greedy:
1. For each zero i:
   a. Compute the effect of setting h[i]=1 (keeping sum as is by not changing anything yet)
   b. For each one j: compute the additional effect of setting h[j]=0
   c. If the combined effect improves C5, do the swap

This is O(n² * n) = O(n³) per sweep. For n=250, that's ~15M operations per sweep, which should take < 1 second with NumPy.

Actually, we can be smarter. The effect of a swap (i,j) on the correlation is:
delta[idx] = effect of h[i]: 0→1 + effect of h[j]: 1→0

The effect of h[i]: 0→1 on corr[idx] depends only on i and the current h (not on j).
Similarly, the effect of h[j]: 1→0 depends only on j and h.

So we can precompute:
- effect_plus[i][idx] = effect of h[i] going 0→1 on corr[idx] (for each i that is currently 0)
- effect_minus[j][idx] = effect of h[j] going 1→0 on corr[idx] (for each j that is currently 1)

Then delta for swap (i,j) = effect_plus[i] + effect_minus[j].

Computing effect_plus[i] for all i is O(n²) (n zeros * O(n) each).
Then for each pair (i,j), we check if (corr + effect_plus[i] + effect_minus[j]).max() < cur_c.

This is still O(n³) total but with a smaller constant.

For n=250: 125 zeros * 125 ones * 499 (correlation length) = 7.8M operations. Very fast!

    dx = 2.0 / n
    h = h.copy()
    corr = np.correlate(h, 1-h, mode='full').astype(float)
    cur_c = corr.max() * dx
    best_c = cur_c
    best_h = h.copy()
    
    for sweep in range(max_sweeps):
        improved = False
        zeros = np.where(h == 0)[0]
        ones = np.where(h == 1)[0]
        
        # Precompute effects
        # effect_plus[i]: change in corr when h[i] goes 0→1
        # For lag m = idx-(n-1):
        #   First factor: (1-h[i-m]) if 0≤i-m<n
        #   Second factor: -h[i+m] if 0≤i+m<n
        mags = np.arange(2*n-1) - (n-1)  # lags
        
        for i in zeros:
            # effect of h[i] 0→1
            ep = np.zeros(2*n-1)
            # first factor: n=m... wait, let me use the formula:
            # For lag k: contribution = (1-h[i-k])*valid(i,k) - h[i+k]*valid(i,k)
            # where valid means the index is in [0,n)
            fk = i - mags  # i-k, the index for (1-h[...])
            sk = i + mags  # i+k, the index for h[...]
            vm_f = (fk >= 0) & (fk < n)  # valid for first factor
            vm_s = (sk >= 0) & (sk < n)  # valid for second factor
            ep[vm_f] += (1 - h[fk[vm_f]])
            ep[vm_s] -= h[sk[vm_s]]

                # Second factor: +h[j+k] if valid
