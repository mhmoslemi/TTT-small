where i ranges over valid indices. With n_a = n_b = n:
c_full[k] = sum_i a[i] * b[i - k + n - 1]

For this to be nonzero, we need 0 ≤ i < n and 0 ≤ i - k + n - 1 < n.
The second condition: k - n + 1 ≤ i ≤ k.
Combined: max(0, k-n+1) ≤ i ≤ min(n-1, k).

So c_full[k] = sum_{i=max(0,k-n+1)}^{min(n-1,k)} h[i] * (1-h[i-k+n-1])

Let j = i - k + n - 1 (so i = j + k - n + 1):

I'll define the correlation as:
For shift s (where s ranges from -(n-1) to (n-1)):
corr[s] = sum_{x} h(x) * (1-h(x+s)) where the sum is over x such that both x and x+s are in [0, n-1].

In the full correlation array, index k = s + (n-1), so k ranges from 0 to 2n-2.

corr[s] = sum_x h(x) * (1-h(x+s)) for x, x+s ∈ [0, n-1]

When h[p] changes by δ:
- h(x) = h(p) contributes when x = p: term is h(p)*(1-h(p+s)) → h(p)*1 = (hp+δ)*(1-h(p+s)). Change: δ*(1-h(p+s)).
  Valid when p+s ∈ [0, n-1].
- h(x+s) = h(p) contributes when x+s = p, i.e., x = p-s: term is h(p-s)*(1-h(p)) → h(p-s)*(1-hp-δ). Change: -δ*h(p-s).
  Valid when p-s ∈ [0, n-1] (and x = p-s is in [0,n-1], same condition).

(hp+δ)(1-hp-δ) - hp(1-hp) = hp - hp² + δ - 2hpδ - δ² - hp + hp² + ...

Great, the formula is verified. Now I can implement efficient coordinate descent.

For each coordinate p:
1. Compute w_p[k] for k = 0, ..., 2n-2:
   s = k - (n-1)
   w_p[k] = (1 - h[p+s]) * I(0 ≤ p+s < n) - h[p-s] * I(0 ≤ p-s < n)
   
   Note: for s=0, this gives (1-h[p]) - h[p] = 1-2h[p], and we subtract δ² separately.

2. The objective for h[p] = t (with δ = t - hp):
   f(t) = max( c[k] + δ*w_p[k] for k≠n-1,  c[n-1] + δ*(1-2hp) - δ² )
   
   = max( max_{k≠n-1} (c[k] + δ*w_p[k]),  c[n-1] + δ*(1-2hp) - δ² )
   
   Let A = max_{k≠n-1} (c[k] + δ*w_p[k]) [max of linear functions of δ, i.e., convex in δ]
   Let B(δ) = c[n-1] + δ*(1-2hp) - δ² [concave quadratic in δ]
   
   f(δ) = max(A(δ), B(δ)) * dx, where δ ∈ [-hp, 1-hp]

3. To minimize f(δ) on [-hp, 1-hp]:
   - A(δ) is convex piecewise linear (max of linear functions)
   - B(δ) is concave
   - f = max(A, B)
   - Minimum can only be at: min of A where A≥B, or at crossing points A=B, or at boundaries.

For a practical approach, I'll use a grid of ~30 points + golden section refinement (even though f isn't unimodal, in practice it's close to unimodal for small perturbations from the current value).

Actually, let me think about this differently. The current value hp is already a local minimum (or close to it). The optimal t is likely close to hp. So I can use a small range and a fine grid.

Let me use: grid from max(0, hp-0.1) to min(1, hp+0.1) with 30 points, then refine the best with golden section (10 iterations).

Per coordinate: 30 + 10 = 40 evaluations of f(δ), each O(n) (just taking max of a vector of length 2n-1).
Per pass: n * 40 * O(n) = 40n² = 40 * 90000 = 3.6M operations.

- max over axis=1 (shape: 30,)

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h.copy(), 0.0, 1.0)
