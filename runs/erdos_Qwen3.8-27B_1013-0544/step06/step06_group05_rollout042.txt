Where Δc_from_flip_i[k] = 1 - h[i-k] - h[i+k] (but h[i] was 0, so h[i-k] and h[i+k] are current values)

2. Compute c = correlate(h, 1-h, 'full')
3. Find the current max M and the critical lags.
4. For each pair (i, j) with h[i]=0, h[j]=1:

   b. Compute new max

5. Repeat until no improvement or time runs out.

Actually, let me use a different approach. Instead of trying all swaps, use the coordinate descent idea but in a way that maintains feasibility:

**Offset-based coordinate descent:**
- Think of h as a binary vector with exactly n/2 ones.
- A "move" is: pick position i (currently 0) and position j (currently 1), swap them.
- The change in objective depends on both i and j.
- Use a greedy approach: for each i with h[i]=0, find the j with h[j]=1 that most improves the objective.

For a fixed i (h[i]=0), the change in c[k] from setting h[i]=1 (ignoring the need to set some j to 0) is:
Δc_i[k] = 1 - h[i-k] - h[i+k] (out-of-bounds = 0)

Then we need to subtract the change from setting h[j]=1 back to 0:
Δc_j[k] = h[j-k] + h[j+k] - 1

Total: Δc[k] = (1 - h[i-k] - h[i+k]) + (h[j-k] + h[j+k] - 1) = h[j-k] + h[j+k] - h[i-k] - h[i+k]

(Simplification: the 1's cancel!)

So for a swap (i, j): Δc[k] = h[j-k] + h[j+k] - h[i-k] - h[i+k]

This is O(n) to compute for a given (i,j) pair.

The new objective is max_k (c[k] + Δc[k]).

For a fixed i, we want to find j that minimizes max_k (c[k] + h[j-k] + h[j+k] - h[i-k] - h[i+k]).

Let d[k] = c[k] - h[i-k] - h[i+k] (the "base" after removing i's contribution)
Then we want to minimize max_k (d[k] + h[j-k] + h[j+k]).

This is still O(n²) for each i (try all j, compute max for each). Total O(n³) per sweep.

Let me also think about a continuous version. After finding a good binary solution, I can try to improve by allowing fractional values.

For the continuous case, the coordinate descent would be:
- For each position i, find h[i] ∈ [0,1] that minimizes max_k c_new[k]
- c_new[k] = c[k] + Δc[k](h[i]) where Δc is the change when h[i] changes

For continuous h[i] = t (was previously t_old):
- Change in c[k]: the terms involving h[i] change
- c[k] = ... + h[i+k]*(1-h[i]) + h[i]*(1-h[i-k]) + ...
- If h[i] changes from t_old to t:
  - Term m=i: h[i+k]*(1-t) - h[i+k]*(1-t_old) = -h[i+k]*(t - t_old)
  - Term m=i-k: t*(1-h[i-k]) - t_old*(1-h[i-k]) = (t-t_old)*(1-h[i-k])
  - Also: h[i] appeared in h[i+k] or h[i-k] for other terms? No, those are different positions.
  
  Wait, I also need to account for the fact that (1-h[i]) appears in term m=i:
  c[k] includes the term h[m+k]*(1-h[m]) for m=i, which is h[i+k]*(1-h[i]).
  If h[i] changes, this term changes.
  
  And h[i] itself appears as h[m+k] when m=i-k: the term is h[i]*(1-h[i-k]).

So the change in c[k] when h[i] goes from t_old to t:
Δc[k] = -h[i+k]*(t-t_old) + (t-t_old)*(1-h[i-k])
       = (t-t_old) * (1 - h[i+k] - h[i-k])

Where out-of-bounds values are 0.

So c_new[k] = c[k] + (t-t_old) * a_k where a_k = 1 - h[i+k] - h[i-k].

Interesting! So c_new[k] is LINEAR in t (for k≠0). For k=0:
c[0] = sum_j h[j]*(1-h[j])
The change from h[i] going t_old → t:
Δc[0] = t*(1-t) - t_old*(1-t_old) = (t-t_old) - (t²-t_old²) = (t-t_old)(1-t-t_old)

So c_new[0] = c[0] + (t-t_old)(1-t-t_old), which is quadratic (and concave) in t.

For the max over all k: max(max_{k≠0} (c[k] + (t-t_old)*a_k), c[0] + (t-t_old)(1-t-t_old))

The first part (k≠0) is max of linear functions = convex in t.
The second part (k=0) is concave in t.
The max of a convex and a concave function is not necessarily convex.

However, in practice, c[0] is usually small (it's sum h[i](1-h[i]) ≤ n/4) and the maximum is usually achieved at some nonzero lag. So we can approximately ignore k=0 and solve the 1D convex minimax.

For the 1D problem: minimize max_{k≠0} (c[k] + (t-t_old)*a_k) subject to t ∈ [0,1].

This is: minimize max_k (a_k * t + (c[k] - t_old * a_k)) = minimize max_k (a_k * t + b_k)

where b_k = c[k] - t_old * a_k.

The minimum of max of lines on [0,1] can be found by:
1. If all lines have the same slope, the answer is at a boundary.
2. Otherwise, find the breakpoints (intersections of adjacent lines in the upper envelope).

A practical approach: since n=250 (so ~498 lines), I'll just evaluate at a grid of points (e.g., 100 points in [0,1]) and pick the best. This is O(100 * 498) ≈ 50k per position, O(12.5M) per sweep. Fast enough.

        for i in range(n):
            if time.time() > deadline:
                break
            t_old = h[i]
            # a_k = 1 - h[i+k] - h[i-k]
            a = np.ones(2*n-1)
            for ki, k in enumerate(k_vals):
                k = int(k)
                if 0 <= i+k < n: a[ki] -= h[i+k]
                if 0 <= i-k < n: a[ki] -= h[i-k]

            # c_new[k] for k≠0: c[k] + (t-t_old)*a[k]
            # c_new[0]: c[0] + t*(1-t) - t_old*(1-t_old)
            
            best_t = t_old
            best_val = cur_max
            
            for t in grid:
                if abs(t - t_old) < 1e-12:
                    continue
                c_new = c + (t - t_old) * a
                # Fix k=0 (index n-1 in full correlation)
                c_new[n-1] = c[n-1] + t*(1-t) - t_old*(1-t_old)
                val = float(c_new.max())
                if val < best_val:
                    best_val = val
                    best_t = t
            
            if best_t != t_old:
                h[i] = best_t
                c = np.correlate(h, 1.0 - h, mode='full').astype(float)
                cur_max = float(c.max())
                improved = True
        
        if not improved:
            break

def project_feasible(h, n):
    h = np.clip(h, 0.0, 1.0)
    target = n / 2.0
    for _ in range(200):
        diff = target - h.sum()
        if abs(diff) < 1e-12:
            break
        if diff > 0:
            room = 1.0 - h
            s = room.sum()
            if s < 1e-14: break
            h += diff / s * room
        else:
            s = h.sum()
            if s < 1e-14: break
            h += diff / s * h
    return np.clip(h, 0.0, 1.0)

def binarize(h, n):
    """Convert to binary with exactly n/2 ones."""
    idx = np.argsort(h)[::-1]
    out = np.zeros(n)
    out[idx[:n//2]] = 1.0
    return out

def binary_swap_search(h, n, deadline, max_passes=300):

    nk = len(k_vals)
    c = np.correlate(h, 1.0 - h, mode='full').astype(float)
    cur_max = float(c.max())
    
    for _pass in range(max_passes):
        if time.time() > deadline:
            break
        improved = False
        
        # Build V: V[j, ki] = h[j-k] + h[j+k]
        V = np.zeros((n, nk))
        for ki in range(nk):
            k = int(k_vals[ki])
            lo, hi = max(0, k), min(n, n + k)
            if lo < hi:
                V[lo:hi, ki] += h[lo-k:hi-k]
            lo, hi = max(0, -k), min(n, n - k)
            if lo < hi:
                V[lo:hi, ki] += h[lo+k:hi+k]
        
        zeros = np.where(h == 0)[0]
        ones = np.where(h == 1)[0]

            if time.time() > deadline:
                break
            if h[i] != 0:
                continue
            base = c.copy()
            for ki in range(nk):
                k = int(k_vals[ki])
                if 0 <= i+k < n: base[ki] -= h[i+k]
                if 0 <= i-k < n: base[ki] -= h[i-k]
            
            if len(ones) == 0:
                break
            scores = (V[ones, :] + base[None, :]).max(axis=1)
            best_local = int(np.argmin(scores))

    k_vals = np.arange(-(n-1), n)
    nk = 2*n - 1
    c = np.correlate(h, 1.0 - h, mode='full').astype(float)
    cur_max = float(c.max())
    
    for _it in range(max_iters):
        if time.time() > deadline:
            break
        
        # Build V
        V = np.zeros((n, nk))
        for ki in range(nk):
            k = int(k_vals[ki])
            lo, hi = max(0, k), min(n, n + k)
            if lo < hi: V[lo:hi, ki] += h[lo-k:hi-k]
            lo, hi = max(0, -k), min(n, n - k)
            if lo < hi: V[lo:hi, ki] += h[lo+k:hi+k]
        
        zeros = np.where(h == 0)[0]
        ones = np.where(h == 1)[0]

        if nz == 0 or no == 0:

def compute_c5(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(c) * dx)

def project_feasible(h, n):
    h = np.clip(h, 0.0, 1.0)
    target = n / 2.0
    for _ in range(200):
        diff = target - h.sum()
        if abs(diff) < 1e-12:
            break
        if diff > 0:
            room = 1.0 - h
            s = room.sum()
            if s < 1e-14:
                break
            h += diff / s * room
        else:
            s = h.sum()
            if s < 1e-14:
                break
            h += diff / s * h
    return np.clip(h, 0.0, 1.0)

def binarize(h, n):
    idx = np.argsort(h)[::-1]
    out = np.zeros(n)
    out[idx[:n // 2]] = 1.0
    return out

def build_V(h, n, k_vals):
    nk = len(k_vals)
    V = np.zeros((n, nk))
    for ki in range(nk):
        k = int(k_vals[ki])
        lo, hi = max(0, k), min(n, n + k)
        if lo < hi:
            V[lo:hi, ki] += h[lo - k:hi - k]
        lo, hi = max(0, -k), min(n, n - k)
        if lo < hi:
            V[lo:hi, ki] += h[lo + k:hi + k]
    return V

def binary_swap_search(h, n, deadline, max_iters=500):
    k_vals = np.arange(-(n - 1), n)
    nk = 2 * n - 1
    c = np.correlate(h, 1.0 - h, mode='full').astype(float)
    cur_max = float(c.max())
    for _ in range(max_iters):
        if time.time() > deadline:
            break
        V = build_V(h, n, k_vals)
        zeros = np.where(h == 0)[0]
        ones = np.where(h == 1)[0]
        nz, no = len(zeros), len(ones)
        if nz == 0 or no == 0:
            break
        ip = zeros[:, None] + k_vals[None, :]
        im = zeros[:, None] - k_vals[None, :]
        vp = (ip >= 0) & (ip < n)
        vm = (im >= 0) & (im < n)
        h_ip = np.zeros((nz, nk))
        h_im = np.zeros((nz, nk))
        h_ip[vp] = h[ip[vp]]
        h_im[vm] = h[im[vm]]
        base = c[None, :] - h_ip - h_im
        V_ones = V[ones]
        scores = (base[:, None, :] + V_ones[None, :, :]).max(axis=2)

            break

        j = int(ones[flat_idx % no])

def continuous_cd(h, n, deadline, n_grid=100):
    k_vals = np.arange(-(n - 1), n)
    nk = 2 * n - 1
    c = np.correlate(h, 1.0 - h, mode='full').astype(float)
