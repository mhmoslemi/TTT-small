Let me implement the coordinate descent approach for the continuous problem:

The problem is: min h max_k c_k(h) * dx
subject to 0 ≤ h[i] ≤ 1, sum(h) = n/2

Using a penalty for the sum constraint:
min h [max_k c_k(h) * dx + λ * (sum(h) - n/2)^2]

Coordinate descent: for each i, minimize over h[i] ∈ [0,1]:
f_i(h[i]) = max_k [d_k + e_k * h[i]] * dx + λ * (S + h[i] - n/2)^2

where d_k, e_k are constants (given other coordinates), S = sum_{j≠i} h[j].

This is a 1D convex minimization problem. The function is:
g(t) = max_k (d_k + e_k * t) * dx + λ * (S + t - n/2)^2

The max of linear functions is convex, and the quadratic is convex, so g is convex. We can minimize it using:
- Ternary search (works for convex functions)
- Or find the subgradient and use projection

For ternary search on [0,1], we need about 50-100 evaluations to get high precision.

But we need to do this for each of n=250 coordinates, and multiple passes. Each evaluation of g(t) requires computing max_k (d_k + e_k * t) which is O(n) (over all k). So each coordinate update is O(n), and a full pass is O(n^2) = 62500 operations. With 100 ternary search steps, that's 6.25M per pass. With 100 passes, that's 625M. At maybe 100M operations/second in Python/NumPy, that's about 6 seconds per "outer iteration". We have ~1000 seconds, so we can do about 150 outer iterations.

Actually, let me be smarter. For the 1D problem, since g(t) is convex and piecewise (the max changes which function is active), we can:
1. Find all breakpoints t_k = (d_m - d_k) / (e_k - e_m) for all pairs where e_k ≠ e_m
2. Clip to [0,1]
3. Sort
4. Evaluate g at each breakpoint and at 0, 1
5. The minimum is at one of these points

But there are O(n^2) breakpoints, which is too many.

Alternative: use a subgradient method. The subgradient of max_k (d_k + e_k * t) with respect to t is e_k* where k* is the argmax. Plus the subgradient of the penalty term.

So we can use projected subgradient descent on the 1D problem:
t_{new} = clip(t - lr * (e_{k*} * dx + 2*λ*(S + t - n/2)), 0, 1)

With a decreasing learning rate, this converges. But it might be slow.

                t = float(max(0.0, min(1.0, t)))

                new_corr_max = max(np.max(corr[i:i+n] + delta_c),
