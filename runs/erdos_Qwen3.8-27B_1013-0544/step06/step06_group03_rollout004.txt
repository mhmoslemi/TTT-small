Let me also think about **coordinate descent** more carefully.

For a fixed lag m > 0, c_m = dx * f(h) where f is bilinear. If I fix all coordinates except h[k], then f as a function of h[k] is:
f(h) = A*h[k] + B*h[k]^2 + C  (where A, B, C depend on the other coordinates)

Wait, is f quadratic in h[k]? Let's see:
f = sum_{i} h[i]*(1-h[i+m])

If k < n-m: h[k] appears in term i=k as h[k]*(1-h[k+m]), which is linear in h[k].
If k >= m: h[k] appears in term i=k-m as h[k-m]*(1-h[k]), which is linear in h[k].

So f is LINEAR in h[k]! Not quadratic! Because each term h[i]*(1-h[j]) involves TWO different variables, and when we fix all but one, each term involving the free variable is linear.

This means: for a fixed active set of lags, the problem becomes:
minimize max_{k in A} (a_k · h + b_k)  [linear in h for each active k]
subject to: 0 <= h <= 1, sum(h) = n/2

This is a LINEAR program in n variables with |A| + n + 2 constraints! And it's convex!

Wait, but this is only valid if we're at a point where the ACTIVE set A captures all the constraints that are binding. If I solve this LP and the solution violates a non-active constraint, I need to add that constraint and re-solve.

This is essentially the **cutting plane method** or **active set method** for the max of linear functions!

But wait - c_k(h) is NOT linear in h in general. It's bilinear. The issue is that c_k(h) is only LINEAR in h when we fix the "other" variables. For the full problem, it's bilinear.

However, if we do coordinate descent (fixing all but one variable at a time), then at each step the problem IS linear in the free variable. So we can do:

**Coordinate Descent for min max of bilinear functions:**

For iteration:
1. Compute all c_k, find max value t* and active set A
2. For each coordinate k (in some order):
   a. Fix all h[j] for j ≠ k
   b. For each active lag l in A, compute c_l as a function of h[k] (it's linear: α_l * h[k] + β_l)
   c. The constraint c_l(h[k]) <= t* becomes α_l * h[k] + β_l <= t*
   d. Find the range of h[k] that satisfies all constraints: [lo_k, hi_k]
   e. Also: 0 <= h[k] <= 1, and sum constraint: h[k] >= n/2 - sum_{j≠k} h[j] and h[k] <= n/2 - sum_{j≠k} h[j]
   f. Choose h[k] to minimize the new max (or to reduce the worst violation)

For step (f), since each c_l is linear in h[k], the max of lines is a convex piecewise-linear function of h[k]. The minimum is at a breakpoint (where two constraints are tight) or at a boundary.

This is a very clean algorithm! Let me implement it.

Actually, let me think about the sum constraint more carefully. If I change h[k] by δ, I need to adjust another coordinate to maintain the sum. Or I can just allow the sum to be violated temporarily and fix it at the end.

Better: incorporate the sum constraint directly. If I increase h[k] by δ, I need to decrease some other h[j] by δ. This complicates things.

Alternative: use the "free variable" approach where I optimize h[k] free, then project to the constraint set. The projection onto {h: 0<=h<=1, sum(h)=n/2} is the same `project_feasible` function from before.

Let me simplify: at each step, choose the new h[k] to minimize the max over active lags, respecting only the [0,1] bounds. Then project the whole vector to satisfy the sum constraint.

Here's my refined algorithm:

```python
def coordinate_descent(h, n, deadline, max_sweeps=100):
    h = project_feasible(h.copy(), n)
    best_c = compute_c5(h, n)
    best_h = h.copy()
    
    for sweep in range(max_sweeps):
        if time.time() > deadline:
            break
        c_all = compute_all_lags(h, n)
        t_star = c_all.max()
        # Active set: lags within 1% of max
        active_mask = c_all >= t_star * 0.99
        active_idx = np.where(active_mask)[0]
        
        improved = False
        for k in range(n):
            if time.time() > deadline:
                break
            # For each active lag, compute c_lag as function of h[k]
            # c_lag = alpha_lag * h[k] + beta_lag
            alphas = []
            betas = []
            for idx in active_idx:
                lag = idx - (n - 1)
                # Compute alpha and beta for this lag
                # c_lag = dx * sum_i h[i]*(1-h[i+lag_effective])
                # where the effective lag depends on convention
                # Use the gradient: grad_lag[i] = dc/dh[i]
                # So c_lag = grad_lag[k] * h[k] + (c_lag - grad_lag[k]*h[k])
                grad = lag_gradient(h, n, lag)
                alphas.append(grad[k])
                betas.append(c_all[idx] - grad[k] * h[k])
            
            # Now find h_new that minimizes max_lag (alpha_lag * h_new + beta_lag)
            # subject to 0 <= h_new <= 1
            # This is min of max of lines = find lowest point of upper envelope
            
            h_new = optimize_1d(alphas, betas, h[k])
            if h_new != h[k]:
                h[k] = h_new
                improved = True
        
        if improved:
            h = project_feasible(h, n)
            c_new = compute_c5(h, n)
            if c_new < best_c:
                best_c = c_new
                best_h = h.copy()
        else:
            break
    
    return best_h, best_c

def optimize_1d(alphas, betas, h_curr):
    # Find h in [0,1] that minimizes max_i (alphas[i]*h + betas[i])
    # The function f(h) = max_i (a_i*h + b_i) is convex piecewise linear
    # Minimum is at a vertex or at boundary
    # Vertices are intersections of pairs of lines
    a = np.array(alphas)
    b = np.array(betas)
    
    candidates = [0.0, 1.0, h_curr]
    # Add intersections
    for i in range(len(a)):
        for j in range(i+1, len(a)):
            if abs(a[i] - a[j]) > 1e-12:
                h_int = (b[j] - b[i]) / (a[i] - a[j])
                if 0 <= h_int <= 1:
                    candidates.append(h_int)
    
    best_h = h_curr
    best_val = float('inf')
    for hc in candidates:
        val = np.max(a * hc + b)
        if val < best_val:
            best_val = val
            best_h = hc
    return best_h
```

Wait, this O(n^2) intersection computation per coordinate is too expensive. For n=300 coordinates and say 10 active lags, that's 300 * C(10,2) = 13500 intersection checks per sweep. That's actually fine.

But the compute_all_lags is O(n^2) (due to correlate), and the lag_gradient is O(n) per lag. So per coordinate: O(num_active * n) for gradients. Total per sweep: O(n * num_active * n) = O(n^2 * num_active). For n=300, num_active=10: 900,000 operations per sweep. That's fine.

Actually wait, I can precompute all the gradients! For all lags at once, the gradient matrix is G[k, lag] = ∂c_lag/∂h[k]. I can compute this efficiently.

Actually, let me reconsider. The gradient of c_lag w.r.t. h[k] only depends on h at specific positions. For lag m:
- If k < n-m: grad[k] = -(h[k+m]) + (1-h[k-m]) if k>=m, else -h[k+m]
- If k >= n-m: grad[k] = (1-h[k-m]) if k>=m, else 0

This is O(1) per (k, lag) pair if I have h. So computing the gradient matrix is O(n * num_lags) = O(n^2) which is fine.

```
h_0 = initial

for t = 0, 1, 2, ...:
```

The Lipschitz constant of the gradient of c_k is bounded by... well, the Hessian of c_k has eigenvalues bounded by 2 (since c_k = sum h[i](1-h[j]), the Hessian has 1's and -1's on off-diagonal entries). So L ≈ 2 * n (worst case). In practice, L is much smaller.

```python
import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1 - h, mode='full')
    return float(np.max(c) * dx)

def compute_all_lags(h, n):
    dx = 2.0 / n
    return np.correlate(h, 1 - h, mode='full') * dx

def project_feasible(h, n):
    target_sum = n / 2.0
    h = np.clip(h.copy(), 0.0, 1.0)
    for _ in range(100):
        diff = target_sum - h.sum()
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            room = 1.0 - h
            tot = room.sum()
            if tot < 1e-14:
                break
            h += (diff / tot) * room
        else:
            tot = h.sum()
            if tot < 1e-14:
                break
            h += (diff / tot) * h
    return np.clip(h, 0.0, 1.0)

def smooth_max_obj(x, n, alpha):
    dx = 2.0 / n
    c = np.correlate(x, 1 - x, mode='full') * dx
    m = c.max()
    shifted = alpha * (c - m)
    mx = shifted.max()
    if mx > 500:
        return m + (mx + np.log(np.sum(np.exp(shifted - mx)))) / alpha
    return m + np.log(np.sum(np.exp(shifted))) / alpha

def sum_con(x, n):
    return np.sum(x) - n / 2.0

def sum_con_jac(x, n):
    return np.ones(n)

def slsqp_opt(h, n, alpha, maxiter=3000, ftol=1e-14):
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': sum_con, 'jac': sum_con_jac, 'args': (n,)}]
    try:
        res = minimize(smooth_max_obj, h, args=(n, alpha), method='SLSQP',
                       bounds=bounds, constraints=cons,
                       options={'maxiter': maxiter, 'ftol': ftol})
        return project_feasible(res.x, n)
    except:
        return h.copy()

def lag_grad(h, n, lag):
    m = abs(lag)
    grad = np.zeros(n)
    if m >= n:
        return grad
    if m == 0:
        grad[:] = 1.0 - 2.0 * h
    elif lag > 0:
        grad[:n-m] -= h[m:]
        grad[m:] += (1.0 - h[:n-m])
    else:
        grad[:n-m] += (1.0 - h[m:])
        grad[m:] -= h[:n-m]
    return grad

def coord_descent(h, n, deadline, max_sweeps=200, active_frac=0.995):
    h = project_feasible(h.copy(), n)
    best_c = compute_c5(h, n)
    best_h = h.copy()
    
    for sweep in range(max_sweeps):
        if time.time() > deadline:
            break
        c_all = compute_all_lags(h, n)
        t_star = c_all.max()
        threshold = t_star * active_frac
        active_idx = np.where(c_all >= threshold)[0]
        lags = active_idx - (n - 1)
        
        # Precompute gradients for active lags
        # grad_matrix[i, j] = d(c_lag_j)/d(h_i)
        G = np.zeros((n, len(lags)))
        for j, lag in enumerate(lags):
            G[:, j] = lag_grad(h, n, lag)
        
        improved = False
        # Iterate over coordinates in random order for diversity
        order = np.random.permutation(n)
        for k in order:
            if time.time() > deadline:
                break
            # c_lag_j as function of h[k]: G[k,j]*h[k] + (c_all[active_idx[j]] - G[k,j]*h[k])
            alphas = G[k, :]
            betas = c_all[active_idx] - G[k, :] * h[k]
            
            # Find h_new in [0,1] minimizing max_j (alphas[j]*h_new + betas[j])
            h_new = min_1d_max(alphas, betas, h[k])
            if abs(h_new - h[k]) > 1e-12:
                h[k] = h_new
                improved = True
        
        if improved:
            h = project_feasible(h, n)
            c_new = compute_c5(h, n)
            if c_new < best_c - 1e-14:
                best_c = c_new
                best_h = h.copy()
        else:
            # Try with wider active set
            if active_frac > 0.95:
                active_frac = max(0.95, active_frac - 0.01)
            else:
                break
    
    return best_h, best_c

def min_1d_max(alphas, betas, h_curr):
    a = alphas
    b = betas
    n_a = len(a)
    
    # f(h) = max_i (a_i * h + b_i) is convex piecewise linear on [0,1]
    # Find all breakpoints in [0,1]
    candidates = [0.0, 1.0]
    
    # Intersections of pairs
    for i in range(n_a):
        for j in range(i+1, n_a):
            da = a[i] - a[j]
            if abs(da) > 1e-14:
                hi = (b[j] - b[i]) / da
                if -1e-10 <= hi <= 1 + 1e-10:
                    candidates.append(np.clip(hi, 0, 1))
    
    # Evaluate at all candidates
    best_val = float('inf')
    best_h = h_curr
    for hc in candidates:
        val = np.max(a * hc + b)
        if val < best_val:
            best_val = val
            best_h = hc
    
    return best_h

def subgradient_momentum(h, n, deadline, max_iters=5000):
    h_curr = project_feasible(h.copy(), n)
    best_h = h_curr.copy()
    best_c = compute_c5(h_curr, n)
    prev_h = h_curr.copy()
    
    t = 0
    L = 4.0  # Lipschitz constant estimate
    
    while time.time() < deadline and t < max_iters:
        c_all = compute_all_lags(h_curr, n)
        t_star = c_all.max()
        
        if t_star < best_c - 1e-14:
            best_c = t_star
            best_h = h_curr.copy()
        
        # Subgradient: gradient of the max active constraint
        active_idx = np.where(c_all >= t_star - 1e-10)[0]
        if len(active_idx) == 0:
            active_idx = [np.argmax(c_all)]
        
        # Average gradient of active constraints
        g = np.zeros(n)
        for idx in active_idx:
            lag = idx - (n - 1)
            g += lag_grad(h_curr, n, lag)
        g /= len(active_idx)
        
        # Nesterov momentum
        t += 1
        beta = (1.0 + np.sqrt(1.0 + 4.0*(t-1)**2)) / 2.0
        mu = (t - 1) / (t - 1 + beta) if t > 1 else 0.0
        y = h_curr + mu * (h_curr - prev_h)
        
        # Polyak step size
        f_lower = 0.0  # We know c5 >= 0
        step = (t_star - f_lower) / (np.dot(g, g) + 1e-12)
        step = min(step, 5.0)  # Cap the step
        
        h_new = project_feasible(y - step * g, n)
        prev_h = h_curr
        h_curr = h_new
    
    return best_h, best_c

def local_search(h, n, deadline):
    h = h.copy()
    best_c = compute_c5(h, n)
    deltas = [0.01, 0.005, 0.002, 0.001, 0.0005, 0.0002, 0.0001]
    
    for d in deltas:
        if time.time() > deadline:
            break
        improved = True
        while improved:
            if time.time() > deadline:
                break
            improved = False
            c_all = compute_all_lags(h, n)
            k_star = int(np.argmax(c_all))
            lag = k_star - (n - 1)
            if lag == 0:
                break
            m = abs(lag)
            # Try moving mass from high to low in the conflicting region
            if lag > 0:
                pairs = [(i, i+m) for i in range(n-m)]
            else:
                pairs = [(i+m, i) for i in range(n-m)]
            
            # Sort by conflict
            conflicts = []
            for i, j in pairs:
                conflict = h[i] * (1 - h[j]) + h[j] * (1 - h[i])
                conflicts.append((conflict, i, j))
            conflicts.sort(reverse=True)
            
            for conflict, i, j in conflicts[:50]:
                if time.time() > deadline:
                    break
                if h[i] > h[j]:
                    delta = min(d, h[i], 1.0 - h[j])
                    if delta < 1e-10:
                        continue
                    h[i] -= delta
                    h[j] += delta
                    c_new = compute_c5(h, n)
                    if c_new < best_c - 1e-14:
                        best_c = c_new
                        improved = True
                    else:
                        h[i] += delta
                        h[j] -= delta
                elif h[j] > h[i]:
                    delta = min(d, h[j], 1.0 - h[i])
                    if delta < 1e-10:
                        continue
                    h[i] += delta
                    h[j] -= delta
                    c_new = compute_c5(h, n)
                    if c_new < best_c - 1e-14:
                        best_c = c_new
                        improved = True
                    else:
                        h[i] -= delta
                        h[j] += delta
    return h, best_c
```

```python
import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1 - h, mode='full')
    return float(np.max(c) * dx)

def compute_all_lags(h, n):
    dx = 2.0 / n
    return np.correlate(h, 1 - h, mode='full') * dx

def project_feasible(h, n):
    target_sum = n / 2.0
    h = np.clip(h.copy(), 0.0, 1.0)
    for _ in range(100):
        diff = target_sum - h.sum()
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            room = 1.0 - h
            tot = room.sum()
            if tot < 1e-14:
                break
            h += (diff / tot) * room
        else:
            tot = h.sum()
            if tot < 1e-14:
                break
            h += (diff / tot) * h
    return np.clip(h, 0.0, 1.0)

def smooth_max_obj(x, n, alpha):
    dx = 2.0 / n
    c = np.correlate(x, 1 - x, mode='full') * dx
    m = c.max()
    shifted = alpha * (c - m)
    mx = shifted.max()
    if mx > 500:
        return m + (mx + np.log(np.sum(np.exp(shifted - mx)))) / alpha
    return m + np.log(np.sum(np.exp(shifted))) / alpha

def sum_con(x, n):
    return np.sum(x) - n / 2.0

def sum_con_jac(x, n):
    return np.ones(n)

def slsqp_opt(h, n, alpha, maxiter=3000, ftol=1e-14):
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': sum_con, 'jac': sum_con_jac, 'args': (n,)}]
    try:
        res = minimize(smooth_max_obj, h, args=(n, alpha), method='SLSQP',
                       bounds=bounds, constraints=cons,
                       options={'maxiter': maxiter, 'ftol': ftol})
        return project_feasible(res.x, n)
    except Exception:
        return h.copy()

def lag_grad(h, n, lag):
    m = abs(lag)
    grad = np.zeros(n)
    if m >= n:
        return grad
    if m == 0:
        grad[:] = 1.0 - 2.0 * h
    elif lag > 0:
        grad[:n - m] -= h[m:]
        grad[m:] += (1.0 - h[:n - m])
    else:
        grad[:n - m] += (1.0 - h[m:])
        grad[m:] -= h[:n - m]
    return grad

def min_1d_max(alphas, betas, h_curr):
    a = alphas
    b = betas
    na = len(a)
    candidates = [0.0, 1.0]
    for i in range(na):
        for j in range(i + 1, na):
            da = a[i] - a[j]
            if abs(da) > 1e-14:
                hi = (b[j] - b[i]) / da
                if -1e-10 <= hi <= 1 + 1e-10:
                    candidates.append(float(np.clip(hi, 0, 1)))
    best_val = float('inf')
    best_h = h_curr
    for hc in candidates:
        val = float(np.max(a * hc + b))
        if val < best_val:
            best_val = val
            best_h = hc
    return best_h

def coord_descent(h, n, deadline, max_sweeps=200, active_frac=0.995, rng=None):
    h = project_feasible(h.copy(), n)
    best_c = compute_c5(h, n)
    best_h = h.copy()
    if rng is None:
        rng = np.random.RandomState(0)
    for sweep in range(max_sweeps):
        if time.time() > deadline:
            break
        c_all = compute_all_lags(h, n)
        t_star = float(c_all.max())
        threshold = t_star * active_frac
        active_idx = np.where(c_all >= threshold)[0]
        lags = active_idx - (n - 1)
        G = np.zeros((n, len(lags)))
        for j in range(len(lags)):
            G[:, j] = lag_grad(h, n, int(lags[j]))
        improved = False
        order = rng.permutation(n)
        for k in order:
            if time.time() > deadline:
                break
            alphas = G[k, :]
            betas = c_all[active_idx] - G[k, :] * h[k]
            h_new = min_1d_max(alphas, betas, h[k])
            if abs(h_new - h[k]) > 1e-12:
                h[k] = h_new
                improved = True
        if improved:
            h = project_feasible(h, n)
            c_new = compute_c5(h, n)
            if c_new < best_c - 1e-15:
                best_c = c_new
                best_h = h.copy()
        else:
            if active_frac > 0.97:
                active_frac = max(0.97, active_frac - 0.005)
            else:
                break
    return best_h, best_c

def subgradient_momentum(h, n, deadline, max_iters=8000):
    h_curr = project_feasible(h.copy(), n)
    best_h = h_curr.copy()
    best_c = compute_c5(h_curr, n)
    prev_h = h_curr.copy()
    t = 0
    while time.time() < deadline and t < max_iters:
        c_all = compute_all_lags(h_curr, n)
        t_star = float(c_all.max())
        if t_star < best_c - 1e-14:
            best_c = t_star
            best_h = h_curr.copy()
        tol = max(1e-10, t_star * 0.01)
        active_idx = np.where(c_all >= t_star - tol)[0]
        g = np.zeros(n)
        for idx in active_idx:
            lag = int(idx - (n - 1))
            g += lag_grad(h_curr, n, lag)
        g /= max(1, len(active_idx))
        t += 1
        beta = (1.0 + np.sqrt(1.0 + 4.0 * (t - 1) ** 2)) / 2.0
        mu = (t - 1) / (t - 1 + beta) if t > 1 else 0.0
        y = h_curr + mu * (h_curr - prev_h)
        gnorm2 = float(np.dot(g, g))
        step = (t_star - 0.0) / (gnorm2 + 1e-12)
        step = min(step, 3.0)
        h_new = project_feasible(y - step * g, n)
        prev_h = h_curr
        h_curr = h_new
    return best_h, best_c

def local_search(h, n, deadline):
    h = h.copy()
    best_c = compute_c5(h, n)
    deltas = [0.01, 0.005, 0.002, 0.001, 0.0005, 0.0002, 0.0001]
    for d in deltas:
        if time.time() > deadline:
            break
        improved = True
        while improved:
            if time.time() > deadline:
                break
            improved = False
            c_all = compute_all_lags(h, n)
            k_star = int(np.argmax(c_all))
            lag = k_star - (n - 1)
            if lag == 0:
                break
            m = abs(lag)
            if lag > 0:
                pairs = [(i, i + m) for i in range(n - m)]
            else:
                pairs = [(i + m, i) for i in range(n - m)]
            conflicts = []
            for i, j in pairs:
                conf = h[i] * (1.0 - h[j]) + h[j] * (1.0 - h[i])
                conflicts.append((conf, i, j))
            conflicts.sort(key=lambda x: -x[0])
            for conf, i, j in conflicts[:80]:
                if time.time() > deadline:
                    break
                if h[i] > h[j]:
                    delta = min(d, h[i], 1.0 - h[j])
                    if delta < 1e-10:
                        continue
                    h[i] -= delta
                    h[j] += delta
                    c_new = compute_c5(h, n)
                    if c_new < best_c - 1e-14:
                        best_c = c_new
                        improved = True
                    else:
                        h[i] += delta
                        h[j] -= delta
                elif h[j] > h[i]:
                    delta = min(d, h[j], 1.0 - h[i])
                    if delta < 1e-10:
                        continue
                    h[i] += delta
                    h[j] -= delta
                    c_new = compute_c5(h, n)
                    if c_new < best_c - 1e-14:
                        best_c = c_new
                        improved = True
                    else:
                        h[i] -= delta
                        h[j] += delta
    return h, best_c

def optimize_at_n(h_start, n, deadline, rng):
    h = project_feasible(h_start.copy(), n)
    best_h = h.copy()
    best_c = compute_c5(best_h, n)
```
