**New approach: Continuous optimization with log-sum-exp smoothing and FISTA/proximal gradient**

The smoothed objective:
f(h) = (1/α)·log(Σ_k exp(α·overlap_k(h)))

where overlap_k(h) = dx·(corr_h)[k]

The gradient:
∇f(h)[j] = (1/α)·Σ_k (α·overlap_k(h)·(∂overlap_k/∂h[j])·exp(α·overlap_k(h))) / Σ_k exp(α·overlap_k(h))
= Σ_k (overlap_k(h)·(∂overlap_k/∂h[j])) · softmax(α·overlap_k)

This is a weighted average of the gradients of individual overlaps, weighted by how "active" each overlap is.

The constraint set {h : 0≤h≤1, Σh=n/2} is a product of a box and a hyperplane. The projection onto this set is:
1. Project onto {h : 0≤h≤1, Σh=n/2}
   This is: find τ such that Σ_j clip(h[j]-τ, 0, 1) = n/2, then project = clip(h-τ, 0, 1).
   Can be solved by bisection on τ.

So the algorithm is:
1. Initialize h
2. Repeat:
   a. Compute gradient of smoothed objective
   b. h ← h - step_size · gradient
   c. h ← project(h)
   d. Optionally: backtracking line search

This is essentially projected gradient descent (or FISTA with momentum).

def project_box_sum(h, n):
    """Project h onto {x: 0<=x<=1, sum(x)=n/2}"""
    target = n / 2.0
    # Bisection on tau
    lo, hi = h.min() - 1, h.max() + 1
    for _ in range(100):
        tau = (lo + hi) / 2
        proj = np.clip(h - tau, 0, 1)
        s = proj.sum()
        if s > target:
            lo = tau
        else:
            hi = tau
    return np.clip(h - tau, 0, 1)

def smoothed_max_grad(corr, alpha):
    """Compute value and gradient of log-sum-exp smoothing of max(corr)"""
    # corr is the correlation vector (before multiplying by dx)
    m = corr.max()
    shifted = alpha * (corr - m)
    exps = np.exp(shifted)
    lse = m + np.log(exps.sum()) / alpha
    weights = exps / exps.sum()
    return lse, weights  # weights gives the softmax distribution over lags

def gradient_c5(h, n, alpha):
    """Compute gradient of smoothed C5 objective"""
    dx = 2.0 / n
    corr = np.correlate(h, 1 - h, mode='full').astype(float)
    lse, weights = smoothed_max_grad(corr, alpha)
    
    # Gradient of corr[k] with respect to h[j]:
    # corr[k] = sum_i h[i] * (1-h[i+k-(n-1)]) for valid i
    # d(corr[k])/d(h[j]) = (1-h[j+k-(n-1)]) - h[j-(k-(n-1))] (for valid indices)
    
    n_corr = len(corr)
    grad = np.zeros(n)
    for k in range(n_corr):
        if weights[k] < 1e-15:
            continue
        lag = k - (n - 1)
        # Term 1: h[j] appears as h[i] with i=j, contributing (1-h[j+lag])
        valid1 = (j + lag >= 0) & (j + lag < n)  # but this varies with j
        # Actually, for each j:
        # d(corr[k])/d(h[j]) = (1-h[j+lag]) * [j+lag valid] - h[j-lag] * [j-lag valid]
        
        # Let me compute this vectorized
        # For fixed k, lag = k-(n-1):
        # d(corr[k])/d(h[j]) = (1-h[j+lag]) if 0<=j+lag<n, else 0
        #                         - h[j-lag] if 0<=j-lag<n, else 0
        
        # Vectorized:
        j_idx = np.arange(n)
        term1 = np.zeros(n)
        v1 = (j_idx + lag >= 0) & (j_idx + lag < n)
        term1[v1] = 1 - h[j_idx[v1] + lag]
        
        term2 = np.zeros(n)
        v2 = (j_idx - lag >= 0) & (j_idx - lag < n)
        term2[v2] = h[j_idx[v2] - lag]
        
        grad += weights[k] * (term1 - term2)
    
    return lse * dx, grad * dx

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h, 0.0, 1.0)
    for _ in range(100):
        diff = target - h.sum()
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            room = 1.0 - h
            s = room.sum()
            if s < 1e-14:

        else:
            s = h.sum()
            if s < 1e-14:
                break
            h = h + diff / s * h

So for a=h, v=1-h:
corr[p] = Σ_i h[i] · (1-h[i + p - (n-1)])

Let k = p - (n-1) (the lag). Then:
corr[k] = Σ_i h[i] · (1-h[i+k]) where the sum is over i such that 0 ≤ i < n and 0 ≤ i+k < n.

d(corr[k])/d(h[j]):
- h[j] appears in the first factor: when i=j, contributes (1-h[j+k]) if 0 ≤ j+k < n
- h[j] appears in the second factor (1-h[i+k]): when i+k=j, i.e., i=j-k, contributes -h[j-k] if 0 ≤ j-k < n

So:
d(corr[k])/d(h[j]) = (1-h[j+k])·1[0≤j+k<n] - h[j-k]·1[0≤j-k<n]

For lag k > 0:
- First term: valid for j = 0, 1, ..., n-k-1 (j+k < n ⟺ j < n-k)
  value: 1-h[k], 1-h[k+1], ..., 1-h[n-1] (i.e., 1-h[k:])
- Second term: valid for j = k, k+1, ..., n-1 (j-k ≥ 0)
  value: h[0], h[1], ..., h[n-k-1] (i.e., h[:n-k])

So for lag k > 0:
grad[k] = [0,...,0, 1-h[k], 1-h[k+1], ..., 1-h[n-1]]

```python
def compute_smooth_grad(h, n, alpha):
    dx = 2.0 / n
    corr = np.correlate(h, 1 - h, mode='full').astype(float)
    nc = len(corr)
    m = corr.max()
    shifted = alpha * (corr - m)
    shifted -= shifted.max()
    exps = np.exp(shifted)
    weights = exps / exps.sum()
    lse_value = (m + shifted.max() / alpha + np.log(exps.sum()) / alpha) * dx
    # Actually: log-sum-exp = m + max(shifted)/alpha + log(sum(exp(shifted)))/alpha
    # But shifted = alpha*(corr-m), so max(shifted) = alpha*(max(corr)-m) = 0
    # So LSE = m + log(sum(exp(alpha*(corr-m))))/alpha
    # And after normalizing: LSE = m + (shifted.max() + log(sum(exp(shifted - shifted.max()))))/alpha
    # Since shifted.max() = 0: LSE = m + log(sum(exp(shifted)))/alpha
    
    grad = np.zeros(n)
    for k in range(nc):
        w = weights[k]
        if w < 1e-10:
            continue
        lag = k - (n - 1)
        if lag == 0:
            grad += w * (1.0 - 2.0 * h)
        elif lag > 0:
            # term1: positions 0..n-1-lag get (1-h[lag..n-1])
            # term2: positions lag..n-1 get h[0..n-1-lag]
            grad[:n-lag] += w * (1.0 - h[lag:])
            grad[lag:] -= w * h[:n-lag]
        else:
            kl = -lag
            # term1: positions kl..n-1 get (1-h[0..n-1-kl])
            # term2: positions 0..n-1-kl get h[kl..n-1]
            grad[kl:] += w * (1.0 - h[:n-kl])
            grad[:n-kl] -= w * h[kl:]
    
    grad *= dx
    return lse_value, grad
```
