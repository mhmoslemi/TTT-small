Actually, for a fixed active set A (the lags where f_k = t = max):
The Lagrangian is:
L = t + sum_{k in A} λ_k (f_k(h) - t) + μ (sum(h) - n/2) + sum_i ν_i^+ (1-h_i) + sum_i ν_i^- (0-h_i)

KKT conditions:
- ∂L/∂h_i = 0: -sum_{k in A} λ_k ∂f_k/∂h_i + μ + ν_i^+ - ν_i^- = 0
- ∂L/∂t = 1 - sum_{k in A} λ_k = 0 → sum λ_k = 1
- Complementarity: λ_k ≥ 0, λ_k (f_k - t) = 0

So we need to find λ_k (for k in A), μ, t, h such that:
- sum_{k in A} λ_k = 1
- t = f_k(h) for all k in A
- sum_i (-λ^T ∂f/∂h)_i + μ = 0 for i not at bounds (and appropriate complementarity at bounds)
- f_j(h) ≤ t for j not in A

This is a nonlinear system. For a small active set (say 3-5 lags), it might be tractable.
