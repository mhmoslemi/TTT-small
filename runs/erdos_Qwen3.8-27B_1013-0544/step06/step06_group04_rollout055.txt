    dx = 2.0 / n
    return float(np.max(np.correlate(h, 1 - h, mode='full')) * dx)

def project_feasible(h, n):
    h = np.clip(h.copy(), 0.0, 1.0)
    target = n / 2.0
    for _ in range(50):
        diff = target - h.sum()
        if abs(diff) < 1e-12:
            break

            room = 1.0 - h
            s = room.sum()
            if s < 1e-14:

            h += diff / s * room
        else:

            if s < 1e-14:
                break
            h += diff / s * h

Wait, let me redo this. The log-sum-exp objective is:
F(h) = (1/alpha) * log(sum_k exp(alpha * corr_k))

dF/dh_j = (1/alpha) * (sum_k alpha * exp(alpha*corr_k) * d(corr_k)/dh_j) / sum_k exp(alpha*corr_k)
= sum_k (exp(alpha*corr_k) / sum_j exp(alpha*corr_j)) * d(corr_k)/dh_j
= sum_k p_k * d(corr_k)/dh_j

where p_k = exp(alpha*corr_k) / sum_j exp(alpha*corr_j) is a softmax distribution over lags.

So the gradient of F is just the expectation of the individual gradients under the softmax distribution. No alpha factor in the gradient!

But the gradient magnitude is bounded (each individual gradient has bounded norm), so the step size should be similar regardless of alpha.

For large alpha, p_k concentrates on the max lag, and we recover the top-1 gradient. For small alpha, p_k is more uniform, and we get an average gradient.

This is a nice smooth interpolation! Let me use this approach.
