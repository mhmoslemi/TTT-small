```python
    best_new_max = np.inf
    best_swap = None
    
    # Process in batches of zeros
    batch_size = 25
    for start in range(0, n_z, batch_size):
        end = min(start + batch_size, n_z)
        z_batch = zeros[start:end]
        # (batch, 1, n_corr) + (1, n_o, n_corr) patterns
        # new_corr[b, o, k] = corr[k] + A[z_batch[b], k] - A[ones[o], k] - B[z_batch[b], k] + B[ones[o], k]
        Ac = A[z_batch]  # (batch, n_corr)
        Bc = B[z_batch]  # (batch, n_corr)
        Ao = A[ones]  # (n_o, n_corr)
        Bo = B[ones]  # (n_o, n_corr)
        
        # new_max[b, o] = max_k (corr[k] + Ac[b,k] - Ao[o,k] - Bc[b,k] + Bo[o,k])
        # = max_k (corr[k] + (Ac[b,k] - Bc[b,k]) - (Ao[o,k] - Bo[o,k]))
        
        C = Ac - Bc  # (batch, n_corr)
        D = Ao - Bo  # (n_o, n_corr)
        # new_max[b,o] = max_k (corr[k] + C[b,k] - D[o,k])
        
        # This is (batch, n_o, n_corr
        vals = corr[None, None, :] + C[:, None, :] - D[None, :, :]
        new_maxes = vals.max(axis=2)  # (batch, n_o)
        
        flat_idx = new_maxes.argmin()
        b = flat_idx // n_o
        o = flat_idx % n_o
        best_new_max_b = new_maxes[b, o]
        
        if best_new_max_b < best_new_max:
            best_new_max = best_new_max_b
            best_swap = (z_batch[b], ones[o])
    
    return best_swap, best_new_max
```

This is much more efficient! The (batch, n_o, n_corr) array is (25, 125, 499) ≈ 1.5M elements per batch, and we have 5 batches. Total: ~7.8M elements processed per sweep. In numpy, this should take < 0.1 seconds.

But wait, there's a subtlety. The A and B matrices depend on h, which changes after each swap. So I need to rebuild them after each accepted swap. Rebuilding is O(n^2) = 62500 operations, which is fast.

Let me now write the complete algorithm:

1. Multiple initializations (Thue-Morse, random, structured)
2. For each, do local search with the vectorized swap evaluation
3. When stuck (no improving swap), do multi-swap perturbation
4. At the end, do SLSQP continuous polish

result[k] = sum_n a[n+k] * v[n]

where the sum is over all n such that 0 <= n < len(v) and 0 <= n+k < len(a).

For len(a) = len(v) = 4:

The mapping is: output index k corresponds to lag k - (len(v)-1) = k-3.
