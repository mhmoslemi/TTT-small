```python
    # grad[i] = dx * (sum_m w[m]*(1-h[i+m-(n-1)]) * 1{valid} - sum_m w[m]*h[i-m+(n-1)] * 1{valid})
    
    # First sum: for each i, sum over m where i+m-(n-1) ∈ [0,n-1]
    #   = sum over m where m ∈ [n-1-i, 2n-2-i] of w[m]*(1-h[i+m-(n-1)])
    #   Let j = i+m-(n-1), so m = j+i-(n-1), j ∈ [0, n-1]
    #   = sum_{j=0}^{n-1} w[j+i-(n-1)] * (1-h[j]) * 1{j+i-(n-1) ∈ [0, 2n-2]}
    #   = sum_{j=0}^{n-1} w[j+i-(n-1)] * (1-h[j]) (since j+i-(n-1) ranges from i-(n-1) to i+n-1-(n-1)=i, 
    #     and for i ∈ [0,n-1], i-(n-1) ∈ [-(n-1), 0] and i ∈ [0, n-1],
    #     so j+i-(n-1) ∈ [i-(n-1), i] ⊆ [-(n-1), n-1] ⊆ [0, 2n-2] ∪ [negative, 0])
    #     Need j+i-(n-1) ≥ 0, i.e., j ≥ n-1-i
    #   = sum_{j=n-1-i}^{n-1} w[j+i-(n-1)] * (1-h[j])
    
    # This is a cross-correlation of w and (1-h)!
    # Specifically: first_sum[i] = sum_{j=n-1-i}^{n-1} w[j+i-(n-1)] * (1-h[j])
    # Let k = j - (n-1-i), so j = n-1-i+k, k from 0 to i
    #   = sum_{k=0}^{i} w[k] * (1-h[n-1-i+k])
    # This is the cross-correlation of w and (1-h) at a specific offset.
    
    # Similarly for the second sum:
    # second_sum[i] = sum_{m: i-m+(n-1) ∈ [0,n-1]} w[m] * h[i-m+(n-1)]
    #   Let j = i-m+(n-1), so m = i-j+(n-1), j ∈ [0,n-1]
    #   = sum_{j: m=i-j+(n-1) ∈ [0,2n-2]} w[i-j+(n-1)] * h[j]
    #   m = i-j+(n-1) ∈ [0, 2n-2] → j ∈ [i+(n-1)-(2n-2), i+(n-1)] = [i-n+1, i+n-1]
    #   intersected with [0, n-1]: j ∈ [max(0, i-n+1), min(n-1, i)]
    #   Since i ∈ [0,n-1]: j ∈ [0, i]
    #   = sum_{j=0}^{i} w[i-j+(n-1)] * h[j]
    # This is also a cross-correlation!
    
    # So: grad[i] = dx * (first_sum[i] - second_sum[i])
    # where first_sum = cross-corr of w[0:i+1] reversed with (1-h[n-1-i:n])... 
    
    # Actually, let me just use np.correlate or a direct implementation.
    # For n=250, even a direct O(n²) loop is fine.
    
    grad = np.zeros(n)
    # Vectorized approach using the correlation structure
    # first_sum[i] = sum_{j=max(0,n-1-i)}^{n-1} w[j+i-(n-1)] * (1-h[j])
    # second_sum[i] = sum_{j=0}^{min(n-1,i)} w[i-j+(n-1)] * h[j]
    
    # Let me compute these using matrix multiplication or direct loops
    # For efficiency, I'll use the fact that these are truncated correlations
    
    # Alternative: just compute the gradient directly
    # corr_m = sum_t h[t] * (1-h[t+m-(n-1)])
    # d(corr_m)/d(h[i]) = (1-h[i+m-(n-1)]) * 1{valid} + h[i] * (-1) * d(h[i+m-(n-1)])/d(h[i]) * 1{valid}
    # Wait, h[i+m-(n-1)] depends on h[i] only when i+m-(n-1) = i, i.e., m = n-1
    # Similarly, the first factor h[t] depends on h[i] only when t = i
    # So: d(corr_m)/d(h[i]) = (1-h[i+m-(n-1)]) * 1{i+m-(n-1) ∈ [0,n-1]} 
    #                              - h[i-m+(n-1)] * 1{i-m+(n-1) ∈ [0,n-1]}
    #                              - h[i] * 1{m = n-1 and i+m-(n-1) = i}  [this is the product rule for the diagonal]
    # Wait, for m = n-1: corr_{n-1} = sum_t h[t]*(1-h[t]) 
    # d(corr_{n-1})/d(h[i]) = (1-2*h[i])
    # But from the formula: (1-h[i]) - h[i] - h[i]*(1) ... hmm
    # Actually: corr_m = sum_t h[t]*(1-h[t+m-(n-1)])
    # d/dh[i]: the term t=i gives (1-h[i+m-(n-1)])
    #           the term where t+m-(n-1)=i gives -h[i-m+(n-1)] (derivative of (1-h) w.r.t. h[i] is -1)
    # For m=n-1: both terms give (1-h[i]) and -h[i], total = 1-2h[i]. ✓
    # For m≠n-1: the two terms are at different t values, so they don't interfere.
    
    # So: grad[i] = dx * sum_m w[m] * [(1-h[i+m-(n-1)]) * 1{i+m-(n-1)∈[0,n-1]} - h[i-m+(n-1)] * 1{i-m+(n-1)∈[0,n-1]}]
    
    # This is O(n²) to compute directly, but for n=250 it's fast enough.
    # Let me use a matrix approach:
    # Build a matrix A where A[i,m] = (1-h[i+m-(n-1)]) if valid, else 0
    # And B where B[i,m] = h[i-m+(n-1)] if valid, else 0
    # Then grad = dx * ((A.T @ w) - (B.T @ w))
    
    # For n=250, A and B are 250 x 499 matrices, which is fine.
    
    # Build A and B:
    # A[i, m] = 1 - h[i+m-(n-1)] if 0 ≤ i+m-(n-1) < n, else 0
    # B[i, m] = h[i-m+(n-1)] if 0 ≤ i-m+(n-1) < n, else 0
    
    i_idx = np.arange(n)[:, None]  # (n, 1)
    m_idx = np.arange(2*n-1)[None, :]  # (1, 2n-1)
    
    # A indices: i + m - (n-1)
    idx_A = i_idx + m_idx - (n-1)  # (n, 2n-1)
    valid_A = (idx_A >= 0) & (idx_A < n)
    A_vals = np.where(valid_A, 1.0 - h[idx_A.clip(0, n-1)], 0.0)
    
    # B indices: i - m + (n-1)
    idx_B = i_idx - m_idx + (n-1)
    valid_B = (idx_B >= 0) & (idx_B < n)
    B_vals = np.where(valid_B, h[idx_B.clip(0, n-1)], 0.0)
    
    grad = ((A_vals.T @ w) - (B_vals.T @ w)) * dx
    return grad
```

This is O(n²) memory and O(n²) compute per gradient, which for n=250 is about 250×499 ≈ 125K elements. Very fast.
