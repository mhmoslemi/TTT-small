For simplicity, let's ignore the quadratic term (it's small for small d) or handle it separately.

The 1D problem is: min_{d ∈ [d_lo, d_hi]} max_k (a_k + b_k * d)

where a_k = c_k and b_k = s_k.

This is a classic 1D convex optimization. The optimal d is where the "max" function has a kink, i.e., where two lines cross.

Algorithm:
1. Compute all lines (a_k, b_k)
2. The max of these lines is a convex piecewise linear function
3. Find its minimum:
   - At d=0, the active line is k* (the one with max c_k)
   - If b_{k*} < 0, the function is decreasing at d=0, so we should increase d
   - Find the range where k* remains active: [d_left, d_right]
   - If 0 is in this range and b_{k*} < 0, the minimum is at d_right (or the boundary)
   - Etc.

Actually, a simpler approach: since it's a 1D convex problem, use ternary search or binary search on the derivative.

The derivative of max_k (a_k + b_k*d) at point d is b_{k*(d)} where k*(d) = argmax_k (a_k + b_k*d).

If the derivative is positive, we need to decrease d. If negative, increase d.

We can binary search for where the derivative changes sign. But the derivative is piecewise constant (jumping at kink points), so we need to be careful.

Simpler: since the domain [d_lo, d_hi] is bounded and the function is convex, we can use:
1. Evaluate at d_lo, d_mid, d_hi
2. If f(d_mid) < f(d_lo), the minimum is in [d_mid, d_hi]
3. If f(d_mid) < f(d_hi), the minimum is in [d_lo, d_mid]
4. Repeat (ternary search)

```python
def compute_c5(h, n):
    dx = 2.0 / n
    return float(np.max(np.correlate(h, 1.0 - h, mode='full')) * dx)

def project_feasible(h, n):
    h = np.clip(h.copy(), 0.0, 1.0)
    for _ in range(500):
        diff = n / 2.0 - h.sum()
        if abs(diff) < 1e-13:
            break
        if diff > 0:
            room = 1.0 - h
            tot = room.sum()
            if tot < 1e-15:
                break
            h += (diff / tot) * room
        else:
            tot = h.sum()
            if tot < 1e-15:
                break
            h += (diff / tot) * h
    return np.clip(h, 0.0, 1.0)

def fast_cd(h, n, max_passes=300, grid=80, deadline=None, penalty=5.0):

            d_lo = -h[p]
            d_hi = 1.0 - h[p]

def subgradient_phase(h, n, n_iters=2000, deadline=None):

    h = h.copy()
    best = h.copy()
    best_c = compute_c5(h, n)
    dx = 2.0 / n
    c = np.correlate(h, 1.0 - h, mode='full')
    for it in range(n_iters):
        if deadline and time.time() > deadline:
            break
        k_star = int(np.argmax(c))
        offset = k_star - (n - 1)
        # Compute subgradient
        grad = np.zeros(n)
        # Forward contribution: p is first index, j = p + offset
        if offset >= 0:
            for p in range(n - offset):
                grad[p] = 1.0 - h[p + offset]
        else:
            for p in range(-offset, n):
                grad[p] = 1.0 - h[p + offset]
        # Backward contribution: p is second index, i = p - offset
        if offset >= 0:
            for p in range(offset, n):
                grad[p] -= h[p - offset]
        else:
            for p in range(n + offset, n):
                grad[p] -= h[p - offset]
        
        # Step size: decreasing
        step = 0.05 / (1.0 + 0.05 * it)**0.7
        h_new = project_feasible(h - step * grad, n)
        c_new = compute_c5(h_new, n)
        if c_new < best_c:
            best_c = c_new
            best = h_new.copy()
            h = h_new
            c = np.correlate(h, 1.0 - h, mode='full')
        # Also try moving in the negative subgradient direction (since we want to minimize max)
        # Actually, the subgradient of max_k c_k at the current point is grad_{k*}
        # We want to decrease the max, so we move in the -grad direction
        # That's what we're doing: h - step * grad
    return best, best_c
```

Wait, I have a problem with the subgradient phase. The subgradient computation is O(n) per iteration, but I'm doing it with a Python loop which is slow. Let me vectorize it.

For offset = k_star - (n-1):
- Forward: grad[p] += (1 - h[p+offset]) for valid p where 0 <= p+offset < n
- Backward: grad[p] -= h[p-offset] for valid p where 0 <= p-offset < n

Vectorized:

```python
if offset >= 0:
    grad[:n-offset] += 1.0 - h[offset:]
    grad[offset:] -= h[:n-offset]
else:
    grad[-offset:] += 1.0 - h[:n+offset]
    grad[:n+offset] -= h[-offset:]
```

This is O(n) and fully vectorized.
