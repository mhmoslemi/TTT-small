So c_k = P_k + h[i] * Q_k

where:
P_k = S_k + h[i+k]*1_{0≤i+k<n}
Q_k = 1 - h[i-k]*1_{0≤i-k<n} - h[i+k]*1_{0≤i+k<n}

Note that Q_k can be negative! (If both h[i-k] and h[i+k] are close to 1, Q_k ≈ 1-1-1 = -1.)

So C₅ = max_k (P_k + Q_k * h[i]) * dx

This is the max of linear functions of h[i], which is indeed convex in h[i].

To minimize this over h[i] ∈ [0,1], we need to find the value that minimizes the maximum. This is a 1D minimax problem.

The minimum of max_k (P_k + Q_k * x) over x ∈ [0,1] occurs at:
- x = 0 or x = 1 (if the max is achieved at a boundary)
- Or at an intersection point of two lines P_k + Q_k * x = P_j + Q_j * x

This can be solved by finding the lower envelope of the upper convex hull... actually, it's simpler: we binary search for the minimum value.

For a given target value T, we check if there exists x ∈ [0,1] such that P_k + Q_k * x ≤ T for all k. This is a system of linear inequalities in x:
- For Q_k > 0: x ≤ (T - P_k) / Q_k
- For Q_k < 0: x ≥ (T - P_k) / Q_k
- For Q_k = 0: need P_k ≤ T

So the feasible range for x is [max of lower bounds, min of upper bounds] ∩ [0,1].

We can binary search on T to find the minimum T such that this range is non-empty.

This gives us an exact (up to floating point) optimal value for h[i] given all other variables fixed!

For the pair-swap, δ must satisfy:
- 0 ≤ h[i] + δ ≤ 1 → -h[i] ≤ δ ≤ 1 - h[i]
- 0 ≤ h[j] - δ ≤ 1 → h[j] - 1 ≤ δ ≤ h[j]

So δ ∈ [max(-h[i], h[j]-1), min(1-h[i], h[j])]

And we want to minimize max_k (c_k(0) + R[k]*δ) over this interval.

This is a 1D convex minimization problem that can be solved by checking the breakpoints.

```python
def pair_swap_optimize(h, i, j):
    """Find optimal δ for pair swap h[i]+δ, h[j]-δ."""
    n = len(h)
    dx = 2.0 / n
    
    # Compute c_k(0)
    corr = np.correlate(h, 1 - h, mode='full')
    
    # Compute R[k] for each lag k
    # R[k] = h[j-k] + h[j+k] - h[i-k] - h[i+k] (with out-of-bounds = 0)
    # Output index m corresponds to lag k = m - (n-1)
    
    num_k = 2 * n - 1
    R = np.zeros(num_k)
    
    for m in range(num_k):
        k = m - (n - 1)
        r = 0.0
        if 0 <= j - k < n:
            r += h[j - k]
        if 0 <= j + k < n:
            r += h[j + k]
        if 0 <= i - k < n:
            r -= h[i - k]
        if 0 <= i + k < n:
            r -= h[i + k]
        R[m] = r
    
    # Now minimize max_m (corr[m] + R[m] * δ) over δ ∈ [δ_lo, δ_hi]
    δ_lo = max(-h[i], h[j] - 1)
    δ_hi = min(1 - h[i], h[j])
    
    if δ_lo >= δ_hi:
        return None, None
    
    # Find the minimum of a convex piecewise-linear function
    # The breakpoints are where corr[m] + R[m]*δ = corr[m'] + R[m']*δ
    # i.e., δ = (corr[m'] - corr[m]) / (R[m] - R[m'])
    
    # For efficiency, evaluate at a grid and refine
    # With num_k = 189, a grid of 500 points should be fine
    
    δ_vals = np.linspace(δ_lo, δ_hi, 500)
    f_vals = np.max(corr[None, :] + R[None, :] * δ_vals[:, None], axis=1)
    best_idx = np.argmin(f_vals)
    best_δ = δ_vals[best_idx]
    best_val = f_vals[best_idx] * dx
    
    return best_δ, best_val
```

```python
def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1 - h, mode='full')
    return np.max(corr) * dx

    h = np.clip(h, 0, 1)
    diff = target_sum - np.sum(h)
    if abs(diff) < 1e-12:
        return h
    if diff > 0:
        order = np.argsort(h)
        for idx in order:
            add = min(diff, 1.0 - h[idx])
            h[idx] += add
            diff -= add
            if diff <= 1e-12:
                break

            sub = min(-diff, h[idx])
            h[idx] -= sub
            diff += sub
            if diff >= -1e-12:
                break

    n = len(h)

    corr = np.correlate(h, 1 - h, mode='full')
```

```python
    j_pk = j + k_range
    i_mk = i - k_range
    i_pk = i + k_range

    m = (j_pk >= 0) & (j_pk < n)
    if np.any(m):

    m = (i_mk >= 0) & (i_mk < n)
    if np.any(m):
        R[m] -= h[i_mk[m]]
    m = (i_pk >= 0) & (i_pk < n)
    if np.any(m):
        R[m] -= h[i_pk[m]]
    
    d_lo = max(-h[i], h[j] - 1.0)
    d_hi = min(1.0 - h[i], h[j])
    
    if d_lo >= d_hi - 1e-15:
        return 0.0, compute_c5(h)

    f_vals = np.max(corr[None, :] + R[None, :] * d_vals[:, None], axis=1)

    best_d = d_vals[best_idx]
    best_c5 = f_vals[best_idx] * (2.0 / n)
```

```python
        return 0.0, np.max(corr) * dx
    d_vals = np.linspace(d_lo, d_hi, 300)
    f_vals = np.max(corr[None, :] + R[None, :] * d_vals[:, None], axis=1)
    best_idx = int(np.argmin(f_vals))
    return d_vals[best_idx], f_vals[best_idx] * dx

def local_search(h, target, deadline, seed):
    rng = np.random.RandomState(seed)
    n = len(h)
    c5 = compute_c5(h)
    no_improve = 0
    while time.time() < deadline:
        i = rng.randint(n)
        j = rng.randint(n)
        if i == j:
            continue
        d, new_c5 = pair_swap_optimal(h, i, j)
        if abs(d) > 1e-12 and new_c5 < c5 - 1e-12:
            h[i] += d
            h[j] -= d
            c5 = new_c5
            no_improve = 0
        else:
            no_improve += 1
        if no_improve > 5000:
            idx = rng.choice(n, min(15, n // 4), replace=False)
            h[idx] += rng.uniform(-0.3, 0.3, len(idx))
            h = repair(h, target)
            c5 = compute_c5(h)
            no_improve = 0
    return h, c5
```

Wait, actually I realize there's a smarter way to find the optimum of max of linear functions without a grid. The minimum of max_k (a_k + b_k * x) over x ∈ [x_lo, x_hi] occurs at:
- x_lo or x_hi, or
- A point where two of the lines cross and both are the maximum

The set of points where the maximum changes are the breakpoints, which are the upper envelope of the lines. Finding this exactly is O(K log K) where K is the number of lines (using a convex hull trick), but that's complex to implement.

A simpler approach: the minimum of the upper envelope of K lines on [x_lo, x_hi] is at one of the vertices of the upper envelope. The vertices are where pairs of lines intersect. So I can:
1. For each pair (p, q) with b_p ≠ b_q, compute x = (a_q - a_p) / (b_p - b_q)
2. Keep only those x in [x_lo, x_hi]
3. Evaluate f at each candidate x (plus x_lo and x_hi)
4. Return the minimum

This is O(K²) candidates × O(K) evaluation = O(K³) in the worst case. With K = 189, that's 189³ ≈ 6.7 million, which is too slow.

Alternatively, I can be smarter: only the lines that are on the upper envelope matter. But finding them is itself O(K log K).

For practical purposes, the grid approach with 100-300 points is fine. Let me stick with 200 points.
