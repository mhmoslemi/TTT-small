- If i ≥ ℓ: h[i-ℓ](1-h[i])

Wait, that's a key insight! For a single variable h[i], each g_ℓ is LINEAR in h[i] (not quadratic!). Because h[i] appears in g_ℓ only as h[i]*(constant) or (constant)*h[i], never as h[i]*h[i].

minimize_t max_k (a_k * t + b_k)
subject to 0 ≤ t ≤ 1 and sum constraint.

Where a_k and b_k are the coefficient and constant of h[i] in g_k.

This is a 1D convex optimization problem (max of linear functions is convex)!

The optimal t is where the two largest lines cross (or at a boundary).

Each g_k as a function of t:
g_k = (terms not involving i or j) + [terms involving i] + [terms involving j]

  = t*(1-h[i+ℓ]) + h[i-ℓ] - t*h[i-ℓ]

g_k(t) = constant_k + t * (coef_i_k + coef_j_k)

Where coef_i_k = (1 - h[i+ℓ] - h[i-ℓ]) (sum over valid terms for position i at lag ℓ)

import numpy as np
from scipy.optimize import minimize, Bounds
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)

def smooth_max(x, beta):
    m = np.max(x)
    x_shift = np.clip(beta * (x - m), -500, 500)
    return m + np.log(np.sum(np.exp(x_shift)) / len(x)) / beta

def project_h(h, target_sum):
    h = np.clip(h, 0.0, 1.0)
    for _ in range(200):
        diff = target_sum - h.sum()
        if abs(diff) < 1e-14:
            break
        free = (h > 1e-8) & (h < 1.0 - 1e-8)
        if free.sum() == 0:
            free = np.ones(len(h), dtype=bool)
        h[free] += diff / free.sum()
        h = np.clip(h, 0.0, 1.0)
    return h

def slsqp_optimize(h, target_sum, betas, max_iter_each=300):
    N = len(h)
    dx = 2.0 / N
    bounds = Bounds(np.zeros(N), np.ones(N))
    best_h = h.copy()
    best_c5 = compute_c5(h)
    
    for beta in betas:
        def obj(h_in):
            c = np.correlate(h_in, 1.0 - h_in, mode="full")
            return smooth_max(c, beta) * dx
        def con(x_in):
            return np.sum(x_in) - target_sum
        def con_jac(x_in):
            return np.ones(x_in.shape)
        
        constraints = [{'type': 'eq', 'fun': con, 'jac': con_jac}]
        try:
            res = minimize(obj, best_h, method='SLSQP', bounds=bounds,
                           constraints=constraints,
                           options={'maxiter': max_iter_each, 'ftol': 1e-14})
            h_new = project_h(res.x, target_sum)
            c5_new = compute_c5(h_new)
            if c5_new < best_c5:
                best_h = h_new.copy()
                best_c5 = c5_new
        except Exception:
            pass
    return best_h, best_c5
