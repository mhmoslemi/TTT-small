Wait, I'm computing `compute_c5(h_cur)` multiple times in the coordinate descent which is wasteful. Let me optimize.

Also, I realize the coordinate descent approach of pushing to 0 or 1 might be too aggressive. Let me think of a better coordinate descent:

For each coordinate i, given all other coordinates fixed, the objective is:
f(t) = max_k [C_k + t * D_k] * dx

where C_k is the part of corr_k not involving h[i], and D_k is the coefficient of h[i] in corr_k.

Since f(t) is the max of linear functions, it's convex in t. So we can find the minimum over t ∈ [0,1] by:
1. Computing D_k for all k
2. Finding the t that minimizes max_k (C_k + t*D_k)

This is a 1D convex minimization problem! We can solve it exactly or by bisection.

Actually, the minimum of max of linear functions over [0,1] occurs either at t=0, t=1, or at a point where two of the linear functions cross (and are both maximal).

But computing C_k and D_k for each i is O(n) per i (since each i appears in O(n) lags), so total is O(n^2) per sweep, which for n=70 is about 5000 operations. Very fast!

Let me implement this properly:

For coordinate i, h[i] = t:
- For lag k ≥ 0: corr_k = sum_{j=0}^{n-1-k} h[j+k](1-h[j])
  - h[i] appears as h[j+k] when j = i-k (if 0 ≤ i-k ≤ n-1-k), contributing (1-h[i-k])
  - h[i] appears as h[j] when j = i (if 0 ≤ i ≤ n-1-k), contributing -h[i+k]
  - So: corr_k = C_k + t * (1-h[i-k] if valid) + t * (-h[i+k] if valid)
  - D_k = (1-h[i-k] if 0≤i-k≤n-1-k else 0) + (-h[i+k] if 0≤i≤n-1-k else 0)
  - C_k = corr_k - t * D_k (computed with current t = h[i])

- For lag k < 0 (let k' = -k > 0): corr_{-k'} = sum_{j=k'}^{n-1} h[j-k'](1-h[j])
  - h[i] appears as h[j-k'] when j = i+k' (if k'≤i+k'≤n-1, i.e., 0≤i≤n-1-k'), contributing (1-h[i+k'])
  - h[i] appears as h[j] when j = i (if k'≤i≤n-1), contributing -h[i-k']
  - D_{-k'} = (1-h[i+k'] if 0≤i≤n-1-k' else 0) + (-h[i-k'] if k'≤i≤n-1 else 0)
  - C_{-k'} = corr_{-k'} - t * D_{-k'}

So for each i, I compute D_k for all k, C_k = corr_k - h[i]*D_k, then minimize max_k (C_k + t*D_k) over t ∈ [0,1].

The function g(t) = max_k (C_k + t*D_k) is convex piecewise linear. Its minimum can be found by:
- If all D_k ≤ 0: minimum at t = 1
- If all D_k ≥ 0: minimum at t = 0
- Otherwise: find the crossing point

For the general case, we can use binary search on the derivative (subgradient):
- g'(t) = D_k* where k* = argmax_k (C_k + t*D_k)
- We want g'(t) = 0, i.e., D_{k*(t)} = 0, or at a crossing

Actually, the simplest approach for 1D convex minimization is ternary search or just eval at a few points. Since g is convex piecewise linear, the minimum is at a breakpoint or endpoint. The breakpoints are where C_a + t*D_a = C_b + t*D_b, i.e., t = (C_b - C_a)/(D_a - D_b).

But with O(n) breakpoints, finding the minimum is O(n log n) in the worst case. For n=70, that's fine.

Actually, even simpler: since g is convex, we can just use a few evaluations:
- g(0), g(1), and g at the "crossing" point

Or even simpler: just do a few iterations of subgradient: t_{new} = t - alpha * D_{k*(t)}.

Let me just use a simple approach: evaluate at t = 0, t = 1, and t = -C_{k0}/D_{k0} (clipped to [0,1]) for the k with the largest |D_k|.

Actually, the cleanest approach: since g(t) = max_k (C_k + t*D_k) is convex, use the fact that the minimum satisfies 0 ∈ ∂g(t*), i.e., there exists a convex combination of the active D_k's that equals 0. The simplest: use binary search on the subgradient.

```python
def coord_optimize(h, i, target_sum):
    """Optimize h[i] given all other coordinates fixed, maintaining sum constraint."""
    n = len(h)
    dx = 2.0 / n
    t = h[i]
    
    # Compute D_k for all lags
    corr = np.correlate(h, 1.0 - h, mode="full")
    n_corr = len(corr)  # 2n-1
    D = np.zeros(n_corr)
    
    for k_idx in range(n_corr):
        k = k_idx - (n - 1)  # actual lag
        if k >= 0:
            # h[i] as h[j+k] when j=i-k: valid if 0<=i-k<=n-1-k => k<=i<=n-1
            if k <= i:
                D[k_idx] += (1.0 - h[i - k])
            # h[i] as h[j] when j=i: valid if 0<=i<=n-1-k => i<=n-1-k
            if i <= n - 1 - k:
                D[k_idx] += (-h[i + k])
        else:
            kp = -k
            # h[i] as h[j-kp] when j=i+kp: valid if kp<=j<=n-1 => kp<=i+kp<=n-1 => 0<=i<=n-1-kp
            if i <= n - 1 - kp:
                D[k_idx] += (1.0 - h[i + kp])
            # h[i] as h[j] when j=i: valid if kp<=i<=n-1
            if i >= kp:
                D[k_idx] += (-h[i - kp])
    
    # C_k = corr_k - t * D_k
    C = corr - t * D
    
    # Minimize g(t) = max_k (C_k + t * D_k) over t in [0,1]
    # g is convex piecewise linear
    # Use bisection on subgradient
    lo, hi = 0.0, 1.0
    for _ in range(30):
        mid = (lo + hi) / 2
        vals = C + mid * D
        k_star = np.argmax(vals)
        d = D[k_star]
        if d > 1e-10:
            hi = mid
        elif d < -1e-10:
            lo = mid
        else:
            lo = hi = mid
            break
    
    t_opt = (lo + hi) / 2
    
    # Apply: change h[i] from t to t_opt, adjust others to maintain sum
    delta = t_opt - t
    h_new = h.copy()
    h_new[i] = t_opt
    # Distribute -delta among other coordinates
    others = np.arange(n)
    others = others[others != i]
    h_new[others] -= delta / (n - 1)
    h_new = np.clip(h_new, 0.0, 1.0)
    h_new = project_h(h_new, target_sum)
    
    return h_new
```

Wait, but the issue is that when I change h[i], the D_k values change too (because they depend on h). So this is only valid as a first-order approximation. In practice, for small changes it works well, and we can do multiple passes.

But there's a subtlety: the sum constraint. When I change h[i] by delta, I need to change other coordinates to maintain the sum. The simplest is to distribute uniformly, but a better approach is to only change coordinates that have "room" (aren't at 0 or 1).

Actually, for the coordinate descent, I can consider pairs: change h[i] and h[j] simultaneously to maintain the sum. Or I can just do the uniform adjustment and project.

Let me simplify: I'll do coordinate descent where for each i, I optimize h[i] assuming uniform redistribution, then project. This will converge (maybe slowly) to the optimum.

```python
def project_h(h, target_sum):
```

```python
import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)

def project_h(h, target_sum):
    h = h.copy()
    for _ in range(60):
        h = np.clip(h, 0.0, 1.0)
        diff = target_sum - h.sum()
        if abs(diff) < 1e-15:
            break
        free = (h > 1e-14) & (h < 1.0 - 1e-14)
        if free.sum() > 0:
            h[free] += diff / free.sum()
        else:
            h += diff / len(h)
    return np.clip(h, 0.0, 1.0)

def coord_optimize(h, i, target_sum):
    n = len(h)
    t = h[i]
    corr = np.correlate(h, 1.0 - h, mode="full")
    nc = len(corr)
    D = np.zeros(nc)
    for ki in range(nc):
        k = ki - (n - 1)
        if k >= 0:
            if k <= i:
                D[ki] += 1.0 - h[i - k]
            if i <= n - 1 - k:
                D[ki] -= h[i + k]
        else:
            kp = -k
            if i <= n - 1 - kp:
                D[ki] += 1.0 - h[i + kp]
            if i >= kp:
                D[ki] -= h[i - kp]
    C = corr - t * D
    lo, hi = 0.0, 1.0
    for _ in range(40):
        mid = (lo + hi) * 0.5
        ks = np.argmax(C + mid * D)
        if D[ks] > 1e-12:
            hi = mid
        elif D[ks] < -1e-12:
            lo = mid
        else:
            break
    t_opt = (lo + hi) * 0.5
    delta = t_opt - t
    h_new = h.copy()
    h_new[i] = t_opt
    mask = np.ones(n, dtype=bool)
    mask[i] = False
    h_new[mask] -= delta / (n - 1)
    return project_h(h_new, target_sum)

def subgrad_step(h, beta, step):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    mc = np.max(corr)
    p = np.exp(beta * (corr - mc))
    p /= p.sum()
    grad = np.zeros(n)
    for ki in range(len(corr)):
        if p[ki] < 1e-10:
            continue
        k = ki - (n - 1)
        w = p[ki] * dx
        if k >= 0:
            a, b = k, n
            grad[a:b] += w * (1.0 - h[0:b - k])
            a, b = 0, n - k
            grad[a:b] += w * (-h[k:n])
        else:
            kp = -k
            a, b = 0, n - kp
            grad[a:b] += w * (1.0 - h[kp:n])
            a, b = kp, n
            grad[a:b] += w * (-h[0:n - kp])
    return h - step * grad, grad

def make_initial(n, seed_val):
    rng = np.random.RandomState(seed_val)
    phi = (1.0 + np.sqrt(5.0)) / 2.0
    h = np.zeros(n)
    for i in range(n // 2):
        h[int((i * phi) % n)] = 1.0
    h += rng.randn(n) * 0.1
    return project_h(h, n / 2.0)

def run(seed=42, budget_s=1100, **kwargs):
    np.random.seed(seed)
    start_time = time.time()

    def tleft():
        return budget_s - (time.time() - start_time)

    best_h = None
    best_c5 = np.inf

    if 'initial_h_values' in globals() and initial_h_values is not None:
        h0 = np.array(initial_h_values, dtype=float)
        best_h = h0.copy()
        best_c5 = compute_c5(best_h)

    n_list = []
    if best_h is not None:
        n_list.append(len(best_h))
    for n in [50, 60, 70, 80, 90, 100, 120, 140]:
        if n not in n_list:
            n_list.append(n)

    for n in n_list:
        if tleft() < 40:
            break
        ts = n / 2.0
        if best_h is not None and len(best_h) == n:
            h_cur = best_h.copy()
        else:
            h_cur = make_initial(n, seed + n)

        # Phase 1: Coordinate descent (many sweeps)
        c5_cur = compute_c5(h_cur)
        for sweep in range(500):
            if tleft() < 40:
                break
            idx = np.random.permutation(n)
            for i in idx:
                h_try = coord_optimize(h_cur, i, ts)
                c5_try = compute_c5(h_try)
                if c5_try < c5_cur - 1e-14:
                    h_cur = h_try
                    c5_cur = c5_try
                    if c5_cur < best_c5:
                        best_c5 = c5_cur
                        best_h = h_cur.copy()
            # Occasional random restart to avoid stagnation
            if sweep % 50 == 49:
                h_try = h_cur + np.random.randn(n) * 0.02
                h_try = project_h(h_try, ts)
                if compute_c5(h_try) < c5_cur * 1.01:
                    h_cur = h_try
                    c5_cur = compute_c5(h_cur)

        # Phase 2: Subgradient refinement
        if tleft() > 60:
            h_cur = best_h if len(best_h) == n else h_cur
            h_prev = h_cur.copy()
            g_prev = None
            step = 0.003
            no_imp = 0
            for it in range(200000):
                if tleft() < 40:
                    break
                beta = min(50.0 + 0.3 * it, 600.0)
                h_new, g = subgrad_step(h_cur, beta, step)
                if g_prev is not None:
                    s = h_cur - h_prev
                    y = g - g_prev
                    sy, yy = np.dot(s, y), np.dot(y, y)
                    if yy > 1e-18 and sy > 1e-18:
                        step = 0.7 * step + 0.3 * np.clip(np.dot(s, s) / sy, 1e-7, 0.04)
                h_prev = h_cur.copy()
                g_prev = g
                h_new = project_h(h_new, ts)
                c5_new = compute_c5(h_new)
                if c5_new < best_c5:
                    best_c5 = c5_new
                    best_h = h_new.copy()
                    no_imp = 0
                else:
                    no_imp += 1
                h_cur = h_new
                if no_imp > 300:
                    h_cur = best_h.copy()
                    h_prev = h_cur.copy()
                    g_prev = None
                    step = max(step * 0.4, 1e-7)
                    no_imp = 0

        # Phase 3: Final coordinate polish
        if tleft() > 20:
            h_cur = best_h if len(best_h) == n else h_cur
            c5_cur = compute_c5(h_cur)
            for _ in range(50):
                if tleft() < 20:
                    break
                imp = False
                for i in range(n):
                    h_try = coord_optimize(h_cur, i, ts)
                    c5_try = compute_c5(h_try)

                        if c5_cur < best_c5:
                            best_c5 = c5_cur
                            best_h = h_cur.copy()
                if not imp:
                    break

    return best_h, best_c5, len(best_h)
```
