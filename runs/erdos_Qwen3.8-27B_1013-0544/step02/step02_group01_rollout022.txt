Actually, for coordinate descent: fixing all h[i] for i ≠ j, the objective as a function of h[j] is:
F(h[j]) = max_k [corr_k(h[j])] * dx

where corr_k(h[j]) is linear in h[j] for most k (those where h[j] appears) and constant for others.

Specifically, for a given k where h[j] appears:
- If h[j] appears as h[n+s]: corr_k increases by (1-h[n]) per unit increase in h[j]
- If h[j] appears as h[n]: corr_k decreases by h[n+s] per unit increase in h[j]

So corr_k is linear in h[j]: corr_k = a_k * h[j] + b_k

And F(h[j]) = max_k (a_k * h[j] + b_k) * dx, which is a piecewise linear function of h[j]!

The minimum of a piecewise linear convex function over [0,1] is at a vertex or at the intersection of two lines. This can be solved in O(n) time per coordinate (find the max of n lines at the optimal point).

This gives us an exact coordinate descent method! And since each coordinate update is exact (not approximate), this should converge well.

**Coordinate descent algorithm:**
For each coordinate j:
  1. Compute a_k and b_k for all k (2n-1 values)
  2. Find h[j] ∈ [0,1] that minimizes max_k (a_k * h[j] + b_k)
  3. Update h[j]

Step 2 is a 1D problem: minimize a piecewise linear convex function over [0,1]. The minimum occurs at:
- h[j] = 0
- h[j] = 1  
- An intersection point of two lines a_p * x + b_p = a_q * x + b_q

The value at the optimum is the minimum over all breakpoints of the envelope.

Actually, for minimizing the max of linear functions, the optimal point is where the "active" constraints are balanced. This is a 1D linear programming problem:
min t
s.t. a_k * x + b_k ≤ t for all k
     0 ≤ x ≤ 1

This can be solved by finding the point x where the upper envelope of {a_k * x + b_k} is minimized.

The upper envelope of lines is a convex piecewise linear function. Its minimum over [0,1] is at:
- x = 0 if the slope at 0 is ≥ 0
- x = 1 if the slope at 1 is ≤ 0
- Otherwise, at the "knee" where the slope changes from negative to positive

The slope of the upper envelope at a point x is the a_k of the line that's maximal at x. As x increases, different lines become active.

To find the minimum efficiently:
1. Evaluate all lines at x=0 and x=1
2. The minimum of the max is at most min(max at 0, max at 1)
3. But it could be lower at an interior point

For the interior point: sort the lines by their value at x=0. The upper envelope is formed by the "upper hull" of lines. The minimum of the upper envelope is at the leftmost point where the slope becomes non-negative.

Actually, a simpler approach: the minimum of max_k (a_k * x + b_k) over x ∈ [0,1] can be found by binary search on t:
- Is there an x ∈ [0,1] such that a_k * x + b_k ≤ t for all k?
- This is: for all k, if a_k > 0 then x ≤ (t - b_k)/a_k, if a_k < 0 then x ≥ (t - b_k)/a_k
- So we need max_{k: a_k<0} (t-b_k)/a_k ≤ x ≤ min_{k: a_k>0} (t-b_k)/a_k, and 0 ≤ x ≤ 1
- The tightest lower bound is L(t) = max(0, max_{k: a_k<0} (t-b_k)/a_k)
- The tightest upper bound is U(t) = min(1, min_{k: a_k>0} (t-b_k)/a_k)
- Feasible iff L(t) ≤ U(t)

Binary search on t gives the answer in O(n log(precision)) time. But since we're doing this for each coordinate in each sweep, and we have n coordinates, the total per sweep is O(n² log(precision)) which for n=200 is about 200*200*20 = 800,000 operations per sweep. from scipy.interpolate import interp1d
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)

def project_feasible(h, target_sum):
    h = np.clip(h, 0.0, 1.0)
    diff = target_sum - h.sum()
    if abs(diff) > 1e-12:
        h = h + diff / len(h)
        h = np.clip(h, 0.0, 1.0)
        diff2 = target_sum - h.sum()
        if abs(diff2) > 1e-12:
            free = (h > 1e-8) & (h < 1.0 - 1e-8)
            if free.sum() > 0:
                h[free] = h[free] + diff2 / free.sum()
                h = np.clip(h, 0.0, 1.0)
    return h

def smoothmax_val_grad(h, beta):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    m = np.max(corr)
    shifted = beta * (corr - m)
    max_sh = np.max(shifted)
    exps = np.exp(shifted - max_sh)
    sw = np.sum(exps)
    w = exps / sw
    val = (m + (max_sh + np.log(sw)) / beta) * dx
    
    grad = np.zeros(n)
    j = np.arange(n)
    for k in range(len(corr)):
        wk = w[k]
        if wk < 1e-12:
            continue
        s = k - (n - 1)
        js = j - s
        jp = j + s
        ms = (js >= 0) & (js < n)
        mp = (jp >= 0) & (jp < n)
        if ms.any():
            grad[ms] += wk * (1.0 - h[js[ms]])
        if mp.any():
            grad[mp] += wk * (-h[jp[mp]])
    grad *= dx
    return val, grad

def lbfgs_smoothmax(h, beta, maxiter=500):
    n = len(h)
    target = n / 2.0
    
    def obj(x):
        v, _ = smoothmax_val_grad(x, beta)
        return v
    
    def objg(x):
        _, g = smoothmax_val_grad(x, beta)
        return g
    
    from scipy.optimize import Bounds
    bounds = Bounds(np.zeros(n), np.ones(n))
    cons = [{'type': 'eq', 'fun': lambda x: x.sum() - target, 'jac': lambda x: np.ones(n)}]
    
    res = minimize(obj, h, jac=objg, method='SLSQP',
                   bounds=bounds, constraints=cons,
                   options={'maxiter': maxiter, 'ftol': 1e-16})

def compute_c5(h):

    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)

def project_feasible(h, target_sum):
    h = np.clip(h, 0.0, 1.0)
    diff = target_sum - h.sum()
    if abs(diff) > 1e-10:
        h = h + diff / len(h)
        h = np.clip(h, 0.0, 1.0)
        diff2 = target_sum - h.sum()
        if abs(diff2) > 1e-10:

            if free.sum() > 0:
                h[free] = h[free] + diff2 / free.sum()
                h = np.clip(h, 0.0, 1.0)
    return h

def smoothmax_val_grad(h, beta):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")

def coord_descent(h, n_sweeps=200, tol=1e-14):
    n = len(h)
    target = n / 2.0
    for sweep in range(n_sweeps):
        max_change = 0.0
        for j in range(n):
            ch = coord_desc_step(h, j, n)
            max_change = max(max_change, ch)
        h = project_feasible(h, target)
        if max_change < tol:
            break
    return h
