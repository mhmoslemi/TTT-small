**Spectral approach:**
The autocorrelation `b_k = sum_i a_i * a_{k+i}` (for appropriate range) is the inverse DFT of `|FFT(a)|^2` (up to normalization). So minimizing `max(b_k)` is equivalent to making `|FFT(a)|^2` as flat as possible (in a certain sense).

For a random sequence with `a_i > 0` and `sum(a) = 1`, the expected value of `|FFT(a)|_k^2` for `k ≠ 0` is approximately `1/(n^2)` (like a noise floor), while `|FFT(a)|_0^2 = (sum a)^2 = 1`. The peak of `b` is dominated by the `k=0` term in the DFT domain, which corresponds to `b_0 = sum a_i^2`.

To minimize the peak of `b`, we want to minimize `sum a_i^2` (which happens when `a` is as spread out as possible) AND minimize the sidelobes of the DFT.

For a uniform sequence, `b_0 = 1/n` and all other `b_k = 0` (ideal), but in practice with circular autocorrelation, the uniform sequence gives `b_k = 1/n` for all k (due to the rectangular window). With linear autocorrelation, `b_k = (n-|k|)/n^2`.

The key is to design `a` so that the linear autocorrelation is as flat as possible. This is essentially the **minimum peak sidelobe** problem in radar/communications.

**Iterative amplitude adjustment (like the FFA or SCAFSA algorithms):**

1. Start with random positive `a`.
2. Compute `B = FFT(a)` (zero-padded to `2n-1` or next power of 2).
3. In the frequency domain, the autocorrelation is `|B|^2`.
4. We want `|B|^2` to be flat. So project: `B_new = exp(j*phase(B)) * target_amplitude` where target_amplitude is flat except at DC.
5. `a_new = IFFT(B_new)`.
6. Project `a_new` to be non-negative: `a_new = max(a_new, 0)`.
7. Repeat.

This is similar to the Gerchberg-Saxton algorithm used in optics! It alternates between:
- Enforcing flat spectrum (frequency domain constraint)
- Enforcing non-negativity (time domain constraint)

This might be a very effective approach and is quite different from the previous exponentiated gradient method.

def gerchberg_saxton(a0, time_limit, rng):
    a = a0.copy()
    a = np.maximum(a, 0)
    a /= a.sum()
    
    n = len(a)
    N = next_pow2(2*n - 1)  # FFT size
    
    best_a = a.copy()
    best_score = inf
    
    for t in range(time_limit):
        # Forward FFT
        A = np.fft.rfft(a, N)
        
        # Modify amplitude in frequency domain
        # We want |A|^2 to be as flat as possible
        # DC component: |A[0]|^2 = (sum a)^2 = 1
        # For k > 0: we want |A[k]|^2 ≈ constant
        # Target: |A[k]|^2 = 1/(2n) for k > 0 (roughly)
        # Actually, sum |A[k]|^2 = N * sum a_i^2 by Parseval
        # And |A[0]|^2 = 1
        # So sum_{k>0} |A[k]|^2 = N * sum a_i^2 - 1
        
        # Simpler: just flatten |A| for k > 0
        amp = np.abs(A)
        phase = np.angle(A)
        
        # Flatten: set all non-DC amplitudes to the geometric mean
        non_dc_amp = amp[1:]
        target_amp = np.sqrt(np.prod(non_dc_amp))  # geometric mean (could underflow)
        # Better: arithmetic mean
        target_amp = np.mean(non_dc_amp)
        
        new_amp = np.concatenate([[amp[0]], np.full(len(non_dc_amp), target_amp)])
        
        A_new = new_amp * np.exp(1j * phase)
        a_new = np.fft.irfft(A_new, N)[:n]
        
        # Project to non-negative
        a_new = np.maximum(a_new, 0)
        
        # Renormalize
        s = a_new.sum()
        if s < 1e-30:
            break
        a_new /= s
        
        a = a_new
        
        # Score
        b = fft_square(a)
        score = 2 * n * b.max()
        if score < best_score:
            best_score = score
            best_a = a.copy()
    
    return best_a, best_score

import numpy as np
import time

def _next_pow2(x):
    x = int(max(1, x))
    if x <= 1:
        return 1
    return 1 << (x - 1).bit_length()

def _fft_convolve(a):
    n = len(a)
    L = 2 * n - 1
    N = _next_pow2(L)
    fa = np.fft.rfft(a, N)
    b = np.fft.irfft(fa * fa, N).real[:L]
    return np.maximum(b, 0.0)

def _score(a):
    n = len(a)
    s = a.sum()
    if s < 1e-30:
        return float('inf')
    b = _fft_convolve(a)
    return 2.0 * n * b.max() / (s * s)

    a = np.maximum(a0.astype(np.float64).copy(), 0.0)
    s = a.sum()
    if s < 1e-30:
        a = np.ones(len(a)) / len(a)
    else:
        a /= s

    if x <= 1:

We have `a` (length n), zero-padded to N. `A = rfft(a_pad, N)` where `a_pad = [a, 0, 0, ..., 0]` (length N).

`B = A * A` (element-wise). `b_pad = irfft(B, N)` (length N). `b = b_pad[:2n-1]` is the linear convolution.

Now, if we modify `b` to get `b_mod`, and want to find `a_mod` such that `conv(a_mod, a_mod) ≈ b_mod`:

`fft(b_mod, N) = A_mod^2` (where `A_mod = fft(a_mod_padded, N)`)
`A_mod = sqrt(fft(b_mod, N))` (branch choice)

The branch choice: we want `A_mod` to be "close" to `A = fft(a_padded, N)`. Since `A = sqrt(B)` where `B = fft(b, N)`, and `A_mod = sqrt(fft(b_mod, N))`, the natural branch is the one with the same phase as `A`.

So: `A_mod = sqrt(|fft(b_mod, N)|) * exp(i * arg(A))`

This should work. Let me also handle the DC component carefully: `A[0] = sum(a) = 1`, so `A_mod[0]` should be approximately 1.

Actually, `fft(b_mod, N)[0] = sum(b_mod)`. And `sum(b) = sum(conv(a,a)) = (sum(a))^2 = 1`. So `fft(b_mod, N)[0] ≈ 1` if we only modify the peaks.

```python
"""
Optimize non-negative sequence to minimize 2*n*max(conv(a,a))/(sum(a))^2.
Uses three complementary methods:
1. SCAFSA - iterative autocorrelation clipping via FFT
2. Exponentiated gradient with adaptive focus
3. Simulated annealing for fine-tuning
"""
import numpy as np
import time

def _pow2(x):
    x = int(max(1, x))
    if x <= 1:
        return 1
    return 1 << (x - 1).bit_length()

def _fft_conv(a):
    n = int(a.size)
    L = 2 * n - 1
    N = _pow2(L)
    fa = np.fft.rfft(a, N)
    b = np.fft.irfft(fa * fa, N).real[:L]
    return np.maximum(b, 0.0)

def _eval_score(a):
    n = int(a.size)
    s = float(a.sum())
    if s < 1e-30:
        return float('inf')
    b = _fft_conv(a)
    return 2.0 * n * float(b.max()) / (s * s)

def _normalize(a):
    a = np.maximum(np.asarray(a, dtype=np.float64).ravel(), 0.0)
    s = float(a.sum())
    n = a.size
    if s < 1e-30:
        return np.full(n, 1.0/n, dtype=np.float64)
    return a / s

def _random_start(n, rng, amp=3.0):
    z = rng.normal(0, amp, n)
    z -= z.max()
    a = np.exp(z)
    return _normalize(a)

def _anti_start(n, rng, amp=3.0):
    m = n // 2
    v = rng.normal(0, 1, m)
    v = amp * (v - v.mean()) / (v.std() + 1e-30)
    z = np.zeros(n)
    z[:m] = v
    if n % 2 == 0:
        z[m:] = -v[::-1]
    else:
        z[m+1:] = -v[::-1]
        z[m] = 0
    return _normalize(np.exp(z - z.max()))

def _scafsa_optimize(a0, time_limit, rng, verbose=False):
    a = _normalize(a0)
    n = int(a.size)
    N = _pow2(2 * n - 1)
    best_a = a.copy()
    best_sc = float('inf')
    
    clip_mult = 1.3
    min_clip = 1.005
    blend = 0.4
    
    t0 = time.monotonic()
    it = 0
    stall = 0
    
    while time.monotonic() - t0 < time_limit:
        b = _fft_conv(a)
        sc = 2.0 * n * float(b.max())
        
        if sc < best_sc - 1e-12:
            best_sc = sc
            best_a = a.copy()
            stall = 0
        else:
            stall += 1
        
        if verbose and it % 5000 == 0:
            print(f"    SCA it={it} t={time.monotonic()-t0:.1f} sc={sc:.6f} best={best_sc:.6f} clip={clip_mult:.4f}")
        
        if stall > 300:
            a = _normalize(a * np.exp(rng.normal(0, 0.3, n)))
            clip_mult = min(clip_mult + 0.2, 2.5)
            stall = 0
        
        b_max = float(b.max())
        b_mean = float(b.mean())
        clip_lvl = clip_mult * b_mean
        
        if b_max <= clip_lvl * 1.002:
            clip_mult = max(clip_mult * 0.99, min_clip)
            it += 1
            continue
        
        # Modify b: reduce peaks
        excess = np.maximum(b - clip_lvl, 0)
        b_mod = b - blend * excess
        
        # Reconstruct
        B = np.fft.rfft(b_mod, N)
        A = np.fft.rfft(a, N)
        amp_B = np.abs(B)
        ph_A = np.angle(A)
        A_new = np.sqrt(amp_B + 1e-30) * np.exp(1j * ph_A)
        a_new = np.fft.irfft(A_new, N)[:n].real
        a_new = np.maximum(a_new, 0.0)

def _exp_grad_optimize(a0, time_limit, rng, verbose=False, focus0=3.0):
    a = _normalize(a0)
    n = int(a.size)
    best_a = a.copy()
    best_sc = float('inf')
    
    focus = focus0
    focus_rate = 1.012
    focus_max = 500.0
    eta = 0.4
    eta_min = 0.01
    eta_max = 5.0
    eps = 0.01
    
    t0 = time.monotonic()
    it = 0
    stall = 0
    
    while time.monotonic() - t0 < time_limit:
        b = _fft_conv(a)
        sc = 2.0 * n * float(b.max())
        
        if sc < best_sc - 1e-12:
            best_sc = sc
            best_a = a.copy()
            stall = 0
        else:
            stall += 1
        
        if verbose and it % 5000 == 0:
            print(f"    EG it={it} t={time.monotonic()-t0:.1f} sc={sc:.6f} best={best_sc:.6f} f={focus:.1f} eta={eta:.3f}")
        
        if stall > 800:
            a = _normalize(a * np.exp(rng.normal(0, 0.2, n)))
            focus = rng.choice([2.0, 5.0, 10.0, 30.0, 100.0])
            eta = 0.4
            stall = 0
        
        # Make weights
        b_max = float(b.max())
        if b_max < 1e-30:
            break
        z = (b_max - b) / b_max
        p = np.exp(-z * focus)
        s_p = float(p.sum())
        if s_p < 1e-30:
            p = np.zeros_like(b)
            p[int(np.argmax(b))] = 1.0
        else:
            p = (1-eps) * p/s_p + eps/len(b)
        
        # Gradient via FFT
        N = _pow2(2 * n - 1)
        fw = np.fft.rfft(p, N)
        fa = np.fft.rfft(a, N)
        grad = np.fft.irfft(fw * np.conj(fa), N)[:n] * 2.0
        
        # Center gradient
        gd = grad - float(np.dot(a, grad))
        max_g = float(np.max(np.abs(gd)))
        if max_g < 1e-18:
            break
        gd /= max_g
        
        # Update
        a_new = a * np.exp(-eta * gd)
        a_new = np.maximum(a_new, 1e-300)
        a_new /= a_new.sum()
        
        b_new = _fft_conv(a_new)
        sc_new = 2.0 * n * float(b_new.max())
        
        wt_old = float(np.dot(p, b))
        wt_new = float(np.dot(p, b_new))
        
        accept = (sc_new < best_sc - 1e-12) or (sc_new < sc - 1e-12) or (sc_new < sc * 1.002 and wt_new < wt_old - 1e-10)
        
        if accept:
            a = a_new
            eta = min(eta * 1.04, eta_max)
        else:
            eta = max(eta * 0.72, eta_min)
            if eta < 0.03:
                a = _normalize(a * np.exp(rng.normal(0, 0.08, n)))
        
        focus = min(focus * focus_rate, focus_max)
        it += 1
    
    return best_a, best_sc

def _anneal_optimize(a0, time_limit, rng):
    """Fine-tuning with random perturbations (simulated annealing)."""
    a = _normalize(a0)
    n = int(a.size)
    best_a = a.copy()
    best_sc = _eval_score(a)
    
    t0 = time.monotonic()
    temp = 0.05
    it = 0
    
    while time.monotonic() - t0 < time_limit:
        # Random perturbation
        a_trial = a * np.exp(rng.normal(0, temp, n))
        a_trial = _normalize(a_trial)
        
        sc_trial = _eval_score(a_trial)
        sc_cur = _eval_score(a)
        
        if sc_trial < sc_cur or rng.random() < np.exp(-(sc_trial - sc_cur) / max(temp * 0.1, 1e-6)):
            a = a_trial
            if sc_trial < best_sc:
                best_sc = sc_trial
                best_a = a.copy()
        
        # Cool down
        progress = (time.monotonic() - t0) / time_limit
        temp = max(0.001, 0.05 * (1 - progress) ** 2)
        it += 1
    
    return best_a, best_sc
