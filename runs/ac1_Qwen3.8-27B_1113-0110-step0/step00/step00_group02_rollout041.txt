So ∇f_t(x) = 2 * (x ⋆ w) where w = softmax(conv(x,x)).

We can compute this efficiently using FFT: cross-correlation can be done via FFT in O(N log N) time.

Similarly, the objective value f_t(x) = t * log(sum_k exp(conv[k]/t)) can be computed from conv in O(n) time (after computing conv in O(N log N)).

So each gradient evaluation costs O(N log N) where N is the DFT length (>= 2n-1). For n = 6962, N ≈ 13923, and N log N ≈ 13923 * 14 ≈ 195K operations. With numpy FFT, this is very fast (microseconds).

So we can do many iterations of gradient descent!

**Algorithm:**
1. Initialize x (e.g., from parent, normalized to sum = 1)
2. Set t = initial temperature (e.g., t = 0.1 * max(conv) or similar)
3. For each iteration:
   a. Compute conv = x * x (via FFT)
   b. Compute softmax weights w = exp(conv/t) / sum(exp(conv/t))
   c. Compute gradient ∇x = 2 * cross_corr(x, w) (via FFT)
   d. Compute the full gradient of the objective (including the 1/S^2 factor):
      Actually, since we've normalized sum(x) = 1, the objective is just 2n * f_t(x). So the gradient is 2n * ∇f_t(x). But we need to maintain the constraint sum(x) = 1, so we project back after each step.
   e. Update: x_new = x - lr * ∇x (or use a more sophisticated method)
   f. Project: x_new = max(x_new, 0); x_new = x_new / sum(x_new)
   g. Optionally decrease t (annealing)
4. Return the best x found (using the true max, not the smoothed version)

This is essentially a form of "proximal gradient" or "projected gradient descent" with a smoothed max.

sum(x) = 1 and minimize 2*n*max(conv(x,x)). We use:
1. Frequency-domain spectral flattening (GRASP-like) for coarse optimization
2. Smoothed-max gradient descent for fine optimization
3. Multiple random/structured initializations

def _fft_convolve(x, N):
    """Full linear convolution x*x via FFT. Returns array of length 2*len(x)-1."""
    X = np.fft.rfft(x, N)
    return np.fft.irfft(X * X, N)[: 2 * len(x) - 1]

def _freq_flatten_step(x, N, alpha):
    """One step of frequency-domain flattening. Returns new x (unprojected)."""
    X = np.fft.rfft(x, N)
    mag = np.abs(X)
    # Geometric mean as target
    log_mag = np.log(mag + 1e-30)
    target = np.exp(np.mean(log_mag))
    # Blend
    new_mag = np.power(mag + 1e-30, 1.0 - alpha) * np.power(target, alpha)
    phase = np.angle(X)
    X_new = new_mag * (np.cos(phase) + 1j * np.sin(phase))
    x_new = np.fft.irfft(X_new, N)[: len(x)]
    return x_new

def _project(x):
    """Project onto {x >= 0, sum(x) = 1}."""
    x = np.maximum(x, 0.0)
    s = np.sum(x)
    if s < 1e-15:
        n = len(x)
        return np.ones(n) / n
    return x / s

    """
    Compute gradient of f_t(x) = t*log(sum(exp(conv[k]/t)))
    which approximates max(conv) from above.
    Returns (f_t_value, gradient).
    """
    n = len(x)
    conv = _fft_convolve(x, N)
    # Numerically stable log-sum-exp
    c = np.max(conv)
    log_sum = c / t + np.log(np.sum(np.exp((conv - c) / t)))
    f_val = t * log_sum
    # Softmax weights
    w = np.exp((conv - c) / t)

    # Gradient: grad[i] = 2 * sum_j w[i+j] * x[j]
    # = 2 * cross_correlation(x, w)[i]

    w_n = np.fft.fft(w, N)
    grad = 2.0 * np.fft.ifft(x_n * np.conj(w_n)).real[:n]
    return f_val, grad

where softmax_k = exp(conv[k]/t) / sum_j exp(conv[j]/t).

The Lipschitz constant of ∇f_t is bounded by (1/t) * Lipschitz(∇max(conv)) approximately. The Hessian of conv[k] is 2*Q_k (the matrix with 1's on the anti-diagonal for sum=k). The eigenvalues of Q_k can be up to... well, for k=0, Q_0 = I (identity), eigenvalues are all 1. For other k, the eigenvalues are bounded by 1 (since Q_k is a submatrix of the identity "shifted"). Actually, Q_k has at most n non-zero eigenvalues, each bounded by 1 in absolute value (since it's a permutation-like matrix).

So the Hessian of conv[k] has eigenvalues bounded by 2. The Hessian of f_t = t * log(sum exp(conv/t)) has eigenvalues bounded by (1/t) * 2 * max(softmax) ≈ (1/t) * 2 * (1/|active|) where |active| is the number of near-max elements.

For a safe upper bound, L <= 2/t (when only one element is active). So a safe learning rate is lr = 1/L = t/2.
