def coordinate_optimize(a, j):
    """Find optimal a[j] given all other coordinates fixed."""
    n = len(a)
    S = np.sum(a)
    b = np.convolve(a, a)  # current convolution
    
    # Remove contribution of a[j] to get base
    aj = a[j]
    base = b.copy()
    for k in range(n):
        ij = k - j
        if 0 <= ij < n:
            if k == 2*j:
                base[k] -= aj * aj
            else:
                base[k] -= 2 * aj * a[ij]
    
    # Now base[k] is the convolution with a[j] = 0
    # For new x = a[j]:
    # b_new[k] = base[k] + 2*x*a[k-j] (if 0<=k-j<n and k!=2j)
    # b_new[2j] = base[2j] + x^2
    # b_new[k] = base[k] (if not 0<=k-j<n)
    
    # Find the linear coefficients
    # For k where 0 <= k-j < n: linear term is 2*x*a[k-j]
    # For k = 2j: quadratic term is x^2
    
    # Ternary search for x in [0, upper_bound]
    upper = max(1000.0, 2 * aj)

        b_new = base.copy()
        for k in range(n):
            ij = k - j
            if 0 <= ij < n:
                if k == 2*j:
                    b_new[k] += x * x
                else:
                    b_new[k] += 2 * x * a[ij]

        if new_S < 0.01:
            return np.inf

        m2 = hi - (hi - lo) / 3
        if objective(m1) < objective(m2):
            hi = m2
        else:
            lo = m1
    
    return (lo + hi) / 2

For the infinite case: b[k] = sum_{i=max(0,k-n+1)}^{min(n-1,k)} r^k

For k < n: b[k] = (k+1) * r^k (approximately, ignoring boundary)
For k >= n: b[k] = (2n-1-k) * r^k

The peak of (k+1)*r^k is at k ≈ 1/|log(r)| - 1 (maximize (k+1)*r^k: derivative of log((k+1)*r^k) = 1/(k+1) + log(r) = 0, so k+1 = 1/|log(r)|).

max(b) ≈ 1 (at k=0 or k=1)
S ≈ 1/(1-0.5) = 2
objective ≈ 2n*1/4 = n/2. That's terrible for large n!

The problem is that the sum is bounded (S → 1/(1-r)) while n grows. We need S to scale with n.
