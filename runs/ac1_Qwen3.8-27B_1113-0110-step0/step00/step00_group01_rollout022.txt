  grad_k[i] = a[k-i] for i in [0, k] (since k-i >= 0 means i <= k, and k-i < n means k-i < n which is always true if k < n and i >= 0)
  Also need i < n: i < n.
  So for k < n: grad_k[i] = a[k-i] for i in [0, min(k, n-1)]
  
- If k >= n: grad_k[i] = a[k-i] for i in [k-n+1, k] (since k-i < n means i > k-n, and k-i >= 0 means i <= k)
  Also need i in [0, n-1].
  So for k >= n: grad_k[i] = a[k-i] for i in [max(0, k-n+1), min(n-1, k)]
  Since k < 2n-1, k-n+1 < n, and k >= n.
  So: grad_k[i] = a[k-i] for i in [k-n+1, n-1]

So the gradient for a given k is always a contiguous segment of the reversed a.

For efficiency, I'll precompute the reversed a: ar[j] = a[n-1-j].
Then grad_k[i] = a[k-i] = ar[n-1-(k-i)] = ar[n-1-k+i] (if valid).

So grad_k is ar shifted by (n-1-k), clipped to [0, n-1].

This is very efficient to compute!
