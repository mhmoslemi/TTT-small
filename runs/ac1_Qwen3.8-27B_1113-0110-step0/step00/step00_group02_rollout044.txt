I think using $c_k^{p-1}$ as weights (with moderate $p$ like 10-100) is a good approach. It's simpler and avoids the numerical issues of exp.

Actually, let me think about this problem in terms of the discrete Fourier transform. For the circular convolution (DFT), we have:
$(x \circ x)_k = \text{IDFT}(|\text{DFT}(x)|^2)_k$

So to make the circular autocorrelation flat, we need $|\text{DFT}(x)|$ to be flat (all equal), which means $x$ is a chirp (in the complex case). For real sequences, we can't achieve perfectly flat $|\text{DFT}|$, but we can get close.

For the linear convolution, it's more complex, but if we zero-pad $x$ to length $2n$ (or more), the circular convolution of the zero-padded sequence equals the linear convolution. So:
$(x * x)_{\text{linear}} = \text{IDFT}(|\text{DFT}(x_{\text{padded}})|^2)$

where $x_{\text{padded}}$ is $x$ zero-padded to length $2n-1$ (or a power of 2 for FFT efficiency).

So to make the linear convolution flat, we need $|\text{DFT}(x_{\text{padded}})|$ to be as flat as possible, subject to $x_{\text{padded}}$ being non-negative in the first $n$ positions and zero in the rest.

This is a constrained optimization problem in the frequency domain. The constraint is that the IDFT has zeros in the last $n-1$ positions and non-negative values in the first $n$ positions.

This is related to "minimum-entropy" or "flat-spectrum" signal design with constraints.

2. Compute $x = \text{IDFT}(X)$.
3. Project: set $x[n:] = 0$ (enforce zero padding) and $x[0:n] = \max(x[0:n], 0)$ (enforce non-negativity).
4. Recompute $X = \text{DFT}(x)$.
5. Project in frequency: set $|X_k| = 1$ for all $k$ (enforce flat magnitude), keeping the phase.
6. Repeat.
