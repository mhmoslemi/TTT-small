def _peak_cancel(a, n_iters=500, alpha=0.05, deadline=None):

    a = a.copy()
    n = len(a)
    target = np.sqrt(2.0 * n)
    best = a.copy()

            break

        kp = int(np.argmax(c))

            idx = kp - j
            if 0 <= idx < n:
                direction[j] = a[idx]
        # Try to reduce peak: move mass from high-contribution to low-contribution
        # Simple: a_new = a - alpha * direction, clip to non-negative
        a_new = a - alpha * direction
        a_new = np.maximum(a_new, 0.0)
        s = a_new.sum()

            a_new *= target / s
        o = _objective(a_new)
        if o < best_obj:
            best_obj = o
            best = a_new.copy()
            a = a_new
    return best, best_obj

Hmm wait, I think the peak cancellation as I've written it might not work well. The direction `a[kp-j]` is the "autocorrelation kernel" and subtracting it reduces the peak but might create other issues.

Let me think about this differently. A better peak cancellation:

The peak at lag kp is: c(kp) = sum_j a[j] * a[kp-j]

If I reduce a[j] by δ_j (for positions j where a[kp-j] > 0), the change in c(kp) is:
Δc(kp) = -sum_j δ_j * a[kp-j]

And the change in c(k) for other lags is:
Δc(k) = -sum_j δ_j * a[k-j]

I want to choose δ_j to minimize the maximum of (c(k) + Δc(k)) over all k.

This is a linear program! But solving it for n=3809 might be too slow.

A simpler heuristic: choose δ_j proportional to a[j] * a[kp-j] / max_k sum_j a[j] * a[k-j] ... this is getting complicated.

Let me use a different heuristic:
- Find the position j* that contributes most to the peak: j* = argmax_j a[j] * a[kp-j]
- Reduce a[j*] by a small amount
- Add the mass to a position that minimizes the increase in max(c)

For adding mass, a good position is one where a[j] is already small (so adding to it doesn't create a new peak).

Actually, let me just use the gradient of the MAX function (subgradient approach):

The subgradient of max(c(0), ..., c(2n-2)) w.r.t. a[j] is:
- 2 * a[k*-j] (if k* is the unique argmax)

So the subgradient descent step is:
a_new = max(0, a - lr * subgrad)

where subgrad[j] = 2 * a[k*-j] (for valid k*-j).

This is essentially what I had before. Let me use a small learning rate and see if it works.

The issue with subgradient descent is that it's slow (O(1/sqrt(T)) convergence). But for our purposes, even a rough reduction might help.

Let me try a different approach: **direct "mass transfer" moves.**

Move: Pick position i (large value, high peak contribution) and position j (small value, low peak contribution). Transfer mass from i to j.

Specifically:
- i = argmax_j a[j] * a[kp-j] (maximizes reduction of peak)
- j = argmin_k a[k] * a[kp-k] (minimizes increase of peak)
  - Or better: j = position where moving mass doesn't increase any c(k) significantly

For j, a good choice is a position where a[kp-j] is small AND a[j] itself is small (so adding to it doesn't create new peaks at other lags).

Let me implement this:

```python
def _peak_transfer(a, deadline, rng):
    n = len(a)
    target = np.sqrt(2.0 * n)
    best = a.copy()
    best_obj = _objective(a)
    no_improve = 0
    while time.monotonic() < deadline and no_improve < 500:
        c = np.convolve(a, a)
        kp = int(np.argmax(c))
        # Find best donor and receiver
        contrib = np.zeros(n)
        for j in range(n):
            idx = kp - j
            if 0 <= idx < n:
                contrib[j] = a[j] * a[idx]
        # Donor: max contribution
        i = int(np.argmax(contrib))
        # Receiver: min value (to avoid creating new peaks)
        # But also avoid positions that contribute to the peak
        # Use a combined score: low value AND low peak contribution
        receiver_score = a + 0.1 * contrib  # prefer low value and low contribution
        j = int(np.argmin(receiver_score))
        if i == j:
            no_improve += 1
            continue
        # Transfer a fraction of a[i] to a[j]
        frac = 0.05 * (1.0 + 0.5 * rng.random())
        transfer = frac * a[i]
        a_new = a.copy()
        a_new[i] -= transfer
        a_new[j] += transfer
        a_new = np.maximum(a_new, 0.0)
        s = a_new.sum()
        if s > 1e-12:
            a_new *= target / s
        o = _objective(a_new)
        if o < best_obj:
            best_obj = o
            best = a_new.copy()
            a = a_new
            no_improve = 0
        else:
            no_improve += 1
    return best, best_obj
```
