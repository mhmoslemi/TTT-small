b[n-1] = sum_{i=0}^{n-1} (i+1)(n-i) = sum_{i=0}^{n-1} (i+1)(n-i)
= sum_{i=0}^{n-1} (n(i+1) - i(i+1))
= n * sum(i+1) - sum(i²+i)
= n * n(n+1)/2 - (n(n+1)(2n+1)/6 + n(n+1)/2)
= n²(n+1)/2 - n(n+1)(2n+1)/6 - n(n+1)/2
= n(n+1)[n/2 - (2n+1)/6 - 1/2]
= n(n+1)[3n/6 - (2n+1)/6 - 3/6]
= n(n+1)(3n - 2n - 1 - 3)/6
= n(n+1)(n-4)/6

S² = n²(n+1)²/4.
S²/n = n(n+1)²/4.

For b[n-1] < S²/n: n(n+1)(n-4)/6 < n(n+1)²/4
(n-4)/6 < (n+1)/4
4(n-4) < 6(n+1)
4n - 16 < 6n + 6
-22 < 2n
n > -11.

This is always true for n ≥ 1! So b[n-1] < S²/n for the linearly increasing sequence.

But we need to check ALL lags, not just the center. Let me check the peak.

For a[i] = i+1 (linearly increasing), the convolution is:
b[k] = sum_{i=max(0,k-n+1)}^{min(n-1,k)} (i+1)(k-i+1)

For k = 2n-2 (the last position): b[2n-2] = a[n-1]² = n².
S² = n²(n+1)²/4. S²/n = n(n+1)²/4 ≈ n³/4.
For large n, n² < n³/4, so b[2n-2] < S²/n. Good.

For k = n-1 (center): b[n-1] = n(n+1)(n-4)/6 ≈ n³/6.
S²/n ≈ n³/4. n³/6 < n³/4. Good.

What about intermediate k? Let me check k = n-2:
b[n-2] = sum_{i=1}^{n-1} (i+1)(n-1-i+1) = sum_{i=1}^{n-1} (i+1)(n-i)
= sum_{i=0}^{n-1} (i+1)(n-i) - 1*n
= n(n+1)(n-4)/6 - n
= n[n(n-4)/6 - 1]
= n(n²-4n-6)/6

For large n, this is ≈ n³/6, similar to b[n-1].

What about k = 2n-3?
b[2n-3] = a[n-2]*a[n-1] + a[n-1]*a[n-2] = 2*(n-1)*n = 2n(n-1) ≈ 2n².
S²/n ≈ n³/4. For n > 8, 2n² < n³/4. Good.

So for large n, the peak is at the center (or near it), with value ≈ n³/6, and S²/n ≈ n³/4. Since n³/6 < n³/4, the score would be:
score = 2*n*(n³/6)/(n²(n+1)²/4) = 2n⁴/6 * 4/(n²(n+1)²) = 8n²/(6(n+1)²) ≈ 8/6 = 4/3.

Wait, that gives score ≈ 4/3 again! Let me recompute more carefully.

score = 2*n*max_b/S².

For the linear sequence a[i] = i+1:
S = n(n+1)/2.
S² = n²(n+1)²/4.
b[n-1] = n(n+1)(n-4)/6.

score = 2*n*n(n+1)(n-4)/6 / (n²(n+1)²/4)
= 2n²(n+1)(n-4)/6 * 4/(n²(n+1)²)
= 8(n-4)/(6(n+1))
= 4(n-4)/(3(n+1))

For n = 100: score = 4*96/(3*101) = 384/303 ≈ 1.267.
For n = 1000: score = 4*996/(3*1001) = 3984/3003 ≈ 1.327.
For n → ∞: score → 4/3 ≈ 1.333.

So the linearly increasing sequence gives a score approaching 4/3 from below! That's great!
