Let me think about a better approach. Actually, the issue is that we're trying to minimize the max, which is a non-smooth objective. The gradient of the max is only defined where the max is attained (and is a subgradient otherwise).

A better approach might be to use the "water-filling" idea: at each step, identify the bins that are "too high" (above the target) and push them down by adjusting a.

But I think the gradient descent approach with the soft max should work, especially with sufficient iterations and a good learning rate schedule.

For n=3, we found objective 1.875. Can we do better?

For n=3, a=(a,b,c), the convolution is (a², 2ab, 2ac+b², 2bc, c²).
We want to minimize 6*max(a², 2ab, 2ac+b², 2bc, c²)/(a+b+c)².

By symmetry, we can assume a ≥ c (or a ≤ c). Let's try to make all 5 bins equal:
a² = 2ab = 2ac+b² = 2bc = c²

From a² = c²: a = c (assuming positive). Then 2ab = 2ac → b = c. And 2ac+b² = 2a²+a² = 3a² ≠ a². Contradiction.

So we can't make all equal. Let's minimize the max.

By symmetry, the best is probably a = c (symmetric sequence). Then:
c = (a², 2ab, 2a²+b², 2ab, a²)
max = max(a², 2ab, 2a²+b²)
sum = 2a+b

Let x = b/a: minimize 6(2+x²)/(2+x)²
d/dx [(2+x²)/(2+x)²] = [2x(2+x)² - (2+x²)*2(2+x)] / (2+x)^4
= 2x(2+x)[(2+x) - (2+x²)] / (2+x)^4
= 2x(2+x)(2+x-2-x²) / (2+x)^4
= 2x(2+x)(x-x²) / (2+x)^4
= 2x²(2+x)(1-x) / (2+x)^4
= 2x²(1-x) / (2+x)³

Setting = 0: x=0 or x=1.

x=1: value = 3/9 = 1/3, objective = 6/3 = 2.
