6. Repeat

    for _ in range(n_iters):
        c = np.convolve(a, a)
        M = c.max()
        # Reduce contributions to the peak
        # The peak is at some k*. For each i, a[i] contributes a[k*-i] to c[k*]
        k_star = np.argmax(c)

Let me just use the simpler O(n^2) approach since n=6733 gives ~45M operations which is fine.

Actually, for the "multi-peak" approach, I don't even need the exact pressure. I can just use the convolution values directly:

**Simplified Approach:**
1. Compute c = convolve(a, a)
2. Identify "hot" lags: where c[k] > threshold * max(c)
3. For each hot lag k, the "pressure" on a[j] is proportional to a[k-j]
4. Update: a[j] *= exp(-eta * total_pressure[j] / max(c))
5. Renormalize

The total pressure is:
total_pressure[j] = sum_{k in hot} a[k-j] = convolve(hot_indicator, a)[j] (cross-correlation)

I can compute this using FFT for efficiency.
