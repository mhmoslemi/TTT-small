For a uniform distribution on a set A of size m, the peak of the self-convolution is max_k |A ∩ (k-A)| / m² where |A ∩ (k-A)| is the number of pairs (a,b) in A² with a+b=k.

The minimum over all sets A of size m in [n] of max_k r_A(k) where r_A(k) = |{(a,b) in A² : a+b=k}|.

This is related to the "additive energy" and "doubling" of sets.

For a random set of size m in [n], the expected max is about m²/n * log(n)/n or something... actually for a random set, r_A(k) is approximately Poisson with mean m²/n, and the max over O(n) values is about m²/n + O(m/sqrt(n)).

Actually, let me reconsider the problem. Maybe I should think about it in terms of the DFT.

The convolution theorem says: DFT(x*x) = DFT(x) * DFT(x) (pointwise).

The peak of x*x in the time domain is related to the L1 norm of DFT(x)² in the frequency domain (by the inversion formula). Specifically:
(x*x)[k] = (1/N) * sum_m |DFT(x)_m|² * exp(2πimk/N) (for cyclic convolution of length N)

For linear convolution, it's more complicated, but the idea is similar.

The maximum of (x*x)[k] is bounded by (1/N) * sum_m |DFT(x)_m|² = (1/N) * N * sum x[i]² = sum x[i]² (by Parseval).

This gives the bound max(x*x) <= sum(x[i]²), which we already knew.

But we can get a tighter bound if DFT(x) has special structure. If DFT(x) is "flat" (all frequency components have similar magnitude), then (x*x)[k] would be approximately constant, and the max would be close to the average.

sum_k (x*x)[k] / (2n-1) = (sum x)² / (2n-1)
