**Goal**  
Find a step‑function `h` on `[0,2]` (discretised with `n` points) that satisfies  

* `0 ≤ h[i] ≤ 1` for all `i`  
* `∑ h[i]·dx = 1`  (with `dx = 2/n`)  

and minimises  

```
C5 = max_k   ∫₀² h(x)·(1−h(x+k)) dx .
```

Equivalently  

```
C5 = 1 – min_k  ∫₀² h(x)·h(x+k) dx .
```

Hence we must **maximise the smallest autocorrelation** of `h`.  
The objective is a maximum of *quadratic* forms in `h`, which makes the problem non‑convex.  
The strategy below solves a *convex relaxation* of the quadratic terms, extracts a high‑quality feasible `h`, and then refines it with a fast projected‑gradient local search.

The whole pipeline fits comfortably into the 600 s budget and works with the allowed libraries (NumPy, SciPy, CVXPY, any of the listed LP/MIP solvers).

### 1. Discretisation and Notation

* Choose a modest number of sample points `n`.  
  *If `initial_h_values` is present, use its length (≈ 70).  
  *Otherwise take `n = 80` – small enough for the LP but enough resolution.  
* `dx = 2.0 / n`.  
* Vector `h ∈ ℝⁿ` holds the step values.  

For a shift `s = −(n−1)…(n−1)` the discrete autocorrelation term is  

```
A_s(h) = dx·∑_{i=0}^{n-1-s} h[i]·h[i+s]        (s ≥ 0)
A_{-s}(h) = A_s(h)                              (symmetry)
```

and the overlap integral is  

```
C_s(h) = dx·(∑ h[i] – A_s(h))  = 1 – A_s(h) .
```

The optimisation target is  

```

subject to t ≥ C_s(h)   for all shifts s .
```

### 2. Convex Relaxation via McCormick Envelopes (Linear Program)

The only non‑linear part is the product `h[i]·h[j]`.  
For variables confined to `[0,1]` the convex hull of the product is described by the four **McCormick constraints**:

```
p_{ij} ≤ h_i
p_{ij} ≤ h_j
p_{ij} ≥ h_i + h_j – 1
p_{ij} ≥ 0
```

where `p_{ij}` is a new variable standing for `h_i·h_j`.  
These constraints are *exact* when `h` is binary, and otherwise they give the tightest possible linear outer‑approximation of the bilinear term.

**Variables**
* `h[i]` (continuous, 0 ≤ h[i] ≤ 1) for i = 0…n−1
* `p[i,j]` (continuous, 0 ≤ p[i,j] ≤ 1) for all i ≤ j (symmetry `p[i,j]=p[j,i]`)
* scalar `t` (the upper bound on the overlap)

**Linear constraints**

1. **Box & mass**  
   `0 ≤ h[i] ≤ 1` for all i.  
   `∑ h[i] = n/2`  (guarantees ∫h = 1).

2. **McCormick envelope** (only for i ≤ j, the other half is forced by symmetry)  

```
p[i,j] ≤ h[i]          (i≤j)
p[i,j] ≤ h[j]
p[i,j] ≥ h[i] + h[j] – 1
p[i,j] ≥ 0
```

3. **Shift autocorrelation constraints** – for each integer shift `s` (‑(n‑1) … (n‑1))  

```
∑_{i : 0≤i,i+s<n} p[i, i+s]  ≥  (∑ h[i]) – t/dx   .
```

Because `∑ h[i] = n/2` is a constant, the right‑hand side is a linear expression in `t`.

4. **Symmetry (optional but valuable)** – force the step function to be symmetric around the centre of the interval:  

```
h[i] = h[n‑1‑i]   for all i .
```

Adding these equalities reduces the search space and exploits the natural invariance of the problem.

**Objective**  

```
minimise   t .
```

All constraints are linear; the problem is a pure linear program (LP).

### 5. Local Refinement – Projected Soft‑max Gradient Descent

The LP provides an excellent starting point, but the true objective involves the *maximum* of many quadratic forms.  
A smooth surrogate is the **log‑sum‑exp** (soft‑max) of the correlation vector:

```
f_β(h) = (1/β)·log( ∑_s exp( β·C_s(h) ) ) .
```

For large β this approaches `max_s C_s(h)`; for moderate β it yields a differentiable objective whose gradient is a weighted average of the gradients of the individual shifts.

**Gradient of a single shift**  
For a shift `s` the gradient of `C_s(h)` w.r.t. `h[m]` is  

```
∂C_s/∂h[m] = (1 - h[m+s])  –  h[m‑s]    (indices out of range give 0) .
```

All gradients are multiplied by `dx`.

**Algorithm (per iteration)**  

1. Compute the full correlation vector `c = correlate( h , 1‑h , mode='full') * dx`.  
2. Choose a smoothing parameter β (start ≈ 5, increase slowly to ≈ 30).  
3. Form weights  
   `w_s = exp( β·(c_s – max(c)) ) / ∑ exp(…)`.  
   The subtraction of `max(c)` prevents overflow.  
4. Form the gradient `g = Σ_s w_s·∇C_s(h)` (using the formula above).  
5. Take a step: `h̃ = h – η·g`, where η is a **step size** (initially η≈ 5·dx, i.e. about 0.1 for n≈70).  
6. **Projection onto the feasible set**  
   * Clip to the box `[0,1]`.  
   * Adjust to satisfy the mass constraint exactly using a simple **water‑filling** (bisection on a Lagrange multiplier λ):  
     `h_new[i] = clip( h̃[i] – λ , 0 , 1 )` with λ chosen so that `∑ h_new = n/2`.  
   * (Optional) Enforce symmetry again: `h_new = (h_new + reverse(h_new))/2`.  
7. Evaluate `c5_new = max(correlate( h_new , 1‑h_new ))·dx`.  
   Keep the best `h` ever seen.  
8. Adapt η: if `c5_new` did not improve for, say, 200 iterations, halve η; otherwise increase η gently (e.g. multiply by 1.02).  
9. Increase β gradually (e.g. β ← min(β+0.5, 30)) to sharpen the approximation as we approach a local optimum.

**Stopping criteria** – run until the allocated time slice (≈ 0.9 · budget) is exhausted, or until no improvement has been observed for a several thousand iterations.
