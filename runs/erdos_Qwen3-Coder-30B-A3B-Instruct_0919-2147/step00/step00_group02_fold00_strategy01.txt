**1. Mathematical formulation**

- The unknown is a step‑function  \(h:[0,2]\to[0,1]\).  
- Discretise the interval with a uniform grid of size \(n\) (the number of samples).  
  *Grid step* \(dx = 2/n\).  
  *Vector representation* \(h = (h_0,\dots ,h_{n-1})\), where each entry corresponds to the value of \(h\) on a sub‑interval of length \(dx\).

- **Constraints**
  1. **Box**: \(0 \le h_i \le 1\) for all \(i\).  
  2. **Mass**: \(\sum_{i=0}^{n-1}h_i\,dx = 1\)  ↔ \(\sum_i h_i = n/2\).  
  The feasible set is the **capped simplex** \(\{h\in[0,1]^n \mid \mathbf{1}^\top h = n/2\}\).

- **Objective**
  The “overlap” for a shift \(k\) (in grid units) is  
  \[
  F_k(h)=\int_0^2 h(x)\bigl(1-h(x+k\,dx)\bigr)\,dx
        =dx\sum_{i=0}^{n-1-k}h_i\bigl(1-h_{i+k}\bigr)
  \quad(k\ge0)
  \]
  (negative lags are handled symmetrically).  
  In discrete form this is exactly the **cross‑correlation**
  \[
  f = \operatorname{corr}\bigl(h,\,\mathbf{1}-h\bigr)
  \qquad\Longrightarrow\qquad
  F_k = dx\; f_{k+n-1}.
  \]
  The constant we want to minimise is
  \[
  C_5(h)=\max_{k}F_k(dx)=dx\;\max_{k}f_{k+n-1}.
  \]

**2. Smooth surrogate for the max**

Directly minimising a max is non‑differentiable. Introduce a smooth approximation
\[
G_\alpha(h)=\frac{1}{\alpha}\log\Bigl(\sum_k e^{\alpha\,f_k}\Bigr),
\]
with a “temperature” \(\alpha>0\). As \(\alpha\to\infty\), \(G_\alpha \to \max_k f_k\).  
For a given \(\alpha\) we can compute gradients analytically; a continuation
strategy (gradually increase \(\alpha\)) will drive the solution towards the true max‑minimum.

**3. Gradient of the surrogate**

Write the unscaled correlation vector \(f\) (length \(2n-1\)).  
Define weights
\[
w_k = \frac{e^{\alpha f_k}}{\sum_j e^{\alpha f_j}},\qquad \sum_k w_k=1.
\]

For a fixed lag \(k\) the (unscaled) overlap is
\[
f_k = \sum_i h_i - \sum_i h_i\,h_{i+k}.
\]
Hence the partial derivative w.r.t. a component \(h_i\) is
\[
\frac{\partial f_k}{\partial h_i}=1-
\bigl(h_{i+k}+h_{i-k}\bigr),
\]
where out‑of‑range indices are interpreted as 0.
The gradient of the surrogate is a weighted sum:
\[
\frac{\partial G_\alpha}{\partial h_i}
=dx\!\sum_k w_k\bigl[1-(h_{i+k}+h_{i-k})\bigr]
=dx\Bigl(1-\underbrace{\sum_k w_k h_{i+k}}_{\text{term}_1}
           -\underbrace{\sum_k w_k h_{i-k}}_{\text{term}_2}\Bigr).
\]
Both \(\text{term}_1\) and \(\text{term}_2\) are **convolutions** of the weight
vector with the current \(h\); they can be evaluated in \(O(n^2)\) with simple
slicing loops (fast enough for \(n\le200\)) or via FFT if desired.

**4. Projection onto the capped simplex**

After a gradient step we obtain a raw vector \(z\). To enforce the constraints we
project onto \(\{0\le x\le1,\; \mathbf{1}^\top x = n/2\}\).  

The projection has the closed form:
\[
x_i = \operatorname{clip}(z_i-\lambda,0,1),
\]
with a single scalar \(\lambda\) chosen so that \(\sum_i x_i=n/2\).
Because the sum is monotone in \(\lambda\), a **bisection** on \(\lambda\) finds the
correct value in a few dozen iterations (tolerance \(10^{-9}\) is sufficient).
