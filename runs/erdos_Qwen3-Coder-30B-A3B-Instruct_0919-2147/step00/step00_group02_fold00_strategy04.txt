### 1.  Problem restatement in discrete form  

*Choose a uniform grid of size `n` on the interval \([0,2]\) (step \(dx=2/n\)).*  
A step‑function is represented by a vector  

\[
h=(h_0,\dots ,h_{n-1}),\qquad 0\le h_i\le 1,
\]

with the mass constraint  

\[
\sum_{i=0}^{n-1}h_i = n/2 .
\]

For a shift of `k` grid steps (positive or negative) the overlap integral is  

\[
F_k(h)=dx\sum_{i=0}^{n-1-|k|}h_i\bigl(1-h_{i+|k|}\bigr),
\]

and the quantity to be minimised is  

\[
C_5(h)=\max_{k}F_k(h).
\]

### 2.  A radically different parametrisation  

Instead of working with a value at every grid point, **describe the function as a small number of constant blocks** (a piecewise‑constant representation).  

* **Number of blocks** – choose a modest integer `M` (e.g. 8 – 15).  
* **Variables** –  
  * widths \(w_1,\dots,w_M>0\) with \(\sum_{m=1}^{M}w_m=2\);  
  * heights \(a_1,\dots,a_M\in[0,1]\).  

The continuous step‑function is  

\[
h(x)=a_m\quad\text{for }x\in\Bigl[\sum_{j< m}w_j,\;\sum_{j\le m}w_j\Bigr).
\]

The discrete grid values required by the evaluator are obtained by sampling this function at the `n` uniformly spaced points (or, equivalently, by assigning each grid node to the block in which it falls).

The constraints become  

\[
\sum_{m=1}^{M} a_m w_m = 1 .
\]

Thus the optimisation lives in a **low‑dimensional continuous space** (\(2M\) variables) while still honouring the original box constraints.

### 3.  Exact evaluation of the max‑overlap for a piecewise‑constant shape  

For two blocks \(m\) and \(\ell\) the contribution to the overlap for a shift \(\tau\) (continuous, not limited to grid steps) is simply  

\[
\text{contrib}_{m,\ell}(\tau)=a_m\bigl(1-a_\ell\bigr)\,
\operatorname{len}\bigl(I_m\cap(I_\ell-\tau)\bigr) ,
\]

where \(I_m\) is the interval occupied by block \(m\) and “\(-\tau\)” denotes a translation.  
The length of the intersection of two intervals is a **piecewise‑linear** function of \(\tau\); it changes only when an endpoint of one interval aligns with an endpoint of the other. Consequently the total overlap  

\[
F(\tau)=\sum_{m,\ell}\text{contrib}_{m,\ell}(\tau)
\]

is a piecewise‑linear function of \(\tau\) whose breakpoints are **all pairwise differences of interval endpoints**. There are at most  

\[
K_{\max}=M(2M-1)
\]

such breakpoints (each block supplies a left‑ and a right‑endpoint).  

*Algorithm to obtain the exact max:*  

1. Collect all endpoint positions \(\{0,\;w_1,\;w_1+w_2,\dots ,2\}\).  
2. Form the set of all differences \(\Delta=\{e_i-e_j\}\) (both signs).  
3. For each \(\tau\in\Delta\) compute \(F(\tau)\) by a double loop over the blocks (cost \(O(M^2)\)).  
4. The maximum of this finite set equals the true \(\max_{\tau}F(\tau)\) because a piecewise‑linear function attains its maximum at a breakpoint.  

Thus a single objective evaluation costs only a few hundred elementary operations even for `M=15`.

### 4.  Global black‑box optimisation on the low‑dimensional space  

Since the objective is now cheap to evaluate and the search space is low‑dimensional, we can afford a **global stochastic optimiser** that does not rely on gradients. The plan is to use a **Covariance Matrix Adaptation Evolution Strategy (CMA‑ES)** (or, if preferred, Differential Evolution) because:

* It adapts its search distribution automatically, which greatly reduces the need to tune step‑sizes.  
* It works well on non‑convex, non‑smooth problems.  
* It only requires objective evaluations.

**Encoding of a candidate:**  

* **Widths** – generate `M-1` ordered numbers \(u_1<\dots<u_{M-1}\) uniformly in \([0,1]\); set  

  \[
  w_1=2u_1,\quad w_m = 2(u_m-u_{m-1})\;(2\le m\le M-1),\quad
  w_M = 2(1-u_{M-1}).
  \]  

  This guarantees positivity and \(\sum w_m =2\).

* **Heights** – sample raw values \(b_m\in[0,1]\), then enforce the mass constraint \(\sum a_m w_m =1\) by a **capped‑simplex projection** on the vector \((b_1,\dots,b_M)\) with the custom total \(T = 1/\!\bigl(\sum w_m\bigr)=1/2\) after scaling by the widths. In practice:  
  1. Compute raw heights \(b_m\).  
  2. Form \(c_m=b_m w_m\).  
  3. Project \(c\) onto the simplex \(\{c\ge0,\;\sum c =1\}\) using the standard “water‑filling” bisection;  
  4. Set the final heights \(a_m=c_m/w_m\).  
  This gives a feasible point satisfying both box constraints and the integral constraint.

**Population and termination:**  

* Population size: `pop = 4 + floor(3*log(2M))` (standard CMA‑ES rule).  
* Maximum number of objective evaluations: allocate roughly 0.8 × `budget_s` seconds (≈ 480 s). Empirically each evaluation is sub‑millisecond, so we can afford tens of thousands of evaluations.  
* Stop when either a preset evaluation budget (e.g. 30 000 evaluations) is reached or when the improvement of the best objective over the last 500 evaluations falls below \(10^{-7}\).  

**Multiple restarts:**  

CMA‑ES is stochastic; after a restart (new random seed) we keep the best overall solution. Restart if (i) the current best does not improve for a while, or (ii) the elapsed time exceeds 0.7 × budget. Typically 3–5 restarts are sufficient.

### 5.  Fine‑tuning on a finer uniform grid  

The piecewise‑constant representation is already a step‑function, but the evaluator expects a uniform grid. Once the CMA‑ES finishes, we:

1. Sample the best continuous block description on a **moderately dense grid** (e.g. `n = 200` points).  
2. Apply the **capped‑simplex projection** one final time to guarantee the exact mass constraint on the discrete grid (tiny rounding errors may appear after sampling).
