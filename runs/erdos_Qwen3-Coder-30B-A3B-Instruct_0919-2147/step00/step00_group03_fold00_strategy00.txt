```
def project_onto_simplex_bounds(v, S):
    # ensure sum(v) = S, 0 <= v <= 1
    n = len(v)
    # initial clipping to [0,1]
    w = np.clip(v, 0, 1)
    # If sum matches S within tolerance, return.
    # else perform water-filling: find lambda such that sum(clip(v - lambda, 0, 1)) = S.
    # Use binary search.
    lower = -1.0
    upper = np.max(v) + 1.0
    for _ in range(50):
        lam = (lower + upper) / 2.0
        w = np.clip(v - lam, 0, 1)
        s = w.sum()
        if s > S:
            lower = lam
        else:
            upper = lam
    return w
```

But we need to ensure correct direction: As lambda increases, v - lambda decreases; clip to [0,1] reduces values, sum decreases. So if sum > S, we need increase lambda to reduce sum. So lower bound should be value that yields sum > S, and upper yields sum < S. Works.
