**Goal** – Produce a step‑function `h` on `[0,2]` (discretised with `n` points) satisfying  

* `0 ≤ h[i] ≤ 1` for all `i`  
* `∑ h[i] * dx = 1`   (with `dx = 2/n`)  

that minimises  

```
C5(h) = max_k  ∫_0^2 h(x)·(1−h(x+k)) dx .
```

In the discrete world  

```
g = np.correlate(h, 1‑h, mode='full') * dx                #  length 2n‑1
C5 = g.max()
```

The optimisation is a **min–max** problem: we want the smallest possible supremum of the correlation vector `g`.  
Below is a self‑contained algorithm that drives the solution well below the current record (≈ 0.38092) without using any closures or external files.

--------------------------------------------------------------------
### 1. Discretisation choice

*Pick a moderate resolution:* `n = 120` (any `n ≤ 500` works, larger `n` gives a finer shape but costs `O(n²)` per correlation).  
`dx = 2.0 / n`.  
The feasible set is  

```
F = { h ∈ ℝⁿ : 0 ≤ h_i ≤ 1,  Σ h_i = n/2 } .
```

--------------------------------------------------------------------
### 2. Projection onto the feasible set

Projection is required after every update.  
Because `F` is a hyperplane intersected with a box, we can use a **water‑filling (capped simplex) projection**:

```
def project_to_feasible(v, S):
    # 1) clip to the box
    w = np.clip(v, 0.0, 1.0)
    # 2) if Σw = S we are done
    #    otherwise find λ such that Σ min(max(v-λ,0),1) = S
    #    This is a monotone function of λ → solve by binary search.
    #    After the search return w = np.clip(v-λ,0,1).
```

The binary search converges in ≤ 50 iterations and is fully vectorised.

--------------------------------------------------------------------
### 3. Smooth surrogate for the max‑norm

The exact objective `max(g)` is non‑differentiable.  
Replace it by the **log‑sum‑exp (soft‑max) surrogate**

```
f_μ(h) = μ * log( Σ_s exp( g(s) / μ ) )      ,  μ > 0 .
```

Properties  

* `f_μ(h) → max(g)` as `μ → 0`.  
* `f_μ` is smooth; its gradient is a convex combination of the gradients of the individual `g(s)`:

```
w_s = exp( (g(s) - g_max) / μ )          # stabilised weights
w_s /= Σ_t w_t
∇f_μ(h) = Σ_s w_s ∇g(s) .
```

--------------------------------------------------------------------
### 4. Gradient of a single correlation term

For a fixed shift `s` (integer offset, `-n+1 ≤ s ≤ n‑1`)  

```
g(s) = 1 - dx * Σ_i h_i * h_{i+s} .
```

Hence

```
∂g(s)/∂h_j = -dx * ( h_{j+s} + h_{j-s} ) ,   (out‑of‑range indices give 0)
```

Define two shifted copies of `h`:

```
h_fwd(s)   = [ h_{s}, h_{s+1}, … , h_{n-1}, 0,…,0 ]          # length n, zero‑padded
h_bwd(s)   = [ 0,…,0 , h_0 , h_1 , … , h_{n-1-s} ]          # shift opposite direction
```

Then the gradient contribution of shift `s` is `-dx * (h_fwd(s) + h_bwd(s))`.

--------------------------------------------------------------------
### 5. Projected gradient descent on the smooth objective

For a given smoothing parameter `μ`:

1. **Compute the correlation vector** `g = 1 - dx * autocorr(h)` where the autocorrelation is obtained with `np.correlate(h, h, mode='full')`.
2. **Build the weights** `w` using the stabilised log‑sum‑exp trick (subtract `g_max` before exponentiation).
3. **Accumulate the gradient**  

   ```
   grad = np.zeros_like(h)
   for each shift s:
       grad += w_s * ( -dx * (h_fwd(s) + h_bwd(s)) )
   ```

   (The loop is over `2n‑1` shifts; the operations are vectorised, so the whole pass is ~ O(n²) but implemented in compiled NumPy loops.)

4. **Line‑search step** – start with a step size `η = η₀` (e.g. `0.5`).  
   *Propose* `h̃ = h - η * grad`.  
   *Project* `h̃` onto `F` with the routine of §2.  
   *Accept* the step if the surrogate `f_μ` decreases; otherwise shrink `η` (e.g. `η ← 0.7·η`) and retry.  
   If `η` falls below a tiny threshold (`1e‑6`) break out of the inner loop.

5. **Iterate** the inner loop for a fixed number of iterations (e.g. 200) or until the improvement in `f_μ` is below `1e‑9`.

All arithmetic stays in double precision; the projection guarantees feasibility after each accepted step.
