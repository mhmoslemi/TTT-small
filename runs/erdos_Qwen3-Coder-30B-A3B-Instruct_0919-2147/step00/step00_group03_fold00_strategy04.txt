**Goal** – Find a step‑function `h` on `[0,2]`, discretised with `n` points, that minimizes  

\[
C_5(h)=\max_{k}\int_0^2 h(x)\bigl(1-h(x+k)\bigr)\,dx ,
\]

subject to  

* `0 ≤ h[i] ≤ 1` for all indices,  
* `∑_i h[i] · dx = 1`   (equivalently `∑_i h[i] = n/2` with `dx = 2/n`).

The current best numerical bound is ≈ 0.38092; we aim to push it below 0.3807.

The strategy consists of three tightly coupled phases that together explore the non‑convex landscape far more aggressively than a plain projected gradient or a local search.

--------------------------------------------------------------------
### 1. Reformulation as a smoothed max‑problem

Define the discrete correlation vector  

\[
g_k(h)=\int h(x)\bigl(1-h(x+k)\bigr)dx
       =1-\!\!\sum_{i}h_i\,h_{i+k}\,dx .
\]

The objective is `max_k g_k`.  
Introduce a *soft‑max* surrogate

\[
F_\alpha(h)=\frac{1}{\alpha}\log\!\Bigl(\sum_{k} \exp\bigl(\alpha\,g_k(h)\bigr)\Bigr),
\qquad \alpha>0 .
\]

* For small `α` the surrogate is smooth and its gradient is easy to compute;  
* As `α → ∞`, `F_α` converges to the true `max`.  
We will **homotope** `α`: start with a modest value (e.g. `α₀≈5`), optimise, then increase `α` (e.g. multiply by 1.5 each stage) and re‑optimise, finishing with a large `α≈200` that makes `F_α` an accurate proxy for the original max.

--------------------------------------------------------------------
### 2. Efficient gradient evaluation via the FFT

Observe that the inner products  

\[
c_k(h)=\sum_i h_i\,h_{i+k}\,dx
\]

are exactly the (aperiodic) autocorrelation of `h`.  With zero padding the full correlation of length `2n-1` can be obtained by a single FFT:

* Pad `h` to length `2n`.
* Compute `H = FFT(h, 2n)`.
* Form `C = IFFT( H·conj(H) )` – the convolution of `h` with its reversed copy.
* Keep the real part, multiply by `dx` and obtain all `c_k`.

Because `g_k = 1 - c_k`, we have the full vector `g`.  
The gradient of a single `g_k` w.r.t. a component `h_j` is  

\[
\frac{\partial g_k}{\partial h_j}= -dx\bigl(h_{j+k}+h_{j-k}\bigr)
\]

(where out‑of‑range indices contribute zero).  The gradient of `F_α`

\[
\nabla F_\alpha(h)=\sum_{k} w_k\,\nabla g_k(h),\qquad 
w_k =\frac{\exp(\alpha g_k)}{\sum_\ell \exp(\alpha g_\ell)} .
\]

The weight vector `w` is already available from the soft‑max computation.  
The convolution structure of the gradient again allows an FFT‑based evaluation:

* Form the array `w` (length `2n-1` centred at shift `0`).
* Compute the convolution `w * h` via FFT (zero‑pad both to length `2n`).
* The result gives, for each index, the sum of `w_k·h_{j+k}` across all `k`.
* Adding the symmetric term (convolution with the reversed `w`) yields the full gradient.

Thus **one gradient evaluation costs O(n log n)**, which makes it feasible to run thousands of iterations even for `n≈400`.

--------------------------------------------------------------------
### 3. Projection onto the feasible set (capped simplex)

After a gradient step we obtain a tentative vector `h̃`.  We must enforce

* box constraints `0 ≤ h_i ≤ 1`,
* exact sum `∑ h_i = n/2`.

Both are captured by the **capped simplex**  

\[
\mathcal{S}=\{h\in\mathbb{R}^n\mid 0\le h_i\le 1,\;\sum_i h_i = S\},
\qquad S=n/2 .
\]

Projection onto `𝒮` is performed by a *water‑filling* (binary‑search) routine:

1. Clip `h̃` to the box obtaining `v_i = min(max(h̃_i,0),1)`.
2. If `∑v = S` we are done.
3. Otherwise solve for a scalar `τ` such that  

   \[
   \sum_i \operatorname{clip}(v_i-τ,0,1)=S ,
   \]

   by binary search on `τ` (the mapping `τ↦∑clip(v_i-τ,0,1)` is monotone).
4. Return the clipped vector `h = clip(v-τ,0,1)`.

The routine is `O(n log ε⁻¹)` and numerically stable (the exponential scaling in the soft‑max is neutralised by subtracting the maximum before exponentiation).

```
initialisation:

    # ----- increase smoothness parameter -----

```

The inner loop usually converges in a few hundred FFT calls for each `α`.  By gradually sharpening the objective we keep the optimisation well‑behaved and avoid being trapped in the many flat regions of the hard max.

### 5. Seeding the optimisation

A good seed dramatically reduces the number of homotopy stages required.

* **Binary seed** – take the supplied `initial_h_values` (a 0/1 vector of length ≈ 70) and up‑sample by nearest‑neighbour interpolation to the target `n`.  The up‑sampled vector automatically satisfies the sum constraint because the number of ones is preserved; a final projection onto `𝒮` restores exactness.
* **Perturbed binary seed** – add a tiny uniform jitter (±0.01) before projection.  This breaks symmetry and gives the gradient method room to move away from a purely binary configuration.
* **Multi‑interval deterministic seed** – construct a set of `m` disjoint intervals of total length 1, evenly spaced across `[0,2]`.  The corresponding indicator vector is also a feasible binary start and often yields a lower initial `C₅` than a random binary vector.

We try each of the above seeds (in parallel or sequentially, respecting the time budget) and keep the best result across them.

### 6. Final local refinement (pairwise exchange)

After the homotopy has converged we perform a **pairwise exchange** phase that can squeeze out the last few hundredths:

* Pick two indices `i≠j`.
* Determine the admissible mass transfer `Δ = min( h_i, 1‑h_j )`.
* Propose `h' = h` with `h'_i = h_i - ε`, `h'_j = h_j + ε` for a random `ε∈[0,Δ]`.
* Evaluate the exact `C₅` for `h'` using the direct correlation (still an FFT for speed).
* Accept the move if `C₅` decreases; otherwise accept with probability `exp(-(C₅'‑C₅)/T)` where the temperature `T` is linearly cooled to zero over the allocated refinement time.

Because each move preserves the sum exactly and respects the box constraints, no projection is needed.  The exchange process is extremely cheap (O(1) update of the correlation can be done analytically, but even recomputing the FFT each time is fast for `n ≤ 512`).  Running a few thousand such swaps typically lowers the bound by 0.0002–0.0005.

### 7. Time‑budget handling and fallback

* The outer loop monitors `time.time()`.  
* If the remaining budget falls below a fixed safety margin (≈ 5 s) we abort the current inner iteration, perform a final quick evaluation of the current `h`, and return the best solution seen so far.  
* As a **fallback** (in case the homotopy fails to improve the seed within the allotted time) we keep the best binary start that we evaluated at the very beginning – this guarantees we never return a worse bound than the known record.

| Potential issue | Why it occurs | Counter‑measure |
|-----------------|----------------|-----------------|
| **Overflow/underflow in the soft‑max** | `exp(α g_k)` may overflow for large `α`. | Subtract `max(g)` from `g` before exponentiation (`exp(α(g‑g_max))`). This leaves the weights unchanged. |
| **Stagnation at a non‑optimal plateau** | The softened objective can have very flat regions. | Homotopy: increase `α` slowly; also use a small random perturbation after each inner convergence to escape flat zones. |
| **Projection drift** | Numerical errors may make the projected vector slightly violate the sum constraint. | After projection recompute the sum; if it differs from `S` by more than `1e‑12` perform one extra correction sweep (redistribute the tiny residual over non‑saturated entries). |
| **FFT‑induced wrap‑around** | Zero‑padding is essential; otherwise the periodic convolution would corrupt the aperiodic correlation. | Always pad `h` to length `2n` before FFT and keep only the first `2n‑1` entries of the inverse transform. |
| **Excessive step size** | A too large gradient step can push many entries to the box limits, flattening progress. | Use a backtracking line search based on the Armijo condition; initialise with `η = 1.0` and halve until the surrogate `F_α` decreases. |
| **Memory blow‑up for large `n`** | Storing many intermediate arrays of length `2n` for each `α` may stress memory. | Limit `n` to ≤ 512 (≈ 1 MiB per array) – well within the 1 GB typical limit for the execution environment. |
