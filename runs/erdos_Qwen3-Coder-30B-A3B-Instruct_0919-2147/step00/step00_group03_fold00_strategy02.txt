and minimizes

\]

A lower C₅ gives a tighter upper bound on the Erdős constant.  

The strategy below solves the problem in two **phases**:

1. **Phase A – Global combinatorial optimisation on a coarse grid**

### 1️⃣ Problem reformulation for MILP (Phase A)

**Variables**  

| Symbol | Meaning | Domain |
|--------|---------|--------|
| h[i]   | step value at sample i | {0, 1} (binary) |
| w[i,k] | auxiliary product h[i]·h[i+k] | {0, 1} |
| t      | upper bound on all overlaps | ℝ₊ |

**Parameters**  

* n – number of samples (choose a modest size, e.g. 70, 80 or 100).  
* dx = 2 / n.  
* S = n/2 – required total “mass”.  
* For each shift k ∈ {-(n‑1), … , n‑1} define the index‑mapping i→i+k (out‑of‑range → ignored).

**Constraints**

1. **Mass**: ∑₀^{n‑1} h[i] = S.  
2. **Box**: 0 ≤ h[i] ≤ 1 (enforced by binary domain).  
3. **Product linearisation** (McCormick): for every i,k with i+k in [0,n‑1]  

   ```
   w[i,k] ≤ h[i]
   w[i,k] ≤ h[i+k]
   w[i,k] ≥ h[i] + h[i+k] – 1
   ```

   (If i+k is out of range set w[i,k]=0; the constraints can be omitted.)

4. **Overlap bound**: for each shift k  

   \[
   t \;\ge\; \sum_i h[i]\;dx \;-\; \sum_i w[i,k]\;dx
        \;=\; 1 \;-\; dx\;\sum_i w[i,k].
   \]

   Since the first term Σ h[i] dx equals 1 by the mass constraint, the inequality simplifies to  

   \[
   t \;\ge\; 1 \;-\; dx\;\sum_i w[i,k].
   \]

5. **Objective**: minimise t.

**Why this works**  
For a binary h, the overlap for shift k is exactly  

\[
\int h(x)(1-h(x+k))dx
   = 1 - dx \sum_i h[i]h[i+k]
   = 1 - dx \sum_i w[i,k],
\]

so the MILP constraints are precisely the definition of C₅ . Because every constraint is linear, the MILP solver (CBC, SCIP, GLPK, etc.) can locate the global optimum for the chosen grid size.

**Implementation notes**

* Build the MILP once per chosen n using **cvxpy** with a mixed‑integer solver (CBC/SCIP).  
* To keep the model tractable, generate w[i,k] only for shifts |k| ≤ Kₘₐₓ where Kₘₐₓ = ceil(1/dx). Shifts larger than the support of h cannot produce a larger overlap than the trivial bound, and their constraints are automatically satisfied.  
* Solve the MILP with a **time limit** (e.g. 120 s). If the solver does not finish, abort and keep the best feasible integer solution found (cvxpy provides the incumbent).

**Expected outcome**

### 2️⃣ Continuous refinement (Phase B)

Having a promising binary pattern, we now allow h[i] ∈ [0,1] to reduce the maximum overlap further. The optimisation problem is:

\[
\min_{h\in\mathcal{F}} \; \max_{k} g_k(h),\quad
g_k(h)=1 - dx\sum_i h[i]h[i+k].
\]

Because the **max** is nonsmooth, we replace it by a **smooth upper‑bound**:

\[
\Phi_\alpha(h)=\frac{1}{\alpha}\log\Bigl(\sum_k \exp\bigl(\alpha\,g_k(h)\bigr)\Bigr),
\]

with a temperature‑like parameter α (large α ≈ 30–100 gives a tight approximation). Minimising Φₐ drives the true maximum down while providing a differentiable objective for gradient‑based methods.

#### 2.1 Gradient computation

For shift k, the derivative of g_k w.r.t. h[j] is

\[
\frac{\partial g_k}{\partial h_j}
   = -dx\;(h_{j+k}+h_{j-k}),
\]

with the convention that out‑of‑range indices contribute 0.  
The gradient of Φₐ is then a weighted sum of the individual gradients:

\[
\nabla\Phi_\alpha(h)
   = \sum_k p_k(h)\; \bigl(-dx\;(h_{\cdot+k}+h_{\cdot-k})\bigr),
\]
where  

\[
p_k(h)=\frac{\exp(\alpha g_k(h))}
            {\sum_{k'}\exp(\alpha g_{k'}(h))}
\]

are soft‑max weights (they sum to 1).

All required operations are vectorised **convolutions** that can be evaluated with `np.convolve` or `np.fft.ifft` for speed.

#### 2.2 Projection onto the feasible set  

After a gradient step we obtain a provisional vector ĥ. We must enforce  

* 0 ≤ ĥ ≤ 1,  
* Σ ĥ = S.

The projection onto the intersection of a box and an affine hyperplane is a **capped‑simplex projection**. It can be performed by a simple binary search on a threshold λ such that  

\[
\tilde h_i = \operatorname{clip}(ĥ_i - λ, 0, 1)
\]
satisfies Σ \tilde h_i = S. Because the mapping λ ↦ Σ clip(·) is monotone, 50 iterations of bisection converge to machine precision.

#### 2.3 Optimisation loop  

```
h ← h_bin  (cast to float)
t ← Φ_α(h)                     # initial smoothed objective
α ← 30                         # start with a moderate smoothness
step ← 0.1                     # initial gradient step size
while time left > ε:
    compute g_k(h) and Φ_α(h)
    compute gradient ∇Φ_α(h)
    h_new ← project( h - step * ∇Φ_α(h) )
    t_new ← Φ_α(h_new)
    if t_new < t or accept_uphill(t_new, t, temperature):
        h ← h_new ; t ← t_new
    decay step (e.g. step *= 0.99)
    occasionally increase α (α ← min(α*1.1, 200))
```

*The “accept_uphill” test implements a simple simulated‑annealing schedule (probability = exp(-(t_new−t)/T) with a temperature T that decays linearly). This helps escape shallow plateaus.*

The loop terminates when the remaining budget is below ~5 s. At each iteration we compute the **true** C₅ value (the exact max correlation) and keep the best‑ever vector h_best.

#### 2.4 Optional second‑order refinement  

If the budget permits, run a **limited‑memory BFGS** (L‑BFGS‑B) on the exact non‑smooth objective using the *max* directly. The optimizer will treat the max as a piecewise‑linear function; SciPy’s SLSQP or L‑BFGS‑B can handle it if we supply a subgradient (the gradient of any active shift). This step typically yields a few extra digits of improvement.

### 6️⃣ Why this approach is materially different

* **Exact combinatorial optimisation** – The first phase solves a *global* MILP for binary patterns, guaranteeing that the starting point is provably optimal among all binary step functions on the chosen grid.  
* **Two‑stage hybrid** – After the integer optimum is obtained, we switch to a *continuous* gradient‑based refinement, a step not present in pure gradient‑only or pure simulated‑annealing strategies.  
* **Smooth‑max surrogate** – Replacing the max by a log‑sum‑exp objective provides a differentiable landscape suitable for high‑performance quasi‑Newton methods.  
* **Capped‑simplex projection** – The projection onto the affine‑box intersection is performed analytically via a binary search, ensuring exact feasibility after each gradient step.  
* **Explicit big‑M linearisation** – By introducing auxiliary product variables we turn the inherently quadratic overlap constraints into a pure linear model, enabling the use of fast MILP solvers instead of general non‑linear solvers.

Together these elements form a novel pipeline that leverages the strengths of integer optimisation for a strong discrete seed and the flexibility of continuous optimisation for fine‑grained improvement.
