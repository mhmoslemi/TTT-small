The plan below uses a **semidefinite‑programming (SDP) relaxation** of the quadratic max‑min problem, followed by a **rank‑1 extraction and rounding** step, and finally a **light local polishing**.  This approach is fundamentally different from the gradient‑based smoothing, MILP, or interval‑union methods presented earlier.

### 1. Reformulation in matrix form

Let `N = n_points` and `dx = 2/N`.  
Define a vector `v ∈ ℝ^N` with components `v_i = h[i]`.  
For a shift `k` (integer, `‑N+1 ≤ k ≤ N‑1`) the discrete auto‑correlation is  

```
c_k = dx · Σ_{i=0}^{N-1‑k} v_i·v_{i+k}       (k ≥ 0)
c_{‑k} = c_k                                 (symmetry)
```

Collect the products `v_i·v_j` into a symmetric matrix  

```
M = v vᵀ   ∈ ℝ^{N×N} .
```

Then each correlation value is a linear functional of `M`:

```
c_k = dx · Σ_{i=0}^{N‑1‑k} M_{i,i+k} .
```

Consequently  

```
min_k c_k   =   dx· min_{k} Σ_{i} M_{i,i+k} .
```

Our original problem – maximise the minimum correlation – becomes

```
maximise   t
subject to Σ_{i} M_{i,i+k} ≥ t   for all k = 0,…,N‑1
           M ⪰ 0               (positive semidefinite)
           M_{ii} = v_i         (diagonal extracts v)
           0 ≤ v_i ≤ 1
           Σ_i v_i = N/2 .
```

If we enforce the rank‑one condition `M = v vᵀ`, the model is exact but non‑convex.  
Relax the rank requirement: keep all linear constraints and the PSD cone, producing an **SDP relaxation**.  The optimal value `t*` from this relaxation is an *upper bound* on the achievable `min_k c_k`.  Moreover, the optimal matrix `M*` typically has a few dominant eigenvalues, allowing us to extract a near‑rank‑one vector.

### 2. SDP construction (variables and constraints)

| Variable | Type | Description |
|----------|------|-------------|
| `M`      | `N×N` symmetric PSD | Intended to be `v vᵀ`. |
| `v`      | length‑`N` real   | Diagonal of `M` (enforced by `M_{ii}=v_i`). |
| `t`      | scalar            | Lower bound on every correlation value. |

**Constraints**

1. **Correlation lower bounds** – For each shift `k = 0,…,N‑1`  
   `Σ_{i=0}^{N‑1‑k} M_{i,i+k} ≥ t`.  (One linear inequality per shift.)

2. **PSD** – `M ⪰ 0`.  Enforced by the SDP solver.

3. **Diagonal coupling** – `M_{ii} = v_i` for all `i`.  This ties `M` to a feasible `v`.

4. **Box on `v`** – `0 ≤ v_i ≤ 1`.

5. **Mass constraint** – `Σ_i v_i = N/2`.

6. **Optional symmetry** – Because the problem is shift‑invariant, we may impose `M` to be Toeplitz (`M_{i,j}` depends only on `|i‑j|`).  This reduces variables dramatically (to `N` independent entries) and speeds up the SDP.  The Toeplitz constraint is linear: `M_{i,j} = τ_{|i‑j|}` for a new vector `τ`.  The PSD constraint then becomes “Toeplitz PSD”, automatically satisfied if the corresponding spectral density is non‑negative.

*Choosing the Toeplitz reduction is the key to keep the SDP tractable for `N` up to about 200.*

1. **Select a discretisation size** – Begin with a moderate `N = 120` (so `dx ≈ 0.0167`). 3. **Objective** – Maximise `t`.  In CVXPY the objective is `Maximize(t)`.

4. **Time budget** – Allocate **≈ 200 seconds** for the SDP.  Set the solver’s `max_iters` and `eps` to reasonable values (`eps = 1e‑6`).  If the solver fails to converge within this window, accept the best feasible `t` it has produced.

5. **Result extraction** – After the solver finishes, obtain the optimal Toeplitz vector `τ*` and the diagonal `v* = M*_{ii}`.  Because the rank‑one condition is relaxed, `M*` will usually have a dominant eigenvalue `λ₁` with eigenvector `u₁`.  

--------------------------------------------------------------------
### 4. Rank‑1 extraction and construction of a feasible `h`

1. **Eigen‑decomposition** – Compute the eigenvectors of `M*`.  Take the leading eigenpair `(λ₁, u₁)`.  Form a provisional continuous vector  

   ```
   h̃ = sqrt(λ₁)·u₁ .
   ```

   Since `M* ≈ λ₁·u₁u₁ᵀ`, this `h̃` is the natural rank‑1 approximation.

2. **Boxing and mass correction** – `h̃` is not guaranteed to lie in `[0,1]` nor to have the correct sum.  Perform the **projection onto the intersection of the box `[0,1]` and the hyperplane `∑ h = N/2`**:

   * Define `x = h̃`.  
   * Find a scalar `θ` such that `∑ clip(x_i + θ, 0, 1) = N/2`.  Because the function of `θ` is monotone, locate the root by bisection (≈ 60 iterations).  
   * Set `h = clip(x + θ, 0, 1)`.  This yields a feasible vector that stays as close as possible (in Euclidean norm) to the rank‑1 approximation.

3. **Binary rounding (optional)** – If the extracted `h` is already close to binary (most entries ≈ 0 or 1), keep it.  Otherwise, produce a binary version by taking the `N/2` largest entries and setting them to `1`, the rest to `0`.  Immediately re‑project onto the box‑hyperplane (the binary version already satisfies the sum, but clipping removes any stray values caused by floating‑point error).

### 5. Evaluation of the candidate

* Compute the full correlation `c = dx·np.correlate(h, h, mode='full')`.  
* Determine `C5 = 1 – np.min(c)`.  
* If `C5` improves on the current best bound, store `(h, C5, N)`.

Because the SDP gave an upper bound `t*` on the *minimum* correlation, the true `C5` of the extracted vector cannot be larger than `1 – t*`.  This guarantee lets us stop early if we already achieve `C5 < 0.3807`.

--------------------------------------------------------------------
### 6. Local polishing (light gradient or hill‑climbing)

The extracted `h` may be fractional and not fully optimal.  A short **projected sub‑gradient ascent** (identical to the one described in earlier material but limited to a few dozen iterations) can be run:

1. Compute the correlation `c`.  
2. Identify the *worst* shift(s) `k_min` where `c` attains its minimum.  
3. Build a sub‑gradient `g` by summing the contributions `h[i+k_min] + h[i‑k_min]` for each `i`.  
4. Take a small step `h ← project( h + η·g )` with `η = 0.02` (or adaptively reduced).  
5. Accept only if `C5` decreases; otherwise revert and halve `η`.  

Perform at most **500** such iterations – this costs negligible time compared with the SDP.
