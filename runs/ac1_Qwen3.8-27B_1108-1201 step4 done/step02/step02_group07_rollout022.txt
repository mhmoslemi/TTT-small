The key insight from the LP approach in the previous code is: given a sequence f, find the "best" sequence g that has `conv(f, g) <= M` (the current peak), and then move towards g. This is a form of projected subgradient descent on the max-convolution.

The score is `2n * max_k conv[k] / S^2`. Since the problem is scale-invariant, let's fix `S = 1`. Then we want to minimize `max_k conv[k]` subject to `sum(a) = 1` and `a >= 0`.

This is a convex optimization problem! We're minimizing the maximum of linear functions (each `conv[k]` is linear in `a`) subject to linear constraints. So it's a linear program!

The LP is:
Minimize t
Subject to: `conv_k(a) <= t` for all k = 0, ..., 2n-2
`sum(a) = 1`
`a >= 0`

Where `conv_k(a) = sum_i a[i] * a[k-i]`... wait, that's NOT linear in a! The convolution is quadratic!

Oh right, `conv(a, a)` is quadratic in a. So the problem is:
Minimize `max_k (a * Q_k * a)` subject to `sum(a) = 1`, `a >= 0`.

Where `Q_k` is a matrix such that `(a * Q_k * a) = conv_k(a, a)`. This is a quadratic program, not linear.

However, the previous LP approach works by fixing one factor: given f, find g that minimizes `max_k conv(f, g)` subject to `sum(g) = sum(f)`, `g >= 0`. This IS a linear program because `conv(f, g)[k] = sum_i f[i] * g[k-i]` is linear in g.

So the LP approach is a form of "alternating minimization" or "coordinate descent" on the two factors of the quadratic form.

Actually, let me think about this differently. The score is:
`score = 2n * max_k conv_k / S^2`

where `conv_k = sum_i a[i] * a[k-i]` (with appropriate bounds).

Note that `sum_k conv_k = S^2` (total sum of all convolution values equals the square of the sum). So `max_k conv_k >= S^2 / (2n-1)` by the pigeonhole principle. A better lower bound: the "flat" convolution would have all values equal to `S^2/(2n-1)`. But we can't achieve this with a non-negative sequence (as we've seen, even for n=2 the minimum is 16/9 ≈ 1.78, not 2/3).

Let me think about the problem from a different angle. The convolution `c = conv(a, a)` must satisfy:
1. `c` is a "valid" autocorrelation sequence (it must be positive definite in a certain sense).
2. `c[k] = c[2n-2-k]` (symmetry).
3. `a >= 0`.

For non-negative a, the convolution has additional structure. Specifically, `c[k] = sum_i a[i] * a[k-i] >= 0` and the sequence a can be "recovered" from c (up to the sign of the first element, but here a[0] >= 0).

Actually, for non-negative a, the relationship between a and c is very specific. Given c, we can recover a by:
- `a[0] = sqrt(c[0])` (since c[0] = a[0]^2)
- `a[1] = c[1] / (2 * a[0])`
- `a[2] = (c[2] - a[1]^2) / (2 * a[0])`
- etc.

This is the "square root" of the convolution, and it's guaranteed to be non-negative if and only if c is a valid autocorrelation of a non-negative sequence.

So the problem can be reformulated as: find a sequence c (satisfying the constraints of being a valid autocorrelation of a non-negative sequence) that minimizes `max(c)` subject to `sum(c) = S^2` (which is fixed since S is fixed by normalization).
