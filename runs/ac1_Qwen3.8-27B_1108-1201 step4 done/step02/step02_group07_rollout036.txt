import numpy as np
import time
from scipy.fft import rfft, irfft
from scipy.optimize import linprog

def fft_convolve(a, b):
    n, m = len(a), len(b)
    size = 1
    while size < n + m - 1:
        size <<= 1
    return irfft(rfft(a, size) * rfft(b, size), size)[:n + m - 1]

def score_fast(a):
    a = np.asarray(a, dtype=np.float64)
    a = np.clip(a, 0.0, 1000.0)
    n = len(a)
    S = float(np.sum(a))
    if S < 0.01:
        return np.inf
    c = fft_convolve(a, a)
    return float(2.0 * n * np.max(c) / (S * S))

def normalize(p):
    """Normalize to sum to 1."""
    S = np.sum(p)
    if S < 1e-15:
        return p
    return p / S

def mirror_descent(f, time_limit, verbose=True):
    """Multiplicative weight updates (mirror descent with KL divergence)."""
    n = len(f)
    p = f.astype(np.float64).copy()
    p = np.clip(p, 1e-10, None)
    p = normalize(p)
    best_p = p.copy()
    best_score = score_fast(p)
    t0 = time.monotonic()
    it = 0
    eta = 0.5  # step size
    top_k = 3  # number of top lags to use
    
    while time.monotonic() - t0 < time_limit:
        c = fft_convolve(p, p)
        # Find top-k lags
        top_idx = np.argsort(c)[-top_k:]
        weights = c[top_idx]
        weights = weights / np.sum(weights)  # softmax-like weighting
        
        # Compute subgradient
        g = np.zeros(n)
        for w, k in zip(weights, top_idx):
            ki = int(k)
            for j in range(n):
                idx = ki - j
                if 0 <= idx < n:
                    g[j] += 2.0 * w * p[idx]
        
        # Multiplicative update
        p = p * np.exp(-eta * g)
        p = np.clip(p, 1e-15, None)
        p = normalize(p)
        
        it += 1
        if it % 100 == 0:
            s = score_fast(p)
            if s < best_score:
                best_score = s
                best_p = p.copy()
            if verbose:
                print(f"    [MD {time.monotonic()-t0:6.1f}s] it={it} score={s:.6f} best={best_score:.6f}")
    
    s = score_fast(p)
    if s < best_score:
        best_score = s
        best_p = p.copy()
    return best_p, best_score

Actually, let me try a different approach. Since the problem is convex (in a generalized sense), we can use the **method of conditional gradients** (a.k.a. Frank-Wolfe method):

1. Start with p_0 (e.g., uniform)
2. At each iteration:
   a. Compute the linear approximation: L(p) = f(p_t) + <g_t, p - p_t> where g_t is a subgradient
   b. Solve the LP: min <g_t, p> subject to sum(p) = 1, p >= 0
   c. Update: p_{t+1} = (1-alpha_t) * p_t + alpha_t * p_LP
3. Repeat

The subgradient g_t at p_t is:
g_t[j] = (1/|A|) * sum_{k in A} 2 * p_t[k-j] (if 0 <= k-j < n)
where A is the set of active lags (those achieving the max).

The LP in step (b) is:
min sum_j g_t[j] * p[j]
subject to sum(p) = 1, p >= 0

The solution is: p_LP[j] = 1 for j = argmin g_t[j], and 0 otherwise. (It's a vertex of the simplex!)

So the Frank-Wolfe update is:
p_{t+1} = (1-alpha_t) * p_t + alpha_t * e_{j*}
where j* = argmin g_t[j].

This is very simple! At each step, we move towards the basis vector that has the smallest subgradient component.

The step size alpha_t can be:
- Constant: alpha = 0.5
- Decreasing: alpha_t = 2/(t+2)
- Line search

Wait, that's not right either. Let me just write it out:
(p*p)[k] = sum_j p[j] * p[k-j]

For this to be p^T Q p, we need:
p^T Q p = sum_{j,l} p[j] * Q[j,l] * p[l] = (p*p)[k]

So Q[j,l] should satisfy: sum_{j,l} Q[j,l] p[j] p[l] = sum_j p[j] p[k-j]

This means Q[j,l] = 1/2 if l = k-j (and j != l), and Q[j,l] = 1 if l = k-j = j (self-term).
