Another approach that might work better: **alternating minimization**.

Since the objective is max_k (f*f)[k], and for a fixed "active set" of lags, the problem is a QP, we can:
1. Identify the active lags (where the convolution is at its max)
2. Solve the QP: minimize max_{k in active} (f*f)[k] s.t. f >= 0, sum f = 1
3. Update the active set
4. Repeat

The QP in step 2 can be solved with cvxpy or a custom solver.

Actually, for a single active lag m, minimizing (f*f)[m] = sum_i f[i]f[m-i] subject to f >= 0, sum f = 1 is a QP with a special structure (the matrix is the anti-diagonal shifted by m).

For m = n-1 (center): the matrix is the reversal matrix J (J[i,j] = 1 if i+j = n-1).
The QP is: minimize f^T J f subject to f >= 0, 1^T f = 1.

This has a closed-form solution! By symmetry, the optimum is f[i] = f[n-1-i] = 1/(2n) for i ≠ n-1-i, and f[(n-1)/2] = 1/n if n is odd. Wait, that's just uniform again.

Hmm, no. The QP minimize f^T J f has the same solution as minimize (sum f[i])^2 / n by C-S... no.

Actually, f^T J f = sum_i f[i] f[n-1-i] = (f, Jf) where J is the reversal.
By the symmetry of J, this equals the inner product of f and its reversal.

The minimum of this over f >= 0, sum f = 1 is achieved by... Let me use KKT.
L = f^T J f - λ(1^T f - 1) - μ^T f
∂L/∂f = 2Jf - λ1 - μ = 0
For f_i > 0: 2f[n-1-i] = λ
So f[n-1-i] = λ/2 for all i with f_i > 0.
This means f is constant (= λ/2) on the set of active indices, and since it's symmetric (f[i] = f[n-1-i]), the active set is symmetric.

If all indices are active: f[i] = 1/n for all i (uniform). Value = 1/n.
If a subset is active: the value would be higher (concentration).

So for the single-constraint QP (minimize the central convolution), the optimum is uniform with value 1/n. This confirms that we can't beat 2 using just the central constraint.

We need MULTIPLE active constraints to get below 2. The key is that when we constrain multiple lags simultaneously, the feasible set becomes more restrictive, and the optimum might have a lower max value.

For example, if we constrain both lag n-1 and lag n-2:
minimize max((f*f)[n-1], (f*f)[n-2])
s.t. f >= 0, sum f = 1

This is a more complex QP that might have a non-trivial optimum.

3. Polish with local search

"""
Minimize 2n*max(conv(f,f))/(sum f)^2 over non-negative f of length n.
Uses FFT-based subgradient descent with Nesterov acceleration from diverse
initializations (asymmetric windows), followed by local search polishing.
Key insight: asymmetric sequences can beat the symmetric lower bound of 2.
"""

import numpy as np
import time


def compute_objective(f):
    """Compute the scale-invariant objective."""
    n = len(f)
    s = f.sum()
    if s < 1e-10:
        return np.inf
    b = np.convolve(f, f)
    return 2.0 * n * b.max() / (s * s)


def subgradient_fft(f, weights):
    """Compute weighted subgradient via FFT cross-correlation.
    
    sg[j] = 2 * sum_d weights[j+d] * f[d] for valid d.
    Computed as: sg = 2 * conv(reversed(weights), f)[n-1:2n-1][::-1]
    """
    n = len(f)
    w_flipped = weights[::-1]
    needed = len(w_flipped) + n - 1  # = 3n - 2
    fft_size = 1
    while fft_size < needed:
        fft_size *= 2
    W = np.fft.rfft(w_flipped, fft_size)
    F = np.fft.rfft(f, fft_size)
    conv_full = np.fft.irfft(W * F, fft_size)
    seg = conv_full[n - 1:2 * n - 1][::-1]
    return 2.0 * seg


def optimize_subgradient(f, time_budget):
    """FFT-based subgradient descent with Nesterov momentum and adaptive tau."""
    n = len(f)
    f = np.clip(f, 0.0, None).astype(np.float64)
    s = f.sum()
    if s < 1e-10:
        return f
    f = f / s

    best_f = f.copy()
    best_obj = compute_objective(f)

    v = np.zeros(n)
    momentum = 0.9
    tau = 3.0
    lr_base = 50.0 / n  # initial learning rate
    lr_scale = 1.0
    patience = 0
    max_patience = 150

    # Nesterov lookahead
    y = f.copy()

    start = time.monotonic()
    t = 0

    while time.monotonic() - start < time_budget:
        t += 1
        cur_time = time.monotonic() - start

        b = np.convolve(f, f)
        max_val = b.max()
        cur_obj = 2.0 * n * max_val  # f normalized to sum=1

        if cur_obj < best_obj:
            best_obj = cur_obj
            best_f = f.copy()
            patience = 0
            tau = max(3.0, tau * 0.95)  # slightly reduce tau to explore
        else:
            patience += 1
            if patience % 75 == 0:
                lr_scale *= 0.7
                tau = min(tau * 1.3, 80.0)
                patience = 0
            if patience > max_patience:
                lr_scale *= 0.4
                patience = 0
                v *= 0.5
                if lr_scale < 1e-8:
                    break

        # Softmax weights over convolution values
        b_shifted = b - b.max()
        weights = np.exp(tau * b_shifted)
        wsum = weights.sum()
        if wsum > 1e-300:
            weights /= wsum
        else:
            weights = np.zeros(len(b))
            weights[np.argmax(b)] = 1.0

        # Subgradient at Nesterov lookahead point
        y = f + momentum * v / (lr_scale * lr_base / np.sqrt(max(t, 1)))
        y = np.clip(y, 0.0, None)
        ys = y.sum()
        if ys > 1e-10:
            y = y / ys

        sg = subgradient_fft(y, weights)

        # Update
        lr = lr_base * lr_scale / np.sqrt(max(t, 1))
        v = momentum * v + lr * sg
        f_new = f - v

        # Project onto {f >= 0, sum(f) = 1}
        f_new = np.clip(f_new, 0.0, None)
        s = f_new.sum()
        if s > 1e-10:
            f_new = f_new / s
        else:
            f_new = best_f.copy()

        f = f_new

    return best_f


def local_search(f, time_budget, rng):
    """Block-perturbation local search for final polishing."""
    n = len(f)
    best_f = np.clip(f, 0.0, None).astype(np.float64)
    s = best_f.sum()
    if s < 1e-10:
        return best_f
    best_f = best_f / s
    best_obj = compute_objective(best_f)

    start = time.monotonic()
    stall_count = 0
    pert_scale = 0.08

    while time.monotonic() - start < time_budget:
        # Multi-scale block perturbation
        f_try = best_f.copy()
        n_blocks = int(rng.integers(1, 4))
        for _ in range(n_blocks):
            width = int(rng.integers(max(1, n // 300), max(2, n // 8)))
            start_idx = int(rng.integers(0, max(1, n - width)))
            end_idx = min(n, start_idx + width)
            factor = np.exp(rng.normal(0.0, pert_scale))
            f_try[start_idx:end_idx] *= factor

        # Occasionally try a global rescale of half the sequence
        if rng.random() < 0.15:
            half = n // 2
            f_try[:half] *= np.exp(rng.normal(0.0, 0.05))
            f_try[half:] *= np.exp(rng.normal(0.0, 0.05))

        # Occasionally mirror-averge
        if rng.random() < 0.1:
            f_try = 0.5 * (f_try + f_try[::-1])

        f_try = np.clip(f_try, 0.0, None)
        s = f_try.sum()
        if s > 1e-10:
            f_try = f_try / s
            obj = compute_objective(f_try)
            if obj < best_obj:
                best_obj = obj
                best_f = f_try.copy()
                stall_count = 0
                pert_scale = max(0.02, pert_scale * 0.95)
            else:
                stall_count += 1
                if stall_count > 300:
                    pert_scale = min(0.3, pert_scale * 1.3)
                    stall_count = 0
                    if pert_scale > 0.25:
                        # Try a larger random restart perturbation
                        f_try = best_f * np.exp(rng.normal(0, 0.1, n))
                        f_try = np.clip(f_try, 0.0, None)
                        s = f_try.sum()
                        if s > 1e-10:
                            f_try = f_try / s
                            obj = compute_objective(f_try)
                            if obj < best_obj:
                                best_obj = obj
                                best_f = f_try.copy()
                                stall_count = 0
                                pert_scale = 0.08

    return best_f


def make_inverse_cosine_window(n, c=1.0):
    """U-shaped (inverse Hann-like) window: high at edges, low in middle."""
    i = np.arange(n, dtype=np.float64)
    w = 1.0 + c * np.cos(2.0 * np.pi * (i + 0.5) / n)
    w = np.clip(w, 1e-6, None)
    return w / w.sum()


def make_power_law_window(n, alpha=0.5):
    """One-sided power law: f[i] proportional to (i+1)^alpha."""
    i = np.arange(n, dtype=np.float64) + 1.0
    w = i ** alpha
    return w / w.sum()


def make_beta_window(n, a=2.0, b=2.0):
    """Beta-distribution-like window."""
    i = np.arange(n, dtype=np.float64)
    x = (i + 0.5) / n
    w = x ** (a - 1) * (1 - x) ** (b - 1)
    w = np.clip(w, 1e-10, None)
    return w / w.sum()


def make_fourier_window(n, coeffs):
    """Custom Fourier window: f[i] = sum_k c_k * cos(2*pi*k*(i+0.5)/n + phi_k)."""
    i = np.arange(n, dtype=np.float64)
    w = np.ones(n, dtype=np.float64)
    for amplitude, freq, phase in coeffs:
        w += amplitude * np.cos(2.0 * np.pi * freq * (i + 0.5) / n + phase)
    w = np.clip(w, 1e-6, None)
    return w / w.sum()


def make_gaussian_window(n, sigma_frac=0.25):
    """Gaussian centered at middle."""
    i = np.arange(n, dtype=np.float64)
    center = (n - 1) / 2.0
    sigma = n * sigma_frac
    w = np.exp(-(i - center) ** 2 / (2.0 * sigma * sigma))
    return w / w.sum()


def make_skewed_gaussian(n, sigma_frac=0.3, skew=0.3):
    """Skewed Gaussian (offset from center)."""
    i = np.arange(n, dtype=np.float64)
    center = (n - 1) * (0.5 + skew)
    sigma = n * sigma_frac
    w = np.exp(-(i - center) ** 2 / (2.0 * sigma * sigma))
    w = np.clip(w, 1e-10, None)
    return w / w.sum()


def make_tapered_asymmetric(n, taper=0.5):
    """Asymmetric taper: one side tapers more than the other."""
    i = np.arange(n, dtype=np.float64)
    x = i / (n - 1)
    # Asymmetric: left side has linear taper, right side has sqrt taper
    left_taper = np.where(x < 0.5, 1.0 + taper * (2 * x - 1), 1.0)
    right_taper = np.where(x >= 0.5, 1.0 - taper * (2 * x - 1) ** 0.5, 1.0)
    w = left_taper * right_taper
    w = np.clip(w, 1e-6, None)
    return w / w.sum()
