The bandwidth is n (each row has n non-zeros at most). So the matrix is n-banded. For a (2n-1) × n matrix with bandwidth n, the number of non-zeros is approximately n*(n+1)/2 + (n-1)*n/2 ≈ n^2. So it's about n^2 non-zeros.

def central_binomial_sequence(n):
    """Generate the central binomial coefficient sequence of length n."""
    # C_k = binom(2k, k) / 4^k
    # Use recurrence: C_{k+1} = C_k * (2k+1) / (2k+2)
    C = np.ones(n, dtype=np.float64)

- Row k has a[k-j] for j from max(0,k-n+1) to min(k,n-1).
- This is the sequence a[k], a[k-1], ..., a[max(0,k-n+1)] padded with zeros.
