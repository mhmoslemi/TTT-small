```python
        j_min = max(0, k_star - n + 1)
        j_max = min(n - 1, k_star)
        grad[j_min:j_max+1] = a[k_star - j_max : k_star - j_min + 1][::-1]
        
        # Momentum update
        v = momentum * v - lr * grad
        a_new = a + v
        a_new = np.clip(a_new, 0, None)
        
        # Renormalize
        s = a_new.sum()
        if s < 1e-10:
            a_new = a  # revert
            v = np.zeros(n)
            lr *= 0.5
            continue
        a_new = a_new / s * target_sum
        
        # Evaluate
        score = evaluate_sequence(a_new.tolist())
        if score < best_score:
            best_score = score
            best = a_new.copy()
        
        # Adaptive learning rate
        a = a_new
    
    return best
```

Wait, I'm calling evaluate_sequence every iteration, which is expensive (it does its own convolution). Let me instead compute the score directly:

```python
conv = np.convolve(a_new, a_new)
score = 2 * n * np.max(conv) / (np.sum(a_new))**2
```

This avoids the overhead of evaluate_sequence (type checking, etc.).

Actually, since I need to return a valid sequence and the evaluate_sequence function is authoritative, let me just use it for the final check and use my own fast computation during optimization.

Let me also think about the step size. The gradient at the peak is the "partner" vector, which has the same scale as a. So the step should be proportional to the scale of a. A good choice is:

lr = eta / max_a * a (i.e., relative step)

Or: lr = eta * sum_a / n (proportional to the average value).
