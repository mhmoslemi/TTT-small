Let me think about this differently. The convolution (a*a)[n] = sum_k a[k]*a[n-k]. If a is "random" (i.i.d. from some distribution), then by concentration of measure, each (a*a)[n] is approximately E[a]^2 * (number of terms) + variance terms. The peak would be about (sum a)^2 / (2n-1) * some factor.

Actually, for a random sequence with mean μ and variance σ^2, the expected value of (a*a)[n] for the center (with n terms) is n*μ^2 + n*σ^2 = n*(μ^2 + σ^2) = n*E[a^2]. And E[a^2] = σ^2 + μ^2. So the expected peak is about n*E[a^2], while the mean of the sequence is n*μ, so S = n*μ, S^2 = n^2*μ^2. The ratio is n*E[a^2]/(n^2*μ^2) = E[a^2]/(n*μ^2) = (1 + CV^2)/n where CV = σ/μ is the coefficient of variation.

So for a random sequence, score ≈ 2*(1+CV^2). If CV = 0 (constant), score = 2. If CV > 0, score > 2. So random sequences are WORSE than constant!

    a_padded[:n] = a
    A = np.fft.rfft(a_padded)
