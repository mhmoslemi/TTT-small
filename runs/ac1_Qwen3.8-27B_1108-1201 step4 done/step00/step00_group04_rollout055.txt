`= (n-1)*xy` (if `n-1 <= n`)
Or `(a*a)[n-2]` (even, `m = (n-2)/2`):
`= ((n-2)/2+1)x^2 + ((n-2)/2)*y^2 = (n/2)x^2 + ((n-2)/2)*y^2`

The peak is approximately `max(n*xy/1, n*x^2/2)` (roughly).

`sum_a = (n/2)(x+y)`
`sum_a^2 = (n^2/4)(x+y)^2`

`objective = 2n * peak / sum_a^2 ≈ 2n * n*xy / (n^2/4)(x+y)^2 = 8xy/(x+y)^2`

This is maximized when `x = y` (giving 2), and minimized when one of them is 0 (giving 0, but that's degenerate).
