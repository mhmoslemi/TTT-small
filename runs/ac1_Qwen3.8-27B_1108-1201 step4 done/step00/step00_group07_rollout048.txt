The maximum of the convolution could be at any lag. For the constant sequence, it's at the center (lag n-1).

To minimize the max, we want the convolution to be as flat as possible. This means we want all (f*f)(k) to be as equal as possible.

For a "flat" convolution, we'd want (f*f)(k) ≈ C for all k. Then max ≈ C and score ≈ 2n*C/(sum f)^2.

The sum of all (f*f)(k) values is (sum f)^2 (this is a standard result: sum of all cross-correlation values = |sum f|^2). So if all values are equal, (f*f)(k) = (sum f)^2/(2n-1) for each of the 2n-1 lags. Then max = (sum f)^2/(2n-1) and score = 2n * (sum f)^2/((2n-1)*(sum f)^2) = 2n/(2n-1).

For large n, this approaches 1! So in principle, we can get the score close to 1 if we can make the self-convolution perfectly flat.

But can we? We need f >= 0. The question is whether there exists a non-negative sequence whose self-convolution is (approximately) flat.

This is related to the theory of "perfect autocorrelation" or "flat power spectrum" sequences. In the frequency domain, a flat autocorrelation means |FFT(f)|^2 is constant (except at DC). This means |FFT(f)(k)| is constant for all non-DC frequencies.

For a real non-negative sequence f, can |FFT(f)(k)| be constant for all non-DC k? This is related to "Zadoff-Chu" sequences and related constructions, but those are complex-valued. For real non-negative sequences, it's more restrictive.
