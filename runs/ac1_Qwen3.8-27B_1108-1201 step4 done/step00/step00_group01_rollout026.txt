Here u and v are not generally proportional, so Q is NOT PSD. This means the constraint (a*a)[k] <= M is NOT convex.

So the problem is non-convex. We can't use standard convex optimization solvers directly.

However, we can use the following trick: for a FIXED support pattern (which elements are zero and which are positive), the problem becomes a convex QCQP (or even a QP). But the support pattern is part of the optimization.

This suggests an **alternating approach**:

3. Update the support based on the solution

Actually, let me reconsider the problem from scratch.

The objective is `2n * max(a*a) / (sum a)^2`. Since it's scale-invariant, let's fix `sum(a) = 1` and minimize `max(a*a)`.

The minimum possible value of `max(a*a)` is `(sum a)^2 / (2n-1) = 1/(2n-1)` (by the pigeonhole principle, since sum of all (a*a)[k] = (sum a)^2 = 1, and there are 2n-1 values).

So the minimum objective is `2n/(2n-1)`, achieved when all (a*a)[k] are equal. But can a non-negative sequence achieve a flat convolution? Probably not exactly, but maybe approximately.

For a flat convolution, we'd need (a*a)[k] = 1/(2n-1) for all k. This is a system of quadratic equations in a. It's like finding a "perfect" autocorrelation sequence, which is related to Golay complementary sequences and other combinatorial designs.

For non-negative sequences, this is likely impossible (the boundary effects of the convolution make it hard to be flat). But we can get close.

**Key idea: Use a sequence that is "spread out" in a way that minimizes the convolution peak.**

One approach: start with a random non-negative sequence and use gradient descent to flatten the convolution.

Let me think about the gradient more carefully. If we define f(a) = max_k (a*a)[k], and the max is achieved at k*, then:
∇f(a) = 2 * P(a, k*) where P(a, k*)[i] = a[k*-i] if 0 <= k*-i < n else 0.

So the gradient is 2 times a "folded" version of a. The folding maps index i to index k*-i.

The subgradient descent step is:
a ← a - η * 2 * P(a, k*)

This means: for each i, we reduce a[i] by an amount proportional to a[k*-i]. So we're reducing a[i] more when its "partner" a[k*-i] is large. This makes sense: if both a[i] and a[k*-i] are large, their product a[i]*a[k*-i] contributes a lot to the peak, so we should reduce at least one of them.

But the update reduces a[i] based on a[k*-i], not a[i] itself. This is like a "cross" operation.

Let me think about what happens after one step:
a_new[i] = a[i] - 2η * a[k*-i]

The new convolution at k* is:
(a_new * a_new)[k*] = sum_j a_new[j] * a_new[k*-j]
= sum_j (a[j] - 2η*a[k*-j]) * (a[k*-j] - 2η*a[j])
= sum_j a[j]*a[k*-j] - 2η*sum_j a[j]*a[j] - 2η*sum_j a[k*-j]*a[k*-j] + 4η^2*sum_j a[k*-j]*a[j]
= (a*a)[k*] - 4η*sum_j a[j]^2 + 4η^2*(a*a)[k*]
= (a*a)[k*] * (1 + 4η^2) - 4η * ||a||_2^2

For this to decrease: (a*a)[k*] * (1 + 4η^2) - 4η * ||a||_2^2 < (a*a)[k*]
=> 4η^2 * (a*a)[k*] < 4η * ||a||_2^2
=> η * (a*a)[k*] < ||a||_2^2
=> η < ||a||_2^2 / (a*a)[k*]

Since (a*a)[k*] >= ||a||_2^2 (the peak is at least the sum of squares... wait, is that true?)

(a*a)[k*] = sum_j a[j]*a[k*-j]. By Cauchy-Schwarz, (sum_j a[j]*a[k*-j])^2 <= (sum_j a[j]^2) * (sum_j a[k*-j]^2) = ||a||_2^4.
So (a*a)[k*] <= ||a||_2^2.

Wait, that means (a*a)[k*] <= ||a||_2^2 = sum a[i]^2. And ||a||_2^2 >= (sum a)^2 / n by Cauchy-Schwarz.

So (a*a)[k*] <= ||a||_2^2, and the condition for decrease is η < ||a||_2^2 / (a*a)[k*] >= 1. So any η < 1 works for the "pure" update (without projection).

But we also need a >= 0, so the projection (clipping to 0) might interfere.

This analysis suggests that a moderate learning rate (say η = 0.1 to 0.5) should work for the descent step.

However, there's a subtlety: after the update, the argmax might shift to a different k, and the new subgradient direction might be different. This can cause oscillation.

For a sequence with sum S, the maximum of the convolution is at most S^2 (if all mass is at one point). The minimum is S^2/(2n-1) (if perfectly spread). The objective ranges from 2n/(2n-1) ≈ 1 to 2n.

For the objective to be 1.5, we need max(a*a) = 1.5 * S^2 / (2n) = 0.75 * S^2 / n.

For a uniform sequence, max(a*a) = S^2/n. So we need the max to be 25% below the uniform value.

Is this achievable? The convolution of a uniform sequence is triangular, peaking at n. To reduce the peak, we need to "reshape" the sequence.

One idea: use a sequence that is "anti-triangular" in some sense. If the sequence is high at the edges and low in the middle, the convolution might be flatter.

Let me try: a[i] = 1 + α * (2i/(n-1) - 1)^2 for i = 0, ..., n-1.
This is a parabola with minimum at the center.

For α = 1: a[i] = 1 + (2i/(n-1) - 1)^2
At i=0: a[0] = 1 + 1 = 2
At i=n/2: a[n/2] = 1
At i=n-1: a[n-1] = 2

sum ≈ n * (1 + 1/3) = 4n/3 (approximately, since the average of (x-1)^2 over [-1,1] is 1/3)

The convolution of a parabolic sequence... this is getting complex. Let me just estimate.

For a[i] = 1 + (2i/(n-1) - 1)^2, the convolution at the center (k = n-1) would be:
(a*a)[n-1] = sum_j a[j] * a[n-1-j]

Since a is symmetric (a[j] = a[n-1-j]), this is sum_j a[j]^2.

sum_j a[j]^2 ≈ n * E[a^2] where a is distributed as 1 + X^2, X ~ Uniform(-1,1).
E[a] = 1 + E[X^2] = 1 + 1/3 = 4/3
E[a^2] = E[(1+X^2)^2] = 1 + 2E[X^2] + E[X^4] = 1 + 2/3 + 1/5 = 1 + 0.667 + 0.2 = 1.867

So (a*a)[n-1] ≈ n * 1.867
S = sum a ≈ n * 4/3
S^2 ≈ n^2 * 16/9

objective ≈ 2n * n * 1.867 / (n^2 * 16/9) = 2 * 1.867 * 9/16 = 2 * 1.05 = 2.1

That's worse than 2! The "valley in the middle" hurts because it increases the variance.

What about a[i] = 1 + α * (2i/(n-1) - 1) (linear ramp)?
a is not symmetric. a[0] = 1-α, a[n-1] = 1+α.
(a*a)[n-1] = sum_j a[j]*a[n-1-j] = sum_j (1 + α(2j/(n-1)-1)) * (1 + α(2(n-1-j)/(n-1)-1))
= sum_j (1 + α(2j/(n-1)-1))(1 - α(2j/(n-1)-1))
= sum_j (1 - α^2(2j/(n-1)-1)^2)
= n - α^2 * sum_j (2j/(n-1)-1)^2
≈ n - α^2 * n/3

S = sum a = n (the linear terms cancel)
S^2 = n^2

objective ≈ 2n * (n - α^2 n/3) / n^2 = 2(1 - α^2/3)

For α = 1: objective ≈ 2 * (1 - 1/3) = 4/3 ≈ 1.333!

Wait, that's way below 2! Let me double-check.

For a linear ramp a[i] = 1 + α*(2i/(n-1) - 1):
- a[0] = 1 - α
- a[n-1] = 1 + α
- a[i] = 1 + α*(2i - n + 1)/(n-1)

Let me compute (a*a)[n-1] = sum_{j=0}^{n-1} a[j] * a[n-1-j]

Let t_j = (2j - n + 1)/(n-1). Then a[j] = 1 + α*t_j.
and a[n-1-j] = 1 + α*(2(n-1-j) - n + 1)/(n-1) = 1 + α*(n - 1 - 2j)/(n-1) = 1 - α*t_j.

So a[j]*a[n-1-j] = (1+α*t_j)(1-α*t_j) = 1 - α^2*t_j^2.

sum_j (1 - α^2*t_j^2) = n - α^2 * sum_j t_j^2.

For t_j = (2j-n+1)/(n-1), j = 0, ..., n-1:
sum_j t_j^2 = sum_j ((2j-n+1)^2)/(n-1)^2

Let m = n-1. t_j = (2j-m)/m, j=0,...,m.
sum_j t_j^2 = (1/m^2) * sum_j (2j-m)^2 = (1/m^2) * sum_j (4j^2 - 4jm + m^2)
= (1/m^2) * (4*sum j^2 - 4m*sum j + m^2 * (m+1))
= (1/m^2) * (4*m(m+1)(2m+1)/6 - 4m*m(m+1)/2 + m^2*(m+1))
= (m+1)/m^2 * (4(2m+1)/6 - 2m + m)
= (m+1)/m^2 * (2(2m+1)/3 - m)
= (m+1)/m^2 * (4m/3 + 2/3 - m)
= (m+1)/m^2 * (m/3 + 2/3)
= (m+1)(m+2)/(3m^2)
≈ 1/3 for large m.

So (a*a)[n-1] ≈ n - α^2 * n/3 = n(1 - α^2/3).
