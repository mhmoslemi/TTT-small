At the optimum, we have:
- $\text{conv}[k^*] = M$ for some set of peak bins $K^*$
- $\sum_i a[i] = 1$
- $a[i] \geq 0$ for all $i$
- For $a[i] > 0$: the gradient of the Lagrangian is zero

  - where $\lambda_k \geq 0$ are Lagrange multipliers for the active constraints
  - and $\mu$ is the multiplier for $\sum a = 1$

This gives us a system of equations. If we know the active set $K^*$ and the support of $a$ (which indices have $a[i] > 0$), we can solve this system.

The system is:
$$\sum_{k \in K^*} \lambda_k \cdot a[k-i] = \mu \quad \text{for all } i \text{ in support}$$
$$\sum_{i \in \text{support}} a[i] = 1$$
$$\text{conv}[k] = M \quad \text{for } k \in K^*$$

This is a system of $|K^*| + |\text{support}|$ equations in $|K^*| + |\text{support}|$ unknowns ($\lambda_k$, $\mu$, $a[i]$, $M$).

In practice, the support is likely all of $\{0, ..., n-1\}$ (all $a[i] > 0$), and $|K^*|$ is small (maybe 1-5 peak bins). So we have about $n + |K^*|$ equations in $n + |K^*|$ unknowns. The system is nonlinear (the $\text{conv}[k] = M$ equations are quadratic in $a$), but we can solve it with Newton's method.

    a = np.maximum(a, 1e-15)
    a = a / a.sum()
    n = len(a)

        conv = fast_convolve(a)
        scaled = beta * conv
        scaled -= scaled.max()
        p = np.exp(scaled)
        p /= p.sum()
        
        # Gradient of smoothed max w.r.t. a
        grad_a = compute_grad_a(a, p)
        
        # Mirror descent step (multiplicative update):
        # a_new[i] = a[i] * exp(-eta * grad_a[i])
        # Then normalize
        a_new = a * np.exp(-eta * grad_a)
        a_new = np.maximum(a_new, 1e-15)
        a_new = a_new / a_new.sum()
        
        # Check improvement
        obj = fast_convolve(a_new).max()
        if obj < best_obj:
            best_obj = obj
            best_a = a_new.copy()
        a = a_new
        
        # Decrease learning rate
        eta *= 0.999
    
    return best_a, best_obj

Actually, the "constant modulus" problem is: find $a$ (real, non-negative, length $n$) such that $|\text{DFT}_N(a_{padded})|^2$ is as close to constant as possible. This is a non-convex problem.

One approach: **Weinberger's algorithm** or **iterative amplitude adjustment**:
1. Start with some $a$ (e.g., uniform).
2. Compute $A = \text{DFT}(a_{padded})$.
3. Replace $|A|$ with a flat target (e.g., $\sqrt{c}$), keeping the phase.
4. Take IFFT, zero-pad back to length $n$, and project to non-negative.
5. Repeat.

This is similar to the "Gilbert" or "Fienup" algorithm used in optics for phase retrieval.

def spectral_flat_design(n, target_mean=None, n_iter=1000, seed=42):
    """Design a non-negative sequence of length n with flat auto-power spectrum."""
    rng = np.random.default_rng(seed)
    N = 2 * n - 1  # DFT size (minimum for no aliasing)
    
    if target_mean is None:
        target_mean = 1.0 / N  # mean of conv
    
    # Target: |A(omega)|^2 = N * target_mean = 1/N * N = 1 ... hmm
    # Parseval: sum_k conv[k] = (1/N) * sum_omega |A(omega)|^2
    # If conv[k] = target_mean for all k (k=0,...,2n-2), then sum conv = (2n-1)*target_mean = 1
    # So target_mean = 1/(2n-1)
    # (1/N) * sum_omega |A(omega)|^2 = 1, so sum_omega |A(omega)|^2 = N
    # If |A(omega)|^2 = c for all omega, then N*c = N, so c = 1.
    # So target: |A(omega)| = 1 for all omega.
    
    target = np.ones(N)  # target |A(omega)|
    
    # Initialize
    a = rng.dirichlet(np.ones(n) * 0.5)
    
    for it in range(n_iter):
        # Forward: compute spectrum
        A = np.fft.fft(a, N)
        
        # Amplitude adjustment: set |A| to target, keep phase
        phase = A / np.abs(A + 1e-30)
        A_new = target * phase
        
        # Inverse: get time domain
        a_complex = np.fft.ifft(A_new)
        
        # Keep only first n samples, make real and non-negative
        a = np.real(a_complex[:n])
        a = np.maximum(a, 0)
        s = a.sum()
        if s < 1e-10:
            a = np.ones(n) / n
        else:
            a /= s
    
    return a

Actually, one more consideration: for the "peak shaving" method, instead of the previous approach (transfer mass from peak-contributing elements to random positions), I can use a more principled approach:

3. We want to minimize the sum of products of paired elements.

    return 2.0 * np.array([np.dot(a, p[i:i+n]) for i in range(n)])

def lse_value_and_grad_a(a, beta):
    """Return (LSE value, gradient w.r.t. a)."""
    conv = fast_convolve(a)
    scaled = beta * conv
    scaled -= scaled.max()
    p = np.exp(scaled)
    p_sum = p.sum()
    if p_sum < 1e-300:
        p = np.zeros_like(conv)
        p[np.argmax(conv)] = 1.0

        p /= p_sum

    grad_a = compute_grad_a(a, p)

def compute_grad_a_fft(a, p):

    a has length n, p has length 2n-1."""
    n = len(a)
    # We need cross[i] = sum_j a[j] * p[j+i] for i=0,...,n-1
    # cross = a ⋆ p (cross-correlation)
    # Using the relation: (a ⋆ p)[i] = conv(a, p_flipped)[len(p)-1-i]
    # where p_flipped = p[::-1]
    p_flipped = p[::-1]  # length 2n-1

    P = np.fft.rfft(p_flipped, fft_size)
    conv = np.fft.irfft(A * P, fft_size)[:size]
    # cross[i] = conv[len(p)-1-i] = conv[2n-2-i]
    grad = 2.0 * conv[2*n-2 : n-2 : -1]
    return grad

Wait, I need to double-check the indexing. `conv` has length $3n-2$, indexed $0, 1, ..., 3n-3$.

$\text{conv}[k] = \sum_j a[j] \cdot p_{\text{flipped}}[k-j]$ where $p_{\text{flipped}}[m] = p[2n-2-m]$.

So $\text{conv}[k] = \sum_j a[j] \cdot p[2n-2-(k-j)] = \sum_j a[j] \cdot p[2n-2-k+j]$.

Setting $2n-2-k+j = i+j$ (for the cross-correlation formula $\text{cross}[i] = \sum_j a[j] p[i+j]$):
$2n-2-k = i$, so $k = 2n-2-i$.

$\text{cross}[i] = \text{conv}[2n-2-i]$.

For $i = 0$: $\text{conv}[2n-2]$. For $i = n-1$: $\text{conv}[n-1]$.

In numpy: `conv[2*n-2 : n-2 : -1]` gives elements at indices $2n-2, 2n-3, ..., n-1$. That's $n$ elements. ✓

Let me verify with a small example:
- $n=2$, $a = [a_0, a_1]$, $p = [p_0, p_1, p_2]$
- $p_{\text{flipped}} = [p_2, p_1, p_0]$
- $\text{conv}(a, p_{\text{flipped}}) = [a_0 p_2, a_0 p_1 + a_1 p_2, a_0 p_0 + a_1 p_1, a_1 p_0]$

- $\text{cross}[1] = a_0 p_1 + a_1 p_2 = \text{conv}[1] = \text{conv}[2(2)-2-1] = \text{conv}[1]$ ✓

import numpy as np
import time
from scipy.optimize import minimize


def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    if n == 0:
        return np.array([])
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]


def softmax_fn(x):
    """Numerically stable softmax."""
    x = x - x.max()
    e = np.exp(x)
    s = e.sum()
    if s < 1e-300:
        return np.ones(len(x)) / len(x)
    return e / s


def compute_grad_a_fft(a, p):
    """Compute grad[i] = 2 * sum_j a[j] * p[i+j] using FFT.
    a has length n, p has length 2n-1."""
    n = len(a)
    p_flipped = p[::-1]
    size = 3 * n - 2
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    P = np.fft.rfft(p_flipped, fft_size)
    conv = np.fft.irfft(A * P, fft_size)[:size]
    return 2.0 * conv[2 * n - 2 : n - 2 : -1]


def compute_grad_a_direct(a, p):
    """Compute grad[i] = 2 * sum_j a[j] * p[i+j] directly."""
    n = len(a)
    return 2.0 * np.array([np.dot(a, p[i:i + n]) for i in range(n)])


def lse_value_grad_a(a, beta):
    """Return (LSE(beta*conv)/beta, gradient w.r.t. a) for normalized a."""
    conv = fast_convolve(a)
    scaled = beta * conv
    mx = scaled.max()
    scaled -= mx
    p = np.exp(scaled)
    p_sum = p.sum()
    if p_sum < 1e-300:
        p = np.zeros_like(conv)
        p[np.argmax(conv)] = 1.0
        val = conv.max()
    else:
        p /= p_sum
        val = (mx + np.log(p_sum)) / beta
    grad_a = compute_grad_a_fft(a, p)
    return val, grad_a


def true_obj(a):
    """Compute 2n*max(conv(a,a))/(sum(a))^2."""
    n = len(a)
    s = a.sum()
    if s < 0.01:
        return np.inf
    conv = fast_convolve(a)
    return 2.0 * n * conv.max() / (s * s)


def normalize(a):

    a = np.maximum(a, 0.0)

    if s < 1e-15:

    return a / s

    """L-BFGS in softmax parameterization with adaptive beta schedule."""
    if betas is None:

            a_loc = np.maximum(a_loc, 1e-30)

    top_configs.append((best_n, spectral_flat_init(best_n, 200, seed=int(rng.integers(0, 99999)))))

    n_configs = len(top_configs)
    per_config = max(20.0, (p2_budget - (time.monotonic() - t_p2_start)) / n_configs)

    for i, (n, a0) in enumerate(top_configs):
        if time.monotonic() > deadline - 200:
            break
        t_alloc = min(per_config, 250.0)
        if t_alloc < 15:
            break

        print(f"  Config {i}: n={n}", flush=True)

        # Sub-phase A: L-BFGS (60% of allocation)
        t_a = t_alloc * 0.55
        if t_a > 10:
            a_a, obj_a = optimize_lbfgs(a0, t_a,
                                        betas=[10, 25, 50, 100, 200, 500, 1000])
            score_a = true_obj(a_a)
            if score_a < best_score:
                best_score = score_a
                best_a = a_a.copy()
                print(f"    LBFGS: {score_a:.6f}", flush=True)
            a0 = a_a  # continue from L-BFGS result

        # Sub-phase B: Mirror descent (25%)
        t_b = t_alloc * 0.25
        if t_b > 8:
            a_b, obj_b = optimize_mirror(a0, t_b, beta=300, eta0=0.02, decay=0.9995)
            score_b = true_obj(a_b)
            if score_b < best_score:
                best_score = score_b
                best_a = a_b.copy()
                print(f"    Mirror: {score_b:.6f}", flush=True)
            a0 = a_b

        # Sub-phase C: Fine L-BFGS (20%)
        t_c = t_alloc * 0.20
        if t_c > 5:
            a_c, obj_c = optimize_lbfgs(a0, t_c, betas=[200, 500, 1000, 2000])
            score_c = true_obj(a_c)
            if score_c < best_score:
                best_score = score_c
                best_a = a_c.copy()
                print(f"    FineLBFGS: {score_c:.6f}", flush=True)

    # === Phase 3: Polish ===
    print("=== Phase 3: Polish ===", flush=True)
    if best_a is not None:
        remaining = deadline - time.monotonic() - 10.0

        # Peak shaving
        t_ps = remaining * 0.4
        if t_ps > 10:
            a_ps, obj_ps = optimize_peak_shave(best_a, t_ps, seed=777)
            score_ps = true_obj(a_ps)
            if score_ps < best_score:
                best_score = score_ps
                best_a = a_ps.copy()
            print(f"  PeakShave: {best_score:.6f}", flush=True)

        # Fine L-BFGS
        remaining = deadline - time.monotonic() - 10.0
        t_fg = remaining * 0.3
        if t_fg > 8:
            a_fg, obj_fg = optimize_lbfgs(best_a, t_fg, betas=[500, 1000, 2000, 5000])
            score_fg = true_obj(a_fg)
            if score_fg < best_score:
                best_score = score_fg
                best_a = a_fg.copy()
            print(f"  FineGrad: {best_score:.6f}", flush=True)

        # More peak shaving
        remaining = deadline - time.monotonic() - 5.0
        if remaining > 8:
            a_fs, obj_fs = optimize_peak_shave(best_a, remaining, seed=1234)
            score_fs = true_obj(a_fs)
            if score_fs < best_score:
                best_score = score_fs
                best_a = a_fs.copy()
            print(f"  FinalShave: {best_score:.6f}", flush=True)

        # One more L-BFGS if time
        remaining = deadline - time.monotonic() - 3.0
        if remaining > 10:
            a_l2, obj_l2 = optimize_lbfgs(best_a, remaining, betas=[1000, 3000, 10000])
            score_l2 = true_obj(a_l2)
            if score_l2 < best_score:
                best_score = score_l2
                best_a = a_l2.copy()
            print(f"  FinalLBFGS: {best_score:.6f}", flush=True)

    # Fallback
    if best_a is None:
        best_a = np.ones(128) / 128

    # Final verification
    final_score = float(evaluate_sequence(best_a.tolist()))
    if np.isfinite(final_score):
        best_score = final_score
    else:
        best_a = np.ones(128) / 128
        best_score = float(evaluate_sequence(best_a.tolist()))

    print(f"\nFINAL: score={best_score:.6f}, n={len(best_a)}", flush=True)
    return [float(x) for x in best_a]
