   - For the peak, the gradient says: reduce a[i] for i where a[k*-i] is large
   - So: transfer mass from positions i where a[k*-i] is large to positions where a[k*-i] is small
   - Do a line search on the transfer amount
4. **Use multiple "views" of the problem**:
   - The peak might be at different positions at different times
   - Track multiple near-peak positions and use a weighted gradient

Let me also consider: what if the issue is that the previous algorithm got stuck in a local minimum? In that case, I should:
- Try more aggressive restarts
- Try different lengths
- Try different initializations that are structurally different from the parent

Let me write the code now. I'll aim for a clean, effective implementation.

Key design decisions:
1. Use Adam optimizer with exact subgradient (not smoothed)
2. Multiple lengths: 256, 320, 384, 448, 512
3. Diverse initializations
4. Peak-targeted coordinate moves as a secondary optimization
5. Time management: allocate time proportionally to phases

Let me also think about the "transfer" move more carefully:

Given current a, peak at k*, gradient g[i] = 2*a[k*-i] (if valid):
- We want to DECREASE a[i] where g[i] is large (because increasing a[i] would increase c[k*])
- We want to INCREASE a[j] where g[j] is small
- Transfer: a[i] -= δ, a[j] += δ
- The change in c[k*]: Δc[k*] = -δ * g[i] + δ * g[j] = δ * (g[j] - g[i])
- Since g[i] > g[j], this is negative → c[k*] decreases ✓
- But we also need to check that no OTHER c[k] increases above the current max!

The other c[k] values change as:
Δc[k] = -δ * 2*a[k-i] + δ * 2*a[k-j] (for k where both i and j contribute)
= 2δ * (a[k-j] - a[k-i])

So we need: for all k, c[k] + 2δ*(a[k-j] - a[k-i]) ≤ current_max (or at least not exceed it by too much)

This gives us a bound on δ:
δ ≤ (current_max - c[k]) / (2*(a[k-j] - a[k-i])) for all k where a[k-j] > a[k-i]

The optimal δ is the minimum over all such k (and also δ ≤ a[i] to keep non-negativity).

This is a clean 1D water-filling problem!

Let me implement this. The computational cost per move is O(n) (to compute the bound on δ), and we do O(n) moves per iteration, so total O(n^2) per outer iteration. For n=384, that's about 150K operations per outer iteration, which is very fast.

Actually, for each move we pick a specific (i,j) pair, so it's O(n) per move. If we do, say, 10 moves per outer iteration, it's O(10n) = O(4000) which is negligible.

"""
Minimizes 2n*max(conv(a,a))/(sum(a))^2 using:
1. Adam optimizer with exact subgradient descent on the simplex
2. Peak-targeted coordinate transfer moves with analytic line search
3. Multi-length diverse search with population restarts
4. Final polish with fine-grained coordinate descent
"""

import numpy as np
import time

def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    if n == 0:
        return np.array([])
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]

def project_simplex(v):
    """Euclidean projection onto the probability simplex {x >= 0, sum(x)=1}."""
    n = len(v)
    if n == 1:
        return np.array([1.0])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)

def subgradient_peak(a, k):
    """Compute subgradient of c[k] = sum_i a[i]*a[k-i] w.r.t. a."""
    n = len(a)
    g = np.zeros(n)
    for i in range(n):
        ki = k - i
        if 0 <= ki < n:
            if k == 2 * i:
                g[i] = 2.0 * a[i]
            else:
                g[i] = 2.0 * a[ki]
    return g

def objective(a):
    """Compute 2n * max(conv(a,a)) assuming sum(a) = 1."""
    n = len(a)
    c = fast_convolve(a)
    return 2.0 * n * c.max()

def adam_subgradient_descent(a0, time_limit, seed=0, lr=0.01, beta1=0.9, beta2=0.999,
                              eps=1e-8, perturb_every=500, perturb_scale=0.005):
    """
    Adam optimizer with exact subgradient for min 2n*max(conv(a,a)) on simplex.
    """
    rng = np.random.default_rng(seed)
    a = np.maximum(a0.astype(np.float64), 0.0).copy()
    s = a.sum()
    if s < 1e-15:
        a = np.ones(len(a)) / len(a)
    else:
        a = a / s
    n = len(a)
    
    m = np.zeros(n)
    v = np.zeros(n)
    t = 0
    
    conv = fast_convolve(a)
    best_obj = 2.0 * n * conv.max()
    best_a = a.copy()
    
    t0 = time.monotonic()
    no_improve = 0
    
    while time.monotonic() - t0 < time_limit:
        conv = fast_convolve(a)
        max_val = conv.max()
        # Find all near-max peaks (within 5% of max)
        threshold = max_val * 0.95
        peak_mask = conv >= threshold
        peak_indices = np.where(peak_mask)[0]
        
        # Compute weighted subgradient (uniform weight over near-max peaks)
        g = np.zeros(n)
        for k in peak_indices:
            k = int(k)
            for i in range(n):
                ki = k - i
                if 0 <= ki < n:
                    g[i] += 2.0 * a[ki]
        g /= len(peak_indices)
        
        # Adam update
        t += 1
        m = beta1 * m + (1 - beta1) * g
        v = beta2 * v + (1 - beta2) * g * g
        m_hat = m / (1 - beta1**t)
        v_hat = v / (1 - beta2**t)
        
        # Adaptive learning rate
        lr_t = lr * np.sqrt(1 - beta2**t) / (1 - beta1**t)
        
        a_new = a - lr_t * m_hat / (np.sqrt(v_hat) + eps)
        a = project_simplex(a_new)
        
        # Check improvement
        conv = fast_convolve(a)
        cur_obj = 2.0 * n * conv.max()
        
        if cur_obj < best_obj - 1e-10:
            best_obj = cur_obj
            best_a = a.copy()
            no_improve = 0
        else:
            no_improve += 1
        
        # Perturbation to escape local minima
        if no_improve >= perturb_every:
            noise = rng.standard_normal(n) * perturb_scale
            a = project_simplex(a + noise)
            m *= 0.5
            v *= 0.5
            no_improve = 0
            perturb_every = int(perturb_every * 1.3)
            perturb_scale *= 0.7
    
    return best_a, best_obj

def peak_transfer_optimize(a0, time_limit, seed=0, max_moves_per_iter=20):
    """
    Peak-targeted coordinate transfer with analytic line search.
    Transfers mass from positions that contribute to the peak to positions that don't.
    """
    rng = np.random.default_rng(seed)
    a = np.maximum(a0.astype(np.float64), 0.0).copy()
    s = a.sum()
    if s < 1e-15:
        a = np.ones(len(a)) / len(a)
    else:
        a = a / s
    n = len(a)
    
    conv = fast_convolve(a)
    best_obj = 2.0 * n * conv.max()
    best_a = a.copy()
    
    t0 = time.monotonic()
    iterations = 0
    
    while time.monotonic() - t0 < time_limit:
        conv = fast_convolve(a)
        max_val = conv.max()
        
        # Find the primary peak
        k_star = int(np.argmax(conv))
        
        # Gradient for the peak: g[i] = 2*a[k_star - i] if valid
        g = np.zeros(n)
        for i in range(n):
            ki = k_star - i
            if 0 <= ki < n:
                g[i] = 2.0 * a[ki]
        
        # Try max_moves_per_iter random transfers
        moved = False
        for _ in range(max_moves_per_iter):
            # Choose source: high gradient (contributes to peak)
            # Choose target: low gradient (doesn't contribute to peak)
            sorted_idx = np.argsort(g)
            # Source from top half, target from bottom half
            half = n // 2
            sources = sorted_idx[half:]
            targets = sorted_idx[:half]
            
            if len(sources) == 0 or len(targets) == 0:
                break
            
            i = int(rng.choice(sources))
            j = int(rng.choice(targets))
            
            if a[i] < 1e-10:
                continue
            
            # Compute the optimal transfer amount
            # After transferring δ from i to j:
            # c[k] changes by: δ * (2*a[k-j] - 2*a[k-i]) for k where both contribute
            # We need c[k] + δ * (2*a[k-j] - 2*a[k-i]) <= max_val for all k
            # (approximately, ignoring second-order effects)
            
            # Compute delta_conv[k] for each k
            # delta_conv[k] = -2*δ*a[k-i] + 2*δ*a[k-j] (approximate, ignoring the a[i]*a[i] term)
            # More precisely:
            # If k-i is in [0,n-1]: c[k] loses 2*δ*a[k-i] (or δ*a[i] if k=2i... let's use the 2*a[k-i] approx)
            # If k-j is in [0,n-1]: c[k] gains 2*δ*a[k-j]
            
            delta = np.zeros(2 * n - 1)
            # Contribution from removing δ from position i
            for k in range(2 * n - 1):
                ki = k - i
                if 0 <= ki < n:
                    delta[k] -= 2.0 * a[ki] * δ  # placeholder, will compute bound
                kj = k - j
                if 0 <= kj < n:
                    delta[k] += 2.0 * a[kj] * δ
            
            # Actually, let's compute the constraint directly
            # For the transfer to be valid, we need:
            # c[k] + δ * d[k] <= max_val for all k
            # where d[k] = -2*a[k-i] (if valid) + 2*a[k-j] (if valid)
            
            d = np.zeros(2 * n - 1)
            for k in range(2 * n - 1):
                ki = k - i
                if 0 <= ki < n:
                    d[k] -= 2.0 * a[ki]
                kj = k - j
                if 0 <= kj < n:
                    d[k] += 2.0 * a[kj]
            
            # Find max allowed δ
            max_delta = a[i]  # Can't transfer more than a[i]
            for k in range(2 * n - 1):
                if d[k] > 1e-12:
                    allowed = (max_val - conv[k]) / d[k]
                    if allowed < max_delta:
                        max_delta = allowed
            
            if max_delta <= 1e-10:
                continue
            
            # Use a fraction of the max allowed delta
            delta_use = min(max_delta, 0.5 * a[i])
            
            # Apply transfer
            a_try = a.copy()
            a_try[i] -= delta_use
            a_try[j] += delta_use
            
            conv_try = fast_convolve(a_try)
            obj_try = 2.0 * n * conv_try.max()
            
            if obj_try < best_obj - 1e-12:
                best_obj = obj_try
                best_a = a_try.copy()
                a = a_try.copy()
                moved = True
                conv = conv_try
                max_val = conv.max()
                # Recompute gradient
                k_star = int(np.argmax(conv))
                g[:]= 0
                for ii in range(n):
                    ki = k_star - ii
                    if 0 <= ki < n:
                        g[ii] = 2.0 * a[ki]
        
        iterations += 1
        if not moved and iterations % 100 == 0:
            # Try random perturbation
            noise = rng.standard_normal(n) * 0.002
            a = project_simplex(a + noise)
    
    return best_a, best_obj

def generate_diverse_inits(n, rng, parent=None):
    """Generate diverse initializations."""
    inits = {}
    x = np.arange(n, dtype=np.float64)
    
    inits['uniform'] = np.ones(n) / n
    
    # Sinusoidal patterns (inspired by m-sequences)
    for freq in [1, 2, 3, 5]:
        s = 0.5 + 0.4 * np.sin(2 * np.pi * freq * x / n)
        s = np.maximum(s, 0.01)
        s /= s.sum()
        inits[f'sin_{freq}'] = s
    
    # Cosine window
    cw = 0.5 * (1 + np.cos(2 * np.pi * x / (n - 1)))
    cw = np.maximum(cw, 0.01)
    cw /= cw.sum()
    inits['cosine'] = cw
    
    # Gaussian
    g = np.exp(-2.0 * ((x - n/2) / (n/3))**2)
    g /= g.sum()
    inits['gaussian'] = g
    
    # Bimodal
    bi = np.zeros(n)
    edge = max(2, n // 4)
    bi[:edge] = 1.0
    bi[-edge:] = 1.0
    bi /= bi.sum()
    inits['bimodal'] = bi
    
    # Random
    inits['rand1'] = rng.dirichlet(np.ones(n) * 0.3)
    inits['rand2'] = rng.dirichlet(np.ones(n) * 1.0)
    inits['rand3'] = rng.dirichlet(np.ones(n) * 3.0)
    
    # Sparse random
    sparse = np.zeros(n)
    k_sparse = max(5, n // 10)
    idx = rng.choice(n, size=k_sparse, replace=False)
    sparse[idx] = 1.0
    sparse /= sparse.sum()
    inits['sparse'] = sparse
    
    # Parent
    if parent is not None and len(parent) > 0:
        if len(parent) >= n:
            pp = np.maximum(parent[:n], 0)
        else:
            pp = np.interp(np.linspace(0, 1, n), np.linspace(0, 1, len(parent)), parent)
        pp = np.maximum(pp, 0)
        ps = pp.sum()
        if ps > 1e-10:
            inits['parent'] = pp / ps
    
    return inits

import numpy as np
import time


def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    if n == 0:
        return np.array([])
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]


def project_simplex(v):
    """Euclidean projection onto the probability simplex {x >= 0, sum(x)=1}."""
    n = len(v)
    if n == 1:
        return np.array([1.0])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)


def compute_subgradient(a, k):
    """
    Compute subgradient of c[k] = sum_i a[i]*a[k-i] w.r.t. a.
    Returns vector g where g[i] = d c[k] / d a[i].
    """
    n = len(a)
    g = np.zeros(n)
    i_start = max(0, k - n + 1)
    i_end = min(n - 1, k)
    if i_start > i_end:
        return g
    # g[i] = 2*a[k-i] for i in [i_start, i_end]
    # k-i ranges from k-i_start down to k-i_end
    g[i_start:i_end + 1] = 2.0 * a[k - i_end:k - i_start + 1][::-1]
    return g


def score_from_conv(a, conv):
    """Compute objective 2*n*max(conv) assuming sum(a)=1."""
    n = len(a)
    return 2.0 * n * conv.max()


def adam_subgradient_descent(a0, time_limit, seed=0, lr=0.015, beta1=0.9,
                              beta2=0.999, eps=1e-8, perturb_every=400,
                              perturb_scale=0.008, near_peak_frac=0.92):
    """
    Adam optimizer with exact subgradient for min 2n*max(conv(a,a)) on simplex.
    Uses multiple near-peak positions for a more robust gradient.
    """
    rng = np.random.default_rng(seed)
    a = np.maximum(a0.astype(np.float64), 0.0).copy()
    s = a.sum()
    if s < 1e-15:
        a = np.ones(len(a)) / len(a)
    else:
        a = a / s
    n = len(a)

    m = np.zeros(n)
    v = np.zeros(n)
    t = 0

    conv = fast_convolve(a)
    best_obj = score_from_conv(a, conv)
    best_a = a.copy()

    t0 = time.monotonic()
    no_improve = 0
    pe = perturb_every

    while time.monotonic() - t0 < time_limit:
        conv = fast_convolve(a)
        max_val = conv.max()

        # Find near-max peaks
        threshold = max_val * near_peak_frac
        peak_indices = np.where(conv >= threshold)[0]

        # Compute weighted subgradient
        g = np.zeros(n)
        for k in peak_indices:
            g += compute_subgradient(a, int(k))
        g /= max(1, len(peak_indices))

        # Adam update
        t += 1
        m = beta1 * m + (1.0 - beta1) * g
        v = beta2 * v + (1.0 - beta2) * g * g
        m_hat = m / (1.0 - beta1 ** t)
        v_hat = v / (1.0 - beta2 ** t)

        # Adaptive LR (standard Adam)
        lr_t = lr

        a_new = a - lr_t * m_hat / (np.sqrt(v_hat) + eps)
        a = project_simplex(a_new)

        # Check improvement
        conv = fast_convolve(a)
        cur_obj = score_from_conv(a, conv)

        if cur_obj < best_obj - 1e-12:
            best_obj = cur_obj
            best_a = a.copy()
            no_improve = 0
        else:
            no_improve += 1

        # Perturbation to escape local minima
        if no_improve >= pe:
            noise = rng.standard_normal(n) * perturb_scale
            a = project_simplex(a + noise)
            m *= 0.3
            v *= 0.3
            no_improve = 0
            pe = int(pe * 1.2)
            perturb_scale = max(0.001, perturb_scale * 0.6)

        # Early exit if very close to convergence
        if no_improve > 5000:
            break

    return best_a, best_obj


def multiplicative_descent(a0, time_limit, seed=0, lr=0.05,
                           near_peak_frac=0.9, perturb_every=500, perturb_scale=0.005):
    """
    Multiplicative (exponential) updates: a[i] *= exp(-lr * g[i]), then renormalize.
    Naturally maintains non-negativity.
    """
    rng = np.random.default_rng(seed)
    a = np.maximum(a0.astype(np.float64), 0.0).copy()
    s = a.sum()
    if s < 1e-15:
        a = np.ones(len(a)) / len(a)
    else:
        a = a / s
    n = len(a)

    # Ensure no zeros for log
    a = np.maximum(a, 1e-15)
    a = a / a.sum()

    conv = fast_convolve(a)
    best_obj = score_from_conv(a, conv)
    best_a = a.copy()

    t0 = time.monotonic()
    no_improve = 0
    pe = perturb_every

    while time.monotonic() - t0 < time_limit:
        conv = fast_convolve(a)
        max_val = conv.max()

        threshold = max_val * near_peak_frac
        peak_indices = np.where(conv >= threshold)[0]

        g = np.zeros(n)
        for k in peak_indices:
            g += compute_subgradient(a, int(k))
        g /= max(1, len(peak_indices))

        # Multiplicative update
        a = a * np.exp(-lr * g)
        a = np.maximum(a, 1e-15)
        a = a / a.sum()

        conv = fast_convolve(a)
        cur_obj = score_from_conv(a, conv)

        if cur_obj < best_obj - 1e-12:
            best_obj = cur_obj
            best_a = a.copy()
            no_improve = 0
        else:
            no_improve += 1

        if no_improve >= pe:
            noise = rng.standard_normal(n) * perturb_scale
            a = np.maximum(a + noise, 1e-15)
            a = a / a.sum()
            no_improve = 0
            pe = int(pe * 1.3)
            perturb_scale = max(0.001, perturb_scale * 0.5)
            lr = max(0.001, lr * 0.7)

        if no_improve > 5000:
            break

    return best_a, best_obj


def peak_transfer_optimize(a0, time_limit, seed=0, max_moves=30, min_delta=1e-8):
    """
    Peak-targeted coordinate transfer with vectorized analytic bounds.
    Transfers mass from high-contribution positions to low-contribution ones.
    """
    rng = np.random.default_rng(seed)
    a = np.maximum(a0.astype(np.float64), 0.0).copy()
    s = a.sum()
    if s < 1e-15:
        a = np.ones(len(a)) / len(a)
    else:
        a = a / s
    n = len(a)

    conv = fast_convolve(a)
    best_obj = score_from_conv(a, conv)
    best_a = a.copy()

    t0 = time.monotonic()
    stuck = 0

    while time.monotonic() - t0 < time_limit:
        conv = fast_convolve(a)
        max_val = conv.max()
        k_star = int(np.argmax(conv))

        # Gradient for the peak
        g = compute_subgradient(a, k_star)

        # Rank positions by gradient
        sorted_idx = np.argsort(g)
        half = n // 2
        targets = sorted_idx[:half]    # Low gradient (good to increase)
        sources = sorted_idx[half:]    # High gradient (good to decrease)

        moved = False
        for _ in range(max_moves):
            # Choose random source and target
            i = int(rng.choice(sources))
            j = int(rng.choice(targets))

            if a[i] < min_delta:
                continue
            if g[i] <= g[j] + 1e-12:
                continue

            # Compute d[k] = change in c[k] per unit transfer from i to j
            # d[k] = -2*a[k-i] (if valid) + 2*a[k-j] (if valid)
            d = np.zeros(2 * n - 1)
            # -2*a[k-i] for k in [i, i+n-1]
            d[i:i + n] -= 2.0 * a
            # +2*a[k-j] for k in [j, j+n-1]
            d[j:j + n] += 2.0 * a

            # Find max allowed delta such that c[k] + delta*d[k] <= max_val for all k
            pos_mask = d > 1e-12
            if np.any(pos_mask):
                allowed = (max_val - conv[pos_mask]) / d[pos_mask]
                max_delta = min(a[i], np.min(allowed))
            else:
                max_delta = a[i]

            if max_delta < min_delta:
                continue

            # Use a fraction for safety
            delta = min(max_delta * 0.8, a[i] * 0.3)

            a_try = a.copy()
            a_try[i] -= delta
            a_try[j] += delta

            conv_try = fast_convolve(a_try)
            obj_try = score_from_conv(a_try, conv_try)

            if obj_try < best_obj - 1e-12:
                best_obj = obj_try
                best_a = a_try.copy()
                a = a_try.copy()
                conv = conv_try
                max_val = conv.max()
                k_star = int(np.argmax(conv))
                g = compute_subgradient(a, k_star)
                sorted_idx = np.argsort(g)
                targets = sorted_idx[:half]
                sources = sorted_idx[half:]
                moved = True

        if moved:
            stuck = 0
        else:
            stuck += 1
            if stuck > 50:
                # Random perturbation to escape
                noise = rng.standard_normal(n) * 0.003
                a = project_simplex(a + noise)
                stuck = 0
                if stuck > 200:
                    break

    return best_a, best_obj


def coordinate_descent_polish(a0, time_limit, seed=0, pairs_per_iter=10):
    """
    Pairwise coordinate descent: try small transfers between random pairs,
    accept if objective improves. Very fine-grained local search.
    """
    rng = np.random.default_rng(seed)
    a = np.maximum(a0.astype(np.float64), 0.0).copy()
    s = a.sum()
    if s < 1e-15:
        a = np.ones(len(a)) / len(a)
    else:
        a = a / s
    n = len(a)

    conv = fast_convolve(a)
    best_obj = score_from_conv(a, conv)
    best_a = a.copy()

    t0 = time.monotonic()

    while time.monotonic() - t0 < time_limit:
        conv = fast_convolve(a)
        max_val = conv.max()
        k_star = int(np.argmax(conv))
        g = compute_subgradient(a, k_star)

        improved = False
        for _ in range(pairs_per_iter):
            # Choose pairs biased towards high->low gradient
            i = int(rng.integers(0, n))
            j = int(rng.integers(0, n))
            if i == j or a[i] < 1e-10:
                continue
            if g[i] <= g[j]:
                continue

            # Try small fractions of a[i]
            for frac in [0.01, 0.03, 0.05, 0.1]:
                delta = a[i] * frac
                a_try = a.copy()
                a_try[i] -= delta
                a_try[j] += delta

                conv_try = fast_convolve(a_try)
                obj_try = score_from_conv(a_try, conv_try)

                if obj_try < best_obj - 1e-12:
                    best_obj = obj_try
                    best_a = a_try.copy()
                    a = a_try.copy()
                    conv = conv_try
                    max_val = conv.max()
                    k_star = int(np.argmax(conv))
                    g = compute_subgradient(a, k_star)
                    improved = True
                    break
                elif obj_try < max_val * 2 * n:
                    # Slight improvement in peak even if not overall
                    break

        if not improved:
            # Try peak-targeted move
            sorted_idx = np.argsort(g)
            i = int(sorted_idx[-1])  # Highest gradient
            j = int(sorted_idx[0])   # Lowest gradient
            if a[i] > 1e-10 and g[i] > g[j]:
                for frac in [0.005, 0.01, 0.02, 0.05]:
                    delta = a[i] * frac
                    a_try = a.copy()
                    a_try[i] -= delta
                    a_try[j] += delta
                    conv_try = fast_convolve(a_try)
                    obj_try = score_from_conv(a_try, conv_try)
                    if obj_try < best_obj - 1e-12:
                        best_obj = obj_try
                        best_a = a_try.copy()
                        a = a_try.copy()
                        break

    return best_a, best_obj


def generate_initializations(n, rng, parent=None):
    """Generate diverse initializations of length n."""
    inits = {}
    x = np.arange(n, dtype=np.float64)

    inits['uniform'] = np.ones(n) / n

    # Sinusoidal patterns
    for freq in [1, 2, 3, 5, 8]:
        s = 0.5 + 0.4 * np.sin(2 * np.pi * freq * x / n + rng.uniform(0, 2 * np.pi))
        s = np.maximum(s, 0.01)
        s /= s.sum()
        inits[f'sin_{freq}'] = s

    # Cosine window
    cw = 0.5 * (1.0 + np.cos(2 * np.pi * x / max(1, n - 1)))
    cw = np.maximum(cw, 0.01)
    cw /= cw.sum()
    inits['cosine'] = cw

    # Gaussian (centered)
    g = np.exp(-2.0 * ((x - n / 2) / (n / 3)) ** 2)
    g /= g.sum()
    inits['gaussian'] = g

    # Bimodal
    bi = np.zeros(n)
    edge = max(2, n // 5)
    bi[:edge] = 1.0
    bi[-edge:] = 1.0
    bi /= bi.sum()
    inits['bimodal'] = bi

    # Random Dirichlet
    inits['rand_a'] = rng.dirichlet(np.ones(n) * 0.3)
    inits['rand_b'] = rng.dirichlet(np.ones(n) * 1.0)
    inits['rand_c'] = rng.dirichlet(np.ones(n) * 3.0)

    # Sparse
    sparse = np.zeros(n)
    k_sp = max(5, n // 8)
    idx = rng.choice(n, size=k_sp, replace=False)
    sparse[idx] = rng.uniform(0.5, 2.0, k_sp)
    sparse /= sparse.sum()
    inits['sparse'] = sparse

    # Alternating (high-low pattern)
    alt = np.ones(n)
    alt[::2] = 1.0
    alt[1::2] = 0.3
    alt /= alt.sum()
    inits['alternating'] = alt

    # Parent-based
    if parent is not None and len(parent) > 0:
        if len(parent) >= n:
            pp = np.maximum(parent[:n], 0)
        else:
            pp = np.interp(np.linspace(0, 1, n), np.linspace(0, 1, len(parent)), parent)
        pp = np.maximum(pp, 0)
        ps = pp.sum()
        if ps > 1e-10:
            inits['parent'] = pp / ps

    return inits

        if t_alloc < 25:

        init_score = 2.0 * n * fast_convolve(a0).max()
        print(f"  Config {idx}: n={n}, init_score={init_score:.6f}, alloc={t_alloc:.0f}s", flush=True)

        # Sub-phase A: Adam (35%)
        t_a = t_alloc * 0.35
        a_a, _ = adam_subgradient_descent(
            a0, t_a, seed=int(rng.integers(0, 100000)),
            lr=0.012, beta1=0.9, beta2=0.999,
            perturb_every=250, perturb_scale=0.008, near_peak_frac=0.9)

        score_a = float(evaluate_sequence(a_a.tolist()))
        if np.isfinite(score_a) and score_a < best_score:
            best_score = score_a
            best_sequence = a_a.copy()
            print(f"    Adam: {score_a:.6f}", flush=True)

        # Sub-phase B: Multiplicative (20%)
        t_b = t_alloc * 0.20
        if t_b > 15:
            a_b, _ = multiplicative_descent(
                a_a, t_b, seed=int(rng.integers(0, 100000)),
                lr=0.04, near_peak_frac=0.88,
                perturb_every=300, perturb_scale=0.005)

            score_b = float(evaluate_sequence(a_b.tolist()))
            if np.isfinite(score_b) and score_b < best_score:
                best_score = score_b
                best_sequence = a_b.copy()
                print(f"    Multi: {score_b:.6f}", flush=True)
            if np.isfinite(score_b) and score_b < score_a:
                a_a = a_b

        # Sub-phase C: Peak transfer (25%)
        t_c = t_alloc * 0.25
        if t_c > 15:
            a_c, _ = peak_transfer_optimize(
                a_a, t_c, seed=int(rng.integers(0, 100000)),
                max_moves=25)

            score_c = float(evaluate_sequence(a_c.tolist()))
            if np.isfinite(score_c) and score_c < best_score:
                best_score = score_c
                best_sequence = a_c.copy()
                print(f"    Transfer: {score_c:.6f}", flush=True)
            if np.isfinite(score_c) and score_c < score_a:
                a_a = a_c

        # Sub-phase D: Fine Adam (20%)
        t_d = t_alloc * 0.20
        if t_d > 10:
            a_d, _ = adam_subgradient_descent(
                a_a, t_d, seed=int(rng.integers(0, 100000)),
                lr=0.004, beta1=0.95, beta2=0.999,
                perturb_every=400, perturb_scale=0.003, near_peak_frac=0.95)

            score_d = float(evaluate_sequence(a_d.tolist()))
            if np.isfinite(score_d) and score_d < best_score:
                best_score = score_d
                best_sequence = a_d.copy()
                print(f"    FineAdam: {score_d:.6f}", flush=True)

    print(f"Phase 2 done. Best: {best_score:.6f} (n={len(best_sequence)})", flush=True)

    # === Phase 3: Final polish (300s) ===
    print("=== Phase 3: Final Polish ===", flush=True)
    if best_sequence is not None:
        remaining = deadline - time.monotonic() - 15.0
        method_idx = 0
        polish_improvements = 0

        while time.monotonic() < deadline - 15:
            t_chunk = min(80.0, deadline - time.monotonic() - 15)
            if t_chunk < 10:
                break

            prev_best = best_score

            if method_idx % 4 == 0:
                a_tmp, _ = adam_subgradient_descent(
                    best_sequence, t_chunk, seed=int(rng.integers(0, 10**9)),
                    lr=0.003, beta1=0.95, beta2=0.999,
                    perturb_every=300, perturb_scale=0.002, near_peak_frac=0.95)
            elif method_idx % 4 == 1:
                a_tmp, _ = peak_transfer_optimize(
                    best_sequence, t_chunk, seed=int(rng.integers(0, 10**9)),
                    max_moves=30)
            elif method_idx % 4 == 2:
                a_tmp, _ = coordinate_descent_polish(
                    best_sequence, t_chunk, seed=int(rng.integers(0, 10**9)),
                    pairs_per_iter=15)
            else:
                a_tmp, _ = multiplicative_descent(
                    best_sequence, t_chunk, seed=int(rng.integers(0, 10**9)),
                    lr=0.02, near_peak_frac=0.93,
                    perturb_every=400, perturb_scale=0.003)

            score_tmp = float(evaluate_sequence(a_tmp.tolist()))
            if np.isfinite(score_tmp) and score_tmp < best_score:
                best_score = score_tmp
                best_sequence = a_tmp.copy()
                polish_improvements += 1
                print(f"  Polish [{method_idx}]: {score_tmp:.6f}", flush=True)

            method_idx += 1

            # If no improvement in 3 consecutive polishes, try restart
            if method_idx % 3 == 0 and polish_improvements == 0:
                # Small random restart around best
                noise = rng.standard_normal(len(best_sequence)) * 0.005
                a_restart = project_simplex(best_sequence + noise)
                score_r = float(evaluate_sequence(a_restart.tolist()))
                if np.isfinite(score_r) and score_r < best_score:
                    best_score = score_r
                    best_sequence = a_restart.copy()
                    polish_improvements += 1
                    print(f"  Restart: {score_r:.6f}", flush=True)
                polish_improvements = 0

    # Fallback
    if best_sequence is None:
        best_sequence = np.ones(256) / 256

    # Final verification and cleanup
    best_sequence = np.clip(np.asarray(best_sequence, dtype=np.float64), 0.0, 1000.0)
    final_score = float(evaluate_sequence(best_sequence.tolist()))
    if np.isfinite(final_score):
        best_score = final_score
    else:
        # Emergency fallback
        best_sequence = np.ones(128) / 128
        best_score = float(evaluate_sequence(best_sequence.tolist()))

    print(f"\nFINAL: score={best_score:.6f}, n={len(best_sequence)}", flush=True)
    return [float(x) for x in best_sequence]
