def project_simplex(v):
    n = len(v)
    if n == 1:
        return np.array([min(1.0, max(0.0, v[0]))])
    u = np.sort(v)[::-1]  # descending order
    cssv = np.cumsum(u)
    # Maximum condition
    cond = 1 * np.arange(1, n+1) > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1] + 1  # get the last binding constraint index

    return np.maximum(v - theta, 0).astype(float)

The goal is to minimize the maximum autocorrelation value for a normalized sequence (sum equal to 1) of length `n`. The key observation is that the problem is invariant to scaling, so we can optimize the structure of the sequence while keeping the sum normalized.

The strategy involves:

3. Applying Nesterov accelerated projected subgradient to refine local search with higher emphasis on edge cases.
4. Including smart restarts at specific positions and times to avoid local minima.

This differs from the standard cosine modulation by introducing a more generalized envelope that can be tailored for extreme transitions, potentially lowering the convolution max.

The objective is to minimize:
  2 * n * max( (a * a)[i] for i in range(2 * n - 1) ) / s²
