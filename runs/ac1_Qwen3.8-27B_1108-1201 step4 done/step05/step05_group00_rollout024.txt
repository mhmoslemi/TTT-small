- This is O(n) per (j, m) pair.
- Finding the optimal δ: since f(δ) = max_k (c[k] + δ*delta[k]) is convex and piecewise linear, we can find the minimum by:
  - The minimum is where the subgradient contains 0.
  - Subgradient = {delta[k] : c[k] + δ*delta[k] = max}
  - So we need δ such that 0 is in the convex hull of {delta[k] : k is argmax}.
  - This is equivalent to: min_{k in argmax} delta[k] <= 0 <= max_{k in argmax} delta[k].
  - We can find this δ by bisection: increase δ until the argmax set changes to include a k with delta[k] <= 0.

Actually, a simpler approach for the line search: since f(δ) is convex, use ternary search or just evaluate at a few points.

For practical purposes, I'll evaluate f at δ = 0, and at the δ values where the argmax changes (these are the "breakpoints"). The breakpoints occur when c[k1] + δ*delta[k1] = c[k2] + δ*delta[k2], i.e., δ = (c[k2] - c[k1]) / (delta[k1] - delta[k2]).

For the max function, the relevant breakpoints are those involving the current max. So:
- Current max is M at position k*.
- The breakpoints are δ = (M - c[k]) / (delta[k*] - delta[k]) for all k ≠ k* where delta[k*] ≠ delta[k].
- The function decreases until we hit a breakpoint where the new max has a lower slope, then increases.

import numpy as np

def fast_convolve(a):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]

def project_simplex(v):
    n = len(v)
    if n == 1:
        return np.array([max(float(v[0]), 0.0)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)

def eval_obj(a):
    """Compute 2*n*max(conv(a,a)) / (sum(a))^2."""
    s = a.sum()
    if s < 1e-15:
        return np.inf
    c = fast_convolve(a)
    return 2.0 * len(a) * c.max() / (s * s)

            if a[m] <= 0:

            j = top_j

            for k in range(0, min(n - j, 2 * n - 1)):

            for k in range(0, min(n - m, 2 * n - 1)):

                continue

                if val < best_val:

                    t2 = best_t + step
                    if t1 < lo:

                    if v1 < best_val:

                c = fast_convolve(a)
                M = c.max()
                no_improve = 0
    
    return best_a

    """Compute delta[k] = a[k-j] + a[j+k] - a[k-m] - a[m+k] for k=0,...,2n-2."""
    delta = np.zeros(2 * n - 1)

    if j < 2 * n - 1:
        end = min(j + n, 2 * n - 1)
        delta[j:end] += a[:end-j]
    
    # a[j+k] for valid k: k in [0, n-1-j], value = a[j+k]
    if j <= n - 1:
        end = min(n - j, 2 * n - 1)
        delta[:end] += a[j:j+end]
    
    # a[k-m] for valid k: k in [m, m+n-1], value = a[k-m]
    if m < 2 * n - 1:

        delta[m:end] -= a[:end-m]

    if lo < hi:
        delta[lo:hi] += a[:hi-lo]
    # a[j+k]: k in [0, n-1-j], values a[j], a[j+1], ..., a[n-1]
    hi = min(n - j, 2 * n - 1)
    if hi > 0:
        delta[:hi] += a[j:j+hi]
    # -a[k-m]: k in [m, m+n-1]
    lo = m
    hi = min(m + n, 2 * n - 1)
    if lo < hi:
        delta[lo:hi] -= a[:hi-lo]
    # -a[m+k]: k in [0, n-1-m]
    hi = min(n - m, 2 * n - 1)
    if hi > 0:
        delta[:hi] -= a[m:m+hi]
    return delta

def line_search(c, delta, lo, hi):
    """Find δ in [lo, hi] that minimizes max(c + δ*delta)."""
    # Coarse search
    n_trials = 16
    trials = np.linspace(lo, hi, n_trials)
    best_t = 0.0
    best_val = np.inf
    for t in trials:
        val = np.max(c + t * delta)
        if val < best_val:
            best_val = val
            best_t = t
    # Fine search
    step = (hi - lo) / n_trials
    for _ in range(10):
        t1 = max(lo, best_t - step)
        t2 = min(hi, best_t + step)
        v1 = np.max(c + t1 * delta)
        v2 = np.max(c + t2 * delta)
        if v1 < best_val:
            best_val = v1
            best_t = t1
        elif v2 < best_val:
            best_val = v2
            best_t = t2
        step /= 2
        if step < 1e-12:
            break
    return best_t, best_val

def coordinate_descent(a0, time_limit, seed=42, verbose=False):
    """Peak-directed coordinate descent with exact line search."""
    rng = np.random.default_rng(seed)
    a = np.maximum(a0.astype(np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(len(a)) / len(a)
    else:
        a = a / s
    n = len(a)
    
    c = fast_convolve(a)
    M = c.max()
    best_a = a.copy()
    best_M = M
    
    t0 = time.monotonic()
    it = 0
    no_improve = 0
    
    while time.monotonic() - t0 < time_limit:
        it += 1
        if time.monotonic() - t0 > time_limit - 0.01:
            break
        
        # Find top peaks
        k_star = int(np.argmax(c))
        
        # Find top contributors to this peak
        js = max(0, k_star - n + 1)
        je = min(n - 1, k_star)
        if je < js:
            break
        
        # Contributions: a[j] * a[k_star - j] for j in [js, je]
        contrib = a[js:je+1] * a[k_star-je:k_star-js+1]
        
        # Pick the top contributor
        top_local = int(np.argmax(contrib))
        j = js + top_local
        
        # Candidate m positions: try a mix of random and "safe" (low a[m])
        n_candidates = 8
        candidates = set()
        # Random
        for _ in range(n_candidates // 2):
            candidates.add(int(rng.integers(n)))
        # Low a[m]
        low_idx = np.argsort(a)[:n_candidates // 2]
        for idx in low_idx:
            candidates.add(int(idx))
        candidates.discard(j)
        
        best_delta_val = 0.0
        best_m = -1
        best_new_M = M
        
        for m in candidates:
            if m == j or a[m] < 1e-15:
                continue
            
            delta = compute_delta(a, j, m)
            
            # Feasibility: a[j] + δ >= 0 → δ >= -a[j]; a[m] - δ >= 0 → δ <= a[m]
            lo = -a[j] + 1e-12
            hi = a[m] - 1e-12
            if lo >= hi:
                continue
            
            t_opt, val_opt = line_search(c, delta, lo, hi)
            
            if val_opt < best_new_M - 1e-15:
                best_new_M = val_opt
                best_delta_val = t_opt
                best_m = m
        
        if best_m >= 0 and best_new_M < M - 1e-15:
            a[j] += best_delta_val
            a[best_m] -= best_delta_val
            a = np.maximum(a, 0.0)
            a = a / a.sum()
            c = fast_convolve(a)
            M = c.max()
            no_improve = 0
            if M < best_M - 1e-14:
                best_M = M
                best_a = a.copy()
        else:
            no_improve += 1
            if no_improve > 500:
                # Random restart
                scale = 0.005 + 0.01 * min(1.0, no_improve / 2000.0)
                a = project_simplex(best_a + rng.standard_normal(n) * scale)
                c = fast_convolve(a)
                M = c.max()
                no_improve = 0
    
    return best_a, best_M

def smoothed_gradient_descent(a0, time_limit, seed=42, T=0.001, lr=0.01):
    """Smoothed gradient descent with softmax-weighted peaks."""
    rng = np.random.default_rng(seed)
    a = np.maximum(a0.astype(np.float64), 0.0)
    a = a / a.sum()
    n = len(a)
    
    v = np.zeros(n)  # momentum
    best_a = a.copy()
    best_obj = fast_convolve(a).max()
    t0 = time.monotonic()
    it = 0
    no_improve = 0
    beta1, beta2, eps = 0.9, 0.999, 1e-8
    m = np.zeros(n)  # first moment
    vv = np.zeros(n)  # second moment
    t = 1
    
    while time.monotonic() - t0 < time_limit:
        it += 1
        if time.monotonic() - t0 > time_limit - 0.01:
            break
        
        c = fast_convolve(a)
        
        # Softmax gradient
        scaled = c / T
        scaled -= scaled.max()
        p = np.exp(scaled)
        p = p / p.sum()
        
        # Gradient: 2 * correlate(p, a) = 2 * hankel_mv(p, a)
        grad = 2.0 * np.correlate(p, a, mode='valid')
        
        # Adam update
        m = beta1 * m + (1 - beta1) * grad
        vv = beta2 * vv + (1 - beta2) * grad**2
        m_hat = m / (1 - beta1**t)
        vv_hat = vv / (1 - beta2**t)
        t += 1
        
        a_new = a - lr * m_hat / (np.sqrt(vv_hat) + eps)
        a_new = project_simplex(a_new)
        
        # Check improvement
        c_new = fast_convolve(a_new)
        obj_new = c_new.max()
        
        if obj_new < best_obj - 1e-15:
            a = a_new
            c = c_new
            best_obj = obj_new
            best_a = a.copy()
            no_improve = 0
        else:
            no_improve += 1
            # Don't update a, try smaller lr
            if no_improve % 100 == 0:
                lr *= 0.95
                T *= 1.01
        
        if no_improve > 2000:
            scale = 0.003 + 0.007 * min(1.0, (no_improve - 2000) / 5000.0)
            a = project_simplex(best_a + rng.standard_normal(n) * scale)
            m = np.zeros(n)
            vv = np.zeros(n)
            t = 1
            lr = 0.01
            T = 0.001
            no_improve = 0
    
    return best_a, best_obj

Wait, I realize there might be an issue with the line search. The function `max(c + δ*delta)` is convex in δ (it's the max of linear functions), so the minimum is well-defined. But the line search might be slow if δ is very small (which it often is near convergence).

Let me also think about whether the coordinate descent is actually effective. The issue is:
- At each step, I pick the peak position k*.
- I find the top contributor j to this peak.
- I try to move mass from j to some m.
- The line search finds the best amount to move.

But this only affects ONE peak at a time. If there are multiple peaks, reducing one might increase another. The line search accounts for this (it checks max over ALL positions), so it should be OK.

However, the issue is that near convergence, the improvements become very small, and the no_improve counter will trigger restarts frequently. This might not be efficient.

**Alternative: Batch updates.** Instead of moving mass from one j to one m, move mass from a group of j's to a group of m's. This is like a "min-cost flow" or "transportation" problem.

Actually, let me think about a simpler but effective approach: **simulated annealing with the max-convolution as energy.**

```
E(a) = max(conv(a,a))

Start with some a.
For each iteration:
    Pick random j, m.
    Compute the delta (change in conv) for shifting δ from m to j.
    Compute E_new = max(conv + δ*delta).
    With probability min(1, exp(-(E_new - E)/T)), accept the move.
    Decrease T.
```

This is simple and can escape local minima. The downside is that it's stochastic and might need many iterations.

For n=768, each iteration is O(n) (to compute the delta and the new max). With ~10M iterations possible in 1800s, and a good annealing schedule, this could work.

But I think the coordinate descent approach is better because it makes deterministic improvements when possible, and only resorts to random restarts when stuck.

Let me also consider: **what if I try a completely different structural approach?**

**Idea: "Anti-convolution" initialization.**

Instead of starting from the parent or a smooth function, start from a sequence that is designed to have a flat convolution. For example:
- Start with a random sequence, compute its convolution.
- The "error" is the deviation from flat: e = conv(a,a) - mean(conv(a,a)).
- Try to minimize the L∞ norm of e.
- This is exactly our problem, but we can use the error to guide the optimization.

**Idea: Use the Fourier domain.**

The convolution theorem says: DFT(conv(a,a)) = |DFT(a)|^2 (with zero-padding).

So if we want conv(a,a) to be flat (all values = 1/(2n-1)), we need:
- DFT(conv)[0] = 1 (the total)
- DFT(conv)[k] = 0 for k ≠ 0

This means |DFT(a_padded)[k]|^2 = 0 for k ≠ 0, which means a_padded is constant (and hence a is constant, the uniform sequence).

So the "flat convolution" ideal is only achievable by the uniform sequence! This confirms that we can't make the convolution perfectly flat with a non-uniform sequence.

But we CAN make it "less peaked" than uniform. The uniform has a triangular convolution shape (peak in the middle). We want to flatten the middle peak.

**Key insight**: The middle peak of the uniform convolution is `n * (1/n)^2 = 1/n`. The edge values are `(1/n)^2 = 1/n^2`. The ratio is n. To flatten, we need to reduce the middle while increasing the edges. But the edges are `a[0]^2` and `a[n-1]^2`, so increasing the edges means increasing a[0] and a[n-1], which increases other parts of the convolution.

This is a delicate balance. The optimal solution likely has:
- a[0] and a[n-1] somewhat large (to boost the edges)
- The middle of a having a complex pattern that reduces the center peak

**Let me try a different approach: iterative reweighting.**

Consider the following fixed-point iteration:
1. Compute c = conv(a, a).
2. Define w = 1 / c (element-wise, with some regularization).
3. Update a_new[j] = a[j] * (average of w over neighbors that involve j) / normalization.

This is like a "self-consistent field" method. The idea is: if c[k] is large, we want to reduce the a[j]'s that contribute to c[k]. The weight w = 1/c tells us "how much to reduce."

Actually, this is similar to the "water-filling" or "best response" in a game. Let me formalize:

We want to minimize max_k c[k] where c[k] = sum_j a[j] a[k-j].

The KKT conditions for the problem min max_k c[k] s.t. a >= 0, sum(a) = 1 are:
- There exists λ ≥ 0 such that for each k: c[k] ≤ λ (complementary slackness)
- For each j: 2 sum_k p[k] (a[k-j] + a[j+k]) - μ = 0 if a[j] > 0, where p is the dual variable (probability distribution on k)
- sum(a) = 1, a >= 0

This is a zero-sum game:
- Player 1 (primal) chooses a to minimize max_k c[k]
- Player 2 (dual) chooses a distribution p on {0, ..., 2n-2} to maximize min_j (2 sum_k p[k] (a[k-j] + a[j+k]) - μ)

The value of the game is the optimal max convolution.

**Fictitious play**: Alternate between:
1. Given p (dual), find the best response a (primal): minimize sum_k p[k] c[k] = a^T H(p) a where H(p)[j,m] = p[j+m] + p[j+m] (if j+m ≤ 2n-2) ... this is a QP.
2. Given a (primal), find the best response p (dual): p = delta at argmax c.

This is exactly the "game iteration" approach from the previous program! The difference is that the previous program uses a smoothed version (softmax instead of delta) and a QP solver.

I think the key improvement I can make is:
1. **Better QP solve**: The QP is min a^T H a s.t. a >= 0, sum(a) = 1. This is a quadratic program. For n=768, it can be solved with a dedicated QP solver (like scipy's minimize with SLSQP, or cvxpy).

2. **Faster iteration**: Instead of one step per iteration, do multiple QP solves per dual update (or vice versa).

3. **Better smoothing**: Use a tempered distribution p = softmax(c/T) with adaptive T.

Actually, the previous program already does game iteration. Let me focus on something different.

**New idea: "Deflation" / "Whitening" approach.**

Inspired by non-negative matrix factorization and ICA:
1. Compute c = conv(a, a).
2. The peaks of c are at positions k_1, k_2, ..., k_m.
3. For each peak k_i, the "deflating" direction is to reduce a[j] * a[k_i - j] for the dominant j.
4. But instead of coordinate descent, use a **global** update:
   - Define a "deflation operator" D that reduces the peaks: D(a) = a * (1 - α * R) where R[j] = sum_i p[k_i] * a[k_i - j] (the "responsibility" of a[j] for the peaks).
   - This is a multiplicative update (like in NMF or EM).

Let me formalize the multiplicative update:
- Current a, current c = conv(a, a).
- Peak weights: p[k] = softmax(c[k] / T) (or p = delta at argmax, or p = top-k uniform).
- Update: a_new[j] = a[j] * (1 - α * sum_k p[k] * (a[k-j] + a[j+k])) / Z
  where Z normalizes to keep sum(a_new) = 1.

The term `sum_k p[k] * (a[k-j] + a[j+k])` is the "gradient" of the weighted sum of peaks with respect to a[j]. So this is a multiplicative gradient descent.

This is similar to the "Sinkhorn" or "iterative scaling" approach. The multiplicative update naturally keeps a >= 0.

Let me implement this:

```python
def multiplicative_update(a0, time_limit, T=0.01, alpha=0.1, seed=42):
    rng = np.random.default_rng(seed)
    a = np.maximum(a0.astype(np.float64), 0.0)
    a = a / a.sum()
    n = len(a)
    
    best_a = a.copy()
    best_obj = fast_convolve(a).max()
    t0 = time.monotonic()
    it = 0
    no_improve = 0
    current_T = T
    
    while time.monotonic() - t0 < time_limit:
        it += 1
        if time.monotonic() - t0 > time_limit - 0.01:
            break
        
        c = fast_convolve(a)
        
        # Peak weights
        scaled = c / current_T
        scaled -= scaled.max()
        p = np.exp(scaled)
        p = p / p.sum()
        
        # Gradient: grad[j] = 2 * sum
