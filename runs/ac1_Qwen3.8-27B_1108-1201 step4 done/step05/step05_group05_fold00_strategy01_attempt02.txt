## Approach and Rationale

The goal is to minimize the objective function `2*n*max(convolve(a,a)) / (sum(a))**2` for a non-negative sequence `a`. Our approach combines a multi-phase strategy that leverages geometric sequence length variation, Fourier-domain initialization for low autocorrelation, and advanced optimization techniques including a penalized Frank-Wolf algorithm with adaptive constraints, frequency-domain initialization, multi-start coordinate descent with linesearch, and multiphase subgradient polishing. 

This method systematically explores candidates of increasing length (512, 1024, 2048) with inherent guards against computational bottlenecks (FFT-based convolution for larger sequences). By interleaving these optimizations and validity checks, we avoid local minima and maintain feasibility.

We start from the parent sequence `height_sequence_1` if available. If not, we use a default uniform sequence. We then run the primary optimization on sequences of length 512, then create longer candidates by interpolation, running the optimization again on the next length until the time limit is reached. Within each optimization phase, we use a mix of simplex projection and coordinate descent refinements.

## Mathematical Specification

**Variables**: One-dimensional array `a` of `n` non-negative coefficients.

**Objective**: Minimize  
`objective = (2 * n * max_linear_convolve_full(a)) / (sum(a))**2`  
where `linear_convolve_full` is computed with `numpy.fft`.

**Constraints**:  
- Non-negative coefficients: `a_i >= 0` for all `i`  
- Sum at least 0.01: `sum(a) >= 0.01`

**Operations**:  
- The linear auto-convolution is the full convolution of `a` with itself  
- The maximum value is taken over `2*n-1` points  
- The penalty parameter `m` is dynamically activated during iterations to maintain strict constraints

**Implementation**:  
All algorithms are FFT-accelerated. The primal problem is normalized by extending to the desired length while ensuring non-negativity and proper scaling.

def project_simplex(v):
    n = len(v)
    if n == 0:
        return np.array([])

    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n+1) > (cssv - 1)
    s = np.sum(v)

        return np.ones(n) / s
    
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
