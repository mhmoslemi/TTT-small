## Approach and Rationale

The central idea is to minimize the peak of the auto-convolution of the sequence \(a\) while maintaining a sum greater than a small threshold, through an exhaustive search guided by coordinate ascent. Unlike the previous methods using convex optimization and gradient descent, which might be trapped by local minima, this algorithm systematically explores multiple scales of sequence values by repeatedly projecting candidate solutions onto the simplex of non-negative coefficients summing to exactly 1, and then maximizing the minimum value at each coordinate while satisfying the constraint based on the auto-convolution of the candidate.

This approach is chosen for its ability to systematically push the peaks of the auto-convolution downwards without being constrained by computational structure or non-convexity, given the ample time budget. It uses the exact same metric as the evaluator, ensuring that we don't mistake surrogate objectives.

The algorithm will:

1. Start from an initial sequence (either the provided parent or a uniform random one)
2. For each coordinate:
   Hydrogen onset factness
   - Briefly consider that coordinate under the current state and try to increase its contribution while reducing the maximum auto-convolution
3. Use a pool of hyperparameters that can be systematically explored

### Important Note

This strategy is designed for a **fixed sequence length**. Given the previous program's best result was around 1.504826 and the parent sequence length was 768, we clamp our search to sequences of fixed length 768 to ensure consistency with the problem's norms.

## Mathematical Specification

Let \(n = 768\) be the sequence length.

We are to minimize the objective:
\[
\text{objective}(a) = 2 \times n \times \max(\text{auto-convolution}(a)) / (\text{sum}(a))^2
\]
with constraint:
\[
\sum_{i=1}^{n} a_i \geq 0.01, \quad a_i \geq 0 \quad \forall i
\]

However, as noted, scaling doesn't affect the objective, so we can normalize \(a\) to have sum exactly 1.

We minimize:
\[
\text{objective}(a) = 2 \times 768 \times \max(\text{convolve}(a, a)) / (1)^2 = 1536 \times \max(\text{convolve}(a, a))
\]

using the `evaluate_sequence` function that does the required normalization and clipping.

We represent a state by a vector \(a \in \mathbb{R}^{768}\) with \(a_i \geq 0\) for all \(i\), and let \(s = 1 / \text{normalize}(a)\) so that \(a = s \times \text{normalize}(a)\) projects to our simplex.

The algorithm will:

- Start with an initial vector \(a_{\text{current}}\) (initialization)
- For each coordinate index \(j\):
  - Determine the "upper bound" constraint for \(a_j\) based on the current state and the required contribution of \(j\) to the sum.
  - Adjust all coordinates to satisfy the constraint and seek a state where the maximum auto-convolution is minimized.
