`conv[k] = sum_{i=0}^{n-1} sum_{j=0}^{n-1} a[i] a[j] * I(i+j=k)`... no, that's not right for linear convolution.

For linear convolution: `conv[k] = sum_i a[i] * b[k-i]` where b = a.
So `conv[k] = sum_{i: 0<=i<n, 0<=k-i<n} a[i] * a[k-i]`.

Let j = k-i, so i+j=k and 0<=i<n, 0<=j<n.
`conv[k] = sum_{i+j=k, 0<=i<n, 0<=j<n} a[i] * a[j]`.

As a quadratic form: `conv[k] = a^T T_k a` where:
`T_k[i,j] = 1` if `i+j=k` and `0<=i<n, 0<=j<n`, else 0.

But this T_k is not symmetric in general (since `T_k[i,j] = 1` when `i+j=k`, but `T_k[j,i] = 1` when `j+i=k`, which is the same condition). So T_k IS symmetric!

And `a^T T_k a = sum_{i,j} a[i] T_k[i,j] a[j] = sum_{i+j=k} a[i] a[j]` (summing over valid i,j).

But wait, this counts each pair (i,j) once. In the convolution, `a[i]*a[k-i]` appears once for each valid i. And in the quadratic form, `a[i]*a[j]` with i+j=k appears for each valid (i,j) pair. If i≠j, the pair (i,j) and (j,i) both contribute to `a^T T_k a`, giving `2*a[i]*a[j]`. But in the convolution, `a[i]*a[j]` with i+j=k appears only once (for the specific i).

So actually: `a^T T_k a = 2 * conv[k]` for k ≠ 2i (i.e., when no diagonal element is involved), and `a^T T_k a = 2*conv[k] - (a[k/2])^2` when k is even (for the diagonal term).

    n = len(v)
    if n == 1:
        return np.array([max(float(v[0]), 0.0)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)

def solve_lp_direction(f, conv_f, B, top_k=None):
    """Solve the linearized LP to get a descent direction."""
    n = len(f)
    
    if top_k is not None and top_k < 2*n-1:

        peaks = np.argpartition(conv_f, -(top_k))[-(top_k):]
