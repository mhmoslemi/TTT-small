Let me try a different approach: **iterative projection between two sets**.

Set A: `{a : a >= 0, sum(a) = 1}` (the simplex)
Set B: `{a : max_k (a*a)[k] <= T}` for some threshold T

We want to find a point in A ∩ B with the smallest T. This is like a bisection on T combined with projection.

But projecting onto B is hard (it's the intersection of quadratic constraints).

Alternatively, let's use an iterative approach:

1. Start with `a` in A
2. Compute `c = a*a`, find peak `T = max(c)`
3. Modify `a` to reduce the peak: reduce values at positions that contribute most to the peak
4. Project back to A
5. Repeat

Step 3 is the key. The peak is at lag `k*`. The contribution to `c[k*]` from position `j` is `a[j]*a[k*-j]`. To reduce `c[k*]`, we should reduce `a[j]` for positions `j` where `a[k*-j]` is large (or vice versa).

A simple heuristic: for each position `j` in the support of the peak, reduce `a[j]` proportionally to `a[k*-j]` (the "partner" value at the peak lag).

Let me formalize this:

```
for each iteration:
    c = convolve(a, a)
    k_star = argmax(c)
    # Gradient of c[k_star] w.r.t. a:
    # d(c[k_star])/d(a[j]) = a[k_star - j] (for valid k_star - j)
    # So the "pressure" on position j is a[k_star - j]
    pressure[j] = a[k_star - j] (if k_star - j is in range, else 0)
    # Reduce a where pressure is high
    a_new = a - lr * pressure
    a_new = project to simplex (a >= 0, sum = 1)
```
