Setting `n-1-m+k = k-j` gives `n-1-m = -j`, so `m = n-1+j`.

Therefore: `h[j] = (convolve(p, a_rev))[n-1+j]` for `j = 0, ..., n-1`.

So `h = np.convolve(p, a_rev, mode='full')[n-1 : 2*n-1]`.

def score_sequence_fast(a):
    """Compute score = 2n * max(conv(a,a)) / sum(a)^2"""
    n = len(a)
    c = np.convolve(a, a)
    M = c.max()
    S = a.sum()

def smooth_score_and_grad(a, T):
    """
    Compute smooth approximation of score and its gradient.
    Uses log-sum-exp smoothing of the max.
    """
    n = len(a)
    c = np.convolve(a, a)
    S = a.sum()
    
    # Log-sum-exp
    c_max = c.max()
    exp_c = np.exp(T * (c - c_max))
    p = exp_c / exp_c.sum()
    L = c_max + np.log(exp_c.sum()) / T  # smooth max
    
    # Gradient of L w.r.t. a:
    # dL/da_j = 2 * sum_k p[k] * a[k-j]
    a_rev = a[::-1]
    conv_p_a = np.convolve(p, a_rev, mode='full')
    h = conv_p_a[n-1 : 2*n-1]  # h[j] = sum_k p[k] * a[k-j]
    dL_da = 2.0 * h
    
    # Score = 2n * L / S^2
    score = 2.0 * n * L / (S * S)
    
    # d(score)/da_j = 2n/S^2 * (dL/da_j * S - 2L) = 2n/S * dL/da_j - 4nL/S^2
    grad = (2.0 * n / S) * dL_da - (4.0 * n * L) / (S * S)
    
    return score, grad

def optimize_smooth(a0, T, lr, max_iters, momentum=0.9):

    Optimize using projected gradient with momentum.

    a = a0.copy().astype(np.float64)

        a_new = a + v  # Note: we're adding v which already has the negative sign
        
        # Project to non-negative
        a_new = np.maximum(0, a_new)
        
        # Normalize to keep sum = 1
        S_new = a_new.sum()
        if S_new < 1e-15:
            a_new = a0.copy()
        else:
            a_new = a_new / S_new
        
        # Accept
        a = a_new
        
        # Track best (using true score, not smooth)
        true_score = score_sequence_fast(a)
        if true_score < best_score:
            best_score = true_score
            best_a = a.copy()

Actually, I recall now: the pointwise maximum of a family of functions is convex if and only if all the functions in the family are convex. Since `c_k(a) = sum_i a_i a_{k-i}` is NOT convex (as I showed with the Hessian), `max_k c_k` is NOT necessarily convex.

In general, I don't think `max_k c_k` is convex on the non-negative orthant or the simplex. So the problem is likely non-convex, and we need non-convex optimization methods.

This means my projected gradient approach might get stuck in local minima. But in practice, the landscape might be "benign" (no bad local minima), which is common for many non-convex problems.

Let me also think about a completely different approach: **Wiener filter / spectral method**.

The auto-convolution `c = a * a` in the frequency domain is `C(ω) = A(ω)^2` (where `A` is the DFT of `a`). We want to minimize `max_k c_k`, which is equivalent to minimizing the peak of the inverse DFT of `A(ω)^2`.

If we could make `A(ω)^2` as "flat" as possible (in the relevant frequency range), then `c` would be as "concentrated" as possible at k=0... wait, no. A flat `C(ω)` corresponds to a delta `c_k` (all mass at k=0). We want the opposite: we want `c_k` to be flat, which means `C(ω)` should be concentrated at ω=0.

So we want `A(ω)` to be concentrated near ω=0, which means `a` should be "smooth" (low-pass filtered). This is consistent with using smooth initializations like raised cosine or Gaussian.

But there's a tradeoff: if `a` is too smooth (too concentrated at low frequencies), then `c = a*a` is also very smooth and concentrated, which might have a high peak relative to its average.

The optimal balance is somewhere in between. The raised cosine is already a good compromise.

def compute_subgrad(a):
    """
    Compute a subgradient of f(a) = 2n * max(conv(a,a)) / sum(a)^2.
    Returns (score, subgradient).
    """
    n = len(a)
    c = np.convolve(a, a)
    S = a.sum()
    M = c.max()
    score = 2.0 * n * M / (S * S)
    
    # Find all positions where max is achieved (within tolerance)
    tol = 1e-10 * M
    max_positions = np.where(c >= M - tol)[0]
    
    # Subgradient: average of subgradients at max positions
    # Subgradient at position k: 2n/S^2 * (2*a_{k-j} - 2M/S) for component j
    # = 4n/S^2 * (a_{k-j} - M/S)
    a_rev = a[::-1]
    n_subgrad = len(max_positions)
    grad = np.zeros(n)
    for k in max_positions:

        # Valid indices: max(0, k-n+1) to min(n-1, k)
        j_min = max(0, k - n + 1)
        j_max = min(n - 1, k)
        # a[k-j] for j in [j_min, j_max]
        # = a[k - j_min] ... a[k - j_max]
        # = a[k-j_min : k-j_max+1] = a[max(0,k-n+1) ... k]
        # Actually: for j from j_min to j_max, a[k-j] = a[k-j_max] to a[k-j_min]
        # So h[j_min:j_max+1] = a[k-j_max : k-j_min+1][::-1]
        # k-j_max = k - min(n-1, k)
        # k-j_min = k - max(0, k-n+1)
        if j_max >= j_min:

            grad[j_min:j_max+1] += h_segment
    
    grad /= n_subgrad
    grad = (4.0 * n / (S * S)) * (grad - M / S)
    
    return score, grad

def compute_smooth_grad(a, T):
    """
    Compute smooth approximation of score and its gradient using log-sum-exp.
    """
    n = len(a)
    c = np.convolve(a, a)
    S = a.sum()
    
    c_max = c.max()
    exp_c = np.exp(T * (c - c_max))
    p = exp_c / exp_c.sum()
    L = c_max + np.log(exp_c.sum()) / T
    
    # h[j] = sum_k p[k] * a[k-j]
    a_rev = a[::-1]
    conv_pa = np.convolve(p, a_rev, mode='full')
    h = conv_pa[n-1 : 2*n-1]
    
    score = 2.0 * n * L / (S * S)
    grad = (4.0 * n / S) * h - (4.0 * n * L) / (S * S)
    
    return score, grad

    """

    n = len(a)
    v = np.zeros(n)
    best_a = a.copy()
    best_score = score_fast(a)

        a_new = a + v
        a_new = np.maximum(0, a_new)
        s = a_new.sum()

            v *= 0.5
