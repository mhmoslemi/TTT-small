Let me also think about a **coordinate descent** approach:

For each coordinate j, the objective as a function of a[j] (with all other coordinates fixed) is:
F(a[j]) = 2n * max_k c(k; a[j]) / (sum(a))^2

where c(k; a[j]) is the k-th convolution term as a function of a[j].

c(k; a[j]) is linear in a[j] (it's a sum of terms, and a[j] appears linearly in each product a[i]*a[k-i] where either i=j or k-i=j).

Wait, c(k) as a function of a[j]:
c(k) = sum_i a[i]*a[k-i]
The terms involving a[j] are:
- a[j]*a[k-j] (when i=j): linear in a[j] with coefficient a[k-j]
- a[k-j]*a[j] (when i=k-j): linear in a[j] with coefficient a[k-j]

So c(k) = a[j] * (2*a[k-j]) + (terms not involving a[j]) [when j != k-j]
or c(k) = a[j]^2 + (terms not involving a[j]) [when j = k-j]

The sum of a is: sum(a) = a[j] + (sum of other a[i])

So F(a[j]) = 2n * max_k (linear or quadratic in a[j]) / (a[j] + S)^2

where S = sum of all a[i] for i != j.

This is a 1D optimization problem! We can solve it by golden section search or by finding the minimum analytically.

This coordinate descent approach could be very effective, especially combined with the subgradient method.

Let me design the final algorithm:

```
1. Initialize with multiple starting points
2. For each starting point:
   a. Run subgradient descent (with adaptive step size) for T1 iterations
   b. Run coordinate descent for T2 iterations (cycling through coordinates)
   c. Run LP-based refinement for T3 iterations
   d. Apply random perturbations and re-optimize
3. Keep the best result
```

For the coordinate descent, at each step:
- For coordinate j, compute the optimal a[j] given all other coordinates
- This involves finding the minimum of F(a[j]) over a[j] >= 0
- F(a[j]) = 2n * max_k (c_k_base + c_k_coef * a[j] + c_k_quad * a[j]^2) / (a[j] + S)^2

where c_k_base, c_k_coef, c_k_quad are precomputed.

Actually, for the "max_k" part, the optimal a[j] is where the maximum is minimized. This is a bit complex but doable.

Let me simplify: for coordinate j, c(k) as a function of x = a[j] is:
- If k = 2j: c(k) = x^2 + B_k (where B_k is the sum of terms not involving a[j])
- If k != 2j (and k-j is valid): c(k) = 2*a[k-j]*x + B_k
- If k-j is not valid: c(k) = B_k

So max_k c(k) is the max of a set of linear functions and possibly one quadratic function of x.

The objective is 2n * max_k c(k) / (x + S)^2.

To minimize this over x >= 0, we can:
1. Find the point where the "active" constraint changes (where the argmax of c(k) changes)
2. Between these breakpoints, the objective is 2n * (linear or quadratic) / (x+S)^2, which can be minimized analytically

This is getting complex. Let me just use a simple approach: sample a grid of x values and pick the best one. Or use scipy.optimize.minimize_scalar on the 1D function.

Actually, for n up to 2048, the coordinate descent with golden section search should be fast enough.

```python
"""
Hybrid optimization for minimizing the autocorrelation peak of a non-negative
step function. Uses subgradient descent, coordinate descent, and LP-based
refinement in an interleaved fashion.
"""
import numpy as np
import scipy.sparse as sp
from scipy.optimize import linprog, minimize_scalar
import time


def fast_score(f):
    """Compute the objective score."""
    f = np.asarray(f, dtype=np.float64)
    f = np.clip(f, 0.0, 1000.0)
    s = f.sum()
    if s < 0.01:
        return np.inf
    conv = np.convolve(f, f)
    return float(2.0 * len(f) * conv.max() / (s * s))


def compute_conv_gradient(f, k):
    """Compute gradient of convolution term c[k] w.r.t. f."""
    n = len(f)
    # (grad_k)[m] = 2*f[k-m] if 0 <= k-m < n else 0
    grad = np.zeros(n)
    m_min = max(0, k - n + 1)
    m_max = min(n - 1, k)
    if m_min <= m_max:
        grad[m_min:m_max+1] = 2.0 * f[k - m_max:k - m_min + 1][::-1]
    return grad


def subgradient_descent(f, n_iters=200, eta_init=0.1, eta_decay=0.99):
    """Subgradient descent with adaptive step size."""
    f = f.copy()
    n = len(f)
    eta = eta_init
    best_f = f.copy()
    best_sc = fast_score(f)
    
    for it in range(n_iters):
        conv = np.convolve(f, f)
        M = conv.max()
        
        # Active set: where conv is within 5% of max
        threshold = M * 0.95
        active = np.where(conv >= threshold)[0]
        
        # Compute subgradient
        grad = np.zeros(n)
        for k in active:
            grad += compute_conv_gradient(f, k)
        grad /= len(active)
        
        # Step
        f_new = f - eta * (grad - grad.mean())
        f_new = np.maximum(f_new, 0.0)
        s = f_new.sum()
        if s < 1e-10:
            break
        f_new = f_new / s
        
        sc = fast_score(f_new)
        if sc < best_sc:
            best_sc = sc
            best_f = f_new.copy()
            f = f_new
        else:
            eta *= eta_decay
            f = f_new  # still move, just smaller effective step
        
        eta = max(eta * 0.999, 0.001)
    
    return best_f, best_sc


def coordinate_descent(f, n_sweeps=10):
    """Cycle through coordinates, optimizing each one."""
    f = f.copy()
    n = len(f)
    best_sc = fast_score(f)
    
    for sweep in range(n_sweeps):
        improved = False
        for j in range(n):
            # Optimize a[j] with all others fixed
            others = f.copy()
            others[j] = 0.0
            S = others.sum()  # sum excluding a[j]
            
            # c(k) as function of x = a[j]:
            # c(k) = B_k + coef_k * x + quad_k * x^2
            # where coef_k = 2*a[k-j] if valid (for k != 2j), or 0
            # and quad_k = 1 if k = 2j, else 0
            
            # Actually let me just compute it directly
            # c(k; x) for x = a[j]:
            # Terms where a[j] appears: a[j]*a[k-j] (contrib x * a[k-j]) and a[k-j]*a[j] (contrib a[k-j]*x)
            # So c(k) = base_k + 2*a[k-j]*x for k != 2j (when k-j valid)
            #           = base_k + x^2 for k = 2j
            
            def obj_1d(x):
                f_try = others.copy()
                f_try[j] = x
                if f_try.sum() < 0.01:
                    return np.inf
                conv = np.convolve(f_try, f_try)
                return 2.0 * n * conv.max() / (f_try.sum() ** 2)
            
            # Use bounded minimization
            x_cur = f[j]
            # Bound: x should be reasonable
            x_max = max(2.0 * f.max(), x_cur * 3 + 0.1)
            res = minimize_scalar(obj_1d, bounds=(0.0, x_max), method='bounded',
                                  options={'xatol': 1e-8})
            if res.success and res.fun < best_sc - 1e-10:
                f[j] = res.x
                best_sc = res.fun
                improved = True
        
        if not improved:
            break
    
    return f, best_sc


def build_conv_matrix(n, f):
    """Sparse matrix A (2n-1 x n) with A[k,j] = f[k-j] for valid indices."""
    rows = []
    cols = []
    data = []
    for k in range(2 * n - 1):
        j_min = max(0, k - n + 1)
        j_max = min(n - 1, k)
        for j in range(j_min, j_max + 1):
            rows.append(k)
            cols.append(j)
            data.append(f[k - j])
    A = sp.coo_matrix((data, (rows, cols)), shape=(2 * n - 1, n)).tocsr()
    return A


def solve_lp_for_g(f, M, time_limit_s=5.0):
    """Solve max sum(g) s.t. A g <= M*1, g >= 0."""
    n = int(len(f))
    A = build_conv_matrix(n, f)
    c = -np.ones(n)
    b = np.full(2 * n - 1, M)
    bounds = [(0.0, None)] * n
    try:
        res = linprog(c, A_ub=A, b_ub=b, bounds=bounds, method='highs',
                      options={'time_limit': time_limit_s, 'presolve': True})
        if res.status == 0:
            return np.maximum(res.x, 0.0)
    except Exception:
        pass
    return None


def lp_step(f, t=0.3, time_limit_s=5.0):
    """One LP-based update step."""
    conv = np.convolve(f, f)
    M = float(conv.max())
    if M < 1e-15:
        return f
    g = solve_lp_for_g(f, M, time_limit_s)
    if g is None:
        return f
    gs = g.sum()
    if gs < 1e-10:
        return f
    g = g / gs
    f_new = (1.0 - t) * f + t * g
    f_new = np.maximum(f_new, 0.0)
    s = f_new.sum()
    if s < 1e-10:
        return f
    return f_new / s


def block_perturb(f, rng, block_size=None):
    """Random multiplicative block perturbation."""
    n = len(f)
    cand = f.copy()
    if block_size is None:
        block_size = int(rng.integers(1, max(2, n // 10 + 1)))
    start = int(rng.integers(0, max(1, n - block_size + 1)))
    stop = min(n, start + block_size)
    scale = np.exp(rng.normal(0.0, 0.3))
    cand[start:stop] *= scale
    cand = np.maximum(cand, 0.0)
    s = cand.sum()
    if s < 1e-10:
        return f
    return cand / s


def make_initial(n, rng, method='perturbed_uniform'):
    """Create initial sequence."""
    if method == 'perturbed_uniform':
        a = np.ones(n) + rng.normal(0.0, 0.3, n)
    elif method == 'cosine':
        x = np.linspace(0.0, np.pi, n)
        a = 0.5 * (1.0 + np.cos(x))
    elif method == 'sinc':
        x = np.arange(n, dtype=np.float64)
        center = n / 2
        a = np.sinc((x - center) / (n / 4))
    elif method == 'random':
        a = rng.random(n)
    elif method == 'two_peaks':
        x = np.arange(n, dtype=np.float64)
        s = max(1, n // 16)
        a = (np.exp(-0.5 * ((x - n // 4) / s) ** 2) +
             np.exp(-0.5 * ((x - 3 * n // 4) / s) ** 2))
    elif method == 'package':
        # "Package" construction: repeat a short pattern
        p = max(4, n // 32)
        pattern = rng.random(p) + 0.1
        a = np.tile(pattern, n // p + 1)[:n]
    else:
        a = np.ones(n)
    a = np.maximum(a, 0.01)
    a = a / a.sum()
    return a


def optimize_sequence(f, budget_s=100.0):
    """Run a full optimization cycle on a sequence."""
    f = f.copy()
    n = len(f)
    best_f = f.copy()
    best_sc = fast_score(f)
    start_time = time.monotonic()
    
    # Phase 1: Subgradient descent
    t1_end = start_time + budget_s * 0.3
    while time.monotonic() < t1_end:
        f_new, _ = subgradient_descent(f.copy(), n_iters=20, eta_init=0.05)
        sc = fast_score(f_new)
        if sc < best_sc:
            best_sc = sc
            best_f = f_new.copy()
            f = f_new
        else:
            f = block_perturb(f, np.random.default_rng(int(time.monotonic()*1000)))
    
    # Phase 2: Coordinate descent
    t2_end = min(start_time + budget_s * 0.6, time.monotonic() + budget_s * 0.3)
    while time.monotonic() < t2_end and n <= 1024:
        f_new, sc = coordinate_descent(f.copy(), n_sweeps=2)
        if sc < best_sc:
            best_sc = sc
            best_f = f_new.copy()
            f = f_new
        else:
            break
    
    # Phase 3: LP-based refinement
    t3_end = start_time + budget_s * 0.85
    lp_time = min(5.0, budget_s / 20)
    while time.monotonic() < t3_end:
        f_new = lp_step(f, t=0.3, time_limit_s=lp_time)
        sc = fast_score(f_new)
        if sc < best_sc:
            best_sc = sc
            best_f = f_new.copy()
            f = f_new
        else:
            f = block_perturb(f, np.random.default_rng(int(time.monotonic()*1000)))
    
    # Phase 4: Final local search
    while time.monotonic() < start_time + budget_s:
        rg = np.random.default_rng(int(time.monotonic()*100000))
        cand = block_perturb(f, rg, block_size=max(1, n // 50))
        sc = fast_score(cand)
        if sc < best_sc - 1e-8:
            best_sc = sc
            best_f = cand.copy()
            f = cand
    
    return best_f, best_sc
```

Hmm, let me think about potential issues:

```python
    n = len(f)
    N = 2 * n - 1
    B = np.zeros(N)
    B[active] = 1.0
    
    # We want: grad[m] = sum_{j=0}^{n-1} f[j] * B[j+m] for m = 0, ..., n-1
    # This is the cross-correlation of f and B.
    # Using the property: corr(f, B)[m] = ifft(conj(fft(f, N)) * fft(B, N))[m]
    # But we need to be careful about the exact definition.

    # result[k] = sum_j f[j] * conj(B[j - (k - (len(B)-len(f)))])  ... this is confusing.

    # (B has length N = 2n-1, so B[m:m+n] is valid for m = 0, ..., n-1)
```
