**Section 1: Approach and Rationale**

Our algorithm is built upon the principles of **controlled dynamical constraint search (CDCS)**, an approach designed to find globally minimal step-function attacks while respecting the original objective's mathematical properties. The core idea is to maintain a set of **binding constraint indicators** that precisely delineate the most aggressive signal-processing directions, optimizing the sequence-by-sequence evaluation process.

Instead of relying solely on linear programming (LP) refinements or genetic-like methods, we periodically raise and lower these constraint indicators in a structured, time-aware fashion. By tracking the convergence behavior of constraint-directed peaks and leveraging a wait-like autocorrelation barrier, we ensure that our search remains focused yet exploratory.

**Bottlenecks Addressed:**

-   The LP-based refinement in prior work often assumes a path toward a local optimum, neglecting broadly scoped directions.
-   Early termination relies on arbitrary stagnation metrics (like 40 LPs without improvement) rather than objective evaluation.

**Scope:**

We assume sequences of length `1000` as our operational algebraic dimension due to the trade-off between computational cost and search surface. The **CDCS** framework involves:

1.  **Multi-start Initialization:** We generate diverse initial sequences using standard shapes (`raised_cosine`, `gaussian`, `blackman`) and constraints-compliant randomization.
2.  **Iterative Constraint Adjustment:** Rather than fixed scheduling, we actively update the constraint set based on observed peak changes and timing.
3.  **Rotation-Invariant Queueing:** We maintain a global ranking mechanism to choose the next LP/neighborhood search based on both score and time-to-conv.
4.  **Final Validation:** Only the best candidate sequence is re-evaluated with the full evaluator function.

**Section 2: Mathematical Specification**

We minimize the score function `score = (2 * n * max_conv_val) / (sum_coeffs^2)`, where `max_conv_val` is the peak of the full linear convolution `conv(a, a)`, and `sum_coeffs >= 0.01`.

**Variables & Objectives:**

-   Sequence *S*: non-negative float values of length `n`
-   Binding factor *gamma* ∈ [0, 1]: controls constraint tightness.
-   Search state *σ*: holds the best-known candidate *S* and a time monitor *t0*.

**Constraints:**

- Non-negativity for *S*: `S[i] ≥ 0 ∀i`
- Peak bound: `conv(S, S)[max_index] ≤ (n*gamma)/factor`
- Sum: `(sum of S) ≥ 0.01`

**Indicators:**

- An indicator function *I(k)* checks if a given index *k* is binding (i.e., contributes most significantly to the peak).

**Formulation:**

Minimize `score` with respect to *S* under the constraints above. *gamma* starts at 0.2 and increases at predetermined intervals until the maximum number of steps (`5` by default) is reached.
