Let me also think about whether the "full" correlate is the right thing to minimize. The problem says:
C₅ = max_k ∫ h(x)(1 - h(x+k)) dx

This integral is over x where both h(x) and h(x+k) are defined. Since h: [0,2] → [0,1], h(x+k) is only defined for x+k ∈ [0,2], i.e., x ∈ [-k, 2-k].

So the integral is ∫_{max(0,-k)}^{min(2, 2-k)} h(x)(1-h(x+k)) dx for k ≥ 0
And similarly for k < 0.

But the problem says to use np.correlate(h, 1-h, mode="full") * dx as the evaluation. The "full" mode gives correlations at all lags from -(n-1) to (n-1). At lag m (where m goes from -(n-1) to n-1), the correlation is:
Σ_{i=max(0,-m)}^{min(n-1, n-1-m)} h[i+m] * (1-h[i])

This represents the sum of h(x) * (1-h(x+k)) over the overlapping domain, where k = m*dx.

So max over all these gives us the worst-case overlap at any shift. This matches the problem statement.

def project_feasible(h, target_sum):
    h = np.clip(h, 0.0, 1.0)
    for _ in range(100):
        diff = target_sum - h.sum()
        if abs(diff) < 1e-13:
            break
        if diff > 0:
            m = h < 1.0
            if not np.any(m):
                break
            h[m] += diff / np.count_nonzero(m)
            h = np.clip(h, 0.0, 1.0)
        else:
            m = h > 0.0
            if not np.any(m):
                break
            h[m] += diff / np.count_nonzero(m)
            h = np.clip(h, 0.0, 1.0)
    # Final exact adjustment
    diff = target_sum - h.sum()
    if abs(diff) > 1e-15:
        m = (h > 0.0) & (h < 1.0)
        if np.any(m):
            h[m] += diff / np.count_nonzero(m)
            h = np.clip(h, 0.0, 1.0)
    return h

def eval_c5(h):
    dx = 2.0 / len(h)
    return float(np.max(np.correlate(h, 1.0 - h, "full")) * dx)

def soft_max_obj(h, alpha):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, "full") * dx
    m = np.max(corr)
    e = np.exp(alpha * (corr - m))
    return m + np.log(np.sum(e)) / alpha

    n = len(h)
    eps = 1e-5
    grad = np.zeros(n)
    for j in range(n):
        hp = h.copy()
        hp[j] += eps
        cp = soft_max_obj(hp, alpha)
        hm = h.copy()
        hm[j] -= eps
        cm = soft_max_obj(hm, alpha)
        grad[j] = (cp - cm) / (2.0 * eps)
    return grad

    eps = 5e-5

        hp[j] = min(1.0, h[j] + eps)

            grad[j] = (soft_obj(hp, alpha) - soft_obj(hm, alpha)) / e
    return grad
