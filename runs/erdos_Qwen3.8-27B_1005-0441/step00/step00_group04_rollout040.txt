For m ≤ n-1: length is min(n, 2n-1-m) = n (since 2n-1-m ≥ n for m ≤ n-1).
So always n terms! The formula is:
grad[m] = dx * Σ_{j=0}^{n-1} w[m+j] * (1 - 2*h[j])

This is a sliding dot product, computable via convolution/correlation in O(n log n) using FFT, or O(n²) directly.

For n=280, O(n²) = 78K is trivial. Let's just do it with a simple loop or numpy.

Actually, I can write it as:

# grad[m] = dx * dot(a, w[m:m+n])
grad = np.array([np.dot(a, w[m:m+n]) for m in range(n)]) * dx

Or even better, using the convolution trick:
```python
# We want S[m] = sum_{j=0}^{n-1} a[j] * w[m+j] for m=0..n-1
# This is the cross-correlation of w and a
S = np.correlate(w, a, mode="valid")  # w has length 2n-1, a has length n
# "valid" mode gives length 2n-1-n+1 = n, which is exactly what we want!
grad = S * dx
```

Let me verify: np.correlate(w, a, "valid") where w has length 2n-1 and a has length n:
The "valid" mode gives the output where the two arrays fully overlap, length = 2n-1-n+1 = n.
output[k] = Σ_j w[j+k] * a[j] for j=0..n-1, k=0..n-1.

Yes! That's exactly S[m] with m=k. 

So the gradient computation is:
```python
def compute_grad(h, T, n):
    dx = 2.0 / n
    g = 1.0 - h
    corr = np.correlate(h, g, mode="full") * dx
    max_c = np.max(corr)
    exp_vals = np.exp((corr - max_c) / T)
    w = exp_vals / np.sum(exp_vals)
    a = 1.0 - 2.0 * h
    S = np.correlate(w, a, mode="valid")
    return S * dx
```

This is O(n log n) with FFT-based correlation! Beautiful.

Now for the optimization:
- Use projected gradient descent
- At each step: compute gradient, take step, project to feasible set
- Use adaptive step size (backtracking or diminishing)
- Multiple restarts

The projection to {h: 0≤h≤1, sum(h)=n/2} can be done efficiently. It's a projection onto the intersection of a box and a hyperplane. There's a known method using a 1D root-finding (bisection) on the shift parameter.

For projection: find α such that sum(clamp(h - grad_step, 0, 1)) + α * correction = n/2. Actually it's more like:

We want to find h' = argmin ||h - h_new||² subject to 0≤h'≤1, sum(h')=n/2.

This can be solved by: h'_i = clamp(h_new_i - μ, 0, 1) for some μ, where μ is chosen so sum(h') = n/2. Use bisection on μ.

import numpy as np

import time

def project_box_hyperplane(h_new, n):
    """Project h_new onto {h: 0<=h<=1, sum(h)=n/2}."""
    target = n / 2.0
    # Find mu such that sum(clamp(h_new - mu, 0, 1)) = target
    # clamp(h_new - mu, 0, 1) is monotonically decreasing in mu
    lo, hi = min(h_new) - 1.0, max(h_new) + 1.0
    for _ in range(100):
        mu = (lo + hi) / 2
        proj = np.clip(h_new - mu, 0.0, 1.0)
        s = np.sum(proj)
        if s > target:
            lo = mu
        else:
            hi = mu
        if hi - lo < 1e-15:
            break
    return np.clip(h_new - mu, 0.0, 1.0)

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)

def compute_smooth_grad(h, T, n):
    dx = 2.0 / n
    g = 1.0 - h
    corr = np.correlate(h, g, mode="full") * dx
    max_c = np.max(corr)
    exp_vals = np.exp((corr - max_c) / T)
    w = exp_vals / np.sum(exp_vals)
    a = 1.0 - 2.0 * h
    S = np.correlate(w, a, mode="valid")
    return S * dx

def upsample(h_small, n_new):

    if n_old == n_new:

    x_new = (np.arange(n_new) + 0.5) / n_new

corr[k] = Σ_n h[n] * (1-h[k-n]) for valid n (0≤n<n_points, 0≤k-n<n_points).

∂corr[k] / ∂h[m]:
Case 1: h[m] is the first factor. n=m, need 0≤m<n and 0≤k-m<n.
  Contribution: (1-h[k-m])

Case 2: h[m] is inside (1-h[k-n]). k-n=m, so n=k-m. Need 0≤k-m<n and 0≤m<n.
  Contribution: h[n]*(-1) = h[k-m]*(-1) = -h[k-m]

Combined: (1-h[k-m]) - h[k-m] = 1-2*h[k-m], valid when 0≤m<n, 0≤k-m<n (from case 1) AND 0≤k-m<n, 0≤m<n (from case 2). Both give the same condition: 0≤m<n and 0≤k-m<n.

So: ∂corr[k]/∂h[m] = (1-2*h[k-m]) * I(0≤m<n) * I(0≤k-m<n)

For 0≤m<n (always in our sum): the condition is 0≤k-m<n, i.e., m≤k≤m+n-1.

So: ∂corr[k]/∂h[m] = (1-2*h[k-m]) for k ∈ [m, m+n-1], and 0 otherwise.

grad[m] = dx * Σ_k w[k] * (1-2*h[k-m]) * I(m≤k≤m+n-1)

where j = k-m.

import time

def project_box_hyperplane(h_new, n):
    target = n / 2.0
    lo = float(np.min(h_new)) - 1.5
    hi = float(np.max(h_new)) + 1.5
    mu = 0.0
    for _ in range(80):
        mu = (lo + hi) / 2.0
        proj = np.clip(h_new - mu, 0.0, 1.0)
        s = np.sum(proj)
        if s > target:
            lo = mu
        else:
            hi = mu
    return np.clip(h_new - mu, 0.0, 1.0)

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr)) * dx

def compute_smooth_grad_and_val(h, T, n):
    dx = 2.0 / n
    g = 1.0 - h
    corr = np.correlate(h, g, mode="full") * dx
    max_c = np.max(corr)
    exp_vals = np.exp((corr - max_c) / T)
    w = exp_vals / np.sum(exp_vals)
    a = 1.0 - 2.0 * h
    S = np.correlate(w, a, mode="valid")
    obj = T * (max_c + np.log(np.sum(exp_vals)))

    n_old = len(h_small)
