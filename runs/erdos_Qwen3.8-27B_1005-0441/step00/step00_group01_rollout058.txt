Let me also consider: what does the optimal solution look like? 

The constraint is ∫h = 1 over [0,2], so the "average" value is 1/2. The function h represents a set of measure 1 in [0,2]. We want to minimize the maximum "disagreement" between h and its shifts.

This is related to the problem of finding a set of measure 1 in [0,2] such that no shift of it overlaps too little (equivalently, no shift of it avoids it too much).

The complement (1-h) has measure 1 as well. We're looking at ∫h(x)(1-h(x+k))dx = measure of {x: x in A, x+k not in A} where A is the set {x: h(x)=1}.

So we want a set A of measure 1 in [0,2] such that for all shifts k, the measure of A \ (A-k) is minimized in the max.

This is essentially the "minimum overlap" problem.

def _make_feasible(h, N):
    h = np.clip(h.astype(float), 0.0, 1.0)
    target = N / 2.0
    diff = target - np.sum(h)

        if diff > 0:
            mask = h < 1.0 - 1e-10
            cnt = np.sum(mask)
            if cnt > 0:
                h[mask] += diff / cnt
        else:
            mask = h > 1e-10
            cnt = np.sum(mask)
            if cnt > 0:
                h[mask] += diff / cnt
        h = np.clip(h, 0.0, 1.0)
    diff2 = target - np.sum(h)
    if abs(diff2) > 1e-13:
        if diff2 > 0:
            for ii in np.argsort(1.0 - h):
                a = min(diff2, 1.0 - h[ii])
                h[ii] += a
                diff2 -= a
                if diff2 <= 1e-13:
                    break
        else:
            for ii in np.argsort(h):
                s = min(-diff2, h[ii])
                h[ii] -= s
                diff2 += s
                if diff2 >= -1e-13:
                    break
    return h
