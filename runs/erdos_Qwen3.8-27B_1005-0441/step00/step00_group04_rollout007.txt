import time

    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def compute_grad_smooth(h, dx, tau):
    n = len(h)
    corr = np.correlate(h, 1.0 - h, mode='full') * dx
    max_corr = np.max(corr)
    exp_vals = np.exp(tau * (corr - max_corr))
    w = exp_vals / np.sum(exp_vals)
    grad = np.zeros(n)

        wt = w[t] * dx
        if wt < 1e-8:
            continue

        if total > 1e-12:

For lag s (where s can be negative), the correlation at index t = s + (n-1) is:
corr[t] = sum over valid i: h[i] * (1-h[i+s])

Where valid means 0 ≤ i < n AND 0 ≤ i+s < n.

d(corr[t])/dh[m]:
- m appears as i in h[i]: contributes (1-h[m+s]) if 0 ≤ m < n AND 0 ≤ m+s < n
- m appears as i+s in (1-h[i+s]): contributes -h[i] where i = m-s, so -h[m-s] if 0 ≤ m-s < n AND 0 ≤ m < n

So:
d(corr[t])/dh[m] = I[0≤m+s<n] * (1-h[m+s]) - I[0≤m-s<n] * h[m-s]
(for 0 ≤ m < n, which is always true since we're indexing h)
