    corr = np.correlate(h, 1.0 - h, mode="full") * dx

    return c_max + t * np.log(np.sum(np.exp((corr - c_max) / t)))

For a periodic pattern with period p, only lags that are multiples of p would give high correlation. But we need to handle all lags.
