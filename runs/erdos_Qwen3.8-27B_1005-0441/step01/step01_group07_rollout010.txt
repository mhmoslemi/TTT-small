The objective is max_k (c_k + d_k * h[i]), and we want to minimize this subject to 0 ≤ h[i] ≤ 1 and the sum constraint.

The sum constraint makes this tricky: if I change h[i], I need to adjust another h[j] to maintain the sum.

If I ignore the sum constraint temporarily, the optimal h[i] for minimizing max_k (c_k + d_k * h[i]) is found by:
- If all d_k > 0: set h[i] = 0 (but sum constraint might prevent this)
- If all d_k < 0: set h[i] = 1
- Mixed: the optimal is at a point where two of the lines c_k + d_k*h[i] are equal (the "max" changes hands)

This is a 1D problem that can be solved exactly! But the sum constraint complicates things.

**Idea: Pairwise coordinate descent**
- Pick a pair (i, j)
- Fix all other h values
- Optimize h[i] + h[j] = constant (to maintain sum) subject to 0 ≤ h[i], h[j] ≤ 1
- This is a 2D problem: minimize max_k (c_k + d_k * h[i] + e_k * h[j]) subject to h[i] + h[j] = s, 0 ≤ h[i], h[j] ≤ 1
- Substitute h[j] = s - h[i]: minimize max_k (c_k + (d_k - e_k) * h[i] + e_k * s)
- This is a 1D convex problem (minimize max of linear functions)!
- Can be solved with bisection or by finding the intersection points.

This is a great approach! It's guaranteed to not increase the objective, and it can be done very efficiently.

Let me code this up:

```python
def pairwise_update(h, i, j):
    """Optimize h[i] and h[j] while keeping h[i]+h[j] constant."""
    n = len(h)
    s = h[i] + h[j]  # Must maintain this sum
    # Constraint: 0 <= h[i] <= 1, 0 <= h[j] <= 1, h[j] = s - h[i]
    # So: max(0, s-1) <= h[i] <= min(1, s)
    
    lo = max(0.0, s - 1.0)
    hi = min(1.0, s)
    if lo >= hi:
        return h  # No room to optimize
    
    # For each lag k, overlap(k) = c_k + d_k * h[i] + e_k * h[j]
    # = c_k + d_k * h[i] + e_k * (s - h[i])
    # = (c_k + e_k * s) + (d_k - e_k) * h[i]
    # = C_k + D_k * h[i]
    
    # Compute d_k and e_k for each k
    # d_k = coefficient of h[i] in overlap(k)
    # e_k = coefficient of h[j] in overlap(k)
    
    # overlap(k) = sum_m h[m] * (1-h[m+lag_k])
    # Coefficient of h[x] in overlap(k):
    #   from h[x] * (1-h[x+lag_k]): (1-h[x+lag_k]) if x+lag_k in range
    #   from h[x-lag_k] * (1-h[x]): -h[x-lag_k] if x-lag_k in range
    
    def coeff(x, lag):
        c = 0.0
        xp = x + lag
        xm = x - lag
        if 0 <= xp < n and h[xp] < 1.0:  # (1-h[xp]) term, but h[xp] is fixed (x≠i,j)
            # Actually, we need to be careful: if xp == i or xp == j, h[xp] is variable
            # For now, assume x is not i or j (we handle x=i and x=j separately)
            c += (1.0 - h[xp])
        if 0 <= xm < n:
            c -= h[xm]
        return c
    
    # Actually, let me compute it differently.
    # For the full correlation: corr[k] = sum_m h[m] * (1-h[m+k-(n-1)])
    # Let's use the lag formulation: overlap at lag L (L from -(n-1) to (n-1)):
    # overlap(L) = sum_{m: 0<=m<n, 0<=m+L<n} h[m] * (1-h[m+L])
    
    # The coefficient of h[i] in overlap(L) is:
    #   (1-h[i+L]) if 0<=i+L<n  [from the h[m] term with m=i]
    #   -h[i-L] if 0<=i-L<n  [from the (1-h[m+L]) term with m+L=i, m=i-L]
    # But if i+L == i (L=0): (1-h[i]) - 0, but that's messy.
    # Actually for L=0: overlap(0) = sum h[m](1-h[m]) which for our purposes...
    # Let's just compute the full overlap with h[i] and h[j] as variables.
    
    # Simpler approach: just compute the 1D objective f(t) = max_k overlap_k(t)
    # where we set h[i]=t, h[j]=s-t.
    # Sample at a few points and use bisection.
    
    # For speed, let's compute the overlaps at a few t values and find the min max.
    
    def eval_at_t(t_i):
        t_j = s - t_i
        h_copy = h.copy()
        h_copy[i] = t_i
        h_copy[j] = t_j
        corr = np.correlate(h_copy, 1.0 - h_copy, 'full')
        return float(corr.max())
    
    # Find the minimum of the max of linear functions over [lo, hi]
    # This is a 1D convex optimization. Use ternary search or golden section.
    # But actually, it's a "minimax of linear functions" which can be solved by
    # finding the point where the top two lines cross.
    
    # For simplicity, use golden section search.
    golden = (1 - math.sqrt(5)) / 2  # ≈ -0.618
    
    a, b = lo, hi
    c = b - golden * (b - a)
    d = a + golden * (b - a)
    fc = eval_at_t(c)
    fd = eval_at_t(d)
    
    for _ in range(50):
        if fc < fd:
            b = d
            d = c
            fd = fc
            c = b - golden * (b - a)
            fc = eval_at_t(c)
        else:
            a = c
            c = d
            fc = fd
            d = a + golden * (b - a)
            fd = eval_at_t(d)
    
    t_best = (a + b) / 2
    h[i] = t_best
    h[j] = s - t_best
    return h
```

Actually, I can make it much more efficient. Since the objective as a function of t_i is the max of linear functions, I can compute the slopes and intercepts directly:

For each lag L (encoded as index k in the full correlation):
overlap(L) = sum_m h[m] * (1-h[m+L])

The terms involving h[i] = t:
- If 0 <= i+L < n: h[i] * (1-h[i+L]) = t * (1-h[i+L])
- If 0 <= i-L < n: h[i-L] * (1-h[i]) = h[i-L] * (1-t)

The terms involving h[j] = s-t:
- If 0 <= j+L < n: h[j] * (1-h[j+L]) = (s-t) * (1-h[j+L])
- If 0 <= j-L < n: h[j-L] * (1-h[j]) = h[j-L] * (1-(s-t))

So overlap(L) = [const_L] + t*(1-h[i+L]) + h[i-L]*(1-t) + (s-t)*(1-h[j+L]) + h[j-L]*(1-s+t)
= [const_L] + t*(1-h[i+L]) - h[i-L]*t + (s-t)*(1-h[j+L]) + h[j-L]*t - h[j-L]*(1-s)

Actually, let me just do it computationally but efficiently. For each pair (i,j), I can precompute:
- For each lag L, the "base" overlap (with h[i] and h[j] set to 0)
- The coefficient of t (from h[i]=t)
- The coefficient of (s-t) (from h[j]=s-t)

Then overlap(L) = base(L) + t*ci(L) + (s-t)*cj(L) = (base(L) + s*cj(L)) + t*(ci(L) - cj(L))

And I need to minimize max_L [(base(L) + s*cj(L)) + t*(ci(L) - cj(L))] over t ∈ [lo, hi].

This is the minimum of the maximum of linear functions, which is a 1D convex problem. The optimal t is where two of the "upper envelope" lines cross.

I can find it by:
1. Computing all lines: a_k = base(k) + s*cj(k), b_k = ci(k) - cj(k)
2. The objective is max_k (a_k + b_k * t)
3. Find t* that minimizes this: it's where the slopes of the two "active" lines bracket 0, OR at a boundary.

For n=70, there are 139 lags. Computing the base, ci, cj for each lag is O(n) per lag, total O(n²) = 4900. Then finding the optimal t is O(n log n) (sort by slope and find the crossover).

This is much faster than the golden section approach!

```python
import numpy as np
import time, math

def project_feasible(h, target_sum):
    lo, hi = -2.0, 2.0
    for _ in range(100):
        mid = (lo + hi) / 2.0
        proj = np.clip(h - mid, 0.0, 1.0)
        if proj.sum() > target_sum:
            lo = mid
        else:
            hi = mid
    return np.clip(h - (lo + hi) / 2.0, 0.0, 1.0)

def compute_c5_val(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, 'full')
    return float(corr.max() * dx)

def grad_smooth(h, dx, tau):
    n = len(h)
    omh = 1.0 - h
    corr = np.correlate(h, omh, 'full')
    mc = corr.max()
    shifted = np.clip(tau * (corr - mc), -500, 500)
    exps = np.exp(shifted)
    weights = exps / exps.sum()
    grad = np.zeros(n)
    for k in range(len(corr)):
        w = weights[k]
        if w < 1e-12:
            continue
        lag = k - (n - 1)
        if lag >= 0:
            rem = n - lag
            grad[lag:] += w * omh[:rem]
            grad[:rem] -= w * h[lag:]
        else:
            L = -lag
            rem = n - L
            grad[:rem] += w * omh[L:]
            grad[L:] -= w * h[:rem]
    return grad * dx

def grad_topm(h, dx, m=3):
    n = len(h)
    omh = 1.0 - h
    corr = np.correlate(h, omh, 'full')
    idx = np.argsort(corr)[::-1][:m]
    weights = np.zeros(len(corr))
    weights[idx] = 1.0 / m
    grad = np.zeros(n)
    for k in range(len(corr)):
        w = weights[k]
        if w < 1e-12:
            continue
        lag = k - (n - 1)
        if lag >= 0:
            rem = n - lag
            grad[lag:] += w * omh[:rem]
            grad[:rem] -= w * h[lag:]
        else:
            L = -lag
            rem = n - L
            grad[:rem] += w * omh[L:]
            grad[L:] -= w * h[:rem]
    return grad * dx

def adam_optimize(h_init, time_budget, seed, lr_init=0.05, tau_start=500.0):
    rng = np.random.RandomState(seed)
    n = len(h_init)
    target_sum = n / 2.0
    dx = 2.0 / n
    h = project_feasible(h_init.copy(), target_sum)
    best_h = h.copy()
    best_c5 = compute_c5_val(h)
    m1 = np.zeros(n)
    m2 = np.zeros(n)
    b1, b2, eps_adam = 0.9, 0.999, 1e-8
    t = 0
    lr = lr_init
    tau = tau_start
    t0 = time.time()
    deadline = t0 + time_budget
    no_imp = 0
    
    while time.time() < deadline - 0.1:
        t += 1
        # Alternate: 70% smooth, 30% sharp
        if t % 10 < 7:
            grad = grad_smooth(h, dx, tau)
        else:
            grad = grad_topm(h, dx, 3)
        
        m1 = b1 * m1 + (1 - b1) * grad
        m2 = b2 * m2 + (1 - b2) * (grad * grad)
        t_hat = t + 1
        m1_hat = m1 / (1.0 - b1 ** t_hat)
        m2_hat = m2 / (1.0 - b2 ** t_hat)
        h_new = project_feasible(h - lr * m1_hat / (np.sqrt(m2_hat) + eps_adam), target_sum)
        c5 = compute_c5_val(h_new)
        
        if c5 < best_c5 - 1e-10:
            best_h = h_new.copy()
            best_c5 = c5
            no_imp = 0
        else:
            no_imp += 1
        h = h_new
        
        # Decrease tau (focus more on worst)
        tau = max(tau * 0.9995, 5.0)
        # Decay LR
        if t % 200 == 0:
            lr = max(lr * 0.9, 0.003)
        
        # Restart
        if no_imp > 200:
            noise = 0.02 + 0.03 * min(no_imp / 400.0, 1.0)
            h = project_feasible(best_h + rng.randn(n) * noise, target_sum)
            m1[:] = 0.0
            m2[:] = 0.0
            lr = lr_init
            tau = tau_start
            no_imp = 0
    
    return best_h, best_c5

def pairwise_polish(h, max_pairs, seed):
    """Try pairwise updates to reduce C5."""
    rng = np.random.RandomState(seed)
    n = len(h)
    target_sum = n / 2.0
    best_h = h.copy()
    best_c5 = compute_c5_val(h)
    
    for _ in range(max_pairs):
        i = rng.randint(n)
        j = rng.randint(n)
        if i == j:
            continue
        s = h[i] + h[j]
        lo = max(0.0, s - 1.0)
        hi = min(1.0, s)
        if hi - lo < 1e-6:
            continue
        # Try a few candidate t values
        candidates = np.linspace(lo, hi, 7)
        best_t = h[i]
        best_local = compute_c5_val(h)
        for t_c in candidates:
            h[i] = t_c
            h[j] = s - t_c
            c = compute_c5_val(h)
            if c < best_local:
                best_local = c
                best_t = t_c
        h[i] = best_t
        h[j] = s - best_t
        c5 = compute_c5_val(h)
        if c5 < best_c5:
            best_c5 = c5
            best_h = h.copy()
    
    return best_h, best_c5
