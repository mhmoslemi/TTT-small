1. As h[i] where i=j: the term is h[j]*(1-h[j+lag_p]), valid when 0 ≤ j+lag_p ≤ n-1
2. In (1-h[i+lag_p]) where i+lag_p = j, i = j-lag_p: the term is h[j-lag_p]*(1-h[j]), valid when 0 ≤ j-lag_p ≤ n-1

So the coefficient of h[j] in corr[p] is:
- (1-h[j+lag_p]) if 0 ≤ j+lag_p ≤ n-1, else 0
- minus h[j-lag_p] if 0 ≤ j-lag_p ≤ n-1, else 0

So a_p = (1-h[j+lag_p])*I(0≤j+lag_p<n) - h[j-lag_p]*I(0≤j-lag_p<n)

And b_p = corr[p] - h[j]*a_p
