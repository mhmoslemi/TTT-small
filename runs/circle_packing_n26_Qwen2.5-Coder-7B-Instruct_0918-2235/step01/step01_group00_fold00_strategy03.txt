### 1.  Greedy “largest‑empty‑circle” insertion

1. **State representation**  
   Maintain a list of already‑placed circles  
   `P = {(xₖ, yₖ, rₖ)} for k=1..m`  (initially empty).

2. **Function that returns the maximum feasible radius at a point**  
   For any candidate centre `(x, y)` define  

   ```
   λ(x, y) = min(
        x,                1 - x,            # distance to left/ right wall
        y,                1 - y,            # distance to bottom/top wall
        min_{(xₖ,yₖ,rₖ)∈P} ( sqrt((x-xₖ)²+(y-yₖ)²) - rₖ )   # clearance from existing discs
   )
   ```

   If λ ≤ 0, the point is infeasible; otherwise it is the radius that a disc centred at `(x, y)` would achieve without overlap.

3. **Grid sampling**  
   Use a dense regular grid over the square, e.g.  
   `x_i = (i+0.5)/N,  i=0..N-1`  with `N = 200`.  
   For all `N²` grid points evaluate λ(x_i, y_j).  
   Keep the point with the largest λ; denote it `(x*, y*, r*)`.

4. **Refinement of the centre**  
   Apply a derivative‑free local optimiser (e.g. Nelder–Mead)
   to maximise λ around `(x*, y*)`.  
   The optimiser starts from `(x*, y*)`, keeps the step‑size
   ≤ 0.01 initially and progressively halves it;  
   termination when the change in λ is < 1 × 10⁻⁶.

5. **Insert the circle**  
   Add `(x*, y*, r*)` to `P`.

### 2.  Exact radius computation via linear programming

Given any fixed set of centres the optimal radii are the solution of

```
maximise   Σ r_i
subject to r_i ≥ 0
           r_i ≤ min(x_i, 1-x_i, y_i, 1-y_i)
```
