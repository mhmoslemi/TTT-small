**A.  High‑level idea**

We turn the packing problem into a *continuous optimisation* problem, but instead of using a deterministic gradient‑based solver or a black‑box global optimiser we employ a **Particle Swarm Optimiser (PSO)**.  
A PSO keeps a *population of candidate solutions* that move through the search space under the influence of an attractive “social” force (the best particle seen by the swarm) and an “inertia” force (the particle’s own previous velocity).  The algorithm is highly parallelisable, can work with only simple function calls, and is very good at escaping the narrow basins that typically trap gradient based methods on non‑convex geometry problems.

In short we will:

1. Encode all 26 centres and 26 radii in one vector of shape (78,).
2. Use a **penalty‑augmented objective** that rewards a large sum of radii but subtracts a large penalty whenever a geometric constraint is violated.
3. Run the PSO for a modest number of generations (≈ 4000 particle evaluations) to converge to a near‑optimal packing.
4. Post‑process the best particle locally (gradient‑descent on radii only) to clean up any tiny violations caused by the penalty rounding.

This strategy is materially different from the previous approaches – it does **not** rely on an outer global optimiser (DE), nor on an interior‑point relaxation (trust‑constr), nor on a greedy construction followed by a force‑field anneal.  PSO is a population‑based stochastic method that is especially suitable for low‑dimensional, highly non‑convex design tasks such as ours, and it gives us a simple, fully deterministic final solution once the random seed is fixed.

**B.  Variable encoding**

Let  

```
v = [x0, y0, r0, x1, y1, r1, …, x25, y25, r25]   (length 78)
```

- `x_i, y_i ∈ [0,1]` – centre coordinates  
- `r_i ∈ [0,0.5]`   – radius (≤ 0.5 guarantees a circle fits somewhere in the square)

These bounds are enforced by clipping at each particle update.

**C.  Penalty‑augmented objective**

We want to maximise  

```
f(v) = Σ_i r_i
```

Subject to  
```
x_i - r_i ≥ 0,                1 - x_i - r_i ≥ 0
y_i - r_i ≥ 0,                1 - y_i - r_i ≥ 0
‖c_i - c_j‖² - (r_i + r_j)² ≥ 0     for all i<j
```

A standard way in PSO is to **convert** the constrained problem into an unconstrained one by adding a penalty term that is *zero* when all constraints are satisfied and grows when violations occur.  Define

```
pen(v) = Σ_{i} clip( -(x_i - r_i),   0)      # <0 means violation
        + Σ_{i} clip( -(1 - x_i - r_i), 0)
        + Σ_{i} clip( -(y_i - r_i),     0)
        + Σ_{i} clip( -(1 - y_i - r_i), 0)
        + Σ_{i<j} clip( (r_i + r_j) - ‖c_i - c_j‖, 0 )
```

where `clip(a, 0)` returns `a` if `a > 0` and `0` otherwise.  
The penalty has *units of radius*; we multiply it by a large factor `λ` to strongly discourage violations:

```
g(v) = Σ_i r_i  –  λ * pen(v)
```

The PSO will try to maximise `g(v)`; because `λ` is huge (e.g. 1e6) any violation results in a catastrophic drop in the objective, effectively preventing the swarm from exploring infeasible regions.

**D.  PSO algorithm**

1. **Parameters**  
   - population size `P = 60`  
   - inertia weight `w = 0.7298` (conservative)  
   - cognitive constant `c1 = 1.49618`  
   - social constant `c2 = 1.49618`  
   - maximum generations `G = 200`  
   - velocity clamp `|v_{k,j}| ≤ v_max_j` where `v_max_j` equals the variable bounds width (i.e. `1` for coordinates, `0.5` for radii)  

2. **Initialisation**  
   - For each of the `P` particles generate random centres uniformly in `[0,1]^2` and radii uniformly in `[0,0.01]`.  
   - For each particle compute its current velocity as zero vector.  
   - Evaluate `g(v)`; store the best fitness `p_best` and the best particle `g_best`.

3. **Iteration (for g = 1 … G)**  
   - For each particle `p`  
     - Update velocity:
       ```
       v_p = w * v_p
             + c1 * rand() * (p_best_p - x_p)
             + c2 * rand() * (g_best - x_p)
       ```
       Clip component‑wise to `[-v_max, v_max]`.  
     - Update position: `x_p = x_p + v_p`.  
     - Clip `x_p` to the valid bounds `[0,1]` for x/y and `[0,0.5]` for r.  
     - Evaluate `g(x_p)`; if better than `p_best_p`, set `p_best_p = x_p`.  
     - If better than global `g_best`, set `g_best = x_p`.  
   - After all particles processed, increase the penalty multiplier `λ` gradually (e.g. multiply by 1.02 each generation) to make the algorithm stricter as it converges.

4. **Early stopping**  
   If the top fitness has not improved for 15 consecutive generations, break from the loop.

**E.  Post‑processing with local refinement**

All PSO particles are *feasible* to the extent that the penalty was effective.  Nevertheless, the final best particle may still miss a few tiny bits of overlap or boundary clearance because the penalty only stops the swarm at a threshold.

We perform a deterministic **gradient‑based fine‑tuning** that respects all constraints exactly:

1. **Radius‑maximisation with fixed centres**  
   For the best particle `x*`, recompute each radius as the smallest clearance to either a wall or another circle:
   ```
   r_i = min( x_i, 1-x_i, y_i, 1-y_i,
              min_j sqrt((x_i-x_j)^2+(y_i-y_j)^2) - r_j   (j ≠ i) )
   ```
   We iterate over all circles until the radii converge (difference < 1e‑10).  
   Because the initial radii are already almost maximal, only a few passes are needed.

2. **Local perturbation pass**  
   For a fixed number of sweeps (e.g. 10), pick a random circle, slightly jitter its centre (`±1e‑4`) and recompute the radius as in step 1.  
   If the sum of radii improves, accept; otherwise revert.  
   This deterministic “shake” cleans up any residual slack and guarantees feasibility.

The refined coordinates and radii are returned as `centers`, `radii` and their sum.
