2. **Search for a good set of centres** → maximise the LP objective over the 52‑dimensional position space by a black‑box optimiser (DI, hill‑climbing, or simulated annealing).

The LP is always feasible (we can always set all radii to 0), so the optimiser only ever faces a well‑defined evaluation function.

### 1. Geometry & Constraints

| Symbol | Meaning | Constraint |
|--------|---------|------------|
| \(c_k=(x_k,y_k)\) | centre of circle \(k\) | \(0 \le x_k, y_k \le 1\) |
| \(r_k\) | radius of circle \(k\) | \(r_k \ge 0\) |
| \(d_{ij} = \lVert c_i-c_j\rVert\) | Euclidean distance between centres \(i,j\) | |
| Walls |  | \(r_k \le x_k,\; r_k \le 1-x_k,\; r_k \le y_k,\; r_k \le 1-y_k\) |
| Overlaps | | \(r_i + r_j \le d_{ij}\) for all \(i<j\) |

The LP variables are only the radii; the distances \(d_{ij}\) are constants for a fixed set of centres.

### 2. Linear Programme for Radii

**Variables** : vector \( \mathbf{r}\in\mathbb{R}^{26}\).

**Objective** : maximise \( \sum_{k=1}^{26} r_k\) → equivalently minimise \(-\mathbf{1}^\top \mathbf{r}\).

**Constraints**  

*Boundary* (four inequalities per circle):
\[
\begin{array}{l}
r_k \le x_k\\
r_k \le 1-x_k\\
r_k \le y_k\\
r_k \le 1-y_k
\end{array}
\]

*Inter‑circle* (one inequality per unordered pair \((i,j)\)):
\[
r_i + r_j \le d_{ij}
\]

All inequalities are linear in \(\mathbf{r}\).  
The LP is solved with SciPy’s `linprog(method='highs')`; it is robust, fast, and handles up to a few hundred constraints gracefully.

**Result** : If the LP is infeasible (e.g., due to illegal centre positions that force negative radii), we treat the candidate positions as invalid and assign a very negative score to the optimiser.
