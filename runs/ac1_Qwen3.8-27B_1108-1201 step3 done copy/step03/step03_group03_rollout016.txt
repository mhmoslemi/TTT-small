`a^T Q a = sum_{i: i+k-i = k} a_i * 1 * a_{k-i} = sum_i a_i * a_{k-i}` (for valid `i`).

But wait, we also have the terms where `i + j = k` but we're summing over ALL `j`, not just `j = k-i`. Since `Q_{ij} = 0` when `j ≠ k-i`, we get:
`a^T Q a = sum_i a_i * Q_{i, k-i} * a_{k-i} = sum_i a_i * a_{k-i}`.

But this counts each pair twice (once for `(i, k-i)` and once for `(k-i, i)`), except when `i = k-i`.

So `a^T Q a = 2 * sum_{i < k-i} a_i * a_{k-i} + (if k even) a_{k/2}^2`.

While `conv_k = sum_i a_i * a_{k-i} = 2 * sum_{i < k-i} a_i * a_{k-i} + (if k even) a_{k/2}^2`.

Wait, these are the same! So `conv_k = a^T Q_k a` where `(Q_k)_{ij} = 1` if `i+j=k` and 0 otherwise.

Now, is `Q_k` positive semidefinite? `Q_k` is a permutation-like matrix (it has 1s on an anti-diagonal). The eigenvalues of such a matrix are `±1` (it's a flip/anti-identity matrix restricted to a sub-diagonal). So `Q_k` is NOT PSD in general.

This means the problem is NOT convex! We can't use convex solvers directly.

So we're back to non-convex optimization. The LP approach (fixing one variable and optimizing the other) is a way around this.

OK, let me focus on a practical approach that's different from the previous one and likely to be effective:

**New Approach: Multiplicative Weights + Stochastic Subgradient + CD**

The multiplicative weights update is:
`a_i <- a_i * exp(-eta * g_i) / Z`

where `g_i` is the subgradient of the objective with respect to `a_i`.

For the current problem, if the active peak is at lag `k*`, then `g_i = 2 * a[k*-i]` (with out-of-range = 0).

This update naturally:
- Reduces `a_i` when `a[k*-i]` is large (i.e., when `a_i` contributes to the peak).
- Preserves the sum (after normalization).

The key advantage over additive subgradient descent is that multiplicative updates stay in the interior of the simplex and don't need projection.

Let me also add a "temperature" concept: instead of always using the argmax, use a softmax over the top peaks to get a smoother subgradient.

**Algorithm:**
1. Initialize `a` (normalized to sum 1).
2. For each iteration:
   a. Compute `conv = fft_conv(a)`.
   b. Find top K peaks with weights `w_k = softmax(conv_k / T)`.
   c. Compute `g_i = sum_k w_k * 2 * a[k-i]` (weighted subgradient).
   d. Update: `a_i *= exp(-eta * g_i)`, then normalize.
   e. Optionally blend with previous: `a = (1-blend)*a_old + blend*a_new`.
3. Decrease `eta` and `T` over time.
4. Polish with coordinate descent.

This should be fast (O(n log n) per iteration) and might find better solutions than the LP approach.

"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using multiplicative weights update,
subgradient descent with momentum, LP-based refinement, and coordinate descent.
Key innovation: uses exponential (multiplicative) updates for the simplex
optimization, which naturally stay in the interior and avoid projection issues.
"""

import numpy as np
import time
import sys
from scipy.optimize import linprog

def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 2 ** (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]

def project_simplex(v):
    """Euclidean projection onto the probability simplex."""
    n = len(v)
    if n == 1:
        return np.array([max(v[0], 0.0)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)

def build_lp_pairs(n):
    """Pre-build index pairs for LP constraint matrix."""
    pairs = []
    for k in range(2 * n - 1):
        j_start = max(0, k - n + 1)
        j_end = min(n - 1, k)
        for j in range(j_start, j_end + 1):
            pairs.append((k, j, k - j))
    return pairs

def solve_lp_direction(f, M, pairs, n):
    """Solve LP: max sum(g) s.t. g>=0, (f*g)_k <= M for all k."""
    A_ub = np.zeros((2 * n - 1, n))
    for k, j, idx in pairs:
        A_ub[k, j] = f[idx]
    b_ub = np.full(2 * n - 1, M)
    c = -np.ones(n)
    bounds = [(0, None)] * n
    try:
        result = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=bounds,
                         method='highs', options={'presolve': True})
        if result.success:
            return np.maximum(result.x, 0.0)
    except Exception:
        pass
    return None

def multiplicative_weights(a0, time_limit, eta_init=1.0, eta_decay=0.999,
                           temp_init=0.5, temp_decay=0.998,
                           top_k=30, blend_init=0.7, blend_decay=0.9995):
    """Optimize using multiplicative (exponential) weights updates."""
    a = np.maximum(a0.copy(), 0.0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(len(a)) / len(a)
    else:
        a = a / s
    n = len(a)
    
    conv = fast_convolve(a)
    best_obj = 2.0 * n * conv.max()
    best_a = a.copy()
    
    t0 = time.monotonic()
    eta = eta_init
    temp = temp_init
    blend = blend_init
    no_improve = 0
    iter_count = 0
    
    while time.monotonic() - t0 < time_limit:
        iter_count += 1
        
        # Find top peaks
        if top_k < len(conv):
            top_idx = np.argpartition(conv, -top_k)[-top_k:]
        else:
            top_idx = np.arange(len(conv))
        top_vals = conv[top_idx]
        
        # Softmax weights over top peaks
        scaled = top_vals / (temp + 1e-15)
        scaled -= scaled.max()
        w = np.exp(scaled)
        w_sum = w.sum()
        if w_sum < 1e-15:
            w = np.zeros(len(top_idx))
            w[np.argmax(top_vals)] = 1.0
        else:
            w = w / w_sum
        
        # Compute weighted subgradient: g_i = sum_k 2*w_k * a[k-i]
        g = np.zeros(n)
        for ii in range(len(top_idx)):
            if w[ii] < 1e-12:
                continue
            k = int(top_idx[ii])
            wi = 2.0 * w[ii]
            i_start = max(0, k - n + 1)
            i_end = min(n - 1, k)
            # Vectorized: a[k-i] for i in [i_start, i_end]
            # k-i ranges from k-i_end to k-i_start
            idx_start = k - i_end
            idx_end = k - i_start
            g[i_start:i_end+1] += wi * a[idx_start:idx_end+1]
        
        # Multiplicative update
        # a_new_i = a_i * exp(-eta * g_i)
        # Clip to avoid overflow/underflow
        exp_arg = -eta * g
        exp_arg = np.clip(exp_arg, -50, 50)
        a_new = a * np.exp(exp_arg)
        a_new_sum = a_new.sum()
        if a_new_sum < 1e-15:
            break
        a_new = a_new / a_new_sum
        
        # Blend with previous
        a = (1.0 - blend) * a + blend * a_new
        a = np.maximum(a, 0.0)
        a_sum = a.sum()
        if a_sum < 1e-15:
            break
        a = a / a_sum
        
        # Evaluate
        conv = fast_convolve(a)
        cur_obj = 2.0 * n * conv.max()
        
        if cur_obj < best_obj - 1e-13:
            best_obj = cur_obj
            best_a = a.copy()
            no_improve = 0
        else:
            no_improve += 1
        
        # Anneal
        eta *= eta_decay
        temp *= temp_decay
        blend *= blend_decay
        
        if no_improve > 200:
            # Restart with perturbation
            rng = np.random.default_rng(iter_count)
            a = np.maximum(a + rng.standard_normal(n) * 0.02, 0.0)
            a = a / a.sum()
            conv = fast_convolve(a)
            no_improve = 0
            eta = max(0.1, eta * 2)
            blend = max(0.3, blend * 1.5)
        
        if eta < 0.001:
            break
    
    return best_a, best_obj

        g_sum = g.sum()
        if g_sum < 1e-15:
            break
        g = g / g_sum
        
        # If LP solution is too sparse, blend with uniform
        if g.max() > 0.5:
            g = 0.7 * g + 0.3 * uniform
        
        a_new = (1.0 - blend) * a + blend * g
        a = project_simplex(a_new)
        conv = fast_convolve(a)
        cur_obj = 2.0 * n * conv.max()
        
        if cur_obj < best_obj - 1e-12:
            best_obj = cur_obj
            best_a = a.copy()
            stall = 0
        else:
            stall += 1
        
        if stall >= blend_halve_every:
            blend = max(blend_min, blend * 0.5)
            stall = 0
            if blend < blend_min:
                break
        
        if stall > blend_halve_every * 4:
            rng = np.random.default_rng(hash(a.tobytes()[:10]) % 2**31)
            a = project_simplex(a + rng.standard_normal(n) * 0.01)
            conv = fast_convolve(a)
            stall = 0
    
    return best_a, best_obj

def coordinate_descent(a_in, max_rounds=50, step_frac=0.05):
    """Coordinate descent: try moving mass between pairs."""
    a = np.maximum(a_in.copy(), 0.0)
    s = a.sum()
    if s < 1e-15:
        return a
    a = a / s
    n = len(a)
    
    conv = fast_convolve(a)
    best_obj = 2.0 * n * conv.max()
    
    for rnd in range(max_rounds):
        improved = False
        # Process in random order
        rng = np.random.default_rng(rnd * 12345 + 678)
        order = rng.permutation(n)
        
        for i in order:
            if a[i] < 1e-8:
                continue
            delta = a[i] * step_frac
            if delta < 1e-9:
                continue
            
            # Try moving to each j (sample subset for speed)
            if n <= 256:
                candidates = [j for j in range(n) if j != i]
            else:
                candidates = list(rng.choice(n, size=min(50, n), replace=False))
                if i in candidates:
                    candidates.remove(i)
            
            best_j = -1
            best_obj_j = best_obj
            
            for j in candidates:
                a_test = a.copy()
                a_test[i] -= delta
                a_test[j] += delta
                if a_test[i] < 0:
                    continue
                a_test = np.maximum(a_test, 0.0)
                st = a_test.sum()
                if st < 1e-15:
                    continue
                a_test /= st
                conv_test = fast_convolve(a_test)
                obj_test = 2.0 * n * conv_test.max()
                if obj_test < best_obj_j - 1e-14:
                    best_obj_j = obj_test
                    best_j = j
            
            if best_j >= 0:
                a[i] -= delta
                a[best_j] += delta
                a = np.maximum(a, 0.0)
                a = a / a.sum()
                conv = fast_convolve(a)
                best_obj = best_obj_j
                improved = True
        
        if not improved:
            break
    
    return a

def gen_inits(n, parent=None, rng=None):
    """Generate diverse initializations."""
    if rng is None:
        rng = np.random.default_rng(42)
    inits = {}
    x = np.arange(n, dtype=np.float64)
    
    inits['uniform'] = np.ones(n) / n
    
    tri = np.minimum(x + 1.0, n - x)
    tri = np.maximum(tri, 0.01)
    inits['triangle'] = tri / tri.sum()
    
    edge = np.zeros(n)
    e = max(1, n // 6)
    edge[:e] = 1.0
    edge[-e:] = 1.0
    inits['edge'] = edge / edge.sum()
    
    g = np.exp(-0.5 * ((x - 0.5 * (n - 1)) / (0.3 * n)) ** 2)
    inits['gauss'] = g / g.sum()
    
    inits['random'] = rng.dirichlet(np.ones(n) * 0.3)
    
    # Bimodal
    g2 = (np.exp(-0.5 * ((x - 0.25 * n) / (0.12 * n)) ** 2) +
          np.exp(-0.5 * ((x - 0.75 * n) / (0.12 * n)) ** 2))
    inits['bimodal'] = g2 / g2.sum()
    
    # Cosine window
    cos_w = 0.5 * (1 + np.cos(2 * np.pi * x / n))
    cos_w = np.maximum(cos_w, 0.01)
    inits['cosine'] = cos_w / cos_w.sum()
    
    # Power law
    pw = (x + 1.0) ** (-0.5)
    inits['power'] = pw / pw.sum()
    
    # Sine (one period)
    sin_w = np.abs(np.sin(np.pi * x / n))
    sin_w = np.maximum(sin_w, 0.01)
    inits['sine'] = sin_w / sin_w.sum()
    
    if parent is not None and len(parent) > 0:
        p = np.maximum(parent, 0)
        ps = p.sum()
        if ps > 1e-10:
            if len(p) == n:
                inits['parent'] = p / ps
            elif len(p) > n:
                p_int = np.interp(np.linspace(0, 1, n), np.linspace(0, 1, len(p)), p)
                p_int = np.maximum(p_int, 0)
                inits['parent_ds'] = p_int / p_int.sum()
            else:
                p_int = np.interp(np.linspace(0, 1, n), np.linspace(0, 1, len(p)), p)
                p_int = np.maximum(p_int, 0)
                inits['parent_up'] = p_int / p_int.sum()
    
    return inits

"""
Minimizes 2*n*max(conv(a,a))/(sum(a))^2 using multiplicative weights (exponential)
updates as the primary optimizer, combined with subgradient descent, LP-based
refinement, and coordinate descent polish. The multiplicative weights approach
naturally stays in the interior of the simplex and provides a smooth path through
the landscape, escaping local optima more effectively than pure LP or subgradient
methods alone. Multiple sequence lengths and diverse initializations are explored.
"""

import numpy as np
import time
from scipy.optimize import linprog


def fast_convolve(a):
    """Linear auto-convolution via FFT."""
    n = len(a)
    size = 2 * n - 1
    fft_size = 2 ** (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]


def project_simplex(v):
    """Euclidean projection onto the probability simplex {x>=0, sum(x)=1}."""
    n = len(v)
    if n == 1:
        return np.array([max(v[0], 0.0)])
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    cond = u * np.arange(1, n + 1) > (cssv - 1)
    if not cond.any():
        return np.ones(n) / n
    rho = np.nonzero(cond)[0][-1]
    theta = (cssv[rho] - 1.0) / (rho + 1.0)
    return np.maximum(v - theta, 0.0)


def build_lp_pairs(n):
    """Pre-build index pairs for LP constraint matrix."""
    pairs = []
    for k in range(2 * n - 1):
        j_start = max(0, k - n + 1)
        j_end = min(n - 1, k)
        for j in range(j_start, j_end + 1):
            pairs.append((k, j, k - j))
    return pairs


def solve_lp_direction(f, M, pairs, n):
    """Solve LP: max sum(g) s.t. g>=0, (f*g)_k <= M for all k."""
    A_ub = np.zeros((2 * n - 1, n))
    for k, j, idx in pairs:
        A_ub[k, j] = f[idx]
    b_ub = np.full(2 * n - 1, M)
    c = -np.ones(n)
    bounds = [(0, None)] * n
    try:
        result = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=bounds,
                         method='highs', options={'presolve': True})
        if result.success:
            return np.maximum(result.x, 0.0)
    except Exception:
        pass
    return None


def multiplicative_weights(a0, time_limit, eta_init=1.0, eta_decay=0.999,
                           temp_init=1.0, temp_decay=0.997,
                           top_k=25, blend_init=0.7, blend_decay=0.9995):

    a = np.maximum(a0.copy(), 0.0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(len(a)) / len(a)
    else:
        a = a / s
    n = len(a)

    conv = fast_convolve(a)
    best_obj = 2.0 * n * conv.max()
    best_a = a.copy()

    t0 = time.monotonic()
    eta = eta_init
    temp = temp_init
    blend = blend_init
    no_improve = 0
    iter_count = 0

    while time.monotonic() - t0 < time_limit:
        iter_count += 1

        # Find top peaks
        if top_k < len(conv):
            top_idx = np.argpartition(conv, -top_k)[-top_k:]
        else:
            top_idx = np.arange(len(conv))
        top_vals = conv[top_idx]

        # Softmax weights over top peaks
        scaled = top_vals / (temp + 1e-15)
        scaled -= scaled.max()
        w = np.exp(scaled)
        w_sum = w.sum()
        if w_sum < 1e-15:
            w_arr = np.zeros(len(top_idx))
            w_arr[np.argmax(top_vals)] = 1.0
        else:
            w_arr = w / w_sum

        # Compute weighted subgradient: g_i = sum_k 2*w_k * a[k-i]
        g = np.zeros(n)
        for ii in range(len(top_idx)):
            if w_arr[ii] < 1e-12:
                continue
            k = int(top_idx[ii])
            wi = 2.0 * w_arr[ii]
            i_start = max(0, k - n + 1)
            i_end = min(n - 1, k)
            idx_start = k - i_end
            idx_end = k - i_start
            g[i_start:i_end + 1] += wi * a[idx_start:idx_end + 1]

        # Multiplicative update: a_i *= exp(-eta * g_i)
        exp_arg = -eta * g
        exp_arg = np.clip(exp_arg, -50.0, 50.0)
        a_new = a * np.exp(exp_arg)
        a_new_sum = a_new.sum()
        if a_new_sum < 1e-15:
            break
        a_new = a_new / a_new_sum

        # Blend with previous
        a = (1.0 - blend) * a + blend * a_new
        a = np.maximum(a, 0.0)
        a_sum = a.sum()
        if a_sum < 1e-15:
            break
        a = a / a_sum

        # Evaluate
        conv = fast_convolve(a)
        cur_obj = 2.0 * n * conv.max()

        if cur_obj < best_obj - 1e-13:
            best_obj = cur_obj
            best_a = a.copy()
            no_improve = 0
        else:
            no_improve += 1

        # Anneal
        eta *= eta_decay
        temp *= temp_decay
        blend *= blend_decay

        if no_improve > 200:
            rng_local = np.random.default_rng(iter_count * 31 + 7)
            a = np.maximum(a + rng_local.standard_normal(n) * 0.02, 0.0)
            a = a / a.sum()
            conv = fast_convolve(a)
            no_improve = 0
            eta = max(0.05, eta * 2.0)
            blend = min(0.9, blend * 1.5)

        if eta < 0.005:
            break

    return best_a, best_obj


def subgradient_optimize(a0, time_limit, lr_init=0.02, momentum=0.9,
                         top_k=30, temp_init=0.1):
    """Subgradient descent with momentum on the simplex."""
    a = np.maximum(a0.copy(), 0.0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(len(a)) / len(a)
    else:
        a = a / s
    n = len(a)

    v = np.zeros(n)
    conv = fast_convolve(a)
    best_obj = 2.0 * n * conv.max()
    best_a = a.copy()

    t0 = time.monotonic()
    lr = lr_init
    no_improve = 0
    iter_count = 0

    while time.monotonic() - t0 < time_limit:
        iter_count += 1

        if top_k < len(conv):
            top_idx = np.argpartition(conv, -top_k)[-top_k:]
        else:
            top_idx = np.arange(len(conv))
        top_vals = conv[top_idx]
        pmax = top_vals.max()

        # Softmax weights
        scaled = top_vals / (temp_init + pmax * 0.1)
        scaled -= scaled.max()
        w = np.exp(scaled)
        w_sum = w.sum()
        if w_sum < 1e-15:
            w_arr = np.zeros(len(top_idx))
            w_arr[np.argmax(top_vals)] = 1.0
        else:
            w_arr = w / w_sum

        # Compute weighted subgradient
        g = np.zeros(n)
        for ii in range(len(top_idx)):
            if w_arr[ii] < 1e-12:
                continue
            k = int(top_idx[ii])
            wi = 2.0 * w_arr[ii]
            i_start = max(0, k - n + 1)
            i_end = min(n - 1, k)
            idx_start = k - i_end
            idx_end = k - i_start
            g[i_start:i_end + 1] += wi * a[idx_start:idx_end + 1]

        g_norm = np.linalg.norm(g)
        if g_norm > 1e-15:
            g = g / g_norm

        v = momentum * v - lr * g
        a_new = a + v
        a = project_simplex(a_new)

        conv = fast_convolve(a)
        cur_obj = 2.0 * n * conv.max()

        if cur_obj < best_obj - 1e-13:
            best_obj = cur_obj
            best_a = a.copy()
            no_improve = 0
        else:
            no_improve += 1

        if no_improve > 150:
            rng_local = np.random.default_rng(iter_count * 13 + 1)
            a = project_simplex(a + rng_local.standard_normal(n) * 0.01)
            conv = fast_convolve(a)
            v *= 0.3
            lr = max(0.003, lr * 0.7)
            no_improve = 0

        lr *= 0.999

        if lr < 0.001:
            break

    return best_a, best_obj


def lp_optimize(a0, time_limit, blend_init=0.4, blend_min=0.005,
                blend_halve_every=12):
    """LP-based directional optimization (for moderate n)."""
    a = np.maximum(a0.copy(), 0.0)
    s = a.sum()
    if s < 1e-15:
        a = np.ones(len(a)) / len(a)
    else:
        a = a / s
    n = len(a)

    if n > 768:
        return subgradient_optimize(a, time_limit, lr_init=0.01, top_k=40)

    pairs = build_lp_pairs(n)
    uniform = np.ones(n) / n

    conv = fast_convolve(a)
    best_obj = 2.0 * n * conv.max()
    best_a = a.copy()

    t0 = time.monotonic()
    blend = blend_init
    stall = 0

    while time.monotonic() - t0 < time_limit:
        M = conv.max()
        if M < 1e-15:
            break

        g = solve_lp_direction(a, M, pairs, n)
        if g is None:
            break

        g_sum = g.sum()
        if g_sum < 1e-15:
            break
        g = g / g_sum

        if g.max() > 0.5:
            g = 0.7 * g + 0.3 * uniform

        a_new = (1.0 - blend) * a + blend * g
        a = project_simplex(a_new)
        conv = fast_convolve(a)
        cur_obj = 2.0 * n * conv.max()

        if cur_obj < best_obj - 1e-12:
            best_obj = cur_obj
            best_a = a.copy()
            stall = 0
        else:
            stall += 1

        if stall >= blend_halve_every:
            blend = max(blend_min, blend * 0.5)
            stall = 0
            if blend < blend_min:
                break

        if stall > blend_halve_every * 4:
            rng_local = np.random.default_rng(iter(max(1, int(sum(a[:5]) * 1e10)), 999))
            a = project_simplex(a + rng_local.standard_normal(n) * 0.01)
            conv = fast_convolve(a)
            stall = 0

    return best_a, best_obj


def coordinate_descent(a_in, max_rounds=50, step_frac=0.04):
    """Coordinate descent: try moving mass between pairs of coordinates."""
    a = np.maximum(a_in.copy(), 0.0)
    s = a.sum()
    if s < 1e-15:
        return a
    a = a / s
    n = len(a)

    conv = fast_convolve(a)
    best_obj = 2.0 * n * conv.max()

    for rnd in range(max_rounds):
        improved = False
        rng = np.random.default_rng(rnd * 12345 + 67890)
        order = rng.permutation(n)

        for i in order:
            if a[i] < 1e-8:
                continue
            delta = a[i] * step_frac
            if delta < 1e-9:
                continue

            if n <= 300:
                candidates = [j for j in range(n) if j != i]
            else:
                cands = rng.choice(n, size=min(40, n - 1), replace=False)
                candidates = [j for j in cands if j != i]

            best_j = -1
            best_obj_j = best_obj

            for j in candidates:
                a_test = a.copy()
                a_test[i] -= delta
                a_test[j] += delta
                if a_test[i] < 0:
                    continue
                a_test = np.maximum(a_test, 0.0)
                st = a_test.sum()
                if st < 1e-15:
                    continue
                a_test /= st
                conv_test = fast_convolve(a_test)
                obj_test = 2.0 * n * conv_test.max()
                if obj_test < best_obj_j - 1e-14:
                    best_obj_j = obj_test
                    best_j = j

            if best_j >= 0:
                a[i] -= delta
                a[best_j] += delta
                a = np.maximum(a, 0.0)
                a = a / a.sum()
                conv = fast_convolve(a)
                best_obj = best_obj_j
                improved = True

        if not improved:
            break

    return a


def gen_inits(n, parent=None, rng=None):
    """Generate diverse initializations."""
    if rng is None:
        rng = np.random.default_rng(42)
    inits = {}
    x = np.arange(n, dtype=np.float64)

    inits['uniform'] = np.ones(n) / n

    tri = np.minimum(x + 1.0, n - x)
    tri = np.maximum(tri, 0.01)
    inits['triangle'] = tri / tri.sum()

    edge = np.zeros(n)
    e = max(1, n // 5)
    edge[:e] = 1.0
    edge[-e:] = 1.0
    inits['edge'] = edge / edge.sum()

    g = np.exp(-0.5 * ((x - 0.5 * (n - 1)) / (0.3 * n)) ** 2)
    inits['gauss'] = g / g.sum()

    inits['random'] = rng.dirichlet(np.ones(n) * 0.3)

    g2 = (np.exp(-0.5 * ((x - 0.25 * n) / (0.12 * n)) ** 2) +
          np.exp(-0.5 * ((x - 0.75 * n) / (0.12 * n)) ** 2))
    inits['bimodal'] = g2 / g2.sum()

    cos_w = 0.5 * (1.0 + np.cos(2.0 * np.pi * x / n))
    cos_w = np.maximum(cos_w, 0.01)
    inits['cosine'] = cos_w / cos_w.sum()

    pw = (x + 1.0) ** (-0.5)
    inits['power'] = pw / pw.sum()

    sin_w = np.abs(np.sin(np.pi * x / n))
    sin_w = np.maximum(sin_w, 0.01)
    inits['sine'] = sin_w / sin_w.sum()

    # Triangular with sharper peak
    tri2 = np.exp(-0.5 * (x / (0.15 * n)) ** 2) + np.exp(-0.5 * ((n - 1 - x) / (0.15 * n)) ** 2)
    inits['sharp_edge'] = tri2 / tri2.sum()

    if parent is not None and len(parent) > 0:
        p = np.maximum(parent, 0)
        ps = p.sum()
        if ps > 1e-10:
            if len(p) == n:
                inits['parent'] = p / ps
            elif len(p) > n:
                p_int = np.interp(np.linspace(0, 1, n), np.linspace(0, 1, len(p)), p)
                p_int = np.maximum(p_int, 0)
                ps_int = p_int.sum()
                if ps_int > 1e-10:
                    inits['parent_ds'] = p_int / ps_int
            else:
                p_int = np.interp(np.linspace(0, 1, n), np.linspace(0, 1, len(p)), p)
                p_int = np.maximum(p_int, 0)
                ps_int = p_int.sum()
                if ps_int > 1e-10:
                    inits['parent_up'] = p_int / ps_int

    return inits


def propose_candidate(seed=42, budget_s=1800, **kwargs):
    """
    Multi-phase search combining multiplicative weights, subgradient descent,
    LP refinement, and coordinate descent across multiple sequence lengths.
    """
    rng = np.random.default_rng(seed)
    deadline = time.monotonic() + max(1.0, float(budget_s) - 30.0)

    best_sequence = None
    best_score = float('inf')

    # Get parent sequence
    parent = None
    try:
        p = np.asarray(height_sequence_1, dtype=np.float64)
        p = np.clip(p, 0.0, 1000.0)
        if p.ndim == 1 and p.size > 0 and np.isfinite(p).all() and p.sum() > 1e-10:
            parent = p
            par_score = float(evaluate_sequence(p.tolist()))
            print(f"Parent: n={len(p)}, score={par_score:.6f}")
            best_score = par_score
            best_sequence = p.copy()
    except Exception:
        pass

    # Phase 1: Multiplicative weights scan over multiple lengths
    print("=== Phase 1: MW Scan ===")
    t_start = time.monotonic()
    lengths = [384, 512, 640, 768, 1024]

    results = []
    phase1_end = time.monotonic() + min(450.0, (deadline - time.monotonic()) * 0.30)

    for n in lengths:
        if time.monotonic() > phase1_end - 30:
            break
        inits = gen_inits(n, parent, rng)
        prio = ['parent', 'parent_ds', 'parent_up', 'uniform', 'bimodal',
                'triangle', 'random', 'cosine', 'edge', 'sharp_edge']
        names = [nm for nm in prio if nm in inits][:4]

        remaining_p1 = phase1_end - time.monotonic()
        t_per = max(12.0, remaining_p1 / max(1, (len(lengths) - lengths.index(n)) * 4))

        for name in names:
            if time.monotonic() > phase1_end - 8:
                break
            t_alloc = min(t_per, phase1_end - time.monotonic() - 5)
            if t_alloc < 8:
                break

            a0 = inits[name]
            a_opt, obj_opt = multiplicative_weights(a0, t_alloc,
                                                    eta_init=1.2, eta_decay=0.999,
                                                    temp_init=0.8, temp_decay=0.996,
                                                    top_k=20, blend_init=0.75,
                                                    blend_decay=0.999)

            # Quick subgradient follow-up
            a_opt2, obj2 = subgradient_optimize(a_opt, min(4.0, t_alloc * 0.1),
                                                 lr_init=0.01, momentum=0.9,
                                                 top_k=20, temp_init=0.05)
            if obj2 < obj_opt:
                a_opt = a_opt2

            score = float(evaluate_sequence(a_opt.tolist()))
            if np.isfinite(score):
                results.append((score, n, name, a_opt.copy()))
                if score < best_score:
                    best_score = score
                    best_sequence = a_opt.copy()
                    print(f"  n={n} {name}: {score:.6f}")

        print(f"  Length {n} done, best so far: {best_score:.6f}")

    results.sort(key=lambda x: x[0])
    print(f"Phase 1 best: {best_score:.6f} (elapsed {time.monotonic()-t_start:.0f}s)")

    # Phase 2: Deep optimization on top candidates
    print("=== Phase 2: Deep Optimization ===")
    t_start2 = time.monotonic()
    top_list = []
    seen = set()
    for score, n, name, a_opt in results[:12]:
        if n not in seen:
            top_list.append((n, a_opt))
            seen.add(n)
        if len(top_list) >= 5:
            break
    if best_sequence is not None and len(best_sequence) not in seen:
        top_list.append((len(best_sequence), best_sequence.copy()))

    remaining2 = deadline - time.monotonic() - 300.0
    t_per_cand = max(25.0, remaining2 / max(1, len(top_list)))

    for n, a0 in top_list:
        if time.monotonic() > deadline - 270:
            break
        t_cand = min(t_per_cand * 1.5, deadline - time.monotonic() - 250)
        if t_cand < 15:
            break

        # Strategy 1: MW with different params
        t_s = min(t_cand * 0.3, deadline - time.monotonic() - 230)
        if t_s > 8:
            a_opt, obj_opt = multiplicative_weights(a0, t_s,
                                                    eta_init=0.6, eta_decay=0.9992,
                                                    temp_init=0.4, temp_decay=0.997,
                                                    top_k=35, blend_init=0.5,
                                                    blend_decay=0.9992)
            score = float(evaluate_sequence(a_opt.tolist()))
            if np.isfinite(score) and score < best_score:
                best_score = score
                best_sequence = a_opt.copy()
                print(f"  Deep MW n={n}: {score:.6f}")

        # Strategy 2: Subgradient
        t_s2 = min(t_cand * 0.3, deadline - time.monotonic() - 210)
        if t_s2 > 8:
            a_opt, obj_opt = subgradient_optimize(a0, t_s2,
                                                   lr_init=0.012, momentum=0.92,
                                                   top_k=40, temp_init=0.04)
            score = float(evaluate_sequence(a_opt.tolist()))
            if np.isfinite(score) and score < best_score:
                best_score = score
                best_sequence = a_opt.copy()
                print(f"  Deep SG n={n}: {score:.6f}")

        # Strategy 3: LP (if n is manageable)
        if n <= 768:
            t_s3 = min(t_cand * 0.25, deadline - time.monotonic() - 190)
            if t_s3 > 8:
                a_opt, obj_opt = lp_optimize(a0, t_s3,
                                              blend_init=0.25, blend_min=0.003)
                score = float(evaluate_sequence(a_opt.tolist()))
                if np.isfinite(score) and score < best_score:
                    best_score = score
                    best_sequence = a_opt.copy()
                    print(f"  Deep LP n={n}: {score:.6f}")

        # Strategy 4: MW with aggressive exploration
        t_s4 = min(t_cand * 0.25, deadline - time.monotonic() - 170)
        if t_s4 > 8:
            a_opt, obj_opt = multiplicative_weights(a0, t_s4,
                                                    eta_init=2.0, eta_decay=0.998,
                                                    temp_init=2.0, temp_decay=0.99,
                                                    top_k=15, blend_init=0.9,
                                                    blend_decay=0.998)
            score = float(evaluate_sequence(a_opt.tolist()))
            if np.isfinite(score) and score < best_score:
                best_score = score
                best_sequence = a_opt.copy()
                print(f"  Deep MW-agg n={n}: {score:.6f}")

    print(f"Phase 2 best: {best_score:.6f} (elapsed {time.monotonic()-t_start2:.0f}s)")

    # Phase 3: Polish the best solution
    print("=== Phase 3: Polish ===")
    t_start3 = time.monotonic()
    if best_sequence is not None:
        n_b = len(best_sequence)

        # Subgradient polish
        t_s = min(50.0, max(10.0, (deadline - time.monotonic() - 120.0) * 0.25))
        a_s, _ = subgradient_optimize(best_sequence, t_s,
                                       lr_init=0.004, momentum=0.93,
                                       top_k=50, temp_init=0.02)
        score_s = float(evaluate_sequence(a_s.tolist()))
        if np.isfinite(score_s) and score_s < best_score:
            best_score = score_s
            best_sequence = a_s.copy()
            print(f"  SG polish: {score_s:.6f}")

        # MW polish
        t_m = min(50.0, max(10.0, (deadline - time.monotonic() - 100.0) * 0.25))
        a_m, _ = multiplicative_weights(best_sequence, t_m,
                                         eta_init=0.3, eta_decay=0.9995,
                                         temp_init=0.2, temp_decay=0.998,
                                         top_k=40, blend_init=0.3,
                                         blend_decay=0.999)
        score_m = float(evaluate_sequence(a_m.tolist()))
        if np.isfinite(score_m) and score_m < best_score:
            best_score = score_m
            best_sequence = a_m.copy()
            print(f"  MW polish: {score_m:.6f}")

        # LP polish
        if n_b <= 768:
            t_l = min(50.0, max(10.0, (deadline - time.monotonic() - 80.0) * 0.3))
            a_l, _ = lp_optimize(best_sequence, t_l,
                                  blend_init=0.12, blend_min=0.002)
            score_l = float(evaluate_sequence(a_l.tolist()))
            if np.isfinite(score_l) and score_l < best_score:
                best_score = score_l
                best_sequence = a_l.copy()
                print(f"  LP polish: {score_l:.6f}")

        # Coordinate descent
        t_cd = max(5.0, deadline - time.monotonic() - 40.0)
        if t_cd > 10:
            max_rounds = max(20, int(t_cd / 3))
            a_cd = coordinate_descent(best_sequence, max_rounds=max_rounds,
                                       step_frac=0.03)
            score_cd = float(evaluate_sequence(a_cd.tolist()))
            if np.isfinite(score_cd) and score_cd < best_score:
                best_score = score_cd
                best_sequence = a_cd.copy()
                print(f"  CD: {score_cd:.6f}")

    print(f"Phase 3 done (elapsed {time.monotonic()-t_start3:.0f}s)")

    # Phase 4: Perturbations and re-optimization
    print("=== Phase 4: Perturbations ===")
    if best_sequence is not None and time.monotonic() < deadline - 20:
        n_b = len(best_sequence)
        pert_budget = deadline - time.monotonic() - 15.0
        n_perts = max(3, int(pert_budget / 8.0))

        for trial in range(n_perts):
            if time.monotonic() > deadline - 15:
                break
            ps = 0.005 + 0.01 * (trial % 3)
            noise = rng.standard_normal(n_b) * ps
            a_p = project_simplex(best_sequence + noise)

            t_p = min(4.0, (deadline - time.monotonic() - 12.0) * 0.4)
            if t_p < 3:
                break
            a_opt, _ = multiplicative_weights(a_p, t_p,
                                               eta_init=0.8, eta_decay=0.998,
                                               temp_init=0.5, temp_decay=0.995,
                                               top_k=30, blend_init=0.6,
                                               blend_decay=0.998)
            t_sg = min(3.0, (deadline - time.monotonic() - 10.0) * 0.4)
