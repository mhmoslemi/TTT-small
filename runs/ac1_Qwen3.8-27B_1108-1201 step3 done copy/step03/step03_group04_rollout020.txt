    """Linear convolution via FFT."""
    if b is None:
        b = a
    n = len(a)
    m = len(b)
    size = n + m - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    B = np.fft.rfft(b, fft_size)
    return np.fft.irfft(A * B, fft_size)[:size]

            a_new = a_new / s
        else:

        a = a_new
        conv = fast_convolve(a)
        cur_obj = 2.0 * n * conv.max()
        
        if cur_obj < best_obj - 1e-12:
            best_obj = cur_obj
            best_a = a.copy()
            no_improve = 0
        else:
            no_improve += 1
        
        # Adaptive strategies
        if no_improve > 300:
            # Reduce LR
            lr *= 0.6
            no_improve = 0
            
        if no_improve > 800:
            # Add noise and reset
            noise = rng.standard_normal(n) * 0.002
            a = norm_to_simplex(a + noise)
            m_v = np.zeros(n)
            v_v = np.zeros(n)
            t_count = 0
            lr = lr_init * 0.5
            no_improve = 0
        
        # Slow LR decay
        lr = max(lr * 0.9998, 1e-5)
        
        it += 1
        if verbose and it % verbose_every == 0:
            elapsed = time.monotonic() - t0
            print(f"    Adam it={it}, obj={best_obj:.6f}, M={M:.4e}, lr={lr:.2e}, elapsed={elapsed:.1f}s")
    
    return best_a, best_obj

Now let me think about good initializations. The key insight is that we want the autocorrelation to be flat. Sequences with good autocorrelation properties include:

1. **m-sequences (maximum length sequences)**: Binary sequences with near-optimal autocorrelation. We can convert to real by mapping {0,1} to {alpha, 1-alpha} or by taking the magnitude of a complex m-sequence.

2. **Zadoff-Chu sequences**: Have perfect periodic autocorrelation. `z[n] = exp(-j*pi*k*n*(n+1)/N)` for k=1..N-1. The magnitude is 1, so not directly useful, but we can modify.

3. **Barker sequences**: Short binary sequences with optimal aperiodic autocorrelation.

4. **Golay complementary sequences**: Pairs that have zero aperiodic autocorrelation sum.

For our problem, since we need non-negative reals, let's think about what structures help:

**Key realization**: If `a` is symmetric (`a[j] = a[n-1-j]`), then `c[n-1] = sum_j a[j]^2` = energy. So the center peak equals the energy. To minimize this, we want to spread mass (reduce energy = sum a^2). The minimum energy for sum=1 is 1/n (uniform). So for symmetric sequences, the center peak is at least 1/n, giving obj >= 2.

Wait, that's interesting! For symmetric sequences, `c[n-1] = sum_j a[j] * a[n-1-j] = sum_j a[j]^2 >= 1/n`. So obj >= 2n * (1/n) = 2.

But we've achieved 1.507 < 2! So the best sequences must be **asymmetric**.

For asymmetric sequences, `c[n-1] = sum_j a[j] * a[n-1-j]` can be less than `sum_j a[j]^2` (by Cauchy-Schwarz, it's <= sqrt(sum a^2 * sum a^2) = sum a^2, with equality when a is symmetric). So asymmetric sequences can have lower center peaks!

This is a crucial insight. The optimal sequence must be asymmetric.

Let me think about what kind of asymmetry helps. If we put more mass at one end:
- `c[0] = a[0]^2` (small if a[0] is small)
- `c[n-1] = sum a[j]*a[n-1-j]` (the "cross-correlation with reversed")
- `c[2n-2] = a[n-1]^2` (small if a[n-1] is small)

For a sequence that's mostly concentrated in the first half:
- High values at positions 0..n/2
- Low values at positions n/2..n-1
Then `c[n-1]` would be the correlation of the "high" part with the "low" part (reversed), which could be small.

But then `c[0] = a[0]^2` might be large if a[0] is large.

So there's a trade-off. The optimal solution probably has a "ramp" or "exponential decay" structure.

Let me think about exponential decay: `a[j] = C * r^j` for r < 1.
- `c[k] = C^2 * sum_{j=max(0,k-n+1)}^{min(n-1,k)} r^j * r^{k-j} = C^2 * (number of terms) * r^k`... 

Wait, that's not right. Let me redo:
`c[k] = sum_j a[j] * a[k-j]` where both j and k-j must be in [0, n-1].
For `a[j] = C * r^j`:
`c[k] = C^2 * sum_{j: 0<=j<n, 0<=k-j<n} r^j * r^{k-j} = C^2 * r^k * (number of valid j)`

For 0 <= k <= n-1: all j from 0 to k are valid, so `c[k] = C^2 * r^k * (k+1)`
For n <= k <= 2n-2: j from k-n+1 to n-1, so `c[k] = C^2 * r^k * (2n-1-k)`

So `c[k]` increases for k < n-1 (r^k * (k+1) increases while k+1 grows faster than r^k decreases, for r not too small) and then... actually let's check the derivative.

For the first half: `f(k) = r^k * (k+1)`. `f(k+1)/f(k) = r * (k+2)/(k+1)`. This is < 1 when `r < (k+1)/(k+2)`, i.e., for large k if r < 1.

So the peak in the first half is where `r * (k+2)/(k+1) = 1`, i.e., `k+2 = (k+1)/r`, i.e., `k = (1-r)/(r*(1))`... let me redo:
`r*(k+2) = k+1` → `rk + 2r = k + 1` → `k(r-1) = 1-2r` → `k = (2r-1)/(1-r)` (for r > 1/2).

So for r > 1/2, there's a peak at k = (2r-1)/(1-r) in the first half.
For r = 0.9: k = 0.8/0.1 = 8
For r = 0.95: k = 0.9/0.05 = 18
For r → 1: k → ∞ (uniform case, peak at center)

For the second half (k >= n), it's a mirror: `c[k] = C^2 * r^k * (2n-1-k)`, which decreases.

So for an exponentially decaying sequence, the convolution is a single-bump function peaked somewhere in the first half. This is different from the symmetric case where the peak is at the center.

The max for the exponential case: `C^2 * r^k * (k+1)` at the peak k.
With sum = C * (1-r^n)/(1-r) = 1, so C = (1-r)/(1-r^n).

For large n and r close to 1: C ≈ (1-r), and the peak is at k ≈ (2r-1)/(1-r).
`c_peak ≈ C^2 * r^k * (k+1) ≈ (1-r)^2 * (k+1)` (since r^k ≈ 1 for small k relative to 1/(1-r))
`k+1 ≈ (2r-1)/(1-r) + 1 = (2r-1+1-r)/(1-r) = r/(1-r)`
So `c_peak ≈ (1-r)^2 * r/(1-r) = r*(1-r)`
Max occurs at r = 1/2: c_peak = 1/4
But wait, for r=1/2, k = 0, so c[0] = C^2 = ((1/2)/(1-1/2^n))^2 ≈ 1/4. Yes.

Obj = 2n * c_peak / 1 = 2n * r*(1-r) (approximately)
At r=1/2: obj = 2n/4 = n/2. That's terrible for large n!

So pure exponential decay is bad. We need something more nuanced.

**Better idea: "Two-bump" or "off-center" sequences**

What if we have two groups of mass, separated?
- Group 1: positions 0 to p-1
- Group 2: positions q to n-1 (where q > p)

Then the self-convolution has:
- c[k] for 0 <= k < p: within group 1
- c[k] for q <= k < 2q: cross terms between groups
- c[k] for k >= 2q-p: within group 2 (but reversed)

If the groups are far apart, the cross terms might be small, and each group's self-convolution is localized.

"""
Multi-strategy optimization for minimizing 2*n*max(conv(a,a))/(sum(a))^2.
Uses Adam subgradient descent with spectral reshaping, diverse initializations
including asymmetric decays and bimodal profiles, and adaptive restarts.
Key insight: optimal sequences are asymmetric, exploiting the difference between
c[n-1] (cross-correlation) and c[0] (energy) to achieve peaks below 1/n.
"""

import numpy as np
import time

def fast_convolve(a, b=None):
    """Linear convolution via FFT."""
    if b is None:
        b = a
    n = len(a)
    m = len(b)
    size = n + m - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    B = np.fft.rfft(b, fft_size)
    return np.fft.irfft(A * B, fft_size)[:size]

def local_obj(a):
    """Compute 2*n*max(conv(a,a))/(sum(a))^2 assuming a is on simplex."""
    n = len(a)
    conv = fast_convolve(a)
    return 2.0 * n * conv.max()

def norm_simplex(a):
    """Project to non-negative simplex."""
    a = np.maximum(a.astype(np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        return np.ones(len(a)) / len(a)
    return a / s

def compute_subgradient(a, n_peaks=30, sharpness=0.2):
    """Compute softmax-weighted subgradient of max(conv(a,a))."""
    n = len(a)
    conv = fast_convolve(a)
    M = conv.max()
    top_k = min(n_peaks, 2 * n - 1)
    peak_indices = np.argsort(conv)[-top_k:]
    peak_vals = conv[peak_indices]
    spread = max(peak_vals.max() - peak_vals.min(), 1e-15)
    w = np.exp((peak_vals - peak_vals.max()) / (spread * sharpness))
    w /= w.sum()
    g = np.zeros(n)
    for i in range(len(peak_indices)):
        if w[i] < 1e-12:
            continue
        k = int(peak_indices[i])
        j_start = max(0, k - n + 1)
        j_end = min(n - 1, k)
        if j_start <= j_end:
            idx = np.arange(j_start, j_end + 1)
            g[idx] += w[i] * a[k - idx]
    return g, M, conv

def adam_optimize(a0, time_limit, lr_init=0.03, n_peaks=30, seed=0, 
                  verbose=False, verbose_every=500):
    """Adam subgradient with adaptive restarts and spectral reshaping."""
    n = len(a0)
    a = norm_simplex(a0)
    conv = fast_convolve(a)
    best_obj = 2.0 * n * conv.max()
    best_a = a.copy()
    
    rng = np.random.default_rng(seed)
    m_v = np.zeros(n)
    v_v = np.zeros(n)
    t_count = 0
    beta1, beta2, eps = 0.8, 0.999, 1e-8
    lr = lr_init
    
    t0 = time.monotonic()
    it = 0
    no_improve = 0
    
    while time.monotonic() - t0 < time_limit:
        g, M, conv = compute_subgradient(a, n_peaks)
        t_count += 1
        m_v = beta1 * m_v + (1 - beta1) * g
        v_v = beta2 * v_v + (1 - beta2) * (g * g)
        m_hat = m_v / (1 - beta1 ** t_count)
        v_hat = v_v / (1 - beta2 ** t_count)
        update = m_hat / (np.sqrt(v_hat) + eps)
        a = np.maximum(a - lr * update, 0.0)
        s = a.sum()
        if s > 1e-15:
            a /= s
        else:
            a = best_a.copy()
            m_v = np.zeros(n)
            v_v = np.zeros(n)
            t_count = 0
        
        conv = fast_convolve(a)
        cur_obj = 2.0 * n * conv.max()
        if cur_obj < best_obj - 1e-12:
            best_obj = cur_obj
            best_a = a.copy()
            no_improve = 0
        else:
            no_improve += 1
        
        # Adaptive strategies
        if no_improve > 200:
            lr *= 0.5
            no_improve = 0
        if no_improve > 500:
            # Spectral reshaping: reduce peaks in power spectrum
            fft_size = 1 << (2 * n - 1).bit_length()
            A = np.fft.rfft(a, fft_size)
            power = np.abs(A) ** 2
            mean_p = power.mean()
            # Soft-cap the power
            cap = mean_p * 2.0
            power_capped = np.minimum(power, cap)
            # Blend
            power_new = 0.7 * power + 0.3 * power_capped
            phase = np.angle(A)
            new_A = np.sqrt(power_new) * np.exp(1j * phase)
            a_new = np.fft.irfft(new_A, fft_size)[:n]
            a_new = np.maximum(a_new, 0.0)
            s = a_new.sum()
            if s > 1e-15:
                a = a_new / s
            else:
                a = best_a.copy()
            m_v = np.zeros(n)
            v_v = np.zeros(n)
            t_count = 0
            lr = lr_init * 0.3
            no_improve = 0
        if no_improve > 1200:
            # Full restart with noise
            noise = rng.standard_normal(n) * 0.003
            a = norm_simplex(best_a + noise)
            m_v = np.zeros(n)
            v_v = np.zeros(n)
            t_count = 0
            lr = lr_init * 0.5
            no_improve = 0
        
        lr = max(lr * 0.9999, 1e-5)
        it += 1
        if verbose and it % verbose_every == 0:
            elapsed = time.monotonic() - t0
            print(f"    Adam it={it}, obj={best_obj:.6f}, lr={lr:.2e}, T={elapsed:.0f}s")
    
    return best_a, best_obj

def generate_inits(n, parent, rng):
    """Generate diverse asymmetric initializations."""
    inits = {}
    x = np.arange(n, dtype=np.float64)
    
    # Exponential decay from left
    for r in [0.90, 0.93, 0.95, 0.97, 0.98, 0.99]:
        a = r ** x
        inits[f'expL_{r}'] = norm_simplex(a)
    
    # Exponential decay from right  
    for r in [0.90, 0.93, 0.95, 0.97, 0.98, 0.99]:
        a = r ** (n - 1 - x)
        inits[f'expR_{r}'] = norm_simplex(a)
    
    # Bimodal: two bumps
    for frac in [0.2, 0.3, 0.4]:
        for width in [0.1, 0.15, 0.2]:
            c1 = frac
            c2 = 1.0 - frac
            s1 = width * n
            s2 = width * n
            b1 = np.exp(-0.5 * ((x - c1 * n) / s1) ** 2)
            b2 = np.exp(-0.5 * ((x - c2 * n) / s2) ** 2)
            inits[f'bimodal_{frac}_{width}'] = norm_simplex(b1 + b2)
    
    # Cosine modulated
    for freq in [1, 2, 3, 5]:
        for alpha in [0.3, 0.5, 0.7, 0.9]:
            a = 1.0 + alpha * np.cos(2 * np.pi * freq * x / n)
            a = np.maximum(a, 0)
            if a.sum() > 1e-10:
                inits[f'cos_{freq}_{alpha}'] = norm_simplex(a)
    
    # Super cosinusoid (squared cosine)
    for freq in [1, 2, 3]:
        for alpha in [0.5, 0.8, 1.0]:
            a = (1.0 + alpha * np.cos(2 * np.pi * freq * x / n)) ** 2
            inits[f'scos_{freq}_{alpha}'] = norm_simplex(np.maximum(a, 0))
    
    # Power law decay
    for p in [0.5, 1.0, 2.0, 3.0]:
        a = (x + 1.0) ** (-p)
        inits[f'pow_{p}'] = norm_simplex(a)
        inits[f'powR_{p}'] = norm_simplex(a[::-1])
    
    # Hanning window shifted
    for shift_frac in [0.0, 0.2, 0.3, 0.5]:
        c = shift_frac * n + 0.5 * (n - 1)
        a = 0.5 * (1 + np.cos(2 * np.pi * (x - c + 0.5 * n) / n))
        a = np.maximum(a, 0)
        if a.sum() > 1e-10:
            inits[f'hann_{shift_frac}'] = norm_simplex(a)
    
    # Ramp
    a = x + 1.0
    inits['ramp'] = norm_simplex(a)
    inits['rampR'] = norm_simplex(a[::-1])
    
    # Triangle (peak at various positions)
    for peak_pos in [0.2, 0.3, 0.5, 0.7, 0.8]:
        c = peak_pos * (n - 1)
        tri = 1.0 - np.abs(x - c) / (n * 0.8)
        inits[f'tri_{peak_pos}'] = norm_simplex(np.maximum(tri, 0))
    
    # Random
    inits['rand1'] = norm_simplex(rng.random(n))
    inits['rand2'] = norm_simplex(rng.random(n) ** 2)
    inits['rand3'] = norm_simplex(rng.dirichlet(np.ones(n) * 0.5))
    
    # Sparse random
    for sparsity in [0.3, 0.5, 0.7]:
        mask = rng.random(n) > sparsity
        a = np.where(mask, rng.random(n), 0.0)
        if a.sum() > 1e-10:
            inits[f'sparse_{sparsity}'] = norm_simplex(a)
    
    # Parent
    if parent is not None and len(parent) > 0:
        if len(parent) == n:
            pp = np.clip(parent, 0, 1000).astype(np.float64)
            if pp.sum() > 1e-10:
                inits['parent'] = pp / pp.sum()
        else:
            pp = np.interp(np.linspace(0, 1, n), np.linspace(0, 1, len(parent)), np.clip(parent, 0, 1000))
            if pp.sum() > 1e-10:
                inits['parent_interp'] = pp / pp.sum()
    
    return inits

**Theoretical lower bound analysis:**

We want to minimize `2n * max_k c[k]` subject to `sum a = 1, a >= 0`.

We know `sum_k c[k] = 1`, so `avg c[k] = 1/(2n-1)`.
Thus `max c[k] >= 1/(2n-1)`, giving `obj >= 2n/(2n-1) ≈ 1`.

Can we achieve this? We'd need `c[k] = 1/(2n-1)` for all k. This means `ifft(|FFT(a,N)|^2)` is constant, so `|FFT(a,N)|^2` has only one non-zero bin, so `a` is constant. But constant gives triangular c, not flat. So the bound is not achievable.

What's the actual minimum? This is related to the theory of "minimum peak factor" sequences or "caisson" sequences.

- We want `c[k]` to be as flat as possible
- `c[0] = a[0]^2` (energy of first element)
- `c[2n-2] = a[n-1]^2` (energy of last element)
- `c[n-1] = sum_j a[j]*a[n-1-j]` (center, reversal correlation)
- `c[1] = 2*a[0]*a[1]`
- `c[2n-3] = 2*a[n-1]*a[n-2]`

To make c flat, we need:
- a[0]^2 ≈ c_flat, so a[0] ≈ sqrt(c_flat)
- a[n-1]^2 ≈ c_flat
- 2*a[0]*a[1] ≈ c_flat, so a[1] ≈ c_flat/(2*sqrt(c_flat)) = sqrt(c_flat)/2
- In general, a[j] should be such that the convolution is flat

This is essentially the "perfect autocorrelation" problem. For non-negative sequences, it's known to be impossible to have perfectly flat autocorrelation (for any length). The best we can do is minimize the deviation.

"""
Multi-strategy Adam subgradient optimization for minimizing 2*n*max(conv(a,a))/(sum(a))^2.
Uses diverse asymmetric initializations, adaptive Adam with spectral reshaping,
multi-peak tracking, and perturbation restarts. Key insight: optimal sequences are
asymmetric, exploiting the cross-correlation structure to achieve peaks below 1/n.
"""

import numpy as np
import time


def fast_convolve(a, b=None):
    """Linear convolution via FFT."""
    if b is None:
        b = a
    n = len(a)
    m = len(b)
    size = n + m - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    B = np.fft.rfft(b, fft_size)
    return np.fft.irfft(A * B, fft_size)[:size]


def local_obj(a):
    """Compute 2*n*max(conv(a,a))/(sum(a))^2."""
    n = len(a)
    s = a.sum()
    if s < 1e-15:
        return np.inf
    conv = fast_convolve(a)
    return 2.0 * n * conv.max() / (s * s)


def norm_simplex(a):
    """Project to non-negative simplex (sum=1)."""
    a = np.maximum(a.astype(np.float64), 0.0)
    s = a.sum()
    if s < 1e-15:
        return np.ones(len(a), dtype=np.float64) / len(a)
    return a / s


def compute_subgradient(a, n_peaks=30, sharpness=0.15):
    """Compute softmax-weighted subgradient of max(conv(a,a))."""
    n = len(a)
    conv = fast_convolve(a)
    M = conv.max()
    top_k = min(n_peaks, 2 * n - 1)
    peak_indices = np.argsort(conv)[-top_k:]
    peak_vals = conv[peak_indices]
    spread = max(peak_vals.max() - peak_vals.min(), 1e-15)
    w = np.exp((peak_vals - peak_vals.max()) / (spread * sharpness))
    w /= w.sum()
    g = np.zeros(n)
    for i in range(len(peak_indices)):
        if w[i] < 1e-12:
            continue
        k = int(peak_indices[i])
        j_start = max(0, k - n + 1)
        j_end = min(n - 1, k)
        if j_start <= j_end:
            idx = np.arange(j_start, j_end + 1)
            g[idx] += w[i] * a[k - idx]
    return g, M, conv


def adam_optimize(a0, time_limit, lr_init=0.03, n_peaks=30, seed=0,
                  verbose=False, verbose_every=500):
    """Adam subgradient with adaptive restarts and spectral reshaping."""
    n = len(a0)
    a = norm_simplex(a0)
    conv = fast_convolve(a)
    best_obj = 2.0 * n * conv.max()
    best_a = a.copy()

    rng = np.random.default_rng(seed)
    m_v = np.zeros(n)
    v_v = np.zeros(n)
    t_count = 0
    beta1, beta2, eps = 0.8, 0.999, 1e-8
    lr = lr_init

    t0 = time.monotonic()
    it = 0
    no_improve = 0

    while time.monotonic() - t0 < time_limit:
        g, M, conv = compute_subgradient(a, n_peaks)
        t_count += 1
        m_v = beta1 * m_v + (1.0 - beta1) * g
        v_v = beta2 * v_v + (1.0 - beta2) * (g * g)
        m_hat = m_v / (1.0 - beta1 ** t_count)
        v_hat = v_v / (1.0 - beta2 ** t_count)
        update = m_hat / (np.sqrt(v_hat) + eps)
        a = np.maximum(a - lr * update, 0.0)
        s = a.sum()
        if s > 1e-15:
            a /= s
        else:
            a = best_a.copy()
            m_v = np.zeros(n)
            v_v = np.zeros(n)
            t_count = 0

        conv = fast_convolve(a)
        cur_obj = 2.0 * n * conv.max()
        if cur_obj < best_obj - 1e-13:
            best_obj = cur_obj
            best_a = a.copy()
            no_improve = 0
        else:
            no_improve += 1

        # Adaptive strategies
        if no_improve == 150:
            lr *= 0.6
            no_improve = 0
        elif no_improve == 400:
            # Spectral reshaping
            fft_size = 1 << (2 * n - 1).bit_length()
            A = np.fft.rfft(a, fft_size)
            power = np.abs(A) ** 2
            mean_p = power.mean()
            cap = mean_p * 1.8
            power_capped = np.minimum(power, cap)
            power_new = 0.5 * power + 0.5 * power_capped
            phase = np.angle(A)
            new_A = np.sqrt(np.maximum(power_new, 0)) * np.exp(1j * phase)
            a_new = np.fft.irfft(new_A, fft_size)[:n]
            a_new = np.maximum(a_new, 0.0)
            s = a_new.sum()
            if s > 1e-15:
                a = a_new / s
            else:
                a = best_a.copy()
            m_v = np.zeros(n)
            v_v = np.zeros(n)
            t_count = 0
            lr = lr_init * 0.4
            no_improve = 0
        elif no_improve == 1000:
            # Noisy restart from best
            noise = rng.standard_normal(n) * 0.003
            a = norm_simplex(best_a + noise)
            m_v = np.zeros(n)
            v_v = np.zeros(n)
            t_count = 0
            lr = lr_init * 0.5
            no_improve = 0

        lr = max(lr * 0.99995, 1e-5)
        it += 1
        if verbose and it % verbose_every == 0:
            elapsed = time.monotonic() - t0
            print(f"    Adam it={it}, obj={best_obj:.6f}, lr={lr:.2e}, elapsed={elapsed:.0f}s")

    return best_a, best_obj


def lp_based_polish(a0, time_limit, verbose=False):
    """LP-based Frank-Wolfe step (one LP solve per iteration, quick)."""
    from scipy.optimize import linprog
    from scipy.sparse import coo_matrix

    n = len(a0)
    a = norm_simplex(a0)
    conv = fast_convolve(a)
    M = conv.max()
    best_obj = 2.0 * n * M
    best_a = a.copy()

    t0 = time.monotonic()
    it = 0
    no_improve = 0

    while time.monotonic() - t0 < time_limit:
        # Build constraint matrix: A @ b <= M for all k
        rows = []
        cols = []
        vals = []
        for k in range(2 * n - 1):
            j_start = max(0, k - n + 1)
            j_end = min(n - 1, k)
            for j in range(j_start, j_end + 1):
                rows.append(k)
                cols.append(j)
                vals.append(a[k - j])

        A_mat = coo_matrix((vals, (rows, cols)), shape=(2 * n - 1, n)).tocsr()
        c_obj = -np.ones(n)
        b_ub = np.full(2 * n - 1, M)
        bounds = [(0.0, None)] * n

        res = linprog(c_obj, A_ub=A_mat, b_ub=b_ub, bounds=bounds,
                      method='highs', options={'presolve': True, 'time_limit': 3.0, 'dual_feasibility_tolerance': 1e-7})
        if not res.success:
            break

        b = np.maximum(res.x, 0.0)
        sb = b.sum()
        if sb < 1e-15:
            break
        b = b / sb

        # Line search
        best_t = 0.0
        best_candidate_obj = best_obj
        for t in [0.1, 0.3, 0.5, 0.7, 0.9]:
            candidate = (1.0 - t) * a + t * b
            c = fast_convolve(candidate)
            obj = 2.0 * n * c.max()
            if obj < best_candidate_obj:
                best_candidate_obj = obj
                best_t = t

        if best_t < 0.05:
            no_improve += 1
        else:
            a = (1.0 - best_t) * a + best_t * b
            conv = fast_convolve(a)
            M = conv.max()
            if M < best_obj / (2.0 * n) - 1e-13:
                best_obj = 2.0 * n * M
                best_a = a.copy()
                no_improve = 0
            else:
                no_improve += 1

        if no_improve > 30:
            break

        it += 1
        if verbose and it % 20 == 0:
            elapsed = time.monotonic() - t0
            print(f"    LP it={it}, obj={best_obj:.6f}, elapsed={elapsed:.0f}s")

    return best_a, best_obj


def generate_inits(n, parent, rng):
    """Generate diverse asymmetric initializations."""
    inits = {}
    x = np.arange(n, dtype=np.float64)

    # Exponential decays (asymmetric - key for beating 2.0)
    for r in [0.90, 0.93, 0.95, 0.97, 0.98, 0.99]:
        inits[f'expL_{r}'] = norm_simplex(r ** x)
        inits[f'expR_{r}'] = norm_simplex(r ** (n - 1 - x))

    # Power law decays
    for p in [0.5, 1.0, 1.5, 2.0, 3.0]:
        inits[f'pow_{p}'] = norm_simplex((x + 1.0) ** (-p))
        inits[f'powR_{p}'] = norm_simplex((x + 1.0) ** (-p))[::-1]

    # Cosine modulated (asymmetric via phase)
    for freq in [1, 2, 3]:
        for alpha in [0.3, 0.5, 0.7, 0.9]:
            a = 1.0 + alpha * np.cos(2.0 * np.pi * freq * x / n + np.pi * 0.3)
            a = np.maximum(a, 0)
            if a.sum() > 1e-10:
                inits[f'cos_{freq}_{alpha}'] = norm_simplex(a)

    # Squared cosine
    for freq in [1, 2, 3]:
        for alpha in [0.5, 0.8, 1.0]:
            a = (1.0 + alpha * np.cos(2.0 * np.pi * freq * x / n)) ** 2
            inits[f'scos_{freq}_{alpha}'] = norm_simplex(np.maximum(a, 0))

    # Bimodal
    for frac in [0.15, 0.25, 0.35, 0.45]:
        for width in [0.08, 0.12, 0.2]:
            c1 = frac
            c2 = 1.0 - frac * 0.5
            s1 = width * n
            s2 = width * n * 1.5
            b1 = np.exp(-0.5 * ((x - c1 * n) / s1) ** 2)
            b2 = np.exp(-0.5 * ((x - c2 * n) / s2) ** 2)
            inits[f'bim_{frac}_{width}'] = norm_simplex(b1 + 0.5 * b2)

    # Ramp
    a = x + 1.0
    inits['ramp'] = norm_simplex(a)
    inits['rampR'] = norm_simplex(a[::-1])

    # Logsine
    a = np.sin(np.pi * (x + 0.5) / n) + 0.3
    inits['logsine'] = norm_simplex(a)
    inits['logsineR'] = norm_simplex(a[::-1])

    # Triangle at various positions
    for peak_pos in [0.2, 0.3, 0.5, 0.7, 0.8]:
        c = peak_pos * (n - 1)
        tri = 1.0 - np.abs(x - c) / (0.7 * n)
        inits[f'tri_{peak_pos}'] = norm_simplex(np.maximum(tri, 0))

    # Random
    inits['rand1'] = norm_simplex(rng.random(n))
    inits['rand2'] = norm_simplex(rng.random(n) ** 3)
    inits['rand3'] = norm_simplex(rng.dirichlet(np.ones(n) * 0.3))

    # Sparse
    for sp in [0.3, 0.5, 0.7]:
        mask = rng.random(n) > sp
        a = np.where(mask, rng.random(n), 0.0)
        if a.sum() > 1e-10:
            inits[f'sparse_{sp}'] = norm_simplex(a)

    # Parent
    if parent is not None and len(parent) > 0:
        if len(parent) == n:
            pp = np.clip(parent, 0, 1000).astype(np.float64)
            if pp.sum() > 1e-10:
                inits['parent'] = pp / pp.sum()
        else:
            pp = np.interp(np.linspace(0, 1, n), np.linspace(0, 1, len(parent)),
                           np.clip(parent, 0, 1000))
            if pp.sum() > 1e-10:
                inits['parent_interp'] = pp / pp.sum()

    return inits
