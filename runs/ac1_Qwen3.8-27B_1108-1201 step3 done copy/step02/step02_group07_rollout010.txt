If i = k-i (k = 2i): it's one term: a[i]*a[i] = a[i]^2
  Derivative w.r.t. a[i]: 2*a[i]

If k-i < 0 or k-i >= n: neither term exists, derivative is 0.

  2*a[k-i] if 0 <= k-i < n and k ≠ 2i
  2*a[i] if k = 2i (and 0 <= i < n, which is always true)
  0 otherwise

Note that when k = 2i, we also have k-i = i which is in range, so the formula "2*a[k-i] if 0 <= k-i < n" would give 2*a[i], which is the same. So we can simplify:

d(conv[k])/d(a[i]) = 2*a[k-i] if 0 <= k-i < n, else 0.

Great, so the gradient of the max convolution value M(a) = max_k conv[k] w.r.t. a[i] is:
If the max is achieved at a unique k*, then ∇M = 2 * a[k*-i] (for valid k*-i).
If the max is achieved at multiple k*, we take a subgradient: the average (or any convex combination) of 2*a[k*-i] for each active k*.

The score is 2n*M/S^2 where S = sum(a). The gradient of the score w.r.t. a[i] is:
∂(score)/∂a[i] = 2n * (S^2 * ∂M/∂a[i] - M * 2S * 1) / S^4
= 2n * (S * ∂M/∂a[i] - 2M) / S^3

So to minimize the score, we want to move a[i] in the direction -∂(score)/∂a[i].

This gives us a proper gradient (when M is differentiable, i.e., unique max) or subgradient.

For the LP approach, the dual variables give us the "weights" on the active constraints, which is exactly the subgradient information.
