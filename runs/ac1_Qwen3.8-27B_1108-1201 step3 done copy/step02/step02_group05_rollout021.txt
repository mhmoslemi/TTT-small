Let me try a different angle. What if I use **CVXPY** to solve the problem more directly?

The problem:
```
minimize t
subject to sum(a) == 1
a >= 0
quad_form(a, B_k) <= t for all k
```

Since `B_k` is indefinite, this is non-convex. CVXPY won't accept it directly. But we can use the following trick:

For each `k`, decompose `B_k = B_k^+ - B_k^-` where `B_k^+` and `B_k^-` are PSD. Then `a^T B_k a = a^T B_k^+ a - a^T B_k^- a`. The constraint `a^T B_k^+ a - a^T B_k^- a <= t` is still non-convex.

Alternatively, we can use the **Dinkelbach's algorithm** or **parametric approach**:
- For a given `t`, check feasibility: is there `a >= 0, sum(a)=1` such that `a^T B_k a <= t` for all `k`?
- This is still non-convex.

Let me also think about a specific technique that might help: **element-wise optimization**.

Given the current sequence `a`, the objective is `2n * max_k conv(a,a)[k]`. If I change a single element `a[j]` to `a[j] + δ` (and adjust another element to maintain sum=1), how does the objective change?

`conv(a,a)[k]` changes by:
- For lag `k`: the terms involving `a[j]` are `a[j]*a[k-j]` and `a[k-j]*a[j]` (if valid). So the change is `2*δ*a[k-j]` (if `k-j` is valid and `k-j ≠ j`), or `2*δ*a[j] + δ^2` (if `k-j = j`).

This is linear in `δ` (plus a small quadratic term). So for a single-element change, the change in the peak is approximately:
`Δmax ≈ max_k (2*δ*a[k-j])` (for the lags where `a[k-j]` contributes).

To minimize the peak, we want to choose `δ` and `j` such that this is minimized. This gives us a greedy local search:
- For each `j`, compute the "damage" of increasing `a[j]` by `δ`: it's `2*δ * max_k a[k-j]` (approximately).
- Choose the `j` with the smallest damage and increase it slightly.
- To maintain sum=1, decrease another element.

This is essentially the local search from the parent, but with a more principled choice of which elements to swap.

import numpy as np
import time
import scipy.optimize

def fast_convolve(a):
    n = len(a)
    size = 2 * n - 1
    fft_size = 1 << (size - 1).bit_length()
    A = np.fft.rfft(a, fft_size)
    return np.fft.irfft(A * A, fft_size)[:size]

def obj(a):
    """Objective assuming sum(a) = 1."""
    n = len(a)
    return 2.0 * n * fast_convolve(a).max()

def normalize(a):
    a = np.maximum(a, 0.0)
    s = a.sum()
    if s < 1e-11:
        return np.ones(len(a)) / len(a)
    return a / s

def compute_subgradient(a, k):
    """Compute gradient of conv(a,a)[k] w.r.t. a."""
    n = len(a)
    grad = np.zeros(n)
    for j in range(n):
        kj = k - j
        if 0 <= kj < n:
            grad[j] = 2.0 * a[kj]
    return grad

def gradient_descent_step(a, step_size, active_lags):
    """Take a gradient descent step using subgradients of active lags."""
    n = len(a)
    g = np.zeros(n)
    for k in active_lags:
        g += compute_subgradient(a, k)
    g /= len(active_lags)
    # Center the gradient (to maintain sum constraint approximately)
    g -= g.mean()
    a_new = a - step_size * g
    return normalize(a_new)

def local_search_swaps(a, n_swaps=100):
    """Try random pairwise swaps to reduce the objective."""
    n = len(a)
    best_obj = obj(a)
    best_a = a.copy()
    rng = np.random.default_rng()
    
    for _ in range(n_swaps):
        i = rng.integers(n)
        j = rng.integers(n)
        if i == j:
            continue
        for frac in [0.1, 0.3, 0.5]:
            amount = frac * min(a[i], a[j])
            if amount < 1e-12:
                continue
            a_trial = a.copy()
            a_trial[i] -= amount
            a_trial[j] += amount
            a_trial = normalize(a_trial)
            o = obj(a_trial)
            if o < best_obj - 1e-10:
                best_obj = o
                best_a = a_trial
                a = a_trial  # Continue from the improved point
                break
    return best_a, best_obj

def lp_step(f, M, time_limit):
    """LP-based direction finding."""
    n = len(f)
    # Build constraint matrix: conv(f, g)[k] <= M for all k
    # conv(f, g)[k] = sum_i f[i] * g[k-i]
    # For each k, the coefficients of g[j] are f[k-j] (for valid j)
    A = np.zeros((2*n-1, n))
    for j in range(n):
        # g[j] appears in conv[f,g][k] for k = j, j+1, ..., j+(n-1)
        # with coefficient f[k-j]
        for k in range(j, j+n):
            A[k, j] = f[k-j]
    
    c = -np.ones(n)
    b = np.full(2*n-1, M)
    bounds = [(0.0, None)] * n
    
    try:
        res = scipy.optimize.linprog(c, A_ub=A, b_ub=b, bounds=bounds, method='highs', options={'presolve': True, 'dual_feasibility_tolerance': 1e-9})
        if res.success:
            g = np.maximum(res.x, 0.0)
            s = g.sum()
            if s > 1e-12:
                return g / s
    except Exception:
        pass
    return f.copy()

def line_search(f, g, max_iter=30):
    """Line search for f_new = (1-t)*f + t*g."""
    best_t = 0.0
    best_obj = obj(f)
    lo, hi = 0.0, 1.0
    gr = (np.sqrt(5.0) - 1.0) / 2.0
    c = hi - gr * (hi - lo)
    d = lo + gr * (hi - lo)
    fc = obj((1-c)*f + c*g)
    fd = obj((1-d)*f + d*g)
    for _ in range(max_iter):
        if fc < fd:
            hi = d
            d = c
            fd = fc
            c = hi - gr * (hi - lo)
            fc = obj(np.maximum((1-c)*f + c*g, 0) / np.maximum((1-c)*f + c*g, 0).sum())
        else:
            lo = c
            c = d
            fc = fd
            d = lo + gr * (hi - lo)
            fd = obj(np.maximum((1-d)*f + d*g, 0) / np.maximum((1-d)*f + d*g, 0).sum())
    t = (lo + hi) / 2.0
    a_new = np.maximum((1-t)*f + t*g, 0)
    s = a_new.sum()
    if s < 1e-12:
        return f, best_obj
    a_new /= s
    return a_new, obj(a_new)
