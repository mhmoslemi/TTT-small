Identify the current optimum and try variations:

- Scalar perturbation: s = t * s_base, where t is 1.15 or 0.75.
- Additive noise: s += n * noise, n being standard normally distributed.
- Block Gaussian perturbation: Apply limited in-width Gaussian perturbations.
- Cyclic reflection: Force a mirrored perturbation.
- Random deletion/removal: Remove about 5% of coefficients randomly and then upscale.

3.3. Evaluate and Update
In each iteration, generate a candidate sequence using one of the above methods, evaluate it, and update the best sequence if applicable.

4. Search choices and variations

- **Gaussian parameters**: Use a standard deviation of 0.2 for robust exploration.
- **Block width**: For scalable block perturbations, use a random block width between 5 and 20.
