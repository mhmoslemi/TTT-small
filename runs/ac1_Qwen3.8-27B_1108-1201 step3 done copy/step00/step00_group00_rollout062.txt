grad_c[1][j] = 2*a[1-j] for valid j. grad_c[1] = (2a[1], 2a[0], 0, ..., 0).
grad_c[k][j] = 2*a[k-j] for j=0,...,k (and j up to n-1).
grad_c[n-1][j] = 2*a[n-1-j] for j=0,...,n-1. So grad_c[n-1] = (2a[n-1], 2a[n-2], ..., 2a[0]).

The uniform subgradient of the max over {0,...,n-1}:
g[j] = (1/n) * sum_{k=0}^{n-1} grad_c[k][j] = (1/n) * sum_{k=max(0,j)}^{n-1} 2*a[k-j] (for k >= j)
     = (1/n) * 2 * sum_{k=j}^{n-1} a[k-j]
     = (2/n) * sum_{i=0}^{n-1-j} a[i]
     = (2/n) * S_{n-1-j}

where S_m = sum_{i=0}^{m} a[i] is the cumulative sum.

For the binomial sequence, a[i] = C(2i,i)/4^i ≈ 1/sqrt(pi*i) for large i.
S_m ≈ sum_{i=0}^{m} 1/sqrt(pi*i) ≈ 2*sqrt(m/pi) for large m.

So g[j] ≈ (2/n) * 2*sqrt((n-1-j)/pi) = 4*sqrt(n-1-j)/(n*sqrt(pi)).

This is a decreasing function of j. So the subgradient is large for small j (left side) and small for large j (right side).

After projection (subtracting mean): the direction d = -g + (sum(g)/n)*ones will be negative for small j and positive for large j. So we're moving mass from the left to the right.

This makes sense: we want to reduce the peak, and since the first n entries are all at the peak, we need to reduce them all. Moving mass from left to right (or vice versa) can help.

But wait, if we move mass from left to right, c[0] = a[0]^2 decreases (good), but c[n-1-j] for small j might increase (bad).

The LP approach handles this more carefully by considering all constraints simultaneously.

"""
Minimizes 2*n*max(convolve(a,a))/sum(a)^2 using binomial sequence initialization
and LP-based active set reduction. The binomial sequence C(2i,i)/4^i has a
perfectly flat auto-convolution for the infinite case, giving a strong starting
point near pi/2 ≈ 1.5708. The LP active set method then reduces the peak
by exploiting slack in the non-active convolution entries.
"""

import numpy as np
import time
from scipy.optimize import linprog

def _binomial_sequence(n):
    """Generate normalized binomial sequence a[i] = C(2i,i)/4^i."""
    a = np.empty(n, dtype=np.float64)
    a[0] = 1.0
    for i in range(1, n):
        a[i] = a[i - 1] * (2.0 * i - 1.0) / (2.0 * i)
    return a / a.sum()


def _convolve(a):
    """Compute full linear convolution of a with itself using FFT."""
    n = len(a)
    size = 1
    while size < 2 * n - 1:
        size <<= 1
    A = np.fft.rfft(a, size)
    C = np.fft.irfft(A * A, size)[:2 * n - 1]
    return C


def _solve_lp_direction(a, active_k):
    """Solve LP to find direction d minimizing max increase of active c[k].
    Returns (direction, delta) or (None, 0)."""
    n = len(a)
    m = len(active_k)
    
    # A_ub @ x <= b_ub, where x = [d_0,...,d_{n-1}, delta]
    # For each k: sum_j 2*a[k-j]*d_j + delta <= 0
    A_ub = np.zeros((m, n + 1), dtype=np.float64)
    for idx in range(m):
        k = active_k[idx]
        j_lo = max(0, k - (n - 1))
        j_hi = min(n - 1, k)
        if j_hi >= j_lo:
            js = np.arange(j_lo, j_hi + 1)
            A_ub[idx, js] = 2.0 * a[k - js]
        A_ub[idx, n] = 1.0
    
    b_ub = np.zeros(m)
    
    # Equality: sum(d) = 0
    A_eq = np.zeros((1, n + 1))
    A_eq[0, :n] = 1.0
    b_eq = np.array([0.0])
    
    # Minimize -delta (i.e., maximize delta)
    c_obj = np.zeros(n + 1)
    c_obj[n] = -1.0
    
    try:
        res = linprog(c_obj, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq,
                      method='highs', options={'presolve': True})
        if res.success and res.x[n] > 1e-12:
            return res.x[:n], res.x[n]
    except Exception:
        pass
    return None, 0.0

    Uses binomial init + LP active set + line search.
    """

    best_score = np.inf
    best_seq = None
    rng = np.random.default_rng(seed)
    
    n_values = [1000, 2000, 3000]
    max_active = 150
    
    for n in n_values:
        if time.monotonic() > deadline - 20:
            break
        
        a = _binomial_sequence(n)
        # Small perturbation to help with symmetry breaking
        a += rng.random(n) * 1e-6
        a = np.maximum(a, 0)
        a /= a.sum()
        
        t_n_start = time.monotonic()
        time_budget_n = min(500.0, deadline - t_n_start - 20.0)
        
        no_improve_count = 0
        prev_score = np.inf
        
        for it in range(10000):
            if time.monotonic() > t_n_start + time_budget_n:
                break
            if time.monotonic() > deadline - 10:
                break
            
            c = _convolve(a)
            M = c.max()
            score = 2.0 * n * M
            
            if score < best_score - 1e-10:
                best_score = score
                best_seq = a.copy()
                no_improve_count = 0
                if it % 200 == 0:
                    print(f"n={n} iter={it} score={score:.8f} M={M:.8f}")
            else:

            # Active set: top entries
            thresh = M * 0.999
            active = np.where(c >= thresh)[0]

                vals = c[active]
                top = np.argsort(vals)[-max_active:]
                active = active[top]
            
            # Solve LP
            d, delta = _solve_lp_direction(a
