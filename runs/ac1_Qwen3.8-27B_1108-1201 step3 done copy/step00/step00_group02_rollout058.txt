Since the parent sequence is likely non-uniform (it achieved J=2.0 which is the same as uniform, but might have a different shape), let me start with it and add some randomness.

Actually, J=2.0 is the value for ANY sequence where the peak of the autocorrelation equals the average times (2n-1)/n... no wait.

For uniform: max C = n*c², S = n*c, J = 2n*n*c²/(n*c)² = 2.

For a general sequence: J = 2n*max(C)/S². For J = 2, we need max(C) = S²/n.

So the parent sequence has max(C) = S²/n, which is exactly the Cauchy-Schwarz bound. This means the parent is "close to uniform" in some sense.

To improve, we need max(C) < S²/n. This requires the sequence to NOT be uniform - it needs structure that makes the autocorrelation peak lower than the "average" value implied by Cauchy-Schwarz.

This is exactly the problem of finding sequences with low peak autocorrelation!

Let me think about what kind of perturbation would help. If I take a uniform sequence and add a small perturbation that reduces the peak:

a = c * (1 + ε * p) where p has zero mean.

C[k] = c² * sum_j (1+εp[j])(1+εp[k-j])
= c² * (n - |k|) + c²ε * (sum_{valid j} p[j] + p[k-j]) + O(ε²)

The peak at k=0 (or near center) is approximately c²*n + c²ε * (sum_j p[j] + sum_j p[j]) = c²*n + 2c²ε*sum(p) = c²*n (since sum p = 0).

Hmm, so to first order, the peak doesn't change. We need second-order effects.

At second order:
C[center] = c² * (n + ε * 2*sum(p) + ε² * sum(p²)) ≈ c² * (n + ε² * sum(p²))

So the peak INCREASES to second order! This makes sense - by the variance, the peak is pushed up.

But other peaks might decrease. Let's look at C[k] for k ≠ 0:
C[k] ≈ c² * (n-k) + c²ε * sum_{valid} p[j] + p[k-j] + O(ε²)

If p is chosen to cancel the linear term at the problematic peaks, we might reduce the overall max.

This is exactly what the LP approach does! It finds a direction p that minimizes the maximum of the perturbed autocorrelation.

OK so let me think about a practical algorithm:

1. Start with a sequence (parent or random).
2. At each iteration:
   a. Compute C = convolve(a, a).
   b. Find the "worst" peaks (top few values in C).
   c. Find a perturbation direction p (zero mean, a + εp >= 0) that reduces the worst peaks.
   d. Take a step in that direction.
3. Repeat.

For step (c), a simple approach is:
- For each worst peak at position k, the "problematic" positions are those i where a[i] contributes to C[k] (i.e., a[i] * a[k-i] is large).
- Reduce those positions and increase positions that don't contribute to any worst peak.

This is essentially a "water-filling" or "balancing" approach.

Actually, let me think about this problem from a higher level. The key challenge is:
1. The objective is non-smooth (max of many functions).
2. The feasible set is a[0] (non-negative, normalized).
3. The landscape has many local minima.

For (1), subgradient methods work but are slow.
For (3), we need good initialization and possibly multiple restarts.

Let me try a different approach: **iterative thresholding / projection**.

The idea:
1. Start with a random non-negative sequence.
2. Compute C = convolve(a, a).
3. Identify the "excess" peaks (values above some threshold).
4. Reduce a at positions that contribute to these peaks.
5. Renormalize.
6. Repeat.

This is similar to the "Eigenvalue Power Iteration" but for autocorrelation.

Actually, here's another idea inspired by the "BFGS" or "Newton" method for non-smooth problems:

**Active Set LP Method** (simplified from the paper):
1. At each iteration, identify the top K peaks in C.
2. Solve: min max_{k in top K} (a + εd)[k] - C[k]  (linearize the convolution)
   s.t. a + εd >= 0, sum(d) = 0
3. Take a step.

The linearization: (a+εd) * (a+εd) ≈ a*a + ε*(a*d + d*a)
So C_new[k] ≈ C[k] + ε * (sum_j a[j]*d[k-j] + d[j]*a[k-j]) = C[k] + ε * (a*d_conv)[k]

Where d_conv = convolve(a, d) + convolve(d, a) = 2*convolve(a, d) (by symmetry of convolution for real signals... wait no, convolve(a,d) and convolve(d,a) are the same for real signals since convolution is commutative).

Actually, convolve(a, d) = convolve(d, a) for real signals. So:
(a+εd)*(a+εd) ≈ a*a + 2ε * convolve(a, d)

So C_new[k] ≈ C[k] + 2ε * convolve(a, d)[k]

We want to minimize max_{k in top K} C_new[k] = C[k] + 2ε * convolve(a,d)[k]
Subject to: a[i] + ε*d[i] >= 0 for all i, sum(d) = 0.

This is a linear program! Let t be the max, then:
min t
s.t. C[k] + 2ε * convolve(a,d)[k] <= t for k in top K
     a[i] + ε*d[i] >= 0 for all i
     sum(d) = 0

We can solve this with scipy.optimize.linprog.

But the LP has n + K variables (d[0..n-1] and t) and n + K constraints. For n ~ 7000 and K ~ 100, that's ~7100 variables and ~7100 constraints. This might be solvable with a good LP solver.

Let me check: scipy.optimize.linprog with method='highs' (or the older 'interior-point' or 'simplex') should handle this.

The constraint matrix would be:
- For each k in top K: sum_{j} 2ε * a[k-j]_valid * d[j] - t <= -C[k]
  (i.e., 2ε * (a*d_conv)[k] - t <= -C[k])
- For each i: -d[i] <= a[i]/ε (i.e., a[i] + ε*d[i] >= 0)
- sum(d) = 0

The (a*d_conv)[k] = sum_j a[j] * d[k-j] (with valid indexing).

So the constraint for peak k is:
sum_j 2ε * a[j] * d[k-j]_valid - t <= -C[k]

The coefficient of d[j] in this constraint is 2ε * (a[j-(k-j)]... 

Wait, let me be more careful. convolve(a, d)[k] = sum_j a[j] * d[k-j].

So the coefficient of d[m] in convolve(a, d)[k] is a[k-m] (if 0 <= k-m < n, else 0).

So the constraint for peak k is:
sum_m 2ε * a[k-m]_valid * d[m] - t <= -C[k]

where a[k-m]_valid = a[k-m] if 0 <= k-m < n, else 0.

This is a linear constraint in (d, t).

The constraint matrix A has rows for each peak k and each non-negativity constraint i:
- Row for peak k: [2ε*a[k-0], 2ε*a[k-1], ..., 2ε*a[k-(n-1)], -1] (length n+1, with zeros where k-m >= n or k-m < 0)
- Row for non-neg i: [-e_i / ε] (where e_i is the unit vector)
- Equality: sum(d) = 0, i.e., [1, 1, ..., 1, 0] * [d; t] = 0

The size is (K + n) constraints by (n+1) variables. For n=7000, K=100: 7100 x 7001 matrix.

This should be manageable with a sparse LP solver.

Let me implement this:

```python
import scipy.optimize as opt
import scipy.sparse as sp

def lp_step(a, C, top_K, eps, n):
    """Solve the LP to find the best direction d."""
    # Variables: d[0..n-1], t
    # Objective: minimize t
    c_obj = np.zeros(n + 1)
    c_obj[-1] = 1.0  # minimize t
    
    # Inequality constraints: A_ub @ x <= b_ub
    # For each peak k: sum_m 2*eps*a[k-m]_valid * d[m] - t <= -C[k]
    # For each i: -d[i] <= a[i]/eps
    
    # Build sparse matrix
    rows = []
    cols = []
    vals = []
    b_ub = []
    
    for k in top_K_indices:
        for m in range(n):
            jm = k - m
            if 0 <= jm < n:
                rows.append(len(b_ub))
                cols.append(m)
                vals.append(2.0 * eps * a[jm])
        # -t
        rows.append(len(b_ub))
        cols.append(n)
        vals.append(-1.0)
        b_ub.append(-C[k])
    
    for i in range(n):
        rows.append(len(b_ub))
        cols.append(i)
        vals.append(-1.0)
        b_ub.append(a[i] / eps)
    
    A_ub = sp.coo_matrix((vals, (rows, cols)), shape=(len(b_ub), n+1))
    
    # Equality: sum(d) = 0
    A_eq = np.zeros((1, n+1))
    A_eq[0, :n] = 1.0
    b_eq = np.array([0.0])
    
    result = opt.linprog(c_obj, A_ub=A_ub, A_eq=A_eq, b_ub=b_ub, b_eq=b_eq, method='highs')
    
    if result.success:
        d = result.x[:n]
        return d
    return None
```

import numpy as np
import time
import scipy.optimize as opt
import scipy.sparse as sp

def compute_convolution(a):
    """Compute full convolution using FFT for efficiency."""
    n = len(a)
    N = 1
    while N < 2*n - 1:
        N *= 2
    fa = np.fft.rfft(a, N)
    fc = fa * fa
    result = np.fft.irfft(fc, N)
    return result[:2*n-1]

def lp_direction(a, C, peak_indices, n):
    """Solve LP to find descent direction."""
    c_obj = np.zeros(n + 1)
    c_obj[-1] = 1.0
    
    rows = []
    cols = []
    vals = []
    b_ub = []
    
    # Peak constraints: 2 * convolve(a, d)[k] - t <= -C[k]
    # convolve(a, d)[k] = sum_m a[k-m] * d[m] (valid terms)
    for k in peak_indices:
        row_idx = len(b_ub)
        for m in range(n):
            jm = k - m
            if 0 <= jm < n:
                rows.append(row_idx)
                cols.append(m)
                vals.append(2.0 * a[jm])
        rows.append(row_idx)
        cols.append(n)
        vals.append(-1.0)
        b_ub.append(-C[k])
    
    # Non-negativity: -d[i] <= a[i]
    for i in range(n):
        rows.append(len(b_ub))
        cols.append(i)
        vals.append(-1.0)
        b_ub.append(a[i])
    
    A_ub = sp.coo_matrix((vals, (rows, cols)), shape=(len(b_ub), n+1)).tocsr()
    
    A_eq = sp.lil_matrix((1, n+1))
    A_eq[0, :n] = 1.0
    A_eq = A_eq.tocsr()
    b_eq = np.array([0.0])
    
    result = opt.linprog(c_obj, A_ub=A_ub, A_eq=A_eq, b_ub=b_ub, b_eq=b_eq, 
                         method='highs', options={'presolve': True, 'time_limit': 30})
    
    if result.success:
        return result.x[:n]
    return None
