If |S| = 1 (in continuous terms) and total length is 2, then:
h*(1-h) at lag k = 1 - |S ∩ (S+k)|

So C₅ = max_k (1 - |S ∩ (S+k)|) * dx... no wait.

Actually: ∫ h(x)(1-h(x+k)) dx = ∫ h(x)dx - ∫ h(x)h(x+k) dx = 1 - |S ∩ (S+k)| (for characteristic functions)

So C₅ = max_k (1 - |S ∩ (S+k)|)

To minimize this, we want to maximize the minimum of |S ∩ (S+k)| over all k. For a set of measure 1 in [0,2], what's the best we can do?

If S = [0,1], then |S ∩ (S+k)| = 1-|k| for |k|<1, = 0 for |k|≥1.
So max_k (1-|S∩(S+k)|) = 1 (at k=1). That gives C₅ = 1. Bad.

If S is something more "spread out", like S = [0, 0.5] ∪ [1, 1.5], then:
At k=0: |S∩S| = 1, so 1-1 = 0
At k=0.5: S ∩ (S+0.5) = [0,0.5]∩[0.5,1] ∪ [1,1.5]∩[1.5,2] = ∅, so 1-0 = 1. Bad.

Hmm, for characteristic functions it's hard to do well. That's why the optimal h is not 0-1 but has intermediate values.

    h = np.array(h, dtype=float).copy()
    h = np.clip(h, 0.0, 1.0)
    target = n / 2.0
    for _ in range(80):
        diff = target - np.sum(h)
        if abs(diff) < 1e-14:

        mask = (h > 1e-10) & (h < 1.0 - 1e-10)
        cnt = np.sum(mask)
        if cnt > 0:
            h[mask] += diff / cnt
        else:
            h[:] += diff / n
        h = np.clip(h, 0.0, 1.0)

def smmax_val_grad(h, n, beta):

    g = 1.0 - h
    corr = np.correlate(h, g, mode='full')
    f = corr * dx
    m = f.max()
    shifted = beta * (f - m)
    shifted_max = shifted.max()
    w = np.exp(shifted - shifted_max)
    wsum = np.sum(w)
    val = m + (shifted_max + np.log(wsum)) / beta
    
    A = g  # 1-h, length n
    B = h   # length n
    W = w   # length 2n-1
    
    corr_AW = np.correlate(A, W, mode='full')  # length 3n-2
    T1 = corr_AW[3*n-3 : 2*n-3 : -1].copy()  # length n

    h = h_init.copy()
    mu = mu_init

        if remaining_time() < 10:
            break

            x_clipped = np.clip(x, 0.0, 1.0)
            val, grad = smmax_val_grad(x_clipped, n, beta)
            penalty = mu / 2.0 * (np.sum(x_clipped) - n/2.0) ** 2
            grad_pen = mu * (np.sum(x_clipped) - n/2.0)
            total_val = val + penalty
            total_grad = grad + grad_pen
            return total_val, total_grad
        
        try:
            res = minimize(obj_grad, h, method='L-BFGS-B', jac=True,
                         bounds=[(0.0, 1.0)] * n,
                         options={'maxiter': max_iter, 'gtol': gtol, 'iprint': 0})
            h_new = project_feasible(res.x, n)
        except Exception:
