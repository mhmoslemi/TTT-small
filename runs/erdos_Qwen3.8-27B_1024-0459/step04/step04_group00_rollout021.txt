  Valid when 0 ≤ j+m-n+1 < n, i.e., n-1-j ≤ m ≤ 2n-2-j (intersection with [0, 2n-2])
  For the valid range, fp[j][m] first part = 1 - h[j+m-n+1]
  
- Second term: j-m+n-1 ranges from j+2n-2-n+1 = j+n-1 (at m=0) to j+0-n+1 = j-n+1 (at m=2n-2)
  Valid when 0 ≤ j-m+n-1 < n, i.e., m ≤ j+n-1 and m ≥ j-n+1 (intersection with [0, 2n-2])
  For the valid range, fp[j][m] second part = -h[j-m+n-1]

This is getting complex to implement efficiently. Let me just use the direct formula with numpy:

For a given h (length n) and position j:
```
# fp for position j, all lags m=0..2n-2
# lag = m - (n-1)
lags = np.arange(2*n-1) - (n-1)  # shape (2n-1,)
idx1 = j + lags  # positions for first term
idx2 = j - lags  # positions for second term
fp = np.zeros(2*n-1)
valid1 = (idx1 >= 0) & (idx1 < n)
valid2 = (idx2 >= 0) & (idx2 < n)
fp[valid1] = 1 - h[idx1[valid1]]
fp[valid2] -= h[idx2[valid2]]
```

This is O(n) per position. For a swap, we compute fp[a] and fp[b], then delta = fp[b] - fp[a], new_corr = corr + delta, new_max = max(new_corr). Total O(n).

For n=384, this is very fast. We can probably do 100K+ swaps per second.

```python
    h = np.array(h, dtype=float).copy()

    corr = compute_corr(h)
    m = np.max(corr)
    dx = 2.0 / n
    sh = corr - m
    cl = np.clip(beta * sh, -50, 50)
    ex = np.exp(cl)
    return (m + np.log(np.sum(ex)) / beta) * dx

def smooth_max_grad(h, n, beta):
    corr = compute_corr(h)
    m = np.max(corr)
    sh = corr - m
    cl = np.clip(beta * sh, -50, 50)
    ex = np.exp(cl)
    s = np.sum(ex)
    w = ex / s
    dx = 2.0 / n
    # grad of corr[k] wrt h[j]
    # corr[k] = sum_i h[i] * (1-h[i+k-(n-1)])
    g = np.zeros(n)
    for k in range(2*n-1):
        wk = w[k] * dx
        if wk < 1e-16:
            continue
        l = k - (n-1)  # lag
        if l >= 0:
            np_ = n - l
            g[l:l+np_] += wk * (1.0 - h[:np_])
            g[:np_] -= wk * h[l:l+np_]
        else:
            al = -l
            np_ = n - al
            g[:np_] += wk * (1.0 - h[al:al+np_])
            g[al:al+np_] -= wk * h[:np_]
    return g

    bounds = [(0.0, 1.0)] * n
    # Use equality constraint sum(h) = n/2

        return smooth_max_obj(x, n, beta)
    def grad(x):
        return smooth_max_grad(x, n, beta)
    def con_eq(x):
        return np.sum(x) - n/2.0
    def con_eq_jac(x):
        return np.ones(n)
    cons = [{'type': 'eq', 'fun': con_eq, 'jac': con_eq_jac}]
    try:
        res = minimize(obj, h, jac=grad, method='SLSQP',
                       bounds=bounds, constraints=cons,
                       options={'maxiter': maxiter, 'ftol': 1e-16, 'iprint': 0})
        if res.success or res.fun < obj(h):
            return project_feasible(res.x, n)
    except Exception:
        pass
    return h
```

The key question is: what's limiting the previous approach?

Looking at the previous code, it does:

But there's another issue: the SLSQP with smooth max might not be finding the true minimum. The smooth max with finite beta has a bias - it overestimates the max, so the optimizer might be slightly off.

Let me also think about a different angle: **iterative reweighting**.

Idea: Start with uniform weights on all lags. 
1. Compute corr for current h
2. Set target = max(corr)
3. For the lags achieving the max, increase their weights
4. Minimize weighted sum of corr[k] * w[k] subject to constraints
5. Repeat

This is similar to the "method of conditional expectation" or "exponential weights" approach for minimax.

Actually, the smooth max is already doing something similar (exponential weighting of the near-max lags). The issue is that SLSQP might not converge well.

Let me try a different approach: **projected gradient method with backtracking line search**.

```python
def projected_gradient(h, n, beta, lr, maxiter):
```

Hmm, but projecting after a gradient step might not work well because the gradient of the smooth max is not necessarily in the direction that reduces the actual max.

Let me think differently. The key insight is:

For the optimal solution, the top few correlations should be equalized (if there's a unique optimum). The "top shifts focus" approach in the previous code does this, but it's a heuristic.

A better approach: **Alternating Minimization / ADMM**

1. Introduce variable t (the max correlation)
2. Minimize t subject to corr[k] ≤ t for all k, sum(h) = n/2, 0 ≤ h ≤ 1
3. But corr[k] is bilinear in h, so this is non-convex

For the bilinear corr[k] = sum_i h[i](1-h[i+k]):
- If we fix h as the "first factor", corr is linear in (1-h_shifted)
- If we fix h as the "second factor", corr is linear in h

So we can do alternating:
- Fix "second factor" h[i+k], optimize h[i] (linear problem)
- Fix "first factor" h[i], optimize h[i+k] (linear problem)

But this doesn't directly work because h appears in both roles.

Actually, let me try a simpler but potentially effective approach:

**Coordinate Descent with Smart Moves**:
1. For each position j, try changing h[j] (within [0,1]) to minimize the max correlation
2. For each pair (a, b), try swapping h[a] and h[b]
3. Accept improvements

The key is to compute the effect of changing h[j] efficiently.

For a small change dh at position j:
delta_corr[m] ≈ dh * fp[j][m] (for small dh, linear approximation)

So the new max ≈ max(corr + dh * fp[j])
We want to choose dh to minimize this.

This is equivalent to: minimize max_m (corr[m] + dh * fp[j][m]) over dh.

The optimal dh is the value that equalizes the top correlations. Specifically, if corr[m*] is the current max and fp[j][m*] < 0, we should increase dh (if fh[j] is currently 0) or decrease it.

This is a 1D minimization problem for each coordinate, solvable in O(n) (find the dh that minimizes the max of n linear functions).

Let me implement this:

```python
def coordinate_descent(h, n, max_sweeps=10):
    h = h.copy()
    corr = compute_corr(h)
    cur_max = float(np.max(corr))
    dx = 2.0/n
    lags = np.arange(2*n-1) - (n-1)
    
    for sweep in range(max_sweeps):
        improved = False
        for j in range(n):
            # Compute fp[j]
            idx1 = j + lags
            idx2 = j - lags
            fp = np.zeros(2*n-1)
            v1 = (idx1 >= 0) & (idx1 < n)
            v2 = (idx2 >= 0) & (idx2 < n)
            fp[v1] = 1.0 - h[idx1[v1]]
            fp[v2] -= h[idx2[v2]]
            
            # Minimize max_m (corr[m] + (h[j]+dh - h[j]) * fp[m])
            # = max_m (corr[m] + dh * fp[m])
            # over dh in [-h[j], 1-h[j]]
            
            # The function f(dh) = max_m (corr[m] + dh*fp[m])
            # is piecewise linear. We want to minimize it over dh in [lo, hi].
            lo = -h[j]
            hi = 1.0 - h[j]
            
            # Find the minimum: try the "breakpoints" where two lines cross
            # f(dh) = max(corr + dh*fp)
            # At dh=0: f = max(corr) = cur_max
            # The slope at 0 from the right is fp[argmax(corr)] (approximately)
            
            # Simple approach: ternary search or evaluate at a few points
            # Since f is convex (max of linear functions), we can do:
            # Find where f is minimized
            
            # Evaluate at endpoints and at the "optimal" dh
            # Optimal dh: the value where the two "tightest" constraints are equal
            # corr[m1] + dh*fp[m1] = corr[m2] + dh*fp[m2]
            # dh = (corr[m2] - corr[m1]) / (fp[m1] - fp[m2])
            
            # Quick approach: evaluate at a few candidate dh values
            candidates = [0.0]
            if fp[np.argmax(corr)] < 0:
                candidates.append(hi)  # increase h[j]
            elif fp[np.argmax(corr)] > 0:
                candidates.append(lo)  # decrease h[j]
            
            # Also try the breakpoint
            # Find top 2 correlations
            top2 = np.argsort(-corr)[:2]
            if len(top2) >= 2:
                m1, m2 = top2[0], top2[1]
                denom = fp[m1] - fp[m2]
                if abs(denom) > 1e-10:
                    dh_star = (corr[m2] - corr[m1]) / denom
                    if lo < dh_star < hi:
                        candidates.append(dh_star)
            
            # Evaluate
            best_dh = 0.0
            best_f = cur_max
            for dh in candidates:
                if dh < lo - 1e-10 or dh > hi + 1e-10:
                    continue
                dh = np.clip(dh, lo, hi)
                new_max = float(np.max(corr + dh * fp))
                if new_max < best_f:
                    best_f = new_max
                    best_dh = dh
            
            if best_dh != 0.0:
                h[j] += best_dh
                h[j] = np.clip(h[j], 0, 1)
                corr = compute_corr(h)  # Recompute (expensive but necessary for accuracy)
                cur_max = float(np.max(corr))
                improved = True
        
        if not improved:
            break
    
    return h, cur_max * dx
```

Wait, but recomputing the full correlation after each coordinate step is O(n²) or O(n log n). With n=384 and 384 coordinates, that's 384 * O(n log n) per sweep ≈ 384 * 384 * 9 ≈ 1.3M operations per sweep. That's fast.

But we can do better: update corr incrementally. When h[j] changes by dh, corr changes by dh * fp[j]. So:
new_corr = corr + dh * fp[j]

This is O(n) per coordinate update. Total per sweep: O(n²). For n=384: ~147K operations per sweep. Very fast.

Let me refine the coordinate descent to use incremental updates:

```python
            v1 = (idx1 >= 0) & (idx1 < n)
            v2 = (idx2 >= 0) & (idx2 < n)
            fp[v1] = 1.0 - h[idx1[v1]]
            fp[v2] -= h[idx2[v2]]
            
            lo = -h[j]
            hi = 1.0 - h[j]
            if hi - lo < 1e-12:
                continue
            
            # Find best dh
            candidates = [0.0, lo, hi, hi/2, lo/2]
            # Add breakpoints from top correlations
            top_mask = corr > cur_max - 1.0  # near-max correlations
            top_idx = np.where(top_mask)[0]
            for m in top_idx[:5]:  # top 5 near-max
                if abs(fp[m]) > 1e-10:
                    # dh that makes corr[m] + dh*fp[m] = cur_max
                    dh_eq = (cur_max - corr[m]) / fp[m]
                    if lo < dh_eq < hi:
                        candidates.append(dh_eq)
            
            best_dh = 0.0
            best_f = float(np.max(corr))  # current max (dh=0)
            for dh in candidates:
                dh = np.clip(dh, lo, hi)
                new_max = float(np.max(corr + dh * fp))
                if new_max < best_f - 1e-12:
                    best_f = new_max
                    best_dh = dh
            
            if best_dh != 0.0:
                h[j] += best_dh
                h[j] = np.clip(h[j], 0, 1)
                corr += best_dh * fp
                cur_max = best_f
                improved = True
        
        if not improved:
            break
    
    # Project to maintain sum constraint
    h = project_feasible(h, n)
    corr = compute_corr(h)
    return h, float(np.max(corr)) * dx
```

This is O(n * (n + |near-max|)) per sweep ≈ O(n²) per sweep. For n=384, that's ~150K per sweep. We can do many sweeps.

The issue is that this is a LOCAL method - it finds a local minimum. To escape, we need:
1. Random perturbations
2. Multiple starting points
3. Simulated annealing (accept some bad moves)

```python
import numpy as np
from scipy.optimize import minimize
import time

_T0 = 0.0
_BUDGET = 1300.0

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def compute_corr(h):
    return np.correlate(h, 1.0 - h, mode='full')

def project_feasible(h, n):
    h = np.array(h, dtype=float).copy()
    h = np.clip(h, 0.0, 1.0)
    target = n / 2.0
    for _ in range(100):
        diff = target - np.sum(h)
        if abs(diff) < 1e-13:
            break
        mask = (h > 1e-12) & (h < 1.0 - 1e-12)
        cnt = np.count_nonzero(mask)
        if cnt > 0:
            h[mask] += diff / cnt
        else:
            h[:] += diff / n
        h = np.clip(h, 0.0, 1.0)
    return h

def remaining():
    return max(0.0, _BUDGET - (time.time() - _T0) - 2.0)

def _sm_obj(h, n, beta):
    corr = compute_corr(h)
    m = np.max(corr)
    dx = 2.0 / n
    sh = corr - m
    cl = np.clip(beta * sh, -50.0, 50.0)
    ex = np.exp(cl)
    return (m + np.log(np.sum(ex)) / beta) * dx

def _sm_grad(h, n, beta):
    corr = compute_corr(h)
    m = np.max(corr)
    sh = corr - m
    cl = np.clip(beta * sh, -50.0, 50.0)
    ex = np.exp(cl)
    s = np.sum(ex)
    w = ex / s
    dx = 2.0 / n
    g = np.zeros(n)
    for k in range(2 * n - 1):
        wk = w[k] * dx
        if wk < 1e-16:
            continue
        l = k - (n - 1)
        if l >= 0:
            np_ = n - l
            g[l:l + np_] += wk * (1.0 - h[:np_])
            g[:np_] -= wk * h[l:l + np_]
        else:
            al = -l
            np_ = n - al
            g[:np_] += wk * (1.0 - h[al:al + np_])
            g[al:al + np_] -= wk * h[:np_]
    return g

def slsqp_optimize(h, n, beta, maxiter=400):
    h0 = project_feasible(h, n)
    bounds = [(0.0, 1.0)] * n
    def obj(x):
        return _sm_obj(x, n, beta)
    def grad(x):
        return _sm_grad(x, n, beta)
    def con_eq(x):
        return np.sum(x) - n / 2.0
    def con_eq_jac(x):
        return np.ones(n)
    cons = [{'type': 'eq', 'fun': con_eq, 'jac': con_eq_jac}]
    try:
        res = minimize(obj, h0, jac=grad, method='SLSQP',
                       bounds=bounds, constraints=cons,
                       options={'maxiter': maxiter, 'ftol': 1e-16, 'iprint': 0})
        if res.fun < obj(h0) - 1e-14:
            return project_feasible(res.x, n)
    except Exception:
        pass
    return h0

def fp_vector(j, h, n, lags):
    idx1 = j + lags
    idx2 = j - lags
    fp = np.zeros(2 * n - 1)
    v1 = (idx1 >= 0) & (idx1 < n)
    v2 = (idx2 >= 0) & (idx2 < n)
    fp[v1] = 1.0 - h[idx1[v1]]
    fp[v2] -= h[idx2[v2]]
    return fp

def coord_sa(h_init, n, time_limit=60, rng=None, T0=0.5, T1=0.005):

    best_max = cur_max

def binary_fast_search(h_bin, n, time_limit=60, rng=None, T0=2.0, T1=0.02):
    if rng is None:
        rng = np.random.RandomState(42)
    h = (h_bin > 0.5).astype(float).copy()
    n_half = n // 2
    n_ones = int(np.sum(h))
    if n_ones != n_half:

            rem = rng.choice(ones_idx, n_ones - n_half, replace=False)
            h[rem] = 0
        else:
            zeros_idx = np.where(h == 0)[0]
            add = rng.choice(zeros_idx, n_half - n_ones, replace=False)

    cur_max = float(np.max(corr))
    best_corr = corr.copy()
    best_max = cur_max
    best_h = h.copy()

    lags = np.arange(2 * n - 1) - (n - 1)
    start_time = time.time()
    it = 0
    stall = 0

        it += 1
        T = max(T1, T0 * (T1 / T0) ** (it / max(20000, 1)))

        ones = np.where(h == 1)[0]

        if len(ones) == 0 or len(zeros) == 0:
            break

        best_a = -1
        best_b = -1

        if best_delta <= 0:
            accept = True
        elif T > 0.01 and rng.rand() < np.exp(-best_delta / T):
            accept = True

        if accept:
            h[best_a] = 0.0
            h[best_b] = 1.0
            corr += best_delta_vec
            cur_max += best_delta
            if cur_max < -1e-9:
                cur_max = 0.0
            stall = 0
            if cur_max < best_max:

                best_h = h.copy()
                best_corr = corr.copy()

def interp_to(src_h, src_n, dst_n):
    if src_n == dst_n:
        return src_h.copy()
    xp = (np.arange(src_n) + 0.5) * 2.0 / src_n
    x_new = (np.arange(dst_n) + 0.5) * 2.0 / dst_n
    return np.interp(x_new, xp, src_h)

def targeted_sweep(h, n, max_sweeps=30):
    """Coordinate descent that targets the max-correlation lag."""
    h = h.copy()
    corr = compute_corr(h).copy()
    cur_max = float(np.max(corr))
    dx = 2.0 / n
    lags = np.arange(2 * n - 1) - (n - 1)

    for sweep in range(max_sweeps):
        if remaining() < 3:
            break
        k_star = int(np.argmax(corr))
        fp_k = np.zeros(n)
        # fp[j] value at lag k_star: how much h[j] affects corr[k_star]
        l = k_star - (n - 1)
        if l >= 0:
            np_ = n - l
            fp_k[l:l + np_] += (1.0 - h[:np_])
            fp_k[:np_] -= h[l:l + np_]
        else:
            al = -l
            np_ = n - al
            fp_k[:np_] += (1.0 - h[al:al + np_])
            fp_k[al:al + np_] -= h[:np_]

        # For each j, the derivative of corr[k_star] wrt h[j] is fp_k[j]
        # We want to reduce corr[k_star], so move h[j] in direction -sign(fp_k[j])
        # But we must maintain sum constraint and [0,1] bounds
        improved_any = False
        for j in range(n):
            if abs(fp_k[j]) < 1e-10:
                continue
            lo = -h[j]
            hi = 1.0 - h[j]
            if hi - lo < 1e-12:
                continue

            fp = fp_vector(j, h, n, lags)
            # Try to reduce max: binary search on dh
            best_dh = 0.0
            best_f = cur_max
            # Try moving in direction that reduces corr[k_star]
            if fp_k[j] > 0:
                steps = [hi, hi * 0.7, hi * 0.4, hi * 0.15, hi * 0.05]
            else:
                steps = [lo, lo * 0.7, lo * 0.4, lo * 0.15, lo * 0.05]

            for dh in steps:
                dh_c = np.clip(dh, lo, hi)
                nm = float(np.max(corr + dh_c * fp))
                if nm < best_f - 1e-13:
                    best_f = nm
                    best_dh = dh_c

            if best_dh != 0.0:
                h[j] = np.clip(h[j] + best_dh, 0.0, 1.0)
                corr += best_dh * fp
                cur_max = best_f
                improved_any = True
                # Recompute fp_k if needed
                if l >= 0:
                    np_ = n - l
                    fp_k[l:l + np_] += (1.0 - h[:np_])
                    fp_k[l:l + np_] -= (1.0 - h[:np_])  # reset
                    fp_k[:np_] -= h[l:l + np_]
                    fp_k[:np_] += h[l:l + np_]  # reset
                    # Actually just recompute
                    fp_k = np.zeros(n)
                    fp_k[l:l + np_] += (1.0 - h[:np_])
                    fp_k[:np_] -= h[l:l + np_]
                else:
                    al = -l
                    np_ = n - al
                    fp_k = np.zeros(n)
                    fp_k[:np_] += (1.0 - h[al:al + np_])
                    fp_k[al:al + np_] -= h[:np_]

        if not improved_any:
            break

    h = project_feasible(h, n)
    corr = compute_corr(h)
    return h, float(np.max(corr)) * dx

                                   rng=np.random.RandomState(seed + n_t), T0=0.3, T1=0.002)
            if c5_cs < c5_opt:
                c5_opt = c5_cs
                h_opt = h_cs

        # Binary search at this resolution
        if remaining() > 20:
            h_bin_t = np.where(h_opt > 0.5, 1.0, 0.0)
            n_ones_t = int(np.sum(h_bin_t))
            if n_ones_t != n_t // 2:
                sort_idx_t = np.argsort(-h_opt)
                h_bin_t = np.zeros(n_t)
                h_bin_t[sort_idx_t[:n_t // 2]] = 1.0
            bs_t = min(40, max(5, int(remaining() * 0.1)))
            h_bt, c5_bt = binary_fast_search(h_bin_t, n_t, time_limit=bs_t,
                                             rng=np.random.RandomState(seed + n_t + 100))
            if remaining() > 8:
                h_bt = slsqp_optimize(h_bt, n_t, 8000, maxiter=200)
                c5_bt = compute_c5(h_bt)
            if c5_bt < c5_opt:
                c5_opt = c5_bt
                h_opt = h_bt

        if c5_opt < best_c5:
            best_c5 = c5_opt
            best_h = h_opt.copy()
            best_n = n_t
            h = h_opt.copy()

    # Phase 6: Final intensive refinement at best resolution
    n = best_n
    h = best_h.copy()

    for beta in [10000, 25000, 50000]:
        if remaining() < 5:
            break
        h_new = slsqp_optimize(h, n, beta, maxiter=400)
        c5_new = compute_c5(h_new)
        if c5_new < best_c5:
            best_c5 = c5_new
            best_h = h_new.copy()
            h = h_new.copy()

    # Final targeted sweep
    if remaining() > 10:
        h_ts2, c5_ts2 = targeted_sweep(h, n, max_sweeps=50)
        if c5_ts2 < best_c5:
            best_c5 = c5_ts2
            best_h = h_ts2.copy()
            h = h_ts2.copy()

    # Final coord SA
    if remaining() > 15:
        cs_t = min(60, max(5, int(remaining() * 0.2)))
        h_cs2, c5_cs2 = coord_sa(h, n, time_limit=cs_t,
                                 rng=np.random.RandomState(seed + 999), T0=0.2, T1=0.001)
        if c5_cs2 < best_c5:
            best_c5 = c5_cs2
            best_h = h_cs2.copy()

    # Final binary nudge
    if remaining() > 15:
        h_bin_f = np.where(best_h > 0.5, 1.0, 0.0)
        n_ones_f = int(np.sum(h_bin_f))
        if n_ones_f != n // 2:
            sort_idx_f = np.argsort(-best_h)
            h_bin_f = np.zeros(n)
            h_bin_f[sort_idx_f[:n // 2]] = 1.0
        bf_t = min(40, max(5, int(remaining() * 0.2)))
        h_bf, c5_bf = binary_fast_search(h_bin_f, n, time_limit=bf_t,
                                         rng=np.random.RandomState(seed + 2000))
        if remaining() > 5:
            h_bf = slsqp_optimize(h_bf, n, 20000, maxiter=200)
            c5_bf = compute_c5(h_bf)
        if c5_bf < best_c5:
            best_c5 = c5_bf
            best_h = h_bf.copy()

    # Final high-beta polish
    if remaining() > 5:
        h_new = slsqp_optimize(best_h, best_n, 50000, maxiter=200)
        c5_new = compute_c5(h_new)
        if c5_new < best_c5:
            best_c5 = c5_new
            best_h = h_new.copy()

    # Ensure feasibility
    best_h = project_feasible(best_h, best_n)
    final_c5 = compute_c5(best_h)
    if final_c5 < best_c5:
        best_c5 = final_c5

    # Validate with provided function
    try:
        eval_c5 = evaluate_erdos_solution(best_h)
        if eval_c5 < best_c5:
            best_c5 = eval_c5
    except Exception:
        pass

    return (best_h, best_c5, best_n)
```
