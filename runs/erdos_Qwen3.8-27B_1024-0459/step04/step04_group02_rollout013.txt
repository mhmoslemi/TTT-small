For the binary local search, here's a more efficient approach:

To improve: find a swap (p, q) such that after the swap, max_k O'(k) < max_k O(k).

Key observation: if the current max is M, we only need to fix the lags where O(k) = M. If we can reduce these without increasing any other O(k) to M or above, we're good.

Algorithm:
1. Compute O(k) for all k
2. Let M = max O(k), and A = {k : O(k) = M} (active set)
3. For each p where h[p]=1:
   a. Compute A_p = the change vector if h[p] goes to 0
   b. For the active lags in A, check if O(k) + A_p(k) < M (i.e., A_p(k) < 0 for all k in A)
   c. If so, find q where h[q]=0 such that for all k: O(k) + A_p(k) + A_q(k) ≤ M-1
4. Accept the best such swap

This is still O(n² * n) in worst case, but with pruning it should be much faster.

When h[p] goes 1→0 and h[q] goes 0→1:

- The term h[i]*(1-h[i+L]) at i=p-L (so i+L=p): was h[p-L]*(1-1)=0, now h[p-L]*(1-0)=h[p-L]. Delta = +h[p-L] [if 0≤p-L<n]

Let me also think about the coordinate descent more carefully. For coordinate i:
- All other h[j] are fixed
- The objective as a function of t = h[i] is: max_k (base_k + a_k * t + b_k * t²) * dx
  where b_k = -1 if k=0 (the self term), 0 otherwise
  a_k depends on neighbors of i
  base_k = O(k) - contribution of current h[i] to O(k)

This is a max of linear/quadratic functions, which is convex in t! So we can find the exact minimizer.

The exact minimizer of max_k (a_k * t + b_k * t² + c_k) for t ∈ [0,1]:
- This is a convex optimization in 1D
- Can be solved by bisection on the subgradient, or by checking the "breakpoints" where the argmax changes

The breakpoints occur where two functions are equal: a_k*t + b_k*t² + c_k = a_l*t + b_l*t² + c_l.
With b_k ∈ {0, -1}, these are either linear or quadratic equations in t.

For the case b_k=0 and b_l=0: linear equation, one breakpoint
For b_k=0 and b_l=-1: quadratic, up to 2 breakpoints
For b_k=-1 and b_l=-1: linear, one breakpoint

So there are O(n) breakpoints for O(n) functions. We can find them all in O(n log n) and then check the minimum in each interval.

This gives an exact 1D minimization! The coordinate descent would then converge very fast.

def coord_exact_minimize(h, n, i):

    dx = 2.0 / n
    # For each lag L (index k = L + n - 1 in np.correlate output):
    # O(L) = sum_{valid j} h[j] * (1 - h[j+L])
    # The terms involving h[i] = t:
    #   j = i: t * (1 - h[i+L]) if valid
    #   j+L = i, j = i-L: h[i-L] * (1-t) if valid
    # So O(L) = base_L + t*(1-h[i+L])_valid + h[i-L]_valid*(1-t)
    #         = base_L + t*(1-h[i+L])_valid - h[i-L]_valid*t + h[i-L]_valid
    #         = (base_L + h[i-L]_valid) + t*((1-h[i+L])_valid - h[i-L]_valid)
    # For L=0: O(0) = sum j h[j](1-h[j]), the term with j=i is t(1-t)
    #   So O(0) = base_0 + t(1-t) = base_0 + t - t²
    #   This has a t² term!
    
    # So the objective is max over L of:
    #   L=0: c0 + t - t²  (concave quadratic)
    #   L≠0: cL + aL*t  (linear)
    
    # The max of a concave quadratic and linear functions is... not necessarily convex!
    # Wait, max of convex functions is convex. But t-t² is concave, not convex.
    # So the max is NOT convex in general.
    
    # However, for the L=0 term: t(1-t) ≤ 1/4, and for the L≠0 terms, they're linear.
    # The L=0 term only matters if it's the max, which happens when all linear terms
    # are below t(1-t).
    
    # For practical purposes, let's just do a fine grid search + golden section.
    # Or: evaluate at many points and take the min.
    
    ncorr = 2 * n - 1
    a = np.zeros(ncorr)  # coefficient of t
    c = np.zeros(ncorr)  # constant term
    b = np.zeros(ncorr)  # coefficient of t² (only for L=0)

        if L == 0:
            b[k] = -1.0
            a[k] = 1.0
            # c[0] = O(0) - h[i](1-h[i]) = O(0) - h[i] + h[i]²
        else:
            # Term j=i: t*(1-h[i+L]) if 0 ≤ i+L < n
            if 0 <= i + L < n:
                a[k] += (1.0 - h[i + L])
            # Term j=i-L: h[i-L]*(1-t) if 0 ≤ i-L < n
            if 0 <= i - L < n:
                a[k] += (-h[i - L])
                c[k] += h[i - L]
        if L == 0:
            c[k] += h[i] - h[i]**2  # subtract h[i](1-h[i]) from O(0)
    
    # Actually, let me recompute. O(k) for the full correlation:
    # O[k] = sum_{valid i} h[i] * (1-h[i+L]) where L = k-(n-1)
    # The terms involving h[i_current] (let's call it index 'idx'):
    #   As h[j] where j=idx: h[idx]*(1-h[idx+L]) if idx+L in [0,n)
    #   As (1-h[j+L]) where j+L=idx, j=idx-L: h[idx-L]*(1-h[idx]) if idx-L in [0,n)
    # So contribution to O[k] from h[idx]:
    #   (1-h[idx+L])*h[idx] + h[idx-L]*(1-h[idx]) = h[idx] - h[idx]*h[idx+L] + h[idx-L] - h[idx]*h[idx-L]
    #   = h[idx] + h[idx-L] - h[idx]*(h[idx+L] + h[idx-L])
    
    # Let me just compute directly:
    # O[k] = sum_{j valid} h[j]*(1-h[j+L])
    # Write h[j] = t if j==idx, else fixed
    # = sum_{j≠idx, valid} h[j]*(1-h[j+L]) + [t*(1-h[idx+L]) if idx+L valid] + [h[idx-L]*(1-t) if idx-L valid and L≠0]
    #   + [t*(1-t) if L==0]  (the j=idx term when L=0)
    
    # Wait, when L=0, j=idx: h[idx]*(1-h[idx]) = t*(1-t)
    # When L≠0:
    #   j=idx (if idx+L in range): t*(1-h[idx+L])
    #   j=idx-L (if idx-L in range and idx != idx-L, i.e., L≠0): h[idx-L]*(1-t)
    
    # So:
    # L=0: O[0] = base0 + t*(1-t)
    # L≠0: O[L] = baseL + [t*(1-h[idx+L]) if valid] + [h[idx-L]*(1-t) if valid]

    #        = (baseL + h[idx-L]_v) + t*(1-h[idx+L])_v - t*h[idx-L]_v

def _smooth_obj_and_grad(x, n, beta):
    dx = 2.0 / n
    corr = np.correlate(x, 1.0 - x, mode='full')
    m = np.max(corr)
    shifted = np.minimum(beta * (corr - m), 0.0)
    exp_vals = np.exp(shifted)
    wsum = np.sum(exp_vals)
    weights = exp_vals / wsum
    val = (m + np.log(wsum) / beta) * dx
    grad = np.zeros(n)
    for k in range(len(corr)):
        w = weights[k]
        if w < 1e-12:
            continue
        offset = k - (n - 1)
        if offset >= 0:
            npairs = n - offset
            if npairs > 0:
                grad[offset:offset + npairs] += w * (1.0 - x[:npairs])

def binary_local_search(h_start, n, max_time_frac=0.3):
    """Binary local search: swap 1s and 0s to reduce max overlap."""
    time_limit = remaining_time() * max_time_frac
    t_start = time.time()
    
    h_bin = (h_start > 0.5).astype(float)
    # Ensure exactly n/2 ones
    ones_count = int(np.sum(h_bin))
    target = n // 2
    if ones_count > target:
        ones_idx = np.where(h_bin == 1)[0]
        to_remove = ones_idx[np.argsort(h_start[ones_idx])[:ones_count - target]]
        h_bin[to_remove] = 0
    elif ones_count < target:
        zeros_idx = np.where(h_bin == 0)[0]
        to_add = zeros_idx[np.argsort(-h_start[zeros_idx])[:target - ones_count]]
        h_bin[to_add] = 1
    
    O = np.correlate(h_bin, 1.0 - h_bin, mode='full')
    M = O.max()
    
    for sweep in range(2000):
        if time.time() - t_start > time_limit:
            break
        if remaining_time() < 5:
            break
        
        ones = np.where(h_bin == 1)[0]
        zeros = np.where(h_bin == 0)[0]
        if len(ones) == 0 or len(zeros) == 0:
            break
        
        improved = False
        M = O.max()
        
        # Try to find a swap that reduces M
        # Focus: positions p where h[p]=1 that are "bad" (contribute to high O at active lags)
        active_lags = np.where(O >= M - 0.5)[0]
        
        # For efficiency, try random swaps but biased
        n_tries = min(5000, len(ones) * len(zeros) // 10)
        rng_ls = np.random.RandomState(sweep * 13 + 7)
        
        for _ in range(n_tries):
            # Bias toward positions that affect active lags
            p = rng_ls.choice(ones)
            q = rng_ls.choice(zeros)
            if p == q:
                continue
            
            # Compute delta O for swap
            # dO[L] for L from -(n-1) to n-1:
            dO = np.zeros(2 * n - 1)
            # p goes 1->0:
            #   -(1-h[p+L]) for L where 0<=p+L<n
            #   +h[p-L] for L where 0<=p-L<n
            # q goes 0->1:
            #   +(1-h[q+L]) for L where 0<=q+L<n
            #   -h[q-L] for L where 0<=q-L<n
            
            # p contribution (1->0):
            L_range = np.arange(-(n - 1), n)
            # -(1-h[p+L]) valid when 0<=p+L<n => -p <= L <= n-1-p
            mask1 = (L_range >= -p) & (L_range <= n - 1 - p)
            if np.any(mask1):
                idx1 = L_range[mask1] + p  # = p+L for valid L
                dO[mask1] += -(1.0 - h_bin[idx1])
            # +h[p-L] valid when 0<=p-L<n => p-n+1 <= L <= p
            mask2 = (L_range >= p - n + 1) & (L_range <= p)
            if np.any(mask2):
                idx2 = p - L_range[mask2]  # = p-L for valid L
                dO[mask2] += h_bin[idx2]
            
            # q contribution (0->1):
            # +(1-h[q+L]) valid when 0<=q+L<n
            mask3 = (L_range >= -q) & (L_range <= n - 1 - q)
            if np.any(mask3):
                idx3 = L_range[mask3] + q
                dO[mask3] += (1.0 - h_bin[idx3])
            # -h[q-L] valid when 0<=q-L<n
            mask4 = (L_range >= q - n + 1) & (L_range <= q)
            if np.any(mask4):
                idx4 = q - L_range[mask4]
                dO[mask4] -= h_bin[idx4]
            
            O_new = O + dO
            M_new = O_new.max()
            
            if M_new < M - 1e-10:
                h_bin[p] = 0
                h_bin[q] = 1
                O = O_new
                M = M_new
                improved = True
                break
        
        if not improved:
            # Try a wider search: all active positions
            improved2 = False
            for p in ones[:min(len(ones), 50)]:
                if time.time() - t_start > time_limit:
                    break
                # Check if removing p helps any active lag
                dO_p = np.zeros(2 * n - 1)
                L_range = np.arange(-(n - 1), n)
                mask1 = (L_range >= -p) & (L_range <= n - 1 - p)
                if np.any(mask1):
                    dO_p[mask1] += -(1.0 - h_bin[L_range[mask1] + p])
                mask2 = (L_range >= p - n + 1) & (L_range <= p)
                if np.any(mask2):
                    dO_p[mask2] += h_bin[p - L_range[mask2]]
                
                # For this dO_p, find if any q makes max(O+dO_p+dO_q) < M
                # Simplified: just try a few random q
                for q_try in zeros[rng_ls.choice(len(zeros), min(20, len(zeros)), replace=False)]:
                    dO_q = np.zeros(2 * n - 1)
                    mask3 = (L_range >= -q_try) & (L_range <= n - 1 - q_try)
                    if np.any(mask3):
                        dO_q[mask3] += (1.0 - h_bin[L_range[mask3] + q_try])
                    mask4 = (L_range >= q_try - n + 1) & (L_range <= q_try)
                    if np.any(mask4):
                        dO_q[mask4] -= h_bin[q_try - L_range[mask4]]
                    
                    O_new = O + dO_p + dO_q
                    if O_new.max() < M - 1e-10:
                        h_bin[p] = 0
                        h_bin[q_try] = 1
                        O = O_new
                        M = O_new.max()
                        improved = True
                        improved2 = True
                        break
                if improved2:
                    break
            if not improved:
                break
    
    return h_bin, M * 2.0 / n

def subgrad_descent(h, n, max_iters=500):
    """Subgradient descent with diminishing step size."""
    best = h.copy()
    best_c5 = compute_c5(best)
    dx = 2.0 / n
    
    for it in range(max_iters):
        if remaining_time() < 3:
            break
        corr = compute_corr(best)
        max_corr = np.max(corr)
        active = np.where(corr >= max_corr - 0.01)[0]
        if len(active) > 10:
            active = active[np.argsort(corr[active])[::-1][:10]]
        
        grad = np.zeros(n)
        for k_idx in active:
            offset = int(k_idx) - (n - 1)
            if offset >= 0:
                npairs = n - offset
                if npairs > 0:
                    grad[offset:offset + npairs] += (1.0 - best[:npairs])
                    grad[:npairs] -= best[offset:offset + npairs]
            else:
                aoff = -offset
                npairs = n - aoff
                if npairs > 0:
                    grad[:npairs] += (1.0 - best[aoff:aoff + npairs])
                    grad[aoff:aoff + npairs] -= best[:npairs]
        
        gnorm = np.linalg.norm(grad)
        if gnorm < 1e-14:
            break
        
        grad /= gnorm
        base_step = 0.05 / (1.0 + 0.01 * it)
        improved = False
        for sm in [1.0, 0.5, 2.0, 0.25, 0.75, 0.1]:
            step = base_step * sm
            h_trial = best - step * grad
            h_trial = project_feasible(h_trial, n)
            c5_trial = compute_c5(h_trial)
            if c5_trial < best_c5 - 1e-16:
                best_c5 = c5_trial
                best = h_trial.copy()
                improved = True
                break
        if not improved and it % 100 == 50:
            break
    
    return best, best_c5

def run(seed=42, budget_s=1300, **kwargs):
    global _START_TIME, _BUDGET_S
    _START_TIME = time.time()
    _BUDGET_S = budget_s
    rng = np.random.RandomState(seed)
    
    best_h = None
    best_c5 = float('inf')
    best_n = 0
    
    try:
        parent_h = np.array(initial_h_values, dtype=float)
        parent_n = len(parent_h)
        parent_c5 = compute_c5(parent_h)
        best_h = parent_h.copy()
        best_c5 = parent_c5
        best_n = parent_n
    except Exception:
        best_n = 640
        h_tmp = np.zeros(best_n)
        # Thue-Morse like initialization
        for i in range(best_n):
            v = i
            cnt = 0
            while v:
                cnt ^= (v & 1)
                v >>= 1
            h_tmp[i] = 1.0 if cnt == 1 else 0.0
        best_h = project_feasible(h_tmp, best_n)
        best_c5 = compute_c5(best_h)
    
    n = best_n
    h = best_h.copy()
    
    # Phase 1: SLSQP at current resolution with increasing beta
    for beta in [500, 2000, 8000, 30000]:
        if remaining_time() < 20:
            break
        h_new = slsqp_refine(h, n, beta, 800)
        c5_new = compute_c5(h_new)
        if c5_new < compute_c5(h) - 1e-15:
            h = h_new
            if c5_new < best_c5:
                best_c5 = c5_new
                best_h = h.copy()
                best_n = n
    
    # Phase 2: Coordinate descent
    if remaining_time() > 30:
        h_cd, c5_cd = coord_descent(h, n, max_sweeps=30)
        if c5_cd < best_c5:
            best_c5 = c5_cd
            best_h = h_cd.copy()
            best_n = n
    
    # Phase 3: Binary local search
    if remaining_time() > 60:
        h_bin = (h > 0.5).astype(float)
        # Ensure correct count
        oc = int(np.sum(h_bin))
        tgt = n // 2
        if oc != tgt:
            h_bin = (h >= 0.5).astype(float)
            oc = int(np.sum(h_bin))
            if oc > tgt:
                oi = np.where(h_bin == 1)[0]
                h_bin[oi[np.argsort(h[oi])[:oc - tgt]]] = 0
            elif oc < tgt:
                zi = np.where(h_bin == 0)[0]
                h_bin[zi[np.argsort(-h[zi])[:tgt - oc]]] = 1
        
        h_bin_ls, c5_bin = binary_local_search(h, n, max_time_frac=0.25)
        if c5_bin < best_c5:
            best_c5 = c5_bin
            best_h = h_bin_ls.copy()
            best_n = n
    
    # Phase 4: Refine the binary solution continuously
    if remaining_time() > 60:
        h = best_h.copy()
        n = best_n
        for beta in [5000, 20000, 80000]:
            if remaining_time() < 15:
                break
            h_new = slsqp_refine(h, n, beta, 600)
            c5_new = compute_c5(h_new)
            if c5_new < best_c5 - 1e-15:
                h = h_new
                best_c5 = c5_new
                best_h = h.copy()
    
    # Phase 5: Coordinate descent on best
    if remaining_time() > 40:
        h_cd, c5_cd = coord_descent(best_h, best_n, max_sweeps=40)
        if c5_cd < best_c5:
            best_c5 = c5_cd
            best_h = h_cd.copy()
    
    # Phase 6: Try different resolution
    if remaining_time() > 120:
        # Try lower resolution (easier to optimize)
        n_low = max(320, best_n // 2)
        if n_low % 2 == 0:
            h_low = interp_to(best_h, best_n, n_low)
            h_low = project_feasible(h_low, n_low)
            c5_low = compute_c5(h_low)
            for beta in [2000, 10000]:
                if remaining_time() < 20:
                    break
                h_low_new = slsqp_refine(h_low, n_low, beta, 600)
                c5_low_new = compute_c5(h_low_new)
                if c5_low_new < c5_low:
                    h_low = h_low_new
                    c5_low = c5_low_new
            if c5_low < best_c5:
                best_c5 = c5_low
                # Upsample back
                best_h = interp_to(h_low, n_low, best_n)
                best_h = project_feasible(best_h, best_n)
                best_c5 = compute_c5(best_h)
        
        # Try higher resolution
        n_high = min(1280, 2 * best_n)
        if n_high % 2 == 0 and n_high > best_n:
            h_high = interp_to(best_h, best_n, n_high)
            h_high = project_feasible(h_high, n_high)
            c5_high = compute_c5(h_high)
            for beta in [1000, 5000]:
                if remaining_time() < 20:
                    break
                h_high_new = slsqp_refine(h_high, n_high, beta, 500)
                c5_high_new = compute_c5(h_high_new)
                if c5_high_new < c5_high:
                    h_high = h_high_new
                    c5_high = c5_high_new
            if c5_high < best_c5:
                best_c5 = c5_high
                best_h = h_high.copy()
                best_n = n_high
    
    # Phase 7: Another binary local search round
    if remaining_time() > 40:
        h_bin_ls, c5_bin = binary_local_search(best_h, best_n, max_time_frac=0.2)
        if c5_bin < best_c5:
            best_c5 = c5_bin
            best_h = h_bin_ls.copy()
    
    # Phase 8: Final SLSQP polish
    if remaining_time() > 15:
        h = best_h.copy()
        n = best_n
        for beta in [50000, 200000]:
            if remaining_time() < 8:
                break
            h_new = slsqp_refine(h, n, beta, 400)
            c5_new = compute_c5(h_new)
            if c5_new < best_c5:
                best_c5 = c5_new
                best_h = h_new.copy()
                h = h_new.copy()
    
    # Phase 9: Final coordinate descent
    if remaining_time() > 10:
        h_cd, c5_cd = coord_descent(best_h, best_n, max_sweeps=20)
        if c5_cd < best_c5:
            best_c5 = c5_cd
            best_h = h_cd.copy()
    
    # Phase 10: Subgradient on best
    if remaining_time() > 10:
        h_sg, c5_sg = subgrad_descent(best_h, best_n, 300)
        if c5_sg < best_c5:
            best_c5 = c5_sg
            best_h = h_sg.copy()
    
    # Final: one more micro SLSQP
    if remaining_time() > 5:
        h_new = slsqp_refine(best_h, best_n, 100000, 200)
        c5_new = compute_c5(h_new)
        if c5_new < best_c5:
            best_c5 = c5_new
            best_h = h_new.copy()
    
    best_h = project_feasible(best_h, best_n)
    final_c5 = compute_c5(best_h)
    
    try:
        eval_c5 = evaluate_erdos_solution(best_h)
        if eval_c5 < final_c5:
            final_c5 = eval_c5
    except Exception:
        pass
    
    return (best_h, final_c5, best_n)
