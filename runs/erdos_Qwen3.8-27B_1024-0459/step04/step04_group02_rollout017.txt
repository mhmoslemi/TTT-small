Actually, let me think about this problem from a different angle. The function h is on [0,2]. The integral constraint is ∫h = 1. The overlap is ∫h(x)(1-h(x+k))dx.

If we think of h as a probability of "being on" at each point, then the overlap at shift k is the probability that x is "on" and x+k is "off", integrated over valid x.

For a binary function with n/2 ones, this is just the number of (1,0) transitions at distance k, divided by (n * dx).

The key is to make this number as small as possible AND as uniform as possible (to minimize the max).

One approach: use a "disjoint" pattern where the 1s are spread out as evenly as possible. For example, if n/2 = m ones, place them at positions 0, n/m, 2*n/m, etc. (roughly). But this gives a periodic function which might have high correlation at period n/m.

Better: use a "well-spaced" set like the van der Corput sequence or a low-discrepancy sequence.

def _slsqp_obj_and_grad(x, n, beta):
    dx = 2.0 / n
    corr = np.correlate(x, 1.0 - x, mode='full')
    m = np.max(corr)
    shifted = np.minimum(beta * (corr - m), 0.0)
    exp_vals = np.exp(shifted)
    wsum = np.sum(exp_vals)
    weights = exp_vals / wsum
    val = (m + np.log(wsum) / beta) * dx

    grad = np.zeros(n)
    for k in range(len(corr)):
        w = weights[k]
        if w < 1e-14:
            continue
        offset = k - (n - 1)
        if offset >= 0:
            npairs = n - offset
            if npairs > 0:
                grad[offset:offset+npairs] += w * (1.0 - x[:npairs])
                grad[:npairs] -= w * x[offset:offset+npairs]
        else:
            aoff = -offset
            npairs = n - aoff
            if npairs > 0:
                grad[:npairs] += w * (1.0 - x[aoff:aoff+npairs])
                grad[aoff:aoff+npairs] -= w * x[:npairs]
    grad *= dx
    return val, grad

        return _slsqp_obj_and_grad(x, n, beta)[1]
    def cfun(x):
        return _slsqp_sum(x, n)
    def cjac(x):
        return np.ones(n)

    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': cfun, 'jac': cjac}]
    try:

                       bounds=bounds, constraints=cons,
