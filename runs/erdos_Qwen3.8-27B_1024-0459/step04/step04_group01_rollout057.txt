This is getting complicated with the index handling. Let me just write it more carefully.

For lag d (where d can be negative, 0, or positive):
R[d] = sum_{i: 0≤i<n, 0≤i+d<n} h[i] * (1-h[i+d])

The effect of changing h[i] from 1 to 0 on R[d]:
- If 0 ≤ i+d < n (i is the first index in a valid pair): term h[i]*(1-h[i+d]) goes from (1-h[i+d]) to 0. Change: -(1-h[i+d])
- If 0 ≤ i-d < n (i is the second index, i.e., first index is i-d): term h[i-d]*(1-h[i]) goes from 0 to h[i-d]. Change: +h[i-d]
- Both can be true simultaneously (if d=0, but R[0]=0 for binary so doesn't matter)

So: effect_1to0(i, d) = -(1-h[i+d])·[0≤i+d<n] + h[i-d]·[0≤i-d<n]

The effect of changing h[i] from 0 to 1 on R[d]:
- If 0 ≤ i+d < n: term goes from 0 to (1-h[i+d]). Change: +(1-h[i+d])
- If 0 ≤ i-d < n: term goes from h[i-d] to 0. Change: -h[i-d]

So: effect_0to1(i, d) = +(1-h[i+d])·[0≤i+d<n] - h[i-d]·[0≤i-d<n]

Note: effect_0to1(i, d) = -effect_1to0(i, d) for the SAME d? No!
effect_1to0(i, d) = -(1-h[i+d])·[valid] + h[i-d]·[valid]
effect_0to1(i, d) = +(1-h[i+d])·[valid] - h[i-d]·[valid]
Yes! They are negatives. Good.

So for a swap (a: 1→0, b: 0→1):
ΔR[d] = effect_1to0(a, d) + effect_0to1(b, d)
       = effect_1to0(a, d) - effect_1to0(b, d)

This simplifies things! ΔR[d] = effect(a, d) - effect(b, d) where effect(i, d) = effect_1to0(i, d).

Now, for a full scan of all (a, b) pairs:
ΔR[d] = E[a,d] - E[b,d] where E[i,d] = -(1-h[i+d])·[valid] + h[i-d]·[valid]

For the swap to improve the max correlation at lag d*:
R[d*] + E[a,d*] - E[b,d*] < R[d*]
⟹ E[a,d*] < E[b,d*]

And for it not to worsen other critical lags:
R[d] + E[a,d] - E[b,d] ≤ R[d] for all critical d
⟹ E[a,d] ≤ E[b,d] for all critical d

So I need to find (a,b) with h[a]=1, h[b]=0 such that E[a,d] < E[b,d] for all critical lags d.

I can precompute E[i,d] for all i and critical d, then for each pair (a,b) check the condition. This is O(n² × K) which is fast.

M_new = max_d (R[d] + E[a,d] - E[b,d])
improvement = M - M_new
