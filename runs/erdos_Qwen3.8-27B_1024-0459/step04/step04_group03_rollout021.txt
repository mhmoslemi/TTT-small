**Idea: Use the problem structure more directly.**

The correlation at lag 0 (center of the full output) is:
corr[n-1] = sum i h[i]*(1-h[i]) = n/2 - sum h[i]²

To make this small, we want sum h[i]² large → h should be binary.
But we also need other lags to be small.

For a binary sequence with n/2 ones, corr[n-1] = 0 (since h*(1-h) = 0 for binary h).
So the max must come from non-zero lags.

For binary h, corr at lag k (in the full array, index n-1+k for positive k):
= sum_{j=0}^{n-1-k} h[j+k] * (1-h[j])
= number of j where h[j+k]=1 and h[j]=0

This is the "forward mismatch count" at distance k.

To minimize max_k of this, we want the binary sequence to have low "asymmetric autocorrelation" in all directions.

This is related to the "consecutive ones" problem or "balanced sequences".

For a Thue-Morse-like sequence of period 2^m:
- It has the property that the autocorrelation is bounded by O(1) (actually, the autocorrelation of the Thue-Morse sequence is at most 1 in magnitude for the balanced version)

But we need the LINEAR autocorrelation (not circular), and we need the ASYMMETRIC count (1 at j+k, 0 at j specifically).

full[k] = sum_j h[j + l] * (1 - h[j]) for 0≤j<n and 0≤j+l<n

For l ≥ 0: full = sum_{j=0}^{n-1-l} h[j+l] * (1-h[j])
For l < 0: full = sum_{j=-l}^{n-1} h[j+l] * (1-h[j]) = sum_{j=0}^{n-1+l} h[j+|l|] * (1-h[j])

So d(full[k])/d(h[i]):
For l ≥ 0 (k ≥ n-1):
  If i is in [0, n-1-l]: contribution to h[j+l] when j+l = i, i.e., j = i-l

  If i is in [0, n-1-l]: contribution to (1-h[j]) when j = i

Wait, I need to be more careful. Let me denote the correlation at "lag" l (where l = k - (n-1)):

For l ≥ 0: C[l] = sum_{j=0}^{n-1-l} h[j+l] * (1-h[j])

dC[l]/dh[i]:
- h[i] appears as h[j+l] when j+l = i, i.e., j = i-l. This requires 0 ≤ i-l < n and 0 ≤ j < n-1-l, so 0 ≤ i-l ≤ n-1-l, i.e., l ≤ i ≤ n-1.
  Contribution: d/dh[i] of h[i]*(1-h[i-l]) = (1-h[i-l])

So: dC[l]/dh[i] = (1-h[i-l]) * 1_{l≤i≤n-1} - h[i+l] * 1_{0≤i≤n-1-l} for l ≥ 0

For l < 0 (let l' = -l > 0): C[-l'] = sum_{j=l'}^{n-1} h[j-l'] * (1-h[j])
= sum_{j=0}^{n-1-l'} h[j] * (1-h[j+l'])  [reindexing with j→j+l']

dC[-l']/dh[i]:
- h[i] appears in the first factor h[j] when j = i, requiring 0 ≤ i < n-l'.
  Contribution: (1-h[i+l'])
- h[i] appears in (1-h[j+l']) when j+l' = i, i.e., j = i-l', requiring 0 ≤ i-l' < n-l', i.e., l' ≤ i ≤ n-1.
  Contribution: -h[i-l']

So: dC[-l']/dh[i] = (1-h[i+l']) * 1_{0≤i≤n-1-l'} - h[i-l'] * 1_{l'≤i≤n-1}

Now, for the smooth max:
S = C_max + (1/β) * log(sum_k exp(β(C[k] - C_max)))

dS/dC[k] = exp(β(C[k]-C_max)) / sum_j exp(β(C[j]-C_max))

import numpy as np
from scipy.optimize import minimize
import time

_START_TIME = 0.0
_BUDGET_S = 1300.0

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def compute_corr(h):
    return np.correlate(h, 1.0 - h, mode='full')

def smooth_max(corr, beta):
    m = np.max(corr)
    shifted = beta * (corr - m)
    shifted = np.clip(shifted, -500.0, 0.0)
    return m + np.log(np.sum(np.exp(shifted))) / beta

def project_feasible(h, n):
    h = np.array(h, dtype=float).copy()
    h = np.clip(h, 0.0, 1.0)
    target = n / 2.0
    for _ in range(100):
        diff = target - np.sum(h)
        if abs(diff) < 1e-14:
            break
        mask = (h > 1e-12) & (h < 1.0 - 1e-12)
        cnt = np.sum(mask)
        if cnt > 0:
            h[mask] += diff / cnt
        else:
            h[:] += diff / n
        h = np.clip(h, 0.0, 1.0)
    diff = target - np.sum(h)
    if abs(diff) > 1e-12 and n > 1:
        order = np.argsort(np.minimum(h, 1.0 - h))[::-1]
        for idx in order:
            if abs(diff) < 1e-14:
                break
            delta = np.clip(diff, -(h[idx]), 1.0 - h[idx])
            h[idx] += delta
            diff -= delta
    return h

def remaining_time():
    return max(0.0, _BUDGET_S - (time.time() - _START_TIME) - 3.0)

def lbfgs_optim(h_init, n, beta, maxiter=400, penalty=2000):
    target = n / 2.0
    dx = 2.0 / n

    def obj(x):
        h = np.clip(x, 0.0, 1.0)
        corr = np.correlate(h, 1.0 - h, mode='full')
        sm = smooth_max(corr, beta) * dx
        pen = penalty * (np.sum(h) - target) ** 2
        return sm + pen

    try:
        res = minimize(obj, h_init, method='L-BFGS-B',
                       bounds=[(0.0, 1.0)] * n,
                       options={'maxiter': maxiter, 'ftol': 1e-18,
                                'gtol': 1e-9, 'maxfun': maxiter * 10, 'iprint': 0})
        return project_feasible(res.x, n)
    except Exception:
        return project_feasible(h_init.copy(), n)

def interp_to(src_h, src_n, dst_n):
    if src_n == dst_n:
        return src_h.copy()
    xp = (np.arange(src_n) + 0.5) * (2.0 / src_n)
    x_new = (np.arange(dst_n) + 0.5) * (2.0 / dst_n)
    return np.interp(x_new, xp, src_h)

def local_pair_search(h_in, n_in, rng, max_sweeps=12, window=35):
    h = h_in.copy()
    c5 = compute_c5(h)
    for sweep in range(max_sweeps):
        if remaining_time() < 3:
            break
        improved = False
        order = rng.permutation(n_in)
        for i in order:
            if remaining_time() < 1:
                break
            if h[i] < 0.04 or h[i] > 0.96:
                continue
            j_end = min(i + 1 + window, n_in)
            for j in range(i + 1, j_end):
                if abs(h[i] - h[j]) < 0.06:
                    continue
                for frac in [0.3, 0.5, 0.7]:
                    amt = (h[i] - h[j]) * frac
                    if abs(amt) < 0.005:
                        continue
                    h_trial = h.copy()
                    h_trial[i] -= amt
                    h_trial[j] += amt
                    h_trial = project_feasible(h_trial, n_in)
                    c5_t = compute_c5(h_trial)
                    if c5_t < c5 - 1e-12:
                        c5 = c5_t
                        h = h_trial.copy()
                        improved = True
                        break
        if not improved:
            break
    return h, c5

def parametric_init(n, rng):
    x = (np.arange(n) + 0.5) * (2.0 / n)
    K = rng.randint(2, 7)
    h = np.full(n, 0.5)
    for k in range(K):

        amp = rng.uniform(0.08, 0.35)
        phase = rng.uniform(0.0, 2.0 * np.pi)
        h += amp * np.sin(np.pi * freq * x + phase)
    h = np.clip(h, 0.0, 1.0)
    h = project_feasible(h, n)
    return h

def block_parametric_init(n, rng):
    """Initialize as sum of rectangular blocks (near-binary structure)."""
    h = np.zeros(n)
    n_blocks = rng.randint(3, min(10, n // 16))

        start = rng.randint(0, max(1, n - 10))
        width = rng.randint(5, max(6, n // n_blocks + 5))
        end = min(start + width, n)
        h[start:end] = 1.0
    h = np.clip(h, 0.0, 1.0)
    h = project_feasible(h, n)
    return h

                best_h = h_new.copy()
