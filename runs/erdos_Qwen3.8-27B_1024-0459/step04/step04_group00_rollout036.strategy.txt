2. Mathematical Specification

The optimization problem is defined as finding h: [0,2] → [0,1] minimizing:
C5 = max_k ∫ h(x)(1-h(x+k)) dx

At discrete resolution n:
- h(x_i) = h_i, x_i = i*(2/n) for i=0 to n-1
- dx = 2/n
- Objective computed via: max_k (dx * correlation(h, 1-h)[k])
- Constraints:
  0 ≤ h_i ≤ 1 for all i
  Σ h_i = n/2 (ensuring integral 1)

The repair function ensures feasibility by:
- First clipping all values to [0,1]
- Adjusting the sum through iterative redistribution
- Maintaining norm preservation to prevent constraint violation during optimization

def _repair_vector(v, n):
    v_arr = np.array(v)  # Current candidate vector
    total_needed = n/2.0 # Required integral constraint
    current_sum = np.sum(v_arr)
    
    # Iterate until target is approached within tolerance
    diff = abs(total_needed - current_sum)
    while diff > 1e-4 and attempts < 100:
        diff = total_needed - current_sum
        
        # Strength-based redistribution method
        if current_sum < total_needed:
            # Add value proportionally distributed by existing values
            v_arr += (diff * 0.1 / n)
            # Apply clipping
            v_arr = np.clip(v_arr, 0, 1)
        else:
            # Remove overflow using Manhattan distance
            remove_amount = diff * 0.1
            # Normalize direction vector
            direction = np.clip(v_arr.copy(), 0.1, None).astype(bool)
            direction = direction / max(1e-3, np.sum(direction))
            v_arr -= remove_amount * direction
            v_arr = np.clip(v_arr, 0, 1)
        
        current_sum = np.sum(v_arr)
        attempts += 1
    
    return np.clip(v_arr, 0, 1).tolist()
