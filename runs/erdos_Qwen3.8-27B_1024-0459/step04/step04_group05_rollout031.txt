Wait, I realize there's an issue with using L-BFGS-B with the penalty approach. The penalty needs to be large enough to enforce the sum constraint, but if it's too large, it dominates the objective and the optimization just tries to satisfy the sum constraint without minimizing the max correlation.

A better approach: eliminate the equality constraint. We can parameterize h as:
- h[0], h[1], ..., h[n-2] are free variables in [0,1]
- h[n-1] = n/2 - sum(h[0:n-1])

But h[n-1] might go outside [0,1], which complicates bounds.

Alternative: use a reparameterization. Let h[i] = sigmoid(t[i]) for some t[i], and choose t to satisfy the sum constraint. But this is also complex.

Actually, the simplest approach that works well in practice: use a large penalty (like 1e6) and L-BFGS-B. The penalty will keep the sum close to n/2, and the log-sum-exp term will drive down the max correlation. The key is to start from a feasible point, so the penalty just needs to keep us close.

Let me also think about whether we should use a different formulation altogether.

**Alternative: Direct min-max with bisection**

We want to find the minimum C such that there exists h with:
- For all k: corr[k] * dx ≤ C
- sum(h) = n/2
- 0 ≤ h ≤ 1

For a fixed C, this is a feasibility problem. We can try to solve it with a sequential quadratic programming approach or with a penalty method.

Actually, here's an idea: **use the fact that only a few shifts are active**.

At optimum, typically 2-5 shifts achieve the maximum. So we can:
1. Find the active set A
2. Solve: min t s.t. corr[k] ≤ t for k in A, sum(h) = n/2, 0 ≤ h ≤ 1
3. Check if any non-active k exceeds t
4. If yes, add it to A and go to step 2

For a fixed active set A, step 2 is a **quatically constrained program** (QCP). We can solve it with:
- Direct methods (if A is small, say |A| ≤ 3)
- Penalty/SQP methods

For |A| = 2 or 3, we could even use a direct approach:
- Minimize max(corr[k1], corr[k2]) subject to constraints
- This is equivalent to minimizing t s.t. corr[k1] ≤ t, corr[k2] ≤ t, ...
- With 2 or 3 quadratic constraints + linear constraints, this can be solved with-standard QP/QCP solvers

But implementing a QCP solver from scratch is complex. Let me stick with the penalty/L-BFGS-B approach but make it more robust.

**Final algorithm:**

1. Start from parent (n=256)
2. Optimize with L-BFGS-B + penalty + log-sum-exp, β from 20 to 5000
3. Try subgradient refinement (like before but with better step selection)

5. Try n=768 or n=1024
6. Final polish with active-set method

def project_feasible(h, n):
    h = np.array(h, dtype=float).copy()

    h = np.clip(h, 0.0, 1.0)
    for _ in range(100):
        diff = target - np.sum(h)
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            room = 1.0 - h
            total_room = np.sum(room)
            if total_room < 1e-14:
                break
            h += diff * room / total_room
        else:
            total_h = np.sum(h)
            if total_h < 1e-14:
                break
            h += diff * h / total_h
        h = np.clip(h, 0.0, 1.0)

For coordinate i, fixing all other coordinates, the objective becomes:
$f(h_i) = \max_k c_k(h_1, ..., h_i, ..., h_n)$

where $c_k$ is linear in $h_i$ (since the only bilinear terms involving $h_i$ are $h_i \cdot h_{i+k}$ and $h_{i-k} \cdot h_i$). So $c_k$ as a function of $h_i$ is:
$c_k = a_k \cdot h_i + b_k$ (linear!)

where $a_k = (1 - h_{i+k}) - h_{i-k}$ (for the relevant k) and $b_k = c_k - a_k \cdot h_i$ (the rest).

So the max of linear functions is a piecewise linear convex function! We can find its minimum by checking the breakpoints.

This is a great property. For each coordinate, the 1D subproblem is: minimize a piecewise linear convex function over [0,1] (with the sum constraint handled separately).

Wait, but the sum constraint couples all coordinates. So we can't just optimize each coordinate independently.

However, if we use the penalty method (penalty for sum constraint), then the 1D subproblem becomes:
minimize $f(h_i) + \lambda \cdot h_i$ (where $\lambda = 2\mu(\sum h - n/2)$ is a constant from the penalty)

This is still piecewise linear + linear = piecewise linear. We can solve it by checking all breakpoints.

But the number of breakpoints can be large (up to O(n) per coordinate). So this approach is O(n²) per full sweep, which is the same as before.

Actually, for the max of piecewise linear functions, the minimum occurs at either a breakpoint or at the boundary. We can find the minimum by:
1. Computing the value at 0 and 1
2. Finding all breakpoints in (0,1)
3. Evaluating at each breakpoint
4. Taking the minimum

The breakpoints occur where two of the linear pieces cross. With O(n) pieces, there are O(n²) potential breakpoints, but in practice few are in (0,1).

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr)) * dx

def compute_corr(h):
    return np.correlate(h, 1.0 - h, mode='full')

def project_feasible(h, n):
    h = np.array(h, dtype=float).copy()
    target = n / 2.0
    h = np.clip(h, 0.0, 1.0)
    for _ in range(100):
        diff = target - np.sum(h)
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            room = 1.0 - h
            total_room = np.sum(room)
            if total_room < 1e-14:
                break
            h += diff * room / total_room
        else:
            total_h = np.sum(h)
            if total_h < 1e-14:
                break
            h += diff * h / total_h
        h = np.clip(h, 0.0, 1.0)
    diff = target - np.sum(h)
    if abs(diff) > 1e-13:
        if diff > 0:
            idx = int(np.argmax(1.0 - h))
            h[idx] = min(1.0, h[idx] + diff)
        else:
            idx = int(np.argmax(h))
            h[idx] = max(0.0, h[idx] + diff)
    return h

def interp_to(src_h, src_n, dst_n):
    if src_n == dst_n:
        return src_h.copy()
    xp = (np.arange(src_n) + 0.5) * 2.0 / src_n
    x_new = (np.arange(dst_n) + 0.5) * 2.0 / dst_n
    return np.interp(x_new, xp, src_h)

def make_thue_morse(n):
    h = np.zeros(n)
    for i in range(n):
        h[i] = 1.0 if bin(i).count('1') % 2 == 1 else 0.0
    return project_feasible(h, n)

def make_m_sequence(n, seed_val=1):
    """Generate an m-sequence-like binary pattern."""
    h = np.zeros(n)
    state = seed_val * (1 << 7) + 1
    for i in range(n):
        h[i] = float(state % 2)
        lsb = (state ^ (state >> 1)) & 1
        state = (state >> 1) ^ (0b100100010 if lsb else 0)
        state &= (1 << 8) - 1
    return project_feasible(h, n)

def make_random_binary(rng, n):
    h = np.zeros(n)
    idx = rng.permutation(n)
    h[idx[:n // 2]] = 1.0
    return h

_G_N = 0
_G_BETA = 1.0
_G_PENALTY = 1e5

def _obj_lse_pen(x):
    n = _G_N
    dx = 2.0 / n
    corr = np.correlate(x, 1.0 - x, mode='full')
    m = np.max(corr)
    beta = _G_BETA
    shifted = corr - m
    exps = np.exp(np.clip(beta * shifted, -500, 500))
    obj = (m + np.log(np.sum(exps)) / beta) * dx
    obj += _G_PENALTY * (np.sum(x) - n / 2.0) ** 2
    return obj

def _grad_lse_pen(x):
    n = _G_N
    dx = 2.0 / n
    corr = np.correlate(x, 1.0 - x, mode='full')
    m = np.max(corr)
    beta = _G_BETA
    shifted = corr - m
    exps = np.exp(np.clip(beta * shifted, -500, 500))
    weights = exps / np.sum(exps)
    grad = np.zeros(n)
    for k_idx in range(len(corr)):
        w = weights[k_idx]
        if w < 1e-12:
            continue
        offset = k_idx - (n - 1)
        if offset >= 0:
            n_pairs = n - offset
            if n_pairs <= 0:
                continue
            grad[:n_pairs] += w * (1.0 - x[offset:offset + n_pairs])
            grad[offset:] -= w * x[:n_pairs]
        else:
            abs_off = -offset
            n_pairs = n - abs_off
            if n_pairs <= 0:
                continue
            grad[:n_pairs] -= w * x[abs_off:abs_off + n_pairs]
            grad[abs_off:] += w * (1.0 - x[:n_pairs])
    grad *= dx
    grad += 2.0 * _G_PENALTY * (np.sum(x) - n / 2.0)
    return grad

def _obj_and_grad(x):
    return _obj_lse_pen(x), _grad_lse_pen(x)

def optimize_lbfgsb(h_start, n, beta_list, time_left_fn, maxiter_per_beta=400):
    global _G_N, _G_BETA, _G_PENALTY
    _G_N = n
    h = h_start.copy()
    best_c5 = compute_c5(h)
    for i, beta in enumerate(beta_list):
        if time_left_fn() < 8.0:
            break
        _G_BETA = float(beta)
        _G_PENALTY = 1e5
        bounds = [(0.0, 1.0)] * n
        maxiter = min(maxiter_per_beta, max(50, int(time_left_fn() / 0.03)))
        try:
            res = minimize(_obj_and_grad, h, jac=True, method='L-BFGS-B',
                          bounds=bounds,
                          options={'maxiter': maxiter, 'ftol': 1e-14,
                                   'gtol': 1e-7, 'maxfun': 20000})
            h_new = project_feasible(res.x, n)
            c5_new = compute_c5(h_new)
            if c5_new < best_c5 - 1e-15:
                best_c5 = c5_new
                h = h_new
        except Exception:
            pass
    return h, best_c5

def nesterov_optimize(h_start, n, beta, time_left_fn, max_iters=3000):
    dx = 2.0 / n
    h = h_start.copy()
    h_prev = h.copy()
    best_h = h.copy()
    best_c5 = compute_c5(h)
    t_val = 1.0
    step = 1.0 / max(beta * 0.1, 1.0)

    for it in range(max_iters):
        if time_left_fn() < 3.0:
            break
        t_new = (1.0 + np.sqrt(1.0 + 4.0 * t_val * t_val)) / 2.0
        momentum = (t_val - 1.0) / t_new
        t_val = t_new

        y = h + momentum * (h - h_prev)
        y = project_feasible(y, n)

        corr_y = np.correlate(y, 1.0 - y, mode='full')
        m = np.max(corr_y)
        shifted = corr_y - m
        exps = np.exp(np.clip(beta * shifted, -500, 500))
        weights = exps / np.sum(exps)
        f_y = (m + np.log(np.sum(exps)) / beta) * dx

        grad_y = np.zeros(n)
        for k_idx in range(len(corr_y)):
            w = weights[k_idx]
            if w < 1e-12:
                continue
            offset = k_idx - (n - 1)
            if offset >= 0:
                n_pairs = n - offset
                if n_pairs <= 0:
                    continue
                grad_y[:n_pairs] += w * (1.0 - y[offset:offset + n_pairs])
                grad_y[offset:] -= w * y[:n_pairs]
            else:
                abs_off = -offset
                n_pairs = n - abs_off
                if n_pairs <= 0:
                    continue
                grad_y[:n_pairs] -= w * y[abs_off:abs_off + n_pairs]
                grad_y[abs_off:] += w * (1.0 - y[:n_pairs])
        grad_y *= dx

        h_prev = h.copy()
        s = step
        for _ in range(15):
            h_new = project_feasible(y - s * grad_y, n)
            corr_new = np.correlate(h_new, 1.0 - h_new, mode='full')
            m_new = np.max(corr_new)
            shifted_new = corr_new - m_new
            exps_new = np.exp(np.clip(beta * shifted_new, -500, 500))
            f_new = (m_new + np.log(np.sum(exps_new)) / beta) * dx
            if f_new <= f_y - 1e-5 * s * np.sum(grad_y ** 2):
                break
            s *= 0.5
        else:
            s = step

        h = h_new
        c5_now = compute_c5(h)
        if c5_now < best_c5 - 1e-15:
            best_c5 = c5_now
            best_h = h.copy()

    return best_h, best_c5

def active_set_subgrad(h_start, n, time_left_fn, rng, max_iters=500):
    h = h_start.copy()
    best_c5 = compute_c5(h)
    dx = 2.0 / n
    no_improve = 0
    for it in range(max_iters):
        if time_left_fn() < 3.0:
            break
        corr = compute_corr(h)
        max_val = np.max(corr)
        threshold = max_val - 0.0005
        active = np.where(corr >= threshold)[0]
        if len(active) == 0:
            active = np.argsort(corr)[-3:]

        grad = np.zeros(n)
        for k_idx in active:
            ki = int(k_idx)
            offset = ki - (n - 1)
            if offset >= 0:
                n_pairs = n - offset
                if n_pairs <= 0:
                    continue
                grad[:n_pairs] += (1.0 - h[offset:offset + n_pairs])

            else:
                abs_off = -offset

                if n_pairs <= 0:

                grad[:n_pairs] -= h[abs_off:abs_off + n_pairs]
                grad[abs_off:] += (1.0 - h[:n_pairs])
        grad *= dx / float(len(active))

        gnorm = np.linalg.norm(grad)
        if gnorm < 1e-16:
            break
        grad /= gnorm

        improved = False
        steps = [0.005, 0.01, 0.02, 0.04, 0.008, 0.015, 0.03, 0.06, 0.012]
        for step in steps:
            h_try = project_feasible(h - step * grad, n)
            c5_try = compute_c5(h_try)
            if c5_try < best_c5 - 1e-14:
                best_c5 = c5_try
                h = h_try
                improved = True
                no_improve = 0
                break
        if not improved:
            no_improve += 1
            if no_improve > 40:
                noise = rng.randn(n) * 0.015
                h_try = project_feasible(h + noise, n)
                c5_try = compute_c5(h_try)
                if c5_try < best_c5 - 1e-14:
                    best_c5 = c5_try
                    h = h_try
                    no_improve = 0

    return h, best_c5

def coord_descent_continuous(h_start, n, time_left_fn, rng, max_sweeps=20):
    h = h_start.copy()
    best_c5 = compute_c5(h)
    dx = 2.0 / n
    for sweep in range(max_sweeps):
        if time_left_fn() < 3.0:
            break
        any_imp = False
        order = rng.permutation(n)
        for i in order:
            if time_left_fn() < 1.5:
                break
            old_val = h[i]
            candidates = [0.0, 1.0, old_val * 0.5, old_val * 1.5,
                         (old_val + 0.0) * 0.3, (old_val + 1.0) * 0.7]
            candidates = [min(1.0, max(0.0, c)) for c in candidates]
            best_val = old_val
            best_c = best_c5
            for cv in candidates:
                if abs(cv - old_val) < 1e-9:
                    continue
                h[i] = cv
                h = project_feasible(h, n)
                c = compute_c5(h)
                if c < best_c - 1e-14:
                    best_c = c
                    best_val = cv
            if best_c < best_c5 - 1e-14:
                h[i] = best_val
                h = project_feasible(h, n)
                best_c5 = best_c
                any_imp = True
            else:
                h[i] = old_val
                h = project_feasible(h, n)
        if not any_imp:
            break
    return h, best_c5

def multi_start_optimize(n, time_left_fn, rng, best_h_ref, best_n_ref, n_starts=3):
    best_h = best_h_ref.copy()
    best_c5 = compute_c5(best_h_ref)

    for s in range(n_starts):
        if time_left_fn() < 20.0:
            break

        if s == 0:
            h_init = project_feasible(interp_to(best_h_ref, best_n_ref, n), n)
        elif s == 1:
            h_bin = (interp_to(best_h_ref, best_n_ref, n) > 0.5).astype(float)
            h_init = project_feasible(h_bin, n)
        else:
            h_init = make_random_binary(rng, n)

        c5_init = compute_c5(h_init)
        if c5_init < best_c5:
            best_c5 = c5_init
            best_h = h_init.copy()

        h_opt, c5_opt = optimize_lbfgsb(h_init, n, [50, 200, 800], time_left_fn, maxiter_per_beta=250)
        if c5_opt < best_c5:
            best_c5 = c5_opt
            best_h = h_opt.copy()

    return best_h, best_c5
