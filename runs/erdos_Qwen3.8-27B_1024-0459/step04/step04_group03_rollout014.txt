Alternative: precompute the index structure once, and only update the h-dependent parts.

Actually, the valid masks (valid1, valid2) and the index arrays (idx1, idx2) are FIXED for a given n. Only the values in h change. So I can precompute:
- idx1_clipped = np.clip(idx1, 0, n-1) (shape n × (2n-1))
- idx2_clipped = np.clip(idx2, 0, n-1)
- valid1, valid2 (boolean, shape n × (2n-1))

Then on each gradient eval:
term1_vals = np.where(valid1, one_minus_h[idx1_clipped], 0.0)
first_term = term1_vals @ probs

The np.where creates a fresh array each time, and the matrix-vector product is O(n * 2n). For n=256, that's about 262K operations, which is fast.

But creating the 2D array (n × 2n-1) of floats each time is O(n²) memory allocation. For n=512, that's about 4MB per call, and if L-BFGS-B calls the gradient 1000 times, that's 4GB of total allocation. Might be slow due to GC.

Better approach: precompute the matrices as int arrays, and use them to index h/one_minus_h.

Actually, the cleanest approach for moderate n is to just use the matrix formulation:

Let M1 be an (n, 2n-1) matrix where M1[j,k] = 1 if j+k-(n-1) ∈ [0,n-1], else 0
Let I1 be an (n, 2n-1) matrix where I1[j,k] = j+k-(n-1) (the index into one_minus_h)

Then: first_term[j] = sum_k M1[j,k] * one_minus_h[I1[j,k]] * probs[k]

first_term = Diagonal(one_minus_h) @ M1 @ probs  ... no, that's not right either.

**Alternative approach: Coordinate descent / cyclic coordinate search**

For the minimax problem, I can:
1. Identify the "active" lags (those where corr[k] is close to the max)
2. For each variable h[j], find the optimal value given all others fixed, subject to the active constraints
3. Cycle through variables

This is a block coordinate descent method. For each variable h[j], the objective is:
max_k corr[k](h) where corr[k] is linear in h[j] (given all other h[i] fixed).

So for a fixed h[-j], corr[k] = a_k * h[j] + b_k where a_k and b_k are known.
The constrained problem is: minimize max_k (a_k * h[j] + b_k) subject to 0 ≤ h[j] ≤ 1 and sum constraint.

This is a 1D minimax problem, solvable by bisection or directly.

The sum constraint complicates things, but I can handle it by adjusting after each coordinate update.

Actually, for a pure 1D minimax: minimize max_k (a_k * x + b_k) for x ∈ [0,1]
The optimal x is where the two largest lines cross (if that crossing is in [0,1]).

import numpy as np
from scipy.optimize import minimize

    return max(0.0, _BUDGET_S - (time.time() - _START_TIME) - 4.0)

def _c5(h):
    dx = 2.0 / len(h)
    c = np.array(np.correlate(h, 1.0 - h, mode='full'), dtype=np.float64)
    return float(np.max(c) * dx)

def _cm(h):

def _pf(h, n):
    h = np.array(h, dtype=np.float64).copy()
    np.clip(h, 0.0, 1.0, out=h)
    T = 0.5 * n
    for _ in range(200):
        d = T - float(np.sum(h))
        if abs(d) < 1e-14:
            break
        m = (h > 1e-12) & (h < 1.0 - 1e-12)
        c = int(np.count_nonzero(m))

def _it(s, sn, dn, sv=None):
    if sn == dn:
        return np.array(s, dtype=np.float64).copy()

    xn = (np.arange(dn) + 0.5) * (2.0 / dn)
    if sv is not None:
        yq = (np.arange(sn) + 0.5) * (2.0 / sn)

class _CG:
    def __init__(self, n):
        self.n = n
        self.dn = 2 * n - 1
        self.pc = np.empty((n, self.dn), dtype=np.int32)
        self.m1m = np.ones((n, self.dn), dtype=np.float64)
        self.m2m = np.zeros((n, self.dn), dtype=np.float64)
        js = np.arange(n).astype(np.int32)
        ks = np.arange(self.dn).astype(np.int32)
        i1 = js[:, None] + ks[None, :]
        i2 = js[:, None] - ks[None, :]
        v1 = (i1 >= n - 1) & (i1 <= (n - 1) * 2)
        v2 = (i2 >= n - 1) & (i2 <= (n - 1) * 2)
        self.pc[:, v1] = i1[:, v1] - (n - 1)
        self.pc[:, v2] = i2[:, v2] - (n - 1)
        self.m1m[v1] = 1.0
        self.m2m[v2] = 1.0
        self.i1 = self.pc
        self.i2a = (i2 - (n - 1)).clip(0, n - 1)
        self.v1 = v1
        self.v2 = v2

    def fgh(self, h, beta):
        n = self.n
        omh = 1.0 - h
        c = np.correlate(omh, h, mode='full')
        mx = float(np.max(c))
        sh = (c - mx) * beta
        np.clip(sh, -50.0, 0.0, out=sh)
        e = np.exp(sh)
        ss = float(np.sum(e))
        if ss < 1e-300:
            p = np.zeros(self.dn)
            np.fill(p, 1.0 / self.dn)
        else:
            p = e / ss
        t1 = np.zeros(n)
        ts = omh[self.i1[:, self.v1]] * p[None, self.v1]
        np.dot(self.m1m, ts, out=t1)
        t2 = np.zeros(n)
        ts2 = h[self.i2a[:, self.v2]] * p[None, self.v2]
        np.dot(self.m2m, ts2, out=t2)
        g = t1 - t2
        val = (mx + np.log(ss) / beta) * (2.0 / n)
        return val, g * (2.0 / n)

        return v

def _MME(cg, beta, ab):
    def fg(x):
        v, g = cg.fgh(x, beta)
        s = float(np.sum(x))
        m = int(np.sum(x > 1.0)) + int(np.sum(x < 0.0))
        if m > 0:
            v += 1e8 * m
            g += 1e8 * (np.sign(x) * (x > 1.0).astype(float) - np.sign(x) * (x < 0.0).astype(float))
        if ab > 0:

            if abs(d) > 1e-10:
                v += 5e-3 * d * d
                g += 5e-3 * d * np.ones_like(x)
        return v, g
    return fg
