```python
def eval_swap(k_val, i, j, h, v, n):
    """Compute change in corr[k_val] when h[i] goes 1->0 and h[j] goes 0->1."""
    d = 0.0
    # Term 1: -v[n-1-(k-i)] if i <= k <= i+n-1
    if i <= k_val <= i + n - 1:
        p = n - 1 - (k_val - i)
        if 0 <= p <= n-1:
            d -= v[p]
    # Term 2: +v[n-1-(k-j)] if j <= k <= j+n-1
    if j <= k_val <= j + n - 1:
        p = n - 1 - (k_val - j)
        if 0 <= p <= n-1:
            d += v[p]
    # Term 3: +h[i+k-n+1] if n-1-i <= k <= n-1+i
    if n - 1 - i <= k_val <= n - 1 + i:
        m = i + k_val - n + 1
        if 0 <= m <= n-1:
            d += h[m]
    # Term 4: -h[j+k-n+1] if n-1-j <= k <= n-1+j
    if n - 1 - j <= k_val <= n - 1 + j:
        m = j + k_val - n + 1
        if 0 <= m <= n-1:
            d -= h[m]
    return d
```

**Alternative approach: Just compute the change directly for the specific (i,j,k) triple.**

For a given swap (i,j) and shift k, the change in corr[k] is:
Δ = Σ_m (h_new[m]*v_new[m-k+n-1] - h_old[m]*v_old[m-k+n-1])

The only m values where this is non-zero are:
- m = i (h changes)
- m = j (h changes)
- m = i+k-n+1 (v at position i changes, i.e., m-k+n-1 = i)
- m = j+k-n+1 (v at position j changes)

But some of these might be the same! So I should take the set of distinct m values and compute the change at each.

Let M = {i, j, i+k-n+1, j+k-n+1} ∩ [0, n-1]

For each m in M:
  Δ_m = h_new[m]*v_new[m-k+n-1] - h_old[m]*v_old[m-k+n-1]

This is exact and handles all cross-interactions automatically!

The number of distinct m values is at most 4, so this is O(1) per (i,j,k) evaluation.

Let me code this up:

```python
def swap_delta(i, j, k, h, v, n):
    """Compute exact change in corr[k] when h[i] 1->0 and h[j] 0->1."""
    # Positions where the product changes
    ms = set()
    ms.add(i)
    ms.add(j)
    m3 = i + k - n + 1
    m4 = j + k - n + 1
    if 0 <= m3 < n:
        ms.add(m3)
    if 0 <= m4 < n:
        ms.add(m4)
    
    delta = 0.0
    for m in ms:
        # Old product
        p_old = h[m]
        v_idx = m - k + n - 1
        if 0 <= v_idx < n:
            prod_old = h[m] * v[v_idx]
        else:
            prod_old = 0.0
        
        # New product
        if m == i:
            h_new_m = 0.0
        elif m == j:
            h_new_m = 1.0
        else:
            h_new_m = h[m]
        
        if 0 <= v_idx < n:
            if v_idx == i:
                v_new_vi = 1.0
            elif v_idx == j:
                v_new_vi = 0.0
            else:
                v_new_vi = v[v_idx]
            prod_new = h_new_m * v_new_vi
        else:
            prod_new = 0.0
        
        delta += prod_new - prod_old
    
    return delta
```

This is exact! And it's O(1) per evaluation (at most 4 positions to check).
