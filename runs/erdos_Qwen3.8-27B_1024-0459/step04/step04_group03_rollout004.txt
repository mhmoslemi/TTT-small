c[m] = sum_j h[j] * (1-h[j-shift]) where shift = m - (n-1)

If I change h[i] from 0 to 1 (or from h[i] to h[i]+δ), the change in c[m] is:
- From the term j=i: h[i] appears in h[j], so change is δ*(1-h[i-shift]) if i-shift is valid
- From the term j-shift=i (j=i+shift): (1-h[j]) contains (1-h[i]), so change is -h[i+shift]*δ if i+shift is valid

So: Δc[m] = δ * [(1-h[i-shift]) * valid1 - h[i+shift] * valid2]

This is O(n) to compute (one for each m), much faster than O(n²) for the full correlation!

            # At t: c(t) = a + t*d_c
            
            a = c - h_i * d_c
            b = d_c
            
            # Minimize max(a + b*t) over t in [0,1]
            lo_v = np.max(a)
            hi_v = np.max(a + b)
            
            if hi_v - lo_v < 1e-14:
                continue
            
            for _ in range(50):
                mid_v = (lo_v + hi_v) / 2.0
                pos = b > 1e-12
                neg = b < -1e-12
                zero = ~(pos | neg)
                
                if np.any(zero) and np.max(a[zero]) > mid_v:
                    lo_v = mid_v
                else:
                    L = 0.0
                    U = 1.0
                    if np.any(neg):
                        L = max(L, float(np.max((mid_v - a[neg]) / b[neg])))
                    if np.any(pos):
                        U = min(U, float(np.min((mid_v - a[pos]) / b[pos])))
                    if L <= U + 1e-12:
                        hi_v = mid_v
                    else:
                        lo_v = mid_v
            
            v = hi_v
            pos = b > 1e-12
            neg = b < -1e-12
            L = 0.0
            U = 1.0
            if np.any(neg):
                L = max(L, float(np.max((v - a[neg]) / b[neg])))
            if np.any(pos):
                U = min(U, float(np.min((v - a[pos]) / b[pos])))
            L = max(0.0, L)
            U = min(1.0, U)
            t_opt = np.clip((L + U) / 2.0, 0.0, 1.0)
            
            if abs(t_opt - h_i) > 1e-12:
                # Update c
                delta = t_opt - h_i
                c += delta * d_c
                h[i] = t_opt
                improved += 1
        
        if improved == 0:
            break
        
        h = project_feasible(h, n)
        # Recompute c after projection
        c = np.correlate(h, 1.0 - h, mode='full')
        c5_now = np.max(c) * (2.0/n)
        if c5_now < best_c5:
            best_c5 = c5_now
    
    return h, compute_c5(h)
```

This is much faster! Each coordinate update is O(n) for the d_c computation and O(n) for the binary search (50 iterations * O(n) mask operations). Total per sweep: O(n²). For n=512: ~262K operations per sweep. Can do ~5000 sweeps easily.

Actually, I realize there might be an even faster approach. Let me think about the structure of d_c:

For coordinate i, d_c[m] = (1-h[i-shift_m]) * v1 - h[i+shift_m] * v2

where shift_m = m - (n-1) and v1, v2 are validity indicators.

Note that d_c is the "cross-correlation" of the "delta at i" with (1-h) minus the "correlation" of delta at i with h, basically.

Actually, d_c[m] can be computed as:
- The contribution to c[m] from h[i] in the "h" slot: (1-h[i-shift_m]) if valid
- The contribution to c[m] from h[i] in the "(1-h)" slot: -h[i+shift_m] if valid

This is exactly:
d_c = cross_corr(delta_i, 1-h) - cross_corr(delta_i, h)

where cross_corr(delta_i, x)[m] = x[i + shift_m] if valid, 0 otherwise.

In other words, d_c is just two shifted copies of h and (1-h), masked to valid regions. This can be computed very efficiently with numpy slicing.

```python
import numpy as np
from scipy.optimize import minimize
import time

_START_TIME = 0.0
_BUDGET_S = 1300.0

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return np.max(corr) * dx

def project_feasible(h, n):
    h = np.array(h, dtype=float).copy()
    h = np.clip(h, 0.0, 1.0)
    target = n / 2.0
    for _ in range(100):
        diff = target - np.sum(h)
        if abs(diff) < 1e-14:
            break
        mask = (h > 1e-12) & (h < 1.0 - 1e-12)
        cnt = np.sum(mask)
        if cnt > 0:
            h[mask] += diff / cnt
        else:
            h[:] += diff / n
        h = np.clip(h, 0.0, 1.0)
    return h

def remaining_time():
    return max(0.0, _BUDGET_S - (time.time() - _START_TIME) - 5.0)

def interp_to(src_h, src_n, dst_n):
    if src_n == dst_n:
        return src_h.copy()
    xp = (np.arange(src_n) + 0.5) * (2.0 / src_n)
    x_new = (np.arange(dst_n) + 0.5) * (2.0 / dst_n)
    return np.interp(x_new, xp, src_h)

def coord_descent(h, n, max_sweeps, rng):
    """Fast coordinate descent with incremental correlation updates."""
    h = h.copy()
    c = np.correlate(h, 1.0 - h, mode='full').copy()
    best_c5 = np.max(c) * (2.0 / n)
    n_c = 2 * n - 1
    
    shifts = np.arange(-(n-1), n)
    
    # Precompute valid1 and valid2 for each coordinate
    # valid1[i] = which m's have i-shift_m in [0, n-1]
    # valid2[i] = which m's have i+shift_m in [0, n-1]
    # For each i, valid1: i-shift >= 0 => shift <= i, and i-shift < n => shift > i-n
    #   shift ranges from -(n-1) to (n-1)
    #   So valid1 for coordinate i: shift in (i-n, i] intersect [-(n-1), n-1]
    #   i.e., shift in [max(-(n-1), i-n+1), min(n-1, i)]
    # For each i, valid2: i+shift >= 0 => shift >= -i, and i+shift < n => shift < n-i
    #   So valid2 for coordinate i: shift in [-i, n-i-1] intersect [-(n-1), n-1]
    #   i.e., shift in [max(-(n-1), -i), min(n-1, n-i-1)]
    
    for sweep in range(max_sweeps):
        if remaining_time() < 5:
            break
        
        order = rng.permutation(n)
        improved = 0
        
        for idx in range(n):
            if remaining_time() < 2:
                break
            i = int(order[idx])
            h_i = h[i]
            
            # Compute d_c (derivative of c w.r.t. h[i])
            # valid1: shift in [max(-(n-1), i-n+1), min(n-1, i)]
            # valid2: shift in [max(-(n-1), -i), min(n-1, n-i-1)]
            
            s1_lo = max(-(n-1), i - n + 1)
            s1_hi = min(n-1, i)
            s2_lo = max(-(n-1), -i)
            s2_hi = min(n-1, n - i - 1)
            
            # d_c[m] where m = shift + (n-1)
            # For valid1: d_c contribution = (1-h[i-shift]) at m = shift+(n-1)
            # For valid2: d_c contribution = -h[i+shift] at m = shift+(n-1)
            
            # I'll compute d_c as a full array
            d_c = np.zeros(n_c)
            
            if s1_hi >= s1_lo:
                idx1 = np.arange(s1_lo, s1_hi + 1) + (n - 1)  # m indices
                h_vals = h[i - np.arange(s1_lo, s1_hi + 1)]  # h[i-shift]
                d_c[idx1] += (1.0 - h_vals)
