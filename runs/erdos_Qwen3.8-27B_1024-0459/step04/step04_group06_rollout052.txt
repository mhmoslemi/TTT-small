Actually, one more important insight: the problem is defined with `np.correlate(h, 1-h, mode='full')`. For the "full" mode, the output has length 2n-1, and the lag ranges from -(n-1) to (n-1) samples. The integral for each lag k (in samples) is:

- For lag k < 0: let m = -k. sum_{i=0}^{n-1-m} h[i+m] * (1-h[i])

The dx factor makes this an approximation to the continuous integral.

Note: the lag 0 term is sum h[i]*(1-h[i]) = sum h - sum h². For h ∈ {0,1}, this is 0. For h ∈ [0,1], this is non-negative.

So for binary h, the lag 0 term is always 0, and we only need to worry about non-zero lags. This is a significant simplification for binary solutions.
