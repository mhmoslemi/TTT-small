def corr_grad_per_shift(x, n, k):
    g = np.zeros(n)
    off = k - (n - 1)
    if off >= 0:
        npairs = n - off
        g[off:off + npairs] += (1.0 - x[:npairs])
        g[:npairs] -= x[off:off + npairs]
    else:
        ao = -off
        npairs = n - ao
        g[:npairs] += (1.0 - x[ao:ao + npairs])
        g[ao:ao + npairs] -= x[:npairs]
    return g

**Key insight for local search**: When we swap h[i] from 1 to 0 and h[j] from 0 to 1, the change in the correlation at shift s is:
- At shift s = j - i: we remove the contribution from (i, i+s) = (i, j) if h[i]=1, h[j]=0 was contributing, and add contribution from (j, j-s) = (j, i) if h[j]=1, h[i]=0 now contributes.
- Actually, the change affects multiple shifts simultaneously.

For a swap of positions i and j (h[i]: 1→0, h[j]: 0→1):
- For any shift s where the pair (i, i+s) or (j, j+s) or (i-s, i) or (j-s, j) is in the overlap:
  - The correlation changes.

Specifically:
- shift s = j - i: previously h[i]=1, h[j]=h[i+s]=0, contributing 1 to X_s. Now h[i]=0, contributing 0. So X_s decreases by 1.
- shift s = i - j = -(j-i): previously h[j]=0, h[i]=h[j+s]=1, contributing h[j]*(1-h[i]) = 0*0 = 0. Now h[j]=1, h[i]=0, contributing h[j]*(1-h[i]) = 1*1 = 1. So X_{-(j-i)} increases by 1.
- For other shifts s where i and i+s are both in range: h[i] changed from 1 to 0, so X_s changes by -(1-h[i+s]) = -h[i+s] (decreases by h[i+s], which is 0 or 1).
  Wait, X_s = sum h[i']*(1-h[i'+s]). The term involving i is h[i]*(1-h[i+s]). Before: 1*(1-h[i+s]) = 1-h[i+s]. After: 0*(1-h[i+s]) = 0. Change: -(1-h[i+s]) = h[i+s]-1.
  If h[i+s]=0: change = -1 (X_s decreases by 1)
  If h[i+s]=1: change = 0

- Similarly for j: the term involving j is h[j]*(1-h[j+s]). Before: 0*(...) = 0. After: 1*(1-h[j+s]) = 1-h[j+s]. Change: +(1-h[j+s]).
  If h[j+s]=0: change = +1
  If h[j+s]=1: change = 0

So a swap (i,j) with h[i]:1→0, h[j]:0→1 affects:
- All shifts s where i is in the valid range: X_s changes by h[i+s] - 1 (i.e., -1 if h[i+s]=0, 0 if h[i+s]=1)
- All shifts s where j is in the valid range: X_s changes by 1 - h[j+s] (i.e., +1 if h[j+s]=0, 0 if h[j+s]=1)

This means a single swap can affect O(n) shifts. Computing the exact change is O(n) per swap, which for n=360 is feasible.

This gives us a way to do a more informed local search: for each candidate swap, compute the exact change in the max correlation.

But that's O(n) per candidate, and there are O(n²) candidates, so O(n³) per iteration. For n=360, that's about 47 million operations per iteration, which is too slow for many iterations.

A faster approach: only evaluate the change at the currently worst shifts (top-k). If the max is at shift s*, we mainly care about whether X_{s*} decreases. The change in X_{s*} from swap (i,j) is:
- If i is in range for shift s*: contribution change = h[i+s*] - 1 (which is -1 if h[i+s*]=0)
- If j is in range for shift s*: contribution change = 1 - h[j+s*] (which is +1 if h[j+s*]=0)

So the total change in X_{s*} = (h[i+s*] - 1) * [i in range] + (1 - h[j+s*]) * [j in range]

This is O(1) per candidate! We can quickly identify swaps that reduce X_{s*}.

But we also need to make sure other shifts don't increase more. A practical approach:
1. Find the current max shift s*.
2. Generate candidate swaps that reduce X_{s*} (i.e., h[i+s*]=0 and h[j+s*]=1, or i not in range and h[j+s*]=1, etc.)
3. Among these, pick one that also doesn't increase other top shifts too much.
4. Accept if the overall max doesn't increase.

This is a "directed" local search that's much more efficient than random swaps.

        # Generate candidate swaps that reduce the worst shift
        worst_k = top_idx[0]
        worst_s = shifts[0]  # actual shift

                j = zeros[rng.randint(len(zeros))]
            else:
                i = ones[rng.randint(len(ones))]
                j = zeros[rng.randint(len(zeros))]

            else:
                i = ones[rng.randint(len(ones))]
                j = zeros[rng.randint(len(zeros))]
        
        # Perform swap and evaluate
        h[i], h[j] = 0.0, 1.0
        new_corr = compute_corr(h)
        new_max = float(np.max(new_corr))
        delta = new_max - cur_max
        
        if delta < 0 or (T > 0.05 and rng.rand() < np.exp(-delta / T)):
            cur_max = new_max
            corr = new_corr

                best_max = new_max
                best_h = h.copy()
                stall = 0
            else:
                stall += 1
        else:
            h[i], h[j] = 1.0, 0.0
            stall += 1
        
        T *= alpha
        if stall > 3000:
            T = max(T, 2.0)
            stall = 0
    
    return best_h, best_max * dx_val

Change from i (h[i] goes from 1 to 0):

  More precisely: if s > 0 and i < n-s: Δ_i(s) = -(1-h[i+s])

Wait, for s=0: X_0 = sum h[i](1-h[i]). If h[i] goes from 1 to 0, the term changes from 1*0 to 0*1 = 0. No change.

For s > 0: X_s = sum_{i=0}^{n-1-s} h[i](1-h[i+s]).
If h[i] changes from 1 to 0 (and i < n-s): term changes from (1-h[i+s]) to 0. Δ = -(1-h[i+s]) = h[i+s]-1.
If h[j] changes from 0 to 1 (and j < n-s): term changes from 0 to (1-h[j+s]). Δ = (1-h[j+s]).

For s < 0 (let s = -t, t > 0): X_{-t} = sum_{i=t}^{n-1} h[i](1-h[i-t]).
If h[i] changes from 1 to 0 (and i ≥ t): term changes from (1-h[i-t]) to 0. Δ = -(1-h[i-t]) = h[i-t]-1.
If h[j] changes from 0 to 1 (and j ≥ t): term changes from 0 to (1-h[j-t]). Δ = (1-h[j-t]).

So the total change at shift s for swap (i, j) [h[i]:1→0, h[j]:0→1]:
ΔX_s = [i in valid range for s] * (h[i+s] - 1) + [j in valid range for s] * (1 - h[j+s])

where "valid range for s" means:
- If s ≥ 0: position p is valid if p < n - s (for the h[p] term)
- If s < 0: position p is valid if p ≥ |s| (for the h[p] term)

And h[i+s] is only defined when i+s is in [0, n-1].

        else:

        if len(valid_i) == 0:

            h[i], h[j] = 0.0, 1.0

        h = h.copy()
        psize = perturb_sizes[pi % len(perturb_sizes)]
        ones = np.where(h == 1)[0]
        zeros = np.where(h == 0)[0]
        for _ in range(psize):
            if len(ones) == 0 or len(zeros) == 0:
                break
            i = ones[rng.randint(len(ones))]
            j = zeros[rng.randint(len(zeros))]
            h[i], h[j] = 0.0, 1.0
            ones = np.where(h == 1)[0]
            zeros = np.where(h == 0)[0]

        # Cycling perturbation size: increase if stuck, decrease if improving
        if rng.rand() < 0.3:
            pi += 1
        elif rng.rand() < 0.2 and pi > 0:
            pi -= 1

        # Reset perturbation if we made progress
        if best_max < float(np.max(compute_corr(h))) - 5:
            pi = 0

    return best_h, best_max * dx_val


def smooth_obj(x):
    n = _N
    dx_val = 2.0 / n
    corr = compute_corr(x)
    m = np.max(corr)
    beta = _BETA
    shifted = corr - m
    cl = np.clip(beta * shifted, -60, 60)
    ex = np.exp(cl)
    return (m + np.log(np.sum(ex)) / beta) * dx_val


def corr_grad_per_shift(x, n, k):
    g = np.zeros(n)
    off = k - (n - 1)
    if off >= 0:
        npairs = n - off
        g[off:off + npairs] += (1.0 - x[:npairs])
        g[:npairs] -= x[off:off + npairs]
    else:
        ao = -off
        npairs = n - ao
        g[:npairs] += (1.0 - x[ao:ao + npairs])
        g[ao:ao + npairs] -= x[:npairs]
    return g


def smooth_grad(x):
    n = _N
    dx_val = 2.0 / n
    beta = _BETA
    corr = compute_corr(x)
    m = np.max(corr)
    shifted = corr - m
    cl = np.clip(beta * shifted, -60, 60)
    ex = np.exp(cl)
    w = ex / np.sum(ex)
    g = np.zeros(n)
    for k in range(len(corr)):
        if w[k] > 1e-14:
            g += w[k] * corr_grad_per_shift(x, n, k)
    return g * dx_val


def sum_con(x):
    return np.sum(x) - _TGT


def sum_con_jac(x):
    return np.ones(_N)


def slsqp_smooth(h, n, beta, maxiter=400):
    global _N, _BETA, _TGT
    _N = n
    _TGT = n / 2.0
    _BETA = beta
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': sum_con, 'jac': sum_con_jac}]
    try:
        res = minimize(smooth_obj, h, jac=smooth_grad, method='SLSQP',
                       bounds=bounds, constraints=cons,
                       options={'maxiter': maxiter, 'ftol': 1e-18, 'iprint': 0})
        return project_feasible(res.x, n)
    except Exception:
        return h


def multi_start_ils(h_init, n, time_limit, seed=42, n_starts=8):
    """Run ILS from multiple starts derived from h_init."""
    rng = np.random.RandomState(seed)
    best_h = h_init.astype(float).copy()
    best_c5 = compute_c5(best_h)
    t_per = time_limit / n_starts

    for s in range(n_starts):
        if remaining() < 10:
            break

        # Create a perturbed start
        if s == 0:
            h_cur = best_h.copy()
        else:
            h_cur = best_h.copy()
            n_pert = 10 + s * 5
            ones = np.where(h_cur == 1)[0]
            zeros = np.where(h_cur == 0)[0]
            for _ in range(n_pert):
                if len(ones) == 0 or len(zeros) == 0:
                    break
                i = ones[rng.randint(len(ones))]
                j = zeros[rng.randint(len(zeros))]
                h_cur[i], h_cur[j] = 0.0, 1.0
                ones = np.where(h_cur == 1)[0]
                zeros = np.where(h_cur == 0)[0]

        h_res, c5_res = ils_binary(h_cur, n, time_limit=min(t_per, remaining() * 0.8),
                                   seed=seed + s * 7919)
        if c5_res < best_c5:
            best_c5 = c5_res
            best_h = h_res.copy()

    return best_h, best_c5
