```python
import time

_START = 0.0
_BUDGET = 1300.0

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def compute_corr(h):
    return np.correlate(h, 1.0 - h, mode='full')

def project_feasible(h, n):
    h = np.array(h, dtype=float).copy()
    target = n / 2.0
    lo, hi = -2.0, 2.0
    for _ in range(60):
        mid = (lo + hi) / 2.0
        h_trial = np.clip(h - mid, 0.0, 1.0)
        s = np.sum(h_trial)
        if s > target:
            lo = mid
        else:
            hi = mid
    h = np.clip(h - (lo + hi) / 2.0, 0.0, 1.0)
    for _ in range(30):
        diff = target - np.sum(h)
        if abs(diff) < 1e-14:
            break
        mask = (h > 1e-12) & (h < 1.0 - 1e-12)
        cnt = np.sum(mask)
        if cnt > 0:
            h[mask] += diff / cnt
        else:
            h[:] += diff / n
        h = np.clip(h, 0.0, 1.0)
    return h

def remaining():
    return max(0.0, _BUDGET - (time.time() - _START) - 3.0)

def corr_grad_per_shift(x, n, k):
    g = np.zeros(n)
    off = k - (n - 1)
    if off >= 0:
        npairs = n - off
        if npairs > 0:
            g[off:off + npairs] += (1.0 - x[:npairs])
            g[:npairs] -= x[off:off + npairs]
    else:
        ao = -off
        npairs = n - ao
        if npairs > 0:
            g[:npairs] += (1.0 - x[ao:ao + npairs])
            g[ao:ao + npairs] -= x[:npairs]
    return g
```

Now for the binary optimization, let me think about the most effective approach.

For a binary vector b of length n with n/2 ones:
- corr_full = np.correlate(b, 1-b, 'full') has length 2n-1
- We want to minimize max(corr_full)

The swap delta formula:
When swapping b[i](1→0) and b[j](0→1):
For lag shift (where full_corr index = n-1+shift):
Δ[shift] = (b[i-shift] if 0≤i-shift<n else 0) - (b[i+shift] if 0≤i+shift<n else 0)
           + (b[j+shift] if 0≤j+shift<n else 0) - (b[j-shift] if 0≤j-shift<n else 0)

This is O(1) to compute for a specific shift, or O(n) for all shifts.

Strategy for greedy:
1. Compute corr_full, find argmax (worst shift)
2. For each 1-position i and 0-position j:
   - Compute Δ[worst_shift] (O(1))
   - If Δ < 0, this swap reduces the worst lag
   - Among those, pick the one that gives the lowest max(corr_full + Δ) (O(n) to check)
3. Apply the best swap
4. Repeat until no improvement

For n=312: 156 ones × 156 zeros = 24,336 pairs. O(1) each for the worst lag check. Then O(n) for the full check on candidates. This should be fast.

But actually, I can vectorize this. For a fixed i (1→0):
Δ[shift] from the "i part" = b[i-shift] - b[i+shift] (with boundary handling)
This is a vector of length 2n-1.

For a fixed j (0→1):
Δ[shift] from the "j part" = b[j+shift] - b[j-shift]

So total Δ = (i_part + j_part)

I can precompute the "i_part" for all i's and the "j_part" for all j's, then for each pair just add them and check the max.
