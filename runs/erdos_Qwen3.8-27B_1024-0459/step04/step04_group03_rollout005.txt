For each λ, the QP: min_h sum_k λ_k * (sum_j h[j]*(1-h[j-k+n-1])) * dx
= min_h sum_k λ_k * dx * (sum_{valid j} h[j] - sum_{valid j} h[j]*h[j-k+n-1])

The first term is linear in h, the second is quadratic. This is a QP that CVXPY can solve.

The outer problem: max_λ min_h QP(λ) where λ is a probability vector on 2n-1 lags.

This is a convex-concave game / zero-sum game. We can solve it with:
- Multiplicative weights / Hedge algorithm
- Frank-Wolfe on λ
- ADMM

But 2n-1 = 511 lags for n=256, and each QP has n=256 variables. This is feasible but each QP solve takes a few seconds.

Actually, let me think about this differently. The QP for a fixed λ:
min_h sum_i h[i] * g_i - sum_{i,j: j-k+n-1=i} h[i]*h[j] * c_{i,j}

where g_i = sum_k λ_k * dx * (indicator that i contributes to the "first" term of corr[k])
and c_{i,j} = sum_k λ_k * dx * (indicator that (i,j) is a valid pair for corr[k])

This is a quadratic form: min_h (h^T C h - g^T h) s.t. 0≤h≤1, sum h = n/2

If C is positive semidefinite, this is a convex QP. Let's check: C_{ij} = sum_k λ_k * dx * [i+j = k+n-1]... 

Actually, the quadratic term is:
sum_k λ_k * dx * sum_{valid j} h[j] * h[j-k+n-1]

Let me write this as sum_{i,j} Q_{ij} h[i] h[j] where Q_{ij} = sum_k λ_k * dx * [j = i-k+n-1 for some valid k] = sum_k λ_k * dx * [k = i-j+n-1 for valid k]

For fixed i,j: k = i-j+n-1 is valid if 0 ≤ k ≤ 2n-2.
So Q_{ij} = λ_{i-j+n-1} * dx (if 0 ≤ i-j+n-1 ≤ 2n-2) = λ_{i-j+n-1} * dx

The matrix Q is a "centroid" matrix (constant along anti-diagonals), which is a Toeplitz-like structure.

Is Q PSD? Q = sum_k λ_k * dx * T_k where T_k is the matrix with 1s on the (k+n-1)-th anti-diagonal. Each T_k is symmetric and PSD (it's a rank-1 matrix or zero). Actually T_k has 1s on one anti-diagonal, so it's not rank-1...

Hmm, T_k has entries (T_k)_{ij} = 1 if i+j = k+n-1, else 0. This is a symmetric matrix. Its eigenvalues... for the full anti-diagonal (k=n-1), it's the "reversal" matrix J which has eigenvalues ±1. So T_{n-1} = J is NOT PSD (it has negative eigenvalues).

So the QP is NOT convex in general. This means the dual approach doesn't directly work.

import numpy as np
from scipy.optimize import minimize
import time

_T0 = 0.0
_BUDGET = 1300.0

# Global state for objective functions
_G_N = 0
_G_BETA = 0
_G_TOPK = None

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def compute_corr(h):
    return np.correlate(h, 1.0 - h, mode='full')

def project_feasible(h, n):
    h = np.array(h, dtype=float).copy()
    h = np.clip(h, 0.0, 1.0)
    target = n / 2.0
    for _ in range(100):
        diff = target - np.sum(h)
        if abs(diff) < 1e-14:
            break
        mask = (h > 1e-10) & (h < 1.0 - 1e-10)
        cnt = int(np.sum(mask))
        if cnt > 0:
            h[mask] += diff / cnt
        else:
            h[:] += diff / n
        h = np.clip(h, 0.0, 1.0)
    diff = target - np.sum(h)
    if abs(diff) > 1e-12:
        idx = int(np.argmin(np.abs(h - 0.5)))
        h[idx] = float(np.clip(h[idx] + diff, 0.0, 1.0))
        diff2 = target - np.sum(h)
        if abs(diff2) > 1e-12:
            for j in range(n):
                if 1e-6 < h[j] < 1.0 - 1e-6:
                    h[j] = float(np.clip(h[j] + diff2, 0.0, 1.0))
                    break
    return h

def remaining_time():
    return max(0.0, _BUDGET - (time.time() - _T0) - 3.0)

def interp_to(h_src, n_src, n_dst):
    if n_src == n_dst:
        return h_src.copy()
    xp = (np.arange(n_src) + 0.5) * (2.0 / n_src)
    xp_new = (np.arange(n_dst) + 0.5) * (2.0 / n_dst)
    return np.interp(xp_new, xp, h_src)

def _smooth_obj(x):
    n = _G_N
    beta = _G_BETA
    dx = 2.0 / n
    h = np.clip(x, 0.0, 1.0)
    corr = np.correlate(h, 1.0 - h, mode='full')
    if _G_TOPK is not None:
        top = np.argsort(corr)[::-1][:_G_TOPK]
        vals = corr[top]
    else:
        vals = corr
    m = np.max(vals)
    shifted = np.minimum(beta * (vals - m), 0.0)
    return (m + np.log(np.sum(np.exp(shifted))) / beta) * dx

def _eq(x):
    return np.sum(x) - _G_N / 2.0

def slsqp_smooth(h_init, n, beta, maxiter=300, topk=None):
    global _G_N, _G_BETA, _G_TOPK
    _G_N = n
    _G_BETA = beta
    _G_TOPK = topk
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': _eq}]
    try:
        res = minimize(_smooth_obj, h_init, method='SLSQP',
                      bounds=bounds, constraints=cons,
                      options={'maxiter': maxiter, 'ftol': 1e-16, 'iprint': 0})
        if res.x is not None:
            return project_feasible(res.x, n)
    except Exception:
        pass
    return h_init.copy()

def slsqp_minimax(h_init, n, max_rounds=10, max_iter=200, n_active=10):

    _G_N = n

    h = h_init.copy()

            break

        active = np.unique(np.concatenate([active, active2]))
        active = np.sort(active)
