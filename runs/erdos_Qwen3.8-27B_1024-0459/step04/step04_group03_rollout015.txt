**Structural approach**: The optimal binary sequence for this problem is related to the "Turan" problem and has been studied. One construction is based on the binary representation of x/2 (the "Thompson" construction).

The Thompson series: h(x) = 1 if the binary expansion of x has more 0s than 1s in the first k digits (for appropriate k). This gives a near-optimal solution.

def thompson_init(n):
    """Initialize using Thompson/popcount construction."""
    h = np.zeros(n)
    pcs = popcount(np.arange(n))
    # Count values at each popcount level
    for pc in range(n.bit_length() + 1):
        mask = pcs == pc
        cnt = np.sum(mask)
        h[mask] = 1.0
    # Now we have too many 1s, need to reduce to n/2
    n_ones = int(np.sum(h))
    excess = n_ones - n // 2
    if excess > 0:
        # Remove from highest popcount first
        for pc in range(n.bit_length(), -1, -1):
            mask = (h == 1.0) & (pcs == pc)
            idx = np.where(mask)[0]

            h[idx[:to_remove]] = 0.0
