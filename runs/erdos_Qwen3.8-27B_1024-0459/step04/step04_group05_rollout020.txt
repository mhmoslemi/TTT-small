Wait, that's the same formula! So corr[k] for k=-m is:
sum_{j=0}^{N-1-m} h[j+m] * (1-h[j])

And corr[m] for k=m is:
sum_{n=0}^{N-1-m} h[n+m] * (1-h[n])

These are the same! So corr is symmetric? No wait, that can't be right for asymmetric sequences.

Let me re-read the numpy doc more carefully.

numpy.correlate(a, v, mode='full'):
c_k = sum_n a_{n+k} * conj(v_n)

where the sum is over all valid n such that both a[n+k] and v[n] are in bounds.

So for a=h, v=(1-h), N=n:
c_k = sum_n h[n+k] * (1-h[n])

For this to be valid: 0 ≤ n ≤ n-1 and 0 ≤ n+k ≤ n-1
So: max(0, -k) ≤ n ≤ min(n-1, n-1-k)

If k ≥ 0: 0 ≤ n ≤ n-1-k, so n goes from 0 to n-1-k. Number of terms: n-k.
c_k = sum_{n=0}^{n-1-k} h[n+k] * (1-h[n])  [for k ≥ 0]

If k < 0, let m = -k > 0: max(0, m) = m ≤ n ≤ min(n-1, n-1+m) = n-1
c_k = sum_{n=m}^{n-1} h[n-m] * (1-h[n])  [for k = -m < 0]
Let j = n-m: = sum_{j=0}^{n-1-m} h[j] * (1-h[j+m])

So:
c_k for k ≥ 0: sum_{n=0}^{n-1-k} h[n+k] * (1-h[n])  [h shifted forward]
c_{-k} for k > 0: sum_{n=0}^{n-1-k} h[n] * (1-h[n+k])  [h shifted backward]

These are NOT the same in general. c_k counts (1,0) pairs where the 1 is at position n+k and 0 is at n. c_{-k} counts (1,0) pairs where 1 is at n and 0 is at n+k.

OK so now for the swap effect:
If I swap position p (was 1, now 0) and q (was 0, now 1):

Effect on c_k for k ≥ 0: c_k = sum h[n+k]*(1-h[n])
- Position p as the "1" part (n+k=p, so n=p-k):
  - If 0 ≤ p-k ≤ n-1 and 0 ≤ p ≤ n-1: term was h[p]*(1-h[p-k]) = 1*(1-h[p-k])
  - Now h[p]=0, so term becomes 0. Delta = -(1-h[p-k])
- Position p as the "0" part (n=p):
  - If 0 ≤ p ≤ n-1-k and 0 ≤ p+k ≤ n-1: term was h[p+k]*(1-h[p]) = h[p+k]*1 = h[p+k]
  - Now (1-h[p])=1, so term becomes h[p+k]*(1-0) = h[p+k]. No change!
  Wait: before h[p]=1, so (1-h[p])=0, term = h[p+k]*0 = 0
  After h[p]=0, so (1-h[p])=1, term = h[p+k]*1 = h[p+k]
  Delta = +h[p+k]
- Position q (was 0, now 1) as the "1" part:
  - Before: h[q]=0, term = 0*(1-h[n]) = 0
  - After: h[q]=1, term = 1*(1-h[n]) = 1-h[n]
  - Delta = +(1-h[n]) where n = q-k (if valid)
- Position q as the "0" part:
  - Before: (1-h[q])=1, term = h[n+k]*1
  - After: (1-h[q])=0, term = 0
  - Delta = -h[n+k] where n=q (if valid)
