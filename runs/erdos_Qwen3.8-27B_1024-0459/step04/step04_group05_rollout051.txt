def fft_corr(h):
    """Compute np.correlate(h, 1-h, 'full') using FFT."""
    n = len(h)
    v = 1.0 - h
    N = 2 * n - 1
    Nfft = 1
    while Nfft < N:

    H = np.fft.fft(h, Nfft)

    return full

Cross-correlation (circular): (h ⋆ v)[m] = sum_n h[(n+m) mod N] * v[n]

Let's compute DFT of (h ⋆ v):
DFT(h ⋆ v)[k] = sum_m [sum_n h[(n+m) mod N] * v[n]] * exp(-2πikm/N)
= sum_m sum_n h[(n+m) mod N] * v[n] * exp(-2πikm/N)

Let p = (n+m) mod N, so m = (p-n) mod N:
= sum_p sum_n h[p] * v[n] * exp(-2πik(p-n)/N)

= H[k] * conj(V[k])
