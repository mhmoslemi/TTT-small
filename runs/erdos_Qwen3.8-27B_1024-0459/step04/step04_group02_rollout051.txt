- Constraints: H[i,i] = h[i] for all i (diagonal constraint)
- H >= 0 (PSD)
- 0 <= h <= 1
- sum h = n/2
- For each offset off: sum_{valid i} (h[min(i, ...)] - H[...]) * dx <= t

For the [0,1] relaxation (h not necessarily binary), we can't use H = h*h^T directly because H[i,i] = h[i]^2 ≠ h[i] in general.

def project_feasible(h, n):
    """Project h onto {sum = n/2, 0 <= h <= 1}"""
    h = np.array(h, dtype=float).copy()
    h = np.clip(h, 0.0, 1.0)
    target = n / 2.0
    for _ in range(500):
        diff = target - np.sum(h)
        if abs(diff) < 1e-15:
            break
        # Distribute to interior points
        interior = np.where((h > 1e-10) & (h < 1.0 - 1e-10))[0]
        if len(interior) > 0:
            h[interior] += diff / len(interior)
        else:
            # All at boundaries, need to move one
            if diff > 0:
                idx = np.argmin(h)
            else:
                idx = np.argmax(h)
            h[idx] = np.clip(h[idx] + diff, 0.0, 1.0)
        h = np.clip(h, 0.0, 1.0)
    # Final fix
    diff = target - np.sum(h)
    if abs(diff) > 1e-12:
        # Find the closest-to-0.5 point
        idx = int(np.argmin(np.abs(h - 0.5)))
        h[idx] = np.clip(h[idx] + diff, 0.0, 1.0)
        diff2 = target - np.sum(h)
        if abs(diff2) > 1e-12:
            # Spread over all interior
            interior = np.where((h > 1e-12) & (h < 1.0 - 1e-12))[0]

Let me also try a completely different angle: **direct coordinate descent with exact line search**.

For each coordinate i, the objective as a function of h[i] (with all other h fixed) is:
f(t) = max_k (base_k + a_k * t + b_k * t^2) * dx

where for each lag k (offset off):
- a_k and b_k depend on the other h values
- b_k is nonzero only for off=0 (where we have h[i]*(1-h[i]) = t*(1-t))

This is the max of a set of quadratic functions, which is convex in t (well, the max of convex functions is convex, but the quadratics here might not all be convex).

Actually, for off ≠ 0: the contribution is linear in t (either (1-h[j])*t or -h[j]*t or (1-h[j]) or -h[j], depending on which side i is on).
For off = 0: the contribution is t*(1-t) which is concave.

So f(t) is the max of linear functions and one concave function. This isn't necessarily convex. But for a fixed starting point, we can find the minimum on [0,1] by checking critical points.

The previous code did a golden section search, which works for unimodal functions. But if f(t) isn't unimodal, golden section might not find the global min.

Better: find all "breakpoints" where the active lag changes, and evaluate f at each breakpoint and at the vertex of the concave part.

For the linear parts: the breakpoints are where two linear functions cross. For n lags, there are O(n²) breakpoints, but in practice much fewer matter.

Actually, a simpler approach: evaluate f(t) on a fine grid (say 1000 points) and take the minimum. This is exact (up to grid resolution) and doesn't assume unimodality.

import numpy as np
from scipy.optimize import minimize
import time
import math

_START_TIME = 0.0
_BUDGET_S = 1300.0
_N_W = 0
_BETA_W = 0.0

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def compute_corr(h):
    return np.correlate(h, 1.0 - h, mode='full')

def project_feasible(h, n):
    h = np.array(h, dtype=float).copy()
    h = np.clip(h, 0.0, 1.0)
    target = n / 2.0
    for _ in range(500):
        diff = target - np.sum(h)
        if abs(diff) < 1e-14:
            break
        interior = np.where((h > 1e-10) & (h < 1.0 - 1e-10))[0]
        if len(interior) > 0:
            h[interior] += diff / len(interior)
        else:
            if diff > 0:
                idx = np.argmin(h)
            else:
                idx = np.argmax(h)
            h[idx] = np.clip(h[idx] + diff, 0.0, 1.0)
        h = np.clip(h, 0.0, 1.0)
    diff = target - np.sum(h)
    if abs(diff) > 1e-10:
        idx = int(np.argmin(np.abs(h - 0.5)))
        h[idx] = np.clip(h[idx] + diff, 0.0, 1.0)
    return h

def remaining():
    return max(0.0, _BUDGET_S - (time.time() - _START_TIME) - 5.0)

# Smoothed objective and gradient
def _smooth_val_grad(x, n, beta):
    dx = 2.0 / n
    corr = np.correlate(x, 1.0 - x, mode='full')
    m = np.max(corr)
    shifted = np.minimum(beta * (corr - m), 0.0)
    ev = np.exp(shifted)
    ws = np.sum(ev)
    w = ev / ws
    val = (m + np.log(ws) / beta) * dx
    # Gradient
    grad = np.zeros(n)
    for k in range(2*n-1):
        wk = w[k]
        if wk < 1e-14:
            continue
        off = k - (n-1)
        if off >= 0:
            np_ = n - off
            if np_ > 0:
                grad[off:off+np_] += wk * (1.0 - x[:np_])
                grad[:np_] -= wk * x[off:off+np_]
        else:
            a = -off
            np_ = n - a
            if np_ > 0:
                grad[:np_] += wk * (1.0 - x[a:a+np_])
                grad[a:a+np_] -= wk * x[:np_]
    grad *= dx
    return val, grad

def _g_val(x):
    return _smooth_val_grad(x, _N_W, _BETA_W)[0]

def _g_grad(x):
    return _smooth_val_grad(x, _N_W, _BETA_W)[1]

def _g_cons(x):
    return np.sum(x) - _N_W / 2.0

def _g_cons_jac(x):
    return np.ones(_N_W)

def slsqp_opt(h, n, beta, maxiter):
    global _N_W, _BETA_W
    _N_W = n
    _BETA_W = beta
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': _g_cons, 'jac': _g_cons_jac}]
    try:
        res = minimize(_g_val, h, jac=_g_grad, method='SLSQP',
                      bounds=bounds, constraints=cons,
                      options={'maxiter': maxiter, 'ftol': 1e-18, 'iprint': 0})
        if res.x is not None and np.all(np.isfinite(res.x)):
            trial = project_feasible(res.x, n)
            if compute_c5(trial) <= compute_c5(h) + 1e-13:
                return trial
    except:
        pass
    return h.copy()

def interp_to(src, src_n, dst_n):
    if src_n == dst_n:
        return src.copy()
    xp = (np.arange(src_n) + 0.5) * 2.0 / src_n
    xq = (np.arange(dst_n) + 0.5) * 2.0 / dst_n
    return np.interp(xq, xp, src)

def fine_grid_coord_descent(h, n, max_sweeps=50, grid_size=200):
    dx = 2.0 / n
    best_corr = compute_corr(h)
    best_c5 = float(np.max(best_corr) * dx)
    grid = np.linspace(0.0, 1.0, grid_size)
    
    for sweep in range(max_sweeps):
        if remaining() < 5:
            break
        improved = False
        for i in range(n):
            # Build coefficients
            a_coef = np.zeros(2*n-1)
            a_coef[n-1] = 1.0
            b_coef = np.zeros(2*n-1)
            b_coef[n-1] = -1.0
            
            # Positive offsets
            max_off_pos = n - 1 - i  # max off where i+off < n
            if max_off_pos >= 1:
                offs = np.arange(1, max_off_pos + 1)
                a_coef[n-1+offs] += (1.0 - h[i+offs])
            max_off_neg = i  # max off where i-off >= 0
            if max_off_neg >= 1:
                offs = np.arange(1, max_off_neg + 1)
                a_coef[n-1+offs] += (-h[i-offs])
            
            # Negative offsets (k = n-1-off)
            if max_off_neg >= 1:
                offs = np.arange(1, max_off_neg + 1)
                a_coef[n-1-offs] += (1.0 - h[i-offs])
            if max_off_pos >= 1:
                offs = np.arange(1, max_off_pos + 1)
                a_coef[n-1-offs] += (-h[i+offs])
            
            t0 = h[i]
            base = best_corr - a_coef * t0 - b_coef * t0 * t0
            
            # Evaluate on grid
            vals = base[None,:] + a_coef[:,None] * grid[None,:] + b_coef[:,None] * grid[None,:]**2
            obj_curve = np.max(vals, axis=0) * dx
            best_idx = np.argmin(obj_curve)
            
            if obj_curve[best_idx] < best_c5 - 1e-14:
                h[i] = grid[best_idx]
                best_corr = compute_corr(h)
                best_c5 = float(np.max(best_corr) * dx)
                improved = True
        
        if not improved:
            break
    
    return h, best_c5

def binary_local_search(h, n, max_iter=5000, temp=0.01):
    """Simulated annealing on binary (or near-binary) solution"""
    h_bin = np.where(h > 0.5, 1.0, 0.0)
    h_bin = project_feasible(h_bin, n)
    cur_c5 = compute_c5(h_bin)
    best_h = h_bin.copy()
    best_c5 = cur_c5
    cur_h = h_bin.copy()
    cur_corr = compute_corr(cur_h)
    
    ones = np.where(cur_h > 0.5)[0]
    zeros = np.where(cur_h < 0.5)[0]
    
    for it in range(max_iter):
        if remaining() < 5:
            break
        if len(ones) == 0 or len(zeros) == 0:
            break
        
        i = ones[rng_binary.randint(len(ones))]
        j = zeros[rng_binary.randint(len(zeros))]
        
        # Check if i != j (should be since one is in ones, other in zeros)
        if i == j:
            continue
        
        # Perform swap
        cur_h[i] = 0.0
        cur_h[j] = 1.0
        new_corr = compute_corr(cur_h)
        new_c5 = float(np.max(new_corr) * (2.0/n))
        
        delta = new_c5 - cur_c5
        if delta < 0 or rng_binary.random() < math.exp(-delta / max(temp, 1e-10)):
            # Accept
            cur_c5 = new_c5
            cur_corr = new_corr
            # Update ones/zeros

            zeros = np.where(cur_h < 0.5)[0]
            if cur_c5 < best_c5:
                best_c5 = cur_c5
                best_h = cur_h.copy()
        else:
            # Reject
            cur_h[i] = 1.0
            cur_h[j] = 0.0
        
        # Cool down
        temp *= 0.9995
    
    return best_h, best_c5

Better: compute the delta in corr for the swap in O(n).

For a swap (i: 1→0, j: 0→1):
The change in corr[k] for each k:
- Position i changes from 1 to 0
- Position j changes from 0 to 1

For corr at offset off > 0 (k = n-1+off):
corr[k] = sum_{p=0}^{n-1-off} h[p]*(1-h[p+off])

Change from i (1→0):
- If i is a "first" index (i <= n-1-off): was h[i]*(1-h[i+off]) = (1-h[i+off]), now 0. Delta: -(1-h[i+off])
- If i is a "second" index (i-off >= 0, i-off <= n-1-off, i.e., off <= i <= n-1): was h[i-off]*(1-h[i]) = 0 (since h[i]=1), now h[i-off]*1 = h[i-off]. Delta: +h[i-off]

Change from j (0→1):
- If j is a "first" index (j <= n-1-off): was h[j]*(1-h[j+off]) = 0, now 1*(1-h[j+off]) = (1-h[j+off]). Delta: +(1-h[j+off])
- If j is a "second" index (off <= j <= n-1): was h[j-off]*(1-h[j]) = h[j-off], now 0. Delta: -h[j-off]

For corr at offset -off (k = n-1-off), where off > 0:
corr[k] = sum_{p=0}^{n-1-off} h[p+off]*(1-h[p])

Change from i (1→0):
- If i is "second" (i <= n-1-off): was h[i+off]*(1-h[i]) = 0, now h[i+off]*1 = h[i+off]. Delta: +h[i+off]
- If i is "first" (i-off >= 0, i.e., off <= i): was h[i]*(1-h[i-off]) = (1-h[i-off]), now 0. Delta: -(1-h[i-off])

Change from j (0→1):
- If j is "second" (j <= n-1-off): was h[j+off]*(1-h[j]) = h[j+off], now 0. Delta: -h[j+off]
- If j is "first" (off <= j): was h[j]*(1-h[j-off]) = 0, now (1-h[j-off]). Delta: +(1-h[j-off])

For offset 0 (k = n-1):
corr[k] = sum h[p]*(1-h[p]) = 0 for binary. No change.

So the total delta for each k:

Let me define arrays for the contribution:
- delta_i[k]: change due to i going from 1 to 0
- delta_j[k]: change due to j going from 0 to 1

For k = n-1+off (off = 1 to n-1):
delta_i[n-1+off] = -(1-h[i+off]) * [i <= n-1-off] + h[i-off] * [i >= off]
delta_j[n-1+off] = (1-h[j+off]) * [j <= n-1-off] - h[j-off] * [j >= off]

For k = n-1-off (off = 1 to n-1):
delta_i[n-1-off] = -(1-h[i-off]) * [i >= off] + h[i+off] * [i <= n-1-off]
delta_j[n-1-off] = (1-h[j-off]) * [j >= off] - h[j+off] * [j <= n-1-off]

Note: [condition] is 1 if true, 0 otherwise.

This can be computed in O(n) per position (vectorized over offsets).

Let me precompute delta_i for all i in O(n²) total, and delta_j for all j in O(n²) total. Then for a specific swap (i,j), the new corr is corr + delta_i[i] + delta_j[j].

Then the new C₅ = max(corr + delta_i[i] + delta_j[j]) * dx.
