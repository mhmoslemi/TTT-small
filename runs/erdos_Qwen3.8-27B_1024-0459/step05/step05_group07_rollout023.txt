If we change h[i] by delta_i and h[j] by delta_j, the change in corr is:

For np.correlate(h, 1-h):
corr[n-1+s] = sum_a h[a+s] * (1-h[a]) for valid a

If h[i] changes by dh (i.e., h[i] → h[i]+dh), then:
- (1-h[i]) → (1-h[i]-dh)
- The term where a=i: h[i+s]*(1-h[i]-dh) instead of h[i+s]*(1-h[i]), change = -dh * h[i+s]
- The term where a+s=i (i.e., a=i-s): h[i]*(1-h[a]) → (h[i]+dh)*(1-h[a]), change = dh*(1-h[i-s])

  corr[n-1+s] += -dh * h[i+s]
- For shift s where a=i-s is valid (0≤i-s<n) and i valid (always):
  corr[n-1+s] += dh * (1-h[i-s])

Combined: for each valid s:
delta_corr[n-1+s] = dh * [(1-h[i-s]) - h[i+s]] (where terms are 0 if index out of range)

For a swap (h[i]: 1→0, dh_i = -1; h[j]: 0→1, dh_j = +1):

= h[i+s] + h[i-s] - h[j+s] - h[j-s] (approximately, with boundary conditions)

This is O(n) to compute for all s. So each swap evaluation is O(n) instead of O(n²).

Let me also consider: for the binary case, the problem relates to "difference sets" or "Golomb rulers" type problems. The Thue-Morse sequence is known to have good autocorrelation properties.

Actually, I realize I should think about what makes a good binary sequence for this problem:
- We want: for every shift k, the number of 1→0 pairs (at distance k) to be as small as possible
- Also: the number of 0→1 pairs (at distance k) to be as small as possible (these are the negative shifts)
- By the constraint (n/2 ones), we can't make both zero simultaneously for all k

For a "perfect" sequence: at shift k, exactly (n-|k|)/4 pairs are 1→0 and (n-|k|)/4 are 0→1, with (n-|k|)/2 being same-value pairs. This would give corr[k] = (n-|k|)/4 for all k, and C₅ ≈ (n/4) * 2/n = 1/2.

But we can do better! The maximum is over ALL shifts including small ones. At shift 1, we have n-1 pairs. If we alternate 1,0,1,0,..., then at shift 1: all n-1 pairs are different (alternating), giving corr = n-1 for one direction. That's terrible.

Actually for alternating 1,0,1,0,...:
- h = [1,0,1,0,...,1,0] (n/2 ones, n/2 zeros, starting with 1)
- At shift 1: h[i+1]*(1-h[i]): for i=0: h[1]*1 = 0, for i=1: h[2]*0 = 0, etc. All zero!
- At shift 1 (other direction): h[i]*(1-h[i+1]): for i=0: 1*1=1, for i=2: 1*1=1, etc. = n/2 - 1 or so.

Wait, let me be more careful with the correlate definition.

np.correlate(h, 1-h, mode='full'):
The result has length 2n-1.
result[k] = sum_i h[i+k-(n-1)] * (1-h)[i] where the indices are valid.

Actually, the standard definition: for a of length N and v of length M,
correlate(a, v)[k] = sum_n a[n+k] * conj(v[n])

where n ranges over all valid indices (0 ≤ n < M and 0 ≤ n+k < N).

So correlate(h, 1-h)[k] = sum_n h[n+k] * (1-h[n]) for valid n.

For k = 0: sum_n h[n] * (1-h[n]) = 0 for binary
For k = 1: sum_{n=0}^{n-2} h[n+1] * (1-h[n])
For k = -1: sum_{n=1}^{n-1} h[n-1] * (1-h[n])

Wait, but k ranges from -(M-1) to N-1 = -(n-1) to n-1.

For the alternating case h = [1,0,1,0,...]:
- k=1: sum_{n=0}^{n-2} h[n+1]*(1-h[n]) = for n=0: h[1]*1=0, n=1: h[2]*0=0, ... all 0. So corr[1] = 0.
- k=-1: sum_{n=1}^{n-1} h[n-1]*(1-h[n]) = for n=1: h[0]*1=1, n=3: h[2]*1=1, ... = n/2 - 1 (approximately)

So the negative shift gives a large value! That's bad.

What about h = [1,1,0,0,1,1,0,0,...]?
- k=1: h[n+1]*(1-h[n]): n=0: 1*1=1, n=1: 0*0=0, n=2: 0*1=0, n=3: 1*0=0, n=4: 1*1=1, ...
  Pattern: 1,0,0,0,1,0,0,0,... → about (n/2-1) ones, so corr[1] ≈ n/4
- k=-1: h[n-1]*(1-h[n]): n=1: 1*1=1, n=2: 1*0=0, n=3: 0*1=0, n=4: 0*0=0, n=5: 1*1=1, ...
  Same pattern ≈ n/4

This is better! The "1100" repeating pattern gives corr[k] ≈ (n-|k|)/4 for most small k.

In fact, the optimal binary pattern might be something like blocks of 1s and 0s that are "well-mixed" at all scales. This is related to "balanced sequences" in coding theory.

Let me just implement the optimization and let it find the best pattern.

```python
import numpy as np
from scipy.optimize import minimize
import time

_START_TIME = 0.0
_BUDGET_S = 1300.0

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return np.max(corr) * dx

def compute_corr(h):
    return np.correlate(h, 1.0 - h, mode='full')

def project_feasible(h, n):
    h = np.clip(np.array(h, dtype=float), 0.0, 1.0).copy()
    target = n / 2.0
    for _ in range(500):
        diff = target - h.sum()
        if abs(diff) < 1e-15:
            break
        mask = (h > 1e-10) & (h < 1.0 - 1e-10)
        if mask.any():
            h[mask] += diff / mask.sum()
        else:
            h[int(np.argmin(h))] += diff if diff > 0 else diff
        h = np.clip(h, 0.0, 1.0)
    return h

def remaining_time():
    return max(0.0, _BUDGET_S - (time.time() - _START_TIME) - 5.0)

def random_binary(n, rng):
    h = np.zeros(n)
    h[rng.choice(n, n//2, replace=False)] = 1.0
    return h

def block_pattern(n, block_size):
    """Create pattern of alternating blocks of 1s and 0s."""
    h = np.zeros(n)
    pos = 0
    val = 1.0
    while pos < n:
        end = min(pos + block_size, n)
        h[pos:end] = val
        pos = end
        val = 1.0 - val
    return project_feasible(h, n)

def thue_morse(n):
    h = np.zeros(n)
    for i in range(n):
        v, p = i, 0
        while v:
            p ^= (v & 1)
            v >>= 1
        h[i] = p
    return project_feasible(h, n)

def binary_sa(h, n, rng, n_iter=30000, T0=0.05, T1=0.001):

    h = h.copy()
    corr = compute_corr(h).astype(float)
    c5 = np.max(corr) * (2.0/n)
    best_c5 = c5
    best_h = h.copy()
    
    ones = np.where(h == 1.0)[0]
    zeros = np.where(h == 0.0)[0]
    
    dx = 2.0 / n
    ncorr = 2*n - 1
    
    for it in range(n_iter):
        if remaining_time() < 5:
            break
        T = T0 * (T1/T0) ** (it / n_iter)
        
        i = ones[rng.randint(len(ones))]
        j = zeros[rng.randint(len(zeros))]

        # Change: h[i] 1→0, h[j] 0→1
        # delta_corr[s] for shift s (corr index = n-1+s):
        # From h[i] 1→0:
        #   corr[n-1+s] += h[i+s] (if 0<=i+s<n) [from (1-h[i]) going 0→1]
        #   corr[n-1+s] -= (1-h[i-s]) (if 0<=i-s<n) [from h[i] going 1→0 in h[a+s] term]
        # Wait, I need to be more careful.

            c5 = new_max * dx

            zeros = zeros[zeros != j]
            zeros = np.append(zeros, i)
            ones = np.append(ones, j)
            
            if c5 < best_c5:
                best_c5 = c5
                best_h = h.copy()
        else:
            pass  # Reject, h unchanged

                    else:

                corr += A * (best_t - old)
                corr[n-1] -= (best_t-old)**2
                improved = True

            break
    
    return best, np.max(corr) * dx
```

```python
    corr = np.correlate(x, 1.0 - x, mode='full')
    m = np.max(corr)
    shifted = np.minimum(beta * (corr - m), 0.0)
    exp_vals = np.exp(shifted)
    wsum = np.sum(exp_vals)
    weights = exp_vals / wsum
    val = (m + np.log(wsum) / beta) * dx
    
    grad = np.zeros(n)
    ncorr = 2 * n - 1
    for k in range(ncorr):
        w = weights[k]
        if w < 1e-15:
            continue
        offset = k - (n - 1)
        # d(corr[k])/d(h[j]) = (1-h[j-offset])*I(0<=j-offset<n) - h[j+offset]*I(0<=j+offset<n)
        # For each valid j:
        j1_lo = max(0, offset)
        j1_hi = min(n-1, n-1+offset)
        if j1_hi >= j1_lo:
            grad[j1_lo:j1_hi+1] += w * (1.0 - x[j1_lo-offset:j1_hi-offset+1])
        j2_lo = max(0, -offset)
        j2_hi = min(n-1, n-1-offset)
        if j2_hi >= j2_lo:
            grad[j2_lo:j2_hi+1] -= w * x[j2_lo+offset:j2_hi+offset+1]
    grad *= dx
    return val, grad


def _smooth_obj(x):
    return smooth_obj_grad(x, _N_WORK, _BETA_WORK)[0]


def _smooth_grad(x):
    return smooth_obj_grad(x, _N_WORK, _BETA_WORK)[1]


def _sum_con(x):
    return np.sum(x) - _N_WORK / 2.0


def _sum_con_jac(x):
    return np.ones(_N_WORK)


def slsqp_optimize(h_in, n, beta, maxiter=500):
    global _N_WORK, _BETA_WORK
    _N_WORK = n
    _BETA_WORK = beta
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': _sum_con, 'jac': _sum_con_jac}]
    try:
        res = minimize(_smooth_obj, h_in, jac=_smooth_grad, method='SLSQP',
                      bounds=bounds, constraints=cons,
                      options={'maxiter': maxiter, 'ftol': 1e-22, 'iprint': 0})
        if res.x is not None and np.all(np.isfinite(res.x)):
            trial = project_feasible(res.x, n)
            c5_trial = compute_c5(trial)
            c5_orig = compute_c5(h_in)
            if c5_trial <= c5_orig + 1e-12:
                return trial
    except Exception:
        pass
    return np.array(h_in, dtype=float).copy()


def block_cd(h_in, n, block_size=4, max_sweeps=100):
    """Block coordinate descent: optimize blocks simultaneously via local search."""
    best = np.array(h_in, dtype=float).copy()
    corr = compute_corr(best).astype(float)
    dx = 2.0 / n
    ncorr = 2 * n - 1
    
    for sweep in range(max_sweeps):
        if remaining_time() < 15:
            break
        improved = False
        for start in range(0, n - block_size + 1, block_size):
            idx = list(range(start, start + block_size))
            old_vals = best[idx].copy()
            old_c5 = np.max(corr)
            
            # Try random perturbations of the block
            best_local_t = old_vals.copy()
            best_local_c5 = old_c5
            
            for trial in range(20):
                cand = old_vals.copy()
                mask = np.random.random(block_size) < 0.5
                cand[mask] += np.random.randn(np.sum(mask)) * 0.1
                cand = np.clip(cand, 0.0, 1.0)
                # Check sum constraint approximately
                test_h = best.copy()
                test_h[idx] = cand
                test_corr = compute_corr(test_h)
                tc5 = np.max(test_corr)
                if tc5 < best_local_c5 - 1e-14:
                    best_local_c5 = tc5
                    best_local_t = cand.copy()
            
            if best_local_c5 < old_c5 - 1e-13:
                # Update corr incrementally
                best[idx] = best_local_t
                corr = compute_corr(best)
                improved = True
        
        if not improved:
            break
    
    return best, np.max(corr) * dx


def perturb_restart(h_in, n, rng, scale=0.1, density=0.3):
    h_p = np.array(h_in, dtype=float).copy()
    mask = rng.random(n) < density
    h_p[mask] += rng.randn(np.sum(mask)) * scale
    return project_feasible(h_p, n)


def run(seed=42, budget_s=1300, **kwargs):
    global _START_TIME, _BUDGET_S
    _START_TIME = time.time()
    _BUDGET_S = budget_s
    rng = np.random.RandomState(seed)
    
    best_h = None
    best_c5 = float('inf')
    best_n = 0
    
    # Load parent
    try:
        parent_h = np.array(initial_h_values, dtype=float)
        parent_n = len(parent_h)
        parent_c5 = compute_c5(parent_h)
        best_h = parent_h.copy()
        best_c5 = parent_c5
        best_n = parent_n
    except Exception:
        best_n = 640
        best_h = np.full(best_n, 0.5)
        best_h[rng.choice(best_n, best_n // 2, replace=False)] = 1.0
        best_h = project_feasible(best_h, best_n)
        best_c5 = compute_c5(best_h)
    
    n = best_n
    
    # Phase 1: Aggressive coordinate descent from parent
    h_work = best_h.copy()
    h_work, c5_work = coord_descent(h_work, n, max_sweeps=200)
    if c5_work < best_c5:
        best_c5 = c5_work
        best_h = h_work.copy()
    
    # Phase 2: SLSQP with increasing beta
    h_work = best_h.copy()
    for beta in [500, 2000, 8000, 20000, 50000]:
        if remaining_time() < 30:
            break
        h_new = slsqp_optimize(h_work, n, beta, maxiter=600)
        c5_new = compute_c5(h_new)
        if c5_new < compute_c5(h_work) - 1e-15:
            h_work = h_new
        if c5_new < best_c5:
            best_c5 = c5_new
            best_h = h_new.copy()
    
    # Phase 3: More coordinate descent after SLSQP
    if remaining_time() > 30:
        h_work = best_h.copy()
        h_work, c5_work = coord_descent(h_work, n, max_sweeps=200)
        if c5_work < best_c5:
            best_c5 = c5_work
            best_h = h_work.copy()
    
    # Phase 4: Multiple random restarts
    if remaining_time() > 60:
        n_restarts = 10
        for r in range(n_restarts):
            if remaining_time() < 40:
                break
            scale = 0.15 / (1.0 + r * 0.4)
            density = 0.25 + 0.1 * rng.random()
            h_pert = perturb_restart(best_h, n, rng, scale=scale, density=density)
            h_new, c5_new = coord_descent(h_pert, n, max_sweeps=100)
            if c5_new < best_c5:
                best_c5 = c5_new
                best_h = h_new.copy()
            if remaining_time() > 50:
                h_slq = slsqp_optimize(h_new, n, 5000, maxiter=400)
                c5_slq = compute_c5(h_slq)
                if c5_slq < best_c5:
                    best_c5 = c5_slq
                    best_h = h_slq.copy()
                    h_cd, c5_cd = coord_descent(best_h, n, max_sweeps=80)
                    if c5_cd < best_c5:
                        best_c5 = c5_cd
                        best_h = h_cd.copy()
    
    # Phase 5: Block coordinate descent
    if remaining_time() > 40:
        for bs in [4, 8]:
            if remaining_time() < 30:
                break
            h_work = best_h.copy()
            h_work, c5_work = block_cd(h_work, n, block_size=bs, max_sweeps=50)
            if c5_work < best_c5:
                best_c5 = c5_work
                best_h = h_work.copy()
    
    # Phase 6: Try higher resolution
    if remaining_time() > 120:
        for mult in [2, 3]:
            if remaining_time() < 100:
                break
            high_n = n * mult
            if high_n > 4000:
                continue
            h_high = interp_to(best_h, n, high_n)
            h_high = project_feasible(h_high, high_n)
            h_new, c5_new = coord_descent(h_high, high_n, max_sweeps=80)
            if c5_new < best_c5:
                best_c5 = c5_new
                best_h = h_new.copy()
                best_n = high_n
            if remaining_time() > 80:
                h_slq = slsqp_optimize(h_new, high_n, 10000, maxiter=300)
                c5_slq = compute_c5(h_slq)
                if c5_slq < best_c5:
                    best_c5 = c5_slq
                    best_h = h_slq.copy()
                    best_n = high_n
                h_cd, c5_cd = coord_descent(best_h, high_n, max_sweeps=60)
                if c5_cd < best_c5:
                    best_c5 = c5_cd
                    best_h = h_cd.copy()
                    best_n = high_n
            # Go back to original n for subsequent phases if we didn't improve
            n = best_n
    
    # Phase 7: Subgradient-inspired directions
    if remaining_time() > 60:
        n_cur = best_n
        h_work = best_h.copy()
        for it in range(200):
            if remaining_time() < 10:
                break
            corr = compute_corr(h_work)
            max_val = np.max(corr)
            # Active set: top correlations
            threshold = max_val - 0.15
            active = np.where(corr >= threshold)[0]
            if len(active) == 0:
                active = np.array([np.argmax(corr)])
            if len(active) > 12:
                active = active[np.argsort(corr[active])[::-1][:12]]
            
            grad = np.zeros(n_cur)
            for k_idx in active:
                offset = int(k_idx) - (n_cur - 1)
                j1_lo = max(0, offset)
                j1_hi = min(n_cur - 1, n_cur - 1 + offset)
                if j1_hi >= j1_lo:
                    grad[j1_lo:j1_hi+1] += (1.0 - h_work[j1_lo-offset:j1_hi-offset+1])
                j2_lo = max(0, -offset)
                j2_hi = min(n_cur - 1, n_cur - 1 - offset)
                if j2_hi >= j2_lo:
                    grad[j2_lo:j2_hi+1] -= h_work[j2_lo+offset:j2_hi+offset+1]
            
            gnorm = np.linalg.norm(grad)
            if gnorm < 1e-14:
                break
            step = 0.03 / (1.0 + it * 0.02)
            h_try = h_work - step * grad / gnorm
            h_try = project_feasible(h_try, n_cur)
            c5_try = compute_c5(h_try)
            if c5_try < best_c5 - 1e-14:
                best_c5 = c5_try
                best_h = h_try.copy()
                h_work = h_try.copy()
            else:
                # Try small coordinate descent to recover
                if it % 30 == 15 and remaining_time() > 20:
                    h_cd, c5_cd = coord_descent(h_work, n_cur, max_sweeps=20)
                    if c5_cd < best_c5:
                        best_c5 = c5_cd
                        best_h = h_cd.copy()
                        h_work = h_cd.copy()
    
    # Phase 8: Final SLSQP polish with very high beta
    if remaining_time() > 20:
        n_cur = best_n
        h_work = best_h.copy()
        for beta in [50000, 200000, 500000]:
            if remaining_time() < 10:
                break
            h_new = slsqp_optimize(h_work, n_cur, beta, maxiter=500)
            c5_new = compute_c5(h_new)
            if c5_new < best_c5:
                best_c5 = c5_new
                best_h = h_new.copy()
                h_work = h_new.copy()
    
    # Phase 9: Final coordinate descent
    if remaining_time() > 15:
        h_new, c5_new = coord_descent(best_h, best_n, max_sweeps=300)
        if c5_new < best_c5:
            best_c5 = c5_new
            best_h = h_new.copy()
    
    # Phase 10: One more SLSQP
    if remaining_time() > 10:
        h_new = slsqp_optimize(best_h, best_n, 100000, maxiter=400)
        c5_new = compute_c5(h_new)
        if c5_new < best_c5:
            best_c5 = c5_new
            best_h = h_new.copy()
    
    # Final projection and verification
    n_final = best_n
    best_h = project_feasible(best_h, n_final)
    final_c5 = compute_c5(best_h)
    
    try:
        eval_c5 = evaluate_erdos_solution(best_h)
        if eval_c5 < final_c5:
            final_c5 = eval_c5
    except Exception:
        pass
    
    return (best_h, final_c5, n_final)
```
