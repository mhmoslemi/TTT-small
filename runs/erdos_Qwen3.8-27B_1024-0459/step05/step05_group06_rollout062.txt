            A[k0] = 1.0 - 2.0 * t0

            for o in range(1, n):

            # Key points: t=0, t=1, t=t0, and where the quadratic crosses dominant lines

                candidates.append(min(1.0, t0 + 0.1))
                candidates.append(max(0.0, t0 - 0.05))
                candidates.append(min(1.0, t0 + 0.05))

            # For each k≠k0: best_corr[k] + A[k]*(t-t0) = best_corr[k0] + (t-t0)(1-t-t0)
            # This is: A[k]*(t-t0) - best_corr[k] + best_corr[k0] = (t-t0)(1-t-t0)
            # Let u = t-t0: A[k]*u = (1-t0-u)*u - u^2... wait that's not right
            # (t-t0)(1-t-t0) = u*(1-t0-u) = u*(1-t0) - u²
            # So: A[k]*u = u*(1-t0) - u²

            # If u≠0: A[k] = (1-t0) - u, so u = (1-t0) - A[k]
            # t = t0 + (1-t0) - A[k] = 1 - A[k]

                if f < best_f:

                    best_t = t

                lo = max(0.0, best_t - 0.3)
                hi = min(1.0, best_t + 0.3)

                c2 = lo + gr * (hi - lo)

                d2 = c2 - t0

                for _ in range(80):

                        c2 = c1
                        f2 = f1

                        d1 = c1 - t0
                        f1 = np.max(best_corr + A * d1 + B * d1 * d1) * dx
                    else:
                        lo = c1
                        c1 = c2
                        f1 = f2
                        c2 = lo + gr * (hi - lo)
                        d2 = c2 - t0
                        f2 = np.max(best_corr + A * d2 + B * d2 * d2) * dx

                d_opt = t_opt - t0

                if f_opt < best_f:
                    best_f = f_opt
                    best_t = t_opt

                best[i] = best_t
                best_corr = compute_corr(best)
                best_c5 = compute_c5(best)
                improved_any = True
        
        if not improved_any:
            break

    return best, best_c5

Actually, the max of a set of concave functions is concave. Wait no - the max of concave functions is NOT necessarily concave. The max of convex functions is convex.

Each term best_corr[k] + A[k]*(t-t0) is linear (both convex and concave). The quadratic term is concave. The max of linear and one concave function... 

Let's see: if the quadratic is above all lines, f is the quadratic (concave, so minimum at boundary). If a line is above the quadratic, f is that line (linear, minimum at boundary of the region where it's the max).

Actually, the minimum of f over [0,1] will always be at:
- t = 0 or t = 1, OR
- A point where two "active" functions cross (and the crossing is a local minimum of the max)

For linear functions, the max is convex, so its minimum is at a vertex where two lines cross. Adding the quadratic (concave) can only lower the max (if it's below the lines) or raise it (if it's above). If the quadratic is above, the min is at the minimum of the quadratic clipped to where it's above all lines, which is at a crossing point or the vertex of the quadratic.

In practice, golden section should work if the function is "roughly unimodal" in a small neighborhood. Since we're doing a local refinement from a good starting point, this should be fine.

    corr = np.correlate(x, 1.0 - x, mode='full')
    m = np.max(corr)
    shifted = np.minimum(beta * (corr - m), 0.0)
    exp_vals = np.exp(shifted)
    wsum = np.sum(exp_vals)
    weights = exp_vals / wsum
    val = (m + np.log(wsum) / beta) * dx
    ncorr = 2 * n - 1
