Better approach: update best_corr incrementally. When we change best[i] from t0 to t_new, which correlations change?

corr[k] = sum_j h[j] * (1-h[j+off_k]) where off_k = k-(n-1).
The terms involving h[i] are those where j = i or j+off_k = i.
- j = i: valid if i is in range → corr[k] changes by (t_new - t0) * (1-h[i+off_k]) if i+off_k valid
- j+off_k = i, j = i-off_k: valid if i-off_k in range → corr[k] changes by h[i-off_k] * (-(t_new-t0)) if i-off_k valid
- If off_k = 0 (k = n-1): corr[n-1] changes by (t_new - t_new²) - (t0 - t0²) = (t_new-t0)(1-t0-t_new)

So for each changed coordinate i, only O(n) correlation entries change (those where i participates). We can update them in O(n) time.

Let me implement this:

```python
def update_corr_after_change(best_corr, old_h, new_h, i, n):
    """Update correlations after changing h[i] from old to new."""
    delta = new_h - old_h
    if abs(delta) < 1e-15:
        return best_corr
    changed = best_corr.copy()
    # offset 0 (k = n-1): h[i]*(1-h[i]) changes by (new-new²)-(old-old²) = delta*(1-old-new)
    changed[n-1] += delta * (1.0 - old_h - new_h)
    # positive offsets: off = 1..n-1, k = n-1+off
    for off in range(1, n):
        k = n - 1 + off
        # h[i] as h[j+off] (j = i-off): if 0 <= i-off and i < n
        if i >= off:
            changed[k] += delta * (1.0 - old_h[i-off])  # wait, h[i-off] hasn't changed
            # Actually: h[j+off] = h[i] changes from old to new
            # corr[k] includes h[j+off]*(1-h[j]) = h[i]*(1-h[i-off])
            # Change: (new-old)*(1-h[i-off]) = delta*(1-h[i-off])
        # h[i] as h[j] (j = i): if i+off < n
        if i + off < n:
            # corr[k] includes h[j+off]*(1-h[j]) = h[i+off]*(1-h[i])
            # Change: h[i+off]*(-delta) = -delta*h[i+off]
            changed[k] += -delta * old_h[i+off]  # h[i+off] hasn't changed
    
    for off in range(1, n):
        k = n - 1 - off
        # offset = -off
        # corr[k] = sum_{j=off}^{n-1} h[j]*(1-h[j-off])
        # h[i] as h[j] (j = i): if off <= i < n
        if off <= i:
            # h[i]*(1-h[i-off]) change: delta*(1-h[i-off])
            changed[k] += delta * (1.0 - old_h[i-off])
        # h[i] as h[j-off] (j = i+off): if 0 <= i < n-off... wait, j ranges from off to n-1
        # j-off = i → j = i+off, valid if off <= i+off <= n-1, i.e., 0 <= i <= n-1-off
        if i + off < n:
            # h[i+off]*(1-h[i]) change: h[i+off]*(-delta)
            changed[k] += -delta * old_h[i+off]
    
    return changed
```
