   - Pure binary search as fallback if feasible (based on remaining budget).  
   - Exit if remaining time < 20s.

iii. **Resolution Exploration: Progressive Scale Changes**  
   - For n in [n_start-div: n_start+div] (e.g., delta steps ±12,16 for coarse adjustment).  
   - Perform averaging/interpolation between old and new n.  
   - dx=2/n, so reindexing needed for transition.  
   - If original objective underperforms at new n, re-run SLSQP-loop.  

iv. **Fallback Strategy**  
   - If NaNs, set clip tolerance to default; if subgradient err, restart SLSQP.  
   - Backup via interpolation tree rebuild if dimensionality jumps too high.

**3.3 Termination Conditions**  
- Time-based: stop if remaining() < 5s and no progress for last 10 samples.  
- Success: accept any improvement in C5 value.  
- Bounce criterion: n > 1024 or n < 128 → adjust budget fraction and optimization energy.
