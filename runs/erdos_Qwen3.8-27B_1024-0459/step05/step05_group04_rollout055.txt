Actually, the simplest effective approach for the continuous problem:

- Use projected gradient descent: take a gradient step, then project onto the feasible set
- The projection onto {0≤h≤1, sum(h)=n/2} is: clip to [0,1], then adjust by a uniform shift to meet the sum

The gradient of corr[k] with respect to h[m]:
corr[k] = sum_j h[j]*(1-h[j+k-(n-1)])
∂corr[k]/∂h[m] = (1-h[m+k-(n-1)]) - h[m-k+(n-1)] (for valid indices)

This is the same formula as before. The gradient of the soft max is a weighted sum of these.

Let me implement a clean projected gradient descent:

```python
def pgd_continuous(h, n, beta, n_iters=5000, lr_schedule=True):
    dx = 2.0 / n
    h = project_feasible(h.copy(), n)
    corr = compute_corr(h)
    
    lr = 0.01
    for it in range(n_iters):
        if remaining() < 5:
            break
        # Compute soft max and gradient
        m = np.max(corr)
        shifted = corr - m
        cl = np.clip(beta * shifted, -50, 50)
        exp_cl = np.exp(cl)
        w = exp_cl / np.sum(exp_cl)
        soft_max = m + np.log(np.sum(exp_cl)) / beta
        
        # Gradient of soft_max with respect to h
        g = np.zeros(n)
        for k in range(2*n-1):
            wk = w[k]
            if wk < 1e-15:
                continue
            d = k - (n-1)
            # ∂corr[k]/∂h[m] = (1-h[m+d]) - h[m-d] for valid m
            # Vectorized:
            lo1 = max(0, -d)
            hi1 = min(n-1, n-1-d)
            if lo1 <= hi1:
                g[lo1:hi1+1] += wk * (1.0 - h[lo1+d:hi1+1+d])
            lo2 = max(0, d)
            hi2 = min(n-1, n-1+d)
            if lo2 <= hi2:
                g[lo2:hi2+1] -= wk * h[lo2-d:hi2+1-d]
        
        g *= dx  # scale by dx since objective is soft_max * dx
        
        # Line search / adaptive step
        for step in [lr, lr*0.5, lr*0.25, lr*2]:
            h_new = project_feasible(h - step * g, n)
            c5_new = compute_c5(h_new)
            c5_old = soft_max * dx
            if c5_new < c5_old:
                h = h_new
                corr = compute_corr(h)
                break
        else:
            lr *= 0.5
            if lr < 1e-8:
                break
    
    return h, compute_c5(h)
```
