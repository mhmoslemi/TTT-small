For the exact coordinate descent, I need to efficiently compute, for a given coordinate j:

Actually, I realize there's a much faster way to do the coordinate descent. Instead of computing rest_k for all k, I can:
1. Compute the current corr vector (O(n²) using np.correlate)
2. For coordinate j, compute the derivative = ∂corr_k/∂h[j] for all k (this is just the gradient of corr_k w.r.t. h[j], which I can compute in O(n))
3. The new corr when h[j] changes to t: corr_k(t) = corr_k(current) + (t - h[j]) * ∂corr_k/∂h[j]
4. Find t that minimizes max_k corr_k(t) over [0,1]

Step 3 is valid because corr_k is linear in h[j] (as I showed earlier)!

So the algorithm is:
1. Compute corr = np.correlate(h, 1-h, 'full')  [O(n²)]
2. Compute d_j = [∂corr_k/∂h[j] for all k]  [O(n), using the gradient formula for a single coordinate]
3. For t ∈ [0,1]: corr_k(t) = corr_k + (t - h[j]) * d_j[k]
4. Minimize max_k corr_k(t) over t ∈ [0,1]

Step 4: This is a 1D convex minimization of max_k (a_k + b_k * t) where a_k = corr_k - h[j]*d_j[k] and b_k = d_j[k].

The minimum of max_k (a_k + b_k * t) over [0,1] can be found by:
- The function is convex piecewise-linear
- The minimum is where the subgradient contains 0
- Subgradient at t is conv{b_k : k is active at t}
- k is active at t if a_k + b_k*t = max_j(a_j + b_j*t)

Efficient algorithm:
1. Compute f(0) = max_k a_k and f(1) = max_k (a_k + b_k)
2. If f(0) <= f(t) for all t, minimum is at t=0
3. If f(1) <= f(t) for all t, minimum is at t=1
4. Otherwise, binary search for the point where the minimum of the active slopes crosses 0

Actually, a simpler approach: since the function is convex, I can use golden section search. Or even simpler, since it's piecewise linear, I can find all the "breakpoints" where the identity of the max changes.

But the simplest correct approach for a 1D convex piecewise linear function:
- Evaluate at t=0 and t=1
- If f is decreasing at t=0 (i.e., the active slope at t=0 is negative), and increasing at t=1 (active slope at t=1 is positive), then the minimum is where the slope changes sign.
- We can find this by binary search on the slope.

The slope at t (where f is differentiable) is b_k for any k that is active (i.e., achieves the max). If multiple k are active, the subgradient is the interval [min active b_k, max active b_k].

So the algorithm is:
1. If all active b_k at t=0 are ≥ 0, minimum is at t=0
2. If all active b_k at t=1 are ≤ 0, minimum is at t=1
3. Otherwise, binary search for t* where 0 ∈ subgradient

For step 3, at each t in the binary search:
- Compute f(t) = max_k (a_k + b_k * t)
- Find the active set: k such that a_k + b_k * t ≥ f(t) - ε
- Check if min(active b_k) ≤ 0 ≤ max(active b_k)

This takes O(n) per evaluation. Binary search takes about 50 iterations. Total: O(50n) per coordinate. Full sweep: O(50n²) = O(50 * 1024²) ≈ 50M. At 100M ops/sec, that's 0.5 seconds per sweep. Very fast!
