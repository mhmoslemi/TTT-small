When we swap h[i] (1→0) and h[j] (0→1):

Actually, for a swap (i, j), the affected corr values are only those k where:
- n+k = i or n = i or n+k = j or n = j (for some valid n)
- So k = i-n, k = n-i, k = j-n, k = n-j for valid n

This spans a range of k values. For a given swap (i,j), the number of affected k values is O(n) in the worst case (when i and j are far apart). But we can compute the delta in O(n) time.

Let me also think about structured initial sequences:

1. **Van der Corput / Halton sequence**: Place ones at positions {⌊n * i / (n/2)⌋} or {⌊n * {i * α}⌋} for irrational α.

2. **Thue-Morse sequence**: t(n) = parity of number of 1s in binary representation of n.

3. **M-sequence (maximal length LFSR sequence)**: Nearly balanced, good autocorrelation properties.

4. **Circle method**: Place n/2 points as evenly as possible on the circle [0, n). Start with positions {⌊i * n / (n/2)⌋} for i = 0, ..., n/2-1. But this gives alternating pattern.

5. **Irrational rotation**: Place ones at {⌊i * n * α⌋ mod n} for i = 0, ..., n/2-1 where α is irrational (e.g., golden ratio conjugate). This gives a "low-discrepancy" distribution.

    h_bin = np.zeros(n)
    h_bin[sorted_idx[:n // 2]] = 1.0
    return h_bin

def make_thue_morse(n, n_ones):
    """Generate a Thue-Morse-like sequence with exactly n_ones ones."""
    # Generate Thue-Morse
    t = np.zeros(1)
    while len(t) < n:
        t = np.concatenate([t, 1-t])
    t = t[:n]
    # Adjust to have exactly n_ones
    # If too many ones, flip some 1s to 0s (and vice versa)
    ones = np.where(t == 1)[0]
    zeros = np.where(t == 0)[0]
    n_ones_actual = len(ones)
    if n_ones_actual > n_ones:
        # Need to flip (n_ones_actual - n_ones) ones to zeros
        to_flip = ones[len(ones) - (n_ones_actual - n_ones):]
        t[to_flip] = 0
    elif n_ones_actual < n_ones:
        to_flip = zeros[:n_ones - n_ones_actual]
        t[to_flip] = 1
    return t

def make_irrational_rotation(n, n_ones, alpha=None):
    """Place n_ones ones at positions determined by irrational rotation."""
    if alpha is None:
        alpha = (np.sqrt(5) - 1) / 2  # golden ratio conjugate
    positions = np.sort((np.arange(n_ones) * alpha * n) % n).astype(int)
    # Handle duplicates
    unique_pos = []
    used = set()
    for p in positions:
        p = p % n
        while p in used:
            p = (p + 1) % n
        used.add(p)
        unique_pos.append(p)
    h = np.zeros(n)
    h[unique_pos[:n_ones]] = 1.0
    return h

def make_crude(n, n_ones):
    """Simple block pattern."""
    h = np.zeros(n)
    h[:n_ones] = 1.0
    return h

        ib = rng.randint(len(zeros))

        pb = zeros[ib]

        h[pb] = 1.0
