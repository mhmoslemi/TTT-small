Actually, for the discrete correlation computed by np.correlate, the formula is:
corr[k] = ∑_{i} h[i] * (1-h[i-(k-(n-1))])

where the sum is over all i where both i and i-(k-(n-1)) are in [0, n-1].

Let off = k - (n-1). Then corr[k] = ∑_i h[i] * (1-h[i-off]) where i ranges over values such that both i and i-off are in [0, n-1].

So valid i range: max(0, off) ≤ i ≤ n-1+min(0, off) = n-1 if off≥0, or 0 ≤ i ≤ n-1-off if off<0.

For off ≥ 0: i ranges from off to n-1, and i-off ranges from 0 to n-1-off.
For off < 0: i ranges from 0 to n-1+off, and i-off ranges from -off to n-1.

Now, when we change h[a] from 1 to 0 and h[b] from 0 to 1:

The terms in corr[k] that change are:
1. Where h[a] appears as the first factor: i = a (if a is in valid range for this k)
   - Contribution was: 1 * (1-h[a-off]) = 1-h[a-off]
   - New contribution: 0
   - Change: -(1-h[a-off])

2. Where h[a] appears as the second factor: i-off = a, i.e., i = a+off (if valid)
   - Contribution was: h[a+off] * (1-1) = 0
   - New contribution: h[a+off] * (1-0) = h[a+off]
   - Change: +h[a+off]

3. Where h[b] appears as the first factor: i = b (if valid)
   - Contribution was: 0
   - New: 1 * (1-h[b-off]) = 1-h[b-off]
   - Change: +(1-h[b-off])

Actually, the validity condition is simpler: a-off is in [0,n-1] for term 1 to exist (since i=a, and we need i-off = a-off in range). Similarly, a+off in [0,n-1] for term 2 (i=a+off, need i in range).

Let me simplify: for the full correlation, every pair (i, i-off) where both are in [0,n-1] contributes. So:
- Term 1 (a as first factor) exists iff a ∈ [0,n-1] AND a-off ∈ [0,n-1]
- Term 2 (a as second factor, i=a+off) exists iff a+off ∈ [0,n-1] AND a ∈ [0,n-1]
- Similarly for b.

Since a and b are always in [0,n-1], the conditions are:
- Term 1: a-off ∈ [0,n-1]
- Term 2: a+off ∈ [0,n-1]
- Term 3: b-off ∈ [0,n-1]
- Term 4: b+off ∈ [0,n-1]

OK this is getting complex but manageable. For the speed-ahead, let me precompute for each position and each lag whether it's valid.

Actually, for simplicity and since n is at most ~768, let me just compute the delta directly:
- Undo the swap in a copy, compute corr, compare.
- No, that's O(n) per trial which is the same as before.

The O(1) formula is:
Δcorr[k] = indicator(a-off valid) * h[a-off] + indicator(a+off valid) * h[a+off] 
           - indicator(b-off valid) * h[b-off] - indicator(b+off valid) * h[b+off]

This is O(1) per lag, so O(K) for K top lags. Much faster than O(n) for full correlation.

Let me implement this properly. But I need to be careful: when computing "delta_max" (the change in the maximum), I need to consider not just the top lags but also lags that weren't top but might become the new max after the change.

A safe upper bound: new_max ≤ max(old_max + max_over_k Δcorr[k], old_max)
And new_max ≥ max(old_max + Δcorr[top_k]) for the current top lag.

For a practical approach:
- Compute Δcorr[k] for the top T lags (say T=10)
- Also estimate the worst-case increase for other lags
- If the maximum of (corr[k] + Δcorr[k]) over all k is less than the current best, accept the move

But computing for all k is O(n) per evaluation. For the "other" lags, we can bound:
|Δcorr[k]| ≤ 2 for all k (since it's sum of at most 4 binary values with coefficient ±1)

So: new_corr[k] ≤ corr[k] + 2 for any k.
And new_corr[k] ≥ corr[k] - 2 for any k.

This means: new_max ≤ max(corr) + 2 = c_max + 2. Not very tight.

A better bound: for lags where |off| is large (far from the center), the number of terms in the correlation is small, so the change is bounded by the number of terms that involve position a or b.

For lag with offset off: the valid range of i is of size n - |off|. Position a appears in at most 2 terms (as first or second factor), and position b in at most 2 terms. So |Δcorr[k]| ≤ 2 for any k.

OK, I think for practical purposes, I'll just compute the full correlation after each accepted move (O(n) per move), and use the O(1) formula only for screening potential moves.

import numpy as np
from scipy.optimize import minimize
import time

_T0 = 0.0
_BUDGET = 1300.0
_CUR_N = 0
_SM_BETA = 1000.0


def remaining_time():
    return max(0.0, _BUDGET - (time.time() - _T0) - 5.0)


def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)


def compute_corr(h):
    return np.correlate(h, 1.0 - h, mode='full')


def project_feasible(h, n):
    h = np.clip(np.array(h, dtype=float).flatten(), 0.0, 1.0)
    target = n / 2.0
    for _ in range(200):
        diff = target - np.sum(h)
        if abs(diff) < 1e-14:
            break
        mask = (h > 1e-10) & (h < 1.0 - 1e-10)
        cnt = np.count_nonzero(mask)
        if cnt > 0:
            h[mask] += diff / cnt
        else:
            h[:] += diff / n
        h = np.clip(h, 0.0, 1.0)
    return h


def _sm_obj(x):
    n = _CUR_N
    dx = 2.0 / n
    corr = compute_corr(x)
    m = np.max(corr)
    beta = _SM_BETA
    z = np.clip(beta * (corr - m), -50.0, 50.0)
    ez = np.exp(z)
    return (m + np.log(np.sum(ez)) / beta) * dx


def _sm_grad(x):
    n = _CUR_N
    dx = 2.0 / n
    corr = compute_corr(x)
    m = np.max(corr)
    beta = _SM_BETA
    z = np.clip(beta * (corr - m), -50.0, 50.0)
    ez = np.exp(z)
    S = np.sum(ez)
    w = ez / S
    g = np.zeros(n)
    for k in range(2 * n - 1):
        wk = w[k] * dx
        if wk < 1e-14:
            continue
        off = k - (n - 1)
        if off >= 0:
            np_ = n - off
            if np_ <= 0:
                continue
            g[off:] += wk * (1.0 - x[:np_])
            g[:np_] -= wk * x[off:]
        else:
            a = -off
            np_ = n - a
            if np_ <= 0:
                continue
            g[:np_] += wk * (1.0 - x[a:])
            g[a:] -= wk * x[:np_]
    return g


def _eq_fun(x):
    return np.sum(x) - _CUR_N / 2.0


def _eq_jac(x):
    return np.ones(_CUR_N)


def slsqp_opt(h, n, beta, maxiter=500):
    global _CUR_N, _SM_BETA
    _CUR_N = n
    _SM_BETA = beta
    h0 = project_feasible(h, n)
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': _eq_fun, 'jac': _eq_jac}]
    obj0 = _sm_obj(h0)
    try:
        res = minimize(_sm_obj, h0, jac=_sm_grad, method='SLSQP',
                       bounds=bounds, constraints=cons,
                       options={'maxiter': maxiter, 'ftol': 1e-18})
        if res.x is not None:
            res_x = project_feasible(res.x, n)
            if _sm_obj(res_x) < obj0 - 1e-15:
                return res_x
    except Exception:
        pass
    return h0


def grad_corr_k(h, n, k):
    g = np.zeros(n)
    off = k - (n - 1)
    if off >= 0:
        np_ = n - off
        if np_ > 0:
            g[off:] += (1.0 - h[:np_])
            g[:np_] -= h[off:]
    else:
        a = -off
        np_ = n - a
        if np_ > 0:
            g[:np_] += (1.0 - h[a:])
            g[a:] -= h[:np_]
    return g


def top_k_equalize(h, n, top_k=5, max_iters=800):
    h = project_feasible(h, n)
    best_c5 = compute_c5(h)
    for it in range(max_iters):
        if remaining_time() < 3:
            break
        corr = compute_corr(h)
        idx_top = np.argsort(-corr)[:top_k]
        g_dir = np.zeros(n)
        for k in idx_top:
            g_dir += grad_corr_k(h, n, k)
        gn = np.linalg.norm(g_dir)
        if gn < 1e-14:
            break
        d = g_dir / gn
        improved = False
        for step in [0.01, 0.02, 0.005, 0.05, 0.002, 0.08, 0.15, 0.03, 0.015]:
            ht = project_feasible(h - step * d, n)
            cn = compute_c5(ht)
            if cn < best_c5 - 1e-14:
                h = ht
                best_c5 = cn
                improved = True
                break
        if not improved:
            break
    return h, best_c5


def interp_to(src, src_n, dst_n):
    if src_n == dst_n:
        return src.copy()
    xp = (np.arange(src_n) + 0.5) * 2.0 / src_n
    xn = (np.arange(dst_n) + 0.5) * 2.0 / dst_n
    return np.interp(xn, xp, src)


def theta_morse(n):
    h = np.zeros(n)
    for i in range(n):
        v = i
        cnt = 0
        while v:
            cnt += v & 1
            v >>= 1
        h[i] = 1.0 if cnt % 2 == 1 else 0.0
    return project_feasible(h, n)


def delta_corr_swap(h, n, a, b, top_lags):
    """Compute approximate delta in corr for top lags when swapping h[a]=1->0, h[b]=0->1."""
    deltas = np.zeros(len(top_lags))
    for idx, k in enumerate(top_lags):
        off = k - (n - 1)
        d = 0.0
        # a-off valid (a as first factor)
        ia = a - off
        if 0 <= ia < n:
            d += h[ia]
        # a+off valid (a as second factor, i=a+off)
        ia2 = a + off
        if 0 <= ia2 < n:
            d += h[ia2]
        # b-off valid
        ib = b - off
        if 0 <= ib < n:
            d -= h[ib]
        # b+off valid
        ib2 = b + off
        if 0 <= ib2 < n:
            d -= h[ib2]
        deltas[idx] = d
    return deltas


def binary_informed_search(h, n, time_limit=120, rng=None):
    """Binary 2-flip search using O(1) delta computation for screening."""
    if rng is None:
        rng = np.random.RandomState(42)
    h = (h > 0.5).astype(float).copy()
    n_half = n // 2
    if int(np.sum(h)) != n_half:
        sort_idx = np.argsort(-h)
        h = np.zeros(n)
        h[sort_idx[:n_half]] = 1.0
    dx = 2.0 / n
    start = time.time()
    corr = compute_corr(h)
    best_c5 = float(corr.max() * dx)
    best_h = h.copy()
    ones_list = np.where(h == 1.0)[0]
    zeros_list = np.where(h == 0.0)[0]
    no_improve = 0
    max_no_improve = 50

    while time.time() - start < time_limit and remaining_time() > 5:
        corr = compute_corr(h)
        c_max = corr.max()
        top_lags = np.argsort(-corr)[:8]
        top_corr = corr[top_lags].copy()

        best_new_c5 = best_c5
        best_pair = None

        n_trials = 400
        for _ in range(n_trials):
            i = ones_list[rng.randint(len(ones_list))]
            j = zeros_list[rng.randint(len(zeros_list))]
            if i == j:
                continue
            # Fast screening with delta
            deltas = delta_corr_swap(h, n, i, j, top_lags)
            new_top = top_corr + deltas
            approx_max = max(new_top.max(), c_max - 2.0 * len(top_lags) / (2 * n))
            if approx_max * dx >= best_new_c5:
                continue
            # Verify with full computation
            h[i] = 0.0
            h[j] = 1.0
            c_new = float(np.max(compute_corr(h)) * dx)
            if c_new < best_new_c5 - 1e-12:
                best_new_c5 = c_new
                best_pair = (i, j)
            else:
                h[i] = 1.0
                h[j] = 0.0

        if best_pair is not None:
            i, j = best_pair
            h[i] = 0.0
            h[j] = 1.0
            best_c5 = best_new_c5
            best_h = h.copy()
            ones_list = np.where(h == 1.0)[0]
            zeros_list = np.where(h == 0.0)[0]
            no_improve = 0
        else:
            no_improve += 1
            if no_improve > max_no_improve:
                break
            # Random accepted step (hill climbing with occasional uphill moves)
            i = ones_list[rng.randint(len(ones_list))]
            j = zero_zeros = zeros_list[rng.randint(len(zeros_list))]
            h[i] = 0.0
            h[j] = 1.0
            c_new = float(np.max(compute_corr(h)) * dx)
            if c_new < best_c5 * 1.02:
                best_h = h.copy()
                best_c5 = min(best_c5, c_new)
            else:
                h[i] = 1.0
                h[j] = 0.0
            ones_list = np.where(h == 1.0)[0]
            zeros_list = np.where(h == 0.0)[0]

    return best_h, best_c5


def subgradient_refine(h, n, max_iters=2000):
    """Project-onto-simplex subgradient method for minimax."""
    h = project_feasible(h, n)
    best_c5 = compute_c5(h)
    best_h = h.copy()
    alpha = 0.02

    for it in range(max_iters):
        if remaining_time() < 3:
            break
        corr = compute_corr(h)
        c_max = corr.max()
        # Active set: lags within 1% of max
        threshold = c_max * 0.99 + 1e-10
        active = np.where(corr >= threshold)[0]
        if len(active) == 0:
            active = np.array([np.argmax(corr)])

        G = np.zeros(n)
        for k in active:
            G += grad_corr_k(h, n, k)
        G /= len(active)

        Gn = np.linalg.norm(G)
        if Gn < 1e-14:
            break
        d = G / Gn

        improved = False
        for a in [alpha, alpha * 0.5, alpha * 0.25]:
            h_new = project_feasible(h - a * d, n)
            c5_new = compute_c5(h_new)
            if c5_new < best_c5 - 1e-14:
                h = h_new
                best_c5 = c5_new
                best_h = h_new.copy()
                improved = True
                break
        if not improved:
            alpha *= 0.8
            if alpha < 1e-6:
                break
        else:
            alpha = min(alpha * 1.1, 0.05)

    return best_h, best_c5


def targeted_lag_reduction(h, n, max_iters=500):
    """Iteratively target the single worst lag and reduce it."""
    h = project_feasible(h, n)
    best_c5 = compute_c5(h)
    for it in range(max_iters):
        if remaining_time() < 3:
            break
        corr = compute_corr(h)
        k_worst = np.argmax(corr)
        c_worst = corr[k_worst]
        g = grad_corr_k(h, n, k_worst)
        gn = np.linalg.norm(g)
        if gn < 1e-14:
            break
        d = g / gn
        improved = False
        for step in [0.01, 0.02, 0.005, 0.05, 0.002, 0.08]:
            ht = project_feasible(h - step * d, n)
            cn = compute_c5(ht)
            if cn < best_c5 - 1e-14:
                h = ht
                best_c5 = cn
                improved = True
                break
        if not improved:
            break
    return h, best_c5
