  i.e., set h[j] = const - h[i], and optimize over h[i]
- This maintains the sum exactly

For the pair optimization:
- The change in corr when h[i] → t and h[j] → s (with t+s = t0+s0) is:
  For each k: Δcorr[k] = (Δt)*(contribution of i) + (Δs)*(contribution of j)
  where Δt = t - t0, Δs = s - s0 = -Δt
  
  So Δcorr[k] = Δt * (grad_i[k] - grad_j[k])
  
  This is still linear in Δt! So the max of (corr + Δt*(grad_i - grad_j)) is easy to compute.
  
  Plus the k=0 quadratic corrections for both i and j.

                best_c5 = c5m
                best_h = pm.copy()

    # Phase 10: Final intensive CD
    if remaining_time() > 15:
        h, c5 = _coord_cd(best_h, best_n, 40)
        if c5 < best_c5:
            best_c5 = c5
            best_h = h.copy()

    # Phase 11: SLSQP polish
    if remaining_time() > 10:
        h = _slsqp(best_h, best_n, 2000000, 200)
        c5 = compute_c5(h)
        if c5 < best_c5:
            best_c5 = c5
            best_h = h.copy()

    # Phase 12: Final CD
    if remaining_time() > 5:
        h, c5 = _coord_cd(best_h, best_n, 20)
        if c5 < best_c5:
            best_c5 = c5
            best_h = h.copy()

    # Final validation
    best_h = project_feasible(best_h, best_n)
    final_c5 = compute_c5(best_h)

    target = best_n / 2.0
    diff = target - np.sum(best_h)
    if abs(diff) > 1e-10:
        free = (best_h > 1e-14) & (best_h < 1.0 - 1e-14)
        if np.sum(free) > 0:
            best_h[free] += diff / np.sum(free)
            best_h = np.clip(best_h, 0.0, 1.0)

    try:
        ec5 = evaluate_erdos_solution(best_h)
        if ec5 < final_c5:
            final_c5 = ec5
    except Exception:
        pass

    return (best_h, final_c5, best_n)
