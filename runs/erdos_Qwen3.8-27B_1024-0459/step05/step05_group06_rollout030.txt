Now, after binary local search, I need to do soft refinement. The idea is:
1. Start with the binary solution
2. Allow small deviations from 0/1 (e.g., ±ε)
3. Use SLSQP or projected gradient to minimize the max overlap

For the soft refinement, I'll use a different approach than before:
- Use the "active lags" (those achieving the max) to define a smoothed objective
- Use a p-norm approximation: (Σ f_k^p)^(1/p) for large p
- This is smoother than log-sum-exp and might work better with SLSQP

Actually, let me try a completely different approach for the soft part: **cutting plane / elliptical method** for the min-max problem.

The problem is: min max_k f_k(h) subject to constraints.
This is equivalent to: min t subject to f_k(h) ≤ t for all k, 0≤h≤1, Σh=n/2.

This is a convex problem if f_k is convex, but f_k is not convex (it's bilinear).

However, I can use a non-convex approach:
1. Start with a feasible h and current t = max_k f_k(h)
2. Identify active lags: A = {k : f_k(h) ≥ t - ε}
3. Solve: min (1/|A|) Σ_{k∈A} f_k(h) (or min max_{k∈A} f_k(h))
   subject to constraints
4. Update active set
5. Repeat

This is like a cutting plane method.

For step 3, if I minimize the average of active f_k's, each f_k is bilinear, so the average is also bilinear. This is still non-convex, but I can use SLSQP.

def project_feasible(h, n):
    h = np.array(h, dtype=float).copy()
    target = n / 2.0
    h = np.clip(h, 0.0, 1.0)
    for _ in range(500):
        diff = target - np.sum(h)

def smooth_value_grad(x, n, beta):
    dx = 2.0 / n
    corr = np.correlate(x, 1.0 - x, mode='full')
    m = np.max(corr)
    shifted = np.minimum(beta * (corr - m), 0.0)
    exp_vals = np.exp(shifted)
    wsum = np.sum(exp_vals)
    weights = exp_vals / wsum
    val = (m + np.log(wsum) / beta) * dx
    
    ncorr = 2 * n - 1
    grad = np.zeros(n)
    for k in range(ncorr):
        w = weights[k]
        if w < 1e-15:
            continue
        offset = k - (n - 1)
        if offset >= 0:
            npairs = n - offset
            if npairs > 0:
                grad[offset:offset+npairs] += w * (1.0 - x[:npairs])
                grad[:npairs] -= w * x[offset:offset+npairs]
        else:
            aoff = -offset
            npairs = n - aoff
            if npairs > 0:
                grad[:npairs] += w * (1.0 - x[aoff:aoff+npairs])
                grad[aoff:aoff+npairs] -= w * x[:npairs]
    grad *= dx
    return val, grad
