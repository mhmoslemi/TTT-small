For changing h[pa] from 1 to 0:
- In corr at shift s (index n-1+s): 
  - If 0 ≤ pa+s < n: the term h[pa]*(1-h[pa+s]) changes from (1-h[pa+s]) to 0. Delta = -(1-h[pa+s])
  - If 0 ≤ pa-s < n: the term h[pa-s]*(1-h[pa]) changes from 0 to h[pa-s]. Delta = +h[pa-s]

For changing h[pb] from 0 to 1:
  - If 0 ≤ pb+s < n: the term h[pb]*(1-h[pb+s]) changes from 0 to (1-h[pb+s]). Delta = +(1-h[pb+s])
  - If 0 ≤ pb-s < n: the term h[pb-s]*(1-h[pb]) changes from h[pb-s] to 0. Delta = -h[pb-s]

So the total delta for corr at shift s:
delta[s] = -(1-h[pa+s]) [if valid] + h[pa-s] [if valid] + (1-h[pb+s]) [if valid] - h[pb-s] [if valid]

This is O(1) per shift, O(n) total per swap candidate. But we still have O(n²) swap candidates, so O(n³) total per round.

            # Reject
            h[pa] = 1.0
            h[pb] = 0.0

    c_max = np.max(corr)

        ones = np.where(h == 1.0)[0]
        zeros = np.where(h == 0.0)[0]
        n_ones = len(ones)
        n_zeros = len(zeros)
        
        # Precompute delta vectors
        # delta_a[i, j] = effect of changing h[ones[i]] from 1 to 0, at correlation index j
        # delta_b[i, j] = effect of changing h[zeros[i]] from 0 to 1, at correlation index j
        # corr index j corresponds to shift s = j - (n-1)
        
        # For position p, changing 1→0:
        # At shift s: delta = -(1-h[p+s]) [if 0≤p+s<n] + h[p-s] [if 0≤p-s<n]
        # corr index = n-1+s
        
        delta_a = np.zeros((n_ones, 2*n-1))
        delta_b = np.zeros((n_zeros, 2*n-1))
        
        for i, p in enumerate(ones):
            # -(1-h[p+s]) for s where 0≤p+s<n → s in [-p, n-1-p]
            s_range1 = np.arange(max(-p, -(n-1)), min(n-1-p, n-1) + 1)
            idx1 = s_range1 + (n-1)
            valid1 = (p + s_range1 >= 0) & (p + s_range1 < n)
            delta_a[i, idx1[valid1]] -= (1.0 - h[p + s_range1[valid1]])
            
            # +h[p-s] for s where 0≤p-s<n → s in [p-(n-1), p]
            s_range2 = np.arange(max(p-(n-1), -(n-1)), min(p, n-1) + 1)
            idx2 = s_range2 + (n-1)
            valid2 = (p - s_range2 >= 0) & (p - s_range2 < n)
            delta_a[i, idx2[valid2]] += h[p - s_range2[valid2]]
        
        for i, p in enumerate(zeros):

            s_range1 = np.arange(max(-p, -(n-1)), min(n-1-p, n-1) + 1)

            delta_b[i, idx1[valid1]] += (1.0 - h[p + s_range1[valid1]])
            
            # -h[p-s] for valid s
            s_range2 = np.arange(max(p-(n-1), -(n-1)), min(p, n-1) + 1)
            idx2 = s_range2 + (n-1)
            valid2 = (p - s_range2 >= 0) & (p - s_range2 < n)

        best_improve = 0

        best_pb_idx = -1

For the term involving h[pa] as (1-h[m-k+n-1]) (m=pa+k-n+1): valid if max(0, k-n+1) ≤ pa+k-n+1 ≤ min(n-1, k), and 0 ≤ pa ≤ n-1 (always true).
So: 0 ≤ pa+k-n+1 ≤ n-1 → n-1-pa ≤ k ≤ n-1+pa.

OK this is getting complicated. Let me just use a simpler approach in the code: for each pa, compute the delta vector by directly computing which entries of corr are affected and what the delta is.

Actually, the simplest approach that's still efficient:

For a fixed pa, the delta_a[k] for k = 0, 1, ..., 2n-2:
- Only non-zero when either:
  - 0 ≤ pa-k+n-1 < n (the m=pa term is in the sum)
  - 0 ≤ pa+k-n+1 < n (the m=pa+k-n+1 term is in the sum)

The first condition: n-1-pa ≤ k ≤ n-1+pa. Since k ranges [0, 2n-2], this is a range of about 2*pa+1 or 2*(n-1-pa)+1 indices.

The second condition: n-1-pa ≤ k ≤ n-1+pa. Same range!

So delta_a is non-zero for k in [max(0, n-1-pa), min(2n-2, n-1+pa)], which is a contiguous range of about 2*min(pa, n-1-pa)+1 values.

For pa near the center, this is about n values. For pa near the edge, it's less.

In any case, for the vectorized approach, I'll just compute the full delta_a vector (length 2n-1) for each pa, which is O(n) per pa. Total O(n²) per round for all pa's precomputation. Then the inner loop is O(n_zeros * (2n-1)) per pa. Total O(n³) per round.
