If the worst correlation is at lag k, then c_k = sum_m h[m+k]*(1-h[m]).
To reduce c_k, we want to either:

- Change h[m] from 0 to 1 (where h[m+k]=1) → reduces c_k by 1

Wait, that doesn't maintain the sum. Let me think again.

To reduce c_k while maintaining sum(h) = N/2:
- We need to swap: change h[i] from 0 to 1 and h[j] from 1 to 0 for some i, j.
- The effect on c_k depends on the specific positions.

For a swap (i: 0→1, j: 1→0), the change in c_k is:
- If the swap affects the "h[m+k]" term: 
  - If i+k = some valid m: h[i+k] doesn't change, but h[i] does → (1-h[i]) changes from 1 to 0, so we lose h[i+k] from c_k (if i is in the valid range for c_k)
  - If j+k = some valid m: h[j+k] doesn't change, but h[j] does → (1-h[j]) changes from 0 to 1, so we gain h[j+k] to c_k
  - If i = m+k for some m: h[i] = h[m+k] changes from 0 to 1, so we gain (1-h[m]) = (1-h[i-k]) to c_k
  - If j = m+k for some m: h[j] = h[m+k] changes from 1 to 0, so we lose (1-h[m]) = (1-h[j-k]) from c_k

This matches what I derived earlier. The delta for lag k (≥ 0) is:
delta_k = [i-k valid? (1-h[i-k]) : 0] - [j-k valid? (1-h[j-k]) : 0] - [i+k valid? h[i+k] : 0] + [j+k valid? h[j+k] : 0]

For targeted moves: if c_k is the maximum, we want delta_k < 0.
delta_k < 0 when:
- h[i-k] is small (ideally 0) → first term is small
- h[j-k] is large (ideally 1) → second term is large
- h[i+k] is large (ideally 1) → third term is large (negative contribution)
- h[j+k] is small (ideally 0) → fourth term is small

So good candidates for i: positions where h[i-k]=0 and h[i+k]=1 (near a "1→0" transition at distance k)
Good candidates for j: positions where h[j-k]=1 and h[j+k]=0 (near a "0→1" transition at distance k)

def theta_morse(n):
    h = np.zeros(n)
