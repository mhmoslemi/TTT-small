import numpy as np
import time

def compute_c5_binary(h):
    """Compute C5 for a binary sequence h."""
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def simulate_annealing(h0, n, max_iters, T0, T1, rng):
    """Simulated annealing on binary sequences."""
    h = h0.copy()
    best_h = h.copy()
    best_c5 = compute_c5_binary(h)
    T = T0
    
    for it in range(max_iters):
        # Pick a random 1 and a random 0 to swap
        ones = np.where(h == 1)[0]
        zeros = np.where(h == 0)[0]
        a = ones[rng.randint(len(ones))]
        b = zeros[rng.randint(len(zeros))]
        
        # Compute C5 before
        # Apply swap
        h[a] = 0
        h[b] = 1
        c5_new = compute_c5_binary(h)
        
        # Decide
        if c5_new < best_c5:
            best_c5 = c5_new
            best_h = h.copy()
        elif rng.random() < np.exp(-(c5_new - best_c5) / T):
            pass  # accept
        else:
            # reject
            h[a] = 1
            h[b] = 0
        
        # Cool
        T = T0 * (T1 / T0) ** (it / max_iters)
    
    return best_h, best_c5

If I store the current corr array, and I swap h[a] (1→0) and h[b] (0→1), the change in corr is:

The corr at index (n-1+d) is Σ_{i=0}^{n-1-d} h[i]*(1-h[i+d])

The change due to h[a]: 1→0
- If a is in [0, n-1-d] (i.e., a+d < n): the term h[a]*(1-h[a+d]) changes from (1-h[a+d]) to 0. Δ = -(1-h[a+d])
- If a-d is in [0, n-1-d] (i.e., a >= d and a-d < n-d, i.e., a >= d): the term h[a-d]*(1-h[a]) changes from h[a-d]*0=0 to h[a-d]*1=h[a-d]. Δ = +h[a-d]

The change due to h[b]: 0→1
- If b is in [0, n-1-d] (i.e., b+d < n): the term h[b]*(1-h[b+d]) changes from 0 to (1-h[b+d]). Δ = +(1-h[b+d])
- If b-d is in [0, n-1-d] (i.e., b >= d): the term h[b-d]*(1-h[b]) changes from h[b-d]*1=h[b-d] to h[b-d]*0=0. Δ = -h[b-d]

So total change in corr[n-1+d] for d in [1, n-1]:
Δ(d) = -(1-h[a+d])*[a+d<n] + h[a-d]*[a>=d] + (1-h[b+d])*[b+d<n] - h[b-d]*[b>=d]

This is O(1) per d, so O(n) total to compute all changes. Then I update the corr array and recompute the max in O(n).

So per swap: O(n) to compute changes + O(n) to update + O(n) to find max = O(n).
