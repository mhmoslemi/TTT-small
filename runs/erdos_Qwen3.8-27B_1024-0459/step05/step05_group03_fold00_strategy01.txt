    - If initial_h_values provided: load(parent_h); candidate = post_process_initial(parent_h/len(parent_h), n=parent_n)
    - Else generate random candidate via exponential hill-climb with symmetry

b) Optimization phase
    Step 1: Global search in parameter space using bounded L-BFGS-B
        Decision variables: (a,b,c) ∈ [0,1]^3
        Objective function: analytical η(α,β,γ) = max_lag corr(σ(f_exp))
        Gradient: computed via automatic differentiation of the thresholded version
        Reparameterization: scale factors maintain integral during searches

    Step 2: Thresholding projection
        Project solution to valid thresholded form while maintaining integral by:
            Apply threshold to all α such that only top N kept, adjusting N to maintain integral
            Use binary search for optimal fragment count

    Step 3: Micro-localization
        Optimize positions of fragments using continuous relaxation with piecewise linear projection

    Jump condition: Switch to local optimization if improvement below 10^-6

c) Helper functions
    exp_transform(a,b,c): produces continuous base function
    project_temporal(h): 
        h_clipped = np.clip(h,0,1)
        integral = 2 * np.mean(h_clipped)
        balance by linear solver with slack variables
    piecewise_position: calculates optimal positions based on derivative condition
