This is cleaner. Each sweep is O(n_o * n_z) evaluations = O((n/2)²) = O(n²/4). For n=384, that's ~37K evaluations at ~50μs each = ~2 seconds per sweep.

But wait, I'm recomputing the full correlation each time. Can I do better?

When I flip h[i] from 1 to 0 and h[j] from 0 to 1:
- The correlation changes only at shifts related to i and j
- Specifically, corr[k] changes by:
  - Contribution of i: was h[i]*(1-h[i+m]) = 1-h[i+m] (when i is in range), now 0
  - Contribution of j: was h[j]*(1-h[j+m]) = 0 (when j is in range), now 1-h[j+m]
  - Plus the "other side": was h[i+m]*(1-h[i]) = h[i+m], now 0
  - Plus: was h[j+m]*(1-h[j]) = h[j+m]*(1-0) = h[j+m], now h[j+m]*(1-1) = 0
  
Wait, the correlation is:
corr[k] = sum_i h[i] * (1-h[i+k-n+1]) (for valid i)

Let m = k-(n-1). Then corr[k] = sum_i h[i] * (1-h[i+m]) for valid i (where both i and i+m are in [0, n-1]).

When we change h[i₀] from 1 to 0:
- Terms where i = i₀: h[i₀]*(1-h[i₀+m]) goes from 1-h[i₀+m] to 0
- Terms where i+m = i₀, i.e., i = i₀-m: h[i₀-m]*(1-h[i₀]) goes from h[i₀-m] to 0

When we change h[j₀] from 0 to 1:
- Terms where i = j₀: h[j₀]*(1-h[j₀+m]) goes from 0 to 1-h[j₀+m]
- Terms where i+m = j₀, i.e., i = j₀-m: h[j₀-m]*(1-h[j₀]) goes from 0 to 1-h[j₀-m]

So the change in corr[k] (for shift m = k-(n-1)):
Δcorr[k] = -h[i₀+m] - h[i₀-m] + (1-h[j₀+m]) + (1-h[j₀-m])
(for valid indices; 0 for invalid)

After the flip: h'[i₀]=0, h'[j₀]=1, others unchanged.

From h[i₀] going 1→0:
- In the term i=i₀: (1-0)*(1-h[i₀+m]) → 0, change = -(1-h[i₀+m])
- In the term i=i₀-m: h[i₀-m]*(1-1) → h[i₀-m]*(1-0)=h[i₀-m], change = +h[i₀-m]

Wait no. Original: h[i₀-m]*(1-h[i₀]) = h[i₀-m]*0 = 0. New: h[i₀-m]*(1-0) = h[i₀-m]. Change = +h[i₀-m].

From h[j₀] going 0→1:
- In the term i=j₀: 0*(1-h[j₀+m]) → 1*(1-h[j₀+m]), change = +(1-h[j₀+m])
- In the term i=j₀-m: h[j₀-m]*(1-0) → h[j₀-m]*(1-1)=0, change = -h[j₀-m]

So: Δcorr_m = -(1-h[i₀+m]) + h[i₀-m] + (1-h[j₀+m]) - h[j₀-m]

Where we interpret h[x] = 0 if x is out of bounds.
