   - Generate candidate swaps: for each hot lag, find positions where a swap would reduce the correlation at that lag
   - Evaluate top candidates (compute exact new max)
   - Accept the best improving swap
   - Use simulated annealing to escape local minima (accept worsening moves with probability exp(-Δ/T))
   
3. **Continuous refinement**: After finding a good binary solution, do a few steps of gradient-based optimization in the continuous space (allowing values in [0,1]) to potentially shave off a tiny amount.

4. **Multi-resolution**: Try the best pattern at neighboring resolutions (n±2, n±4, etc.)

```python
def swap_delta(h, i, j, n):
    """Compute the change in all correlations when h[i]: 1->0, h[j]: 0->1."""
    delta = np.zeros(2*n-1)
    d_min = -(n-1)
    d_max = n-1
    
    # h[i]: 1 -> 0
    # As first factor: for offset d where 0 <= i+d < n
    d_lo = max(d_min, -i)
    d_hi = min(d_max, n-1-i)
    for d in range(d_lo, d_hi+1):
        # offset d, index m = d + (n-1)
        m = d + (n-1)
        delta[m] -= (1.0 - h[i+d])
    
    # As second factor: for offset d where 0 <= i-d < n
    d_lo = max(d_min, i-n+1)
    d_hi = min(d_max, i)
    for d in range(d_lo, d_hi+1):
        m = d + (n-1)
        delta[m] += h[i-d]
    
    # h[j]: 0 -> 1
    # As first factor: for offset d where 0 <= j+d < n
    d_lo = max(d_min, -j)
    d_hi = min(d_max, n-1-j)
    for d in range(d_lo, d_hi+1):
        m = d + (n-1)
        delta[m] += (1.0 - h[j+d])
    
    # As second factor: for offset d where 0 <= j-d < n
    d_lo = max(d_min, j-n+1)
    d_hi = min(d_max, j)
    for d in range(d_lo, d_hi+1):
        m = d + (n-1)
        delta[m] -= h[j-d]
    
    return delta
```
