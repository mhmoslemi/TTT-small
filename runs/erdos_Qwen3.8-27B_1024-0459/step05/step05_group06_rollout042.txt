Let me also think about whether the bisection is correct. The function f(t) = max_k (A_k + B_k * t) is convex. Its subgradient at t is {B_k : k ∈ argmax}. The minimum is where 0 ∈ ∂f(t), i.e., there exists an active k with B_k = 0, or the subgradient brackets 0 (some active B_k < 0 and some active B_k > 0).

The bisection: if B[argmax] < 0, the function is decreasing at mid, so the minimum is to the right (lo = mid). If B[argmax] > 0, the function is increasing, so minimum is to the left (hi = mid). If B[argmax] = 0, we're at the minimum.

This is correct for convex functions. After 60 bisection steps, we have precision 2^{-60} ≈ 10^{-18}, which is more than enough.

But there's a subtlety: at the minimum, the function might be flat (a whole interval of minimizers). In that case, the bisection converges to some point in that interval, which is fine.
