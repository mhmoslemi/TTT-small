        h = np.clip(h, 0.0, 1.0)

For the continuous case, the objective is:
f(h) = max_k corr[k] * dx

where corr[k] = sum_n h[n] * (1-h[n+m]) for m = k-(n-1).

- As β → ∞, g → f

∂g/∂h[j] = (dx/sum_k exp(β*corr[k]*dx)) * sum_k exp(β*corr[k]*dx) * ∂corr[k]/∂h[j]
= dx * sum_k w_k * ∂corr[k]/∂h[j]

1. Start from the best binary solution (max correlation = M)
2. Try to find a small perturbation δ (with |δ[i]| ≤ ε for all i, sum δ = 0) such that corr[k] + (linearized change) ≤ M for all k where corr[k] = M.

Variables: δ[0], ..., δ[n-1]
Constraints:
- For each k with corr[k] = M: sum_n (δ[n]*(1-h[n+m_k]) - h[n]*δ[n+m_k]) ≤ 0
- sum δ = 0
- -ε ≤ δ[i] ≤ ε (for small ε, to stay in [0,1])
