### 2. Mathematical Specification

**Representation:**
- The function `h` is represented discretely as a NumPy array `h` with `n_points` elements, defined on the interval `[0, 2]` with spacing `dx = 2 / n_points`.
- The overlap is computed via `np.correlate(h, 1-h, mode="full") * dx`.

**Constraints:**
- Each `h[i]` must be between 0 and 1.
- The integral constraint: `sum(h) * dx = 1`, i.e., `sum(h) * (2 / n_points) = 1` so `sum(h) = n_points / 2`.

**Exact Objective:**
- `C_5 = max_k (np.correlate(h, 1-h, mode="full") * dx)`

**Multiresolution MRA Steps:**
1. Choose an initial resolution (e.g., 128) and a wavelet (e.g., Daubechies wavelet of order 4, 'db4').
2. At each resolution `n`, we perform:
   - Forward discrete wavelet transform (DWT) to get approximation and detail coefficients.
   - Hard thresholding on the detail coefficients to denoise.
   - Inverse DWT to get a refined solution.
3. Then, we project the refined solution to a double resolution (e.g., to 256) using interpolation and repeat.

**Wavelet Denoising:**
Use a threshold proportional to the noise level (which can be set by the coder). The threshold is `threshold = sigma * sqrt(2*log(n))`, and the thresholding is hard.

**Mathematical Definition of DWT:**
Given `h` in `R^n`, the DWT using `db4` gives two sets of coefficients: approximation `cA` and details `cD`. The inverse transform recovers `h`.

**Gradient Handling:**
The objective function is non-differentiable (because of the absolute max), so we cannot use traditional gradient descent. Instead, we rely on wavelet coefficients to guide local features.

**Converting to a Step Function:**
The method naturally produces a piecewise constant function (if we stop after sufficient MRA levels). We must ensure the integral constraint is satisfied, and we clip the values to [0,1].

```python
import pywt

def wavelet_denoise(h, wavelet='db4', level=None, threshold_ratio=0.1):
    # h: 1D array of candidate solution
    # wavelet: name of wavelet filter
    # level: decomposition level (if None, chosen automatically)
    # threshold_ratio: fraction of energy used for threshold
    # Returns: denoised h
    n = len(h)
    # Compute wavelet coefficients
    if level is None:
        level = pywt.dwt_max_level(n, wavelet)
    coeffs = pywt.wavedec(h, wavelet, level=level)
    sigma = threshold_ratio * np.median(np.abs(coeffs[-level]))
    # Thresholding: only in det coeffs
    ɳ_coeffs = [coeffs[0]]  # approximation at top level
    for i in range(1, level+1):
        cD = coeffs[i]
        # Calculate threshold for this level
        th = sigma * np.sqrt(2 * np.log(n)) * np.sqrt(np.sum(cD**2) / len(cD))  # adjust for level
        # Hard thresholding
        cD_thr = pywt.threshold(cD, th, 'hard')
        ɳ_coeffs.append(cD_thr)
    # Reconstruction
    ɳ_h = pywt.waverec(ɳ_coeffs, wavelet)
    ɳ_h = np.clip(ɳ_h, 0, 1)
    # Adjust sum to n/2 (projection)
    target = len(ɳ_h) / 2.0  # because dx=2/n, so total integral is (projection) (sum*h)*dx=1 -> sum*h * 2/n =1 -> sum*h = n/2.
    # Instead, we should adjust by projection: proj(h, n) from above plan.
    # But for now, we adjust the sum
    diff = target - np.sum(ɳ_h)
    if abs(diff) > 1e-5:
        # Uniformly add the difference (or scale the entire vector if necessary)
        ɳ_h += diff / len(ɳ_h)
    ɳ_h = np.clip(ɳ_h, 0, 1)
    # Ensure the integral is correct
    total = np.sum(ɳ_h) * 2.0 / len(ɳ_h)
    if abs(total - 1) > 1e-5:
        # Another adjustment: scale h so that integral becomes 1
        scale = 1.0 / total
        ɳ_h *= scale
    return ɳ_h
```
