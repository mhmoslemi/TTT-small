- At t=0, compute active set, check if max Δ_tau ≥ 0 (if so, f is non-decreasing at 0, min is at 0 or later)
- At t=1, compute active set, check if min Δ_tau ≤ 0 (if so, f is non-increasing at 1, min is at 1 or earlier)

Actually the simplest correct approach: evaluate f at t = 0, 0.25, 0.5, 0.75, 1.0 (or more points) and pick the best. Since f is convex, this is guaranteed to find a point within a factor of (1/4) of optimal in the function value... no that's not quite right.

For a convex function on [0,1], the minimum of the piecewise linear interpolation through 5 equally spaced points is within (1/4)²/8 * f'' of the true minimum... that's not helpful without knowing f''.

Let me just use bisection on the subgradient:
1. At t=0: compute g_0 = max_active Δ_tau (right derivative)
2. If g_0 ≥ 0: minimum is at t=0
3. At t=1: compute g_1 = min_active Δ_tau (left derivative)
4. If g_1 ≤ 0: minimum is at t=1
5. Otherwise: binary search for where the derivative crosses 0

For the derivative at t: it's the maximum Δ_tau among lags that are active at t.

This is O(n log n) per line search (O(n) for sorting to find active set, O(log(1/ε)) iterations).

Total per Frank-Wolfe iteration: O(n log n) for subgradient + O(n log n) for vertex + O(n log n) for line search = O(n log n).

For n=384, that's very fast. We can do thousands of iterations.

Now, one issue with Frank-Wolfe: it can be slow to converge (O(1/t) rate). But with the "away steps" variant or with strong Wolfe line search, it can be faster.

Let me also consider **shrinking Frank-Wolfe** (also called "freedium" or "extended Frank-Wolfe"):
- Instead of moving to a vertex, move toward a point in the convex hull of previous vertices
- This can give O(1/t²) rate

- For binary h, swapping 1 at position i with 0 at position j changes corr[τ] by:
  - For τ > 0: -1 if h[i+τ]=0 (we removed a (1,0) pair), +1 if h[j+τ]=0 (we added a (1,0) pair)

Actually, let me think about this more carefully. For binary h:
corr[τ] = count of i such that h[i]=1 and h[i+τ]=0 (for valid i)

When we flip h[i] from 1 to 0 and h[j] from 0 to 1:
- Position i no longer contributes as a "1" source
- Position j now contributes as a "1" source

  So change: +h[i-τ] (for i-τ >= 0)

- Position j was 0, so (1-h[j]) = 1. The term h[j-τ]*(1-h[j]) = h[j-τ]*1 = h[j-τ]. Now h[j]=1, so (1-h[j])=0. The term becomes 0.
  So change: -h[j-τ] (for j-τ >= 0)

Total change in corr[τ] from swapping i (1→0) and j (0→1):
Δcorr[τ] = -1 + h[i+τ] + h[i-τ] - h[j+τ] - h[j-τ] (with appropriate bounds)
(terms are 0 if the index is out of bounds)

Wait, let me redo this more carefully.

Original: corr[τ] = sum_{i: i+τ < n} h[i] * (1-h[i+τ])

After swap (h[i]: 1→0, h[j]: 0→1):

    Δ_source_j = 1 - h'[j+τ] = 1 - h[j+τ] (if j+τ ≠ i) or 1 - 0 = 1 (if j+τ = i)

    new term: h'[i-τ]*(1-h'[i]) = h'[i-τ]*1 = h'[i-τ]
    h'[i-τ] = h[i-τ] unless i-τ = j, in which case h'[i-τ] = 1
    Δ_target_i = h'[i-τ] - 0 = h[i-τ] (if i-τ ≠ j) or 1 (if i-τ = j)
    
  - k = j-τ (if 0 ≤ j-τ < n and j < n):
    old term: h[j-τ]*(1-h[j]) = h[j-τ]*1 = h[j-τ]
    new term: h'[j-τ]*(1-h'[j]) = h'[j-τ]*0 = 0
    Δ_target_j = 0 - h[j-τ] = -h[j-τ]

This is getting complicated with the special cases. Let me simplify by assuming i ≠ j (which they always are since one is 1 and the other is 0) and i+τ ≠ j, i-τ ≠ j, j+τ ≠ i, j-τ ≠ i (which is the common case).

In the generic case:
Δcorr[τ] = (-1 + h[i+τ]) + (1 - h[j+τ]) + h[i-τ] + (-h[j-τ])
          = h[i+τ] - h[j+τ] + h[i-τ] - h[j-τ]

(supposing all indices are valid, otherwise the corresponding term is 0)

For τ = 0:
Δcorr[0] = (1-2*1) + (1-2*0) + ... wait, for τ=0 the formula is different.
corr[0] = sum h[i]*(1-h[i]) = sum h[i] - sum h[i]²
For binary: corr[0] = number of 1s - number of 1s = 0. (Always 0 for binary!)
So Δcorr[0] = 0 always. Good.

For general binary h, the change in corr[τ] from swapping position i (1→0) and j (0→1) is:
Δcorr[τ] = (h[i+τ] - h[j+τ]) + (h[i-τ] - h[j-τ]) (with out-of-bounds terms = 0)

This can be computed in O(1) per lag per swap!

So for a given pair (i,j), the change in C₅ = max_τ corr[τ] * dx is:
- Compute new_corr[τ] = corr[τ] + Δcorr[τ] for all τ
- New C₅ = max(new_corr) * dx

This is O(n) per pair evaluation. With O(n²) pairs, a full evaluation is O(n³) per round. For n=384, that's about 56M operations per round. With a few rounds, this is feasible.

But we can do better: we only need to check if the swap improves C₅. Since C₅ = max corr[τ] * dx, a swap improves C₅ if and only if it reduces the maximum correlation.

A quick check: find the current max corr value M. A swap helps only if it reduces corr[τ] for all τ where corr[τ] = M (or at least the maximum).

Let me implement a fast binary local search:
1. Find all lags τ* where corr[τ*] = M (the maximum)
2. For a swap to be beneficial, it must reduce corr[τ*] for at least one τ* without increasing any other corr above M
3. Efficiently: for each τ*, find swaps that reduce corr[τ*]

For a specific max lag τ*, a swap (i,j) reduces corr[τ*] by:
δ = h[i+τ*] - h[j+τ*] + h[i-τ*] - h[j-τ*]
We want δ < 0, i.e., h[i+τ*] + h[i-τ*] < h[j+τ*] + h[j-τ*]

This means: position i has fewer "adjacent zeros" at distance τ* than position j does.

So the algorithm is:
1. Find max lag(s) τ*
2. For each 1-position i, compute s(i) = h[i+τ*] + h[i-τ*] (number of adjacent 1s at distance τ*)
   Lower s(i) means removing i reduces corr[τ*] more.
3. For each 0-position j, compute s(j) = h[j+τ*] + h[j-τ*]
   Higher s(j) means adding j increases corr[τ*] less.
4. Best swap: minimize s(i) over 1-positions, maximize s(j) over 0-positions
5. Check if the swap improves C₅ (verify no other lag exceeds M)

This is O(n) per round! Much better than O(n³).

Let me now put together the full algorithm:

import numpy as np
from scipy.optimize import minimize
import time

_T0 = 0.0
_BUDGET = 1300.0

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def compute_corr(h):
    return np.correlate(h, 1.0 - h, mode='full')

def remaining():
    return max(0.0, _BUDGET - (time.time() - _T0) - 3.0)

def project_hypersimplex(y, n):
    """Project y onto {x: 0<=x<=1, sum(x)=n/2}"""
    target = n / 2.0
    # Find lambda such that sum(clip(y - lambda, 0, 1)) = target
    lo, hi = y.min() - 1, y.max() + 1
    for _ in range(60):
        mid = (lo + hi) / 2
        s = np.sum(np.clip(y - mid, 0, 1))
        if s > target:
            lo = mid
        else:
            hi = mid
    lam = (lo + hi) / 2
    return np.clip(y - lam, 0, 1)

def frank_wolfe(h, n, max_iters=5000):
    """Frank-Wolfe with exact subgradient for the max correlation."""
    h = h.astype(float).copy()
    best_h = h.copy()
    best_c5 = compute_c5(h)
    
    for it in range(max_iters):
        if remaining() < 5:
            break
        corr = compute_corr(h)
        cmax = np.max(corr)
        # Active lags
        active = (corr >= cmax - 1e-12)
        n_active = np.sum(active)
        
        # Compute subgradient: average of gradients of active lags
        g = np.zeros(n)
        # For each active lag tau, add gradient contribution
        # lag index k in corr array corresponds to tau = k - (n-1)
        for k in np.where(active)[0]:
            tau = k - (n - 1)
            if tau == 0:
                g += 1.0 - 2.0 * h
            elif tau > 0:
                # d[tau][i] = (1-h[i+tau]) * [i+tau<n] - h[i-tau] * [i-tau>=0]
                g[:n-tau] += (1.0 - h[tau:])
                g[tau:] -= h[:n-tau]
            else:
                s = -tau
                g[s:] += (1.0 - h[:n-s])
                g[:n-s] -= h[s:]
        
        g /= n_active
        
        # Find vertex v: 1 for n/2 indices with smallest g
        idx = np.argsort(g)
        v = np.zeros(n)
        v[idx[:n//2]] = 1.0
        
        # Line search
        # f(t) = max_tau (corr[tau] + t * (corr_v[tau] - corr[tau])) * dx
        corr_v = compute_corr(v)
        delta = corr_v - corr
        
        # Binary search for optimal t
        lo_t, hi_t = 0.0, 1.0
        best_t = 0.0
        best_f = np.max(corr)
        
        for _ in range(50):
            mid_t = (lo_t + hi_t) / 2
            f_mid = np.max(corr + mid_t * delta)
            # Check subgradient at mid_t
            active_mid = (corr + mid_t * delta) >= np.max(corr + mid_t * delta) - 1e-12
            slope = np.max(delta[active_mid])  # right derivative
            
            if slope < -1e-10:
                lo_t = mid_t
            elif slope > 1e-10:
                hi_t = mid_t
            else:
                best_t = mid_t
                best_f = f_mid
                break
            if f_mid < best_f:
                best_f = f_mid
                best_t = mid_t
        
        # Also check t=0, 0.5, 1
        for t_check in [0.0, 0.25, 0.5, 0.75, 1.0]:
            f_check = np.max(corr + t_check * delta)
            if f_check < best_f:
                best_f = f_check
                best_t = t_check
        
        h_new = (1 - best_t) * h + best_t * v
        
        c5_new = compute_c5(h_new)
        if c5_new < best_c5:
            best_c5 = c5_new
            best_h = h_new.copy()
            h = h_new.copy()
        else:
            # Stagnation check
            if it > 100 and it % 100 == 0:
                # Try a random direction to escape
                rng = np.random.RandomState(it)
                g_rand = rng.randn(n)
                g_rand -= np.mean(g_rand)
                idx = np.argsort(g_rand)
                v_rand = np.zeros(n)
                v_rand[idx[:n//2]] = 1.0
                h_try = 0.5 * h + 0.5 * v_rand
                h_try = project_hypersimplex(h_try, n)
                c5_try = compute_c5(h_try)
                if c5_try < best_c5:
                    best_c5 = c5_try
                    best_h = h_try.copy()
                    h = h_try.copy()
    
    return best_h, best_c5

def binary_ls_fast(h_bin, n, max_rounds=100):
    """Fast binary local search using O(n) per round."""
    h = (h_bin > 0.5).astype(float).copy()
    dx = 2.0 / n
    best_c5 = compute_c5(h)
    best_h = h.copy()
    
    for rnd in range(max_rounds):
        if remaining() < 5:
            break
        corr = compute_corr(h)
        cmax = np.max(corr)
        active_lags = np.where(corr >= cmax - 1e-12)[0]
        
        best_improve = 0
        best_swap = None
        
        for k in active_lags:
            tau = k - (n - 1)
            if tau == 0:
                continue  # corr[0] is always 0 for binary
            
            # For 1-positions: s(i) = h[i+tau] + h[i-tau] (want to minimize)
            # For 0-positions: s(j) = h[j+tau] + h[j-tau] (want to maximize)
            ones = np.where(h == 1)[0]
            zeros = np.where(h == 0)[0]
            
            # Compute scores
            s_ones = np.zeros(len(ones))
            s_zeros = np.zeros(len(zeros))
            
            for idx_i in range(len(ones)):
                i = ones[idx_i]
                s = 0.0
                if i + tau < n:
                    s += h[i + tau]
                if i - tau >= 0:
                    s += h[i - tau]
                s_ones[idx_i] = s
            
            for idx_j in range(len(zeros)):
                j = zeros[idx_j]
                s = 0.0
                if j + tau < n:
                    s += h[j + tau]
                if j - tau >= 0:
                    s += h[j - tau]
                s_zeros[idx_j] = s
            
            # Best 1 to remove: min s_ones
            # Best 0 to add: max s_zeros
            best_i_idx = np.argmin(s_ones)
            best_j_idx = np.argmax(s_zeros)
            
            i = ones[best_i_idx]
            j = zeros[best_j_idx]
            
            # Verify the swap improves C5
            h[j] = 1.0
            h[i] = 0.0
            new_c5 = np.max(compute_corr(h)) * dx
            h[i] = 1.0
            h[j] = 0.0
            
            improve = best_c5 - new_c5
            if improve > best_improve:
                best_improve = improve
                best_swap = (i, j)
        
        if best_swap is None or best_improve < 1e-12:
            break
        
        i, j = best_swap
        h[i] = 0.0
        h[j] = 1.0
        best_c5 = compute_c5(h)
        best_h = h.copy()
    
    return best_h, best_c5
