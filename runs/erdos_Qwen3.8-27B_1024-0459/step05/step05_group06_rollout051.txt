```python
def slp_step(h, n, active_indices=None, max_active=200):
    """One SLP iteration: linearize and solve LP."""
    import cvxpy as cp
    
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    ncorr = 2 * n - 1
    
    if active_indices is None:
        # Use top max_active correlations
        threshold = corr.max() - 0.1  # within 0.1 of max
        active_indices = np.where(corr >= threshold)[0]
        if len(active_indices) > max_active:
            active_indices = active_indices[np.argsort(-corr[active_indices])[:max_active]]
    
    # Build LP
    h_var = cp.Variable(n)
    t_var = cp.Variable()
    
    constraints = [
        cp.sum(h_var) == n / 2.0,
        h_var >= 0,
        h_var <= 1,
        t_var >= 0
    ]
    
    for k_idx in active_indices:
        offset = k_idx - (n - 1)
        # Linearized constraint: sum_i [(1-h[i+off]^t) * h[i] - h[i]^t * h[i+off] + h[i]^t * h[i+off]^t] * dx <= t
        lhs_coeff = np.zeros(n)
        const_val = 0.0
        
        if offset >= 0:
            for i in range(n - offset):
                lhs_coeff[i] += 1.0 - h[i + offset]
                lhs_coeff[i + offset] += -h[i]
                const_val += h[i] * h[i + offset]
        else:
            a = -offset
            for i in range(a, n):
                lhs_coeff[i] += 1.0 - h[i - a]
                lhs_coeff[i - a] += -h[i]
                const_val += h[i] * h[i - a]
        
        constraint = (lhs_coeff @ h_var + const_val) * dx <= t_var
        constraints.append(constraint)
    
    prob = cp.Problem(cp.Minimize(t_var), constraints)
    prob.solve(solver=CP ECOS or CVXOPT)
    
    if h_var.value is not None:
        return np.clip(h_var.value, 0, 1), t_var.value
    return h, np.max(corr) * dx
```

h[i](1-h[i+d]) ≈ (1-h[i+d]^t)h[i] - h[i]^t h[i+d] + h[i]^t h[i+d]^t

This is a first-order Taylor approximation. The LP will find the point that minimizes t subject to these linearized constraints. But the linearized constraints are only valid at h^t. Moving away from h^t, the linearized constraints may not accurately represent the true quadratic constraints.

The standard SLP approach handles this by:
1. Solving the LP
2. Checking if the LP solution satisfies the true nonlinear constraints
3. If not, restricting the step (trust region or line search)
4. Updating and repeating

For our problem, the true constraint is:
∑_valid h_i(1-h_{i+k}) dx ≤ t

The linearized constraint is:
∑_valid [(1-h_{i+k}^t)h_i - h_i^t h_{i+k} + h_i^t h_{i+k}^t] dx ≤ t
