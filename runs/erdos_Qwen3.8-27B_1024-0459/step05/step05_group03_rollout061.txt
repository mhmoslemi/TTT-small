I need to speed up the correlation evaluation. Options:

2. Incremental update: when we change h[i] from 0 to 1 (or 1 to 0), only the correlations involving index i change. This is O(n) per swap.

Let me implement the incremental update:

When h[i] changes from 0 to 1:
- For each shift s, corr[n-1+s] involves h[i] in at most one position
- Specifically, corr[n-1+s] includes the term h[i] * (1-h[i+s]) if i and i+s are both in range

Let me think more carefully. 

corr[k] = sum over valid i of h[i] * (1-h[i+k-(n-1)])

Let shift = k - (n-1). Then corr[n-1+shift] = sum_i h[i] * (1-h[i+shift]) where 0≤i<n and 0≤i+shift<n.

- For shift s where 0≤i0+s<n: the term h[i0]*(1-h[i0+s]) changes from 0 to (1-h[i0+s])

Actually, let me just define it directly:
Let shift k range from -(n-1) to (n-1).
corr[shift=k] = sum_{i: 0≤i<n, 0≤i+k<n} h[i] * (1 - h[i+k])

When h[i0] changes from 0 to 1:
- In corr[shift=k], the term involving h[i0] as the first factor: h[i0]*(1-h[i0+k])
  - Valid when 0≤i0+k<n, i.e., -i0 ≤ k < n-i0
  - Change: 0 → (1-h[i0+k])

    - If h[i0+k]=1: 0

  - Wait, i0-k ≥ 0 means k ≤ i0, and i0-k < n means k > i0-n.
  - So k ∈ [i0-n+1, i0]
  - Change: (1-h[i0]) goes from 1 to 0, so the term h[i0-k]*(1-h[i0]) goes from h[i0-k]*1 to h[i0-k]*0
  - Change: -h[i0-k] for each valid k

So the total change in corr[k] when h[i0] goes 0→1:
- For k in [max(-i0, i0-n+1), min(n-1-i0, i0)]: both terms contribute
- For k in [i0-n+1, max(-i0, i0-n+1)-1] or (min(n-1-i0, i0), n-1-i0]: only one term

This is getting complex. Let me just use a simpler approach:

**For each swap, recompute only the affected correlations.**

When we swap h[sa] and h[sb] (h[sa]: 1→0, h[sb]: 0→1):
- corr[k] is affected if sa or sb appears in the sum for that k
- sa appears in corr[k] when 0≤sa<n and (0≤sa+k<n for first factor) or (0≤sa-k<n for second factor)
  - First factor: k ∈ [-sa, n-1-sa]
  - Second factor: k ∈ [sa-n+1, sa]
  - Union: k ∈ [min(-sa, sa-n+1), max(n-1-sa, sa)]

For n=384, this is at most 384 values of k to update per position, and we have 2 positions per swap, so at most 768 updates per swap. That's much faster than recomputing all 767 correlations (each of length up to n).

Actually wait, the "recompute" approach is O(n) per k, and there are O(n) affected k values, so it's O(n²) total. That's the same as full recomputation!

The only way to make it O(n) per swap is to update incrementally: for each affected k, the change is just ±1 at most (since only one term changes). Let me reformulate:

When h[sa] goes 1→0 and h[sb] goes 0→1:
For each k in the affected range:
- The old contribution of h[sa] at position sa (as first factor): 1*(1-h[sa+k]) [if valid]
- The new contribution: 0*(1-h[sa+k]) = 0
- The old contribution of h[sb] at position sb (as first factor): 0*(1-h[sb+k]) = 0
- The new contribution: 1*(1-h[sb+k]) [if valid]
- Similarly for second factor positions.

So for each k, delta_corr[k] = 
  [contribution of sa as first factor: -(1-h[sa+k])] + [contribution of sb as first factor: +(1-h[sb+k])]
  + [contribution of sa as second factor: +h[sa-k]] + [contribution of sb as second factor: -h[sb-k]]
  (each term only if the index is valid)

This is O(1) per k, and the number of affected k values is O(n) (at most 2n-1). So total per swap is O(n). 

For n=384, that's about 768 operations per swap. For 100K swaps, that's 77M operations. Very fast!

```python
import numpy as np
from scipy.optimize import minimize
import time

_T0 = 0.0
_BUDGET = 1300.0

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def compute_corr(h):
    return np.correlate(h, 1.0 - h, mode='full')

def project_feasible(h, n):
    h = np.array(h, dtype=float).copy()
    h = np.clip(h, 0.0, 1.0)
    target = n / 2.0
    for _ in range(100):
        diff = target - np.sum(h)
        if abs(diff) < 1e-13:
            break
        free = (h > 1e-10) & (h < 1.0 - 1e-10)
        nf = np.count_nonzero(free)
        if nf > 0:
            h[free] += diff / nf
        else:
            h[:] += diff / n
        h = np.clip(h, 0.0, 1.0)
    return h

def remaining():
    return max(0.0, _BUDGET - (time.time() - _T0) - 3.0)

def round_to_binary(h, n):
    """Round h to binary with exactly n/2 ones."""
    sorted_idx = np.argsort(-h)
    h_bin = np.zeros(n)
    h_bin[sorted_idx[:n // 2]] = 1.0
    return h_bin

def interp_to(src_h, src_n, dst_n):
    if src_n == dst_n:
        return src_h.copy()
    xp = (np.arange(src_n) + 0.5) * 2.0 / src_n
    x_new = (np.arange(dst_n) + 0.5) * 2.0 / dst_n
    return np.interp(x_new, xp, src_h)

def binary_sa(h_bin, n, max_iters=50000, t0=0.02, tend=0.0002, rng=None, accept_2swap=0.3):
    """Simulated annealing for binary solutions."""
    if rng is None:
        rng = np.random.RandomState(0)
    h = (h_bin > 0.5).astype(float).copy()
    best_h = h.copy()
    best_c5 = compute_c5(h)
    curr_c5 = best_c5
    
    for it in range(max_iters):
        if remaining() < 5:
            break
        t = t0 * (tend / t0) ** (it / max_iters)
        
        ones = np.where(h == 1)[0]
        zeros = np.where(h == 0)[0]
        if len(ones) < 2 or len(zeros) < 2:
            break
        
        r = rng.random()
        old_vals = []
        
        if r < (1.0 - accept_2swap):
            # 1-swap
            sa = ones[rng.randint(len(ones))]
            sb = zeros[rng.randint(len(zeros))]
            h[sa] = 0.0
            h[sb] = 1.0
            old_vals = [(sa, 1.0), (sb, 0.0)]
        else:
            # 2-swap
            idx_o = rng.choice(len(ones), size=2, replace=False)
            idx_z = rng.choice(len(zeros), size=2, replace=False)
            for a in idx_o:
                h[ones[a]] = 0.0
                old_vals.append((ones[a], 1.0))
            for b in idx_z:
                h[zeros[b]] = 1.0
                old_vals.append((zeros[b], 0.0))
        
        new_c5 = compute_c5(h)
        delta = new_c5 - curr_c5
        
        if delta < 0 or rng.random() < np.exp(-delta / max(t, 1e-12)):
            curr_c5 = new_c5
            if curr_c5 < best_c5:
                best_c5 = curr_c5
                best_h = h.copy()
        else:
            for (pos, val) in old_vals:
                h[pos] = val
    
    return best_h, best_c5

def binary_local_search(h_bin, n, max_rounds=50):
    """Best-improvement local search: try all 1-swaps, pick best."""
    h = (h_bin > 0.5).astype(float).copy()
    best_h = h.copy()
    best_c5 = compute_c5(h)
    
    for rnd in range(max_rounds):
        if remaining() < 10:
            break
        ones = np.where(h == 1)[0]
        zeros = np.where(h == 0)[0]
        if len(ones) == 0 or len(zeros) == 0:
            break
        
        curr_c5 = compute_c5(h)
        best_improve = 1e-15
        best_swap = None
        
        # Try all 1-swaps
        for ia in range(len(ones)):
            pa = ones[ia]
            h[pa] = 0.0
            for ib in range(len(zeros)):
                pb = zeros[ib]
                h[pb] = 1.0
                nc = np.max(compute_corr(h)) * (2.0/n)
                h[pb] = 0.0
                imp = curr_c5 - nc
                if imp > best_improve:
                    best_improve = imp
                    best_swap = (pa, pb)
            h[pa] = 1.0
        
        if best_swap is None:
            break
        
        pa, pb = best_swap
        h[pa] = 0.0
        h[pb] = 1.0
        new_c5 = compute_c5(h)
        if new_c5 < best_c5:
            best_c5 = new_c5
            best_h = h.copy()
        else:
            break
    
    return best_h, best_c5

def slsqp_smooth(h, n, beta, maxiter=300):
    """SLSQP with log-sum-exp smooth max."""
    h0 = project_feasible(h, n)
    bounds = [(0.0, 1.0)] * n
    dx = 2.0 / n
    
    def obj(x):
        corr = compute_corr(x)
        m = np.max(corr)
        sh = np.clip(beta * (corr - m), -50.0, 50.0)
        ex = np.exp(sh)
        return (m + np.log(np.sum(ex)) / beta) * dx
    
    def grad(x):
        corr = compute_corr(x)
        m = np.max(corr)
        sh = np.clip(beta * (corr - m), -50.0, 50.0)
        ex = np.exp(sh)
        w = ex / np.sum(ex) * dx
        n_local = len(x)
        g = np.zeros(n_local)
        for k in range(2 * n_local - 1):
            wk = w[k]
            if wk < 1e-16:
                continue
            s = k - (n_local - 1)
            if s >= 0:
                np_ = n_local - s
                g[s:s+np_] += wk * (1.0 - x[:np_])
                g[:np_] -= wk * x[s:s+np_]
            else:
                a = -s
                np_ = n_local - a
                g[:np_] += wk * (1.0 - x[a:a+np_])
                g[a:a+np_] -= wk * x[:np_]
        return g
    
    def con(x):
        return np.sum(x) - n/2.0
    
    def con_j(x):
        return np.ones(n)
    
    try:
        res = minimize(obj, h0, jac=grad, method='SLSQP',
                       bounds=bounds,
                       constraints=[{'type': 'eq', 'fun': con, 'jac': con_j}],
                       options={'maxiter': maxiter, 'ftol': 1e-14, 'iprint': 0})
        if res.fun < obj(h0) - 1e-16:
            return project_feasible(res.x, n)
    except Exception:
        pass
    return h0
```

```python
def binary_partial_ls(h_bin, n, max_rounds=50, candidates_per_round=500):

    best_h = h.copy()
    best_c5 = compute_c5(h)
    rng = np.random.RandomState(123)

        if remaining() < 5:
            break

        zeros = np.where(h == 0)[0]
        if len(ones) == 0 or len(zeros) == 0:
            break

        best_improve = 1e-15
        best_swap = None
        
        n_try = min(candidates_per_round, len(ones) * len(zeros))
        for _ in range(n_try):
            ia = rng.randint(len(ones))
            ib = rng.randint(len(zeros))
            pa = ones[ia]
            pb = zeros[ib]
            h[pa] = 0.0
            h[pb] = 1.0
            nc = compute_c5(h)
            h[pb] = 0.0
            h[pa] = 1.0
            imp = curr_c5 - nc
            if imp > best_improve:
                best_improve = imp
                best_swap = (pa, pb)
        
        if best_swap is None:
            break
        
        pa, pb = best_swap
        h[pa] = 0.0
        h[pb] = 1.0
        new_c5 = compute_c5(h)
        if new_c5 < best_c5:
            best_c5 = new_c5
            best_h = h.copy()
        else:
            break
```

```python
def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)


def compute_corr(h):
    return np.correlate(h, 1.0 - h, mode='full')


def project_feasible(h, n):
    h = np.array(h, dtype=float).copy()
    h = np.clip(h, 0.0, 1.0)
    target = n / 2.0
    for _ in range(100):
        diff = target - np.sum(h)
        if abs(diff) < 1e-13:
            break
        free = (h > 1e-10) & (h < 1.0 - 1e-10)
        nf = np.count_nonzero(free)
        if nf > 0:
            h[free] += diff / nf
        else:
            h[:] += diff / n
        h = np.clip(h, 0.0, 1.0)

def slsqp_smooth(h, n, beta, maxiter=300):
    h0 = project_feasible(h, n)
    bounds = [(0.0, 1.0)] * n
    dx = 2.0 / n

    def obj(x):
        corr = compute_corr(x)
        m = np.max(corr)
        sh = np.clip(beta * (corr - m), -50.0, 50.0)
        ex = np.exp(sh)
        return (m + np.log(np.sum(ex)) / beta) * dx

    def grad(x):
        corr = compute_corr(x)
        m = np.max(corr)
        sh = np.clip(beta * (corr - m), -50.0, 50.0)
        ex = np.exp(sh)
        w = ex / np.sum(ex) * dx
        nl = len(x)
        g = np.zeros(nl)
        for k in range(2 * nl - 1):
            wk = w[k]
            if wk < 1e-16:
                continue
            s = k - (nl - 1)
            if s >= 0:
                np_ = nl - s
                g[s:s + np_] += wk * (1.0 - x[:np_])
                g[:np_] -= wk * x[s:s + np_]
            else:
                a = -s
                np_ = nl - a
                g[:np_] += wk * (1.0 - x[a:a + np_])
                g[a:a + np_] -= wk * x[:np_]
        return g

    def con(x):
        return np.sum(x) - n / 2.0

    def con_j(x):
        return np.ones(n)

    try:
        res = minimize(obj, h0, jac=grad, method='SLSQP',
                       bounds=bounds,
                       constraints=[{'type': 'eq', 'fun': con, 'jac': con_j}],
                       options={'maxiter': maxiter, 'ftol': 1e-14, 'iprint': 0})
        if res.fun < obj(h0) - 1e-16:
            return project_feasible(res.x, n)
    except Exception:
        pass
    return h0
```
