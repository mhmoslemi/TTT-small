- If p < n-k (p is a valid first index): term p changes from t*(1-h[p+k]) to s*(1-h[p+k]), change = (s-t)*(1-h[p+k])
- If p ≥ k (p is a valid second index, p = i+k where i = p-k): term p-k changes from h[p-k]*(1-t) to h[p-k]*(1-s), change = h[p-k]*(t-s)

So total change in c(k):
Δc(k) = (s-t) * [(1-h[p+k]) * [p < n-k] - h[p-k] * [p ≥ k]] * dx

This is LINEAR in (s-t)! So for a fixed k, c(k) is linear in h[p].

BUT: we're taking the MAX over all k. So the objective max_k c(k) is the max of linear functions of h[p], which is convex in h[p]. The coordinate descent for minimizing a convex function is well-behaved.

For the coordinate descent, when we change h[p] from t to s:
new_c(k) = old_c(k) + (s-t) * L(k,p) * dx

where L(k,p) = (1-h[p+k]) * [p < n-k] - h[p-k] * [p ≥ k] (for k > 0; similar for k < 0)

So the new objective is max_k [old_c(k) + (s-t) * L(k,p) * dx]

This is a 1D convex optimization in s! We can solve it exactly.

The function f(s) = max_k [C_k + (s-t) * L_k * dx] where C_k = old_c(k) and L_k are constants.

This is the max of linear functions of s, which is a piecewise-linear convex function. The minimum is at the point where the upper envelope changes slope from negative to positive.

We can find this by:
1. Computing all L_k values
2. Finding the range of s where each k is the active one
3. Finding the minimum

Or more practically:
- f(s) = max_k [C_k + (s-t) * L_k * dx]
- f'(s) = L_{k*(s)} * dx where k*(s) is the active constraint
- At the minimum, f'(s) changes sign, meaning the active constraint's L_k = 0 or there's a kink.

Actually, the minimum of max of linear functions occurs where the subgradient contains 0. The subgradient at s is convex hull of {L_k * dx : k is active at s}.

A practical approach:
1. Evaluate f at s = t (current), s = 0, s = 1
2. Use ternary search (or binary search on the derivative) to find the minimum

Since f is piecewise linear convex, we can use a "bisection on slope" approach:
- The slope of f at any point is L_{k*} * dx where k* is the active constraint
- As s increases, the active constraint changes, and the slope is non-decreasing
- We want the slope to cross 0

This is much faster than the golden section search in the previous code!

            # c_k = sum_{valid p} h[p] * (1-h[p+o]) * dx
            # 
            # h[i] appears in c_k when:
            # (a) i + o is in [0, n-1]: h[i] is the first factor, coefficient of h[i] is (1-h[i+o])

                best_f = f1

            if best_u != 0.0:

                lo = min(0.0, best_u) - 0.01

                hi = min(hi, u_hi)

                gr = (np.sqrt(5.0) - 1.0) / 2.0
                a = u_lo
                b = u_hi
                c = b - gr * (b - a)
                d = a + gr * (b - a)
                fc = f_at(c)
                fd = f_at(d)
                for _ in range(40):
                    if b - a < 1e-12:
                        break
                    if fc < fd:
                        b = d
                        d = c
                        fd = fc
                        c = b - gr * (b - a)
                        fc = f_at(c)
                    else:
                        a = c
                        c = d
                        fc = fd
                        d = a + gr * (b - a)
                        fd = f_at(d)
                
                u_opt = (a + b) / 2.0
                f_opt = f_at(u_opt)
                if f_opt < best_f:
                    best_f = f_opt
                    best_u = u_opt
            
            s_opt = t + best_u

                best_corr = compute_corr(best)
                best_c5 = compute_c5(best)
                improved = True
        
        if not improved:
            break
    
    return best, best_c5

    corr = np.correlate(h, 1.0 - h, mode='full')

def project_feasible(h, n):

    h = np.clip(h, 0.0, 1.0)

        if abs(diff) < 1e-15:
            break
        mask = (h > 1e-14) & (h < 1.0 - 1e-14)
        cnt = int(np.sum(mask))
        if cnt > 0:
            h[mask] += diff / cnt
        elif diff > 0:
            idx = np.argmin(h)
            h[idx] = np.clip(h[idx] + diff, 0.0, 1.0)
        else:
            idx = np.argmax(h)

        cnt = int(np.sum(free))
        if cnt > 0:
            h[free] += diff / cnt
            h = np.clip(h, 0.0, 1.0)
    return h

    return max(0.0, _BUDGET_S - (time.time() - _START_TIME) - 3.0)

def smooth_value_grad(x, n, beta):
    dx = 2.0 / n
    corr = np.correlate(x, 1.0 - x, mode='full')
    m = np.max(corr)
    shifted = np.minimum(beta * (corr - m), 0.0)
    exp_vals = np.exp(shifted)
    wsum = np.sum(exp_vals)
    weights = exp_vals / wsum
    val = (m + np.log(wsum) / beta) * dx
    ncorr = 2 * n - 1
    grad = np.zeros(n)
    for k in range(ncorr):
        w = weights[k]
        if w < 1e-15:
            continue
        offset = k - (n - 1)
        if offset >= 0:
            npairs = n - offset
            if npairs > 0:
                grad[offset:offset + npairs] += w * (1.0 - x[:npairs])
                grad[:npairs] -= w * x[offset:offset + npairs]
        else:
            aoff = -offset
            npairs = n - aoff
            if npairs > 0:
                grad[:npairs] += w * (1.0 - x[aoff:aoff + npairs])
                grad[aoff:aoff + npairs] -= w * x[:npairs]
    grad *= dx
    return val, grad

    return smooth_value_grad(x, _N_OPT, _BETA_OPT)[0]

def _grad_fn(x):
    return smooth_value_grad(x, _N_OPT, _BETA_OPT)[1]

def _con_fun(x):
    return np.sum(x) - _N_OPT / 2.0

def _con_jac(x):
    return np.ones(_N_OPT)

def slsqp_optimize(h, n, beta, maxiter=400):
    global _N_OPT, _BETA_OPT
    _N_OPT = n
    _BETA_OPT = beta
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': _con_fun, 'jac': _con_jac}]
    c5_before = compute_c5(h)
    try:
        res = minimize(_obj_fn, h, jac=_grad_fn, method='SLSQP',
                      bounds=bounds, constraints=cons,
                      options={'maxiter': maxiter, 'ftol': 1e-16, 'iprint': 0})

            c5_trial = compute_c5(trial)
            if c5_trial <= c5_before + 1e-13:
                return trial
    except Exception:
        pass
    return h.copy()
