Let me provide the gradient. The smooth max objective is:
f(h) = (2/n) * [m + (1/β) * log(Σ exp(β(c_k - m)))]

where m = max(c) and c = correlate(h, 1-h).

∂f/∂h[j] = (2/n) * (1/β) * Σ_k exp(β(c_k - m)) * ∂c_k/∂h[j] / Σ_k exp(β(c_k - m))

Let w_k = exp(β(c_k - m)) / Σ_j exp(β(c_j - m)) (normalized weights)

Then ∂f/∂h[j] = (2/n) * Σ_k w_k * ∂c_k/∂h[j]

And ∂c_k/∂h[j] where c_k = c_full[n-1+k] = Σ_i h[i+k](1-h[i]):
- h[j] appears in h[i+k] when i+k=j → i=j-k: ∂/∂h[j] = (1-h[j-k])
- h[j] appears in (1-h[i]) when i=j: ∂/∂h[j] = -h[j+k]

So ∂c_k/∂h[j] = (1-h[j-k])·[0≤j-k<n] - h[j+k]·[0≤j+k<n]

This is O(n) per (j,k) pair, and we need it for all j (n values) and all k (2n-1 values). Total: O(n²) per gradient evaluation.

For n=256: O(65K) per gradient. 1000 SLSQP iterations: 65M. Fast!

```python
def _c_smooth_grad(x):
    n = _g_n
    c = np.correlate(x, 1.0 - x, mode='full')
    m = np.max(c)
    sh = _g_beta * (c - m)
    sh = np.clip(sh, -500.0, 0.0)
    w = np.exp(sh) / np.sum(np.exp(sh))
    
    # Gradient: (2/n) * sum_k w_k * dc_k/dx[j]
    # dc_k/dx[j] = (1-x[j-k])*[0<=j-k<n] - x[j+k]*[0<=j+k<n]
    grad = np.zeros(n)
    for k in range(-(n-1), n):
        if w[n-1+k] < 1e-15:
            continue
        for j in range(n):
            val = 0.0
            jk = j - k
            if 0 <= jk < n:
                val += (1.0 - x[jk])
            jpk = j + k
            if 0 <= jpk < n:
                val -= x[jpk]
            grad[j] += w[n-1+k] * val
    
    return (2.0 / n) * grad
```

This is O(n²) per gradient (the k loop is 2n-1 values, j loop is n values, and we skip most k due to the weight threshold). With the weight threshold, typically only O(1) to O(sqrt(n)) lags have significant weight, so it's actually O(n * sqrt(n)) ≈ O(n^1.5).

For n=256: about 4000 operations per gradient. Very fast!

                    best_val = cv
            
            if best_val != old_j:
                h[j] = best_val
                h[n-1] = target - np.sum(h[:n-1])
                h = np.clip(h, 0.0, 1.0)
                h = project_feasible(h, n)
                improved = True
        
        if not improved:
            break
    
    return h

def run(seed=42, budget_s=1300, **kwargs):
    t_start = time.time()
    rng = np.random.RandomState(seed)
    
    best_h = None
    best_c5 = float('inf')
    best_n = 0
    
    # Get parent
    try:
        ph = np.array(initial_h_values, dtype=float)
        if len(ph) > 0:
            best_h = ph.copy()
            best_n = len(ph)
            best_c5 = compute_c5(ph)
    except NameError:
        pass
    except Exception:
        pass
    
    if best_h is None:
        best_n = 192
        best_h = np.ones(best_n) * 0.5
        best_c5 = compute_c5(best_h)
    
    def time_left():
        return max(0.0, budget_s - (time.time() - t_start) - 5.0)
    
    # Helper: interpolate to new resolution
    def interp_h(h, n_from, n_to):
        xp = (np.arange(n_from) + 0.5) * 2.0 / n_from
        xn = (np.arange(n_to) + 0.5) * 2.0 / n_to
        return project_feasible(np.interp(xn, xp, h), n_to)
    
    # Phase 1: SLSQP at parent resolution
    if time_left() > 30:
        h_opt = slsqp_optimize(best_h, best_n, time_left() * 0.1)
        c5 = compute_c5(h_opt)
        if c5 < best_c5:
            best_c5 = c5
            best_h = h_opt.copy()
