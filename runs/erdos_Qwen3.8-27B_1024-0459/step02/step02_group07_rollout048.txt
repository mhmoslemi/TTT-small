Let me also think about the log-sum-exp approach more carefully. Instead of minimizing max_m f_m(h), I minimize:
$g_\epsilon(h) = \epsilon \log \sum_m \exp(f_m(h)/\epsilon)$

As $\epsilon \to 0$, $g_\epsilon \to \max_m f_m$. For finite $\epsilon$, this is smooth and we can use gradient methods.

The gradient of $g_\epsilon$ is:
$\nabla g_\epsilon = \sum_m w_m \nabla f_m$ where $w_m = \exp(f_m/\epsilon) / \sum_k \exp(f_k/\epsilon)$

This is a weighted average of the gradients of the individual f_m, weighted by softmax. As $\epsilon \to 0$, the weights concentrate on the argmax.

This is a great approach because it's smooth and we can use L-BFGS or similar methods.

For the constraint $\sum h = n/2$, I'll use a penalty or handle it via projection.

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return np.max(corr) * dx

def get_corr(h):
    return np.correlate(h, 1.0 - h, mode='full')

def make_feasible(h, n):
    h = np.array(h, dtype=float).copy()
    h = np.clip(h, 0.0, 1.0)
    target = n / 2.0
    for _ in range(2000):
        s = np.sum(h)
        diff = target - s
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            mask = h < 1.0 - 1e-14
            cnt = np.count_nonzero(mask)
            if cnt == 0:
                break
            h[mask] += diff / cnt
        else:
            mask = h > 1e-14
            cnt = np.count_nonzero(mask)
            if cnt == 0:
                break
            h[mask] += diff / cnt
        h = np.clip(h, 0.0, 1.0)
    return h

def interpolate_to_n(h_src, n_dst):
    if len(h_src) < 2:
        return np.ones(n_dst) * 0.5

    x_new = np.linspace(0.0, 2.0, n_dst, endpoint=False)
    h_interp = np.interp(x_new, x_old, h_src)
    return make_feasible(h_interp, n_dst)

def coord_descent(h_init, n, max_passes, time_limit):

    dx = 2.0 / n

    t0 = time.time()
    n_corr = 2 * n - 1
    
    for p in range(max_passes):
        if time.time() - t0 > time_limit:
            break
        
        for j in range(n):
            mf_lo = max(0, n - 1 - j)
            mf_hi = min(2 * n - 2, 2 * n - 2 - j)
            ms_lo = max(0, j + 1)
            ms_hi = min(2 * n - 2, n - 1 + j)

                a[idx] += (-h[jm])
