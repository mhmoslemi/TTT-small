corr[k] = sum_{i} h[i] * (1-h[i+k]) for valid i (where both i and i+k are in [0,n))

For mode='full', the shifts go from -(n-1) to (n-1). For a given shift s:
corr[s] = sum_{i: 0<=i<n and 0<=i+s<n} h[i] * (1-h[i+s])

This is quadratic in h (because of the h[i]*h[i+s] term). So the problem is:
maximize corr[s] over all s, minimize that maximum
subject to sum(h) = n/2, 0 <= h <= 1

This is a min-max quadratic program, which is non-convex.

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def make_feasible(h, n):
    h = np.array(h, dtype=float).copy()
    h = np.clip(h, 0.0, 1.0)
    target = n / 2.0
    for _ in range(1000):
        s = np.sum(h)
        diff = target - s
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            mask = h < 1.0 - 1e-14
            cnt = np.count_nonzero(mask)
            if cnt == 0:
                break
            h[mask] += diff / cnt
        else:
            mask = h > 1e-14
            cnt = np.count_nonzero(mask)
            if cnt == 0:
                break
            h[mask] += diff / cnt
        h = np.clip(h, 0.0, 1.0)
