We want to minimize f(t) = max_k (B_k + t*A_k) over t ∈ [0,1].

f(t) is convex (max of affine functions). The subgradient at t is A_k for the k that achieves the max (or the convex hull of such A_k values).

For a convex function, the minimum occurs where 0 is in the subgradient, i.e., where some active A_k values straddle 0.

Binary search:
- If all active A_k > 0, the function is increasing at t, so decrease t (hi = mid)
- If all active A_k < 0, the function is decreasing at t, so increase t (lo = mid)
- If straddling 0, we're at the minimum

The previous code uses: if mean(A[active]) > 0: hi = mid; elif < 0: lo = mid.

This is correct for the convex case. ✓

If A_k < 0, increasing t decreases the active constraint, f is decreasing → increase t → lo = mid. ✓

def slsqp_polish(h, n, max_iter=5000):
    if n > 300:
        return None, None
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': lambda x: np.sum(x) - n / 2.0}]

    def obj(x):
        return float(np.max(np.correlate(x, 1.0 - x, mode='full')))

    try:
        res = minimize(obj, h, method='SLSQP', bounds=bounds,
                       constraints=cons, options={'maxiter': max_iter, 'ftol': 1e-14})
        if res.fun < 1e10:
            h_out = make_feasible(res.x, n)
            return h_out, compute_c5(h_out)
    except Exception:
        pass
    return None, None


def generate_structured_inits(n, rng):
    inits = []
    if n % 4 == 0:
        inits.append(np.tile([1.0, 1.0, 0.0, 0.0], n // 4).copy())
        inits.append(np.tile([1.0, 0.0, 0.0, 1.0], n // 4).copy())
    if n % 2 == 0:
        h_block = np.zeros(n)
        h_block[:n // 4] = 1.0
        h_block[n // 2:n // 2 + n // 4] = 1.0
        inits.append(h_block)
    # Thue-Morse
    h_tm = np.zeros(n)
    for i in range(n):
        h_tm[i] = 1.0 if bin(i).count('1') % 2 == 0 else 0.0
    inits.append(make_feasible(h_tm, n))
    # Random
    inits.append(make_feasible(rng.rand(n) * 2.0, n))
    # Golay-like (if power of 2)
    if n > 0 and (n & (n - 1)) == 0:
        m = n
        g = 1
        while m > 1:
            h_g = np.zeros(len(g))
            h_g[:len(g)//2] = g
            g = np.concatenate([g, 1.0 - g]) if len(g) > 1 else g
            m //= 2
        g = np.resize(g, n)
        inits.append(make_feasible(g, n))
    return inits
