  = h_j - h_j*h_{j+k} + h_{j-k} - h_{j-k}*h_j
  = h_j(1 - h_{j+k} - h_{j-k}) + h_{j-k}
  
  So corr[k] = A_k + h_j * (1 - h_{j+k} - h_{j-k}) + h_{j-k}
  
  This is LINEAR in h_j! The coefficient is (1 - h_{j+k} - h_{j-k}).
  
  So for each k, corr[k] as a function of h_j is:
  corr[k] = B_k + c_k * h_j
  
  where c_k = (1 - h_{j+k} - h_{j-k}) and B_k is everything else.
  
  Therefore, max_k corr[k] as a function of h_j is:
  max_k (B_k + c_k * h_j)
  
  which is the max of linear functions of h_j, i.e., a convex piecewise-linear function of h_j!
  
  To minimize this over h_j ∈ [0,1] (with the sum constraint handled by adjusting another variable or by a Lagrange multiplier), we just need to find the minimum of a convex piecewise-linear function, which occurs at a breakpoint or at the boundary.

This is great! Coordinate descent is exact (for the 1D subproblem) and the subproblem is trivial.

**Optimized coordinate descent:**
For each coordinate j:
  1. Compute c_k = (1 - h_{j+k} - h_{j-k}) for all valid k
     (Note: h_{j+k} is 0 if j+k is out of bounds, similarly for h_{j-k})
  2. Compute B_k = corr[k] - h_j * c_k (the current corr minus the h_j contribution)
  3. The function to minimize is max_k (B_k + c_k * t) for t ∈ [0,1]
  4. This is minimized at t = 0, t = 1, or at a breakpoint where B_a + c_a*t = B_b + c_b*t for two active k values
  5. Find the optimal t* (with the constraint that sum(h) is maintained)

Wait, the sum constraint complicates things. If I change h_j, I need to adjust another h_i to maintain the sum. This makes it a 2D subproblem.

Alternative: Use a Lagrange multiplier for the sum constraint. The Lagrangian subproblem for coordinate j is:
min_{t ∈ [0,1]} max_k (B_k + c_k * t) + λ * t

The λ term is linear, so the function is still convex piecewise-linear. The minimum is at a breakpoint or boundary.

After finding t*, update λ to drive the sum toward n/2.

This is doable but complex. Let me simplify:

**Simpler coordinate descent:**
1. For coordinate j, compute the optimal t ignoring the sum constraint
2. After sweeping all coordinates, project back to the sum constraint (distribute the excess deficit uniformly or to the free variables)
3. Repeat

This is approximate but should work well in practice.

Actually, an even simpler approach: 

**Greedy 1D coordinate descent with sum fix:**
1. Pick coordinate j
2. Compute optimal t ∈ [0,1] for h_j (minimizing max corr, ignoring sum)
3. Set h_j = t
4. Fix the sum: distribute the change (t - old_h_j) among all other coordinates proportionally
5. Repeat for next j

This maintains feasibility after each step.

Let me code this up. The key computation is: given c_k and B_k for all k, find t ∈ [0,1] minimizing max_k (B_k + c_k * t).

Since this is a 1D convex problem, I can:
- Find the breakpoints: t = (B_a - B_b) / (c_b - c_a) for all pairs (a,b) where c_a ≠ c_b
- Sort breakpoints in [0,1]
- Evaluate at each breakpoint and at 0, 1
- Return the t with minimum value

For n=160, there are 2n-1 = 319 values of k, so O(n²) breakpoints, O(n² log n) sort, O(n²) evaluations. Total O(n²) per coordinate. For all n coordinates: O(n³) per sweep. For n=160: about 4M per sweep. Very fast.

def project_sum(h, target):
    """Project h (already in [0,1]) to have sum = target, staying in [0,1]."""
    h = h.copy()
    for _ in range(20):
        diff = target - np.sum(h)
        if abs(diff) < 1e-14:
            break
        free = (h > 1e-10) & (h < 1.0 - 1e-10)
        if np.any(free):
            h[free] += diff / np.sum(free)
        else:

            if diff > 0:

                h[zeros] += diff / max(1, np.sum(zeros))
            else:
                ones = (h > 0.5)
                h[ones] += diff / max(1, np.sum(ones))
        h = np.clip(h, 0, 1)
    return h

    return project_sum(h, n / 2.0)

def optimal_1d(B, c, h_min=0.0, h_max=1.0):
    """Find t in [h_min, h_max] minimizing max_k (B[k] + c[k]*t)."""
    # Evaluate at boundaries
    best_t = h_min
    best_val = np.max(B + c * h_min)
    val_max = np.max(B + c * h_max)
    if val_max < best_val:
        best_t = h_max
        best_val = val_max
    
    # Find breakpoints
    # Breakpoint between lines a and b: t = (B[a]-B[b])/(c[b]-c[a])
    n_lines = len(B)
    breakpoints = set()
    breakpoints.add(h_min)
    breakpoints.add(h_max)
    
    # O(n²) breakpoints - for n=319, this is ~100K, fine
    for a in range(n_lines):
        for b in range(a+1, n_lines):
            denom = c[b] - c[a]
            if abs(denom) > 1e-15:
                t = (B[a] - B[b]) / denom
                if h_min < t < h_max:
                    breakpoints.add(t)
    
    # Evaluate at all breakpoints
    for t in breakpoints:
        val = np.max(B + c * t)
        if val < best_val - 1e-15:
            best_val = val
            best_t = t
    
    return best_t

                # Fix sum
                h = project_sum(h, target)

    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return np.max(corr) * dx

def compute_corr(h):
    return np.correlate(h, 1.0 - h, mode='full')

def project_sum(h, target):
    h = np.array(h, dtype=float).copy()
    h = np.clip(h, 0.0, 1.0)
    for _ in range(50):
        diff = target - np.sum(h)
        if abs(diff) < 1e-13:
            break
        free = (h > 1e-12) & (h < 1.0 - 1e-12)
        nfree = np.sum(free)
        if nfree > 0:
            h[free] += diff / nfree
        else:
            if diff > 0:
                mask = h < 1.0
            else:
                mask = h > 0.0
            nmask = np.sum(mask)
            if nmask > 0:

    if src_n == dst_n:
        return src_h.copy()
    xp = (np.arange(src_n) + 0.5) * 2.0 / src_n
    x_new = (np.arange(dst_n) + 0.5) * 2.0 / dst_n
    return np.interp(x_new, xp, src_h)

    return max(0.0, _BUDGET_S - (time.time() - _START_TIME))

    """Compute c[k] = d(corr[k])/d(h[j]) for all k."""
    n = len(h)
    n_corr = 2 * n - 1
    c = np.zeros(n_corr)

    k1s = n - 1 - j

    # s from j-(n-1) to j, k = s+(n-1) from j to n-1+j
    # h[j-s] for s=j-(n-1),...,j is h[n-1],h[n-2],...,h[0]
    k2s = j
    k2e = n - 1 + j
    c[k2s:k2e+1] -= h[::-1]
    
    return c

def solve_1d(B, c):
    """Find t in [0,1] minimizing max_k (B[k] + c[k]*t)."""
    def f(t):
        return np.max(B + c * t)
    
    # Coarse search
    ts = np.linspace(0, 1, 200)
    vals = np.array([f(t) for t in ts])
    best_idx = np.argmin(vals)
    
    # Refine around the best
    if best_idx == 0:
        lo, hi = 0, ts[1]
    elif best_idx == len(ts) - 1:
        lo, hi = ts[-2], 1
    else:
        lo, hi = ts[best_idx - 1], ts[best_idx + 1]
    
    res = minimize_scalar(f, bounds=(lo, hi), method='bounded',
                          options={'xatol': 1e-10})
    return res.x

def coord_descent(h, n, max_sweeps=100, rng=None):
    """Coordinate descent with exact 1D subproblem."""
    if rng is None:
        rng = np.random.default_rng(0)
    h = h.copy()
    target = n / 2.0
    best_c5 = compute_c5(h)
    
    for sweep in range(max_sweeps):
        if remaining_time() < 5:
            break
        order = rng.permutation(n)
        any_change = False
        
        for j in order:
            if remaining_time() < 2:
                break
            c = compute_c_vec(h, j)
            corr = compute_corr(h)
            B = corr - h[j] * c
            
            t_opt = solve_1d(B, c)
            
            if abs(t_opt - h[j]) > 1e-10:
                h[j] = t_opt
                h = project_sum(h, target)
                any_change = True
                
                new_c5 = compute_c5(h)
                if new_c5 < best_c5:
                    best_c5 = new_c5
        
        if not any_change:
            break
    
    return h, best_c5

def subgradient_descent(h, n, max_iter=10000, lr_init=0.1, rng=None):
    """Subgradient descent on the max-correlation objective."""
    if rng is None:
        rng = np.random.default_rng(1)
    h = h.copy()
    target = n / 2.0
    dx = 2.0 / n
    best_c5 = compute_c5(h)
    best_h = h.copy()
    
    lr = lr_init
    momentum = 0.5
    v = np.zeros(n)
    
    for it in range(max_iter):
        if remaining_time() < 5:
            break
        corr = compute_corr(h)
        k_max = np.argmax(corr)
        
        # Subgradient at k_max
        s = k_max - (n - 1)
        grad = np.zeros(n)
        for j in range(n):
            g = 0.0
            if 0 <= j + s < n:
                g += (1 - h[j + s])
            if 0 <= j - s < n:
                g -= h[j - s]
            grad[j] = g
        
        # Center the gradient (for the sum constraint)
        grad -= np.mean(grad)
        
        v = momentum * v + (1 - momentum) * grad
        h_new = h - lr * v
        h_new = project_sum(h_new, target)
        
        c5_new = compute_c5(h_new)
        if c5_new < best_c5:
            best_c5 = c5_new
            best_h = h_new.copy()
            h = h_new.copy()
        else:
            # Reset momentum
            v *= 0.5
        
        # Decrease learning rate
        lr *= 0.9995
    
    return best_h, best_c5

def smooth_obj(h, beta):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    m = np.max(corr)
    shifted = corr - m
    return (m + np.log(np.sum(np.exp(beta * shifted))) / beta) * dx

def random_binary_init(n, rng):
    h = np.zeros(n)
    idx = rng.permutation(n)
    h[idx[:n//2]] = 1.0
    return h

def make_thue_morse(n):
    h = np.zeros(n)
    for i in range(n):
        cnt = bin(i).count('1')
        h[i] = 1.0 if cnt % 2 == 1 else 0.0
    return h
