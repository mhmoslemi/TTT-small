- Semidefinite relaxation (probably too expensive)
- Coordinate descent (as in the previous code)

Let me think about a different approach. Instead of optimizing all n variables simultaneously, what if we:
1. Start with a good binary pattern
2. Use the fact that the objective is the max of linear (in the "overlap" variables) functions
3. Use a cutting-plane / level-set method

Actually, here's an idea: use the "max" structure more directly. The objective is:
C₅ = max_s f_s(h) where f_s(h) = (2/n) * ∑_i h[i](1-h[i+s])

By KKT conditions, at the optimum, the subgradient of C₅ is a convex combination of the gradients of the active f_s's. The active set (those s where f_s = C₅) is key.

Algorithm:
1. Start with an initial h
2. Compute all f_s(h), find the active set A (those with f_s close to max)
3. Compute the subgradient: g = (1/|A|) * ∑_{s∈A} ∇f_s(h)
4. Take a projected gradient step: h_new = proj_{feasible}(h - α*g)
5. Repeat with adaptive step size

The projected gradient onto the feasible set {0 ≤ h ≤ 1, ∑h = n/2} is:
- First, clip to [0,1]
- Then, adjust to make the sum exactly n/2 (adding/subtracting from non-bound coordinates)

This is essentially what the subgradient step in the previous code does, but let me make it more sophisticated.

For a better step size: use a line search. Try α, 0.5α, 0.25α, ... and pick the one that minimizes C₅.

Also, I should consider:
- Using more points (higher n) gives more degrees of freedom
- The objective is piecewise smooth (max of smooth functions), so the gradient is well-defined almost everywhere
- Near the optimum, the active set is stable, and we can use Newton-type methods within the active set

Let me also think about the resolution. With n=160, dx = 2/160 = 0.0125. The C₅ value is 0.380975, meaning the max correlation is 0.380975 * 80 ≈ 30.48.

If I use n=320, dx = 0.00625, and a "similar" pattern (interploated), the max correlation would be about 61 (twice as many points, each contributing about the same). C₅ = 61 * 0.00625 ≈ 0.381. Same.

But with more points, I have more freedom to adjust individual values, potentially reducing the max.

Let me also consider: what if the optimal solution is NOT binary? The previous code allows [0,1] values. For the continuous case, the optimal might use fractional values to smooth out the peaks.

Here's my plan:
1. Start from the parent (n=160)
2. Interpolate to higher resolution (e.g., n=320, 480, 640)
3. Use a more sophisticated optimization:
   a. Projected subgradient with adaptive step size and line search
   b. Periodic coordinate descent with the binary-search approach (but with momentum)
   c. SLSQP polishing at the end
4. Also try from scratch with structured initializations at higher resolution
5. Use multiple random restarts

Let me also think about the coordinate descent more carefully. The previous code's coord_opt_j does a binary search on h[j] to minimize the max correlation. This is correct but slow (50 iterations of bisection per coordinate, times n coordinates, times many passes).

A faster approach: at each step, only update coordinates that are "active" (i.e., appear in the currently-maximizing shifts). This reduces the work per pass.

Also, I can vectorize the correlation computation. np.correlate is already reasonably fast for n up to a few thousand.

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return np.max(corr) * dx

def get_corr(h):
    return np.correlate(h, 1.0 - h, mode='full')

def make_feasible(h, n):
    h = np.array(h, dtype=float).copy()
    h = np.clip(h, 0.0, 1.0)
    target = n / 2.0
    for _ in range(2000):
        s = np.sum(h)
        diff = target - s
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            mask = h < 1.0 - 1e-14
            cnt = np.count_nonzero(mask)
            if cnt == 0:
                break
            h[mask] += diff / cnt
        else:
            mask = h > 1e-14
            cnt = np.count_nonzero(mask)
            if cnt == 0:
                break
            h[mask] += diff / cnt
        h = np.clip(h, 0.0, 1.0)
    return h

def proj_feasible(h, n):
    """Project onto {0<=h<=1, sum(h)=n/2}"""
    h = np.clip(h, 0.0, 1.0)
    target = n / 2.0
    # Binary search on the Lagrange multiplier for the sum constraint
    lo, hi = -1.0, 1.0
    for _ in range(60):
        mid = 0.5 * (lo + hi)
        h_proj = np.clip(h - mid, 0.0, 1.0)
        s = np.sum(h_proj)
        if s > target:
            lo = mid
        else:
            hi = mid
    h_proj = np.clip(h - 0.5*(lo+hi), 0.0, 1.0)
    # Fine adjustment
    diff = target - np.sum(h_proj)
    if abs(diff) > 1e-12:
        if diff > 0:
            mask = h_proj < 1.0 - 1e-14
        else:
            mask = h_proj > 1e-14
        cnt = np.count_nonzero(mask)
        if cnt > 0:
            h_proj[mask] += diff / cnt
            h_proj = np.clip(h_proj, 0.0, 1.0)
    return h_proj

def subgradient_compute(h, n, n_top=10):
    """Compute subgradient of max_s f_s(h) using top n_top active shifts."""
    corr = get_corr(h)
    # Find the top n_top correlation values
    top_vals = np.sort(corr)[-n_top:]
    thresh = top_vals[0]
    active = np.where(corr >= thresh - 1e-10)[0]
    
    grad = np.zeros(n)
    for idx in active:
        shift = idx - (n - 1)  # the actual shift
        e = int(shift)
        if e == 0:
            # f_0 = sum h[i]*(1-h[i]) -> grad = 1 - 2*h[i]
            grad += (1.0 - 2.0 * h)
        elif e > 0:
            # f_e = sum_{i=0}^{n-1-e} h[i]*(1-h[i+e])
            # d/de: d/dh[i] for i in [0, n-1-e]: (1-h[i+e])
            #        d/dh[i] for i in [e, n-1]: -h[i-e]
            i_start = 0
            i_end = n - e  # exclusive
            grad[i_start:i_end] += (1.0 - h[i_start + e:i_end + e])
            grad[i_start + e:i_end + e] += (-h[i_start:i_end])
        else:  # e < 0
            ee = -e
            # f_{-ee} = sum_{i=0}^{n-1-ee} h[i+ee]*(1-h[i])
            # d/dh[i+ee]: (1-h[i]) for i in [0, n-1-ee]
            # d/dh[i]: -h[i+ee] for i in [0, n-1-ee]
            i_start = 0
            i_end = n - ee  # exclusive
            grad[i_start + ee:i_end + ee] += (1.0 - h[i_start:i_end])
            grad[i_start:i_end] += (-h[i_start + ee:i_end + ee])
    
    grad /= len(active)
    return grad, corr

def subgradient_optimize(h, n, time_limit, max_iter=50000):
    """Optimize using subgradient method with adaptive step size."""
    h = h.copy()
    best_c5 = compute_c5(h)
    best_h = h.copy()
    start = time.time()
    
    alpha = 0.05
    patience = 2000
    no_improve = 0
    
    for it in range(max_iter):
        if time.time() - start > time_limit:
            break
        if it % 500 == 0 and time.time() - start > time_limit:
            break
        
        grad, corr = subgradient_compute(h, n, n_top=15)
        
        # Try several step sizes (line search)
        best_alpha_step = None
        best_c5_step = best_c5
        for scale in [1.0, 0.5, 0.25, 0.1]:
            a = alpha * scale
            h_try = proj_feasible(h - a * grad, n)
            c5_try = compute_c5(h_try)
            if c5_try < best_c5_step:
                best_c5_step = c5_try
                best_alpha_step = a
                h_new = h_try
        if best_alpha_step is None:
            h_new = h.copy()
        
        if best_c5_step < best_c5 - 1e-12:
            best_c5 = best_c5_step
            best_h = h_new.copy()
            no_improve = 0
            alpha = min(alpha * 1.01, 0.5)  # slightly increase step
        else:
            h_new = h.copy()  # reject
            no_improve += 1
            alpha *= 0.95
        
        h = h_new
        
        if no_improve > patience:
            # Reset with a smaller step
            alpha = 0.01
            no_improve = 0
    
    return best_h, best_c5

def coord_opt_j(h, j, n, corr):
    """Find optimal h[j] to minimize max correlation, given other h fixed."""
    ells = np.arange(-(n-1), n)
    idx_in_correl = j  # 0-indexed in h
    # For each lag index k in [0, 2n-2], the shift is k-(n-1)
    # h[j] appears in corr[k] if j is in the valid range for that shift
    # corr[k] = sum_i h[i] * (1-h[i+k-(n-1)]) for valid i
    # h[j] appears as h[i] when i=j, or as (1-h[...]) when j = i + shift
    
    # Actually, let me think about this more carefully.
    # corr[k] = sum_{valid i} h[i] * (1 - h[i + (k-(n-1))])
    # Let shift = k - (n-1)
    # corr[k] = sum_{valid i} h[i] - sum_{valid i} h[i]*h[i+shift]
    
    # h[j] appears in:
    # 1. Term h[i] when i=j (if j is valid for this shift)
    # 2. Term -h[i]*h[i+shift] when i=j or i+shift=j
    
    # This is complex. Let me use the approach from the previous code.
    # corr[k] - h[j] * (contribution of h[j] to corr[k]) = (terms not involving h[j])
    # So corr[k] = a_k * h[j] + b_k where a_k is the coefficient of h[j]
    
    a = np.zeros(2*n - 1)
    for k in range(2*n - 1):
        shift = k - (n - 1)
        # Valid i: max(0, -shift) <= i <= min(n-1, n-1-shift)
        i_lo = max(0, -shift)
        i_hi = min(n-1, n-1-shift)
        if i_lo > i_hi:
            a[k] = 0
            continue
        # h[j] appears if:
        # j in [i_lo, i_hi] AND (1-h[j+shift]) is the other factor -> contributes (1-h[j+shift]) to coefficient
        # j-shift in [i_lo, i_hi] AND h[j-shift] is the other factor -> contributes -h[j-shift]
        coeff = 0.0
        if i_lo <= j <= i_hi:
            other_idx = j + shift
            if 0 <= other_idx < n:
                coeff += (1.0 - h[other_idx])
        if i_lo <= j - shift <= i_hi and shift != 0:
            other_idx2 = j - shift
            if 0 <= other_idx2 < n:
                coeff += (-h[other_idx2])
        # Wait, I need to be more careful.
        # corr[k] = sum_{i=i_lo}^{i_hi} h[i] * (1 - h[i+shift])
        # = sum_{i=i_lo}^{i_hi} h[i] - sum_{i=i_lo}^{i_hi} h[i]*h[i+shift]
        #
        # Coefficient of h[j]:
        # From first sum: 1 if j in [i_lo, i_hi]
        # From second sum: -(h[j+shift]) if j in [i_lo, i_hi] (when j is the first index)
        #                    -(h[j-shift]) if j-shift in [i_lo, i_hi] (when j is the second index) i.e., j in [i_lo+shift, i_hi+shift]
        #
        # But we need i+shift to be a valid index in [0, n-1] as well.
        # Actually, the validity condition already ensures this.
        
        coeff = 0.0
        if i_lo <= j <= i_hi:
            # j is the first index: contributes 1 - h[j+shift]
            coeff += 1.0 - h[j + shift]
        if shift != 0 and (i_lo + shift) <= j <= (i_hi + shift):
            # j is the second index (j = i + shift, so i = j - shift)
            # Need j-shift in [i_lo, i_hi]
            i2 = j - shift
            if i_lo <= i2 <= i_hi:
                coeff += -h[i2]
        
        a[k] = coeff
    
    b = corr - h[j] * a
    lo = 0.0
    hi = 1.0
    for _ in range(60):
        mid = 0.5 * (lo + hi)
        vals = a * mid + b
        mx = np.max(vals)
        active_mask = vals >= mx - 1e-13
        sg = np.mean(a[active_mask])
        if sg > 1e-14:
            hi = mid
        elif sg < -1e-14:
            lo = mid
        else:
            break
    return 0.5 * (lo + hi)

def coord_descent(h, n, n_passes, time_limit):
    h = h.copy()
    best_c5 = compute_c5(h)
    best_h = h.copy()
    corr = get_corr(h)
    start = time.time()
    for p in range(n_passes):
        if time.time() - start > time_limit:
            break
        improved = False
        for j in range(n):
            t_opt = coord_opt_j(h, j, n, corr)
            if abs(t_opt - h[j]) > 1e-10:
                h[j] = t_opt
                improved = True
        h = make_feasible(h, n)
        corr = get_corr(h)
        c5 = np.max(corr) * (2.0 / n)
        if c5 < best_c5 - 1e-12:
            best_c5 = c5
            best_h = h.copy()
        if not improved:
            break
    return best_h, best_c5

def interpolate_to_n(h_src, n_dst):
    if len(h_src) < 2:
        return np.ones(n_dst) * 0.5
    x_old = np.linspace(0.0, 2.0, len(h_src), endpoint=False)
    x_new = np.linspace(0.0, 2.0, n_dst, endpoint=False)
    h_interp = np.interp(x_new, x_old, h_src)
    return make_feasible(h_interp, n_dst)

def slsqp_polish(h, n, max_iter=3000):
    def obj(x):
        return np.max(np.correlate(x, 1.0 - x, mode='full'))
    def sum_constraint(x):
        return np.sum(x) - n / 2.0
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': sum_constraint}]
    try:
        res = minimize(obj, h, method='SLSQP', bounds=bounds,
                       constraints=cons, options={'maxiter': max_iter, 'ftol': 1e-15})
        if res.success or res.fun < 1e10:
            h_out = make_feasible(res.x, n)
            c5_out = compute_c5(h_out)
            if c5_out < 1.0:  # sanity check
                return h_out, c5_out
    except Exception:
        pass
    return None, None

def generate_structured_init(n, rng):
    """Generate diverse initializations."""
    inits = []
    # 1100 pattern
    if n % 4 == 0:
        h1 = np.tile([1.0, 1.0, 0.0, 0.0], n // 4)
        inits.append(h1.copy())
    # 1010 pattern
    if n % 2 == 0:
        h2 = np.tile([1.0, 0.0], n // 2)
        inits.append(h2.copy())
    # Block pattern: half 1s, half 0s
    h3 = np.zeros(n)
    h3[:n//2] = 1.0
    inits.append(h3.copy())
    # Two blocks
    h4 = np.zeros(n)
    h4[:n//4] = 1.0
    h4[n//2:n//2+n//4] = 1.0
    inits.append(h4.copy())
    # Thue-Morse
    tm = np.zeros(n)
    for i in range(n):
        tm[i] = 1.0 if bin(i).count('1') % 2 == 0 else 0.0
    inits.append(make_feasible(tm, n))
    # Greedy: place 1s to minimize max overlap
    h5 = np.zeros(n)
    ones_placed = 0
    for target_sum in range(n // 2):
        best_pos = -1
        best_max = float('inf')
        for pos in range(n):
            if h5[pos] == 0:
                h5[pos] = 1
                c = np.max(get_corr(h5))
                h5[pos] = 0
                if c < best_max:
                    best_max = c
                    best_pos = pos
        if best_pos >= 0:
            h5[best_pos] = 1
    inits.append(h5.copy())
    # Random
    for _ in range(3):
        h_r = (rng.rand(n) > 0.5).astype(float)
        # Fix sum
        s = np.sum(h_r)
        diff = n/2 - s
        if diff > 0:
            zeros = np.where(h_r == 0)[0]
            h_r[zeros[:int(diff)]] = 1
        elif diff < 0:
            ones = np.where(h_r == 1)[0]
            h_r[ones[:int(-diff)]] = 0
        inits.append(h_r.copy())
    return inits
