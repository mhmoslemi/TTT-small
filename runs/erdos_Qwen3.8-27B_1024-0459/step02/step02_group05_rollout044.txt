```python
def compute_profiles(h, n):
    """Compute P[r](k) = h[r-k] + h[r+k] for all r and k."""
    # k ranges from -(n-1) to (n-1), stored at index k + n - 1
    # P has shape (n, 2n-1)
    P = np.zeros((n, 2 * n - 1))
    for r in range(n):
        # h[r-k] valid when 0 <= r-k < n, i.e., -r < k < n-r
        # h[r+k] valid when 0 <= r+k < n, i.e., -r < k < n-1-r... wait
        # 0 <= r+k < n means -r <= k <= n-1-r
        for k in range(-(n-1), n):
            # h[r-k]
            if 0 <= r - k < n:
                P[r, k + n - 1] += h[r - k]
            # h[r+k]
            if 0 <= r + k < n:
                P[r, k + n - 1] += h[r + k]
    return P
```

Actually, after swapping h[p] and h[q]:
- corr changes by P[p] - P[q] (before the swap)
- P[p] changes: P[p](k) = h[p-k] + h[p+k]. After swap, h[p] went from 1 to 0.
  The new P'[p](k) = old P[p](k) - [(1 if p-k==p or p+k==p else 0)]
  p-k==p iff k=0. p+k==p iff k=0.
  So P'[p](0) = P[p](0) - 2 (since h[p] appears twice at k=0)
  All other P[p](k) unchanged.
  
  Wait, P[p](k) = h[p-k] + h[p+k]. At k=0: P[p](0) = h[p] + h[p] = 2*h[p] = 2. After: 0. Change: -2.
  At k≠0: P[p](k) = h[p-k] + h[p+k]. Neither p-k nor p+k equals p (for k≠0), so P[p](k) doesn't involve h[p] directly... wait, it does! If p-k = p, that requires k=0. If p+k = p, also k=0. So for k≠0, P[p](k) is unchanged.
