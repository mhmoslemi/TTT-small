For the subgradient of the soft-max:

∂f/∂h_j = (1/β) Σ_k (β ∂c_k/∂h_j) exp(β c_k) / Σ_k exp(β c_k)

So the gradient is a convex combination of the individual lag gradients, weighted by softmax.

For β → ∞, this becomes the gradient of the argmax lag.
For moderate β, it's a smooth approximation.

This is a smooth, differentiable function, so I can use gradient-based methods.

For the individual lag gradient ∂c_k/∂h_j, I derived earlier:
Let s = k - (n-1).

If s ≥ 0:
  For j in [s, n-1]: ∂c_k/∂h_j += (1 - h_{j-s})
  For j in [0, n-s-1]: ∂c_k/∂h_j -= h_{j+s}

If s < 0, sp = -s:
  For j in [0, n-sp-1]: ∂c_k/∂h_j += (1 - h_{j+sp})
  For j in [sp, n-1]: ∂c_k/∂h_j -= h_{j-sp}

For the soft-max gradient:
grad_j = Σ_k softmax(β c_k)_k * ∂c_k/∂h_j

This requires computing ∂c_k/∂h_j for all k, which is O(n²) per coordinate j, and O(n³) total. For n=160, that's about 4 million operations per gradient evaluation. Fast enough.

Let me compute this for all j at once.
