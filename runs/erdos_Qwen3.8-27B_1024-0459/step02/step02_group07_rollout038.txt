    # corr is the full correlation of current h with 1-h
    # When we change h[j] from old to new, the correlation changes linearly
    # corr_new[m] = corr[m] + (new - old) * delta[m]
    # where delta[m] depends on which terms involve h[j]

    # - term j in h (multiplied by 1-h[j+k] for shift k)
    # - term j-k in (1-h) (i.e., h[j] appears as 1-h[j] in the second factor)

    # corr[k] = sum_i h[i] * (1-h[i+k]) (for valid i)
    # h[j] appears when i=j: contribution h[j]*(1-h[j+k])
    # h[j] appears when i+k=j, i.e., i=j-k: contribution h[j-k]*(1-h[j])
    
    old = h[j]
    ells = np.arange(-(n-1), n)  # lag values
    # For each lag ell (corresponding to output index ell + n - 1):
    # h[j] contributes (1-h[j+ell]) if j+ell is valid (as the h factor)
    # h[j] contributes -h[j-ell] if j-ell is valid (as the 1-h factor)
    
    delta = np.zeros(2*n-1)
    # h[j] as first factor: h[j]*(1-h[j+ell])
    j1 = j  # this is the index in h
    # lag ell means output index ell + n - 1
    # For output index m, lag = m - (n-1)
    # h[j] * (1-h[j+lag]) where lag = m-(n-1)
    # j+lag is valid: 0 ≤ j+lag < n → -(j) ≤ lag < n-j
    lags1 = np.arange(-j, n-j)  # valid lags for h[j] as first factor

    # But we need h[j+lag] for these:
    vals1 = 1.0 - h[j + lags1]

    delta[idx2] += vals2

    # We want to minimize max_m corr_new[m]

    # For a given T, we need: for all m with delta[m] > 0, new_val ≤ (T - corr[m]) / delta[m] + old
    # For all m with delta[m] < 0, new_val ≥ (T - corr[m]) / delta[m] + old (flipped inequality)
    # And 0 ≤ new_val ≤ 1
    
    # Actually, let's just binary search on new_val directly (as the previous code does)
    lo = 0.0
    hi = 1.0
    for _ in range(40):

        new_corr = corr + (mid - old) * delta
        mx = np.max(new_corr)
        # Gradient of max w.r.t. mid:
        active = new_corr >= mx - 1e-14
        sg = np.mean(delta[active])
        if sg > 1e-13:
            hi = mid
        elif sg < -1e-13:
            lo = mid
        else:
            break
    return 0.5 * (lo + hi)

Another idea: **Projected subgradient method with momentum (FISTA)**

The objective f(h) = max_k corr_k(h) is the maximum of (2n-1) differentiable functions. Its subgradient is the average of the gradients of the active (maximum) functions.

FISTA (Fast Iterative Shrinkage-Thresholding Algorithm) can be used:
1. Compute subgradient g at current h
2. Update: y = h + momentum * (h - h_prev)
3. h_new = y - step_size * g
4. Project h_new to feasible set [0,1] with sum = n/2
5. Update momentum

This should converge faster than plain subgradient and can be run for many iterations.

Let me think about the projection step. We need to project onto:
- 0 ≤ h_i ≤ 1
- sum(h_i) = n/2

This is a "constrained projection" that can be solved by:
1. Clip to [0,1]
2. Adjust to meet sum (distribute the difference among non-saturated entries)
3. Iterate until converged

This is what the previous `make_feasible` does.

def fista_step(h, n, momentum_t):
    """One FISTA-style step using subgradient of max correlation."""
    corr = np.correlate(h, 1.0 - h, mode='full')
    max_val = np.max(corr)
    # Active set: correlations within epsilon of max
    thresh = max_val - 1e-6 * max(n, 1)  # or a fixed small epsilon
    active = corr >= thresh - 1e-10
    
    # Subgradient: average of gradients of active correlations
    # grad of corr[k] w.r.t. h[j]:
    # = (1-h[j+k]) if j+k valid (as first factor)
    # + (-h[j-k]) if j-k valid (as second factor)

    grad = np.zeros(n)
    for k_idx in np.where(active)[0]:
        lag = k_idx - (n-1)
        # First factor: h[j] * (1-h[j+lag]), j+lag valid
        # As function of h[j]: contributes (1-h[j+lag])
