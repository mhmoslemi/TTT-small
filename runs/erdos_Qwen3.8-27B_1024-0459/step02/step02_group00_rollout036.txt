Let me also think about a completely different approach: **Use the structure of the correlation matrix.**

The correlation at shift k is:
corr[k] = sum_i h[i] * (1-h[i+k])

If I define A = h (as a column vector), then:
corr[k] = sum_i A[i] - sum_i A[i]*A[i+k]
         = ||A||_1 - A^T S^k A

where S is the shift matrix.

So the objective is:
max_k (||A||_1 - A^T S^k A) * dx

Since ||A||_1 is fixed (= n/2), this is equivalent to:
min max_k (n/2 - A^T S^k A) * dx
= min (n/2 - min_k A^T S^k A) * dx
= (n/2 * dx) - (min_k A^T S^k A) * dx
= 1 - (min_k A^T S^k A) * dx

So minimizing C5 is equivalent to maximizing min_k A^T S^k A!

This is a max-min problem: maximize the minimum eigenvalue-like quantity.

A^T S^k A is a quadratic form. The problem is:
max_A min_k A^T S^k A
s.t. sum(A) = n/2, 0 <= A <= 1

This is still non-convex, but the structure is clearer.

For binary A (A[i] in {0,1}), A^T S^k A = number of pairs (i, i+k) where both A[i]=1 and A[i+k]=1.

So we want to maximize the minimum number of "1-1 pairs" at any distance k.

This is a combinatorial optimization problem! And it's equivalent to finding a binary sequence with the property that for every distance k, there are many pairs of 1s at that distance.

This is related to the concept of "dense sets" in additive combinatorics. A set A ⊂ {0,...,n-1} with |A| = n/2 that maximizes the minimum difference count.

**Key insight from additive combinatorics**: The Thue-Morse sequence and related sequences have good "difference set" properties. But we can do better by specifically optimizing for the minimum.

def project_feasible(h, n):

def make_thue_morse(n):
    h = np.zeros(n)
    for i in range(n):
        v = i
        cnt = 0
        while v:
            cnt ^= (v & 1)
            v >>= 1
        h[i] = 1.0 if cnt == 1 else 0.0
    return h

                _P = p
                h_new = slsqp_optimize(h_cur, n, obj_lp, maxiter=250)
                c5_new = compute_c5(h_new)
                if c5_new < c5_cur:
                    h_cur = h_new
                    c5_cur = c5_new

            # COBYLA on L4 (good for non-smooth)
            if remaining_time() > 15:
                _P = 4
                h_new = cobyla_optimize(h_cur, n, obj_lp, maxiter=400)
                c5_new = compute_c5(h_new)
                if c5_new < c5_cur:
                    h_cur = h_new
                    c5_cur = c5_new

            if c5_cur < best_c5:
                best_c5 = c5_cur
                best_h = h_cur.copy()
                best_n = n
                print("  Phase1 n={}, C5={:.8f}".format(n, best_c5))

    # Phase 2: Targeted reduction (focus on worst shifts)
    if remaining_time() > 120:
        print("\nPhase 2: Targeted reduction at n={}".format(best_n))
        best_h, best_c5 = targeted_reduction(best_h, best_c5, max_rounds=15, rng=rng)
        print("  After targeted: C5={:.8f}".format(best_c5))

    # Phase 3: Simulated annealing at multiple resolutions
    if remaining_time() > 100:
        print("\nPhase 3: Simulated annealing")
        # Try at best_n and a couple others
        sa_n_list = [best_n]
        for alt_n in [128, 192, 256]:
            if alt_n != best_n and 96 <= alt_n <= 320:
                sa_n_list.append(alt_n)

        for n in sa_n_list:
            if remaining_time() < 40:
                break

            h_start = project_feasible(interp_to(best_h, best_n, n), n)
            h_sa, c5_sa = sim_anneal(h_start, n, max_iters=4000, t0=0.06, t_end=0.0003, rng=rng)
            if c5_sa < best_c5:
                best_c5 = c5_sa
                best_h = h_sa.copy()
                best_n = n
                print("  SA improved n={}, C5={:.8f}".format(n, best_c5))

    # Phase 4: Nelder-Mead on high-p objective (derivative-free, handles non-smooth)
    if remaining_time() > 40:
        print("\nPhase 4: Nelder-Mead polish")
        n = best_n
        _TGT = n / 2.0
        for p in [16, 32, 64]:
            if remaining_time() < 10:
                break
            _P = p
            h_new = nelder_mead_optimize(best_h, n, obj_lp, maxiter=1500)
            c5_new = compute_c5(h_new)
            if c5_new < best_c5:
                best_c5 = c5_new
                best_h = h_new.copy()
                print("  NM p={} C5={:.8f}".format(p, best_c5))

    # Phase 5: Coordinate descent / bit-flipping
    if remaining_time() > 15:
        print("\nPhase 5: Coordinate descent")
        n = best_n
        best_h, best_c5 = coordinate_descent(best_h, n, max_sweeps=8, rng=rng)
        print("  After CD: C5={:.8f}".format(best_c5))

    # Phase 6: Final high-p SLSQP polish
    if remaining_time() > 10:
        n = best_n
        _TGT = n / 2.0
        for p in [64, 128, 256]:
            if remaining_time() < 5:
                break
            _P = p
            h_new = slsqp_optimize(best_h, n, obj_lp, maxiter=400)
            c5_new = compute_c5(h_new)
            if c5_new < best_c5:
                best_c5 = c5_new
                best_h = h_new.copy()

    # Final validation
    best_h = project_feasible(best_h, best_n)
    final_c5 = compute_c5(best_h)

    try:
        eval_c5 = evaluate_erdos_solution(best_h)
        if eval_c5 < final_c5:
            final_c5 = eval_c5
    except Exception:
        pass

    print("\nFINAL: n={}, C5={:.8f}".format(best_n, final_c5))
    return (best_h, final_c5, best_n)
