    #   j = i → k = j - i + (n-1) - j + ... wait let me redo

    # Let a = k - (n-1), so corr[k] = sum_i h[i+a] * (1-h[i])
    # h[j] appears as h[i+a] when j = i+a, i.e., i = j-a
    #   contribution: (1 - h[j-a])
    # h[j] appears as h[i] when j = i, i.e., i = j

    # Instead of computing this directly (O(n²)), I can use the structure
    # The gradient of the smooth max wrt h is:
    # grad[j] = dx * sum_k weights[k] * d corr[k] / d h[j]
    #         = dx * sum_k weights[k] * [(1-h[j-(k-(n-1))]) * indicator - h[j+(k-(n-1))] * indicator]

    # = sum_i w[(j-i)+(n-1)] * (1-h[i]) where 0 ≤ i ≤ n-1 and 0 ≤ j-i ≤ n-1

    grad = np.zeros(n)
    for j in range(n):

        for k in range(2*n-1):
            a = k - (n-1)

Wait, this O(n²) gradient computation is too slow for n=1024 (would be 1M operations per gradient eval, and with SLSQP doing hundreds of iterations, it's too slow).

Let me use a smarter approach. The correlation can be computed via FFT, and the gradient can also be computed via FFT.

Actually, let me think about this differently. The correlation corr[k] = sum_i h[i+a] * (1-h[i]) where a = k-(n-1).

I can split this: corr[k] = sum_i h[i+a] - sum_i h[i+a]*h[i]

The first term: sum_i h[i+a] is just a shifted sum of h. For a > 0, it's sum of h[a:a+n] (the last n-a elements). For a < 0, it's sum of h[0:n+a].

The second term: sum_i h[i+a]*h[i] is the autocorrelation of h at lag a.

So corr[k] = (shifted sum of h) - (autocorrelation of h at lag a).

The gradient of the autocorrelation: d/dh[j] sum_i h[i+a]*h[i] = h[j-a] * 1[valid] + h[j+a] * 1[valid]

The gradient of the shifted sum: d/dh[j] sum_i h[i+a] = 1[j-a in range] = 1[0 ≤ j-a ≤ n-1]

So the gradient of corr[k] with respect to h[j]:
= 1[0 ≤ j-a ≤ n-1] - h[j-a]*1[0≤j-a≤n-1] - h[j+a]*1[0≤j+a≤n-1]
= (1-h[j-a])*1[0≤j-a≤n-1] - h[j+a]*1[0≤j+a≤n-1]

This matches what I had before. Now, to compute the full gradient efficiently:

grad[j] = dx * sum_k weights[k] * [(1-h[j-a_k])*1[valid] - h[j+a_k]*1[valid]]

where a_k = k - (n-1) ranges from -(n-1) to (n-1).

Let me define W[a] = weights[a+(n-1)] for a ∈ [-(n-1), (n-1)].

Then:
grad[j] = dx * [sum_{a: 0≤j-a≤n-1} W[a] * (1-h[j-a]) - sum_{a: 0≤j+a≤n-1} W[a] * h[j+a]]

First sum: let i = j-a, a = j-i. Range: 0≤i≤n-1 and 0≤j-i≤n-1, i.e., max(0,j-n+1)≤i≤min(n-1,j).
= sum_{i=max(0,j-n+1)}^{min(n-1,j)} W[j-i] * (1-h[i])

Second sum: let i = j+a, a = i-j. Range: 0≤i≤n-1 and 0≤i-j≤n-1, i.e., max(0,j)≤i≤min(n-1,j+n-1) = n-1 (since j≥0).
Wait, 0≤j+a≤n-1 means 0≤i≤n-1, and a=i-j, and a ranges from -(n-1) to (n-1), so i-j ∈ [-(n-1),(n-1)], i.e., j-(n-1)≤i≤j+(n-1). Combined with 0≤i≤n-1: max(0, j-n+1)≤i≤min(n-1, j+n-1).

So second sum = sum_{i=max(0,j-n+1)}^{min(n-1,j+n-1)} W[i-j] * h[i]

These are both convolution-like operations! I can compute them using FFT.

Let me define:
- A[j] = (1-h) convolved with W (truncated) → gives first sum
- B[j] = h convolved with W (truncated) → gives second sum
