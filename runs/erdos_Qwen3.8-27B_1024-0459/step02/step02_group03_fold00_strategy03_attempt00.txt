### Mathematical Specification

#### Representation of Step Function
The step function ⟨h⟩ on n discrete points x_i = (i-0.5)/n * 2 is represented by:
$$ h(x) = 0.5 + \sum_{k=1}^{K} \left( A_k \cos(2\pi k x / \Omega) + B_k \sin(2\pi k x / \Omega) \right) $$
with $\Omega = 2$ (full interval) and K being the number of Fourier modes (5-8). This representation satisfies the integral constraint by design since:
$$ \int_0^2 h(x)dx = \int_0^2 0.5 dx + \sum_{k=1}^K \int_0^2 (A_k \cos(2\pi k x / \Omega) + B_k \sin(2\pi k x / \Omega)) dx = 1 + 0 $$

#### Objective Function
The overlap integral C5 is computed via discrete convolution:
$$ C_5 = \max_l \Delta x \cdot \langle h(x)(1 - h(x+l)) \rangle $$
for lag l, with $\Delta x = 2/n$. To enable gradient-based optimization, a smooth approximation is used:
$$ C_5^{\text{smooth}}(h) = \frac{1}{\beta} \log\left(\sum_{t=0}^{2n-1} \exp(\beta (1 - \Delta x) \cdot \tilde{c}_t)\right) $$
where c_t is the normalized convolution value at lag t.

#### Projection to Feasible Set
After each optimization step, projection onto the feasible set requires:
1. Domain normalization: h(x) ∈ [0,1] for all x
