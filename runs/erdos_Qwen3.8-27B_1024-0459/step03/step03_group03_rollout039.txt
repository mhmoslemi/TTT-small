Actually, I just realized something. Let me reconsider the problem.

The correlation `np.correlate(h, 1-h, mode='full')` computes:
For output index i (0 to 2n-2), the value is:
sum_{j} h[j] * (1-h)[j + (i - (n-1))]
= sum_{j} h[j] * (1 - h[j + i - n + 1])

Let k = i - (n-1). Then:
output[i] = sum_{j: 0 ≤ j < n, 0 ≤ j+k < n} h[j] * (1 - h[j+k])

This is the cross-correlation of h with (1-h) at lag k.

Now, C₅ = max_k output[i] * dx where dx = 2/n.

Note that output[i] is always non-negative (since h ∈ [0,1], both h[j] and 1-h[j+k] are non-negative).

Also, output[n-1] (k=0) = sum h[j](1-h[j]) = sum h[j] - sum h[j]^2 = n/2 - sum h[j]^2.

Since sum h[j] = n/2, this equals n/2 - sum h[j]^2.
By Cauchy-Schwarz, sum h[j]^2 ≥ (sum h[j])^2 / n = (n/2)^2 / n = n/4.
So output[n-1] ≤ n/2 - n/4 = n/4.
And C₅ at k=0 is at most (n/4) * (2/n) = 1/2.

This is consistent with the continuous case: if h=1/2 everywhere, C₅ = 1/2.

To get C₅ < 1/2, we need h to not be constant (which reduces the k=0 contribution) while also keeping other lags low.

            print("After main: n={} C5={:.10f}".format(npar, c5))

    for noise in [0.03, 0.01, 0.005]:
        if _tl() < 120:
            break
        h_pert = bh + noise * rng.randn(npar)
        h_pert = _proj(h_pert, npar)
        if _np_allclose(h_pert, bh):
            continue
        h, c5 = _full_opt(h_pert, npar, rng)
        if c5 < bc5:
            bh, bc5 = h, c5
            print("Perturb {:.3f}: n={} C5={:.10f}".format(noise, npar, c5))

    res_list = [npar + d for d in [2, -2, 4, -4, 6, -6, 8, -8, 10, -10, 12, -12, 14, -14, 16, 20, -16, -20]]
    res_list = [r for r in res_list if r >= 40 and r % 2 == 0]
    seen = set()
    res_list = [r for r in res_list if r not in seen and not seen.add(r)]

    for nn in res_list:
        if _tl() < 100:
            break
        hi = _proj(_interp(bh, bn, nn), nn)
        h2, c2 = _full_opt(hi, nn, rng)
        if c2 < bc5:
            bh, bc5, bn = h2, c2, nn
            print("New best: n={} C5={:.10f}".format(nn, c2))

    if _tl() > 40:
        h, c5 = _polish(bh, bn, rng)
        if c5 < bc5:
            bh, bc5 = h, c5
            print("After polish: n={} C5={:.10f}".format(bn, c5))

    if _tl() > 20:
        h, c5 = _gd_loop(bh, bn, 500, 15000.0)
        if c5 < bc5:
            bh, c5 = h, c5
        h, c5 = _value_transfer(bh, bn, 100, rng)
        if c5 < bc5:
            bh, bc5 = h, c5
        h2 = _slsqp(bh, bn, 10000.0, 400)
        c2 = _c5(h2)
        if c2 < bc5:
            bh, bc5 = h2, c2
        h, c5 = _gd_loop(bh, bn, 300, 20000.0)
        if c5 < bc5:
            bh, bc5 = h, c5
        h, c5 = _value_transfer(bh, bn, 50, rng)
        if c5 < bc5:
            bh, bc5 = h, c5

    bh = _proj(bh, bn)
    fc5 = _c5(bh)
    try:
        ec = evaluate_erdos_solution(bh)
        if ec < fc5:
            fc5 = ec
    except Exception:
        pass
    print("FINAL: n={} C5={:.10f}".format(bn, fc5))
    return (bh, fc5, bn)


def _np_allclose(a, b):
    return np.allclose(a, b, atol=1e-12)
