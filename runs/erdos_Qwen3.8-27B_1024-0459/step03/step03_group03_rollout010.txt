The key insight is that C₅ depends on h through the correlations. The correlations are:
corr_m = Σ_i h[i] * (1-h[i+m]) = Σ_i h[i] - Σ_i h[i]*h[i+m]

The first term is constant (Σ_i h[i] = n/2), so minimizing C₅ is equivalent to maximizing the minimum Σ_i h[i]*h[i+m] over m≠0.

Wait, that's not quite right. C₅ = dx * max_m corr_m = dx * max_m (n/2 - Σ_i h[i]*h[i+m]).

Wait, corr_m = Σ_i h[i]*(1-h[i+m]) = Σ_i h[i] - Σ_i h[i]*h[i+m] (where the sums are over valid indices).

For m≠0, Σ_i h[i] over valid indices is not exactly n/2 (boundary effects). But for large n, it's approximately n/2.

So C₅ ≈ dx * max_m (n/2 - Σ_i h[i]*h[i+m]) = dx * (n/2 - min_m Σ_i h[i]*h[i+m]).

To minimize C₅, we want to maximize min_m Σ_i h[i]*h[i+m] over m≠0.

This is related to the "minimum auto-correlation" problem! We want a sequence with high minimum auto-correlation (excluding m=0).

For binary sequences, this is the "maximum minimum auto-correlation" problem, which is well-studied in coding theory. Optimal sequences include:
- Barker sequences (maximally flat)
- Costas arrays
- M-sequences (maximal length linear feedback shift register sequences)

But our constraint is that the sequence has exactly n/2 ones (balanced). For n=160, we need 80 ones.

The "maximum minimum auto-correlation" for balanced binary sequences is a hard combinatorial problem, but heuristics exist.

This reframing might help: instead of minimizing the max of (constant - autocorrelation), we maximize the min of autocorrelations. This is a maximin problem.

For the gradient method, the subgradient of the max at the active constraints points in the direction that increases those specific correlations. We want to move in the direction that increases the minimum autocorrelation, which is the negative of the subgradient of the max.

def _c5(h):
    n = len(h)
    c = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(c)) * (2.0 / n)

def _proj(h, n):
    h = np.array(h, dtype=np.float64).copy()
    np.clip(h, 0.0, 1.0, out=h)
    for _ in range(50):
        d = 0.5 * n - h.sum()
        if abs(d) < 1e-13:
            break
        m = (h > 1e-10) & (h < 1.0 - 1e-10)
        k = int(np.sum(m))

            h[m] += d / k
        else:

                if len(z) > 0:

            else:

                if len(o) > 0:
                    h[o[0]] = max(h[o[0]] + d, 0.0)
        np.clip(h, 0.0, 1.0, out=h)
    return h

def _ggrad(h, k):
    n = len(h)
    s = k - (n - 1)
    g = np.zeros(n)
    if s == 0:
        g[:] = 1.0 - 2.0 * h
    elif s > 0:
        g[:n - s] += (1.0 - h[s:])
        g[s:] -= h[:n - s]
    else:
        p = -s
        g[p:] += (1.0 - h[:n - p])
        g[:n - p] -= h[p:]
    return g

def _smgrad(h, bw, topk=None):
    n = len(h)
    corr = np.correlate(h, 1.0 - h, mode='full')
    mx = float(np.max(corr))
    if topk is not None and topk < len(corr):
        # Only use top-k correlations
        idx = np.argpartition(corr, -topk)[-topk:]
        w = np.zeros_like(corr)
        ctop = corr[idx]
        w[idx] = np.exp(bw * (ctop - mx))
    else:
        w = np.exp(bw * (corr - mx))
    sw = float(np.sum(w))
    if sw < 1e-30:
        idx_max = np.argmax(corr)
        w = np.zeros_like(corr)
        w[idx_max] = 1.0
        sw = 1.0
    w /= sw
    g = np.zeros(n)
    nz = np.where(w > 1e-8)[0]
    for k in nz:
        g += w[k] * _ggrad(h, int(k))
    return g

    best = h.copy()
