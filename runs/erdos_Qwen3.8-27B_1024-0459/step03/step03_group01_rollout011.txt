1. Identify the top K shifts (K=3 or 4)
2. Try to minimize their maximum while keeping others below
3. Use a Newton method on the K active constraints

For the active set {k1, k2, ..., kK}, we want to find h such that:
corr[k1] = corr[k2] = ... = corr[kK] = t (minimal)
with all other corr[j] ≤ t.

This gives us K equations (corr[kj] = t for j=1..K) plus the constraint sum(h) = n/2, giving K+1 equations in n+1 unknowns (h[0..n-1] and t).

For K << n, we can use the Jacobian to compute the Newton step. The Jacobian of corr[k] w.r.t. h is:
J[k, i] = ∂corr[k]/∂h[i] = (1-h[i+L])·[valid] - h[i-L]·[valid]

where L = k-(n-1).

This is a sparse matrix with at most 2 nonzeros per row (for the specific k).

Actually, for a given k (shift L), J[k, i] is nonzero only for i = a (where a+L valid) and i = b (where b-L valid, i.e., b = i+L). So each row of J (for a specific k) has at most n nonzeros. The full J is (2n-1) × n.

For the Newton step on the active set, we solve:
[J_active] Δh = -[corr_active - t]  (K equations)
[1, 1, ..., 1] [Δh; Δt] = 0  (constraint)

Actually, it's:
∂corr[kj]/∂h · Δh + ∂corr[kj]/∂t · Δt = -(corr[kj] - t) for j=1..K
sum(Δh) = 0

Since corr[kj] doesn't depend on t: ∂corr/∂t = 0.
And we want corr[kj] + J[kj,:]Δh = t for all j.

So: J_active · Δh = 1·t - corr_active (K equations)
     1' · Δh = 0 (one equation)

This is a (K+1) × n system. We can solve it using the pseudoinverse or by eliminating.

Actually, the simplest approach: minimize the K + 1 ≈ K+1 variables. Let's use a small QP or just solve the linear system.

J_active · Δh = [t]·ones - corr_active
1'·Δh = 0

[J'J + λ·(11')] Δh = J'·([t]·ones - corr_active)

```python
def grad_matrix(h, n):
    G = np.zeros((n, 2*n-1))
    for a in range(n):
        L_vals = np.arange(-(n-1), n)  # all possible L
        # First term: (1-h[a+L]) where 0<=a+L<n
        idx1 = (a + L_vals >= 0) & (a + L_vals < n)
        if idx1.any():
            G[a, idx1] += (1.0 - h[a + L_vals[idx1]])
        # Second term: -h[a-L] where 0<=a-L<n
        idx2 = (a - L_vals >= 0) & (a - L_vals < n)
        if idx2.any():
            G[a, idx2] -= h[a - L_vals[idx2]]
    return G
```

def binary_steepest(h, n, time_limit=30):

    n_ones = int(np.sum(h))
    if n_ones != n//2:
        if n_ones > n//2:

            perms = np.random.permutation(n_ones - n//2)
            h[ones[perms]] = 0

            h[zeros[perms]] = 1

        zeros_idx = np.where(h==0)[0]

                best_a = a
                best_b = zeros_idx[bi]

            h[best_a] = 0
            h[best_b] = 1
            corr = compute_corr(h)
            cur_max = np.max(corr)
            improved = True
        elif best_a >= 0 and best_delta < cur_max - 1e-15:

            h[best_a] = 0
            h[best_b] = 1
            corr = compute_corr(h)
            cur_max = np.max(corr)
            improved = True
    
    return h, cur_max * 2.0 / n

def newton_active(h, n, K=4, max_iter=100):

    for it in range(max_iter):
        if remaining() < 3:
            break
        corr = compute_corr(h)
        # Top K shifts
        topk = np.argsort(-corr)[:K]
        active_vals = corr[topk]
        t = active_vals.mean()

        G = grad_matrix(h, n)  # (n, 2n-1)
        G_act = G[:, topk]  # (n, K)

        A = np.vstack([G_act, np.ones(n)])  # (K+1, n)

                break

def compute_corr(h):

def compute_c5(h):

def project_feasible(h, n):
    h = np.clip(np.array(h, dtype=float), 0.0, 1.0)
    target = n / 2.0

        cnt = np.sum(free)
        if cnt > 0:
            h[free] += diff / cnt
        else:
            h += diff / n
        h = np.clip(h, 0.0, 1.0)
    return h


def interp_to(src, src_n, dst_n):
    if src_n == dst_n:
        return src.copy()
    xp = (np.arange(src_n) + 0.5) * 2.0 / src_n
    xq = (np.arange(dst_n) + 0.5) * 2.0 / dst_n
    return np.interp(xq, xp, src)


def grad_matrix(h, n):
    G = np.zeros((n, 2 * n - 1))
    L_vals = np.arange(-(n - 1), n)
    for a in range(n):
        idx1 = (a + L_vals >= 0) & (a + L_vals < n)
        if idx1.any():
            G[a, idx1] += (1.0 - h[a + L_vals[idx1]])
        idx2 = (a - L_vals >= 0) & (a - L_vals < n)
        if idx2.any():
            G[a, idx2] -= h[a - L_vals[idx2]]
    return G

def sigmoid(x):
    return 1.0 / (1.0 + np.exp(-np.clip(x, -50, 50)))


def t_to_h(t, n):
    s = sigmoid(t)
    return s / s.sum() * (n / 2.0)


def smooth_obj_t(t, n, beta):
    h = t_to_h(t, n)
    corr = compute_corr(h)
    dx = 2.0 / n
    m = np.max(corr)
    shifted = np.clip(beta * (corr - m), -50, 50)
    logsum = np.log(np.sum(np.exp(shifted)))
    return (m + logsum / beta) * dx


def smooth_grad_t(t, n, beta):
    h = t_to_h(t, n)
    corr = compute_corr(h)
    dx = 2.0 / n
    m = np.max(corr)
    shifted = np.clip(beta * (corr - m), -50, 50)
    ex = np.exp(shifted)
    ex_sum = ex.sum()
    w = ex / ex_sum
    G = grad_matrix(h, n)
    dh = G.T @ w
    s = sigmoid(t)
    s_sum = s.sum()
    v = s * (1.0 - s)
    c = n / 2.0
    dot_dv = np.dot(dh, v)
    grad_t = (c / s_sum ** 2) * (dh * v - s * dot_dv)
    return grad_t * dx

        return (m + np.log(ex.sum()) / _BETA_g) * dx_v

        dx_v = 2.0 / n
        m = np.max(corr)
        shifted = np.clip(_BETA_g * (corr - m), -50, 50)
        ex = np.exp(shifted)
        w = ex / ex.sum()
        G = grad_matrix(x, n)
        dh = G.T @ w
        return dh * dx_v

        return np.sum(x) - _TGT_g

    def con_jac(x):
        return np.ones(n)

    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': con_fun, 'jac': con_jac}]
    try:
        res = minimize(obj_direct, h0, jac=grad_direct, method='SLSQP',
                       bounds=bounds, constraints=cons,
                       options={'maxiter': maxiter, 'ftol': 1e-16, 'iprint': 0})

    except Exception:
        return h0
