But this might violate the [0,1] constraint. So it's not always feasible.

For the binary case (h[i] ∈ {0,1}), changing h[i] from 0 to 1 means we need to decrease some other coordinate by 1, which means setting another coordinate from 1 to 0. So it's a swap.

Let me implement a swap-based local search that's more efficient:

```python
def swap_local_search(h, n, budget_check, max_iter=5000):
    """Try all possible swaps (i,j) where h[i]=1, h[j]=0"""
    c5_best = compute_c5(h)
    h_best = h.copy()
    
    ones = np.where(h_best >= 0.5)[0]
    zeros = np.where(h_best < 0.5)[0]
    
    for it in range(max_iter):
        if budget_check() < 1.0:
            break
        
        improved = False
        best_swap_c5 = c5_best
        best_i, best_j = -1, -1
        
        # Try all swaps (this is O(n²/4) evaluations)
        for i in ones:
            for j in zeros:
                trial = h_best.copy()
                trial[i] = 0.0
                trial[j] = 1.0
                # No need to project since sum is preserved
                c5 = compute_c5(trial)
                if c5 < best_swap_c5:
                    best_swap_c5 = c5
                    best_i, best_j = i, j
        
        if best_i >= 0:
            h_best[best_i] = 0.0
            h_best[best_j] = 1.0
            c5_best = best_swap_c5
            improved = True
            ones = np.where(h_best >= 0.5)[0]
            zeros = np.where(h_best < 0.5)[0]
        
        if not improved:
            break
    
    return h_best, c5_best
```
