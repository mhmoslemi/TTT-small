∂f_k/∂h[j] = for each term h[i]*(1-h[i+k]) where j appears:
- If j = i (0 ≤ j ≤ n-1-k): contribution (1-h[j+k])
- If j = i+k (k ≤ j ≤ n-1): contribution -h[j-k]

So ∂f_k/∂h[j] = (1-h[j+k]) * 1[j ≤ n-1-k] - h[j-k] * 1[j ≥ k]

For k < 0 (which represents the negative lag in np.correlate), it's similar by symmetry.

def project_feasible(h, n):

        if abs(diff) < 1e-15:

            h[mask] += diff / cnt
        else:
            h[:] += diff / n

    if src_n == dst_n:

def thue_morse(n):
    h = np.zeros(n)
    for i in range(n):
        cnt = 0
        v = i
        while v:
            cnt ^= (v & 1)
            v >>= 1
        h[i] = 1.0 if cnt == 1 else 0.0
    return h
