    dx = _G_DX
    corr = np.correlate(x, 1.0 - x, mode='full')
    beta = _G_BETA
    max_c = np.max(corr)
    shifted = corr - max_c
    exps = np.exp(np.clip(beta * shifted, -500, 500))
    weights = exps / np.sum(exps)
    
    grad = np.zeros(n)
    for k in range(2*n-1):
        w = weights[k] * dx
        if w < 1e-12:
            continue
        offset = k - (n-1)
        if offset >= 0:
            length = n - offset
            grad[:length] += w * (1.0 - x[offset:offset+length])
            grad[offset:] -= w * x[:length]
        else:
            a = -offset
            length = n - a
            grad[a:] += w * (1.0 - x[:length])
            grad[:length] -= w * x[a:]
    
    # Add penalty gradient for sum constraint
    sum_pen_grad = 2.0 * 1000.0 * (np.sum(x) - _G_TGT)
    grad += sum_pen_grad
    
    return grad

Actually, one more thought: the problem has a nice structure. Let me define:
- a_k = the overlap at lag k (i.e., corr[k] * dx)
- We want to minimize max_k a_k

The "worst" lags are typically the small lags (k close to 0 in absolute value) and large lags (k close to ±(n-1)). The small lags have the most pairs, while the large lags have the fewest.

For the small lags: a_k ≈ dx * (n-|k|) * E[h(1-h)] (if h is "random")
For the large lags: a_k ≈ dx * (n-|k|) * E[h(1-h)] but with fewer terms

The key insight: at lag 0, a_0 = dx * sum h[i]*(1-h[i]). If h is binary, this is 0. If h is continuous, this is dx * sum(h - h²) = dx * (n/2 - sum(h²)).

So for continuous h, the lag-0 value is related to the "variance" of h. To minimize lag-0, we want h to be as binary as possible.

For non-zero lags, the situation is more subtle.

1. A binary (or near-binary) sequence with good autocorrelation properties
2. A smooth function with careful amplitude modulation

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')

def project_feasible(h, n):
    h = np.array(h, dtype=float).copy()
    h = np.clip(h, 0.0, 1.0)
    target = n / 2.0
    for _ in range(100):
        diff = target - np.sum(h)
        if abs(diff) < 1e-14:
            break
        mask = (h > 1e-10) & (h < 1.0 - 1e-10)
        cnt = int(np.sum(mask))
        if cnt > 0:
            h[mask] += diff / cnt
        else:
            h[:] += diff / n
        h = np.clip(h, 0.0, 1.0)
    return h

    n = _G_N
    dx = _G_DX
    corr = np.correlate(x, 1.0 - x, mode='full')
    beta = _G_BETA

    val = (max_c + np.log(np.sum(exps)) / beta) * dx
    penalty = 1e6 * (np.sum(x) - _G_TGT) ** 2
    return val + penalty

    dx = _G_DX
