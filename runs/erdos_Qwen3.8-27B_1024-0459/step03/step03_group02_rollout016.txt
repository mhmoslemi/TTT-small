- From -sum_{i=m}^{n-1} h[i]*h[i-m]:

  - h[j] appears as h[i-m] when i-m=j, i=j+m (if 0 <= j <= n-1-m): contributes -h[j+m]

So d/dh[j] full[k] = [1 if m<=j<n] - [h[j-m] if m<=j<n] - [h[j+m] if j<n-m]
