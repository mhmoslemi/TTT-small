C5 = max_k (dx * corr[k]) where corr = np.correlate(h, 1-h, mode='full')

The length of corr is 2n-1. The indices go from 0 to 2n-2, corresponding to shifts from -(n-1) to n-1.

For shift 0 (index n-1): corr[n-1] = sum_i h[i]*(1-h[i]) = sum_i h[i] - sum_i h[i]² 
Since sum h[i] = n/2, this is n/2 - sum h[i]².
To minimize this, we want to MAXIMIZE sum h[i]², which means making h as close to 0 or 1 as possible.

For large shifts (near the edges): the overlap length is small, so the correlation is small.
The maximum is likely at small to moderate shifts.

Let me also think about whether there's a structural insight I'm missing.

For the Erdős problem, the function h represents a set (or fuzzy set) of measure 1 in [0,2]. The overlap ∫h(x)(1-h(x+k))dx measures how much of the set is "shifted to the complement". 

If h is the indicator of a set A of measure 1 in [0,2], then:
∫_R 1_A(x)(1-1_A(x+k))dx = |A| - |A ∩ (A-k)| = 1 - |A ∩ (A-k)|

So C5 = max_k (1 - |A ∩ (A-k)|). To minimize C5, we want to maximize min_k |A ∩ (A-k)|.

For a set A of measure 1 in [0,2], the autocorrelation |A ∩ (A-k)| is:
- At k=0: |A| = 1
- As |k| increases: generally decreases

The minimum of |A ∩ (A-k)| over all k gives us 1 - C5.

This is related to the "thin" structure of A. If A is a "sparse" set (like a Cantor set), the autocorrelation drops to 0 for large k. But the maximum of 1-|A∩(A-k)| is determined by the k values where |A∩(A-k)| is smallest.

For a set that's "spread out" (like a fat interval), |A∩(A-k)| stays high for small k and drops linearly for larger k. The maximum of 1-|A∩(A-k)| would be at the drop-off.

For a set that's "clumped" into several pieces, the autocorrelation has multiple peaks.

I think the optimal structure is something like several intervals of appropriate length, arranged to minimize the worst-case gap.

But for a discrete grid, the optimal might be a specific binary (or near-binary) pattern.

def project_feasible(h, target_sum):
    h = np.asarray(h, dtype=float).copy()
    h = np.clip(h, 0.0, 1.0)
    for _ in range(25):
        diff = target_sum - np.sum(h)
        if abs(diff) < 1e-15:
            break
        # Adjust free variables
        mask = (h > 1e-12) & (h < 1.0 - 1e-12)
        cnt = np.count_nonzero(mask)
        if cnt == 0:
            # Adjust all
            if diff > 0:
                mask = h < 1.0
            else:
                mask = h > 0.0
            cnt = np.count_nonzero(mask)
            if cnt == 0:
                break
        step = diff / cnt
        # Limit step
        if step > 0:
            max_step = (1.0 - h[mask]).min() if cnt > 0 else step
            step = min(step, max_step)
        else:
            min_step = h[mask].min() if cnt > 0 else step
            step = max(step, -min_step)
        h[mask] += step
        h = np.clip(h, 0.0, 1.0)
    return h

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def get_active_lags(corr, n_active=5):
    """Get indices of the top n_active correlations"""
    idx = np.argsort(corr)[-n_active:]
    return idx

def exact_subgradient(h, active_idx):
    """Compute exact subgradient at the active lags (uniform weights)"""
    n = len(h)
    dx = 2.0 / n
    grad = np.zeros(n)
    for k_idx in active_idx:
        k = k_idx - (n - 1)
        if k >= 0:
            i_lo = 0
            i_hi = n - 1 - k
        else:
            i_lo = -k
            i_hi = n - 1
        if i_lo > i_hi:
            continue
        m_vals = np.arange(i_lo, i_hi + 1)
        j_vals = m_vals + k
        # d/dh[m]: (1-h[m+k]) - h[m-k] (if valid)
        grad[m_vals] += (1.0 - h[j_vals])
        j2 = m_vals - k
        valid = (j2 >= 0) & (j2 < n)
        grad[m_vals[valid]] -= h[j2[valid]]
    # Average over active lags
    grad /= len(active_idx)
    return grad * dx

def smooth_obj(h, beta, target, penalty_weight):

    mx = cw.max()
    sm = mx + np.log(np.sum(np.exp(beta * (cw - mx)))) / beta
    sum_err = np.sum(h) - target
    return sm * dx + penalty_weight * sum_err * sum_err
