Wait, the numpy documentation says:
c_k = ∑_n a_{n+k} * conj(v_n)

For real signals: c_k = ∑_n a_{n+k} * v_n

The "full" output has length N + M - 1 where N = len(a), M = len(v).
The k-th output (0-indexed) corresponds to lag k - (M-1).

So for a = h, v = 1-h, both length n:
output[k] = ∑_{valid n} h[n + k - (n-1)] * (1-h[n])

Let d = k - (n-1) (the lag):
- d ≥ 0: output[n-1+d] = ∑_{n=0}^{n-1-d} h[n+d] * (1-h[n])

  Substituting m = n-e: ∑_{m=0}^{n-1-e} h[m] * (1-h[m+e])
  This counts: m where h[m]=1 and h[m+e]=0. I.e., "1...0" at distance e.

So the full correlation array has:
- Index n-1: lag 0, value = 0 (for binary)
- Index n-1+d (d>0): count of "0 then 1" at distance d
- Index n-1-d (d>0): count of "1 then 0" at distance d

        k_max = int(np.argmax(corr))
        d_star = abs(k_max - (n - 1))
        
        # Find candidate 1-positions that contribute to the peak
        candidates_i = []
        for i in ones_list:
            if d_star > 0:
                if i - d_star >= 0 and h[i - d_star] == 0:
                    candidates_i.append(i)
                if i + d_star < n and h[i + d_star] == 0:
                    candidates_i.append(i)
            # Also consider positions where removing the 1 helps other near-max lags
        
        if not candidates_i:
            # Fallback: random
            i = ones_list[rng.randint(len(ones_list))]
        else:
            i = candidates_i[rng.randint(len(candidates_i))]
        
        # Find a good j to swap with
        # Prefer j that doesn't create new peaks
        best_j = None
        best_new_max = float('inf')
        n_try = 50
        for _ in range(n_try):
            j = zeros_list[rng.randint(len(zeros_list))]
            h[i] = 0.0
            h[j] = 1.0
            g[i] = 1.0
            g[j] = 0.0
            new_corr = np.correlate(h, g, mode='full')
            new_max = float(np.max(new_corr))
            h[i] = 1.0
            h[j] = 0.0
            g[i] = 0.0
            g[j] = 1.0
            if new_max < best_new_max:
                best_new_max = new_max
                best_j = j
        
        if best_j is not None and best_new_max < cur_max:
            j = best_j
            h[i] = 0.0
            h[j] = 1.0
            g[i] = 1.0
