**2. Mathematical Specification**  
- **Variables**: `h` is a piecewise constant function defined by:
  - **Knots**: Positions `x_j` where `h` changes (parameters to optimize).  
  - **Levels**: Values `y_i` of `h` between knots.  
  - **Integral Constraint**: Let `Δx = 2 / n_points`. The integral is satisfied by ensuring the total "length" under `h` is `Δx * n_points / 2`.  
- **Objectives**:  
  - Primary: Minimize `C_5` (maximum overlap integral).  
  - Secondary: Maintain feasibility (0 ⟦ h(x) ⟧ 1 and integral = 1).  
- **Representation**:  
  - Define a sorted list of knots `X = [x_0, x_1, ..., x_{m-1}]` in `[0, 2]`.  
  - `h` changes value at these knots. For example, if `h` is constant `c₁` on `(x_0, x_1)`, `c₂` on `(x₁, x_₂)`, etc.
