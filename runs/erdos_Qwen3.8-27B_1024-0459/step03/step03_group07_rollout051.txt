where max_unaffected is constant, corr[k]+C_k*(x-old) are affine in x, and rest0+x-x² is concave.

The maximizer over x is the upper envelope of these functions. We want to minimize this upper envelope.

For the affine functions: the minimum of the max of affine functions occurs where two of them are equal (or at a boundary). We can find this by:
1. Computing all breakpoints where pairs of affine functions cross
2. Evaluating f at each breakpoint and at the boundaries 0 and 1
3. Taking the minimum

Number of affine functions: O(n). Number of pairs: O(n²). That's too many.

Alternative: use a grid + refinement approach, which is what I had before. 30 grid points + 40 refinement steps should be enough.

Actually, for a piecewise linear function (ignoring the quadratic), the minimum of the max can be found by:
- Sorting the affine functions by slope
- Maintaining the upper envelope
But this is complex. Let me just use grid + refinement.

Let me also think about whether to use subgradient methods as an alternative. The subgradient of the objective at h is:
- For the lag k* that achieves the max: gradient of corr[k*] with respect to h
- This is a vector with O(n) non-zero entries

Subgradient method: h_{new} = project(h - lr * grad, [0,1]^n, sum=n/2)

This might be slower to converge than coordinate descent for this problem, but it has the advantage of being simple and globally convergent (with diminishing step sizes).

Let me go with fast coordinate descent as the main algorithm, with:
- Multiple resolutions: 256, 384, 512
- Many sweeps (100-500)
- Grid + refinement for 1D subproblem
- Periodic projection

Let me also add a "random restart" strategy: after coordinate descent converges, perturb the solution and run again.
