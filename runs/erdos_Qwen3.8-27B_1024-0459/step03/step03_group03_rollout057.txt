g[i] = (2/n) * sum_{d=-(n-1)}^{n-1} w[n-1+d] * gc(h,d)[i]

This can be computed as:
g[i] = (2/n) * [w[n-1]*(1-2h[i]) + sum_{d=1}^{n-1} w[n-1+d]*(1-h[i+d])*1[i+d<n] - sum_{d=1}^{n-1} w[n-1+d]*h[i-d]*1[i-d≥0] + sum_{d=1}^{n-1} w[n-1-d]*(1-h[i-d])*1[i-d≥0] - sum_{d=1}^{n-1} w[n-1-d]*h[i+d]*1[i+d<n]]

Let me define:
A[d] = w[n-1+d] for d=1,...,n-1 (positive lags)
B[d] = w[n-1-d] for d=1,...,n-1 (negative lags, i.e., weight at lag -d)

Then:
g[i] = (2/n) * [w[n-1]*(1-2h[i]) 
    + sum_{d=1}^{min(n-1-i, n-1)} A[d]*(1-h[i+d])
    - sum_{d=1}^{min(i, n-1)} A[d]*h[i-d]
    + sum_{d=1}^{min(i, n-1)} B[d]*(1-h[i-d])
    - sum_{d=1}^{min(n-1-i, n-1)} B[d]*h[i+d]]

This is O(n) per i, so O(n²) total. For n=160, that's about 25600 operations per gradient, which is fine.

But actually, I can compute this more efficiently using convolution! 

sum_{d=1}^{n-1} A[d]*(1-h[i+d]) for fixed i is like a cross-correlation of A with (1-h), evaluated at position i.

Let me use np.correlate for this:
s1[i] = sum_{d=1}^{min(n-1-i, n-1)} A[d]*(1-h[i+d])

This is correlate(1-h, A, 'full') evaluated at certain positions... actually it's a bit tricky with the bounds.

You know what, for n=160-300, the O(n²) loop is fast enough. Let me just do it straightforwardly.

Actually wait, I can vectorize the whole thing:

g[i] = (2/n) * [w0*(1-2*h[i]) + sum_j h[j]*(B-j-i related stuff) - sum_j A[j-i] related stuff]

Let me just use the loop approach but only for the top-M weights:

```python
def _smooth_grad(h, n, topm=20):
```

Now let me think about the overall algorithm:

Phase 1: Start from initial_h_values, project, evaluate
Phase 2: Smooth descent with annealing (beta: 10→50→200→1000→5000)
Phase 3: Binary refinement: round to nearest binary, do local swap search
Phase 4: Continuous refinement from the binary point
Phase 5: Try at different resolutions

For the binary local search, the key insight is: if h is binary (0 or 1), then a swap (i,j) where h[i]=1, h[j]=0 changes the correlation at lag d by:
- For lag d where both i+d and i, j+d and j are valid:
  - c[n-1+d] changes by: removing h[i](1-h[i+d]) + h[j](1-h[j+d]) and adding (1-h[j])(1-h[j+d])... 

Wait, after swap, h'[i]=0, h'[j]=1. The change in c[n-1+d]:
- Old contribution involving position i: h[i]*(1-h[i+d]) = 1*(1-h[i+d])
- Old contribution involving position j: h[j]*(1-h[j+d]) = 0*(1-h[j+d]) = 0
- Also i appears as the "second" factor: h[i-d]*(1-h[i]) = h[i-d]*0 = 0 (wait, h[i]=1 so 1-h[i]=0)
- And j appears: h[j-d]*(1-h[j]) = h[j-d]*1 = h[j-d]

After swap:
- Position i (now 0): h'[i]*(1-h'[i+d]) = 0
- Position j (now 1): h'[j]*(1-h'[j+d]) = 1*(1-h[j+d])
- i as second: h'[i-d]*(1-h'[i]) = h[i-d]*1 (since h'[i]=0)
- j as second: h'[j-d]*(1-h'[j]) = h[j-d]*0 = 0

Change in c[n-1+d] from position i (as first factor): 0 - (1-h[i+d]) = h[i+d] - 1
Change from position i (as second factor): h[i-d] - 0 = h[i-d]
Change from position j (as first factor): (1-h[j+d]) - 0 = 1-h[j+d]
Change from position j (as second factor): 0 - h[j-d] = -h[j-d]

Total: Δc[n-1+d] = (h[i+d]-1) + h[i-d] + (1-h[j+d]) - h[j-d]
                     = h[i+d] + h[i-d] - h[j+d] - h[j-d] - h[i+d] + h[i-d]... 

Wait let me redo this more carefully.

c[n-1+d] = sum_{valid i} h[i] * (1-h[i+d])

A position p contributes to c[n-1+d] in two ways:
1. As the "first" index: h[p] * (1-h[p+d]) if 0≤p<n and 0≤p+d<n
2. As the "second" index (p = i+d, so i = p-d): h[p-d] * (1-h[p]) if 0≤p-d<n and 0≤p<n

After swap (h[i]: 1→0, h[j]: 0→1):

For position i:
- As first: was 1*(1-h[i+d]) = 1-h[i+d], now 0*(1-h'[i+d]) = 0. Change: -(1-h[i+d])
- As second: was h[i-d]*(1-1) = 0, now h[i-d]*(1-0) = h[i-d]. Change: +h[i-d]
  (assuming h[i-d] doesn't change, i.e., i-d ≠ j)

For position j:
- As first: was 0*(1-h[j+d]) = 0, now 1*(1-h[j+d]) = 1-h[j+d]. Change: +(1-h[j+d])
- As second: was h[j-d]*(1-0) = h[j-d], now h[j-d]*(1-1) = 0. Change: -h[j-d]

Also, positions i+d and j+d might be affected if they equal j or i respectively:
- If i+d = j: then h[i+d] = h[j] = 0, and after swap h'[j] = 1. This affects the "first" contribution of i.
  Actually, the "first" contribution of i is h[i]*(1-h[i+d]). If i+d=j, this is h[i]*(1-h[j]) = 1*1 = 1 before, and h'[i]*(1-h'[j]) = 0*0 = 0 after. Change: -1.
  But I already computed this as -(1-h[i+d]) = -(1-0) = -1. ✓

- If j+d = i: then h[j+d] = h[i] = 1, after swap h'[i] = 0. The "first" contribution of j is h[j]*(1-h[j+d]) = 0*(1-1) = 0 before, h'[j]*(1-h'[j+d]) = 1*0 = 0 after. Change: 0.
  My formula gives +(1-h[j+d]) = 1-1 = 0. ✓

- If i-d = j: affects "second" contribution of i. h[i-d]*(1-h[i]) = h[j]*0 = 0 before. h'[i-d]*(1-h'[i]) = h'[j]*1 = 1 after. Change: +1.
  My formula gives +h[i-d] = h[j] = 0. Hmm, that's wrong because h[j] changes to 1.

This is getting complicated. For the local search, it's easier to just compute c5 before and after the swap directly. For n=160, computing the full correlation is O(n²) ≈ 25600 ops, which is fast.

```python
import numpy as np
from scipy.optimize import minimize
import time

_t0 = 0.0
_tb = 1300.0
_ng = 160
_bv = 100.0


def _tl():
    return max(0.0, _tb - (time.time() - _t0) - 3.0)


def _c5(h):
    n = len(h)
    c = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(c)) * (2.0 / n)


def _proj(h, n):
    h = np.clip(np.asarray(h, dtype=np.float64), 0.0, 1.0)
    for _ in range(40):
        d = 0.5 * n - h.sum()
        if abs(d) < 1e-14:
            break
        free = (h > 1e-12) & (h < 1.0 - 1e-12)
        k = int(free.sum())
        if k > 0:
            h[free] += d / k
        else:
            h[:] = 0.5
        np.clip(h, 0.0, 1.0, out=h)
    return h


def _interp_f(h, ns, nd):
    if ns == nd:
        return h.copy()
    xs = (np.arange(ns) + 0.5) * (2.0 / ns)
    xd = (np.arange(nd) + 0.5) * (2.0 / nd)
    return np.interp(xd, xs, h)


def _gc(h, d):
    n = len(h)
    g = np.zeros(n)
    if d == 0:
        g[:] = 1.0 - 2.0 * h
    elif d > 0:
        g[:n - d] += (1.0 - h[d:])
        g[d:] -= h[:n - d]
    else:
        d = -d
        g[d:] += (1.0 - h[:n - d])
        g[:n - d] -= h[d:]
    return g


def _smooth_max(c, beta):
    mx = c.max()
    if beta < 1e6:
        sh = c - mx
        ex = np.exp(beta * sh)
        s = ex.sum()
        if s > 1e-30:
            sm = mx + np.log(s) / beta
        else:
            sm = mx
    else:
        sm = mx
    return float(sm)


def _smooth_grad(h, n, beta, topm=30):
    c = np.correlate(h, 1.0 - h, mode='full')
    mx = c.max()
    if topm < len(c):
        top_idx = np.argpartition(c, -topm)[-topm:]
    else:
        top_idx = np.arange(len(c))
    w = c[top_idx] - mx
    if beta < 1e6:
        w = np.exp(beta * w)
        sw = w.sum()
        if sw < 1e-30:
            w = np.zeros_like(w)
            w[top_idx == int(np.argmax(c))] = 1.0
            sw = 1.0
        w /= sw
    else:
        w = np.zeros_like(w)
        w[top_idx == int(np.argmax(c))] = 1.0
    g = np.zeros(n)
    for idx, wt in zip(top_idx, w):
        if wt < 1e-12:
            continue
        d = int(idx) - (n - 1)
        g += wt * _gc(h, d)
    return g * (2.0 / n)


def _sg_anneal(h0, n, n_iter, rng):
    h = h0.copy()
    best = h.copy()
    bc = _c5(h)
    betas = [20, 40, 80, 150, 300, 600, 1200, 2500, 5000]
    steps_per = max(20, n_iter // len(betas))
    for beta in betas:
        if _tl() < 5:
            break
        for s in range(steps_per):
            if _tl() < 5:
                break
            g = _smooth_grad(h, n, beta)
            gn = float(np.linalg.norm(g))
            if gn < 1e-14:
                break
            g /= gn
            moved = False
            for a in [0.04, 0.02, 0.01, 0.005, 0.025, 0.015, 0.007, 0.003]:
                h2 = _proj(h - a * g, n)
                c2 = _c5(h2)
                if c2 < _c5(h) - 1e-14:
                    h = h2
                    if c2 < bc:
                        best = h2.copy()
                        bc = c2
                    moved = True
                    break
            if not moved:
                break
    return best, bc


def _slsqp_beta(h0, n, beta, maxiter):
    global _ng, _bv
    _ng = n
    _bv = beta

    def obj(x):
        c = np.correlate(x, 1.0 - x, mode='full')
        mx = float(np.max(c))
        sh = c - mx
        ex = np.exp(_bv * sh)
        s = ex.sum()
        if s < 1e-30:
            sm = mx
        else:
            sm = mx + np.log(s) / _bv
        return sm * (2.0 / _ng)

    def cons_fun(x):
        return x.sum() - 0.5 * _ng

    try:
        r = minimize(obj, h0, method='SLSQP',
                     bounds=[(0.0, 1.0)] * n,
                     constraints=[{'type': 'eq', 'fun': cons_fun}],
                     options={'maxiter': maxiter, 'ftol': 1e-16, 'iprint': 0})
        return _proj(np.asarray(r.x, dtype=np.float64), n)
    except Exception:
        return _proj(h0.copy(), n)


def _binary_local(h0, n, n_rounds, rng):
    """Local search on near-binary solutions using 0-1 swaps focused on hard lags."""
    h = _proj(h0.copy(), n)
    # Round to binary
    h_bin = (h > 0.5).astype(np.float64)
    # Fix count
    num_ones = int(h_bin.sum())
    target = n // 2
    if num_ones > target:
        # Remove excess ones (from those closest to 0.5)
        ones = np.where(h_bin == 1)[0]
        order = np.argsort(h[ones])  # lowest h values first (most uncertain)
        for idx in order[:num_ones - target]:
            h_bin[ones[idx]] = 0
    elif num_ones < target:
        zeros = np.where(h_bin == 0)[0]
        order = np.argsort(-h[zeros])  # highest h values first
        for idx in order[:target - num_ones]:
            h_bin[zeros[idx]] = 1
    best = h_bin.copy()
    bc = _c5(best)
    for rnd in range(n_rounds):
        if _tl() < 3:
            break
        # Find hardest lags
        c = np.correlate(best, 1.0 - best, mode='full')
        top_lags = np.argpartition(c, -5)[-5:]
        improved = False
        ones = np.where(best > 0.999)[0]
        zeros = np.where(best < 0.001)[0]
        if len(ones) == 0 or len(zeros) == 0:
            break
        # Try swaps targeting the hardest lags
        tried = 0
        max_tries = 500
        while tried < max_tries:
            if _tl() < 2:
                break
            k = top_lags[rng.randint(len(top_lags))]
            d = int(k) - (n - 1)
            i = ones[rng.randint(len(ones))]
            j = zeros[rng.randint(len(zeros))]
            tried += 1
            h2 = best.copy()
            tmp = h2[i]
            h2[i] = h2[j]
            h2[j] = tmp
            c2 = _c5(h2)
            if c2 < bc - 1e-14:
                best = h2
                bc = c2
                improved = True
                c = np.correlate(best, 1.0 - best, mode='full')
                top_lags = np.argpartition(c, -5)[-5:]
                ones = np.where(best > 0.999)[0]
                zeros = np.where(best < 0.001)[0]
        if not improved:
            # Try systematic: for each hard lag, find best swap
            c = np.correlate(best, 1.0 - best, mode='full')
            top_lags = np.argpartition(c, -3)[-3:]
            found = False
            for lag in top_lags:
                d = int(lag) - (n - 1)
                best_delta = 0
                best_pair = None
                for ii in range(len(ones)):
                    for jj in range(len(zeros)):
                        i2 = ones[ii]
                        j2 = zeros[jj]
                        h2 = best.copy()
                        tmp = h2[i2]
                        h2[i2] = h2[j2]
                        h2[j2] = tmp
                        c2 = np.correlate(h2, 1.0 - h2, mode='full')
                        if c2[lag] < c[lag] - 1e-10 and c2.max() < bc + 1e-10:
                            delta = float(c2.max()) - bc
                            if delta < best_delta - 1e-10:
                                best_delta = delta
                                best_pair = (i2, j2)
                if best_pair is not None:
                    i2, j2 = best_pair
                    best[i2], best[j2] = best[j2], best[i2]
                    bc = _c5(best)
                    found = True
                    ones = np.where(best > 0.999)[0]
                    zeros = np.where(best < 0.001)[0]
            if not found:
                break
    return best, bc


def _cont_finish(h0, n, rng, steps=200):
    """Final continuous refinement."""
    h = _proj(h0.copy(), n)
    best = h.copy()
    bc = _c5(h)
    for s in range(steps):
        if _tl() < 4:
            break
        g = _smooth_grad(h, n, 500.0)
        gn = float(np.linalg.norm(g))
        if gn < 1e-14:
            g = _smooth_grad(h, n, 100.0)
            gn = float(np.linalg.norm(g))
            if gn < 1e-14:
                break
        g /= gn
        best_step = None
        for a in [0.03, 0.015, 0.007, 0.003, 0.02, 0.01, 0.005, 0.002, 0.008, 0.012]:
            h2 = _proj(h - a * g, n)
            c2 = _c5(h2)
            if c2 < _c5(h) - 1e-15:
                best_step = (h2, c2)
                break
        if best_step is None:
            # Try max-specific gradient
            c = np.correlate(h, 1.0 - h, mode='full')
            kmax = int(np.argmax(c))
            g2 = _gc(h, kmax - (n - 1))
            gn2 = float(np.linalg.norm(g2))
            if gn2 < 1e-14:
                break
            g2 /= gn2
            for a in [0.03, 0.015, 0.007, 0.003]:
                h2 = _proj(h - a * g2, n)
                c2 = _c5(h2)
                if c2 < _c5(h) - 1e-15:
                    best_step = (h2, c2)
                    break
        if best_step is None:
            break
        h, c2 = best_step
        if c2 < bc:
            best = h.copy()
            bc = c2
    return best, bc


def _full_optimize(h0, n, rng, time_limit):
    """Full optimization pipeline for a given resolution."""
    h = _proj(h0.copy(), n)
    c5 = _c5(h)
    best = h.copy()
    bc5 = c5

    # Phase 1: SLSQP with moderate smoothness
    for beta in [50, 200, 500]:
        if _tl() < 15:
            break
        h2 = _slsqp_beta(h, n, beta, 300)
        c2 = _c5(h2)
        if c2 < c5:
            h, c5 = h2, c2
        if c5 < bc5:
            best, bc5 = h.copy(), c5

    # Phase 2: Annealed subgradient
    h, c5 = _sg_anneal(h, n, 500, rng)
    if c5 < bc5:
        best, bc5 = h.copy(), c5

    # Phase 3: Binary local search
    h2, c2 = _binary_local(h, n, 30, rng)
    if c2 < bc5:
        best, bc5 = h2.copy(), c2
        h = h2.copy()

    # Phase 4: Continuous from binary
    h, c5 = _cont_finish(h, n, rng, 300)
    if c5 < bc5:
        best, bc5 = h.copy(), c5

    # Phase 5: SLSQP with high smoothness
    for beta in [1000, 3000]:
        if _tl() < 12:
            break
        h2 = _slsqp_beta(h, n, beta, 350)
        c2 = _c5(h2)
        if c2 < c5:
            h, c5 = h2, c2
        if c5 < bc5:
            best, bc5 = h.copy(), c5

    # Phase 6: More subgradient + binary
    h, c5 = _sg_anneal(h, n, 300, rng)
    if c5 < bc5:
        best, bc5 = h.copy(), c5
    h2, c2 = _binary_local(h, n, 20, rng)
    if c2 < bc5:
        best, bc5 = h2.copy(), c2
        h = h2.copy()

    # Phase 7: Final polish
    h, c5 = _cont_finish(h, n, rng, 200)
    if c5 < bc5:
        best, bc5 = h.copy(), c5

    if _tl() > 10:
        h2 = _slsqp_beta(best, n, 6000, 400)
        c2 = _c5(h2)
        if c2 < bc5:
            best, bc5 = h2.copy(), c2
            h = h2.copy()
        h, c5 = _cont_finish(h, n, rng, 150)
        if c5 < bc5:
            best, bc5 = h.copy(), c5

    return _proj(best, n), bc5


def _multi_start(n, rng):
    """Create diverse binary initializations with n/2 ones."""
    inits = []
    # Random
    arr = np.zeros(n)
    arr[:n // 2] = 1.0
    idx = rng.permutation(n)
    arr2 = np.zeros(n)
    arr2[idx[:n // 2]] = 1.0
    inits.append(arr2)
    # Block pattern
    arr3 = np.zeros(n)
    arr3[np.arange(0, n, 2)] = 1.0
    if int(arr3.sum()) != n // 2:
        # Fix
        excess = int(arr3.sum()) - n // 2
        if excess > 0:
            ones = np.where(arr3 == 1)[0]
            arr3[ones[-excess:]] = 0
        elif excess < 0:
            zeros = np.where(arr3 == 0)[0]
            arr3[zeros[: -excess]] = 1
    inits.append(arr3)
    # Sierpinski-like
    arr4 = np.zeros(n)
    for i in range(n):
        b = i ^ (i >> 1)
        if (b & 1) == 0:
            arr4[i] = 1.0
    # Fix count
    s = int(arr4.sum())
    if s > n // 2:
        ones = np.where(arr4 == 1)[0]
        arr4[ones[s - n // 2:]] = 0
    elif s < n // 2:
        zeros = np.where(arr4 == 0)[0]
        arr4[zeros[:n // 2 - s]] = 1
    inits.append(arr4)
    return inits

        if _tl() < 40:
            break
        # Interpolate
        hi = _proj(_interp_f(bh, len(bh), nn), nn)
        h2, c2 = _full_optimize(hi, nn, rng, 200)
        if c2 < bc5:
            bh, bc5 = h2, c2
            print("Res n={} C5={:.8f}".format(nn, c2), flush=True)

    # Second pass: more iterations at best resolution
    bn = len(bh)
    if _tl() > 30:
        h, c5 = _sg_anneal(bh, bn, rng.__class__(seed + 1), 400)
        rng2 = np.random.RandomState(seed + 1)
        h, c5 = _sg_anneal(bh, bn, rng2, 400)
        if c5 < bc5:
            bh, bc5 = h, c5
        print("Pass2 n={} C5={:.8f}".format(bn, bc5), flush=True)

    if _tl() > 20:
        h2, c2 = _binary_local(bh, bn, 40, rng)
        if c2 < bc5:
            bh, bc5 = h2, c2
        h, c5 = _cont_finish(bh, bn, rng, 250)
        if c5 < bc5:
            bh, bc5 = h, c5

    if _tl() > 15:
        h2 = _slsqp_beta(bh, bn, 8000, 500)
        c2 = _c5(h2)
        if c2 < bc5:
            bh, bc5 = h2, c2
            h = h2.copy()
        h, c5 = _cont_finish(h, bn, rng, 200)
        if c5 < bc5:
            bh, bc5 = h, c5

    if _tl() > 10:
        h2, c2 = _binary_local(bh, bn, 30, rng)
        if c2 < bc5:
            bh, bc5 = h2, c2
        h, c5 = _cont_finish(bh, bn, rng, 150)
        if c5 < bc5:
            bh, bc5 = h, c5

    # Final polish
    if _tl() > 8:
        h, c5 = _cont_finish(bh, bn, rng, 100)
        if c5 < bc5:
            bh, bc5 = h, c5

    bh = _proj(bh, bn)
    fc5 = _c5(bh)

    try:
        ec = evaluate_erdos_solution(bh)
        if ec < fc5:
            fc5 = ec
    except Exception:
        pass

    print("FINAL n={} C5={:.8f}".format(bn, fc5), flush=True)
    return (bh, fc5, bn)
```
