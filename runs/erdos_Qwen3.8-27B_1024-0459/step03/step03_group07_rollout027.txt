- If j >= k: a += (1 - h[j-k])
- If j <= n-1-k: a += (-h[j+k]), b += h[j+k]

For negative lags (s=1,...,n-1):
- If j <= n-1-s: a += (1 - h[j+s])
- If j >= s: a += (-h[j-s]), b += h[j-s]

Notice: for positive lag k, the conditions j >= k and j <= n-1-k.
For negative lag s, the conditions j <= n-1-s and j >= s.

These are actually the same conditions with k and s! So:
- Positive lag k: affected if j >= k or j <= n-1-k
- Negative lag s: affected if j <= n-1-s or j >= s

For a given j:
- Positive lags affected: k in [1, min(j, n-1)] ∪ [max(1, n-j), n-1]
  Wait: j >= k means k <= j. j <= n-1-k means k <= n-1-j.
  So affected positive lags: k <= j OR k <= n-1-j, i.e., k <= max(j, n-1-j).
  Unaffected: k > j AND k > n-1-j, i.e., k > max(j, n-1-j).
  
  For j = n/2: max(j, n-1-j) = n/2 (approximately). So lags k > n/2 are unaffected.
  For j = 0: max(0, n-1) = n-1. All lags affected.

- Negative lags affected (s): j <= n-1-s OR j >= s, i.e., s <= n-1-j OR s <= j.
  So affected: s <= max(n-1-j, j) = max(j, n-1-j). Same as positive!
  Unaffected: s > max(j, n-1-j).

So the unaffected lags are |k| > max(j, n-1-j) = max(j, n-1-j).

For j near the edges (j=0 or j=n-1): max = n-1, so ALL lags are affected.
For j = n/2: max ≈ n/2, so lags |k| > n/2 are unaffected (about n/2 lags unaffected).

This means for j near the center, about half the lags are unaffected. For j near edges, all are affected.
