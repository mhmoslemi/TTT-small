This subtracts from grad[j] the value h[j+d] for j=0..n-d-1.
So grad[i] -= h[i+d] for i = 0..n-d-1. ✓

Great, the code is correct for d ≥ 0.

For d < 0 (e = -d > 0):

∂out/∂h[i]:

def compute_corr(h):

def lag_grad(h, n, offset):
    grad = np.zeros(n)
    if offset >= 0:
        n_pairs = n - offset
        if n_pairs <= 0:
            return grad
        grad[offset:offset + n_pairs] += (1.0 - h[:n_pairs])
        grad[:n_pairs] -= h[offset:offset + n_pairs]
    else:
        a = -offset
        n_pairs = n - a
        if n_pairs <= 0:
            return grad
        grad[:n_pairs] += (1.0 - h[a:a + n_pairs])
        grad[a:a + n_pairs] -= h[:n_pairs]
    return grad
