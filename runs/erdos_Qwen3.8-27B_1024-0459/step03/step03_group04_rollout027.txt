Let me also reconsider the coefficient computation. I want to make sure it's correct.

For coordinate i, I need: for each shift τ (indexed as m = τ + n - 1), what is the coefficient of h[i] in corr[m]?

corr[m] = sum_j h[j+τ]*(1-h[j]) where τ = m-(n-1), and j ranges over valid indices.

h[i] appears in this sum in two ways:
1. As h[j+τ] = h[i], i.e., j = i-τ. Valid if 0 ≤ i-τ ≤ n-1 AND 0 ≤ j ≤ n-1 (which is the same condition since τ is in [-(n-1), n-1]).
   More precisely, for the correlation sum, we need 0 ≤ j ≤ n-1 AND 0 ≤ j+τ ≤ n-1.
   With j = i-τ: 0 ≤ i-τ ≤ n-1 AND 0 ≤ i ≤ n-1 (second is automatic).
   So valid when max(0, -τ) ≤ i ≤ min(n-1, n-1-τ), i.e., τ ≤ i ≤ n-1 for τ ≥ 0, or 0 ≤ i ≤ n-1+τ for τ < 0 (i.e., 0 ≤ i ≤ n-1-|τ|).
   
   Contribution to corr[m]: 1 * (1-h[j]) = 1-h[i-τ]
   
   Wait, the term is h[j+τ]*(1-h[j]) = h[i]*(1-h[i-τ]). The coefficient of h[i] is (1-h[i-τ]).

2. As (1-h[j]) = (1-h[i]), i.e., j = i. Valid if 0 ≤ i ≤ n-1 AND 0 ≤ i+τ ≤ n-1.

   Contribution to corr[m]: h[j+τ] * (-1) = -h[i+τ]
   
   Wait, the term is h[j+τ]*(1-h[j]) = h[i+τ]*(1-h[i]). The coefficient of h[i] is -h[i+τ].
