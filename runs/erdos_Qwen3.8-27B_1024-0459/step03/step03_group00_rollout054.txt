       = sum_{j=0}^{n-1-t} x[j+t] * (1-x[j])

∂O_{-t}/∂x[j]:
- From x[j+t]: appears when j = i with i in [t, n-1], so j in [t, n-1]. Contribution: (1-x[j-t])
- From -x[j]: appears when j = i-t with i in [t, n-1], so j in [0, n-1-t]. Contribution: -x[j+t]

So for s = -t < 0:
∂O_s/∂x[j] = [j in [t, n-1]] * (1-x[j-t]) - [j in [0, n-1-t]] * x[j+t]
            = [j >= t] * (1-x[j-t]) - [j <= n-1-t] * x[j+t]

Great, this is clean. Let me code the gradient:

```python
def softmax_grad(x, beta):
    n = len(x)
    corr = np.correlate(x, 1.0-x, mode='full')
    m = np.max(corr)
    exps = np.exp(np.clip(beta * (corr - m), -500, 500))
    weights = exps / np.sum(exps)
    
    grad = np.zeros(n)
    for m_idx in range(2*n-1):
        w = weights[m_idx]
        if w < 1e-12:
            continue
        s = m_idx - (n-1)
        
        if s >= 0:
            # [j in [0, n-1-s]] * (1-x[j+s]) - [j in [s, n-1]] * x[j-s]
            if n-1-s >= 0:
                grad[0:n-s] += w * (1.0 - x[s:n])
            if s <= n-1:
                grad[s:n] -= w * x[0:n-s]
        else:
            t = -s
            # [j >= t] * (1-x[j-t]) - [j <= n-1-t] * x[j+t]
            if n-1-t >= 0:
                grad[t:n] += w * (1.0 - x[0:n-t])
                grad[0:n-t] -= w * x[t:n]
    
    return grad * _G_DX
```

Let me verify with s=0:
grad[0:n] += w*(1-x[0:n]) → adds w*(1-x[j])
grad[0:n] -= w*x[0:n] → subtracts w*x[j]
Total for s=0: w*(1-2x[j]). ✓

Now, for the optimization, I'll use L-BFGS-B with:
- Objective: smoothed_max * dx + penalty * (sum(x) - n/2)^2
- Gradient: softmax_grad + 2*penalty*(sum(x)-n/2)*ones
- Bounds: [(0,1)]*n

The penalty should be large enough to maintain feasibility but not so large that it dominates.

Actually, a better approach: since the constraint is linear, I can handle it by projecting after each step. L-BFGS-B handles bounds, and I project the sum constraint.

Or even better: I can fix one variable. Let x[n-1] = n/2 - sum(x[0:n-1]). Then I optimize over x[0:n-1] with bounds [0,1] and the additional constraint that sum(x[0:n-1]) is in [n/2-1, n/2]. L-BFGS-B doesn't handle this linear constraint, but I can add it as a penalty.

Let me just use the penalty approach with a moderate penalty (say 100) and verify feasibility at the end.

Now for the local search: after the gradient-based optimization, I'll do a careful single-coordinate search.

For a single coordinate j, the objective as a function of x[j]=b (with all other x fixed) is:
C5(b) = max_k O_k(b) * dx

where O_k(b) is affine in b (since only one variable is changing):
O_k(b) = O_k(current) + (b - x[j]) * ∂O_k/∂x[j]

So for each k, O_k(b) = A_k + B_k * b where A_k and B_k are constants (computed once).

The problem becomes: minimize max_k (A_k + B_k * b) subject to 0 <= b <= 1 and sum constraint.

If we ignore the sum constraint: this is a 1D min-max of linear functions, solved by finding the b where the two "active" constraints intersect, or at a boundary.

With the sum constraint: if we change x[j] from a to b, we need to also adjust another coordinate (or the constraint is violated). For simplicity, let's ignore it during local search and project at the end.

The 1D min-max of linear functions:
- Sort by B_k (slope)
- The optimal b is where the upper envelope changes
- Can be solved by binary search or by checking all intersection points

For practical purposes, I'll just do a grid search over b in [0,1] with fine steps, or use the fact that the optimum must be at an intersection of two lines or at a boundary.

Actually, for efficiency, let me just try b = 0, b = 1, and b at the intersections of the top few O_k's.

import numpy as np
from scipy.optimize import minimize
import time

_G_N = 0
_G_BETA = 100.0
_G_START = 0.0
_G_BUDGET = 1300.0
_G_DX = 1.0
_G_TGT = 0.0
_G_PENALTY = 100.0


def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr)) * dx


def compute_corr(h):
    return np.correlate(h, 1.0 - h, mode='full')


def project_feasible(h, n):
    h = np.array(h, dtype=float).copy()
    h = np.clip(h, 0.0, 1.0)
    target = n / 2.0
    for _ in range(50):
        diff = target - np.sum(h)
        if abs(diff) < 1e-14:
            break
        # Distribute to interior points
        mask = (h > 1e-10) & (h < 1.0 - 1e-10)
        cnt = int(np.sum(mask))
        if cnt > 0:
            h[mask] += diff / cnt
        else:
            h[:] += diff / n
        h = np.clip(h, 0.0, 1.0)
    # Final exact fix
    diff = target - np.sum(h)
    if abs(diff) > 1e-13:
        # Find a point to adjust
        idx = int(np.argmax((h > 0.01) & (h < 0.99)))
        h[idx] += diff
        h = np.clip(h, 0.0, 1.0)
    return h


def interp_to(src_h, src_n, dst_n):
    if src_n == dst_n:
        return src_h.copy()
    xp = (np.arange(src_n) + 0.5) * 2.0 / src_n
    x_new = (np.arange(dst_n) + 0.5) * 2.0 / dst_n
    return np.interp(x_new, xp, src_h)


def remaining_time():
    return max(0.0, _G_BUDGET - (time.time() - _G_START) - 5.0)


def smooth_obj_and_grad(x):
    """Compute smoothed objective and gradient."""
    n = _G_N
    dx = _G_DX
    beta = _G_BETA
    penalty = _G_PENALTY
    
    corr = np.correlate(x, 1.0 - x, mode='full')
    m = np.max(corr)
    shifted = corr - m
    exps = np.exp(np.clip(beta * shifted, -500, 500))
    logsum = np.log(np.sum(exps))
    obj = (m + logsum / beta) * dx
    
    # Penalty for sum constraint
    s = np.sum(x) - _G_TGT
    obj += penalty * s * s
    
    # Gradient
    weights = exps / np.sum(exps)
    grad = np.zeros(n)
    voh = 1.0 - x  # 1-x
    
    for m_idx in range(2 * n - 1):
        w = weights[m_idx]
        if w < 1e-12:
            continue
        s_shift = m_idx - (n - 1)
        if s_shift >= 0:
            # O_s = sum_{i=0}^{n-1-s} x[i]*(1-x[i+s])
            # d/dx[j]: [j in [0,n-1-s]]*(1-x[j+s]) - [j in [s,n-1]]*x[j-s]
            n1s = n - s_shift
            if n1s > 0:
                grad[0:n1s] += w * (1.0 - x[s_shift:s_shift + n1s])
                grad[s_shift:n] -= w * x[0:n1s]
        else:
            t = -s_shift
            n1t = n - t
            if n1t > 0:
                grad[t:n] += w * (1.0 - x[0:n1t])
                grad[0:n1t] -= w * x[t:n]
    
    grad *= dx
    grad += 2.0 * penalty * s
    
    return obj, grad


def local_search_1d(h, n, top_k=5, max_rounds=200):
    """Analytical 1D local search: for each coordinate, find optimal value."""
    global _G_N, _G_DX, _G_TGT
    _G_N = n
    _G_DX = 2.0 / n
    _G_TGT = n / 2.0
    
    c5_best = compute_c5(h)
    h_best = h.copy()
    
    for r in range(max_rounds):
        if remaining_time() < 3.0:
            break
        corr = compute_corr(h_best)
        # Get top-k worst shifts
        top_idx = np.argsort(corr)[-top_k:][::-1]
        
        improved = False
        for j in range(n):
            if remaining_time() < 2.0:
                break
            # For coordinate j, compute how each top-k O_s changes
            # O_s(b) for b in [0,1]
            # Compute coefficients: O_s = A_s + B_s * b
            # where the contribution from x[j] to O_s is:
            #   for s>=0: [j in [0,n-1-s]]*(1-x[j+s]) - [j in [s,n-1]]*x[j-s]
            #   for s<0, t=-s: [j>=t]*(1-x[j-t]) - [j<=n-1-t]*x[j+t]
            
            # Current x[j] = a
            a = h_best[j]
            
            # For each top shift, compute the coefficient B_s (derivative w.r.t. x[j])
            # and the current O_s
            B_vals = np.zeros(len(top_idx))
            for ii, m_idx in enumerate(top_idx):
                s = m_idx - (n - 1)
                B = 0.0
                if s >= 0:
                    n1s = n - s
                    if j < n1s:
                        B += (1.0 - h_best[j + s])
                    if j >= s:
                        B -= h_best[j - s]
                else:
                    t = -s
                    n1t = n - t
                    if j >= t:
                        B += (1.0 - h_best[j - t])
                    if j < n1t:
                        B -= h_best[j + t]
                B_vals[ii] = B
            
            # O_s(b) = corr[m_idx] - a * B_s + b * B_s = corr[m_idx] + (b-a) * B_s
            # We want to minimize max_s O_s(b) * dx, subject to 0<=b<=1
            # Equivalent to minimize max_s (corr[m_idx] + (b-a)*B_s)
            
            # Optimal b: find b in [0,1] minimizing max of lines
            # The maximum of lines as a function of b is a convex piecewise-linear function
            # Minimum is at a breakpoint or boundary
            
            # Quick approach: try b=0, b=1, and intersection points of adjacent lines
            best_b = a
            best_val = c5_best
            
            # Try a few candidate values
            candidates = [0.0, 1.0, a]
            # Add some nearby values
            for delta in [0.01, 0.05, 0.1, 0.2, 0.5, -0.01, -0.05, -0.1, -0.2, -0.5]:
                candidates.append(a + delta)
            # Add intersection points of top-2 lines
            if len(top_idx) >= 2:
                for i1 in range(min(3, len(top_idx))):
                    for i2 in range(i1+1, min(3, len(top_idx))):
                        B1, B2 = B_vals[i1], B_vals[i2]
                        C1 = corr[top_idx[i1]] - a * B1
                        C2 = corr[top_idx[i2]] - a * B2
                        if abs(B1 - B2) > 1e-10:
                            b_int = (C2 - C1) / (B1 - B2)
                            if 0 <= b_int <= 1:
                                candidates.append(b_int)
            
            for b in candidates:
                b = np.clip(b, 0.0, 1.0)
                if abs(b - a) < 1e-8:
                    continue
                h_test = h_best.copy()
                h_test[j] = b
                h_test = project_feasible(h_test, n)
                c5_test = compute_c5(h_test)
                if c5_test < best_val - 1e-12:
                    best_val = c5_test
                    best_b = b
                    h_best = h_test.copy()
                    improved = True
                    break  # restart from new h
            
            if best_b != a and h_best[j] != a:
                continue  # already handled
            
            if best_b != a:
                # Apply the best change
                h_best[j] = best_b
                h_best = project_feasible(h_best, n)
                c5_best = compute_c5(h_best)
                improved = True
        
        if not improved:
            break
    
    return h_best, c5_best


def local_search_pairs(h, n, top_k=3, max_rounds=50):

    h_best = h.copy()

        if remaining_time() < 3.0:
            break
        corr = compute_corr(h_best)
        top_idx = np.argsort(corr)[-top_k:][::-1]
        
        improved = False
        # Try random pairs
        n_pairs = min(200, n * 2)
        for _ in range(n_pairs):
            if remaining_time() < 2.0:
                break
            i = np.random.randint(n)
            j = np.random.randint(n)
            if i == j:
                continue

                for bj in [0.0, 1.0]:
                    if abs(bi - h_best[i]) < 1e-8 and abs(bj - h_best[j]) < 1e-8:
                        continue
                    h_test = h_best.copy()
                    h_test[i] = bi
                    h_test[j] = bj
                    h_test = project_feasible(h_test, n)
                    c5_test = compute_c5(h_test)
                    if c5_test < c5_best - 1e-12:

                        improved = True
                        break
                if improved:
                    break
            if improved:
                break
        
        if not improved and r > 5:
            break
    
    return h_best, c5_best


def make_thue_morse(n):
    h = np.zeros(n)
    for i in range(n):
        cnt = 0
        v = i
        while v:
            cnt ^= (v & 1)
            v >>= 1
        h[i] = 1.0 if cnt == 1 else 0.0
    return h


def make_golden_ratio(n):
    h = np.zeros(n)
    gr = (1.0 + np.sqrt(5.0)) / 2.0
    for i in range(n):
        frac = (i * gr) % 1.0
        h[i] = 1.0 if frac < 0.5 else 0.0
    return h


def make_random_bin(rng, n):
    h = np.zeros(n)
    idx = rng.permutation(n)
    h[idx[:n // 2]] = 1.0
    return h
