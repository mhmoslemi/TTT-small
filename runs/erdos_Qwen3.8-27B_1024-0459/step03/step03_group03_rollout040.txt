Let me try a different angle: **iterative reweighting / ADMM**.

The problem min_h max_k q_k(h) can be written as:
min_{h, t} t
s.t. q_k(h) ≤ t for all k
     ∑h = n/2, 0≤h≤1

Using Lagrange multipliers λ_k ≥ 0 for each constraint q_k(h) ≤ t:
L = t + ∑_k λ_k (q_k(h) - t) = t(1-∑λ_k) + ∑_k λ_k q_k(h)

The dual problem:
max_{λ≥0, ∑λ=1} min_h ∑_k λ_k q_k(h) subject to ∑h=n/2, 0≤h≤1

The inner problem is a QP (minimize a quadratic with box and equality constraints). If we can solve this QP efficiently, we can use a cutting-plane or bundle method on the dual.

The QP: min_h ∑_k λ_k ∑_i h[i](1-h[i+k])dx
= min_h ∑_i h[i](1-h[i]) - ∑_k λ_k ∑_i h[i]h[i+k]dx
= -∑_i h[i]h[i] (since h[i](1-h[i]) = h[i] - h[i]²)

Wait, for continuous h, h[i](1-h[i+k]) is not the same as h[i](1-h[i]) (which would be for k=0). Let me be more careful:

q_k(h) = ∑_i h[i](1-h[i+k])dx = ∑_i h[i]dx - ∑_i h[i]h[i+k]dx = 1 - ∑_i h[i]h[i+k]dx

So ∑_k λ_k q_k(h) = 1 - ∑_k λ_k ∑_i h[i]h[i+k]dx = 1 - h^T (∑_k λ_k S_k) h (approximately, where S_k is the shift matrix)

This is a quadratic form! If Q = ∑_k λ_k S_k is positive definite, the QP min h^T Q h subject to constraints is convex. But Q is a sum of shift matrices, which may or may not be PD.

In practice, for a "well-spread" set of λ's, Q should be PD (it's like a weighted sum of all shifts, which is like a convolution operator that's positive definite for reasonable weights).

So the inner QP is:
min_h h^T Q(λ) h
s.t. ∑h = n/2
     0 ≤ h ≤ 1

This can be solved with scipy.optimize.minimize (SLSQP) or a dedicated QP solver.

The outer problem (max over λ) is a concave maximization (the inner value function is concave in λ), so we can use subgradient methods.

This is a **Dinkelbach's algorithm** or **bisection** approach. Let me implement it:

1. Start with λ = uniform (all lags equally weighted)
2. Solve the QP: min h^T Q(λ) h s.t. constraints
3. The solution h* tells us which lags are "active" (q_k(h*) close to the max)
4. Update λ to put more weight on the active lags
5. Repeat

This is essentially the **column generation** approach for the dual.
