    h = np.array(h, dtype=np.float64).copy()

        d = 0.5 * n - h.sum()
        if abs(d) < 1e-13:
            break

        if nf > 0:
            h[free] += d / nf
        else:

                order = np.argsort(h)[::-1]
                for idx in order:
                    room = 1.0 - h[idx]
                    take = min(room, d)
                    h[idx] += take
                    d -= take
                    if d < 1e-14: break
            else:

                    room = h[idx]
                    take = min(room, -d)

Let me also think about one more thing: the `_proj` function. It needs to be correct and efficient. The projection onto {h : 0 ≤ h ≤ 1, sum(h) = n/2} is:
1. Clip to [0,1]
2. If sum < n/2, distribute the deficit among the entries that can be increased (not at 1)
3. If sum > n/2, distribute the surplus among the entries that can be decreased (not at 0)

The issue is that after a single adjustment, the sum might not be exactly n/2 due to clipping. So we iterate.

A more efficient approach:
1. Clip to [0,1]
2. Compute the deficit d = n/2 - sum(h)
3. If d > 0: we need to increase the sum by d
   - The "free" entries are those with 0 < h < 1
   - If there are enough free entries, we can distribute d evenly
   - Otherwise, we push the free entries to 1 and distribute the remaining deficit among the entries at 0
4. Similarly for d < 0

This is essentially the Euclidean projection onto the hypercube intersected with a hyperplane, which has a closed form. But the iterative approach is simpler and works well enough.

        if nn >= 32 and nn % 2 == 0:
            res_candidates.append(nn)

    for nn in res_candidates:
        if _tl() < _tb * 0.12:
            break
        hi = _proj(_interp(bh, bn, nn), nn)
        # Quick refinement: SLSQP + gradient + swaps
        h2 = _slsqp(hi, nn, 150, 150)
        c2 = _c5(h2)
        if c2 <= _c5(hi):
            hi = h2
        h2, c2 = _grad_desc(hi, nn, 200, 50, 500, rng)
        h2, c2 = _swap_opt(h2, nn, 25, rng)
        h2, c2 = _grad_desc(h2, nn, 150, 200, 1000, rng)
        h2, c2 = _swap_opt(h2, nn, 20, rng)
        if c2 < bc5:
            bh, bc5, bn = h2, c2, nn
            print("Res n={} C5={:.8f}".format(nn, bc5), flush=True)

    # Phase 3: Final polish at best resolution (~20% budget)
    if _tl() > 20:
        bh, bc5 = _swap_opt(bh, bn, 40, rng)
        if _tl() > 15:
            h2 = _slsqp(bh, bn, 5000, 300)
            c2 = _c5(h2)
            if c2 < bc5:
                bh, bc5 = h2, c2
        bh, bc5 = _grad_desc(bh, bn, 300, 500, 5000, rng)
        bh, bc5 = _coord_desc(bh, bn, 100, rng)
        bh, bc5 = _swap_opt(bh, bn, 30, rng)

    # Try one more resolution bump if time allows
    if _tl() > 30:
        nn = bn + 4
        if nn % 2 == 0:
            hi = _proj(_interp(bh, bn, nn), nn)
            h2 = _slsqp(hi, nn, 300, 200)
            h2, c2 = _grad_desc(h2, nn, 200, 100, 1000, rng)
            h2, c2 = _swap_opt(h2, nn, 20, rng)
            if c2 < bc5:
                bh, bc5, bn = h2, c2, nn
                print("Bump n={} C5={:.8f}".format(nn, bc5), flush=True)

    bh = _proj(bh, bn)
    fc5 = _c5(bh)
    try:
        ec = evaluate_erdos_solution(bh)
        if ec < fc5:
            fc5 = ec
    except Exception:
        pass
    print("FINAL n={} C5={:.8f}".format(bn, fc5), flush=True)
    return (bh, fc5, bn)
