```python
def compute_swap_delta(h, a, b, n):
    h_rev = h[::-1]
    delta = np.zeros(2*n - 1)
    delta[n-1-a : 2*n-1-a] += h - 1.0      # a as source
    delta[a : a+n] += h_rev                   # a as target
    delta[n-1-b : 2*n-1-b] += 1.0 - h        # b as source
    delta[b : b+n] += -h_rev                  # b as target
    return delta
```

This is O(n) and uses only numpy vectorized operations! Very fast.
