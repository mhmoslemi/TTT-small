Unlike the parent solution, which uses binary mutations and gradient-based phases separately, here we interweave resolution adjustments with adaptive smooth optimization. The rationale is that transitioning between resolutions allows us to explore both high-detail and low-detail regions of the solution space, preventing premature convergence. This method capitalizes on the trade-off between resolution and optimization cost: finer grids allow better function representation but require more expensive evaluations, while coarser grids facilitate global search.

Key limitations and heuristics:
- The method relies on the validity of the provided initial_h_values as a starting point for resolution transitions.
- Simulated annealing is used with exponentially increasing local searches to ensure robustness.
- All optimizations proceeds through explicit resolution steps with feasibility projection and interpolation.

Mathematical specification:
Variables: h is a function on [0,2] decomposed into samples [h0, h1, ..., h_{n-1}].
The objective is scaled to be comparable across resolutions:

C₅(h) = (2/n) · max_{k} ∑_{i=0}^{n-1} h[i] · (1 - h[i+k % n])

where the convolution is computed with linear mode and n is the current resolution.

Constraints:
1. 0 ≤ h[i] ≤ 1 for all i
2. ∑_{i} h[i] · Δx = 1 (with Δx = 2 / n)

The computations are done exactly via:
- clamping to [0,1] after each iteration (projection step)
- explicit summation for feasibility and score calculation

Implementation procedure:

      Use linear interpolation to downscale best_global

Phase 2: Local Refinement
During final resolution, perform:

Comparison of candidates:
