This looks reasonable. But I'm concerned about the inner loop: 100 trials × O(n log n) correlate each = 100 × 5000 = 500K ops per outer iteration. At ~10⁹ ops/sec, that's 0.5ms per outer iteration. In 100 seconds: 200K outer iterations. Each reduces the max by at least 1 (count unit), so we can reduce by up to 200K count units. Starting from ~97 max count (at n=512), we'd be done quickly if the reduction is monotone.

But in practice, the reduction won't be monotone (we might get stuck). The no_improve counter handles that.

Let me also think about the continuous refinement. After binary local search, we can try:
1. Slightly perturb the binary solution
2. Run SLSQP with smooth max
3. This might squeeze out a bit more improvement

Let me also consider: should I try different resolutions? The problem says we can choose n freely. Let me try n=256, 512, 1024.

At n=256: dx = 2/256 = 1/128. C₅ = max_count / 128.
At n=512: dx = 2/512 = 1/256. C₅ = max_count / 256.
At n=1024: dx = 2/1024 = 1/512. C₅ = max_count / 512.

The average count at lag is (n/2)²/(2n-1) ≈ n/8.
At n=256: avg ≈ 32, so C₅_avg ≈ 32/128 = 0.25
At n=512: avg ≈ 64, so C₅_avg ≈ 64/256 = 0.25
At n=1024: avg ≈ 128, so C₅_avg ≈ 128/512 = 0.25

So the average C₅ is the same regardless of resolution (as expected, since it's approximating the same integral). The question is how well we can distribute the counts above average.

For the target C₅ = 0.38085:
At n=512: max_count ≤ 0.38085 × 256 ≈ 97.5
At n=256: max_count ≤ 0.38085 × 128 ≈ 48.7
At n=1024: max_count ≤ 0.38085 × 512 ≈ 195.0

The "excess" over average:
At n=512: 97.5 - 64 = 33.5
At n=256: 48.7 - 32 = 16.7
At n=1024: 195 - 128 = 67

The relative excess (excess/avg):
At n=512: 33.5/64 ≈ 0.52
At n=256: 16.7/32 ≈ 0.52
At n=1024: 67/128 ≈ 0.52

So the relative difficulty is the same at all resolutions. The absolute difficulty (number of counts to reduce) is larger at higher resolution, but the relative difficulty is the same.

However, the local search might work better at lower resolution because:
1. Fewer variables → easier to search
2. Fewer lags → fewer constraints to satisfy
3. Each "step" (swap) has a larger relative impact

So let me try multiple resolutions and see which gives the best bound.

Actually, I just realized something important. The C₅ value depends on the resolution! A solution that achieves C₅ = 0.38 at n=256 might achieve C₅ = 0.381 at n=512 (due to discretization). So we should evaluate at the resolution we report.

But the problem says "Choose n_points freely to minimize the exact task objective." So we should choose the n that gives the lowest C₅.

Let me now think about the overall algorithm structure:

1. Get initial solution from parent (n=512)
2. Binarize it
3. Run binary local search at n=512
4. Also try at n=256 (downsample, binarize, local search)
5. Also try at n=1024 (upsample, binarize, local search)
6. For the best binary solution at each resolution, try continuous refinement
7. Return the best overall

Let me code this up properly. I'll also add a "kick" mechanism: when stuck, make a random perturbation to escape local optima.

One more thought: the binary local search as described is a form of "best improvement" local search (we try 100 random swaps and take the best). A "first improvement" strategy (take the first improving swap) might be faster per iteration but might get stuck more easily. Let me use a hybrid: try 20-50 swaps and take the best, but limit the number of trials to keep each iteration fast.

Let me also add a "multi-start" component: try different initial binary configurations (not just the parent rounded).

import numpy as np
from scipy.optimize import minimize

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr)) * dx


def project_feasible(h, n):
    h = np.array(h, dtype=float).copy()
    h = np.clip(h, 0.0, 1.0)
    target = n / 2.0
    for _ in range(500):
        diff = target - np.sum(h)
        if abs(diff) < 1e-14:
            break
        mask = (h > 1e-10) & (h < 1.0 - 1e-10)
        cnt = np.count_nonzero(mask)
        if cnt > 0:
            h[mask] += diff / cnt
        else:
            h[:] += diff / n
        h = np.clip(h, 0.0, 1.0)
    return h


def binarize_h(h, n):
    h_bin = (h >= 0.5).astype(np.float64)
    n_ones = int(np.sum(h_bin))
    target = n // 2
    if n_ones > target:
        ones_idx = np.where(h_bin == 1)[0]
        order = np.argsort(h[ones_idx])
        for k in range(n_ones - target):
            h_bin[ones_idx[order[k]]] = 0.0
    elif n_ones < target:
        zeros_idx = np.where(h_bin == 0)[0]
        order = np.argsort(-h[zeros_idx])
        for k in range(target - n_ones):
            h_bin[zeros_idx[order[k]]] = 1.0
    return h_bin


def find_reducing_swaps_vectorized(h, n, d_offset):
    ones = np.where(h == 1)[0]
    zeros = np.where(h == 0)[0]
    
    ip = ones + d_offset
    im = ones - d_offset
    valid_ip = (ip >= 0) & (ip < n)
    valid_im = (im >= 0) & (im < n)
    
    h_ip = np.ones(len(ones))
    h_ip[valid_ip] = h[ip[valid_ip]]
    h_im = np.zeros(len(ones))
    h_im[valid_im] = h[im[valid_im]]
    
    A = ones[(h_ip == 0) & (h_im == 0)]
    A2 = ones[(h_ip == 1) & (h_im == 0)]
    
    jp = zeros + d_offset
    jm = zeros - d_offset
    valid_jp = (jp >= 0) & (jp < n)
    valid_jm = (jm >= 0) & (jm < n)
    
    h_jp = np.ones(len(zeros))
    h_jp[valid_jp] = h[jp[valid_jp]]
    h_jm = np.zeros(len(zeros))
    h_jm[valid_jm] = h[jm[valid_jm]]
    
    B = zeros[(h_jp == 1) & (h_jm == 0)]
    B2 = zeros[(h_jm == 1) & (h_jp == 1)]
    
    return A, B, A2, B2

def smooth_max_c5(h, n, K, beta):
    corr = np.correlate(h, 1.0 - h, mode='full')
    idx = np.argsort(-corr)[:K]
    c_top = corr[idx]
    m = np.max(c_top)
    sh = np.clip(beta * (c_top - m), -50.0, 50.0)
    ex = np.exp(sh)
    val = (m + np.log(ex.sum()) / beta) * (2.0 / n)
    return val


def smooth_max_grad(h, n, K, beta):
    corr = np.correlate(h, 1.0 - h, mode='full')
    idx = np.argsort(-corr)[:K]
    c_top = corr[idx]
    m = np.max(c_top)
    sh = np.clip(beta * (c_top - m), -50.0, 50.0)
    ex = np.exp(sh)
    w = ex / ex.sum()
    dx = 2.0 / n
    g = np.zeros(n)
    for i in range(K):
        wi = w[i] * dx
        if wi < 1e-15:
            continue
        k = idx[i]
        offset = k - (n - 1)
        if offset >= 0:
            npairs = n - offset
            g[offset:] += wi * (1.0 - h[:npairs])
            g[:npairs] -= wi * h[offset:]
        else:
            a = -offset
            npairs = n - a
            g[:npairs] += wi * (1.0 - h[a:])
            g[a:] -= wi * h[:npairs]
    return g


def slsqp_refine(h, n, K, beta, maxiter=300):
    def obj(x):
        return smooth_max_c5(x, n, K, beta)
    
    def grad(x):
        return smooth_max_grad(x, n, K, beta)
    
    def cfun(x):
        return np.sum(x) - n / 2.0
    
    def cjac(x):
        return np.ones(n)
    
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': cfun, 'jac': cjac}]
    
    h_proj = project_feasible(h, n)
    try:
        res = minimize(obj, h_proj, jac=grad, method='SLSQP',
                       bounds=bounds, constraints=cons,
                       options={'maxiter': maxiter, 'ftol': 1e-16, 'iprint': 0})
        if res.x is not None:
            h_new = project_feasible(res.x, n)
            return h_new
    except Exception:
        pass
    return h_proj


def interp_to(src_h, src_n, dst_n):
    xp = (np.arange(src_n) + 0.5) * 2.0 / src_n
    x_new = (np.arange(dst_n) + 0.5) * 2.0 / dst_n
    return np.interp(x_new, xp, src_h)
