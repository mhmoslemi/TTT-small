18. **What kind of structure achieves low maximum correlation?**

    We need a binary sequence where the "1-0" pairs are spread as evenly as possible across all offsets. This means:
    - The sequence should not have any preferred distance between 1s and 0s
    - It should be "equidistributed" in the sense that for every offset, the number of 1-0 transitions is about the same

    This is related to the concept of a "perfect difference set" or "Singer difference set" in combinatorial design theory!

    A (v, k, λ) difference set in Z_v is a subset D of size k such that every non-zero element of Z_v can be written as d₁ - d₂ for exactly λ pairs (d₁, d₂) ∈ D × D.

    If we have a perfect difference set, the autocorrelation is perfectly flat!

    For our problem: we want a subset S of {0, 1, ..., n-1} of size n/2 such that the "circular autocorrelation" is as flat as possible.

    A (v, k, λ) difference set has v = k(k-1)/λ + 1 parameters. For k = n/2 and v = n:
    n = (n/2)(n/2-1)/λ + 1
    λ ≈ (n/2)(n/2-1)/(n-1) ≈ n/4

    So λ ≈ n/4, which means the circular autocorrelation at each non-zero lag is λ (or k-λ, depending on convention). This gives a perfectly flat circular autocorrelation!

    However, perfect difference sets only exist for certain parameter values. For k = n/2, we need n to be of the form k(k-1)/λ + 1 for integer λ. This is very restrictive.

    But we can use "almost" difference sets or "Barker sequences" which have nearly flat autocorrelation.

    Barker sequences of length L have the property that the aperiodic autocorrelation is at most 1 for all non-zero lags. They exist for L = 2, 3, 4, 5, 7, 11, 13.

    For our problem, we need length n sequences with flat autocorrelation. Barker sequences are too short. But we can use:
    - m-sequences (from finite fields)
    - Legendre sequences
    - Or construct sequences using the "floor" method: S = {floor(i * n/2) : i = 0, ..., n/2-1} (van der Corput type)
