def compute_c5(h):

    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')

def compute_corr(h):
    return np.correlate(h, 1.0 - h, mode='full')

def project_feasible(h, n):
    h = np.array(h, dtype=float).copy()

        if abs(diff) < 1e-14:
            break
        mask = (h > 1e-10) & (h < 1.0 - 1e-10)
        cnt = np.count_nonzero(mask)
        if cnt > 0:
            h[mask] += diff / cnt
        else:
            h[:] += diff / n
        h = np.clip(h, 0.0, 1.0)
    return h

def smooth_max(corr, beta):
    m = np.max(corr)
    shifted = beta * (corr - m)
    clipped = np.clip(shifted, -50.0, 50.0)
    ex = np.exp(clipped)
    return m + np.log(np.sum(ex)) / beta

Let me also add one more technique: **alternating minimization over the active set**.

Idea: 
1. Identify the top K lags (those contributing to the max)
2. Solve a QP: min sum_{k in active} corr[k] / K subject to constraints
   (average of top K lags is a smooth approximation to the max)
3. Update the active set
4. Repeat

This is like a cutting-plane method where the "cuts" are the correlation constraints.

For step 2, the objective is a sum of bilinear terms, which is a QP (quadratic program) if we fix the "linearization point." Actually, it's not a standard QP because the bilinear terms couple different h variables.

However, I can use an alternating direction method:
- Fix h and linearize: corr[k] ≈ corr[k]_current + g_k^T (h - h_current)
- Solve: min sum_{k in active} [corr[k]_current + g_k^T (h - h_current)] subject to constraints
  This is an LP!
- Update h
- Go back to linearization

This is essentially a linearization-based method (like the method of conditional gradients or Frank-Wolfe).
