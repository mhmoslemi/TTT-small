### 2. Mathematical specification

**Variables:**  
- **Dimension:** `n` (resolution, 1024 or 2048 by default). Parent n=768 will be interpolated if needed.
- **Function space:** `h: [0,2] → [0,1]` with integral ∫h(x)dx=1.

**Objectives:**  
- **Primary:** Minimize
  ```
  C_5 = max_{k∈Z} dx * |corr[h(i), 1-h(i+k)]|
  ```
  where `dx=2/n`, correlation `corr` uses linear convolution over [0,2].

**Constraints:**  
1. $0 ≤ h_i ≤ 1$ for all i  
2. $\sum h_i = n/2$ (normalized)

**Gradient Components**
For lag k, $\partial C_5/\partial h_i$ is computed via:
∂/∂h_i [h(i) * (1-h(i+k))] = 1 - h(i+k) - [h(i) * ∂(1-h(i+k))/∂h_i] if chain rule applied. But since h(i) and h(i+k) are shared variables, we must compute directional derivatives.

**Gradient Structure**  
Use finite-differences with:
```python
def grad_finite_diff(h, n, dx):
    g = np.zeros(n)
    corr_arr = compute_corr(h)
    max_idx = np.argmax(corr_arr)
    term = dx * corr_arr[max_idx]
    for i in range(n):
        h_i = h[i].copy()
        h_i[i] += 1e-4
        h_pos = project_feasible(h_i, n)
        grad_val = (compute_c5(h_pos) - term) / 1e-4
        g[i] = grad_val
    return g
```

**Gradient-based Optimization**  
We will use:
- **Coordinate Descent (CD):** For sparse gradient regions.
- **BFGS:** For low-dimensional subspaces (when derivatives are cached).

**Feasibility Projection**  
Use projection operator:
```python
def projection_feasible(h, n, tol=1e-6):
    h = np.array(h, dtype=float)
    sum_val = np.sum(h)
    # Normalization
    if abs(np.abs(sum_val) - n/2) > tol and n>0:
        alpha = (2/n) / (sum_val/2)  # Factor to adjust to ∑h_i = n/2
        h *= alpha
    # Optional clipping
    h = np.clip(h, 0, 1)
    return h
```
