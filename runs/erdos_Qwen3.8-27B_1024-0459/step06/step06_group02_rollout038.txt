Actually, let me think about this more simply. If h is a smooth function (e.g., a sinusoid), then for small k:

The first term h(x)(1-h(x)) is independent of k. So f(h,k) ≈ ∫h(1-h) dx - k*∫h*h' dx + O(k²).

The derivative term ∫h*h' dx = [h²/2]_0² = (h(2)²-h(0)²)/2. For periodic h, this is 0.

So for a periodic smooth h: f(h,k) ≈ ∫h(1-h) dx + O(k²).

The leading term is ∫h(1-h) dx = 1 - ∫h² dx.

To minimize this, we want to maximize ∫h². For h ∈ [0,1] with ∫h=1 on [0,2]:

Min ∫h² = 1/2 (achieved by h=1/2 everywhere).

So the minimum of the leading term is 0 (for binary h), and the maximum is 1/2 (for constant h).

For binary h, the leading term vanishes and we need to look at the k-dependent terms, which give C5 ≈ 0.5 as we computed.

For smooth h, the leading term 1-∫h² is positive, and the k-dependent corrections are smaller. So the optimal h is somewhere in between: "nearly binary" but with some smoothing.

    """Compute gradient using FFT. w has length 2n-1."""
    dx = 2.0 / n
    # w[m] for m=0,...,2n-2 corresponds to lag k=m-(n-1)
    # W[k] = w[k+(n-1)] for k in [-(n-1), ..., n-1]
    
    # We need: g[j] = dx * [sum_m W[m-j] (1-h[m]) - sum_m W[j-m] h[m]]
    # = dx * [conv(W, 1-h)[j] - conv(W_rev, h)[j]] (linear convolution, restricted)
    
    # Using FFT:
    L = 1
    while L < 3*n:  # to avoid circular wrap-around

def grad_sparse(h, w, n, K=50):
    """Compute gradient using only the top K weighted lags."""
    dx = 2.0 / n
    # Get top K lags by weight
    top_idx = np.argsort(-w)[:K]
    g = np.zeros(n)
    for m in top_idx:
        wk = w[m]
        if wk < 1e-15:
            continue
        k = m - (n-1)
        if k >= 0:
            np_ = n - k
            if np_ > 0:
                g[:np_] += wk * (1.0 - h[k:k+np_])
                g[k:] -= wk * h[:np_]
        else:
            a = -k
            np_ = n - a
            if np_ > 0:
                g[a:] += wk * (1.0 - h[:np_])
                g[:np_] -= wk * h[a:a+np_]
    return dx * g

def slsqp_smooth_max(h, n, beta, maxiter=400, ftol=1e-16):
    dx = 2.0 / n

    def obj(x):
        corr = compute_corr(x)
        m = np.max(corr)
        shifted = beta * (corr - m)
        clipped = np.clip(shifted, -60.0, 60.0)
        ex = np.exp(clipped)
        val = (m + np.log(np.sum(ex)) / beta) * dx
        return val

    def grad(x):
        corr = compute_corr(x)
        m = np.max(corr)
        shifted = beta * (corr - m)
        clipped = np.clip(shifted, -60.0, 60.0)
        ex = np.exp(clipped)
        s = ex.sum()
        w = ex / s
        return grad_weighted_direct(x, w, n, K=None)

    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': lambda x: np.sum(x) - n / 2.0,
             'jac': lambda x: np.ones(n)}]

    try:
        res = minimize(obj, h, jac=grad, method='SLSQP',
                       bounds=bounds, constraints=cons,
                       options={'maxiter': maxiter, 'ftol': ftol, 'iprint': 0})
        if res.x is not None:
            h_new = project_feasible(res.x, n)
            if compute_c5(h_new) <= compute_c5(h) + 1e-10:
                return h_new
    except Exception:
        pass
    return h.copy()
