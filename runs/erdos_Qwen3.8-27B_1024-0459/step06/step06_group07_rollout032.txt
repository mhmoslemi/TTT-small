  - Valid when 0 ≤ i0-j < n and 0 ≤ i0 < n
  - i.e., j in [i0-(n-1), i0]

Δc[j] = -(1-h[i0+j]) [for j in [-i0, n-1-i0]] + h[i0-j] [for j in [i0-(n-1), i0]]

And when flipping h[j0] from 0 to 1:
- Terms involving h[j0] as first factor: 0→h[j0]*(1-h[j0+j]) = 1*(1-h[j0+j])
  - Add (1-h[j0+j]) for j in [-j0, n-1-j0]
  
- Terms involving h[j0] as second factor: h[j0-j]*(1-h[j0]) = h[j0-j]*1
  - Before: h[j0-j]*1 (since h[j0]=0, 1-h[j0]=1)
  - Wait no. Before the flip, h[j0]=0, so (1-h[j0]) = 1.
  - The term is h[j0-j]*(1-h[j0]) = h[j0-j]*1 = h[j0-j]
  - After the flip, h[j0]=1, so (1-h[j0]) = 0.
  - The term becomes h[j0-j]*0 = 0.
  - So we REMOVE h[j0-j] for j in [j0-(n-1), j0]

So the total change to c[j] when flipping h[j0] from 0 to 1:
Δc[j] = (1-h[j0+j]) [for j in [-j0, n-1-j0]] - h[j0-j] [for j in [j0-(n-1), j0]]

Combined (remove at i0, add at j0):
Δc[j] = -(1-h[i0+j]) [for j in [-i0, n-1-i0]] + h[i0-j] [for j in [i0-(n-1), i0]]

import numpy as np
import time

def compute_corr(h):
    return np.correlate(h, 1.0 - h, mode='full')

def make_binary(h, n, rng):
    h_bin = (h >= 0.5).astype(np.float64)
    s = int(h_bin.sum())
    target = n // 2
    if s > target:
        ones = np.where(h_bin == 1)[0]
        to_flip = rng.choice(ones, size=s - target, replace=False)
        h_bin[to_flip] = 0.0
    elif s < target:
        zeros = np.where(h_bin == 0)[0]
        to_flip = rng.choice(zeros, size=target - s, replace=False)
        h_bin[to_flip] = 1.0
    return h_bin

def project_feasible(h, n):
    h = np.clip(h, 0.0, 1.0)
    target = n / 2.0
    diff = target - h.sum()
    if abs(diff) > 1e-12:
        h += diff / n
    return np.clip(h, 0.0, 1.0)
