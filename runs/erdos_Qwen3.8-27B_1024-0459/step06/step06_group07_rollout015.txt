  Wait, if j+d=k: old = h[k]*(1-h[j]) = 0*0 = 0, new = h[k]*(1-h[j]) = 1*1 = 1. Change: +1.
  If j+d≠k: old = h[j+d]*0 = 0, new = h[j+d]*1. Change: +h[j+d].

- i=j-d (the h[i+d] = h[j] part): h[j]*(1-h[j-d]) goes from 1*(1-h[j-d]) to 0*(1-h[j-d])=0. Change: -(1-h[j-d]).
  If j-d=k: old = h[j]*(1-h[k]) = 1*1 = 1, new = 0*0 = 0. Change: -1.
  If j-d≠k: Change: -(1-h[j-d]).

- i=k: h[k+d]*(1-h[k]) goes from h[k+d]*1 to h[k+d]*0=0. Change: -h[k+d].
  If k+d=j: old = h[j]*(1-h[k]) = 1*1 = 1, new = 0*0 = 0. Change: -1.
  If k+d≠j: Change: -h[k+d].

- i=k-d: h[k]*(1-h[k-d]) goes from 0*(1-h[k-d])=0 to 1*(1-h[k-d]). Change: +(1-h[k-d]).
  If k-d=j: old = h[k]*(1-h[j]) = 0*0 = 0, new = 1*1 = 1. Change: +1.
  If k-d≠j: Change: +(1-h[k-d]).

So the total change at lag d≥0 (t=m+d) is:
sum of the above 4 contributions (each present only if the corresponding i is valid).

This is O(1) per lag per (j,k) pair! So the total change for all lags is O(n) per (j,k) pair.
