**Nesterov-accelerated projected gradient for smooth max:**

The smooth max of {f_i(x)} is: m_β(x) = (1/β) log(sum exp(β f_i(x)))

Gradient: ∇m_β(x) = sum_i w_i ∇f_i(x) where w_i = exp(β f_i(x)) / sum_j exp(β f_j(x))

Nesterov step:
y_k = x_k + (t_{k-1}-1)/t_k * (x_k - x_{k-1})
x_{k+1} = Proj_C(y_k - α_k ∇m_β(y_k))
t_{k+1} = (1 + sqrt(1+4t_k²))/2

Where Proj_C is projection onto {h: 0≤h≤1, sum(h)=n/2}.

The projection is:
1. Clip to [0,1]
2. Adjust to satisfy sum constraint (add uniform offset to interior points, then re-clip)

This iterates a few times for convergence of the projection.

def nesterov_smooth_max(h, n, beta_start, beta_end, max_iter, alpha0):
    dx = 2.0 / n
    h = project_feasible(h, n)
    best_h = h.copy()
    best_c5 = compute_c5(h)
    
    t = 1.0
    x_old = h.copy()
    
    for it in range(max_iter):
        # Adaptive beta
        beta = beta_start * (beta_end / beta_start) ** (it / max_iter)
        
        # Nesterov extrapolation
        t_new = (1.0 + np.sqrt(1.0 + 4.0 * t * t)) / 2.0
        theta = (t - 1.0) / t_new
        y = h + theta * (h - x_old)
        
        # Compute smooth max gradient at y
        corr = compute_corr(y)
        m = np.max(corr)
        z = beta * (corr - m)
        z = np.clip(z, -50.0, 50.0)
        ez = np.exp(z)
        S = np.sum(ez)
        w = ez / S
        
        # Gradient of smooth max
        g = np.zeros(n)
        for k in range(2 * n - 1):
            wk = w[k]
            if wk < 1e-15:
                continue
            off = k - (n - 1)
            if off >= 0:
                np_ = n - off
                g[off:] += wk * (1.0 - y[:np_])
                g[:np_] -= wk * y[off:]
            else:
                a = -off
                np_ = n - a
                g[:np_] += wk * (1.0 - y[a:])
                g[a:] -= wk * y[:np_]
        g *= dx  # scale by dx since objective is max(corr)*dx
        
        # Step size (Barzilai-Borwein or simple decay)
        alpha = alpha0 / (1.0 + 0.01 * it)
        
        # Gradient step
        x_new = y - alpha * g
        # Project
        x_new = project_feasible(x_new, n)
        
        # Check improvement
        c5_new = compute_c5(x_new)
        if c5_new < best_c5:
            best_c5 = c5_new
            best_h = x_new.copy()
        
        x_old = h
        h = x_new
        t = t_new
    
    return best_h, best_c5
```

def project_feasible(h, n):
    h = np.array(h, dtype=float).flatten()
    target = n / 2.0
    # Bisection for the offset
    lo, hi = -2.0, 2.0
    for _ in range(100):
        mid = (lo + hi) / 2.0
        s = np.sum(np.clip(h + mid, 0.0, 1.0))
        if s < target:
            lo = mid
        else:
            hi = mid
    result = np.clip(h + (lo + hi) / 2.0, 0.0, 1.0)
    return result
```
