where f_k(v) is the k-th correlation value as a function of v (holding other h values fixed).

Each f_k(v) is linear in v (since corr[k] = sum h[j](1-h[j+k]) and h[i] appears linearly in this expression... wait, no.

Actually, corr[k] = sum_n h[n+lag](1-h[n]). If h[i] appears in this sum, it appears as either h[n+lag] = h[i] (so the term is h[i]*(1-h[n]) which is linear in h[i]) or h[n] = h[i] (so the term is h[n+lag]*(1-h[i]) = h[n+lag] - h[n+lag]*h[i], which is also linear in h[i]).

So each f_k(v) is linear in v! That means the max of linear functions is a convex piecewise-linear function of v. We can find the minimum of this convex function by finding the point where the subgradient changes sign.

For coordinate descent, at each step:
1. Fix all h[j] for j ≠ i
2. Find v* = argmin_v max_k f_k(v) where v = h[i] and v ∈ [0,1]
3. Update h[i] = v*

Since f_k(v) is linear in v, max_k f_k(v) is the upper envelope of lines, which is a convex PL function. Its minimum can be found by binary search on the derivative (subgradient).

The subgradient of max_k f_k(v) at v is:
{sum_{k: f_k(v) = max} alpha_k * f_k'(v) : alpha_k ≥ 0, sum alpha_k = 1}

We want to find v where 0 is in the subgradient, i.e., where there exist active k's such that sum alpha_k f_k'(v) = 0.

This is equivalent to finding v where the "left derivative" ≤ 0 ≤ "right derivative".

For a PL convex function, the left derivative at v is min_{k active} f_k'(v) and the right derivative is max_{k active} f_k'(v).

So we want: min_{active k} f_k'(v) ≤ 0 ≤ max_{active k} f_k'(v).

This can be found by binary search!

```python
def smooth_max_grad(h, n, beta):
    corr = compute_corr(h)
    m = corr.max()
    shifted = beta * (corr - m)
    shifted = np.clip(shifted, -50, 50)
    exp_s = np.exp(shifted)
    w = exp_s / exp_s.sum()
    
    # Objective value
    obj = (m + np.log(exp_s.sum()) / beta) * (2.0 / n)
    
    # Gradient: only compute for shifts with significant weight
    g = np.zeros(n)
    threshold = 1e-10
    active = w > threshold
    for k in np.where(active)[0]:
        wk = w[k] * (2.0 / n)
        if wk < 1e-15:
            continue
        lag = k - (n - 1)
        if lag >= 0:
            g[lag:] += wk * (1.0 - h[:n-lag])
            g[:n-lag] -= wk * h[lag:]
        else:
            l = -lag
            g[:n-l] += wk * (1.0 - h[l:])
            g[l:] -= wk * h[:n-l]
    
    return obj, g, corr
```

def compute_corr_fft(h):
    n = len(h)
    v = 1.0 - h
    N = 2 * n  # or next power of 2
    H = np.fft.rfft(h, N)
    V = np.fft.rfft(v, N)
    # Cross-correlation: corr[k] = sum_i h[i+k] * v[i]
    # This is the same as the convolution of h and reversed v
    # Or: corr = ifft(conj(FFT(h)) * FFT(v)) ... need to be careful
    # Actually: np.correlate(h, v) = ifft(conj(FFT(h, N)) * FFT(v, N))
    # with appropriate indexing

    return result
