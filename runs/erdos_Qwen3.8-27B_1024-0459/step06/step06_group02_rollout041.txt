- Do a few iterations of SLSQP with high-beta smooth-max to fine-tune the values.
- Or do coordinate descent: for each coordinate, find the value in [0,1] that minimizes the objective (with other coordinates fixed).

For the coordinate descent approach:
For coordinate i, the objective as a function of h[i] (with all other h fixed) is:
f(h[i]) = max_r C_r(h)

Each C_r as a function of h[i]:
C_r = (terms not involving h[i]) + (terms involving h[i])

The terms involving h[i] in C_r:
- If r > 0 and i ≥ r: h[i]*(1-h[i-r]) → linear in h[i] with coefficient (1-h[i-r])
- If r > 0 and i ≤ n-1-r: (1-h[i])*h[i+r] → linear in h[i] with coefficient -h[i+r] (plus constant h[i+r])
- If r < 0 (a = -r):
  - If i ≤ n-1-a: h[i]*(1-h[i+a]) → linear in h[i] with coefficient (1-h[i+a])
  - If a ≤ i: (1-h[i])*h[i-a] → linear in h[i] with coefficient -h[i-a] (plus constant h[i-a])

Wait, so each C_r is LINEAR in h[i] (when other variables are fixed)! That's because each term involving h[i] is of the form h[i]*c or c*h[i] where c is a constant (depends on other h values).

So C_r(h) = A_r * h[i] + B_r, where A_r and B_r depend on the other h values.

Then f(h[i]) = max_r (A_r * h[i] + B_r).

This is the max of linear functions of h[i], which is a convex piecewise-linear function!

The minimum of a convex piecewise-linear function over [0,1] is either at a breakpoint or at a boundary.

The breakpoints occur where A_r * h[i] + B_r = A_s * h[i] + B_s for some r ≠ s, i.e., h[i] = (B_s - B_r) / (A_r - A_s) (when A_r ≠ A_s).

So for each coordinate i, I can:
1. Compute A_r and B_r for all r.
2. Find all breakpoints in [0,1].
3. Evaluate f at 0, 1, and all breakpoints.
4. Choose the best value.

This is an exact coordinate minimization! And since f is convex in h[i], the minimum is well-defined.

The number of breakpoints is at most O(n^2) (one for each pair of lags), but in practice it's much less. We can find the minimum without enumerating all breakpoints by noting that the minimum of a max of linear functions occurs where two (or more) of the functions are equal and at their maximum.

Actually, a simpler approach: since f is convex and piecewise linear, the minimum over [0,1] occurs at:
- h[i] = 0
- h[i] = 1
- h[i] = (B_s - B_r) / (A_r - A_s) for the pair (r,s) that achieves the maximum at that point

We can find this by:
1. Evaluating f at 0 and 1.
2. Finding the subgradient (set of active lags) at the optimal point.
3. The optimal point is where the subgradient contains 0 (i.e., there exist active lags r, s with A_r > 0 and A_s < 0, and f(r) = f(s) at that point).

This is more complex to implement. A simpler approximation: just evaluate f at 0, 1, and a few candidate values (like 0.25, 0.5, 0.75, and the breakpoints of the top few lags).

Or even simpler: since the function is piecewise linear with at most O(n) pieces (the number of distinct slopes A_r is limited), we can find the minimum by:
1. Computing all A_r values.
2. The minimum is at h[i] = 0 if all A_r ≥ 0 (function is non-decreasing).
3. The minimum is at h[i] = 1 if all A_r ≤ 0 (function is non-increasing).
4. Otherwise, the minimum is at a breakpoint where the function transitions from decreasing to increasing.

For a practical implementation, I'll just evaluate f at h[i] = 0, 1, and the intersection points of the top few C_r values.

This coordinate descent approach is exact (in the sense that each coordinate step finds the exact minimum over that coordinate) and should converge to a local optimum. Combined with the binary local search, it should give a very good solution.

def round_to_binary(h, n):

def compute_A_B(h, n, i):

    For coordinate i, compute A_r and B_r such that
    C_r = A_r * h[i] + B_r for each lag r.
    
    Returns arrays A and B of length 2n-1 (indexed by k = 0, ..., 2n-2).

    #     contribution: h[i]*(1-h[i-r]), so A += (1-h[i-r]), B no change for this part

    #     so A += -h[i-a], B += h[i-a]

    Coordinate descent: for each coordinate i, find the value in [0,1]

    """

    target = n / 2.0

            if time.time() - t_start > time_limit:

            A, B = compute_A_B(h, n, i)

            # - x = 1 (if all A_k <= 0)
            # - x = (B_j - B_i) / (A_i - A_j) where A_i > 0, A_j < 0, and the two lines cross

            neg_mask = A < -1e-10
