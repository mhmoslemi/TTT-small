So: Δcorr[m] = δ_p * [(1-h[p+shift]) - h[p-shift]] + δ_q * [(1-h[q+shift]) - h[q-shift]]

For the pair swap, δ_p = ε, δ_q = -ε:
Δcorr[m] = ε * [(1-h[p+shift]) - h[p-shift] - (1-h[q+shift]) + h[q-shift]]

This is a linear function of ε for each correlation value. The new corr[m] = corr[m] + ε * d[m] where d[m] is as above.

We want to choose ε to minimize max_m (corr[m] + ε * d[m]).

This is a 1D minimization problem! We can solve it by:
1. For each m, the maximum of corr[m] + ε*d[m] over ε is achieved at the endpoint where the line is highest.
2. The minimum over ε of this maximum is at the intersection of the two "highest" lines.

More precisely, we want min_ε max_m (c_m + ε*d_m).

- For ε > 0: the constraint is c_m + ε*d_m ≤ t for all m
- For ε < 0: similar
- The optimal ε is where the two "binding" constraints intersect

h[q]-1 ≤ ε ≤ h[q]
ε ∈ [-h[p], 1-h[p]] ∩ [h[q]-1, h[q]]
