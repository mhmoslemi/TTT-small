Actually, you know what, let me try a completely different approach: **coordinate descent / subgradient method**.

The key observation: the objective max_k c_k is the maximum of a finite number of (bilinear) functions. We can use the following iterative method:

1. Compute all c_k
2. Find the set S of "active" lags (|S| = K, top K)
3. For each active lag k, compute ∂c_k/∂h
4. Take a gradient step in the direction -average of active gradients (or steepest descent on the max)
5. Project to feasible set
6. Repeat

This is essentially a projected subgradient method. With Nesterov acceleration, it should converge.

The issue is that the subgradient of the max is not unique (any convex combination of active gradients works). Using the average of top-K gradients is one choice.

For the line search, we can use backtracking.

```python
def projected_subgradient_c5(h, n, max_iter=5000, K=5, lr0=0.01):
    h = h.copy()
    for t in range(max_iter):
        c = np.correlate(h, 1.0 - h, mode="full")
        # Find top-K lags
        top_K = np.argsort(c)[-K:]
        # Average gradient of top-K lags
        grad = np.zeros(n)
        for k_idx in top_K:
            lag = k_idx - (n - 1)
            if lag >= 0:
                grad[lag:] += (1.0 - h[:n - lag])
                grad[:n - lag] -= h[lag:]
            else:
                grad[:n + lag] += (1.0 - h[-lag:])
                grad[-lag:] -= h[:n + lag]
        grad /= K
        grad *= (2.0 / n)
        # Gradient step
        lr = lr0 / (1.0 + t * 0.01)
        h_new = h - lr * grad
        h_new = project_feasible(h_new, n)
        # Check improvement
        if compute_c5(h_new, n) < compute_c5(h, n) or t < 10:
            h = h_new
        else:
            lr *= 0.5
            h_new = h - lr * grad
            h_new = project_feasible(h_new, n)
            h = h_new
    return h
```
