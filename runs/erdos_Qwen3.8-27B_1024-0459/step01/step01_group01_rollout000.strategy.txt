- Gaussian smoothing prevents sharp discontinuities that cause packing inefficiencies.
- Nelder-Mead optimization ensures continuous improvement, while linear interpolation enhances short-term fit.

**Bottlenecks Addressed**:
1. **Constraint Handling**: Uses iterative clipping and resampling to maintain feasibility.
2. **Grid Resolution**: Dynamically adjusts based on time/budget.
3. **Overhead**: Modular code avoids reinventing optimization tools.

### 2. Mathematical Specification

#### Variables:
- **`n`**: Resolution (divisible by 30 for even shifting).
- **`h`**: Piecewise constant function with values ∈ `{-1, 0, 1}` and normalized sum.

#### Objective:
Minimize **`C_5`** = max_{k} ∫ h(x) h(x+k) dx (adjusted via rounding).

#### Constraints:
- `0 ≤ h[i] ≤ 1` → Handled via `fix_sum`.
- Sum normalization: `sum(h) / n ≈ 0.5` (≈100% clipping iterations).

#### Smoothed Max Objective:
Minimizes (via SLSQP) a smoothed convex upper bound on the Laplace-transformed overlap.
