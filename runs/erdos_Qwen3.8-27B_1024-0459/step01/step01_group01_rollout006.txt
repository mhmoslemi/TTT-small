    n = len(h)
    c = np.correlate(h, 1.0 - h, mode='full')
    cm = c.max()
    p = np.exp((c - cm) / tau)
    p /= p.sum()
    
    # Compute gradient
    grad = np.zeros(n)
    for k in range(len(c)):
        if p[k] < 1e-10:
            continue
        lo = max(0, k - n + 1)
        hi = min(n - 1, k)
        # First term: (1-h[k-m]) for m in [lo, hi]

        idx2 = k - m_range

        grad[m_range[valid2]] += p[k] * (1.0 - h[idx2[valid2]])
        # Second term: -h[m] for m where k-m in [lo, hi], i.e., k-hi <= m <= k-lo

Let me also think about what makes the Erdős problem special. The key insight is:

For a function h on [0,2] with ∫h = 1, we're measuring the "worst-case" overlap between h and its complement shifted by various amounts. The optimal h should be as "spread out" as possible so that no single shift creates large overlap.

For binary functions, this is related to the problem of finding binary sequences with low autocorrelation. Specifically, we want to minimize the maximum "1-0" cross-correlation.

A well-known construction for low cross-correlation is the "m-sequence" or "Kasami sequence", but those are for specific correlations. For our problem, we want to minimize the MAX over all shifts.

For a truly random binary sequence with n/2 ones, the expected 1-0 correlation at each shift is approximately (n/2) * (1/2) = n/4 (for the sum, before multiplying by dx=2/n, giving C₅ ≈ 1/2). Wait, that's the same as the constant function.

Actually no. For a random binary sequence with n/2 ones and n/2 zeros:
- P(h[i]=1, h[i+k]=0) = (1/2)(1/2) = 1/4 (if independent)
- Expected count at lag k: (n-k) * 1/4 ≈ n/4
- C₅ ≈ (n/4) * (2/n) = 1/2

So random binary gives C₅ ≈ 1/2, which is the same as the constant function. We need to do better than random.
