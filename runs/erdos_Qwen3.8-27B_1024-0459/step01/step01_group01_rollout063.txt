    active = np.where(corr >= max_corr - active_tol * max_corr)[0]
    
    # Subgradient of corr[k] w.r.t. h[i]: 1 - h[i+k] - h[i-k]
    # where k = idx - (n-1) for full correlation index idx
    # h[i+k] valid when 0 <= i+k < n
    # h[i-k] valid when 0 <= i-k < n

        # h[i-k] for i in [0,n): valid when 0 <= i-k < n, i.e., k <= i < n+k
        bwd_idx = np.arange(n) - k  # i-k
        bwd_valid = (bwd_idx >= 0) & (bwd_idx < n)
        
        contrib = np.ones(n)  # the "1" in 1 - h[i+k] - h[i-k]
        contrib[fwd_valid] -= h[fwd_idx[fwd_valid]]
        contrib[bwd_valid] -= h[bwd_idx[bwd_valid]]
        grad += contrib
    
    grad /= len(active)
    grad *= dx  # because f = max corr * dx
    
    # Projected gradient step
    h_new = np.clip(h - lr * grad, 0.0, 1.0)
    h_new = fix_sum(h_new, n)

np.correlate(a, v, mode='full') computes:
c_k = sum_n a[n+k] * conj(v[n]) for k = -(len(v)-1), ..., len(a)-1

So for a=h (length n), v=1-h (length n):
c_k = sum_n h[n+k] * (1-h[n]) for valid n (0<=n<n and 0<=n+k<n)

The result has length 2n-1, indexed 0 to 2n-2.
- Index 0: k = -(n-1), i.e., c_{-(n-1)} = sum_n h[n-(n-1)]*(1-h[n]) for valid n = h[1]*(1-h[n-1])... 

Actually, it's easier to think of it as:
result[n-1+k] = sum_m h[m+k] * (1-h[m]) for m such that 0<=m<n and 0<=m+k<n

For k=0: result[n-1] = sum_m h[m]*(1-h[m])
For k=1: result[n] = sum_m h[m+1]*(1-h[m]) for m=0..n-2
For k=-1: result[n-2] = sum_m h[m-1]*(1-h[m]) for m=1..n-1

OK so the "shift" in korrelate is: result[idx] corresponds to shift k = idx - (n-1).

The integral ∫ h(x)(1-h(x+k)) dx is approximated by dx * sum_m h[m] * (1-h[m+k]) for the appropriate range.

Wait, but in the discrete correlation, the shift k goes from -(n-1) to n-1. The integral ∫₀² h(x)(1-h(x+k)) dx would only make sense for k where both h(x) and h(x+k) are defined, i.e., x ∈ [0,2] and x+k ∈ [0,2]. So the effective range of k is [-2, 2] in continuous, or [-(n-1)*dx, (n-1)*dx] in discrete.

The problem statement says C₅ = max_k ∫ h(x)(1-h(x+k)) dx, and the evaluation is max(np.correlate(h, 1-h, mode="full") * dx). So it takes the max over ALL shifts (including negative ones), multiplied by dx.

This is what I've been computing. Good.

So C₅ = max over all k of [dx * sum_{valid m} h[m] * (1-h[m+k])]

        if abs(diff) < 1e-13:
            break
        if diff > 0:

def upsample_to(h, n_new):

    x_new = np.linspace(0.0, 2.0, n_new, endpoint=False)

def round_binary(h, n, rng=None):
