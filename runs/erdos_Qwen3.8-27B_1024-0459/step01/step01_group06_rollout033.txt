For the coordinate descent:

- Optimize h_j while keeping others fixed: the objective becomes a 1D problem
- c_k as a function of h_j is linear: c_k = (const_k) + h_j * (coef_k)
- So the max over k is a piecewise-linear function of h_j
- Minimize it: the minimum is at the point where the "upper envelope" of lines is minimized
- This is a 1D LP! Very fast.

The 1D coordinate descent is appealing because:
- Each step is O(n) (compute the coefficients)
- Very fast per step
- Can do millions of steps in the time budget
- Guaranteed to not increase the objective (if we do exact 1D minimization)

Let me implement the coordinate descent carefully:

For a fixed j, c_k depends on h_j as:
c_k = A_k + h_j * B_k

where A_k and B_k don't depend on h_j.

Specifically, from c_k = sum_i h[i]*(1-h[i+lag]):
- If j appears as the "first" factor: h[j]*(1-h[j+lag]) contributes h_j*(1-h[j+lag])
- If j appears as the "second" factor: h[j-lag]*(1-h[j]) contributes -h[j-lag]*h_j

So B_k = (1-h[j+lag_k]) - h[j-lag_k] (with appropriate bounds)
And A_k = c_k - h_j * B_k (computed at current h_j)

Then we minimize max_k (A_k + h_j * B_k) over h_j ∈ [0, 1] (with the sum constraint handled by adjusting another coordinate, or by treating it as a soft constraint).

The 1D problem min_{x∈[0,1]} max_k (A_k + x*B_k) can be solved by:
- It's the minimum of the upper envelope of lines
- The minimum occurs either at x=0, x=1, or at an intersection of two lines
- We can solve it by: for each pair of lines (k1, k2), find their intersection x* = (A_k2 - A_k1)/(B_k1 - B_k2), check if x* ∈ [0,1], and evaluate the max at x*
- But this is O(n²) which is too slow for millions of steps

Alternative: use bisection or ternary search on x ∈ [0,1] to find the minimum of the convex piecewise-linear function max_k(A_k + x*B_k). This takes O(n * log(precision)) per step.

Actually, the function f(x) = max_k(A_k + x*B_k) is convex in x (as a max of linear functions). So we can use subgradient methods or bisection on the subgradient.

The subgradient of f at x is the set of B_k for k where A_k + x*B_k = max. If all maximizing k have B_k > 0, then f is increasing at x. If all have B_k < 0, f is decreasing. If mixed, x is optimal.

So: bisection on x:
- f'(x) ∈ {sum of B_k for maximizing k} (subgradient)
- If min B_k > 0 (among maximizers): increase x
- If max B_k < 0: decrease x
- Else: x is optimal

Each bisection step is O(n) (compute all A_k + x*B_k and find the max and the corresponding B_k).

For log2(1/epsilon) steps with epsilon = 1e-8: about 27 steps. Each step O(n). So O(27n) per coordinate descent step. For n=300: ~8100 operations. We can do 100,000 steps in a few seconds.

import numpy as np
from scipy.optimize import minimize, linprog
import time

def compute_correlations(h, n):
    return np.correlate(h, 1.0 - h, mode="full")

def compute_c5(h, n):
    c = compute_correlations(h, n)
    return float(np.max(c) * (2.0 / n))

def project_feasible(h, n):
    h = np.asarray(h, dtype=float).copy()
    h = np.clip(h, 0.0, 1.0)
    target = n / 2.0
    for _ in range(500):
        s = h.sum()
        diff = target - s
        if abs(diff) < 1e-15:
            break
        if diff > 0:
            mask = h < 1.0
            cnt = mask.sum()
            if cnt == 0:
                break
            step = min(diff / cnt, (1.0 - h[mask]).min())
            h[mask] += step
        else:
            mask = h > 0.0
            cnt = mask.sum()
            if cnt == 0:
                break
            step = min(-diff / cnt, h[mask].min())
            h[mask] -= step
        h = np.clip(h, 0.0, 1.0)
    # Exact fix
    diff = h.sum() - target
    if abs(diff) > 1e-14:
        # Find entries not at bounds
        free = (h > 1e-12) & (h < 1.0 - 1e-12)
        if free.sum() > 0:
            h[free] -= diff / free.sum()
        h = np.clip(h, 0.0, 1.0)
    return h

def get_c5_grad(h, n):
    """Gradient of c5 = max_k c_k * dx w.r.t. h. Returns (grad, c5_value, k_max)"""
    dx = 2.0 / n
    c = compute_correlations(h, n)
    k_max = np.argmax(c)
    c5_val = c[k_max] * dx
    lag = k_max - (n - 1)
    grad = np.zeros(n)
    if lag >= 0:
        # c = sum_{i=0}^{n-1-lag} h[i]*(1-h[i+lag])
        # d/dh[j] = (1-h[j+lag]) for j in [0, n-1-lag]
        #           - h[j-lag] for j in [lag, n-1]
        if n - 1 - lag >= 0:
            grad[:n - lag] += (1.0 - h[lag:n])
        if lag < n:
            grad[lag:] -= h[:n - lag]
    else:
        l = -lag
        # c = sum_{i=l}^{n-1} h[i]*(1-h[i-l])
        # d/dh[j] = (1-h[j-l]) for j in [l, n-1]
        #           - h[j+l] for j in [0, n-1-l]
        grad[l:] += (1.0 - h[:n-l])
        if l < n:
            grad[:n-l] -= h[l:]
    return grad * dx, c5_val, k_max

def soft_max_value(h, n, beta):
    dx = 2.0 / n
    c = compute_correlations(h, n) * dx
    m = c.max()
    return m + np.log(np.sum(np.exp(c - m))) / beta

def soft_max_grad(h, n, beta):
    dx = 2.0 / n
    c_raw = compute_correlations(h, n)
    c = c_raw * dx
    m = c.max()
    w = np.exp(c - m)
    w_sum = w.sum()
    w /= w_sum
    grad = np.zeros(n)
    for k_idx in range(2 * n - 1):
        wk = w[k_idx]
        if wk < 1e-15:
            continue
        lag = k_idx - (n - 1)
        coeff = wk * dx
        if lag >= 0:
            if n - 1 - lag >= 0:
                grad[:n - lag] += coeff * (1.0 - h[lag:n])
            if lag < n:
                grad[lag:] -= coeff * h[:n - lag]
        else:
            l = -lag
            grad[l:] += coeff * (1.0 - h[:n-l])
            if l < n:
                grad[:n-l] -= coeff * h[l:]
    return grad

def coordinate_descent_step(h, n, j, t0, budget_s):
    """Do one coordinate descent step on h[j]."""
    dx = 2.0 / n
    # Compute A_k and B_k for each lag
    c = compute_correlations(h, n)
    # c_k = sum_i h[i]*(1-h[i+lag_k])
    # Writing in terms of h[j]: c_k = A_k + h[j] * B_k
    # We need B_k = dc_k/dh[j]
    B = np.zeros(2*n-1)
    for k_idx in range(2*n-1):
        lag = k_idx - (n-1)
        if lag >= 0:
            b = 0.0
            if lag <= j and j <= n-1-lag:  # j is in [0, n-1-lag] for first term AND j >= lag for second
                # first term: (1-h[j+lag])
                b += (1.0 - h[j+lag]) if j+lag < n else 0.0
            if j >= lag:
                # second term: -h[j-lag]
                b -= h[j-lag] if j-lag >= 0 else 0.0
            # Wait, I need to be more careful
            # c_k = sum_{i=0}^{n-1-lag} h[i]*(1-h[i+lag])
            # dh[j] appears as:
            #   h[j]*(1-h[j+lag]) if j <= n-1-lag: contribution (1-h[j+lag])
            #   h[j-lag]*(1-h[j]) if j >= lag: contribution -h[j-lag]
            if j <= n-1-lag:
                b += (1.0 - h[j+lag])
            if j >= lag:
                b -= h[j-lag]
        else:
            l = -lag
            # c_k = sum_{i=l}^{n-1} h[i]*(1-h[i-l])
            # dh[j] appears as:
            #   h[j]*(1-h[j-l]) if j >= l: contribution (1-h[j-l])
            #   h[j+l]*(1-h[j]) if j+l <= n-1, i.e., j <= n-1-l: contribution -h[j+l]
            if j >= l:
                b += (1.0 - h[j-l])
            if j <= n-1-l:
                b -= h[j+l]
        B[k_idx] = b
    # A_k = c_k - h[j] * B_k
    A = c - h[j] * B
    
    # Minimize max_k (A_k + x * B_k) for x in [0, 1]

    lo, hi = 0.0, 1.0
    for _ in range(50):
        mid = (lo + hi) / 2
        vals = A + mid * B
        max_idx = np.argmax(vals)
        # Subgradient at mid: B[max_idx] (simplified; could use all maximizers)
        # For robustness, use the average subgradient
        max_val = vals.max()
        maximizers = np.where(np.abs(vals - max_val) < 1e-12)[0]
        sg = B[maximizers].mean()
        if sg > 0:
            lo = mid
        elif sg < 0:
            hi = mid
        else:
            break
    x_opt = (lo + hi) / 2
    return x_opt

import numpy as np
from scipy.optimize import minimize, linprog
import time


def compute_correlations(h, n):
    return np.correlate(h, 1.0 - h, mode="full")


def compute_c5(h, n):
    c = compute_correlations(h, n)
    return float(np.max(c) * (2.0 / n))


def project_feasible(h, n):
    h = np.asarray(h, dtype=float).copy()
    h = np.clip(h, 0.0, 1.0)
    target = n / 2.0
    for _ in range(500):
        s = h.sum()
        diff = target - s
        if abs(diff) < 1e-15:
            break
        if diff > 0:
            mask = h < 1.0 - 1e-15
            cnt = mask.sum()
            if cnt == 0:
                break
            step = min(diff / cnt, (1.0 - h[mask]).min() * 0.99)
            h[mask] += step
        else:
            mask = h > 1e-15
            cnt = mask.sum()
            if cnt == 0:
                break
            step = min(-diff / cnt, h[mask].min() * 0.99)
            h[mask] -= step
        h = np.clip(h, 0.0, 1.0)
    diff = h.sum() - target
    if abs(diff) > 1e-14:
        free = (h > 1e-12) & (h < 1.0 - 1e-12)
        if free.sum() > 0:
            h[free] -= diff / free.sum()
        else:
            h -= diff / n
        h = np.clip(h, 0.0, 1.0)
    return h


def soft_max_value(h, n, beta):
    dx = 2.0 / n
    c = compute_correlations(h, n) * dx
    m = c.max()
    return float(m + np.log(np.sum(np.exp(c - m))) / beta)


def soft_max_grad(h, n, beta):
    dx = 2.0 / n
    c_raw = compute_correlations(h, n)
    c = c_raw * dx
    m = c.max()
    w = np.exp(c - m)
    w /= w.sum()
    grad = np.zeros(n)
    for k_idx in range(2 * n - 1):
        wk = w[k_idx]
        if wk < 1e-16:
            continue
        lag = k_idx - (n - 1)
        coeff = wk * dx
        if lag >= 0:
            if n - 1 - lag >= 0:
                grad[:n - lag] += coeff * (1.0 - h[lag:n])
            if lag < n:
                grad[lag:] -= coeff * h[:n - lag]
        else:
            l = -lag
            grad[l:] += coeff * (1.0 - h[:n - l])
            if l < n:
                grad[:n - l] -= coeff * h[l:]
    return grad


def hard_max_grad(h, n):
    dx = 2.0 / n
    c = compute_correlations(h, n)
    c_max = c.max()
    maximizers = np.where(np.abs(c - c_max) < 1e-10 * c_max)[0]
    grad = np.zeros(n)
    for k_idx in maximizers:
        lag = k_idx - (n - 1)
        g = np.zeros(n)
        if lag >= 0:
            if n - 1 - lag >= 0:
                g[:n - lag] += (1.0 - h[lag:n])
            if lag < n:
                g[lag:] -= h[:n - lag]
        else:
            l = -lag
            g[l:] += (1.0 - h[:n - l])
            if l < n:
                g[:n - l] -= h[l:]
        grad += g
    grad /= len(maximizers)
    return grad * dx


def cd_optimize_j(h, n, j):
    """Find optimal value of h[j] via 1D convex minimization."""
    dx = 2.0 / n
    c = compute_correlations(h, n)
    B = np.zeros(2 * n - 1)
    for k_idx in range(2 * n - 1):
        lag = k_idx - (n - 1)
        b = 0.0
        if lag >= 0:
            if j <= n - 1 - lag:
                b += (1.0 - h[j + lag])
            if j >= lag:
                b -= h[j - lag]
        else:
            l = -lag
            if j >= l:
                b += (1.0 - h[j - l])
            if j <= n - 1 - l:
                b -= h[j + l]
        B[k_idx] = b
    A = c - h[j] * B
    # Minimize max_k(A_k + x*B_k) for x in [0,1] via bisection
    lo = 0.0
    hi = 1.0
    for _ in range(40):
        mid = (lo + hi) * 0.5
        vals = A + mid * B
        max_val = vals.max()
        max_idx = np.argmax(vals)
        # Use all near-maximizers for subgradient
        close = np.where(np.abs(vals - max_val) < max_val * 1e-9 + 1e-12)[0]
        sg = B[close].mean()
        if sg > 1e-10:
            lo = mid
        elif sg < -1e-10:
            hi = mid
        else:
            break
    return (lo + hi) * 0.5


def lbfgs_solve(h, n, beta, maxiter, t0, budget_s):
    penalty = 50.0

    def func(x):
        return soft_max_value(x, n, beta) + penalty * (x.sum() - n / 2.0) ** 2

    def grad(x):
        g = soft_max_grad(x, n, beta)
        g += 2.0 * penalty * (x.sum() - n / 2.0)
        return g

    try:
        res = minimize(func, h, jac=grad, method='L-BFGS-B',
                       bounds=[(0.0, 1.0)] * n,
                       options={'maxiter': maxiter, 'ftol': 1e-15, 'gtol': 1e-8})
        return project_feasible(res.x, n)
    except Exception:
        return h

            row = np.zeros(n + 1)

            row[-1] = -1.0
            A_ub_list.append(row)
            b_ub_list.append(-c_scaled[k_idx])
        A_ub = np.array(A_ub_list)
        b_ub = np.array(b_ub_list)

            if res.success:

def coordinate_descent(h, n, n_steps, t0, budget_s):
    h = h.copy()
    rng = np.random.RandomState(12345)
    for it in range(n_steps):
        if time.time() - t0 > budget_s - 15:

            mask[j] = False
            h[mask] -= delta / (n - 1)
