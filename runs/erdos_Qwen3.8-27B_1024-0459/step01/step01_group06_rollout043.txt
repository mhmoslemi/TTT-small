c[m] = sum_{i=0}^{n-1-lag} h[i]*(1-h[i+lag])
= sum_{i=0}^{n-1-lag} h[i] - sum_{i=0}^{n-1-lag} h[i]*h[i+lag]

∂c[m]/∂h[j]:
- From first sum: 1 if 0 ≤ j ≤ n-1-lag, else 0
- From second sum: -h[j+lag] if 0 ≤ j ≤ n-1-lag (from the term h[j]*h[j+lag])
  -h[j-lag] if lag ≤ j ≤ n-1 (from the term h[j-lag]*h[j], which is the i=j-lag term)
  Note: the term h[i]*h[i+lag] with i+lag = j means i = j-lag, valid if lag ≤ j ≤ n-1 and j-lag ≤ n-1-lag, i.e., j ≤ n-1.

So A_m = 1_{0≤j≤n-1-lag} - h[j+lag]*1_{0≤j≤n-1-lag} - h[j-lag]*1_{lag≤j≤n-1}
(When both conditions hold, we get 1 - h[j+lag] - h[j-lag])

If lag < 0 (let m' = |lag|):
c[m] = sum_{i=m'}^{n-1} h[i]*(1-h[i-m'])
= sum_{i=m'}^{n-1} h[i] - sum_{i=m'}^{n-1} h[i]*h[i-m']

∂c[m]/∂h[j]:
- From first sum: 1 if m' ≤ j ≤ n-1
- From second sum: -h[j-m'] if m' ≤ j ≤ n-1 (from h[j]*h[j-m'], i.e., i=j)
  -h[j+m'] if j+m' ≤ n-1 and j+m' ≥ m', i.e., 0 ≤ j ≤ n-1-m' (from h[j+m']*h[j], i.e., i=j+m')

So A_m = 1_{m'≤j≤n-1} - h[j-m']*1_{m'≤j≤n-1} - h[j+m']*1_{0≤j≤n-1-m'}

This is O(1) per lag to compute, so total O(n) per coordinate. Then for each candidate t, the objective is max_k (A_k*t + B_k) * dx + penalty, which is O(n) to evaluate (since there are 2n-1 lags).

So per coordinate: O(n) to precompute A_k, then O(n * n_candidates) to evaluate. Total per sweep: O(n² * n_candidates). For n=95 and n_candidates=100: 95² * 100 = 902,500. That's fast!

def coord_step_fast(h, n, dx, alpha, n_cand=100):
    target = n / 2.0
    S = h.sum()  # should be n/2 if feasible
    
    # Precompute A_k for each coordinate j
    # A_k[j] = coefficient of h[j] in c[k] (for full correlation index k)
    # c[k] = A_k[j] * h[j] + B_k[j]
    
    nfull = 2 * n - 1
    for j in range(n):
        old = h[j]
        S_rest = S - old
        
        # Compute A_k and B_k for all k
        A = np.zeros(nfull)
        for k in range(nfull):
            lag = k - (n - 1)
            if lag >= 0:
                # c[k] = sum_{i=0}^{n-1-lag} h[i]*(1-h[i+lag])
                a = 0.0
                if 0 <= j <= n - 1 - lag:
                    a += 1.0
                    a -= h[j + lag]
                if lag <= j <= n - 1:
                    a -= h[j - lag]
                A[k] = a
            else:
                m = -lag
                a = 0.0
                if m <= j <= n - 1:
                    a += 1.0
                    a -= h[j - m]
                if 0 <= j <= n - 1 - m:
                    a -= h[j + m]
                A[k] = a
        
        # Current c values
        c = get_correlation(h, n)
        # B_k = c[k] - A[k] * old
        B = c - A * old
        
        # Find best t in [0, 1]
        # Objective: max_k (A[k]*t + B[k]) * dx + alpha * (t + S_rest - target)^2
        best_t = old
        best_obj = np.max(c) * dx + alpha * (S - target)**2
        
        # Use a grid
        # Adaptive grid: more points near the current value
        grid = np.linspace(0, 1, n_cand)
        for t in grid:
            c_new = A * t + B
            obj = np.max(c_new) * dx + alpha * (t + S_rest - target)**2
            if obj < best_obj:
                best_obj = obj
                best_t = t
        
        # Refine around best_t
        if 0 < best_t < 1:
            grid2 = np.linspace(max(0, best_t - 0.5/n_cand), min(1, best_t + 0.5/n_cand), 20)
            for t in grid2:
                c_new = A * t + B
                obj = np.max(c_new) * dx + alpha * (t + S_rest - target)**2
                if obj < best_obj:
                    best_obj = obj
                    best_t = t
        
        h[j] = best_t
        S = S_rest + best_t
    
    return h

But wait, there's a subtlety: when I update h[j], the A and B coefficients for subsequent coordinates change (because they depend on h's values). So I can't precompute them all at once. I need to recompute A and B for each coordinate j using the current h.

That's what the code above does - it recomputes A for each j using the current h. Good.

But computing c = get_correlation(h, n) for each j is O(n²), making the total O(n³ * n_cand) per sweep. For n=95: 95³ * 100 ≈ 860M. That might be too slow for many sweeps.

Optimization: I don't need to recompute the full correlation for each j. I can maintain it incrementally. When h[j] changes by δ, the correlation changes by:

where A_k[j] is the coefficient I computed. So I can maintain c incrementally!

        # - h[j-k]*h[j] (from the quadratic part) with coefficient -1

        # = 1_{j in linear range} - h[j+k]*1_{j in range for first quadratic term} - h[j-k]*1_{j in range for second quadratic term}
        
        # For positive lag l = k-(n-1) >= 0:
        #   Linear range: 0 <= j <= n-1-l
        #   First quadratic term h[j]*h[j+l]: valid if 0 <= j <= n-1-l, coefficient -h[j+l]
        #   Second quadratic term h[j-l]*h[j]: valid if l <= j <= n-1, coefficient -h[j-l]
        # For negative lag (m = (n-1)-k > 0, so lag = -m):
        #   Linear range: m <= j <= n-1
        #   First quadratic term h[j]*h[j-m]: valid if m <= j <= n-1, coefficient -h[j-m]
        #   Second quadratic term h[j+m]*h[j]: valid if 0 <= j <= n-1-m, coefficient -h[j+m]

            h[j] = best_t

def get_correlation(h, n):
    return np.correlate(h, 1.0 - h, mode="full")


def compute_c5(h, n):
    c = get_correlation(h, n)
    return float(np.max(c) * (2.0 / n))


def project_feasible(h, n):
    h = np.asarray(h, dtype=float).copy()
    h = np.clip(h, 0.0, 1.0)
    target = n / 2.0
    for _ in range(300):
        diff = h.sum() - target
        if abs(diff) < 1e-15:
            break
        if diff > 0:
            mask = h > 1e-15
        else:
            mask = h < 1.0 - 1e-15
        if mask.sum() == 0:
            break
        h[mask] -= diff / mask.sum()
        h = np.clip(h, 0.0, 1.0)
    return h


def compute_A_for_j(j, h, n):
    nfull = 2 * n - 1
    A = np.zeros(nfull)
    for k in range(nfull):
        lag = k - (n - 1)
        if lag >= 0:
            if 0 <= j <= n - 1 - lag:
                A[k] = 1.0 - h[j + lag]
            if lag <= j <= n - 1:
                A[k] -= h[j - lag]
        else:
            m = -lag
            if m <= j <= n - 1:
                A[k] = 1.0 - h[j - m]
            if 0 <= j <= n - 1 - m:
                A[k] -= h[j + m]
    return A


def coord_descent_sweep(h, n, dx, alpha, n_cand=200):

def soft_max_obj(x, n, beta):
    c = get_correlation(x, n)
    dx = 2.0 / n
    scaled = beta * c * dx
    m = np.max(scaled)
    return float((m + np.log(np.sum(np.exp(scaled - m)))) / beta)


def soft_max_grad(x, n, beta):
    c = get_correlation(x, n)
    dx = 2.0 / n
    scaled = beta * c * dx
    m = np.max(scaled)
    w = np.exp(scaled - m)
    w /= np.sum(w)
    nfull = 2 * n - 1
    grad = np.zeros(n)
    for k_idx in range(nfull):
        wk = w[k_idx]
        if wk < 1e-14:
            continue
        A = compute_A_for_j(0, x, n)  # placeholder, we need per-coordinate
        # Actually compute gradient directly
        lag = k_idx - (n - 1)
        if lag >= 0:
            for i in range(n - lag):
                grad[i] += wk * (1.0 - x[i + lag])
                grad[i + lag] += wk * (-x[i])
        else:
            m = -lag
            for i in range(m, n):
                grad[i] += wk * (1.0 - x[i - m])
                grad[i - m] += wk * (-x[i])
    return grad * dx


def smooth_penalty_obj(x, n, beta, pen_alpha):
    return soft_max_obj(x, n, beta) + pen_alpha * (x.sum() - n / 2.0) ** 2


def smooth_penalty_grad(x, n, beta, pen_alpha):
    g_sm = soft_max_grad(x, n, beta)
    g_pen = 2.0 * pen_alpha * (x.sum() - n / 2.0) * np.ones(n)
    return g_sm + g_pen


def try_smooth_optimize(h, n, beta, pen_alpha, t0, budget_s, margin):
    if time.time() - t0 > budget_s - margin:
        return h, compute_c5(h, n)
    
    bounds = [(0.0, 1.0)] * n
    
    try:

            smooth_penalty_obj, h, jac=smooth_penalty_grad,
            args=(n, beta, pen_alpha),

        h_new = project_feasible(res.x, n)
        c5_new = compute_c5(h_new, n)
        return h_new, c5_new

        return h, compute_c5(h, n)
