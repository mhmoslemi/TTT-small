    n_lags = 2 * n - 1
    for step in range(steps):

        k_max = np.argmax(overlaps)
        lag = k_max - (n - 1)

        h = h_new

Wait, I realize there might be an issue with my gradient computation. Let me re-derive.

f_k(h) = Σ_{i: 0≤i, 0≤i+k<n} h[i] * (1-h[i+k]) * dx

For a specific m:
∂f_k/∂h[m] = dx * (1-h[m+k]) * [0≤m+ k<n and m in valid range for i]
           + dx * (-h[m-k]) * [0≤m-k<n and m-k in valid range for i]

More precisely:
- h[m] appears in f_k as the first factor when i=m: requires 0≤m<n and 0≤m+k<n
  Contribution: (1-h[m+k])*dx

- h[m] appears in f_k as the second factor (inside 1-h) when i+k=m, i.e., i=m-k: requires 0≤m-k<n and 0≤m<n
  Contribution: -h[m-k]*dx (from the -h[i+k] part, which is -h[m])

Wait, the second factor is (1-h[i+k]). When i+k = m, the term is h[i]*(1-h[m]). The derivative with respect to h[m] is -h[i] = -h[m-k].

So:
∂f_k/∂h[m] = dx * [(1-h[m+k]) * 1_{0≤m+k<n} - h[m-k] * 1_{0≤m-k<n}]

Now let me think about the overall strategy more carefully.

Key insight: The problem has a **max of many functions**, and at the optimum, typically 2 or more functions are active (tied at the max). The subgradient at a tie is a convex combination of the individual gradients.

A better approach might be to use a **smoothing** technique:
C₅_smooth(h, τ) = τ * log(Σ_k exp(overlap_k / τ))

As τ → 0, this approaches C₅(h). We can minimize C₅_smooth with standard gradient methods, annealing τ.

The gradient of C₅_smooth is:
∂C₅_smooth/∂h[m] = Σ_k p_k * ∂overlap_k/∂h[m]

where p_k = exp(overlap_k/τ) / Σ_j exp(overlap_j/τ)

This gives a weighted average of all the component gradients, with weights proportional to how close each component is to the maximum. This is much smoother than the hard max and should lead to better optimization.

This is a great idea! Let me implement this.

```python
def smooth_max_obj(h, n, tau):
    overlaps = compute_overlaps(h, n)
    # Shift for numerical stability
    o_max = np.max(overlaps)
    exps = np.exp((overlaps - o_max) / tau)
    log_sum = np.log(np.sum(exps))
    return o_max + tau * log_sum

def smooth_max_grad(h, n, tau):
    overlaps = compute_overlaps(h, n)
    o_max = np.max(overlaps)
    exps = np.exp((overlaps - o_max) / tau)
    weights = exps / np.sum(exps)
    
    # Weighted average of all component gradients
    n_lags = 2 * n - 1
    m = np.arange(n)
    grad = np.zeros(n)
    dx = 2.0 / n
    
    for k in range(n_lags):
        lag = k - (n - 1)
        if weights[k] < 1e-10:
            continue
        m_plus = m + lag
        m_minus = m - lag
        valid_plus = (m_plus >= 0) & (m_plus < n)
        valid_minus = (m_minus >= 0) & (m_minus < n)
        g = np.zeros(n)
        if valid_plus.any():
            g[valid_plus] += (1.0 - h[m_plus[valid_plus]]) * dx
        if valid_minus.any():
            g[valid_minus] -= h[m_minus[valid_minus]] * dx
        grad += weights[k] * g
    
    return grad
```

This is O(n²) per gradient evaluation (n components × O(n) each). For n=70, that's ~5000 operations, very fast. For n=280, that's ~80000, still fine.

1. **Initialize** from parent or structured pattern
2. **Smooth max optimization**: Start with large τ, minimize, then decrease τ
3. **Binary local search**: Round to binary, do swap-based local search
4. **SLSQP polish**: Use the smooth max approximation with small τ
5. **Multi-resolution**: Try different n values

Let me also think about the binary local search more carefully.

For binary h (all 0 or 1), the overlap at lag k is:
count_k = |{i : h[i]=1, h[i+k]=0, 0≤i<n, 0≤i+k<n}|

This is an integer. C₅ = max_k count_k * dx.

For n even, we have n/2 ones and n/2 zeros.

A swap move: pick i with h[i]=1 and j with h[j]=0, swap them.
This changes count_k for every k (since h[i] and h[j] appear in many correlation terms).

But we can compute the NEW counts efficiently:
- After swap, h'[i]=0, h'[j]=1, h'[m]=h[m] for m≠i,j
- count'_k = count_k - Δ_k where Δ_k is the change

For lag k:
- The term (i, i+k): if valid, h[i]*(1-h[i+k]) changes from 1*(1-h[i+k]) to 0, so change = -(1-h[i+k]) = -1 if h[i+k]=0, 0 if h[i+k]=1
  Wait, h[i]=1 originally. So the term was h[i]*(1-h[i+k]) = 1-h[i+k]. After swap, h'[i]=0, so the term is 0. Change = -(1-h[i+k]).
  
- The term (i-k, i): if valid, h[i-k]*(1-h[i]) changes from h[i-k]*0 to h[i-k]*1, so change = h[i-k].
  Wait, h[i]=1, so 1-h[i]=0. After swap, h'[i]=0, so 1-h'[i]=1. The term was h[i-k]*0=0, now h[i-k]*1=h[i-k]. Change = +h[i-k].

- Similarly for j: h[j]=0→1
  - Term (j, j+k): was 0*(1-h[j+k])=0, now 1*(1-h[j+k])=1-h[j+k]. Change = +(1-h[j+k]).
  - Term (j-k, j): was h[j-k]*(1-0)=h[j-k], now h[j-k]*(1-1)=0. Change = -h[j-k].

So the total change in count_k from swapping i,j:
Δ_k = -(1-h[i+k]) + h[i-k] + (1-h[j+k]) - h[j-k]  (for valid indices)

We need count'_k = count_k + Δ_k ≥ 0 for all k (which should be automatic).

The new C₅ = max_k (count_k + Δ_k) * dx.

We want to minimize this. So we want the swap that minimizes the max.

This is still O(n) per swap evaluation (we need to check all k to find the new max). But we can be smarter:
- Only lags k where |k-i| or |k-j| is in range are affected. Actually, ALL lags are affected (as I discussed before). But the DELTA is zero for most lags!

Δ_k is non-zero only if:
- i+k is in [0, n-1] (the (i, i+k) pair at lag k), OR
- i-k is in [0, n-1] (the (i-k, i) pair at lag k), OR
- j+k is in [0, n-1], OR
- j-k is in [0, n-1]

For lag k: i+k in [0,n-1] means k in [-i, n-1-i]. i-k in [0,n-1] means k in [i-(n-1), i].
So i affects lags k in [-(n-1), n-1] (all of them, since 0≤i<n).

Hmm, so indeed all lags are affected. But Δ_k is a simple expression:
Δ_k = -(1-h[i+k])·1_{valid(i,k)} + h[i-k]·1_{valid(i-k)} + (1-h[j+k])·1_{valid(j,k)} - h[j-k]·1_{valid(j-k)}

For most k, at most one or two of these terms are non-zero. Specifically:
- -(1-h[i+k]) is non-zero only when 0≤i+k<n AND h[i+k]=0
- h[i-k] is non-zero only when 0≤i-k<n AND h[i-k]=1
- etc.

So for a random binary sequence, Δ_k is non-zero for O(1) lags on average (since each term involves a specific position being 0 or 1).

Wait, no. For a given i and k, i+k is a specific index. (1-h[i+k]) is 0 or 1. So the term is either 0 or -1. Same for the others.

So Δ_k ∈ {-2, -1, 0, 1, 2} for each k, and it's non-zero for O(1) values of k (specifically, for k where i+k or i-k or j+k or j-k hits a 0 or 1 in a specific way).

Actually, for a given i:
- (1-h[i+k]) ≠ 0 when h[i+k]=0, which happens for about half the k values
- h[i-k] ≠ 0 when h[i-k]=1, which happens for about half the k values

So Δ_k is non-zero for about 50% of k values. That's not very sparse.

But the key insight: for the MAX, we only care about the lags that are currently near the maximum. If the current max is M, and Δ_k = 0 for most k, then the new max is max(M, max of (count_k + Δ_k) for affected k).

Let me just implement it straightforwardly: for each swap, compute the new max. With n=70, there are ~1225 possible swaps, and each evaluation is O(n)=O(70). Total: ~86,000 operations per step. Very fast.

For simulated annealing on binary sequences:
- Temperature T starts high and cools
- At each step, try a random swap or the best swap
- Accept if ΔC₅ < 0, or with probability exp(-ΔC₅/T)

import numpy as np
from scipy.optimize import minimize
import time

def compute_overlaps(h, n):
    dx = 2.0 / n
    return np.correlate(h, 1.0 - h, mode='full') * dx

def compute_c5_val(h, n):
    return np.max(compute_overlaps(h, n))

def project_feasible(h, n):
    target = n / 2.0
    h = np.array(h, dtype=float).copy()
    h = np.clip(h, 0.0, 1.0)
    for _ in range(200):
        s = np.sum(h)
        d = target - s
        if abs(d) < 1e-14:
            break
        if d > 0:
            mask = h < 1.0 - 1e-15
            if not np.any(mask): break
            h[mask] += d / mask.sum()
        else:
            mask = h > 1e-15
            if not np.any(mask): break
            h[mask] += d / mask.sum()
        h = np.clip(h, 0.0, 1.0)
    s = np.sum(h)
    if abs(s - target) > 1e-10:
        h += (target - s) / n
        h = np.clip(h, 0, 1)
    return h

def smooth_obj(h, n, tau):
    ov = compute_overlaps(h, n)
    om = np.max(ov)
    return om + tau * np.log(np.sum(np.exp((ov - om) / tau)))

def smooth_grad(h, n, tau):
    ov = compute_overlaps(h, n)
    om = np.max(ov)
    w = np.exp((ov - om) / tau)
    w /= w.sum()
    dx = 2.0 / n
    m = np.arange(n)
    g = np.zeros(n)
    nlags = 2 * n - 1
    for k in range(nlags):
        p = w[k]
        if p < 1e-12:
            continue
        lag = k - (n - 1)
        mp = m + lag
        mm = m - lag
        vp = (mp >= 0) & (mp < n)
        vm = (mm >= 0) & (mm < n)
        if vp.any():
            g[vp] += p * (1.0 - h[mp[vp]]) * dx
        if vm.any():
            g[vm] -= p * h[mm[vm]] * dx
    return g

def slsqp_smooth(h0, n, tau, maxiter=300):
    target = n / 2.0
    res = minimize(
        lambda x: smooth_obj(x, n, tau),
        h0.copy(),
        jac=lambda x: smooth_grad(x, n, tau),
        method='SLSQP',
        bounds=[(0.0, 1.0)] * n,
        constraints=[{'type': 'eq', 'fun': lambda x: np.sum(x) - target,
                       'jac': lambda x: np.ones(n)}],
        options={'maxiter': maxiter, 'ftol': 1e-10}
    )
    return res.x, compute_c5_val(res.x, n)

def binary_local_search(h_bin, n, n_iter=5000, seed=42):
    """Swap-based local search on binary sequences."""
    rng = np.random.RandomState(seed)
    h = h_bin.copy()
    best_val = compute_c5_val(h, n)
    ones = np.where(h == 1.0)[0]
    zeros = np.where(h == 0.0)[0]
    
    for it in range(n_iter):
        if len(ones) == 0 or len(zeros) == 0:
            break
        # Try all swaps, pick the best
        best_swap = None
        best_new_val = best_val
        
        # For efficiency, try a subset of swaps
        if n <= 100:
            # Try all swaps
            for i in ones:
                for j in zeros:
                    if i == j:
                        continue
                    h[i] = 0.0
                    h[j] = 1.0
                    val = compute_c5_val(h, n)
                    if val < best_new_val - 1e-15:
                        best_new_val = val
                        best_swap = (i, j)
                    h[i] = 1.0
                    h[j] = 0.0
        else:
            # Try random subset
            n_tries = min(200, len(ones) * len(zeros))
            for _ in range(n_tries):
                i = rng.choice(ones)
                j = rng.choice(zeros)
                if i == j:
                    continue
                h[i] = 0.0
                h[j] = 1.0
                val = compute_c5_val(h, n)
                if val < best_new_val - 1e-15:
                    best_new_val = val
                    best_swap = (i, j)
                h[i] = 1.0
                h[j] = 0.0
        
        if best_swap is not None:
            i, j = best_swap
            h[i] = 0.0
            h[j] = 1.0
            best_val = best_new_val
        else:
            # No improving swap: try random swap (simulated annealing)
            if rng.random() < 0.3:
                i = rng.choice(ones)
                j = rng.choice(zeros)
                h[i] = 0.0
                h[j] = 1.0
                new_val = compute_c5_val(h, n)
                T = 0.05 / (1 + it * 0.001)
                if new_val < best_val or rng.random() < np.exp(-(new_val - best_val) / (T + 1e-10)):
                    best_val = min(best_val, new_val)
                else:
                    h[i] = 1.0
                    h[j] = 0.0
    
    ones = np.where(h == 1.0)[0]
    return h, best_val

def thue_morse(n):
    """Generate Thue-Morse sequence of length n."""
    h = np.zeros(n)
    for i in range(n):
        # Count set bits
        c = 0
        x = i
        while x:
            c += x & 1
            x >>= 1
        h[i] = c % 2
    return h

def sturmian(n, alpha):
    """Generate characteristic Sturmian word of length n."""
    h = np.zeros(n)
    x = 0.0
    for i in range(n):
        h[i] = 1.0 if (x + alpha) >= 1.0 else 0.0
        x = (x + alpha) % 1.0
    return h

# Helper functions (top-level)

def compute_overlaps(h, n):
    dx = 2.0 / n
    return np.correlate(h, 1.0 - h, mode='full') * dx

def c5_value(h, n):
    return float(np.max(compute_overlaps(h, n)))

def project_feasible(h, n):
    target = n / 2.0
    h = np.array(h, dtype=float).copy()
    h = np.clip(h, 0.0, 1.0)
    for _ in range(300):
        s = np.sum(h)
        d = target - s
        if abs(d) < 1e-14:
            break
        if d > 0:
            mask = h < 1.0 - 1e-15
            if not np.any(mask):
                break
            h[mask] += d / mask.sum()
        else:
            mask = h > 1e-15
            if not np.any(mask):
                break
            h[mask] += d / mask.sum()
        h = np.clip(h, 0.0, 1.0)
    s = np.sum(h)
    if abs(s - target) > 1e-10:
        h += (target - s) / n
        h = np.clip(h, 0, 1)
    return h

def smooth_obj(h, n, tau):
    ov = compute_overlaps(h, n)
    om = np.max(ov)
    e = np.exp((ov - om) / tau)
    return om + tau * np.log(np.sum(e))

def smooth_grad(h, n, tau):
    ov = compute_overlaps(h, n)
    om = np.max(ov)
    w = np.exp((ov - om) / tau)
    w /= w.sum()
    dx = 2.0 / n
    g = np.zeros(n)
    m = np.arange(n)
    for k in range(2 * n - 1):
        p = w[k]
        if p < 1e-12:
            continue
        lag = k - (n - 1)
        mp = m + lag
        vm = m - lag
        vp = (mp >= 0) & (mp < n)
        vmm = (vm >= 0) & (vm < n)
        if vp.any():
            g[vp] += p * (1.0 - h[mp[vp]]) * dx
        if vmm.any():
            g[vmm] -= p * h[vm[vmm]] * dx
    return g

        h0.copy(),

                       'jac': lambda x: np.ones(n)}],
        options={'maxiter': maxiter, 'ftol': ftol}
    )
    return np.array(res.x), c5_value(res.x, n)

        cnt = 0
        for idx in order:
            if h_bin[idx] == 1.0 and cnt < n1 - target:
                h_bin[idx] = 0.0
                cnt += 1
    elif n1 < target:

        cnt = 0
        for idx in order:
            if h_bin[idx] == 0.0 and cnt < target - n1:
                h_bin[idx] = 1.0
                cnt += 1
    return h_bin

def thue_morse_seq(n):
    h = np.zeros(n)

        c = 0; x = i
        while x:
            c += x & 1
            x >>= 1

    return h

import numpy as np
from scipy.optimize import minimize

def compute_overlaps(h, n):
    dx = 2.0 / n
    return np.correlate(h, 1.0 - h, mode='full') * dx

def c5_value(h, n):
    return float(np.max(compute_overlaps(h, n)))

def project_feasible(h, n):
    target = n / 2.0
    h = np.array(h, dtype=float).copy()
    h = np.clip(h, 0.0, 1.0)
    for _ in range(300):
        s = np.sum(h)
        d = target - s
        if abs(d) < 1e-14:
            break
        if d > 0:
            mask = h < 1.0 - 1e-15
            if not np.any(mask):
                break
            h[mask] += d / mask.sum()
        else:
            mask = h > 1e-15
            if not np.any(mask):
                break
            h[mask] += d / mask.sum()
        h = np.clip(h, 0.0, 1.0)
    s = np.sum(h)
    if abs(s - target) > 1e-10:
        h += (target - s) / n
        h = np.clip(h, 0, 1)
    return h

def smooth_obj(h, n, tau):
    ov = compute_overlaps(h, n)
    om = np.max(ov)
    e = np.exp((ov - om) / tau)
    return om + tau * np.log(np.sum(e))

def smooth_grad(h, n, tau):
    ov = compute_overlaps(h, n)
    om = np.max(ov)
    w = np.exp((ov - om) / tau)
    ws = w.sum()
    if ws < 1e-300:
        return np.zeros(n)
    w /= ws
    dx = 2.0 / n
    g = np.zeros(n)
    m = np.arange(n)
    for k in range(2 * n - 1):
        p = w[k]
        if p < 1e-12:
            continue
        lag = k - (n - 1)
        mp = m + lag
        mm = m - lag
        vp = (mp >= 0) & (mp < n)
        vm = (mm >= 0) & (mm < n)
        if vp.any():
            g[vp] += p * (1.0 - h[mp[vp]]) * dx
        if vm.any():
            g[vm] -= p * h[mm[vm]] * dx
    return g

def slsqp_smooth(h0, n, tau, maxiter=200, ftol=1e-10):
    target = n / 2.0
    res = minimize(
        lambda x: smooth_obj(x, n, tau),
        h0.copy(),
        jac=lambda x: smooth_grad(x, n, tau),
        method='SLSQP',
        bounds=[(0.0, 1.0)] * n,
        constraints=[{'type': 'eq', 'fun': lambda x: np.sum(x) - target,
                       'jac': lambda x: np.ones(n)}],
        options={'maxiter': maxiter, 'ftol': ftol}
    )
    return np.array(res.x), c5_value(res.x, n)

def thue_morse_seq(n):
    h = np.zeros(n)
    for i in range(n):
        c = 0; x = i
        while x:
            c += x & 1
            x >>= 1
        h[i] = c % 2
    return h

def sturmian_seq(n, alpha):
    h = np.zeros(n)
    x = 0.0
    for i in range(n):
        x += alpha
        if x >= 1.0:
            h[i] = 1.0
            x -= 1.0
    return h

                ht, vt = slsqp_smooth(best_h, best_n, tau, maxiter=400, ftol=1e-12)
                ht = project_feasible(ht, best_n)
                vt = c5_value(ht, best_n)
                if vt < best_val:
                    best_h, best_val = ht, vt
                    break
            except Exception:
                break

    # Final binary refinement if beneficial
    if tl() > 15:
        hfb_final = to_binary_proportional(best_h, best_n)
        hfb_final, vfb_final = binary_local_search(hfb_final, best_n, n_iter=3000, seed=seed + 999, rng=rng)
        if vfb_final < best_val:
            best_h, best_val = hfb_final, vfb_final

    best_h = project_feasible(best_h, best_n)
    best_val = c5_value(best_h, best_n)
    return (best_h, best_val, best_n)
