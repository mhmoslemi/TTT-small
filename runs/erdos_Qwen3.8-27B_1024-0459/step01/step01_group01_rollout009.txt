Let me think differently. Let's say we fix h[0], h[2], h[4], ... (even indices) and optimize h[1], h[3], h[5], ... (odd indices).

For shift s (in sample units):
f_s = dx * Σ_{i=0}^{n-1-s} h[i]*(1-h[i+s])

Each term h[i]*(1-h[i+s]) involves:
- If i even, i+s: depends on parity of s
  - If s even: i+s even. Product of two "fixed" variables → constant
  - If s odd: i+s odd. Product of fixed * variable → linear in h[i+s] (odd)
- If i odd, i+s:
  - If s even: i+s odd. Product of two "variable" (odd) variables → quadratic in odd variables!
  - If s odd: i+s even. Product of variable * fixed → linear in h[i] (odd)

So for s even: we have quadratic terms h[odd]*h[odd+s_even] = h[odd]*h[odd]. This is not linear!

This makes the alternating approach problematic for even shifts.

For s odd: the products are always linear in the odd variables. Good.

So if we only optimize over odd shifts, the problem is convex. But we need all shifts.

Alternative: use a "two-phase" approach where in each phase we linearize the quadratic terms using the current values:
h[i]*h[i+s] ≈ h[i]*h_old[i+s] + h[i+s]*h_old[i] - h_old[i]*h_old[i+s] (first-order Taylor)

This gives a linear approximation, and the problem becomes an LP. We iterate this linearization.

This is essentially the "linearized Benders" or "successive linearization" approach.

Let me implement this with cvxpy:

Phase 1: Fix h = h_current
Phase 2: Linearize: h[i]*h[i+s] → h[i]*h_cur[i+s] (for the "free" variable)
Phase 3: Solve LP: minimize t subject to t ≥ f_s for all s, 0≤h≤1, Σh=n/2
Phase 4: Update h, go to Phase 2

This should converge (at least to a stationary point) since we're doing a majorization-minimization type scheme.

```python
import cvxpy as cp

def solve_one_lp_iteration(h_cur, n):
    """One iteration of the linearized LP approach.
    h_cur is the current solution. We linearize h[i]*h[i+s] ≈ h[i]*h_cur[i+s] + (h[i+s]-h[i+s])... 
    Actually, the simplest linearization: h[i]*h[i+s] ≈ h[i]*h_cur[i+s] (hold the second factor fixed)
    This is asymmetric. Better: h[i]*h[i+s] ≈ 0.5*(h[i]*h_cur[i+s] + h[i+s]*h_cur[i]) (symmetric)
    """
    h = cp.Variable(n)
    t = cp.Variable()
    dx = 2.0 / n
    
    constraints = [h >= 0, h <= 1, cp.sum(h) == n/2.0]
    
    # Linearize each overlap
    for s in range(0, n):
        # f_s = dx * sum_{i=0}^{n-1-s} h[i]*(1-h[i+s])
        # Linearize: h[i]*(1-h[i+s]) ≈ h[i]*(1-h_cur[i+s])
        # (holding the second factor fixed)
        if s == 0:
            # f_0 = dx * sum h[i]*(1-h[i]) ≈ dx * sum h[i]*(1-h_cur[i])
            linear_term = cp.sum(h * (1 - h_cur))
        else:
            valid = n - 1 - s
            # h[i] for i=0..valid-1, h[i+s] for i=0..valid-1
            # Linearize h[i]*(1-h[i+s]) ≈ h[i]*(1-h_cur[i+s])
            linear_term = cp.sum(h[:valid] * (1 - h_cur[s:]))
        
        # Also the "other side" correlation:
        # g_s = dx * sum h[i+s]*(1-h[i]) for i=0..n-1-s
        # Linearize: h[i+s]*(1-h[i]) ≈ h_cur[i+s]*(1-h[i])
        valid = n - 1 - s
        linear_term2 = cp.sum(h_cur[s:] * (1 - h[:valid]))
        
        # The full correlation has 2n-1 values. For shift s>0, we have both f_s and g_s
        # f_s = dx * sum h[i](1-h[i+s])
        # g_s = dx * sum h[i+s](1-h[i])
        # We linearized: f_s ≈ dx * sum h[i](1-h_cur[i+s]) [linear in h]
        #              g_s ≈ dx * sum h_cur[i+s](1-h[i]) [linear in h]
        
        constraints.append(t >= dx * linear_term)
        constraints.append(t >= dx * linear_term2)
    
    # For s=0, we only have one value: f_0 = dx * sum h[i](1-h[i])
    # This is quadratic, but linearized: dx * sum h[i](1-h_cur[i])
    
    obj = cp.Minimize(t)
    prob = cp.Problem(obj, constraints)
    prob.solve()
    
    return h.value, t.value
```
