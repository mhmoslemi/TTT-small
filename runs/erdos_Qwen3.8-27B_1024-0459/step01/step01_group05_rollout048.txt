Let me also think about a "coordinate descent" approach:
- For each h[i], the effect on the correlation is:
  - It appears in c[n-1+s] for all s (as h[i] in the sum)
  - Specifically, c[n-1+s] contains h[i]*(1-h[i+s]) for valid s
  - And c[n-1+s-i] contains h[i-s]*(1-h[i]) for valid s
- So changing h[i] affects many correlation values

The coordinate descent would be:
- For each i, find the optimal h[i] (given all others fixed) that minimizes the max correlation
- This is a 1D optimization, can be done quickly
- Repeat until convergence

This is actually a very good approach! Let me implement it:

For fixed h[-i] (all positions except i), the correlation values as a function of h[i] = t are:
c_s(t) = (sum over valid j≠i parts) + t * (1-h[i+s]) - h[i-s] * t ... 

Actually it's more complex because t appears in multiple correlation values. Let me just do a 1D golden section or binary search for the optimal t in [0,1] at each coordinate.

But wait, the constraint sum(h) = n/2 means I can't independently optimize each coordinate. If I fix all other h[j], then h[i] is determined: h[i] = n/2 - sum_{j≠i} h[j]. So coordinate descent with the sum constraint means I'm actually varying pairs of coordinates.

Alternative: use the Lagrange multiplier approach. At the optimum, ∂F/∂h[i] = λ for all i (KKT for equality constraint). So I can:
- Fix λ
- For each i independently, minimize ∂F/∂h[i] - λ (which is the derivative of F - λ*sum(h))
- But this is circular since F depends on all h[j]

Let me stick with SLSQP + analytical gradient. It should be fast enough.

This looks clean. Let me verify the gradient computation is correct.

For np.correlate(a, v, mode='full') where len(a) = len(v) = n:
The result has 2n-1 elements. Element k (0-indexed) is:
result[k] = sum_{m} a[m] * v[m + k - (n-1)]

where the sum is over all m where both m and m+k-(n-1) are in [0, n-1].

Let s = k - (n-1), so s ranges from -(n-1) to (n-1).
result[n-1+s] = sum_m a[m] * v[m+s]

For a = h, v = 1-h = comp:
result[n-1+s] = sum_m h[m] * comp[m+s]

where m ranges from max(0, -s) to min(n-1, n-1-s).

d(result[n-1+s])/dh[j]:
- From h[m] where m=j: contributes comp[j+s] if j is in [max(0,-s), min(n-1, n-1-s)]
  AND j+s is in [0, n-1] (which is guaranteed if j is in range and s is valid)
- From comp[m+s] = 1-h[m+s] where m+s=j, i.e., m=j-s: contributes -1 * h[j-s] *... wait.
  Actually comp[m+s] = 1 - h[m+s]. So d(comp[m+s])/dh[j] = -delta_{m+s, j}
  This is -1 when m+s = j, i.e., m = j-s.
  So the contribution is: for m=j-s, we have -h[m] (since the product is h[m]*comp[m+s], and d/dh[j] of comp[m+s] is -1 when m+s=j, contributing -h[m] = -h[j-s])
  This is valid when m=j-s is in [max(0,-s), min(n-1, n-1-s)] AND j is in [0, n-1].

So:
d(result[n-1+s])/dh[j] = comp[j+s] * I1(j,s) + (-h[j-s]) * I2(j,s)

where:
I1 = 1 if max(0,-s) ≤ j ≤ min(n-1, n-1-s) [and j+s ∈ [0,n-1], which is automatic]
I2 = 1 if max(0,-s) ≤ j-s ≤ min(n-1, n-1-s) [and j ∈ [0,n-1], which is automatic since s ∈ [-(n-1), n-1]]

For I2: j-s ∈ [max(0,-s), min(n-1, n-1-s)]
=> j ∈ [max(0,-s)+s, min(n-1, n-1-s)+s]

def coord_descent(h, n, target, beta, max_sweeps, t0, budget_s, time_frac):
    h = project_sum(h, target)
    best_c5 = compute_c5(h)
    for sweep in range(max_sweeps):
        if time.time() - t0 > budget_s * time_frac:
            break
        improved = False
        for i in range(n):
            # Try small perturbations of h[i], adjusting another coordinate
            # to maintain the sum constraint
            for delta in [-0.05, -0.02, -0.01, 0.01, 0.02, 0.05]:
                h_try = h.copy()
                h_try[i] += delta
                if h_try[i] < 0 or h_try[i] > 1:
                    continue
                # Adjust another coordinate
                adj = -delta
                # Find best j to adjust
                best_j = -1
                best_val = best_c5
                for j in range(n):
                    if j == i:
                        continue
                    h_try[j] += adj
                    if h_try[j] < 0 or h_try[j] > 1:
                        h_try[j] -= adj
                        continue
                    c5_try = compute_c5(h_try)
                    if c5_try < best_val:
                        best_val = c5_try
                        best_j = j
                    h_try[j] -= adj
                if best_j >= 0 and best_val < best_c5 - 1e-14:
                    h = h_try.copy()
                    h[best_j] += adj
                    best_c5 = best_val
                    improved = True
                    break
        if not improved:
            break
    return h, best_c5
