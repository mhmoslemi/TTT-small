Let me think more carefully about the coordinate descent.

**Two-coordinate descent with exact minimization:**

Fix all h[i] for i ∉ {j, k}. Let s = h[j] + h[k] (fixed).
Let h[j] = x, h[k] = s - x.
Constraints: 0 ≤ x ≤ 1, 0 ≤ s-x ≤ 1.

Objective: f(x) = max_ℓ [A_ℓ * x + B_ℓ * (s-x) + C_ℓ]
= max_ℓ [(A_ℓ - B_ℓ) * x + B_ℓ * s + C_ℓ]
= max_ℓ [D_ℓ * x + E_ℓ]

This is a max of linear functions in x. The minimum over x ∈ [0, min(1,s)] ∩ [s-1, 1] is at a breakpoint or endpoint.

To find the minimum:
1. Compute D_ℓ, E_ℓ for all ℓ (2n-1 values)
2. Find min of max_ℓ (D_ℓ * x + E_ℓ) over the feasible x range

For step 2, the minimum of a convex piecewise-linear function over an interval occurs at:
- An endpoint, or
- A point where two lines intersect and are both the maximum

Algorithm:
- Evaluate at x_min and x_max
- For each pair (ℓ1, ℓ2) with D_ℓ1 ≠ D_ℓ2:
  - x* = (E_ℓ2 - E_ℓ1) / (D_ℓ1 - D_ℓ2)
  - If x* ∈ [x_min, x_max]:
    - Check if both lines are ≥ all others at x*
    - If yes, compute f(x*) and update best

This is O((2n)²) per pair (j,k), which is about 100K for n=160. Too slow for all pairs.

Optimization: Instead of all pairs, use a "best improvement" heuristic:
- For each j (cycling through 0 to n-1):
  - Find the lag ℓ* that achieves (or nearly achieves) the max
  - Find the k that most reduces c_{ℓ*} when we adjust (h[j], h[k])
  - Do the exact 1D minimization for that pair

This is much faster and should still make progress.

    return np.max(compute_corr(h)) * 2.0 / n

            break
        h[mask] += diff / cnt
        h = np.clip(h, 0.0, 1.0)

    n = len(h)
    corr = compute_corr(h)
    cmax = np.max(corr)
    exp_c = np.exp(beta * (corr - cmax))
    s = np.sum(exp_c)
    val = cmax + np.log(s) / beta
    p = exp_c / s
    
    # Gradient
    grad = np.zeros(n)
    for m in range(2 * n - 1):
        if p[m] < 1e-12:
            continue
        lag = m - (n - 1)
        pm = p[m]
        # Term 1: (1-h[j-lag]) for j in [max(0,lag), min(n-1, lag+n-1)]
        a1 = max(0, lag)
        b1 = min(n-1, lag + n - 1)
        if a1 <= b1:
            idx = np.arange(a1, b1+1) - lag
            grad[a1:b1+1] += pm * (1.0 - h[idx])
        # Term 2: -h[j+lag] for j in [max(0,-lag), min(n-1, n-1-lag)]
        a2 = max(0, -lag)
        b2 = min(n-1, n-1-lag)
        if a2 <= b2:
            idx2 = np.arange(a2, b2+1) + lag
            grad[a2:b2+1] -= pm * h[idx2]
    return val, grad

        g_penalty = g + 1000.0 * s * np.ones(n)
