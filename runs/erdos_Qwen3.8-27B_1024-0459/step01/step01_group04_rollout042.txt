For a fixed set of "active" shifts (those achieving the max), we can write:
minimize max_{k ∈ active} (sum_i h[i] - sum_i h[i]*h[i-k])

The first term (sum_i h[i]) is constant (= n/2) for valid h. So we're really minimizing:
max_{k ∈ active} (n/2 - autocorr_h(k))

Which is equivalent to:
maximize min_{k ∈ active} autocorr_h(k)

where autocorr_h(k) = sum_i h[i] * h[i-k].

This is a "maximin autocorrelation" problem! And it has a nice structure:
- The feasible set is {h ∈ [0,1]^n : sum h = n/2}
- The objective is the minimum of a set of quadratic forms

This is related to the "frame potential" problem in signal processing, but with a minimax objective instead of a sum.

**New idea: Use the dual problem.**

The minimax problem can be written as:
minimize T
subject to: autocorr_h(k) ≥ n/2 - T for all k ∈ active
           sum h = n/2
           0 ≤ h ≤ 1

This is a quadratic constraint (the autocorrelation is quadratic in h), so it's a non-convex QCQP. But we can solve it with:
- Penalty method: minimize T + lambda * sum_k max(0, n/2 - T - autocorr_h(k))^2
- This is a smooth optimization problem (quadratically penalized)
