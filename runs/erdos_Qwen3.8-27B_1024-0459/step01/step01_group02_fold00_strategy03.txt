2. Mathematical specification
**Variables**:  
- `h(x)` on `[0,2]` is represented as:  
    `h(x) = a₀ + Σ[aₖ*cos(kπx/1) + bₖ*sin(kπx/1)]`  
- `k` ranges from `1` to `8` (sine and cosine terms) to balance dimensionality and resolution.  
- `n_points = 128` (adjusted for Fourier basis dimensionality).  
- Fourier coefficients: `θ = [a₀, a₁, b₁, a₂, b₂, ..., a₈, b₈]` (size 17).  

**Constraints**:  
- Integral constraint: `∫₀² h(x)dx = 1`.  
- Box constraints: `0 ≤ h(x) ≤ 1` enforced by projection.  
- Periodicity enforced by the Fourier basis (period 2).  

**Exact objective**:  
Compute the correlation as the parent:  
`C₅ = max_k (integral of h(x)(1-h(x+k))dx)`  
evaluated numerically via `np.correlate(h, 1-h, mode='full')` with `dx = 2/128`.  

**Representation**:  
- Forward-map: `θ → h(x)` via Fourier reconstruction.  
- Back-projection: Truncate/cycle basis terms to prevent over-parameterization.  

**Solver interface**:  
- CVXPY/SciPy interface using `minimize` with SLSQP.  
- Objective: `max_k (convolution result) × dx`.  
- Equality constraint: `Σa_k + Σb_k cos + Σb_k sin terms = 1`.

4. Search choices and variations  
**Default parameters**:  
- Coefficients: 8 harmonics `k=1` to `8`.  
- Bounds: `θ ∈ [0,1]` for all coefficients.  
- Initial: Random uniform coefficients.  

**Significant variations to try**:  
- Decrease harmonics (*k=1 to 4*) for lower dimensionality.  
- Increase harmonics (*k=1 to 16*) for better resolution but longer run times.  
- Change basis: Use Hermite polynomials instead of Fourier (if better performance).  
- Adaptive-coefficient regularization: Penalize large coefficient magnitudes.  

**Trigger conditions**:  
- Low improvement: Reduce harmonics.  
- High wall time: Reduce harmonics or use stochastic gradient.  
- NaN/Inf in objective: Clip inputs and force gradient checks.  

5. Compute budget and robustness  
**Estimation**:  
- `n=128`, 17 variables → Objective evaluations O(n)=128*number_of_ops_per_eval  
- `np.correlate` is O(128) via FFT but we use a naive implementation for clarity.  
- Wall time: ~16h for 128 variables (estimate).  

**Feasibility**:  
- Project solutions to satisfy [0,1] and integral.  
- Early termination if |cons| > 1e-2.  

**Robustness**:  
- NaN detection: Clip gradients if values outside valid range.  
- Feasibility fallback: Use random walk if gradient-based methods stall.
