Wait, the second term: when i = j, h[j] appears in (1-h[i]) = (1-h[j]), so the derivative gives -h[i+k] = -h[j+k], but only if j+k is valid (i.e., j+k ∈ [0,n-1]) AND j is valid (j ∈ [0,n-1], which it always is) AND the pair (i=j, i+k=j+k) is in the valid range.

The valid range for i is: max(0,k) ≤ i ≤ min(n-1, n-1-k) when k > 0, and max(0,-k) ≤ i ≤ min(n-1, n-1+k) when k < 0.

So:
∂corr[m]/∂h[j] = (1-h[j-k]) · 1[0≤j-k≤n-1, 0≤(j-k)+k≤n-1] - h[j+k] · 1[0≤j≤n-1, 0≤j+k≤n-1]
= (1-h[j-k]) · 1[0≤j-k≤n-1] - h[j+k] · 1[0≤j+k≤n-1]

(The conditions 0≤(j-k)+k≤n-1 simplifies to 0≤j≤n-1 which is always true since j is an index of h.)

So:
∂corr[m]/∂h[j] = (1-h[j-k]) · 1[0≤j-k<n] - h[j+k] · 1[0≤j+k<n]

where k = m-(n-1).

For the smooth max F = (1/β)log(Σexp(β·corr[m])):
∂F/∂h[j] = Σ_m w_m · ∂corr[m]/∂h[j] where w_m = exp(β·corr[m])/Σexp(β·corr[m])

This can be computed in O(n·(2n-1)) = O(n²) time, which for n=160 is about 51200 operations. Very fast.

```python
def smooth_max_and_grad(h, beta):
    n = len(h)
    corr = np.correlate(h, 1.0 - h, mode='full')
    cmax = np.max(corr)
    exp_terms = np.exp(beta * (corr - cmax))
    sum_exp = np.sum(exp_terms)
    weights = exp_terms / sum_exp
    val = cmax + np.log(sum_exp) / beta
    
    grad = np.zeros(n)
    for m in range(2*n-1):
        w = weights[m]
        if w < 1e-15:
            continue
        k = m - (n-1)
        # ∂corr[m]/∂h[j] = (1-h[j-k])·1[0≤j-k<n] - h[j+k]·1[0≤j+k<n]
        # For j from 0 to n-1:
        # Term 1: (1-h[j-k]) when 0≤j-k<n, i.e., k≤j<n+k
        #   For k≥0: j from k to n-1 → indices j-k from 0 to n-1-k
        #   For k<0: j from 0 to n-1+k → indices j-k from -k to n-1
        # Term 2: -h[j+k] when 0≤j+k<n, i.e., -k≤j<n-k
        #   For k≥0: j from 0 to n-1-k → j+k from k to n-1
        #   For k<0: j from -k to n-1 → j+k from 0 to n-1+k
        
        if k >= 0:
            # Term 1: j from k to n-1, (1-h[j-k])
            if k < n:
                grad[k:] += w * (1.0 - h[:n-k])
            # Term 2: j from 0 to n-1-k, -h[j+k]
            if n-k > 0:
                grad[:n-k] -= w * h[k:]
        else:
            # k < 0, let k2 = -k > 0
            k2 = -k
            # Term 1: j from 0 to n-1-k2, (1-h[j+k2])
            if n-k2 > 0:
                grad[:n-k2] += w * (1.0 - h[k2:])
            # Term 2: j from k2 to n-1, -h[j-k2]
            if k2 < n:
                grad[k2:] -= w * h[:n-k2]
    
    return val, grad
```
