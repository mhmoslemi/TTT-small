Or: |shift| ≤ n-1-m and |shift| ≤ m.
So: |shift| ≤ min(m, n-1-m).

For a given m, the valid shifts k satisfy |k-n+1| ≤ min(m, n-1-m).

So Σ_k w_k I[m in range_k] = Σ_{k: |k-n+1| ≤ min(m,n-1-m)} w_k

This is a running sum of w_k, computable in O(n) total.

The second term: Σ_k w_k h[m+shift_k] I[m in range_k, m+shift_k in [0,n)]
But if m is in range_k, then m+shift_k is automatically in [0,n-1] (that's part of the range definition).
So this is Σ_{k: m in range_k} w_k h[m + k - n + 1]

This is a weighted correlation of h with w, which can be computed for all m simultaneously using np.correlate.

Similarly for the third term.

So the gradient can be computed in O(n log n) using FFT-based correlation, or O(n²) directly. For n=256, O(n²) is fine.

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return np.max(corr) * dx

def make_feasible(h, n):
    h = np.array(h, dtype=float).copy()
    h = np.clip(h, 0.0, 1.0)

            break
        if diff > 0:

            cnt = np.sum(mask)

            h[mask] += diff / cnt
        else:
            mask = h > 1e-13
            cnt = np.sum(mask)
            if cnt == 0: break
            h[mask] += diff / cnt
        h = np.clip(h, 0.0, 1.0)
    return h

    cmax = np.max(corr)
    return cmax + (1.0/beta) * np.log(np.sum(np.exp(beta * (corr - cmax))))

    x_new = np.linspace(0.0, 2.0, n_dst, endpoint=False)
    return np.interp(x_new, x_old, h_src)

            return obj_smooth(x, beta)

        except Exception:
            pass

    rng = np.random.RandomState(seed)
    h = make_feasible(h.copy(), n)
    best_c5 = compute_c5(h)

            h = h_try
            best_c5 = c5_try
    return h, best_c5

**Key differentiator: Inexact gradient methods + active set tracking.**

The main issue with SLSQP is that it uses a QP subproblem which is O(n³) per iteration. For the max objective, the gradient is sparse (only involves the active shift). We can exploit this.

**New idea: Inactive set screening.**

At each step:
1. Compute c_k for all k.
2. Identify the "active" set A = {k : c_k > max(c) - ε}.
3. Only the active constraints matter for the gradient.
4. Use a cheap gradient step (projected gradient) in the direction that reduces the active constraints.
5. Periodically recompute the full correlation to check for new active constraints.

This is essentially aFrank-Wolfe / cutting-plane approach.

**Even better idea: Use the structure of the problem.**

The key observation: c_k = Σ_j h[j](1-h[j+k]) for valid j.

This is a quadratic form in h. The max of quadratic forms is a convex function (since max of convex functions is convex... wait, quadratic forms can be non-convex).

Actually, c_k = Σ_j h[j] - Σ_j h[j]h[j+k]. The first term is linear (convex), the second is a quadratic form. The Hessian of the second term is a matrix that's not necessarily positive or negative semidefinite. So c_k is not necessarily convex.

However, the function h ↦ h[j]h[j+k] has Hessian with a 1 at (j,j+k) and (j+k,j), which is indefinite. So c_k is not convex in general.

This means the problem is non-convex, and we can get stuck in local minima. The max of non-convex functions is also non-convex.
