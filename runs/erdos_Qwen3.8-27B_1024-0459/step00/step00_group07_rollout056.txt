Let me try a different approach: **iterative reweighting / soft-min max**.

Replace max_k g_k with a soft version: (1/β) * log(sum_k exp(β * g_k)). As β → ∞, this approaches the max. For moderate β, it's differentiable and we can use gradient methods.

The gradient of the soft-max is:
∂/∂h[i] [(1/β) log sum_k exp(β g_k)] = (1/sum_k exp(β g_k)) * sum_k exp(β g_k) * ∂g_k/∂h[i]

This is a weighted average of the subgradients with weights proportional to exp(β g_k).

This is essentially a "smoothed" subgradient method. The gradient is computable in O(n * n_lags) per evaluation.

For n=200, n_lags = 399, this is 80,000 operations per gradient eval. Very fast.

def soft_max_objective(h, beta=10.0):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    vals = corr * dx
    # Soft max
    max_val = np.max(vals)
    exp_vals = np.exp(beta * (vals - max_val))
    return max_val + np.log(np.sum(exp_vals)) / beta
