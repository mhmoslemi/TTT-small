```python
def evaluate_c5(h):
    """Compute C5 value for a given h."""
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return np.max(corr) * dx

def project_onto_constraint(h, target_sum):
    """Project h onto {0 <= h_i <= 1, sum(h) = target_sum}."""
    # Use bisection to find lambda
    lo, hi = -1.0, 1.0
    for _ in range(100):
        mid = (lo + hi) / 2.0
        projected = np.clip(h - mid, 0.0, 1.0)
        s = np.sum(projected)
        if s > target_sum:
            lo = mid
        else:
            hi = mid
```

This is the max of linear functions of t, hence convex in t. We can find the minimum efficiently.

For a convex piecewise linear function, the minimum is at a "kink" (where the argmax changes) or at a boundary.

To find the minimum, we can:
1. Evaluate f at t=0 and t=t_max
2. If f(0) = f(t_max) and f is not constant, there's a minimum in between
3. Use the fact that the subgradient at t is:
   - If t > 0 and the active set at t has b_k < 0, decrease t
   - If t < t_max and the active set at t has b_k > 0, increase t
   - At the minimum, 0 is in the convex hull of {b_k : k active}

A simpler approach: since f is convex and piecewise linear, we can use binary search on the subgradient:
- Compute the subgradient s(t) = {b_k : k ∈ argmax} (a set)
- If min(s(t)) > 0, t is too small, increase
- If max(s(t)) < 0, t is too large, decrease
- Otherwise, t is optimal

Or even simpler: since there are at most 2n-1 linear pieces, and n is moderate, we can just evaluate f at a grid of t values and take the best.

For practical purposes, let me just evaluate f at, say, 20 evenly spaced points in [0, t_max] and take the best. This is O(20 * n) per pair swap, which is fast.

```python
def optimize_pair(h, i, j):

        else:
```

Alternatively, I can be smarter: since f(t) is the max of linear functions, I can find the minimum analytically.

f(t) = max_k (a_k + b_k * t)

The minimum of a convex piecewise linear function on [0, t_max] occurs at:
- t = 0, if all b_k ≥ 0 for k in argmax at t=0
- t = t_max, if all b_k ≤ 0 for k in argmax at t=t_max
- Some kink point in between

At a kink, two (or more) of the linear functions are equal and the "upper envelope" changes. The kink points are where a_i + b_i * t = a_j + b_j * t for some i, j, i.e., t = (a_j - a_i) / (b_i - b_j).

So the algorithm is:
1. Compute all a_k and b_k
2. Find all kink points t where the argmax changes
3. Evaluate f at each kink point (and at 0 and t_max)
4. Return the t with minimum f

This is O((2n-1)²) to find all kink points, which for n=42 is O(81²) = O(6561). Much faster!

Let me implement this:

```python
def find_optimal_t(h, i, j):
    """Find optimal t for h[i]+t, h[j]-t using analytic method."""
    n = len(h)
    t_max = min(1.0 - h[j], h[i])
    if t_max <= 0:
        return 0.0
    
    # Compute a_k (original g_k) and b_k (coefficient of t)
    # a_k = original correlation at lag k
    # b_k = change in g_k per unit t
    
    corr_orig = np.correlate(h, 1.0 - h, mode='full')
    
    # b_k for each lag:
    # b_k = (1-h[i-k]) - h[i+k] - (1-h[j-k]) + h[j+k]
    # (with out-of-range terms = 0)
    
    # Compute b for all lags
    lags = np.arange(-(n-1), n)  # all possible lags
    # For each lag k, b_k = [0≤i-k<n]*(1-h[i-k]) - [0≤i+k<n]*h[i+k] - [0≤j-k<n]*(1-h[j-k]) + [0≤j+k<n]*h[j+k]
    
    def coeff(k, idx):
        # Contribution of h[idx] change to g_k
        # h[idx] as h_{n+k}: n=idx-k, valid if 0≤idx-k<n → (1-h[idx-k])
        # h[idx] as h_n: n=idx, valid if 0≤idx+k<n → -h[idx+k]
        c = 0.0
        if 0 <= idx - k < n:
            c += 1.0 - h[idx - k]
        if 0 <= idx + k < n:
            c -= h[idx + k]
        return c
    
    b = np.array([coeff(k, i) - coeff(k, j) for k in lags])
    
    # f(t) = max_k (corr_orig[k+n-1] + b[k] * t)  (assuming corr_orig is indexed consistently)
    # Wait, I need to be careful with indexing.
    # np.correlate(h, 1-h, 'full')[j] corresponds to lag j-(n-1)
    # So corr_orig[m] = g_{m-(n-1)} for m = 0, ..., 2n-2
    
    a = corr_orig  # a[m] = g_{m-(n-1)}
    
    # f(t) = max_m (a[m] + b[m-(n-1)] * t) ... wait, I need to align indices.
    # Let me use: for the full correlation, index m corresponds to lag k = m - (n-1)
    # b array is indexed by lag (from -(n-1) to n-1)
    # So b at lag k = m-(n-1) is b[k] where I defined b for k from -(n-1) to n-1
    
    # Let me just use the same indexing:
    # full_corr[m] = g_{m-(n-1)}
    # b_full[m] = b at lag m-(n-1)
    
    b_full = np.array([coeff(k, i) - coeff(k, j) for k in range(-(n-1), n)])
    
    # f(t) = max_m (a[m] + b_full[m] * t)
    # This is a convex piecewise linear function on [0, t_max]
    
    # Find all breakpoints where argmax changes
    # Breakpoint between m1 and m2: a[m1] + b_full[m1]*t = a[m2] + b_full[m2]*t
    # t = (a[m2] - a[m1]) / (b_full[m1] - b_full[m2])
    
    breakpoints = set([0.0, t_max])
    for m1 in range(len(a)):
        for m2 in range(m1+1, len(a)):
            denom = b_full[m1] - b_full[m2]
            if abs(denom) > 1e-12:
                t_bp = (a[m2] - a[m1]) / denom
                if 0 <= t_bp <= t_max:
                    breakpoints.add(t_bp)
    
    # Evaluate f at all breakpoints
    best_t = 0.0
    best_val = np.inf
    for t in breakpoints:
        vals = a + b_full * t
        f_val = np.max(vals)
        if f_val < best_val:
            best_val = f_val
            best_t = t
    
    return best_t
```
