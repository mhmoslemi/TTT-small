But actually, I can do better. Since the objective is piecewise linear and convex, I can find the optimum analytically:
- The function g(δ) = max_m (a_m + b_m * δ) is the upper envelope of lines.
- The minimum of g is at the point where the "knee" of the envelope is.
- I can find it by: for each pair of lines (m1, m2), find their intersection δ* = (a_m2 - a_m1)/(b_m1 - b_m2), and check if it's the minimum of the envelope at that point.

Actually, a simpler approach: since g is convex and piecewise linear, I can use the fact that the minimum is at a point where the subgradient contains 0. The subgradient at δ is {sum of b_m for active m with weight, ...} - no, it's the set of convex combinations of b_m for active m.

For the max of linear functions, the subgradient at δ is the convex hull of {b_m : m is active at δ}. The minimum is where 0 is in this subgradient, i.e., where there exist active m's with both positive and negative b_m (or a zero b_m).

A practical approach: 
1. Start at δ=0
2. Find the active set (m's achieving the max)
3. If all active b_m > 0, decrease δ; if all < 0, increase δ
4. Move to the next breakpoint
5. Repeat until 0 is in the subgradient

This is like a simplex method for 1D LP.

Alternative: since it's 1D convex, I can use the fact that the minimum is where the subgradient contains 0. The subgradient at δ is the convex hull of {b_m : g_m(δ) is maximal}. So I need to find δ where there exist active m's with b_m > 0 and b_m < 0 (or b_m = 0).

A practical approach:
1. Evaluate at δ = 0
2. Find active set A = {m : f[m] + dx*c[m]*0 = max}
3. If all c[m] > 0 for m in A: need to decrease δ (the function is increasing)
   If all c[m] < 0 for m in A: need to increase δ
   If mixed: we're close to optimal, refine locally
4. Move to the next breakpoint (where an inactive line becomes equal to the max)
5. Repeat

This is essentially the simplex method applied to a 1D LP. It should converge in a few iterations.

                    b = t2

import numpy as np
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def project_constraint(h, n):
    h = np.clip(h, 0.0, 1.0)
    target = n / 2.0
    diff = target - np.sum(h)
    if abs(diff) < 1e-12:
        return h
    per = diff / n
    h2 = h + per
    h2 = np.clip(h2, 0.0, 1.0)
    # Fix residual
    residual = target - np.sum(h2)
    if abs(residual) > 1e-12:
        if residual > 0:
            idx = np.where(h2 < 1.0 - 1e-9)[0]
        else:
            idx = np.where(h2 > 1e-9)[0]
        if len(idx) > 0:
            per2 = residual / len(idx)
            h2[idx] = np.clip(h2[idx] + per2, 0.0, 1.0)
    return h2

def resample_to_n(h_old, n_new):
    n_old = len(h_old)
    if n_old == n_new:
        return h_old.copy()
    x_old = (np.arange(n_old) + 0.5) * 2.0 / n_old
    x_new = (np.arange(n_new) + 0.5) * 2.0 / n_new
    h_new = np.interp(x_new, x_old, h_old)
    return project_constraint(h_new, n_new)

def coord_desc(h, n, dx, time_limit=30.0):
    h = h.copy()
    f = np.correlate(h, 1.0 - h, mode='full')
    n_corr = 2 * n - 1
    s = np.arange(-(n-1), n)
    
    t0 = time.time()
    best = float(np.max(f) * dx)
    stall = 0
    
    max_rounds = 200
    moves_per_round = max(200, 4 * n)
    
    for rnd in range(max_rounds):
        if time.time() - t0 > time_limit:
            break
        
        any_improve = False
        for _ in range(moves_per_round):
            if time.time() - t0 > time_limit:
                break
            
            i = int(np.random.randint(n))
            j = int(np.random.randint(n))
            if i == j:
                continue
            hi, hj = h[i], h[j]
            if hi < 1e-12 or hj < 1e-12:
                continue
            if 1.0 - hi < 1e-12 and hj < 1e-12:
                continue
            
            # Compute c vector
            c = np.zeros(n_corr)
            js = j + s
            m = (js >= 0) & (js < n)
            c[m] += h[js[m]]
            is_ = i + s
            m = (is_ >= 0) & (is_ < n)
            c[m] -= h[is_[m]]
            js2 = j - s
            m = (js2 >= 0) & (js2 < n)
            c[m] += h[js2[m]]
            is2 = i - s
            m = (is2 >= 0) & (is2 < n)
            c[m] -= h[is2[m]]
            
            d_lo = max(-hi, hj - 1.0)
            d_hi = min(1.0 - hi, hj)
            if d_hi - d_lo < 1e-13:
                continue
            
            # Ternary search for min of max(f + dx*c*delta)
            a, b = d_lo, d_hi
            for _ in range(45):
                m1 = a + (b - a) / 3
                m2 = b - (b - a) / 3
                if np.max(f + dx * c * m1) > np.max(f + dx * c * m2):
                    a = m1
                else:
                    b = m2
            delta = 0.5 * (a + b)
            
            if abs(delta) < 1e-14:
                continue
            
            nf = f + dx * c * delta
            nm = np.max(nf)
            if nm < np.max(f) - 1e-11:
                h[i] += delta
                h[j] -= delta
                f = nf
                c5v = nm * dx
                if c5v < best:
                    best = c5v
                any_improve = True
        
        if not any_improve:
            stall += 1
            if stall >= 3:
                break
        else:
            stall = 0
    
    return h, best

def make_random_binary(n, rng):
    h = np.zeros(n)
    idx = rng.choice(n, n // 2, replace=False)

    # Fix sum

    # Random

    return results
