For a 0-1 valued h:
- h(x)(1-h(x+k)) = 1 when h(x)=1 and h(x+k)=0
- The integral counts the "overlap" of 1s in h with 0s in the shifted version

For a binary function with n/2 ones:
- At shift k=0: h*(1-h) = 0 everywhere (since h is 0 or 1)
- At other shifts: it counts how many positions have h[i]=1 and h[i+k]=0

So for binary functions, C₅ = dx * max_k (number of positions with h[i]=1 and h[i+k]=0)

This is related to the cross-correlation of a binary sequence with its complement.

For a balanced binary sequence (n/2 ones, n/2 zeros), the cross-correlation at shift k is:
sum_i h[i] * (1-h[i+k])

If the total number of 1s is n/2, then:
sum_i h[i] * h[i+k] + sum_i h[i] * (1-h[i+k]) = sum_i h[i] = n/2

So sum_i h[i]*(1-h[i+k]) = n/2 - sum_i h[i]*h[i+k]

To minimize the max of sum_i h[i]*(1-h[i+k]) over k, we want to maximize the min of sum_i h[i]*h[i+k] over k≠0.

This is related to Barker sequences and optimal binary sequences!

from scipy.optimize import minimize
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return dx * np.max(corr)

def soft_max(x, t):
    x_scaled = x * t
    x_max = np.max(x_scaled)
    return (x_max + np.log(np.sum(np.exp(x_scaled - x_max)))) / t

def softmax_weights(corr, t):
    x = corr * t
    x_max = np.max(x)
    exp_x = np.exp(x - x_max)
    return exp_x / np.sum(exp_x)

def grad_c5(hv, weights, dx):
    n_l = len(hv)
    grad_out = np.zeros(n_l)
    # Threshold small weights
    for s in range(-(n_l-1), n_l):
        w = weights[s + n_l - 1]
        if w < 1e-12:
            continue
        # A contribution: +w * (1 - hv[j-s]) for valid j

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return dx * np.max(corr)

def soft_max(x, t):
    x_scaled = x * t
    x_max = np.max(x_scaled)
    return (x_max + np.log(np.sum(np.exp(x_scaled - x_max)))) / t

def softmax_weights(corr, t):
    x = corr * t
    x_max = np.max(x)
    exp_x = np.exp(x - x_max)
    s = np.sum(exp_x)
    if s < 1e-300:
        return np.ones_like(corr) / len(corr)
    return exp_x / s

def grad_c5_hv(hv, weights, dx):
    n_l = len(hv)
    grad_out = np.zeros(n_l)
    for s in range(-(n_l - 1), n_l):
        w = weights[s + n_l - 1]
        if w < 1e-14:
            continue
        j_start = max(0, s)
        j_end = min(n_l, n_l + s)
        if j_start < j_end:
            grad_out[j_start:j_end] += w * (1.0 - hv[j_start - s:j_end - s])
        j_start = max(0, -s)
        j_end = min(n_l, n_l - s)
        if j_start < j_end:
            grad_out[j_start:j_end] -= w * hv[j_start + s:j_end + s]
    return dx * grad_out
