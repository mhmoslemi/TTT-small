∂c[s]/∂h[j] = (1-h[j-s]) - h[j+s] (approximately, with boundary handling)

- For each coordinate j, try to adjust h[j] to reduce the max correlation
- Given h[-j] fixed, c[s] as a function of h[j] is:

- We want to choose t ∈ [0,1] to minimize max_s c[s](t), subject to sum constraint
- This is a 1D optimization (minimize the max of linear functions)

One more thought: for the coordinate descent, the key insight is that for coordinate j, the effect on all c[m] values is:
c[m] → c[m] + Δh[j] * a_m[j]
where a_m[j] = ∂c[m]/∂h[j] = (1-h[j-s])·𝕀[...] - h[j+s]·𝕀[...]

So after changing h[j] from old_val to new_val (Δ = new_val - old_val):
c_new[m] = c_old[m] + Δ * a_m[j]

The new max is max_m (c_old[m] + Δ * a_m[j]).
We want to choose new_val ∈ [0,1] to minimize this max, and then adjust for the sum constraint.

This is a 1D problem: minimize f(Δ) = max_m (c_old[m] + Δ * a_m[j]) over Δ ∈ [-old_val, 1-old_val].

f is a convex piecewise-linear function in Δ. The minimum is at a breakpoint, which occurs when two of the c_old[m] + Δ * a_m[j] are equal.

We can find the optimal Δ by:
1. Computing all values c_old[m] + Δ * a_m[j] at Δ=0 (the current c)
2. The function f(Δ) = max_m (b_m + Δ*a_m) where b_m = c_old[m]
3. The minimum of f over Δ ∈ [Δ_lo, Δ_hi] is at:
   - Δ_lo, Δ_hi, or
   - A point where two "active" lines cross

For efficiency, I can find the top few m's (by b_m) and solve for the crossover.

Actually, a simpler approach: since f is convex piecewise-linear, I can use ternary search or bisection on the derivative.

f'(Δ) = a_m* where m* is (one of) the argmax at the current Δ.
f is decreasing where the dominant a_m* < 0, increasing where a_m* > 0.

The minimum is where the "active" constraint changes from having negative slope to positive slope. This happens at a breakpoint.

For n=70, I can just try all breakpoints: for each pair (m1, m2) where a_m1 ≠ a_m2:
Δ* = (b_m2 - b_m1) / (a_m1 - a_m2)
If Δ* is in [Δ_lo, Δ_hi] and both m1, m2 are active at Δ*, it's a candidate.

But checking all pairs is O((2n-1)²) per coordinate, and we have n coordinates, so O(n² · n²) = O(n⁴) per full sweep. For n=70, that's about 24 million operations. Might be too slow.

Simpler: just use golden section search or a few bisection steps on f(Δ).
f(Δ) = max_m (b_m + Δ*a_m) - this takes O(2n) to evaluate.
With 20 bisection steps, that's O(40n) per coordinate, O(40n²) per sweep. For n=70, about 200K operations. Very fast.

import numpy as np
from scipy.optimize import minimize
import time

def _eval_c5(h):
    n = len(h)
    dx = 2.0 / n
    c = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(c) * dx)

def _project(h, n):
    target = n / 2.0
    h = np.asarray(h, dtype=float)
    lo, hi = -2.0, 2.0
    for _ in range(80):
        mid = (lo + hi) / 2.0
        test = np.clip(h - mid, 0.0, 1.0)
        if np.sum(test) > target:
            lo = mid
        else:
            hi = mid
    h_p = np.clip(h - (lo + hi) / 2.0, 0.0, 1.0)
    resid = target - np.sum(h_p)
    if abs(resid) > 1e-12:
        free = (h_p > 1e-9) & (h_p < 1.0 - 1e-9)
        nfree = int(np.sum(free))
        if nfree > 0:
            h_p[free] += resid / nfree
            h_p = np.clip(h_p, 0.0, 1.0)
    return h_p

def _upscale(h, n_old, n_new):
    x_old = np.arange(n_old) * (2.0 / n_old)
    x_new = np.linspace(0.0, 2.0, n_new, endpoint=False)
    h_interp = np.interp(x_new, x_old, h)
    h_interp = np.clip(h_interp, 0.0, 1.0)
    return _project(h_interp, n_new)

def _smooth_grad(h, tau):
    n = len(h)
    dx = 2.0 / n
    c = np.correlate(h, 1.0 - h, mode="full")
    c_max = float(np.max(c))
    exp_c = np.exp(tau * (c - c_max))
    s_exp = float(np.sum(exp_c))
    p = exp_c / s_exp
    grad = np.zeros(n)
    for j in range(n):
        g = 0.0
        for m in range(2 * n - 1):
            if p[m] < 1e-15:
                continue
            s_val = m - (n - 1)
            coeff = 0.0
            js = j - s_val
            jp = j + s_val
            if 0 <= js <= n - 1:
                coeff += (1.0 - h[js])
            if 0 <= jp <= n - 1:
                coeff -= h[jp]
            g += p[m] * coeff
        grad[j] = g
    return grad * dx

def _grad_descent(h, n, t_start, max_time, tau0=5.0, tau_final=0.1, alpha0=0.1):
    h = h.copy()
    best_score = _eval_c5(h)
    h_best = h.copy()
    dx = 2.0 / n
    for k in range(100000):
        if time.time() - t_start >= max_time:
            break
        frac = min(1.0, k / (max(1.0, 0.3 * max_time)))
        tau = tau0 * (tau_final / tau0) ** frac
        alpha = alpha0 / (1.0 + 0.05 * k)
        grad = _smooth_grad(h, tau)
        h_new = h - alpha * grad
        h_new = _project(h_new, n)
        s = _eval_c5(h_new)
        if s < best_score - 1e-12:
            best_score = s
            h_best = h_new.copy()
        h = h_new
    return h_best, best_score

def _coord_descent(h, n, t_start, max_time, passes=200):
    h = h.copy()
    best_score = _eval_c5(h)
    h_best = h.copy()
    for p in range(passes):
        if time.time() - t_start >= max_time:
            break
        c_full = np.correlate(h, 1.0 - h, mode="full")
        improved_this_pass = 0
        for j in range(n):
            if time.time() - t_start >= max_time:
                break
            old_val = h[j]
            a = np.zeros(2 * n - 1)
            for m in range(2 * n - 1):
                s_val = m - (n - 1)
                coeff = 0.0
                js = j - s_val
                jp = j + s_val
                if 0 <= js <= n - 1:
                    coeff += (1.0 - h[js])
                if 0 <= jp <= n - 1:
                    coeff -= h[jp]
                a[m] = coeff
            b = c_full - old_val * a
            lo_t = -old_val
            hi_t = 1.0 - old_val
            if lo_t >= hi_t:
                continue
            for _ in range(40):
                mid = (lo_t + hi_t) / 2.0
                f_mid = float(np.max(b + mid * a))
                f_lo = float(np.max(b + lo_t * a))
                f_hi = float(np.max(b + hi_t * a))
                f_left = float(np.max(b + (lo_t + mid) / 2.0 * a))
                f_right = float(np.max(b + (mid + hi_t) / 2.0 * a))
                if f_left < f_right:
                    hi_t = mid
                else:
                    lo_t = mid
            new_val = old_val + (lo_t + hi_t) / 2.0
            new_val = max(0.0, min(1.0, new_val))
            if abs(new_val - old_val) > 1e-10:
                h[j] = new_val
                improved_this_pass += 1
        h = _project(h, n)
        s = _eval_c5(h)
        if s < best_score - 1e-12:
            best_score = s
            h_best = h.copy()
    return h_best, best_score

def _random_search(h_best, n_best, score_best, n_iter, rng, t_start, max_time):
    for _ in range(n_iter):
        if time.time() - t_start >= max_time:
            break
        h_rand = rng.random(n_best)
        h_rand = _project(h_rand, n_best)
        s = _eval_c5(h_rand)
        if s < score_best:
            h_best = h_rand.copy()
            score_best = s
    return h_best, score_best

def _perturb_optimize(h0, n, rng, t_start, max_time, n_perturb=20):
    best_h = h0.copy()
    best_s = _eval_c5(h0)
    for _ in range(n_perturb):
        if time.time() - t_start >= max_time:
            break
        h_p = h0 + rng.normal(0, 0.1, n)
        h_p = _project(h_p, n)
        s_p = _eval_c5(h_p)
        if s_p < best_s:
            best_h = h_p.copy()
            best_s = s_p
            h0 = h_p.copy()
    return best_h, best_s
