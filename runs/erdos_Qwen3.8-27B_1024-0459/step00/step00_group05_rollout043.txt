This is like the "cutting plane" or "subgradient" method for minimax problems. It's simple and doesn't require computing all correlations' derivatives.

Algorithm:
1. Compute all correlations c_k
2. Find k* = argmax c_k
3. Compute gradient of c_{k*} with respect to h
4. Take a step: h_new = h - step_size * gradient
5. Project to feasible set
6. Repeat

This is essentially the "Welch" or "maximin" subgradient method. It should converge to a local optimum.

Let me implement this. The key is computing the gradient of c_{k*} efficiently.

For c(k) = sum_{i} h[i+k] * (1-h[i]) (where we sum over valid i):
∂c(k)/∂h[j] = sum over valid i of:
  δ(i+k, j) * (1-h[i]) + h[i+k] * (-δ(i, j))
= (1-h[j-k]) [if j-k is a valid i for this k] - h[j+k] [if j is a valid i for this k]

Wait, I need to be more careful. Let me define:
For lag k (can be negative or positive), c(k) = sum_{i: valid} h[i+k] * (1-h[i])

where "valid" means 0≤i<n and 0≤i+k<n (for the h[i+k] term to be in range) - actually wait, h is an array of length n, so h[i+k] is only defined for 0≤i+k<n. And h[i] is defined for 0≤i<n. So the valid range of i is: max(0, -k) ≤ i ≤ min(n-1, n-1-k).

∂c(k)/∂h[j]:
Term 1: h[i+k] contributes when i+k = j, i.e., i = j-k. This is valid if max(0,-k) ≤ j-k ≤ min(n-1, n-1-k).
  Contribution: (1-h[j-k])
Term 2: (1-h[i]) contributes when i = j. This is valid if max(0,-k) ≤ j ≤ min(n-1, n-1-k).
  Contribution: -h[j+k]

So: ∂c(k)/∂h[j] = (1-h[j-k]) * I(j-k valid) - h[j+k] * I(j valid for lag k)

where I(j-k valid) means max(0,-k) ≤ j-k ≤ min(n-1, n-1-k)
and I(j valid) means max(0,-k) ≤ j ≤ min(n-1, n-1-k)

This can be computed in O(n) for a given k.

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    r = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(r) * dx)

def feasible_project(h, n):
    h = np.asarray(h, dtype=np.float64).copy()
    h = np.clip(h, 0.0, 1.0)
    target = n * 0.5
    s = h.sum()
    if s > 1e-15:
        h *= target / s
    else:
        h[:] = 0.5
    h = np.clip(h, 0.0, 1.0)
    return h

        return compute_c5(feasible_project(h, n))

                       options={'maxiter': max_iter, 'xatol': 1e-11, 'fatol': 1e-13,

        h_out = feasible_project(res.x, n)

    except Exception:
