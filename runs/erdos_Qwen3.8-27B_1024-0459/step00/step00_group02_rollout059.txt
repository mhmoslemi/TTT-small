C₅ = max_k dx * corr_k where corr_k = Σ_i h[i] * (1-h[i+k-1+n-1])

The "worst" shift is the one that aligns the most 1s with 0s. To minimize the max, we want the 1s to be "spread out" so that no matter how you shift, there aren't too many 1-0 misalignments.

This is related to the concept of "autocorrelation" and "cross-correlation" minimization, similar to error-correcting codes or Sidon sets.

For a good solution:
- The set of 1s should be "random-like" to minimize correlation peaks

    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')

                    h_bin[i] = max(0.0, h_bin[i] - 0.001)
            h_bin = project_feasible(h_bin, n_fin)
            c5_bin = compute_c5(h_bin, n_fin)
            if c5_bin < best_c5:
                best_h = h_bin.copy()
                best_c5 = c5_bin

    if best_h is None:
        n_f = 90
        best_h = make_binary_init(n_f, rng)
        best_h = project_feasible(best_h, n_f)
        best_c5 = compute_c5(best_h, n_f)

    n_final = len(best_h)
    best_h = project_feasible(best_h, n_final)
    best_h = np.clip(best_h, 0.0, 1.0)
    # Final exact sum fix
    target_sum = n_final * 0.5
    s = np.sum(best_h)
    if abs(s - target_sum) > 1e-10:
        best_h = project_feasible(best_h, n_final)
    best_c5 = compute_c5(best_h, n_final)

    return best_h, best_c5, n_final
