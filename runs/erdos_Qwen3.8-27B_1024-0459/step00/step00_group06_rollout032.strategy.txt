# Approach and rationale

The Erdős minimum overlap problem requires minimizing the maximum overlap between a step function and its shifted complement. The approach leverages a constrained optimization with a penalty method to handle the integral constraint and box constraints. The central idea is to use the provided parent solution as an initial guess and refine it using a derivative-free optimization algorithm, ensuring the solution adheres to domain and functional constraints. The key bottleneck is the computational cost of evaluating the objective function (cross-correlation) for high-resolution grids. By combining the parent solution's structure with penalty enforcement for the integral constraint, we maximize the chance of achieving a lower bound than the current record. The method balances exploration and exploitation by allowing a large penalty for constraint violations, guiding the search while maintaining feasibility.

**Limitations and heuristics:**
- Penalties may not enforce exact constraint satisfaction if too large or small, requiring tuning.
- The optimization relies on discontinuities in the objective function, which may require restarts for better convergence.
- Higher-resolution grids (e.g., 200 points) could yield better bounds but are computationally expensive and not the primary focus here.

**Guidance for implementation:**
- This plan prioritizes resolution consistency with the parent (95 points) but includes fallbacks for alternative resolutions (e.g., 100, 64) if necessary.
- The initial guess is always the provided parent solution to leverage its proximity to an optimum.
- Only `scipy.optimize.minimize` with COBYLA via penalty is explicitly formulated; gradient handling occurs implicitly through numerical differentiation or penalty formulations.
- Validate all candidates (including those from penalties) for `0 <= h[i] <= 1` and `sum(h)*dx ≈ 1` before objective evaluation.
- If no improvement over the parent is found, revert to parent metrics under time constraints.

# Mathematical specification

## Representation and objective

The function \( h \) is represented by \( n_{\text{points}} \) samples over \([0, 2]\), discretizing \( dx = 2 / n_{\text{points}} \). Each \( h[i] \in [0, 1] \) and \( \sum h[i] \times dx = 1 \). The objective is:

\[
C_5 = \max_{k} \left( dx \cdot \sum_{\text{valid } i} h[i] \cdot (1 - h[i+k]) \right)
\]

where the sum iterates over \( i \) for which \( i+k \) is within the sample domain. The discrete `mode="full"` in `np.correlate` covers all \( k \in [-n_{\text{points}} + 1, n_{\text{points}} - 1] \).

**Variables:**
- \( n_{\text{points}} \): number of grid points (initially 95, then attempt 100, 64).
- \( h = [h[0], h[1], \ldots, h[n_{\text{points}}-1]) \in \mathbb{R}^{n_{\text{points}}} \): function values.

**Constraints:**
1. Box constraints: \( \forall i, 0 \leq h[i] \leq 1 \)
2. Integral constraint: \( \sum_{i} h[i] \times dx = 1 \)

**Equality set:** \( \sum h[i] = n_{\text{points}} / 2 \) (real number, may not be integer if \( n_{\text{points}} \) is odd).

**Objective:** Minimize \( C_5 \) as the max overlap value.

**Penalty formulation:**
Add a quadratic penalty to handle the integral constraint:
\[
f_{\text{penalty}}(h) = \begin{cases} 
0 & \text{if } \left| \sum h[i] - n_{\text{points}} / 2 \right| < \epsilon \\
( \sum h[i] - n_{\text{points}} / 2 )^2 \cdot S & \text{otherwise}
\end{cases}
\]
where \( \epsilon = 10^{-5} \) and large \( S = 10^6 \) ensure feasibility.

# Search choices and useful variations

### Primary resolution:
- Start with `n_points` = 95 (parent) to leverage its performance and minimize dx.
- Optional: explore n_points ∈ {64, 100} if time budget allows and shows improvement.

### Optimization method:
- **Primary:** COBYLA (derivative-free, handles box constraints).

### Initial guess:
- Mandatory: the parent solution (initialized via `initial_h_values`).

### Tolerance:
- For integral: target error < \( 10^{-4} \) of dx impact.

### Termination:
- Manual: 500 iterations (arbitrary, because COBYLA does not have easy termination by objective value).
- Tracks best solution with improving objective.

### Variations:
1. **Resolution scaling (fallback to parent truncated at high n):**
   - If optimization exceeds time budget, fall back to the parent solution.

# Compute budget and robustness

### Estimation:
- **n_points = 95:** cross-correlation for each evaluation is \( 95^2 \approx 9025 \) operations, ~0.02 seconds per evaluation (fast).
- **COBYLA cost:** ~\( O(n_{\text{points}} \times \text{number of iterations}) \). At 95 variables and 500 iterations, predictions run <10 seconds per round in favorable cases.

### Feasible schedule:
- Target ~500 iterations → ~500 × 0.02 s = 10 seconds for evaluation.
- Use this to test the function. If objective improves (C5 lowered by ~0.01-0.05), promote it.
- Threshold for restart: time exceeds 40% of budget or no improvement for 50 iterations.

### Numerical issues:
- Clip values to [0, 1] at the beginning of `obj_func_optimize`.
- Use \(\epsilon\)-tolerances to avoid terminal constraint violations.
- Energy is avoided by early clipping + penalty.
