Let me also think: should I use the "smooth max" trick? The soft max:
soft_max(x)_α = (1/α) ln(Σ exp(α·x_k))

as α→∞, this approaches max(x). For finite α, it's smooth and differentiable.

The gradient of soft_max is: ∂/∂x_j = exp(α·x_j)/Σ exp(α·x_k) (softmax weights)

So the gradient of the objective is a weighted average of the gradients of individual f_k, with weights given by the softmax.

This is much better than the indicator-based gradient of the hard max!

Let me implement this:

```python
def smooth_c5(h, alpha=100.0):
    n = len(h)
    dx = 2.0 / n
    corr = correlate(h, 1.0 - h, mode='full') * dx
    m = np.max(corr)
    return m + np.log(np.sum(np.exp(alpha * (corr - m)))) / alpha

def smooth_c5_grad(h, alpha=100.0):
    n = len(h)
    dx = 2.0 / n
    one_minus_h = 1.0 - h
    corr = correlate(h, one_minus_h, mode='full')
    corr_dx = corr * dx
    m = np.max(corr_dx)
    weights = np.exp(alpha * (corr_dx - m))
    weights /= weights.sum()
    
    # Gradient: sum_k weights[k] * d(corr_dx[k])/d(h)
    grad = np.zeros(n)
    for k in range(2*n-1):
        if weights[k] < 1e-15:
            continue
        shift = n - 1 - k
        for j in range(n):
            # d(corr[k])/d(h[j]):
            # = dx * [(1-h[j+shift]) if j+shift in [0,n) else 0]
            #       - [h[j-shift] if j-shift in [0,n) else 0]
            val = 0.0
            if 0 <= j + shift < n:
                val += (1.0 - h[j+shift])
            if 0 <= j - shift < n:
                val -= h[j-shift]
            grad[j] += weights[k] * dx * val
    return grad
```

Wait, I need to double-check the gradient formula.

corr[k] = sum_{i: 0≤i<n, 0≤i+shift<n} h[i] * (1-h[i+shift]) where shift = n-1-k.

d(corr[k])/d(h[j]) = sum_{valid i} [δ_{i,j}(1-h[i+shift]) - δ_{i+shift,j} h[i]]

First term: i=j must be valid, i.e., 0≤j<n and 0≤j+shift<n. Contribution: (1-h[j+shift]).
Second term: i+shift=j, so i=j-shift. Must be valid: 0≤j-shift<n and 0≤j<n. Contribution: -h[j-shift].

So d(corr[k])/d(h[j]) = I(0≤j+shift<n)(1-h[j+shift]) - I(0≤j-shift<n)(h[j-shift])

where I(condition) = 1 if condition true, 0 otherwise. And 0≤j<n is always true.

So the gradient of the smooth objective is:
∂/∂h[j] smooth_c5 = dx * Σ_k w_k * [I(0≤j+shift_k<n)(1-h[j+shift_k]) - I(0≤j-shift_k<n)(h[j-shift_k])]

where shift_k = n-1-k and w_k are the softmax weights.

This can be computed in O(n²) total (for each of 2n-1 shifts, we update n elements, but each update is O(1) with the indicator check). Actually it's O(n * (2n-1)) = O(n²) which is the same as the correlation computation.

Let me optimize this: for a given shift s:
- The first term contributes (1-h[j+s]) to grad[j] for j in [max(0,-s), min(n-1, n-1-s))
- The second term contributes -h[j-s] to grad[j] for j in [max(0, s), min(n-1, n-1+s))
