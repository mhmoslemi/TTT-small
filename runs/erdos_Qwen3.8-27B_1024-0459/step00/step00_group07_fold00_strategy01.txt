## 2. Mathematical Specification

### Variables and Representation
- $h$: $n$-point function approximation represented as $h \in \mathbb{R}^{n}$ with $h_i \in [0,1]$
- $dx = 2/n$: Sampling interval
- $L$: Maximum lag (correlation length)

### Objective Function
Minimize: $C_5(h) = \max_{k \in \mathbb{Z}} dx \sum_{i=0}^{n-1} h[i] \cdot (1 - h[(i+k) \mod n])$

### Analytical Form
The objective is defined via:
$$
\max_{k=-L}^{L} dx \left\langle h, \text{shift}_k(1-h) \right\rangle
$$
where $\text{shift}_k$ denotes circular shift by $k$ samples.

### Constraints
**Analytical Constraint**:
$$\sum_{i=0}^{n-1} h[i] \cdot dx = 1 \implies \sum_{i=0}^{n-1} h[i] = n/2$$

**Bounds**:
$$\forall i, \: 0 \leq h[i] \leq 1$$

### Formulation for Solvers
The optimization is reformulated as:
Minimize: $-\log\text{likelihood} + \alpha \cdot \text{constraints}$
Subject to: $\alpha \cdot (\text{sum}(h) - n/2)^2 + \gamma \cdot \sum_i h[i](1-h[i])$

This combines:
1. MLE-like form for maximization tasks
2. Smooth constraint enforcement
3. Regularization

def enforce_constraints(candidate):
    # Analytical constraint: adjust sum
    desired_sum = len(candidate)/2
    s_val = np.sum(candidate)
    diff = desired_sum - s_val + np.random.uniform(-0.2, 0.2)  # Introduce randomness to avoid degeneracy
    if abs(diff) < 1e-4: return candidate
    # Distribute adjustment across ALL candidates (guaranteed improvement)

    candidate = np.clip(candidate, 0, 1)
    # Check constraint again

def unit_integral_projection(h):

        h_adjusted = np.clip(h_adjusted, 0, 1)
