    dx = 2.0 / n
    one_h = 1.0 - h
    corr = np.correlate(h, one_h, mode='full')
    c5_val = np.max(corr) * dx

- If j+t in [t, n-1], i.e., j in [0, n-1-t]: contributes -h[j+t] [from (1-h[i-t]) when i-t=j]

So:
d corr(-t) / d h[j] = (1-h[j-t]) * [t <= j <= n-1] - h[j+t] * [0 <= j <= n-1-t]

This is symmetric to the s >= 0 case with roles reversed.

d f / d h[j] = dx * sum_k exp(tau * corr[k] * dx) * d corr[k] / d h[j] / sum_k exp(tau * corr[k] * dx)

This is a weighted average of the individual gradients, weighted by softmax. This is a valid subgradient of the max when tau → ∞, and a proper gradient of the smoothed function for finite tau.
