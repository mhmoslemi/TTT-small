1. Approach and rationale
The Erdős minimum overlap problem seeks to minimize the maximum overlap integral between a step function h and its complement 1-h over all shifts. The current record is 0.38085, and the central idea here is to treat the problem as a quadratic minimization with linear constraints. Since the optimal solution likely resides on the boundary where many function values are 0 or 1, we combine derivative-based optimization with a boundary-enforcement mechanism. We use a compact representation of h(x) via coefficients of a piecewise linear interpolation on a uniform grid. This allows the problem to be formulated with linear equality constraints. We also introduce a two-phase approach: initialization with the parent set and iterative refinement using quadratic programming.

Implementation complexity is manageable due to the quadratic form. The main limitation is that quadratic programs require integer constraints for piecewise linear solutions, but we overcome this by enforcing boundaries during solution validation.

2. Mathematical specification
We parameterize h via P sampled points on [0,2]. The function is constructed as a piecewise linear interpolation between these points:
