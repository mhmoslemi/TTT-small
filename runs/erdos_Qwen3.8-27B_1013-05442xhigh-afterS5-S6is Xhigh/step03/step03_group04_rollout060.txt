- For each coordinate, we need to evaluate f(s) = max_m (c_m + s*a_m)
- c_m and a_m can be precomputed from the current h
- Actually, we can maintain corr[] incrementally

Let me think about maintaining corr[]:
- corr[m] = sum_j h[j+m] * (1-h[j]) for valid j
- When we change h[i] from v to t:
  - For m where i-m is valid (j = i-m): corr[m] += (t-v) * (1-h[i-m])
  - For m where i+m is valid (j = i): corr[m] += -(t-v) * h[i+m]

So we can update corr[] in O(n) per coordinate change.

Then for the 1D subproblem:
- Current corr[] is known
- coeff_m = (1-h[i-m])*[0≤i-m<n] - h[i+m]*[0≤i+m<n]
- We want to find t ∈ [0,1] minimizing max_m (corr[m] + (t-v)*coeff_m) * dx

This is: find s = t-v ∈ [-v, 1-v] minimizing max_m (corr[m] + s*coeff_m)

For the 1D problem, let me just use a simple grid + refinement:
- Evaluate at s = -v, -v/2, 0, (1-v)/2, 1-v (5 points)
- Find the best

- h[i] = 0
- h[i] = 1  
- h[i] = current value
- h[i] = value that equalizes the top 2-3 lags

The "equalize" approach:
- Find the top 2 lags (m1, m2) that achieve (or nearly achieve) the max
- Find t such that corr[m1] + (t-v)*coeff_m1 = corr[m2] + (t-v)*coeff_m2
- t = (corr[m2] - corr[m1]) / (coeff_m1 - coeff_m2) + v
- Clip to [0,1]
- Evaluate at this t and at 0 and 1, pick the best

This is O(n) per coordinate (to find the top lags) and gives a good approximate solution.

For a convex function f:

- If f is increasing at s (subgradient > 0), the minimum is to the left

The subgradient of f at s is the set of slopes of active lines. A valid subgradient is the slope of any active line. If we pick the slope of the argmax line, it's a valid subgradient.

import time

def compute_c5(h):

    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)

def project_h(h, target_sum):
    h = np.clip(h, 0.0, 1.0).copy()
    for _ in range(100):
        diff = target_sum - h.sum()
        if abs(diff) < 1e-12:
            break
        free = (h > 1e-10) & (h < 1.0 - 1e-10)
        k = free.sum()
        if k == 0:
            h += diff / len(h)
        else:
            h[free] += diff / k
        h = np.clip(h, 0.0, 1.0)
    return h

def cd_sweep(h, corr, target, rng):
    """One coordinate descent sweep. Returns updated h, corr."""
    n = len(h)
    nl = 2 * n - 1
    order = rng.permutation(n)
    for i in order:
        v = h[i]
        effect = np.zeros(nl)
        # Term 1: (1-h[i+m-n+1]) for valid m
        mlo = max(n - 1 - i, 0)
        mhi = min(2*n - 2 - i, nl - 1)
        if mlo <= mhi:
            effect[mlo:mhi+1] += 1.0 - h[i + mlo - n + 1 : i + mhi - n + 2]
        # Term 2: -h[i-m+n-1] for valid m
        mlo2 = max(i, 0)
        mhi2 = min(i + n - 1, nl - 1)
        if mlo2 <= mhi2:
            hi_s = n - 1  # h index when m = i (mlo2)
            hi_e = 0      # h index when m = i+n-1 (mhi2)
            # h indices: n-1, n-2, ..., 0 (reversed)
            # More precisely: h[i+m+n-1-m] = h[n-1] at m=i, h[0] at m=i+n-1
            # index = i + n - 1 - m, so at mlo2: i+n-1-mlo2, at mhi2: i+n-1-mhi2
            idx_s = i + n - 1 - mlo2
            idx_e = i + n - 1 - mhi2
            # We need h[idx_e : idx_s+1][::-1]
            effect[mlo2:mhi2+1] -= h[idx_e:idx_s+1][::-1]
        
        # 1D convex minimization: min s in [-v, 1-v] of max(corr + s*effect)
        slo, shi = -v, 1.0 - v
        # Subgradient bisection
        a, b = slo, shi
        for _ in range(12):
            mid = 0.5 * (a + b)
            act = int(np.argmax(corr + mid * effect))
            sl = effect[act]
            if sl < -1e-12:
                a = mid
            elif sl > 1e-12:
                b = mid
            else:
                break
        bs = 0.5 * (a + b)
        # Check endpoints too
        best_s, best_v = bs, float(np.max(corr + bs * effect))
        for sc in (slo, shi):
            vv = float(np.max(corr + sc * effect))
            if vv < best_v:

            h[i] = t
    # Project
    h = project_h(h, target)
    corr = np.correlate(h, 1.0 - h, mode="full")
    return h, corr

    c = np.correlate(h, 1.0 - h, mode="full")
    m = np.max(c)
    xs = np.clip(beta * (c - m), -500, 500)
