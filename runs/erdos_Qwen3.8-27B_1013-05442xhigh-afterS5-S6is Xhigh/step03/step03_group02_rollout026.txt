    For the projection onto {0≤h≤1, sum(h)=n/2}, I'll use the water-filling algorithm (which is exact for this constraint set).

    Let me also think about the line search. For the objective f(h) = max_k c_k(h):
    - We have a direction d (negative gradient)
    - We want to find α > 0 such that f(h + α*d) < f(h)
    - Use backtracking: start with α, halve until improvement or α < α_min

    The projection after the step is important. After projecting, the actual step is h_new = P(h + α*d) where P is the projection. The line search should account for this.

    Actually, for simplicity, let me do:
    1. Compute gradient g
    2. Try h_try = project(h - α*g_normalized)
    3. If c5(h_try) < c5(h), accept and increase α
    4. Otherwise, decrease α

    This is a subgradient method (since we're using a subgradient of the max).

    For a more efficient method, I can use the "smooth max" with a large beta and trust that the gradient is accurate enough:
    f_β(h) = (1/β) * log(sum_k exp(β*c_k(h)))
    ∇f_β(h) = (1/sum_k exp(β*c_k)) * sum_k exp(β*c_k) * ∇c_k

    This is the exact gradient of the smooth approximation, and for large β it concentrates on the argmax.

    Let me combine approaches:
    - Use smooth max gradient with adaptive β
    - Backtracking line search
    - Periodic binary local search
    - Multiple restarts

    ```python
        n = len(h)
        dx = 2.0 / n

        return float(np.max(corr) * dx)

        return np.correlate(h, 1.0 - h, mode="full")

        """Compute gradient of all correlation values.
        Returns array of shape (2n-1, n) where grad[m, j] = d(c_m)/d(h_j).
        This is memory-intensive for large n, so we'll compute on-the-fly.
        """
        pass  # Not used directly

    def smooth_max_grad(corr, beta):
        """Compute gradient of smooth max w.r.t. corr values (softmax weights)."""
        c = corr - np.max(corr)
        weights = np.exp(beta * c)
        weights /= weights.sum()
        return weights

    def grad_smooth_max(h, beta):
        """Compute gradient of smooth max of correlations w.r.t. h."""
        n = len(h)
        corr = compute_corr(h)
        weights = smooth_max_grad(corr, beta)
        grad = np.zeros(n)
        for m in range(len(corr)):
            w = weights[m]
            if w < 1e-10:
                continue
            lag = m - (n - 1)
            L = abs(lag)
            if L >= n:
                continue
            if lag > 0:
                grad[L:] += w * (1.0 - h[:n-L])
                grad[:n-L] -= w * h[L:]
            elif lag < 0:
                grad[:n-L] += w * (1.0 - h[L:])
                grad[L:] -= w * h[:n-L]
            else:
                grad += w * (1.0 - 2.0 * h)
        return grad

    def project_h(h, target_sum):
        """Project h onto {0<=h<=1, sum(h)=target_sum} using water-filling."""
        h = h.copy()
        for _ in range(50):
            h = np.clip(h, 0.0, 1.0)
            diff = target_sum - h.sum()
            if abs(diff) < 1e-12:
                break
            # Water filling
            if diff > 0:
                # Need to increase: add to elements not at 1
                mask = h < 1.0 - 1e-12
                if mask.sum() == 0:
                    break
                h[mask] += diff / mask.sum()
            else:
                # Need to decrease: subtract from elements not at 0
                mask = h > 1e-12
                if mask.sum() == 0:
                    break
                h[mask] += diff / mask.sum()
        return np.clip(h, 0.0, 1.0)
    ```

    Wait, the water-filling approach above is not quite right. The issue is that when we add diff/mask.sum() to elements below 1, some might exceed 1, requiring re-clipping. This iterative approach works but might be slow.

    A better approach: sort the values and find the threshold.

    ```python
    def project_h(h, target_sum):
        """Exact projection onto {0<=h<=1, sum(h)=target_sum}."""
        n = len(h)
        h = np.clip(h, 0.0, 1.0)
        for _ in range(100):
            diff = target_sum - h.sum()
            if abs(diff) < 1e-13:
                break
            if diff > 0:
                # Add to non-saturated variables
                mask = h < 1.0
                if not mask.any():
                    break
                h[mask] += diff / mask.sum()
            else:
                mask = h > 0.0
                if not mask.any():
                    break
                h[mask] += diff / mask.sum()
            h = np.clip(h, 0.0, 1.0)
        return h
    ```

    This should converge quickly in practice.
