The original correlation is:
c[m] = sum_i h[i] * (1 - h[i+d_m])

After the change, the new correlation is:
c'[m] = c[m] + δ * (change due to h[s]) - δ * (change due to h[t])

The change due to h[s] in c[m]:
- If 0 ≤ s + d_m < n: h[s] appears as the first factor in term i=s, so the change is δ * (1 - h[s+d_m])
- If 0 ≤ s - d_m < n: h[s] appears in (1-h[s]) where the term is h[s-d_m] * (1-h[s]), so the change is -δ * h[s-d_m]

Total change due to h[s]: δ * [(1-h[s+d_m])*[0≤s+d_m<n] - h[s-d_m]*[0≤s-d_m<n]] = δ * w_s(d_m)

Similarly for h[t]: change is -δ * w_t(d_m) (because h[t] decreases by δ)

So c'[m] = c[m] + δ * (w_s(d_m) - w_t(d_m)) = c[m] + δ * b[m]
