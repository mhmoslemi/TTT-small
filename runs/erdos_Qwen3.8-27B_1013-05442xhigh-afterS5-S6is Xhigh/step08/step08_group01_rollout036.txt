    """Project x onto {y: 0 <= y <= 1, sum(y) = t}."""
    n = len(x)

    lo = x.min() - 1.0
    hi = x.max() + 1.0
    for _ in range(100):
        mid = (lo + hi) / 2

        if s > t:

        else:
            hi = mid

        if active.sum() > 0:

For the exact 1D minimization: f(d) = max(c_aff + d*a, unaff_max) is a convex piecewise linear function. Its minimum is at a breakpoint (where two lines cross) or at a boundary. The breakpoints occur where c_i + d*a_i = c_j + d*a_j for some i, j, or where c_i + d*a_i = unaff_max.

∂f(d) = {sum_{i in argmax} a_i * λ_i : λ_i ≥ 0, sum λ_i = 1}

Actually, f(d) = max(max_i (c_i + d*a_i), unaff_max)
= max(max_i (c_i + d*a_i), unaff_max)

The subgradient w.r.t. d is:
If max_i(c_i + d*a_i) > unaff_max:
  ∂f/d ∩ a_i for i in argmax(c_i + d*a_i)
If max_i(c_i + d*a_i) < unaff_max:
  ∂f/d = {0}
If they're equal:
  ∂f/d = convex hull of {a_i for i in argmax} ∪ {0}

So the optimum is where 0 is in the subgradient, i.e., where the max_i(c_i + d*a_i) is minimized (and <= unaff_max) or at the boundary where max_i(c_i + d*a_i) = unaff_max.

A simple approach: binary search for d such that the "crossing point" has 0 in its subgradient. This is equivalent to finding d such that min(a_i for i in argmax) ≤ 0 ≤ max(a_i for i in argmax), or max_i(c_i + d*a_i) ≤ unaff_max.

        h5, c5 = cd_optimize(best_h, n_cur, 500, deadline, 150)
        if c5 < best_c:
            best_h, best_c = h5, c5
    # Phase 5: Perturbation restarts
    n_cur = len(best_h)
    for r in range(8):
        if time.time() > deadline - 20:
            break
        s = 0.005 + 0.03 * r
        hp = project_capped(best_h + rng.normal(0, s, n_cur), n_cur)
        ho, co = cd_optimize(hp, n_cur, 150, deadline, 80)
        if co < best_c:
            best_h, best_c = ho, co
    # Phase 6: Final polish
    n_cur = len(best_h)
    if time.time() < deadline - 10:
        h6, c6 = cd_optimize(best_h, n_cur, 300, deadline, 200)
        if c6 < best_c:
            best_h, best_c = h6, c6
    # Check complement
    h_flip = project_capped(1.0 - best_h, n_cur)
    c_flip = compute_c5(h_flip, n_cur)
    if c_flip < best_c:
        best_h, best_c = h_flip, c_flip
    best_h = project_capped(best_h, len(best_h))
    best_c = compute_c5(best_h, len(best_h))
    return best_h, best_c, len(best_h)
