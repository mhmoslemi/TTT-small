    - Pair (j-k, j) changes iff j-k ∈ {i, j} or j ∈ {i, j}. The second condition is always true. So pair (j-k, j) always changes (if j-k >= 0).
    
    But wait, pair (i-k, i) and pair (j-k, j) might be the same pair if i-k = j-k, i.e., i = j. But i ≠ j (one is 0, other is 1). Also pair (i, i+k) and pair (j-k, j) might be the same: i = j-k means k = j-i. In that case, pair (i, i+k) = (i, j) and pair (j-k, j) = (i, j). Same pair!
    
    Similarly, pair (i-k, i) and pair (j, j+k) might be the same: i-k = j means k = i-j. In that case, pair (i-k, i) = (j, i) and pair (j, j+k) = (j, i). Same pair!
    
    So let me handle the cases:
    
    Case 1: k = j-i > 0 (assuming j > i)
    Pairs that change:
    - (i, j) [from m=i, i+k=j]: Before: 0*(1-1)=0. After: 1*(1-0)=1. Change: +1
    - (i-k, i) = (2i-j, i) [if 2i-j >= 0 and 2i-j ≠ j]: Before: h[2i-j]*1 = h[2i-j]. After: h[2i-j]*0 = 0. Change: -h[2i-j]
    - (j, j+k) = (j, 2j-i) [if 2j-i < n and 2j-i ≠ i]: Before: 1*(1-h[2j-i]). After: 0*(1-h[2j-i]) = 0. Change: -(1-h[2j-i])
    - (j-k, j) = (i, j): Same as first pair! Don't double count.
    
    So total Δc_k for k = j-i > 0: +1 - h[2i-j] - (1-h[2j-i]) (with out-of-bounds terms = 0)
    = 1 - h[2i-j] - 1 + h[2j-i] = h[2j-i] - h[2i-j]
    
    Case 2: k = i-j > 0 (assuming i > j)
    Pairs that change:
    - (i-k, i) = (j, i): Before: 1*(1-0) = 1. After: 0*(1-1) = 0. Change: -1
    - (i, i+k) = (i, 2i-j) [if 2i-j < n]: Before: 0*(1-h[2i-j]). After: 1*(1-h[2i-j]). Change: +(1-h[2i-j])
    - (j, j+k) = (j, i): Same as first pair! Don't double count.
    - (j-k, j) = (2j-i, j) [if 2j-i >= 0]: Before: h[2j-i]*1 = h[2j-i]. After: h[2j-i]*0 = 0. Change: -h[2j-i]
    
    Total Δc_k for k = i-j > 0: -1 + (1-h[2i-j]) - h[2j-i] = -h[2i-j] - h[2j-i]
    
    Case 3: k ≠ |i-j|, k > 0
    Pairs that change:
    - (i, i+k) [if i+k < n, i+k ≠ j]: Before: 0. After: (1-h[i+k]). Change: +(1-h[i+k])
    - (i-k, i) [if i-k >= 0, i-k ≠ j]: Before: h[i-k]. After: 0. Change: -h[i-k]
    - (j, j+k) [if j+k < n, j+k ≠ i]: Before: (1-h[j+k]). After: 0. Change: -(1-h[j+k])
    - (j-k, j) [if j-k >= 0, j-k ≠ i]: Before: h[j-k]. After: h[j-k]. Change: 0.
    
    Wait, (j-k, j): Before: h[j-k]*(1-h[j]) = h[j-k]*0 = 0. After: h[j-k]*(1-h[j]) = h[j-k]*1 = h[j-k]. Change: +h[j-k].
    
    Hmm wait, I need to be more careful. h[j] goes from 1 to 0.
    (j-k, j): Before: h[j-k]*(1-1) = 0. After: h[j-k]*(1-0) = h[j-k]. Change: +h[j-k].
    
    So for case 3:
    Δc_k = (1-h[i+k]) - h[i-k] - (1-h[j+k]) + h[j-k]
    (with out-of-bounds and "≠ other position" terms = 0)
    
    This is O(1) per lag. So the total Δc for all lags can be computed in O(n) time.
    
    Now, for the optimization: we want to find the swap (i, j) that minimizes max_k (c_k + Δc_k).
    
    A simpler approach: just find the swap that minimizes the sum of the top few c_k values, or the one that most reduces the maximum c_k.
    
    For a greedy approach: focus on the lag(s) k* that achieve the maximum. Try to reduce c_{k*}.
    
    For a given k*, which swap (i, j) most reduces c_{k*}?
    From case 3 (k* ≠ |i-j|):
    Δc_{k*} = (1-h[i+k*]) - h[i-k*] - (1-h[j+k*]) + h[j-k*]
    
    Since h[i] = 0 and h[j] = 1:
    - To make Δc_{k*} very negative, we want:
      - h[i+k*] = 1 (so 1-h[i+k*] = 0)
      - h[i-k*] = 1 (so -h[i-k*] = -1)
      - h[j+k*] = 0 (so -(1-h[j+k*]) = 0)
      - h[j-k*] = 0 (so h[j-k*] = 0)
    - Best case: Δc_{k*} = 0 - 1 - 0 + 0 = -1
    
    So we want to find i (a 0-position) and j (a 1-position) such that:
    - h[i+k*] = 1, h[i-k*] = 1, h[j+k*] = 0, h[j-k*] = 0
    (all within bounds, and i+k* ≠ j, i-k* ≠ j, j+k* ≠ i, j-k* ≠ i)
    
    This gives a -1 improvement in c_{k*}.
    
    But we also need to check that other lags don't increase too much.

```python
def compute_c5(h, n):

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h, 0.0, 1.0)
    for _ in range(200):
        diff = target - h.sum()
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            room = 1.0 - h
            s = room.sum()
            if s < 1e-14:
                break
            h += diff / s * room
        else:
            s = h.sum()
            if s < 1e-14:
                break
            h += diff / s * h
    return np.clip(h, 0.0, 1.0)

def make_binary(h, n):
```

```python
from scipy.optimize import minimize
import time

def compute_c5(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1 - h, mode='full')
    return float(np.max(c) * dx)

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h, 0.0, 1.0)
    for _ in range(200):
        diff = target - h.sum()
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            room = 1.0 - h
            s = room.sum()
            if s < 1e-14:
                break
            h += diff / s * room
        else:
            s = h.sum()
            if s < 1e-14:
                break
            h += diff / s * h
    return np.clip(h, 0.0, 1.0)

    h_b = np.zeros(n)
    h_b[idx[:n // 2]] = 1.0
    return h_b

            top_o = np.argsort(B_o)[:min(3, len(ones))]

            best_j = -1

                    j = ones[oj]

                # Update lists

                ones.append(best_i)
                zeros.remove(best_i)
                zeros.append(best_j)

                    best_max = cur_max
                    best_h = h_b.copy()
            else:
                no_improve += 1
                if no_improve > max_no_improve:

                    rj = rng.randint(len(ones))
                    i = zeros[ri]
                    j = ones[rj]

                    h_b[j] = 0

                    ones.remove(j)
                    ones.append(i)
                    zeros.remove(i)
                    zeros.append(j)
                    no_improve = 0

            no_improve += 1
            if no_improve > max_no_improve:

def _full_delta(h, i, j, n):
    """Compute full correlation delta for swapping h[i]:0→1, h[j]:1→0."""
    # Using the formula: delta[k] = (1-h[i-k])_v - (1-h[j-k])_v - h[i+k]_v + h[j+k]_v + inter
    delta = np.zeros(2 * n - 1)

    k = np.arange(-(n-1), n)

    mask_ik = (idx_ik >= 0) & (idx_ik < n)
    idx_jk = j - k
    mask_jk = (idx_jk >= 0) & (idx_jk < n)
    idx_ikp = i + k
    mask_ikp = (idx_ikp >= 0) & (idx_ikp < n)
    idx_jkp = j + k
    mask_jkp = (idx_jkp >= 0) & (idx_jkp < n)
    
    delta[mask_ik] += (1.0 - h[idx_ik[mask_ik]])
    delta[mask_jk] -= (1.0 - h[idx_jk[mask_jk]])
    delta[mask_ikp] -= h[idx_ikp[mask_ikp]]
    delta[mask_jkp] += h[idx_jkp[mask_jkp]]

        delta[n-1+dk] += 1
    dk = j - i
    if dk != 0 and -(n-1) <= dk <= n-1:
        delta[n-1+dk] += 1
    
    return delta
```

Let me also think about a different continuous optimization approach: **proximal gradient method** for the log-sum-exp objective.

The objective is f(h) = max_k c_k(h) ≈ logsumexp(αc) / α for large α.

The gradient of logsumexp(αc)/α with respect to h is:
∂/∂h [logsumexp(αc)/α] = (1/α) * exp(αc - logsumexp(αc)) * ∂c/∂h

where ∂c/∂h is the subgradient of the continuous max.

For a specific lag k, ∂c_k/∂h[i] = (1-h[i+k]) - h[i-k] (with bounds).

The projected gradient step is:
h ← clip(h - η * ∇f, 0, 1)
then project to sum(h) = n/2.

This is simple and fast. With Adam or similar adaptive methods, it should converge well.

Let me implement a projected Adam optimizer:

```python
def projected_adam(h, n, deadline, alpha=10000, lr=0.01, max_iters=100000):
    m = np.zeros(n)
    v = np.zeros(n)
    beta1, beta2 = 0.9, 0.999
    t = 0
    best_h = h.copy()
    best_c = compute_c5(h, n)
    dx = 2.0 / n
    
    for it in range(max_iters):
        if time.time() > deadline:
            break
        t += 1
        c = np.correlate(h, 1-h, mode='full') * dx
        # logsumexp gradient
        mval = c.max()
        shifted = alpha * (c - mval)
        weights = np.exp(shifted - shifted.max())
        weights /= weights.sum()
        # grad = (1/alpha) * weights @ ∂c/∂h
        # ∂c_k/∂h[i] for the k-th lag
        # Instead of computing the full gradient, use the top few lags
        top_k = np.argsort(c)[::-1][:5]
        grad = np.zeros(n)
        for idx in top_k:
            k = idx - (n-1)
            w = weights[idx] / alpha
            if k >= 0:
                if k == 0:
                    grad += w * (1 - 2*h)
                else:
                    grad[k:] += w * (1 - h[:n-k])
                    grad[:n-k] -= w * h[k:]
            else:
                kk = -k
                grad[:n-kk] += w * (1 - h[kk:])
                grad[kk:] -= w * h[:n-kk]
        
        m = beta1 * m + (1-beta1) * grad
        v = beta2 * v + (1-beta2) * grad**2
        m_hat = m / (1 - beta1**t)
        v_hat = v / (1 - beta2**t)
        h_new = h - lr * m_hat / (np.sqrt(v_hat) + 1e-8)
        h_new = project_feasible(h_new, n)
        c_new = compute_c5(h_new, n)
        if c_new < compute_c5(h, n) * 1.001:  # Accept if close to or better
            h = h_new
            if c_new < best_c:
                best_c = c_new
                best_h = h.copy()
    
    return best_h, best_c
```

```python
import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1 - h, mode='full')
    return float(np.max(c) * dx)

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h, 0.0, 1.0)
    for _ in range(200):
        diff = target - h.sum()
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            room = 1.0 - h
            s = room.sum()
            if s < 1e-14:
                break
            h += diff / s * room
        else:
            s = h.sum()
            if s < 1e-14:
                break
            h += diff / s * h
    return np.clip(h, 0.0, 1.0)

def make_binary(h, n):
    idx = np.argsort(h)[::-1]
    h_b = np.zeros(n)
    h_b[idx[:n // 2]] = 1.0
    return h_b

def full_delta(h, i, j, n, karr):
    delta = np.zeros(2 * n - 1)
    idx = i - karr
    m = (idx >= 0) & (idx < n)
    delta[m] += 1.0 - h[idx[m]]
    idx = j - karr
    m = (idx >= 0) & (idx < n)
    delta[m] -= 1.0 - h[idx[m]]
    idx = i + karr
    m = (idx >= 0) & (idx < n)
    delta[m] -= h[idx[m]]
    idx = j + karr
    m = (idx >= 0) & (idx < n)
    delta[m] += h[idx[m]]
    d1 = i - j
    if d1 != 0:
        delta[n - 1 + d1] += 1.0
    d2 = j - i
    if d2 != 0:
        delta[n - 1 + d2] += 1.0
    return delta

def fast_local_search(h_b, n, deadline, max_iters, seed):
    dx = 2.0 / n
    c = np.correlate(h_b, 1 - h_b, mode='full').astype(float)
    cur_max = c.max()
    best_h = h_b.copy()
    best_max = cur_max
    karr = np.arange(-(n - 1), n)
    ones = np.where(h_b == 1)[0].tolist()
    zeros = np.where(h_b == 0)[0].tolist()
    rng = np.random.RandomState(seed)
    no_improve = 0
    max_no_improve = 3000
    pertub_count = 0

    for it in range(max_iters):
        if time.time() > deadline:
            break
        if len(zeros) == 0 or len(ones) == 0:
            break

        k_max = c.argmax()
        k_actual = k_max - (n - 1)
        kk = abs(k_actual)

        if kk == 0:
            no_improve += 1
        else:
            A = np.zeros(n)
            A[kk:] -= h_b[:n - kk]
            A[:n - kk] -= h_b[kk:]
            B = np.zeros(n)
            B[kk:] += h_b[:n - kk]
            B[:n - kk] += h_b[kk:]

            A_z = A[zeros]
            B_o = B[ones]
            top_z = np.argsort(A_z)[:min(5, len(zeros))]
            top_o = np.argsort(B_o)[:min(5, len(ones))]

            best_score = cur_max
            best_i = -1
            best_j = -1
            best_d = None

            for zi in top_z:
                i = zeros[zi]
                for oj in top_o:
                    j = ones[oj]
                    d = full_delta(h_b, i, j, n, karr)
                    nm = (c + d).max()
                    if nm < best_score:
                        best_score = nm
                        best_i = i
                        best_j = j
                        best_d = d

            if best_i >= 0:
                h_b[best_i] = 1.0
                h_b[best_j] = 0.0
                c += best_d
                cur_max = best_score
                ones.remove(best_j)
                ones.append(best_i)
                zeros.remove(best_i)
                zeros.append(best_j)
                no_improve = 0
                if cur_max < best_max:
                    best_max = cur_max
                    best_h = h_b.copy()
            else:
                no_improve += 1
                if no_improve > max_no_improve:
                    for _ in range(10):
                        ri = rng.randint(len(zeros))
                        rj = rng.randint(len(ones))
                        i = zeros[ri]
                        j = ones[rj]
                        d = full_delta(h_b, i, j, n, karr)
                        h_b[i] = 1.0
                        h_b[j] = 0.0
                        c += d
                        cur_max = c.max()
                        ones.remove(j)
                        ones.append(i)
                        zeros.remove(i)
                        zeros.append(j)
                    no_improve = 0
                    pertub_count += 1
                    if pertub_count > 50:
                        break

    return best_h, best_max * dx

def slsqp_step(h, n, alpha, maxiter):
    dx = 2.0 / n
    def obj(x):
        c = np.correlate(x, 1.0 - x, mode='full')
        m = c.max()
        shifted = alpha * (c - m)
        sm = shifted.max()
        return m + (sm + np.log(np.exp(shifted - sm).sum())) / alpha
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': lambda x: x.sum() - n / 2.0, 'jac': lambda x: np.ones(n)}]
    try:
        res = minimize(obj, h, method='SLSQP', bounds=bounds,
                       constraints=cons, options={'maxiter': maxiter, 'ftol': 1e-16})
        return project_feasible(res.x, n)
    except Exception:
        return h

def projected_gradient(h, n, deadline, lr, max_iters, top_k):
    dx = 2.0 / n
    G = np.zeros(n)
    momentum = np.zeros(n)
    beta = 0.9
    best_h = h.copy()
    best_c = compute_c5(h, n)
    for it in range(max_iters):
        if time.time() > deadline:
            break
        c = np.correlate(h, 1 - h, mode='full') * dx
        cur_c = c.max()
        if cur_c < best_c:
            best_c = cur_c
            best_h = h.copy()
        top_idx = np.argsort(c)[::-1][:top_k]
        grad = np.zeros(n)
        for idx in top_idx:
            k = idx - (n - 1)
            if k >= 0:
                if k == 0:
                    grad += 1.0 - 2.0 * h
                else:
                    grad[k:] += (1.0 - h[:n - k])
                    grad[:n - k] -= h[k:]
            else:
                kk = -k
                grad[:n - kk] += (1.0 - h[kk:])
                grad[kk:] -= h[:n - kk]
        grad = dx * grad / top_k
        momentum = beta * momentum + (1 - beta) * grad
        G += momentum ** 2
        step = lr / (np.sqrt(G) + 1e-8)
        h_new = project_feasible(h - step * momentum, n)
        h = h_new
    return best_h, best_c

def run(seed=42, budget_s=1100, **kwargs):
    t0 = time.time()
    total = budget_s - 5
    dl = t0 + total
    rng = np.random.RandomState(seed)

    try:
        h0 = np.array(initial_h_values, dtype=float).copy()

    except Exception:

        h0 = np.full(n, 0.5)

    best_h = project_feasible(h0, n)

    p1_end = t0 + 0.15 * total
    h = best_h.copy()
    for alpha in [5000, 50000, 500000, 5000000]:

        h = slsqp_step(h, n, alpha, 2000)
        c = compute_c5(h, n)
        if c < best_c:

    # Phase 2: Fast binary local search (55%)
    p2_end = t0 + 0.70 * total
    h_b = make_binary(best_h, n)
    hb2, cb2 = fast_local_search(h_b, n, p2_end, 3000000, seed)
    if cb2 < best_c:
        best_c, best_h = cb2, hb2.copy()

    # Phase 3: Additional binary starts (15%)
    p3_end = t0 + 0.85 * total
    for trial in range(8):
        if time.time() > p3_end - 5:

        perm = rng.permutation(n)
        h_b3 = np.zeros(n)
        h_b3[perm[:n // 2]] = 1.0

        if cb3 < best_c:
            best_c, best_h = cb3, hb3.copy()

    # Phase 4: SLSQP from binary (10%)
    p4_end = t0 + 0.93 * total
    h = best_h.copy()
    for alpha in [50000, 500000, 5000000]:
        if time.time() > p4_end - 2:

        c = compute_c5(h, n)
        if c < best_c:

    # Phase 5: Final projected gradient polish

        if cs < best_c:
            best_c, best_h = cs, hs.copy()

    best_h = project_feasible(best_h, n)
    best_c = compute_c5(best_h, n)
    return best_h, best_c, n
```
