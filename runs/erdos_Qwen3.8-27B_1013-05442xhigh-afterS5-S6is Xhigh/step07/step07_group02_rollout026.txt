import time

from scipy.optimize import minimize

def compute_c5(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1 - h, mode='full')
    return float(np.max(c) * dx)

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h, 0.0, 1.0)
    for _ in range(200):
        diff = target - h.sum()
        if abs(diff) < 1e-13:
            break
        if diff > 0:
            room = 1.0 - h
            s = room.sum()
            if s < 1e-14:
                break
            h += diff / s * room
        else:
            s = h.sum()
            if s < 1e-14:
                break
            h += diff / s * h
    return np.clip(h, 0.0, 1.0)

def compute_grad_max(h, n):
    """Compute gradient of the max correlation."""
    dx = 2.0 / n
    c = np.correlate(h, 1 - h, mode='full')
    kmax = np.argmax(c) + 1  # shift amount (can be negative)
    # kmax is the index in 0..2n-2, actual shift is kmax - (n-1)
    k = kmax - (n - 1)
    g = np.zeros(n)
    if k >= 0:
        g[:n-k] += (1 - h[k:])
        g[k:] -= h[:n-k]
    else:
        g[-k:] += (1 - h[:n+k])
        g[:n+k] -= h[-k:]
    return g * dx, c[kmax] * dx

def nesterov_pg(h, n, lr, max_iter, momentum=0.9):
    """Nesterov accelerated projected gradient descent."""
    dx = 2.0 / n
    y = h.copy()
    v = np.zeros(n)
    best_h = h.copy()
    best_c5 = compute_c5(h, n)
    for i in range(max_iter):
        g, _ = compute_grad_max(y, n)
        v = momentum * v + lr * g
        y_new = y - v
        y_new = project_feasible(y_new, n)
        c5_new = compute_c5(y_new, n)
        if c5_new < best_c5:
            best_c5 = c5_new
            best_h = y_new.copy()
        y = y_new
    return best_h, best_c5

where p_k = exp(α*f_k) / ∑_j exp(α*f_j)

And ∇f_k(x) has a specific structure (it's related to the cross-correlation derivative).

For f_k(x) = ∑_i x[i](1-x[i+k])*dx:
∂f_k/∂x[j] = dx * [(1-x[j+k])*1_{j+k<n} - x[j-k]*1_{j-k≥0}]

So the weighted gradient is:
g[j] = dx * ∑_k p_k * [(1-x[j+k])*1_{j+k<n} - x[j-k]*1_{j-k≥0}]

            c5 = compute_c5(h, n)

For a swap of position i (1→0) and j (0→1), the change in f_k is:
Δf_k = change in ∑_m h[m](1-h[m+k])

The only terms that change are those where m or m+k equals i or j.

Terms involving i:
- When m = i: was h[i](1-h[i+k]) = 1*(1-h[i+k]) = 1-h[i+k], now 0*(1-h[i+k]) = 0. Change: -(1-h[i+k])
- When m+k = i, i.e., m = i-k: was h[i-k](1-h[i]) = h[i-k]*1 = h[i-k], now h[i-k]*0 = 0. Change: -h[i-k]

Terms involving j:
- When m = j: was h[j](1-h[j+k]) = 0*(1-h[j+k]) = 0, now 1*(1-h[j+k]) = 1-h[j+k]. Change: +(1-h[j+k])
- When m+k = j, i.e., m = j-k: was h[j-k](1-h[j]) = h[j-k]*1 = h[j-k], now h[j-k]*0 = 0. Change: -h[j-k]

So Δf_k = -(1-h[i+k]) - h[i-k] + (1-h[j+k]) - h[j-k] (with appropriate bounds checking)

This is O(1) per k! So to compute the change in C₅ = max_k f_k, we need to:
1. Compute Δf_k for all k (O(n) work)
2. Find the new max (O(n) work)
3. Also check if the old max is still valid

Total: O(n) per swap. For n=400, that's 400 operations per swap. Much faster than the full correlate!

Let me vectorize the delta computation! Instead of looping over k, I can compute the delta using shifts of the array:

For position i (1→0):
- The change to f_k is: -(1-h[i+k])*1_{valid} - h[i-k]*1_{valid}
- This is like: -(1-h) shifted by -i, minus h shifted by i

For position j (0→1):
- The change to f_k is: +(1-h[j+k])*1_{valid} - h[j-k]*1_{valid}
- This is: +(1-h) shifted by -j, minus h shifted by j

So the total delta vector is:
delta = -shift(1-h, -i) - shift(h, i) + shift(1-h, -j) - shift(h, -j)

where shift(v, s) means the vector v shifted by s positions (with zeros padding).

In numpy, a shift of v by s positions is: the element v[m+s] goes to position m.
Or equivalently, the element at position m of shift(v, s) is v[m+s] (if in bounds, else 0).

For the correlation vector f (length 2n-1, indexed from shift -(n-1) to n-1):
f[k] = ∑_i h[i]*(1-h[i+k]) for shift k

The contribution of position i to f[k] is:
- h[i]*(1-h[i+k]) when i is the "left" index (i.e., the first factor)
- h[i-k]*(1-h[i]) when i is the "right" index (i.e., the second factor)

When h[i] changes from 1 to 0:
- As left index: f[k] loses h[i]*(1-h[i+k]) = 1*(1-h[i+k]) = 1-h[i+k] (for valid i+k)
- As right index: f[k] loses h[i-k]*(1-h[i]) = h[i-k]*1 = h[i-k] (for valid i-k)

So the change vector (over shifts k) is:
Δ[k] = -(1-h[i+k])*1_{0≤i+k<n} - h[i-k]*1_{0≤i-k<n}

In terms of the correlation vector (indexed from -(n-1) to n-1):
Δ[k + (n-1)] = -(1-h[i+k]) * 1_{0≤i+k<n} - h[i-k] * 1_{0≤i-k<n}

For k ranging from -(n-1) to n-1:
- i+k ranges from i-(n-1) to i+(n-1), and we need 0≤i+k<n
- i-k ranges from i-(n-1) to i+(n-1), and we need 0≤i-k<n

```python
def subgrad_smoothed(h, n, eps=0.01):
    """Smoothed subgradient: average gradient over all near-max components."""
    dx = 2.0 / n
    c = np.correlate(h, 1 - h, mode='full') * dx
    cmax = c.max()
    weights = (c >= cmax - eps).astype(float)
    if weights.sum() == 0:
        weights = np.zeros(len(c))
        weights[np.argmax(c)] = 1.0
    else:
        weights /= weights.sum()
    
    g = np.zeros(n)
    for k_idx in range(len(weights)):
        if weights[k_idx] == 0:
            continue
        k = k_idx - (n - 1)
        if k >= 0:
            g[:n-k] += weights[k_idx] * (1.0 - h[k:])
            g[k:] -= weights[k_idx] * h[:n-k]
        else:
            nk = -k
            g[nk:] += weights[k_idx] * (1.0 - h[:n-nk])
            g[:n-nk] -= weights[k_idx] * h[nk:]
    return g * dx, cmax
```
