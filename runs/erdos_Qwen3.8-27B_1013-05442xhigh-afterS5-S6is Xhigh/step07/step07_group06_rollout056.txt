Let me also think about a key optimization: the greedy swap evaluation.

In the previous code, `compute_base_binary` computes a matrix `base[p]` for each position p, where `base[p, m]` represents the change in correlation at lag m if we flip position p (from 0 to 1 or 1 to 0). Then for a swap (i→1, j→0), the new correlation is `base[i] - base[j] + corr`.

This is O(n) memory and O(n) per swap evaluation, and we evaluate O((n/2)^2) = O(n²/4) swaps per sweep. For n=400, that's 40000 evaluations of 800-length vectors, which is manageable.

Actually, looking more carefully at the previous code, it uses a chunked approach and only finds one improving swap per sweep (the best one). This is O(n² * n) per sweep = O(n³) which for n=400 is 64M operations per sweep. With 30-35 sweeps, that's ~2 billion operations. This might be slow.

Let me think about a faster approach:

**Faster greedy:**
Instead of finding the single best swap, we can:
1. For each zero position i, compute the best one position j to swap with
2. This is O(n²) per zero, O(n³) total - same as before

Or:
1. Precompute for each position p, the effect matrix base[p]
2. For a swap (i, j): new_corr = corr + base[i] - base[j]
3. We want to minimize max(new_corr)
4. This is equivalent to finding (i,j) that minimizes max(corr + base[i] - base[j])

One optimization: instead of evaluating all (i,j) pairs, we can:
- For each i (zero), find the j (one) that minimizes the max
- This is still O(n²) per i, O(n³) total

But we can vectorize: for a fixed i, we want to find j that minimizes max over m of (corr[m] + base[i,m] - base[j,m]). This is a min-max problem.

Actually, a key observation: if we define d[i,j,m] = corr[m] + base[i,m] - base[j,m], we want argmin_j max_m d[i,j,m].

For each i, we can compute this as:
- For each j: val[j] = max_m (corr[m] + base[i,m] - base[j,m])
- Then pick j with minimum val[j]

Using numpy: for fixed i, we can compute:
temp = corr[None,:] + base[i][None,:] - base[ones]  # shape (n_ones, 2n-1)
vals = temp.max(axis=1)
best_j = ones[argmin(vals)]

This is O(n_ones * (2n-1)) per i, and O(n_zeros * n_ones * (2n-1)) total.
For n=400: 200 * 200 * 799 ≈ 32M operations per sweep. That's fast!

def project_feasible(a, n):

def polish_continuous(h, n, deadline):
    """Polish using L-BFGS-B with log-sum-exp."""
    beta = 5000.0
    dx = 2.0 / float(n)
    
    def obj(x):
        hv = np.clip(x, 0.0, 1.0)
        v = 1.0 - hv
        c = np.correlate(hv, v, mode="full") * dx
        c = np.maximum(c, 0.0)
        m = float(c.max())
        y = beta * (c - m)
        e = np.exp(np.minimum(y, 0.0))
        s = float(e.sum())
        if not np.isfinite(s) or s <= 0:
            return 1e100, np.zeros_like(hv)
        F = m + np.log(s) / beta
        # Gradient
        P = e / s
        R = P[::-1]
        A = np.convolve(R, v, mode="full")[n-1:2*n-1]
        B = np.convolve(P, hv, mode="full")[n-1:2*n-1]
        g = dx * (A - B)
        # Add constraint penalty
        dev = float(hv.sum() - 0.5 * n)
        pen = 1e4
        F += 0.5 * pen * dev * dev
        g = g + pen * dev
        return F, g
    
    bounds = [(0.0, 1.0)] * n
    options = {"maxiter": 50000, "maxls": 30, "ftol": 1e-14, "gtol": 1e-10}
    
    try:
        res = minimize(obj, h, method="L-BFGS-B", jac=True,
                      bounds=bounds, callback=stop_callback, options=options)
        x = res.x if (res is not None and hasattr(res, "x")) else h
    except Exception:
        x = h
    
    # Binary project
    return top_n_binary(x, n)

def stop_callback(*args):

def compute_c5(h, n):
    dx = 2.0 / float(n)
    c = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(c) * dx)

def top_n_binary(h, n):
    h = np.asarray(h, dtype=float).ravel()
    target = n // 2
    hb = np.zeros(n)
    if target > 0:
        idx = np.argsort(-h)[:target]
        hb[idx] = 1.0
    return hb

def compute_base(h, n):
    l = np.arange(-(n-1), n, dtype=int)
    base = np.zeros((n, 2*n-1), dtype=float)

        mf = (f >= 0) & (f < n)
        base[p, mf] = 1.0 - h[f[mf]]
        b = p - l
        mb = (b >= 0) & (b < n)
        base[p, mb] -= h[b[mb]]
    return base
