One idea: **lag trading**. If lag k1 is the worst, try to reduce it while not increasing other lags too much. This is essentially what the active-set gradient does, but we can be more selective.

Another idea: **second-order information**. The Hessian of the correlation with respect to h is sparse and has a specific structure. We could use a Gauss-Newton or quasi-Newton step focused on the active lags.

Actually, for the active set of T lags, the problem is:
minimize max(c_{k1}, ..., c_{kT})
subject to 0 <= h <= 1, sum(h) = n/2

This is equivalent to:
minimize t
subject to c_ki <= t for i=1,...,T
0 <= h <= 1, sum(h) = n/2

Each c_ki is linear in h! So this is a linear program! We can solve it with cvxpy!

Wait, is c_k linear in h? Let's check:
c_k = sum_i h[i] * (1 - h[i+k]) for k > 0

This is NOT linear in h because of the h[i] * h[i+k] term. So it's not a LP.

But if we fix the "other" values and only vary a few, it could be approximated as linear. That's not very helpful.

Let me think differently. The correlation c_k = sum_i h[i](1-h[i+k]) = sum_i h[i] - sum_i h[i]h[i+k].

For the zero lag: c_0 = sum h[i] - sum h[i]² = n/2 - sum h[i]² (since sum h = n/2).

So minimizing c_0 is equivalent to maximizing sum h[i]², which means making h more binary.

For lag k: c_k = sum_{i=0}^{n-1-k} h[i](1-h[i+k])

This is a quadratic function of h. The overall problem is a nonconvex quadratic optimization (minimize max of quadratic functions subject to box and equality constraints).

    c = compute_c5_vec(x, n)
    logits = alpha * c
    mx = logits.max()
    val = mx / alpha + np.log(np.sum(np.exp(logits - mx))) / alpha
    val += mu * (x.sum() - n / 2.0) ** 2
    return float(val)

def _pen_grad(x, n, alpha, mu):
    g = smooth_grad(x, n, alpha)
    g += 2.0 * mu * (x.sum() - n / 2.0)
    return g

    return float(x.sum() - n / 2.0)

    return np.ones(len(x))

def lbfgs_phase(h, n, deadline, maxiter=300):
    best_c = compute_c5(h, n)
    h = project_lm(h, n)
    bounds = [(0.0, 1.0)] * n
    alphas = [50, 200, 1000, 5000, 20000, 100000, 500000]
    mus = [100, 500, 2000, 5000, 10000, 50000, 200000]
    for i, (alpha, mu) in enumerate(zip(alphas, mus)):
        if time.time() > deadline - 2:
            break
        try:
            res = minimize(_pen_obj, h, jac=_pen_grad, args=(n, alpha, mu),
                          method='L-BFGS-B', bounds=bounds,
