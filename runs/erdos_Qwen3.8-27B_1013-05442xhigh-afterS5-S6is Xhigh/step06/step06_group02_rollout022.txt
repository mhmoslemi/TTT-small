= h[i] * A_k + B_k - h[i] * B_k
= h[i] * (A_k - B_k) + B_k

This is LINEAR in h[i]! (Not quadratic, because h[i] only appears once in each term.)

Wait, that's for a fixed k. So for the max:
max_k (h[i] * (A_k - B_k) + B_k)

This is the max of linear functions of h[i], which is a convex piecewise-linear function. The minimum of a convex function on [0,1] subject to the sum constraint is at a point where the slopes change sign, or at a boundary.

But we also have the sum constraint: sum(h) = n/2. So changing h[i] from its current value to a new value changes the sum. We need to compensate by changing some other coordinate.

This suggests a **pair coordinate descent**: pick a pair (i, j), and optimize h[i] and h[j] jointly while keeping the sum constraint satisfied (h[i] + h[j] = constant).

For a fixed pair (i,j) with h[i] + h[j] = s (constant):
max_k (h[i]*α_{k,i} + h[j]*α_{k,j} + β_k)
= max_k (h[i]*α_{k,i} + (s-h[i])*α_{k,j} + β_k)
= max_k (h[i]*(α_{k,i} - α_{k,j}) + s*α_{k,j} + β_k)

This is still max of linear functions of h[i], so convex piecewise-linear. Minimum is where the slope changes sign or at the boundary.

This gives an exact coordinate descent step that should converge (though possibly slowly to a local optimum).

But the issue is that this is a local method and might get stuck. We need to combine it with global exploration.

```python
def grad_c5_fft(h, n, alpha):
    c = compute_c5_vec(h, n)
    m = c.max()
    sh = alpha * (c - m)
    mx = sh.max()
    if mx > 500:
        e = np.exp(sh - mx)
        w = e / e.sum()
    else:
        w = np.exp(sh - mx)
        w /= w.sum()
    
    dx = 2.0 / n
    wp = w[n-1:]       # weights for shifts 0, 1, ..., n-1
    wn = w[n-1::-1][:n]  # weights for shifts 0, -1, ..., -(n-1)
    # Actually wn[m] = w[n-1-m] for m=0,...,n-1
    wn = np.array([w[n-1-m] for m in range(n)])
    
    one_minus_h = 1.0 - h
    
    # Compute the 4 terms using FFT
    N = 2 * n
    H = np.fft.fft(h, N)
    OH = np.fft.fft(one_minus_h, N)
    
    # conv_wp_h[j] = sum_{i=0}^{j} wp[i]*(h)[j-i]
    WPH = np.fft.ifft(np.fft.fft(wp, N) * H)[0:n]
    
    # conv_wn_1h[j] = sum_{i=0}^{j} wn[i]*(1-h)[j-i]
    WN1H = np.fft.ifft(np.fft.fft(wn, N) * OH)[0:n]
    
    # cc_wp_1h[j] = sum_{t=0}^{n-1-j} wp[t]*(1-h)[j+t]
    # = ifft(fft(wp_rev, N) * OH)[n-1]
    WP_rev = wp[::-1]
    CC_WP_1H = np.fft.ifft(np.fft.fft(WP_rev, N) * OH)[n-1:2*n-1]
    
    # cc_wn_h[j] = sum_{t=0}^{n-1-j} wn[t]*h[j+t]
    WN_rev = wn[::-1]
    CC_WN_H = np.fft.ifft(np.fft.fft(WN_rev, N) * H)[n-1:2*n-1]
    
    wn0 = wn[0]
    grad = dx * (-wn0 + 2*wn0*h + CC_WP_1H - WPH + WN1H - CC_WN_H)
    
    return np.real(grad)
```

This should be O(n log n) per gradient evaluation instead of O(n²)!

For n=300, that's a huge speedup. The FFT of size 600 takes about 600*log2(600) ≈ 600*10 = 6000 operations, compared to 300*300 = 90000 for the direct method. About 15x speedup.

1. **Phase 1**: Coarse optimization with L-BFGS-B using the fast gradient
2. **Phase 2**: Fine optimization with SLSQP or more L-BFGS iterations
3. **Phase 3**: Pair coordinate descent for exact local refinement
4. **Phase 4**: Random restarts to escape local optima

For the pair coordinate descent, I can use the insight that for a fixed pair (i,j) with h[i]+h[j]=s, the objective as a function of h[i] is convex piecewise-linear. The minimum occurs where the derivative changes sign.

The derivative of the soft-max objective with respect to h[i] (with h[j] = s - h[i]) is:
d/dh[i] [smooth_max(c(h))] = sum_k w_k * (∂c_k/∂h[i] - ∂c_k/∂h[j])

Since each ∂c_k/∂h[i] is linear in h[i] (and h[j] = s - h[i] is also linear), the derivative is piecewise... actually it's not piecewise-linear in h[i] because w_k depends on h (through the soft-max weights). But if I freeze the weights (which is a common approximation), then it's linear and I can solve exactly.

Actually, for the exact (non-smooth) max, if I know which k is active (gives the max), then the objective is linear in h[i] (as I showed earlier), and the minimum of a linear function on an interval is at an endpoint. So for the exact max, the optimal h[i] for a given pair is either at the boundary or where the active set changes.

For the soft-max, it's smooth, so I can just use the gradient and do a line search.

```python
import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h, n):
    dx = 2.0 / n
    return float(np.max(np.correlate(h, 1 - h, mode='full')) * dx)

def compute_c5_vec(h, n):
    dx = 2.0 / n
    return np.correlate(h, 1 - h, mode='full') * dx

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h.copy(), 0.0, 1.0)
    for _ in range(200):
        diff = target - h.sum()
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            room = 1.0 - h
            tot = room.sum()
            if tot < 1e-14:
                break
            h += (diff / tot) * room
        else:
            tot = h.sum()
            if tot < 1e-14:
                break
            h += (diff / tot) * h
    return np.clip(h, 0.0, 1.0)

def grad_c5_fft(h, n, alpha):
    """O(n log n) gradient of smooth max C5."""
    c = compute_c5_vec(h, n)
    m = c.max()
    sh = alpha * (c - m)
    mx = sh.max()
    if mx > 500:
        e = np.exp(sh - mx)
        w = e / e.sum()
    else:
        w = np.exp(sh - mx)
        w /= w.sum()
    
    dx = 2.0 / n
    wp = w[n-1:]  # length n: weights for shifts 0, 1, ..., n-1
    wn = w[:n][::-1]  # length n: weights for shifts 0, -1, ..., -(n-1)
    # wn[m] = w[n-1-m]
    
    one_minus_h = 1.0 - h
    N = 2 * n
    
    H = np.fft.rfft(h, N)
    OH = np.fft.rfft(one_minus_h, N)
    
    # conv_wp_h[j] = sum_{i=0}^{j} wp[i]*h[j-i] for j=0,...,n-1
    WPH = np.fft.irfft(np.fft.rfft(wp, N) * H)[0:n]
    
    # conv_wn_1h[j] = sum_{i=0}^{j} wn[i]*(1-h)[j-i] for j=0,...,n-1
    WN1H = np.fft.irfft(np.fft.rfft(wn, N) * OH)[0:n]
    
    # cc_wp_1h[j] = sum_{t=0}^{n-1-j} wp[t]*(1-h)[j+t]
    CC_WP_1H = np.fft.irfft(np.fft.rfft(wp[::-1], N) * OH)[n-1:2*n-1]
    
    # cc_wn_h[j] = sum_{t=0}^{n-1-j} wn[t]*h[j+t]
    CC_WN_H = np.fft.irfft(np.fft.rfft(wn[::-1], N) * H)[n-1:2*n-1]
    
    wn0 = wn[0]
    grad = dx * (-wn0 + 2.0*wn0*h + CC_WP_1H - WPH + WN1H - CC_WN_H)
    
    return np.real(grad)

def smooth_max_obj(x, n, alpha, mu):
    """Penalized smooth max objective."""
    c = compute_c5_vec(x, n)
    m = c.max()
    sh = alpha * (c - m)
    mx = sh.max()
    if mx > 500:
        val = m + (mx + np.log(np.sum(np.exp(sh - mx)))) / alpha
    else:
        val = m + np.log(np.sum(np.exp(sh - mx))) / alpha
    val += mu * (x.sum() - n / 2.0) ** 2
    return float(val)

def smooth_max_grad(x, n, alpha, mu):
    g = grad_c5_fft(x, n, alpha)
    g += 2.0 * mu * (x.sum() - n / 2.0)
    return g

def lbfgs_optimize(h, n, deadline, max_iters=500, alpha=50000, mu=1.0):
    """L-BFGS-B optimization with fast gradient."""
    bounds = [(0.0, 1.0)] * n
    h = project_feasible(h, n)
    best_c = compute_c5(h, n)
    t_start = time.time()
    
    try:
        res = minimize(smooth_max_obj, h, jac=smooth_max_grad,
                      args=(n, alpha, mu), method='L-BFGS-B',
                      bounds=bounds,
                      options={'maxiter': max_iters, 'ftol': 1e-16,
                               'gtol': 1e-12, 'maxfun': max_iters * 5,
                               'maxls': 30})
        h_new = project_feasible(res.x, n)
        c_new = compute_c5(h_new, n)
        if c_new < best_c:
            best_c = c_new
            h = h_new
    except:
        pass
    
    return h, best_c
```
