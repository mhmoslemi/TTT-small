from scipy.optimize import minimize
import time

def compute_c5(h, n):
    dx = 2.0 / n
    return float(np.max(np.correlate(h, 1.0 - h, mode='full')) * dx)

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h.copy(), 0.0, 1.0)
    for _ in range(200):
        diff = target - h.sum()
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            room = 1.0 - h
            tot = room.sum()
            if tot < 1e-15:

            h += (diff / tot) * room
        else:
            tot = h.sum()
            if tot < 1e-15:

- This is sum_t a[t] * v[t+a-n] where n = len(v)-1, for the 'valid' case
- For 'full', it's the untruncated cross-correlation

More precisely, for arrays a of length na and v of length nv:
result has length na + nv - 1
result[k] = sum_{t} a[t+k] * v[t] for k = -(nv-1), ..., na-1 (shifted to 0, ..., na+nv-2)

So: result[k + (nv-1)] = sum_t a[t+k] * v[t] for valid t (0 ≤ t < nv and 0 ≤ t+k < na)

In our case: a = h (length n), v = 1-h (length n).
result[k + (n-1)] = sum_t h[t+k] * (1-h[t]) for valid t (0 ≤ t < n and 0 ≤ t+k < n)

For k = -l (l > 0): result[n-1-l] = sum_t h[t-l] * (1-h[t]) for t = l, ..., n-1
= sum_{i=0}^{n-1-l} h[i] * (1-h[i+l])  [substituting i = t-l]

For k = l (l > 0): result[n-1+l] = sum_t h[t+l] * (1-h[t]) for t = 0, ..., n-1-l
= sum_{t=0}^{n-1-l} h[t+l] * (1-h[t])

So:
c[n-1+l] = sum_{t=0}^{n-1-l} h[t+l]*(1-h[t])  ... (A)
c[n-1-l] = sum_{t=0}^{n-1-l} h[t]*(1-h[t+l])  ... (B)

Note (A) and (B) are different! (A) = sum h[t+l] - sum h[t+l]*h[t], (B) = sum h[t] - sum h[t]*h[t+l].
The difference (A)-(B) = sum_{t=0}^{n-1-l} (h[t+l] - h[t])

So in general c[n-1+l] ≠ c[n-1-l].
