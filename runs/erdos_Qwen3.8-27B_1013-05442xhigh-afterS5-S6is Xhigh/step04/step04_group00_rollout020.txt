So: ∂g_k/∂h[i] = dx * (1-h[i-k]) * [0 <= i-k < n and i < n] - dx * h[i+k] * [0 <= i < n-k]
             = dx * (1-h[i-k]) * [k <= i < n] - dx * h[i+k] * [0 <= i < n-k]  (for k >= 0)

For k < 0, let k' = -k > 0:
c[k] = sum_n h[n-k']*(1-h[n]) (for valid n, i.e., n >= k')
∂c[k]/∂h[i] = contribution from h[i] as h[n-k']: n-k'=i, n=i+k', valid if i+k' < n, so i < n-k'

```python
    gm = g.max()

    obj = log_sum / alpha  # This is (1/alpha)*log(sum exp(alpha*g)) = (1/alpha)*log_sum + gm... 
    # Actually: (1/alpha) * log(sum exp(alpha * g_k)) = (1/alpha) * (alpha*gm + log(sum exp(alpha*(g_k - gm))))
    # = gm + (1/alpha) * log(sum exp(alpha*(g_k - gm)))

    # where p_k = exp(alpha * g_k) / sum exp(alpha * g_k) = exp(alpha*(g_k - gm)) / sum exp(alpha*(g_k-gm))

        #   ∂c/∂h[j] = (1-h[j-k]) if k <= j <= n-1 (from h[j] = h[i+k] with i=j-k)
        #            - h[j+k] if 0 <= j <= n-1-k (from (1-h[j]) with i=j)
```

sum_k p_k * (1-h[j-k]) * [j >= k] = sum_{k=0}^{j} p_k * (1-h[j-k]) = sum_{i=0}^{j} p_{j-i} * (1-h[i])

These are both convolutions (or cross-correlations) that can be computed in O(n log n) using FFT!

Let me reformulate:
Let p_pos = p[n-1:] (the part for k >= 0, i.e., shifts 0, 1, ..., n-1)
Let p_neg = p[:n-1] (the part for k < 0, i.e., shifts -(n-1), ..., -1)

Wait, the indexing is: m goes from 0 to 2n-2, and k = m - (n-1).
So m = n-1 corresponds to k = 0.
m = n-1+i corresponds to k = i (for i = 0, 1, ..., n-1).
m = n-1-i corresponds to k = -i (for i = 1, 2, ..., n-1).

So p_pos[i] = p[n-1+i] for i = 0, ..., n-1 (shifts 0 to n-1)
p_neg[i] = p[n-1-i] for i = 1, ..., n-1 (shifts -1 to -(n-1))

A[j] = sum_{k=0}^{j} p_pos[k] * (1-h[j-k])  [this is a convolution of p_pos and (1-h)]

These can all be computed using FFT-based convolution.

```python
def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h, 0.0, 1.0)
    for _ in range(100):
        diff = target - h.sum()
        if abs(diff) < 1e-14:
            break
        if diff > 0:

            s = room.sum()
            if s < 1e-14:

            h = h + diff / s * room

            if s < 1e-14:
                break
            h = h + diff / s * h
    return np.clip(h, 0.0, 1.0)

    def obj(x):
        return smooth_objective(x, n, alpha)
    
    def grad(x):
```

Let me implement a smarter binary search:
1. For the current binary solution, compute all g_k values
2. Identify the "bottleneck" shifts (those with g_k near the max)
3. For each bottleneck shift k, find the best swap (i, j) that reduces g_k the most
4. Check if the swap also doesn't increase other g_k above the current max
5. Apply the best swap

This is O(n^2) per iteration (n choices for i × n choices for j), but we can prune: for a given bottleneck shift k, the best swap is determined by the formula above, so we can find it in O(n) for each k.

```python
            #   change: -h[j+k] (if j < n-k)
            # Change at position i (as the "shifted" position, i.e., in h[i+k] where the base is i-k):
            #   was: 1*(1-h[i-k]) (if i-k >= 0, i.e., i >= k)
            #   now: 0*(1-h[i-k]) = 0
            #   change: -(1-h[i-k]) = h[i-k]-1 (if i >= k)
            # Change at position j (as shifted):
            #   was: 0*(1-h[j-k]) = 0 (if j >= k)
            #   now: 1*(1-h[j-k]) = 1-h[j-k] (if j >= k)
            #   change: +(1-h[j-k]) (if j >= k)
            
            # Total: Δg_k = h[i+k]*[i<n-k] - h[j+k]*[j<n-k] + (h[i-k]-1)*[i>=k] + (1-h[j-k])*[j>=k]
            
            # For binary h:
            # If i < n-k: h[i+k] is 0 or 1
            # If i >= k: h[i-k] is 0 or 1, so h[i-k]-1 is -1 or 0
            # If j < n-k: h[j+k] is 0 or 1
            # If j >= k: 1-h[j-k] is 0 or 1
            
            # Simplified for binary:
            # Δg_k = h[i+k]*[i<n-k] - h[j+k]*[j<n-k] - [i>=k and h[i-k]==0] + [j>=k and h[j-k]==0]
            # (since h[i-k]-1 = -1 if h[i-k]=0, and 0 if h[i-k]=1)
            # (and 1-h[j-k] = 1 if h[j-k]=0, and 0 if h[j-k]=1)
            
            # So Δg_k = h[i+k]*[i<n-k] - h[j+k]*[j<n-k] - [i>=k, h[i-k]=0] + [j>=k, h[j-k]=0]
            
            # To minimize this (make it most negative), we want:
            # - h[i+k]=1 and i<n-k (contributes -1 net from the -1 at i>=k part... wait)
            
            # Let me just enumerate. For each i in ones, j in zeros:
            # Compute Δg_k. But this is O(|ones|*|zeros|) = O(n^2/4) per k.
            # For n=250, that's ~15,600 evaluations per k. With ~10 bottleneck k's, that's 156,000.
            # Each evaluation is O(1). So total is ~156,000 operations per iteration. That's fine.
            
            # But let's be smarter. For fixed k, Δg_k(i, j) = f(i) + g(j) where:
            # f(i) = h[i+k]*[i<n-k] + (h[i-k]-1)*[i>=k]  [terms depending on i]
            # g(j) = -h[j+k]*[j<n-k] + (1-h[j-k])*[j>=k]  [terms depending on j]
            
            # So the best (i, j) pair minimizes f(i) + g(j), which means:
            # pick i that minimizes f(i) and j that minimizes g(j) independently!
            
            # f(i) for i in ones:
            #   = h[i+k]*[i<n-k] + (h[i-k]-1)*[i>=k]
            #   For binary h[i]=1:
            #   If i < n-k: h[i+k] is 0 or 1
            #   If i >= k: (h[i-k]-1) is -1 or 0
            #   So f(i) ∈ {0, 1} + {-1, 0} = {-1, 0, 1}
            
            # g(j) for j in zeros:
            #   = -h[j+k]*[j<n-k] + (1-h[j-k])*[j>=k]
            #   For binary h[j]=0:
            #   If j < n-k: -h[j+k] is 0 or -1
            #   If j >= k: (1-h[j-k]) is 0 or 1
            #   So g(j) ∈ {0, -1} + {0, 1} = {-1, 0, 1}
            
            # To minimize f(i) + g(j), pick i with min f(i) and j with min g(j).
            
            # Let's compute:
            best_f = float('inf')
            best_i = -1
            for i in ones:
                fi = 0
                if i < n-k:
                    fi += h[i+k]
                if i >= k:
                    fi += h[i-k] - 1
                if fi < best_f:
                    best_f = fi
                    best_i = i
            
            best_g = float('inf')
            best_j = -1
            for j in zeros:
                gj = 0
                if j < n-k:
                    gj -= h[j+k]
                if j >= k:
                    gj += 1 - h[j-k]
                if gj < best_g:
                    best_g = gj
                    best_j = j
            
            if best_i >= 0 and best_j >= 0:
                delta_k = best_f + best_g
                if delta_k < 0:
                    # This swap reduces g_k. Check if it breaks any other constraint.
                    # Apply the swap temporarily
                    h[best_i] = 0
                    h[best_j] = 1
                    ones.discard(best_i)
                    zeros.discard(best_j)
                    ones.add(best_j)
                    zeros.add(best_i)
                    
                    # Check new C5
                    g_new = np.correlate(h, 1-h, 'full') * (2.0/n)
                    new_max = g_new.max()
                    
                    if new_max < m + 1e-15:
                        # Accept (new max is not worse than old max)
                        if new_max < best_c:
                            best_c = new_max
                        improved = True
                        break
                    else:
                        # Revert
                        h[best_i] = 1
                        h[best_j] = 0
                        ones.discard(best_j)
                        zeros.discard(best_i)
                        ones.add(best_i)
                        zeros.add(best_j)
        
        if not improved:
            break
    
    return h, best_c
```

For k < 0 (let kp = -k > 0):

After swap h[i]:1→0, h[j]:0→1:

- h[j] appears in (1-h[.]) when index is j:
  - was: h[j-kp]*(1-0) = h[j-kp] → now: h[j-kp]*(1-1) = 0. Change: -h[j-kp] (if j >= kp)
- h[i] appears in h[. - kp] when i-kp is the index... wait, h[i] = h[(i+kp)-kp], so it's the "shifted" value at base index i+kp:

g(j) = -h[j-kp]*[j>=kp] + (1-h[j+kp])*[j+kp<n]

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1-h, 'full')
    return float(np.max(c) * dx)

def compute_all_g(h, n):
    dx = 2.0 / n
    return np.correlate(h, 1-h, 'full') * dx

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h, 0.0, 1.0)
    for _ in range(200):
        diff = target - h.sum()
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            room = 1.0 - h
            s = room.sum()
            if s < 1e-14:
                break
            h = h + diff / s * room
        else:
            s = h.sum()
            if s < 1e-14:
                break
            h = h + diff / s * h
    return np.clip(h, 0.0, 1.0)

def smooth_obj(x, n, alpha):
    g = compute_all_g(x, n)
    gm = g.max()
    return gm + np.log(np.sum(np.exp(alpha * (g - gm)))) / alpha

def smooth_grad(x, n, alpha):
    dx = 2.0 / n
    g = compute_all_g(x, n)
    gm = g.max()
    p = np.exp(alpha * (g - gm))
    p /= p.sum()
    grad = np.zeros(n)
    for m in range(2 * n - 1):
        pm = p[m]
        if pm < 1e-14:
            continue
        k = m - (n - 1)
        if k >= 0:
            if k == 0:
                grad += pm * dx * (1.0 - 2.0 * x)
            else:
                grad[k:] += pm * dx * (1.0 - x[:n-k])
                grad[:n-k] += -pm * dx * x[k:]
        else:
            kp = -k
            grad[:n-kp] += pm * dx * (1.0 - x[kp:])
            grad[kp:] += -pm * dx * x[:n-kp]
    return grad

    """Trust-constr optimization of smoothed objective."""
    def obj(x):
        return smooth_obj(x, n, alpha)
    def jac(x):
        return smooth_grad(x, n, alpha)
    cons = [{'type': 'eq', 'fun': lambda x: x.sum() - n/2.0,
             'jac': lambda x: np.ones(n)}]
    bounds = [(0.0, 1.0)] * n
    try:
        res = minimize(obj, h, jac=jac, method='trust-constr',
                      bounds=bounds, constraints=cons,
                      options={'maxiter': maxiter, 'gtol': 1e-10, 'xtol': 1e-14})
        return project_feasible(res.x, n)
    except Exception:
        return project_feasible(h, n)
