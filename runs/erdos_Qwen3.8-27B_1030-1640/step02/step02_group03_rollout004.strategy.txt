1. Approach and rationale

1.1 Central idea

The task is a discrete finite-dimensional minimax problem with a box-simplex feasible set. The supplied parent is already a strong locally polished instance. The main failure mode in many simple descendants is that all phases continue to exploit the same smooth-minimax gradient/epigraph neighborhood, so the search sticks to one local basin near the parent score. This plan keeps a guaranteed parent fallback but introduces a substantive second search mechanism: directly explore the feasible manifold through global projected search and a target-violation loss, then use exact resampling and directed exact line-polishing to transfer a newly discovered global pattern into a small, valid, lower-scoring construction.

The primary new pipeline is:

1. Probabilistically generate many feasible inputs by mapping random low- and medium-dimensional artificial signals through the exact box-sum projection. This is a projected global stochastic search over the same evaluator feasible set, not a derivative descent from the parent.
2. Replace “drive the maximum value down” by “drive a violation term below a target” in one dedicated target-loss descent. This focuses computation on satisfying c_k ≤ t for a t below the current best, rather than only reducing the smoothed maximum.
3. Polish the best global candidates from high resolution down to smaller sizes using resampling, feasibility projection, and exact line moves that are independent of the previous tau/LSE or epigraph pipeline.
4. Accept only candidates that pass the authoritative evaluator and exact feasibility repair checks. The parent or any previously found better vector is retained as fallback.

This addresses two limitations of derivative-only methods:
- They can be trapped in one local basin of the nonsmooth max objective.
- With small number of discretization points the feasible manifold is a low-dimensional subset, so local contracted via one-dimensional active-gradient updates may miss a different coarse pattern that substantially reduces the worst shifted overlap.

1.2 Why this could improve the parent

The projected global stochastic search is not merely “optimizing harder”; it explores shapes that are not reachable by local active-set transformations from the parent. Random low-dimensional Fourier or piecewise blocks can pass through discontinuities of the projected objective, and exact projection moves every proposed point onto the feasible set. If one such projected signal gets below the current best, the final line/target refinement can amplify it below 0.38085. The target-loss descent attacks the inequality c_k ≤ t on many possible lags directly, which is closer to the end-task certification than minimizing a soft-max surrogate.

This is explicitly heuristic. It gives no global-optimality proof. However, every returned array is evaluated with the authoritative exact evaluator, and the fallback is parent validation. Thus an attempted new basin cannot hurt a returned bound as long as the candidate manager is implemented as specified.

1.3 Important limitations

- The projected global search objective is nonsmooth and highly degenerate because different raw vectors project to almost the same feasible point.
- The failure mode is excessive time; the plan therefore has explicit budgets, small dimensions for primary global exploration, and time-resculate skip conditions.
- The exact line-step and feasibility repair introduce no new approximation, but acceptance is still local along selected pair directions.
- The target-loss relies on a penalty; its intermediate vector has a sum violation. Only post-projection candidates are recorded or returned. If the penalty weight is too small or too large, some basins may be missed.

1.4 Interpretation of historical targets

The requested certified upper bound is `0.38085`; the “goal” value `0.3808` may be used as an internal target if available in kwargs or the literal default. It is not an external signal. 1. Approach and rationale

1.1 Central idea

The evaluator is a finite-dimensional nonsmooth minimax problem on a box-simplex feasible set. A derivative-only continuation from the supplied parent tends to remain in the same parent basin. This plan keeps the parent as a valid fallback but changes the primary search mechanism: first generate many feasible candidate patterns by mapping random low-dimensional or full-dimensional signal vectors through the exact box-sum projection, then attack the minimax condition with a target-violation feasible local solver and exact sum-preserving pair line minimizations. Finally, transfer promising information through a resolution pipeline and small-resolution repair.

The four substantive new components are:

1. Projected stochastic global search in the evaluator’s native coordinates: random raw vectors are fitted to the evaluator feasible set by `project_box_sum`, and the exact score is recorded directly. This samples qualitatively different shapes from smooth local basins and does not pass through an epsmax/commit/maximin solver.
2. A target-loss descent: optimize a smooth positive-part loss from `c_k - t` for `t` below the current bound under bounds and exact equality constraints. This directly tries to satisfy `c_k <= t`, which is closer to certification than making a log-sum-exp objective smaller. This local solver uses different constraint geometry and objective versus only minimizing the maximum smoothing family.
3. Exact pair line moves: for two coordinates `i,j`, move `h_i += delta`, `h_j -= delta`. This preserves `sum(h)` exactly before bounds. Minimize the authoritative score along the feasible interval for `delta`. These line moves couple coordinates through the equality constraint and are not reproducible by single-coordinate coordinate descent.
4. Resolution refinement: resample valid states to temporary larger lengths, precise local targeting, then repair to smaller arrays and accept only if the exact请先 `initial_h_values` plus fallback unchanged best used. This changes the formative search order and sizes.

This combination is still a constructive heuristic. Do not claim a global optimum. The important justification is that each attempted mechanism is evaluated using the exactly specified evaluator and cannot worsen the final rigorous bound because the manager always stores a lower exact-valid state.

1.2 Parent relationship

When `initial_h_values` exists, it is the first and most trustworthy state. validate it, repair it, score exactly, and place it in a manager before generating any random seed. every downstream transformation can only return a final result better than the parent, or return the exact parent. This protects against unstable random search or an internally failed solver state.

A missing or malformed initial state must not stop the run. A deterministic algorithmically generated feasible family is supplied as described below.
