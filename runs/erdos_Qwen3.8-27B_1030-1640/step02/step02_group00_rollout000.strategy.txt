1. Approach and rationale

The task is to find a feasible discrete step vector whose exact evaluated Erdős overlap constant  
\[
C_5(h)=\max_{r=0}^{2n-2} \left(\texttt{np.correlate}(h,1-h,\texttt{"full"})_r\cdot \frac{2}{n}\right)
\]
is below about 0.3808. The supplied parent construction is close to the current record 0.380931, so the bottleneck is not a broad global exploration but a very small nonconvex local improvement in a constrained feasible polytope.

The previous class of methods mainly used first-order Taylor minimax linearizations plus random restarts. Because the objective contains products \(h_i(1-h_j)\), Taylor cuts are only local approximations and can become blunt near fractionally constrained optima. The proposed method attacks this bottleneck with three complementary mechanisms, while judging every retained candidate using the exact evaluator:

1. Smoothed minimax with exact gradients.  
   Use a log-sum-exp surrogate that is close to the maximum correlation over all lags. The gradient is a softmax-weighted average of the true constraint gradients, which reveals which near-active and active overlaps restrain the solution. This replaces blunt nearest-maximum Taylor cuts with directions that balance several constraints simultaneously.

2. Exact one-dimensional feasibility-preserving line search.  
   For each candidate descent direction, generate candidates constrained to the feasible set by construction: direction components sum to zero and the step size is chosen so that all coordinates remain within \([0,1]\). The original object is evaluated exactly at sampled and refined positions on a segment. This extracts real improvements from smooth or random gradients without relying on the exactness of any surrogate.

3. Nonmonotone paired-coordinate / annealed improvement followed by monotone polish.  
   A stochastic ann.P囘olish loop permits small decreases in exact objective to escape nonconvex traps, using only exact evaluations. After the stochastic escape phase, a strictly monotone polish using exact line searches retains best candidates only when the exact evaluated constant improves.

A secondary but important repair stage uses dimension reduction / resolution adaptation: the parent or best candidate may be resampled to nearby dimensions and then polished there. Smaller dimensions are preferred when they tie the objective tolerance; larger dimensions are allowed as constructive enabling steps only if their exact objective is competitive.

This plan should not be claimed to guarantee a global optimum. The nonconvex objective makes global optimality difficult. The plan is designed to search several independent local basins and exact line directions and accept only verified improvements.

def exact_c5(h):
    h = np.asarray(h, dtype=float).reshape(-1)
    if h.size == 0:
        return float('inf')
    if not np.all(np.isfinite(h)):
        return float('inf')
    dx = 2.0 / float(h.size)

    if n == 0:
        return np.array([0.5, 0.5], dtype=float)

    if not np.all(np.isfinite(h)):
        h = np.where(np.isfinite(h), h, 0.5)

    h = np.clip(h, 0.0, 1.0)
    target = 0.5 * float(n)

    def clipped_sum(shift):
        z = h + shift
        z = np.clip(z, 0.0, 1.0)
        return float(np.sum(z))

    lo = -float(np.max(h)) - 1.0
    hi = 1.0 - float(np.min(h)) + 1.0
    if hi <= lo:
        hi = lo + 1.0

    a = lo
    b = hi
    for _ in range(100):
        m = 0.5 * (a + b)
        if clipped_sum(m) < target:
            a = m
        else:
            b = m
    t = 0.5 * (a + b)
    x = np.clip(h + t, 0.0, 1.0)

    def distribute_residual(r):
        x2 = x.copy()
        if abs(r) <= 1e-14:
            return x2
        if r > 0:
            for _ in range(200):
                gap = 1.0 - x2
                idxs = np.where(gap > 1e-14)[0]
                if idxs.size == 0:
                    break
                idx = int(idxs[0])
                delta = min(r, gap[idx])
                x2[idx] += delta
                r -= delta
                if r <= 1e-14:
                    break
        else:
            for _ in range(200):
                cap = x2.copy()
                idxs = np.where(cap > 1e-14)[0]
                if idxs.size == 0:
                    break
                idx = int(idxs[0])
                delta = min(-r, cap[idx])
                x2[idx] -= delta
                r += delta
                if r >= -1e-14:
                    break

        x2 = np.clip(x2, 0.0, 1.0)
        rr = target - float(np.sum(x2))
        if abs(rr) > 1e-12:
            interior = np.where((x2 > 1e-13) & (x2 < 1.0 - 1e-13))[0]
            if interior.size > 0:
                add = rr / float(interior.size)
                x2[interior] += add
                x2 = np.clip(x2, 0.0, 1.0)
        return np.clip(x2, 0.0, 1.0)

    r = target - float(np.sum(x))
    x = distribute_residual(r)

    if abs(float(np.sum(x)) - target) > 1e-10:
        interior = np.where((x > 1e-13) & (x < 1.0 - 1e-13))[0]
        if interior.size > 0:
            add = (target - float(np.sum(x))) / float(interior.size)
            x[interior] += add
            x = np.clip(x, 0.0, 1.0)

    return x


def resample_fallback(n, rng=None):
    n = int(max(4, n))
    if rng is None:
        rng = np.random.default_rng(0)
    period = rng.integers(2, max(3, min(n - 2, 16)))
    pattern = np.zeros(period, dtype=float)
    ones_needed = max(1, int(round(0.5 * period)))
    pattern[:ones_needed] = 1.0
    rng.shuffle(pattern)
    reps = int(math.ceil(n / float(period)))
    rep = np.tile(pattern, reps)[:n]
    denom = float(np.sum(rep))
    if denom <= 1e-12:
        rep = np.full(n, 0.5, dtype=float)
    return ensure_feasible(rep)


def resample_h(h_old, n_new, rng=None):
    h_old = np.asarray(h_old, dtype=float).reshape(-1)
    n_old = int(h_old.size)
    n_new = int(max(4, n_new))
    if n_old == 0 or not np.all(np.isfinite(h_old)):
        return resample_fallback(n_new, rng=rng)
    if n_old == n_new:
        return ensure_feasible(h_old)

    dx_old = 2.0 / float(n_old)
    dx_new = 2.0 / float(n_new)
    x_old = (np.arange(n_old, dtype=float) + 0.5) * dx_old
    x_new = (np.arange(n_new, dtype=float) + 0.5) * dx_new
    y = np.interp(x_new, x_old, h_old, left=h_old[0], right=h_old[-1])
    return ensure_feasible(y)

def is_valid_vector(h):
    h = np.asarray(h, dtype=float).reshape(-1)
    if h.size < 4:
        return False
    if not np.all(np.isfinite(h)):
        return False
    if not np.all(h >= -1e-11) or not np.all(h <= 1.0 + 1e-11):
        return False
    target = 0.5 * float(h.size)
    return abs(float(np.sum(h)) - target) < 2e-9


def try_update(best_tuple, h, c, n):
    h = np.asarray(h, dtype=float).reshape(-1)
    n = int(n)
    if best_tuple is None:
        return (h.copy(), float(c), n)
    bh, bc, bn = best_tuple
    if not np.isfinite(c):
        return best_tuple
    if c < bc - EPS:
        return (h.copy(), float(c), n)
    if abs(c - bc) <= 1e-8 and n < bn:
        return (h.copy(), float(c), n)
    return best_tuple


def direction_pool_from_smoothed(h, current_c, beta, top_count, rng):
    h = np.asarray(h, dtype=float).reshape(-1)
    n = int(h.size)
    if n < 4:
        return []

    dx = 2.0 / float(n)
    m_full = 2 * n - 1
    values = np.zeros(m_full, dtype=float)
    base_idx = n - 1

    for row in range(m_full):
        ell = row - base_idx
        if ell >= 0:
            m = n - ell
            if m > 0:
                p = h[:m]
                q = h[ell:]
                values[row] = dx * float(np.dot(p, 1.0 - q))
        else:
            s = -ell
            m = n - s
            if m > 0:
                p = h[s:]
                q = h[:m]
                values[row] = dx * float(np.dot(p, 1.0 - q))

    top = min(int(max(1, top_count)), m_full)
    if top > m_full:
        top = m_full
    order = np.argsort(values)
    idx_sel = order[-top:]
    vals_sel = values[idx_sel]
    v_max = float(np.max(vals_sel))

    exponents = beta * (vals_sel - v_max)
    weights = np.exp(exponents)
    total = float(np.sum(weights))
    if not np.isfinite(total) or total <= 0.0:
        weights = np.ones_like(vals_sel, dtype=float)
        total = float(np.sum(weights))

    if total <= 0.0:
        full_mean = np.mean(h) - 0.5
        if abs(float(full_mean)) > 1e-10:
            d = -full_mean * np.ones(n, dtype=float)
            d -= np.mean(d)
            denom = max(1e-12, float(np.max(np.abs(d))))
            return [d / denom]
        if rng is None:
            d = np.random.default_rng(0).normal(0.0, 1.0, n)
        else:
            d = rng.normal(0.0, 1.0, n)
        d -= np.mean(d)
        denom = max(1e-12, float(np.max(np.abs(d))))
        return [d / denom]

    weights = weights / total

    g_vec = np.zeros(n, dtype=float)

    def accumulate_row(row):
        ell = row - base_idx
        if ell >= 0:
            ln = n - ell
            if ln > 0:
                p = h[:ln]
                q = h[ell:]
                g_vec[:ln] += dx * weights[0] * (1.0 - q)
                g_vec[ell:] -= dx * weights[0] * p
        else:
            s = -ell
            ln = n - s
            if ln > 0:
                p = h[s:]
                q = h[:ln]
                g_vec[s:] += dx * weights[0] * (1.0 - q)
                g_vec[:ln] -= dx * weights[0] * p

    # Weighted gradient for top rows only; this is cheap in terms of sum per constraint.
    # For performance we only directional pool happens through approximation heavily.
    # We redistribute full accumulator if current row weight was scaled differently.
    # A safe proper weighted gradient is straightforward:
    for pos, row in enumerate(idx_sel):
        w = float(weights[pos])
        if w <= 1e-14:
            continue
        ell = int(row) - base_idx
        if ell >= 0:
            ln = n - ell
            if ln > 0:
                p = h[:ln]
                q = h[ell:]
                g_vec[:ln] += dx * w * (1.0 - q)
                g_vec[ell:] -= dx * w * p
        else:
            s = -ell
            ln = n - s
            if ln > 0:
                p = h[s:]
                q = h[:ln]
                g_vec[s:] += dx * w * (1.0 - q)
                g_vec[:ln] -= dx * w * p

    out = []

    if np.all(np.isfinite(g_vec)):
        d = -g_vec
        d -= np.mean(d)
        if float(np.linalg.norm(d)) > 1e-11:
            denom = max(1e-12, float(np.max(np.abs(d))))
            out.append(d / denom)

    def unit(t):
        t = np.asarray(t, dtype=float)
        t -= np.mean(t)
        a = float(np.max(np.abs(t)))
        if a <= 1e-12:
            return None
        return t / a

    # random reweighted near-top gradient
    if rng is not None and idx_sel.size >= 2:
        dead = False
        w2 = rng.random(idx_sel.length if hasattr(idx_sel, 'length') else len(idx_sel))
        w2 = w2.astype(float)
        if float(np.sum(w2)) > 1e-14:
            w2 = w2 / float(np.sum(w2))
            g2 = np.zeros(n, dtype=float)
            for pos, row in enumerate(idx_sel):
                ww = float(w2[pos])
                ell = int(row) - base_idx
                if ell >= 0:
                    ln = n - ell
                    if ln > 0:
                        p = h[:ln]
                        q = h[ell:]
                        g2[:ln] += dx * ww * (1.0 - q)
                        g2[ell:] -= dx * ww * p
                else:
                    s = -ell
                    ln = n - s
                    if ln > 0:
                        p = h[s:]
                        q = h[:ln]
                        g2[s:] += dx * ww * (1.0 - q)
                        g2[:ln] -= dx * ww * p
            if np.all(np.isfinite(g2)):
                d2 = -g2
                du = unit(d2)
                if du is not None:
                    out.append(du)

    # residual-based direction: choose residuals q=ceil internal rows
    order2 = np.argsort(values)
    q_len = min(len(order2), max(4, n - 1))
    idx2 = order2[-q_len:]

    residual = values[idx2] - current_c
    residual = np.maximum(residual, 0.0)
    if float(np.sum(residual)) <= 1e-13:
        residual = np.maximum(values[idx2] - (current_c - max(1e-4, 0.0008 * abs(current_c))), 0.0)
    if float(np.sum(residual)) > 1e-13:
        residual = residual / float(np.sum(residual))
        g3 = np.zeros(n, dtype=float)
        for pos, row in enumerate(idx2):
            ww = float(residual[pos])
            ell = int(row) - base_idx
            if ell >= 0:
                ln = n - ell
                if ln > 0:
                    p = h[:ln]
                    q = h[ell:]
                    g3[:ln] += dx * ww * (1.0 - q)
                    g3[ell:] -= dx * ww * p
            else:
                s = -ell
                ln = n - s
                if ln > 0:
                    p = h[s:]
                    q = h[:ln]
                    g3[s:] += dx * ww * (1.0 - q)
                    g3[:ln] -= dx * ww * p
        if np.all(np.isfinite(g3)):
            tu = unit(-g3)
            if tu is not None:
                out.append(tu)

    # coordinate-pair directions
    if n >= 2:
        try:
            source = np.where(h > 0.005)[0]
            sink = np.where(h < 0.995)[0]
        except Exception:
            source = np.arange(n)
            sink = np.arange(n)
        rngr = rng if rng is not None else np.random.default_rng(0)
        pair_count = min(12, max(6, n))
        for _ in range(pair_count):
            if source.size == 0 or sink.size == 0:
                break
            i = int(source[rngr.integers(0, len(source))])
            j = int(sink[rngr.integers(0, len(sink))])
            if i == j:
                continue
            d = np.zeros(n, dtype=float)
            d[i] = -1.0
            d[j] = 1.0
            out.append(d)

        c_count = min(8, max(4, n // 2))
        for _ in range(c_count):
            i = int(rngr.integers(0, n))
            j = int(rngr.integers(0, n))
            if i == j and n > 1:
                j = int((j + 1) % n)
            if i == j:
                continue
            d = np.zeros(n, dtype=float)
            d[i] = -1.0
            d[j] = 1.0
            out.append(d)

    # generic random feasible vectors
    for _ in range(2):
        if rng is None:
            rnd = np.random.default_rng(0)
        else:
            rnd = rng
        d = rnd.normal(0.0, 1.0, n)
        d -= np.mean(d)
        sort = np.sort(d)
        d = sort - np.mean(sort)
        denom = max(1e-12, float(np.max(np.abs(d))))
        out.append(d / denom)

    # uniform-to-mid and mirror directions
    try:
        xx = (np.arange(n, dtype=float) + 0.5) * dx
        d_perm = np.zeros(n, dtype=float)
        d_perm[:] = 0.75 * np.sin(math.pi * xx)
        d_perm -= np.mean(d_perm)
        denom = max(1e-12, float(np.max(np.abs(d_perm))))
        if denom > 1e-10:
            out.append(d_perm / denom)

        d_round = ensure_feasible(0.3 * (h + h[::-1]))
        d_r = d_round - float(np.mean(h[:1]))
        d_r = d_round - np.mean(d_round)
        dmm = max(1e-12, float(np.max(np.abs(d_r))))
        if dmm > 1e-10:
            out.append(d_r / dmm)
    except Exception:
        pass

    filtered = []
    seen = []
    for d in out:
        if d is None:
            continue
        d = np.asarray(d, dtype=float)
        if d.size != n or not np.all(np.isfinite(d)):
            continue

        work[k] += ww * (1.0 - h[ell:ell + ln])
                continue
            work[k - base_idx + ell] -= dx * ww * ell
        else:
            s = -ell
            ln = n - s
            if ln <= 0:
                continue
            work[k + 1:n?] += dx * ww * (1.0 - h[:n?])
