1. Approach and rationale

1.1. Core idea

The supplied parent has value about 0.381157, while the target is at most 0.3808. The gap is small, so the main bottleneck is not feasibility but the quality and diversity of local minima reached from a single starting point. Rather than relying on one deterministic local method, use a hybrid stochastic/gradient/polish pipeline that:

- preserves the parent as a rigorously feasible fallback;
- exploits a feasible structured subspace in which the mean-sum constraint is exact and requires no projection;
- globally probes that subspace with a controllable differential evolution search;
- polishes returned candidates using exact-objective evaluation plus gradient/LSE smoothing and active-set SLSQP when time remains;
- stores only candidates whose exact Evaluator metric is no worse than the current best, so a lower value or a tied smaller sequence can be returned.

The key structured subspace is the anti-complementary family:
h[i] + h[n-1-i] = 1 for paired indices, and h[center] = 1/2 for odd n. Every such sequence automatically satisfies 0 <= h <= 1 and sum(h) = n/2 up to floating-point error, because each paired sum is exactly 1. This makes global stochastic exploration much easier than optimizing arbitrary h variables under a hard sum constraint. It is a heuristic restriction, not a proof of optimality, and the program must always keep any original parent or unrestricted local candidate that is better.

1.2. Why this can improve the parent

The discrete objective is a nonsmooth max of bilinear functions. Deterministic cutting-plane or SLSQP methods can get stuck in a local minimum and may overfit the current active set. Differential evolution in a low-dimensional structured manifold can replace or reduce the active-lag constraint landscape. The anti-complementary parameterization removes projection artifacts and removes missing-half degrees of freedom when they are essentially paired. The addition of exact evaluation after every trial ensures the returned bound is an upper bound on the given Evaluator, not a surrogate lower estimate.

1.3. Limitations and explicitly untested hypotheses

- Anti-complementary symmetry may exclude an optimal non-symmetric solution. The final output always compares against the parent and against unrestricted feasible candidates generated by random perturbations and projection.
- Differential evolution is stochastic and not guaranteed to locate the global discrete optimum within 1100 seconds. It is used as a seeding/coloring mechanism for the later local phase.
- SLSQP on the epigraph receives inequalities that are not convex because overlap_components contains products h_i h_j. Therefore SLSQP can produce only local candidates and sometimes fail; only the exact Evaluator decides acceptance.
- Very large n increases evaluation time and memory of Jacobians. Use dynamic deadline-based skipping of large n and constraints.

All exact values must still be checked by calling np.correlate and max exactly as in the problem statement, because that is the authoritative scoring convention.
