1. Approach and rationale

The supplied parent construction has value about 0.380931 and is a local production-layer point on the 64-sample discretized feasible set. The goal is to generate exact feasible candidates below 0.3808, preferably at fewer samples. The discretized objective is nonconvex because constraints contain products h[i]*(1-h[j]); a direct convex solver cannot prove global optimality on the original objective. The proposed algorithm therefore never replaces the formal evaluation with a surrogate: every accepted solution, and in particular the vector returned, is checked by the true evaluator max(np.correlate(h, 1-h, full))*dx and the simultaneous constraints.

The primary new mechanism is a smoothed steepest-descent/line-search optimizer on the polytope h ∈ [0,1]n, sum(h)=n/2. The maximum over all full correlation lags is approximated by a stable log-sum-exp transform with adaptive temperature. The smooth gradient is projected back exactly into the polytope using a certified capped-simplex projection. Whenever the smoothed function identifies a feasible descent direction, a one-dimensional exact-objective search is performed on a feasible subvector in that direction, and only an exactly feasible candidate whose true C₅ improves is stored. This is an important algorithmic change from a pure linearization/LP routine because it reduces the non-smooth true maximum directly instead of relying on many local linear constraints.

Smoothing and projected gradients by themselves can stagnate in bad local minima. The search is therefore wrapped in an aggressive multi-resolution basin-hopping master loop. Starting from the supplied parent (converting feasibility properly when the resolution changes), the code runs the smoothed search at several resolutions, both smaller and larger than the parent. When local progress stops, exact candidates are perturbed by random, harmonic, or block-domain noise, projected to exact feasibility, and refined again. A simple population/priority list balances solvent dimensions with promising true scores. The supplied parent is retained as a robust fallback: if the stochastic search does not improve it, the parent or its projected resampling is returned. The plan does not claim that any candidate is a global discretized optimum; no global upper bound is claimed here, only an improved construction whose exact metric has been measured.

Main limitations/hypotheses:

- If the global optimum has a different topology, multi-start exact evaluation is needed to find it; the plan randomizes that repeatedly.
- The log-sum-exp gradient is an upper approximately linearization of the hard maximum. Some good local true-objective moves may be ignored; the exact line-search and stochastic escapes therefore compensate.
- The coordinate dimension and noise scale are discrete scanning choices, not theoretical constants; they are intentionally regime-adapted and multiple dimensions are scanned.
- The returned solution can have a slightly larger local smooth oscillator than the parent if the global best has not yet been improved, but final fallback ensures cannot worsen the parent value merely by resampling unless a true exact score is better.
