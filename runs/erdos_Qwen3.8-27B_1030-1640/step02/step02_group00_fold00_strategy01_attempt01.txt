1. Approach and rationale

The supplied parent construction is already very close to the current best bound, so the remaining gap is only about `1.3e-4`. A broad global-search restart is therefore not the main requirement: the search needs to exploit the known shape while changing the active overlap constraints one by one. The previous high-level programs emphasize solving full-dimensional first-order minimax-linearizations, Taylor trusted regions, LP steps, or random restarts. This plan uses a materially different primary mechanism: exact feasible rotations of ordered entries, driven by the ordered products that directly contribute to the largest overlaps and judged only by the exact evaluator.

The central primitive is:
- Choose an ordered pair or a structured mean-zero pattern `(a,b)`.
- Replace the vector by `h + t d`, where `d` is chosen so that the sum constraint is exactly zero along the movement and the interval in `t` is feasible by construction.
- Minimize the exact maximum-correlation objective along that one-dimensional feasible segment.

This is not a linearized step. It improves actual correlation values and accepts inaccuracies in gradient models by refining every proposed segment with exact correlation evaluations. The optimization path preserves feasibility without repeatedly performing a nontrivial quadratic projection because the chosen moves are mean-zero and the feasible interval in `t` is clipped only by pointwise bounds. At stages where general mean-zero directions are used, a joint bound-and-sum repair is applied, but only prior to exact evaluation, while the returned best point is always re-evaluated after a final feasibility projection.

The plan is organized as a multi-stage trustworthy local-search framework with three different search spaces:
1. Critical ordered-pair rotations, which target specific active overlap terms.
2. Structured global patterns such as median-vs-peak, smooth inverse-warp, and random balanced wave directions, which prevent “stuck” local optima not resolvable by individual pair moves.
3. Low-dimensional active-plane minimization, built from the latest improving directions, which can coordinate several constraints without solving a cut-based LP.

Dimension scanning remains part of the design because smaller dimensions are the more valuable output if they can match a competitive bound. The implementation also treats `initial_h_values` exclusively as a runtime input, never as a hard-coded table, and dynamically derives all dimensions from it.

The method is nonconvex and local. It does not claim global optimality; all retained values are exact evaluator values. If it fails to find an improvement under the upper bound, it returns the best exact verifier value produced by the parent and its safe variants.

2. Mathematical specification

2.1 Representation and exact objective

For a vector `h` of length `n`, use midpoint sampling on `[0, 2]`. The step size is

`dx = 2.0 / n`.

Feasible set:

`0 <= h[i] <= 1` for all `i`,
`sum_i h[i] = n/2`.

The exact problematic objective requested by the evaluator is

`C5(h) = max(np.correlate(h, 1 - h, mode="full") * dx)`.

This is the sole authoritative value. Internal surrogate or gradient-like scoring may only generate proposed moves; every stored candidate value must be recomputed by the above direct call.

Let

`v(h) = np.correlate(h, 1.0 - h, "full") * dx`,

so that `C5(h) = max(v(h))`. The objective contains all linear and negative shifts. Do not replace it by circular correlation, periodic autocorrelation, or `1 - min autocorrelation` without a boundary-preserving derivation. This plan evaluates the full vector each time it is needed.

2.2 Ordered-product orientation

For the phrase “critical pair,” use the following practical objective-relevant scoring. The evaluator produces correlations over shifted pairs; conceptually, each correlated pair is product-like. If direction

`d = e_b - e_a`

is used and `t` is increased, then coordinates `a` decreases and `b` increases. For a general product term `h[a] * (1 - h[b])`, its combined change is directed toward reducing that term. The algorithm therefore scores each ordered pair `(a,b)` using

`score(a,b) = F规范性文件 h[a] * (1 - h[b])`.

This is not an exact gradient of the maximum, so it is a heuristic scoring, not an exact linearization. It is a candidate generator only. Candidate validity comes from exact evaluation.

To pick near-maximum pairs, weight the score by a soft proximity to the actual top overlaps:

- Compute `c = v(h)` and `C = max(c)`.
- For row residual `res = C - c[m]`, define a row weight
  `w[m] = exp(BETA * (c[m] - C))` with `BETA = 3000` by default.
  For numerical safety use the exponent shifted by the maximum row, which is exactly `c[m] - C`.
- Sort or corpus active rows by `w[m]` or by taking `top_rows = argsort(c)[-topact]` with `topact = 6..12`.

A pair score matrix is mathematically specified as follows:

Initialize `S` as `n x n` zero matrix.

For each selected active row index `m`, with `k = m - n + 1`:

- If `k >= 0`, terms conventionally correspond to directions assigning positive contribution from `i` and negative contribution from `j=i+k`. To reduce these terms, add
  `w[m] * h[i] * (1-h[i+k])` to `S[i, i+k]` for all valid `i`.
- If `k < 0`, use `s = -k`, add
  `w[m] * h[i+s] * (1-h[i])` to `S[i+s, i]`.
  - The chosen movement pattern is increase the pair second index and decrease the pair first index.

Then select ordered pairs with zero weights. This inconsistent index reversal relative to `np.correlate` is acceptable because it is only a heuristic for choosing ordered-pair movements; acceptance is invariant under exact evaluator comparison. The implementation must nevertheless evaluate final `C5` with `np.correlate`.

Overflow handling: if `cvec[m] - C5` is less than `-44`, its exponential underflows to zero safely; no scaling is needed beyond subtracting `C5`.

2.3 One-dimensional feasible lines

A direction vector `d` satisfies the sum-preserving property when

`sum_i d[i] = 0`.

For every base feasible `h`, the feasible interval for scalar `t` is

For each index `i`:

If `d[i] > 0`:
`-h[i] / d[i] <= t <= (1 - h[i]) / d[i]`.

If `d[i] < 0`:
`(1 - h[i]) / d[i] <= t <= -h[i] / d[i]`.

If `d[i] == 0`, no bound condition is needed.

The interval endpoint definitions give

`t_lower = max(-h/d for d > 0 or (1-h)/d for d < 0)`,
`t_upper = min((1-h)/d for d > 0 or -h/d for d < 0)`.

A valid line exists if `t_upper > t_lower` and `t=0` lies in its interval. Rounding may make this technical expression fail when direction normalization leaves a negligible mean; in that case, clip a slight widening by `1e-12`. At endpoints, coordinates are at bounds.

The exact path objective is

`phi(t) = max(np.correlate(h + t d, 1 - h - t d, "full") * dx)`.

To minimize `phi`, use exact evaluations only:
1. Evaluate `phi` at `t=0` as the baseline.
2. Evaluate a coarse grid of at most 12–18 points on `[t_lower, t_upper]`, always including both endpoints and a few points near `t=0`.
3. Let `t_best` be the minimum exact value seen. If the best lies strictly interior, take bracket endpoints defined by adjacent sample nodes; if it lies exactly at an endpoint, breadth around that endpoint using a small segment into the interval.
4. Repeat four refinement grids inside the current best bracket, each time choosing candidate grid including 9–13 points. Avoid golden-ternary methods due to multiple local piecewise maxima.
5. Retain only vectors such as `h_try = h + t_best d` whose exact `C5` is strictly smaller than the prior exact value by `EPS_IMP = 1e-10` or, during tolerance-staging acceptance mode, no worse than `current + epsilon_nonmono` as described below.

Because every coordinate is evaluated after normalizing `d` by its max absolute component, step-size magnitude is comparable across directions. For pair directions, the raw direction `e_b - e_a` or `e_a-e_b` is exactly sum-zero and often stable to numerical error; therefore, use it before any general mean projection.
