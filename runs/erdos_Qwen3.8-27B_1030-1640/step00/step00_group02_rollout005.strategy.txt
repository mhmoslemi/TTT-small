1. Approach and rationale

Central idea:
Construct feasible vectors `h` of a few dozen samples, improve them with local nonlinear programming, and accept only candidates evaluated by the exact discrete objective. The main exact formulation is an epigraph minimization:
    minimize s subject to s >= overlap_m(h),  0 <= h_i <= 1,  sum_i h_i = n/2.
This linearizes the outer max only on an enlarged variable `s`; the overlap constraints remain quadratic and the feasible set is nonconvex. Then a secondary smooth maximization based on log-sum-exp of overlap values is used for fast exploration and as a fallback. Both formulations are wrapped by exact evaluations with the task metric. The search is multi-start and multi-resolution; all candidate dimensions become explicit return values. This addresses the important bottleneck: the optimizer cannot be allowed to optimize a surrogate that fails to exactly reproduce `max(np.correlate(h, 1-h, "full"))*dx`, including both lag directions and finite-overlap boundary terms.

Why this may improve the supplied parent:
The supplied `initial_h_values` is a strong feasible local geometry, but a small numerical gap to the target is likely masked by local variables, active constraints, resolution choices, or asymmetry. An exact epigraph NLP can push down maxima that are active at the parent. Log-sum-exp starts and random/reconstructed profiles widen exploration without permanently violating feasibility. Symmetrization of feasible parent/campaign candidates is an independent cheap candidate filter that may reduce the supremum of the symmetric pairs.

Important limitations:
- The epigraph formulation is not convex because terms `- h_i h_j` are indefinite on `[0,1]^2`, even though they are concavity-like for scalar diagonal. Solver success is local and should be called local refinement, not global optimization.
- Smooth log-sum-exp changes the objective to a differentiable surrogate and can bias active-lag selection. It is used only to generate candidate vectors; candidates are accepted only after exact evaluation.
- CVXPY is intentionally avoided as a proof of global optimality. CVX cannot express the exact nonconvex epigraph as a conic DCP problem without relaxation; a relaxation would need additional recovery and exact acceptance.
- The plan retains a valid parent/fallback if optimization spends too much time, to avoid returning invalid values for the fixed budget.

2. Mathematical specification

Discrete representation and objective:
Use `h in R^n`, `dx = 2.0/n`, target sum `S = n/2`. The authoritative exact objective is:
    F(h) = dx * max_{m=0,...,2n-2} c_m(h),
where `c_m(h)` is the m-th component of `np.correlate(h, 1-h, mode="full")`.
The count of overlaps is always odd, `L=2*n-1`.

For local gradients, use the direct pair formula, which is equivalent to the linear-correlation output (up to the nonessential ordering when taking the maximum):
For lag/output index `m`, define linear pair index set:
    A_m = {i : max(0, m-n+1) <= i <= min(m, n-1)},
    s   = n-1-m,
    j(i)= i + s.
The pair validity ensures all `(i,j)` inside `[0,n-1]^2`. The exact overlap component was expressed as:
    c_m(h) = dx * sum_{i in A_m} h_i * (1 - h_{j(i)}).
The pair direction is always included; both lag directions appear as `m` over the full set `[0,2n-2]`. The derivative of this exact component is:
    d c_m / d h_r =
      dx * [I(r in A_m but i=r) * (1 - h_{j(r)})]
    - dx * [I(exists i in A_m with j(i)=r) * h_i],
with combined terms where r is both i and j becoming `dx*(1-2 h_r)`.
This is the gradient required for both local smooth and epigraph methods. In every acceptance step, the final value is not taken from the direct gradient path or from the CV condition tolerance; it is recomputed by `dx*np.max(np.correlate(h, unhappy_hd[1]-hd, "full"))`.

Objective:
    minimize x[n].
Feasible set with explicit functions, not implicit closure:
