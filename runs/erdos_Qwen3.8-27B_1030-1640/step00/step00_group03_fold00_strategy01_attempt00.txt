1. Approach and rationale

The central idea is to solve the same discretized problem directly in its exact epigraph nonlinear-programming form, rather than replacing the maximum with a smoothed surrogate and then hoping that the smoothed optimum transfers. For a vector h ∈ [0,1]^n with sum(h)=n/2, the objective is

  C₅(h) = max_{k∈{-(n-1),…,n-1}} C_k(h),

where

  C_k(h) = dx * sum_{i valid for lag k} h[i] * (1 - h[i+k]),

dx = 2/n, and the “full” evaluator is an ”sc containing all these lag values. The proposed algorithm minimizes a real variable τ subject to τ ≥ C_k(h) for selected or all lag constraints, together with the mass and box constraints. This formulation has the same feasible set and endpoint scoring rule as the task. It is unlikely to be merely a renamed previous method because the search is built as an exact epigraph SQP/SLSQP process with analytic local gradients, an active-set safeguard for controller cost, and a separate repair/validation layer. The exact objective of every proposed vector is recomputed after local solving and after any feasibility repair; no candidate is accepted by comparing surrogate values or constraints alone.

The main bottleneck to address is the nonsmooth active constraint in a small, finite, nonconvex finite-dimensional problem. A direct fixed-point or smoothed-max optimization can differ from the original max at the active set and boundary terms. The new method avoids this by retaining epigraph constraints. To keep the number of inequalities manageable and the time robust, the SLSQP step initially sees only the currently largest lags, then violations discovered by the full evaluator are added if budget permits. A final dyadic feasibility alignment with exact summability is supplied, with non-dyadic valid candidates retained as a defensive fallback only if strict integer-feasibility checking is not achievable.
