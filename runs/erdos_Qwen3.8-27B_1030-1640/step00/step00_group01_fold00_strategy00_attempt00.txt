1. Approach and rationale
-------------------------

The problem is a box-and-hyperplane constrained nonconvex minimax finite-dimensional problem. The exact candidate objective, for a returned vector h of length n, is

C(h) = max_{r=0,...,2n-2} np.correlate(h, 1-h, mode="full")[r] * (2.0 / n).

No continuous surrogate should be optimized to finality, because the evaluator computes finite linear correlation with boundary truncation and includes both lag directions. The algorithm must therefore keep the exact evaluator value for acceptance and use it as the final proof.

The central method is active-set minimax optimization from the supplied construction:

- The exact evaluator is used at every candidate point for best-record check.
- To make product terms derivative-friendly, replace the max by a smooth exponential maximum (or a top-K smooth maximum) during local search. The resulting smooth objective is only a surrogate for descent. Candidate acceptance for setting explicit best uses the exact spectral evaluation, not the smooth value.
- Feasibility is handled by exact projection onto the box plus sum constraint. A line search/projection method never moves to a point violating 0 <= h <= 1 or sum(h) = n/2.
- The search starts from the supplied construction and then explores several meaningful variants: same-resolution re-optimization with different smoothing schedules, symmetry averaging, reversal, quantization, noise offsets shifted edges, resampling to nearby and larger resolutions, and features from multiple resolutions. A final “hard polish” uses a sharp active-minimax smoothing and a line method to reduce the recorded exact maximum below the supplied loose margin.
- Since the objective is nonconvex, this is not a globally proven optimizer. The method must be considered a high-quality local metaheuristist technique that reliably evaluates exact bounds and uses budget to test a large diverse set of starting points. That retained initial fallback may be the parent. For the offered problem and budget, this strategy is appropriate: exact evaluation, tight feasibility, descent and multiple starting constructions. Limitations must be kept in implementation reserved for multistart breadth rather than claimed global optimum.

1. Approach and rationale
-------------------------

The problem is a finite-dimensional nonconvex minimax problem: minimize, over a vector h with entries in [0,1] and sum(h)=n/2, the largest finite-lag cross-correlation between h and 1-h computed by np.correlate(..., "full") scaled by dx=2/n. The nonconvexity comes from products h_i h_j in the correlation terms, and the boundary truncation caused by linear (not circular) correlation means that simple “max autocorrelation” or periodic reformulations must not be used for the accepted score.

The proposed method is an exact-objective checking, surrogate-guided, multi-resolution local/metaheuristic method:

- Start from the supplied construction. Do not hard-code or copy its entries; it is read from the predefined input if available.
- For descent, replace the non-smooth maximum by a smooth exponential-maximum (log-sum-exp or top-K smooth maximum). This surrogate is only used to choose search directions; every evaluated candidate is scored with the exact evaluator.
- Maintain exact feasibility at all stored/accepted points by projecting onto the box intersect hyperplane {0≤h≤1, sum(h)=n/2} after every proposal. Exact feasibility is enforced by specialized projection/repair helpers.
- Search several related structures: the optimized parent, reversed/symmetrized parents, noise-perturbed parents, quantized versions, rotated/shifted versions, and resamplings to nearby or larger resolutions. This reduces the risk of getting stuck only in the parent’s exact local basin.
- Use budget-aware stage quotas, calibration of evaluation cost, finite iteration caps, and internal deadline checks so that whatever valid candidate is found before the budget survives to return. The best exact score seen anywhere is retained in a best-record object.

This gives a robust high-quality path to reduce the bound below the supplied/current parent values. It does not guarantee global optimality, because the underlying objective is nonconvex; exact specialization is guaranteed only for acceptance and final returning, while ascent is surrogate/local and possibly empirical improvement.
