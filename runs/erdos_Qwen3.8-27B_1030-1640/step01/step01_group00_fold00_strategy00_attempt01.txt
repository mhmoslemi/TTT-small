1. Approach and rationale

1.1 Central idea.
The objective is a finite nonconvex minimax problem:
C(h) = max_r dx * correlate_r(h, 1-h), with dx=2/n and sum(h)=n/2.
The supplied parent only provides a local feasible point. The likely bottleneck in previous first-order/soft-max searches is that the maximum is determined by a small asymmetric set of lags, while global constraints, bounds, and bilinear interactions prevent smooth descent from reaching a better basin. The new plan combines three complementary mechanisms:

- Exact combinatorial global/local optimization on binary vectors using a specialised MILP or simulated annealing/local-swap search. Binary solutions are useful because the bilinear terms are forced exact by linear McCormick constraints and because many locally optimal step functions are very close to binary.

- Exact active-constraint local refinement using linearProgramming trust-region moves in the original continuous space. This avoids premature soft-max bias and explicitly reduces the largest lags locally, while accepting only values whose `np.correlate` exact objective improves.

- Multiple local continuous minimax polishes: smooth log-sum-exp descent with SLSQP, direct epigraphic SLSQP on the original components, and residual refinement on several saved parent/binary candidates. All candidates are finally re-evaluated with the authoritative evaluator.

The plan does not claim finding the global continuous optimum. It is a strong local-search and diversification scheme intended to improve the supplied parent and, ideally, reach the target near 0.3808.

1.2 Why this could improve.
Binary pattern optimization is qualitatively different from continuous smoothing because it moves across topological barriers created by the max operator. It gives distinct starting feasibility configurations. Afterwards, continuous polish can lower the max slightly by nudging the most harmful active-pair variables inward. The active-constraint LP gives explicit local model reductions at the exact current matrix, substantially stronger than generic soft-max acceptance on a fixed tau schedule. Multiple candidate management prevents a single local basin from consuming the budget.

1.3 Limitations.
The binary MIP is honest only for binary vectors; its continuous relaxation is not convex or exact globally, so the final output must never be just the continuous relaxed values without projection and re-evaluation. Simulated annealing and MILP incumbents may be unavailable or slow. All component denominators and gradients can become ill-conditional at box boundaries; every solver must be wrapped with try/except and fallback to the set of stored exact values. No step is allowed to return a relaxed objective as final if feasibility or exact evaluation fails.
