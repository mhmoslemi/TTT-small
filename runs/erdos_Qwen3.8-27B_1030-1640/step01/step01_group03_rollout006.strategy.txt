1. Approach and rationale

The problem is a non-convex discrete minimax problem:

- Input is a sequence h[0],...,h[n-1] representing a step function on n equal cells over [0,2].
- Feasibility is 0 <= h[i] <= 1 and sum_i h[i] = n/2, so integral is 1.
- Exact score is the maximum over all 2n-1 fractional lags produced by the evaluator:
  C(h) = dx * max_m corr_m,
  dx = 2/n,
  corr_m = sum over valid overlapping indices of h[i] * (1 - h[i+k]),
  where k = m - (n-1) and both indices stay inside 0..n-1. This is linear, finite-support correlation, not circular correlation.

The previous program used one smooth soft-max descent and randomly sampled pair moves. The next program should address two bottlenecks:

1. It used simulated/soft gradient descent, but the nonlinear objective is a maximum of true bilinear functions. Small improvements often require simultaneous coordinated changes of several coordinates and are missed by local pair moves chosen randomly.
2. Pair polish was randomized; a candidate was accepted only if it became the new global best. Repeated full pairwise line optimization can produce a reliable pairwise-local improvement sequence.

The proposed construction is a deterministic or lightly randomized pipeline based on:

- exact parent preservation and fallback;
- exhaustive or intereval rigorous pairwise coordinate-subspace minimization;
- active-lag linearized minmax LP steps for coordinated batch updates;
- adaptive soft-max local minimization;
- diversity through symmetrization, transfer/resampling, quantization, random transforms;
- global best candidate management with exact evaluation every time.

This is justified because:
- the supplied objective is the metric to minimize; no surrogate or claim of a global optimum is used;
- candidate acceptance always uses the original evaluator objective;
- the method is local/non-convex but has multiple restarts and coordinated moves, much better than the previous random pair polish.

2. Mathematical specification

2.1 Representation

For a given n (default n = len(initial_h_values) if present, otherwise 45):

- dx = 2.0 / n.
- h is a one-dimensional numpy float array of length n.
- target integer count is target = n / 2 (it can be half-integer). The child values integrate to 1 as sum(h) * dx = (n/2)*(2/n)=1.

Feasibility:

- 0 <= h[i] <= 1 for each i.
- sum(h) is close to target, preferably to machine precision.
- Feasibility is enforced in a joint way, not by clip-then-rescale. The joint feasibility operation is:

hydro_project(y, target):

For a y array, let S(lambda) = sum(clip(y + lambda, 0, 1)). S(lambda) is continuous piecewise linear and nondecreasing. As lambda -> -infinity, S(lambda) -> 0. As lambda -> +infinity, S(lambda) -> n. Therefore there exists lambda such that S(lambda)=target. Bisection over lambda gives a shifted clipped array z = clip(y + lambda, 0, 1) satisfying the box and target constraints. In exact normal floating arithmetic the target is not necessarily bitwise zero due to rounding. We use tolerance 1e-10, and if desired an optional exact-feasibility tolerance pass: after slicing or intersections set the remaining residual residual = target - sum(z) on a coordinate with enough slack in the current direction:
- if residual > 0, choose j with z[j] + residual <= 1 and modify z[j] += residual; choose a coordinate where z[:j]; if no coordinate can accommodate, use hydro_project again;
- if residual < 0 use the symmetric negative on a coordinate with z[j] <= -residual.

Answer: The candidate manager keeps the last feasible result checked by the actual objective after all candidate transformations.

2.2 Exact objective for candidate validation

For every candidate h, compute:

objective(h):

- corr = np.correlate(h, 1.0 - h, mode="full")
- corr_float = corr.astype(float)
- return corr_float.max() * (2.0 / n)

Equivalent vectorized for gradient uses 2n-1 lag values F[0:2n-1] = dx * corr.

The correct dual lag index k is:

m ranges 0..2n-2:
k = m - (n-1)

For row (lag) m, define derivative G[m, j]=dx times the derivative of one lag sum L_m(h):

For k >= 0:
- valid first index j=0..n-k-1: add dx*(1 - h[j+k]) into G[m,j]
- valid second index j=k..n-1: add -dx*h[j-k] into G[m,j]

For k < 0:
Let l=-k
- valid first index j=l..n-1: add dx*(1 - h[j-l])
- valid second index j=0..n-l-1: add -dx*h[j+l]

This matches the finite-support correlation evaluator and includes both lag polarities.

2.3 Non-smooth maximization

We minimize:

C(h) = max_m F_m(h), dx positive doesn't change placeholder vector but based exact final scan.

This is generally nonconvex. The least-squares Hamiltonian surrogate, soft-log-sum maxima, and linear restrictions are only for deciding candidate points, never treated as proof of global optimality.

Linearization model:

Given h, and a set S of objective lag indices, solve min over d,t:

F_m(h) + G[m,:] dot d <= t, for all m in S
sum_j d_j = 0
max(-h[j], -tau) <= d_j <= max(1-h[j], tau)
minimum t

The box bound of tau makes trust region on the formulation to reduce smallness of model, improves accuracy. box uncertainty is incorporated by taking a trust step delta on d and checking the actual value after applying h + delta*d.

2.4 Pair coordinate subset for following whole problem precision
