1. Approach and rationale

1.1 Central idea

The supplied parent and the prior method rely mainly on continuous smoothed projected-gradient descent. That is useful locally, but it can get trapped in fractional plateaus and does not search the dominant combinatorial structure of low-overlap step functions. In the binary limit, the exact objective becomes a pure integer overlap-counting problem: for lag `s`, the quantity to minimize is the number of pairs `(i, i+s)` where a sampled one is followed by zero. That discrete structure is exactly what simulated annealing over balanced binary words can explore well.

The new plan is a strict two-level search:

- First run a binary combinatorial search with exact leave-one-pair-swap updates to find promising balanced binary templates at several sample resolutions.
- Then retain only valid binary templates or parent candidates as seeds and apply continuous exact-step refinement, including:
  - low-ε smoothing of binary templates,
  - exact active-gradient line descent preserving the integral constraint exactly,
  - feasible pair-transfer moves,
  - smoothed log-sum-exp projected-gradient polishing.
- All stored upper bounds are re-evaluated by the authoritative evaluator. No solver surrogate is used as final proof.

This is materially different from the previous algorithm because the primary global generator is combinatorial and exact at fixed resolution, not random continuous LSE starting from a single parent.

2.1 Discrete representation and feasibility

All `2n-1` lags, including both directions and the zero lag, are included. The program must compare candidates by this exact expression.

2.2 Binary integer objective

For a vector maintained by the binary simulated annealing exact objective uses the overlap count

```
C_s(b) = sum_{i valid} b_i * (1 - b_{i+s})
```

where `s ∈ {-(n-1), ..., n-1}` and invalid indices are omitted. This list is the same set of finite overlap correlations as `np.correlate` but the array ordering may be reversed. The maximum is invariant under this reversal. Final acceptance still uses exact `np.correlate`.

An exact swap update increases one position `q` from 0 to 1 and decreases another position `p` from 1 to 0. Let `b_old` be the prior array, and define signed contribution

```
f = +1   for the zero-to-one position q
f = +1   for the zero-to-one contribution sign
f = -1   for the one-to-zero position p
```

For each overlap shift `s`:

First-index contribution:

```
δ1_s = f * valid(p+s) * (1 - b_old[p+s])
```

because the first factor moves by `f`.

Second-index-term contribution:

```
δ2_s = -f * valid(p-s) * b_old[p-s]
```

because the second factor is `1 - b_i` and changes by `-f`.

For a complete swap, add the above contribution with `f=-1` for `p` and `f=+1` for `q`. The new count vector is `C + δ` before changing the binary array. This gives exact incremental update without recomputing all correlations, preserving feasibility exactly.
