1. Approach and rationale

Primary approach: a trust-region, linearized minimax sequential program (called LP-SQP below) for the discrete Erdős overlap objective. At a feasible point, the nonlinear overlap components

  c_m(h) = ∑_i h_i (1 - h_{i+s_m})

are replaced by first-order nonlinear-approximation supports, giving a linear program with minimax variable t:

  minimize t
  subject to c_m(h_current) + ∇c_m(h_current)ᵀ(h - h_current) ≤ t,
             0 ≤ h_i ≤ 1,
             ∑_i h_i = n/2,
             h_i ∈ trust box around current point.

The LP direction is evaluated by the exact original objective. Accepted only if it improves the exact max-overlap objective or, in controlled “pivoting” steps, remains within a small tolerance. Then the candidate is polished by coordinate search and mirrored/symmetrized candidates, and accepted against the true evaluator. Global diversification is supplied by a hand-coded symmetric differential-evolution search using compact pair assignment, plus mutation/restarting around the supplied initial construction. The initial parent, when available, is retained as a valid fallback and used as a primary high-quality seed; it is never copied as a hard-coded table.

Why this may improve the supplied construction: the previous solution relied on SLSQP with many nonlinear epigraph inequalities and log-sum-exp smoothing. The new method replaces nonlinear nonsmooth local descent by a stochastic-linearized trust-region LP whose step is chosen from an approximate linearized minimax problem. This is closer to solving the true minimax geometry: it uses all active first-order supports and box/mean constraints directly, while still guaranteeing final candidates are judged by the true nonconvex objective. It is particularly suited to this small problem (allowable n about 40-60), where a fresh document can outperform epigraph constrained methods.

Risks and limitations:
- The CL and augmented variables are nonconvex; linearization is only local.
- No global optimality is claimed. LP-SQP may find different local optima. Exact acceptance prevents false improvements. Symmetric population search may miss an optimal very near optimum in full vector space if it lacks a good graceful mirror pair.
- Constraint repair and LP solvers add roundoff errors; explicit exact summation and clipping checks are necessary.
