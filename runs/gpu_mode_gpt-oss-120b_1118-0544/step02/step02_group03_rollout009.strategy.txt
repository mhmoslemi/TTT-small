<strategy>Approach and rationale
The outgoing Triangle Multiplicative Update (TriMul) operator from AlphaFold3 computes an output tensor by performing a batched matrix multiplication-like operation. The operation involves sequences of indices and hidden dimensions, and must be optimized for large sequence lengths (up to 1024) and various batch sizes. The primary bottleneck is the O(N^3) core computation, which requires careful blocking and reuse of temporary registers to maximize Tensor Core utilization and minimize memory accesses. The goal is to achieve lower runtime by async prefetching tensor elements and computing partial sums entirely in software, thus eliminating the need for expensive hardware intrinsics. This allows us to bypass synchronization issues and potential performance losses from software-only dot products.

Mathematical specification
Given input tensor `x` of shape [B, N, N, C], followed by projection to hidden_dim produces `left` and `right` tensors of shape [B, N, N, hidden_dim]. The output tensor `out` is defined as:

out[b, i, j, h] = σ_{k=0}^{N-1} (left[b, i, k, h] * right[b, j, k, h])

provided mask[b, i, j] is True (or the mask is not present and no_nomask=True). The operations involve:
- LayerNorm on `x`
- Two linear projections (left_proj, right_proj) from `x` to hidden_dim.
- Option to apply binary masks to the hidden representations.
- Three sigmoid gates (left_gate, right_gate, out_gate).
- The core update.
- Another LayerNorm on hidden representations, followed by gated output.

The implementation must handle both `nomask=True` and `nomask=False` cases for the mask, and the distribution of input (normal or Cauchy) affects the LayerNorm outcome.

Implementation procedure
1. LayerNorm (norm): Normalize input `x` using LayerNorm parameters (norm_weight, norm_bias). Cast to fp16 for speed.
2. Projection: Perform linear projections on `x` to get `left` and `right` (tensors of shape [B, N, N, hidden_dim]). Cast these to fp16.
3. Masking: If mask is not None and no_nomask=False, broadcast mask to coverage all hidden_dim, then multiply left and right innomask mode.
4. Gate activation: Compute three sigmoid gates, element-wise multiply left and right by their respective gates.
5. Core update: Perform a batched operation over [B, hidden_dim, N, N] dimensions with async load and store. This is the core stage.
6. View and contiguous reshape: Merge the two first dimensions (B and hidden_dim) to a single contiguous batch dimension (B_shape = B * hidden_dim).
7. In-place matmul with async prefetching: For batch dimension of size B_shape, perform matrix multiplications using only software FMA, and store results in the new shape.
8. Apply out_gate and project to original dimensions using a final linear layer.

Note: The respective linear layers require transposed weights for efficient tensor multiplication. To avoid out-of-bound errors, we synchronize appropriately.
