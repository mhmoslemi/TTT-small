The main bottleneck is this matrix multiplication across N x N for each hidden channel, which is O(N^3). Actually each left and right have shapes [B, N, N, hidden_dim]; after rearrangement to (B*hidden_dim, N, N), we compute a matrix multiplication where left and right are both (B*hidden_dim, N, N). The reduction is left * right^T per pair of i, j indices, but note the reduction dimension is over k (third dimension). This yields [batch*hidden, N, N], which matches out shape.

Complexity: each matrix multiply is O(N^3). For hidden=128, that's 128 * N^3 ~ large. However using batched matrix multiplication with GPU tensor cores can compute it relatively fast due to GPU parallelism, but runtime target given is 550 microseconds for N up to 1024, which is still demanding. Potential approach: use combination of two steps: compute left and right as shape [B, N, hidden, N] (permute dimensions) and then perform batched gemm using triton with block tile across i and j dims, summing over k.

Essentially compute out[b,i,j,d] = sum_k left[b,i,k,d] * right[b,j,k,d]; we can treat d as independent tasks. Another approach: we can fuse the gating, linear projections, and multiplication in a single Triton kernel to reduce memory traffic. However, implementing layernorm and linear in Triton is non-trivial, especially computing mean/variance across channel dimension.

Alternatively, we could implement the multiplication using a fused kernel that reads left and right from memory, does the multiplication for each output element (i, j) for all hidden_dim channels simultaneously via vectorized loads (maybe using 128-bit loads). The algorithm loops over k in blocks.

We'll implement a Triton kernel for out computation directly, then use torch ops for layernorm, gating, projection, etc. That may already speed up enough.

The kernel tiles the i‑ and j‑dimensions with BLOCK_M×BLOCK_N threads (≤1024 per
program) and iterates over k in BLOCK_K chunks, using fp16 inputs and fp32
accumulation (tensor‑core friendly).  Hidden channels are parallelised over the
second grid dimension.
"""

import torch
import torch.nn.functional as F
import triton
import triton.language as tl

@triton.jit
def tri_mul_kernel(
    left_ptr,   # const float16 *
    right_ptr,  # const float16 *
    out_ptr,    # float32 *
    B, N, H,    # int64 runtime args
    stride_l_b, stride_l_i, stride_l_k, stride_l_d,
    stride_r_b, stride_r_i, stride_r_k, stride_r_d,
    stride_o_b, stride_o_i, stride_o_j, stride_o_d,
    BLOCK_M: tl.constexpr, BLOCK_N: tl.constexpr, BLOCK_K: tl.constexpr,
):
    """Compute the outgoing tri‑multiplicative update.

    Each program processes a TILE (BLOCK_M × BLOCK_N) of the output matrix for a
    single batch element and a single hidden channel (d = tl.program_id(1)).
    """
    pid0 = tl.program_id(0)          # encodes (batch, i_tile, j_tile)
    pid1 = tl.program_id(1)          # hidden channel index d

    # --------------------------------------------------------------
    # Decode program id into batch and tile coordinates
    # --------------------------------------------------------------
    num_i = tl.cdiv(N, BLOCK_M)
    num_j = tl.cdiv(N, BLOCK_N)
    total_tiles = num_i * num_j

    b = pid0 // total_tiles
    tile_id = pid0 % total_tiles
    i_tile = tile_id // num_j
    j_tile = tile_id % num_j

    i0 = i_tile * BLOCK_M
    j0 = j_tile * BLOCK_N

    # --------------------------------------------------------------
    # Offsets within the tile
    # --------------------------------------------------------------
    offs_i = i0 + tl.arange(0, BLOCK_M)
    offs_j = j0 + tl.arange(0, BLOCK_N)
    mask_i = offs_i < N
    mask_j = offs_j < N

    # accumulator in FP32
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # --------------------------------------------------------------
    # Loop over the reduction dimension k
    # --------------------------------------------------------------
    for k in range(0, N, BLOCK_K):
        offs_k = k + tl.arange(0, BLOCK_K)
        mask_k = offs_k < N

        # left[b, i, k, d]   -> shape (M, K)
        left_ptrs = left_ptr + b * stride_l_b \
                    + offs_i[:, None] * stride_l_i \
                    + offs_k[None, :] * stride_l_k \
                    + pid1 * stride_l_d

        # right[b, j, k, d] (need (K, N) layout for matmul)
        right_ptrs = right_ptr + b * stride_r_b \
                    + offs_k[:, None] * stride_r_k \
                    + offs_j[None, :] * stride_r_i \
                    + pid1 * stride_r_d

        left = tl.load(left_ptrs,
                       mask=mask_i[:, None] & mask_k[None, :],
                       other=0.0)      # FP16
        right = tl.load(right_ptrs,
                        mask=mask_k[:, None] & mask_j[None, :],
                        other=0.0)     # FP16

        # promote to FP32 for accumulation (Tensor‑core friendly)
        left = left.to(tl.float32)
        right = right.to(tl.float32)

        acc += tl.dot(left, right)   # (M,K) @ (K,N) -> (M,N)

    # --------------------------------------------------------------
    # Store the result to out[b, i, j, d] (FP32)
    # --------------------------------------------------------------
    out_ptrs = out_ptr + b * stride_o_b \
               + offs_i[:, None] * stride_o_i \
               + offs_j[None, :] * stride_o_j \
               + pid1 * stride_o_d

    tl.store(out_ptrs, acc, mask=mask_i[:, None] & mask_j[None, :])

def custom_kernel(data):
    """
    Forward pass for the outgoing TriMul operator.

    Args:
        data: tuple (input_tensor, mask, weights, config)
            - input_tensor: torch.Tensor of shape [B, N, N, dim] (float32)
            - mask: torch.Tensor of shape [B, N, N] (bool/float) or None
            - weights: dict with the following keys (all float32 tensors):
                * "norm.weight", "norm.bias"
                * "left_proj.weight", "right_proj.weight"
                * "left_gate.weight", "right_gate.weight", "out_gate.weight"
                * "to_out_norm.weight", "to_out_norm.bias"
                * "to_out.weight"
            - config: dict containing at least "dim" (int) and "hidden_dim" (int);
                      optional "nomask" bool.

    Returns:
        torch.Tensor of shape [B, N, N, dim] (float32)
    """
    input_tensor, mask, weights, config = data
    dim = config["dim"]
    hidden_dim = config["hidden_dim"]
    nomask = config.get("nomask", False)

    device = input_tensor.device
    B, N, _, C = input_tensor.shape
    assert C == dim, "input dim mismatch"

    # ------------------------------------------------------------------
    # 0) unpack weights
    # ------------------------------------------------------------------
    norm_weight = weights["norm.weight"]
    norm_bias = weights["norm.bias"]
    left_proj_weight = weights["left_proj.weight"]
    right_proj_weight = weights["right_proj.weight"]
    left_gate_weight = weights["left_gate.weight"]
    right_gate_weight = weights["right_gate.weight"]
    out_gate_weight = weights["out_gate.weight"]
    to_out_norm_weight = weights["to_out_norm.weight"]
    to_out_norm_bias = weights["to_out_norm.bias"]
    to_out_weight = weights["to_out.weight"]

    # ------------------------------------------------------------------
    # 1) Input LayerNorm (dim)
    # ------------------------------------------------------------------
    x = F.layer_norm(
        input_tensor,
        normalized_shape=(dim,),
        weight=norm_weight,
        bias=norm_bias,
        eps=1e-5,
    )  # [B, N, N, dim]

    # ------------------------------------------------------------------
    # 2) Linear projections (bias‑free)
    # ------------------------------------------------------------------
    left = F.linear(x, left_proj_weight)   # [B, N, N, hidden_dim]
    right = F.linear(x, right_proj_weight)

    # ------------------------------------------------------------------
    # 3) Optional mask
    # ------------------------------------------------------------------
    if not nomask and mask is not None:
        mask_f = mask.to(x.dtype).unsqueeze(-1)   # [B, N, N, 1]
        left = left * mask_f
        right = right * mask_f

    # ------------------------------------------------------------------
    # 4) Gating (sigmoid of linear layers)
    # ------------------------------------------------------------------
    left_gate = torch.sigmoid(F.linear(x, left_gate_weight))
    right_gate = torch.sigmoid(F.linear(x, right_gate_weight))
    out_gate = torch.sigmoid(F.linear(x, out_gate_weight))

    # ------------------------------------------------------------------
    # 5) Apply gates and cast to FP16 for the heavy reduction
    # ------------------------------------------------------------------
    left = (left * left_gate).to(torch.float16)
    right = (right * right_gate).to(torch.float16)

    # ------------------------------------------------------------------
    # 6) Triton kernel for the O(N³) reduction
    # ------------------------------------------------------------------
    # Output tensor in FP32 (will be fed into the final LayerNorm)
    out = torch.empty((B, N, N, hidden_dim), dtype=torch.float32, device=device)

    # Tiling parameters – empirically good for B200 (adjustable if needed)
    BLOCK_M = 32
    BLOCK_N = 32
    BLOCK_K = 32

    # Grid dimensions:
    #   dim0 : batch * tiles_i * tiles_j
    #   dim1 : hidden_dim (one program per hidden channel)
    num_i = (N + BLOCK_M - 1) // BLOCK_M
    num_j = (N + BLOCK_N - 1) // BLOCK_N
    total_tiles = num_i * num_j
    grid0 = B * total_tiles
    grid = (grid0, hidden_dim)

    # Strides for pointer arithmetic
    stride_l_b, stride_l_i, stride_l_k, stride_l_d = left.stride()
    stride_r_b, stride_r_i, stride_r_k, stride_r_d = right.stride()
    stride_o_b, stride_o_i, stride_o_j, stride_o_d = out.stride()

    tri_mul_kernel[grid](
        left,
        right,
        out,
        B,
        N,
        hidden_dim,
        stride_l_b,
        stride_l_i,
        stride_l_k,
        stride_l_d,
        stride_r_b,
        stride_r_i,
        stride_r_k,
        stride_r_d,
        stride_o_b,
        stride_o_i,
        stride_o_j,
        stride_o_d,
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
        num_warps=8,
    )

    # ------------------------------------------------------------------
    # 7) Post‑processing: LayerNorm over hidden dim, gating, final projection
    # ------------------------------------------------------------------
    out = F.layer_norm(
        out,
        normalized_shape=(hidden_dim,),
        weight=to_out_norm_weight,
        bias=to_out_norm_bias,
        eps=1e-5,
    )
    out = out * out_gate                     # element‑wise output gate
    out = F.linear(out, to_out_weight)       # [B, N, N, dim]

    return out
```
