   - `x` (input): [B, N, N, C]  
   **Projected dimensions**:  
   - `left_proj`: [B, N, N, H]  
   - `right_proj`: [B, N, N, H]  

   **Without mask**:  
   - `out[b, i, j, h] = sum_{k=0}^{N-1} left_proj[b, i, k, h] * right_proj[b, j, k, h]`  
   - Output through a combined output gate and final linear projection  

   **With mask**:  
   - Apply element-wise multiplication with `mask[b, j, k]` for valid pairs  

   Let `M = left_proj[b, i, :]` and `N = right_proj[b, j, :]` (faster notation):  
   `out[b, i, j, h] = sum_{k} M[k, h] * N[k, h]`  
   where `batch_index = b`, `sequence_index_i = i`, `sequence_index_j = j`

3. Implementation Procedure  
   **Step-by-Step Execution**:  

   - **3.1 LayerNorm**:  
     Apply LayerNorm to input tensor along channel dimension  
     `scale = 1/np.sqrt(variance)`  
     `x_ln = (x - mean) * scale + bias`  

   - **3.2 Transpose Input**:  
     Change dimensions [B, N, N, C] -> [B, C, N, N] to align with weights shape [C, H]  
     `x_trans = x_ln.transpose(0,1,2,3)`  
     Then apply linear transformation: `left_proj = x_trans @ left_proj_weight`  

   - **3.3 Reduce and Transpose**:  
     For reduction:  
     `[batch_size, num_heads, N, N] -> [batch_size * num_heads, N, N]`  
     `right_proj = right_proj @ right_proj_weights`  
     Transpose right to align with left for reduction  

   - **3.4 Grouped Matrix Multiplication**:  
     Launch triton kernel with:  
     - `BLOCK = min(BLOCK_SIZE, N)` per thread block  
     - `ROUND_FN = tl.fmod` for coordinate mapping  

     The kernel performs:  
     `out_flat[h_idx, i, j] = sum_h_{tl.arange(BLOCK)} left_flat[h_idx, i, k] * right_flat[h_idx, j, k]`

   - **3.5 Output Processing**:  
     Convert results from FP16 to the original dtype  
     `out = torch.reshape(out_flat, [B, N, N, H]) @ out_weights`  

4. Search Choices  
   The default implementation uses a standard grouped matrix multiplication with:  
   - `BLOCK_SIZE = 128` for memory efficiency
   - `num_batches = B * N * N * H // BLOCK_SIZE`  
   - `seq_len = N` and `num_heads = H`

   The mask option adds an extra element-wise multiplication step:
   `mask = data[2]` if `"nomask": False` else `None`

5. Compute Budget  
   - The reduction has `B*N*N*H` elements  
   - Each reduction across k takes `N` operations  
   - Total operations ~ `B*N^2*H` (be mindful of unused passages)
   - Use `BLOCK_SIZE = 128` for triton thread blocks  

   **Stop Condition**: When mask application completes without exceeding time limits  
   **Fallback**: Use CPU implementation as backup

   - Shape must be [B, N, N, dim]  
   - Sum of sequence indices: `N % 2 == 0`  
   - Temporary checks: verify output shape after linear projection is [B, N, N, H]
