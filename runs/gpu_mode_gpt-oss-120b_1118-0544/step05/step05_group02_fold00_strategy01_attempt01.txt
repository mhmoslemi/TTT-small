We are implementing the "outgoing" version of the TriMul operator from AlphaFold 3. The input is a 4D tensor [B, N, N, C] and an optional mask [B, N, N]. The goal is to compute an output tensor [B, N, N, C] via a series of linear projections and a fused matrix multiplication.

Key steps from the PyTorch code:
1. LayerNorm on the input tensor (with dimension C, but note the shape is [B, N, N, C]).
2. Linear projections (left_proj and right_proj) without bias, which map input dimension C to a hidden dimension (hidden_dim).
3. Compute gates for each projection (sigmoid activations for left_gate, right_gate, and out_gate).
4. If a mask is present, multiply the left and right projections (after first two gates) by the mask element-wise.
5. Perform a matrix multiplication for each hidden dimension: 
   out[b, i, j, h] = sum_{k} left[b, i, k, h] * right[b, j, k, h]
   This is equivalent to a batched matrix multiplication for each batch (b, h): 
   out = (left reshaped as [B*hidden_dim, N, N]) @ (right reshaped as [B*hidden_dim, N, N]^T)
6. Apply a second LayerNorm (with hidden_dim) and then multiply by the output gate and project back to the original dimension.

The input tensor is of shape [B, N, N, C], and there may be an optional mask [B, N, N]. The goal is to compute an output tensor [B, N, N, C] through a series of linear projections, gate activations, and a Hamonic-like summation over the sequence dimension.

The key steps in the TriMul operation are:
1. Apply LayerNorm to the input tensor along the last two dimensions.
2. Apply linear projections (left_proj and right_proj) to project the input from channel C to hidden_dim.
3. Apply gate projections and sigmoid activation for left_gate, right_gate, and out_gate.
4. Optionally multiply by the mask.
5. Perform a batched matrix multiplication: for each batch b and each channel h, compute the matrix product between left[b, :, :, h] and right[b, :, :, h].
6. Apply a second LayerNorm, multiply by the output_gate, and project back to the original channel dimension.
