So we need to implement this with a Triton kernel to accelerate the heavy O(N^3 * hidden_dim) operation (the einsum). That's the main computational bottleneck: sum over k of left(b,i,k,d) * right(b,j,k,d). That's essentially a batched matrix multiplication for each hidden_dim channel: for each d, we have left[b,:, :, d] shape [N,N] vs right[b,:, :, d] shape [N,N] in which the multiplication is left[i,k] * right[j,k] and sum over k. That's essentially left[b,:, :, d] @ right[b,:, :, d].T? Actually if we treat left[b,i,k] (N x N) with shape i x k. And right[b,j,k] shape j x k. Then out[i,j] = sum_k left[i,k] * right[j,k]; in matrix multiplication, (L) * (R)^T where R[j,k] -> R^T[k,j]; sum_k L[i,k] * R^T[k,j] = sum_k L[i,k] * R[j,k]; yep out = L @ R.T. So out[b, :, :, d] = left[b, :, :, d] @ right[b, :, :, d].T

Thus the einsum reduces to a batched matrix multiplication for each hidden_dim channel (i.e., hidden_dim independent matrix multiplications). This can be implemented efficiently using GEMM. Since we need to multiply left x right.T per hidden channel, we can treat each d as its own independent GEMM with same batch and dimension.

Design of kernel:

We want to compute output block of shape [BLOCK_M, BLOCK_N] for each (b, d) pair.

So we can treat each combination of batch and hidden channel as a separate "task" group launching a 2D grid: program_id(0) for batch * hidden_dim dimension; program_id(1) for block row (i); program_id(2) for block column (j). Or we can flatten them into a 2D grid where program_id(0) indexes over (batch, hidden_dim, block_row) maybe.

We need to loop over k in blocks (BLOCK_K) for each multiplication. So we can reuse the standard matrix multiplication Triton kernel but with extra dimension for hidden_dim (like batches). Essentially we can treat the left and right arrays as 3D tensors: A shape [B*hidden_dim, M, K], B shape [B*hidden_dim, N, K] (since we need right transpose we can pass B as [B*hidden_dim, N, K]), but in GEMM we need B of shape [B*hidden_dim, K, N] for A @ B (assuming B is KxN). Actually standard GEMM: C = A @ B, where A [M,K] B [K,N]. Our out must be sum over k: left[i,k] * right[j,k] => treat A = left[b,d,i,k], B = right[b,d,j,k]^T i.e. using right_T shape [B,d,N,K] (j,k). So B_T has shape [B*hidden_dim, K,N] if we transpose. Wait let's restructure:

Given left shape [B, hidden_dim, N, N] (with axes (b,d,i,k)). Right shape [B, hidden_dim, N, N] (b,d,j,k). For multiplication we want (left) @ (right)^T => we need right transposed to shape [B, hidden_dim, K, N] where K = N, N = N. Since K = N, both dims same.

If we compute C = left @ right_T, where left is [M,K] (M=i, K=k), right_T is [K,N] (K=k, N=j), we get C[M,N] = out[i,j]. So for each (b,d) we need to do matmul of size N x N with N x N.

Thus we can treat the combined batch dimension as B * hidden_dim. So we can implement standard GEMM kernel handling batched matrices: feed pointers to A, B, C, with stride accordingly.

Parameters:

- A_ptr: starting address of left tensor (flattened as [B*hidden_dim, N, N]).
- B_ptr: starting address of right_transposed tensor (flattened as [B*hidden_dim, N, N]).
- C_ptr: output pointer.

We need to compute strides in memory for the tensors.

Alternatively we could treat left and right as contiguous slices per hidden_dim, ensuring layout is correct.

But note that the input tensors are originally shape [B,N,N,hidden_dim]. But after projection and gating, they are shape [B,N,N,hidden_dim] which is `contiguous` in memory as last dimension fast. So memory layout is row-major: stride of hidden_dim is 1, stride of N (k) is hidden_dim, stride of N (i) is N*hidden_dim, stride of B is N*N*hidden_dim.

But we want to treat them as [B, hidden_dim, N, N] for batch > hidden. We can reorder dimensions using view or permute which will cause non-contiguous memory. To avoid costly transpose, we can compute using original layout by adjusting strides accordingly. In Triton we can use stride offsets accordingly.

Specifically, for left tensor shape [B, N, N, hidden_dim], we want access to element left[b,i,k,d]. This is at pointer: x_ptr + b*stride_b + i*stride_i + k*stride_k + d*stride_d. Since contiguous memory in PyTorch default is C-contiguous with last dimension fastest (d). Let's get strides:

Assuming x is contiguous as described:

- stride_d = 1
- stride_k = hidden_dim (since moving one step in third dimension N (the second N) changes hidden_dim elements)
- stride_i = N * hidden_dim
- stride_b = N * N * hidden_dim

Thus left pointer offset formula: offset = b*stride_b + i*stride_i + k*stride_k + d*stride_d.

Similarly right tensor same layout.

Now for matmul: left's indices: i (row), k (col) for each (b,d). We need to treat left as matrix of shape (N (i), N (k)). The hidden_dim d just picks which matrix within hidden_dim for each b.

Thus we want to load a block of left: block rows i_range (size BLOCK_M), block cols k_range (size BLOCK_K). Offsets will be computed accordingly.

Similarly for right_transposed we need to multiply left[i,k] with right[j,k] with sum over k; right must be accessed as (j,k) but for GEMM we need B[k,j] (i.e., column major on j). In memory we store right as [b,i?, k? hidden]? Actually right is shape [B,N,N,hidden_dim] where right[b, j, k, d] (the second N index is j, third is k). In original layout, j is second dimension (the first N), k is third dimension (the second N), d is hidden. So if we want to treat B as shape [B, hidden_dim, K, N] we need to use stride arrangement accordingly: we need to read right values but swapped positions for i and j being changed.

But if we load right with offset where we treat row dimension as k and col dimension as j, we need to broadcast accordingly. So we need to compute B block offset formula as: offset_B = b*stride_b + j*stride_i + k*stride_k + d*stride_d. But for B's rows we want k, for columns we want j. Thus we can just compute offsets using the original layout but swap the meanings of i/j arguments: Instead of using i for row dimension, we use k.

When we compute B block offset we want to load a tile of shape (BLOCK_K x BLOCK_N) where rows correspond to k, columns to j. So we can let offsets = b*stride_b + (j_offset)*stride_i + (k_offset)*stride_k + d*stride_d.

Thus we can treat right data as B with row stride = stride_k (since we need to move in k direction) and column stride = stride_i (since moving in j direction). But typical GEMM expects B stride in rows (K) and columns (N). Row stride is stride_k (advancing to next k), column stride is stride_i (advancing to next j). But in memory, advancing row is moving along k dimension because each increment in k increases offset by stride_k (hidden_dim). And advancing column moves across j dimension (increase i index) offset by stride_i (N*hidden_dim). That matches shape.

Thus we can implement GEMM using these strides.

Thus overall pipeline:

1. Get x, mask tensor, weight dict, config dict.

2. Extract configuration parameters: dim (input_dim), hidden_dim.

3. Perform LayerNorm on x (input). Use precomputed weight and bias of `norm` part:
   - According to nn.LayerNorm, the output is: (x - mean) / sqrt(var + eps) * weight + bias
   - weight shape [dim], bias shape [dim].
   - Epsilon default is 1e-5. We'll use config.get('eps', 1e-5) (if not present). We'll set epsilon constant: 1e-5.

   - Compute mean per element: because we need mean across dim dimension. For shape [B,N,N,dim] we can compute using torch.mean along last dimension: `mean = x.mean(dim=-1, keepdim=True)`. Similarly var = x.var(dim=-1, unbiased=False, keepdim=True). Unbiased flag false because torch.nn.LayerNorm uses unbiased=False (i.e., var = mean of squared diff). So var = ((x - mean)**2).mean(dim=-1, keepdim=True). So we can implement using torch.var(dim=-1, unbiased=False) which uses N denominator that's correct.

   - Normalize: x_norm = (x - mean) * rsqrt(var + eps)  # (var + eps). rsqrt = 1/sqrt(...). Compute using torch.rsqrt. Then x_norm = x_norm * weight + bias. weight and bias broadcast.

   - weight and bias are `norm.weight` and `norm.bias`. Make sure they have shape [dim] and are loaded onto proper device and dtype (float32). Use `.view(1,1,1,dim)` for broadcasting.

4. Compute left_proj = linear over last dim: left = torch.nn.functional.linear(x_norm, left_proj_weight). Since bias=False, we can compute left = torch.einsum('...d,hd->...h', x_norm, left_proj_weight.T?) Actually left_proj_weight shape is [hidden_dim, dim] (since Linear(dim, hidden_dim) weight shape [hidden_dim, dim]). So we can compute left = torch.nn.functional.linear(x_norm, left_proj_weight) or using torch.matmul: left = torch.einsum('...d, hd -> ...h', x_norm, left_proj_weight.t())? However torch.nn.functional.linear expects weight shape [out_features, in_features]. So correct: left = torch.nn.functional.linear(x_norm, left_proj_weight) (the weight argument is [hidden_dim, dim]) and bias=None. Similarly for right.

5. Apply mask if not nomask: mask shape [B,N,N] maybe missing. In code, they unsqueeze mask to shape [B,N,N,1] and broadcast. So left = left * mask.unsqueeze(-1); right similarly.

   - Input mask may be boolean or float with 0 or 1 values. We'll assume it's float or bool.

   - Could be no mask (nomask True). In that case mask tensor may still be present but maybe contains all 1's? Or the code expects we can skip mask multiplication to save compute. But we can still multiply; not huge effect.

6. Compute gates:

   where weights have shape [hidden_dim, dim] similarly.

7. Apply gating: left = left * left_gate; right = right * right_gate

8. Now we have left and right as shape [B,N,N,hidden_dim] ready for reduction.

   - In kernel we compute batch_hidden combined id.

"""
TriMul forward pass with a Triton‐accelerated reduction.

1. LayerNorm on the input tensor (shape [B,N,N,dim]).
2. Linear projections (left/right) and three sigmoids (gates) – done with
   torch.nn.functional.linear for simplicity.
3. Apply mask (if present) and gate multiplications.
4. Compute the core O(N³) reduction:
       out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d]
   This is a batched matrix multiplication for each hidden dimension.
   Implemented in Triton (blocked GEMM) for high throughput.
5. LayerNorm on the reduction result, multiply by the output gate,
   and a final linear projection back to 'dim'.

All heavy compute (the reduction) runs on the GPU via Triton, while the
remaining tensor ops use fast PyTorch kernels.
"""
import torch
import triton
import triton.language as tl

# ----------------------------------------------------------------------
# Triton kernel: batched GEMM where each batch corresponds to (b, hidden)
# ----------------------------------------------------------------------
@triton.jit
def batched_matmul_kernel(
    a_ptr, b_ptr, c_ptr,               # pointers
    B, N, H,                           # runtime sizes
    stride_a_b, stride_a_i, stride_a_k, stride_a_d,
    stride_b_b, stride_b_i, stride_b_k, stride_b_d,
    stride_c_b, stride_c_i, stride_c_j, stride_c_d,
    BLOCK_M: tl.constexpr, BLOCK_N: tl.constexpr, BLOCK_K: tl.constexpr,
):
    pid0 = tl.program_id(0)   # combined batch * hidden index
    pid_m = tl.program_id(1)   # block row   (i)
    pid_n = tl.program_id(2)   # block col   (j)

    # --------------------------------------------------------------
    # decode batch and hidden index
    # --------------------------------------------------------------
    batch_idx = pid0 // H
    hidden_idx = pid0 % H

    # --------------------------------------------------------------
    # tile offsets
    # --------------------------------------------------------------
    offs_m = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_n = pid_n * BLOCK_N + tl.arange(0, BLOCK_N)

    mask_m = offs_m < N
    mask_n = offs_n < N

    # ------------------------------------------------------------------
    # base pointers for this (batch, hidden) pair
    # ------------------------------------------------------------------
    a_base = a_ptr + batch_idx * stride_a_b + hidden_idx * stride_a_d
    b_base = b_ptr + batch_idx * stride_b_b + hidden_idx * stride_b_d
    c_base = c_ptr + batch_idx * stride_c_b + hidden_idx * stride_c_d

    # accumulator
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # --------------------------------------------------------------
    # loop over K dimension (the summed sequence index)
    # --------------------------------------------------------------
    num_k = tl.cdiv(N, BLOCK_K)
    for k_iter in range(num_k):
        k_offset = k_iter * BLOCK_K
        offs_k = k_offset + tl.arange(0, BLOCK_K)
        mask_k = offs_k < N

        # pointers to the current tiles of A (left) and B (right.T)
        a_ptrs = a_base + offs_m[:, None] * stride_a_i + offs_k[None, :] * stride_a_k
        b_ptrs = b_base + offs_k[:, None] * stride_b_k + offs_n[None, :] * stride_b_i

        # masked loads
        mask_a = mask_m[:, None] & mask_k[None, :]
        mask_b = mask_k[:, None] & mask_n[None, :]

        a = tl.load(a_ptrs, mask=mask_a, other=0.0)
        b = tl.load(b_ptrs, mask=mask_b, other=0.0)

        acc += tl.dot(a, b)          # (BLOCK_M, BLOCK_K) @ (BLOCK_K, BLOCK_N) -> (BLOCK_M, BLOCK_N)

    # --------------------------------------------------------------
    # write the result tile
    # --------------------------------------------------------------
    c_ptrs = c_base + offs_m[:, None] * stride_c_i + offs_n[None, :] * stride_c_j
    mask_c = mask_m[:, None] & mask_n[None, :]
    tl.store(c_ptrs, acc, mask=mask_c)

# ----------------------------------------------------------------------
# Entry point called from the test harness
# ----------------------------------------------------------------------
def custom_kernel(data):
    """
    Compute the forward pass of AlphaFold3's outgoing TriMul.
    Arguments:
        data = (input_tensor, mask, weights_dict, config_dict)

    Returns:
        Tensor of shape [bs, seq_len, seq_len, dim] (float32, on the same device)
    """
    # ------------------------------------------------------------------
    # unpack inputs
    # ------------------------------------------------------------------
    x, mask, weights, config = data
    device = x.device
    dtype = x.dtype

    dim = config["dim"]
    hidden_dim = config["hidden_dim"]
    eps = config.get("layer_norm_eps", 1e-5)

    # ------------------------------------------------------------------
    # fetch weights (ensure correct dtype/device)
    # ------------------------------------------------------------------
    def to_tensor(t):
        return t.to(device=device, dtype=dtype)

    norm_weight = to_tensor(weights["norm.weight"])
    norm_bias = to_tensor(weights["norm.bias"])
    left_proj_weight = to_tensor(weights["left_proj.weight"])
    right_proj_weight = to_tensor(weights["right_proj.weight"])
    left_gate_weight = to_tensor(weights["left_gate.weight"])
    right_gate_weight = to_tensor(weights["right_gate.weight"])
    out_gate_weight = to_tensor(weights["out_gate.weight"])
    to_out_norm_weight = to_tensor(weights["to_out_norm.weight"])
    to_out_norm_bias = to_tensor(weights["to_out_norm.bias"])
    to_out_weight = to_tensor(weights["to_out.weight"])

    # ------------------------------------------------------------------
    # 1. LayerNorm on input (over the last dim)
    # ------------------------------------------------------------------
    # mean and variance over the feature dimension
    mean = x.mean(dim=-1, keepdim=True)
    var = ((x - mean) ** 2).mean(dim=-1, keepdim=True)
    x_norm = (x - mean) * torch.rsqrt(var + eps)
    # apply learned scale & bias
    x_norm = x_norm * norm_weight.view(1, 1, 1, -1) + norm_bias.view(1, 1, 1, -1)

    # ------------------------------------------------------------------
    # 2. Linear projections (no bias)
    # ------------------------------------------------------------------
    left = torch.nn.functional.linear(x_norm, left_proj_weight)   # [B,N,N,hidden]
    right = torch.nn.functional.linear(x_norm, right_proj_weight)

    # ------------------------------------------------------------------
    # 3. Mask handling (broadcast to hidden dim)
    # ------------------------------------------------------------------
    if mask is not None:
        mask = mask.to(dtype).unsqueeze(-1)                     # [B,N,N,1]
        left = left * mask
        right = right * mask

    # ------------------------------------------------------------------
    # 4. Gating (sigmoid on linear transforms)
    # ------------------------------------------------------------------
    left_gate = torch.nn.functional.linear(x_norm, left_gate_weight).sigmoid()
    right_gate = torch.nn.functional.linear(x_norm, right_gate_weight).sigmoid()
    out_gate = torch.nn.functional.linear(x_norm, out_gate_weight).sigmoid()

    left = left * left_gate
    right = right * right_gate

    # ------------------------------------------------------------------
    # 5. TriMul reduction via Triton (batched GEMM)
    # ------------------------------------------------------------------
    # ensure contiguous layout for pointer arithmetic
    left = left.contiguous()
    right = right.contiguous()

    B, N, _, _ = left.shape
    out = torch.empty_like(left)  # shape [B,N,N,hidden]

    # strides in element units (not bytes)
    stride_a_b, stride_a_i, stride_a_k, stride_a_d = left.stride()
    stride_b_b, stride_b_i, stride_b_k, stride_b_d = right.stride()
    stride_c_b, stride_c_i, stride_c_j, stride_c_d = out.stride()

    # block sizes – chosen to give good occupancy on B200
    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 64

    grid = (
        B * hidden_dim,                # program_id(0) – batch * hidden
        (N + BLOCK_M - 1) // BLOCK_M, # program_id(1) – row blocks
        (N + BLOCK_N - 1) // BLOCK_N, # program_id(2) – col blocks
    )

    batched_matmul_kernel[grid](
        left.data_ptr(),
        right.data_ptr(),
        out.data_ptr(),
        B, N, hidden_dim,
        stride_a_b, stride_a_i, stride_a_k, stride_a_d,
        stride_b_b, stride_b_i, stride_b_k, stride_b_d,
        stride_c_b, stride_c_i, stride_c_j, stride_c_d,
        BLOCK_M=BLOCK_M, BLOCK_N=BLOCK_N, BLOCK_K=BLOCK_K,
    )

    # ------------------------------------------------------------------
    # 6. Post‑norm, out‑gate and final projection
    # ------------------------------------------------------------------
    # LayerNorm over hidden dimension
    out_norm = torch.nn.functional.layer_norm(
        out,
        (hidden_dim,),
        weight=to_out_norm_weight,
        bias=to_out_norm_bias,
        eps=eps,
    )
    out_norm = out_norm * out_gate  # broadcast gate

    # Final linear (hidden -> dim)
    output = torch.nn.functional.linear(out_norm, to_out_weight)

    return output
