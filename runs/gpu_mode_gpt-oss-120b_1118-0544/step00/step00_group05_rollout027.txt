Goal: Implement TriMul forward pass, but must use at least part of operations in a Triton kernel. The rest may be done in PyTorch.

The kernel must compute out = einsum('... i k d, ... j k d -> ... i j d', left, right). That's the key heavy part, O(N^3 * hidden_dim). The rest is normalization (LayerNorm), linear projections, gating (sigmoids) - can be done in PyTorch (including left_gate, right_gate, out_gate). After computing out, apply to_out_norm (LayerNorm) and to_out linear.

We want runtime optimization. However, given the AI environment, focusing on correctness is fine; runtime faster but not too heavy constraint.

We need to support up to N = 1024, hidden_dim could be 128, dim up to 384.

Our kernel: Input left: [B, N, N, hidden_dim], same shape as right. Compute out: [B, N, N, hidden_dim] where out[b,i,j,d] = sum_k left[b,i,k,d] * right[b,j,k,d].

Thus it's like for each batch b and each head channel d, we multiply left matrix (N x N) and right matrix (N x N) but transposed differently: left has dimensions (i, k) and right (j, k). Summing over k yields something like left @ right^T? Actually if we consider left[b,:, :, d] as an N x N matrix with rows i, columns k. Right[b,:, :, d] as N x N matrix with rows j, columns k? Because right[b, j, k, d] uses j as first index, but we sum over k; both left and right use k as second axis. So out[i,j] = sum_k left[i, k] * right[j, k]; This is left * right^T (dot product of row i of left with row j of right). Equivalent to left @ right.T.

Thus for each hidden dim d, we do matmul of left (N x N) with right (N x N). But note: left and right are not transposed: right_jk not right_kj. So it's left * right.T.

Thus we can compute for each d and batch, the matrix multiplication left[b,:, :, d] (N,N) with right[b,:, :, d].T (N,N). Complexity N^3 per d.

Thus we can implement this as a kernel that performs batched matmul across the hidden dim. We could also collapse hidden dim into channels (C) and compute using Triton's batched matmul for each d simultaneously (like depending on block size of hidden dim). But we can also treat hidden dim as separate independent matmul tasks.

Simplifications: Use PyTorch's torch.einsum directly, but that would not use Triton; we must incorporate a Triton kernel.

We could implement a custom kernel that for each batch b and hidden dim d computes a matrix multiplication using tile algorithm: the typical Triton matmul kernel behavior but with 3 axes: we want compute C = A @ B^T where A, B are N x N; C is N x N.

We can implement a kernel that loops over the k dimension in blocks (BLOCK_K). Use block sizes for M and N (i.e., for output i,j). Use tl.dot for dot product.

The earlier example code shows a matmul kernel that handles A[M,K], B[K,N] -> C[M,N]. That code can be adapted.

Specifically, we can call the kernel per (batch, d) pair. That would mean launching kernel with number of blocks = B * hidden_dim * ceil(N / BLOCK_M) * ceil(N / BLOCK_N). That may be large but okay.

Alternatively, we can vectorize hidden_dim dimension in registers: treat hidden_dim as extra dimension within each thread.

But hidden_dim is small (128), and we can compute that as separate independent kernels, but launching many kernels may cause overhead. Alternatively we can compute block of hidden dims per thread using vectorized loads (like load a block of hidden_dim elements per (i,j) tile). For simplicity implement kernel where each thread block handles a tile of output (i0..i0+BLOCK_M, j0..j0+BLOCK_N) and accumulates over k in blocks of size BLOCK_K. def trmul_outgoing_kernel(
    left_ptr, right_ptr, out_ptr,
    B, N, hidden_dim,
    stride_left_b, stride_left_i, stride_left_k, stride_left_d,
    stride_right_b, stride_right_j, stride_right_k, stride_right_d,
    stride_out_b, stride_out_i, stride_out_j, stride_out_d,
    BLOCK_M: tl.constexpr, BLOCK_N: tl.constexpr, BLOCK_K: tl.constexpr,
    BLOCK_D: tl.constexpr
):
    pid = tl.program_id(0)
    batch_idx = tl.program_id(1)
    d_chunk = tl.program_id(2)

    # compute tile indices
    num_tiles_n = tl.cdiv(N, BLOCK_N)
    tile_i = pid // num_tiles_n
    tile_j = pid % num_tiles_n

    i0 = tile_i * BLOCK_M
    j0 = tile_j * BLOCK_N
    d0 = d_chunk * BLOCK_D

    # coordinate offsets
    offs_i = i0 + tl.arange(0, BLOCK_M)
    offs_j = j0 + tl.arange(0, BLOCK_N)
    offs_k = tl.arange(0, BLOCK_K)
    offs_d = d0 + tl.arange(0, BLOCK_D)

    # mask for out-of-range
    mask_i = offs_i < N
    mask_j = offs_j < N
    mask_k = offs_k < N
    mask_d = offs_d < hidden_dim

    # compute batch offset
    batch_off = batch_idx * stride_left_b

    # loop over d within block
    for d_idx in range(0, BLOCK_D):
        # compute actual d
        d = d0 + d_idx
        # only compute if d < hidden_dim
        if d_idx >= hidden_dim - d0:
            # break early if no more d remains
            break
        # allocate accumulator
        acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)
        # loop over k blocks
        for kk in range(0, tl.cdiv(N, BLOCK_K)):
            k0 = kk * BLOCK_K
            # compute offsets for this block
            cur_offs_k = k0 + offs_k
            cur_mask_k = cur_offs_k < N

            # left pointer: b, i, k, d
            left_ptrs = left_ptr + batch_off + \
                (offs_i[:, None] * stride_left_i) + \
                (cur_offs_k[None, :] * stride_left_k) + \
                d * stride_left_d
            # right pointer transposed (k,j)

                (cur_offs_k[:, None] * stride_right_k) + \
                (offs_j[None, :] * stride_right_j) + \
                d * stride_right_d

            # load with masks
            left = tl.load(left_ptrs, mask=mask_i[:, None] & cur_mask_k[None, :], other=0.0)
            right = tl.load(right_ptrs, mask=cur_mask_k[:, None] & mask_j[None, :], other=0.0)

            # compute dot product
            acc += tl.dot(left, right)
        # store to output
        out_ptrs = out_ptr + batch_off + \
            (offs_i[:, None] * stride_out_i) + \
            (offs_j[None, :] * stride_out_j) + \
            d * stride_out_d
        tl.store(out_ptrs, acc, mask=mask_i[:, None] & mask_j[None, :])
    # end of kernel

@triton.jit
def trmul_outgoing_kernel(
    left_ptr, right_ptr, out_ptr,
    B, N, hidden_dim,
    stride_left_b, stride_left_i, stride_left_k, stride_left_d,
    stride_right_b, stride_right_j, stride_right_k, stride_right_d,
    stride_out_b, stride_out_i, stride_out_j, stride_out_d,
    BLOCK_M: tl.constexpr, BLOCK_N: tl.constexpr,
    BLOCK_K: tl.constexpr, BLOCK_D: tl.constexpr):
  
    pid = tl.program_id(0)
    batch_idx = tl.program_id(1)
    d_chunk = tl.program_id(2)

    # Compute tile indices
    num_tiles_n = tl.cdiv(N, BLOCK_N)
    tile_i = pid // num_tiles_n
    tile_j = pid % num_tiles_n

    i0 = tile_i * BLOCK_M
    j0 = tile_j * BLOCK_N
    d0 = d_chunk * BLOCK_D

    # Offsets for each dimension
    offs_i = i0 + tl.arange(0, BLOCK_M)
    offs_j = j0 + tl.arange(0, BLOCK_N)
    offs_k = tl.arange(0, BLOCK_K)
    offs_d = d0 + tl.arange(0, BLOCK_D)

    # Bounds masks
    mask_i = offs_i < N
    mask_j = offs_j < N
    mask_k = offs_k < N
    mask_d = offs_d < hidden_dim

    batch_offset = batch_idx * stride_left_b

    # Loop over d within the block
    for d_off in range(0, BLOCK_D):
        # current hidden index
        d = d0 + d_off
        # Skip if out of range
        if d >= hidden_dim:
            break
        acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

        # Loop over K dimension blocks
        num_k_blocks = tl.cdiv(N, BLOCK_K)
        for kb in range(0, num_k_blocks):
            k0 = kb * BLOCK_K
            cur_k = k0 + offs_k
            cur_mask_k = cur_k < N

            # pointers for left: (i,k,d)
            left_ptrs = left_ptr + batch_offset + \
                (offs_i[:, None] * stride_left_i) + \
                (cur_k[None, :] * stride_left_k) + \
                d * stride_left_d

            # pointers for right transposed: (k,j,d)
            right_ptrs = right_ptr + batch_offset + \
                (cur_k[:, None] * stride_right_k) + \
                (offs_j[None, :] * stride_right_j) + \
                d * stride_right_d

            # load with masking
            left = tl.load(left_ptrs,
                           mask=mask_i[:, None] & cur_mask_k[None, :],
                           other=0.0)
            right = tl.load(right_ptrs,
                            mask=cur_mask_k[:, None] & mask_j[None, :],
                            other=0.0)

            # accumulate dot product
            acc += tl.dot(left, right)

        # Store result
        out_ptrs = out_ptr + batch_offset + \
            (offs_i[:, None] * stride_out_i) + \
            (offs_j[None, :] * stride_out_j) + \
            d * stride_out_d

                 acc,
                 mask=mask_i[:, None] & mask_j[None, :])

"""
Outgoing Triangle Multiplicative Update (TriMul) implemented with Triton.

Algorithm
---------
1. Layer‑norm the [B, N, N, dim] input.
2. Linear projections to hidden_dim (left/right) and three gating vectors
   (left_gate, right_gate, out_gate).  Mask (if provided) is applied to the
   projected tensors before gating.
3. Core O(N³·hidden_dim) contraction:
        out[b, i, j, d] = Σ_k left[b, i, k, d] * right[b, j, k, d]
   This is a batched matrix multiplication left @ rightᵀ for each hidden
   channel.  The contraction is performed by a Triton kernel that tiles the
   i, j, k dimensions and also iterates over the hidden dimension in small
   blocks (BLOCK_D).
4. Layer‑norm over the hidden dimension, element‑wise multiplication with
   out_gate, and a final linear projection back to the original dim.

The kernel is written for float32 (the model weights and inputs are float32)
and uses modest tile sizes (32×32×32) that fit well on a B200 GPU while
supporting all test configurations.
"""

import torch
import triton
import triton.language as tl


@triton.jit
def trmul_outgoing_kernel(
    left_ptr,    # const float*  [B, N, N, hidden]
    right_ptr,   # const float*  [B, N, N, hidden]
    out_ptr,     # float*        [B, N, N, hidden]
    B, N, hidden_dim,
    stride_left_b, stride_left_i, stride_left_k, stride_left_d,
    stride_right_b, stride_right_j, stride_right_k, stride_right_d,
    stride_out_b, stride_out_i, stride_out_j, stride_out_d,
    BLOCK_M: tl.constexpr, BLOCK_N: tl.constexpr,
    BLOCK_K: tl.constexpr, BLOCK_D: tl.constexpr
):
    """
    Compute out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d].

    Grid:
        program_id(0) -> (tile_i, tile_j) flattened
        program_id(1) -> batch index
        program_id(2) -> hidden‑dim chunk index (size BLOCK_D)
    """
    pid = tl.program_id(0)
    batch_idx = tl.program_id(1)
    d_chunk = tl.program_id(2)

    # ----------------------------------------------------------------------
    # Tile indices
    # ----------------------------------------------------------------------
    num_tiles_n = tl.cdiv(N, BLOCK_N)
    tile_i = pid // num_tiles_n
    tile_j = pid % num_tiles_n

    i0 = tile_i * BLOCK_M
    j0 = tile_j * BLOCK_N
    d0 = d_chunk * BLOCK_D

    # Offsets for each dimension
    offs_i = i0 + tl.arange(0, BLOCK_M)
    offs_j = j0 + tl.arange(0, BLOCK_N)
    offs_k = tl.arange(0, BLOCK_K)
    offs_d = d0 + tl.arange(0, BLOCK_D)

    # Boundary masks
    mask_i = offs_i < N
    mask_j = offs_j < N
    mask_k = offs_k < N
    mask_d = offs_d < hidden_dim

    # Base offset for the current batch
    batch_off = batch_idx * stride_left_b

    # ----------------------------------------------------------------------
    # Loop over hidden‑dim sub‑block
    # ----------------------------------------------------------------------
    for d_off in range(0, BLOCK_D):
        d = d0 + d_off                # absolute hidden index
        if d >= hidden_dim:
            break                     # past the actual hidden dimension

        # accumulator for the (BLOCK_M, BLOCK_N) tile of this hidden channel
        acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

        # ------------------------------------------------------------------
        # Loop over K dimension in tiles
        # ------------------------------------------------------------------
        num_k_blocks = tl.cdiv(N, BLOCK_K)
        for kb in range(0, num_k_blocks):
            k0 = kb * BLOCK_K
            cur_k = k0 + offs_k
            cur_mask_k = cur_k < N

            # left[b, i, k, d]  -> shape (BLOCK_M, BLOCK_K)
            left_ptrs = left_ptr + batch_off + \
                (offs_i[:, None] * stride_left_i) + \
                (cur_k[None, :] * stride_left_k) + \
                d * stride_left_d

            # right[b, j, k, d] transposed to (k, j) -> shape (BLOCK_K, BLOCK_N)
            right_ptrs = right_ptr + batch_off + \
                (cur_k[:, None] * stride_right_k) + \
                (offs_j[None, :] * stride_right_j) + \
                d * stride_right_d

            left = tl.load(
                left_ptrs,
                mask=mask_i[:, None] & cur_mask_k[None, :],
                other=0.0
            )
            right = tl.load(
                right_ptrs,
                mask=cur_mask_k[:, None] & mask_j[None, :],
                other=0.0
            )
            acc += tl.dot(left, right)   # (M,K) @ (K,N) -> (M,N)

        # ------------------------------------------------------------------
        # Store the tile back to global memory
        # ------------------------------------------------------------------
        out_ptrs = out_ptr + batch_off + \
            (offs_i[:, None] * stride_out_i) + \
            (offs_j[None, :] * stride_out_j) + \
            d * stride_out_d

        tl.store(
            out_ptrs,
            acc,
            mask=mask_i[:, None] & mask_j[None, :]
        )
