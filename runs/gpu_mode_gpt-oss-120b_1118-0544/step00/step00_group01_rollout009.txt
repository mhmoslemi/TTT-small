analysisWe need to implement a Triton kernel for the TriMul operation. Problem wants us to implement an outgoing version (e.g., left and right are projected and multiplied, then out_gate applied). The kernel must compute the contraction `out[b,i,j,d] = sum_{k} left[b,i,k,d] * right[b,j,k,d]`. The rest of the pipeline (LayerNorm, Linear projections, gates, mask, final LayerNorm, final linear) can be done in PyTorch.

Implementation details:

- Input shape: [B, N, N, C], where C = dim (original dim). We need config dim (input dimension) and hidden_dim (e.g., the inner dimension). The linear layers: left_proj, right_proj, left_gate, right_gate, out_gate map from dim to hidden_dim (C -> hidden_dim). Because linear projects (weights shape [hidden_dim, dim]) presumably (like nn.Linear without bias). Actually default nn.Linear weight is shape (out_features, in_features). So left_proj is weight shape [hidden_dim, dim]. Right_proj same. Gates also [hidden_dim, dim]. To_out_norm: layernorm of hidden_dim, to_out: weight shape [dim, hidden_dim] (since Linear dim from hidden_dim->dim). Actually to_out weight shape [dim, hidden_dim] (out_features=dim). Since bias disabled for all linear except layernorm.

The algorithm flow:

1. input_tensor shape [B, N, N, C].
2. Apply LayerNorm over C (last dim). LayerNorm weight and bias provided. We'll use torch.nn.functional.layer_norm or manually.

3. Compute left_proj = torch.einsum('...c,hd->...d', x_norm, left_proj_weight.T) is basically a linear. But we can do x_norm @ left_proj_weight.T.

   Since weight shape is [hidden_dim, dim]. We'll compute left = x_norm @ left_proj_weight.T  (or x_norm @ weight.t()).

4. Compute right_proj similarly.

5. Apply mask: If mask is provided (tensor shape [B,N,N]), then mask = mask.unsqueeze(-1) and apply to left and right: left = left * mask; right = right * mask.

6. Compute gates: left_gate = torch.sigmoid(x_norm @ left_gate_weight.T); similarly for right_gate and out_gate.

   Multiply left by left_gate, right by right_gate: left = left * left_gate, right = right * right_gate.

   Note: left_gate shape matches left (B,N,N,hidden_dim) as gates broadcast.

7. We have left and right each shape [B,N,N,hidden_dim] after gating.

8. Compute out = triMul contraction (einsum) across k dimension (the second sequence dimension): out[b,i,j,d] = sum_k left[b,i,k,d] * right[b,j,k,d].

def custom_kernel(data):
    input_tensor, mask, weights, config = data
    bs, N, _, C = input_tensor.shape
    H = config["hidden_dim"]
    # ensure input shape: [bs, N, N, C]

    # LayerNorm
    x = torch.nn.functional.layer_norm(input_tensor, normalized_shape=(C,),
        weight=weights["norm.weight"], bias=weights["norm.bias"])

    # Linear projections (no bias)
    left_proj = torch.nn.functional.linear(x, weight=weights["left_proj.weight"])
    right_proj = torch.nn.functional.linear(x, weight=weights["right_proj.weight"])

    # Apply mask if present
    if mask is not None:
        mask = mask.unsqueeze(-1)  # shape [bs, N, N, 1]
        left_proj = left_proj * mask
        right_proj = right_proj * mask

    # Gates
    left_gate = torch.nn.functional.linear(x, weight=weights["left_gate.weight"]).sigmoid()
    right_gate = torch.nn.functional.linear(x, weight=weights["right_gate.weight"]).sigmoid()
    out_gate = torch.nn.functional.linear(x, weight=weights["out_gate.weight"]).sigmoid()

    left = left_proj * left_gate
    right = right_proj * right_gate

    # Cast to float32 (if not already)
    left = left.contiguous()
    right = right.contiguous()
    # Proceed to Triton kernel

    # Output buffer
    out_hidden = torch.empty((bs, N, N, H), dtype=left.dtype, device=left.device)

    # Compute strides in elements
    stride_left = left.stride()  # tuple length 4: b,i,k,h
    stride_right = right.stride()
    stride_out = out_hidden.stride()

    # Block sizes
    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 64

    # Grid dimensions
    num_bh = bs * H
    grid = (num_bh,
            (N + BLOCK_M - 1) // BLOCK_M,
            (N + BLOCK_N - 1) // BLOCK_N)

    tri_mul_contract_kernel[grid](
        left,
        right,
        out_hidden,
        bs, N, H,
        stride_left[0], stride_left[1], stride_left[2], stride_left[3],
        stride_right[0], stride_right[1], stride_right[2], stride_right[3],
        stride_out[0], stride_out[1], stride_out[2], stride_out[3],
        BLOCK_M=BLOCK_M, BLOCK_N=BLOCK_N, BLOCK_K=BLOCK_K
    )
    # Apply to_out_norm
    out_normed = torch.nn.functional.layer_norm(out_hidden, normalized_shape=(H,),
        weight=weights["to_out_norm.weight"],
        bias=weights["to_out_norm.bias"])

    # Apply out gate
    out_normed = out_normed * out_gate

    # Final linear projection
    out = torch.nn.functional.linear(out_normed, weight=weights["to_out.weight"])

    return out
```

import triton
import triton.language as tl

@triton.jit
def tri_mul_contract_kernel(
    left_ptr, right_ptr, out_ptr,
    B, N, H,
    stride_left_b, stride_left_i, stride_left_k, stride_left_h,
    stride_right_b, stride_right_j, stride_right_k, stride_right_h,
    stride_out_b, stride_out_i, stride_out_j, stride_out_h,
    BLOCK_M: tl.constexpr, BLOCK_N: tl.constexpr, BLOCK_K: tl.constexpr
):
    # program ids
    pid0 = tl.program_id(0)  # combined batch and hidden dim
    pid1 = tl.program_id(1)  # i tile
    pid2 = tl.program_id(2)  # j tile

    # compute batch and hidden dim indices
    b = pid0 // H
    h = pid0 % H

    # compute start offsets for i and j
    i_start = pid1 * BLOCK_M
    j_start = pid2 * BLOCK_N

    # create range vectors
    offs_i = i_start + tl.arange(0, BLOCK_M)
    offs_j = j_start + tl.arange(0, BLOCK_N)
    offs_k = tl.arange(0, BLOCK_K)

    # mask for i,j within N bounds
    mask_i = offs_i < N
    mask_j = offs_j < N

    # compute base pointers for this batch and hidden dim
    # offsets need to include b and h
    # left base offset = b*stride_left_b + h*stride_left_h
    # right base offset = b*stride_right_b + h*stride_right_h
    # out base offset = b*stride_out_b + h*stride_out_h

    left_base = b * stride_left_b + h * stride_left_h
    right_base = b * stride_right_b + h * stride_right_h
    out_base = b * stride_out_b + h * stride_out_h

    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # loop over k
    num_k = (N + BLOCK_K - 1) // BLOCK_K
    for k_iter in range(num_k):
        k_start = k_iter * BLOCK_K
        offs_k_cur = k_start + offs_k

"""
TriMul (outgoing) forward pass implemented with a fused Triton kernel.

The kernel computes, for each batch b and hidden channel h:

    out[b, i, j, h] = Σ_k left[b, i, k, h] * right[b, j, k, h]

where `left` and `right` are the gated linear projections of the normalized
input. This is the costly O(N³·H) contraction and is performed in a
blocked GEMM style using Triton. All other operations (LayerNorms, linear
projections, gates, final projection) are done in PyTorch for simplicity.
"""
import torch
import triton
import triton.language as tl

@triton.jit
def tri_mul_contract_kernel(
    left_ptr, right_ptr, out_ptr,
    B, N, H,
    stride_left_b, stride_left_i, stride_left_k, stride_left_h,
    stride_right_b, stride_right_j, stride_right_k, stride_right_h,
    stride_out_b, stride_out_i, stride_out_j, stride_out_h,
    BLOCK_M: tl.constexpr, BLOCK_N: tl.constexpr, BLOCK_K: tl.constexpr
):
    # program IDs
    pid0 = tl.program_id(0)  # combined batch * hidden
    pid1 = tl.program_id(1)  # i tile
    pid2 = tl.program_id(2)  # j tile

    # Decode batch and hidden dimension
    b = pid0 // H
    h = pid0 % H

    # Tile offsets
    i_start = pid1 * BLOCK_M
    j_start = pid2 * BLOCK_N

    # Range vectors
    offs_i = i_start + tl.arange(0, BLOCK_M)
    offs_j = j_start + tl.arange(0, BLOCK_N)
    offs_k = tl.arange(0, BLOCK_K)

    # Bounds masks
    mask_i = offs_i < N
    mask_j = offs_j < N

    # Base pointer offsets for the current (b, h)
    left_base = b * stride_left_b + h * stride_left_h
    right_base = b * stride_right_b + h * stride_right_h
    out_base = b * stride_out_b + h * stride_out_h

    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # Loop over the reduction dimension k
    num_k = (N + BLOCK_K - 1) // BLOCK_K
    for k_iter in range(num_k):
        k_start = k_iter * BLOCK_K
        cur_k = k_start + offs_k
        mask_k = cur_k < N

        # ---- Load left tile (M x K) ----
        # left[b, i, k, h] --> strides: i, k
        left_ptrs = left_base + (offs_i[:, None] * stride_left_i) + (cur_k[None, :] * stride_left_k)
        left = tl.load(left_ptrs,
                       mask=mask_i[:, None] & mask_k[None, :],
                       other=0.0).to(tl.float32)

        # ---- Load right tile (K x N) ----
        # right[b, j, k, h] --> we need (k, j) ordering for dot
        right_ptrs = right_base + (offs_j[None, :] * stride_right_j) + (cur_k[:, None] * stride_right_k)
        right = tl.load(right_ptrs,
                        mask=mask_j[None, :] & mask_k[:, None],
                        other=0.0).to(tl.float32)

        # ---- Accumulate block matrix product ----
        acc += tl.dot(left, right)   # (M,K) @ (K,N) -> (M,N)

    # ---- Store the computed block ----
    out_ptrs = out_base + (offs_i[:, None] * stride_out_i) + (offs_j[None, :] * stride_out_j)
    tl.store(out_ptrs,
            acc,
            mask=mask_i[:, None] & mask_j[None, :])


def custom_kernel(data):
    """
    Forward pass of the TriMul (outgoing) module.
    Arguments:
        data: tuple (input_tensor, mask_tensor, weights_dict, config_dict)
    Returns:
        Tensor with shape [bs, seq_len, seq_len, dim] (float32).
    """
    input_tensor, mask, weights, config = data
    device = input_tensor.device
    dtype = input_tensor.dtype

    bs, seq_len, _, dim = input_tensor.shape
    hidden_dim = config["hidden_dim"]
    nomask = config.get("nomask", True)

    # ---------- LayerNorm ----------
    x = torch.nn.functional.layer_norm(
        input_tensor,
        normalized_shape=(dim,),
        weight=weights["norm.weight"],
        bias=weights["norm.bias"],
    )

    # ---------- Linear projections ----------
    left_proj = torch.nn.functional.linear(x, weights["left_proj.weight"])   # [B,N,N,H]
    right_proj = torch.nn.functional.linear(x, weights["right_proj.weight"])

    # ---------- Apply mask ----------
    if not nomask and mask is not None:
        mask = mask.to(dtype=dtype).unsqueeze(-1)       # [B,N,N,1]
        left_proj = left_proj * mask
        right_proj = right_proj * mask

    # ---------- Gates ----------
    left_gate = torch.nn.functional.linear(x, weights["left_gate.weight"]).sigmoid()
    right_gate = torch.nn.functional.linear(x, weights["right_gate.weight"]).sigmoid()
    out_gate = torch.nn.functional.linear(x, weights["out_gate.weight"]).sigmoid()

    left = left_proj * left_gate   # [B,N,N,H]
    right = right_proj * right_gate

    # Ensure contiguous layout for Triton
    left = left.contiguous()
    right = right.contiguous()

    # ---------- Triton contraction ----------
    out_hidden = torch.empty((bs, seq_len, seq_len, hidden_dim),
                             dtype=left.dtype,
                             device=device)

    # Strides in elements (not bytes)
    sL_b, sL_i, sL_k, sL_h = left.stride()
    sR_b, sR_j, sR_k, sR_h = right.stride()
    sO_b, sO_i, sO_j, sO_h = out_hidden.stride()

    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 64

    grid = (
        bs * hidden_dim,                     # batch * hidden
        (seq_len + BLOCK_M - 1) // BLOCK_M, # i tiles
        (seq_len + BLOCK_N - 1) // BLOCK_N  # j tiles
    )

    tri_mul_contract_kernel[grid](
        left,
        right,
        out_hidden,
        bs, seq_len, hidden_dim,
        sL_b, sL_i, sL_k, sL_h,
        sR_b, sR_j, sR_k, sR_h,
        sO_b, sO_i, sO_j, sO_h,
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
    )

    # ---------- Final LayerNorm, gating and output projection ----------
    out_normed = torch.nn.functional.layer_norm(
        out_hidden,
        normalized_shape=(hidden_dim,),
        weight=weights["to_out_norm.weight"],
        bias=weights["to_out_norm.bias"],
    )
    out_normed = out_normed * out_gate
    out = torch.nn.functional.linear(out_normed, weights["to_out.weight"])

    return out
