 Steps from the original PyTorch implementation:
  1. Apply LayerNorm to the input tensor.
  2. Project the tensor using two linear layers (left_proj, right_proj) to get two tensors [B, N, N, hidden_dim].
  3. If mask is provided, apply it element-wise.
  4. Compute three gating vectors (left_gate, right_gate, out_gate) with sigmoid activation from the input tensor (using the provided linear weights).

  6. The core operation: out[b,i,j,d] = sum_{k} (left[b,i,k,d] * right[b,j,k,d])
     This is equivalent to a matrix multiplication in the form: left[b, i, :, :] @ right[b, j, :, :] for each (b,i,j) and d.
