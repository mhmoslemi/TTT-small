We are implementing the outgoing version of the TriMul operator as described in the AlphaFold3 paper.
 The operator is defined on a 4D tensor [B, N, N, C]. The steps are:

 1. Apply LayerNorm to the input tensor (float32 for numerical stability).
 2. Project the input tensor to hidden_dim using two linear layers (left_proj and right_proj) in fp16.
 3. Compute three gates: left_gate (sigmoid of left_proj), right_gate (sigmoid of right_proj), and out_gate (sigmoid of out_gate projection).
 4. If mask is present, apply it and the gates using a masked operation (element-wise multiplication with mask and gates).
 5. Compute the core contraction: out = (L @ R)   # where L and R are the projected tensors and the operation is over the sequence length (N) and hidden_dim (H)
    Specifically: for each i, j, k: 
        out[b, i, j, d] = sum_{k} left[b, i, k, d1] * right[b, j, k, d2] for d1, d2 in the hidden_dim.
 6. Apply a LayerNorm to the hidden_dim output, multiply by out_gate, and then project back to the original dimension.
 7. Cast the output back to the original dtype and return.
