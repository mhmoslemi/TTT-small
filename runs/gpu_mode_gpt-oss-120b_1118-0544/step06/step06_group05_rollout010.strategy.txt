   **Approach and Rationale**

   We are to implement the outgoing version of the TriMul operator, which is a core part of AlphaFold3 and other BioML models.    The input tensor has shape [B, N, N, C] (after LayerNorm, [B, N, N, dim]). We will do four-dimensional tensor reshaping for the kernel. The operation is defined as:
