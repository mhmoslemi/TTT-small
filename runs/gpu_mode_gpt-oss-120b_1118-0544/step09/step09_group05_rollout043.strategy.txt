*The core goal is to implement the outgoing Triangle Multiplicative Update (TriMul) operator used in AlphaFold3 and other protein structure prediction models. The operator performs a fused operation involving layer normalization, linear projections, gating, and a reduction over the sequence length. The primary bottleneck is the reduction for outgoing edges, which scales as O(N^3) for sequence length N, making it critical to optimize. We will implement:
    - Layer normalization for input
    - Linear projections and gating in Python
    - Reduction kernel in Triton that computes outgoing edges
    - Output LayerNorm and projection
*Key limitations:*
    - The reduction kernel listed indices as 
    - We must handle large N values efficiently
</strategy>

**Mathematical specification**
```
out[b, i, j, h] = Σ_k (left[b, i, k, h] * right[b, j, k, h])
```
*Constraints:* 
    - `N` can be up to 1024
    - If a mask is present, this index `h` must be nonzero
    - We must use `triton.config.DEFAULT` for the kernel
