 The input is a 4D tensor [B, N, N, C] and an optional mask [B, N, N] (boolean or float).
 The module has the following structure:

 1. Normalize the input with LayerNorm.
 2. Project the normalized tensor with two linear layers (left_proj and right_proj) and two gating layers (left_gate and right_gate), but note the paper uses an "outgoing" version which is defined by a triple product.
