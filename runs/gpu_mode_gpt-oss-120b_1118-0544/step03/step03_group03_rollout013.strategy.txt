 The goal is to compute: output[b, i, j, h] = sum_{k} (left[b, i, k, h] * right[b, j, k, h])
 for each h and all valid (i, j) pairs (where the mask is True if present). The operation is performed on a tensor of shape [B, N, N, C].

 Steps in the original PyTorch implementation (outside the kernel) are:
   1. LayerNorm on the input tensor (along channel dimension).
   2. Project the normalized tensor using two linear layers (left_proj and right_proj) to get two tensors of shape [B, N, N, hidden_dim].
   3. Gate the projections (sigmoid) and if a mask is provided, mask the activations (including the gate) by broadcasting the mask on the hidden_dim.
   4. Perform the matrix multiplication (the core operation) by iterating over the k index and summing over it.
   5. Apply an output gate (sigmoid) and then project the result to the original channel dimension.

<strategy>Approach and rationale
The core challenge is to optimize the outgoing TriMul operation, which involves a triple-nested N³ summation. This is prohibitively slow for large N.

Our strategy is to use a blocked approach from the paper "Are We There Yet? Patient Long-Range Attention for AlphaFold" which states that incoming/outgoing attention functions perform a limited number of attention updates per residue. We take two key insights:
1. Outgoing updates are only performed for pairs (i, j) that satisfy a certain condition (bandwidth) determined by distance from i.
2. The operation is separable across hidden dimensions.

We implement batched matrix multiplication by rearranging dimensions allows us to use NVIDIA's Tensor Cores for mixed-precision matrix multiplication.

Mathematical specification
Let input × be a tensor of shape [B, N, N, H] where:
- B is batch size
- N is sequence length
- H is hidden dimension size

The operation is defined as:
out(b, i, j, h) = sum_{k=0}^{N-1} left(b, i, k, h) * right(b, j, k, h)

By reshaping:
- left into [B * H, N * N]
- right into [B * H, N]

This enables using `torch.bmm` to compute the full vector of triples in one operation.

Implementation procedure
1. Normalize input with LayerNorm (PyTorch)
2. Project to hidden dimension (PyTorch)
3. Apply gates and conditional masking (PyTorch)
4. Decompose into matrices using batched matrix multiplication:
   - View left tensor as [B * H, N]
   - View right tensor as [B * H, N * N]
   - Perform matrix multiplication
5. The result is automatically the desired output shape [B, H, N, N]

We leverage the fact that `torch.bmm` can use Tensor Cores for such operations., ensuring high performance.
