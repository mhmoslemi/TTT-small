**Approach and rationale:**
The Triangular Multiplicative Update (TriMul) operator from AlphaFold3 involves three core components: normalization, projection, gating, and triangular reduction. The triangular reduction is particularly critical, involving an O(N^3) computation due to the sequence-length dimensions. The outgoing version requires masking pairs where i < j, effectively disabling the lower triangle of the resulting 4D tensor. Accuracy and performance are intertwined, as the reduction must be correctly computed while the optional input mask must overwrite the triangular mask at specific positions. The implementation must avoid unnecessary computations in masked regions, use appropriate data types for efficiency, and cache convolution and pooling operations to reduce kernel launch overhead. This approach focuses on performance via direct indexing and reduction, ensuring correctness regardless of mask conditions.

**Mathematical specification:**
1. **Normalization**:  
   Perform LayerNorm on input `x` with `dim=C` using mean and variance computed from `x`.  
   Let `mu = mean` and `var = variance`, then normalized `x` is `x_norm = (x - mu) / sqrt(var + eps)`.
   Normalizing parameters include `norm_weight`, `norm_bias`, `eps`, and `affine` (if applicable).

2. **Projection**:  
   Project the normalized input to `hidden_dim` using two linear layers (`left_proj`, `right_proj`).  
   `left_proj` = `input` @ `left_proj_matrix` (with optional bias). Similarly for `right_proj`.  
   The matrix operations must be fused and packed for seam imprint efficient.

3. **Gating**:  
   Apply gating functions to the projected outputs:  
   `left_after_gate = left * left_gate.sigmoid()`  
   `right_after_gate = right * right_gate.sigmoid()`
   These are incorporated via matrix multiplication without separate sigmoid operations.

4. **Reduction**:  
   Compute the triangular reduction:  
   `output[b, i, j, h] = sum_{k} (left_after_gate[b, i, k] * right_after_gate[b, j, k])`
   output for `i >= j` is forced to `0`, while the input mask (if present) may further zero portions of the upper triangle.  
   We use the input mask to overwrite the triangular mask at specific positions if provided.

5. **Output**:  
   Apply final output_gate.sigmoid(), then project back to original `dim` using `to_out_linear`, normalize, and cast to `float32`.
