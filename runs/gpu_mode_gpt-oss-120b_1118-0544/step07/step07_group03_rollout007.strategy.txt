The core operation is a reduction that involves computing a gemm (batched matrix multiplication) over the sequence dimension for every pair of residues and every channel. Specifically, for each batch b and each channel d, we have a matrix A of shape [N, N] and a matrix B of shape [N, N] (both are the same size) and we want to compute:

  out[b, i, j, d] = sum_{k} (left[b, i, k, d] * right[b, j, k, d])

where left and right are computed from the input and weights via linear projections and gated activation by a sigmoid. Additionally, if a mask is provided (and option not to ignore it), it is applied elementwise.

Steps in PyTorch:
1. LayerNorm on the input tensor along the channel dimension (last dimension). This normalizes the input so that each channel has mean 0 and variance 1.
