 2. Project the tensor to a hidden dimension using left_proj and right_proj (both linear layers).
 3. Compute the gates (left_gate, right_gate, out_gate) using sigmoid activation on the projected tensors.
 4. If mask is present, multiply the projected tensors (left and right) by the mask (broadcasted over hidden dimension).
 5. Perform a batched matrix multiplication (GEMM) over the sequence dimension N, for each (B, hidden_dim) as a batch and for each channel in the hidden_dim, but note the operation is:

    out[b, i, j, d] = sum_{k=0}^{N-1} (left_proj[b, i, k, d] * right_proj[b, j, k, d])

    This can be seen as: for each batch b and output channel d, we compute a matrix (N x N) by doing two matrix multiplications (with one being transposed appropriately) and then multiplying the two matrices and summing over the k dimension.
