                1/ Background: The TriMul operator is defined as follows in the AlphaFold3 paper for the outgoing version:

        Let x = input tensor [B, N, N, C]
        Let mask = optional mask [B, N, N]

        Let hidden_dim = H

        Steps:
            1. x = LayerNorm(x, ...)
            2. left = Linear(x) -> [B, N, N, H]
            3. right = Linear(x) -> [B, N, N, H]
            4. If mask is provided, set left = left * (broadcasted mask) and similarly for right.
            5. For each (i, j) and (b), the value out[b,i,j] is computed as a weighted sum over k from 0 to N-1 of 
               left[b,i,k] * right[b,j,k], where the weight is a sigmoid gating function for each of left and right.
            6. Then apply a final sigmoid gating and linear projection to the output.

        However, the provided code does an element-wise multiplication by the gating functions and the mask, then a reduction.

        The reduction is a form of dot product attention over the k-axis.

        Due to the high cost of the reduction (O(N^3) for each (i,j) in the tensor), Triton is a good choice for acceleration.
