 The main idea is to break down the operation and use tensor cores efficiently by collapsing dimensions appropriately.

 Steps:
 1. LayerNorm on input (channel dimension: dim)
 2. Linear projections (left_proj, right_proj, left_gate, right_gate, out_gate) into hidden_dim (using FP16)
 3. Optional masking (elementwise multiplication of left_proj/right_proj by the mask, converted to FP16)
 4. Apply gating: elementwise multiplication of left_proj by left_gate and right_proj by right_gate (FP16)
 5. Batched GEMM: for each hidden channel, compute a matrix multiplication over the sequence dimension (N) for the batch.
    This is expensive because the sequence length N can be up to 1024, and we have to do it for each hidden channel (hidden_dim) and each batch element (B).
    We can break the operation into two steps:
        - First, compute the matrix multiplication for each hidden channel and each batch element. This is O(B * hidden_dim * N^2)
        - We can use caching and blocking to reduce the number of global memory accesses.

 7. Compute out_gate via linear projection and sigmoid (FP16)
 8. Elementwise multiply the output of the GEMM by the out_gate (using a Triton kernel) because it's a large matrix (N^2 in each batch element and hidden channel)
 9. Fully connected (linear) projection back to the original dim (using FP16)
