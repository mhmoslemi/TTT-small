We are implementing the outgoing version of the Triangle Multiplicative Update (TriMul) operator from AlphaFold3.
 The input is a 4D tensor of shape [B, N, N, C] and a binary mask of shape [B, N, N] (or None).
 Steps:
 1. Apply LayerNorm on the input tensor (along the H dimension, which is the channel dimension C).
 2. Project the normalized input to a hidden dimension H using two linear layers (left_proj and right_proj).
 3. If a mask is provided, multiply the projected tensors by the mask (broadcast to the hidden dimension).
 4. Compute three gates (sigmoid activations) using linear projections (left_gate, right_gate, out_gate).
 5. Multiply the left and right projected tensors by their gates.
 6. Perform a batched matrix multiplication (BMM) on the left and right tensors along the sequence length dimension (N).
    That is, for each batch and each hidden dimension, we do a batched matrix multiplication of two matrices of size [N, N].
 7. Normalize the result over the hidden dimension (to_out_norm) and multiply by the output gate (sigmoid).
 8. Project back to the original channel dimension and return.

 Constraints and considerations:
 - The input tensor and mask are on CUDA device.
 - We must support two distributions: 'normal' (normal) and 'cauchy'. Since the input distribution is used for correctness checks,
   we don't necessarily have to change the kernel, but note that the operations (like LayerNorm) are defined to work on these distributions.
   However, the kernel should be generic and work for any input distribution.
