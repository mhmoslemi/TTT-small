Let me also think about the binary local search more carefully.

For the binary case, the key operation is: find a swap (a in ones, b in zeros) that reduces the max correlation.

My approach:
1. Compute the full correlation.
2. Find the top M shifts by value (M = 5 or 10).
3. For each critical shift s, compute A_s(a) for all a in ones and B_s(b) for all b in zeros.
4. For each critical shift, the best swap is argmin_a A_s(a) + argmin_b B_s(b).
5. Collect all candidate swaps (at most M of them).
6. For each candidate, compute the full delta and check if the new max is lower.
7. Accept the best swap.

This is O(M * n + M * n) = O(Mn) per iteration (for computing A, B, and the full delta). With M=5 and n=600, that's ~6000 operations per iteration. Very fast.

Actually, I realize I can do even better. Instead of computing the full delta for each candidate, I can just check the critical shifts. If the swap reduces the max at the critical shift and doesn't increase any other critical shift above the old max, it's a good swap. This is a necessary (not sufficient) condition, but in practice it works well.

One more idea: **simulated annealing with the separable structure**.

In SA, I need to:
1. Generate a random swap (a, b).
2. Compute the change in the objective.
3. Accept or reject.

For the objective change, I need the full delta (to find the new max). This is O(n) per swap.

To speed this up, I can:
- Precompute the current max and its location.
- For the new max, I only need to check if any shift exceeds the old max.
- The delta at shift s is A_s(a) + B_s(b).
- So I need to check: max_s (corr[s] + A_s(a) + B_s(b)) < corr_max?
- This is O(n) in the worst case, but I can early-exit if I find a violation.

In practice, the max is usually at one of the top few shifts, so I can just check those.

    n = len(h)

    return float(np.max(corr)) * dx

def project_binary(h, target_sum):
    """Project h to binary with exactly target_sum ones."""
    n = len(h)
    h_r = np.round(h).astype(int)
    h_r = np.clip(h_r, 0, 1)
    current = int(h_r.sum())
    if current == target_sum:
        return h_r.astype(float)
    ones = np.where(h_r == 1)[0]
    zeros = np.where(h_r == 0)[0]
    if current > target_sum:
        need = current - target_sum
        # Remove 'need' ones, preferring those with lowest h value
        order = np.argsort(h[ones])[:need]
        h_r[ones[order]] = 0
    else:
        need = target_sum - current
        order = np.argsort(-h[zeros])[:need]
        h_r[zeros[order]] = 1
