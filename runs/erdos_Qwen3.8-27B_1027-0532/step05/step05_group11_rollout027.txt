**Approach: Direct minimization of the "max" using the dual variables**

The problem: min_h max_k f_k(h) subject to Σh = target, 0 ≤ h ≤ 1

This is equivalent to: min_h,t t subject to f_k(h) ≤ t, Σh = target, 0 ≤ h ≤ 1

The Lagrangian dual (relaxing f_k(h) ≤ t):
max_{λ≥0} min_{h,t} t + Σ_k λ_k(f_k(h) - t) + μ(Σh - target) + Σ_j ν_j^+ * 0 + Σ_j ν_j^- * h_j

= max_{λ≥0, μ} min_{h,t} t(1-Σλ_k) + Σ_k λ_k f_k(h) + μ(Σh - target) + ...

For the inner minimization to be bounded, we need Σλ_k = 1.
Then: min_h [Σ_k λ_k f_k(h) + μ(Σh - target)]

This is a quadratic program (since f_k is bilinear, the weighted sum is quadratic).
Σ_k λ_k f_k(h) = Σ_k λ_k Σ_i h[i](1-h[i+k])dx = Σ_i h[i]dx - Σ_k λ_k Σ_i h[i]h[i+k]dx

= Σ_i h[i]dx - Σ_i h[i] (Σ_k λ_k h[i+k]) dx

This is a quadratic form in h! So the dual problem is:
max_{λ ≥ 0, Σλ_k = 1} [min_h {h^T Q(λ) h + c^T h : 0 ≤ h ≤ 1, Σh = target}]

where Q(λ) = -dx * Σ_k λ_k S_k (S_k is the shift matrix for lag k)
and c = dx * (1 - μ * 1)

This is a concave maximization (max of concave functions) which is as hard as the original.

But we can solve it iteratively:
1. Start with λ = uniform
2. Solve the QP: min_h h^T Q h + c^T h subject to constraints
3. Update λ: λ_k ∝ exp(η * f_k(h*)) (multiplicative weights)
4. Repeat

The QP in step 2 can be solved with cvxpy (it's a convex QP since Q should be PSD... let me check).

Q(λ) = -dx * Σ_k λ_k S_k where S_k has S_k[i,j] = 1 if j = i+k.
So h^T Q h = -dx * Σ_k λ_k Σ_i h[i]h[i+k]
This is negative of the weighted autocorrelation, which is generally NOT PSD. So the QP might not be convex!

This means the dual approach doesn't directly give a convex subproblem. The problem is fundamentally non-convex.
