   Now, for efficiency, computing the a vector for each j is O(n) with a Python loop. For n=400, that's 400 iterations per coordinate, and 400 coordinates per sweep, so 160,000 inner loop iterations per sweep. Each iteration does a few float operations. In Python, this might take ~1-2 seconds per sweep. Over 10 minutes, we'd get ~300-600 sweeps. That should be enough for good convergence.

   But we can vectorize the a computation! For a fixed j:
   - Positive lags (k = 0, ..., n-1): a[n-1+k] depends on k relative to j
     - For k <= j: a[n-1+k] += (1 - h[j-k])
     - For k <= n-1-j: a[n-1+k] -= h[j+k]
   - Negative lags (ell = 1, ..., n-1): a[n-1-ell] depends on ell relative to j
     - For ell <= n-1-j: a[n-1-ell] += (1 - h[j+ell])
     - For ell <= j: a[n-1-ell] -= h[j-ell]

   if j >= 0:
