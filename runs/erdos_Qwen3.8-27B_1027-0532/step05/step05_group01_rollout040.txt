**Approach: Iteratively Reighted Least Squares (IRLS) style**

At each iteration:
1. Compute f_k for all k
2. Identify the "active" shifts (those near the max)
3. Form a weighted quadratic objective: sum_k w_k * f_k(h) where w_k emphasizes the active shifts
4. Minimize this quadratic (it's a QP!) using a QP solver or projected gradient
5. Update weights

The key insight is that at step 4, we're minimizing a quadratic function of h (since sum_k w_k * f_k(h) is quadratic in h), which can be solved more efficiently than the full non-convex problem.

For a fixed set of weights w, the objective is:
sum_k w_k * sum_i h[i] * (1-h[i+k]) * dx
= dx * sum_i h[i] * sum_k w_k * (1 - h[i+k])
= dx * sum_i h[i] * (sum_k w_k - sum_k w_k * h[i+k])

Let W = sum_k w_k (a constant), and define (Aw)[i+k] = sum_k w_k h[i+k] (a "blurring" of h).

Then the objective = dx * W * sum_i h[i] - dx * sum_i h[i] * (Ah)[i]

The second term is h^T * M * h where M is a matrix defined by the weights w and the shift structure.

So we're maximizing h^T M h - W * sum(h) (or minimizing the negative), subject to box and equality constraints.

If M is symmetric (which it should be if we're careful with the shift definitions), this is a standard QP.

The matrix M would be dense (since shifts can overlap), so solving a n=400 QP directly might be expensive. But we can use projected gradient on the QP, where each step is:
1. Compute gradient: 2Mh - W*1 (minus Lagrange multiplier for equality constraint)
2. Project to feasible set

The gradient computation requires M*h, which is:
(Mh)[i] = sum_k w_k * h[i+k] (with boundary handling)

This is a weighted sum of shifted versions of h, which can be computed in O(n * K) where K is the number of distinct weights (or O(n log n) with FFT if the weights have structure).

Actually, for n=400 and K=799 (number of shifts), M*h takes O(n*K) = O(400*799) ≈ 320,000 operations per gradient evaluation. That's manageable.
