If we linearize around the current solution h0:

Then c_k(h) ≈ c_k(h0) + sum_i ∂c_k/∂h[i] * δ[i] + (1/2) sum_{i,j} ∂²c_k/∂h[i]∂h[j] * δ[i] * δ[j]

∂²c_k/∂h[i]∂h[j] = -1 if {i,j} corresponds to a valid pair in the correlation, 0 otherwise.

c_k(h) ≈ c_k(h0) + g_k^T δ - (1/2) sum_{(i,j)∈E_k} δ[i]*δ[j]

where E_k is the set of valid pairs for shift k.

This is a concave quadratic in each c_k! So the max of concave quadratics is not convex, but each individual c_k is concave.

def compute_corr(h):

def compute_c5(h):

    dx = 2.0 / n
    return float(np.max(compute_corr(h))) * dx

def project_feasible(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    for _ in range(500):
        diff = target_sum - np.sum(h)

        h[mask] += diff / cnt
        h = np.clip(h, 0.0, 1.0)

def compute_B(h, i, n):
    nl1 = 2 * n - 1
    B = np.zeros(nl1)
    ks = np.arange(n)
    mask1 = ks <= i
    mask2 = (i + ks) < n
    b_pos = np.zeros(n)
    if np.any(mask1):
        b_pos[mask1] += (1.0 - h[i - ks[mask1]])
    if np.any(mask2):
        b_pos[mask2] -= h[i + ks[mask2]]
    B[n - 1:n - 1 + n] = b_pos
    ms = np.arange(1, n)
    mask3 = (i + ms) < n
    mask4 = ms <= i
    b_neg = np.zeros(n - 1)
    if np.any(mask3):
        b_neg[mask3] += (1.0 - h[i + ms[mask3]])
    if np.any(mask4):
        b_neg[mask4] -= h[i - ms[mask4]]
    B[0:n - 1] = b_neg
    return B

The gradient of LSE:

where p_k = exp(α*corr_k) / sum_j exp(α*corr_j) is a softmax over the correlations.

So the gradient is a weighted average of the individual correlation gradients, with weights proportional to the softmax of the correlations. This is O(n^2) to compute (for the softmax) + O(n) per i (for the weighted gradient).

Actually, computing all ∂corr_k/∂h[i] for all k and i is O(n^2) (it's the "Jacobian" of the correlation, which is a 2n-1 by n matrix). This is expensive.

But we can compute it more efficiently:
∂corr_k/∂h[i] for a fixed k is O(n) (as derived earlier).
The weighted sum sum_k p_k * ∂corr_k/∂h[i] for a fixed i is O(n) if we can express it compactly.

Let me see: corr_k = sum_j h[j] * (1-h[j+k-(n-1)]) for valid j.
∂corr_k/∂h[i] = (1-h[i+k-(n-1)]) * 1[valid] - h[i-(n-1-k)] * 1[valid]

So the weighted sum is:
g[i] = sum_k p_k * [(1-h[i+k-(n-1)]) * 1[valid] - h[i-(n-1-k)] * 1[valid]]

Let m = k-(n-1), so k = m+(n-1), m ranges from -(n-1) to (n-1).
p_m = exp(α * corr_{m+n-1}) / Z

g[i] = sum_m p_m * [(1-h[i+m]) * 1[0≤i+m<n, valid] - h[i-m] * 1[0≤i-m<n, valid]]

The first term: sum_m p_m * (1-h[i+m]) * 1[valid(i+m)]

Similarly for the second term.

We can compute both terms using convolution! 
term1[i] = sum_m p_m * (1-h[i+m]) (with appropriate masking)
= convolution of p (reversed) with (1-h), masked appropriately
