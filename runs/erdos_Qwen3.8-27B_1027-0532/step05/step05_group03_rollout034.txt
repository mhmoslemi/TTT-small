Actually, I realize I should also think about the **step size** for the subgradient method. The standard approach is:
- Use a diminishing step size: α_t = c / sqrt(t)
- Or use backtracking: if the objective increases, halve the step size

For non-smooth problems, the standard subgradient method with α_t = c/sqrt(t) gives O(1/sqrt(T)) convergence. This is slow.

A better approach for our problem:
1. Use a **constant** step size (tunable)
2. Combined with **projection** onto the feasible set
3. Add **momentum** (Nesterov acceleration)

Or even better: use a **proximal gradient** method with a carefully chosen step size.

The Lipschitz constant of the gradient (when we use soft-max weights) is bounded by:
L ≤ max_k |∂²c_k/∂h²| * (max weight) * n

For the soft-max with temperature τ, the max weight is 1 (on the max lag), and the Hessian of c_k is bounded by 2n (roughly). So L ≤ 2n/τ * dx.

For n=400, τ=1, dx=0.005: L ≤ 4. Step size ≤ 1/L = 0.25.

But this is very conservative. In practice, we can use much larger steps with backtracking.

Let me use the following strategy:
- Start with step size 0.5
- If the objective decreases, increase by 1.05x (cap at 2.0)
- If it increases, decrease by 0.5x
- Use Nesterov momentum with β = 0.9

This should give fast convergence.
