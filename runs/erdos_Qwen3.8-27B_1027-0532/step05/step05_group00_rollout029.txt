**Key insight for continuous refinement:**

The continuous problem is: minimize max_k corr_k(h) subject to 0 ≤ h[i] ≤ 1 and sum(h) = n/2.

This is a convex optimization problem! The max of linear functions is convex, and the constraints are linear. So we can use:
- Interior point methods
- Cutting plane methods
- Or simply: binary search on the target value T, and check feasibility of corr_k ≤ T for all k

The feasibility check is a linear program! We can use CVXPY with a solver like GLOP or CBC.

LP formulation:
Minimize: (dummy, or 0)
Subject to:
- sum(h) = n/2
- 0 ≤ h[i] ≤ 1 for all i
- corr_k(h) ≤ T for all k

Where corr_k(h) = sum_{i=0}^{n-1-k} h[i] - h[i+k] is LINEAR in h!

Wait, corr_k(h) = sum_{i} h[i]*(1-h[i+k]) = sum_i h[i] - sum_i h[i]*h[i+k]

The second term sum_i h[i]*h[i+k] is NOT linear (it's bilinear). So the problem is NOT a linear program!

However, if we fix all h except one variable, it becomes linear. This suggests a coordinate descent approach:
- For each j, fix all h[i] for i ≠ j
- Optimize h[j] to minimize the resulting max_k corr_k
- This is a 1D problem

For fixed h[-j], corr_k as a function of h[j] is:
corr_k = (sum of h[i](1-h[i+k]) for i≠j, i+k≠j) + [terms involving h[j]]

The terms involving h[j]:
- If j is in the "i" position: h[j]*(1-h[j+k]) for shift k where j+k < n
- If j is in the "i+k" position: h[j-k]*(1-h[j]) for shift k where j-k >= 0

So corr_k as a function of h[j] = x is:
corr_k(x) = c_k + x*(1-h[j+k])*[j+k<n] - h[j-k]*x*[j-k>=0] (approximately)

Wait, more carefully:
corr_k = sum_i h[i]*(1-h[i+k])

The terms involving h[j]:
1. i = j: h[j]*(1-h[j+k]) = x*(1-h[j+k]) [if j+k < n]
2. i+k = j, i.e., i = j-k: h[j-k]*(1-h[j]) = h[j-k]*(1-x) [if j-k >= 0]

So corr_k(x) = corr_k(0) + x*(1-h[j+k])*[j+k<n] + h[j-k]*(1-x)*[j-k>=0] - h[j-k]*[j-k>=0]

Wait, let me be more careful. Let corr_k = f_k(x) where x = h[j].

f_k(x) = [sum of terms not involving h[j]] + x*(1-h[j+k])*[j+k<n] + h[j-k]*(1-x)*[j-k>=0]

Let me denote:
- A_k = [j+k < n] * (1-h[j+k])
- B_k = [j-k >= 0] * h[j-k]
- C_k = corr_k with h[j] set to 0 (i.e., removing h[j]'s contribution)

Then f_k(x) = C_k + x*A_k + (1-x)*B_k = C_k + B_k + x*(A_k - B_k)

This is LINEAR in x! So for each k, corr_k is linear in h[j].

We want to minimize max_k f_k(x) over x ∈ [0, 1].

This is a 1D problem: minimize the maximum of linear functions of x over [0,1]. The minimum is achieved at a point where two (or more) of the linear functions cross, or at a boundary.

We can solve this by:
1. Evaluating all f_k(0) and f_k(1) to find the current max
2. Finding the x that minimizes the max (this is a small LP in 1D)

This coordinate descent converges (since we're minimizing a convex function with coordinate descent, and the function is convex).

**Algorithm: Coordinate descent for continuous optimization**

```
x = initial solution

        solve 1D problem: min_x max_k (C_k + B_k + x*(A_k - B_k)) s.t. x in [0,1]
        update h[j] = x
until convergence
```

def compute_c5(h):
    n = len(h)

def project_feasible(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    diff = target_sum - np.sum(h)
    if abs(diff) < 1e-14:
        return h
    if diff > 0:
        idx = np.where(h < 1.0)[0]
    else:
        idx = np.where(h > 0.0)[0]
    if len(idx) == 0:
        return h
    h = h.copy()
    h[idx] += diff / len(idx)
    return np.clip(h, 0.0, 1.0)

def project_binary(h, target_sum):
    n = len(h)
    h_r = np.round(h)
    h_r = np.clip(h_r, 0, 1).astype(int)
    current_sum = int(h_r.sum())
    if current_sum == target_sum:
        return h_r.astype(float)
    ones = np.where(h_r == 1)[0]
    zeros = np.where(h_r == 0)[0]
    if current_sum > target_sum:
        need = current_sum - target_sum
        if need <= len(ones):
            order = np.argsort(h[ones])[:need]
            h_r[ones[order]] = 0
    else:
        need = target_sum - current_sum
        if need <= len(zeros):
            order = np.argsort(-h[zeros])[:need]
            h_r[zeros[order]] = 1
    final_sum = int(h_r.sum())
    while final_sum != target_sum:
        if final_sum > target_sum:
            idx = np.where(h_r == 1)[0]
            h_r[idx[0]] = 0
            final_sum -= 1
        else:
            idx = np.where(h_r == 0)[0]
            h_r[idx[0]] = 1
            final_sum += 1
    return h_r.astype(float)

import numpy as np

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr)) * dx


def project_feasible(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    diff = target_sum - np.sum(h)
    if abs(diff) < 1e-14:
        return h
    if diff > 0:
        idx = np.where(h < 1.0)[0]
    else:
        idx = np.where(h > 0.0)[0]
    if len(idx) == 0:
        return h
    h = h.copy()
    h[idx] += diff / len(idx)
    return np.clip(h, 0.0, 1.0)


def project_binary(h, target_sum):
    n = len(h)
    h_r = np.round(h)
    h_r = np.clip(h_r, 0, 1).astype(int)
    current_sum = int(h_r.sum())
    if current_sum == target_sum:
        return h_r.astype(float)
    ones = np.where(h_r == 1)[0]
    zeros = np.where(h_r == 0)[0]
    if current_sum > target_sum:
        need = current_sum - target_sum
        if need <= len(ones):
            order = np.argsort(h[ones])[:need]
            h_r[ones[order]] = 0
    else:
        need = target_sum - current_sum
        if need <= len(zeros):
            order = np.argsort(-h[zeros])[:need]
            h_r[zeros[order]] = 1
    final_sum = int(h_r.sum())
    while final_sum != target_sum:
        if final_sum > target_sum:
            idx = np.where(h_r == 1)[0]
            h_r[idx[0]] = 0
            final_sum -= 1
        else:
            idx = np.where(h_r == 0)[0]
            h_r[idx[0]] = 1
            final_sum += 1
    return h_r.astype(float)


def greedy_multi(h, max_iters, time_limit=None, start_time=None, n_top=10):
    n = len(h)
    h = h.copy().astype(float)
    corr = np.correlate(h, 1.0 - h, mode='full')
    best_c5 = float(corr.max()) * (2.0 / n)
    best_h = h.copy()
    stall = 0
    max_stall = 500

    for it in range(max_iters):
        if time_limit is not None and start_time is not None:
            if time.time() - start_time > time_limit:
                break
        if stall > max_stall:
            break

        max_val = float(corr.max())
        top_idx = np.argsort(corr)[-n_top:]
        top_shifts = top_idx - (n - 1)
        top_vals = corr[top_idx].astype(float)

        ones = np.where(h == 1)[0]
        zeros = np.where(h == 0)[0]
        if len(ones) == 0 or len(zeros) == 0:
            break

        best_improve = 0.0
        best_i = -1
        best_j = -1

        for k_star in top_shifts:
            i_cand = [i for i in ones if 0 <= i + k_star < n and h[i + k_star] == 0]
            j_cand = [j for j in zeros if 0 <= j + k_star < n and h[j + k_star] == 1]
            if len(i_cand) == 0 or len(j_cand) == 0:
                continue

            for i in i_cand[:25]:
                for j in j_cand[:25]:
                    nm = max_val
                    for t_idx in top_idx:
                        k = t_idx - (n - 1)
                        d = 0.0
                        if 0 <= i + k < n:
                            d -= (1.0 - h[i + k])
                        if 0 <= i - k < n:
                            d += h[i - k]
                        if 0 <= j + k < n:
                            d += (1.0 - h[j + k])
                        if 0 <= j - k < n:
                            d -= h[j + k]
                        v = top_vals[t_idx - top_idx[0]] + d if t_idx >= top_idx[0] else top_vals[t_idx - top_idx[0]] + d
                        v = corr[t_idx] + d
                        if v > nm:
                            nm = v
                            break
                    if nm < max_val - best_improve:
                        best_improve = max_val - nm
                        best_i = i
                        best_j = j

        if best_i >= 0:
            h[best_i] = 0
            h[best_j] = 1
            corr = np.correlate(h, 1.0 - h, mode='full')
            sc = float(corr.max()) * (2.0 / n)

                best_h = h.copy()
            stall = 0
        else:
            stall += 1

    return best_h, best_c5

def coord_descent(h_start, target, n_sweeps, time_limit=None, start_time=None, grid_size=21):

    h = h_start.copy().astype(float)

    max_no_improve = 5

                    break

            x_old = h[j]
            if x_old < 1e-15 or x_old > 1.0 - 1e-15:
                pass

            k_vals = np.arange(-(n - 1), n)
            valid_plus = (j + k_vals >= 0) & (j + k_vals < n)
            valid_minus = (j - k_vals >= 0) & (j - k_vals < n)

            term_plus = np.zeros(n_active)
            term_minus = np.zeros(n_active)

            idx_p = np.where(valid_plus)[0]
            if len(idx_p) > 0:
                pos_p = j + k_vals[idx_p]
                term_plus[idx_p] = 1.0 - h[pos_p]

            idx_m = np.where(valid_minus)[0]
            if len(idx_m) > 0:

            no_improve_sweeps = 0
