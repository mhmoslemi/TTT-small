The projection onto {x : sum(x) = t, 0 <= x[i] <= 1} is done as follows:

- This can be done by sorting v and bisection

Here's the algorithm:
1. Sort v in descending order
2. Find the threshold: for each possible threshold index j (0 to n-1), compute what lambda would be if exactly j elements are at their upper bound (1) and n-j-1 elements are at their lower bound (0), and the (j+1)-th element is at the threshold.
3. Actually, the standard approach is:
   - Sort v: v_sorted
   - For threshold t_j between v_sorted[j] and v_sorted[j+1], the solution has:
     - x[i] = 1 for v[i] > v_sorted[j] (upper bound active)
     - x[i] = 0 for v[i] < v_sorted[j+1] (lower bound active)
     - x[i] = v_sorted[j] - lambda for v_sorted[j+1] <= v[i] <= v_sorted[j] (free)
   - We need sum(x) = t, which determines lambda
   - The correct j is where the constraint is satisfied

A simpler approach: bisection on lambda.
- lambda_low: all x[i] = 1 → sum = n
- lambda_high: all x[i] = 0 → sum = 0
- We want sum(clip(v - lambda, 0, 1)) = t
- Bisection converges in O(log(range/epsilon)) iterations

```python
def project_to_simplex_box(v, target):
    """Project v onto {x: sum(x) = target, 0 <= x[i] <= 1}."""
    lo = v.min() - target  # ensures sum >= target
    hi = v.max()  # ensures sum <= target
    # Actually: sum(clip(v - lo, 0, 1)) > target (since lo is very negative)
    # sum(clip(v - hi, 0, 1)) < target (since hi is very positive)
    for _ in range(100):
        mid = (lo + hi) / 2
        s = np.clip(v - mid, 0, 1).sum()
        if s > target:
            lo = mid
        else:
            hi = mid
    return np.clip(v - (lo + hi) / 2, 0, 1)
```

```python
        if len(i_cand) == 0:
            i_cand = [i for i in ones if 0 <= i + k_star < n]
        if len(j_cand) == 0:
            j_cand = [j for j in zeros if 0 <= j + k_star < n]
        if len(i_cand) == 0 or len(j_cand) == 0:
            stall += 1
            continue
        top_indices = np.argsort(corr)[-top_k:]
        top_vals = corr.astype(float)
        best_improve = 0.0
        best_i = -1
        best_j = -1
        n_i = min(len(i_cand), scan_width)
        n_j = min(len(j_cand), scan_width)
        for ii in range(n_i):
            i = i_cand[ii]
            for jj in range(n_j):
                j = j_cand[jj]
                nm = max_val
                for t_idx in top_indices:
                    k = t_idx - (n - 1)
                    d = 0.0
                    if 0 <= i + k < n:
                        d -= (1.0 - h[i + k])
                    if 0 <= i - k < n:
                        d += h[i - k]
                    if 0 <= j + k < n:
                        d += (1.0 - h[j + k])
                    if 0 <= j - k < n:
                        d -= h[j - k]
                    v = top_vals[t_idx] + d
                    if v > nm:
                        nm = v
                        break
                if nm < max_val - best_improve:
                    best_improve = max_val - nm
                    best_i = i
                    best_j = j
        if best_i >= 0:
            h[best_i] = 0
            h[best_j] = 1
            corr = np.correlate(h, 1.0 - h, mode='full')
            sc = float(corr.max()) * (2.0 / n)
            if sc < best_c5:
                best_c5 = sc
                best_h = h.copy()
            stall = 0
        else:
            stall += 1
    return best_h, best_c5
```
