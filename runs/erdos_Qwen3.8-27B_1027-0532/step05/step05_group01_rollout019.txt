One more thought: should I try a completely different approach, like using cvxpy to solve a sequence of convex relaxations?

The problem is non-convex (bilinear), so cvxpy can't directly solve it. But we could:
1. Linearize the bilinear terms at the current iterate
2. Solve the resulting convex problem
3. Update the linearization point
4. Repeat

This is the "successive convex approximation" (SCA) method. At each iteration:
- Linearize h^T A_k h around the current h: h^T A_k h ≈ 2 h_cur^T A_k h - h_cur^T A_k h_cur
- Solve: min t s.t. 2 h_cur^T A_k h - h_cur^T A_k h_cur ≥ t for all k, 0≤h≤1, sum h = n/2

The resulting problem is a linear program (LP):
min t
s.t. 2 h_cur^T A_k h - t ≥ h_cur^T A_k h_cur for all k
     0 ≤ h ≤ 1
     sum h = n/2

This can be solved with a linear programming solver (like scipy.optimize.linprog or cvxpy with GLPK).

The number of constraints is O(n) (one per lag k) plus O(n) bounds. For n=400, that's about 800 constraints and 401 variables (400 for h + 1 for t). This is very fast!

The SCA method is guaranteed to converge (under mild conditions) to a stationary point. It might be faster than the log-sum-exp + SLSQP approach because each iteration is a fast LP solve.

The objective is:
C5 = max_k ∫ h(x)(1-h(x+k)) dx = max_k [∫ h(x)dx - ∫ h(x)h(x+k) dx] = max_k [1 - R_h(k)]

where R_h(k) = ∫ h(x)h(x+k) dx is the autocorrelation.

So minimizing C5 is equivalent to maximizing min_k R_h(k).

In discrete form:
R_h[k] = dx * Σ_i h_i * h_{i+k} (with h_j = 0 for j outside [0, n-1])

The constraint is Σ h_i = n/2 (equivalently, dx * Σ h_i = 1).

So we want: max min_k [dx * Σ_i h_i * h_{i+k}]
s.t. 0 ≤ h_i ≤ 1, Σ h_i = n/2

This is a non-convex problem (maximin of bilinear functions).

SCA approach:
At iterate h⁰, linearize R_h[k] around h⁰:
R_h[k] ≈ R_{h⁰}[k] + Σ_i (h_i - h⁰_i) * (h⁰_{i+k} + h^{something}...)

Actually, the bilinear term x^T A x linearized around x⁰ is:
x^T A x ≈ 2 (x⁰)^T A x - (x⁰)^T A x⁰

So R_h[k] ≈ 2 (h⁰)^T A_k h - (h⁰)^T A_k h⁰

where A_k is the shift matrix.

The SCA subproblem is:
max min_k [2 (h⁰)^T A_k h - (h⁰)^T A_k h⁰]
s.t. 0 ≤ h ≤ 1, Σ h = n/2

This is: max t s.t. 2 (h⁰)^T A_k h - t ≥ (h⁰)^T A_k h⁰ for all k

This is a linear program! The variables are h (n variables) and t (1 variable). The constraints are:
- 2 (h⁰)^T A_k h - t ≥ c_k for k = -(n-1), ..., n-1  [2n-1 constraints]
- h_i ≥ 0 for i = 0, ..., n-1  [n constraints]
- h_i ≤ 1 for i = 0, ..., n-1  [n constraints]
- Σ h_i = n/2  [1 constraint]

Total: about 4n + 1 constraints and n+1 variables. For n=400: ~1601 constraints, 401 variables. Very manageable.

```python
def sca_lp_solve(h0, n):
    """Solve the SCA linear programming subproblem."""
    target = n / 2.0
    # Variables: [h_0, ..., h_{n-1}, t]
    # We want to maximize t
    # Equivalent to minimize -t
    
    # Constraints: 2 * h0^T A_k * h - t >= h0^T A_k * h0 for all k
    # In standard form: -2 * h0^T A_k * h + t <= -h0^T A_k * h0
    
    n_corr = 2 * n - 1
    mid = n - 1
    
    # Compute h0^T A_k h0 for all k (this is the autocorrelation of h0)
    ac = np.correlate(h0, h0, mode='full')
    
    # Compute 2 * h0^T A_k * (linear form in h) for all k
    # (h0^T A_k h) = sum_i h0[i] * h[i+k] (with boundary handling)
    # This is a linear form in h: sum_i (A_k h0)[i] * h[i]
    # where (A_k h0)[i] = h0[i+k] (with boundary handling: h0[j]=0 if j outside [0,n-1])
    
    # For each k, the linear form is: sum_i h0[i+k] * h[i] (where h0[i+k]=0 if invalid)
    # = sum_i (shifted h0)[i] * h[i]
    # where shifted_h0[i] = h0[i+k] if 0<=i+k<n, else 0
    
    A = np.zeros((n_corr, n))  # A[k, i] = h0[i+k] (0 if invalid)
    for k_idx in range(n_corr):
        k = k_idx - mid
        if k >= 0:
            A[k_idx, :n-k] = h0[k:]
        else:
            A[k_idx, -k:] = h0[:n+k]
    
    # c_k = h0^T A_k h0 = ac[k_idx]
    c = ac
    
    # LP: min -t
    # s.t. -2*A[k,:] @ h + t <= -c[k] for all k
    #      0 <= h[i] <= 1
    #      sum h = n/2
    
    c_vec = np.zeros(n + 1)
    c_vec[-1] = -1.0  # minimize -t
    
    # Inequality constraints: A_ineq @ x <= b_ineq
    # -2*A[k,:] @ h + 1*t <= -c[k]
    A_ineq = np.zeros((n_corr, n + 1))
    A_ineq[:, :n] = -2.0 * A
    A_ineq[:, -1] = 1.0
    b_ineq = -c
    
    # h[i] >= 0 → -h[i] <= 0
    # h[i] <= 1 → h[i] <= 1
```
