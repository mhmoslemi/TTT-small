### Central idea:
The current greedy and simulated annealing approaches are effective in local search but may get stuck in local optima. We hypothesize that by using wavelet transforms, we can model the function in multiple scales and thus perform global optimization by transferring information between scales.

### Mathematical specification:
We represent the function `h` as a linear combination of basis functions (wavelets) and use a two-level optimization:

1. **Coarse level**: A low-resolution version of `h` that captures the global structure.
2. **Fine level**: The original high-resolution function, which is reconstructed from the coarse level using a wavelet reconstruction.

The objective function remains the same:

```
C_5 = (2/n) * max_k { sum_i h[i] * (1 - h[i+k]) }
```

But now we decompose `h` as a linear combination of wavelet coefficients at a given decomposition level. We can then optimize the coarse representation and project back to the fine level.

Constraints are still:
  - h[i] in [0, 1] for all i
  - Sum(h) = n/2
