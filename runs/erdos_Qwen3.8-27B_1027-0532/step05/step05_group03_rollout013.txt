```python
    """Compute change in corr_full array when h[i] changes by dir_sign.
    dir_sign = +1: h[i] goes from 0 to 1
    dir_sign = -1: h[i] goes from 1 to 0
    Returns: array of length 2n-1 with the changes.
```

3. For each j (one position), compute delta_j[k*]
4. The best pair is approximately the one that minimizes corr[k*] + delta_i[k*] + delta_j[k*]
5. Verify the full max for the top candidates

```python
def binary_local_search_efficient(h, target, n_sweeps=50, time_limit=60):
    n = len(h)
    dx = 2.0 / n
    h = h.copy()
    corr = compute_corr_full(h)
    best_score = float(np.max(corr)) * dx
    start_time = time.time()
    
    for sweep in range(n_sweeps):
        if time.time() - start_time > time_limit:
            break
        
        improved = False
        k_star_idx = int(np.argmax(corr))
        
        zeros = np.where(h == 0)[0]
        ones = np.where(h == 1)[0]
        
        if len(zeros) == 0 or len(ones) == 0:
            break
        
        # For each zero i, compute delta_i at k_star
        # delta_i[k_star_idx] = (1-h[i + (n-1) - k_star_idx]) * [valid, i≠j] 
        #                       - h[k_star_idx + i - (n-1)] * [valid, idx≠i]
        
        # Vectorized computation of delta at k_star_idx for all i
        def delta_at_k(i_arr, k_idx, h_cur, n_vals, dir_s):
            """Compute delta at correlation index k_idx for flipping positions i_arr."""
            # Part 1: m = i + (n-1) - j where m = k_idx, so j = i + (n-1) - k_idx
            j_val = i_arr + (n_vals - 1) - k_idx
            valid1 = (j_val >= 0) & (j_val < n_vals) & (j_val != i_arr)
            part1 = np.zeros(len(i_arr))
            part1[valid1] = (1.0 - h_cur[j_val[valid1]])
            
            # Part 2: idx = k_idx + i - (n-1), exclude idx == i
            idx_val = k_idx + i_arr - (n_vals - 1)
            valid2 = (idx_val >= 0) & (idx_val < n_vals) & (idx_val != i_arr)
            part2 = np.zeros(len(i_arr))
            part2[valid2] = h_cur[idx_val[valid2]]
            
            return dir_s * part1 - dir_s * part2
        
        d_zero = delta_at_k(zeros.astype(int), k_star_idx, h, n, +1.0)
        d_one = delta_at_k(ones.astype(int), k_star_idx, h, n, -1.0)
        
        # Score for pair (i, j): corr[k_star] + d_zero[i] + d_one[j]
        # We want to minimize this
        # Best i: min d_zero[i], Best j: min d_one[j]
        # But the optimal pair might not be (best_i, best_j) due to interactions at other lags
        
        # Try top candidates
        top_i = np.argsort(d_zero)[:10]
        top_j = np.argsort(d_one)[:10]
        
        best_improve = 0
        best_pair = None
        
        for ii in top_i:
            for jj in top_j:
                i = int(zeros[ii])
                j = int(ones[jj])
                if i == j:
                    continue
                # Compute full delta
                d_i = flip_delta(h, i, +1, n)
                d_j = flip_delta(h, j, -1, n)
                new_corr = corr + d_i + d_j
                new_max = float(np.max(new_corr))
                improve = float(corr[k_star_idx]) - new_max  # Hmm, should compare to overall max
                # Actually: improve = max(corr) - max(new_corr)
                improve = float(np.max(corr)) - new_max
                if improve > best_improve:
                    best_improve = improve
                    best_pair = (i, j)
        
        if best_pair is not None and best_improve > 1e-10:
            i, j = best_pair
            h[i] = 1.0
            h[j] = 0.0
            corr = compute_corr_full(h)
            best_score = float(np.max(corr)) * dx
            improved = True
        
        if not improved:
            break
    
    return h, best_score
```

Let me also think about what makes this problem hard:
- The max of correlations is a non-smooth, non-convex function
- There are many local minima
- The "worst lag" can jump around as h changes
- Binary and continuous solutions can be quite different

One key insight: the problem has a "minimax" structure. We're minimizing the maximum of n-1 (or 2n-1) linear (in h²) functions. This is similar to a "scheme design" problem in communications.

Another approach: **Water-filling / equalization**
- Try to make all correlations equal (or as equal as possible)
- This is like "equalizing" the interference
- Algorithm: repeatedly find the maximum correlation, reduce it by adjusting h, then check if we created a new maximum

This is essentially what the "surgery" approach does, but I can make it more systematic.

Let me also consider **alternating direction method of multipliers (ADMM)** style:
- Split the problem into: minimize the max (which is a scalar t) subject to corr_k ≤ t for all k
- The constraint corr_k ≤ t is a quadratic constraint in h
- Solve via Lagrangian relaxation: minimize max_k (corr_k - λ_k * t) + ...
