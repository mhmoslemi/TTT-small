However, if we fix the "other" variable (as in the alternating approach), it becomes linear. That's why the alternating LP works.

Alternatively, we can use a **quadratic programming** approach:
minimize t
subject to: h^T Q_k h - b_k^T h ≤ t for all k (where Q_k and b_k encode the bilinear form)

Wait, f_k(h) = sum_i h[i] - sum_i h[i]*h[i+k] = c^T h - h^T Q_k h

where c is a vector of 1s (for the valid range) and Q_k is a matrix with 1s at positions (i, i+k) for valid i.

So the constraint is: c^T h - h^T Q_k h ≤ t

This is a bilinear constraint, not a quadratic constraint. QP requires the objective and constraints to be quadratic (h^T A h + b^T h + c), but here we have -h^T Q_k h on the LHS which is fine (it's quadratic), and c^T h is linear. So the constraint IS quadratic!

Wait: c^T h - h^T Q_k h ≤ t
⟹ h^T Q_k h - c^T h + t ≥ 0

This is a quadratic constraint. We can solve this as a QP!

But Q_k is not necessarily positive semidefinite (it's a shift matrix, which has eigenvalues on the unit circle). So this is a non-convex QP in general.

Hmm, but for the specific structure here, Q_k is a 0-1 matrix with at most one 1 in each row and column (it's a partial permutation matrix). The eigenvalues are on the unit circle, so Q_k is not PSD in general.

So direct QP won't work. We're back to the alternating approach.

**Let me try a different angle: use the SCS solver with a better formulation.**

Instead of the alternating approach, we can use a **semidefinite relaxation** or a **lifted formulation**. But that's likely too expensive.

**Practical plan:**

Given the small gap (0.000037), I think the most effective approach is:

1. **High-resolution LP refinement**: Run the alternating LP with very tight tolerances and many iterations, starting from the parent solution.

2. **SLSQP with extremely high alpha**: The softmax smoothing with alpha=50000-200000 should approximate the max very well. Combined with tight SLSQP tolerances, this should squeeze out the last bit of improvement.

3. **Try nearby n values**: n=398, 402, 410, 390 might give slightly different optima.

4. **Binary perturbation + refinement**: Take the parent, flip a few bits (randomly), project, and refine. This might find a nearby but better solution.

5. **Multi-start at the binary level**: Generate random binary sequences, do quick LP refinement on each, keep the best.

import numpy as np
from scipy.optimize import minimize
import cvxpy as cp
import time

_global_n = 0
_global_target = 0.0
_global_alpha = 100.0


def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr)) * dx


def project_feasible(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    diff = target_sum - np.sum(h)
    if abs(diff) < 1e-14:
        return h
    h = h.copy()
    if diff > 0:
        idx = np.where(h < 1.0 - 1e-10)[0]
    else:
        idx = np.where(h > 1e-10)[0]
    if len(idx) == 0:
        return h
    h[idx] += diff / len(idx)
    h = np.clip(h, 0.0, 1.0)
    residual = target_sum - np.sum(h)
    if abs(residual) > 1e-10:
        if residual > 0:
            idx2 = np.where(h < 1.0)[0]
        else:
            idx2 = np.where(h > 0.0)[0]
        if len(idx2) > 0:
            h[idx2] += residual / len(idx2)
            h = np.clip(h, 0.0, 1.0)
    return h


def alternating_lp_v2(h_init, n, target, max_iter, time_limit,
                      damping_init=0.7, reg=5e-4, n_active=60):
    start = time.time()
    dx = 2.0 / n
    h = h_init.copy()
    h = project_feasible(h, target)
    best_h = h.copy()
    best_c5 = compute_c5(h)
    damping = damping_init
    current_reg = reg
    half_n = n - 1

    corr = np.correlate(h, 1.0 - h, mode='full')
    active_k = set(np.argsort(corr)[-n_active:].tolist())

    for it in range(max_iter):
        if time.time() - start > time_limit:
            break

        g = 1.0 - h
        h_var = cp.Variable(n)
        t_var = cp.Variable()

        constraints = [
            cp.sum(h_var) == target,
            h_var >= 0.0,
            h_var <= 1.0
        ]

        sorted_active = sorted(active_k)
        for k_idx in sorted_active:
            k = k_idx - half_n
            lo = max(0, k)
            hi = min(n, k + n)
            if hi > lo:
                coeff = np.zeros(n)
                coeff[lo:hi] = g[lo - k:hi - k] * dx
                constraints.append(coeff @ h_var <= t_var)

        objective = t_var + current_reg * cp.sum_squares(h_var - h)
        prob = cp.Problem(cp.Minimize(objective), constraints)

        solved = False
        try:
            prob.solve(solver=cp.SCS, eps=1e-12, max_iters=100000, verbose=False)
            solved = h_var.value is not None
        except Exception:
            pass
        if not solved:
            try:
                prob.solve(solver=cp.ECOS, max_iter=100000)
                solved = h_var.value is not None
            except Exception:
                pass

        if not solved:
            break

        h_new = np.clip(np.asarray(h_var.value).ravel(), 0.0, 1.0)
        h = (1.0 - damping) * h + damping * h_new
        h = project_feasible(h, target)

        c5_val = compute_c5(h)
        if c5_val < best_c5 - 1e-15:
            best_c5 = c5_val
            best_h = h.copy()

        corr = np.correlate(h, 1.0 - h, mode='full')
        top_k = set(np.argsort(corr)[-n_active:].tolist())

        t_val = t_var.value if t_var.value is not None else best_c5
        violations = []
        for k_idx in range(1, len(corr) - 1):
            if k_idx not in active_k:
                if corr[k_idx] * dx > t_val + 1e-5:
                    violations.append((corr[k_idx] * dx, k_idx))
        if violations:
            violations.sort(reverse=True)
            for _, k_idx in violations[:5]:
                active_k.add(k_idx)

        active_k = top_k | active_k
        if len(active_k) > 4 * n_active:
            active_k = set(np.argsort(corr)[-4 * n_active:].tolist())

        if c5_val >= best_c5 - 1e-15:
            damping = max(0.2, damping * 0.90)
        else:
            damping = min(0.95, damping + 0.03)

        if it % 50 == 0 and current_reg > 1e-8:
            current_reg = max(1e-8, current_reg * 0.75)

    return best_h, best_c5


def smooth_obj(h, alpha):
    corr = np.correlate(h, 1.0 - h, mode='full')
    c_max = np.max(corr)
    shifted = np.clip(alpha * (corr - c_max), -500.0, 0.0)
    return float(c_max + np.log(np.sum(np.exp(shifted))) / alpha)


def cons_fun(h):
    return np.array([np.sum(h) - _global_target])


def cons_jac(h):
    return np.array([np.ones(_global_n)])


def slsqp_round(h_start, n, target, alphas, maxiter_per_alpha, ftol):
    global _global_n, _global_target, _global_alpha
    _global_n = n
    _global_target = target
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': cons_fun, 'jac': cons_jac}]
    h_cur = h_start.copy()
    cur_score = compute_c5(h_cur)

    for alpha in alphas:
        _global_alpha = alpha
        try:
            res = minimize(smooth_obj, h_cur, args=(alpha,),
                           method='SLSQP', bounds=bounds, constraints=cons,
                           options={'maxiter': maxiter_per_alpha, 'ftol': ftol})
            h_new = project_feasible(res.x, target)
            sc = compute_c5(h_new)
            if sc < cur_score - 1e-15:
                h_cur = h_new
                cur_score = sc
        except Exception:
            pass
    return h_cur


def binary_local_search(h, n, target, max_iters, seed, time_limit):
    start = time.time()
    rng = np.random.RandomState(seed)
    h = (h > 0.5).astype(float)
    h = project_feasible(h, target)
    best_h = h.copy()
    best_c5 = compute_c5(h)

    ones = list(np.where(h == 1)[0])
    zeros = list(np.where(h == 0)[0])

    no_improve = 0
    for it in range(max_iters):
        if time.time() - start > time_limit:
            break

        i = ones[rng.randint(len(ones))]
        j = zeros[rng.randint(len(zeros))]

        h[i], h[j] = h[j], h[i]
        c5 = compute_c5(h)

        if c5 < best_c5 - 1e-15:
            best_c5 = c5
            best_h = h.copy()
            ones.remove(i)
            zeros.remove(j)
            ones.append(j)
            zeros.append(i)
            no_improve = 0
        else:
            h[i], h[j] = h[j], h[i]
            no_improve += 1

        if no_improve > 3000:
            break

    return best_h, best_c5


def interpolate_to(h_src, n_dst, target_dst):
    n_src = len(h_src)
    if n_src == n_dst:
        return project_feasible(h_src.copy(), target_dst)
    x_new = np.linspace(0.0, 1.0, n_dst)
    x_old = np.linspace(0.0, 1.0, n_src)
    h_out = np.interp(x_new, x_old, h_src)
    return project_feasible(h_out, target_dst)


def subgradient_improve(h, n, target, max_steps, time_limit):
    start = time.time()
    dx = 2.0 / n
    h_cur = h.copy()
    best_h = h_cur.copy()
    best_c5 = compute_c5(h_cur)
    half_n = n - 1
    idxs = np.arange(n)

    for step in range(max_steps):
        if time.time() - start > time_limit:
            break

        corr = np.correlate(h_cur, 1.0 - h_cur, mode='full')
        k_star = int(np.argmax(corr)) - half_n
        k = k_star
        idx_valid1 = (0 <= idxs - k) & ((idxs - k) < n)
        idx_valid2 = (0 <= idxs + k) & ((idxs + k) < n)
        grad = np.zeros(n)
        grad[idx_valid1] += (1.0 - h_cur[idxs[idx_valid1] - k])
        grad[idx_valid2] -= h_cur[idxs[idx_valid2] + k]
        grad *= dx

        improved = False
        for lr in [0.001, 0.002, 0.005, 0.01, 0.02, 0.05, 0.1, 0.2]:
            h_try = h_cur - lr * grad
            h_try = project_feasible(h_try, target)
            sc = compute_c5(h_try)
            if sc < best_c5 - 1e-14:
                best_c5 = sc
                best_h = h_try.copy()
                h_cur = h_try
                improved = True
                break

        if not improved and step > 100:
            break

    return best_h, best_c5
