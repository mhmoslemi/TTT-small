Note: Σ_{i=0}^{n-1-k} h[i] ≠ n/2 in general (it's only the sum over a subset of indices).

Hmm, this complicates things. The "linear" part depends on k.

Let me just use the full objective:
F_w(h) = Σ_k w_k * f_k(h) = dx * Σ_k w_k * [Σ_{i: valid for k} h[i] - Σ_{i: valid for k} h[i]*h[i+k]]

The linear part: dx * Σ_k w_k * Σ_{i: valid for k} h[i] = dx * Σ_i h[i] * (Σ_{k: i valid for k} w_k)

For a given i, which k values make i "valid"?
For k ≥ 0: i is valid if i ≤ n-1-k, i.e., k ≤ n-1-i
For k < 0 (let ell = -k > 0): i is valid if i ≥ ell, i.e., ell ≤ i

So: Σ_{k: i valid for k} w_k = Σ_{k=0}^{n-1-i} w_k + Σ_{ell=1}^{i} w_{-ell}

This is a prefix sum! Let me define:
W_pos[k] = w_k for k ≥ 0 (indexing into the correlation vector as w[n-1+k])
W_neg[ell] = w_{-ell} for ell > 0 (indexing as w[n-1-ell])

prefix_pos[i] = Σ_{k=0}^{i} W_pos[k]
prefix_neg[i] = Σ_{ell=1}^{i} W_neg[ell]

Then the coefficient of h[i] in the linear part is:
dx * (prefix_pos[n-1-i] + prefix_neg[i])

And the quadratic part:
-dx * Σ_k W_pos[k] * h^T A_k h - dx * Σ_ell W_neg[ell] * h^T A_ell h

Note: A_k and A_ell are the same matrix for |k| = |ell| (since A_k = A_{-k} by symmetry of the bilinear form). So:

-quadratic: -dx * Σ_{k=1}^{n-1} (W_pos[k] + W_neg[k]) * h^T A_k h - dx * W_pos[0] * h^T A_0 h

Wait, A_0 has (A_0)_{i,i} = 0.5, so h^T A_0 h = 0.5 * Σ h[i]². Hmm, that's not right either.

Let me be more careful. For k=0:
The "correlation" at lag 0 is: corr[n-1] = Σ_i h[i] * (1-h[i]) = Σ h[i] - Σ h[i]²

So f_0(h) = dx * (Σ h[i] - Σ h[i]²)

The quadratic part is -dx * Σ h[i]², which corresponds to h^T (dx * I) h with a negative sign... actually it's -dx * h^T I h.

For k > 0:
f_k(h) = dx * (Σ_{i=0}^{n-1-k} h[i] - Σ_{i=0}^{n-1-k} h[i]*h[i+k])

The quadratic part is -dx * Σ_{i=0}^{n-1-k} h[i]*h[i+k] = -dx * h^T A_k h

So the total objective F_w(h):
F_w(h) = dx * [linear_part - quadratic_part]

where:
linear_part = Σ_k w_k * (sum of h over valid indices for k)
quadratic_part = w_0 * Σ h[i]² + Σ_{k=1}^{n-1} (w_k + w_{-k}) * h^T A_k h

(Here w_k and w_{-k} refer to the weights at lags ±k in the correlation vector.)

The gradient:
∂F_w/∂h_i = dx * [linear_coeff[i] - 2 * quadratic_grad[i]]

where quadratic_grad[i] = w_0 * h[i] + Σ_{k=1}^{n-1} (w_k + w_{-k}) * (A_k h)[i]

And (A_k h)[i] = 0.5 * (h[i+k] (if valid) + h[i-k] (if valid))

So: quadratic_grad[i] = w_0 * h[i] + 0.5 * Σ_{k=1}^{n-1} (w_k + w_{-k}) * (h[i+k] * 1[i+k<n] + h[i-k] * 1[i-k≥0])

This can be computed in O(n²) time, or O(n * max_k) if we only consider the significant weights.

def compute_corr(h):
    return np.correlate(h, 1.0 - h, mode='full')

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    return float(np.max(compute_corr(h))) * dx

def project_feasible(h, target_sum):
    h = h.astype(float).copy()
    h = np.clip(h, 0.0, 1.0)
    for _ in range(200):
        diff = target_sum - np.sum(h)
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            mask = h < 1.0 - 1e-12
        else:
            mask = h > 1e-12
        cnt = int(mask.sum())
        if cnt == 0:
            break
        h[mask] += diff / cnt
        h = np.clip(h, 0.0, 1.0)
    return h

    corr = compute_corr(h)
    c_max = float(np.max(corr))
    shifted = np.clip(alpha * (corr - c_max), -700.0, 0.0)
    return c_max + float(np.log(np.sum(np.exp(shifted)))) / alpha

def lse_grad(h, alpha):

    if w_sum < 1e-300:

def optimize_slsqp(h, n, target, alpha, maxiter):
