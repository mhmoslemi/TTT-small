```python
import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr)) * dx

def compute_corr(h):
    return np.correlate(h, 1.0 - h, mode='full')

def gradient_max_corr(h, top_k=10):
    """Compute subgradient of max correlation."""
    n = len(h)
    corr = compute_corr(h)
    # Find top lags
    top_indices = np.argsort(corr)[-top_k:]
    top_indices = top_indices[np.argsort(corr[top_indices])]  # sort by value
    n_active = top_k
    
    grad = np.zeros(n)
    for idx in top_indices:
        k = idx - (n - 1)  # actual lag
        if k == 0:
            continue
        # ∂corr(k)/∂h[i] = [1-h[i+k] if valid] - [h[i-k] if valid]
        for i in range(n):
            g = 0.0
            if 0 <= i + k < n:
                g += (1.0 - h[i + k])
            if 0 <= i - k < n:
                g -= h[i - k]
            grad[i] += g / n_active
    
    return grad, corr
```

```python
def gradient_max_corr(h, top_k=10):
    n = len(h)
    corr = compute_corr(h)
    top_indices = np.argsort(corr)[-top_k:]
    n_active = len(top_indices)
    
    grad = np.zeros(n)
    for idx in top_indices:
        k = idx - (n - 1)
        if k == 0:
            continue
        # For positive k: i+k valid when i < n-k, i-k valid when i >= k
        # For negative k: let k' = -k > 0, i+k valid when i < n-k', i-k valid when i >= k'
        k_abs = abs(k)
        # Term 1: (1-h[i+sign(k)*k_abs]) for valid i
        # Term 2: -h[i-sign(k)*k_abs] for valid i
        if k > 0:
            # i+k valid: i = 0 to n-1-k
            grad[:n-k] += (1.0 - h[k:]) / n_active
            # i-k valid: i = k to n-1
            grad[k:] -= h[:n-k] / n_active
        else:
            # k < 0, let k_neg = -k
            k_neg = -k
            # i+k valid: i+k = i-k_neg, valid when i >= k_neg, so i = k_neg to n-1
            grad[k_neg:] += (1.0 - h[:n-k_neg]) / n_active
            # i-k valid: i-k = i+k_neg, valid when i+k_neg < n, so i = 0 to n-1-k_neg
            grad[:n-k_neg] -= h[k_neg:] / n_active
    
    return grad, corr
```

**Alternative: Direct optimization using the structure**

Since the problem is to minimize max_k corr(k), and corr(k) is a quadratic form in h, we can use a different approach:

1. Start with a good initial guess (e.g., sinusoidal).
2. Use a "bisection" style: find the worst lag, then try to reduce it by adjusting h.
3. The key insight: to reduce corr(k*) at the worst lag k*, we want to make h[i] and h[i+k*] more similar (both high or both low) for the positions where they currently differ.

For a specific lag k*, corr(k*) = Σ_i h[i](1-h[i+k*]) (for positive k*).
To reduce this, we want to increase h[i+k*] where h[i] is large (making 1-h[i+k*] smaller), and decrease h[i] where h[i+k*] is small.

This is like a "balancing" operation along the lag k*.

**Better approach: Iterated projection / averaging**

For each active lag k, the ideal is that h[i] ≈ h[i+k] for all i (to minimize corr(k)). This is like a consistency constraint. We can enforce it by averaging: h[i] ← (h[i] + h[i+k])/2 (or similar).

But we need to do this for multiple lags simultaneously, while maintaining the sum constraint.

This is related to the "H_", or "consensus" problem in signal processing.

Let me try a different approach: **Alternating minimization over lags**.

For a fixed lag k, the optimal h (minimizing corr(k) subject to the sum constraint) can be found by:
- For each pair (i, i+k), we want h[i] ≈ h[i+k].
- The minimum of Σ h[i](1-h[i+k]) subject to Σh = n/2 and 0≤h≤1 is achieved when h[i] = h[i+k] for all i in the overlap.

But this is only for one lag. For multiple lags, it's a compromise.

Actually, let me think about this differently. The subgradient method for minimizing a max of functions is known to converge slowly. A better approach might be:

**Approach: Minimize a smooth approximation of the max**

Instead of max_k corr(k), minimize the log-sum-exp:
f(h) = (1/α) * log(Σ_k exp(α * corr(k)))

As α → ∞, this approaches the max. For finite α, it's smooth and we can use gradient descent.

The gradient of f with respect to h[i]:
∂f/∂h[i] = (1/α) * Σ_k exp(α*corr(k)) * ∂corr(k)/∂h[i] / Σ_k exp(α*corr(k))
= Σ_k w_k * ∂corr(k)/∂h[i]

where w_k = exp(α*corr(k)) / Σ_j exp(α*corr(j)) are softmax weights.

This is a weighted sum of the individual gradients, with weights concentrated on the lags with highest correlation. This is actually the exact gradient of the smooth approximation, so gradient descent should work well.

This is essentially what the `top_k` approach does, but with smooth weighting instead of hard top-k selection.
