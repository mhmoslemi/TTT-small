    h = h.astype(float).copy()

        s = np.sum(projected)

        else:

def lse_value(over, alpha):

        grad[k:] += wk * (1.0 - h[:n-k])
        grad[:n-k] -= wk * h[k:]
    grad *= dx

L-BFGS-B is designed for bound-constrained problems and is very efficient in high dimensions. The issue is that it doesn't handle equality constraints. But I can handle the sum constraint by:
- Optimizing n-1 variables (the last one is determined by the sum constraint)
- Or using a penalty for the sum constraint

Actually, a cleaner approach: use the fact that the projection onto the sum constraint is straightforward. I can:
1. Run L-BFGS-B on the LSE objective with box constraints [0,1]
2. After each iteration, project onto the sum constraint
3. This gives a "projected L-BFGS-B" method

But scipy's L-BFGS-B doesn't support callbacks for projection. So I'd need to implement my own.

Alternatively, I can reduce the dimensionality by one: fix h[n-1] = target - sum(h[0:n-1]) and optimize only h[0:n-1]. But then h[n-1] might go out of [0,1], which is a constraint.

Let me try a different approach. Here's my refined plan:

1. Use the bisection projection (exact Euclidean projection) - this is better than the iterative one
2. Use a combination of:
   a. LSE-smoothed optimization with Adam (fast, handles the smoothing)
   b. "Active set" optimization where I identify the top few lags and optimize their average (more targeted)
   c. Final polish with line search on the exact max

3. Key improvement: Use a **homotopy** approach:
   - Start with a relatively smooth approximation (low alpha)
   - Gradually increase alpha
   - At each alpha level, run a few optimization steps
   - This is like annealing - we avoid local minima by starting smooth and gradually sharpening

Let me also add a **random restart** mechanism: if we're stuck (no improvement for many steps), perturb the solution randomly and continue.

import time

def compute_overlap(h):
    n = len(h)
    corr = np.correlate(h, 1.0 - h, mode='full')
    return corr[n-1:2*n-1]

def compute_c5(h):
    over = compute_overlap(h)
    dx = 2.0 / len(h)
    return float(np.max(over)) * dx

def project_feasible(h, target_sum):
    h = np.asarray(h, dtype=float)
    lo, hi = -3.0, 3.0
    for _ in range(80):
        mid = (lo + hi) / 2
        s = np.sum(np.clip(h - mid, 0.0, 1.0))
        if s > target_sum:
            lo = mid
        else:
            hi = mid
    return np.clip(h - (lo + hi) / 2, 0.0, 1.0)
