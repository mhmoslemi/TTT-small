So: ∂c(k)/∂h[j] = (1-h[j+k])·[j ≤ n-1-k] - h[j-k]·[j ≥ k]

The gradient of the LSE objective:
∂f/∂h[j] = dx * Σ_k w[k] * ∂c(k)/∂h[j]

First sum: Σ_k w[k]*(1-h[j+k])·[k < n-j] = Σ_{k=0}^{min(j, n-1-j)} ... 

Actually it's cleaner to think of it as:
Sum1[j] = Σ_{k=0}^{n-1-j} w[k] * (1-h[j+k])  [for k such that j+k < n]

This is the (n-1-j)-th element of the cross-correlation of w and v...

This is A[j] if we define A[m] = Σ_{k=0}^{min(len(w)-1, len(v)-1-m)} w[k]*v[k+m].

In the parent code, they use:

Let me verify: ifft(rfft(w_flipped) * rfft(v))[m] = Σ_k w_flipped[k] * v[m-k] (circular, for m in range)
= Σ_k w[n-1-k] * v[m-k]

For m = n-1+j (j in 0..n-1):

Let l = n-1-k, so k = n-1-l:

Now let me think about what specific improvements to make.

**Key insight for improvement**: The previous solution uses FISTA which is good for convex problems, but our problem is non-convex. FISTA can get stuck in local minima. To escape, we need:
1. Multiple restarts from different initial points
2. More aggressive exploration

**Another insight**: The LSE smoothing with finite alpha changes the problem. At the optimum of the LSE-smoothed problem, the top correlations are not necessarily equalized as well as in the true max problem. Using a very high alpha (say 100000+) would be better but makes the problem harder to optimize (sharper landscape).

**My approach**:
1. Start with FISTA at moderate alpha (50-500) to get a good starting point
2. Switch to a "top-3 focused" optimization where we only consider the top 3 lags
3. Use a combination of gradient descent and projection for the focused problem
4. Try structured restarts
5. Final polish

For the "top-3 focused" optimization, the idea is:
- Let k1, k2, k3 be the top 3 lags
- We want to minimize max(c(k1), c(k2), c(k3))
- Use a very sharp LSE (high alpha) on just these 3
- This is easier than the full problem because we have fewer "active" constraints

Actually, a better idea: **Alternating minimization**.
- Alternate between:
  a) Fix h, compute the "effective" distribution over lags (softmax of top lags)
  b) Fix the distribution, optimize h to minimize the weighted sum

This is similar to the cutting plane approach I mentioned earlier.

Let me code this up. Actually, for step (b), the objective is:
f(h) = Σ_k p[k] * c(k) = Σ_k p[k] * Σ_i h[i](1-h[i+k])
= Σ_i h[i] - Σ_i Σ_k p[k] h[i]h[i+k]
= n/2 - h^T B h (where B is a symmetric matrix with B[i,j] = (p[j-i] + p[i-j])/2 on the diagonals)

Wait: Σ_k p[k] h[i]h[i+k] = Σ_i h[i] (Σ_k p[k] h[i+k]) = h^T P h (where P is the matrix with P[i, i+k] = p[k]/2 and P[i+k, i] = p[k]/2 for symmetry)

Actually it's: h^T A h where A[i, j] = p[|i-j|]/2 (with appropriate boundary handling). This is a symmetric matrix.

So f(h) = n/2 - h^T A h (times dx).

We want to minimize f(h) = n/2 * dx - dx * h^T A h, which is equivalent to maximizing h^T A h.

The matrix A is a "banded" matrix (sum of weighted diagonals). It's symmetric but not necessarily positive definite. If it's not positive definite, maximizing h^T A h is a non-convex problem.

However, we can still use gradient methods:
∇(h^T A h) = 2Ah

So the gradient of our objective is -2dx*A*h, and we minimize by doing gradient ascent on h^T A h (or equivalently, gradient descent on -h^T A h).

With the constraint 0≤h≤1, Σh=n/2, we can use projected gradient:
h_new = project(h + step * 2*A*h)

This is a simple iterative method! And the matrix-vector product A*h can be computed efficiently using FFT (since A is a sum of diagonals, it's a Toeplitz-like matrix).

This is actually a nice approach. Let me call it the **dual-averaging method** or **Lagrangian dual method**.

The algorithm:
1. Initialize p (distribution over lags) to be uniform or concentrated on current top lags
2. Iterate:
   a. Compute A from p (the banded matrix)
   b. Do several steps of projected gradient ascent on h^T A h
   c. Update p based on the new h: p[k] ∝ exp(β * c_k(h)) (softmax on current correlations)
3. Return the best h found

This is essentially the **mirror descent / multiplicative weights** approach to the maximin problem.

The key advantage is that each inner iteration is cheap (FFT for the matrix-vector product), and the outer loop naturally adapts to the active lags.

Let me implement this:

Now let me think about the step size. The objective Q(h) = h^T A h has a Lipschitz gradient constant of at most 2*λ_max(A). Since A is a sum of p[k]*D_k where D_k are diagonal-shift matrices, λ_max(A) ≤ Σ p[k] * ||D_k|| ≤ Σ p[k] * 2 = 2. So the Lipschitz constant is at most 4. A safe step size is 1/4 = 0.25, but in practice we can be more aggressive.

Actually, let me be more careful. The matrix A has entries A[i,j] = p[|i-j|]/2 (for i≠j) and A[i,i] includes p[0]. Actually from Q(h) = Σ_k p[k] Σ_i h[i]h[i+k], the Hessian is:
H[j,l] = p[|j-l|] (symmetric part)

So the Hessian is a Toeplitz matrix with first row [p[0], p[1], p[2], ...]. Since p is a probability distribution, the sum of the first row is 1. The eigenvalues of such a Toeplitz matrix are bounded by the Fourier transform of p, which has absolute value ≤ ||p||_1 = 1. So λ_max ≤ 1 and the Lipschitz constant of ∇Q is 2*1 = 2. A safe step is 1/2.

But we also have the projection constraint, so let's use a smaller step and backtracking.

4. Structured restarts
5. Final coordinate descent

```python
import numpy as np
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')[n-1:]
    return float(np.max(corr)) * dx

def get_correlations(h):
    n = len(h)
    return np.correlate(h, 1.0 - h, mode='full')[n-1:]

def project_feasible(h, target):
    h = np.asarray(h, dtype=float)
    lo = float(h.min()) - 1.0
    hi = float(h.max()) + 1.0
    for _ in range(200):
        mid = (lo + hi) / 2.0
        s = np.sum(np.clip(h - mid, 0.0, 1.0))
        if s > target:
            lo = mid
        else:
            hi = mid
    return np.clip(h - (lo + hi) / 2.0, 0.0, 1.0)

def lse_obj_and_grad(h, alpha):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')[n-1:]
    c_max = float(np.max(corr))
    shifted = alpha * (corr - c_max)
    shifted = np.clip(shifted, -700.0, 0.0)
    exp_shifted = np.exp(shifted)
    sum_exp = float(exp_shifted.sum())
    weights = exp_shifted / sum_exp
    obj = (c_max + np.log(sum_exp) / alpha) * dx
    fsize = 2 * n
    w_flipped = weights[::-1].copy()
    v = 1.0 - h
    Wf = np.fft.rfft(w_flipped, fsize)
    V = np.fft.rfft(v, fsize)
    corr_pos = np.fft.irfft(Wf * V, fsize)[n-1:2*n-1]
    W = np.fft.rfft(weights, fsize)
    H = np.fft.rfft(h, fsize)
    corr_neg = np.fft.irfft(W * H, fsize)[:n]
    grad = dx * (corr_pos - corr_neg)
    return obj, grad

def fista_optimize(h0, target, alpha, max_iters, deadline):
    n = len(h0)
    x = project_feasible(h0, target).copy()
    x_prev = x.copy()
    y = x.copy()
    t = 1.0
    best_x = x.copy()
    best_obj = compute_c5(x)
    
    # Initial step size estimation
    obj0, grad0 = lse_obj_and_grad(x, alpha)
    L = float(np.linalg.norm(grad0)) / max(np.linalg.norm(x - x_prev + 1e-10), 1e-10)
    step = 1.0 / max(L, 1.0)
    step = min(step, 1.0 / max(alpha * 0.1, 1.0))  # cap to avoid too-large steps
    step = max(step, 1e-4)
    
    for k in range(max_iters):
        if time.time() > deadline:
            break
        t_new = (1.0 + np.sqrt(1.0 + 4.0 * t * t)) / 2.0
        y = x + ((t - 1.0) / t_new) * (x - x_prev)
        y_clipped = np.clip(y, 0.0, 1.0)
        obj_y, grad_y = lse_obj_and_grad(y_clipped, alpha)
        
        # Backtracking line search
        x_new = project_feasible(y_clipped - step * grad_y, target)
        shrink = 0.0
        for _ in range(50):
            obj_new, _ = lse_obj_and_grad(x_new, alpha)
            decrease = obj_y - obj_new
            quad = 0.5 * (1.0 / step) * np.dot(x_new - y_clipped, x_new - y_clipped)
            if decrease >= quad * (1.0 - shrink):
                break
            step *= (1.0 - shrink)
            x_new = project_feasible(y_clipped - step * grad_y, target)
        else:
            step = max(step, 1e-15)
            x_new = project_feasible(y_clipped - step * grad_y, target)
        step = min(step / (1.0 - shrink), 2.0)
        
        x_prev = x
        x = x_new
        t = t_new
        
        sc = compute_c5(x)
        if sc < best_obj:
            best_obj = sc
            best_x = x.copy()
    
    return best_x, best_obj

def dual_avg_optimize(h0, target, beta, max_outer, inner_iters, deadline):
    """Lagrangian dual / multiplicative weights method."""
    n = len(h0)
    dx = 2.0 / n
    h = project_feasible(h0, target).copy()
    best_h = h.copy()
    best_score = compute_c5(h)
    
    fsize = 2 * n
    
    for outer in range(max_outer):
        if time.time() > deadline:
            break
        
        # Compute correlations and update weights
        corr = get_correlations(h)
        c_max = float(np.max(corr))
        shifted = beta * (corr - c_max)
        shifted = np.clip(shifted, -700.0, 0.0)
        p = np.exp(shifted)
        p /= p.sum()
        
        # Precompute FFT of p
        p_flip = p[::-1].copy()
        Pf = np.fft.rfft(p, fsize)
        Pff = np.fft.rfft(p_flip, fsize)
        
        # Inner loop: projected gradient ascent on Q(h) = sum_k p[k] sum_i h[i]h[i+k]
        step = 0.3
        for inner in range(inner_iters):
            if time.time() > deadline:
                break
            
            Hf = np.fft.rfft(h, fsize)
            grad1 = np.fft.irfft(Pff * Hf, fsize)[n-1:2*n-1]
            grad2 = np.fft.irfft(Pf * Hf, fsize)[:n]
            grad = grad1 + grad2
            
            # Projected gradient ascent
            h_new = h + step * grad
            h_new = project_feasible(h_new, target)
            
            sc = compute_c5(h_new)
            if sc < best_score:
                best_score = sc
                best_h = h_new.copy()
            
            # Check if we should reduce step
            h_check = h_new
            if not np.allclose(h_check, h, atol=1e-10):
                h = h_new
            else:
                step *= 0.5
    
    return best_h, best_score

def arc_polish(h, target, max_rounds, deadline):
    """Subgradient method on top active lags."""
    n = len(h)
    dx = 2.0 / n
    h_cur = h.copy()
    cur_score = compute_c5(h_cur)
    
    for rd in range(max_rounds):
        if time.time() > deadline:
            break
        corr = get_correlations(h_cur)
        sorted_idx = np.argsort(corr)[::-1]
        num_active = min(5, n-1)
        active = sorted_idx[:num_active]
        
        # Build weights (sharper than before)
        diffs = corr[active] - corr[active[0]]
        w = np.exp(diffs / 0.003)
        w /= w.sum()
        
        # Compute gradient
        grad = np.zeros(n)
        for wi, ki in zip(w, active):
            ki = int(ki)
            if ki == 0:
                continue
            jp = np.arange(0, n - ki)
            grad[jp] += wi * (1.0 - h_cur[jp + ki])
            jn = np.arange(ki, n)
            grad[jn] -= wi * h_cur[jn - ki]
        grad *= dx
        
        # Try different step sizes
        improved = False
        for eps in [0.01, 0.005, 0.002, 0.001, 0.0005, 0.0002, 0.0001]:
            h_new = h_cur - eps * grad
            h_new = project_feasible(h_new, target)
            sc = compute_c5(h_new)
            if sc < cur_score - 1e-15:
                h_cur = h_new
                cur_score = sc
                improved = True
                break
        if not improved:
            break
    
    return h_cur, cur_score

def freq_restart(h, target, alpha, deadline, rng):
    """Restart with frequency-domain perturbation."""
    n = len(h)
    # Perturb in frequency domain
    Hf = np.fft.rfft(h)
    noise = (rng.randn(len(Hf)) + 1j * rng.randn(len(Hf))) * 0.1
    # Keep DC component
    noise[0] = 0
    Hf_pert = Hf + noise
    h_pert = np.fft.irfft(Hf_pert, n)
    h_pert = project_feasible(h_pert, target)
    
    h_new, sc_new = fista_optimize(h_pert, target, alpha, 20000, deadline)
    return h_new, sc_new

def block_restart(h, target, alpha, deadline, rng):
    """Restart with block-shifting perturbation."""
    n = len(h)
    # Divide into blocks and shuffle
    n_blocks = rng.randint(4, 12)
    block_size = n // n_blocks
    indices = np.arange(n)
    # Shuffle blocks
    block_starts = np.arange(0, n_blocks * block_size, block_size)

    n = len(h)
    dx = 2.0 / n
    h_cur = project_feasible(h.copy(), target)
    best_h = h_cur.copy()
    best_score = compute_c5(h_cur)

        if time.time() > deadline:
            break

        # Get top-k lags
        top_idx = np.argsort(corr)[::-1][:top_k]

        c_top_max = float(np.max(corr[top_idx]))
        shifted = alpha * (corr[top_idx] - c_top_max)
        w_top = np.exp(shifted)
        w_top /= w_top.sum()
        
        # Compute gradient using only top-k lags
        grad = np.zeros(n)
        for wi, ki in zip(w_top, top_idx):
            ki = int(ki)
            if ki == 0:
                continue
            jp = np.arange(0, n - ki)
            grad[jp] += wi * (1.0 - h_cur[jp + ki])
            jn = np.arange(ki, n)
            grad[jn] -= wi * h_cur[jn - ki]
        grad *= dx

        step = 0.05
        for _ in range(10):

            sc_new = compute_c5(h_new)
            if sc_new < compute_c5(h_cur) or step < 1e-8:
                break
            step *= 0.5
        
        if sc_new < best_score:
            best_score = sc_new
            best_h = h_new.copy()
        h_cur = h_new
    
    return best_h, best_score
```

```python
import numpy as np
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')[n-1:]
    return float(np.max(corr)) * dx

def get_correlations(h):
    n = len(h)
    return np.correlate(h, 1.0 - h, mode='full')[n-1:]

def project_feasible(h, target):
    h = np.asarray(h, dtype=float)
    lo = float(h.min()) - 1.0
    hi = float(h.max()) + 1.0
    for _ in range(200):
        mid = (lo + hi) / 2.0
        s = np.sum(np.clip(h - mid, 0.0, 1.0))
        if s > target:
            lo = mid
        else:
            hi = mid
    return np.clip(h - (lo + hi) / 2.0, 0.0, 1.0)

def lse_obj_and_grad(h, alpha):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')[n-1:]
    c_max = float(np.max(corr))
    shifted = alpha * (corr - c_max)
    shifted = np.clip(shifted, -700.0, 0.0)
    exp_shifted = np.exp(shifted)
    sum_exp = float(exp_shifted.sum())
    weights = exp_shifted / sum_exp
    obj = (c_max + np.log(sum_exp) / alpha) * dx
    fsize = 2 * n
    w_flipped = weights[::-1].copy()
    v = 1.0 - h
    Wf = np.fft.rfft(w_flipped, fsize)
    V = np.fft.rfft(v, fsize)
    corr_pos = np.fft.irfft(Wf * V, fsize)[n-1:2*n-1]
    W = np.fft.rfft(weights, fsize)
    H = np.fft.rfft(h, fsize)
    corr_neg = np.fft.irfft(W * H, fsize)[:n]
    grad = dx * (corr_pos - corr_neg)
    return obj, grad

def fista_optimize(h0, target, alpha, max_iters, deadline):
    n = len(h0)
    x = project_feasible(h0, target).copy()
    x_prev = x.copy()
    y = x.copy()
    t = 1.0
    best_x = x.copy()
    best_obj = compute_c5(x)
    step = 1.0 / max(alpha * 0.05, 1.0)
    step = max(step, 1e-5)

    for k in range(max_iters):
        if time.time() > deadline:
            break
        t_new = (1.0 + np.sqrt(1.0 + 4.0 * t * t)) / 2.0
        y = x + ((t - 1.0) / t_new) * (x - x_prev)
        y_clipped = np.clip(y, 0.0, 1.0)
        obj_y, grad_y = lse_obj_and_grad(y_clipped, alpha)
        x_new = project_feasible(y_clipped - step * grad_y, target)
        shrink = 0.0
        for _ in range(50):
            obj_new, _ = lse_obj_and_grad(x_new, alpha)
            decrease = obj_y - obj_new
            quad = 0.5 * (1.0 / step) * np.dot(x_new - y_clipped, x_new - y_clipped)
            if decrease >= quad * (1.0 - shrink):
                break
            step *= (1.0 - shrink)
            x_new = project_feasible(y_clipped - step * grad_y, target)
        else:
            step = max(step, 1e-15)
            x_new = project_feasible(y_clipped - step * grad_y, target)
        step = min(step / (1.0 - shrink), 2.0 / max(alpha * 0.05, 1.0))
        x_prev = x
        x = x_new
        t = t_new
        sc = compute_c5(x)
        if sc < best_obj:
            best_obj = sc
            best_x = x.copy()
    return best_x, best_obj

def dual_avg_optimize(h0, target, beta, max_outer, inner_iters, deadline):
    n = len(h0)

    h = project_feasible(h0, target).copy()

        p_flip = p[::-1].copy()
        Pf = np.fft.rfft(p, fsize)

        for inner in range(inner_iters):
            if time.time() > deadline:
                break
            Hf = np.fft.rfft(h, fsize)

            h_new = project_feasible(h_new, target)

            h_old = h.copy()

    return best_h, best_score

        w = np.exp(diffs / 0.003)

        grad = np.zeros(n)
        for wi, ki in zip(w, active):

            if ki == 0:

            jp = np.arange(0, n - ki)

            grad[jn] -= wi * h_cur[jn - ki]

                best_score = sc_new
                best_h = h_new
            if tleft() < 50:
                break
            h_new, sc_new = arc_polish(best_h, target, 200, start_time + 40)
            if sc_new < best_score:
                best_score = sc_new
                best_h = h_new

    if tleft() > 200:
        for i in range(3):
            if tleft() < 80:
                break
            h_new, sc_new = block_restart(best_h, target, 5000, start_time + 60, rng)
            if sc_new < best_score:
                best_score = sc_new
                best_h = h_new
            if tleft() < 40:
                break
            h_new, sc_new = arc_polish(best_h, target, 150, start_time + 30)
            if sc_new < best_score:
                best_score = sc_new
                best_h = h_new

    # Phase 7: More dual averaging with different beta
    if tleft() > 150:
        for b in [500, 5000]:
            if tleft() < 60:
                break
            h_new, sc_new = dual_avg_optimize(best_h, target, b, 200, 20, start_time + 55)
            if sc_new < best_score:
                best_score = sc_new
                best_h = h_new

    # Phase 8: Final high-alpha FISTA + arc polish
    if tleft() > 80:
        h_new, sc_new = fista_optimize(best_h, target, 80000, 100000, start_time + 50)
        if sc_new < best_score:
            best_score = sc_new
            best_h = h_new
        if tleft() > 25:
            h_new, sc_new = arc_polish(best_h, target, 300, start_time + max(tleft() - 5, 15))
            if sc_new < best_score:
                best_score = sc_new
                best_h = h_new

    # Phase 9: Final top-k equalization + arc polish
    if tleft() > 30:
        h_new, sc_new = top_k_equalize(best_h, target, 20000, 3, 10000, start_time + max(tleft() - 10, 15))
        if sc_new < best_score:
            best_score = sc_new
            best_h = h_new
        if tleft() > 10:
            h_new, sc_new = arc_polish(best_h, target, 200, start_time + max(tleft() - 3, 5))
            if sc_new < best_score:
                best_score = sc_new
                best_h = h_new

    h_final = project_feasible(best_h, target)
    final_score = compute_c5(h_final)
    return h_final, final_score, n
```
