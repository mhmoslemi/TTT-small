```python
def extract_transitions(h, thresh=0.5):
    """Extract transition points from a binary-like array."""
    n = len(h)
    dx = 2.0 / n
    binary = (h > thresh).astype(int)
    # Find transitions
    transitions = []
    for i in range(1, n):
        if binary[i] != binary[i-1]:
            transitions.append(i * dx)
    return transitions

def transitions_to_h(transitions, n):
    """Convert transition points to a discrete h array."""
    h = np.zeros(n)

            if idxs:
                end = min(idxs, n)
            else:
                end = n
            h[idx:min(end, n)] = 1.0
            on = not on
        else:
            on = not on
    # Actually this is getting complicated. Let me use a different approach.
```

The problem with this approach is that recomputing the full correlation each step is O(n²) = 160,000 operations. For 100,000 steps, that's 16 billion operations. Too slow.

I need the O(n) update per step. Let me do it properly:

When h[j] changes from old to new (where new = 1 - old):
- For lag k (1 to n-1):
  - corr[k] = sum_{i=0}^{n-1-k} h[i](1-h[i+k])
  - Change from h[j]:
    - If j <= n-1-k: the term at i=j changes from old*(1-h[j+k]) to new*(1-h[j+k]).
      Delta = (new - old)*(1-h[j+k]) = (1-2*old)*(1-h[j+k])
    - If j-k >= 0 (i.e., j >= k): the term at i=j-k changes from h[j-k]*(1-old) to h[j-k]*(1-new).
      Delta = h[j-k]*((1-new) - (1-old)) = h[j-k]*(old - new) = h[j-k]*(2*old - 1)

So total delta for lag k:
delta_k = (1-2*old)*(1-h[j+k]) * [j <= n-1-k] + h[j-k]*(2*old-1) * [j >= k]

Let me simplify. Let s = 1-2*old (so s = +1 if old=0, s = -1 if old=1).
delta_k = s*(1-h[j+k]) * [j + k <= n-1] - s*h[j-k] * [j >= k]

Wait: (new - old) = (1-old) - old = 1 - 2*old = s.
And (old - new) = -s.

So:
- Term 1 (i=j): delta = s * (1-h[j+k]) if j+k <= n-1
- Term 2 (i=j-k): delta = -s * h[j-k] if j >= k

Total: delta_k = s * (1-h[j+k]) * [j+k < n] - s * h[j-k] * [j >= k]

This can be computed for all k in O(n) using vectorization!

```python
def flip_delta(h, j):
    n = len(h)
    old = h[j]
    s = 1.0 - 2.0 * old  # +1 if old=0, -1 if old=1
    delta = np.zeros(n)
    # Term 1: for k such that j+k < n, i.e., k < n-j
    if n - j > 1:  # k from 1 to n-j-1
        k_range = np.arange(1, n - j)
        term1 = s * (1.0 - h[j + k_range])
        delta[k_range] += term1
    # Term 2: for k such that j >= k, i.e., k <= j
    if j >= 1:
        k_range = np.arange(1, j + 1)
        term2 = -s * h[j - k_range]
        delta[k_range] += term2
    return delta
```

This is O(n) per flip! Now I can do simulated annealing efficiently.

When h[j] changes from old to new:
- For the term where i = j (contributes to corr[k] when j <= n-1-k, i.e., k <= n-1-j):
  Old contribution: h[j] * (1-h[j+k]) = old * (1-h[j+k])
  New contribution: new * (1-h[j+k]) = (1-old) * (1-h[j+k])
  Delta: (1-old - old) * (1-h[j+k]) = (1-2*old) * (1-h[j+k]) = s * (1-h[j+k])

- For the term where i+k = j, i.e., i = j-k (contributes to corr[k] when j-k >= 0, i.e., k <= j):
  Old contribution: h[j-k] * (1-h[j]) = h[j-k] * (1-old)
  New contribution: h[j-k] * (1-new) = h[j-k] * old
  Delta: h[j-k] * (old - (1-old)) = h[j-k] * (2*old - 1) = -s * h[j-k]

```python
        order = np.argsort(h[one_idx])[::-1]  # smallest first
        excess = n_ones - target
        for i in range(excess):
            h_b[one_idx[order[i]]] = 0
    elif n_ones < target:
        zero_idx = np.where(h_b == 0)[0]
        order = np.argsort(h[zero_idx])  # largest first
        deficit = target - n_ones
        for i in range(deficit):
            h_b[zero_idx[order[i]]] = 1
    return h_b
```
