Let me think about the Bezier approach more carefully.

For a Bezier curve of degree m on [0,1], with control points p_0, ..., p_m:
h(2t) = Σ_{i=0}^{m} C(m,i) * t^i * (1-t)^(m-i) * p_i

At sample point j (x_j = 2*j/n, t_j = j/n):
h[j] = Σ_{i=0}^{m} B_i^{(m)}(t_j) * p_i

where B_i^{(m)}(t) = C(m,i) * t^i * (1-t)^(m-i)

To go from h (n values) to control points p (m+1 values), we solve:
h = B * p

where B is an n × (m+1) matrix with B[j,i] = B_i^{(m)}(j/n)

If n > m+1, this is overdetermined. We solve in least squares:
p = (B^T B)^{-1} B^T h

But we also need to satisfy sum(p) = (m+1)/2. We can handle this with a constrained least squares.

where f_k(h) = dx * Σ_j h[j](1-h[j+k])

The subgradient of max_k f_k at the maximizer k* is ∇f_{k*}. The issue with subgradient methods is that they converge slowly. The log-sum-exp smooth approximation gives us a gradient that's a weighted average of the gradients of the top lags, which converges faster.

The key parameter is alpha: larger alpha → sharper focus on the max → faster convergence to the true max, but more ill-conditioned.

A good strategy is:
1. Start with moderate alpha (say 100) and broad top_k (say 20)
2. Gradually increase alpha and decrease top_k
3. Use a fixed but small step size (since the gradient magnitude is bounded)

Let me also think about the constraint handling. The projection to {h : 0 ≤ h ≤ 1, sum(h) = target} is:
1. Clip to [0,1]
2. Adjust to meet the sum constraint

This projection is the Euclidean projection onto the intersection of the box and the hyperplane. The simple iterative method (clip, adjust, clip, adjust, ...) converges but can be slow. A better approach:

The Euclidean projection onto {h : 0 ≤ h ≤ 1, sum(h) = t} can be computed in O(n log n) time:
1. Find λ such that Σ clamp(h_i - λ, 0, 1) = t
2. This is a 1D root-finding problem

Let me implement this:

```python
def project_box_sum(h, target_sum):
    """Euclidean projection onto {h: 0<=h<=1, sum(h)=target_sum}."""
    n = len(h)
    h = h.copy()
    # First check if just clipping works
    h_clipped = np.clip(h, 0.0, 1.0)
    s = h_clipped.sum()
    if abs(s - target_sum) < 1e-15:
        return h_clipped
    
    # Need to find lambda
    # We want sum(clamp(h_i - lambda, 0, 1)) = target_sum
    # clamp(x, 0, 1) = max(0, min(1, x))
    
    def objective(lam):
        return np.clip(h - lam, 0.0, 1.0).sum() - target_sum
    
    # Bisection
    lo = h.min() - 1.0
    hi = h.max() + 1.0
    for _ in range(100):
        mid = (lo + hi) / 2
        if objective(mid) > 0:
            lo = mid
        else:
            hi = mid
    lam = (lo + hi) / 2
    return np.clip(h - lam, 0.0, 1.0)
```

This is much better than iterative clipping! It's the exact Euclidean projection.

Let me verify: the set {h : 0 ≤ h_i ≤ 1, Σh_i = t} is the intersection of the box [0,1]^n and the hyperplane {h : Σh_i = t}. The Euclidean projection onto this set is indeed given by the "shrinkage" formula: h_proj = clip(h - λ, 0, 1) where λ is chosen so that Σh_proj = t.

This works because the problem is separable (the objective is Σ(h_i - h_proj_i)²) with a single linear constraint.

    # Using log for numerical stability
    from math import lgamma, exp
    B = np.zeros((n, m+1))
    log_C = np.array([lgamma(m+1) - lgamma(i+1) - lgamma(m-i+1) for i in range(m+1)])

import numpy as np
from scipy.optimize import minimize
import time
import math

def compute_corr_array(h):
    n = len(h)
    full = np.correlate(h, 1.0 - h, mode='full')
    return full[n-1:n-1+n]

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    return float(np.max(compute_corr_array(h))) * dx

def project_box_sum(h, target_sum):
    h = h.astype(float).copy()
    h_c = np.clip(h, 0.0, 1.0)
    if abs(h_c.sum() - target_sum) < 1e-14:
        return h_c
    def f(lam):
        return np.clip(h - lam, 0.0, 1.0).sum() - target_sum
    lo = h.min() - 2.0
    hi = h.max() + 2.0
    for _ in range(200):
        mid = 0.5 * (lo + hi)
        if f(mid) > 0:
            lo = mid
        else:
            hi = mid
    return np.clip(h - 0.5 * (lo + hi), 0.0, 1.0)

def smooth_obj_grad(h, alpha, top_k, dx):
    n = len(h)
    corr = compute_corr_array(h)
    if top_k < n:
        idx = np.argsort(corr)[::-1][:top_k]
        vals = corr[idx]
    else:
        idx = np.arange(n)
        vals = corr
    c_max = vals[0]
    shifted = alpha * (vals - c_max)
    shifted = np.clip(shifted, -700.0, 0.0)
    exp_s = np.exp(shifted)
    s = exp_s.sum()
    w = exp_s / s
    obj = (c_max + math.log(s) / alpha) * dx
    grad = np.zeros(n)
    for wi, ki in zip(w, idx):
        ki = int(ki)
        if ki == 0:
            grad += wi * (1.0 - 2.0 * h)
        else:
            grad[:n-ki] += wi * (1.0 - h[ki:])
            grad[ki:] -= wi * h[:n-ki]
    return obj, grad * dx

def pgrad_phase(h, n, target, t_start, t_dur, a0, a1, k0, k1):
    h_c = h.copy()
    best = h.copy()
    best_s = compute_c5(best)
    dx = 2.0 / n
    v = np.zeros(n)
    lr = 0.004
    mu_start = 0.9
    mu_end = 0.3
    t_end = t_start + t_dur
    stall = 0
    while time.time() < t_end:
        frac = min((time.time() - t_start) / t_dur, 1.0)
        a = a0 * (a1 / a0) ** frac
        tk = max(3, int(k0 + (k1 - k0) * frac))
        mu = mu_start + (mu_end - mu_start) * frac
        obj, g = smooth_obj_grad(h_c, a, tk, dx)
        v = mu * v - lr * g
        h_t = project_box_sum(h_c + v, target)
        s = compute_c5(h_t)
        if s < best_s:
            best_s = s
            best = h_t.copy()
            stall = 0
        else:
            stall += 1
        cs = compute_c5(h_c)
        if s <= cs + 1e-15:
            h_c = h_t
            lr = min(lr * 1.02, 0.025)
        else:
            lr *= 0.7
            v *= 0.5
        if stall > 200:
            v = np.zeros(n)
            lr = max(lr * 0.5, 0.001)
            stall = 0
    return best, best_s

def slsqp_polish(h, n, target, alpha, maxiter, deadline):
    dx = 2.0 / n
    nk = min(15, n)
    def of(x):
        o, _ = smooth_obj_grad(x, alpha, nk, dx)
        return o
    def gf(x):
        _, g = smooth_obj_grad(x, alpha, nk, dx)
        return g
    def con_f(x):
        return x.sum() - target
    try:
        r = minimize(of, h, jac=gf, method='SLSQP',
                     bounds=[(0.0, 1.0)] * n,
                     constraints=[{'type': 'eq', 'fun': con_f}],
                     options={'maxiter': maxiter, 'ftol': 1e-18})
        return project_box_sum(r.x, target)
    except Exception:
        return h

                scores[i] = sc
                if sc < best_s:
                    best_s = sc
                    best_h = trial.copy()
