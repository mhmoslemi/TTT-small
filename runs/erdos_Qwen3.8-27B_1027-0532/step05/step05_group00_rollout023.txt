Let me think about Frank-Wolfe more carefully.

The problem (continuous relaxation):
minimize f(h) = max_k corr[k] + lambda * (sum(h) - n/2)² (or as a constraint)
subject to 0 ≤ h[i] ≤ 1, sum(h) = n/2

Without the constraint, Frank-Wolfe is:
- At step t, compute subgradient g_t of f at h_t
  - g_t[i] = gradient of corr[k*] w.r.t. h[i] where k* = argmax corr
  - gradient of corr[k] w.r.t. h[i] = (1-h[i+k]) - h[i-k] (with boundary: terms where index is out of range are 0)
- Solve: v_t = argmin_{v: 0≤v≤1} g_t · v
  - This is: set v[i] = 1 for the smallest g_t[i] values, 0 for the rest
  - Specifically, sort g_t, pick the threshold
- Update: h_{t+1} = (1-tau_t) * h_t + tau_t * v_t
  - tau_t = 2/(t+2) (standard) or backtracking line search

With the constraint sum(h) = n/2:
- The linear minimization becomes: min g·v subject to 0≤v≤1, sum(v) = n/2
- Solution: sort g, set v[i] = 1 for the n/2 smallest g values, 0 otherwise

Actually, for the constrained Frank-Wolfe (also called Conditional Gradient for convex optimization over polytopes), the constraint sum(h) = n/2 makes the feasible set a permutahedron (or more precisely, the intersection of the hypercube with a hyperplane), which is still a polytope. The linear minimization oracle is: sort g, pick n/2 smallest.

This is very efficient! O(n log n) per iteration.

Let me also think about the subgradient more carefully.
