def project_feasible(h, target_sum):

For the LogSE gradient, the key computation is:
g[j] = dx * sum_m w[m] * d(corr[m])/dh[j]

We can write this as:
g = dx * (W_conv_forward(1-h) - W_conv_backward(h))

where W_conv_forward and W_conv_backward are specific correlation operations with the weight vector W.

Actually, let me define it more carefully. Let's define the "full" weight vector for the positive lags:
W_pos[k] = w[n-1+k] for k = 0, ..., n-1

Then:
d(corr[n-1+k])/dh[j] = (1-h[j+k]) * 1_{j+k < n} - h[j-k] * 1_{j >= k}

So:
g[j] = dx * sum_{k=0}^{n-1} W_pos[k] * [(1-h[j+k]) * 1_{j+k<n} - h[j-k] * 1_{j>=k}]

The first term: sum_{k=0}^{n-1-j} W_pos[k] * (1-h[j+k])
This is a "forward weighted average" of (1-h) starting from position j.

The second term: sum_{k=1}^{j} W_pos[k] * h[j-k]  (k=0 term is h[j]-h[j]=0, wait no)

Wait for k=0: d(corr[n-1])/dh[j] = (1-h[j]) - h[j] = 1-2h[j]. So the formula works.
