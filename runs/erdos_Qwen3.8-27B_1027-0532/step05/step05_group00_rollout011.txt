- For fixed i and k: the contribution from i is -[0<=i+k<n]*(1-h[i+k]) + [0<=i-k<n]*h[i-k]
- For fixed j and k: the contribution from j is [0<=j+k<n]*(1-h[j+k]) - [j-k<n]*h[j-k]

So δ(i,j,k) = A(i,k) + B(j,k) where:
A(i,k) = -[0<=i+k<n]*(1-h[i+k]) + [0<=i-k<n]*h[i-k]
B(j,k) = [0<=j+k<n]*(1-h[j+k]) - [0<=j-k<n]*h[j-k]

For fixed set of top shifts K = {k_1, ..., k_T}, we can precompute:
- A_matrix[i, t] = A(i, k_t) for all i and t
- B_matrix[j, t] = B(j, k_t) for all j and t

Then δ(i,j,k_t) = A_matrix[i,t] + B_matrix[j,t].

The new correlation at shift k_t is: corr[k_t] + A_matrix[i,t] + B_matrix[j,t].

We want to minimize max_t (corr[k_t] + A_matrix[i,t] + B_matrix[j,t]).
