Key insight: The log-sum-exp (LSE) approximation to max is:
max(x) ≈ (1/α) * log(Σ exp(αx_i))

As α → ∞, this approaches max. But for optimization, we need α large enough that the LSE is a tight approximation, but not so large that the optimization becomes ill-conditioned.

The previous code uses alphas like [50, 200, 800, 3000, 10000, 50000]. Let me try even larger values and more of them.

Another insight: Instead of LSE, I could use a "trimmed max" that only considers the top-k values. This gives a different smooth approximation that might be easier to optimize:

f_k(x) = (1/k) * Σ_{top k} x_i

The gradient of this is simply the average of the gradients of the top-k components. This is exactly what the subgradient method does with a fixed k!

So the subgradient method with a fixed top-k is optimizing a linear combination of the top-k correlations, which is a convex function (since each correlation is linear in h). The maximum over h of a convex function... wait, we're minimizing, and the top-k average is convex in the correlations (which are linear in h), so it's convex in h. That means any local minimum is a global minimum for this smoothed objective!

But the issue is that as we change h, the set of "top k" changes, so the function isn't truly convex in h. However, within a region where the top-k set is fixed, it is linear (hence convex), and the overall function ispiecewise linear.

This is actually nice! The subgradient method should work well for this.

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr)) * dx

def project_feasible(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    for _ in range(500):
        diff = target_sum - np.sum(h)
        if abs(diff) < 1e-13:
            break
        if diff > 0:
            mask = h < 0.9999
        else:
            mask = h > 0.0001
        cnt = int(mask.sum())
        if cnt == 0:
            break
        h = h.copy()
        h[mask] += diff / cnt
        h = np.clip(h, 0.0, 1.0)
    return h

def subgradient_optimize(h, n, target, max_steps, temp_init, temp_min, top_k, deadline):
    h_cur = h.copy()
    best_h = h_cur.copy()
    best_score = compute_c5(h_cur)
    dx = 2.0 / n
    temp = temp_init
    step_size = 0.01
    
    for step in range(max_steps):
        if time.time() > deadline:
            break
        
        corr = np.correlate(h_cur, 1.0 - h_cur, mode='full')
        c_max = float(np.max(corr))
        cur_score = c_max * dx
        
        if cur_score < best_score:
            best_score = cur_score
            best_h = h_cur.copy()
        
        # Anneal temperature
        temp = max(temp_min, temp_init * (0.999 ** step))
        
        # Compute softmax weights
        shifted = (corr - c_max) / temp
        shifted = np.clip(shifted, -50.0, 0.0)
        weights = np.exp(shifted)
        weights /= weights.sum()
        
        # Keep only top lags
        nc = len(corr)
        n_keep = min(top_k, nc)
        top_idx = np.argsort(weights)[::-1][:n_keep]
        
        # Compute gradient
        grad = np.zeros(n)
        for idx in top_idx:
            k = idx - (n - 1)
            ak = abs(k)
            wp = weights[idx]
            if wp < 1e-15:
                continue
            if ak == 0:
                grad += wp * (1.0 - 2.0 * h_cur)
            else:
                grad[ak:] += wp * (1.0 - h_cur[:n-ak])
                grad[:n-ak] -= wp * h_cur[ak:]
        grad *= dx
        
        # Backtracking line search
        alpha = step_size
        f0 = cur_score
        for _ in range(30):
            h_new = h_cur - alpha * grad
            h_new = project_feasible(h_new, target)
            f_new = compute_c5(h_new)
            if f_new < f0:
                h_cur = h_new
                step_size = min(alpha * 1.1, 0.05)
                break
            alpha *= 0.5
        else:
            step_size *= 0.5
            if step_size < 1e-10:
                break
    
    return best_h, best_score

def slsqp_optimize(h, n, target, alphas, maxiter, ftol, deadline):
    h_cur = h.copy()
    cur_score = compute_c5(h_cur)
    bounds = [(0.0, 1.0)] * n
    
    for a in alphas:
        if time.time() > deadline:
            break
        alpha = float(a)
        
        def obj(x):
            corr = np.correlate(x, 1.0 - x, mode='full')
            c_max = float(np.max(corr))
            shifted = alpha * (corr - c_max)
            shifted = np.clip(shifted, -700.0, 0.0)
            return c_max + float(np.log(np.sum(np.exp(shifted)))) / alpha
        
        def cons_eq(x):
            return np.sum(x) - target
        
        def cons_jac(x):
            return np.ones(n)
        
        cons = [{'type': 'eq', 'fun': cons_eq, 'jac': cons_jac}]
        
        try:
            res = minimize(obj, h_cur, method='SLSQP', bounds=bounds,
                           constraints=cons, options={'maxiter': maxiter, 'ftol': ftol})
            h_new = project_feasible(res.x, target)
            sc = compute_c5(h_new)
            if sc < cur_score:
                h_cur = h_new
                cur_score = sc
        except Exception:
            pass
    
    return h_cur, cur_score
