Let me think about the efficiency. For each pair (i, j), we need to compute:
- The change in the correlation when we move delta from i to j
- The optimal delta (via line search)

The correlation change for moving delta from i to j:
corr_new[m] = corr[m] + delta * g[m]
where g[m] is the "gradient" of the correlation in the direction (e_j - e_i).

Computing g:
g[m] = effect of increasing h[j] by 1 and decreasing h[i] by 1 on corr[m]

For corr[m] = sum_l h[l] * (1-h[l+m]):
- Increasing h[j] by 1: affects corr[m] at positions where l=j (adds (1-h[j+m])) and where l+m=j (subtracts h[j-m])
- Decreasing h[i] by 1: affects corr[m] at positions where l=i (subtracts (1-h[i+m])) and where l+m=i (adds h[i-m])

So g[m] = (1-h[j+m]) - h[j-m] - (1-h[i+m]) + h[i-m]
= h[i+m] - h[j+m] - h[j-m] + h[i-m] (for valid indices)

This can be computed efficiently!

The line search then finds delta* = argmin_delta max_m (corr[m] + delta * g[m])
subject to 0 <= h[i] - delta <= 1 and 0 <= h[j] + delta <= 1.

The function f(delta) = max_m (corr[m] + delta * g[m]) is the maximum of linear functions, hence convex in delta. We can find the minimum via bisection on the subgradient.

The subgradient of f at delta is g[m*] where m* = argmax_m (corr[m] + delta * g[m]).
f is decreasing where g[m*] < 0 and increasing where g[m*] > 0.

So the optimal delta* is where the sign of g[m*] changes. Bisection works:
- If g[m*] < 0, f is decreasing, so delta* > delta
- If g[m*] > 0, f is increasing, so delta* < delta

This is what the previous code does. The 22 bisection iterations give precision of about 2^-22 in the interval, which is more than enough.
