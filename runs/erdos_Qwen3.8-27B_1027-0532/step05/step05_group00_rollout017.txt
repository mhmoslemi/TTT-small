Actually, for the gradient of the smooth max:
f(h) = (1/α) * log(∑_k exp(α * C_k(h)))

where C_k(h) = ∑_i h[i] * (1 - h[i+k]) (the correlation at shift k)

∂f/∂h[j] = (1/∑_k exp(α C_k)) * ∑_k exp(α C_k) * ∂C_k/∂h[j]

And ∂C_k/∂h[j] can be computed analytically as I derived earlier.

But computing ∂C_k/∂h[j] for all k is O(n²) which is expensive. Instead, I can use the log-sum-exp with a subset of k (the top ones) to make it cheaper.

Or even simpler: just use the max (not log-sum-exp) and use subgradient methods. The subgradient of max_k C_k with respect to h[j] is the derivative of C_{k*} where k* is the argmax.

This gives: ∂f/∂h[j] = ∂C_{k*}/∂h[j]

Which is:
- If j ≤ n-1-k*: 1 - h[j+k*]
- If j ≥ k* (and j-k* ≤ n-1-k*): -h[j-k*]
- (These can both apply)

So the subgradient is:
g[j] = (1 - h[j+k*]) * [j ≤ n-1-k*] - h[j-k*] * [j ≥ k* and j-k* ≤ n-1-k*]

This is O(n) to compute! Then we can do:
h_new = clip(h - lr * g, 0, 1)
h_new = project_sum(h_new, n/2)
