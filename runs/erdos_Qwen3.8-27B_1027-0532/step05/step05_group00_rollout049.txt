```python
        if w < 1e-10:
            continue
        # (1-h[i+s]) for valid i: i in [max(0,-s), min(n-1, n-1-s)]
        i_min = max(0, -s)
        i_max = min(n-1, n-1-s)
        if i_min <= i_max:
            grad[i_min:i_max+1] += w * (1.0 - h[i_min+s:i_max+s+1])
        # -h[i-s] for valid i: i-s in [0,n-1], i in [max(0,s), min(n-1, n-1+s)]
        i_min2 = max(0, s)
        i_max2 = min(n-1, n-1+s)
        if i_min2 <= i_max2:
            grad[i_min2:i_max2+1] -= w * h[i_min2-s:i_max2-s+1]
    return grad * (2.0/n)
```

This is O(n * 2n) = O(n²) = ~734K operations for n=606, which is fast.

```python
        best_j = -1
```

f(h, α) = (2/n) * (1/α) * log(Σ_s exp(α * corr[s]))

As α → ∞, this approaches (2/n) * max_s corr[s] = C5.

The gradient:
∂f/∂h[q] = (2/n) * Σ_s p_s * ∂corr[s]/∂h[q]

where p_s = exp(α*corr[s]) / Σ exp(α*corr[s]) (softmax weights).

And ∂corr[s]/∂h[q] = (1-h[q+s]) - h[q-s] (for s≠0, with boundary conditions)
                        = 1-2h[q] (for s=0)

Wait, I showed earlier that for s≠0: ∂corr[s]/∂h[q] = (1-h[q+s]) - h[q-s]
And for s=0: ∂corr[0]/∂h[q] = 1-2h[q]

Let me verify: corr[0] = Σ h[p](1-h[p]). ∂/∂h[q] = (1-h[q]) - h[q] = 1-2h[q]. ✓

For s≠0: corr[s] = Σ h[p](1-h[p+s]). 
∂/∂h[q]: the term p=q gives (1-h[q+s]). The term where p+s=q (i.e., p=q-s) gives -h[q-s].
Total: (1-h[q+s]) - h[q-s]. ✓ (assuming both terms exist, i.e., q+s and q-s are in [0,n))

So the gradient at position q is:

where the sum is over valid s (those where q+s and/or q-s are in [0,n)).

This can be computed as:

```python
    g = np.zeros(n)
    for s_idx in range(2*n-1):

        w = p_softmax[s_idx]
```
