    # For each lag k, compute partial derivatives and weight by exponential scaling
    for k in range(1, max_lag+1):
        # Compute weight based on current correlation for lag k
        w = weights[k-1]
        # Directional derivative
        if k == 0:
            part = dx * (1 - 2*h[k])
            grad[k] += w * part
        else:
            idx1_end = n - k
            part_neg = dx * (-h[k:])   # -h(x-k) term
            part_pos = dx * (1 - h[:n-k])  # (1-h(x+k)) term
            grad[:idx1_end+1] += w * part_pos
            grad[k:] -= w * part_neg
    return grad

Constraint handling:
- Lagrange multiplier formulation: 
    min h ↦ C5(h) 
    s.t. ∫ h dx = 1

The gradient is modified by the Lagrange multiplier λ, effectively transforming the optimization to unconstrained minimization of:
    L(h) = λ * (∫h dx - 1) + C5(h)

λ is adaptively tuned during optimization.

3. Implementation procedure

3.1 Phasing:

Phase1: Initial Projection and Warmstart
   Input: initial_h_values (n=400)
   Steps:
   1. Create a reduced-coordinate representation h_sample = initial_h_values
   2. Compute initial lag correlations
   3. Prioritize lags based on exponential weighting
   4. Perform grid sampling on priority regions
   5. Create a warmstart candidate using top-dimensional coordinates

Phase2: Directional Optimization
   Steps:
   1. Initialize scores for prioritized lags
   2. Set up Lagrange multiplier λ and dynamic update scheme
   3. Key Variables:
        • h_vec: 400-dimensional vector representation
        • target_int: integral constraint value (200.0 for n=400)
        • max_iter = 200
        • λ_min = 0.001, λ_max = 0.1
        • step_size schedule: starting at 0.003, reducing by 0.98 each step

   4. Main optimization loop:
        For iteration in range(max_iter):
            Compute directional gradient
            Compute projected gradient direction
            Compute line-search using gradient descent
            Update h_vec
            Check constraint: adjust to satisfy integral constraint via perpendicular projection
            Update λ based on constraint satisfaction

   5. Maintain a candidate archive of best solutions at each priority level

Phase3: Geometric Projection

   3.3.1 Geometric components:
        - s(t): current objective value
        - m(t): median of all candidate scores
        - r(t): relative improvement rate

   3.3.2 Constraint handling:
        We maintain the integral constraint by projecting optimization steps onto the feasible manifold. The constraint satisfaction condition is: ∫h dx ≈ target_int.

   3.3.3 Optimization update:
        h_new = h_old - α ∇L(h_old) + Π_{x: ∫x≈target_int}(η(x))

        Where Π is the projection operator onto the constrained manifold.

Phase4: Final adjustments

   4.4.1 After main optimization:
        1. Apply a secondary round of geometric projection
        2. Use integral constraint to determine appropriate h scaling
        3. Clip/hardadjust to enforce h ∈ [0,1] in regions where overshoot/undershoot occurs
        4. Final overlap score computation

3.4.5 Geometric Projection pseudocode:

def geometric_projection(h_proj, target, convergence_threshold=1e-6):
    new_h = h_proj.copy()
    diff = np.abs(np.sum(new_h) * dx - target)
    if diff <= convergence_threshold:
        return new_h
    else:
        # Adjust primarily the first quarter of samples
        adjustment = (target - np.sum(new_h) * dx) / 2
        new_h[0::4] += adjustment * np.sign(new_h[0::4])
        return np.clip(new_h, 0, 1)
