- Solve F = 0 using Newton's method (Jacobian is |A_k|+1 by n+1)

1. Solve with current active set
2. Check if any inactive constraint is violated
3. If yes, add it to the active set and re-solve
4. If no inactive constraint is violated and all active constraints are satisfied with equality, we're done (KKT conditions satisfied)

Now, let me think about whether the LP-M-M is actually going to help. The concern is that the linearization might not be accurate enough, and the LP solution might not be a good direction.

An alternative to LP-M-M that might be more effective: **Frank-Wolfe (conditional gradient) method** applied to a smoothed version of the problem.

The idea: minimize f(h) = max_m A(m) (smoothed) over the polytope {h: 0≤h≤1, sum h = n/2}.

Frank-Wolfe iterates:
1. h_{t+1} = (1-γ_t) h_t + γ_t * s_t
2. s_t = argmin_{s ∈ P} ⟨∇f(h_t), s⟩ (linear minimization over the polytope)

The linear minimization over {h: 0≤h≤1, sum h = n/2} is simple: set s[j]=1 for the n/2 indices with the smallest gradient components, and s[j]=0 otherwise.

This is very fast! Each iteration is O(n log n) for the sort.

The smoothed function f_α(h) = (1/α) log(sum_m exp(α * A(m))) has gradient:
∇f_α(h) = sum_m (exp(α*A(m)) / sum_k exp(α*A(k))) * ∇A(m)

This is a weighted sum of the gradients, with weights concentrated on the largest A(m).

Frank-Wolfe with this smoothed objective should converge to a stationary point. With decreasing step sizes (γ_t = 2/(t+2)), it has O(1/t) convergence rate.

This is much faster per iteration than SLSQP and might give comparable quality. Let me implement this.

Actually, the issue with Frank-Wolfe is that it converges slowly (O(1/t)). For a precise answer, I'd need many iterations. But each iteration is very cheap (O(n log n)), so I can afford lots of them.

```python
def frank_wolfe(h_init, n, target, time_limit, alpha=100.0):
    h = h_init.copy()
    h = project_feasible(h, target)
    start = time.time()
    dx = 2.0 / n
    mid = n - 1
    idx = np.arange(n)
    
    best_c5 = compute_c5(h)
    best_h = h.copy()
    t = 0
    
    while time.time() - start < time_limit:
        t += 1
        gamma = 2.0 / (t + 2.0)
        
        # Compute smoothed gradient
        corr = np.correlate(h, 1.0 - h, mode='full')
        exp_alpha = np.exp(alpha * (corr - corr.max()))
        weights = exp_alpha / exp_alpha.sum()
        
        # Gradient = weighted sum of individual gradients
        grad = np.zeros(n)
        for m in range(len(corr)):
            if weights[m] < 1e-8:
                continue
            shift = m - mid
            if shift >= 0:
                grad[shift:] += weights[m] * (1.0 - h[:n-shift])
                grad[:n-shift] -= weights[m] * h[shift:]
            else:
                s = -shift
                grad[:n-s] += weights[m] * (1.0 - h[s:])
                grad[s:] -= weights[m] * h[:n-s]
        
        # Frank-Wolfe step: s = argmin grad·s subject to 0≤s≤1, sum s = n/2
        # Sort by gradient, take n/2 smallest
        sorted_idx = np.argsort(grad)
        s = np.zeros(n)
        s[sorted_idx[:n//2]] = 1.0
        
        # Update
        h_new = (1 - gamma) * h + gamma * s
        h_new = project_feasible(h_new, target)
        
        c5_new = compute_c5(h_new)
        if c5_new < best_c5:
            best_c5 = c5_new
            best_h = h_new
        h = h_new
    
    return best_h, best_c5
```

_g_n = 0
_g_target = 0.0

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr)) * dx

def project_feasible(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    n = len(h)
    for _ in range(50):
        diff = target_sum - np.sum(h)
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            mask = h < 1.0 - 1e-15
        else:
            mask = h > 1e-15
        if not mask.any():
            break
        h[mask] += diff / mask.sum()
        h = np.clip(h, 0.0, 1.0)
    return h

def _smooth_obj(x, alpha):
    corr = np.correlate(x, 1.0 - x, mode='full')

    return float(c_max + np.log(np.sum(np.exp(shifted))) / alpha)
