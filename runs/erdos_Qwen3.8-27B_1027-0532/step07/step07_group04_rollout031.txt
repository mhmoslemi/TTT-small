6. If g[k*] == 0 (or active set has both signs): we're at the optimum

This is the same bisection but we can vectorize it over all pairs simultaneously!

**Vectorized version:**
- Stack all g vectors: G shape (n_pairs, n_corr)
- For each bisection step, compute: vals = corr[None,:] + deltas[:,None] * G
- Find max: f = vals.max(axis=1)
- Find argmax: k_star = vals.argmax(axis=1)
- Get g at k_star: g_star = G[np.arange(n_pairs), k_star]
- Update deltas based on sign of g_star

This is O(n_pairs * n_corr * n_bisection) but fully vectorized in numpy, which is much faster than a Python loop.

For n_pairs = 10000 (100*100), n_corr = 1199, n_bisection = 8:
10000 * 1199 * 8 = 95.9M operations. In numpy, this should take about 0.5-1 second.

Compare to the original: 10000 pairs * 16 bisection steps * 1199 elements = same operations but done in a Python loop, taking maybe 10-30 seconds.

So vectorization gives a 10-30x speedup!

But wait, 10000 pairs * 1199 = 12M floats = 96MB. That's a lot of memory. Let's use smaller batches.

Actually, for n_cand = 50, n_pairs = 2500, n_corr = 1199: 2500 * 1199 = 3M floats = 24MB. That's fine.

Let me redesign the algorithm:

```python
def vectorized_cd(h, n, target, time_limit, n_cand=50, max_bisect=8):
    dx = 2.0 / n
    start = time.time()
    n_corr = 2 * n - 1
    shifts = np.arange(-(n-1), n)
    idxs = np.arange(n)
    mid = n - 1
    
    h = h.copy().astype(float)
    best_c5 = compute_c5(h)
    best_h = h.copy()
    consecutive_no_improve = 0
    
    # Precompute change matrix
    change = np.zeros((n, n_corr))
    for p in range(n):
        pos = (p + shifts >= 0) & (p + shifts < n)
        neg = (p - shifts >= 0) & (p - shifts < n)
        change[p, pos] += (1.0 - h[p + shifts[pos]])
        change[p, neg] -= h[p - shifts[neg]]
    
    for sweep in range(100000):
        if time.time() - start > time_limit:
            break
        
        corr = np.correlate(h, 1.0 - h, mode='full')
        c5_val = float(np.max(corr)) * dx
        
        if c5_val < best_c5 - 1e-13:
            best_c5 = c5_val
            best_h = h.copy()
            consecutive_no_improve = 0
        else:
            consecutive_no_improve += 1
            if consecutive_no_improve > 200:
                break
        
        # Gradient for candidate selection
        k_star = int(np.argmax(corr)) - mid
        grad = np.zeros(n)
        v1 = (idxs - k_star >= 0) & (idxs - k_star < n)
        v2 = (idxs + k_star >= 0) & (idxs + k_star < n)
        grad[v1] += (1.0 - h[idxs[v1] - k_star])
        grad[v2] -= h[idxs[v2] + k_star]
        grad -= np.mean(grad)
        
        sorted_idx = np.argsort(grad)
        low_set = sorted_idx[:n_cand]
        high_set = sorted_idx[-n_cand:]
        
        # Build all candidate pairs
        pairs = []
        G = []  # g = change[j] - change[i]
        deltas_lo = []
        deltas_hi = []
        
        for ii in range(len(high_set)):
            i = int(high_set[ii])
            for jj in range(len(low_set)):
                j = int(low_set[jj])
                if i == j:
                    continue
                d_lo = max(h[i] - 1.0, -h[j])
                d_hi = min(h[i], 1.0 - h[j])
                if d_hi - d_lo < 1e-12:
                    continue
                pairs.append((i, j))
                G.append(change[j] - change[i])
                deltas_lo.append(d_lo)
                deltas_hi.append(d_hi)
        
        if not pairs:
            continue
        
        G = np.array(G)  # shape (n_pairs, n_corr)
        deltas_lo = np.array(deltas_lo)
        deltas_hi = np.array(deltas_hi)
        
        # Vectorized bisection
        n_pairs = len(pairs)
        d_lo = deltas_lo.copy()
        d_hi = deltas_hi.copy()
        
        for _ in range(max_bisect):
            d_mid = 0.5 * (d_lo + d_hi)
            vals = corr[None, :] + d_mid[:, None] * G  # (n_pairs, n_corr)
            f_vals = vals.max(axis=1)
            k_active = vals.argmax(axis=1)
            g_at_active = G[np.arange(n_pairs), k_active]
            
            # Where g_at_active > 0, f is increasing -> reduce d_hi
            # Where g_at_active < 0, f is decreasing -> increase d_lo
            inc_mask = g_at_active > 1e-12
            dec_mask = g_at_active < -1e-12
            d_hi[inc_mask] = d_mid[inc_mask]
            d_lo[dec_mask] = d_mid[dec_mask]
        
        d_star = 0.5 * (d_lo + d_hi)
        
        # Evaluate
        final_vals = corr[None, :] + d_star[:, None] * G
        final_max = final_vals.max(axis=1) * dx
        
        best_improve = c5_val
        best_pair_idx = -1
        for idx in range(n_pairs):
            if final_max[idx] < best_improve:
                best_improve = final_max[idx]
                best_pair_idx = idx
        
        if best_pair_idx >= 0:
            i, j = pairs[best_pair_idx]
            delta = d_star[best_pair_idx]
            h[i] -= delta
            h[j] += delta
            h = np.clip(h, 0.0, 1.0)
            h = project_feasible(h, target)
            # Update change matrix
            pos_i = (i + shifts >= 0) & (i + shifts < n)
            neg_i = (i - shifts >= 0) & (i - shifts < n)
            change[i, :] = 0
            change[i, pos_i] += (1.0 - h[i + shifts[pos_i]])
            change[i, neg_i] -= h[i - shifts[neg_i]]
            pos_j = (j + shifts >= 0) & (j + shifts < n)
            neg_j = (j - shifts >= 0) & (j - shifts < n)
            change[j, :] = 0
            change[j, pos_j] += (1.0 - h[j + shifts[pos_j]])
            change[j, neg_j] -= h[j - shifts[neg_j]]
    
    return best_h, best_c5
```

Wait, this is still building G in a Python loop which is slow. Let me vectorize that too.

Actually, for n_cand=50, we have 2500 pairs. The loop to build G takes 2500 iterations of numpy array subtraction (each O(n_corr)). That's 2500 * 1199 = 3M operations in the loop. In Python, this might take 0.1-0.5s. With the vectorized bisection being ~0.1s, the loop is the bottleneck.

Let me restructure: instead of building G explicitly, compute it on the fly during bisection.

Actually, a better approach: use matrix operations.

change has shape (n, n_corr). For all pairs (i, j) where i in high_set and j in low_set:
G[pair_idx] = change[j] - change[i]

If high_set has shape (n_cand,) and low_set has shape (n_cand,):
G = change[low_set[:,None], :] - change[high_set[None,:], :]  # shape (n_cand, n_cand, n_corr)

But this is n_cand^2 * n_corr = 2500 * 1199 = 3M floats = 24MB. That's fine.

Then we flatten and do the bisection on the flattened version.

Let me rewrite:

```python
def vectorized_cd_v2(h, n, target, time_limit, n_cand=50, max_bisect=10):

        else:
            consecutive_no_improve += 1
            if consecutive_no_improve > 200:
                break
        
        # Gradient for candidate selection (using top shifts)
        top_k = 3
        top_idxs = np.argsort(corr)[-top_k:]
        grad = np.zeros(n)
        for s_idx in top_idxs:
            k = int(s_idx) - mid
            v1 = (idxs - k >= 0) & (idxs - k < n)
            v2 = (idxs + k >= 0) & (idxs + k < n)
            grad[v1] += (1.0 - h[idxs[v1] - k])
            grad[v2] -= h[idxs[v2] + k]
        grad /= top_k
        grad -= np.mean(grad)
        
        sorted_idx = np.argsort(grad)
        low_set = sorted_idx[:n_cand].astype(int)
        high_set = sorted_idx[-n_cand:].astype(int)
        
        # Build G matrix: G[ii, jj] = change[low_set[jj]] - change[high_set[ii]]
        # Shape: (n_cand, n_cand, n_corr)
        G = change[low_set[:, None], :] - change[high_set[None, :], :]
        
        # Delta bounds
        # For pair (high_set[ii], low_set[jj]):
        # d_lo = max(h[high_set[ii]] - 1, -h[low_set[jj]])
        # d_hi = min(h[high_set[ii]], 1 - h[low_set[jj]])
        hi_vals = h[high_set]  # (n_cand,)
        lo_vals = h[low_set]  # (n_cand,)
        d_lo_mat = np.maximum(hi_vals[:, None] - 1.0, -lo_vals[None, :])  # (n_cand, n_cand)
        d_hi_mat = np.minimum(hi_vals[:, None], 1.0 - lo_vals[None, :])  # (n_cand, n_cand)
        
        # Mask out invalid pairs (where i == j or no room to move)
        valid = (d_hi_mat - d_lo_mat) > 1e-12
        # Also exclude i == j
        eye_mask = np.eye(n_cand, dtype=bool)
        valid[eye_mask] = False
        
        if not valid.any():
            continue
        
        # Flatten for bisection
        G_flat = G[valid]  # (n_valid, n_corr)
        d_lo = d_lo_mat[valid].copy()
        d_hi = d_hi_mat[valid].copy()
        
        n_valid = len(d_lo)
        if n_valid == 0:
            continue
        
        # Vectorized bisection
        for _ in range(max_bisect):
            d_mid = 0.5 * (d_lo + d_hi)
            vals = corr[None, :] + d_mid[:, None] * G_flat
            f_vals = vals.max(axis=1)
            k_active = vals.argmax(axis=1)
            g_at_active = G_flat[np.arange(n_valid), k_active]

            d_hi[inc_mask] = d_mid[inc_mask]
            d_lo[dec_mask] = d_mid[dec_mask]
        
        d_star = 0.5 * (d_lo + d_hi)
        
        # Final evaluation
        final_vals = corr[None, :] + d_star[:, None] * G_flat
        final_max = final_vals.max(axis=1) * dx
        
        best_idx = int(np.argmin(final_max))
        if final_max[best_idx] < c5_val - 1e-14:
            # Map back to (ii, jj)
            valid_idx = np.where(valid)[0]
            ii, jj = np.unravel_index(valid_idx[best_idx], (n_cand, n_cand))
            i = int(high_set[ii])
            j = int(low_set[jj])

            h[i] -= delta
            h[j] += delta
            h = np.clip(h, 0.0, 1.0)
            h = project_feasible(h, target)
            
            # Update change matrix
            for p in [i, j]:
                change[p, :] = 0
                pos = (p + shifts >= 0) & (p + shifts < n)
                neg = (p - shifts >= 0) & (p - shifts < n)
                change[p, pos] += (1.0 - h[p + shifts[pos]])
                change[p, neg] -= h[p - shifts[neg)]
    
    return best_h, best_c5
```

This should be significantly faster than the original. The key speedups are:
1. Vectorized bisection (all pairs simultaneously)
2. Matrix operations for G computation
3. Fewer bisection iterations needed (10 instead of 16) due to better convergence

Now, let me also think about the overall strategy:

1. Start with initial_h_values (n=400)
2. Do a quick SLSQP polish
3. Interpolate to n=600, run vectorized CD
4. Interpolate to n=800, run vectorized CD  
5. SLSQP polish
6. More CD
7. Final polish

The key question is: will the vectorized CD find a better solution than the sequential CD? It should, because:
- It can do more sweeps in the same time
- It evaluates more candidate pairs per sweep (all at once)
- The better candidate evaluation leads to better moves

Let me also add a "multi-shift gradient" approach where we use a weighted combination of gradients from the top shifts for candidate selection.

One more idea: **alternating between CD and a "smoothing" step**. The smoothing step would be a few gradient descent steps on the smooth objective (log-sum-exp), which can help escape local minima of the max function.

Let me write the final solution:

```python
import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr)) * dx

def project_feasible(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    n = len(h)
    for _ in range(100):
        diff = target_sum - np.sum(h)
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            mask = h < 1.0 - 1e-15
        else:
            mask = h > 1e-15
        if not mask.any():
            h = np.clip(h + diff / n, 0.0, 1.0)
            break
        h[mask] += diff / mask.sum()
        h = np.clip(h, 0.0, 1.0)
    return h

def interpolate_to(h_src, n_dst, target_dst):
    n_src = len(h_src)
    if n_src == n_dst:
        return project_feasible(h_src.copy(), target_dst)
    x_new = np.linspace(0.0, 1.0, n_dst)
    x_old = np.linspace(0.0, 1.0, n_src)
    h_out = np.interp(x_new, x_old, h_src)
    return project_feasible(h_out, target_dst)

def smooth_obj(x, alpha):
    corr = np.correlate(x, 1.0 - x, mode='full')
    c_max = np.max(corr)
    shifted = np.clip(alpha * (corr - c_max), -500.0, 0.0)
    return float(c_max + np.log(np.sum(np.exp(shifted))) / alpha)

_g_n = 0
_g_target = 0.0

def _cons_fun(x):
    return np.sum(x) - _g_target

def _cons_jac(x):
    return np.ones(_g_n)

def slsqp_round(h_start, n, target, alphas, maxiter_per_alpha, ftol=1e-14,
                time_limit=None, start_time=None):
    global _g_n, _g_target
    _g_n = n
    _g_target = target
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': _cons_fun, 'jac': _cons_jac}]
    h_cur = h_start.copy()
    cur_score = compute_c5(h_cur)
    for alpha in alphas:
        if time_limit is not None and start_time is not None:
            if time.time() - start_time > time_limit:
                break
        try:
            res = minimize(smooth_obj, h_cur, args=(alpha,),
                           method='SLSQP', bounds=bounds, constraints=cons,
                           options={'maxiter': maxiter_per_alpha, 'ftol': ftol})
            h_new = project_feasible(res.x, target)
            sc = compute_c5(h_new)
            if sc < cur_score:
                cur_score = sc
                h_cur = h_new
        except Exception:
            pass
    return h_cur, cur_score

def vectorized_cd(h_init, n, target, time_limit, n_cand=50, max_bisect=10,
                  top_k_shifts=3, max_sweeps=50000, max_no_improve=300):
    dx = 2.0 / n
    start = time.time()
    n_corr = 2 * n - 1
    shifts = np.arange(-(n-1), n)
    idxs = np.arange(n)
    mid = n - 1
    
    h = h_init.copy().astype(float)
    best_c5 = compute_c5(h)
    best_h = h.copy()
    consecutive_no_improve = 0
    
    # Precompute change matrix
    change = np.zeros((n, n_corr))
    for p in range(n):
        pos = (p + shifts >= 0) & (p + shifts < n)
        neg = (p - shifts >= 0) & (p - shifts < n)
        change[p, pos] += (1.0 - h[p + shifts[pos]])
        change[p, neg] -= h[p - shifts[neg]]
    
    for sweep in range(max_sweeps):
        if time.time() - start > time_limit:
            break
        
        corr = np.correlate(h, 1.0 - h, mode='full')
        c5_val = float(np.max(corr)) * dx
        
        if c5_val < best_c5 - 1e-13:
            best_c5 = c5_val
            best_h = h.copy()
            consecutive_no_improve = 0
        else:
            consecutive_no_improve += 1
            if consecutive_no_improve > max_no_improve:
                break
        
        # Multi-shift gradient for candidate selection
        top_idxs = np.argsort(corr)[-top_k_shifts:]
        grad = np.zeros(n)
        for s_idx in top_idxs:
            k = int(s_idx) - mid
            v1 = (idxs - k >= 0) & (idxs - k < n)
            v2 = (idxs + k >= 0) & (idxs + k < n)
            grad[v1] += (1.0 - h[idxs[v1] - k])
            grad[v2] -= h[idxs[v2] + k]
        grad /= top_k_shifts
        grad -= np.mean(grad)
        
        sorted_idx = np.argsort(grad)
        low_set = sorted_idx[:n_cand].astype(np.int32)
        high_set = sorted_idx[-n_cand:].astype(np.int32)
        
        # Build G matrix
        G = change[low_set[:, None], :] - change[high_set[None, :], :]
        
        hi_vals = h[high_set]
        lo_vals = h[low_set]
        d_lo_mat = np.maximum(hi_vals[:, None] - 1.0, -lo_vals[None, :])
        d_hi_mat = np.minimum(hi_vals[:, None], 1.0 - lo_vals[None, :])
        
        valid = (d_hi_mat - d_lo_mat) > 1e-12
        eye_mask = np.eye(n_cand, dtype=bool)
        valid[eye_mask] = False
        
        if not valid.any():
            continue
        
        G_flat = G[valid]
        d_lo = d_lo_mat[valid].copy()
        d_hi = d_hi_mat[valid].copy()
        
        n_valid = len(d_lo)
        
        # Vectorized bisection
        for _ in range(max_bisect):
            d_mid = 0.5 * (d_lo + d_hi)
            vals = corr[None, :] + d_mid[:, None] * G_flat
            f_vals = vals.max(axis=1)
            k_active = vals.argmax(axis=1)
            g_at_active = G_flat[np.arange(n_valid), k_active]
            
            inc_mask = g_at_active > 1e-12
            dec_mask = g_at_active < -1e-12
            d_hi[inc_mask] = d_mid[inc_mask]
            d_lo[dec_mask] = d_mid[dec_mask]
        
        d_star = 0.5 * (d_lo + d_hi)
        
        # Final evaluation
        final_vals = corr[None, :] + d_star[:, None] * G_flat
        final_max = final_vals.max(axis=1) * dx
        
        best_idx = int(np.argmin(final_max))
        if final_max[best_idx] < c5_val - 1e-14:
            valid_positions = np.where(valid)[0]
            flat_idx = valid_positions[best_idx]
            ii, jj = np.unravel_index(flat_idx, (n_cand, n_cand))
            i = int(high_set[ii])
            j = int(low_set[jj])
            delta = d_star[best_idx]
            
            h[i] -= delta
            h[j] += delta
            h = np.clip(h, 0.0, 1.0)
            h = project_feasible(h, target)
            
            for p in [i, j]:
                change[p, :] = 0
                pos = (p + shifts >= 0) & (p + shifts < n)
                neg = (p - shifts >= 0) & (p - shifts < n)
                change[p, pos] += (1.0 - h[p + shifts[pos]])
                change[p, neg] -= h[p - shifts[neg]]
    
    return best_h, best_c5

def sa_cd(h_init, n, target, time_limit, max_steps=30000,
          t_start=0.03, t_end=0.0002, n_cand=50, seed=123):
    """Simulated annealing with CD-like moves."""
    dx = 2.0 / n
    start = time.time()
    n_corr = 2 * n - 1
    shifts = np.arange(-(n-1), n)
    idxs = np.arange(n)
    mid = n - 1
    rng = np.random.RandomState(seed)
    
    h = h_init.copy().astype(float)
    best_c5 = compute_c5(h)
    best_h = h.copy()
    consecutive_no_improve = 0
    
    change = np.zeros((n, n_corr))
    for p in range(n):
        pos = (p + shifts >= 0) & (p + shifts < n)
        neg = (p - shifts >= 0) & (p - shifts < n)
        change[p, pos] += (1.0 - h[p + shifts[pos]])
        change[p, neg] -= h[p - shifts[neg]]
    
    for step in range(max_steps):
        if time.time() - start > time_limit:
            break
        if consecutive_no_improve > 500:
            break
        
        progress = min(step / max_steps, 1.0)
        temperature = t_start * (t_end / t_start) ** progress
        
        corr = np.correlate(h, 1.0 - h, mode='full')
        c5_val = float(np.max(corr)) * dx
        
        k_star = int(np.argmax(corr)) - mid
        grad = np.zeros(n)
        v1 = (idxs - k_star >= 0) & (idxs - k_star < n)
        v2 = (idxs + k_star >= 0) & (idxs + k_star < n)
        grad[v1] += (1.0 - h[idxs[v1] - k_star])
        grad[v2] -= h[idxs[v2] + k_star]
        grad -= np.mean(grad)
        
        sorted_idx = np.argsort(grad)
        low_set = sorted_idx[:n_cand]
        high_set = sorted_idx[-n_cand:]
        
        i = int(high_set[rng.randint(len(high_set))])
        j = int(low_set[rng.randint(len(low_set))])
        if i == j:
            continue
        
        d_lo = max(h[i] - 1.0, -h[j])
        d_hi = min(h[i], 1.0 - h[j])
        if d_hi - d_lo < 1e-12:
            continue
        
        delta = (d_hi - d_lo) * rng.rand() + d_lo
        
        g = change[j] - change[i]
        approx_new = np.max(corr + delta * g) * dx
        delta_c = approx_new - c5_val
        
        accept = False
        if delta_c < -1e-14:
            accept = True
        elif temperature > 1e-10:
            if rng.rand() < np.exp(-max(delta_c, 0.0) / max(temperature * dx, 1e-15)):
                accept = True
        
        if accept:
            h[i] -= delta
            h[j] += delta
            h = np.clip(h, 0.0, 1.0)
            h = project_feasible(h, target)
            
            for p in [i, j]:
                change[p, :] = 0
```
