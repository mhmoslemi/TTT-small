Terms involving h[j]:
1. i = j: term is h[j] * (1-h[j+m]) * dx, valid when 0 ≤ j+m < n

= B_m + h[j] * (1-h[j+m]) * dx - h[j] * h[j-m] * dx

where B_m = c[m] - h[j]*(1-h[j+m])*dx - h[j-m]*(1-h[j])*dx

= B_m + h[j] * dx * [(1-h[j+m]) - h[j-m]] (with appropriate boundary handling)

So A_m = dx * [(1-h[j+m]) - h[j-m]] (with terms set to 0 if index out of range)
And B_m = c[m] - A_m * h[j]

We want to minimize max_m (A_m * t + B_m) for t ∈ [0,1].

This is a convex piecewise-linear function of t. The minimum can be found by:
1. Computing the subdifferential at various points
2. Or more practically: since it's 1D convex, use a simple bisection on the subgradient

The subgradient of f(t) = max_m (A_m * t + B_m) at t is {A_m : m ∈ active(t)} where active(t) = {m : A_m * t + B_m = f(t)}.

f is minimized where 0 ∈ ∂f(t*, i.e., there exist active m+ with A_{m+} ≥ 0 and active m- with A_{m-} ≤ 0.

Algorithm for exact 1D minimization:
1. Start with t = h[j] (current value)
2. Evaluate f(t) and find active set
3. If all active A_m > 0: minimum is to the left, set upper bound = t
4. If all active A_m < 0: minimum is to the right, set lower bound = t
5. If both signs present: we're at the minimum (or very close)
6. Otherwise, bisect

This converges in O(log(1/epsilon)) iterations, each O(n). For n=600 and 50 iterations, that's 30,000 per coordinate, 18,000,000 per sweep. At 100 MHz effective, that's 0.18 seconds per sweep. We can do ~1000 sweeps in 180 seconds. That's feasible!

One approach: do the 1D optimization for h[j] ignoring the sum constraint, then project back. But the projection might undo the improvement.

Better approach: optimize h[j] and h[j'] simultaneously (a pair), ensuring the sum is preserved. This is the "pair CD" but with exact 1D (well, 1D since we're moving along a line) optimization.

For a pair (j, j'): move δ from j to j', i.e., h[j] -= δ, h[j'] += δ.
c[m] becomes:

- Doesn't increase other correlations that are close to the max

This suggests looking at the "second-order" effect: after reducing the max, what's the new max? If the new max is at a different shift, we might have just traded one problem for another.

**New idea: "Lookahead" pair CD**

For each candidate pair (i,j), compute:
1. The immediate improvement in the current max
2. The "regret": how much the second-worst (or third-worst) correlation increases
3. Choose the pair that maximizes (improvement - regret * λ) for some λ

This is more expensive but might find better moves.

Actually, let me think about this from a different angle. The problem is essentially:
minimize max_k c[k]

At the optimum (assuming the max is achieved at a unique k*), we need:
- For all j: the directional derivative in the "good" direction for c[k*] is non-negative
- This means: for all j, the best we can do is keep c[k*] constant while trying to reduce it, but we can't without increasing some other c[k]

If the max is achieved at multiple k values (say k1 and k2), then at the optimum:
- c[k1] = c[k2] = max
- We can't reduce either without increasing the other

This is the "active set" condition. The LSE approach handles this by softening the max, but the pair CD only looks at one k at a time.

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr)) * dx

def project_feasible(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    diff = target_sum - np.sum(h)
    if abs(diff) < 1e-14:
        return h
    if diff > 0:
        idx = np.where(h < 1.0 - 1e-10)[0]
    else:
        idx = np.where(h > 1e-10)[0]
    if len(idx) == 0:
        return h
    h = h.copy()
    h[idx] += diff / len(idx)
    h = np.clip(h, 0.0, 1.0)
    residual = target_sum - np.sum(h)
    if abs(residual) > 1e-10:
        if residual > 0:
            idx2 = np.where(h < 1.0)[0]
        else:
            idx2 = np.where(h > 0.0)[0]
        if len(idx2) > 0:
            h[idx2] += residual / len(idx2)
            h = np.clip(h, 0.0, 1.0)
    return h

Let me also think about a fundamentally different optimization approach:

**Approach: Frank-Wolfe (Conditional Gradient) Method**

The problem is: minimize f(h) = max_k c_k(h) subject to h ∈ P where P = {h : 0 ≤ h ≤ 1, sum(h) = target}.

Frank-Wolfe works for non-convex f on convex P (it's not guaranteed to find global optimum, but it's simple and often works well in practice):

1. Start with h^0
2. At each iteration:
   a. Compute subgradient g = ∂f(h^t) (gradient of the active correlation)
   b. Solve: s = argmin_{s ∈ P} <g, s>
      This is a linear program: minimize sum_i g[i] * s[i] subject to 0 ≤ s ≤ 1, sum(s) = target
      The solution is: s[i] = 1 for i in top n_target indices of -g, s[i] = 0 otherwise (with one fractional entry to satisfy the sum exactly)
   c. Update: h^{t+1} = h^t + γ_t * (s - h^t) where γ_t is a step size

The FW method is attractive because:
- Each iteration is O(n log n) (sorting for the LP solution)
- It naturally handles the constraints
- The step size can be chosen by line search (minimize f along the line from h^t to s)
- It has the "away step" variant which can be much faster

Let me implement the FW method with away steps:

**FW with away steps (FW-A)**:
1. Maintain a support set S (indices where h is not at bound)
2. At each iteration:
   a. Compute subgradient g
   b. Find s = argmin <g, s> over P (as before)
   c. Also find i_best = argmin_{i ∈ S} <g, e_i - h_i / |S|> (the "away" direction)
   d. Choose between moving toward s or away from i_best
   e. Line search

This is more complex but often converges much faster.

Actually, for our problem, the FW method has a nice property: the "vertex" of the constraint set P that minimizes <g, s> is simply:
- Set s[i] = 1 for the target/2 indices with the most negative g[i]
- Set s[i] = 0 for the rest

So s[i] = 1 for the n/2 indices with the smallest g[i], s[i] = 0 otherwise.

def linear_correlate(a, b):
    """Compute full linear correlation using FFT"""
    n = len(a)
    m = len(b)
    size = 2 * max(n, m)
    fa = np.fft.rfft(a, size)
    fb = np.fft.rfft(b, size)

    # The result is the circular correlation, which for our zero-padded case
    # gives the linear correlation in the right position
    return result[:max(n,m) + min(n,m) - 1]

import time

    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr)) * dx

def project_feasible(h, target_sum):

    diff = target_sum - np.sum(h)
    if abs(diff) < 1e-14:
        return h
    if diff > 0:
        idx = np.where(h < 1.0 - 1e-10)[0]
    else:
        idx = np.where(h > 1e-10)[0]
    if len(idx) == 0:
        return h
    h = h.copy()
    h[idx] += diff / len(idx)
    h = np.clip(h, 0.0, 1.0)
    residual = target_sum - np.sum(h)
    if abs(residual) > 1e-10:
        if residual > 0:
            idx2 = np.where(h < 1.0)[0]
        else:
            idx2 = np.where(h > 0.0)[0]
        if len(idx2) > 0:
            h[idx2] += residual / len(idx2)
            h = np.clip(h, 0.0, 1.0)
    return h

    n_corr = 2 * n - 1

            break
        no_improve = 0
        iter_count = 0

            iter_count += 1
            if no_improve > 3000:
                break
            
            corr = np.correlate(h, 1.0 - h, mode='full')
            cur_max = float(np.max(corr))
            c5_now = cur_max * dx
            if c5_now < best_c5 - 1e-14:
                best_c5 = c5_now
                best_h = h.copy()
                no_improve = 0
            else:
                no_improve += 1
            
            # Compute subgradient with temperature
            # Use top correlations weighted by exp(temp * (c - max))
            sorted_corr = np.sort(corr)[::-1]
            # How many to include? Those within temp/max of the top
            n_top = max(1, int(np.sum(corr >= cur_max - 1.0 / temp)))
            n_top = min(n_top, 20)  # cap at 20 for efficiency
            top_idx = np.argsort(corr)[-n_top:]
            w = np.exp(temp * (corr[top_idx] - cur_max))
            w = w / w.sum()

            for wi, si in zip(w, top_idx):
                k = int(si) - mid

                v2 = (idxs + k >= 0) & (idxs + k < n)

                if np.any(v2):
                    g[v2] -= wi * h[idxs[v2] + k]
            g *= dx
            
            # FW step: find s = argmin <g, s> over simplex {0<=s<=1, sum(s)=target}
            # Sort by g, take the target/2 smallest
            sorted_g = np.argsort(g)
            s = np.zeros(n)
            s[sorted_g[:int(target)]] = 1.0
            
            # Direction
            d = s - h
            if np.max(np.abs(d)) < 1e-12:
                break
            
            # Compute D_k = directional derivative of c_k in direction d
            # D_k = sum_i d[i]*(1-h[i+k]) - h[i]*d[i+k]
            # = corr(d, 1-h) - corr(h, d) for the appropriate lags
            D = np.correlate(d, 1.0 - h, mode='full') - np.correlate(h, d, mode='full')

            lo, hi_g = 0.0, 1.0

                f_mid = float(np.max(vals))

                f_prime = float(np.max(D[active]))
                if f_prime > 1e-13:
                    hi_g = mid_g
                else:
                    lo = mid_g
            
            gamma = 0.5 * (lo + hi_g)
            if gamma < 1e-10:
                break
            
            h = h + gamma * d
            h = project_feasible(h, target)
        
    return best_h, best_c5

c_k(h) = sum_i h[i] * (1 - h[i+k]) for valid i (this is the "c" without dx)

c_k(h + gamma*d) = sum_i (h[i] + gamma*d[i]) * (1 - h[i+k] - gamma*d[i+k])
= sum_i h[i]*(1-h[i+k]) + gamma * sum_i [d[i]*(1-h[i+k]) - h[i]*d[i+k]]
= c_k(h) + gamma * D_k

where D_k = sum_i d[i]*(1-h[i+k]) - h[i]*d[i+k]

Now, np.correlate(d, 1-h, mode='full')[m] = sum_i d[i] * (1-h[i + m - (n-1)])

So for lag k = m - (n-1):
np.correlate(d, 1-h, mode='full')[k + n - 1] = sum_i d[i] * (1-h[i+k])

Similarly:
np.correlate(h, d, mode='full')[k + n - 1] = sum_i h[i] * d[i+k]

So D_{k+n-1} = np.correlate(d, 1-h, mode='full')[k+n-1] - np.correlate(h, d, mode='full')[k+n-1]

And D = np.correlate(d, 1-h, mode='full') - np.correlate(h, d, mode='full')

This gives us D for all lags at once, computed in O(n²) (or O(n log n) with FFT).

def lse_objective(x, alpha, target, penalty):
    n = len(x)
    dx = 2.0 / n
    corr = np.correlate(x, 1.0 - x, mode='full')
    c_max = np.max(corr)
    shifted = np.clip(alpha * (corr - c_max), -500.0, 0.0)
    log_sum = np.log(np.sum(np.exp(shifted)))
    obj = (c_max + log_sum / alpha) * dx
    obj += penalty * (np.sum(x) - target) ** 2
    return obj

def lse_gradient(x, alpha, target, penalty):
    n = len(x)
    dx = 2.0 / n
    corr = np.correlate(x, 1.0 - x, mode='full')
    c_max = np.max(corr)
    shifted = np.clip(alpha * (corr - c_max), -500.0, 0.0)
    e = np.exp(shifted)
    total_e = np.sum(e)
    weights = e / total_e
    grad = np.zeros(n)
    mid = n - 1
    idxs = np.arange(n)
    active_mask = weights > 1e-12
    if np.any(active_mask):
        active_idx = np.where(active_mask)[0]
        for m in active_idx:
            k = int(m) - mid
            w = weights[int(m)]
            v1 = (idxs - k >= 0) & (idxs - k < n)
            v2 = (idxs + k >= 0) & (idxs + k < n)
            if np.any(v1):
                grad[v1] += w * (1.0 - x[idxs[v1] - k])
            if np.any(v2):
                grad[v2] -= w * x[idxs[v2] + k]
    grad *= dx
    grad += 2.0 * penalty * (np.sum(x) - target)
    return grad

def lbfgs_phase(h_start, n, target, alphas, maxiter, time_limit, penalty=100.0):
    start = time.time()
    h_cur = h_start.copy()
    best_h = h_cur.copy()
    best_c5 = compute_c5(h_cur)
    bounds = [(0.0, 1.0)] * n
    for alpha in alphas:
        if time.time() - start > time_limit:
            break
        for pen_mult in [1.0, 10.0, 100.0]:
            if time.time() - start > time_limit:
                break
            pen = penalty * pen_mult
            try:
                res = minimize(lse_objective, h_cur, args=(alpha, target, pen),
                              jac=lse_gradient, method='L-BFGS-B',
                              bounds=bounds,
                              options={'maxiter': maxiter, 'ftol': 1e-18, 'gtol': 1e-10})
                h_new = project_feasible(res.x, target)
                c5_new = compute_c5(h_new)
                if c5_new < best_c5:
                    best_c5 = c5_new
                    best_h = h_new.copy()
                h_cur = h_new
                if abs(np.sum(h_cur) - target) < 1e-8:
                    break
            except Exception:
                pass
    return best_h, best_c5

def interpolate_to(h_src, n_dst, target_dst):
    n_src = len(h_src)
    if n_src == n_dst:
        return project_feasible(h_src.copy(), target_dst)
    x_new = np.linspace(0.0, 1.0, n_dst)
    x_old = np.linspace(0.0, 1.0, n_src)
    h_out = np.interp(x_new, x_old, h_src)
    return project_feasible(h_out, target_dst)

    if sc < compute_c5(h_init):
        hcd, c5cd = pair_cd(hp, n, target, time_limit=min(30, time_limit * 0.4),
                            n_cand=25, max_sweeps=50000, n_shifts=1)
        if c5cd < sc:
            return hcd, c5cd
        return hp, sc
    return h_pert, compute_c5(h_pert)

def run(seed=42, budget_s=1300, **kwargs):
    start_time = time.time()
    h_init = np.array(initial_h_values, dtype=float)
    n = len(h_init)
    target = n / 2.0
    best_h = project_feasible(h_init, target)
    best_score = compute_c5(best_h)

    def tleft():
        return budget_s - 20.0 - (time.time() - start_time)

    # Phase 1: FW method - main new workhorse
    if tleft() > 120:
        hp, sc = fw_method(best_h, n, target, time_limit=min(100, tleft() * 0.35),
                           temps=[30, 100, 400, 1500])
        if sc < best_score:
            best_score = sc
            best_h = hp

    # Phase 2: Pair CD polishing
    if tleft() > 150:
        hcd, c5cd = pair_cd(best_h, n, target, time_limit=min(120, tleft() * 0.3),
                            n_cand=30, max_sweeps=200000, n_shifts=1)
        if c5cd < best_score:
            best_score = c5cd
            best_h = hcd

    # Phase 3: FW with higher temps (more exploration)
    if tleft() > 100:
        hp, sc = fw_method(best_h, n, target, time_limit=min(80, tleft() * 0.35),
                           temps=[500, 2000, 8000])
        if sc < best_score:
            best_score = sc
            best_h = hp

    # Phase 4: Pair CD multi-shift
    if tleft() > 120:
        hcd, c5cd = pair_cd(best_h, n, target, time_limit=min(100, tleft() * 0.3),
                            n_cand=40, max_sweeps=200000, n_shifts=3)
        if c5cd < best_score:
            best_score = c5cd
            best_h = hcd

    # Phase 5: L-BFGS with LSE
    if tleft() > 80:
        hp, sc = lbfgs_phase(best_h, n, target,
                            alphas=[500, 2000, 10000],
                            maxiter=300, time_limit=min(60, tleft() * 0.4),
                            penalty=200.0)
        if sc < best_score:
            best_score = sc
            best_h = hp

    # Phase 6: Perturbation + recovery
    if tleft() > 100:
        hp, sc = perturb_and_recover(best_h, n, target, time_limit=min(80, tleft() * 0.4),
                                     seed=seed + 1, scale=0.04)
        if sc < best_score:
            best_score = sc
            best_h = hp

    # Phase 7: FW again on best
    if tleft() > 80:
        hp, sc = fw_method(best_h, n, target, time_limit=min(60, tleft() * 0.4),
                           temps=[50, 200, 800])
        if sc < best_score:
            best_score = sc
            best_h = hp

    # Phase 8: Pair CD final polish
    if tleft() > 60:
        hcd, c5cd = pair_cd(best_h, n, target, time_limit=min(50, tleft() * 0.5),
                            n_cand=50, max_sweeps=200000, n_shifts=1)
        if c5cd < best_score:
            best_score = c5cd
            best_h = hcd

    # Phase 9: Try higher resolution
    if tleft() > 200:
        n_new = 800
        target_new = n_new / 2.0
        h_interp = interpolate_to(best_h, n_new, target_new)
        hp, sc = fw_method(h_interp, n_new, target_new,
                           time_limit=min(80, tleft() * 0.35),
                           temps=[30, 100, 400])
        if sc < best_score:
            best_score = sc
            best_h = hp
            n = n_new
            target = target_new
        if tleft() > 80:
            hcd, c5cd = pair_cd(best_h, n, target,
                                time_limit=min(60, tleft() * 0.4),
                                n_cand=30, max_sweeps=100000, n_shifts=1)
            if c5cd < best_score:
                best_score = c5cd
                best_h = hcd

    # Phase 10: Another perturbation with different seed
    if tleft() > 80:
        n_use = len(best_h)
        target_use = n_use / 2.0
        hp, sc = perturb_and_recover(best_h, n_use, target_use,
                                     time_limit=min(60, tleft() * 0.5),
                                     seed=seed + 42, scale=0.02)
        if sc < best_score:
            best_score = sc
            best_h = hp

    # Phase 11: L-BFGS very high alpha
    if tleft() > 60:
        n_use = len(best_h)
        target_use = n_use / 2.0
        hp, sc = lbfgs_phase(best_h, n_use, target_use,
                            alphas=[50000, 200000, 1000000],
                            maxiter=200, time_limit=min(50, tleft() * 0.5),
                            penalty=10000.0)
        if sc < best_score:
            best_score = sc
            best_h = hp

    # Phase 12: Final pair CD
    if tleft() > 30:
        n_use = len(best_h)
        target_use = n_use / 2.0
        hcd, c5cd = pair_cd(best_h, n_use, target_use,
                            time_limit=min(20, tleft() * 0.6),
                            n_cand=30, max_sweeps=50000, n_shifts=1)
        if c5cd < best_score:
            best_score = c5cd
            best_h = hcd

    # Final feasibility
    n_use = len(best_h)
    target_use = n_use / 2.0
    h_final = project_feasible(best_h, target_use)
    final_score = compute_c5(h_final)
    return h_final, final_score, n_use
