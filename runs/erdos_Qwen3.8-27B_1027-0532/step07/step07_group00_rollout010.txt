The key efficiency question: how do we compute the change in corr from a swap (i, j) where h[i]=1→0, h[j]=0→1?

For a swap, the change in corr[m] is:

For a single flip of h[idx] by delta (delta = +1 for 0→1, delta = -1 for 1→0):

The index m ranges from 0 to 2n-2.
Let shift = m - n + 1 (ranges from -(n-1) to n-1).

h[idx] appears in corr[m] in two ways:
1. As h[i] where i = idx: valid when 0 ≤ idx + shift < n, i.e., -idx ≤ shift < n-idx
   m range: n-1-idx ≤ m ≤ n-1+idx
   Contribution to delta_corr[m]: delta * (1 - h[idx + shift]) = delta * (1 - h[idx + m - n + 1])

2. As part of (1-h[j]) where j = idx, i.e., i + shift = idx → i = idx - shift:
   valid when 0 ≤ idx - shift < n, i.e., idx-n+1 < shift ≤ idx (actually idx-n < shift ≤ idx)

   Contribution to delta_corr[m]: h[i] * (-delta) where i = idx - shift = idx - (m-n+1) = idx + n - 1 - m
   So: -delta * h[idx + n - 1 - m]

So for a flip of h[idx] by delta:
