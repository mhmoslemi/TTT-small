For the proximal gradient method:
- Objective: F_alpha(h) = max(corr) + (1/alpha) log(sum(exp(alpha*(corr - max(corr)))))
- Gradient: weighted average of ∂corr[k]/∂h, weights = softmax(alpha*(corr - max(corr)))
- Step: h_new = project(h - lr * grad)
- Step size: I'll use a fixed step size that decreases over time

The key question is: what step size to use?

For the log-sum-exp with parameter alpha, the Lipschitz constant of the gradient is roughly alpha * (max eigenvalue of the Hessian of the correlation). The Hessian of corr[k] with respect to h is a sparse matrix (diagonal entries from the quadratic term). Its eigenvalues are bounded by 2 (since each h[i] appears in at most 2 terms of the quadratic part of corr[k]).

So the Lipschitz constant is roughly 2*alpha. A safe step size is lr = 1/(2*alpha).

But this is very conservative. In practice, we can use a much larger step size because the effective curvature is much smaller than the worst case.

1. Start with lr = initial_lr
2. Compute h_new = project(h - lr * grad)
3. If F_alpha(h_new) > F_alpha(h) - 0.5*lr*||grad||^2, halve lr and retry
4. Otherwise, accept the step

This is the standard Armijo condition.

        for t in [0.005, 0.01, 0.02, 0.05, 0.1, 0.2, 0.4, 0.8]:
            h_try = h - t * grad_unit
            h_try = project_feasible(h_try, target)
            corr_try = np.correlate(h_try, 1.0 - h_try, mode='full')
            obj_try = float(np.max(corr_try)) * dx
            if obj_try < best_obj - 1e-15:
                best_obj = obj_try
                best_t = t
        if best_t > 0:
            h = h - best_t * grad_unit
            h = project_feasible(h, target)
    return best_h, best_c5

def stochastic_search(h_init, n, target, time_limit, max_steps=30000):
    start = time.time()
    rng = np.random.RandomState(12345)
    h = h_init.copy().astype(float)
    best_h = h.copy()
    best_c5 = compute_c5(h)
    cur_c5 = best_c5
    no_improve = 0
    for step in range(max_steps):
        if time.time() - start > time_limit:
            break
        if no_improve > 3000:
            break
        scale = 0.03 * max(0.1, 1.0 - step / float(max_steps))
        n_pert = int(rng.choice([3, 5, 8, 15, 25]))
        n_pert = min(n_pert, n)
        idxs = rng.choice(n, size=n_pert, replace=False)
        h_try = h.copy()
        h_try[idxs] += rng.randn(n_pert) * scale
        h_try = project_feasible(h_try, target)
        sc = compute_c5(h_try)
        if sc < cur_c5 - 1e-15:
            h = h_try
            cur_c5 = sc
            no_improve = 0
            if sc < best_c5 - 1e-14:
                best_c5 = sc
                best_h = h.copy()
        else:
            no_improve += 1
            if no_improve > 200:
                h = best_h.copy()
                cur_c5 = best_c5
                no_improve = 0
    return best_h, best_c5

def run(seed=42, budget_s=1300, **kwargs):

    start_time = time.time()

    best_h = project_feasible(h_init, target0)
    best_score = compute_c5(best_h)

    def _tl():
        return budget_s - 30.0 - (time.time() - start_time)

    if _tl() > 60:
        h_pol = slsqp_optimize(best_h, n0, target0, [100, 500, 2000], 500, 1e-15)
