def minimax_ow(h_init, n, target, time_limit, eta=0.1):
    # h_init: initial point
    # n: number of points
    # target: sum constraint
    # time_limit: seconds
    # eta: learning rate for multiplicative weights
    
    start = time.time()
    dx = 2.0 / n
    n_corr = 2 * n - 1
    mid = n - 1
    
    h = h_init.copy().astype(float)
    best_h = h.copy()
    best_score = compute_c5(h)
    
    # Initialize p uniformly
    p = np.ones(n_corr) / n_corr
    
    # SMW step size
    smw = 1.0
    T = 0
    
    for iteration in range(100000):
        T += 1
        if time.time() - start > time_limit:
            break
        
        # Compute corr at current h
        corr = np.correlate(h, 1.0 - h, mode='full')
        c5_val = np.max(corr) * dx
        
        if c5_val < best_score - 1e-14:
            best_score = c5_val
            best_h = h.copy()
        
        # Compute expected gradient: grad of Σ_k p_k * f_k(h)
        grad = np.zeros(n)
        idxs = np.arange(n)
        for k_idx in range(n_corr):
            if p[k_idx] < 1e-12:
                continue
            k = k_idx - mid
            v1 = (idxs + k >= 0) & (idxs + k < n)
            v2 = (idxs - k >= 0) & (idxs - k < n)
            grad[v1] += p[k_idx] * (1.0 - h[idxs[v1] + k])
            grad[v2] -= p[k_idx] * h[idxs[v2] - k]
        
        # SMW step
        smw = np.sqrt(smw**2 + np.sum(grad**2))
        # Polyak-like step
        # We want to reduce max_k f_k(h), use expected gradient
        step = 1.0 / smw
        
        h_new = h - step * grad
        h_new = project_feasible(h_new, target)
        
        # Line search (backtracking)
        f_curr = np.max(corr)
        for ls in range(20):
            h_trial = h - (step / (2**ls)) * grad
            h_trial = project_feasible(h_trial, target)
            corr_trial = np.correlate(h_trial, 1.0 - h_trial, mode='full')
            if np.max(corr_trial) < f_curr * (1 - 0.1 * (step / (2**ls))):
                h = h_trial
                break
        else:
            h = h_new
        
        # Update p using multiplicative weights
        corr_new = np.correlate(h, 1.0 - h, mode='full')
        p = p * np.exp(eta * corr_new)
        p = p / np.sum(p)
    
    return best_h, best_score

            break

        h = np.clip(h, 0.0, 1.0)

If we change h[i] from 1 to 0:
- For term p=i: was h[i]*(1-h[i+k]) = 1*(1-h[i+k]), now 0. Change: -(1-h[i+k])
- For term p where p+k=i, i.e., p=i-k: was h[i-k]*(1-h[i]) = h[i-k]*0 = 0, now h[i-k]*1. Change: +h[i-k]

If we change h[j] from 0 to 1:
- For term p=j: was 0, now 1*(1-h[j+k]) = 1-h[j+k]. Change: +(1-h[j+k])
- For term p where p+k=j, i.e., p=j-k: was h[j-k]*(1-0) = h[j-k], now h[j-k]*0 = 0. Change: -h[j-k]

So total change in corr_k:
Δcorr_k = -(1-h[i+k]) + h[i-k] + (1-h[j+k]) - h[j-k]
         = h[j+k] - h[i+k] + h[i-k] - h[j-k]

(where we interpret h[x] = 0 if x is out of bounds)

This is O(1) per lag! So for a given (i,j) pair, we can compute the new max corr in O(n) by looking at the changes.

Actually, even better: we only need to check if the new max is lower than the current max. The new corr at lag k is:
new_corr_k = corr_k + Δcorr_k(i,j)

And the new max is max_k new_corr_k = max_k (corr_k + Δcorr_k(i,j)).

Since Δcorr_k(i,j) depends on i, j, and k in a structured way, we can precompute some of it.

For a fixed pair (i,j), Δcorr_k = h[j+k] - h[i+k] + h[i-k] - h[j-k] for all valid k.

This is essentially the difference of two "shifted" versions of h. We can compute this vector in O(n) for a given (i,j), and then the new max is just max(corr + Δcorr_vector).
