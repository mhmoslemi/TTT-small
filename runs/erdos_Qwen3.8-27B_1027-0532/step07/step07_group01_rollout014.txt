Wait, the p-norm approach: (∑ |c_k|^p)^(1/p). For p=2, this is the L2 norm of the correlation vector. For large p, it approaches the L∞ norm (max). The gradient of the p-norm is:
∂/∂h[p] of (∑ |c_k|^p)^(1/p) = (1/p) * (∑ |c_k|^p)^(1/p - 1) * ∑ p*|c_k|^(p-1)*sign(c_k)*∂c_k/∂h[p]

This is well-behaved and SLSQP can handle it. But the issue is that for large p, the function is nearly non-smooth and SLSQP might struggle.

The log-sum-exp approach is: (1/α) * log(∑ exp(α*c_k)). Its gradient is:
∂/∂h[p] = (1/α) * (∑ α*exp(α*c_k)*∂c_k/∂h[p]) / (∑ exp(α*c_k))
         = ∑ (exp(α*c_k) / ∑ exp(α*c_j)) * ∂c_k/∂h[p]
         = E_k[∂c_k/∂h[p]] where the "expectation" is with softmax weights.

This is a weighted average of the gradients, weighted by the softmax probabilities. It's always smooth and well-behaved.

I think the log-sum-exp is actually better for SLSQP because it's always C∞. The p-norm has issues at c_k = 0 for non-integer p.

Let me stick with log-sum-exp but use a better schedule.

Actually, let me reconsider. The p-norm with even integer p (like p=4, 8, 16, 32) is C∞ (since c_k can be negative, we need |c_k|^p which is smooth for even p). For even p, |c_k|^p = c_k^p, and the derivative is p*c_k^(p-1)*∂c_k/∂h[p], which is smooth.

So for even p, the p-norm is actually a good alternative to log-sum-exp. And it might be faster to compute (no exp, just power).

Let me use p = 4, 8, 16, 32, 64 for the SLSQP rounds.

import numpy as np
from scipy.optimize import minimize
import time

_g_n = 0
_g_target = 0.0

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr)) * dx

def project_feasible(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    n = len(h)
    for _ in range(100):
        diff = target_sum - np.sum(h)
        if abs(diff) < 1e-15:
            break
        if diff > 0:
            mask = h < 1.0 - 1e-16
        else:
            mask = h > 1e-16
        if not mask.any():
            step = diff / n
            h = np.clip(h + step, 0.0, 1.0)
            break
        h[mask] += diff / mask.sum()
        h = np.clip(h, 0.0, 1.0)
    return h

def _smooth_obj(x, alpha):
    corr = np.correlate(x, 1.0 - x, mode='full')
    c_max = float(np.max(corr))
    shifted = alpha * (corr - c_max)
    shifted = np.clip(shifted, -500.0, 0.0)
    return c_max + float(np.sum(np.exp(shifted))) / alpha

def _cons_fun(x):
    return np.sum(x) - _g_target

def _cons_jac(x):
    return np.ones(_g_n)

def slsqp_round(h_start, n, target, alphas, maxiter_per_alpha, ftol=1e-15):
    global _g_n, _g_target
    _g_n = n
    _g_target = target
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': _cons_fun, 'jac': _cons_jac}]
    h_cur = h_start.copy()
    cur_score = compute_c5(h_cur)
    for alpha in alphas:
        try:
            res = minimize(_smooth_obj, h_cur, args=(alpha,),
                           method='SLSQP', bounds=bounds, constraints=cons,
                           options={'maxiter': maxiter_per_alpha, 'ftol': ftol})
            h_new = project_feasible(res.x, target)
            sc = compute_c5(h_new)
            if sc < cur_score:
                cur_score = sc
                h_cur = h_new
        except Exception:
            pass
    return h_cur, cur_score

    return project_feasible(h_out, target_dst)
