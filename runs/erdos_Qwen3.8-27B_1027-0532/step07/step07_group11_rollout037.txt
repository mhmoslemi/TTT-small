Actually, one more important consideration: the `project_feasible` function. The previous implementation uses an iterative approach with up to 50 iterations. I should make sure this is efficient and correct.

The constraint is: 0 ≤ h[i] ≤ 1 for all i, and sum(h) = target.

The projection onto this set is:
1. Start with g (the point to project)
2. Find τ such that sum(clip(g - τ, 0, 1)) = target
3. Return clip(g - τ, 0, 1)

This can be done by:
- Sort g in decreasing order: g_(1) ≥ g_(2) ≥ ... ≥ g_(n)
- The optimal τ is such that:
  - For i where g_(i) - τ > 1: h_(i) = 1
  - For i where g_(i) - τ < 0: h_(i) = 0
  - For i where 0 ≤ g_(i) - τ ≤ 1: h_(i) = g_(i) - τ
  
- Let p = number of elements with g_(i) - τ > 1 (i.e., g_(i) > 1+τ)
- Let q = number of elements with g_(i) - τ < 0 (i.e., g_(i) < τ)
- The remaining n-p-q elements contribute (g_(i) - τ) each
- Total: p·1 + (n-p-q)·(g_(i) - τ) + q·0 = target
  Wait, this isn't quite right because the "middle" elements all have different g values.

The correct approach:
- p = number of elements set to 1
- m = number of elements in [0,1] (the "free" ones)
- q = number of elements set to 0
- p + m + q = n
- Sum = p + Σ_{free}(g_i - τ) = target
- So: p + (Σ_{free} g_i) - m·τ = target
- τ = (p + Σ_{free} g_i - target) / m

To find the correct p and m:
- Sort g in decreasing order
- For each possible p (number of 1s), the free elements are the next m = n - p - q elements
  Actually, this is the standard "water-filling" or "isotonic regression" approach.

A simpler approach (binary search on τ):
- If τ is very large: sum = 0 (all clipped to 0)
- If τ is very small: sum = n (all clipped to 1)
- Binary search for τ such that sum(clip(g-τ, 0, 1)) = target

This is O(n log n) per projection (binary search with O(n) evaluation).

Or even simpler: since we're projecting g - η·grad where grad is bounded, the values won't be too far from [0,1], so the iterative approach in the previous code should converge quickly.

import time

_g_n = 0
_g_target = 0.0

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr)) * dx

def project_feasible(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    n = len(h)
    for _ in range(100):
        diff = target_sum - np.sum(h)
        if abs(diff) < 1e-13:
            break
        if diff > 0:
            mask = h < 1.0 - 1e-15
        else:
            mask = h > 1e-14
        if not mask.any():
            h = np.clip(h + diff / n, 0.0, 1.0)
            break

        h = np.clip(h, 0.0, 1.0)

    corr = np.correlate(x, 1.0 - x, mode='full')
    c_max = np.max(corr)
    shifted = np.clip(alpha * (corr - c_max), -500.0, 0.0)
    return float(c_max + np.log(np.sum(np.exp(shifted))) / alpha)

    return np.sum(x) - _g_target

def _cons_jac(x):
    return np.ones(_g_n)

    global _g_n, _g_target
    _g_n = n
    _g_target = target
    bounds = [(0.0, 1.0)] * n

                         options={'maxiter': maxiter_per_alpha, 'ftol': 1e-14})
            h_new = project_feasible(res.x, target)
            sc = compute_c5(h_new)
            if sc < cur_score:

def momentum_subgrad(h_init, n, target, time_limit, n_steps=50000, 
                     K_shifts=3, step_scale=0.01, momentum=0.9):
    start = time.time()
    dx = 2.0 / n
    idxs = np.arange(n)
    mid = n - 1
    
    h = h_init.copy().astype(float)
    v = np.zeros(n)  # momentum
    best_h = h.copy()
    best_c5 = compute_c5(h)
    lr = step_scale
    
    for step in range(n_steps):
        if time.time() - start > time_limit:
            break
        
        corr = np.correlate(h, 1.0 - h, mode='full')
        c5_val = float(np.max(corr)) * dx
        if c5_val < best_c5 - 1e-14:
            best_c5 = c5_val
            best_h = h.copy()
        
        # Compute gradient using top K shifts
        top_k = np.argsort(corr)[-K_shifts:]
        weights = corr[top_k]
        w_sum = weights.sum()
        if w_sum < 1e-15:
            w_sum = 1.0
        weights /= w_sum

            # Adagrad-like step size

            v = 0.5 * v

Let me think about what alpha values to use. The log-sum-exp approximation:
f_α(x) = (1/α) ln(Σ e^{αx_i})

For this to be a good approximation of max(x_i), we need α to be large. But if α is too large, the function becomes very peaked and SLSQP might have convergence issues.

- For n=400: 799 shifts

- For α=1000: within 0.014 of max → probably 2-5 shifts active
- For α=10000: within 0.0014 of max → probably 1-2 shifts active
- For α=50000: within 0.0003 of max → probably 1 shift active (essentially the max)

So higher alpha is better for precision, but SLSQP might struggle with very peaked functions. Let me use a progression: start moderate, increase.

One issue: when α is very large, the function is essentially the max, which is not differentiable at points where two or more shifts achieve the max. import numpy as np
from scipy.optimize import minimize
import time

_g_n = 0
_g_target = 0.0


def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr)) * dx


def project_feasible(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    n = len(h)
    for _ in range(100):
        diff = target_sum - np.sum(h)
        if abs(diff) < 1e-13:
            break
        if diff > 0:
            mask = h < 1.0 - 1e-15
        else:
            mask = h > 1e-14
        if not mask.any():
            h = np.clip(h + diff / n, 0.0, 1.0)
            break
        h[mask] += diff / mask.sum()
        h = np.clip(h, 0.0, 1.0)
    return h


def smooth_obj(x, alpha):
    corr = np.correlate(x, 1.0 - x, mode='full')
    c_max = np.max(corr)
    shifted = np.clip(alpha * (corr - c_max), -500.0, 0.0)
    return float(c_max + np.log(np.sum(np.exp(shifted))) / alpha)


def _cons_fun(x):
    return np.sum(x) - _g_target


def _cons_jac(x):
    return np.ones(_g_n)


def slsqp_optimize(h_start, n, target, alphas, maxiter_per_alpha):
    global _g_n, _g_target
    _g_n = n
    _g_target = target
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': _cons_fun, 'jac': _cons_jac}]
    h_cur = h_start.copy()
    cur_score = compute_c5(h_cur)
    for alpha in alphas:
        try:
            res = minimize(smooth_obj, h_cur, args=(alpha,),
                           method='SLSQP', bounds=bounds,
                           constraints=cons,
                           options={'maxiter': maxiter_per_alpha, 'ftol': 1e-14})
            h_new = project_feasible(res.x, target)
            sc = compute_c5(h_new)
            if sc < cur_score:
                cur_score = sc
                h_cur = h_new
        except Exception:
            pass
    return h_cur, cur_score


def momentum_subgrad(h_init, n, target, time_limit, n_steps=50000,
                     K_shifts=3, step_scale=0.008, momentum_coeff=0.85):
    start = time.time()
    dx = 2.0 / n
    idxs = np.arange(n)
    mid = n - 1

    h = h_init.copy().astype(float)
    v = np.zeros(n)
    best_h = h.copy()
    best_c5 = compute_c5(h)
    lr = step_scale

    for step in range(n_steps):
        if time.time() - start > time_limit:
            break

        corr = np.correlate(h, 1.0 - h, mode='full')
        c5_val = float(np.max(corr)) * dx
        if c5_val < best_c5 - 1e-14:
            best_c5 = c5_val
            best_h = h.copy()

        top_k = np.argsort(corr)[-K_shifts:]
        weights = corr[top_k].astype(float)
        w_sum = weights.sum()
        if w_sum < 1e-15:
            w_sum = 1.0
        weights = weights / w_sum

        grad = np.zeros(n)
        for si in range(K_shifts):
            s_idx = int(top_k[si])
            k = s_idx - mid
            w = weights[si]
            v1 = (idxs - k >= 0) & (idxs - k < n)
            v2 = (idxs + k >= 0) & (idxs + k < n)
            grad[v1] += w * (1.0 - h[idxs[v1] - k])
            grad[v2] -= w * h[idxs[v2] + k]
        grad -= np.mean(grad)

        v = momentum_coeff * v - lr * grad
        h_new = project_feasible(h + v, target)
        sc = compute_c5(h_new)
        if sc < c5_val - 1e-15:
            h = h_new
            lr = max(step_scale * max(0.3, 1.0 - step / (n_steps * 1.5)), 1e-6)
        else:
            v = 0.5 * v
            lr *= 0.97

    return best_h, best_c5

            n_restarts=6,
            slsqp_alphas=[3000, 10000, 30000])
        if c5_r < best_score:
            best_score = c5_r
            best_h = h_r

    if tleft() > 40:
        h_final, sc = slsqp_optimize(best_h, cur_n, cur_target,
                                     [20000, 50000], 500)
        if sc < best_score:
            best_score = sc
            best_h = h_final

    final_h = project_feasible(best_h, len(best_h) / 2.0)
    final_score = compute_c5(final_h)

    return final_h, final_score, len(final_h)
