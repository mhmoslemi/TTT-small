    """Compute change in correlation vector when swapping h[i]:1->0, h[j]:0->1.
    Returns delta array of length 2n-1."""

    mid = n-1

        # Term from p=i: -(1-h[i+k]) if 0<=i+k<n

        if 0 <= i+k < n:

        # Term from p=i-k: +h[i-k] if 0<=i-k<n
        if 0 <= i-k < n:

        if 0 <= j+k < n:

        # Term from p=j-k: -h[j-k] if 0<=j-k<n
        if 0 <= j-k < n:

def compute_delta(h, i, j, n):
    """Vectorized delta computation."""
    k = np.arange(-(n-1), n)  # shape (2n-1,)
    delta = np.zeros(2*n-1)
    
    # Term 1: -(1-h[i+k]) where valid
    idx1 = i + k  # positions h[i+k]
    valid1 = (idx1 >= 0) & (idx1 < n)
    delta[valid1] -= (1.0 - h[idx1[valid1]])
    
    # Term 2: +h[i-k] where valid
    idx2 = i - k
    valid2 = (idx2 >= 0) & (idx2 < n)
    delta[valid2] += h[idx2[valid2]]
    
    # Term 3: +(1-h[j+k]) where valid
    idx3 = j + k
    valid3 = (idx3 >= 0) & (idx3 < n)
    delta[valid3] += (1.0 - h[idx3[valid3]])
    
    # Term 4: -h[j-k] where valid
    idx4 = j - k
    valid4 = (idx4 >= 0) & (idx4 < n)
    delta[valid4] -= h[idx4[valid4]]
    
    return delta

                   bounds=[(0,1)]*m,

                                 'jac': lambda f: np.ones(m)}],
                   options={'maxiter': 10000, 'ftol': 1e-15})

Actually, here's another idea: **alternating minimization over shifts**.

The objective is max_k corr[k]. This is a minimax problem. We can use the following approach:
- Maintain a distribution w over the shifts (initially uniform, or concentrated on the worst shift)
- At each iteration, solve: min_h sum_k w[k] * corr[k] subject to constraints
  This is a (weighted) linear program in h! Because corr[k] = sum_p h[p]*(1-h[p+k]) is bilinear...

Wait, it's still bilinear. Unless we fix one factor...

If we fix the "shifted" part: corr[k] = sum_p h[p] * (1-h[p+k]). If we treat (1-h[p+k]) as fixed coefficients (linearizing), then we have a linear objective in h. This gives a linear program!

**Alternating linearization (like ADMM or sinkhorn-like approach):**
1. Initialize w (weights over shifts)
2. Solve: min_h sum_k w[k] * corr[k] subject to 0≤h≤1, sum(h)=n/2
   This is: min_h sum_k w[k] * sum_p h[p]*(1-h[p+k])
   = min_h sum_p h[p] * sum_k w[k]*(1-h[p+k])
   = min_h sum_p h[p] * (1 - sum_k w[k]*h[p+k])
   
   Let c[p] = sum_k w[k]*h[p+k]. Then the objective is:
   min_h sum_p h[p] * (1 - c[p])
   
   This is a linear program in h! (c is fixed from the previous iteration)
   min sum_p (1-c[p]) * h[p] subject to 0≤h[p]≤1, sum h[p] = n/2
   
   The optimal solution: set h[p]=1 where (1-c[p]) is most negative (i.e., c[p] is largest), and h[p]=0 where (1-c[p]) is most positive. Set h[p] in [0,1] for the boundary.
   
   More precisely: the LP min sum d[p]*h[p] s.t. sum h[p]=S, 0≤h≤1 has the optimal solution:
   h[p] = 1 if d[p] < λ
   h[p] = 0 if d[p] > λ
   h[p] = fractional if d[p] = λ
   where λ is chosen so that sum h[p] = S.

3. Update w: w[k] proportional to exp(β * corr[k]) (or just put weight on the worst shifts)
4. Repeat

This is like a **multiplicative weights** or **fictitious play** approach! It alternates between:
- A "primal" step: optimize h given the current shift weights (solved exactly as LP)
- A "dual" step: update shift weights based on current correlations

This should converge to a local optimum of the minimax problem. And each step is O(n^2) (for computing c = W*h) and O(n log n) (for the LP solution via sorting).

Let me work out the details:

**Primal step**: Given w (vector of length 2n-1, non-negative, sum to 1):
- Compute c[p] = sum_k w[k] * h[p+k] (where h is indexed circularly or with zero-padding)
  Actually, we need to be careful about the correlation definition.
  
  corr[k] = sum_p h[p] * (1-h[p+k]) for valid p (0≤p<n, 0≤p+k<n)
  
  So the weighted objective is:
  sum_k w[k] * corr[k] = sum_k w[k] * sum_p h[p]*(1-h[p+k])

Or simply: w[k] = corr[k] / sum(corr) (proportional to the current correlations).
Or: w[k] = corr[k]^β / sum(corr^β) for some β > 1 to emphasize the worst.

This is essentially the **mirror descent / multiplicative weights algorithm for zero-sum games**! The "game" here is:
- Row player chooses h (continuous, from the polytope {0≤h≤1, sum=n/2})
- Column player chooses k (shift)
- Payoff is corr[k] (the row player wants to minimize, column player wants to maximize)

The multiplicative weights algorithm converges to the value of the game (which is the minimax value).

    dx = 2.0 / n
    n_corr = 2 * n - 1
    mid = n - 1
    h = h_init.copy()
    w = np.ones(n_corr) / n_corr  # uniform initial weights
    
    best_h = h.copy()
    best_c5 = compute_c5(h)
    
    for it in range(n_iters):
        # Compute current correlations
        corr = np.correlate(h, 1.0 - h, mode='full')
        c5_val = float(np.max(corr)) * dx
        if c5_val < best_c5:
            best_c5 = c5_val
            best_h = h.copy()
        
        # Dual step: update weights
        if beta > 0:
            w_shifted = np.exp(beta * corr / np.max(corr + 1e-15))
            w = w_shifted / np.sum(w_shifted)
        else:
            w = corr / np.sum(corr + 1e-15)
        
        # Primal step: solve LP min sum (1-c[p])*h[p] s.t. sum h = target, 0<=h<=1
        # c[p] = sum_k w[k]*h[p+k] for valid p+k
        c = np.zeros(n)
        for p in range(n):
            # sum over k such that 0 <= p+k < n
            # k ranges from -p to n-1-p
            # In correlation indexing: s = k + mid, so s ranges from mid-p to mid+n-1-p
            lo = max(0, mid - p)  # k >= -p means k+mid >= mid-p
            hi = min(n_corr-1, mid + n - 1 - p)  # k <= n-1-p means k+mid <= mid+n-1-p
            if lo <= hi:
                c[p] = np.sum(w[lo:hi+1] * h[p + np.arange(lo-mid, hi+1-mid)])
        
        # LP solution: min sum d[p]*h[p] where d[p] = 1-c[p]
        d = 1.0 - c
        # Sort by d, assign h=1 to smallest d, h=0 to largest d
        sorted_idx = np.argsort(d)
        h_new = np.zeros(n)
        h_new[sorted_idx[:int(target_sum)]] = 1.0
        # Handle fractional part
        rem = target_sum - int(target_sum)
        if rem > 1e-10:
            h_new[sorted_idx[int(target_sum)]] = rem
        
        h = h_new
    return best_h, best_c5
