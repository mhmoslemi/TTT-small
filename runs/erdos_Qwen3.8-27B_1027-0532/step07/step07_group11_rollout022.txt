import numpy as np
from scipy.optimize import minimize
import time

_g_n = 0
_g_target = 0.0

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr)) * dx

def project_feasible(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    n = len(h)
    for _ in range(100):
        diff = target_sum - np.sum(h)
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            mask = h < 1.0 - 1e-15
        else:
            mask = h > 1e-14
        if not mask.any():
            step = diff / n
            h = np.clip(h + step, 0.0, 1.0)
            break
        h[mask] += diff / mask.sum()
        h = np.clip(h, 0.0, 1.0)
    return h

def _smooth_obj_func(x, alpha):
    corr = np.correlate(x, 1.0 - x, mode='full')
    c_max = np.max(corr)
    shifted = np.clip(alpha * (corr - c_max), -500.0, 0.0)
    return float(c_max + np.log(np.sum(np.exp(shifted))) / alpha)

def _cons_fun(x):
    return np.sum(x) - _g_target

def _cons_jac(x):
    return np.ones(_g_n)

def slsqp_round(h_start, n, target, alphas, maxiter_per_alpha, ftol=1e-14):
    global _g_n, _g_target
    _g_n = n
    _g_target = target
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': _cons_fun, 'jac': _cons_jac}]
    h_cur = h_start.copy()
    cur_score = compute_c5(h_cur)
    for alpha in alphas:
        try:
            res = minimize(_smooth_obj_func, h_cur, args=(alpha,),
                           method='SLSQP', bounds=bounds, constraints=cons,
                           options={'maxiter': maxiter_per_alpha, 'ftol': ftol})
            h_new = project_feasible(res.x, target)
            sc = compute_c5(h_new)
            if sc < cur_score:
                cur_score = sc
                h_cur = h_new
        except Exception:
            pass
    return h_cur, cur_score

Now let me think about the CD more carefully. The key insight for a faster CD:

For a pair (i, j) with move delta (decrease h[i], increase h[j]):
- The new corr vector is: corr + delta * g, where g = change[j] - change[i]
- change[p, k] = ∂corr[k]/∂h[p] = (1-h[p-k]) if p-k in [0,n) else 0) - (h[p+k] if p+k in [0,n) else 0)

Wait, let me be more careful. The correlation is:
corr[k] = Σ_{x: x, x+k ∈ [0,n)} h[x] * (1-h[x+k])

(using the discrete version; the correlate function handles the indexing)

Actually, np.correlate(h, 1-h, mode='full') computes:
result[k] = Σ_i h[i] * (1-h)[i + k - (n-1)]

where k ranges from 0 to 2n-2.

So result[k] = Σ_i h[i] * (1-h[i - (k-(n-1))])

Let me define shift s = k - (n-1), so s ranges from -(n-1) to (n-1).
result[s + n - 1] = Σ_i h[i] * (1-h[i - s]) for valid i (where i-s is in [0,n-1])

= Σ_{i: 0 ≤ i < n, 0 ≤ i-s < n} h[i] * (1-h[i-s])

The derivative with respect to h[p]:
∂/∂h[p] = Σ_{s: valid} [contribution of h[p] to the sum]

For a given s, h[p] appears in the sum if p is in the valid range AND p-s is in the valid range.
- If p is the "h" term: p appears as h[p], and p-s must be valid → h[p] * (1-h[p-s])
- If p is the "(1-h)" term: p appears as (1-h[p]), meaning p-s is the "h" index → h[p+s] * (1-h[p])

So:
∂corr[s+n-1]/∂h[p] = (1-h[p-s]) [if 0≤p-s<n] - h[p+s] [if 0≤p+s<n]

This is the "change" vector for position p.

Now, for the CD, when we do h[i] -= d, h[j] += d:
New corr[s+n-1] = corr[s+n-1] - d * change[i, s] + d * change[j, s]
= corr[s+n-1] + d * (change[j, s] - change[i, s])

So the change vector for the pair is g[s] = change[j, s] - change[i, s] for all s.

To find the optimal d, we minimize: max_s (corr[s+n-1] + d * g[s]) subject to d ∈ [0, d_max].

This is a 1D convex piecewise linear minimization. The minimum is at the point where the slope changes from negative to positive.

The slope at d is: max over s of g[s] where corr[s+n-1] + d*g[s] is "active" (i.e., achieves the max).

At d=0, the active set is {s: corr[s+n-1] = max(corr)}. The slope is max{g[s] : s active}.

If this slope is < 0, we can increase d. The optimal d is where the slope becomes ≥ 0.

To find this efficiently, we can:
1. Sort the "breakpoints" where the active set changes
2. The breakpoints are at d = (corr[s2] - corr[s1]) / (g[s1] - g[s2]) for pairs (s1, s2) where g[s1] ≠ g[s2]

But computing all breakpoints is O(n²) which is too slow.

A simpler approach: since f(d) is convex piecewise linear, we can use ternary search or binary search on the slope. Binary search on d with slope evaluation at each step takes O(log(d_max/eps) * n) time.

With n=400 and 10 iterations of binary search, that's 4000 operations per pair. With 10000 pairs, that's 40 million per sweep. With 20000 sweeps, that's 800 billion. Still too slow.

We need to reduce the number of pairs or the cost per pair.

**Key optimization**: Instead of evaluating all pairs, use a "reduced candidate set" based on a fast scoring.

Score for decreasing h[i]: benefit_i = -Σ_{s active} change[i, s] (how much h[i] contributes to the active shifts)
Score for increasing h[j]: benefit_j = -Σ_{s active} change[j, s] (how much increasing h[j] helps)

Wait, that's not quite right. The benefit of the pair (i,j) is:
min_d max_s (corr[s] - d*change[i,s] + d*change[j,s])

A good upper bound on the benefit is:
reduce in the max shift: d * (change[i, s_max] - change[j, s_max]) where s_max is the argmax shift

So we can precompute for each position p:
- decrease_score[p] = change[p, s_max] (how much the max shift decreases when h[p] decreases)
- increase_score[p] = -change[p, s_max] (how much the max shift increases when h[p] increases... wait, we want to decrease the max)

Actually: if we decrease h[i] by d, the max shift changes by -d * change[i, s_max].
If we increase h[j] by d, the max shift changes by d * change[j, s_max].
Total change in max shift: d * (change[j, s_max] - change[i, s_max]).

We want this to be negative (reducing the max). So we want change[i, s_max] > change[j, s_max].

For s_max (the argmax shift), change[p, s_max] = (1-h[p-s_max]) - h[p+s_max] (with bounds).

So:
- We want to decrease h[i] where change[i, s_max] is large positive (i.e., h[i-s_max] is small and h[i+s_max] is large)
- We want to increase h[j] where change[j, s_max] is small (i.e., h[j-s_max] is large and h[j+s_max] is small)

This gives us a fast scoring that only looks at one shift. For a better score, we can use the top m shifts weighted by their excess over the max.

    start = time.time()
    dx = 2.0 / n
    mid = n - 1
    idxs = np.arange(n)
    
    h = h_init.copy().astype(float)
    best_c5 = compute_c5(h)
    best_h = h.copy()
    no_improve = 0
    
    for sweep in range(max_sweeps):
        if time.time() - start > time_limit:
            break
        if no_improve > 200:
            break
        
        corr = np.correlate(h, 1.0 - h, mode='full')
        c5_val = float(np.max(corr)) * dx

            best_c5 = c5_val
            best_h = h.copy()
            no_improve = 0
        else:
            no_improve += 1
        
        # Get top shifts
        top_k = np.argsort(corr)[-n_top_shifts:]

        grad = np.zeros(n)
        for s_idx in top_k:

            v1 = (idxs - k >= 0) & (idxs - k < n)
            v2 = (idxs + k >= 0) & (idxs + k < n)
            grad[v1] += (1.0 - h[idxs[v1] - k])
            grad[v2] -= h[idxs[v2] + k]
        grad -= np.mean(grad)
        
        # Select candidates based on gradient
        sorted_idx = np.argsort(grad)
        low_set = sorted_idx[:n_cand_low]
        high_set = sorted_idx[-n_cand_high:]
        
        # Try pairs
        best_trial = c5_val
        best_move = None
        
        for i in high_set:
            i = int(i)
            for j in low_set:
                j = int(j)
                if i == j:
                    continue
                d_max = min(h[i], 1.0 - h[j])
                if d_max < 1e-12:
                    continue
                
                # Compute g = change[j] - change[i] for top shifts only
                # g[s] = change[j, s] - change[i, s]
                # For efficiency, only compute for top shifts
                g_top = np.zeros(len(top_k))
                for si, s_idx in enumerate(top_k):
                    k = int(s_idx) - mid
                    # change[i, s] = (1-h[i-k]) - h[i+k] (with bounds)
                    ci = 0.0
                    if 0 <= i - k and i - k < n:
                        ci += (1.0 - h[i - k])
                    if 0 <= i + k and i + k < n:
                        ci -= h[i + k]
                    cj = 0.0
                    if 0 <= j - k and j - k < n:
                        cj += (1.0 - h[j - k])
                    if 0 <= j + k and j + k < n:
                        cj -= h[j + k]
                    g_top[si] = cj - ci
                
                corr_top = corr[top_k]
                
                # Binary search for optimal d
                # f(d) = max(corr_top + d * g_top)
                # slope at d: max of g_top[s] where corr_top[s] + d*g_top[s] = f(d)
                
                # Check slope at d=0
                f0 = np.max(corr_top)
                active0 = corr_top >= f0 - 1e-12
                slope0 = np.max(g_top[active0])
                if slope0 >= -1e-14:
                    continue  # Can't improve by increasing d
                
                # Binary search
                a, b = 0.0, d_max
                for _ in range(8):
                    mid_d = 0.5 * (a + b)
                    vals = corr_top + mid_d * g_top
                    f_mid = np.max(vals)
                    active_mid = vals >= f_mid - 1e-12
                    slope = np.max(g_top[active_mid])
                    if slope > 1e-14:
                        b = mid_d
                    else:
                        a = mid_d
                
                d_star = 0.5 * (a + b)
                if d_star < 1e-12:

                # Evaluate new max (only on top shifts as approximation)
                new_max_top = np.max(corr_top + d_star * g_top) * dx

                    best_trial = new_max_top
                    best_move = (i, j, d_star)
        
        if best_move is not None:
            i, j, d = best_move
            h[i] -= d
            h[j] += d
            h = np.clip(h, 0.0, 1.0)
            h = project_feasible(h, target)
    
    return best_h, best_c5

def vectorized_cd(h_init, n, target, time_limit, n_top=10, n_cand=30, max_sweeps=100000):
    start = time.time()
    dx = 2.0 / n
    mid = n - 1
    idxs = np.arange(n)
    
    h = h_init.copy().astype(float)
    best_c5 = compute_c5(h)
    best_h = h.copy()
    no_improve = 0
    
    for sweep in range(max_sweeps):
        if time.time() - start > time_limit:
            break
        if no_improve > 100:
            break
        
        corr = np.correlate(h, 1.0 - h, mode='full')
        c5_val = float(np.max(corr)) * dx
        
        if c5_val < best_c5 - 1e-14:
            best_c5 = c5_val
            best_h = h.copy()
            no_improve = 0
        else:
            no_improve += 1
        
        # Top shifts
        top_k = np.argsort(corr)[-n_top:]
        corr_top = corr[top_k]
        
        # Compute change matrix for top shifts: shape (n, n_top)
        change = np.zeros((n, n_top))
        for si, s_idx in enumerate(top_k):
            k = int(s_idx) - mid
            # change[p, si] = (1-h[p-k]) - h[p+k] (with bounds)
            # Vectorize:
            pk = idxs - k  # p - k for all p
            pk2 = idxs + k  # p + k for all p
            mask1 = (pk >= 0) & (pk < n)
            mask2 = (pk2 >= 0) & (pk2 < n)
            change[mask1, si] += (1.0 - h[pk[mask1]])
            change[mask2, si] -= h[pk2[mask2]]
        
        # Score: gradient from weighted top shifts
        # weight by excess over min of top
        weights = corr_top / np.sum(corr_top)
        grad = change @ weights  # (n,)
        grad -= np.mean(grad)
        
        sorted_idx = np.argsort(grad)
        low_set = sorted_idx[:n_cand]
        high_set = sorted_idx[-n_cand:]
        
        # Vectorized pair evaluation
        n_h = len(high_set)
        n_l = len(low_set)
        
        # change for high and low sets: shape (n_h, n_top) and (n_l, n_top)
        ch_high = change[high_set, :]  # (n_h, n_top)
        ch_low = change[low_set, :]  # (n_l, n_top)
        
        # g[i,j,s] = ch_low[j,s] - ch_high[i,s]
        # Shape: (n_h, n_l, n_top)
        g = ch_low[None, :, :] - ch_high[:, None, :]  # (n_h, n_l, n_top)
        
        # d_max[i,j] = min(h[high[i]], 1-h[low[j]])
        h_high = h[high_set]  # (n_h,)
        h_low = h[low_set]  # (n_l,)
        d_max = np.minimum(h_high[:, None], 1.0 - h_low[None, :])  # (n_h, n_l)
        
        # Binary search for optimal d: (n_h, n_l) values
        d_lo = np.zeros((n_h, n_l))
        d_hi = d_max.copy()
        
        for _ in range(8):
            d_mid = 0.5 * (d_lo + d_hi)  # (n_h, n_l)
            # vals[i,j,s] = corr_top[s] + d_mid[i,j] * g[i,j,s]
            vals = corr_top[None, None, :] + d_mid[:, :, None] * g  # (n_h, n_l, n_top)
            f_mid = np.max(vals, axis=2)  # (n_h, n_l)
            # Active mask: (n_h, n_l, n_top)
            active = (vals >= f_mid[:, :, None] - 1e-12)
            # Slope: max of g where active
            # Where active is False, set g to -inf
            g_masked = np.where(active, g, -np.inf)
            slope = np.max(g_masked, axis=2)  # (n_h, n_l)
            
            # Where slope > 0, the optimal d is less than d_mid
            d_hi = np.where(slope > 1e-14, d_mid, d_hi)
            d_lo = np.where(slope > 1e-14, d_lo, d_mid)
        
        d_star = 0.5 * (d_lo + d_hi)  # (n_h, n_l)
        
        # Evaluate: new_max[i,j] = max_s(corr_top[s] + d_star[i,j] * g[i,j,s])
        vals_star = corr_top[None, None, :] + d_star[:, :, None] * g
        new_max = np.max(vals_star, axis=2) * dx  # (n_h, n_l)
        
        # Find best pair
        new_max = np.where(d_max > 1e-12, new_max, np.inf)
        best_val = np.min(new_max)
        
        if best_val < c5_val - 1e-14:
            flat_idx = np.argmin(new_max)
            i_idx = flat_idx // n_l
            j_idx = flat_idx % n_l
            i = int(high_set[i_idx])
            j = int(low_set[j_idx])
            d = float(d_star[i_idx, j_idx])
            
            h[i] -= d
            h[j] += d
            h = np.clip(h, 0.0, 1.0)
            h = project_feasible(h, target)
    
    return best_h, best_c5

Now, let me also think about a completely different approach: **alternating between shift optimization and h optimization**.

The problem is:
min_h max_k f_k(h) where f_k(h) = Σ_i h[i]·(1-h[i-k])·dx

This is a min-max problem. We can use the von Neumann minimax theorem in a relaxed sense:
min_h max_k f_k(h) = min_h max_{p∈Δ} Σ_k p_k f_k(h) = min_{p∈Δ} max_h Σ_k p_k f_k(h)

where Δ is the simplex. This doesn't exactly apply (the feasible set for h is not symmetric), but we can use it as motivation for an alternating algorithm:
1. Given p (distribution over shifts), minimize Σ_k p_k f_k(h) over h
2. Given h, find the worst shift k* = argmax_k f_k(h) and update p toward k*

Step 1 is: minimize Σ_k p_k Σ_i h[i](1-h[i-k])·dx over h
= minimize Σ_i h[i] · (1 - Σ_k p_k h[i-k]) · dx

This is still non-convex (bilinear in h). But we can linearize:
Let g[i] = 1 - Σ_k p_k h[i-k]

    dx = 2.0 / n
    mid = n - 1
    idxs = np.arange(n)
    n_corr = 2 * n - 1
    
    h = h_init.copy().astype(float)
    best_h = h.copy()
    best_c5 = compute_c5(h)
    
    for it in range(max_iters):
        if time.time() - start > time_limit:
            break
        
        # Compute all f_k(h)
        corr = np.correlate(h, 1.0 - h, mode='full')
        c5_val = float(np.max(corr)) * dx
        
        if c5_val < best_c5 - 1e-14:
            best_c5 = c5_val
            best_h = h.copy()
            
        # Compute p = softmax(eta * corr)
        corr_clipped = np.clip(eta * corr - np.max(eta * corr), -500, 0)
        exp_vals = np.exp(corr_clipped)
        p = exp_vals / exp_vals.sum()
        
        # Compute g[i] = 1 - sum_k p[k] h[i-k] (with bounds)
        g = np.ones(n)
        for s_idx in range(n_corr):
            if p[s_idx] < 1e-10:
                continue
            k = s_idx - mid
            # h[i-k] for valid i
            if k >= 0:
                # i-k >= 0 means i >= k
                g[k:] -= p[s_idx] * h[:n-k]
            else:
                # i-k < n means i < n+k
                g[:n+k] -= p[s_idx] * h[-k:]
        
        # Solve LP: min sum h[i]*g[i] s.t. 0<=h<=1, sum(h)*dx=1
        # Optimal: h[i]=1 where g[i] is smallest, h[i]=0 where largest
        # Need sum(h) = target = n/2
        sorted_g = np.sort(g)
        # The threshold is sorted_g[n//2] (approximately)
        threshold = sorted_g[int(target)]
        h_new = np.where(g < threshold, 1.0, 0.0)
        # Adjust to get exact sum
        diff = target - np.sum(h_new)
        if abs(diff) > 1e-10:
            # Set fractional values at the boundary
            boundary = np.abs(g - threshold) < 1e-10
            n_boundary = np.sum(boundary)
            if n_boundary > 0:
                frac = diff / n_boundary  # This might not be in [0,1]
                frac = np.clip(frac, 0.0, 1.0)
                h_new[boundary] = frac
            else:
                h_new = project_feasible(h_new, target)
        
        # Blend
        h = (1 - alpha) * h + alpha * h_new
        h = project_feasible(h, target)
    
    return best_h, best_c5

import numpy as np
from scipy.optimize import minimize
import time

_g_n = 0
_g_target = 0.0


def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr)) * dx


def project_feasible(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    n = len(h)
    for _ in range(100):
        diff = target_sum - np.sum(h)
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            mask = h < 1.0 - 1e-15
        else:
            mask = h > 1e-14
        if not mask.any():
            h = np.clip(h + diff / n, 0.0, 1.0)
            break
        h[mask] += diff / mask.sum()
        h = np.clip(h, 0.0, 1.0)
    return h


def _smooth_obj(x, alpha):
    corr = np.correlate(x, 1.0 - x, mode='full')
    c_max = np.max(corr)
    shifted = np.clip(alpha * (corr - c_max), -500.0, 0.0)
    return float(c_max + np.log(np.sum(np.exp(shifted))) / alpha)


def _cons_fun(x):
    return np.sum(x) - _g_target


def _cons_jac(x):
    return np.ones(_g_n)


def slsqp_round(h_start, n, target, alphas, maxiter_per_alpha, ftol=1e-14):
    global _g_n, _g_target
    _g_n = n
    _g_target = target
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': _cons_fun, 'jac': _cons_jac}]
    h_cur = h_start.copy()
    cur_score = compute_c5(h_cur)
    for alpha in alphas:
        try:
            res = minimize(_smooth_obj, h_cur, args=(alpha,),
                           method='SLSQP', bounds=bounds, constraints=cons,
                           options={'maxiter': maxiter_per_alpha, 'ftol': ftol})
            h_new = project_feasible(res.x, target)
            sc = compute_c5(h_new)
            if sc < cur_score:
                cur_score = sc
                h_cur = h_new
        except Exception:
            pass
    return h_cur, cur_score


def vectorized_cd(h_init, n, target, time_limit, n_top=12, n_cand=35, max_sweeps=200000):
    start = time.time()
    dx = 2.0 / n
    mid = n - 1
    idxs = np.arange(n)

    h = h_init.copy().astype(float)
    best_c5 = compute_c5(h)
    best_h = h.copy()
    no_improve = 0

    for sweep in range(max_sweeps):
        if time.time() - start > time_limit:
            break
        if no_improve > 80:
            break

        corr = np.correlate(h, 1.0 - h, mode='full')
        c5_val = float(np.max(corr)) * dx

        if c5_val < best_c5 - 1e-14:
            best_c5 = c5_val
            best_h = h.copy()
            no_improve = 0
        else:
            no_improve += 1

        top_k = np.argsort(corr)[-n_top:]
        corr_top = corr[top_k]

        change = np.zeros((n, n_top))
        for si, s_idx in enumerate(top_k):
            k = int(s_idx) - mid
            pk = idxs - k
            pk2 = idxs + k
            m1 = (pk >= 0) & (pk < n)
            m2 = (pk2 >= 0) & (pk2 < n)
            change[m1, si] += (1.0 - h[pk[m1]])
            change[m2, si] -= h[pk2[m2]]

        weights = corr_top / (np.sum(corr_top) + 1e-30)
        grad = change @ weights
        grad -= np.mean(grad)

        sorted_idx = np.argsort(grad)
        low_set = sorted_idx[:n_cand]
        high_set = sorted_idx[-n_cand:]

        ch_high = change[high_set, :]
        ch_low = change[low_set, :]
        g = ch_low[None, :, :] - ch_high[:, None, :]

        h_high = h[high_set]
        h_low = h[low_set]
        d_max = np.minimum(h_high[:, None], 1.0 - h_low[None, :])

        d_lo = np.zeros((len(high_set), len(low_set)))
        d_hi = d_max.copy()

        for _ in range(8):
            d_mid = 0.5 * (d_lo + d_hi)
            vals = corr_top[None, None, :] + d_mid[:, :, None] * g
            f_mid = np.max(vals, axis=2)
            active = (vals >= f_mid[:, :, None] - 1e-12)
            g_masked = np.where(active, g, -np.inf)
            slope = np.max(g_masked, axis=2)
            d_hi = np.where(slope > 1e-14, d_mid, d_hi)
            d_lo = np.where(slope > 1e-14, d_lo, d_mid)

        d_star = 0.5 * (d_lo + d_hi)
        vals_star = corr_top[None, None, :] + d_star[:, :, None] * g
        new_max = np.max(vals_star, axis=2) * dx
        new_max = np.where(d_max > 1e-12, new_max, np.inf)

        best_val = np.min(new_max)
        if best_val < c5_val - 1e-13:
            flat_idx = int(np.argmin(new_max))
            ni = flat_idx // len(low_set)
            nj = flat_idx % len(low_set)
            i = int(high_set[ni])
            j = int(low_set[nj])
            d = float(d_star[ni, nj])
            if d > 1e-12:
                h[i] -= d
                h[j] += d
                h = np.clip(h, 0.0, 1.0)
                h = project_feasible(h, target)
        else:
            if no_improve % 30 == 0 and no_improve > 30:
                rng = np.random.RandomState(sweep + 42)
                i1, i2 = rng.choice(n, 2, replace=False)
                dd = 0.02 * min(h[i1], 1.0 - h[i2])
                if dd > 1e-10:
                    h[i1] -= dd
                    h[i2] += dd
                    h = project_feasible(h, target)

    return best_h, best_c5


def self_consistent(h_init, n, target, time_limit, eta=30.0, alpha=0.7, max_iters=20000, n_effective=25):
    start = time.time()
    dx = 2.0 / n
    mid = n - 1
    idxs = np.arange(n)
    n_corr = 2 * n - 1

    h = h_init.copy().astype(float)
    best_h = h.copy()
    best_c5 = compute_c5(h)
    no_improve = 0

    for it in range(max_iters):
        if time.time() - start > time_limit:
            break
        if no_improve > 200:
            break

        corr = np.correlate(h, 1.0 - h, mode='full')
        c5_val = float(np.max(corr)) * dx
        if c5_val < best_c5 - 1e-14:
            best_c5 = c5_val
            best_h = h.copy()
            no_improve = 0
        else:
            no_improve += 1

        top_shifts = np.argsort(corr)[-n_effective:]
        top_corr = corr[top_shifts]
        top_corr_clipped = np.clip(eta * top_corr - np.max(eta * top_corr), -500, 0)
        exp_vals = np.exp(top_corr_clipped)
        p = exp_vals / (exp_vals.sum() + 1e-30)

        g = np.ones(n)
        for si, s_idx in enumerate(top_shifts):
            if p[si] < 1e-8:
                continue
            k = int(s_idx) - mid
            if k >= 0:
                g[k:] -= p[si] * h[:n - k]
            else:
                g[:n + k] -= p[si] * h[-k:]

        sorted_g = np.sort(g)
        threshold = sorted_g[int(target) - 1] + 1e-15
        h_new = np.where(g <= threshold, 1.0, 0.0)
        diff = target - np.sum(h_new)
        if diff > 1e-10:
            boundary = np.where((g > threshold - 1e-10) & (g < threshold + 1e-10))[0]
            if len(boundary) > 0:
                h_new[boundary[:int(diff) + 1]] = 1.0
            h_new = project_feasible(h_new, target)
        elif diff < -1e-10:
            h_new = project_feasible(h_new, target)

        h = (1.0 - alpha) * h + alpha * h_new
        h = project_feasible(h, target)

    return best_h, best_c5


def momentum_subgrad(h_init, n, target, time_limit, n_steps=50000, step_scale=0.01, mu=0.9, n_top=5):
    start = time.time()
    dx = 2.0 / n
    mid = n - 1
    idxs = np.arange(n)

    h = h_init.copy().astype(float)
    best_h = h.copy()
    best_c5 = compute_c5(h)
    v = np.zeros(n)
    eta = step_scale

    for step in range(n_steps):
        if time.time() - start > time_limit:
            break

        corr = np.correlate(h, 1.0 - h, mode='full')
        c5_val = float(np.max(corr)) * dx
        if c5_val < best_c5 - 1e-14:
            best_c5 = c5_val
            best_h = h.copy()

        top_k = np.argsort(corr)[-n_top:]
        grad = np.zeros(n)
        for s_idx in top_k:
            k = int(s_idx) - mid
            v1 = (idxs - k >= 0) & (idxs - k < n)
            v2 = (idxs + k >= 0) & (idxs + k < n)
            grad[v1] += (1.0 - h[idxs[v1] - k])
            grad[v2] -= h[idxs[v2] + k]
        grad /= n_top
        grad -= np.mean(grad)

        v = mu * v - eta * grad
        h_try = project_feasible(h + v, target)
        sc = compute_c5(h_try)
        if sc < c5_val:
            h = h_try
            eta = min(eta * 1.02, 0.05)
        else:
            v *= 0.5
            eta *= 0.9

    return best_h, best_c5


def interpolate_to(h_src, n_dst, target_dst):
    n_src = len(h_src)
    if n_src == n_dst:
        return project_feasible(h_src.copy(), target_dst)
    x_new = np.linspace(0.0, 1.0, n_dst)
    x_old = np.linspace(0.0, 1.0, n_src)
    h_out = np.interp(x_new, x_old, h_src)
    return project_feasible(h_out, target_dst)

        h_sc2, c5_sc2 = self_consistent(best_h, cur_n, cur_target,
                                        time_limit=min(40, tleft() * 0.3),
                                        eta=50.0, alpha=0.5, max_iters=15000)
        if c5_sc2 < best_score:
            best_score = c5_sc2
            best_h = h_sc2
        elif tleft() > 60:
            h_cd3, c5_cd3 = vectorized_cd(h_sc2, cur_n, cur_target,
                                          time_limit=min(40, tleft() * 0.5),
                                          n_top=12, n_cand=35, max_sweeps=100000)
            if c5_cd3 < best_score:
                best_score = c5_cd3
                best_h = h_cd3

    if tleft() > 150:
        n2 = 1600
        target2 = n2 / 2.0
        h2 = interpolate_to(best_h, n2, target2)
        sc2 = compute_c5(h2)
        if sc2 < best_score:
            best_score = sc2
            best_h = h2
            cur_n = n2
            cur_target = target2
        if tleft() > 100:
            h_cd2, c5_cd2 = vectorized_cd(best_h, cur_n, cur_target,
                                          time_limit=min(80, tleft() * 0.5),
                                          n_top=12, n_cand=25, max_sweeps=100000)
            if c5_cd2 < best_score:
                best_score = c5_cd2
                best_h = h_cd2

    if tleft() > 80:
        rng = np.random.RandomState(seed)
        for noise in [0.03, 0.06, 0.1]:
            if tleft() < 50:
                break
            h_pert = best_h + rng.randn(cur_n) * noise
            h_pert = project_feasible(h_pert, cur_target)
            h_ref, sc = slsqp_round(h_pert, cur_n, cur_target,
                                    [100, 500, 2000], 400, 1e-14)
            if sc < best_score:
                best_score = sc
                best_h = h_ref

    if tleft() > 60:
        h_cd_f, c5_cf = vectorized_cd(best_h, cur_n, cur_target,
                                      time_limit=min(40, tleft() * 0.6),
                                      n_top=15, n_cand=50, max_sweeps=150000)
        if c5_cf < best_score:
            best_score = c5_cf
            best_h = h_cd_f

    if tleft() > 40:
        h_final, sc_final = slsqp_round(best_h, cur_n, cur_target,
                                        [5000, 15000], 600, 1e-14)
        if sc_final < best_score:
            best_score = sc_final
            best_h = h_final

    final_h = project_feasible(best_h, len(best_h) / 2.0)
    final_score = compute_c5(final_h)
    return final_h, final_score, len(final_h)
