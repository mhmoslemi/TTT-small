   where g = gradient of corr_{k*} at current h, and f = corr_{k*}(h).
   
   The idea is: at the current point, corr_{k*}(h) = f. The linear approximation is:
   corr_{k*}(h') ≈ f + g · (h' - h) = f + g·h' - g·h
   
   We want corr_{k*}(h') ≤ t, so:
   f + g·h' - g·h ≤ t
   g·h' ≤ t - f + g·h
   
   In the previous code, the cut is:
   A_ub[i, :n] = cuts_g[i]  (which is g)
   A_ub[i, n] = -1.0  (coefficient of t)
   b_ub[i] = cuts_g[i] @ cuts_h[i] - cuts_f[i]  (which is g·h - f)
   
   So the constraint is: g·h' - t ≤ g·h - f, i.e., g·h' ≤ t + g·h - f.
   
   This matches! Good.

When we move delta from i to j:

- h[j] becomes h[j] + delta

The correlation at lag k changes by:

For h[i] → h[i] - delta:
- corr[k] = ∑ h[a](1-h[a+k])
- The terms involving h[i] are: h[i](1-h[i+k]) and h[i-k](1-h[i])
- After change: (h[i]-delta)(1-h[i+k]) and h[i-k](1-(h[i]-delta))
- Change: -delta*(1-h[i+k]) + delta*h[i-k] (if indices valid)

For h[j] → h[j] + delta:
- Change: +delta*(1-h[j+k]) - delta*h[j-k] (if indices valid)

So: Δcorr[k] = -delta*(1-h[i+k]) + delta*h[i-k] + delta*(1-h[j+k]) - delta*h[j-k]

This is O(1) per lag k! So computing Δcorr for all lags is O(n), and finding the max is O(n).

def precompute_gradients(h):
    n = len(h)
    mid = n - 1
    n_corr = 2*n - 1
    g = np.zeros((n, n_corr))
    shifts = np.arange(-mid, n)  # lags from -(n-1) to n-1

        pos = (i + shifts >= 0) & (i + shifts < n)
        neg = (i - shifts >= 0) & (i - shifts < n)
        g[i, pos] += (1.0 - h[i + shifts[pos]])
        g[i, neg] -= h[i - shifts[neg]]
    return g

Actually, let me think about this more carefully. The objective is to minimize max_k corr[k]. The active constraint is k*. The gradient of corr[k*] with respect to h is g[:, k*] (the k*-th column of g).

To decrease corr[k*], we want to move in the direction of -g[:, k*]. That is, decrease h where g[:, k*] is positive, increase h where g[:, k*] is negative.

But we also need to make sure we don't increase other corr[k] too much. So we need to check the effect on all corrs.

The approach:
1. Pick i = argmax g[:, k*] (most positive gradient → decreasing h[i] most helps corr[k*])
2. Pick j = argmin g[:, k*] (most negative gradient → increasing h[j] also helps corr[k*])
3. Compute d = g[j] - g[i] (the change in all correlations per unit delta)
4. Find optimal delta by 1D optimization: minimize max_k (corr[k] + delta * d[k])
5. Update h

For step 4, the function f(delta) = max_k (corr[k] + delta * d[k]) is convex in delta. We can use binary search.

The derivative at delta is: f'(delta) = d[k*(delta)] where k*(delta) is the active lag at delta. If f'(delta) > 0, increase delta; if < 0, decrease.

But we need to find where f'(delta) = 0, i.e., where the active lag has d[k*] = 0. This might not exist, in which case the optimum is at a kink.

        return budget_s - 25.0 - (time.time() - start_time)

    h_init = np.array(initial_h_values, dtype=float)
    n0 = len(h_init)
    target0 = n0 / 2.0

    best_h = project_feasible(h_init, target0)
    best_score = compute_c5(best_h)
    best_n = n0
    best_target = target0

    if tleft() > 80:
        h_s, sc = slsqp_round(best_h, n0, target0, [50, 200, 1000], 400, 1e-14)
        if sc < best_score:
            best_score = sc
            best_h = h_s

    if tleft() > 200:
        h_cp, sc_cp = cutting_plane_fast(best_h, n0, target0,
                                         time_limit=min(200, tleft() * 0.7),
                                         max_iters=5000, n_cuts_per_iter=5, max_cuts=400)
        if sc_cp < best_score:
            best_score = sc_cp
            best_h = h_cp

    if tleft() > 150:
        h_cd, sc_cd = coord_descent_precomp(best_h, n0, target0,
                                            time_limit=min(150, tleft() * 0.7))
        if sc_cd < best_score:
            best_score = sc_cd
            best_h = h_cd

    if tleft() > 100:
        h_ns, sc_ns = nesterov_smooth(best_h, n0, target0,
                                      time_limit=min(80, tleft() * 0.6), n_iters=2000)
        if sc_ns < best_score:
            best_score = sc_ns
            best_h = h_ns

    if tleft() > 150:
        h_cp2, sc_cp2 = cutting_plane_fast(best_h, n0, target0,
                                           time_limit=min(120, tleft() * 0.6),
                                           max_iters=4000, n_cuts_per_iter=8, max_cuts=500)
        if sc_cp2 < best_score:
            best_score = sc_cp2
            best_h = h_cp2

    if tleft() > 400:
        n1 = 800
        target1 = n1 / 2.0
        h800 = interpolate_to(best_h, n1, target1)

        if tleft() > 350:
            h800_cp, sc800 = cutting_plane_fast(h800, n1, target1,
                                                 time_limit=min(250, tleft() * 0.6),
                                                 max_iters=4000, n_cuts_per_iter=4, max_cuts=350)
            if sc800 < best_score:
                best_score = sc800
                best_h = h800_cp
                best_n = n1
                best_target = target1

        if tleft() > 150 and best_n == n1:
            h800_cd, sc800cd = coord_descent_precomp(best_h, n1, target1,
                                                      time_limit=min(150, tleft() * 0.6))
            if sc800cd < best_score:
                best_score = sc800cd
                best_h = h800_cd

        if tleft() > 80 and best_n == n1:
            h800_sls, sc800s = slsqp_round(best_h, n1, target1, [2000, 10000], 400, 1e-14)
            if sc800s < best_score:
                best_score = sc800s
                best_h = h800_sls

    if tleft() > 100:
        rng = np.random.RandomState(seed)
        for trial in range(4):
            if tleft() < 60:
                break
            scale = [0.03, 0.05, 0.08, 0.12][trial]
            h_pert = best_h + rng.randn(best_n) * scale
            h_pert = project_feasible(h_pert, best_target)
            h_ref, sc_ref = coord_descent_precomp(h_pert, best_n, best_target,
                                                   time_limit=min(50, tleft() * 0.5))
            if sc_ref < best_score:
                best_score = sc_ref
                best_h = h_ref

    if tleft() > 60:
        h_final_cd, sc_final = coord_descent_precomp(best_h, best_n, best_target,
                                                      time_limit=min(50, tleft() * 0.7))
        if sc_final < best_score:
            best_score = sc_final
            best_h = h_final_cd

    if tleft() > 30:
        h_final_cp, sc_fcp = cutting_plane_fast(best_h, best_n, best_target,
                                                 time_limit=min(25, tleft() * 0.7),
                                                 max_iters=2000, n_cuts_per_iter=5, max_cuts=300)
        if sc_fcp < best_score:
            best_score = sc_fcp
            best_h = h_fcp

    final_h = project_feasible(best_h, best_n / 2.0)
    final_score = compute_c5(final_h)
    return final_h, final_score, len(final_h)
