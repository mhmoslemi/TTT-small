- The subgradient at delta is the convex hull of {b_k : k is active}
- f is minimized where 0 is in the subgradient
- This means min{b_k : k active} <= 0 <= max{b_k : k active}

So I can:
1. Start at delta = 0
2. Find active set (k where a_k + delta*b_k = max)
3. If all active b_k > 0, decrease delta
4. If all active b_k < 0, increase delta
5. Otherwise, we're at the minimum

But "increase/decrease" needs a step size. Alternatively, I can just do a binary search or use the fact that the minimum of a convex PL function can be found in O(m log m) where m is the number of pieces, by sorting the breakpoints.

For practical purposes, let me just use a simple approach: evaluate f at a few candidate delta values (including the endpoints and the "breakpoints" that are closest to the current value) and pick the best.

Actually, the simplest effective approach for 1D convex PL minimization is:
1. Evaluate at delta_lo and delta_hi
2. If f(delta_lo) < f(delta_hi), the minimum is in [delta_lo, mid]
3. Binary search until convergence

But since the function is piecewise linear, the minimum is at a breakpoint or at a boundary. The breakpoints are at delta = (a_k - a_m) / (b_m - b_k) for each pair. There are O(m²) breakpoints but we only need to check O(m) of them (the ones near the current value).

For practical purposes, I'll just use a "golden section search" or evaluate at 20-30 evenly spaced points in the feasible range and pick the best. Given that each evaluation is O(2n) (just computing the max of corr + delta*change), this is cheap.

The issue is that `change[i, k] = (1-h[i+k]) - h[i-k]` depends on h. So after h changes, I need to update the change matrix rows that are affected.

When h[j] changes, which entries of the change matrix are affected?
- change[i, k] is affected if h[i+k] or h[i-k] changed, i.e., if i+k = j or i-k = j.
  - i+k = j → i = j-k, for each k
  - i-k = j → i = j+k, for each k

So changing h[j] affects all rows i where i = j±k for some k, which is ALL rows (since k ranges over -(n-1) to n-1, j±k covers all of 0 to n-1 for some k).

Wait no. For a fixed j, the affected entries are:
- change[j-k, k+(n-1)] for all valid k (because h[j-k+k] = h[j] appears in the forward term)
- change[j+k, -(k)+(n-1)] for all valid k (because h[j+k-k] = h[j] appears in the backward term)

So changing h[j] affects O(n) entries across O(n) rows. That's O(n²) total updates, which defeats the purpose.

Alternative: don't maintain the change matrix. Instead, compute the gradient directly each time.

The gradient is:
grad[i] = sum_k w[k] * ((1-h[i+k]) * 1[valid] - h[i-k] * 1[valid])

I can compute this as:
grad[i] = (w * (1-h))[i] (correlation-like) - (w * h)[i] (correlation-like)

where (w * x)[i] = sum_k w[k] * x[i+k] (with appropriate boundary handling).

This is a correlated convolution, which I can compute using FFT or directly.

    n_corr = 2 * n - 1
    mid = n - 1
    idxs = np.arange(n)

- Find the optimal delta (accounting for box constraints and sum constraint)
- The sum constraint means if I increase h[i] by delta, I need to decrease some h[j] by delta

  where delta > 0 means moving mass from j to i.

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr)) * dx

def compute_corr(h):
    return np.correlate(h, 1.0 - h, mode='full')

def project_feasible(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    n = len(h)
    for _ in range(100):
        diff = target_sum - np.sum(h)
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            mask = h < 1.0 - 1e-15
        else:
            mask = h > 1e-15
        if not mask.any():
            h = np.clip(h + diff / n, 0.0, 1.0)
            break
        h[mask] += diff / mask.sum()
        h = np.clip(h, 0.0, 1.0)
    return h

def get_smooth_weights(corr, alpha):
    c_max = np.max(corr)
    shifted = np.clip(alpha * (corr - c_max), -600.0, 0.0)
    weights = np.exp(shifted)
    w_sum = np.sum(weights)
    if w_sum < 1e-300:
        weights = np.zeros(len(corr))
        weights[np.argmax(corr)] = 1.0
    else:
        weights /= w_sum
    return weights

def grad_from_weights(h, weights, n):
    mid = n - 1
    grad = np.zeros(n)
    for k_idx in range(len(weights)):
        w = weights[k_idx]
        if w < 1e-14:
            continue
        k = k_idx - mid
        if k >= 0:
            n_f = n - k
            grad[:n_f] += w * (1.0 - h[k:])
            grad[k:] -= w * h[:n_f]
        else:
            kp = -k
            n_f = n - kp
            grad[kp:] += w * (1.0 - h[:n_f])
            grad[:n_f] -= w * h[kp:]
    grad -= np.mean(grad)
    return grad
