The Frank-Wolfe method works for minimizing a convex function over a convex polytope. Our objective is NOT convex (it's the max of bilinear forms), so FW doesn't directly apply.

2. Find the vertex v of the feasible polytope that minimizes <grad, v> (the linear minimization oracle)
3. Take a step: h_new = (1-γ) * h + γ * v
4. Update step size γ

The linear minimization oracle for our polytope:
minimize <g, v> s.t. 0 ≤ v ≤ 1, sum(v) = n/2

This is solved by: sort g, set v_i = 1 for the smallest g_i values and v_i = 0 for the largest, with one value partially set to meet the sum constraint.

This is O(n log n) per iteration, which is fast!

The advantage of FW:
- Simple implementation
- Each iteration is fast (O(n log n) for the oracle + O(n * n_corr) for the gradient)
- No need for line search
- Convergence is linear for smooth objectives

```python
def fw_smooth_step(h, g, target):
    # Frank-Wolfe step: find v that minimizes <g, v> over the polytope
    # Polytope: 0 <= v <= 1, sum(v) = target
    n = len(h)
    sorted_idx = np.argsort(g)
    # We want sum(v) = target
    # Set v = 1 for smallest g values, 0 for largest
    # One value is fractional
    v = np.zeros(n)
    remaining = float(target)
    for idx in sorted_idx:
        if remaining >= 1.0:
            v[idx] = 1.0
            remaining -= 1.0
        elif remaining > 0:
            v[idx] = remaining
            remaining = 0
            break
    return v
```

This gives a vertex of the polytope (or a face point). The FW update is:
h_new = (1 - γ) * h + γ * v

where γ is the step size. For the standard FW, γ_t = 2/(t+2). For accelerated FW (FISTA-like), we can use a different schedule.

```python
def block_cd(h_init, n, target, time_limit, block_size=8, max_passes=100):
    start = time.time()
    h = h_init.copy().astype(float)
    best_c5 = compute_c5(h)
    best_h = h.copy()
    n_blocks = n // block_size
    remaining = n % block_size
    
    dx = 2.0 / n
    n_corr = 2 * n - 1
    shifts = np.arange(-(n-1), n)
    
    for iteration in range(max_passes * n_blocks):
        if time.time() - start > time_limit:
            break
        
        # Select block (cycling or random)
        block_id = iteration % n_blocks
        if block_id == n_blocks - 1 and remaining > 0:
            start_idx = block_id * block_size
            end_idx = n
        else:
            start_idx = block_id * block_size
            end_idx = start_idx + block_size
        
        b = end_idx - start_idx
        target_block = float(np.sum(h[start_idx:end_idx]))  # Keep same sum
        
        # Optimize this block
        def block_obj(x):
            h_trial = h.copy()
            h_trial[start_idx:end_idx] = x
            corr = np.correlate(h_trial, 1.0 - h_trial, mode='full')
            c_max = np.max(corr)
            # Smooth max for gradient
            alpha = 100.0
            shifted = alpha * (corr - c_max)
            shifted = np.clip(shifted, -500.0, 0.0)
            return float(c_max + np.log(np.sum(np.exp(shifted))) / alpha) * dx
        
        bounds = [(0.0, 1.0)] * b
        cons = [{'type': 'eq', 'fun': lambda x: np.sum(x) - target_block,
                 'jac': lambda x: np.ones(b)}]
        
        try:
            res = minimize(block_obj, h[start_idx:end_idx].copy(), method='SLSQP',
                          bounds=bounds, constraints=cons, options={'maxiter': 200, 'ftol': 1e-12})
            if res.fun < block_obj(h[start_idx:end_idx]):
                h[start_idx:end_idx] = res.x
                h = project_feasible(h, target)
                c5 = compute_c5(h)
                if c5 < best_c5:
                    best_c5 = c5
                    best_h = h.copy()
        except Exception:
            pass
    
    return best_h, best_c5
```

The total budget is 1300s, so there's plenty of time. The question is whether the algorithm is efficient enough.

Key insight: The pairwise CD with exact line search is the most efficient local optimizer. The bottleneck is that it only considers O(n_cand^2) pairs per sweep, and each pair requires a bisection line search (18 iterations of computing max of 799 values).

For n=400, n_cand=80, that's 80*80 = 6400 pairs per sweep, each requiring 18 * O(799) ≈ 14K operations. Total per sweep: ~90M operations. At ~100M ops/s in NumPy, that's about 0.9s per sweep. So in 280s, we get about 300 sweeps.

To improve:
- Use vectorized line search (compute all pairs' optimal deltas simultaneously) - but this requires more memory
- Use a smaller search space (fewer candidates but smarter selection)
- Use a different move type (triplet or block moves)

Let me try a different approach: **vectorized pairwise CD**

Instead of looping over all pairs, I can:
1. Compute the gradient (subgradient) of the max
2. For each coordinate i, the best direction is to decrease h[i] if grad[i] > 0 or increase if grad[i] < 0
3. The "best" pair is the one with the largest product |grad[i]| * |grad[j]| where they have opposite signs

But the exact line search requires the full correlation vector, not just the gradient. So we can't fully vectorize.

However, we can **pre-filter** candidates more aggressively:
- Only consider pairs where the estimated improvement (using first-order approximation) is above a threshold
- This reduces the number of pairs that need exact line search

```python
import numpy as np
from scipy.optimize import minimize
import time

# Global variables for SLSQP callbacks
_g_n = 0
_g_target = 0.0
_g_block_h = None
_g_block_start = 0
_g_block_end = 0
_g_block_target = 0.0
_g_alpha = 100.0

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr)) * dx

def project_feasible(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    n = len(h)
    for _ in range(100):
        diff = target_sum - np.sum(h)
        if abs(diff) < 1e-15:
            break
        if diff > 0:
            mask = h < 1.0 - 1e-16
        else:
            mask = h > 1e-16
        if not mask.any():
            step = diff / n
            h = np.clip(h + step, 0.0, 1.0)
            break
        h[mask] += diff / mask.sum()
        h = np.clip(h, 0.0, 1.0)
    return h

def compute_change_matrix(h, n):
    n_corr = 2 * n - 1
    shifts = np.arange(-(n - 1), n)
    change = np.zeros((n, n_corr))
    for p in range(n):
        pos_mask = (p + shifts >= 0) & (p + shifts < n)
        neg_mask = (p - shifts >= 0) & (p - shifts < n)
        change[p, pos_mask] += (1.0 - h[p + shifts[pos_mask]])
        change[p, neg_mask] -= h[p - shifts[neg_mask]]
    return change

def update_change_row(change, p, h, n, shifts):
    change[p, :] = 0.0
    pos_mask = (p + shifts >= 0) & (p + shifts < n)
    neg_mask = (p - shifts >= 0) & (p - shifts < n)
    change[p, pos_mask] += (1.0 - h[p + shifts[pos_mask]])
    change[p, neg_mask] -= h[p - shifts[neg_mask]]
    return change

# Smooth objective for SLSQP
def _smooth_obj(x, alpha):
    corr = np.correlate(x, 1.0 - x, mode='full')
    c_max = np.max(corr)
    shifted = alpha * (corr - c_max)
    shifted = np.clip(shifted, -500.0, 0.0)
    return float(c_max + np.log(np.sum(np.exp(shifted))) / alpha)

def _cons_fun(x):
    return np.sum(x) - _g_target

def _cons_jac(x):
    return np.ones(_g_n)

def slsqp_round(h_start, n, target, alphas, maxiter_per_alpha, ftol=1e-15):
    global _g_n, _g_target
    _g_n = n
    _g_target = target
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': _cons_fun, 'jac': _cons_jac}]
    h_cur = h_start.copy()
    cur_score = compute_c5(h_cur)
    for alpha in alphas:
        try:
            res = minimize(_smooth_obj, h_cur, args=(alpha,),
                           method='SLSQP', bounds=bounds, constraints=cons,
                           options={'maxiter': maxiter_per_alpha, 'ftol': ftol})
            h_new = project_feasible(res.x, target)
            sc = compute_c5(h_new)
            if sc < cur_score:
                cur_score = sc
                h_cur = h_new
        except Exception:
            pass
    return h_cur, cur_score

# Block objective for SLSQP
def _block_obj(x):
    h_trial = _g_block_h.copy()
    h_trial[_g_block_start:_g_block_end] = x
    corr = np.correlate(h_trial, 1.0 - h_trial, mode='full')
    c_max = np.max(corr)
    shifted = _g_alpha * (corr - c_max)
    shifted = np.clip(shifted, -500.0, 0.0)
    return float(c_max + np.log(np.sum(np.exp(shifted))) / _g_alpha)

def _block_con_fun(x):
    return np.sum(x) - _g_block_target

def _block_con_jac(x):
    return np.ones(_g_block_end - _g_block_start)

def block_cd(h_init, n, target, time_limit, block_size=8, max_passes=50):
    global _g_block_h, _g_block_start, _g_block_end, _g_block_target, _g_alpha
    start = time.time()
    h = h_init.copy().astype(float)
    best_c5 = compute_c5(h)
    best_h = h.copy()
    n_blocks = n // block_size
    
    for iteration in range(max_passes * n_blocks):
        if time.time() - start > time_limit:
            break
        
        block_id = iteration % n_blocks
        if block_id == n_blocks - 1 and (n % block_size > 0):
            start_idx = block_id * block_size
            end_idx = n
        else:
            start_idx = block_id * block_size
            end_idx = min(start_idx + block_size, n)
        
        b = end_idx - start_idx
        if b < 2:
            continue
        
        # Keep the block sum the same
        block_target = float(np.sum(h[start_idx:end_idx]))
        
        _g_block_h = h
        _g_block_start = start_idx
        _g_block_end = end_idx
        _g_block_target = block_target
        _g_alpha = 200.0
        
        bounds = [(0.0, 1.0)] * b
        cons = [{'type': 'eq', 'fun': _block_con_fun, 'jac': _block_con_jac}]
        
        try:
            res = minimize(_block_obj, h[start_idx:end_idx].copy(), method='SLSQP',
                          bounds=bounds, constraints=cons, options={'maxiter': 300, 'ftol': 1e-14})
            if res.success and res.fun < _block_obj(h[start_idx:end_idx]):
                h[start_idx:end_idx] = res.x
                h = project_feasible(h, target)
                c5 = compute_c5(h)
                if c5 < best_c5:
                    best_c5 = c5
                    best_h = h.copy()
        except Exception:
            pass
    
    return best_h, best_c5

# Pre-filtered pairwise CD
def prefilter_cd(h_init, n, target, time_limit, max_sweeps=30000,
                 n_cand_start=20, n_cand_end=80, max_no_improve=500,
                 n_prefilter=300, restart_every=200, restart_scale=0.02):
    start = time.time()
    dx = 2.0 / n
    n_corr = 2 * n - 1
    shifts = np.arange(-(n - 1), n)
    idxs = np.arange(n)
    mid = n - 1
    
    h = h_init.copy().astype(float)
    best_c5 = compute_c5(h)
    best_h = h.copy()
    consecutive_no_improve = 0
    rng = np.random.RandomState(12345)
    
    change = compute_change_matrix(h, n)
    
    for sweep in range(max_sweeps):
        if time.time() - start > time_limit:
            break
        
        corr = np.correlate(h, 1.0 - h, mode='full')
        c5_val = float(np.max(corr)) * dx
        
        if c5_val < best_c5 - 1e-14:
            best_c5 = c5_val
            best_h = h.copy()
            consecutive_no_improve = 0
        else:
            consecutive_no_improve += 1
        
        if consecutive_no_improve > max_no_improve:
            break
        
        if consecutive_no_improve > restart_every and consecutive_no_improve % 50 == 0:
            h = best_h + rng.randn(n) * restart_scale
            h = project_feasible(h, target)
            change = compute_change_matrix(h, n)
            consecutive_no_improve = 0
        
        k_star_idx = int(np.argmax(corr))
        k_star = k_star_idx - mid
        
        # Compute subgradient
        grad = np.zeros(n)
        v1 = (idxs - k_star >= 0) & (idxs - k_star < n)
        v2 = (idxs + k_star >= 0) & (idxs + k_star < n)
        grad[v1] += (1.0 - h[idxs[v1] - k_star])
        grad[v2] -= h[idxs[v2] + k_star]
        grad -= np.mean(grad)
        
        # Select candidates
        progress = min(float(sweep) / max_sweeps, 1.0)
        current_ncand = int(n_cand_start + (n_cand_end - n_cand_start) * progress)
        current_ncand = min(current_ncand, n // 2)
        
        sorted_idx = np.argsort(grad)
        low_set = sorted_idx[:current_ncand]
        high_set = sorted_idx[-current_ncand:]
        
        # Pre-filter: rank pairs by first-order estimate
        n_h = len(high_set)
        n_l = len(low_set)
        
        # Compute first-order improvement estimates
        # For pair (i, j) with i in high, j in low:
        # improvement ≈ delta * (grad[j] - grad[i]) where delta = min(h[i], 1-h[j])
        # (approximately, since we're decreasing h[i] and increasing h[j])
        
        # Vectorized computation of improvement estimates
        h_hi = h[high_set]  # (n_h,)
        h_lo = h[low_set]   # (n_l,)
        grad_hi = grad[high_set]  # (n_h,)
        grad_lo = grad[low_set]   # (n_l,)
        
        # For each pair, the max delta is min(h[i], 1-h[j])
        # The improvement estimate is delta * |grad[j] - grad[i]|
        # (we're moving in the direction that decreases the active correlation)
        
        # Actually, the change in corr_k for moving delta from i to j is:
        # delta * (change[j, k_star] - change[i, k_star])
        # = delta * (grad[j] - grad[i]) (approximately, for the active shift)
        # But we need to consider ALL shifts, not just the active one
        # So the first-order estimate is just for screening
        
        delta_matrix = np.minimum(h_hi[:, None], 1.0 - h_lo[None, :])  # (n_h, n_l)
        grad_diff = grad_lo[None, :] - grad_hi[:, None]  # (n_h, n_l)
        
        # We want pairs where grad_diff > 0 (reducing h[i] and increasing h[j] helps)
        # and delta is large
        estimate = delta_matrix * np.clip(grad_diff, 0, None)
        
        # Get top n_prefilter pairs
        flat_estimate = estimate.ravel()
        flat_idx = np.argsort(flat_estimate)[::-1]
        
        best_trial_c5 = c5_val
        best_i = -1
        best_j = -1
        best_delta = 0.0
        
        checked = 0
        for flat_i in flat_idx:
            if checked >= n_prefilter:
                break
            ii = int(flat_i // n_l)
            jj = int(flat_i % n_l)
            i = int(high_set[ii])
            j = int(low_set[jj])
            if i == j:
                continue
            checked += 1
            
            delta_lo = max(h[i] - 1.0, -h[j])
            delta_hi = min(h[i], 1.0 - h[j])
            if delta_hi - delta_lo < 1e-13:
                continue
            
            g = change[j] - change[i]
            a_d = delta_lo
            b_d = delta_hi
            for _ in range(18):
                mid_d = 0.5 * (a_d + b_d)
                vals = corr + mid_d * g
                f_mid = np.max(vals)
                active_mask = vals >= f_mid - 1e-14
                if active_mask.any():
                    f_prime = np.max(g[active_mask])
                else:
                    f_prime = 0.0
                if f_prime > 1e-12:
                    b_d = mid_d
                else:
                    a_d = mid_d
            delta_star = 0.5 * (a_d + b_d)
            if abs(delta_star) < 1e-13:
                continue
            approx_max = np.max(corr + delta_star * g) * dx
            if approx_max < best_trial_c5:
                best_trial_c5 = approx_max
                best_i = i
                best_j = j
                best_delta = delta_star
        
        if best_i >= 0:
            h[best_i] -= best_delta
            h[best_j] += best_delta
            h = np.clip(h, 0.0, 1.0)
            h = project_feasible(h, target)
            update_change_row(change, best_i, h, n, shifts)
            update_change_row(change, best_j, h, n, shifts)
    
    return best_h, best_c5

def interpolate_to(h_src, n_dst, target_dst):
    n_src = len(h_src)
    if n_src == n_dst:
        return project_feasible(h_src.copy(), target_dst)
    x_old = np.linspace(0.0, 2.0, n_src + 1, endpoint=True)
    x_old_mid = x_old[:-1] + (x_old[1] - x_old[0]) / 2.0
    x_new = np.linspace(0.0, 2.0, n_dst + 1, endpoint=True)
    x_new_mid = x_new[:-1] + (x_new[1] - x_new[0]) / 2.0
    h_out = np.interp(x_new_mid, x_old_mid, h_src)
    return project_feasible(h_out, target_dst)

# FW-style diversification
def fw_diversify(h_init, n, target, n_iter=500, alpha=100.0):
    h = h_init.copy().astype(float)
    best_c5 = compute_c5(h)
    best_h = h.copy()
    
    for t in range(n_iter):
        # Compute smoothed gradient
        corr = np.correlate(h, 1.0 - h, mode='full')
        c_max = np.max(corr)
        shifted = alpha * (corr - c_max)
        shifted = np.clip(shifted, -500.0, 0.0)
        weights = np.exp(shifted)
        weights = weights / weights.sum()
        
        # Grad = sum_k weights[k] * d(corr_k)/d(h)
        # Use change matrix for efficiency
        # Actually, let's compute it directly
        n_corr = 2 * n - 1
        shifts = np.arange(-(n-1), n)
        mid = n - 1
        idxs = np.arange(n)
        
        grad = np.zeros(n)
        for s in range(n_corr):
            if weights[s] < 1e-10:
                continue
            k = s - mid
            v1 = (idxs - k >= 0) & (idxs - k < n)
            v2 = (idxs + k >= 0) & (idxs + k < n)
            grad[v1] += weights[s] * (1.0 - h[idxs[v1] - k])
            grad[v2] -= weights[s] * h[idxs[v2] + k]
        
        # FW oracle: find vertex of polytope minimizing <grad, v>
        sorted_idx = np.argsort(grad)
        v = np.zeros(n)
        remaining = float(target)
        for idx in sorted_idx:
            if remaining >= 1.0 - 1e-12:
                v[idx] = 1.0
                remaining -= 1.0
            elif remaining > 1e-12:
                v[idx] = remaining
                remaining = 0.0
                break
        
        # Step
        gamma = 2.0 / (t + 2.0)
        h_new = (1.0 - gamma) * h + gamma * v
        h_new = project_feasible(h_new, target)
        
        c5 = compute_c5(h_new)
        if c5 < best_c5:
            best_c5 = c5
            best_h = h_new.copy()
        h = h_new
    
    return best_h, best_c5
```

```python
_g_block_end = 0

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr)) * dx


def project_feasible(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    n = len(h)
    for _ in range(100):
        diff = target_sum - np.sum(h)
        if abs(diff) < 1e-15:
            break
        if diff > 0:
            mask = h < 1.0 - 1e-16
        else:
            mask = h > 1e-16
        if not mask.any():
            step = diff / n
            h = np.clip(h + step, 0.0, 1.0)
            break
        h[mask] += diff / mask.sum()
        h = np.clip(h, 0.0, 1.0)
    return h


def compute_change_matrix(h, n):
    n_corr = 2 * n - 1
    shifts = np.arange(-(n - 1), n)
    change = np.zeros((n, n_corr))
    for p in range(n):
        pos_mask = (p + shifts >= 0) & (p + shifts < n)
        neg_mask = (p - shifts >= 0) & (p - shifts < n)
        change[p, pos_mask] += (1.0 - h[p + shifts[pos_mask]])
        change[p, neg_mask] -= h[p - shifts[neg_mask]]
    return change


def update_change_row(change, p, h, n, shifts):
    change[p, :] = 0.0
    pos_mask = (p + shifts >= 0) & (p + shifts < n)
    neg_mask = (p - shifts >= 0) & (p - shifts < n)
    change[p, pos_mask] += (1.0 - h[p + shifts[pos_mask]])
    change[p, neg_mask] -= h[p - shifts[neg_mask]]
    return change


def _smooth_obj(x, alpha):
    corr = np.correlate(x, 1.0 - x, mode='full')
    c_max = np.max(corr)
    shifted = alpha * (corr - c_max)
    shifted = np.clip(shifted, -500.0, 0.0)
    return float(c_max + np.log(np.sum(np.exp(shifted))) / alpha)


def _cons_fun(x):
    return np.sum(x) - _g_target


def _cons_jac(x):
    return np.ones(_g_n)


def slsqp_round(h_start, n, target, alphas, maxiter_per_alpha, ftol=1e-15):
    global _g_n, _g_target
    _g_n = n
    _g_target = target
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': _cons_fun, 'jac': _cons_jac}]
    h_cur = h_start.copy()
    cur_score = compute_c5(h_cur)
    for alpha in alphas:
        try:
            res = minimize(_smooth_obj, h_cur, args=(alpha,),
                           method='SLSQP', bounds=bounds, constraints=cons,
                           options={'maxiter': maxiter_per_alpha, 'ftol': ftol})
            h_new = project_feasible(res.x, target)
            sc = compute_c5(h_new)
            if sc < cur_score:
                cur_score = sc
                h_cur = h_new
        except Exception:
            pass
    return h_cur, cur_score

            if approx_max < best_trial_c5:
                best_trial_c5 = approx_max
                best_i = i
                best_j = j
                best_delta = delta_star

        if best_i >= 0:
            h[best_i] -= best_delta
            h[best_j] += best_delta
            h = np.clip(h, 0.0, 1.0)
            h = project_feasible(h, target)
            update_change_row(change, best_i, h, n, shifts)
            update_change_row(change, best_j, h, n, shifts)

    return best_h, best_c5


def multi_shift_cd(h_init, n, target, time_limit, max_sweeps=15000,
                   n_cand=50, n_shifts=5, n_prefilter=250):
    start = time.time()
    dx = 2.0 / n
    n_corr = 2 * n - 1
    shifts_arr = np.arange(-(n - 1), n)
    idxs = np.arange(n)
    mid = n - 1

    h = h_init.copy().astype(float)
    best_c5 = compute_c5(h)
    best_h = h.copy()
    consecutive_no_improve = 0
    change = compute_change_matrix(h, n)

    for sweep in range(max_sweeps):
        if time.time() - start > time_limit:
            break

        corr = np.correlate(h, 1.0 - h, mode='full')
        c5_val = float(np.max(corr)) * dx

        if c5_val < best_c5 - 1e-14:
            best_c5 = c5_val
            best_h = h.copy()
            consecutive_no_improve = 0
        else:
            consecutive_no_improve += 1

        if consecutive_no_improve > 350:
            break

        top_shifts = np.argsort(corr)[-n_shifts:]
        top_sum = np.sum(corr[top_shifts])
        if top_sum < 1e-15:
            top_sum = 1.0

        grad = np.zeros(n)
        for s_idx in top_shifts:
            w = corr[s_idx] / top_sum
            k = int(s_idx) - mid
            v1 = (idxs - k >= 0) & (idxs - k < n)
            v2 = (idxs + k >= 0) & (idxs + k < n)
            grad[v1] += w * (1.0 - h[idxs[v1] - k])
            grad[v2] -= w * h[idxs[v2] + k]
        grad -= np.mean(grad)

        sorted_idx = np.argsort(grad)
        low_set = sorted_idx[:n_cand]
        high_set = sorted_idx[-n_cand:]
        n_h = len(high_set)
        n_l = len(low_set)

        h_hi = h[high_set]
        h_lo = h[low_set]
        grad_hi = grad[high_set]
        grad_lo = grad[low_set]
        delta_max = np.minimum(h_hi[:, None], 1.0 - h_lo[None, :])
        grad_improve = grad_hi[:, None] - grad_lo[None, :]
        estimate = delta_max * np.maximum(grad_improve, 0.0)
        flat_est = estimate.ravel()
        flat_order = np.argsort(flat_est)[::-1]

        best_trial_c5 = c5_val
        best_i = -1
        best_j = -1
        best_delta = 0.0
        checked = 0
        for fi in flat_order:
            if checked >= n_prefilter:
                break
            ii = int(fi // n_l)
            jj = int(fi % n_l)
            i = int(high_set[ii])
            j = int(low_set[jj])
            if i == j:
                continue
            checked += 1
            delta_lo = max(h[i] - 1.0, -h[j])
            delta_hi = min(h[i], 1.0 - h[j])
            if delta_hi - delta_lo < 1e-13:
                continue
            g = change[j] - change[i]
            a_d = delta_lo
            b_d = delta_hi
            for _ in range(18):
                mid_d = 0.5 * (a_d + b_d)
                vals = corr + mid_d * g
                f_mid = np.max(vals)
                active_mask = vals >= f_mid - 1e-14
                if active_mask.any():
                    f_prime = np.max(g[active_mask])
                else:
                    f_prime = 0.0
                if f_prime > 1e-12:
                    b_d = mid_d
                else:
                    a_d = mid_d
            delta_star = 0.5 * (a_d + b_d)
            if abs(delta_star) < 1e-13:
                continue
            approx_max = np.max(corr + delta_star * g) * dx
            if approx_max < best_trial_c5:
                best_trial_c5 = approx_max
                best_i = i
                best_j = j
                best_delta = delta_star

        if best_i >= 0:
            h[best_i] -= best_delta
            h[best_j] += best_delta
            h = np.clip(h, 0.0, 1.0)
            h = project_feasible(h, target)
            update_change_row(change, best_i, h, n, shifts_arr)
            update_change_row(change, best_j, h, n, shifts_arr)

    return best_h, best_c5


def interpolate_to(h_src, n_dst, target_dst):
    n_src = len(h_src)
    if n_src == n_dst:
        return project_feasible(h_src.copy(), target_dst)
    x_old = np.linspace(0.0, 2.0, n_src + 1, endpoint=True)
    x_old_mid = x_old[:-1] + (x_old[1] - x_old[0]) / 2.0
    x_new = np.linspace(0.0, 2.0, n_dst + 1, endpoint=True)
    x_new_mid = x_new[:-1] + (x_new[1] - x_new[0]) / 2.0
    h_out = np.interp(x_new_mid, x_old_mid, h_src)
    return project_feasible(h_out, target_dst)


def fw_diversify(h_init, n, target, n_iter=300, alpha=200.0, gamma_init=0.5):
    h = h_init.copy().astype(float)
    best_c5 = compute_c5(h)
    best_h = h.copy()
    idxs = np.arange(n)
    mid = n - 1
    shifts = np.arange(-(n - 1), n)
    cur_score = compute_c5(h)

    for t in range(n_iter):
        corr = np.correlate(h, 1.0 - h, mode='full')
        c_max = np.max(corr)
        shifted = alpha * (corr - c_max)
        shifted = np.clip(shifted, -500.0, 0.0)
        weights = np.exp(shifted)
        w_sum = weights.sum()
        if w_sum < 1e-300:
            break
        weights = weights / w_sum

        grad = np.zeros(n)
        for s in range(len(shifts)):
            if weights[s] < 1e-12:
                continue
            k = s - mid
            v1 = (idxs - k >= 0) & (idxs - k < n)
            v2 = (idxs + k >= 0) & (idxs + k < n)
            grad[v1] += weights[s] * (1.0 - h[idxs[v1] - k])
            grad[v2] -= weights[s] * h[idxs[v2] + k]

        sorted_idx = np.argsort(grad)
        v = np.zeros(n)
        remaining = float(target)
        for idx in sorted_idx:
            if remaining >= 1.0 - 1e-12:
                v[idx] = 1.0
                remaining -= 1.0
            elif remaining > 1e-12:
                v[idx] = remaining
                remaining = 0.0
                break

        gamma = gamma_init * 2.0 / (t + 2.0)
        gamma = min(gamma, 0.5)
        h_new = (1.0 - gamma) * h + gamma * v
        h_new = project_feasible(h_new, target)

        c5 = compute_c5(h_new)
        if c5 < best_c5:
            best_c5 = c5
            best_h = h_new.copy()
        h = h_new
        cur_score = c5

    return best_h, best_c5


def run(seed=42, budget_s=1300, **kwargs):
    global _g_n, _g_target
    start_time = time.time()

    def tleft():
        return budget_s - 12.0 - (time.time() - start_time)

    h_init = np.array(initial_h_values, dtype=float)
    n0 = len(h_init)
    target0 = n0 / 2.0

    best_h = project_feasible(h_init, target0)
    best_score = compute_c5(best_h)
    current_n = n0
    current_target = target0

    # Phase 1: SLSQP warm start
    if tleft() > 80:
        h_pol, sc = slsqp_round(best_h, current_n, current_target,
                                [100, 500, 2000, 10000, 50000],
                                1000, 1e-15)
        if sc < best_score:
            best_score = sc
            best_h = h_pol

    # Phase 2: Pre-filtered pairwise CD (main workhorse)
    if tleft() > 250:
        h_cd, c5_cd = prefilter_cd(best_h, current_n, current_target,
                                   time_limit=min(300, tleft() * 0.45),
                                   max_sweeps=50000,
                                   n_cand_start=25, n_cand_end=90,
                                   max_no_improve=500,
                                   n_prefilter=400,
                                   restart_every=200, restart_scale=0.015)
        if c5_cd < best_score:
            best_score = c5_cd
            best_h = h_cd

    # Phase 3: Block coordinate descent
    if tleft() > 120:
        h_blk, c5_blk = block_cd(best_h, current_n, current_target,
                                 time_limit=min(100, tleft() * 0.4),
                                 block_size=10, max_passes=30)
        if c5_blk < best_score:
            best_score = c5_blk
            best_h = h_blk

    # Phase 4: SLSQP polish
    if tleft() > 80:
        h_pol2, sc2 = slsqp_round(best_h, current_n, current_target,
                                   [5000, 20000, 100000, 300000],
                                   1500, 1e-15)
        if sc2 < best_score:
            best_score = sc2
            best_h = h_pol2

    # Phase 5: Higher resolution (n=512)
    if tleft() > 350:
        n1 = 512
        target1 = n1 / 2.0
        h1 = interpolate_to(best_h, n1, target1)
        sc1 = compute_c5(h1)
        if tleft() > 200:
            h_cd1, c5_cd1 = prefilter_cd(h1, n1, target1,
                                         time_limit=min(180, tleft() * 0.4),
                                         max_sweeps=25000,
                                         n_cand_start=20, n_cand_end=70,
                                         max_no_improve=400,
                                         n_prefilter=300)
            if c5_cd1 < best_score:
                best_score = c5_cd1
                best_h = h_cd1
                current_n = n1
                current_target = target1
        if current_n == n1 and tleft() > 60:
            h_pol1, sc1b = slsqp_round(best_h, n1, target1,
                                       [5000, 30000],
                                       1000, 1e-15)
            if sc1b < best_score:
                best_score = sc1b
                best_h = h_pol1
        if current_n == n1 and tleft() > 80:
            h_blk1, c5_blk1 = block_cd(best_h, n1, target1,
                                       time_limit=min(60, tleft() * 0.4),
                                       block_size=8, max_passes=20)
            if c5_blk1 < best_score:
                best_score = c5_blk1
                best_h = h_blk1

    # Phase 6: Multi-shift CD
    if tleft() > 120:
        h_ms, c5_ms = multi_shift_cd(best_h, current_n, current_target,
                                     time_limit=min(120, tleft() * 0.45),
                                     max_sweeps=15000, n_cand=50, n_shifts=5,
                                     n_prefilter=250)
        if c5_ms < best_score:
            best_score = c5_ms
            best_h = h_ms

    # Phase 7: FW diversification + local refinement
    if tleft() > 200:
        h_fw, c5_fw = fw_diversify(best_h, current_n, current_target,
                                    n_iter=200, alpha=200.0, gamma_init=0.4)
        if c5_fw < best_score:
            best_score = c5_fw
            best_h = h_fw
        if tleft() > 100:
            h_cd_fw, c5_cd_fw = prefilter_cd(best_h, current_n, current_target,
                                             time_limit=min(90, tleft() * 0.4),
                                             max_sweeps=15000,
                                             n_cand_start=30, n_cand_end=80,
                                             max_no_improve=300,
                                             n_prefilter=350)
            if c5_cd_fw < best_score:
                best_score = c5_cd_fw
                best_h = h_cd_fw

    # Phase 8: Noise restarts
    if tleft() > 180:
        rng = np.random.RandomState(seed)
        for noise_scale in [0.01, 0.03, 0.07]:
            if tleft() < 80:
                break
            h_pert = best_h + rng.randn(current_n) * noise_scale
            h_pert = project_feasible(h_pert, current_target)
            h_ref, sc_ref = prefilter_cd(h_pert, current_n, current_target,
                                         time_limit=min(55, tleft() * 0.25),
                                         max_sweeps=8000,
                                         n_cand_start=30, n_cand_end=70,
                                         max_no_improve=200,
                                         n_prefilter=250)
            if sc_ref < best_score:
                best_score = sc_ref
                best_h = h_ref

    # Phase 9: Final CD pass
    if tleft() > 80:
        h_final_cd, c5_final = prefilter_cd(best_h, current_n, current_target,
                                            time_limit=min(70, tleft() * 0.65),
                                            max_sweeps=20000,
                                            n_cand_start=40, n_cand_end=100,
                                            max_no_improve=350,
                                            n_prefilter=500)
        if c5_final < best_score:
            best_score = c5_final
            best_h = h_final_cd

    # Phase 10: Final SLSQP
    if tleft() > 30:
        h_final_pol, sc_final = slsqp_round(best_h, current_n, current_target,
                                             [100000, 300000, 500000],
                                             1000, 1e-15)
        if sc_final < best_score:
            best_score = sc_final
            best_h = h_final_pol

    final_h = project_feasible(best_h, len(best_h) / 2.0)
    final_score = compute_c5(final_h)
    return final_h, final_score, len(final_h)
```
