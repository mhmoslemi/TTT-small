- sum(h) = target

The projection onto this set can be done as:
1. Start with x = h - step * grad (or similar)
2. Find λ such that sum(clamp(x + λ, 0, 1)) = target
3. Return clamp(x + λ, 0, 1)

def compute_correlations(h):
    return np.correlate(h, 1.0 - h, mode='full')

def evaluate_score(h):
    n = len(h)
    dx = 2.0 / n
    corr = compute_correlations(h)
    return np.max(corr) * dx

def project_simplex_box(v, target):
    """Project v onto {x: 0<=x<=1, sum(x)=target} using bisection."""
    n = len(v)
    # f(lambda) = sum(clamp(v + lambda, 0, 1)) - target
    # f is monotonically increasing in lambda
    lo, hi = -v.max() - 1, 1 - v.min()
    for _ in range(60):
        mid = (lo + hi) / 2
        s = np.sum(np.clip(v + mid, 0, 1)) - target
        if s > 0:
            hi = mid
        else:
            lo = mid
    lam = (lo + hi) / 2
    return np.clip(v + lam, 0, 1)

def compute_gradient(h, alpha, dx):
    """Compute softmax-weighted gradient of max correlation."""
    n = len(h)
    result = np.correlate(h, 1.0 - h, mode='full')
    max_r = np.max(result)
    exp_r = np.exp(alpha * (result - max_r))
    p = exp_r / exp_r.sum()
    
    j = np.arange(n)
    k = np.arange(2 * n - 1)
    
    # First term: sum_k p[k] * (1-h[j+k-(n-1)])
    idx1 = j[:, None] + k[None, :] - (n - 1)
    valid1 = (idx1 >= 0) & (idx1 < n)
    h_clipped = np.where(valid1, 1.0 - h[idx1], 0.0)
    term1 = h_clipped @ p

    idx2 = j[:, None] - k[None, :] + (n - 1)
    valid2 = (idx2 >= 0) & (idx2 < n)
    h_clipped2 = np.where(valid2, h[idx2], 0.0)
    term2 = h_clipped2 @ p
    
    return dx * (term1 - term2)

def gradient_descent(h, target, alpha, n_iters, t0, deadline):

    n = len(h)

            break
        
        grad = compute_gradient(h, alpha, dx)
        grad_norm = np.linalg.norm(grad)
        if grad_norm < 1e-12:
            break
        
        v = beta * v + (1 - beta) * grad
        # Normalize momentum for stable step size
        v_norm = np.linalg.norm(v)
        if v_norm > 1e-10:
            v = v / v_norm
        
        # Backtracking line search
        s = lr
        improved = False
        for _ in range(30):

            f_trial = np.max(np.correlate(h_trial, 1 - h_trial, mode='full')) * dx
            if f_trial < f_curr - 1e-12:
                h = h_trial
                f_curr = f_trial
                improved = True
                break
            s *= 0.5
        
        if not improved:
            lr *= 0.5
            if lr < 1e-8:
                break
        else:
            lr = min(s * 1.2, 0.5)
    
    return h, f_curr

**Better idea: Coordinate descent on the full [0,1]^n**

- For each coordinate j, optimize h[j] while keeping all other coordinates fixed
- The objective as a function of h[j] (with other coordinates fixed) is:

Wait, is g_k a quadratic? Let's see:
g_k(h[j]) = sum_i h[i]*(1-h[i+k-(n-1)])

The terms involving h[j] are:
- h[j]*(1-h[j+k-(n-1)])  [when i=j]
- h[j-k+(n-1)]*(1-h[j])  [when i+k-(n-1) = j, i.e., i = j-(n-1)+k... wait]

Let me be more careful. g_k = sum_i h[i]*(1-h[i+k-(n-1)])

The terms where h[j] appears:
1. i = j: h[j]*(1-h[j+k-(n-1)]) - this is linear in h[j]
2. i+k-(n-1) = j, i.e., i = j-k+(n-1): h[j-k+(n-1)]*(1-h[j]) - this is also linear in h[j]

So g_k is LINEAR in h[j] (not quadratic)! The coefficient of h[j] in g_k is:
(1-h[j+k-(n-1)]) - h[j-k+(n-1)]

(if both indices are valid; otherwise just one term)

So f(h[j]) = max_k (a_k * h[j] + b_k) where a_k and b_k don't depend on h[j].

The maximum of linear functions is a convex piecewise-linear function of h[j]. Its minimum over [0,1] is at a vertex: either 0, 1, or at a breakpoint (where two lines cross).

This means coordinate descent can find the exact optimum for each coordinate! And since each coordinate optimization is exact (not just a line search), convergence should be fast.
