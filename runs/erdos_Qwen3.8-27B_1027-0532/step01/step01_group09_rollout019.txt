Wait, this is the max of affine functions in x (since each c_k is affine in h[j] when all other variables are fixed). The max of affine functions is convex. So we're minimizing a convex function of x (specifically, the max of lines)!

This is great! For coordinate descent:
- For each j, compute the "lines" that define the objective as a function of h[j]
- Find the x that minimizes the maximum of these lines (this is a 1D convex minimization)
- Update h[j]

The minimum of the max of affine functions in 1D can be found by:
- The function is V-shaped (or more generally, piecewise linear and convex)
- The minimum is where the subgradient contains 0
- Equivalently, it's where the slope changes from negative to positive

For the max of lines f(x) = max_i (a_i * x + b_i), the minimum is at the point where the slope (which is the max of the a_i for lines that are active) changes sign.

This is equivalent to finding x* such that:
- There exist lines i, j with a_i < 0 < a_j (or a_i = 0 = a_j)
- Such that a_i * x* + b_i = a_j * x* + b_j = f(x*)

This can be found by bisection on the slope!

Let me implement this:

```python
    # 
    # c_k = sum_i h[i] * (1 - h[i+k])

    #   i = j-k: h[j-k] * (1 - h[j]) [if j-k valid]
    #

    #         = base_k + h[j]*(1-h[j+k]) + h[j-k] - h[j-k]*h[j]
    #         = base_k + h[j-k] + h[j] * (1 - h[j+k] - h[j-k])

    # So c_k(x) = base_k + h[j-k] + x * (1 - h[j+k] - h[j-k])
    # where h[j+k] and h[j-k] are the CURRENT values (not changing)
    #
    # So it's affine in x: c_k(x) = A_k * x + B_k
    # where A_k = (1 - h[j+k] - h[j-k]) [with 0 for invalid indices]
    # and B_k = base_k + h[j-k]

    # First, compute base_k = c_k - h[j]*(1-h[j+k_valid]) - h[j-k_valid]*(1-h[j])
    # Actually, it's easier to just compute A_k directly.
    
    # A_k = (1 - h[j+k] if valid else 1) - (h[j-k] if valid else 0)
    # Wait, let me redo:
    # c_k(x) = base + x * (1 - h[j+k] if j+k valid else 0) - h[j-k] if j-k valid else 0
    # Hmm, I need to be more careful.
    
    # c_k = sum_i h[i] * (1 - h[i+k])
    # Terms with h[j]:
    #   i=j: h[j] * (1 - h[j+k]) if j+k in [0,n)
    #   i=j-k: h[j-k] * (1 - h[j]) if j-k in [0,n)
    #
    # Let a = h[j+k] if j+k in [0,n) else 0  (this is the value that h[j] multiplies)
    # Let b = h[j-k] if j-k in [0,n) else 0  (this multiplies (1-h[j]))
    #
    # c_k(x) = [c_k - h[j]*(1-a) - b*(1-h[j])] + x*(1-a) + b*(1-x)
    #        = c_k - h[j]*(1-a) - b + b*h[j] + x - x*a + b - b*x
    #        = c_k - h[j] + h[j]*a - b + b*h[j] + x - a*x + b - b*x
    #        = c_k - h[j] + h[j]*a + b*h[j] + x*(1-a-b)

    # And B_k = c_k - h[j] + h[j]*a + b*h[j] = c_k + h[j]*(a + b - 1)
    
    # For the max: F(x) = max_k (A_k * x + B_k)
    # We want to find x in [0,1] that minimizes F(x)
    # (also need to maintain sum constraint, but let's handle that separately)
    
    # Compute A_k for all k:
    ks = np.arange(-(n-1), n)
    a_vals = np.zeros(2*n-1)
    b_vals = np.zeros(2*n-1)
    for idx, k in enumerate(ks):
        jk = j + k
        jmk = j - k
        a = h[jk] if 0 <= jk < n else 0.0
        b = h[jmk] if 0 <= jmk < n else 0.0
        a_vals[idx] = a
        b_vals[idx] = b
    
    A = 1.0 - a_vals - b_vals
    B = corr - h[j] + h[j] * (a_vals + b_vals)  # B_k = c_k + h[j]*(a+b-1)
    
    # Wait, let me recheck:
    # B_k = c_k - h[j] + h[j]*a + b*h[j] = c_k + h[j]*(a + b - 1)
    # Yes, that's correct.
    
    # Now minimize F(x) = max_k (A_k * x + B_k) over x in [0, 1]
    # F is convex (max of affine functions)
    # Use ternary search or bisection on the derivative
    
    def F(x):
        return (A * x + B).max()
    
    # The derivative (subgradient) at x is the max A_k among active constraints
    # F'(x) = max{k: A_k*x + B_k = F(x)} A_k
    
    # Bisection: find x where F' changes from negative to positive
    lo, hi = 0.0, 1.0
    for _ in range(50):
        mid = 0.5 * (lo + hi)
        F_mid = (A * mid + B).max()
        # Subgradient: max A_k among those achieving the max
        active = np.abs(A * mid + B - F_mid) < 1e-10
        if active.sum() == 0:
            sg = A.max()
        else:
            sg_max = A[active].max()
            sg_min = A[active].min()
        if sg_min > 0:
            hi = mid
        elif sg_max < 0:
            lo = mid
        else:
            break  # 0 is in the subgradient
    
    x_opt = 0.5 * (lo + hi)
    return x_opt, F(x_opt)
```

This is a clean coordinate descent step! The key insight is that for each coordinate, the objective is the max of affine functions (hence convex in 1D), and we can find the optimal value by bisection on the subgradient.

However, we also need to handle the sum constraint. One approach:
- Do coordinate descent without the sum constraint for a few sweeps
- Then project back to the feasible set
- Repeat

Or: incorporate the sum constraint by adding a penalty or by adjusting after each step.

Actually, a simpler approach: after updating h[j], adjust one other coordinate to maintain the sum. Or: do the coordinate descent with a Lagrange multiplier for the sum constraint.

Let me think about this differently. If I add a Lagrange multiplier λ for the constraint sum(h) = target, then the modified objective for coordinate j is:
F_λ(x) = max_k (A_k * x + B_k) + λ * (x - h[j])

The derivative is: max{k: active} A_k + λ

So the optimal x satisfies: max{k: active} A_k = -λ

This means for all active k, A_k ≤ -λ, and at least one has A_k = -λ.

This is still solvable by bisection, but we'd need to find λ too.

Alternatively, I can just do:
1. Coordinate descent (ignoring the sum constraint)
2. Project back to feasible set
3. Repeat

The projection is cheap (binary search for the threshold), so this should work fine.

This is a 1D feasibility problem that can be solved by:

```python
import numpy as np
from scipy.optimize import minimize
import time

def project_feasible(x, target):
    n = len(x)
    x = np.clip(x.astype(float), 0.0, 1.0)
    lo, hi = -5.0, 5.0
    for _ in range(60):
        mid = 0.5 * (lo + hi)
        s = np.clip(x - mid, 0.0, 1.0).sum()
        if s > target:
            lo = mid
        else:
            hi = mid
    return np.clip(x - 0.5 * (lo + hi), 0.0, 1.0)

def eval_c5(h):
    n = len(h)
    dx = 2.0 / n
    return (np.correlate(h, 1.0 - h, mode='full') * dx).max()

def coord_optimize(h, j):
    """Find optimal value for coordinate j, given all others fixed.
    Returns the optimal x in [0,1]."""
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, 'full') * dx  # shape (2n-1,)
    
    # For coordinate j, compute A_k and B_k for all k
    # c_k(x) = A_k * x + B_k
    ks = np.arange(-(n-1), n)  # shape (2n-1,)
    
    # a[k] = h[j+k] if valid, else 0
    # b[k] = h[j-k] if valid, else 0
    jk = j + ks  # indices for h[j+k]
    jmk = j - ks  # indices for h[j-k]
    
    a_vals = np.zeros(2*n-1)
    b_vals = np.zeros(2*n-1)
    valid_a = (jk >= 0) & (jk < n)
    valid_b = (jmk >= 0) & (jmk < n)
    a_vals[valid_a] = h[jk[valid_a]]
    b_vals[valid_b] = h[jmk[valid_b]]
    
    A = 1.0 - a_vals - b_vals
    B = corr + h[j] * (a_vals + b_vals - 1.0)
    
    # Minimize F(x) = max_k (A_k * x + B_k) over x in [0, 1]
    # Bisection on subgradient
    
    def F_and_sg(x):
        vals = A * x + B
        F = vals.max()
        # Subgradient: range of A_k among active constraints
        tol = 1e-12
        active = vals >= F - tol
        if active.any():
            sg_lo = A[active].min()
            sg_hi = A[active].max()
        else:
            sg_lo = sg_hi = A.max()
        return F, sg_lo, sg_hi
    
    lo, hi = 0.0, 1.0
    for _ in range(40):
        mid = 0.5 * (lo + hi)
        F_mid, sg_lo, sg_hi = F_and_sg(mid)
        if sg_lo > 1e-14:
            hi = mid
        elif sg_hi < -1e-14:
            lo = mid
        else:
            break
    
    x_opt = 0.5 * (lo + hi)
    return x_opt

def coord_descent(h, max_sweeps=200, tol=1e-10, time_limit=60):
    """Coordinate descent for the C5 minimization."""
    n = len(h)
    target = n / 2.0
    h = project_feasible(h.copy(), target)
    best = h.copy()
    best_c5 = eval_c5(best)
    t0 = time.time()
    
    for sweep in range(max_sweeps):
        if time.time() - t0 > time_limit:
            break
        max_change = 0.0
        for j in range(n):
            x_opt = coord_optimize(h, j)
            change = abs(x_opt - h[j])
            max_change = max(max_change, change)
            h[j] = x_opt
        h = project_feasible(h, target)
        c5 = eval_c5(h)
        if c5 < best_c5:
            best_c5 = c5
            best = h.copy()
        if max_change < tol:
            break
    
    return best, best_c5

def lse_smoothed_optimize(h0, max_time=60, tau_start=5.0, tau_end=100.0, n_steps=5):
    """Optimize using log-sum-exp smoothed objective with L-BFGS-B."""
    n = len(h0)
    dx = 2.0 / n
    target = n / 2.0
    h = project_feasible(h0.copy(), target)
    best = h.copy()
    best_c5 = eval_c5(best)
    t0 = time.time()
    
    taus = np.geomspace(tau_start, tau_end, n_steps)
    for tau in taus:
        if time.time() - t0 > max_time * 0.9:
            break
        
        def obj(x):
            x = np.clip(x, 0.0, 1.0)
            corr = np.correlate(x, 1.0 - x, 'full') * dx
            max_c = corr.max()
            lse = max_c + np.log(np.sum(np.exp(tau * (corr - max_c)))) / tau
            viol = x.sum() - target
            return lse + 100.0 * viol * viol
        
        def grad(x):
            x = np.clip(x, 0.0, 1.0)
            corr = np.correlate(x, 1.0 - x, 'full') * dx
            max_c = corr.max()
            exp_c = np.exp(tau * (corr - max_c))
            w = exp_c / exp_c.sum()
            
            # Gradient of the LSE part
            j = np.arange(n)
            g = np.ones(n)  # from the "1" in derivative of c_k
            for ki in range(2*n-1):
                if w[ki] < 1e-10:
                    continue
                k = ki - (n-1)
                wi = w[ki]
                if k >= 0:
                    g[:n-k] -= wi * x[k:]
                    g[k:] -= wi * x[:n-k]
                else:
                    kk = -k
                    g[kk:] -= wi * x[:n-kk]
                    g[:n-kk] -= wi * x[kk:]
            
            # Gradient of constraint penalty
            viol = x.sum() - target
            g += 200.0 * viol
            
            return g
        
        try:
            result = minimize(obj, h, jac=grad, method='L-BFGS-B',
                            bounds=[(0.0, 1.0)] * n,
                            options={'maxiter': 5000, 'ftol': 1e-15, 'gtol': 1e-10})
            h_new = project_feasible(result.x, target)
            c5_new = eval_c5(h_new)
            if c5_new < best_c5:
                best_c5 = c5_new
                best = h_new.copy()
                h = h_new.copy()
        except Exception:
            pass
    
    return best, best_c5

def subgrad_optimize(h0, max_time=30, lr_init=0.1, n_iter=200000):
    """Subgradient method for the max objective."""
    n = len(h0)
    dx = 2.0 / n
    target = n / 2.0
    h = project_feasible(h0.copy(), target)
    best = h.copy()
    best_c5 = eval_c5(h)
    t0 = time.time()
    j = np.arange(n)
    lr = lr_init
    
    for it in range(n_iter):
        if time.time() - t0 > max_time:
            break
        corr = np.correlate(h, 1.0 - h, 'full') * dx
        ki = np.argmax(corr)
        k = ki - (n - 1)
        
        # Subgradient: gradient of c_k at h
        g = np.zeros(n)
        if k >= 0:
            g[:n-k] += (1.0 - h[k:])
            g[k:] -= h[:n-k]
        else:
            kk = -k
            g[kk:] += (1.0 - h[:n-kk])
            g[:n-kk] -= h[kk:]
        g *= dx
        
        h = project_feasible(h - lr * g, target)
        c5 = eval_c5(h)
        if c5 < best_c5:
            best_c5 = c5
            best = h.copy()
        
        lr *= 0.99995
        if lr < 1e-8:
            break
    
    return best, best_c5

def resample_h(h_src, n_dst):
    n_src = len(h_src)
    if n_src == n_dst:
        return h_src.astype(float).copy()
    xs = np.arange(n_src, dtype=float)
    xd = np.linspace(0.0, float(n_src), n_dst, endpoint=False)
    h_new = np.interp(xd, xs, h_src)
    return project_feasible(np.clip(h_new, 0.0, 1.0), n_dst / 2.0)
```

```python
def coord_optimize_fast(h, j, corr):
    """Fast coordinate optimization using precomputed correlation."""
    n = len(h)
    dx = 2.0 / n
    
    ks = np.arange(-(n-1), n)
    jk = j + ks
    jmk = j - ks
    
    a_vals = np.zeros(2*n-1)
    b_vals = np.zeros(2*n-1)
    valid_a = (jk >= 0) & (jk < n)
    valid_b = (jmk >= 0) & (jmk < n)
    a_vals[valid_a] = h[jk[valid_a]]
    b_vals[valid_b] = h[jmk[valid_b]]
    
    # For k ≠ 0 (all except center index n-1):
    # c_k(x) = A_k * x + B_k where A_k = 1-a_k-b_k, B_k = c_k + h[j]*(a_k+b_k-1)
    center = n - 1
    A = 1.0 - a_vals - b_vals
    B = corr + h[j] * (a_vals + b_vals - 1.0)
    
    # For k = 0 (center): c_0(x) = corr[center] - h[j]*(1-h[j]) + x*(1-x)
    c0_const = corr[center] - h[j] * (1.0 - h[j])
    # c_0(x) = c0_const + x - x^2
    
    # Evaluate F(x) = max(max_{k≠0}(A_k*x + B_k), c0_const + x - x^2)
    # Use grid + refinement
    
    grid = np.linspace(0.0, 1.0, 51)
    F_vals = np.zeros(51)
    for i, x in enumerate(grid):
        F_vals[i] = max((A * x + B).max(), c0_const + x - x*x)
    
    i_min = np.argmin(F_vals)
    
    # Refine around the grid minimum
    if i_min == 0:
        lo, hi = 0.0, grid[1]
    elif i_min == 50:
        lo, hi = grid[49], 1.0
    else:
        lo, hi = grid[i_min-1], grid[i_min+1]
    
    # Bisection/ternary for refinement
    best_x = 0.5 * (lo + hi)
    best_F = F_vals[i_min]
    
    for _ in range(30):
        m1 = lo + (hi - lo) / 3.0
        m2 = hi - (hi - lo) / 3.0
        F1 = max((A * m1 + B).max(), c0_const + m1 - m1*m1)
```

```python
    dx = 2.0 / n
    center = n - 1
    ks = np.arange(-(n - 1), n)
    jk = j + ks
    jmk = j - ks
    a_vals = np.zeros(2 * n - 1)
    b_vals = np.zeros(2 * n - 1)
    va = (jk >= 0) & (jk < n)
    vb = (jmk >= 0) & (jmk < n)
    a_vals[va] = h[jk[va]]
    b_vals[vb] = h[jmk[vb]]
    A = 1.0 - a_vals - b_vals
    B = corr + h[j] * (a_vals + b_vals - 1.0)
    c0_const = corr[center] - h[j] * (1.0 - h[j])
    grid = np.linspace(0.0, 1.0, 101)
    F_vals = np.empty(101)
    for i in range(101):
        x = grid[i]
        F_vals[i] = max((A * x + B).max(), c0_const + x - x * x)
    i_min = np.argmin(F_vals)
    if i_min == 0:
        lo, hi = 0.0, grid[1]
    elif i_min == 100:
        lo, hi = grid[99], 1.0
    else:
        lo, hi = grid[i_min - 1], grid[i_min + 1]
    best_x = 0.5 * (lo + hi)
    best_F = F_vals[i_min]
    for _ in range(25):
        m1 = lo + (hi - lo) / 3.0
        m2 = hi - (hi - lo) / 3.0
        F1 = max((A * m1 + B).max(), c0_const + m1 - m1 * m1)
        F2 = max((A * m2 + B).max(), c0_const + m2 - m2 * m2)
        if F1 < F2:
            hi = m2
        else:
            lo = m1
        mx = 0.5 * (lo + hi)
        Fm = max((A * mx + B).max(), c0_const + mx - mx * mx)
        if Fm < best_F:
            best_F = Fm
            best_x = mx
    return best_x

def coord_descent(h0, max_sweeps=500, time_limit=60):
    n = len(h0)
    target = n / 2.0
    h = project_feasible(h0.astype(float).copy(), target)
    corr = np.correlate(h, 1.0 - h, 'full') * (2.0 / n)
    best = h.copy()
    best_c5 = corr.max()
    t0 = time.time()
    for sweep in range(max_sweeps):
        if time.time() - t0 > time_limit:
            break
        max_change = 0.0
        for j in range(n):
            x_opt = coord_optimize_fast(h, j, corr)
            delta = x_opt - h[j]
            if abs(delta) > 1e-13:
                max_change = max(max_change, abs(delta))
                h[j] = x_opt
        corr = np.correlate(h, 1.0 - h, 'full') * (2.0 / n)
        h = project_feasible(h, target)
        corr = np.correlate(h, 1.0 - h, 'full') * (2.0 / n)
        c5 = corr.max()
        if c5 < best_c5 - 1e-14:
            best_c5 = c5
            best = h.copy()
        if max_change < 1e-12:
            break
    return best, best_c5

def lse_optimize(h0, max_time=60, tau_seq=None):
    n = len(h0)
    dx = 2.0 / n
    target = n / 2.0
    h = project_feasible(h0.astype(float).copy(), target)
    best = h.copy()
    best_c5 = eval_c5(best)
    t0 = time.time()
    if tau_seq is None:
        tau_seq = [5.0, 15.0, 40.0, 100.0, 200.0]
    for tau in tau_seq:
        if time.time() - t0 > max_time * 0.92:
            break
        def obj(x):
            x = np.clip(x, 0.0, 1.0)
            c = np.correlate(x, 1.0 - x, 'full') * dx
            mc = c.max()
            lse = mc + np.log(np.sum(np.exp(tau * (c - mc)))) / tau
            v = x.sum() - target
            return lse + 50.0 * v * v
        def grad(x):
            x = np.clip(x, 0.0, 1.0)
            c = np.correlate(x, 1.0 - x, 'full') * dx
            mc = c.max()
            ev = np.exp(tau * (c - mc))
            w = ev / ev.sum()
            g = np.ones(n)
            for ki in range(2 * n - 1):
                if w[ki] < 1e-12:
                    continue
                k = ki - (n - 1)
                wi = w[ki]
                if k >= 0:
                    g[:n - k] -= wi * x[k:]
                    g[k:] -= wi * x[:n - k]
                else:
                    kk = -k
                    g[kk:] -= wi * x[:n - kk]
                    g[:n - kk] -= wi * x[kk:]
            v = x.sum() - target
            g += 100.0 * v
            return g
        try:
            res = minimize(obj, h, jac=grad, method='L-BFGS-B',
                          bounds=[(0.0, 1.0)] * n,
                          options={'maxiter': 3000, 'ftol': 1e-16, 'gtol': 1e-12})
            h_new = project_feasible(res.x, target)
            c5_new = eval_c5(h_new)
            if c5_new < best_c5:
                best_c5 = c5_new
                best = h_new.copy()
                h = h_new.copy()
        except Exception:
            pass
    return best, best_c5

def subgrad_opt(h0, max_time=30, lr_init=0.05):
    n = len(h0)
    dx = 2.0 / n
    target = n / 2.0
    h = project_feasible(h0.astype(float).copy(), target)
    best = h.copy()
    best_c5 = eval_c5(h)
    t0 = time.time()
    lr = lr_init
    for it in range(300000):
        if time.time() - t0 > max_time:
            break
        corr = np.correlate(h, 1.0 - h, 'full') * dx
        ki = np.argmax(corr)
        k = ki - (n - 1)
        g = np.zeros(n)
        if k >= 0:
            g[:n - k] += (1.0 - h[k:])
            g[k:] -= h[:n - k]
        else:
            kk = -k
            g[kk:] += (1.0 - h[:n - kk])
            g[:n - kk] -= h[kk:]
        g *= dx
        h = project_feasible(h - lr * g, target)
        c5 = eval_c5(h)
        if c5 < best_c5:
            best_c5 = c5
            best = h.copy()
        lr *= 0.99997
        if lr < 1e-9:
            break
    return best, best_c5

def resample_h(h_src, n_dst):
    n_src = len(h_src)
    if n_src == n_dst:
        return h_src.astype(float).copy()
    xs = np.arange(n_src, dtype=float)
    xd = np.linspace(0.0, float(n_src), n_dst, endpoint=False)
    h_new = np.interp(xd, xs, h_src)
    return project_feasible(np.clip(h_new, 0.0, 1.0), n_dst / 2.0)

def run(seed=42, budget_s=1300, **kwargs):
    rng = np.random.RandomState(seed)
    t_start = time.time()

    try:
        h_init = np.array(initial_h_values, dtype=float)
    except Exception:
        h_init = np.full(200, 0.5)

    n = len(h_init)
    best = project_feasible(h_init, n / 2.0)
    best_c5 = eval_c5(best)

    def remaining(frac=0.95):
        return budget_s * frac - (time.time() - t_start)

    # Phase 1: Coordinate descent on initial solution
    if remaining(0.30) > 10:
        h1, c1 = coord_descent(best, max_sweeps=2000, time_limit=remaining(0.30))
        if c1 < best_c5:
            best, best_c5 = h1, c1

    # Phase 2: LSE smoothed optimization
    if remaining(0.45) > 15:
        h2, c2 = lse_optimize(best, max_time=min(120, remaining(0.45)))
        if c2 < best_c5:
            best, best_c5 = h2, c2

    # Phase 3: More coordinate descent after LSE
    if remaining(0.55) > 10:
        h3, c3 = coord_descent(best, max_sweeps=2000, time_limit=remaining(0.55))
        if c3 < best_c5:
            best, best_c5 = h3, c3

    # Phase 4: Multi-restart with perturbation + coordinate descent
    for attempt in range(15):
        if remaining(0.75) < 8:
            break
        scale = 0.03 + 0.02 * rng.random()
        h_pert = best + rng.normal(0, scale, size=n)
        h_pert = project_feasible(h_pert, n / 2.0)
        h4, c4 = coord_descent(h_pert, max_sweeps=500, time_limit=min(20, remaining(0.75) * 0.4))
        if c4 < best_c5:
            best, best_c5 = h4, c4
        if remaining(0.75) > 5:
            h4b, c4b = coord_descent(best, max_sweeps=300, time_limit=min(15, remaining(0.75) * 0.3))
            if c4b < best_c5:
                best, best_c5 = h4b, c4b

    # Phase 5: Try different resolutions
    n_targets = [400, 300, 500, 250, 600]
    for n_t in n_targets:
        if remaining(0.90) < 25:
            break
        h_res = resample_h(best, n_t)
        h5, c5v = coord_descent(h_res, max_sweeps=500, time_limit=min(60, remaining(0.90) * 0.4))
        if c5v < best_c5:
            best, best_c5 = h5, c5v
        if remaining(0.90) > 15:
            h5b, c5b = lse_optimize(best, max_time=min(40, remaining(0.90) * 0.3), tau_seq=[10, 50, 150])
            if c5b < best_c5:
                best, best_c5 = h5b, c5b
        if remaining(0.90) > 10:
            h5c, c5c = coord_descent(best, max_sweeps=500, time_limit=min(30, remaining(0.90) * 0.3))
            if c5c < best_c5:
                best, best_c5 = h5c, c5c

    # Phase 6: Final intensive polish
    n_best = len(best)
    if remaining(0.97) > 30:
        h6, c6 = coord_descent(best, max_sweeps=5000, time_limit=min(200, remaining(0.97)))
        if c6 < best_c5:
            best, best_c5 = h6, c5c if c6 < c5c else c6
            best_c5 = c6

    if remaining(0.98) > 15:
        h6b, c6b = lse_optimize(best, max_time=min(60, remaining(0.98)), tau_seq=[50, 150, 500])
        if c6b < best_c5:
            best, best_c5 = h6b, c6b

    if remaining(0.99) > 10:
        h6c, c6c = coord_descent(best, max_sweeps=3000, time_limit=remaining(0.99))
        if c6c < best_c5:
            best, best_c5 = h6c, c6c

    final_c5 = eval_c5(best)
    return best, final_c5, len(best)
```
