- If j appears as h[i] in corr[p] (condition (b)): corr[p] changes by h[i+lag] * (1-h_j') - h[i+lag] * (1-h_j) = h[i+lag] * (h_j - h_j')

So the new corr[p] = corr_old[p] + delta_a[p] + delta_b[p] where:
delta_a[p] = (h_j' - h_j) * (1-h[j-lag]) if condition (a) is satisfied, else 0
delta_b[p] = h[j+lag] * (h_j - h_j') if condition (b) is satisfied, else 0

Both are linear in h_j'! So the new corr[p] is linear in h_j'.

For the 1D optimization, I need to find h_j' ∈ [0,1] that minimizes max_p (corr_old[p] + delta_a[p](h_j') + delta_b[p](h_j')).

Since each term is linear in h_j', the max is convex and piecewise linear. I'll use a simple approach:
- Evaluate at h_j' = 0 and h_j' = 1
- Check if the current h_j is optimal (i.e., the subgradient contains 0)
- If not, do bisection or just use the endpoints

For the subgradient check: the subgradient of f(t) = max_p (a_p + b_p * t) at t* is the convex hull of {b_p : f(t*) = a_p + b_p * t*} (the set of active lines). 0 is in this subgradient iff there exist active lines with both positive and negative slopes (or an active line with slope 0).

In practice, I'll just evaluate f at h_j=0, h_j=1, and the current h_j, and pick the best. This is a 3-point evaluation that's exactly correct if the minimum is at a boundary, and approximately correct if it's interior (but for piecewise linear, the minimum is at a breakpoint or boundary, so this might miss interior breakpoints).

A better approach: evaluate at a grid of, say, 20 points in [0,1], pick the best, then refine. Or just use the full ternary search since each evaluation is O(n) and we do O(log(1/ε)) iterations.

For the implementation, I'll do:
1. For each coordinate j, compute the affected indices and the coefficients (slope and intercept for each affected correlation as a function of h_j)
2. Do ternary search (or golden section) on [0,1] using 20-30 iterations
3. Each iteration evaluates the max over all 2n-1 correlations (the unaffected ones are just corr_old, the affected ones are linear in h_j)

This gives O(n * 30) per coordinate, O(30n²) per pass. For n=663, that's about 13M ops per pass, which in numpy should take about 0.1-0.5 seconds.

    c_max = np.max(corr)
    shifted = alpha * (corr - c_max)
    shifted = np.clip(shifted, -500.0, 0.0)
    return float(c_max + np.log(np.sum(np.exp(shifted))) / alpha)

    target_sum = n / 2.0

    lag = np.arange(2*n-1) - (n-1)
    
    for j in range(n):

        i_a = j - lag
        cond_a = (i_a >= 0) & (i_a < n)

            continue

        slope = np.zeros(len(affected_idx))
        intercept = corr[affected_idx].copy()
        
        ca = cond_a[affected_idx]
        cb = cond_b[affected_idx]
        ia_aff = i_a[affected_idx]
        il_aff = (j + lag[affected_idx]).astype(int)
        
        if np.any(ca):
            slope[ca] += (1.0 - h[ia_aff[ca]])
            intercept[ca] -= h[j] * (1.0 - h[ia_aff[ca]])
        
        if np.any(cb):
            slope[cb] += -h[il_aff[cb]]
            intercept[cb] += h[j] * h[il_aff[cb]]

        a, b = 0.0, 1.0
        for _ in range(n_iters):
            m1 = a + (b-a)/3.0
            m2 = b - (b-a)/3.0

            f2 = max(base_max, np.max(intercept + slope * m2))
            if f1 <= f2:

            else:
                a = m1

                val += h[il] * (h[j] - new_hj)
            corr[p] = val
