For a fixed "direction" (say, we fix all h[j] for j ≠ j*), the subproblem for h[j*] is:
minimize max_k (a_k * h[j*] + b_k)
subject to 0 ≤ h[j*] ≤ 1

This is exactly what we're already doing. The LP would be:
minimize t
subject to a_k * h[j*] + b_k ≤ t for all k
           0 ≤ h[j*] ≤ 1

This has the same solution as the max-of-linears minimization. So no gain there.

**Alternative: Semidefinite programming relaxation**

Not practical for n=350.

**Alternative: Benders decomposition**

Add cutting planes to approximate the max. Each iteration:
1. Fix h, identify k* that achieves the max
2. Add constraint c[k*] ≤ t
3. Solve the resulting (non-convex) problem

This doesn't really help for the non-convex part.

**Alternative: Mirror descent / FTRL with the max loss**

The objective is a max of smooth (bilinear) functions. We can use mirror descent with the negative entropy regularization:
h^{new} = exp(η * h^old - η * ∇f(h^old)) / Z

But the gradient of the max is the gradient of the active component, which is:
∇f(h) = ∇c[k*(h)] = ... (gradient of the correlation at the active shift)

For shift k*, the gradient of c[k*] = ∑_i h[i+k*]*(1-h[i]) is:
[∂c[k*]/∂h[j]] = [1-h[j-k*]] * [0≤j-k*<n] - h[j+k*] * [0≤j+k*<n]

This is the same slope we computed before! So mirror descent would be:
h[j] ← h[j] * exp(-η * slope[j])

But this doesn't respect the sum constraint directly. We'd need to project.

For a "random" binary solution with n/2 ones, E[c[k]] ≈ (n-|k|)/4 for |k| ≤ n.

For the fractional case, we have more freedom. The optimal fractional solution could achieve a lower C₅ than the best binary solution.

I suspect the optimal solution is mostly binary (0 or 1) with a few fractional values at the "boundaries" where the constraint is active.

Actually, here's another idea: **alternating projections**. 
1. Project onto {h: max_k c[k] ≤ t} (for a given t)
2. Project onto {h: sum(h) = target, 0 ≤ h ≤ 1}
3. Iterate

This is like Dykstra's algorithm for feasibility. If we can find a feasible h for a given t, we binary search on t to find the minimum.

The projection onto {h: max_k c[k] ≤ t} is the hard part. But for a given t, checking feasibility is:
Does there exist h ∈ [0,1]^n with sum(h) = n/2 and c[k] ≤ t for all k?

This is a non-convex feasibility problem (because c[k] is bilinear). So alternating projections won't directly work.

However, if we linearize c[k] around the current h, we can solve an LP:
minimize 0
subject to ∑_i (h[i+k]_old*(1-h[i]) + h[i+k]*(1-h[i]_old)) / 2 ≤ t for all k
           0 ≤ h[i] ≤ 1
           sum(h) = n/2

Wait, that's not a valid linearization. The correct first-order approximation of h[i+k]*(1-h[i]) at h_old is:
h_old[i+k]*(1-h_old[i]) + (1-h_old[i])*(h[i+k]-h_old[i+k]) - h_old[i+k]*(h[i]-h_old[i])
= h_old[i+k]*(1-h_old[i]) + (1-h_old[i])*Δh[i+k] - h_old[i+k]*Δh[i]

This IS linear in Δh! So we can use this as a cutting plane.

Algorithm:
1. Start with h_0
2. Linearize the objective at h_0
3. Solve the LP: min t s.t. linearized c[k] ≤ t, 0≤h≤1, sum(h)=n/2
4. Update h_1 = argmin of the LP
5. Repeat

This is essentially the **cutting plane method** applied to the non-convex problem. It's not guaranteed to converge to a global optimum, but it might do better than coordinate descent.

However, solving an LP with 2n-1 + 2n + 1 = 4n-1 constraints and n+1 variables for n=350 is a 351-variable LP with ~1400 constraints. This is very solvable with scipy or cvxpy in a fraction of a second.

```python
import numpy as np
from scipy.optimize import minimize, linprog
import time

def evaluate_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)

def repair_h(h, n):
    h = np.clip(h, 0.0, 1.0).copy()
    target = n / 2.0
    for _ in range(50):
        diff = target - np.sum(h)
        if abs(diff) < 1e-13:
            break
        if diff > 0:
            mask = h < 1.0
            if mask.sum() == 0:
                break
            h[mask] = np.minimum(1.0, h[mask] + diff / mask.sum())
        else:
            mask = h > 0.0
            if mask.sum() == 0:
                break
            h[mask] = np.maximum(0.0, h[mask] + diff / mask.sum())
    return h

def compute_slope_mat(h, n):
    """Compute the (2n-1, n) matrix of partial derivatives."""
    s = np.arange(-(n-1), n)
    slope_mat = np.zeros((2*n-1, n))
    for j in range(n):
        valid_a = (j - s >= 0) & (j - s < n)
        valid_b = (j + s >= 0) & (j + s < n)
        slope_mat[valid_a, j] += (1.0 - h[j - s[valid_a]])
        slope_mat[valid_b, j] += (-h[j + s[valid_b]])
    return slope_mat

def coord_descend(h, n, max_sweeps=300, grid_size=51, refine_size=21):
    h = h.copy().astype(float)
    target = n / 2.0
    s = np.arange(-(n-1), n)
    
    for sweep in range(max_sweeps):
        c = np.correlate(h, 1.0 - h, mode="full").astype(float)
        max_before = float(np.max(c))
        
        for j in range(n):
            valid_a = (j - s >= 0) & (j - s < n)
            valid_b = (j + s >= 0) & (j + s < n)
            
            slope = np.zeros(2*n-1)
            slope[valid_a] += (1.0 - h[j - s[valid_a]])
            slope[valid_b] += (-h[j + s[valid_b]])
            
            hj = h[j]
            ts = np.linspace(0.0, 1.0, grid_size)
            diffs = (ts - hj).reshape(-1, 1)
            vals = c.reshape(1, -1) + slope.reshape(1, -1) * diffs
            maxes = np.max(vals, axis=1)
            best_idx = int(np.argmin(maxes))
            best_t = float(ts[best_idx])
            
            if 0 < best_idx < grid_size - 1:
                lo = ts[best_idx - 1]
                hi = ts[best_idx + 1]
                ts_ref = np.linspace(lo, hi, refine_size)
                diffs_ref = (ts_ref - hj).reshape(-1, 1)
                vals_ref = c.reshape(1, -1) + slope.reshape(1, -1) * diffs_ref
                maxes_ref = np.max(vals_ref, axis=1)
                best_t = float(ts_ref[np.argmin(maxes_ref)])
            
            if abs(best_t - hj) > 1e-12:
                delta = best_t - hj
                h[j] = best_t
                c += slope * delta
        
        h = repair_h(h, n)
        c_new = np.correlate(h, 1.0 - h, mode="full")
        max_after = float(np.max(c_new))
        
        if max_before - max_after < 1e-14:
            break
    
    return h

def lp_refine(h, n, max_iters=30):
    """Linearized LP refinement."""
    from scipy.optimize import linprog
    h = h.copy().astype(float)
    target = n / 2.0
    
    for it in range(max_iters):
        c = np.correlate(h, 1.0 - h, mode="full")
        c5_curr = float(np.max(c))
        
        slope_mat = compute_slope_mat(h, n)
        
        # b_ub[k] = -c[k] + slope_mat[k,:] @ h
        b_ub = -c + slope_mat @ h
        
        # A_ub: (2n-1) x (n+1)
        A_ub = np.zeros((2*n-1, n+1))
        A_ub[:, :n] = slope_mat
        A_ub[:, n] = -1.0
        
        # Beq: sum(h) = target
        Beq = np.zeros((1, n+1))
        Beq[0, :n] = 1.0
        beq = np.array([target])
        
        # Bounds
        bounds = [(0, 1)] * n + [(0, None)]
        
        # Objective: minimize t
        c_obj = np.zeros(n+1)
        c_obj[n] = 1.0
        
        try:
            result = linprog(c_obj, A_ub=A_ub, b_ub=b_ub, Beq=Beq, beq=beq,
                            bounds=bounds, method='highs',
                            options={'presolve': True, 'time_limit': 10})
        except Exception:
            break
        
        if result.status == 0:
            h_new = np.clip(result.x[:n], 0, 1)
            h_new = repair_h(h_new, n)
            if evaluate_c5(h_new) <= c5_curr + 1e-10:
                h = h_new
            else:
                break
        elif result.status == 2:  # infeasible
            break
        else:
            break
    
    return h

def run(seed=42, budget_s=1300, **kwargs):
    np.random.seed(seed)
    rng = np.random.RandomState(seed)
    t0 = time.time()
    
    def remaining():
        return budget_s - (time.time() - t0)
    
    h_init = np.asarray(initial_h_values, dtype=float).copy()
    n_init = len(h_init)
    best_h = h_init.copy()
    best_c5 = evaluate_c5(best_h)
    
    # Phase 1: Coordinate descent
    h_cd = coord_descend(best_h, n_init, max_sweeps=200)
    c5_cd = evaluate_c5(h_cd)
    if c5_cd < best_c5:
        best_h, best_c5 = h_cd, c5_cd
    
    # Phase 2: LP refinement
    if remaining() > 100:
        h_lp = lp_refine(best_h, len(best_h), max_iters=20)
        c5_lp = evaluate_c5(h_lp)
        if c5_lp < best_c5:
            best_h, best_c5 = h_lp, c5_lp
        # Follow with coord descent
        h_lp2 = coord_descend(h_lp, len(h_lp), max_sweeps=100)
        c5_lp2 = evaluate_c5(h_lp2)
        if c5_lp2 < best_c5:
            best_h, best_c5 = h_lp2, c5_lp2
    
    # Phase 3: Try different n values
    n_candidates = [n for n in [280, 300, 320, 350, 380, 400, 420, 450, 500, 550, 600]
                    if n % 2 == 0 and n != n_init]
    
    for n in n_candidates:
        if remaining() < 80:
            break
        
        h_interp = np.interp(np.linspace(0, 2, n), np.linspace(0, 2, len(best_h)), best_h)
        h_interp = repair_h(h_interp, n)
        
        h_opt = coord_descend(h_interp, n, max_sweeps=150)
        c5_opt = evaluate_c5(h_opt)
        if c5_opt < best_c5:
            best_h, best_c5 = h_opt, c5_opt
        
        if remaining() > 100:
            h_bin = np.zeros(n)
            h_bin[::2] = 1.0
```

```python
import numpy as np
from scipy.optimize import minimize, linprog
import time

def evaluate_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)

def repair_h(h, n):
    h = np.clip(h, 0.0, 1.0).copy()
    target = n / 2.0
    for _ in range(100):
        diff = target - np.sum(h)
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            mask = h < 1.0
            if mask.sum() == 0:
                break
            h[mask] = np.minimum(1.0, h[mask] + diff / mask.sum())
        else:
            mask = h > 0.0
            if mask.sum() == 0:
                break
            h[mask] = np.maximum(0.0, h[mask] + diff / mask.sum())
    return h

def compute_slope_vec(h, j, n, s):
    valid_a = (j - s >= 0) & (j - s < n)
    valid_b = (j + s >= 0) & (j + s < n)
    slope = np.zeros(2 * n - 1)
    slope[valid_a] += (1.0 - h[j - s[valid_a]])
    slope[valid_b] += (-h[j + s[valid_b]])
    return slope

def coord_descend(h, n, max_sweeps=300, grid_size=51, refine_size=21):
    h = h.copy().astype(float)
    s = np.arange(-(n - 1), n)
    for sweep in range(max_sweeps):
        c = np.correlate(h, 1.0 - h, mode="full").astype(float)
        max_before = float(np.max(c))
        for j in range(n):
            slope = compute_slope_vec(h, j, n, s)
            hj = h[j]
            ts = np.linspace(0.0, 1.0, grid_size)
            diffs = (ts - hj).reshape(-1, 1)
            vals = c.reshape(1, -1) + slope.reshape(1, -1) * diffs
            maxes = np.max(vals, axis=1)
            best_idx = int(np.argmin(maxes))
            best_t = float(ts[best_idx])
            if 0 < best_idx < grid_size - 1:
                lo_t = ts[best_idx - 1]
                hi_t = ts[best_idx + 1]
                ts_ref = np.linspace(lo_t, hi_t, refine_size)
                diffs_ref = (ts_ref - hj).reshape(-1, 1)
                vals_ref = c.reshape(1, -1) + slope.reshape(1, -1) * diffs_ref
                maxes_ref = np.max(vals_ref, axis=1)
                best_t = float(ts_ref[np.argmin(maxes_ref)])
            if abs(best_t - hj) > 1e-13:
                delta = best_t - hj
                h[j] = best_t
                c += slope * delta
        h = repair_h(h, n)
        c_new = np.correlate(h, 1.0 - h, mode="full")
        max_after = float(np.max(c_new))
        if max_before - max_after < 1e-14:
            break
    return h

def lp_refine(h, n, max_iters=25):
    h = h.copy().astype(float)
    target = n / 2.0
    s = np.arange(-(n - 1), n)
    for it in range(max_iters):
        c = np.correlate(h, 1.0 - h, mode="full").astype(float)
        c5_curr = float(np.max(c))
        slope_mat = np.zeros((2 * n - 1, n))
        for j in range(n):
            slope_mat[:, j] = compute_slope_vec(h, j, n, s)
        b_ub = -c + slope_mat @ h
        A_ub = np.zeros((2 * n - 1, n + 1))
        A_ub[:, :n] = slope_mat
        A_ub[:, n] = -1.0
        Beq = np.zeros((1, n + 1))
        Beq[0, :n] = 1.0
        beq = np.array([target])
        bounds = [(0, 1)] * n + [(0, None)]
        c_obj = np.zeros(n + 1)
        c_obj[n] = 1.0
        try:
            result = linprog(c_obj, A_ub=A_ub, b_ub=b_ub, Beq=Beq, beq=beq,
                            bounds=bounds, method='highs',
                            options={'presolve': True, 'time_limit': 15})
        except Exception:
            break
        if result.status == 0:
            h_new = np.clip(result.x[:n], 0.0, 1.0)
            h_new = repair_h(h_new, n)
            if evaluate_c5(h_new) <= c5_curr + 1e-10:
                h = h_new
            else:
                break
        else:
            break
    return h

    target = int(n // 2)
    idx = np.argsort(h)[::-1]
    h_bin = np.zeros(n)
    h_bin[idx[:target]] = 1.0
    return h_bin
```
