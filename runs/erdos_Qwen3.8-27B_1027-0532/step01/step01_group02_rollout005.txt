- The optimal h[j] given all others can be found by solving a 1D problem

For a fixed coordinate j, with all other coordinates fixed, the objective is:
max_k [f_k + (v - h[j]) * g_k]

where v is the new value of h[j], f_k is the current value of lag k, and g_k is the coefficient of h[j] in lag k.

This is the max of linear functions of v, which is a convex piecewise-linear function. The minimum is at a point where two (or more) of the linear functions intersect.

So the optimal v is at one of the intersection points of the lines f_k + (v-h[j])*g_k.

The number of such intersection points is O(n^2) in the worst case, but in practice, only the "active" lags (those near the maximum) matter.

So the algorithm for one coordinate update is:
1. Compute g_k for all k
2. Consider only the lags that are near the current maximum (say within 0.01 of the max)
3. For each pair of active lags (k1, k2), find the intersection point v* = (f_k2 - f_k1) / (g_k1 - g_k2)
4. Check all candidate v* values (and the boundaries 0, 1)
5. Pick the one that minimizes the max

This is O(m^2) where m is the number of active lags, which should be small.

def project_onto_constraint(h, n, tol=1e-10):
    """Project h onto {0<=h_i<=1, sum(h)=n/2}"""
    target = n / 2.0
    # Bisection on the Lagrange multiplier lambda
    # h_i = clip(h_i - lambda, 0, 1)
    # Find lambda such that sum(h_i) = target
    
    lo, hi = h.min() - target, h.max()  # rough bounds
    # Actually: if lambda is very negative, all h_i = 1, sum = n
    # if lambda is very positive, all h_i = 0, sum = 0
    lo, hi = -target - 1, target + 1  # safe bounds
    
    for _ in range(100):
        mid = (lo + hi) / 2
        h_proj = np.clip(h - mid, 0, 1)
        s = np.sum(h_proj)
        if s > target:
            lo = mid
        else:
            hi = mid
        if abs(s - target) < tol:
            break
    
    return h_proj

def subgradient_step(h, n, step_size, k_active):
    """Take a subgradient step focusing on active lags."""
    dx = 2.0 / n
    # Compute gradient of f_k at the active lags
    # f_k(h) = ∫h(x)(1-h(x+k))dx
    # df_k/dh[j] = dx * [(1-h[j+k-offset]) - h[j-k+offset]] for valid indices
    # where offset = n-1 (for the full correlation indexing)
    
    grad = np.zeros(n)
    for k in k_active:
        shift = k - (n - 1)
        weight = 1.0 / len(k_active)  # equal weight for active lags
        for j in range(n):
            g = 1.0
            if 0 <= j + shift < n:
                g -= h[j + shift]
            if 0 <= j - shift < n:
                g -= h[j - shift]
            grad[j] += weight * g
    
    # Take a step in the negative gradient direction (minimizing the max)
    h_new = h - step_size * grad * dx
    h_new = project_onto_constraint(h_new, n)
    return h_new
