def project_onto_constraint(h, target_sum):
    """Project h onto {0 <= x <= 1, sum(x) = target_sum} using bisection."""
    h = np.asarray(h, dtype=np.float64).copy()
    # We need to find tau such that sum(clip(h - tau, 0, 1)) = target_sum
    lo, hi = -1.0, 2.0
    for _ in range(100):
        mid = (lo + hi) / 2
        projected = np.clip(h - mid, 0.0, 1.0)
        s = np.sum(projected)
        if s > target_sum:
            lo = mid
        else:
            hi = mid
    return np.clip(h - (lo + hi) / 2, 0.0, 1.0)

Let me also add a **coordinate descent** phase that's very cheap per iteration:

For each coordinate j, the effect on each autocorr is:
ac_m changes by: h[j-s_m] * delta + h[j+s_m] * delta (approximately, where delta is the change in h[j])

So if we change h[j] by delta:
Δac_m ≈ (h[j-s_m] + h[j+s_m]) * delta

The new softmin would be approximately:
new_softmin ≈ old_softmin + delta * sum_m w_m * (h[j-s_m] + h[j+s_m])

This is linear in delta, so the optimal delta (ignoring the nonlinearity and constraints) is:
- If the coefficient is positive, increase h[j] (delta > 0)
- If negative, decrease h[j] (delta < 0)
- The maximum delta is limited by h[j] reaching 0 or 1

But we also need to maintain the sum constraint. If we increase h[j], we need to decrease some other h[k].

This suggests an **exchange-based** coordinate descent:
1. Find the coordinate j that would most benefit from increasing
2. Find the coordinate k that would least hurt from decreasing
3. Exchange: h[j] += delta, h[k] -= delta

This is similar to the "Hungarian algorithm" approach for assignment problems.

Let me implement something like this:

```python
def coordinate_exchange(h, beta, n_iter=100):
    """Exchange-based coordinate descent."""
    n = len(h)
    target = n * 0.5
    h = h.copy()
    
    for _ in range(n_iter):
        # Compute gradient (direction of improvement for each coordinate)
        grad = softmin_gradient(h, beta, top_k=50)
        
        # Find best pair to exchange
        # Increasing h[j] by delta and decreasing h[k] by delta:
        # Change in softmin ≈ delta * (grad[j] - grad[k])
        # Best: maximize grad[j] - grad[k] subject to h[j] < 1 and h[k] > 0
        # Also: must maintain sum constraint (we're doing equal exchange)
        
        # Simple heuristic: find j with highest grad and k with lowest grad
        # But respect bounds
        j = np.argmax(grad * (1 - h + 1e-10))  # prefer large grad and room to increase
        k = np.argmin(grad * (h - 1e-10))  # prefer small grad and room to decrease
        
        # Actually, let's be simpler:
        # Best increase: j = argmax grad among h[j] < 1
        # Best decrease: k = argmin grad among h[k] > 0
        can_incr = h < 1.0 - 1e-10
        can_decr = h > 1e-10
        
        if not np.any(can_incr) or not np.any(can_decr):
            break
        
        j = np.argmax(np.where(can_incr, grad, -np.inf))
        k = np.argmin(np.where(can_decr, grad, np.inf))
        
        if j == k:
            break
        
        # Determine delta: limited by h[j] reaching 1 or h[k] reaching 0
        delta = min(1.0 - h[j], h[k], 0.1)  # cap at 0.1
        if delta <= 0:
            break
        
        h[j] += delta
        h[k] -= delta
        # Note: this maintains the sum constraint exactly
    
    return project_onto_constraint(h, target)
```

                h_sq = run_slsqp(best_h, best_n, 12.0, 100, 2000)
                c_sq = c5_value(h_sq, 2.0 / best_n)
                if c_sq < best_c5:
                    best_c5 = c_sq
                    best_h = h_sq

    # Phase 6: Final coordinate exchange + SLSQP polish
    if (time.time() - t0) < budget_s - 15:
        h_ce2, val_ce2 = coordinate_exchange(best_h, best_n, best_n * 0.5, 2.0 / best_n, 6.0, 300, time_up)
        if val_ce2 < best_c5:
            best_c5 = val_ce2
            best_h = h_ce2

    if (time.time() - t0) < budget_s - 5:
        h_final = run_slsqp(best_h, best_n, 8.0, 80, 5000)
        c_final = c5_value(h_final, 2.0 / best_n)
        if c_final < best_c5:
            best_c5 = c_final
            best_h = h_final
            best_n = best_n

    # Final repair
    best_h = project_onto_constraint(best_h, best_n * 0.5)
    best_c5 = c5_value(best_h, 2.0 / best_n)

    return best_h, best_c5, best_n
