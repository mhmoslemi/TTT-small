For each pair (i, j) with i ≠ j, the term h[j](1-h[i]) appears once (when k = j-i).
For i = j, the term h[i](1-h[i]) appears once (when k = 0).

So: sum_k O(k) = sum_i h[i](1-h[i]) + sum_{i≠j} h[j](1-h[i])
= sum_i h[i](1-h[i]) + sum_j h[j] * (n - 1 - sum_i≠j h[i])
= sum_i h[i](1-h[i]) + sum_j h[j] * (n - 1 - (sum_i h[i] - h[j]))
= sum_i h[i](1-h[i]) + sum_j h[j] * (n - sum_i h[i])
= sum_i h[i](1-h[i]) + sum_j h[j] * (n - n/2)
= sum_i h[i](1-h[i]) + (n/2) * sum_j h[j]
= sum_i h[i] - sum_i h[i]² + (n/2) * (n/2)
= n/2 - sum_i h[i]² + n²/4

Since sum_i h[i] = n/2.

So: sum_k O(k) = n²/4 + n/2 - sum_i h[i]²

And: max_k O(k) ≥ sum_k O(k) / (2n-1) = (n²/4 + n/2 - sum_i h[i]²) / (2n-1)

To minimize the RHS, we want to maximize sum_i h[i]², which means making h as binary as possible.

For binary h (60 ones, 60 zeros for n=120):
sum_i h[i]² = 60
RHS = (3600 + 60 - 60) / 239 = 3600 / 239 ≈ 15.06

C₅ ≥ 15.06 * (2/120) = 15.06 / 60 ≈ 0.251

This is a lower bound of about 0.251, which is much less than 0.38. So the bound from the sum is not tight.

The actual bottleneck is that we can't simultaneously minimize all lags. The "best" we can do is spread the overlap evenly across all lags, giving max ≈ average ≈ 0.251. But in practice, we can't do that well, and the max is higher.

This suggests that the optimal C₅ is somewhere between 0.251 and 0.38. Our current best is 0.38085, and we want to get to 0.3808.

OK let me just write the code and try to optimize as well as possible.

Let me think about one more approach: **particle swarm optimization (PSO)** in the space of h values.

PSO:
- Maintain a swarm of M particles (solutions)
- Each particle has a position h^(m) and velocity v^(m)
- Update: v^(m) = ω * v^(m) + c1 * r1 * (pbest^(m) - h^(m)) + c2 * r2 * (gbest - h^(m))
- h^(m) = h^(m) + v^(m)
- Project onto constraint set
- Update pbest and gbest

Parameters:
- M = 20-50 particles
- ω: inertia weight, decay from 0.9 to 0.4
- c1, c2: cognitive and social parameters, ~2.0
- r1, r2: random in [0,1]

This is a global optimization method that might escape local optima better than gradient methods.

The downside is that each particle evaluation requires computing C₅, which is O(n²). With M=30 particles and n=120, each iteration is 30 * 14400 = 432,000 operations. With 1000 iterations, that's 432 million operations, which might take 30-60 seconds. Feasible.

Let me include PSO as one of the phases.

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return np.max(corr) * dx

def project_onto_constraint(h, target_sum):
    lo = -1.0
    hi = 1.0
    for _ in range(100):
        mid = (lo + hi) / 2.0
        p = np.clip(h - mid, 0.0, 1.0)
        if p.sum() > target_sum:
            lo = mid
        else:
            hi = mid
    return np.clip(h - (lo + hi) / 2.0, 0.0, 1.0)

def soft_max_obj_and_grad(h, tau):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    tau_corr = tau * corr
    max_tc = np.max(tau_corr)
    exp_vals = np.exp(tau_corr - max_tc)
    log_sum_exp = max_tc + np.log(np.sum(exp_vals))
    obj = (log_sum_exp / tau) * dx
    weights = exp_vals / np.sum(exp_vals)
    
    grad = np.zeros(n)
    for m in range(2 * n - 1):
        w = weights[m]
        if w < 1e-15:
            continue
        lag = m - (n - 1)
        j1_lo = max(0, lag)
        j1_hi = min(n - 1, n - 1 + lag)
        if j1_lo <= j1_hi:
            grad[j1_lo:j1_hi+1] += w * (1.0 - h[j1_lo - lag:j1_hi - lag + 1])
        j2_lo = max(0, -lag)
        j2_hi = min(n - 1, n - 1 - lag)
        if j2_lo <= j2_hi:
            grad[j2_lo:j2_hi+1] += w * (-h[j2_lo + lag:j2_hi + lag + 1])
    
    return obj, grad * dx

def nesterov_pgd(h0, n, target_sum, deadline, tau_init=50.0, tau_max=400.0,
                  lr_init=0.04, max_iter=20000):
    h = h0.copy()
    y = h0.copy()
    best_h = h.copy()
    best_c5 = compute_c5(h)
    tau = tau_init
    lr = lr_init
    t_mom = 1.0
    stall = 0
    best_stall_action = 0
    
    for it in range(max_iter):
        if time.time() > deadline:
            break
        
        obj, g = soft_max_obj_and_grad(y, tau)
        
        t_new = (1.0 + np.sqrt(1.0 + 4.0 * t_mom * t_mom)) / 2.0
        beta = (1.0 - t_mom) / t_new
        
        y_new = h - lr * g + beta * (h - y)
        h = project_onto_constraint(y_new, target_sum)
        t_mom = t_new
        
        c5 = compute_c5(h)
        if c5 < best_c5 - 1e-14:
            best_c5 = c5
            best_h = h.copy()
            stall = 0
            tau = min(tau * 1.003, tau_max)
        else:
            stall += 1
            if stall > 40:
                tau = min(tau * 1.5, tau_max)
                lr *= 0.75
                t_mom = 1.0
                stall = 0
                best_stall_action += 1
                if best_stall_action > 8 or lr < 0.002:
                    break
    
    return best_h, best_c5

def worst_lag_refine(h0, n, target_sum, deadline, max_iter=5000):
    h = h0.copy()
    best_h = h.copy()
    best_c5 = compute_c5(h)
    lr = 0.05
    stall = 0
    
    for it in range(max_iter):
        if time.time() > deadline:
            break
        
        corr = np.correlate(h, 1.0 - h, mode="full")
        k_star = np.argmax(corr)
        lag = k_star - (n - 1)
        dx = 2.0 / n
        
        g = np.zeros(n)
        j1_lo = max(0, lag)
        j1_hi = min(n - 1, n - 1 + lag)
        if j1_lo <= j1_hi:
            g[j1_lo:j1_hi+1] += (1.0 - h[j1_lo - lag:j1_hi - lag + 1])
        j2_lo = max(0, -lag)
        j2_hi = min(n - 1, n - 1 - lag)
        if j2_lo <= j2_hi:
            g[j2_lo:j2_hi+1] += (-h[j2_lo + lag:j2_hi + lag + 1])

def pso_optimize(h0, n, target_sum, deadline, n_particles=25, max_iter=500):
    # PSO in the space of h
    n_p = n_particles
    # Initialize particles around h0
    particles = np.zeros((n_p, n))
    for i in range(n_p):
        if i == 0:
            particles[i] = h0
        else:
            particles[i] = h0 + 0.05 * np.random.randn(n)
            particles[i] = project_onto_constraint(particles[i], target_sum)
    
    velocities = np.zeros((n_p, n))
    pbest = particles.copy()
    pbest_c5 = np.array([compute_c5(particles[i]) for i in range(n_p)])
    gbest_idx = np.argmin(pbest_c5)
    gbest = particles[gbest_idx].copy()
    gbest_c5 = pbest_c5[gbest_idx]
    
    omega_start, omega_end = 0.9, 0.4
    c1, c2 = 2.0, 2.0
    
    for it in range(max_iter):
        if time.time() > deadline:
            break
        
        omega = omega_start + (omega_end - omega_start) * (it / max_iter)
        
        for i in range(n_p):
            r1 = np.random.rand(n)
            r2 = np.random.rand(n)
            velocities[i] = omega * velocities[i] + c1 * r1 * (pbest[i] - particles[i]) + c2 * r2 * (gbest - particles[i])
            particles[i] = particles[i] + velocities[i]
            particles[i] = project_onto_constraint(particles[i], target_sum)
            
            c5_i = compute_c5(particles[i])
            if c5_i < pbest_c5[i]:
                pbest_c5[i] = c5_i
                pbest[i] = particles[i].copy()
            if c5_i < gbest_c5:
                gbest_c5 = c5_i
                gbest = particles[i].copy()
                gbest_idx = i
    
    return gbest, gbest_c5

def coordinate_descent(h0, n, target_sum, deadline, max_sweeps=50):
    h = h0.copy()
    best_c5 = compute_c5(h)
    dx = 2.0 / n
    step = 0.05
    
    for sweep in range(max_sweeps):
        if time.time() > deadline:
            break
        improved = False
        for j in range(n):
            for delta in [step, -step, step * 0.5, -step * 0.5]:
                h_new = h.copy()
                h_new[j] += delta
                if h_new[j] < 0 or h_new[j] > 1:
                    continue
                # Recompute sum constraint
                h_new = project_onto_constraint(h_new, target_sum)
                c5 = compute_c5(h_new)
                if c5 < best_c5 - 1e-14:
                    h = h_new
                    best_c5 = c5
                    improved = True
                    break
        if not improved:
            step *= 0.7
            if step < 0.001:
                break
    
    return h, best_c5
