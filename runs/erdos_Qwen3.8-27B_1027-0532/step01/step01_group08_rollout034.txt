The problem is: minimize max_k ∫ h(x)(1-h(x+k)) dx

Note that ∫ h(x)(1-h(x+k)) dx = ∫h(x)dx - ∫h(x)h(x+k)dx = 1 - autocorr(h, k)

Wait, that's only true if the integrals are over the same domain. Since h is defined on [0,2] and h(x+k) might go outside [0,2], the integral ∫h(x)(1-h(x+k))dx is only over the intersection of the domains.

Actually, in the discrete case with np.correlate, the "overlap" at a given lag is already accounting for the domain restriction. So I can't simply write it as 1 - autocorr.

But for small lags (where the domain restriction has minimal effect), we have approximately:
overlap(k) ≈ 1 - autocorr(h, k)

So minimizing the maximum overlap is approximately equivalent to maximizing the minimum autocorrelation. This is a "flat spectrum" problem - we want the autocorrelation to be as flat (close to its mean value) as possible.

The mean autocorrelation (averaged over all lags) is related to (∫h)²/(2*length) by the Wiener-Khinchin theorem (in the periodic case). For our case, it's roughly (1)²/2 = 1/2.

So we want autocorr(h, k) ≈ 1/2 for all k ≠ 0, which means overlap(k) ≈ 1/2 for all k. But we can't achieve this exactly; the best we can do is minimize the maximum deviation.

This connects to the theory of "minimum autocorrelation" sequences. For binary sequences, the best-known constructions achieve autocorrelation values that are O(√n) from the mean. For continuous-valued functions, we can potentially do better.

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return np.max(corr) * dx

def project_onto_constraint(h, target_sum):
    lo = -1.0
    hi = 1.0
    for _ in range(100):
        mid = (lo + hi) / 2.0
        p = np.clip(h - mid, 0.0, 1.0)
        if p.sum() > target_sum:
            lo = mid
        else:
            hi = mid
    return np.clip(h - (lo + hi) / 2.0, 0.0, 1.0)

def grad_single_lag(h, lag, n):
    dx = 2.0 / n
    g = np.zeros(n)
    if lag >= 0:
        if lag < n:
            j_hi = n - 1 - lag
            g[0:j_hi+1] += (1.0 - h[lag:n])
            g[lag:n] += (-h[0:n-lag])
    else:
        abs_lag = -lag
        if abs_lag < n:
            g[abs_lag:n] += (1.0 - h[0:n-abs_lag])
            g[0:n-abs_lag] += (-h[abs_lag:n])
    return g * dx

def topk_soft_max_obj_and_grad(h, tau, k_top):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    if k_top < 2*n-1:
        top_k_idx = np.argsort(corr)[-k_top:]
        top_k_corr = corr[top_k_idx]
    else:
        top_k_idx = np.arange(2*n-1)
        top_k_corr = corr
    tau_tc = tau * top_k_corr
    max_tc = np.max(tau_tc)
    log_sum_exp = max_tc + np.log(np.sum(np.exp(tau_tc - max_tc)))
    obj = (log_sum_exp / tau) * dx
    weights = np.exp(tau_tc - max_tc)
    weights /= np.sum(weights)
    grad = np.zeros(n)
    for wi, idx in zip(weights, top_k_idx):
        if wi < 1e-14:

        lag = idx - (n - 1)
        g = grad_single_lag(h, lag, n)

    return obj, grad

        c5 = compute_c5(h_new)
