    """Find optimal δ to add to h[j] and subtract from h[k]."""
    dx = 2.0 / n
    
    def objective_at_delta(delta):
        h_trial = h.copy()
        h_trial[j] += delta
        h_trial[k] -= delta
        if h_trial[j] < 0 or h_trial[j] > 1 or h_trial[k] < 0 or h_trial[k] > 1:
            return np.inf
        corr = np.correlate(h_trial, 1.0 - h_trial, mode='full')
        return np.max(corr) * dx
    
    # Binary search / golden section on feasible δ
    delta_lo = max(-h[j], h[k] - 1.0)
    delta_hi = min(1.0 - h[j], h[k])
    
    # Use golden section search
    gr = (np.sqrt(5) - 1) / 2
    a = delta_lo
    b = delta_hi
    c = b - gr * (b - a)
    d = a + gr * (b - a)
    fc = objective_at_delta(c)
    fd = objective_at_delta(d)
    
    for _ in range(50):
        if fc < fd:
            b = d
            d = c
            fd = fc
            c = b - gr * (b - a)
            fc = objective_at_delta(c)
        else:
            a = c
            c = d
            fc = fd
            d = a + gr * (b - a)
            fd = objective_at_delta(d)
    
    delta_opt = (a + b) / 2
    return delta_opt

Let me now think about the exact 2-coordinate descent more carefully.

Given h, for a pair (j, k) with j having h[j] > 0 and k having h[k] < 1:
- We want to find δ* that minimizes f(δ) = C₅(h + δ*e_j - δ*e_k)
- where e_j is the unit vector at position j
- Feasible: 0 ≤ δ ≤ min(h[j], 1-h[k])

f(δ) = dx * max_s (overlap_s + δ * (g_j[s] - g_k[s]))
where g_j[s] = ∂overlap_s/∂h[j] = (1-h[j+s])*1_{valid} - h[j-s]*1_{valid}

This is the max of linear functions in δ, hence convex in δ.
The minimum is at the point where the subgradient contains 0, or at a boundary.

To find it:
1. Compute all g_j[s] and g_k[s] for s = 0,...,2n-2
2. Compute d[s] = g_j[s] - g_k[s]
3. f(δ) = max_s (corr[s] + δ * d[s])
4. Find δ* that minimizes this

Since f is convex piecewise linear, the minimum is at a breakpoint or boundary.
The breakpoints occur where two lines cross: corr[a] + δ*d[a] = corr[b] + δ*d[b]
→ δ = (corr[b] - corr[a]) / (d[a] - d[b]) (when d[a] ≠ d[b])

Algorithm:
1. Start with δ=0, find the active set (lines achieving the max)
2. If all active lines have d[s] > 0, increase δ until a new line becomes active
3. If all active lines have d[s] < 0, decrease δ until a new line becomes active
4. If there are both positive and negative d[s] in the active set, we're at the minimum (the max switches between lines with positive and negative slopes)

Actually, a simpler approach: just do a ternary search (or binary search on the derivative) since f is convex.

For a convex function, binary search on the subgradient works:
- If the max is achieved by a line with positive slope, we need to decrease δ
- If the max is achieved by a line with negative slope, we need to increase δ
- If the max is achieved by lines with both positive and negative slopes (or zero), we're at the optimum
