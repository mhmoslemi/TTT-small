Let me define: g_k(i) = h[i+shift_k] + h[i-shift_k] (with boundary terms = 0 if index out of range)

Then Δf_k = delta * (g_k(i) - g_k(j))

This is clean! For a given pair (i, j), the effect on each correlation coefficient is delta * (g_k(i) - g_k(j)).

The new max corr is max_k (corr[k] + delta * (g_k(i) - g_k(j))).

To find the optimal delta for a given pair (i,j):
- We want to minimize max_k (corr[k] + delta * d_k) where d_k = g_k(i) - g_k(j)
- This is a 1D convex optimization problem

The optimal delta is where the top two (or more) active constraints become equal.

This is getting complex but very powerful. Let me implement a simpler version first and see if it works.

Let me simplify: for each i, find the best j to pair with (or the best delta). This reduces to O(n² * n) = O(n³) per pass = 614K operations, which is very fast.

Actually, let me just implement a practical version:

1. Compute corr
2. For each i, compute the "potential" of decreasing h[i] (i.e., the gradient of the max corr w.r.t. h[i] if we could decrease it)
3. For each j, compute the "potential" of increasing h[j]
4. Do the best paired move
5. Repeat

The "potential" of decreasing h[i] by 1 (before projection) is:
reduction_k = (1-h[i+shift_k]) + h[i-shift_k] = 1 - g_k(i)
The new max would be max_k (corr[k] - reduction_k)

Similarly, the "potential" of increasing h[j] by 1 is:
increase_k = (1-h[j+shift_k]) + h[j-shift_k] = 1 - g_k(j)  [wait, sign is wrong]

Actually, I already derived: Δf_k for h[i]-=delta, h[j]+=delta is delta * (g_k(i) - g_k(j)).

So if we want to DECREASE the max, we want delta > 0 and g_k(i) > g_k(j) for the active k's.
Or delta < 0 and g_k(i) < g_k(j) for the active k's.

    best = h.copy()
    corr = np.correlate(best, 1.0 - best, mode='full')
    best_score = np.max(corr) * dx
    n_passes = 0
    
    while time.time() - t_start < time_limit:
        n_passes += 1
        improved = False
        # Find all pairs (i, j) with i < j where best[i] > 0 and best[j] < 1
        # For efficiency, only consider promising pairs
        
        # Compute g_k(i) for all i, k
        # g_k(i) = h[i+shift_k] + h[i-shift_k] (with 0 for out-of-bounds)
        # shift_k = k - (n-1)
        
        # This is a (n x (2n-1)) matrix
        # g[k, i] = h[i + shift_k] (if valid) + h[i - shift_k] (if valid)
        
        # Actually, let me just compute it on the fly for the top candidates
        
        # Find the active constraints
        active_k = np.where(corr > best_score - 0.01/dx)[0]
        
        # For each active k, find the best (i, j) pair
        for k in active_k[:10]:  # Only top 10 active constraints
            shift = k - (n - 1)
            # g(i) = h[i+shift] (if valid) + h[i-shift] (if valid)
            g = np.zeros(n)
            for i in range(n):
                val = 0.0
                if 0 <= i + shift < n:
                    val += best[i + shift]
                if 0 <= i - shift < n:
                    val += best[i - shift]
                g[i] = val
            
            # We want to increase h at locations where g is small (to not increase f_k much)
            # and decrease h at locations where g is large (to decrease f_k a lot)
            # But we also need to consider OTHER constraints (not just this k)
            
            # Simple heuristic: find i with max g[i] and best[i] > 0.01
            # and j with min g[j] and best[j] < 0.99
            dec_candidates = np.where(g > np.median(g) + 0.1)[0]
            inc_candidates = np.where(g < np.median(g) - 0.1)[0]
            
            # Filter by feasibility
            dec_candidates = dec_candidates[best[dec_candidates] > 0.01]
            inc_candidates = inc_candidates[best[inc_candidates] < 0.99]
            
            if len(dec_candidates) == 0 or len(inc_candidates) == 0:
                continue
            
            # Try the best pair
            i_best = dec_candidates[np.argmax(g[dec_candidates])]
            j_best = inc_candidates[np.argmin(g[inc_candidates])]
            
            # Compute optimal delta for this pair
            d = g - g[j_best]  # d[i] = g_k(i) - g_k(j) for all i
            # Wait, I need d for ALL correlation coefficients, not just k
            # Let me recompute for all k
            
            # Actually, for the paired move h[i]-=delta, h[j]+=delta:
            # Δcorr[m] = delta * (g_m(i) - g_m(j)) for each m
            # where g_m(i) = h[i+shift_m] + h[i-shift_m]
            
            # Let me compute the full delta vector
            # delta_corr[m] = g_m(i) - g_m(j)
            
            # This requires computing g_m for the specific i and j for all m
            # g_m(i) = h[i+shift_m] + h[i-shift_m]
            
            d_full = np.zeros(2*n-1)
            for m in range(2*n-1):
                sm = m - (n-1)
                gi = 0.0
                if 0 <= i_best + sm < n:
                    gi += best[i_best + sm]
                if 0 <= i_best - sm < n:
                    gi += best[i_best - sm]
                gj = 0.0
                if 0 <= j_best + sm < n:
                    gj += best[j_best + sm]
                if 0 <= j_best - sm < n:
                    gj += best[j_best - sm]
                d_full[m] = gi - gj
            
            # Now find optimal delta: minimize max(corr + delta * d_full)
            # subject to 0 <= delta <= min(best[i_best], 1-best[j_best])
            
            # This is a 1D problem. The function max(corr + delta*d_full) is convex in delta.
            # Find the minimum by bisection or by finding where the top constraints cross.
            
            delta_lo = 0.0
            delta_hi = min(best[i_best], 1.0 - best[j_best])
            
            if delta_hi <= 0:
                continue
            
            # Find the minimum of f(delta) = max_m (corr[m] + delta * d_full[m])
            # Use ternary search or golden section
            # Or: find where the derivative changes sign
            # f'(delta) = d_full[m*] where m* = argmax_m (corr[m] + delta * d_full[m])
            # At optimum, the active constraint switches from one with positive slope to one with negative slope
            
            # Simple approach: try several delta values
            best_delta = 0.0
            best_f = best_score
            for frac in [0.1, 0.25, 0.5, 0.75, 0.9, 1.0]:
                d_test = frac * delta_hi
                f_test = np.max(corr + d_test * d_full) * dx
                if f_test < best_f:
                    best_f = f_test
                    best_delta = d_test
            
            # Refine around best_delta
            if best_delta > 0:
                step = delta_hi * 0.05
                for _r in range(20):
                    for dd in [best_delta - step, best_delta + step]:
                        if dd < 0 or dd > delta_hi:
                            continue
                        f_test = np.max(corr + dd * d_full) * dx
                        if f_test < best_f:
                            best_f = f_test
                            best_delta = dd
                    step *= 0.5
                
                # Apply the move
                trial = best.copy()
                trial[i_best] = np.clip(best[i_best] - best_delta, 0.0, 1.0)
                trial[j_best] = np.clip(best[j_best] + best_delta, 0.0, 1.0)
                # Since we moved equal amounts, sum is preserved
                # Verify
                if abs(np.sum(trial) - n/2.0) > 1e-10:
                    trial = project_feasible(trial, n)
                
                new_corr = np.correlate(trial, 1.0 - trial, mode='full')
                s = np.max(new_corr) * dx
                if s < best_score - 1e-14:
                    best = trial
                    corr = new_corr
                    best_score = s
                    improved = True
        
        if not improved:
            # Try random pairs
            for _ in range(100):
                i_try = np.random.randint(n)
                j_try = np.random.randint(n)
                if i_try == j_try:
                    continue
                if best[i_try] < 0.01 or best[j_try] > 0.99:
                    continue
                
                d_full = np.zeros(2*n-1)
                for m in range(2*n-1):
                    sm = m - (n-1)
                    gi = 0.0
                    if 0 <= i_try + sm < n:
                        gi += best[i_try + sm]
                    if 0 <= i_try - sm < n:
                        gi += best[i_try - sm]
                    gj = 0.0
                    if 0 <= j_try + sm < n:
                        gj += best[j_try + sm]
                    if 0 <= j_try - sm < n:
                        gj += best[j_try - sm]
                    d_full[m] = gi - gj
                
                delta_hi = min(best[i_try], 1.0 - best[j_try])
                if delta_hi <= 0:
                    continue
                
                best_delta = 0.0
                best_f = best_score
                for frac in [0.3, 0.5, 0.7, 1.0]:
                    d_test = frac * delta_hi
                    f_test = np.max(corr + d_test * d_full) * dx
                    if f_test < best_f:
                        best_f = f_test
                        best_delta = d_test
                
                if best_delta > 0:
                    trial = best.copy()
                    trial[i_try] -= best_delta
                    trial[j_try] += best_delta
                    if abs(np.sum(trial) - n/2.0) > 1e-10:

                    new_corr = np.correlate(trial, 1.0 - trial, mode='full')
                    s = np.max(new_corr) * dx
                    if s < best_score - 1e-14:
                        best = trial
                        corr = new_corr
                        best_score = s
                        improved = True
                # Also try the reverse direction
        if not improved:
            break
    
    return best, best_score, n_passes

import numpy as np
from scipy.optimize import minimize
import time

def score_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return np.max(corr) * dx

def project_feasible(x, n):
    target = n / 2.0
    lo = -5.0
    hi = 5.0
    for _ in range(100):
        mid = (lo + hi) / 2.0
        proj = np.clip(x - mid, 0.0, 1.0)
        s = np.sum(proj)
        if s > target:
            lo = mid
        else:
            hi = mid
    lam = (lo + hi) / 2.0
    return np.clip(x - lam, 0.0, 1.0)

def compute_delta_corr(h, n, i, j):
    """Compute the change in each correlation coefficient if h[i] decreases and h[j] increases by the same amount."""
    d = np.zeros(2 * n - 1)
    for k in range(2 * n - 1):
        shift = k - (n - 1)
        gi = 0.0
        if 0 <= i + shift < n:
            gi += h[i + shift]
        if 0 <= i - shift < n:
            gi += h[i - shift]
        gj = 0.0
        if 0 <= j + shift < n:
            gj += h[j + shift]
        if 0 <= j - shift < n:
            gj += h[j - shift]
        d[k] = gi - gj
    return d

def find_optimal_delta(corr, d, delta_max):
    """Find delta in [0, delta_max] that minimizes max(corr + delta * d)."""
    # The function f(delta) = max_k(corr[k] + delta * d[k]) is convex in delta.
    # Find minimum by checking where the active constraint changes.
    
    if delta_max <= 0:
        return 0.0, np.max(corr)
    
    # Find the minimum using a combination of:
    # 1. Check delta = 0
    # 2. Check delta = delta_max
    # 3. For each pair of constraints, find the crossing point
    
    best_delta = 0.0
    best_val = np.max(corr)
    
    # Check endpoints
    val_max = np.max(corr + delta_max * d)
    if val_max < best_val:
        best_val = val_max
        best_delta = delta_max
    
    # Find crossing points between top constraints
    # Sort by corr value (descending)
    order = np.argsort(-corr)
    top_n = min(20, len(corr))
    
    for a in range(top_n):
        for b in range(a + 1, top_n):
            ka = order[a]
            kb = order[b]
            if d[ka] == d[kb]:
                continue
            # corr[ka] + delta * d[ka] = corr[kb] + delta * d[kb]
            # delta = (corr[kb] - corr[ka]) / (d[ka] - d[kb])
            delta_cross = (corr[kb] - corr[ka]) / (d[ka] - d[kb])
            if 0 < delta_cross < delta_max:
                val = np.max(corr + delta_cross * d)
                if val < best_val:
                    best_val = val
                    best_delta = delta_cross
    
    # Refine around best_delta
    if 0 < best_delta < delta_max:
        step = delta_max * 0.1
        for _ in range(15):
            for dd in [best_delta - step, best_delta + step]:
                if 0 < dd < delta_max:
                    val = np.max(corr + dd * d)
                    if val < best_val:
                        best_val = val
                        best_delta = dd
            step *= 0.5
    
    return best_delta, best_val

def paired_search(h, n, t_start, time_limit):
    dx = 2.0 / n
    best = h.copy()
    corr = np.correlate(best, 1.0 - best, mode='full')
    best_score = np.max(corr) * dx
    rng = np.random.RandomState(12345)
    
    while time.time() - t_start < time_limit:
        improved = False
        
        # Strategy 1: Greedy - for each i with best[i] > 0.01, find best j to send mass to
        for i in range(n):
            if time.time() - t_start > time_limit:
                return best, best_score
            if best[i] < 0.005:
                continue
            # For this i, find the best j
            delta_hi_i = best[i]
            best_j_score = best_score
            best_j_pair = None
            best_j_delta = 0.0
            
            # Try a subset of j's (those with best[j] < 0.995)
            candidates_j = np.where(best < 1.0 - 0.005)[0]
            candidates_j = candidates_j[candidates_j != i]
            
            if len(candidates_j) == 0:
                continue
            
            # Score each candidate j by the potential improvement
            # For efficiency, only try the most promising ones
            # A good heuristic: j's where best[j] is small (more room to increase)
            # and where the delta_corr would reduce the max
            
            # Pre-compute: for each j, what's the max of (corr + delta_max * d)?
            # This is expensive for all j, so let's sample
            
            # Actually, let's just try all j's but with a quick screening
            # Quick screen: for the active constraint k*, check if g_k*(i) > g_k*(j)
            k_star = np.argmax(corr)
            shift_star = k_star - (n - 1)
            
            def compute_g(idx):
                val = 0.0
                if 0 <= idx + shift_star < n:
                    val += best[idx + shift_star]
                if 0 <= idx - shift_star < n:
                    val += best[idx - shift_star]
                return val
            
            gi_star = compute_g(i)
            
            # Filter: only consider j where gi_star > g_j_star (to reduce the active constraint)
            promising_j = []
            for j in candidates_j:
                gj_star = compute_g(j)

                        best = trial
                        corr = new_corr

                        improved = True

                    elif val_opt < best_j_score:

                    trial[i_try] = best[i_try] - delta_opt

                    actual_score = np.max(new_corr) * dx

                        corr = new_corr
                        best_score = actual_score

                    corr = new_corr

def lse_objective(x, T):
    n = len(x)
    dx = 2.0 / n
    corr = np.correlate(x, 1.0 - x, mode='full')
    cmax = np.max(corr)
    scaled = (corr - cmax) / T
    return dx * (cmax + T * np.log(np.sum(np.exp(scaled))))
