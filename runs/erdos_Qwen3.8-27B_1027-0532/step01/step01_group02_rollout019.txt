    dx = 2.0 / n
    # Compute all C(k) values

    grad = np.zeros(n)

    #   dC(k)/dh[j] = (1-h[j+k]) if j <= n-1-k, else 0
    #                 - h[j-k] if j >= k, else 0
    # Negative lag -k (k > 0): C(-k) = sum_{i=k}^{n-1} h[i](1-h[i-k])

    # Vectorized approach:

        if w < 1e-15:

- The upper envelope is formed by a subset of these lines
- The minimum of the envelope over [0,1] is either at x=0, x=1, or at an intersection point

1. The function is convex, so the minimum is unique (or a flat region)
2. We can binary search:

**Lagrangian approach for coordinate descent:**

minimize max_k (a_k * x + b_k) + λ * x
subject to 0 ≤ x ≤ 1

The optimal x satisfies: 0 ∈ ∂(max_k (a_k*x + b_k)) + λ at the optimum (if interior)

So we need: -λ ∈ conv{a_k : k active at x}

This means: min{a_k : k active} ≤ -λ ≤ max{a_k : k active}

To find x:
- If -λ < min_k a_k: x = 1 (push to upper bound)
- If -λ > max_k a_k: x = 0 (push to lower bound)
- Otherwise: x is where the upper envelope has slope crossing -λ

This can be found by:
1. Sorting the (a_k, b_k) pairs by a_k
2. Finding the upper envelope
3. Finding where the envelope's slope crosses -λ

Or more simply: for a given λ, the optimal x is:
x*(λ) = argmin_{x∈[0,1]} max_k ((a_k+λ)*x + b_k)

This is the same problem with modified slopes. We can find it by:
1. Computing g_λ(x) = max_k ((a_k+λ)*x + b_k) for x ∈ [0,1]
2. Finding the minimum of g_λ

For the binary search on λ:
- After updating all coordinates with the current λ, check if sum(h) = n/2
- If sum > n/2, increase λ (to push values down)
- If sum < n/2, decrease λ (to push values up)

This gives a coordinate descent algorithm with a 1D outer binary search on λ.

def repair_h(h, n):
    """Project onto {h : 0 <= h <= 1, sum(h) = n/2}"""
    h = np.clip(h, 0.0, 1.0)
    target = n / 2.0
    for _ in range(50):
        diff = target - np.sum(h)
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            mask = h < 1.0
            if not mask.any():
                break
            h[mask] += diff / mask.sum()
            h = np.minimum(h, 1.0)
        else:
            mask = h > 0.0
            if not mask.any():
                break

            h = np.maximum(h, 0.0)

        else:

Now, let me think about the optimization algorithm more carefully.

**The key challenge**: The objective C₅ = max_k C(k) * dx is non-smooth (it's the max of many smooth functions). Standard gradient-based methods struggle with this.

**Approach: Smoothing + Gradient Descent**

Use the log-sum-exp approximation:
C₅_smooth(h; β) = (1/β) * log(Σ_k exp(β * C(k) * dx))

This is a smooth approximation to C₅ that converges to C₅ as β → ∞.

The gradient of C₅_smooth is:
∇C₅_smooth = (1/Σ_k w_k) * Σ_k w_k * ∇C(k) * dx

where w_k = exp(β * C(k) * dx).

This is a weighted average of the gradients of the individual C(k) functions, with weights proportional to exp(β*C(k)*dx).

For large β, only the C(k) near the maximum contribute significantly, and the gradient is approximately ∇C(k*) where k* = argmax C(k).

**Algorithm:**
1. Start with a good initial point (linear ramp or initial_h_values)
2. For β = 5, 10, 20, 50, 100, 200, 500, 1000:
   a. Run gradient descent with learning rate adapted to β
   b. Project onto constraint set after each step
3. Final polish with coordinate descent or SLSQP

**Learning rate**: For the smoothed objective, the Lipschitz constant is approximately β * L where L is the Lipschitz constant of C(k). So the learning rate should be O(1/(β*L)).

For C(k), the gradient components are bounded by 1 (since they involve products of values in [0,1]). So L ≈ sqrt(n) (Euclidean norm of gradient is at most sqrt(n)). The Lipschitz constant of the smoothed objective is roughly β * sqrt(n).

So learning rate ≈ 1/(β * sqrt(n)).

For n=350, β=100: lr ≈ 1/(100 * 18.7) ≈ 5.3e-4.

Let me also think about **momentum** to speed up convergence:
h_{t+1} = h_t - lr * grad + momentum * (h_t - h_{t-1})

This can help escape shallow local minima of the smoothed objective.

**Projection**: After each step, project onto {h : 0 ≤ h ≤ 1, sum(h) = n/2}.
A good projection:
1. h ← clip(h, 0, 1)
2. If sum(h) > n/2: reduce values proportional to (1-h) to push sum down
3. If sum(h) < n/2: increase values proportional to h to push sum up
4. Iterate until sum is correct

Actually, the standard projection onto the intersection of a hypercube and a hyperplane can be done in O(n) using bisection:
Find λ such that sum(clip(h - λ, 0, 1)) = n/2.

This is a 1D convex problem (sum of clip functions is monotone in λ), solvable by bisection in O(n log(1/eps)).

Let me implement this:

```python
def project_onto_constraint(h, n):
    """Project h onto {x : 0 <= x_i <= 1, sum(x) = n/2}."""
    target = n / 2.0
    
    # Bisection on lambda: find lam such that sum(clip(h - lam, 0, 1)) = target
    lo = h.min() - 1
    hi = h.max() + 1
    
    for _ in range(60):
        mid = (lo + hi) / 2
        projected = np.clip(h - mid, 0, 1)
        s = projected.sum()
        if s > target:
            lo = mid
        else:
            hi = mid
    
    lam = (lo + hi) / 2
    return np.clip(h - lam, 0, 1)
```

This is O(n) per evaluation and O(60n) total, which is very fast.

def evaluate_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)

def project_onto_constraint(h, n):
    """Project onto {x : 0 <= x_i <= 1, sum(x) = n/2} using bisection."""
    target = n / 2.0
    lo = h.min() - 1
    hi = h.max() + 1
    for _ in range(60):
        mid = (lo + hi) / 2
        s = np.clip(h - mid, 0, 1).sum()
        if s > target:
            lo = mid
        else:
            hi = mid
    return np.clip(h - (lo + hi) / 2, 0, 1)

    """Compute smoothed C5 and its gradient."""
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    scaled = beta * corr * dx
    m = scaled.max()
    exp_vals = np.exp(scaled - m)
    sum_exp = exp_vals.sum()
    obj = (m + np.log(sum_exp)) / beta * dx
    weights = exp_vals / sum_exp
    
    grad = np.zeros(n)

        if w < 1e-15:

            grad[k2:] += w * (1 - h[:n-k2])
