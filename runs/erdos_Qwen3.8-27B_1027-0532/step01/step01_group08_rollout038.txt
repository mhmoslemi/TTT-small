Let me focus on making the L-BFGS-B optimization as effective as possible, since that's where most of the improvement will come from.

Key insight: The log-sum-exp approximation with tau controls the "sharpness" of the max approximation. 
- High tau → smooth, easier to optimize, but far from the true max
- Low tau → sharp, close to true max, but harder to optimize (more non-convex)

The nested approach (high to low tau) should work well:
- Start at tau=100: find a rough minimum of the smooth approximation
- Decrease to tau=50, 30, 20, 15, 10, 8, 5, 3: progressively sharpen

At each step, the previous solution provides a good starting point.

For L-BFGS-B, the main issue is that it uses a limited memory BFGS approximation of the Hessian. For our problem, the Hessian is:
H = dx * Σ_m w_m * (J_m^T J_m - diagonal terms)

where J_m is the Jacobian of corr[m] with respect to h. This is a sum of rank-2 matrices (since each corr[m] is bilinear), so the Hessian has low numerical rank. L-BFGS-B should handle this well.

Let me also add a **constraint handling** trick: since we need sum(h) = n/2 exactly, and L-BFGS-B only handles inequality constraints (bounds), I should either:
(a) Add a large penalty for sum(h) ≠ n/2, or
(b) Project onto the equality constraint after each L-BFGS-B call

Option (b) is cleaner. After each L-BFGS-B call, project the result onto {h: 0 ≤ h ≤ 1, sum(h) = n/2}.

But wait, during the L-BFGS-B optimization, the sum constraint is not enforced. This could lead to the optimizer finding a point that's optimal for the bounds but has the wrong sum. 

A better approach: **reparameterize**. Instead of optimizing h directly, optimize h = g(t) where g is a parameterization that automatically satisfies the constraints. For example:
- h_i = sigmoid(t_i) / Σ_j sigmoid(t_j) * n/2
- This ensures 0 < h_i < 1 and sum(h) = n/2

But this makes the objective more complex. Let me just use the penalty approach:
- Add penalty * (sum(h) - n/2)² to the objective
- Use a large penalty value

Actually, the simplest approach that works well in practice:
- Optimize with L-BFGS-B (bounds only)
- After convergence, project onto the equality constraint
- The projection changes the objective slightly, but if the L-BFGS-B solution is close to the constraint, the change is small

In practice, L-BFGS-B with bounds [0,1] will naturally try to use the full range, and the sum will be close to n/2. The projection step will make a small adjustment.

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)

def smooth_obj(h, tau):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    scaled = corr / tau
    max_s = np.max(scaled)
    lse = max_s + np.log(np.sum(np.exp(scaled - max_s)))
    return lse * tau * dx

def smooth_grad(h, tau):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    scaled = corr / tau
    max_s = np.max(scaled)
    weights = np.exp(scaled - max_s)
    weights /= np.sum(weights)
    grad = np.zeros(n)
    for m in range(len(corr)):
        w = weights[m]
        if w < 1e-15:
            continue
        lag = m - (n - 1)
        lo1 = max(0, -lag)
        hi1 = min(n, n - lag)
        if lo1 < hi1:
            grad[lo1:hi1] += w * (1.0 - h[lo1 + lag:hi1 + lag])
        lo2 = max(0, lag)
        hi2 = min(n, n + lag)
        if lo2 < hi2:
            grad[lo2:hi2] += -w * h[lo2 - lag:hi2 - lag]
    return grad * dx

def smooth_obj_grad(h, tau):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    scaled = corr / tau
    max_s = np.max(scaled)
    lse = max_s + np.log(np.sum(np.exp(scaled - max_s)))
    obj = lse * tau * dx
    weights = np.exp(scaled - max_s)
    weights /= np.sum(weights)
    grad = np.zeros(n)
    for m in range(len(corr)):
        w = weights[m]
        if w < 1e-15:
            continue
        lag = m - (n - 1)
        lo1 = max(0, -lag)
        hi1 = min(n, n - lag)
        if lo1 < hi1:
            grad[lo1:hi1] += w * (1.0 - h[lo1 + lag:hi1 + lag])
        lo2 = max(0, lag)
        hi2 = min(n, n + lag)
        if lo2 < hi2:
            grad[lo2:hi2] += -w * h[lo2 - lag:hi2 - lag]
    return obj, grad * dx

def project_onto_constraint(h, target_sum):
    lo = -2.0
    hi = 2.0
    for _ in range(80):
        mid = (lo + hi) / 2.0
        p = np.clip(h - mid, 0.0, 1.0)
        if p.sum() > target_sum:
            lo = mid
        else:
            hi = mid
    return np.clip(h - (lo + hi) / 2.0, 0.0, 1.0)

def lbfgsb_single(h0, n, target_sum, tau, maxiter=300, deadline=None):
    def obj_fun(x):
        o, _ = smooth_obj_grad(x, tau)
        return o
    def grad_fun(x):
        _, g = smooth_obj_grad(x, tau)
        return g
    
    bounds = [(0.0, 1.0)] * n
    try:
        res = minimize(obj_fun, h0, jac=grad_fun, method='L-BFGS-B',
                       bounds=bounds,
                       options={'maxiter': maxiter, 'ftol': 1e-15, 'gtol': 1e-10,
                                'maxls': 100})
        if hasattr(res, 'x') and res.x is not None:
            h_opt = np.clip(res.x, 0.0, 1.0)
            h_opt = project_onto_constraint(h_opt, target_sum)
            return h_opt
    except Exception:
        pass
    return h0

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)

def smooth_obj_grad(h, tau):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    scaled = corr / tau
    max_s = np.max(scaled)
    lse = max_s + np.log(np.sum(np.exp(scaled - max_s)))
    obj = lse * tau * dx
    weights = np.exp(scaled - max_s)
    weights /= np.sum(weights)
    grad = np.zeros(n)
    for m in range(len(corr)):
        w = weights[m]
        if w < 1e-15:
            continue
        lag = m - (n - 1)
        lo1 = max(0, -lag)
        hi1 = min(n, n - lag)
        if lo1 < hi1:
            grad[lo1:hi1] += w * (1.0 - h[lo1 + lag:hi1 + lag])
        lo2 = max(0, lag)
        hi2 = min(n, n + lag)
        if lo2 < hi2:
            grad[lo2:hi2] += -w * h[lo2 - lag:hi2 - lag]
    return obj, grad * dx

def project_onto_constraint(h, target_sum):
    lo = -2.0
    hi = 2.0
    for _ in range(80):
        mid = (lo + hi) / 2.0
        p = np.clip(h - mid, 0.0, 1.0)
        if p.sum() > target_sum:
            lo = mid
        else:
            hi = mid
    return np.clip(h - (lo + hi) / 2.0, 0.0, 1.0)

def lbfgsb_single(h0, n, target_sum, tau, maxiter=300):
    def obj_fun(x):
        o, _ = smooth_obj_grad(x, tau)
        return o
    def grad_fun(x):
        _, g = smooth_obj_grad(x, tau)
        return g
    bounds = [(0.0, 1.0)] * n
    try:
        res = minimize(obj_fun, h0, jac=grad_fun, method='L-BFGS-B',
                       bounds=bounds,
                       options={'maxiter': maxiter, 'ftol': 1e-15, 'gtol': 1e-10,
                                'maxls': 100})
        if hasattr(res, 'x') and res.x is not None:
            h_opt = np.clip(res.x, 0.0, 1.0)
            h_opt = project_onto_constraint(h_opt, target_sum)
            return h_opt
    except Exception:
        pass
    return h0

def nested_lbfgsb(h0, n, target_sum, deadline, tau_seq=None):
    if tau_seq is None:
        tau_seq = [80.0, 40.0, 25.0, 15.0, 10.0, 7.0, 5.0, 4.0, 3.0]
    h = h0.copy()

        if time.time() > deadline - 10:
            break
        remaining = deadline - time.time()
        maxiter = min(400, max(30, int(remaining / (len(tau_seq) - i + 2))))
        h = lbfgsb_single(h, n, target_sum, tau, maxiter=maxiter)
    return h

def nesterov_pgd(h0, n, target_sum, deadline, tau=5.0, max_iter=20000):
    h = h0.copy()
    y = h.copy()
    best_h = h.copy()
    best_c5 = compute_c5(h)
    t_k = 1.0
    corr0 = np.correlate(h, 1.0 - h, mode="full")
    dx = 2.0 / n
    L_est = max(4.0 * np.max(np.abs(corr0)) * dx, 5.0)
    lr_base = 1.0 / L_est
    for it in range(max_iter):
        if time.time() > deadline:
            break
        t_new = (1.0 + np.sqrt(1.0 + 4.0 * t_k * t_k)) / 2.0
        lr = lr_base * 2.0 / (t_new + 1.0)
        _, grad = smooth_obj_grad(y, tau)
        y_new = y - lr * grad
        y_new = np.clip(y_new, 0.0, 1.0)
        y_new = project_onto_constraint(y_new, target_sum)
        beta = (t_k - 1.0) / t_new
        h_new = y_new + beta * (y_new - h)
        h_new = np.clip(h_new, 0.0, 1.0)
        h_new = project_onto_constraint(h_new, target_sum)
        h = h_new
        y = y_new
        t_k = t_new
        if it % 200 == 0:
            c5 = compute_c5(h)
            if c5 < best_c5:
                best_c5 = c5
                best_h = h.copy()

    return best_h, best_c5

        lo2 = max(0, lag)

            g[lo2:hi2] += -h[lo2 - lag:hi2 - lag]

            lo1 = max(0, -lag)
            hi1 = min(n, n - lag)
            if lo1 < hi1:
                g[lo1:hi1] += (1.0 - h[lo1 + lag:hi1 + lag])
            lo2 = max(0, lag)
            hi2 = min(n, n + lag)
            if lo2 < hi2:
                g[lo2:hi2] += -h[lo2 - lag:hi2 - lag]
        h_new = h - lr * g * dx / n_top
        h_new = project_onto_constraint(h_new, target_sum)

        if c5 < best_c5 - 1e-13:
            best_c5 = c5
            best_h = h_new.copy()
            h = h_new
            stale = 0

            h = h_new

def interpolate_h(h_old, n_new):
    n_old = len(h_old)
    if n_old == n_new:
        return h_old.copy()
    x_old = np.linspace(0, 2, n_old, endpoint=False)
    x_new = np.linspace(0, 2, n_new, endpoint=False)
    return np.interp(x_new, x_old, h_old)

def random_structured_init(n, target_sum, seed=None):
    rng = np.random.RandomState(seed)
    x = np.linspace(0, 2, n, endpoint=False)
    freq = rng.uniform(1.0, 6.0)
    phase = rng.uniform(0, 2 * np.pi)
    h = 0.5 + 0.35 * np.sin(2 * np.pi * freq * x + phase)
    h += 0.15 * rng.uniform(-1, 1, n)
    h = np.clip(h, 0, 1)
    return project_onto_constraint(h, target_sum)
