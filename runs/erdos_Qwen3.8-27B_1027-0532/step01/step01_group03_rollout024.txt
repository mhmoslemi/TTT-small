Let me also add a coordinate descent step, which can be very effective for this type of problem. For each coordinate j, we can compute the optimal value given all other coordinates fixed. This is a 1D optimization problem:

Given h with h[j] = t, the correlation at lag m is:
C_m = sum_{i≠j in valid range} h[i](1-h[i+m]) + (terms involving h[j])

The terms involving h[j] in C_m are:
- If j+m is valid: h[j](1-h[j+m]) = t(1-h[j+m]) → linear in t
- If j-m is valid: h[j-m](1-h[j]) = h[j-m](1-t) → linear in t

- B_m = (1-h[j+m]) * [j+m valid] - h[j-m] * [j-m valid]
- A_m = C_m - t_actual * B_m (where t_actual is the current value)
