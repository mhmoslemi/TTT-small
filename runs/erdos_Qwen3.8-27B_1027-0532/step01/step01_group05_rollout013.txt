     = δ * dx * B[k]

This is EXACT (no approximation), because g_k is bilinear in h (each term h[i]*(1-h[i+k]) is linear in each variable separately when the other is fixed).

Wait, is it? h[i]*(1-h[i+k]) = h[i] - h[i]*h[i+k]. The term h[i]*h[i+k] is bilinear. So g_k is NOT linear in h, it's a sum of bilinear terms.

But the PARTIAL derivative with respect to h[j] treating all other h as fixed IS:
∂g_k/∂h[j] = dx * [(1-h[j+k]) - h[j-k]] (with boundary conditions)

And the CHANGE in g_k when we change ONLY h[j] by δ (keeping all else fixed) is:
Δg_k = δ * dx * [(1-h[j+k]) - h[j-k]]

This is exact because g_k is linear in h[j] when all other variables are fixed.

Now, when we change BOTH h[j] and h[m]:
Δg_k = δ * ∂g_k/∂h[j] + (-δ) * ∂g_k/∂h[m] + (cross term)

The cross term: does changing h[j] affect ∂g_k/∂h[m] or vice versa?
∂g_k/∂h[m] = dx * [(1-h_ext[m+k]) - h_ext[m-k]]
This depends on h[m+k] and h[m-k]. If m+k = j (i.e., k = j-m), then h[m+k] = h[j] which we're also changing. So there IS a cross term!

The cross term for g_k when both h[j] and h[m] change:
The term h[j]*h[j+k] in g_k: if j+k = m, then this becomes h[j]*h[m], which changes by (h_old[j]+δ)*(h_old[m]-δ) - h_old[j]*h_old[m] = -h_old[j]*δ - h_old[m]*δ + δ²

Similarly, h[m]*h[m-k]: if m-k = j, i.e., k = m-j, then this is h[m]*h[j], which changes similarly.

And h[j]*h[j-k]: if j-k = m, i.e., k = j-m, same issue.
And h[m]*h[m+k]: if m+k = j, i.e., k = j-m, same issue.

So the cross terms only appear for k = j-m and k = m-j (at most 2 values of k). For all other k, the incremental update is exact.

For those 2 special k values, the error is O(δ²) which is negligible for small δ. So the incremental update is approximately correct, with error O(δ²) at most 2 lags.

Given that δ is typically very small (the golden section finds the optimum of a 1D problem, so δ is the optimal step), this error is negligible. And we recompute corr at the start of each sweep anyway.

def compute_c5(h, n):

def project_onto_constraint(h, n):

    lo, hi = -2.0, 2.0

        projected = np.clip(h - mid, 0.0, 1.0)
        if np.sum(projected) > target:
            lo = mid
        else:
            hi = mid
    return np.clip(h - (lo + hi) / 2.0, 0.0, 1.0)

def subgradient_polish(h, n, n_iter=500, top_k=1):
    h = h.copy().astype(float)
    best_h = h.copy()
    best_c5 = compute_c5(h, n)
    dx = 2.0 / n
    alpha = 0.1
    for it in range(n_iter):
        overlaps = np.correlate(h, 1.0 - h, mode="full") * dx
        idx = np.argmax(overlaps)
        lag = idx - (n - 1)
        grad = np.zeros(n)
        if lag >= 0:
            grad[lag:] += (1.0 - h[:n - lag])
            grad[:n - lag] += -h[lag:]
        else:
            l = -lag
            grad[:n - l] += (1.0 - h[l:])
            grad[l:] += -h[:n - l]
        grad *= dx
        h = h - alpha * grad
        h = project_onto_constraint(h, n)
        c5 = compute_c5(h, n)
        if c5 < best_c5:
            best_c5 = c5
            best_h = h.copy()
        alpha *= 0.999
    return best_h, best_c5

And overlap_k(h) = ∫h(x)*(1-h(x+k))dx

These are different in general. So 1-h is a different starting point.

Also, h(x+1) (shift by 1) might be interesting, but the domain is [0,2] so this needs care.

Let me include 1-h as one of the starting points.

import numpy as np
import time


def compute_c5(h, n):
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)


def project_onto_constraint(h, n):
    target = n / 2.0
    lo = -2.0
    hi = 2.0
    for _ in range(80):
        mid = (lo + hi) / 2.0
        projected = np.clip(h - mid, 0.0, 1.0)
        if np.sum(projected) > target:
            lo = mid
        else:
            hi = mid
    return np.clip(h - (lo + hi) / 2.0, 0.0, 1.0)


def subgradient_polish(h, n, n_iter=500):
    h = h.copy().astype(float)
    best_h = h.copy()
    best_c5 = compute_c5(h, n)
    dx = 2.0 / n
    alpha = 0.1
    for it in range(n_iter):
        overlaps = np.correlate(h, 1.0 - h, mode="full") * dx
        idx = np.argmax(overlaps)
        lag = idx - (n - 1)
        grad = np.zeros(n)
        if lag >= 0:
            grad[lag:] += (1.0 - h[:n - lag])
            grad[:n - lag] += -h[lag:]
        else:
            l = -lag
            grad[:n - l] += (1.0 - h[l:])
            grad[l:] += -h[:n - l]
        grad *= dx
        h = h - alpha * grad
        h = project_onto_constraint(h, n)
        c5 = compute_c5(h, n)
        if c5 < best_c5:
            best_c5 = c5
            best_h = h.copy()
        alpha *= 0.999
    return best_h, best_c5
