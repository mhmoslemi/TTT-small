∂f_s/∂h[k] = dx * [(1-h[k+s]) if 0≤k+s<n else 0] - dx * [h[k-s] if 0≤k-s<n else 0]

For the weighted sum over active lags:
g[k] = dx * sum_s w_s * [(1-h[k+s])_+ - h[k-s]_+]

where (x)_+ means x if the index is valid, else 0.

This can be computed efficiently:
- First part: for each valid offset s, add w_s * (1-h[k+s]) to g[k]

  - This is a convolution of h with w

            # h[k-s] = h[k+s2] is valid for k in [0, n-1-s2]

    return g

1. Compute the score and identify the worst lag s*
2. For lag s*, the overlap is f_{s*} = sum_i h[i](1-h[i+s*])
3. To reduce f_{s*}, we want to:

Let me think about a "conditional gradient" or "Frank-Wolfe" style approach:

At each step, find the direction d that most reduces the objective, then take a step in that direction.

The feasible set is {h : 0 ≤ h ≤ 1, sum(h) = n/2}. The extreme points of this set are vectors with exactly n/2 ones and n/2 zeros (for even n), or similar for odd n.

For the Frank-Wolfe method:
1. Given current h, find the extreme point v that minimizes <∇F, v - h>
2. t = argmin_{τ ∈ [0,1]} F(h + τ(v-h))
3. h ← h + t(v-h)

Finding the best extreme point v is itself a combinatorial problem, but we can approximate it by:
- v[i] = 1 if ∇F[i] < median, else 0 (approximately)

This is essentially the "conditional greedy" approach.

def project_feasible(h, target_sum):
    """Project h onto {0 <= h_i <= 1, sum(h) = target_sum} using bisection on shift."""
    h = np.asarray(h, dtype=float)
    n = len(h)
    # Bisection to find shift
    lo, hi = -2.0, 2.0
    for _ in range(80):
        mid = (lo + hi) / 2.0
        s = np.sum(np.clip(h - mid, 0.0, 1.0))
        if s > target_sum:
            lo = mid
        else:
            hi = mid

    # Fix residual
    diff = target_sum - np.sum(result)
    if abs(diff) > 1e-12:
        if diff > 0:
            order = np.argsort(result)
        else:

                result[idx] += add
                diff -= add
            else:
                sub = min(-diff, result[idx])
                result[idx] -= sub
                diff += sub

Actually, numpy's correlate is defined as:
output[k] = sum_n a[n] * v[n + k]

where the sum is over all n such that both n and n+k are valid indices.

For a=[1,0,0], v=[0,1,1], n=3:
