```python
def coord_descent_step(corr_full, h, j, n):
    # corr_full has length 2n-1, index k corresponds to lag k-(n-1)
    # Compute a[lag] = change in corr(lag) per unit change in h[j]
    # a[lag] = (1-h[j+lag]) if 0<=j+lag<n minus h[j-lag] if 0<=j-lag<n
    
    a = np.zeros(2*n-1)
    # First term: h[j] as the "first" variable
    # lag = k - (n-1), j+lag valid means 0 <= j+lag < n
    # lag ranges from -j to n-1-j
    lo1 = max(-(n-1), -j)
    hi1 = min(n-1, n-1-j)
    if lo1 <= hi1:
        lags = np.arange(lo1, hi1+1)
        a[lags + n - 1] += (1 - h[j+lags])
    
    # Second term: h[j] as the "second" variable (in 1-h[j-lag])
    # j-lag valid means 0 <= j-lag < n
    # lag ranges from j-(n-1) to j
    lo2 = max(-(n-1), j-(n-1))
    hi2 = min(n-1, j)
    if lo2 <= hi2:
        lags = np.arange(lo2, hi2+1)
        a[lags + n - 1] -= h[j-lags]
    
    # Now find optimal delta to minimize max(corr_full + delta * a)
    # subject to -h[j] <= delta <= 1-h[j]
    # Use a simple approach: evaluate at a few points
    L = -h[j]
    U = 1 - h[j]
    
    # The minimum of max(c + delta*a) over delta in [L,U]
    # Try: delta=0, delta=L, delta=U, and the point where the two
    # most restrictive constraints are tight
    candidates = [0.0, L, U]
    # Also try the "break-even" point if it exists
    # Find the pair (i,j) that determines the minimum
    # For now, use a coarse grid
    grid = np.linspace(L, U, 21)
    for d in grid:
        val = np.max(corr_full + d * a)
        candidates.append(d)
    
    best_val = np.inf
    best_d = 0.0
    for d in candidates:
        d = np.clip(d, L, U)
        val = np.max(corr_full + d * a)
        if val < best_val:
            best_val = val
            best_d = d
    
    return best_d, best_val
```

- Or at a point where two lines c_i + δ*a_i and c_j + δ*a_j cross, and this crossing value is the maximum

To find the minimum efficiently:

2. The maximum at δ=0 is c_max (at index k_max)
3. For δ > 0: lines with larger a_k will dominate. Find the upper envelope.
4. For δ < 0: lines with smaller a_k will dominate.

This is essentially computing the upper hull of a set of lines, which can be done in O(n log n).

**Simple effective approach: Coordinate descent with exact 1D line search**

The key advantage: much faster than SLSQP for large n, and can do thousands of iterations.

For each coordinate j:
1. Compute the "direction" a[k] = ∂corr[k]/∂h[j] for all k (O(n) work)
2. Find δ* = argmin_δ max_k (c[k] + δ*a[k]) subject to -h[j] ≤ δ ≤ 1-h[j]
3. Update h[j] += δ*

The line search in step 2: f(δ) = max_k(c[k] + δ*a[k]) is a convex piecewise-linear function. Its minimum can be found by:
- Computing the upper envelope of the lines {c[k] + δ*a[k]}
- Finding the minimum of this envelope over [L, U]

A practical approach: 
- At δ=0, the max is at the indices where c[k] is maximum
- For δ>0, lines with large a[k] will rise
- For δ<0, lines with small (negative) a[k] will rise

I can use a bisection on the subgradient:
- Subgradient of f at δ is the set {a[k] : c[k] + δ*a[k] = f(δ)}
- f is minimized when 0 is in the subgradient, i.e., when there exist k₁, k₂ with a[k₁] < 0 < a[k₂] and c[k₁] + δ*a[k₁] = c[k₂] + δ*a[k₂] = f(δ)

Or more simply: I'll use a ternary search on [L, U] since f is convex.

Ternary search requires O(n) per evaluation (to compute the max) and O(log((U-L)/ε)) iterations. With U-L ≤ 1 and ε = 1e-8, that's about 27 iterations, each O(n). Total: O(n log(1/ε)) per coordinate.

With n coordinates per pass, a full pass is O(n² log(1/ε)). For n=350: 350² * 27 ≈ 3.3 million operations. In numpy, this should be very fast (a few ms).

Wait, but I need to maintain the correlation array incrementally. When I update h[j] by δ, the correlation changes by δ*a (where a is the direction vector). So I just add δ*a to the correlation array. This is O(n) per update.

The total cost per pass is: n coordinates * (O(n) for computing a + O(n log(1/ε)) for line search) = O(n² + n² log(1/ε)) ≈ O(n² log(1/ε)).

For n=350: about 350² * 30 ≈ 3.7 million. With numpy vectorization, each "operation" is a vectorized call, so this should take maybe 100-200ms per pass. I can do 500-1000 passes in a few minutes.

    t0 = time.time()
    corr = np.correlate(h, 1.0 - h, mode="full").astype(float)
    n_lags = 2 * n - 1
    
    for p in range(max_passes):
        if time.time() - t0 > time_limit:
            break
        max_before = np.max(corr)
        
        for j in range(n):
            # Compute direction vector a for coordinate j
            a = np.zeros(n_lags)
            
            # Part 1: h[j] as the first factor h[i] where i=j
            # corr[k] = sum_i h[i] * (1-h[i+lag]), lag = k-(n-1)
            # h[j] appears when i=j: term is h[j]*(1-h[j+lag])
            # j+lag must be in [0, n-1]: -j <= lag <= n-1-j
            # k = lag + n-1: n-1-j <= k <= 2n-2-j
            k_start = max(0, n - 1 - j)
            k_end = min(n_lags - 1, 2 * n - 2 - j)
            if k_start <= k_end:
                idx = np.arange(k_start, k_end + 1) - (n - 1)  # lags
                a[k_start:k_end + 1] += (1.0 - h[j + idx])
            
            # Part 2: h[j] in (1-h[i+lag]) where i+lag=j, so i=j-lag
            # term is h[j-lag]*(1-h[j]), change is -h[j-lag]*delta
            # j-lag must be in [0, n-1]: j-n+1 <= lag <= j
            # k = lag + n-1: j <= k <= j+n-1
            k_start2 = max(0, j)
            k_end2 = min(n_lags - 1, j + n - 1)
            if k_start2 <= k_end2:
                idx2 = np.arange(k_start2, k_end2 + 1) - (n - 1)  # lags
                a[k_start2:k_end2 + 1] -= h[j - idx2]
            
            # Line search: min delta in [-h[j], 1-h[j]] of max(corr + delta*a)
            L = -h[j]
            U = 1.0 - h[j]
            if U - L < 1e-12:
                continue
            
            # Ternary search (30 iterations for good precision)
            lo, hi = L, U
            for _ in range(30):
                m1 = lo + (hi - lo) / 3.0
                m2 = hi - (hi - lo) / 3.0
                f1 = np.max(corr + m1 * a)
                f2 = np.max(corr + m2 * a)
                if f1 < f2:
                    hi = m2
                else:
                    lo = m1
            best_d = (lo + hi) / 2.0
            
            # Check if it's an improvement
            new_max = np.max(corr + best_d * a)
            if new_max < max_before - 1e-12:
                h[j] += best_d
                corr += best_d * a
                max_before = new_max
        
        # Periodic repair
        if (p + 1) % 20 == 0:
            h = repair_h(h, n)
            corr = np.correlate(h, 1.0 - h, mode="full").astype(float)
    
    h = repair_h(h, n)
    return h, evaluate_c5(h)

def _sum_con_fun(x):
    return np.sum(x) - _target_sum

def _sum_con_jac(x):
    return np.ones(len(x))

def _softmax_obj(x):
    n = _soft_n
    beta = _soft_beta
    dx = 2.0 / n
    corr = np.correlate(x, 1.0 - x, mode="full") * dx
    scaled = beta * corr
    m = np.max(scaled)
    return float((m + np.log(np.sum(np.exp(scaled - m)))) / beta)

def evaluate_c5(h):
    n = len(h)
    dx = 2.0 / n

    return float(np.max(corr) * dx)

def repair_h(h, n):
    h = np.clip(h, 0.0, 1.0).astype(float).copy()
    target = n / 2.0
    for _ in range(50):

        if abs(diff) < 1e-12:

            cnt = mask.sum()
            if cnt == 0:

        else:

            cnt = mask.sum()
            if cnt == 0:

        else:
            src = h_interp
        remaining = budget_s - (time.time() - t0)
        if remaining > 60:
            limit = min(remaining * 0.3, 120.0)
            h5, c5_5 = coord_descent(src, n_new, max_passes=1500, time_limit=limit)
            if c5_5 < best_c5:
                best_h, best_c5 = h5, c5_5

    n_best = len(best_h)
    for attempt in range(6):
        remaining = budget_s - (time.time() - t0)
        if remaining < 60:
            break
        starts = generate_starts(best_h, n_best, _rng_global)
        for h_s in starts:
            remaining = budget_s - (time.time() - t0)
            if remaining < 30:
                break
            limit = min(remaining * 0.2, 60.0)
            h6, c5_6 = coord_descent(h_s, n_best, max_passes=800, time_limit=limit)
            if c5_6 < best_c5:
                best_h, best_c5 = h6, c5_6

    n_best = len(best_h)
    remaining = budget_s - (time.time() - t0)
    if remaining > 40:
        h7, c5_7 = block_local_search(best_h, n_best, time_limit=min(remaining * 0.3, 40.0))
        if c5_7 < best_c5:
            best_h, best_c5 = h7, c5_7

    remaining = budget_s - (time.time() - t0)
    if remaining > 30:
        h8, c5_8 = slsqp_opt(best_h, len(best_h), maxiter=1500)
        if c5_8 < best_c5:
            best_h, best_c5 = h8, c5_8

    remaining = budget_s - (time.time() - t0)
    if remaining > 15:
        limit = max(5.0, remaining - 5.0)
        h9, c5_9 = coord_descent(best_h, len(best_h), max_passes=1000, time_limit=limit)
        if c5_9 < best_c5:
            best_h, best_c5 = h9, c5_9

    best_h = repair_h(best_h, len(best_h))
    best_c5 = evaluate_c5(best_h)
    return best_h, best_c5, len(best_h)
