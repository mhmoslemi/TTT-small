        if no_improve > 50:

Let me think about a different approach: **use the gradient to do a line search**.

For a given direction d (the negative gradient), find the best step size α that minimizes f(x + α*d) subject to feasibility. Since f is the max of bilinear functions, f(x + α*d) is not convex in α (because the bilinear terms become quadratic in α). But for small α, it's approximately linear, so we can use Armijo backtracking.

Actually, let me just go with a practical approach that's likely to work well:

1. **SLSQP with SMAC-style adaptive temperature**: Instead of a fixed schedule, monitor the improvement and adjust T dynamically.
2. **Pairwise coordinate descent**: After SLSQP, do pairwise optimization.
3. **Resolution increase**: Upsample the solution and re-optimize.

For the pairwise coordinate descent, here's a cleaner formulation:

For pair (i, j) with i ≠ j, consider the transfer h[i] → h[j] with amount δ:
- New h': h'[i] = h[i] - δ, h'[j] = h[j] + δ, h'[k] = h[k] for k ≠ i,j
- Feasibility: max(0, h[j]-1) ≤ δ ≤ min(h[i], 1-h[j])
  Wait: h[i]-δ ≥ 0 → δ ≤ h[i]; h[j]+δ ≤ 1 → δ ≤ 1-h[j]; δ ≥ 0.
  So δ ∈ [0, min(h[i], 1-h[j])]

The objective: f(δ) = max_k c_k(δ) where c_k(δ) = c_k(0) + δ * (∂c_k/∂h_j - ∂c_k/∂h_i)

Let d_k = ∂c_k/∂h_j - ∂c_k/∂h_i. Then f(δ) = max_k (c_k(0) + d_k * δ).

This is a convex piecewise-linear function of δ. Its minimum over [0, δ_max] is at:
- δ = 0 if f is decreasing at 0 (i.e., all active d_k ≤ 0... wait no, if f is decreasing, we want to increase δ)
- Actually, f(δ) = max_k (a_k + b_k * δ) where a_k = c_k(0), b_k = d_k.
- The minimum is where the subgradient contains 0, i.e., where there exist active constraints with b_k < 0 and b_k > 0.
- Equivalently, it's the point where the "knee" of the upper envelope occurs.

To find it efficiently: we can sort the breakpoints. The upper envelope changes at points where two lines cross: a_k + b_k * δ = a_l + b_l * δ → δ = (a_l - a_k)/(b_k - b_l).

But this is O(n^2 log n) per pair, which is too expensive for all O(n^2) pairs.

Simpler approach: ternary search on δ ∈ [0, δ_max]. Since f is convex (as max of linear functions), ternary search works.

But actually, for the convex piecewise-linear case, we can do binary search on the subgradient:
- Compute f'(δ) (the subgradient, which is the set of slopes of active constraints).
- If all active slopes > 0, decrease δ.
- If all active slopes < 0, increase δ.
- Otherwise, we're at the minimum.

In practice, we can just evaluate f at a few points (say, 10 evenly spaced) and pick the best. Since f is convex, this gives a good approximation.

Let me think about the computational budget for pairwise CD:
- n=85, so n^2/2 ≈ 3600 pairs.
- For each pair, evaluating f at 10 points requires computing the full correlation each time (O(n)) if we update only 2 elements.
- Actually, we can compute c_k(δ) for all k in O(n) given c_k(0) and d_k.
- Computing d_k for all k is O(n) (since it's just the difference of two gradient vectors at positions i and j).
- So per pair: O(n) to compute d_k, O(n * num_evals) to find best δ.
- Total: O(n^3 * num_evals) = O(85^3 * 10) ≈ 6 million operations per full sweep.
- That's fast enough.

But we only want to evaluate pairs where an improvement is likely. We can filter:
- Only consider pairs where h[i] > 0.3 and h[j] < 0.7 (or similar).

import numpy as np
from scipy.optimize import minimize
import time

def score_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def project_feasible(x, n):
    target = n / 2.0
    lo = -10.0
    hi = 10.0
    for _ in range(80):
        mid = (lo + hi) / 2.0
        proj = np.clip(x - mid, 0.0, 1.0)
        s = proj.sum()
        if s > target:
            lo = mid
        else:
            hi = mid
    lam = (lo + hi) / 2.0
    return np.clip(x - lam, 0.0, 1.0)

def smooth_obj(h, T, n):
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    cmax = corr.max()
    scaled = (corr - cmax) / T
    vals = np.exp(scaled)
    return dx * (cmax + T * np.log(vals.sum()))

def smooth_grad(h, T, n):
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    cmax = corr.max()
    scaled = (corr - cmax) / T
    exp_scaled = np.exp(scaled)
    w = exp_scaled / exp_scaled.sum()
    grad = np.zeros(n)
    for r in range(2 * n - 1):
        wk = w[r]
        if wk < 1e-14:
            continue
        k = r - (n - 1)
        if k >= 0:
            grad[:n-k] += wk * (1.0 - h[k:])
            grad[k:] -= wk * h[:n-k]
        else:
            kp = -k
            grad[kp:] += wk * (1.0 - h[:n-kp])
            grad[:n-kp] -= wk * h[kp:]
    return dx * grad

def sum_con(x):
    return x.sum() - len(x) / 2.0

def sum_con_jac(x):
    return np.ones(len(x))

def slsqp_step(h, T, n, max_iter):
    def obj(x):
        return smooth_obj(x, T, n)
    def jac(x):
        return smooth_grad(x, T, n)
    try:
        res = minimize(obj, h, jac=jac, method='SLSQP',
                       bounds=[(0.0, 1.0)] * n,
                       constraints=[{'type': 'eq', 'fun': sum_con, 'jac': sum_con_jac}],
                       options={'maxiter': max_iter, 'ftol': 1e-12})
        if res.success or res.x is not None:
            x_new = project_feasible(res.x, n)
            return x_new, score_c5(x_new)
    except Exception:
        pass
    return h, score_c5(h)

def pairwise_cd(h, n, t0, deadline, max_sweeps=100):
    best = h.copy()
    best_score = score_c5(best)
    cx = 2.0 / n
    for sweep in range(max_sweeps):
        if time.time() - t0 > deadline:
            break
        improved = False
        # Get current correlation
        corr = np.correlate(best, 1.0 - best, mode='full')
        for i in range(n):
            if time.time() - t0 > deadline:
                break
            if best[i] < 1e-10:
                continue
            for j in range(n):
                if i == j:
                    continue
                if best[j] > 1.0 - 1e-10:
                    continue
                # Compute d_k = dc_k/dh_j - dc_k/dh_i for all k
                # dc_k/dh_i for shift k:
                #   if k >= 0: (1-h_{i+k})*[i<=n-1-k] - h_{i-k}*[i>=k]
                #   if k < 0: (1-h_{i+kp})*[i>=kp] - h_{i+kp}*[i<=n-1-kp] where kp=-k
                # Similarly for j.
                # This is O(n) per pair, giving O(n^3) total per sweep.
                # For n=85, that's about 600K ops per sweep - fine.
                
                # Let's compute the gradient contributions for i and j
                # grad_i[r] = dc_{k(r)}/dh_i, where k(r) = r - (n-1)
                # grad_j[r] = dc_{k(r)}/dh_j
                # d[r] = grad_j[r] - grad_i[r]
                
                # For efficiency, precompute the gradient vectors for i and j
                gi = np.zeros(2 * n - 1)
                gj = np.zeros(2 * n - 1)
                for r in range(2 * n - 1):
                    k = r - (n - 1)
                    if k >= 0:
                        # dc_k/dh_p = (1-h_{p+k})*[p<=n-1-k] - h_{p-k}*[p>=k]
                        contrib_i = 0.0
                        if i <= n - 1 - k:
                            contrib_i += (1.0 - best[i + k])
                        if i >= k:
                            contrib_i -= best[i - k]
                        contrib_j = 0.0
                        if j <= n - 1 - k:
                            contrib_j += (1.0 - best[j + k])
                        if j >= k:
                            contrib_j -= best[j - k]
                    else:
                        kp = -k
                        contrib_i = 0.0
                        if i >= kp:
                            contrib_i += (1.0 - best[i - kp])
                        if i <= n - 1 - kp:
                            contrib_i -= best[i + kp]
                        contrib_j = 0.0
                        if j >= kp:
                            contrib_j += (1.0 - best[j - kp])
                        if j <= n - 1 - kp:
                            contrib_j -= best[j + kp]
                    gi[r] = contrib_i
                    gj[r] = contrib_j
                d = gj - gi  # d[r] = dc_k/dh_j - dc_k/dh_i
                # c_k(δ) = corr[r] + d[r] * δ
                # f(δ) = max_r (corr[r] + d[r] * δ)
                # δ ∈ [0, min(best[i], 1-best[j])]
                delta_max = min(best[i], 1.0 - best[j])
                if delta_max < 1e-12:
                    continue
                # Binary search for optimum of convex PWL function
                # Subgradient at δ: sum of d[r] for r achieving the max
                # Simpler: evaluate at a few points
                best_delta = 0.0
                best_f = score_c5(best)  # current value (δ=0)
                # Try some candidate deltas
                candidates = [delta_max * t / 8.0 for t in range(1, 9)]
                # Also try the "optimal" point via subgradient zeroing
                for delta in candidates:
                    trial = best.copy()
                    trial[i] -= delta
                    trial[j] += delta
                    s = score_c5(trial)
                    if s < best_f:
                        best_f = s
                        best_delta = delta
                # Also try a few more around the best
                if best_delta > 0:
                    for frac in [0.7, 0.8, 0.9, 1.0, 1.1, 1.2, 1.3, 1.5]:
                        delta = best_delta * frac
                        if delta > delta_max:
                            continue
                        trial = best.copy()
                        trial[i] -= delta
                        trial[j] += delta
                        s = score_c5(trial)
                        if s < best_f:
                            best_f = s
                            best_delta = delta
                if best_f < best_score - 1e-12 and best_delta > 0:
                    best[i] -= best_delta
                    best[j] += best_delta
                    best_score = best_f
                    improved = True
                    corr = np.correlate(best, 1.0 - best, mode='full')
        if not improved:
            break
    return best, best_score

_CURRENT_T = 1.0
_CURRENT_N = 0


def score_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)


def project_feasible(x, n):
    target = n / 2.0
    lo = -10.0
    hi = 10.0
    for _ in range(80):
        mid = (lo + hi) / 2.0
        proj = np.clip(x - mid, 0.0, 1.0)
        s = proj.sum()
        if s > target:
            lo = mid
        else:
            hi = mid
    lam = (lo + hi) / 2.0
    return np.clip(x - lam, 0.0, 1.0)


def smooth_obj_fn(h, T, n):
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    cmax = corr.max()
    scaled = (corr - cmax) / T
    vals = np.exp(scaled)
    return float(dx * (cmax + T * np.log(vals.sum())))


def smooth_grad_fn(h, T, n):
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    cmax = corr.max()
    scaled = (corr - cmax) / T
    exp_scaled = np.exp(scaled)
    w = exp_scaled / exp_scaled.sum()
    grad = np.zeros(n)
    for r in range(2 * n - 1):
        wk = w[r]
        if wk < 1e-14:
            continue
        k = r - (n - 1)
        if k >= 0:
            grad[:n - k] += wk * (1.0 - h[k:])
            grad[k:] -= wk * h[:n - k]
        else:
            kp = -k
            grad[kp:] += wk * (1.0 - h[:n - kp])
            grad[:n - kp] -= wk * h[kp:]
    return dx * grad


def _obj(x):
    return smooth_obj_fn(x, _CURRENT_T, _CURRENT_N)


def _jac(x):
    return smooth_grad_fn(x, _CURRENT_T, _CURRENT_N)

    return x.sum() - _CURRENT_N / 2.0


def _sum_con_jac(x):
    return np.ones(_CURRENT_N)

    _CURRENT_N = n

        res = minimize(_obj, h, jac=_jac, method='SLSQP',

            lr *= 0.7
            no_improve = 0
        if step % 5000 == 0 and step > 0:
            T = max(T * 0.5, 0.001)
    return best, best_score


def try_resolution(h_start, n_new, rng, t0, deadline):
    global _CURRENT_T, _CURRENT_N
    h = np.repeat(h_start, n_new // len(h_start))
    h = project_feasible(h, n_new)
    for T in [0.5, 0.1, 0.03, 0.01]:
        if time.time() - t0 > deadline:
            break
        _CURRENT_T = T
        _CURRENT_N = n_new
        x_new, s_new = slsqp_opt(h, T, n_new, 3000)
        if s_new < score_c5(h):
            h = x_new
    if time.time() - t0 < deadline:
        h, s = pairwise_cd(h, n_new, t0, deadline)
    return h, score_c5(h)


def run(seed=42, budget_s=1300, **kwargs):
    global _CURRENT_T, _CURRENT_N
    rng = np.random.RandomState(seed)
    t0 = time.time()

    if 'initial_h_values' in globals() and initial_h_values is not None:
        h = np.array(initial_h_values, dtype=float).copy()
    else:
        h = rng.random(85)

    n = len(h)
    h = project_feasible(h, n)
    best_h = h.copy()
    best_c5 = score_c5(best_h)

    deadline1 = t0 + budget_s * 0.25
    temps = [1.5, 0.8, 0.4, 0.2, 0.1, 0.05, 0.03, 0.015, 0.01]
    for T in temps:
        if time.time() - t0 > deadline1:
            break
        x_new, s_new = slsqp_opt(best_h, T, n, 4000)
        if s_new < best_c5:
            best_c5 = s_new
            best_h = x_new.copy()

    deadline2 = t0 + budget_s * 0.65
    best_h, best_c5 = pairwise_cd(best_h, n, t0, deadline2)

    deadline3 = t0 + budget_s * 0.75
    if time.time() - t0 < deadline3:
        best_h, best_c5 = subgradient_polish(best_h, n, t0, deadline3)

    if time.time() - t0 < t0 + budget_s * 0.80:
        x_new, s_new = slsqp_opt(best_h, 0.005, n, 3000)
        if s_new < best_c5:
            best_c5 = s_new
            best_h = x_new.copy()

    deadline4 = t0 + budget_s * 0.93
    if time.time() - t0 < deadline4:
        for n_try in [102, 128, 170]:
            if time.time() - t0 > deadline4:
                break
            tl = deadline4 - (time.time() - t0)
            if tl < 30:
                break
            h_try, s_try = try_resolution(best_h, n_try, rng, t0, t0 + tl)
            if s_try < best_c5:
                best_c5 = s_try
                best_h = h_try.copy()

    if time.time() - t0 < t0 + budget_s * 0.97:
        n = len(best_h)
        x_new, s_new = slsqp_opt(best_h, 0.003, n, 2000)
        if s_new < best_c5:
            best_c5 = s_new
            best_h = x_new.copy()
        best_h, best_c5 = pairwise_cd(best_h, len(best_h), t0, t0 + budget_s * 0.99)

    best_h = project_feasible(best_h, len(best_h))
    best_c5 = score_c5(best_h)
    return best_h, best_c5, len(best_h)
