**Key mathematical insight**: The problem has a connection to "Golay sequences" and "complementary sets" in signal processing. A pair of sequences (a, b) is complementary if a's autocorrelation + b's autocorrelation = delta (zero for all non-zero lags).

In our problem, we're looking at h's correlation with (1-h). Let g = 1-h. Then:
- h + g = 1 (pointwise)
- ∫h = 1, so ∫g = 2-1 = 1
- C₅ = max_k ∫ h(x)g(x+k) dx

We want to minimize max_k ∫ h(x)g(x+k) dx.

The "complementary" condition would be ∫ h(x)g(x+k) dx = 0 for all k ≠ 0, which is impossible (since at k=0, ∫h·g = ∫h(1-h) > 0).

But we can try to make the cross-correlation as "flat" as possible (close to its average value) for k ≠ 0.

The average value of ∫ h(x)g(x+k) dx over all k (in the periodic extension) is (∫h)(∫g)/(period) = 1*1/2 = 1/2.

Wait, that doesn't seem right for the non-periodic case. Let me think differently.

For the periodic extension (period 2):
(1/2) ∫₀² h(x)g(x+k) dx should average to (1/2)(∫h)(∫g)/2 = (1/2)(1)(1)/2 = 1/4.

So we want the cross-correlation to be close to 1/4 for all k, and the maximum to be as close to 1/4 as possible. This would give C₅ ≈ 1/4 = 0.25.

But wait, at k=0: ∫h(x)g(x) dx = ∫h(1-h) dx = 1 - ∫h². For h binary (values 0 and 1), this is 0. For h=0.5, this is 0.5. So the value at k=0 can range from 0 to 0.5.

If h is binary, the cross-correlation at k=0 is 0, and at other k it's some positive value. The minimum possible maximum is what we're looking for.

For a "perfect" complementary pair (h, g) where h+g=1:
- We'd want ∫h(x)g(x+k) dx = c (constant) for all k
- At k=0: c = ∫h(1-h) dx
- The average over all k (circular, period 2) is (∫h)(∫g)/2 = 1/4
- So c = 1/4, meaning ∫h(1-h) = 1/4, which means ∫h² = 3/4.

For h taking values in [0,1] with ∫h=1 over [0,2]:
∫h² = 3/4 is achievable (e.g., h takes value a on a set of measure m and b on measure 2-m, with ma+(2-m)b=1 and ma²+(2-m)b²=3/4).

If h is binary (0 or 1): ∫h² = ∫h = 1. So at k=0, the cross-correlation is 0.
The question is: what's the minimum possible max of the cross-correlation at other lags?

For a binary h with ∫h=1 (i.e., h=1 on a set of measure 1):
∫h(x)g(x+k) dx = ∫h(x)(1-h(x+k)) dx = measure({x: h(x)=1, h(x+k)=0})

Let S = {x: h(x)=1}, |S|=1.
Then we want to minimize max_k |S \ (S-k)| where S-k = {x: x+k ∈ S}.

|S \ (S-k)| = |S| - |S ∩ (S-k)| = 1 - |S ∩ (S-k)|

So C₅ = 1 - min_k |S ∩ (S-k)|.

We want to maximize min_k |S ∩ (S-k)| over all measurable S ⊂ [0,2] with |S|=1.

This is a classical problem in additive combinatorics / geometric measure theory!

The maximum of min_k |S ∩ (S-k)| is related to the "difference set" of S.

If S is an interval of length 1 (say [0,1]), then:
|S ∩ (S-k)| = |[-k, 1-k] ∩ [0,1]| = 1-|k| for |k|≤1, 0 for |k|>1.
min_k = 0 (for k>1). So C₅ = 1. Bad.

If S is "spread out" evenly (like a union of many small intervals), the autocorrelation decays slowly.

The optimal S for maximizing min_k |S ∩ (S-k)| is related to "Kakeya sets" or more precisely to sets with "maximal difference set coverage."

Actually, this is exactly the problem of finding a set S of measure 1 in a space of measure 2 that maximizes the minimum autocorrelation. By the uncertainty principle / Fourier analysis:

If 1_S has Fourier transform Ẇ(ξ), then the autocorrelation is the inverse Fourier transform of |Ẇ(ξ)|².

To make the autocorrelation as flat as possible (large minimum), we want |Ẇ(ξ)|² to be as concentrated as possible at ξ=0. But by the uncertainty principle, we can't concentrate it too much without making S large.

For a set of measure 1 in a space of measure 2, the "optimal" Fourier concentration gives an autocorrelation that's approximately uniform at about 1/4 (the mean), with some deviation.

                   bounds=bnds, constraints=cons,
                   options={'maxiter': maxiter, 'ftol': 1e-15})
    return repair_h(res.x, n) if res.x is not None else h0

def run_lbfgsb(h0, n, dx, beta, pen, maxiter):

                   bounds=bnds, options={'maxiter': maxiter, 'ftol': 1e-15})
    return repair_h(res.x, n) if res.x is not None else h0

    xs = np.linspace(0, 2, n_src, endpoint=False)
    xd = np.linspace(0, 2, n_dst, endpoint=False)
    return np.interp(xd, xs, h_src)

def subgrad_step(h, n, dx, lr, topk):
    corr = c5_all(h, dx)
    idx = np.argsort(-corr)[:topk]
    grad = np.zeros(n)
    for p in idx:
        lag = p - (n - 1)
        if lag == 0:
            grad += dx * (1.0 - 2.0 * h)
        elif lag > 0:
            g = np.zeros(n)
            g[:n-lag] += 1.0 - h[lag:]
            g[lag:] += -h[:n-lag]
            grad += dx * g

            g = np.zeros(n)
            g[L:] += 1.0 - h[:n-L]
            g[:n-L] += -h[L:]
            grad += dx * g
    grad /= topk
    h_new = repair_h(h - lr * grad, n)
