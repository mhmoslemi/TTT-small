**Bisection on the subgradient**: 
The subgradient of g(δ) = max_k (a_k + b_k*δ) at δ is b_{k*} where k* is the argmax (or any convex combination of b_{k*} for tied argmaxes).

1. Find k1 = argmax_k (a_k + b_k*L) (value at left boundary)
2. Find k2 = argmax_k (a_k + b_k*U) (value at right boundary)
3. If b_{k1} ≤ 0 and b_{k2} ≥ 0: the minimum is somewhere in between.

4. If the function is decreasing at L and increasing at U, the minimum is in the interior. We can find it by:
   - Start with δ = L. The active constraint is k1 (argmax at L).
   - Increase δ until k1 is no longer the argmax (i.e., until a_k1 + b_k1*δ = max_k (a_k + b_k*δ)).
   - The next active constraint becomes the new "leading" line.
   - Continue until the active constraint has non-negative slope.

This is like "walking" along the upper envelope. The number of steps is at most the number of lines, so O(n) in the worst case, but typically much less.

def find_optimal_delta(a, b, L, U):
    # Minimize max_k (a[k] + b[k]*delta) for delta in [L, U]
    # a, b are arrays of length m
    # Returns optimal delta and the optimal value
    
    # Check boundaries
    val_L = np.max(a + b * L)
    val_U = np.max(a + b * U)
    
    # Subgradient at L
    active_L = np.where(a + b * L == val_L)[0]
    if np.all(b[active_L] >= 0):
        return L, val_L  # minimum at L
    
    # Subgradient at U
    active_U = np.where(a + b * U == val_U)[0]
    if np.all(b[active_U] <= 0):
        return U, val_U  # minimum at U
    
    # Walk along upper envelope from L
    delta = L
    for _ in range(len(a) * 2):  # at most O(n) steps
        val = np.max(a + b * delta)
        active = np.where(a + b * delta == val)[0]
        # Find the smallest b among active (most negative slope)
        b_min = np.min(b[active])
        b_max = np.max(b[active])
        if b_min >= 0:
            break  # at optimum (subgradient contains 0)
        # All active have negative slope, need to move right
        # Find next breakpoint: where a non-active line crosses val
        # The next line to become active is the one that reaches val first
        # For line i: a[i] + b[i]*delta' = val → delta' = (val - a[i]) / b[i] (if b[i] > 0)
        # We want the smallest such delta' > delta
        candidates = []
        for i in range(len(a)):
            if b[i] > 0 and i not in active:
                dp = (val - a[i]) / b[i]
                if dp > delta + 1e-15:
                    candidates.append(dp)
        if not candidates:
            break
        delta = min(max(candidates), U)
    
    return delta, np.max(a + b * delta)

    delta = float(np.clip(delta, L, U))
    return delta, hi
