The correlation is a quadratic form: corr[k] = Σ_i h[i] - Σ_i h[i]h[i+k]

This is equivalent to: n/2 - min_k Q_k(h).

So we want to maximize min_k Q_k(h).

This is a max-min problem. We can write it as:
max_t { t : Q_k(h) ≥ t ∀ k, 0 ≤ h ≤ 1, Σh = n/2 }

The constraints Q_k(h) ≥ t are quadratic (not convex in general). But if we fix t, the feasible set {h : Q_k(h) ≥ t ∀ k} is the intersection of superlevel sets of quadratic forms, which is generally non-convex.

**Approach: Subgradient method for the max**

The function f(h) = max_k f_k(h) where f_k(h) = Σ_i h[i](1-h[i+k]) is the max of bilinear functions. Its subgradient (at points where the max is unique) is the gradient of the active f_k.

We can use a projected subgradient method:
1. Compute corr = np.correlate(h, 1-h, 'full')
2. Find active lags: A = {k : corr[k] ≥ corr_max - ε}
3. Compute the average gradient over active lags
4. Take a step in the negative gradient direction
5. Project onto the feasible set {0 ≤ h ≤ 1, Σh = n/2}

The projection onto {0 ≤ h ≤ 1, Σh = n/2} can be done efficiently (it's the Euclidean projection onto a hypercube intersected with a hyperplane).

This is essentially a form of Frank-Wolfe or projected gradient descent.

Let me implement this:

```python
def projected_subgradient_step(h, step_size, n_active=5):
    """One step of projected subgradient descent on max_k corr[k]."""
    corr = compute_corr(h)
    corr_max = np.max(corr)
    
    # Find active lags
    active_mask = corr >= corr_max - 0.01 * corr_max
    active_idx = np.where(active_mask)[0]
    
    # Compute gradient of avg of active corr[k]
    # corr[k] = sum_i h[i]*(1-h[i+k-(n-1)])
    # d corr[k] / d h[j] = (1-h[j+k-(n-1)]) - h[j-(n-1-k)] (for valid indices)
    # This is complex; let's use automatic differentiation conceptually
    
    # Actually, for the correlation:
    # corr_full[k] = sum_{i} h[i] * (1-h[i + k - (n-1)])
    # Let l = k - (n-1) be the actual lag
    # corr_full[n-1+l] = sum_{i=max(0,-l)}^{min(n-1, n-1-l)} h[i] * (1-h[i+l])
    
    # d corr[n-1+l] / d h[j] = (1-h[j+l]) * 1_{j+l valid} - h[j-l] * 1_{j-l valid}
    # (the first term is from h[j] being the left factor, the second from h[j] being the right factor in 1-h)
    
    # For the average over active lags:
    # grad[j] = (1/|A|) * sum_{l in active_lags} [(1-h[j+l]) * 1_{0<=j+l<n} - h[j-l] * 1_{0<=j-l<n}]
    
    n = len(h)
    grad = np.zeros(n)
    active_lags = active_idx - (n - 1)  # Convert to actual lags
    
    for l in active_lags:
        # (1-h[j+l]) for valid j+l
        if l >= 0:
            valid_j = slice(0, n - l)
            grad[valid_j] += (1 - h[l:])
        else:
            valid_j = slice(-l, n)
            grad[valid_j] += (1 - h[:n+l])
        # -h[j-l] for valid j-l
        if l >= 0:
            valid_j = slice(l, n)
            grad[valid_j] -= h[:n-l]
        else:
            valid_j = slice(0, n+l)
            grad[valid_j] -= h[-l:]
    
    grad /= len(active_lags)
    
    # Step
    h_new = h - step_size * grad
    h_new = project_feasible(h_new, n / 2.0)
    return h_new
```

This is O(n * |A|) per step, which is fast. We can take many steps.

`c_k = sum_n a_{n+k} * conj(v_n)`

So `np.correlate(a, v, mode='full')` gives:

For our case: a = h, v = 1-h

This is the cross-correlation of h and (1-h) at lag k (where k can be negative).
