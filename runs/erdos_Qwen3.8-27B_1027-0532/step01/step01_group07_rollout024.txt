    Part2 = M2.dot(h)

The key question is: **what is the structure of the optimal solution?**

For the Erdős C₅ problem, the constant C₅ is related to the maximum overlap of a set with its translates. The optimal h should be "as anti-correlated as possible" with all its shifts.

A key insight: if h is a step function (0 or 1 everywhere), then h(x+k) is either 0 or 1, and h(x)(1-h(x+k)) is either 0 or h(x). The overlap integral becomes the measure of the set where h=1 and h(x+k)=0.

For a step function with a single transition at x=a: h = 1 on [0,a], 0 on [a,2].
Then h(x)(1-h(x+k)) is 1 when x ∈ [0,a] and x+k ∈ [a,2], i.e., x ∈ [max(0,a-k), min(a, 2-k)].
The integral is the length of this interval.

For k > 0: the interval is [a-k, min(a,2-k)] (if a > k and 2-k > a-k)
Length = min(a, 2-k) - (a-k) = min(k, 2-a)

For k < 0 (let k = -m, m > 0): the interval is [a, min(a+m, 2)]
Length = min(a+m, 2) - a = min(m, 2-a)

So C₅ for this step function = max(

max_{m>0} min(m, 2-a), max_{m>0} min(m, a)
) = max(2-a, a) = max(a, 2-a)

This is minimized at a=1, giving C₅ = 1. That's terrible.

So a single step is no good. We need a more complex structure.
