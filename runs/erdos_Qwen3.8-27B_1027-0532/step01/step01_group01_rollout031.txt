def project_feasible(x, n):
    target = n / 2.0

One more idea: **Lagrangian relaxation / dual approach**

The problem is:
minimize max_k f_k(h)
subject to g(h) = 0 (sum constraint)
         h ∈ [0,1]^n

We can write this as:
minimize t
subject to f_k(h) ≤ t ∀k
         g(h) = 0
         h ∈ [0,1]^n

The Lagrangian is:
L(h, t, λ, μ) = t + Σ_k λ_k (f_k(h) - t) + μ(g(h))
= t(1 - Σ_k λ_k) + Σ_k λ_k f_k(h) + μ(sum(h) - n/2)

At the optimum, 1 - Σ_k λ_k = 0, i.e., Σ_k λ_k = 1. So we can normalize: λ_k are probabilities.

Then the subproblem is:
minimize_h Σ_k λ_k f_k(h) + μ(sum(h) - n/2)
subject to h ∈ [0,1]^n

This is a quadratic minimization (since f_k is quadratic in h). With the constraint sum(h) = n/2 fixed, it becomes:
minimize_h Σ_k λ_k f_k(h)
subject to h ∈ [0,1]^n, sum(h) = n/2

The objective Σ_k λ_k f_k(h) = Σ_k λ_k Σ_i h[i](1-h[i+k])
= Σ_i h[i] Σ_k λ_k (1-h[i+k])
= n/2 - Σ_i h[i] Σ_k λ_k h[i+k]  (using sum(h) = n/2)

Wait, that's not quite right. Let me be more careful.

Σ_k λ_k f_k(h) = Σ_k λ_k Σ_{i valid for k} h[i](1-h[i+k])

This is a quadratic function in h. The Hessian is:
H_{ij} = -Σ_k λ_k (δ_{i,j+k} + δ_{i,j-k}) / dx ... (something like that)

The point is that for fixed λ, the subproblem is a quadratic program (QP), which can be solved efficiently (even though it's non-convex, we can use local methods).

The outer loop updates λ based on which constraints are violated (similar to the multiplicative weights approach I mentioned earlier).

This is essentially the "Frank-Wolfe" or "cutting plane" approach to min-max problems.
