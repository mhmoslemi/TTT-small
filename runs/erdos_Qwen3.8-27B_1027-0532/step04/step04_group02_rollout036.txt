```python
def compute_swap_delta(h, i, j, n):
    """Compute change in full correlation when flipping h[i] 1->0 and h[j] 0->1."""
    delta = np.zeros(2*n-1)
    # h_old[i]=1, h_old[j]=0, h_new[i]=0, h_new[j]=1
    
    for s in range(-(n-1), n):
        # Valid range for m: max(0, -s) <= m <= min(n-1, n-1-s)
        m_lo = max(0, -s)
        m_hi = min(n-1, n-1-s)
        
        affected = []
        for m_cand in [i, j, i-s, j-s]:
            if m_lo <= m_cand <= m_hi:
                affected.append(m_cand)
        
        # Remove duplicates
        affected = list(set(affected))
        
        total_delta = 0.0
        for m in affected:
            # Determine the change at this m
            h_m_new = h[m]  # old value (since we haven't applied the swap yet)
            h_ms_new = h[m+s] if 0 <= m+s < n else None
            
            # If m == i: h goes 1->0
            # If m == j: h goes 0->1
            # If m+s == i: h[m+s] goes 1->0
            # If m+s == j: h[m+s] goes 0->1
            
            # Old term: h[m] * (1-h[m+s])
            h_m_old = h[m]
            h_ms_old = h[m+s] if 0 <= m+s < n else 0  # out of range means not in sum
            
            # New values
            h_m_tmp = h[m]
            h_ms_tmp = h[m+s] if 0 <= m+s < n else 0
            if m == i: h_m_tmp = 0
            if m == j: h_m_tmp = 1
            if 0 <= m+s < n:
                if m+s == i: h_ms_tmp = 0
                if m+s == j: h_ms_tmp = 1
            
            old_term = h_m_old * (1 - h_ms_old) if 0 <= m+s < n else 0
            new_term = h_m_tmp * (1 - h_ms_tmp) if 0 <= m+s < n else 0
            total_delta += new_term - old_term
        
        delta[n-1+s] = total_delta
    
    return delta
```

**Fast binary local search with efficient delta computation:**

The key insight is: for a swap (i: 1→0, j: 0→1), the change in the correlation vector can be computed in O(n) time.

For each shift s (in np.correlate indexing, s goes from 0 to 2n-2, corresponding to shift s-(n-1)):

The correlation at index k (shift = k-(n-1)) is:
c[k] = Σ_{valid m} h[m] * (1-h[m - (k-(n-1))])

When we swap h[i]: 1→0 and h[j]: 0→1, the change in c[k] is:
Δ[k] = (new terms) - (old terms) for all m where m or m-(k-(n-1)) is in {i, j}

Let shift = k - (n-1). Then c[k] = Σ_m h[m] * (1-h[m-shift]) for valid m.

The affected m values are: i, j, i+shift, j+shift (those that are in the valid range).

For each affected m:
- If m == i: old contribution = h[i]*(1-h[i-shift]) = 1*(1-h[i-shift]), new = 0
- If m == j: old contribution = 0, new = 1*(1-h_new[j-shift])
- If m-shift == i (m = i+shift): old contribution = h[m]*(1-h[i]) = h[m]*0 = 0, new = h[m]*(1-0) = h[m]
- If m-shift == j (m = j+shift): old contribution = h[m]*(1-h[j]) = h[m]*1 = h[m], new = h[m]*(1-1) = 0

Wait, I need to be more careful. Let me define things clearly.

shift = k - (n-1), ranges from -(n-1) to (n-1)
Valid m: 0 ≤ m < n and 0 ≤ m-shift < n, i.e., max(0, shift) ≤ m ≤ min(n-1, n-1+shift)

For the swap (i: 1→0, j: 0→1):

Affected m values: m ∈ {i, j, i+shift, j+shift} ∩ [max(0,shift), min(n-1, n-1+shift)]

For each such m:

- h_new[m] and h_new[m-shift] are the new values (with the swap applied)

Δ at index k = h_new[m]*(1-h_new[m-shift]) - h_old[m]*(1-h_old[m-shift])

```python
def swap_delta(h, i, j, n):
    """Compute the change in the full correlation vector when swapping h[i](=1) and h[j](=0)."""
    delta = np.zeros(2*n-1)
    
    # For each shift s from -(n-1) to n-1:
    for shift in range(-(n-1), n):
        m_lo = max(0, shift)
        m_hi = min(n-1, n-1+shift)
        
        # Affected m values
        candidates = [i, j, i+shift, j+shift]
        
        total = 0.0
        seen = set()
        for m in candidates:
            if m in seen:
                continue
            if m_lo <= m <= m_hi:
                seen.add(m)
                ms = m - shift
                if 0 <= ms < n:
                    # Old term
                    ho_m = h[m]
                    ho_ms = h[ms]
                    # New term (after swap)
                    hn_m = 0.0 if m == i else (1.0 if m == j else h[m])
                    hn_ms = 0.0 if ms == i else (1.0 if ms == j else h[ms])
                    total += hn_m * (1.0 - hn_ms) - ho_m * (1.0 - ho_ms)
        
        delta[n-1+shift] = total
    
    return delta
```
