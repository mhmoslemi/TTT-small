For the continuous relaxation, the key insight is:
min max_k ∫h(x)(1-h(x+k))dx
s.t. ∫h = 1, 0 ≤ h ≤ 1

This can be written as:
min C
s.t. ∫h(x)(1-h(x+k))dx ≤ C for all k
∫h = 1
0 ≤ h ≤ 1

The constraint ∫h(x)(1-h(x+k))dx ≤ C is:
∫h(x)dx - ∫h(x)h(x+k)dx ≤ C
1 - ∫h(x)h(x+k)dx ≤ C
∫h(x)h(x+k)dx ≥ 1-C

This is a quadratic constraint. For fixed k, the matrix A_k with (A_k)_{ij} = 1 if |i-j| corresponds to shift k is a banded matrix. The constraint h^T A_k h ≥ 1-C is non-convex (the set {h: h^T A h ≥ c} is non-convex when A is not PSD).

However, if we fix the target C and check feasibility, this becomes a quadratic constraint satisfaction problem. We can use SLSQP to handle it.

Actually, for SLSQP, we can write:
min C (or min 0)
s.t. ∫h(x)(1-h(x+k))dx - C ≤ 0 for all k (this is the key constraint)
∫h = 1
0 ≤ h ≤ 1

The constraint ∫h(x)(1-h(x+k))dx - C ≤ 0 is:
∫h(x)dx - ∫h(x)h(x+k)dx - C ≤ 0
1 - h^T A_k h - C ≤ 0
h^T A_k h + C - 1 ≥ 0

This is a non-convex constraint (quadratic inequality with ≥ 0). SLSQP can handle non-convex constraints in principle (it's a general nonlinear solver), but it might get stuck in local minima.
