4. Score each candidate swap by the new C₅
5. Accept the best swap if it improves C₅
6. Repeat until no improvement

This is like a greedy hill-climbing with a larger neighborhood. The key is that we try many candidates per "step" and pick the best one.

For n=600 with n/2=300 ones, trying all 300×300=90000 pairs is feasible (each evaluation is O(n) for the correlation, so total is O(n²)=360000 operations per step). We can do this maybe 1000 times in the time budget.

But wait, we can be smarter. Instead of full correlation, we can compute the delta for each candidate pair in O(1) (using the formula above) and then only do a full verification for the top candidates.

Let me implement this:

```python
def greedy_lag_descent(h, start_time, time_limit, rng):
    n = len(h)
    dx = 2.0 / n
    h = h.copy()
    
    corr = np.correlate(h, 1.0 - h, mode='full').astype(np.float64)
    cur_c5 = float(np.max(corr)) * dx
    best_h = h.copy()
    best_c5 = cur_c5
    
    while time.time() - start_time < time_limit:
        # Find top 5 worst lags
        top_idx = np.argsort(corr)[::-1][:5]
        
        improved = False
        # For each worst lag, find the best swap
        for lag_idx in top_idx:
            lag = lag_idx - (n - 1)
            
            # Try all 1→0 positions that contribute to this lag
            ones = np.where(h == 1)[0]
            zeros = np.where(h == 0)[0]
            
            best_delta = 0
            best_p = -1
            best_q = -1
            
            # For efficiency, only try a subset
            # Positions p where h[p]=1 and the flip would reduce corr at this lag
            # For lag > 0: h[p]=1, h[p+lag]=0 → flipping p reduces corr
            # For lag < 0: h[p]=1, h[p+lag]=0 → flipping p reduces corr (same formula)
            
            # Just try all ones and a few zeros
            for p in ones:
                # This would reduce corr[lag_idx] by (1-h[p+lag]) if p+lag is in range
                # and h[p-lag] if p-lag is in range (these are the two affected terms)
                # Simplified: just check if this position is "bad" for this lag
                pi = int(p)
                if 0 <= pi + lag < n and h[pi + lag] == 0:
                    # Flipping h[pi] to 0 would reduce corr at this lag
                    # Now find a good q to flip to 1
                    # We want q such that flipping h[q] from 0 to 1 doesn't increase corr at this lag
                    # i.e., h[q+lag] should be 1 (so the term (1-h[q+lag]) = 0)
                    # or q+lag is out of range
                    # And h[q-lag] should be 0 (so the term h[q-lag] = 0)
                    # or q-lag is out of range
                    
                    # For now, just try a few random zeros
                    for _ in range(3):
                        q = int(zeros[rng.randint(len(zeros))])
                        if q == pi:
                            continue
                        # Quick check: compute delta at this lag
                        # Δcorr[lag] = -[0≤p+lag<n]*(1-h[p+lag]) + [0≤p-lag<n]*h[p-lag]
                        #              + [0≤q+lag<n]*(1-h[q+lag]) - [0≤q-lag<n]*h[q-lag]
                        d = 0
                        if 0 <= pi + lag < n:
                            d -= (1 - h[pi + lag])
                        if 0 <= pi - lag < n:
                            d += h[pi - lag]
                        if 0 <= q + lag < n:
                            d += (1 - h[q + lag])
                        if 0 <= q - lag < n:
                            d -= h[q - lag]
                        
                        # This is the change at the specific lag. We want d < 0.
                        # But we also need to check it doesn't make other lags worse.
                        # For now, accept if d < 0 and do full verification.
                        if d < 0 and d < best_delta:
                            best_delta = d
                            best_p = pi
                            best_q = q
            
            if best_p >= 0 and best_q >= 0:
                # Full verification
                h[best_p] = 0
                h[best_q] = 1
                new_corr = np.correlate(h, 1.0 - h, mode='full').astype(np.float64)
                new_c5 = float(np.max(new_corr)) * dx
                if new_c5 < cur_c5 - 1e-15:
                    corr = new_corr
                    cur_c5 = new_c5
                    improved = True
                    if cur_c5 < best_c5:
                        best_c5 = cur_c5
                        best_h = h.copy()
                else:
                    h[best_p] = 1
                    h[best_q] = 0
        
        if not improved:
            # Stuck: perturb
            h = best_h.copy()
            corr = np.correlate(h, 1.0 - h, mode='full').astype(np.float64)
            cur_c5 = float(np.max(corr)) * dx
            ones = np.where(h == 1)[0]
            zeros = np.where(h == 0)[0]
            n_pert = rng.randint(2, 5)
            for _ in range(n_pert):
                pi = int(ones[rng.randint(len(ones))])
                pj = int(zeros[rng.randint(len(zeros))])
                h[pi] = 0
                h[pj] = 1
            corr = np.correlate(h, 1.0 - h, mode='full').astype(np.float64)
            cur_c5 = float(np.max(corr)) * dx
    
    return best_h, best_c5
```

This is O(n²) per iteration (trying all ones × 3 random zeros), which for n=600 is about 360,000 operations per iteration. Each iteration involves a few np.correlate calls for the candidates that pass the quick check. This should be fast enough.
