Let me also consider a different approach: **Simulated Annealing with delta evaluation**.

For SA, at each step:
1. Pick a random i with h[i]=1
2. Pick a random j with h[j]=0
3. Compute delta = new_max - old_max (where new_max is after the swap)
4. Accept if delta < 0 or with probability exp(-delta/T)

The key is step 3: computing the new max after the swap. This requires computing the full correlation vector (O(n²)) or using the delta formula.

With the delta formula, we can compute the new correlation in O(n) (just add the delta to the old correlation). Then finding the max is O(n). So each SA step is O(n) after the initial O(n²) computation.

For n=600: O(600) = 600 operations per step. We can do ~1M steps per second. With 1000 seconds, that's 1 billion steps. That should be more than enough.

```python
def sa_optimize_v2(h_start, target_sum, time_limit, start_time, rng):
    n = len(h_start)
    h = project_binary(h_start, target_sum).astype(int)
    dx = 2.0 / n
    
    # Compute initial correlation
    corr = np.correlate(h.astype(float), 1.0 - h.astype(float), mode='full')
    best_h = h.copy()
    best_c5 = corr.max() * dx
    current_c5 = best_c5
    
    T_init = 0.05
    T_final = 0.0001
    total_time = time_limit
    # Estimate number of iterations
    # Each iteration takes about 0.1ms, so ~10000/s
    max_iters = int(total_time * 8000)  # conservative estimate
    
    for it in range(max_iters):
        if time.time() - start_time > start_time + time_limit:
            break
        
        # Cooling schedule
        ratio = min(it / max_iters, 1.0)
        T = T_init * (T_final / T_init) ** ratio
        
        # Pick random swap
        ones = np.where(h == 1)[0]
        zeros = np.where(h == 0)[0]
        i = ones[rng.randint(len(ones))]
        j = zeros[rng.randint(len(zeros))]
        
        # Compute delta for this swap
        # We need to compute how corr changes
        # Instead of full recomputation, use the delta formula
        # But for simplicity and to avoid bugs, let's just recompute
        # For n=600, this should be fast enough
        
        h[i] = 0
        h[j] = 1
        new_corr = np.correlate(h.astype(float), 1.0 - h.astype(float), mode='full')
        new_max = new_corr.max()
        delta = new_max - corr.max()
        
        if delta < 0 or (T > 1e-15 and rng.random() < np.exp(-delta / T)):
            corr = new_corr
            current_c5 = new_max * dx
            if current_c5 < best_c5:
                best_c5 = current_c5
                best_h = h.copy()
        else:
            h[i] = 1
            h[j] = 0
    
    return best_h.astype(float), best_c5
```

Wait, let me be more careful about the definition.

From numpy docs: np.correlate(a, v, mode='full') returns:
out[k] = sum_n a[n+k] * conj(v[n]) for k = -(len(v)-1), ..., len(a)-1

So for a=h, v=1-h:
out[k] = sum_n h[n+k] * (1-h[n]) for k = -(n-1), ..., n-1

The output has length 2n-1, indexed from 0 to 2n-2.
out[0] corresponds to k=-(n-1)
out[n-1] corresponds to k=0
out[2n-2] corresponds to k=n-1

So: out[idx] = sum_n h[n + (idx-(n-1))] * (1-h[n])

where the sum is over n such that 0 <= n < n and 0 <= n + idx - (n-1) < n.

Let m = idx - (n-1) (the actual shift). Then:
out[idx] = sum_n h[n+m] * (1-h[n]) for 0 <= n < n and 0 <= n+m < n

For m >= 0: sum_{n=0}^{n-1-m} h[n+m] * (1-h[n])
For m < 0: sum_{n=-m}^{n-1} h[n+m] * (1-h[n])

Now, if we flip h[i] from 1 to 0:
- h[i] appears in the sum when n+m = i, i.e., n = i-m
  - Contribution was 1 * (1-h[i-m]) = 1-h[i-m], now 0
  - Change: -(1-h[i-m]) if 0 <= i-m < n
- h[i] also appears in (1-h[n]) when n = i
  - Contribution was h[i+m] * (1-1) = 0, now h[i+m] * (1-0) = h[i+m]
  - Change: +h[i+m] if 0 <= i+m < n

And if we flip h[j] from 0 to 1:
- h[j] appears when n+m = j, i.e., n = j-m
  - Contribution was 0 * (1-h[j-m]) = 0, now 1-h[j-m]
  - Change: +(1-h[j-m]) if 0 <= j-m < n
- h[j] appears in (1-h[n]) when n = j
  - Contribution was h[j+m] * (1-0) = h[j+m], now h[j+m] * (1-1) = 0
  - Change: -h[j+m] if 0 <= j+m < n

Total delta for shift m:
delta[m] = -(1-h[i-m]) * [0<=i-m<n] + h[i+m] * [0<=i+m<n] + (1-h[j-m]) * [0<=j-m<n] - h[j+m] * [0<=j+m<n]

This can be computed for all m in O(n) time.

So the algorithm is:
1. Maintain the current corr vector
2. For each swap, compute delta in O(n)
3. new_corr = corr + delta
4. new_max = max(new_corr)
5. If accepted, update corr = new_corr

This makes each SA step O(n) instead of O(n²). For n=600, that's 600 operations per step, allowing ~1M steps per second.

```python
def compute_delta(h, i, j, n):
    """Compute the delta vector for swapping h[i]:1->0, h[j]:0->1"""
    delta = np.zeros(2*n - 1)
    m_offset = n - 1
    
    # From flipping h[i]: 1->0
    # Term 1: -(1-h[i-m]) for valid m where 0 <= i-m < n
    m_lo = max(0, i - (n-1))
    m_hi = min(n-1, i)
    if m_lo <= m_hi:
        m_range = np.arange(m_lo, m_hi + 1)
        delta[m_range + m_offset] -= (1.0 - h[i - m_range])
    
    # Term 2: +h[i+m] for valid m where 0 <= i+m < n
    m_lo2 = max(0 - i, -(n-1))  # = max(-i, -(n-1))
    m_hi2 = min(n-1-i, n-1)
    if m_lo2 <= m_hi2:
        m_range2 = np.arange(m_lo2, m_hi2 + 1)
        delta[m_range2 + m_offset] += h[i + m_range2]
    
    # From flipping h[j]: 0->1
    # Term 3: +(1-h[j-m]) for valid m where 0 <= j-m < n
    m_lo3 = max(0, j - (n-1))
    m_hi3 = min(n-1, j)
    if m_lo3 <= m_hi3:
        m_range3 = np.arange(m_lo3, m_hi3 + 1)
        delta[m_range3 + m_offset] += (1.0 - h[j - m_range3])
    
    # Term 4: -h[j+m] for valid m where 0 <= j+m < n
    m_lo4 = max(-j, -(n-1))
    m_hi4 = min(n-1-j, n-1)
    if m_lo4 <= m_hi4:
        m_range4 = np.arange(m_lo4, m_hi4 + 1)
        delta[m_range4 + m_offset] -= h[j + m_range4]
    
    return delta
```
