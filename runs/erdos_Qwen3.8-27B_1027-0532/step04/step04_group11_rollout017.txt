def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr)) * dx

def project_feasible(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    for _ in range(1000):
        diff = target_sum - np.sum(h)
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            mask = h < 1.0
        else:
            mask = h > 0.0
        cnt = int(mask.sum())
        if cnt == 0:
            break
        h[mask] += diff / cnt
        h = np.clip(h, 0.0, 1.0)
    return h

**Algorithm: Fast Binary Local Search**

```
1. Initialize h as a binary array with n/2 ones
2. Compute corr = np.correlate(h, 1-h, mode='full')
3. current_max = np.max(corr)
4. For each iteration:

   b. Pick random j from {p : h[p] = 1}

   d. new_max = max(corr + Δ)
   e. If new_max < current_max (or accept with SA prob):

      - Update corr += Δ
      - current_max = new_max
      - Update zero/one position lists
   f. Track best solution found
```

The key optimization is step (c)-(d): computing the max of (corr + Δ) in O(n) time.

- The max can only decrease if the current max lag's value decreases AND no other lag exceeds it.
- We can check: is max(corr + Δ) < current_max?
