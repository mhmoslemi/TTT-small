For B: idx ranges from b_s=N-1-i to b_e-1=min(2N-2-i, 2N-2)
  h_index = i+idx-N+1
  When idx = N-1-i: h_index = 0
  When idx = 2N-2-i: h_index = N-1
  So h_index goes from 0 up to...
  
  b_len = b_e - b_s
  h_index starts at i+(N-1-i)-N+1 = 0
  h_index ends at i+(b_e-1)-N+1 = i+b_e-N
  
  delta[b_s:b_e] -= h[0 : b_e-N+i] = h[0 : b_len]
  
  Wait: b_e-1 = min(2N-2-i, 2N-2), and b_s = N-1-i
  b_len = b_e - b_s = min(2N-2-i, 2N-2) - (N-1-i)
  If 2N-2-i ≤ 2N-2 (always true): b_len = 2N-2-i - N+1+i = N-1
  So b_len = N-1 always? Let me check: b_e = min(2N-1-i, 2N-1) = 2N-1-i (since i≥0, 2N-1-i ≤ 2N-1)
  b_s = N-1-i
  b_len = 2N-1-i - (N-1-i) = N
  
  Hmm wait, b_e should be exclusive. Let me redo.
  
  Valid idx: N-1-i ≤ idx ≤ 2N-2-i
  So b_s = N-1-i, b_e = 2N-2-i+1 = 2N-1-i (exclusive)
  But we need b_e ≤ 2N-1 (the length of the correlation array)
  2N-1-i ≤ 2N-1 since i ≥ 0 ✓
  
  Also b_s ≥ 0 since N-1-i ≥ 0 (i ≤ N-1) ✓
  
  b_len = (2N-1-i) - (N-1-i) = N
  
  h_index = i + idx - N + 1
  At idx = b_s = N-1-i: h_index = i + N-1-i-N+1 = 0
  At idx = b_e-1 = 2N-2-i: h_index = i + 2N-2-i-N+1 = N-1
  
  So delta[b_s:b_e] -= h[0:N] = h

So B simplifies to: delta[N-1-i : 2N-1-i] -= h

Similarly:
For D: valid idx: N-1-j ≤ idx ≤ 2N-2-j
  d_s = N-1-j, d_e = 2N-1-j
  d_len = N
  h_index = j + idx - N + 1
  At idx = d_s: h_index = 0
  At idx = d_e-1: h_index = N-1
  delta[d_s:d_e] += h

For A: valid idx: i ≤ idx ≤ i+N-1
  a_s = i, a_e = i+N (exclusive)
  But a_e ≤ 2N-1? i+N ≤ 2N-1? i ≤ N-1 ✓
  a_len = N
  h_index = i+N-1-idx
  At idx = i: h_index = N-1
  At idx = i+N-1: h_index = 0
  delta[i:i+N] += 1 - h[N-1::-1] = 1 - h[::-1]

For C: valid idx: j ≤ idx ≤ j+N-1
  c_s = j, c_e = j+N
  c_len = N
  h_index = j+N-1-idx
  At idx = j: h_index = N-1
  At idx = j+N-1: h_index = 0
  delta[j:j+N] += -1 + h[::-1]

So the full delta computation simplifies to:
```python
delta = np.zeros(2*N-1)
delta[i:i+N] += 1.0 - h_rev      # A
delta[N-1-i:2*N-1-i] -= h         # B
delta[j:j+N] += -1.0 + h_rev      # C
delta[N-1-j:2*N-1-j] += h         # D
```

Where h_rev = h[::-1] (which we can precompute and maintain!).

This is extremely fast - just 4 slice additions of length N on an array of length 2N-1. In NumPy, this should take about 2-5μs total.
