But wait, the lags where the current max M is achieved: if at such a lag s*, delta_s* < 0, then the new value there is M - 2 < M, which is good. If delta_s* = 0, new value is still M. If delta_s* > 0, new value is M + 2, which is bad.

So the strategy is clear:
- Find all lags at (or near) the current max
- Find (a, b) such that at those critical lags, h[a+s] = 0 and h[b+s] = 1 (so delta_s = -2, reducing the max)
- Avoid (a, b) where at critical lags, h[a+s] = 1 and h[b+s] = 0 (so delta_s = +2, increasing the max)

Now, for the scoring:
- For a candidate a (currently 1): "danger" at critical lag s is h[a+s] = 1 (would increase corr at s)
- For a candidate b (currently 0): "help" at critical lag s is h[b+s] = 1 (would decrease corr at s)

So:
- score_a = -|{s in critical: h[a+s] = 1}| + |{s in critical: h[a+s] = 0}| (we want this to be high, meaning fewer bad interactions)
  Actually simpler: score_a = -|{s in critical: h[a+s] = 1}| (fewer ones at critical lags is better)
  
- score_b = |{s in critical: h[b+s] = 1}| (more ones at critical lags is better)

We want to minimize score_a and maximize score_b.

But actually, it's not just the critical lags that matter. Even non-critical lags could become the new max if they increase. So we should also consider lags that are close to the max.

Let me define the "at-risk" set as lags where corr[s] >= M - threshold (for some threshold, say 2 or 4).

For the scoring, I'll use:
- For a in ones: bad_a = number of at-risk lags s where h[a+s] = 1
- For b in zeros: good_b = number of at-risk lags s where h[b+s] = 1

Pick a with minimum bad_a and b with maximum good_b, then verify.

The Erdős problem is related to the "cross-correlation" of a set with its complement. For a set A of measure 1 in [0,2], we want to minimize max_t measure(A ∩ (A+t)^c).

Known constructions include:
- Random sets: give C ≈ 0.5 (bad)
- Interval [0,1]: C = 1 (very bad, since for small t, A ∩ (A+t)^c is large)
- Cantor-like sets: might be better
- Periodic patterns: h(x) = 1 if floor(x) is even, 0 otherwise (on [0,2]): 
  For t=1, A ∩ (A+1)^c = [0,1] ∩ [1,2]^c ∪ [1,2] ∩ [0,1]^c = [0,1] ∩ [1,2] = empty... 
  Wait, that's not right. Let me reconsider.
  
  If h(x) = 1 for x in [0,1] and 0 for x in [1,2]:
  ∫ h(x)(1-h(x+t)) dx: for t in (0,1), this is the measure of [0,1-t] (where h=1 and h(x+t)=0 since x+t in (t,1+t) overlaps with [1,2]) 
  Actually: h(x)=1 for x in [0,1], h(x+t)=0 for x+t in [1,2] i.e., x in [1-t, 2-t].
  So the overlap is [0,1] ∩ [1-t, 2-t] = [1-t, 1] for t in (0,1], measure = t.
  For t in (1,2]: h(x+t) is 0 for x+t in [2-t, 2] (if 2-t < 1) or empty.
  For t in (1,2): x+t in [1,2] when x in [1-t, 2-t], but 1-t < 0, so x in [0, 2-t]. And h(x)=1 for x in [0,1]. So overlap is [0, min(1, 2-t)] = [0, 2-t], measure = 2-t.
  At t=1: measure = 1.
  So C = max(t for t in [0,1], 2-t for t in [1,2]) = 1. Very bad.

- Alternating pattern with period 1: h(x) = 1 for x in [0, 0.5), 0 for x in [0.5, 1), repeating.
  This is a 50-50 pattern within each unit. The correlation at shift t would depend on the overlap of the 1-regions with the 0-regions of the shifted version.
  For t = 0.5: the 1-regions of h shift to align with 0-regions, giving overlap = measure of 1-regions = 0.5.
  So C ≈ 0.5. Still bad.

- What about a finer pattern? If h alternates with period 2/n (n periods):
  For t = 1/n: each 1-block shifts to a 0-block, giving overlap ≈ 0.5.
  The maximum would be at t = 1/n, giving C ≈ 0.5.

It seems like periodic patterns don't help much. The best constructions are likely aperiodic or quasi-periodic.

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr)) * dx

def get_corr(h):
    return np.correlate(h, 1.0 - h, mode='full').astype(float)

def project_feasible(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    diff = target_sum - np.sum(h)
    if abs(diff) < 1e-14:
        return h
    if diff > 0:
        idx = np.where(h < 1.0)[0]
    else:
        idx = np.where(h > 0.0)[0]
    if len(idx) == 0:
        return h
    h = h.copy()
    h[idx] += diff / len(idx)
    return np.clip(h, 0.0, 1.0)

def project_binary(h, target_sum):
    n = len(h)
    h_r = np.round(h).astype(int)
    h_r = np.clip(h_r, 0, 1)
    current_sum = int(h_r.sum())
    if current_sum == target_sum:
        return h_r.astype(float)
    if current_sum > target_sum:
        ones = np.where(h_r == 1)[0]
        need = current_sum - target_sum
        order = np.argsort(h[ones])[:need]
        h_r[ones[order]] = 0
    else:
        zeros = np.where(h_r == 0)[0]
        need = target_sum - current_sum
        order = np.argsort(-h[zeros])[:need]
        h_r[zeros[order]] = 1
    return h_r.astype(float)

def compute_delta(h, a, b, n):
    shift_range = np.arange(-(n-1), n)
    a_idx = a + shift_range
    b_idx = b + shift_range
    va = np.zeros(2*n - 1)
    ma = (a_idx >= 0) & (a_idx < n)
    va[ma] = h[a_idx[ma]]
    vb = np.zeros(2*n - 1)
    mb = (b_idx >= 0) & (b_idx < n)
    vb[mb] = h[b_idx[mb]]
    return 2.0 * (va - vb)

def smart_binary_sa(h_start, target_sum, max_iters, t_init, t_final, rng, time_limit, start_time):
    n = len(h_start)
    dx = 2.0 / n
    h = project_binary(h_start, target_sum).astype(float)
    corr = get_corr(h)
    best_h = h.copy()
    best_raw = float(np.max(corr))
    best_c5 = best_raw * dx
    current_c5 = best_c5
    current_raw = best_raw
    
    ones = np.where(h == 1)[0]
    zeros = np.where(h == 0)[0]
    
    no_improve = 0
    max_no_improve = max(500, max_iters // 20)
    
    for i in range(max_iters):
        if time.time() - start_time > time_limit:
            break
        if no_improve > max_no_improve:
            if rng.random() < 0.05:
                # Perturb
                n_pert = rng.randint(3, 7)
                for _ in range(n_pert):
                    a = ones[rng.randint(len(ones))]
                    b = zeros[rng.randint(len(zeros))]
                    delta = compute_delta(h, a, b, n)
                    corr = corr + delta
                    h[a] = 0.0
                    h[b] = 1.0
                    ones = np.where(h == 1)[0]
                    zeros = np.where(h == 0)[0]
                current_raw = float(np.max(corr))
                current_c5 = current_raw * dx
                no_improve = 0
            else:
                break
        
        ratio = i / max(max_iters - 1, 1)
        t = t_init * (t_final / t_init) ** ratio
        
        M = float(np.max(corr))
        
        # At-risk lags: those within 4 raw units of max
        threshold = M - 4.0
        at_risk = np.where(corr >= threshold)[0]
        if len(at_risk) == 0:
            at_risk = np.array([n - 1])
        if len(at_risk) > 200:
            at_risk_idx = np.argsort(corr[at_risk])[::-1][:200]
            at_risk = at_risk[at_risk_idx]
        
        at_risk_shifts = at_risk - (n - 1)
        
        # Score candidates
        if len(ones) == 0 or len(zeros) == 0:
            break
        
        # Bad scores for ones (higher = worse)
        ones_indices = ones[:, None] + at_risk_shifts[None, :]
        ones_valid = (ones_indices >= 0) & (ones_indices < n)
        ones_h = np.where(ones_valid, h[np.clip(ones_indices, 0, n-1)], 0)
        bad_scores = np.sum(ones_h == 1, axis=1)
        
        # Good scores for zeros (higher = better)
        zeros_indices = zeros[:, None] + at_risk_shifts[None, :]
        zeros_valid = (zeros_indices >= 0) & (zeros_indices < n)
        zeros_h = np.where(zeros_valid, h[np.clip(zeros_indices, 0, n-1)], 0)
        good_scores = np.sum(zeros_h == 1, axis=1)
        
        # Pick top candidates
        k_a = min(8, len(ones))
        k_b = min(8, len(zeros))
        top_a_idx = np.argsort(bad_scores)[:k_a]
        top_b_idx = np.argsort(-good_scores)[:k_b]
        top_a = ones[top_a_idx]
        top_b = zeros[top_b_idx]
        
        # Try pairs
        best_new_raw = np.inf
        best_pair = None
        best_delta = None
        
        for a in top_a:

            b_valid = (b_indices >= 0) & (b_indices < n)
            b_vals = np.where(b_valid, h[np.clip(b_indices, 0, n-1)], 0)
            
            new_corrs = corr[None, :] + 2.0 * (va[None, :] - b_vals)
            new_maxes = np.max(new_corrs, axis=1)
            
            best_bi = int(np.argmin(new_maxes))
            if new_maxes[best_bi] < best_new_raw:

                best_pair = (a, top_b[best_bi])
                best_delta = 2.0 * (va - b_vals[best_bi])
        
        if best_pair is None:
            no_improve += 1
            continue
        
        new_c5 = best_new_raw * dx
        delta_c5 = new_c5 - current_c5
        
        accept = False
        if delta_c5 < -1e-12:
            accept = True
        elif abs(delta_c5) < 1e-12:
            accept = rng.random() < 0.3
        elif t > 1e-12:
            accept = rng.random() < np.exp(-delta_c5 / t)
        
        if accept:
            corr = corr + best_delta
            h[best_pair[0]] = 0.0
            h[best_pair[1]] = 1.0
            ones = np.where(h == 1)[0]
            zeros = np.where(h == 0)[0]
            current_raw = best_new_raw
            current_c5 = new_c5
            if current_c5 < best_c5 - 1e-12:

                best_h = h.copy()
                no_improve = 0
            else:
                no_improve += 1
        else:
            no_improve += 1
    
    # Verify best
    final_c5 = compute_c5(best_h)
    if final_c5 < best_c5:
        best_c5 = final_c5
    return best_h, best_c5

Let me now think about the SLSQP refinement more carefully.

The objective is: min_h max_k corr_k(h) * dx

Subject to: 0 ≤ h_i ≤ 1, sum(h) = n/2

The log-sum-exp approximation:
f_alpha(h) = (1/alpha) * log(sum_k exp(alpha * corr_k(h)))
