If we swap h[i1] from 1 to 0 and h[i0] from 0 to 1, the change in corr[k] is:
- For lag k where i1+k is valid: corr[k] changes by -(1-h[i1+k]) + ... 

Actually, let me think about this more carefully.

corr[k] = sum_i h[i+k] * (1-h[i]) (for valid i, i.e., 0 ≤ i < n and 0 ≤ i+k < n)

If we change h[i1] from 1 to 0:
- corr[k] changes for k = i1 - i (for all i where i and i+k are valid)
  Specifically, for any lag d such that position i1 is involved:
  - As h[i1] in the "first" position: corr[n-1+d] involves h[i1+d]*(1-h[i1]) for various d
    When h[i1] goes from 1 to 0: (1-h[i1]) goes from 0 to 1
    So corr[n-1+d] increases by h[i1+d] for each valid d
  - As h[i1] in the "second" position: corr[n-1-d] involves h[i1]*(1-h[i1-d])
    When h[i1] goes from 1 to 0: h[i1] goes from 1 to 0
    So corr[n-1-d] decreases by (1-h[i1-d]) for each valid d

If we change h[i0] from 0 to 1:
  - As h[i0] in the "first" position: corr[n-1+d] involves h[i0+d]*(1-h[i0])
    When h[i0] goes from 0 to 1: (1-h[i0]) goes from 1 to 0
    So corr[n-1+d] decreases by h[i0+d] for each valid d
  - As h[i0] in the "second" position: corr[n-1-d] involves h[i0]*(1-h[i0-d])
    When h[i0] goes from 0 to 1: h[i0] goes from 0 to 1
    So corr[n-1-d] increases by (1-h[i0-d]) for each valid d

So the total change in corr[n-1+d] when swapping (i1: 1→0, i0: 0→1) is:
Δcorr[n-1+d] = h_new[i1+d] - (1-h[i1-d]) - h_new[i0+d] + (1-h[i0-d])

where h_new differs from h only at i1 and i0.

This is O(1) to compute for a given d, but we need to check all d (up to n values) to find the new max.

The key question is: can we compute the NEW MAX of corr efficiently after the swap?

The new corr is: corr_new[d] = corr[d] + Δcorr[d]
We need max_d corr_new[d] = max_d (corr[d] + Δcorr[d])

This is O(n) in the worst case, but Δcorr[d] is non-zero only for d in specific ranges:
- d from -(i1-1) to n-1-i1 (for the i1 changes)
- d from -(i0-1) to n-1-i0 (for the i0 changes)

Actually, Δcorr[d] is non-zero for d where either i1 or i0 is in the "active window" for that lag.

For lag k (in the range -(n-1) to n-1):
- i1 is active if 0 ≤ i1 < n and 0 ≤ i1+k < n, i.e., -i1 ≤ k ≤ n-1-i1
- i0 is active if -i0 ≤ k ≤ n-1-i0

So Δcorr is non-zero for k in the union of these two intervals, which is at most 2n-2 values.

But in practice, for random i1 and i0, most of these intervals cover most of the range, so we can't really avoid the O(n) check.

However, we CAN use a data structure to track the max more efficiently. If we maintain a segment tree or heap over the corr values, we can update the affected entries and query the max in O(log n) time.

But implementing this correctly is complex. For now, let me just use the O(n) approach but with FFT for the initial computation.

Actually, for n=600, O(n) per evaluation is fine. The bottleneck is the correlation computation itself, which FFT helps with.

Let me also think about a "worst-lag targeting" strategy:
- Identify the top-m worst lags
- For each worst lag k*, find the swap (i1, i0) that most reduces corr[k*]
- Apply the best swap found

The delta in corr[k*] for swapping i1 (1→0) and i0 (0→1):
Δcorr[k*] = -(1-h[i1-k*]) + h[i1+k*] + h[i0-k*] - (1-h[i0+k*])
(where we treat out-of-bounds as 0)

Wait, let me be more careful. In the "full" correlation:
corr_full has indices 0 to 2n-2, where corr_full[n-1+d] corresponds to lag d.

corr_full[n-1+d] = sum_{i=0}^{n-1-|d|} ... (depends on sign of d)

For d > 0: corr_full[n-1+d] = sum_{i=0}^{n-1-d} h[i+d] * (1-h[i])
For d < 0: corr_full[n-1+d] = sum_{i=-d}^{n-1} h[i+d] * (1-h[i]) = sum_{i=0}^{n-1+d} h[i] * (1-h[i-d])

Let me use the convention: for lag d (can be negative), the correlation is:
C(d) = sum_{i} h[i+d] * (1-h[i]) where i ranges over valid values

If d > 0: i from 0 to n-1-d, so C(d) = sum_{i=0}^{n-1-d} h[i+d]*(1-h[i])
If d < 0: i from -d to n-1, so C(d) = sum_{i=-d}^{n-1} h[i+d]*(1-h[i])
If d = 0: C(0) = 0 (for binary h)

Now, if we swap h[i1]: 1→0 and h[i0]: 0→1, the change in C(d) is:

The position i1 contributes to C(d) as:
- h[i1] in the "first" slot: when i1 = i, contributes h[i1+d]*(1-h[i1]) = h[i1+d]*0 = 0 (was), now h[i1+d]*1 = h[i1+d]
  So C(d) increases by h[i1+d] if i1 is a valid "first" position for lag d (i.e., i1 + d is in [0, n-1] and i1 is in [0, n-1])
- h[i1] in the "second" slot: when i1 = i+d, i.e., i = i1-d, contributes h[i1]*(1-h[i1-d]) = 1*(1-h[i1-d]) (was), now 0*(1-h[i1-d]) = 0
  So C(d) decreases by (1-h[i1-d]) if i1-d is in [0, n-1]

The position i0 contributes to C(d) as:
- h[i0] in the "first" slot: when i0 = i, contributes h[i0+d]*(1-h[i0]) = h[i0+d]*1 (was), now h[i0+d]*0 = 0
  So C(d) decreases by h[i0+d] if valid
- h[i0] in the "second" slot: when i0 = i+d, i.e., i = i0-d, contributes h[i0]*(1-h[i0-d]) = 0 (was), now 1*(1-h[i0-d])
  So C(d) increases by (1-h[i0-d]) if valid

Total ΔC(d) for the swap:
ΔC(d) = [h[i1+d] * valid(i1, i1+d) - (1-h[i1-d]) * valid(i1-d, i1)] 
       + [(1-h[i0-d]) * valid(i0-d, i0) - h[i0+d] * valid(i0, i0+d)]

where valid(a, b) means both a and b are in [0, n-1].

Let me define:
- f1(d) = h[i1+d] (if 0≤i1+d<n and 0≤i1<n) else 0  [contribution of i1 as first slot, after change]
- g1(d) = (1-h[i1-d]) (if 0≤i1-d<n and 0≤i1<n) else 0  [contribution of i1 as second slot, removed]
- f0(d) = (1-h[i0-d]) (if 0≤i0-d<n and 0≤i0<n) else 0  [contribution of i0 as second slot, added]
- g0(d) = h[i0+d] (if 0≤i0+d<n and 0≤i0<n) else 0  [contribution of i0 as first slot, removed]

ΔC(d) = f1(d) - g1(d) + f0(d) - g0(d)

This is O(1) per lag d! So we can compute the new max by checking all d in O(n), which is the same as recomputing the full correlation. But we can be smarter:

If we only care about whether the NEW MAX is lower, we can:
1. Compute ΔC(d) for all d (O(n))
2. New corr = old corr + ΔC (O(n))
3. New max = max(new corr) (O(n))

Total: O(n) per proposed move, same as computing the full correlation from scratch. So there's no speedup from the delta approach for a single move.

BUT, if we use FFT to compute the correlation from scratch, it's O(n log n). So the delta approach (O(n)) is actually FASTER than FFT (O(n log n)) for n > ~100!

Wait, that's an interesting insight. For n=600:
- Direct correlation (np.correlate): O(n²) = 360,000 operations
- FFT correlation: O(n log n) = 600 * 10 ≈ 6,000 operations
- Delta approach: O(n) = 600 operations

So the delta approach is 10-600x faster than the alternatives! This is a huge speedup.

But the delta approach requires us to maintain the current correlation array and update it incrementally. Let me implement this.

Actually wait - the delta approach gives us the change in corr for a SINGLE swap. If we accept the swap, we update corr in place. If we reject, we undo. This is very efficient.

            worst_d = worst_k - (n - 1)
            # We want to reduce corr[worst_k]
            # ΔC(worst_d) = f1(worst_d) - g1(worst_d) + f0(worst_d) - g0(worst_d)
            # We want this to be negative
            # f0(worst_d) - g0(worst_d) = (1-h[i0-worst_d]) - h[i0+worst_d] (with bounds)
            # To make ΔC negative, we want f0 - g0 to be very negative
            # i.e., h[i0+worst_d] large and (1-h[i0-worst_d]) small
            # i.e., h[i0+worst_d]=1 and h[i0-worst_d]=1
            # So we want i0 such that h[i0+worst_d]=1 and h[i0-worst_d]=1
            # This means i0 is a zero that has ones on both sides at distance |worst_d|
            
            # Let's score zeros by how much they'd reduce corr[worst_d]
            # f0(d) - g0(d) = (1-h[i0-d])*valid - h[i0+d]*valid
            # We want this to be as negative as possible
            # = -h[i0+d] - (1-h[i0-d]) (both terms subtract)
            # Minimum = -2 (when h[i0+d]=1 and h[i0-d]=1)
            
            scores = np.zeros(len(zeros))
            for idx, z in enumerate(zeros):
                s = 0.0
                j = z + worst_d
                if 0 <= j < n:
                    s -= h[j]  # this is -g0
                j2 = z - worst_d
                if 0 <= j2 < n:
                    s -= (1.0 - h[j2])  # this is -f0... 
                    # Wait, f0 = (1-h[i0-d]), so -f0 = -(1-h[i0-d]) = h[i0-d]-1
                    # And -g0 = -h[i0+d]
                    # So f0 - g0 = (1-h[i0-d]) - h[i0+d]
                    # We want this to be negative: h[i0+d] > 1-h[i0-d]
                    # i.e., h[i0+d] + h[i0-d] > 1
                    # For binary: h[i0+d]=1 and h[i0-d]=1
                scores[idx] = s
            
            # Pick the zero that most reduces the worst lag
            i0 = zeros[np.argmin(scores)]
        else:
            i0 = zeros[rng.randint(len(zeros))]
        
        # Apply swap
        h[i1] = 0
        h[i0] = 1
        corr_new = np.correlate(h, 1.0 - h, mode='full')
        c5_new = float(np.max(corr_new)) * dx
        delta = c5_new - current_c5
        
        # Temperature schedule
        elapsed = time.time() - start_time
        t = 0.02 * np.exp(-3.0 * elapsed / time_limit)
        
        if delta < -1e-12 or (t > 1e-12 and rng.random() < np.exp(-delta / t)):
            current_c5 = c5_new
            corr = corr_new
            if c5_new < best_c5 - 1e-14:
                best_c5 = c5_new
                best_h = h.copy()
                no_improve = 0
            else:
                no_improve += 1
        else:
            h[i1] = 1
            h[i0] = 0
            no_improve += 1
    
    return best_h, best_c5

def project_feasible(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    diff = target_sum - np.sum(h)
    if abs(diff) < 1e-14:
        return h
    h = h.copy()
    if diff > 0:
        order = np.argsort(1.0 - h)
        remaining = diff
        for i in order:
            if remaining <= 1e-14:
                break
            add = min(1.0 - h[i], remaining)
            h[i] += add
            remaining -= add
    else:
        order = np.argsort(h)
        remaining = -diff
        for i in order:
            if remaining <= 1e-14:
                break
            sub = min(h[i], remaining)
            h[i] -= sub
            remaining -= sub
    return np.clip(h, 0.0, 1.0)


def project_binary(h, target_sum):

        return h_r.astype(float)
    ones = np.where(h_r == 1)[0]
    zeros = np.where(h_r == 0)[0]
    if current_sum > target_sum:
        need = min(current_sum - target_sum, len(ones))
        order = np.argsort(h[ones])[:need]
        h_r[ones[order]] = 0
    else:
        need = min(target_sum - current_sum, len(zeros))
        order = np.argsort(-h[zeros])[:need]
        h_r[zeros[order]] = 1
    final_sum = int(h_r.sum())

    t = np.zeros(n, dtype=np.int8)
    for i in range(1, n):
        t[i] = (t[i >> 1] ^ 1) & 1 if (i & 1) else t[i >> 1]
    # Simpler: count bits
    t = np.zeros(n, dtype=np.int8)
    for i in range(n):
        t[i] = bin(i).count('1') & 1
    return t.astype(float)


def m_sequence_poly(n, poly_coeff):
    """Generate m-sequence using LFSR with given polynomial (list of tap positions)."""
    seq = np.zeros(n, dtype=np.int8)
    state = 1
    m = n
    for i in range(m):
        seq[i] = state & 1
        bit = 0
        for tap in poly_coeff:
            bit ^= (state >> tap) & 1
        state = (state >> 1) | (bit << (m - 1))
    return seq.astype(float)


def generate_starts(n, rng, n_init, h_init):
    starts = []
    target = n // 2

    if n_init == n:

    else:
        x_old = np.linspace(0, 1, n_init)
        x_new = np.linspace(0, 1, n)
        h_interp = np.interp(x_new, x_old, h_init)
        starts.append(project_binary(h_interp, target))

    # Start 2: Thue-Morse
    starts.append(project_binary(thue_morse(n), target))

    perm = rng.permutation(n)
    h_r[perm[:target]] = 1.0

            # For k=10: x^10 + x^7 + 1 (taps at 10, 7)

                        8: [8, 6], 9: [9, 5], 10: [10, 7], 11: [11, 9],
                        12: [12, 11], 13: [13, 12]}
            taps = poly_map.get(k, [k, k - 2])
            seq = m_sequence_poly(min(n, period + 1), taps)
            if len(seq) < n:
                seq = np.resize(seq, n)

def logsumexp_obj(h, alpha, p):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full') * dx
    sorted_c = np.sort(corr)
    top = sorted_c[-p:]
    if len(top) == 0:
        return 0.0
    m = float(np.max(top))
    if alpha > 1:
        shifted = alpha * (top - m)
        shifted = np.clip(shifted, -500.0, 0.0)
        return float(m + np.log(np.sum(np.exp(shifted))) / alpha)
    else:
        return float(np.mean(top))


def slsqp_refine(h_start, n, target, time_limit, start_time):
    global _g_n, _g_target
    _g_n = n
    _g_target = target

    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': _cons_fun, 'jac': _cons_jac}]

    h_cur = h_start.copy()
    curr_score = compute_c5(h_cur)

    p_vals = [max(3, n // 60), max(5, n // 40), max(8, n // 25)]
    alphas = [100, 300, 800, 2000]

    for pi in range(len(p_vals)):
        for ai in range(len(alphas)):
            if (time.time() - start_time) > time_limit:
                return h_cur, curr_score
            p = p_vals[pi]
            alpha = alphas[ai]
            try:
                def obj(x, _a=alpha, _p=p):
                    return logsumexp_obj(x, _a, _p)

                res = minimize(obj, h_cur, method='SLSQP', bounds=bounds,
                               constraints=cons,
                               options={'maxiter': 800, 'ftol': 1e-14})
                h_new = project_feasible(res.x, target)
                sc = compute_c5(h_new)
                if sc < curr_score - 1e-15:
                    curr_score = sc
                    h_cur = h_new
            except Exception:
                pass

    # Softer passes
    for alpha in [50, 150]:
        if (time.time() - start_time) > time_limit:
            return h_cur, curr_score
        try:
            def obj2(x, _a=alpha):
                return logsumexp_obj(x, _a, n - 1)

            res = minimize(obj2, h_cur, method='SLSQP', bounds=bounds,
                           constraints=cons,
                           options={'maxiter': 500, 'ftol': 1e-14})
            h_new = project_feasible(res.x, target)
            sc = compute_c5(h_new)
            if sc < curr_score - 1e-15:
                curr_score = sc
                h_cur = h_new
        except Exception:
            pass

    return h_cur, curr_score

        if len(ones) == 0 or len(zeros) == 0:
            break
        i1 = ones[rng.randint(len(ones))]
        i0 = zeros[rng.randint(len(zeros))]
        h[i1] = 0
        h[i0] = 1
        corr_new = np.correlate(h, 1.0 - h, mode='full')
        c5_new = float(np.max(corr_new)) * dx
        if c5_new < best_c5 - 1e-14:
            best_c5 = c5_new
            corr = corr_new
            stall = 0
        else:
            h[i1] = 1
            h[i0] = 0
            stall += 1

    return h, best_c5


def run(seed=42, budget_s=1300, **kwargs):
    start_time = time.time()
    rng = np.random.RandomState(seed)

    def tleft():
        return budget_s - 25.0 - (time.time() - start_time)

    h_init = np.array(initial_h_values, dtype=float)
    n_init = len(h_init)
    target_init = n_init // 2

    best_h = project_binary(h_init, target_init)
    best_score = compute_c5(best_h)

    # Phase 1: SA from multiple diverse starts at n_init
    starts = generate_starts(n_init, rng, n_init, h_init)

    for si in range(min(len(starts), 5)):
        if tleft() < 120:
            break
        allowed = min(200.0, tleft() * 0.35)
        h_sa, c5_sa = sa_informed(starts[si], target_init, allowed, start_time, rng,
                                  t_init=0.012, t_final=0.0001, top_m=8)
        if c5_sa < best_score:
            best_score = c5_sa
            best_h = h_sa.copy()
        # Quick hill climb after SA
        if tleft() > 60:
            h_hc, c5_hc = hill_climb(h_sa, target_init, 8000, rng)
            if c5_hc < best_score:
                best_score = c5_hc
                best_h = h_hc.copy()

    # Phase 2: SLSQP refinement at n_init
    if tleft() > 100:
        h_ref, sc_ref = slsqp_refine(best_h, n_init, float(target_init),
                                     tleft() - 60, start_time)
        if sc_ref < best_score:
            best_score = sc_ref
            best_h = h_ref

    # Phase 3: Try different grid sizes
    n_candidates = []
    for nf in [0.75, 0.85, 0.9, 1.1, 1.15, 1.25, 1.4, 1.5]:
        n_try = int(n_init * nf)
        if n_try % 2 == 0 and n_try != n_init and n_try >= 200:
            n_candidates.append(n_try)
    # Also try specific values
    for n_special in [512, 1024, 384, 768]:
        if n_special != n_init and n_special >= 200:
            n_candidates.append(n_special)
    n_candidates = sorted(set(n_candidates))

    for n_try in n_candidates[:6]:
        if tleft() < 100:
            break
        target_try = n_try // 2
        h_interp = interpolate_to(best_h, n_try, target_try)
        h_bin = project_binary(h_interp, target_try)
        allowed = min(100.0, tleft() * 0.3)
        h_sa, c5_sa = sa_informed(h_bin, target_try, allowed, start_time, rng,
                                  t_init=0.010, t_final=0.0001, top_m=6)
        if tleft() > 50:
            h_hc, c5_hc = hill_climb(h_sa, target_try, 5000, rng)
            if c5_hc < c5_sa:
                h_sa = h_hc
                c5_sa = c5_hc
        if tleft() > 40:
            h_ref_n, sc_n = slsqp_refine(h_sa, n_try, float(target_try),
                                         min(60.0, tleft() - 30), start_time)
            if sc_n < c5_sa:
                h_sa = h_ref_n
                c5_sa = sc_n
        if c5_sa < best_score:
            best_score = c5_sa
            best_h = h_sa.copy()

    # Phase 4: Intensive refinement of best solution
    n_best = len(best_h)
    target_best = best_h.sum()
    if abs(target_best - n_best // 2.0) < 1.0:
        target_best = n_best // 2

    # More SA from perturbed best
    for restart in range(3):
        if tleft() < 50:
            break
        noise = rng.choice([0.005, 0.01, 0.02])
        h_pert = best_h + rng.randn(n_best) * noise
        h_pert = project_binary(h_pert, int(target_best))
        allowed = min(80.0, tleft() * 0.25)
        h_sa, c5_sa = sa_informed(h_pert, int(target_best), allowed, start_time, rng,
                                  t_init=0.005, t_final=0.00005, top_m=10)
        if c5_sa < best_score:
            best_score = c5_sa
            best_h = h_sa.copy()

    # Final SLSQP
    if tleft() > 40:
        h_ref, sc_ref = slsqp_refine(best_h, n_best, float(target_best),
                                     min(tleft() - 20, 80.0), start_time)
        if sc_ref < best_score:
            best_score = sc_ref
            best_h = h_ref

    # Final hill climb
    if tleft() > 15:
        h_bin_final = project_binary(best_h, int(target_best))
        h_hc, c5_hc = hill_climb(h_bin_final, int(target_best),
                                 int(max(5000, tleft() * 3000)), rng)
        if c5_hc < best_score:
            best_score = c5_hc
            best_h = h_hc

    # Ensure feasibility
    n_final = len(best_h)
    target_final = int(round(np.sum(best_h)))
    if target_final != n_final // 2:
        best_h = project_binary(best_h, n_final // 2)
    else:
        best_h = np.clip(best_h, 0.0, 1.0)
        s = np.sum(best_h)
        if abs(s - n_final // 2) > 0.01:
            best_h = project_feasible(best_h, n_final // 2.0)

    final_score = compute_c5(best_h)
    if final_score > best_score + 1e-6:
        final_score = best_score

    return best_h, final_score, n_final
