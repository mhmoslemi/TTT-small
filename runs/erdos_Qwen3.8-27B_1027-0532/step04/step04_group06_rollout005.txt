- Where b appears in h[n] (n=b): was h[b+ℓ]*(1-0)=h[b+ℓ], now h[b+ℓ]*(1-1)=0. Change: -h[b+ℓ]

So ΔO(ℓ) from flipping b (0→1) = (1-h[b-ℓ]) - h[b+ℓ] = 1 - h[b-ℓ] - h[b+ℓ]

For binary h:
- If both neighbors are 0: 1-0-0 = +1
- If one neighbor is 0, other is 1: 1-0-1 = 0 or 1-1-0 = 0
- If both neighbors are 1: 1-1-1 = -1

Combined swap (a: 1→0, b: 0→1):
ΔO(ℓ) = [h[a+ℓ] + h[a-ℓ] - 1] + [1 - h[b-ℓ] - h[b+ℓ]]
        = h[a+ℓ] + h[a-ℓ] - h[b-ℓ] - h[b+ℓ]

This is very clean! For binary h, the change in overlap at lag ℓ from swapping a and b is:
ΔO(ℓ) = h[a+ℓ] + h[a-ℓ] - h[b-ℓ] - h[b+ℓ]

This can be computed for all ℓ in O(n) using numpy:
ΔO = h[a+ℓ_range] + h[a-ℓ_range] - h[b-ℓ_range] - h[b+ℓ_range]

where ℓ_range = np.arange(-(n-1), n) and we use np.roll or indexing with clipping.

Actually, we can use a clever trick. Define the "influence vector" of position p at lag ℓ as:

Then ΔO(ℓ) = f_a(ℓ) - f_b(ℓ)

This is a vector of length 2n-1, and it's the difference of two "influence vectors".

Now, the new max is:

We want this to be less than the current max.

import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr)) * dx

def get_overlap(h):
    """Return the overlap vector O(ℓ) for all lags ℓ."""
    return np.correlate(h, 1.0 - h, mode='full')

def influence_vec(a, h, n):
    """Compute f_a[ℓ] = h[a+ℓ] + h[a-ℓ] for all lags."""
    lags = np.arange(-(n-1), n)
    idx1 = a + lags
    idx2 = a - lags
    h1 = np.where((idx1 >= 0) & (idx1 < n), h[np.clip(idx1, 0, n-1)], 0)
    h2 = np.where((idx2 >= 0) & (idx2 < n), h[np.clip(idx2, 0, n-1)], 0)
    return h1 + h2

def project_binary(h, target_sum):
    """Project h to nearest binary with exactly target_sum ones."""
    n = len(h)
    h_r = np.round(h).astype(int)
    h_r = np.clip(h_r, 0, 1)
    current = h_r.sum()
    if current == target_sum:
        return h_r.astype(float)
    if current > target_sum:
        need = current - target_sum
        ones = np.where(h_r == 1)[0]
        order = np.argsort(h[ones])[:need]
        h_r[ones[order]] = 0
    else:
        need = target_sum - current
        zeros = np.where(h_r == 0)[0]
        order = np.argsort(-h[zeros])[:need]
        h_r[zeros[order]] = 1
    return h_r.astype(float)

def project_feasible(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    diff = target_sum - np.sum(h)
    if abs(diff) > 1e-14:
        if diff > 0:
            idx = np.where(h < 1.0)[0]
        else:
            idx = np.where(h > 0.0)[0]
        if len(idx) > 0:
            h = h.copy()
            h[idx] += diff / len(idx)
            h = np.clip(h, 0.0, 1.0)
    return h

    if n_src == n_dst:
        return project_feasible(h_src.copy(), target_dst)
    x_new = np.linspace(0.0, 1.0, n_dst)
    x_old = np.linspace(0.0, 1.0, n_src)
    h_out = np.interp(x_new, x_old, h_src)
    return project_feasible(h_out, target_dst)

Let me also think about a completely different approach that might be more effective:

**Approach: Minimax with iterative lag focusing**

Instead of a pure greedy approach, use an iterative algorithm that:
1. Identifies the worst lag ℓ*
2. Finds the best single swap that reduces O(ℓ*) the most (while not increasing any other lag above the current max)
3. If no such swap exists, relax the constraint and find the best swap that reduces O(ℓ*)
4. Repeat

This is more focused but might get stuck if one lag is "locked" (can't be reduced without hurting another).

**Approach: Multi-objective with weighted sum**

Instead of exactly minimizing the max, approximate it with a weighted sum:
minimize Σ_ℓ w_ℓ * O(ℓ) where w_ℓ is proportional to how close O(ℓ) is to the max.

This can be optimized with standard techniques (e.g., coordinate descent on the binary variables).

For a weighted sum objective with binary variables, the best single move is:
minimize (a,b) Σ_ℓ w_ℓ * ΔO(ℓ) = (a,b) [Σ_ℓ w_ℓ * f_a(ℓ) - Σ_ℓ w_ℓ * f_b(ℓ)]
= (a,b) [g(a) - g(b)]

where g(p) = Σ_ℓ w_ℓ * (h[p+ℓ] + h[p-ℓ])

So the best move is: pick a with smallest g(a) among ones, and b with largest g(b) among zeros.

This can be computed efficiently:
1. Compute g(p) for all p = 0, ..., n-1 (O(n²) total, or O(n) per p)
2. Pick a = argmin_{p: h[p]=1} g(p)
3. Pick b = argmax_{p: h[p]=0} g(b)
4. Apply swap

Actually, g(p) can be computed for all p at once!

g(p) = Σ_ℓ w_ℓ * h[p+ℓ] + Σ_ℓ w_ℓ * h[p-ℓ]
     = Σ_ℓ w_ℓ * h[p+ℓ] + Σ_ℓ w_ℓ * h[p-ℓ]

The first sum is a convolution: (w * h)[p] where w is indexed by ℓ.
The second sum is a correlation: (w ⋆ h)[p].

So g = convolve(w, h) + correlate(w, h) (in the appropriate sense).

This can be computed in O(n log n) using FFT!
