Actually, let me think about this differently. The function f(t) = max_m (C_m + s_m * t) is convex. For a convex piecewise-linear function, the minimum is where the subgradient contains 0. The subgradient at t is:
∂f(t) = [min_{m ∈ A(t)} s_m, max_{m ∈ A(t)} s_m]
where A(t) = {m : C_m + s_m * t = f(t)} is the active set.

The optimal t* satisfies: 0 ∈ ∂f(t*), i.e., min_{m ∈ A(t*)} s_m ≤ 0 ≤ max_{m ∈ A(t*)} s_m.

For a practical implementation:
1. Find t where the two "extreme" lines cross
2. The "lower" line is the one with the smallest slope that's still active
3. The "upper" line is the one with the largest slope that's still active

A simple O(M) algorithm:
- Sort lines by slope
- The upper envelope changes at specific breakpoints
- The minimum of the upper envelope is at the leftmost breakpoint where the slope changes from negative to positive

```python
def solve_1d_minimax(C, s, t_lo=0.0, t_hi=1.0, n_grid=50):
    """Solve min_t max_m (C[m] + s[m]*t) for t in [t_lo, t_hi]."""
    # Coarse grid
    t_grid = np.linspace(t_lo, t_hi, n_grid)
    vals = np.max(C[None, :] + s[None, :] * t_grid[:, None], axis=1)
    best_idx = np.argmin(vals)
    best_t = t_grid[best_idx]
    
    # Refine: bisection on the subgradient
    # At the optimum, there should be lines with negative and positive slopes in the active set
    for _ in range(30):
        f_val = np.max(C + s * best_t)
        active = np.abs(C + s * best_t - f_val) < 1e-10
        if not np.any(active):
            active = (C + s * best_t) > f_val - 1e-10
        s_active = s[active]
        if np.min(s_active) > 0:
            # All active slopes positive → move left
            best_t = max(t_lo, best_t * 0.5)
        elif np.max(s_active) < 0:
            # All active slopes negative → move right
            best_t = min(t_hi, best_t + (t_hi - best_t) * 0.5)
        else:
            # 0 is in the subgradient → we're at the optimum (approximately)
            break
    
    return best_t
```

```python
def solve_1d_minimax(C, s, t_lo=0.0, t_hi=1.0):
    """Golden section search for min_t max_m (C[m] + s[m]*t)."""
    def f(t):
        return np.max(C + s * t)
    
    gr = (np.sqrt(5) - 1) / 2  # golden ratio
    a, b = t_lo, t_hi
    c = b - gr * (b - a)
    d = a + gr * (b - a)
    fc = f(c)
    fd = f(d)
    
    for _ in range(50):  # 50 iterations gives ~gr^50 ≈ 2^-75 precision
        if fc < fd:
            b = d
            d = c
            fd = fc
            c = b - gr * (b - a)
            fc = f(c)
        else:
            a = c
            c = d
            fc = fd
            d = a + gr * (b - a)
            fd = f(d)
    
    return (a + b) / 2
```
