```python
        i_end = a - k_min_a + 1
        delta[j_start:j_end] += h[i_start:i_end][::-1] - 1.0
    
    # B: position a in (1-h[i]) slot
    k_min_b = max(-(n-1), -a)
    k_max_b = min(n-1, n-1-a)
    if k_min_b <= k_max_b:
        j_start = k_min_b + n - 1
        j_end = k_max_b + n - 1 + 1
        idx_start = a + k_min_b
        idx_end = a + k_max_b + 1
        delta[j_start:j_end] += h[idx_start:idx_end]
    
    # C: position b in h[i+k] slot
    k_min_c = max(b - n + 1, -(n-1))
    k_max_c = min(b, n-1)
    if k_min_c <= k_max_c:
        j_start = k_min_c + n - 1
        j_end = k_max_c + n - 1 + 1
        i_start = b - k_max_c
        i_end = b - k_min_c + 1
        delta[j_start:j_end] += 1.0 - h[i_start:i_end][::-1]
    
    # D: position b in (1-h[i]) slot
    k_min_d = max(-(n-1), -b)
    k_max_d = min(n-1, n-1-b)
    if k_min_d <= k_max_d:
        j_start = k_min_d + n - 1
        j_end = k_max_d + n - 1 + 1
        idx_start = b + k_min_d
        idx_end = b + k_max_d + 1
        delta[j_start:j_end] += -h[idx_start:idx_end]
    
    return delta
```

This is O(1) vectorized operations (each is a slice assignment of length O(n)), so it's very fast.

Now, the key algorithm:

1. Maintain h (binary), corr vector (before *dx)
2. For each iteration:
   a. Identify top-M worst shifts (highest corr values)
   b. Compute the "gradient" for the worst shifts
   c. Generate candidate swaps (a from 1s, b from 0s) scored by their effect on worst shifts
   d. Evaluate the top candidates using compute_swap_delta_vec
   e. Pick the best swap (lowest new max corr)
   f. Apply it and update corr

Let me think about the scoring for candidate swaps more carefully.

For the worst shift k*, if h[a]=1 and h[a+k*]=0 (or h[a-k*]=0), then moving h[a] from 1 to 0 would reduce corr[k*]. Similarly, if h[b]=0 and h[b+k*]=1 (or h[b-k*]=1), then moving h[b] from 0 to 1 would... wait, let me think again.

corr[k] = sum_i h[i+k]*(1-h[i])

If h[a]=1 and I change it to 0:
- In the h[i+k] slot: was contributing (1-h[i]) where a=i+k, i.e., h[a]*(1-h[a-k]) = 1-h[a-k]. Now 0. Reduces corr by (1-h[a-k]).
- In the (1-h[i]) slot: was contributing h[i+k]*(1-h[a]) = 0. Now h[i+k]*1 = h[i+k]. Increases corr by h[i+k].

Wait, so changing h[a] from 1 to 0:
- Reduces corr[k] by (1-h[a-k]) for shift k (a in h slot)
- Increases corr[k] by h[a+k] for shift k (a in (1-h) slot)

Net effect on corr[k]: -(1-h[a-k]) + h[a+k] = h[a-k] - 1 + h[a+k]

For the worst shift k*, if h[a-k*]=0 and h[a+k*]=0:
Net effect = 0 - 1 + 0 = -1 (reduces corr[k*] by 1)

If h[a-k*]=1:
Net effect = 1 - 1 + h[a+k*] = h[a+k*] >= 0 (might increase!)

So the best a to move from 1 to 0 for shift k* is one where h[a-k*]=0 and h[a+k*]=0.

Similarly for b (0 to 1):
- In h slot: was 0, now 1-h[b-k]. Increases by (1-h[b-k]).
- In (1-h) slot: was h[b+k], now 0. Decreases by h[b+k].

Net effect on corr[k]: (1-h[b-k]) - h[b+k]

Best b to move from 0 to 1 for shift k*: h[b-k*]=1 and h[b+k*]=1.
Net effect = 0 - 1 = -1 (reduces corr[k*] by 1).

Wait, that doesn't seem right. Let me recheck.

For b (changing from 0 to 1):
- b in h[i+k] slot: i+k=b, i=b-k. Old: h[b]*(1-h[b-k]) = 0. New: 1*(1-h[b-k]) = 1-h[b-k]. Delta: +(1-h[b-k]).
- b in (1-h[i]) slot: i=b. Old: h[b+k]*(1-h[b]) = h[b+k]*1 = h[b+k]. New: h[b+k]*0 = 0. Delta: -h[b+k].

Net: (1-h[b-k]) - h[b+k]

If h[b-k]=1 and h[b+k]=1: net = 0 - 1 = -1. Good, reduces corr.
If h[b-k]=0 and h[b+k]=0: net = 1 - 0 = +1. Bad, increases corr!

So for the worst shift k*:
- Best a (1->0): h[a-k*]=0, h[a+k*]=0
- Best b (0->1): h[b-k*]=1, h[b+k*]=1

This makes intuitive sense: move a 1 that doesn't "help" any correlation to a position that "helps" reduce a correlation.

Now, for multiple worst shifts, I want to find a and b that are good for many of them simultaneously.

Let me code up the full algorithm:

```python
def greedy_local_search(h, target_sum, max_iters, rng, time_limit, start_time):
    n = len(h)
    h = h.copy()
    assert h.sum() == target_sum
    corr_raw = np.correlate(h, 1-h, mode='full')  # before *dx
    dx = 2.0 / n
    best_c5 = np.max(corr_raw) * dx
    best_h = h.copy()
    
    no_improve = 0
    max_no_improve = 5000
    
    for it in range(max_iters):
        if time.time() - start_time > time_limit:
            break
        if no_improve > max_no_improve:
            break
        
        # Find top-M worst shifts
        M = min(20, 2*n-1)
        worst_indices = np.argsort(-corr_raw)[:M]
        
        # Compute multi-shift gradient
        # grad_a[i] for i where h[i]=1: net effect on worst shifts if h[i] 1->0
        # grad_b[i] for i where h[i]=0: net effect on worst shifts if h[i] 0->1
        ones = np.where(h == 1)[0]
        zeros = np.where(h == 0)[0]
        
        if len(ones) == 0 or len(zeros) == 0:
            break
        
        # For each worst shift k (as offset from n-1 in the corr array):
        # k offset = worst_index - (n-1)
        # Net effect of 1->0 at position a: sum over worst shifts of (h[a-k]-1+h[a+k])
        #   where valid indices only
        # Net effect of 0->1 at position b: sum over worst shifts of (1-h[b-k]-h[b+k])
        
        # Vectorized computation:
        # For position a and shift k: contribution is h[a-k]-1+h[a+k] (if valid)
        # For position b and shift k: contribution is 1-h[b-k]-h[b+k] (if valid)
        
        # Build the score arrays
        score_a = np.zeros(n)  # lower is better (more negative = better reduction)
        score_b = np.zeros(n)
        
        for wi in worst_indices:
            k = wi - (n - 1)
            # For a: h[a-k]-1+h[a+k] for valid a-k and a+k
            # a-k valid: 0<=a-k<n => k<=a<n+k
            # a+k valid: 0<=a+k<n => -k<=a<n-k
            # Combined: max(0,-k) <= a < min(n, n-k) if k>=0, or max(0,k) <= a < min(n, n+k) if k<0
            # Simplify: a in [max(0, k), min(n-1, n-1-k)] if k >= 0
            #           a in [max(0, -k), min(n-1, n-1+k)] if k < 0
            # Actually: a-k >= 0 => a >= k (if k>0) or always (if k<=0)
            #           a-k <= n-1 => a <= n-1+k
            #           a+k >= 0 => a >= -k (if k<0) or always (if k>=0)
            #           a+k <= n-1 => a <= n-1-k
            # So a in [max(0, k if k>0 else 0, (-k) if k<0 else 0), min(n-1, (n-1+k) if k>0 else n-1, (n-1-k) if k<0 else n-1)]
            
            a_lo = max(0, k) if k > 0 else max(0, -k)
            a_hi = min(n-1, n-1+k) if k > 0 else min(n-1, n-1-k)
            
            if a_lo <= a_hi:
                # For a in [a_lo, a_hi]:
                # contribution = h[a-k] - 1 + h[a+k]
                score_a[a_lo:a_hi+1] += h[a_lo-k:a_hi-k+1] - 1.0 + h[a_lo+k:a_hi+k+1]
            
            # For b: 1-h[b-k]-h[b+k]
            b_lo = max(0, k) if k > 0 else max(0, -k)
            b_hi = min(n-1, n-1+k) if k > 0 else min(n-1, n-1-k)
            
            if b_lo <= b_hi:
                score_b[b_lo:b_hi+1] += 1.0 - h[b_lo-k:b_hi-k+1] - h[b_lo+k:b_hi+k+1]
        
        # For positions with h=1, we want the most negative score_a (biggest reduction)
        # For positions with h=0, we want the most negative score_b
        
        # Mask to valid positions
        score_a_masked = np.where(h == 1, score_a, np.inf)
        score_b_masked = np.where(h == 0, score_b, np.inf)
        
        # Get top candidates
        num_cand_a = min(50, len(ones))
        num_cand_b = min(50, len(zeros))
        
        top_a = np.argsort(score_a_masked)[:num_cand_a]
        top_b = np.argsort(score_b_masked)[:num_cand_b]
        
        # Also add some random candidates for diversity
        if rng.random() < 0.3:
            rand_a = ones[rng.randint(len(ones))]
            rand_b = zeros[rng.randint(len(zeros))]
            top_a = np.append(top_a, rand_a)
            top_b = np.append(top_b, rand_b)
        
        best_new_c5 = np.inf
        best_a = None
        best_b = None
        best_corr_new = None
        
        for a in top_a:
            if h[a] != 1:
                continue
            for b in top_b:
                if h[b] != 0:
                    continue
                if a == b:
                    continue
                delta = compute_swap_delta_vec(h, a, b, n)
                corr_new = corr_raw + delta
                new_max = np.max(corr_new)
                if new_max < best_new_c5:
                    best_new_c5 = new_max
                    best_a = a
                    best_b = b
                    best_corr_new = corr_new
        
        if best_a is None:
            # Try random swaps
            for _ in range(100):
                a = ones[rng.randint(len(ones))]
                b = zeros[rng.randint(len(zeros))]
                if a == b:
                    continue
                delta = compute_swap_delta_vec(h, a, b, n)
                corr_new = corr_raw + delta
                new_max = np.max(corr_new)
                if new_max < best_new_c5:
                    best_new_c5 = new_max
                    best_a = a
                    best_b = b
                    best_corr_new = corr_new
        
        if best_a is None or best_new_c5 >= corr_raw.max():
            no_improve += 1
            continue
        
        # Apply the swap
        h[best_a] = 0
        h[best_b] = 1
        corr_raw = best_corr_new
        current_c5 = np.max(corr_raw) * dx
        
        if current_c5 < best_c5 - 1e-14:
            best_c5 = current_c5
            best_h = h.copy()
            no_improve = 0
        else:
            no_improve += 1
    
    return best_h, best_c5
```

2. We use the full correlation vector to evaluate moves in O(n) time
3. We focus specifically on the worst shifts

Actually, let me also think about a different approach: **pairwise conflict resolution**.

The correlation at shift k is:
corr[k] = sum_i h[i+k]*(1-h[i])

This counts the number of "conflicts" at shift k: pairs (i, i+k) where h[i+k]=1 and h[i]=0.

To minimize the maximum, we want to balance the conflicts across all shifts. A good strategy is:
1. Find the current maximum shift k*
2. Find all conflict pairs at shift k*
3. For each conflict pair (i, i+k*), consider: can we resolve it by flipping one of the positions?
   - Flip h[i+k*] from 1 to 0: reduces corr[k*] by 1, but might increase other correlations
   - Flip h[i] from 0 to 1: reduces corr[k*] by 1, but might increase other correlations
   - Move the 1 from position i+k* to some other position j: more complex

The greedy approach I described above essentially does this but in a smarter way by considering all positions simultaneously and using the full correlation vector for evaluation.

Let me also think about whether we should work in the continuous space or stick with binary. The problem says h: [0,2] -> [0,1], so non-binary values are allowed. However, for the discrete problem with the sum constraint sum(h) = n/2, the optimal solution is likely binary (or close to binary) because the objective is linear in each h[i] for fixed other values.

Wait, is that true? Let's check. The correlation at shift k is:
corr[k] = sum_i h[i+k]*(1-h[i]) = sum_i h[i+k] - sum_i h[i+k]*h[i]

This is not linear in h! The term h[i+k]*h[i] is quadratic. So the objective is not linear in h.

However, for binary h, corr[k] = (number of i where h[i+k]=1 and h[i]=0), which is an integer. The maximum is then an integer times dx.

For non-binary h, we might get better values. But the SLSQP approach in the previous code already tries this. Let me focus on the binary case first and then try SLSQP refinement.

```python
import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr)) * dx

def compute_corr_raw(h):
    return np.correlate(h, 1.0 - h, mode='full')

def project_binary(h, target_sum):
    n = len(h)
    h_r = np.round(h).astype(int)
    current_sum = h_r.sum()
    if current_sum == target_sum:
        return h_r.astype(float)
    ones = np.where(h_r == 1)[0]
    zeros = np.where(h_r == 0)[0]
    if current_sum > target_sum:
        need = int(current_sum - target_sum)
        if need <= len(ones):
            order = np.argsort(h[ones])[:need]
            h_r[ones[order]] = 0
    else:
        need = int(target_sum - current_sum)
        if need <= len(zeros):
            order = np.argsort(-h[zeros])[:need]
            h_r[zeros[order]] = 1
    final_sum = h_r.sum()
    if final_sum != target_sum:
        if final_sum > target_sum:
            o = np.where(h_r == 1)[0]
            h_r[o[:int(final_sum - target_sum)]] = 0
        else:
            z = np.where(h_r == 0)[0]
            h_r[z[:int(target_sum - final_sum)]] = 1
    return h_r.astype(float)

def compute_swap_delta(h, a, b, n):
    """O(n) vectorized computation of correlation change for swap a(1->0), b(0->1)."""
    delta = np.zeros(2 * n - 1)
    
    # A: a in h[i+k] slot => i = a-k, j = k+n-1
    # k range: a-n+1 <= k <= a, intersect [-(n-1), n-1]
    k_lo = max(a - n + 1, -(n-1))
    k_hi = min(a, n-1)
    if k_lo <= k_hi:
        js = k_lo + n - 1
        je = k_hi + n - 1 + 1
        # i = a-k, when k=k_lo, i=a-k_lo; when k=k_hi, i=a-k_hi
        # i ranges from a-k_hi to a-k_lo
        i_s = a - k_hi
        i_e = a - k_lo + 1
        delta[js:je] += h[i_s:i_e][::-1] - 1.0
    
    # B: a in (1-h[i]) slot => i=a, j=k+n-1, need 0<=a+k<n
    # k range: -a <= k <= n-1-a, intersect [-(n-1), n-1]
    k_lo = max(-(n-1), -(a))  # -a can be 0
    k_hi = min(n-1, n-1-a)
    if k_lo <= k_hi:
        js = k_lo + n - 1
        je = k_hi + n - 1 + 1
        delta[js:je] += h[a+k_lo : a+k_hi+1]
    
    # C: b in h[i+k] slot => i = b-k, j = k+n-1
    k_lo = max(b - n + 1, -(n-1))
    k_hi = min(b, n-1)
    if k_lo <= k_hi:
        js = k_lo + n - 1
        je = k_hi + n - 1 + 1
        i_s = b - k_hi
        i_e = b - k_lo + 1
        delta[js:je] += 1.0 - h[i_s:i_e][::-1]
    
    # D: b in (1-h[i]) slot => i=b, j=k+n-1, need 0<=b+k<n
    k_lo = max(-(n-1), -(b))
    k_hi = min(n-1, n-1-b)
    if k_lo <= k_hi:
        js = k_lo + n - 1
        je = k_hi + n - 1 + 1
        delta[js:je] += -h[b+k_lo : b+k_hi+1]
    
    return delta

def greedy_search(h_init, target_sum, max_iters, rng, time_limit, start_time, M=20, n_cand=30):
    n = len(h_init)
    h = h_init.copy()
    dx = 2.0 / n
    corr = compute_corr_raw(h)
    best_c5 = float(np.max(corr)) * dx
    best_h = h.copy()
    no_improve = 0
    max_no_improve = max(5000, max_iters // 10)
    
    for it in range(max_iters):
        if time.time() - start_time > time_limit:
            break
        if no_improve > max_no_improve:
            break
        
        ones = np.where(h == 1)[0]
        zeros = np.where(h == 0)[0]
        if len(ones) == 0 or len(zeros) == 0:
            break
        
        # Top-M worst shifts
        M_use = min(M, 2*n-1)
        worst = np.argsort(-corr)[:M_use]
        
        # Compute scores
        score_a = np.zeros(n)
        score_b = np.zeros(n)
        
        for wi in worst:
            k = wi - (n - 1)
            # For a (1->0): contribution to shift k is h[a-k]-1+h[a+k]
            # Valid range for a: need 0<=a-k<n and 0<=a+k<n
            if k >= 0:
                a_lo = k
                a_hi = min(n-1, n-1-k)
            else:
                a_lo = -k
                a_hi = min(n-1, n-1+k)
            
            if a_lo <= a_hi:
                score_a[a_lo:a_hi+1] += h[a_lo-k:a_hi-k+1] - 1.0 + h[a_lo+k:a_hi+k+1]
            
            # For b (0->1): contribution is 1-h[b-k]-h[b+k]
            # Same valid range
            if k >= 0:
                b_lo = k
                b_hi = min(n-1, n-1-k)
            else:
                b_lo = -k
                b_hi = min(n-1, n-1+k)
            
            if b_lo <= b_hi:
                score_b[b_lo:b_hi+1] += 1.0 - h[b_lo-k:b_hi-k+1] - h[b_lo+k:b_hi+k+1]
        
        # Get candidates
        nc = min(n_cand, len(ones))
        nc_b = min(n_cand, len(zeros))
        
        sa_m = np.where(h == 1, score_a, 1e9)
        sb_m = np.where(h == 0, score_b, 1e9)
        
        top_a = np.argsort(sa_m)[:nc]
        top_b = np.argsort(sb_m)[:nc_b]
        
        # Add random candidates
        if len(ones) > nc:
            for _ in range(5):
                top_a = np.append(top_a, ones[rng.randint(len(ones))])
        if len(zeros) > nc_b:
            for _ in range(5):
                top_b = np.append(top_b, zeros[rng.randint(len(zeros))])
        
        best_new_max = np.inf
        best_a = -1
        best_b = -1
        best_corr_new = None
        current_max = np.max(corr)
        
        for a in top_a:
            if a < 0 or a >= n or h[a] != 1:
                continue
            for b in top_b:
                if b < 0 or b >= n or h[b] != 0 or a == b:
                    continue
                d = compute_swap_delta(h, a, b, n)
                rn_max = np.max(corr + d)
                if rn_max < best_new_max:
                    best_new_max = rn_max
                    best_a = a
                    best_b = b
                    best_corr_new = corr + d
        
        if best_a < 0:
            # Random search
            for _ in range(50):
                a = ones[rng.randint(len(ones))]
                b = zeros[rng.randint(len(zeros))]
                if a == b:
                    continue
                d = compute_swap_delta(h, a, b, n)
                rn_max = np.max(corr + d)
                if rn_max < best_new_max:
                    best_new_max = rn_max
                    best_a = a
                    best_b = b
                    best_corr_new = corr + d
        
        if best_a < 0:
            no_improve += 1
            # Try random perturbation to escape
            if no_improve > max_no_improve // 2 and rng.random() < 0.1:
                a = ones[rng.randint(len(ones))]
                b = zeros[rng.randint(len(zeros))]
                h[a] = 0
                h[b] = 1
                corr = compute_corr_raw(h)
                no_improve = max(0, no_improve - 100)
            continue
        
        # Apply swap
        h[best_a] = 0
        h[best_b] = 1
        corr = best_corr_new
        c5_cur = np.max(corr) * dx
        
        if c5_cur < best_c5 - 1e-14:
            best_c5 = c5_cur
            best_h = h.copy()
            no_improve = 0
        else:
            no_improve += 1
    
    return best_h, best_c5
```

**Alternative: Subgradient method with projection**

The objective is f(h) = max_k g_k(h) where g_k(h) = sum_i h[i+k]*(1-h[i]) * dx.

The subgradient of f at h is in the convex hull of {grad g_k : g_k(h) = f(h)}.

A practical approach:
1. Compute all g_k(h)
2. Find the set S of active constraints (g_k ≈ f(h))
3. Compute the subgradient as the average of grad g_k for k in S
4. Take a step in the -subgradient direction
5. Project to the feasible set [0,1]^n with sum constraint

The gradient of g_k with respect to h[j]:
g_k(h) = sum_i h[i+k]*(1-h[i]) * dx

d/dh[j] g_k = dx * [sum over i where i+k=j of (1-h[i]) - sum over i where i=j of h[i+k]]
= dx * [(1-h[j-k]) * I[valid] - h[j+k] * I[valid]]

This is the same as what I computed before for the swap delta!

So the subgradient at position j is:
grad[j] = dx * sum_{k in S} [(1-h[j-k]) - h[j+k]] (with validity checks)

This is exactly the score_a / score_b I computed in the greedy search!

So the greedy search is essentially a discrete version of the subgradient method. The improvement would be to:
1. Use the subgradient to identify which positions to adjust
2. Make small continuous adjustments (not just binary swaps)
3. Project to [0,1] and the sum constraint

```python
def subgradient_method(h_init, target_sum, max_iters, time_limit, start_time):
    n = len(h_init)
    dx = 2.0 / n
    h = h_init.astype(float).copy()
    h = project_feasible(h, target_sum)
    
    best_h = h.copy()
    best_c5 = compute_c5(h)
    
    for it in range(max_iters):
        if time.time() - start_time > time_limit:
            break
        
        corr = compute_corr_raw(h) * dx
        current_max = np.max(corr)
        
        # Find active set (top values within epsilon of max)
        epsilon = 0.01 * dx  # or some adaptive threshold
        active = np.where(corr >= current_max - epsilon)[0]
        
        if len(active) == 0:
            active = np.array([np.argmax(corr)])
        
        # Compute subgradient
        grad = np.zeros(n)
        for wi in active:
            k = wi - (n - 1)
            # grad[j] += (1-h[j-k]) - h[j+k] (with validity)
            if k >= 0:
                j_lo = k
                j_hi = n - 1 - k
            else:
                j_lo = -k
                j_hi = n - 1 + k
            grad[j_lo:j_hi+1] += (1 - h[j_lo-k:j_hi-k+1]) - h[j_lo+k:j_hi+k+1]
        
        # Normalize
        grad_norm = np.linalg.norm(grad)
        if grad_norm < 1e-10:
            break
        
        # Step size (adaptively)
        step = 0.1 / (grad_norm + 1e-10)
        # Or use a simple decay
        # step = 0.5 / (it + 10)
        
        h_new = h - step * grad
        h_new = np.clip(h_new, 0, 1)
        
        # Project to sum constraint
        diff = target_sum - h_new.sum()
        if abs(diff) > 1e-10:
            # Adjust uniformly
            h_new += diff / n
            h_new = np.clip(h_new, 0, 1)
            # If still not feasible, do iterative projection
            for _ in range(20):
                h_new = np.clip(h_new, 0, 1)
                diff = target_sum - h_new.sum()
                if abs(diff) < 1e-10:
                    break
                mask = (h_new < 1) if diff > 0 else (h_new > 0)
                if mask.sum() == 0:
                    break
                h_new[mask] += diff / mask.sum()
        
        c5_new = compute_c5(h_new)
        if c5_new < best_c5:
            best_c5 = c5_new
            best_h = h_new.copy()
            h = h_new
        else:
            # Try smaller step
            h_try = h - 0.1 * step * grad
            h_try = np.clip(h_try, 0, 1)
            # ... project ...
            c5_try = compute_c5(h_try)
            if c5_try < best_c5:
                best_c5 = c5_try
                best_h = h_try.copy()
                h = h_try
            else:
                # No improvement, reduce step
                step *= 0.8
    
    return best_h, best_c5
```

```python
def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr)) * dx

def compute_corr_raw(h):
    return np.correlate(h, 1.0 - h, mode='full')

def project_feasible(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    diff = target_sum - np.sum(h)
    if abs(diff) < 1e-12:
        return h
    h = h.copy()
    for _ in range(50):
        h = np.clip(h, 0.0, 1.0)
        diff = target_sum - np.sum(h)
        if abs(diff) < 1e-12:
            break
        if diff > 0:
            mask = h < 1.0
        else:
            mask = h > 0.0
        if mask.sum() == 0:
            break
        h[mask] += diff / mask.sum()
    return np.clip(h, 0.0, 1.0)

def project_binary(h, target_sum):
    n = len(h)
    h_r = np.round(h).astype(int)
    current_sum = h_r.sum()
    if current_sum == target_sum:
        return h_r.astype(float)
    ones = np.where(h_r == 1)[0]
    zeros = np.where(h_r == 0)[0]
    if current_sum > target_sum:
        need = int(current_sum - target_sum)
        if need <= len(ones):
            order = np.argsort(h[ones])[:need]
            h_r[ones[order]] = 0
    else:
        need = int(target_sum - current_sum)
        if need <= len(zeros):
            order = np.argsort(-h[zeros])[:need]
            h_r[zeros[order]] = 1
    final_sum = h_r.sum()
    if final_sum != target_sum:
        if final_sum > target_sum:
            o = np.where(h_r == 1)[0]
            h_r[o[:int(final_sum - target_sum)]] = 0
        else:
            z = np.where(h_r == 0)[0]
            h_r[z[:int(target_sum - final_sum)]] = 1
    return h_r.astype(float)

def compute_swap_delta(h, a, b, n):
    delta = np.zeros(2 * n - 1)
    k_lo = max(a - n + 1, -(n - 1))
    k_hi = min(a, n - 1)
    if k_lo <= k_hi:
        js = k_lo + n - 1
        je = k_hi + n - 1 + 1
        i_s = a - k_hi
        i_e = a - k_lo + 1
        delta[js:je] += h[i_s:i_e][::-1] - 1.0
    k_lo = max(-(n - 1), -a)
    k_hi = min(n - 1, n - 1 - a)
    if k_lo <= k_hi:
        js = k_lo + n - 1
        je = k_hi + n - 1 + 1
        delta[js:je] += h[a + k_lo:a + k_hi + 1]
    k_lo = max(b - n + 1, -(n - 1))
    k_hi = min(b, n - 1)
    if k_lo <= k_hi:
        js = k_lo + n - 1
        je = k_hi + n - 1 + 1
        i_s = b - k_hi
        i_e = b - k_lo + 1
        delta[js:je] += 1.0 - h[i_s:i_e][::-1]
    k_lo = max(-(n - 1), -b)
    k_hi = min(n - 1, n - 1 - b)
    if k_lo <= k_hi:
        js = k_lo + n - 1
        je = k_hi + n - 1 + 1
        delta[js:je] += -h[b + k_lo:b + k_hi + 1]
    return delta

def top_p_smooth(h, alpha, p):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full') * dx
    sorted_corr = np.sort(corr)
    top = sorted_corr[-p:]
    max_top = np.max(top)
    shifted = np.clip(alpha * (top - max_top), -500.0, 0.0)
    return float(max_top + np.log(np.sum(np.exp(shifted))) / alpha)

    h_cur = h_start.copy()
    curr_score = compute_c5(h_cur)

    for p in p_vals:
        for alpha in alphas:
            if time_limit is not None and start_time is not None:
                if (time.time() - start_time) > time_limit:
                    return h_cur, curr_score
            try:
                res = minimize(lambda x: top_p_smooth(x, alpha, p), h_cur,
                               method='SLSQP', bounds=bounds, constraints=cons,
                               options={'maxiter': maxiter, 'ftol': ftol})
                h_new = project_feasible(res.x, target)
                sc = compute_c5(h_new)
                if sc < curr_score:
                    curr_score = sc
                    h_cur = h_new
            except Exception:
                pass
    return h_cur, curr_score

def subgradient_refine(h_start, target_sum, max_iters, time_limit, start_time,
                       step_init=0.05, step_decay=0.999, active_eps=0.005):
    n = len(h_start)
    dx = 2.0 / n
    h = h_start.astype(float).copy()
    h = project_feasible(h, target_sum)
    best_h = h.copy()
    best_c5 = compute_c5(h)
    step = step_init

    for it in range(max_iters):
        if time.time() - start_time > time_limit:
            break

        corr = compute_corr_raw(h) * dx
        current_max = np.max(corr)
        active_thresh = current_max - active_eps * dx * 10
        active = np.where(corr >= active_thresh)[0]
        if len(active) == 0:
            active = np.array([np.argmax(corr)])

        grad = np.zeros(n)
        for wi in active:
            k = wi - (n - 1)
            if k >= 0:
                lo = k
                hi = n - 1 - k
            else:
                lo = -k
                hi = n - 1 + k
            if lo <= hi:
                grad[lo:hi + 1] += (1.0 - h[lo - k:hi - k + 1]) - h[lo + k:hi + k + 1]

        grad_norm = np.linalg.norm(grad)
        if grad_norm < 1e-12:
            break

        h_try = h - step * grad
        h_try = np.clip(h_try, 0.0, 1.0)
        diff = target_sum - h_try.sum()
        if abs(diff) > 1e-10:
            for _ in range(30):
                h_try = np.clip(h_try, 0.0, 1.0)
                diff = target_sum - h_try.sum()
                if abs(diff) < 1e-10:
                    break
                mask = (h_try < 1.0) if diff > 0 else (h_try > 0.0)
                if mask.sum() == 0:
                    break
                h_try[mask] += diff / mask.sum()
        h_try = np.clip(h_try, 0.0, 1.0)

        c5_try = compute_c5(h_try)
        if c5_try < best_c5 - 1e-14:
            h = h_try
            best_c5 = c5_try
            best_h = h.copy()
            step = min(step * 1.05, 0.5)
        else:
            step *= step_decay

    return best_h, best_c5

def thue_morse_binary(n):
    t = np.zeros(n, dtype=float)
    for i in range(1, n):
        t[i] = np.binary_repr(i).count('1') % 2
    return project_binary(t, n // 2)

def interpolate_to(h_src, n_dst, target_dst):
    n_src = len(h_src)
    if n_src == n_dst:
        return project_feasible(h_src.copy(), target_dst)
    x_new = np.linspace(0.0, 1.0, n_dst)
    x_old = np.linspace(0.0, 1.0, n_src)
    h_out = np.interp(x_new, x_old, h_src)
    return project_feasible(h_out, target_dst)

def run(seed=42, budget_s=1300, **kwargs):
    global _cons_n, _cons_target
    start_time = time.time()
    rng = np.random.RandomState(seed)

    def tleft():
        return budget_s - 25.0 - (time.time() - start_time)

    h_init = np.array(initial_h_values, dtype=float)
    n = len(h_init)
    target = n / 2.0

    best_h = project_feasible(h_init.copy(), target)
    best_score = compute_c5(best_h)

    h_bin = project_binary(h_init, target)
    c5_bin = compute_c5(h_bin)

    starts = [h_bin]
    h_tm = thue_morse_binary(n)
    starts.append(h_tm)
    for _ in range(2):
        h_rand = np.zeros(n)
        perm = rng.permutation(n)
        h_rand[perm[:n // 2]] = 1.0
        starts.append(h_rand)

    for si in range(len(starts)):
        if tleft() < 200:
            break
        allowed = min(250.0, tleft() * 0.35)
        max_it = int(min(80000, max(5000, allowed * 3000)))
        h_s, c5_s = annealed_greedy(starts[si], target, max_it, rng,
                                     allowed, start_time, t_init=0.02, t_final=0.0001,
                                     M=15, n_cand=30)
        if c5_s < best_score:
            best_score = c5_s
            best_h = h_s.copy()

    if tleft() > 150:
        allowed = min(200.0, tleft() * 0.4)
        max_it = int(min(100000, max(10000, allowed * 3000)))
        h_s, c5_s = greedy_search(best_h, target, max_it, rng,
                                   allowed, start_time, M=20, n_cand=40)
        if c5_s < best_score:
            best_score = c5_s
            best_h = h_s.copy()

    n_use = len(best_h)
    target_use = n_use / 2.0

    if tleft() > 100:
        p_vals = [max(3, n_use // 60), max(5, n_use // 40), max(8, n_use // 25)]
        alphas = [100, 300, 800, 2000]
        h_ref, sc = slsqp_refine(best_h, n_use, target_use, p_vals, alphas,
                                  800, 1e-15, time_limit=min(150.0, tleft() - 60), start_time=start_time)
        if sc < best_score:
            best_score = sc
            best_h = h_ref

    if tleft() > 80:
        h_sub, sc_sub = subgradient_refine(best_h, target_use, 20000,
                                            time_limit=min(80.0, tleft() - 40),
                                            start_time=start_time,
                                            step_init=0.03, step_decay=0.998,
                                            active_eps=0.003)
        if sc_sub < best_score:
            best_score = sc_sub
            best_h = h_sub

    n_candidates = []
    for nf in [0.75, 0.9, 1.1, 1.3, 1.6]:
        n_try = int(n_use * nf)
        if n_try % 2 == 0 and n_try != n_use and n_try >= 200:
            n_candidates.append(n_try)
    n_candidates = sorted(set(n_candidates))

    for n_try in n_candidates[:3]:
        if tleft() < 100:
            break
        target_try = n_try / 2.0
        h_interp = interpolate_to(best_h, n_try, target_try)
        h_bin_try = project_binary(h_interp, target_try)
        allowed = min(120.0, tleft() * 0.3)
        max_it = int(min(60000, max(5000, allowed * 2500)))
        h_sa, c5_sa = annealed_greedy(h_bin_try, target_try, max_it, rng,
                                       allowed, start_time, t_init=0.015, t_final=0.0001,
                                       M=15, n_cand=30)
        if tleft() > 50:
            p_v = [max(3, n_try // 50), max(5, n_try // 30)]
            a_l = [200, 600, 1500]
            h_r, sc_r = slsqp_refine(h_sa, n_try, target_try, p_v, a_l,
                                      500, 1e-15, time_limit=min(50.0, tleft() - 40), start_time=start_time)
            if sc_r < c5_sa:
                h_sa = h_r
                c5_sa = sc_r
        if c5_sa < best_score:
            best_score = c5_sa
            best_h = h_sa.copy()

    n_use = len(best_h)
    target_use = n_use / 2.0

    if tleft() > 80:
        p_vals2 = [max(2, n_use // 80), max(4, n_use // 50), max(6, n_use // 35)]
        alphas2 = [300, 800, 2000, 5000]
        h_ref2, sc2 = slsqp_refine(best_h, n_use, target_use, p_vals2, alphas2,
                                    1000, 1e-16, time_limit=min(100.0, tleft() - 50), start_time=start_time)
        if sc2 < best_score:
            best_score = sc2
            best_h = h_ref2

    if tleft() > 50:
        n_use = len(best_h)
        target_use = n_use / 2.0
        h_bin_final = project_binary(best_h, target_use)
        allowed = min(40.0, tleft() * 0.5)
        max_it = int(max(5000, allowed * 3000))
        h_gf, c5_f = greedy_search(h_bin_final, target_use, max_it, rng,
                                    allowed, start_time, M=20, n_cand=40)
        if c5_f < best_score:
            best_score = c5_f
            best_h = h_gf

    if tleft() > 30:
        n_use = len(best_h)
        target_use = n_use / 2.0
        h_sub2, sc2 = subgradient_refine(best_h, target_use, 15000,
                                          time_limit=min(25.0, tleft() - 20),
                                          start_time=start_time,
                                          step_init=0.02, step_decay=0.997,
                                          active_eps=0.002)
        if sc2 < best_score:
            best_score = sc2
            best_h = h_sub2

    fine_n = len(best_h)
    fine_target = fine_n / 2.0
    h_final = project_feasible(best_h, fine_target)
    final_score = compute_c5(h_final)

    if final_score > best_score + 1e-10:
        h_final = best_h
        final_score = best_score

    return h_final, final_score, fine_n
```
