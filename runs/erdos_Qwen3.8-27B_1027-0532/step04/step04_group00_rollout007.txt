Let me think about the "dual equalization" more carefully. The idea is:

Given the current solution h, compute all corr_k values. Let K_max be the set of lags where corr_k is within ε of the maximum. We want to find weights λ_k for k in K_max such that the weighted gradient direction most effectively reduces the maximum.

The optimal direction (for reducing the max) is:
d = -Σ_{k ∈ K_max} λ_k ∇f_k

where λ is chosen to minimize ||d|| (making the step most uniform) subject to Σ λ_k = 1, λ_k ≥ 0.

This is a QP: min ||Σ λ_k ∇f_k||² s.t. Σ λ_k = 1, λ ≥ 0.

We can solve this with scipy.optimize or even a simple active set method for small |K_max|.

Then we take a step: h_new = h - step * d, projected to be feasible.

```python
def dual_equalize_step(h, n, target, top_m=10, step_size=0.001):
    corr = compute_corr(h)
    dx = 2.0 / n
    over = corr[n-1:n-1+n]  # these are corr for k=0..n-1
    # Actually, for the overlap problem, we want k >= 1
    # corr from np.correlate(h, 1-h, 'full') gives lags from -(n-1) to n-1
    # The overlap for shift k is at index n-1+k
    # So over[k] = corr[n-1+k] for k=0..n-1
    # We want k >= 1 (shifts of at least 1)
    
    top_indices = np.argsort(over[1:])[::-1][:top_m] + 1
    top_corr = over[top_indices]
    
    # Compute gradients for each active lag
    grads = np.zeros((top_m, n))
    for m, k in enumerate(top_indices):
        k = int(k)
        grad = np.zeros(n)
        j_pos = np.arange(0, n - k)
        grad[j_pos] += (1.0 - h[j_pos + k])
        j_neg = np.arange(k, n)
        grad[j_neg] -= h[j_neg - k]
        grads[m] = grad
    
    # Solve QP: min ||sum lam_k * grad_k||^2 s.t. sum lam = 1, lam >= 0
    # This is: min lam^T (G^T G) lam s.t. 1^T lam = 1, lam >= 0
    G = grads  # (m, n)
    A = G @ G.T  # (m, m)
    
    # Use scipy to solve
    from scipy.optimize import minimize as sci_min
    m = top_m
    x0 = np.ones(m) / m
    res = sci_min(lambda x: 0.5 * x @ A @ x, x0, method='SLSQP',
                  bounds=[(0,1)]*m,
                  constraints=[{'type':'eq', 'fun': lambda x: x.sum()-1, 'jac': lambda x: np.ones(m)}],
                  options={'maxiter': 100})
    lam = np.clip(res.x, 0, 1)
    lam /= lam.sum()
    
    # Compute direction
    d = grads.T @ lam  # (n,)
    d *= dx  # scale by dx
    
    # Line search
    best_step = 0
    best_obj = compute_c5(h)
    for factor in [1.0, 0.5, 0.1, 0.05, 0.01]:
        step = step_size * factor
        h_new = project_feasible(h - step * d, target)
        obj = compute_c5(h_new)
        if obj < best_obj:
            best_obj = obj
            best_step = step
    
    if best_step > 0:
        h_new = project_feasible(h - best_step * d, target)
        return h_new, best_obj
    return h, best_obj
```

def project_feasible(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)

        diff = target_sum - np.sum(h)
