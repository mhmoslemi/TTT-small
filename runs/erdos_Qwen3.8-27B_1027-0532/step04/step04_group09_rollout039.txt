- The (1-h[i-k]) term is non-zero for k such that 0 ≤ i-k < n, i.e., i-n+1 ≤ k ≤ i
- The -h[i+k] term is non-zero for k such that 0 ≤ i+k < n, i.e., -i ≤ k < n-i

So the change vector has support on k ∈ [max(i-n+1, -i), min(i, n-i-1)], which is O(n) entries.

For the swap, I need to compute this for both i and j and add them. This is O(n) per swap.

In Python, I can precompute the "influence vector" for each position. Let me define:
influence[i, j] = the change in c_{output_index_j} when h[i] increases by 1.

This is a n × (2n-1) matrix. For n=400, that's 400 × 799 = 319600 entries. That's manageable.

influence[i, n-1+k] = (1-h[i-k]) * 1[0≤i-k<n] - h[i+k] * 1[0≤i+k<n]

But this depends on h, so it changes as h changes. For binary h, (1-h[i-k]) is either 0 or 1, and h[i+k] is either 0 or 1.

For the swap (i: 0→1, j: 1→0), the change in the correlation vector is:
Δ = influence[i] - influence[j]

where influence[i] is computed with the current h (before the swap).

Hmm, but influence[i] depends on h. So I need to compute it on the fly. Let me just compute it:

For position i (0-indexed), the change in c_k (lag k, output index n-1+k) when h[i] increases by 1:
- Term 1: (1-h[i-k]) if 0 ≤ i-k < n, else 0. This is at lag k, so output index n-1+k.
  The valid range of k is: max(-(n-1), i-(n-1)) ≤ k ≤ min(n-1, i)
  Simplifying: k ranges from i-(n-1) to i (clamped to [-(n-1), n-1])
  
- Term 2: -h[i+k] if 0 ≤ i+k < n, else 0. At lag k, output index n-1+k.
  Valid range: k from -i to n-1-i (clamped to [-(n-1), n-1])

So for the full correlation vector (length 2n-1, indexed 0 to 2n-2, where index m corresponds to lag k = m-(n-1)):

delta[m] for m = 0 to 2n-2:
  k = m - (n-1)
  delta[m] = (1-h[i-k]) * 1[0≤i-k<n] - h[i+k] * 1[0≤i+k<n]

This is a sparse vector with at most 2n-1 non-zero entries (but typically about n entries).

For the swap (i: 0→1, j: 1→0):
total_delta = delta_i - delta_j

Then the new max is max(c + total_delta).

For SA, I need to compute the new max after the swap. If I maintain c (the current correlation vector) and the max, I can update:
new_c = c + delta_i - delta_j
new_max = max(new_c)

Computing max of a length 799 vector is O(799) per iteration. For 10^6 iterations, that's 8*10^8 operations. In numpy, this should take a few seconds.

Actually, I can be smarter. I only need to check if the new max is less than the old max (for acceptance). If the old max was at position p, and delta[p] < 0, then the new max might be lower. Otherwise, I need to check the full vector.

import numpy as np
from scipy.optimize import minimize
import time

def compute_corr(h):
    return np.correlate(h, 1.0 - h, mode='full')

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    return float(np.max(compute_corr(h))) * dx

def project_feasible(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    for _ in range(1000):
        diff = target_sum - np.sum(h)
        if abs(diff) < 1e-12:
            break
        if diff > 0:
            mask = h < 1.0
        else:
            mask = h > 0.0
        cnt = int(mask.sum())
        if cnt == 0:
            break
        h = h.copy()
        h[mask] += diff / cnt
        h = np.clip(h, 0.0, 1.0)
    return h

def lse_obj_and_grad(h, alpha):
    n = len(h)
    corr = compute_corr(h)
    c_max = float(np.max(corr))
    shifted = alpha * (corr - c_max)
    shifted = np.clip(shifted, -700.0, 0.0)
    exp_v = np.exp(shifted)
    sum_exp = np.sum(exp_v)
    w = exp_v / sum_exp
    obj = c_max + np.log(sum_exp) / alpha
    grad = np.zeros(n)
    for idx in range(2 * n - 1):
        wi = w[idx]
        if wi < 1e-14:
            continue
        k = idx - (n - 1)
        if k >= 0:
            if k < n:
                grad[:n - k] -= wi * h[k:]
                grad[k:] += wi * (1.0 - h[:n - k])
        else:
            kk = -k
            if kk < n:
                grad[kk:] -= wi * h[:n - kk]
                grad[:n - kk] += wi * (1.0 - h[kk:])
    return obj, grad

def slsqp_one(h, target, alpha, n, maxiter=2000, ftol=1e-16):
    cur_score = compute_c5(h)
    bounds = [(0.0, 1.0)] * n
    
    def fun(x):
        return lse_obj_and_grad(x, alpha)[0]
    def jac(x):
        return lse_obj_and_grad(x, alpha)[1]
    def cfun(x):
        return np.sum(x) - target
    def cjac(x):
        return np.ones(n)
    
    try:
        res = minimize(fun, h, jac=jac, method='SLSQP',
                       bounds=bounds,
                       constraints=[{'type': 'eq', 'fun': cfun, 'jac': cjac}],
                       options={'maxiter': maxiter, 'ftol': ftol})
        h_new = project_feasible(res.x, target)
        sc = compute_c5(h_new)
        if sc < cur_score:
            return h_new, sc
    except Exception:
        pass
    return h, cur_score

def slsqp_refine(h, target, alpha_list, maxiter, ftol, deadline):
    n = len(h)
    h_cur = h.copy()
    cur_score = compute_c5(h_cur)
    for alpha in alpha_list:
        if time.time() > deadline:
            break
        h_cur, cur_score = slsqp_one(h_cur, target, alpha, n, maxiter, ftol)
    return h_cur, cur_score

def binary_sa(h_init, n, n_swaps, t_init, t_min, deadline):
    """Simulated annealing on binary sequences."""
    # Start from thresholded version
    h_bin = (h_init >= 0.5).astype(float)
    # Adjust to have exactly n/2 ones
    n_ones = int(h_bin.sum())
    target_ones = n // 2
    if n_ones > target_ones:
        # Remove excess ones (pick those with lowest "importance")
        ones_idx = np.where(h_bin == 1)[0]
        # Randomly remove
        rng = np.random.RandomState(0)
        to_remove = rng.choice(ones_idx, n_ones - target_ones, replace=False)
        h_bin[to_remove] = 0
    elif n_ones < target_ones:
        zeros_idx = np.where(h_bin == 0)[0]
        rng = np.random.RandomState(0)
        to_add = rng.choice(zeros_idx, target_ones - n_ones, replace=False)
        h_bin[to_add] = 1
    
    best_h = h_bin.copy()
    best_corr = compute_corr(h_bin)
    best_max = float(np.max(best_corr))
    cur_corr = best_corr.copy()
    cur_max = best_max
    
    rng = np.random.RandomState(42)
    ones_set = set(np.where(h_bin == 1)[0].tolist())
    zeros_set = set(np.where(h_bin == 0)[0].tolist())
    
    for it in range(n_swaps):
        if time.time() > deadline:
            break
        t = t_init * (t_min / t_init) ** (it / max(n_swaps, 1))
        
        # Pick a random one and zero to swap
        i = rng.choice(list(ones_set))
        j = rng.choice(list(zeros_set))
        
        # Compute delta in correlation
        # For h[i]: 1->0, h[j]: 0->1
        # delta_c = -influence[i] + influence[j]
        # influence[m, output_idx] = change in c[output_idx] when h[m] increases by 1
        # For output_idx corresponding to lag k:
        #   influence[m, n-1+k] = (1-h[m-k]) * [0<=m-k<n] - h[m+k] * [0<=m+k<n]
        
        # Compute influence for i and j
        k_vals = np.arange(-(n-1), n)  # lags
        out_idx = np.arange(2*n - 1)  # output indices
        
        # influence[i]: for each output position, what's the change?
        # At output position out_idx[p] (lag k = p - (n-1)):
        #   (1-h[i-k]) if 0 <= i-k < n, minus h[i+k] if 0 <= i+k < n
        k_arr = k_vals  # shape (2n-1,)
        term1_i = np.where((i - k_arr >= 0) & (i - k_arr < n), 1.0 - h_bin[i - np.clip(i - k_arr, 0, n-1)], 0.0)
        term2_i = np.where((i + k_arr >= 0) & (i + k_arr < n), h_bin[i + np.clip(i + k_arr, 0, n-1)], 0.0)
        inf_i = term1_i - term2_i
        
        term1_j = np.where((j - k_arr >= 0) & (j - k_arr < n), 1.0 - h_bin[j - np.clip(j - k_arr, 0, n-1)], 0.0)
        term2_j = np.where((j + k_arr >= 0) & (j + k_arr < n), h_bin[j + np.clip(j + k_arr, 0, n-1)], 0.0)
        inf_j = term1_j - term2_j
        
        delta = inf_j - inf_i  # j goes 0->1 (add influence), i goes 1->0 (remove influence)
        
        new_corr = cur_corr + delta
        new_max = float(np.max(new_corr))
        
        # Acceptance
        if new_max <= cur_max:
            accept = True
        else:
            delta_e = t * (cur_max - new_max)  # negative
            accept = rng.random() < np.exp(delta_e)
        
        if accept:
            h_bin[i] = 0
            h_bin[j] = 1
            ones_set.remove(i)
            ones_set.add(j)
            zeros_set.remove(j)
            zeros_set.add(i)
            cur_corr = new_corr
            cur_max = new_max
            if cur_max < best_max:
                best_max = cur_max
                best_h = h_bin.copy()
                best_corr = cur_corr.copy()
    
    return best_h, best_max

def interpolate_to(h_src, n_dst, target_dst):
    n_src = len(h_src)
    if n_src == n_dst:
        return project_feasible(h_src.copy(), target_dst)
    x_new = np.linspace(0.0, 1.0, n_dst)
    x_old = np.linspace(0.0, 1.0, n_src)
    h_out = np.interp(x_new, x_old, h_src)
    return project_feasible(h_out, target_dst)

def coordinate_descent(h, target, n_iters, deadline):

    n = len(h)

    best_score = compute_c5(h_cur)
    corr = compute_corr(h_cur)
    
    for it in range(n_iters):

            break
        improved = False

                break

import numpy as np
from scipy.optimize import minimize
import time

def compute_corr(h):
    return np.correlate(h, 1.0 - h, mode='full')

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    return float(np.max(compute_corr(h))) * dx

def project_feasible(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    for _ in range(200):
        diff = target_sum - np.sum(h)
        if abs(diff) < 1e-13:
            break
        if diff > 0:
            mask = h < 1.0 - 1e-15
        else:
            mask = h > 1e-15
        cnt = int(mask.sum())
        if cnt == 0:
            break
        h = h.copy()
        h[mask] += diff / cnt
        h = np.clip(h, 0.0, 1.0)
    return h

def lse_obj_and_grad(h, alpha):
    n = len(h)
    corr = compute_corr(h)
    c_max = float(np.max(corr))
    shifted = alpha * (corr - c_max)
    shifted = np.where(shifted < -700.0, -700.0, shifted)
    exp_v = np.exp(shifted)
    sum_exp = np.sum(exp_v)
    w = exp_v / sum_exp
    obj = c_max + np.log(sum_exp) / alpha
    grad = np.zeros(n)
    for idx in range(2 * n - 1):
        wi = w[idx]
        if wi < 1e-14:
            continue
        k = idx - (n - 1)
        if k >= 0:
            if k < n:
                grad[:n - k] -= wi * h[k:]
                grad[k:] += wi * (1.0 - h[:n - k])
        else:
            kk = -k
            if kk < n:
                grad[kk:] -= wi * h[:n - kk]
                grad[:n - kk] += wi * (1.0 - h[kk:])
    return obj, grad

def slsqp_one_call(h, target, alpha, maxiter=2000, ftol=1e-16):
    n = len(h)
    cur_score = compute_c5(h)
    bounds = [(0.0, 1.0)] * n
    def fun(x):
        return lse_obj_and_grad(x, alpha)[0]
    def jac(x):
        return lse_obj_and_grad(x, alpha)[1]
    def cfun(x):
        return np.sum(x) - target
    def cjac(x):
        return np.ones(n)
    try:
        res = minimize(fun, h, jac=jac, method='SLSQP',
                       bounds=bounds,
                       constraints=[{'type': 'eq', 'fun': cfun, 'jac': cjac}],
                       options={'maxiter': maxiter, 'ftol': ftol})
        h_new = project_feasible(res.x, target)
        sc = compute_c5(h_new)
        if sc < cur_score:
            return h_new, sc
    except Exception:
        pass
    return h, cur_score

def slsqp_refine(h, target, alpha_list, maxiter, ftol, deadline):
    n = len(h)
    h_cur = h.copy()
    cur_score = compute_c5(h_cur)
    for alpha in alpha_list:
        if time.time() > deadline:
            break
        h_cur, cur_score = slsqp_one_call(h_cur, target, alpha, maxiter, ftol)
    return h_cur, cur_score

def binary_sa(h_init, n, max_iters, t_init, t_final, deadline, seed=42):
    rng = np.random.RandomState(seed)
    h_bin = (h_init >= 0.5).astype(np.int8)
    n_ones = int(h_bin.sum())
    target_ones = n // 2
    if n_ones > target_ones:
        ones_idx = np.where(h_bin == 1)[0]
        to_rem = rng.choice(ones_idx, n_ones - target_ones, replace=False)
        h_bin[to_rem] = 0
    elif n_ones < target_ones:
        zeros_idx = np.where(h_bin == 0)[0]
        to_add = rng.choice(zeros_idx, target_ones - n_ones, replace=False)
        h_bin[to_add] = 1
    
    ones_list = np.where(h_bin == 1)[0].copy()
    zeros_list = np.where(h_bin == 0)[0].copy()
    
    best_h = h_bin.astype(float).copy()
    best_corr = compute_corr(best_h)
    best_max = float(np.max(best_corr))
    cur_corr = best_corr.copy()
    cur_max = best_max
    
    k_arr = np.arange(-(n - 1), n).astype(float)
    
    for it in range(max_iters):
        if time.time() > deadline:
            break

        pj = rng.randint(len(zeros_list))
        i = int(ones_list[pi])
        j = int(zeros_list[pj])
        
        mi1 = (i - k_arr >= 0) & (i - k_arr < n)

        inf_i = np.where(mi1, 1.0 - h_bin[vi1].astype(float), 0.0) - np.where(mi2, h_bin[vi2].astype(float), 0.0)

def interpolate_to(h_src, n_dst, target_dst):
    n_src = len(h_src)
    if n_src == n_dst:
        return project_feasible(h_src.copy(), target_dst)
    x_new = np.linspace(0.0, 1.0, n_dst)
    x_old = np.linspace(0.0, 1.0, n_src)
    h_out = np.interp(x_new, x_old, h_src)
    return project_feasible(h_out, target_dst)

def subgrad_polish(h, target, n_steps, step0, deadline):
    n = len(h)
    h_cur = h.copy()
    best_h = h_cur.copy()
    best_score = compute_c5(h_cur)
    for it in range(n_steps):
        if time.time() > deadline:
            break
        corr = compute_corr(h_cur)
        c_max = float(np.max(corr))
        c_min = float(np.min(corr))
        thresh = c_max - 0.01 * (c_max - c_min)
        active = np.where(corr >= thresh)[0]
        grad = np.zeros(n)
        for idx in active:
            k = idx - (n - 1)
            if k >= 0:
                if k < n:
                    grad[:n-k] -= h_cur[k:]
                    grad[k:] += (1.0 - h_cur[:n-k])
            else:
                kk = -k
                if kk < n:
                    grad[kk:] -= h_cur[:n-kk]
                    grad[:n-kk] += (1.0 - h_cur[kk:])
        grad /= max(len(active), 1)
        step = step0 / (1.0 + 0.005 * it)
        h_new = project_feasible(h_cur - step * grad, target)
        sc = compute_c5(h_new)
        if sc < best_score:
            best_score = sc
            best_h = h_new.copy()
        h_cur = h_new
    return best_h, best_score
