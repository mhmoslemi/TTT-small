**New approach: Greedy Lag-Attacking Local Search (GLALS)**

The idea: 
1. Identify the worst lag k* (where correlation is maximized)
2. For lag k*, we want to minimize sum_i h[i]*(1-h[i+k*])
3. This is equivalent to: for each pair (i, i+k*), we want h[i] and h[i+k*] to be equal (both 0 or both 1)
4. So the strategy is: find positions i where h[i] ≠ h[i+k*], and flip the one that causes least damage to other lags

This is a greedy heuristic but should be effective.

```python
            g[i] += (1.0 - h[i - k])
        if 0 <= i + k < n:
            g[i] -= h[i + k]
    return g
```

But end_vals = p_vals + n can be up to 2n-1 = result_len. So suffix_max[end_vals] is suffix_max[result_len] = -inf. That's handled.

This is O(n²) total (the middle matrix is n×n), which for n=600 is 360,000 operations. Very fast.

Now I can do exact local search in O(n²) per step, and each step guarantees improvement (or we know we're at a local optimum). This should be much more effective than the heuristic SA approach.

Let me also think about **pair moves**: swapping two adjacent positions, or swapping a 1 and a 0 that are far apart. A pair move (swap positions a and b where h[a]=1, h[b]=0) is equivalent to doing a 1→0 flip at a followed by a 0→1 flip at b. The combined effect on the correlation is:
Δresult[k] = -(flipped[k-a]) + flipped[k-b] (for valid ranges)

This can also be vectorized but is more complex. Let me start with single flips and see if that's enough.

Actually, I realize there's an even better approach: **2-opt style moves**. Instead of single flips, try "block moves" where we flip a contiguous block. This can escape local optima that single flips can't.

```python
import numpy as np
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr)) * dx

def get_corr(h):
    return np.correlate(h, 1.0 - h, mode='full')

def project_feasible(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    diff = target_sum - np.sum(h)
    if abs(diff) < 1e-14:
        return h
    if diff > 0:
        idx = np.where(h < 1.0)[0]
    else:
        idx = np.where(h > 0.0)[0]
    if len(idx) == 0:
        return h
    h = h.copy()
    h[idx] += diff / len(idx)
    return np.clip(h, 0.0, 1.0)

def project_binary(h, target_sum, rng):
    n = len(h)
    r = rng.random(n)
    h_round = (h > r).astype(float)
    current = h_round.sum()
    target = int(target_sum)
    if current == target:
        return h_round
    diff = target - current
    if diff > 0:
        zeros = np.where(h_round == 0)[0]
        order = np.argsort(-h[zeros])[:diff]
        h_round[zeros[order]] = 1.0
    else:
        ones = np.where(h_round == 1)[0]
        order = np.argsort(h[ones])[:(-diff)]
        h_round[ones[order]] = 0.0
    return h_round

def exact_local_search(h, target_sum, max_rounds=200, time_limit=60.0, start_time=0.0):
    """Exact local search using vectorized flip evaluation."""
    n = len(h)
    h = h.copy()
    best_c5 = compute_c5(h)
    result_len = 2 * n - 1
    
    for rnd in range(max_rounds):
        if time.time() - start_time > time_limit:
            break
        
        corr = get_corr(h)
        flipped = 1.0 - 2.0 * h
        
        # Precompute prefix and suffix max
        prefix_max = np.maximum.accumulate(np.concatenate([[-np.inf], corr]))
        # prefix_max[i] = max(corr[0:i]) for i in 1..result_len
        suffix_max = np.zeros(result_len + 1)
        suffix_max[-1] = -np.inf
        for i in range(result_len - 1, -1, -1):
            suffix_max[i] = max(suffix_max[i+1], corr[i])
        # suffix_max[i] = max(corr[i:result_len])
        
        ones = np.where(h == 1)[0]
        zeros = np.where(h == 0)[0]
        
        if len(ones) == 0 or len(zeros) == 0:
            break
        
        best_new_max = np.max(corr)
        best_p = None
        best_to = None
        
        # Evaluate all 1->0 flips
        if len(ones) > 0:
            p_vals = ones
            middle = corr[p_vals[:, None] + np.arange(n)[None, :]] - flipped[None, :]
            middle_max = np.max(middle, axis=1)
            pre = prefix_max[1:][p_vals]  # max(corr[0:p])
            end_idx = np.minimum(p_vals + n, result_len)
            suff = suffix_max[end_idx]
            new_maxes = np.maximum(np.maximum(pre, middle_max), suff)
            
            idx = np.argmin(new_maxes)
            if new_maxes[idx] < best_new_max:
                best_new_max = new_maxes[idx]
                best_p = p_vals[idx]
                best_to = 0.0
        
        # Evaluate all 0->1 flips
        if len(zeros) > 0:
            p_vals = zeros
            middle = corr[p_vals[:, None] + np.arange(n)[None, :]] + flipped[None, :]
            middle_max = np.max(middle, axis=1)
            pre = prefix_max[1:][p_vals]
            end_idx = np.minimum(p_vals + n, result_len)
            suff = suffix_max[end_idx]
            new_maxes = np.maximum(np.maximum(pre, middle_max), suff)
            
            idx = np.argmin(new_maxes)
            if new_maxes[idx] < best_new_max:
                best_new_max = new_maxes[idx]
                best_p = p_vals[idx]
                best_to = 1.0
        
        if best_p is not None:
            h[best_p] = best_to
            new_c5 = best_new_max * (2.0 / n)
            if new_c5 < best_c5:
                best_c5 = new_c5
        else:
            break
    
    return h, best_c5
```

But for n=1200, it would be (600, 1200) = 720,000 elements. Still fine.

This creates a temporary (len(p_vals), n) array for the indices AND a (len(p_vals), n) array for the values. For n=4096, that's 8.4M integers + 8.4M floats = about 134 MB just for one evaluation. Now, let me think about the overall algorithm structure:

1. **Phase 1**: Start from initial_h_values, do exact local search
2. **Phase 2**: Try block moves (flip contiguous blocks of length 2-8)
3. **Phase 3**: Multi-resolution (try different n values)
4. **Phase 4**: Continuous relaxation + binary projection
5. **Phase 5**: Diverse restarts

For block moves, the effect on the correlation is:
Flipping a block [a, a+L-1] is equivalent to δ*(flipped[k-a] - flipped[k-(a+L)]) for k in the appropriate range. This is because we're adding δ*flipped at position a and subtracting δ*flipped at position a+L (the edge effects).

Wait, that's not quite right. Flipping a block means changing h[p] for p in [a, a+L-1]. The effect is:
Δresult[k] = δ * sum_{p=a}^{a+L-1} (flipped[k-p]) for valid k-p
= δ * sum_{j=k-(a+L-1)}^{k-a} flipped[j] for valid j

This is a convolution of a boxcar of length L with flipped. I can precompute the cumulative sum of flipped to make this O(1) per k.

Actually, this is getting complex. Let me stick with single flips and maybe 2-flips (pairs) for the local search, and use random restarts + multi-resolution to escape local optima.

```python
import numpy as np
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr)) * dx

def get_corr(h):
    return np.correlate(h, 1.0 - h, mode='full')

def project_feasible(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    diff = target_sum - np.sum(h)
    if abs(diff) < 1e-14:
        return h
    if diff > 0:
        idx = np.where(h < 1.0)[0]
    else:
        idx = np.where(h > 0.0)[0]
    if len(idx) == 0:
        return h
    h = h.copy()
    h[idx] += diff / len(idx)
    return np.clip(h, 0.0, 1.0)

def project_binary(h, target_sum, rng):
    n = len(h)
    r = rng.random(n)
    h_round = (h > r).astype(float)
    current = int(h_round.sum())
    target = int(target_sum)
    if current == target:
        return h_round
    diff = target - current
    if diff > 0:
        zeros = np.where(h_round == 0)[0]
        if diff <= len(zeros):
            order = np.argsort(-h[zeros])[:diff]
            h_round[zeros[order]] = 1.0
    else:
        ones = np.where(h_round == 1)[0]
        if (-diff) <= len(ones):
            order = np.argsort(h[ones])[:(-diff)]
            h_round[ones[order]] = 0.0
    return h_round

def find_best_flip(h, corr):
    """Find best single flip. Returns (p, new_val, new_max) or None."""
    n = len(h)
    result_len = 2 * n - 1
    flipped = 1.0 - 2.0 * h
    
    # Prefix max: prefix_max[i] = max(corr[0:i]) for i=0..result_len
    prefix_max = np.empty(result_len + 1)
    prefix_max[0] = -np.inf
    prefix_max[1:] = np.maximum.accumulate(corr)
    
    # Suffix max: suffix_max[i] = max(corr[i:result_len]) for i=0..result_len
    suffix_max = np.empty(result_len + 1)
    suffix_max[result_len] = -np.inf
    for i in range(result_len - 1, -1, -1):
        suffix_max[i] = max(suffix_max[i + 1], corr[i])
    
    curr_max = np.max(corr)
    best_new_max = curr_max
    best_p = None
    best_to = None
    
    ones = np.where(h == 1)[0]
    zeros = np.where(h == 0)[0]
    
    if len(ones) > 0:
        p_vals = ones
        idx = p_vals[:, None] + np.arange(n)[None, :]
        middle = corr[idx] - flipped[None, :]
        middle_max = np.max(middle, axis=1)
        pre = prefix_max[1:][p_vals]
        end_idx = np.minimum(p_vals + n, result_len)
        suff = suffix_max[end_idx]
        new_maxes = np.maximum(np.maximum(pre, middle_max), suff)
        
        idx_best = np.argmin(new_maxes)
        if new_maxes[idx_best] < best_new_max:
            best_new_max = float(new_maxes[idx_best])
            best_p = int(p_vals[idx_best])
            best_to = 0.0
    
    if len(zeros) > 0:
        p_vals = zeros
        idx = p_vals[:, None] + np.arange(n)[None, :]
        middle = corr[idx] + flipped[None, :]
        middle_max = np.max(middle, axis=1)
        pre = prefix_max[1:][p_vals]
        end_idx = np.minimum(p_vals + n, result_len)
        suff = suffix_max[end_idx]
        new_maxes = np.maximum(np.maximum(pre, middle_max), suff)
        
        idx_best = np.argmin(new_maxes)
        if new_maxes[idx_best] < best_new_max:
            best_new_max = float(new_maxes[idx_best])
            best_p = int(p_vals[idx_best])
            best_to = 1.0
    
    if best_p is not None:
        return best_p, best_to, best_new_max
    return None

def exact_local_search(h, target_sum, max_rounds=300, time_limit=60.0, start_time=0.0):
    """Exact local search with single flips."""
    n = len(h)
    h = h.copy()
    best_c5 = compute_c5(h)
    
    for rnd in range(max_rounds):
        if time.time() - start_time > time_limit:
            break
        
        corr = get_corr(h)
        result = find_best_flip(h, corr)
        
        if result is None:
            break
        
        p, new_val, new_max = result
        h[p] = new_val
        new_c5 = new_max * (2.0 / n)
        if new_c5 < best_c5:
            best_c5 = new_c5
        else:
            # Shouldn't happen but be safe
            break
    
    return h, best_c5

def pair_local_search(h, target_sum, max_rounds=100, time_limit=60.0, start_time=0.0):
    """Try pairs of flips (swap a 1 and a 0)."""
    n = len(h)
    h = h.copy()
    best_c5 = compute_c5(h)
    
    for rnd in range(max_rounds):
        if time.time() - start_time > time_limit:
            break
        
        corr = get_corr(h)
        curr_max = np.max(corr)
        result_len = 2 * n - 1
        flipped = 1.0 - 2.0 * h
        
        prefix_max = np.empty(result_len + 1)
        prefix_max[0] = -np.inf
        prefix_max[1:] = np.maximum.accumulate(corr)
        
        suffix_max = np.empty(result_len + 1)
        suffix_max[result_len] = -np.inf
        for i in range(result_len - 1, -1, -1):
            suffix_max[i] = max(suffix_max[i + 1], corr[i])
        
        ones = np.where(h == 1)[0]
        zeros = np.where(h == 0)[0]
        
        if len(ones) < 2 or len(zeros) < 2:
            break
        
        # Sample pairs for efficiency
        n_sample = min(len(ones), 40)
        n_sample0 = min(len(zeros), 40)
        r = np.random.RandomState(rnd * 1000 + 42)
        one_samples = r.choice(ones, n_sample, replace=False)
        zero_samples = r.choice(zeros, n_sample0, replace=False)
        
        best_new_max = curr_max
        best_pair = None
        
        for a in one_samples:
            for b in zero_samples:
                # Effect: -(flipped at a) + (flipped at b)
                # new_corr = corr - flipped_shifted_a + flipped_shifted_b
                # The change is only nonzero in ranges [a, a+n-1] and [b, b+n-1]
                
                # For the max, we need:
                # max over all k of (corr[k] + delta[k])
                # delta[k] = -flipped[k-a] (if 0<=k-a<n) + flipped[k-b] (if 0<=k-b<n)
                
                # This is complex to vectorize for pairs. Let's just compute directly.
                # The affected range is [min(a,b), max(a,b)+n-1]
                lo = max(0, min(a, b))
                hi = min(result_len - 1, max(a, b) + n - 1)
                
                delta = np.zeros(hi - lo + 1)
                # Add -flipped contribution from a
                ka = np.arange(lo, hi + 1) - a
                valid_a = (ka >= 0) & (ka < n)
                delta[valid_a] -= flipped[ka[valid_a]]
                # Add +flipped contribution from b
                kb = np.arange(lo, hi + 1) - b
                valid_b = (kb >= 0) & (kb < n)
                delta[valid_b] += flipped[kb[valid_b]]
                
                new_seg = corr[lo:hi+1] + delta
                pre = prefix_max[1:][lo] if lo > 0 else -np.inf
                suff = suffix_max[hi+1] if hi + 1 < result_len else -np.inf
                new_max = max(float(np.max(new_seg)), float(pre), float(suff))
                
                if new_max < best_new_max:
                    best_new_max = new_max
                    best_pair = (a, b)
        
        if best_pair is not None:
            a, b = best_pair
            h[a] = 0.0
            h[b] = 1.0
            new_c5 = best_new_max * (2.0 / n)
            if new_c5 < best_c5:
                best_c5 = new_c5
            else:
                h[a] = 1.0
                h[b] = 0.0
                break
        else:
            break
    
    return h, best_c5

def interpolate_to(h_src, n_dst):
    n_src = len(h_src)
    if n_src == n_dst:
        return h_src.copy()
    x_new = np.linspace(0.0, 1.0, n_dst)
    x_old = np.linspace(0.0, 1.0, n_src)
    return np.interp(x_new, x_old, h_src)

def continuous_refine(h, target_sum, n_steps=100, time_limit=60.0, start_time=0.0, rng=None):
    """Subgradient method on continuous relaxation, then project to binary."""
    n = len(h)
    h = h.copy()
    best_h = h.copy()
    best_c5 = compute_c5(h)
    
    for step in range(n_steps):
        if time.time() - start_time > time_limit:
            break
        
        ratio = step / n_steps
        lr = 0.5 * (1.0 - 0.9 * ratio)
        
        corr = get_corr(h)
        center = n - 1
        # Find top lags
        top_k = 5
        sorted_idx = np.argsort(corr)[::-1][:top_k]
        
        if np.max(corr) <= 0:
            break
        
        # Subgradient
        grad = np.zeros(n)
        for idx in sorted_idx:
            k = int(idx - center)
            if k == 0:
                continue
            g = np.zeros(n)
            for i in range(n):
                if 0 <= i - k < n:
                    g[i] += (1.0 - h[i - k])
                if 0 <= i + k < n:
                    g[i] -= h[i + k]
            grad += g
        grad /= len(sorted_idx)
        
        h_new = h - lr * grad * (2.0 / n)
        h_new = project_feasible(h_new, target_sum)
        
        # Project to binary and evaluate
        if rng is not None:
            h_bin = project_binary(h_new, target_sum, rng)
            c5_bin = compute_c5(h_bin)
            if c5_bin < best_c5:
                best_c5 = c5_bin
                best_h = h_bin.copy()
        
        h = h_new
    
    return best_h, best_c5
```

Wait, I have a concern about the `find_best_flip` function. The line:

creates an array of size (len(p_vals), n). For n=600 and 300 ones, that's 180,000 integers. Then `corr[idx]` creates a (300, 600) float array. This should be fine memory-wise.

Let me also think about correctness. The formula I derived was:
For a flip at p (δ change), the correlation at index k changes by:
- δ*(1-2*h[k-p]) if 0 ≤ k-p ≤ n-1
- 0 otherwise

Let me verify: for a 0→1 flip (δ=1) at position p:
- new_corr[k] = corr[k] + (1-2*h[k-p]) for 0 ≤ k-p ≤ n-1

The "flipped" array is 1-2*h, which is +1 where h=0 and -1 where h=1.
So for h[k-p]=0: change = +1 (we're adding 1 at that correlation position)
For h[k-p]=1: change = -1 (we're subtracting 1 at that correlation position)

Let me verify with a simple example. Say n=4, h = [1, 0, 1, 0].
corr = correlate(h, 1-h, 'full') = correlate([1,0,1,0], [0,1,0,1], 'full')

Let me compute manually:
result[0] = h[0]*g[0] = 1*0 = 0
