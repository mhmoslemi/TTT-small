The Lipschitz constant of the gradient of the log-sum-exp objective:
The Hessian of c_k with respect to h is a matrix with entries:
H_{ij} = -[i=j+k for some k] - [i=j-k for some k] + higher order terms
Actually, c_k = sum_i h[i](1-h[i+k]), which is bilinear in h.
dc_k/dh[j] = (1-h[j+k]) - h[j-k] (with appropriate validity checks)
d²c_k/dh[j]dh[l] = -[l=j+k] - [l=j-k] (from the second derivatives of the bilinear form)

So the Hessian of c_k has entries that are -1 at positions (j, j+k) and (j, j-k), and 0 elsewhere. The spectral norm of this Hessian is at most 2 (since each row has at most 2 non-zero entries of value -1).

For the log-sum-exp: F = (1/alpha) log(sum_k exp(alpha c_k))
∇F = sum_k w_k ∇c_k where w_k = exp(alpha c_k) / sum exp(alpha c_m)
∇²F = sum_k w_k ∇²c_k + (alpha) sum_k w_k (∇c_k)(∇c_k)^T - (alpha) [sum_k w_k ∇c_k][sum_k w_k ∇c_k]^T

The first term has spectral norm ≤ 2 (since each ∇²c_k has norm ≤ 2 and the w_k sum to 1).
The second term is more complex but is bounded by alpha * max_k ||∇c_k||² = alpha * 4 (since ||∇c_k|| ≤ 2).
So the Lipschitz constant of ∇F is roughly O(1 + 4*alpha).

For the projected gradient method, the optimal step size is 1/L where L is the Lipschitz constant. So step ≈ 1/(1 + 4*alpha).

                # Reduce step and retry
                for _ in range(10):
                    step *= 0.5
                    h_new = h - step * grad
                    h_new = project_feasible(h_new, target_sum)
                    f_new = logsumexp_objective(h_new, alpha)

                best_h = h.copy()

        h = project_feasible(h, target_sum)
        c5_cur = compute_c5(h)
        if c5_cur < best_score:
            best_score = c5_cur
            best_h = h.copy()

The issue with this approach is that computing the logsumexp gradient is O(n²) (due to the loop over j), and computing the logsumexp objective is O(n log n) (due to FFT-based correlation). For n=2048, each gradient computation takes about 10ms, and we might want to do 1000-5000 iterations per alpha value. With maybe 5-10 alpha values, that's 5000-50000 gradient computations, taking 50-500 seconds. That's within budget.

Actually wait, let me reconsider. The gradient computation loop is O(n) Python iterations, each doing O(n) numpy work. For n=2048:
- Each iteration: 2 dot products of length 2048 ≈ 2 * 2048 * ~2ns ≈ 8μs (BLAS-optimized)
- Plus Python overhead: ~1μs per iteration
- Total per gradient: 2048 * 9μs ≈ 18ms

So 1000 iterations would take 18s. With 10 alpha values, that's 180s. That's fine.

But actually, I should also try the L-BFGS-B approach, which can converge much faster than projected gradient (quadratic convergence in the ideal case). Let me use L-BFGS-B with the gradient and handle the constraint via the penalty method.

Let me also think about a key improvement: instead of using the same alpha schedule for all, I should adaptively increase alpha based on the sharpness of the log-sum-exp approximation. Specifically, if the max correlation is achieved at a single lag (or few lags), then even moderate alpha gives a good approximation. If many lags have similar values, we need larger alpha.

Let me now write the complete solution. I'll combine:
1. Targeted SA at n=600 (quick polish)
2. Upsampling to n=1024, 2048
3. L-BFGS-B with log-sum-exp + penalty at higher resolutions
4. Final SA polish

Let me also add a key trick: after L-BFGS-B finds a continuous solution, I can try to "binarize" it (project to binary) and see if that gives a better C₅. Sometimes the binary projection happens to be better because of the specific structure.

Another idea: use "shift invariance". The problem has a shift symmetry: if h is optimal, then h shifted by any amount (with appropriate boundary handling) is also optimal. But in our discrete setting, shifting changes the function. However, we can use this to generate diverse starting points.

            b_idx = zeros[rng.randint(len(zeros))]
            h[a_idx] = 0.0
            h[b_idx] = 1.0
            c5_new = compute_c5(h)
            if c5_new < current_c5:
                current_c5 = c5_new
                ones = np.where(h == 1)[0]
                zeros = np.where(h == 0)[0]
                if c5_new < best_c5 - 1e-12:
                    best_c5 = c5_new
                    best_h = h.copy()
                    no_improve = 0
                else:
                    no_improve += 1
            else:
                h[a_idx] = 1.0
                h[b_idx] = 0.0
                no_improve += 1
        elif r < 0.9 and len(ones) >= 2 and len(zeros) >= 2:
            ia = rng.choice(len(ones), 2, replace=False)
            ib = rng.choice(len(zeros), 2, replace=False)
            h[ones[ia[0]]] = 0.0
            h[ones[ia[1]]] = 0.0
            h[zeros[ib[0]]] = 1.0
            h[zeros[ib[1]]] = 1.0
            c5_new = compute_c5(h)
            delta = c5_new - current_c5
            if delta < 0 or (t > 1e-12 and rng.random() < np.exp(-delta / t)):
                current_c5 = c5_new
                ones = np.where(h == 1)[0]
                zeros = np.where(h == 0)[0]
                if c5_new < best_c5 - 1e-12:
                    best_c5 = c5_new
                    best_h = h.copy()
                    no_improve = 0
                else:
                    no_improve += 1
            else:
                h[ones[ia[0]]] = 1.0
                h[ones[ia[1]]] = 1.0
                h[zeros[ib[0]]] = 0.0
                h[zeros[ib[1]]] = 0.0
                no_improve += 1
        else:
            a_idx = ones[rng.randint(len(ones))]
            b_idx = zeros[rng.randint(len(zeros))]
            h[a_idx] = 0.0
            h[b_idx] = 1.0
            c5_new = compute_c5(h)
            if c5_new < best_c5 - 1e-12:
                current_c5 = c5_new
                best_c5 = c5_new
                best_h = h.copy()
                ones = np.where(h == 1)[0]
                zeros = np.where(h == 0)[0]
                no_improve = 0
            else:
                h[a_idx] = 1.0
                h[b_idx] = 0.0
                no_improve += 1
    return best_h, best_c5


def run(seed=42, budget_s=1300, **kwargs):
    start_time = time.time()
    rng = np.random.RandomState(seed)

    def tleft():
        return max(0.0, budget_s - 30.0 - (time.time() - start_time))

    h_init = np.array(initial_h_values, dtype=float)
    n_init = len(h_init)
    target_init = int(n_init / 2)

    best_h = h_init.copy()
    best_score = compute_c5(best_h)

    h_bin = project_binary(h_init, target_init)
    h_sa, c5_sa = targeted_sa(h_bin, target_init, 40000, 0.012, 0.00004,
                              rng, time_limit=min(60.0, tleft() * 0.1), start_time=start_time)
    if c5_sa < best_score:
        best_score = c5_sa
        best_h = h_sa.copy()

    res_list = [1024, 2048, 1536]
    for n_res in res_list:
        if tleft() < 150:
            break
        target_res = n_res / 2.0
        h_interp = interpolate_to(best_h, n_res, target_res)

        alphas_slb = [n_res / 30, n_res / 15, n_res / 8, n_res / 5, n_res / 3, n_res / 2]
        mu = 500.0
        time_limit_slb = min(180.0, tleft() * 0.3)
        h_opt, c5_opt = slb_optimize(h_interp, n_res, alphas_slb, mu, 150, time_limit_slb, start_time)

        if tleft() > 100:
            alphas_pg = [n_res / 8, n_res / 5, n_res / 3, n_res / 2]
            time_limit_pg = min(80.0, tleft() * 0.2)
            h_pg, c5_pg = projected_grad_optimize(h_opt, n_res, alphas_pg, time_limit_pg, start_time)
            if c5_pg < c5_opt:
                h_opt = h_pg
                c5_opt = c5_pg

        if c5_opt < best_score:
            best_score = c5_opt
            best_h = h_opt.copy()

    n_best = len(best_h)
    target_best = n_best / 2.0
    if tleft() > 50:
        h_bin_best = project_binary(best_h, target_best)
        h_sa2, c5_sa2 = targeted_sa(h_bin_best, target_best, 20000, 0.006, 0.00002,
                                    rng, time_limit=min(50.0, tleft() * 0.25), start_time=start_time)
        if c5_sa2 < best_score:
            best_score = c5_sa2
            best_h = h_sa2.copy()

    for n_try in [512, 768, 896, 1152, 1792, 2560, 3200]:
        if tleft() < 30:
            break
        if abs(n_try - n_best) < 100:
            continue
        target_try = n_try / 2.0
        h_interp = interpolate_to(best_h, n_try, target_try)
        c5_try = compute_c5(h_interp)
        if c5_try < best_score:
            best_score = c5_try
            best_h = h_interp.copy()
        h_bin_try = project_binary(h_interp, target_try)
        h_sa_try, c5_sa_try = targeted_sa(h_bin_try, target_try, 5000, 0.005, 0.00001,
                                          rng, time_limit=min(15.0, tleft() * 0.1), start_time=start_time)
        if c5_sa_try < best_score:
            best_score = c5_sa_try
            best_h = h_sa_try.copy()

    n_final = len(best_h)
    target_final = n_final / 2.0
    if tleft() > 40:
        alphas_final = [n_final / 3, n_final / 2, n_final]
        h_ref, sc = slb_optimize(best_h, n_final, alphas_final, 2000.0, 100,
                                 min(30.0, tleft() * 0.5), start_time)
        if sc < best_score:
            best_score = sc
            best_h = h_ref

    n_final = len(best_h)
    target_final = n_final / 2.0
    h_final = project_feasible(best_h, target_final)
    final_score = compute_c5(h_final)
    if final_score > best_score + 1e-10:
        h_final = best_h
        final_score = best_score
    return h_final, final_score, n_final
