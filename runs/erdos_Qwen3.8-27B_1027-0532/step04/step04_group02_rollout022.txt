Also, I want to make sure I'm computing the correlation correctly. Let me double-check:

The problem says: C₅ = max_k ∫ h(x)(1 - h(x+k)) dx

With discretization: h is n_points samples over [0,2], dx = 2/n_points.
The evaluation computes: C₅ = max(np.correlate(h, 1-h, mode="full") * dx)

np.correlate(h, 1-h, mode="full") gives an array of length 2n-1.
Element k (0-indexed) = sum_i h[i] * (1-h[i + k - (n-1)]) for valid i.

Wait, let me check numpy's definition again. From the docs:
"Let A be the signal and B be the kernel. Then the correlation C is defined as:
c_k = sum_n A_{n+k} * conj(B_n)"

So np.correlate(h, 1-h, 'full')[k] = sum_n h[n+k] * (1-h[n]) for valid n.

The index k in the full output corresponds to the "lag" in a specific way. The full output has length 2n-1, with index 0 corresponding to the case where only the last element of h overlaps with the first of (1-h), and index 2n-2 corresponding to the case where only the first of h overlaps with the last of (1-h).

The "zero lag" (where h and 1-h are aligned) is at index n-1.

So np.correlate(h, 1-h, 'full')[n-1] = sum_i h[i] * (1-h[i]) = 0 for binary h.

And np.correlate(h, 1-h, 'full')[n-1+d] = sum_i h[i+d] * (1-h[i]) (for d ≥ 0, valid i)
And np.correlate(h, 1-h, 'full')[n-1-d] = sum_i h[i-d] * (1-h[i]) = sum_j h[j] * (1-h[j+d]) (for d ≥ 0, j = i-d)

So:
- Positive lag d (index n-1+d): counts (0,1) pairs at distance d (h[i]=0, h[i+d]=1)
- Negative lag -d (index n-1-d): counts (1,0) pairs at distance d (h[i]=1, h[i+d]=0)

This confirms my earlier analysis.

Now, for the greedy swap targeting:
Given the worst index in the correlation array (let's call it `worst_idx`), the corresponding lag is `d = worst_idx - (n-1)`.

If d > 0: the worst is the (0,1) count at distance d. To reduce it, we want to:
- Change a 0 to 1 at position i (so it's no longer 0, reducing the count) - but wait, this INCREASES the count at other positions...
  
  Actually, if we set h[b]=1 (was 0) at position b:
  - The pair (b, b+d) is no longer counted (h[b] is no longer 0): reduces R(d) by 1 if h[b+d]=1
  - The pair (b-d, b) is now counted (h[b] is now 1, h[b-d] might be 0): increases R(d) by 1 if h[b-d]=0
  
  Net effect on R(d): +h[b+d]*(0-0)... let me redo.
  
  R(d) = sum_i h[i+d]*(1-h[i]) for i=0 to n-1-d.
  
  Before: h[b]=0. After: h[b]=1.
  - Term i=b: was h[b+d]*(1-0) = h[b+d]. Now: h[b+d]*(1-1) = 0. Delta: -h[b+d].
  - Term i=b-d (if b-d >= 0): was h[b]*(1-h[b-d]) = 0. Now: 1*(1-h[b-d]) = 1-h[b-d]. Delta: +(1-h[b-d]).
  
  So setting h[b] from 0 to 1 changes R(d) by: -h[b+d] + (1-h[b-d]) (both terms if valid).

- Change a 1 to 0 at position a:
  - Term i=a: was h[a+d]*(1-1) = 0. Now: h[a+d]*(1-0) = h[a+d]. Delta: +h[a+d].
  - Term i=a-d (if a-d >= 0 && a-d <= n-1-d): was h[a]*(1-h[a-d]) = 1-h[a-d]. Now: 0. Delta: -(1-h[a-d]).
  
  So setting h[a] from 1 to 0 changes R(d) by: h[a+d] - (1-h[a-d]).

For a swap (a: 1→0, b: 0→1), total delta in R(d):
= h[a+d] - (1-h[a-d]) - h[b+d] + (1-h[b-d])
  (each term included only if the relevant index is valid)

We want to minimize this (most negative = best reduction of R(d)).

For d < 0 (worst is at negative lag), let d = -|d|:
R(-|d|) = sum_i h[i-|d|]*(1-h[i]) for i=|d| to n-1 = sum_j h[j]*(1-h[j+|d|]) for j=0 to n-1-|d|

So it's the same formula with +d replaced by -d and the "direction" reversed. Actually:
R(-d) for d>0 = sum_j h[j]*(1-h[j+d]) = number of (1,0) pairs at distance d.

Setting h[b] from 0 to 1 at position b:
- Term j=b: was h[b]*(1-h[b+d]) = 0. Now: 1*(1-h[b+d]) = 1-h[b+d]. Delta: +(1-h[b+d]).
- Term j=b-d (if b-d >= 0): was h[b-d]*(1-h[b]) = h[b-d]*0... wait, 1-h[b] was 1 (since h[b]=0). So term was h[b-d]*1 = h[b-d]. Now: h[b-d]*(1-1) = 0. Delta: -h[b-d].

Setting h[a] from 1 to 0 at position a:
- Term j=a: was h[a]*(1-h[a+d]) = 1-h[a+d]. Now: 0. Delta: -(1-h[a+d]).
- Term j=a+d (if a+d < n): was h[a+d]*(1-h[a+d])... no wait, the term at j is h[j]*(1-h[j+d]).
  - j=a: h[a]*(1-h[a+d]). Before: 1*(1-h[a+d]). After: 0. Delta: -(1-h[a+d]).
  - j=a-d (if a-d >= 0): h[a-d]*(1-h[a]). Before: h[a-d]*0 = 0. After: h[a-d]*1 = h[a-d]. Delta: +h[a-d].

So for negative lag -d (d>0), the delta from swap (a: 1→0, b: 0→1):
= -(1-h[a+d]) + h[a-d] + (1-h[b+d]) - h[b-d]
  (validity conditions apply)

import numpy as np

def compute_corr(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return corr * dx


def compute_c5(h):
    return float(np.max(compute_corr(h)))


def project_feasible(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    diff = target_sum - np.sum(h)
    if abs(diff) < 1e-14:
        return h
    h = h.copy()
    if diff > 0:
        room = 1.0 - h
        order = np.argsort(-room)
        remaining = diff
        for i in order:
            if remaining <= 1e-14:
                break
            add = min(room[i], remaining)
            h[i] += add
            remaining -= add
    else:
        room = h.copy()
        order = np.argsort(-room)
        remaining = -diff
        for i in order:
            if remaining <= 1e-14:
                break
            sub = min(room[i], remaining)
            h[i] -= sub
            remaining -= sub
    return np.clip(h, 0.0, 1.0)


def project_binary(h, target_sum):
    n = len(h)
    h_r = np.round(h).astype(int)
    current_sum = h_r.sum()
    if current_sum == int(target_sum):
        return h_r.astype(float)
    ones = np.where(h_r == 1)[0]
    zeros = np.where(h_r == 0)[0]
    need = int(target_sum)
    if current_sum > need:
        excess = current_sum - need
        order = np.argsort(h[ones])[:excess]
        h_r[ones[order]] = 0
    else:
        deficit = need - current_sum
        order = np.argsort(-h[zeros])[:deficit]
        h_r[zeros[order]] = 1
    final_sum = h_r.sum()
    if final_sum != need:
        if final_sum > need:
            ones2 = np.where(h_r == 1)[0]
            h_r[ones2[:int(final_sum - need)]] = 0
        else:
            zeros2 = np.where(h_r == 0)[0]
            h_r[zeros2[:int(need - final_sum)]] = 1
    return h_r.astype(float)


def interpolate_to(h_src, n_dst, target_dst):
    n_src = len(h_src)
    if n_src == n_dst:
        return project_feasible(h_src.copy(), target_dst)
    x_new = np.linspace(0.0, 1.0, n_dst)
    x_old = np.linspace(0.0, 1.0, n_src)
    h_out = np.interp(x_new, x_old, h_src)
    return project_feasible(h_out, target_dst)


def greedy_best_swap(h, corr, n, top_k_lags=1):
    worst_indices = np.argsort(-corr)[:top_k_lags]
    ones = np.where(h == 1)[0]
    zeros = np.where(h == 0)[0]
    if len(ones) == 0 or len(zeros) == 0:
        return None
    best_score = 1e9
    best_a = None
    best_b = None
    for wi in worst_indices[:top_k_lags]:
        d = wi - (n - 1)
        a_dp = ones + d
        a_dm = ones - d
        delta_a = np.zeros(len(ones))
        mask_ap = (a_dp >= 0) & (a_dp < n)
        mask_am = (a_dm >= 0) & (a_dm < n)
        if d >= 0:
            delta_a[mask_ap] += h[a_dp[mask_ap]]
            delta_a[mask_am] -= (1.0 - h[a_dm[mask_am]])
        else:
            dd = -d
            a_dp2 = ones + dd
            a_dm2 = ones - dd
            mask_ap2 = (a_dp2 >= 0) & (a_dp2 < n)
            mask_am2 = (a_dm2 >= 0) & (a_dm2 < n)
            delta_a[mask_ap2] -= (1.0 - h[a_dp2[mask_ap2]])
            delta_a[mask_am2] += h[a_dm2[mask_am2]]
        b_dp = zeros + d
        b_dm = zeros - d
        delta_b = np.zeros(len(zeros))
        if d >= 0:
            mask_bp = (b_dp >= 0) & (b_dp < n)
            mask_bm = (b_dm >= 0) & (b_dm < n)
            delta_b[mask_bp] -= h[b_dp[mask_bp]]
            delta_b[mask_bm] += (1.0 - h[b_dm[mask_bm]])
        else:
            dd = -d
            b_dp2 = zeros + dd
            b_dm2 = zeros - dd
            mask_bp2 = (b_dp2 >= 0) & (b_dp2 < n)
            mask_bm2 = (b_dm2 >= 0) & (b_dm2 < n)
            delta_b[mask_bp2] += (1.0 - h[b_dp2[mask_bp2]])
            delta_b[mask_bm2] -= h[b_dm2[mask_bm2]]
        best_a_local = np.argmin(delta_a)
        best_b_local = np.argmin(delta_b)
        score = delta_a[best_a_local] + delta_b[best_b_local]
        if score < best_score:
            best_score = score
            best_a = ones[best_a_local]
            best_b = zeros[best_b_local]
    return best_a, best_b, best_score

            i1a, i1b, i1c = ones_cache[idx[0]], ones_cache[idx[1]], ones_cache[idx[2]]
            jdx = rng.choice(len(zeros_cache), 3, replace=False)
            i0a, i0b, i0c = zeros_cache[jdx[0]], zeros_cache[jdx[1]], zeros_cache[jdx[2]]
            h_new[i1a] = 0
            h_new[i1b] = 0
            h_new[i1c] = 0
            h_new[i0a] = 1
            h_new[i0b] = 1
            h_new[i0c] = 1
            moved = True
        if not moved:
            continue
        corr_new = compute_corr(h_new)
        c5_new = float(np.max(corr_new))
        delta = c5_new - current_c5
        if delta < -1e-12 or (t > 1e-12 and rng.random() < np.exp(-delta / t)):
            h = h_new
            corr = corr_new
            current_c5 = c5_new
            ones_cache = np.where(h == 1)[0]
            zeros_cache = np.where(h == 0)[0]
            if c5_new < best_c5 - 1e-14:
                best_c5 = c5_new
                best_h = h.copy()
                no_improve = 0
            else:
                no_improve += 1
        else:
            no_improve += 1
    return best_h, best_c5


def top_p_smooth(h, alpha, p):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full') * dx
    sorted_corr = np.sort(corr)
    top = sorted_corr[-p:]
    max_top = np.max(top)
    shifted = np.clip(alpha * (top - max_top), -500.0, 0.0)
    return float(max_top + np.log(np.sum(np.exp(shifted))) / alpha)


def cons_fun(h):
    return np.sum(h) - _cons_target


def cons_jac(h):
    return np.ones(_cons_n)


def slsqp_refine(h_start, n, target, time_limit=None, start_time=None):
    global _cons_n, _cons_target
    _cons_n = n
    _cons_target = target
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': cons_fun, 'jac': cons_jac}]
    h_cur = h_start.copy()
    curr_score = compute_c5(h_cur)
    p_vals = [max(3, n // 40), max(5, n // 25), max(8, n // 15)]
    alphas = [100, 300, 800, 2000, 5000]
    for p in p_vals:
        for alpha in alphas:
            if time_limit is not None and start_time is not None:
                if (time.time() - start_time) > time_limit:
                    return h_cur, curr_score
            try:
                res = minimize(lambda x: top_p_smooth(x, alpha, p), h_cur,
                               method='SLSQP', bounds=bounds, constraints=cons,
                               options={'maxiter': 400, 'ftol': 1e-15})
                h_new = project_feasible(res.x, target)
                sc = compute_c5(h_new)
                if sc < curr_score:
                    curr_score = sc
                    h_cur = h_new
            except Exception:
                pass
    return h_cur, curr_score


def run(seed=42, budget_s=1300, **kwargs):
    global _cons_n, _cons_target
    start_time = time.time()
    rng = np.random.RandomState(seed)

    def tleft():
        return budget_s - 30.0 - (time.time() - start_time)

    h_init = np.array(initial_h_values, dtype=float)
    n_init = len(h_init)
    target_init = n_init / 2.0

    best_h = np.array(h_init, dtype=float)
    best_score = compute_c5(best_h)

    h_bin_start = project_binary(h_init, target_init)
    best_h = h_bin_start.copy()
    best_score = compute_c5(best_h)

    phase1_time = min(200.0, tleft() * 0.25)
    h_g, c5_g = smart_greedy_descent(h_bin_start, target_init, 10000, rng,
                                      time_limit=phase1_time, start_time=start_time)
    if c5_g < best_score:
        best_score = c5_g
        best_h = h_g.copy()

    if tleft() > 100:
        h_sa, c5_sa = sa_informed(best_h, target_init, 50000, 0.01, 0.00005,
                                   rng, time_limit=min(200.0, tleft() * 0.2), start_time=start_time)
        if c5_sa < best_score:
            best_score = c5_sa
            best_h = h_sa.copy()

    if tleft() > 80:
        h_g2, c5_g2 = smart_greedy_descent(best_h, target_init, 10000, rng,
                                            time_limit=min(100.0, tleft() * 0.15), start_time=start_time)
        if c5_g2 < best_score:
            best_score = c5_g2
            best_h = h_g2.copy()

    if tleft() > 150:
        ils_time = min(400.0, tleft() * 0.35)
        h_ils, c5_ils = ils_search(best_h, target_init, rng,
                                    time_limit=ils_time, start_time=start_time)
        if c5_ils < best_score:
            best_score = c5_ils
            best_h = h_ils.copy()

    if tleft() > 30:
        h_g3, c5_g3 = smart_greedy_descent(best_h, target_init, 20000, rng,
                                            time_limit=min(60.0, tleft() * 0.3), start_time=start_time)
        if c5_g3 < best_score:
            best_score = c5_g3
            best_h = h_g3.copy()

    n_use = len(best_h)
    target_use = n_use / 2.0

    if tleft() > 80:
        slsqp_time = min(200.0, tleft() * 0.3)
        h_ref, sc_ref = slsqp_refine(best_h, n_use, target_use,
                                      time_limit=slsqp_time, start_time=start_time)
        if sc_ref < best_score:
            best_score = sc_ref
            best_h = h_ref

    n_candidates = []
    for nf in [0.75, 0.85, 1.15, 1.3, 1.5, 2.0]:
        n_try = int(n_init * nf)
        if n_try % 2 == 0 and n_try != n_init and n_try >= 200 and n_try <= 3000:
            n_candidates.append(n_try)
    n_candidates = sorted(set(n_candidates))

    for n_try in n_candidates[:4]:
        if tleft() < 60:
            break
        target_try = n_try / 2.0
        h_interp = interpolate_to(best_h, n_try, target_try)
        h_bin_try = project_binary(h_interp, target_try)
        allowed = min(80.0, tleft() * 0.3)
        h_sa_n, c5_sa_n = sa_informed(h_bin_try, target_try, 30000, 0.012, 0.00008,
                                       rng, time_limit=allowed, start_time=start_time)
        if tleft() > 20:
            h_g_n, c5_g_n = smart_greedy_descent(h_sa_n, target_try, 5000, rng,
                                                  time_limit=min(20.0, tleft() * 0.2), start_time=start_time)
            if c5_g_n < c5_sa_n:
                h_sa_n = h_g_n
                c5_sa_n = c5_g_n
        if c5_sa_n < best_score:
            best_score = c5_sa_n
            best_h = h_sa_n.copy()

    n_use = len(best_h)
    target_use = n_use / 2.0

    if tleft() > 50:
        alphas_fine = [1000, 3000, 8000]
        p_fine = [max(3, n_use // 30)]
        global _cons_n, _cons_target
        _cons_n = n_use
        _cons_target = target_use
        bounds = [(0.0, 1.0)] * n_use
        cons = [{'type': 'eq', 'fun': cons_fun, 'jac': cons_jac}]
        for alpha in alphas_fine:
            if tleft() < 20:
                break
            try:
                res = minimize(lambda x: top_p_smooth(x, alpha, p_fine[0]), best_h,
                               method='SLSQP', bounds=bounds, constraints=cons,
                               options={'maxiter': 300, 'ftol': 1e-15})
                h_new = project_feasible(res.x, target_use)
                sc = compute_c5(h_new)
                if sc < best_score:
                    best_score = sc
                    best_h = h_new
            except Exception:
                pass

    n_use = len(best_h)
    target_use = n_use / 2.0
    if tleft() > 40:
        h_bin_final = project_binary(best_h, target_use)
        max_it = int(max(5000, tleft() * 2000))
        h_sa_f, c5_f = sa_informed(h_bin_final, target_use, max_it, 0.005, 0.00003,
                                    rng, time_limit=max(5.0, tleft() - 10), start_time=start_time)
        if c5_f < best_score:
            best_score = c5_f
            best_h = h_sa_f
        h_g_f, c5_g_f = smart_greedy_descent(best_h, target_use, 10000, rng,
                                              time_limit=max(3.0, tleft() - 5), start_time=start_time)
        if c5_g_f < best_score:
            best_score = c5_g_f
            best_h = h_g_f

    n_final = len(best_h)
    target_final = n_final / 2.0
    h_final = project_feasible(best_h, target_final)
    final_score = compute_c5(h_final)
    if final_score > best_score + 1e-14:
        h_final = best_h
        final_score = best_score
    return h_final, final_score, n_final
