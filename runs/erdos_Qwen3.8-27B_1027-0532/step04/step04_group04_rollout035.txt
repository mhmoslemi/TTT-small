def subgradient_descent(h, n, target, time_limit, start_time, lr_init=0.1, lr_decay=0.999):
    best_h = h.copy()
    best_c5 = compute_c5(best_h)
    h_cur = h.copy()
    lr = lr_init
    
    while time.time() - start_time < time_limit:
        corr = compute_corr(h_cur)
        max_idx = np.argmax(corr)
        k_star = max_idx - (n - 1)
        
        # Compute gradient of c_{k_star} with respect to h
        grad = np.zeros(n)
        # For shift k_star:
        if k_star >= 0:
            # c_k = sum_{m=0}^{n-1-k} h[m+k]*(1-h[m])
            k = k_star
            for i in range(max(k, 0), n):
                # h[i] as h[m+k] with m=i-k
                if i - k >= 0 and i - k <= n - 1 - k:
                    grad[i] += (1 - h_cur[i - k])
            for i in range(0, n - k):
                # h[i] as (1-h[m]) with m=i
                if i <= n - 1 - k and i + k < n:
                    grad[i] += -h_cur[i + k]
        else:
            m = -k_star
            # c_{-m} = sum_{mm=m}^{n-1} h[mm]*(1-h[mm-m])
            for i in range(m, n):
                # h[i] as h[mm] with mm=i
                grad[i] += (1 - h_cur[i - m])
            for i in range(0, n - m):
                # h[i] as (1-h[mm-m]) with mm-m=i, mm=i+m
                if i + m < n:
                    grad[i] += -h_cur[i + m]
        
        # Gradient step
        h_new = h_cur - lr * grad
        h_new = project_feasible(h_new, target)
        
        c5_new = compute_c5(h_new)
        if c5_new < best_c5:
            best_c5 = c5_new
            best_h = h_new.copy()
        
        h_cur = h_new
        lr *= lr_decay
    
    return best_h, best_c5

Actually wait, c_k is NOT linear in h! It's bilinear: c_k = Σ h[m+k] - h[m+k]*h[m]. So the objective is a max of bilinear functions, which is non-convex.

3. Take a step in the direction that reduces c_{k*} (while maintaining feasibility)

Let me also think about the SLSQP step. The smooth objective is:
f(h) = max_k c_k + (1/α) * log(Σ exp(α*(c_k - max_k c_k)))

This is a smooth upper bound on max_k c_k. As α→∞, it approaches the max. The gradient of this objective is:
∇f = (1/α) * Σ_k exp(α*(c_k - max))/(Σ_j exp(α*(c_j - max))) * α * ∇c_k

where w_k = exp(α*(c_k - max)) / Σ_j exp(α*(c_j - max)) (softmax weights).

So the gradient is a weighted average of the individual correlation gradients, with weights concentrated on the k with the largest c_k.

I can compute this efficiently:
1. Compute all c_k (O(n) via correlate)
2. Compute softmax weights (O(n))
3. Compute the weighted gradient: for each k with w_k > threshold, add w_k * corr_gradient(h, n, k) (O(n * num_active_k))

If α is large, only a few k have significant weight, so this is fast.
