For continuous refinement, the key challenge is that the objective (max of correlations) is non-smooth. The soft-max trick helps but introduces a bias.

An alternative: use the "max" directly with a subgradient method. The subgradient of max(corr) at a point where the max is unique is just the gradient of the max component. When the max is not unique (multiple shifts achieve the max), the subgradient is a convex combination.

For the simple case where the max is unique at shift k*, the gradient of corr[k*] wrt h is:
For k* > 0: d/dh[n] corr[k*] = 
  - If n ∈ [0, n-1-k*]: d/dh[n] [sum_{m=0}^{n-1-k*} h[m+k*](1-h[m])] = -h[n+k*] (from the (1-h[n]) term)
  - If n-k* ∈ [0, n-1-k*], i.e., n ∈ [k*, n-1]: d/dh[n] [sum h[m+k*](1-h[m])] = 1-h[n-k*] (from the h[n] = h[(n-k*)+k*] term)
  - Both can apply: gradient = (1-h[n-k*]) - h[n+k*] (with validity checks)

For k* < 0 (let t = -k* > 0): corr[-t] = sum_{n=t}^{n-1} h[n](1-h[n-t])
  d/dh[n]:
  - If n ∈ [t, n-1]: contributes 1-h[n-t] (from h[n] term)
  - If n+t ∈ [t, n-1], i.e., n ∈ [0, n-1-t]: contributes -h[n+t] (from (1-h[n]) term)
  - Both: gradient = (1-h[n-t]) - h[n+t] (with validity)

So the subgradient for the unique-max case is straightforward. I can use this for a projected subgradient method.

But the issue is that the max might not be unique, and we need to handle that. The soft-max approach handles this smoothly.

        if w < 1e-12:
            continue
        if s >= 0:
            grad[s:] += w * (1.0 - h[:n-s])
            grad[:n-s] -= w * h[s:]
        else:
            grad[:n+s] += w * (1.0 - h[-s:])
            grad[-s:] -= w * h[:n+s]
    return grad

def slsqp_refine(h0, n, target, alpha, maxiter, deadline):
    global _g_alpha, _g_target
    _g_alpha = alpha
    _g_target = target
    
    def obj(x):
        corr = compute_corr(x)
        cm = float(np.max(corr))
        shifted = np.clip(_g_alpha * (corr - cm), -700.0, 0.0)
        return cm + float(np.log(np.sum(np.exp(shifted)))) / _g_alpha
    
    def cons(x):
        return np.sum(x) - _g_target
    
    try:
        res = minimize(obj, h0, method='SLSQP',
                      bounds=[(0.0, 1.0)] * n,
                      constraints=[{'type': 'eq', 'fun': cons}],
                      options={'maxiter': maxiter, 'ftol': 1e-13})
        return project_feasible(res.x, target)
    except Exception:
        return h0
