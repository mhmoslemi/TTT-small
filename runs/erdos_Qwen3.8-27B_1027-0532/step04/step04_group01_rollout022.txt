Let me also think about a key optimization: instead of recomputing the full correlation after each move, I can compute the change in correlation analytically.

If I change h[i] from 0 to 1 (and h[j] from 1 to 0 to maintain the sum), how does the correlation change?

corr[k] = sum_l h[l] * (1-h[l-k]) (for appropriate k)

The change in corr at lag k due to changing h[i]:
- If h[i] goes 0→1: corr changes by (1-h[i-k]) at the relevant lags
- If h[j] goes 1→0: corr changes by -(1-h[j-k]) at the relevant lags

More precisely, corr[n-1+k] = sum_{l} h[l] * (1-h[l-k])
If h[i] goes from 0 to 1:
  corr[n-1+k] changes by (1-h[i-k]) for each k where i-k is valid
  i.e., for k = i - m where m ranges over valid indices

This is O(n) per affected lag, but there are O(n) lags, so it's O(n²) total, same as recomputing.

However, for a single position change, the change in corr is:
Δcorr[n-1+k] = (1-h[i-k]) for the position i change
and Δcorr[n-1+k] = -(1-h[j-k]) for the position j change

So the total change is a vector of length 2n-1 that's mostly zero except for O(n) non-zero entries. We can compute this in O(n) time!

This is a huge speedup. Let me implement this.

For a swap (h[i]: 0→1, h[j]: 1→0):
Δcorr[m] for m in [0, 2n-2]:
  lag = m - (n-1)
  For position i (0→1): contributes (1 - h[i-lag]) if 0 ≤ i-lag < n
  For position j (1→0): contributes -(1 - h[j-lag]) if 0 ≤ j-lag < n

So Δcorr[m] = (1 - h[i-(m-n+1)]) * [0≤i-(m-n+1)<n] - (1 - h[j-(m-n+1)]) * [0≤j-(m-n+1)<n]

This gives us the new corr in O(n) time per move (to find the new max), or O(1) if we track the max with a heap.

Actually, finding the new max is still O(n) in the worst case (if the current max is affected). But typically it's O(1) if we have a priority queue.

```python
def apply_swap_delta(corr, h, i, j, n):
    """Compute the change in correlation when h[i] goes 0->1 and h[j] goes 1->0."""
    # corr has length 2n-1
    # corr[m] = sum_l h[l] * (1-h[l - (m - (n-1))])
    # For position i changing 0->1: adds (1-h[i-(m-n+1)]) for valid indices
    # For position j changing 1->0: removes (1-h[j-(m-n+1)]) for valid indices
    
    delta = np.zeros(2*n-1)
    
    # Contribution from i (0->1): adds (1 - h[i - lag]) where lag = m - (n-1)
    # i - lag must be in [0, n-1], so lag in [i-(n-1), i], i.e., m in [i, i+n-1]
    lag_min_i = max(0, i - (n - 1))
    lag_max_i = min(n - 1, i)
    m_min_i = lag_min_i + (n - 1)
    m_max_i = lag_max_i + (n - 1)
    for m in range(m_min_i, m_max_i + 1):
        lag = m - (n - 1)
        delta[m] += (1.0 - h[i - lag])
    
    # Contribution from j (1->0): removes (1 - h[j - lag])
    lag_min_j = max(0, j - (n - 1))
    lag_max_j = min(n - 1, j)
    m_min_j = lag_min_j + (n - 1)
    m_max_j = lag_max_j + (n - 1)
    for m in range(m_min_j, m_max_j + 1):
        lag = m - (n - 1)
        delta[m] -= (1.0 - h[j - lag])
    
    return delta
```

            # Try all zeros that, if set to 1, would reduce the worst lag
            # For positive lag: setting h[j]=1 where h[j]=(0) and h[j+lag]=1 reduces count
            # For negative lag: setting h[i]=1 where h[i+m]=(0) and h[i]=1 reduces count
            improved = False
            if abs(worst_lag) > 0:
                if worst_lag > 0:
                    m = worst_lag
                    # Current count: # of j in [0,n-1-m] where h[j]=0, h[j+m]=1
                    # Setting h[j]=1 (from 0) reduces this by 1 if h[j+m]=1
                    cands = [j for j in range(min(50, n-m)) if h[j] == 0 and h[j+m] == 1]
                    if cands:
                        jj = cands[rng.randint(len(cands))]
                        ii = int(zeros[rng.randint(len(zeros))])
                        # We need to set h[jj]=1 and h[ii]=0
                        # But jj is already a zero, so we set it to 1 and set some one to 0
                        h[jj] = 1
                        omh[jj] = 0
                        # Now find an ii to set to 0
                        # Prefer ones that are at positions where h[i+m] is already 1
                        # (so removing it doesn't increase another lag too much)
                        o_candidates = list(ones)
                        oi = o_candidates[rng.randint(len(o_candidates))]
                        h[oi] = 0
                        omh[oi] = 1
                        saved = [(oi, 1), (jj, 0)]
                        valid = True
                        improved = True
                else:
                    m = -worst_lag
                    # Current count: # of i in [0,n-1-m] where h[i]=1, h[i+m]=0
                    # Setting h[i+m]=1 (from 0) reduces this by 1 if h[i]=1
                    cands = [i+m for i in range(min(50, n-m)) if h[i] == 1 and h[i+m] == 0]
                    if cands:
                        jj = cands[rng.randint(len(cands))]
                        oi = int(ones[rng.randint(len(ones))])
                        h[jj] = 1
                        omh[jj] = 0
                        h[oi] = 0
                        omh[oi] = 1
                        saved = [(oi, 1), (jj, 0)]
                        valid = True
                        improved = True
