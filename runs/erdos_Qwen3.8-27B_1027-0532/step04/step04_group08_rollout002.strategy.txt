   - Minimize \( C_5 = \max_k \int_0^2 h(x)(1-h(x+k))  dx \), evaluated via `compute_c5` from the task.
3. **Repair Mechanism**:
   - After crossover, the sum of ones must be adjusted to 200 (see implementation below).
4. **Operators**:
   - Crossover: Single-point crossover on the binary string, followed by repair.
   - Mutation: Swap two random bits (0 and 1) to maintain sum=200.

### Implementation procedure
1. **Initialization**:
   - Start with a population of binary vectors of length 400 with exactly 200 ones. Use the parent solution `initial_h_values` as the initial best candidate.
   - `population_size = 100`.

2. **Selection**:
   - Tournament selection (size 5) to choose parents based on minimized \( C_5 \).

3. **Crossover**:
   - For each parent, perform single-point crossover with a random partner.
   - **Repair**: Adjust the vector to have exactly 200 ones by flipping mismatched bits. Specifically:
     - If the number of ones exceeds 200, flip the excess from the most recently modified positions (see repair function below).
     - If fewer than 200 ones, flip the deficit from the most recently modified positions.
   - Mutation: Apply swap mutation (swap two bits) with probability 0.05 per bit.

4. **Fitness Evaluation**:
   - Use `compute_c5(h)` for each individual.
   - Elitism: Retain the best 1-3 individuals per generation.

5. **Termination**:
   - Time budget: 1300 seconds, yield every 10 generations up to budget exhaustion.

6. **Repair Function** (Python-like pseudocode):
   ```python
   def repair(h):
       target = 200
       current = np.sum(h)
       diff = current - target
       h_flip = h.copy()
       while abs(diff) > 0:
           n_flip = abs(diff)
           if diff > 0:
               # Flip excess from the end
               end_indices = np.arange(len(h))(h == 1)  # Flatten to get positions of 1s
               if len(end_indices) > n_flip:
                   indices_to_flip = end_indices[:n_flip]
                   h_flip[indices_to_flip] = 0
               else:
                   # Fallback: flip all trailing ones if repair needed
                   idx = 0
                   while idx < len(h_flip) and h_flip[idx] == 1:
                       idx += 1
                       h_flip[idx] = 0
                   # Additional fill if still deficit?
                   idx = len(h_flip) - 1
                   while idx >= 0 and np.sum(h_flip) < target:
                       if h_flip[idx] == 0:
                           h_flip[idx] = 1
                       idx -= 1
           else:
               # Flip deficit from the beginning
               start_indices = range(len(h))(h == 0)
               if len(start_indices) > n_flip:
                   indices_to_flip = start_indices[:n_flip]
                   h_flip[indices_to_flip] = 1
               else:
                   idx = 0
                   while idx < len(h_flip) and np.sum(h_flip) < target:
                       if h_flip[idx] == 0:
                           h_flip[idx] = 1
                       idx += 1
           current = np.sum(h_flip)
           diff = current - target
       return h_flip.astype(float)  # Convert to float after repair
   ```
