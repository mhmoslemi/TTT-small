2. Filtering breakpoints that lie in [δ_min, δ_max]

4. Returning the δ with minimum value

        ei[lo_i2:hi_i2+1] += -h[n-1::-1]  # -h[n-1], -h[n-2], ..., -h[0]
        
        # Similarly for position j (with opposite sign since h[j] changes by -δ)
        ej = np.zeros(2*n-1)
        lo_j = n - 1 - j
        hi_j = 2 * n - 2 - j
