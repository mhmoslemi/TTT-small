import numpy as np
from scipy.optimize import minimize_scalar, minimize
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr)) * dx

def project_feasible(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    for _ in range(500):
        diff = target_sum - np.sum(h)
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            mask = h < 1.0
        else:
            mask = h > 0.0
        cnt = int(mask.sum())
        if cnt == 0:
            break
        h[mask] += diff / cnt
        h = np.clip(h, 0.0, 1.0)
    return h

def upsample(h, new_n):
    old_n = len(h)
    x_old = (np.arange(old_n) + 0.5) * 2.0 / old_n
    x_new = (np.arange(new_n) + 0.5) * 2.0 / new_n
    h_new = np.interp(x_new, x_old, h)
    return project_feasible(h_new, new_n / 2.0)

def compute_B_fast(h, j, n):
    m_range = np.arange(-(n-1), n)
    jm = j + m_range
    jp = j - m_range
    valid_jp = (jp >= 0) & (jp < n)
    valid_jm = (jm >= 0) & (jm < n)
    B = np.zeros(2*n - 1)
    B[valid_jp] += 1.0 - h[jp[valid_jp]]
    B[valid_jm] -= h[jm[valid_jm]]
    return B

Now let me think about the 1D subproblem more carefully. The objective is:
f(t) = max_k (corr[k] + B[k] * (t - t_old)) + lam * (t - target_t)^2

This is a piecewise linear + quadratic function. The minimum is at a point where:
- Either at a "kink" (where two lines cross, and the derivative changes sign)
- Or at a smooth point where the derivative is zero
- Or at a boundary (t=0 or t=1)

The derivative (where it exists) is:
f'(t) = B[k*] + 2*lam*(t - target_t)
where k* is the index of the active line (the one achieving the max).

At the minimum:
- f'(t) = 0: t = target_t - B[k*] / (2*lam)
- At a kink: the left derivative <= 0 and right derivative >= 0
- At boundary: f'(0) >= 0 (for t=0) or f'(1) <= 0 (for t=1)

Finding the exact minimum requires identifying the active set, which is non-trivial. The simple approach (minimize_scalar with bounded method) is good enough and fast.

Actually, for a 1D piecewise linear + quadratic function, I can do better:
1. Compute the "breakpoints" where the active line changes. These occur where two lines cross:

   t = (corr[k2] - corr[k1]) / (B[k1] - B[k2])

2. Sort all breakpoints in [0,1].
3. The function is linear + quadratic on each interval between consecutive breakpoints.
4. On each interval, the active line is fixed, so I can solve the quadratic exactly.
5. Check the minimum in each interval and at the breakpoints.
