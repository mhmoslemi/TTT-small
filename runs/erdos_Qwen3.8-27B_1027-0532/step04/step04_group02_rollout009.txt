c'[n-1] - c[n-1] = h'[a]*(1-h'[a]) + h'[b]*(1-h'[b]) - h[a]*(1-h[a]) - h[b]*(1-h[b])
= 0 + 0 - 0 - 0 = 0 (for binary h)

So my formula gives 2 but the actual value is 0. The issue is that at k=0, the terms S1, S2, S3, S4 all overlap, and there's double-counting.

Let me redo this more carefully.

c[m] = Σ_i h[i] * (1-h[i+k]) where k = m-(n-1)

c'[m] = Σ_i h'[i] * (1-h'[i+k])

Δc[m] = c'[m] - c[m] = Σ_i [h'[i]*(1-h'[i+k]) - h[i]*(1-h[i+k])]

For most i, both h'[i]=h[i] and h'[i+k]=h[i+k], so the term is 0.

Non-zero terms occur when:
- i ∈ {a, b} (because h'[i] ≠ h[i]), OR
- i+k ∈ {a, b} (because h'[i+k] ≠ h[i+k]), i.e., i ∈ {a-k, b-k}

So the set of relevant i values is {a, b, a-k, b-k} (removing duplicates and out-of-range).

For each such i, compute h'[i]*(1-h'[i+k]) - h[i]*(1-h[i+k]).

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr)) * dx

def compute_corr(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return corr * dx

def project_feasible(h, target_sum):
    """Project h to satisfy sum constraint and box constraints."""
    h = np.clip(h.astype(float), 0.0, 1.0)
    diff = target_sum - np.sum(h)
    if abs(diff) < 1e-10:
        return h
    # Use iterative proportional fitting
    for _ in range(10):
        if abs(diff) < 1e-10:
            break
        if diff > 0:
            room = 1.0 - h
            mask = room > 1e-10
            if not mask.any():
                break
            h[mask] += diff / mask.sum()
        else:
            mask = h > 1e-10
            if not mask.any():
                break
            h[mask] += diff / mask.sum()
        h = np.clip(h, 0.0, 1.0)
        diff = target_sum - np.sum(h)
    return h

def project_binary(h, target_sum):
    """Project to binary with exact sum."""
    n = len(h)
    h_r = np.round(h).astype(int)
    current_sum = h_r.sum()
    if current_sum == target_sum:
        return h_r.astype(float)
    if current_sum > target_sum:
        need = int(current_sum - target_sum)
        ones = np.where(h_r == 1)[0]
        order = np.argsort(h[ones])[:need]
        h_r[ones[order]] = 0
    else:
        need = int(target_sum - current_sum)
        zeros = np.where(h_r == 0)[0]
        order = np.argsort(-h[zeros])[:need]
        h_r[zeros[order]] = 1
    return h_r.astype(float)

def smooth_max(corr, alpha):
    """Log-sum-exp based smooth maximum."""
    c = np.max(corr)
    if alpha < 1e-6:
        return c
    shifted = alpha * (corr - c)
    shifted = np.clip(shifted, -500, 0)
    return c + np.log(np.sum(np.exp(shifted))) / alpha

def top_p_smooth(h, p, alpha):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full') * dx
    sorted_corr = np.sort(corr)
    top = sorted_corr[-p:]
    max_top = np.max(top)
    shifted = np.clip(alpha * (top - max_top), -500.0, 0.0)
    return float(max_top + np.log(np.sum(np.exp(shifted))) / alpha)

# Global variables for SLSQP
_cons_n = 0
_cons_target = 0.0

def cons_fun(h):
    return np.sum(h) - _cons_target

def cons_jac(h):
    return np.ones(_cons_n)

def slsqp_optimize(h_start, n, target, p, alpha, maxiter, time_limit, start_time):
    global _cons_n, _cons_target
    _cons_n = n
    _cons_target = target
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': cons_fun, 'jac': cons_jac}]
    try:
        res = minimize(lambda x: top_p_smooth(x, p, alpha), h_start,
                       method='SLSQP', bounds=bounds, constraints=cons,
                       options={'maxiter': maxiter, 'ftol': 1e-15})
        h_new = project_feasible(res.x, target)
        return h_new, compute_c5(h_new)
    except Exception:
        return h_start, compute_c5(h_start)

def swap_delta(h, a, b, n, corr):
    """Compute new correlation after swapping h[a]=1->0, h[b]=0->1.
    Uses O(n) delta computation instead of O(n²) full recompute."""
    # k ranges from -(n-1) to n-1, m = k + (n-1) ranges from 0 to 2n-2
    k = np.arange(2*n-1) - (n-1)
    
    # We need to compute the change at each m.
    # The change only comes from i values in {a, b, a-k, b-k} (that are in [0,n))
    
    new_corr = corr.copy()
    
    # For i = a (h changes from 1 to 0):
    # Valid when 0 <= a+k < n, i.e., -a <= k < n-a
    # Change: 0*(1-h'(a+k)) - 1*(1-h(a+k)) = -(1-h(a+k))
    # But h'(a+k) = h(a+k) unless a+k = b, in which case h'(a+k) = 1
    # So change = -(1-h(a+k)) + (1-h'(a+k)) * 0 ... wait
    # Actually: old term = h(a)*(1-h(a+k)) = 1*(1-h(a+k)) = 1-h(a+k)
    #           new term = h'(a)*(1-h'(a+k)) = 0*(1-h'(a+k)) = 0
    #           change = 0 - (1-h(a+k)) = -(1-h(a+k))
    # This is correct regardless of h'(a+k) since the new term is 0.
    
    mask_a = (a + k >= 0) & (a + k < n)
    new_corr[mask_a] -= (1.0 - h[a + k[mask_a]])
    
    # For i = b (h changes from 0 to 1):
    # Valid when 0 <= b+k < n
    # Old term = h(b)*(1-h(b+k)) = 0
    # New term = h'(b)*(1-h'(b+k)) = 1*(1-h'(b+k))
    # h'(b+k) = h(b+k) unless b+k = a, in which case h'(b+k) = 0
    # So new term = 1-h(b+k) if b+k ≠ a, or 1-0 = 1 if b+k = a
    # Change = (1-h'(b+k)) - 0 = 1-h'(b+k)
    
    mask_b = (b + k >= 0) & (b + k < n)
    # For mask_b positions, the change is 1-h'(b+k)
    # h'(b+k) = h(b+k) except when b+k = a, where h' = 0
    val_b = h[b + k[mask_b]].copy()
    # Check if any of b+k[mask_b] equals a
    is_a = (b + k[mask_b]) == a
    val_b[is_a] = 0.0  # h'(a) = 0
    new_corr[mask_b] += (1.0 - val_b)
    
    # For i = a-k (so i+k = a, h at position a changes from 1 to 0):
    # Valid when 0 <= a-k < n (i.e., 0 <= i < n) and 0 <= a < n (always true since 0<=a<n)

    # The term is h(i)*(1-h(a)) which changes to h(i)*(1-h'(a)) = h(i)*(1-0) = h(i)
    # Old: h(a-k)*(1-h(a)) = h(a-k)*(1-1) = 0
    # New: h'(a-k)*(1-h'(a)) = h'(a-k)*1 = h'(a-k)
    # h'(a-k) = h(a-k) unless a-k = b, in which case h' = 1
    # Change = h'(a-k) - 0 = h'(a-k)
    
    i_ak = a - k  # the i value
    mask_ak = (i_ak >= 0) & (i_ak < n)
    # But we also need the original i to be valid for the correlation:
    # The correlation at shift k sums over i where 0<=i<n and 0<=i+k<n
    # i = a-k, i+k = a. We need 0<=a<n (true) and 0<=a-k<n (that's mask_ak)
    val_ak = h[i_ak[mask_ak]].copy()
    is_b = (i_ak[mask_ak]) == b
    val_ak[is_b] = 1.0  # h'(b) = 1
    new_corr[mask_ak] += val_ak
    
    # For i = b-k (so i+k = b, h at position b changes from 0 to 1):
    # i = b-k, i+k = b

    # New: h'(b-k)*(1-h'(b)) = h'(b-k)*(1-1) = 0
    # Change = 0 - h(b-k) = -h(b-k)

    # Wait, we're subtracting the OLD value h(b-k), not h'(b-k)
    # So change = -h(b-k) (using old h values)
    
    i_bk = b - k
    mask_bk = (i_bk >= 0) & (i_bk < n)
    new_corr[mask_bk] -= h[i_bk[mask_bk]]

After swap: corr'[m] = Σ_i h'(i) - Σ_i h'(i)h'(i+k)

Since Σ_i h'(i) = Σ_i h(i) (sum is preserved):
Δc[m] = -[Σ_i h'(i)h'(i+k) - Σ_i h(i)h(i+k)] = -ΔAC[k]

where ΔAC[k] is the change in the autocorrelation Σ_i h(i)h(i+k) at lag k!

So the change in the overlap correlation is the NEGATIVE of the change in the autocorrelation!

This makes sense: we want to MINIMIZE the overlap, which means we want to MAXIMIZE the autocorrelation at each lag. A positive autocorrelation means similar bits are close together, which means fewer (1,0) pairs.

Now, the change in autocorrelation at lag k when we swap h[a]: 1→0 and h[b]: 0→1:

AC[k] = Σ_i h(i)h(i+k) for valid i

ΔAC[k] = Σ_i [h'(i)h'(i+k) - h(i)h(i+k)]

Non-zero terms when i ∈ {a,b} or i+k ∈ {a,b}:
- i=a: h'(a)h'(a+k) - h(a)h(a+k) = 0*h'(a+k) - 1*h(a+k) = -h(a+k)
  (using h(a)=1, h'(a)=0; h'(a+k)=h(a+k) unless a+k=b)
  If a+k=b: 0*1 - 1*0 = 0 - 0 = 0. Wait: h(a+k) = h(b) = 0. So -h(b) = 0. ✓
  
- i=b: h'(b)h'(b+k) - h(b)h(b+k) = 1*h'(b+k) - 0*h(b+k) = h'(b+k)
  h'(b+k) = h(b+k) unless b+k=a, in which case h'=0.
  If b+k=a: 0. Otherwise: h(b+k).
  
- i=a-k (so i+k=a): h'(a-k)h'(a) - h(a-k)h(a) = h'(a-k)*0 - h(a-k)*1 = -h(a-k)
  (h'(a)=0, h(a)=1)
  Note: h(a-k) here is the OLD value. If a-k=b, h(a-k)=h(b)=0. If a-k=a (k=0), h(a-k)=h(a)=1.
  
- i=b-k (so i+k=b): h'(b-k)h'(b) - h(b-k)h(b) = h'(b-k)*1 - h(b-k)*0 = h'(b-k)
  h'(b-k) = h(b-k) unless b-k=a, in which case h'=0.
  If b-k=a: 0. Otherwise: h(b-k).

So:
ΔAC[k] = -h(a+k) + h'(b+k) - h(a-k) + h'(b-k)

with the modifications:
- h(a+k): use old value. (a+k=b gives h(b)=0)
- h'(b+k): = h(b+k) unless b+k=a, then = 0
- h(a-k): use old value. (a-k=b gives h(b)=0; a-k=a at k=0 gives h(a)=1)
- h'(b-k): = h(b-k) unless b-k=a, then = 0

And Δc[m] = -ΔAC[k] where k = m-(n-1).

Let me verify at k=0:
ΔAC[0] = -h(a+0) + h'(b+0) - h(a-0) + h'(b-0)
= -h(a) + h'(b) - h(a) + h'(b)
= -1 + 1 - 1 + 1 = 0 ✓

At k = b-a (so a+k = b):
ΔAC[b-a] = -h(b) + h'(b+b-a) - h(a-(b-a))
