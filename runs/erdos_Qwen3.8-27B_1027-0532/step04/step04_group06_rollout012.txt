Total ΔC_k = -(1-h[a+k])*[a < n-k] + h[a-k]*[a ≥ k] + (1-h[b+k])*[b < n-k] - h[b-k]*[b ≥ k]

This is O(1) per lag! So to compute the exact delta for all lags, it's O(n). And to find the max, it's O(n) as well.

This means we can do exact delta computation in O(n) per move, which is much better than O(n log n) or O(n²) for the full correlation.

4. Track the max (using a heap or just scanning)

    """Compute the delta in the full correlation when h[a]: 1->0, h[b]: 0->1."""
    # corr[k_idx] corresponds to lag k = k_idx - (n-1)
    # C_k for k >= 0: sum_{i=0}^{n-1-k} h[i](1-h[i+k])
    # In "full" mode: corr[n-1+k] = C_k for k >= 0 (approximately)
    
    # Actually, let's just work with the lag directly.
    # The "full" correlation has 2n-1 elements.
    # corr[j] for j in [0, 2n-2] corresponds to...
    # np.correlate(h, 1-h, mode='full')[j] = sum_i h[i] * (1-h)[i+j-(n-1)]
    # = sum_i h[i] * (1-h[i-(n-1-j)])
    # Let k = n-1-j, then: sum_i h[i] * (1-h[i+k])
    # So corr[n-1-k] = sum_i h[i](1-h[i+k]) = C_k
    
    # Delta for C_k when h[a]: 1->0, h[b]: 0->1:
    # ΔC_k = -(1-h[a+k])*[0<=a<n, 0<=a+k<n] + h[a-k]*[0<=a<n, 0<=a-k<n]
    #        + (1-h[b+k])*[0<=b<n, 0<=b+k<n] - h[b-k]*[0<=b<n, 0<=b-k<n]
    
    # But a is in [0,n-1] and b is in [0,n-1] always, so:
    # ΔC_k = -(1-h[a+k])*[a+k<n] + h[a-k]*[a-k>=0]
    #        + (1-h[b+k])*[b+k<n] - h[b-k]*[b-k>=0]
    
    delta = np.zeros(2*n-1)
    # For each lag k from -(n-1) to n-1:
    # The index in the "full" array is n-1+k
    # ΔC_k = -(1-h[a+k])*[0<=a+k<n] + h[a-k]*[0<=a-k<n]
    #        + (1-h[b+k])*[0<=b+k<n] - h[b-k]*[0<=b-k<n]
    
    # h[a+k] is valid when 0 <= a+k < n, i.e., -a <= k < n-a
    # h[a-k] is valid when 0 <= a-k < n, i.e., a-n < k <= a
    # Similarly for b.
    
    # This is a sum of at most 4 "indicator" terms, each shifted.
    # Let's compute it directly.
    
    # For k from max(-(n-1), -a, a-n+1) to min(n-1, n-1-a, a):
    # This is getting complex. Let me just loop over k.
    
    for k in range(-(n-1), n):
        dk = 0.0
        if 0 <= a+k < n:
            dk -= (1.0 - h[a+k])
        if 0 <= a-k < n:
            dk += h[a-k]
        if 0 <= b+k < n:
            dk += (1.0 - h[b+k])
        if 0 <= b-k < n:
            dk -= h[b-k]
        delta[n-1+k] = dk
    
    return delta

def delta_corr_vectorized(h, a, b, n):
    # Returns the delta array of length 2n-1
    delta = np.zeros(2*n-1)
    
    # Contribution from h[a]: 1->0
    # For lag k: -(1-h[a+k]) if 0<=a+k<n, +h[a-k] if 0<=a-k<n
    # a+k in [0,n-1] means k in [-a, n-1-a]
    k_min_a1 = -a
    k_max_a1 = n-1-a
    if k_max_a1 >= k_min_a1:

        values1 = (1.0 - h[a + (idx1 - (n-1))])
        delta[idx1] -= values1
    
    k_min_a2 = a-(n-1)
    k_max_a2 = a
    if k_max_a2 >= k_min_a2:
        idx2 = np.arange(k_min_a2, k_max_a2+1) + (n-1)
        values2 = h[a - (idx2 - (n-1))]
        delta[idx2] += values2
    
    # Contribution from h[b]: 0->1
    k_min_b1 = -b
    k_max_b1 = n-1-b
    if k_max_b1 >= k_min_b1:
        idx1 = np.arange(k_min_b1, k_max_b1+1) + (n-1)
        values1 = (1.0 - h[b + (idx1 - (n-1))])
        delta[idx1] += values1
    
    k_min_b2 = b-(n-1)
    k_max_b2 = b
    if k_max_b2 >= k_min_b2:
        idx2 = np.arange(k_min_b2, k_max_b2+1) + (n-1)
        values2 = h[b - (idx2 - (n-1))]
        delta[idx2] -= values2
    
    return delta

Let me also think about a **deterministic local search** that's more aggressive:
- For each of the top K lags (where K is small, say 5-10), try all possible moves that would reduce C_k
- This is like a coordinate descent on the correlation values

Actually, a better approach: **best-improvement local search**
- For the current worst lag k*, find the move (a, b) that most reduces C_{k*} while not increasing other C_k's too much
- This is like a greedy approach

But the "not increasing other C_k's" constraint makes it hard. Let me think...

For a move (a: 1→0, b: 0→1), the change in C_{k*} is:
ΔC_{k*} = -(1-h[a+k*]) + h[a-k*] + (1-h[b+k*]) - h[b-k*]

To minimize C_{k*}, we want ΔC_{k*} to be as negative as possible:
- We want h[a+k*] = 1 (so we lose 0)
- We want h[a-k*] = 0 (so we gain 0)
- We want h[b+k*] = 0 (so we gain 1)
- We want h[b-k*] = 1 (so we lose 1)

So the ideal move is: a is a 1 that has neighbors 1 and 0 at distances k*, and b is a 0 that has neighbors 0 and 1 at distances k*.

The maximum reduction in C_{k*} is 2 (if we find such a move).

But we also need to check the effect on other lags. The total effect on C5 is determined by the max over all lags after the move.

**Strategy: "Targeted best move"**
1. Identify the top K worst lags
2. For each worst lag k*, enumerate candidate moves (a from ones, b from zeros) that reduce C_{k*}
3. For each candidate, compute the full delta (O(n)) and check if C5 decreases
4. Make the best move found

This is more expensive per move but might find better improvements.

For n=600, the number of (a,b) pairs is about 300*300 = 90,000. For each, computing the delta is O(n) = O(600). So total is 90,000 * 600 = 54 million operations. That's too slow for a single step.

Instead, let's be smarter: for a given worst lag k*, we can pre-filter candidates:
- a should be a 1 where h[a+k*]=1 and h[a-k*]=0 (to maximize reduction in C_{k*})
- b should be a 0 where h[b+k*]=0 and h[b-k*]=1 (to maximize reduction in C_{k*})

These are relatively rare, so the candidate set should be small.

Let me now think about the overall algorithm structure:

**New Algorithm:**

1. **Phase 1: Exact-delta SA with correlation tracking**
   - Maintain the full correlation array
   - Use exact delta computation for move evaluation
   - Focus moves on the worst lags
   - Run for a fixed number of iterations or time

2. **Phase 2: Best-improvement local search on worst lags**
   - For the current worst lag, find the best single move
   - Repeat until no improvement possible
   - This should polish the SA result

3. **Phase 3: Multi-lag optimization**
   - Try to simultaneously reduce the top 3-5 worst lags
   - Use a few coupled moves (2-3 swaps at once)

4. **Phase 4: Resolution increase**
   - Interpolate to higher n
   - Repeat phases 1-3

5. **Phase 5: Continuous optimization (SLSQP)**
   - Final polish with continuous values

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr)) * dx

def get_corr(h):
    return np.correlate(h, 1.0 - h, mode='full')

def project_feasible(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    diff = target_sum - np.sum(h)
    if abs(diff) < 1e-14:
        return h
    if diff > 0:
        idx = np.where(h < 1.0)[0]
    else:
        idx = np.where(h > 0.0)[0]
    if len(idx) == 0:
        return h
    h = h.copy()
    h[idx] += diff / len(idx)
    return np.clip(h, 0.0, 1.0)

def project_binary(h, target_sum):
    n = len(h)
    h_r = np.round(h)
    h_r = np.clip(h_r, 0, 1).astype(int)
    current_sum = h_r.sum()
    if current_sum == target_sum:
        return h_r.astype(float)
    ones = np.where(h_r == 1)[0]
    zeros = np.where(h_r == 0)[0]
    if current_sum > target_sum:
        need = int(current_sum - target_sum)
        if need <= len(ones):
            order = np.argsort(h[ones])[:need]
            h_r[ones[order]] = 0
    else:
        need = int(target_sum - current_sum)
        if need <= len(zeros):
            order = np.argsort(-h[zeros])[:need]
            h_r[zeros[order]] = 1
    return h_r.astype(float)

def exact_delta(h, a, b, n):
    """Compute delta in correlation when h[a]:1->0 and h[b]:0->1"""
    # corr index for lag k is n-1+k
    # ΔC_k = -(1-h[a+k])*[0<=a+k<n] + h[a-k]*[0<=a-k<n]
    #        + (1-h[b+k])*[0<=b+k<n] - h[b-k]*[0<=b-k<n]
    delta = np.zeros(2*n-1)
    
    # h[a+k] valid for k in [-a, n-1-a]
    lo1, hi1 = max(-a, -(n-1)), min(n-1-a, n-1)
    if hi1 >= lo1:
        ks = np.arange(lo1, hi1+1)
        delta[n-1+ks] -= (1.0 - h[a + ks])
    
    # h[a-k] valid for k in [a-(n-1), a]
    lo2, hi2 = max(a-(n-1), -(n-1)), min(a, n-1)
    if hi2 >= lo2:
        ks = np.arange(lo2, hi2+1)
        delta[n-1+ks] += h[a - ks]
    
    # h[b+k] valid for k in [-b, n-1-b]
    lo3, hi3 = max(-b, -(n-1)), min(n-1-b, n-1)
    if hi3 >= lo3:
        ks = np.arange(lo3, hi3+1)
        delta[n-1+ks] += (1.0 - h[b + ks])
    
    # h[b-k] valid for k in [b-(n-1), b]
    lo4, hi4 = max(b-(n-1), -(n-1)), min(b, n-1)
    if hi4 >= lo4:
        ks = np.arange(lo4, hi4+1)
        delta[n-1+ks] -= h[b - ks]
    
    return delta

def exact_delta_multi(h, a_list, b_list, n):
    """Compute delta for multiple swaps: a_list go 1->0, b_list go 0->1"""
    delta = np.zeros(2*n-1)
    for a in a_list:
        lo1, hi1 = max(-a, -(n-1)), min(n-1-a, n-1)
        if hi1 >= lo1:
            ks = np.arange(lo1, hi1+1)
            delta[n-1+ks] -= (1.0 - h[a + ks])
        lo2, hi2 = max(a-(n-1), -(n-1)), min(a, n-1)
        if hi2 >= lo2:
            ks = np.arange(lo2, hi2+1)
            delta[n-1+ks] += h[a - ks]
    for b in b_list:
        lo3, hi3 = max(-b, -(n-1)), min(n-1-b, n-1)
        if hi3 >= lo3:
            ks = np.arange(lo3, hi3+1)
            delta[n-1+ks] += (1.0 - h[b + ks])
        lo4, hi4 = max(b-(n-1), -(n-1)), min(b, n-1)
        if hi4 >= lo4:
            ks = np.arange(lo4, hi4+1)
            delta[n-1+ks] -= h[b - ks]
    return delta
