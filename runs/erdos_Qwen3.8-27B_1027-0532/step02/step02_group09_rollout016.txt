- h[p-ℓ] * (-δ) if 0 ≤ p-ℓ < n (the (1-h[p]) term, from the i = p-ℓ position)
  Wait, (1-h)[p-ℓ] = 1-h[p-ℓ], and if i+ℓ = p, then i = p-ℓ.
  So the term is h[p-ℓ] * (1-h[p]), and changing h[p] by δ changes this by h[p-ℓ] * (-δ).

So ΔC[j] = δ * [(1-h[p+ℓ]) - h[p-ℓ]] (where terms are 0 if indices are out of range)
= δ * [1 - h[p+ℓ] - h[p-ℓ]]

This is O(1) per j, so computing the full effect is O(n) per coordinate.
Then finding the optimal h[p] requires minimizing max_j (C[j] + ΔC[j]) over h[p] ∈ [0,1].

Since ΔC[j] is linear in δ (and hence in h[p]), each C[j] + ΔC[j] is affine in h[p]. The max of affines is convex, and we can find the minimum by checking where the maximum is "flat" or at the boundaries.

        x = np.linspace(0.0, 2.0, n, endpoint=False)
        for freq, amp in [(2.0, 0.4), (3.0, 0.5), (1.0, 0.6), (4.0, 0.3)]:
            if time_left() < 60:
                break
            h_sine = 0.5 + amp * np.sin(2.0 * np.pi * freq * x)
            h_sine = np.clip(h_sine, 0.0, 1.0)
            h_sine = project_box_sum(h_sine, n / 2.0)
            h_new, s_new = _lbfgs_refine(h_sine, 5000, n, min(40.0, time_left() * 0.3))
            if s_new < best_score:
                best_score = s_new
                best_h = h_new.copy()

    # Phase 8: Final high-precision polish
    if time_left() > 30:
        for alpha in [50000, 100000]:
            if time_left() < 15:
                break
            h_new, s_new = _lbfgs_refine(best_h, alpha, n, min(25.0, time_left() * 0.6))
            if s_new < best_score:
                best_score = s_new
                best_h = h_new.copy()
        if time_left() > 10:
            h_new, s_new = _slsqp_refine(best_h, 20000, n, 500)
            if s_new < best_score:
                best_score = s_new
                best_h = h_new.copy()

    # Final projection and evaluation
    best_h = project_box_sum(best_h, len(best_h) / 2.0)
    best_h = np.clip(best_h, 0.0, 1.0)
    best_score = evaluate_score(best_h)

    return (best_h, best_score, len(best_h))
