Actually, for the smooth max gradient, I can compute it as a weighted sum of the individual gradients:

For lag l = k - n + 1, the gradient of corr[k] with respect to h is:
- For i such that i+l is in [0,n-1] (i.e., i in [max(0,-l), min(n-1, n-1-l)]): grad[i] += (1-h[i+l])
- For i such that i-l is in [0,n-1] (i.e., i in [max(0,l), min(n-1, n-1+l)]): grad[i] -= h[i-l]

This is essentially:
grad = (1-h)[shifted by -l] + (-h)[shifted by l] (with appropriate zero-padding)

In numpy:
```python
def grad_of_corr_lag(h, l, n):
    """Gradient of corr at lag l with respect to h."""
    grad = np.zeros(n)
    # Forward: i + l in [0, n-1] => i in [0, n-1-l] (if l>=0) or i in [-l, n-1] (if l<0)
    if l >= 0:
        grad[:n-l] += (1 - h[l:])  # h[i+l] for i=0,...,n-1-l
        grad[l:] -= h[:n-l]        # h[i-l] for i=l,...,n-1
    else:
        grad[-l:] += (1 - h[:n+l])  # h[i+l] for i=-l,...,n-1
        grad[:n+l] -= h[-l:]        # h[i-l] for i=0,...,n-1+l
    return grad
```

Wait, I need to be more careful. The lag l = k - (n-1). So k = l + n - 1.

corr[k] = sum_j h[j] * (1-h[j+l+n-1-(n-1)]) = sum_j h[j] * (1-h[j+l])

where j+l must be in [0, n-1].

So corr[k] = sum_{j: 0<=j<n, 0<=j+l<n} h[j] * (1-h[j+l])

The gradient with respect to h[i]:
- From the h[j] factor: if j=i and 0<=i+l<n, contribution is (1-h[i+l])
- From the (1-h[j+l]) factor: if j+l=i and 0<=j<n, i.e., j=i-l and 0<=i-l<n, contribution is -h[i-l]

So:
grad[i] = (1-h[i+l]) * [0<=i+l<n] + (-h[i-l]) * [0<=i-l<n]

In numpy:
```python
def grad_corr_lag(h, l, n):
    grad = np.zeros(n)
    # Term 1: (1-h[i+l]) for valid i
    if l >= 0:
        # i+l < n => i < n-l, and i >= 0
        # So i = 0, ..., n-l-1
        grad[:n-l] += (1 - h[l:])  # h[i+l] = h[l + 0], h[l+1], ..., h[n-1]
    else:
        # i+l >= 0 => i >= -l = |l|
        # So i = |l|, ..., n-1
        grad[abs(l):] += (1 - h[:n-abs(l)])  # h[i+l] for i=|l|,...,n-1 gives h[0],...,h[n-1-|l|]... 
        # Wait: i+l for i=|l| is |l|-|l|=0, for i=n-1 is n-1-|l|
        # So h[i+l] = h[0], h[1], ..., h[n-1-|l|] = h[:n-abs(l)]
        # And there are n-|l| values, going into grad[|l|:] which also has n-|l| slots. ✓
    
    # Term 2: -h[i-l] for valid i
    if l >= 0:
        # i-l >= 0 => i >= l
        # i-l < n => i < n+l (always true since i < n and l < n typically)
        # So i = l, ..., n-1
        grad[l:] -= h[:n-l]  # h[i-l] for i=l,...,n-1 gives h[0],...,h[n-1-l]
    else:
        # i-l >= 0 => i >= l (but l<0, so always true since i>=0)
        # i-l < n => i < n+l = n-|l|
        # So i = 0, ..., n-|l|-1
        grad[:n+abs(l)] -= h[abs(l):]  # Wait, n+l = n-|l|
        # h[i-l] for i=0,...,n-|l|-1 gives h[|l|], h[|l|+1], ..., h[n-1]
        # That's h[abs(l):] which has |n|... wait n - |l| elements
        # And grad[:n-|l|] has n-|l| slots. ✓
    
    return grad
```

def smooth_max_gradient(h, eps, n):
    dx = 2.0 / n
    corr = np.correlate(h, 1-h, mode="full")
    weights = np.exp(eps * (corr - np.max(corr)))
    weights /= np.sum(weights)
    
    grad = np.zeros(n)
    n_corr = 2 * n - 1
    for k in range(n_corr):
        w = weights[k]
        if w < 1e-10:
            continue
        l = k - (n - 1)
        # Add w * grad_corr_lag(h, l, n)
        if l >= 0:
            if n - l > 0:
                grad[:n-l] += w * (1 - h[l:])
            if l > 0:
                grad[l:] -= w * h[:n-l]
            elif l == 0:
                grad[:] -= w * h[:]
        else:
            al = abs(l)
            if n - al > 0:
                grad[al:] += w * (1 - h[:n-al])
            grad[:n-al] -= w * h[al:]
    
    grad *= dx
    return grad
