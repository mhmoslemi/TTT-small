- Specifically, S[p][t] = h[p+m_t] + h[p-m_t]

- t such that 0 ≤ i + t - n + 1 < n: n - 1 - i < t ≤ n - 1 + i, i.e., t ∈ [n-i, n+i-1] (clamped to [0, 2n-2])
  And p = i + t - n + 1

So for each t in [0, 2n-2], the affected p values are at most 2 (one from each condition). Total affected entries: O(n).

def update_S_flip(h, S, i, old_val):
    """Update S after h[i] changes. h[i] has already been updated."""
    n = len(h)
    delta = h[i] - old_val  # change in h[i]
    # S[p][t] = h[p+m_t] + h[p-m_t]
    # h[i] contributes when p+m_t = i or p-m_t = i
    
    m = np.arange(-(n-1), n)  # length 2n-1
    # p + m_t = i → p = i - m_t
    # Valid when 0 ≤ i - m_t < n
    pm_idx = i - m  # candidate p values for each t
    valid_pm = (pm_idx >= 0) & (pm_idx < n)
    # S[pm_idx][t] += delta for valid t
    for t in range(2*n-1):
