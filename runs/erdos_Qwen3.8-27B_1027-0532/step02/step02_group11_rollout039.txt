Instead of recomputing the full correlation, I can update only the affected entries.

When h[i] changes from 1 to 0 and h[j] changes from 0 to 1:
For each k (lag), the change in c_k is:
Δc_k = [-(1-h_old[i-k]) - h_old[i+k]] + [(1-h_old[j-k]) - h_old[j+k]]

where h_old is the state before the swap, and we include a term only if the index is valid.

Since h is binary, h[i-k] is either 0 or 1. So:
- (1-h[i-k]) is 1 if h[i-k]=0, 0 if h[i-k]=1
- h[i+k] is 1 if h[i+k]=1, 0 if h[i+k]=0

So Δc_k = -(1 if h[i-k]=0 else 0) - (1 if h[i+k]=1 else 0) + (1 if h[j-k]=0 else 0) - (1 if h[j+k]=1 else 0)

This is:
= -(1-h[i-k]) - h[i+k] + (1-h[j-k]) - h[j+k]

Each term is 0 or ±1, so Δc_k ∈ {-2, -1, 0, 1, 2}.
