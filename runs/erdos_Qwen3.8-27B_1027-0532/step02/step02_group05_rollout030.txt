def optimize_single_coordinate(h, j, alpha, corr, weights):
    """Optimize h[j] given correlations and weights from current h."""
    n = len(h)
    k_range = np.arange(-(n-1), n)  # all shifts
    
    # Compute coeff[m] for changing h[j]
    coeff = np.zeros(2*n - 1)
    for idx, k in enumerate(k_range):
        # Change in corr[idx] when h[j] increases by 1
        c = 0.0
        if j + k >= 0 and j + k < n:
            c += (1.0 - h[j + k])
        if j - k >= 0 and j - k < n:
            c -= h[j - k]
        coeff[idx] = c
    
    # f(δ) = (1/α) * log(sum_m weights[m] * exp(α * δ * coeff[m]))
    # f'(δ) = sum_m coeff[m] * p_m(δ) where p_m = w_m * exp(α*δ*c_m) / sum(...)
    # f''(δ) = α * (E[c²] - (E[c])²) where E is under p(δ)
    
    hj = h[j]
    δ_lo = -hj
    δ_hi = 1.0 - hj
    
    # Newton's method
    δ = 0.0
    for _ in range(20):
        # Clip δ to feasible range
        δ = max(δ_lo, min(δ_hi, δ))
        
        # Compute p(δ)
        exponents = alpha * δ * coeff
        exponents -= np.max(exponents)  # for numerical stability
        p = weights * np.exp(exponents)
        p_sum = np.sum(p)
        if p_sum < 1e-300:
            break
        p = p / p_sum
        
        # f'(δ) = E[c] under p
        fprime = np.sum(coeff * p)
        
        # f''(δ) = α * Var[c] under p
        fsecond = alpha * (np.sum(coeff**2 * p) - fprime**2)
        
        if abs(fsecond) < 1e-15:
            break
        
        δ_new = δ - fprime / fsecond
        
        if abs(δ_new - δ) < 1e-12:
            δ = δ_new
            break
        δ = δ_new
    
    δ = max(δ_lo, min(δ_hi, δ))
    h[j] += δ
    return h

    k = np.arange(-(n-1), n)

The function to minimize is:
f(t) = (1/α) * log(Σ_m w_m * exp(α * t * c_m))

where w_m = exp(α * corr_m) / Σ exp(α * corr_m) (normalized)

f'(t) = Σ_m c_m * p_m(t) where p_m = w_m * exp(α*t*c_m) / Σ w_n * exp(α*t*c_n)
f''(t) = α * (Σ_m c_m² * p_m - (Σ_m c_m * p_m)²) = α * Var_p(c) ≥ 0

Newton step: t_{new} = t - f'(t) / f''(t)

Since f is convex, Newton from any starting point will monotonically decrease f (as long as we stay in the domain). But we need to check that the step doesn't go outside [lo, hi].

If the Newton step goes outside, we clip and then do a line search (bisection) to find the optimum on the boundary of the feasible interval.

Actually, since f is convex and defined on [lo, hi], the minimum is either at an interior critical point (where f' = 0) or at a boundary. Newton will find the interior point if it exists. If not, the function is monotone on [lo, hi] and the minimum is at lo or hi.
