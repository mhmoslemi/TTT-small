C(s) = Σ_{i=0}^{n-1-s} h[i](1-h[i+s]) for s > 0

This is the number of positions i where h[i]=1 and h[i+s]=0.

Total 1s in positions 0 to n-1-s: let's call it N1(s).
Overlapping 1s (h[i]=1 and h[i+s]=1): A(s).
So C(s) = N1(s) - A(s).

If the sequence is "balanced" (ones uniformly distributed), N1(s) ≈ 90*(n-s)/n.
And A(s) ≈ 45 (from difference set approximation).

So C(s) ≈ 90(180-s)/180 - 45 = (180-s)/2 - 45 = 45 - s/2.

For s=0: C(0) = 0 (exact).
For s=1: C(1) ≈ 44.5.
For s=179: only one term, C(179) = h[0](1-h[179]) which is 0 or 1.

So the maximum is around s=1 or s=2, giving C(s) ≈ 44-45.

Then C₅ = dx * max C(s) = (2/180) * 45 = 0.5. That's much higher than 0.38!

So the difference set approach doesn't directly apply. The issue is that for small shifts, C(s) is large because N1(s) is close to 90 while A(s) is only about 45.

To minimize C(s) for small s, we want A(s) to be large (many overlapping 1s). But A(s) can be at most min(N1(s), N1_shifted(s)) ≤ 90. And C(s) = N1(s) - A(s).

To minimize C(1): we want A(1) to be as large as possible, meaning h[i]=1 implies h[i+1]=1 for as many i as possible. This means the 1s should be in long runs.

But then for large shifts, C(s) would be large because the runs won't overlap.

So there's a trade-off. The optimal solution balances between having 1s clustered (to reduce small-shift C) and spread out (to reduce large-shift C).

This is a non-trivial optimization problem, which is why we need numerical methods.

    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(dx * np.max(corr))

def project_to_binary_fast(h, target):
    n = len(h)
    diffs = np.abs(h - 0.5)
    order = np.argsort(diffs)[::-1]
    result = np.zeros(n)
    result[order[:target]] = 1.0
    return result

def project_onto_constraint(h, target_sum):
    lo, hi = -2.0, 2.0
    for _ in range(100):
        mid = (lo + hi) / 2.0
        s = np.clip(h - mid, 0.0, 1.0).sum()
        if s > target_sum:
            lo = mid
        else:
            hi = mid
    lam = (lo + hi) / 2.0
    return np.clip(h - lam, 0.0, 1.0)

def smooth_objective(h, eps):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full') * dx
    cmax = np.max(corr)
    x = (corr - cmax) / eps
    x -= np.max(x)
    return cmax + eps * np.log(np.sum(np.exp(x)))

def smooth_gradient(h, eps):
    n = len(h)
    dx = 2.0 / n
    omh = 1.0 - h
    corr = np.correlate(h, omh, mode='full') * dx
    cmax = np.max(corr)
    x = (corr - cmax) / eps
    x -= np.max(x)
    ex = np.exp(x)
    sexp = np.sum(ex)
    w = ex / sexp
    grad = np.zeros(n)
    for k in range(2 * n - 1):
        wk = w[k]
        if wk < 1e-14:
            continue
        s = k - (n - 1)
        if s >= 0:
            m = n - s
            grad[s:] += wk * dx * omh[:m]
            grad[:m] -= wk * dx * h[s:]
        else:
            r = -s
            m = n - r
            grad[:m] += wk * dx * omh[r:]
            grad[r:] -= wk * dx * h[:m]
    return grad

    return float(np.sum(h) - len(h) / 2.0)

    return np.ones(len(h))

        h_opt = project_onto_constraint(result.x, target_sum)
        return h_opt, compute_c5(h_opt)
    except Exception:
        return h0, compute_c5(h0)

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')

def project_to_binary_fast(h, target):
    n = len(h)
    diffs = np.abs(h - 0.5)
    order = np.argsort(diffs)[::-1]
    result = np.zeros(n)
    result[order[:target]] = 1.0

def project_onto_constraint(h, target_sum):
    lo, hi = -2.0, 2.0
    for _ in range(100):
        mid = (lo + hi) / 2.0
        s = np.clip(h - mid, 0.0, 1.0).sum()
        if s > target_sum:
            lo = mid
        else:
            hi = mid
    lam = (lo + hi) / 2.0
    return np.clip(h - lam, 0.0, 1.0)

def smooth_objective(h, eps):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full') * dx
    cmax = np.max(corr)
    x = (corr - cmax) / eps
    x -= np.max(x)
    return cmax + eps * np.log(np.sum(np.exp(x)))

def smooth_gradient(h, eps):
