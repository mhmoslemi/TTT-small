The problem is equivalent to finding h that minimizes the maximum cross-correlation between h and 1-h. This is related to "low cross-correlation" sequences in signal processing.

In the discrete setting, if we think of h as a binary sequence (0 or 1), then we're looking for a sequence that has low cross-correlation with its complement. But h is allowed to be non-binary, which gives more flexibility.

One approach from signal processing: use "m-sequences" (maximum length sequences) which have good autocorrelation properties. But those are for autocorrelation, not cross-correlation with the complement.

Actually, for a binary sequence h ∈ {0,1}^n, the cross-correlation with 1-h is:
O(k) = ∑_i h[i] * (1-h[i+k])

This counts the number of positions where h[i]=1 and h[i+k]=0. If the sequence is "balanced" (about n/2 ones), then for random shifts, O(k) ≈ n/4. We want the max to be minimized.

For a pseudo-random binary sequence, the cross-correlation peaks are typically O(√n), so the max would be O(n/4 + √n), which is much better than n/2 (the case for a step function).

But we're not constrained to binary h. The optimum might be non-binary.

Let me think about this differently. In the continuous case, we want:
min_h max_k ∫ h(x)(1-h(x+k)) dx

If h is smooth and varies slowly, then for small k, h(x+k) ≈ h(x) + k*h'(x), so:
h(x)(1-h(x+k)) ≈ h(x)(1-h(x) - k*h'(x)) = h(x)(1-h(x)) - k*h(x)*h'(x)

The integral of h(x)(1-h(x)) is fixed (it's ∫h - ∫h² = 1 - ∫h²), and the cross term ∫k*h(x)*h'(x) dx = k*[h²/2]_0^2 = 0 (for periodic) or k*(h(2)²-h(0)²)/2.

So for small k, the overlap is approximately 1 - ∫h² (independent of k to first order). This suggests that for slowly varying h, all small-k overlaps are approximately equal, and the maximum is set by the larger k values.

For large k (near 2), the overlap region is small, so the integral is small. The maximum is likely at intermediate k values.

This suggests that the optimal h should be chosen to equalize the overlaps at the "peak" shifts.

import numpy as np
from scipy.optimize import minimize
import time


def fft_convolve(a, b):
    na = len(a)
    nb = len(b)
    n = na + nb - 1
    nfft = 1 << (n - 1).bit_length()
    fa = np.fft.rfft(a, nfft)
    fb = np.fft.rfft(b, nfft)
    return np.fft.irfft(fa * fb, nfft)[:n]


def compute_correlations(h):
    g = 1.0 - h
    return fft_convolve(h, g[::-1])


def evaluate_score(h):
    n = len(h)
    dx = 2.0 / n
    corr = compute_correlations(h)
    return float(np.max(corr) * dx)


def project_sum(h, target):
    h = h.copy()
    n = len(h)
    for _ in range(300):
        s = np.sum(h)
        diff = target - s
        if abs(diff) < 1e-15:
            break
        h += diff / n
        np.clip(h, 0.0, 1.0, out=h)
    return h


def smooth_max_and_grad(h, alpha):
    n = len(h)
    g = 1.0 - h
    corrs = fft_convolve(h, g[::-1])
    m = np.max(corrs)
    shifted = alpha * (corrs - m)
    exp_shifted = np.exp(np.clip(shifted, -700, 700))
    sum_exp = np.sum(exp_shifted)
    if sum_exp < 1e-300:
        weights = np.zeros(len(corrs))
        weights[np.argmax(corrs)] = 1.0
    else:
        weights = exp_shifted / sum_exp
    obj = m + np.log(sum_exp) / alpha
    w_rev = weights[::-1]
    conv1 = fft_convolve(g, w_rev)
    conv2 = fft_convolve(h, weights)
    idx = np.arange(n) + n - 1
    grad = conv1[idx] - conv2[idx]
    return obj, grad


def bottleneck_subgrad(h):
    n = len(h)
    corrs = compute_correlations(h)
    k_star = int(np.argmax(corrs))
    r = k_star - (n - 1)
    g = 1.0 - h
    grad = np.zeros(n)
    lo1 = max(0, -r)
    hi1 = min(n, n - r)
    if hi1 > lo1:
        grad[lo1:hi1] += g[lo1 + r:hi1 + r]
    lo2 = max(0, r)
    hi2 = min(n, n + r)
    if hi2 > lo2:
        grad[lo2:hi2] -= h[lo2 - r:hi2 - r]
    return k_star, grad


def subgradient_descent(h, n_iter, base_lr, decay=0.005):
    n = len(h)
    h = h.copy()
    for t in range(n_iter):
        lr = base_lr / (1.0 + decay * t)
        _, grad = bottleneck_subgrad(h)
        h -= lr * grad
        h = project_sum(h, n / 2.0)
    return h


def slsqp_fun_grad(h, alpha):
    return smooth_max_and_grad(h, alpha)


def constraint_eq(h):
    return np.array([np.sum(h) - len(h) / 2.0])


def constraint_eq_jac(h):
    return np.ones((1, len(h)))


def slsqp_optimize(h0, alpha, maxiter, bounds):
    res = minimize(
        slsqp_fun_grad, h0, method='SLSQP', bounds=bounds, args=(alpha,),
        jac=True,
        constraints=[{'type': 'eq', 'fun': constraint_eq, 'jac': constraint_eq_jac}],
        options={'maxiter': maxiter, 'ftol': 1e-15, 'iprint': 0}
    )
    return res.x


def lbfgsb_optimize(h0, alpha, mu, maxiter, bounds):
    def fun_grad(x):
        obj, grad = smooth_max_and_grad(x, alpha)
        viol = np.sum(x) - len(x) / 2.0
        obj += 0.5 * mu * viol * viol
        grad = grad + mu * viol
        return obj, grad

    res = minimize(
        fun_grad, h0, method='L-BFGS-B', bounds=bounds,
        options={'maxiter': maxiter, 'ftol': 1e-18, 'gtol': 1e-14,
                 'iprint': 0, 'maxls': 50, 'maxfun': maxiter * 20}
    )
    return res.x
