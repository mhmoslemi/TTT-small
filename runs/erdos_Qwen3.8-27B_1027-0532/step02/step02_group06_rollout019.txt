The key challenge is efficiently finding min_{t∈[0,1]} F(t) where F(t) = max of O(n) affine functions and one concave quadratic.

A practical approach: 
1. Compute F(0), F(1), and F at a few intermediate points.
2. Use the subgradient to determine the direction of steepest decrease.
3. Do a few iterations of a 1D method.

Or even simpler: since we only have ~849 functions to take the max of, we can:

But this might not be precise enough. Let me think of a better way.

Actually, the minimum of the max of linear functions over an interval occurs at a breakpoint (intersection of two lines) or at a boundary. So if I have m lines, there are at most m-1 breakpoints, and I need to check m+1 points (boundaries + breakpoints) plus any intersection with the parabola.

**Practical approach for find_optimal_t:**

Since the objective is the max of affine functions and a concave quadratic, and we want to minimize it:

1. At the current t_old, compute which lag(s) are "active" (achieve the max).
2. The subgradient at t_old is the set of slopes of the active functions.
3. If the subgradient contains 0, we're at a local minimum.
4. Otherwise, move in the direction of steepest descent (opposite to the subgradient).
5. Do a line search.

Actually, let me just use scipy.optimize.minimize_scalar with method='bounded' and a reasonable number of iterations. For each coordinate, this will take maybe 20-30 evaluations of F, each O(n). So per coordinate: O(n) * 30 = O(30n). Per sweep: O(30n^2). With n=425: 30 * 425^2 ≈ 5.4M per sweep. With 50 sweeps: 270M. That might be too slow in Python.

Let me think of a faster approach.

**Faster approach: Direct computation of the minimum**

For the max of affine functions af(t) = a*t + b (for l≠0) and a concave quadratic q(t) = B_0 + t - t^2:

The minimum of max(af_1, ..., af_m, q) on [0,1] can be found as follows:

Step 1: Find the upper envelope of the affine functions. The minimum of the upper envelope of m lines on [0,1] is at a vertex (intersection of two consecutive lines on the upper envelope) or at a boundary. The upper envelope can be computed in O(m log m) time.

Step 2: Check where the parabola is above the upper envelope. In those regions, F(t) = q(t), which is minimized at the boundaries of that region.

Combining: the minimum is at one of finitely many candidate points.

But implementing the upper envelope algorithm is non-trivial. Let me use a different approach.

**Alternative: Bisection on the optimal value**

We want to find the minimum of F(t) = max(g_1(t), ..., g_m(t), q(t)) on [0,1].

Binary search on the value: for a candidate value v, check if there exists t ∈ [0,1] such that F(t) ≤ v. This is equivalent to checking if the intersection of {t : g_i(t) ≤ v for all i} ∩ {t : q(t) ≤ v} ∩ [0,1] is non-empty.

For each g_i(t) = a_i * t + b_i ≤ v: this gives a half-line constraint on t.
For q(t) = B_0 + t - t^2 ≤ v: this is t^2 - t + (v - B_0) ≥ 0, which means t ≤ r1 or t ≥ r2 (where r1, r2 are roots).

So the feasible set for value v is an intersection of half-lines and a "two-sided" constraint, which is either empty or an interval (or union of two intervals). We can check this in O(m) time.

Then binary search on v gives us the optimal value in O(m log M) time where M is the range of v.

This is O(n log n) per coordinate, and O(n^2 log n) per sweep. With n=425: 425^2 * 9 ≈ 1.6M per sweep. Very fast!

import numpy as np
from scipy.optimize import minimize, minimize_scalar
import time


def compute_correlations(h):
    return np.correlate(h, 1.0 - h, mode='full')


def evaluate_score(h):
    n = len(h)
    dx = 2.0 / n
    corr = compute_correlations(h)
    return np.max(corr) * dx


def project_to_feasible(h, target_sum):
    lo, hi = -2.0, 2.0
    for _ in range(80):
        mid = (lo + hi) / 2.0
        x = np.clip(h - mid, 0.0, 1.0)
        if np.sum(x) > target_sum:
            lo = mid
        else:
            hi = mid
    return np.clip(h - (lo + hi) / 2.0, 0.0, 1.0)


def single_coord_obj(t, h, i):
    old = h[i]
    h[i] = t
    corr = np.correlate(h, 1.0 - h, mode='full')
    val = np.max(corr)
    h[i] = old
    return val


def pair_coord_obj(t_i, h, i, j, sum_ij):
    t_j = sum_ij - t_i
    if t_j < -1e-9 or t_j > 1.0 + 1e-9:
        return 1e10
    old_i = h[i]
    old_j = h[j]
    h[i] = t_i
    h[j] = t_j
    corr = np.correlate(h, 1.0 - h, mode='full')
    val = np.max(corr)
    h[i] = old_i
    h[j] = old_j
    return val


def run_single_cd(h, n, t0, time_limit, seed, full=True):
    rng = np.random.RandomState(seed)
    best_h = h.copy()
    best_score = evaluate_score(h)
    target_sum = n / 2.0
    maxiter = 50 if full else 20
    
    for sweep in range(100000):
        if time.time() - t0 > t0 + time_limit:
            break
        order = rng.permutation(n)
        h_work = best_h.copy()
        for i in order:
            if time.time() - t0 > t0 + time_limit:
                break
            res = minimize_scalar(single_coord_obj, bounds=(0.0, 1.0),
                                  args=(h_work, i), method='bounded',
                                  options={'maxiter': maxiter})
            h_work[i] = res.x
        h_work = project_to_feasible(h_work, target_sum)
        score = evaluate_score(h_work)
        if score < best_score:
            best_score = score
            best_h = h_work.copy()
    return best_h, best_score


def run_pair_cd(h, n, t0, time_limit, seed):
    rng = np.random.RandomState(seed)
    best_h = h.copy()
    best_score = evaluate_score(h)
    
    for sweep in range(100000):
        if time.time() - t0 > t0 + time_limit:
            break
        h_work = best_h.copy()
        n_pairs = n // 2
        for _ in range(n_pairs):
            if time.time() - t0 > t0 + time_limit:
                break
            i = rng.randint(n)
            j = rng.randint(n)
            if i == j:
                continue
            sum_ij = h_work[i] + h_work[j]
            lo = max(0.0, sum_ij - 1.0)
            hi = min(1.0, sum_ij)
            if lo >= hi:

            res = minimize_scalar(pair_coord_obj, bounds=(lo, hi),

                                  options={'maxiter': 40})
            if res.x is not None:

                h_work[i] = res.x
                h_work[j] = t_j
        score = evaluate_score(h_work)
        if score < best_score:
            best_score = score
            best_h = h_work.copy()
    return best_h, best_score


def slsqp_refine(h, alpha, maxiter=200):
    n = len(h)
    target_sum = n / 2.0
    bounds = [(0.0, 1.0)] * n
    
    def obj(hv):
        corr = compute_correlations(hv)
        m = np.max(corr)
        return m + np.log(np.sum(np.exp(alpha * (corr - m)))) / alpha
    
    def constraint_fun(hv):
        return np.sum(hv) - target_sum
    
    def constraint_jac(hv):
        return np.ones(n)
    
    res = minimize(obj, h, method='SLSQP', bounds=bounds,
                   constraints=[{'type': 'eq', 'fun': constraint_fun, 'jac': constraint_jac}],
                   options={'maxiter': maxiter, 'ftol': 1e-18, 'iprint': 0})
    if res.x is not None and np.all(np.isfinite(res.x)):
        return project_to_feasible(np.clip(res.x, 0.0, 1.0), target_sum)
    return None
