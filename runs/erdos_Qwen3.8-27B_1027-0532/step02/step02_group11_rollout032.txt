```python
def smooth_max_val(h, eps, n):
    dx = 2.0 / n
    corr = np.correlate(h, 1 - h, mode="full")
    m = np.max(corr)
    shifted = eps * (corr - m)
    return (m + (1.0 / eps) * np.log(np.sum(np.exp(shifted)))) * dx

def smooth_max_grad(h, eps, n):
    dx = 2.0 / n
    corr = np.correlate(h, 1 - h, mode="full")
    m = np.max(corr)
    shifted = eps * (corr - m)
    exp_s = np.exp(shifted)
    sum_exp = np.sum(exp_s)
    weights = exp_s / sum_exp
    grad = np.zeros(n)
    for k in range(len(weights)):
        w = weights[k]
        if w < 1e-14:
            continue
        l = k - (n - 1)
        # d/dh[j] of corr[k] = (1-h[j-l]) if 0<=j-l<n + (-h[j+l]) if 0<=j+l<n
        # Vectorized:
        jl = np.arange(n) - l
        jp = np.arange(n) + l
        mask_l = (jl >= 0) & (jl < n)
        mask_p = (jp >= 0) & (jp < n)
        grad[mask_l] += w * (1.0 - h[jl[mask_l]])
        grad[mask_p] += w * (-h[jp[mask_p]])
    grad *= dx
    return grad

        return smooth_max_val(x, eps, n)

        return smooth_max_grad(x, eps, n)
```

Wait, I have an issue. The `smooth_max_grad` function has a loop over all correlation values (339 for n=170) and does vectorized operations inside. Each iteration is O(n) with numpy, so total is O(n * 2n) = O(n²) per gradient evaluation. For n=170, that's about 58000 operations per gradient call. SLSQP calls gradient many times, so this could be slow.

Let me optimize the gradient computation. Actually, for the smooth max, the gradient can be computed more efficiently:

grad[j] = dx * sum_k weights[k] * [(1-h[j-l_k]) * 1_{0<=j-l_k<n} + (-h[j+l_k]) * 1_{0<=j+l_k<n}]

This is like a weighted sum of shifted versions of (1-h) and -h. We can compute it using convolution:

Let w[k] = weights[k] for k = 0, ..., 2n-2 (corresponding to shifts l = k-(n-1) = -(n-1), ..., n-1)

Then:
grad[j] = dx * [sum_{k: 0<=j-(k-(n-1))<n} w[k] * (1-h[j-(k-(n-1))]) + sum_{k: 0<=j+(k-(n-1))<n} w[k] * (-h[j+(k-(n-1))])]

The first sum is a convolution of w with (1-h), and the second is a convolution of w with -h (with appropriate sign and shift).

Actually, let me just use the direct formula. For n=170, the loop over 339 values with O(n) numpy operations each gives 339 * 170 ≈ 57630 floating point operations, which is fast.

But wait, I'm using Python loop for the 339 iterations. Each iteration has a few numpy operations on arrays of size 170. The overhead of 339 Python loop iterations with small numpy ops is probably 339 * 1μs = 339μs ≈ 0.3ms per gradient call. SLSQP might call gradient 100-1000 times, so 30-300ms total for one SLSQP call. That's fine.

Let me also think about whether I should try to be smarter about the binary search. One idea: instead of random pair sampling, use a "best-first" approach where we compute the potential improvement for each pair.

For a pair (i, j) where h[i]=1, h[j]=0, the change in correlation is:
δ[l] = -(1-h[i+l]) * 1_{0≤i+l<n} + h[i-l] * 1_{0≤i-l<n} + (1-h[j+l]) * 1_{0≤j+l<n} - h[j-l] * 1_{0≤j-l<n}

The new max is max_l (corr[l] + δ[l]). We want to minimize this.

Computing δ for all pairs (i,j) would be O(n⁴) which is too expensive. But we can precompute some terms.

Actually, let me think of it this way. The change in corr when flipping h[i] from 1 to 0 (alone) is:
δi[l] = -(1-h[i+l]) * 1_{0≤i+l<n} + h[i-l] * 1_{0≤i-l<n}

And flipping h[j] from 0 to 1 (alone) is:
δj[l] = (1-h[j+l]) * 1_{0≤j+l<n} - h[j-l] * 1_{0≤j-l<n}

So the combined change is δ[l] = δi[l] + δj[l].

For each i, δi is a vector of length 2n-1 that's non-zero in at most 2n elements. Similarly for δj.

If I precompute δi for all i (85 of them) and δj for all j (85 of them), that's 170 vectors of length 339. Then for each pair (i,j), the new corr is corr + δi + δj, and I just need to take the max.

Precomputation: O(n * n) = O(n²) = 28900 operations.
Storage: 170 * 339 = 57630 floats.
Per pair evaluation: O(n) to compute max of (corr + δi + δj).
Total for all pairs: O(n² * n) = O(n³) = 4.9M operations.

That's feasible! For n=170, 4.9M operations is nothing for numpy (maybe 5ms).

So the approach would be:
1. Precompute δi for all positions where h[i]=1 (the "cost" of removing a 1)
2. Precompute δj for all positions where h[j]=0 (the "cost" of adding a 1)
3. For each pair (i,j), compute new_max = max(corr + δi + δj)
4. Find the pair that minimizes new_max
5. Apply the best pair
6. Repeat

This is exact best-improvement local search, and it's O(n³) per iteration. For n=170, that's about 5M operations per iteration, or maybe 5ms. We can do about 2000 iterations in 10 seconds. That should converge quickly.

Let me implement this:

```python
def best_improve_ls(h, n, max_rounds, time_fn):
    """Exact best-improvement local search for binary vectors"""
    h = h.copy()
    dx = 2.0 / n
    corr = compute_corr(h)
    curr_max = float(corr.max())
    best_c5 = curr_max * dx
    best_h = h.copy()
    
    ones = np.where(h == 1)[0]
    zeros = np.where(h == 0)[0]
    
    for rnd in range(max_rounds):
        if time_fn():
            break
        
        # Precompute delta for removing each 1
        # delta_remove[i][l] = change in corr[l] when h[i] goes 1->0
        # = -(1-h[i+l]) if 0<=i+l<n, else 0
        #   + h[i-l] if 0<=i-l<n, else 0
        # (where l ranges from -(n-1) to n-1, indexed as l+(n-1) in corr)
        
        n_corr = 2 * n - 1
        delta_remove = np.zeros((len(ones), n_corr))
        for idx, i in enumerate(ones):
            # As first element: h[i] * (1-h[i+l]) for l where 0<=i+l<n
            for l in range(-(n-1), n):
                ip = i + l
                im = i - l
                d = 0.0
                if 0 <= ip < n:
                    d -= (1.0 - h[ip])
                if 0 <= im < n:
                    d += h[im]
                delta_remove[idx, l + (n-1)] = d
        
        # Precompute delta for adding each 0 (h[j] goes 0->1)
        delta_add = np.zeros((len(zeros), n_corr))
        for idx, j in enumerate(zeros):
            for l in range(-(n-1), n):
                jp = j + l
                jm = j - l
                d = 0.0
                if 0 <= jp < n:
                    d += (1.0 - h[jp])
                if 0 <= jm < n:
                    d -= h[jm]
                delta_add[idx, l + (n-1)] = d
        
        # For each pair (i, j), compute new_max = max(corr + delta_remove[i] + delta_add[j])
        best_val = curr_max
        best_ii = -1
        best_jj = -1
        
        for ii in range(len(ones)):
            for jj in range(len(zeros)):
                new_corr = corr + delta_remove[ii] + delta_add[jj]
                nm = float(new_corr.max())
                if nm < best_val - 1e-12:
                    best_val = nm
                    best_ii = ii
                    best_jj = jj
        
        if best_ii < 0:
            break
        
        i = int(ones[best_ii])
        j = int(zeros[best_jj])
        h[i] = 0.0
        h[j] = 1.0
        corr = corr + delta_remove[best_ii] + delta_add[best_jj]
        curr_max = float(corr.max())
```
