**Coordinate Descent for the active set:**

After the main optimization, identify the "active" lags: those where c_k >= c_max - eps (for some small eps like 1e-4 * c_max).

For each active lag k, we have the constraint: c_k(h) <= T where T is the target value.

The Lagrangian subgradient at h is: sum_{k in active} w_k * ∇c_k(h) + λ * 1 (for the sum constraint)

For coordinate descent on h[m]:
- Fix all other h[j], j≠m
- The objective max_k c_k becomes a function of t = h[m]:
  For each active k: c_k(t) = a_k * t + b_k (linear in t, where a_k = ∂c_k/∂h[m] computed with other h's fixed)
- We want to minimize max_k (a_k * t + b_k) subject to 0 ≤ t ≤ 1 and sum constraint
- The sum constraint: if we change h[m] from old to t, we need sum(h) to stay at target. 
  Option: ignore sum constraint in CD and re-project after each step.
  Option: use a 2D move (change h[m] and one other coordinate).

For simplicity, let me use the "ignore and re-project" approach:
- For each m, compute the optimal t that minimizes max_k (a_k * t + b_k) on [0,1]
- Update h[m] = t
- After a full pass, re-project to feasible set

To find the optimal t:
- The function f(t) = max_k (a_k * t + b_k) is convex and piecewise linear
- The minimum is where 0 is in the subdifferential: there exist k1, k2 with a_{k1} < 0 < a_{k2} (or a_k = 0 for all active k)
- More precisely, the minimum is at t* where the "slope" changes from negative to positive
- We can find t* by: among all active k, find the t where the max switches from one line to another
- t* = (b_k1 - b_k2) / (a_k2 - a_k1) for the "upper envelope" intersection

This is a standard "minimize the maximum of linear functions" problem. The solution is:
- Find all intersection points of pairs of lines (a_k * t + b_k) and (a_j * t + b_j)
- The minimum of the upper envelope occurs at one of these intersection points (or at a boundary t=0 or t=1)
- Among all such candidates, pick the one with the smallest max value

For efficiency, if we have m active lags, there are O(m^2) intersection points to check. For m=20-50, that's 400-2500 points, each evaluated in O(m), so O(m^3) total. For m=50, that's 125K operations per coordinate update. With n=850 coordinates, that's ~100M operations per full CD pass. That's a bit much.

Alternative: use bisection on the subgradient. The subgradient of f(t) = max_k (a_k*t + b_k) at t is {a_k : c_k(t) = f(t)} (the set of slopes of the active lines). We want to find t where 0 ∈ ∂f(t), i.e., there exist k1, k2 with a_k1 ≤ 0 ≤ a_k2 and c_k1(t) = c_k2(t) = f(t).

We can use binary search: if all active slopes are positive, f is increasing, so the minimum is at the leftmost point. If all are negative, minimum is at the rightmost. Otherwise, bisect.

Actually, a simpler approach: just evaluate f(t) at a few candidate points (0, 1, and the intersection of the two "most constraining" lines) and pick the best.

For the "most constraining" lines: find k1 = argmin a_k (most negative slope) and k2 = argmax a_k (most positive slope). Their intersection is t_cross = (b_k1 - b_k2)/(a_k2 - a_k1). Check if this is in [0,1] and if c_k1(t_cross) = c_k2(t_cross) = f(t_cross) (i.e., no other line is above at this point). If not, try other pairs.

This is heuristic but should work well in practice.

import numpy as np
from scipy.optimize import minimize
import time

def compute_correlations(h):
    return np.correlate(h, 1.0 - h, mode='full')

def evaluate_score(h):
    n = len(h)
    dx = 2.0 / n
    corr = compute_correlations(h)
    return np.max(corr) * dx

def project_to_feasible(h, target_sum):
    lo, hi = -2.0, 2.0
    for _ in range(60):
        mid = (lo + hi) / 2.0
        x = np.clip(h - mid, 0.0, 1.0)
        if np.sum(x) > target_sum:
            lo = mid
        else:
            hi = mid
    return np.clip(h - (lo + hi) / 2.0, 0.0, 1.0)

def softmax_gradient(h, alpha, top_k=None):
    """Compute softmax-weighted gradient. If top_k is given, only use top k lags."""
    n = len(h)
    corr = compute_correlations(h)
    
    if top_k is not None:
        top_idx = np.argsort(-corr)[:top_k]
        top_vals = corr[top_idx]
        shifted = top_vals - top_vals[0]
        weights = np.exp(alpha * shifted)
        weights /= weights.sum()
        active_idx = top_idx
    else:
        shifted = corr - corr.max()
        weights = np.exp(alpha * shifted)
        weights /= weights.sum()
        active_idx = np.argsort(-weights)
    
    grad = np.zeros(n)
    for i, idx in enumerate(active_idx):
        w = weights[i] if top_k is not None else weights[idx]
        if w < 1e-12:
            continue
        lag = int(idx - (n - 1))
        if lag == 0:
            grad += w * (1.0 - 2.0 * h)
        elif lag > 0:
            grad[lag:] += w * (1.0 - h[:-lag])
            grad[:n-lag] -= w * h[lag:]
        else:
            la = -lag
            grad[:n-la] += w * (1.0 - h[la:])
            grad[la:] -= w * h[:n-la]
    
    return grad, corr

def nesterov_subgradient(h0, alpha_start, alpha_end, max_iters, t0, time_limit, 
                          momentum=0.9, top_k=None, seed=42):
    """Nesterov-accelerated subgradient method with adaptive step size."""
    n = len(h0)
    target_sum = n / 2.0
    h = project_to_feasible(h0.copy(), target_sum)
    v = np.zeros(n)  # momentum velocity
    
    best_score = evaluate_score(h)
    best_h = h.copy()
    rng = np.random.RandomState(seed)
    
    # Step size schedule
    step_init = 2.0 / (n ** 0.5)
    step = step_init
    
    stall_count = 0
    best_stall_score = best_score
    
    for it in range(max_iters):
        if time.time() - t0 > t0 + time_limit:
            break
        
        # Adaptive alpha
        progress = it / max(max_iters, 1)
        alpha = alpha_start * (alpha_end / alpha_start) ** progress
        
        # Nesterov: evaluate gradient at lookahead point
        h_look = h + momentum * v
        h_look = np.clip(h_look, 0.0, 1.0)
        
        grad, corr = softmax_gradient(h_look, alpha, top_k=top_k)
        
        # Update velocity
        v = momentum * v - step * grad
        
        # Tentative update
        h_new = h + v
        h_new = project_to_feasible(h_new, target_sum)
        
        # Backtracking line search
        score_new = evaluate_score(h_new)
        
        if score_new < best_score:
            best_score = score_new
            best_h = h_new.copy()
            stall_count = 0
        elif score_new < best_stall_score:
            best_stall_score = score_new
            stall_count = 0
        else:
            stall_count += 1
        
        h = h_new
        
        # Adaptive step size
        if score_new <= best_score * (1 + 1e-4):
            step = step * 1.02  # slight increase
        else:
            step = step * 0.5
        
        step = min(step, step_init * 2)
        
        # Restart if stalled
        if stall_count > 500:
            h = best_h + rng.randn(n) * 0.05 / np.sqrt(n)
            h = project_to_feasible(h, target_sum)
            v = np.zeros(n)
            step = step_init
            stall_count = 0
            best_stall_score = evaluate_score(h)
    
    return best_h, best_score

def coordinate_descent_polish(h, n_passes=100, eps=1e-5, t0=None, time_limit=None):
    """Coordinate descent polish on the active set."""
    n = len(h)
    target_sum = n / 2.0
    h = project_to_feasible(h.copy(), target_sum)
    
    for p in range(n_passes):
        if t0 is not None and time.time() - t0 > time_limit:
            break
        
        corr = compute_correlations(h)
        c_max = corr.max()
        
        # Find active lags
        active = np.where(corr >= c_max - eps * c_max)[0]
        
        improved = False
        for m in range(n):
            # Compute slopes a_k and offsets b_k for each active lag
            # c_k = a_k * t + b_k where t = h[m]
            a_vals = np.zeros(len(active))
            b_vals = np.zeros(len(active))
            
            for i, idx in enumerate(active):
                lag = int(idx - (n - 1))
                # dc_lag/dh[m] and c_lag - (dc_lag/dh[m]) * h[m]
                if lag == 0:
                    a = 1.0 - 2.0 * h[m]
                elif lag > 0:
                    a = 0.0
                    if m >= lag:
                        a += (1.0 - h[m - lag])
                    if m + lag < n:
                        a -= h[m + lag]
                else:
                    la = -lag
                    a = 0.0
                    if m < n - la:
                        a += (1.0 - h[m + la])
                    if m - la >= 0:
                        a -= h[m - la]
                
                a_vals[i] = a
                b_vals[i] = corr[idx] - a * h[m]
            
            # Minimize max_i (a_i * t + b_i) over t in [0, 1]
            # Candidate points: 0, 1, and intersections
            candidates = [0.0, 1.0]
            
            # Find intersection of the two "extreme" lines
            min_a_idx = np.argmin(a_vals)
            max_a_idx = np.argmax(a_vals)
            if a_vals[max_a_idx] - a_vals[min_a_idx] > 1e-10:
                t_cross = (b_vals[min_a_idx] - b_vals[max_a_idx]) / (a_vals[max_a_idx] - a_vals[min_a_idx])
                if 0 <= t_cross <= 1:
                    candidates.append(t_cross)
            
            # Also try intersections with the current max line
            max_c_idx = np.argmax(a_vals * h[m] + b_vals)
            for i in range(len(active)):
                if i == max_c_idx:
                    continue
                if abs(a_vals[i] - a_vals[max_c_idx]) > 1e-10:
                    t_cross = (b_vals[max_c_idx] - b_vals[i]) / (a_vals[i] - a_vals[max_c_idx])
                    if 0 <= t_cross <= 1:
                        candidates.append(t_cross)
            
            # Evaluate at all candidates
            best_t = h[m]
            best_val = np.max(a_vals * h[m] + b_vals)
            for t_c in candidates:
                val = np.max(a_vals * t_c + b_vals)
                if val < best_val:
                    best_val = val
                    best_t = t_c
            
            if abs(best_t - h[m]) > 1e-8:
                h[m] = best_t
                improved = True
        
        # Re-project after full pass
        h = project_to_feasible(h, target_sum)
        
        if not improved:
            break
    
    return h

            grad[lag:] += w * (1.0 - h[:-lag])
            grad[:n - lag] -= w * h[lag:]
        else:
            la = -lag
            grad[:n - la] += w * (1.0 - h[la:])
            grad[la:] -= w * h[:n - la]
    return grad, corr


def nesterov_optimize(h0, alpha_start, alpha_end, max_iters, t0, time_limit, momentum, seed):
    n = len(h0)
    target_sum = n / 2.0
    h = project_to_feasible(h0.copy(), target_sum)
    v = np.zeros(n)
    best_score = evaluate_score(h)
    best_h = h.copy()
    rng = np.random.RandomState(seed)
    step = 2.0 / np.sqrt(n)
    step_max = 4.0 / np.sqrt(n)
    step_min = step * 0.01
    stall = 0
    for it in range(max_iters):
        if time.time() - t0 > t0 + time_limit:
            break
        progress = min(it / max(max_iters, 1), 1.0)
        alpha = alpha_start * (alpha_end / alpha_start) ** progress
        h_look = h + momentum * v
        h_look = np.clip(h_look, 0.0, 1.0)
        grad, corr = softmax_gradient_full(h_look, alpha)
        v = momentum * v - step * grad
        h_new = h + v
        h_new = project_to_feasible(h_new, target_sum)
        score = evaluate_score(h_new)
        if score < best_score:
            best_score = score
            best_h = h_new.copy()
            stall = 0
        else:
            stall += 1
        h = h_new
        if stall == 0:
            step = min(step * 1.03, step_max)
        elif stall > 200:
            step = max(step * 0.6, step_min)
        else:
            step = max(step * 0.97, step_min)
        if stall > 1000:
            noise_mag = 0.02 + 0.05 * min(stall / 2000.0, 1.0)
            h = best_h + rng.randn(n) * noise_mag / np.sqrt(n)
            h = project_to_feasible(h, target_sum)
            v = np.zeros(n)
            step = 2.0 / np.sqrt(n)
            stall = 0
    return best_h, best_score


def cd_polish(h, max_passes, eps_rel, t0, time_limit):
    n = len(h)
    target_sum = n / 2.0
    h = project_to_feasible(h.copy(), target_sum)
    for p in range(max_passes):
        if time.time() - t0 > time_limit:
            break
        corr = compute_correlations(h)
        c_max = corr.max()
        if c_max < 1e-12:
            break
        active = np.where(corr >= c_max - eps_rel * c_max)[0]
        na = len(active)
        any_improved = False
        lags_active = (active - (n - 1)).astype(int)
        for m in range(n):
            a_vals = np.zeros(na)
            b_vals = np.zeros(na)
            for i in range(na):
                lag = lags_active[i]
                if lag == 0:
                    a = 1.0 - 2.0 * h[m]
                elif lag > 0:
                    a = 0.0
                    if m >= lag:
                        a += (1.0 - h[m - lag])
                    if m + lag < n:
                        a -= h[m + lag]
                else:
                    la = -lag
                    a = 0.0
                    if m < n - la:
                        a += (1.0 - h[m + la])
                    if m >= la:
                        a -= h[m - la]
                a_vals[i] = a
                b_vals[i] = corr[active[i]] - a * h[m]
            cur_val = np.max(a_vals * h[m] + b_vals)
            best_t = h[m]
            best_val = cur_val
            v0 = np.max(b_vals)
            if v0 < best_val - 1e-12:
                best_val = v0
                best_t = 0.0
            v1 = np.max(a_vals + b_vals)
            if v1 < best_val - 1e-12:
                best_val = v1
                best_t = 1.0
            imin = np.argmin(a_vals)
            imax = np.argmax(a_vals)
            da = a_vals[imax] - a_vals[imin]
            if abs(da) > 1e-12:
                tc = (b_vals[imin] - b_vals[imax]) / da
                if 0.0 < tc < 1.0:
                    vc = np.max(a_vals * tc + b_vals)
                    if vc < best_val - 1e-12:
                        best_val = vc
                        best_t = tc
            imax2 = np.argmax(a_vals * h[m] + b_vals)
            for i in range(na):
                if i == imax2:
                    continue
                da2 = a_vals[i] - a_vals[imax2]
                if abs(da2) > 1e-12:
                    tc2 = (b_vals[imax2] - b_vals[i]) / da2
                    if 0.0 < tc2 < 1.0:
                        vc2 = np.max(a_vals * tc2 + b_vals)
                        if vc2 < best_val - 1e-12:
                            best_val = vc2
                            best_t = tc2
            if abs(best_t - h[m]) > 1e-10:
                h[m] = best_t
                any_improved = True
        h = project_to_feasible(h, target_sum)
        if not any_improved:
            break
    return h


def slsqp_smoothed(h, alpha, maxiter):
    n = len(h)
    target_sum = n / 2.0

    def obj(hv):
        corr = compute_correlations(hv)
        m = np.max(corr)
        return m + np.log(np.sum(np.exp(alpha * (corr - m)))) / alpha

    def con_fun(hv):
        return np.sum(hv) - target_sum

    def con_jac(hv):
        return np.ones(n)

    bounds = [(0.0, 1.0)] * n
    res = minimize(obj, h, method='SLSQP', bounds=bounds,
                   constraints=[{'type': 'eq', 'fun': con_fun, 'jac': con_jac}],
                   options={'maxiter': maxiter, 'ftol': 1e-14, 'iprint': 0})
    if res.x is not None and np.all(np.isfinite(res.x)):
        return project_to_feasible(np.clip(res.x, 0.0, 1.0), target_sum)
    return None


def upscale_h(h_old, n_old, n_new):
    x_old = np.linspace(0.0, 2.0, n_old, endpoint=False)
    x_new = np.linspace(0.0, 2.0, n_new, endpoint=False)
    h_new = np.interp(x_new, x_old, h_old)
    return project_to_feasible(h_new, n_new / 2.0)


def run(seed=42, budget_s=1300, **kwargs):
    t0 = time.time()

    def remaining():
        return budget_s - (time.time() - t0)

    init = np.array(initial_h_values, dtype=float)
    n_init = len(init)
    init = project_to_feasible(init, n_init / 2.0)

    best_h = init.copy()
    best_score = evaluate_score(init)
    best_n = n_init
    rng = np.random.RandomState(seed)

    phase1_configs = [
        (5.0, 50.0, 0.95),
        (5.0, 100.0, 0.90),
        (10.0, 200.0, 0.85),
        (3.0, 30.0, 0.97),
        (20.0, 500.0, 0.80),
        (50.0, 1000.0, 0.70),
    ]

    for i, (a_s, a_e, mom) in enumerate(phase1_configs):
        if remaining() < budget_s * 0.25:
            break
        t_allow = min(budget_s * 0.10, remaining() * 0.5)
        if t_allow < 15:
            break
        h_new, score_new = nesterov_optimize(best_h, a_s, a_e, 100000, t0, t_allow, mom, seed + i * 137)
        if score_new < best_score:
            best_score = score_new
            best_h = h_new.copy()

    if remaining() > budget_s * 0.10:
        t_allow = min(remaining() * 0.12, 120)
        h_cd = cd_polish(best_h, 300, 1e-3, t0, t0 + t_allow)
        sc = evaluate_score(h_cd)
        if sc < best_score:
            best_score = sc
            best_h = h_cd.copy()

    upscale_targets = [2, 3]
    for factor in upscale_targets:
        if remaining() < budget_s * 0.10:
            break
        n_new = best_n * factor
        if n_new > 2500:
            continue
        h_up = upscale_h(best_h, best_n, n_new)
        t_allow = min(remaining() * 0.18, 180)
        if t_allow < 10:
            break
        h_new, score_new = nesterov_optimize(h_up, 10.0, 100.0, 100000, t0, t_allow, 0.9, seed + 3000 + factor * 100)
        if score_new < best_score:
            best_score = score_new
            best_h = h_new.copy()
            best_n = n_new
            if remaining() > budget_s * 0.06:
                t_cd = min(remaining() * 0.10, 100)
                h_cd = cd_polish(best_h, 200, 1e-3, t0, t0 + t_cd)
                sc = evaluate_score(h_cd)
                if sc < best_score:
                    best_score = sc
                    best_h = h_cd.copy()
        if remaining() < budget_s * 0.08:
            break
        n_new2 = best_n * 2 if best_n * 2 <= 2500 else best_n * 3
        if n_new2 > best_n:
            h_up2 = upscale_h(best_h, best_n, n_new2)
            t_allow2 = min(remaining() * 0.15, 150)
            if t_allow2 < 10:
                break
            h_new2, score_new2 = nesterov_optimize(h_up2, 10.0, 100.0, 100000, t0, t_allow2, 0.9, seed + 5000 + n_new2)
            if score_new2 < best_score:
                best_score = score_new2
                best_h = h_new2.copy()
                best_n = n_new2

    if remaining() > 40:
        for alpha in [50, 200, 500]:
            if remaining() < 15:
                break
            h_ref = slsqp_smoothed(best_h, alpha, maxiter=80)
            if h_ref is not None:
                sc = evaluate_score(h_ref)
                if sc < best_score:
                    best_score = sc
                    best_h = h_ref.copy()

    n_restarts = 3
    for r in range(n_restarts):
        if remaining() < budget_s * 0.05:
            break
        noise_mag = [0.03, 0.06, 0.015][r]
        h_pert = best_h + rng.randn(best_n) * noise_mag / np.sqrt(best_n)
        h_pert = project_to_feasible(h_pert, best_n / 2.0)
        t_allow = min(remaining() * 0.20, 120)
        if t_allow < 10:
            break
        a_s = [5.0, 10.0, 20.0][r]
        a_e = [80.0, 200.0, 500.0][r]
        mom = [0.9, 0.85, 0.75][r]
        h_new, score_new = nesterov_optimize(h_pert, a_s, a_e, 50000, t0, t_allow, mom, seed + 7000 + r * 100)
        if score_new < best_score:
            best_score = score_new
            best_h = h_new.copy()
            if remaining() > 20:
                t_cd = min(remaining() * 0.08, 60)
                h_cd = cd_polish(best_h, 100, 1e-3, t0, t0 + t_cd)
                sc = evaluate_score(h_cd)
                if sc < best_score:
                    best_score = sc
                    best_h = h_cd.copy()

    if remaining() > 30:
        t_allow = remaining() - 15
        h_new, score_new = nesterov_optimize(best_h, 200.0, 1000.0, 50000, t0, t_allow, 0.5, seed + 9999)
        if score_new < best_score:
            best_score = score_new
            best_h = h_new.copy()

    if remaining() > 15:
        t_cd = remaining() - 5
        h_cd = cd_polish(best_h, 500, 5e-4, t0, t0 + t_cd)
        sc = evaluate_score(h_cd)
        if sc < best_score:
            best_score = sc
            best_h = h_cd.copy()

    best_h = project_to_feasible(best_h, len(best_h) / 2.0)
    best_score = evaluate_score(best_h)
    return (best_h, best_score, len(best_h))
