When we swap h[i] (1→0) and h[j] (0→1), the change in corr at lag l is:
delta_corr[l] = -[1-h[i-l]] * [valid] - [h[i+l]] * [valid] + [1-h[j-l]] * [valid] + [h[j+l]] * [valid]

Wait, I need to be careful. Let me use the formula:
C(l) = sum_{valid n} h[n] * (1-h[n-l])

After swapping h[i]↔h[j] (where h[i]=1, h[j]=0):
h'[i] = 0, h'[j] = 1

Delta C(l) = C'(l) - C(l)

C'(l) = sum_{valid n} h'[n] * (1-h'[n-l])

The only terms that change are those involving h[i] or h[j]:
- Term where n=i: was h[i]*(1-h[i-l]) = 1*(1-h[i-l]), now 0*(1-h'[i-l]).
  If i-l == j: h'[i-l] = h'[j] = 1, so new term = 0. Delta = -(1-h[i-l]) = -(1-1) = 0.
  If i-l != j: h'[i-l] = h[i-l], so new term = 0. Delta = -(1-h[i-l]).
  
- Term where n-l=i, i.e., n=i+l: was h[i+l]*(1-h[i]) = h[i+l]*0 = 0, now h'[i+l]*(1-h'[i]) = h'[i+l]*1.
  If i+l == j: h'[i+l] = h'[j] = 1. New term = 1. Delta = +1.
  If i+l != j: h'[i+l] = h[i+l]. New term = h[i+l]. Delta = +h[i+l].

- Term where n=j: was h[j]*(1-h[j-l]) = 0, now 1*(1-h'[j-l]).
  If j-l == i: h'[j-l] = h'[i] = 0. New term = 1. Delta = +1.
  If j-l != i: h'[j-l] = h[j-l]. New term = 1-h[j-l]. Delta = 1-h[j-l].

- Term where n-l=j, i.e., n=j+l: was h[j+l]*(1-h[j]) = h[j+l]*1 = h[j+l], now h'[j+l]*(1-h'[j]) = h'[j+l]*0 = 0.
  If j+l == i: h'[j+l] = h'[i] = 0. New term = 0. Delta = -h[j+l] = -0 = 0.
  If j+l != i: h'[j+l] = h[j+l]. New term = 0. Delta = -h[j+l].

So the total delta at lag l:
delta_C(l) = -(1-h[i-l])*[i≠j+l and i-l valid] + h[i+l]*[i+l≠j and valid] + (1-h[j-l])*[j-l≠i and valid] - h[j+l]*[j+l≠i and valid]

def delta_corr_swap(h, n, i, j):
