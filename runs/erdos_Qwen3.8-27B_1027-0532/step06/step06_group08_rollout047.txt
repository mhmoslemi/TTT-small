Let me also think about a fundamentally different approach: **Coordinate descent in the ±1 space**.

In the ±1 space (s[i] = 2h[i]-1), the objective at shift k is:
f_k = (1/4)(N_k - R_k) where R_k = sum_{valid} s[i]*s[i+k]

Minimizing max_k f_k is equivalent to: for the "worst" shift k*, maximize R_{k*} (since N_{k*} is fixed).

A coordinate descent step: flip s[i] (change sign). The change in R_k for all k:
Delta R_k = -2*s[i] * (sum of s[i+k] - s[i-k] over valid positions) ... 

Actually, flipping s[i] from +1 to -1 (or vice versa) changes R_k by:
- For shift k>0: R_k includes s[i]*s[i+k] (if valid) and s[i-k]*s[i] (if valid)
  After flip: (-s[i])*s[i+k] and s[i-k]*(-s[i])
  Change: -2*s[i]*s[i+k] - 2*s[i]*s[i-k] (if respective terms are valid)
  
  Wait, R_k = sum_{i=0}^{n-1-k} s[i]*s[i+k]
  Flipping s[i] affects:
  - The term s[i]*s[i+k] in R_k (if i+k < n): change = -2*s[i]*s[i+k]
  - The term s[i-k]*s[i] in R_k (if i-k >= 0): change = -2*s[i-k]*s[i]
  - The term s[i]*s[i-k] in R_{-k}... no, R is defined for k>0 only (or |k|).
  
  Actually for the full correlation, we have shifts from -(n-1) to n-1. Let me define:
  C(k) = sum_{valid i} s[i]*s[i+k] for k from -(n-1) to n-1.
  
  Flipping s[i]:
  C(k) changes by: -2*s[i]*s[i+k] (if i+k valid) + ... wait:
  C(k) = sum_i s[i]*s[i+k]
  After flip s[i] -> -s[i]:
  C_new(k) = C(k) - s[i]*s[i+k] + (-s[i])*s[i+k] = C(k) - 2*s[i]*s[i+k] (if i+k valid)
  But also, C(k) has a term s[i-k]*s[i] (from i' = i-k in the sum):
  C_new(k) = C(k) - s[i]*s[i+k] + (-s[i])*s[i+k] - s[i-k]*s[i] + s[i-k]*(-s[i])
  Wait no, each term s[i']*s[i'+k] only involves s[i] if i'=i or i'+k=i.
  - If i'=i: term is s[i]*s[i+k], changes to -s[i]*s[i+k], delta = -2*s[i]*s[i+k]
  - If i'+k=i (i'=i-k): term is s[i-k]*s[i], changes to s[i-k]*(-s[i]), delta = -2*s[i-k]*s[i]
  
  So Delta C(k) = -2*s[i]*s[i+k]*valid(i+k) - 2*s[i-k]*s[i]*valid(i-k)
                 = -2*s[i] * (s[i+k]*valid(i+k) + s[i-k]*valid(i-k))

This is a clean formula! And the objective to minimize is max_k (N_k - C(k)) where N_k = n-|k|.

So if we're focusing on the worst shift k*, we want to maximize C(k*) (since N_{k*} is fixed).
Delta C(k*) = -2*s[i] * (s[i+k*]*valid + s[i-k*]*valid)

To increase C(k*), we should flip s[i] where -s[i]*(s[i+k*]+s[i-k*]) > 0, i.e., where s[i] has the opposite sign to (s[i+k*]+s[i-k*]).

But we also need to keep the sum of s = 0 (for the constraint sum h = n/2). Flipping one s[i] changes the sum by -2*s[i]. To maintain the constraint, we need to flip another s[j] with the same sign.

This gives us a **paired flip** strategy:
- Pick the worst shift k*
- Find pairs (i,j) where flipping both increases C(k*) and maintains the sum constraint
- The pair must have s[i] = s[j] (same sign) so that flipping both keeps the sum unchanged

This is essentially what the binary SA does, but with a more principled move selection.

Let me implement this as a **coordinate descent with pair flips**:

```
while not converged:
    k* = argmax_k (N_k - C(k))  # worst shift
    For each i with s[i] = +1:
        score_i = s[i+k*] + s[i-k*]  (with valid checks)
    For each j with s[j] = -1:

    # We want to flip i (from +1 to -1) and j (from -1 to +1)
    # Delta C(k*) for flipping i: -2*1*(s[i+k*]+s[i-k*]) = -2*score_i
    # Delta C(k*) for flipping j: -2*(-1)*(s[j+k*]+s[j-k*]) = 2*score_j
    # Total delta: 2*(score_j - score_i)
    # We want this to be positive, so score_j > score_i
    # Best move: maximize (score_j - score_i) = pick i with smallest score_i and j with largest score_j
```

```python
import numpy as np
```

```python
def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr)) * dx

def project_box_sum(y, target_sum):
    n = len(y)
    y = np.clip(y, 0.0, 1.0).astype(float)
    diff = target_sum - y.sum()
    if abs(diff) < 1e-12:
        return y
    if diff < 0:
        order = np.argsort(y)[::-1]
        remaining = -diff
        for idx in order:
            if remaining <= 1e-12:
                break
            can_reduce = y[idx]
            if can_reduce > remaining:
                y[idx] -= remaining
                remaining = 0.0
            else:
                remaining -= can_reduce
                y[idx] = 0.0
    else:
        order = np.argsort(y)
        remaining = diff
        for idx in order:
            if remaining <= 1e-12:
                break
            can_inc = 1.0 - y[idx]
            if can_inc > remaining:
                y[idx] += remaining
                remaining = 0.0
            else:
                remaining -= can_inc
                y[idx] = 1.0
    return y

def project_binary(h, target_sum):
    n = len(h)
    h_r = np.round(h)
    h_r = np.clip(h_r, 0, 1).astype(int)
    current_sum = int(h_r.sum())
    if current_sum == target_sum:
        return h_r.astype(float)
    ones = np.where(h_r == 1)[0]
    zeros = np.where(h_r == 0)[0]
    if current_sum > target_sum:
        need = current_sum - target_sum
        if need <= len(ones):
            order = np.argsort(h[ones])[:need]
            h_r[ones[order]] = 0
    else:
        need = target_sum - current_sum
        if need <= len(zeros):
            order = np.argsort(-h[zeros])[:need]
            h_r[zeros[order]] = 1
    return h_r.astype(float)

def compute_delta(h, i, j):
    n = len(h)
    result = np.zeros(2 * n - 1)
    k = np.arange(2 * n - 1) - (n - 1)
    idx = i + k
    mask = (idx >= 0) & (idx < n)
    result[mask] -= (1.0 - h[idx[mask]])
    idx = j + k
    mask = (idx >= 0) & (idx < n)
    result[mask] += (1.0 - h[idx[mask]])
    idx = i - k
    mask = (idx >= 0) & (idx < n)
    result[mask] += h[idx[mask]]
    idx = j - k
    mask = (idx >= 0) & (idx < n)
    result[mask] -= h[idx[mask]]
    s_val = j - i
    if s_val != 0 and 0 <= n - 1 + s_val < 2 * n - 1:
        result[n - 1 + s_val] += 1.0
    s_val = i - j
    if s_val != 0 and 0 <= n - 1 + s_val < 2 * n - 1:
        result[n - 1 + s_val] += 1.0
    result[n - 1] = 0.0
    return result

def continuous_momentum(h_start, time_limit, start_time, lr_init=0.04, lr_end=0.001, topk=8):
    n = len(h_start)
    dx = 2.0 / n
    h = h_start.copy().astype(float)
    target = n / 2.0
    corr = np.correlate(h, 1.0 - h, mode='full')
    best_h = h.copy()
    best_c5 = float(corr.max()) * dx
    shifts = np.arange(2 * n - 1) - (n - 1)
    momentum = np.zeros(n)
    beta = 0.9
    stall = 0
    max_stall = 6000
    elapsed_start = time.time()
    n_iters = int(max(1000, (time_limit - (elapsed_start - start_time)) * 25000))

    for it in range(n_iters):
        if time.time() - start_time > time_limit:
            break
        if stall > max_stall:
            break

        ratio = float(it) / max(n_iters, 1)
        lr = lr_init * (lr_end / lr_init) ** ratio
        topk_idx = np.argsort(corr)[-topk:]
        grad = np.zeros(n)
        for k in topk_idx:
            s = int(shifts[k])
            if s >= 0:
                grad[:n - s] += (1.0 - h[s:])
                grad[s:] += (-h[:n - s])
            else:
                abs_s = -s
                grad[abs_s:] += (1.0 - h[:n - abs_s])
                grad[:n - abs_s] += (-h[abs_s:])
        grad /= topk
        momentum = beta * momentum + (1 - beta) * grad
        h = h - lr * momentum
        h = project_box_sum(h, target)
        corr = np.correlate(h, 1.0 - h, mode='full')
        curr_c5 = float(corr.max()) * dx
        if curr_c5 < best_c5 - 1e-12:
            best_c5 = curr_c5
            best_h = h.copy()
            stall = 0
        else:
            stall += 1

    return best_h, best_c5

def continuous_softmax(h_start, time_limit, start_time, alphas=None):
    n = len(h_start)
    dx = 2.0 / n
    h = h_start.copy().astype(float)
    target = n / 2.0

    best_h = h.copy()

    shifts = np.arange(2 * n - 1) - (n - 1)

    for alpha in alphas:
        if time.time() - start_time > time_limit:
            break
        h_cur = h.copy()
        n_sub = int(max(500, (time_limit - (time.time() - start_time)) * 3000 / len(alphas)))
        lr_decay = 0.999
        lr = 0.02
        stall = 0

        for it in range(n_sub):
            if time.time() - start_time > time_limit:
                break
            if stall > 3000:
                break
            max_corr = float(corr.max())
            shifted = alpha * (corr - max_corr)
            shifted = np.clip(shifted, -300.0, 0.0)
            exp_w = np.exp(shifted)
            W = exp_w / exp_w.sum()

            grad = np.zeros(n)
            active_shifts = np.where(W > 1e-6)[0]
            for k in active_shifts:
                wk = W[k]
                s = int(shifts[k])
                if s >= 0:
                    grad[:n - s] -= wk * h[s:]
                    grad[s:] -= wk * h[:n - s]
                else:
                    abs_s = -s
                    grad[abs_s:] -= wk * h[:n - abs_s]
                    grad[:n - abs_s] -= wk * h[abs_s:]

            h_cur = h_cur - lr * grad
            h_cur = project_box_sum(h_cur, target)
            corr = np.correlate(h_cur, 1.0 - h_cur, mode='full')
            curr_c5 = float(corr.max()) * dx
            if curr_c5 < best_c5 - 1e-12:
                best_c5 = curr_c5
                best_h = h_cur.copy()
                stall = 0
            else:
                stall += 1
            lr *= lr_decay

        if float(corr.max()) * dx < best_c5 + 0.01:
            h = h_cur

    return best_h, best_c5

def slsqp_polish(h_start, n, target, alphas, maxiter, time_limit, start_time):
    bounds = [(0.0, 1.0)] * n

    def smooth_obj(x, alpha):
        corr = np.correlate(x, 1.0 - x, mode='full')
        c_max = float(np.max(corr))
        shifted = np.clip(alpha * (corr - c_max), -300.0, 0.0)
        return c_max + float(np.log(np.sum(np.exp(shifted)))) / alpha

    def cons_fun(x):
        return np.sum(x) - target

    def cons_jac(x):
        return np.ones(n)

    cons = [{'type': 'eq', 'fun': cons_fun, 'jac': cons_jac}]
    h_cur = h_start.copy()
    curr_score = compute_c5(h_cur)

    for alpha in alphas:
        if time.time() - start_time > time_limit:
            break
        try:
            res = minimize(lambda x: smooth_obj(x, alpha), h_cur,
                           method='SLSQP', bounds=bounds, constraints=cons,
                           options={'maxiter': maxiter, 'ftol': 1e-14})
            h_new = project_box_sum(res.x, target)
            sc = compute_c5(h_new)
            if sc < curr_score:
                curr_score = sc
                h_cur = h_new
        except Exception:
            pass
    return h_cur, curr_score

def interpolate_to(h_src, n_dst):
    n_src = len(h_src)
    if n_src == n_dst:
        return h_src.copy()
    x_new = np.linspace(0.0, 1.0, n_dst)
    x_old = np.linspace(0.0, 1.0, n_src)
    return np.interp(x_new, x_old, h_src)

    def tleft():
        return budget_s - 12.0 - (time.time() - start_time)

    h_init = np.array(initial_h_values, dtype=float)
    n_init = len(h_init)
    target_init = float(n_init) / 2.0

    best_h_bin = project_binary(h_init, int(n_init / 2.0))
    best_score_bin = compute_c5(best_h_bin)
    best_h_cont = project_box_sum(h_init, target_init)
    best_score_cont = compute_c5(best_h_cont)

    overall_best_h = best_h_cont.copy()
    overall_best_score = min(best_score_bin, best_score_cont)

    # Phase 1: Quick greedy on binary
    allowed = min(40.0, tleft() * 0.06)
    if allowed > 10:
        h_g, c5_g = greedy_binary(best_h_bin, rng, allowed, start_time)
        if c5_g < best_score_bin:
            best_score_bin = c5_g
            best_h_bin = h_g.copy()
    overall_best_score = min(overall_best_score, best_score_bin, best_score_cont)

    # Phase 2: SA on binary (main workhorse)
    allowed = min(180.0, tleft() * 0.22)
    if allowed > 30:
        h_sa, c5_sa = sa_binary(best_h_bin, rng, 0.015, 0.00003, allowed, start_time)
        if c5_sa < best_score_bin:
            best_score_bin = c5_sa
            best_h_bin = h_sa.copy()
    overall_best_score = min(overall_best_score, best_score_bin, best_score_cont)

    # Phase 3: Continuous momentum optimization
    allowed = min(120.0, tleft() * 0.15)
    if allowed > 20:
        h_mom, c5_mom = continuous_momentum(best_h_bin, allowed, start_time,
                                            lr_init=0.05, lr_end=0.0005, topk=6)
        if c5_mom < best_score_cont:
            best_score_cont = c5_mom
            best_h_cont = h_mom.copy()
    overall_best_score = min(overall_best_score, best_score_bin, best_score_cont)

    # Phase 4: Continuous softmax
    allowed = min(100.0, tleft() * 0.12)
    if allowed > 20:
        h_sm, c5_sm = continuous_softmax(best_h_cont, allowed, start_time,
                                          alphas=[40.0, 120.0, 400.0])
        if c5_sm < best_score_cont:
            best_score_cont = c5_sm
            best_h_cont = h_sm.copy()
    overall_best_score = min(overall_best_score, best_score_cont)

    # Phase 5: SLSQP polish
    allowed = min(tleft() - 30, 80.0)
    if allowed > 20:
        h_ref, sc_ref = slsqp_polish(best_h_cont, n_init, target_init,
                                      alphas=[100, 500, 2000], maxiter=2000,
                                      time_limit=allowed, start_time=start_time)
        if sc_ref < best_score_cont:
            best_score_cont = sc_ref
            best_h_cont = h_ref.copy()
    overall_best_score = min(overall_best_score, best_score_cont)

    # Phase 6: Iterative refinement loop
    for iteration in range(8):
        if tleft() < 70:
            break

        # 6a: Perturb and SA
        allowed = min(30.0, tleft() * 0.08)
        if allowed > 15:
            h_pert = block_perturb(best_h_bin, rng.randint(3, 8), rng)
            h_sa2, c5_sa2 = sa_binary(h_pert, rng, 0.008, 0.00002, allowed, start_time,
                                       max_stall=40000)
            if c5_sa2 < best_score_bin:
                best_score_bin = c5_sa2
                best_h_bin = h_sa2.copy()
        overall_best_score = min(overall_best_score, best_score_bin)

        if tleft() < 50:
            break

        # 6b: Continuous from best binary
        allowed = min(40.0, tleft() * 0.1)
        if allowed > 15:
            h_mom2, c5_mom2 = continuous_momentum(best_h_bin, allowed, start_time,
                                                   lr_init=0.03, lr_end=0.0003, topk=4)
            if c5_mom2 < best_score_cont:
                best_score_cont = c5_mom2
                best_h_cont = h_mom2.copy()
        overall_best_score = min(overall_best_score, best_score_cont)

        if tleft() < 40:
            break

        # 6c: Quick SLSQP
        allowed = min(25.0, tleft() * 0.07)
        if allowed > 10:
            h_ref2, sc_ref2 = slsqp_polish(best_h_cont, n_init, target_init,
                                            alphas=[300, 1000], maxiter=1500,
                                            time_limit=allowed, start_time=start_time)
            if sc_ref2 < best_score_cont:
                best_score_cont = sc_ref2
                best_h_cont = h_ref2.copy()
        overall_best_score = min(overall_best_score, best_score_cont)

    # Phase 7: Try nearby resolutions
    for dn in [4, -4, 8, -8, 12, -12, 16, -16]:
        if tleft() < 60:
            break
        n_try = n_init + dn
        if n_try < 200 or n_try % 2 != 0:
            continue
        target_try = float(n_try) / 2.0
        h_interp = interpolate_to(best_h_cont, n_try)
        h_interp = project_box_sum(h_interp, target_try)
        h_bin_try = project_binary(h_interp, n_try // 2)

        allowed_g = min(15.0, tleft() * 0.05)
        if allowed_g < 8:
            continue
        h_g2, c5_g2 = greedy_binary(h_bin_try, rng, allowed_g, start_time,
                                     max_top=50, max_rand=20)

        allowed_c = min(30.0, tleft() * 0.08)
        if allowed_c < 10:
            continue
        h_c2, c5_c2 = continuous_momentum(h_g2, allowed_c, start_time,
                                           lr_init=0.04, lr_end=0.0005, topk=5)
        if c5_c2 < overall_best_score:
            overall_best_score = c5_c2
            overall_best_h = h_c2.copy()
            best_score_cont = c5_c2
            best_h_cont = h_c2.copy()

    # Phase 8: Final burst
    if tleft() > 25:
        n_use = len(best_h_cont)
        h_final_try, sc_final = continuous_momentum(best_h_cont,
                                                     max(5.0, tleft() - 8), start_time,
                                                     lr_init=0.02, lr_end=0.0001, topk=3)
        if sc_final < overall_best_score:
            overall_best_score = sc_final
            overall_best_h = h_final_try.copy()

    # Choose best
    n_final = len(overall_best_h)
    target_final = float(n_final) / 2.0
    h_final = project_box_sum(overall_best_h, target_final)
    final_score = compute_c5(h_final)

    h_bin_final = project_binary(best_h_bin, n_init // 2)
    bin_final_score = compute_c5(h_bin_final)

    if bin_final_score < final_score:
        return h_bin_final, bin_final_score, n_init
    return h_final, final_score, n_final
```
