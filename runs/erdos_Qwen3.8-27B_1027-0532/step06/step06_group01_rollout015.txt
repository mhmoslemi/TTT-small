The minimax problem can be written as a game:
- Player 1 chooses h (minimizing player)
- Player 2 chooses k (maximizing player, a probability distribution over shifts)

The value of the game is what we want to minimize.

By the minimax theorem (for the relaxed version where k is a probability distribution):

We can use a multiplicative weights / mirror descent approach:
- Update h using gradient descent (or mirror descent) on f(h, λ_current)
- Update λ using multiplicative weights on the corr_k values
