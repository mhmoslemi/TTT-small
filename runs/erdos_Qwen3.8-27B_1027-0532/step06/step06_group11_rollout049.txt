- Schedule: decrease temperature over time

This is a kind of "simulated annealing" or "Metropolis" algorithm on the space of binary sequences.

The space has C(400, 200) elements, which is astronomically large, but local search can work well.

For the energy computation: given b, computing all D(k) takes O(n²) time (for each k, scan the overlap). For n=400, that's 160,000 operations per evaluation. If we do 100,000 evaluations, that's 16 billion operations, which is too slow in Python.

We need to speed this up. Options:
1. Use FFT to compute the autocorrelation in O(n log n)
2. Use the precomputed F matrix approach (O(n) per move evaluation)
3. Use numpy vectorization

For the FFT approach:
- The autocorrelation R(k) = Σ_i b[i]b[i+k] can be computed via FFT
- D(k) = #{i: b[i]=1, b[i+k]=0} = #{i: b[i]=1} - #{i: b[i]=1, b[i+k]=1} = (n-k)·(something) - R(k)... 

Actually: D(k) = Σ_{i=0}^{n-1-k} b[i](1-b[i+k]) = Σ_{i} b[i] - Σ_i b[i]b[i+k] (for the valid range)
= sum(b[0:n-k]) - R(k)

where R(k) = Σ_{i=0}^{n-1-k} b[i]b[i+k] is the autocorrelation.

So if I can compute R(k) for all k quickly (via FFT), and also compute sum(b[0:n-k]) for all k (which is prefix sums), I can get D(k) for all k in O(n log n).

But for the local search, when I swap b[i] and b[j], the change in R(k) is:
ΔR(k) = b[i]b[i+k] + b[j]b[j+k] - (1-b[i])b[i+k] - (1-b[j])b[j+k]
= b[i+k] - b[i+k]... 

Wait, let me be more careful. If b[i]: 1→0 and b[j]: 0→1:
New b[i] = 0, new b[j] = 1.
ΔR(k) = [new b[i]·b[i+k] - b[i]·b[i+k]] + [new b[j]·b[j+k] - b[j]·b[j+k]] + [b[i+k]·new b[i] - b[i+k]·b[i]] + [b[j+k]·new b[j] - b[j+k]·b[j]]
= [0·b[i+k] - 1·b[i+k]] + [1·b[j+k] - 0·b[j+k]] + [b[i+k]·0 - b[i+k]·1] + [b[j+k]·1 - b[j+k]·0]
= -b[i+k] + b[j+k] - b[i+k] + b[j+k]
= 2(b[j+k] - b[i+k])

So ΔR(k) = 2(b[j+k] - b[i+k]) for each k. This is O(n) to compute for all k.

And the change in D(k):
ΔD(k) = Δsum(b[0:n-k]) - ΔR(k)

The change in sum(b[0:n-k]) when b[i] changes from 1 to 0: contributes -1 to sum(b[0:n-k]) for all k < n-i (i.e., when i < n-k, i.e., k < n-i).
And when b[j] changes from 0 to 1: contributes +1 to sum(b[0:n-k]) for all k < n-j.

So Δsum(b[0:n-k]) = +1[k < n-j] - 1[k < n-i]

And ΔD(k) = +1[k < n-j] - 1[k < n-i] - 2(b[j+k] - b[i+k])

This is O(n) to compute for all k. So each move evaluation is O(n) = O(400), which is fast.

With a good implementation in numpy, I could do about 10^6 - 10^7 move evaluations per second, which would be enough for a good simulated annealing run.

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr)) * dx

def project_feasible(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    diff = target_sum - np.sum(h)
    if abs(diff) < 1e-14:
        return h
    if diff > 0:
        idx = np.where(h < 1.0 - 1e-10)[0]
    else:
        idx = np.where(h > 1e-10)[0]
    if len(idx) == 0:
        return h
    h = h.copy()
    h[idx] += diff / len(idx)
    h = np.clip(h, 0.0, 1.0)
    residual = target_sum - np.sum(h)
    if abs(residual) > 1e-10:
        if residual > 0:
            idx2 = np.where(h < 1.0)[0]
        else:
            idx2 = np.where(h > 0.0)[0]
        if len(idx2) > 0:
            h[idx2] += residual / len(idx2)
            h = np.clip(h, 0.0, 1.0)
    return h

def get_grad_shift(h, k, n):
    idxs = np.arange(n)
    g = np.zeros(n)
    v1 = (idxs - k >= 0) & (idxs - k < n)
    v2 = (idxs + k >= 0) & (idxs + k < n)
    g[v1] += (1.0 - h[idxs[v1] - k])
    g[v2] -= h[idxs[v2] + k]
    return g

    start = time.time()
    dx = 2.0 / n
    h = h_start.copy()
    best_h = h.copy()
    best_c5 = compute_c5(h)
    mid = n - 1
    no_improve = 0
    for it in range(max_iter):
        if time.time() - start > time_limit:
            break
        if no_improve > 30:
            break
        corr = np.correlate(h, 1.0 - h, mode='full')
        c5_val = float(np.max(corr)) * dx
        if c5_val < best_c5 - 1e-12:
            best_c5 = c5_val
            best_h = h.copy()
            no_improve = 0
        else:
            no_improve += 1
        c_max = np.max(corr)
        active = np.where(corr > c_max - active_thresh / dx)[0]
        if len(active) == 0:
            active = np.array([np.argmax(corr)])
        # Build LP
        # Variables: h' (n vars) + t (1 var) = n+1 vars
        # Minimize t: c = [0, 0, ..., 0, 1]
        c_obj = np.zeros(n + 1)
        c_obj[n] = 1.0
        # Inequality constraints: A_ub @ x <= b_ub
        # For each active lag k: g_k · h' - t <= -corr[k] + g_k · h
        # i.e., [g_k, -1] · [h', t] <= -corr[k] + g_k · h
        A_rows = []
        b_rows = []
        for p in active:
            k_lag = int(p) - mid
            g_k = get_grad_shift(h, k_lag, n)
            rhs = -corr[p] + np.dot(g_k, h)
            row = np.zeros(n + 1)
            row[:n] = g_k
            row[n] = -1.0
            A_rows.append(row)
            b_rows.append(rhs)
        # Equality: sum(h') = target
        # A_eq = [1, 1, ..., 1, 0], b_eq = target
        A_eq = np.zeros((1, n + 1))
        A_eq[0, :n] = 1.0
        b_eq = np.array([target])
        bounds_lp = [(0.0, 1.0)] * n + [(0.0, None)]
        if len(A_rows) > 0:
            A_ub = np.array(A_rows)
            b_ub = np.array(b_rows)
        else:
            A_ub = None
            b_ub = None
        result = linprog(c_obj, A_ub=A_ub, b_ub=b_ub, A_eq=A_eq, b_eq=b_eq,
                        bounds=bounds_lp, method='highs')
        if result.success:
            h_new = result.x[:n]
            h_new = project_feasible(h_new, target)
            h_new = damping * h_new + (1 - damping) * h
            h_new = project_feasible(h_new, target)
            h = h_new
    return best_h, best_c5

Hmm, this binary local search is going to be slow because of the copy + correlate in each iteration. Let me optimize.

For n=400, np.correlate on two float arrays takes about 2-5 microseconds. The copy takes about 0.5 μs. The numpy operations in the loop take maybe another 5-10 μs. So total per iteration: ~15-20 μs. In 100 seconds: ~5×10^6 to 7×10^6 iterations.

But the issue is that we're doing a full correlate (length 799) every time. Can we do better?

The key insight is: when we change b[i] from 1 to 0 and b[j] from 0 to 1, the change in corr at each lag k is:
Δcorr at lag k = (effect of b[i]: 1→0 at lag k) + (effect of b[j]: 0→1 at lag k)

Effect of b[i]: 1→0 at lag k (where the full-mode index is p = k + n - 1, and k ranges from -(n-1) to n-1):
- b[i] appears in corr[p] as:
  - First factor (h[m] with m=i): if i-k is in [0,n-1], contributes (1-b[i-k]) to the sum. Removing it: Δ = -(1-b[i-k]) = b[i-k]-1
  - Second factor (h[m] with m-k=i, i.e., m=i+k): if i+k is in [0,n-1], the term is b[i+k]*(1-b[i]). Changing b[i] from 1 to 0: new term is b[i+k]*(1-0) = b[i+k], old term was b[i+k]*(1-1) = 0. Δ = b[i+k]

So: Δ_remove_i at lag k = (b[i-k]-1 if 0≤i-k<n else 0) + (b[i+k] if 0≤i+k<n else 0)

Similarly: Δ_add_j at lag k = ((1-b[j-k]) if 0≤j-k<n else 0) + (-b[j+k] if 0≤j+k<n else 0)

Total: Δcorr[k] = (b[i-k]-1)·1[0≤i-k<n] + b[i+k]·1[0≤i+k<n] + (1-b[j-k])·1[0≤j-k<n] - b[j+k]·1[0≤j+k<n]

This can be computed in O(1) per k, or O(n) for all k. But we only need the max of (corr + Δcorr), which requires checking all k.

Actually, we can precompute vectors:
- For position i: vec_remove[i, k] = (b[i-k]-1)·1[valid] + b[i+k]·1[valid] for all k
- For position j: vec_add[j, k] = (1-b[j-k])·1[valid] - b[j+k]·1[valid] for all k

from scipy.optimize import minimize, linprog
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr)) * dx

def project_feasible(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    diff = target_sum - np.sum(h)
    if abs(diff) < 1e-14:
        return h
    if diff > 0:
        idx = np.where(h < 1.0 - 1e-10)[0]
    else:
        idx = np.where(h > 1e-10)[0]
    if len(idx) == 0:
        return h
    h = h.copy()
    h[idx] += diff / len(idx)
    h = np.clip(h, 0.0, 1.0)
    residual = target_sum - np.sum(h)
    if abs(residual) > 1e-10:
        if residual > 0:
            idx2 = np.where(h < 1.0)[0]
        else:
            idx2 = np.where(h > 0.0)[0]
        if len(idx2) > 0:
            h[idx2] += residual / len(idx2)
            h = np.clip(h, 0.0, 1.0)
    return h

def get_grad_shift(h, k, n):
    idxs = np.arange(n)
    g = np.zeros(n)
    v1 = (idxs - k >= 0) & (idxs - k < n)
    v2 = (idxs + k >= 0) & (idxs + k < n)
    g[v1] += (1.0 - h[idxs[v1] - k])
    g[v2] -= h[idxs[v2] + k]
    return g

    constraints and solve an LP."""

    best_h = h.copy()
    best_c5 = compute_c5(h)
    mid = n - 1
    no_improve = 0
    
    for it in range(max_iter):
        if time.time() - start > time_limit:
            break
        if no_improve > 40:
            break
        
        corr = np.correlate(h, 1.0 - h, mode='full')
        c5_val = float(np.max(corr)) * dx
        if c5_val < best_c5 - 1e-12:
            best_c5 = c5_val
            best_h = h.copy()
            no_improve = 0
        else:
            no_improve += 1
        
        c_max = float(np.max(corr))
        # Select active constraints: top fraction of correlations
        n_active = max(5, int(active_fraction * (2 * n - 1)))
        active = np.argsort(corr)[-n_active:]
        
        # Build LP: minimize t

        c_obj = np.zeros(n + 1)
        c_obj[n] = 1.0

        b_ub = np.array(b_rows)

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr)) * dx

def project_feasible(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    diff = target_sum - np.sum(h)
    if abs(diff) < 1e-14:
        return h
    if diff > 0:
        idx = np.where(h < 1.0 - 1e-10)[0]
    else:
        idx = np.where(h > 1e-10)[0]
    if len(idx) == 0:
        return h
    h = h.copy()
    h[idx] += diff / len(idx)
    h = np.clip(h, 0.0, 1.0)
    residual = target_sum - np.sum(h)
    if abs(residual) > 1e-10:
        if residual > 0:
            idx2 = np.where(h < 1.0)[0]
        else:
            idx2 = np.where(h > 0.0)[0]
        if len(idx2) > 0:
            h[idx2] += residual / len(idx2)
            h = np.clip(h, 0.0, 1.0)
    return h
