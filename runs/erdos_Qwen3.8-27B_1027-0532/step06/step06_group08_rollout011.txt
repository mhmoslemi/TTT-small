- If s = j0-i0 (and i0 = j0-s is in [0,n)): delta[s] += 1

- If s = -(i0-j0) = j0-i0: delta[s] += 1

So the condition is simply: if s = i0-j0 OR s = j0-i0, add 1 to delta[s].

In the vectorized form: the position s = i0-j0 corresponds to index (i0-j0)+(n-1) in the correlation array, and s = j0-i0 corresponds to index (j0-i0)+(n-1) = (n-1)-(i0-j0).
