The best case would be if A is such that A ∩ (A-k) always has measure close to 1. But that's impossible for all k simultaneously (at k=2, A∩(A-2) is empty).

The constraint is that k ranges over all real values (in the continuous case). In the discrete case, k ranges over {-(n-1), ..., n-1} * dx.

For the discrete case with n points and n/2 ones:
- At k=0: |A ∩ A| = |A| = n/2 (in units of dx)
- At k=n: |A ∩ (A-n)| = 0 (no overlap)
- The question is: what's the minimum over k?

Actually wait, I need to be more careful. In the discrete formulation:
c(k) = Σ_{i: 0≤i<n, 0≤i+k<n} h[i]·(1-h[i+k])

This counts the number of pairs (i, i+k) where h[i]=1 and h[i+k]=0.
= (number of i with h[i]=1 and i+k<n) - (number of i with h[i]=1 and h[i+k]=1)
= |{i: h[i]=1, i+k∈[0,n)}| - |{i: h[i]=1, h[i+k]=1}|

Let |A| = n/2 (number of ones).
|{i: h[i]=1, i+k∈[0,n)}| = |A ∩ [0, min(n, n-k))| for k≥0
This is approximately |A| - (number of ones near the boundary that get "cut off").

For the maximum of c(k), we want to minimize this. The minimum possible value of c(k) for a given k is:
max(0, |{i: h[i]=1, i+k∈[0,n)}| - |{i: h[i]=1, h[i+k]=1}|)
≥ max(0, |{i: h[i]=1, i+k∈[0,n)}| - min(|{i: h[i]=1, i+k∈[0,n)}|, |{i+k: i∈A, i+k∈[0,n)}|))

Key idea for improvement: **Use the O(1) per-shift delta computation to do many more iterations**.

Let me also think about a completely different approach: **annealing on the correlation vector directly**.

Instead of swapping individual bits, what if we:
1. Identify the "critical" shifts (those with correlation near the max)
2. For each critical shift k, find the swap that most reduces c(k)
3. Apply that swap
4. Update

This is a "steepest descent on the max" approach, but with the constraint that we can only do single swaps.

For a given shift k, c(k) = Σ_i h[i]·(1-h[i+k]). To decrease c(k), we want to:
- Set h[i]=0 where h[i]=1 and h[i+k]=0 (reduces c(k) by 1)
- But we must also set h[j]=1 somewhere (to maintain the sum constraint)
- Setting h[j]=1 increases c(k) by (1-h[j+k]) if j+k is valid, and by -h[j-k]... wait no.

Actually, the delta at shift k for swap (i: 1→0, j: 0→1) is:
δ(k) = -(1-h[i+k])·[i+k∈[0,n)) + h[i-k]·[i-k∈[0,n)) + (1-h[j+k])·[j+k∈[0,n)) - h[j-k]·[j-k∈[0,n))

To minimize c(k), we want δ(k) < 0, i.e.:
-(1-h[i+k]) + h[i-k] + (1-h[j+k]) - h[j-k] < 0
(simplifying assuming all indices are valid)
= h[i+k] - 1 + h[i-k] + 1 - h[j+k] - h[j-k]
= h[i+k] + h[i-k] - h[j+k] - h[j-k] < 0

So we want: h[i+k] + h[i-k] < h[j+k] + h[j-k]

This means: for the "removed" one (i), the neighbors at distance k should be mostly 1s (so removing i doesn't help much at shift k... wait, that's the opposite).

Let me re-derive:
δ(k) = h[i+k] - 1 + h[i-k] + (1 - h[j+k]) - h[j-k]
     = (h[i+k] + h[i-k]) - (h[j+k] + h[j-k]) - 1 + 1
     = (h[i+k] + h[i-k]) - (h[j+k] + h[j-k])

Wait let me redo this carefully:
- h[i]: 1→0
  - As left factor at position i: contributes -(1-h[i+k]) = h[i+k]-1 (if i+k valid)
  - As right factor at position i-k: contributes +h[i-k] (if i-k valid)
- h[j]: 0→1
  - As left factor at position j: contributes +(1-h[j+k]) (if j+k valid)
  - As right factor at position j-k: contributes -h[j-k] (if j-k valid)

Total: δ(k) = (h[i+k]-1) + h[i-k] + (1-h[j+k]) - h[j-k]
           = h[i+k] + h[i-k] - h[j+k] - h[j-k]

So δ(k) < 0 iff h[i+k] + h[i-k] < h[j+k] + h[j-k]

This is a clean condition! For a given shift k:
- We want to remove a 1 at position i where h[i+k]+h[i-k] is small (i.e., neighbors are mostly 0)
- We want to add a 1 at position j where h[j+k]+h[j-k] is large (i.e., neighbors are mostly 1)

This gives us a very efficient local search:
1. For each active shift k, compute the "score" for each position: score_k(i) = h[i+k]+h[i-k]
2. For the shift with the highest correlation, find the best swap (i with low score, j with high score)
3. Apply it

This is O(n) per shift, O(K·n) per iteration, but with K being small (say 10-50), this is much faster than the O(n²) full correlation recomputation.

Actually, even better: we can precompute the scores for all active shifts at once, and then find the best swap in O(K·n) time.

def steepest_descent_swap(h, k_arr, active_idx, n, K_focus=20):

    Find the swap (i,j) that most reduces the max correlation
    among the active shifts.
    """
    n = len(h)
    ones = np.where(h == 1.0)[0]
    zeros = np.where(h == 0.0)[0]
    if len(ones) < 2 or len(zeros) < 2:
        return None, None, 0.0
    
    best_delta_max = 0.0  # We want the most negative
    best_i, best_j = None, None
    
    # For each active shift, compute scores
    # score for removing i: h[i+k] + h[i-k] (lower is better for removal)
    # score for adding j: h[j+k] + h[j-k] (higher is better for addition)
    # delta at shift k = (h[i+k]+h[i-k]) - (h[j+k]+h[j-k])
    # We want to minimize max over active shifts of (corr[k] + delta[k])
    
    # Simple approach: try the worst shift and find the best swap for it
    # Then verify it doesn't increase other active shifts too much
    
    # For now, let's just do greedy on the worst shift
    worst_shift_local = 0  # index into active_idx
    # Actually, let's try a few of the worst shifts
    
    candidates = []
    for a_idx in active_idx[:min(5, len(active_idx))]:
        k = int(k_arr[a_idx])
        if k == 0:
            continue
        
        # Compute scores for ones and zeros
        # For i in ones: score_remove = h[i+k] + h[i-k] (where valid)
        # For j in zeros: score_add = h[j+k] + h[j-k] (where valid)
        
        # Vectorized:
        ip = ones + k
        valid_ip = (ip >= 0) & (ip < n)
        im = ones - k
        valid_im = (im >= 0) & (im < n)
        score_remove = np.zeros(len(ones))
        score_remove[valid_ip] += h[ip[valid_ip]]
        score_remove[valid_im] += h[im[valid_im]]
        
        jp = zeros + k
        valid_jp = (jp >= 0) & (jp < n)
        jm = zeros - k
        valid_jm = (jm >= 0) & (jm < n)
        score_add = np.zeros(len(zeros))
        score_add[valid_jp] += h[jp[valid_jp]]
        score_add[valid_jm] += h[jm[valid_jm]]
        
        # Best swap for this shift: minimize score_remove[i] - score_add[j]
        # = minimize score_remove[i] + minimize (-score_add[j])
        # So: pick i with min score_remove, j with max score_add
        i_best = ones[np.argmin(score_remove)]
        j_best = zeros[np.argmax(score_add)]
        
        # Compute delta at all active shifts for this swap
        # (this is where we verify it doesn't hurt other shifts)
        deltas = np.zeros(len(active_idx))
        for m, a_i in enumerate(active_idx):
            k_m = int(k_arr[a_i])
            d = 0.0
            ip_m = i_best + k_m
            if 0 <= ip_m < n:
                d += (h[ip_m] - 1.0)
            im_m = i_best - k_m
            if 0 <= im_m < n:
                d += h[im_m]
            jp_m = j_best + k_m
            if 0 <= jp_m < n:
                d += (1.0 - h[jp_m])
            jm_m = j_best - k_m
            if 0 <= jm_m < n:
                d -= h[jm_m]
            deltas[m] = d
        
        # The new max at active shifts
        # We'd need the current correlation values...
        # For now, just use the delta at the target shift
        target_delta = float(deltas[0])
        candidates.append((target_delta, i_best, j_best))
    
    if not candidates:
        return None, None, 0.0
    
    # Pick the most negative
    candidates.sort()
    return candidates[0][1], candidates[0][2], candidates[0][0]

def swap_delta_at_k(h, i, j, k, n):
    """O(1) computation of delta at a single shift k."""
    d = 0.0
    ip = i + k
    if 0 <= ip < n:
        d += h[ip] - 1.0
    im = i - k
    if 0 <= im < n:
        d += h[im]
    jp = j + k
    if 0 <= jp < n:
        d += 1.0 - h[jp]
    jm = j - k
    if 0 <= jm < n:
        d -= h[jm]
    return d

def full_corr_np(h):

def project_box_sum(h, target):
    lo, hi = -2.0, 2.0
    for _ in range(60):
        mid = (lo + hi) / 2.0
        if np.clip(h - mid, 0.0, 1.0).sum() > target:
            lo = mid
        else:
            hi = mid
    return np.clip(h - (lo + hi) / 2.0, 0.0, 1.0)

def project_binary(h, target_sum):
    h_r = np.round(h).clip(0, 1)
    s = int(h_r.sum())
    if s > target_sum:
        ones = np.where(h_r == 1)[0]
        h_r[ones[np.argsort(h[ones])[:s - target_sum]]] = 0
    elif s < target_sum:
        zeros = np.where(h_r == 0)[0]
        h_r[zeros[np.argsort(-h[zeros])[:target_sum - s]]] = 1
    return h_r.astype(float)

def swap_delta_vec(h, i, j, k_arr, n):
    d = np.zeros(len(k_arr))
    ip = i + k_arr
    v = (ip >= 0) & (ip < n)
    d[v] += h[ip[v]] - 1.0
    im = i - k_arr
    v = (im >= 0) & (im < n)
    d[v] += h[im[v]]
    jp = j + k_arr
    v = (jp >= 0) & (jp < n)
    d[v] += 1.0 - h[jp[v]]
    jm = j - k_arr
    v = (jm >= 0) & (jm < n)
    d[v] -= h[jm[v]]
    return d

def swap2_delta_vec(h, i1, i2, j1, j2, k_arr, n):

def smooth_c5_obj(h, alpha=2000.0):
    corr = full_corr_np(h)
    cmax = float(corr.max())
    shifted = np.clip(alpha * (corr - cmax), -500.0, 0.0)
    return cmax + float(np.log(np.sum(np.exp(shifted))) / alpha)

def _cfun(h):
    return np.sum(h) - _cons_target

def _cjac(h):
    return np.ones(_cons_n)

def slsqp_refine(h_start, n, target, alpha, maxiter, deadline, start_time):
    global _cons_n, _cons_target
    _cons_n = n
    _cons_target = target
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': _cfun, 'jac': _cjac}]
    try:
        res = minimize(smooth_c5_obj, h_start, args=(alpha,),
                       method='SLSQP', bounds=bounds, constraints=cons,
                       options={'maxiter': maxiter, 'ftol': 1e-14})
        return project_box_sum(res.x, target), compute_c5(project_box_sum(res.x, target))
    except Exception:
        return h_start, compute_c5(h_start)

def gradient_refine(h0, target, deadline, start_time, alphas):
    n = len(h0)
    h = project_box_sum(h0.astype(float), target)
    best_h = h.copy()
    best_sc = compute_c5(h)

    for alpha in alphas:
        if time.time() > deadline:
            break
        lr = 1.0 / (alpha + 1.0)
        mom = 0.5
        v = np.zeros(n)
        n_it = 80
        for it in range(n_it):
            if time.time() > deadline:
                break
            corr = full_corr_np(h)
            cmax = float(corr.max())
            exp_c = np.exp(alpha * (corr - cmax))
            w = exp_c / exp_c.sum()
            N_fft = 1
            while N_fft < 3 * n:
                N_fft <<= 1
            wp = np.zeros(N_fft)

            conv = np.fft.ifft(np.fft.fft(wp) * np.fft.fft(hp)).real[:n]

            h = project_box_sum(h + v, target)

                    best_sc = sc
                    best_h = h.copy()

    sc = compute_c5(h)

        return budget_s - 3.0 - (time.time() - start_time)

    # Phase 1: Primary SA with restarts
    deadline1 = start_time + min(400, tleft() * 0.40)
    h1, c5_1 = sar_sa(best_h, 4, 150000, 0.022, 0.00002, rng, deadline1, start_time, K=50)
    if c5_1 < best_score:
        best_score = c5_1
        best_h = h1

    # Phase 2: Second SA with different params
    if tleft() > 60:
        deadline2 = start_time + min(300, tleft() * 0.25)
        h2, c5_2 = sar_sa(best_h, 3, 200000, 0.015, 0.00001, rng, deadline2, start_time, K=35, )
        if c5_2 < best_score:
            best_score = c5_2
            best_h = h2

    # Phase 3: Multi-restart with diverse perturbations
    n_restarts = 6
    for r in range(n_restarts):
        if tleft() < 30:
            break
        h_p = best_h.copy()
        n_pert = rng.randint(3, 7 + 2 * r)
        ones = np.where(h_p == 1.0)[0]
        zeros = np.where(h_p == 0.0)[0]
        for _ in range(n_pert):
            if len(ones) < 2 or len(zeros) < 2:
                break
            h_p[ones[rng.randint(len(ones))]] = 0.0
            h_p[zeros[rng.randint(len(zeros))]] = 1.0
            ones = np.where(h_p == 1.0)[0]
            zeros = np.where(h_p == 0.0)[0]
        allowed = min(60, tleft() * 0.09)
        dl = start_time + allowed
        h_r, c5_r = fast_guided_sa(h_p, int(allowed * 90000), 0.012, 0.00002,
                                   rng, dl, start_time, K=40, use_double=True)
        if c5_r < best_score:
            best_score = c5_r
            best_h = h_r

    # Phase 4: Different resolutions
    for n_try in [n_base + 4, n_base - 4, n_base + 8, n_base - 8,
                  n_base + 12, n_base + 16, n_base - 12]:
        if tleft() < 25:
            break
        if n_try < 100 or n_try % 2 != 0:
            continue
        tgt = n_try // 2
        xo = np.linspace(0, 1, len(best_h))
        xn = np.linspace(0, 1, n_try)
        hi = np.interp(xn, xo, best_h)
        hb = project_binary(hi, tgt)
        allowed = min(35, tleft() * 0.08)
        dl = start_time + allowed
        h_d, c5_d = fast_guided_sa(hb, int(allowed * 70000), 0.01, 0.00003,
                                   rng, dl, start_time, K=35)
        if c5_d < best_score:
            best_score = c5_d
            best_h = h_d

    # Phase 5: Continuous gradient refinement
    if tleft() > 80:
        n_use = len(best_h)
        tgt = float(n_use) / 2.0
        alphas = [5, 20, 80, 300, 1200, 5000]
        dl = start_time + min(150, tleft() * 0.25)
        h_gr, sc_gr = gradient_refine(best_h, tgt, dl, start_time, alphas)
        if sc_gr < best_score:
            best_score = sc_gr
            best_h = h_gr

    # Phase 6: SLSQP refinement
    if tleft() > 50:
        n_use = len(best_h)
        tgt = float(n_use) / 2.0
        for alpha in [500, 2000, 8000]:
            if tleft() < 20:
                break
            dl = start_time + min(40, tleft() * 0.2)
            h_s, sc_s = slsqp_refine(best_h, n_use, tgt, alpha, 1000, dl, start_time)
            if sc_s < best_score:
                best_score = sc_s
                best_h = h_s

    # Phase 7: Final binary SA polish
    if tleft() > 20:
        n_f = len(best_h)
        tgt_f = n_f // 2
        hb = project_binary(best_h, tgt_f)
        allowed = max(5, tleft() - 8)
        dl = start_time + allowed
        h_f, c5_f = fast_guided_sa(hb, int(allowed * 100000), 0.005, 0.000005,
                                   rng, dl, start_time, K=60)
        if c5_f < best_score:
            best_score = c5_f
            best_h = h_f

    # Final feasibility projection
    n_final = len(best_h)
    h_final = project_box_sum(best_h, float(n_final) / 2.0)
    final_score = compute_c5(h_final)

    return h_final, final_score, n_final
