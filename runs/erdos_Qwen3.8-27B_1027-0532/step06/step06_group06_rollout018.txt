**New idea: Iterative water-filling**
The "maximize minimum overlap" problem is like water-filling: we want to raise the minimum until all overlaps are as equal as possible. We can do this iteratively:
1. Find the minimum overlap shift k_min
2. Try to increase overlap at k_min
3. This means finding pairs (i, j) where h[i]=1, h[j]=0, and setting h[j]=1, h[i]=0 would increase overlap at k_min
4. But we need to make sure this doesn't decrease other overlaps below the current minimum

This is a constrained optimization at each step.

This is O(n²) per iteration in the worst case (scanning all pairs), which is too slow for n=606 (367K per iteration, and we'd need many iterations).

Let me optimize: instead of scanning all pairs, use a smarter selection.

**Key insight**: The change in correlation for swap (a, b) at shift k is:
Δc_k = h[a-k] + h[a+k] - h[b-k] - h[b+k]

For the worst shift k*, we want:
h[a-k*] + h[a+k*] - h[b-k*] - h[b+k*] < 0

This means: (h[a-k*] + h[a+k*]) < (h[b-k*] + h[b+k*])

So I want a "1" position a where the "neighborhood" at distance k* has few 1s, and a "0" position b where the neighborhood at distance k* has many 1s.

This is a much more efficient selection criterion!

Let me define:
- score_1[a] = h[a-k*] + h[a+k*] (for a where h[a]=1)
- score_0[b] = h[b-k*] + h[b+k*] (for b where h[b]=0)

I want score_1[a] < score_0[b].

Best a: minimum score_1 among 1s
Best b: maximum score_0 among 0s

Then check if the swap actually improves the max correlation.

This is O(n) per iteration!

But I also need to make sure the swap doesn't hurt other correlations. I'll check the top few.

Let me refine this approach and also add 2-for-2 swaps.

For a 2-for-2 swap (a1, a2 → 0, b1, b2 → 1):
Δc_k = (h[a1-k]+h[a1+k]+h[a2-k]+h[a2+k]) - (h[b1-k]+h[b1+k]+h[b2-k]+h[b2+k])

The selection is similar but with 4 terms.

```python
            break
        ratio = (it + 1) / max_iters
        t = t_init * (t_final / t_init) ** ratio
        
        ones = np.where(h == 1)[0]
        zeros = np.where(h == 0)[0]
        if len(ones) == 0 or len(zeros) == 0:
            break
        
        r = rng.random()
        old_vals = []  # (index, old_value) pairs for undo
        
        if r < 0.5:
            # Single swap
            a = ones[rng.randint(len(ones))]
            b = zeros[rng.randint(len(zeros))]
            old_vals = [(a, 1), (b, 0)]
            h[a] = 0
            h[b] = 1
        elif r < 0.8:
            # 2-for-2 swap
            a1, a2 = rng.choice(len(ones), 2, replace=False)
            b1, b2 = rng.choice(len(zeros), 2, replace=False)
            old_vals = [(ones[a1], 1), (ones[a2], 1), (zeros[b1], 0), (zeros[b2], 0)]
            h[ones[a1]] = 0
            h[ones[a2]] = 0
            h[zeros[b1]] = 1
            h[zeros[b2]] = 1
        else:

            block_len = rng.randint(1, 4)
            a_start = rng.randint(0, max(1, n - block_len - 1))
            # Check if positions a_start..a_start+block_len-1 are all 1
            if not np.all(h[a_start:a_start+block_len] == 1):
                # Just do a single swap
                a = ones[rng.randint(len(ones))]
                b = zeros[rng.randint(len(zeros))]
                old_vals = [(a, 1), (b, 0)]
                h[a] = 0
                h[b] = 1
            else:
                b_start = rng.randint(0, max(1, n - block_len - 1))
                if np.all(h[b_start:b_start+block_len] == 0):
                    old_vals = [(a_start+i, 1) for i in range(block_len)] + \
                               [(b_start+i, 0) for i in range(block_len)]
                    h[a_start:a_start+block_len] = 0
                    h[b_start:b_start+block_len] = 1
                else:
                    a = ones[rng.randint(len(ones))]
                    b = zeros[rng.randint(len(zeros))]
                    old_vals = [(a, 1), (b, 0)]
                    h[a] = 0
                    h[b] = 1
        
        corr = np.correlate(h, 1.0 - h, mode='full')
        new_c5 = float(corr.max()) * dx
        delta = new_c5 - current_c5
        
        if delta < 0 or (t > 1e-10 and rng.random() < np.exp(-delta / max(t, 1e-30))):
            current_c5 = new_c5
            if new_c5 < best_c5:
                best_c5 = new_c5
                best_h = h.copy()
        else:
            # Undo
            for idx, old_val in old_vals:
                h[idx] = old_val
    
    return best_h, best_c5
```

Now let me think about the continuous optimization. The previous code used L-BFGS-B with a log-sum-exp objective. This is good but might get stuck. Let me try a different approach:

**Projected subgradient method with averaging:**
- At each step, compute the subgradient of max_k c_k (which is the gradient of the active correlation)
- Take a step in the negative subgradient direction
- Project back to {0≤h≤1, sum(h)=n/2}
- Use Polyak step size or diminishing step size
- Use averaged iterate (Nesterov averaging) for the final answer

The subgradient of f(h) = max_k c_k at h is:
If k* is the unique maximizer: ∇f = ∇c_{k*}
If multiple maximizers: ∇f is a convex combination of their gradients

∇c_k[j] = (1-h[j-k]) - h[j+k] (with boundary conditions)

This is O(n) to compute per step, which is very fast.

```python
def subgradient_method(h_start, n_steps, time_limit, start_time):
    n = len(h_start)
    target = float(n / 2)
    dx = 2.0 / n
    h = h_start.copy()
    
    # Running average (Nesterov)
    h_avg = h.copy()
    counter = 1
    
    best_c5 = compute_c5(h)
    best_h = h.copy()
    
    for step in range(n_steps):
        if time.time() - start_time > time_limit:
            break
        
        # Compute correlations and find active set
        corr = np.correlate(h, 1.0 - h, mode='full')
        max_corr = corr.max()
        
        # Find active set (correlations within epsilon of max)
        eps = 0.01  # in correlation units
        active = np.where(corr >= max_corr - eps)[0]
        
        # Compute subgradient (average of active gradients)
        grad = np.zeros(n)
        for k_idx in active:
            k = k_idx - (n - 1)
            for j in range(n):
                g = 0.0
                jmk = j - k
                jpk = j + k
                if 0 <= jmk < n:
                    g += (1.0 - h[jmk])
                if 0 <= jpk < n:
                    g -= h[jpk]
                grad[j] += g
        grad /= len(active)
        grad *= dx  # Scale by dx for the integral
        
        # Step size
        alpha = 2.0 / (step + 1 + n)  # Polyak-like
        
        # Gradient step
        h_new = h - alpha * grad
        
        # Project
        h = project_box_sum(h_new, target)
        
        # Update running average
        h_avg += (h - h_avg) / (counter + 1)
        counter += 1
        
        if step % 100 == 0:
            c5_avg = compute_c5(h_avg)
            c5_cur = compute_c5(h)
            if c5_avg < best_c5:
                best_c5 = c5_avg
                best_h = h_avg.copy()
            if c5_cur < best_c5:
                best_c5 = c5_cur
                best_h = h.copy()
    
    return best_h, best_c5
```

For a given h and shift k, the gradient ∇c_k[j] = (1-h[j-k]) - h[j+k]

This is:
∇c_k[j] = 1 - h[j-k] - h[j+k]

For multiple active shifts, the average gradient is:
(1/|A|) * Σ_{k∈A} [(1-h[j-k]) - h[j+k]]

= (1/|A|) * [ |A| - Σ_{k∈A} h[j-k] - Σ_{k∈A} h[j+k] ]

= 1 - (1/|A|) * [ (h * 1_A)[j] + (h * 1_{-A})[j] ]

Actually, let me reconsider the coordinate descent. The issue is that for each coordinate j, I want to find the h[j] that minimizes max_k c_k. This is a 1D problem. 

Given all other coordinates fixed, c_k as a function of h[j] = x is:
- For k=0: c_0(x) = x(1-x) + c_0_const (quadratic, concave)
- For k≠0: c_k(x) = x * a_k + b_k (linear)

where a_k = (1-h[j-k]) - h[j+k] (with boundary) and b_k = c_k_current - x_current * a_k.

The maximum of these functions is a piecewise-linear (with one concave piece) function. Its minimum can be found by:
1. Evaluating at x=0 and x=1
2. Finding the "crossing points" where the active function changes

For the minimum of max of linear functions, it occurs where the two "tightest" linear functions cross, or at a boundary.

I'll just do a fine grid search (50 points) and use the O(n) formula to compute the max for each candidate.

For efficiency: at each coordinate j, I precompute a_k for all k (which is O(n)), then for each of 50 candidate x values, I compute max_k (x*a_k + b_k) in O(n). Total: O(n * 50) per coordinate, O(n² * 50) per pass. For n=606: 606² * 50 ≈ 18.4M per pass. In numpy, this should take about 0.1 seconds per pass. So I can do 100 passes in ~10 seconds.

```python
            # a_k = (1-h[j-k]) - h[j+k] (with boundary handling)
            # In correlation indexing: index = k + (n-1)

                if 0 <= jpk < n:
                    a -= h[jpk]

                    best_x = x
```
