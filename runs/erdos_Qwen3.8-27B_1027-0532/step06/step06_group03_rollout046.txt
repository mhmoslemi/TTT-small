def fast_gradient(h, alpha):
    n = len(h)
    dx = 2.0 / n
    one_minus_h = 1.0 - h
    corr = np.correlate(h, one_minus_h, mode='full')
    
    c_max = np.max(corr)
    shifted = np.clip(alpha * (corr - c_max), -500.0, 0.0)
    exp_shifted = np.exp(shifted)
    w = exp_shifted / np.sum(exp_shifted)
    
    # grad[j] = dx * (sum_m w[m] * (1-h[j-s_m]) * [valid] - sum_m w[m] * h[j+s_m] * [valid])
    # s_m = m - (n-1)

    # But this is an n x (2n-1) matrix, which is 400 x 799 = 319600 entries.
    # That's fine for memory.
    
    j_idx = np.arange(n)[:, None]  # n x 1
    s = np.arange(-(n-1), n)[None, :]  # 1 x (2n-1)
    
    # First term: (1-h[j - s]) for valid j-s

    valid1 = (diff1 >= 0) & (diff1 < n)

    diff2 = j_idx + s
    valid2 = (diff2 >= 0) & (diff2 < n)
    
    # P[j] = sum_m w[m] * (1-h[j-s_m]) * valid1
    # Q[j] = sum_m w[m] * h[j+s_m] * valid2

    Q_vals = np.where(valid2, h[np.where(valid2, diff2, 0)], 0.0)
    Q = Q_vals @ w  # n x 1

Let me also think about the **active set method** in more detail:

At the optimum, we have:
- A non-empty set of active lags A = {k : c_k = max}
- A set of free coordinates F = {j : 0 < h[j] < 1}
- KKT conditions: for j ∈ F, ∑_{k∈A} λ_k * ∂c_k/∂h_j = 0
- For k ∈ A: λ_k > 0, ∑ λ_k = 1 (from the max constraint)

5. Transform back: h_new = IDFT(H_modified).
6. Project to [0,1] and fix the sum constraint.
