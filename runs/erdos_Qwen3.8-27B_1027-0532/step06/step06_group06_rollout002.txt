def smooth_gradient_vec(h, beta, target, penalty):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    c_max = float(corr.max())
    shifted = beta * (corr - c_max)
    shifted -= shifted.max()  # numerical stability
    weights = np.exp(shifted)
    weights /= weights.sum()
    
    # weights[k] = p_k for k = 0, ..., 2n-2
    # shift s = k - (n-1), so s ranges from -(n-1) to (n-1)

    # Term 2: sum_s weights[s+(n-1)] * h[j-s] for valid j-s
    
    # These are cross-correlations
    # Term 1: cross-correlate weights (as function of s) with (1-h)
    # For j: sum_{s} w[s] * (1-h[j+s]) = (w ⋆ (1-h))[j] where ⋆ is cross-correlation

    # Hmm, that's not quite what I want.

    # (w ⋆ f)[j] = sum_s w[s] * f[j+s]

    # So w_rev_arr = weights[::-1] (reversed!)

    term1_full = fftconvolve(w_rev, 1.0 - h, mode='full')

**Idea: "Shift balancing" objective**
Instead of just minimizing the max, we could use a "bounded" objective:
min max_k corr[k] subject to corr[k] ≤ B for all k

This is a feasibility problem. We can use bisection on B:
- Start with B = current max
- Try to find h with all corr[k] ≤ B
- If infeasible, increase B
- Use this as a branch-and-bound or penalty approach

**Idea: "Worst-shift focused" optimization**
Identify the top 5-10 worst shifts. Focus the optimization on reducing those specifically. Use a "surgical" approach: for each worst shift, find the move that most reduces that shift's correlation, while not increasing others too much.

**Idea: "Pattern insertion"**
Instead of single swaps, insert a "balanced pattern" (like a Golay sequence or a sporadic group pattern) at a specific location. This could break out of local optima that single swaps can't escape.

**Idea: "Convex combination"**
Take two good binary solutions h1 and h2, and try h = α*h1 + (1-α)*h2 for various α. This might give a better continuous solution.
