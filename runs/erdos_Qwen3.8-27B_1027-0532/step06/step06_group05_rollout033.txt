For position i, the overlap at shift k (k ≠ 0) is:
overlap(k) = sum_{j: valid} h[j] * (1-h[j+k])

The terms involving h[i]:
- j = i: h[i] * (1-h[i+k]) [valid if 0 ≤ i+k < n]
- j+k = i, i.e., j = i-k: h[i-k] * (1-h[i]) [valid if 0 ≤ i-k < n]

So overlap(k) = C_k + h[i] * [(1-h[i+k]) - h[i-k]] (with out-of-bounds terms being 0)

where C_k = overlap(k) - h[i]*[(1-h[i+k]) - h[i-k]] is the part not involving h[i].

Let A_k = (1-h[i+k]) - h[i-k] (the coefficient of h[i] in overlap(k))

We want to minimize max_k (C_k + A_k * t) for t ∈ [0,1].

This is a 1D convex optimization (max of linear functions). The optimal t is:
- If all A_k = 0, any t works
- Otherwise, find t where the "upper envelope" of the lines C_k + A_k*t is minimized

The minimum of the upper envelope occurs at a "crossing point" where two lines intersect at the maximum level. We can find it by:
1. Sort lines by A_k
2. Use a "lower envelope" type algorithm
3. Or simply use bisection on the subgradient

For simplicity, I'll use bisection:
- At t=0, the active lines are those with the largest C_k
- At t=1, the active lines are those with the largest C_k + A_k
- The optimal t is where the subgradient changes sign

The subgradient of max_k(C_k + A_k*t) at t is the convex hull of {A_k : k active at t}.
- If all active A_k > 0, we should decrease t
- If all active A_k < 0, we should increase t
- If 0 is in the convex hull, we're at the optimum

This bisection converges in O(log(1/ε)) steps, each requiring O(|active|) work.

For efficiency, I'll limit |active| to the top 20-50 shifts.

Let me also handle the k=0 case specially. At k=0:
overlap(0) = sum_j h[j]*(1-h[j]) = sum_j h[j] - sum_j h[j]^2

The term involving h[i] is h[i] - h[i]^2, which is quadratic. So for k=0, the coordinate descent is:
minimize max(overlap(0)(t), max_{k≠0} (C_k + A_k * t))

where overlap(0)(t) = C_0 + t - t^2 (with C_0 = overlap(0) - h[i] + h[i]^2).

This is more complex but still solvable in 1D. The function t - t^2 is a concave parabla with max at t=0.5.

For simplicity, I'll just handle the linear case (k≠0) in the coordinate descent and ignore k=0 (since for binary h, overlap(0) = 0, and for near-binary h, it's small).
