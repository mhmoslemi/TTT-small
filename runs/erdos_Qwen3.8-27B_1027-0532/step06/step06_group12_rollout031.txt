One more consideration: the log-sum-exp computation. For numerical stability:
logsumexp(alpha * x) = alpha * x_max + log(sum(exp(alpha * (x - x_max))))

So the smooth max is: x_max + log(sum(exp(alpha * (x - x_max)))) / alpha

For very large alpha (like 10^6), alpha * (x - x_max) will be very negative for non-maximal elements, and the exp will underflow to 0. This is actually fine - it means only the max element contributes, and we recover the true max. But for SLSQP/L-BFGS, we need the gradient to be well-defined.
