For the problem of minimizing max_k |R(k)| (where R is autocorrelation) for a binary sequence of length n with n/2 ones, the optimal construction is related to "Golay complementary sequences" or "Barker sequences". Actually, for very long sequences, the boundary effects become negligible, and the problem approaches: minimize max_k (n/2 - R(k)) = n/2 - min_k R(k). So we want to maximize min_k R(k).

For a binary sequence with n/2 ones, the autocorrelation R(k) = sum_i h[i]*h[i+k]. We want this to be as large as possible for all k simultaneously.

The minimum possible value of max_k (n/2 - R(k)) is related to the "Sidon set" or "difference set" theory. A (v, k, λ) difference set has the property that every nonzero difference appears exactly λ times. If we could find such a set in Z_n with v=n, k=n/2, then R(k) = λ for all k≠0, and λ = k(k-1)/(v-1) ≈ n/4.

But difference sets exist only for specific parameters. For v=n, k=n/2, we need λ = (n/2)(n/2-1)/(n-1) ≈ n/4. This requires n-1 | (n/2)(n/2-1), which is a strong condition.

In any case, the theoretical lower bound for C5 (in the limit n→∞) is related to these constructions. The value 0.38 ≈ 19/50 is close to but not exactly a simple fraction.

Let me formalize:
- delta_i[k] = change in overlap_k when h[i] goes from 1 to 0 (all else fixed)
- delta_j[k] = change in overlap_k when h[j] goes from 0 to 1 (all else fixed)

For a swap (i,j):
- If i and j are "far" (|i-j| > max critical shift), then delta_{i,j}[k] ≈ delta_i[k] + delta_j[k].
- If they're close, there are interaction terms.

But actually, the delta for a swap is NOT simply the sum of individual deltas, because the individual deltas assume all other values are fixed, including the other variable being swapped.

Let me just do it properly:
- delta_remove_i[k] = change when h[i]: 1→0 (with h[j] still at its current value)
- delta_add_j[k] = change when h[j]: 0→1 (with h[i] already at 0)

Then delta_swap[i,j][k] = delta_remove_i[k] + delta_add_j[k] (since we do them sequentially).

But delta_add_j depends on h[i]=0 (the new value), so it's different from the "individual" delta.

The difference is:
- In delta_add_j (individual): h[i] is still 1. So if j+k=i or j-k=i, the computation uses h[i]=1.
- In delta_add_j (after removing i): h[i] is 0. So if j+k=i or j-k=i, the computation uses h[i]=0.

The difference only matters when |i-j| = |k| for some critical k. For most pairs (i,j) and shifts k, this doesn't happen.

So for an efficient approximate evaluation:
1. Precompute delta_remove[i, k] for all i (where h[i]=1) and all critical k.
2. Precompute delta_add[j, k] for all j (where h[j]=0) and all critical k.
3. For each pair (i,j): approx_delta[k] = delta_remove[i,k] + delta_add[j,k].
4. Score = max_k (A[k] + approx_delta[k]).
5. Take top M candidates, verify exactly.

The precomputation is O(n * |critical|) for each of delta_remove and delta_add.
The scoring is O(n_ones * n_zeros * |critical|) which for n_ones = n_zeros = n/2 = 303 and |critical| = 10 is about 303*303*10 ≈ 900K operations. That's fast!

def local_search_with_shifts(h, n, max_time, start_time, n_crit=12, top_m=80):
    h = h.copy()
    A = np.correlate(h, 1.0 - h, mode='full').astype(float)
    max_A = float(A.max())
    dx = 2.0 / n
    best_c5 = max_A * dx
    best_h = h.copy()
    stall = 0
    stall_limit = 300

    while time.time() - start_time < start_time + max_time:
        if stall > stall_limit:
            break

        ones_idx = np.where(h >= 0.5)[0]
        zeros_idx = np.where(h < 0.5)[0]
        n_ones = len(ones_idx)
        n_zeros = len(zeros_idx)

        if n_ones == 0 or n_zeros == 0:
            break

        max_val = float(A.max())
        critical = np.argsort(A)[-n_crit:]

        # Build candidate list: all (i,j) pairs plus shifts
        candidates = []
        for i in ones_idx:
            for j in zeros_idx:
                candidates.append((i, j))
            if i + 1 < n and h[i + 1] < 0.5:
                candidates.append((i, i + 1))
            if i - 1 >= 0 and h[i - 1] < 0.5:
                candidates.append((i, i - 1))

        if len(candidates) == 0:
            break

        # Score candidates using critical shifts
        A_crit = A[critical]
        n_crit_local = len(critical)
        n_cand = len(candidates)

        # Vectorize scoring for first min(n_cand, 5000) candidates
        verify_limit = min(n_cand, 5000)
        rng_local = np.random.RandomState(12345)
        if n_cand > verify_limit:
            sample = rng_local.choice(n_cand, verify_limit, replace=False)
        else:
            sample = np.arange(n_cand)

        best_improve = 0.0
        best_pair = None
        best_new_max = max_val

        for ci in sample:
            i, j = candidates[ci]
            if h[i] < 0.5 or h[j] >= 0.5:
                continue

            # Quick score on critical shifts
            max_score = -np.inf
            for ki, c in enumerate(critical):
                k = int(c)
                d = 0.0
                if 0 <= i + k < n:
                    d += (0.0 - h[i + k]) if (i + k == j) else (h[i + k] - 1.0)
                if 0 <= i - k < n:
                    d += h[i - k] if (i - k != j) else 1.0
                if 0 <= j + k < n:
                    d += (1.0 - 0.0) if (j + k == i) else (1.0 - h[j + k])
                if 0 <= j - k < n:
                    d += -(0.0) if (j - k == i) else (-h[j - k])
                val = A_crit[ki] + d
                if val > max_score:
                    max_score = val
                if max_score >= max_val:
                    break

            if max_score < best_new_max:
                best_new_max = max_score
                best_pair = (i, j)
                best_improve = max_val - max_score

        if best_pair is not None:
            i, j = best_pair
            h[i] = 0.0
            h[j] = 1.0
            A_new = np.correlate(h, 1.0 - h, mode='full').astype(float)
            new_max = float(A_new.max())
            if new_max < max_val - 1e-12:
                A = A_new
                max_val = new_max
                if max_val * dx < best_c5:
                    best_c5 = max_val * dx
                    best_h = h.copy()
                stall = 0
            else:
                h[i] = 1.0
                h[j] = 0.0
                stall += 1
        else:
            stall += 1

    return best_h, best_c5

def sa_binary(h, n, max_time, start_time, t_init=0.05, t_final=0.0001):
    h = h.copy()
    A = np.correlate(h, 1.0 - h, mode='full').astype(float)
    max_A = float(A.max())
    dx = 2.0 / n
    best_c5 = max_A * dx
    best_h = h.copy()
    current_c5 = best_c5
    rng = np.random.RandomState(777)
    stall = 0
    max_stall = 10000
    it = 0
    max_iters = 500000

    while time.time() - start_time < start_time + max_time and it < max_iters:
        it += 1
        if stall > max_stall:
            break
        ratio = min(1.0, it / max_iters)
        temp = t_init * (t_final / t_init) ** ratio

        ones_idx = np.where(h >= 0.5)[0]
        zeros_idx = np.where(h < 0.5)[0]
        if len(ones_idx) == 0 or len(zeros_idx) == 0:
            break

        r = rng.random()
        h_new = h.copy()
        moved = False
        if r < 0.6:
            i = int(ones_idx[rng.randint(len(ones_idx))])
            j = int(zeros_idx[rng.randint(len(zeros_idx))])
            h_new[i] = 0.0
            h_new[j] = 1.0
            moved = True
        elif r < 0.85:
            worst = np.argsort(A)[-5:]
            k = int(worst[rng.randint(len(worst))]) - (n - 1)
            ip = [i for i in ones_idx if 0 <= i + k < n]
            jp = [j for j in zeros_idx if 0 <= j + k < n]
            if len(ip) > 0 and len(jp) > 0:
                i = int(ip[rng.randint(len(ip))])
                j = int(jp[rng.randint(len(jp))])
                h_new[i] = 0.0
                h_new[j] = 1.0
                moved = True
        else:
            if len(ones_idx) >= 2 and len(zeros_idx) >= 2:
                i1, i2 = rng.choice(len(ones_idx), 2, replace=False)
                j1, j2 = rng.choice(len(zeros_idx), 2, replace=False)
                h_new[ones_idx[i1]] = 0.0
                h_new[ones_idx[i2]] = 0.0
                h_new[zeros_idx[j1]] = 1.0
                h_new[zeros_idx[j2]] = 1.0
                moved = True

        if not moved:
            stall += 1
            continue

        A_new = np.correlate(h_new, 1.0 - h_new, mode='full').astype(float)
        c5_new = float(A_new.max()) * dx
        delta = c5_new - current_c5

        if delta < 0 or (temp > 1e-15 and rng.random() < np.exp(-delta / max(temp, 1e-15))):
            h = h_new
            A = A_new
            current_c5 = c5_new
            if c5_new < best_c5:
                best_c5 = c5_new
                best_h = h.copy()
                stall = 0
            else:
                stall += 1
        else:
            stall += 1

    return best_h, best_c5

def continuous_refine(h_start, n, target, max_time, start_time, alphas=None, lr=0.003):
    if alphas is None:
        alphas = [200, 500, 1500, 4000, 10000, 30000, 80000]
    h = h_start.copy()
    m = np.zeros(n)
    v = np.zeros(n)
    t = 0
    beta1, beta2, eps = 0.9, 0.999, 1e-8
    best_h = h.copy()
    best_score = compute_c5(h)

    for alpha in alphas:
        if time.time() - start_time > start_time + max_time:
            break
        m = np.zeros(n)
        v = np.zeros(n)
        t = 0
        stall = 0
        local_best = float('inf')

        while time.time() - start_time < start_time + max_time and t < 5000:
            t += 1
            corr = np.correlate(h, 1.0 - h, mode='full')
            c_max = float(np.max(corr))
            shifted = np.clip(alpha * (corr - c_max), -500.0, 0.0)
            exp_vals = np.exp(shifted)
            w_sum = float(np.sum(exp_vals))
            weights = exp_vals / w_sum
            val = c_max + np.log(w_sum) / alpha

            if val < local_best - 1e-10:
                local_best = val
                stall = 0
            else:
                stall += 1
            if stall > 200:
                break

            grad = np.zeros(n)
            one_minus_h = 1.0 - h
            for s in range(n):
                w = weights[n - 1 + s]
                if w < 1e-12:
                    continue
                grad[:n - s] += w * one_minus_h[s:]
                if s > 0:
                    grad[s:] -= w * h[:n - s]
            for p in range(1, n):
                w = weights[n - 1 - p]
                if w < 1e-12:
                    continue
                grad[p:] += w * one_minus_h[:n - p]
                grad[:n - p] -= w * h[p:]

            m = beta1 * m + (1.0 - beta1) * grad
            v = beta2 * v + (1.0 - beta2) * (grad * grad)
            m_hat = m / (1.0 - beta1 ** t)
            v_hat = v / (1.0 - beta2 ** t)
            h_new = h - lr * m_hat / (np.sqrt(v_hat) + eps)
            h = project_box_sum(h_new, target)

        actual = compute_c5(h)
        if actual < best_score:
            best_score = actual
            best_h = h.copy()

    return best_h, best_score

def make_random_binary(n, rng):
    h = np.zeros(n)
    idx = rng.choice(n, n // 2, replace=False)
    h[idx] = 1.0
    return h

def make_structured_binary(n, rng):
    target = n // 2
    h = np.zeros(n)
    # Try several structures and pick the best
    best_h = None
    best_c5 = float('inf')

    # Structure 1: Two intervals
    for _ in range(20):
        L1 = rng.randint(n // 8, n // 2)
        L2 = target - L1
        if L2 <= 0 or L1 <= 0:
            continue
        a1 = rng.randint(0, max(1, n - L1))
        a2 = rng.randint(0, max(1, n - L2))
        h_temp = np.zeros(n)
        h_temp[a1:a1 + L1] = 1.0
        h_temp[a2:a2 + L2] = 1.0
        actual_sum = int(h_temp.sum())
        if actual_sum != target:
            # Adjust
            if actual_sum > target:
                ones = np.where(h_temp == 1)[0]
                to_remove = rng.choice(ones, actual_sum - target, replace=False)
                h_temp[to_remove] = 0.0
            else:
                zeros = np.where(h_temp == 0)[0]
                to_add = rng.choice(zeros, target - actual_sum, replace=False)
                h_temp[to_add] = 1.0
        c5 = compute_c5(h_temp)
        if c5 < best_c5:
            best_c5 = c5
            best_h = h_temp.copy()

    # Structure 2: Periodic-ish pattern
    for period in range(max(3, n // 30), max(4, n // 10)):
        duty = target / n
        h_temp = np.zeros(n)
        for i in range(n):
            phase = (i % period) / period
            if phase < duty:
                h_temp[i] = 1.0
        # Adjust to exact count
        actual_sum = int(h_temp.sum())
        if actual_sum > target:
            ones = np.where(h_temp == 1)[0]
            to_remove = rng.choice(ones, actual_sum - target, replace=False)
            h_temp[to_remove] = 0.0
        elif actual_sum < target:
            zeros = np.where(h_temp == 0)[0]
            to_add = rng.choice(zeros, target - actual_sum, replace=False)
            h_temp[to_add] = 1.0
        c5 = compute_c5(h_temp)
        if c5 < best_c5:
            best_c5 = c5
            best_h = h_temp.copy()

    # Structure 3: Random
    for _ in range(10):
        h_temp = make_random_binary(n, rng)
        c5 = compute_c5(h_temp)
        if c5 < best_c5:
            best_c5 = c5
            best_h = h_temp.copy()

    if best_h is None:
        best_h = make_random_binary(n, rng)
        best_c5 = compute_c5(best_h)

    return best_h, best_c5

def _smooth_slsqp_obj(h, alpha):
    corr = np.correlate(h, 1.0 - h, mode='full')
    c_max = float(np.max(corr))
    shifted = np.clip(alpha * (corr - c_max), -500.0, 0.0)
    return c_max + float(np.log(np.sum(np.exp(shifted))) / alpha)

def slsqp_polish(h_start, n, target, max_time, start_time):
    global _slsqp_n, _slsqp_target
    _slsqp_n = n
    _slsqp_target = target
    bounds = [(0.0, 1.0)] * n
    alphas = [3000, 10000, 30000, 80000, 200000]
    h_cur = h_start.copy()
    curr_score = compute_c5(h_cur)
    for alpha in alphas:
        if time.time() - start_time > start_time + max_time:
            break
        try:
            res = minimize(_smooth_slsqp_obj, h_cur, args=(alpha,),
                           method='SLSQP', bounds=bounds,
                           constraints=[{'type': 'eq', 'fun': _slsqp_cons, 'jac': _slsqp_jac}],
                           options={'maxiter': 2000, 'ftol': 1e-18})
            h_new = project_box_sum(res.x, target)
            sc = compute_c5(h_new)
            if sc < curr_score:
                curr_score = sc
                h_cur = h_new
        except Exception:
            pass
    return h_cur, curr_score

def run(seed=42, budget_s=1300, **kwargs):
    global _slsqp_n, _slsqp_target
    start_time = time.time()
    rng = np.random.RandomState(seed)

    def tleft():
        return max(0.0, budget_s - 30.0 - (time.time() - start_time))

    # Get initial solution
    try:
        h_init = np.array(initial_h_values, dtype=float)
        n = len(h_init)
    except NameError:
        n = 606
        h_init = None

    target = float(n) / 2.0
    best_h = None
    best_score = float('inf')

    # Phase 0: Get a good starting point
    if h_init is not None:
        h_bin = project_binary(h_init, int(target))
    else:
        h_bin, _ = make_structured_binary(n, rng)

    best_h = h_bin.copy()
    best_score = compute_c5(best_h)

    # Phase 1: Scored binary local search (main workhorse)
    if tleft() > 100:
        t1_time = min(400, tleft() * 0.35)
        h1, s1 = local_search_scored(best_h, n, t1_time, start_time, n_crit=15, top_m=120)
        if s1 < best_score:
            best_score = s1
            best_h = h1.copy()

    # Phase 2: Local search with shifts
    if tleft() > 80:
        t2_time = min(200, tleft() * 0.2)
        h2, s2 = local_search_with_shifts(best_h, n, t2_time, start_time, n_crit=12, top_m=100)
        if s2 < best_score:
            best_score = s2
            best_h = h2.copy()

    # Phase 3: Continuous refinement
    if tleft() > 60:
        t3_time = min(250, tleft() * 0.25)
        h3, s3 = continuous_refine(best_h, n, target, t3_time, start_time,
                                    alphas=[300, 1000, 3000, 10000, 30000, 80000, 200000],
                                    lr=0.003)
        # Also try binary projection of continuous solution
        h3_bin = project_binary(h3, int(target))
        s3_bin = compute_c5(h3_bin)
        if s3 < best_score:
            best_score = s3
            best_h = h3.copy()
        if s3_bin < best_score:
            best_score = s3_bin
            best_h = h3_bin.copy()

    # Phase 4: Local search on the new binary solution
    if tleft() > 50:
        h_bin4 = project_binary(best_h, int(target))
        t4_time = min(200, tleft() * 0.2)
        h4, s4 = local_search_scored(h_bin4, n, t4_time, start_time, n_crit=20, top_m=150)
        if s4 < best_score:
            best_score = s4
            best_h = h4.copy()

    # Phase 5: Simulated annealing for escape
    if tleft() > 60:
        h_bin5 = project_binary(best_h, int(target))
        t5_time = min(150, tleft() * 0.2)
        h5, s5 = sa_binary(h_bin5, n, t5_time, start_time, t_init=0.03, t_final=0.00001)
        if s5 < best_score:
            best_score = s5
            best_h = h5.copy()

    # Phase 6: Restart with perturbation and local search
    if tleft() > 80:
        for restart_i in range(3):
            if tleft() < 30:
                break
            jitter = 0.01 + 0.005 * restart_i
            h_pert = best_h + rng.randn(n) * jitter
            h_pert = project_box_sum(h_pert, target)
            h_pert_bin = project_binary(h_pert, int(target))
            rt = min(80, (tleft() - 30) / max(1, 3 - restart_i))
            hr, sr = local_search_scored(h_pert_bin, n, rt, start_time, n_crit=15, top_m=100)
            if sr < best_score:
                best_score = sr
                best_h = hr.copy()

    # Phase 7: SLSQP polish on continuous
    if tleft() > 40:
        t7_time = min(100, tleft() - 20)
        h7, s7 = slsqp_polish(best_h, n, target, t7_time, start_time)
        if s7 < best_score:
            best_score = s7
            best_h = h7.copy()
        h7_bin = project_binary(h7, int(target))
        s7_bin = compute_c5(h7_bin)
        if s7_bin < best_score:
            best_score = s7_bin
            best_h = h7_bin.copy()

    # Phase 8: Final local search on best binary
    if tleft() > 20:
        h_final_bin = project_binary(best_h, int(target))
        tf_time = max(5.0, tleft() - 10)
        hf, sf = local_search_scored(h_final_bin, n, tf_time, start_time, n_crit=20, top_m=150)
        if sf < best_score:
            best_score = sf
            best_h = hf.copy()

    # Final: ensure feasibility
    h_out = project_box_sum(best_h, target)
    s_out = compute_c5(h_out)
    if s_out > best_score:
        h_out = project_binary(best_h, int(target))
        s_out = compute_c5(h_out)

    return h_out, s_out, n
