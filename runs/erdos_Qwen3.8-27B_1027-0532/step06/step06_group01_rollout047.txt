  And for box constraints: if 0 < h[j] < 1, the above holds; if h[j]=0, the component is ≥ 0; if h[j]=1, the component is ≤ 0.

This is a complementarity problem. We can solve it iteratively:
1. Start with an active set A
2. Solve the subproblem: minimize C₅ subject to f(kᵢ) ≤ C₅ for i in A, sum(h)=target, 0≤h≤1
   (This is a non-linear program due to the product terms in f)
3. Update A: add any k where f(k) > C₅ + ε
4. Repeat

But step 2 is still non-linear. However, if we linearize f(kᵢ) ≈ f(kᵢ) + ∇f(kᵢ)·(h-h₀), we get a linear program!

This is the **cutting-plane / Kelley's cutting-plane method** approach:
1. At point h₀, compute all f(k) and their gradients
2. The active set is {k : f(k) ≥ max - ε}
3. Solve LP: minimize t subject to:
   - f(kᵢ) + ∇f(kᵢ)·(h-h₀) ≤ t for i in active set
   - sum(h) = target
   - 0 ≤ h ≤ 1
4. The new h* is the LP solution
5. Go to step 1

This is actually very promising! Let me implement it.

The LP has:
- Variables: h[0], ..., h[n-1], t → n+1 variables
- Constraints:
  - For each active k: Σᵢ ∂f(k)/∂h[i] · h[i] ≤ t + f(k) - Σᵢ ∂f(k)/∂h[i] · h₀[i]
  - sum(h) = target
  - 0 ≤ h[i] ≤ 1
  - t is free (or t ≥ 0)

This is a standard LP that can be solved with scipy.optimize.linprog or cvxpy.

For n=600 and ~50 active constraints, the LP has 601 variables and ~650 constraints. This should be fast.

The cutting-plane method should converge to the optimum of the convex relaxation. But wait - is the problem convex?

f(k) = Σᵢ h[i](1-h[i+k]) = Σᵢ h[i] - Σᵢ h[i]h[i+k]

The first term is linear in h. The second term Σᵢ h[i]h[i+k] is quadratic (bilinear). So f(k) is NOT convex in h.

However, the Hessian of f(k) w.r.t. h is:
∂²f(k)/∂h[j]∂h[l] = -(δ_{j,l+k} + δ_{j+k,l}) (for valid indices)

This is not positive semidefinite in general (it has both positive and negative eigenvalues). So the problem is non-convex.

The cutting-plane method would only give a lower bound on the minimum of the non-convex problem... Actually no, cutting-plane gives an upper bound on the minimum of a convex problem. For non-convex problems, it's not guaranteed to work.

```python
    start = time.time()
    dx = 2.0 / n
    h = h_init.copy()
    best_c5 = compute_c5(h)
    best_h = h.copy()
    n_corr = 2 * n - 1
    no_improve = 0
    idxs = np.arange(n)
    
    for sweep in range(100000):
        if time.time() - start > time_limit:
            break

        cur_max = float(np.max(corr))
        c5_val = cur_max * dx
        if c5_val < best_c5 - 1e-14:
            best_c5 = c5_val
            best_h = h.copy()
            no_improve = 0
        else:
            no_improve += 1
            if no_improve > 300:
                break
        
        # Top-m shifts
        top_m = np.argpartition(corr, -m)[-m:]
        top_m_corr = corr[top_m]
        w = np.exp(beta * (top_m_corr - cur_max))
        w /= w.sum()

        grad = np.zeros(n)
        for wi, si in zip(w, top_m):
            k = int(si) - (n - 1)

            v2 = (idxs + k >= 0) & (idxs + k < n)
            if np.any(v1):
                grad[v1] += wi * (1.0 - h[idxs[v1] - k])
            if np.any(v2):
                grad[v2] -= wi * h[idxs[v2] + k]
        
        # Find best pair swap
        sorted_by_grad = np.argsort(-grad)
        high_set = sorted_by_grad[:n_cand]
        low_set = sorted_by_grad[-n_cand:]

        all_cands = np.unique(np.concatenate([high_set, low_set]))
        n_c = len(all_cands)
        profiles = np.zeros((n_c, n_corr))
        for ci in range(n_c):
            mi = int(all_cands[ci])
            ks = np.arange(-(n-1), n)
            idx1 = mi - ks
            idx2 = mi + ks
            valid1 = (idx1 >= 0) & (idx1 < n)
            valid2 = (idx2 >= 0) & (idx2 < n)
            if np.any(valid1):
                profiles[ci, valid1] += h[idx1[valid1]]
            if np.any(valid2):
                profiles[ci, valid2] += h[idx2[valid2]]
        
        cand_pos = {int(all_cands[p]): p for p in range(n_c)}
        
        best_improve = 0.0
        best_i = -1
        best_j = -1
        best_delta = 0.0
        
        for i in high_set:
            hi_val = float(h[i])
            if hi_val < 1e-12:
                continue
            ci = cand_pos[int(i)]
            for j in low_set:
                if int(i) == int(j):
                    continue
                hj_val = float(h[j])
                delta_max = min(hi_val, 1.0 - hj_val)
                if delta_max < 1e-12:
                    continue
                cj = cand_pos[int(j)]
                g = profiles[ci] - profiles[cj]
                
                # Binary search for best delta
                lo = 0.0
                hi_d = delta_max
                for _ in range(20):
                    mid = 0.5 * (lo + hi_d)
                    vals = corr + mid * g
                    # Use top-m smoothed max
                    top = np.partition(vals, -m)[-m:]
                    tmax = float(np.max(top))

                    active = vals >= (tmax - 1e-12)

                    else:
                        f_prime = 0.0

                        hi_d = mid
                    else:
                        lo = mid
                
                delta_star = 0.5 * (lo + hi_d)
                if delta_star < 1e-10:
                    continue

                if improve > best_improve:

                    best_i = int(i)
                    best_j = int(j)
                    best_delta = delta_star
        
        if best_i >= 0 and best_improve > 1e-14:
            h[best_i] -= best_delta
            h[best_j] += best_delta
            h = np.clip(h, 0.0, 1.0)
            h = project_feasible(h, target)
    
    return best_h, best_c5
```

```python
import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr)) * dx

def project_feasible(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    diff = target_sum - np.sum(h)
    if abs(diff) < 1e-14:
        return h
    h = h.copy()
    if diff > 0:
        idx = np.where(h < 1.0 - 1e-10)[0]
    else:
        idx = np.where(h > 1e-10)[0]
    if len(idx) == 0:
        return h
    h[idx] += diff / len(idx)
    h = np.clip(h, 0.0, 1.0)
    residual = target_sum - np.sum(h)
    if abs(residual) > 1e-10:
        if residual > 0:
            idx2 = np.where(h < 1.0)[0]
        else:
            idx2 = np.where(h > 0.0)[0]
        if len(idx2) > 0:
            h[idx2] += residual / len(idx2)
            h = np.clip(h, 0.0, 1.0)
    return h

def lse_obj(x, alpha, target, penalty):
    corr = np.correlate(x, 1.0 - x, mode='full')
    c_max = np.max(corr)
    shifted = np.clip(alpha * (corr - c_max), -500.0, 0.0)
    lse = c_max + np.log(np.sum(np.exp(shifted))) / alpha
    pen = penalty * (np.sum(x) - target) ** 2
    return lse + pen

def lse_grad(x, alpha, target, penalty, n_active=200):
    corr = np.correlate(x, 1.0 - x, mode='full')
    c_max = np.max(corr)
    if n_active < len(corr):
        top_idx = np.argpartition(corr, -n_active)[-n_active:]
    else:
        top_idx = np.arange(len(corr))
    top_corr = corr[top_idx]
    shifted = np.clip(alpha * (top_corr - c_max), -500.0, 0.0)
    weights = np.exp(shifted)
    wsum = weights.sum()
    if wsum < 1e-30:
        weights = np.ones(len(top_idx)) / len(top_idx)
    else:
        weights /= wsum
    
    n = len(x)
    mid = n - 1
    idxs = np.arange(n)
    grad = np.zeros(n)
    for w, ci in zip(weights, top_idx):
        if w < 1e-12:
            continue
        k = int(ci) - mid
        v1 = (idxs - k >= 0) & (idxs - k < n)
        v2 = (idxs + k >= 0) & (idxs + k < n)
        if np.any(v1):
            grad[v1] += w * (1.0 - x[idxs[v1] - k])
        if np.any(v2):
            grad[v2] -= w * x[idxs[v2] + k]
    grad += 2.0 * penalty * (np.sum(x) - target)
    return grad

def lbfgsb_round(h_start, n, target, alphas, maxiter, ftol):
    bounds = [(0.0, 1.0)] * n
    h_cur = h_start.copy()
    best_h = h_cur.copy()
    best_c5 = compute_c5(h_cur)
    for alpha in alphas:
        penalty = 100.0
        try:
            res = minimize(lse_obj, h_cur, args=(alpha, target, penalty),
                          jac=lambda x, a, t, p: lse_grad(x, a, t, p, 200),
                          method='L-BFGS-B', bounds=bounds,
                          options={'maxiter': maxiter, 'ftol': ftol, 'gtol': 1e-8})
            h_new = project_feasible(res.x, target)
            c5_new = compute_c5(h_new)
            if c5_new < best_c5:
                best_c5 = c5_new
                best_h = h_new.copy()
            h_cur = h_new
        except Exception:
            pass
    return best_h, best_c5
```

```python
    shifted = np.clip(_LBFGS_ALPHA * (top_corr - c_max), -500.0, 0.0)
    weights = np.exp(shifted)
    wsum = weights.sum()
    if wsum < 1e-30:
        weights = np.ones(len(top_idx)) / len(top_idx)
    else:
        weights /= wsum
    n = len(x)
    mid = n - 1
    idxs = np.arange(n)
    grad = np.zeros(n)
    for w, ci in zip(weights, top_idx):
        if w < 1e-12:
            continue
        k = int(ci) - mid
        v1 = (idxs - k >= 0) & (idxs - k < n)
        v2 = (idxs + k >= 0) & (idxs + k < n)
        if np.any(v1):
            grad[v1] += w * (1.0 - x[idxs[v1] - k])
        if np.any(v2):
            grad[v2] -= w * x[idxs[v2] + k]
    grad += 2.0 * _LBFGS_PENALTY * (np.sum(x) - _LBFGS_TARGET)
    return grad

def lbfgsb_round(h_start, n, target, alphas, maxiter=300, ftol=1e-16):
    global _LBFGS_ALPHA, _LBFGS_TARGET, _LBFGS_PENALTY, _LBFGS_NACTIVE
    bounds = [(0.0, 1.0)] * n
    h_cur = h_start.copy()
    best_h = h_cur.copy()
    best_c5 = compute_c5(h_cur)
    for alpha in alphas:
        _LBFGS_ALPHA = alpha
        _LBFGS_TARGET = target
        _LBFGS_PENALTY = 200.0
        _LBFGS_NACTIVE = 200
        try:
            res = minimize(_lbfgs_obj, h_cur, jac=_lbfgs_grad,
                          method='L-BFGS-B', bounds=bounds,
                          options={'maxiter': maxiter, 'ftol': ftol, 'gtol': 1e-9})
            h_new = project_feasible(res.x, target)
            c5_new = compute_c5(h_new)
            if c5_new < best_c5:
                best_c5 = c5_new
                best_h = h_new.copy()
            h_cur = h_new
        except Exception:
            pass
        _LBFGS_NACTIVE = min(300, int(alpha * 0.5) + 50)
    return best_h, best_c5

def topm_pair_cd(h_init, n, target, time_limit, m=5, n_cand=30, max_sweeps=50000):
    start = time.time()
    dx = 2.0 / n
    h = h_init.copy()
    best_c5 = compute_c5(h)
    best_h = h.copy()
    n_corr = 2 * n - 1
    no_improve = 0
    idxs = np.arange(n)
    ks = np.arange(-(n - 1), n)

    for sweep in range(max_sweeps):
        if time.time() - start > time_limit:
            break

        corr = np.correlate(h, 1.0 - h, mode='full')
        cur_max = float(np.max(corr))
        c5_val = cur_max * dx
        if c5_val < best_c5 - 1e-14:
            best_c5 = c5_val
            best_h = h.copy()
            no_improve = 0
        else:
            no_improve += 1
            if no_improve > 400:
                break

        top_m = np.argpartition(corr, -m)[-m:]
        top_m_corr = corr[top_m]
        beta_w = 30.0
        w = np.exp(beta_w * (top_m_corr - cur_max))
        w /= w.sum()

        grad = np.zeros(n)
        for wi, si in zip(w, top_m):
            k = int(si) - (n - 1)
            v1 = (idxs - k >= 0) & (idxs - k < n)
            v2 = (idxs + k >= 0) & (idxs + k < n)
            if np.any(v1):
                grad[v1] += wi * (1.0 - h[idxs[v1] - k])
            if np.any(v2):
                grad[v2] -= wi * h[idxs[v2] + k]

        sorted_by_grad = np.argsort(-grad)
        high_set = sorted_by_grad[:n_cand]
        low_set = sorted_by_grad[-n_cand:]
        all_cands = np.unique(np.concatenate([high_set, low_set]))
        n_c = len(all_cands)
        profiles = np.zeros((n_c, n_corr))
        for ci in range(n_c):
            mi = int(all_cands[ci])
            idx1 = mi - ks
            idx2 = mi + ks
            valid1 = (idx1 >= 0) & (idx1 < n)
            valid2 = (idx2 >= 0) & (idx2 < n)
            if np.any(valid1):
                profiles[ci, valid1] += h[idx1[valid1]]
            if np.any(valid2):
                profiles[ci, valid2] += h[idx2[valid2]]

        cand_pos = {}
        for p in range(n_c):
            cand_pos[int(all_cands[p])] = p

        best_improve = 0.0
        best_i = -1
        best_j = -1
        best_delta = 0.0

        for i in high_set:
            hi_val = float(h[i])
            if hi_val < 1e-12:
                continue
            ci = cand_pos[int(i)]
            for j in low_set:
                if int(i) == int(j):
                    continue
                hj_val = float(h[j])
                delta_max = min(hi_val, 1.0 - hj_val)
                if delta_max < 1e-12:
                    continue
                cj = cand_pos[int(j)]
                g = profiles[ci] - profiles[cj]

                lo = 0.0
                hi_d = delta_max
                for _ in range(18):
                    mid = 0.5 * (lo + hi_d)
                    vals = corr + mid * g
                    f_mid = float(np.max(vals))
                    active = vals >= (f_mid - 1e-10)
                    if not np.any(active):
                        break
                    f_prime = float(np.max(g[active]))
                    if f_prime > 1e-10:
                        hi_d = mid
                    else:
                        lo = mid

                delta_star = 0.5 * (lo + hi_d)
                if delta_star < 1e-10:
                    continue

                new_max = float(np.max(corr + delta_star * g))
                improve = cur_max - new_max
                if improve > best_improve:
                    best_improve = improve
                    best_i = int(i)
                    best_j = int(j)
                    best_delta = delta_star

        if best_i >= 0 and best_improve > 1e-13:
            h[best_i] -= best_delta
            h[best_j] += best_delta
            h = np.clip(h, 0.0, 1.0)
            h = project_feasible(h, target)

    return best_h, best_c5

def block_swap_cd(h_init, n, target, time_limit, block_size=5, max_sweeps=20000):
    start = time.time()
    dx = 2.0 / n
    h = h_init.copy()
    best_c5 = compute_c5(h)
    best_h = h.copy()
    n_corr = 2 * n - 1
    no_improve = 0
    idxs = np.arange(n)
    ks = np.arange(-(n - 1), n)

    for sweep in range(max_sweeps):
        if time.time() - start > time_limit:
            break

        corr = np.correlate(h, 1.0 - h, mode='full')
        cur_max = float(np.max(corr))
        c5_val = cur_max * dx
        if c5_val < best_c5 - 1e-14:
            best_c5 = c5_val
            best_h = h.copy()
            no_improve = 0
        else:
            no_improve += 1
            if no_improve > 200:
                break

        k_star = int(np.argmax(corr)) - (n - 1)
        grad = np.zeros(n)
        v1 = (idxs - k_star >= 0) & (idxs - k_star < n)
        v2 = (idxs + k_star >= 0) & (idxs + k_star < n)
        if np.any(v1):
            grad[v1] += (1.0 - h[idxs[v1] - k_star])
        if np.any(v2):
            grad[v2] -= h[idxs[v2] + k_star]

        n_blocks = n - block_size + 1
        block_grads = np.zeros(n_blocks)
        block_mins = np.zeros(n_blocks)
        block_maxs = np.zeros(n_blocks)
        for b in range(n_blocks):
            bidx = np.arange(b, b + block_size)
            block_grads[b] = grad[bidx].sum()
            block_mins[b] = h[bidx].min()
            block_maxs[b] = 1.0 - h[bidx].max()

        dec_candidates = np.where((block_grads < -1e-8) & (block_mins > 1e-4))[0]
        inc_candidates = np.where((block_grads > 1e-8) & (block_maxs > 1e-4))[0]

        if len(dec_candidates) == 0 or len(inc_candidates) == 0:
            no_improve = no_improve + 5
            continue

        top_dec = dec_candidates[np.argsort(block_grads[dec_candidates])[:15]]
        top_inc = inc_candidates[np.argsort(-block_grads[inc_candidates])[:15]]

        best_improve = 0.0
        best_dec_b = -1
        best_inc_b = -1
        best_delta = 0.0

        for db in top_dec:
            for ib in top_inc:
                if ib <= db + block_size or db <= ib + block_size:
                    continue
                d_max = min(h[np.arange(db, db+block_size)].min(), 1e-2)
                i_max = min(1.0 - h[np.arange(ib, ib+block_size)].max(), 1e-2)
                delta_max = min(d_max, i_max)
                if delta_max < 1e-6:
                    continue

                dec_idx = np.arange(db, db + block_size)
                inc_idx = np.arange(ib, ib + block_size)
                g = np.zeros(n_corr)
                for di in dec_idx:
                    idx1 = int(di) - ks
                    idx2 = int(di) + ks
                    va1 = (idx1 >= 0) & (idx1 < n)
                    va2 = (idx2 >= 0) & (idx2 < n)
                    if np.any(va1):
                        g[va1] -= h[idx1[va1]]
                    if np.any(va2):
                        g[va2] -= h[idx2[va2]]
                for ii in inc_idx:
                    idx1 = int(ii) - ks
                    idx2 = int(ii) + ks
                    va1 = (idx1 >= 0) & (idx1 < n)
                    va2 = (idx2 >= 0) & (idx2 < n)
                    if np.any(va1):
                        g[va1] += h[idx1[va1]]
                    if np.any(va2):
                        g[va2] += h[idx2[va2]]

                new_max = float(np.max(corr + delta_max * g))
                improve = cur_max - new_max
                if improve > best_improve:
                    best_improve = improve
                    best_dec_b = int(db)
                    best_inc_b = int(ib)
                    best_delta = delta_max

        if best_dec_b >= 0 and best_improve > 1e-12:
            dec_idx = np.arange(best_dec_b, best_dec_b + block_size)
            inc_idx = np.arange(best_inc_b, best_inc_b + block_size)
            h[dec_idx] -= best_delta
            h[inc_idx] += best_delta
            h = np.clip(h, 0.0, 1.0)
            h = project_feasible(h, target)

    return best_h, best_c5

def random_restart_optimize(h_best, n, target, time_per_restart, n_restarts=3, noise_scale=0.1):
    start = time.time()
    best_h = h_best.copy()
    best_c5 = compute_c5(h_best)
    bounds = [(0.0, 1.0)] * n

    for r in range(n_restarts):
        if time.time() - start > time_per_restart * n_restarts - 30:
            break
        elapsed = time.time() - start
        if time_per_restart * n_restarts - elapsed < 40:
            break
        np.random.seed(1000 + r * 7)
        noise = np.random.randn(n) * noise_scale
        h_pert = project_feasible(h_best + noise, target)
        start_r = time.time()
        avail = min(time_per_restart, time_per_restart * n_restarts - (time.time() - start))
        g_alpha = 5000.0
        g_target = target
        g_pen = 200.0
        g_na = 200
        _LBFGS_ALPHA = g_alpha
        _LBFGS_TARGET = g_target
        _LBFGS_PENALTY = g_pen
        _LBFGS_NACTIVE = g_na
        try:
            res = minimize(_lbfgs_obj, h_pert, jac=_lbfgs_grad,
                          method='L-BFGS-B', bounds=bounds,
                          options={'maxiter': 200, 'ftol': 1e-16})
            h_new = project_feasible(res.x, target)
        except Exception:
            h_new = h_pert
        c5_new = compute_c5(h_new)
        if c5_new < best_c5:
            best_c5 = c5_new
            best_h = h_new.copy()

    return best_h, best_c5

def interpolate_to(h_src, n_dst, target_dst):
    n_src = len(h_src)
    if n_src == n_dst:
        return project_feasible(h_src.copy(), target_dst)
    x_new = np.linspace(0.0, 1.0, n_dst)
    x_old = np.linspace(0.0, 1.0, n_src)
    h_out = np.interp(x_new, x_old, h_src)
    return project_feasible(h_out, target_dst)

def run(seed=42, budget_s=1300, **kwargs):
    start_time = time.time()

    def tleft():
        return budget_s - 20.0 - (time.time() - start_time)

    np.random.seed(seed)
    h_init = np.array(initial_h_values, dtype=float)
    n = len(h_init)
    target = n / 2.0

    best_h = project_feasible(h_init, target)
    best_score = compute_c5(best_h)

    # Phase 1: L-BFGS-B with increasing alpha
    if tleft() > 120:
        hp, sc = lbfgsb_round(best_h, n, target, [30, 100, 500, 2000, 10000], maxiter=200)
        if sc < best_score:
            best_score = sc
            best_h = hp

    # Phase 2: Top-m pair CD
    if tleft() > 200:
        cd_time = min(250, tleft() * 0.25)
        hcd, c5cd = topm_pair_cd(best_h, n, target, time_limit=cd_time, m=5, n_cand=30)
        if c5cd < best_score:
            best_score = c5cd
            best_h = hcd

    # Phase 3: L-BFGS-B polish
    if tleft() > 80:
        hp, sc = lbfgsb_round(best_h, n, target, [5000, 20000, 100000], maxiter=150)
        if sc < best_score:
            best_score = sc
            best_h = hp

    # Phase 4: Top-m pair CD with more candidates
    if tleft() > 200:
        cd_time = min(200, tleft() * 0.2)
        hcd, c5cd = topm_pair_cd(best_h, n, target, time_limit=cd_time, m=10, n_cand=40)
        if c5cd < best_score:
            best_score = c5cd
            best_h = hcd

    # Phase 5: Block swap CD
    if tleft() > 120:
        btime = min(100, tleft() * 0.15)
        hb, c5b = block_swap_cd(best_h, n, target, time_limit=btime, block_size=5)
        if c5b < best_score:
            best_score = c5b
            best_h = hb

    # Phase 6: L-BFGS-B after block moves
    if tleft() > 60:
        hp, sc = lbfgsb_round(best_h, n, target, [5000, 50000], maxiter=100)
        if sc < best_score:
            best_score = sc
            best_h = hp

    # Phase 7: Random restarts
    if tleft() > 150:
        rtime = min(120, tleft() * 0.15)
        hr, c5r = random_restart_optimize(best_h, n, target, time_per_restart=rtime/3, n_restarts=3, noise_scale=0.08)
        if c5r < best_score:
            best_score = c5r
            best_h = hr

    # Phase 8: Final pair CD
    if tleft() > 100:
        cd_time = min(80, tleft() * 0.2)
        hcd, c5cd = topm_pair_cd(best_h, n, target, time_limit=cd_time, m=5, n_cand=35)
        if c5cd < best_score:
            best_score = c5cd
            best_h = hcd

    # Phase 9: Resolution sweep - try n-10 and n+10
    for dn in [10, -10]:
        if tleft() > 120:
            n_new = n + dn
            target_new = n_new / 2.0
            h_interp = interpolate_to(best_h, n_new, target_new)
            hp, sc = lbfgsb_round(h_interp, n_new, target_new, [500, 5000, 50000], maxiter=150)
            if tleft() > 60:
                hcd2, c5cd2 = topm_pair_cd(hp, n_new, target_new, time_limit=min(50, tleft()*0.3), m=5, n_cand=25)
                if c5cd2 < best_score:
                    best_score = c5cd2
                    best_h = hcd2
                    n = n_new
                    target = target_new
                elif sc < best_score:
                    best_score = sc
                    best_h = hp
                    n = n_new
                    target = target_new

    # Phase 10: Final L-BFGS-B polish
    if tleft() > 40:
        hp, sc = lbfgsb_round(best_h, n, target, [50000, 200000], maxiter=100)
        if sc < best_score:
            best_score = sc
            best_h = hp

    # Phase 11: Final pair CD
    if tleft() > 40:
        hcd, c5cd = topm_pair_cd(best_h, n, target, time_limit=min(30, tleft()*0.5), m=5, n_cand=30)
        if c5cd < best_score:
            best_score = c5cd
            best_h = hcd

    n_use = len(best_h)
    target_use = n_use / 2.0
    h_final = project_feasible(best_h, target_use)
    final_score = compute_c5(h_final)

    return h_final, final_score, n_use
```
