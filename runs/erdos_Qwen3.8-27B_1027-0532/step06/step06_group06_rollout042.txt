(where the second term is non-zero only when i = j - m + (n-1), i.e., i + m - (n-1) = j)

So: dcorr[m]/dh[j] = (1-h)[j + m - (n-1)] - h[j - m + (n-1)]

(in both cases, the index must be in [0, n-1], otherwise the term is 0)

And: d/dh_j [smooth_objective] = dx * sum_m w_m * [(1-h)[j + m - (n-1)] - h[j - m + (n-1)]]
+ 2 * penalty * (sum(h) - target)

Let me define r = m - (n-1) (the actual shift, ranges from -(n-1) to n-1).
Then: dcorr_r/dh[j] = (1-h)[j+r] - h[j-r] (with 0 for out-of-range)

And the gradient is:
grad[j] = dx * sum_r w_{r+(n-1)} * [(1-h)[j+r] - h[j-r]] + 2*penalty*(sum(h)-target)

This can be computed efficiently:
- sum_r w_{r+(n-1)} * (1-h)[j+r] = convolution of w with (1-h), evaluated at j
- sum_r w_{r+(n-1)} * h[j-r] = correlation of w with h, evaluated at j

Both can be done with FFT in O(n log n)!

Let me implement this:

```python
def smooth_gradient_fft(h, beta, target, penalty):
    N = len(h)
    dx = 2.0 / N
    corr = np.correlate(h, 1.0 - h, mode='full')
    c_max = float(corr.max())
    shifted = beta * (corr - c_max)
    shifted -= shifted.max()
    w = np.exp(shifted)
    w /= w.sum()
    
    # grad[j] = dx * [sum_r w[r] * (1-h)[j+r] - sum_r w[r] * h[j-r]] + 2*penalty*(sum-h-target)
    # where w is indexed by r from -(N-1) to N-1 (stored in corr indices 0 to 2N-2)
    
    # First term: sum_r w[r] * (1-h)[j+r]
    # This is the correlation of (1-h) with w, but we need to be careful about indexing.
    # corr_w[j] should be sum over valid r of w[r] * (1-h)[j+r]
    
    # Let's use np.correlate: np.correlate(a, v)[k] = sum_n a[n+k] * v[n]
    # We want: for each j, sum_r w[r_offset] * (1-h)[j+r] where r_offset = r + N - 1
    # Let a = (1-h), v = w (padded appropriately)
    
    # Actually, let me think about this differently.
    # Define w_shifted[r] for r in [-(N-1), N-1], stored as w[r + N - 1]
    # We want: T1[j] = sum_{r: j+r in [0,N-1]} w_shifted[r] * (1-h)[j+r]
    # This is a cross-correlation: T1 = correlate(1-h, w_shifted) type operation
    
    # Using np.correlate:
    # np.correlate(a, v, mode='full')[k] = sum_n a[n + k - (len(v)-1)] * v[n]
    # Hmm, the indexing is tricky. Let me just use FFT.
    
    # T1[j] = sum_r w[r+N-1] * (1-h)[j+r]
    # Let's define w_full as a vector of length 2N-1 with w_full[r+N-1] = w[r+N-1]
    # Then T1 = cross-correlation of (1-h) (length N) with w_full (length 2N-1)
    # T1[j] = sum_n (1-h)[n] * w_full[j - n + (2N-1)-1] ... this is getting confusing.
    
    # Let me just use direct computation with numpy broadcasting for clarity (n=606 is small enough)
    # T1[j] = sum_{valid r} w[j+r+N-1] * (1-h)[j+r] ... no wait.
    
    # Let me define it clearly:
    # corr[m] = sum_i h[i] * (1-h)[i + m - (N-1)] where all indices are valid
    # dcorr[m]/dh[j] = (1-h)[j + m - (N-1)] - h[j - m + (N-1)] (valid indices only)
    # 
    # grad[j] = dx * sum_{m=0}^{2N-2} w[m] * ((1-h)[j+m-(N-1)] - h[j-m+(N-1)])
    
    # Term A: sum_m w[m] * (1-h)[j+m-(N-1)]
    # Let r = m - (N-1), so m = r + (N-1), r ranges from -(N-1) to (N-1)
    # Term A = sum_r w[r+N-1] * (1-h)[j+r] (where j+r in [0,N-1])
    
    # This is: for each j, the weighted sum of (1-h) at positions j+r with weights w[r+N-1]
    # This is a convolution: (1-h) * w where w is centered at position 0
    # In numpy: T1 = np.convolve(1-h, w_centered, mode='same') ... but w has length 2N-1
    
    # Let me just do it directly for N=606 (it's O(N²) but fast enough)
    one_minus_h = 1.0 - h
    grad = np.zeros(N)
    r_vals = np.arange(-(N-1), N)  # r from -(N-1) to N-1
    w_vals = w  # w indexed by r + (N-1)
    
    for j in range(N):
        # Term A: sum over valid r of w[r+N-1] * (1-h)[j+r]
        valid = (j + r_vals >= 0) & (j + r_vals < N)
        if np.any(valid):
            term_a = np.dot(w_vals[valid], one_minus_h[j + r_vals[valid]])
        else:
            term_a = 0.0
        # Term B: sum over valid r of w[r+N-1] * h[j-r]
        valid2 = (j - r_vals >= 0) & (j - r_vals < N)
        if np.any(valid2):
            term_b = np.dot(w_vals[valid2], h[j - r_vals[valid2]])
        else:
            term_b = 0.0
        grad[j] = dx * (term_a - term_b)
    
    grad += 2.0 * penalty * (float(np.sum(h)) - target)
    return grad
```

This is O(N²) per gradient evaluation. For N=606, that's about 367K operations per element, times 606 elements = 222M operations. That might be slow in a Python loop.
