At each iteration:
1. Compute corr and find the active shift k*
2. Compute the subgradient g = df_{k*}/dh (O(n))
3. Take a step: h_new = h - step * g
4. Project h_new onto the feasible set {0≤h≤1, sum(h)=n/2}
5. Evaluate C₅(h_new); if improved, accept; otherwise decrease step

The step size can be set using the "generalized Polyak step size":
step = (f(h) - f_lb) / ||g||²

where f_lb is a lower bound on the optimum (we can use 0 or a better estimate).

This is very simple and each iteration is O(n) (for the subgradient) + O(n) (for the projection) + O(n²) (for the evaluation).

The convergence is O(1/t) for the average iterate, so after T iterations, the average of all iterates has objective ≤ f* + O(1/T).

def compute_change_matrix(h, n):
    n_corr = 2 * n - 1

        sc = compute_c5(h_final)
        if sc < best_score:
            best_score = sc
            best_h = h_final

    final_h = project_feasible(best_h, len(best_h) / 2.0)
    final_score = compute_c5(final_h)
    return final_h, final_score, len(final_h)
