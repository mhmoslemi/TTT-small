**Algorithm: Gradient equalization**
1. Compute the weighted subgradient g (using softmax weights)
2. For variables not at bounds (0 < h[j] < 1), we want g[j] to be equal
3. Adjust h to make g more uniform: h[j] += η * (g_mean - g[j]) for free variables
4. Project and check improvement

This is essentially what FW does, but without the "vertex" step.

The minimum of a max of linear functions occurs at an intersection point of two of the functions, or at a boundary (x=0 or x=1).

For n=400, there are 799 linear functions. The minimum of their max is at one of O(n²) intersection points, or at x=0 or x=1.

But we can do better: the minimum of max of linear functions f_i(x) = a_i + b_i * x occurs at:
- x = 0: value = max(a_i)
- x = 1: value = max(a_i + b_i)
- At intersection of f_p and f_q: x = (a_q - a_p) / (b_p - b_q) where f_p(x) = f_q(x) and f_p(x) ≥ f_i(x) for all i

For the intersection to be the minimum, we need it to be the "lowest point" of the upper envelope.

A simpler approach: binary search on the value C. For a given C, check if there exists x ∈ [0,1] such that a_ℓ + c_ℓ + x*(b_ℓ - c_ℓ) ≤ C for all ℓ. This is a linear feasibility problem in 1D, which can be solved by checking:
max_ℓ (C - a_ℓ - c_ℓ) / (b_ℓ - c_ℓ) ≤ x ≤ min_ℓ (C - a_ℓ - c_ℓ) / (-(b_ℓ - c_ℓ))
(for b_ℓ - c_ℓ > 0 and < 0 respectively)

This gives a range of valid x values. If the range is non-empty and intersects [0,1], then C is achievable.

So we can binary search on C to find the optimal value for coordinate j, and take the midpoint of the valid range as the new h[j].

This is an **exact coordinate descent** step! Each step gives the globally optimal h[j] (given all other coordinates fixed). This is much better than gradient-based methods.

    """Exact coordinate descent for the Eridos overlap problem."""
    start = time.time()
    dx = 2.0 / n
    n_lags = 2 * n - 1
    n_half = n - 1
    
    h = h_init.copy()
    best_c5 = compute_c5(h)
    best_h = h.copy()
    
    for sweep in range(max_passes):
        if time.time() - start > time_limit:
            break
        
        improved = False
        # Compute current overlaps
        overlaps = np.correlate(h, 1.0 - h, mode='full') * dx
        
        for j in range(n):
            # Compute a_lag, b_lag, c_lag for coordinate j
            # overlap_lag = a_lag + x * b_lag + (1-x) * c_lag
            # where x = h[j]
            
            # For each lag k (index in the full correlation), lag = k - n_half
            # The term involving h[j] in overlap_lag:
            # - If j is the "first" index (i = j): h[j] * (1 - h[j+lag]) for valid j+lag
            # - If j is the "second" index (i+lag = j, i = j-lag): h[j-lag] * (1 - h[j]) for valid j-lag
            
            # b_lag = (1 - h[j+lag]) if j+lag < n else 0
            # c_lag = h[j-lag] if j-lag >= 0 else 0
            # a_lag = overlap_lag - h[j]*b_lag - (1-h[j])*c_lag
            
            lags = np.arange(n_lags) - n_half  # shape (n_lags,)
            
            # b: (1 - h[j+lag]) where j+lag is in [0, n)
            j_plus_lag = j + lags  # shape (n_lags,)
            valid_plus = (j_plus_lag >= 0) & (j_plus_lag < n)
            b = np.zeros(n_lags)
            b[valid_plus] = 1.0 - h[j_plus_lag[valid_plus]]
            
            # c: h[j-lag] where j-lag is in [0, n)
            j_minus_lag = j - lags  # shape (n_lags,)
            valid_minus = (j_minus_lag >= 0) & (j_minus_lag < n)
            c = np.zeros(n_lags)
            c[valid_minus] = h[j_minus_lag[valid_minus]]
            
            # a: overlap - h[j]*b - (1-h[j])*c
            a = overlaps - h[j] * b - (1.0 - h[j]) * c
            
            # Now find x* = argmin_{x in [0,1]} max_lag (a_lag + x*b_lag + (1-x)*c_lag)
            # = argmin_{x in [0,1]} max_lag (a_lag + c_lag + x*(b_lag - c_lag))
            # Let d_lag = a_lag + c_lag, e_lag = b_lag - c_lag
            # We want: min_x max_lag (d_lag + x * e_lag)
            
            d = a + c
            e = b - c

            # - x = 1 if f'(1-) <= 0
