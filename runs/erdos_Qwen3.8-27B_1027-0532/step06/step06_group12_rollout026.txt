np.correlate(h, 1-h, mode='full'):
- Output has length 2n-1
- Output index j corresponds to lag k = j - (n-1)
- out[j] = sum_{m} h[m] * (1-h)[m-k] where k = j-(n-1)

Actually, the numpy correlate documentation says:
c_k = sum_n a[n+k] * conj(v[n])

So for a=h, v=1-h:
c_k = sum_n h[n+k] * (1-h[n])

where the sum is over all n such that 0<=n<N and 0<=n+k<N.

For mode='full', k ranges from -(len(v)-1) to len(a)-1, i.e., from -(N-1) to N-1.

So out[k + (N-1)] = c_k = sum_{n: max(0,-k) <= n <= min(N-1, N-1-k)} h[n+k] * (1-h[n])

Now, if h[a] changes by δ_a and h[b] changes by δ_b:

The terms involving h[a]:
- h[a] appears as h[n+k] when n+k=a, i.e., n=a-k. Valid if 0<=a-k<N and 0<=a<N.
  Since 0<=a<N always (a is a valid index), the condition is 0<=a-k<N.
  Contribution: δ_a * (1-h[a-k]) [times 1_{0<=a-k<N}]

- h[a] appears as h[n] when n=a. The term is h[n+k]*(1-h[n]) = h[a+k]*(1-h[a]).
  Change: h[a+k] * (-δ_a) [times 1_{0<=a+k<N}]
  Wait: (1-h[a]) becomes (1-(h[a]+δ_a)) = (1-h[a]-δ_a). So the change is h[a+k]*(-δ_a).
  Valid if 0<=a<N (always) and 0<=a+k<N.

So Δc_k from a: δ_a * (1-h[a-k]) * 1_{0<=a-k<N} + (-δ_a) * h[a+k] * 1_{0<=a+k<N}
= δ_a * [(1-h[a-k]) * 1_{0<=a-k<N} - h[a+k] * 1_{0<=a+k<N}]

For our swap (δ_a = -1, δ_b = +1):
Δc_k = -1 * [(1-h[a-k]) * 1_{0<=a-k<N} - h[a+k] * 1_{0<=a+k<N}]
     + 1 * [(1-h[b-k]) * 1_{0<=b-k<N} - h[b+k] * 1_{0<=b+k<N}]

Let me define:
f_a(k) = (1-h[a-k]) * 1_{0<=a-k<N} - h[a+k] * 1_{0<=a+k<N}
f_b(k) = (1-h[b-k]) * 1_{0<=b-k<N} - h[b+k] * 1_{0<=b+k<N}

Then Δc_k = -f_a(k) + f_b(k) = f_b(k) - f_a(k)

And the new max overlap is max_k (c_k + Δc_k).

For efficient computation:
- Precompute f_a(k) for all k: this is O(N) for a given a.
- For all b: Δc_k = f_b(k) - f_a(k), and we want max_k (c_k + f_b(k) - f_a(k))
  = max_k (c_k - f_a(k) + f_b(k))
  
  Let g(k) = c_k - f_a(k). Then for each b, we want max_k (g(k) + f_b(k)).
  
  This is a "max over k of (g + f_b)" which is like a max-plus convolution. Not trivially fast.

Alternative approach: just do it naively but vectorized.

For a given a, precompute f_a as an array of length 2N-1.
For a given b, compute f_b as an array of length 2N-1.
Then max_k (c_k + f_b(k) - f_a(k)) is just np.max(c + f_b - f_a).

Each f computation is O(N), and np.max is O(N). So per swap evaluation: O(N).
For all O(N²) swaps: O(N³) = 64M for N=400. In numpy, this should take about 1-2 seconds per full scan.

Actually, we can be even more efficient. For a fixed a, f_a is fixed. Then for all b:
Δc_k(b) = f_b(k) - f_a(k)

f_b(k) = (1-h[b-k]) * 1_{0<=b-k<N} - h[b+k] * 1_{0<=b+k<N}

Let me define:
left[b][k] = (1-h[b-k]) * 1_{0<=b-k<N} → this is (1-h)[b-k] if 0<=b-k<N, else 0 → this is the "reversed" (1-h) at position b-k
right[b][k] = h[b+k] * 1_{0<=b+k<N} → this is h[b+k] if 0<=b+k<N, else 0

So f_b(k) = left[b][k] - right[b][k]

For k > 0: left[b][k] = (1-h)[b-k] (if b>=k), right[b][k] = h[b+k] (if b+k<N)
For k < 0: let m=-k>0: left[b][k] = (1-h)[b+m] (if b+m<N), right[b][k] = h[b-m] (if b>=m)
For k = 0: left[b][0] = (1-h)[b], right[b][0] = h[b]

This is essentially a "profile" of position b. Let me think of it differently.

For a given b, f_b is a vector of length 2N-1 (indexed by k from -(N-1) to N-1):
f_b[k] = (1-h)[b-k] * 1_{0<=b-k<N} - h[b+k] * 1_{0<=b+k<N}

Let me reindex: let j = b-k, so k = b-j. Then:
f_b[b-j] = (1-h)[j] * 1_{0<=j<N} - h[2b-j] * 1_{0<=2b-j<N}

And also with k = b-j:
The second term: h[b+k] = h[b+(b-j)] = h[2b-j], valid if 0<=2b-j<N.

So f_b is determined by the values of h in certain ranges around b.

```python
def compute_f_vec(h, pos, n):
```

```python

from scipy.optimize import minimize
import time

def compute_corr(h):
    return np.correlate(h, 1.0 - h, mode='full')

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    return float(np.max(compute_corr(h))) * dx

def project_feasible(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    diff = target_sum - np.sum(h)
    if abs(diff) < 1e-14:
        return h
    if diff > 0:
        idx = np.where(h < 1.0 - 1e-10)[0]
    else:
        idx = np.where(h > 1e-10)[0]
    if len(idx) == 0:
        return h
    h = h.copy()
    h[idx] += diff / len(idx)
    h = np.clip(h, 0.0, 1.0)
    residual = target_sum - np.sum(h)
    if abs(residual) > 1e-10:
        if residual > 0:
            idx2 = np.where(h < 1.0)[0]
        else:
            idx2 = np.where(h > 0.0)[0]
        if len(idx2) > 0:
            h[idx2] += residual / len(idx2)
            h = np.clip(h, 0.0, 1.0)
    return h

def to_binary(h, n, target, rng):
    """Convert to binary with exactly target ones using eigenvalues of h"""
    h = np.round(h)
    n_ones = int(np.sum(h))
    if n_ones == target:
        return h.astype(float)
    if n_ones > target:
        ones = np.where(h == 1.0)[0]
        # Turn off ones with smallest original h value
        perm = np.argsort(h[ones])
        to_off = ones[perm[:n_ones - target]]
        h = h.copy()
        h[to_off] = 0.0
    else:
        zeros = np.where(h == 0.0)[0]
        perm = np.argsort(-h[zeros])
        to_on = zeros[perm[:target - n_ones]]
        h = h.copy()
        h[to_on] = 1.0
    return h

def compute_f_vec(h, pos, n):
    n_half = n - 1
    k = np.arange(-n_half, n_half + 1)
    pk = pos - k
    pk2 = pos + k
    left = np.where((pk >= 0) & (pk < n), 1.0 - h[np.clip(pk, 0, n-1)], 0.0)
    right = np.where((pk2 >= 0) & (pk2 < n), h[np.clip(pk2, 0, n-1)], 0.0)
    return left - right

def local_search_binary(h, n, target, max_rounds=50, time_limit=None, start_time=0):
    dx = 2.0 / n
    c = compute_corr(h)
    current_max = float(np.max(c))
    k_arr = np.arange(-(n-1), n)
    
    ones = np.where(h == 1.0)[0]
    zeros = np.where(h == 0.0)[0]
    
    rounds = 0
    while rounds < max_rounds:
        rounds += 1
        if time_limit and time.time() - start_time > time_limit:
            break
        if len(ones) == 0 or len(zeros) == 0:
            break
        
        best_new_max = current_max
        best_a, best_b = -1, -1
        
        for a in ones:
            f_a = compute_f_vec(h, a, n)
            bk = zeros[:, None] - k_arr[None, :]
            bk2 = zeros[:, None] + k_arr[None, :]
            left = np.where((bk >= 0) & (bk < n), 1.0 - h[np.clip(bk, 0, n-1)], 0.0)
            right = np.where((bk2 >= 0) & (bk2 < n), h[np.clip(bk2, 0, n-1)], 0.0)
            f_b_all = left - right
            
            new_maxes = np.max(c[None, :] + f_b_all - f_a[None, :], axis=1)
            min_idx = np.argmin(new_maxes)
            if new_maxes[min_idx] < best_new_max - 1e-10:
                best_new_max = new_maxes[min_idx]
                best_a = a
                best_b = zeros[min_idx]
        
        if best_a >= 0 and best_new_max < current_max - 1e-10:
            h[best_a] = 0.0
            h[best_b] = 1.0
            c = compute_corr(h)
            current_max = float(np.max(c))
            ones = np.where(h == 1.0)[0]
            zeros = np.where(h == 0.0)[0]
        else:
            break
    
    return h, current_max * dx

def simulated_annealing_binary(h, n, target, time_limit, start_time, rng, T_init=5.0, T_min=0.1, cooling=0.999):
    """Simulated annealing on binary solutions"""
    dx = 2.0 / n
    c = compute_corr(h)
    current_max = float(np.max(c))
    best_c5 = current_max * dx
    best_h = h.copy()
    
    ones = np.where(h == 1.0)[0]
    zeros = np.where(h == 0.0)[0]
    k_arr = np.arange(-(n-1), n)
    
    T = T_init
    step = 0
    while T > T_min:
        if time.time() - start_time > time_limit:
            break
        step += 1
        
        # Pick random a from ones, b from zeros
        a = ones[rng.randint(len(ones))]
        b = zeros[rng.randint(len(zeros))]
        
        f_a = compute_f_vec(h, a, n)
        f_b = compute_f_vec(h, b, n)
        delta = f_b - f_a
        new_max = float(np.max(c + delta))
        
        delta_max = new_max - current_max
        if delta_max < 0 or rng.rand() < np.exp(-delta_max / T):
            h[a] = 0.0
            h[b] = 1.0
            c = c + delta
            current_max = new_max
            ones = np.where(h == 1.0)[0]
            zeros = np.where(h == 0.0)[0]
            if current_max * dx < best_c5:
                best_c5 = current_max * dx
                best_h = h.copy()
        
        T *= cooling
        if step % 1000 == 0:
            T = max(T_min, T * 0.95)
    
    return best_h, best_c5
```

```python
def greedy_construct(n, target, rng):
    h = np.zeros(n)
    c = np.zeros(2*n - 1)  # current overlaps (raw)
    k_arr = np.arange(-(n-1), n)
    
    empty = np.arange(n)
    
    for step in range(target):
        if len(empty) == 0:
            break
        # Compute f_p for all empty positions
        pk = empty[:, None] - k_arr[None, :]  # (n_empty, 2n-1)
        pk2 = empty[:, None] + k_arr[None, :]
        left = np.where((pk >= 0) & (pk < n), 1.0 - h[np.clip(pk, 0, n-1)], 0.0)
        right = np.where((pk2 >= 0) & (pk2 < n), h[np.clip(pk2, 0, n-1)], 0.0)
        f_all = left - right  # (n_empty, 2n-1)
        
        new_maxes = np.max(c[None, :] + f_all, axis=1)
        best_idx = np.argmin(new_maxes)
        p = empty[best_idx]
        
        h[p] = 1.0
        c += f_all[best_idx]
        empty = np.delete(empty, best_idx)
    
    return h, np.max(c) * (2.0/n)
```

```python
    """Build left_profile and right_profile matrices, shape (n, 2n-1) each"""
    k_arr = np.arange(-(n-1), n)  # (2n-1,)
    # For position p, shift k:
    # left_profile[p, k_idx] = (1 - h[p-k]) if 0 <= p-k < n, else 0
    # right_profile[p, k_idx] = h[p+k] if 0 <= p+k < n, else 0
    
    # Vectorized:
    p = np.arange(n)[:, None]  # (n, 1)
    k = k_arr[None, :]  # (1, 2n-1)
    
    pk = p - k  # (n, 2n-1)
    pk2 = p + k  # (n, 2n-1)
    
    left = np.where((pk >= 0) & (pk < n), 1.0 - h[np.clip(pk, 0, n-1)], 0.0)
    right = np.where((pk2 >= 0) & (pk2 < n), h[np.clip(pk2, 0, n-1)], 0.0)
    
    return left, right  # each (n, 2n-1)
```
