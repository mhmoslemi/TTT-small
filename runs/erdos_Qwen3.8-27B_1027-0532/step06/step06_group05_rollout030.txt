c[k] = sum_i h[i] * (1 - h[i+k]) for valid i (0≤i<n, 0≤i+k<n)

When h[i] changes from 1 to 0:
- As first factor: c[k] loses (1-h[i+k]) if 0≤i+k<n
- As second factor (i+k = i, so the (1-h) term has index i): this means the sum index j satisfies j+k = i, so j = i-k.
  Contribution before: h[j]*(1-h[i]) = h[i-k]*(1-1) = 0
  Contribution after: h[i-k]*(1-0) = h[i-k]
  So c[k] GAINS h[i-k] if 0≤i-k<n

When h[j] changes from 0 to 1:
- As first factor: c[k] gains (1-h[j+k]) if 0≤j+k<n
- As second factor (j+k = j, so (1-h) term has index j): sum index i satisfies i+k = j, i = j-k
  Contribution before: h[j-k]*(1-0) = h[j-k]
  Contribution after: h[j-k]*(1-1) = 0
  So c[k] LOSES h[j-k] if 0≤j-k<n

Total: Δc[k] = -(1-h[i+k]) + h[i-k] + (1-h[j+k]) - h[j-k]
           = h[i+k] + h[i-k] - h[j+k] - h[j-k]

where h[t] = 0 for t<0 or t≥n. ✓
