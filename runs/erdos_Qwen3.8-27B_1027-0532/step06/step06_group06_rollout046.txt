def fft_convolve_real(a, b):
    """Compute convolution of two real arrays using FFT."""
    n = len(a) + len(b) - 1
    size = 1 << (n - 1).bit_length()

    fb = np.fft.rfft(b, size)

For a binary h, the correlation is:

For a swap (i: 1→0, j: 0→1):

Wait, let me re-derive. The correlation at shift s (where s = k-(n-1)):
corr_s = ∑_i h[i] * (1-h[i+s]) (with valid indices only)

Swap: h[i] changes from 1 to 0, h[j] changes from 0 to 1.

Effect on corr_s:
- Terms involving h[i] as the first factor: h[i] * (1-h[i+s]) changes from (1-h[i+s]) to 0. Delta: -(1-h[i+s]) = h[i+s]-1
- Terms involving h[i] as the second factor: h[i-s] * (1-h[i]) changes from h[i-s]*0 to h[i-s]*1. Delta: +h[i-s]
- Terms involving h[j] as the first factor: h[j] * (1-h[j+s]) changes from 0*(1-h[j+s]) to 1*(1-h[j+s]). Delta: +(1-h[j+s])
- Terms involving h[j] as the second factor: h[j-s] * (1-h[j]) changes from h[j-s]*1 to h[j-s]*0. Delta: -h[j-s]

Total delta_s = (h[i+s]-1) + h[i-s] + (1-h[j+s]) - h[j-s]

where h[x] = 0 for x < 0 or x >= n.

For the greedy approach:
1. Find the current max: s* = argmax_s corr_s, M = corr[s*]
2. For the best swap targeting s*:

   Let B_j = (1-h[j+s*]) - h[j-s*] for j in zeros
