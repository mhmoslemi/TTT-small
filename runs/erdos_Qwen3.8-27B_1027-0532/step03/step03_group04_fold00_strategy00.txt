We start with the given initial solution but introduce a new global exploration phase (Phase 0) using self-adaptive particle swarm optimization (PSO) to escape local optima. This is followed by three phases of refinement: a local gradient-based optimization (Phase 1), a ternary-resampling approach (Phase 2), and a final multi-resolution optimization (Phase 3). - Requires parameter tuning for PSO (inertia and cognitive weights)

- Overlap might vary with resolution changes

2. Mathematical Specification

- Representation: Piecewise constant function approximated by samples in [0,1] space with volume preservation.
- Objective: Minimize max_k `∫ h(x)(1-h(x+k)) dx` by scaling with discretization dx.
- Constraints:
  - 0 ≤ h(x) ≤ 1 for all x
  - ∫h(x) dx = 1 (discretized as sum/points * dx)
- Formulation:
  Local search: `∇compute_c5(h) + projected gradient`
  Global optimization: `Pareto-optimal tradeoffs between PSO inertia and system cusps`
