Actually, for the purpose of coordinate descent, at each step we fix all other coordinates and optimize over h[i]. The objective as a function of h[i] is:

where a_k and b_k are determined by the current values of all other coordinates. This IS a piecewise-linear convex function of h[i], and we can minimize it by finding the point where the "slope" changes from negative to positive.

The slope of the max at h[i] = x is the a_k of the active k (the one achieving the max at that x). As x increases, different k become active.

To find the minimum:
1. Compute a_k and b_k for all k
2. The function f(x) = max_k (a_k * x + b_k) is convex piecewise-linear
3. Its minimum is where the subgradient contains 0, i.e., where there exist k, k' with a_k ≤ 0 ≤ a_{k'} and a_k * x + b_k = a_{k'} * x + b_{k'}
4. Or at x = 0 or x = 1 if the function is monotone

So the algorithm is:
1. Compute a_k, b_k for all k (O(n) work, since each a_k involves at most 2 terms)
2. Find the minimum of max_k (a_k * x + b_k) on [0, 1]
   - This can be done by: find all breakpoints x* where two lines cross, evaluate f at each breakpoint plus 0 and 1, pick the minimum
   - Or more efficiently: the minimum of a max of lines is at a point where at least two lines are tied (or at a boundary)
   - We can use a "megiddo" style algorithm, or just do a binary search on the derivative

Actually, the simplest approach:

Actually, there's an even simpler approach. Since the function f(x) = max_k (a_k * x + b_k) is convex, we can use ternary search or binary search on the derivative.

The derivative (subgradient) at x is the set of a_k for all k that achieve the max at x. The minimum is where 0 is in the subgradient, or at a boundary.

Algorithm:
1. Evaluate f at x=0 and x=1
2. If f is increasing at 0 (all active a_k > 0), minimum is at 0
3. If f is decreasing at 1 (all active a_k < 0), minimum is at 1
4. Otherwise, binary search: find x where the subgradient transitions from negative to positive

For the binary search:
- At current x, find k* that achieves max
- If a_{k*} < 0, the function is decreasing at x, move right
- If a_{k*} > 0, the function is increasing at x, move left
- If a_{k*} = 0 (or there exist k, k' with a_k < 0 < a_{k'} both achieving max), we're at the minimum

This converges in O(log(1/eps)) iterations, each O(n) to evaluate.

def compute_influence(h, i):
    """Compute the slope of corr(m) with respect to h[i] for all lags m."""
    n = len(h)
    # For lag m (0-indexed from -(n-1) to n-1, or equivalently corr index 0 to 2n-2):
    # corr_idx = n-1+m
    # 
    # h[i] contributes to corr at:
    # - lag 0: coefficient (1-2*h[i]) [quadratic, approximate as (1-h[i])-h[i]]
    #   Actually exact: d/dx [x*(1-x)] at x=h[i] = 1-2*h[i]
    # - lag +m (m>0): h[i] appears as h[j+m] when j=i-m (if 0<=i-m<=n-1-m)
    #   coefficient: (1-h[i-m])
    #   h[i] appears as h[j] when j=i (if 0<=i<=n-1-m)
    #   coefficient: -h[i+m]
    # - lag -m (m>0): h[i] appears as h[j] when j=i (if m<=i<=n-1)
    #   coefficient: (1-h[i-m])
    #   h[i] appears as h[j-m] when j-m=i, j=i+m (if 0<=i<=n-1-m, i.e., i+m<=n-1)
    #   coefficient: -h[i+m]
    
    slopes = np.zeros(2*n-1)
    # lag 0 (index n-1)
    slopes[n-1] = 1.0 - 2.0 * h[i]  # This is the derivative, but we want the difference
    # Actually for coordinate descent, we want corr(k | h[i]=x) as a function of x
    # For lag 0: corr(0 | x) = sum_{j≠i} h[j](1-h[j]) + x(1-x) = B + x - x^2 where B = sum_{j≠i} h[j](1-h[j])
    # So it's not linear. But the change from x=old to x=new is:
    # (new-new²) - (old-old²) = (new-old)(1-new-old)
    
    # For lag m > 0 (index n-1+m):
    # corr(m | x) = A + x*(1-h[i-m]) * [m<=i] + (-h[i+m])*x * [i+m<n]
    # where A is the sum over all terms not involving h[i]
    # So slope = (1-h[i-m])*[m<=i] - h[i+m]*[i+m<n]
    
    for m in range(1, n):
        # positive lag m, index n-1+m
        slope = 0.0
        if m <= i:
            slope += (1.0 - h[i-m])
        if i+m < n:
            slope -= h[i+m]
        slopes[n-1+m] = slope
        
        # negative lag -m, index n-1-m
        slope = 0.0
        if m <= i:
            slope += (1.0 - h[i-m])
        if i+m < n:
            slope -= h[i+m]
        slopes[n-1-m] = slope
    
    return slopes

                new_corr = corr.copy()
                for m in range(1, n):

                    if i + m < n:
                        s -= h[i+m]

                        new_corr[n-1+m] += delta_c
                        new_corr[n-1-m] += delta_c

                new_corr[n-1] += delta * (1.0 - old - x)
                
                obj = np.max(new_corr)
                if obj < best_obj:

                    best_x = x
            
            # Apply best update
            if best_x != old:

                for m in range(1, n):

            return h

    n = len(h)
    old = h[i]
    
    if n <= 1:
        return old
    
    m_arr = np.arange(1, n)
    slopes = np.zeros(n - 1)

    full_slope[n:] = slopes
    full_slope[:n-1] = slopes[::-1]

        delta = x - old
        linear_max = np.max(corr + delta * full_slope)
        lag0_exact = corr[n-1] + delta * (1.0 - old - x)
        return max(linear_max, lag0_exact)

    a, b = 0.0, 1.0

        else:

        if v < best_val:
            best_val = v
            best_x = x
