Actually, I realize I should think about this more carefully. The correlation at lag (center + j) where center = n-1:

corr[center + j] = sum over valid i of h[i] * (1-h[i+j])

For j > 0: valid i are 0 to n-1-j
For j < 0: valid i are |j| to n-1 (i.e., i+j >= 0)

A swap of h[a] from 1 to 0 and h[b] from 0 to 1 changes corr[center + j] by:
- If a is a valid i for shift j: -(1-h[a+j])
- If a is a valid (i+j) for shift j, i.e., a-j is a valid i: -h[a-j]
- If b is a valid i for shift j: +(1-h[b+j])
- If b is a valid (i+j) for shift j, i.e., b-j is a valid i: +h[b-j]

For the swap to REDUCE corr[center + j], we want the total change < 0:
-(1-h[a+j]) - h[a-j] + (1-h[b+j]) + h[b-j] < 0

The simplest sufficient condition (when a is not at distance j from b):
If h[a+j] = 0 (so first term = -1) and h[b+j] = 1 (so third term = 0), and the other terms are 0 or small, then the change is approximately -1.

So the targeted move is: pick a from ones with h[a+j]=0, and b from zeros with h[b+j]=1.

But we need to be careful about the "other term" effects. If a-j is a valid index and h[a-j]=1, then we get an additional -1. Similarly for b.
