    h = np.clip(h.astype(float), 0.0, 1.0)
    diff = target_sum - np.sum(h)
    if abs(diff) < 1e-10:

    if diff > 0:

    else:
        idx = np.where(h > 0.0)[0]

        return h

    h[idx] += diff / len(idx)

Anyway, the key point is that each g_k is a concave function (negative of a convex quadratic, plus a constant), and we're minimizing the max of concave functions. This is a non-convex problem.

For the log-sum-exp smoothing:
LSE(h) = (1/α) log ∑ exp(α * g_k(h))

The Hessian of this is:
∇² LSE = (1/α) * [∑ exp(α*g_k) * (α² * H_k) / ∑ exp(α*g_k)] - (1/α) * [∑ exp(α*g_k) * (α * ∇g_k)(∑ exp(α*g_k) * (α * ∇g_k))^T / (∑ exp(α*g_k))²]

= α * ∑ p_k H_k - α * (∑ p_k ∇g_k)(∑ p_k ∇g_k)^T

where p_k = exp(α*g_k) / ∑ exp(α*g_j).

Since H_k = -2*S_k (negative semi-definite for the autocorrelation part), the first term is negative semi-definite. The second term is negative semi-definite. So the Hessian of LSE is negative semi-definite, meaning LSE is concave!

Wait, that means we're minimizing a concave function over a convex set! That's a non-convex problem (the minimum of a concave function over a polytope is at the boundary).

This explains why the optimal solution tends to be near the boundary (near binary). The continuous values help slightly but the solution is mostly binary with a few fractional values.

1. Get a very good binary solution
2. Then carefully adjust a small number of variables away from binary to reduce the max
