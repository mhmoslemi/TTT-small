So the change is: Δ[m] = (1-h[j+shift_m]) * [j+shift_m in range] - (1-h[i+shift_m]) * [i+shift_m in range]

For binary h:
- (1-h[j+shift_m]) is 1 if h[j+shift_m]=0, 0 if h[j+shift_m]=1
- (1-h[i+shift_m]) is 1 if h[i+shift_m]=0, 0 if h[i+shift_m]=1

So Δ[m] ∈ {-1, 0, 1} as before.

Now, the key insight: I can precompute two vectors for each position:
- contrib_1[i] = vector of length (2n-1) where contrib_1[i][m] = (1-h[i+shift_m]) * [i+shift_m in range]
- contrib_0[j] = vector of length (2n-1) where contrib_0[j][m] = (1-h[j+shift_m]) * [j+shift_m in range]

Then for swap (i,j): Δ = contrib_0[j] - contrib_1[i]

And the new max = max(corr + contrib_0[j] - contrib_1[i])

This is a vector operation on length (2n-1) = 1199 vectors. For each candidate pair, this is O(n) work. With |candidates| ~ O(n^2/4) = 90K pairs, that's 90K * 1200 = 108M operations per greedy step. That's too slow in Python.

I need to be smarter. Let me limit to checking only the top K lags (where K is small, say 20-50).

For the top K lags, I can precompute:
- contrib_1_top[i] = array of length K (contribution at the top K lags)
- contrib_0_top[j] = array of length K

Then checking if a swap (i,j) is "safe" (doesn't increase the max) is:
For all k in top_K: corr[top_lag_k] + contrib_0_top[j][k] - contrib_1_top[i][k] ≤ current_max

This is O(K) per pair, and with K=50, that's 50 * 90K = 4.5M per step. Still a lot but more manageable with numpy vectorization.

Actually, let me think about this more carefully. I'll vectorize over the j candidates for a fixed i:

For a fixed i, I want to find j such that:
max_k (corr[top_k] + contrib_0_top[j][k] - contrib_1_top[i][k]) < current_max

This is: max_k (corr[top_k] - contrib_1_top[i][k] + contrib_0_top[j][k]) < current_max
            max_k ((corr[top_k] - contrib_1_top[i][k]) + contrib_0_top[j][k]) < current_max

Let base[k] = corr[top_k] - contrib_1_top[i][k]
Then we need: max_k (base[k] + contrib_0_top[j][k]) < current_max for all k
            base[k] + contrib_0_top[j][k] < current_max for all k
            contrib_0_top[j][k] < current_max - base[k] for all k

So for a fixed i, I can precompute the threshold vector: thresh[k] = current_max - base[k]
Then j is safe if contrib_0_top[j][k] < thresh[k] for all k.

This is a simple comparison that can be vectorized over all j at once:
safe_mask = (contrib_0_top < thresh[None, :]).all(axis=1)

Where contrib_0_top has shape (num_zeros, K) and thresh has shape (K,).

This is O(|zeros| * K) per i, and we have |ones| i's to check. Total: O(|ones| * |zeros| * K) = O(n^2 * K / 4).

For n=600, K=50: 600^2 * 50 / 4 = 4.5M. That's fine with numpy.

But we also need to ensure the swap actually helps (reduces the max at the worst lag). The condition for reducing the max at lag m* is:
contrib_1_top[i][m*_idx] = 1 and contrib_0_top[j][m*_idx] = 0
i.e., h[i+m*_shift] = 0 and h[j+m*_shift] = 1

Which is exactly our i_candidates and j_candidates conditions.

    else:
        idx = np.where(h > 0.0)[0]

    h_r = np.clip(h_r, 0, 1).astype(int)
    current_sum = h_r.sum()
    if current_sum == target_sum:
        return h_r.astype(float)

        if need <= len(ones):

            h_r[ones[order]] = 0

        need = int(target_sum - current_sum)

            extra = int(target_sum - final_sum)
            h_r[zeros2[:extra]] = 1

def greedy_swap(h, corr, n, rng, top_k=30):
    """Find and apply the best improving swap. Returns (h, corr, improved)."""
    max_val = float(corr.max())
    max_idx = int(np.argmax(corr))
    k_star = max_idx - (n - 1)
    
    ones = np.where(h == 1)[0]
    zeros = np.where(h == 0)[0]
    
    if len(ones) == 0 or len(zeros) == 0:
        return h, corr, False
    
    # Find i candidates: h[i]=1, h[i+k_star]=0
    i_cand = []
    for i in ones:
        jp = i + k_star
        if 0 <= jp < n and h[jp] == 0:
            i_cand.append(i)
    
    if len(i_cand) == 0:
        return h, corr, False
    
    i_cand = np.array(i_cand)
    
    # Find j candidates: h[j]=0, h[j+k_star]=1
    j_cand = []
    for j in zeros:
        ip = j + k_star
        if 0 <= ip < n and h[ip] == 1:
            j_cand.append(j)
    
    if len(j_cand) == 0:
        return h, corr, False
    
    j_cand = np.array(j_cand)
    
    # Get top-k lags
    top_indices = np.argsort(corr)[-top_k:][::-1]
    
    # For each top lag, compute the shift
    top_shifts = top_indices - (n - 1)
    
    # Compute contrib_1 for i_cand at top lags: shape (|i_cand|, top_k)
    # contrib_1[i, m] = (1 - h[i + shift_m]) * [i + shift_m in range]
    positions_i = i_cand[:, None] + top_shifts[None, :]  # shape (|i_cand|, top_k)
    valid_i = (positions_i >= 0) & (positions_i < n)
    contrib_1 = np.where(valid_i, 1.0 - h[positions_i.clip(0, n-1)], 0.0)
    
    # Compute contrib_0 for j_cand at top lags: shape (|j_cand|, top_k)
    positions_j = j_cand[:, None] + top_shifts[None, :]
    valid_j = (positions_j >= 0) & (positions_j < n)
    contrib_0 = np.where(valid_j, 1.0 - h[positions_j.clip(0, n-1)], 0.0)
    
    # For the swap to be safe (not increase max at top lags):
    # corr[top_m] + contrib_0[j, m] - contrib_1[i, m] <= max_val for all m
    # i.e., contrib_0[j, m] - contrib_1[i, m] <= max_val - corr[top_m] for all m
    # i.e., contrib_0[j, m] <= max_val - corr[top_m] + contrib_1[i, m] for all m
    
    # For a fixed i: threshold[m] = max_val - corr[top_m] + contrib_1[i, m]
    # j is safe if contrib_0[j, m] <= threshold[m] for all m
    
    # Vectorize: for each i, check all j
    # Shape: (|i_cand|, top_k) - (|j_cand|, top_k) needs broadcasting
    # Let's do it in chunks to avoid memory issues
    
    best_new_max = np.inf
    best_i_idx = -1
    best_j_idx = -1
    
    # Process i candidates in batches
    batch_size = min(len(i_cand), 200)
    for start in range(0, len(i_cand), batch_size):
        end = min(start + batch_size, len(i_cand))
        c1_batch = contrib_1[start:end]  # (batch, top_k)
        
        # For each i in batch, compute threshold
        # threshold[b, m] = max_val - corr[top_indices[m]] + c1_batch[b, m]
        thresholds = max_val - corr[top_indices][None, :] + c1_batch  # (batch, top_k)
        
        # Check if c0[j, m] <= thresholds[b, m] for all m
        # c0 shape: (|j_cand|, top_k), thresholds shape: (batch, top_k)
        # We need: for each b, find j such that (c0 <= thresholds[b]).all(axis=1)
        
        # This is: (c0[None, :, :] <= thresholds[:, None, :]).all(axis=2)
        # Shape: (batch, |j_cand|)
        safe = (contrib_0[None, :, :] <= thresholds[:, None, :]).all(axis=2)
        
        # Find the first safe pair
        for b in range(end - start):
            safe_js = np.where(safe[b])[0]
            if len(safe_js) > 0:
                # Pick one (first or random)
                j_idx = safe_js[0]
                new_max = max_val - 1  # guaranteed to be at most max_val - 1 at the worst lag
                if new_max < best_new_max:
                    best_new_max = new_max
                    best_i_idx = start + b
                    best_j_idx = j_idx
                break  # found a safe swap for this i
    
    if best_i_idx < 0:
        # No safe swap found; try random swap
        i = ones[rng.randint(len(ones))]
        j = zeros[rng.randint(len(zeros))]
        h[i] = 0
        h[j] = 1
        corr = compute_corr(h)
        improved = corr.max() < max_val
        return h, corr, improved
    
    # Apply the best safe swap
    i = i_cand[best_i_idx]
    j = j_cand[best_j_idx]
    h[i] = 0
    h[j] = 1
    corr = compute_corr(h)
    return h, corr, True

def sa_focal(h, target_sum, max_iters, t_init, t_final, rng, time_limit=None, start_time=None):

def slsqp_refine(h_start, n, target, alphas, maxiter, ftol, time_limit=None, start_time=None):
    global _cons_n, _cons_target
    _cons_n = n
    _cons_target = target
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': _cons_fun, 'jac': _cons_jac}]
    h_cur = h_start.copy()
    curr_score = compute_c5(h_cur)
    
    for alpha in alphas:
        if time_limit is not None and start_time is not None:
            if time.time() - start_time > time_limit:
                break
        try:
            res = minimize(_smooth_obj, h_cur, args=(alpha,),
                           method='SLSQP', bounds=bounds, constraints=cons,
                           options={'maxiter': maxiter, 'ftol': ftol})
            h_new = project_feasible(res.x, target)
            sc = compute_c5(h_new)
            if sc < curr_score:
                curr_score = sc
                h_cur = h_new
        except Exception:
            pass
    return h_cur, curr_score

def _smooth_obj(h, alpha):
    corr = np.correlate(h, 1.0 - h, mode='full')
    c_max = np.max(corr)
    shifted = np.clip(alpha * (corr - c_max), -500.0, 0.0)
    return float(c_max + np.log(np.sum(np.exp(shifted))) / alpha)

def _cons_fun(h):
    return np.sum(h) - _cons_target

def _cons_jac(h):
    return np.ones(_cons_n)

import numpy as np

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr)) * dx


def compute_corr(h):
    return np.correlate(h, 1.0 - h, mode='full')


def project_feasible(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    diff = target_sum - np.sum(h)
    if abs(diff) < 1e-14:
        return h
    if diff > 0:
        idx = np.where(h < 1.0)[0]
    else:
        idx = np.where(h > 0.0)[0]
    if len(idx) == 0:
        return h
    h = h.copy()
    h[idx] += diff / len(idx)
    return np.clip(h, 0.0, 1.0)


def project_binary(h, target_sum):
    n = len(h)
    h_r = np.round(h)
    h_r = np.clip(h_r, 0, 1).astype(int)
    current_sum = int(h_r.sum())
    if current_sum == target_sum:
        return h_r.astype(float)
    ones = np.where(h_r == 1)[0]
    zeros = np.where(h_r == 0)[0]
    if current_sum > target_sum:
        need = current_sum - target_sum
        if need <= len(ones):
            order = np.argsort(h[ones])[:need]
            h_r[ones[order]] = 0
    else:
        need = target_sum - current_sum
        if need <= len(zeros):
            order = np.argsort(-h[zeros])[:need]
            h_r[zeros[order]] = 1
    final_sum = int(h_r.sum())
    if final_sum != target_sum:
        if final_sum > target_sum:
            ones2 = np.where(h_r == 1)[0]
            extra = final_sum - target_sum
            h_r[ones2[:extra]] = 0
        else:
            zeros2 = np.where(h_r == 0)[0]
            extra = target_sum - final_sum
            h_r[zeros2[:extra]] = 1
    return h_r.astype(float)

def _smooth_obj(h, alpha):
    corr = np.correlate(h, 1.0 - h, mode='full')
    c_max = float(np.max(corr))
    shifted = np.clip(alpha * (corr - c_max), -500.0, 0.0)
    return c_max + float(np.log(np.sum(np.exp(shifted))) / alpha)

    return np.sum(h) - _cons_target

    return np.ones(_cons_n)


def slsqp_refine(h_start, n, target, alphas, maxiter, ftol, time_limit=None, start_time=None):
    global _cons_n, _cons_target
    _cons_n = n
    _cons_target = target
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': _cons_fun, 'jac': _cons_jac}]
    h_cur = h_start.copy()
    curr_score = compute_c5(h_cur)

    for alpha in alphas:

            if time.time() - start_time > time_limit:
                break
        try:
            res = minimize(_smooth_obj, h_cur, args=(alpha,),
                           method='SLSQP', bounds=bounds, constraints=cons,

            sc = compute_c5(h_new)
            if sc < curr_score:
                curr_score = sc
                h_cur = h_new
        except Exception:
            pass
    return h_cur, curr_score


def interpolate_to(h_src, n_dst, target_dst):
    n_src = len(h_src)
    if n_src == n_dst:
        return project_feasible(h_src.copy(), target_dst)
    x_new = np.linspace(0.0, 1.0, n_dst)
    x_old = np.linspace(0.0, 1.0, n_src)
    h_out = np.interp(x_new, x_old, h_src)
    return project_feasible(h_out, target_dst)


def quasi_random_init(n, rng):
    """Generate a quasi-random binary initialization using van der Corput-like spacing."""
    h = np.zeros(n)
    ones_count = n // 2
    golden = (1.0 + np.sqrt(5.0)) / 2.0
    positions = []
    for i in range(ones_count):
        frac = ((i + 1) / golden) % 1.0
        positions.append(int(frac * n))
    positions = sorted(set(positions))
    while len(positions) < ones_count:
        candidates = [p for p in range(n) if p not in set(positions)]
        if not candidates:
            break
        pos = candidates[rng.randint(len(candidates))]
        positions.append(pos)
    positions = positions[:ones_count]
    h[positions] = 1.0
    return h
