Actually let me just look at what numpy computes. From the docs:
np.correlate(a, v, mode='full')[k] = sum_n a_{n+k} * conj(v_n) for valid n

So for a=h, v=(1-h):
result[k] = sum_n h[n+k] * (1-h[n]) for valid n

For k = n-1 (the "middle" of the full output, corresponding to zero shift):
result[n-1] = sum_n h[n] * (1-h[n]) = 0 for binary h

For k > n-1 (positive shift s = k-(n-1)):
result[k] = sum_n h[n+s] * (1-h[n]) for valid n = sum_{n=0}^{n-1-s} h[n+s] * (1-h[n])
This counts positions where the "shifted" h is 1 and the "unshifted" h is 0, i.e., "0→1" transitions.

For k < n-1 (negative shift s = k-(n-1)):
result[k] = sum_n h[n+s] * (1-h[n]) where s < 0
= sum_{n=-s}^{n-1} h[n+s] * (1-h[n])
= sum_{m=0}^{n-1-|s|} h[m] * (1-h[m+|s|])
This counts positions where the "unshifted" h is 1 and the "shifted" h is 0, i.e., "1→0" transitions.

So the full correlation contains both types of transitions, and we take the max over ALL of them.

For a binary sequence with n/2 ones, the "1→0" and "0→1" counts at shift s are:
- "1→0" at shift s: |{i: h[i]=1, h[i+s]=0}| (for i+s in [0,n-1])
- "0→1" at shift s: |{i: h[i]=0, h[i+s]=1}| (for i+s in [0,n-1])

And these are equal! Because:
|{i: h[i]=1, h[i+s]=0}| = |{i: h[i]=1}| - |{i: h[i]=1, h[i+s]=1}| (for the overlapping region)
|{i: h[i]=0, h[i+s]=1}| = |{i: h[i+s]=1}| - |{i: h[i]=1, h[i+s]=1}|

But |{i: h[i]=1}| and |{i: h[i+s]=1}| are not equal in general for a finite sequence (boundary effects).

However, for the "full" correlation, the overlapping regions for positive and negative shifts are different, so the "1→0" and "0→1" counts at |s| might differ.

Anyway, the key point is: we want to minimize the max over all these counts.

import numpy as np

def project_onto_constraint(h, target_sum):
    lo, hi = -2.0, 2.0
    for _ in range(60):
        mid = (lo + hi) / 2.0
        s = np.clip(h - mid, 0.0, 1.0).sum()
        if s > target_sum:
            lo = mid
        else:
            hi = mid
    lam = (lo + hi) / 2.0
    return np.clip(h - lam, 0.0, 1.0)

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(dx * np.max(corr))

def smooth_objective(h, eps, target_sum):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full') * dx
    cmax = np.max(corr)
    x = (corr - cmax) / eps
    x -= np.max(x)
    return cmax + eps * np.log(np.sum(np.exp(x)))

def smooth_gradient(h, eps):
    n = len(h)
    dx = 2.0 / n
    omh = 1.0 - h
    corr = np.correlate(h, omh, mode='full') * dx
    cmax = np.max(corr)
    x = (corr - cmax) / eps
    x -= np.max(x)
    ex = np.exp(x)
    sexp = np.sum(ex)
    w = ex / sexp
    grad = np.zeros(n)
    for k in range(2 * n - 1):
        wk = w[k]
        if wk < 1e-14:
            continue
        s = k - (n - 1)
        if s >= 0:
            m = n - s
            grad[s:s+m] += wk * dx * omh[:m]
            grad[:m] -= wk * dx * h[s:s+m]
        else:
            r = -s
            m = n - r
            grad[r:r+m] += wk * dx * omh[:m]
            grad[:m] -= wk * dx * h[r:r+m]
    return grad

def constraint_fun(h, target_sum):
    return float(np.sum(h) - target_sum)

def constraint_jac(h):
    return np.ones(len(h))

def slsqp_optimize(h_init, eps, target_sum, maxiter=200):
    n = len(h_init)
    h0 = project_onto_constraint(h_init.astype(float).copy(), target_sum)
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': lambda h: constraint_fun(h, target_sum), 'jac': constraint_jac}]
    try:
        result = minimize(smooth_objective, h0, args=(eps, target_sum),
                          jac=smooth_gradient, method='SLSQP',
                          bounds=bounds, constraints=cons,
                          options={'maxiter': maxiter, 'ftol': 1e-14})
        h_opt = project_onto_constraint(result.x, target_sum)
        return h_opt, compute_c5(h_opt)
    except Exception:
        return h0, compute_c5(h0)

**Alternative: Coordinate descent on the continuous problem**

At each step, pick one coordinate h[i] and optimize it (keeping others fixed). The objective as a function of h[i] is:
f(h[i]) = max_k corr_k(h[i])

where corr_k depends linearly on h[i] (since the correlation is bilinear in h).

Actually, corr_k = sum_j h[j] * (1-h[j+s(k,j)]) where s depends on k.
The terms involving h[i] are:
- When j = i: h[i] * (1-h[i+k-(n-1)]) for the appropriate k
- When j+k-(n-1) = i, i.e., j = i - k + (n-1): h[j] * (1-h[i])

So corr_k is linear in h[i] (for fixed other coordinates). The max of linear functions is convex, so we can minimize it by finding the point where the "active" constraints balance.

This is actually a 1D convex optimization problem! We can solve it analytically or with a few bisection steps.

    h2 = np.zeros(n2)
    h2[0::2] = best_h[:n]
    h2[1::2] = best_h[:n]
    h2 = project_onto_constraint(h2, n2 / 2.0)
    best_c5_2 = compute_c5(h2)
    best_h_2 = h2.copy()

    phase4_end = start_time + 1100
    for eps in [0.01, 0.005, 0.002, 0.001, 0.0005, 0.0002]:
        if time.time() > phase4_end:
            break
        h2_opt, c5_2 = slsqp_optimize(best_h_2, eps, 200)
        if c5_2 < best_c5_2:
            best_c5_2 = c5_2
            best_h_2 = h2_opt

    if best_c5_2 < best_c5:
        best_c5 = best_c5_2
        best_h = best_h_2

    remaining = budget_s - (time.time() - start_time)
    if remaining > 80:
        h_bin_2 = make_binary(best_h)
        bin2_c5 = compute_c5(h_bin_2)
        if bin2_c5 < best_c5:
            best_c5 = bin2_c5
            best_h = h_bin_2.astype(float)
        t_end = start_time + budget_s - 40
        h_bin_2, bin2_c5 = binary_sa(h_bin_2, start_time, t_end, seed=seed + 12345)
        if bin2_c5 < best_c5:
            best_c5 = bin2_c5
            best_h = h_bin_2.astype(float)

    remaining = budget_s - (time.time() - start_time) - 5
    if remaining > 30:
        cur_n = len(best_h)
        for eps in [0.0001, 0.00005, 0.00002]:
            if time.time() > start_time + budget_s - 5:
                break
            maxit = min(int(remaining / max(1, len(best_h) * 0.01)), 500)
            h_opt, c5_opt = slsqp_optimize(best_h, eps, maxit)
            if c5_opt < best_c5:
                best_c5 = c5_opt
                best_h = h_opt
            remaining = budget_s - (time.time() - start_time) - 5
            if remaining < 20:
                break

    final_h = project_onto_constraint(best_h, len(best_h) / 2.0)
    final_c5 = compute_c5(final_h)
    if final_c5 > best_c5:
        return best_h, best_c5, len(best_h)
    return final_h, final_c5, len(final_h)
