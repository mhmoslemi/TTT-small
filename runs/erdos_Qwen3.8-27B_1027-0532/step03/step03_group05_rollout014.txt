```python
def project_exact(h, target_sum):
    """Project h onto {x : 0 <= x <= 1, sum(x) = target_sum} using bisection."""
    n = len(h)
    if target_sum <= 0:
        return np.zeros(n)
    if target_sum >= n:
        return np.ones(n)
    
    def sum_at_lambda(lam):
        return np.sum(np.clip(h - lam, 0.0, 1.0))
    
    lo = h.min() - 1.0
    hi = h.max() + 1.0
    for _ in range(60):
        mid = (lo + hi) / 2.0
        if sum_at_lambda(mid) > target_sum:
            lo = mid
        else:
            hi = mid
    lam = (lo + hi) / 2.0
    return np.clip(h - lam, 0.0, 1.0)
```

**Pair swap**: Choose two indices i and j. Consider the move:

So the best pair swap at a given point is to find (i, j) that maximizes ∂C/∂h[i] - ∂C/∂h[j], i.e., the index with the highest gradient and the index with the lowest gradient.

This is essentially a 2D gradient step! And it's what the subgradient method is already doing (in aggregate). But the pair swap gives us a direction that's feasible (preserves the sum) and stays in the box (if δ is small enough).

```python
        if s3 < best_score:
            best_score = s3
            best_h = h3
    
    # Phase 4: High-beta SLSQP polish
    for beta in [500, 1000, 2000]:
        if tleft() < 50:
            break
        h4 = slsqp_smoothed(best_h, target, beta, maxiter=100)
        s4 = compute_c5(h4)
        if s4 < best_score:
            best_score = s4
            best_h = h4
    
    # Phase 5: Final coordinate descent
    if tleft() > 60:
        h5, s5 = fine_coord_descent(best_h, target, int(tleft() - 20), seed + 1)
        if s5 < best_score:
            best_score = s5
            best_h = h5
    
    # Phase 6: Final SLSQP
    if tleft() > 40:
        h6 = slsqp_smoothed(best_h, target, 5000, maxiter=50)
        s6 = compute_c5(h6)
        if s6 < best_score:
            best_score = s6
            best_h = h6
    
    h_final = project_feasible(best_h, target)
    final_score = compute_c5(h_final)
    if final_score < best_score:
        best_score = final_score
        best_h = h_final
    
    return best_h, best_score, n
```

Actually, let me use a different strategy for the equality constraint:
- Fix h[n-1] = target - sum(h[0:n-1])
- But this might go out of bounds...

Alternative: use Lagrange multipliers. The Lagrangian is:
L(h, λ) = C_β(h) + λ * (sum(h) - target)
∂L/∂h[j] = ∂C_β/∂h[j] + λ = 0
→ λ = -∂C_β/∂h[j] for all j (at the unconstrained optimum)

This means at the optimum (ignoring box constraints), all partial derivatives are equal. So I can project the gradient onto the hyperplane sum(h) = target by subtracting the mean gradient:
h ← h - α * (grad - mean(grad))

This automatically preserves the sum! This is the "projected gradient" method.

Let me implement this as an alternative to SLSQP:

```python
def projected_gradient_descent(h, target, time_limit, beta=100, alpha_init=0.01):
    n = len(h)
    dx = 2.0 / n
    start = time.time()
    best = h.copy()
    best_score = compute_c5(best)
    alpha = alpha_init
    
    while time.time() - start < time_limit:
        _, grad = lse_obj_grad(best, beta, dx)
        # Project gradient onto the sum=0 hyperplane
        grad_proj = grad - np.mean(grad)
        gn = np.linalg.norm(grad_proj)
        if gn < 1e-10:
            break
        # Take a step
        h_new = best - alpha * grad_proj / gn
        h_new = project_feasible(h_new, target)
        s = compute_c5(h_new)
        if s < best_score:
            best_score = s
            best = h_new
            alpha = min(alpha * 1.05, 0.1)
        else:
            alpha *= 0.7
            if alpha < 1e-6:
                break
    return best, best_score
```

This is simpler and might be more effective than SLSQP for this problem. The key insight is that by projecting the gradient onto the sum=0 hyperplane, we automatically maintain the equality constraint (up to the projection step which handles bounds).
