    # ...

    current_max = corr.max()

    best_max = current_max
    best_h = h.copy()

        if time_limit() < 30:
            break

        zeros = np.where(h == 0)[0]
        
        # Find hot lags
        hot = np.where(corr >= current_max - 1)[0]
        
        best_improve = 0
        best_swap = None
        
        for lag_idx in hot[:20]:  # limit to 20 hot lags
            k = lag_idx - (n - 1)

            # contribution_i = h[i-k] + h[i+k] (0 if out of range)
            # We want to REMOVE the one with smallest contribution
            # And ADD a zero with largest "removal benefit" = h[j-k] + h[j+k]
            
            # Vectorized computation
            i_offset_m = ones - k
            i_offset_p = ones + k
            valid_m = (i_offset_m >= 0) & (i_offset_m < n)
            valid_p = (i_offset_p >= 0) & (i_offset_p < n)
            
            i_contrib = np.zeros(len(ones))
            i_contrib[valid_m] += h[i_offset_m[valid_m]]
            i_contrib[valid_p] += h[i_offset_p[valid_p]]
            
            j_offset_m = zeros - k
            j_offset_p = zeros + k
            valid_m_j = (j_offset_m >= 0) & (j_offset_m < n)
            valid_p_j = (j_offset_p >= 0) & (j_offset_p < n)
            
            j_contrib = np.zeros(len(zeros))
            j_contrib[valid_m_j] += h[j_offset_m[valid_m_j]]
            j_contrib[valid_p_j] += h[j_offset_p[valid_p_j]]
            
            # Best swap: minimize i_contrib - j_contrib
            # = minimize i_contrib + minimize (-j_contrib) = minimize i_contrib - j_contrib
            # Best i: argmin of i_contrib
            # Best j: argmax of j_contrib
            
            bi = np.argmin(i_contrib)
            bj = np.argmax(j_contrib)
            
            delta = i_contrib[bi] - j_contrib[bj]
            if delta < -best_improve:
                best_improve = -delta
                best_swap = (ones[bi], zeros[bj])
        
        if best_swap is None:
            break
        
        i, j = best_swap
        h[i] = 0.0
        h[j] = 1.0
        
        # Update corr incrementally
        # delta f_k = h_old[i-k] + h_old[i+k] - h_old[j-k] - h_old[j+k]
        # But we already changed h, so we need to use old values
        # Let's just recompute (for n=400, it's fast)
        corr = np.correlate(h, 1.0 - h, mode='full')
        new_max = corr.max()
        
        if new_max < current_max:
            current_max = new_max
            if new_max < best_max:
                best_max = new_max
                best_h = h.copy()
                best_corr = corr.copy()
        else:
            # Revert
            h[i] = 1.0
            h[j] = 0.0
            # Try next best or break
            break  # Stuck in local optimum
    
    return best_h, best_max * (2.0/n)

**Strategy: Use the continuous optimizer but with a better objective landscape.**

Instead of the standard log-sum-exp, I'll use a **piecewise-linear majorization** approach:
1. At the current point h0, compute all f_k(h0)
2. Find the top-T lags (T = 5-10)
3. Minimize the average of these T lags (a linear combination, not the full smooth max)
4. This is a quadratic program (since each f_k is quadratic in h)
5. Update h and repeat

This "top-T" approach focuses the optimization on the most critical lags and avoids the numerical issues of very high alpha in the log-sum-exp.

Actually, minimizing a weighted sum of quadratic functions is a QP (if we ignore the box constraints) or a non-convex QP (with the bilinear terms). Let me think...

f_k(h) = sum_i h[i+k](1-h[i]) = sum_i h[i+k] - sum_i h[i+k]h[i]

The first term is linear. The second term -sum_i h[i+k]h[i] is a quadratic form. The Hessian of this term has -1's at positions (i+k, i) and (i, i+k), which makes it indefinite (not positive semidefinite). So the QP is non-convex.

We can still use L-BFGS-B on the weighted sum (it's smooth, just non-convex). The gradient is:
d/dh[j] of sum_k lambda_k * f_k(h) = sum_k lambda_k * [(1-h[j-k])_{valid} - h[j+k]_{valid}]

This is the same as the smooth gradient but with w = lambda (fixed weights, not adaptive).

So the "top-T" approach is:
1. Compute corr = correlate(h, 1-h, 'full')
2. Find top T indices
3. Set weights: w[k_idx] = 1/T for top-T, 0 otherwise
4. Run L-BFGS-B to minimize sum_k w[k] * f_k(h)
5. Iterate
