**Alternative: Projected Nesterov Accelerated Gradient (FISTA)**

FISTA converges at O(1/k²) rate for smooth convex functions. Our objective (the log-sum-exp smoothed max) is smooth, so FISTA should work well.

The FISTA update is:
1. y_k = x_k + (t_k - 1)/(t_{k+1}) * (x_k - x_{k-1})

        idx = np.where(h < 1.0)[0]
        if len(idx) > 0:
            h[idx] += diff / len(idx)
    else:

        if len(idx) > 0:

def compute_grad_weighted(h, lags, weights):
    n = len(h)
    grad = np.zeros(n)
    one_minus_h = 1.0 - h
    for i in range(len(lags)):
        w = weights[i]
        if w < 1e-14:
            continue
        lag = lags[i] - (n - 1)
        if lag >= 0:
            if lag < n:
                grad[lag:] += w * one_minus_h[:n - lag]
                grad[:n - lag] -= w * h[lag:]
        else:
            m = -lag
            if m < n:
                grad[:n - m] += w * one_minus_h[m:]
                grad[m:] -= w * h[:n - m]
    return grad

Actually, I just realized something: the SLSQP with the smooth log-sum-exp objective is solving a *smoothed* version of the problem. As alpha → ∞, the smoothed objective approaches the true max. But for finite alpha, there's a gap of O(1/alpha) between the smoothed and true objectives.

So if we use alpha=500, the gap is about 1/500 = 0.002. That's larger than our target gap of 0.000043! We need alpha much larger, like 5000 or 10000.

But with very large alpha, the log-sum-exp becomes essentially a max, and the gradient becomes ill-conditioned (only the argmax lag contributes). This makes the optimization harder.

The solution: use a **continuation method** - start with small alpha and gradually increase it.

Let me revise the SLSQP phase:
- Start with alpha=20, increase to 50, 100, 200, 500, 1000, 2000, 5000
- At each alpha, run SLSQP for a few hundred iterations
- The solution from alpha=200 becomes the starting point for alpha=500, etc.

This is a standard technique in optimization.

Let me also consider: at very high alpha, the problem essentially becomes:
minimize corr[argmax(corr)]
subject to 0 ≤ h ≤ 1, sum(h) = n/2

This is a non-smooth problem, and SLSQP might struggle. But the continuation approach should help.

import numpy as np
from scipy.optimize import minimize

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr)) * dx

def project_feasible(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    diff = target_sum - np.sum(h)
    if abs(diff) < 1e-10:
        return h
    h = h.copy()
    if diff > 0:
        idx = np.where(h < 1.0)[0]
        if len(idx) > 0:
            h[idx] += diff / len(idx)
    else:
        idx = np.where(h > 0.0)[0]
        if len(idx) > 0:
            h[idx] += diff / len(idx)
    return np.clip(h, 0.0, 1.0)

def compute_grad_weighted(h, lags, weights):
    n = len(h)
    grad = np.zeros(n)
    one_minus_h = 1.0 - h
    for i in range(len(lags)):
        w = weights[i]
        if w < 1e-14:
            continue
        lag = lags[i] - (n - 1)
        if lag >= 0:
            if lag < n:
                grad[lag:] += w * one_minus_h[:n - lag]
                grad[:n - lag] -= w * h[lag:]
        else:
            m = -lag
            if m < n:
                grad[:n - m] += w * one_minus_h[m:]
                grad[m:] -= w * h[:n - m]
    return grad

             noise_prob, noise_scale, patience, seed):
    rng = np.random.RandomState(seed)
    n = len(h_init)
    h = h_init.copy()
    m_acc = np.zeros(n)
    v_acc = np.zeros(n)
    best_h = h.copy()
    best_score = compute_c5(h)
    stagnation = 0
    t = 0
    b1 = 0.9
    b2 = 0.999
    
    for it in range(max_iter):
        t += 1
        corr = np.correlate(h, 1.0 - h, mode='full')
        topk = topk_list[it % len(topk_list)]
        alpha = alpha_list[it % len(alpha_list)]
        
        top_indices = np.argpartition(corr, -topk)[-topk:]
        top_vals = corr[top_indices]
        w = np.exp(alpha * (top_vals - np.max(top_vals)))
        w_sum = np.sum(w)
        if w_sum < 1e-300:
            w = np.ones(topk) / topk
        else:
            w = w / w_sum
        
        grad = compute_grad_weighted(h, top_indices, w)
        
        m_acc = b1 * m_acc + (1.0 - b1) * grad
        v_acc = b2 * v_acc + (1.0 - b2) * grad * grad
        m_hat = m_acc / (1.0 - b1 ** t)
        v_hat = v_acc / (1.0 - b2 ** t)
        h_new = h - lr * m_hat / (np.sqrt(v_hat) + 1e-8)
        h_new = project_feasible(h_new, target_sum)
        
        if noise_prob > 0.0 and rng.random() < noise_prob:
            h_new = h_new + rng.randn(n) * noise_scale
            h_new = project_feasible(h_new, target_score)
        
        score = compute_c5(h_new)
        if score < best_score:
            best_score = score
            best_h = h_new.copy()
            stagnation = 0
        else:
            stagnation += 1
        h = h_new
        if stagnation > patience:
            break
    
    return best_h, best_score

def slsqp_step(h_start, target_sum, alpha, maxiter, ftol):
    n = len(h_start)
    
    def obj(x):
        corr = np.correlate(x, 1.0 - x, mode='full')
        c_max = np.max(corr)
        shifted = np.clip(alpha * (corr - c_max), -500.0, 0.0)
        return c_max + np.log(np.sum(np.exp(shifted))) / alpha
    
    def jac(x):
        corr = np.correlate(x, 1.0 - x, mode='full')
        c_max = np.max(corr)
        shifted = np.clip(alpha * (corr - c_max), -500.0, 0.0)
        exp_s = np.exp(shifted)
        total = np.sum(exp_s)
        weights = exp_s / total
        return compute_grad_weighted(x, np.arange(2 * n - 1), weights)
    
    def con_eq(x):
        return np.sum(x) - target_sum
    
    def con_jac(x):
        return np.ones(n)
    
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': con_eq, 'jac': con_jac}]
    
    try:
        res = minimize(obj, h_start, jac=jac, method='SLSQP',
                       bounds=bounds, constraints=cons,
                       options={'maxiter': maxiter, 'ftol': ftol})
        return project_feasible(res.x, target_sum)
    except Exception:
        return h_start

    h_out = np.interp(x_new, x_old, h_src)
    return project_feasible(h_out, target_dst)
