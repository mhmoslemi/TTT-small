Hmm, this binary local search with the full O(n) delta computation per swap might be too slow in Python due to the overhead of creating masks and doing boolean indexing for each of the O(n^2/4) swaps.

Let me think of a faster approach. Actually, for the specific structure here, I can precompute the "contribution" of each position.

Let me define for each position i and each lag k:
contrib[i, k] = h[i+k] (if valid) + h[i-k] (if valid)

Then for a swap (oi, zi), delta_corr[p] = contrib[oi, k_p] - contrib[zi, k_p]

I can precompute the contrib matrix (size n x (2n-1)), and then for each swap, delta is just a row difference. The new max is max(corr + contrib[oi] - contrib[zi]).

Precomputation: O(n * (2n-1)) = O(n^2)
Each swap evaluation: O(n) (vector subtraction + max)
Total per round: O(n^2) precompute + O(n^3/4) for all swaps

For n=180: O(180^2) + O(180^3/4) ≈ 32400 + 2.9M per round. In Python, this might take 30-100ms per round. That's about 10,000-30,000 rounds in 1000 seconds. Should be enough.

But wait, I can do better. Instead of evaluating all swaps, I can use a greedy approach:
- For each position i, compute the "impact" vector v[i] = contrib[i] (a vector of length 2n-1)
- The swap (oi, zi) gives delta = v[oi] - v[zi]
- new_max = max(corr + v[oi] - v[zi])

I can try to find the best zi for a given oi by looking at where v[zi] is "large" where corr is large. But this is hard to do analytically.

An alternative: just use a random subset of swaps (e.g., 1000 random swaps per round) and pick the best one. This reduces the per-round cost to O(1000 * n) = O(n) with a large constant. For n=180, that's 180,000 operations per round, which is very fast.

Let me use this approach: random sampling of swaps + occasional full sweep.

Actually, let me reconsider. The key insight is that I want to minimize the maximum correlation. The "bottleneck" is the lag k* that achieves the maximum. If I can reduce the correlation at the bottleneck lag, I'll improve.

So a good strategy is:
1. Find the bottleneck lag k* (the one with maximum correlation)
2. Find swaps that reduce corr[k*] the most
3. Check if they increase other corrs too much

This is a more targeted search. Let me implement this.

For a specific bottleneck lag k*, corr[k*] = sum_i h[i+k*] * (1-h[i]). To reduce this, I want to:
- Set h[i+k*] = 0 for some i where h[i+k*]=1 and h[i]=0 (removes a contribution)
- Or set h[i] = 1 for some i where h[i]=0 and h[i+k*]=1 (removes a contribution)

Both of these are "flips" that can be paired with another flip to maintain the sum constraint.

For case 1: flip h[i+k*] from 1 to 0. This also affects other corrs.
For case 2: flip h[i] from 0 to 1. This also affects other corrs.

The pairing flip should be chosen to minimize the increase in other corrs.

This is still complex. Let me just go with the straightforward approach: random swaps with the fast O(n) evaluation, plus occasional steepest descent rounds.

import numpy as np
from scipy.optimize import linprog, minimize
import time

def project_onto_constraint(h, target_sum):
    lo, hi = -2.0, 2.0
    for _ in range(80):
        mid = (lo + hi) / 2.0
        s = np.clip(h - mid, 0.0, 1.0).sum()
        if s > target_sum:
            lo = mid
        else:
            hi = mid
    return np.clip(h - (lo + hi) / 2.0, 0.0, 1.0)

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(dx * np.max(corr))

def compute_correlation(h):
    return np.correlate(h, 1.0 - h, mode='full')

def build_A_ub(n):
    A = np.zeros((2 * n - 1, n + 1))
    A[:, n] = -1.0
    for p in range(n):
        A[p, :p + 1] = 1.0
    for p in range(n, 2 * n - 1):
        start = p - (n - 1)
        A[p, start:] = 1.0
    return A

def compute_d_values(h, n):
    corr = compute_correlation(h)
    csum = np.cumsum(h)
    total = csum[n - 1]
    lin = np.zeros(2 * n - 1)
    lin[:n] = csum[:n]
    for p in range(n, 2 * n - 1):
        start = p - (n - 1)
        if start > 0:
            lin[p] = total - csum[start - 1]
        else:
            lin[p] = total
    return lin - corr

def solve_lp_subproblem(h, n, target_sum, A_ub):
    d = compute_d_values(h, n)
    c = np.zeros(n + 1)
    c[n] = 1.0
    A_eq = np.ones((1, n + 1))
    A_eq[0, n] = 0.0
    b_eq = np.array([target_sum])
    bounds = [(0.0, 1.0)] * n + [(0.0, None)]
    try:
        result = linprog(c, A_ub=A_ub, b_ub=d, A_eq=A_eq, b_eq=b_eq,
                         bounds=bounds, method='highs')
        if result.status == 0:
            return result.x[:n]
    except Exception:
        pass
    return h.copy()

def lp_linearize(h, n, time_limit, start_time, max_iters=5000, damping=0.6):
    target_sum = n / 2.0
    A_ub = build_A_ub(n)
    best_h = h.copy()
    best_c5 = compute_c5(h)
    h = h.copy()
    for it in range(max_iters):
        if time.time() - start_time > time_limit:
            break
        h_lp = solve_lp_subproblem(h, n, target_sum, A_ub)
        h_new = (1.0 - damping) * h + damping * h_lp
        h_new = project_onto_constraint(h_new, target_sum)
        c5_new = compute_c5(h_new)
        if c5_new < best_c5:
            best_c5 = c5_new
            best_h = h_new.copy()
        h = h_new
    return best_h, best_c5

def make_binary(h, rng=None):
    n = len(h)
    if rng is not None:
        h = h + 0.001 * rng.standard_normal(n)
    sorted_idx = np.argsort(-h)
    result = np.zeros(n)
    result[sorted_idx[:n // 2]] = 1.0
    return result

def binary_fast_local(h, n, max_rounds, time_limit, start_time, rng):
    h = h.copy()
    current = compute_c5(h)
    corr = compute_correlation(h)
    k_vals = np.arange(2 * n - 1) - (n - 1)
    ones = np.where(h == 1.0)[0]
    zeros = np.where(h == 0.0)[0]
    for _ in range(max_rounds):
        if time.time() - start_time > time_limit:
            break
        n_try = min(500, len(ones) * len(zeros))
        best_delta = 0.0
        best_oi = -1
        best_zi = -1
        for _ in range(n_try):
            oi = ones[rng.integers(len(ones))]
            zi = zeros[rng.integers(len(zeros))]
            oi_plus = oi + k_vals
            oi_minus = oi - k_vals
            zi_plus = zi + k_vals
            zi_minus = zi - k_vals
            delta = np.zeros(2 * n - 1)
            mp = (oi_plus >= 0) & (oi_plus < n)
            mm = (oi_minus >= 0) & (oi_minus < n)
            mzp = (zi_plus >= 0) & (zi_plus < n)
            mzm = (zi_minus >= 0) & (zi_minus < n)
            delta[mp] += h[oi_plus[mp]]
            delta[mm] += h[oi_minus[mm]]
            delta[mzp] -= h[zi_plus[mzp]]
            delta[mzm] -= h[zi_minus[mzm]]
            new_max = np.max(corr + delta)
            delta_c5 = (new_max - np.max(corr)) * (2.0 / n)
            if delta_c5 < best_delta:
                best_delta = delta_c5
                best_oi = oi
                best_zi = zi
                best_delta_corr = delta.copy()
        if best_oi < 0:
            break
        h[best_oi] = 0.0
        h[best_zi] = 1.0
        corr = corr + best_delta_corr
        current += best_delta
        ones = np.where(h == 1.0)[0]
        zeros = np.where(h == 0.0)[0]
    return h, current

def binary_sa(h, n, time_limit, start_time, rng, t_start=0.05, t_end=0.001):
    h = h.copy()
    current = compute_c5(h)
    corr = compute_correlation(h)
    k_vals = np.arange(2 * n - 1) - (n - 1)
    best_h = h.copy()
    best_c5 = current
    total_steps = 200000
    for step in range(total_steps):
        if time.time() - start_time > time_limit:
            break
        t = t_start * (t_end / t_start) ** (step / max(total_steps - 1, 1))
        ones = np.where(h == 1.0)[0]
        zeros = np.where(h == 0.0)[0]
        oi = ones[rng.integers(len(ones))]
        zi = zeros[rng.integers(len(zeros))]
        oi_plus = oi + k_vals
        oi_minus = oi - k_vals
        zi_plus = zi + k_vals
        zi_minus = zi - k_vals
        delta = np.zeros(2 * n - 1)
        mp = (oi_plus >= 0) & (oi_plus < n)
        mm = (oi_minus >= 0) & (oi_minus < n)
        mzp = (zi_plus >= 0) & (zi_plus < n)
        mzm = (zi_minus >= 0) & (zi_minus < n)
        delta[mp] += h[oi_plus[mp]]
        delta[mm] += h[oi_minus[mm]]
        delta[mzp] -= h[zi_plus[mzp]]
        delta[mzm] -= h[zi_minus[mzm]]
        new_max = np.max(corr + delta)
        new_c5 = new_max * (2.0 / n)
        acceptance = delta_c5_accept(new_c5, current, t)
        if acceptance:
            h[oi] = 0.0
            h[zi] = 1.0
            corr = corr + delta
            current = new_c5
            if current < best_c5:
                best_c5 = current
                best_h = h.copy()
        else:
            pass
    return best_h, best_c5

def delta_c5_accept(new_c5, current, t):
    delta = new_c5 - current
    if delta < 0:
        return True
    if t < 1e-10:
        return False
    return np.random.random() < np.exp(-delta / t)

def smooth_objective(h, eps):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full') * dx
    cmax = np.max(corr)
    x = (corr - cmax) / eps
    x -= np.max(x)
    return cmax + eps * np.log(np.sum(np.exp(x)))

def smooth_gradient(h, eps):
    n = len(h)
    dx = 2.0 / n
    omh = 1.0 - h
    corr = np.correlate(h, omh, mode='full') * dx
    cmax = np.max(corr)
    x = (corr - cmax) / eps
    x -= np.max(x)
    ex = np.exp(x)
    sexp = np.sum(ex)
    w = ex / sexp
    grad = np.zeros(n)
    for k in range(2 * n - 1):
        wk = w[k]
        if wk < 1e-14:
            continue
        s = k - (n - 1)
        if s >= 0:
            m = n - s
            grad[s:] += wk * dx * omh[:m]
            grad[:m] -= wk * dx * h[s:]
        else:
            r = -s
            m = n - r
            grad[:m] += wk * dx * omh[r:]
            grad[r:] -= wk * dx * h[:m]
    return grad

def slsqp_optimize(h_init, eps, maxiter, ftol=1e-12):
    n = len(h_init)
    target_sum = n / 2.0
    h0 = project_onto_constraint(h_init.astype(float).copy(), target_sum)
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': lambda h: float(np.sum(h) - target_sum),
             'jac': lambda h: np.ones(n)}]
    try:
        result = minimize(smooth_objective, h0, args=(eps,),
                          jac=smooth_gradient, method='SLSQP',
                          bounds=bounds, constraints=cons,
                          options={'maxiter': maxiter, 'ftol': ftol})
        h_opt = project_onto_constraint(result.x, target_sum)
        return h_opt, compute_c5(h_opt)
    except Exception:
        return h0, compute_c5(h0)

def upscale(h, factor):
    n = len(h)
    n_new = n * factor
    h_up = np.zeros(n_new)
    for i in range(n_new):
        h_up[i] = h[i // factor]
    return h_up

def random_binary(n, rng):
    idx = rng.choice(n, size=n // 2, replace=False)
    result = np.zeros(n)
    result[idx] = 1.0
    return result
