        #   grad[j] += w * (-h[j-k]) * dx

Actually, I realize I should also consider a completely different approach: **projection onto the feasible set using the structure of the problem**.

The problem is: minimize max_k f_k(h) subject to g(h) = 0, 0 ≤ h ≤ 1
where f_k(h) = sum_i h[i]*(1-h[i+k])*dx and g(h) = sum(h) - n/2.

This is a convex problem in (h, t) if we relax to:
minimize t
subject to f_k(h) ≤ t for all k
g(h) = 0
0 ≤ h ≤ 1

But f_k(h) is NOT convex in h (it's bilinear: h[i]*(1-h[i+k])). So the relaxed problem is also non-convex.

However, for the ALTERNATING approach:
- Fix h, the constraint f_k(h) ≤ t is linear in t (trivially satisfied if t ≥ max f_k)
- Fix t, the constraint f_k(h) ≤ t is... still non-convex in h

So there's no easy convex relaxation.

What about a different formulation? Note that:
f_k(h) = sum_i h[i]*dx - sum_i h[i]*h[i+k]*dx (over valid i)

The first term is linear in h (and depends on k through the range of valid i). The second term is the autocorrelation, which is quadratic.

For a fixed k, f_k(h) is a quadratic function of h. The problem is to minimize the maximum of (2n-1) quadratic functions subject to linear constraints. This is a max-of-quadratics problem, which can be solved by bisection on t: for a given t, check if there exists h with all f_k(h) ≤ t. This is a system of quadratic inequalities, which is NP-hard in general but can be approached with SDP relaxations or other methods.

def projected_gradient(h0, n, target, alpha, max_steps, time_limit):
    """Projected gradient descent with the smooth max objective."""
    start = time.time()
    h_cur = project_feasible(h0.copy(), target)
    best_h = h_cur.copy()
    best_c5 = compute_c5(h_cur)
    
    for step in range(max_steps):
        if time.time() - start > time_limit:
            break
        
        val, grad = smooth_c5_and_gradient(h_cur, alpha)
        
        # Find step size by backtracking
        found = False
        lr = 0.1
        for _ in range(10):
            h_try = h_cur - lr * grad
            h_try = project_feasible(h_try, target)
            sc = compute_c5(h_try)
            if sc < best_c5 - 1e-14:
                best_c5 = sc
                best_h = h_try.copy()
                h_cur = h_try
                found = True
                break
            lr *= 0.5
        
        if not found:
            # Stuck, try random perturbation
            h_try = h_cur + np.random.randn(n) * 0.1
            h_try = project_feasible(h_try, target)
            sc = compute_c5(h_try)
            if sc < best_c5:
                best_c5 = sc
                best_h = h_try.copy()
                h_cur = h_try
            elif step > 100:
                break
    
    return best_h, best_c5

def interpolate_to(h_src, n_dst, target_dst):
    n_src = len(h_src)
    if n_src == n_dst:
        return project_feasible(h_src.copy(), target_dst)
    x_new = np.linspace(0.0, 1.0, n_dst)
    x_old = np.linspace(0.0, 1.0, n_src)
    h_out = np.interp(x_new, x_old, h_src)
    return project_feasible(h_out, target_dst)
