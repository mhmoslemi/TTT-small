```python
def _c5_of(h):
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * (2.0 / len(h)))

def _corr_of(h):
    return np.correlate(h, 1.0 - h, mode='full')

def _fix_sum(h, target_sum):
    h = np.clip(h.copy(), 0.0, 1.0)
    diff = target_sum - h.sum()
    if abs(diff) < 1e-12:
        return h
    if diff > 0:
        order = np.argsort(1.0 - h)
        for i in order:
            if diff <= 1e-12:
                break
            add = min(diff, 1.0 - h[i])
            h[i] += add
            diff -= add
    else:
        order = np.argsort(h)
        for i in order:
            if diff >= -1e-12:
                break
            sub = min(-diff, h[i])
            h[i] -= sub
            diff += sub
    return h

    dx = 2.0 / n

    # Weight by exp(beta * (corr - max_c))
    weights = np.exp(beta * (corr - max_c))
    total = weights.sum()
    if total < 1e-300:
        weights = np.zeros(len(corr))
        weights[np.argmax(corr)] = 1.0
    else:
        weights = weights / total
    # Focus on top-k
    top_idx = np.argsort(weights)[::-1][:top_k]
    w_top = weights[top_idx].copy()
    w_top = w_top / w_top.sum()
    g = np.zeros(n)
    for i in range(len(top_idx)):
        g += w_top[i] * _grad_corr(h, top_idx[i])
    return g * dx
```

- It's a min-max problem (non-smooth)
- The constraint is a simplex (sum = n/2, 0 ≤ h ≤ 1)
- The objective is a max of many bilinear forms

The bilinear forms are: f_k(h) = ∑ h[i](1-h[i+k]) for each valid k.

Each f_k is concave in h (it's a sum of products h[i]*(1-h[j]) which are bilinear, and since h[i] ≥ 0 and 1-h[j] ≥ 0, each term is non-negative, and the sum is... actually it's not concave or convex in general).

Wait, f_k(h) = ∑_{i} h[i] - ∑_{i} h[i]h[i+k]. The first part is linear in h (for a fixed valid range), and the second part is a quadratic form. Specifically, if we write it as -h^T A_k h where A_k has 1's at positions (i, i+k), then f_k is linear minus a quadratic form. The quadratic form h^T A_k h is not necessarily convex or concave.

So the problem is: min max_k (linear_k(h) - quadratic_k(h)) subject to simplex constraints.

This is a non-convex problem, which explains why global optimization is hard.

Let me focus on making the local search more effective. The key idea:

**Gradient of the max**: At any point, the "active" lags (those achieving the max) determine the subgradient. If multiple lags are active, we average their gradients (or use a weighted combination).

**Key improvement**: Instead of just looking at the top-m lags, look at ALL lags that are within ε of the maximum. This gives a more accurate subgradient.

Let me also think about a different angle: **what structure does the optimal solution have?**

For the continuous case, if h(x) = 1 on a set A and 0 on [0,2]\A, then:
∫ h(x)(1-h(x+k)) dx = measure of {x ∈ A : x+k ∉ A}

For h to be a step function (which it is by our discretization), the optimal h might have a specific structure. For example, it might be 1 on a union of intervals, or have a periodic pattern.

Actually, for the discrete case with n even and sum = n/2, the "most balanced" function would be alternating 1,0,1,0,... which has correlation structure related to the length-2 period.

Let me think about what kind of structure minimizes the max correlation. We want:
- For every lag k, the number of positions where h[i]=1 and h[i+k]=0 should be as small as possible.
- This is equivalent to: for every lag k, the "1→0 transitions" at distance k should be minimized.

This is related to the concept of **low-discrepancy sequences** or **sequentially optimal 0-1 sequences**.

Actually, I recall that for the continuous version of this problem, the optimal solution involves h being 1 on a "fat Cantor set" or some fractal-like set. But for the discrete case with bounded n, the optimal is different.

Let me try a different computational approach. Instead of the complex multi-phase optimization, let me focus on:

1. **A very efficient subgradient method** that tracks the "active set" of lags
2. **A "rebalancing" local search** that moves mass from high-contribution positions to low-contribution ones

For the "rebalancing" idea:
- For each position i, compute its "contribution" to the max overlap
- Move mass from high-contribution positions to low-contribution positions
- This is like a form of steepest descent in the L1 sense

Actually, let me think about this more carefully. The subgradient approach is the right one, but I need to make it more effective.

**Key improvement idea**: Use a **proximal subgradient method** where the proximal term is the projection onto the constraint set. This is equivalent to:
x_{t+1} = proj(x_t - α_t * g_t)

where g_t is the (sub)gradient and proj is the projection onto {h: 0≤h≤1, sum(h)=n/2}.

The standard Nesterov acceleration already does this, but the key is getting the right gradient.

**Another idea**: Instead of using a fixed number of top lags, use **all lags** with a softmax weighting. The computational cost is O(n²) per iteration (for computing the correlation) + O(n²) for the weighted gradient. For n=200, that's 40000 operations per step, which is fine.

Let me write a cleaner, more focused solution:

```python
import time
import numpy as np
from scipy.optimize import minimize

def _c5_of(h):
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * (2.0 / len(h)))

def _corr_array(h):
    return np.correlate(h, 1.0 - h, mode='full')

def _fix_sum(h, target_sum):
    h = np.clip(h.copy(), 0.0, 1.0)
    diff = target_sum - h.sum()
    if abs(diff) < 1e-14:
        return h
    if diff > 0:
        order = np.argsort(1.0 - h)
        for i in order:
            if diff <= 1e-14:
                break
            add = min(diff, 1.0 - h[i])
            h[i] += add
            diff -= add
    else:
        order = np.argsort(h)
        for i in order:
            if diff >= -1e-14:
                break
            sub = min(-diff, h[i])
            h[i] -= sub
            diff += sub
    return h

def _project_simplex(y, S):
    n = len(y)
    lo = y.min() - 1.0
    hi = y.max() + 1.0
    for _ in range(100):
        mid = (lo + hi) / 2.0
        s = np.clip(y - mid, 0.0, 1.0).sum()
        if s > S:
            lo = mid
        else:
            hi = mid
    x = np.clip(y - (lo + hi) / 2.0, 0.0, 1.0)
    diff = S - x.sum()
    if abs(diff) > 1e-10:
        if diff > 0:
            order = np.argsort(1.0 - x)
            for i in order:
                if diff <= 0:
                    break
                add = min(diff, 1.0 - x[i])
                x[i] += add
                diff -= add
        else:
            order = np.argsort(x)
            for i in order:
                if diff >= 0:
                    break
                sub = min(-diff, x[i])
                x[i] -= sub
                diff += sub
    return x

def _grad_at_lag(h, lag_idx):
    """Gradient of the correlation at a specific full-correlation index."""
    n = len(h)
    shift = lag_idx - (n - 1)
    g = np.zeros(n)
    if shift >= 0:
        m = n - shift
        if m > 0:
            idx = np.arange(m)
            g[idx] += (1.0 - h[idx + shift])
            g[idx + shift] += (-h[idx])
    else:
        j = -shift
        m = n - j
        if m > 0:
            idx = np.arange(j, n)
            g[idx] += (1.0 - h[idx - j])
            g[idx - j] += (-h[idx])
    return g

def _weighted_grad(h, beta, top_k=None):
    """Compute weighted subgradient with softmax over lags."""
    n = len(h)
    dx = 2.0 / n
    corr = _corr_array(h)
    max_c = np.max(corr)
    if max_c < 0:
        max_c = 0
    # Softmax weights
    weights = np.exp(beta * (corr - max_c))
    total_w = weights.sum()
    if total_w < 1e-300:
        weights = np.zeros(len(corr))
        weights[np.argmax(corr)] = 1.0
    else:
        weights /= total_w
    
    if top_k is not None and top_k < len(corr):
        top_idx = np.argsort(weights)[::-1][:top_k]
        w_top = weights[top_idx].copy()
        w_top /= w_top.sum()
        g = np.zeros(n)
        for i in range(len(top_idx)):
            g += w_top[i] * _grad_at_lag(h, top_idx[i])
    else:
        g = np.zeros(n)
        for i in range(len(corr)):
            if weights[i] > 1e-10:
                g += weights[i] * _grad_at_lag(h, i)
    return g * dx

def _prox_subgrad(h0, n, target_sum, n_iters, beta_start, beta_end, 
                  top_k, step_scale, deadline):
    """Proximal subgradient with Nesterov acceleration."""
    x = h0.copy()
    y = h0.copy()
    t = 1.0
    best = x.copy()
    best_val = _c5_of(x)
    
    for it in range(n_iters):
        if time.time() > deadline:
            break
        frac = it / max(1, n_iters - 1)
        beta = beta_start + (beta_end - beta_start) * frac
        step = step_scale / (1.0 + 0.01 * it)
        
        g = _weighted_grad(y, beta, top_k)
        step = step_scale / (1.0 + 0.01 * it)
        
        t_new = (1.0 + np.sqrt(1.0 + 4.0 * t * t)) / 2.0
        x_new = _project_simplex(y - step * g, target_sum)
        y_new = x_new + ((t - 1.0) / t_new) * (x_new - x)
        y_new = _project_simplex(y_new, target_sum)
        
        x = x_new
        y = y_new
        t = t_new
        
        cv = _c5_of(x)
        if cv < best_val:
            best_val = cv
            best = x.copy()
    
    return best, best_val

def _greedy_mass_transfer(h0, n, target_sum, max_iters=2000, deadline=None):
    """Greedy: find position with highest "cost" and transfer mass to lowest cost position."""
    h = h0.copy()
    current_val = _c5_of(h)
    best_val = current_val
    best_h = h.copy()
    
    rng_local = np.random.RandomState(777)
    
    for it in range(max_iters):
        if deadline is not None and time.time() > deadline:
            break
        # Compute "marginal cost" of each position
        # ≈ gradient of max correlation with respect to h[i]
        corr = _corr_array(h)
        max_c = np.max(corr)
        beta = 5.0
        weights = np.exp(beta * (corr - max_c))
        weights /= weights.sum()
        
        # Weighted gradient gives marginal cost
        g = np.zeros(n)
        top_k = min(50, len(corr))
        top_idx = np.argsort(weights)[::-1][:top_k]
        w_top = weights[top_idx].copy()
        w_top /= w_top.sum()
        for i in range(len(top_idx)):
            g += w_top[i] * _grad_at_lag(h, top_idx[i])
        
        # Find position with most positive gradient (increasing h[i] increases objective most)
        # and position with most negative gradient (decreasing h[i] decreases objective most)
        # Transfer mass from high-g to low-g
        i_src = int(np.argmax(g))  # removing mass here helps most
        i_dst = int(np.argmin(g))  # adding mass here helps most
        
        if i_src == i_dst:
            break
        
        # Find valid transfer amount
        max_transfer = min(h[i_src], 1.0 - h[i_dst])
        if max_transfer < 1e-6:
            # Try random pairs
            for _ in range(10):
                i_src = rng_local.randint(n)
                i_dst = rng_local.randint(n)
                if i_src == i_dst:
                    continue
                max_transfer = min(h[i_src], 1.0 - h[i_dst])
                if max_transfer > 1e-6:
                    break
            else:
                continue
        
        # Binary search for best transfer amount
        lo, hi = 0.0, max_transfer
        best_delta = 0.0
        best_trial_val = current_val
        for _ in range(8):
            mid = (lo + hi) / 2.0
            h[i_src] -= mid
            h[i_dst] += mid
            tv = _c5_of(h)
            h[i_src] += mid
            h[i_dst] -= mid
            if tv < best_trial_val:
                best_trial_val = tv
                best_delta = mid
                lo = mid
            else:
                hi = mid
        
        if best_delta > 1e-8:
            h[i_src] -= best_delta
            h[i_dst] += best_delta
            current_val = best_trial_val
            if current_val < best_val:
                best_val = current_val
                best_h = h.copy()
        else:
            # No improvement found with best pair; try some random pairs
            found = False
            for _ in range(5):
                a = rng_local.randint(n)
                b = rng_local.randint(n)
                if a == b:
                    continue
                for d in [0.02, 0.05, 0.1]:
                    if h[a] < d or h[b] > 1.0 - d:
                        continue
                    h[a] -= d
                    h[b] += d
                    tv = _c5_of(h)
                    if tv < current_val - 1e-12:
                        current_val = tv
                        found = True
                        if tv < best_val:
                            best_val = tv
                            best_h = h.copy()
                        break
                    else:
                        h[a] += d
                        h[b] -= d
                    # Also try reverse
                    if h[b] < d or h[a] > 1.0 - d:
                        continue
                    h[b] -= d
                    h[a] += d
                    tv = _c5_of(h)
                    if tv < current_val - 1e-12:
                        current_val = tv
                        found = True
                        if tv < best_val:
                            best_val = tv
                            best_h = h.copy()
                        break
                    else:
                        h[b] += d
                        h[a] -= d
                if found:
                    break
            if not found:
                break
    
    return best_h, best_val

def _slsqp_smooth(h0, n, target_sum, alpha, maxiter, deadline):
    """SLSQP with smooth max approximation."""
    dx = 2.0 / n
    
    def obj(h):
        corr = np.correlate(h, 1.0 - h, mode='full')
        m = np.max(corr)
        if m < -500:
            return m * dx
        return (m + np.log(np.sum(np.exp(alpha * (corr - m)))) / alpha) * dx
    
    def eq_fun(h):
        return h.sum() - target_sum
    
    def eq_jac(h):
        return np.ones(n)
    
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': eq_fun, 'jac': eq_jac}]
    
    try:
        res = minimize(obj, h0, method='SLSQP', bounds=bounds, constraints=cons,
                       options={'maxiter': maxiter, 'ftol': 1e-14})
        return _fix_sum(res.x, target_sum)
    except Exception:
        return h0

def _interpolate_to(h_src, n_dst):
    n_src = len(h_src)
    if n_src == n_dst:
        return h_src.copy()
    return np.interp(np.arange(n_dst), np.arange(n_src), h_src)

def run(seed=42, budget_s=1300, **kwargs):
    t_start = time.time()
    deadline = t_start + budget_s - 30
    
    if 'initial_h_values' in globals() and initial_h_values is not None:
```

Let me also add one more idea: **simulated annealing on the binary values**. Since the optimal solution is likely close to 0-1 valued (in the discrete case), we can do a local search where we flip individual bits. This is the "binary coordinate descent" but done more intelligently.

For a bit flip at position j (from 0 to 1 or 1 to 0), the change in the objective can be computed efficiently:
- If h[j] goes from 0 to 1: the change in corr[t] for each t is the change in the terms involving h[j]
- Specifically, for lag k (shift = k - (n-1)):
  - If j is in the "first" position: corr changes by (1 - h[j+k]) 
  - If j is in the "second" position: corr changes by h[j-k]

So we can compute the exact change in all correlations in O(n) for a single bit flip, and then check if the max decreases.

This is much faster than re-evaluating the full correlation!

```python
def _flip_delta(h, j):
    """Compute the change in each correlation bin if we flip h[j]."""
    n = len(h)
    # If h[j] = 0, flipping to 1 changes corr by:
    # For each valid lag, the terms involving h[j] change
    # corr[t] = sum_i h[i] * (1-h[i+t-(n-1)])
    # If j is the "first" index (i=j): term changes from 0 to (1-h[j+shift])
    # If j is the "second" index (i+shift=j, so i=j-shift): term changes from h[j-shift]*1 to h[j-shift]*0
    # So delta_corr[lag] = (1-h[j+shift]) - h[j-shift] for valid shifts
    
    # Actually it's easier to just compute the gradient of each corr[t] w.r.t. h[j]
    # and the change is delta * grad[t] where delta = +1 or -1
    
    n_corr = 2 * n - 1
    deltas = np.zeros(n_corr)
    shift_zero = n - 1
    
    for t in range(n_corr):
        shift = t - shift_zero
        if shift >= 0:
            # j can be a "first" index if j + shift < n, i.e., j < n - shift
            # j can be a "second" index if j >= shift (since i = j - shift >= 0 and i < n - shift)
            contrib = 0.0
            if shift >= 0 and j < n - shift:
                # j is a first index: term = h[j] * (1-h[j+shift])
                # d/dh[j] = (1-h[j+shift])
                contrib += (1.0 - h[j + shift])
            if shift >= 0 and j >= shift and j - shift < n - shift:
                # j is a second index: term = h[j-shift] * (1-h[j])
                # d/dh[j] = -h[j-shift]
                contrib += (-h[j - shift])
        else:
            j_shift = -shift
            if j >= j_shift and j - j_shift < n - j_shift:
                # j is a first index: term = h[j] * (1-h[j-shift])  [since h[j - j_shift] = h[j+shift] for negative shift]
                # Wait, for negative shift, the correlation is:
                # corr[t] = sum_{i=-shift}^{n-1} h[i] * (1-h[i+shift]) = sum_{i=-shift}^{n-1} h[i] * (1-h[i-j_shift])
                # j is first: h[j] * (1-h[j-j_shift]), valid if j >= j_shift and j-j_shift >= 0
                contrib += (1.0 - h[j - j_shift])
            if j_shift <= j and j < n:
                # j is second: h[j+j_shift] * (1-h[j]), valid if j+j_shift < n
                if j + j_shift < n:
                    contrib += (-h[j + j_shift])
        deltas[t] = contrib
    
    return deltas
```

```python
import time
import numpy as np
from scipy.optimize import minimize


def _c5_of(h):
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * (2.0 / len(h)))


def _corr_array(h):
    return np.correlate(h, 1.0 - h, mode='full')


def _fix_sum(h, target_sum):
    h = np.clip(h.copy(), 0.0, 1.0)
    diff = target_sum - h.sum()
    if abs(diff) < 1e-14:
        return h
    if diff > 0:
        order = np.argsort(1.0 - h)
        for i in order:
            if diff <= 1e-14:
                break
            add = min(diff, 1.0 - h[i])
            h[i] += add
            diff -= add
    else:
        order = np.argsort(h)
        for i in order:
            if diff >= -1e-14:
                break
            sub = min(-diff, h[i])
            h[i] -= sub
            diff += sub
    return h


def _project_simplex(y, S):
    n = len(y)
    lo = y.min() - 1.0
    hi = y.max() + 1.0
    for _ in range(100):
        mid = (lo + hi) / 2.0
        s = np.clip(y - mid, 0.0, 1.0).sum()
        if s > S:
            lo = mid
        else:
            hi = mid
    x = np.clip(y - (lo + hi) / 2.0, 0.0, 1.0)
    diff = S - x.sum()
    if abs(diff) > 1e-10:
        if diff > 0:
            order = np.argsort(1.0 - x)
            for i in order:
                if diff <= 0:
                    break
                add = min(diff, 1.0 - x[i])
                x[i] += add
                diff -= add
        else:
            order = np.argsort(x)
            for i in order:
                if diff >= 0:
                    break
                sub = min(-diff, x[i])
                x[i] -= sub
                diff += sub
    return x


def _grad_at_lag(h, lag_idx):
    n = len(h)
    shift = lag_idx - (n - 1)
    g = np.zeros(n)
    if shift >= 0:
        m = n - shift
        if m > 0:
            idx = np.arange(m)
            g[idx] += (1.0 - h[idx + shift])
            g[idx + shift] += (-h[idx])
    else:
        j = -shift
        m = n - j
        if m > 0:
            idx = np.arange(j, n)
            g[idx] += (1.0 - h[idx - j])
            g[idx - j] += (-h[idx])
    return g


def _weighted_grad(h, beta, top_k):
    n = len(h)
    dx = 2.0 / n
    corr = _corr_array(h)
    max_c = np.max(corr)
    weights = np.exp(beta * (corr - max_c))
    total_w = weights.sum()
    if total_w < 1e-300:
        weights = np.zeros(len(corr))
        weights[np.argmax(corr)] = 1.0
    else:
        weights /= total_w
    if top_k is not None and top_k < len(corr):
        top_idx = np.argsort(weights)[::-1][:top_k]
        w_top = weights[top_idx].copy()
        w_top /= w_top.sum()
        g = np.zeros(n)
        for i in range(len(top_idx)):
            g += w_top[i] * _grad_at_lag(h, top_idx[i])
    else:
        g = np.zeros(n)
        for i in range(len(corr)):
            if weights[i] > 1e-12:
                g += weights[i] * _grad_at_lag(h, i)
    return g * dx


def _prox_subgrad(h0, n, target_sum, n_iters, beta_start, beta_end,
                  top_k, step_scale, deadline):
    x = h0.copy()
    y = h0.copy()
    t = 1.0
    best = x.copy()
    best_val = _c5_of(x)
    stall = 0
    for it in range(n_iters):
        if time.time() > deadline:
            break
        frac = it / max(1, n_iters - 1)
        beta = beta_start + (beta_end - beta_start) * frac
        if frac > 0.7:
            beta = beta_end
        step = step_scale / (1.0 + 0.015 * it)
        g = _weighted_grad(y, beta, top_k)
        t_new = (1.0 + np.sqrt(1.0 + 4.0 * t * t)) / 2.0
        x_new = _project_simplex(y - step * g, target_sum)
        y_new = x_new + ((t - 1.0) / t_new) * (x_new - x)
        y_new = _project_simplex(y_new, target_sum)
        x = x_new
        y = y_new
        t = t_new
        cv = _c5_of(x)
        if cv < best_val - 1e-10:
            best_val = cv
            best = x.copy()
            stall = 0
        else:
            stall += 1
        if stall > 80:
            x = _project_simplex(best + 0.1 * (np.random.RandomState(it).rand(n) - 0.5), target_sum)
            y = x.copy()
            t = 1.0
            stall = 0
    return best, best_val

        i_src = int(np.argmax(g))

def _slsqp_smooth(h0, n, target_sum, alpha, maxiter, deadline):
    dx = 2.0 / n

    def obj(h):
        corr = np.correlate(h, 1.0 - h, mode='full')
        m = np.max(corr)
        if m < -500:
            return m * dx
        return (m + np.log(np.sum(np.exp(alpha * (corr - m)))) / alpha) * dx

    def eq_fun(h):
        return h.sum() - target_sum

    def eq_jac(h):
        return np.ones(n)

    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': eq_fun, 'jac': eq_jac}]
    try:
        res = minimize(obj, h0, method='SLSQP', bounds=bounds, constraints=cons,
                       options={'maxiter': maxiter, 'ftol': 1e-14})
        return _fix_sum(res.x, target_sum)
    except Exception:
        return h0


def _interpolate_to(h_src, n_dst):
    n_src = len(h_src)
    if n_src == n_dst:
        return h_src.copy()
    return np.interp(np.arange(n_dst), np.arange(n_src), h_src)


def _flip_cd(h0, n, target_sum, max_rounds, deadline):
    h = h0.copy()
    cur_val = _c5_of(h)
    for rd in range(max_rounds):
        if time.time() > deadline:
            break
        improved = False
        for j in range(n):
            old = h[j]
            if old < 0.01 or old > 0.99:
                continue
            h[j] = 0.0
            c0 = _c5_of(h)
            h[j] = 1.0
            c1 = _c5_of(h)
            if min(c0, c1) < cur_val - 1e-12:
                h[j] = 0.0 if c0 < c1 else 1.0
                cur_val = min(c0, c1)
                improved = True
            else:
                h[j] = old
        if not improved:
            break
    return h, _c5_of(h)
```
