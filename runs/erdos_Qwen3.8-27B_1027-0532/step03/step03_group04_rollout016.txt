This is still O(n) per pair. The total is O(|A|·|B|·n) = O(n³/4).

For n=400: 16M operations. In pure Python this would be slow, but with numpy vectorization over the k dimension, it's just 40000 numpy operations on arrays of length 400, which should take a few seconds.

Let me also consider: is it possible that the optimal solution is NOT binary? 

If the optimal solution has a fractional value, then no amount of binary local search will find it. In that case, the SLSQP refinement step is crucial.

However, I suspect that for this problem, the optimal solution is binary (or very close to binary), because:
- The feasible region is a polytope (box + one linear constraint)
- The objective is the maximum of linear functions
- The maximum of linear functions is convex (wait, no - max of affine functions is convex)
- We're minimizing a convex function over a polytope

Wait, that's a key point! The objective is:
f(h) = max_k (A_k @ h) where A_k is a fixed vector (depending on the shift k and the "1-h" part)

But wait, it's not exactly linear in h because (1-h(x+k)) depends on h. Let me reconsider.

O(k) = ∑_i h[i] * (1-h[i+k]) = ∑_i h[i] - ∑_i h[i]*h[i+k]

The first term ∑_i h[i] = n/2 is constant (by constraint). So:
O(k) = n/2 - ∑_i h[i]*h[i+k]

We want to minimize max_k O(k) = n/2 - min_k ∑_i h[i]*h[i+k]

So we want to maximize min_k ∑_i h[i]*h[i+k].

The function g(k) = ∑_i h[i]*h[i+k] is the autocorrelation of h (at lag k). We want to maximize the minimum autocorrelation value.

Now, ∑_i h[i]*h[i+k] is a quadratic form in h (it's h^T P_k h where P_k is a shift matrix). The objective is:
maximize min_k (h^T P_k h)

This is a non-convex optimization problem (maximizing a minimum of quadratic forms). The constraint set is a polytope.

For a non-convex optimization over a polytope, the optimal solution is NOT necessarily at a vertex. So the optimal solution might be non-binary.

However, in practice, for this type of problem, the solutions tend to be near-binary. Let me verify: if we consider the Lagrangian, at an optimum, the gradient of the active constraint(s) should be in the normal cone of the feasible set at that point. For a vertex of the polytope, this means at most n/2 + 1 coordinates are not at their bounds (by the linear constraint). But actually, at a vertex of the set {h : 0≤h≤1, ∑h=n/2}, at most one coordinate is fractional (since we have n box constraints + 1 equality constraint, a vertex has at least n-1 active constraints, meaning at most 1 fractional variable).

Wait, that's not right either. At a vertex of {h ∈ [0,1]^n : ∑h_i = n/2}, we need n linearly independent active constraints. The constraint ∑h_i = n/2 is one. Then we need n-1 more from the box constraints. So at most 1 variable is fractional. Yes!

So any vertex of the feasible polytope has at most one fractional variable. For n even, n/2 is an integer, so we can have all variables binary and still satisfy the constraint.

Now, the question is: is the optimal solution at a vertex? For non-convex problems, the global optimum can be anywhere. But in practice, for this problem, I believe the optimum is very close to a vertex.

So my strategy of searching in the binary space + polishing with continuous optimization should work well.

def compute_c5(h):

def compute_overlap_scores(h):

    n = len(h)

def project_feasible(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    diff = target_sum - np.sum(h)
    if abs(diff) < 1e-14:
        return h
    if diff > 0:
        idx = np.where(h < 1.0 - 1e-10)[0]
    else:
        idx = np.where(h > 1e-10)[0]
    if len(idx) == 0:
        return h
    h = h.copy()
    h[idx] += diff / len(idx)
    h = np.clip(h, 0.0, 1.0)
    residual = target_sum - np.sum(h)
    if abs(residual) > 1e-10:
        if residual > 0:
            idx2 = np.where(h < 1.0)[0]
        else:
            idx2 = np.where(h > 0.0)[0]
        if len(idx2) > 0:
            h[idx2] += residual / len(idx2)
            h = np.clip(h, 0.0, 1.0)
    return h

def to_binary(h, target_n_ones):
    """Convert h to binary with exactly target_n_ones ones."""
    n = len(h)
    idx = np.argsort(-h)
    out = np.zeros(n)
    out[idx[:target_n_ones]] = 1.0
    return out

def thue_morse(n):

    tm = np.zeros(n, dtype=int)
    for i in range(1, n):
        tm[i] = tm[i // 2] ^ (i % 2)
    return tm.astype(float)

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr)) * dx

def project_feasible(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    diff = target_sum - np.sum(h)
    if abs(diff) < 1e-14:
        return h
    if diff > 0:
        idx = np.where(h < 1.0 - 1e-10)[0]
    else:
        idx = np.where(h > 1e-10)[0]
    if len(idx) == 0:
        return h
    h = h.copy()
    h[idx] += diff / len(idx)
    h = np.clip(h, 0.0, 1.0)
    residual = target_sum - np.sum(h)
    if abs(residual) > 1e-10:
        if residual > 0:
            idx2 = np.where(h < 1.0)[0]
        else:
            idx2 = np.where(h > 0.0)[0]
        if len(idx2) > 0:
            h[idx2] += residual / len(idx2)
            h = np.clip(h, 0.0, 1.0)
