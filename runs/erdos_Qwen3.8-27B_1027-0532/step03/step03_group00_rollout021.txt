This is the minimum of the autocorrelation of the indicator function of A!

So the problem reduces to: find a measurable set A ⊂ [0,2] with |A| = 1 that maximizes the minimum of its autocorrelation function.

The autocorrelation is R(k) = |A ∩ (A-k)| = ∫ 1_A(x) 1_A(x+k) dx.

We want to maximize min_k R(k).

Since R(0) = |A| = 1, and R(k) → 0 as |k| → ∞ (for bounded sets), the minimum is achieved at some finite k.

For A = [0,1], R(k) = |A ∩ (A-k)| = |[0,1] ∩ [-k, 1-k]|.
- For k ∈ [0,1]: R(k) = 1-k
- For k ∈ [-1,0]: R(k) = 1+k
- For |k| > 1: R(k) = 0

So min_k R(k) = 0, giving C₅ = 1 - 0 = 1. Bad.

For A = ∪ of many small intervals spread throughout [0,2]:
If A is "equidistributed", then R(k) ≈ |A|² / |domain| = 1/2 for all k (in the large-scale limit).
So min_k R(k) ≈ 1/2, giving C₅ ≈ 1 - 1/2 = 1/2 = 0.5.

But we know we can do better than 0.5 (the current record is ~0.38).

The key is to find a set A where the autocorrelation is as flat as possible (close to 1/2 for all k), but slightly above 1/2 at the "worst" lags.

This is related to the concept of "difference sets" and "Sidon sets" in combinatorics, but in the continuous setting.

25. **A different approach - Fourier analysis**:

R(k) = ∫ 1_A(x) 1_A(x+k) dx

In Fourier space:
1_A(x) = sum_n c_n e^{2πinx/2} (Fourier series on [0,2])

R(k) = sum_n |c_n|² e^{2πink/2}

We want R(k) to be as close to a constant as possible. R(0) = |A| = 1.
The average of R(k) over k ∈ [0,2] is |c_0|² = (|A|/2)² = 1/4.

Wait, that doesn't seem right. Let me redo.

If f(x) = 1_A(x) on [0,2] (periodically extended), then:
R(k) = ∫₀² f(x) f(x+k) dx (with periodic extension)

Fourier: f(x) = sum_n c_n e^{iπnx} (period 2)
R(k) = sum_n |c_n|² e^{iπnk}

R(0) = sum |c_n|² = ∫ f² = |A| = 1 (since f is 0/1).
Average of R over [0,2] = |c_0|² = (mean of f)² = (1/2)² = 1/4.

We want min_k R(k) to be as large as possible. Since the average is 1/4, the maximum possible minimum is at most 1/4 (if R is constant, which it can't be since R(0)=1).

Actually, we can't make R constant because R(0) = 1 ≠ 1/4. So there's always some variation.

The question is: what's the best we can do?

If we think of it as: we have a "budget" of 1 for R(0) and the rest of the energy is spread among other Fourier modes. To maximize the minimum of R(k), we want to spread the non-DC energy as evenly as possible across all shifts.

In the discrete setting, this is related to "flat" autocorrelation sequences (like Barker sequences, Zadoff-Chu sequences, etc.).

    return np.correlate(h, 1.0 - h, mode='full')

    n = len(h)
    dx = 2.0 / n
    return float(np.max(compute_corr(h))) * dx

def project_feasible(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    for _ in range(500):
        diff = target_sum - np.sum(h)
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            mask = h < 1.0
        else:
            mask = h > 0.0
        cnt = int(mask.sum())
        if cnt == 0:

        h = h.copy()
        h[mask] += diff / cnt

def lse_obj_grad(h, alpha, target, pen_w):
    n = len(h)
    corr = np.correlate(h, 1.0 - h, mode='full')
    c_max = float(np.max(corr))
    shifted = alpha * (corr - c_max)
    shifted = np.clip(shifted, -700.0, 0.0)
    exp_shifted = np.exp(shifted)
    sum_exp = float(np.sum(exp_shifted))
    logsum = float(np.log(sum_exp))
    obj = c_max + logsum / alpha
    diff = float(np.sum(h) - target)
    obj += pen_w * diff * diff

    term1 = np.convolve(w, 1.0 - h, mode='full')

_g_blk_target = 0.0


def compute_corr(h):
    return np.correlate(h, 1.0 - h, mode='full')


def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    return float(np.max(compute_corr(h))) * dx


def project_feasible(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    for _ in range(500):
        diff = target_sum - np.sum(h)
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            mask = h < 1.0
        else:
            mask = h > 0.0
        cnt = int(mask.sum())
        if cnt == 0:
            break
        h = h.copy()
        h[mask] += diff / cnt
        h = np.clip(h, 0.0, 1.0)
    return h


def _lse_obj_and_grad(h, alpha, target, pen_w):
    n = len(h)
    corr = np.correlate(h, 1.0 - h, mode='full')
    c_max = float(np.max(corr))
    shifted = alpha * (corr - c_max)
    shifted = np.clip(shifted, -700.0, 0.0)
    exp_shifted = np.exp(shifted)
    sum_exp = float(np.sum(exp_shifted))
    if sum_exp < 1e-300:
        sum_exp = 1e-300
    obj = c_max + float(np.log(sum_exp)) / alpha
    diff = float(np.sum(h) - target)
    obj += pen_w * diff * diff
    w = exp_shifted / sum_exp
    term1 = np.convolve(w, 1.0 - h, mode='full')
    w_flip = w[::-1]
    term2 = np.convolve(w_flip, h, mode='full')
    grad = term1[n - 1:2 * n - 1].copy() - term2[n - 1:2 * n - 1]
    grad += 2.0 * pen_w * diff
    return obj, grad


def _global_fun(x):
    if time.time() > _g_deadline:
        raise ValueError("timeout")
    return _lse_obj_and_grad(x, _g_alpha, _g_target, _g_pen_w)[0]


def _global_jac(x):
    if time.time() > _g_deadline:
        raise ValueError("timeout")
    return _lse_obj_and_grad(x, _g_alpha, _g_target, _g_pen_w)[1]


def _global_optimize(h0, alpha, target, pen_w, maxiter, t_limit):
    global _g_alpha, _g_target, _g_pen_w, _g_deadline, _g_n
    _g_alpha = alpha
    _g_target = target
    _g_pen_w = pen_w
    _g_deadline = time.time() + t_limit
    _g_n = len(h0)
    bounds = [(0.0, 1.0)] * len(h0)
    try:
        res = minimize(_global_fun, h0, jac=_global_jac, method='L-BFGS-B',
                       bounds=bounds, options={'maxiter': maxiter, 'ftol': 1e-16, 'gtol': 1e-12})
        return res.x
    except Exception:
        return h0


def _block_fun(x):
    n = len(_g_blk_full)
    h = _g_blk_full.copy()
    h[_g_blk_s:_g_blk_e] = np.clip(x, 0.0, 1.0)
    h = project_feasible(h, _g_blk_target)
    corr = np.correlate(h, 1.0 - h, mode='full')
    c_max = float(np.max(corr))
    shifted = _g_blk_alpha * (corr - c_max)
    shifted = np.clip(shifted, -700.0, 0.0)
    exp_s = np.exp(shifted)
    sum_e = float(np.sum(exp_s))
    return c_max + float(np.log(sum_e)) / _g_blk_alpha


def _block_jac(x):
    n = len(_g_blk_full)
    h = _g_blk_full.copy()
    h[_g_blk_s:_g_blk_e] = np.clip(x, 0.0, 1.0)
    h = project_feasible(h, _g_blk_target)
    corr = np.correlate(h, 1.0 - h, mode='full')
    c_max = float(np.max(corr))
    shifted = _g_blk_alpha * (corr - c_max)
    shifted = np.clip(shifted, -700.0, 0.0)
    exp_s = np.exp(shifted)
    sum_e = float(np.sum(exp_s))
    w = exp_s / sum_e
    t1 = np.convolve(w, 1.0 - h, mode='full')
    t2 = np.convolve(w[::-1], h, mode='full')
    g = t1[n - 1:2 * n - 1] - t2[n - 1:2 * n - 1]
    return g[_g_blk_s:_g_blk_e].copy()


def _block_optimize(h, s, e, alpha, target, maxiter):
    global _g_blk_full, _g_blk_s, _g_blk_e, _g_blk_alpha, _g_blk_target
    _g_blk_full = h
    _g_blk_s = s
    _g_blk_e = e
    _g_blk_alpha = alpha
    _g_blk_target = target
    bs = e - s
    x0 = h[s:e].copy()
    bounds = [(0.0, 1.0)] * bs
    try:
        res = minimize(_block_fun, x0, jac=_block_jac, method='L-BFGS-B',
                       bounds=bounds, options={'maxiter': maxiter, 'ftol': 1e-14})
        return res.x
    except Exception:
        return x0


def _interpolate(h_src, n_dst, target_dst):
    n_src = len(h_src)
    if n_src == n_dst:
        return project_feasible(h_src.copy(), target_dst)
    x_new = np.linspace(0.0, 1.0, n_dst)
    x_old = np.linspace(0.0, 1.0, n_src)
    h_out = np.interp(x_new, x_old, h_src)
    return project_feasible(h_out, target_dst)


def run(seed=42, budget_s=1300, **kwargs):
    global _g_n, _g_alpha, _g_target, _g_pen_w, _g_deadline
    start_time = time.time()
    rng = np.random.RandomState(seed)

    def tleft():
        return budget_s - 30.0 - (time.time() - start_time)

    h_init = np.array(initial_h_values, dtype=float)
    n = len(h_init)
    target = n / 2.0

    best_h = project_feasible(h_init.copy(), target)
    best_score = compute_c5(best_h)

    # Phase 1: L-BFGS-B with smooth-to-sharp alpha schedule
    alphas_p1 = [3, 5, 10, 20, 50, 100, 200, 500, 1000]
    for i, a in enumerate(alphas_p1):
        if tleft() < 70:
            break
        pw = 500.0 + 500.0 * i
        tl = min(tleft() - 10, 40.0 + 5.0 * i)
        h_new = _global_optimize(best_h, a, target, pw, 150 + 30 * i, tl)
        h_new = project_feasible(h_new, target)
        sc = compute_c5(h_new)
        if sc < best_score:
            best_score = sc
            best_h = h_new

    # Phase 2: Block coordinate descent with L-BFGS-B
    deadline_p2 = start_time + (budget_s - 30.0) * 0.42
    for bs in [10, 14, 18, 24]:
        if time.time() > deadline_p2 or tleft() < 60:
            break
        n_blocks = n // bs
        for rd in range(3):
            if time.time() > deadline_p2:
                break
            perm = list(range(n_blocks))
            rng.shuffle(perm)
            for bi in perm:
                if time.time() > deadline_p2:
                    break
                s = bi * bs
                e = s + bs
                x_new = _block_optimize(best_h, s, e, 400, target, 80)
                h_test = best_h.copy()
                h_test[s:e] = np.clip(x_new, 0.0, 1.0)
                h_test = project_feasible(h_test, target)
                sc = compute_c5(h_test)
                if sc < best_score:
                    best_score = sc
                    best_h = h_test

    # Phase 3: High-alpha L-BFGS-B
    if tleft() > 70:
        for a in [2000, 5000, 10000]:
            if tleft() < 45:
                break
            h_new = _global_optimize(best_h, a, target, 10000.0, 300, min(tleft() - 10, 55.0))
            h_new = project_feasible(h_new, target)
            sc = compute_c5(h_new)
            if sc < best_score:
                best_score = sc
                best_h = h_new

    # Phase 4: Multi-scale (coarse optimize then upsample)
    if tleft() > 200:
        n_coarse = max(n // 3, 50)
        if n_coarse % 2 == 0:
            target_coarse = n_coarse / 2.0
            h_coarse = _interpolate(best_h, n_coarse, target_coarse)
            h_coarse = _global_optimize(h_coarse, 200, target_coarse, 5000.0, 200, 40.0)
            h_coarse = _global_optimize(h_coarse, 1000, target_coarse, 10000.0, 200, 40.0)
            h_coarse = project_feasible(h_coarse, target_coarse)
            h_up = _interpolate(h_coarse, n, target)
            h_up = _global_optimize(h_up, 500, target, 10000.0, 200, 40.0)
            h_up = project_feasible(h_up, target)
            sc = compute_c5(h_up)
            if sc < best_score:
                best_score = sc
                best_h = h_up

    # Phase 5: Stochastic perturbations + refinement
    deadline_p5 = start_time + (budget_s - 30.0) * 0.78
    scales = [0.005, 0.01, 0.02, 0.03, 0.05, 0.08]
    for trial in range(12):
        if time.time() > deadline_p5:
            break
        sc_ = scales[trial % len(scales)]
        h_pert = best_h + rng.randn(n) * sc_
        h_pert = project_feasible(h_pert, target)
        h_new = _global_optimize(h_pert, 500, target, 10000.0, 200, min(35.0, tleft() - 10))
        h_new = project_feasible(h_new, target)
        sc = compute_c5(h_new)
        if sc < best_score:
            best_score = sc
            best_h = h_new

    # Phase 6: Final block descent with high alpha
    if tleft() > 50:
        deadline_p6 = start_time + budget_s - 45.0
        for bs in [12, 16, 20]:
            if time.time() > deadline_p6:
                break
            n_blocks = n // bs
            for bi in range(n_blocks):
                if time.time() > deadline_p6:
                    break
                s = bi * bs
                e = s + bs
                x_new = _block_optimize(best_h, s, e, 1500, target, 60)
                h_test = best_h.copy()
                h_test[s:e] = np.clip(x_new, 0.0, 1.0)
                h_test = project_feasible(h_test, target)
                sc = compute_c5(h_test)
                if sc < best_score:
                    best_score = sc
                    best_h = h_test

    # Phase 7: Final L-BFGS-B polish
    if tleft() > 20:
        h_new = _global_optimize(best_h, 5000, target, 20000.0, 300, min(tleft() - 5, 40.0))
        h_new = project_feasible(h_new, target)
        sc = compute_c5(h_new)
        if sc < best_score:
            best_score = sc
            best_h = h_new

    best_h = project_feasible(best_h, target)
    best_score = compute_c5(best_h)
    return best_h, best_score, n
