2.Approachandrationale

The central idea is to apply a binary particle swarm optimization (PSO) algorithm specifically tailored for non-negative functions with bounded integrals. Unlike gradient-based optimization, PSO explores a broader solution space by representing the step function as a binary vector (0 or 1) while satisfying the integral constraint (sum = n_points/2). This approach addresses the gradient-based optimization's tendency to get stuck in local minima by leveraging particle swarm dynamics.

The key innovations are:
1. Using binary representation to model the step function
2. Maintaining explicit feasibility through repair mechanisms
3. Implementing targeted binary mutations (swap, crossover, binary crossover) and global reinitialization
4. Performing resolution increases with mode changes between binary and real representations

The algorithm distinguishes valid solutions by ensuring:
- All values are within [0,1]
- Sum(h) * dx = 1 (where dx=2/n_points)
Through iterative repair operations, any solution falling outside these constraints is automatically corrected by 1-bit flips.

3.Mathematicalspecification

Variables:
- h: Binary vector of length n_points
- dx = 2/n_points (step size)
- Projection function to enforce 0-h[i]-1 and integral constraint
- Cross-correlation computation for C_5

Constraints:
1. 0 ≤ h[i] ≤ 1 for all i
2. ∫₀² h(x) dx = 1 ⇔ ∑h[i] * dx = 1 ⇔ ∑h[i] = n_points/2

Objective:
Minimize C_5 = (1/n_points) * max_k ∫₀² h(x)(1-h(x+k)) dx  
⇒ Minimize max displacement overlap (ED note: The original formulation included dx=2/n_points, but we'll maintain n_points in denominator consistent with the provided code)

Optimization transformation:
Convert continuous constraint to integer problem by:
h[i] ∈ {0,1} and ∑h[i] = n_points/2

Operations:
- Binary swap mutation: Exchange three randomized indices
- Crossover mutation: Swap blocks between randomly selected parents
- Binary crossover: Create artificial parents via tournament selection
- Projection: Iterative clipping/repair to meet feasibility

def binary_repair(x):
    """Repair to enforce [0,1] and correct sum over 180 points"""
    x = np.clip(x, 0, 1)
    n = len(x)
    target_sum = n / 2.0  # 90 for n=180
    s = np.sum(x)
    if abs(s - target_sum) < 1e-5:
        return x.copy()
    # Iterate 80x to enforce sum
    lo, hi = -2.0, 2.0
    for _ in range(80):
        mid = (lo + hi) / 2.0
        s_temp = np.clip(x - mid, 0, 1).sum()
        if s_temp > target_sum:
            lo = mid
        else:
            hi = mid
    lam = (lo + hi) / 2.0
    return np.clip(x - lam, 0, 1)

def project_onto_constraint(x, target_sum):
    lo, hi = -2.0, 2.0
    while hi - lo > 1e-7:
        mid = (lo + hi) / 2.0
        s_temp = np.clip(x - mid, 0, 1).sum()
        if s_temp > target_sum:
            lo = mid
        else:
            hi = mid
    lam = (lo + hi) / 2.0
    return np.clip(x - lam, 0, 1)
