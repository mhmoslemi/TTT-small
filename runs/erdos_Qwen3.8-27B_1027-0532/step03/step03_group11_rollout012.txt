- j appears as h[n+ℓ] when n = j-ℓ, valid if 0 ≤ j-ℓ ≤ N-1-ℓ, i.e., ℓ ≤ j ≤ N-1
  Contribution: dx * (1-h[j-ℓ])
- j appears as h[n] (inside 1-h[n]) when n = j, valid if 0 ≤ j ≤ N-1-ℓ
  Contribution: -dx * h[j+ℓ]

So for ℓ ≥ 0:
∂c/∂h[j] = dx*(1-h[j-ℓ]) * [ℓ ≤ j ≤ N-1] - dx*h[j+ℓ] * [0 ≤ j ≤ N-1-ℓ]

For lag < 0, ℓ = -m (m > 0):
c = dx * sum_{n=0}^{N-1-m} h[n]*(1-h[n+m])
∂c/∂h[j]:
- j appears as h[n] when n = j, valid if 0 ≤ j ≤ N-1-m
  Contribution: dx * (1-h[j+m])
- j appears as h[n+m] (inside 1-h[n+m]) when n = j-m, valid if 0 ≤ j-m ≤ N-1-m, i.e., m ≤ j ≤ N-1
  Contribution: -dx * h[j-m]

So for m > 0:
∂c/∂h[j] = dx*(1-h[j+m]) * [0 ≤ j ≤ N-1-m] - dx*h[j-m] * [m ≤ j ≤ N-1]

Let me code this up cleanly:

```python
def gradient_of_shift(h, k_idx):
    n = len(h)
    dx = 2.0 / n
    lag = k_idx - (n - 1)
    grad = np.zeros(n)
    if lag >= 0:
        ell = lag
        m = n - ell
        # ∂c/∂h[j] for j in [ell, n-1]: dx*(1-h[j-ell])
        grad[ell:] += dx * (1.0 - h[:m])
        # ∂c/∂h[j] for j in [0, m-1]: -dx*h[j+ell]
        grad[:m] -= dx * h[ell:]
    else:
        m = -lag
        mm = n - m
        # ∂c/∂h[j] for j in [0, mm-1]: dx*(1-h[j+m])
        grad[:mm] += dx * (1.0 - h[m:m+mm])
        # ∂c/∂h[j] for j in [m, n-1]: -dx*h[j-m]
        grad[m:] -= dx * h[:mm]
    return grad
```

Now let me think about the overall algorithm:

**Algorithm: Momentum Subgradient + Binary Refinement + SLSQP Polish**

Phase 1: Multi-start SLSQP (similar to before but with different initializations)
Phase 2: Momentum subgradient method on the worst shift
Phase 3: Binary local search with multi-shift awareness
Phase 4: Final SLSQP polish

For Phase 2, the key steps:
- Maintain momentum vector v
- At each iteration:
  - Compute all c_k values
  - Find k* = argmax
  - Compute g = ∇c_{k*}(h)
  - Update: v = β*v + (1-β)*g
  - Step: h_new = h - α * v
  - Project: h_new = project_onto_constraint(h_new, N/2)
  - If c5(h_new) < c5(h): accept
  - Else: try smaller step or revert

For the step size α, I'll use a simple adaptive scheme:
- Start with α = 0.1
- If improvement: α *= 1.05 (slightly increase)
- If no improvement: α *= 0.7 (decrease)

Actually, for subgradient methods, the standard step size is:
α_t = γ_t / ||g_t|| where γ_t decreases (e.g., γ_t = 1/sqrt(t) or γ_t = 1/t)

But with momentum, we can use a fixed step size that works well in practice.

Let me also think about the "active set" approach: instead of just the single worst shift, we could use a weighted average of the top few shifts. This is like the "centrally corrected subgradient" method.

**Active set subgradient:**
- Find the top M shifts (by c_k value)
- Compute a weighted average of their gradients (weights proportional to c_k)
- Take a step in that averaged direction

This should give a more robust descent direction than just the single worst shift.

```python
import numpy as np
from scipy.optimize import minimize
import time

def project_onto_constraint(h, target_sum):
    lo, hi = -2.0, 2.0
    for _ in range(80):
        mid = (lo + hi) / 2.0
        s = np.clip(h - mid, 0.0, 1.0).sum()
        if s > target_sum:
            lo = mid
        else:
            hi = mid
    lam = (lo + hi) / 2.0
    return np.clip(h - lam, 0.0, 1.0)

def compute_c5_array(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full') * dx
    return corr

def compute_c5(h):
    return float(np.max(compute_c5_array(h)))

def gradient_of_shift(h, k_idx):
    n = len(h)
    dx = 2.0 / n
    lag = k_idx - (n - 1)
    grad = np.zeros(n)
    if lag >= 0:
        ell = lag
        m = n - ell
        grad[ell:] += dx * (1.0 - h[:m])
        grad[:m] -= dx * h[ell:]
    else:
        m = -lag
        mm = n - m
        grad[:mm] += dx * (1.0 - h[m:m+mm])
        grad[m:] -= dx * h[:mm]
    return grad

def active_set_gradient(h, c5_arr, top_m=5):
    """Compute weighted average gradient of the top M worst shifts."""
    n = len(h)
    # Find the top M shifts
    idx = np.argsort(c5_arr)[::-1][:top_m]
    weights = c5_arr[idx]
    weights = weights / weights.sum()
    grad = np.zeros(n)
    for w, ki in zip(weights, idx):
        grad += w * gradient_of_shift(h, ki)
    return grad

def momentum_subgradient(h_init, budget_s, start_time, top_m=5):
    n = len(h_init)
    target_sum = n / 2.0
    h = h_init.copy()
    v = np.zeros(n)
    beta = 0.7  # momentum coefficient
    alpha = 0.3  # initial step size
    current_c5 = compute_c5(h)
    best_h = h.copy()
    best_c5 = current_c5
    
    patience = 0
    max_patience = 500
    
    while time.time() - start_time < budget_s:
        c5_arr = compute_c5_array(h)
        k_star = np.argmax(c5_arr)
        current_c5 = float(c5_arr[k_star])
        
        if current_c5 < best_c5 - 1e-10:
            best_c5 = current_c5
            best_h = h.copy()
            patience = 0
        else:
            patience += 1
        
        if patience > max_patience:
            break
        
        # Compute active set gradient
        g = active_set_gradient(h, c5_arr, top_m)
        
        # Normalize gradient for step size
        g_norm = np.linalg.norm(g)
        if g_norm < 1e-10:
            break
        
        # Update momentum
        v = beta * v + (1 - beta) * g / g_norm
        
        # Take step
        h_new = h - alpha * v
        h_new = project_onto_constraint(h_new, target_sum)
        
        new_c5 = compute_c5(h_new)
        if new_c5 < current_c5:
            h = h_new
            alpha = min(alpha * 1.02, 1.0)
        else:
            # Try smaller step
            h_new = h - alpha * 0.5 * v
            h_new = project_onto_constraint(h_new, target_sum)
            new_c5 = compute_c5(h_new)
            if new_c5 < current_c5:
                h = h_new
            alpha *= 0.8
        
        # Adapt momentum
        if patience > 100:
            beta = max(beta * 0.99, 0.3)
    
    return best_h, best_c5
```

```python
from scipy.optimize import minimize
import time

def project_onto_constraint(h, target_sum):
    lo, hi = -2.0, 2.0
    for _ in range(80):
        mid = (lo + hi) / 2.0
        s = np.clip(h - mid, 0.0, 1.0).sum()
        if s > target_sum:
            lo = mid
        else:
            hi = mid
    lam = (lo + hi) / 2.0
    return np.clip(h - lam, 0.0, 1.0)

def compute_c5_array(h):
    n = len(h)
    dx = 2.0 / n
    return np.correlate(h, 1.0 - h, mode='full') * dx

def compute_c5(h):
    return float(np.max(compute_c5_array(h)))

def gradient_of_shift(h, k_idx):
    n = len(h)
    dx = 2.0 / n
    lag = k_idx - (n - 1)
    grad = np.zeros(n)
    if lag >= 0:
        ell = lag
        m = n - ell
        grad[ell:] += dx * (1.0 - h[:m])
        grad[:m] -= dx * h[ell:]
    else:
        m = -lag
        mm = n - m
        grad[:mm] += dx * (1.0 - h[m:m+mm])
        grad[m:] -= dx * h[:mm]
    return grad

def smooth_objective(h, eps):
    n = len(h)
    c5_arr = compute_c5_array(h)
    cmax = np.max(c5_arr)
    x = (c5_arr - cmax) / eps
    x -= np.max(x)
    return cmax + eps * np.log(np.sum(np.exp(x)))

def smooth_gradient(h, eps):
    n = len(h)
    c5_arr = compute_c5_array(h)
    cmax = np.max(c5_arr)
    x = (c5_arr - cmax) / eps
    x -= np.max(x)
    ex = np.exp(x)
    sexp = np.sum(ex)
    w = ex / sexp
    grad = np.zeros(n)
    # Only compute gradients for shifts with significant weight
    for k in range(2 * n - 1):
        wk = w[k]
        if wk < 1e-15:
            continue
        grad += wk * gradient_of_shift(h, k)
    return grad

def constraint_fun(h):
    return float(np.sum(h) - len(h) / 2.0)

def constraint_jac(h):
    return np.ones(len(h))

def slsqp_optimize(h_init, eps, maxiter, maxtime=None, start_time=None):
    n = len(h_init)
    target_sum = n / 2.0
    h0 = project_onto_constraint(h_init.astype(float).copy(), target_sum)
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': constraint_fun, 'jac': constraint_jac}]
    options = {'maxiter': maxiter, 'ftol': 1e-14}
    try:
        result = minimize(smooth_objective, h0, args=(eps,),
                          jac=smooth_gradient, method='SLSQP',
                          bounds=bounds, constraints=cons, options=options)
        h_opt = project_onto_constraint(result.x, target_sum)
        return h_opt, compute_c5(h_opt)
    except Exception:
        return h0, compute_c5(h0)

def momentum_subgradient(h_init, time_budget, start_time, top_m=5, verbose=False):

    target_sum = n / 2.0
    h = h_init.copy()
    v = np.zeros(n)
    beta = 0.5
    alpha = 0.5
    current_c5 = compute_c5(h)
    best_h = h.copy()
    best_c5 = current_c5
    patience = 0
    
    while time.time() - start_time < time_budget:
        c5_arr = compute_c5_array(h)
        current_c5 = float(np.max(c5_arr))
        
        if current_c5 < best_c5 - 1e-12:
            best_c5 = current_c5
            best_h = h.copy()
            patience = 0
        else:
            patience += 1
        
        if patience > 2000:
            break
        
        # Active set: top M shifts
        top_idx = np.argsort(c5_arr)[::-1][:top_m]

        weights = weights / weights.sum()

            g += w * gradient_of_shift(h, ki)
```

For binary h (values in {0,1}), the problem becomes:

def gradient_of_shift(h, k_idx):
    n = len(h)
    dx = 2.0 / n
    lag = k_idx - (n - 1)
    grad = np.zeros(n)
    if lag >= 0:
        ell = lag
        m = n - ell
        grad[ell:] += dx * (1.0 - h[:m])
        grad[:m] -= dx * h[ell:]
    else:
        m = -lag
        mm = n - m
        grad[:mm] += dx * (1.0 - h[m:m+mm])
        grad[m:] -= dx * h[:mm]
    return grad

    cmax = np.max(c5_arr)
    x = (c5_arr - cmax) / eps
    x -= np.max(x)
    return cmax + eps * np.log(np.sum(np.exp(x)))

    cmax = np.max(c5_arr)

    x -= np.max(x)
