min_h ∑_k λ_k ∑_i h[i]g[i+k]dx s.t. sum(h)=n/2, 0≤h≤1
= min_h (G_λ @ h) s.t. ...

where G_λ[i] = ∑_k λ_k g[i+k] dx

This is just: put all mass where G_λ is smallest (since we're minimizing a linear function). The solution is: h[i] = 1 where G_λ[i] is smallest, h[i] = 0 where it's largest, with exactly n/2 ones.

max_λ min_h (G_λ @ h) s.t. λ ≥ 0, ∑λ = 1
= max_λ (sum of the n/2 smallest values of G_λ)

This is a concave maximization over the simplex! We can solve it with:
- Mirror descent / multiplicative weights on λ
- Or just: iteratively set λ proportional to the current f_k values

**This gives us a much faster algorithm!**

1. Initialize λ uniformly (or based on current solution)
2. Compute G_λ[i] = ∑_k λ_k * g[i+k] * dx
3. Set h[i] = 1 where G_λ is smallest (n/2 of them), 0 otherwise
4. Update λ: λ_k ∝ f_k(h) (or use exponential weights: λ_k ← λ_k * exp(η * f_k(h)))
5. Repeat

**Primal (for fixed g)**: min_h max_k f_k(h) s.t. sum(h)=n/2, 0≤h≤1

By strong duality, the optimal values are equal. So if we can solve the dual well, we get the optimal primal solution.

The dual objective "sum of n/2 smallest values of G_λ" is a concave function of λ (since it's the minimum of linear functions, hence concave; and the sum of the smallest is also concave... wait, let me verify).

Actually, "sum of k smallest values of a vector" as a function of the vector is a concave function. And G_λ is linear in λ. So the composition is concave in λ. Yes, it's a concave maximization over the simplex - a convex optimization problem!

We can solve it with:
- Projected gradient ascent (projecting onto the simplex)
- Mirror descent (multiplicative weights)
- Frank-Wolfe (conditional gradient)

The Frank-Wolfe method is particularly nice here:
- At each step, find the vertex of the simplex that most improves the objective
- This means: for each k, compute the objective value if we set λ = e_k, then take a step toward the best e_k

Actually, for Frank-Wolfe on the simplex:
- Current iterate: λ
- Find v = argmin_{e_k} ⟨∇f(λ), e_k⟩ = e_{k*} where k* = argmin_k ∂f/∂λ_k
- Update: λ ← λ + γ (k* - λ) where γ is the step size

The gradient of the dual objective f(λ) = sum of n/2 smallest values of G_λ:
∂f/∂λ_k = sum of n/2 smallest values of (A_k as a vector) ... no that's not right.

Let me be more careful. f(λ) = sum of the n/2 smallest components of G_λ where G_λ = ∑_k λ_k a_k and a_k is the vector with a_k[i] = g[i+k] * dx.

The subgradient of f with respect to G is: the indicator vector of the n/2 smallest components of G.

So ∂f/∂λ_k = S^T a_k where S[i] = 1 if G[i] is among the n/2 smallest, 0 otherwise.

This means: ∂f/∂λ_k = ∑_{i ∈ S} a_k[i] = ∑_{i ∈ S} g[i+k] * dx

So the gradient is just: for each k, the sum of g[i+k]*dx over the positions i where h=1 (since in the optimal primal, h[i]=1 exactly where G_λ[i] is smallest).

This is exactly f_k(h)! So the gradient of the dual objective is the vector (f_1(h), f_2(h), ..., f_{2n-1}(h)).

So Frank-Wolfe becomes:
1. Compute h (top n/2 positions where G_λ is smallest)
2. Compute f_k(h) for all k
3. Find k* = argmax_k f_k(h) (the worst shift)
4. Update: λ ← (1-γ)λ + γ * e_{k*}
5. Compute new G_λ
6. Repeat

This is essentially the **mirror descent / exponentiated gradient** algorithm for the max! And it's extremely simple and fast.

Each iteration:
- Compute G_λ: O(n²) (for n=400, ~160K ops)
- Find n/2 smallest: O(n log n)
- Compute f_k for all k: this is O(n²) (correlation)
- Update λ: O(n)

Total per iteration: O(n²) ≈ 160K ops for n=400.
In 1 second: ~10^7 iterations (at 160K ops each, with numpy vectorization, probably 10K-100K iterations per second).

This is MUCH faster than the LP approach! And it directly optimizes the dual, which by strong duality gives the optimal primal solution.

import numpy as np
from scipy.optimize import minimize
import cvxpy as cp
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr)) * dx

def project_feasible(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    diff = target_sum - np.sum(h)
    if abs(diff) < 1e-12:
        return h
    h = h.copy()
    if diff > 0:
        idx = np.where(h < 1.0 - 1e-10)[0]
    else:
        idx = np.where(h > 1e-10)[0]
    if len(idx) > 0:
        h[idx] += diff / len(idx)
    h = np.clip(h, 0.0, 1.0)
    residual = target_sum - np.sum(h)
    if abs(residual) > 1e-10:
        if residual > 0:
            idx2 = np.where(h < 1.0)[0]
        else:
            idx2 = np.where(h > 0.0)[0]
        if len(idx2) > 0:
            h[idx2] += residual / len(idx2)
            h = np.clip(h, 0.0, 1.0)
    return h

def build_overlap_matrix(g, n):
    """M[i,k] = g[i+k-(n-1)]*dx if 0<=i+k-(n-1)<n, else 0.
    Shape: (n, 2n-1)"""
    dx = 2.0 / n
    n_shifts = 2 * n - 1
    i_idx = np.arange(n)[:, None]
    tau_idx = np.arange(-(n-1), n)[None, :]
    combined = i_idx + tau_idx
    valid = (combined >= 0) & (combined < n)
    M = np.zeros((n, n_shifts))
    M[valid] = g[combined[valid]] * dx
    return M

def solve_lp_for_fixed_g(g, n, target, M, max_iters=2000, eta_init=1.0):
    """Solve min_h max_k (M_k @ h) using multiplicative weights on dual.
    M has shape (n, 2n-1), so (M.T @ lambda) has shape (n,).
    The optimal h has 1s where (M.T @ lambda) is smallest.
    """
    n_shifts = 2 * n - 1
    lam = np.ones(n_shifts) / n_shifts
    eta = eta_init
    h = np.zeros(n)
    f_k = np.zeros(n_shifts)
    
    for it in range(max_iters):
        # Compute cost vector for h
        cost = M.T @ lam  # shape (n,)
        
        # Set h: 1 where cost is smallest (exactly 'target' positions)
        h_new = np.zeros(n)
        # Use partition for efficiency
        part_idx = np.argpartition(cost, int(target))
        threshold = cost[part_idx[int(target)]]
        mask = cost < threshold
        n_set = int(np.sum(mask))
        h_new[mask] = 1.0
        if n_set < int(target):
            eq_mask = (cost == threshold) & (~mask)
            n_eq = int(np.sum(eq_mask))
            n_needed = int(target) - n_set
            if n_needed > 0 and n_eq >= n_needed:
                eq_indices = np.where(eq_mask)[0]
                # Just take the first n_needed (deterministic for reproducibility)
                h_new[eq_indices[:n_needed]] = 1.0
        h = h_new
        
        # Compute f_k = M @ h (overlap at each shift)
        f_k = M @ h  # shape (n_shifts,)
        
        # Dual update: multiplicative weights (exponentiated gradient)
        # lambda_k proportional to exp(eta * f_k)
        # For numerical stability, subtract max
        f_shifted = f_k - np.max(f_k)
        lam = lam * np.exp(eta * f_shifted)
        lam_sum = np.sum(lam)
        if lam_sum > 1e-300:
            lam = lam / lam_sum
        else:
            lam = np.ones(n_shifts) / n_shifts
        
        # Decay eta for convergence
        if it % 200 == 0 and it > 0:
            eta *= 0.98
    
    return h, float(np.max(f_k))

def coa_binary(h_init, n, target, time_limit, n_restarts=3, eta_init=1.0, inner_iters=2000):
    """Cycle of alternating approximations with binary solutions.
    Uses dual decomposition for speed.
    """
    start = time.time()
    best_h = h_init.copy()
    best_c5 = compute_c5(best_h)
    
    for restart in range(n_restarts):
        if time.time() - start > time_limit:
            break
        
        if restart == 0:
            h = h_init.copy()
        else:
            noise = 0.3 * restart
            h = h_init + np.random.randn(n) * noise
            h = project_feasible(h, target)
        
        # Binarize initial h
        h_bin = np.zeros(n)
        sorted_idx = np.argsort(h)[::-1]
        h_bin[sorted_idx[:int(target)]] = 1.0
        h = h_bin.copy()
        
        for outer in range(2000):
            if time.time() - start > time_limit:
                break
            
            g = 1.0 - h
            M = build_overlap_matrix(g, n)
            h_new, val = solve_lp_for_fixed_g(g, n, target, M, 
                                              max_iters=inner_iters, eta_init=eta_init)
            
            # Check if we made progress
            if np.sum(h_new != h) == 0:
                # No change, converged
                break
            
            h = h_new
            c5 = compute_c5(h)
            if c5 < best_c5 - 1e-10:
                best_c5 = c5
                best_h = h.copy()
        
    return best_h, best_c5

def binary_simulated_annealing(h_start, n, target, time_limit, seed=42):
    """Simulated annealing on binary solutions with swap moves."""
    rng = np.random.RandomState(seed)
    start = time.time()
    dx = 2.0 / n
    
    h = h_start.copy()
    best_h = h.copy()
    best_c5 = compute_c5(best_h)
    
    ones = np.where(h == 1)[0]
    zeros = np.where(h == 0)[0]
    
    T = 0.05  # initial temperature (in units of C5)
    T_min = 0.001
    total_steps = 5000000
    cooling = (T_min / T) ** (1.0 / total_steps)
    
    stall = 0
    
    for step in range(total_steps):
        if time.time() - start > time_limit:
            break
        
        # Propose move: swap a random 1 with a random 0
        i = ones[rng.randint(len(ones))]
        j = zeros[rng.randint(len(zeros))]
        
        h[i] = 0
        h[j] = 1
        ones = np.where(h == 1)[0]
        zeros = np.where(h == 0)[0]
        
        c5_new = compute_c5(h)
        delta = c5_new - best_c5
        
        if delta < 0 or rng.random() < np.exp(-delta / T):
            # Accept
            if c5_new < best_c5:
                best_c5 = c5_new
                best_h = h.copy()
                stall = 0
            else:
                stall += 1
        else:
            # Reject: undo
            h[i] = 1
            h[j] = 0
            ones = np.where(h == 1)[0]
            zeros = np.where(h == 0)[0]
            stall += 1
        
        T *= cooling
        
        # Restart if stalled too much
        if stall > 100000:
            h = best_h.copy()
            ones = np.where(h == 1)[0]
            zeros = np.where(h == 0)[0]
            T = 0.02
            stall = 0
    
    return best_h, best_c5
