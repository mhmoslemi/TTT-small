Actually, for a convex piecewise linear function on [0,1], the minimum is at the point where the subgradient contains 0. I can find this by:
1. Computing the slopes at t=0 and t=1
2. If slope at 0 > 0, minimum is at 0
3. If slope at 1 < 0, minimum is at 1
4. Otherwise, binary search for where the slope changes sign

The slope at t is: $\max_k b_k$ among the active k's (the ones achieving the max). More precisely, the subdifferential at t is the convex hull of {b_k : C_k(t) = max_l C_l(t)}.

For a practical implementation:
1. Compute C_k for all k at the current h (with h_j = 0 and h_j = 1 as test points)
2. Find the active set at t=0 and t=1
3. If the max slope is positive at t=0, the minimum is at t=0
4. If the min slope is negative at t=1, the minimum is at t=1
5. Otherwise, use bisection on the slope

import numpy as np
from scipy.optimize import minimize
import time

def compute_corr(h):
    return np.correlate(h, 1.0 - h, mode='full')

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    return float(np.max(compute_corr(h))) * dx

def project_feasible(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    for _ in range(500):
        diff = target_sum - np.sum(h)
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            mask = h < 0.999
        else:
            mask = h > 0.001
        cnt = int(mask.sum())
        if cnt == 0:
            break
        h = h.copy()
        h[mask] += diff / cnt
        h = np.clip(h, 0.0, 1.0)
    return h

def binary_coord_descent(h, n, target, n_sweeps, deadline, rng=None):
    """Binary coordinate descent: for each coordinate, try 0 and 1, keep the better."""

def compute_corr(h):
    return np.correlate(h, 1.0 - h, mode='full')

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    return float(np.max(compute_corr(h))) * dx

def project_feasible(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    for _ in range(500):
        diff = target_sum - np.sum(h)
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            mask = h < 0.999
        else:
            mask = h > 0.001
        cnt = int(mask.sum())
        if cnt == 0:
            break
        h = h.copy()
        h[mask] += diff / cnt
        h = np.clip(h, 0.0, 1.0)
    return h

# Global variables for the objective function (to avoid closures)
_g_alpha = 1.0
_g_n = 0
_g_target = 0.0
_g_pen = 100.0

def _lse_obj_grad(x):
    n = _g_n
    dx = 2.0 / n
    c = np.correlate(x, 1.0 - x, mode='full')
    c_max = np.max(c)
    shifted = _g_alpha * (c - c_max)
    shifted = np.clip(shifted, -700, 0)
    log_sum = np.log(np.sum(np.exp(shifted)))
    val = c_max * dx + log_sum / _g_alpha * dx + _g_pen * (np.sum(x) - _g_target)**2
    
    # Gradient
    # p_k = exp(alpha * (c_k - c_max)) / sum exp(alpha * (c_k - c_max))
    exp_shifted = np.exp(shifted)
    p = exp_shifted / np.sum(exp_shifted)
    
    # grad_lse[j] = dx * sum_k p_k * ((1-h[j+k-n+1])*1_valid - h[j-k+n-1]*1_valid)
    # = dx * (w[j] - f1[j] - f2[j])
    # where w[j] = sum_k p_k * 1_{valid for term (1-h)}
    # f1[j] = sum_k p_k * h[j+k-n+1] * 1_{valid}
    # f2[j] = sum_k p_k * h[j-k+n-1] * 1_{valid}
    
    k_range = np.arange(2*n-1)
    j_range = np.arange(n)
    
    idx1 = j_range[:, None] + k_range[None, :] - n + 1
    valid1 = (idx1 >= 0) & (idx1 < n)
    
    idx2 = j_range[:, None] - k_range[None, :] + n - 1
    valid2 = (idx2 >= 0) & (idx2 < n)
    
    # w[j] = sum_k p[k] * valid1[j,k]
    w = valid1.astype(float) @ p
    
    # f1[j] = sum_k p[k] * h[idx1[j,k]] * valid1[j,k]
    h1 = np.where(valid1, x[np.clip(idx1, 0, n-1)], 0.0)
    f1 = h1 @ p
    
    # f2[j] = sum_k p[k] * h[idx2[j,k]] * valid2[j,k]
    h2 = np.where(valid2, x[np.clip(idx2, 0, n-1)], 0.0)
    f2 = h2 @ p

    grad_pen = 2 * _g_pen * (np.sum(x) - _g_target) * np.ones(n)
    
    return val, grad_lse + grad_pen

Let me also add a "coordinate descent" phase that uses the exact 1D subproblem solution. For the log-sum-exp objective, the 1D subproblem for coordinate j is:

$\min_t \frac{1}{\alpha} \log \sum_k \exp(\alpha (c_k + (t-h_j) \cdot s_{k,j}))$

where $s_{k,j} = \frac{\partial c_k}{\partial h_j}$ is the sensitivity of c_k to h_j.

This is a 1D convex problem that can be solved by Newton's method or bisection in O(n) time per coordinate.

Actually, for the log-sum-exp, the 1D subproblem has a closed-form Newton step:
$f(t) = \frac{1}{\alpha} \log \sum_k \exp(\alpha(c_k + (t-h_j)s_k))$
$f'(t) = \sum_k p_k(t) \cdot s_k$ where $p_k(t) = \frac{\exp(\alpha(c_k + (t-h_j)s_k))}{\sum_l \exp(\alpha(c_k + (t-h_j)s_l))}$
$f''(t) = \alpha \cdot \text{Var}_p(s_k) > 0$

Newton step: $t_{new} = t - f'(t)/f''(t)$

This converges quadratically, so 5-10 Newton iterations per coordinate should be enough. Total: 400 × 10 × O(n) = 400 × 10 × 800 = 3.2M operations per sweep. In numpy, this is fast.
