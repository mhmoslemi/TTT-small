But in practice, for well-optimized solutions, the boundary effects are small and the solution is approximately symmetric.

OK, let me just focus on writing good optimization code. Let me design the algorithm:

```
Phase 1 (0-60s): Global DE on n=30 grid using scipy.optimize.differential_evolution
Phase 2 (60-150s): Refine best coarse solutions to n=200 with SLSQP
Phase 3 (150-400s): Full n=400 optimization:
   - Interpolate best to n=400
   - SLSQP with increasing alpha
   - Worst-lag line search
   - Multi-restart SLSQP
Phase 4 (400-800s): Intensive polishing:
   - Alternate SLSQP and worst-lag surgery
   - Try different alpha schedules
   - Local perturbations + SLSQP
Phase 5 (800-1280s): Final refinement
```

Actually, I realize I should be more careful about time management. Let me profile:
- SLSQP on n=400 with LSE objective: each function eval is O(n) for the correlation + O(n) for LSE. SLSQP with maxiter=2000 might take 30-60 seconds.
- Differential evolution on n=30: fast, maybe 10-20 seconds for a few hundred generations.
- Worst-lag line search: each iteration is O(n) for a few lags, very fast.

Let me write the code now. I'll focus on making it robust and time-aware.

One more thought: the previous solution's DE implementation is hand-rolled and might not be as effective as scipy's built-in `differential_evolution`. Also, the previous solution spends a lot of time on DE at various resolutions but might not converge as well as a focused SLSQP approach.

My strategy:
1. Quick global search on coarse grid (n=30) to find diverse starting points
2. Quick SLSQP on medium grid (n=100) to refine
3. Focus most time on n=400 with intensive SLSQP + worst-lag surgery iteration

Let me also add a key innovation: **iterative reweighting**. Instead of LSE (which treats all lags equally in the limit), I'll use explicit weights that are updated:
- w_k = exp(beta * corr_k) / sum(exp(beta * corr_j))
- Minimize sum_k w_k * corr_k

This is similar to LSE but with explicit weight updates that can be tuned.

Actually, LSE with high alpha IS iterative reweighting in disguise. The gradient of LSE at high alpha is dominated by the max, which is the same as reweighting with high beta. So I'll stick with LSE but use very high alpha values.

```python
import numpy as np
from scipy.optimize import minimize, differential_evolution
import time

_g_alpha = 0.0
_g_n = 0
_g_target = 0.0
_g_smooth_coeff = 0.0


def compute_corr(h):
    return np.correlate(h, 1.0 - h, mode='full')


def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    return float(np.max(compute_corr(h))) * dx


def project_feasible(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    for _ in range(500):
        diff = target_sum - np.sum(h)
        if abs(diff) < 1e-15:
            break
        if diff > 0:
            mask = h < 0.9999
        else:
            mask = h > 0.0001
        cnt = int(mask.sum())
        if cnt == 0:
            break
        h = h.copy()
        h[mask] += diff / cnt
        h = np.clip(h, 0.0, 1.0)
    return h


def interpolate_to(h_src, n_dst, target_dst):
    n_src = len(h_src)
    if n_src == n_dst:
        return project_feasible(h_src.copy(), target_dst)
    x_new = np.linspace(0.0, 1.0, n_dst)
    x_old = np.linspace(0.0, 1.0, n_src)
    h_out = np.interp(x_new, x_old, h_src)
    return project_feasible(h_out, target_dst)


def lse_val(corr, alpha):
    c_max = float(np.max(corr))
    shifted = alpha * (corr - c_max)
    shifted = np.clip(shifted, -700.0, 0.0)
    return c_max + float(np.log(np.sum(np.exp(shifted)))) / alpha


def _slsqp_obj(x):
    corr = compute_corr(x)
    base = lse_val(corr, _g_alpha)
    if _g_smooth_coeff > 0.0:
        d2 = np.diff(x, 2)
        base += _g_smooth_coeff * float(np.sum(d2 * d2))
    return base


def _slsqp_eq(x):
    return np.sum(x) - _g_target


def _slsqp_eq_jac(x):
    return np.ones(_g_n)


def slsqp_optimize(h, n, target, alphas, maxiter, deadline, smooth=0.0):
    global _g_alpha, _g_n, _g_target, _g_smooth_coeff
    _g_n = n
    _g_target = target
    _g_smooth_coeff = smooth
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': _slsqp_eq, 'jac': _slsqp_eq_jac}]
    h_cur = h.copy()
    cur_score = compute_c5(h_cur)
    for a in alphas:
        if time.time() > deadline:
            break
        _g_alpha = float(a)
        try:
            res = minimize(_slsqp_obj, h_cur, method='SLSQP', bounds=bounds,
                           constraints=cons, options={'maxiter': maxiter, 'ftol': 1e-16})
            h_new = project_feasible(res.x, target)
            sc = compute_c5(h_new)
            if sc < cur_score:
                h_cur = h_new
                cur_score = sc
        except Exception:
            pass
    return h_cur, cur_score


def worst_lag_line_search(h, n, target, max_rounds, deadline, top_m=3):
    h_cur = h.copy()
    cur_score = compute_c5(h_cur)
    dx = 2.0 / n
    for rnd in range(max_rounds):
        if time.time() > deadline:
            break
        corr = compute_corr(h_cur)
        over = corr[n - 1:n - 1 + n]
        top_indices = np.argsort(over)[::-1][:top_m]
        improved = False
        for k in top_indices:
            k = int(k)
            if k <= 0 or k >= n:
                continue
            grad = np.zeros(n)
            idx_pos = np.arange(0, n - k)
            grad[idx_pos] += (1.0 - h_cur[idx_pos + k])
            idx_neg = np.arange(k, n)
            grad[idx_neg] -= h_cur[idx_neg - k]
            grad *= dx
            step = 0.01
            best_step = 0.0
            best_val = cur_score
            for _ in range(25):
                h_test = h_cur - step * grad
                h_test = project_feasible(h_test, target)
                val = compute_c5(h_test)
                if val < best_val:
                    best_val = val
                    best_step = step
                step *= 0.55
            if best_step > 0.0 and best_val < cur_score - 1e-15:
                h_test = h_cur - best_step * grad
                h_test = project_feasible(h_test, target)
                h_cur = h_test
                cur_score = best_val
                improved = True
        if not improved:
            break
    return h_cur, cur_score


def subgradient_polish(h, n, target, n_steps, n_active, lr_init, lr_decay, deadline):
    h_cur = h.copy()
    best_h = h_cur.copy()
    best_score = compute_c5(h_cur)
    dx = 2.0 / n
    lr = lr_init
    for step in range(n_steps):
        if time.time() > deadline:
            break
        corr = compute_corr(h_cur)
        over = corr[n - 1:n - 1 + n]
        c_curr = float(np.max(over)) * dx
        if c_curr < best_score:
            best_score = c_curr
            best_h = h_cur.copy()
        top_idx = np.argsort(over)[::-1][:n_active]
        diffs = over[top_idx] - over[top_idx[0]]
        weights = np.exp(diffs / 0.004)
        weights /= weights.sum()
        grad = np.zeros(n)
        for wk, k in zip(weights, top_idx):
            k = int(k)
            if k <= 0:
                continue
            j_pos = np.arange(0, n - k)
            grad[j_pos] += wk * (1.0 - h_cur[j_pos + k])
            j_neg = np.arange(k, n)
            grad[j_neg] -= wk * h_cur[j_neg - k]
        grad *= dx
        h_new = h_cur - lr * grad
        h_new = project_feasible(h_new, target)
        sc_new = compute_c5(h_new)
        if sc_new < c_curr:
            h_cur = h_new
            lr = min(lr * 1.02, lr_init * 5.0)
        else:
            lr *= lr_decay
            if lr < 1e-12:
                break
    return best_h, best_score


def multi_restart_slsqp(h, n, target, n_restarts, alphas, maxiter, deadline, rng):
    h_best = h.copy()
    sc_best = compute_c5(h_best)
    for r in range(n_restarts):
        if time.time() > deadline - 30:
            break
        pert_scale = 0.03 * (1.0 + r * 0.3)
        h_pert = h_best + rng.randn(n) * pert_scale
        h_pert = project_feasible(h_pert, target)
        h_new, sc_new = slsqp_optimize(h_pert, n, target, alphas, maxiter,
                                       min(time.time() + 60, deadline))
        if sc_new < sc_best:
            sc_best = sc_new
            h_best = h_new
    return h_best, sc_best


def coarse_de(n, target, deadline, rng, popsize=15, maxiter=200):
    bounds = [(0.0, 1.0)] * n

    def de_obj(x):
        h = project_feasible(x, target)
        return compute_c5(h)

    x0 = rng.rand(n)
    try:
        res = differential_evolution(de_obj, bounds, seed=int(rng.randint(10000)),
                                     maxiter=maxiter, popsize=popsize,
                                     tol=1e-8, init='latinhypercube',
                                     polish=False, updating='deferred',
                                     callback=None)
        h_best = project_feasible(res.x, target)
    except Exception:
        h_best = project_feasible(x0, target)
    return h_best, compute_c5(h_best)


def run(seed=42, budget_s=1300, **kwargs):
    global _g_alpha, _g_n, _g_target, _g_smooth_coeff
    start_time = time.time()
    rng = np.random.RandomState(seed)
    hard_deadline = start_time + budget_s - 20.0

    def tleft():
        return hard_deadline - time.time()

    n_final = len(initial_h_values)
```
