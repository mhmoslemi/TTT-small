Actually, one more idea: **pairwise interchange** (PI) heuristic. This is a well-known metaheuristic that:
1. Starts from a feasible solution
2. At each step, considers all possible pairwise interchanges (i from ones, j from zeros)
3. Selects the best interchange (largest improvement or smallest deterioration)
4. Applies it
5. Repeats until no improvement

The key difference from simple greedy is that PI considers ALL pairs, not just a random subset. For n=606, there are 303*303 ≈ 92000 possible pairs. With incremental evaluation (O(top_k) per pair), this is 92000 * 10 = 920K operations per iteration. That's feasible.

Let me implement PI:

```python
def pairwise_interchange(h, max_iters, time_limit, start_time, top_k=5):
    n = len(h)
    dx = 2.0 / n
    h = h.copy()
    corr = np.correlate(h, 1.0 - h, mode='full')
    best_c5 = float(corr.max()) * dx
    best_h = h.copy()
    
    for it in range(max_iters):
        if time.time() - start_time > time_limit:
            break
        
        ones = np.where(h == 1)[0]
        zeros = np.where(h == 0)[0]
        if len(ones) == 0 or len(zeros) == 0:
            break
        
        # Get top shifts
        top_idx = np.argsort(corr)[-top_k:]
        top_shifts = top_idx - (n - 1)
        
        max_val = float(corr.max())
        
        best_improve = 0.0
        best_i = -1
        best_j = -1
        
        for i in ones:
            for j in zeros:
                # Check if this swap can improve
                new_max = 0.0
                improved = True
                for k in top_shifts:
                    d = 0.0
                    if 0 <= i + k < n:
                        d -= (1.0 - h[i + k])
                    if 0 <= i - k < n:
                        d += h[i - k]
                    if 0 <= j + k < n:
                        d += (1.0 - h[j + k])
                    if 0 <= j - k < n:
                        d -= h[j - k]
                    v = int(corr[k + (n-1)]) + d
                    if v > new_max:
                        new_max = v
                if new_max < max_val - best_improve:
                    best_improve = max_val - new_max
                    best_i = i
                    best_j = j
        
        if best_i >= 0:
            h[best_i] = 0
            h[best_j] = 1
            corr = np.correlate(h, 1.0 - h, mode='full')
            sc = float(corr.max()) * dx
            if sc < best_c5:
                best_c5 = sc
                best_h = h.copy()
        else:
            break
    
    return best_h, best_c5
```

For a fixed i, the delta for all j simultaneously:
delta_j = -(1-h[i+k]) + h[i-k] + (1-h[j+k]) - h[j-k] for each shift k

The terms depending on i are constant for a given i,k. The terms depending on j vary.

So for fixed i:
const_i_k = -(1-h[i+k]) + h[i-k] (for each k)
var_j_k = (1-h[j+k]) - h[j-k] (for each j, k)

For each shift k:
new_corr_k(j) = corr[k] + const_i_k + var_j_k

We want to find (i,j) that minimizes max_k new_corr_k(j).

This is still not trivially vectorizable because of the max over k. But for small top_k (say 5), we can do it.

Let me try a different approach: precompute for each i and each k the const_i_k, then for each j and k compute var_j_k. Then for each (i,j) pair, the new max is max_k (corr_k + const_i_k + var_j_k).

I can precompute const_i_k as a matrix of shape (n_ones, top_k) and var_j_k as (n_zeros, top_k). Then for each (i,j) pair, the new values are corr_k + const_i[k] + var_j[k] for k in top_k, and we take the max.

```python
            break

                if 0 <= i - k < n:

                    d += (1.0 - h[j + k])
                if 0 <= j - k < n:

        # We want to minimize max_k(new_corr_k)

        best_improve = 0.0

        best_jj = -1

            if min_row < max_val - best_improve:
                best_improve = max_val - min_row
                best_ii = ii

                best_h = h.copy()
        else:
            break
```

    corr = np.correlate(h, 1.0 - h, mode='full')
    c_max = float(np.max(corr))
    shifted = np.clip(alpha * (corr - c_max), -500.0, 0.0)
    return c_max + float(np.log(np.sum(np.exp(shifted))) / alpha)
