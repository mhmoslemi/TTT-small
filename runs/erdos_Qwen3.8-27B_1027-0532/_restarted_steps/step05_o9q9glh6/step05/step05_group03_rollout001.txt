This is related to the "flat autocorrelation" problem in signal processing! A "flat autocorrelation" sequence has equal autocorrelation at all non-zero shifts. This is achieved by "perfect difference sets" or "m-sequences" (for binary sequences of prime length).

For our problem, we can't have perfect flatness because the length isn't prime and we have boundary effects. But we can aim for approximately flat autocorrelation.

**M-sequence insight**: A binary m-sequence (maximum length sequence) of length 2^m - 1 has the property that its autocorrelation is -1 at all non-zero shifts (for the periodic version). For the aperiodic version (which is what we need), the autocorrelation decays linearly.

        try:
            res = minimize(obj_soft_max, h_cur, method='SLSQP', bounds=bounds,
                           constraints=cons, options={'maxiter': maxiter, 'ftol': ftol})
            h_new = project_feasible(res.x, _g_target)
            sc = compute_c5(h_new)
            if sc < cur_score:
                h_cur = h_new
                cur_score = sc
        except Exception:
            pass
    return h_cur, cur_score

def interpolate_to(h_src, n_dst, target_dst):
    n_src = len(h_src)
    if n_src == n_dst:
        return project_feasible(h_src.copy(), target_dst)
    x_new = np.linspace(0.0, 1.0, n_dst)
    x_old = np.linspace(0.0, 1.0, n_src)
    h_out = np.interp(x_new, x_old, h_src)
    return project_feasible(h_out, target_dst)
