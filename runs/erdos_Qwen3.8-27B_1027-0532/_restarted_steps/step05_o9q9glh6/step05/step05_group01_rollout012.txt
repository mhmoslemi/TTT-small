3. Solve: minimize t subject to linearized_corr_k <= t for all k, sum(h) = target, 0 <= h <= 1

Actually, here's another idea that might be better: **Use the fact that the objective is a max of bilinear functions, and apply the Frank-Wolfe (conditional gradient) method.**

The Frank-Wolfe method for min-max:
1. At current h_t, find the shift s* with maximum correlation
2. Solve the subproblem: min_h grad_{s*}(h_t) · h subject to sum(h) = target, 0 <= h <= 1
3. Update: h_{t+1} = (1-γ)h_t + γ * h_sub

The subproblem is just: minimize a linear function over the polytope {h : sum(h) = target, 0 <= h <= 1}. The optimal solution is to put 1s where the gradient is most negative and 0s where it's most positive, with at most one fractional value.

This is very fast (O(n log n) for sorting) and doesn't require any solver!

Let me combine this with the multi-active-set approach:
1. Find top-K shifts by correlation
2. For each, compute the gradient
3. Solve the subproblem for each gradient (or a weighted combination)
4. Update h

Actually, the standard FW method only uses one constraint at a time. For min-max, we want to use all active constraints. We can use a **generalized FW** or **LISTA-like** approach.

A simpler variant: use the **exponential weighting** of active gradients:
w_s = exp(α * corr_s / dx) / ∑_t exp(α * corr_t / dx)
grad = ∑_s w_s * grad_s

Then do FW step in direction of this weighted gradient.

This is essentially what the `soft_subgradient` function in the previous code does, but with a FW step instead of a projected gradient step.

Let me implement a **Frank-Wolfe with soft max** approach:

```python
def fw_step(h_t, grad, n, target):
    """Solve min grad · h subject to sum(h) = target, 0 <= h <= 1."""
    # Sort by gradient values
    order = np.argsort(grad)
    # h_sub should have 1s at the lowest gradient positions and 0s at the highest
    # with at most one fractional value
    h_sub = np.zeros(n)
    remaining = target
    for i in order:
        if remaining >= 1.0 - 1e-12:
            h_sub[i] = 1.0
            remaining -= 1.0
        elif remaining > 1e-12:
            h_sub[i] = remaining
            remaining = 0
        else:
            break
    return h_sub
```

```python
import numpy as np

_global_n = 0
_global_target = 0.0

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr)) * dx

def project_feasible(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    diff = target_sum - np.sum(h)
    if abs(diff) < 1e-14:
        return h
    h = h.copy()
    if diff > 0:
        idx = np.where(h < 1.0 - 1e-10)[0]
    else:
        idx = np.where(h > 1e-10)[0]
    if len(idx) == 0:
        return h
    h[idx] += diff / len(idx)
    h = np.clip(h, 0.0, 1.0)
    return h

def _smooth_obj(x):
    corr = np.correlate(x, 1.0 - x, mode='full')
    c_max = np.max(corr)
    shifted = np.clip(_global_alpha * (corr - c_max), -500.0, 0.0)
    return float(c_max + np.log(np.sum(np.exp(shifted))) / _global_alpha)

def _cons_fun(x):
    return np.sum(x) - _global_target

def _cons_jac(x):
    return np.ones(_global_n)

def slsqp_round(h_start, n, target, alphas, max_iter_each, time_limit):

    _global_n = n
    _global_target = target
    start = time.time()
    h_cur = h_start.copy()
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': _cons_fun, 'jac': _cons_jac}]
    for alpha in alphas:
        if time.time() - start > time_limit:
            break
        _global_alpha = float(alpha)
        try:
            res = minimize(_smooth_obj, h_cur, method='SLSQP', bounds=bounds,
                          constraints=cons, options={'maxiter': max_iter_each, 'ftol': 1e-15})
            h_new = project_feasible(res.x, target)
            if compute_c5(h_new) < compute_c5(h_cur):
                h_cur = h_new
        except Exception:
            pass

def fw_minmax(h_start, n, target, max_iter=2000, alpha=8.0, time_limit=30):

            if np.any(v2):

def interpolate_to(h_src, n_dst, target_dst):
    n_src = len(h_src)
    if n_src == n_dst:
        return project_feasible(h_src.copy(), target_dst)
    x_new = np.linspace(0.0, 1.0, n_dst)
    x_old = np.linspace(0.0, 1.0, n_src)
    h_out = np.interp(x_new, x_old, h_src)
    return project_feasible(h_out, target_dst)

def structured_perturb(h, n, rng, mode):
    h_p = h.copy()
    if mode == 0:
        m = int(rng.randint(1, n // 4))
        phase = rng.random() * 2.0 * np.pi
        amp = 0.15
        idxs = np.arange(n)
        h_p += amp * np.sin(2.0 * np.pi * m * idxs / n + phase)
    elif mode == 1:
        block_len = int(rng.randint(n // 10, n // 3))
        block_start = int(rng.randint(0, n - block_len))
        h_p[block_start:block_start + block_len] = 1.0 - h_p[block_start:block_start + block_len]
    elif mode == 2:
        center = int(rng.randint(0, n))
        width = int(rng.randint(n // 20, n // 5))
        idxs = np.arange(n)
        bump = 0.3 * np.exp(-0.5 * ((idxs - center) / width) ** 2)
        h_p += bump * rng.choice([1.0, -1.0])
    elif mode == 3:
        period = int(rng.randint(max(4, n // 20), n // 4))
        idxs = np.arange(n)
        pattern = np.where((idxs % period) < period // 2, 0.1, -0.1)
        h_p += pattern * rng.choice([1.0, -1.0])
    else:
        n_pert = int(rng.randint(max(2, n // 100), n // 10))
        idxs = rng.choice(n, size=n_pert, replace=False)
        h_p[idxs] += rng.randn(n_pert) * 0.2
    return project_feasible(h_p, n / 2.0)
```
