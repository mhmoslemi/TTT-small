where p_k(α) = exp(α*f_k(h)) / sum_j exp(α*f_j(h)) (a softmax over the f_k values).

This is exactly what the log-sum-exp SLSQP in the previous code uses! The gradient is a mixture of the subgradients, weighted by the softmax.

So the previous approach is already using this. The question is whether we can do better.

One idea: **Use a larger α (less smoothing)** to get closer to the true subgradient, but use a smaller step size to avoid oscillation.

Another idea: **Use the "proximal" version** - instead of just following the gradient, also pull towards a "center" (like the average of all iterates, or a previous good solution).

Let me try: **Proximal gradient with adaptive step size and momentum**

```python
def proximal_gradient(h, n, target, n_steps, deadline):
    h_cur = h.copy()
    h_mom = h.copy()  # momentum
    best_h = h.copy()
    best_score = compute_c5(h_cur)
    dx = 2.0 / n
    gamma = 1.0  # momentum
    lr = 0.01  # learning rate
    
    for step in range(n_steps):
        if time.time() > deadline:
            break
        
        # Compute weights (softmax over correlation values)
        corr = np.correlate(h_cur, 1-h_cur, mode='full')
        # Use top-K lags for efficiency
        top_k = 10
        top_idx = np.argsort(corr)[::-1][:top_k]
        c_vals = corr[top_idx]
        c_max = c_vals[0]
        
        # Softmax weights
        alpha = 100.0  # smoothing parameter
        w = np.exp(alpha * (c_vals - c_max))
        w /= w.sum()
        
        # Compute gradient as weighted sum of subgradients
        grad = np.zeros(n)
        for wk, k_idx in zip(w, top_idx):
            k = int(k_idx) - (n-1)
            if k >= 0:
                # f_k(h) = sum_{i=0}^{n-1-k} h[i+k]*(1-h[i])
                # ∂f_k/∂h[i] = (1-h[i]) for i=0,...,n-1-k (from the -h[i] term)
                #                + h[i+k] for i=k,...,n-1 (from the h[i+k] term)
                i_pos = np.arange(0, n-k)
                grad[i_pos] += wk * (1 - h_cur[i_pos])
                i_neg = np.arange(k, n)
                grad[i_neg] += wk * h_cur[i_neg - k]
            else:
                k2 = -k
                i_pos = np.arange(0, n-k2)
                grad[i_pos] += wk * h_cur[i_pos + k2]
                i_neg = np.arange(k2, n)
                grad[i_neg] += wk * (1 - h_cur[i_neg])
        
        grad *= dx
        
        # Momentum update
        h_mom = gamma * h_mom + (1-gamma) * (-grad)
        
        # Take step
        h_new = h_cur + lr * h_mom
        h_new = project_feasible(h_new, target)
        
        # Check improvement
        new_score = compute_c5(h_new)
        if new_score < best_score:
            best_score = new_score
            best_h = h_new.copy()
        
        # Adaptive step size
        if new_score < compute_c5(h_cur):
            lr = min(lr * 1.05, 0.1)
        else:
            lr *= 0.9
        
        h_cur = h_new
    
    return best_h, best_score
```

The full correlation is: c[m] = np.correlate(h, 1-h, mode='full')[m] for m = 0, 1, ..., 2n-2.

The element at index m corresponds to lag k = m - (n-1):
c[m] = sum_i h[i+k]*(1-h[i]) where k = m-(n-1), and i ranges over valid values.

For k ≥ 0: c[n-1+k] = sum_{i=0}^{n-1-k} h[i+k]*(1-h[i])
For k < 0: c[n-1+k] = sum_{i=-k}^{n-1} h[i+k]*(1-h[i]) = sum_{i=0}^{n-1+k} h[i]*(1-h[i-k])

Let me focus on k ≥ 0 first (the more common case in practice):
f_k(h) = c[n-1+k] = sum_{i=0}^{n-1-k} h[i+k]*(1-h[i])

  Contribution: -h[p+k]

- For the second term: p ∈ [0, n-1-k]

Taking derivative with respect to h[p]:

∇(max_k f_k)(h) = ∇f_{k*}(h) where k* = argmax_k f_k(h)

∇φ_α(h) = sum_k p_k * ∇f_k(h) where p_k = softmax(α * f_k)

For a given set of top lags K = {k_1, ..., k_m} with weights w_1, ..., w_m:
Total gradient = sum_j w_j * ∇f_{k_j}(h)

For each k (assume k ≥ 0):
∇f_k(h)[p] = (1-h[p-k]) * 1[k≤p<-n] - h[p+k] * 1[0≤p<n-k]

def compute_gradient(h, k_weights, n):
    """Compute weighted sum of subgradients for given lags and weights.
    k_weights: list of (lag, weight) pairs, lag can be negative.
    """
    grad = np.zeros(n)
    for k, w in k_weights:
        if w < 1e-10:
            continue
        if k >= 0:
            # (1-h[p-k]) for p in [k, n-1]
            grad[k:] += w * (1 - h[:n-k])
            # -h[p+k] for p in [0, n-1-k]
            grad[:n-k] -= w * h[k:]
        else:
            k2 = -k
            # For k < 0: f_k = sum_{i=0}^{n-1+k} h[i]*(1-h[i-k2])  [where k2=-k>0]
            # Actually let me re-derive for k < 0.
            # c[n-1+k] = sum_{i=-k}^{n-1} h[i+k]*(1-h[i])
            # Let k2 = -k > 0: sum_{i=k2}^{n-1} h[i-k2]*(1-h[i])
            # = sum_{j=0}^{n-1-k2} h[j]*(1-h[j+k2])
            # So f_{-k2} = sum_{j=0}^{n-1-k2} h[j]*(1-h[j+k2])
            # ∂/∂h[p]:
            #   -h[p+k2] for p in [0, n-1-k2]
            #   (1-h[p-k2]) for p in [k2, n-1]
            grad[:n-k2] -= w * h[k2:]
            grad[k2:] += w * (1 - h[:n-k2])
    return grad

For k < 0, let k2 = -k > 0:
c[n-1+k] = c[n-1-k2] = sum_{i=k2}^{n-1} h[i-k2]*(1-h[i])

  contribution: -(1-h[p+k2]) * (-1) ... wait no.
  The term is h[j]*(1-h[j+k2]). Derivative w.r.t. h[j] is (1-h[j+k2]).
  So contribution to ∂/∂h[p] from this: (1-h[p+k2]) if 0 ≤ p ≤ n-1-k2.

- h[p] appears as h[j+k2] when j+k2 = p, i.e., j = p-k2 (valid if 0 ≤ p-k2 ≤ n-1-k2, i.e., k2 ≤ p ≤ n-1):
  The term is h[j+k2]*(1-h[j]) = h[p]*(1-h[p-k2]).
  Derivative w.r.t. h[p] is: (1-h[p-k2]).
  But wait, it's h[j]*(1-h[j+k2]) and h[p] = h[j+k2], so derivative w.r.t. h[j+k2] is -h[j] = -h[p-k2].

So ∂f_{-k2}/∂h[p]:
- From h[j] term: (1-h[p+k2]) if 0 ≤ p ≤ n-1-k2
- From h[j+k2] term: -h[p-k2] if k2 ≤ p ≤ n-1

Let me verify with n=4, k2=1 (so k=-1):

∂/∂h0: 1-h1 ✓

Using my formula:
- For p=0: (1-h[0+1]) = 1-h1 (from first term, 0≤0≤2) + 0 (from second term, 0<1) = 1-h1 ✓
- For p=1: (1-h[1+1]) = 1-h2 (from first term, 0≤1≤2) + (-h[1-1]) = -h0 (from second term, 1≤1≤3) = 1-h2-h0 ✓
- For p=2: (1-h[2+1]) = 1-h3 (from first term, 0≤2≤2) + (-h[2-1]) = -h1 (from second term) = 1-h3-h1 ✓
- For p=3: 0 (from first term, 3>2) + (-h[3-1]) = -h2 (from second term) = -h2 ✓

So the formula for k<0 (k2=-k) is:
∂f_{-k2}/∂h[p] = (1-h[p+k2]) * 1[0≤p≤n-1-k2] + (-h[p-k2]) * 1[k2≤p≤n-1]

```

Now let me think about the overall algorithm structure. I'll combine:
1. Binary local search (fast, O(n) per step)
2. Projected gradient with momentum and softmax weights
3. SLSQP polishing (from the previous code, but with different parameters)
4. Block coordinate descent

Let me write the final code:

```python
import numpy as np
from scipy.optimize import minimize
import time

def compute_corr(h):
    return np.correlate(h, 1.0 - h, mode='full')

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    return float(np.max(compute_corr(h))) * dx

def project_feasible(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    for _ in range(200):
        diff = target_sum - np.sum(h)
        if abs(diff) < 1e-13:
            break
        if diff > 0:
            mask = h < 0.9999
        else:
            mask = h > 0.0001
        cnt = int(mask.sum())
        if cnt == 0:
            break
        h = h.copy()
        h[mask] += diff / cnt
        h = np.clip(h, 0.0, 1.0)
    return h

def interpolate_to(h_src, n_dst, target_dst):
    n_src = len(h_src)
    if n_src == n_dst:
        return project_feasible(h_src.copy(), target_dst)
    x_new = np.linspace(0.0, 1.0, n_dst)
    x_old = np.linspace(0.0, 1.0, n_src)
    h_out = np.interp(x_new, x_old, h_src)
    return project_feasible(h_out, target_dst)

def compute_weighted_gradient(h, lags, weights, n):
    """Compute weighted sum of subgradients."""
    grad = np.zeros(n)
    for k, w in zip(lags, weights):
        if w < 1e-12:
            continue
        k = int(k)
        if k >= 0:
            if k >= n:
                continue
            grad[k:] += w * (1.0 - h[:n-k])
            grad[:n-k] -= w * h[k:]
        else:
            k2 = -k
            if k2 >= n:
                continue
            grad[:n-k2] += w * (1.0 - h[k2:])
            grad[k2:] -= w * h[:n-k2]
    return grad

def gradient_polish(h, n, target, n_steps, deadline, alpha_init=50.0, lr_init=0.01):
    """Projected gradient with momentum and softmax weights."""
    h_cur = h.copy()
    h_mom = np.zeros(n)
    best_h = h_cur.copy()
    best_score = compute_c5(h_cur)
    dx = 2.0 / n
    gamma = 0.9  # momentum
    lr = lr_init
    alpha = alpha_init
    top_k = 15
    
    for step in range(n_steps):
        if time.time() > deadline:
            break
        
        corr = compute_corr(h_cur)
        c_max = np.max(corr)
        
        # Get top k lags
        top_idx = np.argsort(corr)[::-1][:top_k]
        c_top = corr[top_idx]
        
        # Softmax weights
        w = np.exp(alpha * (c_top - c_top[0]))
        w_sum = w.sum()
        if w_sum < 1e-300:
            w = np.ones(top_k) / top_k
        else:
            w /= w_sum
        
        # Compute gradient
        lags = top_idx - (n - 1)
        grad = compute_weighted_gradient(h_cur, lags, w, n) * dx
        
        # Momentum
        h_mom = gamma * h_mom + (1.0 - gamma) * grad
        grad_norm = np.linalg.norm(h_mom)
        if grad_norm < 1e-15:
            break
        
        # Adaptive step size (Barzilai-Borwein style)
        if step > 0:
            # Use previous step info
            pass  # Simplified: just use fixed decay
        
        h_new = h_cur + lr * h_mom / (grad_norm / 0.1)  # normalize step
        # Actually let me use a simpler approach
        h_new = h_cur + lr * h_mom
        h_new = project_feasible(h_new, target)
        
        new_score = compute_c5(h_new)
        if new_score < best_score:
            best_score = new_score
            best_h = h_new.copy()
        
        # Adaptive lr
        if new_score < c_max * dx:
            lr = min(lr * 1.02, 0.05)
        else:
            lr *= 0.92
        
        h_cur = h_new
        # Slowly increase alpha (less smoothing)
        alpha *= 1.005
    
    return best_h, best_score

def binary_local_search(h, n, target, n_iter, deadline, rng):
    """Local search on binary vectors."""
    # Round to binary
    h_bin = (h >= 0.5).astype(float)
    # Fix to have exactly target ones
    ones = np.where(h_bin == 1)[0]
    zeros = np.where(h_bin == 0)[0]
    n_ones = len(ones)
    n_target = int(target)
    
    if n_ones > n_target:
        # Remove excess ones (preferentially those with high h value? no, just random)
        excess = n_ones - n_target
        remove = rng.choice(ones, size=excess, replace=False)
        h_bin[remove] = 0
    elif n_ones < n_target:
        need = n_target - n_ones
        add = rng.choice(zeros, size=need, replace=False)
        h_bin[add] = 1
    
    dx = 2.0 / n
    best_h = h_bin.copy()
    best_max = np.max(np.correlate(h_bin, 1-h_bin, mode='full'))
    
    for it in range(n_iter):
        if time.time() > deadline:
            break
        
        corr = np.correlate(h_bin, 1-h_bin, mode='full')
        c_max = np.max(corr)
        if c_max < best_max:
            best_max = c_max
            best_h = h_bin.copy()
        
        k_star = int(np.argmax(corr)) - (n - 1)
        
        # Compute neighbor scores for k_star
        nscore = np.zeros(n)
        if k_star >= 0:
            if k_star < n:
                nscore[:n-k_star] += h_bin[k_star:]
                nscore[k_star:] += h_bin[:n-k_star]
        else:
            k2 = -k_star
            if k2 < n:
                nscore[:n-k2] += h_bin[k2:]
                nscore[k2:] += h_bin[:n-k2]
        
        zeros = np.where(h_bin == 0)[0]
        ones = np.where(h_bin == 1)[0]
        
        if len(zeros) == 0 or len(ones) == 0:
            break
        
        # Best swap: maximize nscore[i] - nscore[j]
        best_i = zeros[np.argmax(nscore[zeros])]
        best_j = ones[np.argmin(nscore[ones])]
        
        # Apply swap
        h_bin[best_i] = 1.0
        h_bin[best_j] = 0.0
        
        # Check if overall max improved
        new_corr = np.correlate(h_bin, 1-h_bin, mode='full')
        new_max = np.max(new_corr)
        
        if new_max > c_max + 2:
            # Revert
            h_bin[best_i] = 0.0
            h_bin[best_j] = 1.0
            # Try a random swap
            i_rand = rng.choice(zeros)
            j_rand = rng.choice(ones)
            h_bin[i_rand] = 1.0
            h_bin[j_rand] = 0.0
            rc = np.max(np.correlate(h_bin, 1-h_bin, mode='full'))
            if rc > c_max + 3:
                h_bin[i_rand] = 0.0
                h_bin[j_rand] = 1.0
    
    return best_h, best_max

# Globals for SLSQP
_g_n = 0
_g_target = 0.0
_g_alpha = 0.0

def _cons_eq(x):
    return np.sum(x) - _g_target

def _cons_jac(x):
    return np.ones(_g_n)

def _lse_obj(x):
    corr = compute_corr(x)
    c_max = float(np.max(corr))
    shifted = _g_alpha * (corr - c_max)
    shifted = np.clip(shifted, -700.0, 0.0)
    return c_max + float(np.log(np.sum(np.exp(shifted)))) / _g_alpha

def slsqp_optimize(h, n, target, alphas, maxiter, ftol, deadline):
    global _g_n, _g_target, _g_alpha
    _g_n = n
    _g_target = target
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': _cons_eq, 'jac': _cons_jac}]
    h_cur = h.copy()
    cur_score = compute_c5(h_cur)
    for a in alphas:
        if time.time() > deadline:
            break
        _g_alpha = float(a)
        try:
            res = minimize(_lse_obj, h_cur, method='SLSQP', bounds=bounds,
                           constraints=cons, options={'maxiter': maxiter, 'ftol': ftol})
            h_new = project_feasible(res.x, target)
            sc = compute_c5(h_new)
            if sc < cur_score:
                h_cur = h_new
                cur_score = sc
        except Exception:
            pass
    return h_cur

def multi_lag_surgery(h, n, target, max_steps, deadline, n_lags=5):
    """Surgery on multiple worst lags simultaneously."""
    h_cur = h.copy()
    cur_score = compute_c5(h_cur)
    dx = 2.0 / n
    eps = 0.003
    
    for step in range(max_steps):
        if time.time() > deadline:
            break
        
        corr = compute_corr(h_cur)
        top_idx = np.argsort(corr)[::-1][:n_lags]
        top_vals = corr[top_idx]
        
        # Softmax weights for the top lags
        a = 200.0
        w = np.exp(a * (top_vals - top_vals[0]))
        w /= w.sum()
        
        lags = top_idx - (n - 1)
        grad = compute_weighted_gradient(h_cur, lags, w, n) * dx
        
        h_new = h_cur - eps * grad
        h_new = project_feasible(h_new, target)
        sc_new = compute_c5(h_new)
        
        if sc_new < cur_score - 1e-14:
            h_cur = h_new
            cur_score = sc_new
            eps = min(eps * 1.03, 0.02)
        else:
            eps *= 0.6
            if eps < 1e-9:
                break
    
    return h_cur, cur_score

    rng = np.random.RandomState(seed)
    hard_deadline = start_time + budget_s - 10.0

    def tleft():
        return hard_deadline - time.time()

    n_final = len(initial_h_values)
