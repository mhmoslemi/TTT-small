Let me also think about whether there's a smarter way to find t*.

Since f(t) = max_k (C0[k] + t*a[k]) (ignoring the quadratic for a moment) is the upper envelope of lines, the minimum is at:
- t = 0 or t = 1, or
- An intersection of two lines where one has positive slope and one has negative slope

The key insight: at the optimal t, the maximum is "flat" (two lines cross at the maximum). So:
- Find all pairs (i,j) with a[i] > 0 and a[j] < 0
- For each pair, compute t = (C0[j] - C0[i]) / (a[i] - a[j])
- Check if t ∈ [0,1] and if C0[i] + t*a[i] = C0[j] + t*a[j] is indeed the maximum
- Pick the t with the lowest maximum

But checking "is it the maximum" requires O(n) per candidate, and there could be O(n²) candidates. Total: O(n³) which is too slow.

Alternative: use the "smallest enclosing" approach. The optimal t is the one where the minimum of the max is achieved. This is equivalent to: find the smallest T such that there exists t with C0[k] + t*a[k] ≤ T for all k.

This is a 1D feasibility problem: for a given T, check if there exists t ∈ [0,1] such that:
C0[k] + t*a[k] ≤ T for all k

This gives: t ≤ (T - C0[k])/a[k] for a[k] > 0, and t ≥ (T - C0[k])/a[k] for a[k] < 0.

So we need: max_{k: a[k]<0} (T-C0[k])/a[k] ≤ min_{k: a[k]>0} (T-C0[k])/a[k] and the result is in [0,1].

We can binary search on T! This gives O(n log n * log_precision) per coordinate.

```python
def solve_1d_bisect(C0, a, half_n):
    """Find t* that minimizes max_k (C0[k] + t*a[k]) with quadratic at k=half_n."""
    
    # Binary search on T
    # Lower bound: min of individual minimums
    # Upper bound: max of C0[k] (at t=0)
    
    T_lo = np.max(C0 + np.where(a > 0, 0, 1) * 0)  # just max(C0) as initial
    T_hi = np.max(C0)  # value at t=0
    
    # Actually, let me think of a better bound.
    # At t=0: max is max(C0)
    # At t=1: max is max(C0 + a) (approximately, ignoring quadratic)
    # The optimal T is ≤ min(max(C0), max(C0+a))
    
    T_hi = np.min([np.max(C0), np.max(C0 + a)])
    T_lo = np.min(C0)  # very loose lower bound
    
    for _ in range(80):
        T_mid = (T_lo + T_hi) / 2
        if feasible(T_mid, C0, a, half_n):
            T_hi = T_mid
        else:
            T_lo = T_mid
    
    # Now T_hi is the optimal T (approximately)
    # Find the corresponding t:
    # t must satisfy: for all k with a[k] > 0: t ≤ (T_hi - C0[k]) / a[k]
    #              for all k with a[k] < 0: t ≥ (T_hi - C0[k]) / a[k]
    pos = a > 1e-15
    neg = a < -1e-15
    
    t_ub = 1.0
    t_lb = 0.0
    if np.any(pos):
        t_ub = np.min((T_hi - C0[pos]) / a[pos])
    if np.any(neg):
        t_lb = np.max((T_hi - C0[neg]) / a[neg])
    
    t_ub = min(t_ub, 1.0)
    t_lb = max(t_lb, 0.0)
    
    if t_lb <= t_ub:
        return (t_lb + t_ub) / 2
    else:
        # Infeasible (shouldn't happen), return midpoint
        return 0.5

def feasible(T, C0, a, half_n):

    pos = a > 1e-15
    neg = a < -1e-15
    
    t_ub = 1.0
    t_lb = 0.0
    if np.any(pos):
        t_ub = np.min((T - C0[pos]) / a[pos])
        if t_ub < 0:
            return False
    if np.any(neg):
        t_lb = np.max((T - C0[neg]) / a[neg])
        if t_lb > 1:
            return False
    
    # Check quadratic constraint at half_n
    # C0[half_n] + t - t² <= T for t in [t_lb, min(t_ub, 1)]
    # i.e., t² - t + (T - C0[half_n]) >= 0 for t in [t_lb, min(t_ub, 1)]
    # The quadratic t² - t + c >= 0 has roots at (1±sqrt(1-4c))/2
    # It's >= 0 outside the roots (since leading coefficient is positive)
    
    t_check_hi = min(t_ub, 1.0)
    if t_lb <= t_check_hi:
        # Check the constrained interval [t_lb, t_check_hi]
        # The minimum of t - t² on [t_lb, t_check_hi]:
        # t - t² is maximized at t=0.5, so it's minimized at the endpoints
        # We need: C0[half_n] + t - t² <= T for all t in [t_lb, t_check_hi]
        # Max of t - t² on [t_lb, t_check_hi]:
        lo_check = t_lb
        hi_check = t_check_hi
        max_quad = max(lo_check - lo_check**2, hi_check - hi_check**2)
        if 0.5 >= lo_check and 0.5 <= hi_check:
            max_quad = max(max_quad, 0.25)
        if C0[half_n] + max_quad > T:
```

But wait, I need to handle the quadratic constraint correctly. Let me reconsider.

The constraint is: C0[half_n] + t - t² ≤ T for some t in [t_lb, t_ub] ∩ [0,1].

The function q(t) = C0[half_n] + t - t² is a concave parabola with maximum at t=0.5.
So q(t) ≤ T is equivalent to t² - t + (T - C0[half_n]) ≥ 0.

The roots of t² - t + (T - C0[half_n]) = 0 are:
t = (1 ± sqrt(1 - 4(T - C0[half_n])))/2

Let D = 1 - 4(T - C0[half_n]).
If D < 0: the quadratic is always negative (no real roots), so q(t) > T for all t. Infeasible.
If D ≥ 0: roots are r1 = (1-sqrt(D))/2 and r2 = (1+sqrt(D))/2. q(t) ≤ T for t ≤ r1 or t ≥ r2.

So we need [t_lb, t_ub] ∩ [0,1] to have a non-empty intersection with (-∞, r1] ∪ [r2, ∞).

This is a feasibility check that can be done in O(1).

Let me refine:

```python
def feasible(T, C0, a, half_n):
    pos = a > 1e-15
    neg = a < -1e-15
    
    t_ub = 1.0
    t_lb = 0.0
    if np.any(pos):
        vals = (T - C0[pos]) / a[pos]
        t_ub = np.min(vals)
        if t_ub < 0:
            return False
    if np.any(neg):
        vals = (T - C0[neg]) / a[neg]
        t_lb = np.max(vals)
        if t_lb > 1:
            return False
    
    t_ub = min(t_ub, 1.0)
    t_lb = max(t_lb, 0.0)
    if t_lb > t_ub:
        return False
    
    # Check quadratic constraint
    c = T - C0[half_n]
    D = 1.0 - 4.0 * c
    if D < 0:
        return False
    sqrt_D = np.sqrt(D)
    r1 = (1.0 - sqrt_D) / 2.0
    r2 = (1.0 + sqrt_D) / 2.0
    # Need t in [t_lb, t_ub] AND (t <= r1 OR t >= r2)
    # i.e., [t_lb, t_ub] ∩ ((-inf, r1] ∪ [r2, inf]) is non-empty
    if t_lb <= r1 or t_ub >= r2:
        return True
    return False
```

Let me also add a "2D block" optimization: pick two coordinates (j, l) and optimize them jointly. The objective becomes:
f(t_j, t_l) = max_k (C0[k] + t_j*a_k^(j) + t_l*a_k^(l))

This is the upper envelope of planes in 2D. The minimum is at:
- A vertex of the upper envelope (intersection of 3 planes), or
- On an edge (intersection of 2 planes), or
- At a corner of the feasible region (t_j=0, t_j=1, t_l=0, t_l=1)

With the sum constraint t_j + t_l = constant, it reduces to 1D anyway.

So for the 2D case with sum constraint: let t_j = s, t_l = c - s where c is the current sum contribution.
Then f(s) = max_k (C0[k] + s*a_k^(j) + (c-s)*a_k^(l)) = max_k ((C0[k] + c*a_k^(l)) + s*(a_k^(j) - a_k^(l)))

This is again a 1D problem! So the 2D optimization with sum constraint is no harder than 1D.

The difference is: in 1D coordinate descent, we optimize one coordinate and project (which changes many other coordinates). In 2D block optimization with the sum constraint absorbed, we only change two coordinates and don't need to project.

This is actually better! Let me implement a "pairwise" coordinate descent:

1. Pick a pair (j, l)
2. Fix all other coordinates
3. Let s = t_j + t_l = h[j] + h[l] (must be preserved)
4. Optimize t_j (and t_l = s - t_j) using the 1D bisection method
5. Update h[j] and h[l]

This avoids the projection step entirely and is more precise.

Wait, I need to be more careful. The coefficient a_k^(j) is the change in C_k per unit increase in h[j], assuming h[l]=0. But if h[l] is also changing, there might be cross-terms.

Actually, since the correlation is bilinear in h (it's a sum of products h[i]*(1-h[i+k]) = h[i] - h[i]*h[i+k]), there ARE cross-terms when both h[j] and h[l] are non-zero.

Let me expand: C_k = sum_i h[i]*(1-h[i+k]) = sum_i h[i] - sum_i h[i]*h[i+k]

The first term is linear in h. The second term is bilinear.

So C_k = sum_i h[i] - sum_i h[i]*h[i+k]

This is NOT linear in h! It's quadratic (bilinear) in h. So my earlier analysis of "linear in t" was only correct when changing ONE coordinate at a time (since the cross-terms with other coordinates are fixed).

When changing two coordinates j and l, the cross-term h[j]*h[j+k] and h[j+k]*h[j] (and similarly for l) create bilinear terms.

Specifically, if both h[j] and h[l] are non-zero, and j+k = l (or l+k = j) for some k, then there's a cross-term h[j]*h[l] in C_k.

So the 2D optimization is NOT simply a 1D problem. It's a proper 2D problem (well, 1D with a quadratic term due to the cross-terms).

In practice, for random pairs (j, l), the probability that j+k = l for the "active" k values is small. So the cross-term is usually negligible. But for correctness, I should handle it.

Let me just stick with 1D coordinate descent (one coordinate at a time) and use the projection step. The projection is a small perturbation, and the overall algorithm still converges.

Alternatively, I can do the 2D optimization correctly by including the cross-terms:

C_k(t_j, t_l) = corr0[k] + t_j * a_k^(j) + t_l * a_k^(l) + t_j * t_l * b_k

where b_k is the cross-term coefficient (non-zero only when j+k=l or l+k=j).

For the sum constraint t_j + t_l = s_total, let t_j = s, t_l = s_total - s:
C_k(s) = corr0[k] + s*a_k^(j) + (s_total-s)*a_k^(l) + s*(s_total-s)*b_k
= (corr0[k] + s_total*a_k^(l)) + s*(a_k^(j) - a_k^(l)) + s*(s_total-s)*b_k

The last term s*(s_total-s)*b_k is quadratic in s. So C_k(s) is still quadratic in s (but with a different form than the single-coordinate case).

The overall objective is max_k C_k(s) which is the max of quadratics - not convex in general. This makes the 1D optimization harder.

For simplicity, let me just do 1D coordinate descent with projection. The cross-terms are handled correctly in the 1D case (since only one coordinate changes at a time).

Key optimization: instead of recomputing the full correlation after each coordinate update, I'll update it incrementally.

When h[j] changes from old to new:
- The change in corr at index half_n + k is:
  Δ = new*(1-h[j-k])*1[valid] + h[j+k]*(1-new)*1[valid] - old*(1-h[j-k])*1[valid] - h[j+k]*(1-old)*1[valid]
  = (new-old)*(1-h[j-k])*1[valid] - h[j+k]*(new-old)*1[valid]
  = (new-old) * [(1-h[j-k])*1[0≤j-k<n] - h[j+k]*1[0≤j+k<n]]
  = (new-old) * a[k]  (where a[k] is the coefficient I computed earlier!)

So corr_new = corr_old + (new - old) * a

This is O(n) to update! Much better than O(n²) recomputation.

```python
import numpy as np

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr)) * dx

def project_feasible(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    diff = target_sum - np.sum(h)
    if abs(diff) < 1e-14:
        return h
    h = h.copy()
    if diff > 0:
        idx = np.where(h < 1.0 - 1e-10)[0]
    else:
        idx = np.where(h > 1e-10)[0]
    if len(idx) == 0:
        return h
    h[idx] += diff / len(idx)
    h = np.clip(h, 0.0, 1.0)
    residual = target_sum - np.sum(h)
    if abs(residual) > 1e-10:
        if residual > 0:
            idx2 = np.where(h < 1.0)[0]
        else:
            idx2 = np.where(h > 0.0)[0]
        if len(idx2) > 0:
            h[idx2] += residual / len(idx2)
            h = np.clip(h, 0.0, 1.0)
    return h

def compute_coefficients(h, j, n):
    """Compute the coefficient vector a[k] for coordinate j.
    a[k] represents the change in corr[half_n+k] per unit increase in h[j]."""
    half_n = n - 1
    ks = np.arange(-n + 1, n)
    a = np.zeros(2 * n - 1)
    
    # First term: (1 - h[j-k]) for 0 <= j-k < n
    idx1 = j - ks
    valid1 = (idx1 >= 0) & (idx1 < n)
    a[valid1] += 1.0 - h[idx1[valid1]]
    
    # Second term: -h[j+k] for 0 <= j+k < n
    idx2 = j + ks
    valid2 = (idx2 >= 0) & (idx2 < n)
    a[valid2] -= h[idx2[valid2]]
    
    return a

def solve_1d_bisect(C0, a, half_n, n_bisect=60):
    """Find t* that minimizes max_k (C0[k] + t*a[k]) with quadratic correction at k=half_n."""
    
    # Binary search on T (the optimal max value)
    T_lo = np.min(C0 + a * 0.5)  # rough lower bound
    T_hi = np.min([np.max(C0), np.max(C0 + a)])  # upper bound
    
    # Ensure T_lo < T_hi
    if T_lo >= T_hi:
        T_lo = T_hi - 1.0
    
    for _ in range(n_bisect):
        T_mid = (T_lo + T_hi) / 2.0
        if feasible_T(T_mid, C0, a, half_n):
            T_hi = T_mid
        else:
            T_lo = T_mid
    
    # Extract t from the constraints at T = T_hi
    pos = a > 1e-12
    neg = a < -1e-12
    
    t_ub = 1.0
    t_lb = 0.0
    if np.any(pos):
        t_ub = np.min((T_hi - C0[pos]) / a[pos])
    if np.any(neg):
        t_lb = np.max((T_hi - C0[neg]) / a[neg])
    
    t_ub = min(max(t_ub, 0.0), 1.0)
    t_lb = max(min(t_lb, 1.0), 0.0)
    
    if t_lb > t_ub:
        # Shouldn't happen, return midpoint
        return 0.5
    
    # Check quadratic constraint and adjust
    # We need t such that C0[half_n] + t - t^2 <= T_hi
    # and t in [t_lb, t_ub]
    c = T_hi - C0[half_n]
    D = 1.0 - 4.0 * c
    if D < 0:
        # Quadratic constraint infeasible, relax
        return (t_lb + t_ub) / 2.0
    sqrt_D = np.sqrt(D)
    r1 = (1.0 - sqrt_D) / 2.0
    r2 = (1.0 + sqrt_D) / 2.0
    
    # Valid t: [t_lb, t_ub] ∩ ((-inf, r1] ∪ [r2, inf])
    candidates = []
    if t_lb <= r1:
        candidates.append(t_lb)
        candidates.append(min(r1, t_ub))
    if t_ub >= r2:
        candidates.append(max(r2, t_lb))
        candidates.append(t_ub)
    
    if not candidates:
        return (t_lb + t_ub) / 2.0
    
    # Pick the candidate that minimizes the max
    best_t = candidates[0]
    best_val = np.inf
    for tc in candidates:
        tc = max(0.0, min(1.0, tc))
        vals = C0 + tc * a
        vals[half_n] = C0[half_n] + tc - tc * tc
        v = np.max(vals)
        if v < best_val:
            best_val = v
            best_t = tc
    
    return best_t

def feasible_T(T, C0, a, half_n):
    """Check if there exists t in [0,1] with C0[k] + t*a[k] <= T (and quadratic constraint)."""
    pos = a > 1e-12
    neg = a < -1e-12
    
    t_ub = 1.0
    t_lb = 0.0
    if np.any(pos):
        vals = (T - C0[pos]) / a[pos]
        t_ub = np.min(vals)
        if t_ub < 0:
            return False
    if np.any(neg):
        vals = (T - C0[neg]) / a[neg]
        t_lb = np.max(vals)
        if t_lb > 1.0:
            return False
    
    t_ub = min(t_ub, 1.0)
    t_lb = max(t_lb, 0.0)
    if t_lb > t_ub:
        return False
    
    # Quadratic constraint: C0[half_n] + t - t^2 <= T
    c = T - C0[half_n]
    D = 1.0 - 4.0 * c
    if D < 0:
        return False
    sqrt_D = np.sqrt(D)
    r1 = (1.0 - sqrt_D) / 2.0
    r2 = (1.0 + sqrt_D) / 2.0
    
    # Need [t_lb, t_ub] ∩ ((-inf, r1] ∪ [r2, inf]) non-empty
    if t_lb <= r1 or t_ub >= r2:
        return True
    return False
```
