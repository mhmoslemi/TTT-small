Let me also add a technique I haven't tried: **cyclic coordinate descent on pairs**.

For the worst lag k*, we want to minimize sum_i h[i](1-h[i+k*]).
For each pair (i, i+k*), the contribution is h[i](1-h[i+k*]).
If we change h[i] and h[i+k*] while keeping their sum constant, we can reduce this term.

Specifically, for a pair (i, j) where j = i + k*:
- Current: h[i] + h[j] = s (constant)
- We want to minimize h[i](1-h[j]) = h[i](1-s+h[i]) = h[i]^2 - (s-1)h[i]
- This is minimized at h[i] = (s-1)/2, so h[j] = (s+1)/2
- But we also need h[i], h[j] in [0,1]

Wait, this only works for the single lag. In reality, changing h[i] and h[j] affects ALL lags, not just k*. So this is a local move that might help one lag but hurt others.

A better version: for the worst lag k*, do a pass over all pairs, and for each pair, make a small move in the direction that reduces the k* correlation the most, while checking that the overall max doesn't increase.

This is essentially what the subgradient method does, but the pair-based approach might be more efficient because it makes targeted moves.

def pair_optimization(h, n, target, k_star, max_passes, deadline):
    """Optimize pairs (i, i+k_star) to reduce the k_star correlation."""
    h_cur = h.copy()
    cur_score = compute_c5(h_cur)
    dx = 2.0 / n
    
    for _pass in range(max_passes):
        if time.time() > deadline:
            break
        improved = False
        for i in range(n - k_star):
            j = i + k_star
            # Current pair values
            hi = h_cur[i]
            hj = h_cur[j]
            s = hi + hj  # keep sum constant
            
            # Optimal for just this lag: h[i] = max(0, min(1, (s-1)/2))
            optimal_hi = (s - 1.0) / 2.0
            optimal_hi = max(0.0, min(1.0, optimal_hi))
            optimal_hj = s - optimal_hi
            
            # Try a fractional move toward the optimal
            for frac in [0.3, 0.5, 0.7, 1.0]:
                new_hi = hi + frac * (optimal_hi - hi)
                new_hj = hj + frac * (optimal_hj - hj)
                if new_hi < 0 or new_hi > 1 or new_hj < 0 or new_hj > 1:
                    continue
                h_test = h_cur.copy()
                h_test[i] = new_hi
                h_test[j] = new_hj
                h_test = project_feasible(h_test, target)
                sc = compute_c5(h_test)
                if sc < cur_score:
                    h_cur = h_test
                    cur_score = sc
                    improved = True
                    break
        if not improved:
            break
    
    return h_cur, cur_score
