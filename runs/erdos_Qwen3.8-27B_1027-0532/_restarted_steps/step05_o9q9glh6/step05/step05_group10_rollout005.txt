   At lag k (integer): h(x+k) = 1/2 + A*cos(2πf(x+k)) = 1/2 + A*cos(2πfx + 2πfk) = 1/2 + A*cos(2πfx) = h(x).
   
   So for integer k and integer f, h(x+k) = h(x)! This means h(x)(1-h(x+k)) = h(x)(1-h(x)) for all integer k.
   At k=0: h(1-h). The max of h(1-h) is 1/4 (at h=1/2).
   ∫ h(1-h) dx = ∫ (1/4 - A²cos²(2πfx)) dx = 1/2 - A²/2 = (1-A²)/2.

   For A = 1/2: C₅ = (1-1/4)/2 = 3/8 = 0.375.

   And for non-integer k, h(x+k) ≠ h(x) in general, so the overlap is different.

   But wait, in the DISCRETE case, the lag k is an integer number of grid points. If h[i] = 1/2 + A*cos(2πfi/n) for i=0,...,n-1, then:
   h[i+k] = 1/2 + A*cos(2πf(i+k)/n) = 1/2 + A*cos(2πfi/n + 2πfk/n)

   For this to equal h[i], we need 2πfk/n = 2πm for some integer m, i.e., fk = mn.
   If f | n and k = n/f, then h[i+k] = h[i].

   So for h[i] = 1/2 + A*cos(2πfi/n) with f | n, the "self-correlation" lags are multiples of n/f.

   At lag k = n/f: h[i](1-h[i+k]) = h[i](1-h[i]). 
   The sum: ∑ h[i](1-h[i]) = ∑ (1/4 - A²cos²(2πfi/n)) = n/4 - A² * n/4 = n(1-A²)/4.
   C₅ contribution: n(1-A²)/4 * 2/n = (1-A²)/2.

   For A = 1/2: (1-1/4)/2 = 3/8 = 0.375.

   But what about other lags? At lag k not a multiple of n/f:
   h[i](1-h[i+k]) = (1/2 + A cos(2πfi/n))(1/2 - A cos(2πf(i+k)/n))
   = 1/4 - A/2 cos(2πf(i+k)/n) + A/2 cos(2πfi/n) - A² cos(2πfi/n)cos(2πf(i+k)/n)

   Summing over i=0 to n-1-k:
   The first term: (n-k)/4
   The second and third terms: sums of cosines, which are O(1) (bounded) for non-resonant frequencies.
   The fourth term: -A²/2 ∑ [cos(2πfk/n) + cos(2πf(2i+k)/n)]
   = -A²/2 [(n-k)cos(2πfk/n) + O(1)]

   So the sum ≈ (n-k)/4 - A²(n-k)cos(2πfk/n)/2 + O(1)
   = (n-k)(1/4 - A²cos(2πfk/n)/2) + O(1)

   For A = 1/2:
   = (n-k)(1/4 - cos(2πfk/n)/8) + O(1)
   = (n-k)(2 - cos(2πfk/n))/8 + O(1)

   The maximum of (2 - cos(2πfk/n))/8 is at cos = -1: (2+1)/8 = 3/8.
   The minimum is at cos = 1: (2-1)/8 = 1/8.

   So for the cosine hamp with A=1/2, the C₅ at various lags ranges from about (n-k)/8 * dx to (n-k)*3/8 * dx.
   The maximum is at k where cos(2πfk/n) = -1, i.e., 2πfk/n = π, i.e., k = n/(2f).

   At k = n/(2f): C₅ ≈ (n - n/(2f)) * 3/8 * 2/n = (1 - 1/(2f)) * 3/4.
   For f=1: C₅ ≈ 3/4. That's terrible!

   So a single cosine hamp is NOT a good solution. The issue is that at the anti-period, the overlap is maximized.

   What if we use MULTIPLE frequencies? Like a Fourier series with multiple components?

   h[i] = 1/2 + ∑_j A_j cos(2πf_j i/n + φ_j)

   The constraint ∑h = n/2 is automatically satisfied (the cosines sum to 0).
   The constraint 0 ≤ h ≤ 1 requires careful choice of amplitudes.

   The overlap at lag k:
   ∑ h[i](1-h[i+k]) ≈ (n-k)/4 - ∑_j A_j²(n-k)cos(2πf_j k/n)/2 + cross terms

   To minimize the max over k, we want the "autocorrelation" of h to be as uniformly positive as possible.
