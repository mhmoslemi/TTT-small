    The Erdős problem is related to finding sets with low overlap. For C₅, we want a set S of measure 1 in [0,2] such that |S ∩ (S+k)| is close to the maximum possible for all k.
    
    For a periodic pattern with period p, the autocorrelation has peaks at multiples of p. To minimize the maximum overlap, we want the autocorrelation to be as "flat" as possible (equally distributed).
    
    One natural candidate: h = indicator of union of intervals arranged to have uniform autocorrelation. For example, if we take h as a "checkerboard" pattern at fine scale, the autocorrelation would be close to 1/2 everywhere (for shifts not aligned with the pattern).
    
    But we also need to handle the boundary effects (the correlation only considers x where both x and x+k are in [0,2]).

    Actually, for the continuous problem, a good heuristic is:
    - h(x) = 1 for x in a "Salem-Zygmund" type set
    - Or: h(x) = 1 for x in a set that is "equidistributed" in some sense
    
    For discrete n=400, let me think about what pattern minimizes max autocorrelation.
    
    For a binary sequence of length n with n/2 ones, the aperiodic autocorrelation at lag k is:
    R(k) = ∑_{j=0}^{n-1-k} h[j]h[j+k] - (n-k)/4
    
    (normalized to have zero mean). We want |R(k)| to be small for all k. This is related to Barker sequences and low-autocorrelation sequences.

    diff = target_sum - np.sum(h)
    if abs(diff) < 1e-14:

            h[i] = 1.0
            h[ip] = 0.0

            one_idx = np.delete(one_idx, best_b)

            one_idx = np.append(one_idx, i)

                    one_idx = np.append(one_idx, i)

                C_max = C.max()

                stuck_count = 0
    
    return best_h, best_C_max

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr)) * dx

def project_feasible(h, target_sum):
    h = np.clip(h.astype(float), 0.0, 1.0)
    diff = target_sum - np.sum(h)
    if abs(diff) < 1e-14:
        return h
    if diff > 0:
        idx = np.where(h < 1.0 - 1e-10)[0]
    else:
        idx = np.where(h > 1e-10)[0]
    if len(idx) == 0:
        return h
    h = h.copy()
    h[idx] += diff / len(idx)
    h = np.clip(h, 0.0, 1.0)
    residual = target_sum - np.sum(h)
    if abs(residual) > 1e-10:
        if residual > 0:
            idx2 = np.where(h < 1.0)[0]
        else:
            idx2 = np.where(h > 0.0)[0]
        if len(idx2) > 0:
            h[idx2] += residual / len(idx2)
            h = np.clip(h, 0.0, 1.0)
    return h

def compute_correlation(h):
    n = len(h)
    dx = 2.0 / n
    return np.correlate(h, 1.0 - h, mode='full') * dx

def get_f_matrix(h, idx, n, k_vals):
    dx = 2.0 / n
    ik = idx[:, None] + k_vals[None, :]
    ik_valid = (ik >= 0) & (ik < n)
    first = np.where(ik_valid, 1.0 - h[ik.clip(0, n - 1)], 0.0)
    ik2 = idx[:, None] - k_vals[None, :]
    ik2_valid = (ik2 >= 0) & (ik2 < n)
    second = np.where(ik2_valid, -h[ik2.clip(0, n - 1)], 0.0)
    return (first + second) * dx
