        #   0 <= h <= 1

        t_var = cp.Variable()

Let me think about the **step size** for the gradient method. The function F(h) = max c[m] * dx is Lipschitz with constant L. What's L?

For n=400: L ≤ 4/20 = 0.2

Actually, the Lipschitz constant for the gradient (smoothness parameter) is what matters for the step size in gradient descent. The smoothing parameter of c[m] (as a function of h) is the operator norm of its Hessian.

The Hessian of c[m] is a band matrix with -1 on the (k, k+m) and (k+m, k) positions (within the valid range). Its operator norm is at most 2.

So the smoothness parameter L = 2 * dx = 2 * 2/400 = 0.01.

With L = 0.01, the optimal step size for gradient descent on a smooth function is 1/L = 100. But this is for the smooth unconstrained case. With projection, we should use a smaller step.
