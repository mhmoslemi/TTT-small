Actually, let me reconsider the coordinate descent. For a fixed j, the problem is:

1. Binary search on the derivative
2. Or enumerate the breakpoints

Actually, even better: since f is convex and piecewise linear, the minimum is at a point where the derivative crosses zero. The derivative is c_k where k is the argmax. So:
- If c_{argmax} > 0 at v=0, the function is increasing at v=0, so min is at v=0
- If c_{argmax} < 0 at v=1, the function is decreasing at v=1, so min is at v=1
- Otherwise, the min is in (0,1) at a kink point

At a kink point, two (or more) shifts tie for the max. We can find this by:
- Start at v where c_{argmax} < 0 (function is decreasing)
- Increase v until the argmax changes
- At the change, check if the new c_{argmax} > 0 (then we've passed the min)
- Use bisection to find the crossing

This is efficient: O(n) per coordinate update.

import numpy as np

def project(x, target):
    lo = -2.0
    hi = 3.0
    for _ in range(80):
        mid = (lo + hi) * 0.5
        s = np.clip(x - mid, 0.0, 1.0).sum()
        if s > target:
            lo = mid
        else:
            hi = mid
    return np.clip(x - (lo + hi) * 0.5, 0.0, 1.0)

def c5_val(h, dx):
    return float(np.max(np.correlate(h, 1.0 - h, mode='full')) * dx)

    if s == 0:
        g[:] = 1.0 - 2.0 * h

        g[s:] += (-h[:n-s])
    else:
        t = -s
        g[t:] = (1.0 - h[:n-t])
        g[:n-t] += (-h[t:])
