def evaluate(h, dx):
    corr = np.correlate(h, 1.0 - h, mode="full")
    return np.max(corr) * dx

def project_feasible(h, target_sum):
    lo, hi = -2.0, 2.0
    for _ in range(80):
        mid = 0.5 * (lo + hi)
        hc = np.clip(h - mid, 0.0, 1.0)
        s = hc.sum()
        if s > target_sum:
            lo = mid
        else:
            hi = mid
    return np.clip(h - 0.5*(lo+hi), 0.0, 1.0)

def compute_gradient(h, dx, beta):
    n = len(h)
    corr = np.correlate(h, 1.0 - h, mode="full")
    scaled = beta * corr * dx
    mx = scaled.max()
    w = np.exp(scaled - mx)
    w /= w.sum()

    conv2 = np.convolve(w, h_rev, mode='full')
    first_sum = conv1[n-1 : 2*n-1]
    second_sum = conv2[n-1 : 2*n-1][::-1]

    c5 = evaluate(h, dx)
    
    while time.time() - start < max_time:
        # Anneal beta
        t_frac = (time.time() - start) / max_time
        beta = beta_start * (beta_end / beta_start) ** t_frac if max_time > 0 else beta_end
        
        grad = compute_gradient(h, dx, beta)

            c5 = c5_new
        else:
            # Reduce learning rate
            lr *= 0.5

Actually, let me think about a better approach. For coordinate descent, since the objective is convex in each coordinate (piecewise linear), I can find the exact optimal value for each coordinate by finding the "knee" of the piecewise linear function.

The objective as a function of h[j] (with other coordinates fixed) is:

where c_k(h) = c_k_base + a_k * h[j] for some constants c_k_base and a_k (which depend on the other coordinates).

The maximum of linear functions is a convex piecewise linear function. The minimum is at a point where the slope changes from negative to positive.

The slope of c_k with respect to h[j] is:
a_k = dc_k/dh[j] (computed as before)

So I need to find the value of h[j] that minimizes max_k (c_k_base + a_k * h[j]).

This is a 1D minimax problem! The optimal h[j] is where the "upper envelope" of the lines c_k_base + a_k * h[j] has its minimum.

This can be found by:
1. Computing all (c_k_base, a_k) pairs
2. Finding the lower envelope's minimum (or rather, the upper envelope's minimum)

The upper envelope of lines y = a_k * x + b_k is a convex piecewise linear function. Its minimum is at a vertex of the upper envelope, which is at the intersection of two lines a_k1 * x + b_k1 = a_k2 * x + b_k2.

Finding the minimum of the upper envelope is equivalent to finding x that minimizes max_k (a_k * x + b_k), which is a 1D linear programming problem (minimize t subject to a_k * x + b_k ≤ t for all k, 0 ≤ x ≤ 1).

This can be solved by:
- The optimal x is at a breakpoint of the upper envelope
- There are at most O(n) breakpoints (one for each pair of lines, but the upper envelope has at most n vertices)
- We can find all candidate x values (intersections of pairs) and evaluate F at each

But that's O(n²) candidate points, each requiring O(n) evaluation, so O(n³) per coordinate. For n=63, that's 63³ * 63 ≈ 1.6 * 10^7 per full pass. That's too slow.

Alternative: use a bisection or ternary search on x ∈ [0, 1]. Since F(x) is convex, ternary search works. Each evaluation is O(n) (compute all c_k_base + a_k * x and take max). So ternary search takes O(n * log(1/eps)) per coordinate.

For n=63, log(1/eps) ≈ 50 (for machine precision): 63 * 50 = 3150 per coordinate, 63 coordinates = 198,450 per full pass. Very fast!

import numpy as np

def evaluate_erdos(h, dx):
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)

def project_feasible(h, target_sum):
    lo = h.min() - 1.0
    hi = h.max() + 1.0
    for _ in range(100):
        mid = 0.5 * (lo + hi)
        hc = np.clip(h - mid, 0.0, 1.0)
        s = np.sum(hc)
        if s > target_sum:
            lo = mid
        else:
            hi = mid
    return np.clip(h - 0.5*(lo + hi), 0.0, 1.0)

def compute_smooth_grad(h, dx, beta):
    n = len(h)
    corr = np.correlate(h, 1.0 - h, mode="full")
    val = beta * corr * dx
    val -= val.max()
    w = np.exp(val)
    w /= w.sum()

    A = 1.0 - h

    first_sum = conv1[n-1 : 2*n-1]
    second_sum = conv2[n-1 : 2*n-1][::-1]
