For the projection onto {h: 0<=h<=1, sum(h)=target}:
This is the "isotonic regression with sum constraint" or "Euclidean projection onto a polytope". The algorithm is:
1. Start with x = h - (sum(h) - target) / (number of free variables)
2. Identify variables that are at bounds
3. Re-solve for the free variables
4. Iterate

A simpler approach: bisection on a threshold λ such that:
h_proj[i] = clip(h[i] - λ, 0, 1) and sum(h_proj) = target

This works because the projection onto {0<=h<=1, sum(h)=target} is:
h_proj[i] = min(1, max(0, h[i] - λ)) for some λ chosen so that sum = target.

This is because the constraint set is the intersection of a box and a hyperplane, and the normal to the hyperplane is (1,1,...,1).

Let me implement this with bisection:

```python
def project_constraint(h, target):
    n = len(h)
    # Find lambda such that sum(clip(h - lambda, 0, 1)) = target
    lo = h.min() - 1
    hi = h.max()
    for _ in range(100):
        mid = (lo + hi) / 2
        s = np.clip(h - mid, 0, 1).sum()
        if s > target:
            lo = mid
        else:
            hi = mid
    return np.clip(h - (lo+hi)/2, 0, 1)
```

```python
    c_max = np.max(c)
```

```python
def compute_gradient(h, dx, temp):
    n = len(h)
    c = np.correlate(h, 1-h, mode="full")
    c_max = np.max(c)
    w = np.exp((c - c_max) / temp)
    w /= np.sum(w)
    
    one_minus_h = 1 - h
    grad = np.zeros(n)
    for m in range(n):
        for k in range(2*n - 1):
            wk = w[k]
            if wk < 1e-12:
                continue
            # first term: (1-h[m+n-1-k]) if 0 <= m+n-1-k < n
            idx1 = m + n - 1 - k
            if 0 <= idx1 < n:
                grad[m] += wk * one_minus_h[idx1]
            # second term: -h[m-n+1+k] if 0 <= m-n+1+k < n
            idx2 = m - n + 1 + k
            if 0 <= idx2 < n:
                grad[m] -= wk * h[idx2]
    grad *= dx
    return grad
```
