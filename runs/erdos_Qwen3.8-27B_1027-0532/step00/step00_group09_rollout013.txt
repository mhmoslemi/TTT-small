overlap[k] (as computed by np.correlate) is a sum of products.
C5 = max_k(overlap[k]) * dx

The gradient of C5 w.r.t. h[j] is: dx * (subgradient of max_k overlap[k]) w.r.t. h[j]

The subgradient of max_k overlap[k] is the weighted sum of d(overlap[k])/d(h[j]) for active k.

So: d(C5)/d(h[j]) = dx * sum_k weights[k] * d(overlap[k])/d(h[j])

Where d(overlap[k])/d(h[j]) is what I computed above (without the dx factor).

In my code, I compute corr = np.correlate(h, 1-h, mode="full"), which gives the raw sums. Then C5 = max(corr) * dx.

The gradient should be: dx * (weighted sum of d(corr[k])/d(h[j]))

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1 - h, mode="full")

def compute_grad(h, active_tol=1e-3):
    """Compute subgradient of C5 = max_k(corr[k]) * dx."""
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1 - h, mode="full")
    max_val = np.max(corr)
    active_mask = corr >= max_val - active_tol
    active_idx = np.where(active_mask)[0]
    
    grad = np.zeros(n)
    count = float(len(active_idx))
    
    for k in active_idx:
        s = k - (n - 1)
        if s >= 0:
            j1 = np.arange(0, n - s)
            grad[j1] -= h[j1 + s]
            j2 = np.arange(s, n)
            grad[j2] += (1.0 - h[j2 - s])
        else:
            t = -s

            grad[j1] += (1.0 - h[j1 - t])
            j2 = np.arange(0, n - t)
            grad[j2] -= h[j2 + t]
