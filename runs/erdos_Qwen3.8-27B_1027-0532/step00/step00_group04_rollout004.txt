Actually, let me reconsider the whole approach. The key insight is:

The pairwise optimization is exact for the 2-variable subproblem. If I do a full sweep (all pairs, in random order), I should make progress. The question is how many sweeps I need.

Let me also consider: what if I use a "greedy" approach where at each step, I find the pair (j,l) that gives the largest improvement, and update? This is like a greedy coordinate descent.

But finding the best pair requires evaluating all O(n^2) pairs, which is expensive.

A compromise: use random pairs, but with a "long memory" - keep track of which pairs have been tried recently and avoid re-trying them.

Key optimization: instead of computing the full correlation each time in pairwise_optimize, I can compute just the change in the max correlation value.

When we change h[j] from orig_j to t and h[l] from orig_l to c-t:
- The correlation values change only for lags where j or l are in the "active" range
- Specifically, for lag k with shift s=k-(n-1):
  c_k changes if j or j+s or l or l+s is in [0,n)

This means only O(1) correlation values change (at most 4 shifts for each of j and l, so ~8 values). We can compute the new max without recomputing the full correlation!

Wait, that's not quite right. c_k = sum_i h[i]*(1-h[i+s]). If h[j] changes, then c_k changes for any k where j is in the valid range for the "h" part OR for the "1-h" part.

For the "h" part: j is valid when 0≤j<n (always true) and the corresponding "1-h" term is at position j+s (valid if 0≤j+s<n).
For the "1-h" part: j is valid when 0≤j-s<n (i.e., s<j) and the corresponding "h" term is at position j-s.

So c_k changes for shifts s where:
- 0≤j+s<n (j is in range for the h part) → s ∈ [-j, n-1-j]
- 0≤j-s<n (j is in range for the 1-h part) → s ∈ [j-n+1, j]

Combined: s ∈ [j-n+1, j] ∪ [-j, n-1-j]

For j=0: s ∈ [-n+1, 0] ∪ [0, n-1] = [-n+1, n-1] (all shifts!)
For j=n/2: s ∈ [-n/2, n/2] ∪ [-n/2, n/2] = [-n/2, n/2] (half the shifts)

So for j near the edges, almost all correlation values change. This means we can't easily avoid recomputing the full correlation.

Unless... we maintain the full correlation array and only update the changed entries. But for j=0, that's all entries.

OK, so the full recomputation is the way to go. For n=70, np.correlate is very fast, so this is fine.

import numpy as np
import time

def project_onto_constraint(v, target_sum):
    """Project v onto {h: 0<=h[i]<=1, sum(h)=target_sum}"""
    n = len(v)
    lo = v.min() - 1.0
    hi = v.max() + 1.0
    for _ in range(300):
        mid = (lo + hi) * 0.5
        s = np.sum(np.clip(v - mid, 0.0, 1.0))
        if s > target_sum:
            lo = mid
        else:
            hi = mid
    lam = (lo + hi) * 0.5
    return np.clip(v - lam, 0.0, 1.0)

def compute_c5(h):
    """Compute the C5 overlap value"""
    dx = 2.0 / len(h)
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def compute_all_corr(h):
    """Compute all correlation values"""
    return np.correlate(h, 1.0 - h, mode='full')

def subgradient_descent(h, target_sum, max_steps, initial_alpha, alpha_decay):
    """Perform subgradient descent"""
    n = len(h)
    alpha = initial_alpha
    best_val = compute_c5(h)
    best_h = h.copy()
    stale = 0
    
    for step in range(max_steps):
        corr = compute_all_corr(h)
        max_val = np.max(corr)
        
        # Find active set (within 2% of max)
        threshold = max_val * 0.98
        active = np.where(corr >= threshold)[0]
        
        # Compute averaged subgradient
        grad = np.zeros(n)
        for k in active:
            shift = k - (n - 1)
            j_arr = np.arange(n)
            vp = j_arr + shift
            vm = j_arr - shift
            mask_p = (vp >= 0) & (vp < n)
            mask_m = (vm >= 0) & (vm < n)
            grad[mask_p] += 1.0 - h[vp[mask_p]]
            grad[mask_m] -= h[vm[mask_m]]
        
        grad /= max(1, len(active))
        
        # Update
        h = h - alpha * grad
        h = project_onto_constraint(h, target_sum)
        
        val = compute_c5(h)
        if val < best_val - 1e-12:
            best_val = val
            best_h = h.copy()
            stale = 0
        else:
            stale += 1
        
        if stale >= 100:
            h = best_h.copy()
            alpha *= alpha_decay
            stale = 0
        
        alpha *= 0.999
    
    return best_h, best_val

def pairwise_descent(h, target_sum, max_time, rng):
    """Perform pairwise coordinate descent"""
    n = len(h)
    best_val = compute_c5(h)
    best_h = h.copy()
    t_start = time.time()
    
    sweep = 0
    no_improve_sweeps = 0
    
    while time.time() - t_start < max_time:
        sweep += 1
        improved = False
        indices = list(range(n))
        rng.shuffle(indices)
        
        for i in range(len(indices)):
            for j_idx in range(i + 1, len(indices)):
                a = indices[i]
                b = indices[j_idx]
                
                # Optimize pair (a, b)
                c_ab = best_h[a] + best_h[b]
                t_lo = max(0.0, c_ab - 1.0)
                t_hi = min(1.0, c_ab)
                
                if t_hi - t_lo < 1e-14:
                    continue
                
                # Golden section search
                gr = (np.sqrt(5.0) - 1.0) / 2.0
                lo_ = t_lo
                hi_ = t_hi
                c_pt = hi_ - gr * (hi_ - lo_)
                d_pt = lo_ + gr * (hi_ - lo_)
                
                h_work = best_h.copy()
                h_work[a] = c_pt; h_work[b] = c_ab - c_pt
                fc = compute_c5(h_work)
                h_work[a] = d_pt; h_work[b] = c_ab - d_pt
                fd = compute_c5(h_work)
                
                for _ in range(35):
                    if hi_ - lo_ < 1e-12:
                        break
                    if fc < fd:
                        hi_ = d_pt; d_pt = c_pt; fd = fc
                        c_pt = hi_ - gr * (hi_ - lo_)
                        h_work[a] = c_pt; h_work[b] = c_ab - c_pt
                        fc = compute_c5(h_work)
                    else:
                        lo_ = c_pt; c_pt = d_pt; fc = fd
                        d_pt = lo_ + gr * (hi_ - lo_)
                        h_work[a] = d_pt; h_work[b] = c_ab - d_pt
                        fd = compute_c5(h_work)
                
                h_work[a] = (lo_ + hi_) * 0.5
                h_work[b] = c_ab - h_work[a]
                final_val = compute_c5(h_work)
                
                if final_val < best_val - 1e-11:
                    best_h = h_work
                    best_val = final_val
                    improved = True
        
        if not improved:
            no_improve_sweeps += 1
            if no_improve_sweeps >= 3:
                break
        else:
            no_improve_sweeps = 0
    
    return best_h, best_val
