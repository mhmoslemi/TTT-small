For corr[i] where i is the index in the full correlation (0 to 2n-2):
- The "lag" is `lag = i - (n-1)` (ranges from -(n-1) to (n-1))
- corr[i] = sum_j h[j+lag] * (1-h[j]) * dx, summed over valid j

For the gradient ∂corr[i]/∂h[m]:
- h[m] appears in the "first factor" h[j+lag] when j+lag = m, i.e., j = m-lag
  - Valid if 0 ≤ m-lag < n (and 0 ≤ j+lag = m < n, which is automatic)
  - Contribution: (1-h[m-lag]) * dx
- h[m] appears in the "second factor" (1-h[j]) when j = m
  - Valid if 0 ≤ m < n (always) and 0 ≤ m+lag < n
  - Contribution: -h[m+lag] * dx

So: ∂corr[i]/∂h[m] = dx * [1_{0≤m-lag<n} * (1-h[m-lag]) - 1_{0≤m+lag<n} * h[m+lag]]

This is correct.

∂F/∂h[m] = sum_i w_i * ∂corr[i]/∂h[m]

where w_i = softmax(T * corr[i]).

This can be computed as:
∂F/∂h[m] = dx * sum_i w_i * [1_{0≤m-lag_i<n} * (1-h[m-lag_i]) - 1_{0≤m+lag_i<n} * h[m+lag_i]]

This is a weighted sum over all lags, which is O(n^2) total (n lags × n components).

    h = project_feasible(h, target_sum)

    v_v = np.zeros(n)

    h = np.clip(h, 0.0, 1.0)
    s = np.sum(h)
    if abs(s - target_sum) < 1e-14:
        return h.copy()
    lo, hi = -1.0, 1.0

            lo = mid
        else:

def smooth_max_grad(h, dx, T):
    n = len(h)
    corr = np.correlate(h, 1.0 - h, mode='full') * dx
    m = np.max(corr)
    shifted = T * (corr - m)
    # Clip for numerical stability
    shifted = np.clip(shifted, -50, 50)
    exp_vals = np.exp(shifted)
    sum_exp = np.sum(exp_vals)
    weights = exp_vals / sum_exp
    value = m + np.log(sum_exp) / T

        else:

            grad[:n - nl] += w * dx * (1.0 - h[nl:])
            grad[nl:] += -w * dx * h[:-nl]
    
    return value, grad

    x_old = (np.arange(n_old) + 0.5) / n_old
    x_new = (np.arange(n_new) + 0.5) / n_new
    return np.interp(x_new, x_old, h)
