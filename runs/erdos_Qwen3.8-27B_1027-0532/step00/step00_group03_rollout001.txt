However, if we restrict to binary h (h ∈ {0,1}), then f_k(h) becomes linear (it's just counting (1,0) pairs). But we can't always achieve the constraint with pure binary values (for n=45, we need sum=22.5).

Let me try a hybrid approach:
1. Mostly binary values (0 or 1) with a few fractional values to satisfy the sum constraint
2. Optimize the binary pattern using combinatorial search
3. Fine-tune the fractional values

For the binary optimization, I can use:
- Local search: flip individual bits or swap pairs
- The objective is the maximum over all lags of the count of (1,0) pairs

This is reminiscent of the "sidon set" or "difference set" problems.

    active = corr * dx > threshold * c5

def subgradient_optimization(h, rng, n_iter=100, lr=0.1):
    n = len(h)
    dx = 2.0 / n
    h = h.copy()

        corr = np.correlate(h, 1 - h, mode="full") * dx
        active_idx = np.argmax(corr)
        lag = active_idx - (n - 1)

        grad = np.zeros(n)
        for j in range(n):

            if 0 <= jp < n:

            # h[j] appears as second factor (as (1-h[j])) in h[j-lag]*(1-h[j])
            jm = j - lag
            if 0 <= jm < n:

        deficit = n / 2.0 - h_new.sum()
        h_new += deficit / n
        h_new = np.clip(h_new, 0, 1)
        
        # Check if improved
        if compute_c5(h_new) < compute_c5(h):
            h = h_new
        else:
            lr *= 0.9  # Reduce learning rate
    
    return h

def compute_c5(h):
    n = len(h)

def ensure_constraint(h):
    n = len(h)
