c_k = ∑ h[n+k](1-h[n])

After the swap:
- h[i] changes from 1 to 0
- h[j] changes from 0 to 1

The change in c_k:
- Terms involving h[i]: 
  - As h[n+k] with n=i-k: old contribution = 1*(1-h[i-k]), new = 0*(1-h[i-k]) = 0. Change: -(1-h[i-k])
  - As h[n] with n=i: old contribution = h[i+k]*(1-1) = 0, new = h[i+k]*(1-0) = h[i+k]. Change: +h[i+k]
- Terms involving h[j]:
  - As h[n+k] with n=j-k: old contribution = 0*(1-h[j-k]) = 0, new = 1*(1-h[j-k]). Change: +(1-h[j-k])
  - As h[n] with n=j: old contribution = h[j+k]*(1-0) = h[j+k], new = h[j+k]*(1-1) = 0. Change: -h[j+k]

So Δc_k = [-(1-h[i-k]) + h[i+k]] + [(1-h[j-k]) - h[j+k]] (for valid indices)

This is O(1) per k, and at most 4 lags are affected (the ones where i or j participate). So computing the new max c_k after a swap is O(n) in the worst case (if we need to recompute the max), but typically much faster.

Actually, only the affected c_k values change. The unaffected ones stay the same. So the new max is max(new values for affected k, old max for unaffected k). If the old max was at an unaffected k, the new max is at least the old max. So we can quickly check: if the old max > the max of the new affected values, the new max is the old max (no improvement).

    ones = np.where(h > 0.5)[0]
    zeros = np.where(h < 0.5)[0]

    best_c5 = compute_c5(h, n, dx)
    
    for iteration in range(max_iter):
        improved = False
        corr = np.correlate(h, 1.0 - h, mode='full')
        max_c = np.max(corr)
        
        # Try all swaps
        best_swap = None
        best_min_max = max_c
        
        for i_idx in ones:
            for j_idx in zeros:
                # Compute Δc_k for affected lags
                # Affected k: those where i_idx or j_idx participates
                affected_ks = set()
                for pos in [i_idx, j_idx]:
                    for k in range(-(n-1), n):
                        if k == 0:
                            continue
                        if k >= 0:
                            if k <= pos or k <= n-1-pos:
                                affected_ks.add(k)
                        else:
                            m = -k
                            if pos <= n-1-m or pos >= m:
                                affected_ks.add(k)
                
                # For each affected k, compute new c_k
                new_max = 0.0
                for k in affected_ks:
                    # Old c_k
                    old_ck = corr[k + (n-1)]
                    # Delta
                    delta = 0.0
                    # i_idx: 1->0
                    # As h[n+k], n=i-k: -(1-h[i-k]) if valid
                    n1 = i_idx - k
                    if 0 <= n1 < n and max(0,-k) <= n1 <= min(n-1, n-1-k):
                        delta -= (1.0 - h[n1])  # old h[i] was 1, new is 0
                    # As h[n], n=i: +h[i+k] if valid
                    if 0 <= i_idx + k < n and max(0,-k) <= i_idx <= min(n-1, n-1-k):
                        delta += h[i_idx + k]
                    # j_idx: 0->1
                    # As h[n+k], n=j-k: +(1-h[j-k]) if valid
                    n2 = j_idx - k
                    if 0 <= n2 < n and max(0,-k) <= n2 <= min(n-1, n-1-k):
                        delta += (1.0 - h[n2])
                    # As h[n], n=j: -h[j+k] if valid
                    if 0 <= j_idx + k < n and max(0,-k) <= j_idx <= min(n-1, n-1-k):
                        delta -= h[j_idx + k]
                    
                    new_ck = old_ck + delta
                    if new_ck > new_max:
                        new_max = new_ck
                
                # Unaffected max
                if len(affected_ks) < 2*n-1:
                    affected_idx = [k + (n-1) for k in affected_ks]
                    mask = np.ones(2*n-1, dtype=bool)
                    mask[affected_idx] = False
                    unaffected_max = np.max(corr[mask])
                else:
                    unaffected_max = 0.0
                
                total_max = max(new_max, unaffected_max)
                if total_max < best_min_max - 1e-12:
                    best_min_max = total_max
                    best_swap = (i_idx, j_idx)

            h[i_idx] = 0.0
            h[j_idx] = 1.0
            improved = True
            best_c5 = compute_c5(h, n, dx)
        
        if not improved:
            break
    
    return h, best_c5
