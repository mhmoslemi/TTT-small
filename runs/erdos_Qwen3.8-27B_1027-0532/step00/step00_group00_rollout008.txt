f_smooth(h, β) = (1/β) * log(sum_k exp(β * corr(h, 1-h, k) * dx))

For large β, this approximates the max. For moderate β, it's smooth and can be optimized with gradient-based methods.

The gradient of corr(h, 1-h, k) with respect to h[i] is:
∂/∂h[i] [sum_n h[n+k] * (1-h[n])] = (1-h[i-k]) if i is a valid position for the first factor - h[i] if i is a valid position for the second factor

More precisely:
corr_k = sum_n h[n+k] * (1-h[n])
∂corr_k/∂h[i] = (1-h[i-k]) * 1[i-k is valid] + h[i+k] * (-1) * 1[i+k is valid]
= (1-h[i-k]) * 1[0 ≤ i-k ≤ N-1] - h[i+k] * 1[0 ≤ i+k ≤ N-1]

def smooth_objective(h, beta):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full") * dx
    # Log-sum-exp for numerical stability
    max_c = np.max(corr)
    return max_c + np.log(np.sum(np.exp(beta * (corr - max_c)))) / beta
