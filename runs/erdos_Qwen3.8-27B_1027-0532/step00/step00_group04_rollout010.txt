**Approach: Minimize the maximum using a "target" value**

Instead of directly minimizing the max, I can:
1. Set a target T
2. Check if there exists h such that corr_k(h) <= T/dx for all k

Actually wait, corr_k(h) = sum_i h[i] * (1-h[i+k]) = sum_i h[i] - sum_i h[i]*h[i+k]

The term sum_i h[i]*h[i+k] is the autocorrelation of h at lag k. This is a quadratic form.

So the constraint is: sum_i h[i] - (h^T Q_k h) <= T/dx for each k

where Q_k is a matrix with Q_k[i, i+k] = Q_k[i+k, i] = 1 (for the overlapping indices).

This is a QCQP (quadratically constrained quadratic program), which is non-convex.

However, the objective sum_i h[i]*(1-h[i+k]) = sum_i h[i] - h^T Q_k h is actually concave in h (since -h^T Q_k h is concave when Q_k is PSD, and Q_k here is a "band matrix" which is PSD).

Wait, is Q_k PSD? Q_k has 1s on the k-th diagonal and the (-k)-th diagonal. This is a (symmetric) circulant-like matrix. For a circulant matrix with first row [0, 0, ..., 1, 0, ..., 0, 1, 0, ..., 0] (1s at positions k and n-k), the eigenvalues are 2*cos(2πj*k/n) for j=0,...,n-1. These can be negative, so Q_k is NOT PSD in general.

So the function h^T Q_k h is indefinite, and sum_i h[i] - h^T Q_k h is neither convex nor concave in general.

This confirms the problem is genuinely non-convex.
