**Accelerated subgradient / FISTA:**
We can use Nesterov acceleration for f(x) = max_k c_k(x) (which is convex since it's the max of convex functions... wait, c_k is quadratic but not necessarily convex).

Actually, c_k(x) = sum_i x_i x_{k-i} is a quadratic form. Its Hessian is the (n×n) symmetric matrix H_k where (H_k)_{ij} = 1 if i+j = k (counting multiplicity). This is a "cross" matrix (anti-diagonal). The Hessian is NOT positive semidefinite in general (it has both positive and negative eigenvalues), so c_k is NOT convex!

This means the objective F(x) = max_k c_k(x) is NOT convex, and we can't use standard convex optimization techniques.

However, the subgradient method can still be applied (it's a non-convex problem). The convergence is not guaranteed, but in practice it might work well.

**Alternative: Direct nonlinear optimization**

Since we want to minimize 2n * max_k c_k(x) / S(x)^2 where S(x) = sum(x), we can:
1. Normalize: Let u = x / S(x), so sum(u) = 1.
2. Then minimize 2n * max_k c_k(u) (since S(u) = 1).
3. c_k(u) = sum_i u_i * u_{k-i}

This is a non-convex optimization problem with the constraint sum(u) = 1, u ≥ 0.

We could use scipy.optimize with L-BFGS-B, but we need to handle the max nicely. We can use a smooth approximation:
max_k c_k ≈ logsumexp(β * c_k) / β for large β.

Or we can use the "gradient at the argmax" approach directly.

The optimal value of the primal (max sum(g)) equals the optimal value of the dual (min M * sum(y)).

x_i ← x_i * exp(-η * g_i) / Z

where g is the subgradient and Z is a normalizing constant.

This is equivalent to:
x_i ← x_i * exp(-2η * x_{k*-i})

This is a multiplicative update that reduces the weight at positions i where x_{k*-i} is large. Intuitively, if the peak of the autocorrelation is at lag k*, then positions i that correlate with position k*-i (which has high value) should be reduced.

This is O(n) per iteration (plus the O(n log n) FFT for the convolution).
