**Alternative update using dual y:**

Given the dual solution y (from the greedy), the complementary slackness tells us:
- Support of b: {j : (A^T y)_j = 1} (tight dual constraints)
- Tight primal constraints: {k : y_k > 0}

On the support of b, we have (f*b)(k) = M for all k with y_k > 0.

This is a system of linear equations in b. If the support has size m, we have m unknowns and (number of tight primal constraints) equations. If these are independent, we can solve for b uniquely (up to the objective direction).

1. Solve dual greedily to get y
2. Identify the set S = {j : (A^T y)_j >= 1 - eps} (near-tight dual constraints)
3. Set b_j = 1/f[j] for j in S, b_j = 0 otherwise
4. Project: for each k with y_k > 0, if (f*b)(k) > M, scale down b_j for j contributing to position k

Instead of max_k c[k], use a smooth approximation like the log-sum-exp:
f(x) = (1/temperature) * log(sum_k exp(temperature * c[k]))

- c = autoconv(x): one FFT pair
- softmax_k = exp(temperature * c[k]) / sum: O(n)
- g = 2 * cross_correlate(softmax, x): one FFT pair
