This is a minimax problem. By Sion's minimax theorem (or von Neumann minimax), we can write:
min_f max_k (f*f)_k = max_{p in simplex} min_f max_k p_k * (f*f)_k

max_k (f*f)_k = max_{p >= 0, sum p = 1} sum_k p_k * (f*f)_k

So: min_f max_k (f*f)_k = min_f max_p sum_k p_k * (f*f)_k

By minimax: = max_p min_f sum_k p_k * (f*f)_k

For fixed p, the inner minimization is:

Wait, (f*f)_k = sum_i f_i * f_{k-i}. So sum_k p_k * (f*f)_k = sum_k p_k * sum_i f_i * f_{k-i} = sum_{i,j} f_i * f_j * p_{i+j}.

So the quadratic form has matrix Q[i,j] = p_{i+j}.

The minimization of f^T Q f subject to sum(f) = 1, f >= 0 is a non-convex problem (Q might not be positive semidefinite).

Let me try a different strategy: since the problem is scale-invariant and the key is to minimize the peak of the autocorrelation, let me use the following iterative method:

1. Start with f (normalized to sum=1).
2. Compute C = f * f (autocorrelation).
3. Compute the "target": we want C to be as flat as possible. The ideal is C_k = 1/(2n-1) for all k (uniform autocorrelation), but that's only achievable for certain sequences.
4. Update f to reduce the peak of C.

A practical method: "peak reduction" by modifying f.

If the peak is at k*, then to reduce C_{k*} = sum_i f_i * f_{k*-i}, we can reduce f at positions where f_i * f_{k*-i} is large. But we need to keep sum(f) = 1.

Idea: For each pair (i, k*-i), the product f_i * f_{k*-i} contributes to C_{k*}. To minimize the sum of products with fixed sum, we want to "balance" the products. By AM-GM, for a pair with f_i + f_{k*-i} = s, the product is maximized when f_i = f_{k*-i} = s/2.

So the strategy is: for pairs (i, k*-i) where one is much larger than the other, move mass from the larger to the smaller (while maintaining the sum of the pair).

This is like a "balancing" operation. Let me implement it:

```python
def balance_pairs(f, k_star, n, steps=100):
    """Balance pairs (i, k_star-i) to reduce their product sum."""
    f = f.copy()
    for step in range(steps):
        # Find the pair with the largest imbalance
        # Pair (i, k_star-i): both must be in [0, n-1]
        i_min = max(0, k_star - n + 1)
        i_max = min(n - 1, k_star)
        # Exclude i = k_star-i (i.e., i = k_star/2) as it's self-pairing
        pairs = []
        for i in range(i_min, i_max + 1):
            j = k_star - i
            if i != j and 0 <= j < n:
                pairs.append((i, j))
        
        # For each pair, the product is f[i]*f[j], and f[i]+f[j] is fixed.
        # To minimize product, make them equal: f[i] = f[j] = (f[i]+f[j])/2
        # But we should do this for the pair with the largest product (or largest imbalance).
        
        # Find max product pair
        if not pairs:
            break
        max_prod = 0
        max_pair = None
        for i, j in pairs:
            prod = f[i] * f[j]
            if prod > max_prod:
                max_prod = prod
                max_pair = (i, j)
        
        if max_pair is None:
            break
        i, j = max_pair
        # Balance: make them equal
        avg = (f[i] + f[j]) / 2
        f[i] = avg
        f[j] = avg
    
    return f
```
