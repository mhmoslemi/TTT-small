```python
            f = f * target_sum / np.sum(f)
            f_mean = np.mean(f)
            continue
        
        delta = eta * f_mean * grad_tan / gmax
        f_new = f - delta
        f_new = np.clip(f_new, 0, 1000)
        s_new = np.sum(f_new)
        if s_new < 0.01:
            eta *= 0.5
            stuck += 1
            continue
        f_new = f_new * target_sum / s_new
        
        new_s = fast_score(f_new)
        if new_s < cur:
            f = f_new
            f_mean = np.mean(f)
            stuck = 0
            eta = min(0.5, eta * 1.01)
        else:
            eta *= 0.85
            stuck += 1
            if stuck > 50:
                f += rng.normal(0, 0.01 * f_mean, n)
                f = np.clip(f, 0, 1000)
                f = f * target_sum / np.sum(f)
                f_mean = np.mean(f)
                eta = 0.1
                stuck = 0
    
    return best_f, best_s
```

This looks reasonable. Let me estimate the number of iterations:
- Each iteration: fft_conv (O(n log n)) + argmax (O(n)) + gradient (O(n)) + score (O(n)) ≈ 2 * n * log(n) ≈ 2 * 6962 * 13 ≈ 180,000 flops
- In Python (with numpy), this is probably 0.5-2ms per iteration
- In 1500 seconds: 750,000 to 3,000,000 iterations

That should be more than enough.

Now, the question is: will this actually find a solution better than 2.0? Let me think about it theoretically.

Starting from a uniform sequence with a small cosine perturbation f[j] ≈ 1 + ε*cos(2πj/n):
- The peak of f*f is at the center (k=n-1)
- The gradient at the center is grad[j] = f[n-1-j] ≈ 1 + ε*cos(2π(n-1-j)/n) ≈ 1 + ε*cos(2π - 2π/n - 2πj/n) ≈ 1 + ε*cos(2πj/n + 2π/n)

So the gradient is approximately 1 + ε*cos(2πj/n + 2π/n), which is a shifted cosine. After projection (subtracting mean), we get approximately ε*cos(2πj/n + 2π/n) (the DC term is removed).

The update is: f[j] -= η * ε * cos(2πj/n + 2π/n) (approximately)

So the new sequence is f[j] ≈ 1 + ε*cos(2πj/n) - η*ε*cos(2πj/n + 2π/n)

This is still a cosine (same frequency, slightly different phase and amplitude). The optimizer will keep updating the phase and amplitude of the first Fourier mode.

Will this reduce the peak? Let me think...

For f[j] = 1 + A*cos(2πj/n + φ), the autocorrelation is:
(f*f)[k] ≈ n + A²/2 * n * cos(2πk/n) + ... (for large n)

Wait, that's not right. Let me compute more carefully.

For f[j] = 1 + A*cos(2πj/n) (φ=0 for simplicity):
(f*f)[k] = Σ_{j valid} (1 + A*cos(2πj/n)) * (1 + A*cos(2π(k-j)/n))
= Σ_{j valid} [1 + A*cos(2πj/n) + A*cos(2π(k-j)/n) + A²*cos(2πj/n)*cos(2π(k-j)/n)]

The first term: Σ_{j valid} 1 = m_k (number of valid j's, which is min(k+1, n, 2n-1-k))
The second term: A * Σ cos(2πj/n) ≈ 0 for large n (sum of a full period of cosine)
The third term: A * Σ cos(2π(k-j)/n) = A * Σ cos(2πk/n - 2πj/n) ≈ 0 (similarly)
The fourth term: A² * Σ cos(2πj/n)*cos(2π(k-j)/n) = A²/2 * Σ [cos(2πk/n) + cos(4πj/n - 2πk/n)]
≈ A²/2 * m_k * cos(2πk/n) (the second term averages to 0 for large n)

So (f*f)[k] ≈ m_k + A²/2 * m_k * cos(2πk/n) = m_k * (1 + A²/2 * cos(2πk/n))

At k=0: (f*f)[0] = 1 * (1 + A²/2) = 1 + A²/2
At k=n-1: (f*f)[n-1] ≈ n * (1 + A²/2 * cos(2π(n-1)/n)) ≈ n * (1 + A²/2 * cos(2π - 2π/n)) ≈ n * (1 + A²/(2n))

Wait, cos(2π(n-1)/n) = cos(2π - 2π/n) = cos(2π/n) ≈ 1 - 2π²/n².

So (f*f)[n-1] ≈ n * (1 + A²/2 * (1 - 2π²/n²)) ≈ n + A²n/2 - A²π²/n

And (f*f)[0] = f[0]² = (1 + A)² = 1 + 2A + A²

For the peak to be at the center: n + A²n/2 > 1 + 2A + A², which is true for large n and small A.

Max(f*f) ≈ n + A²n/2 (at the center, approximately).
Sum(f) = n (approximately, since the integral of cosine over a period is 0).
Score ≈ 2n * (n + A²n/2) / n² = 2(1 + A²/2) = 2 + A².

So adding a cosine mode INCREASES the score! The uniform is a local minimum!

This is a crucial insight. The uniform sequence is not just a critical point but a LOCAL MINIMUM of the objective (at least among single Fourier mode perturbations).

This means that my gradient-based approach, starting from a slightly perturbed uniform, will actually INCREASE the score initially, and then the "if new_score < cur" check will reject the step, and eta will decrease.

So the gradient descent approach as I've formulated it won't work to improve on the uniform!

What do we need to do differently?

Option 1: Use a non-local perturbation (larger step) to jump to a different basin.
Option 2: Use a different objective function (e.g., minimize the sum of squares of f*f, which is convex).
Option 3: Use a different initialization that's already in a "good" basin.

Let me explore Option 2 first. Minimizing ||f*f||² (the L2 norm of the autocorrelation) is related to minimizing the energy of the autocorrelation. By Parseval's theorem:
||f*f||² = (1/(2π)) ∫ |F(ω)|⁴ dω (in the continuous case)

where F is the Fourier transform of f. Minimizing this is equivalent to making |F| as flat as possible, which means making f as "spread out" in frequency as possible. For a band-limited signal, this is related to the "prolate spheroidal wave function" (PSWF).

But we have the constraint f ≥ 0, which makes this non-trivial.

Actually, for non-negative f, the Fourier transform F(ω) = ∫ f(x) e^{-iωx} dx is a characteristic-function-like object. The constraint f ≥ 0 means that f is a probability density (up to scale), and F is its characteristic function.

Minimizing ||f*f||² is equivalent to minimizing ∫|F|⁴, which for a probability density is related to the "fourth moment" of the distribution. For a uniform distribution, ∫|F|⁴ is already quite small.

Hmm, I think the L2 approach might not help much either.
