## 1. Approach and Rationale

### Central Idea
We will develop a method for constructing coefficient sequences that minimize the AC1 upper bound, which is defined as `2*n*max(convolve(a, a)[sum(a)]^2`. The core insight is that this upper bound can be interpreted as the product of the maximum autocorrelation and a regularization parameter derived from the sequence's energy. To optimize effectively, we will employ a two-phase strategy: (1) a deterministic initialization based on block perturbations of the parent solution and (2) a greedy local search guided by projected conditional gradients.

### Rationale
The parent sequence with length 4806 serves as a strong reference point but likely does not achieve the target bound of 1.50274. Our method builds upon this by introducing non-trivial perturbations that modify specific blocks while preserving the overall structure. The local search phase ensures that these modifications improve the objective function. This approach combines structure-aware perturbations with optimization theory to find high-quality candidates efficiently.

### Key Limitations
1. The method operates solely in the "full" autocorrelation space (-n+1 to n-1) and does not consider circular convolution.
2. The integer constraint and clipping bounds impose ceilings on coefficient values.
3. The optimization landscape may not be convex, potentially leading to local optima.

### New Directions
1. For longer sequences, we will use sparse initialization to distribute candidate weights more effectively.
2. We may introduce a low-rank approximation strategy for substantially better sequences.

## 2. Mathematical Specification

### Variables and Representation
- **Dimension**: `n = 4806` (maintain parent sequence length)
- **Variables**:
  - `a ∈ R^n`: Coefficient vector with `0 ≤ a_i ≤ 1000`
  - `m ∈ Int`: Autocorrelation bound index where maximum occurs (found via `np.argmax(np.convolve(a, a)`)

### Objective Function
- AC1 upper bound: `f(a) := 2*n*max_k [sum_{i+j=k} a_i a_j] / (sum a)^2`
- Minimization: `min_{a} f(a)` subject to `0 ≤ a_i ≤ 1000`

def block_perturbation(base):
    n = len(base)
    width = max(1, min(n//50, 5))
    start = np.random.randint(0, n - width + 1)
    end = start + width
    segment = base[start:end]
    logamps = np.log(segment + 1e-6)
    new_segment = np.exp(logamps + np.random.normal(0, 0.15, len(logamps)))
    base[start:end] = new_segment
    return np.clip(base, 0, 1000)

def reflect_subset(base):
    if np.random.random() < 0.35:
        mid_idx = (len(base) + 1) // 2
        left = base[:mid_idx]
        right = base[mid_idx:]
        return 0.5*(left + left[::-1]) if len(left) == len(right) else None
