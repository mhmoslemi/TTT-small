**Alternative approach: Subgradient method without LP**

Since the subgradient has a simple structure (it's a reflected copy of a), I can implement the subgradient method directly without an LP:

1. Compute b = convolve(a, a)
2. Find all k where b[k] is close to max (within some tolerance)
3. Compute the subgradient as the average of the individual gradients for those k's
4. Take a step in the negative subgradient direction
5. Project back to a >= 0, sum(a) = 1

The subgradient for lag k is: `g_k[m] = 2*a[k-m]` if `0 <= k-m < n`, else 0.

This is cheap to compute (O(n) per lag, and we only need a few lags).

The problem is that the subgradient method converges slowly for non-smooth objectives. To improve, I can use:
- Averaging (use the average of past iterates)
- Polak-Ribiere step size
- Nesterov acceleration (though this is for smooth problems)

`= sum_k w_k * 2*a[k-m]` (with appropriate bounds)

1. Compute b = convolve(a, a) - O(n) with FFT

                        step = 0.05
                        flip = 1.0

            if it % 100 == 0:
                T = max(0.05, T * 0.995)

        return local_best, local_best_score

    remaining = deadline - time.monotonic()
    if remaining > 10:
        best, best_score = optimize(best, remaining * 0.6)

    remaining = deadline - time.monotonic()
    if remaining > 20:
        n_trials = min(int(remaining // 15), 30)
        for trial in range(n_trials):
            left = deadline - time.monotonic() - 5
            if left < 8:
                break
            t_limit = left / max(1, n_trials - trial)
            scale = rng.choice([0.1, 0.2, 0.4, 0.7])
            a_init = best * (1.0 + rng.normal(0, scale, n))
            a_init = np.maximum(a_init, 0)
            ss = a_init.sum()
            if ss < 1e-10:
                continue
            a_init /= ss
            c, s = optimize(a_init, t_limit)
            if s < best_score:
                best = c
                best_score = s

    # Polish: a few exact-subgradient steps on the best
    remaining = deadline - time.monotonic()
    if remaining > 2:
        a = best.copy()
        step = 0.01
        for _ in range(200):
            if time.monotonic() > deadline - 2:
                break
            b = fft_conv(a, a)
            k_star = b.argmax()
            g = np.zeros(n)
            valid = (k_star - np.arange(n) >= 0) & (k_star - np.arange(n) < n)
            g[valid] = 2.0 * a[k_star - np.arange(n)[valid]]
            a_new = a - step * g
            a_new = np.maximum(a_new, 0)
            ss = a_new.sum()
            if ss < 1e-10:
                break
            a_new /= ss
            sc = score_of(a_new)
            if sc < best_score:
                best = a_new.copy()
                best_score = sc
                a = a_new
            else:
                step *= 0.8

    # Final check with evaluator
    final_list = [float(x) for x in best]
    fs = evaluate_sequence(final_list)
    if not np.isfinite(fs):
        final_list = [float(x) for x in a0]
        evaluate_sequence(final_list)

    return final_list
