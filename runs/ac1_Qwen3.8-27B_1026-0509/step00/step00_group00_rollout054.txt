The problem is: minimize 2n * max(c) / s² where c = a*a (convolution), a >= 0, s = sum(a).

By scale invariance, set s = 1. Minimize 2n * max(c) subject to sum(a) = 1, a >= 0.

Equivalently, minimize max(c) subject to sum(a) = 1, a >= 0.

This is equivalent to: find the nonnegative vector a of length n, summing to 1, that minimizes the peak of its autocorrelation.

This is a well-studied problem in signal processing. For real-valued (signed) sequences, the minimum peak sidelobe is related to Barker sequences, Zadoff-Chu sequences, etc. For nonnegative sequences, it's a different and harder problem.
