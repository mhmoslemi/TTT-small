where (x*x)[k] is the k-th element of the linear convolution.

This is a non-convex problem (the objective is non-convex in x since it's bilinear). However, if we fix one variable, it becomes convex in the other.

This suggests an **alternating minimization** approach:
1. Fix x, minimize over g: this is the LP described above
2. Fix g, minimize over x: this is the same LP with roles swapped

Since the problem is symmetric in x and g (the objective is x*g), alternating between the two LPs should work.

But actually, this is exactly what the parent strategy describes! Let me implement it properly.

The key is to solve the LP efficiently. For n=4498 and a small active set, the LP should be fast.

            break
