Alternative approach: use the subgradient method or projected gradient descent.

The objective (with sum(f)=1 normalization) is g(f) = max_k (Cf)_k. This is convex. The subgradient at f is (C^T * 1_{argmax})(scaled). We can do:
1. Normalize f to sum 1
2. Compute conv = C*f
3. Find the argmax lags
4. Subgradient = C^T * (one-hot at argmax) / n (for the active constraints)
5. Update f = f - alpha * subgradient
6. Project onto {f: sum(f)=1, f>=0}
7. Repeat

The projection onto {sum(f)=1, f>=0} is the Euclidean projection onto the probability simplex, which has a well-known O(n log n) algorithm (water-filling).

C^T * v for a vector v of length 2n-1: this is the cross-correlation of v with a length-n ones vector. It can be computed via FFT in O(n log n).

This gives us an O(n log n) per iteration algorithm! With 1500 seconds, we can do many iterations.

```python
import numpy as np
from scipy.fftpack import fft, ifft

def convolve_full(f):
    """Compute full convolution of f with itself using FFT."""
    n = len(f)
    size = 2*n - 1
    fft_size = 1 << (size - 1).bit_length()  # next power of 2
    F = fft(f, fft_size)
    conv = np.real(ifft(F * F, fft_size))[:size]
    return conv

def convolve_T(v, n):
    """Compute C^T * v where C is the convolution matrix for length n."""
    size = 2*n - 1
    fft_size = 1 << (size - 1).bit_length()
    V = fft(v, fft_size)
    # C^T * v = cross-correlation of v with ones(n)
    ones = np.zeros(fft_size)
    ones[:n] = 1
    O = fft(ones, fft_size)
    result = np.real(ifft(V * np.conj(O), fft_size))
    # Actually, we need to be careful with the indexing
    # (Cf)[k] = sum_j f[j] * delta(k-j in [0,n-1])
    # (C^T v)[j] = sum_k v[k] * delta(j in [k-n+1, k])
    # = sum_k v[k] * delta(k in [j, j+n-1])
    # = sum_{k=j}^{j+n-1} v[k]
    # This is a sliding window sum!
    return result
```

Wait, actually (C^T v)[j] = sum_{k} C[k,j] v[k] = sum_{k: j in [k-n+1, k]} v[k] = sum_{k: k in [j, j+n-1]} v[k] (with k in [0, 2n-2]).

This is just a sliding window sum of v with window size n! We can compute this with a cumulative sum in O(n) time, no FFT needed!

```python
def convolve_T(v, n):
    """C^T * v: sliding window sum of v with window n."""
    size = 2*n - 1
    cs = np.concatenate([[0], np.cumsum(v)])
    result = np.zeros(n)
    for j in range(n):
        lo = j
        hi = min(j + n, size)
        result[j] = cs[hi] - cs[lo]
    return result
```

This is O(n) which is great!

1. Compute conv = C*f via FFT: O(n log n)
2. Compute softmax weights: w[k] = exp(lambda * conv[k]) / sum(exp(lambda * conv))
3. Compute gradient: grad = C^T * w via sliding window: O(n)
4. Update f: f -= alpha * grad
5. Project onto probability simplex: O(n log n)
6. Total: O(n log n) per iteration
