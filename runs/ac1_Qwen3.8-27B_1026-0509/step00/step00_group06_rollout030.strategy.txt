# 1. Approach and rationale
The central idea is to combine convex optimization and efficient search methods to minimize the AC1 bound \frac{2n \max_{k} (a * a)[k]}{(\sum a)^2}, where * denotes linear convolution (mode='full'). We start by solving a linear program (LP) that maximizes the sequence length subject to the convolution bound, then update the sequence in the direction that minimizes the AC1 bound. For large sequences (n=5582), we use FFT-based convolution and sparse representations to maintain efficiency.

The rationale is:
1. The LP embeds the optimization into a feasible space defined by the convolution
2. The update rule ensures progress toward minimizing the bound
3. Local search with structured perturbations explores promising regions
4. Early termination is built in for performance

This addresses the core bottleneck of directly solving the non-convex optimization by embedding it into iterative linear programs.

# 2. Mathematical specification
**Variables:**
- Let \(a = (a_0, \dots, a_{n-1})\) be the decision variables
- Let \(c = \text{convolve}(a, a)\) be the full-length convolution (length 2n-1)

**Problem formulation:**
Maximize \(\sum_{i=0}^{n-1} a_i\) subject to:
- \((a * a)[k] \leq \max(\text{convolve}(a_{\text{prev}}, a_{\text{prev}}))\) for all k
- \(0 \leq a_i \leq 1000\) for all i
- Sum condition: \(\sum_{i=0}^{n-1} a_i \geq 0.01\) (via evaluator)

**Update rule:** \(a_{\text{new}} = \gamma a + (1-\gamma) g\), where \(g\) is the LP solution

**Termination:** \(|\Gamma(a_{\text{new}}) - \Gamma(a)| < \epsilon\) or time limit
