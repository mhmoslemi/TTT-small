This is a "phase retrieval" problem with additional constraints, and it's generally not solvable in closed form.

**Approach: Directly optimize using scipy.optimize.minimize**

Define the objective:
f(a) = 2 * n * max(conv(a, a)) / (sum(a))^2

Use scipy.optimize.minimize with method='L-BFGS-B' or 'SLSQP'.

The issue is that f(a) is non-smooth (due to the max) and non-convex. But we can use the "smoothing" trick:
f_smooth(a) = 2n * softmax(conv(a,a) / tau) / (sum(a))^2

where softmax(x) = log(sum exp(x/tau)) * tau.

The gradient of f_smooth can be computed analytically.

But the smoothing parameter tau needs to be small for accuracy, which makes the gradient noisy.

Alternatively, I can use the "exact" max and its subgradient:
f(a) = 2n * c[k*] / (sum(a))^2 where k* = argmax(c).

The gradient (where the max is unique) is:
grad f = 2n * grad(c[k*]) / (sum(a))^2 - 2 * f(a) * grad(sum(a)) / sum(a)
= 2n * 2 * shift(a, k*) / (sum(a))^2 - 2 * f(a) * 1 / sum(a)

where shift(a, k)[j] = a[k-j] (with zero padding).

This is O(n) to compute (plus O(n^2) for the convolution to find k*).

Let me use this with a projected gradient method:
1. Compute gradient.
2. Step: a = a - eta * grad.
3. Project: a = max(a, 0), then scale to [0, 1000] (but we can work with sum=1 normalization).
4. Repeat.

The challenge is choosing eta. I'll use a backtracking line search.

def _gradient_step(a, eta):
    n = len(a)
    c = np.convolve(a, a)
    k_star = np.argmax(c)
    S = a.sum()
    
    # Gradient of 2n * c[k*] / S^2
    # = 2n * (2 * shift(a, k*)) / S^2 - 2 * (2n * c[k*] / S^2) * (1 / S) * 1
    # = 4n * shift(a, k*) / S^2 - 4n * c[k*] / S^3
    
    g = np.zeros(n)
    lo = max(0, k_star - n + 1)
    hi = min(n - 1, k_star)
    js = np.arange(lo, hi + 1)
    g[js] = 2 * a[k_star - js]
    
    grad = (4 * n * g - 4 * n * c[k_star] / S) / S * S  # let me redo this
    
    # Actually: f(a) = 2n * c[k*] / S^2
    # df/da[j] = 2n * dc[k*]/da[j] / S^2 + 2n * c[k*] * d(1/S^2)/da[j]
    # = 2n * 2*a[k*-j] / S^2 + 2n * c[k*] * (-2/S^3) * 1
    # = 4n*a[k*-j] / S^2 - 4n*c[k*] / S^3
    
    grad = 4 * n * g / S**2 - 4 * n * c[k_star] / S**3
    
    # But note: if k*-j is out of range, g[j] = 0, which is correct.
    
    # Line search
    best_a = a.copy()
    best_f = 2 * n * c[k_star] / S**2
    for alpha in [eta, eta/2, eta/4, eta/8, eta/16]:
        a_try = a - alpha * grad
        a_try = np.maximum(a_try, 0)
        if a_try.sum() < 1e-10:
            continue
        a_try = a_try / a_try.sum()  # renormalize
        c_try = np.convolve(a_try, a_try)
        f_try = 2 * n * c_try.max() / a_try.sum()**2  # = 2n * c_try.max() since sum=1
        if f_try < best_f:
            best_f = f_try
            best_a = a_try.copy()
    return best_a, best_f
