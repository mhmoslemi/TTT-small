```python
def project_simplex(v):
    """Project v onto the probability simplex."""
    n = len(v)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1
    ind = np.arange(1, n+1)
    cond = u * ind > cssv
    if not cond.any():
        return np.ones(n) / n
    rho = ind[np.argmax(cond)]
    tau = (cssv[np.argmax(cond)] + 1) / rho
    return np.maximum(v - tau, 0)
```

dF/dz_j = a_j * (g_j - sum_i g_i * a_i) = a_j * (g_j - <g, a>)

So the gradient w.r.t. z is: `a * (g - dot(g, a))`.

This is nice and simple! And the optimization in z is unconstrained (well, z can be any real vector, and a = softmax(z) is automatically in the interior of the simplex).

The downside is that softmax can be numerically unstable (overflow in exp). But we can handle this by subtracting the max: `softmax(z) = exp(z - max(z)) / sum(exp(z - max(z)))`.

Let me use this approach:

```python
def softmax(z):
    z = z - z.max()
    e = np.exp(z)
    return e / e.sum()

def softmax_grad(z, g):
    """dF/dz where F(a) and a = softmax(z), g = dF/da."""
    a = softmax(z)
    return a * (g - np.dot(g, a))
```

Now the optimization is unconstrained gradient descent (or L-BFGS) in z-space. This avoids the projection step entirely.

However, the softmax parameterization might make the optimization ill-conditioned when some a_j are very small (the gradient w.r.t. z_j is ~a_j * g_j, which is tiny when a_j is tiny). This means the optimizer might struggle to adjust very small components.

Alternative: use a "shifted softmax" or the "expNormalize" trick: a = (1 + exp(z)) / sum(1 + exp(z)). This keeps all components bounded away from 0 in a sense.

Or: just use the standard simplex projection approach with projected gradient descent. It's simpler and avoids the numerical issues of softmax.

        A = np.fft.rfft(a, n=L)
        return np.fft.irfft(A*A, n=L)[:2*n-1]

        S = a.sum()
        if S < 1e-10: return np.inf
        b = compute_b(a)
        return 2*n*b.max() / (S*S)
    
    def project_simplex(v):
        n = len(v)
        u = np.sort(v)[::-1]
        idx = np.arange(1, n+1, dtype=np.float64)
        cssv = np.cumsum(u) - 1
        cond = u > cssv / idx
        rho = int(np.sum(cond))
        if rho == 0:
            return np.ones(n) / n
        tau = cssv[rho-1] / rho
        return np.maximum(v - tau, 0)
    
    def smooth_obj_grad(a, p=4):
        """Compute gradient of sum(b^p) w.r.t. a."""
        b = compute_b(a)
        c = b**(p-1)
        # grad[i] = p * sum_k c[k] * (a[k-i] + a[i-k])
