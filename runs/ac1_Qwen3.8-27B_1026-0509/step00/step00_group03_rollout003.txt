To flatten the convolution, we want the middle values to be lower and/or edge values to be higher. But the edges are constrained: $a[0]^2 \leq M$ means $a[0] \leq \sqrt{M}$.

If we set $a[0] = a[n-1] = \sqrt{M}$, then the remaining $n-2$ elements must sum to $1 - 2\sqrt{M}$ (in the $\sum = 1$ normalization), and the middle constraint becomes:
$a[0]a[n-1] + \sum_{i=1}^{n-2} a[i]a[n-1-i] \leq M$
$\Rightarrow M + \sum_{i=1}^{n-2} a[i]a[n-1-i] \leq M$
$\Rightarrow \sum_{i=1}^{n-2} a[i]a[n-1-i] \leq 0$

Since all $a \geq 0$, this forces $a[i] = 0$ for $i = 1, \ldots, n-2$ (or $a[n-1-i] = 0$). But then $\sum a = 2\sqrt{M}$, and $M = (\sum a)^2/4 = 1/4$. So $f = 2n \cdot (1/4) = n/2$. That's terrible for large $n$.

So we can't push the edges too high. The optimal balance is somewhere in between.

Actually, solving the full LP might be slow. Let me use a subgradient step instead, which is $O(n \log n)$ per iteration:

**Subgradient method:**
1. Compute $c = a * a$ (FFT).
2. $g = a$ reversed and circularly shifted by $k^* = \arg\max c$.
   Specifically, $g_i = a[k^* - i]$ for valid $i$.
3. Update: $a_i \leftarrow a_i - \eta \cdot g_i$ (for all $i$), clip to 0, renormalize.

The step size $\eta$ should decrease over time. A good choice: $\eta_t = c_0 / t$ or $\eta_t = c_0 / \sqrt{t}$.

This gives $O(1/\sqrt{T})$ convergence, so after $T$ iterations, the gap is $O(1/\sqrt{T})$. For $T = 10^5$ iterations (feasible at $O(n \log n)$ each), the gap would be about $0.3\%$. Starting from $f = 2$, we'd get to about $f \approx 1.994$. Not great.

Let me also consider: what's the actual structure of the optimal solution?

For the problem $\min_{a \geq 0, \sum a = 1} \max_k (a*a)_k$, at the optimum, there should be multiple active constraints (multiple $k$ with $(a*a)_k = M$). This is because if only one $k$ were active, we could perturb $a$ to reduce the peak at $k$ while keeping other values below $M$.

The KKT conditions at the optimum:
- $\sum a_i = 1$, $a_i \geq 0$
- $(a*a)_k \leq M$ for all $k$, with complementary slackness
- $\nabla_i \max_k (a*a)_k - \lambda e_i \leq 0$ (where $\lambda$ is the dual of the sum constraint)
  - For active $k$, the gradient is $\sum_{k \in \text{active}} w_k a[k-i]$ (weighted by dual variables $w_k$)
  - So: $\sum_{k \in \text{active}} w_k a[k-i] = \lambda$ for $a_i > 0$

This means: at the optimum, the "weighted reverse-convolution" of the active peaks is constant on the support of $a$.

This is a strong structural condition. It suggests that the optimal $a$ has a fairly smooth shape (not spiky).

For a practical algorithm, let me go with:

**Algorithm:**

   c. Set $a \leftarrow a^*$ (or a convex combination).
3. Track best single-sequence score.
