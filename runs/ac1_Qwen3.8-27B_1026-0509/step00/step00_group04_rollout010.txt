```python
def fast_convolve(a):
    n = len(a)
    size = 2*n  # next power of 2
    fa = np.fft.rfft(a, size=size)
    b = np.fft.irfft(fa * fa, size=size)[:2*n-1]
    return b
```

Actually, the LP approach from the parent hint is:

- This is a linear program: max sum(g) s.t. (a*g)[k] <= M for all k, g >= 0
- The constraint matrix is the convolution of a (a Toeplitz-like matrix)
- Then update: a_new = (1-t)*a + t*g_normalized

The LP has n variables and 2n-1 constraints. For n=3809, that's 3809 variables and 7617 constraints. This is manageable with cvxpy and a modern solver.
