`G[i] = sum_j a[j] * w[(i+j) mod N_fft]`

With N_fft >= n + (2n-1) - 1 = 3n-2, there's no wrap-around for the linear part:
`G[i] = sum_{j=0}^{n-1} a[j] * w[i+j]` for i in [0, 2n-2] (since i+j < 3n-2 = N_fft for j < n and i < 2n-2).

So `g[i] = 2 * G[i]` for i in [0, n-1].

This works! And it's O(N_fft log N_fft) per iteration.

        best = parent / parent.sum()
    
    return [float(x) for x in best]
