Hmm, but I realize the single-peak gradient for a constant sequence gives ZERO gradient (as I showed earlier). So the noise is essential to break the symmetry.

Let me reconsider. For a constant sequence x[i] = c:
- conv[k] = (number of valid pairs) * c^2 (triangular)
- k* = n-1 (center), M = n*c^2
- grad[i] = x[n-1-i] = c for all i
- The update: x[i] -= lr*c + lr*M = x[i] - lr*(c + n*c^2)

Wait, I wrote: x[lo:hi+1] -= lr * grad_part and x[lo:hi+1] += lr * M.
So the net update is: x[i] += lr*(M - grad_part[i]) = lr*(M - c).

For the constant sequence: M = n*c^2 = n*(1/n)^2 = 1/n (since we normalized to sum=1, c=1/n).
Update: x[i] += lr*(1/n - 1/n) = 0.

So the gradient is indeed zero. The "add back M" was meant to center the step, but for a constant sequence, M = c (the average of the partner values), so the centered gradient is zero.

I need a different approach for the initial "kick" out of the constant sequence.

Ideas:
1. Initialize from non-constant (add structured noise).
2. Use the LSE gradient (which doesn't vanish at the constant sequence).
3. Use a different objective (e.g., minimize the variance of the convolution).

Let me go with option 2: LSE gradient. For the constant sequence:
- conv[k] = (n-|k-(n-1)|)/n^2 (triangular, with c=1/n)
- The LSE gradient at position i: 2 * sum_k w[k] * (1/n) where w is the softmax.
- = 2/n * sum_k w[k] * 1_{valid}
- For i=0: sum over k in [0, n-1] of w[k]
- For i=(n-1)/2: sum over k in [0, 2n-2] of w[k] = 1

So the gradient varies with i (larger at center, smaller at edges). This breaks the symmetry!

The update would be: x[i] -= lr * 2/n * (partial sum of w).
This decreases center values more than edge values, creating a U-shape.

To compute the LSE gradient efficiently, I need:
grad[i] = sum_{j=0}^{n-1} w[i+j] * x[j]

This is a cross-correlation. I can compute it via FFT:
- Pad x and w to appropriate length.
- Compute FFT of both.
- Pointwise multiply (with conjugate).
- Inverse FFT.

Let me work out the details:
- x has length n, w has length 2n-1.
- We want grad[i] = sum_{j=0}^{n-1} x[j] * w[i+j] for i = 0, ..., n-1.
- This is the cross-correlation of x and w at offset i.
- In terms of convolution: grad = ifft(fft(x_padded) * conj(fft(w_padded)))
- Padding: we need the linear cross-correlation, so pad to at least n + (2n-1) - 1 = 3n-2.
- Use FFT size ≥ 3n-2, say next power of 2.

For n=6962: 3n = 20886, next power of 2 = 32768. FFT of size 32768 is fast (~0.1ms).

So the LSE gradient computation is:
1. conv = np.convolve(x, x) [O(n log n) via FFT]
2. w = softmax(T * conv) [O(n)]
3. grad = cross_correlate(x, w) [O(n log n) via FFT]
4. Update x [O(n)]

Total per iteration: O(n log n) ≈ a few hundred microseconds. Very fast!
