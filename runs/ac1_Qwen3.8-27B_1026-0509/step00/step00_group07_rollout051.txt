And $\frac{\partial (a*a)[k]}{\partial a_j} = a_{k-j}$ (with $a_i = 0$ for $i < 0$ or $i \geq n$).

So the subgradient at component $j$ is: $\sum_{k \in K^*, 0 \leq k-j < n} a_{k-j}$.

This can be computed as: for each $k \in K^*$, add the "shifted" $a$ to the gradient. If $K^*$ has $r$ elements, this takes $O(rn)$ time.

The subgradient method:
1. $G_j = \sum_{k \in K^*} a_{k-j}$ (for valid indices)
2. $a_j \leftarrow a_j - \eta \cdot G_j$
3. Project onto $\{a \geq 0, \sum a = 1\}$ (which is: clip to 0, then rescale)
4. Repeat.

The projection onto $\{a \geq 0, \sum a = 1\}$:
- $b_j = \max(0, a_j - \tau)$ for some $\tau$ chosen so that $\sum b = 1$.
- This is a simple bisection on $\tau$.

This is $O(n)$ per iteration for the projection, and $O(|K^*| \cdot n)$ for the gradient.

The issue: the subgradient method is slow (convergence rate $O(1/\sqrt{t})$). And the number of iterations needed might be very large.

Let me think about a better approach.

**Approach: Extragradient / Mirror descent with entropy**

Since the constraint set is the simplex $\{a \geq 0, \sum a = 1\}$, we can use mirror descent with the negative entropy as the Bregman divergence. This gives the "exponential weights" update:

$a_j \leftarrow a_j \cdot \exp(-\eta \cdot G_j) / Z$

where $Z = \sum_k a_k \exp(-\eta \cdot G_k)$ is the partition function.

This is equivalent to a "soft" projection that naturally keeps $a \geq 0$ and $\sum a = 1$.

The gradient $G$ is the same subgradient as before.

This might converge faster than Euclidean projection.

```python
def build_conv_mat(f, n):
    """Build the (2n-1) x n convolution matrix C where C[k,j] = f[k-j] if valid."""
    # For offset d = k-j (0 to n-1):
    #   k = j + d, j = 0..n-1
    #   Row k ranges from d to d+n-1
    #   Col j ranges from 0 to n-1
    #   Value = f[d]
    all_rows = []
    all_cols = []
    all_vals = []
    for d in range(n):
        all_rows.append(np.arange(d, d+n))
        all_cols.append(np.arange(n))
        all_vals.append(f[d] * np.ones(n))
    return scipy.sparse.csr_matrix(
        (np.concatenate(all_vals), (np.concatenate(all_rows), np.concatenate(all_cols))),
        shape=(2*n-1, n)
    )
```
