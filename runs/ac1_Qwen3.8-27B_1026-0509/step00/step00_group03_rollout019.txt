The LP approach:
- Given current `f` with max convolution value `M`, find `g` that maximizes `sum(g)` subject to `g >= 0` and `(f*g)[k] <= M` for all k.
- This is a linear program with `n` variables and `2n-1` constraints.

Let me think about the implementation:
1. Start with uniform (or parent)
2. At each iteration:
   a. Compute M = max(f*f)
   b. Solve LP: max sum(g) s.t. (f*g) <= M, g >= 0
   c. Normalize g to have same sum as f
   d. Update f = (1-t)*f + t*g
   e. Repeat

The LP in step (b) has the constraint `(f*g)[k] = sum_i f[i]*g[k-i] <= M` for k=0..2n-2. This is a system of `2n-1` linear inequalities in `n` variables.
