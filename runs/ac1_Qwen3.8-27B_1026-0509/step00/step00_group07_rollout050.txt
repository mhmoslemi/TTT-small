This is great! We can do projected gradient descent:
1. Compute the full autocorrelation (2n-1 values)
2. Find the argmax j*
3. Compute gradient: g[m] = 2*a[j*-m] (clipped to valid range)
4. Update: a <- max(0, a - learning_rate * g)
5. Normalize: a <- a / sum(a) (to fix sum, though the score is scale-invariant)

But we want to minimize the max, and the max is at j*. The gradient points in the direction of increasing (a*a)[j*]. So we want to move in the direction that DECREASES (a*a)[j*], which is -g.

a <- max(0, a + lr * g) ? No, that increases (a*a)[j*].

We want: a <- max(0, a - lr * g) where g = ∇(a*a)[j*] = 2*shift(a, j*).

This decreases (a*a)[j*] but might increase other (a*a)[j] values.

def propose_candidate(seed=42, budget_s=1500, **kwargs):

    n = len(a)

    a = a / a.sum()

    best_score = evaluate_sequence(best_a.tolist())

    beta = 50.0  # will increase over time

    lr = 0.1

        if time.monotonic() > deadline:
            break
        
        # Compute autocorrelation via FFT
        size = 1 << (2*n - 1).bit_length()
        fa = np.fft.rfft(a, size)
        ac = np.fft.irfft(fa * np.conj(fa), size)[:2*n-1]
        ac = np.maximum(ac, 0)  # numerical issues
        
        # Smooth max
        # To avoid overflow, subtract max
        ac_max = ac.max()
        if ac_max > 0:
            shifted = beta * (ac - ac_max)
            log_sum_exp = np.log(np.sum(np.exp(shifted))) + beta * ac_max
            smooth_max = log_sum_exp / beta
            
            # Gradient of smooth max
            probs = np.exp(shifted) / np.sum(np.exp(shifted))
            grad_ac = probs  # d smooth_max / d ac[j]
            
            # Gradient w.r.t. a: sum_j grad_ac[j] * 2*shift(a, j)
            # For each j, the contribution to grad_a[m] is 2 * grad_ac[j] * a[j-m] (valid range)
            # This is 2 * (grad_ac * a) reversed... 
            # Actually: grad_a[m] = 2 * sum_j grad_ac[j] * a[j-m] (where 0<=j-m<n)
            # = 2 * (grad_ac convolve reversed_a)[n-1-m] ... hmm, this is getting complex
            
            # Simpler: just use the argmax gradient
            jstar = np.argmax(ac)
            # grad_a[m] = 2*a[jstar-m] for 0<=jstar-m<n, else 0
            lo = max(0, jstar - n + 1)
            hi = min(n, jstar + 1)
            grad_a = np.zeros(n)
            for m in range(lo, hi):
                jm = jstar - m
                if 0 <= jm < n:
                    grad_a[m] = 2 * a[jm]
        
        # Update
        a = np.maximum(0, a - lr * grad_a)
        if a.sum() < 1e-10:
            a = best_a.copy()
            continue
        a = a / a.sum()
        
        # Occasionally evaluate exact score
        if it % 100 == 0:
            score = evaluate_sequence(a.tolist())
            if np.isfinite(score) and score < best_score:
                best_score = score
                best_a = a.copy()
                lr *= 0.95  # reduce learning rate on improvement
        
        # Adapt learning rate

    # Final evaluation
