With $\eta = 0.01$ and gradient $\sim 1/\sqrt{n} \sim 0.013$, the step size in terms of the actual change is $\eta \cdot grad \sim 0.00013$, which is very small relative to $a_i \sim 1/n \sim 0.00018$. So the step changes each coordinate by about 70% of its value. That seems too large.

Let me use a smaller initial step size, like $\eta = 0.001$.

**Another important consideration: the "trap" of the uniform sequence.**

The uniform sequence is a local minimum of the $L^\infty$ objective (as we showed from the KKT conditions). So gradient-based methods starting from uniform will NOT escape! We need to either:
1. Start from a non-uniform initialization
2. Use a method that can escape local minima (like simulated annealing or random restarts)
3. Use a different objective that doesn't have the uniform sequence as a local minimum

For option 3: The $L^p$ objective for finite $p$ HAS the uniform sequence as a global minimum (as we showed for $p=2$). So that won't help either.

For option 2: We need to perturb the uniform sequence and hope the perturbation leads to a better region.

For option 1: What non-uniform initializations might be good?

For $n$ even, $n-1$ is odd, so $(-1)^{n-1-i} = -(-1)^i$.
$a_i a_{n-1-i} = \frac{(1+\epsilon(-1)^i)(1-\epsilon(-1)^i)}{n^2} = \frac{1-\epsilon^2}{n^2}$

The score would be $2n \cdot (1-\epsilon^2)/n = 2(1-\epsilon^2)$.

Wait, $n-1$ is odd (for even $n$). So $n-1-i$ has the opposite parity of $i$.

**What actually works?**

The key insight from the literature on autocorrelation minimization is that you need a more global structure. For binary sequences, this leads to Golay sequences, Barker sequences, etc. For real nonnegative sequences, the optimal structure is less clear.

One approach that might work: use a sequence that's concentrated at a few positions (sparse), so the autocorrelation has fewer peaks. But for nonnegative sequences, sparsity tends to increase the peak (concentration at one point gives $c_0 = a_0^2$ which is large).

**Better plan: Use the LP-based approach from the prior art, but more efficiently.**

The LP at each iteration solves:
maximize $\sum b_j$ subject to $b_j \geq 0$ and $\sum_j a_{k-j} b_j \leq M$ for all $k$.

The key insight: the constraint matrix is a convolution matrix. We can solve this LP using a **dual** approach or an **iterative** approach that exploits the structure.

The dual of this LP is:
minimize $M \cdot \sum_{k=0}^{2n-2} y_k$
subject to $\sum_{k=0}^{2n-2} a_{k-j} y_k \geq 1$ for all $j = 0, ..., n-1$
$y_k \geq 0$

This dual has $2n-1$ variables and $n$ constraints. The constraint matrix is the transpose of the primal constraint matrix (still a convolution structure).

For $n = 5582$: dual has 11163 variables and 5582 constraints. The constraint matrix (5582 × 11163) has about $n^2 = 31M$ nonzeros. This is large but might be feasible with a sparse LP solver.

Actually, wait. The dual constraint for variable $j$ is:
$\sum_k a_{k-j} y_k \geq 1$

where $a_{k-j}$ is nonzero only when $0 \leq k-j \leq n-1$, i.e., $j \leq k \leq j+n-1$.

So for each $j$, the constraint involves $y_k$ for $k \in [j, j+n-1]$ (intersected with $[0, 2n-2]$).

This is a "sliding window" structure. The constraint matrix is banded with bandwidth $n$. Total nonzeros: $n^2$ as before.

For a sparse LP solver like CBC or GLPK, 31M nonzeros might be too many. Let me think of alternatives.

**Alternating direction / projected subgradient for the LP:**

Instead of solving the LP exactly, use a few iterations of projected subgradient on the primal:
- Start with $b = a$ (or $b = 1/n$)
- For each constraint $k$ that is violated (i.e., $\sum_j a_{k-j} b_j > M$), project $b$ to satisfy it
- Repeat

This is like a Frank-Wolfe or projection-based approach.

Actually, a simpler approach: use the **multiplicative weights** method or **exponentiated gradient** for the LP.

For the primal LP: max $\sum b_j$ s.t. $A b \leq M \mathbf{1}$, $b \geq 0$.

Exponentiated gradient: $b_j \leftarrow b_j \cdot \exp(-\eta \cdot (\text{violation}_j))$

where $\text{violation}_j$ is the most violated constraint involving $b_j$.

This is getting complicated. Let me just go with a practical approach:

**Practical algorithm:**

1. Start with the parent sequence (normalized to sum 1)
2. Use **random restarts + local search**:
   a. Generate random perturbations of the current best
   b. For each perturbation, do a few steps of gradient descent (using the multi-peak subgradient)
   c. Keep the best result
3. Use a **smoothed max** (log-sum-exp) as a differentiable surrogate

Let me implement the log-sum-exp approach:

$f(a) = \frac{2n}{\beta} \log(\sum_k \exp(\beta c_k)) \approx 2n \cdot \max_k c_k$ for large $\beta$.

The gradient is:
$\nabla_i f = \frac{2n}{\beta} \cdot \frac{\sum_k \exp(\beta c_k) \cdot \partial c_k / \partial a_i}{\sum_k \exp(\beta c_k)}$
$= 2n \cdot \sum_k p_k \cdot a_{k-i}$

where $p_k = \exp(\beta c_k) / \sum_j \exp(\beta c_j)$ (Boltzmann distribution over the peaks).

For large $\beta$, $p_k$ is concentrated on the argmax. For small $\beta$, it's spread out.

Computing the gradient:
1. Compute $c = a \star a$ (1 FFT pair)
2. Compute $p_k = \text{softmax}(\beta c_k)$ ($O(n)$)
3. Compute $g_i = \sum_k p_k \cdot a_{k-i}$ (this is the cross-correlation of $p$ and $a$)

Step 3 can be done with FFT: $g = \text{IFFT}(\text{FFT}(p) \cdot \overline{\text{FFT}(a)})$

Total: 3 FFT operations per gradient step. Very fast!

The step size for this smoothed objective:
The Hessian is bounded by $2n \cdot \beta$ (roughly), so a safe step size is $\eta \sim 1/(2n\beta)$.

But actually, since we're projecting onto the simplex, the effective step size is more nuanced. Let me just use adaptive stepping.

        return np.fft.irfft(X * X, fft_n)[:2 * n - 1]

    def smooth_grad(a, beta):
        X = np.fft.rfft(a, fft_n)
        c = np.fft.irfft(X * X, fft_n)[:2 * n - 1]
        bc = beta * c - beta * c.max()
        exp_bc = np.exp(bc)
        p = exp_bc / exp_bc.sum()
        P = np.fft.rfft(p, fft_n)
        G = P * np.conj(X)
        g = np.fft.irfft(G, fft_n)[:n]
        return g, c

    eta = 0.05
    beta = 30.0
    no_improve = 0
    cooldown = 0

    it = 0
    while time.monotonic() < deadline - 20:
        it += 1
        if cooldown > 0:
            cooldown -= 1
            a = best_a.copy() if cooldown == 0 else a
            continue

        g, c = smooth_grad(a, beta)
        M = c.max()
        score = 2.0 * n * M

        if score < best_score - 1e-12:
            best_score = score
            best_a = a.copy()
            no_improve = 0

            no_improve += 1

        beta = min(beta * 1.03, 400.0)

        if s < 1e-15:
