**Alternative: Direct "peak shaving" via coordinate updates**

At each step:
1. Find the peak lag $k^*$
2. For each pair $(i, k^*-i)$ that contributes to the peak, reduce the "product" $a_i \cdot a_{k^*-i}$
3. This can be done by reducing the larger of the two (or both proportionally)

This is like a "water-filling" approach. But it's O(n) per step and might be slow to converge.

**Alternative: Use the structure of the problem**

The key observation: $(a*a)_k = \sum_{i=0}^{min(k, n-1)} a_i \cdot a_{k-i}$ (with $a_j = 0$ for $j < 0$ or $j \geq n$).

For the peak to be low, we need each $(a*a)_k$ to be approximately equal. This is a system of $2n-1$ quadratic equations in $n$ unknowns (with $n$ free parameters after normalization). It's overdetermined, so we can't satisfy all exactly, but we can minimize the max.

This is similar to the "prolate spheroidal wave function" or "slepian sequence" design problem.

**Practical approach: Iterative water-filling**

1. Initialize $a$ (e.g., uniform or from parent)
2. Compute $b = a*a$
3. For the peak lag $k^*$, compute the "excess": $e_i = a_i \cdot a_{k^*-i} - S^2/(2n-1)$ for each pair
4. Reduce $a_i$ and/or $a_{k^*-i}$ proportionally to the excess
5. Repeat

This is a form of alternating minimization.

Actually, I think the cleanest approach for this problem is:

**Iterative Proportional Fitting / Sinkhorn-like approach:**

The goal is to make $b_k \approx S^2/(2n-1)$ for all $k$. We can think of this as:
- We want $a$ such that the "quadratic form" $a^T T_k a = b_k$ is approximately constant for all $k$
- where $T_k$ is the "lag-k" matrix

This is like finding a vector $a$ that has approximately equal "energy" at all lags.

A practical algorithm:
1. Start with $a$ (initialized)
2. Compute $b = a*a$
3. Compute the "target": $t = S^2 / (2n-1)$
4. For lags where $b_k > t$, reduce the contributions
5. For lags where $b_k < t$, we can't directly increase (due to non-negativity)
6. The reduction at lag $k$: scale down $a_i$ for $i$ that contribute to lag $k$
