```python
def projected_subgradient_step(a, eta, n_active=50):
    n = len(a)
    S = a.sum()
    corr = np.convolve(a, a)
    M = corr.max()
    
    # Active set: lags where corr is close to M
    threshold = M * 0.99  # 99% of max
    active = np.where(corr >= threshold)[0]
    if len(active) == 0:
        active = np.argmax(corr)
        active = np.array([active])
    if len(active) > n_active:
        # Keep only the top n_active
        top_vals = np.sort(corr)[-n_active]
        threshold = top_vals[0]
        active = np.where(corr >= threshold)[0]
    
    # Compute subgradient
    g = np.zeros(n)
    for k in active:
        m_min = max(0, k - (n-1))
        m_max = min(n-1, k)
        g[m_min:m_max+1] += 2.0 * a[k - np.arange(m_min, m_max+1)]
    g /= len(active)
    
    # Take step
    a_prime = a - eta * g
    
    # Project onto {a >= 0, sum(a) = S}
    # Water-filling
    lo, hi = a_prime.min(), a_prime.max()
    for _ in range(50):
        mid = (lo + hi) / 2
        s = np.sum(np.maximum(a_prime - mid, 0))
        if s > S:
            lo = mid
        else:
            hi = mid
    tau = (lo + hi) / 2
    a_new = np.maximum(a_prime - tau, 0)
    # Renormalize to be exact
    a_new *= S / a_new.sum()
    
    return a_new
```

For $k = n-1$: $(a*a)_{n-1} = \sum_j a_j a_{n-1-j} = \sum_j a_j^2 = \|a\|_2^2$

For $k = 0$: $(a*a)_0 = a_0^2$
For $k = 2n-2$: $(a*a)_{2n-2} = a_{n-1}^2 = a_0^2$ (by symmetry)

So the autocorrelation is symmetric: $(a*a)_k = (a*a)_{2n-2-k}$.

This means the max is either at the center ($k = n-1$) or somewhere symmetric. For a palindromic sequence, the center value is $\|a\|_2^2$, and by Cauchy-Schwarz, $\|a\|_2^2 \geq S^2/n$. So the center value is at least $S^2/n$.

For the $1/\sqrt{j+1}$ sequence (which is NOT palindromic), the center value is $\sum_j a_j a_{n-1-j} = \sum_j \frac{1}{\sqrt{(j+1)(n-j)}} \approx \pi$.
