The optimal nonnegative solution for this is known to be related to the "prolate spheroidal wave function" in some contexts, but for the one-sided (linear) autocorrelation with non-negativity constraint, it's less clear.

Actually, let me reconsider the problem. The key variables are the 6733 coefficients. The objective is 2n * max(convolve(a,a)) / sum(a)². Since it's scale-invariant, fix sum(a) = 1 (or any constant) and minimize max(convolve(a,a)).

The subgradient of max_k (a^T T_k a) at a is 2 * T_{k*} * a where k* = argmax. T_{k*} * a is just a shifted/reversed copy of a (with zero-padding). Specifically:
(T_k * a)[j] = a[k-j] (with a[m] = 0 for m < 0 or m >= n).

So the subgradient direction is 2 * a_reversed_shifted[k*].

The projected subgradient method:
```
a = init (non-negative, sum=1)
for iter:
    c = convolve(a, a)  # O(n²) or O(n log n) with FFT
    k* = argmax(c)
    g[j] = 2 * a[k* - j] if 0 <= k* - j < n else 0
    # Also subtract the component in the sum(a) direction:
    g = g - (mean(g)) * ones  # to maintain sum
    a = a - lr * g
    a = max(a, 0)
    a = a / sum(a)
```

The step size lr should decrease: lr = c0 / sqrt(iter) or similar.

This will be slow but might work. The key challenge is that each iteration requires computing the full convolution (O(n²) = O(4.5 * 10^7) operations for n=6733, or O(n log n) with FFT).

With FFT: O(n log n) ≈ 6733 * 13 ≈ 87000 FFT operations per iteration. Very fast.
Without FFT: 6733² ≈ 45 million multiply-adds. Still fast in numpy.

Let me estimate: numpy convolve of two 6733-length arrays takes about 1-10ms. So we can do thousands of iterations in 1500s.
