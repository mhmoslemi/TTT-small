    col_idx = np.repeat(np.arange(n, dtype=np.int32), n)
    row_idx = (col_idx + np.remainder(np.arange(total, dtype=np.int32), n)).astype(np.int32)
    
    def lp_solve(f, tl=15):
        M = float(np.max(np.convolve(f, f)))
        if M < 1e-15:
            return None
        A = csr_matrix((np.tile(f, n), (row_idx, col_idx)), shape=(2*n-1, n))
        try:
            r = linprog(np.full(n, -1.0), A_ub=A, b_ub=np.full(2*n-1, M),
                       bounds=[(0, None)]*n, method='highs-ds',
                       options={'time_limit': tl})
        except Exception:
            return None
        if r.success and r.x is not None:
            g = np.maximum(np.asarray(r.x, dtype=np.float64), 0.0)
            sg = float(g.sum())
            if sg > 1e-12:
                return g / sg
        return None
    
    t = 0.3
    stall = 0
    
    while time.monotonic() < deadline - 10:
        f = best.copy()
        improved_this_round = False
        
        for _ in range(50):
            if time.monotonic() > deadline - 15:
                break
            g = lp_solve(f, tl=15)
            if g is None:
                break
            f_new = (1.0 - t) * f + t * g
            f_new = np.clip(f_new, 0.0, None)
            sn = float(f_new.sum())
            if sn < 1e-6:
                break
            f_new /= sn
            sc = float(evaluate_sequence(f_new.tolist()))
            if np.isfinite(sc) and sc < best_score:
                best = f_new.copy()
                best_score = sc
                improved_this_round = True
                stall = 0
            else:
                stall += 1
            f = f_new
            if stall > 40:
                break
        
        if not improved_this_round and stall > 20:
            # Perturb to escape local optimum
            best = best * (1.0 + 0.2 * rng.standard_normal(n))
            best = np.clip(best, 0.0, None)
            sb = best.sum()
            if sb > 1e-6:
                best /= sb
            else:
                best = np.ones(n) / n
            best_score = float(evaluate_sequence(best.tolist()))
            if not np.isfinite(best_score):
                best = f0.copy()
                best_score = float(evaluate_sequence(best.tolist()))
            stall = 0
            t = 0.4
        else:
            t = max(0.05, t * 0.95)
    
    out = [float(x) for x in best]
    sc = evaluate_sequence(out)
    if not np.isfinite(sc):
        return [1.0]
    return out

Hmm wait, there's a subtle issue. When I do `best = best * (1.0 + 0.2 * rng.standard_normal(n))`, this can create negative values (which I clip to 0) and can significantly change the sum. I then renormalize to sum=1. This should be fine.

But there's another issue: the `evaluate_sequence` function clips to [0, 1000]. Since I'm working in normalized form (sum=1, max value <= 1), the upper clip at 1000 never activates. Good.

Let me also think about whether the LP is actually improving things. Let me trace through one iteration:

1. f = uniform (each entry = 1/n). M = max(conv(f,f)) = 1/n.
2. LP: maximize sum(g) s.t. conv(f, g) <= 1/n, g >= 0.
   conv(f, g)[k] = (1/n) * (sum of g entries in window of size min(k+1, n, 2n-1-k)) <= 1/n.
   So: sum of g entries in each window <= 1.
   The tightest constraint is the full window (center): sum(g) <= 1.
   LP optimum: sum(g) = 1. Many solutions.
3. Solver returns some g with sum = 1. It might be uniform (g = f) or something else.
4. Blend: f_new = 0.7*f + 0.3*g. If g = f, no change. If g != f, some change.

The issue is step 3: the LP has many optimal solutions when f is uniform. The solver's choice is arbitrary. This is the degeneracy problem.

To avoid this, I should start from a non-uniform f. Let me add a small perturbation to the initial f:

```python
f0 = f0 + 0.01 * rng.standard_normal(n)
f0 = np.clip(f0, 0, None)
f0 = f0 / f0.sum()
```

This breaks the degeneracy and gives the LP a unique (or at least well-defined) solution.

Actually, even better: I can add a small perturbation to the LP objective to break ties. E.g., maximize sum(g) - epsilon * sum(g*f) (or some other tie-breaking term). But this changes the LP slightly. Let me just perturb the initial f.

Let me also consider: what if I use a different LP formulation? Instead of maximizing sum(g), I could minimize the variance of conv(g,g) (a quadratic objective). But that's QP, not LP. Let me stick with LP.

Another idea: instead of the LP from the strategy, I could directly minimize the peak using a bisection + LP feasibility:
- Binary search on M_target.
- For each M_target, check: exists g >= 0, sum(g) = 1, conv(g,g) <= M_target?
- But conv(g,g) <= M_target is a QUADRATIC constraint, not linear. So this doesn't work as an LP.

The LP approach (linearizing around f) is the right one for this problem.
