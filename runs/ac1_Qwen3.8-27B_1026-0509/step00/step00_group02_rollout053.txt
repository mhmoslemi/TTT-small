= -4n * T / S^3   (when m-j not in [0,n-1], i.e., derivative of T is 0)

Wait, d/df[j] S = 1 for all j.

dB/df[j] = 2n * ( (d/df[j] T) / S^2 - T * 2 / S^3 )
= 2n * (2*f[m-j] / S^2 - 2T/S^3)   (when 0<=m-j<n)
= 4n * (f[m-j] - T/S) / S^2

For descent, we want to decrease B. So we move f[j] in the direction -dB/df[j].

If f[m-j] < T/S: dB/df[j] < 0, so increasing f[j] decreases B.
If f[m-j] > T/S: dB/df[j] > 0, so decreasing f[j] decreases B.

This makes sense! T/S is the "average" value of f weighted by the convolution structure. We want to increase f at positions where f[m-j] is small (relative to average) and decrease where it's large.

But this is only the gradient at the argmax. The true gradient involves the max, which is non-smooth. We'd need to handle that.

For a practical approach, I'll use a combination of:
1. Gradient descent on the active peak (with smoothing over top few peaks)
2. Random perturbations to escape local minima
3. Periodic global moves

Let me design the algorithm:

```python
import numpy as np
import time

def propose_candidate(seed=42, budget_s=1500, **kwargs):
    rng = np.random.default_rng(seed)
    t0 = time.monotonic()
    deadline = t0 + budget_s - 5.0  # 5s headroom
    
    # Initialize
    parent = np.clip(np.asarray(height_sequence_1, dtype=np.float64), 0, 1000)
    n = parent.size
    if n == 0 or not np.isfinite(parent).all():
        parent = np.ones(256)
        n = 256
    
    # Normalize to sum = sqrt(2n)
    s = parent.sum()
    if s < 1e-10:
        parent = np.ones(n)
        s = n
    f = parent * np.sqrt(2*n) / s
    
    def score(x):
        s = x.sum()
        if s < 0.01:
            return np.inf
        conv = np.convolve(x, x)
        return float(2 * n * conv.max() / s**2)
    
    best = f.copy()
    best_score = score(best)
    
    while time.monotonic() < deadline:
        # Compute convolution and find peaks
        conv = np.convolve(best, best)
        peak = conv.max()
        sum_f = best.sum()
        
        # Find indices where conv is close to peak
        threshold = peak * 0.99
        active = np.where(conv >= threshold)[0]
        
        # Gradient direction: for each peak index m, 
        # d/d f[j] (f*f)[m] = 2*f[m-j] for valid m-j
        # We want to decrease the peak: increase f[j] where f[m-j] < peak/sum_f
        # and decrease where f[m-j] > peak/sum_f
        
        # Simplified: compute "pressure" on each f[j]
        pressure = np.zeros(n)
        for m in active:
            j_start = max(0, m - (n-1))
            j_end = min(n-1, m)
            if j_start <= j_end:
                idx = j_start + np.arange(j_end - j_start + 1)
                partner_idx = m - idx
                pressure[idx] -= 2 * best[partner_idx]  # negative = increase f[j]
                pressure[idx] -= 2 * best[partner_idx]  # from other term
                # Wait, I computed d/dbest[j] (f*f)[m] = 2*best[m-j]
                # To decrease the peak, we want to move in -gradient direction
                # -gradient means: -2*best[m-j], so we add -2*best[m-j] to the update
        
        # Actually, let me think about this more carefully.
        # We want to minimize the peak. The steepest descent direction for the objective
        # at the peak is: df[j] = -grad_B[j] * step
        # where grad_B[j] = 4n(f[m-j] - T/S)/S^2 for the active peak m
        
        # So df[j] is proportional to -(f[m-j] - T/S) = T/S - f[m-j]
        # For multiple active peaks, sum over them.
        
        # T/S is the "average"
        avg = peak / sum_f  # approx T/S
        
        # Update direction: for active peaks, move f in direction (avg - f[m-j])
        # This means: increase f[j] where its partner f[m-j] is below average, decrease where above
        
        direction = np.zeros(n)
        for m in active[:20]:  # limit to top 20 peaks
            j_start = max(0, m - (n-1))
            j_end = min(n-1, m)
            if j_start <= j_end:
                idx = np.arange(j_start, j_end + 1)
                partner = m - idx
                direction[idx] += (avg - best[partner])
        
        # Normalize direction
        dir_norm = np.linalg.norm(direction)
        if dir_norm > 1e-10:
            direction /= dir_norm
        
        # Add random component
        noise = rng.standard_normal(n) * 0.1
        direction = direction + noise
        
        # Line search: try several step sizes
        best_local = best.copy()
        best_local_score = best_score
        for step in [0.01, 0.005, 0.002, 0.001, 0.05]:
            candidate = best + step * direction
            candidate = np.clip(candidate, 0, 1000)
            sc = score(candidate)
            if np.isfinite(sc) and sc < best_local_score:
                best_local = candidate.copy()
                best_local_score = sc
        
        if best_local_score < best_score:
            best = best_local
            best_score = best_local_score
        else:
            # Random perturbation as fallback
            for step in [0.05, 0.1, 0.2]:
                candidate = best + step * rng.standard_normal(n)
                candidate = np.clip(candidate, 0, 1000)
                sc = score(candidate)
                if np.isfinite(sc) and sc < best_score:
                    best = candidate
                    best_score = sc
                    break
        
        # Check time
        if time.monotonic() > deadline:
            break
    
    # Final validation
    final_score = score(best)
    if not np.isfinite(final_score):
        # Fallback
        return [1.0] * 256
    
    return [float(x) for x in best]
```

Let me reformulate. For the linear convolution (f*f)[m] = sum_i f[i]f[m-i], the "unwrapped" derivative is:
- For m in [0, n-1]: d/d f[j] = 2*f[m-j] for j in [0, m]
- For m in [n, 2n-2]: d/d f[j] = 2*f[m-j] for j in [m-n+1, n-1]

So the gradient vector for peak m is: a length-n vector where entry j is 2*f[m-j] if 0 <= m-j < n, else 0.

This is just a shifted (and possibly truncated) version of f (reversed). We can compute it efficiently.

```python
                tilt = 1.0 + a * (2.0 * xvec / n - 1.0) + b * np.sin(2 * np.pi * xvec / n)
                cand = best * tilt
                cand = np.clip(cand, 0, None)
                if cand.sum() > 1e-10:
                    cand /= cand.sum()
                    sc = obj(cand)
                    if sc < best_score:
                        best = cand.copy()
                        best_score = sc
                        scrambled = True
                        break
            if not scrambled and stall > 120:
                # Complete reset to a fresh random shape
                kind = rng.integers(4)
                if kind == 0:
                    best = (xvec + 1) / (xvec + 1).sum()
                elif kind == 1:
                    x = np.linspace(0, 1, n)
                    best = np.exp(-rng.uniform(1, 4) * x)
                    best /= best.sum()
                elif kind == 2:
                    half = n // 2
                    best[:half] = 1.0
                    best[half:] = rng.uniform(0.1, 0.8)
                    best /= best.sum()
                else:
                    x = np.linspace(0, 1, n)
                    best = np.cos(np.pi * x / 2.0) ** rng.uniform(1, 5)
                    best /= best.sum()
                best_score = obj(best)

        if time.monotonic() > deadline:
            break

    # Final validation with exact evaluator
    best = np.clip(best, 0, 1000)
    result = [float(v) for v in best]
    ev_best = evaluate_sequence(result)

    parent_list = [float(v) for v in parent]
    ev_parent = evaluate_sequence(parent_list)

    if np.isfinite(ev_best) and (not np.isfinite(ev_parent) or ev_best < ev_parent):
        return result
    if np.isfinite(ev_parent):
        return parent_list
    return [1.0] * 256
```
