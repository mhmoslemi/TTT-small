- In the frequency domain: C(f) = G(f)^2 (where G is the DFT of g).
- If we want c to be flat, we want G(f)^2 to be flat, i.e., |G(f)| to be constant.
- But G(f)^2 is complex in general (since G is complex), so "flat" in the real sense means both Re(G^2) and Im(G^2) are constant.
- Re(G^2) + j*Im(G^2) = |G|^2 * exp(2j*angle(G))
- For this to be constant (real, positive), we need |G| constant AND angle(G) = 0 or pi (i.e., G real).
- But G is the DFT of a real sequence, so G(n-k) = conj(G(k)). G being real means g is symmetric.
- For a symmetric real sequence with flat DFT magnitude: this is a Zadoff-Chu-like sequence or a Barker sequence (for small n).

Actually, I'm overcomplicating this. The DFT of a real sequence has conjugate symmetry, so G(k) = conj(G(n-k)). For G^2 to be real and positive, we need G(k)^2 real and positive, i.e., G(k) real (G(k) = ±|G(k)|). This means g is symmetric (g[i] = g[n-1-i]).

For a symmetric sequence with flat |G|: this is like a "perfect" binary sequence, which doesn't exist for most n. For real-valued, we can get closer.

Practical approach: use the Fourier domain to iteratively flatten the convolution.

Let me also think about the LP more carefully. The LP constraint matrix A has a special structure: it's a "convolution matrix" (Toeplitz-like). For the matrix:
A[k, j] = g[k-j] if 0 <= k-j < n, else 0.

This is a (2n-1) x n matrix where each column j has g at rows j, j+1, ..., j+n-1. So it's a "banded" matrix with band width n.

For the LP: max 1^T g' s.t. A g' <= M * 1, g' >= 0.

The dual: min M * 1^T y s.t. A^T y >= 1, y >= 0.
A^T y has entries: (A^T y)[j] = sum_k A[k,j] * y[k] = sum_k g[k-j] * y[k] (for valid k) = (g*y)[j] (with appropriate bounds).

So the dual is: min M * sum(y) s.t. (g*y)[j] >= 1 for all j, y >= 0.

This is also a structured problem! The constraint (g*y)[j] >= 1 involves a convolution.

For a near-uniform g (g ≈ 1/n), the constraint becomes: (1/n * y)[j] >= 1, i.e., y convolved with ones >= n. The minimum sum(y) subject to this... it's related to the "covering" problem.

        if sc < best_score:

            best_score = sc
            g = g_init
            cur_score = sc
