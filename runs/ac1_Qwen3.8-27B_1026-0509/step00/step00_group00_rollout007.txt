The score is 2n * max(c) / (sum a)². Let me define the "normalized" sequence p_i = a_i / sum(a). Then sum(p) = 1 and score = 2n * max(c_p) where c_p = p * p (full linear convolution).

So we want to minimize max_k (p*p)[k] where p >= 0, sum p = 1.

For uniform p (p_i = 1/n): max(p*p) = n/n² = 1/n. Score = 2n*(1/n) = 2.

For p = [1/n, 1/n, ..., 1/n] concentrated on m < n elements: max(p*p) = m/m² = 1/m > 1/n. Score = 2n/m > 2.

The question is: can max(p*p) be less than 1/n?

(p*p)[k] = sum_i p_i p_{k-i}. The sum over all k: sum_k (p*p)[k] = (sum p)² = 1. There are 2n-1 values. So the AVERAGE is 1/(2n-1) < 1/n. But the max is >= the average.

Can the max be less than 1/n? That would require all (p*p)[k] < 1/n. In particular, (p*p)[n-1] = sum_i p_i p_{n-1-i} < 1/n.

By Cauchy-Schwarz: (sum_i p_i p_{n-1-i})² <= (sum_i p_i²)(sum_i p_{n-1-i}²) = (sum_i p_i²)².
So (p*p)[n-1] <= sum p_i².

Also, (p*p)[0] = p_0² and (p*p)[2n-2] = p_{n-1}².
