def simplex_project(v, s=1.0):
    """Project v onto the simplex {x: sum(x)=s, x>=0}."""
    n = len(v)
    # Scale to target sum
    u = v / (s / np.sum(v)) if np.sum(v) > 0 else v
    # Actually, let's just project onto {x: sum x = s, x >= 0}
    # Standard algorithm:

$\nabla S = \sum_{k \in K^*} \lambda_k \cdot \text{shift\_reverse}(x, k)$

where $K^*$ is the set of indices achieving the max, and $\lambda_k \geq 0, \sum \lambda_k = 1$.

$\nabla \tilde{S}_j = 2 \sum_k p_k \cdot x_{k-j}$

where $p_k = e^{\beta (x*x)_k} / \sum_l e^{\beta (x*x)_l}$.

For large $\beta$, this concentrates on the max positions, recovering the subgradient.

This is a smooth approximation that's easy to compute!
