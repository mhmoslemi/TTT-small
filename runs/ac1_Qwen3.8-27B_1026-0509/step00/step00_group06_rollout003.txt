**Approach: Use the "smoothing" trick + BFGS or L-BFGS.**

Replace max_k conv[k] with log-sum-exp: L_τ(a) = τ * log(sum_k exp(conv[k]/τ)).

As τ -> 0, this approaches max. For large τ, it's smooth.

The gradient of L_τ is:
∂L_τ/∂a[j] = sum_k p_k * ∂conv[k]/∂a[j]
where p_k = exp(conv[k]/τ) / sum_l exp(conv[l]/τ)

And ∂conv[k]/∂a[j] = 2*a[k-j] (if 0<=k-j<n else 0).

So ∂L_τ/∂a[j] = 2 * sum_k p_k * a[k-j] * indicator(0<=k-j<n)
= 2 * sum_i a[i] * p_{j+i} * indicator(0<=j+i<2n-1)  [substituting i=k-j]

This is a "weighted convolution" of a with the weights p_k.

We can compute this efficiently using FFT if p_k is smooth, but for general p_k we need O(n²). For n=5582, that's 31M operations, which is about 1-2 ms in numpy.

So the gradient computation per iteration is O(n²) ≈ 31M ops. With L-BFGS doing maybe 100 iterations, that's 3G ops, about 1-2 seconds total. Very feasible!

But L-BFGS doesn't handle the a>=0 and sum(a)=1 constraints directly. We can:
- Use a change of variables: a[j] = exp(x[j]) / sum(exp(x)) (softmax parameterization). This automatically satisfies a>0 and sum(a)=1.
- Optimize over x using L-BFGS.

The softmax parameterization: a = softmax(x). Then:
∂a[j]/∂x[i] = a[j](δ_{ij} - a[i])

And the gradient w.r.t. x:
∂L/∂x[i] = sum_j (∂L/∂a[j]) * (∂a[j]/∂x[i])
= sum_j g[j] * a[j] * (δ_{ij} - a[i])
= g[i]*a[i] - a[i]*sum_j g[j]*a[j]
= a[i] * (g[i] - sum_j g[j]*a[j])

where g = ∂L/∂a.

This is clean! The gradient w.r.t. x is a[i] * (g[i] - mean_weighted).
