Then b_v[n-1] = sum_j v[j]*v[n-1-j] = sum_j (j-(n-1)/2)*((n-1-j)-(n-1)/2) = sum_j (j-c)*(c-j) where c=(n-1)/2 = -sum_j (j-c)^2 < 0.

So a linear ramp perturbation should reduce the center peak!

Let me compute the resulting score. a[i] = 1 + ε*(2i/(n-1) - 1). For small ε:
- a is nonnegative if |ε| < 1 (roughly)
- sum a = n (since the perturbation sums to 0)
- b[n-1] ≈ n - ε^2 * (n-1)^3/3 (approximately, the "variance" of the ramp)
- b[0] = a[0]^2 = (1-ε)^2 ≈ 1 - 2ε
- b[2n-2] = a[n-1]^2 = (1+ε)^2 ≈ 1 + 2ε

Wait, for the ramp v[i] = 2i/(n-1) - 1:
v[0] = -1, v[n-1] = 1.
a[0] = 1-ε, a[n-1] = 1+ε.
b[0] = (1-ε)^2 = 1-2ε+ε^2
b[2n-2] = (1+ε)^2 = 1+2ε+ε^2

The max of b is at the center: b[n-1]. Let me compute it:
b[n-1] = sum_{i=0}^{n-1} a[i]*a[n-1-i]
= sum_{i=0}^{n-1} (1+ε*(2i/(n-1)-1)) * (1+ε*(2(n-1-i)/(n-1)-1))
= sum_{i=0}^{n-1} (1+ε*v[i])*(1+ε*v[n-1-i])
where v[i] = 2i/(n-1)-1, so v[n-1-i] = 2(n-1-i)/(n-1)-1 = 1-2i/(n-1) = -v[i].

So b[n-1] = sum (1+ε*v[i])*(1-ε*v[i]) = sum (1-ε^2*v[i]^2) = n - ε^2*sum v[i]^2.

sum v[i]^2 = sum (2i/(n-1)-1)^2 = (1/(n-1)^2) * sum (2i-(n-1))^2
= (1/(n-1)^2) * sum_{j=-(n-1)/2}^{(n-1)/2} (2j)^2  [reindexing]
≈ (1/(n-1)^2) * 4 * sum_{j=1}^{(n-1)/2} j^2 * 2 (by symmetry)
≈ (4/(n-1)^2) * (n-1)^3/3
= 4(n-1)/3 ≈ 4n/3

So b[n-1] ≈ n - ε^2 * 4n/3 = n(1 - 4ε^2/3).

The score = 2n * max_b / S^2 ≈ 2n * n(1-4ε^2/3) / n^2 = 2(1-4ε^2/3) = 2 - 8ε^2/3.

For ε = 0.1: score ≈ 2 - 8*0.01/3 = 2 - 0.0267 = 1.973.
For ε = 0.3: score ≈ 2 - 8*0.09/3 = 2 - 0.24 = 1.76.
For ε = 0.5: score ≈ 2 - 8*0.25/3 = 2 - 0.667 = 1.333.
