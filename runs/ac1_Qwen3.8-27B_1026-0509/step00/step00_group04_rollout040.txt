```python
def project_simplex(v, s=1.0):
    """Project v onto {x >= 0, sum(x) = s}"""
    n = len(v)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.nonzero(u * np.arange(1, n+1) > (cssv - s))[0][-1]
    theta = (cssv[rho] - s) / (rho + 1.0)
    return np.maximum(v - theta, 0)
```

For k = n-1 (center): valid j is 0 to n-1, so `sum_j u_j = 0` and `sum_j u_{n-1-j} = 0`. First-order change is 0. ✓ (symmetric point)

For k = 0: only j=0, so `sum = u_0 + u_0 = 2*u_0`. First-order change is `2*eps*u_0/n^2`.

So by choosing u_0 < 0, we can decrease `(a*a)_0`. But `(a*a)_{n-1}` doesn't change to first order. And other lags change too.

The key question: is there a direction u (with sum=0) that decreases ALL the autocorrelation values simultaneously? If not, the uniform point is a local minimum.

For the max to decrease, we need ALL `(a*a)_k` to decrease (or at least the ones that are at the max). At the uniform point, only k=n-1 is at the max (value 1/n). All others are strictly smaller.

So we only need to decrease `(a*a)_{n-1}` to first order. But we showed that `d(a*a)_{n-1}/d eps = 0` for any u with sum=0.

So the uniform point is a **second-order** stationary point. The question is whether it's a local min, max, or saddle at second order.

Second-order change in `(a*a)_{n-1}`:
`eps^2 * sum_j u_j * u_{n-1-j}`

This can be positive or negative depending on u. For example, if u is antisymmetric about the center (`u_i = -u_{n-1-i}`), then `sum_j u_j * u_{n-1-j} = sum_j u_j * (-u_j) = -sum_j u_j^2 < 0`.

So there ARE directions that decrease the central autocorrelation to second order! This means the uniform point is a **saddle point**, not a local minimum.

This means we need a method that can escape saddle points. Options:
1. Add random perturbation and then use gradient/subgradient
2. Use second-order information (Hessian)
3. Use a different objective that is smooth and whose gradient is nonzero at the uniform point
