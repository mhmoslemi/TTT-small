Let me implement the exact simplex projection:

```python
def project_simplex(v):
    n = len(v)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.nonzero(u * np.arange(1, n+1) > (cssv - 1))[0][-1]
    theta = (cssv[rho] - 1) / (rho + 1.0)
    return np.maximum(v - theta, 0)
```

This is $O(n \log n)$ per call due to sorting. For $n=5582$, that's about $5582 \times 13 \approx 72000$ comparisons, which is fast.

For continuous nonnegative values, the optimal solution is a "continuous Barker sequence" or "minimum peak sidelobe" (MPSL) sequence.

One practical approach: **iterative amplitude and phase (IAP) algorithm**, adapted for real nonnegative sequences:
1. Start with a random nonnegative sequence.
2. Compute its DFT.
3. In the frequency domain, modify the amplitude to have a flat (constant) magnitude spectrum while keeping the phase.
4. Invert DFT.
5. Project back to nonnegative (clip at 0).
6. Repeat.

This is the "spectral flattening" or "minimum peak power" algorithm, well-known in radar and communications.

Step 3 is the key: set $|\hat{v}[k]| = \text{const}$ for all $k$, keeping $\arg(\hat{v}[k])$ unchanged. Then the inverse DFT has a flat power spectrum, and by Parseval, the autocorrelation is a delta (or close to it).

But the projection in step 5 (clipping to nonnegative) disrupts the flat spectrum. The IAP algorithm iterates between the two constraints.
