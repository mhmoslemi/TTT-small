- Gradient of c_max: `sg_i = 2 * a[k_max - i]` where k_max = n-1.
  - `sg_i = 2 * S/n` for all valid i (since a is uniform).
  - So `sg = 2*S/n` (constant vector, for the portion where k_max - i is valid).
  
  For k_max = n-1: `valid_i` where `0 <= n-1-i < n`, i.e., `0 <= i <= n-1`. So all i are valid!
  `sg_i = 2 * S/n` for all i.

So the gradient is uniform! The step `a - lr * sg` makes all elements decrease equally. After renormalization (sum = S), the sequence returns to uniform! The method stalls!

This is a problem. The uniform sequence is a critical point of the max-convolution (by symmetry, all directions that preserve the sum give the same change in max to first order).

To escape, I need a perturbation that breaks the symmetry. This is where the random perturbation comes in. After a small random perturbation, the uniformity is broken, and the gradient will point in a specific direction that reduces the max.

So the algorithm should be:
1. Start from a slightly perturbed uniform sequence (or the parent + noise).
2. Do subgradient descent.
3. When stuck (no progress for many iterations), add a larger perturbation.

Actually, you know what, let me think about this differently. The problem is essentially: find a nonnegative vector a of length n, sum = S, that minimizes ||a*a||_∞ (the peak of the linear autocorrelation).

This is related to the "flat-top" window design problem in signal processing. The solution involves iterative methods like:
1. Projected gradient / Fourier domain methods (like in code sequence design)
2. The "cutoff" method: iteratively zero out the largest spectral components

For our problem (linear autocorrelation, nonnegative constraint), a natural approach is:

1. Compute c = conv(a, a)
2. Find the peak location k*
3. Reduce a_k* (or elements that contribute to c_{k*})
4. Compensate to maintain sum
5. Repeat

This is essentially what the subgradient method does. Let me just implement it cleanly.
