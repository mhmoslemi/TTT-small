Actually, I realize there might be a better approach. Let me think about the problem from the perspective of the "active set."

At the optimum, there's a set of lags K* where b[k] = t (the maximum). For all other lags, b[k] < t. The KKT conditions require:
- For j with a[j] > 0: sum_{k in K*} a[k-j] / |K*| = λ (the Lagrange multiplier for the sum constraint)
- For j with a[j] = 0: sum_{k in K*} a[k-j] / |K*| >= λ

This means: at the optimum, the "pressure" from the peak lags is uniform over all active (positive) positions.

So an alternative algorithm:
1. Start with a and find K*.
2. Compute p[j] = sum_{k in K*} a[k-j] / |K*| for all j.
3. Find λ such that if we "reduce" a[j] proportionally to (p[j] - λ) for j where p[j] > λ, the sum is preserved.
4. Update a.
5. Repeat.

Step 3 is the water-filling: we want a_new[j] = max(a[j] - η*(p[j] - λ), 0) such that sum a_new = sum a.

This is equivalent to finding λ such that:
sum_j max(a[j] - η*(p[j] - λ), 0) = sum a

This is a 1D root-finding problem that can be solved by binary search on λ.

Let me implement this:

```python
def waterfill(a, p, eta, S):
    """Find lambda such that sum_j max(a[j] - eta*(p[j] - lambda), 0) = S"""
    # For a given lambda, the active set is {j : a[j] - eta*(p[j] - lambda) > 0}
    # = {j : lambda > p[j] - a[j]/eta}
    # Let q[j] = p[j] - a[j]/eta. Active if lambda > q[j].
    # sum_active (a[j] - eta*p[j] + eta*lambda) = S
    # sum_active a[j] - eta*sum_active p[j] + eta*lambda*|active| = S
    # lambda = (S - sum_active a[j] + eta*sum_active p[j]) / (eta * |active|)
    
    q = p - a / eta
    # Sort q in ascending order
    order = np.argsort(q)
    q_sorted = q[order]
    a_sorted = a[order]
    p_sorted = p[order]
    
    # For active set = last m elements (largest q values are NOT active; smallest q are active)
    # Active if lambda > q[j], so the active set is {j : q[j] < lambda}
    # If q is sorted ascending: active set = first m elements where q[0] < ... < q[m-1] < lambda <= q[m]
    # sum_{j=0}^{m-1} (a[j] - eta*p[j] + eta*lambda) = S
    # (sum_{j=0}^{m-1} a[j] - eta*sum_{j=0}^{m-1} p[j]) + eta*lambda*m = S
    # lambda = (S - cumsum_a[m] + eta*cumsum_p[m]) / (eta*m) where cumsum is from the start
    
    cumsum_a = np.cumsum(a_sorted)
    cumsum_p = np.cumsum(p_sorted)
    cumsum_a = np.concatenate([[0], cumsum_a])
    cumsum_p = np.concatenate([[0], cumsum_p])
    
    # For m = 1, ..., n: lambda_m = (S - cumsum_a[m] + eta*cumsum_p[m]) / (eta*m)
    # We need q_sorted[m-1] < lambda_m <= q_sorted[m] (with q_sorted[n] = +inf)
    
    n_active = np.arange(1, len(a) + 1)
    lambda_candidates = (S - cumsum_a[n_active] + eta * cumsum_p[n_active]) / (eta * n_active)
    
    # Check which m is valid
    # Valid if q_sorted[m-1] < lambda_m and (m == n or lambda_m <= q_sorted[m])
    q_with_inf = np.concatenate([q_sorted, [np.inf]])
    valid = (q_sorted[:n_active-1+1] < lambda_candidates) & (lambda_candidates <= q_with_inf[n_active])
    # q_sorted[:n_active-1+1] = q_sorted[0..n-1] = all elements (the "left boundary")
    # Actually: for m active elements, we need q_sorted[m-1] < lambda_m <= q_sorted[m]
    lower = q_sorted[np.clip(n_active - 1, 0, n-1)]
    upper = q_with_inf[n_active]
    valid = (lower < lambda_candidates) & (lambda_candidates <= upper)
    
    if np.any(valid):
        m = int(np.argmax(valid)) + 1  # first valid (smallest m)
        lambda_val = lambda_candidates[m-1]
    else:
        # Fallback: all active
        lambda_val = (S - a.sum() + eta * p.sum()) / (eta * len(a))
    
    a_new = np.maximum(a - eta * (p - lambda_val), 0.0)
    return a_new
```

Hmm, this is getting complex. Let me simplify by just doing a bisection on λ:

```python
def waterfill_bisect(a, p, eta, S, tol=1e-10, max_iter=100):
    """Find lambda such that f(lambda) = sum max(a - eta*(p - lambda), 0) = S"""
    # f is monotonically increasing in lambda
    # f(lower) where lower = min(p) - max(a)/eta - 1: f = 0
    # f(upper) where upper = max(p) + max(a)/eta + 1: f = sum a + eta*(upper - mean(p)) * n >> S
    lo = p.min() - a.max() / eta - 1.0
    hi = p.max() + a.max() / eta + 1.0
    
    for _ in range(max_iter):
        mid = 0.5 * (lo + hi)
        f_mid = np.maximum(a - eta * (p - mid), 0.0).sum()
        if abs(f_mid - S) < tol:
            break
        if f_mid < S:
            lo = mid
        else:
            hi = mid
    
    lambda_val = 0.5 * (lo + hi)
    return np.maximum(a - eta * (p - lambda_val), 0.0)
```

This is simpler and should work. Each bisection iteration is O(n), and 100 iterations give sufficient precision.
