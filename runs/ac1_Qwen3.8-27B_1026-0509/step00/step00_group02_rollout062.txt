Now, the score is 2n * max_k C[k] / S^2 where S = sum(f). The gradient of the score (w.r.t. f) involves the gradient of the max and the gradient of S^2 in the denominator.

If we fix S (by normalizing after each step), then we just need to minimize max_k C[k]. The subgradient of max_k C[k] is in the convex hull of {grad C[k] : C[k] = max}. For simplicity, we can use the gradient of the C[k] at the maximizing k (or the average over all k's that are within epsilon of the max).

So the algorithm would be:
1. Start with f (parent sequence)
2. Normalize so sum(f) = sqrt(2n)
3. Compute C = convolve(f, f)
4. Find k* = argmax C[k]
5. Compute grad = 2 * f reversed and shifted by k* (i.e., grad[j] = 2*f[k*-j] if 0<=k*-j<n)
6. Update: f[j] = f[j] - eta * grad[j] (gradient descent to REDUCE C[k*])
7. Clip f to [0, 1000]
8. Re-normalize
9. Repeat

But this only reduces one C[k]. We want to reduce the MAX, so we should focus on all k's that are near the max.

Better: use a "soft max" approximation or iterate over the active set.

Even better: this is essentially the dual of a convex optimization problem. We want:

subject to f^T Q_k f <= t for all k
sum(f) = sqrt(2n)
f >= 0

This is a QCQP (quadratically constrained quadratic program). Not trivially solvable.

- At each step, the "active" constraints are those with C[k] close to max
- Compute the negative gradient of the active C[k] values
- Project onto the feasible set (f >= 0, sum = sqrt(2n))
