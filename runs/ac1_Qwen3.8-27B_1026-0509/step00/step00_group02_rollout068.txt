||q||_p^p = sum_k q_k^p
d/dp_i ||q||_p^p = p * sum_k q_k^{p-1} * dq_k/dp_i

The "weights" are w_k = q_k^{p-1} / sum_j q_j^{p-1} (normalized). For large p, these concentrate on the peaks.

Then the gradient computation is the same as before but with s_k replaced by w_k.

This is smoother and might converge faster. Let me use p=20 or so (large enough to approximate max, but smooth enough for good gradients).

Actually, even simpler: I can just use the squared version or a moderate power. Let me use p_power = 10.

Let me revise my approach:

```python
def compute_grad_smooth(p, q, power):
    # w_k proportional to q_k^power (emphasizes peaks)
    q_pos = np.maximum(q, 1e-30)
    w = q_pos ** power
    w /= w.sum()  # normalize to sum=1
    
    # Now compute grad = 2*(C1 + C2) as before, with s replaced by w
    P = np.fft.rfft(p, N)
    S = np.fft.rfft(w, N)
    C2 = np.fft.irfft(P * S, N)[:n]
    Sr = np.fft.rfft(w[::-1], N)
    Conv = np.fft.irfft(P * Sr, N)
    C1 = Conv[n-1:2*n-1][::-1]
    return power * (C1 + C2)  # the factor of p from d/dp_i sum q_k^p
```

Wait, I need to be careful with the scaling. The objective I'm optimizing is:
f(p) = (sum_k q_k^P)^(1/P) ≈ max(q) for large P

Or I can directly minimize sum_k q_k^P (equivalent for fixed P).

d/dp_i sum_k q_k^P = P * sum_k q_k^{P-1} * dq_k/dp_i

If I set w_k = q_k^{P-1} / sum_j q_j^{P-1}, then:
d/dp_i sum_k q_k^P = P * (sum_k q_k^{P-1}) * sum_k w_k * dq_k/dp_i
= P * Q * sum_k w_k * 2*p_{|k-i|} (approx)
= P * Q * 2 * (C1[i] + C2[i]) (approx, with w as the weight)

where Q = sum_k q_k^{P-1}.

The factor P*Q is a positive scalar that doesn't affect the direction of steepest descent. So I can just use:
grad_dir = C1 + C2 (computed with w as weights)

And the step size absorbs the P*Q factor.

OK let me just implement this cleanly. Let me use power=8 (moderate smoothing).

Actually, you know what, let me just go with the subgradient approach (top-k peaks, uniform weight). It's simpler and for our purpose (getting from 2.0 to ~1.5), it should work.

The key issue is step size. Let me use a simple heuristic:
- step = alpha * (1/n)
- If objective decreases: alpha *= 1.05
- If objective increases: alpha *= 0.5
- Clamp alpha to [0.1, 100]

```python
import numpy as np
import time

def propose_candidate(seed=42, budget_s=1500, **kwargs):
    rng = np.random.default_rng(seed)
    t0 = time.monotonic()
    deadline = t0 + max(1.0, float(budget_s)) - 10.0

    parent = np.clip(np.asarray(height_sequence_1, dtype=np.float64), 0, 1000).copy()
    n = parent.size
    if n < 10 or not np.isfinite(parent).all() or parent.sum() < 1e-10:
        n = 256
        parent = np.ones(n, dtype=np.float64)

    N = 1
    while N < 3 * n:
        N *= 2

    def conv_p(p):
        F = np.fft.rfft(p, N)
        return np.fft.irfft(F * F, N)[:2 * n - 1]

    def smooth_grad(p, q, pw):
        qp = np.maximum(q, 1e-20)
        w = qp ** pw
        wsum = w.sum()
        if wsum < 1e-30:
            w = np.zeros(2 * n - 1)
            w[int(np.argmax(q))] = 1.0
        else:
            w /= wsum
        P = np.fft.rfft(p, N)
        S = np.fft.rfft(w, N)
        C2 = np.fft.irfft(P * S, N)[:n]
        Sr = np.fft.rfft(w[::-1], N)
        Cv = np.fft.irfft(P * Sr, N)
        C1 = Cv[n - 1:2 * n - 1][::-1]
        return C1 + C2

    inits = []
    pp = parent.copy()
    pp_pp = np.maximum(pp, 0)
    if pp_pp.sum() > 0:
        pp_pp /= pp_pp.sum()
        inits.append(pp_pp)
    ramp = np.linspace(n, 1, n, dtype=np.float64)
    ramp /= ramp.sum()
    inits.append(ramp)
    for gm in [1.5, 3.0, 5.0]:
        e = np.exp(-gm * np.arange(n, dtype=np.float64) / n)
        e /= e.sum()
        inits.append(e)
    for _ in range(4):
        r = np.abs(rng.standard_normal(n)) + 0.05
        r += 0.7 * np.linspace(1.0, 0.1, n)
        r /= r.sum()
        inits.append(r)

    best_p = pp_pp.copy()
    best_obj = evaluate_sequence(best_p.tolist())

    for p0 in inits:
        if time.monotonic() > deadline:
            break
        p = p0.copy()
        alpha = 3.0
        pw = 6.0
        no_improve = 0

        for it in range(300000):
            if time.monotonic() > deadline:
                break

            q = conv_p(p)
            obj = 2.0 * n * q.max()

            if obj < best_obj:
                best_obj = obj
                best_p = p.copy()
                no_improve = 0
            else:
                no_improve += 1

            if no_improve > 8000 and alpha < 0.5:
                break
            if no_improve > 15000:
                break

            g = smooth_grad(p, q, pw)
            step = alpha / n
            p_new = p - step * g
            p_new = np.maximum(p_new, 0.0)
            sv = p_new.sum()
            if sv < 1e-14:
                alpha *= 0.5
                continue
            p_new /= sv

            q_new = conv_p(p_new)
            obj_new = 2.0 * n * q_new.max()

            if obj_new <= obj * 1.002:
                p = p_new
                alpha = min(alpha * 1.03, 200.0)
                pw = min(pw * 1.01, 30.0)
            else:
                alpha = max(alpha * 0.6, 0.05)
                pw = max(pw * 0.95, 4.0)

            if it % 5000 == 0 and no_improve > 2000:
                p = np.maximum(p + rng.standard_normal(n) * 0.005, 0)
                sv = p.sum()
                if sv > 0:
                    p /= sv

    result = best_p.copy()
    sc = evaluate_sequence(result.tolist())
    ps = evaluate_sequence(parent.tolist())
    if ps < sc:
        result = parent
    result = np.clip(result, 0, 1000)
    if result.sum() < 0.01:
        result = np.ones(n) * 0.01 / n
    return [float(x) for x in result]
```
