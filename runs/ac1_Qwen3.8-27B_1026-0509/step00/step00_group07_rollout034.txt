For the "one-sided" condition (c[k] = C for k = 0, ..., n-1), the sequence is determined by the recurrence:
a[k]^2 + 2*sum_{i=0}^{k-1} a[i]*a[k-i] = C.

This gives a unique non-negative solution (assuming it exists). The sequence is strictly decreasing: a[0] > a[1] > a[2] > ....

But we also need c[k] = C for k = n, ..., 2n-2, which gives additional constraints. For a general n, these constraints are overdetermined (we have 2n-1 constraints on n unknowns), so a perfect solution may not exist.

However, we can find the sequence that minimizes the deviation from flat, which is a nonlinear optimization problem.
