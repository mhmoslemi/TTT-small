    f[0] = f0
    C = f0**2  # target convolution value
    for k in range(1, n):
        # c[k] = sum_{j=0}^{k} f[j]*f[k-j] = C (for k < n)
        # c[k] = f[0]*f[k] + 2*sum_{j=1}^{k//2} f[j]*f[k-j] + ...

Now, about the gradient computation. I need to be careful about the FFT-based cross-correlation.

I want: g[i] = sum_{k=0}^{2n-2} w[k] * f[k-i] (with f[x] = 0 for x < 0 or x ≥ n)

This is: g[i] = sum_{k=i}^{i+n-1} w[k] * f[k-i] = sum_{j=0}^{n-1} w[i+j] * f[j]

This is the cross-correlation of w and f: (w ⋆ f)[i] = sum_j w[j+i] * f[j]

In FFT: if we define A = f (padded to Nft) and B = w (padded to Nft), then:
ifft(fft(B) * conj(fft(A)))[i] = sum_j B[j] * conj(A[j-i]) = sum_j B[j] * A[j-i] (for real)
= sum_j w[j] * f[j-i] (with padding)
= sum_m w[m+i] * f[m] (substituting m = j-i)
= g[i] ✓

So: g = ifft(fft(w_padded) * conj(fft(f_padded)))
