`scipy.linalg.toeplitz(c, r)` creates a Toeplitz matrix where `c` is the first column and `r` is the first row. The matrix element `A[i,j] = c[i-j]` if `i >= j` and `A[i,j] = r[j-i]` if `i < j`.

I want `A[k,j] = f[k-j]` if `0 <= k-j < n`, else 0.

- First column (j=0): `A[k,0] = f[k]` for `k < n`, else 0. So `c = [f_0, f_1, ..., f_{n-1}, 0, ..., 0]` (length 2n-1).

- `A[k,j]` for `k >= j`: `c[k-j] = f[k-j]` if `k-j < n`, else 0. ✓
