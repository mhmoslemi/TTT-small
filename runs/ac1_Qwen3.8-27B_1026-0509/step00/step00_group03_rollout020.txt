2. Solve: minimize t s.t. 2*f*[k]*x <= t (linearize the quadratic at f)

3. Update f towards the solution
4. Repeat

This is essentially a sequential linearization approach (like the active set method for QP).

The linearized constraint at step k is:
(f*f)[k] + 2 * sum_i f[k-i] * dx[i] <= t

(f*f)[k] + 2*(dx*f)[k] <= t

This is linear in dx (and t). The LP becomes:
minimize t
subject to 2*(dx*f)[k] <= t - (f*f)[k] for all k
sum(dx) = 0 (to preserve normalization)
f + dx >= 0

This is a standard LP with n+1 variables (dx_0, ..., dx_{n-1}, t) and 2n+1 constraints.

The constraint matrix for the "2*(dx*f)[k] <= t - (f*f)[k]" part is the same convolution matrix A (with f as coefficients).

```python
def solve_direction_lp(f, n):
    """Solve the linearized direction-finding LP."""
    S = float(np.sum(f))
    aa = np.convolve(f, f)  # (2n-1, )
    M = float(np.max(aa))
    
    # Build A (same as before): A[k,j] = f[k-j] if valid
    A = np.zeros((2 * n - 1, n))
    for j in range(n):
        A[j:j+n, j] = f
    
    # Variables: dx (n) + t (1) = n+1 total
    # Minimize t: c = [0, 0, ..., 0, 1]
    c = np.zeros(n + 1)
    c[-1] = 1.0  # minimize t
    
    # Constraints: 2*A@dx - t <= -aa
    # => [2*A | -1] @ [dx; t] <= -aa
    Ab = np.concatenate([2 * A, -np.ones((2*n-1, 1))], axis=1)
    bb = -aa
    
    # Equality: sum(dx) = 0
    # In linprog, equality constraints are handled separately
    Aeq = np.zeros((1, n + 1))
    Aeq[0, :n] = 1.0  # sum of dx = 0
    beq = [0.0]
    
    # Bounds: f + dx >= 0 => dx >= -f
    # And t >= 0
    bounds = [(-f[i], None) for i in range(n)] + [(0, None)]
    
    res = linprog(c, A_ub=Ab, b_ub=bb, A_eq=Aeq, b_eq=beq,
                  bounds=bounds, method='highs')
    
    if res.success:
        dx = res.x[:n]
        return dx  # direction to add to f
    return None
```
