1. Start with an initial guess (e.g., two-step or parent)
2. At each iteration:
   a. Compute c = a*a (via FFT)
   b. Find the peak position k*
   c. The "cost" is c[k*]
   d. Try small perturbations: add ε to a random position and subtract ε from another (to maintain sum)
   e. Accept if the peak decreases

This is essentially a random walk with acceptance criterion. It's slow but guaranteed to eventually find improvements.

A faster approach: **Active set / water-filling**

The idea is:
1. Compute c = a*a
2. The peak is at k*. To reduce c[k*] = sum_i a[i]*a[k*-i]:
   - We want to "move" mass from positions i where a[i]*a[k*-i] is large to positions where it's small
   - Specifically, if we transfer δ from position i to position j, the change in c[k*] is approximately:
     δ * (a[j]*a[k*-j] - a[i]*a[k*-i]) / (a[i] + δ) ... (complicated)
   - Simpler: just reduce a[i] for the i that maximizes a[i]*a[k*-i] and increase a[j] for the j that minimizes a[j]*a[k*-j]

This is essentially a "steepest descent" on the peak value.

**Better approach: Direct optimization of the "flat" target**

The key insight is: we want the convolution to be as flat as possible. The "ideal" convolution is a flat top with value S^2/(2n-1) everywhere.

For a given sequence a, define the "excess" at position k: e_k = c[k] - S^2/(2n-1).
We want to minimize max(e_k) = max(c) - S^2/(2n-1).

The "active constraints" are the positions where c[k] is at its maximum.

A practical algorithm:
1. Start with an initial a
2. Compute c = a*a
3. Identify the "hottest" position k*
4. Compute the "sensitivity" vector: s_j = 2*a[k*-j] (gradient of c[k*] w.r.t. a[j])
5. Perform a "deflation" step: reduce a[j] where s_j is large, increase where s_j is small
