The issue is that subgradient descent for max-type objectives is very slow. The function max_k (a*a)[k] is piecewise quadratic, and the subgradient only uses information from one active constraint. Convergence to the optimum is O(1/T) at best (for non-smooth functions), meaning we need O(1/epsilon^2) iterations to get within epsilon of optimal.

For a more effective approach, let me consider:

**Approach: Alternating with a "dual" variable.**

The problem min_a max_k (a*a)[k] can be written as:
min_a max_{lambda in simplex} sum_k lambda_k (a*a)[k]

By minimax theorem (if we can interchange min and max, which requires convexity... and we established the problem is non-convex). So this doesn't directly help.

But we can still use it heuristically:
1. Maintain a distribution lambda over the lags.
2. Given lambda, the inner minimization is: min_a sum_k lambda_k (a*a)[k] s.t. a >= 0, sum(a) = 1.
   This is: min_a a^T (sum_k lambda_k T_k) a s.t. a >= 0, sum(a) = 1.
   The matrix sum_k lambda_k T_k is a weighted sum of "shift-reversal" matrices. This is a symmetric matrix (since each T_k is symmetric), but not necessarily PSD.
   If it is PSD (or we restrict to a >= 0 where the quadratic form is positive), this is a QP with a simplex constraint, which can be solved efficiently.

3. Update lambda: put more weight on the lags that currently have high (a*a)[k].

This is essentially the "multiplicative weights" or "Hedge" approach for the max.

The QP in step 2: min a^T Q a s.t. a >= 0, sum(a) = 1, where Q = sum_k lambda_k T_k.

For n=6733, this QP has n variables and is a dense quadratic program. The matrix Q is n x n = 6733^2 ≈ 45M entries (360MB). This is large but might be feasible.

Actually, Q has a special structure: Q = sum_k lambda_k T_k where T_k[i,j] = 1 if j = k - i (i.e., i + j = k). So Q[i,j] = lambda_{i+j} (where lambda_k is defined for k = 0 to 2n-2, and we extend with lambda_k = 0 outside this range).

So Q is a "Hankel" matrix! Q[i,j] = lambda_{i+j}. This is a very structured matrix - it's determined by just 2n-1 values (lambda_0 to lambda_{2n-2}).

For a Hankel matrix, we can exploit the structure. The eigenvalue decomposition of a Hankel matrix can be computed in O(n^2) time. The QP min a^T Q a can be solved using the Karush-Kuhn-Tucker conditions.

KKT conditions for min a^T Q a s.t. sum(a) = 1, a >= 0:
- 2Qa + mu * 1 - nu = 0 (where nu >= 0 is the multiplier for a >= 0)
- nu * a = 0 (complementary slackness)
- sum(a) = 1, a >= 0, nu >= 0

From the first equation: 2Qa + mu * 1 = nu, so nu = 2Qa + mu * 1.
Since nu >= 0 and a >= 0: for a_i > 0, nu_i = 0, so 2(Qa)_i + mu = 0, i.e., (Qa)_i = -mu/2.
For a_i = 0, nu_i >= 0, so 2(Qa)_i + mu >= 0, i.e., (Qa)_i >= -mu/2.

So the solution is: find the smallest subset S of indices such that for all i in S, (Qa)_i = -mu/2, and for all i not in S, (Qa)_i >= -mu/2, with sum_{i in S} a_i = 1 and a_i > 0 for i in S.

This is the "active set" method for QPs. In each iteration, we identify the active set S and solve the linear system Q[S,S] a[S] + mu/2 * 1[S] = 0 with sum a[S] = 1.

But this still requires inverting Q[S,S], which for a Hankel matrix is O(|S|^2) using specialized algorithms.

2. The step size needs to be small to avoid oscillation.

To address (1), I can use the "subdifferential" more carefully: when multiple lags are near the max, average the subgradients.

Let me implement a version where I use a "soft max" (log-sum-exp) instead of hard max:
F(a) = (1/tau) * log(sum_k exp(tau * (a*a)[k]))

This is a smooth approximation to max_k, and its gradient is:
grad F = sum_k p_k * grad (a*a)[k] / 1 (since the 1/tau cancels)
where p_k = exp(tau * (a*a)[k]) / sum_j exp(tau * (a*a)[j])

This is a weighted average of the subgradients, with weights concentrated on the max-lags for large tau.

As tau -> inf, this converges to the hard max. For moderate tau, it's smooth and we can use gradient descent with adaptive step size.

This is a much better approach! Let me implement it.

The gradient of F(a) = (1/tau) log(sum_k exp(tau * (a*a)[k])) is:
grad F[m] = sum_k p_k * 2 * a[k-m] * 1_{0<=k-m<n}

where p_k = softmax(tau * (a*a))[k].

This is a convex combination of the "reversed-shift" of a. It's O(n * (2n-1)) to compute naively, but we can do it more efficiently.

Actually, grad F[m] = 2 * sum_k p_k * a[k-m] * 1_{0<=k-m<n}
= 2 * sum_{j: 0<=j<n} a[j] * p_{m+j} * 1_{0<=m+j<2n-1}
= 2 * sum_j a[j] * p_{j+m}

where p is defined for k = 0 to 2n-2 and p_k = 0 outside.

This is a "circulant-like" convolution of a with p! Specifically:
grad F = 2 * (a * p_truncated) where p is zero-padded.

Wait, let me be more careful. grad F[m] = 2 * sum_j a[j] * p[j+m] (with p[k] = 0 for k < 0 or k >= 2n-1). This is a "cross-correlation" of a and p. We can compute it via FFT!

So the gradient computation is O(n log n) per step. 

Now, the full algorithm:
1. Compute corr = convolve(a, a) via FFT: O(n log n)
2. Compute p = softmax(tau * corr): O(n)
3. Compute grad F via cross-correlation of a and p: O(n log n)
4. Gradient step: a <- a - eta * grad F (with projection onto simplex)
5. Repeat

Total per iteration: O(n log n). For n=6733, this is fast (~1ms).

import time

def propose_candidate(seed=42, budget_s=1500, **kwargs):

        c = np.convolve(x, x)  # length 2n-1
        return c.max(), c.argmax(), c
    
    def score(x):
        return 2 * n * convolve_max(x)[0] / (x.sum()**2)
    
    best = a.copy()
    best_score = score(a)
    
    # LP-based alternating method
    # Step 1: Given a, solve LP: max sum(b) s.t. conv(a,b)[k] <= M, b >= 0
    # Step 2: Rescale b, update a
    
    for it in range(10000):
        if time.monotonic() > deadline:
            break
        
        M, k_star, _ = convolve_max(a)
        
        # Build constraint matrix: A[k,j] = a[k-j] if 0<=k-j<n else 0

                if res.status == 0 and res.x is not None:
                    b = res.x
                    b_sum = b.sum()
                    if b_sum > 1e-10:
                        b = b / b_sum
                        improved = False
                        for t in [1.0, 0.7, 0.5, 0.3]:
                            a_new = np.maximum((1 - t) * a + t * b, 0)
                            S = a_new.sum()
                            if S > 1e-10:
                                a_new = a_new / S
                                c_new = np.convolve(a_new, a_new)
                                s_new = 2.0 * n * c_new.max()
                                s_old = 2.0 * n * M
                                if s_new < s_old * (1 - 1e-8):
                                    a = a_new
                                    improved = True
                                    break
                        if improved:
                            no_improve = 0
                        else:
                            no_improve += 1
                        if no_improve > 300:
                            break
                else:
                    no_improve += 1
                    if no_improve > 100:
                        break

            # SLSQP polish
            if time.monotonic() < deadline - 30:
                try:
                    res2 = minimize(
                        lambda x: objective(x, n),
                        a, method='SLSQP',
                        constraints=[{'type': 'eq', 'fun': lambda x: x.sum() - 1}],
                        bounds=[(0, None)] * n,
                        options={'maxiter': 800, 'ftol': 1e-15}
                    )
                    if res2.x is not None and np.all(res2.x >= -1e-10):
                        a = np.maximum(res2.x, 0)
                        if a.sum() > 1e-10:
                            a = a / a.sum()
                except Exception:
                    pass

            try_update(a)

    # Gradient-based attack on parent (if still time)
    if time.monotonic() < deadline - 20:
        try:
            parent = np.clip(np.asarray(height_sequence_1, dtype=np.float64), 0, 1000)
            if parent.size > 0:
                n_p = parent.size
                a = parent / parent.sum()
                N = 2 * n_p - 1
                Nfft = 1 << (N - 1).bit_length()
                Nfft2 = 1 << (3 * n_p - 3).bit_length()

                eta = 0.002
                momentum = 0.9
                v = np.zeros(n_p)
                tau = 3.0

                for it in range(3000):
                    if time.monotonic() > deadline - 20:
                        break
                    A_f = np.fft.rfft(a, Nfft)
                    corr = np.fft.irfft(A_f * A_f, Nfft)[:N]
                    M = corr.max()

                    shifted = tau * (corr - M)
                    p = np.exp(shifted)
                    p /= p.sum()

                    # Gradient via cross-correlation
                    r = a[::-1]
                    r_f = np.fft.rfft(r, Nfft2)
                    q = np.zeros(Nfft2)
                    q[:N] = p
                    q_f = np.fft.rfft(q)
                    conv_rq = np.fft.irfft(r_f * q_f, Nfft2)
                    grad = 2.0 * conv_rq[n_p - 1:2 * n_p - 1]

                    v = momentum * v - eta * grad
                    a_new = a + v
                    a_new = np.maximum(a_new, 0)
                    S = a_new.sum()
                    if S > 1e-10:
                        a = a_new / S

                    if it % 20 == 0:
                        try_update(a)
                        eta *= 0.995
                        tau *= 1.005
        except Exception:
            pass

    if best is None:
        return [1.0]
    return [float(x) for x in best]
