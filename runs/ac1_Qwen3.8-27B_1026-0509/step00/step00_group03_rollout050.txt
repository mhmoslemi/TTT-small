The simplex projection: given y, find x = argmin ||x-y||² s.t. sum x=1, x>=0.
Algorithm: sort y descending, find threshold τ such that sum max(y_i - τ, 0) = 1, then x_i = max(y_i - τ, 0).

Let me implement this:

```python
def proj_simplex(y):
    n = len(y)
    u = np.sort(y)[::-1]
    cssv = np.cumsum(u)
    rho = np.nonzero(u * np.arange(1, n+1) > (cssv - 1))[0][-1]
    theta = (cssv[rho] - 1) / (rho + 1.0)
    return np.maximum(y - theta, 0)
```
