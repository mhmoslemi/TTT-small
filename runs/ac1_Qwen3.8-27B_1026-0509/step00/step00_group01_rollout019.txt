- If `j + (k-j) = k`: the term `f[j] * f[k-j]` appears, so `(f*f)[k]` is linear in `f[j]` (coefficient `f[k-j]`).

So for a fixed k, `(f*f)[k]` is at most quadratic in `f[j]`. The max over k is the max of such functions, which is still nonconvex in general.

But we can do a "sequential" coordinate update: fix `f[j]`, compute the new `f*f`, find the new max, and check if it improved. This is O(n^2) per coordinate (recomputing `f*f`), and O(n) coordinates per full sweep, so O(n^3) per sweep. For n=6121, that's ~228 billion operations. Too slow.

Better: update `f*f` incrementally. If we change `f[j]` by `delta`, then:
- `(f*f)[k]` changes by `delta * f[k-j] + f[j] * delta` (for the terms involving f[j])
  Actually: the new `(f*f) = old (f*f) + delta * f[:,k-j] + f[j]_old * delta_vec`
  
Let me be more precise. If `f[j] -> f[j] + delta`:

- If `k-j = j` (k=2j): `(f*f)[2j] -> (f*f)[2j] + 2*delta*f[j] + delta^2`

Wait, this isn't quite right. Let me redo:

`(f*f)[k] = sum_i f[i] * f[k-i]`

If we change `f[j]` to `f[j] + delta`:
- Terms where `i = j`: contribute `f[j] * f[k-j]` -> `(f[j]+delta) * f[k-j]`, change is `delta * f[k-j]`
- Terms where `k-i = j`, i.e., `i = k-j`: contribute `f[k-j] * f[j]` -> `f[k-j] * (f[j]+delta)`, change is `delta * f[k-j]`

If `j != k-j` (i.e., `k != 2j`): total change is `2 * delta * f[k-j]`
If `j = k-j` (i.e., `k = 2j`): only one term (i=j=k-j), change is `delta * f[j] + delta^2`... 

Wait, when `i = j` and `k-i = j`, that's the same term `f[j]*f[j]`. So:
- Old: `f[j] * f[j] = f[j]^2`
- New: `(f[j]+delta)^2 = f[j]^2 + 2*delta*f[j] + delta^2`
- Change: `2*delta*f[j] + delta^2`

But in the general formula, when `j = k-j`:
- "Terms where i=j": `f[j]*f[k-j] = f[j]*f[j]`
- "Terms where k-i=j": `f[k-j]*f[j] = f[j]*f[j]`
- These are the SAME term! So we should only count it once.

So the correct update is:
- If `k != 2j` (and `0 <= k-j < n`): change is `2 * delta * f[k-j]`
- If `k == 2j`: change is `2 * delta * f[j] + delta^2`
- Otherwise: change is 0

This allows O(n) update of `f*f` per coordinate change. A full coordinate sweep is O(n^2), and we can do many sweeps in the time budget.

For coordinate descent, at coordinate j, we want to find `delta` that minimizes `max_k (f*f)[k] + delta_effect(k)` subject to `f[j] + delta >= 0` and maintaining `sum(f) = s` (which means we'd need to adjust another coordinate, making it trickier).

The "try changing f[j]" step: we can do a 1D line search. For a given j, `max_k (f*f)[k]` as a function of `f[j]` (denoted x) is:
- For k != 2j: linear in x (coefficient 2*f[k-j])
- For k = 2j: quadratic in x (x^2 + ...)

The max of these is a convex piecewise-linear (plus one quadratic) function of x. So we can find the minimum by checking breakpoints.

Actually, the max of linear functions is convex (it's the supremum of linear functions). Adding one quadratic term... the overall function is still convex in x (it's the max of convex functions, and the quadratic at k=2j is convex).

Wait, is `max_k (f*f)[k]` as a function of `f[j] = x` convex? Let's see:
- For k ≠ 2j: `(f*f)[k](x) = a_k * x + b_k` (linear)
- For k = 2j: `(f*f)[2j](x) = x^2 + c*x + d` (convex quadratic)
- Max of these: convex ✓

So we CAN do exact 1D minimization! The minimum of a convex piecewise-linear+quadratic function occurs at:
- A breakpoint (where two pieces cross)
- The vertex of the quadratic
- The boundary (x = 0)

This is O(n) to find (check all breakpoints).

This gives us an efficient coordinate descent: O(n) per coordinate (line search) + O(n) for the `f*f` update = O(n) per coordinate, O(n^2) per sweep.

Actually, let me reconsider the whole approach. The key insight is:

1. The score is scale-invariant: `score(c*f) = score(f)` for any c > 0.

For a practical approach that's likely to work well:

**Strategy: Iterated LP + subgradient + random restarts**

1. Start with parent, normalize to sum=1.
2. Loop:
   a. Compute `ff = f*f`, `M = max(ff)`
   b. Solve LP: max `sum(g)` s.t. `g >= 0`, `(f*g)[k] <= M` for top-K lags
   c. Rescale g to sum=1, blend with f
   d. If no improvement after a few LP iterations, do subgradient steps
   e. If stuck, do random perturbations
3. Track best

The LP is the key differentiator from the previous program. Let me make sure it's implemented efficiently.

For the LP, I need to build the constraint matrix efficiently. For K constraints and n variables:

```python
def build_constraint_matrix(f, k_list):
    """Build A[i,j] = f[k_i - j] if valid, else 0."""
    n = len(f)
    A = np.zeros((len(k_list), n))
    for i, k in enumerate(k_list):
        j = np.arange(n)
        idx = k - j
        valid = (idx >= 0) & (idx < n)
        A[i, valid] = f[idx[valid]]
    return A
```

For n=6121, K=200: A is 200×6121 ≈ 1.2M entries. Building it takes O(K*n) = 1.2M operations. Fast.

import time
import cvxpy as cp

def propose_candidate(seed=42, budget_s=1500, **kwargs):
    rng = np.random.default_rng(seed)
    deadline = time.monotonic() + max(0.0, float(budget_s) - 10.0)
    
    parent = np.clip(np.asarray(height_sequence_1, dtype=np.float64), 0.0, 1000.0)
    if parent.ndim != 1 or parent.size == 0 or not np.isfinite(parent).all():
        parent = np.ones(1024, dtype=np.float64)
    
    best = parent.copy() / parent.sum()  # normalize to sum=1
    best_score = float(evaluate_sequence(best.tolist()))
    n = best.size
    
    def eval_score(f):
        return float(evaluate_sequence(f.tolist()))
    
    def solve_attack_lp(f, M, K=300):
        """Solve LP to find attack sequence."""
        ff = np.convolve(f, f)
        top_k = np.argsort(ff)[-K:]
        
        g_var = cp.Variable(n, nonneg=True)
        obj = cp.Maximize(cp.sum(g_var))
        constraints = []
        
        for k in top_k:
            j = np.arange(n)
            idx = k - j
            row = np.zeros(n)
            valid = (idx >= 0) & (idx < n)
            if valid.any():
                row[valid] = f[idx[valid]]
                constraints.append(row @ g_var <= M)
        
        prob = cp.Problem(obj, constraints)
        try:
            prob.solve(solver=cp.CLARABEL)
        except Exception:
            try:
                prob.solve(solver=cp.SCS, max_iters=20000)
            except Exception:
                return None
        
        if g_var.value is None:
            return None
        g_val = np.asarray(g_var.value, dtype=np.float64)
        g_val = np.clip(g_val, 0, None)
        if g_val.sum() <= 0:
            return None
        return g_val / g_val.sum()  # normalize to sum=1
    
    def subgradient_step(f, ff, M):

        k_star = np.argmax(ff)
        # Subgradient of (f*f)[k_star] w.r.t. f[j] = 2*f[k_star-j]
        grad = np.zeros(n)
        idx = k_star - np.arange(n)

            valid2 = (idx2 >= 0) & (idx2 < n)
            grad[valid2] += 2.0 * f[idx2[valid2]]

        # where project = onto {g >= 0, sum(g) = 1}
        best_f = f
        best_m = M

            v = f - eta * grad
            # Project to simplex: g = max(0, v - tau), sum(g) = 1
            lo, hi = v.min() - 1, v.max() + 1
            for _ in range(50):
                tau = (lo + hi) / 2
                g = np.maximum(0, v - tau)
                if g.sum() > 1:
                    lo = tau
                else:
                    hi = tau
            g = np.max
