For a Toeplitz matrix with A[i,j] = c[i-j]:
- First column (j=0): A[i,0] = c[i] for i=0,...,2n-2. So c[0], c[1], ..., c[2n-2].
- First row (i=0): A[0,j] = c[-j] for j=0,...,n-1. So c[0], c[-1], ..., c[-(n-1)].

In our case, c[m] = x[m] for 0<=m<n and 0 otherwise. So:
- First column: x[0], x[1], ..., x[n-1], 0, 0, ..., 0 (length 2n-1)
- First row: x[0], 0, 0, ..., 0 (length n)

```python
def make_lp_matrix(x):
    n = len(x)
    diags = [np.full(n, x[d], dtype=np.float64) for d in range(n)]
    offsets = list(range(n))
    return sparse.diags(diags, offsets, shape=(2*n-1, n), format='csc')
```
