For these to be ≈ S^2/(2n-1), we'd need a_0 ≈ S/sqrt(2n-1), meaning all elements should be ≈ S/sqrt(2n-1), which is the uniform case. But then the center lag has n terms each of size S/(n*sqrt(2n-1))^2... this doesn't work out to flat.

I think the fundamental issue is: for nonnegative sequences, the autocorrelation cannot be perfectly flat. The best we can do is reduce the peak by making the sequence non-uniform in a specific way.

        j_min = max(0, k_star - (n-1))
        j_max = min(n-1, k_star)
        j_vals = np.arange(j_min, j_max + 1)
        idx_vals = k_star - j_vals
        grads[j_vals] = 2.0 * a[idx_vals]
        if k_star % 2 == 0:
            mid = k_star // 2
            if 0 <= mid < n:
                grads[mid] = a[mid]
        
        # Gradient of score w.r.t. a (up to positive constant)
        # d(2n*max_b/S^2)/da_j = (2n/S^3)(S*grads_j - 2*max_b)

        direction = 2.0 * max_b / S - grads
        direction = direction - direction.mean()  # maintain sum (approx)
        
        v = gamma * v + direction
        a = np.clip(a + lr * v, 0.0, 1000.0)
        
        # Decay learning rate
        lr *= 0.9999
        
        if lr < 1e-8:
            break
    
    # Final validation
    final_score = float(evaluate_sequence(a.tolist()))
    if final_score < best_score:
        best = a.copy()
        best_score = final_score
    
    return [float(x) for x in best]

Score F(a) = 2n * b_{k*}(a) / S(a)^2

dF/da_j = (2n/S^2) * (db_{k*}/da_j) - (2n * b_{k*} / S^3) * (dS/da_j)
= (2n/S^2) * grads_j - (2n * max_b / S^3) * 1
= (2n/S^2) * (grads_j - max_b/S)

So the negative gradient (descent direction) is: -dF/da_j = (2n/S^2) * (max_b/S - grads_j)

Let me define: direction_j = max_b/S - grads_j (dropping the positive constant 2n/S^2)

Then we do: a_j += lr * direction_j

This means: elements where grads_j > max_b/S get decreased (they contribute too much to the peak), and elements where grads_j < max_b/S get increased.

The mean of direction is: (1/n) * sum_j (max_b/S - grads_j) = max_b/S - (1/n)*sum_j grads_j.

For k_star = n-1 (center): sum_j grads_j = sum_j 2*a_{n-1-j} = 2*sum a_i = 2S.
So mean direction = max_b/S - 2S/n.

If max_b < 2S^2/n (which is always true since max_b >= S^2/n), the mean is negative, meaning we're decreasing the average. We should subtract the mean to maintain the sum.
