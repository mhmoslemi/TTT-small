Let me think about whether the gradient descent will actually make progress from the uniform initialization. At the uniform point:
- c is triangular: c[k] = (k+1)/n² for k < n, c[k] = (2n-1-k)/n² for k ≥ n
- w = softmax(τ * c) is also triangular-shaped (peaked at center for large τ)
- grad[i] = 2 * sum_j a[j] * w[i+j] = 2/n * sum_j w[i+j] (since a[j] = 1/n)
- = 2/n * (sum of w from i to i+n-1)

For the uniform a, the sum of w from i to i+n-1 depends on i:
- For i near 0: sum of w[0] to w[n-1] (the rising part of the triangle)
- For i near n-1: sum of w[n-1] to w[2n-2] (the falling part)
- For i = n-1: sum of w[n-1] to w[2n-2]... wait, w has length 2n-1.

Actually, w[i+j] for j=0,...,n-1 means we're summing n consecutive elements of w starting at position i. For a triangular w (peak at n-1), the sum of n consecutive elements is maximized when centered at the peak. So the gradient is largest in the middle and smallest at the edges.

This means the descent direction REDUCES the middle values of a and increases the edge values. This makes sense: we want a to be "anti-symmetric" in some sense to reduce the central peak of the convolution.

So the gradient descent SHOULD make progress from the uniform! The issue is just whether the step size is appropriate and whether it converges to a good local minimum.

Let me also think about what the optimal solution looks like. If we could make c perfectly flat (c[k] = 1/(2n-1) for all k), then:
- sum c[k] = (2n-1) * 1/(2n-1) = 1 = (sum a)² ✓
- a would need to satisfy a*a = (1/(2n-1)) * ones(2n-1)
- In the FFT domain: |A|² = constant... but A² = constant (not |A|²)
- This means A[k]² = sqrt(1/(2n-1)) * exp(iθ_k) for all k
- A[k] = (1/sqrt(2n-1)) * exp(iθ_k/2)
- For a to be real: A[-k] = conj(A[k]), so A[k] = c * exp(iφ_k) with φ_{-k} = -φ_k
- And a[j] = (1/(2n-1)) * sum_k exp(iφ_k) * exp(2πikj/(2n-1))
- This gives a real sequence only for specific φ_k patterns

This is related to "flat-top" or "ideal" autocorrelation sequences. For real sequences, achieving perfectly flat convolution is generally impossible (except for n=1,2). But we can get close.

For the optimization, let me also consider using the "alternating direction" approach:
1. Fix a, compute optimal c (trivially c = a*a)
2. Project c to the "flattest" version (set all c[k] = max(c[k]))
3. Invert: find a such that a*a ≈ projected c (this is a quadratic system)

This is like the Goldreich-Levin or spectral method for finding sequences with good autocorrelation. But step 3 is nontrivial.

Actually, a simpler approach: use the fact that in the Fourier domain, c = a*a means C = A² (element-wise, for circular convolution with sufficient padding). If we want C to be flat (all C[k] = 1/(2n-1)), then A[k] = sqrt(1/(2n-1)) * exp(iφ_k/2). For a to be real, we need A[-k] = A[k]*, which means φ_{-k} = -φ_k (mod 4π).
