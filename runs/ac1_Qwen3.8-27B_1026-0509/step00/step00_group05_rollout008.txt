For the self-convolution `b = convolve(a, a)`:
`b[k] = sum_{j: max(0,k-n+1) <= j <= min(n-1,k)} a[j] * a[k-j]`

The gradient `∂b[k]/∂a[m]`:

- Both conditions give the same term when `m = k-m` i.e. `k = 2m`. In that case, the contribution is `a[m]^2` and the derivative is `2*a[m]`.
- Otherwise, the two appearances are distinct: `a[m]*a[k-m] + a[k-m]*a[m] = 2*a[k-m]`.

- First appearance: `a[m] * a[k-m]`, derivative w.r.t. `a[m]` is `a[k-m]`
- Second appearance: `a[k-m] * a[m]`, derivative w.r.t. `a[m]` is `a[k-m]`
- Total: `2*a[k-m]`

If `m = k-m` (i.e., `k = 2m`):
- Only one term: `a[m]^2`, derivative is `2*a[m]`
- Which is `2*a[k-m]` (same thing)
