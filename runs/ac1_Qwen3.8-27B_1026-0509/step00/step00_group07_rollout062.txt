conv[2i] includes the term a[i]² (when the shift is exactly 2i and i is valid). So conv[2i] >= a[i]².

But sum a[i]² is the sum over all i, while conv[2i] for a specific i is just one sum. The max over k of conv[k] is >= max_i a[i]², but not necessarily >= sum a[i]².

However, conv[n-1] = sum a[i]*a[n-1-i]. For non-negative a, by C-S:
conv[n-1] = <a, reverse(a)> <= ||a|| * ||reverse(a)|| = ||a||² = sum a[i]².

So conv[n-1] <= sum a[i]². And max conv >= conv[n-1] and >= max_i conv[2i] >= max_i a[i]².

But is max conv >= sum a[i]²? Not necessarily! The sum a[i]² is spread across many conv[k] values.

Example: a = [1, 1, 1]:
sum a[i]² = 3.
conv = [1, 2, 3, 2, 1]. Max = 3 = sum a[i]². ✓ (for symmetric)

a = [1, 2, 1] (symmetric): sum a[i]² = 6.
conv = [1, 4, 6, 4, 1]. Max = 6. ✓

a = [2, 1, 1] (asymmetric): sum a[i]² = 6.
conv[0] = 4, conv[1]
