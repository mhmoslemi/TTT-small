The standard algorithm (Golden & Jia, 2013):
```python
def project_simplex(v, S):
    # Project v onto {a >= 0, sum(a) = S}
    n = len(v)
    u = np.sort(v)[::-1]  # descending
    cssv = np.cumsum(u)
    rho = np.where(u * np.arange(1, n+1) > (cssv - S))[0][-1]
    theta = (cssv[rho] - S) / (rho + 1)
    return np.maximum(v - theta, 0)
```

This is $O(n \log n)$ due to sorting.
