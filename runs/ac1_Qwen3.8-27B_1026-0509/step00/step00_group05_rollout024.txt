Wait, I realize there might be an issue. The `compute_grad` function is called twice per iteration (once for the current point, once for the trial step). That doubles the cost. For n=4498, each call involves:
- One forward FFT of size 16384 (for convolution): ~0.1ms
- One forward FFT of size 16384 (for cross-corr): ~0.1ms
- One inverse FFT of size 16384: ~0.1ms
- Softmax over 8995 elements: ~0.01ms
Total: ~0.4ms per call, ~0.8ms per iteration.

In 1500 seconds: ~1.9 million iterations. That's more than enough.

But actually, I'm being wasteful. Let me restructure to compute the gradient only once per iteration and use a line search for the step size.

Also, I realize I should be more careful about the temperature. If τ is too small, the softmax is too peaked and the gradient is noisy. If τ is too large, we're not focusing on the actual maximum.

Let me use a "top-k" approach instead: compute the exact max, then compute a weighted average of gradients over the top k lags. This is more robust.

Actually, let me try a different approach: use the exact max for the "value" but the softmax for the "gradient direction". This is the "straight-through" estimator.

Or even simpler: just use the gradient at the single max lag (subgradient). This is the steepest descent for the non-smooth max function.

For the subgradient at the unique max:
∂max(c)/∂x[j] = ∂c[k*]/∂x[j] where k* = argmax c

This is: ∂c[k*]/∂x[j] = (2-δ_{k*,2j}) * x[k*-j] * 1[k*-j ∈ [0,n-1]]

This can be computed in O(n) without FFT!

And if multiple lags tie for the max, we average their subgradients.

Let me use this approach: it's simpler, faster, and more direct.

        c = np.convolve(x, x)
        s = x.sum()
        return float(2.0 * n * c.max() / (s * s))

    fft_size = 1
    while fft_size < 2 * n - 1:
        fft_size <<= 1
    fft_cc = 1
    while fft_cc < 3 * n - 2:
        fft_cc <<= 1

    def fast_conv(x):
        X = np.fft.rfft(x, fft_size)
        return np.fft.irfft(X * X, fft_size)[:2 * n - 1]

    def smooth_obj(x, tau):
        c = fast_conv(x)
        cm = c.max()
        e = np.exp((c - cm) / tau)
        tot = e.sum()
        L = cm / tau + np.log(tot)
        p = e / tot
        x_rev = x[::-1]
        Xr = np.fft.rfft(x_rev, fft_cc)
        P = np.fft.rfft(p, fft_cc)
        h = np.fft.irfft(Xr * P, fft_cc)[n - 1:2 * n - 1]
        idx2 = 2 * np.arange(n)
        valid = idx2 < 2 * n - 1
        corr = np.zeros(n)
        corr[valid] = p[idx2[valid]] * x[valid]
        grad = (2.0 * h - corr) / tau
        return L, grad, c
