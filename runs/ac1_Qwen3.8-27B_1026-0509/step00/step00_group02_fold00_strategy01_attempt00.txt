The goal is to iteratively reduce the maximum convolution value (automated constraint) while maintaining nonnegativity and respecting the coefficient cap. Minimize `AC1(f) = 2 * n * ||f * f||_∞ / ||f||₂²` (evaluated via clamped `evaluate_sequence`).

**Constraints:**  
- `fᵢ ≥ 0` for all `i`.  
- `fᵢ ≤ 1000` for all `i`.  
- `AC1(f)` is finite and ≥ min objective (1.50274).

**Solver Support:**  
- **Optimization:** Local search using gradient-free perturbations (no derivative needed), evaluated via evaluator.  
- **Feasibility:** Manual insertion of constraints ensures nonnegative and capped values.  
- **Scale:** Matrix-free, using time-series techniques with FFT-accelerated convolution.

### Implementation Procedure

**Steps:**  
1. **Initialization (`init_candidates`)**  
   - **Input:**  
     - `seed`: Random seed for reproducibility.  
     - `budget_s`: Total execution time in seconds.  
     - `seq_len = 6962` (fixed from `height_sequence_1`).  
   - **Output:** Initial valid sequence.  
   - **Steps:**  
     1. If `height_sequence_1` exists and valid, clone it and add a nominal step-function perturbation (e.g., a ±5% rate increase).  
     2. Otherwise, create a random step-function (e.g., n=178 uniform steps of magnitude 10).  
     3. Accept only sequences with `sum(a) ≥ 0.01`.  
     4. **Pseudocode:**  
        ```python
        if height_sequence_1 is not None:  
            init_seq = np.array(height_sequence_1) * 1.10
        else:  
            init_seq = np.ones(6962) * (0.01 / 6962)  # Sum=0.01, minimal autocorrelation peak.
        # Normalize to typical range, ensure nonnegative.
        init_seq = np.clip(init_seq * np.random.uniform(0.8, 1.2) + np.random.randn(6962) * 0.05, 0, 1000)
        ```

2. **Convolution Analysis (`analyze_constraints`)**  
   - **Purpose:** Extract indices in the convolution `b = f * f` where peaks occur.  
   - **Steps:**  
     1. Compute full convolution `b` (length 2*6962-1) via `np.convolve(sequence, mode='full')`.  
     2. `max_b = np.max(b)`, `sum_a = np.sum(sequence)`.  
     3. Identify active indices: `core_idx = argwhere(b == max_b)` but strictly, sparse active peaks near `M` (allow ±10% slack).  
     4. **Pseudocode:**  
        ```python
        def analyze_constraints(sequence):  
            b = np.convolve(sequence, sequence, mode='full')  
            max_val = np.max(b)  
            sum_val = np.sum(sequence)  
            if sum_val < 0.01 or np.any(np.isinf(sequence)) or np.any(np.isnan(sequence)):  
                return None, None  
            # Active peaks based on proximity to max_val (±5% window)  
            active_mask = np.abs(b - max_val) <= 0.05 * max_val  
            active_idx = np.arange(len(b))[active_mask]  
            return active_idx, max_val
        ```

3. **Iterative Update Ray (`create_ray_updates`)**  
   - **Purpose:** Generate signs of perturbation vectors to reduce peak autocorrelation.  
   - **Steps:**  
     1. For each active peak, downscale its influence by a factor (`1-scale_down`) and shift by a new random step.  
     2. Maintain magnitude constraints via normalization.  
     3. **Pseudocode:**  
        ```python
        def create_ray_updates(base_seq, active_peaks=['low', 'high', 'random']):  
            # 'low' reduces peaks, 'high' boosts valleys (escape local minima), 'random' changes sign arbitrarily  
            n = len(base_seq)  
            updates = np.zeros((n, 3))  # Three perturbation types per index.  
            for i in active_peaks:  
                if i == 'low':  
                    updates[i] = base_seq * 0.9  # Local shear to reduce peaks  
                elif i == 'high':  
                    updates[i] = base_seq * 1.1  # Boost non-active regions  
                elif i == 'random':  
                    updates[i] = np.random.choice([-1, 1], size=n) * base_seq * 0.95
        ```

4. **Budget-Aware Loop (`search_loop`)**  
   - **Purpose:** Balance exploration and exploitation within `budget_s`.  
   - **Steps:**  
     1. Use `zarr`-style partitioning: allocate `<total_time>` per stage (e.g., 60% refinement, 40% random sampling).  
     2. Compute wall-clock time for each step: `start_time`, `end_time`.  
     3. **Pseudocode:**  
        ```python
        deadline = time.time() + budget_s - 150  # Reserve time for final eval  
        stage_time = {'refine': 0.6, 'explore': 0.4}  
        last_update = {'refine': deadline, 'explore': deadline}
        ```

**Combined Execution:**  
1. ** Validation:** Use evaluator on all proposals.  
2. **Fallback:** Return valid fallback if initial steps fail: `np.ones(256) * (0.01 / 256)` (but force sequence length to `6962`).  
3. **Checkpoint:** Re-evaluate top `k=5` candidates periodically.

### Search Choices and Variations

**Phase 1: Refinement (60% budget)**  
- Narrow updates (length: 50 bins of 178 samples), targeted perturbations to reduce active peaks.  
- Polarity: random sign changes with probability `p=0.1` to introduce global structure.

**Phase 2: Exploration (40% budget)**  
- Wide-scale random injection within sampled windows (`p=0.2` top-candidates only).  
- Interval length: `min(1000, int(0.05 * n))` with uniform window size.

**Mitigation:**  
- **First Move:** Use parent seed to bias initial search.  
- **Sensitivity:** Tune λ (e.g., `β = 0.02`) for π adaptive step size based on last 5 AC1 values (low β means small steps for stability).

### Computation Budget and Robustness

**Estimates:**  
- **Convolution:** `evaluator` uses FFT; about 150ms per evaluation.  
- **Candidates:** Target 15-25 per time unit (avoid 1 evaluation/second for 1500 seconds!); use budget allocation to limit 150 evaluations during refinement.  
- **Fallback:** Return best of the first `10 candidates` if original `height_sequence_1` is invalid.  
- **Stability:** Clip all vectors after mutation. Use `try-except` around `evaluate_sequence` to recover.

**Explicit Responses:**  
- **Timeout:** Break loop if `time.time() > deadline`.  
- **NaN/Inf:** Check evaluator's score and skip candidates.  
- **No Improvement:** Reduce exploration rate by `50%` to favor fine-tuning.

### Validation and Return Contract

**Before Return:**  
1. **Feasibility:** Check `0 ≤ fᵢ ≤ 1000` and `np.sum(f) ≥ 0.01` for `evaluator`’s support.  
2. **Score:** Evaluate final candidate via `evaluator` and return `<= 1.50274` for success.  
3. **Fallback Format:** If early timeout, `np.ones(6962) * X` where `X = max(1000, sum(diff/25))`.

**Return Format:** `[float(x) for x in best_candidate.tolist()]`.
