import time
from scipy.fft import fft, ifft, next_fast_len

    deadline = time.monotonic() + budget_s - 5.0
    rng = np.random.default_rng(seed)
    
    # Get parent
    try:
        p0 = np.asarray(height_sequence_1, dtype=np.float64).flatten()
        p0 = np.clip(p0, 0.0, 1000.0)
        n = p0.size
    except Exception:
        n = 6733
        p0 = None
    
    if p0 is None or n < 10 or p0.sum() < 0.01:
        p0 = np.ones(n)
    
    p0 = p0 / p0.sum()
    
    # FFT setup
    conv_len = next_fast_len(2 * n - 1)
    
    def do_conv(x):
        X = fft(x, conv_len)
        return np.real(ifft(X * X)[:2 * n - 1])
    
    def compute_score(x):
        b = do_conv(x)
        return float(2.0 * n * b.max() / (x.sum() ** 2))
    
    # Simplex projection (project onto {x >= 0, sum(x) = 1})
    def proj_simplex(v):
        n = v.size
        u = np.sort(v)[::-1]
        cv = np.cumsum(u)
        rho = np.where(u * np.arange(1, n + 1) > cv - 1)[0]
        if rho.size == 0:
            return np.ones(n) / n
        r = rho[-1]
        theta = (cv[r] - 1.0) / (r + 1.0)
        return np.maximum(v - theta, 0.0)
    
    best = p0.copy()
    best_s = compute_score(p0)
    
    # Phase 1: Subgradient descent with top-K smoothing
    topK = 5
    alpha = 0.002
    no_improve = 0
    
    while time.monotonic() < deadline:
        b = do_conv(best)
        # Top-K lags
        idx = np.argpartition(b, -topK)[-topK:]
        idx_order = idx[np.argsort(b[idx])[::-1]]
        
        # Accumulate subgradient
        g = np.zeros(n)
        for k in idx_order:
            k = int(k)
            lo = max(0, k - n + 1)
            hi = min(n - 1, k)
            if lo <= hi:
                j = np.arange(lo, hi + 1)
                g[j] += best[k - j]

   - Phase B: Fix the values and optimize the support (add/remove positions).

4. **Use the structure of the problem**: Since the convolution is a quadratic form, we can write:
   b[k] = p^T C_k p  where C_k is a symmetric matrix (the "cross-correlation" matrix at lag k).
   
   The objective is max_k p^T C_k p. This is a "min-max quadratic" problem.

For the min-max quadratic problem, there's a connection to eigenvalue optimization. Specifically:
min_p max_k p^T C_k p  s.t. ||p||_1 = 1, p >= 0

At the optimum, we expect several C_k to be "active" (achieving the max simultaneously).

**Alternative approach: Use scipy.optimize.minimize**

I could formulate this as:
min f(p) = max_k (p*p)[k]  s.t. p >= 0, sum(p) = 1

Using scipy.optimize.minimize with SLSQP or trust-constr, providing the gradient.

But for n=6733, SLSQP might be too slow (it uses a dense Hessian approximation).

**Better: Use scipy.optimize.minimize with L-BFGS-B**

L-BFGS-B is designed for large-scale problems and uses only first derivatives. But it requires a smooth objective. I can smooth the max with a softmax:
f_ε(p) = ε * log(sum_k exp(b[k]/ε))

This is a smooth approximation of max_k b[k], and its gradient is:
∇f_ε(p) = sum_k (exp(b[k]/ε) / sum_j exp(b[j]/ε)) * ∇b[k]

For small ε, this approximates the subgradient of the max. For larger ε, it's smoother but less accurate.

This might converge faster than the subgradient method because L-BFGS-B uses second-order information (approximated) to take better steps.

**Better approach: Direct optimization of the "shape" with a parameterization.**

Since the problem is scale-invariant, I can fix the sum and optimize the shape. But the shape lives on the simplex, which is a high-dimensional constraint set.

The gradient of the objective w.r.t. v is:

Wait, for the softmax parameterization:
∂p[i]/∂v[j] = p[i](δ_{ij} - p[j])

So ∂f/∂v[j] = Σ_i (∂f/∂p[i]) * p[i](δ_{ij} - p[j])
= p[j] * ∂f/∂p[j] - p[j] * Σ_i p[i] * ∂f/∂p[i]

This is the "centered" gradient. It automatically preserves the sum constraint.

import numpy as np
import time
from scipy.fft import fft, ifft, next_fast_len

def propose_candidate(seed=42, budget_s=1500, **kwargs):
    deadline = time.monotonic() + budget_s - 5.0
    rng = np.random.default_rng(seed)
    
    # Get parent
    try:
        p0 = np.asarray(height_sequence_1, dtype=np.float64).flatten()
        p0 = np.clip(p0, 0.0, 1000.0)
        n = p0.size
    except Exception:
        n = 6733
        p0 = np.ones(n)
    
    if p0.size != n or p0.sum() < 0.01:
        p0 = np.ones(n)
    p0 = p0 / p0.sum()
    
    conv_len = next_fast_len(2 * n - 1)
    b_len = 2 * n - 1
    
    def do_conv(x):
        X = fft(x, conv_len)
        return np.real(ifft(X * X)[:b_len])
    
    def scores(x):
        b = do_conv(x)
        return 2.0 * n * b.max() / (x.sum() ** 2)
    
    def proj_simplex(v):
        n = v.size
        u = np.sort(v)[::-1]
        cv = np.cumsum(u)
        rho = np.where(u * np.arange(1, n + 1) > cv - 1)[0]
        if rho.size == 0:
            return np.ones(n) / n
        r = rho[-1]
        theta = (cv[r] - 1.0) / (r + 1.0)
        w = np.maximum(v - theta, 0.0)
        return w / w.sum()
    
    def smooth_grad(p, b, K=10):
        idx = np.argpartition(b, -K)[-K:]
        w = b[idx] ** 2  # weight by squared values to emphasize peaks
        w /= w.sum()
        g = np.zeros(p.size)
        for ki in range(K):
            k = int(idx[ki])
            lo = max(0, k - p.size + 1)
            hi = min(p.size - 1, k)
            if lo <= hi:
                j = np.arange(lo, hi + 1)
                g[j] += w[ki] * p[k - j]
        return 2.0 * g
    
    # Optimization
    best = p0.copy()
    best_s = scores(best)
    
    # Try different initializations
    inits = [p0.copy()]
    # Random
    inits.append(proj_simplex(0.1 * rng.standard_normal(n)))
    # Cosine taper
    j = np.arange(n)
    inits.append(proj_simplex(0.5 + 0.5 * np.cos(2 * np.pi * j / n)))
    # Gaussian
    center = n // 2
    inits.append(proj_simplex(np.exp(-0.5 * ((j - center) / (n/8))**2)))
    
    for init in inits:
        if time.monotonic() > deadline:
            break
        p = init.copy()
        alpha = 0.003
        momentum = np.zeros(n)
        beta = 0.9
        no_imp = 0
        
        while time.monotonic() < deadline and no_imp < 10000:
            b = do_conv(p)
            g = smooth_grad(p, b, K=10)
            
            # Nesterov momentum
            momentum = beta * momentum + (1 - beta) * g
            p_new = proj_simplex(p - alpha * momentum)
            
            s_new = scores(p_new)
            if s_new < best_s:
                best = p_new
                best_s = s_new
                no_imp = 0
                alpha = min(0.01, alpha * 1.002)
            else:
                no_imp += 1
                alpha = max(0.0002, alpha * 0.998)
            
            p = p_new
        
        # Random restart within this init
        if time.monotonic() < deadline:
            p = proj_simplex(best + 0.005 * rng.standard_normal(n))
            alpha = 0.003
            momentum = np.zeros(n)
            no_imp = 0
            while time.monotonic() < deadline and no_imp < 5000:

                g = smooth_grad(p, b, K=10)
                momentum = beta * momentum + (1 - beta) * g
                p_new = proj_simplex(p - alpha * momentum)
                s_new = scores(p_new)
                if s_new < best_s:
                    best = p_new
                    best_s = s_new
                    no_imp = 0
                else:
                    no_imp += 1
                    alpha = max(0.0002, alpha * 0.998)
                p = p_new
    
    result = [float(x) for x in best]
    s_final = evaluate_sequence(result)
    if not np.isfinite(s_final):
        result = [float(x) for x in p0]
    return result

The key issue: the subgradient method converges slowly (O(1/√T) for convex problems, and this is non-convex). For n=6733, the landscape is complex.

Let me think about a completely different approach that might be more effective.

**Alternative: "Spectral" approach**

In the frequency domain, the autocorrelation is the inverse DFT of the power spectrum |P(k)|². We want the autocorrelation to be as flat as possible, which means the power spectrum should be as concentrated at k=0 as possible.

But p ≥ 0 constrains what power spectra are achievable.

Key insight: if p is a "measurement" (like a probability distribution), then its DFT P(k) = Σ_j p[j] e^{-2πikj/n} has P(0) = 1 and |P(k)| ≤ 1 for all k.

The power spectrum |P(k)|² has |P(0)|² = 1 and |P(k)|² ≤ 1 for k≠0.

The autocorrelation b = IDFT(|P|²) (approximately, for the circular case). For b to be flat (= 1/n approximately), we need |P(k)|² to be concentrated at k=0, i.e., |P(k)| ≈ 0 for k≠0.

This means p should be "smooth" (low-pass). The smoothest non-negative function with fixed integral is... well, it depends on the smoothness constraint.

If p is a Gaussian: P(k) is also Gaussian (in the continuous case), concentrated at k=0. The autocorrelation is a broader Gaussian. The peak of the autocorrelation is ∫p² dx = 1/(σ√(2π)) for p(x) = exp(-x²/2σ²)/(σ√(2π)).

For the discrete case with n points and σ = n/4: peak ≈ 1/((n/4)√(2π)) = 4/(n√(2π)) ≈ 4/(3.24n) ≈ 1.23/n.
Score = 2n * 1.23/n = 2.47. Worse than uniform!

So Gaussian is bad. The uniform is better because it has the minimum L2 norm (by Cauchy-Schwarz) among all distributions on n points.

This confirms: for non-negative p on n consecutive points, the uniform minimizes (p*p)[0] = ||p||². And since (p*p)[0] is the maximum (for "well-behaved" p), the uniform is close to optimal.

But wait, I showed earlier that (p*p)[0] is NOT always the maximum. For p=[1,2,3], the max was at lag 3, not lag 0 (or the center). So the question is: among non-negative p, what's the minimum possible max of the full linear convolution?

I think the answer is slightly below 1/n (the uniform value), and the optimal sequence is slightly non-uniform.

Let me try a specific construction: p[j] = 1/n * (1 + a * (-1)^j) (alternating perturbation).
For small a: this creates a "ripple" in the sequence.
b[k] = Σ_i p[i]*p[k-i] (for the full convolution).

For the center (k=n-1): b[n-1] = Σ_i p[i]*p[n-1-i].
If n is even and we pair i with n-1-i: p[i]*p[n-1-i] = (1/n²)(1+a*(-1)^i)(1+a*(-1)^{n-1-i}).
If n-1 is odd (n even), then (-1)^{n-1-i} = (-1)^{1-i} = -(-1)^i.
So p[i]*p[n-1-i] = (1/n²)(1+a*(-1)^i)(1-a*(-1)^i) = (1/n²)(1-a²).
b[n-1] = n * (1-a²)/n² = (1-a²)/n.

For k ≠ n-1, the cross terms won't cancel as nicely, and some b[k] will be larger than (1-a²)/n.
