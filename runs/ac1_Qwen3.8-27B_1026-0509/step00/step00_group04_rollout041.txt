Actually, let me think about this more carefully. We want to minimize `max(b)` subject to `sum(a) = 1, a >= 0`.

The Lagrangian is `L = max(b) - lambda * (sum(a) - 1) + mu^T * (-a)` where `mu >= 0`.

KKT conditions:
- For `a_i > 0`: `d(max(b))/da_i = lambda`
- For `a_i = 0`: `d(max(b))/da_i <= lambda`
- `sum(a) = 1`
- Complementarity: `mu_i * a_i = 0`

So at the optimum, for all positive entries, the subgradient of `max(b)` should be constant (= lambda). This suggests an algorithm:

1. Compute subgradient `g = d(max(b))/da`
2. For positive entries, we want `g_i` to be as equal as possible
3. Update: reduce entries where `g_i` is large, increase where `g_i` is small

This is like a multiplicative weight update! 

**Multiplicative weight / mirror descent approach:**

Update: `a_i <- a_i * exp(-lr * (g_i - lambda))` where `lambda = average of g_i over positive entries` (or the mean of g).

This is the mirror descent / multiplicative weights algorithm for the problem. It naturally maintains non-negativity and we can rescale to maintain the sum constraint.

Let me think about this more formally. The problem:
minimize `f(a) = max_k (a*a)_k`
subject to `1^T a = 1, a >= 0`

Mirror descent with entropy prox:
`a^{t+1} = argmin_{a >= 0, 1^T a = 1} <g^t, a> + (1/eta) * D_KL(a || a^t)`

where `g^t` is the subgradient and `D_KL(a||b) = sum a_i log(a_i/b_i)`.

The solution to this is: `a_i^{t+1} = a_i^t * exp(-eta * g_i^t) / Z` where `Z = sum_j a_j^t * exp(-eta * g_j^t)`.

This is exactly the multiplicative weight update! And it's computationally efficient - just a few vector operations per iteration.
