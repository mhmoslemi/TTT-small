import numpy as np
import scipy.sparse as sp
from scipy.optimize import linprog
import time

def build_convolution_matrix(a, n):
    """Build sparse matrix A where (A@g)[k] = (a*g)[k]."""
    rows, cols, vals = [], [], []
    for k in range(2*n - 1):
        i_start = max(0, k - n + 1)
        i_end = min(k, n - 1)
        if i_start <= i_end:
            idx = np.arange(i_start, i_end + 1)
            rows.extend([k] * len(idx))
            cols.extend(idx.tolist())
            vals.extend(a[idx].tolist())
    A = sp.csc_matrix((vals, (rows, cols)), shape=(2*n-1, n))
    return A

Key insight for local search: the score is roughly 2*n*max(a*a)/(sum a)². To reduce max(a*a), I want to make the sequence more "spread out" in its convolution. A good heuristic: at each step, find the lag k* where (a*a)[k*] is maximum, and reduce the "concentration" at that lag by adjusting a[i] and a[k*-i] (making them less correlated).

For example: if (a*a)[k*] is at its max, and the dominant contribution is from a[i]*a[k*-i] for some i, then decreasing a[i] while increasing a[j] (where j is far from both i and k*-i) might help.

This is essentially what the LP does, but in a more targeted way. Let me implement a "targeted perturbation" local search:

```python
def targeted_perturbation(a, rng, n):
    c = np.convolve(a, a, mode='full')
    k_star = np.argmax(c)
    # Find the pair (i, k_star-i) that contributes most to c[k_star]
    i_range = range(max(0, k_star-n+1), min(k_star, n-1)+1)
    contributions = [a[i]*a[k_star-i] for i in i_range]
    i_max = list(i_range)[np.argmax(contributions)]
    j_max = k_star - i_max
    
    # Transfer mass from the high-contribution pair
    delta = 0.01 * (a[i_max] + a[j_max])
    a_new = a.copy()
    a_new[i_max] -= delta * 0.5
    if j_max != i_max:
        a_new[j_max] -= delta * 0.5
    # Add to a random far position
    j_new = rng.integers(0, n)
    a_new[j_new] += delta
    a_new = np.maximum(a_new, 0)
    return a_new
```
