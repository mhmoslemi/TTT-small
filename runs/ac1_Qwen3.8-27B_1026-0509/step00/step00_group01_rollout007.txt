   This is O(n) to compute. And the convolution C = np.convolve(f, f) is O(n log n) with FFT.

   So the overall algorithm:
   1. Compute C = fft_convolve(f, f) (O(n log n))
   2. Find k* = argmax(C)
   3. Compute subgradient sg (O(n))
   4. Take a gradient step: f_new = f - α * sg (for minimizing sum C_k, or for the max, use the subgradient)
   5. Project onto {f >= 0, sum f = 1}
   6. Repeat

   But this is only a subgradient method for the max, which converges slowly. Better to use the log-sum-exp smoothing:
   smooth_max(C, τ) = τ * log(sum(exp(C_k/τ)))
   Its gradient is well-defined and smooth.

   For the full problem with sum f = 1:
   minimize τ * log(sum(exp(C_k/τ))) subject to f >= 0, sum f = 1.
