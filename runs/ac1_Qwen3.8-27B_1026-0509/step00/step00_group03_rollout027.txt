Where A = {k : alpha_k > 0} is the active set.

Let me try a more aggressive optimization approach. Instead of subgradient descent, let's use a "top-K gradient" method where we average the gradients over the top K values of c. This gives a better direction than a single subgradient.

```python
def top_k_gradient(p, c, K=10):
    n = len(p)
    top_idx = np.argpartition(c, -K)[-K:]  # indices of K largest values
    weights = c[top_idx] / c[top_idx].sum()  # normalize weights
    g = np.zeros(n)
    for k in top_idx:
        idx = k - np.arange(n)
        valid = (idx >= 0) & (idx < n)
        g[valid] += weights[top_idx.tolist().index(k)] * 2.0 * p[idx[valid]]
    return g
```
