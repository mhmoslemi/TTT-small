**Approach: Iterative flattening**

The idea is:
1. Compute the autocorrelation b = conv(a, a)
2. Compute the "target" autocorrelation: a flat spectrum, or the minimum achievable autocorrelation
3. Update a to move its autocorrelation toward the target

This is similar to the Gerchberg-Saxton algorithm or the error reduction method in phase retrieval.

Specifically:
1. Compute b = conv(a, a)
2. Compute b_target = b / max(b) * min_other (flatten the peaks)
3. In the frequency domain: A = FFT(a), then |A|^2 = FFT(b)
4. Modify |A|^2 to have a flatter spectrum
5. Inverse FFT to get new a
6. Project to a >= 0 and sum(a) = 1

But this doesn't directly minimize the peak. Let me think of a simpler version.

**Iterative peak reduction:**
1. Compute b = conv(a, a)
2. Find the peak location k*
3. The peak b[k*] = sum_i a[i] * a[k*-i]
4. To reduce this peak, we want to reduce the product a[i]*a[k*-i] for the contributing i's
5. This suggests reducing a[i] for i that contribute most to the peak

A simple heuristic:
- g[i] = a[k*-i] (the "partner" of a[i] in the peak)
- Update: a[i] ← a[i] - eta * g[i] (reduce a[i] proportional to how much it contributes to the peak)
- Project to a >= 0, sum(a) = 1

This is essentially a multiplicative update: a[i] ← a[i] * (1 - eta * a[k*-i] / a[i]) = a[i] - eta * a[k*-i]

But this might not work well because it only addresses one peak at a time.
