= n[1-2c+c^2+2c+2c^2/3]
= n[1+c^2+2c^2/3]
= n[1+5c^2/3]

Wait, that's LARGER than the uniform n! That can't be right for large c.

Let me recheck. αβn = (1-c)*2c/(n-1)*n ≈ 2c(1-c) for large n.
α^2 + αβn + β^2*n(n+1)/6 ≈ (1-c)^2 + 2c(1-c) + 2c^2/3
= 1-2c+c^2+2c-2c^2+2c^2/3
= 1-c^2+2c^2/3
= 1-c^2/3

So conv[n] ≈ n(1-c^2/3). Same as conv[n-1]!

Let me recheck conv[n-1]:
α^2 + αβ(n-1) + β^2(n+1)(n-2)/6
= (1-c)^2 + (1-c)*2c + 4c^2(n+1)(n-2)/(6(n-1)^2)
= 1-2c+c^2+2c-2c^2+2c^2/3*(approx)
= 1-c^2+2c^2/3
= 1-c^2/3

Yes! So both center lags give ≈ n(1-c^2/3).

Now what about the endpoints? conv[0] = α^2 = (1-c)^2, conv[2n-2] = (α+β(n-1))^2 = (1+c)^2.
For c=0.3: conv[0] ≈ 0.49, conv[2n-2] ≈ 1.69. Both much less than n(1-c^2/3) for large n.

What about intermediate lags? For k << n, conv[k] ≈ (k+1)[1+c(c)(k)/(n) + ...] ≈ k+1 (small).
For k ≈ n/2, conv[k] ≈ (k+1)[1+c^2/3 + ...] which is about n/2 * (1+c^2/3), much less than n(1-c^2/3).

So for the linear ramp, the max convolution is at the center, with value ≈ n(1-c^2/3), and:
score ≈ 2n * n(1-c^2/3) / (n(1+c*(0)))^2

Wait, what's the sum? sum = n*α + β*n(n-1)/2 = n(1-c) + 2c/(n-1) * n(n-1)/2 = n(1-c) + cn = n.

Oh great, the sum is still n! Because the linear ramp is symmetric about 1.

So score ≈ 2n * n(1-c^2/3) / n^2 = 2(1-c^2/3).
