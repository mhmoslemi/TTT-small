At ε = 1/3: a = [4/3, 2/3]. c = [16/9, 16/9, 4/9]. max = 16/9. score = 4*(16/9)/4 = 16/9 ≈ 1.78. This matches [2,1] (just scaled)!

So the optimal for n=2 is at the boundary where c[0] = c[1], i.e., the peak is "shared" between two locations. This gives score 16/9.

This suggests that the optimal strategy is to "equalize" the peaks of the convolution. The optimal sequence is one where multiple elements of c are tied at the maximum.

For larger n, the optimal would have many elements of c tied at the maximum, making the convolution as "flat-topped" as possible.

This is a key insight! The optimal sequence makes the convolution as flat as possible (in the sense of minimizing the maximum, the peaks should be spread out).

With this understanding, the gradient method should work: it will push down the peaks and the flat-top will emerge naturally.

            break

        max_c = c.max()

            best = a.copy()
        
        # Smoothed gradient
        shifted = c - max_c
        exp_T = np.exp(T * shifted)
        p = exp_T / exp_T.sum()
        
        # Gradient: g[i] = 2 * sum_j p[i+j] * a[j]
        g = 2.0 * np.correlate(p, a, mode='valid')

        s = a_try.sum()
        if s < 1e-15:
            eta *= 0.5
            continue
        a_try /= s
        
        # Evaluate
        c_try = np.convolve(a_try, a_try, mode='full')
        if c_try.max() < max_c:
            a = a_try
            eta = min(eta * 1.02, 1.0)
        else:
            eta *= 0.5
            if eta < 1e-6:
                # Restart with perturbation
                a = a + 0.01 * rng.standard_normal(n)
                a = np.maximum(a, 0)
                a /= a.sum()
                eta = 0.1
                T = max(T * 0.8, 5.0)
        
        # Decrease T over time to sharpen the gradient
        T = max(T * 0.9999, 50.0)  # keep T high for sharp max approximation
        
    # Final check
    final = best.tolist()
    final_score = float(evaluate_sequence(final))
    if not np.isfinite(final_score):
        final = [1.0]
    
    return final
