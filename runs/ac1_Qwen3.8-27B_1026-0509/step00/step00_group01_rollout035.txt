For small n, this is a well-defined finite-dimensional problem. Let me use scipy's SLSQP or trust-constr with the constraint sum(f)=1, f≥0.

But the objective max(conv(f,f)) is not smooth (it's the max of multiple quadratic forms). However, we can use the fact that it's the max of smooth functions and use a smoothing technique, or just use a derivative-free method.

Actually, for Nelder-Mead, we don't need gradients. And for n up to 10-15, the simplex dimension is manageable.

Let me also try a "warm start" approach: start from the uniform sequence and use the LP iteration.

import time

def compute_score(f):
    """Direct score computation."""
    n = len(f)
    s = f.sum()
    if s < 0.01:
        return np.inf
    conv = np.convolve(f, f)
    return 2.0 * n * conv.max() / (s * s)

def lp_step(f, M):
    """Solve LP: max sum(g) s.t. conv(f,g) <= M, g >= 0.
    Returns optimal g or None if infeasible/too large."""
    n = len(f)

    # A[m, j] = f[j] if 0 <= m-j < n (i.e., j in [max(0,m-n+1), min(n-1,m)])
    # Actually: conv(f,g)[m] = sum_j f[j]*g[m-j], so A[m, k] = f[m-k] if 0<=m-k<n and 0<=k<n
    
    # This is a banded matrix. Let's use scipy.sparse.
    from scipy.sparse import csr_matrix
    
    rows = []
    cols = []
    vals = []

        j_start = max(0, m - n + 1)
        j_end = min(n - 1, m)

            # A[m, k] = f[m-k] if 0 <= m-k < n
            idx = m - k
            if 0 <= idx < n:
                rows.append(m)
                cols.append(k)
                vals.append(f[idx])
    
    A = csr_matrix((vals, (rows, cols)), shape=(2*n-1, n))
