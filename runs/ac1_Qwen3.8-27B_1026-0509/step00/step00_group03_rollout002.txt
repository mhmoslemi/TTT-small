∂conv(n-1)/∂a_i = a_{n-1-i} + a_{n-1-i} = 2*a_{n-1-i}.

For general k in [0, 2n-2]:
The gradient is a "shifted" version of a, possibly with two contributions.

Practically, I can compute the gradient of conv at the active lag(s) using the formula above.

Algorithm:
1. Normalize a so sum(a) = 1 (or sqrt(2n)).
2. Find k* = argmax conv(a).
3. Compute g = ∂conv(k*)/∂a (a vector of length n).
4. Take a step: a_new = a - lr * g, project to a ≥ 0, re-normalize sum.
5. Repeat.

But this only works for a single active constraint. In practice, multiple lags might be near the maximum. A better approach:

1. Find the top few lags by conv value.
2. Compute combined gradient: g = sum_{k in active} w_k * ∂conv(k)/∂a where w_k ∝ (conv(k) - threshold) or just equal weights for the top few.
3. Step and project.

Even better: use a "max-like" smooth approximation. Replace max(conv) with a soft-max: logsumexp(conv/t) for small t. Then the gradient is:
∂/∂a_i [logsumexp_k conv(k)/t] = (1/t) * sum_k exp(conv(k)/t) * ∂conv(k)/∂a_i / sum_k exp(conv(k)/t)

This is always well-defined and smooth.
