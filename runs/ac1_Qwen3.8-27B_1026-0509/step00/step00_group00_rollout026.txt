- Simplest: use $\lambda_k = 1/|K|$ for all $k \in K$ (uniform)
- Or use $\lambda_k = 1$ for the single $k$ that achieves the max (if unique)

The linear minimization over the simplex: $\min_{x \geq 0, \sum x = 1} g^T x = \min_j g_j$ (achieved by $x = e_{j^*}$ where $j^* = \arg\min_j g_j$).

So the Frank-Wolfe update is: $a \leftarrow (1-t)a + t \cdot e_{j^*}$ where $j^* = \arg\min_j g_j$.

This is very simple! But it only updates one coordinate at a time, so it might be slow.

A variant: use the "away step" Frank-Wolfe or the "pairwise" Frank-Wolfe for faster convergence.

But actually, for our problem, the Frank-Wolfe method might not be the best choice because:
1. The function $\max_k (a*a)_k$ is the max of many convex functions, so it's convex but not smooth.
2. Frank-Wolfe works best for smooth convex objectives.

Let me stick with the LP-based approach (best response) which is more powerful.

Let me also consider: instead of solving the full LP, I can use a simpler approximation.

**Simpler approach: Greedy coordinate descent**

At each step:
1. Compute $g_k = (a*a)_k$ for all $k$
2. Find the $k^*$ that achieves the max
3. Compute the subgradient: $g_j = 2a_{k^*-j}$ (using the single active constraint)
4. Find $j^* = \arg\min_j g_j$ (the coordinate to increase)
5. Update: $a_{j^*} \leftarrow a_{j^*} + \delta$, and renormalize

This is a simple projected gradient step. It's O(n) per iteration (computing the subgradient) plus O(n) for the convolution update.

But the convolution needs to be recomputed, which is O(n^2) naively or O(n log n) with FFT.

With FFT, each iteration is O(n log n). In 1500 seconds, I can do millions of iterations. This might work!

Let me think about this more carefully. The "greedy" approach:

1. Start with $a$ (sorted, normalized to sum 1)
2. Compute $c = a*a$ (via FFT)
3. Find $k^* = \arg\max_k c_k$
4. Compute gradient: $g_j = 2 a_{k^*-j}$ for valid $j$ (i.e., $0 \leq k^*-j \leq n-1$), else $g_j = 0$
5. The direction of steepest descent on the simplex is: decrease $a_j$ for large $g_j$ and increase for small $g_j$
6. Simplest: $a_{j^*} += \epsilon$ where $j^* = \arg\min_j g_j$ (among coordinates with $a_j > 0$), and $a_j -= \epsilon$ for coordinate with max $g_j$ (among non-zero)
7. Renormalize
