$(a*a)_k = \sum_i a_i a_{k-i}$ (sum over valid $i$)

$\frac{\partial (a*a)_k}{\partial a_j}$:
- In the sum, $a_j$ appears:
  - As $a_i$ when $i = j$: contributes $a_{k-j}$
  - As $a_{k-i}$ when $k-i = j$, i.e., $i = k-j$: contributes $a_j$
- If $j = k-j$ (i.e., $2j = k$): it's a single term $a_j^2$, derivative is $2a_j$
- If $j \neq k-j$: two terms, derivative is $a_{k-j} + a_j$
- Additionally, we need $k-j$ to be in $[0, n-1]$ for the first term to exist, and $k-j$ to be in $[0, n-1]$ for the second (which is the same condition since $i = k-j$ needs to be in $[0, n-1]$).

So: $\frac{\partial (a*a)_k}{\partial a_j} = (a_{k-j} + a_j) \cdot \mathbf{1}[0 \leq k-j \leq n-1]$

For $j$ from $js$ to $je$: $k - j$ goes from $k - js$ to $k - je$.
- $k - js = k - \max(0, k-n+1)$:
  - If $k \geq n-1$: $k - (k-n+1) = n-1$
  - If $k < n-1$: $k - 0 = k$
  - So $k - js = \min(k, n-1) = je$
- $k - je = k - \min(k, n-1)$:
  - If $k \leq n-1$: $k - k = 0$
  - If $k > n-1$: $k - (n-1) = k - n + 1$
  - So $k - je = \max(0, k-n+1) = js$

So as $j$ goes from $js$ to $je$, $k-j$ goes from $je$ to $js$ (decreasing).

In NumPy: `a[k-j]` for $j$ in range $[js, je]$ is `a[je:js-1:-1]` (if $js < je$) or `a[js]` (if $js = je$).

Let me also think about whether the simple "clip and normalize" projection is adequate. The issue is that clipping to 0 and then normalizing can cause a large change in the sequence (if many components get clipped). A better projection would be the Euclidean simplex projection, which can be done in $O(n \log n)$ time.

The Euclidean simplex projection of a vector $v$ onto $\{x : x \geq 0, \sum x_i = 1\}$ is:
$x_i = \max(v_i - \tau, 0)$ where $\tau$ is chosen so that $\sum_i \max(v_i - \tau, 0) = 1$.

$\tau$ can be found by sorting $v$ and using the formula:
$\tau = \frac{1}{b} \left(\sum_{i=1}^{b} v_{(i)} - 1\right)$ where $b$ is the largest index such that $v_{(b)} - \frac{1}{b}(\sum_{i=1}^{b} v_{(i)} - 1) > 0$.

This is $O(n \log n)$ due to sorting. For $n = 4806$, this is fast.
