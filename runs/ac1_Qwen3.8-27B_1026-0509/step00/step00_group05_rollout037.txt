**Simpler iterative method: "chasing the peak"**

1. Compute c = conv(x), M = max(c)
2. Find the argmax position k* of c
3. The constraint c[k*] = sum_i x[i]*x[k*-i] <= M is "tight"
4. To reduce c[k*], we should reduce x[i] for the i that contribute most to c[k*]
5. Specifically, reduce x[i] *proportionally* to x[i]*x[k*-i] (or x[k*-i] if we're updating x[i])

This gives the update: x[i] *= (1 - eta * x[k*-i] / M) for the i that contribute to peak position k*.

This is O(n) per step (just updating the n values that interact with the peak position). Very fast!

But it only addresses ONE peak position at a time. For a better approach, address all "hot" positions simultaneously.

**Multi-peak chasing:**

1. Compute c = conv(x), M = max(c)
2. For each position k where c[k] > 0.9*M, compute the "pressure" on each x[i]:
   pressure[i] += x[k-i] * weight[k]
3. Update: x[i] *= (1 - eta * pressure[i] / max_pressure)

The pressure computation is O(n * num_hot_positions), which is O(n^2) in the worst case but typically much less.

This is equivalent to: exp(-eta * pressure[i] / pmax) = constant for all i, i.e., pressure[i] = constant for all i.

So the fixed point is when pressure[i] is constant for all i (among those with x[i] > 0).

pressure[i] = sum_j w[j+i] * x[j] (where w is the normalized convolution).

At the fixed point: sum_j w[j+i] * x[j] = c (constant) for all i.

This means: (w * reversed_x)[i + n - 1] = c for all valid i.

In other words, the convolution of w and reversed_x is constant. Since w is (a function of) the convolution of x with itself, this is a self-consistency equation.

This is analogous to the "eigenfunction" condition in power iteration. The fixed point is a "self-convolution eigenfunction."
