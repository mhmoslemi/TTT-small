**Gradient-based approach:**
Since max_k (a*a)[k] is piecewise quadratic (quadratic in each region where a particular k is the argmax), we can do:

2. Compute the gradient of (a*a)[k*] with respect to a: grad[j] = 2*a[k*-j] (if 0 ≤ k*-j < n).
3. Take a step in the negative gradient direction, projected onto the feasible set (a ≥ 0, sum(a) = 1).
4. Repeat.

The gradient step: a_new = a - η * grad, then project onto {a ≥ 0, sum(a) = 1}.

The projection onto {a ≥ 0, sum(a) = 1} can be done in O(n log n) using a water-filling algorithm.

    """Project v onto the probability simplex {x >= 0, sum(x) = 1}."""
    n = len(v)
