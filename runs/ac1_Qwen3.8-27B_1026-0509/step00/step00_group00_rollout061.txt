3. Update y_k ← y_k / max(1, (Ab)_k / M) (or similar)
4. Repeat

Actually, the peak reduction algorithm works differently:
1. Start with a (complex, in this case real nonnegative)
2. Compute A = FFT(a), get |A|^2 = power spectrum
3. Autocorr = IFFT(|A|^2)
4. Modify autocorr: clip peaks above threshold
5. Get new |A'|^2 = FFT(autocorr_modified)
6. Keep the phase of A: A' = |A'| * exp(i*angle(A))
7. a' = IFFT(A')
8. Enforce constraints (nonnegativity, etc.)
9. Repeat

This preserves the magnitude spectrum approximately while reducing peaks in the autocorrelation. But for nonnegative sequences, the "phase" is either 0 or π (real signal), so this might not work as well.
