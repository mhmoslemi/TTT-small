conv(x,x) = ifft(fft(x) * fft(x)) (with zero-padding for linear conv)

max of conv = max of ifft(|X|² * phase) where X = fft(x).

Wait, it's fft(x)*fft(x), not |fft(x)|². The difference is that conv(x,x) uses X(k)^2 while autocorrelation uses |X(k)|² = X(k)*conj(X(k)).

So conv(x,x) = ifft(X^2) where X = fft(x).

For the autocorrelation: corr(x,x) = ifft(|X|²).

The peak of ifft(|X|²) is at lag 0 and equals ||x||².
The peak of ifft(X^2) can be anywhere and depends on the phase structure of X.

If x is real and nonnegative, X(0) = sum(x) is real and positive. X(k) for k>0 can have arbitrary phases.

X(k)^2 for k=1..n-1: the phase of X(k)^2 is 2*phase(X(k)).

For the ifft to have a low peak, we want X^2 to be as "flat" as possible (analogous to making |X|² flat for low autocorrelation sidelobes).

But X(0)^2 = (sum x)² is always the largest component (for nonnegative x, X(0) is the DC component and is typically the largest). So ifft(X²)[0] ≈ X(0)²/(2n) (for large n, the DC contributes ~X(0)²/(2n) to each bin of the ifft).

**Practical approach: For a sequence with large values at specific positions, the convolution peak at k=0 is x[0]². To avoid this, x[0] should be small. Similarly, all x[i] should be moderate to avoid x[i]² being the peak at edge lags.**

The constraint is: max over all k of conv(x,x)[k] should be small relative to (sum x)².

For the center lag (k=n-1): conv = sum x[i]*x[n-1-i]. For nonnegative x, this is at least the geometric mean type quantity.

For edge lags (k=0): conv = x[0]².
For lag 1: conv = 2*x[0]*x[1].
Etc.

So we need: x[i]² < target for all i (to keep edges down)
AND sum x[i]*x[n-1-i] < target (to keep center down)
AND sum x[i]*x[k-i] < target for all k.

Where target = 0.75 * (sum x)² / n (for score ≈ 1.5).

Setting sum x = n (average 1): target = 0.75n.
Edge constraint: x[i]² < 0.75n → x[i] < sqrt(0.75n). For n=4498: x[i] < 58.
Center constraint: sum x[i]*x[n-1-i] < 0.75n.
If all x[i] = 1: center = n > 0
