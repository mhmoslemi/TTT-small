- Decrease a[i] by a small amount
- Check if the peak decreased

This is O(n) per step (after the conv is computed) and each step changes one coordinate. With n = 6962 and the need to reduce the peak by 25%, this might take many steps.

**Let me try a completely different approach: iterative reweighting.**

Start with a uniform sequence. The convolution is triangular with peak n.

Iteratively:
1. Compute b = conv(a,a)
2. Set target T = mean(b) = (sum a)^2/(2n-1)
3. For each peak location k* where b[k*] > T, reduce the "weight" of the pairs that contribute to b[k*]
4. For each valley location where b[k] < T, increase the weight

This is like an iterative proportional fitting (IPF) or Sinkhorn algorithm.

More concretely:
- The convolution b[k] = sum_i a[i]*a[k-i]
- We want b[k] ≈ T for all k
- If b[k*] > T, we need to reduce a[i]*a[k*-i] for some i
- A natural way: multiply a[i] by a factor that reduces its contribution to the peak

This is similar to the "power iteration" for finding the dominant eigenvector, but in reverse (we want to FLATTEN, not concentrate).
