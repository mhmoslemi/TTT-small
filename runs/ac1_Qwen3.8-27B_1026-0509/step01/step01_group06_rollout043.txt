$(a*b)_k = \frac{1}{n} \sum_i b_i \cdot (\text{number of valid terms})$... 

Actually $(a*b)_k = \sum_i \frac{1}{n} b_{k-i}$ (valid indices) $= \frac{1}{n} \sum_{i: \text{valid}} b_{k-i}$.

For $k = n-1$ (center): $(a*b)_{n-1} = \frac{1}{n} \sum_i b_i = \frac{1}{n} \sum b_i \leq 1/n$, so $\sum b_i \leq 1$.

For $k = 0$: $(a*b)_0 = \frac{1}{n} b_0 \leq 1/n$, so $b_0 \leq 1$.

The binding constraint is the center one: $\sum b_i \leq 1$. So the LP optimum is $\sum b = 1$, which equals $\sum a = 1$. No improvement!

This makes sense: the uniform sequence is a fixed point of the LP iteration (it's the "max-entropy" solution).

So the LP iteration can't improve from the uniform start. We need non-uniform starts.

For a ramp start like $a_i \propto (i+1)$:
The LP should be able to find a better $b$ because the ramp has structure that the LP can exploit.

**Alternative: Direct optimization of the min-max problem**

The problem $\min_a \max_k (a*a)_k$ s.t. $a \geq 0, \sum a = 1$ can be attacked with:
1. **Bisection + feasibility**: For a given $M$, check if $\exists a$ with $(a*a)_k \leq M$ for all $k$. This is a system of quadratic inequalities, which is hard in general.
2. **Alternating direction**: Alternately fix the active set and solve.
3. **Gradient methods**: Use the subgradient of the max.

Let me try approach 3 more carefully. The subgradient of $f(a) = \max_k (a*a)_k$ at $a$ is in the convex hull of $\{2 B_k a : k \in K^*\}$ where $K^*$ is the active set (indices where the max is achieved).

For gradient descent: $a_{new} = \text{proj}(a - \eta \cdot 2 B_{k^*} a)$ where $k^* = \arg\max_k (a*a)_k$ and proj is onto $\{a \geq 0, \sum a = 1\}$.

The projection onto the simplex $\{a \geq 0, \sum a = 1\}$ can be done in $O(n \log n)$ time.

This is a simple and effective approach! Let me code it:

```python
def _project_simplex(v, target_sum=1.0):
    """Project v onto {a >= 0, sum(a) = target_sum}."""
    n = len(v)
    # Using the standard algorithm
    u = v.copy()
    rho = target_sum / n
    # Sort in decreasing order
    idx = np.argsort(u)[::-1]
    u_sorted = u[idx]
    cumsum = np.cumsum(u_sorted)
    # Find largest tau such that (u_tau - rho) / tau > 0... 
    # Actually, the projection onto the simplex {x >= 0, sum x = 1} is:
    # x_i = max(v_i - theta, 0) where theta is chosen so sum x = 1
    # Use bisection on theta
    lo = v.min()
    hi = v.max()
    for _ in range(60):
        mid = (lo + hi) / 2
        s = np.sum(np.maximum(v - mid, 0))
        if s > target_sum:
            lo = mid
        else:
            hi = mid
    theta = (lo + hi) / 2
    return np.maximum(v - theta, 0)
```

Then the gradient step:
```python
def _grad_desc_step(a, eta=0.01):
    n = len(a)
    b = np.convolve(a, a)
    k_star = b.argmax()
    # Gradient of (a*a)_k_star at a
    g = np.zeros(n)
    for j in range(n):
        m = k_star - j
        if 0 <= m < n:
            g[j] = 2 * a[m]
    a_new = a - eta * g
    a_new = _project_simplex(a_new, 1.0)
    return a_new
```

One more thought: for the SLSQP step, I should use the smooth max (softmax approximation) to get a smooth objective:
$f_\tau(a) = \frac{1}{\tau} \log \sum_k \exp(\tau (a*a)_k)$

As $\tau \to \infty$, this approaches $\max_k (a*a)_k$. For $\tau = 100$ or so, it's a good approximation.

The gradient is: $\nabla f_\tau(a) = \sum_k p_k \nabla (a*a)_k$ where $p_k = \exp(\tau (a*a)_k) / \sum_j \exp(\tau (a*a)_j)$.

This gives a smooth, differentiable objective for SLSQP.

import time

def _score(a):
    n = len(a)
    s = a.sum()
    if s < 0.01:
        return np.inf
    mb = np.convolve(a, a).max()
    return 2.0 * n * mb / (s * s)

def _build_conv_mat(a):
    n = len(a)
    L = 2 * n - 1
    A = np.zeros((L, n))
    for k in range(L):
        lo = max(0, k - n + 1)
        hi = min(n, k + 1)
        for i in range(lo, hi):
            A[k, i] = a[k - i]
    return A

def _lp_step(a, M):
    n = len(a)
    A = _build_conv_mat(a)
    res = linprog(-np.ones(n), A_ub=A, b_ub=np.full(A.shape[0], M),
                  bounds=[(0, None)]*n, method='highs')
    if res.success and res.x is not None:
        return np.clip(res.x, 0, None)
    return None

def _lp_iterate(a, deadline, max_iters=5000):
    n = len(a)
    a = np.clip(a, 0, None)
    s = a.sum()
    if s < 1e-12:
        return a

    best = a.copy()

            break

        if g is None:
            break

        if gs <= 1.0 + 1e-10:
            break

            a = g
            best = g.copy()
            best_sc = sc
        else:

            for t in (0.5, 0.25, 0.75, 0.1, 0.9):
                c = np.clip((1-t)*a + t*g, 0, None)
                cs = c.sum()
                if cs < 1e-12: continue
                c /= cs
                s2 = _score(c)
                if s2 < best_sc - 1e-13:
                    a = c; best = a.copy(); best_sc = s2; imp = True; break

def _slsqp_polish(a, max_iter=100):
    n = len(a)
    a0 = np.clip(a, 0, None)
    s = a0.sum()
    if s < 1e-12: return a
    a0 = a0 / s
    tau = 50.0  # softmax temperature
    
    def obj(x):
        x = np.clip(x, 1e-15, None)
        s = x.sum()
        x = x / s
        b = np.convolve(x, x)
        m = b.max()
        return np.log(np.sum(np.exp(tau * (b - m)))) / tau + m
    
    def grad(x):
        x = np.clip(x, 1e-15, None)
        s = x.sum()
        x = x / s
        b = np.convolve(x, x)
        m = b.max()
        p = np.exp(tau * (b - m))
        p /= p.sum()
        g = np.zeros(n)
        for k in range(len(b)):
            if p[k] < 1e-15: continue
            for j in range(n):
                mm = k - j
                if 0 <= mm < n:
                    g[j] += p[k] * 2 * x[mm]
        return g
    
    cons = [{'type': 'eq', 'fun': lambda x: x.sum() - 1, 'jac': lambda x: np.ones(n)}]
    try:
        res = minimize(obj, a0, jac=grad, method='SLSQP', bounds=[(0, None)]*n,
                       constraints=cons, options={'maxiter': max_iter, 'ftol': 1e-14})

            if x.sum() > 1e-12:
                x /= x.sum()
                if _score(x) < _score(a0):
                    return x
    except:
        pass
    return a0
