`c_k = a_0 * a_k + a_1 * a_{k-1} + ... + a_k * a_0` (with valid indices)

The gradient with respect to `a_m`:
- `a_m` appears as `a_m * a_{k-m}` (when i=m) and as `a_{k-m} * a_m` (when j=m, i.e., i=k-m)
- If `m ≠ k-m`: both terms exist, gradient = `a_{k-m} + a_{k-m} = 2a_{k-m}`
- If `m = k-m` (k even, m=k/2): only one term `a_m * a_m`, gradient = `2a_m`

So in all cases: `d(c_k)/d(a_m) = 2 * a[k-m]` if `0 <= k-m < n`, else 0.

Great, so my earlier formula was correct.
