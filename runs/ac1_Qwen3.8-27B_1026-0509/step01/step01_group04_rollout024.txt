Let me also consider: what if instead of the LP, I directly minimize the max using a bisection + LP feasibility approach?

**Bisection approach:**
- We want to find the minimum M such that there exists x >= 0, sum(x) = 1, with (x*x)[k] <= M for all k.
- For a given M, the feasibility problem is: find x >= 0, sum(x) = 1, (x*x)[k] <= M for all k.
- This is a non-convex feasibility problem (quadratic constraints).
- But we can relax: instead of (x*x)[k] <= M, use (f*x)[k] <= M for a fixed f (linear in x). This is the LP approach.

So the LP is a relaxation. The gap between the LP solution and the true optimum is what the blending tries to close.

d/dx[i] softmax(conv, beta) = (1/sum_j exp(beta*conv[j])) * sum_k exp(beta*conv[k]) * (2*x[k-i] if valid)
