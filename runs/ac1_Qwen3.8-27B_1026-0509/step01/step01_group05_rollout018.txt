- dc[k]/da[i] = 2a[k-i], so if I change a[i] by δa[i], c[k] changes by 2a[k-i]δa[i] (first order)

The problem is that this is a non-convex optimization (the feasible set is non-convex due to the quadratic constraints). So IPF may not converge to a global optimum, but it can make good local progress.

Let me try a simpler approach: **Alternating minimization on the frequency domain**.

In frequency: C(ω) = |A(ω)|^2, where A = DFT(a) and C = DFT(c).
We want C(ω) to be flat (all time-domain c[k] equal means C is a delta... no wait).

Actually, I had it backwards. If c[k] is flat in time, then C(ω) = DFT(c) is a delta at ω=0. That means |A(ω)|^2 is a delta, which means A(ω) is a delta, which means a is constant. So flat c ↔ constant a.

Wait, that's not right either. Let me be more careful.

c = a * a (time domain convolution)
C(ω) = A(ω) * A(ω) = A(ω)^2 (frequency domain, with appropriate scaling)

If c is flat: c[k] = C0 for all k in [0, 2n-2]. Then C(ω) = C0 * sum_{k=0}^{2n-2} e^{-iωk} = C0 * e^{-iω(n-1)} * sin(ω(2n-1)/2) / sin(ω/2).

This is a Dirichlet kernel, not a delta. So c being flat doesn't correspond to C being flat.

I think I was confusing myself. Let me just focus on the time-domain optimization.

Let me go back to the subgradient approach but make it simpler and more robust. Here's my revised plan:

1. Start from parent (or best parametric)
2. Use smooth subgradient with adaptive step size
3. Key: use a PROPER step size based on the Lipschitz constant of the gradient

The key insight for step size: if the gradient is L-Lipschitz, then step size 1/L guarantees convergence. For our problem, L is related to the maximum eigenvalue of the Hessian, which is O(n * max(a)^2) or so.

But computing L exactly is expensive. Let me use a backtracking line search instead:
- Try step size eta
- If f(a - eta*g) > f(a), halve eta and retry
- Limit to a few halvings per iteration

This is robust but adds overhead. Since each evaluation is O(n log n), a line search of 10-20 evaluations per iteration is fine.
