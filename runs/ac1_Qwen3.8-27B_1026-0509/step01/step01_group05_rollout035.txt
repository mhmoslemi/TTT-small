The LP is:
maximize sum(g)
subject to (f * g)_k <= M for all k = 0, ..., 2n-2
g >= 0

This finds the "largest" g (in L1 norm) that is "compatible" with f (in the sense that their cross-convolution is bounded by M).

After the update f_new = (1-t)f + tg, the new self-convolution is:
(f_new * f_new)_k = (1-t)^2(f*f)_k + 2t(1-t)(f*g)_k + t^2(g*g)_k
<= (1-t)^2 M + 2t(1-t) M + t^2 * max(g*g)
= M(1 - t^2) + t^2 * max(g*g)

So the new max is bounded by M(1-t^2) + t^2 * max(g*g). For this to be < M, we need max(g*g) < M.

Does the LP ensure max(g*g) < M? Not directly. The LP ensures (f*g)_k <= M, not (g*g)_k <= M.

However, if g is "more spread out" than f (which it should be, since the LP is trying to maximize sum(g) while keeping (f*g) bounded), then (g*g) should be more spread out than (f*f), and max(g*g) should be <= max(f*f) = M.

This is not guaranteed in general, but it's likely in practice. The golden section search handles the case where max(g*g) > M by finding a smaller t.
