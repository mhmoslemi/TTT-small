Also, I realize that for the coordinate descent polish, I'm calling conv_final multiple times per coordinate, which is expensive. Let me optimize: for a single coordinate change, I can compute the change in the convolution analytically.

If I change a[j] from old_val to new_val (delta = new_val - old_val), the change in the convolution c[k] is:
Δc[k] = delta * (a[k-j] + a[j-k]) (for valid indices)
which is delta * 2 * a[|k-j|] (approximately, with boundary effects).

Actually: Δc[k] = delta * a[k-j] (if 0<=k-j<n) + delta * a[j-k] (if 0<=j-k<n)
= delta * (a[k-j] + a[j-k]) (with zeros for out of range)

This is O(n) to compute for all k, which is the same as the FFT convolution. So it's not much faster for a single coordinate. Let me just use the FFT convolution.

Actually, for n=400, the FFT convolution is very fast (~50μs). So even with 15 coordinates × 10 multipliers × 200 rounds = 30,000 evaluations, that's only ~1.5 seconds. Fine.

Let me also think about whether I should try to minimize a slightly different objective during optimization. For example:
- min max(c) + α * (c_max - c_min)  (encourage flatness)
- min sum(c^2)  (encourage uniform distribution of energy in autocorrelation)
- min c_max^p for p > 1 (more aggressive peak reduction)

The sum(c^2) approach might work well: since sum(c) = S^2 = 1 is fixed, minimizing sum(c^2) is equivalent to making c as flat as possible. And sum(c^2) is a smooth objective (quartic in a, but differentiable).

The gradient of sum(c^2) with respect to a:
sum_k c_k^2 = sum_k (sum_i a_i a_{k-i})^2

∂/∂a_j [sum_k c_k^2] = 2 * sum_k c_k * ∂c_k/∂a_j
= 2 * sum_k c_k * 2 * a[k-j] (for valid k-j)
= 4 * sum_{k: 0<=k-j<2n-1, 0<=k-j<n} c_k * a[k-j]
= 4 * sum_{i: 0<=i<n} c_{j+i} * a[i]  (letting i = k-j)

Wait, let me be more careful. c_k = sum_i a_i * a_{k-i}.

∂c_k/∂a_j = 2*a[k-j] (if 0<=k-j<n, else 0) [as derived earlier]

∂/∂a_j [sum_k c_k^2] = 2 * sum_k c_k * ∂c_k/∂a_j = 4 * sum_k c_k * a[k-j] (for valid k-j)

Let i = k-j, so k = i+j:
= 4 * sum_i c_{i+j} * a[i] (where c_{i+j} is defined for 0 <= i+j <= 2n-2, and a[i] for 0 <= i < n)

This is a convolution: 4 * (c_rev * a)[j] where c_rev is the appropriately indexed version of c.

Actually, more precisely:
= 4 * sum_{i=0}^{n-1} a[i] * c[i+j]

where c is defined for indices 0 to 2n-2 (and c[x] = 0 outside this range).

This is like a cross-correlation of a with c, which can be computed via FFT.

So the gradient of sum(c^2) is smooth and can be computed efficiently. This might be a better objective to minimize!

Let me combine both: minimize max(c) + λ * sum(c^2) for some λ. Or just minimize sum(c^2) which implicitly reduces the peak.

Actually, I think minimizing sum(c^2) is a great proxy:
- It's smooth (differentiable)
- It's quadratic in c (quartic in a)
- It encourages all c_k to be equal (since sum(c) is fixed, minimum variance = minimum sum(c^2))
- It avoids the non-differentiability of max

Let me use this as the primary objective, with max(c) tracking for the final score.

The gradient:
g[j] = 4 * sum_{i=0}^{n-1} a[i] * c[i+j]

where c has length 2n-1 and is zero-padded. This is (4 * a * c) in the convolution sense... wait no.

sum_i a[i] * c[i+j]: this is the cross-correlation of a and c at lag j. In convolution terms: (a * c_rev)[j + (2n-2)]... this is getting confusing.

Let me just compute it directly:
- c has length 2n-1 (indices 0 to 2n-2)
- For j = 0 to n-1: g[j] = 4 * sum_{i=0}^{n-1} a[i] * c[i+j]

I can compute this via FFT:
- Pad a to length 2n-1 (already is, since a has length n and c has length 2n-1)
- Actually, let me define: g_raw[j] = sum_{i=0}^{n-1} a[i] * c[i+j] for j = 0..n-1

This is the "cross-correlation" of a with the first n elements of c... no, it's summing a[i] * c[i+j] for i=0..n-1, which is like (flip(a) * c)[n-1+j]... 

Actually, the simplest way: g_raw[j] = sum_{i=0}^{n-1} a[i] * c[i+j]. I can compute this as:
- Let c_ext = c (length 2n-1)
- g_raw = np.array([sum(a[i] * c[i+j] for i in range(n)) for j in range(n)])

For n=400, this is 400 * 400 = 160,000 operations, which is fine. Or I can use FFT.

Using FFT: g_raw[j] = sum_i a[i] * c[i+j] is the cross-correlation of a and c. In terms of convolution:
g_raw = (a_flipped * c)[n-1 + j] where a_flipped = a[::-1]

Or: pad a to length 2n-1, FFT it, FFT c, multiply by conjugate, IFFT.

Actually, the simplest: 
corr = np.correlate(c, a, mode='valid') gives corr[j] = sum_i c[i+j] * a[i] for j = 0..n-1 (since len(c) - len(a) + 1 = (2n-1) - n + 1 = n).

So g_raw = np.correlate(c, a, mode='valid') and g = 4 * g_raw.

This is O(n^2) for the correlate, but for n=400 it's fast. Alternatively, I can use FFT-based correlation.

Let me use np.correlate for simplicity (it's a C implementation and fast for n=400).

Now, the full algorithm with the smoothed objective:

1. Normalize a to sum = 1
2. Compute c = convolve(a, a)
3. Compute g = 4 * correlate(c, a, mode='valid')  [this is the gradient of sum(c^2)]
4. Project g to sum-0 (subtract mean)
5. Take a gradient step: a -= lr * g / ||g||
6. Project to simplex (a >= 0, sum = 1)
7. Repeat

This should smoothly reduce the variance of c, making it flatter, which reduces the peak.

    results.append(opt_smooth(a_tri, n, t3, conv, lr_init=0.08))

    remaining = deadline - time.monotonic()
    t4 = time.monotonic() + 0.15 * remaining
    best_so_far = min(results, key=lambda x: x[1])
    results.append(opt_subgrad(best_so_far[0], n, t4, conv, top_k=3))

    remaining = deadline - time.monotonic()
    t5 = time.monotonic() + 0.07 * remaining
    best_so_far2 = min(results, key=lambda x: x[1])
    results.append(opt_smooth(best_so_far2[0], n, t5, conv, lr_init=0.05))

    best_a = None
    best_sc = np.inf
    for ba, _ in results:
        sc = float(evaluate_sequence(ba.tolist()))
        if np.isfinite(sc) and sc < best_sc:
            best_sc = sc
            best_a = ba.copy()

    if best_a is None:
        best_a = np.ones(n) / n
        best_sc = float(evaluate_sequence(best_a.tolist()))

    if time.monotonic() < deadline - 10:
        a_p = best_a.copy()
        a_p = a_p / a_p.sum()
        cur_peak = 2.0 * n * conv(a_p).max()
        for rd in range(800):
            if time.monotonic() > deadline - 10:
                break
            n_c = min(12, n)
            coords = rng.choice(n, size=n_c, replace=False)
            for idx in coords:
                old = a_p[idx]
                bm = 1.0
                bc = cur_peak
                for mult in [0.15, 0.3, 0.5, 0.7, 0.85, 1.0, 1.15, 1.3, 1.6, 2.0, 3.0]:
                    a_p[idx] = old * mult
                    s = a_p.sum()
                    if s < 1e-12:
                        a_p[idx] = old
                        continue
                    a_p /= s
                    tc = 2.0 * n * conv(a_p).max()
                    if tc < bc:
                        bc = tc
                        bm = mult
                a_p[idx] = old * bm
                s = a_p.sum()
                if s > 1e-12:
                    a_p /= s
                    cur_peak = bc
            sc = float(evaluate_sequence(a_p.tolist()))
            if np.isfinite(sc) and sc < best_sc:
                best_sc = sc
                best_a = a_p.copy()

    fs = float(evaluate_sequence([float(x) for x in best_a]))
    if not np.isfinite(fs):
        best_a = np.ones(n) / n
        fs = float(evaluate_sequence(best_a.tolist()))

    return [float(x) for x in best_a]
