$\nabla_j \log \sum_k e^{\beta b[k]} = \frac{\sum_k \beta e^{\beta b[k]} \frac{\partial b[k]}{\partial a[j]}}{\sum_k e^{\beta b[k]}}$

The indicator condition: $\max(0, k-n+1) \leq j \leq \min(n-1, k)$ is equivalent to $0 \leq j < n$ AND $0 \leq k-j < n$, which is the same as saying $a[k-j]$ is a valid index.

So: $\nabla_j = 2\beta \sum_k p_k \cdot a[k-j]$ where $a[m] = 0$ for $m \notin [0, n-1]$.

This is $2\beta$ times the cross-correlation of $p$ and $a$.

To compute all $n$ values of the cross-correlation:
Let $c[j] = \sum_k p[k] \cdot a[k-j]$ for $j = 0, \ldots, n-1$.

This is the cross-correlation $(p \star a)[j] = \sum_k p[k] a[k-j]$.

Using the relationship to convolution: $c[j] = (p * a_{\text{rev}})[n-1+j]$ where $a_{\text{rev}}[i] = a[n-1-i]$.

$(p * a_{\text{rev}})[m] = \sum_j p[m-n+1+j] a[j]$.

We want $c[j] = \sum_k p[k] a[k-j]$. Let $k-j = i$, so $k = i+j$:

We want $\sum_k p[k] a[k-j]$. Let $k-j = i$, $k = i+j$:

Therefore: $c[j] = (p * a_{\text{rev}})[n-1+j]$ for $j = 0, \ldots, n-1$.

The full convolution $p * a_{\text{rev}}$ has length $(2n-1) + n - 1 = 3n-2$. We extract elements at indices $n-1, n, \ldots, 2n-2$ (i.e., $n$ elements starting at $n-1$).

This can be computed with a single FFT of suitable length.
