    c = np.convolve(x, x)  # length 2n-1
    # Soft max approximation
    log_sum = np.log(np.sum(np.exp(beta * c))) / beta
    # Gradient
    # For each k, grad_c_k[j] = 2*x[k-j] if 0 <= k-j < n
    # Weight = exp(beta * c_k) / sum(exp(beta * c_j))
    weights = np.exp(beta * c) / np.sum(np.exp(beta * c))

        for j in range(max(0, k-n+1), min(n, k+1)):
            grad[j] += 2 * w * x[k-j]
    return log_sum, grad / beta

For the fixed point to be a "good" solution, we want the autocorrelation to be as flat as possible. The LP is essentially asking: "given the filter $x$, what's the best input $g$ that doesn't excite the filter beyond $M$?" If the filter has a flat frequency response, the answer is "hunch up" (all $g$'s contribute equally), giving a large $S^*$.
