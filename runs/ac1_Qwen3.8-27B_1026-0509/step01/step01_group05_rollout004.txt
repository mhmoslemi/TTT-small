OK so the algorithm is:
1. Normalize a to sum 1.
2. Compute b = convolve(a,a) via FFT (length 2n-1).
3. Compute softmax weights p over b with temperature τ.
4. Compute gradient ∇f = 2 * cross_corr(p, a) via FFT.
5. Take a gradient step: a_new = a - η * ∇f.
6. Project: set a_new = max(0, a_new), then renormalize to sum 1.
7. Optionally, adaptive step size (line search or diminishing η).
8. Gradually decrease τ.
