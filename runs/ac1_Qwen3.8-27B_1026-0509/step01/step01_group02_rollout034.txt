def _cross_corr(a, b):
    """Compute (a*b)(k) = sum_i a_i * b_{k-i} for k=0,...,2n-2 via FFT."""
    n = len(a)

    return ifft(fft(a, s) * fft(b, s)).real[:2*n-1]

def _weighted_grad(a, w):
    """
    Compute gradient of sum_k w[k] * (a*a)(k) w.r.t. a.
    grad[j] = 2 * sum_k w[k] * a[k-j] (where 0 <= k-j < n)
    = 2 * (a_flip * w)[n-1+j] where a_flip = a[::-1]
    """

    L = 1 << (3*n - 1).bit_length()

    i = int(np.max(np.where(cond)[0]))

The objective is f(a) = max_k (a*a)(k) subject to a >= 0, sum(a) = 1.

This is the minimax of quadratic functions. It's a convex problem (each (a*a)(k) is convex for a >= 0... wait, is it?).

(a*a)(k) = sum_i a_i * a_{k-i}

The Hessian of this with respect to a is:
H_{j,l} = sum_k w_k * (delta_{j+k,l} + delta_{l+k,j})... 

Actually, (a*a)(k) is a quadratic form: a^T Q_k a where (Q_k)_{i,j} = 1 if i+j=k, 0 otherwise (divided by 2 for i≠j).

Is Q_k PSD? Q_k has 1's on the "anti-diagonal" at position k. This matrix is:
- For k=0: Q_0 = diag(1,0,...,0)... no, (Q_0)_{i,j} = 1 if i+j=0, i.e., only (0,0). So Q_0 = [[1,0,...],[0,0,...],...]. This is PSD.

One more thought: the LP approach. The constraint matrix A has a special structure (banded Toeplitz). Can I exploit this?

The LP is: max 1^T g s.t. A g <= M * 1, g >= 0

The dual is: min M * 1^T y s.t. A^T y >= 1, y >= 0

Where A^T y has entries (A^T y)_j = sum_k A[k,j] * y_k = sum_k a[k-j] * y_k (for valid k-j)

This is a "convolution" of a and y. So A^T y = conv(a, y) (restricted to the first n entries).

The dual has 2n-1 variables and n constraints. Each constraint is a linear combination of y weighted by a. The constraint matrix A^T is the "reverse" of A.
