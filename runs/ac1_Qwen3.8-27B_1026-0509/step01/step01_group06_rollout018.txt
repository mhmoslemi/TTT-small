def _score(a):
    """Compute the AC1 score for a sequence."""
    n = len(a)
    b = np.convolve(a, a)
    max_b = b.max()
    s = a.sum()
    if s < 0.01:
        return np.inf
    return 2.0 * n * max_b / (s * s)

def _lp_solve(a, M, n):
    """Solve the LP: max sum(b) s.t. b>=0, a*b <= M componentwise."""
    L = 2 * n - 1
    # Build constraint matrix
    A = np.zeros((L, n))
    for k in range(L):

        hi = min(n, k + 1)

    return None

Let me try yet another approach: "Frank-Wolfe" (conditional gradient) method.

The Frank-Wolfe algorithm for minimizing `f(a) = max_k (a*a)[k]` subject to `a in Δ` (simplex):
1. At current `a_t`, compute subgradient `g_t` (gradient of the active component)
2. Solve the linear oracle: `v_t = argmin_{v in Δ} <g_t, v>`
   - The minimum of a linear function over the simplex is achieved at a vertex, so `v_t = e_{j*}` where `j* = argmin_j g_t[j]`
3. Update: `a_{t+1} = (1-γ_t) * a_t + γ_t * v_t`

The step size `γ_t` can be chosen as `2/(t+2)` or by line search.

This is very simple to implement! And the "linear oracle" step is trivial (just find the minimum component of the gradient).

Let me think about whether this would work well for our problem. The subgradient of `max(a*a)` is `2 * shift(a, k*)` where `k*` is the argmax. The minimum component of this gradient would be at a position where `a[k*-j]` is smallest. So the FW step would move mass from positions that contribute to the peak toward positions that don't.

This seems reasonable! Let me implement it.

        k_star = int(np.argmax(conv))

        grad = np.zeros(n)
        j_min = max(0, k_star - n + 1)
        j_max = min(n - 1, k_star)
        idx = k_star - np.arange(j_min, j_max + 1)
        grad[j_min:j_max+1] = 2.0 * a[idx]

        j_min_val = int(np.argmin(grad))

            best_s = s
