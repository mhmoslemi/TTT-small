Let me also consider a different approach: instead of the LP, use a "dual subgradient" method. The idea is:

The problem is: min_x max_k (x*x)(k) s.t. x ≥ 0, sum(x) = 1.

By minimax duality (Sion's theorem, since the feasible set is compact and the function is convex-concave):
min_x max_k f_k(x) = max_{p ∈ Δ} min_x sum_k p_k f_k(x)

where f_k(x) = (x*x)(k) is the k-th convolution value, and Δ is the probability simplex over k.

The inner problem: min_x sum_k p_k (x*x)(k) s.t. x ≥ 0, sum(x) = 1.

This is: min_x x^T (sum_k p_k A_k) x s.t. x ≥ 0, sum(x) = 1, where A_k is the matrix for the k-th convolution.

The matrix Q = sum_k p_k A_k is symmetric PSD (since each A_k is PSD and p_k ≥ 0). So the inner problem is a convex QP: min x^T Q x s.t. x ≥ 0, sum(x) = 1.

This can be solved efficiently! It's a quadratic program with a simplex constraint.

The dual of the inner QP: max -λ - sum_i μ_i s.t. 2Qx + 1 + μ = 0, x ≥ 0, μ ≤ 0... hmm, this is getting complicated.

Actually, for min x^T Q x s.t. x ≥ 0, 1^T x = 1, I can use the KKT conditions:
- 2Qx + λ*1 + μ = 0 (stationarity)
- x ≥ 0, μ ≤ 0, x_i * μ_i = 0 (complementarity)
- 1^T x = 1 (primal feasibility)

For the active set S = {i : x_i > 0}:
- For i ∈ S: 2(Qx)_i + λ = 0, i.e., (Qx)_i = -λ/2 for all i ∈ S
- For i ∉ S: 2(Qx)_i + λ ≤ 0, i.e., (Qx)_i ≤ -λ/2

So x restricted to S satisfies: Q_S * x_S = (-λ/2) * 1_S, and 1^T x_S = 1.

From the first equation: x_S = (-λ/2) * Q_S^{-1} * 1_S.
Substituting into 1^T x_S = 1: (-λ/2) * 1^T Q_S^{-1} 1 = 1, so λ = -2 / (1^T Q_S^{-1} 1).
And x_S = (Q_S^{-1} 1) / (1^T Q_S^{-1} 1).

The active set changes as p changes, but for a given p, the inner problem can be solved by finding the right active set.

This is essentially the "water-filling" or "active set" method for convex QPs.

p_k ← p_k * exp(-η * f_k(x)) (normalized to sum to 1)
