We observe that the bound T is invariant under scaling transformations, which allows us to fix the energy level (report sum) to a constant value for optimization stability.

Key components:
- Use the provided parent sequence as initialization (if available)
- Compute the AC1 bound with the full linear convolution (2n-1 points)
- For each Michael Pollington
- address the optimization barrier: T = (2*n * max(convolution))/sum^2
  * Development of an LP-based adaptive descent method
  * Memory management: handle large dimensions (6962) without overflow
  * Use local search with stochastic coordinate-wise updates to explore the landscape
  * Implement time budget exhaustion protection

The rationale is to balance between directional descent (preserving energy) and random perturbation for escaping local minima, leveraging the invariance properties of the objective function.

2. Mathematical specification

Problem dimension: n = (length of candidate sequence)
Fixed energy level E = 1; set E_sum = (energy parameter)
Objective: minimize T = (2*n * max_{k=0}^{2n-2} (convolve(a,a)[k])) / E_sum^2

Constraints:
0 ≤ a_i ≤ 1000 for all i

Decision variables: sequence a = (a_0, a_1, ..., a_{n-1})

Notation:
- `s` is energy (sum of sequence)
- `M0` is maximum of autocorrelation |convolve(a,a)[k]|
- LP formulation:
    maximize sum(g) subject to
    g >= 0 and convolve(a, g) <= [M0 + M1]

Formulation is transformed to sparse representations (avoiding dense arrays) to save memory.
