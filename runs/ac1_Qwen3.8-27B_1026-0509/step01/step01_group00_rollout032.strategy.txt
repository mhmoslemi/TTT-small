1. Approach and Rationale
We develop a projected gradient descent algorithm optimized for minimizing the AC1 upper bound. Unlike the parent example which uses gradient-based updates during optimization, our approach differs by:
- Implementing a rigorous projected gradient descent with line search for automatic step size selection
- Using FFT-based convolution for efficient gradient computation
- Incorporating active-set selection for gradient approximation
- Employing exponential cooling schedule and temperature-based feature selection during search

The AC1 optimization is a classic non-convex problem in spectral theory, and our key insight is to:
- Use FFT convolution to compute gradients in O(n log n)
- Project gradients onto the non-negative orthant with 1000-bound constraint
- Select active spectral components adaptively during learning
- Maintain diverse search trajectories through cooling

The primary limitation is the computational cost of FFT operations for large sequences, which we mitigate through adaptive active-set selection.

2. Mathematical Specification
For a sequence $a \in \mathbb{R}^n_+ $:
- Compute linear convolution $c_j = \sum_{k}\text{clip}(a_k) \cdot \text{clip}(a_{j-k})$
- AC1 score $S(a) = \frac{2n}{(\sum a)^2} \max_j c_j$
- Gradient requires:
    ∂S/∂a_i = $2n/(\sum a)^2 \cdot (\text{gradients from nonzero convolutions}) - 4S/(\sum a)$
Our formulation involves:
- Variable transformation $a \rightarrow \exp(\beta h)$ for sparse solutions
- Temperature parameter $T$ governing feature sparsity
- Activation thresholds $\theta_i = T \cdot g_i$ for adaptive selection

from scipy.fft import rfft, irfft
from scipy.optimize import minimize

def evaluate_sequence_safe(seq):
    if not all(0 <= x <= 1000 for x in seq):
        return np.inf
    if sum(seq) < 0.01:
        return np.inf
    t = np.array(seq, dtype=np.float64)
    conv_result = np.convolve(t, t, mode='full')  # Linear convolution
    M = np.max(conv_result)
    s = 2 * t.shape[0] * M / (sum(t)**2)
    return float(s)

def propose_candidate(seed=42, budget_s=1500, **kwargs):

        parent = None

        n = 256
        a_init = np.clip(np.random.default_rng(seed).normal(1.0, 0.2, n), 0.0, 1000.0)
    else:
        n = parent.shape[0]
        a_init = parent.copy()
    
    a_init = a_init.clip(0, 1000)
    best_candidate = a_init
    best_score = evaluate_sequence_safe(a_init)

    T0 = 1.0  # Initial temperature
    alpha = 0.995  # Cooling rate
    
    for i in range(max_iter):
        # Temperature schedule
        T = T0 * (alpha**i)
        
        # 1. Compute gradients
        current_score = evaluate_sequence_safe(best_candidate)
        grad = compute_gradient(best_candidate, n)
        
        # 2. Sparsity selection
        coeff_threshold = T * np.std(grad)
        candidate = best_candidate / np.sum(best_candidate)  # Normalize shape
        
        # 3. Update candidate with projected gradient
        t_initial = 0.1
        
        def objective_func(t):
            trial = best_candidate * np.exp(t * candidate)
            trial = np.clip(trial, 1e-3, 1000)  # Domain snapping
            if all(0.0 <= x <= 1000 for x in trial):
                return evaluate_sequence_safe(trial)
            return np.inf
        
        # Optimized annealing schedule
        result = minimize(objective_func, t_initial, method='BFGS', bounds=[(0, 0.5)]*n)
        new_candidate = best_candidate * np.exp(result.x.reshape((-1,1)) * candidate)
        new_candidate = np.clip(new_candidate, 1, 1000)  # Enforce bounds
        
        # Line search projection
        grad_step = best_candidate - new_candidate
        grad_step_norm = np.linalg.norm(grad_step)
        if grad_step_norm < 1e-6:
            break  # Local minimum
        
        # Evaluate new candidate
        new_score = evaluate_sequence_safe(new_candidate) if grad_step_norm < 0.1 else np.inf
        
        # Update policy
        if new_score < current_score or np.random.random() < np.exp((new_score - current_score)/(T*current_score if current_score>0 else 1)):
            best_candidate = new_candidate
            current_score = new_score
            
        # Safety net
        if i % 10 == 0:
            current_score_robust = evaluate_sequence_safe(best_candidate)
            if not np.isfinite(current_score_robust):
                best_candidate = np.clip(best_candidate * 0.7 + parent*0.3 if parent is not None else best_candidate * 0.8, 0, 1000)
                current_score = evaluate_sequence_safe(best_candidate)
    
    return list(best_candidate)
