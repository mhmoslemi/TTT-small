When $k \neq 2j$ (i.e., $i = j$ and $i = k-j$ are different terms), we get two separate terms each contributing $a_{k-j}$, so total is $2a_{k-j}$.

Wait, that means $\frac{\partial R_k}{\partial a_j} = 2a_{k-j}$ for all valid $j$? Let me check with $k=3, j=1$:

$\partial R_3 / \partial a_1 = 2a_2 = 6$? But earlier I said it should be $a_2 = 3$.

Let me recompute: $R_3 = \sum_{i=\max(0,3-3+1)}^{\min(2,3)} a_i a_{3-i} = \sum_{i=1}^{2} a_i a_{3-i} = a_1 a_2 + a_2 a_1 = 2 \cdot 2 \cdot 3 = 12$. ✓

$\partial R_3 / \partial a_1 = \partial(a_1 a_2)/\partial a_1 + \partial(a_2 a_1)/\partial a_1 = a_2 + a_2 = 6$.

And $2a_{3-1} = 2a_2 = 6$. ✓

So the formula is simply $\frac{\partial R_k}{\partial a_j} = 2a_{k-j}$ for all valid $j$ (where valid means $0 \leq j < n$ and $0 \leq k-j < n$).

Great, that simplifies things! The factor-2 correction I was computing separately is actually always present. Let me re-derive:

$R_k = \sum_i a_i a_{k-i}$

$\frac{\partial R_k}{\partial a_j} = \sum_i \left(\frac{\partial a_i}{\partial a_j} a_{k-i} + a_i \frac{\partial a_{k-i}}{\partial a_j}\right)$

$= a_{k-j} \cdot \mathbf{1}[0 \leq k-j < n] + a_{k-j} \cdot \mathbf{1}[0 \leq k-j < n]$

$= 2 a_{k-j} \cdot \mathbf{1}[0 \leq k-j < n]$

Yes! So the gradient of $R_k$ with respect to $a$ is simply $2 \cdot$ the valid slice of $a$ reversed.

So the total gradient (for soft-max) is:
$g_j = 2 \sum_k p_k a_{k-j}$ (for valid $k-j$)

This is $2 \times$ the cross-correlation I computed earlier.
