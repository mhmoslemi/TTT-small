This is the same as (1/|active|) * conv(indicator_active, a)[j] where indicator_active is a vector of length 2n-1 with 1 at active positions and 0 elsewhere.

But wait, the subgradient should account for the factor of 2 (both i=j and i=k-j contribute). For the max function, the subgradient is the average of the gradients of the active components. The gradient of c_k w.r.t. a is:
∇c_k[j] = 2*a[k-j] (if k-j ≠ j) or a[j] (if k=j/2, i.e., k=2j)

So the "true" subgradient is:
g[j] = (1/|active|) * Σ_{k in active} ∇c_k[j]
     = (1/|active|) * Σ_{k in active} (2*a[k-j] - [k=2j]*a[j])

The first part (2*conv(ind, a)) can be done with FFT. The second part (diagonal correction) is:
For each j, the correction is a[j] * (number of active k where k = 2j) / |active|
= a[j] * [2j in active] / |active|

This is sparse (at most one k per j), so it's O(n) to compute.

            ind[active] = 1.0
            W = np.fft.rfft(ind, fft_len2)
            A = np.fft.rfft(a, fft_len2)
            g = 2.0 * np.fft.irfft(W * A, fft_len2)[:n].copy()
            j = np.arange(n)
            k = 2*j
            mask = k < len(ind)
            g[mask] -= a[mask] * ind[k[mask]]
            g /= len(active)
            g -= g.mean()
            gn = np.abs(g).max()
            if gn > 1e-15:
                a = a * np.exp(-eta * g / gn)
                a = np.maximum(a, 1e-20)
                a /= a.sum()
            
            if it % 500 == 0:
                update_best(a)
    
    # Final validation
    best_a = np.clip(best_a, 0.0, 1000.0)
    if best_a.sum() < 0.01:
        best_a = np.ones(n) / n
    final = evaluate_sequence(best_a.tolist())
    if not np.isfinite(final) or final > 1e6:
        fallback = np.ones(n) / n
        return [float(x) for x in fallback]
    return [float(x) for x in best_a]
