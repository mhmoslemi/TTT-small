Let me think about the adaptive M strategy more carefully:

At each iteration:
1. Compute M_current = max(f*f)
2. Set M_target = M_current * (1 - delta) where delta is small (e.g., 0.01-0.05)
3. Solve LP: max sum(g) s.t. (f*g)_k <= M_target, g >= 0

5. If feasible, rescale g to match sum(f), blend with f
6. Update f and repeat

The key question is how fast this converges and whether it gets stuck.

Actually, I realize there might be a simpler and more effective approach. Let me think about the problem from scratch.

We want to minimize 2n * max(f*f) / (sum f)^2.

By normalization, set sum f = 1. Then minimize 2n * max(f*f).

The sum of all entries of f*f is (sum f)^2 = 1. So we want to distribute the "mass" of f*f as evenly as possible across its 2n-1 entries.

The constraint is that f*f must be a valid convolution (i.e., it must be in the image of the map f -> f*f for some f >= 0).

This is a non-convex problem (the map f -> f*f is quadratic), but the LP approach linearizes it by fixing one factor.

Alternative: **Iterative reweighted approach**
- Start with f
- Compute w_k = 1 / (f*f)_k (inverse of the convolution)
- Update f by "spreading out" the mass: f_new = some function of f and w
- This is similar to iterative proportional fitting (IPF) or sinkhorn-like methods

Actually, here's another idea: **Gradient flow**
- The objective (with sum f = 1 fixed) is 2n * max_k (f*f)_k
- Gradient with respect to f[i] of (f*f)_k is sum_j f[j] * delta(k, i+j) = sum_{j: i+j=k} f[j] = sum_{j=max(0,k-n+1)}^{min(k,n-1)} f[k-j]
- So the gradient of the max is the gradient of the active constraint(s)
- We can use projected gradient descent: f_new = project(f - lr * grad, nonnegative cone, sum=1)

This is essentially a subgradient method for the max function. It should work but might be slow.

Let me combine approaches:

**Final algorithm plan:**

1. **Initialization**: Use `height_sequence_1` (length 400) and also try other initializations (sine, uniform, etc.) with different lengths.

2. **LP phase** (main driver):
   - For each initialization:
     - Run iterative LP with adaptive M
     - M starts at current peak, decreases by factor (1-delta) each iteration
     - If LP infeasible, back off
     - Blend with current f using adaptive tau
     - Track best solution

3. **Local refinement** (polish):
   - On the best solution from LP phase
   - Use coordinate descent: for each coordinate i, minimize the objective with respect to f[i] (1D optimization)
   - Or use a smooth approximation (log-sum-exp) and gradient descent

4. **Validation**: Evaluate final candidate with the exact evaluator.

The problem is: minimize max_k (f*f)_k subject to f >= 0, sum(f) = 1.

This is a non-convex problem (quadratic objective with a max). But we can use the following reformulation:

minimize t
subject to (f*f)_k <= t for all k
f >= 0
sum(f) = 1

This is still non-convex because (f*f)_k is quadratic. But we can use the following iterative approach:

1. Fix f, compute t = max_k (f*f)_k
2. The active constraints are those k where (f*f)_k = t
3. Solve a QP: minimize sum_i (f_new[i] - f[i])^2 subject to (f*f_new)_k <= t*(1-eps) for active k, f_new >= 0, sum(f_new) = 1

This is a QP (quadratic objective, quadratic constraints) - still non-convex.
