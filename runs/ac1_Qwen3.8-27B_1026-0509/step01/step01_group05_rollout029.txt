**Alternative: Use the fact that the problem is equivalent to minimizing the "peak" of the convolution.**

If we think of the convolution as a "signal," we want it to be as flat as possible. This is similar to "pulse shaping" in communications.

One powerful technique is **iterative reweighting**:
1. Start with $a$.
2. Compute $b = a * a$.
3. Define weights $w_k = 1 / \max(b_k, \epsilon)$ or similar.
4. Update $a_j \leftarrow a_j \cdot \prod_k w_k^{I[k-j=j]}$... this doesn't quite work.

Actually, here's a cleaner reweighting approach:
1. Compute $b = a * a$.
2. The "pressure" on node $j$ from lag $k$ is $a_{k-j}$ (the contribution of $a_j$ to $b_k$).
3. If $b_k$ is too high, we want to decrease the $a_j$ that contribute to it.
4. Update: $a_j \leftarrow a_j \cdot \exp(-\eta \sum_k w_k a_{k-j})$ where $w_k$ weights the lags.

This is essentially mirror descent with the entropy regularizer, which is natural for nonnegative variables.

A potentially very effective approach is **alternating optimization** or **block coordinate descent**:

1. Fix the "shape" of $a$ (ratios between elements) and optimize the scale.
2. Optimize a few elements at a time (coordinate descent).

For coordinate descent: given all $a_l$ for $l \neq j$, the objective as a function of $a_j$ is:
$F(a_j) = \frac{2n \max_k b_k}{S^2}$

where $b_k = c_k + a_j(d_k + a_j e_k)$ (quadratic in $a_j$) and $S = S_0 + a_j$.

Here:
- $c_k = \sum_{l \neq j} a_l a_{k-l}$ (all terms not involving $a_j$)
- $d_k = 2 \sum_{l \neq j} a_l \cdot \mathbf{1}[k-l = j \text{ or } l = k-j]$... 

This is getting complicated. Let me think about it differently.

$b_k = \sum_{l} a_l a_{k-l}$. The terms involving $a_j$ are:
- $a_j a_{k-j}$ (when $l = j$)
- $a_{k-j} a_j$ (when $k-l = j$, i.e., $l = k-j$)

If $j = k-j$ (i.e., $k = 2j$), these are the same term, contributing $a_j^2$.
Otherwise, they contribute $2 a_j a_{k-j}$.

So $b_k = c_k + 2 a_j a_{k-j} \cdot \mathbf{1}[k \neq 2j] + a_j^2 \cdot \mathbf{1}[k = 2j]$

where $c_k = b_k - (\text{terms with } a_j)$.

This means for a fixed $a_j$, all $b_k$ are affine in $a_j$ (except $b_{2j}$ which is quadratic). The max of affine functions is convex, and adding a convex quadratic term keeps it convex. So $F(a_j)$ is... wait, $F = 2n \max_k b_k / S^2$ and $S = S_0 + a_j$ is linear. The ratio of a convex function to a positive linear function is not necessarily convex.

This is getting too complicated for coordinate descent. Let me stick with the subgradient / mirror descent approach but make it more efficient.

**Final plan for the code:**

1. Start with parent, normalize.
2. Main loop using smoothed subgradient with FFT-accelerated gradient:
   - Compute convolution via FFT.
   - Compute softmax weights over lags.
   - Compute gradient via flip-and-convolve trick.
   - Update using projected gradient (clip to nonnegative) or mirror descent (exponential).
   - Adaptive learning rate.
3. Periodic exploration: occasionally add random noise to escape local minima.
4. Final phase: fine-tune with smaller steps.
5. Return best candidate.
