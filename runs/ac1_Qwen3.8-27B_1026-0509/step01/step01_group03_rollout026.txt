    """Find b that minimizes max_k convolve(a, b)[k] subject to sum(b)=1, b>=0."""
    M = np.convolve(a, a).max()
    
    # Variables: [b_0, ..., b_{n-1}, M]
    # Minimize M (last variable)
    c = np.zeros(n + 1)
    c[-1] = 1.0
    
    # Constraints:
    # 1) convolve(a, b)[k] <= M for k = 0, ..., 2n-2
    #    sum_j a[j] * b[k-j] - M <= 0
    # 2) sum(b) = 1
    # 3) b >= 0 (encoded in bounds)
    
    # Build constraint matrix for (1)
    # Row k: [a[0..n-1] appropriately shifted, -1]
    rows = []
    for k in range(2 * n - 1):
        row = np.zeros(n + 1)
        row[-1] = -1.0
        for j in range(n):
            jj = k - j
            if 0 <= jj < n:
                row[j] = a[jj]
        rows.append(row)
    rows = np.array(rows)  # shape (2n-1, n+1)
    
    # Sum constraint: sum(b) = 1
    sum_row = np.zeros(n + 1)
    sum_row[:n] = 1.0
    
    # A_ub = rows (convolution constraints), b_ub = 0
    # A_eq = [sum_row], b_eq = [1]

                  A_eq=sum_row.reshape(1, -1), b_eq=np.array([1.0]),

One more consideration: the `project_simplex` function. Let me make sure it's correct.

The projection onto the simplex {x >= 0, sum(x) = 1} of a point v is:
1. Sort v in decreasing order: v_(1) >= v_(2) >= ... >= v_(n)
2. Find rho = max{j : v_(j) - (sum_{i=1}^{j} v_(i) - 1)/j > 0}
3. theta = (sum_{i=1}^{rho} v_(i) - 1) / rho
4. x_i = max(v_i - theta, 0)

This is the standard algorithm. Let me verify my implementation:

```python
def project_simplex(v):
    n = v.size
    u = np.sort(v)[::-1]  # decreasing
    cssv = np.cumsum(u)   # cumulative sums
    # Find rho: largest j such that u[j-1] * j > cssv[j-1] - 1
    # i.e., u[j-1] > (cssv[j-1] - 1) / j
    # Equivalently: u[j-1] * j > cssv[j-1] - 1
    rho = np.nonzero(u * np.arange(1, n + 1) > (cssv - 1))[0]
    if len(rho) == 0:
        return np.ones(n) / n
    rho = rho[-1]  # largest such index
    theta = (cssv[rho] - 1) / (rho + 1.0)
    return np.maximum(v - theta, 0)
```

This looks correct. The indices: u is 0-indexed, so u[rho] is the (rho+1)-th largest value. cssv[rho] is the sum of the top (rho+1) values. theta = (cssv[rho] - 1) / (rho+1).
