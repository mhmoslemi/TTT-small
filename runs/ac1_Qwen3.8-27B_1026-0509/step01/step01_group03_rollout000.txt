Hmm wait, I realize the LP formulation might have an issue. Let me think about it again.

The convolution `(a*b)_k = sum_j a_j * b_{k-j}`.

For fixed `a` and variable `b`, the constraint `(a*b)_k <= M` becomes:
`sum_{j: valid} a_j * b_{k-j} <= M`

Let me change variables: let `l = k-j`, so `j = k-l`. Then:
`sum_{l: valid} a_{k-l} * b_l <= M`

The valid range: `l` in `[0, n-1]` and `k-l` in `[0, n-1]`, i.e., `l` in `[max(0, k-n+1), min(n-1, k)]`.

So constraint k is: `sum_{l=max(0,k-n+1)}^{min(n-1,k)} a_{k-l} * b_l <= M`

The coefficient of `b_l` in constraint `k` is `a_{k-l}` (when valid, 0 otherwise).

In my sparse matrix construction:
- For each k (0 to 2n-2) and each valid j (i.e., l in my notation):
  - Add entry (k, l) with value a_{k-l}

In my code: `F_rows = k`, `F_cols = l`, and the data is `a[k-l] = a[F_rows - F_cols]`.

That looks correct.

The LP is: maximize `sum b_l` (i.e., minimize `-sum b_l`) subject to `A_ub @ b <= M * 1` and `b >= 0`.

This finds the "largest" (in sum) nonnegative sequence `b` whose convolution with `a` is bounded by M. Then we blend.
