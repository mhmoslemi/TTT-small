        sorted_v = np.sort(v)[::-1]

        rho = np.nonzero(sorted_v * np.arange(1, len(v)+1) > (cssv - s))[0]
        if len(rho) == 0:
            return np.full(len(v), s/len(v))
        rho = rho[-1]
        tau = (cssv[rho] - s) / (rho + 1)
        return np.maximum(v - tau, 0)

    best_score = score(best_a)

Actually, I just realized: the LP has a very specific structure. The constraint matrix A has:
A[k,j] = a_j if max(0, k-n+1) <= j <= min(n-1, k), else 0

This is essentially a (circulant-like) matrix built from a. The LP is:

The objective is max_k (a*a)_k. Think of it as: minimize t s.t. (a*a)_k <= t for all k, sum(a)=1, a>=0.

The key challenge is: the landscape of max_k (a*a)_k over the simplex has many local minima. The subgradient direction at any point only tells us to reduce the currently dominant lag(s). But reducing one lag might increase another.

A more global approach would be to consider all lags simultaneously. The "average" subgradient (averaging over many active constraints) provides a more balanced direction. But it's also less directed.

Then the subgradient is:
g = sum_k w_k * ∇(a*a)_k / sum_k w_k

This is like a softmax-weighted subgradient. With a small temperature, it focuses on the top few. With a large temperature, it's more global.

Actually, the gradient g is centered (sum=0), so some entries get multiplied by exp(positive) and some by exp(negative). Better: use the "additive" projected gradient instead:
arr_new = arr - lr * g
Then project to simplex: find tau such that sum(max(arr_new - tau, 0)) = 1.

The projection is:
sorted_arr = sort(arr_new, descending)
cssv = cumsum(sorted_arr) - 1 (subtract target sum)
rho = largest j where sorted_arr[j] > (cssv[j] - 1) / (j+1)
tau = (cssv[rho] - 1) / (rho + 1)
arr_new = max(arr_new - tau, 0)

This maintains sum=1 and a>=0 exactly, and doesn't have the underflow issue (entries can go to 0 but not below, and the projection redistributes mass).

Let me implement the simplex projection:

```python
def project_simplex(v, s=1.0):
    n = len(v)
    sorted_v = np.sort(v)[::-1]
    cssv = np.cumsum(sorted_v)
    # Find rho: largest j such that sorted_v[j] * (j+1) > cssv[j] - s
    ind = np.arange(1, n+1)
    cond = (sorted_v * ind - (cssv - s)) > 0
    rho = np.max(np.nonzero(cond)[0]) + 1  # 1-indexed
    tau = (cssv[rho-1] - s) / rho
    return np.maximum(v - tau, 0.0)
```
