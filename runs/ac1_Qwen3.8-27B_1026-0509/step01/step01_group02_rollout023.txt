Let me think about the smooth max approach:
$$f_\beta(a) = \frac{1}{\beta} \log \sum_{k=0}^{2n-2} \exp(\beta \cdot c_k)$$

This is a smooth upper bound on $\max_k c_k$, and as $\beta \to \infty$ it approaches the max. The gradient is:
$$\nabla_i f_\beta = \frac{2}{\beta} \sum_k \frac{\exp(\beta c_k)}{\sum_j \exp(\beta c_j)} \cdot \frac{\partial c_k}{\partial a_i}$$

where $\frac{\partial c_k}{\partial a_i} = a_{k-i} + a_{i-k}$ (with appropriate bounds).

This gives us a proper gradient that we can use with Adam or other optimizers.

However, computing this gradient requires the softmax weights over all $2n-1$ lags, which is $O(n)$, and then for each component $i$, the gradient involves a sum over $k$ where $a_{k-i}$ is defined. This is actually a convolution!

Let me think more carefully. If $w_k = \exp(\beta c_k) / \sum_j \exp(\beta c_j)$, then:
$$\nabla_i f_\beta = \frac{2}{\beta} \sum_{k: 0 \leq k-i \leq n-1} w_k \cdot a_{k-i} + \frac{2}{\beta} \sum_{k: 0 \leq i-k \leq n-1} w_k \cdot a_{i-k}$$

The first sum is $(w * a)_i$ (with $w$ defined on $[0, 2n-2]$), and the second sum is $(\tilde{w} * a)_i$ where $\tilde{w}_k = w_{-k}$ (reflection).

So the gradient is:
$$\nabla f_\beta = \frac{2}{\beta} (w * a + \tilde{w} * a)$$

This can be computed with 2 FFTs! Very efficient.
