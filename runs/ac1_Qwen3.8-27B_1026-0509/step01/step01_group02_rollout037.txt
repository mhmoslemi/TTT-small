```python
def _softmax_topK(c, K, temperature=0.01):
    """Get softmax weights on the top K values of c."""
    n = len(c)
    # Find top K indices
    if K >= n:
        idx = np.argsort(c)[::-1]
    else:
        # Use partition for efficiency
        part = np.argpartition(c, -K)[::-1]
        idx = part[:K]
        idx = idx[np.argsort(c[idx])[::-1]]

    # Softmax with temperature
```

**Alternative: Frank-Wolfe / conditional gradient**

The Frank-Wolfe algorithm works on the feasible set {x >= 0, sum(x) = 1} (the simplex). At each step:
1. Compute the gradient g of the objective (or a subgradient)
2. Find the vertex v of the simplex that minimizes <g, v> (which is v = e_j where j = argmin g)
3. Move: x <- (1-t)*x + t*v

The step size t can be chosen by line search or a fixed schedule.

This is interesting because it naturally stays on the simplex and doesn't need projection. The vertex is always a standard basis vector, so the update is: x[j] += t for one j and x[i] -= t/n for all other i (approximately).

Actually, the Frank-Wolfe step for the simplex is:
- v = e_{argmin g} (the vertex with the smallest gradient component)
- x_new = (1-t)*x + t*e_j where j = argmin g

This means we're adding mass to the coordinate with the smallest gradient and subtracting proportionally from all others. This might not be ideal because it always moves towards a vertex.

A better variant is the "pairwise Frank-Wolfe" or "conditional gradient" where we move along a direction that's a difference of two simplex vertices.

```python
def _clip_rescale(p):
    p = np.maximum(p, 0)
    s = p.sum()
    if s < 1e-300:
        return np.ones(len(p)) / len(p)
    return p / s
```
