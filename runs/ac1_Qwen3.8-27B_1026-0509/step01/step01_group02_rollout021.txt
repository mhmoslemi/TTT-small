From numpy docs:
`numpy.correlate(a, v, mode='valid')`

For 'valid' mode, only those outputs that are computed using the complete overlap between the arrays are considered. The length of the output is `max(M, N) - min(M, N) + 1` where M and N are the lengths of a and v.

The formula: `c_k = sum_n a_n * conj(v_{n-k})`

So `np.correlate(wts, a, 'valid')[k] = sum_n wts[n] * a[n-k]`

where the sum is over n such that both `wts[n]` and `a[n-k]` are defined.

`wts` has length `2n-1` (indices 0 to 2n-2)
`a` has length `n` (indices 0 to n-1)

For output index k, we need `a[n-k]` to be valid, i.e., `0 <= n-k <= n-1`, so `k <= n <= k+n-1`.
Also `wts[n]` must be valid: `0 <= n <= 2n-2`.

The range of n for a given k: `max(0, k) <= n <= min(2n-2, k+n-1)`

For 'valid' mode, we need the complete overlap, meaning:
`min(M, N) iterations`. The output length is `M - N + 1 = (2n-1) - n + 1 = n`.

For output index k (0-indexed in the valid output):
The valid range is `k <= n <= k + n - 1` (from the a constraint) and `0 <= n <= 2n-2` (from the wts constraint).

So `n` ranges from `k` to `min(k+n-1, 2n-2)`.
Since `k <= n-1` (valid output has n elements, k = 0 to n-1):
- Lower bound: `max(0, k) = k`
- Upper bound: `min(k+n-1, 2n-2)`
  - `k+n-1 <= 2n-2` iff `k <= n-1`, which is always true for valid k
  - So upper bound is `k+n-1`

Therefore: `np.correlate(wts, a, 'valid')[k] = sum_{n=k}^{k+n-1} wts[n] * a[n-k]`

Let `j = n-k`: `= sum_{j=0}^{n-1} wts[k+j] * a[j]`

This is exactly what we want! `grad_unscaled[k] = sum_{j=0}^{n-1} wts[k+j] * a[j]`

So `grad = beta * np.correlate(wts, a, 'valid')` is correct.

def propose_candidate(seed=42, budget_s=1500, **kwargs):

    rng = np.random.default_rng(seed)

    L = 1 << (2 * n - 1).bit_length()

    def autocorr(x):
        fa = rfft(x, L)
        return irfft(fa * fa, L)[:2 * n - 1]

    best = a.copy()
    best_score = 2.0 * n * autocorr(best).max()

    m_ad = np.zeros(n)
    v_ad = np.zeros(n)
    b1, b2, eps = 0.75, 0.999, 1e-8
    t = 0
    stall = 0
    stall_limit = 30000
    phase = 0

    for it in range(2000000):
        if time.monotonic() > deadline:
            break

        c = autocorr(a)
        score = 2.0 * n * c.max()

        if score < best_score - 1e-12:
            best_score = score
            best = a.copy()
            stall = 0
        else:
            stall += 1

        if stall > stall_limit:
            if phase < 3:
                phase += 1
                stall_limit = max(5000, stall_limit // 3)
            a = best + rng.normal(0, 0.05 / n, n)
            a = np.maximum(a, 0)
            a /= a.sum()
            m_ad[:] = 0
            v_ad[:] = 0
            t = 0
            stall = 0
            phase = 0

        beta = 8.0 + 4.0 * np.log1p(it / 500.0)
        beta = min(beta, 500.0)

        cs = c - c.max()
        wts = np.exp(beta * cs)
        wsum = wts.sum()
        if wsum < 1e-300:
