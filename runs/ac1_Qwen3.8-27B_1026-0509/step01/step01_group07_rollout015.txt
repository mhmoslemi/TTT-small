```python
def project_simplex(v):
    """Project v onto {x >= 0, sum(x) = 1}"""
    n = len(v)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u)
    rho = np.where(u * np.arange(1, n+1) > (cssv - 1))[0][-1]
    theta = (cssv[rho] - 1) / (rho + 1)
    return np.maximum(v - theta, 0)
```

By scale invariance, set sum(a) = 1. Minimize 2n * max_k c_k.

The constraints on c:
- c >= 0 (since a >= 0)
- sum_k c_k = 1 (since (sum a)^2 = 1)
- c is the autocorrelation of a nonnegative sequence

The last constraint is the key one that makes this hard. Not every nonnegative sequence c with sum 1 is achievable as the autocorrelation of a nonnegative sequence.

However, if we ignore the "a >= 0" constraint and just require that c is a valid autocorrelation (i.e., its DFT is nonnegative), then the optimal c is the uniform distribution: c_k = 1/(2n-1) for all k. This gives max c_k = 1/(2n-1) and score = 2n/(2n-1) ≈ 1.

But c_k = 1/(2n-1) for all k is not achievable with a >= 0 (as I discussed earlier). The best we can do with a >= 0 is somewhere between 1 and 2.

The target is 1.50274, which suggests the optimum (or near-optimum) for n=6962 is around 1.5.

One idea: use a sequence whose Fourier transform has approximately constant magnitude. For a nonnegative sequence, this means the sequence is a "logarithmically uniform" sequence in some sense.

Actually, I recall that for the problem of minimizing the peak of the autocorrelation (with the nonnegativity constraint), the optimal solution is related to the "almost difference set" or "cyclic difference set" constructions. But those are for 0-1 sequences.

For continuous nonnegative sequences, I think the optimal solution is a sequence that's close to a "raised cosine" or "B-spline" type window, but modified to have a flatter autocorrelation.

Wait, this makes sense. The uniform sequence is a local minimum of the objective! Any small perturbation increases the peak.

So the uniform sequence is a local minimum, and to get below 2, we need a large perturbation (not a small one).

This means gradient-based methods starting from the uniform sequence won't help. We need a global optimization approach or a different initialization.

Let me think about what kind of sequence would give score < 2.

We need: 2n * max(c) / (sum a)^2 < 2
=> max(c) < (sum a)^2 / n

For the uniform sequence: max(c) = n * (1/n)^2 = 1/n (when sum a = 1). And (sum a)^2/n = 1/n. So it's exactly at the boundary.

For a non-uniform sequence: we need max(c) < (sum a)^2 / n.

But we know that c[n-1] = sum_j a_j * a[n-1-j] (the cross-correlation with the reverse). By Cauchy-Schwarz:
c[n-1] <= (sum a_j^2)^(1/2) * (sum a_j^2)^(1/2) = sum a_j^2

And sum a_j^2 >= (sum a_j)^2 / n (by Cauchy-Schwarz).

So c[n-1] <= sum a_j^2, but we need c[n-1] < (sum a)^2 / n <= sum a_j^2.

This means we need c[n-1] < (sum a)^2 / n, which is possible if the sequence is sufficiently asymmetric (so that a_j and a_{n-1-j} don't align well).

But we also need all other c[k] to be < (sum a)^2 / n.
