Wait, I'm making an error. The projection onto {x >= 0, sum(x) = 1} is NOT just clipping to non-negative and then normalizing. The correct projection is:
x_proj[i] = max(0, v[i] - t) where t is chosen so sum x_proj = 1.

The normalization step (dividing by sum) is only correct if all elements are already non-negative. If some are negative after the gradient step, we need the water-filling projection.

But actually, if I use the simpler "clip to non-negative and normalize" approach, it's not the exact projection but it's a valid "proximal-like" step. It won't give the same convergence guarantees, but it might work in practice.

Let me use the exact projection for correctness:

```python
def project_simplex(v, target=1.0):
    """Project v onto {x >= 0, sum(x) = target}."""
    # Water-filling: find t such that sum(max(0, v - t)) = target
    lo, hi = 0.0, v.max() + target
    for _ in range(50):
        mid = (lo + hi) * 0.5
        s = np.maximum(v - mid, 0.0).sum()
        if s > target:
            lo = mid
        else:
            hi = mid
    t = (lo + hi) * 0.5
    return np.maximum(v - t, 0.0)
```

This is O(50 * n) per call. For n=6962, that's ~350k operations. Acceptable.

Actually, 50 iterations of bisection might be overkill. The precision needed is relative to the values (which are O(1/n) ≈ 1.4e-4 for n=6962). With 50 bisection iterations on [0, max], we get precision 2^-50 * max ≈ 1e-15, which is more than enough. But even 30 iterations give 1e-9 precision. Let me use 35 to be safe.

Now, let me also think about whether the FISTA approach will actually work well here. The issue is that the max function is non-smooth at points where two components of the convolution are tied. At such points, the subgradient is any convex combination of the gradients of the tied components. Using just one active gradient might cause oscillation.

To handle this, I can:
1. Use a "smoothed max": max_k C[k] ≈ (1/t) * log(sum exp(t*C[k])) for large t
2. Or just accept the non-smoothness and hope FISTA works (it does for convex problems)

Actually, FISTA with the subgradient of a single active constraint does work for convex problems, just with potentially slower convergence near non-smooth points. Let me proceed.

- SCA (Successive Convex Approximation): at each step, solve a quadratic program that approximates the max
- Or use the "active set" approach: maintain a set of k values that are "nearly maximal" and solve the QP for that active set
