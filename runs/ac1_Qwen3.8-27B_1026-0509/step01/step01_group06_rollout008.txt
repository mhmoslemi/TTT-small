def _project_simplex(v):
    """Project v onto the probability simplex {x >= 0, sum(x) = 1}."""
    n = len(v)

    rho = cond.sum() - 1  # 0-indexed
    theta = cssv[rho] / (rho + 1)

The constraint (a*g)[k] = sum_i a[i]g[k-i] <= M.

For g >= 0 and a >= 0, the maximum possible sum(g) is bounded. If we then rescale g to sum=1, the peak of g*g might be lower than a*a.

The key insight of the LP approach: it finds the "flattest" g (in terms of maximizing sum while keeping a*g bounded). This tends to spread g's mass evenly, reducing its self-convolution peak.

def _ps(v):
    """Project onto simplex (nonneg, sum=1)."""
    v = v.copy()
    n = len(v)
    u = np.sort(v)[::-1]
    cssv = np.cumsum(u) - 1
    rho = np.searchsorted(-cssv, -1, side='right')  # hmm
    # Standard algorithm:
    cond = u * np.arange(1, n+1) > cssv
    rho = cond.sum() - 1
    if rho < 0:
        rho = 0
    theta = cssv[rho] / (rho + 1)
    return np.maximum(v - theta, 0)
