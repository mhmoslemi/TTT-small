= (1/Z) * sum_k exp(β*c_k) * 2*a[k-i] (with bounds)

- This is 2 * (w * a) convolved... wait, it's the cross-correlation of w and a!

(w ⊛ a)_i = sum_k w_k * a[k-i] (with a=0 outside [0,n-1])

This can be computed with FFT!

1. Compute c = a*a (via FFT)
2. Compute w = exp(β*c) / sum(exp(β*c))
3. Compute grad = 2 * cross_correlate(w, a) (via FFT)
4. Project gradient onto tangent space (subtract mean)
5. Update a

Now, to minimize log Z subject to sum(a) = 1, a >= 0:

- At optimum: 2*(w⊛a)_i - λ - μ_i = 0

Now, the key question is: what β and lr to use?
- β too small: the smooth approximation is too "flat" and doesn't capture the max
- β too large: numerical issues (exp overflows) and the gradient is concentrated on a few points (like a subgradient)
- lr too large: oscillations
- lr too small: slow convergence

A good heuristic: start with β = 10/M (where M = max(c)), so that β*c ranges from 0 to ~10. This gives a smooth but peaked weight distribution.

Then use a decreasing learning rate: lr = lr0 / (1 + it * 0.01) or lr = lr0 / sqrt(it + 1).
