**LP approach refined:**

The idea from the paper (and strategy) is:
1. Given a, compute M = max(conv(a,a)).
2. Solve LP: max sum(g) s.t. conv(a,g) <= M, g >= 0.
3. Scale g to have sum = sum(a).
4. Update: a ← (1-t)*a + t*g.

The LP in step 2: The constraint conv(a,g) <= M means for each k = 0, ..., 2n-2:
sum_{i: valid} a[i]*g[k-i] <= M

This is a system of (2n-1) linear inequalities in n variables. The matrix is a banded Toeplitz-like matrix.

For n = 6962, this is a 13923 × 6962 system. Too large for most LP solvers in reasonable time.

However, we can use a **column generation** or **separation oracle** approach:
- Start with a small set of active constraints.
- Solve the LP with just those constraints.
- Check if any other constraint is violated by the solution.
- Add violated constraints.
- Repeat.

This is the cutting-plane method for LPs. Each sub-LP has at most n constraints (one per variable binding + the added cuts).

Alternatively, we can use a **Lagrangian relaxation** or **multiplicative weight** approach that avoids the LP entirely.

**Multiplicative weight / EXP3 approach:**

This is actually very natural for our problem. Think of it as a game:
- The "row player" chooses a lag k (adversarially, to maximize conv(a,g)[k])
- The "column player" chooses g >= 0, sum(g) = sum(a)
- Payoff: conv(a,g)[k] / M

The multiplicative weight algorithm for the column player:
g[i] ∝ exp(-η * sum_k q[k] * ∂conv(a,g)[k]/∂g[i])

where q is the empirical distribution over lags (from the row player's strategy).

But this is essentially the same as the gradient ascent I described earlier!

4. Periodically "anneal" by adding random perturbations.

2a^2 + 2b^2 = 2t^2 + 2(1/2-t)^2 = 2t^2 + 2(1/4 - t + t^2) = 2t^2 + 1/2 - 2t + 2t^2 = 4t^2 - 2t + 1/2
2ab + b^2 = t(1/2-t) + (1/2-t)^2 = t/2 - t^2 + 1/4 - t + t^2 = 1/4 - t/2

So we want to minimize max(4t^2 - 2t + 1/2, 1/4 - t/2).

Set them equal: 4t^2 - 2t + 1/2 = 1/4 - t/2
4t^2 - 3t/2 + 1/4 = 0
16t^2 - 6t + 1 = 0
t = (6 ± sqrt(36-64))/32 = (6 ± sqrt(-28))/32

Discriminant is negative! So the two functions never cross. Let me check which is larger.

4t^2 - 2t + 1/2 vs 1/4 - t/2:
4t^2 - 2t + 1/2 - (1/4 - t/2) = 4t^2 - 3t/2 + 1/4

At t = 0: 1/4 > 0. At t = 1/4: 4/16 - 3/8 + 1/4 = 1/4 - 3/8 + 1/4 = 1/4 > 0. At t = 1/2: 1 - 3/4 + 1/4 = 1/4 > 0.

So 4t^2 - 2t + 1/2 > 1/4 - t/2 for all t in [0, 1/2]. The max is always 4t^2 - 2t + 1/2.

Minimize 4t^2 - 2t + 1/2: derivative = 8t - 2 = 0, t = 1/4.
Value: 4/16 - 1/2 + 1/2 = 1/4.

So a = 1/4, b = 1/4. That's the uniform sequence! And max = 1/4, T = 2*4*(1/4)/1 = 2.
