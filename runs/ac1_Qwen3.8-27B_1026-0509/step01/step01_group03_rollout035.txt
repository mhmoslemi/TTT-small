For binary sequences, the minimum aperiodic autocorrelation is well-studied. For real non-negative sequences, it's a different problem.

The key challenge: for a non-negative sequence, the "energy" at the center lag c[n-1] = sum a[i]*a[n-1-i] can be made small if the sequence is "anti-palindromic" (large values on one side, small on the other). But then the edge lags (like c[0] = a[0]², c[1] = 2a[0]a[1], etc.) might be large.

The optimal trade-off balances all lags.

For n=200, the parent achieves 1.518835, which means max_c = 1.518835 * S² / 400. If S=1, max_c ≈ 0.003797. The "average" value of c[k] is S²/(2n-1) ≈ 1/400 ≈ 0.0025. So the max is about 1.52 times the average, which makes sense (score ≈ 2 * (max/average) / (2n-1) * n ≈ 2 * 1.52 * n/(2n) ≈ 1.52 for large n).

Actually, more precisely: if all c[k] were equal, each would be S²/(2n-1), and the score would be 2n * S²/((2n-1)*S²) = 2n/(2n-1) ≈ 1. So the theoretical minimum approaches 1 as n→∞ (if we could make the autocorrelation perfectly flat).

For n=200, the theoretical lower bound is 2*200/399 ≈ 1.0025. The parent achieves 1.519, which is about 52% above this bound.

So there's room for improvement, but it requires making the autocorrelation quite flat.
