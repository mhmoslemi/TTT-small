Let me also think about the initial value of lr. The subgradient g has entries up to 2*max(a) = 2*(some value). For the normalized a (sum=1), max(a) is at most 1 (if one element is 1 and rest are 0). Typically, max(a) ≈ 1/sqrt(1) = 1 (for the 1/sqrt shape, a_0 = 1/sqrt(S) ≈ 1/13).

So g entries are at most 2*1 = 2 (for the extreme case) or about 2/13 ≈ 0.15 (for the 1/sqrt shape).

For mirror descent, the step size lr should be chosen so that the update a_j *= exp(-lr * g_j) doesn't change a too dramatically. If lr * max(g) ≈ 1, then the factors are in [e^{-1}, 1] ≈ [0.37, 1], which is reasonable.

For the 1/sqrt shape: max(g) ≈ 2/13 ≈ 0.15. So lr = 1/0.15 ≈ 6.7 would give lr * max(g) ≈ 1. Let me start with lr = 5.

Actually, let me think about this more carefully. The mirror descent step is:
a_j^{new} = a_j * exp(-lr * g_j) / Z

where Z = sum_j a_j * exp(-lr * g_j).

The relative change in a_j is exp(-lr * g_j) / Z. If lr * g_j is small, this is ≈ 1 - lr * g_j.

The "natural" step size for mirror descent on the simplex is lr = 1 / (L * sqrt(K)) where L is the Lipschitz constant of the objective and K is the dimension. But that's a worst-case bound and might be too small.

In practice, I'll use an adaptive scheme:
- Start with lr = 1.
- Evaluate the score after each step.
- If score improved, keep lr or increase slightly.
- If score got worse, halve lr.

Let me now write the final code. I'll keep it concise and focused on the algorithm.

One more consideration: the parent sequence has n = 4806 elements. The FFT size needs to be at least 2*4806 - 1 = 9611. The next power of 2 is 16384. An FFT of size 16384 takes about 0.05ms. So each iteration (FFT + update) takes about 0.1ms. We can do about 10,000 iterations per second.

With 1000 seconds of compute time, we can do about 10 million iterations. That's more than enough.

But the mirror descent might converge slowly (diminishing returns). Let me add a mechanism to switch to a "refinement" mode when progress slows.

In refinement mode, I'll use a "top-k" approach: instead of just the argmax, I'll use a weighted combination of the top k lags. This gives a smoother descent direction and might converge faster near the optimum.

import numpy as np
from scipy.fft import fft, ifft
import time

def propose_candidate(seed=42, budget_s=1500, **kwargs):
    rng = np.random.default_rng(seed)
    start_time = time.monotonic()
    deadline = start_time + max(0.0, float(budget_s) - 10.0)
    
    # Get parent
    try:
        parent = np.clip(np.asarray(height_sequence_1, dtype=np.float64), 0, 1000)
        if parent.ndim != 1 or parent.size == 0 or not np.isfinite(parent).all():
            raise ValueError
        n = parent.size
    except:
        parent = None
        n = 4806
    
    # FFT setup
    fft_size = 1
    while fft_size < 2 * n - 1:
        fft_size <<= 1
    
    def compute_conv(a):
        A = fft(a, fft_size)
        return ifft(A * A, fft_size).real[:2*n-1]
    
    def score_of(a):
        S = a.sum()
        if S < 1e-10:
            return np.inf
        return 2.0 * n * compute_conv(a).max() / (S*S)
    
    # Initialization
    idx = np.arange(1, n+1, dtype=np.float64)
    a_sqrt = 1.0 / np.sqrt(idx)
    a_sqrt /= a_sqrt.sum()
    
    best_a = a_sqrt.copy()
    best_score = score_of(a_sqrt)
    
    if parent is not None:
        p = parent / parent.sum()
        for w in [0.3, 0.5, 0.7, 1.0]:
            a_try = w * a_sqrt + (1-w) * p
            sc = score_of(a_try)
            if sc < best_score:
                best_score = sc
                best_a = a_try.copy()
    
    # Phase 1: Mirror descent
    a = best_a.copy()
    lr = 5.0
    no_improve = 0
    patience = 2000
    
    for it in range(1000000):
        if time.monotonic() > deadline - 60:
            break
        
        c = compute_conv(a)
        k_star = int(c.argmax())
        cur_score = 2.0 * n * c.max()
        
        if cur_score < best_score - 1e-12:
            best_score = cur_score
            best_a = a.copy()
            no_improve = 0
        else:
            no_improve += 1
        
        # Subgradient of c_{k_star}
        g = np.zeros(n)
        jlo = max(0, k_star - n + 1)
        jhi = min(n-1, k_star)
        g[jlo:jhi+1] = 2.0 * a[k_star - np.arange(jlo, jhi+1)]
        
        # Mirror descent update
        s = lr * g
        s -= s.max()
        log_a = np.log(np.maximum(a, 1e-300)) + s
        log_a -= log_a.max()
        a = np.exp(log_a)
        a /= a.sum()
        
        # Adaptive step
        if no_improve % 500 == 0:
            if no_improve > patience:
                lr *= 0.5
                if lr < 1e-4:
                    # Random restart
                    a = best_a * (1 + 0.05 * rng.standard_normal(n))
                    a = np.clip(a, 1e-10, None)
                    a /= a.sum()
                    lr = 5.0
                    no_improve = 0
            # Check if we should increase lr
            elif no_improve == 0:
                lr = min(lr * 1.1, 50.0)
    
    # Phase 2: Top-k refinement
    a = best_a.copy()
    lr2 = 0.5
    for it in range(500000):
        if time.monotonic() > deadline - 30:
            break
        
        c = compute_conv(a)
        k_star = int(c.argmax())
        cur_score = 2.0 * n * c.max()
        
        if cur_score < best_score - 1e-12:
            best_score = cur_score
            best_a = a.copy()
