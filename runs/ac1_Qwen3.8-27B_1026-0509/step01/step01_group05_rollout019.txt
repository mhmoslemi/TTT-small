A better approach might be to use a **proximal gradient method** on a smoothed version of the objective. Specifically:
1. Use `f_smooth(a) = 2n * softmax_tau(ac(a))_max / S^2` where `softmax_tau(x)_max = tau * log(sum exp(x_k/tau))`.
2. Compute the true gradient of this smoothed function.

The gradient of `f_smooth` is:
`∇f_smooth_i = 2n/S^2 * (S * ∂L/∂a_i - 2L/S)`
where `L = tau * log(sum_k exp(ac_k/tau))` and `∂L/∂a_i = sum_k p_k * ∂ac_k/∂a_i` with `p_k = exp(ac_k/tau)/sum_j exp(ac_j/tau)`.

And `∂ac_k/∂a_i = 2*a_{k-i}` for `0 <= k-i < n`, else 0.

So `∂L/∂a_i = sum_{k: 0<=k-i<2n-1} p_k * 2*a_{k-i}` (restricted to valid range).

This can be computed as a weighted sum of shifted copies of a, which is a convolution-like operation. Specifically:
`∂L/∂a_i = 2 * sum_k p_k * a_{k-i} * [0 <= k-i < n]`

Let me define `q[k] = p[k]` for k in [0, 2n-2] and 0 otherwise. Then:
`∂L/∂a_i = 2 * (q * a)[i]` where `*` denotes cross-correlation: `(q ⋆ a)[i] = sum_k q[k] * a[k-i]`.

Wait, that's not quite right. Let me be more careful:
`∂L/∂a_i = 2 * sum_k p_k * a_{k-i} * [0 <= k-i < n]`

= `2 * sum_{j: 0<=j<n} p_{i+j} * a_j` (substituting j = k-i, so k = i+j)

This is a cross-correlation of p and a at lag i: `C[i] = sum_j p[i+j] * a_j`.

We can compute this using FFT: `C = ifft(fft(p, N) * conj(fft(a, N)))` for appropriate N. But we need to be careful about the definition.

Actually, the standard cross-correlation is `(f ⋆ g)[i] = sum_j f[j+i] * conj(g[j])`. For real signals, this is `sum_j f[j+i] * g[j]`.

So `C[i] = (p ⋆ a)[i] = sum_j p[j+i] * a[j]`. And we want `∂L/∂a_i = 2 * C[i]`.

`a_ext = [a_0, a_1, ..., a_{n-1}, 0, 0, ..., 0]` (length N)
