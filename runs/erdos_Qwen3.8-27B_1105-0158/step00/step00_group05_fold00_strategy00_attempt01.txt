## 1. Approach and rationale

The task is to find a discrete feasible vector `h` such that

```text
0 <= h[i] <= 1
sum(h) = n/2
score(h) = max_k np.correlate(h, 1-h, "full")[k] * (2/n)
```

is as small as possible. The feasible set is convex because it is a hyperplane section of the unit cube, but the score is bilinear/nonconvex: each correlation term contains products `h[i]*(1-h[j])`. Therefore a convex global optimization method is not directly applicable, and any solver call should be understood as local if it uses a nonconvex or smoothed score.

The proposed strategy is a robust multi-stage local/global search:

1. **Start from the supplied parent**, but do not remain there. The parent may already be a local optimum around very active lag maxima, so improve it by constrained smooth maximization descent.

2. **Use a smooth log-sum-exp surrogate** for the maximum overlap and run constrained continuous descent using SciPy’s `SLSQP`. This can reduce the largest, near equal, active lag terms because it gives a smooth gradient to the smallest local peak rather than only the single active max. The final objective is always evaluated exactly, not using the surrogate.

3. **Preserve feasibility with joint repair**. The required mean and box constraints are implemented by an exact translation/water-filling repair and by a later dyadic quantization/integer-sum construction for the final vector. This avoids the disconnected errors of clipping followed by rescaling.

4. **Escape local smooth minima with stochastics**. Simulated-annealing/gradient-probe searches are performed on both continuous and exactly feasible dyadic states, using full-scale support-preserving moves and exactly balanced swaps. This addresses nonconvex basins, especially on discrete, binary-like vectors.

5. **Try several resolutions/transfers if time permits**. Although smaller sequences are preferred, transfer the upsampled transfer of the parent helps move between basins. Larger resolution is only attempted if the current parent needs further improvement and time remains.

The method is not a proof of global optimality after the supplied parent. It is an iterative reproduction strategy with an initial validated fallback.

## 2. Mathematical specification

### 2.1 Raw discrete objective and lag indexing

For a vector `h` of length `n`:

- `dx = 2.0 / n`
- target mass `M = n / 2`
- raw score is:

```text
score(h) = max_j c[j] * dx
c = np.correlate(h, 1.0 - h, mode="full")
```

This exact term is authoritative. The surrogate always has to be compared to the actual score below.

For analytic surrogate objective and gradient, use the equivalent indexing:

Let `t = 0, 1, ..., n-1` and `L_t = n - t`.

```text
P_0 = P_0 from the aside, or hold the following equal-index term handled separately.
For t=1,...,n-1:
P_t = dx * sum_{i=0}^{L_t-1} h[i+t] * (1 - h[i])
Q_t = dx * sum_{i=0}^{L_t-1} h[i] * (1 - h[i+t])
```

The overlap for `t=0` is:

```text
D_0 = dx * sum_i h[i] * (1 - h[i])
```

The set

```text
{D_0} union {P_t: t=1..n-1} union {Q_t: t=1..n-1}
```

has exactly `2n-1` elements and is a permutation of the full linear correlation values for `np.correlate(h, 1-h, mode="full")`. The exact evaluator is still an authoritative recheck, but this formula is equivalent to finite correlation including both direct and reverse lags.

### 2.2 Smoothed maximization and its gradient

Let `T(h)` be a vector containing all raw objective terms

```text
[T0, P1, Q1, ..., P_{n-1}, Q_{n-1}]
```

where `T0 = D0`. Define a smooth surrogate

```text
Max_beta(h) = max(T) + (1/beta) * (log(sum(exp(beta*(T - max(T)))) - log(len(T))))
```

The subtracted term `(log(len(T)) / beta)` removes the unavoidable LSE bias when all terms are equal and makes the surrogate converge to `max(T)` as `beta` grows. This LSE has the same minimum behavior on near-active terms and is easier for gradient methods than `max` itself.
