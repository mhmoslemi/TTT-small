<strategy>
1. Approach and rationale

The current parent construction is already extremely close to the target, so the search must be centered on producing a verified slight decrease from about 0.38085 to 0.38080 or lower while never changing the exact evaluator definition. The only accepted value is always computed from the returned vector as

    c5 = dx * max_j np.correlate(h, 1-h, mode="full")_j,
    dx = 2.0 / len(h).

The central idea is a feasible-direction hybrid exact-metric descent. Every move preserves or restores the exact interval density constraint and box bounds, and every proposal is scored using the actual correlation evaluator, not a surrogate, not a circular autocorrelation proxy, and not a relaxed lower bound. The method is materially different from both global hypograph nonlinear programming and simple smooth log-sum-exp maximization because it does not try to make the nonsmooth global max into one differentifiable objective that it then solves. Instead it alternates:

- low-dimensional deformation of the parent through a global differential-evolution phase, with feasible repair inside every objective evaluation, and
- local exact-metric feasible exchanges and zero-sum gradient-aligned line searches from a parent or transferred parent.

The local part focuses on two exact operations that are very cheap and very relevant for minimizing a family of pairwise overlap terms:

- a weighted zero-sum vector direction derived from active raw overlap terms, followed by exact line search along a strictly feasible segment, and
- transfer of small mass between a donor index and a receiver index, followed by exact line search along the exactly area-preserving unit direction.

Both directions are feasible families that change the mass budget only by moving mass from higher constrained product areas to other positions, while keeping the integral exactly. The donor/receiver direction is a natural exact representation of an admissible pairwise exchange over the step-function values and works even when values are at 0 or 1.

Why this should improve the parent:

- The optimum, or near-optimum, lies on nonsmooth constraints where several shifted overlap terms are equal near the maximum and active. Pairwise transfers and zero-sum gradient moves can increase or decrease selected shifted products exactly when active overlap policies select them.
- The supplied parent has 95 samples, an odd length, so any exact vector has a fractional mass budget. A direct transfer to an even nearby length, especially 96, makes the target sum integer and often gives local descent methods another basin or another discretization that can be repaired to a slightly lower exact objective.
- Low-dimensional deformation provides parameters that change global monotone or oscillatory properties of the parent without introducing the many corrugated degrees-of-freedom that make the parent or a short length fall back into itself.
- The asymmetric boundary correlations are preserved because every proposal is checked with the exact `np.correlate(..., mode="full")` vector.
- Close restart candidates from several nearby dimensions are beneficial. Lower dimensions are cheaper, can be faster, and are accepted only if their exact evaluated upper bound is genuinely lower. Larger even dimensions can provide a more regular density-sum constraint and extra resolution.

The method is nonconvex and local, and no optimality claim is made. The goal is a verified returned candidate with evaluator recomputed bound perhaps 0.38080 or smaller. If not achieved, the program simply returns the best exact valid candidate found, while retaining the validated parent as fallback.

2. Mathematical specification

2.1 Exact discrete objective and scaling

Let `n = len(h)`, `dx = 2.0/n`, and `T = n / 2.0`. Feasibility is

    0 <= h[i] <= 1 for all i,
    sum_i h[i] = T.

The exact score is

    raw_j = np.correlate(h, 1-h, mode="full")_j,
    C_h = dx * max_j raw_j.
    max_j raw_j is the raw active overlap. Since `dx` is positive and constant for fixed dimension, local descent directions can be listened to in raw associated units and final comparisons done via C_h.

The objective uses linear correlation over finite support and both positive and negative lags. The vector length `2n-1` includes lags from `-n+1` to `n-1`. No circular wrap-around is intended.

2.2 Exact lag interpretation and derivative orientation

The exact formula for each row is determined from the NumPy evaluator. To remove any possibility of swapping positive and negative lags, implement in every dimension a one-vector orientation detector.

For the current dimension `n`, generate a non-symmetric deterministic test vector `x_test`, for example a repaired/feasible density of length `n` based on `0.5 + 0.15*cos(2*pi*i/n + phase_n) + 0.1*sin(4*pi*i/n + phase_n)`. Compute

    R_true = np.correlate(x_test, 1-x_test, mode="full").

Define two candidate lag formulas that both cover all outputs.

Mode A evaluation:
For output index `r = 0 ... 2n-2`:

    if r >= n-1:
        k = r-(n-1), 0 <= k <= n-1
        R_A[r] = sum_{t=0}^{n-k-1} x_test[t+k] * (1-x_test[t])
    if r < n-1:
        e = (n-1)-r, e>0
        R_A[r] = sum_{t=0}^{n-e-1} x_test[t] * (1-x_test[t+e])

Mode B evaluation is the reversed lag labeling:
For output index `r`:

    if r >= n-1:
        k = r-(n-1)
        R_B[r] = sum_{t=0}^{n-k-1} x_test[t] * (1-x_test[t+k])
    if r < n-1:
        e = (n-1)-r
        R_B[r] = sum_{t=0}^{n-e-1} x_test[t+e] * (1-x_test[t])

Compare `raw_A - R_true` and `raw_B - R_true`. Choose the mode whose maximum absolute component difference is `< 1e-10`; break ties arbitrarily. In practice exactly one of the modes should match. Store the mode as `lag_mode`.

For local gradient calculations use the matching-mode formulas. For a selected active row, define its raw contribution and exact gradient with respect to `h`, without the `dx` multiplier, as follows.

Only rows with nonzero active weights are looped over. If a row with lag pairing uses the Mode A expression and terms are `h[t+k]*(1-h[t])`, for `0<=k<=n-1`:

    grad[t+k] += (1 - h[t])
    grad[t]   += -h[t+k]
    valid length t: 0..n-k-1

For Mode A negative lag index `r < n-1`, with `e=(n-1)-r` and terms `h[t]*(1-h[t+e])`:

    grad[t]     += (1 - h[t+e])
    grad[t+e]   += -h[t]
    valid t: 0..n-e-1

For Mode B positive lag labeling with terms `h[t]*(1-h[t+k])`:

    grad[t]     += (1 - h[t+k])
    grad[t+k]   += -h[t]

For Mode B negative lag with terms `h[t+e]*(1-h[t])`:

    grad[t+e] += (1 - h[t])
    grad[t]   += -h[t+e]

If orientation detection fails, do not use these analytic gradients. Use random feasible line-search and pair-exchange directions, since exact objective scoring does not require analytic gradients.

2.3 Feasible-wise area repair

For any proposal vector `y`, define the feasible projection:

    repair(y, T) = clip(y + alpha, 0, 1)
with `alpha` chosen monotonically so the target sum equals `T`.

Let

    F(alpha) = sum_i clip(y[i]+alpha, 0, 1).

`F` is nondecreasing and maps an interval to `[0,n]`. Compute bracketing values `lo=-max(y)-2.0` and `hi=1.0-min(y)+2.0`, so `F(lo) <= 0` and `F(hi) >= n`. Perform self-verified bisection for 70 iterations: if `F(mid) < T`, set `lo=mid`, else set `hi=mid`. Then take the vector `h=clip(y+lo,0,1)`. This step has target accuracy essentially equal to bisection tolerance. Then apply a residual unit-of-change corrector.

After bisection compute `s=sum(h)`. If `s > T`, inspect indices with `h[i] > 1e-14`. If the sum of available capacities is positive, distribute `s-T` to decrement selected values without violating lower bound; one practical stable method is to use

    delta = s-T
    pos_slots = indices where h[i] > delta_share
              and delta_share = min(delta/len(pos_slots), min(h[pos_slots]))

or to repeat with the smaller positive vector subset. In the final version of the corrective step, while `abs(s-T) > 1e-12` and up to eight passes, if `s<T` add an equal share of the residual only to entries strictly below 1 with sufficient remaining capacity; if `s>T` subtract an equal share only to entries strictly above 0 with sufficient excess. If a full-capacity condition prevents exact square root, use the low-dimensional exact rank construction (`snap_rank_vector`) as the fallback because it is always feasible: sort entries by value; assign the `floor(T)` largest present indices value 1, assign fractional value `T-floor(T)` to one remaining index, assign all later values 0; if `T-floor(T)` is zero, omit this fractional index. Apply this only as a repair of proposals, never as the sole search algorithm.

The projection is a joint feasibility mechanism. It is not a sequence of clipping and scalar rescaling that cannot independently enforce both box and area. The scalar `alpha` is the mechanism; after it the bracket sum gives the area ordering, and the additional small exact correction is used only when numerical drift remains.

Dimension 2.4 Transfer of exact interval densities

Changing representation from length `n_old` to length `n_new` should preserve integral `∫ h dx = 1`.

Given an old `x` length `n_old`, old width `w_old=2/n_old`, new width `w_new=2/n_new`. For new bin `j`, interval `[j*w_new,(j+1)*w_new)` in `[0,2]`. For each old bin `i`, `interval_i=[i*w_old,(i+1)*w_old)`. Adding to new bin:

    overlap_length(old_i,new_j)*x[i]

Compute output by averaging each new bin: `new[j] = sum_overlaps / w_new`. For exactity this can be implemented by compact boundary sums rather than a dense true-triple loop. Because the original integral is preserved as `sum_i x_i w_old`, after repair the new sum satisfies the required sum. Exact transfer does not make C-values comparable, but the resultant candidate is given a fresh dimension and independently evaluated.

Dimensions 2.5 Objective, Tol-defensive scoring, and candidate safe evaluation

Every time a vector is considered:

- Compute `h_particle = repair(h_particle, len(h_particle)/2)`, except when it is already exactly feasible from a previous repaired local step for speed.
- Check finite, bounds with tolerance `1e-10` and sum residual with tolerance `1e-8` (prefer `1e-10`).
- Compute `raw = np.correlate(h_particle,1-h_particle,mode="full")`, `c=dx*np.max(raw)`.
- Accept only if finite and `c` satisfies dimensional convention. Store candidate only if exact accepted.
- Keep `c_bound` equal to the computed by the above operator on the returned array, not an internal raw optimum nor a minimal reported lower-cost search score.
