The search should therefore mainly improve the current parent while avoiding infeasible repairs, random restarts too far from the parent, and any method that claims a global optimum.

The central algorithm is:

1. Use a local, exact-constraint sequential quadratic programming method (Scipy `SLSQP`) applied to the epigraph form
   `minimize_t t subject to r_s(h) <= t, sum_i h_i = n/2, 0 <= h_i <= 1`.

The constraints are nonconvex because they contain products `h_i h_j`; hence `SLSQP` is only a local method and cannot guarantee global optimality.
