1.1 Central idea

The supplied parent is a discrete vector h with length n (reportedly n = 42) satisfying, within tolerance,

    0 <= h[i] <= 1,    sum_i h[i] = n / 2,

and the authoritative objective is

    C(h) = max over all full lags of  dx * correlate(h, 1 - h) at that lag,
    dx = 2 / n.

This is a maximum over many finite-support bilinear terms. The feasible set is convex, but the objective is a nonsmooth maximum of bilinear forms, so the important practical challenge is not only finding a descent direction but also making every proposal exactly feasible and every accepted solution more directly credible using the actual metric. The proposed method is exhaustive exact-dyadic local search. Each state is represented as an integer-valued vector H[i] and an integer total-preserving grid denominator D. The displayed vector is h = H / D, and every proposal preserves sum_i H[i] exactly by moving equal mass from one coordinate to another or by batched paired transfers whose total subtracted units equal the total added units. Candidates are evaluated with the exact official evaluator. Gradient information is used only to bias proposals; no candidate is accepted solely because of a surrogate objective.

This strategy is materially different from standard smooth SLSQP, sequential Frank-Wolfe, or unconstrained probability transformations because:

- Every proposal is already exactly feasible in the box and mass constraints; there is no clipping followed by rescaling and no projection that could silently violate constraints.
- The interpretation is integer-preserved transfers, i.e., h_i decreases by delta and h_j increases by delta in exactly the same discrete units, producing sum-preserving nested cube hyperplane feasible changes.
- Term active gradients are derived exactly and used only for biased local search and self-correcting direction generation. For any active constraints with near-collided explanations, it makes good candidates under time constraints but remains exact with all checks accepted.
- The algorithm searches several feasible families, including high-resolution continuous-like states, binary-like states, parent symmetries, and resized families, and always re-ranks the exact official objectives.

To address the current gap between 0.38085 and target 0.3808, the search exploits that the state space variant creates long, carefully concentrated moves in active regions. Also, it balances robustness of random big-space avoidance and a finer transition fraction near current best. Since this is a nonconvex program, no optimizer is claimed global; a verified feasible fallback is always returned.

1. Approach and rationale

1.1 Central idea

The task is to improve the supplied parent bound slightly below 0.38085, to at most 0.3808. The objective is

C5(h) = max_l dx * np.correlate(h, 1-h, mode="full")[l],  dx = 2/n.

This is a finite-support nonsmooth problem. The feasible set is convex (a box slice with sum_i h_i = n/2), but the max objective is a finite pointwise maximum of bilinear correlations. The main bottleneck is not large-rate improvement, but getting a tiny exact improvement while preserving feasibility exactly. Generic continuous smoothing or projection methods risk drift, local clipping/rescale errors, or acceptance against surrogate objectives. The primary method chosen here uses an exact dyadic representation and exact feasible transfers: every proposal already satisfies the mass and box constraints before it is scored. No proposal is accepted based on a surrogate; every candidate is scored by the official full correlation metric.

The algorithm is a constraint-preserving active-transfer stochastic local search. It searches many feasible states:

- each state is internally an integer array H_int with fixed denominator D, h = H_int / D;
- D is a large power of two chosen so that H_int values and partial sums are exactly representable in double precision for the dimensions used;
- every move changes one or more donor entries down and receiver entries up by the same integer units, so sum(H_int) remains exactly target;
- active correlation terms provide gradients and biases for how much donor and receiver mass should move, but every accepted improvement is only claimed after exact np.correlate scoring;
- deterministic fused top/bottom transfers, batch group transfers, random global transfers, simulated annealing moves, parent symmetries, binary-like boundary families, and resize/family transfers produce candidate diversity;
- a final validated integer or verified direct parent candidate is returned with the official recomputed C5.

1.2 Why this addresses the target

The current parent is close to a local plateau. To gain 0.00005, coordinate changes on the order of 1e-5 in h may be sufficient, and target scale is around 42 lag-boundary constraints that are active near C about 0.38. A grid with D = 2**30 has unit about 9.3e-10, which is far below the needed margin. Term gradients are used only to bias trial transfers toward coordinates that locally reduce the largest active terms. Since all proposals are internally exact feasible, stochastic annealing moves and pool restarts do not accumulate floating error from clipping or rescaling. Because the objective is nonconvex, global optimality is not claimed; all final statements are upper bounds from exact evaluation of returned feasible h.

1.3 Distinctness from prior strategies

Prior strategies include smooth SLSQP descent with proxy gradients, Frank-Wolfe on linearized active constraints, global projection waterfilling/P curve activations with formal CVXPY vagueness, and generative smooth max surrogates. The present method is distinct because:

- the state constraint is repaired only at initialization/resize time; once entered into the main search, every move preserves sum and bounds exactly via transfer units;
- optimization works on exact integer feasible transfers, with explicit pair transfers, group transfers, and binary capacity transfers, rather than projecting continuous proposals back to feasibility;
- smooth terms are not used as an internal acceptance objective and do not locate with LP solver rows; exact effect of current active metrics is checked in full candidate scoring;
- any parent or input continuous feasible candidate can qualify if validated, but primary candidate ranking remains bound lower, then smaller candidate length for ties;
- resize interpolation is used only to generate valid dimension-based family candidates; scores are final-correlation-based numeric comparisons and ties treat smaller sample count only when bound remains effectively equal.

1.4 Known limitations and hypotheses

This is a stochastic local/pool search. It is hypothesis-driven that gradient-biased and batch feasible transfer proposals can escape the parent plateau due active near-tie correlation structures. The program is nonconvex, so local search is not proof of global minimum, and the fixed budget may stop before reaching target. Nonetheless, every time an exact bound decreases, the officially evaluated h is retained. A constant half-integer fallback feasible vector guarantees a valid tuple even if the stochastic search does not reach target.
