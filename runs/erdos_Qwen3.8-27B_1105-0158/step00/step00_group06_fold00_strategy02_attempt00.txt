1. Approach and rationale

1.1 Central idea.
Use a stochastic pair-preserving minimization of the exact discrete Erdős overlap objective. At every proposed move, replace one feasible vector `h` by another feasible vector that changes only two coordinates while preserving their sum, forces all coordinates into `[0,1]`, then immediately evaluates the candidate by the actual finite-support overlap score. The chosen pair is guided by active peaks of the evaluated overlap array and by local subgradients, and the two-coordinate move is minimized/nontrivially sampled using a direct one-dimensional search over the feasible interval of the transferred mass. Every accepted design is checked with the authoritative evaluator; no surrogate, smoothing constant, or relaxed objective determines acceptance.

1.2 Substantive difference from earlier proposals.
The two earlier proposals are based on smoothing the maximum and using a large-scale gradient flow, or on an active-set tangent/LP-like local model. This plan instead does the following:
- It never replaces the objective by a smoothed maximum, logarithmic sum, tangent convex model, global convex approximation, or convex relaxation.
- It uses exact one-dimensional search on the exact evaluator for coordinate-preserving pair rotations. The search space is generated only from the feasible set: change two coordinates, preserve their pair-sum, discretize the resulting admissible interval, and score the exact evaluator.
- It combines this with stochastic simulated annealing and reheat that sample nonzero uphill moves from random mass transfers, giving escape from coordinate-descent local minima without changing the feasible set or the scoring function.
- This method is local, but the one-dimensional moves are insisted to be verified by the original finite-support objective. It addresses the bottleneck that the norm of the griddle or ACT model plowsetting is that the global peak can be hidden at many lags with fractional boundary conditions. Pair rotations sharply change boundary terms and allow fractional adjustments that reduce the maximum overlap while using the exact correlation profile to select which peak relativity updates.

1.3 Justified facts versus hypotheses.
Facts:
- The constraint set `{h: 0 <= h_i <= 1, sum(h_i)=n/2}` is convex and has a compact, projection-type structure; a feasible vector and any pair-rotation of it are feasible up to floating-point tolerance, which can be repaired by a scalar convex projection.
- The objective 
  `C(h) = max_k np.correlate(h,1-h,"full")[k] * (2/n)`
  is continuous, dimensionally correct for the requested vector representation, and finite on the feasible polytope. It actually captures the finite interval boundary terms.
- The exact overlap objective is nonsmooth and not convex due to bilinear terms; therefore there is no claim from a closed-form convex solver. The pair subproblem may also be nonsmooth and occasionally not globally exactly located by sampling, but any final candidate is re-scored and can increase or decrease actual best.
Hypotheses / design heuristics:
- Random pair shifts across distances, and optimizing pairs selected via multiple active lags, are hypothesized to drive down the largest active finite-overlap peaks.
- A binomial random binary starting state can lead to good local minima when the parent is absent.
No method used below should be interpreted as a proof of global optimality.

2. Mathematical specification

2.1 Discrete exact objective.
Let `n = h.size`, `dx = 2.0 / n`, and `h` be a real vector. The authoritative score is:

```
C(h) = max_k Q_k(dx)
```

where `Q` is the length `2*n-1` full linear-correlation array produced by

```
Q_raw = np.correlate(h, 1.0 - h, mode="full")
Q = Q_raw * dx
C = max(Q)
```

The implemented scorer must directly encode exactly this computation and produce a floating scalar. Do not use circular correlation or exchange with an autocorrelation formulation because boundary terms are essential. The correlation ordering and finite-support sides must match the evident evaluation.

For the finite-support count-only correlation lag, set raw index `k = 0,...,2*n-2`, and define the implied lag index

```
r = k - (n - 1)
```

so the raw term counted by `np.correlate` is:

```
Q_raw[k] = sum over valid j of h[j + r] * (1 - h[j])
```

Valid `j` satisfy both `0 <= j + r <= n-1` and `0 <= j <= n-1`, which are equivalent to

```
j_min(r) = max(0, -r)
j_max(r) = min(n-1, n-1-r)
```

If `j_min(r) > j_max(r)` then the contribution for that lag is zero. The raw sum is continuous under `h` with finite boundary counts.

The exact score with multiplied scale is

```
C(h) = dx * max_k Q_raw[k]
```

The scale `dx = 2/n` is mandatory for both optimization and final reproducibility bounds on `C5`.
