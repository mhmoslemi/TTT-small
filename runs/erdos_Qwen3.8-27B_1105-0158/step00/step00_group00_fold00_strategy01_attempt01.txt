1. Approach and rationale

1.1 Central idea

Treat the discretized problem as a nonsmooth finite-dimensional min-max over the feasible box-sum polytope, and improve candidates by exact feasible one-dimensional mass transport directions derived from the currently active shift constraints. The method is not a smoothed max replacement, not a circular correlation approximation, and not a single black-box multistart: it repeatedly evaluates the true evaluator objective and only accepts changes that lower that true objective.

For a vector of length n, the evaluator is exactly

C5(h) = max_{m=0,...,2n-2} [dx * np.correlate(h, 1 - h, mode="full")][m],

where dx = 2/n. The feasible set is

P_n = {h in R^n : 0 <= h_i <= 1, sum(i=0..n-1) h_i = n/2}.

All candidate transformations stay feasible or are repaired by a joint feasibility projection before they are scraped by the true evaluator.

1.2 Why this can improve the parent

The current parent is likely already a local optimum for a generic black-box solver. The proposed method targets a different mechanism of descent: moving a small mass from indices where the active-shift gradients are large to indices where they are small, while preserving the exact sum and bounds. These transport moves respect the finite-support covariance structure. Because the objective is nonsmooth, the active gradients are defined through the set of constraints attaining the current maximum, and the exact candidate score is always re-evaluated.

The algorithm has three cooperating layers:

- Exact transport descent layer. For the current best vector, construct active-gradient directed feasible pair-transport moves and perform conservative one-dimensional exact line searches. This layer can make progress without solving a large nonlinear program.

- Low-dimensional smooth global layer. Generate and locally optimize smooth or Fourier modal parametric shapes, always projected into P_n, to escape local minima and discover new feasible basins. This is an unconstrained optimization of a scalar profile in a compact parameter space.

- Global population layer. Maintain a small population of exact-scored feasible vectors. Use deterministic and stochastic transformation operators: rectangular rescaling/transfer, symmetrization, transport mutation, mutation by smooth noise, and crossover by interpolation. Score and retain using the original C5 evaluator.
