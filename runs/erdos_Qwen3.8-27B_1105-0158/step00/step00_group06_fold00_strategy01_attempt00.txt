    C(h) = max(np.correlate(h, 1-h, mode="full")*(2.0/n)).

The feasible region is the intersection of the box [0,1]^n with one linear equality sum(h)=n/2. The objective contains products h_i(1-h_j); therefore it is nonconvex. A globally convex formulation of the original objective is not available. The proposed algorithm solves neither the smooth max nor its convex envelope globally; instead it produces an explicit feasible vector whose exact evaluator score is a validated upper bound. When the exact value reaches or falls below the target, one may return immediately; this is a budget stopping rule, not a mathematical optimality certification.

The central new idea is to minimize on exact two-coordinate mass-transfer line segments and keep feasibility by construction. For any ordered pair (a,b) and scalar s, define the line

    h_a(s) = h_a + s,
    h_b(s) = h_b - s,
    all other coordinates fixed.

This preserves sum(h) exactly (up to floating roundoff) while the allowed interval

    low_s  = max(-h_a, h_b - 1.0),
    high_s = min(1.0 - h_a, h_b)

keeps both coordinates in [0,1]. Along this one-dimensional line one evaluates the original exact benda metric and searches for an extremal point with a robust grid/refinement. This is a coordinate-descent-like search but not a projected-gradient step: every move is an exact constrained two-atom mass transfer, and only the exact evaluator can accept a candidate.

The high-level method consists of:

- validation of the supplied parent and its use as a fallback;
- pair-line minimization directed toward active high-overlap terms;
- deterministic shape starts and randomized multistart operators applied at native length or controlled downsampled lengths;
- perturb-and-refine cycles around current best local minima;
- pure project-based feasibility repair, used mainly for starts and final repair, not as an optimization trajectory for the most accepted moves;
- strict acceptance based on the implemented and correct evaluator for the raw vector;
- retention of the exact best vector and valid fallback if the budget expires.

The method improves upon a parent of the type supplied by concentrating effort on overlaps causing the current maximum and reducing them through line transfers between the paired variables appearing in those active overlaps. Because each accepted move uses the exact discrete objective, no surrogate error can transform an unfavorable pseudoproblem into a bogus acceptance.

The parent start may be continuous; generated starts may be continuous or binary with exactly fractional sums. Length optimization is handled by explicit transformation and exact comparison at candidate length. Return length can differ from parent length only when the exact evaluated score is strictly better or sufficiently close and the smaller vector is a meaningful runtime preference.

    h_a := h_a + s
    h_b := h_b - s

    (h_a + s) + (h_b - s) = h_a + h_b.

1. Approach and rationale

The problem is to return an explicit feasible step-vector `h` whose exact evaluator metric

    C(h) = max(np.correlate(h, 1 - h, mode="full") * (2.0 / len(h)))

is as small as possible. At the parent length, which is normally 70, the full finite-support problem contains `2*n - 1` boundary-sensitive overlap lags. The constraint is the convex polytope

    sum(h) = n/2,     0 <= h_i <= 1,

but the objective is a maximum of expressions involving products `h_i(1-h_j)`. Therefore a direct convex formulation of the original objective is unavailable. The proposed algorithm does not claim to solve a convex relaxation globally. It instead constructs candidate vectors whose values are judged after-the-fact using the actual evaluator, and it aggressively uses an exact feasible scalar topic for which improvement can be detected directly by sampling a constrained one-dimensional line.

Primary improvement mechanism: choose two coordinates `a` and `b` and move a scalar amount `s` from one to the other:

    h(a) := h(a) + s
    h(b) := h(b) - s

with every other coordinate unchanged. The sum constraint is preserved exactly up to machine round-off. The feasible bounds yield the explicit interval

    low  = max(-h(a), h(b) - 1.0)
    high = min(1.0 - h(a), h(b))

where the other coordinate remains inside [0,1]. Along this interval, the line is sampled using the exact metric. If a grid or refinement improves the score, the resulting vector is accepted only after feasibility validation and exact rescoring. Ending time can be met at any line boundary because each complete decision stage stores the best verified candidate separately.

The method is materially different from a smooth or projected-gradient私家车-style trajectory. The developments are:

- active lags are computed from actual evaluator outputs, not assumed from a surrogate;
- candidate directions are derived from pairs identified as participating actively in large overlap terms, so labor concentrates where the maximum is realized;
- every primitive move constructs a complete feasible vector by construction, reducing reliance on repair;
- multistart containers include a direct parent improvement phase, independent random/binary start-generation, downsampling operators, and perturb/re-descend loops;
- target termination is only a budget tool, not a mathematical proof of optimality;
- the fallback is always the supplied valid parent if none can be improved, or a deterministic controlled balanced construction is supplied.
