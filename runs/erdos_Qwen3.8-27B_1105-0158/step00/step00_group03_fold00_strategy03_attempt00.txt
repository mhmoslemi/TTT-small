1.1 Core idea

The method is a direct black-box search over the feasible set encoded inside the objective. Every proposed vector is first passed through a deterministic feasible transformation that enforces simultaneously:

- 0 <= h_i <= 1 for all i,
- sum_i h_i = n/2.

Then the transformed vector is scored by the exact evaluator metric

    C(h) = max_m np.correlate(h, 1.0 - h, mode="full")[m] * (2.0 / n).

Optimizers, pool searches, and stochastic proposals never manipulate raw invalid samples as candidates. Instead the scalar function is

    f(theta) = exact_score(T(theta)),

where T is a many-to-one map onto the feasible set. Because f evaluates the constrained problem at an exact feasible point, every recorded value is a valid upper bound if the bound reported for it is the exact score after final repair/validation. This avoids penalty-parameter tuning of the two feasibility constraints and completely sidesteps explicit projection/repair failures as the search progresses.

The search itself is stochastic-plus-local. It starts from the supplied parent when available, constructs multiple feasible starts by perturbing it in the encoded space, and then alternates between:

- differential evolution, or equivalent global population search, on low-dimensional logistic transforms or directly on encoded raw variables, treating f as black-box noisy/non-smooth but bounded;
- local coordinate search with Powell-type line directions in bounded vertical-angle variables that always remap to points in [0,1] before projection;
- final exact disentangle and a dyadic quantization for strict feasibility verification.

This differs materially from previously proposed projected-gradient, surrogate SLSQP, fixed pair-line descent, and active-redscспанл approaches. It performs global optimization under constraints through exact projection inside an unconstrained space. It does not require gradients, derivatives, linearized convex subproblems, pairwise single-coordinate exploitation, profilesort means, or LSE smoothing. It treats the nonconvex objective as an opaque feasible map.
