1. Approach and rationale

The central idea is to exploit a structural fact that is easy to prove and amenable to exact evaluation: if only two coordinates are changed along an area-preserving direction, with one coordinate increased by `s` and the other decreased by `s`, then every finite shifted-overlap term is a convex quadratic function of `s`. Therefore the exact task objective, which is the pointwise maximum of the shifted-correlation terms, is convex along each such pair direction. This makes full closed-form-quality coordinate search along that line both cheap and reliable: every proposed candidate can be judged by the actual evaluator, not by a relaxed/expanded objective. The search chooses which pair directions to test by using a subgradient/BFGS-like active-worst-lag heuristic, but acceptance is always by exact rescoring.

This approach is materially different from previous proposals, which rely on global smoothing (log-sum-exp), generic hypograph solvers (SLSQP), linearized LP models, and full nonlinear projection machinery as the main driver. Here the primary optimization operation is:

- evaluate exact convex pair lines using the original evaluator;
- use active-lag derivatives only to rank a small number of pair-coordinate trials;
- never accept a candidate unless recomputed by the task metric and exact box/area validation.

Why this may improve the supplied `initial_h_values` construction:
- The parent is already close to the target, so small exact pair moves can polish it without ruining feasibility.
- A pair move preserves the area algebraically before and after the move, so the area constraint can be maintained exactly without relying on a projection after ascent.
- The objective along that pair is concave exactly from the convexity argument, so a one-dimensional golden-section search can find the best value on that pair line with reasonable exactness.
- A pair move involving positions with opposite-signed subgradient contributions is likely to reduce one or more currently caravaning lag penalties.

This is not a global optimization proof. It is a search heuristic and a candidate certificate by construction: if the final returned vector satisfies the box and area constraints and its authoritative evaluator score is below the current record, then it is a valid valid certificate. The algorithm is sufficient to try for the required target of `0.3808` and lower, but it does not make optimality claims. Compared to the previous generic large-scale methods, this formulation reduces risk of a stalled surrogate and focuses work on a subspace with exact proven structure.

Important deterministic facts used:
- The official evaluator uses linear shifted correlation on the finite grid, not circular autocorrelation; both lag signs and boundary window lengths are retained.
- When `h` has length `n`, `dx = 2.0/n`, the area constraint is `sum(h)*dx = 1`, i.e. `sum(h) = n/2`.
- The returned value must be validated from the exact vector passed for return.

Algorithmic plan in one sentence: transfer the parent to several adaptive lengths by area-preserving averaging, use active-subgradient-guided exact convex pair-line searches to polish each candidate locally, use fallback perturbations/complementation/reversal/binary snapped starts to move out of local stagnation; return the lowest exact score achieved, including a provably feasible fallback.
