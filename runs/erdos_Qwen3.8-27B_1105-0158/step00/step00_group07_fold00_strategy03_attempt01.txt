1. Approach and rationale

1.1 Central idea

The exact discrete minimax objective is

    C(h) = dx * max_j np.correlate(h, 1-h, mode="full")[j],

with

    h in [0, 1]^n, sum_i h_i = n/2, dx = 2/n.

The value of C is determined only by the largest finite순 shifted-overlap terms. Those terms are bilinear and contain finite-boundary entries. The dominant difficulty is not a lack of gradient formulas, but the fact that a naive smooth objective, circular correlation proxy, soft minimum, or global convex relaxation can move in directions that reduce a surrogate while leaving the exact maximum unchanged or worse.

The proposed search is materially different from a smooth log-sum-exp minimization, a direct nonlinear least-squares formulation, or plain coordinate annealing. It performs a sequence of exact-acceptance trust-region probes whose local model is specifically the active exact shifted-correlation rows, linearized at the current vector, and embedded in a convex proximal epigraph optimization. At every iteration:

- The input origin vector is feasible under the exact area and box rules.
- Exact shifted correlations are computed from the evaluator expression.
- Active and near-active lag rows are selected from the exact vector of shifted overlaps.
- For those rows, exact derivatives of the raw correlation terms are constructed.
- A convex auxiliary problem is solved to produce a trial vector that tries to reduce the active local upper envelope while remaining inside a trust region.
- Every trial point is repaired to the exact feasible set using a single joint projection onto `0 <= h_i <= 1` and `sum_i h_i = n/2`.
- Exact evaluation with `np.correlate(h, 1-h, "full") * dx` is the only accepted score.

Thus the auxiliary problem is not treated as producing a certified bound. The solution of the auxiliary problem is a candidate only. The bound reported is always recomputed from the returned feasible vector using the exact supplied formula.

1.2 Why this addresses the bottleneck

The current parent is already very close to the required target. A useful improvement probably requires changing several coordinates jointly in the directions that constrain the largest shifted overlaps. A univariate perturbation or smooth low-temperature annealing may reduce average area movement without reducing the worst exact lag. The proximal active-row model is designed to respect the raw finite-support structure at the largest lags, including partial-overlap boundary terms, while the trust region prevents steps that are too large for the bilinear model to remain meaningful.

The method also attacks this with two complementary escape layers:

- Local exact local model search around the parent, h-complement, h-reverse, and resolution-transferred variants. These emphasize the existing construction basin.
- Low-dimensional Fourier/local-bump subspace search and directed random / pair-transfer search. These reduce sensitivity to active-row solver failure and may exploit shorter discretizations or different local minima.

1.3 Limitations and claims

This is not a proof that the parent global minimizer is improved. The local model contains a first-order approximation of raw relation bilinear terms; exact correlation is nonconvex. The solution of the linear/quadratic model may degrade the true max. The method succeeds only if a valid exact candidate with lower score is satisfactory. If no candidate is found, the program returns a valid fallback, usually the repaired supplied parent. Small discretization can return a lower discrete metric because each `n` is its own return candidate if evaluation passed it as a valid array.

Thus the only defensible claim is: lowered C values are accepted only when the returned vector is feasible and its score is exactly recomputed as supplied metric.

2. Mathematical specification

2.1 Discrete feasibility and units

For a feasible returned vector `h` of length `n`:

    dx = 2.0 / n
    target_sum = n / 2
    0 <= h_i <= 1
    sum_i h_i = target_sum

The integral constraint equivalently means

    dx * sum_i h_i = 1.

To avoid resolving any tension `n` must exactly satisfy the target within the controlled tolerance. For odd `n`, `target_sum` is fractional. This is not inconsistent with box constraints because fractional sum of the coordinates means the fractional mass is distributed different coordinates.

2.2 Exact objective and lag formula

The grader computes

    raw_k = np.correlate(h, 1-h, mode="full")

with length `2n-1`. Let the raw output index be `r = 0, ..., 2n-2` and set

    lag = r - (n - 1).

The lag runs from `-(n-1)` through `n-1`.

Define

    v_i = 1 - h_i.

For NumPy correlation with equal lengths, when orientations are represented within the `r` order by the formula above, the primary exact convention is:

Case A lag = 0:
    raw_0 = sum_{i=0}^{n-1} h_i (1 - h_i)

Case A lag = k > 0:
    raw_k = sum_{t=0}^{n-k-1} h_{t+k} (1 - h_t)

Case A lag = -e < 0:
    raw_k = sum_{t=0}^{n-e-1} h_t (1 - h_{t+e})

This convention preserves all finite-boundary terms because overlap length decreases with shift magnitude and the maximum includes both positive and negative signs. At no point shall the objective be replaced by circular autocorrelation, global sine lower-bound proxies, or smooth cumulative-overlap derivatives.

Because there is a possible mirrored convention depending on implementation, the program should verify one of two formulas before row gradients are used. The mirrored formula is:

Case B lag = k > 0:
    raw_k = sum_{t=0}^{n-k-1} h_t (1 - h_{t+k})

Case B lag = -e < 0:
    raw_k = sum_{t=0}^{n-e-1} h_{t+e} (1 - h_t)

The program:

2.3 Gradient formulas for a raw row

Let `R_r(h)` be the exact raw scalar being tightened for a selected index `r` with detected orientation. Let `g_{r}` be the Euclidean gradient of `R_r` with respect to `h`, in units where the raw scalar is not multiplied by `dx`.

Mode A gradients:

For `lag = k >= 0`:
    initialize vector of zeros length n.
    for indices i in [k, n-1]:
        grad[i] += 1 - h[i-k]
    for indices i in [0, n-k-1]:
        grad[i] -= h[i+k]
If k=0, both updates apply, yielding grad[i] = 1 - 2h[i].

For `lag = -e < 0`:
    for indices i in [0, n-e-1]:
        grad[i] += 1 - h[i+e]
    for indices i in [e, n-1]:
        grad[i] -= h[i-e]

This avoids numerical double gradient calculation, and the first derivative of one exact shifted row is the only needed derivative inside its epigraph/box linearization.
