1. Approach and rationale
The central idea is to optimize the discrete step function directly, using the exact finite-support linear/large-overlap objective defined by the evaluator, but to do so through a different optimization architecture from the standard smooth-max projected-gradient or active-set tangent-plane hand-crafted directions. The method centers on two mechanisms:

A. Exact coordinate-pair coordinate descent  
Rather than solving a smoothed or linearized global surrogate, we perform a sequence of exact one-dimensional feasible moves over the original discrete parameters. Every move transfers one unit of "mass" from one grid sample to another while preserving the sum exactly:
  h_i -> h_i + t, h_j -> h_j - t.
Because the move lives strictly in the original feasible polytope 0 <= h <= 1, sum h = N/2, every line point on the segment can be scored exactly by the original evaluator. This gives a strong and concrete coordinate-descent-like refinement step where the subproblem objective is not an approximation but the true C5 value.

B. Low-dimensional global trial families  
Since exhaustive coordinate-pair descent is strongly local, it is supplemented with a global trial stage that uses a compact Fourier/wave parametrization to construct physically meaningful h-values, then projects them exactly into the feasible set and passes them to the pair-descent routine. This stage explores alternative wave-shaped solutions that may escape narrow pair-coordinate traps.

Why this could work:
- The parent construction is near a local optimum; a direct coordinate-pair line search often catches exploitable improvements that do not show up in smoothed global gradients because it accounts for the true bin-box structure and exact boundary terms at every finite lag.
- A wave/fourier trial search is a materially different search architecture from surrogate or active-set linearization: it uses compact parameter families, exact feasibility projection, and full evaluator scoring, with all information used after exact candidate validation.
- Feasibility is preserved everywhere. Every proposed local move and every generated trial family exits via a projection onto the fixed feasible set, so the returned h-values always satisfy 0 <= h[i] <= 1 and sum h = n_points/2 exactly up to strictly controlled numeric tolerance.

Bottleneck addressed:
- Pure local gradient descent or smoothing can propagate gradient to inactive lags and miss improvements in exact correlations.
- Pure global DE-style optimization over N≈70 vector coordinates is difficult. The hybrid strategy avoids over-dimensionality in the global family while retaining finite support correctness.

Limits and assumptions:
- This is not a globally certified optimizer. The Fourier/wave trial family is a heuristic proposal mechanism. Improvements above the parent are checked only by exact evaluation and exact feasibility verification.
- The returned bound c5_bound is the exact value of the evaluator for the best candidate stored in the independent final array and revalidated by the exact evaluation function before return.
- If the user-provided parent or constructed global trials do not improve the returned bound, the best exact reasonably valid h-array from the initialization is returned, so the current best bound is never intentionally increased for the final answer.

Consistency with evaluator:
The authoritative quantity is always
  C5(h) = max_k { (np.correlate(h, 1-h, mode="full") * (2.0 / N))[k] }
over all 2N-1 finite lags. This excludes circular correlation substitution despite the quasi-periodic families used for design and repair. No routines are used to replace the objective with another equivalent expression.

2. Mathematical specification
Discrete variables and domain:
- Let N denote the returned number of samples. It must be even, because sum h = N/2 is then an integer target. The evaluator map defines h at sample sequences of length N.
- dx = 2.0 / N.
- Feasible set S: 0 <= h[i] <= 1 for all i, sum_i h[i] = N/2 exactly.

Exact evaluator helper used by the program:
For an input array h of length N, dx = 2/N, correlate c_full = np.correlate(h, 1.0 - h, mode="full"), scores = c_full * dx, c5 = max(scores). The function returns a finite number. It will be used for:
- measuring initial parent validity.
- every pair line evaluation.
- candidate acceptances.
- final revalidation.

Feasibility projection for feasibility-preserving trial transformations:
Given a raw trial vector r of length N, define the desired sum S=N/2. Recover a feasible vector h by solving the monotone scalar one-dimensional system
  g(λ) = sum_i clip(r_i + λ, 0, 1) = S.
Because g is continuous and nondecreasing, and g at very negative λ is zero while g at very positive λ is N, a solution exists. An exact bisection over λ is admissible:
- lower bound lam_low = min(r) - 2, making clip values below zero at least sum 0.
- upper bound lam_high = max(r) + 2, making values above one at least sum N.
Run 70 to 85 binary search iterations, then choose h = clip(r + λ*, 0, 1). If numerical sum still deviates by more than strict final tolerance (e.g. > 1e-13 relative to S) distribute corrective amounts among strictly interior indices (those with h_i strictly between 0 and 1). If there are not enough interior indices, restore from a known feasible reference. Because λ-bisection directly adjusts all points with a single scalar, the bounds and sum are jointly satisfied, except for tiny roundoff that is then cleaned with deterministic interior correction only.

Feasibility-oriented wave/sample representation for global stage:
For even N, define sample centers
  x_i = (2*i + 1) / N, i = 0,...,N-1, so x_i range in [0,2).
A global trial parameter vector p of dimension d, in practice d=2M with M=14 to 18 modes, creates a non-centered trigonometric signal W_i:
  W_i = sum_{m=1}^M [ a_m cos(mπ x_i) + b_m sin(mπ x_i) ].
Here a and b are the sampled parameters. Because integer frequencies of cos(mπ x_i) and sin(mπ x_i) have period 2 perhaps with different multiplicities, this generates periodic wave candidate shapes directly relative to the [0,2] step grid.
Normalize W without introducing clipping:
  scale = max(1, max_i |W_i|)
  r = (1 + W / scale) / 2.
This r has range reduced to [0,1] maybe partially clipped, but its sum may not be N/2. Feed r into the monotone projection described above, obtaining exactly feasible h_w(p).
Thus family map is parameters in Euclidean space -> normalized arc wave -> exact projection onto S_N.

Centre-centered h formulation, implicitly exact:
The evaluator's zero-lag term h_i(1-h_i) may dominate if h values sit near 0.5; the exact pair move coordinate and wave transform both accommodate it by evaluation direct. No objective assumed to remove the zero correction. The experiments directly examine finite-lag products using the evaluator.

Pair coordinate move and line objective:
For an ordered or unordered pair of distinct indices (i,j) at current h, because sum has only the pair interacting, define a one-dimensional path of exactly balanced moves depending on the parameter t:
  h_i(t) = h_i(0) + t, h_j(t) = h_j(0) - t.
Feasibility interval:
  t_low = max(-h_i(0), h_j(0) - 1)
  t_high = min(1 - h_i(0), h_j(0)).
The interval always contains t=0 if the current vector is feasible.
For t in [t_low, t_high], define exact scalar objective
  F_{i,j}(t) = evaluator(h^t).
Equivalently, constructing a copy of h with only index modifications, t is feasible. Pair descent minimizes exactly over sampled approximations of F_{i,j}. Since N <= 128 ideally and often 70, an exact evaluation is cheap enough. There is no claimed subproblem convexity; upper-edge exact segment sampling only produces accepted points if the objective improves.

Feasibility relation for pair line final candidate:
Although h^t is matched under floating point sum because values change identically inverse directly, after constructing a candidate array for acceptance maybe some tolerable numerical sum drift occurs. Run error checking, and if the deviation exceeds strict final tolerance, micro-correct inside same pair-project with transfer tweak among variables. If correction is not achievable without dropping bounds, discard candidate.

Values: run seed and noise scale: seed for initialization controls randomness of differential evolution and random feasibility targets, but exact objective remains deterministic.
