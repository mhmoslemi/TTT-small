1. Approach and rationale

1.1 Central idea

Use the exact discrete objective evaluator on a deliberately reduced, automatically feasible, “complement-reversal symmetric” subproblem, and then allow a cautious full-dimensional rescue only if time remains. The primary search is not based on sequential quadratic programming, Lagrange multipliers, or heuristic full-vector clipping-rescaling repair. It is based instead on a group-symmetry parameterization that:

- enforces the mass constraint exactly by construction,
- enforces the box constraint exactly by construction,
- halves the number of free variables,
- produces candidates directly in the range accepted by the evaluator,
- can be searched globally with derivative-free bounded methods and refined by exact one-dimensional searches using the original finite-support correlation objective.

For a vector h of length n, define the complement-reversal transform

    T(h)_i = 1 - h_{n-1-i}.

A broad structural symmetry often present in extremal overlap constructions is invariance under this transformation. Requiring

    h_i + h_{n-1-i} = 1

for paired indices and, when n is odd, h_{(n-1)/2}=1/2, gives an exactly feasible family. For even n=2d, the family is h_i=x_i and h_{n-1-i}=1-x_i; for odd n=2d+1, there is also the fixed central entry 1/2. The mean constraint becomes automatic: each mirrored pair contributes exactly 1 to the sum, and the central entry contributes 1/2 if present. The box constraint is also automatic when x_i is clipped or constrained to [0,1].

This is materially different from local SQP, epigraph solvers, or unconstrained full-space walkers with heuristic waterfilling: the primary low-dimensional family has no equality or box violation to repair. Candidate quality is measured exactly by the required formula

    C(h) = dx * max(np.correlate(h, 1.0 - h, mode="full")),

and every accepted candidate is accepted only after exact recomputation of that formula.

1.2 Why it can improve or preserve the parent

The supplied parent is already close to the known record. Naive unconstrained full-space perturbations often need expensive feasibility repair that changes many coordinates and can push the objective in a non-smooth max direction. The symmetric family preserves exactly the structural relation that is plausible in this_MIN_WORD problem and lets a local/global search work in only 31 variables for n=63. It also gives deterministic, exact mass feasibility and exact boundary feasibility at the same time.

The parent can be projected into this family by a linear averaging map. If this projection lowers the objective, projection alone may improve the record. If not, the projection is still a useful higher-quality seed inside a feasible family. Global bounded search over the reduced variables does not need to solve a constrained nonlinear program.

1.3 Search hierarchy

The plan is:

- Phase A: validate or transform the supplied parent; keep the best feasible candidate as a certified fallback.
- Phase B: if the parent-like vector supports a nice symmetric projection, initialize a reduced-variable population with that projection.
- Phase C: run a custom bounded global search, essentially differential evolution, over x∈[0,1]^d, where d=floor(n/2), using the exact one-dimensional objective for expanded h.
- Phase D: take the reduced population best and apply exact scalar coordinate-line minimization with multi-bracketing. This is derivative-free but evaluates the true objective and accepts only exact improvements.
- Phase E: optionally apply such bounded families with a randomized/biased sweep or bounded Powell if enough time remains.
- Phase F: if the constrained symmetric family has not found an objective below the valid parent and more substantial budget remains, run a short full logistic rescue exact local search built with exact mass feasibility by a scalar implicit global shift. This is rescue only, not the central claim.

The purpose of this ordering is that the low-dimensional constrained search reduces computational overhead and local noise, while the final full rescue, if used, expands from the best feasible candidates already found rather than from an arbitrary full-space guess.

1.4 Limitations and claims

This does not prove global optimality. It does not even prove that the restricted symmetric family contains an optimum for arbitrary densely sampled Erdős overlap problems. The transformation may miss candidate h’s whose mirrored pair sums are not exactly 1. The full rescue also maps most non-extreme interior points into an expit/logistic family, so it may not reach exact live boundary values without large latent variables.

What can be stated confidently:

- Every returned vector must be validated/finalized with exact h∈[0,1], exact sum target under tolerance, and exact objective/value recomputed by the stated evaluator.
- Acceptance rules must guard against accepting a full-dimensional logistic candidate that looks better under smoothing but is worse under exact evaluation. Candidate selection and final output must therefore rely on the exact objective, not an internal surrogate.
- The algorithm is local/global heuristics. It is allowed and expected that output may be the parent or a fallback. That is safe. The goal is to attempt a lower exact bound with a feasible fallback available before deadline.

1.5 Material difference from earlier approaches

Earlier designs use variable-by-variable local SQP/epigraph methods, waterfilling projection, and full-vector smoothing perturbations. Here, the primary design is:

- dimension reduction via exact complement-reversal symmetry,
- exact zero-repair feasibility by expansion rather than projection,
- bounded global boundary search under that structure,
- exact scalar-line coordinate refinement in the reduced basis,
- optional global logistic fallback as an independent, feasibility-exact rescue route.

This is a different optimization manifold and mechanism. It avoids relying on a nonlinear program to maintain constraints: feasibility is part of the candidate parameterization itself.

2.1 sampling normalization and exact objective

2.2 Feasible low-dimensional symmetric family

Let n be current evaluation length. Let

    odd = (n % 2 == 1)

If even:

    h_i = x_i                             for i = 0,...,d-1

    h_left  = x
    h_right = 1 - x[::-1]

- If x_i is clipped to [0,1], pair contribution is x_i + (1-x_i) = 1.
- Even n has n/2 pairs. Sum is d = n/2.
- Odd n has d pairs plus central 1/2. Sum is d+1/2 = n/2.

Therefore, at no point is an equality constraint or repair step required.

The inverse map, used to seed a symmetric family from a feasible or nearly feasible parent h, is:

For even or odd n, for i=0,...,d-1:

This preserves the integral/mass constraint exactly: every mirrored pair contributes exactly 1 when each side is represented as `x` and `1-x`; the optional central entry contributes exactly 0.5. If the reduced variables are maintained in `[0,1]`, the box constraint `0 <= h_i <= 1` is also exact. Therefore the main search does not need equality repair, waterfilling, full-variable clipping/rescaling, or an SQP equality constraint mechanism.

The objective remains the full-vector, boundary-aware finite-support correlation as specified in the task:

    Q(h) = max_k np.correlate(h, 1.0 - h, mode="full").max(),
    C(h) = (2.0 / n) * Q(h).

Every accepted lower candidate is judged using this exact recomputation, not the solver’s internal epigraph value or a surrogate.

1.2 Why this is likely to help

- The raw step-function problem has `n` box variables, one exact equality, and a nonsmooth minimax of quadratic products. A direct local method can spend most effort validating feasibility and tuning equality/boundary repair.
- The complementary symmetry `T(h)_i = 1 - h_{n-1-i}` leaves the visible objective set essentially permuted under exact complementation/reversal, so it is a natural candidate-representative subspace. Requiring the family to be invariant under `T` cuts the free variables roughly in half for `n=63`, from 63 to 31.
- A projected parent in the symmetric family is immediately feasible with no repair risk, making each candidate cheaper and cleaner to evaluate.
- Global bounded search on lower-dimensional boxes can exploit the feasible manifold directly. A later 1D exact diagonal optimization refines the exact evaluator without needing gradients.
- Since the parent is the reference record, failing to find a symmetric improvement is safe: retain the best exact feasible candidate already found, preferably the provided parent if feasible.

1.3 Main bottlenecks addressed

- High-dimensional full `h` optimization has more coordinates and mass constraint drift.
- Heuristic feasibility repair can dominate and move far away from a candidate’s intended local neighborhood.
- Approximate local models can be misleading because the actual objective is max-value over many boundary-valid lags.
- Repeated low-dimensional work is far cheaper than repeated global variable waterfilling or high-dimensional nonsmooth descent.

1.4 Hedge against missed asymmetry

Restricting to complement-reversal symmetry can miss optimal `h` with nonstandard pair-sum patterns. Therefore the plan has a short, strictly guarded optional full-vector rescue phase. That phase uses an exact implicit global shift feasibility map from latent real-valued vectors to feasible `h` vectors, allowing candidates to leave the symmetric family. It is allowed only after the constrained search is completed or early failure, and only if exact evaluation improves the running bound. It is not the main algorithm and must not replace the fallback. The returned candidate must always be recomputed exactly.

1.5 Materially different from earlier proposals

Earlier plans were based on full-variable SQP, epigraph local solving, heavy waterfill repair and smoothing perturbations. This plan is:

- structured around an exact complement-reversal invariant/queryable feasible manifold,
- optimization is primarily in the reduced dimension,
- candidates are constructed under exact feasibility, not repaired after projection,
- main local improvements use derivative-free exact coordinate scalar optimization, using the true correlation max,
- optional full-space rescue is a secondary construction-method component with a new exact summation map.

There is no claim of global optimality anywhere. The only guaranteed properties are feasibility of returned candidates and lower or equal final exact objective to the certified fallback.

2.1 Sampling, normalization, exact objective

Let `n` be the number of samples returned. Define

    dx = 2.0 / n
    mass_target = n / 2.

A candidate `h` has length `n`, entries `h[0],...,h[n-1]`. It is physically feasible if all entries are finite and satisfy approximate constraints

    -epsilon_box <= h_i <= 1 + epsilon_box,
    abs(sum(h) - n/2) <= epsilon_mass,

with tolerances used for internal validation. The exact final verification before return requires the returned values to pass these checks to within one decimal order smaller than the accepted output tolerance.

The physical objective exactly required by evaluation is

    C(h) = dx * max(np.correlate(h, 1.0 - h, mode="full")).

Let

    Q(h) = max(np.correlate(h, 1.0 - h, mode="full")).

For fixed `n`, minimizing `Q` is exactly equivalent to minimizing `C`. But for acceptance and final reporting use `C` when `n` changes. To avoid confusing scaling, all allowed candidates that expand or reduce are recomputed with their actual `n` before accepting a different length.

Do not replace the full vector `np.correlate` objective by autocorrelation, `1 - autocorr`, circular convolution, or periodic versions unless that formula is empirically validated against the evaluator.
