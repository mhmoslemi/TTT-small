1. Approach and rationale

1.1 Central idea

Create a genuinely unconstrained representation of every admissible step function by using a mass-normalized sigmoid/water transform. This completely removes the coupled feasibility constraints `0 <= h_i <= 1` and `sum_i h_i = n/2` from the optimization variable. Then the problem becomes a free-variable unconstrained minimization of a smooth approximation to the full, finite-support, nonsmooth correlation maximum.

The map is:

    h(z) = sigmoid(z + lambda(z))

where `lambda(z)` is chosen uniquely so that `sum_i h_i = n/2`. For any finite `z`, this gives an interior feasible vector satisfying the sum constraint. Thus gradients, line searches, and local solvers need only handle unconstrained coordinates; feasibility is maintained automatically.

The primary optimizer uses a LogSumExp smoothening of the full vector of correlation lag values, not of raw terms. It is optimized with BFGS/L-BFGS in the unconstrained `z` coordinates. A rigorous exact-acceptance layer evaluates every candidate with the supplied evaluator `max(np.correlate(h,1-h,'full')) * (2.0/n)` and only accepts it if feasibility and exact correlation objective are correct.

The method uses the supplied parent as a guaranteed fallback and improves from it by unconstrained local restarts from many noise levels around the parent, around the current best unconstrained coordinates represented by the parent, and around transferred parent interpolations at other grid resolutions. If the smooth surrogate converges within this free algorithm to the vicinity of a better exact solution, it finds small exact improvements while preserving constraints analytically.

1.2 Why this addresses the bottleneck

The bottleneck near the current record is not classic bound checking; it is a nonsmooth, nonconvex zero-gap requirement: many correlation lags switch active status, and any boundary-handling perturbation may violate the exact sum constraint while producing only a tiny exact decrease. If variables are clipped or projected after unconstrained moves, the constraint forces may overwhelm correlation forces. The water/logit transform makes the objective act directly on hidden log-differences, and the exact sum constraint becomes the root of a strictly increasing scalar function. Therefore:

- No clipping followed by re-normalization is needed for constraint satisfaction.
- Box restrictions and the equality relation are analytically coupled.
- Gradient directions inherit the true physical derivative of the transformed function, not an artificial projection correction.
- Full unconstrained escape from the parent is straightforward: perturb hidden coordinates, re-solve the mass scalar, and compute the coarse objective once.

1.3 Justified mathematical facts

- For all `z in R^n`, the sequence `lambda -> sum_i sigmoid(z_i + lambda)` is strictly continuous and strictly increasing. Its range contains `[0, n]`. Since `T = n/2` lies in `[0,n]`, a real root always exists. It is unique when the solution is not elementwise saturated; with the safe finite sigmoid it remains numerically well-defined and root-finding large intervals bracket tightly.
- The gradient of `sum_i h_i - T` with respect to `lambda` is `S = sum_i h_i(1-h_i)`. Implicit differentiation of `h_j = sigmoid(z_j + lambda(z))` gives:

    dh_j/dz_k = delta_jk q_j - q_j q_k / S

  where `q_j = h_j(1-h_j)`. This formula is exact away from the flat, safe-numerical-saturation copies.

- The exact vector of correlation lag values evaluated as `dx * np.correlate(h, 1-h, mode="full")` contains both finite-support lag directions and the boundary-truncated counts. The LagSumExp surrogate is constructed over this exact vector, so the derivative model is based on the same terms that determine the acceptance metric.

1.4 Heuristic assumptions and limitations

- The full objective remains nonconvex and nonsmooth. The LogSumExp smooth surrogate can have local minima that are exact-value saddle points or boundaries, and false local minima are likely. The method therefore uses heuristic multibeta/multinoise restarts and exact acceptance, not a global optimality claim.
- Smooth surrogate convergence only reduces the smoothed expression. An exact improvement is accepted only after the evaluator is applied. Failure to improve the surrogate objective is not treated as proven infeasibility.
- The hidden `z` parameterization has a global equivalence direction: adding a constant to all coordinates leaves `h` unchanged because `lambda` tends to absorb it. A tiny L2 regularizer is added only in hidden directions to keep the BFGS iterate; it is usually ignored in exact final construction; if it penalizes an improvement, a zero-penalty rerun can start from the obtained image of `h`.
- Very extreme hidden coordinates may have meaningful saturated derivatives but no exact mathematical one in a smooth finite parameterization. The coordinate-search stage is added below to give the candidate a fast local exact perturbation path that uses feasible pairwise mass transfer tests and maintains feasibility exactly.
- This is a local/multinaration method. Strict global optimality is not claimed.
