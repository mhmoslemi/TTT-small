1. Approach and rationale

1.1 Central idea

The exact discrete objective is a finite maximum of 2n-1 cross-correlation terms, but these terms are quadratic in the sample vector. For any two feasible vectors a and b, the convex blend

    h(t) = (1-t) a + t b,   0 <= t <= 1

is also feasible: its entries remain in [0,1] and its sum is the same constant n/2. Along this line, every correlation lag is exactly a univariate quadratic polynomial in t. Therefore the objective along the line is the maximum of 2n-1 quadratics. The exact minimum on that feasible line segment can be found only from:

- the two endpoints,
- the stationary points of the individual lags,
- pairwise intersections of the quadratics.

Call this operation an exact segment minimizer. If we can repeatedly generate useful feasible endpoints around a parent and apply exact segment minimization, we obtain a candidate that is no worse than the better of the two endpoints. This creates a very strong local movement across the nonconvex feasible set.

The new search framework combines that exact one-dimensional global operation with diversified endpoints:

- active-direction endpoints produced only by exact scalar evaluations and finite differences;
- feasible random and threshold endpoints;
- partial binary endpoints for both even and odd dimensions;
- dimension-transfer endpoints using area-preserving cell interpolation;
- pool-pairing endpoints selected from previously discovered feasible vectors.

The fundamental difference from surrogate-smoothing, LP trust-region, and generic scalar-gradient methods is that the main descent/recombination primitive is algebraically exact on its full one-dimensional search domain, using the authoritative objective exactly as evaluated by the intended evaluator. It does not replace the max by a soft-max, does not rely on a convex relaxation, does not solve an epigraph linear program as the main basis for stepping, and does not require manual orientation formulas for `np.correlate`; the line coefficients are reconstructed from exact full-correlation arrays at three parameter values.

1.2 Why this can improve the parent

A given construction h is feasible. The min-max objective is nonconvex and piecewise quadratic. Local pros visited from flat subgradients can quickly stagnate when several active lags conflict. Exact segment search does far more: given any two feasible constructions, it finds the true minimum accessible on the face joining them. If those endpoints are chosen as slight projected steps along active-gradient directions, two randomly diversified members of a pool, a partially binary construction near a continuous optimum, or approximate reconstructions at nearby dimensions, this operation can blend complementary improvements into a single feasible vector and often yields an immediate non-increasing objective. If one endpoint is slightly better and another endpoint has reduced a different active lag, the exact optimum between them can reduce the dominant lift.

This is particularly useful for tiny record improvements: a parent near an optimum will generally lie at a point where several active lag values compete. Pairing that parent with endpoints that locally reduce one or more competing lags, then solving the exact line envelope, is a targeted local minimization of the piecewise quadratic structure. Pooling and repeatably reusing the face operation can progressively polish without solving a full convexified subproblem whose exact/global behavior is not trustworthy.

1.3 Main bottlenecks addressed

- Nonsmooth maximum: replaced by exact one-dimensional minimization of the finite maximum along a feasible line.
- Constraint violation from local updates: no coordinate clipping/rescaling is used for accepted dense h points; moves stay on convex combinations of already feasible points or are only treated through a labeled feasibility projection for endpoint creation.
- Correlation indexing errors: the principal optimizer never depends on the orientation of `np.correlate` output, because every objective vector evaluation is returned in the same order and coefficients are fit from exact evaluations at t=0, 1/2, 1. The final accepted score always comes from replications of the evaluator. Finite-difference endpoint choices also take only the scalar exact active weighted objective and do not need an explicitly written correlation pair formula.
- Dimension changes: parent is retained and only improved after exact repair and scoring. Area-preserving transfer to nearby dimensions is explicitly defined and then exact feasibility is restored.
- The problem is genuinely nonconvex: all moves and component-1D дожminimization are judged with the authoritative objective. No solver is allowed to accept its relaxation.

1.4 Honest limitations

The proposed method is not a proof of global optimality. Its segment search is exact in the one-dimensional direction and segment domain specified, but the finite-dimensional search is still controlled by endpoint choice, pool diversity, and finite time. There is no global optimality claim, and there is no guarantee of crossing the target bound by any prescribed time. The target bound is a goal, not a permit. The parent preliminary must be retained and extremely likely to remain the fallback if the search can only produce worse candidates. The heuristics used are endpoint generation, pool acceptance, branching rate, dimension prioritization, and window size; ultimately every store operation reduces to exact feasible evaluation. Whether or not an improvement such as `<= 0.3808` can be found depends on the seeded endpoint trajectories and the time available.

1.5 Behavior if there is no parent

If `initial_h_values` is unavailable, the initialization constructs a compact deterministic/random feasible parent-free seed using trigonometric, uniform, and slightly noisy formulas, projects it exactly to feasible, and uses it as a generic reference dimension. The remaining exact line operation, feasibility repair, pool, and dimension transfer components remain fully applicable. Nothing in the algorithm requires a hard-coded table.

2.1 Representation and exact evaluator objective

Represent a candidate by a one-dimensional NumPy array h of length n. Define

    dx = 2.0 / n.

The constraints are

    0 <= h_i <= 1 for every i
    sum_i h_i = n / 2.

The authoritative objective is exactly

    C5(h) = dx * max_m corr_m(h)
    corr = np.correlate(h, 1-h, mode='full').

The correlation vector has temperature difference dimension L = 2n-1 and contains both lag directions. Do not substitute circular correlation, a convolved positive coefficient, `1 - autocorr` with incomplete boundary terms, or any replaced sum. The implementation must expose a helper returning both the scaled vector for use inside the heuristic and the scalar exact objective used to control best selection. 2.2 Feasible segment and expansion of each lag

For two feasible vectors a,b of the same length n and any t in [0,1], define

    h(t) = a + t d,  d = b - a.

Entry-wise feasibility is automatic because both endpoints are in [0,1]; element affinity and monotone scalar interpolation show the interpolation remains in [0,1]. Sum feasibility follows from

    sum_i h_i(t) = (1-t) sum_i a_i + t sum_i b_i = n/2.

For the group of terms composed by a particular lag m in the exact full-correlation output, the contribution before the scaling factor is a sum of terms of the form

    h_i(t) * (1 - h_j(t)),

where (i,j) is the set of index pairs selected by the corresponding full-correlation output. Expand:

    h_i(t) = a_i + t d_i,
    1 - h_j(t) = 1 - a_j - t d_j,

    h_i(t) (1 - h_j(t))
    = a_i(1-a_j)
      + t [ d_i(1-a_j) - a_i d_j ]
      - t^2 d_i d_j.

Grouping by lag m gives a quadratic function

    Phi_m(t) = dx * (A_m t^2 + B_m t + C_m).

The whole vector Φ(t) has the same length and same ordering as the exact correlation output. Thus

    f(t) = max_m Φ_m(t) = max_m (a_m t^2 + b_m t + c_m)

where coefficients are already scaled by dx exactly. Since c-a is their quadratic pair, it can be recovered exactly from three exact evaluations:

    V0 = dx * np.correlate(a,1-a,mode='full')
    Vm = dx * np.correlate((a+b)/2, 1-(a+b)/2,mode='full')
    V1 = dx * np.correlate(b,1-b,mode='full')

Then solve the interpolation identities

    V0 = C
    Vm = C + B/2 + A/4
    V1 = C + B + A.

Therefore coefficient arrays are

    c = V0
    a = 2 * (V0 + V1 - 2 * Vm)
    b = V1 - V0 - a.

The centered value at t = 1/2 cannot be dropped: three-point interpolation resolves the quadratic coefficients. If rounding makes `a` tiny, set it to zero only inside a protected zero tolerance.

2.3 Exact minima of the maximum of quadratics

For each of L = 2n-1 functions q_m(t)=a_m t^2+b_m t+c_m, let

    f(t) = max_m q_m(t),   0 <= t <= 1.

This is the upper envelope of finitely many quadratics. Let S be the set of points comprising

- t=0 and t=1,
- for any m with |a_m| above tolerance, roots of q'_m(t)=0, namely t = -b_m/(2a_m) if they lie in [0,1],
- any t in [0,1] where q_m(t)=q_k(t) for some pair m<k.

The second derivative order suggests all interior minima of a single smooth piece are among derivative roots; any transition between different active pieces must occur at a pair intersection. The upper envelope overall can move from one branch to another only at breakpoints produced by intersection. Therefore every global minimum of the upper envelope over a closed interval is attained among these selected points. This is exact for one piece discontinuities by continuity, and exact for inactive overlapping types because if a point is a minimum inside one active branch subinterval and differentiable there, it must either be an endpoint of a piece (pair intersection or interval end) or a stationary root of the active lndividual quadratic. There are no global minima at a breakpoint where piece transition occurs that avoid a pair intersection because pair equality is exactly the transition condition.

solve:
