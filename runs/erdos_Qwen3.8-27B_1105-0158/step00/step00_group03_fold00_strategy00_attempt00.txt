1.1 Primary objective representation

Let the returned construction be a vector h of length n over a uniform grid on [0,2]. With dx=2/n, the exact evaluator is:

C(h) = max over all 2n-1 lags of [ np.correlate(h, 1-h, mode='full') * dx ].

Equivalently, each lag value is a directed, truncated pair interaction. The constraints are simultaneous:

0 <= h_i <= 1 for all i,
sum_i h_i = n/2.

The problem is nonconvex because each lag is a sum of terms h_i(1-h_j). There is no convex global formulation accepted by standard CVXPY for the exact objective, so the search is deliberately heuristic but exact for acceptance: every proposed vector is scored by the original evaluator; only finite, feasible vectors that improve the recorded exact score are accepted.

1.2 Chaotic main idea

The essential improvements come from local smoothing of the max objective and constrained local optimization in the feasible polytope. The key facts are:

- C(h) is the maximum of many affine minus bilinear functions. It is nonsmooth but cheap to evaluate.
- For a finite vector, each lag value has an ordinary analytic gradient with respect to h when other components are held fixed. A smooth upper surrogate for the max can be optimized with gradients. A good surrogate is log-sum-exp:
  F_tau(h) = tau log(sum_k exp(c_k(h)/tau)), where c_k is the exact lag value in evaluator units.
  For small tau, F_tau is close to C(h) and has a useful averaged gradient concentrated on the largest lags.
- The equality plus box constraint is a small capped simplex. We repair by solving a monotone clipping problem and then by a valid residual balance through actual slack.
