1. Approach and rationale

The target is a discrete, finite-support cut-pair optimization problem. Let \(n\) be the returned number of samples, \(\Delta x=2/n\), target sum \(S=n/2\), and
\[
c(h)=\Delta x\,\operatorname{corr}(h,1-h,\text{"full"}),\qquad C(h)=\max_\ell c(h)_\ell .
\]
The evaluator is authoritative: the stored candidate after all construction is scored by its original one-line metric, not by any surrogate. The problem is nonconvex because each nonzero output contains terms \(h_i(1-h_j)\), hence bilinear products.

The central plan is to use the supplied parent as the main feasible anchor and improve it by a hierarchy of local, exactly scored searches. The hierarchy is:

- A smooth log-sum-exp epigraph smoothing with SciPy/SLSQP. The exact score is evaluated after each finished internal solve and projected back to the feasible box-simplex. This can move the solution in a way that averages competing active lags.
- A direct-nonsmooth exact integration using active-set finite-difference linear cone directions and exact line searches in the feasible set. The direction is obtained by a linear program using local derivatives of the approximated objective vector computed directly using the same `np.correlate` evaluator. The aim is to reduce the current maximum component, then accept only candidates whose exact retuned achieves a reliable decrease.
- A strange ancillary method to avoid being trapped around the parent: balanced binary simulated annealing, and standard deterministic constructions. If they improve, only their evaluated h to return. They also generate starting inputs to neither localized method.
- If time permits, small model reductions by transferring a validated best candidate to nearby even lower n and exactly als, because the problem rewards smaller binary choices and a valid construction corresponding to lower n can meet the bound even though it is measured according to rounding's metric. This is explicitly a heuristic transfer and exact objective comparison.

No method below is treated as a global optimum proof. A candidate is acceptable only if its exact metric satisfies the constraints and a late exact reevaluation `evaluate(initial)`. There is no claim that any unexpected construction attains a global minimum.
