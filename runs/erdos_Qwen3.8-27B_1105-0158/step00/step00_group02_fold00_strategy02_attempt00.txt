1.1 Central idea
The implementation should improve the supplied parent construction by treating the exact discrete objective as a three-stage minimax problem rather than trying to make one generic nonlinear solver succeed. Every candidate is finally judged only by the exact evaluator; the rest of the algorithm is a search that repeatedly produces feasible vectors and tests them exactly.

The primary mechanism is a staged homotopy minimax optimizer:
- First minimize a smooth logarithmic-sum-exp surrogate of the maximum lag-clearance value with the exact box and equality constraints. This gives a gradient-based well-behaved surrogate around the nonsmooth maximum and can reduce many near-maximal lags at once.
- Then, once the smooth solver stagnates, perform an explicit first-order minimax descent using active lag gradients. Build many valid tangent directions by solving small anchored linear minimax programs of the active subgradients; accept only those that reduce the exact objective after a line search. This is materially different from simply optimizing a soft objective because it targets the active lags that actually determine the exact max and forces many coordinates to move together in a direction that is feasible for the sum and box constraints.
- Periodically add randomized feasible pairwise or multi-coordinate perturbations and stage exact accept/reject, using candidate selection guided by smooth gradients and headroom, but with the real objective deciding acceptance.
