So ∂c_k/∂h[j] = I[j ∈ S] - h[j+k]*I[j ∈ S] - h[j-k]*I[j-k ∈ S]
= (1 - h[j+k]) * I[j ∈ S] - h[j-k] * I[j-k ∈ S]

Where S = {i : max(0,-k) ≤ i ≤ min(n-1, n-1-k)}

This matches what I had before. Good.

For k ≥ 0:
- S = [0, n-1-k]

Let me design a **coordinate descent** approach:

For each coordinate i, I want to find the best (i, j, δ) move. Instead of searching all pairs, I can:
1. Compute the gradient g
2. For coordinate i, the best direction is -g[i] (decrease if g[i] > 0, increase if g[i] < 0)
3. To maintain the sum constraint, I need a partner j
4. The best partner is the one that most reduces the objective

A simpler approach: just do coordinate descent where I change one coordinate and adjust the closest one (or a fixed partner).

Actually, the simplest effective approach: 

**交替坐标下降 (Alternating Coordinate Descent):**
- For each i in 0..n-1:
  - Try h[i] + δ for small δ (and correspondingly adjust h[(i+1)%n] - δ)
  - If it improves, keep it; else revert
  - Also try h[i] - δ with h[(i+1)%n] + δ

This is O(n * number_of_tries) per sweep, and each evaluation is O(n). So O(n² * tries) per sweep.

But actually, I can be smarter. The gradient tells me the best direction for each coordinate. So:

For coordinate i, the best move (maintaining sum) is to move mass from i to j where g[j] - g[i] is most negative (i.e., g[i] is large positive and g[j] is large negative, or vice versa).

Let me implement a **gradient-guided coordinate descent**:

```python
def grad_coord_descent(h, n, deadline, alpha=500):
    h = project_feasible(h, n)
    best_c = compute_c5(h, n)
    
    while time.time() < deadline:
        g = grad_smooth_max(h, n, alpha)
        improved = False
        for i in range(n):
            if time.time() > deadline:
                return h, best_c
            # Find best partner
            # We want to move mass from high gradient to low gradient
            # Best j: minimizes g[j] if g[i] > 0 (move mass away from i)
            # Or maximizes g[j] if g[i] < 0 (move mass to i)
            if g[i] > 1e-10:
                j = np.argmin(g)
                direction = -1  # decrease h[i], increase h[j]
            elif g[i] < -1e-10:
                j = np.argmax(g)
                direction = 1   # increase h[i], decrease h[j]
            else:
                continue
            if i == j:
                continue
            
            # Try several step sizes
            for step in [0.1, 0.05, 0.02, 0.01, 0.005, 0.002, 0.001]:
                if direction == -1:
                    if h[i] - step < 0 or h[j] + step > 1:
                        continue
                    h[i] -= step; h[j] += step
                else:
                    if h[i] + step > 1 or h[j] - step < 0:
                        continue
                    h[i] += step; h[j] -= step
                
                c = compute_c5(h, n)
                if c < best_c - 1e-12:
                    best_c = c
                    improved = True
                    break
                else:
                    if direction == -1:
                        h[i] += step; h[j] -= step
                    else:
                        h[i] -= step; h[j] += step
        
        if not improved:
            # Try with different alpha
            alpha *= 3
            if alpha > 100000:
                break
    
    return h, best_c
```

def compute_c5(h, n):

    return float(np.max(np.correlate(h, 1.0 - h, mode='full')) * dx)

def project_feasible(h, n):
    target = n / 2.0

        if abs(diff) < 1e-14:

            room = 1.0 - h
            tot = room.sum()
            if tot < 1e-14:
                break
            h += (diff / tot) * room
        else:
            tot = h.sum()
            if tot < 1e-14:
                break
            h += (diff / tot) * h
    return np.clip(h, 0.0, 1.0)

def grad_smooth_max(h, n, alpha):
    dx = 2.0 / n
    c = np.correlate(h, 1.0 - h, mode='full') * dx
    cmax = c.max()
    shifted = alpha * (c - cmax)
    mx = shifted.max()
    w = np.exp(shifted - mx)
    w /= w.sum()
    grad = np.zeros(n)
