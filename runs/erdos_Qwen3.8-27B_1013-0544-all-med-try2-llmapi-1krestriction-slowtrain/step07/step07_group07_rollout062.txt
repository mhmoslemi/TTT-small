The feasible polytope is {h : 0 ≤ h ≤ 1, Σh = n/2}. Its vertices are the 0-1 vectors with exactly n/2 ones. The linear objective is min_v g^T v where g is the gradient. This is simply: sort g, take the n/2 smallest, set those to 1 and the rest to 0.

So Frank-Wolfe for this problem is:
1. Compute g = gradient of smooth_max(c)
2. v = top-n/2 indicator of -g (i.e., set v[i]=1 where g[i] is smallest)
3. h_new = (1-γ)h + γv
4. γ = line search (or γ = 2/(t+2))

This is O(n log n) per iteration (for the sort) and very simple! Let me use this.

Actually wait, the smooth max objective is not differentiable in general, but the log-sum-exp approximation is smooth. So the gradient is well-defined.

```python
def frank_wolfe(h, n, alpha, max_iter=5000, tol=1e-10):
    h_curr = h.copy()
    best_h = h_curr.copy()
    best_obj = smooth_obj(h_curr, n, alpha)
    
    for t in range(max_iter):
        # Compute gradient of smooth max
        c = compute_all_lags(h_curr, n)
        m = c.max()
        shifted = alpha * (c - m)
        weights = np.exp(shifted - shifted.max())
        weights /= weights.sum()
        
        # Gradient = sum_k weights[k] * grad(c_k)
        g = np.zeros(n)
        for k in range(2*n-1):
            if weights[k] < 1e-15:
                continue
            g += weights[k] * lag_gradient(h_curr, n, k-(n-1))
        
        # Frank-Wolfe step: find vertex minimizing g^T v
        # v[i] = 1 for the n/2 indices where g[i] is smallest
        idx = np.argsort(g)[:n//2]
        v = np.zeros(n)
        v[idx] = 1.0
        
        # Step size
        gamma = 2.0 / (t + 2.0)
        h_new = (1 - gamma) * h_curr + gamma * v
        h_new = project_feasible(h_new, n)
        
        obj_new = smooth_obj(h_new, n, alpha)
        if obj_new < best_obj:
            best_obj = obj_new
            best_h = h_new.copy()
        
        # Check convergence
        sgd = (h_curr - v) @ g
        if sgd < tol:
            break
        
        h_curr = h_new
    
    return best_h, best_obj
```

For all lags at once, the gradient of the weighted sum is:

For lag L > 0:
grad_k[j] = dx * [(1-h[j+L])*1_{j<n-L} - h[j-L]*1_{j>=L}]

So: g[j] = dx * Σ_{L>0} w_{n-1+L} * (1-h[j+L])*1_{j<n-L} - dx * Σ_{L>0} w_{n-1+L} * h[j-L]*1_{j>=L}

This can be computed using correlations! Note that:
Σ_{L>0} w_L * (1-h[j+L]) = Σ_{L>0} w_L - Σ_{L>0} w_L * h[j+L]

The first term is just a constant. The second term is a weighted sum of shifted h, which is a convolution-like operation.

def weighted_gradient(h, n, weights):
    """Compute sum_k weights[k] * grad(c_k) efficiently."""
    dx = 2.0 / n
    g = np.zeros(n)
    for k in range(2*n-1):
        w = weights[k]
        if w < 1e-15:
            continue
        lag = k - (n-1)
        m = abs(lag)
        if m == 0:
            g += w * dx * (1.0 - 2.0 * h)
        elif lag > 0:
            g[:n-m] += w * dx * (1.0 - h[m:])
            g[m:] += -w * dx * h[:n-m]
        else:
            g[m:] += w * dx * (1.0 - h[:n-m])
            g[:n-m] += -w * dx * h[m:]
    return g

            if tot < 1e-16:

- So the change in the smooth max is approximately:

- where g = Σ_k w_k * grad_k

We want this to be negative, so we want g[i] - g[j] < 0, i.e., g[i] < g[j].

This is: maximize (g[j] - g[i]) over all pairs, subject to h[i] > 0 (can decrease... wait, we're increasing h[i] and decreasing h[j]).

Let me re-derive. The move is: h[i] += δ, h[j] -= δ.
Change in objective ≈ δ * (g[i] - g[j]).
We want this < 0, so g[i] - g[j] < 0, i.e., g[j] > g[i].

So we want to find (i, j) with g[j] - g[i] maximized, subject to:
- h[i] + δ ≤ 1 (room to increase i)
- h[j] - δ ≥ 0 (room to decrease j)

The best pair is: i with smallest g[i] (and h[i] < 1), j with largest g[j] (and h[j] > 0).

So the best move is: i = argmin{g[i] : h[i] < 1}, j = argmax{g[j] : h[j] > 0}.
And δ = min(1 - h[i], h[j]).

This is O(n) to find and O(n²) to evaluate (for compute_c5). Per iteration of local search, this is very fast!

    if time.time() < deadline - 12:
        trust = 0.1
        for _ in range(5):
            if time.time() > deadline - 8:
                break
            h_new = active_set_lp(best_h, n, trust)
            c_new = compute_c5(h_new, n)
            if c_new < best_c:
                best_c = c_new
            best_h = h_new
            trust *= 0.6
    # Phase 4: High-alpha SLSQP
    if time.time() < deadline - 10:
        h_new = slsqp_pass(best_h, n, 200000, maxiter=4000, ftol=1e-16)
        c_new = compute_c5(h_new, n)
        if c_new < best_c:
            best_c, best_h = c_new, h_new
    # Phase 5: Gradient local search
    if time.time() < deadline - 3:
        best_h, best_c = gradient_local_search(best_h, n, min(deadline - 1, time.time() + 15), alpha=5000)
    best_h = project_feasible(best_h, n)
    best_c = compute_c5(best_h, n)
    return best_h, best_c

def run(seed=42, budget_s=1100, **kwargs):
    t0 = time.time()
    rng = np.random.RandomState(seed)
    deadline = t0 + budget_s - 5
    try:
        h_init = np.array(initial_h_values, dtype=float).copy()
        n_init = len(h_init)
    except Exception:
        h_init = None
        n_init = 300
    best_h = None
    best_c = float('inf')
    # Phase A: Optimize at initial n
    if h_init is not None:
        alloc = min(280, (deadline - t0) * 0.28)
        h_opt, c_opt = optimize_at_n(h_init, n_init, t0 + alloc, rng)
        best_h, best_c = h_opt, c_opt
    # Phase B: Try other n values
    n_try_list = [200, 250, 350, 400, 500]
    if n_init in n_try_list:
        n_try_list.remove(n_init)
    for n_try in n_try_list:
        if time.time() > deadline - 60:
            break
        remaining = deadline - time.time() - 30
        if remaining < 50:
            break
        alloc = min(90, remaining * 0.2)
        if best_h is not None:
            x_best = np.linspace(0, 2, len(best_h))
            x_new = np.linspace(0, 2, n_try)
            h_start = np.interp(x_new, x_best, best_h)
        else:
            h_start = np.full(n_try, 0.5)
        h_start = project_feasible(h_start, n_try)
        h_opt, c_opt = optimize_at_n(h_start, n_try, time.time() + alloc, rng)
        if c_opt < best_c:
            best_c = c_opt
            best_h = h_opt
    # Phase C: Refine best with multiple SLSQP passes
    if best_h is not None and time.time() < deadline - 30:
        n = len(best_h)
        for alpha in [50000, 200000, 500000, 1000000]:
            if time.time() > deadline - 15:
                break
            h_new = slsqp_pass(best_h, n, alpha, maxiter=4000, ftol=1e-16)
            c_new = compute_c5(h_new, n)
            if c_new < best_c:
                best_c = c_new
                best_h = h_new
            # Also try FW refinement
            if time.time() < deadline - 20:
                h_fw, c_fw = frank_wolfe(best_h, n, 1000, time.time() + 15, max_iter=5000)
                if c_fw < best_c:
                    best_c = c_fw
                    best_h = h_fw
    # Phase D: Final local search
    if best_h is not None and time.time() < deadline - 3:
        n = len(best_h)
        best_h, best_c = gradient_local_search(best_h, n, deadline - 1, alpha=10000, max_iters=50000)
        best_h = project_feasible(best_h, n)
        best_c = compute_c5(best_h, n)
    if best_h is None:
        best_h = project_feasible(np.full(n_init, 0.5), n_init)
        best_c = compute_c5(best_h, n_init)
    return best_h, best_c, len(best_h)
