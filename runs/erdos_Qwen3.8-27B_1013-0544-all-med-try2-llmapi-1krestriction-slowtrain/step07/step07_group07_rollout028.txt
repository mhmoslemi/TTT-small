def project_feasible(h, n):

        diff = target_sum - h.sum()
        if abs(diff) < 1e-12:

        if diff > 0:

            tot = room.sum()
            if tot < 1e-12: break
            h += (diff / tot) * room
        else:
            tot = h.sum()
            if tot < 1e-12: break
            h += (diff / tot) * h
    return np.clip(h, 0.0, 1.0)

c[k] = sum_i h[i] * (1-h[i+k]) * dx

To decrease c[k], we want to:
- Where h[i] is high and h[i+k] is low: move mass from i to i+k (or vice versa depends on the sign)
- Actually, to decrease h[i]*(1-h[i+k]), we can either decrease h[i] or increase h[i+k]

The gradient tells us: ∂c[k]/∂h[i] = (1-h[i+k]) - h[i-k] (for lag k > 0, with appropriate bounds)

So if the gradient at position i is positive for the active lag, we should decrease h[i]. If negative, increase h[i].

The "pressure" at position i is: P[i] = sum_{k active} w_k * ∂c[k]/∂h[i]

We want to move mass from high-P positions to low-P positions (to decrease the weighted sum of active lags).

This is like a "heat flow" or "chip-firing" process.

Let me implement this as follows:
1. Compute P[i] for all i
2. Find i with max P and j with min P
3. Move a small amount from i to j
4. Repeat

This is O(n^2) per iteration (to find max and min, and to recompute P). But we can be smarter: only recompute P when we've made enough moves.

If I move δ from position i to position j, the change in c[k] (for lag k) is:
Δc[k] ≈ δ * (∂c[k]/∂h[j] - ∂c[k]/∂h[i])

So the total change in the smoothed max is:
Δf ≈ δ * sum_k w_k * (∂c[k]/∂h[j] - ∂c[k]/∂h[i]) = δ * (P[j] - P[i])

where P = sum_k w_k * ∂c[k]/∂h is the total pressure.

So to minimize f, we want P[j] - P[i] < 0, i.e., P[j] < P[i]. We move from high-P to low-P.

The best single move is: find (i,j) that maximizes P[i] - P[j], subject to h[i] > 0 and h[j] < 1.

But we also need to respect the sum constraint (which is automatically satisfied by moving from i to j).

So the algorithm is:
1. Compute P = weighted sum of gradients
2. Find i = argmax P (among positions with h[i] > 0)
3. Find j = argmin P (among positions with h[j] < 1)
4. Move δ = min(h[i], 1-h[j], step_size) from i to j
5. Recompute P
6. Repeat

This is O(n * |active|) per step (to compute P), and we do O(1) work to find the best move. Total: O(n * |active| * num_steps).
