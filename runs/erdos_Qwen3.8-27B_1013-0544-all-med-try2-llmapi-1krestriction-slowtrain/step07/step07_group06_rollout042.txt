The key is that for a fixed pair (i,j), the change in each f_k is linear in δ:
f_k(δ) = f_k(0) + δ * (g_k[i] - g_k[j])

where g_k[i] = ∂f_k/∂h[i].

So the objective max_k f_k(δ) is the maximum of linear functions of δ, which is a convex piecewise-linear function of δ. The minimum can be found exactly!

The minimum of max of linear functions occurs at a breakpoint, which is where two of the linear functions are equal. So I can find it by:
1. Computing all breakpoints δ where f_a(δ) = f_b(δ) for some a, b
2. Evaluating the max at each breakpoint and at the boundaries
3. Taking the minimum
