For the coordinate search, here's the key insight:
- If we move mass from position j to position i (h[i] += d, h[j] -= d), the change in f_k is:
  Δf_k ≈ d * (∂f_k/∂h[i] - ∂f_k/∂h[j])

- For the active constraint k*, we want ∂f_{k*}/∂h[i] - ∂f_{k*}/∂h[j] < 0

This gives us a way to score potential moves without doing a full evaluation.

    dx = 2.0 / n
    best_c = compute_c5(h, n)

            break

        corr = np.correlate(h, 1-h, mode='full') * dx
        idx = np.argsort(corr)[-top_k:]

        # grad_approx[i] = sum over active k of w_k * ∂f_k/∂h[i]

            if tot < 1e-14:

    dx = 2.0 / n
    corr = np.correlate(x, 1 - x, mode='full') * dx
    M = corr.max()
    cs = alpha * (corr - M)
    cs -= cs.max()
    S = np.exp(cs).sum()
    return M + np.log(S) / alpha

def _sm_grad(x, n, alpha):
    dx = 2.0 / n
    corr = np.correlate(x, 1 - x, mode='full') * dx
    M = corr.max()
    cs = alpha * (corr - M)
    cs -= cs.max()
    w = np.exp(cs)
    S = w.sum()
    w /= S

    nn = len(corr)
