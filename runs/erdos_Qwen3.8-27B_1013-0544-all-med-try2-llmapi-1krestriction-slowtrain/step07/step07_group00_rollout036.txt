- i-m+(n-1) is in [0, n-1] (h[i] appears as h[j+m-(n-1)] with j=i-m+(n-1))

For each affected m, the slope of c[m] wrt h[i] is:
- From h[j] role: +（1-h[i+m-(n-1)])*dx (if valid, and i+m-(n-1) != i)
- From (1-h) role: -h[i-m+(n-1)]*dx (if valid, and i-m+(n-1) != i)

If i+m-(n-1) == i (i.e., m = n-1), then h[i] appears as both h[j] and h[j+m-(n-1)] = h[i], giving h[i]*(1-h[i])*dx. The slope of this term is (1-2*h[i])*dx.

So the slope for m = n-1 is special: it's (1-2*h[i])*dx (from the h[i]*(1-h[i]) term), plus any other contributions.

Wait, for m = n-1: c[n-1] = Σ_{j=0}^{n-1} h[j]*(1-h[j])*dx
The term for j=i is h[i]*(1-h[i])*dx. Its derivative wrt h[i] is (1-2*h[i])*dx.
All other terms don't involve h[i]. So slope at m=n-1 is (1-2*h[i])*dx.

For m ≠ n-1:
- If 0 ≤ i+m-(n-1) < n and i+m-(n-1) ≠ i: slope gets +(1-h[i+m-(n-1)])*dx
  (i+m-(n-1) ≠ i means m ≠ n-1, which we already excluded)
- If 0 ≤ i-m+(n-1) < n and i-m+(n-1) ≠ i: slope gets -h[i-m+(n-1)]*dx

And the base value c[m] (with h[i] at its current value) is:
c[m] = c_current[m] - h[i]*slope_total[m] + h[i]*slope_special_part... 

Actually, it's easier to just note: c[m] (current) = c_base[m] + h[i_current] * slope[m]
So c_base[m] = c[m] - h[i_current] * slope[m]

Then the new c[m](t) = c_base[m] + t * slope[m] = c[m] - h[i_current]*slope[m] + t*slope[m] = c[m] + (t - h[i_current])*slope[m]

So to find the best t for coordinate i:
1. Compute slope[m] for all affected m
2. The new objective is max_m (c[m] + (t - h[i])*slope[m])
   = max(m not affected, c[m],  max(m affected, c[m] + (t-h[i])*slope[m]))
   
   The "not affected" part is constant (call it C_not). So we minimize:
   max(C_not, max(m affected, c[m] + (t-h[i])*slope[m]))
   
   over t ∈ [0,1].

3. This is still a convex piecewise linear function of t. We can find its minimum.

Let me define u = t - h[i], so u ∈ [0-h[i], 1-h[i]].
We minimize max(C_not, max(m affected, c[m] + u*slope[m])) over u ∈ [-h[i], 1-h[i]].

For the "affected" part, it's the max of lines u → c[m] + u*slope[m].
Adding C_not (a constant line) doesn't change the structure.

So the problem reduces to: minimize max(C_not, c[m1]+u*s1, c[m2]+u*s2, ...) over u in a range.

This is the same as before. The minimum is at a breakpoint or boundary.

For a set of lines, the upper envelope changes at intersection points. We can find the minimum by:

3. Find where the envelope is minimized in the range

```python
def get_optimal_t(i, h, n, c):
    """Find optimal h[i] given all other coordinates fixed."""
    dx = 2.0 / n
    # Compute slopes for affected m
    slopes = {}
    # Role 1: h[i] as h[j] with j=i
    m1_min = max(0, n-1-i)
    m1_max = min(2*n-2, n-1-i+n-1)
    for m in range(m1_min, m1_max+1):
        j2 = i + m - (n-1)
        if 0 <= j2 < n:
            if m == n-1:
                slope = (1 - 2*h[i]) * dx  # h[i]*(1-h[i]) term
            else:
                slope = (1 - h[j2]) * dx
            slopes[m] = slopes.get(m, 0) + slope
    
    # Role 2: h[i] as h[j+m-(n-1)] with j=i-m+(n-1)
    m2_min = max(0, i)  # i-m+(n-1) >= 0 → m <= i+n-1, always true for m <= 2n-2
    # j = i-m+(n-1), need 0 <= j < n → 0 <= i-m+n-1 < n → 1-n+i < m <= i+n-1
    # m > i-1 → m >= i (integer)
    # m <= i+n-1
    m2_min = max(0, i)
    m2_max = min(2*n-2, i+n-1)
    for m in range(m2_min, m2_max+1):
        j1 = i - m + (n-1)
        if 0 <= j1 < n:
            if m == n-1:
                pass  # already counted in role 1
            else:
                slopes[m] = slopes.get(m, 0) - h[j1] * dx
    
    # Now find C_not (max of c[m] for non-affected m)
    affected_set = set(slopes.keys())
    C_not = max([c[m] for m in range(2*n-1) if m not in affected_set]) if len(affected_set) < 2*n-1 else 0
    
    # Minimize max(C_not, c[m] + (t-h[i])*slopes[m]) over t in [0,1]
    # Let u = t - h[i], u in [-h[i], 1-h[i]]
    # f(u) = max(C_not, max_m (c[m] + u*slopes[m]))
    
    # Evaluate at boundaries and crossing points
    candidates = [-h[i], 1-h[i]]
    
    # For each pair of affected m's, compute crossing point
    # But this is O(k²) where k is number of affected m's (up to ~2n)
    # Let's limit: only consider crossings of the "top" lines
    # At u=0, the top line is argmax c[m] for affected m
    # At u = 1-h[i], the top line is argmax (c[m] + (1-h[i])*slopes[m])
    # At u = -h[i], the top line is argmax (c[m] + (-h[i])*slopes[m])
    
    # Get the top-3 lines at each endpoint
    affected_ms = list(slopes.keys())
    if not affected_ms:
        return h[i]  # no change needed
    
    vals_u0 = [c[m] for m in affected_ms]
    top_at_0 = sorted(affected_ms, key=lambda m: -c[m])[:5]
    
    vals_u_pos = [c[m] + (1-h[i])*slopes[m] for m in affected_ms]
    top_at_pos = sorted(affected_ms, key=lambda m: -(c[m] + (1-h[i])*slopes[m]))[:5]
    
    vals_u_neg = [c[m] + (-h[i])*slopes[m] for m in affected_ms]
    top_at_neg = sorted(affected_ms, key=lambda m: -(c[m] + (-h[i])*slopes[m]))[:5]
    
    all_top = set(top_at_0 + top_at_pos + top_at_neg)
    
    # Try crossings of pairs in all_top
    for idx_a in range(len(all_top)):
        for idx_b in range(idx_a+1, len(all_top)):
            ma = list(all_top)[idx_a]
            mb = list(all_top)[idx_b]
            sa = slopes[ma]
            sb = slopes[mb]
            if abs(sa - sb) < 1e-15:
                continue
            u_cross = (c[mb] - c[ma]) / (sa - sb)
            if -h[i] <= u_cross <= 1-h[i]:
                candidates.append(u_cross)
    
    # Also add the "kinks" where C_not becomes active
    # C_not is a horizontal line; it intersects line m at u = (C_not - c[m])/slopes[m]
    for m in all_top:
        if abs(slopes[m]) > 1e-15:
            u_cross = (C_not - c[m]) / slopes[m]
            if -h[i] <= u_cross <= 1-h[i]:
                candidates.append(u_cross)
    
    # Evaluate f at each candidate
    best_val = float('inf')
    best_u = 0
    for u in candidates:
        u = np.clip(u, -h[i], 1-h[i])
        val = C_not
        for m in affected_ms:
            v = c[m] + u * slopes[m]
            if v > val:
                val = v
        if val < best_val:
            best_val = val
            best_u = u
    
    return h[i] + best_u
```

```python
import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h, n):
    dx = 2.0 / n
    return float(np.max(np.correlate(h, 1 - h, mode='full')) * dx)

def compute_c5_vec(h, n):
    dx = 2.0 / n
    return np.correlate(h, 1 - h, mode='full') * dx

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h.copy(), 0.0, 1.0)
    for _ in range(200):
        diff = target - h.sum()
        if abs(diff) < 1e-13:
            break
        if diff > 0:
            room = 1.0 - h
            tot = room.sum()
            if tot < 1e-14:
                break
            h += (diff / tot) * room
        else:
            tot = h.sum()
            if tot < 1e-14:
                break
            h += (diff / tot) * h
    return np.clip(h, 0.0, 1.0)

def grad_smooth_max(h, n, alpha):
    c = compute_c5_vec(h, n)
    c_shift = alpha * (c - c.max())
    mx = c_shift.max()
    w = np.exp(c_shift - mx)
    w /= w.sum()
    dx = 2.0 / n
    grad = np.zeros(n)
    # Vectorized gradient computation
    for m in range(2 * n - 1):
        if w[m] < 1e-12:
            continue
        k = m - (n - 1)
        wm = w[m] * dx
        if k >= 0:
            nv = n - k
            grad[:nv] += wm * (1.0 - h[k:])
            grad[k:] -= wm * h[:nv]
        else:
            kk = -k
            nv = n - kk
            grad[kk:] += wm * (1.0 - h[:nv])
            grad[:nv] -= wm * h[kk:]
    return grad

def _obj(x, n, alpha):
    c = compute_c5_vec(x, n)
    m = c.max()
    sh = alpha * (c - m)
    mx = sh.max()
    return float(m + (mx + np.log(np.sum(np.exp(sh - mx)))) / alpha)

def _grad(x, n, alpha):
    return grad_smooth_max(x, n, alpha)

def _eq(x, n):
    return float(x.sum() - n / 2.0)

def _eq_jac(x, n):
    return np.ones(n)

def lbfgs_opt(h, n, deadline, max_alphas=(1000, 5000, 20000, 100000, 500000)):
    best_c = compute_c5(h, n)
    bounds = [(0.0, 1.0)] * n
    for alpha in max_alphas:
        if time.time() > deadline - 10:
            break
        remaining = deadline - time.time() - 10
        if remaining < 10:
            break
        maxit = int(remaining * 30)
        try:
            res = minimize(_obj, h, jac=_grad, args=(n, alpha),
                         method='L-BFGS-B', bounds=bounds,
                         options={'maxiter': maxit, 'ftol': 1e-18,
                                  'gtol': 1e-16, 'maxfun': maxit * 20})
            h_new = project_feasible(res.x, n)
            c_new = compute_c5(h_new, n)
            if c_new < best_c:
                best_c = c_new
                h = h_new
        except Exception:
            pass
    return h, best_c

def slsqp_opt(h, n, deadline, alpha=500000, maxiter=3000):
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': _eq, 'jac': _eq_jac, 'args': (n,)}]
    try:
        res = minimize(_obj, h, args=(n, alpha), method='SLSQP',
                      bounds=bounds, constraints=cons,
                      options={'maxiter': maxiter, 'ftol': 1e-16})
        h_new = project_feasible(res.x, n)
        return h_new, compute_c5(h_new, n)
    except Exception:
        return h.copy(), compute_c5(h, n)

def coord_descent(h, n, deadline, max_passes=20):
    """Coordinate descent: for each h[i], find optimal value given others fixed."""
    dx = 2.0 / n
    best_c = compute_c5(h, n)
    
    for p in range(max_passes):
        if time.time() > deadline - 5:
            break
        c = compute_c5_vec(h, n)
        improved = False
        for i in range(n):
            # Compute slopes for affected shifts
            # Role 1: h[i] as h[j] (j=i), affects m where 0<=i+m-(n-1)<n
            # Role 2: h[i] as h[j+m-(n-1)] (j=i-m+(n-1)), affects m where 0<=i-m+(n-1)<n
            
            m_range_1 = range(max(0, n-1-i), min(2*n-1, n-1-i+n))
            m_range_2 = range(max(0, i), min(2*n-1, i+n))
            
            # Collect all affected m and their slopes
            slopes_dict = {}
            for m in m_range_1:
                j2 = i + m - (n - 1)
                if 0 <= j2 < n:
                    if m == n - 1:
                        s = (1.0 - 2.0 * h[i]) * dx
                    else:
                        s = (1.0 - h[j2]) * dx
                    slopes_dict[m] = slopes_dict.get(m, 0.0) + s
            for m in m_range_2:
                j1 = i - m + (n - 1)
                if 0 <= j1 < n:
                    if m == n - 1:
                        pass  # already handled
                    else:
                        slopes_dict[m] = slopes_dict.get(m, 0.0) - h[j1] * dx
            
            if not slopes_dict:
                continue
            
            aff_m = np.array(list(slopes_dict.keys()))
            aff_s = np.array([slopes_dict[m] for m in aff_m])
            aff_c = c[aff_m]
            
            # C_not = max of c for non-affected
            mask = np.ones(2*n-1, dtype=bool)
            mask[aff_m] = False
            C_not = c[mask].max() if mask.any() else 0.0
            
            # Find best u = t - h[i] where t in [0,1], u in [-h[i], 1-h[i]]
            u_lo = -h[i]
            u_hi = 1.0 - h[i]
            
            # Candidates
            candidates = [u_lo, u_hi, 0.0]
            
            # Top lines at each endpoint for crossing computation
            idx_0 = np.argsort(-aff_c)[:5]
            idx_hi = np.argsort(-(aff_c + u_hi * aff_s))[:5]
            idx_lo = np.argsort(-(aff_c + u_lo * aff_s))[:5]
            top_idx = np.unique(np.concatenate([idx_0, idx_hi, idx_lo]))
            
            # Crossings between top lines
            for ia in range(len(top_idx)):
                for ib in range(ia + 1, len(top_idx)):
                    a, b = top_idx[ia], top_idx[ib]
                    ds = aff_s[a] - aff_s[b]
                    if abs(ds) < 1e-15:
                        continue
                    u_cr = (aff_c[b] - aff_c[a]) / ds
                    if u_lo <= u_cr <= u_hi:
                        candidates.append(u_cr)
            
            # Crossings with C_not (horizontal line)
            for a in top_idx:
                if abs(aff_s[a]) > 1e-15:
                    u_cr = (C_not - aff_c[a]) / aff_s[a]
                    if u_lo <= u_cr <= u_hi:
                        candidates.append(u_cr)
            
            # Evaluate
            best_val = float('inf')
            best_u = 0.0
            for u in candidates:
                u = np.clip(u, u_lo, u_hi)
                val = max(C_not, np.max(aff_c + u * aff_s))
                if val < best_val:
                    best_val = val
                    best_u = u
            
            new_h_i = h[i] + best_u
            if abs(new_h_i - h[i]) > 1e-14:
                h[i] = new_h_i
                # Quick check (full recompute is expensive, trust the CD)
                improved = True
        
        if improved:
            c_new = compute_c5(h, n)
            if c_new < best_c:
                best_c = c_new
            else:
                best_c = min(best_c, c_new)
        else:
            break
    
    h = project_feasible(h, n)
    best_c = compute_c5(h, n)
    return h, best_c

def fast_pair_polish(h, n, deadline, radius=30):
    """Faster local search: try moving mass from i to j."""
    dx = 2.0 / n
    best_c = compute_c5(h, n)
    deltas = [0.01, 0.005, 0.002, 0.001]
    for d in deltas:
        any_improved = True
        while any_improved and time.time() < deadline:
            any_improved = False
            c = compute_c5_vec(h, n)
            for i in range(0, n, 1):
                if time.time() > deadline:
                    return h, best_c
                lo = max(0, i - radius)
                hi = min(n, i + radius + 1)
                for j in range(lo, hi):
                    if i == j:
                        continue
                    if h[i] + d <= 1.0 and h[j] - d >= 0.0:
                        h[i] += d
                        h[j] -= d
                        c_new = compute_c5(h, n)
                        if c_new < best_c - 1e-15:
                            best_c = c_new
                            any_improved = True
                        else:
                            h[i] -= d
                            h[j] += d
                    if h[i] - d >= 0.0 and h[j] + d <= 1.0:
                        h[i] -= d
                        h[j] += d
                        c_new = compute_c5(h, n)
                        if c_new < best_c - 1e-15:
                            best_c = c_new
                            any_improved = True
                        else:
                            h[i] += d
                            h[j] -= d
    return h, best_c

def golden_ratio_start(n):
    h = np.zeros(n)
    half = n // 2
    phi = (1.0 + np.sqrt(5.0)) / 2.0
    positions = np.floor(np.arange(half) * phi).astype(int) % n
    h[positions] = 1.0
    return project_feasible(h, n)
```

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h, n):
    dx = 2.0 / n
    return float(np.max(np.correlate(h, 1 - h, mode='full')) * dx)

def compute_c5_vec(h, n):
    dx = 2.0 / n
    return np.correlate(h, 1 - h, mode='full') * dx

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h.copy(), 0.0, 1.0)
    for _ in range(300):
        diff = target - h.sum()
        if abs(diff) < 1e-13:
            break
        if diff > 0:
            room = 1.0 - h
            tot = room.sum()
            if tot < 1e-14:
                break
            h += (diff / tot) * room
        else:
            tot = h.sum()
            if tot < 1e-14:
                break
            h += (diff / tot) * h
    return np.clip(h, 0.0, 1.0)

def grad_smooth_max(h, n, alpha):
    c = compute_c5_vec(h, n)
    c_sh = alpha * (c - c.max())
    mx = c_sh.max()
    w = np.exp(c_sh - mx)
    w /= w.sum()
    dx = 2.0 / n
    grad = np.zeros(n)
    for m in range(2 * n - 1):
        if w[m] < 1e-13:
            continue
        k = m - (n - 1)
        wm = w[m] * dx
        if k >= 0:
            nv = n - k
            grad[:nv] += wm * (1.0 - h[k:])
            grad[k:] += wm * (-h[:nv])
        else:
            kk = -k
            nv = n - kk
            grad[kk:] += wm * (1.0 - h[:nv])
            grad[:nv] += wm * (-h[kk:])
    return grad

def _obj(x, n, alpha):
    c = compute_c5_vec(x, n)
    m = c.max()
    sh = alpha * (c - m)
    mx = sh.max()
    return float(m + (mx + np.log(np.sum(np.exp(sh - mx)))) / alpha)

def _grad(x, n, alpha):
    return grad_smooth_max(x, n, alpha)

def _eq(x, n):
    return float(x.sum() - n / 2.0)

def _eq_jac(x, n):
    return np.ones(n)

def lbfgs_opt(h, n, deadline, alphas=(5000, 50000, 500000)):
    best_c = compute_c5(h, n)
    bounds = [(0.0, 1.0)] * n
    for alpha in alphas:
        if time.time() > deadline - 10:
            break
        rem = deadline - time.time() - 10
        if rem < 8:
            break
        maxit = max(50, int(rem * 25))
        try:

                          method='L-BFGS-B', bounds=bounds,
                          options={'maxiter': maxit, 'ftol': 1e-18,
                                   'gtol': 1e-16, 'maxfun': maxit * 20})
            h_new = project_feasible(res.x, n)
            c_new = compute_c5(h_new, n)
            if c_new < best_c:
                best_c = c_new
                h = h_new
        except Exception:
            pass
    return h, best_c

def slsqp_opt(h, n, deadline, alpha=1000000, maxiter=5000):
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': _eq, 'jac': _eq_jac, 'args': (n,)}]
    try:
        res = minimize(_obj, h, args=(n, alpha), method='SLSQP',
                      bounds=bounds, constraints=cons,
                      options={'maxiter': maxiter, 'ftol': 1e-16})
        h_new = project_feasible(res.x, n)
        return h_new, compute_c5(h_new, n)
    except Exception:
        return h.copy(), compute_c5(h, n)

def coord_descent(h, n, deadline, max_passes=25):
    dx = 2.0 / n
    h = project_feasible(h, n)
    best_c = compute_c5(h, n)
    for p in range(max_passes):
        if time.time() > deadline - 3:
            break
        c = compute_c5_vec(h, n)
        improved = False
        for i in range(n):
            slopes_dict = {}
            m1_lo = max(0, n - 1 - i)
            m1_hi = min(2 * n - 2, 2 * (n - 1 - i))
            for m in range(m1_lo, m1_hi + 1):
                j2 = i + m - (n - 1)
                if 0 <= j2 < n:
                    if m == n - 1:
                        s = (1.0 - 2.0 * h[i]) * dx
                    else:
                        s = (1.0 - h[j2]) * dx
                    slopes_dict[m] = slopes_dict.get(m, 0.0) + s
            m2_lo = max(0, i)
            m2_hi = min(2 * n - 2, i + n - 1)
            for m in range(m2_lo, m2_hi + 1):
                if m == n - 1:
                    continue
                j1 = i - m + (n - 1)
                if 0 <= j1 < n:
                    slopes_dict[m] = slopes_dict.get(m, 0.0) - h[j1] * dx
            if not slopes_dict:
                continue
            aff_m = np.array(list(slopes_dict.keys()))
            aff_s = np.array([slopes_dict[m] for m in aff_m])
            aff_c = c[aff_m]
            mask = np.ones(2 * n - 1, dtype=bool)
            mask[aff_m] = False
            C_not = c[mask].max() if mask.any() else 0.0
            u_lo = -h[i]
            u_hi = 1.0 - h[i]
            candidates = [u_lo, u_hi, 0.0]
            idx0 = np.argsort(-aff_c)[:6]
            idxp = np.argsort(-(aff_c + u_hi * aff_s))[:6]
            idxn = np.argsort(-(aff_c + u_lo * aff_s))[:6]
            top = np.unique(np.concatenate([idx0, idxp, idxn]))
            for ia in range(len(top)):
                for ib in range(ia + 1, len(top)):
                    a, b = top[ia], top[ib]
                    ds = aff_s[a] - aff_s[b]
                    if abs(ds) < 1e-15:
                        continue
                    uc = (aff_c[b] - aff_c[a]) / ds
                    if u_lo <= uc <= u_hi:
                        candidates.append(uc)
            for a in top:
                if abs(aff_s[a]) > 1e-15:
                    uc = (C_not - aff_c[a]) / aff_s[a]
                    if u_lo <= uc <= u_hi:
                        candidates.append(uc)
            cands = np.array(candidates)
            vals = np.max(aff_c[None, :] + cands[:, None] * aff_s[None, :], axis=1)
            vals = np.maximum(vals, C_not)
            bi = np.argmin(vals)
            best_u = np.clip(cands[bi], u_lo, u_hi)
            new_val = h[i] + best_u
            if abs(new_val - h[i]) > 1e-14:
                h[i] = new_val
                improved = True
        if improved:
            h = project_feasible(h, n)
            c_new = compute_c5(h, n)
            if c_new < best_c:
                best_c = c_new
        else:
            break
    h = project_feasible(h, n)
    best_c = compute_c5(h, n)
    return h, best_c

def pair_polish(h, n, deadline, radius=25):
    best_c = compute_c5(h, n)
    deltas = [0.01, 0.005, 0.002, 0.001]
    for d in deltas:
        any_imp = True
        while any_imp and time.time() < deadline:
            any_imp = False
            for i in range(0, n, 2):
                if time.time() > deadline:
                    return h, best_c
                lo = max(0, i - radius)
                hi = min(n, i + radius + 1)
                for j in range(lo, hi):
                    if i == j:
                        continue
                    if h[i] + d <= 1.0 and h[j] - d >= 0.0:
                        h[i] += d; h[j] -= d
                        cn = compute_c5(h, n)
                        if cn < best_c - 1e-15:
                            best_c = cn; any_imp = True
                        else:
                            h[i] -= d; h[j] += d
                    if h[i] - d >= 0.0 and h[j] + d <= 1.0:
                        h[i] -= d; h[j] += d
                        cn = compute_c5(h, n)
                        if cn < best_c - 1e-15:
                            best_c = cn; any_imp = True
                        else:
                            h[i] += d; h[j] -= d
    return h, best_c

def golden_start(n):
    h = np.zeros(n)
    half = n // 2
    phi = (1.0 + np.sqrt(5.0)) / 2.0
    pos = np.floor(np.arange(half) * phi).astype(int) % n
    h[pos] = 1.0
    return project_feasible(h, n)
