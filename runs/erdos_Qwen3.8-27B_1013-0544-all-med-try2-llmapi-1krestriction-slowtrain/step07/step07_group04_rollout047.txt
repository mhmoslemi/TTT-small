For a swap (a: 0→1, b: 1→0), the change in correlation at lag k is:
Δc[k] = (1-h[a+k-(n-1)]) - h[a-k+(n-1)] - (1-h[b+k-(n-1)]) + h[b-k+(n-1)]

Better approach: **Precompute per-position contributions.**

For each position a, precompute:
- da[k] = (1-h[a+k-(n-1)]) - h[a-k+(n-1)] for k = 0..2n-2

Then for a swap (a,b): Δc[k] = da[k] - db[k] + interaction(a,b,k)

The interaction term is non-zero only when:
- a+k-(n-1) = b, i.e., k = b-A+(n-1) [if b-a+(n-1) is in range]
- a-k+(n-1) = b, i.e., k = a-b+(n-1) [if a-b+(n-1) is in range]
- b+k-(n-1) = a, i.e., k = a-b+(n-1) [same as above]
- b-k+(n-1) = a, i.e., k = b-a+(n-1) [same as first]

So the interaction only affects at most 2 lags. This means:
Δc[k] = da[k] - db[k] for all k, except possibly at 2 specific k values.

This is great! We can precompute da for all a, then for each pair (a,b), the delta is just da - db with 2 corrections.

But we still need to find max(corr + da - db) efficiently. If corr has max at position k*, and da - db is small, then the new max is likely near k*.

Let me think of an even faster approach:

**Key optimization**: Instead of checking all pairs, for each zero a, find the one b that minimizes max(corr + da - db).

Since da - db is a fixed vector (given a and the current h), we want to find b that minimizes max(corr + da - db).

This is still hard in general. But we can use the following heuristic:
- The max of corr is at some position k*. For the swap to improve, we need corr[k*] + da[k*] - db[k*] < corr[k*], i.e., da[k*] < db[k*].
- So we want to find b with large db[k*].

This gives a fast heuristic: for each zero a, find the one b with the largest db[k*], make that swap, and check if it actually improves.

def fast_binary_v2(h_init, n, deadline, max_sweeps=10000, seed=42):
    target = n // 2
    dx = 2.0 / n
    rng = np.random.RandomState(seed)
    
    # Make binary
    h = np.zeros(n)
    idx = np.argsort(h_init)[::-1]
    h[idx[:target]] = 1.0
    
    corr = np.correlate(h, 1-h, mode='full').astype(float)
    cur_c = corr.max() * dx
    best_c = cur_c
    best_h = h.copy()
    
    m_range = np.arange(-(n-1), n)
    
    for sweep in range(max_sweeps):
        if time.time() > deadline:
            break
        improved = False
        zeros = np.where(h == 0)[0]
        ones = np.where(h == 1)[0]
        if len(zeros) == 0 or len(ones) == 0:
            break
        
        # Find the argmax of correlation
        k_star = np.argmax(corr)
        
        # For each zero a, compute da[k*] = (1-h[a+k*-(n-1)]) - h[a-k*+(n-1)]
        # We want da[k*] to be small (ideally negative)
        # For each one b, compute db[k*] = (1-h[b+k*-(n-1)]) - h[b-k*+(n-1)]
        # We want db[k*] to be large
        
        # da[k*] = (1-h[a+k*-(n-1)]) - h[a-k*+(n-1)]
        # Let's compute this for all zeros at once
        n1 = n - 1
        
        # For zero a: da[k*] = (1-h[a+k*-(n-1)]) - h[a-k*+(n-1)]
        # a+k*-(n-1) is valid if 0 <= a+k*-(n-1) < n
        # a-k*+(n-1) is valid if 0 <= a-k*+(n-1) < n
        
        # Compute for all zeros vectorized
        a_vals = zeros
        idx1 = a_vals + k_star - n1  # a+k*-(n-1)
        idx2 = a_vals - k_star + n1  # a-k*+(n-1)
        
        da_k = np.zeros(len(a_vals))
        valid1 = (idx1 >= 0) & (idx1 < n)
        valid2 = (idx2 >= 0) & (idx2 < n)
        da_k[valid1] += 1 - h[idx1[valid1]]
        da_k[valid2] -= h[idx2[valid2]]
        
        # Find the zero with the smallest da_k (most improvement potential)
        a_best_idx = np.argmin(da_k)
        a_best = zeros[a_best_idx]

        # Try all ones and pick the best
        b_vals = ones
        # Compute db for all b at k_star
        bidx1 = b_vals + k_star - n1
        bidx2 = b_vals - k_star + n1
        db_k = np.zeros(len(b_vals))
        v1 = (bidx1 >= 0) & (bidx1 < n)
        v2 = (bidx2 >= 0) & (bidx2 < n)
        db_k[v1] += 1 - h[bidx1[v1]]
        db_k[v2] -= h[bidx2[v2]]
        
        # We want to maximize db_k (to make da_k - db_k most negative at k*)
        b_best_idx = np.argmax(db_k)
        b_best = ones[b_best_idx]
        
        # Try the swap
        h[a_best] = 1.0
        h[b_best] = 0.0
        new_corr = np.correlate(h, 1-h, mode='full')
        new_c = new_corr.max() * dx
        h[a_best] = 0.0
        h[b_best] = 1.0
        
        if new_c < cur_c - 1e-12:
            h[a_best] = 1.0
            h[b_best] = 0.0
            corr = new_corr.astype(float)
            cur_c = new_c
            improved = True
            if cur_c < best_c:
                best_c = cur_c
                best_h = h.copy()

        top_b_by_db = ones[np.argsort(db_k)[::-1][:3]]

        for a in top_a:
            for b in top_b_by_db:
                key = (a, b)
                if key in tried or (a == a_best and b == b_best):
                    continue
                tried.add(key)
                h[a] = 1.0
                h[b] = 0.0
                new_corr = np.correlate(h, 1-h, mode='full')
                new_c = new_corr.max() * dx
                h[a] = 0.0
                h[b] = 1.0

                    if cur_c < best_c:
                        best_c = cur_c

                break

            for _ in range(20):
