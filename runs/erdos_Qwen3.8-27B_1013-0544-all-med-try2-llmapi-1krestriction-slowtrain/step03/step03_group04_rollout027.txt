h[i+k](1-h[i]) ≈ g[i+k](1-g[i]) + (1-g[i])(h[i+k]-g[i+k]) - g[i+k](h[i]-g[i])

This gives a linear approximation, and we can solve the resulting LP. Then update g and repeat (successive linearization).

This is essentially the SUMT or cutting-plane approach.

But this might be overkill. Let me focus on the binary SA approach, which is simpler and likely effective.

Now let me think about the SA implementation in more detail.

For n=280, the computation per iteration:
- Pick random i from ones, j from zeros: O(1) if we maintain the lists
- Swap: O(1)
- Compute c5: O(n^2) via np.correlate ≈ 78000 ops ≈ 100μs

In 300 seconds: 300 / 0.0001 = 3 million iterations. That should be enough.

But wait, I can optimize by not recomputing the full correlation every time. I can compute the delta.

When we swap h[i] from 1 to 0 and h[j] from 0 to 1:
The change in the full correlation c (length 2n-1) is:
For the correlation c_full[k] = sum_m h[m + k - (n-1)] * (1-h[m]) (with appropriate bounds):

Actually, let me just use the numpy indexing. The full correlation has 2n-1 elements indexed from 0 to 2n-2. Element k corresponds to lag = k - (n-1).

c_full[k] = sum_{m: valid} h[m + lag] * (1 - h[m]) where lag = k - (n-1)
Valid m: 0 ≤ m ≤ n-1 and 0 ≤ m + lag ≤ n-1

After swapping i (1→0) and j (0→1):
- Terms where m = i: was h[lag+i]*(1-1) = 0, now h[lag+i]*(1-0) = h[lag+i]
  This affects c_full[k] where k = (n-1) + lag, i.e., the element at position (n-1) + (i + lag - i)... 
  
Hmm, this is getting confusing. Let me just use the direct formula.

c_full[k] = sum_m h[m + k - (n-1)] * (1 - h[m]) for valid m

Let lag = k - (n-1). Then c_full[k] = sum_m h[m+lag] * (1-h[m]) for valid m.

After swap (h[i]: 1→0, h[j]: 0→1):
Δc_full[k] = [contribution from m=i] + [contribution from m=j] + [contribution from m+lag=i] + [contribution from m+lag=j]

Wait, I need to be more careful. The terms that change are those involving h[i] or h[j].

Terms involving h[i] (as the "first" factor h[m+lag]):
m+lag = i, so m = i-lag.
Old: h[i] * (1-h[i-lag]) = 1 * (1-h[i-lag]) = 1-h[i-lag]
New: 0 * (1-h[i-lag]) = 0
Change: -(1-h[i-lag])

Terms involving h[j] (as the "first" factor h[m+lag]):
m+lag = j, so m = j-lag.
Old: h[j] * (1-h[j-lag]) = 0 * ... = 0
New: 1 * (1-h[j-lag]) = 1-h[j-lag]
Change: +(1-h[j-lag])

Terms involving h[i] (as the "second" factor (1-h[m])):
m = i.
Old: h[i+lag] * (1-h[i]) = h[i+lag] * 0 = 0
New: h[i+lag] * (1-0) = h[i+lag]
Change: +h[i+lag]

Terms involving h[j] (as the "second" factor (1-h[m])):
m = j.
Old: h[j+lag] * (1-h[j]) = h[j+lag] * 1 = h[j+lag]
New: h[j+lag] * (1-1) = 0
Change: -h[j+lag]

So: Δc_full[k] = -(1-h[i-lag]) + (1-h[j-lag]) + h[i+lag] - h[j+lag]
= -1 + h[i-lag] + 1 - h[j-lag] + h[i+lag] - h[j+lag]
= h[i-lag] - h[j-lag] + h[i+lag] - h[j+lag]

Where h[x] = 0 if x < 0 or x ≥ n (out of bounds).

So: Δc[k] = h[i-lag] + h[i+lag] - h[j-lag] - h[j+lag] where lag = k-(n-1)

Or equivalently, in terms of positions:
Δc[k] = h[i-(k-(n-1))] + h[i+(k-(n-1))] - h[j-(k-(n-1))] - h[j+(k-(n-1))]

This is valid for all k = 0, ..., 2n-2.

So the delta is a function that's non-zero at most at 4 positions per "pair" (i±lag, j±lag). But since lag varies with k, the delta is non-zero at many k values.

Specifically, Δc[k] ≠ 0 when:
- i - (k-(n-1)) is in [0,n-1] and h[i-(k-(n-1))] ≠ 0
- i + (k-(n-1)) is in [0,n-1] and h[i+(k-(n-1))] ≠ 0
- j - (k-(n-1)) is in [0,n-1] and h[j-(k-(n-1))] ≠ 0
- j + (k-(n-1)) is in [0,n-1] and h[j+(k-(n-1))] ≠ 0

For a given i and the full h array, h[i ± lag] = 1 for specific lag values (those where i±lag is a 1-position). Since there are 140 ones, there are at most 280±140 = 420 lag values where h[i±lag] ≠ 0. Similarly for j.

So Δc[k] is non-zero at at most ~560 k values out of 559 total. That means we'd need to update almost all of them.

In that case, it's simpler to just recompute the full correlation from scratch (O(n^2) = 78400 ops) rather than compute the delta.

```python
import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)

def project_h(h, target_sum):
    h = np.clip(h, 0.0, 1.0).copy()
    for _ in range(80):
        diff = target_sum - h.sum()
        if abs(diff) < 1e-13:
            break
        free = (h > 1e-9) & (h < 1.0 - 1e-9)
        if free.sum() == 0:
            free = np.ones(len(h), dtype=bool)
        h[free] += diff / free.sum()
        h = np.clip(h, 0.0, 1.0)
    return h

def make_binary(h, n, target):
    hb = (h >= 0.5).astype(float)
    s = hb.sum()
    if s > target:
        ones = np.where(hb == 1)[0]
        order = ones[np.argsort(h[ones])[::-1]]
        for idx in order[:int(s - target)]:
            hb[idx] = 0.0
    elif s < target:
        zeros = np.where(hb == 0)[0]
        order = zeros[np.argsort(h[zeros])]
        for idx in order[:int(target - s)]:
            hb[idx] = 1.0
    return hb

def sturmian_seq(n, alpha):
    h = np.zeros(n)
    for i in range(n):
        h[i] = 1.0 if (i * alpha) % 1.0 < 0.5 else 0.0
    return h

def greedy_construct(n, target):
    h = np.zeros(n)
    dx = 2.0 / n
    for count in range(target):
        best_pos = -1
        best_val = 1e10
        for p in range(n):
            if h[p] == 1:
                continue
            h[p] = 1
            corr = np.correlate(h, 1.0 - h, mode="full")
            mx = np.max(corr)
            h[p] = 0
            if mx < best_val:
                best_val = mx
                best_pos = p
        if best_pos >= 0:
            h[best_pos] = 1.0
        else:
            h[np.random.randint(n)] = 1.0
    return h

def simulated_annealing(h_init, n, dx, time_limit, seed=0):
    rng = np.random.RandomState(seed)
    t0 = time.time()
    h = h_init.copy()
    target = n // 2
    c = np.correlate(h, 1.0 - h, mode="full")
    curr_max = float(np.max(c))
    best_h = h.copy()
    best_max = curr_max
    T = 0.05
    cool = 0.999997
    no_improve = 0
    patience = 500000
    for it in range(100000000):
        if time.time() - t0 > time_limit:
            break
        ones = np.where(h == 1)[0]
        zeros = np.where(h == 0)[0]
        i = ones[rng.randint(len(ones))]
        j = zeros[rng.randint(len(zeros))]
        h[i] = 0.0
        h[j] = 1.0
        c_new = np.correlate(h, 1.0 - h, mode="full")
        new_max = float(np.max(c_new))
        delta = new_max - curr_max
        if delta <= 0 or rng.random() < np.exp(-delta / max(T, 1e-10)):
            curr_max = new_max
            c = c_new
            if new_max < best_max:
                best_max = new_max
                best_h = h.copy()
                no_improve = 0
            else:
                no_improve += 1
            T *= cool
        else:
            h[i] = 1.0
            h[j] = 0.0
            no_improve += 1
        if no_improve > patience:
            h = best_h.copy()
            curr_max = best_max
            T = max(T * 10.0, 0.02)
            no_improve = 0
    return best_h, best_max * dx

def greedy_refine(h, n, dx, elapsed, remaining_budget):
    t0 = time.time()
    target = n // 2
    h = h.copy()
    c = np.correlate(h, 1.0 - h, mode="full")
    curr_max = float(np.max(c))
    best_h = h.copy()
    best_max = curr_max
    improved = True
    while improved and time.time() - t0 + elapsed < remaining_budget - 5:
        improved = False
        ones = np.where(h == 1)[0]
        zeros = np.where(h == 0)[0]
        best_delta = 1e10
        best_pair = None
        for i in range(len(ones)):
            for j in range(len(zeros)):
                a, b = ones[i], zeros[j]
                h[a] = 0.0
                h[b] = 1.0
                c_new = np.correlate(h, 1.0 - h, mode="full")
                mx = float(np.max(c_new))
                h[a] = 1.0
                h[b] = 0.0
                d = mx - curr_max
                if d < best_delta:
                    best_delta = d
                    best_pair = (a, b, mx)
                if time.time() - t0 + elapsed > remaining_budget - 5:
                    break
            if time.time() - t0 + elapsed > remaining_budget - 5:
                break
        if best_pair is not None and best_delta < -1e-12:
            a, b, mx = best_pair
            h[a] = 0.0
            h[b] = 1.0
            curr_max = mx
            improved = True
            if curr_max < best_max:
                best_max = curr_max
                best_h = h.copy()
    return best_h, best_max * dx

def smooth_max(x, beta):
    m = np.max(x)
    x_shift = np.clip(beta * (x - m), -500, 500)
    return m + np.log(np.sum(np.exp(x_shift)) / len(x)) / beta

def continuous_refine(h, n, dx, budget):
    t0 = time.time()
    target = n / 2.0
    h_cur = h.astype(float).copy()
    cur_c5 = compute_c5(h_cur)
    best_h = h_cur.copy()
    best_c5 = cur_c5
    bounds = [(0.0, 1.0)] * n
    for beta in [100, 300, 1000, 3000, 10000]:
        if time.time() - t0 > budget - 5:
            break
        def obj(x):
            corr = np.correlate(x, 1.0 - x, mode="full")
            return smooth_max(corr, beta) * dx + 1e-4 * (np.sum(x) - target)**2
        try:
            res = minimize(obj, h_cur, method='L-BFGS-B', bounds=bounds,
                           options={'maxiter': 2000, 'gtol': 1e-8})
            h_new = project_h(res.x, target)
            c5_new = compute_c5(h_new)
            if c5_new < cur_c5:
                h_cur = h_new
                cur_c5 = c5_new
                if c5_new < best_c5:
                    best_c5 = c5_new
                    best_h = h_new.copy()
        except Exception:
            pass
    return best_h, best_c5

def run(seed=42, budget_s=1100, **kwargs):
    np.random.seed(seed)
    t0 = time.time()

    if 'initial_h_values' in globals() and initial_h_values is not None:
        h_parent = np.array(initial_h_values, dtype=float).copy()
        n_base = len(h_parent)
    else:
        n_base = 280
        h_parent = np.full(n_base, 0.5)

    n = n_base
    dx = 2.0 / n
    target = n // 2

    candidates = []
    hb = make_binary(h_parent, n, target)
    candidates.append(hb)
    alphas = [0.6180339, 0.3819661, 0.4142136, 0.5566, 0.44544, 0.3568]
    for a in alphas:
        hs = sturmian_seq(n, a)
        hs = make_binary(hs, n, target)
        candidates.append(hs)
    hr = np.zeros(n)
    hr[np.random.choice(n, target, replace=False)] = 1.0
    candidates.append(hr)
    hr2 = np.zeros(n)
    hr2[np.random.choice(n, target, replace=False)] = 1.0
    candidates.append(hr2)

    scored = []
    for h_c in candidates:
        c5_v = compute_c5(h_c)
        scored.append((c5_v, h_c))
    scored.sort(key=lambda x: x[0])

    best_h = scored[0][1].copy()
    best_c5 = scored[0][0]

    sa_budget = budget_s * 0.55
    per_sa = sa_budget / min(6, len(scored))
    for idx in range(min(6, len(scored))):
        elapsed = time.time() - t0
        if elapsed > budget_s - 120:
            break
        budget_left = min(per_sa, budget_s - 120 - elapsed)
        if budget_left < 5:
            break
        h_sa, c5_sa = simulated_annealing(scored[idx][1], n, dx, budget_left, seed=seed + idx * 100)
        if c5_sa < best_c5:
            best_c5 = c5_sa
            best_h = h_sa.copy()

    elapsed = time.time() - t0
    if budget_s - elapsed > 30:
        h_gr, c5_gr = greedy_refine(best_h, n, dx, elapsed, budget_s)
        if c5_gr < best_c5:
            best_c5 = c5_gr
            best_h = h_gr.copy()

    elapsed = time.time() - t0
    if budget_s - elapsed > 20:
        h_cont, c5_cont = continuous_refine(best_h, n, dx, min(budget_s - elapsed - 5, 80))
        if c5_cont < best_c5:
            best_c5 = c5_cont
            best_h = h_cont.copy()

    best_h = project_h(best_h, float(target))
    best_c5 = compute_c5(best_h)
    return best_h, best_c5, n
```
