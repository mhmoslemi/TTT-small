inf[p, m] represents the change in corr[m] when h[p] goes from 0 to 1. This change depends on the current values of h at other positions.

Specifically:
inf[p, m] = (1 - h[p+q]) * 1_{0≤p+q≤n-1} - h[p-q'] * 1_{0≤p-q'≤n-1}

where q = m-(n-1) and q' = m-(n-1).

So inf[p, m] depends on h at positions p+q and p-q'. When we change h[i], it affects inf[p, m] for any p, m where p+q = i or p-q' = i.

That means after each swap, potentially ALL influence vectors need updating. That's O(n²) per step, which defeats the purpose.

**Alternative approach: Don't precompute inf. Instead, compute the delta on the fly but vectorize over j.**

For a fixed i (zero to flip to 1):
- The change in corr when h[i] goes 0→1 is a vector delta_i of length 2n-1
- For each j (one to flip to 0), the total change is delta_i - delta_j

So I need to compute delta_i for each i, then for each i, find the j that minimizes max(corr + delta_i - delta_j).

Computing delta_i:
delta_i[m] = (1-h[i+q]) * 1_{0≤i+q≤n-1} - h[i-q] * 1_{0≤i-q≤n-1}

where q = m-(n-1).

This is O(n) per i, so O(n²) total for all i. Then for the inner loop over j, I need O(n) per (i,j) pair, giving O(n³) total. That's too slow.

Let me also think about the SLSQP part. The smooth approximation of max using log-sum-exp is:
$\text{smooth\_max}(x, \alpha) = \frac{1}{\alpha} \log \sum_k e^{\alpha x_k}$

This converges to max(x) as α→∞. For the optimization, we want α large enough that the smooth max is close to the true max, but not so large that the problem becomes ill-conditioned.

The objective for SLSQP is: minimize smooth_max(corr(h), α) subject to sum(h) = n/2, 0 ≤ h ≤ 1.

The gradient of smooth_max with respect to h can be computed analytically:
$\frac{\partial \text{smooth\_max}}{\partial h_p} = \sum_k \frac{e^{\alpha c_k}}{\sum_j e^{\alpha c_j}} \cdot \frac{\partial c_k}{\partial h_p}$

where $c_k$ is the k-th component of the correlation.

This is expensive to compute (requires the influence vectors and a weighted sum). For n=250, it might be feasible but slow.

Actually, for the SLSQP part, I'll just use numerical gradients (which is what SLSQP does by default with finite differences). The main cost is the function evaluation, which is O(n²) for the correlation.

        return x.sum() - n / 2.0
    
    cons = [{'type': 'eq', 'fun': cons_fun}]
    
    try:
        res = minimize(obj, h, method='SLSQP', bounds=bounds,
                       constraints=cons, options={'maxiter': maxiter, 'ftol': 1e-14})
        return project_feasible(res.x, n)
    except Exception:
        return h
