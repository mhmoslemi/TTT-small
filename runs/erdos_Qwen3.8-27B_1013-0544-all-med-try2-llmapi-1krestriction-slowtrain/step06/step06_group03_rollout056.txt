Wait, is it convex? The max of linear functions is convex. And each f_k as a function of h[i] is linear (since in f_k = sum_j h[j](1-h[j+k]), h[i] appears either as h[i]*(1-h[i+k]) which is linear in h[i] when h[i+k] is fixed, or as h[i-k]*(1-h[i]) which is also linear in h[i]).

So yes! C₅ as a function of a single coordinate h[i] (with all others fixed) is a convex piecewise linear function. We can find its minimum exactly!

The minimum is at a point where the subgradient contains 0, which is where the maximum of the increasing slopes equals the most negative of the decreasing slopes.

This gives us a very powerful coordinate descent method:
1. For each coordinate i in order:
   a. Compute C₅ as a function of h[i] (piecewise linear)
   b. Find the value of h[i] that minimizes it (within [0,1] and respecting the sum constraint)
   c. Update h[i]

The sum constraint complicates things a bit. If we change h[i], we need to adjust another coordinate to maintain the sum. This makes it a 2-coordinate problem.

Alternative: use a "free" parameterization where we only optimize n-1 coordinates and the last one is determined by the constraint. But this might not be the best coordinate to fix.

Better alternative: use a penalty for the constraint in the coordinate optimization, then project at the end of each full sweep.

Or: use the "cycling" approach where we update pairs (i, j) simultaneously to maintain the sum constraint. For each pair (i,j), we optimize the 2D subproblem: minimize C₅(h[i]+d, h[j]-d) over d such that both stay in [0,1].

Since C₅ as a function of d (for fixed pair i,j) is the max of linear functions of d, it's convex. We can find the minimum by binary search on the subgradient.

This is a **pairwise coordinate descent** with exact line search! It should converge well.

```python
    """Find optimal d for pair (i,j): h[i]+=d, h[j]-=d"""
    c_base = np.correlate(h, 1-h, mode='full') * (2.0/n)
    
    # Compute slope for each lag
    # slope[k] = (A[k] - B[k]) where A is from position i, B from position j
    # h[i] appears in corr at lag k as:
    #   as h[m] where m=i: lag k, contributes (1-h[i+k]) if i+k < n
    #   as h[m+k] where m=i-k: lag k, contributes -h[i-k] if i-k >= 0
    # h[j] appears similarly
    
    n_full = 2*n - 1
    slope = np.zeros(n_full)
    
    for k in range(n_full):
        lag = k - (n-1)
        # Contribution from h[i]:
        # h[i] as h[m] at position i: affects corr[lag] if i+lag is valid
        # In the correlate output, index k corresponds to lag k-(n-1)
        # h[i](1-h[i+lag]) is a term in corr[lag] if 0<=i<n and 0<=i+lag<n
        # h[i-lag](1-h[i]) is a term in corr[lag] if 0<=i-lag<n and 0<=i<n
        
        # Wait, I need to be more careful about the indexing.
        # np.correlate(h, 1-h, mode='full')[k] = sum_m h[m] * (1-h[m-(k-(n-1))])

        # = sum_m h[m] * (1-h[m-lag]) for valid m
        
        # h[i] appears as h[m] when m=i:
        #   term: h[i] * (1-h[i-lag]), valid if 0<=i-lag<n
        # h[i] appears as h[m-lag] when m-lag=i, i.e., m=i+lag:
        #   term: h[i+lag] * (1-h[i]), valid if 0<=i+lag<n
        
        # So the change in corr[lag] when h[i] increases by d:
        # (1-h[i-lag])*I(0<=i-lag<n) - h[i+lag]*I(0<=i+lag<n)
        
        a_i = 0.0
        if 0 <= i - lag < n:
            a_i += (1 - h[i - lag])
        if 0 <= i + lag < n:
            a_i -= h[i + lag]

            a_j += (1 - h[j - lag])
        if 0 <= j + lag < n:
            a_j -= h[j + lag]

    # Find d that minimizes this, subject to bounds

            fd = c5_at_d(d_)
        if abs(b - a) < 1e-12:
            break
    
    d_opt = (a + b) / 2
    return d_opt
```

```python
def compute_slope_vec(h, i, j, n):
    """Compute the slope vector for pair (i,j): change in corr when h[i]+=1, h[j]-=1"""
    n_full = 2 * n - 1
    lag = np.arange(n_full) - (n - 1)
    
    # h[i] as h[m] at position i: affects lag k where m=i, so the other index is i-lag
    term1 = np.zeros(n_full)
    valid1 = (i - lag >= 0) & (i - lag < n)
    term1[valid1] = 1 - h[i - lag[valid1]]
    
    # h[i] as h[m+lag] where m+lag=i, so m=i-lag... wait
    # In np.correlate(h, 1-h, mode='full')[k] = sum_m h[m] * (1-h[m - (k-(n-1))])
    # = sum_m h[m] * (1-h[m - lag]) where lag = k-(n-1)
    
    # h[i] appears as h[m] when m=i:
    #   contributes to: (1-h[i-lag]) for the term where m=i
    #   valid if 0 <= i-lag < n
    # h[i] appears in (1-h[m-lag]) when m-lag=i, i.e., m=i+lag:
    #   the term is h[i+lag] * (1-h[i])
    #   change in this term when h[i] changes by d: h[i+lag] * (-d)
    #   valid if 0 <= i+lag < n
    
    # So total change in corr[lag] from h[i] += d:
    # d * (1-h[i-lag]) * I(0<=i-lag<n)  [from the h[m] factor]
    # - d * h[i+lag] * I(0<=i+lag<n)  [from the (1-h[m-lag]) factor]
    
    # Similarly for h[j] -= d (i.e., h[j] changes by -d):
    # -d * (1-h[j-lag]) * I(0<=j-lag<n)
    # + d * h[j+lag] * I(0<=j+lag<n)
    
    slope = np.zeros(n_full)
    
    # From h[i] += 1:
    v1 = (i - lag >= 0) & (i - lag < n)
    slope[v1] += (1 - h[i - lag[v1]])
    v2 = (i + lag >= 0) & (i + lag < n)
    slope[v2] -= h[i + lag[v2]]
    
    # From h[j] -= 1 (so change is -1):
    v3 = (j - lag >= 0) & (j - lag < n)
    slope[v3] -= (1 - h[j - lag[v3]])
    v4 = (j + lag >= 0) & (j + lag < n)
    slope[v4] += h[j + lag[v4]]
    
    return slope
```

```python
        # Let lag = k - (n-1)
        # c[k] = dx * sum_m h[m] * (1-h[m-lag])
        
        # dc[k]/dh[i] = dx * [(1-h[i-lag])*I(0≤i-lag<n) - h[i+lag]*I(0≤i+lag<n)]
        # (from the two ways h[i] can appear)
        
        # Sum over k: sum_k w_k * dc[k]/dh[i]
        # = dx * sum_k w_k * (1-h[i-(k-(n-1))])*I(valid) - dx * sum_k w_k * h[i+(k-(n-1))]*I(valid)
        # = dx * [convolution-like term 1] - dx * [convolution-like term 2]
        
        # Let W[k] = w_k for k=0,...,2n-2 (the weights)
        # Term 1: sum_k W[k] * (1-h[i-(k-(n-1))]) where 0≤i-(k-(n-1))<n
        #   = sum_k W[k] * (1-h[i-k+n-1]) where 0≤i-k+n-1<n
        #   Let j = i-k+n-1, so k = i+n-1-j
        #   = sum_j (1-h[j]) * W[i+n-1-j] where 0≤j<n and 0≤i+n-1-j<2n-1
        #   This is the cross-correlation of (1-h) with W, evaluated at position i+n-1
        
        # This is getting complex. Let me just compute it directly for n=250.
        
        # For each i, grad[i] = dx * sum_k w_k * [(1-h[i-k+n-1])*I(0≤i-k+n-1<n) - h[i+k-n+1]*I(0≤i+k-n+1<n)]
        
        # This is O(n²) total. For n=250, that's 62500 ops. Fine.
        
        grad = np.zeros(n)
        lag = np.arange(2*n-1) - (n-1)  # lags from -(n-1) to n-1
        for i in range(n):
            # (1-h[i-lag]) * I(0≤i-lag<n)
            idx1 = i - lag
            mask1 = (idx1 >= 0) & (idx1 < n)
            term1 = np.sum(weights[mask1] * (1 - h[idx1[mask1]]))
            
            # h[i+lag] * I(0≤i+lag<n)
            idx2 = i + lag
            mask2 = (idx2 >= 0) & (idx2 < n)
            term2 = np.sum(weights[mask2] * h[idx2[mask2]])
            
            grad[i] = dx * (term1 - term2)
        
        # Projected gradient step
        h_new = h - lr * grad
        h_new = project_feasible(h_new, n)
        c_new = compute_c5(h_new, n)
        
        if c_new < best_c:
            best_c = c_new
            h = h_new
            # Increase learning rate slightly
            lr = min(lr * 1.1, 0.1)
        else:
            lr *= 0.5
            if lr < 1e-8:
                break
    
    return h, best_c
```

Wait, the gradient computation is O(n²) per iteration (the loop over i with O(n) work each). For n=250, that's 62500 ops per iteration. With, say, 1000 iterations, that's 62.5M ops. In Python, the loop over i (250 iterations) with NumPy vectorized operations inside should take about 250 * 50μs = 12.5ms per gradient evaluation. With 1000 iterations, that's about 13 seconds. But I can vectorize the gradient computation! Let me think...

grad[i] = dx * (sum_k w_k * (1-h[i-lag_k])*I(valid) - sum_k w_k * h[i+lag_k]*I(valid))

The first term is: for each i, sum over k where 0≤i-lag_k<n of w_k*(1-h[i-lag_k]).

Let me define: for a fixed offset l = lag_k, the term (1-h[i-l]) appears in grad[i] with weight w_{(n-1)+l}.

So: term1[i] = sum_l w_{(n-1)+l} * (1-h[i-l]) * I(0≤i-l<n)

This is a convolution of (1-h) with the weight sequence W (where W[l+(n-1)] = w_l for valid l).

Specifically, if I define W_full as a vector of length 2n-1 where W_full[k] = weights[k], then:
term1[i] = sum_k W_full[k] * (1-h[i-(k-(n-1))]) * I(0≤i-(k-(n-1))<n)

Let j = i-(k-(n-1)), so k = i-(j-(n-1)) = i-j+n-1.
term1[i] = sum_j (1-h[j]) * W_full[i-j+n-1] * I(0≤j<n and 0≤i-j+n-1<2n-1)

This is the cross-correlation of (1-h) with W_full, evaluated at position i+n-1.

In NumPy: np.correlate(1-h, W_full, mode='full')[n-1 + i] for i=0,...,n-1

Wait, let me double-check. np.correlate(a, v, mode='full')[k] = sum_n a[n+k] * v[n] (with appropriate indexing).

Actually, numpy defines:
np.correlate(a, v)[k] = sum_n a[n] * v[n-k] (for 'full' mode, with zero-padding)

```python
import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h, n):
    dx = 2.0 / n
    return float(np.max(np.correlate(h, 1 - h, mode='full')) * dx)

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h.copy(), 0.0, 1.0)
    for _ in range(200):
        diff = target - h.sum()
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            room = 1.0 - h
            tot = room.sum()
            if tot < 1e-15:
                break
            h += (diff / tot) * room
        else:
            tot = h.sum()
            if tot < 1e-15:
                break
            h += (diff / tot) * h
    return np.clip(h, 0.0, 1.0)

def smooth_max_obj(x, n, alpha):
    dx = 2.0 / n
    c = np.correlate(x, 1 - x, mode='full') * dx
    m = c.max()
    if alpha < 1e6:
        sh = alpha * (c - m)
        mx = sh.max()
        if mx > 500:
            return m + (mx + np.log(np.sum(np.exp(sh - mx)))) / alpha
        return m + np.log(np.sum(np.exp(sh))) / alpha
    else:
        return m + (c - m).max() / alpha  # approximate

def smooth_max_grad(x, n, alpha):
    dx = 2.0 / n
    c = np.correlate(x, 1 - x, mode='full') * dx
    m = c.max()
    sh = alpha * (c - m)
    mx = sh.max()
    if mx > 500:
        weights = np.exp(sh - mx)
        weights /= weights.sum()
    else:
        weights = np.exp(sh)
        weights /= weights.sum()
    
    # Gradient of smooth max = weighted sum of gradients of individual c[k]
    # c[k] = dx * sum_m x[m] * (1-x[m-lag_k]) where lag_k = k-(n-1)
    # dc[k]/dx[i] = dx * [(1-x[i-lag_k])*I(0≤i-lag_k<n) - x[i+lag_k]*I(0≤i+lag_k<n)]
    
    lag = np.arange(2*n-1) - (n-1)
    grad = np.zeros(n)
    ones_minus_x = 1 - x
    
    # Vectorized: for each i, grad[i] = dx * (sum_k w[k]*(1-x[i-lag[k]])*I - sum_k w[k]*x[i+lag[k]]*I)
    # Use broadcasting
    # idx1[i,k] = i - lag[k], valid if 0≤idx1<n
    # This creates an (n, 2n-1) matrix which is 250*499 ≈ 125K entries. Fine.
    
    idx1 = np.arange(n)[:, None] - lag[None, :]  # (n, 2n-1)
    mask1 = (idx1 >= 0) & (idx1 < n)
    
    idx2 = np.arange(n)[:, None] + lag[None, :]  # (n, 2n-1)
    mask2 = (idx2 >= 0) & (idx2 < n)
    
    # term1[i] = sum_k w[k] * (1-x[i-lag[k]]) * mask1[i,k]
    term1 = np.sum(weights[None, :] * ones_minus_x[idx1] * mask1, axis=1)
    term2 = np.sum(weights[None, :] * x[idx2] * mask2, axis=1)
    
    grad = dx * (term1 - term2)
    return grad
```

Wait, the indexing `ones_minus_x[idx1]` where idx1 is an (n, 2n-1) matrix with values 0 to n-1 (where valid) and out-of-range (where invalid) - this will give wrong values for the invalid entries, but since we multiply by mask1, those entries will be zeroed out. However, numpy will give an index error if idx1 has values outside [0, n-1].

```python
idx1_clipped = np.clip(idx1, 0, n-1)
```

from scipy.optimize import minimize
import time

def compute_c5(h, n):
    dx = 2.0 / n
    return float(np.max(np.correlate(h, 1 - h, mode='full')) * dx)

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h.copy(), 0.0, 1.0)
    for _ in range(300):
        diff = target - h.sum()
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            room = 1.0 - h
            tot = room.sum()
            if tot < 1e-15:
                break
            h += (diff / tot) * room
        else:
            tot = h.sum()
            if tot < 1e-15:
                break
            h += (diff / tot) * h
    return np.clip(h, 0.0, 1.0)

def obj_smooth(x, n, alpha):
    dx = 2.0 / n
    c = np.correlate(x, 1 - x, mode='full') * dx
    m = c.max()
    sh = alpha * (c - m)
    mx = sh.max()
    if mx > 500:
        return float(m + (mx + np.log(np.sum(np.exp(sh - mx)))) / alpha)
    return float(m + np.log(np.sum(np.exp(sh))) / alpha)

def _sum_c(x, n):
    return float(x.sum() - n / 2.0)

def _sum_j(x, n):
    return np.ones(n)

def slsqp_optimize(h, n, alpha, maxiter=1000):
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': _sum_c, 'jac': _sum_j, 'args': (n,)}]
    try:
        res = minimize(obj_smooth, h, args=(n, alpha), method='SLSQP',
                       bounds=bounds, constraints=cons,
                       options={'maxiter': maxiter, 'ftol': 1e-16})
        return project_feasible(res.x, n)
    except Exception:
        return h.copy()

def proj_grad_optimize(h, n, deadline, alpha=5000):
    h = project_feasible(h.copy(), n)
    best_c = compute_c5(h, n)
    lr = 0.005
    dx = 2.0 / n
    lag = np.arange(2 * n - 1) - (n - 1)
    
    idx1 = np.arange(n)[:, None] - lag[None, :]
    mask1 = (idx1 >= 0) & (idx1 < n)
    idx1_clipped = np.clip(idx1, 0, n - 1)
    
    idx2 = np.arange(n)[:, None] + lag[None, :]
    mask2 = (idx2 >= 0) & (idx2 < n)
    idx2_clipped = np.clip(idx2, 0, n - 1)
    
    stall_count = 0
    while time.time() < deadline:
        c = np.correlate(h, 1 - h, mode='full') * dx
        m = c.max()
        sh = alpha * (c - m)
        mx = sh.max()
        if mx > 500:
            weights = np.exp(sh - mx)
        else:
            weights = np.exp(sh)
        weights /= weights.sum()
        
        ones_minus_x = 1 - h
        term1 = np.sum(weights[None, :] * ones_minus_x[idx1_clipped] * mask1, axis=1)
        term2 = np.sum(weights[None, :] * h[idx2_clipped] * mask2, axis=1)
        grad = dx * (term1 - term2)
        
        h_new = h - lr * grad
        h_new = project_feasible(h_new, n)
        c_new = compute_c5(h_new, n)
        
        if c_new < best_c - 1e-15:
            best_c = c_new
            h = h_new
            lr = min(lr * 1.05, 0.02)
            stall_count = 0
        else:
            lr *= 0.7
            stall_count += 1
            if stall_count > 50 or lr < 1e-10:

    return h, best_c

def compute_slope(h, i, j, n):
    """Compute slope vector for pair (i,j): change in corr[k]*dx when h[i]+=1, h[j]-=1"""
    lag = np.arange(2 * n - 1) - (n - 1)
    n_full = 2 * n - 1
    slope = np.zeros(n_full)
    
    v1 = (i - lag >= 0) & (i - lag < n)
    slope[v1] += (1 - h[i - lag[v1]])
    v2 = (i + lag >= 0) & (i + lag < n)
    slope[v2] -= h[i + lag[v2]]
    v3 = (j - lag >= 0) & (j - lag < n)
    slope[v3] -= (1 - h[j - lag[v3]])
    v4 = (j + lag >= 0) & (j + lag < n)
    slope[v4] += h[j + lag[v4]]
    
    return slope

def fast_pair_search(h, n, deadline, deltas):
    h = h.copy()
    best_c = compute_c5(h, n)
    dx = 2.0 / n
    
    for d in deltas:
        while time.time() < deadline:
            improved = False
            c = np.correlate(h, 1 - h, mode='full') * dx
            for i in range(n):
                if time.time() > deadline:
                    return h, best_c
                for j in range(i + 1, n):
                    # Direction 1: h[i]+=d, h[j]-=d
                    if h[i] + d <= 1.0 and h[j] - d >= 0.0:
                        slope = compute_slope(h, i, j, n)
                        new_max = np.max(c + d * slope)
                        if new_max < best_c - 1e-14:
                            h[i] += d
                            h[j] -= d
                            best_c = new_max
                            improved = True
                            c = c + d * slope
                    # Direction 2: h[i]-=d, h[j]+=d
                    if h[i] - d >= 0.0 and h[j] + d <= 1.0:
                        slope = compute_slope(h, i, j, n)
                        new_max = np.max(c - d * slope)
                        if new_max < best_c - 1e-14:
                            h[i] -= d
                            h[j] += d
                            best_c = new_max
                            improved = True
                            c = c - d * slope
            if not improved:
                break
    return h, best_c
