For a fixed lag k, I can compute s[p, k] for all p simultaneously:
```python
def compute_s_for_lag(h, n, k):
    s = np.zeros(n)
    # h[p-k] for valid p-k
    valid1 = (np.arange(n) - k >= 0) & (np.arange(n) - k < n)
    s[valid1] += h[np.arange(n)[valid1] - k]
    # h[p+k] for valid p+k
    valid2 = (np.arange(n) + k >= 0) & (np.arange(n) + k < n)
    s[valid2] += h[np.arange(n)[valid2] + k]
    return s
```

Then for a fixed lag k:
- For a in ones: sa = s[ones]
- For b in zeros: sb = s[zeros]
- We want a in ones, b in zeros with sa - sb minimized (most negative)
- The best is: min(sa) - max(sb) where min is over ones and max is over zeros
- But we need to check that the resulting flip doesn't make other lags worse

Actually, for a greedy approach, let me just:
1. For the worst lag k*, find the flip that reduces it the most
2. Check if it improves the overall max
3. If yes, accept it

```python
def binary_ls_fast(h, n, deadline, max_rounds=500):
    h = h.copy()
    dx = 2.0 / n
    best_c = compute_c5(h, n)
    ones = np.where(h == 1)[0]
    zeros = np.where(h == 0)[0]
    
    for rnd in range(max_rounds):
        if time.time() > deadline:
            break
        
        c_raw = np.correlate(h, 1 - h, mode='full')
        max_idx = np.argmax(c_raw)
        max_val = c_raw[max_idx]
        k = max_idx - (n - 1)
        
        # Compute s[p] = h[p-k] + h[p+k] for all p
        s = np.zeros(n)
        idx = np.arange(n)
        valid1 = (idx - k >= 0) & (idx - k < n)
        if np.any(valid1):
            s[valid1] += h[idx[valid1] - k]
        valid2 = (idx + k >= 0) & (idx + k < n)
        if np.any(valid2):
            s[valid2] += h[idx[valid2] + k]
        
        # Find best flip: a in ones, b in zeros minimizing s[a] - s[b]
        s_ones = s[ones]
        s_zeros = s[zeros]
        
        # Best a is the one with minimum s among ones
        # Best b is the one with maximum s among zeros
        best_a_local = np.argmin(s_ones)
        best_b_local = np.argmax(s_zeros)
        a = ones[best_a_local]
        b = zeros[best_b_local]
        delta = s[a] - s[b]
        
        if delta >= 0:
            # No flip can reduce this lag
            break
        
        # Apply flip
        h[a] = 0
        h[b] = 1
        new_max = np.max(np.correlate(h, 1 - h, mode='full'))
        
        if new_max * dx < best_c - 1e-15:
            best_c = new_max * dx
            ones = np.where(h == 1)[0]
            zeros = np.where(h == 0)[0]
        else:
            # Revert
            h[a] = 1
            h[b] = 0
    
    return h, best_c
```

This is O(n) per iteration (the correlate is O(n log n) or O(n^2) depending on implementation, but for n=300 it's fast). With 500 rounds, that's very fast.

But this greedy approach might get stuck. Let me add some randomness:

Instead of always picking the best flip for the worst lag, sometimes pick a random flip that reduces the worst lag.

Also, I should consider that reducing one lag might increase another. So I should check the full max after each flip.

Let me also add a "hill climbing" variant where I try all possible flips (a, b) pairs and pick the best one (not just for the worst lag, but for the overall max):

For n=300, there are 150*150 = 22500 possible flips. For each, computing the full correlation is O(n^2) = 90000 (or O(n log n) with FFT). In numpy, np.correlate for n=300 is very fast (probably < 1μs). So 22500 evaluations would take ~5ms. That's very fast!

Wait, actually np.correlate is O(n^2) for the direct method, which for n=300 is 90000 multiply-adds. In C (which numpy uses), that's maybe 1-5μs. So 22500 * 5μs = 112ms per full pass. With 100 passes, that's 11 seconds. Reasonable.

Let me implement a full-enumeration approach:


But this is O(n^4) in the worst case (n^2 pairs × n^2 correlate × n rounds). For n=300: 22500 * 90000 * 200 = way too much.

Let me use the delta formula instead. For a flip (a, b) at the current h:
The new correlation at lag k is: c_raw[n-1+k] + s[a,k] - s[b,k]

where s[p,k] = h[p-k] + h[p+k] (with out-of-range = 0).

So the new max is: max_k (c_raw[n-1+k] + s[a,k] - s[b,k])

I can precompute s for all (p, k) pairs:
S[p, k] = h[p-k] + h[p+k] for p in 0..n-1, k in -(n-1)..n-1

That's an n × (2n-1) matrix. For n=300, that's 300 × 599 ≈ 180K entries. Computing it is O(n^2).

Then for a flip (a, b):
new_c[k] = c_raw[n-1+k] + S[a, k+(n-1)] - S[b, k+(n-1)]
new_max = max(new_c)

This is O(n) per flip (just taking the max of a length (2n-1) array). With n^2 = 22500 flips, that's O(n^3) = 27M per round. In numpy, this can be vectorized.

Actually, I can vectorize over all (a, b) pairs simultaneously!

new_c[a, b, k] = c_raw[k] + S[a, k] - S[b, k]

For fixed k, this is: c_raw[k] + S[:, k][a] - S[:, k][b] for all a, b.

The max over k for each (a, b) pair:
new_max[a, b] = max_k (c_raw[k] + S[a, k] - S[b, k])

This is a 3D array of size n × n × (2n-1) = 300 × 300 × 599 ≈ 54M. That's too large for memory (54M * 8 bytes = 432MB).

Let me process it differently. For each a, compute:
new_c_for_a[b, k] = c_raw[k] + S[a, k] - S[b, k] for all b, k

This is n × (2n-1) = 300 × 599 ≈ 180K per a. With 300 a's, total is 54M. Still large.

Alternative: process one lag at a time.
For lag k: the contribution to new_max from this lag is:
contrib_k[a, b] = c_raw[k] + S[a, k] - S[b, k]

This is an n×n matrix (180K). I can accumulate the max over k:
new_max[a, b] = max(k) contrib_k[a, b]

So I maintain an n×n matrix `new_max` initialized to -inf, and for each k, I update:
new_max = max(new_max, c_raw[k] + S[a,k] (as column vector) - S[b,k] (as row vector))

This is n × (2n-1) = 300 * 599 = 180K operations per lag, times 599 lags = 108M total. In numpy with vectorized operations, this should be fast (maybe 1-2 seconds).

Let me implement this:

```python
def binary_ls_vectorized(h, n, deadline, max_rounds=100):
    h = h.copy()

    best_c = np.max(np.correlate(h, 1 - h, mode='full')) * dx
    ones = np.where(h == 1)[0]
    zeros = np.where(h == 0)[0]
    
    for rnd in range(max_rounds):
        if time.time() > deadline:
            break
        
        c_raw = np.correlate(h, 1 - h, mode='full')  # length 2n-1
        num_lags = 2 * n - 1
        
        # Compute S[p, k] = h[p-k] + h[p+k] for p=0..n-1, k=-（n-1)..n-1
        # k is indexed as 0..2n-2, actual lag = k - (n-1)
        S = np.zeros((n, num_lags))
        for k_idx in range(num_lags):
            k = k_idx - (n - 1)
            idx = np.arange(n)
            valid1 = (idx - k >= 0) & (idx - k < n)
            if np.any(valid1):
                S[valid1, k_idx] += h[idx[valid1] - k]
            valid2 = (idx + k >= 0) & (idx + k < n)
            if np.any(valid2):
                S[valid2, k_idx] += h[idx[valid2] + k]
        
        # For each (a, b) pair with a in ones, b in zeros:
        # new_max[a,b] = max_k (c_raw[k] + S[a,k] - S[b,k])
        # We only care about a in ones, b in zeros
        
        S_ones = S[ones, :]  # shape (n/2, 2n-1)
        S_zeros = S[zeros, :]  # shape (n/2, 2n-1)
        
        # new_max[a_idx, b_idx] = max_k (c_raw[k] + S_ones[a_idx, k] - S_zeros[b_idx, k])
        # = max_k (c_raw[k] + S_ones[a_idx, k] - S_zeros[b_idx, k])
        
        # This is: for each a_idx, compute c_raw + S_ones[a_idx] - S_zeros[b_idx] for all b_idx,
        # then take max over k.
        
        # Vectorized: 
        # temp[a_idx, b_idx, k] = c_raw[k] + S_ones[a_idx, k] - S_zeros[b_idx, k]
        # new_max[a_idx, b_idx] = max_k temp[a_idx, b_idx, k]
        
        # Memory: (n/2) * (n/2) * (2n-1) = 150 * 150 * 599 ≈ 13.5M floats = 108MB
        # That's borderline. Let me do it in chunks.
        
        chunk_size = 20  # process 20 'a' values at a time
        best_gain = 0
        best_a_idx, best_b_idx = -1, -1
        
        for a_start in range(0, len(ones), chunk_size):
            a_end = min(a_start + chunk_size, len(ones))
            # temp shape: (chunk, len(zeros), num_lags)
            temp = np.broadcast_to(c_raw[np.newaxis, np.newaxis, :], 
                                    (a_end - a_start, len(zeros), num_lags)) + \
                   S_ones[a_start:a_end, np.newaxis, :] - \
                   S_zeros[np.newaxis, :, :]
            new_max_chunk = temp.max(axis=2)  # shape (chunk, len(zeros))
            
            current_max = c_raw.max()
            gains = current_max - new_max_chunk
            max_gain_local = gains.max()
            if max_gain_local > best_gain:

                local_flat = np.argmax(gains)
                best_a_idx = a_start + local_flat // len(zeros)
                best_b_idx = local_flat % len(zeros)
        
        if best_a_idx == -1 or best_gain < 1e-10:
            break
        
        a = ones[best_a_idx]
        b = zeros[best_b_idx]
        h[a] = 0
        h[b] = 1
        best_c = np.max(np.correlate(h, 1 - h, mode='full')) * dx
        ones = np.where(h == 1)[0]
```

Now, let me also think about continuous optimization to refine the binary solution.

After binary local search converges, the solution is a 0-1 vector. We can try to improve it by allowing small continuous adjustments. The idea is:
- Positions where h=1: allow them to go slightly below 1
- Positions where h=0: allow them to go slightly above 0
- This gives the optimization more degrees of freedom

I'll use SLSQP with a smooth max objective.

Let me also think about a completely different approach: **simulated annealing** on the binary space.

In simulated annealing:
- State: binary vector with n/2 ones
- Move: swap a 1 and a 0
- Energy: C5 value
- Accept worse moves with probability exp(-ΔE/T)

This can escape local minima. Let me implement it briefly.

OK let me now put together the full solution. I'll aim for:

1. Phase 1: Binary local search (vectorized, greedy) from thresholded initial - ~30s
2. Phase 2: Simulated annealing on binary space - ~30s  
3. Phase 3: Continuous refinement from best binary - ~60s
4. Phase 4: Multi-start with random binary patterns - remaining time
5. Phase 5: Final refinement

Let me code this up:

```python
import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1 - h, mode='full')
    return float(np.max(c) * dx)

def compute_all_lags(h, n):
    dx = 2.0 / n
    return np.correlate(h, 1 - h, mode='full') * dx

def project_feasible(h, n):
    target_sum = n / 2.0
    h = np.clip(h.copy(), 0.0, 1.0)
    for _ in range(500):
        diff = target_sum - h.sum()
        if abs(diff) < 1e-15:
            break
        if diff > 0:
            room = 1.0 - h
            tot = room.sum()
            if tot < 1e-14:
                break
            h += (diff / tot) * room
        else:
            tot = h.sum()
            if tot < 1e-14:
                break
            h += (diff / tot) * h
    return np.clip(h, 0.0, 1.0)

def threshold_to_binary(h, n, rng):
    """Convert continuous h to binary with exactly n/2 ones."""
    scores = h + rng.normal(0, 0.01, n)  # small randomization for tie-breaking
    sorted_idx = np.argsort(-scores)
    k = n // 2
    h_bin = np.zeros(n)
    h_bin[sorted_idx[:k]] = 1.0
    return h_bin

def binary_ls_vectorized(h, n, deadline, max_rounds=500):
    """Greedy binary local search using vectorized correlation updates."""
    h = h.copy()
    dx = 2.0 / n
    best_c = float(np.max(np.correlate(h, 1 - h, mode='full')) * dx)
    ones = np.where(h == 1)[0]
    zeros = np.where(h == 0)[0]
    
    for rnd in range(max_rounds):
        if time.time() > deadline:
            break
        
        c_raw = np.correlate(h, 1 - h, mode='full')
        current_max = float(c_raw.max())
        num_lags = 2 * n - 1
        
        # Compute S[p, k_idx] = h[p-k] + h[p+k]
        S = np.zeros((n, num_lags))
        idx = np.arange(n)
        for k_idx in range(num_lags):
            k = k_idx - (n - 1)
            v1 = (idx - k >= 0) & (idx - k < n)
            if np.any(v1):
                S[v1, k_idx] += h[idx[v1] - k]
            v2 = (idx + k >= 0) & (idx + k < n)
            if np.any(v2):
                S[v2, k_idx] += h[idx[v2] + k]
        
        S_ones = S[ones, :]
        S_zeros = S[zeros, :]
        
        best_gain = 0
        best_a_pos, best_b_pos = -1, -1
        chunk = 30
        
        for a_s in range(0, len(ones), chunk):
            a_e = min(a_s + chunk, len(ones))
            # Shape: (chunk, len(zeros), num_lags)
            temp = (c_raw[np.newaxis, np.newaxis, :]
                    + S_ones[a_s:a_e, np.newaxis, :]
                    - S_zeros[np.newaxis, :, :])
            new_max = temp.max(axis=2)
            gains = current_max - new_max
            mg = float(gains.max())
            if mg > best_gain:
                best_gain = mg
                flat = int(np.argmax(gains))
                best_a_pos = a_s + flat // len(zeros)
                best_b_pos = flat % len(zeros)
        
        if best_a_pos < 0 or best_gain < 1e-12:
            break
        
        a = ones[best_a_pos]
        b = zeros[best_b_pos]
        h[a] = 0
        h[b] = 1
        new_c = float(np.max(np.correlate(h, 1 - h, mode='full')) * dx)
        if new_c < best_c:
            best_c = new_c
        ones = np.where(h == 1)[0]
        zeros = np.where(h == 0)[0]
    
    return h, best_c

def simulated_annealing_binary(h, n, deadline, rng, max_iters=50000):
    """Simulated annealing on binary space."""
    h = h.copy()
    dx = 2.0 / n
    current_c = float(np.max(np.correlate(h, 1 - h, mode='full')) * dx)
    best_c = current_c
    best_h = h.copy()
    
    ones = np.where(h == 1)[0]
    zeros = np.where(h == 0)[0]
    
    T_start = 0.01
    T_end = 1e-6
    n_iters = max_iters
    
    for it in range(n_iters):
        if time.time() > deadline:
            break
        T = T_start * (T_end / T_start) ** (it / max(n_iters - 1, 1))
        
        a = ones[rng.randint(len(ones))]
        b = zeros[rng.randint(len(zeros))]
        
        h[a] = 0
        h[b] = 1
        new_c = float(np.max(np.correlate(h, 1 - h, mode='full')) * dx)
        delta = new_c - current_c
        
        if delta < 0 or rng.random() < np.exp(-delta / max(T, 1e-10)):
            current_c = new_c
            ones = np.where(h == 1)[0]
            zeros = np.where(h == 0)[0]
            if new_c < best_c:
                best_c = new_c
                best_h = h.copy()
        else:
            h[a] = 1
            h[b] = 0
    
    return best_h, best_c

def smooth_max_obj(x, n, alpha):
    dx = 2.0 / n
    c = np.correlate(x, 1 - x, mode='full') * dx
    m = c.max()
    shifted = alpha * (c - m)
    mx = shifted.max()
    if mx > 500:
        return float(m + (mx + np.log(np.sum(np.exp(shifted - mx)))) / alpha)
    return float(m + np.log(np.sum(np.exp(shifted))) / alpha)

def sum_con(x, n):
    return float(np.sum(x) - n / 2.0)

def sum_con_jac(x, n):
    return np.ones(n)

def continuous_refine(h_start, n, deadline, alpha_list=None):
    """Refine a solution using SLSQP with smooth max."""
    if alpha_list is None:
        alpha_list = [5000, 20000, 100000, 500000]
    
    h_curr = project_feasible(h_start.copy(), n)
    best_c = compute_c5(h_curr, n)
    best_h = h_curr.copy()
    
    for alpha in alpha_list:
        if time.time() > deadline - 5:
            break
        bounds = [(0.0, 1.0)] * n
        cons = [{'type': 'eq', 'fun': sum_con, 'jac': sum_con_jac, 'args': (n,)}]
        try:
            res = minimize(smooth_max_obj, h_curr, args=(n, alpha),
                          method='SLSQP', bounds=bounds, constraints=cons,
                          options={'maxiter': 3000, 'ftol': 1e-16})
            h_new = project_feasible(res.x, n)
            c_new = compute_c5(h_new, n)
            if c_new < best_c:
                best_c = c_new
                best_h = h_new.copy()
                h_curr = h_new
        except Exception:
            pass
    
    return best_h, best_c

def local_search_continuous(h, n, deadline):
    """Greedy continuous local search: adjust pairs of elements to reduce max lag."""
    h = h.copy()
    best_c = compute_c5(h, n)
    dx = 2.0 / n
    
    for step in [0.01, 0.005, 0.002, 0.001, 0.0005]:
        if time.time() > deadline:
            break
        improved = True
        while improved and time.time() < deadline:
            improved = False
            c = compute_all_lags(h, n)
            k_star = int(np.argmax(c))
            lag = k_star - (n - 1)
            if lag == 0:
                break
            m = abs(lag)
            for i in range(0, n - m, 2):  # step by 2 for speed
                if time.time() > deadline:
                    break
                j = i + m
                if h[i] > h[j]:
                    delta = min(step, (h[i] - h[j]) * 0.4, h[i] * 0.9, (1.0 - h[j]) * 0.9)
                    if delta < 1e-8:
                        continue
                    h[i] -= delta
                    h[j] += delta
                    c_new = compute_c5(h, n)
                    if c_new < best_c - 1e-14:
                        best_c = c_new
                        improved = True
                    else:
                        h[i] += delta
                        h[j] -= delta
                elif h[j] > h[i]:
                    delta = min(step, (h[j] - h[i]) * 0.4, h[j] * 0.9, (1.0 - h[i]) * 0.9)
                    if delta < 1e-8:
                        continue
                    h[i] += delta
                    h[j] -= delta
                    c_new = compute_c5(h, n)
                    if c_new < best_c - 1e-14:
                        best_c = c_new
                        improved = True
```

```python
import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1 - h, mode='full')
    return float(np.max(c) * dx)

def compute_all_lags(h, n):
    dx = 2.0 / n
    return np.correlate(h, 1 - h, mode='full') * dx

def project_feasible(h, n):
    target_sum = n / 2.0
    h = np.clip(h.copy(), 0.0, 1.0)
    for _ in range(500):
        diff = target_sum - h.sum()
        if abs(diff) < 1e-15:
            break
        if diff > 0:
            room = 1.0 - h
            tot = room.sum()
            if tot < 1e-14:
                break
            h += (diff / tot) * room
        else:
            tot = h.sum()
            if tot < 1e-14:
                break
            h += (diff / tot) * h
    return np.clip(h, 0.0, 1.0)

def threshold_to_binary(h, n, rng):
    scores = h + rng.normal(0, 0.02, n)
    sorted_idx = np.argsort(-scores)
    h_bin = np.zeros(n)
    h_bin[sorted_idx[:n // 2]] = 1.0
    return h_bin

def build_S(h, n):
    num_lags = 2 * n - 1
    S = np.zeros((n, num_lags))
    idx = np.arange(n)
    for k_idx in range(num_lags):
        k = k_idx - (n - 1)
        v1 = (idx - k >= 0) & (idx - k < n)
        if np.any(v1):
            S[v1, k_idx] += h[idx[v1] - k]
        v2 = (idx + k >= 0) & (idx + k < n)
        if np.any(v2):
            S[v2, k_idx] += h[idx[v2] + k]
    return S

def binary_ls_vectorized(h, n, deadline, max_rounds=1000):
    h = h.copy()
    dx = 2.0 / n
    best_c = float(np.max(np.correlate(h, 1 - h, mode='full')) * dx)
    ones = np.where(h == 1)[0]
    zeros = np.where(h == 0)[0]
    stagnant = 0
    for rnd in range(max_rounds):
        if time.time() > deadline:
            break
        c_raw = np.correlate(h, 1 - h, mode='full')
        current_max = float(c_raw.max())
        num_lags = 2 * n - 1
        S = build_S(h, n)
        S_ones = S[ones, :]
        S_zeros = S[zeros, :]
        best_gain = 0
        best_a_pos, best_b_pos = -1, -1
        chunk = 25
        for a_s in range(0, len(ones), chunk):
            a_e = min(a_s + chunk, len(ones))
            temp = (c_raw[np.newaxis, np.newaxis, :]
                    + S_ones[a_s:a_e, np.newaxis, :]
                    - S_zeros[np.newaxis, :, :])
            new_max = temp.max(axis=2)
            gains = current_max - new_max
            mg = float(gains.max())
            if mg > best_gain:
                best_gain = mg
                flat = int(np.argmax(gains))
                best_a_pos = a_s + flat // len(zeros)
                best_b_pos = flat % len(zeros)
        if best_a_pos < 0 or best_gain < 1e-12:
            break
        a = ones[best_a_pos]
        b = zeros[best_b_pos]
        h[a] = 0
        h[b] = 1
        new_c = float(np.max(np.correlate(h, 1 - h, mode='full')) * dx)
        if new_c < best_c - 1e-15:
            best_c = new_c
            stagnant = 0
        else:
            stagnant += 1
        ones = np.where(h == 1)[0]
        zeros = np.where(h == 0)[0]
        if stagnant > 30:
            break
    return h, best_c

def simulated_annealing(h, n, deadline, rng, max_iters=40000):
    h = h.copy()
    dx = 2.0 / n
    current_c = float(np.max(np.correlate(h, 1 - h, mode='full')) * dx)
    best_c = current_c
    best_h = h.copy()
    ones = np.where(h == 1)[0]
    zeros = np.where(h == 0)[0]
    T_start = 0.05
    T_end = 1e-7
    for it in range(max_iters):
        if time.time() > deadline:
            break
        T = T_start * (T_end / T_start) ** (it / max(max_iters - 1, 1))
        a = ones[rng.randint(len(ones))]
        b = zeros[rng.randint(len(zeros))]
        h[a] = 0
        h[b] = 1
        new_c = float(np.max(np.correlate(h, 1 - h, mode='full')) * dx)
        delta = new_c - current_c
        if delta < 0 or (delta / T) < np.log(max(rng.random(), 1e-15)):
            current_c = new_c
            ones = np.where(h == 1)[0]
            zeros = np.where(h == 0)[0]
            if new_c < best_c:
                best_c = new_c
                best_h = h.copy()
        else:
            h[a] = 1
            h[b] = 0
    return best_h, best_c

def smooth_max_obj(x, n, alpha):
    dx = 2.0 / n
    c = np.correlate(x, 1 - x, mode='full') * dx
    m = c.max()
    shifted = alpha * (c - m)
    mx = shifted.max()
    if mx > 500:
        return float(m + (mx + np.log(np.sum(np.exp(shifted - mx)))) / alpha)
    return float(m + np.log(np.sum(np.exp(shifted))) / alpha)

def sum_con(x, n):
    return float(np.sum(x) - n / 2.0)

def sum_con_jac(x, n):
    return np.ones(n)

def continuous_refine(h_start, n, deadline, alpha_list=None):
    if alpha_list is None:
        alpha_list = [5000, 50000, 200000]
    h_curr = project_feasible(h_start.copy(), n)

                best_h = h_new.copy()
```
