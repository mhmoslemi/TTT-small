Hmm, but I'm worried about the Nesterov method. The issue is that the subgradient only gives information about ONE lag (the worst one). This makes the method very noisy. Let me think about how to handle this better.

**Improved subgradient: Use the top-m lags**

Instead of using just the single worst lag, use a weighted average of the top-m lags:
```
weights = softmax(beta * (corr - max(corr)))  # for top m lags
grad = sum_j weights[j] * subgradient(h, k_j, n)
```

This gives a "smoother" subgradient that accounts for multiple near-worst lags.

But this makes each iteration more expensive (need to compute subgradients for m lags). For n=70, this is still fast.

Let me also think about **variance reduction**. The idea is:
- Maintain a running average of the subgradient
- Use this averaged gradient for the update

This is like SAGA or SVRG in the convex setting.

Actually, for this problem, since the "max" changes slowly as h changes (once we're near the optimum, the set of active lags is stable), we could:
1. Identify the active set (lags near the maximum)
2. Average the subgradients over the active set
3. Use this averaged gradient for the Nesterov update

This should give much better convergence.

import numpy as np
from scipy.optimize import minimize, Bounds
import time

def compute_c5(h):
    n = len(h)
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)

def project_polytope(v, s):
    n = len(v)
    if s <= 0 or s >= n:
        return np.clip(v, 0, 1)
    lo = v.min() - s
    hi = v.max()
    for _ in range(80):
        tau = 0.5 * (lo + hi)
        total = np.clip(v - tau, 0.0, 1.0).sum()
        if total > s:
            lo = tau
        else:
            hi = tau
        if hi - lo < 1e-16:
            break
    tau = 0.5 * (lo + hi)
    return np.clip(v - tau, 0.0, 1.0)

def get_subgradient(h, k_worst, n):
    lag = k_worst - (n - 1)
    grad = np.zeros(n)
    if lag >= 0:
        m = n - lag
        idx = np.arange(m)
        grad[idx] += (1.0 - h[idx + lag])
        grad[idx + lag] -= h[idx]
    else:
        la = -lag
        m = n - la
        idx = np.arange(m)
        grad[idx + la] += (1.0 - h[idx])
        grad[idx] -= h[idx + la]
    return grad

def smoothed_subgradient(h, n, top_m, beta_smooth):
    dx = 2.0 / n
    corr = np.correlate(h, 1.0 - h, mode='full')
    vals = corr * dx
    indices = np.argsort(vals)[-top_m:][::-1]
    weights = np.exp(beta_smooth * (vals[indices] - vals[indices[0]]))
    weights /= weights.sum()
    grad = np.zeros(n)
    for j in range(top_m):
        grad += weights[j] * get_subgradient(h, int(indices[j]), n)
    return grad, vals

        y = h + alpha * (h - h_prev)
        y_safe = np.clip(y, 0.0, 1.0)
        grad, _ = smoothed_subgradient(y_safe, n, top_m, beta_smooth)
        lr = lr0 / np.sqrt(t)
        h_new = y_safe - lr * grad
        h_new = project_polytope(h_new, target_sum)

            c5 = compute_c5(h_new)
            if c5 < best_c5:
                best_c5 = c5
                best_h = h_new.copy()
        h_prev = h
        h = h_new
    c5 = compute_c5(h)
    if c5 < best_c5:
        best_h = h.copy()
        best_c5 = c5
    return best_h, best_c5

def power_mean_obj(h, dx, p):
    corr = np.correlate(h, 1.0 - h, mode='full')
    vals = np.maximum(corr * dx, 1e-15)
    return np.sum(vals ** p) ** (1.0 / p)

    return x.sum() - target_sum

def constraint_jac(x, target_sum):
    return np.ones(len(x))

def resample_h(h_old, n_new):
    x_old = np.linspace(0, 2, len(h_old), endpoint=False)

    return np.interp(x_new, x_old, h_old)
