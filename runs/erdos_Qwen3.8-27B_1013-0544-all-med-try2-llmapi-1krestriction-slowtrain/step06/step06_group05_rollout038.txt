```python
import numpy as np
from scipy.optimize import minimize
from scipy.fft import fft, ifft, ifftshift
import time

def fft_correlate(a, b):
    """Full cross-correlation via FFT: result[k] = sum_i a[i] * b[i + k - (len(b)-1)]"""
    n = len(a)
    N = 2 * n - 1
    # Pad to next power of 2 for efficiency
    Nfft = 1
    while Nfft < N:
        Nfft *= 2
    fa = fft(a, Nfft)
    fb = fft(b, Nfft)
    result = ifft(np.conj(fa) * fb).real
    return ifftshift(result)[:N]

def compute_c5_values(h, n):
    dx = 2.0 / n
    c = fft_correlate(h, 1.0 - h)
    return c * dx

def compute_c5(h, n):
    return float(np.max(compute_c5_values(h, n)))

def smooth_objective(h, n, alpha):
    g = compute_c5_values(h, n)
    m = g.max()
    if m > 1.0:  # numerical safety
        return float(m + 0.001)
    shifted = alpha * (g - m)
    mx = shifted.max()
    return float(m + np.log(np.sum(np.exp(shifted - mx)) + 1e-300) / alpha)

def smooth_gradient(h, n, alpha):
    g = compute_c5_values(h, n)
    m = g.max()
```

```python
def _next_pow2(m):
    p = 1
    while p < m:
        p *= 2
    return p

def fft_correlate(a, b):
    na, nb = len(a), len(b)
    N = _next_pow2(na + nb - 1)
    result = ifft(np.conj(fft(a, N)) * fft(b, N)).real
    return ifftshift(result)[:na + nb - 1]

def c5_values(h, n):
    return fft_correlate(h, 1.0 - h) * (2.0 / n)

def c5_max(h, n):
    return float(np.max(c5_values(h, n)))

def smooth_obj(x, n, alpha):
    g = c5_values(x, n)
    m = g.max()
    s = alpha * (g - m)
    mx = s.max()
    return m + float(np.log(np.sum(np.exp(s - mx))) / alpha)
```

Actually, for the pair search, let me think about a faster version. The key insight is:

When we change h[i] by +d and h[j] by -d, the change in the correlation vector is:
Δc[k] = d * (1 - h[i+m_k]) - h[i] - d * (1 - h[j+m_k]) - h[j]
Wait, let me redo this.

c[k] = sum_t h[t] * (1 - h[t + m_k]) where m_k = k - (n-1)

After change: h[i] → h[i]+d, h[j] → h[j]-d

Δc[k] from h[i] change:
- h[i] appears in c[k] as a "first factor": (h[i]+d)*(1-h[i+m_k]) - h[i]*(1-h[i+m_k]) = d*(1-h[i+m_k])
- h[i] appears as a "second factor" when t+m_k = i, i.e., t = i-m_k:
  h[i-m_k]*(1-(h[i]+d)) - h[i-m_k]*(1-h[i]) = -d*h[i-m_k]
- Total from h[i]: d*(1-h[i+m_k]) - d*h[i-m_k] = d*(1 - h[i+m_k] - h[i-m_k])

Similarly for h[j] change (-d):
-d*(1 - h[j+m_k]) + d*h[j-m_k] = d*(h[j+m_k] + h[j-m_k] - 1)

Total: Δc[k] = d*(1 - h[i+m_k] - h[i-m_k] + h[j+m_k] + h[j-m_k] - 1)
           = d*(h[j+m_k] + h[j-m_k] - h[i+m_k] - h[i-m_k])

So the change in c[k] for all k can be computed in O(n) if we precompute:
Δc = d * (roll(1-h, -m_i) ... ) 

Actually, the vector Δc/ d = [h[j+m_k] + h[j-m_k] - h[i+m_k] - h[i-m_k]] for k = 0..2n-2

This is: (the vector of h[j+shifts] + h[j-shifts]) - (the vector of h[i+shifts] + h[i-shifts])

Where shifts = [-(n-1), ..., 0, ..., (n-1)]

Each of these can be computed as: for a fixed index i, the vector v_i[k] = h[i+shifts[k]] + h[i-shifts[k]] (with h out of range = 0).

This is essentially the "correlation profile" of a delta function at position i with h.

We can precompute this for all i using FFT, but for the pair search, we just need it for the specific i, j we're testing.

For a single pair (i, j), computing Δc is O(n). Then checking if max(c + Δc) < current_max is O(n). So each pair evaluation is O(n) instead of O(n log n) or O(n²).
