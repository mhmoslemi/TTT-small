def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h, 0.0, 1.0)
    for _ in range(200):
        diff = target - h.sum()
        if abs(diff) < 1e-13:
            break
        if diff > 0:

            s = room.sum()
            if s < 1e-14:

            h += diff / s * room
        else:
            s = h.sum()
            if s < 1e-14:
                break
            h += diff / s * h

def subgradient_optimize(h, n, deadline, lr_init=0.1, top_k=5):
    """Projected subgradient method for the continuous problem."""
    dx = 2.0 / n
    m_arr = np.arange(2 * n - 1)
    h = project_feasible(h.copy(), n)
    corr = compute_corr(h)
    best_h = h.copy()
    best_c = corr.max() * dx
    cur_c = best_c
    lr = lr_init
    
    step = 0
    while time.time() < deadline:
        # Compute subgradient at top_k lags
        top_idx = np.argsort(corr)[::-1][:top_k]
        top_vals = corr[top_idx]
        
        # Weight by softmax
        exp_vals = np.exp((top_vals - top_vals[0]) / (max(dx * 5, 1e-10)))
        weights = exp_vals / exp_vals.sum()
        
        # Compute weighted subgradient
        sg = np.zeros(n)
        for w_k, idx_k in zip(weights, top_idx):
            lag = idx_k - (n - 1)
            i_range = np.arange(n)
            i_plus = i_range + lag
            i_minus = i_range - lag
            mask_plus = (i_plus >= 0) & (i_plus < n)
            mask_minus = (i_minus >= 0) & (i_minus < n)
            sg[mask_plus] += w_k * (1.0 - h[i_plus[mask_plus]])
            sg[mask_minus] -= w_k * h[i_minus[mask_minus]]
        
        # Update
        h_new = project_feasible(h - lr * sg, n)
        new_corr = compute_corr(h_new)
        new_c = new_corr.max() * dx
        
        if new_c < cur_c:
            h = h_new
            corr = new_corr
            cur_c = new_c
            if cur_c < best_c:
                best_c = cur_c
                best_h = h.copy()
            # Decrease learning rate slightly on success
            lr *= 0.999
        else:
            # Increase learning rate or try different
            lr *= 0.95
        
        step += 1
        # Decay learning rate slowly
        if step % 100 == 0:
            lr = max(lr_init * 0.1, lr * 0.9)
    
    return best_h, best_c

This is linear in h[i]! (since h[i+k] and h[i-k] are treated as constants)

So for a single lag, the problem is linear in each h[i] (coordinate-wise). But for the max over lags, it's:
max_k c_k(h) where each c_k is linear in h[i] for fixed other coordinates.

The max of linear functions is convex! So the subproblem:
min_{h[i] ∈ [0,1]} max_k (a_k * h[i] + b_k)

where a_k and b_k depend on the other coordinates.

This is a 1D convex optimization problem! The solution is:
- If all a_k = 0: h[i] doesn't matter (any value in [0,1])
- Otherwise: the max is achieved by the k with the largest a_k * h[i] + b_k
  - This is a piecewise linear function of h[i]
  - The minimum is at the intersection point or at a boundary

This suggests that **coordinate descent** could work well! For each coordinate, the subproblem is a 1D problem that can be solved analytically.

But the integral constraint couples all coordinates. We can handle this with a Lagrange multiplier:
min_{h[i]} max_k c_k + λ*(sum(h) - n/2)

This adds λ to each a_k, making:
min_{h[i] ∈ [0,1]} max_k ((a_k + λ) * h[i] + b_k)

Still a 1D problem!

After optimizing all coordinates (one pass), we can update λ to enforce the integral constraint.

This is essentially a **Dantzig-Wolfe / Benders decomposition** approach.

Let me implement this:

```python
def coordinate_descent(h, n, deadline, max_iters=10000):
    """Coordinate descent with Lagrange multiplier for integral constraint."""
    dx = 2.0 / n
    m_arr = np.arange(2 * n - 1)
    h = project_feasible(h.copy(), n)
    corr = compute_corr(h)
    best_h = h.copy()
    best_c = corr.max() * dx
    cur_c = best_c
    lam = 0.0
    
    for it in range(max_iters):
        if time.time() > deadline:
            break
        improved = False
        for i in range(n):
            # Compute the 1D subproblem for h[i]
            # c_k = ... + h[i]*(1-h[i+k]) + h[i-k]*(1-h[i]) + ...
            # For each lag k (represented by m in corr array):
            #   contribution of h[i] to c_m:
            #     h[i] * (1 - h[i + lag_m]) + (1-h[i]) * h[i - lag_m]  (if both valid)
            #   = h[i] + h[i-lag_m] - h[i]*(h[i+lag_m] + h[i-lag_m])
            #   = h[i]*(1 - h[i+lag_m] - h[i-lag_m]) + h[i-lag_m]
            #   Let a_m = 1 - h[i+lag_m] - h[i-lag_m] (for valid positions)
            #   Let b_m = h[i-lag_m] (for valid positions)
            #   Then c_m = a_m * h[i] + b_m + (rest, not depending on h[i])
            
            # For the max over m, we want to minimize max_m (a_m * h[i] + b_m + rest_m)
            # = max_m (a_m * h[i] + c'_m) where c'_m = b_m + rest_m = corr[m] - old_contribution_m
            
            # The old contribution of h[i] to c_m was:
            #   h[i]_old * (1-h[i+lag]) + (1-h[i]_old) * h[i-lag]
            
            # New contribution: h[i]_new * (1-h[i+lag]) + (1-h[i]_new) * h[i-lag]
            # Delta = (h[i]_new - h[i]_old) * (1-h[i+lag] - h[i-lag])
            #       = (h[i]_new - h[i]_old) * a_m
            
            # So new c_m = corr[m] + (h[i]_new - h[i]_old) * a_m
            # = corr[m] - h[i]_old * a_m + h[i]_new * a_m
            
            # We want to minimize max_m (corr[m] - h[i]_old * a_m + h[i]_new * a_m)
            # subject to 0 ≤ h[i]_new ≤ 1
            
            # This is: minimize max_m (a_m * h[i]_new + d_m) where d_m = corr[m] - h[i]_old * a_m
            
            # The function max_m (a_m * t + d_m) is piecewise linear and convex in t.
            # Its minimum over [0,1] is at the point where the two "active" lines cross,
            # or at a boundary.
            
            # Compute a_m and d_m for all m
            lag_arr = m_arr - (n - 1)  # shape (2n-1,)
            i_plus = i + lag_arr  # i + lag for each m
            i_minus = i - lag_arr  # i - lag for each m
            valid_plus = (i_plus >= 0) & (i_plus < n)
            valid_minus = (i_minus >= 0) & (i_minus < n)
            
            # a_m = (1 - h[i+lag]) * 1_{valid+} - h[i-lag] * 1_{valid-}
            # Wait, let me re-derive.
            # c_m = sum_j h[j] * (1 - h[j+lag_m])
            # Terms involving h[i]:
            #   j=i: h[i] * (1-h[i+lag])  [requires i+lag valid]
            #   j=i-lag: h[i-lag] * (1-h[i])  [requires i-lag valid]
            # So c_m = h[i]*(1-h[i+lag])*1_{valid+} + h[i-lag]*(1-h[i])*1_{valid-} + rest
            #        = h[i]*(1-h[i+lag])*1_{valid+} + h[i-lag]*1_{valid-} - h[i]*h[i-lag]*1_{valid-} + rest
            #        = h[i]*[(1-h[i+lag])*1_{valid+} - h[i-lag]*1_{valid-}] + h[i-lag]*1_{valid-} + rest
            # So a_m = (1-h[i+lag])*1_{valid+} - h[i-lag]*1_{valid-}
            #    d_m = corr[m] - h[i]_old * a_m  (since corr[m] = h[i]_old * a_m + d_m)
            
            a = np.zeros(2 * n - 1)
            a[valid_plus] += (1.0 - h[i_plus[valid_plus]])
            a[valid_minus] -= h[i_minus[valid_minus]]
            
            d = corr - h[i] * a  # d_m = corr[m] - h[i]_old * a_m
            
            # Now minimize max_m (a_m * t + d_m) over t in [0,1]
            # Using the Lagrange multiplier for the integral:
            # Add lam * t to the objective (approximately)
            # New a'_m = a_m + lam (approximately, since the integral constraint adds lam to the objective)
            # Actually, the integral constraint is sum(h) = n/2, and if we use
            # Lagrangian L = max_k c_k + lam * (sum(h) - n/2), then
            # ∂L/∂h[i] = subgrad_c[h[i]] + lam
            # So the effective a_m for the max is a_m (and we add lam separately)
            # Hmm, this is getting complicated. Let me just solve without the constraint
            # and fix it with projection after.
            
            # Find t* = argmin_{t in [0,1]} max_m (a_m * t + d_m)
            # The maximum is achieved by the upper envelope of lines {a_m * t + d_m}
            # The minimum of the upper envelope over [0,1] is at:
            #   - t=0 if the envelope is decreasing at 0
            #   - t=1 if the envelope is increasing at 1
            #   - The intersection of the two lines that form the lower part of the envelope
            
            # Simple approach: try t=0, t=1, and the "optimal" t
            # The optimal t is where the slope changes from negative to positive
            # Slope of the envelope at t is: max of {a_m : a_m*t + d_m = max}
            
            # For a simpler approach: use binary search or just evaluate at a few points
            # Since the problem is 1D, we can use golden section or just check t=0, 0.5, 1
            
            # Actually, the simplest correct approach:
            # f(t) = max_m (a_m * t + d_m) is convex in t
            # Use ternary search or just evaluate at boundaries and the "crossover"
            
            # The crossover point: find the pair (m1, m2) such that
            # a_m1 * t + d_m1 = a_m2 * t + d_m2 and both are on the upper envelope
            # t_cross = (d_m2 - d_m1) / (a_m1 - a_m2) if a_m1 ≠ a_m2
            
            # For efficiency, let's just evaluate at a few candidate points:
            candidates = [0.0, 1.0]
            # Add the crossover between the current best and worst lines
            # (Heuristic: the optimal t is often near where the current max line crosses
            #  the second max line)
            
            # Evaluate f at candidate points
            # f(0) = max_m (d_m) = max_m (corr[m] - h[i]*a_m)
            # f(1) = max_m (a_m + d_m) = max_m (corr[m] - h[i]*a_m + a_m) = max_m (corr[m] + (1-h[i])*a_m)
            f0 = np.max(d)
            f1 = np.max(a + d)
            
            try:
                t_new = 0.0 if f0 <= f1 else 1.0
            except:
                t_new = h[i]
            
            # Also try the "balanced" point
            # If the max at t=0 is achieved by line m1 and at t=1 by line m2,
            # the crossover is at t = (d_m2 - d_m1) / (a_m1 - a_m2)
            m_at_0 = np.argmax(d)
            m_at_1 = np.argmax(a + d)
            if m_at_0 != m_at_1:
                da = a[m_at_0] - a[m_at_1]
                if abs(da) > 1e-10:
                    t_cross = (d[m_at_1] - d[m_at_0]) / (a[m_at_0] - a[m_at_1])
                    if 0 < t_cross < 1:
                        fc = np.max(a * t_cross + d)
                        if fc < f0 and fc < f1:
                            t_new = t_cross
            
            if abs(t_new - h[i]) > 1e-6:
                h[i] = t_new
                improved = True
        
        # Project to maintain integral constraint
        h = project_feasible(h, n)
        corr = compute_corr(h)
        cur_c = corr.max() * dx
        if cur_c < best_c:
            best_c = cur_c
            best_h = h.copy()
        
        if not improved:
            break
    
    return best_h, best_c
```

Wait, but this coordinate descent approach has an issue: after I update h[i], the correlation changes, which affects the subproblems for other coordinates. I need to either:
1. Recompute the correlation after each coordinate update (expensive: O(n) per coordinate, O(n²) per pass)
2. Or do a "Gauss-Seidel" style where I update the correlation incrementally

Option 2 is better. When I change h[i] from old to new, the change in correlation is:
Δcorr[m] = (new - old) * a_m

where a_m is the same as computed above. So I can update corr in O(n) per coordinate change.

Total cost per pass: O(n²) for all n coordinates. For n=400, that's 160K per pass. Very fast!

But wait, there's a subtlety: when I compute a_m for coordinate i, I'm using the current values of h. After I update h[i], the a_m for subsequent coordinates j will be different (because a_j depends on h[i] if j±lag = i). So the "exact" coordinate descent requires updating the a_m vectors for all subsequent coordinates, which is expensive.

A practical approach: do multiple passes, and in each pass, recompute a_m from scratch for each i. This is the "Jacobi" version. Or, accept that the a_m are slightly stale and just do Gauss-Seidel with the exact correlation update.

Let me go with the Gauss-Seidel approach with exact correlation updates:
