I need to make the local search faster. The key is that I'm doing a Python loop over all (i,j) pairs, and each iteration calls `swap_delta` which creates arrays. This is slow.

Alternative: vectorize the inner loop. For a fixed i, I can compute the deltas for all j simultaneously.

Let me think about this. For fixed i (the zero position), the delta for swapping with j (one position) is:
delta_ij = f_i + g_j + corrections

where f_i is independent of j and g_j depends on j.

f_i[k] = (1-h[i+k])*[valid] - h[i-k]*[valid] (independent of j)
g_j[k] = (h[j+k]-1)*[valid] + h[j-k]*[valid] (depends on j)

The correction is:
- At lag (b-a) = (j-i): f_i gets +1
- At lag (a-b) = (i-j): g_j gets +1

For a vectorized approach, I'd need to compute g_j for all j simultaneously, which is a 2D array of shape (n, 2n-1). For n=250, that's 250*499 = 124,750 elements, which is manageable.

```python
def local_search_fast(h, n, deadline, max_rounds=50):
    dx = 2.0 / n
    h = to_binary(h, n)
    corr = np.correlate(h, 1 - h, mode='full').astype(float)
    cur_c = corr.max() * dx
    best_c = cur_c
    best_h = h.copy()
    m = 2 * n - 1
    k = np.arange(-(n-1), n)
    
    for _ in range(max_rounds):
        if time.time() > deadline:
            return best_h, best_c
        improved = False
        zeros = np.where(h == 0)[0]
        ones = np.where(h == 1)[0]
        
        # For each i in zeros, compute best j in ones
        # Vectorize: for each i, compute f_i, then for each j, compute g_j
        # Find the (i,j) pair with minimum max(corr + f_i + g_j + corrections)
        
        # This is O(n * n * m) = O(n² * m) which is the same as before
        # But we can vectorize the inner loop
        
        for i in zeros:
            if time.time() > deadline:
                return best_h, best_c
            # Compute f_i
            ak = i + k; akm = i - k
            fi = np.zeros(m)
            m1 = (ak >= 0) & (ak < n)
            fi[m1] = 1.0 - h[ak[m1]]
            m2 = (akm >= 0) & (akm < n)
            fi[m2] -= h[akm[m2]]
            
            # Compute g_j for all j in ones
            # g_j[k] = (h[j+k]-1)*[j+k valid] + h[j-k]*[j-k valid]
            # Shape: (len(ones), m)
            bk = ones[:, None] + k[None, :]  # (len(ones), m)
            bkm = ones[:, None] - k[None, :]
            gb = np.zeros((len(ones), m))
            m3 = (bk >= 0) & (bk < n)
            gb[m3] = h[bk[m3]] - 1.0
            m4 = (bkm >= 0) & (bkm < n)
            gb[m4] += h[bkm[m4]]
            
            # Corrections
            # For each j: correction at lag (j-i) in fi, at lag (i-j) in gb
            lags_ji = ones - i  # lag for fi correction
            lags_ij = i - ones  # lag for gb correction
            idx_ji = n - 1 + lags_ji
            idx_ij = n - 1 + lags_ij
            
            # Apply corrections to fi (but fi is a single vector, and the correction
            # depends on j, so we can't apply it to fi directly)
            # Instead, add correction to the combined delta
            # delta_ij = fi + gb[j] + correction
            # correction at position (n-1 + j - i) in the combined vector
            
            combined = fi[None, :] + gb  # (len(ones), m)
            # Add +1 at position idx_ji for each row
            valid_ji = (idx_ji >= 0) & (idx_ji < m)
            for jj in range(len(ones)):
                if valid_ji[jj]:
                    combined[jj, idx_ji[jj]] += 1.0
            # Add +1 at position idx_ij for each row
            valid_ij = (idx_ij >= 0) & (idx_ij < m)
            for jj in range(len(ones)):
                if valid_ij[jj]:
                    combined[jj, idx_ij[jj]] += 1.0
            
            # Find the j that gives minimum max
            new_corrs = corr[None, :] + combined  # (len(ones), m)
            new_maxes = new_corrs.max(axis=1) * dx
            best_jc = new_maxes.argmin()
            
            if new_maxes[best_jc] < cur_c - 1e-15:
                j = ones[best_jc]
                d = combined[best_jc]
                h[i] = 1.0; h[j] = 0.0
                corr += d; cur_c = new_maxes[best_jc]
                improved = True
                if cur_c < best_c:
                    best_c = cur_c; best_h = h.copy()
                break  # Restart the zeros loop
        
        if not improved:
            break
    return best_h, best_h if False else (best_h, best_c)
```

```python
    best_h = h.copy()
    m = 2 * n - 1
    k = np.arange(-(n-1), n)
    
    for r in range(max_rounds):
        if time.time() > deadline:
            break
        improved = False
        zeros = np.where(h == 0)[0]
        ones = np.where(h == 1)[0]
        for i in zeros:
            if time.time() > deadline:
                return best_h, best_c
            ak = i + k; akm = i - k
            fi = np.zeros(m)
            m1 = (ak >= 0) & (ak < n)
            fi[m1] = 1.0 - h[ak[m1]]
            m2 = (akm >= 0) & (akm < n)
            fi[m2] -= h[akm[m2]]
            
            # Vectorized g_j for all j in ones
            n_ones = len(ones)
            bk = ones[:, None] + k[None, :]
            bkm = ones[:, None] - k[None, :]
            gb = np.zeros((n_ones, m))
            m3 = (bk >= 0) & (bk < n)
            gb[m3] = h[bk[m3]] - 1.0
            m4 = (bkm >= 0) & (bkm < n)
            gb[m4] += h[bkm[m4]]
            
            # Add fi to all rows
            combined = gb + fi[None, :]
            
            # Corrections: +1 at position n-1+(j-i) for each j
            lags = ones - i
            idx = n - 1 + lags
            valid = (idx >= 0) & (idx < m)
            combined[valid, idx[valid]] += 1.0
            
            # +1 at position n-1+(i-j) for each j
            lags2 = i - ones
            idx2 = n - 1 + lags2
            valid2 = (idx2 >= 0) & (idx2 < m)
            combined[valid2, idx2[valid2]] += 1.0
            
            # Find best j
            new_maxes = (corr[None, :] + combined).max(axis=1) * dx
            best_ri = new_maxes.argmin()
            
            if new_maxes[best_ri] < cur_c - 1e-15:
                j = ones[best_ri]
                h[i] = 1.0; h[j] = 0.0
                corr += combined[best_ri]
                cur_c = new_maxes[best_ri]
                improved = True
                if cur_c < best_c:
                    best_c = cur_c; best_h = h.copy()
                break
        if not improved:
            break
    return best_h, best_c
```

This should be much faster than the previous version. Let me estimate: for n=250, each i-iteration creates arrays of shape (125, 499) ≈ 62K elements, does a few operations on them. That's maybe 50-100μs per i. With 125 i's per round, one round is 6-12ms. We can do 80-160 rounds per second. If convergence takes 50-200 rounds, the local search takes 0.3-2.5 seconds. 

Now, the key question: will this find a better solution than the previous program? The previous program used a similar approach but with the O(n) per pair evaluation (not vectorized over j). The result should be the same (converging to the same local optimum), but much faster, leaving more time for other phases.
