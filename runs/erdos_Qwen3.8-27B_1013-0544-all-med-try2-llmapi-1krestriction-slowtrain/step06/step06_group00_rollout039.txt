Let me also think about whether I should use a different projection. The current projection (iteratively adjusting to meet the sum constraint) might not be the most accurate. A better approach:

The projection onto {0≤h≤1, sum(h)=target} can be done by:
1. Find a threshold τ such that ∑_i clip(h_i - τ, 0, 1) = target
2. Set h_i = clip(h_i - τ, 0, 1)

This is a one-dimensional root-finding problem that can be solved with bisection in O(n log(1/ε)) time.

Let me implement this:

```python
def project_feasible(h, n):
    target = n / 2.0
    # Find τ such that sum(clip(h - τ, 0, 1)) = target
    lo, hi = h.min() - 1.0, h.max() + 1.0
    for _ in range(100):
        mid = (lo + hi) / 2
        s = np.clip(h - mid, 0.0, 1.0).sum()
        if s > target:
            lo = mid
        else:
            hi = mid
    tau = (lo + hi) / 2
    return np.clip(h - tau, 0.0, 1.0)
```

This is much cleaner and more accurate! The bisection converges in O(log((range)/ε)) iterations, which is about 50-60 for double precision. And each iteration is O(n).
