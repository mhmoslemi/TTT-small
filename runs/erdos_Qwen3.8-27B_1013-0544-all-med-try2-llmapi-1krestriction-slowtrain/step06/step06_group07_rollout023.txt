```python
def compute_c5(h):
    dx = 2.0 / len(h)
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def correlate_fft(h, g):
    """Compute full correlation using FFT."""
    n = len(h)
    m = len(g)
    size = n + m - 1
    # Next power of 2 for efficiency
    size_pow2 = 1
    while size_pow2 < size:
        size_pow2 *= 2
    H = fft(h, size_pow2)
    G = fft(g, size_pow2)
    corr = ifft(H * np.conj(G))[:size].real
    return corr

def smooth_max_val(x, beta):
    m = np.max(x)
    shifted = np.clip(beta * (x - m), -700.0, 700.0)
    return m + np.log(np.sum(np.exp(shifted))) / beta

    corr = np.correlate(h, 1.0 - h, mode='full')
    return smooth_max_val(corr, beta) * dx

def con_fun(h, ts):
    return h.sum() - ts

    return np.ones(len(h))
```

```python
        return x[-1]  # minimize C
```

With FFT-accelerated correlation, subgradient at n=1000 takes O(n log n) ≈ 10000 operations per step. In 1000 seconds, we could do maybe 10^7 steps (assuming ~10^4 ops per step including overhead). That's a lot of steps for subgradient.

But subgradient converges slowly (O(1/√T) for general convex, probably worse for non-convex). We'd need a better method.

**Better idea: Use the smooth max (log-sum-exp) with a very high beta, and optimize with L-BFGS-B (which handles box constraints natively).**

L-BFGS-B is efficient for large n because:
- It only needs gradient evaluations (O(n) for the smooth max)
- It handles box constraints (0 ≤ h ≤ 1)
- It uses quasi-Newton second-order info without explicitly forming the Hessian

The issue is the equality constraint ∑h = n/2. L-BFGS-B doesn't handle equality constraints. We can:
1. Parametrize to satisfy the constraint: h[i] = sigmoid(z[i]) and adjust z to make ∑h = n/2
2. Add a penalty: objective + λ(∑h - n/2)²
3. Use a projection after each step

Option 3 (projection) is simplest and should work well since the constraint is linear.

```python
def obj_lbfgs(h, dx, beta, ts):
    """Objective for L-BFGS-B: smooth max + penalty for sum constraint."""
    h_clipped = np.clip(h, 0, 1)
    corr = np.correlate(h_clipped, 1.0 - h_clipped, mode='full')
    obj = smooth_max_val(corr, beta) * dx
    pen = 0.1 * (h_clipped.sum() - ts) ** 2
    return obj + pen

def obj_lbfgs_grad(h, dx, beta, ts):
    h_clipped = np.clip(h, 0, 1)
    corr = np.correlate(h_clipped, 1.0 - h_clipped, mode='full')
    # Gradient of smooth max
    weights = np.exp(beta * (corr - corr.max()))
    weights /= weights.sum()
    # Gradient of smooth max w.r.t. corr: weights
    # Gradient of corr w.r.t. h: need to compute
    # corr = correlate(h, 1-h), d(corr)/d(h[i]) = ...
    # This is complex, let me use finite differences or a different approach
    
    # Actually, for L-BFGS-B, we can just use the penalty approach with a large enough penalty
    # and skip the gradient of the constraint (rely on the method's internal finite differences)
    
    # Alternative: use the fact that for the smooth max, the gradient w.r.t. h is:
    # grad = dx * ∑_k weights[k] * d(corr[k])/d(h)
    # where d(corr[k])/d(h[i]) is the subgradient we already computed
    
    # Let me compute the full gradient
    grad = np.zeros(len(h))
    for k in range(len(corr)):
        if weights[k] < 1e-15:
            continue
        # Subgradient at lag k
        lag = k - (len(h) - 1)
        if lag >= 0:
            idx = np.arange(len(h) - lag)
            grad[idx] += weights[k] * (1.0 - h_clipped[idx + lag]) * dx
            grad[idx + lag] -= weights[k] * h_clipped[idx] * dx
        else:
            la = -lag
            idx = np.arange(len(h) - la)
            grad[idx + la] += weights[k] * (1.0 - h_clipped[idx]) * dx
            grad[idx] -= weights[k] * h_clipped[idx + la] * dx
    
    # Gradient of penalty
    grad += 0.2 * (h_clipped.sum() - ts) * np.ones(len(h))
    
    # Only for non-clipped values
    grad[h < 0] = 0
    grad[h > 1] = 0
    
    return grad
```

Wait, the gradient computation is O(n²) because of the loop over all k. For n=700, that's 490000 operations per gradient evaluation. L-BFGS-B might need 100-1000 gradient evaluations, so total would be 5×10^7 to 5×10^8 operations. That should be fine.

But actually, we can compute the gradient more efficiently using FFT!

The gradient of the smooth max w.r.t. h is:
∇_h [β^{-1} log ∑_k exp(β * corr_k)] = ∑_k w_k * ∇_h corr_k

where w_k = exp(β * corr_k) / ∑_j exp(β * corr_j)

And ∇_h corr_k is the cross-correlation of h with the "subgradient indicator" at lag k. We can compute ∇_h corr_k for all k simultaneously using FFT!

Actually, ∇_h corr_k: corr_k = ∑_i h[i] * (1-h[i+k-lag_k]) for the appropriate indices. The gradient w.r.t. h[j] is:
- (1 - h[j+k-lag]) if j is in range and j+k-lag is valid
- -h[j-k+lag] if j-k+lag is in valid range
- contributions from both

This is essentially the cross-correlation of (1-h) with a "delta" at the appropriate lag, plus the negative of h with a delta at the reflected lag.

For all k simultaneously with weights w_k, the gradient is:
∇h = ∑_k w_k * [correlate_delta(1-h, lag_k) - correlate_delta(h, -lag_k)]

This can be computed as:
∇h[i] = ∑_k w_k * [(1-h[i+lag_k]) * 1_{valid} - h[i-lag_k] * 1_{valid}]

This is a weighted sum of shifts of (1-h) and h, which can be computed using convolution!

∇h = w ⊛ (1-h) - w ⊛ h (with appropriate shifts and boundary handling)

where w is the weight vector w_k.

Actually, this is just: ∇h[i] = ∑_k w_k * (1 - h[i + lag_k]) (with boundary effects)
minus ∑_k w_k * h[i - lag_k] (with boundary effects)

Which can be written as a convolution:
∇h = convolve(w, 1-h) - convolve(w, h) (with appropriate definitions)

Wait, this isn't quite a standard convolution because of the boundary effects. But for the "full" mode correlation, the boundary effects are that for lags where the overlap is partial, the sum is over fewer terms.

Let me just use the direct O(n²) computation for now (it's fine for n≤500) and use FFT only for the correlation evaluation itself.

Let me write the code with the analytical gradient for the smooth max:

The key formula: If f(h) = (1/β) * ln(∑_k exp(β * c_k(h))) where c_k(h) = corr_k(h) * dx, then:
∇f = (dx/β) * ∑_k exp(β*c_k) / ∑_j exp(β*c_j) * ∇c_k
    = dx * ∑_k w_k * ∇c_k

where w_k = softmax(β * corr) (normalized).

And ∇c_k (the gradient of the k-th correlation value w.r.t. h) is:
For lag = k - (n-1):
- If lag ≥ 0: ∇c_k[j] = (1-h[j+lag]) for j=0..n-1-lag, and ∇c_k[j] = -h[j-lag] for j=lag..n-1
- If lag < 0: similar with sign flipped

Actually, let me be more careful. The correlation is:
corr[k] = ∑_i h[i] * (1-h[i + k - (n-1)])

where the sum is over i such that both indices are in [0, n-1].

Let lag = k - (n-1).

If lag ≥ 0:
corr[k] = ∑_{i=0}^{n-1-lag} h[i] * (1 - h[i+lag])
∂/∂h[j] = (1-h[j+lag]) for j = 0..n-1-lag (from the first term)
          - h[j-lag] for j = lag..n-1 (from the second term)

If lag < 0 (let la = -lag):
corr[k] = ∑_{i=la}^{n-1} h[i] * (1 - h[i-la])
∂/∂h[j] = (1-h[j-la]) for j = la..n-1
          - h[j+la] for j = 0..n-1-la

This is what the subgrad_h function computes (without the weighting).

So the full gradient is:
∇f[h] = dx * ∑_k w_k * subgrad_h(h, k, n)

This is O(n²) per gradient evaluation (sum over n lags, each O(n)).

For n=70: 70*70 = 4900 ops per gradient. Very fast.
For n=500: 500*500 = 250000 ops per gradient. Still fast.
For n=2000: 2000*2000 = 4,000,000 ops per gradient. Getting expensive.

So for n up to ~1000, the analytical gradient is feasible.

```python
import numpy as np
from scipy.optimize import minimize, Bounds
import time

def compute_c5(h):
    dx = 2.0 / len(h)
    corr = np.correlate(h, 1.0 - h, mode='full')
    return float(np.max(corr) * dx)

def smooth_max_val(x, beta):
    m = np.max(x)
    shifted = np.clip(beta * (x - m), -700.0, 700.0)
    return m + np.log(np.sum(np.exp(shifted))) / beta

def corr_grad_single(k, n):
    lag = k - (n - 1)
    g1 = np.zeros(n)
    g2 = np.zeros(n)
    if lag >= 0:
        idx = np.arange(n - lag)
        g1[idx] = 1.0
        g2[idx + lag] = 1.0
    else:
        la = -lag
        idx = np.arange(n - la)
        g1[idx + la] = 1.0
        g2[idx] = 1.0
    return g1, g2

def obj_smooth(h, dx, beta):
    corr = np.correlate(h, 1.0 - h, mode='full')
    return smooth_max_val(corr, beta) * dx

def grad_smooth(h, dx, beta):
    n = len(h)
    corr = np.correlate(h, 1.0 - h, mode='full')
    m = np.max(corr)
    w = np.exp(np.clip(beta * (corr - m), -700.0, 700.0))
    w_sum = w.sum()
    grad = np.zeros(n)
    for k in range(len(corr)):
        wk = w[k] / w_sum * dx
        if wk < 1e-12:
            continue
        lag = k - (n - 1)
        if lag >= 0:
            idx = np.arange(n - lag)
            grad[idx] += wk * (1.0 - h[idx + lag])
            grad[idx + lag] -= wk * h[idx]
        else:
            la = -lag
            idx = np.arange(n - la)
            grad[idx + la] += wk * (1.0 - h[idx])
            grad[idx] -= wk * h[idx + la]
    return grad

def con_fun(h, ts):
    return h.sum() - ts

def con_jac(h, ts):
    return np.ones(len(h))

def project_feasible(h, target_sum):
    h = np.clip(h, 0.0, 1.0)
    for _ in range(100):
        s = h.sum()
        diff = target_sum - s
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            mask = h < 1.0
        else:
            mask = h > 0.0
        cnt = mask.sum()
        if cnt == 0:
            break
        h[mask] += diff / cnt
        h = np.clip(h, 0.0, 1.0)
    return h

def resample_h(h_old, n_new):
    x_old = np.linspace(0, 2, len(h_old), endpoint=False)
    x_new = np.linspace(0, 2, n_new, endpoint=False)
    return np.interp(x_new, x_old, h_old)

def subgrad_h(h, k, n):
    lag = k - (n - 1)
    grad = np.zeros(n)
    if lag >= 0:
        idx = np.arange(n - lag)
        grad[idx] += (1.0 - h[idx + lag])
        grad[idx + lag] -= h[idx]
    else:
        la = -lag
        idx = np.arange(n - la)
        grad[idx + la] += (1.0 - h[idx])
        grad[idx] -= h[idx + la]
    return grad

def obj_pen(h, dx, beta, ts, pen_w):
    hc = np.clip(h, 0.0, 1.0)
    corr = np.correlate(hc, 1.0 - hc, mode='full')
    return smooth_max_val(corr, beta) * dx + pen_w * (hc.sum() - ts) ** 2

def run(seed=42, budget_s=1100, **kwargs):
    np.random.seed(seed)
    t0 = time.time()

    def tl():
        return budget_s - (time.time() - t0)

    if 'initial_h_values' in globals() and initial_h_values is not None:
        h_init = np.array(initial_h_values, dtype=float).copy()
    else:
        h_init = np.full(70, 0.5)

    n = len(h_init)
    dx = 2.0 / n
    target_sum = float(n) / 2.0

    best_h = project_feasible(h_init, target_sum)
    best_c5 = compute_c5(best_h)

    # Phase 1: SLSQP with analytical gradient and continuation
    bounds = Bounds(np.zeros(n), np.ones(n))
    cons = [{'type': 'eq', 'fun': con_fun, 'jac': con_jac, 'args': (target_sum,)}]

    for beta in [10, 50, 200, 1000, 5000, 20000, 80000]:
        if tl() < 30:
            break
        for trial in range(3):
            if tl() < 15:
                break
            x0 = best_h.copy()
            if trial > 0:
                scale = 0.015 / trial
                x0 = x0 + np.random.randn(n) * scale
                x0 = project_feasible(x0, target_sum)
            try:
                res = minimize(obj_smooth, x0, jac=grad_smooth, args=(dx, beta),
                               method='SLSQP', bounds=bounds, constraints=cons,
                               options={'maxiter': 8000, 'ftol': 1e-16})
                h_new = project_feasible(res.x, target_sum)
                c5 = compute_c5(h_new)
                if c5 < best_c5:
                    best_h = h_new.copy()
                    best_c5 = c5
            except Exception:
                pass

    # Phase 2: Subgradient with momentum at current resolution
    if tl() > 120:
        h = best_h.copy()
        velocity = np.zeros(n)
        lr = 0.003
        for it in range(100000):
            if tl() < 30:
                break
            corr = np.correlate(h, 1.0 - h, mode='full')
            k_worst = np.argmax(corr)
            g = subgrad_h(h, k_worst, n)
            lr_t = lr / (1.0 + it * 0.0003)
            velocity = 0.85 * velocity - lr_t * g
            h = h + velocity
            h = project_feasible(h, target_sum)
            if it % 2000 == 1999:
                c5 = compute_c5(h)
                if c5 < best_c5:
                    best_h = h.copy()
                    best_c5 = c5
        c5 = compute_c5(h)
        if c5 < best_c5:
            best_h = h.copy()
            best_c5 = c5

    # Phase 3: Multi-resolution warm-start optimization
    if tl() > 100:
        resolutions = []
        base = n
        resolutions.append(base + 20)
        resolutions.append(base + 50)
        resolutions.append(base + 100)
        resolutions.append(base + 200)
        resolutions.append(base + 400)

        for n_try in resolutions:
            if tl() < 50:
                break
            if n_try <= n:
                continue
            dx_t = 2.0 / n_try
            ts_t = float(n_try) / 2.0
            h_t = resample_h(best_h, n_try)
            h_t = project_feasible(h_t, ts_t)
            bnds_t = Bounds(np.zeros(n_try), np.ones(n_try))
            cons_t = [{'type': 'eq', 'fun': con_fun, 'jac': con_jac, 'args': (ts_t,)}]

            # L-BFGS-B with penalty (good for larger n)
            for beta in [500, 5000]:
                if tl() < 25:
                    break
                try:
                    res = minimize(obj_pen, h_t, args=(dx_t, beta, ts_t, 5.0),
                                   method='L-BFGS-B',
                                   options={'maxiter': 2000, 'ftol': 1e-14})
                    h_new = project_feasible(res.x, ts_t)
                    c5 = compute_c5(h_new)
                    if c5 < best_c5:
                        best_h = h_new.copy()
                        best_c5 = c5
                        n = n_try
                        dx = dx_t
                        target_sum = ts_t
                        bounds = bnds_t
                        cons = cons_t
                except Exception:
                    pass

            # SLSQP with gradient at higher resolution
            if n_try <= 300 and tl() > 25:
                for beta in [2000, 10000]:
                    if tl() < 20:
                        break
                    try:
                        res = minimize(obj_smooth, best_h, jac=grad_smooth,
                                       args=(dx_t, beta), method='SLSQP',
                                       bounds=bnds_t, constraints=cons_t,
                                       options={'maxiter': 5000, 'ftol': 1e-15})
                        h_new = project_feasible(res.x, ts_t)
                        c5 = compute_c5(h_new)
                        if c5 < best_c5:
                            best_h = h_new.copy()
                            best_c5 = c5
                            n = n_try
                            dx = dx_t
                            target_sum = ts_t
                            bounds = bnds_t
                            cons = cons_t
                    except Exception:
                        pass

    # Phase 4: Final polish with very high beta
    if tl() > 15:
        for beta in [50000, 200000]:
            if tl() < 10:
                break
            try:
                res = minimize(obj_smooth, best_h, jac=grad_smooth, args=(dx, beta),
                               method='SLSQP', bounds=bounds, constraints=cons,
                               options={'maxiter': 10000, 'ftol': 1e-16})
                h_new = project_feasible(res.x, target_sum)
                c5 = compute_c5(h_new)
                if c5 < best_c5:
                    best_h = h_new.copy()
                    best_c5 = c5
            except Exception:
                pass

    # Phase 5: Nelder-Mead polish on a smoothed objective
    if tl() > 20:
        def nm_obj(h):
            hc = np.clip(h, 0.0, 1.0)
            corr = np.correlate(hc, 1.0 - hc, mode='full')
            return smooth_max_val(corr, 5000) * dx + 10.0 * (hc.sum() - target_sum) ** 2
        try:
            res = minimize(nm_obj, best_h, method='Nelder-Mead',
                           options={'maxiter': 3000, 'xatol': 1e-10, 'fatol': 1e-14, 'adaptive': True})
            h_new = project_feasible(res.x, target_sum)
            c5 = compute_c5(h_new)
            if c5 < best_c5:
                best_h = h_new.copy()
                best_c5 = c5
        except Exception:
            pass

    return best_h, best_c5, len(best_h)
```
