Alternative: Instead of finding the globally best swap, find a "good enough" swap quickly.

**Heuristic: Only check the bottleneck lag.**

For the bottleneck lag k* (index k*_idx in the corr array):
- The contribution of swap (i,j) to corr[k*_idx] is:
  d1[i][k*_idx] + D0[j][k*_idx]
  
- We want to minimize this (to reduce the bottleneck).

So we can:
1. Compute d1[i][k*_idx] for all zeros i. (O(n_zeros * 1))
2. Compute D0[j][k*_idx] for all ones j. (O(n_ones * 1))
3. The best swap minimizes d1[i][k*_idx] + D0[j][k*_idx], which is achieved by the i with smallest d1[i][k*_idx] and the j with smallest D0[j][k*_idx].
4. Apply that swap.
5. Verify that no other lag exceeds the new max (O(n) check).
6. If it does, try the next best combination.

This is much faster! Each step is O(n) for the check, and we only need a few steps.

```python
            if s < 1e-14:

def slsqp_smooth(h, n, alpha, maxiter, deadline):
    dx = 2.0 / n
    def obj(x):
        g = np.correlate(x, 1 - x, mode='full') * dx
        m = g.max()
        sh = alpha * (g - m)
        sm = sh.max()
        return m + (sm + np.log(np.exp(sh - sm).sum())) / alpha
    def cons_fun(x):
        return x.sum() - n / 2.0
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': cons_fun}]
    try:
        res = minimize(obj, h, method='SLSQP', bounds=bounds,
                       constraints=cons, options={'maxiter': maxiter, 'ftol': 1e-15})
        return project_feasible(res.x, n)
    except Exception:
        return h
```

```python
            msk2 = (imn >= 0) & (imn < n)
            s[msk2] -= x[imn[msk2]]
            grad[j] = dx * np.dot(s, p)
        return grad
    def cons_fun(x):
        return x.sum() - n / 2.0
    def cons_grad(x):
        return np.ones(n)
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': cons_fun, 'jac': cons_grad}]
    try:
        res = minimize(obj, h, jac=grad, method='SLSQP', bounds=bounds,
                       constraints=cons, options={'maxiter': maxiter, 'ftol': 1e-14})
        return project_feasible(res.x, n)
    except Exception:
        return h
```

The gradient computation is O(n²) = O(62500) per call. SLSQP might call it 100-1000 times, so total O(6.25M - 62.5M). Fast enough.

But wait, I can vectorize the gradient computation! Instead of looping over j, I can use the structure:

grad[j] = dx * sum_k p[k+n-1] * [(1-x[j+k]) - x[j-k]] (with bounds)

= dx * sum_k p[k+n-1] * (1-x[j+k]) - dx * sum_k p[k+n-1] * x[j-k]

The first term is dx * (convolution of p with (1-x)) evaluated at positions 0,...,n-1.
The second term is dx * (convolution of p with x) evaluated at positions 0,...,n-1 (with some sign/shift).

Actually, let me think about this more carefully.

For a fixed j, the sum over k of p[k+n-1] * (1-x[j+k]) where 0 ≤ j+k < n.

Let m = j+k, so k = m-j. The sum becomes:
sum_m p[m-j+n-1] * (1-x[m]) where 0 ≤ m < n and -(n-1) ≤ m-j ≤ n-1, i.e., j-(n-1) ≤ m ≤ j+(n-1).

Since 0 ≤ m < n and 0 ≤ j < n, the valid range of m is max(0, j-(n-1)) to min(n-1, j+(n-1)) = 0 to n-1 (since j-(n-1) ≤ 0 and j+(n-1) ≥ n-1 for j in [0, n-1]).

So the sum is: sum_{m=0}^{n-1} p[m-j+n-1] * (1-x[m]) where we define p[m-j+n-1] = 0 if m-j+n-1 < 0 or ≥ 2n-1.

This is a correlation of x with p! Specifically:
sum_m (1-x[m]) * p[m-(j-(n-1))]

This is the cross-correlation of (1-x) and p, evaluated at lag j-(n-1).

In numpy: np.correlate(1-x, p, mode='full')[j] gives sum_m (1-x)[m] * p[m-j] (depending on the exact definition).

Actually, np.correlate(a, v, mode='full')[k] = sum_i a[i+k-len(v)+1] * v[i] for the full mode. This is getting confusing.

Let me just use the direct formula and accept O(n²) per gradient evaluation. For n=250, that's 62500 operations, which is fast.

Let me now write the complete solution. I'll focus on:
1. Fast binary local search (for getting a good starting point).
2. SLSQP with gradient (for the main optimization).
3. Multiple restarts and different n values.

Let me be careful about the time budget. The total budget is 1100s. I'll allocate:
- Phase 1 (binary search): 200s
- Phase 2 (SLSQP): 500s
- Phase 3 (restarts + more SLSQP): 300s
- Phase 4 (final polish): 100s

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1 - h, mode='full')
    return float(np.max(c) * dx)

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h, 0.0, 1.0)
    for _ in range(200):
        diff = target - h.sum()
        if abs(diff) < 1e-12:
            break
        if diff > 0:
            room = 1.0 - h
            s = room.sum()
            if s < 1e-14: break
            h = h + diff / s * room
        else:
            s = h.sum()
            if s < 1e-14: break
            h = h + diff / s * h
    return np.clip(h, 0.0, 1.0)

def smooth_obj(x, n, alpha):
    dx = 2.0 / n
    g = np.correlate(x, 1 - x, mode='full') * dx
    m = g.max()
    sh = alpha * (g - m)
    sm = sh.max()
    return m + (sm + np.log(np.exp(sh - sm).sum())) / alpha

def smooth_grad(x, n, alpha):
    dx = 2.0 / n
    g = np.correlate(x, 1 - x, mode='full') * dx
    m = g.max()
    sh = alpha * (g - m)
    sm = sh.max()
    e = np.exp(sh - sm)
    p = e / e.sum()
    grad = np.zeros(n)
    m_range = np.arange(-(n-1), n)
    for j in range(n):
        im = j + m_range
        imn = j - m_range
        s = np.zeros(2*n-1)
        msk = (im >= 0) & (im < n)
        s[msk] += 1.0 - x[im[msk]]
        msk2 = (imn >= 0) & (imn < n)
        s[msk2] -= x[imn[msk2]]
        grad[j] = dx * np.dot(s, p)
    return grad

def slsqp_opt(h, n, alpha, maxiter, deadline):
    dx = 2.0 / n
    def obj(x):
        return smooth_obj(x, n, alpha)
    def grad(x):
        return smooth_grad(x, n, alpha)
    def cons_fun(x):
        return x.sum() - n / 2.0
    def cons_grad(x):
        return np.ones(n)
    bounds = [(0.0, 1.0)] * n
    cons = [{'type': 'eq', 'fun': cons_fun, 'jac': cons_grad}]
    try:
        res = minimize(obj, h, jac=grad, method='SLSQP', bounds=bounds,
                       constraints=cons, options={'maxiter': maxiter, 'ftol': 1e-14})
        return project_feasible(res.x, n)
    except Exception:
        return h

    h_b = np.where(h >= 0.5, 1.0, 0.0)
    excess = int(h_b.sum()) - n // 2
    if excess > 0:
        ones = np.where(h_b == 1)[0]
