Actually, let me think about this differently. B_j[k] = h[j+lag_k]*valid(j+lag_k) - (1-h[j-lag_k])*valid(j-lag_k)

For binary h, h[j+lag_k] is either 0 or 1, and (1-h[j-lag_k]) is either 0 or 1.

So B_j[k] ∈ {-1, 0, 1}.

And A[k] ∈ {-1, 0, 1} as well.

So Δg[k] = (A[k] + B_j[k]) * dx ∈ {-2dx, -dx, 0, dx, 2dx}.

The new max is max_k (g[k] + Δg[k]).

For the max to decrease, we need Δg[k] ≤ 0 for all k where g[k] is near the maximum, and Δg[k] < 0 for at least one such k.

This gives us a way to quickly reject bad (i,j) pairs: if A[k] + B_j[k] > 0 for any k where g[k] = max(g), then this swap won't help.

```python
def binary_local_search_v2(h, n, deadline):
    dx = 2.0 / n
    c = np.correlate(h, 1 - h, mode='full')
    g = c * dx
    best_c = g.max()
    lags = np.arange(2*n-1) - (n-1)
    
    ones = set(np.where(h == 1)[0].tolist())
    zeros = set(np.where(h == 0)[0].tolist())
    
    improved = True
    while improved and time.time() < deadline:
        improved = False
        for i in sorted(zeros):
            if time.time() > deadline:
                break
            # Compute A for this i
            i_l = i - lags
            i_p = i + lags
            v_im = (i_l >= 0) & (i_l < n)
            v_ip = (i_p >= 0) & (i_p < n)
            h_im = np.zeros(2*n-1)
            h_ip = np.zeros(2*n-1)
            h_im[v_im] = h[i_l[v_im]]
            h_ip[v_ip] = h[i_p[v_ip]]
            A = (1 - h_im) * v_im - h_ip * v_ip
            
            # For each j in ones, compute B_j and check if max decreases
            best_j = -1
            best_max = best_c
            for j in list(ones):
                j_l = j - lags
                j_p = j + lags
                v_jl = (j_l >= 0) & (j_l < n)
                v_jp = (j_p >= 0) & (j_p < n)
                B = np.zeros(2*n-1)
                B[v_jp] += h[j_p[v_jp]]
                B[v_jl] -= (1 - h[j_l[v_jl]])
                
                new_max = np.max(g + (A + B) * dx)
                if new_max < best_max - 1e-15:
                    best_max = new_max
                    best_j = j
            
            if best_j != -1:
                # Make the swap
                h[i] = 1.0
                h[best_j] = 0.0
                zeros.remove(i)
                zeros.add(best_j)
                ones.remove(best_j)
                ones.add(i)
                g = np.correlate(h, 1-h, mode='full') * dx
                best_c = g.max()
                improved = True
    
    return h, best_c
```

This should work. The inner loop (over j) is O(n * 2n) = O(n^2) per i, and the outer loop is O(n) per pass, giving O(n^3) per pass. With early termination and numpy vectorization, this should be fast enough.

For n=250: one pass is about 250 * 125 * 500 ≈ 15.6 million simple operations. In numpy with vectorization, the inner loop (over j) can be partially vectorized.

Actually, let me vectorize the inner loop. For a fixed i, I need to compute B_j for all j simultaneously.

B_j[k] = h[j+lag_k]*valid(j+lag_k) - (1-h[j-lag_k])*valid(j-lag_k)

If I create a matrix M where M[j_idx, k] = B_j[k] for the j_idx-th one position, I can compute max_k(g[k] + (A[k] + M[j_idx, k]) * dx) for all j_idx at once.

The matrix M has shape (n/2, 2n-1) = (125, 499) for n=250. That's 62,500 elements.

M[j_idx, k] = h[j_idx + lags[k]] * valid + h[j_idx - lags[k]] * valid'

This is a Toeplitz-like matrix that can be constructed efficiently.

```python
def binary_zero_scan(h, n, i, ones, g, dx, lags):
    """For a fixed zero position i, find the best one position j to swap with."""
    i_l = i - lags
    i_p = i + lags
    v_im = (i_l >= 0) & (i_l < n)
    v_ip = (i_p >= 0) & (i_p < n)
    A = np.zeros(2*n-1)
    A[v_im] += (1 - h[i_l[v_im]])
    A[v_ip] -= h[i_p[v_ip]]
    
    # B[j_idx, k] for all j in ones
    ones_arr = np.array(ones)
    jm = ones_arr[:, None] - lags[None, :]  # shape (n_ones, 2n-1)
    jp = ones_arr[:, None] + lags[None, :]
    vjm = (jm >= 0) & (jm < n)
    vjp = (jp >= 0) & (jp < n)
    
    # h[j+lag] and h[j-lag]
    h_jp = np.zeros_like(jm, dtype=float)
    h_jm = np.zeros_like(jm, dtype=float)
    h_jp[vjp] = h[jp[vjp]]
    h_jm[vjm] = h[jm[vjm]]
    
    B = h_jp * vjp - (1 - h_jm) * vjm  # shape (n_ones, 2n-1)
    
    # new_g[j_idx, k] = g[k] + (A[k] + B[j_idx, k]) * dx
    new_g_max = np.max(g[None, :] + (A[None, :] + B) * dx, axis=1)
    
    best_idx = np.argmin(new_g_max)
    return best_idx, new_g_max[best_idx]
```

This is O(n_ones * 2n) = O(n^2) per zero position, which is about 62,500 operations for n=250. Very fast!
