$c_k = \sum_i h[i+k] \cdot (1-h[i])$ where the sum is over i such that $0 \leq i \leq n-1$ and $0 \leq i+k \leq n-1$.

So for a fixed j, h[j] appears in $c_k$ as:
- $h[j] \cdot (1-h[j-k])$ when $j = i+k$ (i.e., $i = j-k$), valid if $0 \leq j-k \leq n-1$
- $h[j+k] \cdot (1-h[j])$ when $j = i$, valid if $0 \leq j+k \leq n-1$

So $\frac{\partial c_k}{\partial h[j]} = (1-h[j-k]) \cdot \mathbb{1}[0 \leq j-k \leq n-1] - h[j+k] \cdot \mathbb{1}[0 \leq j+k \leq n-1]$

This is correct. The subgradient of $\max_k c_k$ at h is $\nabla c_{k^*}$ where $k^*$ is a (random) argmax.

Projected subgradient descent:
1. Compute $k^* = \arg\max_k c_k$
2. Compute $g_j = \frac{\partial c_{k^*}}{\partial h[j]}$
3. Update: $h \leftarrow h - \eta \cdot g$
4. Project onto $\{h: 0 \leq h \leq 1, \sum h = n/2\}$
5. Repeat

```python
            if s < 1e-14:
                break
            h += (diff / s) * h
            h = np.clip(h, 0.0, 1.0)

        sm = sh.max()

                       constraints=cons, options={'maxiter': maxiter, 'ftol': 1e-15})
        return project_feasible(res.x, n)

def subgradient_descent(h, n, deadline, n_iter=5000):
    """Projected subgradient descent on the max correlation."""
    dx = 2.0 / n
    h = h.copy()
    best_c = compute_c5(h, n)
    best_h = h.copy()
    
    # Initial step size
    eta = 0.1
    eta_min = 1e-6
    n_range = np.arange(-(n-1), n)  # lags in np.correlate indexing
    
    for it in range(n_iter):
        if time.time() > deadline:
            break
        
        corr = compute_corr(h, n)
        c = corr * dx
        k_star = np.argmax(corr)  # index in the full correlation array
        k = k_star - (n - 1)  # actual lag
        
        # Compute gradient of c_{k_star} w.r.t. h
        grad = np.zeros(n)
        for j in range(n):
            # h[j] appears as h[j] in the "source" and h[j] in the "target"
            # c_k = sum_i h[i+k](1-h[i])
            # h[j] appears when:
            #   i+k = j => i = j-k, valid if 0 <= j-k <= n-1
            #   i = j, valid if 0 <= j+k <= n-1
            g = 0.0
            if 0 <= j - k <= n - 1:
                g += (1.0 - h[j - k])
            if 0 <= j + k <= n - 1:
                g -= h[j + k]
            grad[j] = g
        
        # Update
        h_new = h - eta * grad / dx  # scale by dx to get proper units
        h_new = project_feasible(h_new, n)
        
        c_new = compute_c5(h_new, n)
        if c_new < best_c:
            best_c = c_new
            best_h = h_new.copy()
            h = h_new
            # Keep eta or increase slightly
            eta = min(eta * 1.05, 1.0)
        else:
            h = h_new  # still move (for exploration)
            eta = max(eta * 0.95, eta_min)
    
    return best_h, best_c
```

```python
def compute_grad_at_lag(h, n, k):
    """Compute gradient of c_k = sum_i h[i+k](1-h[i]) w.r.t. h."""
    grad = np.zeros(n)
    # h[j] appears as h[j] in position i+k=j, i=j-k
    if k >= 0:
        # i ranges from 0 to n-1-k, so i+k ranges from k to n-1
        # h[j] for j in [k, n-1] appears as h[j] * (1-h[j-k])
        # derivative: (1-h[j-k])
        grad[k:] += (1 - h[:n-k])
        # h[j] for j in [0, n-1-k] appears as h[j+k] * (1-h[j])
        # derivative: -h[j+k]
        grad[:n-k] -= h[k:]
    else:
        k_abs = -k
        # i ranges from k_abs to n-1, so i+k ranges from 0 to n-1-k_abs
        # h[j] for j in [0, n-1-k_abs] appears as h[j] * (1-h[j+k_abs])
        # derivative: (1-h[j+k_abs])
        grad[:n-k_abs] += (1 - h[k_abs:])
        # h[j] for j in [k_abs, n-1] appears as h[j-k_abs] * (1-h[j])
        # derivative: -h[j-k_abs]
        grad[k_abs:] -= h[:n-k_abs]
    return grad
```

For binary h, the cross terms are: at lag j-i, we get +1 (the new 1 at i and old 1 at j now "overlap"), and at lag i-j similarly.

```python
            zeros[zeros.index(i)] = j
            if nc < best_c:
                best_c = nc
                best_h = h_bin.copy()
    
    return best_h, best_c * dx
```

This is O(n) per random try (for the delta computation). With 100000 tries, that's 25M operations, which should take about 1-2 seconds. Much faster than the O(n³) per sweep approach!

But the issue is that random tries are very inefficient - we need to try many random pairs before finding one that improves. The greedy approach (trying all pairs in order) is more efficient per swap but takes longer per sweep.

**Hybrid approach**: 
- First, do a few full sweeps (greedy) to get to a local optimum
- Then, do many random tries to escape the local optimum (like simulated annealing)
- Then, do more greedy sweeps

With 500s for binary search and O(n) per random try (≈ 0.1ms per try), we can do about 5 million random tries. That should be enough to explore the space well.

Actually, let me benchmark: for n=250, the delta computation involves:
- 4 array operations on arrays of length 499 (the m_range based computations)
- A max over 499 elements

This is about 5 × 499 = 2500 basic operations, which in NumPy is probably ~5-10 μs. So 500s / 10μs = 50 million tries. That's a LOT.

But wait, Python overhead per iteration is probably 50-100 μs (function calls, indexing, etc.). So realistically maybe 5-10 million tries in 500s. Still a lot.

The key question is: how many random tries are needed to find a better solution? If the landscape is "rough" (many local optima), we might need millions of tries. If it's "smooth", a few thousand might suffice.

**Let me also consider: what if we precompute the delta for all pairs?**

For a fixed h, the delta for each pair (i, j) can be precomputed. But there are n²/4 ≈ 15625 pairs, and each delta is a vector of length 499. So the total storage is 15625 × 499 × 8 bytes ≈ 62 MB. That's feasible!

But the issue is that after each swap, all the deltas change. So we'd need to recompute them after each accepted swap. If we do this every, say, 100 accepts, we can amortize the cost.

**Precomputed delta approach:**
1. Precompute deltas for all pairs: O(n³) = 15.6M operations
2. Find the best swap: O(n²) = 62500 max computations (each O(1) if we precompute the max of corr + delta)

Wait, the max of corr + delta for each pair is still O(n) = O(499). So finding the best swap is O(n² × n) = O(n³) = 15.6M. Same as computing all deltas.

So the total cost per "iteration" (precompute + find best + apply) is O(n³) ≈ 15.6M operations ≈ 15ms in NumPy. In 500s, we can do about 33000 such iterations. That's a lot!

But wait, after applying a swap, the deltas for ALL pairs change (because h changed). So we can't just incrementally update. We'd need to recompute from scratch each time, which is O(n³) per iteration. In 500s, that's only about 33000 iterations, and each one only applies one swap. That's not great.

Actually, the delta for a pair (i, j) depends on the current h. If we only change one pair (say (i*, j*)), then the delta for other pairs (i, j) changes only if they involve positions i* or j*. So the number of affected pairs is O(n) (all pairs involving i* or j*). We can update those in O(n²) time.

But this is getting complicated. Let me just go with the simple random approach, which is easy to implement and should work well enough.

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h, n):
    dx = 2.0 / n
    c = np.correlate(h, 1 - h, mode='full')
    return float(np.max(c) * dx)

def project_feasible(h, n):
    target = n / 2.0
    h = np.clip(h, 0.0, 1.0).copy()
    for _ in range(500):
        diff = target - h.sum()
        if abs(diff) < 1e-14:
            break
        if diff > 0:
            room = 1.0 - h
            s = room.sum()
            if s < 1e-14:
                break
            h += (diff / s) * room
            h = np.clip(h, 0.0, 1.0)
        else:
            s = h.sum()
            if s < 1e-14:
                break
            h += (diff / s) * h
            h = np.clip(h, 0.0, 1.0)
    return h

def slsqp_smooth(h, n, alpha, maxiter, deadline):
    def obj(x):
        c = np.correlate(x, 1 - x, mode='full')
        m = c.max()
        sh = alpha * (c - m)
        sm = sh.max()
        return m + (sm + np.log(np.exp(sh - sm).sum())) / alpha
    def cons(x):
        return x.sum() - n / 2.0
    bounds = [(0.0, 1.0)] * n
    cons_list = [{'type': 'eq', 'fun': cons}]
    try:
        res = minimize(obj, h.copy(), method='SLSQP', bounds=bounds,
                       constraints=cons_list, options={'maxiter': maxiter, 'ftol': 1e-15})
        return project_feasible(res.x, n)
    except:
        return h

def grad_subgradient(h, n, deadline, max_iter=20000):
    """Projected subgradient descent."""
    dx = 2.0 / n
    h = h.copy()
    best_c = compute_c5(h, n)
    best_h = h.copy()
    eta = 0.05
    rng = np.random.RandomState(0)
    
    for it in range(max_iter):
        if time.time() > deadline:
            break
        corr = np.correlate(h, 1-h, mode='full')
        # Pick a random argmax (to avoid bias)
        max_val = corr.max()
        argmaxes = np.where(corr >= max_val - 1e-10)[0]
        k_star = argmaxes[rng.randint(len(argmaxes))]
        k = k_star - (n - 1)
        
        # Compute gradient of c_k w.r.t. h
        grad = np.zeros(n)
        if k >= 0:
            grad[k:] += (1 - h[:n-k])
            grad[:n-k] -= h[k:]
        else:
            ka = -k
            grad[:n-ka] += (1 - h[ka:])
            grad[ka:] -= h[:n-ka]
        
        h_new = project_feasible(h - eta * grad, n)
        c_new = compute_c5(h_new, n)
        if c_new < best_c:
            best_c = c_new
            best_h = h_new.copy()
            h = h_new
        else:
            h = h_new
            eta = max(eta * 0.98, 0.001)
    
    return best_h, best_c

def random_swap_search(h, n, deadline, max_tries=2000000, seed=42):
    """Fast random swap search for binary solutions."""
    dx = 2.0 / n
    target = n // 2
    m_range = np.arange(-(n-1), n)
    rng = np.random.RandomState(seed)
    
    idx = np.argsort(h)[::-1]
    h_bin = np.zeros(n)
    h_bin[idx[:target]] = 1.0
    
    corr = np.correlate(h_bin, 1 - h_bin, mode='full').astype(float)
    cur_max = corr.max()
    best_c = cur_max * dx
    best_h = h_bin.copy()
    
    ones = np.where(h_bin == 1)[0].tolist()
    zeros = np.where(h_bin == 0)[0].tolist()
    
    for t in range(max_tries):
        if time.time() > deadline:
            break
        i = zeros[rng.randint(len(zeros))]
        j = ones[rng.randint(len(ones))]
        
        # Compute delta
        delta = np.zeros(2*n - 1)
        im = i + m_range
        imn = i - m_range
        jm = j + m_range
        jmn = j - m_range
        msk = (im >= 0) & (im < n)
        delta[msk] += 1.0 - h_bin[im[msk]]
        msk = (imn >= 0) & (imn < n)
        delta[msk] -= h_bin[imn[msk]]
        msk = (jm >= 0) & (jm < n)
        delta[msk] -= 1.0 - h_bin[jm[msk]]
        msk = (jmn >= 0) & (jmn < n)
        delta[msk] += h_bin[jmn[msk]]
        delta[n-1] -= 2.0
        k1 = n-1 + (j-i)
        if 0 <= k1 < 2*n-1:
            delta[k1] += 1.0
        k2 = n-1 + (i-j)
        if 0 <= k2 < 2*n-1:
            delta[k2] += 1.0
        
        new_corr = corr + delta
        nc = new_corr.max()
        
        if nc < cur_max - 1e-12:
            h_bin[i] = 1.0
            h_bin[j] = 0.0
            corr = new_corr
            cur_max = nc
            ones[j] = i  # replace j with i in ones
            i_idx = zeros.index(i)
            zeros[i_idx] = j  # replace i with j in zeros
            if nc < best_c / dx:
                best_c = nc * dx
                best_h = h_bin.copy()
    
    return best_h, best_c
