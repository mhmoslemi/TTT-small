                if i == j:
                    continue
                delta = np.zeros(2*n-1)
                im = i + mr
                msk = (im >= 0) & (im < n)
                delta[msk] += 1.0 - h[im[msk]]
                imn = i - mr
                msk = (imn >= 0) & (imn < n)
                delta[msk] -= h[imn[msk]]
                jm = j + mr
                msk = (jm >= 0) & (jm < n)
                delta[msk] -= 1.0 - h[jm[msk]]
                jmn = j - mr
                msk = (jmn >= 0) & (jmn < n)
                delta[msk] += h[jmn[msk]]
                delta[n-1] -= 2.0
                k1 = n-1 + (j-i)
                delta[k1] += 1.0
                k2 = n-1 + (i-j)
                delta[k2] += 1.0
                new_corr = corr + delta
                nc = float(new_corr.max() * dx)
                if nc < cur_c - 1e-15:
                    h[i] = 1.0
                    h[j] = 0.0
                    corr = new_corr
                    cur_c = nc
                    improved = True
                    break
            if improved:
                break
        if not improved:
            break
    if cur_c < best_c:
        best_c = cur_c
        best_h = h.copy()
    return best_h, best_c

Let me also add another idea: instead of random swaps, try "smart" swaps. For example, find the lag k* that achieves the max, and try to reduce the correlation at that lag specifically.

For lag k*, the correlation is Σ_m h[m](1-h[m+k*]). To reduce this, we want to:
- Change h[m] from 1 to 0 where h[m+k*] = 0 (reduces the sum)
- Change h[m] from 0 to 1 where h[m+k*] = 0 (increases but... wait)
- Actually: changing h[m] from 1 to 0 reduces the sum by (1-h[m+k*]) = 1 (if h[m+k*]=0)
- Changing h[m+k*] from 0 to 1 reduces the sum by h[m] = 1 (if h[m]=1)

So the "smart" move is: find a position m where h[m]=1 and h[m+k*]=0. Swap h[m] with some h[j]=0 (j ≠ m+k*). Or better: swap h[m] with h[m+k*] (set h[m]=0, h[m+k*]=1). This directly reduces the correlation at lag k* by 1.

But this might increase other lags. The net effect depends on the full delta.

Let me implement a "directed" SA that preferentially tries swaps that reduce the current maximum lag.

    idx = np.argsort(h_init)[::-1]
