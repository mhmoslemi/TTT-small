```python
    dx = 2.0 / n
    best_c = compute_c5(h, n)

        corr = np.correlate(h, 1-h, mode='full') * dx
        # Find active lags
        threshold = corr.max() - 0.01 * corr.max()  # or absolute threshold
        active = np.where(corr > threshold)[0]
        if len(active) == 0:
            active = np.array([np.argmax(corr)])
        
        # Compute sensitivity for each position
        # For position i, changing h[i] by +delta changes corr[lag_idx] by:
        # delta * (1 - h[contributing position]) * dx
        # This depends on the lag

        sens = np.zeros(n)
        for lag_idx in active:
            k = lag_idx - (n - 1)  # actual lag
            if k >= 0:
                # corr[lag_idx] = sum_{i=0}^{n-1-k} h[i]*(1-h[i+k])
                # d(corr)/d(h[i]) = (1-h[i+k]) for i < n-k
                # d(corr)/d(h[i+k]) = -h[i] for i < n-k

                    sens[i] += (1 - h[i+k]) * dx
                    sens[i+k] -= h[i] * dx
            else:
                k_abs = -k
                for i in range(k_abs, n):
                    sens[i] += (1 - h[i-k_abs]) * dx
                    sens[i-k_abs] -= h[i] * dx
        
        # Now find the best pair: maximize sens[j] - sens[i] (transfer from i to j)
        # or sens[i] - sens[j] (transfer from j to i)
        # We want to decrease the objective, so we want to move mass from high sens to low sens
        # Actually, if sens[i] > 0, increasing h[i] increases the objective
        # So we want to decrease h at high-sens positions and increase at low-sens positions
        
        order = np.argsort(sens)
        # Best move: take from order[-1] (highest sens) and give to order[0] (lowest sens)
        improved = False
        for attempt in range(20):
            i = order[-1 - attempt]  # source (high sens)
            j = order[attempt]  # destination (low sens)
            if i == j:
                continue
            # Try multiple step sizes
            for d in [0.05, 0.02, 0.01, 0.005, 0.002, 0.001]:
                if h[i] - d < 0 or h[j] + d > 1:

                h[j] += d

                if c < best_c - 1e-14:
```

```python
            # But this is only valid for small d (linear approximation)
            # For exact: g_k(d) = g_k(0) + d * delta_k where delta_k is the slope
            
            # Actually, for a swap h[i]+=d, h[j]-=d:
            # The change in g_k is linear in d (since g_k is bilinear in h)
            # delta_k = sum of changes
            # For lag k (index li = n-1+k):
            # h[i] appears in g_k with coefficient (1-h[i+k]) or -h[i-k] or both
            # h[j] appears similarly
            # The change is: d * [coeff_i_k - coeff_j_k]
            
            # Let me compute delta_k for each lag
            delta = np.zeros(num_lags)
            for ki in range(-n+1, n):
                li = n - 1 + ki
                # Contribution of h[i] to g_ki:
                ci = 0.0
                if 0 <= i + ki < n:
                    ci += (1 - h[i + ki])  # h[i] as first factor
                if 0 <= i - ki < n:
                    ci -= h[i - ki]  # h[i] in (1-h[i]) as second factor
                # Contribution of h[j] to g_ki:
                cj = 0.0
                if 0 <= j + ki < n:
                    cj += (1 - h[j + ki])
                if 0 <= j - ki < n:
                    cj -= h[j - ki]
                delta[li] = (ci - cj) * dx
            
            # g_k(d) = corr[li] + d * delta[li]
            # We want to minimize max_k (corr[li] + d * delta[li])
            # subject to 0 <= h[i]+d <= 1 and 0 <= h[j]-d <= 1
            # i.e., -h[i] <= d <= 1-h[i] and h[j]-1 <= d <= h[j]
            d_lo = max(-h[i], h[j] - 1)
            d_hi = min(1 - h[i], h[j])
            
            if d_hi <= d_lo:
                continue
            
            # Binary search for optimal d in [d_lo, d_hi]
            # F(d) = max_k (corr[li] + d * delta[li]) is convex in d
            # Find where subgradient changes sign
            lo, hi = d_lo, d_hi
            for _ in range(30):
                mid = (lo + hi) / 2
                # Subgradient at mid: sign of max active delta
                g_at_mid = corr + mid * delta
                active_max = g_at_mid.max()
                # If all active deltas are negative, F is decreasing → move right
                # We need to check the subgradient
                # Actually, for convex F(d) = max_k (a_k*d + b_k):
                # F'(d) (subgradient) = {delta_k : k is active}
                # We want 0 in the subgradient
                active = np.where(g_at_mid >= active_max - 1e-12)[0]
                if len(active) == 0:
                    active = np.array([np.argmax(g_at_mid)])
                if delta[active].min() >= -1e-12:
                    # All active slopes >= 0, F is increasing → move left
                    hi = mid
                elif delta[active].max() <= 1e-12:
                    # All active slopes <= 0, F is decreasing → move right
                    lo = mid
                else:
                    # 0 is in the subgradient → we're at the minimum
                    lo = hi = mid
                    break
            
            d_opt = (lo + hi) / 2
            if abs(d_opt) < 1e-10:
                continue
            
            h[i] += d_opt
            h[j] -= d_opt
            c = compute_c5(h, n)
            if c < best_c - 1e-15:
                best_c = c
                improved = True
            else:
                h[i] -= d_opt
                h[j] += d_opt
        
        if not improved:
            break
    
    return h, best_c
```

Wait, there's a problem with the coordinate descent. When I change h[i] and h[j], the delta values for subsequent coordinates change. I'm computing delta based on the current h at the start of each (i,j) pair, which is correct (sequential updates).

But the issue is that I'm only trying pairs (i, i+1 mod n), which is very restrictive. A better approach would be to try all pairs, but that's O(n²) per sweep.

For n=250, O(n²) = 62500 pairs, and for each pair I do O(n) work to compute delta + 30 bisection steps of O(n) each = O(n) + 30*O(n) = 31*O(n) per pair. Total: 62500 * 31 * 250 ≈ 480M operations per sweep. That's too slow.

Let me optimize: instead of computing delta from scratch for each pair, I can precompute the "sensitivity" of each position:

sens[i] = the total contribution of h[i] to the objective (for the active lags)

Then for a swap (i, j, +d, -d), the approximate change is d * (sens[j] - sens[i]).

This is the gradient-guided approach. The issue is it's only an approximation (valid for small d).

Let me combine both: use the gradient to select promising pairs, then use the exact 1D optimization for the selected pair.
