Wait, this isn't quite right either. The constraint is sum(h) = target, not sum(h) ≥ target. The projection onto the intersection of the box and the hyperplane is more subtle.

Actually, the standard approach is:
1. Project onto the box: h1 = clip(h, 0, 1)
2. If sum(h1) = target, done.
3. If sum(h1) > target, we need to reduce some values. Find λ > 0 such that sum(clip(h1 - λ, 0, 1)) = target. Set h = clip(h1 - λ, 0, 1).
4. If sum(h1) < target, we need to increase some values. Find λ > 0 such that sum(clip(h1 + λ, 0, 1)) = target. Set h = clip(h1 + λ, 0, 1).

But this only works if the target is achievable, which it is since 0 ≤ target ≤ n.

Wait, this isn't the exact Euclidean projection either. The exact projection onto the intersection of a box and a hyperplane requires finding a λ such that:
sum(clip(h_i + λ, 0, 1)) = target

This is because the Lagrangian for the projection problem min ||x - h||² subject to 0≤x≤1, sum(x)=target has the form:
x_i = clip(h_i + λ, 0, 1) for the right λ.

So yes, bisection on λ works!

    obj = m + (sm + np.log(exp_shifted.sum())) / alpha
    
    # Gradient
    first_term = np.convolve(h, p[::-1], 'full')[n-1:2*n-1]
    second_term = np.convolve(p, h, 'full')[n-1:2*n-1]
    grad = -dx * (first_term + second_term)
    
    return obj, grad

    obj, grad = smooth_max_and_grad(h, n, alpha)
    s = h.sum() - n / 2.0
    obj += penalty * s * s
    grad += 2 * penalty * s * np.ones(n)
    return obj, grad
