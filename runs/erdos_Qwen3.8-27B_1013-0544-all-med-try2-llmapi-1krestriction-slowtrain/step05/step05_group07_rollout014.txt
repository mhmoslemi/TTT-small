5. If not, update the active set and repeat

Since the objective (mean of active correlations) is a quadratic function of h (because each corr_k is quadratic in h due to the h[i]*h[i+k] terms), this is a quadratic optimization problem! We can use a QP solver or just L-BFGS on the quadratic.

Wait, is the mean of active correlations actually quadratic? 
corr_k = sum_i h[i] - sum_i h[i]*h[i+k]
The first term is linear in h. The second term is quadratic (it's -h^T Q_k h for some matrix Q_k).
The mean is also quadratic. So the optimization problem is:
minimize (1/|A|) * sum_{k∈A} (sum_i h[i] - sum_i h[i]*h[i+k]) * dx
subject to 0 ≤ h[i] ≤ 1, sum h = n/2

This is a QUADRATIC program (QP)! And since the quadratic form is -sum Q_k (which is a sum of correlation matrices, hence symmetric), this is a well-defined QP.

If the Hessian is negative semidefinite (which it likely is, since we're minimizing a "sum of products" which is concave), then this is a non-convex QP. But we can still use L-BFGS or other methods.
