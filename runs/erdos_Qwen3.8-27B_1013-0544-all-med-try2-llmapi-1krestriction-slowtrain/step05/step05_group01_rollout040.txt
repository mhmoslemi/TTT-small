    best_h = h.copy()

    dx = 2.0 / n

    it = 0

  - Second factor (in 1-h): c[k] gets -d*h[i+k] for k where i+k is valid
- h[j] appears similarly with opposite sign:
  - First factor: c[k] gets -d*(1-h[j-k]) for k where j-k is valid
  - Second factor: c[k] gets +d*h[j+k] for k where j+k is valid

So the total change in c[k] is:
Δc[k] = d * [(1-h[i-k]) - h[i+k] - (1-h[j-k]) + h[j+k]]
       = d * [h[j-k] - h[i-k] - h[i+k] + h[j+k]]

(with appropriate bounds checking, i.e., terms are 0 if the index is out of [0,n-1])

This is O(n) to compute for all k (vectorized), and then checking if max(c + Δc) < max(c) is O(n).

So each move evaluation is O(n) = O(250) with numpy vectorization. That's fast!

When h changes by Δh (sparse), the correlation changes by:
Δc[k] = sum_n Δh[n+k]*(1-h[n]) + h[n+k]*(-Δh[n])
      = sum_n Δh[n+k] - Δh[n+k]*h[n] - h[n+k]*Δh[n]

If Δh is sparse (only 2 non-zero entries at positions i and j):
Δc[k] = Δh[i]*(1-h[i-k]) + Δh[j]*(1-h[j-k]) - h[i+k]*Δh[i] - h[j+k]*Δh[j]
      = Δh[i]*((1-h[i-k]) - h[i+k]) + Δh[j]*((1-h[j-k]) - h[j+k])

(with bounds checking: terms are 0 if the index is out of [0,n-1])

This is O(1) per k, or O(n) for all k. Much faster than recomputing the full correlate!

```python
def correlation_delta(h, i, j, di, dj, n):
    """Compute the change in the full correlation vector when h[i]+=di, h[j]+=dj."""
    # c[k] = sum_n h[n+k]*(1-h[n])
    # Δc[k] = di*((1-h[i-k]) - h[i+k]) + dj*((1-h[j-k]) - h[j+k])
    # where terms are 0 if index is out of bounds
    
    delta = np.zeros(2*n-1)
    
    # Contribution from h[i] change by di
    # h[i] appears as:
    #   First factor: h[n+k] = h[i] when n+k=i, i.e., k=i-n for n in [0, n-1]
    #     → k ranges from i-(n-1) to i
    #     But k must be in [0, 2n-2]
    #   Second factor: h[n] = h[i] when n=i, i.e., k can be anything where n=i is valid
    #     → need 0 ≤ i+k ≤ n-1, so k ranges from -i to n-1-i
    #     But k must be in [0, 2n-2]
    
    # Term 1: di * (1-h[i-k]) for valid k where i-k is in [0,n-1]
    #   i-k in [0,n-1] means k in [i-(n-1), i]
    #   k in [0, 2n-2] ∩ [i-(n-1), i]
    k_lo1 = max(0, i-n+1)
    k_hi1 = min(2*n-2, i)
    if k_hi1 >= k_lo1:
        idx = np.arange(k_lo1, k_hi1+1)
        h_vals = h[i - idx]  # h[i-k] for k in idx
        delta[k_lo1:k_hi1+1] += di * (1 - h_vals)
    
    # Term 2: -di * h[i+k] for valid k where i+k is in [0,n-1]
    #   i+k in [0,n-1] means k in [-i, n-1-i]
    #   k in [0, 2n-2] ∩ [-i, n-1-i]
    k_lo2 = max(0, -i)  # = 0 since i >= 0
    k_hi2 = min(2*n-2, n-1-i)
    if k_hi2 >= k_lo2:
        idx = np.arange(k_lo2, k_hi2+1)
        h_vals = h[i + idx]  # h[i+k] for k in idx
        delta[k_lo2:k_hi2+1] -= di * h_vals
    
    # Same for j
    k_lo1 = max(0, j-n+1)
    k_hi1 = min(2*n-2, j)
    if k_hi1 >= k_lo1:
        idx = np.arange(k_lo1, k_hi1+1)
        h_vals = h[j - idx]
        delta[k_lo1:k_hi1+1] += dj * (1 - h_vals)
    
    k_lo2 = max(0, -j)
    k_hi2 = min(2*n-2, n-1-j)
    if k_hi2 >= k_lo2:
