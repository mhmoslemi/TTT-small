For the smooth max continuation, I'll use:
- Objective: f_τ(h) = τ * log(Σ exp(g_k(h)/τ)) which is a smooth approximation of max(g_k(h))
- This is differentiable everywhere
- As τ → 0, it approaches the max

The gradient of f_τ is:
∂f_τ/∂h[j] = Σ_k p_k * ∂g_k/∂h[j]
where p_k = exp(g_k/τ) / Σ_j exp(g_j/τ) (soft attention weights)

This is a convex combination of the individual gradients, so it's well-defined.

def smooth_c5(h, tau):
    """Compute smooth max of overlap using log-sum-exp."""
    n = len(h)
    dx = 2.0 / n
    conv = np.correlate(h, 1 - h, mode='full')
    max_c = np.max(conv)
    if tau < 1e-12:
        return max_c * dx, np.zeros(2*n-1)

    exp_shifted = np.exp(shifted)
    log_sum = np.log(np.sum(exp_shifted))
    obj = (max_c + tau * log_sum) * dx
    weights = exp_shifted / np.sum(exp_shifted)
