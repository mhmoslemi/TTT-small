### 1.  Mathematical formulation

Let  

```
x_i , y_i          – centre of circle i   (i = 0…25)
r_i                – radius of circle i  (r_i ≥ 0)
```

**Objective**

```
maximise  Σ r_i
```

**Boundary constraints**

```
x_i – r_i ≥ 0,  1 – x_i – r_i ≥ 0,
y_i – r_i ≥ 0,  1 – y_i – r_i ≥ 0
```

**Separation constraints**

Place the circles so that they never overlap.  Rather than using the hard‑to‑differentiate
`dist = sqrt((x_i-x_j)²+(y_i-y_j)²)` we formulate the constraints in *squared* form:

```
(x_i-x_j)² + (y_i-y_j)²  –  (r_i + r_j)²  ≥  0
```

The squared form eliminates the square‑root and improves numerical conditioning of the solver.
