1. **Treat the positions of the 26 centres as the only independent variables.**  
   For any fixed set of centre coordinates the **largest possible radii** can be computed *exactly* by a small linear program (LP).  
   The objective we actually want to maximise – the sum of all radii – therefore becomes a **function of the positions alone**.

2. **Search this 52‑dimensional position space by a global, *temperature‑based* stochastic optimiser – Simulated Annealing (SA).**  
   SA explores the search space more freely than classical evolutionary operators (crossover, mutation).  It accepts not only improvements but also occasional degradations, letting it escape shallow local optima that would trap a purely greedy scheme.

3. **At each SA step**  
   - Compare the new position set against the current one.  
   - Re‑solve the LP for the new positions to obtain the optimal radii and the new total radius sum.  
   - Accept the new state with probability  
     \[
       P_{\text{accept}}=\min\!\Bigl(1,\; e^{\frac{S_{\text{new}}-S_{\text{curr}}}{T}}\Bigr)
     \]  
     where \(S\) is the negative of the objective (so that a *larger* sum of radii corresponds to a *smaller* value to be minimised by SA).

4. **Cooling schedule**  
   Use a logarithmic cooling schedule \(T_{k}=T_{0}/\log(1+k)\).  
   The initial temperature \(T_{0}\) is set so that improvements of a few hundredths of a centimetre are accepted with probability ≈ 0.8 at the start.  
   The algorithm terminates after a fixed number of temperature reductions or after a fixed number of accepted states.

5. **Final local polishing**  
   Once SA has finished, the best position set found is refined by a fast *second‑order* optimiser (SLSQP).  
   In this phase **both centres and radii** are variable:  
   - The initial radii are taken from the LP solution for the best positions.  
   - The same nonlinear constraints as in the original verifier are enforced.

- All floating‑point operations use `numpy.float64`.  
- The LP solver is `highs`, which is fast and numerically stable for matrices of size ~350×26.  
- In the SA move generation the standard deviation shrinks automatically with temperature, ensuring fine‑grained search in later stages.
