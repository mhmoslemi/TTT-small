### 1.  Mathematical formulation

Let  

```
   c_i = (x_i , y_i)   – centre coordinates   (i = 1 … 26)
   r_i              – radius
```

All variables are continuous and bounded:

```
   0 ≤ x_i , y_i ≤ 1
   0 ≤ r_i ≤ 0.5          (0.5 guarantees a circle touching a wall never exceeds the square)
```

With *fixed* centres, the following inequalities are **linear in the radii**:

```
r_i + r_j ≤ d_ij       for every unordered pair (i,j)
r_i     ≤  x_i
r_i     ≤  1−x_i
r_i     ≤  y_i
r_i     ≤  1−y_i
```

where `d_ij = √((x_i−x_j)²+(y_i−y_j)²)` is a constant at that iteration.

The **inner optimisation** becomes:

```
maximise      Σ r_i
subject to    all inequalities above
```

which is a standard linear programme (LP).  
The LP solution is always unique because the objective is strictly increasing in every `r_i` and the feasible region is bounded; thus the solver will push each radius to the maximum allowed by the constraints.

The **outer optimisation** concerns the centre coordinates.  
After solving the LP we know the maximal radii for the current configuration.  
We then take the *slack* of every constraint and interpret it as a physical force:

```
  s_ij = (r_i + r_j) – d_ij          (negative → overlap)
  a_ij = (c_i – c_j) / d_ij * max(0, s_ij)
```

All *overlapping* pairs generate a repulsive vector pointing from one circle to the other.  
Disjoint pairs with slack > 0 also push the centres slightly apart so that a small increase in radius is possible.

Similarly each circle receives a wall–repulsion:

```
  w_i = [  max(0, r_i - x_i)  ,
          max(0, r_i - y_i)  ,
          max(0, r_i - (1-x_i)) ,
          max(0, r_i - (1-y_i)) ]
```

The total force on circle i is the sum of all `a_ij` that involve i plus the wall components.  
We move the centre in the direction of the force:

```
c_i ← c_i + τ * F_i
```

with a step size `τ` that decays geometrically (e.g. `τ_k = τ_0 * γ^k` with `γ = 0.95`).  
After every move we **project** the centres back to the admissible region:

```
x_i ← min( max(x_i, 0), 1 )
y_i ← min( max(y_i, 0), 1 )
```

This guarantees that no circle leaves the square; the radius bounds remain satisfied by the LP in the next iteration.

The algorithm runs for a fixed number of outer iterations (≈ 200–500).
