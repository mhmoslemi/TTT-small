**High‑level idea**

We view the packing as a *physical inflation* process: all circles start very small and grow simultaneously. They are pushed apart whenever they touch, so that eventually every circle is either tangent to a neighbour or to the square boundary.  
Because the final configuration is a mechanical equilibrium, the radii that can exist together are almost maximised for the given layout of centres.  
The algorithm is deterministic, uses only standard Python/NumPy/SciPy primitives, and is formulated entirely at the level of elementary geometry (no closures, no lambdas, no external files).

### 1.  Mathematical model of the inflation step
For each circle \(i\) we keep the current centre \(\mathbf{c}_i=(x_i,y_i)\) and radius \(r_i\).

* **Non‑overlap**  
  For a pair \((i,j)\) with Euclidean distance
  \[
      d_{ij}= \lVert \mathbf{c}_i-\mathbf{c}_j\rVert_2,
  \]
  the circles overlap if \(d_{ij}< r_i+r_j\).  
  We correct this by moving the centres apart along the line connecting them:
  \[
      \delta = \frac{r_i+r_j-d_{ij}}{2\,d_{ij}}, \qquad
      \mathbf{c}_i \gets \mathbf{c}_i + \delta(\mathbf{c}_i-\mathbf{c}_j), \; 
      \mathbf{c}_j \gets \mathbf{c}_j - \delta(\mathbf{c}_i-\mathbf{c}_j).
  \]
  The factor \(1/2\) guarantees that the sum of the two centre displacements equals the overlap distance.  
  If we prefer a size‑asymmetric shift we can weight the displacement proportionally to the radii, e.g.
  \[
      \mathbf{c}_i \gets \mathbf{c}_i + \delta \frac{r_j}{r_i+r_j}(\mathbf{c}_i-\mathbf{c}_j),
  \]
  but the equal split already works well.

* **Containment**  
  After any positional update we clip each coordinate to the admissible interval
  \[
      r_i \le x_i \le 1-r_i, \qquad r_i \le y_i \le 1-r_i,
  \]
  so that the circle never leaves the square.  
  If a centre touches a boundary we reflect it back:
  \[
      x_i \gets \max(r_i,\,\min(x_i,\,1-r_i)), \qquad
      y_i \gets \max(r_i,\,\min(y_i,\,1-r_i)).
  \]

* **Inflation**  
  After all pair corrections we increase every radius by a fixed step \(\Delta r\), but we never exceed the distance to the nearest square side:
  \[
      r_i \gets \min\!\Bigl(r_i+\Delta r,\,
                          \min(x_i,\ 1-x_i,\ y_i,\ 1-y_i)\Bigr).
  \]
  If a radius cannot be grown (because it is already touching a side), it stays unchanged.  
  A small “buffer” \(\varepsilon_{\mathrm{buff}}=10^{-6}\) can be subtracted from the side distances to avoid floating‑point overflow in the next inflation step.

The *inflation loop* is guaranteed to terminate because each step either:
