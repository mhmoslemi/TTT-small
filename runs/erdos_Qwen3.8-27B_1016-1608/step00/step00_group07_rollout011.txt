Actually, I just realized something. Let me re-examine the correlation computation.

For h that is binary (0 or 1) with sum = n/2:
(1-h) is also binary (0 or 1), just the complement.

correlate(h, 1-h, mode="full")[k] = sum of h[i]*(1-h)[i+k-(n-1)] over valid i.

This counts the number of positions where h has a 1 and the shifted (1-h) also has a 1, i.e., where h[i]=1 and h[i+k-(n-1)]=0.

So C5/dx = max over all shifts of the number of "1 in h that align with 0 in h at that shift".

For a binary sequence, this is: max_k (number of i such that h[i]=1 and h[i+k-(n-1)]=0).

The total number of 1s in h is n/2. For a given shift, the "overlap region" has some number of elements. Of those, some are 1-1, some are 1-0, some are 0-1, some are 0-0.

The number of 1-0 pairs = (number of 1s in h in overlap) - (number of 1-1 pairs).

This is a well-studied combinatorial problem. The optimal binary sequence minimizes the maximum "partial sum discrepancy" over all shifts.

This is related to the "directed autocorrelation" or "periodic autocorrelation" problem in sequence design.

For a balanced binary sequence (equal 0s and 1s), the autocorrelation at lag 0 is 0 (since we have equal 1s and 0s, and 1*1 counts equal 0*0 counts, so the "balanced" autocorrelation is 0). Wait, I'm confusing with the standard autocorrelation definition.

import numpy as np
import time

def compute_c5(h, dx):
    return float(np.max(np.correlate(h, 1.0 - h, mode="full") * dx))

def make_binary(h, rng):
    n = len(h)
    target = n // 2
    b = (h >= 0.5).astype(np.float64)
    n1 = int(np.sum(b))
    if n1 > target:
        idx = np.where(b == 1.0)[0]
        b[rng.choice(idx, n1 - target, replace=False)] = 0.0
    elif n1 < target:
        idx = np.where(b == 0.0)[0]
        b[rng.choice(idx, target - n1, replace=False)] = 1.0
    return b

def sa_binary(h_start, dx, n_iter, T_init, T_final, rng):
    n = len(h_start)
    h = h_start.copy()
    c5 = compute_c5(h, dx)
    best_h = h.copy()
    best_c5 = c5
    ratio = T_final / T_init
    ones = np.where(h > 0.5)[0]
    zeros = np.where(h < 0.5)[0]
    for it in range(n_iter):
        T = T_init * (ratio ** (it / max(n_iter - 1, 1)))
        ii = rng.randint(len(ones))
        jj = rng.randint(len(zeros))
        i = ones[ii]
        j = zeros[jj]
        h[i] = 0.0
        h[j] = 1.0
        nc = compute_c5(h, dx)
        d = nc - c5
        if d < 0.0 or (T > 1e-15 and rng.random() < np.exp(-d / T)):
            c5 = nc
            ones[ii] = j
            zeros[jj] = i
            if nc < best_c5:
                best_c5 = nc
                best_h = h.copy()
        else:
            h[i] = 1.0
            h[j] = 0.0
    return best_h, best_c5
