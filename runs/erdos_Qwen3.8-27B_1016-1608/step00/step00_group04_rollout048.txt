For a given shift k:
g_k(h) = dx * sum_n h[n+k](1-h[n])

The gradient ∂g_k/∂h[j] for a specific k:
- Term 1 (h[j] appears in h[n+k]): n = j-k, contributes (1-h[j-k]) if valid
- Term 2 (h[j] appears in h[n]): n = j, contributes -h[j+k] if valid

So grad[j] = dx * [(1-h[j-k]) * I(valid) - h[j+k] * I(valid)]

This can be computed as:

Where "shifted by -k" means element j gets element j-k of (1-h) (or 0 if out of bounds), and "shifted by +k" means element j gets element j+k of h (or 0 if out of bounds).
