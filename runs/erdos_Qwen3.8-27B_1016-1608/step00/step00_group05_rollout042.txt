d(corr_k)/d(h[i]) = (1-h[i+k]) - h[i-k] (if both indices valid)

- From term where j+k=i, i.e., j=i-k: coeff of h[i] is -h[i-k]

So d(corr_k)/d(h[i]) = (1-h[i+k]) - h[i-k]

This is indeed independent of h[i]! So for a single active constraint, corr_k is LINEAR in h[i]. The minimum of a linear function over [0,1] is at one of the endpoints.

This means: for a single active lag, the coordinate-wise optimum of h[i] is either 0 or 1! This is a key insight.

For multiple active lags, the objective is max of multiple linear functions of h[i], and the optimum is where the maximum of these is minimized. This is a 1D convex problem (max of linear functions is convex), solvable by checking the intersection points.

This means the optimal solution is likely to be at a "vertex" of the feasible polytope, which for the box + sum constraint means most coordinates are at 0 or 1.

So the binary approach should be near-optimal! Let me focus more on the binary local search.

For binary h with n/2 ones:
- C₅ = max_k (n/2 - |S ∩ (S-k)|) * 2/n
- We want to minimize this, i.e., maximize the minimum overlap |S ∩ (S-k)| over all k

This is related to the "Erdős distinct distance problem" or more directly to "maximum sum of autocorrelations" problems.

For the binary local search:
- Start from a binary solution
- Try all possible swaps (move a 1 from position i to position j)
- Accept if C₅ improves
- This is O(n² * n) = O(n³) per full swap evaluation

For n=70: 70*70*70 = 343,000 per full evaluation. With numpy, much faster.

Actually, for each swap (i,j): we remove 1 from i, add 1 to j. The correlation changes for all lags. We can compute the new C₅ in O(n) per swap (just update the affected correlation values).

But implementing this efficiently is complex. For n=70, just recomputing the full correlation (O(n²) = 4900 ops) per swap is fast enough.

```python
import numpy as np
from scipy.optimize import minimize
import time

_ON = 70

def repair_h(h, n):
    h = np.clip(np.asarray(h, dtype=np.float64), 0.0, 1.0)
    tgt = 0.5 * n
    for _ in range(50):
        d = tgt - h.sum()
        if abs(d) < 1e-14:
            return h
        m = (h < 1.0) if d > 0 else (h > 0.0)
        if not m.any():
            return h
        h[m] = np.clip(h[m] + d / m.sum(), 0.0, 1.0)
    return h

def eval_c5(h, n):
    dx = 2.0 / n
    return float(np.max(np.correlate(h, 1.0 - h, mode="full")) * dx)

def _obj(x):
    n = _ON
    hx = repair_h(x, n)
    v = np.correlate(hx, 1.0 - hx, mode="full") * (2.0 / n)
    m = v.max()
    return float(m + np.log(np.sum(np.exp(500.0 * (v - m)))) / 500.0)

def _coord_descent(bh, bc, n, rng, max_iter, start_step, time_limit):
    stp = start_step
    for _ in range(max_iter):
        if time.time() > time_limit:
            break
        if stp < 2e-5:
            stp = start_step
        imp = False
        for i in rng.permutation(n):
            ht = bh.copy()
            ht[i] = min(1.0, ht[i] + stp)
            ht = repair_h(ht, n)
            c = eval_c5(ht, n)
            if c < bc - 1e-14:
                bc, bh, imp = c, ht, True
                continue
            ht[i] = max(0.0, bh[i] - stp)
            ht = repair_h(ht, n)
            c = eval_c5(ht, n)
            if c < bc - 1e-14:
                bc, bh, imp = c, ht, True
        if not imp:
            stp *= 0.8
    return bh, bc

def _binary_swap_search(bh, bc, n, time_limit):
    hb = np.where(bh > 0.5, 1.0, 0.0)
    hb = repair_h(hb, n)
    cb = eval_c5(hb, n)
    if cb < bc:
        bc, bh = cb, hb.copy()
    if not np.allclose(bh, np.round(bh)):
        return bh, bc
    bc = eval_c5(bh, n)
    for _ in range(20000):
        if time.time() > time_limit:
            break
        ones = [i for i in range(n) if bh[i] == 1.0]
        zeros = [i for i in range(n) if bh[i] == 0.0]
        best_c, best_i, best_j = bc + 1, -1, -1
        for i in ones:
            for j in zeros:
                ht = bh.copy()
                ht[i] = 0.0
                ht[j] = 1.0
                c = eval_c5(ht, n)
                if c < best_c:
                    best_c, best_i, best_j = c, i, j
        if best_i >= 0:
            bh[best_i] = 0.0
            bh[best_j] = 1.0
            bc = best_c
        else:
            break
    return bh, bc

def run(seed=42, budget_s=1100, **kwargs):
    global _ON
    t0 = time.time()
    rng = np.random.RandomState(seed)
    tlim1 = t0 + budget_s - 180
    tlim2 = t0 + budget_s - 80
    tlim3 = t0 + budget_s - 30

    global initial_h_values
    if 'initial_h_values' in globals() and initial_h_values is not None:
        n = len(initial_h_values)
        h = np.array(initial_h_values, dtype=np.float64).copy()
    else:
        n = 70
        h = np.full(n, 0.5)
    h = repair_h(h, n)
    bc = eval_c5(h, n)
    bh = h.copy()
    _ON = n

    # Phase 1: L-BFGS-B with smooth max
    if time.time() < tlim1:
        bd = [(0.0, 1.0)] * n
        try:
            r = minimize(_obj, h, method="L-BFGS-B", bounds=bd,
                         options={"maxiter": 5000, "ftol": 1e-15, "maxls": 40})
            hx = repair_h(r.x, n)
            c = eval_c5(hx, n)
            if c < bc:
                bc, bh = c, hx.copy()
        except Exception:
            pass

    # Phase 2: Continuous coordinate descent
    if time.time() < tlim2:
        bh, bc = _coord_descent(bh, bc, n, rng, 50000, 0.05, tlim2)

    # Phase 3: Binary projection + swap local search
    if time.time() < tlim3:
        bh, bc = _binary_swap_search(bh, bc, n, tlim3)

    # Phase 4: Perturbation restarts with mixed refinement
    if time.time() < tlim3:
        for _ in range(2000):
            if time.time() > tlim3:
                break
            ht = repair_h(bh + 0.07 * rng.randn(n), n)
            c = eval_c5(ht, n)
            if c < bc:
                bc, bh = c, ht.copy()
                bh, bc = _coord_descent(bh, bc, n, rng, 200, 0.03, tlim3)
                if time.time() < tlim3:
                    bh, bc = _binary_swap_search(bh, bc, n, tlim3)

    bh = repair_h(bh, n)
    bc = eval_c5(bh, n)
    return bh, bc, n
```
