- -p[k] * h[j-s] if 0 ≤ j-s < n (and 0 ≤ j < n automatically since j is in [0,n))

So:
grad[j] = sum_s [p_s * (1-h[j+s]) * 1(0≤j+s<n)] - sum_s [p_s * h[j-s] * 1(0≤j-s<n)]

The first term: for fixed j, sum over s where 0≤j+s<n, i.e., -j ≤ s < n-j.
The second term: for fixed j, sum over s where 0≤j-s<n, i.e., j-n < s ≤ j.

This can be rewritten as:
first[j] = sum_s p_s * (1-h[j+s]) * 1(0≤j+s<n)

If I define q[s] = p[s + n - 1] (reindexing so s goes from -(n-1) to n-1), then:
first[j] = sum_{s: 0≤j+s<n} q[s] * (1-h[j+s])
         = sum_{i: 0≤i<n, i=j+s} q[i-j] * (1-h[i])

This is a convolution! first = convolve(q, 1-h) (with appropriate edge handling).

Similarly:
second[j] = sum_{s: 0≤j-s<n} q[s] * h[j-s]
           = sum_{i: 0≤i<n, i=j-s} q[j-i] * h[i]
           = (convolve(q_rev, h))[j] where q_rev is reversed

                best_h, best_c5 = h_try, c5_try

    if tl() > 10:
        h_cd, c5_cd = coord_descent(best_h, dx, target, rng, 20000, 0.005)
        if c5_cd < best_c5:
            best_h, best_c5 = h_cd, c5_cd

    # Final L-BFGS-B at very high temperature (near max)
    if tl() > 10:
        h_try = lbfgs_optimize(best_h, dx, target, 1e9, maxiter=300)
        if h_try is not None:
            c5_try = compute_c5(h_try, dx)
            if c5_try < best_c5:
                best_h, best_c5 = h_try, c5_try

    best_h = project(best_h, target)
    final_c5 = compute_c5(best_h, dx)
    return (best_h, final_c5, n)
