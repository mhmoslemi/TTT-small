Let me also think about the "equalization" strategy. At the optimum, the top few lags should have similar values. I can use this to construct a better objective: maximize the minimum of the top-k lags, which is a linear program (in terms of the corr values, which are bilinear in h).

Actually, the problem is bilinear: corr[k] = sum_i h[i+lag]*(1-h[i]) = sum_i h[i+lag] - sum_i h[i+lag]*h[i]

The second term is bilinear, so this is a non-convex problem.

Let me think about a different angle. What if I try to find a solution where h is very close to binary (0 or 1)? If h is the indicator of a set S, then:
corr[k] = |S \ (S - lag)| * dx (approximately)

This is the size of the "boundary" of S in the direction of lag. For a set in 1D, the boundary is just 2 points, so the max would be small. But with the discretization, things get more nuanced.

Actually, if h is exactly 0 or 1, then h(x)(1-h(x+k)) is the indicator of {x: x∈S, x+k∉S}. The integral is just the measure of that set. For a single interval S = [a, b] of length 1:
- S = [a, b], |S| = b-a = 1
- S - lag = [a-lag, b-lag]
- S \ (S-lag) = [a, b] \ [a-lag, b-lag]
- If lag > 0: S \ (S-lag) = [b-lag, b] if lag < |S|, or all of S if lag >= |S|
  Wait: [a,b] \ [a-lag, b-lag] = [a, b] \ [a-lag, b-lag]
  If lag > 0: the overlap is [a, b-lag] (if lag < b-a) so S\(S-lag) = [b-lag, b], measure = lag
  If lag >= b-a: S\(S-lag) = S, measure = b-a = 1
  
  So max over positive lags: when lag just exceeds b-a=1, the measure is 1. So C₅ would be at least 1*dx.

That's terrible. A single interval doesn't work.

What about alternating blocks? If S alternates between blocks of length a and gaps of length b:
S = [0,a] ∪ [a+b, 2a+b] ∪ [2a+2b, 3a+3b] ∪ ...

The measure of S in [0,2] would be approximately 2a/(a+b) * 2 / (number of periods) ... this gets complicated.

Let me think differently. The key insight is that we want the "shift loss" to be small for ALL shifts k. This means S should be "self-similar" at all scales - which in 1D is essentially impossible for a finite set. The best we can do is make the loss as uniform as possible.

import numpy as np
from scipy.optimize import minimize
import time

def compute_c5(h, dx):
    corr = np.correlate(h, 1.0 - h, mode="full")
    return float(np.max(corr) * dx)

def project_feasible(h, target):
    h = np.array(h, dtype=float).copy()
    for _ in range(3000):
        h = np.clip(h, 0.0, 1.0)
        excess = h.sum() - target
        if abs(excess) < 1e-14:
            break
        if excess > 0:
            m = h > 0
            if not m.any():
                break
            s = min(excess / m.sum(), h[m].min())
            h[m] -= s
        else:
            m = h < 1
            if not m.any():
                break
            s = min(-excess / m.sum(), (1.0 - h[m]).min())
            h[m] += s
    return h

def lse_smooth(h, dx, temp):
    corr = np.correlate(h, 1.0 - h, mode="full")
    m = np.max(corr)
    return (m + np.log(np.mean(np.exp(temp * (corr - m)))) / temp) * dx

def lse_grad(h, dx, temp):
    corr = np.correlate(h, 1.0 - h, mode="full")
    m = np.max(corr)
    w = np.exp(temp * (corr - m))
    w = w / (w.sum() * len(corr))
    n = len(h)
    grad = np.zeros(n)
    for k in range(len(corr)):
        if w[k] < 1e-16:
            continue
        lag = k - (n - 1)
        wk = w[k]
        for j in range(n):
            if 0 <= j - lag < n:
                grad[j] += wk * (1.0 - h[j - lag])
            if 0 <= j + lag < n:
                grad[j] -= wk * h[j + lag]
    return grad * dx
