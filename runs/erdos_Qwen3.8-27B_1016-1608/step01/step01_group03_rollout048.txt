The full correlation of a (length n) with b (length n) has length 2n-1.
corr[k] = sum_i a[i] * b[i - k + (n-1)] for valid i

Wait, I need to be more careful. Let me look at the definition:
np.correlate(a, v, mode='full') returns c where:
c_k = sum_j a_{j+k} * v_j (for 'full' mode, k ranges from -(n-1) to n-1, but the output is indexed 0 to 2n-2)

Actually, from numpy docs:
c_k = sum_j a_{j+k} \bar{v}_j for k = -(n-1), ..., n-1
But the 'full' output has length 2n-1, indexed from 0.

The mapping is: output index i corresponds to k = i - (n-1)

So output[i] = sum_j a_{j + i - (n-1)} * v_j

For our case: a = h, v = 1-h, both length n.
output[i] = sum_j h_{j + i - n + 1} * (1-h)_j

Let m = i - n + 1 (the shift). Then:
output[i] = sum_j h_{j+m} * (1-h_j)

where the sum is over j such that 0 ≤ j < n and 0 ≤ j+m < n.

So ∂output[i]/∂h_l:
- h_l appears as h_{j+m} when j = l-m: contributes (1-h_{l-m}) if 0 ≤ l-m < n
- h_l appears in (1-h_j) when j = l: contributes -h_{l+m} if 0 ≤ l+m < n

So:
∂output[i]/∂h_l = (1-h_{l-m}) * [0 ≤ l-m < n] - h_{l+m} * [0 ≤ l+m < n]

where m = i - n + 1.

    m = k_idx - (n - 1)

    if lo1 < hi1:
        grad[lo1:hi1] += (1.0 - h[lo1 - m:hi1 - m])
    lo2, hi2 = max(0, -m), min(n, n - m)
    if lo2 < hi2:
        grad[lo2:hi2] -= h[lo2 + m:hi2 + m]
    return grad

    """Weighted subgradient using softmax over lags"""
    corr = np.correlate(h, 1.0 - h, mode="full")
    w = np.exp(beta * (corr - corr.max()))
    s = w.sum()
    if s < 1e-300:
        w = np.zeros_like(corr); w[np.argmax(corr)] = 1.0
    else:
        w = w / s
    grad = np.zeros(n)

            grad += w[i] * lag_gradient(h, n, i)
    return grad, np.max(corr)

                            improved = True
                            break
                if improved:
                    break
            if not improved:
                break

    # Phase 4: SLSQP with subgradient (multiple attempts)
    if time_left() > 30:
        bnds = [(0.0, 1.0)] * n
        cons = [{'type': 'eq', 'fun': lambda x: np.sum(x) - tgt,
                 'jac': lambda x: np.ones(n)}]

        for att in range(4):
            if time_left() < 15:
                break
            try:
                r = minimize(
                    lambda x: compute_c5(repair(x, tgt), dx),
                    best_h,
                    jac=lambda x: smoothed_subgrad(repair(x, tgt), n, beta=30.0)[0],
                    method='SLSQP', bounds=bnds, constraints=cons,
                    options={'maxiter': 200, 'ftol': 1e-15})
                hf = repair(r.x, tgt)
                cf = compute_c5(hf, dx)
                if cf < best_c5:
                    best_c5, best_h = cf, hf
            except Exception:
                if att < 2:
                    continue
                break

    # Phase 5: Try alternative grid sizes
    if time_left() > 120:
        for n_try in [50, 60, 80, 90]:
            if time_left() < 90:
                break
            dx_t = 2.0 / n_try
            tgt_t = n_try / 2.0
            # Interpolate from current best
            h_new = np.interp(
                np.linspace(0, 2, n_try, endpoint=False),
                np.linspace(0, 2, n, endpoint=False), best_h)
            h_new = repair(h_new, tgt_t)
            h_opt = focused_search(h_new, dx_t, tgt_t, n_try, max_iters=200)
            c_opt = compute_c5(h_opt, dx_t)
            if c_opt < best_c5:
                best_c5, best_h, best_n = c_opt, h_opt, n_try
            # SLSQP polish on new grid
            if time_left() > 60 and c_opt < best_c5 + 0.005:
                bnds_t = [(0.0, 1.0)] * n_try
                cons_t = [{'type': 'eq', 'fun': lambda x: np.sum(x) - tgt_t,
                          'jac': lambda x: np.ones(n_try)}]
                try:
                    r = minimize(lambda x: compute_c5(repair(x, tgt_t), dx_t),
                               h_opt, method='SLSQP', bounds=bnds_t,
                               constraints=cons_t,
                               options={'maxiter': 200, 'ftol': 1e-14})
                    hf = repair(r.x, tgt_t)
                    cf = compute_c5(hf, dx_t)
                    if cf < best_c5:
                        best_c5, best_h, best_n = cf, hf, n_try
                except Exception:
                    pass

    # Phase 6: Final refinement
    if time_left() > 20:
        h_f = focused_search(best_h, 2.0 / best_n, best_n / 2.0, best_n, max_iters=200)
        c_f = compute_c5(h_f, 2.0 / best_n)
        if c_f < best_c5:
            best_c5, best_h = c_f, h_f

    # Final validation
    best_h = repair(best_h, best_n / 2.0)
    best_c5 = compute_c5(best_h, 2.0 / best_n)

    return (best_h, best_c5, best_n)
