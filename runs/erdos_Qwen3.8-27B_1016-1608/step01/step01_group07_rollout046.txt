- Solve: min ||h||² (or some convex objective) subject to 0≤h≤1, sum(h)=n/2, and the active correlation constraints
- The active correlation constraints are: Σ_i h[i]*(1-h[i+k])*dx ≤ C

But these are non-linear (bilinear). For a fixed current iterate h₀, we can linearize:
h[i]*(1-h[i+k]) ≈ h₀[i]*(1-h₀[i+k]) + (1-h₀[i+k])*(h[i]-h₀[i]) + h₀[i]*(h₀[i+k]-h[i+k])

This is the first-order Taylor approximation. Then we solve the LP/QP:
min ||h - h₀||² (or 0)
s.t. 0≤h≤1, sum(h)=n/2, linearized constraints ≤ C

This is a QP (or LP if objective is linear) that we can solve with cvxpy!

The outer approximation loop:
1. Start with h₀ = parent
2. Compute g_k(h₀) for all k
3. Identify active/near-active constraints: k where g_k(h₀) ≥ C - ε
4. Linearize those constraints at h₀
5. Solve: min ½||h-h₀||² s.t. linearized constraints, 0≤h≤1, sum(h)=n/2
6. If optimum h satisfies original constraints, done
7. Else, add violated constraints to active set, go to 3

This is essentially the cutting-plane / outer-approximation method for min-max problems.

But with n=400 and potentially hundreds of active constraints, the QP might be slow. Let me limit to the top 50 most active constraints.

Actually, for cvxpy with a QP of size 400 variables and ~100 constraints, each solve should take <1 second. With maybe 20-50 iterations of the outer loop, that's <1 minute per n. We can afford to try multiple n values.

import numpy as np
import time

    n = len(h)
    dx = 2.0/n
    c = np.correlate(h, 1-h, mode='full')
    return float(np.max(c) * dx)

    """Adjust h to have sum = n/2 while staying in [0,1]"""
    target = n * 0.5
    for _ in range(200):
        d = target - np.sum(h)
        if abs(d) < 1e-12:
            break
        if d > 0:
            mask = h < 1.0
        else:
            mask = h > 0.0
        cnt = mask.sum()
        if cnt == 0:
            break
        h = h + (d/cnt)*mask
        h = np.clip(h, 0, 1)
    return h

    dx = 2.0/n
    h = h0.copy()
    active_shifts = list(range(2*n-1))  # start with all

        c = np.correlate(h, 1-h, mode='full') * dx  # shape (2n-1,)
        current_max = c.max()

            break  # feasible!

        idx = np.argsort(c)[::-1][:top_k]

        # But for cutting plane, we use each active constraint separately

        # This is: sum_i h_new[i] * coeff_i <= C where coeff_i = (1-h[i+d_k])*dx

        # Constraint: c[k] + dx*sum_i (1-h[i+d_k])*(h_new[i]-h[i]) <= C_target
        # i.e., dx*sum_i (1-h[i+d_k])*h_new[i] <= C_target - c[k] + dx*sum_i (1-h[i+d_k])*h[i]
        #      dx*sum_i (1-h[i+d_k])*h_new[i] <= C_target - c[k] + c[k]  (since sum_i(1-h[i+d])*h[i] = c[k]/dx)

        # dx * sum_i (1-h[i+d_k])*h_new[i] <= C_target

        # Build QP
        h_var = cp.Variable(n)
        constraints = [h_var >= 0, h_var <= 1, cp.sum(h_var) == n*0.5]

            # coeff[i] = (1 - h[i+d]) for valid i

                # coeff[i] = 0 for i < |d|
                coeff[:|d|] = 0
                coeff[|d|:] = 1 - h[:n-|d|]

        objective = cp.Minimize(cp.sum_squares(h_var - h))
        prob = cp.Problem(objective, constraints)

                h = np.clip(h_var.value, 0, 1)
                h = fix_sum(h, n)
            else:
                break
        except:
            break
    
    return h

    n = len(h)
    return float(np.max(np.correlate(h, 1-h, mode='full')) * 2.0/n)

def fix_sum(h, n):
    target = n * 0.5
    for _ in range(500):
        d = target - h.sum()
        if abs(d) < 1e-13: break
        m = (h < 1 - 1e-15) if d > 0 else (h > 1e-15)
        k = int(m.sum())
        if k == 0: break
        h = np.clip(h + d/k*m, 0, 1)
    return h

def interp_to(h_old, n_new):
    n_old = len(h_old)
    xo = np.linspace(0, 2, n_old, endpoint=False)
    xn = np.linspace(0, 2, n_new, endpoint=False)
    return fix_sum(np.clip(np.interp(xn, xo, h_old), 0, 1), n_new)

def smooth_obj(x, alpha):
    n = len(x)
    dx = 2.0/n
    c = np.correlate(x, 1-x, mode='full') * dx
    m = c.max()
    e = np.exp(np.clip(c - m, -50, 0))
    return m + np.log(e.sum())/alpha
