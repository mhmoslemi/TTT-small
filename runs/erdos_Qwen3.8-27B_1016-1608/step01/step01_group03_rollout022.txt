    """Find t in [0,1] minimizing max_k(base[k] + t*diff[k])."""
    nl = len(base)
    # Pairwise breakpoints
    num = base[np.newaxis, :] - base[:, np.newaxis]  # shape (nl, nl), [a,b] = base[b]-base[a]
    den = diff[:, np.newaxis] - diff[np.newaxis, :]  # shape (nl, nl), [a,b] = diff[a]-diff[b]
    mask = (np.abs(den) > 1e-14) & (num >= 0) & (num <= den)  # tb in [0,1] when den>0
    mask |= (np.abs(den) > 1e-14) & (num <= 0) & (num >= den)  # tb in [0,1] when den<0
    # Actually: tb = num/den, tb in [0,1] means (num>=0 and den>0 and num<=den) or (num<=0 and den<0 and num>=den)
    
    tb_flat = (num / den).ravel()
    valid = ((tb_flat >= 0) & (tb_flat <= 1) & np.isfinite(tb_flat))
    candidates = np.concatenate([[0.0, 1.0], tb_flat[valid]])
    
    # Evaluate f at all candidates
    # f(t) = max_k(base[k] + t*diff[k])
    # For all candidates at once: shape (n_cand, nl)
    vals = base[np.newaxis, :] + candidates[:, np.newaxis] * diff[np.newaxis, :]
    f_vals = vals.max(axis=1)
    
    best_idx = np.argmin(f_vals)
    return candidates[best_idx], f_vals[best_idx]

- h[j] appears in the first factor: contributes (1-h[j+shift]) if 0≤j+shift<n
- h[j] appears in the second factor (inside 1-h[i+shift]): when i+shift=j, i.e., i=j-shift. Contributes -h[j-shift] if 0≤j-shift<n.

So dc[m]/dh[j] = (1-h[j+shift]) * [0≤j+shift<n] - h[j-shift] * [0≤j-shift<n]

For the overall gradient of the objective f = max_m c[m] * dx:
If we know which m is the maximizer, the gradient is dx * dc[m*]/dh[j] for all j.

This is O(n) per m to compute the full gradient vector. And we can compute c for all m in O(n²) using correlate. So the total per iteration is O(n²) for c + O(n) for the gradient. Very fast!
