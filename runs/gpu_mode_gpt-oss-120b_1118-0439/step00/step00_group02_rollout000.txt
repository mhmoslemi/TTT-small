1. LayerNorm across last dim: norm(x) = (x - mean)/sqrt(var+eps) * weight + bias.

We can implement layernorm using torch or using triton. However we can rely on PyTorch for simplicity (as allowed). But we must implement at least part of ops in a kernel. That can be the core einsum (multiplicative update). Possibly also the linear projections can be done with torch.nn.functional.linear, easier.

Goal: produce output identical to reference.

The internal steps:

- x = norm(x) (LayerNorm) with norm.weight, norm.bias.

- left = left_proj(x) = x @ left_proj_weight.T (dim to hidden_dim) (no bias). left shape [B,N,N, hidden_dim].

- right = right_proj(x) similarly.

- mask: shape [B,N,N]. unsqueeze(-1): [B,N,N,1] broadcast.

- left *= mask; right *= mask.

- left_gate = sigmoid(left_gate(x)) = sigmoid(x @ left_gate_weight.T) shape [B,N,N, hidden_dim].

- same for right_gate, out_gate.

- left *= left_gate; right *= right_gate.

- out = einsum('... i k d, ... j k d -> ... i j d', left, right). This multiplies left[b,i,k,:] * right[b,j,k,:] summed over k (dimension N). So for each pair (i,j), out[d] = sum_k left[i,k,d] * right[j,k,d]

Note: dimensions: left, right shape [B,N,N,hidden_dim]. The einsum is over the third dimension of left (k) and third dimension of right (k). But note left indexed i,k: left across rows i and inner dimension k. Right indexed j,k: right across rows j and same inner k dimension (per hidden_dim). So essentially out[b,i,j,d] = Σ_k left[b,i,k,d] * right[b,j,k,d].

This is basically a batched matrix multiplication where matrices of shape (N, N) but with hidden_dim as channel dimension; i.e., for each d, left[:, :, :, d] is an N x N matrix; similarly right[:, :, :, d] is N x N. Then out_d = left_d @ right_d^T? Let's compute: left[i,k] * right[j,k] sum over k. That's (left @ right^T) where left is (i,k) and right is (j,k). Actually standard matmul (i,k) * (k,j) gives out[i,j]. Here we have (i,k)*(j,k) (since second index j is outer). That's left[i,k] * right[j,k] sum over k -> left (i,k) times right (j,k) = left[i,k] * right_transpose_T? If we treat right_transpose: right_T[k,j] = right[j,k]. Then out[i,j] = Σ_k left[i,k] * right_T[k,j] = (left @ right_T)[i,j].

Thus out_d = left_d @ right_d.T (where right_d.T is transpose of right matrix). So we can compute for each d channel hidden_dim but need a per-channel matrix multiplication.

We can compute using a fused approach: we can reshape (B*hidden_dim, N, N) and compute batched matmul between left and right_T.

Specifically, left: shape [B,N,N,hidden_dim]; we can permute to [B, hidden_dim, N, N] (or (B*hidden_dim, N, N)). Right: shape [B,N,N,hidden_dim]; we need its transpose in last two dims: right_T = right.permute(0,3,2,1) => [B, hidden_dim, N, N] but with dims (k,j) where original is (j,k). So right_transpose = right.permute(0,3,2,1) (swap last two dims). Then for each (B, hidden_dim) we compute matmul with left[b, d] @ right_T[b, d]^T? Wait right_T already swapped j and k, so we need left @ right_T? Let's verify: left[i,k] (orig left[b,i,k,d]) -> left_mat shape (N,N). right_transpose[k,j] = right[j,k] (since permuting dims). Then matmul left (N,N) @ right_transpose (N,N) yields (i,j) = Σ_k left[i,k] * right_transpose[k,j] = Σ_k left[i,k] * right[j,k], correct.

Thus out = matmul(left, right_transpose). This is a batched matrix multiplication across B*hidden_dim.

    stride_c_m = c_ptr.stride(1)
    stride_c_n = c_ptr.stride(2)

    out = out * out_gate

    # Step 9: final linear projection to dim
    out = torch.nn.functional.linear(out, to_out_weight)  # weight shape (dim, hidden_dim)

    return out

"""
TriMul forward kernel (outgoing version) – AlphaFold3 style.

Algorithm
---------
1. Layer‑norm the input tensor `x` (shape B×N×N×C) using the provided
   `norm.weight` and `norm.bias`.
2. Linear projections (no bias):
   left  = x @ left_proj.weight.T    # (B,N,N,H)
   right = x @ right_proj.weight.T   # (B,N,N,H)
3. Optional mask: multiply `left` and `right` by mask[...,None].
4. Compute three sigmoidal gates from `x` with the respective
   projection weights, and apply them to `left` and `right`.
5. Compute the multiplicative update:
      out[b,i,j,:] = Σ_k left[b,i,k,:] * right[b,j,k,:]
   This is exactly a batched matrix multiply:
      out = (left reshaped to (B*H,N,N)) @ (rightᵀ reshaped to (B*H,N,N)).
   The heavy N³ work is performed by a custom Triton kernel
   (`batched_matmul_kernel`), tiled with BLOCK_M/BLOCK_N/BLOCK_K.
6. Reshape the result back to (B,N,N,H) and apply a second LayerNorm
   (over hidden dimension H) using `to_out_norm`.
7. Multiply by the output gate (sigmoid of a linear projection of x).
8. Final linear projection to the original channel dimension C.

Only the core N³ matmul is implemented in Triton; all other operations use
standard PyTorch for simplicity and correctness.
"""

import torch
import triton
import triton.language as tl
from torch.nn import functional as F

@triton.jit
def batched_matmul_kernel(
    a_ptr, b_ptr, c_ptr,
    batch, M, N, K,
    stride_a_batch, stride_a_m, stride_a_k,
    stride_b_batch, stride_b_k, stride_b_n,
    stride_c_batch, stride_c_m, stride_c_n,
    BLOCK_M: tl.constexpr, BLOCK_N: tl.constexpr, BLOCK_K: tl.constexpr,
):
    """
    Batched matrix multiplication C = A @ B, where
    A : (batch, M, K)
    B : (batch, K, N)
    C : (batch, M, N)

    All tensors are contiguous float32.
    """
    pid_b = tl.program_id(2)   # batch index
    pid_m = tl.program_id(0)   # tile row
    pid_n = tl.program_id(1)   # tile col

    # Tile offsets
    offs_m = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_n = pid_n * BLOCK_N + tl.arange(0, BLOCK_N)

    # Accumulator
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # Loop over K dimension in tiles
    for kb in range(0, tl.cdiv(K, BLOCK_K)):
        k_offset = kb * BLOCK_K + tl.arange(0, BLOCK_K)

        # Pointers for current tile
        a_ptrs = a_ptr + pid_b * stride_a_batch \
                 + offs_m[:, None] * stride_a_m \
                 + k_offset[None, :] * stride_a_k
        b_ptrs = b_ptr + pid_b * stride_b_batch \
                 + k_offset[:, None] * stride_b_k \
                 + offs_n[None, :] * stride_b_n

        # Masks for out‑of‑bounds loads
        a_mask = (offs_m[:, None] < M) & (k_offset[None, :] < K)
        b_mask = (k_offset[:, None] < K) & (offs_n[None, :] < N)

        a = tl.load(a_ptrs, mask=a_mask, other=0.0)
        b = tl.load(b_ptrs, mask=b_mask, other=0.0)

        # Compute tile multiplication
        acc += tl.dot(a, b)

    # Write back the result
    c_ptrs = c_ptr + pid_b * stride_c_batch \
             + offs_m[:, None] * stride_c_m \
             + offs_n[None, :] * stride_c_n
    c_mask = (offs_m[:, None] < M) & (offs_n[None, :] < N)
    tl.store(c_ptrs, acc, mask=c_mask)


def custom_kernel(data):
    """
    Triton‑accelerated forward pass of the outgoing TriMul operator.

    Parameters
    ----------
    data : tuple
        (input_tensor, mask_tensor, weights_dict, config_dict)

    Returns
    -------
    torch.Tensor
        Output tensor of shape [bs, seq_len, seq_len, dim] on the same device as input.
    """
    # ------------------------------------------------------------------
    # Unpack inputs
    # ------------------------------------------------------------------
    input_tensor, mask_tensor, weights, config = data
    dim = config["dim"]
    hidden_dim = config["hidden_dim"]
    eps = 1e-5  # same default as torch.nn.LayerNorm

    # ------------------------------------------------------------------
    # LayerNorm on the last dimension
    # ------------------------------------------------------------------
    norm_weight = weights["norm.weight"]
    norm_bias = weights["norm.bias"]
    x = F.layer_norm(
        input_tensor,
        normalized_shape=(dim,),
        weight=norm_weight,
        bias=norm_bias,
        eps=eps,
    )

    # ------------------------------------------------------------------
    # Linear projections (no bias)
    # ------------------------------------------------------------------
    left_proj_weight = weights["left_proj.weight"]
    right_proj_weight = weights["right_proj.weight"]
    left = F.linear(x, left_proj_weight)   # (B,N,N,H)
    right = F.linear(x, right_proj_weight)

    # ------------------------------------------------------------------
    # Optional mask (broadcast over hidden dimension)
    # ------------------------------------------------------------------
    if mask_tensor is not None and not config.get("nomask", False):
        mask = mask_tensor.to(x.dtype).unsqueeze(-1)  # (B,N,N,1)
        left = left * mask
        right = right * mask

    # ------------------------------------------------------------------
    # Gating (sigmoid of linear projections)
    # ------------------------------------------------------------------
    left_gate_weight = weights["left_gate.weight"]
    right_gate_weight = weights["right_gate.weight"]
    out_gate_weight = weights["out_gate.weight"]
    left_gate = torch.sigmoid(F.linear(x, left_gate_weight))
    right_gate = torch.sigmoid(F.linear(x, right_gate_weight))
    out_gate = torch.sigmoid(F.linear(x, out_gate_weight))

    left = left * left_gate
    right = right * right_gate

    # ------------------------------------------------------------------
    # Core multiplicative update: batched matmul with transposition
    # out[b,i,j,:] = Σ_k left[b,i,k,:] * right[b,j,k,:]
    # ------------------------------------------------------------------
    B, N, _, H = left.shape

    # Rearrange tensors to (B*H, N, N) for batched matmul
    left_batch = left.permute(0, 3, 1, 2).contiguous().view(B * H, N, N)
    right_batch = right.permute(0, 3, 2, 1).contiguous().view(B * H, N, N)  # transpose k & j

    # Allocate output buffer
    out_batch = torch.empty_like(left_batch)

    # Tile sizes – tuned for typical N (256‑1024) and hidden dim ≤ 768
    BLOCK_M = 64
    BLOCK_N = 64
    BLOCK_K = 32

    # Strides (in elements) for contiguous tensors
    stride_a_batch = left_batch.stride(0)
    stride_a_m = left_batch.stride(1)
    stride_a_k = left_batch.stride(2)

    stride_b_batch = right_batch.stride(0)
    stride_b_k = right_batch.stride(1)
    stride_b_n = right_batch.stride(2)

    stride_c_batch = out_batch.stride(0)
    stride_c_m = out_batch.stride(1)
    stride_c_n = out_batch.stride(2)

    # Launch kernel
    grid = (
        triton.cdiv(N, BLOCK_M),
        triton.cdiv(N, BLOCK_N),
        B * H,
    )
    batched_matmul_kernel[grid](
        left_batch,
        right_batch,
        out_batch,
        B * H,
        N,
        N,
        N,
        stride_a_batch,
        stride_a_m,
        stride_a_k,
        stride_b_batch,
        stride_b_k,
        stride_b_n,
        stride_c_batch,
        stride_c_m,
        stride_c_n,
        BLOCK_M=BLOCK_M,
        BLOCK_N=BLOCK_N,
        BLOCK_K=BLOCK_K,
    )
    torch.cuda.synchronize()

    # Reshape back to (B, N, N, H)
    out = (
        out_batch.view(B, H, N, N)
        .permute(0, 2, 3, 1)
        .contiguous()
    )  # shape (B,N,N,H)

    # ------------------------------------------------------------------
    # Second LayerNorm over hidden dimension
    # ------------------------------------------------------------------
    to_out_norm_weight = weights["to_out_norm.weight"]
    to_out_norm_bias = weights["to_out_norm.bias"]
    out = F.layer_norm(
        out,
        normalized_shape=(hidden_dim,),
        weight=to_out_norm_weight,
        bias=to_out_norm_bias,
        eps=eps,
    )

    # ------------------------------------------------------------------
    # Apply output gate and final linear projection back to dim
    # ------------------------------------------------------------------
    out = out * out_gate
    to_out_weight = weights["to_out.weight"]
    out = F.linear(out, to_out_weight)   # (B,N,N,dim)

    return out
