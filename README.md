# Max-Seeking Agentic Scientific Discovery

This document describes the conceptual framework implemented in this repository. It focuses on the scientific objective, the closed-loop discovery process, and the roles of tree search, online policy optimization, verifier feedback, and causal memory. Infrastructure and tuning details are intentionally omitted.

## 1. Problem setting: discovery is a best-of-budget problem

Let $d$ denote a problem specification containing a candidate space, validity constraints, and an evaluator. At search step $t$, the agent starts from a parent state $s$, proposes an action $a$, and constructs a candidate

$$
s' = T_d(s,a).
$$

The evaluator returns two complementary observations:

$$
R_d(s') \in \mathbb{R},
\qquad
F_d(s') \in \text{text},
$$

where $R_d$ is a scalar measure of candidate quality and $F_d$ is diagnostic feedback such as a violated constraint, failed test, execution error, or numerical issue. Invalid candidates receive the task's failure reward.

The important distinction from ordinary policy learning is that scientific discovery usually keeps the single best valid result. Let $\Pi$ denote the complete adaptive search procedure, including its dependence on all earlier evaluations. Given a total evaluation budget $B$, the natural objective is therefore

$$
J_B(\Pi)
=
\mathbb{E}_{s_{1:B}\sim\Pi}
\left[
\max_{1\le i\le B} R_d(s_i)
\right],
$$

or, for a target $r_\star$, the probability

$$
\Pr\!\left(\max_{1\le i\le B}R_d(s_i)>r_\star\right).
$$

This is not the same as maximizing the mean reward of a random proposal. A risky direction with rare exceptional outcomes can be preferable to a reliable direction that only produces moderate candidates. Every component below is designed around this best-of-budget objective.

## 2. State, tree, archive, and notation

Every valid candidate retained for continued search becomes a node in a rooted search tree. An edge records that a child was generated by modifying its parent. The tree preserves local trajectories: it tells us which ideas led to which descendants. Failed candidates remain learning evidence even when they are not eligible to become future parents.

The same retained nodes also form a flat archive $\mathcal D_t$. The archive allows candidates from different branches and depths to compete globally. The framework returns

$$
s^\star_t = \arg\max_{s\in\mathcal D_t,\,s\text{ valid}}R_d(s),
$$

so a later policy update cannot erase a discovery that has already been made.

We use the following notation throughout:

| Symbol | Meaning |
|---|---|
| $s,p$ | a candidate state and a selected parent state |
| $a,y$ | a proposed action or generated response |
| $r=R_d(s)$ | scalar reward, with larger values preferred |
| $f=F_d(s)$ | textual verifier feedback |
| $\mathcal D_t$ | archive of retained candidates at step $t$ |
| $\mathcal T(s)$ | subtree rooted at $s$ |
| $K$ | rollouts generated from one parent for a group-relative update |
| $B$ | total evaluation budget |
| $\mathcal M_t$ | memory bank after step $t$ |

## 3. The complete discovery loop

One iteration performs the following conceptual operations:

1. **Choose where to search.** Score archived states with max-oriented PUCT and select a diverse batch of parents.
2. **Choose what prior experience to expose.** For each parent, select contextually relevant lessons from memory, retain a no-memory control, and reserve an arm for an under-tested lesson.
3. **Propose candidates.** Sample a group of continuations from each parent. The total rollout budget of a parent is divided among the memory arms rather than increased by them.
4. **Verify every candidate.** Obtain a scalar reward, validity result, and textual diagnostic.
5. **Expand the search structure.** Add valid evaluated candidates to the tree and archive, update lineage statistics, and preserve the strongest discoveries.
6. **Construct the max-seeking reward signal.** Within each parent group, give most of the policy-gradient mass to the upper tail rather than optimizing the group mean.
7. **Construct the failure-repair signal.** On selected failures, turn verifier text into a token-level advantage using the current policy as a feedback-conditioned self-teacher.
8. **Update the proposal policy.** Combine the max-seeking reward advantage and bounded failure-feedback advantage in one online update.
9. **Update memory.** Extract reusable lessons by contrasting children with their parents and successful attempts with failures. Credit injected lessons only from their measured improvement over the matched no-memory arm.
10. **Repeat under a fixed budget.** The archive's best valid candidate is the final output.

The components have different responsibilities. Tree search decides **where** to spend evaluations. The online update changes **how** candidates are proposed. Feedback explains **how to repair** invalid attempts. Memory tests and reuses **what has transferred** across earlier attempts.

## 4. Current max-oriented PUCT

The current selector treats every archived state as a possible parent. For state $s$, define

$$
\operatorname{Score}_t(s)
=
Q_t(s)
+
c\,\Delta_t\,P_t(s)
\frac{\sqrt{1+T_t}}{1+n_t(s)}.
$$

The terms are:

- $Q_t(s)$: the best reward among children generated directly from $s$; before $s$ is expanded, its own reward is used.
- $P_t(s)$: an archive-wide rank prior. Better observed states receive more prior mass, while every retained state keeps nonzero mass.
- $\Delta_t$: the observed reward range, which places exploitation and exploration on a comparable scale.
- $T_t$: total rollout effort allocated so far.
- $n_t(s)$: effort allocated to $s$ or any of its descendants.
- $c$: the exploration strength.

More explicitly, if $\rho_t(s)\in\{1,\ldots,N_t\}$ is the reward rank of $s$ with rank one assigned to the best state, then

$$
P_t(s)
=
\frac{N_t-\rho_t(s)+1}
{\sum_{j=1}^{N_t}j},
\qquad
\Delta_t
=
\max_{u\in\mathcal D_t}R_d(u)-\min_{u\in\mathcal D_t}R_d(u).
$$

Ranks prevent the prior from being dominated by an outlier or by the arbitrary numerical scale of a task. The reward range then restores the units needed to add the exploration term to $Q_t$.

The first term is deliberately a maximum, not an average. If one branch produces an exceptional child and several failures, averaging would hide the event that matters for discovery. The lineage visit count in the denominator prevents a successful family from receiving unlimited budget merely because its best value remains high.

### Batch diversity

Selecting the top several scores independently can waste a batch on one nearly identical lineage. After a state is selected, its ancestors and descendants are temporarily blocked from the rest of the same batch. This encourages simultaneous exploration of structurally different branches. If strict blocking leaves too few candidates, the remaining slots are filled by score.

### Archive update

After evaluation, exact duplicate candidates are removed, each parent retains its strongest children, and the archive retains high-reward candidates while preserving the roots. These operations keep the search state manageable without changing the best-so-far objective.

### Present limitation

PUCT chooses parents, but it does not choose the number of additional samples each parent deserves within the iteration. Once a parent is selected, it receives a predetermined group of rollouts. Weak and saturated parents can therefore consume the same short-term budget as uncertain parents with substantial upside. The budget-aware extension in Section 9 targets this limitation.

## 5. Max-seeking group-relative policy optimization

Tree search reallocates evaluations among existing states, but the proposal policy itself must also learn to place more probability on rare high-quality continuations. A mean-centered group objective is not sufficient: it improves a typical sample, whereas discovery is judged by the best sample found under a budget.

### 5.1 Entropic upper-tail objective

For a fixed parent $p$, consider the risk-seeking objective

$$
\mathcal J_\beta(\pi;p)
=
\frac{1}{\beta}
\log
\mathbb E_{y\sim\pi(\cdot\mid p)}
\left[e^{\beta R_d(y)}\right],
\qquad \beta>0.
$$

It interpolates between mean-seeking and max-seeking behavior:

$$
\lim_{\beta\to 0}\mathcal J_\beta
=
\mathbb E[R_d(y)],
\qquad
\lim_{\beta\to\infty}\mathcal J_\beta
=
\operatorname*{ess\,sup}R_d(y).
$$

For a sampled group $\{y_i,r_i\}_{i=1}^K$ from the same parent, define the exponentially tilted empirical distribution

$$
q_\beta(i)
=
\frac{e^{\beta r_i}}
{\sum_{j=1}^{K}e^{\beta r_j}}.
$$

Increasing $\beta$ concentrates mass on the best members of the group. The update is GRPO-like because it compares sibling responses from the same prompt and does not require a learned value model, but its relative advantage is constructed to favor the upper tail rather than to standardize performance around the group mean.

### 5.2 Adaptive selection pressure

A fixed $\beta$ has no stable meaning across tasks or stages: a small numerical reward gap on one problem may be decisive, while a large gap on another may be ordinary. We therefore choose $\beta$ separately for each parent group by fixing the information distance from uniform weighting:

$$
D_{\mathrm{KL}}\!\left(q_\beta\,\middle\|\,U_K\right)=\gamma,
$$

where $U_K$ is uniform over the $K$ siblings and $\gamma$ is a fixed concentration budget. This makes the strength of selection invariant to reward shifts and positive rescaling: $\beta$ adjusts inversely to the scale. When rewards are close, a larger $\beta$ is needed to reach the same concentration; when rewards are widely separated, a smaller $\beta$ suffices. If ties make the requested divergence unattainable, the most concentrated available tilt is used.

### 5.3 Leave-one-out advantage

To reduce self-inclusion bias, response $i$ is compared with a normalizer formed from its siblings:

$$
Z_{-i}
=
\frac{1}{K-1}
\sum_{j\ne i}e^{\beta(r_j-r_{\max})},
\qquad
A_i^{\max}
=
\frac{e^{\beta(r_i-r_{\max})}}{Z_{-i}}-1.
$$

The best responses receive positive advantages and weak responses receive negative advantages, with the contrast becoming sharper as the tilted distribution concentrates. If every sibling has the same reward, $A_i^{\max}=0$: the scalar evaluator has provided no evidence for preferring one response over another. Failure feedback can still provide a learning signal in exactly this case.

The policy update uses $A_i^{\max}$ across the tokens of response $i$, together with a stabilizing regularization toward a reference policy. This is a surrogate for the exact best-of-$B$ objective, not a claim that every finite-batch update directly optimizes the archive maximum.

## 6. Verifier feedback as token-level failure repair

A scalar failure reward identifies a bad response but cannot identify the responsible decisions. Many failed responses therefore receive the same reward even though one has a syntax error, another violates a constraint, and a third is almost valid. Mean- or max-relative reward alone cannot distinguish them.

For a failed response $y_i=(y_{i,1},\ldots,y_{i,L_i})$, let $x_p$ be its original parent prompt and $f_i$ the verifier's diagnostic. Freeze the rollout policy $\pi_{\bar\theta}$, then evaluate the already-sampled response under two contexts:

$$
\pi_{\bar\theta}
\left(y_{i,\ell}\mid x_p,y_{i,<\ell}\right)
\quad\text{and}\quad
q_{\bar\theta}
\left(y_{i,\ell}\mid x_p,f_i,y_{i,<\ell}\right).
$$

The model parameters are identical; only the presence of the feedback differs. Their log-ratio defines a token-level feedback advantage:

$$
A^{\mathrm{fb}}_{i,\ell}
=
\log q_{\bar\theta}
\left(y_{i,\ell}\mid x_p,f_i,y_{i,<\ell}\right)
-
\log \pi_{\bar\theta}
\left(y_{i,\ell}\mid x_p,y_{i,<\ell}\right).
$$

This has a direct interpretation:

- $A^{\mathrm{fb}}_{i,\ell}>0$: after seeing the diagnostic, the policy considers the sampled token more consistent with a corrected solution.
- $A^{\mathrm{fb}}_{i,\ell}<0$: the diagnostic makes the sampled token less plausible, so it is discouraged.
- $A^{\mathrm{fb}}_{i,\ell}\approx0$: the diagnostic gives little evidence about that token.

Thus the verifier acts as information, not as a second reward function. No separate teacher or learned critic is required; the current policy interprets the diagnostic itself.

For failure indicator $d_i$, the combined token advantage is

$$
A_{i,\ell}
=
A_i^{\max}
+
\lambda_f d_i A^{\mathrm{fb}}_{i,\ell}.
$$

Successful responses are unaffected by the feedback term. Failed responses retain the global direction supplied by max-seeking reward while receiving dense local repair information.

### Adaptive and balanced use of feedback

Feedback is most useful when invalidity is the bottleneck. Its strength is therefore controlled by the observed validity deficit: it is strongest at low validity, decreases as the valid fraction approaches a target region, and turns off when repair is no longer needed. Its magnitude is also bounded relative to the reward advantage so that “be valid” cannot silently replace “make a better discovery” as the optimization objective.

The feedback budget scales with the number of rollouts available in the current step. Within that budget, failures are sampled round-robin across normalized failure signatures, with a cap per signature. This prevents one common error message from dominating the dense signal and preserves evidence about rarer failure modes.

## 7. Memory as a causal contextual bandit

Naive memory injection can accelerate search, but it can also cause rapid collapse into a local basin. The failure mechanism is a positive feedback loop:

1. An early lesson is extracted from a stochastic success.
2. Reusing it changes the proposal distribution toward similar candidates.
3. Similar candidates produce more apparently confirming examples.
4. Selection frequency is mistaken for evidence that the lesson caused improvement.
5. Diversity falls, and alternative strategies stop receiving enough trials to challenge the incumbent basin.

There is also a statistical confound: the maximum of more samples is larger in expectation even when the underlying proposal distributions are identical. Comparing the raw maximum of a large memory arm with that of a small control arm therefore gives memory automatic credit.

We treat memory as an intervention that must earn future search budget, rather than as text that is assumed to be useful.

### 7.1 Lesson formation

After each step, evaluated trajectories are partitioned into valid successes and failures. Extraction is contrastive in two senses:

- **Child versus parent:** a lesson should describe what changed and whether that change improved the reward, not merely restate a high-scoring construction.
- **Success versus failure:** useful operations and recurring pitfalls are both retained. Failures are sampled across distinct signatures so a repeated crash does not fill the evidence set.

Each lesson records a concise strategy or failure-avoidance principle, its origin, scope, and later outcome evidence. Near-duplicate lessons are consolidated. Memory hygiene distinguishes transferable local operations from global prescriptions that effectively copy an entire solution. Over-specific global constructions are rejected because they are especially likely to lock the search to one basin.

### 7.2 Contextual selection

For each selected parent $p$, a memory selector observes a compact catalog of available lessons and may select a small subset or select nothing. The parent is the bandit context, and the chosen lesson set is the action. This makes lesson use explicit and contextual: a lesson may help one search state and harm another.

Selection frequency and textual reconfirmation are not causal evidence. They are tracked separately from the controlled outcome statistics used to estimate a lesson's utility.

### 7.3 Budget-neutral treatment, control, and exploration arms

The existing $K$ rollouts for parent $p$ are divided among three prompt arms:

1. **Selected-memory arm:** the lessons judged relevant to $p$.
2. **No-memory arm:** a matched control generated from the same parent without a lesson.
3. **Exploration arm:** an under-tested lesson chosen by an upper-confidence rule.

The counts satisfy

$$
K_{\mathrm{sel}}+K_0+K_{\mathrm{exp}}=K.
$$

Memory therefore does not require a second full run with and without memory. Treatment and control coexist inside the same parent group and share the same total evaluation budget. Their rollouts are pooled for the max-seeking group update, while their labels are retained for memory credit.

### 7.4 Matched tail-uplift credit

The contextual quantity of interest is not the mean reward of a lesson, but its change in the attainable tail at parent $p$:

$$
\Delta_a^{(n)}(p)
=
\mathbb E\!\left[\max_{1\le j\le n}R_j^{(a)}\mid p\right]
-
\mathbb E\!\left[\max_{1\le j\le n}R_j^{(0)}\mid p\right],
$$

where $R^{(a)}$ and $R^{(0)}$ denote potential rewards under the memory and no-memory prompts. Keeping the parent, policy snapshot, and search step matched removes the main contextual confounders; interpreting the difference causally assumes that rollout randomness is comparable across arms and that an arm's outcomes do not alter another arm within the same comparison.

Let $\mathbf r_a=(r_{a,1},\ldots,r_{a,K_a})$ be the observed rewards from arm $a$. To compare a memory arm $a$ with the control arm $0$, use the common effective sample size

$$
n=\min(K_a,K_0).
$$

For sorted rewards $r_{(1)}\le\cdots\le r_{(K_a)}$, the expected maximum of a uniformly drawn size-$n$ subset without replacement is

$$
\widehat M_n(\mathbf r_a)
=
\frac{1}{\binom{K_a}{n}}
\sum_{j=n}^{K_a}
\binom{j-1}{n-1}r_{(j)}.
$$

The matched max-seeking effect of the memory arm is

$$
\widehat\Delta_a
=
\widehat M_n(\mathbf r_a)
-
\widehat M_n(\mathbf r_0).
$$

Both sides are now best-of-$n$. Positive uplift means the lesson improved the outcome that matters under an equal rollout budget; negative uplift means it hurt. Validity and improvement over the parent are retained as secondary diagnostics, but they do not replace tail uplift as the primary discovery credit.

When several lessons appear in one arm, $\widehat\Delta_a$ identifies the effect of the set, not the isolated contribution of each member. Sparse lesson sets and repeated trials across different contexts improve identifiability.

### 7.5 Exploration and memory retention

For lesson $\ell$, let $N_\ell$ be its number of controlled trials and $\bar\Delta_\ell$ its mean matched tail uplift. An under-tested lesson is selected using an upper-confidence index of the form

$$
\operatorname{UCB}_t(\ell)
=
\bar\Delta_\ell
+
c_m\,s_t
\sqrt{
\frac{\log(1+N_t)}{N_\ell}
},
$$

where $N_t$ is total memory evidence and $s_t$ places the exploration bonus on the observed uplift scale. Untested lessons receive priority. This creates a controlled route for neglected ideas to accumulate evidence instead of letting early winners monopolize retrieval.

Matched uplift is the primary outcome statistic. Tail wins, validity, and improvements over the parent are retained as diagnostics of how a lesson transfers. When memory capacity is limited, lessons with weaker controlled uplift receive lower retention priority. The no-memory arm remains essential throughout: without it, changing parents, policy parameters, or search difficulty would be confounded with the effect of memory.

## 8. Why the signals are complementary

The framework deliberately does not collapse every observation into one scalar:

| Component | Unit of decision | Signal | Role in discovery |
|---|---|---|---|
| Current PUCT | archived state | best child plus exploration bonus | allocate evaluations across branches |
| Max-seeking GRPO | sibling rollout | entropic relative reward | move policy probability toward the upper tail |
| Verifier feedback | token in a failed rollout | feedback-conditioned log-ratio | repair invalid or incorrect trajectories |
| Memory bandit | lesson intervention at a parent | matched best-of-$n$ uplift | retain only reusable experience that causally helps search |

This separation prevents two common objective errors. First, frequent validity failures should trigger repair, but high validity alone is not scientific progress. Second, a plausible or frequently selected lesson should not receive credit unless it improves the tail under a matched budget.

The resulting loop is max-seeking at three time scales:

- **Within a group:** exponential tilting emphasizes the best sibling response.
- **Across search states:** PUCT exploits the best observed continuation while preserving exploration.
- **Across repeated memory use:** lessons are judged by improvement in an equal-budget maximum rather than by average reward or retrieval count.

## 9. Next step: budget-aware dynamic PUCT

The current search allocates a full group after choosing a parent. A more efficient extension should jointly decide **where to search** and **whether that location deserves one more sample**.

For each node $s$, define the demonstrated subtree value and subtree effort

$$
W_m(s)=\max_{y\in\mathcal T(s)}R_d(y),
\qquad
m_s=|\mathcal T(s)|.
$$

Using $W_m$ preserves a rare exceptional descendant instead of averaging it with failures. Let $R^{\mathrm{rk}}(s)$ be its ascending archive-wide rank, so a larger rank means a better subtree, using average ranks for ties. A reward-scale-invariant global logit is

$$
L_{\mathcal D}(s)
=
\frac{R^{\mathrm{rk}}(s)-\mu_{\mathrm{rk}}}
{\sigma_{\mathrm{rk}}},
$$

where $\mu_{\mathrm{rk}}$ and $\sigma_{\mathrm{rk}}$ are computed across the archive.

At a parent $p$, augment the real children with a virtual action $\hat s_p$ meaning “generate one additional child here”:

$$
\mathcal A(p)=\operatorname{Ch}(p)\cup\{\hat s_p\}.
$$

If the real children have logits with mean $\mu_L(p)$ and standard deviation $\sigma_L(p)$, assign the unseen child an optimistic logit

$$
L_p(\hat s_p)=\mu_L(p)+\lambda\sigma_L(p).
$$

The mean estimates the typical productivity of the parent; the dispersion measures upside. A parent that occasionally produces exceptional children can therefore justify another sample even when most of its children are weak. Convert real and virtual logits into a local prior

$$
\pi_{\mathcal D}(a\mid p)
=
\frac{\exp(L_p(a)/\tau)}
{\sum_{b\in\mathcal A(p)}\exp(L_p(b)/\tau)},
$$

and score each action by

$$
\operatorname{D\text{-}PUCT}(p,a)
=
V(p,a)
+
c\,\pi_{\mathcal D}(a\mid p)
\frac{\sqrt{m_p}}{1+m_{p,a}},
$$

where $V(p,a)=W_m(a)$ for a real child and $m_{p,a}$ is the effort already assigned to that action. The virtual action uses a neutral exploitation value and $m_{p,\hat s_p}=0$, so its opportunity is determined by the optimistic prior and the undiminished exploration bonus.

This produces two kinds of work:

- **Deepen:** expand a promising leaf with a group large enough to support a group-relative policy update.
- **Widen:** spend only one additional rollout on the virtual child of an already explored parent.

If a round selects $n$ actions and a leaf expansion produces $K$ siblings while a virtual action produces one, then its evaluation cost obeys

$$
n\le B_t\le nK.
$$

Consequently, the evaluation count becomes adaptive rather than fixed. The search can cheaply probe uncertain parents, stop widening branches whose upper-confidence value has fallen below stronger alternatives, and concentrate the remaining budget on branches that are both promising and insufficiently tested. A small protected exploration share should remain so that early noisy maxima do not eliminate alternative basins.

This extension keeps the same max-seeking principle while making the unit of allocation finer: not “every selected parent receives the same number of rollouts,” but “each additional rollout must compete for the remaining discovery budget.”

## 10. Summary

The framework treats scientific discovery as retaining the best valid candidate found under a limited evaluation budget. Its central design choices follow from that objective:

- max-oriented PUCT allocates search across candidate lineages;
- an adaptive entropic group advantage trains the proposal policy toward rare high rewards;
- verifier-conditioned self-teaching supplies token-level repair information when scalar rewards collapse;
- a controlled memory bandit separates contextual usefulness from self-reinforcing retrieval frequency; and
- the proposed dynamic PUCT extension allocates future evaluations one marginal sample at a time.

The unifying principle is simple: optimize and measure every auxiliary mechanism by whether it increases the best attainable valid result under the same budget.
